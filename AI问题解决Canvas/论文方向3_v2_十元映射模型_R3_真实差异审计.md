# 论文方向3 v2｜十元映射模型研究｜R3 真实差异审计

> 目标：不再问“十元像哪个理论”，而是逐项审：
>
> **Conceptual Spaces + Semantic Differential + Coding Scheme 已经能做到什么；十元还剩哪些差异是真正可实验的。**
>
> 原则：
> - 社会已有的，不抢“新增”；
> - 只是换名的，砍掉；
> - 只有能被独立实验推翻/保留的，进入 R4。

---

# 0｜R3 总结

R2 曾暂时把十元叫：

> Theory-defined Bipolar Semantic Mapping Space

R3 必须收紧。

因为“bipolar semantic scale / conceptual space”通常隐含：
- 明确维度；
- 中间位置；
- 可比较尺度；
- 某种距离或排序结构。

而十元当前只有：

> **5 组理论定义的相反结构端点**

目前没有正式定义：
- 连续轴；
- 中点；
- 距离函数；
- 轴内插值；
- 凸区域；
- prototype distance。

因此当前更安全的说法：

> **Theory-defined Semantic Mapping Scheme with Paired Oppositional Endpoints**

中文：

> **一套由理论定义、包含五组成对相反端点的语义映射体系。**

只有未来证明十元轴具备稳定的尺度、距离和中间结构，才适合进一步称为严格意义上的“semantic space / bipolar scale”。

---

# 1｜十个位置是不是新增？

## 社会已有

Coding / codebook 完全可以预定义：
- 10 个 code；
- inclusion / exclusion；
- nearest-neighbor；
- multi-label；
- hierarchy。

Conceptual Spaces 也可以有多个 prototype / region。

所以：

> **“我有十个位置”本身不是新增。**

## R3 判定

**NO NOVELTY CLAIM**

十元真正需要证明的是：

> 这十个位置是否比普通 codebook 更稳定、更有区分力、更能迁移。

---

# 2｜五组相反端是不是新增？

## 社会已有

Semantic Differential 的核心就是：
> 用固定相反端建立 profile。

Conceptual Spaces 也允许：
> 维度、方向、原型、区域和距离。

所以：

> **“我有 5 对相反端”本身不是新增。**

## 但十元有一个具体差异

十元的 5 对不是：
- 好↔坏；
- 强↔弱；
- 快↔慢。

而是每对都声称共享一个**核心结构变量**，两端是在该变量上的相反操作。

例如当前正本：

```
ZX ↔ NX
同一核心：最终方向与作用权来源
两端：自身生成/占据方向 ↔ 沿既有方向续接

ZN ↔ X
同一核心：对象独立成立资格与归属方式
两端：保留独立成立 ↔ 纳入掌握/处分边界
```

这不是传统 adjective-pair 的表面反义。

## R3 判定

这不是“理论新发明”的证据，但它是一个**可实验结构候选**：

> **PAIR-CORE HYPOTHESIS**
>
> 同一对十元是否真的围绕同一个核心变量形成稳定、可区分的相反操作？

如果不能：
> 五组相反端只是理论命名。

如果能：
> 才有资格继续讨论“结构轴”。

---

# 3｜十元映射 profile 是不是新增？

## 社会已有

Semantic Differential：
- 一个对象；
- 多个尺度；
- 得到 profile。

Multi-label coding：
- 一个对象；
- 多个 code；
- 允许权重 / confidence。

所以：

> **“一个对象有多个十元分数”不是新增。**

主 / 次也可以被普通：
- ranking；
- salience；
- dominant code

表达。

## R3 判定

**NO NOVELTY CLAIM**

但十元需要解决一个测量问题：

> T / M / C 到底是不同可重复测量，还是同一个“感觉强弱”被拆了几个名字？

这进入：
**MEASUREMENT-SEPARATION TEST**

---

# 4｜T / M / C / E 是否新增？

## 社会已有

- weight；
- salience；
- confidence；
- effect magnitude

社会都已有成熟概念。

所以四分法不是基础创新。

## 十元值得验证的是

### T
结构占位是否能跨阶段相对稳定？

### M
当前显影是否能在 T 不变时独立变化？

### C
置信度是否能与 T/M 分离？

### E
关系作用量是否只在关系成立后出现，并与端点自身强弱分离？

如果数据上高度混在一起：
> 四字段只是命名分账。

如果确实能独立变化：
> 才证明这个 schema 分离有实际价值。

## R3 判定

**MEASUREMENT DISCIPLINE CANDIDATE**
不是新增理论。

---

# 5｜三元复核是不是新增？

## 当前十元规则

三元：
- x
- n
- z

与十元：
- 独立判定；
- 不是父子派生；
- 用于比例 / 质地 / 侧重复核。

这意味着同一个对象有两套表示：

```
Ten-Yuan Mapping
↕
Three-Yuan Mapping
```

## 社会已有相近思想

研究方法里早已有：
- multiple coding views；
- convergent evidence；
- multi-method validation；
- independent annotation；
- auxiliary representation。

所以：

> “我有第二套表示来复核”本身不是新增。

## 真正可实验的问题

> **三元复核是否真的发现十元映射的错误？**

例如：
- 没有三元复核：ZX / NX 易混；
- 加三元复核：是否减少某类混淆？

如果只是同一人、同一证据、同一套理论再说一遍：
> 不构成独立验证。

## R3 判定

**ERROR-DETECTION CANDIDATE**

只允许主张：
> 三元可能是映射纠错层。

不能主张：
> 三元已经证明十元正确。

---

# 6｜“跨所有对象都能映射”是不是十元的重要差异？

这是 R3 目前最值得保留的一个候选。

## Conceptual Spaces 通常怎样做

Conceptual Spaces 常以：
- color；
- shape；
- size；
- taste；
- spatial dimensions

等**领域相关 quality dimensions**构建空间。

不同对象域不一定共享完全相同维度。

## Semantic Differential 怎样做

Semantic Differential 的优势恰好是：
> 同一组较通用的 connotative dimensions 可以跨很多概念评分。

但它主要捕捉：
> evaluative / affective / connotative meaning。

## 十元的主张更强

十元试图用**同一套 10 个结构端点**映射：

- 人物本体；
- 人物状态；
- 行为；
- 关系；
- 场景；
- 光影；
- 组织；
- 制度；
- 概念；
- 叙事；
- 音乐；
- 视觉结构……

并通过：
> object_layer / current_window

避免跨层污染。

这不是普通 codebook 的必然属性。

## R3 判定

### **CANDIDATE-A｜Cross-domain Structural Invariance**

问题：

> **同一套十元端点，在换对象域以后，定义是否仍保持同一结构含义，而不是每到一个领域就偷偷换定义？**

这是非常强，也非常危险的主张。

如果：
- 角色里的 ZX；
- 场景里的 ZX；
- 音乐里的 ZX；
- 组织里的 ZX

其实各说各话，

那么“统一映射模型”失败。

如果核心操作保持一致，只是领域显化不同：
> 十元才真正具有跨域映射价值。

---

# 7｜“端点成立后才允许关系”是不是新增？

## 社会已有相近结构

Ontology / typed relation systems 早已有：
- relation domain / range；
- type constraints；
- rule preconditions。

Conceptual-space formalizations也可以定义：
- concept operations；
- concept relations；
- inference。

所以：

> **“先有类型，再限制关系”不是新思想。**

## 十元具体可测的差异

十元关系审计要求：

```
端点A成立
+ 端点B成立
+ 同一对象层 / current window
+ mechanism
+ target_variable
+ reverse test
+ third-factor exclusion
↓
才允许生 / 克 / 补
```

真正要测：

> 这套 endpoint-gated relation protocol 是否减少“看见两个概念就乱连关系”的假阳性？

## R3 判定

### **CANDIDATE-B｜Endpoint-Gated Relation Inference**

不是新逻辑结构，
而是可验证的**关系误判抑制协议**。

---

# 8｜生克补本身还剩什么差异？

不能再拆成：

```
生 vs support
克 vs conflict
补 vs compensate
```

因为那只是词义层。

在十元里真正的单位是：

```
Endpoint A
+ Endpoint B
+ relation eligibility
+ mechanism
+ target_variable
+ direction
+ E
```

所以 R3 对生克补的唯一保留问题是：

> **在十元端点已经可靠以后，生/克/补能否把关系案例分成稳定、互斥或可复核的作用模式？**

这属于：
**Gate 4 Relation Utility**

现在不能提前研究。

---

# 9｜动态重映射是不是新增？

## 社会已有

2024 年已有 Conceptual Spaces 动态模型，明确研究：
- conceptual prototypes 随时间变化；
- conceptual space 随 agent interaction 演化。

因此：

> **“概念空间会动态变化”不是十元新增。**

## 十元可能不同的地方

十元当前要求：

```
Stage0
重新判对象十元
→ 冻结端点
→ 判关系

Stage1
对象/状态变化
→ 重新检查十元映射
→ 端点可能变化
→ 原关系不能自动继承
→ 必须重新判关系
```

这是一套具体的**重映射—再关系审核 protocol**。

## R3 判定

### **CANDIDATE-C｜Remap-before-Relation-Reaudit**

不是新的动态理论。

真正可测的是：

> 每阶段先重映射再判关系，是否比“直接沿用上一阶段标签/关系”更少出错？

---

# 10｜最近邻 / 正反证 / 拿掉 / 反向测试是不是新增？

不是。

成熟 codebook 和可靠性研究本来就强调：
- definition；
- inclusion；
- exclusion；
- boundary cases；
- reliability。

因果/关系研究也大量使用：
- counterfactual reasoning；
- competing explanation；
- robustness checks。

所以这些是：

> **GOOD METHODOLOGICAL DISCIPLINE**

但不能当十元理论创新。

它们的价值在于：
> 把十元从“凭感觉贴标签”推向可审核 coding protocol。

# 12｜R3 最终保留 4 个“可实验差异”

注意：
它们不是“已证明创新”。

只是：
> **值得进入实验的差异。**

## A｜Cross-domain Structural Invariance
### 跨对象域结构不变性

同一个十元在：
- 人物；
- 场景；
- 关系；
- 组织；
- 概念；
- 音乐

中是否保持同一个核心结构？

---

## B｜Pair-Core Discriminability
### 五组相反端的共享核心变量 + 相反操作是否可区分

例如：
ZX / NX 是否真的围绕同一核心变量，
而不是两个随便并排的 code？

---

## C｜Three-Yuan Error-Detection Gain
### 三元复核是否真的减少十元误判

不是问三元“对不对”。

而是：
> 加三元复核后，错误是否下降？

---

## D｜Endpoint-Gated Relation Error Reduction
### 先端点、后关系是否降低关系假阳性

比较：

```
普通：看到 A/B → 直接判关系

十元协议：
A/B → 映射 → 端点冻结 → 机制门 → 再判关系
```

是否真的少乱连边？

---

# 13｜动态链暂时降级

动态链不进入第一轮核心验证。

原因：

> 如果 Mapping Reliability / Pair Discriminability 都还没过，
> 动态链没有可靠端点。

所以新顺序：

```
A 映射可靠
↓
B 相反端区分
↓
C 三元复核增量
↓
D 端点门控关系
↓
最后才动态链
```

这比旧路线安全得多。

# 14｜对论文方向3的直接影响

方向3现在应该优先收小：

旧问题：

> 如何把创作意图结构化，并用十元生克补动态链帮助 AI？

太大。

R3 后最稳的问题变成：

> **一套固定的十元结构映射，能否把不同创作对象稳定映射到可区分的语义位置？**

更进一步才问：

> **这种映射是否比普通分类 / 通用语义 profile 对后续创作判断更有用？**

对于 5000 字本科论文：

> **只做到 Mapping Reliability + Discriminant Validity，其实已经能形成完整研究。**

生克补/动态链可以放：
- 理论背景；
- 后续研究；
- 扩展实验。

不必一次全塞。

# 15｜R3 DONE

本轮完成：

- 撤回“严格 bipolar semantic space”表述；
- 改为 paired oppositional endpoints；
- 证明 10位置 / 双极 / profile / weight / dynamic 本身都有社会先例；
- 找出 4 个真正可实验差异：
  A 跨域结构不变性；
  B 相反端共享核心变量与区分度；
  C 三元复核纠错增量；
  D 端点门控关系误判下降；
- 动态链退出第一验证层；
- 论文优先收束到 Mapping Reliability / Discriminant Validity。

# 16｜R4 READY

R4 只做：

> **把方向3重建成一个本科可做、不会又扩大爆炸的论文方案。**

候选最小实验：

1. 选 30–60 个真实创作对象；
2. 覆盖人物 / 场景 / 关系 / 概念 4 个对象域；
3. 两个以上编码者独立十元映射；
4. 测主十元一致性 + profile 距离/重合；
5. 专门测 5 组相反端最近邻混淆；
6. 加 / 不加三元复核做 A/B；
7. 最后才拿少量端点去做关系门控验证。

R4 输出：
- 可直接写开题的研究问题；
- 变量；
- 样本；
- 方法；
- 指标；
- STOP；
- 5000 字论文结构。
