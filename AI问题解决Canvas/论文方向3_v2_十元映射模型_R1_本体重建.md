# 0｜R1 核心结论

十元当前最准确的研究定位不是：

- 关系词表；
- Generic Intent Graph 的关系层；
- 三元直接派生出的十分类；
- 普通 ontology class。

更接近：

> **Ten-Yuan Semantic Mapping Model**
> 
> 一套把现实对象 / 概念 / 状态 / 创作意图映射到十元语义空间中的结构化映射模型。

然后才是：

> Mapping → Relation Activation → Dynamic Evolution

完整链：

```
现实对象 / 概念 / 创作意图
↓
冻结对象、主体、阶段、对象层
↓
独立十元映射
X / Z / N / ZN / NZ / XN / NX / ZX / XZ / X并Z
↓
主 / 次 + T / M / C
↓
三元 x / n / z 独立判定与比例质感复核
↓
十元端点成立
↓
两个端点进入关系审计
↓
生 / 克 / 补 / NONE / AMBIGUOUS
↓
E 关系作用量
↓
动态链跨阶段重新映射与重新判关系
```

# 1｜十元映射不是单标签分类

一个对象并不是只能得到一个标签。

当前概念映射正本允许：

- 主十元；
- 次十元；
- 功能十元；
- 每个十元 1–10 映射强度；
- 正证据；
- 反证据；
- 最近邻；
- 对象层；
- 当前阶段。

所以更准确是：

> **multi-position weighted semantic mapping**

即：
一个对象可以在十元空间里形成一个分布，而不是被硬塞进唯一类别。

例：

```
对象 O
ZX = 8
Z  = 6
XN = 3
其余较低
```

最后再从分布中判：
- 主；
- 次；
- 功能；
- 当前阶段显影。

# 2｜十元不是由三元算出来

三元正本明确：

> 三元与十元不是父子派生关系。

所以不能：

```
x/n/z比例
→ 算出某个十元
```

正确是：

```
十元独立判断
↕
三元独立判断
↓
做质地 / 比例 / 侧重的复核
```

三元作用更接近：

> **cross-check representation layer**

它帮助解释“为什么同一十元会呈现不同质地”，但不能取代十元本体证据。

# 3｜十元空间具有 5 组相反端

当前正本：

```
木：ZX ↔ NX
火：ZN ↔ X
土：N ↔ X并Z
金：XN ↔ Z
水：XZ ↔ NZ
```

这意味着十元不是十个毫无结构的独立标签。

它具有：

> **五组共享核心变量、方向相反的结构端点。**

所以十元映射模型至少同时包含：

1. 十个语义端点；
2. 五组相反端结构；
3. 主次 / 体量；
4. 显影；
5. 三元质地复核；
6. 后续关系位置盘。

# 4｜十元更像“空间映射”而不是普通 taxonomy

普通 taxonomy 常问：

> 这个对象属于哪个类别？

十元更像问：

> 这个对象在一套固定结构空间里，各个位置映射强度分别是多少？

所以研究语言应该优先使用：

- semantic space；
- mapping；
- position；
- profile；
- distribution；
- polarity / opposite poles；
- domain manifestation。

而不是只用：

- class；
- tag；
- category。

# 5｜映射完成后关系才出现

关系不是输入十元的第一步。

必须：

```
对象A → 十元映射A
对象B → 十元映射B
↓
A/B 两端成立
↓
检查当前对象层 / 阶段 / 改变变量
↓
才调用关系位置与生克补证据
```

因此：

> **mapping produces eligible endpoints for relation analysis**

注意：
不是说“映射自动推出关系”。

更准确是：

> 映射完成后，才获得有资格进行关系审计的端点。

关系仍然需要独立机制证据。

# 6｜动态链也必须建立在重新映射之上

动态链不是：

```
关系词1 → 关系词2 → 关系词3
```

而应该是：

```
Stage 0
对象重新判十元位置
→ 端点成立
→ 关系审核

Stage 1
对象状态/阶段变化
→ 十元位置重新检查
→ 端点可能变
→ 关系必须重新审核

Stage 2
继续
```

所以真正动态的是：

> **对象的映射状态 + 端点 + 关系共同变化。**

# 7｜与社会已有模型的初步邻居

R1 不做最终比较，只建立候选邻居。

## Neighbor A｜Conceptual Spaces
最接近“对象进入一个结构化概念空间”。

社会特点：
- 用 quality dimensions 构成概念空间；
- 对象可以表示为空间中的点 / 向量；
- 概念可以表示为区域；
- 距离表达相似程度。

与十元相似：
- 都不是只贴一个标签；
- 都强调“对象在语义空间里的位置”。

不同：
- 十元目前不是连续欧氏空间；
- 十元端点具有理论定义与相反轴；
- 十元还没有正式 metric / distance。

## Neighbor B｜Semantic Differential
把几乎任何概念映射到固定的双极尺度上。

经典方式：
- good ↔ bad
- strong ↔ weak
- active ↔ passive

形成一个概念的多维 profile。

与十元相似：
- 都可以对不同对象做同一套固定空间映射；
- 都存在相反端；
- 都可以形成强度 profile。

不同：
- Semantic Differential 主要测主观/情感意义；
- 十元端点不是形容词评分；
- 十元的 5 对相反端有各自结构变量与后续关系系统。

## Neighbor C｜Ontology
对象 → 类 / 属性 / 关系，并用正式规则保证一致性。

与十元相似：
- 有明确术语定义；
- 有对象、类、关系和规则；
- 可以做机器可读表示。

不同：
- ontology 强调“是什么 / 属于什么 / 有什么性质”；
- 十元更强调同一对象在一个固定语义结构空间中的映射分布。

## Neighbor D｜Qualitative Coding / Codebook
现实材料 → 按预定义 coding rules 映射到代码类别。

与十元相似：
- 有判定规则；
- 有正例/反例；
- 需要处理混淆类别；
- 可以做跨编码者一致性测试。

不同：
- 普通 codebook 未必有十元的空间结构、对立轴和后续关系盘。

# 8｜当前最接近的社会母类

R1 暂定：

> 十元不是单纯 Ontology，也不是普通 Taxonomy。

最接近的组合是：

> **Theory-defined Semantic Mapping Space**
> 
> + **Structured Coding Scheme**
> 
> + **Post-mapping Relation System**

大白话：

> 先用一套固定的语义坐标系去“定位”对象；
> 再用严格判定规则确认位置；
> 位置确认以后才进入关系和动态。

# 9｜这对论文方向3的意义

方向3不应该再问：

> 我能不能给创作意图加上生克补关系？

而应该问：

> **创作者模糊的创作对象 / 意图，能否先被稳定映射到一套可复核的语义空间；这种映射是否帮助 AI 保持创作者后续的关系、取舍与变化？**

十元在里面是：

> 一种候选 semantic mapping model。

而不是：
> 三种关系词。

# 10｜R1 DONE

本轮完成：

- 十元重新定义为 mapping-first model；
- 明确三元不是父级生成器；
- 明确十元是多位置、带强度分布的映射；
- 明确五组相反端结构；
- 明确关系只在映射端点成立后进入；
- 明确动态链需要跨阶段重新映射；
- 找出 4 个社会邻居：
  Conceptual Spaces / Semantic Differential / Ontology / Qualitative Coding。

# 11｜R2 READY

R2 唯一任务：

> **深挖这 4 类社会映射模型，找出哪个才是十元真正公平的 comparison family。**

比较字段：

- 输入对象是什么；
- 映射目标空间是什么；
- 是单标签还是分布；
- 是否双极；
- 是否允许强度；
- 是否有距离；
- 是否有判定规则；
- 是否允许多标签；
- 如何验证映射可靠性；
- 映射之后有没有关系推理；
- 是否动态重映射。

R2 结束后才能说：
> 十元到底更像哪一类模型。
