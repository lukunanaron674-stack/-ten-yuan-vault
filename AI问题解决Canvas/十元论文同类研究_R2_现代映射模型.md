# 十元论文同类研究｜R2 现代映射模型：从十项1–10到主型/次型

> 状态：R2 DONE
> 日期：2026-10-07
> 研究问题：十元当前“一个对象对十个符号分别做1–10映射，形成十项分布，最高为主型、次高可作为次型”的运行方式，在现代认知科学、分类理论、心理测量和机器学习中最接近什么？
>
> 重要边界：本轮只研究“映射”，不研究生克补、五行关系与动态链。

---

# 0｜R2 总结

当前十元映射最接近的现代结构，不是单一理论，而是四个邻近层：

1. **Graded Membership / Prototype Theory**
   - 一个对象不是非黑即白地属于某类；
   - 可以有“更像某类 / 更典型”的程度；
   - 最接近十元“每个符号都有映射强度”。

2. **Possibilistic / Fuzzy Membership Profile**
   - 一个对象可以同时对多个类别有不同隶属强度；
   - 各类别强度可以独立，不必解释为概率；
   - 最接近“十项1–10同时存在，最高为主型”。

3. **Conceptual Spaces / Similarity Spaces**
   - 提供更高层的几何解释：
   - 对象被放进一个共同空间；
   - 类别由原型 / 区域定义；
   - 距离代表相似度。
   - 但它和十元不是完全同构：十元当前十项更像“对十个类别的相似/映射 profile”，而不是十条独立质量维度坐标。

4. **Semantic Differential / Multidimensional Rating**
   - 提供“怎样把主观意义变成可量化评分”的实验方法；
   - 适合借来验证十元量表；
   - 但十元十个符号不是普通双极形容词维度，所以只能借方法，不能说同一模型。

因此目前最准确的一句话：

> **十元的1–10映射，在现代方法上最像“对十个结构原型的渐进式相似/隶属 profile”，再从 profile 中提取主型与次型。**

---

# 1｜为什么不能直接说“十元 = 十维 Conceptual Space”

Conceptual Spaces 的标准形式是：

```
对象
→ 在若干 quality dimensions 上有坐标
→ 得到空间中的一个点
→ 距离原型越近，越像该类别
```

例如颜色：

```
Hue
Saturation
Brightness
→ 颜色空间中的点
```

这里“维度”是对象可以沿其连续变化的质量轴。

而十元当前做法更像：

```
对象
→ 对 X 的映射强度 = 3
→ 对 Z 的映射强度 = 6
→ 对 N 的映射强度 = 4
...
→ 对 ZX 的映射强度 = 9
...
→ ZX 最高
```

所以十元的 X/Z/N/... 在运行时更接近：

> **十个候选类别 / 原型 / 结构位置**

而不是十条普通质量维度。

因此未来论文不能轻率写：

> “十元就是十维 Conceptual Space。”

更准确：

> **Conceptual Spaces 提供了共同空间、原型、距离和相似性的现代参照；十元当前数据形式更接近“对十个结构原型的相似度 / 隶属度 profile”。**

---

# 2｜Prototype Theory｜原型理论

原型理论最关键的一点：

> 类别不是所有成员都同样典型。

例如：
- robin 比 penguin 更典型地像 bird；
- 但两者都可以是 bird。

因此现代认知研究会区分：
- membership｜是不是这个类；
- typicality｜像这个类有多典型。

Hampton 等研究进一步讨论：
> 类别成员关系也可能是 graded 的，而不是只有 0 / 1。

这和十元很接近：

```
对象A：
ZX = 9
XN = 7
Z  = 5
...
```

这里不是：
> “只有 ZX，其他全部 0。”

而是：
> 对多个十元都可能有不同程度的映射，只是 ZX 最强。

因此十元主型 / 次型可以先被现代化理解成：

```
primary type
= highest mapping / strongest prototype affinity

secondary type
= next strongest stable affinity
```

但必须注意：
十元的“主 / 次”还有自身组合结构定义，不能简单等同 typicality ranking；这里只是研究映射输出形式。

---

# 3｜Fuzzy / Possibilistic Membership｜最像十项同时评分的数学邻居

软分类与模糊分类允许：

> 一个对象同时以不同程度属于多个类别。

示意：

```
对象A：
类1 = 0.2
类2 = 0.7
类3 = 0.9
类4 = 0.3
```

这和十元：

```
X=2
Z=7
ZX=9
XN=3
...
```

数据形态非常接近。

## 3.1 为什么“概率分类”不完全适合十元

概率式 membership 常要求：

```
所有类别概率相加 = 1
```

这意味着一个类别升高，其他类别会被迫相对下降。

但当前十元 1–10 映射并没有明确要求：

```
X + Z + N + ... = 固定总量
```

例如完全可能：

```
ZX=9
Z=8
XN=8
```

三个都很高。

所以当前十元分数：

> **不应先解释成概率。**

## 3.2 Possibilistic Membership 更接近

Possibilistic membership 的核心：

> 每个类别的隶属强度可以独立，不要求总和为 1。

这和十元非常近。

因此当前十元可以暂时借用一个中性描述：

> **independent graded mapping profile**
> 独立渐进映射分布

而不是：
> probability distribution。

---

# 4｜十元的十项1–10到底应该叫什么

当前建议不要急着叫：
- probability；
- weight；
- dimension coordinate；
- confidence。

因为这些词都有已有严格含义。

最稳的临时名：

> **Mapping Strength｜映射强度**

对象 O 的十元映射可以写：

```
M(O) =
[X:3, Z:6, N:4, ZN:5, NZ:2,
 XN:4, NX:3, ZX:9, XZ:5, X并Z:2]
```

然后：

```
primary(O) = argmax M(O)
```

即：
> 最高映射项 = 主映射候选。

如果要保留次型：
> 不能只机械取第二高；
> 还需要考虑主次组合规则、证据稳定性和差值。

---

# 5｜一个非常重要的问题：9分和8分差多少？

这是十元以后必须回答的量表问题。

如果：
```
ZX = 9
XN = 8
```

和：

```
ZX = 9
XN = 3
```

显然不是一个结构。

所以只看“谁最高”会丢掉大量信息。

必须保留整个十项 profile。

未来最少要记录：

```
Top1
Top2
Top1-Top2 gap
完整十项分布
```

例如：

### A
```
ZX9 / XN8 / Z7
```
→ 边界型 / 混合型可能很强。

### B
```
ZX9 / XN3 / Z2
```
→ 更可能是纯度高的 ZX。

因此：

> **十元真正的数据对象不是“一个标签”，而是一条十维映射 profile。**

但再次强调：
这里的“十维”只是数据向量有10个值，
不等于 Conceptual Spaces 中十条 quality dimension。

# 6｜Semantic Differential｜对十元实验方法特别有价值

Osgood 的 Semantic Differential 做的是：

```
一个概念
↓
让人沿很多双极量表评分
例如：
good ↔ bad
strong ↔ weak
active ↔ passive
↓
得到多项评分
↓
再用因子分析寻找稳定底层维度
```

它后来发现很多意义评价可以收敛成：
- Evaluation
- Potency
- Activity

这一点对十元非常有用，不是因为 EPA = 十元，
而是因为它提供了一个成熟实验范式：

> **先让大量对象被多人评分，再看评分结构是否真的稳定地出现。**

十元未来可以借它的方法问：

1. 不告诉被试十元答案，能否稳定评分？
2. 不同评分者的十项 profile 是否相近？
3. 十个十元是否真的彼此有区分？
4. 五个相反对子是否会在数据里自然出现？
5. 同一对象隔一段时间再评，结果是否稳定？
6. 不同领域（人物 / 音乐 / 发型）是否仍保持相同十元结构？

这比“我自己给100个东西评分”强很多。

---

# 7｜Conceptual Spaces 对十元真正有用的地方

虽然十元不是简单的十维 Conceptual Space，
但 Conceptual Spaces 有四个非常值得吸收的工具。

## A｜Prototype
每个十元是否存在：
> 最典型、最没有争议的锚点对象？

例如：
ZX prototype candidates
XN prototype candidates
...

## B｜Distance
两个对象的十项 profile 可以计算“相似程度”。

例如：

```
人物A profile
vs
音乐B profile
```

如果距离很近：
> 可以成为“跨领域同型”的量化基础。

## C｜Boundary
当 Top1 / Top2 接近时：
> 这是边界对象，而不是强行宣布唯一类型。

## D｜Region
未来十元真正成熟以后，
每个十元可能不是一个点，
而是十元空间中的一个“区域”。

---

# 8｜Multi-dimensional Classification 为什么不是最近同类

现代 Multi-dimensional Classification 指：

> 一个对象同时关联多个 class variables。

例如一个对象同时需要预测：
- 颜色；
- 材质；
- 用途；
- 风格。

它更像“同时完成多个分类任务”。

而十元当前是：

> 对同一套十个候选结构位置给不同映射强度。

所以 MDC 可以作为机器学习工程参考，
但不是十元理论最贴近的概念同类。

# 9｜R2 后新的现代对应表

| 十元当前操作 | 最近现代同类 | 相似点 | 关键差异 |
|---|---|---|---|
| 十个符号分别1–10 | Graded Membership | 类别不是0/1 | 十元有自己的十类本体 |
| 多个十元可同时很高 | Possibilistic Membership | 独立多类强度 | 十元分数目前不是正式membership function |
| 最高者为主映射 | Prototype / nearest-category assignment | 最高相似决定主类 | 十元还保留主次与关系 |
| 完整十项profile | Similarity Profile / representation vector | 保留整体分布 | 十元向量含自身语义结构 |
| 十元之间相似/远近 | Conceptual Spaces | 可做距离与区域 | 十元类别≠普通quality dimensions |
| 1–10人工评分 | Semantic Differential / psychometrics | 把主观意义量化 | 十元不是双极形容词量表 |
| 五个相反对子 | bipolar latent structure candidate | 可检验反向轴 | 目前不能假定数据必然验证 |

# 10｜R2 最大的新发现

## 发现1｜十元当前最像“十原型映射 profile”
不是“十个标签之一”。

正确数据对象：

```
Object
→ [10 scores]
→ profile
→ primary / secondary
```

## 发现2｜最高项只是压缩结果
如果论文只记录：
> “这个人物是 ZX”

会丢掉：
- 次型；
- 纯度；
- 边界；
- 混合结构；
- 跨域距离。

所以实验必须保存十项原始分布。

## 发现3｜十元分数不是概率
当前没有总和为1的约束。
因此更接近 independent / possibilistic graded membership。

## 发现4｜十元能否成立，先看“映射稳定性”
在研究审美之前，
必须先证明：

> 不同人 / 不同时间 / 不同表达形式，对同一对象能否得到相近的十项 profile。

否则：
> “同型审美”连自变量都没有稳定定义。

# 11｜十元映射的第一套现代验证指标

后续正式实验至少需要：

### V1｜Inter-rater Agreement
不同人判同一对象，十项 profile 是否接近。

### V2｜Test–Retest
同一人隔一段时间重判，结果是否稳定。

### V3｜Top-1 Stability
主型是否稳定。

### V4｜Top-2 / Gap Stability
主次和最高-次高差值是否稳定。

### V5｜Discriminant Validity
不同十元能否区分，而不是所有东西都被打成几个热门类型。

### V6｜Cross-domain Invariance
同一种结构进入人物、音乐、发型、构图后，映射规则是否仍然一致。

### V7｜Counterexample / Nearest-neighbor
最像的错误类型能否被稳定排除。

这七项比旧 B0–B4 更接近十元真正需要验证的基础。

---

# 12｜R2 对论文的意义

如果 R2 以后十元映射实验通过：

> 十元可以暂时被描述为一种“跨领域的十原型渐进映射模型”。

如果失败：

> 十元后面的同型审美、关系构成、动态链都无法作为稳定研究对象。

所以论文研究顺序必须是：

```
先验证映射
↓
再验证同型统一
↓
再验证关系同构
↓
最后验证动态链审美
```

不能倒过来。
