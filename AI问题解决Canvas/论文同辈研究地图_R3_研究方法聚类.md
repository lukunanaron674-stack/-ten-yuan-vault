# 论文同辈研究地图｜R3 按“研究方法”聚类

> 状态：R3 DONE / EXPLORE
> 依据：R1同辈样本 + 2025–2026同行评议研究作为“方法上限参考”。
> 重要限制：多数本科毕业展公开页只展示作品和创作说明，无法从公开页可靠推断其完整论文方法；因此本轮把“公开可见方法”与“同行评议研究方法”分开。

## 1｜本科同辈公开页最常见的方法

### M1｜创作实践 / Practice-led
结构：
问题/主题 → 工具尝试 → 视觉产出 → 作品展示 → 创作总结

R1里最常见。
适合：
- 动画短片
- IP视觉
- 动态绘本
- 非遗/传统文化转译

优点：
- 与毕设天然结合。
- 材料容易积累。

缺点：
- 如果没有明确比较或评价，容易停在“过程记录”。

### M2｜案例驱动 / Case-based
结构：
已有案例 → 提取特点 → 应用于自己的项目 → 总结方法

常见于：
- 非遗+AIGC
- AI短片
- IP/文创
- 交互设计

风险：
- 很容易变成案例介绍堆砌。
- “借鉴了什么”与“验证了什么”经常混在一起。

### M3｜流程记录 / Workflow documentation
结构：
传统流程 / 原流程 → AI介入节点 → 新流程 → 制作结果

2025–2026明显升温。
它开始回答：
- AI插在哪一步？
- 人在哪一步做决定？
- 什么环节返工？
- 哪些资产能复用？

这比“用了某软件”更像研究方法。

## 2｜正在进入设计/AIGC研究的方法

### M4｜A/B或条件对照
结构：
同一任务 → 改一个条件 → 比较结果

可比较：
- 不同Prompt
- 不同参考图
- 不同流程
- 人工 vs AI辅助
- 平铺描述 vs 结构化描述

价值：
- 能把“我觉得更好”变成较清楚的因果比较。

### M5｜专业评审 / 用户评价
结构：
生成/设计多个条件 → 盲评或量表 → 比较结果

2025 ICCV 的 ICE-Bench把生成评价拆为审美质量、成像质量、prompt following、source consistency、reference consistency和controllability等维度，说明最新图像生成研究越来越重视多维评价，而不是单一“好不好看”。

### M6｜实验组/对照组
2026关于艺术设计教学的人机协同研究已经采用6周实验、90名本科生、实验组与对照组比较，并比较创意表现、完成率与生产时间。

这类方法对5000字本科论文可能偏重，但说明“人机协同”已经开始从概念讨论走向实验验证。

### M7｜流程/系统比较
中国动画流程研究已把传统“线性瀑布式”与“人机协同迭代式”进行流程网络和甘特图层面的对比。

这说明研究对象一旦是“生产流程”，证据可以来自：
- 工序
- 反馈环
- 角色分工
- 时间/成本
- 返工路径

而不一定非要做复杂算法。

### M8｜质性观察 / 访谈
2025的人机视觉叙事研究已经使用参与者研究，观察用户怎样不断协商文本意图与生成图像，并归纳协作模式。

适合回答：
- 创作者在哪些步骤失去控制？
- 为什么会不断改Prompt？
- AI怎样影响创作选择？

## 3｜方法成熟度梯子

从弱到强可粗略看成：

**作品说明**
→ **创作实践**
→ **案例+实践**
→ **流程记录**
→ **条件对照**
→ **人工评价**
→ **多方法交叉验证**

不是说越右越“高级”；而是越往右，越能回答明确的研究问题。

## 4｜对同辈论文的一个关键发现

目前很多毕业设计可以做出很完整的作品，
但“作品完成度”与“研究证据强度”是两件事。

例如：
- 做出一部AI短片，只证明“能做出来”。
- 同任务做两种流程，再记录返工/评价，才开始证明“哪种方法更有效”。

所以后续扫同辈论文时必须同时登记：
**题目是什么 + 它拿什么证据支持结论。**

## 5｜R3方法地图

| 方法 | 本科常见度 | 研究说服力 | 工作量 | 适合回答 |
|---|---|---|---|---|
| 创作实践 | 高 | 中 | 中 | 能不能做 |
| 案例分析 | 高 | 中 | 低 | 别人怎么做 |
| 流程记录 | 中→高 | 中高 | 中 | 制作方式如何变化 |
| A/B对照 | 中低 | 高 | 中 | 某个条件有没有影响 |
| 专业/用户评价 | 中低 | 高 | 中 | 哪种结果更符合目标 |
| 复杂定量实验 | 低 | 高 | 高 | 效果差异是否稳定 |
| 访谈/质性研究 | 低 | 中高 | 中 | 人如何与AI协作 |
| 混合方法 | 低 | 高 | 高 | 同时解释结果与原因 |

## 6｜R4入口

下一轮不再看“常规方法”，只看2025–2026真正升温的新问题：
- 哪些研究问题是最近两年才大量出现的？
- 是工具变了，还是研究对象变了？
- 哪些只是热词，哪些已经有同行评议证据？
