# 01｜感受空间基础结构：Circumplex Model / Core Affect

> 大白话：**很多看起来完全不同的感受，可能不是一堆互不相干的盒子，而是能放进同一张“感受地图”里。**

## 1. 英文到底是什么意思
### Circumplex Model
Circumplex 可以先别硬翻。把它想成：**圆形排列的关系地图**。

它不是说“情绪就是一个圆”。  
它真正做的事是：把很多情绪/感受放到同一套连续坐标里，看它们彼此离得近不近、方向是否相反。

### Core Affect
Core Affect 可以理解成：**还没被你命名成‘愤怒、快乐、悲伤’之前，更底层的总体感觉状态。**

经典研究常把它描述成少量连续维度，最常见的是：
- pleasant ↔ unpleasant：舒服/愉快 ↔ 不舒服/不愉快
- activated ↔ deactivated：激活/兴奋 ↔ 平静/低激活

所以“愤怒”和“兴奋”虽然名字完全不同，却可能共享“高激活”；“悲伤”和“平静”可能都偏低激活，但愉快程度不同。

## 2. 它到底想解决什么
假设有几十上百个感觉词：快乐、害怕、紧张、宁静、兴奋、忧郁……

最直接的方法是给每个词一个盒子。问题是盒子会越来越多。

Circumplex 的思路是反过来问：
**这些表面不同的感觉，底下是不是可以用少数共同方向来描述？**

于是它把“很多类别”变成“一个共同空间”。

## 3. 最重要的脑内图
想象一张地图。

不是：
快乐｜愤怒｜悲伤｜恐惧｜惊讶……

而是：
**每种感觉 = 地图上的一个位置。**

两个感觉靠得近 → 底层体验结构可能比较相似。  
两个感觉方向相反 → 底层体验结构差异较大。

这就是它对感受三元最值得看的地方：  
**它已经在做“很多感受 → 统一结构空间”这件事。**

## 4. 它和“感受三元”真正撞在哪里
我们的核心假设更像：

很多感受  
→ 用同一套 X / Z / N 关系母型提取  
→ 得到可比较的结构  
→ 再扩展到十元、关系和动态变化。

Circumplex 则更像：

很多感受  
→ 用少量连续维度定位  
→ 得到一个共同的感受空间。

所以两者不是简单的“像不像”。

真正的问题是：
**如果 Circumplex 已经能用少量维度描述大量感受，X/Z/N 还能多解释什么？**

这是以后必须正面回答的外部 baseline。

## 5. 最大区别：位置 vs 关系
这里很关键。

Circumplex 更像在回答：
**“这个感觉位于哪里？”**

感受三元如果成立，应该更偏向回答：
**“这个感觉内部是什么关系结构？”**

例如两个体验在愉快度和激活度上可能接近，但内部可能一个是压制关系，一个是互补/依附关系。

如果三元能稳定区分这种 Circumplex 不容易区分的结构，它才可能有新增价值。

## 6. 以后怎么验证
不要直接问“三元是不是比 Circumplex 高级”。

最干净的测试是：
同一批图像/音乐/叙事刺激  
→ 一边做经典 valence/arousal 等评分  
→ 一边做 X/Z/N 结构提取  
→ 看两边各自能预测哪些主观判断。

如果加入三元后，能稳定解释传统维度解释不了的差异，才叫有**增量效度**。

## 7. 不能误读
❌ Circumplex 不是“所有感受已经被二维彻底证明”。  
❌ 不能因为它有几个基础维度，就说它证明了“三元也可以概括全部感受”。  
❌ 它的“维度”也不等于我们的“关系母型”。

正确用法是：
**把它当成感受三元必须比较的成熟外部方案。**

## 8. 对 L1 的价值
❤️ **高价值。**

它给我们的不是答案，而是一条非常清楚的外部参照：

> 别人已经尝试把大量感受放进统一空间；感受三元必须说明自己究竟是在重复“低维感受空间”，还是提供了不同的“关系结构提取”。
