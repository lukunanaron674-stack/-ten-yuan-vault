# 02｜Psychological Construction（心理建构）：第一人称感受怎样形成

> 大白话：一次“我现在感到害怕 / 被打动 / 烦躁”的体验，可能不是一个预装好的情绪按钮被按下；身体状态、眼前情境、过去学到的概念和当下判断，可能一起参与了这次体验。
>
> **本卡的关注点**：体验者自己的感受怎样形成、怎样被自己辨认和报告，以及视觉作品如何表达或引发这种体验。角色看起来像什么情绪、旁观者猜角色在想什么，是相邻但不同的问题。

## 1. 英文和研究对象

**Psychological Construction（心理建构）**不是一条单一公式，而是一组研究路线：它们把一次具体情绪事件看成多个心理过程在特定情境下共同形成的结果。

Russell 的 2003 年文章把 **core affect（核心情感状态）**、对情境的知觉、把感受归因给某个对象、行动和对自身状态的分类放进同一个情绪事件框架。Barrett 的建构情绪路线则强调，身体内部信号、外界感觉和学到的情绪概念如何参与对当前状态的分类。不同作者的理论细节不完全相同，不应把它们写成一套完全一致的模型。

## 2. 它为什么出现

如果把“恐惧”想成一个固定内在模块，似乎它会统一地产生心跳、表情、想法和逃跑行为。但真实经历并不总是这样整齐：同样的心跳加快，可能被体验成紧张、兴奋或期待；同样被称作“害怕”的经历，也可能在身体感受、对象判断和行动上不同。

心理建构研究因此追问：能否从一次体验里分别考察身体状态、情境、概念、判断、行动和主观感受，而不是先把它们都归到一个叫“情绪”的盒子里？

## 3. 作者做了什么

Russell（2003）是一篇理论整合文章，不是一项证明了某个新情绪部件的单独实验。它梳理核心情感状态及其与知觉、归因、评价、行动、表达和自我分类之间可能的关系，并提出应解释具体的情绪事件。

Barrett（2017）提出一个主动推断版本的建构情绪理论，讨论内感受（身体内部信号）、预测和分类如何共同参与情绪及其他有意义体验。它是理论论述与证据综述，不等于对每个环节都做了直接因果验证。

所以阅读时要分开三件事：作者提出的理论结构、文章援引的既有证据、以及本研究未来要亲自验证的假设。

## 4. 主要观点（白话）

一次体验可以被看作“这一个人、在这个时刻、面对这个情境形成的事件”。身体的舒服或难受、精神的活跃或低落，可能与眼前发生的事、个人经验、注意焦点和已有概念一起影响体验。之后，人可能把这段状态认作“我在害怕”“我被打动了”，并据此行动或描述。

这里的“建构”不等于装出来，也不等于当事人可以任意选择感受。它强调的是：感受会受到身体、情境、学习历史和当下活动等因素约束，而且这些因素未必每次以同样方式组合。

## 5. 最重要的一张脑内图

**视觉作品 / 事件** ＋ **此刻身体状态** ＋ **注意、记忆与习得概念** ＋ **对情境的理解**

→ **体验者此刻实际经历的感受**

→ **体验者对“我在感受什么”的辨认、描述和行动**

这是帮助提出问题的示意图，不是 Russell 或 Barrett 的逐字原模型，也不是已经证实的固定流水线。作品里的角色表达、创作者的设计意图、观众推测角色的情绪、观众自己实际感到什么，必须作为不同变量记录。

## 6. 和 Circumplex / Core Affect 的关系

两者都关心感受经验，也都允许用更基础的过程解释很多具体情绪。Circumplex / Core Affect 更直接提供感受空间和连续维度的描述；心理建构则更强调一次具体体验由哪些过程、情境与分类共同形成。它们可以互相参照，但“空间里的位置”和“事件如何形成”不是同一个问题。

## 7. 和感受三元 X / Z / N 哪里碰

它给三元的启发只是一个研究问题：**如果一次第一人称感受由多个过程共同形成，能否在大量具体体验中，找到可重复的关系结构？**

这不等于 X / Z / N 已经被心理建构理论提出或验证。现有建构理论中的“成分”“维度”“身体信号”“概念”也不能直接改名为三元关系元。X / Z / N 究竟描述体验成分、相互关系、生成操作还是事后归纳结构，仍需独立定义和证据。

## 8. 对视觉表达研究的具体提醒

如果问的是“自己的感受如何构成式表现出来”，可先区分：

- **被表现的主体**：创作者、参与者，或作品中的角色；三者不能默认相同。
- **表现材料**：颜色、形状、空间、节奏、动作、镜头、声音等视觉 / 多模态线索。
- **被记录的结果**：体验者自己的即时感受报告；角色情绪识别或创作者意图只能另行记录。

可探索的研究步骤是：先让参与者看视觉材料后自由描述自己的当下感受，再用不预先教授 X / Z / N 的方式收集感受强弱、差异和变化；之后才检验是否能从材料和报告中归纳出稳定结构。还应比较不同参与者、不同语境和重复观看的结果，并记录“作品想表达什么”与“我实际感到什么”之间是否一致。

审美情绪量表 Aesthemos 是可借鉴的测量入口之一：它覆盖艺术、电影、设计等刺激引发的多种自我报告体验。它能帮助提醒研究者，视觉体验不只包含愉快和唤醒；但一套量表无法替代对个人自由描述的记录，也不能替本研究定义三元。

## 9. 不能直接推出什么

- “感受会被建构”不等于“感受恰好由三个基础关系构成”。
- “主观报告会受概念和语境影响”不等于“报告只是主观偏见、不可研究”。
- 角色表现出某种表情或动作，不等于观众本人就经历了同一种感受。
- 创作者说作品表达了某种感受，不等于每位观众都真实体验到它。
- 量表分数、身体指标或神经指标中的任何一项，都不能单独充当体验本身的完整替代物。
- Russell 与 Barrett 的理论有可争论之处；本卡介绍其研究路线，不把它写成情绪科学的唯一共识。

## 10. 对感受三元 L1 的用途

**用途：给“感受是体验者自己的经验，且需区分生成线索、体验和表达”提供一个成熟的研究邻居；同时提醒研究设计不要把角色情绪推断当成观众自己的感受。**

真正可能形成贡献的部分，仍要由研究证明：X / Z / N 是否能从未经引导的第一人称资料中被稳定辨认；它是否提供了比现有感受空间、审美情绪测量和建构理论更清楚的解释或预测。

## 11. 值不值得继续查

**❤️ 高价值，继续查。** 这条路线与“主观感受如何形成”直接相关，且能帮助把第一人称体验与他人情绪识别分开。当前研究题目、理论主张和 X / Z / N 的证据状态仍然开放，不因此冻结选题。

> 优先研究**体验者自身的感受**怎样构成、怎样通过视觉形式表现出来；不要把“别人/角色是什么感受”当作同一个问题。这里先将它保留为研究焦点提示，尚未据此确定最终论文问题或理论答案。
