# 1｜十元的正确位置

十元首先承担的是：

> **把一个对象 / 概念 / 状态 / 关系位置映射到十元语义空间。**

不是先有 generic relation，再给 edge 换成“生克补”。

正确顺序：

```
现实对象 / 创作对象 / 概念
↓
冻结对象、主体、阶段、对象层
↓
独立十元判定
X / Z / N / ZN / NZ / XN / NX / ZX / XZ / X并Z
↓
主 / 次 + T 体量 + M 显影 + C 置信
↓
十元与三元比例质感核对
↓
独立三元判定 x / n / z
↓
映射结构成立
↓
两个已成立十元端点进入关系审计
↓
机制 / target_variable / 方向 / 第三因素 / 反向测试
↓
生 / 克 / 补 / NONE / AMBIGUOUS
↓
E 关系作用量
↓
动态链：跨阶段重新映射与重新审核关系
```

# 2｜三元的位置

三元不是十元的父级生成器。

正本明确：

> 三元与十元不是父子派生关系。

三元 x / n / z 用于描述十元内部的：
- 比例；
- 质地；
- 侧重。

所以流程不是：

```
三元 → 算出十元
```

而是：

```
独立十元判定
↔
三元独立判定 / 比例质感复核
```

两者相容时加强理解；不相容时回到证据重查。

# 3｜为什么映射之后才有关系

生克补不是“所有 Node 都能直接选的三个关系词”。

关系必须依赖：
1. 两端都已成立为十元端点；
2. 同一对象层 / 合法作用窗口；
3. 真实机制；
4. 目标变量发生变化；
5. 方向可归属；
6. 第三因素与反向解释被排除。

所以：

> **十元映射提供关系端点；端点成立以后，关系才进入可判空间。**

# 4｜十元更像什么

在当前论文讨论里，更准确叫：

> **Ten-Yuan Semantic Mapping Model**
> 十元语义映射模型

其后才接：

> **Ten-Yuan Relation Activation**
> 十元关系启动

再接：

> **Dynamic Chain**
> 动态链

完整结构：

```
Semantic Mapping
→ Relation Activation
→ Dynamic Evolution
```

# 5｜与社会已有方法的正确比较单位

不能只比较：

```
生 vs support
克 vs conflict
补 vs compensate
```

这只是表面词义比较。

真正要比较的是：

## B3｜Generic Dynamic Intent Representation

```
对象 / Goal / Constraint / Choice
+ 通用语义分类
+ 通用关系
+ priority / rationale
+ state / transition
+ evidence
```

## B4｜Ten-Yuan Mapping + Relation Model

```
对象层 / current window
→ 十元映射
→ 主次 / T / M / C
→ 三元比例质感复核
→ 十元端点组合
→ 生克补关系启动
→ mechanism / target_variable / E
→ 动态链跨阶段重映射与关系复核
```

因此 B4 的增量问题变成：

> **十元作为一套“先分类映射、再启动关系、再追踪动态”的模型，是否比通用意图表示更稳定地保持和预测创作者意图？**

# 6｜论文方向 3 的核心也要改

旧：
> 十元是 Creative Intent Relation Layer。

修正：
> **十元是一种候选 Creative Intent Semantic Mapping + Relation Model。**

也就是说，研究的不是单独三种关系。

而是：
1. 创作者的对象 / 意图能否先被稳定映射到十元位置；
2. 这种映射是否约束了后续关系判断；
3. 映射 + 生克补 + 动态链整体是否带来额外预测 / 控制价值。

# 7｜对实验的直接影响

B4 必须完整执行：

```
Object/Intent
→ Ten-Yuan Mapping
→ Three-Yuan Cross-check
→ Endpoint Freeze
→ Relation Activation
→ Dynamic Chain
→ Prediction
```

禁止：
- 直接从自然语言写“这是克”；
- 不判十元端点就判生克补；
- 只给 generic graph 的 edge 换三个中文关系词；
- 已知结果后反推十元映射。

# 8｜当前冻结句

> **十元先把对象映射进十元语义空间；三元用于独立复核十元内部质地与比例；只有映射端点成立后，生克补关系才进入可判空间，随后由动态链描述这些映射位置与关系如何跨阶段变化。**
