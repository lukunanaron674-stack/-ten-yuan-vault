## 2｜R1观察：同辈方向正在形成的 8 个簇

1. **AIGC + 传统文化 / 非遗 / 神话**
   - 目前最密集。
   - 题材容易找到、作品容易展示，但重复度已经很高。

2. **AI短片 / AIGC动画全流程**
   - 2025–2026明显升温。
   - 从“用AI做一部分”开始转向“剧本—分镜—角色—场景—动画全流程”。

3. **AIGC辅助个人视觉表达 / 风格化**
   - 有作品实践，但同辈公开题目中还没有像“风格结构化、规则化、一致性评价”这样细分得很深。
   - 目前更多是“用AI做风格化/生成IP”。

4. **AI + IP / 文创 / 品牌动态视觉**
   - 视觉传达与数媒中较常见。
   - 重点常落在成果设计，而不是AIGC控制机制。

5. **交互 / 游戏 / AR / VR + 文化内容**
   - 仍然是强势常规方向。
   - 2026并未被AIGC完全替代，反而与AIGC并行。

6. **人机协同 / 生成式UI**
   - 2026开始在本科毕业展主题中明确出现。
   - 比“AI提高效率”更像下一阶段的问题意识。

7. **虚拟拍摄 / 实时引擎 / 影游融合**
   - 数媒专业明显加强。
   - 更偏技术生产体系。

8. **动画生产流程 / 工业化管线**
   - 学术期刊已开始讨论“瀑布式 → 人机协同迭代式”。
   - 同辈本科题目中还没有完全饱和，属于值得继续跟踪的研究化方向。

## 3｜同辈目前“常见”与“较少见”的区别

### 很常见
- AIGC + 非遗
- AIGC + 传统文化
- AI短片
- AI辅助IP/文创
- AI风格化案例
- “AI赋能某某设计”

### 相对较少见
- AIGC生成结果的一致性怎样被严格评价
- 个人视觉经验如何结构化为可复用规范
- 参考图、Prompt、规则之间怎样分工
- 跨角色 / 跨场景资产如何保持同一视觉体系
- 人机协同中“创作者控制权”如何具体落到工作流
- 同样信息量下，不同信息组织方式是否改变生成结果
- AI美术资产生产如何从单图走向项目级管理

> 这些“较少见”只作为后续探索线索，R1不据此定题。

## 4｜R1对“最新方向”的初判

### 2024
AIGC更多被当作**新工具**：
- 风格化
- IP生成
- 辅助动画
- 辅助文创

### 2025
开始进入**完整创作流程**：
- 非遗AIGC动画
- 实拍 + AIGC
- AI短片
- AIGC + 互动媒体

### 2026
明显向三个更系统的方向移动：
- **全流程AIGC影像生产**
- **人机协同 / 生成式UI**
- **复合生产体系：AIGC + 虚拟拍摄 + 实时引擎 + 影游融合**

同时，“传统文化 + AIGC”仍然非常强，但已经属于高拥挤区。

## 5｜本轮还不能下的结论

- 不能因为某方向公开样本少，就直接认定“研究空白”。
- 不能把毕业作品题目当作完整论文研究内容。
- 不能仅凭高校新闻判断学术质量。
- 不能现在就说用户应该写“个人视觉风格规范”；当前阶段仍是横向摸底。

## 6｜R2入口

下一轮只做一件事：

**把目前收集到的同辈题目按“研究对象”重新聚类。**

重点区分：
- 研究“作品”
- 研究“技术”
- 研究“流程”
- 研究“视觉风格”
- 研究“文化传播”
- 研究“用户/交互”
- 研究“生产系统”

这样才能看出哪些方向只是换题材，哪些方向真正换了研究问题。
