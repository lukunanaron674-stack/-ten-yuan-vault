# 十元论文同类研究｜R1 五行跨领域映射史

> 状态：R1 DONE
> 日期：2026-10-07
> 目的：只研究“传统五行如何把不同领域放进同一结构，以及这种分类为什么会被认为能够相应、联动、形成秩序”。不把古代五行当成现代实验结论。

## 0｜R1 总结

目前找到的最近历史同类不是“创作意图图”，而是：

> **Correlative Cosmology｜相关宇宙论**
> 
> 核心结构：分类（类）→ 同类相应 / 感应 → 五行关系与循环 → 跨领域配属。

这和当前十元真正结构非常接近：

> 对象 → 十元映射 → 同型统一 / 关系构成 → 动态链

但两者不能直接等同。

---

## 1｜五行不是静态“元素表”

现代学术一般把 wuxing 翻译成 Five Phases，而不是固定物质元素。

原因是 xing 更强调：
- 运动；
- 变化；
- 状态转换；
- 相互作用；
- 循环。

也就是说，木火土金水在相关宇宙论里不只是“五种东西”，而是五种变化位置 / 运作方式。

这与十元当前“不是贴名字，而是判断对象怎样行动、怎样反应、处于什么结构位置”的运行方式非常接近。

---

## 2｜五行的跨领域映射是真实历史结构

传统系统会把完全不同领域的对象归入同一行。

典型例：

### 木
- 东方
- 春
- 青 / 绿
- 角音
- 肝
- 酸

类似地，其余四行也会连接：
- 方位；
- 季节；
- 音；
- 色；
- 味；
- 脏腑；
- 数；
- 政治 / 礼制活动等。

因此五行已经具有：

> **不同对象域 → 同一结构类别**

的跨域映射形式。

这不是十元独有的结构发明。

---

## 3｜关键机制一：类（lei）

相关宇宙论的重要前提不是“东西长得像”，而是把现象按“类”组织。

学术解释特别强调：
分类不一定依据固定物质本质，而可能依据：
- 怎么行动；
- 怎么变化；
- 怎么对其它对象反应；
- 在什么关系结构中发挥作用。

因此：

> 同一个具体对象在不同情境下，也可能表现出不同的类属性。

这和十元不能只靠名词判断，而要冻结对象层、阶段、current window 后再映射，非常接近。

---

## 4｜关键机制二：感应（ganying）

《吕氏春秋》相关传统中有一个非常接近当前十元“同型统一”的思想：

- 同类相召；
- 同气相合；
- 同声相应。

学术上通常把这一套叫：
> stimulus-response / resonance｜感应 / 共鸣式关联

这里最重要的不是“神秘感应”四个字，
而是它的结构：

```
A 被归入某一类
B 也被归入某一类
如果 A / B 同类
→ 预期它们存在对应 / 感应 / 共振关系
```

这与十元当前假设：

```
ZX人物
ZX发型
ZX音乐
↓
可能形成跨领域同型统一
```

在结构上非常相近。

---

## 5｜关键机制三：同类不只是“标签相同”，还意味着关系位置相似

SEP 对相关宇宙论有一个非常重要的解释：

> 把两个现象放进同一类别，也是在把它们放进类似的关系配置中。

因此五行分类不是只有：

```
春 = 木
青 = 木
角 = 木
```

更深一层是：

> 它们被认为在各自领域里承担类似的运作位置。

这与十元的“跨领域关系同构”高度相关。

十元可进一步问：

```
人物域：ZX 被 XN 克
音乐域：某组结构也映射出 ZX 被 XN 克
视觉域：再出现相同关系
↓
跨领域重复同一关系骨架
```

传统五行已经提供“跨域对应 + 类似关系配置”的历史原型，
但十元是否能把这种结构做得更明确、可评分、可验证，仍需新研究。

---

## 6｜五行本身也把关系与变化放进分类结果

现代研究指出，五行 / Five Phases 的类别不仅描述“当前是什么”，还携带：
- 会往哪里变化；
- 和其它阶段是什么关系；
- 如何相生；
- 如何相胜 / 相克；
- 如何循环。

所以五行本身已经包含：

> 分类结果 → 关系 → 变化预测

这一层。

这与十元：

> 映射 → 生克补 → 动态链

是强近邻。

---

## 7｜五色 / 五音确实进入了同一美学—礼乐结构

《礼记·乐记》把：
- 五声；
- 五色；
- 大小；
- 终始；
- 和声与秩序

放在同一个“和”的框架中讨论。

其中“五声如五色，成文而不乱”这一类表述说明：
古典礼乐思想已经把视觉和听觉的有序组合放在共同结构里理解。

但必须严格区分：

### 历史上有：
- 五音 / 五色对应；
- 礼乐中的和；
- 跨领域秩序与协调；
- 类应 / 感应。

### 历史资料目前没有直接证明：
- “同一五行的人物 + 发型 + 音乐一定更美”；
- “相同生克结构跨领域重复一定提高审美评分”。

所以后两项仍是可以被现代实验验证的问题。

---

## 8｜与十元最相似的结构

### 五行
```
不同领域对象
↓
归入木火土金水
↓
同类相应
↓
跨域对应
↓
生克与循环
```

### 十元
```
不同领域对象
↓
十项1–10映射
↓
主型 / 次型
↓
同型统一
+
关系对折 / 同构
↓
生克补动态链
↓
审美构成
```

所以：

> **十元不是从零开始发明“跨领域映射 + 关系”的思想。**

真正需要研究的是：
十元是否把它变成了一种更细的、可量化、可跨域实验的结构。

---

## 9｜目前看到的五个重要差异

### D1｜5类 vs 10位置
传统五行：五个 phase。
十元：五行内部阴阳两极 → 十个位置。

### D2｜类别配属 vs 十项连续评分
目前审到的传统资料主要是：
“归木 / 归火 / 归土……”

十元当前做法是：
十个位置同时 1–10 评分，再取最高 / 主次。

这是非常重要的结构差异，后面需要找现代“多维评分 / soft classification”的同类。

### D3｜同类相应 vs 审美统一实验
五行传统提出“同类相应 / 共振”。
十元现在想验证：
“人物、发型、音乐同型是否真的更统一 / 更美”。

后者可以做现代 AB 实验。

### D4｜对应关系 vs 关系同构
传统系统有跨域对应。
十元进一步强调：
不仅对象同型，连“谁生谁、谁克谁、谁补谁”的结构都可以跨领域重复。

这一层需要和现代 relational similarity / structure mapping 比较。

### D5｜循环变化 vs 可评分动态链
五行有生克循环。
十元当前还有：
- 每一步具体关系；
- 主次；
- 体量；
- 作用量；
- 强弱变化；
- 克→生→大克→补这类时间序列。

这一层后面要与 tension / resolution、narrative dynamics 比较。

---

## 10｜传统五行给十元最大的警告

SEP 对相关宇宙论明确指出：

> 当相关分类不断扩展到所有现象时，有些联系会越来越不明显，甚至显得强行和任意。

这几乎就是十元未来最大的验证风险：

```
任何东西都能被解释成十元
≠
十元真的有区分能力
```

所以未来必须有：
- 盲判；
- 多人一致性；
- 最近邻混淆；
- 反例；
- 删除测试；
- 随机配对对照；
- 不允许事后为了好看改映射。

如果不能挡住“什么都能解释”，十元就会重演五行类应扩张后的弱点。

---

## 11｜R1 对论文的新价值

这轮最重要的不是证明十元“原创”。

而是终于找到正确历史位置：

> **十元可以被研究为：传统相关分类 / 五行类应思想在现代跨媒介创作场景中的一种细分映射与关系构成模型候选。**

但论文不能直接写成这个结论，除非后续 R2–R5 验证。
