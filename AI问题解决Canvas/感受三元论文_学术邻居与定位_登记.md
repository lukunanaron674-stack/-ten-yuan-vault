## 2｜74 给的核心定位句

> **感受**：观看者接触视觉对象后，对其形式、关系、空间、力量与意义形成的主观体验。

> 而三元研究的是：**不同具体感受之下，是否存在数量更少、能够重复出现的基础体验结构。**

---

## 3｜74 给的 GAP 判词（本批最硬的一条）

现有理论已经大量回答：
```
视觉特征 → 知觉/加工/评价 → 愉悦/唤醒/兴趣/敬畏等体验
```
所以**不能声称**："我首次发现视觉结构会产生感受"——这个站不住。

**真正可守的窄问题**：
> 不同表面视觉元素产生的复杂感受，是否可以进一步抽象为少量**"关系型感受结构"**？

## 4｜学术邻居对照表（74 原判）

| # | 邻居 | 代表 | 结构相似点（像在） | 关键差异（不像在） | 星级 |
|:-:|:-----|:-----|:-----|:-----|:----:|
| A | **感受空间 / 基础结构** | James Russell —— Circumplex Model / Core Affect | 少量基础结构 → 大量感受（降维） | 他是 affect 的心理构成；你是**视觉对象中的关系结构**如何形成感受。**X/Z/N 不能改名成三种 core affect** | ⭐⭐⭐⭐⭐ 头号对照组 |
| B | **构成主义 / 成分过程** | Russell/Barrett 心理建构 + Scherer 的 Component Process Model | 复杂情绪由更基础成分构成、随时间展开的动态过程 | 他的 component ≠ 你的"关系元"。CPM 强调 appraisal sequence 与 response-system synchronization | ⭐⭐⭐⭐⭐ 必须精读 |
| C | **视觉关系 → 审美感受** | Schloss & Palmer 色彩组合实验；Schloss 博士论文《The Aesthetics of Color Combinations》 | **直接连回三元出生地**（颜色组合）。色对偏好的大量方差来自抽象颜色关系 | 他问 preference/harmony/figure preference；你问**关系结构本身** | ⭐⭐⭐⭐⭐ |
| D | **感受测量 / 统一感受工具** | Geneva Emotion Wheel (GEW) | 把一个"轮盘"变成 **self-report 测量工具**（20 情绪词 × valence×power + 强度） | 你不只要"位置合理"，要可提取、可复现、可比 | ⭐⭐⭐⭐☆ 方法论直接借鉴 |
| E | **混合感受 / 感受关系** | Mixed Emotions / Emotion Blends / 情绪网络分析 | A感受+B感受 → 什么；已区分共现/相反 valence/blends/切换/appraisal 组合 | **你要进一步问：A 与 B 之间是什么关系（生克补），以及关系本身是否改变整体** | ⭐⭐⭐⭐⭐ 最可能被超越的点 |
| H | **审美情绪 / 艺术体验** | Silvia 审美情绪研究 | appraisal → interest 等审美体验 | 你的"感受"混了 emotion + aesthetic experience + perceptual quality + appraisal。**边界不清会被判死刑** | ⭐⭐⭐⭐☆ 概念边界 |

## 5｜74 给的方法学与检索提示

### 5.1 方法学路线（有现成先例，可"让感受自己聚类"）

> 大量感受词 → 相似度/特征评价 → 降维 → 聚类 → **让结构从数据中出现**

先例：研究者拿 **75 个审美情绪词**让参与者按相似性自行分组，再用 GRID 特征 + 主成分分析 + 聚类，得到多个感受簇与 valence/power/arousal/novelty 等潜在维度。

### 5.2 检索拆路（防跑偏）

五行情绪**不能只搜** `Five Elements emotions`，要拆两路再对起来：

- **中国传统理论路**：five emotions Chinese medicine / five phases emotions / wuxing emotion / emotion generation inhibition Chinese medicine
- **现代情绪关系路**：emotion dynamics / emotion transition / mixed emotions / emotion interaction / emotion regulation

⚠️ 否则会犯错：因为"五行情绪有生克" → 只找中医论文 → 整篇论文被带成中医情绪研究。
**主体仍是感受结构。**

### 5.3 值得补搜的中间概念

```
componential models of emotion
component process model
psychological construction of emotion
constructed emotion
affective dimensions
```

> 这批可能比直接搜 "emotion wheel" 更接近理论骨头。

### ① 三元指什么 → 正本已冻结

正本：`01-十元系统/R3A_三元最小感受定义_人类主语_v1.0_20261007.md`
（`three-yuan-minimal-feeling-canon` / L2 / canonical-current）

```
X｜醒  让人"醒过来、差异被拉开、注意被抓住、边界清楚"
Z｜张  让人"张开、凸显、向外释放、存在感被放大"
N｜耐  让人愿意停留、关系能相处、整体可被持续容纳
```

**三元 = 感受母结构**（对基本感受方向的一级归纳）。
- ❌ 不是对象类别（旧"物象/精神/认可"定义降级为 L2 诱发机制）
- ❌ 不是 core affect（区别：Russell 答"感受在哪"，三元问"感受的方向/内部关系"）

核心正本：`01-十元系统/三元十元感受模型_核心正本_v1.0_20261007.md`（v1.2.0 / L2）
明确翻转：从"对象属于哪一类"→"**人被激活了什么感受**"。

### ② 感受的可操作定义 → 正本已冻结

同正本 R3-A §0 最高主语原则：

> **感受的主语是人。** 对象是刺激源；人是体验者；三元/十元是描述人的感受结构的语言。

**可操作定义**：人能够直接**报告、比较、区分**的主观体验。
（感受 ≠ 某一种神经递质/激素数值；生理数据只作未来证据层）

**三层结构**（禁止 L2/L3 冒充 L1）：
```
L1 感受核（人直接感受到什么）
→ L2 诱发机制（哪些结构常诱发这种感受）
→ L3 领域表现（进入人物/音乐/镜头/场景后表现成什么）
```

- 74 说"不能声称首次发现视觉结构产生感受" → **正本已让步**：三元/十元不研究"对象客观是什么"，研究"对象以何种形式作用于人、让人产生什么感受"。
