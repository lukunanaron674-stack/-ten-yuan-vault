# 候选 11｜结构化创作意图对真实创作决策具有预测价值

## 当前核心命题

> **结构化创作意图对真实创作决策具有预测价值。**

进一步说：

> 如果 AI 不只知道“正确不正确、好不好看”，而是能够理解创作者的**关系、优先级、理由与动态轨迹**，它是否能更准确地预测创作者最终会 ACCEPT / REWORK / REJECT？

来源与接口：
- 674-118｜把隐性的个人视觉/创作规律结构化、规范化
- 674-119｜关系 / 优先级 / 理由 / 动态轨迹；十元 × 动态链作为候选关系语法
- 674-120｜多个意图同时存在时的冲突、优先级与非目标保持
- 674-122｜AI 真实评价：从正确性扩展到审美、意图与真实接受/否决
- 674-112｜外部实证方法参考：真实材料、独立盲标、一致性、failure family，避免自产自证
- 674-278｜USER→SOCIETY 社会价值与外部效度验证

状态：**CANDIDATE / NOT FROZEN**

---

## 1｜这题已经不只是“十元能不能解释作品”

真正的问题是：

> **AI 能不能更深地理解一个创作者到底想要什么，并在看到候选结果时，提前预测这个创作者会不会要它？**

普通 Prompt/评分往往只看到：
- 关键词；
- 单次要求；
- 正确性；
- 技术完成度；
- 粗粒度“好不好看”。

但创作者真实意图里还存在：

1. **Relation｜关系**
   - 什么增强什么；
   - 什么压制什么；
   - 什么补偿什么；
   - 哪些关系必须同时存在。

2. **Priority｜优先级**
   - 两个要求冲突时保谁；
   - 哪个是主，哪个是次；
   - 哪些是绝对不能牺牲的。

3. **Rationale｜理由**
   - 为什么接受；
   - 为什么返工；
   - 为什么即使“画得不错”也要否决。

4. **Dynamic Trace｜动态轨迹**
   - 意图如何在探索中更新；
   - 什么被冻结；
   - 什么失效；
   - 哪个选择改变了后续方向。

**674-119 的真正价值就在这里。**

十元 / 动态链只是这一“结构化创作意图”问题的候选表示法之一，不预设它一定正确。

---

## 2｜674-118 在这里的角色

118 不只可以写“个人画风规范”。

它还可以承担更上游的一步：

> **把创作者原本隐性的审美、风格和判断习惯，转成 AI 能读取、比较、执行的结构化创作意图。**

关系变成：

创作者脑中的感觉 / 经验 / 偏好  
→ 可描述视觉规律  
→ 结构化创作意图  
→ 关系 / 优先级 / 理由 / 动态轨迹  
→ AI 生成 / AI 评价 / AI 协作

因此 118 可以成为候选 11 的“意图提取与结构化入口”。

---

## 3｜674-120 在这里的角色

理解意图以后，还会出现冲突：

- 想更压迫，但不能丢人物温度；
- 想改动作，但不能改身份；
- 想增强视觉冲击，但不能破坏原画风；
- 想满足 A，同时必须保持 B/C/D。

120 负责：

> **当多个创作意图同时成立时，AI 能不能知道谁优先、谁可牺牲、什么不能误伤。**

因此：

118｜提取并结构化创作意图  
→ 119｜关系 / 优先级 / 理由 / 动态轨迹  
→ 120｜冲突处理 + 非目标保持  
→ 122｜评价是否真正符合创作者选择

---

## 4｜122：AI 评价为什么重要

传统评价容易集中在：
- 对不对；
- 像不像；
- 有没有错误；
- 完成度高不高。

但创作任务还存在：
- 审美偏好；
- 创作方向；
- 概念风险；
- 作者意图；
- 是否愿意继续使用。

因此：

> **“结果正确”不等于“创作者接受”。**

ACCEPT / REWORK / REJECT 是真实创作决策：

- **ACCEPT**｜收：直接进入下一步；
- **REWORK**｜改：方向保留，修改后继续；
- **REJECT**｜扔：这次结果/方向不再继续。

REJECT 可以发生在“画得很好”的结果上。

### 候选 11 对 AI 评价的推进

不是再造一个“审美总分”。

而是测试：

> **加入结构化创作意图以后，AI 是否更能预测个体创作者真实的审美/创作选择。**

这比单纯“AI 会不会评分图片”更接近 Human-AI Co-creation。

---

## 4.1｜外部研究信号：AI 创意评价已经从“正确”走向“审美与个体选择”

2025–2026 的外部研究正在出现三个明显信号：

### 信号 A｜创意评价不能压成一个“正确分”

2026 Human Creativity Benchmark 区分：
- convergence｜大家更容易一致的部分，如技术正确、视觉层级、可用性；
- divergence｜本来就可能因人而异的部分，如审美方向、概念风险、个人偏好。

这说明：

> **创作评价里，“分歧”不一定是噪声，它可能正是创作者自我和审美差异本身。**

### 信号 B｜AI 已经开始研究“预测具体某个人的审美”

2026 个性化图像审美研究不再只追求通用审美模型，而是通过主动收集个人偏好，预测目标个体的审美评价。

这给候选 11 一个非常重要的外部接口：

> 社会已经开始问“这个具体的人喜欢什么”；  
> 候选 11 再往前问一步：**这个创作者为什么这样选？哪些关系更重要？他的意图如何变化？**

### 信号 C｜AI 与文化讨论越来越强调 human intent / originality / agency

UNESCO 2025–2026 对 AI 与艺术、文化的讨论持续强调：
- 艺术家的意图与原创性；
- 人类创造性不能被单纯自动化替代；
- AI 应增强而不是抹平文化表达；
- 文化多样性和创作者主体性需要被保护。

因此候选 11 的社会问题不是“让 AI 统一决定什么是美”，而是：

> **让 AI 更准确理解不同创作者自己的美学、关系结构和价值优先级。**

这与“艺术家保持自我 / 创作者主权 / 文化多样性”直接相关。

外部研究参考：
- The Human Creativity Benchmark, 2026
- AI Outperforms Humans in Personalized Image Aesthetics Assessment via LLM-Based Interviews and Semantic Feature Extraction, 2026
- UNESCO, AI and Culture / Artificial Intelligence and Art, 2025–2026

## 5｜最重要的实验原则：先预测，再揭晓

候选 11 禁止：

我已经知道最后选了什么  
→ 再用十元解释  
→ 发现解释得很好  
→ 宣称十元有效

正确证据链必须是：

先冻结创作意图表示  
→ 隐藏创作者最终选择  
→ AI 预测 ACCEPT / REWORK / REJECT  
→ 冻结预测  
→ 揭晓真实选择  
→ 统计命中与失败类型

一句话：

> **解释能力不等于预测价值。**

---

## 6｜《方志敏》的正确位置：开发集 / 内部验证

《方志敏》仍然很重要，因为它有：
- 完整真实创作过程；
- 十元/动态链指导痕迹；
- 监狱压迫、日常暖意、战友情、《清贫》插叙等真实关系判断；
- 大量接受 / 修改 / 否决记录。

但为了避免：

> **“用自己编的理论解释自己的作品”**

《方志敏》不应该承担最终外部有效性证明。

更合理的定位：

**DEVELOPMENT / INTERNAL VALIDATION**

用途：
- 把结构化意图字段设计清楚；
- 发现 failure family；
- 调整实验协议；
- 检查能不能真正做预测。

## 7｜硬门：必须找第二位创作者 + 对方自己的项目

### External Creator Validation

最终关键验证必须换：

> **另一个创作者 + 另一个真实项目。**

不是让对方来评价《方志敏》。

而是读取 / 访谈对方自己的：
- 创作目标；
- 参考；
- 选择与否决；
- 修改记录；
- 版本过程；
- 最终真实决策。

### 外部验证流程

第二创作者自己的项目  
→ 在不知道后续真实选择的情况下提取结构化创作意图  
→ 冻结 Relation / Priority / Rationale / Dynamic Trace  
→ 给 AI 看留出的候选结果  
→ AI 预测 ACCEPT / REWORK / REJECT  
→ 冻结预测  
→ 揭晓该创作者真实选择  
→ 与普通画质评价 / 普通自然语言意图比较

### 为什么这个证据特别重要

如果十元 / 结构化意图：

- 只在 74 自己作品里有效 → USER_VALIDATED_INTERNAL；
- 换到别人的真实项目仍能预测 → 开始接近 USER_VALIDATED_EXTERNAL。

这才真正切断自产自证。

## 11｜潜在社会效益

### A｜人机共创
AI 不只是替人生成，而是更准确地理解、保持并响应创作者的创作意图。

### B｜艺术家保持“自我”
目标不是让所有人都得到统一“最优美学”，而是：

> **让 AI 更好地服务不同创作者自己的审美与判断。**

这有助于降低生成模型把作品拉向平均化、模板化方向的风险。

### C｜创作者主权

- 哪些是核心意图；
- 哪些不可被覆盖；
- 哪些决定必须交还创作者；

那么 AI 更可能成为：

> **可控的共同创作者 / 工具**

### D｜文化表达、传承与再创造

对于传统文化、地方文化、历史题材：

真正需要保持的不只是：
- 图案；
- 服装；
- 色彩；
- 表面符号。

还可能包括：
- 叙事关系；
- 价值优先级；
- 情感结构；
- 审美判断；
- 创作者如何理解和转译传统。

结构化创作意图如果有效，**可能**帮助这些深层内容在 AI 生产中被更稳定地保留、转译和再创造。

这可以作为：
- 文化传承；
- 多样性保护；
- AI 时代文化再创造

的潜在社会意义。

**注意：这是潜在社会效益，不能在实验前写成“已经实现文化复兴”。**

# 候选 12｜F 长流程可靠生产：面向独立创作者与小型创作团队的可控 AI 创作生产协议

## 当前一句话

> **能否构建一套面向独立创作者与小型创作团队的长流程 AI 创作生产协议，使创作者意图在多轮 Agent / AIGC 生产中持续保持，同时让自动化权限、结果验收、资产状态与失败恢复都处于可控、可追踪状态？**

来源：
- 674-123｜F-LONGRUN 长流程 Agent 可靠生产与恢复
- 674-278｜USER→SOCIETY 社会价值验证

状态：**CANDIDATE / NOT FROZEN**

## 这题到底研究什么

不是研究“AI 能不能 24 小时自动跑”。

真正的问题是：

> **当 AI 进入长流程、跨工具、多阶段创作后，怎样让它持续推进，却不把创作者的意图、控制权、资产状态和判断依据弄丢？**

核心对象：

```
Intent / Constraint
→ Agency / Escalation
→ Evaluation
→ Recovery / Production
```

对应四层：

1. **Intent / Constraint｜意图与约束**
   - 创作者到底想保留什么；
   - 哪些内容 LOCK；
   - 哪些允许 FLEX；
   - 多轮生产中如何避免意图漂移。

2. **Agency / Escalation｜AI 权限与人工接管**
   - 哪些任务可以 AUTO；
   - 哪些需要 CHECKPOINT；
   - 哪些必须 USER_REVIEW；
   - 哪些情况必须 STOP。

3. **Evaluation｜结果与过程验收**
   - 是否真的完成；
   - 是否保持创作意图；
   - 是否违反约束；
   - 中间轨迹是否可靠。

4. **Recovery / Production｜状态与恢复**
   - 状态是否丢失；
   - 失败是否可续；
   - 资产是否可追踪；
   - path / SHA / seed / manifest / receipt 是否完整；
   - 中断后能否恢复到正确节点继续生产。

## 面向谁

- 独立 AI 创作者；
- 2–20 人的小型动画 / 视觉团队；
- 没有大型基础设施的个人工作室；
- AI 动画 / AIGC 视觉生产团队；
- 技术美术 / AI Pipeline 岗位。

## 和社会已有方法的边界

不能把以下内容说成原创：
- Agent；
- HITL；
- workflow / orchestration；
- checkpoint / rollback / retry；
- provenance；
- benchmark / TEVV。

本候选真正可能新增的是：

> **把这些通用方法整合并操作化到长期视觉创作场景中，使“创作者意图保持 + AI 权限控制 + 真实评价 + 失败恢复”形成一条统一生产链。**

## 最小论文切口

本科论文不需要证明整个系统。

可以压成：

> **长流程 AI 创作中，结构化的意图约束、人工升级门与状态恢复机制，是否能降低多轮生产中的意图漂移与返工？**

### 对照 A｜普通流程
- 聊天；
- 文件夹；
- 人工记忆上下文；
- 需要时再返工。

### 对照 B｜可控长流程协议
- Intent / Constraint；
- AUTO / CHECKPOINT / USER_REVIEW / STOP；
- Outcome / Intent / Trajectory Evaluation；
- state / evidence / recovery / manifest。

### 可以测
- 创作意图丢失次数；
- 错误资产调用次数；
- 人工解释/重复说明次数；
- 返工次数；
- 中断恢复时间；
- 用户审核次数；
- 最终任务完成率。

## 这条为什么值得进候选池

- 与 74 已经实际运行的 Agent / Linear / Canvas / Codex / Worker 工作流直接相连；
- 不是纯理论，可以拿真实生产日志做材料；
- 对作品集和求职同样有价值；
- 面向独立创作者 / 小团队，受益对象明确；
- 可缩小成 5000 字本科论文；
- 即使结果不显著，也可以得到“哪些控制机制有效、哪些只是管理负担”的有效结论。
