## 这题到底在研究什么

普通评价往往问：

> 这张图好不好？

但真实创作里，创作者最终做的是：

- **ACCEPT**｜接受，继续生产；
- **REWORK**｜方向保留，修改后继续；
- **REJECT**｜这次结果/方向不再继续。

而 REJECT 不等于“画得差”。

一个结果可能：
- 技术质量高；
- 画面漂亮；
- 没有明显错误；

但仍然因为：
- 创作关系错了；
- 主次错了；
- 情绪方向错了；
- 本来应保留的关系被抹掉；
- 叙事目标被替换；

而被否决。

因此问题变成：

> **能不能把“创作者脑子里为什么要/不要”的关系结构显式化，并用它预测真实决策？**

---

## 十元在这题里的位置

十元不是先验正确答案，而是**候选的创作意图关系表示法**。

可记录：

- 主十元 / 次十元；
- 生 / 克 / 补；
- 强度；
- 起点 → 变化 → 终点；
- 动态链；
- 哪些关系必须保留；
- 哪些关系允许转向。

它不是为了“解释完作品后显得很合理”，而是要进入**事前规则 / 后续预测**。

## 《方志敏》为什么适合当第一案例

《方志敏》已有真实创作过程，不是为了论文临时造案例。

项目中已经发生过：
- 监狱压迫；
- 日常暖意；
- 战友情；
- 《清贫》插叙；
- 人物关系主次；
- 某些镜头“漂亮但不对”的否决；
- 叙事情绪与关系结构的反复调整。

因此可以把既有创作选择整理成：

```
事前/早期创作意图
→ 十元 / 动态链表示
→ 候选镜头/方案
→ 隐藏最终真实选择
→ 预测 ACCEPT / REWORK / REJECT
→ 揭盲
```

- 起点→变化→终点；


最后和真实创作决策揭盲比较。

## 如果什么结果出现，这题才真正有价值

### 支持
如果 C 组在未见最终答案前：
- 更准确预测真实选择；
- 尤其更能识别“画面很好但创作意图不对”的 REJECT；
- 并且不是靠泄露答案；

那么可以说：

> **结构化创作意图表示，对真实创作选择具有增量预测价值。**

### 不支持
如果 C 与普通文字没有明显差异，或者只能事后解释：

> 十元在这个任务上没有证明额外价值。

这也算有效研究结果。

## 最大风险

### 1｜事后合理化
先知道用户选了什么，再用十元解释。

→ 禁止当验证证据。

### 2｜自产自测
同一个人制定规则、挑案例、打分、解释结果。

→ 必须做隐藏答案、固定规则、最好有独立评价者。

### 3｜样本太少
只拿 3–5 个漂亮案例。

→ 只能当案例分析，不能说有预测能力。
