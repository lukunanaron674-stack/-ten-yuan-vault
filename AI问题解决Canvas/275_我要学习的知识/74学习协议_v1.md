# 74学习协议 v1

> 来源：275 R1-R5
> 状态：FROZEN v1
> 固定输入：`00_BASE_24知识点.md`

## 目标

不是“看懂答案”，而是：不给答案时能从物象恢复原理，在陌生现实问题中识别并采取行动；核心知识最终能跨领域迁移。

## 学习流程

0. 分级：知道 / 识别 / 应用 / 迁移
1. 懂：一句大白话
2. 物：具体可见、可摸、最好能动的物质对象
3. 变：动态机制才加入时元变化链
4. 己：绑定74真实案例
5. 问：设计一句现实触发问题
6. 忆：关闭资料，从物象主动恢复原理
7. 用：陌生案例识别，不提前报术语
8. 迁：换领域仍识别同一结构
9. 十元：理解原知识后再抽关系结构；禁止用十元覆盖原知识

## 记忆宫殿｜AI动画工厂

- 质检室 = Evaluation = 做对了吗？
- 中央控制室 = Agency = 谁决定？
- 导演室 = Intent & Preference = 到底要什么？
- 生产线 = Long-horizon = 怎么一直正确地做？

宫殿只收“重要 + 长期使用 + 容易混淆/遗忘”的知识。

## 各编码分工

- 大白话：理解
- 物象：视觉锚点
- 动态比喻：机制
- 时元：变化过程
- 真实案例：迁移到74现实经验
- 触发问题：现实调用
- 十元：跨领域关系压缩
- 记忆宫殿：长期组织与检索
- 00–99：未来知识规模扩大后的统一数字索引；当前暂不强制启用

## 单课模板

每个重要知识单元包含：

1. 原始术语
2. 一句话大白话
3. 生动物质对象
4. 必要时的时元变化链
5. 74真实案例
6. 一个触发问题
7. 必背锚点（能不背则不背）
8. 主动回忆测试
9. 陌生案例识别测试
10. 核心知识进行跨域迁移测试
11. 十元映射仅在理解后、有关系价值时加入

## 学习深度

L1 知道 → L2 理解 → L3 识别 → L4 解释 → L5 应用 → L6 跨域迁移。

核心知识优先达到 L6；辅助知识以 L4-L5 为主。

## 课程顺序

以 `275-BASE` 的24单元为课程池，从 A1 开始；优先保证核心8点：A1、A3、A7、B2、B4、C1、C6、D5。

## DONE 判定

一个知识只有在以下链路成立后才算真正学会：

`不给答案 → 从物象恢复原理 → 陌生案例主动识别 → 知道采取什么行动`

达到跨领域仍能识别同一关系结构，记为 L6。

## 减法原则

成熟工程细节优先交给 AI / Codex / Worker。74重点学习会影响创作决策、研究判断、系统设计与跨域迁移的知识。
