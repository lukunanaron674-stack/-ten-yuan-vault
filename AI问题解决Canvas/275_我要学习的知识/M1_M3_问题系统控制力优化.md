# M1 + M3｜问题系统控制力优化

> 来源：COURSE-275 学习记录
> 状态：已登记

## 新总定位

问题系统不只是“管理问题”，而是在逐步变成：

**74 对 AI 的控制系统 / 总控制面板**

上层目标：

**持续提高74对AI的判断权、规则权、状态权与素材证据权。**

## 三层结构

### 1. 对象层
管理：
- 图
- 视频
- 角色卡
- 规则
- 素材

### 2. 状态层
管理：
- 任务状态
- 素材状态
- 判断状态
- 偏好版本
- 候选XN → 正式XN

### 3. 控制层
管理：
- AI能否继续
- 当前评价是否可信
- 什么时候需要74接管
- XN是否需要更新

## M1｜评价控制器

M1用于检查：
- 可靠度：固定XN后，Z是否稳定
- 有效性：XN是否真正对上Z
- 目标漂移：目标XN变化/丢失但Z继续
- 评价漂移：Z变化但旧XN继续判断
- 古德哈特：XN变成优化目标后反向绑架Z
- 校准：系统是否知道自己到底有多准
- 人类评价边界：机器XN覆盖不了的NX何时必须由74介入

**M1提升：74对AI判断权的掌控。**

## M3｜偏好 / 素材证据控制器

M3不是只有审美偏好，而是：

**NX审美 → 素材证据 → 对比关系 → 候选XN → 74确认 → 正式XN → 回到生产**

需要把素材管理与状态管理接入：
- 正样本 / 负样本 / 模糊样本
- 对比组
- 规则证据
- 偏好版本
- 候选XN / 正式XN
- 已冻结参考

**M3提升：74对AI学习方向 + 素材证据的掌控。**

## 闭环

问题出现
→ 状态记录
→ AI执行
→ 产生素材
→ 人/机器评价
→ M1检查评价是否可信
→ 74留下偏好反馈
→ M3把反馈与素材变成证据
→ NX逐步XN化
→ 更新规则
→ 再进入AI
→ 检查漂移
→ 必要时74接管

## 结论

问题系统应从“问题清单”升级为：

**对象管理 + 状态管理 + 评价控制 + 偏好证据 + 人类接管**

其中：
- M1 = 评价控制器
- M3 = 偏好/素材证据控制器
