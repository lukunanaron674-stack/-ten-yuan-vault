# 275-BASE｜我要学习的知识｜24个知识点

> 状态：FROZEN BASE
> 用途：275 后续 R1-R5 的固定输入。后续轮次研究“怎么学”，不随意改动“学什么”。

## A｜Evaluation 评价与验收（7）

- A1｜完成定义：任务执行完成、技术完成、质量达标、用户接受并非同一件事。
- A2｜评价指标 Metric：什么可以数字化，以及数字是否真的代表目标。
- A3｜Goodhart / 代理指标：指标被当成目标后，可能出现“指标变好、真实结果变差”。
- A4｜自动评价器 Evaluator：用模型、规则或程序自动审核结果。
- A5｜Human Evaluation：识别哪些判断仍必须由人完成。
- A6｜多层验收体系：程序检查 → AI审核 → 作品审核 → 74最终接受。
- A7｜Evaluation Drift / 假 PASS：系统长期运行后可能越来越擅长证明自己“做对了”，却偏离真实质量。

## B｜Agency 人机自主权（5）

- B1｜Agency：行动权、决定权与责任归属。
- B2｜责任边界：74 / CHATGPT / Agent / WORKER / CODEX 分别负责什么。
- B3｜授权等级：自动执行 / 执行后汇报 / 审核后执行 / 必须询问 / 禁止自主。
- B4｜Mixed-Initiative：人和 AI 在不同阶段如何共同拥有主动权。
- B5｜Human-in-the-loop / Human-on-the-loop：人应逐步参与还是在关键节点监督。

## C｜Intent & Preference 意图与偏好（6）

- C1｜显式要求 vs 隐式意图：说出来的要求与真正想达到的结果可能不同。
- C2｜Constraint：冻结项、可变项、硬约束与软约束。
- C3｜Preference：正确之外的“更喜欢哪一个”。
- C4｜Preference Elicitation：通过选择、比较、反馈逐渐获取人的偏好。
- C5｜Feedback Signal：接受、拒绝、修改、重跑、评分分别提供什么信息。
- C6｜结构化意图表示：自然语言 → 目标 / 对象 / 冻结项 / 可变项 / 关系 / 判断标准 / 决策权等结构字段。

## D｜Long-horizon 长程一致性（6）

- D1｜State：系统当前到底处于哪一步、什么状态。
- D2｜Memory vs State：记得过去发生什么 ≠ 知道当前应该做什么。
- D3｜任务分解与依赖：前置、阻塞、解锁与执行顺序。
- D4｜Checkpoint / 失败恢复：长流程失败后从正确节点继续，而不是全部重来。
- D5｜Goal Drift：长程执行中任务仍在运行，但目标逐渐偏离原始目标。
- D6｜Provenance / 可追溯性：结果由哪个输入、规则、版本和决策产生。
