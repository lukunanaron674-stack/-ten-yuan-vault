## 一、方法论选择与理由

### 1.1 总定位：实践型研究（practice-led research）

本文不是"研究别人的创作"，而是"研究我自己的创作"——研究者=创作者本人。这属于实践型研究范式（practice-led research，见盘点 E11/E12）：创作者以自己的实践为研究现场，第一人称材料是合法且核心的证据，而不是需要被消灭的"偏差"。定位定了，方法就定了。

### 1.2 为什么是混合方法（mixed methods）：定性为主 + 小样本准实验

三个研究问题的性质不一样，必须各配各的方法：

- **RQ1（提取）本质是定性问题**。研究对象是"说不清的感觉"的原话形态，一旦先量化就会把原话压扁成量表分，丢掉最有价值的部分。所以用第一人称报告（参照 DES 描述经验取样法的流程骨架，B4）+ 轮盘词定位（VAWE/GEW，B1/B2）+ 研究者后置编码。
- **RQ2（构成）是过程性问题**。意图怎么落成画面、为什么改，只能靠案例复盘（single case study）回答——方志敏项目有完整生产记录和多轮审美修改，这是文档研究，不需要被试。
- **RQ3（应用）是唯一带因果味的问题**："照目标感受调条件，感受强度会不会朝那个方向动？"这个问题纯定性答不了，必须至少有可比的数字。所以上小样本准实验：SAM 自评（B3）+ 轮盘选词，配对比较。

定性定量的大致比例约 **7:3**：定量只承担"强度与方向"这一项最小任务，不做任何超出此范围的主张。

### 1.3 为什么不是纯量化（答辩必问，先写死）

1. **工具不允许**。五行+三元色彩关系是创作来源和组织架，不是心理学量表——没有信度、效度、常模证据，拿它当测量工具去算相关、算显著性，本身就越界（283红线）。真正承担测量的轮盘词与 SAM 才是有文献背书的工具。
2. **问题不允许**。本文要回答的是"这套提取流程对这位创作者可不可用"，不是"中国人的视觉审美情绪分布"。前者 n=1 就能做，后者需要大样本+验证性设计，本科5000字根本不承载。
3. **范式不允许**。practice-led 的证据链就是"实践记录+第一人称材料+作品"，硬套量化范式反而丢了方法论合法性。

## 二、研究问题细化（每个 RQ 给出"怎么算成立"）

### RQ1 提取：主观感受怎么被挖出来、说清楚？

**可操作化的研究问题**：创作者面对五行+三元色彩关系的触发图时产生的自由原话，能否经由"原话→中性结构→候选编码→本人复核"流程，转化为稳定可复用的感受条目？

**"提取成功"的三条判据**（写进论文②章的结果部分）：

| 判据 | 怎么算 | 指标 |
|---|---|---|
| 覆盖率 | 自由原话拆成意义片段后，能落到轮盘词或五行归类的比例 | 目标 ≥80%，其余进"其他"栏如实报告，不硬塞 |
| 本人确认率 | 后置候选编码逐条经本人复核（✓确认 / △接近 / ✗不是） | 确认+接近的占比；✗条目原样保留并写一句"为什么不像" |
| 稳定性（抽查） | 抽 2–3 条触发图隔天重看，提取结果是否基本一致 | 只做描述性报告，不做重测信度检验（n=1 不够格，也不冒充） |

### RQ2 构成：说清楚的感受怎么落到色彩/角色/场景/叙事/镜头上？

**可操作化的研究问题**：方志敏项目中，创作意图→画面决定→审美修改的链路能否被完整还原？其中多少修改能挂到 RQ1 提取出的感受词上？

**"构成对应"的三条判据**：

1. **链路完整**：每条审美修改在模板C里五项齐全（维度/原因/目标感受/前后对比/达成判定），填不全的如实标注缺什么。
2. **挂接率**：修改原因能对应到感受词表条目的修改占比；对应不上的标"未入表"，也是发现（说明有些修改凭的是别的依据，比如叙事节奏常识）。
3. **沉淀率**：多少条修改最终"定成了规则"（可复用的约束，如"烈士场景压暖色饱和度"）——这是结论章"哪些定成规则"的直接素材。

### RQ3 应用：照目标感受调画面条件，感受强度真的变吗？

**可操作化的研究问题**：在固定工作流的前提下，对一段 H3 短镜做 3–5 个条件变体（基线 + 逐维改动镜头/光影/动态/声音），被试对目标条件变体的感受评分是否朝创作者设定的目标方向移动？

**"感受强度变化"的三条判据**：

1. **方向**：目标条件变体的 valence（愉悦度）/ arousal（唤醒度）均值相对基线的移动方向，是否与目标感受的理论方向一致（如目标"压抑"→ valence 降、arousal 降）。
2. **命中**：目标词命中率 = 该条件下选目标词的被试人数 ÷ 该条件全部选词人数。
3. **检验**：配对比较用 Wilcoxon 符号秩检验（非参数，适配小样本）；n<8 时只做描述性对比，不做检验——论文里如实写"探索性观察"。

**红线防护（设计层面就拆掉）**：模板B 里**只有**强度分与选词，没有"哪个更好看/更艺术"的评价项。艺术性评价与感受强度物理隔离，若结论章要谈艺术性，只能引创作者自述并明确标注与实验数据无关。

## 三、抽样与数据

### 3.1 ①部分：创作者本人 n=1，多次采样

- **样本来源**：论文作者本人（数字媒体艺术创作者，有五行+三元色彩的创作实践基础）。
- **样本量**：n=1 创作者 × 6–10 个采样时点（每个触发图采一次，覆盖起稿/上色/调整等不同创作阶段；不少于6次，否则①章材料单薄）。
- **抽样方法**：目的性抽样（purposive sampling）——触发图按五行/三元色彩关系有代表性地选，不随机。
- **n=1 的合法性声明（论文里要写的一段话的意思）**：practice-led 范式中，研究者即创作者，第一人称材料是该范式的标准证据（E11/E12；流程骨架见 DES，B4）。本文不外推任何人群结论，只回答"这套工具对这位创作者是否可用"——这句话同时就是红线"小规模探索定位"的方法学表达。
- **采样流程（按 674-297 固化顺序）**：看触发图 → **当场**逐字记自由原话（不改写不美化）→ 24小时内本人转写确认"这是我当时的感受" → **之后**研究者角色后置编码（候选标签）→ 本人复核编码。

### 3.2 ②部分：无被试，文档复盘

- **样本来源**：方志敏项目全套生产记录 + 审美修改前后版本素材（改稿前/后分镜、色彩稿）——**此素材包需 674 提供，是 RQ2 的命根子**。
- **方法**：单案例研究（single case study）+ 前后版本对比分析，用模板C逐条登记。登记时尽量引用原始沟通/记录中的原话作为"修改原因"，不事后脑补动机。

### 3.3 ③部分：小样本被试

- **样本来源**：本校同学（方便抽样，convenience sampling），数字媒体/设计类背景优先，视力正常、自愿参加。
- **建议人数**：**最低 8 人，理想 12–15 人**。理由：
  - 8 是 Wilcoxon 检验还能给出方向性结论的下限；
  - 12–15 在 3–5 个条件变体 × 被试内设计（within-subject，每人看所有变体）下，单人总时长约 15–25 分钟，一个宿舍楼层就能凑齐，4 周内稳稳做完——这是本科论文可行性约束下的诚实数字；
  - 参照系：同类正式研究用 60 人（B1 的 VAWE 自评），本科探索取其一个量级以下，定位就是"方向性观察"。
- **抽样声明**：方便抽样，非概率样本，**不代表任何总体**，结论只写"在这 8–15 名被试上观察到……"。
- **实验设计要点**：每人看全部变体（被试内），变体呈现顺序用拉丁方/随机轮换抵消顺序效应；单变体短镜（约10–20秒），看完10秒内打分；变体间休息。条件设计为**基线 + 逐维改动**（每次只动镜头/光影/动态/声音中的一个维度），不做全因子组合——既控条件数，又保住"单一目标感受"的可读性。

## 四、数据收集工具：三份空白模板规格说明

> 以下为规格说明（给 674/后续执行者照此建表），不是填好的表。全部标 CANDIDATE。

### 模板A｜第一人称报告记录表（RQ1 用）

| 字段 | 规格 | 填写规则 |
|---|---|---|
| 编号 | S01–S10 | 一图一号 |
| 采样时间点 | 日期 + 创作阶段（起稿/上色/调整/收尾） | 当场填 |
| 触发图 | 文件名 + 缩略图 + 属性标注（五行属性、三元色彩关系） | 触发图定稿后填，采样时只看图不看标注 |
| 自由原话 | 逐字记录，一条一景 | **原话不加工**：不改写、不美化、不"翻译"成学术词 |
| 时间点 | 该感受对应的画面位置/时刻（如"起稿第3版背景铺色时"） | 当场填 |
| 本人确认 | ✓（是我当时的感受）/ 备注 | 24小时内完成，确认后才算数 |
| 研究者后置编码 | 候选轮盘词（VAWE/GEW 择一为主、另一个补漏）+ 五行归类 + valence/arousal 估计 | **后置**：不在采样当场填；标"候选"字样 |
| 本人复核 | ✓确认 / △接近 / ✗不是（✗需一句"为什么不像"） | 逐条复核，✗条目保留不删 |
| 片段落点 | 该原话拆分后各片段落在哪个词/哪一栏 | 覆盖率统计的原始依据 |

配套规则：①编码者与创作者都是本人，但**角色分离、时间分离**（记录时≠编码时≠复核时），表内用三栏物理隔开；②"其他"栏是合法落点，塞不进去的不硬塞。

### 模板B｜感受强度打分表（RQ3 实验用）

**被试侧字段**（每条记录 = 1名被试 × 1个变体，单条用时控制在 5–10 分…即半分钟内，流程上"看完10秒内打完"）：

| 字段 | 规格 |
|---|---|
| 被试编号 | P01–P15（不记姓名学号） |
| 变体编号 | V0基线 / V1–V4（含条件说明，如 V2=光影改冷调） |
| 呈现顺序 | 该被试看到的顺序号（拉丁方用） |
| SAM 愉悦度 valence | 1–9（9点小人图，B3） |
| SAM 唤醒度 arousal | 1–9 |
| 轮盘选词 | 20词中选 1 个最贴近的（+可选 1 个次贴近） |
| 打分时刻 | 看完至提交的间隔（秒） |

**研究者侧字段**（被试不可见）：

| 字段 | 规格 |
|---|---|
| 目标感受 | 该变体设计时设定的目标词 + 目标方向（valence/arousal 预期升/降） |
| 命中 | 该变体下选目标词的人数（后统计） |
| 工作流参数 | 固定项清单 + 本变体改动参数（配对生成时留档） |

配套规则：①条件变体 3–5 个，多则打分疲劳；②变体素材配对生成、参数留档，与 297 图池分开；③表内**无艺术性评价栏**——这是红线防护，不是遗漏。

### 模板C｜方志敏前后版本对比表（RQ2 用）

| 字段 | 规格 |
|---|---|
| 修改编号 | M01–Mnn |
| 所属场景/镜头 | 场景名 + 镜头号 |
| 修改维度 | 色彩/角色/场景/叙事/镜头 五选一为主，可加一个次维度 |
| 改前描述 | 版本号 + 截图/分镜号 |
| 改后描述 | 版本号 + 截图/分镜号 |
| 修改原因 | 尽量引生产记录/沟通原话；确无记录则写"凭当时的判断"并标注 |
| 对应目标感受 | 链接模板A提取出的感受词编号；挂不上的写"未入表" |
| 达成判定 | 创作者后评：达成/部分/未达成 + 一句理由 |
| 是否沉淀为规则 | 是/否；"是"的写出规则句（结论章直接可用） |

## 五、伦理考量

### 5.1 本人报告的偏差控制（①②部分的核心伦理=方法纪律）

1. **悬置（bracketing）**：采样当场只记原话，不做任何理论解释、不套五行词——解释行为全部推迟到后置编码阶段。表A 的栏位顺序本身就是这个纪律的物理实现。
2. **后置编码 + 候选制**：研究者编码在本人确认原话之后进行，编码一律标"候选"，且必须回本人逐条复核。避免"先有框架、再找话填"的循环论证。
3. **角色分离声明**：论文方法部分明确写"记录/编码/复核三个角色由本人承担，但时间分离、栏位分离"，不假装是两个人——诚实本身就是对偏差的最好管理。
4. **不事后美化**：✗条目、"其他"栏、未达成修改全部留档进论文，负结果不删。

### 5.2 被试（同学）伦理（③部分）

- **知情同意**：实验前发一页知情同意书，要点：观看内容为 AI 生成短片片段；任务为看完打分+选词；总时长约15–25分钟；数据仅用于本毕业论文；匿名化处理（只记编号）；可随时退出且无需理由、不影响任何同学关系与成绩。
- **最小信息收集**：不收集姓名、学号、联系方式；被试编号与本人的对应表（如需要提醒到场）实验结束即销毁。
- **疲劳与不适防护**：单条短镜≤20秒，变体间强制休息；出现视疲劳即中止。
- **报备**：如学院有要求，实验方案先报指导教师备案后再启动。

### 5.3 数据安全与学术诚信

- 原始素材（原话记录、打分表、变体参数）本地存储，论文只呈现必要汇总结果。
- AI 生成素材与生产记录**如实标注生成方式**（ComfyUI 工作流、配对生成参数），不把 AI 产出说成手绘。
- 引用文献规范标注；实验数据不编造、不挑选性报告（显著的全报，不显著的也全报）。

## 六、局限性与答辩应对（每条直接给话术）

### 局限1｜样本极小（本人 n=1，被试 8–15）

**答辩话术**："本文定位是小规模实践探索，回答的是'这套提取工具对这位创作者是否可用、在这个实验设置下强度是否朝目标移动'，不是人群规律。n=1 在 practice-led 范式中是合法数据源（E11/E12；流程参照 DES），被试小样本只做方向性观察，所有结论都已标注'探索性发现'，未做任何总体外推。"

### 局限2｜主观性（自己提取、自己确认、自己判达成，疑似循环论证）

**答辩话术**："设计上做了三道闸：一，原话与编码在时间与栏位上分离，编码全部标候选且逐条回本人复核，不符的原样保留；二，RQ3 引入第三方被试，目标词命中率是独立于创作者自评的外部证据；三，✗条目与未达成修改全部如实呈现，负结果可查。"

### 局限3｜五行/三元色彩分类架不是心理学量表

**答辩话术**："五行+三元色彩在本文中是**创作来源与组织工具**，不是测量工具——论文从头到尾不宣称其获得心理学普适验证（这是论文的明确边界声明）。承担测量的是有文献背书的 VAWE/GEW 轮盘词与 SAM 量表；五行归类只出现在'组织感受条目'这一层。"

### 局限4｜AI 生成条件控制有限（无法实验室级单变量隔离）

**答辩话术**："实验控制到'工作流固定 + 改动参数明示留档'的程度，承认随机性带来的扰动无法完全消除；因此条件数限制在3–5个、采用基线+逐维改动的设计，只做方向性比较，不宣称因果；所有变体配对生成、参数可复查。"

### 局限5｜方便抽样的被试群（同质、非随机）
