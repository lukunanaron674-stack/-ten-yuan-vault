# 674-278｜R3 个人 / 团队 / 社会价值分离评分 v1

> 目标：把“对我有用”“对一个小团队有用”“对社会可迁移”彻底分开。
> 本轮分数是**当前证据下的工作评分**，不是客观真值；分数会随外部验证升降。

---

# 0. 评分口径

## A｜个人效用 Personal Utility
问的是：**现在是否已经真实帮助 74 的工作？**

主要看：
- 是否反复进入真实工作流；
- 是否减少混乱、返工、遗忘或错误；
- 是否帮助做出更稳定的判断；
- 是否已经与 Linear / Canvas / Codex / Worker / 本地生产发生真实连接。

### 解释
- 90–100：已经是核心基础设施/思维工具。
- 70–89：持续有用，但仍依赖人工解释或未闭环。
- 50–69：局部有用。
- <50：主要停留在概念层。

---

## B｜团队效用 Team Utility
问的是：**换成一个 2–20 人的小团队，能不能在有限教学后直接使用？**

主要看：
- 是否有清晰字段、状态、流程和验收；
- 是否依赖 74 的个人隐性知识；
- 是否可复制；
- 是否能降低协作成本；
- 是否有失败处理和责任边界。

### 解释
- 90–100：接近可直接部署。
- 70–89：有很强迁移性，但仍需适配。
- 50–69：可借鉴，尚不能直接复用。
- <50：过度依赖个人语境。

---

## C｜社会可迁移价值 Social Transfer Value
问的是：**陌生用户 / 陌生项目 / 陌生团队是否已有证据能受益？**

主要看：
- 社会问题是否真实存在；
- 74 的新增是否区别于已有方法；
- 是否有独立使用者；
- 是否有陌生场景复现；
- 是否有对照实验；
- 是否有失败边界；
- 是否有公开、可执行、可复现的材料。

### 解释
- 90–100：已有强外部复现和明确新增。
- 70–89：已有多次外部验证。
- 50–69：问题与方法合理，但主要还是内部证据。
- 30–49：有潜力，证据较弱。
- <30：当前主要是个人学习或已有知识转译。

---

## D｜证据强度 Evidence Strength
- E0：只有想法。
- E1：已有结构/规则。
- E2：在个人项目中出现实例。
- E3：多次个人真实运行/内部对照。
- E4：陌生场景或独立使用者复现。
- E5：多项目、多人、对照/统计支持。

当前没有项目达到 E4/E5。

# 2. F｜长流程 AI 创作可靠生产

## 当前评分
- 个人效用：**95/100**
- 团队效用：**84/100**
- 社会可迁移价值：**66/100**
- 潜在上限：**88/100**
- 证据：**E3**
- 置信度：**86%**

## 为什么个人效用极高
它已经不是一个“论文概念”，而是贯穿：
- Linear 工单；
- Canvas；
- Codex / Worker；
- 图片 / 视频资产；
- path / SHA / manifest；
- DONE / STOP / USER_REVIEW；
- Recover before Create；
- Verify before Expand；
- 失败恢复和重新分流。

也就是说，它已经直接参与真实生产。

## 为什么团队效用没有 90+
因为：
- 当前 schema 很多字段仍围绕 74 自己的系统；
- 新团队需要学习 Linear / Canvas / Codex / 资产层；
- 还缺一个“30 分钟上手版”与最小模板；
- 部分流程依赖当前项目目录和个人命名习惯。

## 为什么社会价值只有 66
因为底层概念——state、checkpoint、rollback、logging、provenance、verification——都不是 74 发明的。

74 当前最有价值的是：
**把这些原则变成 AI 创作生产的具体操作协议。**

但还没有陌生创作者独立复现，所以不能给 70+。

## 可以怎么说
### 可以
> 我在长期 AI 动画生产中，将状态管理、证据链、恢复、审核与资产追踪整合成了一套可执行工作流，并在个人真实项目中持续使用。

### 现在不要说
> 我提出了一套新的 Agent 可靠性理论。

> 我的系统已经证明能提升 AI 动画行业生产效率。

# 3. D｜Human-Agent 动态自主权

## 当前评分
- 个人效用：**91**
- 团队效用：**79**
- 社会可迁移价值：**59**
- 潜在上限：**84**
- 证据：**E2–E3**
- 置信度：**79%**

## 已有的真实东西
四因子：
- confidence；
- reversibility；
- preference-load；
- blast-radius。

四级门：
- L3 AUTO；
- L2 AUTO + CHECKPOINT；
- L1 USER_REVIEW；
- L0 BLOCK / STOP。

这套东西最大的价值不是“理论新”，而是非常容易被执行器消费。

## 为什么团队分高
因为它天然可以变成：
- SOP；
- 权限表；
- Agent policy；
- 审核门；
- 自动化路由器。

一个小团队不需要先理解复杂 HAI 理论，也能按表执行。

## 最大缺口
目前没有证明：
**动态四因子策略，比“全部人工审核”或“固定自动化”更好。**

所以社会价值暂时 59。

## 可以怎么说
> 我把 Agent 自主权拆成置信度、可逆性、偏好负载和影响范围四个判断因子，并将任务路由为自动执行、自动+检查点、人工审核、阻断四级。

## 现在不要说
> 我解决了 Human-Agent 动态自主权问题。

# 4. E｜创作型 / 长链 AI 三层真实评价

## 当前评分
- 个人效用：**87**
- 团队效用：**76**
- 社会可迁移价值：**56**
- 潜在上限：**82**
- 证据：**E2–E3**
- 置信度：**80%**

## 三层
1. Outcome Validity；
2. Intent + Constraint Fidelity；
3. Trajectory Reliability。

## 为什么有价值
它纠正了一个很重要的问题：

> “生成出来了” ≠ “完成了”  
> “好看” ≠ “符合作者意图”  
> “最后 PASS” ≠ “中间过程可靠”

这对创作型 AI 的确非常实用。

## 为什么社会价值仍低于 F/D
因为三层结构目前更多是：
**把已有 TEVV / human evaluation / process evaluation 思路做了适合创作场景的重组。**

真正能把分数推上 70 的证据，是：
三层评价能否比单分数、AI 自评、相似度指标更准确预测真实用户 ACCEPT / REJECT / MODIFY。

这个实验还没做完。

## 可以怎么说
> 我把 AI 创作验收拆成结果有效性、创作意图与约束保持、长流程轨迹可靠性三个层级，用于避免只看最终画面或模型自评分。

## 现在不要说
> 我建立了比现有 benchmark 更先进的评价体系。

# 5. C｜创作意图关系化表示

## 当前评分
- 个人效用：**89**
- 团队效用：**67**
- 社会可迁移价值：**46**
- 潜在上限：**91**
- 证据：**E1–E2**
- 置信度：**72%**

## 为什么出现“当前低、上限最高”
因为这是六方向里最像真正研究创新的地方，同时也是最危险的地方。

候选新增：
- Dynamic Relation；
- Priority / Conflict；
- Rationale；
- Dynamic Trace；
- IRG；
- 十元生/克/补关系；
- LOCK / FLEX；
- State0 → State1 → State2。

如果它真的能：
- 从前序行为恢复关系；
- 预测下一轮选择；
- 比普通标签 / 自然语言 / 规则表更好；
- 跨角色、跨场景仍有效；

那价值会很高。

但现在还没有这些证据。

## 当前最大的风险
**事后解释。**

如果用户选完 A，系统再说：
“因为这是 ZX 克 XN”，
那没有研究价值。

必须是：
> 在不知道后续选择的情况下，先根据已有数据生成关系结构，再预测下一轮。

所以当前社会价值只有 46，但潜在上限给到 91。

## 可以怎么说
> 我正在研究一种把创作意图表示成“目标—约束—关系—优先级—选择理由—变化轨迹”的结构，并测试十元/动态链是否能提供额外预测力。

## 现在不要说
> 十元已经可以准确理解人的创作意图。

> 十元比现有 AI 方法更先进。

# 7. H｜社会与制度

- 团队效用：54
- 社会价值：27
- 潜在上限：58

但这需要法律/政策语境下的进一步验证，当前不能当独立贡献。

# 8. 总系统评分

## 候选总系统
> **面向独立创作者与小型创作团队的可控、可监督、可评价、可恢复的长流程 AI 创作生产协议**

组成：

C Intent / Constraint  
→ D Agency / Escalation  
→ E Evaluation  
→ F State / Recovery / Production

## 当前评分
- 个人效用：**97/100**
- 团队效用：**86/100**
- 社会可迁移价值：**68/100**
- 潜在上限：**90/100**
- 当前证据：**E3-（强内部、弱外部）**
- 置信度：**84%**

## 为什么总系统反而比单项强
因为真正有差异的不是任一单个概念，而是：

**把“意图 → 自主权 → 评价 → 恢复生产”放进一个持续运行的创作者工作流。**

社会已有这些零件；
74 当前更像是在搭一个面向创作者的**系统级组合与操作层**。

这比单独宣传十元、Agent、评估器、恢复机制都更站得住。

# 9. 论文 / 作品集 / 求职：现在分别能怎么用

### 可以进入论文正文
与当前毕业论文“AIGC视觉规范/一致性”直接相关的：
- C：约束、LOCK/FLEX、非目标保持；

# 10. 目前禁止宣传的五句话

以下五类现在证据不够：

1. “十元已经被验证能准确理解创作意图。”
2. “我的 AI 系统比行业现有方案更先进。”
3. “我的系统能 24 小时稳定全自动生产动画。”
4. “我的评价体系比现有 benchmark 更准确。”
5. “这套方法已经具有社会普适价值。”

可替换为：
- “正在验证”；
- “内部项目已使用”；
- “候选方法”；
- “领域化整合”；
- “已形成可执行原型”；
- “待外部复现”。

# 11. 最小外部验证：只做 3 个实验就够

## EXP-278-01｜F 外部复现
找 1 位陌生创作者 / 同学。

任务：
用同一套角色或场景生产任务，各跑：
A. 普通聊天 + 文件夹；
B. 74 的状态/证据/恢复协议。

测：
- 找错文件次数；
- 返工次数；
- 中断恢复时间；
- 丢失状态次数；
- 用户需要解释次数；
- 最终完成率。

### 作用
直接验证 F。

---

## EXP-278-02｜D 自主权对照

同一批 20–30 个任务随机分：
A. 全人工审核；
B. 固定自动；
C. 四因子 L0–L3。

测：
- 人工审核次数；
- 错误漏过；
- 总耗时；
- 最终返工；
- 用户控制感。

### 作用
直接验证 D。

---

## EXP-278-03｜C+E 预测实验

冻结 30–50 条历史选择/否决/修改 case。

先隐藏真实后续。

三种方法：
A. 普通标签/自然语言；
B. IRG/关系结构；
C. AI 自由判断。

预测：
- ACCEPT；
- REJECT；
- MODIFY；
- 哪个约束会被保留；
- 哪个会被牺牲。

再用 E 三层协议评价。

### 作用
一次同时验证：
- C 是否有额外预测力；
- E 是否能更好解释真实用户结果。
