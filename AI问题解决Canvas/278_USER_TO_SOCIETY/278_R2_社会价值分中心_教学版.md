# 分中心 A｜674-120 多约束控制与非目标保持

## 一句话教学

> **我只叫 AI 改一件事，它为什么把其他东西也改坏了？**

例如：
- 只改动作，不应改脸；
- 只换景别，不应重设计服装；
- 只换场景，不应丢角色身份；
- 只调某一世界机制，不应把整体画风一起推翻。

这就是 **target change / non-target preservation（目标修改 / 非目标保持）**。

## 社会已经研究到哪里

社会已经在图像编辑、可控生成等方向研究：
- 要改的区域/语义是否按指令改对；
- 不相关内容是否保持；
- 身份、结构和风格是否发生非预期漂移。

所以：

> **“要改 A、不要误伤 B”本身不是 74 发明的。**

## 74 现在的位置

74 真正有潜力推进的是：

> 从“单张图片编辑”提升到“动画项目级、多资产、多轮次的约束保持”。

动画项目不是只有一张图，而是：

角色身份 × 比例 × 服装 × 色卡 × 场景 × 镜头 × 动作 × 世界观规则 × 版本。

一次只允许其中一部分变化。

### 候选贡献

**项目级多约束视觉规范：**
- LOCK：绝对不能变；
- FLEX：允许变化；
- TARGET：本轮必须变化；
- PRESERVE：本轮不许被误改。

这和 674-118 的“层级视觉规范”可以直接接起来。

## 为什么适合当前本科论文

因为已经有：
- 《黎黎隆》角色/场景资产；
- 风格规则；
- 角色身份冻结项；
- 大量失败图与返工记录；
- 可以做 Flat vs Hierarchical / LOCK-FLEX 对照。

**当前评级：高价值候选 / 可立即推进 / 论文方向仍未冻结。**

# 分中心 B｜674-122 真实评价：REJECT 到底是什么

## 先把三个词讲成人话

### ACCEPT｜接受
这个结果可以继续进入下一生产环节。

例：
> “这张角色图可以，拿它继续做四宫格。”

### REWORK｜返工
方向没扔，但需要修改后继续。

例：
> “脸是对的，身体比例不对，改完继续。”

### REJECT｜否决 / 弃用
**这次结果或这条方向不再继续用。**

不是说“它画得一定很烂”。

可能是：
- 画面质量不错，但不是我要的角色；
- 技术上成立，但叙事方向错了；
- 很漂亮，但破坏了项目风格；
- 方案没毛病，但我根本不想走这条创作路线；
- 生产策略本身决定停止。

所以 REJECT 最重要的一句话是：

> **“好不好看” ≠ “我要不要它”。**

## 为什么它和“方志敏项目里十元指导选择”高度相关

**是的，高度相关，但不是同一件事。**

122 在问：
> **“我们怎样判断一个结果最终会被创作者接受、返工还是否决？”**

119/十元在问：
> **“创作者为什么会做这个选择？创作意图内部是什么关系结构？”**

因此可以形成：

```
十元 / 动态链
→ 描述创作意图和关系结构
→ 生成“为什么这个方案对/不对”的理由
→ 122 用真实 ACCEPT / REWORK / REJECT 检验
→ 看这些结构能不能预测真实选择
```

### 《方志敏》可以怎么当案例

《方志敏》项目里并不是只在追求“画得漂亮”。

实际不断在决定：
- 监狱段需要怎样的压迫与对峙；
- 日常温度什么时候出现；
- 战友情怎样承担关系变化；
- 《清贫》插叙为什么在这里出现；
- 某个镜头虽然漂亮，但如果把本来应成立的关系/情绪结构改掉，仍会被否决。

这就很适合研究：

> **只看画质的评价系统，与加入“创作意图关系结构”的评价系统，谁更能预测最终 ACCEPT / REWORK / REJECT？**

这可能把 119 和 122 接成一条研究线。

注意：目前只能叫**候选假设**。必须做盲测/预测测试，不能看完结果后再用十元解释。

# 分中心 C｜674-123 长流程 Agent 可靠生产

## 先纠正当前状态

> **74 现在还没有用 Agent 真正跑出一条可验证的完整动画长流程。**

所以这条线现在**不是已完成贡献**，也不要提前说“已经解决了长流程 Agent”。

当前位置更准确是：

> **有非常丰富的真实创作工作流、失败问题和系统设计需求，但 Agent 长流程证据还没建立。**

## 社会正在解决什么

现在很多 Agent 看起来“会做事”，但任务一长就暴露问题：

- 中间状态丢了；
- 做到一半忘了原目标；
- 前一步错了，后面继续放大；
- 工具失败后不会恢复；
- 最终看似 DONE，但过程非常脆弱；
- 每一步都能做，串起来却不可靠。

## 74 的位置有什么特别

社会目前大量测试集中在：
- coding；
- web；
- terminal；
- GUI 软件。

而你的真实问题是：

> **原创二维动画项目的跨模态、跨资产、跨人工审美节点的长流程生产。**

它同时包含：
- 角色图；
- 场景图；
- 角色卡；
- H3 视频；
- 镜头；
- 音频；
- 文件资产；
- 版本；
- Linear 工单；
- Codex / Worker；
- 本地 GPU；
- 用户审美审核；
- 返工与恢复。

这比“Agent 能不能完成一个网页任务”多了一层：

> **创作者会在中途不断做审美/方向判断，流程不能只追求自动跑到底。**

## 潜在社会价值到底在哪

如果未来真正跑起来，可以研究：

### 1. 状态可靠性
几十步以后，角色身份、版本、任务目标有没有漂移？

### 2. 失败恢复
H3 跑坏、素材路径失效、生成中断后，能不能从正确节点恢复，而不是全部重来？

### 3. 人工介入成本
究竟哪些节点必须叫人，哪些节点 Agent 自己做反而更省事？

### 4. 创意生产的“长链成功”
最终做出视频还不够，要知道：
- 中间错过几次；
- 重跑多少次；
- 人救了多少次；
- 有没有错误资产进入下游；
- 状态是否污染。

### 潜在位置

> **把“Agent 长流程可靠性”从软件/web任务，推进到真实原创动画生产工作流。**

但现在必须标：

**HIGH POTENTIAL / NOT YET RUN / 未来验证线。**

# 分中心 D｜674-121 人机动态自主权

## 一句话教学

> **什么时候 AI 可以自己做，什么时候必须来问我？**

## 这个是不是你的原创？

**不是。**

Human-AI co-creation / mixed initiative / agency distribution / dynamic agency 都是社会已有研究。

所以 121 的正确定位是：

> **SOCIAL_KNOWN → 74 正在学习并转译。**

## 那 74 对社会可能还有什么价值？

现在的四因子：

- confidence｜AI 对当前判断有多确定；
- reversibility｜做错后能不能撤回；
- preference-load｜这一步有多少个人审美/价值判断；
- blast-radius｜做错会污染多少后续内容。

再映射成：

- AUTO｜直接自动做；
- CHECKPOINT｜可以做，但必须留恢复点；
- USER_REVIEW｜必须交给你判断；
- BLOCK｜条件没齐就不许继续。

这不是“动态自主权”思想的原创。

它真正可能成为新增点，只有一种情况：

> **证明这套四因子规则在真实创意生产中，比“每步都问人”或“固定全自动”更少打扰人，同时又更少发生不可逆误推进。**

没验证之前：

**它是 USER_TRANSLATION / METHOD CANDIDATE，不是社会贡献。**

# 分中心 E｜674-118 个人画风 → 项目级层级视觉规范

## 一句话教学

> **我脑子里知道“这像不像我的画风”，怎么把这种隐性的判断变成 AI 能重复执行的规则？**

这里很适合本科论文。

研究链可以很小：

```
个人创作样本
→ 提取稳定视觉规律
→ 写成项目级层级规范
→ AIGC 执行
→ 和等量平铺 Prompt 对照
→ 看跨角色 / 跨场景一致性
```

## 社会已有知识

社会已经大量研究：
- identity consistency；
- style consistency；
- instruction fidelity；
- preservation；
- controllable generation。

所以不能写：
> “我发现 AI 会画风漂移。”

这不是新发现。

## 74 的潜在推进

更具体的问题是：

> **一个原创作者的“隐性风格判断”，能否被编译成可执行、可复用、项目级的视觉规范？**

而且不是一句 style prompt，而是有层级：

- 项目级；
- 角色级；
- 场景级；
- CORE / RANGE / BAN；
- LOCK / FLEX；
- 跨角色共享规则；
- 跨场景共享规则。

这个方向的优点是：

1. 现成素材多；
2. 能做 A/B 对照；
3. 本科 5000 字能收得住；
4. 与《黎黎隆》直接绑定；
5. 可以继续连接 120。

**当前评级：非常适合继续作为论文候选，但题目仍未冻结。**

# 分中心 F｜674-119 创作意图关系化表示｜十元 × 动态链

## 一句话教学

普通 Prompt 往往把意图写成一堆词：

> 压抑、温暖、英雄、克制、监狱、回忆……

但创作者真正想的常常不是“有哪些词”，而是：

> **谁压谁？什么先发生？什么东西在增强？什么东西被迫转向？哪个关系最后要保留下来？**

119 想研究的是：

> **能不能把创作意图从“词袋”升级成“关系结构 + 状态变化”。**

## 十元在这里是什么角色

十元不是拿来证明自己正确的答案机器。

更合理的位置是：

> **一种候选的创作意图关系语法。**

它尝试记录：
- 主/次；
- 生 / 克 / 补；
- 强度；
- 起点 → 变化 → 终点；
- 动态链；
- 哪些关系应该保持；
- 哪些关系应该发生转向。

## 怎么连接《方志敏》

《方志敏》很适合当“已经实际发生过的创作决策案例”。

你不是随机生成镜头，而是在用关系结构决定：
- 监狱段应该怎样压住人物；
- 日常温度什么时候出现；
- 战友情怎样承担关系变化；
- 《清贫》插叙为什么在这里出现；
- 最后整体情绪/价值怎么收束。

因此可以研究两个层级：

### 层级 1｜指导创作
```
十元/动态链
→ 先规定本段关系结构
→ 再设计镜头/人物/场景
→ 看是否能减少方向漂移
```

### 层级 2｜预测选择
```
先记录十元意图
→ 隐藏最终选择
→ AI/评价系统判断候选方案是否符合意图
→ 预测 ACCEPT / REWORK / REJECT
→ 最后揭盲
```

如果第二层能成立，就和 122 直接接上了。

## 最大风险

最危险的是：

```
作品已经做完
→ 再用十元解释
→ “你看，非常合理”
```

这只能证明它**会解释**，不能证明它**会指导/预测**。

所以真正有研究价值的证据必须来自：
- 事前规则；
- 后续选择预测；
- 或有无十元指导的对照。

**当前评级：原创潜力高 / 很适合保留 / 需要预测性验证。**
