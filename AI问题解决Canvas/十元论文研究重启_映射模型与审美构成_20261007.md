# 1｜十元首先是映射模型

面对任意对象、概念、人物、发型、音乐、行为、场景、故事片段等：

```
对象
↓
对十个十元位置分别做 1–10 映射评分
↓
得到十项强度分布
↓
最高项 = 当前主映射
↓
必要时保留次高项 / 主次结构
```

示意：

```
X   3
Z   7
N   4
ZN  5
NZ  2
XN  6
NX  3
ZX  9   ← 最高
XZ  4
X并Z 2
```

则当前对象主映射为 ZX。

这里的核心不是先画关系图，而是：

> **把不同领域中的对象映射进同一个十元结构空间。**

# 2｜三元的位置

三元 x / n / z 是底层观察与质地框架，但现行运行时不机械推出十元。

当前口径：

```
对象
→ 独立十元映射
↔ 三元独立判断 / 比例质地复核
```

理论生成史与现行运行时分开。

# 3｜映射完成以后，关系才成立

只有对象 A、对象 B 都完成十元映射以后，才进入：

- 五行 / 十元位置关系；
- 生 / 克 / 补；
- 主 / 次；
- 作用方向；
- 体量 / 显影 / 作用量；
- 动态链。

因此：

> **关系不是十元之前的输入，而是十元映射完成后的结构结果。**

# 4｜十元的第二层功能：跨领域审美统一

十元的价值不只在“分类”。

如果不同领域对象被映射成同一型：

```
某型人物
+ 某型发型
+ 某型服装
+ 某型音乐
+ 某型构图
```

它们可能形成一种：

> **跨领域同型统一感。**

也就是：
不同媒介、不同对象虽然物质形态不同，但因为映射到同一结构位置，组合后产生统一的审美气质。

这是需要后续验证的核心现象之一。

# 5｜第三层功能：关系构成的审美

不仅“同型 + 同型”能产生统一感。

不同十元映射之间按照五行 / 生克补 / 对立统一等关系组合，也可能产生审美效果。

例如结构可以是：

```
A型人物
→ 以A型行为为主
→ 被B型对象克制
→ 另一个领域再出现与A/B同构的关系
```

于是人物、行为、音乐、发型、色彩、镜头等不同领域之间，不只是“都同型”，还可以：

> **重复同一种关系结构。**

这种跨领域的关系同构本身可能产生魅力。

# 6｜第四层功能：动态链的节奏审美

故事不是静态关系。

关系序列本身也可能形成审美：

```
克
→ 生
→ 大克
→ 补
→ 结束
```

或其他关系节奏。

这里的魅力可能来自：

- 关系类型顺序；
- 作用体量变化；
- 强弱起伏；
- 主次交换；
- 关系跨阶段转型；
- 最终收束方式。

因此动态链不是只解释剧情：

> **动态链本身也是一种审美构成。**

# 7｜当前真正的研究对象

新的研究中心不是：

> “十元能否成为一种创作意图图？”

而是：

> **十元能否作为跨领域结构映射模型，把不同对象映射到同一个十元空间，并通过同型统一、关系同构和动态链节奏，解释或生成稳定可识别的审美构成？**

# 8｜当前四个核心问题

## Q1｜映射
同一个对象，十项 1–10 映射是否能稳定得到主型 / 次型？

## Q2｜同型统一
人物、发型、音乐、服装、构图等跨领域对象若映射到同一型，组合后是否更容易产生统一感？

## Q3｜关系审美
不同领域复用同一种十元 / 五行关系结构，是否会产生可识别的关系性审美？

## Q4｜动态链审美
克→生→大克→补等关系序列及体量变化，是否形成稳定可辨的叙事魅力 / 节奏感？

# 9｜此前研究处理

此前“创作意图结构化 R1–R5”：

- 不再作为当前十元论文的理论主线；
- 不再据其建立 B0–B4 实验；
- 不再以 Generic Intent Graph 作为十元的主要比较对象；
- 仅保留历史记录，不继承结论。

下一轮社会研究必须从这四个真实功能出发重新找：

```

跨领域同型统一
跨领域关系同构
动态关系序列 / 审美节奏
```

而不是先找“创作意图图”再把十元塞进去。
