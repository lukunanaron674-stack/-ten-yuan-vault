# 0｜R1 最终结论

R1 最重要的结论不是“**五行就是五种元素**”，也不是简单反过来说“**五行绝不是物质，只是过程**”。

更准确的说法是：

> **“五行”在先秦到汉代不是一个从头到尾含义固定的单一概念，而是多条早期传统逐渐汇合、重释、系统化的结果。成熟的宇宙论五行更强调动态、相互作用、变化和类联，因此用 Five Phases / Five Processes 往往比 Five Elements 更能避免西方‘固定构成元素’的误读；但早期材料中确实存在‘五材 / 自然资源 / 可施用材质’这一条传统，不能简单抹掉。**

因此，R1 对后续研究最重要的限制是：

1. 不能把后世成熟的“木火土金水 + 生克循环 + 方位季节颜色”整套系统倒灌到最早材料；
2. 不能把“五行”在所有先秦文本中的用法都强行理解成木火土金水；
3. 不能把 Five Elements / Five Phases / Five Processes 任何一个英译当成绝对唯一答案；
4. 必须按**文本时代 + 语境 + “行”字在该文本中的功能**判断。

---

# 1｜“五行”不是一个从一开始就固定的词义

## 1.1 学界最稳的共识：语义高度依语境变化

Internet Encyclopedia of Philosophy 指出，先秦与汉代文献中的“五行”有多种用法，可能对应：
- five elements
- five phases
- five movements
- five actions / conducts

因此不能把“五行”机械地只翻译成一个英文词。

IEP 同时强调：在成熟宇宙论语境里，xing 更接近 movement / alteration / changing states / metamorphosis；五类被理解为相互作用的动态力量或模式，而不是像古希腊“四元素”那样的固定物质砖块。

### R1 判断

**结论等级：STRONG**

> “五行”必须按语境解释；成熟宇宙论语境下，Five Phases / Five Processes 通常比 Five Elements 更少误导。

但这不等于：
> “五行历史上从来没有物质 / 五材含义。”

---

# 2｜早于成熟五行宇宙论的“五”结构已经存在，但不能倒推成熟体系

IEP 对商代甲骨材料的总结指出：
- 商代已经重视“五”这个结构；
- 常见“四方 + 中央”的五分格局；
- 已经出现方位、颜色、祭祀、神灵等初步对应；
- **但还没有证据表明当时已经存在成熟的五行宇宙论，也没有证据表明木火土金水五相互作用体系已经成立。**

### R1 判断

**结论等级：STRONG**

> “五”作为组织世界的数字模式很早，但“五的模式” ≠ “成熟五行理论”。

后续任何“上古已有完整五行”的说法都必须单独举证，不能从“尚五”直接推出。

---

# 3｜五材 / 六府：早期五行有一条非常强的“生活资源 / 材用”线

《左传》材料中可以看到：

- “天生五材，民并用之”中的原词是**五材**；
- 另有水、火、金、木、土、谷合称“六府 / 六种自然资源”的传统。

这些材料更像：
> 人的生活离不开这些基本资源 / 材用。

而不是一开始就在讨论一个抽象宇宙动力模型。

清华大学哲学系丁四新的研究也将《洪范》相关五行解释为水、火、木、金、土五种可施用、可行用的基本材质，即“五材”，强调其生活世界 / 材用基础。

### R1 判断

**结论等级：MEDIUM–STRONG**

> 五行形成史中确实存在“材 / 资源 / 实用”来源，不能为了强调过程性而删掉这条历史线。

---

# 4｜《洪范》是关键文本，但不能把它当成一块没有层次的铁板

现传《尚书·洪范》写：

- 一曰水
- 二曰火
- 三曰木
- 四曰金
- 五曰土

并进一步描述：

- 水：润下
- 火：炎上
- 木：曲直
- 金：从革
- 土：稼穑

这段非常关键。

## 4.1 为什么“润下 / 炎上 / 曲直 / 从革 / 稼穑”重要

G. E. R. Lloyd 的比较科学史研究指出：

这些定义关注的不是“这些东西由什么物质构成”，而是：

> **它们怎样行动、怎样变化、呈现什么过程。**

因此成熟五行至少具有非常明显的**功能 / 过程描述**倾向。

### R1 判断

这里可以暂时写成：

> 五类名称虽然是“水火木金土”，但定义它们时，文本已经明显使用了“典型行为 / 功能 / 变化方式”。

这对以后研究“类别是不是按行为反应而非实体本质划分”非常重要。

---

# 5｜但《洪范》的年代和内部层次存在真实学术争议

不能直接写：

> “周初古人已经完整提出今天的五行理论。”

因为《洪范》的成书时代长期存在争论：

- 传统说法：周初；
- 现代学术曾有战国晚期、战国早/中期等判断；
- 也有学者根据出土文献重新支持较早层次；
- 还有“早期主体 + 后世增补 / 整理”的复合文本解释。

刘起釪就提出：《洪范》可能有很早主体，但其影响后世的五行内容可能在春秋战国逐渐加入。

### R1 规则

后续写作必须使用：

> **“《洪范》现传文本 / 《洪范》相关层次显示……”**

而不要未经说明就写：

> “西周初年已经明确……”

---

# 6｜2023 王博：五行可能不是“单线起源”，而是多重起源

王博《〈尚书·洪范〉的复合结构与五行的多重起源》（《文史哲》2023年第2期）对 R1 特别重要。

论文提出：

《洪范》本身可能叠合了不同“五行”传统：

### 层 1｜地之五行
与水道 / 行的本义相关。

### 层 2｜人之五行
五种行为 / 德行，与“行”为行为、德行相关。

### 层 3｜水、火、木、金、土
成为汉以后最核心的五行含义。

作者因此反对：

> 所有五行都从同一个单一原点线性发展出来。

### R1 判断

**这是本轮非常重要的工作假设：MULTIPLE-ORIGIN HYPOTHESIS。**

后面 R2–R4 都不能预设它一定正确，但它提醒我们：

> “五行”可能是后来把多个原本不同的“五类结构”整合进同一个话语系统。

---

# 7｜更强证据：郭店《五行》里的“五行”根本不是木火土金水

郭店楚简《五行》以及马王堆相关文本中的“五行”指：

- 仁
- 义
- 礼
- 智
- 圣

五种德行。

陈来关于郭店《五行》的研究明确说明，这里的“行”就是德行 / conduct。

Franklin Perkins 对《五行》篇的研究也将其处理为 Five Conducts，而不是木火土金水五种 cosmic phases。

### 这说明什么

至少说明：

> **先秦“五行”这个词本身不能自动等号为木火土金水。**

“行”在不同传统里可以真的就是：

> 行为 / 德行 / conduct。

### R1 判断

**结论等级：STRONG**

这是以后研究十元时非常重要的防误读规则。

# 8｜Five Elements / Five Phases / Five Processes：到底哪个最好

## Five Elements

### 优点
- 传统英文译法；
- 读者最熟悉；
- 某些早期五材 / 材料语境并非完全错误。

### 缺点
容易让现代读者误认为：

> 五行 = 五种固定基本物质，类似古希腊四元素。

这对成熟五行宇宙论很容易造成误导。

---

## Five Phases

### 优点
目前学术界非常常见。
突出：
- 阶段
- 变化
- 循环
- 相互转化

### 缺点
“phase”可能让人误以为：

> 五者只是一个过程中的先后阶段。

但有些五行用法并不只是时间阶段。

---

## Five Processes

### 优点
A. C. Graham 等学者特别用它处理先汉五行。
强调：
- 行动
- 过程
- 互动
- 动态功能

### 缺点
也可能过度强调动态过程，而弱化早期五材 / 分类 / 资源传统。

---

# R1 暂定翻译政策

以后五行×十元研究统一采用：

### 中文正文
优先直接写：
> **五行**

### 第一次出现时
写：
> 五行（wuxing，常译 Five Phases / Five Processes；传统亦译 Five Elements）

### 具体文本
按文本语境进一步标：
- 五材 / material-resource reading
- 五行 / dynamic phase-process reading
- 五德行 / conduct reading

不提前强制统一。

# 9｜“五行不是五种物质”这句话需要降级

原来很容易得出一句：

> 五行不是五种物质，而是五种过程。

R1 后必须修正。

## 更严谨版本

> **成熟的五行宇宙论不宜被理解为五种固定、不可变化的物质元素；但五行形成史中确实存在五材、自然资源和材用传统。五行后来逐步获得功能、过程、类联与宇宙论意义。**

这句话目前证据明显更稳。

---

# 10｜五行是不是一开始就是完整理论？

R1 答案：

> **不是。**

证据链：

1. 商代已有“五”的组织结构，但没有成熟木火土金水互动体系证据；
2. 《左传》等早期传统中五材、六府等资源结构仍存在；
3. 《洪范》文本自身年代 / 层次有争议；
4. 先秦“五行”还有德行意义；
5. 战国以后才出现越来越强的五类宇宙论、相关体系；
6. 邹衍通常被视为重要系统化人物；
7. 到汉代，《淮南子》等材料中五行的生成/制约、类联体系才明显趋于成熟和标准化。

G. E. R. Lloyd 也明确指出，五行学说最终形态经历了数百年的发展。

### R1 冻结结论

> **五行不是一次性发明出来的完整理论，而是一个长期形成、不断整合不同材料与用途的历史系统。**

# 11｜R1 概念模型 v1

当前暂时把五行形成前史拆成四条线，不表示四条已经完全证明独立起源：

## L1｜NUMERIC / SPATIAL FIVE
“五”的组织结构：
四方 + 中央、五方等。

## L2｜MATERIAL / RESOURCE
五材、六府：
水火木金土等作为生活资源 / 材用。

## L3｜CONDUCT / ACTION
“行”作为行为 / 德行：
郭店《五行》等。

## L4｜PHASE / PROCESS / CORRELATION
木火土金水逐渐成为：
功能模式、变化过程、相关分类和宇宙论结构。

### 关键研究问题

R2–R3 要检查：

> L1–L4 是真正不同来源后来汇合，还是同一传统不同阶段 / 用法？

此问题暂时 OPEN。

# 13｜R1 对以后十元研究产生的约束（只登记，不展开）

本轮不分析十元，但已经得到几条以后 R7 必须遵守的限制：

1. 不能说“十元继承了传统五行”，除非明确是哪一时期、哪一种五行；
2. 不能把后世生克体系倒推到所有早期“五行”；
3. 必须区分：
   - 材用五行
   - 德行五行
   - 宇宙论五行
   - 相关分类五行
4. 如果十元真正继承的是“动态关系/过程”，它的直接理论祖先可能只是五行历史中的某个阶段，而不是“五行全部”；
5. R7 必须采用来源等级，而不是一句“来自五行”。
