# 十元审美构成研究｜R3 动态链魅力实验协议 v1.0

> 状态：**R3 PROTOCOL DONE / EMPIRICAL PENDING**
> 日期：2026-10-07
> 核心问题：像“克 → 生 → 大克 → 补”这样的关系序列，是否不仅结构成立，而且会稳定地产生可识别的张力、魅力、收束与继续观看欲？
> 本轮冻结实验协议，不宣称该链已被证明最好看。

# 0｜先纠正：不是四个标签排列
根据现有 Dynamic Chain Evaluator 与音乐消融研究，真正有效的链必须满足：前一阶段改变具体变量 → 留下 residue → 生成下一阶段此前不存在的 next_affordance → 下一关系才真正启动。
所以 R3 测的是：relation sequence + variable trajectory + intensity contour + closure position。

# 1｜首个目标链：K → S → K+ → B
首轮合法候选：
- K1：外部 XN 克 ZX｜mid
- S1：XZ 生 ZX｜mid
- K1+：同一 XN 克 ZX 再度增强｜high
- B1：NX 补 ZX｜mid

简称：**K-S-K+-B｜压 → 生 → 重压 → 补**。
“大克”优先表示同一合法克边的作用范围/强度扩大，不等于剧情更惨。必须说明 XN 又限制了 ZX 哪些合法状态。
强度第一批只用 low / mid / high，不假装 1–10 已有统一量尺。

# 2｜状态空间示意
固定核心变量：available_decision_paths / 可执行决定路径。
- T0：ZX 有4条可执行路径。
- T1 K1：4→2。原目标仍在，两条直接路径被锁；next_affordance=必须寻找新决定接口。
- T2 S1：2→3。XZ触发临时决定空位；原XN约束仍在；next_affordance=ZX可短暂重新行动。
- T3 K1+：3→1。同一XN适用范围扩展到临时接口；T2成果部分保留但持续执行空间急缩；next_affordance=正面夺回权限不足，必须非正面补位。
- T4 B1：1→2。NX补入间接路径，但不恢复T0。XN仍存在，损失不被抹除。

候选审美机制：**补后的余味可能来自“解决了，但没有恢复原状”。**

# 4｜不能拿目标链和因果乱序链比较
如果目标链结构完整，而控制链故意因果不通，那么只能证明“连贯比不连贯好”。
因此核心对照都必须先过 Dynamic Chain Evaluator 的结构门。

# 5｜第一批四个合法顺序候选
使用同一组关系原料 K / S / K+ / B，固定主体、目标、外部系统、端点和问题域，只改顺序与补位时点。

## A｜K → S → K+ → B
压 → 扬 → 再压 → 补收束。用户原始母型候选。

## B｜K → K+ → S → B
连续加压 → 生 → 补。可能前半更窒息，后半连续恢复。

## C｜S → K → K+ → B
先给能力 → 压 → 重压 → 补。可能更像坠落与回升。

## D｜K → S → B → K+
压 → 生 → 补 → 再压。可能 closure 低但 want-to-continue 高。

注意：A–D 每条都必须重新写 mechanism / delta / residue / next_affordance，不能只拖动标签。

# 6｜两个消融
## E｜No Complement：K → S → K+
测最后补是否贡献 Closure / Completeness。
## F｜No Re-Pressure：K → S → B
测第二次强克是否贡献 Tension / Charm。

# 7｜两层实验
## Phase A｜Abstract Dynamic Test
同样几何对象、布局、视觉风格、总时长，不出现角色名、剧情文本和生克补字样，只改变状态空间收缩/扩展/补位顺序。
测：Tension / Charm / Closure / Interest / Want-to-Continue / Beauty。
诊断：Transition Coherence / Structural Clarity。

## Phase B｜Matched Story Animatic
固定同一角色、目标、地点、对手系统、视觉风格和关系原料，只改事件顺序及相应因果连接。
优先低成本 animatic，不先做高完成度动画。

# 8｜审美指标
- Tension
- Charm

- Want-to-Continue
- Beauty
诊断项：Transition Coherence、Structural Clarity。诊断项不算美感本身。

# 9｜强度第一批不用1–10
目标链记作：K_mid → S_mid → K_high → B_mid。
1–10 连续量尺留给 R4。R3 必须用 changed_variable 说明强弱，不用数字替代机制。

# 10｜结构门
每条链进入审美盲审前必须过：same_object_layer、same_core_variable、mechanism、changed_variable before/after、residue、next_affordance、deletion test、reverse test、closure explanation。
不通过则标 STRUCTURAL_FAIL，不进入审美主比较。

# 11｜三个机制假设（不是结论）
1. Contrast/Reversal：压→扬→再压形成两次方向反转，可能提高 Interest/Tension。
2. Earned Relief：最终补填的是重压后真实形成的缺口，可能提高 Closure/Charm。
3. Residue-Preserving Closure：补没有抹去前面的损失与限制，可能产生“有代价的收束”。

# 12｜预注册假设
- H1：A 的 Tension > No-RePressure。
- H2：A 的 Closure > D。
- H3：A 的 Charm 可能 > B/C，但不预设必然。
- H4：No-Complement 的 Closure < A。
- H5：Want-to-Continue 与 Closure 不要求同方向。

# 13｜必须允许的反结果
- B 比 A 更有魅力。
- D 收束低但更想追下去。
- No-RePressure 与 A 接近，说明“大克”未必必要。
- No-Complement 仍有高收束，说明结尾收束可能来自别的形式因素。
- 抽象层无差异、故事层有差异：可能是语义/人物投资在起作用。
- 抽象层有差异、故事层消失：可能是叙事语义覆盖结构节奏。

# 14｜不做单一审美总分
最终矩阵为 Pattern × Metric，分别记录 Tension / Charm / Closure / Interest / W / Beauty / TC / SC。
建议首张二维图：X=Closure，Y=Tension，再看 Charm 与 Want-to-Continue 分布。

# 15｜与旧研究分工
Dynamic Chain Evaluator 回答：链条是不是高质量结构链。
R3 审美实验回答：不同高质量链序会让观众产生什么不同感受。
旧音乐高分只能找候选、反例，不能证明某链审美优越。
