>
> 日期：2026-10-07
>
> 目标：用最小、可反驳的实验检验“同一五轴同端跨领域对齐是否提高统一/匹配”，并初步观察“同轴反端”是否产生更高张力。

# 0｜为什么 R2 首轮选木轴 ZX ↔ NX

首轮优先选择：

> **木轴｜ZX ↔ NX｜最终方向与作用权来源**

不是因为木轴更重要，而是因为视觉/发型库当前：

- ZX 几何本征：confirmed
- NX 几何本征：confirmed
- 两端都有现成发型研究样本
- 相反关系清楚：主动推出/占据方向 ↔ 横向散开/让出中心
- 不需要使用仍 pending 的 XN / X并Z 几何本征

因此它适合作为**方法校准轴**。

首轮跑通后，不能直接外推五轴全部成立。

---

# 1｜不能只做“一个 ZX 人 + 三种发型”

错误设计：

```
ZX人物 + ZX发型
ZX人物 + NX发型
ZX人物 + 随机发型
```

如果 ZX 发型本身普遍更漂亮，那么即使十元关系完全没作用，也可能让 SAME 条件最高。

所以 R2 冻结：

> **必须两端镜像测试。**

---

# 2｜核心设计：2 × 3 交叉

## BASE POLE
- Base-ZX
- Base-NX

## HAIR CONDITION
- SAME
- OPPOSITE
- RANDOM

得到六格：

| 主体 | SAME | OPPOSITE | RANDOM |
|---|---|---|---|
| Base-ZX | ZX发型 | NX发型 | 非木轴匹配控制 |
| Base-NX | NX发型 | ZX发型 | 非木轴匹配控制 |

### 真正支持“同型统一”的模式

不是：
> ZX发型总是高分。

而是：

> ZX主体更偏好 ZX发型；  
> NX主体更偏好 NX发型。

即：
> **匹配关系发生交互，而不是单一发型主效应。**

---

# 3｜第一关键统计思想：看 Match Interaction

先定义：

```
same_mean =
  mean(BaseZX+HairZX, BaseNX+HairNX)

opposite_mean =
  mean(BaseZX+HairNX, BaseNX+HairZX)

random_mean =
  mean(BaseZX+Random, BaseNX+Random)
```

核心候选效应：

## E1｜Same-Match Effect
```
same_mean - opposite_mean
```

主要看：
- Unity
- Fit

## E2｜Structure-Specificity
```
same_mean - random_mean
```

排除只是任意搭配都差不多。

## E3｜Opposition-Tension Effect
```
opposite_Tension - same_Tension
```

检验“同轴反端”是否真的更有拉扯。

### 最重要

还必须分别看：

```
ZX-side effect = ZXbase_ZXhair - ZXbase_NXhair
NX-side effect = NXbase_NXhair - NXbase_ZXhair
```

若只一边成立：
> 只能记“单端效应”，不能宣布“同型统一规律”。

---

# 4｜刺激材料必须先过资格门，不可由作者直接指定

实验分两段。

# STAGE 0｜Stimulus Qualification｜刺激资格预检

正式审美实验之前，分别验证：

## 4.1 Base 主体
候选人物必须在**不看发型条件**时，能被独立结构审核稳定判为：
- Base-ZX
或
- Base-NX

要求：
- 不能只靠角色文字设定；
- 静态实验就必须有可见结构证据；
- 若“人物十元”只存在于剧情行为、静态头像看不出，则该人物不能用于本轮静态实验。

### 失败
若 Base 视觉自身五轴端无法稳定辨认：
> 换主体，不硬跑。

---

## 4.2 Hair 发型
直接复用现有刘海98种 / 发型库。

木轴现行视觉正本：

### ZX
- 菱形方向体
- 中部展开
- 主动推出
- 强斜扫 / 外翻 / 上挑 / 后冲
- 不能只因“翘起”就判 ZX

### NX
- 方形 / 横向散开
- 多束、碎束块面
- 让出中心
- 横向铺展
- 不能只因“轻薄”就判 NX

每个条件至少选：
> **2 个不同发型 exemplar**

防止实验结果只是某一款发型特例。

---

# 5｜RANDOM 不能真随机乱选

RANDOM 是**结构错配控制**，不是丑发型。

要求：

- 非木轴目标端；
- 生产质量相当；
- 复杂度接近；
- 遮挡面积接近；
- 长度/信息量尽量匹配；
- 不能明显比 ZX/NX 更丑或更夸张；
- 表面风格仍然合理。

优先从：
- 火轴 ZN/X
- 水轴 XZ/NZ

挑已 confirmed 的视觉本征。

暂不优先：
- XN
- X并Z

因为几何本征仍 pending。

# 7｜图像制作硬控变量

同一 Base 内只修改：

> **前额/发型结构**

必须冻结：

- 脸
- 五官
- 表情
- 头部角度
- 身体姿态
- 服装
- 配色
- 光影
- 背景
- 构图
- 画风
- 清晰度
- 发色
- 总发量尽量相当

如果发型改变导致：
- 脸型看起来明显不同
- 年龄变化
- 性别气质强变化
- 遮眼程度剧变

必须记录为 confound，必要时淘汰。

因为发型库已经有：

- 98项研究

所以：

> 发型 = 最低成本方法校准

# 9｜观众任务

每位观察者看到匿名 A/B/C…刺激。

## Step 1｜自由描述
“第一眼你觉得这个角色整体是什么感觉？哪一处最影响你？”

## Step 2｜评分
全部：
- Unity
- Fit
- Charm
- Interest
- Preference
- Beauty
- Tension

本轮 Completeness 暂不作为主指标，因为还没进入“补”。

## Step 3｜选择
同一个 Base 的三个条件看完后：

> “如果只能保留一个版本，你会选哪一个？”

记录：
`forced_choice`

但不能用 forced choice 代替所有量表。

# 10｜展示方式：单图评分优先，成组选择后置

如果直接把三张并排：

> 观众容易做相对比较，而不是独立感受。

所以顺序：

## Pass 1｜Single Exposure
每张单独显示，顺序随机。
完成自由描述 + 评分。

## Pass 2｜Within-base Comparison
同一主体的 SAME / OPPOSITE / RANDOM 一起出现，但位置随机。
只做：
- forced choice
- “哪两个最像同一套设计？”

这样同时保留：
- 独立评分
- 直接审美选择

# 11｜评价者

Pilot 阶段建议：

> **12–20 名真实观察者**

定位：
> exploratory pilot，不做社会泛化。

尽量混合：
- 有绘画/设计经验
- 无专业美术背景

记录：
`reviewer_type = art_trained | general`

先不把群体差异当主结论，只检查是否出现明显反向。

没有真实观众：
> 状态必须保持 EMPIRICAL_PENDING。

# 12｜R2 预注册假设

## H1｜同型统一
SAME 的 Unity、Fit > OPPOSITE、RANDOM。

## H2｜关系对折
OPPOSITE 的 Tension > SAME。

## H3｜统一不等于魅力
SAME 即使 Unity 更高，也不要求 Charm / Interest / Preference 必然最高。

这一条非常重要：
> 如果 OPPOSITE 更有 Charm，可能正好支持用户说的“对折更有意思”。

## H4｜结构而非单造型
SAME 优势必须至少在 ZX、NX 两侧方向一致，才开始支持匹配效应。

---

# 13｜可能结果如何解释

## RESULT-A
SAME Unity/Fit 高；OPPOSITE Tension/Charm 高。

这是最有意思的结果：
> **同型负责统一，对折负责张力/魅力。**

进入生/克/补扩展。

---

## RESULT-B
SAME 各项都最高。

说明：
> 同型统一可能同时影响总体偏好。

但必须排除单一发型主效应。

---

## RESULT-C
OPPOSITE 在两个 Base 上都更受欢迎。

说明：
> 审美可能更偏“关系对折”而非纯统一。

不能把它判为理论失败，反而是新规律候选。

---

## RESULT-D
某个 Hair ZX 无论配谁都最高。

说明：
> 这是发型主效应 / attractiveness confound。

**不能算同型效应。**

---

## RESULT-E
RANDOM 和 SAME 无区别。

优先检查：
1. Base轴没视觉显影；
2. 发型轴编码不够强；
3. 观众看不到理论变量；
4. 同型关系本身对审美没有效果。

按这个顺序查，不立即改理论。

# 16｜R2 与现有“刘海98种”的连接

现有库直接作为：

> **刺激候选池，不作为实验结果。**

尤其注意：
- 旧纯度/本征准度属于理论侧开发数据；
- 观众不能看到；
- 不用旧分数筛出“最美”样本；
- 只用其结构证据挑“足够像 ZX / NX”的候选。

也就是说：

> 刘海98种回答“我们认为它是什么结构”；  
> R2观众实验回答“这种结构配起来让人有什么感觉”。

不能混。
