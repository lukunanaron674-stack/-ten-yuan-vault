
# 十元审美构成研究｜总纲 v0.1

> 状态：RESEARCH OPEN
>
> 日期：2026-10-07
>
> 核心纪律：结构成立 ≠ 审美成立；理论解释 ≠ 观众真实感受。

## 0｜四个核心假设

### A1｜跨领域同型统一
同一五轴/十元结构同时出现在人物、发型、服装、音乐、动作、镜头等多个领域时，是否提升统一感、匹配感与整体性？

### A2｜关系对折构成
主结构保持不变时，加入生/克/补等次级关系，是否比“全同型”或“随机不匹配”产生更高的趣味、张力、魅力？

### A3｜动态链魅力
关系顺序本身是否产生审美差异？
例如：克 → 生 → 大克 → 补，是否比随机顺序、全生、全克等更具张力与收束感？

### A4｜十元强度谱
十个十元分别映射 1–10。
最高值作为主导十元，但完整谱形是否比 Top1 更能预测观众感受与跨领域匹配？

## 1｜不要把“美”混成一个总分

至少拆成：
- unity｜统一感
- fit｜匹配感
- coherence｜整体一致性
- interest｜有趣
- tension｜张力
- charm｜魅力
- completeness｜完整感
- memorability｜记忆点
- preference｜喜欢程度
- beauty｜美感

全同型可能很统一，但不一定最有趣；强克可能更有张力，但未必更美；补可能提高完整感，但未必提高刺激度。

## 2｜A1 同型统一实验

固定人物，只改变发型、服装、配乐或镜头结构。

条件：
A｜同轴同端
B｜同轴反端
C｜生关系
D｜克关系
E｜补张关系
F｜随机近邻错配

观众不知道十元标签，只评价 unity / fit / coherence / charm / preference。

核心不是问“ZX好不好看”，而是问：
结构一致性提高时，unity / fit 是否稳定上升？

## 3｜A2 关系对折实验

比较：
- BASE｜主结构单独存在
- SAME｜跨领域重复强化
- GENERATE｜加入生
- OVERCOME｜加入克
- COMPLEMENT｜加入补
- RANDOM｜不构成合法关系的错配

可能结果：
- SAME 最高 unity
- OVERCOME 最高 tension
- COMPLEMENT 最高 completeness
- GENERATE 最高 flow / naturalness
- 某种 SAME + OVERCOME 组合最高 charm

## 4｜A3 动态链魅力

首批只测试少量母型：
1. 克 → 生 → 大克 → 补
2. 生 → 克 → 再生 → 补
3. 双克 → 双生 → 三克 → 选择 → 互补
4. 克/生交替拉扯
5. 并行双线 → 最终汇合
6. 全同关系控制组

固定角色、世界、事件材料，只换关系顺序与强弱曲线。

盲审：
- tension
- charm
- 转折自然度
- 结尾满足感
- 想继续看程度

已有“动态链质量评估器”只检查结构生产力，不等于审美结果，必须分表记录。

## 5｜A4 十元强度谱

向量：
V = [X, Z, N, ZN, NZ, XN, NX, ZX, XZ, X并Z]

每项 1–10。

两层读取：
- 判定层：Top1 = 主导映射
- 构成层：完整向量 = 十元强度谱

进一步记录：
- Top1 / Top2 / Top3
- Top1-Top2 gap
- 同轴两端差值
- 五轴张力
- 谱的集中/分散程度
- 随阶段的谱形变化

比较三种预测：
1. Top1
2. Top1 + Top2/Top3
3. Full Profile

如果 Full Profile 明显更好，说明谱形本身有信息。

## 8｜推荐 5 轮研究

### R1｜审美变量与实验语法冻结
冻结：
- unity / fit / interest / tension / charm / completeness / preference
- SAME / 生 / 克 / 补 / random
- 五轴作为跨域单位
- 盲审格式
- 正负控制

DONE：好看不再混成一个分。

### R2｜同型统一 × 关系对折
做最低成本 A/B。
得到第一张“关系类型 → 审美感受矩阵”。

### R3｜动态链魅力
固定内容，只换关系序列。
验证“克→生→大克→补”等母型。
真实观众盲审，不由链作者自评分。

### R4｜十元强度谱
比较 Top1 vs Top3 vs Full Profile。
判断“最高值就是它”是否足够。

### R5｜跨领域总验证
至少：
- 人物造型 × 音乐
- 角色行为 × 镜头/故事

要求：
- 未参与理论建立的评价者
- 隐藏十元标签
- holdout
- 表面像/结构不同负控
- 开发集与最终验证集分开

DONE 后才能讨论跨领域审美预测价值。

## 9｜当前优先级

P0：先做 R1。
如果不先区分统一、魅力、张力、完整等变量，后面所有“好看”都会重新混成主观总分。

P1：A1/A2 静态或短片小实验。
P2：A3 动态链。
P3：A4 强度谱，必须先解决 1–10 的评分来源与标定。

## 10｜最终研究逻辑

五轴跨领域结构保持
→ 先证明“是同一个结构”
→ SAME / 生 / 克 / 补 / 对折 / 动态链
→ 真实观众盲审
→ 十元强度谱 Top1 vs Top3 vs Full
→ 跨领域 holdout
→ 判断是否存在可预测的审美构成规律

硬纪律：
结构映射正确，不代表一定美。
观众觉得美，也不能倒推结构映射一定正确。
两条证据链必须独立。
