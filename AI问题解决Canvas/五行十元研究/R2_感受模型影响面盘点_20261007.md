## 2｜四类迁移结论

### A｜KEEP｜保留

这些资产本身仍有价值，只需明确“不是对象本体真值”。

1. **五行历史 / 现代理论研究 R1–R8**
   - 保留历史来源、过程/系统/关系理论比较、批判边界。
   - 从“证明十元本体”改读为“理解十元理论来源与可用方法”。

2. **`01-十元系统/00_十元理论来源链_用户口述冻结_20261007.md`**

   - 其中“十类映射方向 / 跨领域预映射”属于理论发展史，不再等于现行判定内核。

3. **五轴配对拓扑**
   - `ZX↔NX / ZN↔X / N↔X并Z / XN↔Z / XZ↔NZ` 暂保留。
   - 旧结构变量保留为候选诱发机制 / 操作化工具，不是世界本体分类证明。

5. **角色、刘海、服装、版式、音乐、银矿案例的原始素材与观察证据**

## 3｜五维 / 五大主题专项判断

五维不删除。

R2把它拆成两件事：

### 保留
- 因果 / 本体 / 空间 / 时间 / 命运作为叙事问题维度；
- 主题显影、阶段变化、动态链、主次等叙事工具。

### 取消默认本体继承
不再默认：

```text
因果 --is-a狭义→ 木
本体 --is-a狭义→ 火
空间 --is-a狭义→ 土
时间 --is-a狭义→ 金
命运 --is-a狭义→ 水
```

后续若五维与五轴之间确实存在稳定感受关系，应以“叙事结构触发何种感受”重新建立，而不是is-a继承。

## 4｜视觉库专项判断

刘海98、现代服装、字体、版式、海报等不是废数据，反而是新模型的重要实验素材。

旧写法：

```text
某刘海 = ZX
ZX本征准度84/100
归入木父库
```

新迁移方向：

```text
同一刘海 + 固定呈现语境
→ 观察者直接感受
→ ZX 8 / Z 5 / NX 2 / ...
→ 保存十维感受谱
→ 再分析哪些结构特征稳定诱发ZX感受
```

因此视觉库属于：
**素材KEEP + 标签DOWNGRADE + 评分体系REWRITE**。

## 5｜现代理论研究专项判断

以下现代方法仍有价值：

- Semantic Differential：从“对象分类邻居”改成“感受强度测量邻居”；
- Qualitative Coding：继续用于感受描述的编码可靠性；
- Conceptual Spaces：可用于研究十维感受空间，但暂不宣称数学等同；
- Structure Mapping：用于比较不同媒介是否诱发相似关系感；
- AI/Agent：用于把感受目标编译为视觉、音乐、动作和叙事控制规则。

因此现代理论线不是推翻，而是**研究主语迁移**：

> 从“十元如何映射对象”  
> 改成  
> “十元如何描述、比较与生成艺术感受”。
