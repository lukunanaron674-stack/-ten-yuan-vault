# 0｜R2 最终结论

十元跨域映射不能由：

> “A 是 ZX，B 也是 ZX”

这种单标签相同来证明。

真正的结构保持必须发生在一个**关系片段 / relational episode**上：

> 对象与角色位置
> → 三元组成
> → 十元组合位置
> → 生/克/补张关系
> → 方向
> → 时序
> → changed_variable
> → 结果
> → 下一步可发生什么

因此十元最小验证单位不是“一个标签”，而是：

> **一段连接起来的关系结构。**

---

# 1｜为什么单点映射几乎没有证明力

假设：

音乐段落 A → ZX  
角色行为 B → ZX

只能说明：

> 两者被编码到同一个位置。

不能说明：

- 它们为什么是同一个深层结构；
- 它们和周围位置关系是否相同；
- 它们后续变化是否相同；
- 映射是不是研究者看到结果后硬贴出来的。

Gentner 的 Structure-Mapping Theory 明确强调：

> analogy 不是匹配孤立属性，而是匹配相互连接的关系系统；
> connected relational systems 比同数量的孤立相似点更有价值。

因此：

> **单十元同名 = local match**
>
> **不是 structure mapping 的充分条件。**

# 2｜十元最小映射单位：Relational Episode

以后跨域案例最少写成：

```
Episode E = {
  roles,
  initial_state,
  ternary_composition,
  tenyuan_positions,
  relations,
  direction,
  temporal_order,
  changed_variables,
  resulting_state,
  next_affordances
}
```

中文：

## 2.1 Roles｜关系角色
谁是作用端，谁是承受端，谁是中介。

## 2.2 Initial State｜起始状态
映射开始前，各对象处于什么关系位置。

## 2.3 Ternary Composition｜三元组合来源
十元位置是怎样由 X/Z/N 组合关系得到的。

## 2.4 Ten-Yuan Position｜十位映射位置
保留组合 provenance，不能只留最终标签。

## 2.5 Relation Topology｜关系拓扑
生 / 克 / 补张等关系怎样连接。

## 2.6 Direction｜方向
A→B 和 B→A 不同。

## 2.7 Temporal Order｜时序
先发生什么、后发生什么。

## 2.8 Changed Variable｜被改变变量
关系到底改变了什么。

## 2.9 Resulting State｜结果状态
变化以后结构进入什么位置。

## 2.10 Next Affordance｜下一可达关系
当前结果使哪条后续关系成为可能 / 不可能。

# 3｜“名字可以换”到底允许换什么

十元跨域结构映射允许大量表面信息变化。

## ALLOW-1｜对象名字可换
角色A ↔ 音色A' ↔ 空间A''

## ALLOW-2｜题材可换
爱情 / 战争 / 音乐 / 建筑 / 工作流可以不同。

## ALLOW-3｜媒介可换
文本 / 图像 / 动画 / 音乐 / 现实组织可以不同。

## ALLOW-4｜具体动作可换
“推门”与“调制升高”表面动作不同。

## ALLOW-5｜物理材料可换
人物 / 声音 / 色块 / 制度 / 镜头均可成为映射对象。

### 关键

允许换的是：

> **surface vocabulary / surface attributes**

不是深层关系。

# 4｜必须保持什么：R2 七个结构不变量

以后把它们叫：

> **TY-SI｜Ten-Yuan Structural Invariants**

不是把十元拆成七个独立理论，而是为了检验整条映射链时使用的七个观察维度。

---

## SI-1｜Composition Invariant｜组合来源保持

如果源领域某位置由某种三元组合结构得到，

目标领域映射后必须保持相应组合逻辑。

不能：

> 源里靠 ZX 组合成立，
> 目标里只是因为“感觉张扬”就写 ZX。

### 状态
**HARD**

---

## SI-2｜Relational Role Invariant｜关系角色保持

对象在关系系统里的角色应保持。

例如：

源：
A 是施加约束者，B 是承受者。

目标：
A' 也应处于相应施加位置，B' 处于相应承受位置。

不能只因为 A 和 A' 都“强”。

### 状态
**HARD**

---

## SI-3｜Relation-Type Invariant｜生/克/补张结构保持

源结构中的关系类型在目标中必须有对应关系。

但这里不是要求表面动作相同。

要求的是：

> **关系效果结构相同。**

例如：
- 促进下一结构成立；
- 压制某变量；
- 通过补入形成缺失侧；
- 形成相互张力后产生新状态。

### 状态
**HARD**

---

## SI-4｜Direction Invariant｜方向保持

```
A → B
```

不能映成：

```
B' → A'
```

除非理论明确说明这是：

> reverse mapping / 反向实例

而不是同一结构。

### 状态
**HARD**

---

## SI-5｜Order / Dependency Invariant｜时序与依赖保持

如果源领域：

> R1 的结果是 R2 能发生的条件，

目标领域必须保留：

> R1' → enable → R2'

不能只保留两条边，却把先后依赖颠倒。

这是 Gentner 所说 higher-order / systematic relation 在十元里的重要对应。

### 状态
**HARD for dynamic chain**

---

## SI-6｜Changed-Variable Invariant｜变化变量角色保持

表面变量名字可以不同。

但变量在结构里的功能必须对应。

例如：

源领域：
> 某关系压缩“选择空间”。

目标领域：
> 可以不是选择空间这个词，
> 但必须是相同关系角色的“可用路径/可逆空间/行动余量”被压缩。

因此不是词义相同，而是：

> **variable-role preservation**

### 状态
**HARD for mechanism claim**

---

## SI-7｜Higher-order Topology Invariant｜高阶链结构保持

真正强的十元映射应保持：

- 分支
- 汇合
- 回返
- 中介
- 条件触发
- 关系嵌套
- 结果成为下一关系前提

这比单条“生 / 克”更重要。

### 状态
**HARD for strong cross-domain claim**

---

# 5｜哪些不要求保持

## SOFT-1｜绝对强度不要求相同
音乐里的 8 和角色里的 8 目前没有统一测量尺度。

所以：

> strength 只允许保持相对排序 / qualitative pattern，
> 暂不要求数值同构。

---

## SOFT-2｜绝对时长不要求相同
3 秒音乐不需要对应 3 秒剧情。

要求的是：
> 先后 / 阶段依赖结构。

---

## SOFT-3｜节点数量可以压缩
一个源领域里的多个实体可能被映射成一个结构角色。

因此十元更像：
> many-to-one abstraction

这也是为什么当前更接近 homomorphism，而非严格 isomorphism。

---

# 6｜十元跨域映射为什么更像 Homomorphism

数学结构同态的核心：

> 一个映射 h 把结构 A 映到结构 B，同时保存指定关系 / 运算。

十元跨域模型很可能是：

```
h : Domain_A → TenYuan_Space
g : Domain_B → TenYuan_Space
```

如果：

```
R_A(a1,a2)
```

和：

```
R_B(b1,b2)
```

经过 h / g 后都保持为：

```
R_T(t1,t2)
```

那么 A 与 B 可以说：

> 在指定关系上共享结构。

### 关键

不是要求：

```
a1 = b1
```

而是：

> 角色与关系对应。

---

# 7｜为什么暂时不能叫 Isomorphism

严格同构通常意味着：

- 双射 / 一一对应；
- 结构完整保持；
- 可以反向恢复。

十元明显允许：

- 信息压缩；
- 多个对象落一个位置；
- 表面信息丢失；
- 映射不可逆。

因此：

> **“跨域同构”现在属于过强表述。**

除非某个具体小结构确实满足双射和完整关系保持，才可局部说：
> local isomorphism candidate。

---

# 8｜Gentner 给十元提供的三条强门

Markman & Gentner 对 Structure Mapping 强调：

## G-1｜Structural Consistency
映射不能互相冲突。

## G-2｜Parallel Connectivity
如果两条关系对应，它们的参数 / 角色也必须对应。

## G-3｜Systematicity
优先匹配成体系、互相制约的关系网络，而不是一堆独立相似点。

这三条可以直接转成十元审核门。

---

# 9｜十元版 Structure-Mapping 三门

## TY-G1｜Role Consistency
同一个角色不能在同一映射里同时被映成互相冲突的位置。

## TY-G2｜Parallel Relation Connectivity
如果说：

> R_source ↔ R_target

那么：
- source role
- target role
- direction
- changed variable role

也要一起对应。

## TY-G3｜Systematicity
优先接受：

> 三条相互依赖的关系链

而不是：

> 五个各自孤立的词义相似。

# 10｜R2 五级结构证据

以后跨域案例按这个等级。

## S0｜Surface Match
只有颜色 / 情绪 / 题材 / 关键词像。

> **FAIL**

---

## S1｜Single-position Match
只有一个十元标签对上。

> **VERY WEAK**

不能支撑跨域结构主张。

---

## S2｜Local Relation Match
至少一条：

> A --R→ B

的角色、方向、关系效果对应。

> **WEAK CANDIDATE**

---

## S3｜Connected Pattern Match
至少两条以上互相连接关系保持：

> A→B→C

并保持：
- role
- relation type
- direction
- changed-variable role

> **STRUCTURAL CANDIDATE**

---

## S4｜Higher-order Structure Match
进一步保持：
- 顺序依赖
- 分支/汇合
- 中介
- 结果→下一条件
- 关系组合

> **STRONG STRUCTURE MAPPING**

---

## S5｜Predictive Structure Transfer
在目标结果未知时：

> 根据源结构 / 十元结构提前预测目标的下一关系或选择，
> 后续真实观察命中。

> **EXTERNAL EVIDENCE**

这是最高等级。

---

# 11｜什么叫“只是类比”

出现任一情况，不能升级成强结构映射：

## F1｜词义对号
“都很张扬，所以都是 Z”。

## F2｜主题对号
“都讲自由，所以结构一样”。

## F3｜结果倒推
先知道结局，再寻找生克补解释。

## F4｜方向丢失
A 克 B，被映成 B' 克 A'。

## F5｜关系类型漂移
源领域写“克”，目标领域其实只是“同时出现”。

## F6｜组合来源漂移
同一个十元标签在不同领域靠完全不同的三元逻辑得到。

## F7｜时序被打乱
关系顺序不同，却仍宣称同一动态链。

## F8｜只保留漂亮命中
不记录无法映射、冲突和失败案例。

---

# 12｜“补张”必须怎样处理

用户强调深层补张形态属于理论核心，不能单独拎出来变成一个孤立模块。

因此本研究把“补张”看作：

> **整套映射拓扑里的一种关系形态**

而不是独立于三元→十元→五行关系之外的第四套理论。

判断补张是否跨域保持，需要同时看：

- 哪两个结构位置形成张力；
- 缺失 / 补入的是哪一侧；
- 补入前后 changed_variable 怎样变化；
- 补入后是否改变后续可达路径。

只有词面上“互补”不算。

---

# 13｜强度如何处理：暂不作为硬同态条件

当前十元有 1–10 强度。

但不同领域：

- 音乐 8
- 角色 8
- 视觉 8

目前没有共同单位。

所以 R2 冻结：

> **跨域结构保持暂时不要求 absolute numeric strength preservation。**

可以要求：

## Rank preservation
如果源领域：
A > B

目标领域相应结构也应：
A' > B'

或者：

## Phase pattern preservation
先增强 → 后减弱 → 再增强

可以跨域对应。

### 以后若建立统一标尺
再研究 weighted homomorphism。

---

# 14｜体量同样不是结构保持硬门

体量目前是：

> 结构存在感 / 占场程度

它可能帮助比较同一领域。

但跨领域暂无统一标尺。

因此：

> **体量不进入 R2 hard invariants。**

避免：

> “音乐体量9 = 角色体量9”

这种伪精确。

# 15｜十元结构签名 v0.1

为了跨域比较，每个关系片段生成一个：

> **Structural Signature**

形式：

```
TSIG = {
  composition_pattern,
  role_pattern,
  relation_sequence,
  direction_pattern,
  dependency_pattern,
  changed_variable_roles,
  topology_pattern
}
```

其中不放：

- 人名
- 题材词
- 具体媒介
- 绝对时长
- 暂未校准的绝对强度

### 目的

两个不同领域先各自生成 TSIG。

然后：

> **比较 TSIG，不比较故事词汇。**

这才真正落实“名字切换”。

# 16｜示意：表面完全不同但结构可能相同

## 领域 A｜角色关系

```
A 压制 B 的行动空间
→ C 提供缺失路径
→ B 获得新行动方向
→ 原压制结构被迫改写
```

## 领域 B｜音乐

```
A' 限制 B' 的展开空间
→ C' 引入新的连接条件
→ B' 获得新的发展路径
→ 原限制结构发生重组
```

如果二者能在：

- role
- relation type
- direction
- dependency
- changed-variable role
- topology

上保持，

那么即使：

> 人物 ≠ 音符

仍可以成为强结构映射候选。

---

# 17｜反例：表面像，但结构不同

## A
两个角色都“很张扬”。

## B
两段音乐都“很强烈”。

如果没有：

- 相同关系角色
- 相同关系方向
- 相同生克补张拓扑
- 相同变量变化
- 相同阶段依赖

那么只是：

> **surface / affective similarity**

不是十元结构保持。

# 18｜十元跨域映射的最低通过门

以后要宣称：

> “A 与 B 是同一十元深层结构”

最低必须：

### REQUIRED
- S3 或以上；
- SI-1～SI-4 全过；
- 动态链主张必须再过 SI-5；
- 机制主张必须过 SI-6；
- 强跨域主张必须过 SI-7；
- 至少一个反例/负控排除。

### 如果只有 S1 / S2
只能写：

> “局部十元相似 / 候选映射”。

# 19｜如何防止自我验证

R4 的风险在这里重新落地。

## 19.1 Source first
先冻结领域 A 的原始结构，不看领域 B。

## 19.2 Independent mapping
A、B 分开编码。

## 19.3 Remove surface words
比较时尽可能遮掉作品名、题材词、风格词。

## 19.4 Compare TSIG
只比较结构签名。

## 19.5 Negative controls
加入：
- 表面很像但结构不同；
- 表面完全不同但结构相同的候选。

## 19.6 Prospective prediction
最高等级 S5 必须先预测再揭晓。

# 20｜R2 对“映射理论”核心的最终定义

当前可以把十元映射写成：

> 给定不同领域 D1、D2，
> 分别通过映射函数 h1、h2 压缩到十元关系空间 T。
>
> 若 D1、D2 中指定的关系结构，在 T 中保持同一组组合角色、关系类型、方向、依赖次序、变化变量角色及高阶拓扑，则称两者存在十元结构映射。
>
> 表面词汇、媒介和具体对象不要求一致。

数学上：

> **partial / selective structure-preserving mapping candidate**

比：

> full isomorphism

更准确。

---

# 21｜R2 最关键的新工具：TSIG

从现在开始，跨域验证不比较：

> “这个像不像那个”。

而比较：

> **TSIG(A) vs TSIG(B)**

如果关系签名不一致：

> 即使故事主题再像，也不能说同一十元结构。

如果关系签名高度一致：

> 即使一个是人物，一个是音乐，也可以进入结构迁移候选。
