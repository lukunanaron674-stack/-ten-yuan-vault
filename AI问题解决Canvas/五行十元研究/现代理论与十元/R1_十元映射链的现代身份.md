---

# 0｜R1 总结论

十元目前最接近的现代组合，不是单一的“系统动力学”或“关系本体论”。

它更像四个现代思想的叠加：

1. **Relational abstraction / schema induction｜关系抽象**
2. **Compositional representation｜组合式表示**
3. **Structure-mapping theory｜结构映射**
4. **Structure-preserving mapping｜结构保持映射（候选数学化）**

其中最关键的新发现：

> **用户所说“领域名字可以换，但深层关系结构不换”，与 Gentner 的 Structure-Mapping Theory 非常接近。**

Structure-Mapping Theory 的核心不是搬运对象属性，而是：

> 从 source/base domain 到 target domain，对齐对象角色，并优先保存关系系统和高阶关系。

这与十元的理论核高度相似：

> 音乐、角色、叙事、视觉等表层对象不同；
> 真正需要检查的是映射后“生/克/补张/方向/动态链”的关系结构是否重复出现。

但这目前只能称：

> **STRONG MODERN NEIGHBOR / 候选现代解释框架**

不能直接声称：
> 十元就是 Gentner SMT。

# 1｜最底层来源：色彩关系经验

用户最新冻结的来源：

## z｜张扬
来源原型：
> **补色 / complementary relation**

视觉体验：
- 两端并置后互相增强；
- 强度被彼此抬高；
- 具有外扩、张扬、振动感。

19 世纪 Chevreul 的 simultaneous contrast 研究，以及后来的印象派/新印象派实践，都明确记录了互补色并置会强化视觉强度。

---

## n｜耐
来源原型：
> **邻近/类似色 / analogous relation**

视觉体验：
- 色相接近；
- 连续、和谐；
- 不靠强冲突夺取注意；
- 容易形成稳定、可持续观看的整体。

现代美术教育资料也明确把色轮相邻色称为 analogous scheme，通常具有较强和谐性。

---

## x｜醒
来源原型：
> **对比 / contrast relation**

视觉体验：
- 差异被迅速拉开；
- 边界、对象和局部变量更清楚；
- 形成“醒目 / 清晰区分”的注意效果。

---

# 2｜非常重要的历史边界：这不是“印象派正式三分法”

必须冻结：

> **补色 / 邻近色 / 对比色 → 张扬 / 耐 / 醒**
>
> 是用户从绘画实践与色彩关系中抽出的三种关系效果母型。

不能写：

> “印象派提出了张扬/耐/醒三元理论。”

原因：

1. Chevreul 1839 年的同时对比理论早于印象派；
2. 印象派、新印象派确实广泛吸收补色与综合色彩理论；
3. “analogous colors”属于更广泛的综合色彩/设计理论语言；
4. complementary 本身也属于 contrast 的特殊强形式，因此标准色彩理论并不把“补色/对比色”视为完全互斥的两大类。

### 最安全来源声明

> **三元起源于用户对近现代综合色彩实践中“互补强化、邻近协调、差异对比”三种关系效果的抽象，而非直接复制某个印象派既有三分理论。**

---

# 3｜现代身份 A：从颜色关系到三元 = RELATIONAL ABSTRACTION

真正被抽出来的不是：

- 红
- 绿
- 蓝

这些对象属性。

而是：

- 互相加强
- 稳定协调
- 清楚区分

这属于：

> **从具体知觉实例中抽取关系模式。**

现代认知语言更接近：

- relational abstraction
- relational schema induction
- abstract relational representation

### 关键点

三元更适合定义成：

> **三种关系效果原型 / relational effect primitives**

而不是：

> 三类世界实体。

这是整个十元现代化最重要的纠偏之一。

---

# 4｜为什么不宜先叫“latent space”

AI 里 latent representation 常指：

> 模型从大量数据中学习出的隐变量/表征。

而 X/Z/N 当前是：

- 用户主动提出；
- 人工定义；
- 有明确艺术实践来源。

因此暂时不宜说：

> “三元就是 latent variables。”

更精确：

> **hand-engineered relational basis｜人工设计的关系基底**

或：

> **symbolic relational basis｜符号关系基底**

如果未来让模型从原始案例中盲学，结果自然收敛出近似三元，那时才能进一步讨论：
> learned latent factors。

---

# 5｜现代身份 B：三元 → 组合 = COMPOSITIONAL REPRESENTATION

十元的第二步不是“再发明七个独立概念”。

而是：

> X / Z / N 作为基本构件发生组合，形成更复杂位置。

这与现代 compositionality 很接近。

组合性的一般思想是：

> 复杂表示由基础构件 + 构件的组合方式决定。

认知科学和 AI 中也强调：
- finite primitives
- recombination
- structured composition
- productivity

### 十元对应

三元：
> primitive relational basis

组合：
> composition rule

十元：
> compositional relational positions

### 当前状态

**STRONG ANALOGY**

但还缺：

> 一套完全冻结、形式化的组合函数 C(X,Z,N)。

所以不能直接声称已经建立完整 formal compositional semantics。

---

# 6｜十元不是“十个平铺类别”，而是组合生成空间

这点由 R6.2 冻结。

错误表示：

```
ZX = class 1
NX = class 2
...
```

更接近：

```
base primitives = {X,Z,N}
composition rules = C
ten positions = C({X,Z,N})
```

因此现代建模时：

> 十元位置应保留“它是怎样组合得到的”这一 provenance。

如果只保存最终标签 ZX，而丢掉 X/Z/N 的组合来源，就丢掉理论核心。

---

# 7｜现代身份 C：三元组合 → 五行十位 = STRUCTURED RECODING / SCHEMA ALIGNMENT

下一步：

> 三元组合位置被映射进阴阳 × 五行的十位结构。

这一步目前最接近：

- structured recoding
- schema alignment
- ontology/representation mapping
- fixed codebook alignment

但它和普通“换词”不同。

因为目标不是：

> ZX 改名成木阳。

而是：

> 组合位置 + 关系位置
> 一起对齐到一个已有的十位关系骨架。

因此最合适的暂名：

> **relational schema alignment｜关系模式对齐**

### 五行在这里的角色

不是装饰、不是权威背书。

而是：

> **intermediate relational scaffold｜中间关系骨架**

它提供：
- 五个父位；
- 阴阳十位；
- 生克循环；
- 对位/互补张力的历史结构资源。

---

# 8｜现代身份 D：五行深层关系 → 十元 = RELATION-PRESERVING MAPPING

用户核心主张：

> 映射的不只是“名字”，还要把深层关系一起映射。

也就是：

如果源结构里：

```
A --R1--> B
B --R2--> C
```

经过十元映射 h 后，目标结构也应该保留相应关系：

```
h(A) --R1*--> h(B)
h(B) --R2*--> h(C)
```

这正是“structure-preserving mapping”的现代问题。

---

# 9｜Homomorphism 比 Isomorphism 更可能适合十元

数学上：

## Isomorphism｜同构
要求非常强：
- 一一对应；
- 结构完整保存；
- 可逆。

十元跨领域映射通常不会满足。

因为：
- 一个领域很多对象可能压到同一个十元位置；
- 映射可能丢失表层信息；
- 并不要求可逆重建原领域。

所以现阶段：

> **不要把十元叫跨域同构理论。**

---

## Homomorphism｜同态
要求相对弱：

> 某些指定关系/运算在映射后仍被保存。

这更符合十元候选结构。

例如：

源领域：
> A 对 B 起促进作用

映射后：
> h(A) 与 h(B) 落到相应“生”关系位置。

### R1 判断

> **十元的数学候选更像“选择性关系保持的 homomorphism”，而不是严格 isomorphism。**

状态：
**FORMALIZATION HYPOTHESIS**

尚未证明。

---

# 10｜Category Theory / Functor 为什么现在还不能直接套

范畴论中的 functor 是：

> objects → objects
> morphisms → morphisms
> 并保持 identity 与 composition。

这听起来和十元很像：

> 对象换名，但关系与关系组合被保存。

所以它是很有吸引力的未来方向。

但是目前十元还没有明确：

- source category 是什么；
- objects / morphisms 分别是什么；
- composition operator 怎样严格定义；
- identity relation 是什么；
- 映射是否真的满足 composition preservation。

因此：

> **Functor = FUTURE FORMAL CANDIDATE**

不能现在直接宣称：

> 十元就是一个 functor。

---

# 11｜现代身份 E：跨域名字切换 = STRUCTURE-MAPPING THEORY

这是 R1 最强发现。

Gentner 的 Structure-Mapping Theory：

> analogy 的关键不是 source 和 target 对象长得像，
> 而是它们之间的关系系统是否能对齐。

SMT 特别强调：

- object attributes 可以不同；
- relational predicates 优先；
- higher-order relational systems 更重要；
- systematicity：优先匹配成体系的关系，而不是孤立属性。

这与用户所说：

> **“只能名字切换，深刻谱/深层关系不能单独抽出来；映射后发现关系结构重复出现。”**

高度接近。

---

# 12｜十元与普通类比的区别，可以用 SMT 精确说明

普通表面类比：

> 红色像愤怒。

这是：
> feature similarity / associative analogy

十元真正想要的：

领域 A：
> 角色 A 限制 B → B 通过 C 获得新路径 → 原限制条件被改写

领域 B：
> 音乐 A 限制 B → B 通过 C 获得新路径 → 原限制条件被改写

即使：
- 人物名称不同；
- 音色不同；
- 媒介不同；

如果关系系统保持：

> 才算十元跨域映射成立。

这更接近：

> **relational analogy / structure mapping**

而不是关键词类比。

# 13｜“名字切换”在现代语言里到底是什么

现在可以更精确地改写用户的“名字切换”：

> **surface vocabulary substitution under relational-role preservation**

中文：

> **在关系角色保持条件下的表层词汇替换。**

即：

- source-domain label 可以换；
- target-domain label 可以换；
- 对象属性可以完全不同；

但：
- relation type
- direction
- composition
- higher-order relation

必须达到预先定义的保持标准。
