# 感受营造路径总表 v1｜从漫画、音乐、光影、人物、居所、世界到H3

## 一句话目标
不是列十元=关键词，也不是一直做一变量A/B；是当创作者说「我要观众感到X」时，**能从不同媒介和层次提供若干真正不同的营造路径**，选择最合适的组合，使人物/环境/剧情/声音/时间在真实视频里形成可感的关系。

**双主任务分工**：主任务1「H3出可信短片/建立信心」由674-286编译、674-216执行、674-296核资产/运行门、674-289记实片、674-173真人审美与感受；主任务2「如何诱发感受」由674-297本库研究、674-106记证据、已有漫画/音乐/电影库供料，不另开主任务。只作方法库，不当毕业论文。

## 1｜路径表（首批15条，按可操作机制而非情绪名分类）

| ID | 路径／媒介 | 感受如何被制造：大白话机制 | 视觉、动作、声音、事件可操作项 | 可能抢走主感受的因素／注意 |
|---|---|---|---|---|
| P01 | **身份与社会位置**（角色） | 他不只是长成这样，而是在众人关系里承担独特地位；他人的回应让身份变成体验 | 服饰与既有身份锚、他人目光/礼仪/距离、他对他人的可见影响 | 只有头衔/道具，画面不成立时只能说明设定 |
| P02 | **特殊居所**（房间、船房、圣所） | 让人物的长期生活/信念在物理空间中留下痕迹 | 空间用途、痕迹密度、居住方式、独特通路、保护/禁入的边界 | 奇观抢戏、普通装饰误当深层关系；船房并不等于船舱 |
| P03 | **整个世界的响应**（城市、生态、组织） | 城市/文明的运行方式不断给观众印证人物内核；角色之外仍看得到那种秩序/缺席 | 道路/建筑轴线、群体习惯、资源分配、空城、远近呼应 | “世界宏大”不等于“感受更强”；多层不保证加法 |
| P04 | **人物与环境的关系** | 同样的人放在同样的地，镜头能表现亲近、隔绝、依附、对抗或未知 | 朝向、视线、距离、谁主动靠近/退避、环境给予/阻止什么 | 单独静态图不能判断“主动孤僻”；必须有可选的关系 |
| P05 | **光影与明暗结构** | 通过注意力集中、明暗层级、照明来源让空间和人物具有权重 | 顶光/侧光/逆光、阴影面积、边缘可见性、光源归属 | 黑色≠XN，顶光≠ZN；必须结合上下文与USER体验 |
| P06 | **色彩纯度/冷暖/面积分配** | 纯度与主辅色控制首先进入感官的基调；配合对象才能有意义 | 主色纯度、冷暖比例、亮暗面积、局部强调、色卡功能分工 | 过强幻想生物/高纯色可能变NZ主导；不要简单从色名判元 |
| P07 | **构图、镜头与尺度** | 让观众站在特定“观看位置”，有中心/失衡/渺小/不可抵达等空间体验 | 景别、俯仰、纵深、主体面积、空白、线的汇聚/偏离、固定或移动机位 | 只求“电影感”而缺少角色/世界对象关系，易变空壳 |
| P08 | **材质、遗物与使用痕迹** | 没有交代全部历史，也能让观众“看见长期发生过什么” | 擦痕、修补、旧物层叠、器物位置、使用手势 | 污损/做旧不必然XN；要有具体持续使用或回返关系 |
| P09 | **可见行为选择** | 感受来自角色本可以做A却选择B；选择的代价让感受可读 | 接近/回避、安抚/命令、留下/离开、保持/改变 | 不能只用“孤独”提示词代替角色行为，角色Canon优先 |
| P10 | **事件与后果** | 让某件已发生的事改变剩余选项、人物地位或世界结构 | 门关闭/通道开放、仪式中断、旅程回头、过去行为留后果 | 惊吓、爆炸、灾变极易抢走更细腻的目标感受 |
| P11 | **时间累积、重复与打破**（H3/漫画） | 反复建立预期，然后保持、变形或失约；观众体验来自“等到了/没等到” | 等待时长、动作/镜头停顿、相同构图重复、某一步延迟、回忆插入 | 机械重复不等于XN；时间必须真实连接当前事件 |
| P12 | **音乐的期待结构** | 节拍/和声/主题/密度制造期待、延迟与归来，能支持或抵触画面含义 | 速度、节奏密度、和声紧张度、持续音、重复动机、音区、音色 | 音乐过强会遮住视觉机制；暂不主张某乐器=某十元 |
| P13 | **环境声、声音的缺席** | 声源说明空间是否有生活/联系；回应落空或突然寂静会改变角色处境 | 远处机械运转、水声、人声是否应答、回响/吸声、环境突然收窄 | 静音不等于孤僻，恐怖声效易把NX推成XZ |
| P14 | **漫画分格与阅读顺序** | 读者被迫在哪停多久、先见谁的反应、翻页知道什么，能改变同一事件的体验 | 大小格、留白、动作切片、重复格、翻页前后信息差、反应镜头 | 漫画分格→H3应转译为“时间和机位”，不能字面复制分格 |
| P15 | **叙事视角与信息先后**（漫画/电影/文字） | 给观众、角色不同的信息，会改变同一个动作被理解成什么 | 先展示行为后揭示原因、先给远处信号后拍回避、隐去/揭示角色知识 | 信息改变可能只是理解变化，仍须区分“知道”与“真实感到” |

上表的手法互不互斥。**路径编号是创作工具ID，不是十元/五轴/五维/生克补的正式节点**。

## 2｜把已发生的 USER 体验放入证据侧（不外推）
- U-N4-01 用户上传亮色水没城市：**NZ主、NX次**。USER解释NZ来自「颜色纯度高＋金鱼这样的幻想系」，NX次级来自「画面中无人／水淹建筑」。这是P05/P06/P03在一个样本中的复合关系，未区分独立贡献。
- U-N4-02 用户上传暗色孤舟城市：**XN主、NX次**。USER解释XN来自「昏昏沉沉压抑氛围＋黑色主角」；NX归因其本人不确定。不是“黑色必然XN”的法则。
- 探索性A/B新图：USER `A=N、B=NZ`，且 **A无人 NX较B强**；两幅画面不严格只差人物，不可说已验证普遍因果。
- H06 当前**创作目标**：「庄严、神圣、不可动摇」。H06暂用ZN主/XN次为工作假设；不能将这三个中文感受词等同ZN定义。钢铁教派整体ZX+NZ是**另外一个层级的对象**。

## 3｜漫画研究怎样真正供给H3（已有漫画库复用、增量一层“营造机制”）
漫画五大维度库仍在`05-银矿库/漫画库/`，例如 `02-时间型 xn+z.md` 包含《蓦然回首》《花牌情缘》等及早期人物分析。**旧分数和人物百分比是历史库分析口径，并非当前真人“被营造出某感受”的命中率**。不把漫画角色十元直接当读者情绪，也不因五维“时间”自动断定XN主。
- 《蓦然回首》用作**候选P11/P14/P15**：相近构图/创作行为在不同时间点重现，直到回望时被观众重新解释；漫长的行动过程被浓缩到少量页格/记忆节点。移植H3：相似手部/空间动作建立「长时痕迹」，最后用短暂停顿触发观众重新解释过去。
- 《花牌情缘》用作**候选P11/P12/P09**：比赛准备、报读/出手时机、节奏与等待之间的关系；移植H3：镜头先明确等待和行动时机，声音/节拍配合，不必靠快切来“表现紧张”。需按原卷画格核实例子，暂不冒充已核页码。
- 漫画学习模板：
  `作品/章节具体画面 → 角色在做什么/谁与谁是什么关系 → 创作者安排了什么信息顺序、格数、景别、停顿 → 观众可能先感到什么 → 另一种竞争解释 → H3对应时间/镜头/声音变量 → USER实际报告`。
- 漫画的**初始XN感**可横纵发散：进入既有秩序(身份/职业/流程)／固定节拍反复／旧行为留下可见积累／一次操作需要按顺序完成／通过一段时间后返看相同物件。这五条是**产生时间连续/过程感的候选机制**，不是XN canonical定义，也未获漫画读者独立评分。

## 4｜两个现成创意例子：跨层嵌套而非堆词
### NX船房：目标“外界没有可回应的生活，船房是长期居所，孤僻小孩主动不接近世界”
- 身份P01/P09：孩子为什么不回应外界？必须有能观察的回应机会才可能推测“主动孤僻”；被迫独处仅是环境状态。
- 居所P02/P08：同一船体不是运输工具，而有持续生活的痕迹、重复劳作与岁月沉积。
- 世界P03/P04：原本用于公共生活的城市被水没，远处无显著人的回应；不要一味用灰暗和惊吓抢主感受。
- 时间/声音P11/P13：短片中远处声音或讯息出现后沉默持续，环境本身不加巨大灾变动作。**原项目是否有真实船房与小孩原图，仍需293/296核实**。

### H06主教：目标“庄严、神圣、不可动摇”（ZN主/XN次为工作映射）
- 身份P01/P07：原有机械青眼、环杖、红披带、清晰轴线；“主教”身份通过群体行为回应而不是英文prompt贴标签。
- 特殊居所P02：候选A不动圣城 / B巨神体内圣所 / C移动圣城静止内核；均非已冻结场景，不能当作A端现存输入，选取需走USER世界观审核。
- 世界P03/P10：教派整体保留对外ZX、对内NZ两面属性；人物/圣所/世界的具体关系可能使庄严与不可动摇变强，也可能带出其他感受；世界图由真实素材和用户判断决定。
- 时间/音乐P11/P12：镜头不凭“站着不动”认作ZN；可通过外部轻微变化、主体轴线稳定、低密度节拍/持续音的选择形成“时间过去但中心不摇”的候选读感。音乐若破坏神圣感则删。
- **工程顺序**：先高质量H06原图单镜 H3/本人主观验收；再把真正有价值的特殊圣所设定制成高质量场景，通过审核后作为下一镜/组合镜消费。两个步骤同属主任务1连续推进，不额外开第三主任务。

## 2026-10-09 增量｜P16：主观感知通道的开放与封闭

新增P16，不改变原P01–P15：角色和环境没有消失，但镜头限制观看者能否看清对方、听清回应，可能让同一关系从可接近变为隔膜。不同于P15的信息先后，P16操纵同一时刻的信息可辨识度。

**例1：《声之形》面部X标记。** 作者大今良时2016年访谈说明，石田视角里同学面部X标记表达他不愿或无法直视对方。AI预测：隔膜、回避；竞争为羞怯、警觉、画面故障。H3 A/B：同一角色和机位，只改变对方脸部的可辨识度；0–1s建立联系机会，1–3.5s主观感知差异，3.5–5.17s固定停顿。来源：https://icv2.com/articles/columns/view/34645/creator-interview-yoshitoki-oima-a-silent-voice

**例2：《声之形》被截断的话框。** 同一访谈中作者说明西宫视角的对话文字缺损是呈现其感知世界的手法。AI预测：沟通受阻、困惑；竞争为字幕故障。H3 A/B：相同动作和同一句话，仅在后期改变语音可辨识度，不同时改变表情、机位和配乐。不得宣称这已证明任何真实听障者的感受。来源同上。

**例3：《蓦然回首》真人电影的笔触声。** 2026-09-07路透采访中，是枝裕和说明希望用笔触从迟疑划擦到自信落笔、再到数位笔轻敲的声音变化表现创作成长。此为2026年真人电影改编的导演构想，不是原作漫画有声音。AI预测：时间累积、成长；竞争为机械重复、单纯节奏变化。归入P08×P11×P13纵向深化，不另增路径编号。H3同一作画画面A用恒定笔触音色，B仅让笔触音色分段演变；音频后期独立控制。来源：https://www.reuters.com/business/media-telecom/japanese-filmmaker-kore-eda-brings-beloved-manga-tale-friendship-venice-2026-09-07/

**纵向约束：** 关系机会P04先存在，感知变化P16才有对象，时间停顿P11再制造期待，环境声P13只辅助；恐怖音、强音乐、角色身份漂移会抢焦点。五轴与十元只做后验比较，不先验贴标签。
