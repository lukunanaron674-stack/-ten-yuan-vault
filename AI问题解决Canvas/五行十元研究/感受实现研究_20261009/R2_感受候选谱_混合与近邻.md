# R2｜旧词源能激发什么感受：候选谱与最近邻

## 核心方法
先让人自由说体验词，再给每一感受 1–10；**绝不先出示五轴和十元标签**。下表全是 AI 的心理联想**预测**，不是人的真实打分；不预填命中率和强度分数。

| 词源刺激（R1） | 预测可能激活（可以多项并存） | 主要混淆与反向 |
|---|---|---|
| 木：生长/生发/破土 | 生机、希望、挣脱、膨胀、顽强 | 侵占、失控、蔓延也可能出现 |
| 木：条达/舒展/曲直 | 松开、舒畅、通透、伸展、自由 | 过度延展可能反成疲惫/空虚 |
| 火：炎热/爆发 | 兴奋、充盈、急切、危险、燥热 | 热烈可变威胁，不能自动等于积极 |
| 火：发光/上升/释放 | 被看见、振奋、开放、眩目、暴露 | 聚光也可能产生审视压力/羞耻 |
| 土：承载/厚实/稼穑 | 安全、托底、踏实、沉稳、被容纳 | 厚重也可能变成沉闷、负担 |
| 土：中和/居中/化生 | 平衡、缓和、持续、滋养、平淡 | 也可能被体验为无聊/被抹平 |
| 金：切割/决断/从革 | 清楚、利落、决绝、锋利、解脱 | 伤害、冰冷、被迫、丧失也可能突出 |
| 金：收敛/肃杀/冷峻 | 克制、严肃、距离、秩序、冷漠 | 整齐可让人安心，亦可让人压抑 |
| 水：润下/流动 | 绵延、宁静、沉浸、漂泊、不确定 | 舒缓与失控都可能存在 |
| 水：深沉/潜藏/闭藏/寒凉 | 神秘、幽静、孤寂、敬畏、危险 | 幽静和恐惧、孤僻和安心需拆开 |

## 对立不能先写死
五组旧历史配对仍保存：木 ZX↔NX、火 ZN↔X、土 N↔X并Z、金 XN↔Z、水 XZ↔NZ。
但**它们是否就是人体验上的五组两极尚无真人证明**。允许：
- 同一刺激出现 2–3 种感受乃至 10D 轮廓；不强制 Top1 单标签。
- 同一词在不同场景刺激下得到相反体验。
- 旧结构端点分得清，但“人的主感受”其实一样。
- 新人类感受簇出现不能由旧五轴解释的情况。

## 必须捕获的反例
1. **同一个词、不同感受**：「生长」= 庭院新芽（活力） vs 墙体被藤蔓侵入（压迫）。
2. 「发光」= 夜航灯塔（希望） vs 牢房强光（受审视）。
3. 「承载」= 托住疲惫的人（安心） vs 承担超载重物（窒息）。
4. 「决断」= 及时停止伤害（解脱） vs 一纸决定生死（恐惧）。
5. 「潜藏」= 温暖被窝里安静等待（安全） vs 黑暗水底无法看清（不安）。
6. **不同词、近似感受**：「厚实」「和缓的流水」「井然的秩序」都可能让人安心，但诱发路径不同。
7. 「无人航船」「空荡房间」「孤独小孩」可能均触发孤寂，但孤僻/宁静/遗弃三者必须分开。
