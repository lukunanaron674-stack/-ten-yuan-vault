# 674-284｜R6 五行 × 现代关系理论：哪些真可比，哪些只是像

> 状态：**R6 DONE**
>
> 目标：把五行与过程哲学、关系论、网络论、系统动力学、动态系统、反馈理论、分类/本体表示逐一比较。
>
> 纪律：**只说可比，不说“古人早就发明了现代科学”。**

---

# 0｜R6 总结论

五行和现代理论的关系不能用一句“它就是系统论”概括。

当前最稳的分层是：

## STRONG COMPARABILITY｜强可比
1. **Process Philosophy｜过程哲学**
2. **Directed / Signed Network｜有向 / 有符号网络表示**

## MEDIUM COMPARABILITY｜中等可比
3. **Relations / Relational structure｜关系结构**
4. **Systems Thinking｜系统思维**
5. **Feedback / Regulation｜反馈 / 调节**

## WEAK / CONDITIONAL｜弱或条件性可比
6. **System Dynamics｜系统动力学**
7. **Dynamical Systems｜数学动态系统**
8. **Relational Ontology / Structural Realism｜关系本体论 / 结构实在论**

一句话：

> **五行最像“过程 + 关系 + 有向正负网络”的定性结构；只有补上状态变量、更新规则、参数、时间和可测试数据后，才能进一步升级成现代动态模型。**

---

# 1｜五行 × 过程哲学｜STRONG COMPARABILITY

SEP 对 process philosophy 的核心定义：

> 现实优先被理解为 becoming / occurrences / processes，而不是静态实体。

这和成熟五行的几个特征高度可比：

- 行强调变化、运行；
- 五类通过生克发生关系；
- 一个对象的位置依其变化关系而定；
- 稳定不是不动，而可能是动态关系形成的暂时稳定。

因此：

> **五行与过程哲学在“把变化和过程放在静态实体之前”这一点上存在强哲学相似性。**

## 但不是同一个理论

过程哲学包含：
- Whitehead
- James
- Dewey
- contemporary analytic process ontology

内部差异极大。

五行没有自动继承：
- Whitehead actual occasions
- Western process ontology
- modern event metaphysics

### 判定
**SUPPORTED ANALOGY**

可说：
> 五行具有明显 process-oriented 特征。

不能说：
> 五行就是 process philosophy，或提前发明了 Whitehead。

---

# 2｜五行 × Relations｜STRONG–MEDIUM

现代关系哲学区分：

- property｜属性
- relation｜关系

方向性非对称关系尤其重要：

> A R B ≠ B R A

这和 R2 的结论直接对上：

木生火 ≠ 火生木  
木克土 ≠ 土克木

因此五行的成熟生克关系天然适合用：

> **binary directed relation｜二元有向关系**

表示。

一个节点还可以按 incoming / outgoing 区分：

- 生我
- 我生
- 克我
- 我克

### 判定
**STRONGLY FORMALIZABLE**

这不是说五行属于现代“关系本体论”。

只能说：

> 五行关系具有可以被现代 relation logic / graph language 清晰表达的结构。

---

# 3｜五行 × Signed Directed Graph｜当前最强形式映射

现代 signed directed graph 可以写：

> G = (V, E, σ)

其中：
- V = 节点
- E = 有方向的边
- σ = 正 / 负符号

五行可以非常自然地映射：

## Nodes
V = {木, 火, 土, 金, 水}

## Positive / enabling edges
生：
木→火→土→金→水→木

## Negative / constraining edges
克：
木→土→水→火→金→木

Wang & Zhang (2020) 已明确把 five-phase system 重述为：

> five-nodal + signed + directed ties

并用：
- enabler
- enablee
- constrainer
- constrainee

描述节点角色。

### 判定
**DIRECT MODERN FORMALIZATION EXISTS**

这是 R6 最强的连接。

---

# 4｜但是“signed graph”只证明拓扑，不证明语义

这一点必须锁死。

把：

木→火

标成 positive edge，只说明：

> 我们决定把“生”编码为一种正向 / enabling relation。

它不自动证明：

- 木真的在现实中因果促进火；
- 所有属木对象都会促进所有属火对象；
- 这种边在音乐、政治、身体、叙事里都同样有效。

因此：

> **graph formalization validates representation, not empirical truth.**

形式化证明的是：
> 关系能被精确写出来。

不是：
> 关系在现实中一定成立。

---

# 5｜五行 × Network Theory｜MEDIUM–STRONG

网络论最适合五行的地方：

- node
- edge
- direction
- sign
- in-degree / out-degree
- cycles
- local structure
- path

成熟五行确实是一个高度规则化的五节点关系图。

每一节点：
- 2 条“生”相关边
- 2 条“克”相关边
- 同时处于输入/输出位置

### 可以研究的现代问题

- 两套 cycle 的拓扑结构
- 删除一条边会怎样
- 反转一条边会怎样
- 节点角色是否对称
- 局部 motif
- 是否存在特殊结构稳定性

### 不可以直接说

> 五行经过网络论验证，所以五行是科学。

网络理论只是：

> **representation + structural analysis layer**

---

# 6｜五行 × Systems Thinking｜MEDIUM COMPARABILITY

系统思维通常强调：

- 部分不能完全脱离整体理解
- 变量相互作用
- 非线性
- 循环因果
- feedback
- delays
- unintended consequences

五行具有：

- 多节点互相作用
- 生克并存
- 循环结构
- 后期制化 / 胜复
- “一处偏盛影响整体”的描述

因此它和 systems thinking 有明显可比性。

### 判定
**USEFUL ANALOGY**

尤其适合说：

> 五行是一种早期关系系统思维资源。

但不能说：

> 五行 = 现代 General Systems Theory。

---

# 7｜五行 × Feedback｜MEDIUM COMPARABILITY

后期五行尤其医学中：

- 生
- 克
- 太过
- 不及
- 乘
- 侮
- 制化
- 胜复

很容易被现代语言重述成：

> amplification / constraint / compensation / balancing response

Wang & Zhang 2020 更直接把五行某些循环解释为：

- balancing feedback
- reinforcing feedback

### 这里有真实可比性

例如：

某一关系过强  
→ 触发另一制约  
→ 系统重新调整

这和“负反馈维持稳定”的思想有结构相似。

---

# 8｜但古代“制化”不能直接等于现代 feedback control

现代 feedback 至少需要：

- 被反馈的变量
- 观测 / 信息路径
- 输入
- 输出
- 响应规则
- 对目标状态 / 偏差的作用

控制论甚至还会要求：
- gain
- stability
- controller
- error signal

五行传统通常没有这种精确定义。

所以：

> 制化 / 胜复 ≈ feedback-like pattern

而不是：

> 制化 = cybernetic feedback control

### 判定
**ANALOGY, NOT IDENTITY**

---

# 9｜五行 × System Dynamics｜只能到中弱可比

MIT 的 system dynamics 明确使用：

- feedback loops
- stocks
- flows
- accumulations
- time delays
- causal loop diagrams
- state changes

五行目前具备：

✅ loop  
✅ positive / negative qualitative links  
✅ qualitative feedback idea  
✅ sequence / cycles

但缺：

❌ 明确定义的 stock  
❌ flow rate  
❌ 单位  
❌ time delay  
❌ equation  
❌ parameter  
❌ calibrated state variable

因此五行最多可以：

> **被重构成 system-dynamics-inspired qualitative causal map**

不能直接说：

> 五行本身就是 System Dynamics。

### 判定
**PARTIAL STRUCTURAL ANALOGY**

---

# 10｜“循环” ≠ “反馈”

这是 R6 一个重要纠偏。

一个图形成：

A→B→C→A

只能说明：

> 存在 directed cycle。

要叫 feedback，还需要：

> 后面的状态变化反过来影响前面的状态变化。

也就是说：

## cycle
拓扑结构

## feedback
动力机制

二者不能混。

五行显然有 cycle。

后期某些制化 / 胜复解释具有 feedback-like meaning。

但：

> 不是所有五行环都自动等于反馈控制环。

---

# 11｜五行 × Dynamical Systems｜WEAK UNTIL FORMALIZED

数学意义的 dynamical system 至少需要：

1. **State space｜状态空间**
2. **Time｜时间**
3. **Evolution rule｜演化规则**

例如：

x(t+1) = F(x(t))

或者连续模型：

dx/dt = f(x)

五行传统目前只能给出：

- 五个关系类别
- 生克拓扑
- 一些顺序 / 循环
- 某些异常状态

它没有自动定义：

> 在状态 S(t) 下，下一时刻 S(t+1) 精确是什么。

### 所以

五行：

> 不是天然数学 dynamical system。

但可以被进一步形式化成：

> discrete-state dynamical model

前提是研究者新增：

- state variables
- transition functions
- timing
- strength
- initial conditions
- stochastic/deterministic rules

### 判定
**FORMALIZATION POTENTIAL**

---

# 12｜五行 × “动态平衡”也要谨慎

“动态平衡”很容易听起来特别现代。

五行/医学确实有：

- 生克并存
- 太过不及
- 制化
- 胜复

所以可以说：

> 具有 dynamic balance / regulation 的思想结构。

但是现代 stability / equilibrium 有严格数学意义，例如：

- equilibrium point
- attractor
- asymptotic stability
- perturbation response

传统五行没有自动给出这些数学定义。

### 判定

**PHILOSOPHICAL / QUALITATIVE BALANCE**

≠

**MATHEMATICAL STABILITY**

---

# 13｜五行 × Relational Ontology｜只能谨慎类比

五行有一个很强特征：

一个“木”不仅靠自身属性定义，
还依赖：

- 谁生它
- 它生谁
- 谁克它
- 它克谁
- 它处在哪个时序 / 方位

所以：

> 一个节点的意义部分来自其关系位置。

这确实具有 relational character。

---

# 14｜但不能直接升级成“关系本体论”

现代 relational ontology / structural realism 可能提出非常强的哲学主张：

> 关系 / 结构在本体论上比对象更基础。

甚至某些 Ontic Structural Realism 版本会认为：

> structure / relations 比 individual objects 更根本。

五行传统未必做这么强的主张。

它仍然谈：
- 木
- 火
- 土
- 金
- 水
- 气
- 物
- 人
- 天地

因此：

> 五行具有关系性 ≠ 五行支持现代强关系本体论。

### 判定
**RELATIONAL CHARACTER: SUPPORTED**
**RELATIONAL ONTOLOGY IDENTITY: OVERREACH**

---

# 15｜五行 × Structural Realism｜弱类比

Structural Realism 在现代科学哲学里讨论：

> 科学真正把握的是否主要是结构 / 关系，而不是对象的内在本性。

五行的生克图确实：

> 高度依赖关系结构。

但五行不是：

- 对现代物理理论的解释
- 科学理论连续性问题
- 对实体实在性的哲学回应

所以：

> “五行具有结构优先倾向”

可以作为很弱的比较。

> “五行就是 structural realism”

不成立。

### 判定
**WEAK ANALOGY / DO NOT CLAIM IDENTITY**

---

# 16｜五行 × Classification / Ontology Representation｜MEDIUM

现代知识表示会区分：

- class
- instance
- property
- relation
- function
- temporal relation

五行传统做的一部分工作确实很像：

> 把现象压缩到五个 class，再定义 class-to-class relation。

例如：

对象 A  
→ 分类为木

对象 B  
→ 分类为火

系统再调用：

木生火

### 这里非常适合现代知识表示

可以重写成：

Entity  
→ hasPhase / classifiedAs  
→ WuxingClass

WuxingClass A  
→ generates / constrains  
→ WuxingClass B

### 最大问题

R4 已经说了：

> classification rule 必须独立、固定。

否则：

任何对象都可以事后改类。

因此形式化分类最关键的不是画 ontology 图，而是：

> **定义 membership criterion。**

---

# 17｜五行 × Causal Loop Diagram｜可画，但不能自动叫 causal

System Dynamics 的 causal loop diagram 会：

- 用箭头表示变量影响
- 用 + / − 表示方向
- 形成 reinforcing / balancing loop

五行完全可以被画成类似 CLD。

但问题是：

> 五行里的“生 / 克”是否真的已经通过数据证明是 causal effect？

答案：

> 不能一概而论。

所以最稳妥叫：

> **RELATIONAL LOOP DIAGRAM**

而不是：

> causal loop diagram

除非某个具体领域的边已经有独立因果证据。

---

# 18｜R6 最重要的“升级阶梯”

我们现在可以把五行从传统语言往现代模型升级分成 6 层：

## F0｜TRADITIONAL DESCRIPTION
木火土金水 + 生克

↓

## F1｜RELATIONAL SCHEMA
节点 + 有向关系

↓

## F2｜SIGNED DIRECTED GRAPH
正 / 负、有向边

↓

## F3｜QUALITATIVE SYSTEM MODEL
加入：
- 状态
- 强弱
- feedback-like loop
- context

↓

## F4｜FORMAL DYNAMICAL MODEL
加入：
- state space
- transition function
- time
- parameter
- initial condition

↓

## F5｜EMPIRICALLY CALIBRATED MODEL
加入：
- 数据
- parameter fitting
- prediction
- holdout test
- external validation

### 关键

传统五行本身主要稳定落在：

> F0–F2

部分现代重构尝试进入：

> F3

要到 F4–F5：
> 必须新增大量现代形式化和外部验证。

# 19｜R6 可比 / 不可比矩阵

| 现代理论 | 五行可比点 | 不能冒充的部分 | 评级 |
|---|---|---|---|
| Process Philosophy | 变化/过程优先、动态相互作用 | 不等于 Whitehead 等具体体系 | STRONG |
| Relations | 有方向、非对称关系 | 不代表完整现代关系形而上学 | STRONG |
| Signed Directed Graph | 五节点 + 生/克正负有向边 | 图结构不证明边真实 | VERY STRONG FORMAL |
| Network Theory | 节点、边、cycle、role | 不自动拥有网络实证指标 | STRONG FORMAL |
| Systems Thinking | 整体、循环、相互制约 | 不等于 General Systems Theory | MEDIUM |
| Feedback | 制化/胜复有调节相似 | 无现代控制器/误差信号定义 | MEDIUM |
| System Dynamics | loop / qualitative influence | 缺 stock/flow/delay/equation | WEAK–MEDIUM |
| Dynamical Systems | 可扩成状态转移 | 原系统无 state-space/evolution function | WEAK UNTIL FORMALIZED |
| Relational Ontology | 节点意义部分来自关系 | 未证明关系本体优先 | WEAK–MEDIUM |
| Structural Realism | 结构关系重要 | 不是现代科学实在论命题 | WEAK |
| Knowledge Representation | class + relation 非常适合编码 | membership rule 必须固定 | MEDIUM–STRONG |

# 20｜R6 最关键的现代形式化原则

如果未来有人想“现代化五行”，顺序不能直接跳到方程。

应该：

### STEP 1
先固定节点 / 类别定义。

### STEP 2
固定 relation type：
- enabling
- constraining

### STEP 3
固定方向。

### STEP 4
确认每条 edge 的语义：
- causal?
- functional?
- correlational?
- symbolic?

### STEP 5
才允许加：
- strength
- state
- context

### STEP 6
再定义：
- transition rule
- time
- feedback
- parameter

### STEP 7
最后才是：
- prediction
- data validation

这样可以避免：

> 画一张漂亮系统图 → 直接宣称发现自然规律。

# 22｜R6 一个非常重要的结论

现代理论给五行最大的帮助，不是：

> 给古代理论“科学认证”。

而是：

> **帮助我们把五行中混在一起的东西拆开。**

现代语言可以分别标：

- class
- node
- relation
- direction
- sign
- state
- weight
- path
- cycle
- feedback
- trajectory
- transition rule

一旦拆开，就能问：

> 哪些是传统五行本来就有？
> 哪些是现代重述？
> 哪些是新模型自己新增？

这正是 R7 审十元需要的工具。
