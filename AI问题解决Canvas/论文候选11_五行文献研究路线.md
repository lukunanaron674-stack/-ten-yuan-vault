# 候选 11｜五行文献研究路线｜十元的来源合法性与增量验证

> 服务对象：论文候选 11「结构化创作意图对真实创作决策具有预测价值」
>
> 状态：RESEARCH REQUIRED / TOPIC NOT FROZEN

## 0｜这个方向真正的两道生死门

### 门 1｜增量门
十元 / 动态链必须证明：

> **比普通自然语言表达创作意图更有预测价值。**

不能只证明：
- 更复杂；
- 更像理论；
- 能解释；
- 自己用起来顺手。

必须比较：

A｜普通自然语言意图  
B｜通用结构化字段（关系 / 优先级 / 理由 / 动态轨迹，不使用十元）  
C｜十元 / 生克补 / 动态链

然后预测真实：
ACCEPT / REWORK / REJECT。

如果 C 不优于 B，就只能说明“结构化有用”，不能说明“十元额外有用”。

---

### 门 2｜自产自证门

最大风险：

> 我自己定义十元 → 用十元解释自己的《方志敏》 → 解释得很好 → 宣称十元有效。

这属于 post-hoc rationalization。

必须切断：

1. 《方志敏》只做开发集 / 内部验证；
2. 规则先冻结；
3. 预测先提交；
4. 最终选择后揭盲；
5. 再换第二创作者自己的项目做外部验证。

---

# 1｜为什么必须研究五行论文

十元如果声明与五行有关，就至少要回答四件事：

### Q1｜五行到底是什么
是“五种物质”，还是“五种过程 / phase / process”？

现代学术常提醒：wuxing 更适合理解为 Five Phases / Five Processes，而不是现代意义的五种物质元素。

### Q2｜五行中的关系到底是什么
需要核对：
- 生
- 克
- 制化
- 是否单向 / 双向
- 循环关系
- 关系是否有方向、强弱、条件

### Q3｜五行原本是描述什么
要区分：
- 分类体系
- 关联宇宙论 / correlative cosmology
- 动态过程模型
- 规范性解释
- 因果解释

不能把“关联”直接冒充现代因果。

### Q4｜十元到底继承了什么、改造了什么
最后必须形成表：

五行原概念  
→ 文献中的定义  
→ 十元采用部分  
→ 十元改造部分  
→ 新增部分  
→ 不再声称属于传统五行的部分

这样才能防止“自己定义完再说古人本来就这样”。

# 2｜五行文献必须分四类读

## A｜思想史 / 哲学基础
目的：搞清楚五行不是你想象中的什么，而是学界怎样解释它。

重点关键词：
- 五行 / Five Phases / Five Processes
- correlative cosmology
- process
- relation
- change
- 感应
- 类 / 分类

## B｜生克关系与形式化
目的：研究关系有没有被严格定义过。

重点：
- 生克次序
- 有向关系
- 循环
- 相容性 / 完整性
- 公理化
- signed directed graph

现代已有把五行画成“节点 + 有向正负关系”的论文，也有中文论文尝试把五行生克做公理化。

## C｜现代关系 / 系统 / 过程解释
目的：看五行是否真的可作为关系结构、动态过程的启发来源。

关注：
- relational thinking
- process view
- dynamic balance
- enabling / constraining ties
- network graph

## D｜批判文献
这一类**必须读**，不能只找支持十元的。

重点问题：
- 五行是否只是后设关联体系？
- 是否存在过度类比？
- 是否缺少经验可证伪性？
- 生克是否被人为调适后总能解释？
- 从相关 / 对应跳到因果是否合理？

候选 11 必须主动吸收这些批评，因为它们和“自产自证”风险是同一个问题。

# 3｜当前已经找到的几个重要外部支点

### ① 五行更像“过程 / phases”而不是静态物质
Internet Encyclopedia of Philosophy 将 wuxing 描述为动态、相互依赖的 processes / phases，而不是类似古希腊不可变元素的东西。

这支持十元研究“关系和变化”，但只支持思想谱系，不支持十元有效性。

### ② 五行的核心之一确实是互动与变化
关于 correlative cosmology 的学术研究指出，五行不只是分类，也涉及持续的生成 / 制约关系与变化过程。

### ③ 已有人把五行形式化为有向关系网络
Wang & Zhang (2020) 将 five-phase system 描述为由五个节点和 signed / directed ties 构成的网络型图，并区分 enabling 与 constraining relations。

这对“十元不是凭空发明关系图”非常重要。

### ④ 已有中文五行公理化尝试
陈瑞祥 2014《五行公理系统的生克关系——五行理论体系的系统化（二）》使用有序偶、圆周模型等尝试定义生克关系、次序与唯一性。

这可以作为“传统关系被形式化”的参考，但不能因此证明这种体系对创作有效。

### ⑤ 学界内部本来就有强烈批判
IEP 记录荀子、王充等对五行扩展解释的批判；现代也有论文直接质疑五行概念的逻辑和经验价值。

这不是坏事，反而是候选 11 必须正面处理的材料：

> **如果一种关系体系总能在事后调节到解释任何结果，它就没有预测价值。**

# 4｜候选 11 最终应该拆成三个彼此独立的主张

## Claim A｜历史 / 理论来源主张
> 十元的关系思想是否可以合理追溯到五行的“过程、生成、制约、循环关系”传统？

证据：文献。

这只能证明“来源有谱系”。

---

## Claim B｜表示能力主张
> 十元是否比普通自然语言，更清楚、更稳定地表示 Relation / Priority / Rationale / Dynamic Trace？

证据：
- 标注一致性
- 信息丢失率
- 跨模型解析一致性
- 使用者理解度

这证明“表示得好不好”。

---

## Claim C｜预测价值主张
> 十元结构化意图是否比自然语言或通用结构化字段，更能预测真实创作者的 ACCEPT / REWORK / REJECT？

证据：
- 先预测后揭盲
- 留出集
- 第二创作者自己的项目
- 与 A/B 基线比较

**这是最重要的一关。**

只有 C 过了，才能真正说它对 AI 理解用户创作意图有增量价值。

---

# 5｜最关键的对照不能只有“自然语言 vs 十元”

为了避免“结构化天然比随手写一段话好”的伪结论，至少要三组：

### NL｜普通自然语言
创作者原始说明。

### STRUCT｜通用结构化意图
只用：
- Relation
- Priority
- Rationale
- Dynamic Trace
- LOCK / FLEX

但**不用十元**。

### TEN｜十元结构化意图
在 STRUCT 基础上加入：
- 十元类别
- 生 / 克 / 补
- 主次
- 强度
- 动态链

真正问题是：

> **TEN 是否比 STRUCT 仍然有额外增量？**

如果只赢 NL、不赢 STRUCT：

结论应该是：

> “结构化创作意图有价值，但暂未证明十元本身有额外价值。”

这个结论依然很有价值，而且更可信。

---

# 6｜五行研究对论文方向真正的作用

五行论文不是拿来“证明十元是对的”。

它有三个作用：

1. **来源审计**：十元到底继承了什么，避免伪传统；
2. **结构启发**：关系、过程、生成/制约等哪些思想值得转成现代表示；
3. **批判约束**：直接吸收历史和现代对五行“过度解释、不可证伪”的批评，反过来设计预测实验。

一句话：

> **研究五行，不是给十元找祖宗背书；是把十元放进一个可以被批评、比较和证伪的学术谱系里。**

# 7｜下一步建议轮次

## R1｜五行概念史
五行是什么？phase/process/classification/correlation 的学术定义。

## R2｜生克关系谱系
生、克、制化、乘侮、方向、循环、条件到底怎么被定义。

## R3｜形式化与现代转译
找 graph / system / relational / process 的现代表示。

## R4｜批判与失败
找“过度类比 / 不可证伪 / 相关非因果 / 任意配属”的批评。

## R5｜五行 → 十元来源审计
逐项标：
- inherited
- transformed
- newly introduced
- unsupported

## R6｜实验设计
NL vs STRUCT vs TEN，内部 + 外部创作者预测实验。

# 8｜当前方向的真正风险评级

- 五行来源被误读：HIGH
- 十元自产自证：VERY HIGH
- 只证明结构化有用、没证明十元有用：VERY HIGH
- 事后解释冒充预测：VERY HIGH
- 第二创作者验证不足：HIGH
- 论文 5000 字范围失控：HIGH

因此这条线能不能成为最终论文，不取决于它“听起来多厉害”，而取决于上面这些风险能不能被实验设计压住。
