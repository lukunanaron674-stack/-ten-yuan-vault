# 论文同辈研究地图｜R4 2025–2026 最新方向雷达

> 状态：R4 DONE / EXPLORE
> 目标：识别最新研究方向，不替用户选题。
> 证据分层：A = 同行评议会议/期刊；B = 高校毕业展/教学方向；C = 行业信号。
> 本轮“最新”指2025–2026明显升温或发生结构变化，而不等同于“最适合本科论文”。

## 1｜T1 从“AI工具应用”转向“创作流程重构”

中国动画研究已经不再只问“AI能不能做动画”，而开始研究：
- 传统线性流程如何被重写
- 人与AI如何反复迭代
- 小团队怎样承担原本分散的岗位

《从“瀑布式”到“协同迭代式”：生成式人工智能对动画创作流程的重构》直接把研究单位从某个软件提升到整个动画生产流程。

趋势强度：★★★★★
成熟度：★★★★☆
同辈拥挤度：中

关键词：workflow / pipeline / iteration / human-AI production

## 2｜T2 从“单张好看”转向“连续资产一致性”

ICCV 2025 的 CharaConsist研究角色在不同动作、不同场景中的身份和服装细节一致性，并同时处理前景角色与背景。

ICCV Workshops 2025 的 Narrative Graph Prompting把角色、场景、道具的固定属性放入中央图结构，再生成场景级prompt以减少visual drift。

变化：
以前问“这一张生成得像不像？”
现在开始问“角色换动作、换场景之后，还能不能属于同一角色/同一视觉世界？”

趋势强度：★★★★★
成熟度：★★★★☆
同辈本科拥挤度：低—中

关键词：consistency / identity preservation / visual drift / reference consistency

## 3｜T3 从“Prompt技巧”转向“结构化控制”

2025 Narrative Graph Prompting使用结构化图保存角色、场景、对象的固定属性。
2026关于生成艺术的人机协作研究开始使用结构化prompt-engineering和可量化迭代评价。

变化：
Prompt不再只是“一段写得更漂亮的描述”，而开始变成：
- 可分层
- 可复用
- 有固定属性
- 能被系统调用的控制结构

趋势强度：★★★★☆
成熟度：★★★☆☆
同辈本科拥挤度：低

关键词：structured prompting / graph prompting / design constraints / reusable rules

## 4｜T4 从“AI辅助创作”转向“人机协同机制”

2026视觉传达设计研究开始明确提出：
- interpretable intent
- controllable generation
- iterable result
- preservable subject

并把学生、AI系统、设计知识库放进同一协作模型。

同年人机协作研究不再只比较“用AI/不用AI”，而开始比较Standard与Collaborative两种交互模式。

变化：
问题从“AI帮我做多少？”
变成“谁在什么时候做什么决定？创作者如何保留控制权？”

趋势强度：★★★★★
成熟度：★★★☆☆
同辈本科拥挤度：低—中

关键词：human-AI collaboration / co-creation / control / iterative feedback

## 5｜T5 从“风格化”转向“可控风格与设计意图对齐”

2026 Scientific Reports 的视觉传达图像生成研究把两个核心挑战直接定义为：
- design requirement alignment不足
- style controllability不稳定

另一项2026视觉设计研究开始把文本、手绘草图、空间布局、brand guidelines等多种设计意图联合输入。

变化：
以前问“能不能生成某种风格？”
现在问“能不能按设计师意图稳定控制风格，而且不破坏内容？”

趋势强度：★★★★☆
成熟度：★★★☆☆
同辈本科拥挤度：低

关键词：style controllability / design intent / multimodal constraints

## 6｜T6 从“生成结果”转向“评价系统”

ICCV 2025 ICE-Bench不再用一个分数概括图像，而是同时评：
- aesthetic quality
- imaging quality
- prompt following
- source consistency
- reference consistency
- controllability

变化：
研究重点开始从“模型会生成”转向“怎样证明生成结果满足真实设计任务？”

趋势强度：★★★★☆
成熟度：★★★★☆
同辈本科拥挤度：低

关键词：evaluation / reference consistency / controllability / multidimensional metrics

## 7｜T7 AI动画微短剧从“奇观”转向“工业美学与叙事机制”

《未来传播》2025已经讨论中国AI动画微短剧的人机协作、叙事分野和潜在互动，并指出现有作品仍有影像断裂、情节单一、表演僵化等问题。

2026相关国产动画研究进一步讨论“人机共生与影像重组”“算法美学”。

变化：
AI短片不再只是“做出来很新”，而开始进入：
- 类型化
- 叙事
- 工业生产
- 算法审美
的研究阶段。

趋势强度：★★★★★
成熟度：★★★☆☆
同辈拥挤度：快速上升

关键词：AI animation micro-drama / industrial aesthetics / algorithmic aesthetics

## 8｜T8 从“单工具”转向“复合生产体系”

2026数媒毕业展和教学方向开始把：
AIGC影视创作 + 虚拟拍摄 + 实时引擎 + 影游融合
放进同一生产体系。

这不是一个单独算法问题，而是媒介生产结构变化。

趋势强度：★★★★☆
成熟度：★★★☆☆
本科实践热度：高
理论研究拥挤度：中低

## 9｜R4最重要的横向变化

2024–2026可以粗略概括为：

**工具 → 作品 → 流程 → 控制 → 协同 → 系统**

最前沿的问题已经不只是“AI能生成什么”，而是：
- 怎样保持一致
- 怎样让创作者控制
- 怎样把规则复用
- 怎样评价
- 怎样形成稳定生产体系

这只是趋势地图，不是选题推荐。

## 10｜需要警惕的“伪新方向”

以下题目即使写着“AIGC”，研究问题也可能并不新：
- AIGC赋能某非遗
- AI助力某传统文化
- AI生成某IP
- 某AI软件在某作品中的应用

如果研究结构仍然只是“介绍工具→做作品→展示效果”，新的是工具/题材，不一定是研究问题。

## 11｜R5入口

R5开始专门做：**高重复方向 / 拥挤区识别。**

不是凭印象，而是把R1–R4出现频率高、结构高度相似的题目聚在一起，判断哪些方向已经很难仅靠“换一个案例”形成新意。
