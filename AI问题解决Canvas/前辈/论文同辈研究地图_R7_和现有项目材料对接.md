# R7｜哪些方向刚好能用我手上的东西？｜速读版

> 用途：不是选题，只看“哪个方向我已经有现成材料，不用从零开始”。
> 依据：仓库里现有《黎黎隆》角色/场景/问题系统/H3测试、方志敏动画分镜与生成记录、现有论文实验草案。

## 先看结论

你现在手上的材料，最适合接的不是“再做一个新作品”，而是这几类：

1. **角色怎么一直像**
2. **角色和场景怎么一直是一套**
3. **自己的画画要求怎么整理给AI**
4. **AI图怎么判断合不合格**
5. **怎么从一张好图变成一批稳定资产**
6. **AI动画/视频最容易在哪些地方跑偏**
7. **人和AI到底怎么分工**

这些你已经有不少真实案例、失败记录、修正过程，不需要凭空造实验。

## 1｜角色怎么一直像
【你手上已经有什么】

《黎黎隆》已经有：
- 多个角色
- 头像
- 四宫格
- 中景/中全景扩展
- 角色卡
- 角色一致性相关问题
- H3参考卡
- 批量角色生产任务

仓库里甚至已经有：
“头像怎么稳定扩中全景”
和
“角色一致性出图：9:16 四格 H3 参考卡”
这类现成问题。

【可以拿来干嘛】

不用重新造案例，直接拿现有角色看：
头像 → 半身 → 中全景 → 动作图
到底从哪一步开始不像。

【额外成本】★☆☆☆☆

【现成材料匹配】★★★★★

## 2｜角色和场景怎么一直像同一个世界
【你手上已经有什么】

《黎黎隆》项目已经不是单角色实验了，仓库里有：
- 世界观
- 角色库
- 场景图包
- 故事层
- 分镜/镜头
- H3视频生产
- 资产版本管理

- 角色单看好不好
- 场景单看好不好
- 两个放一起还像不像一个项目
- 换场景以后角色风格会不会跑

【额外成本】★★☆☆☆

## 3｜自己的画画要求，怎么整理给AI
【你手上已经有什么】

你已经有很多不是“随口一句提示词”的东西：
- 角色卡
- 场景规则
- 画风规则
- 描述词库
- 锁定项/可发散项
- 角色身份与世界位置
- 审核规则
- 参考图职责
- 不同版本冲突处理

这些其实已经是“把脑子里的要求写出来”的材料。

【可以拿来干嘛】

不用重新发明方法。
直接挑一小段现有规则，看：
“乱写一段” 和 “整理后再给AI”
结果差多少。

【额外成本】★★☆☆☆

【现成材料匹配】★★★★★

## 4｜AI图怎么判断合不合格
【你手上已经有什么】

你已经做过很多：
- PASS / FAIL
- 用户审核
- 反例
- 候选图
- 锁卡
- 头像审核
- 角色身份是否跑偏
- 场景/镜头是否符合要求

《黎黎隆》问题系统本身就是：
问题 → 实验 → 任务 → 结果 → 结论 → 锁卡。

【可以拿来干嘛】

直接把你平时“这张不行”的原因整理出来：
- 脸变了
- 身份变了
- 风格碎了
- 场景不统一
- 参考图带错东西
- 动作跑了

然后变成一张特别简单的检查表。

【额外成本】★☆☆☆☆

【现成材料匹配】★★★★★
