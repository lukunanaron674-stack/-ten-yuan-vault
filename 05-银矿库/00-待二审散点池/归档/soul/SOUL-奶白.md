# 三元理论 · 核心框架

---

## 第一层：Z/X/N

共性概念。给万事万物下定义，是归类定义。

| 符号 | 含义 | 本质 |
|------|------|------|
| **x**（阴水） | 欲望、贪婪、深层渴求 | 想要得到 |
| **z**（阴火） | 执念、张扬、被看见的渴望 | 想要被承认 |
| **n**（阳土） | 稳定、承载、包裹 | 想要留住 |

**三元互动法则：**
- x+z = 撕裂
- z+n = 收敛
- x+n = 沉溺
- x+z+n 同时到位 = 完整张力结构

---

## 第二层：十元

共性概念。十元是3元的下一步划分，诞生于阴阳五行相生相克相补。

**N链条（相生）：**
n → nz → nx → x → x并z → n

**X链条（相克）：**
xz → zx → zn → n → xn → xz

**Z关系（互补）：**
zx ↔ nx | zn ↔ x | xz ↔ nz | z ↔ xn | n ↔ x并z

**十元与五行：**
| 十元 | 五行 | 七情 |
|------|------|------|
| ZX | 木 | 怒 |
| ZN | 火 | 喜 |
| n | 土 | 思 |
| xn | 金 | 哀/忧 |
| XZ | 水 | 恐 |
| nz | 土过渡 | 柔 |
| nx | 金过渡 | 算计 |
| x | 水底层 | 欲 |
| x并z | 木过渡 | 包装 |
| z | 火底层 | 执念 |

## 第三层：五维

感觉分类坐标。五维是对五行的进一步深化，把符号关系落到故事维度上。

| 维度 | 公式 | 五行 | 感觉关键词 |
|------|------|------|-----------|
| **时间** | xn+z | 木 | 节拍、时机、倒计时、临界点爆点 |
| **本体** | zn+x | 火 | 内核燃烧、存在驱动、精神燃料 |
| **空间** | x并z+n | 土 | 容器、场域、可进入的结构、停留之地 |
| **因果** | zx+nx | 金 | 局势、博弈、事件结算、暗流推动 |
| **命运** | xz+nz | 水 | 漂流、遭遇、归宿、依恋与警觉 |

**五维生克链：**
木→火→土→金→水→木
相克：木克土 → 土克水 → 水克火 → 火克金 → 金克木

**时间克命运，命运克本体，本体克时间——生克链条贯穿五维。**
