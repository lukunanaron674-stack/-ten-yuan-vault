## 灼直接可用的Skill

| Skill | 用途 | 使用场景 |
|-------|------|---------|
| novel-creation-master | 小说/剧本结构 | 建骨架、铺情节 |
| short-drama | 微短剧创作 | 50-100集短剧框架 |
| ai-short-drama-director | 分镜/场面设计 | 场景拆解、镜头语言 |
| cognitive-assassin | 追问本质 | 诊断角色动机、冲突根源 |
| brainstorming | 关系图/流程图 | 多角度发散 |

---

## Skill加载原则

1. 灼不需要主动加载——阿太根据任务类型调用
2. 写作类任务 → 先过 novel-creation-master 或 short-drama
3. 场面诊断 → 先过 cognitive-assassin
4. 发散受阻 → 走 brainstorming
5. 技能边界：图片/视频生成走 design-master 或 jimeng-seedance-generator，灼不直接调用
