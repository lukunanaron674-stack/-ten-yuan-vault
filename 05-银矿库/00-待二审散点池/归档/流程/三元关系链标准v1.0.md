# 鉴 · 三元关系链标准 v1.0

> 来源：奶白指令
> 日期：2026-04-12（v2：新增相生）
> 分发：典/霜/钧

---

## 奶白的要求

每个原型档案必须包含三元关系链，格式如下：

**克制了什么：** 本原型克制哪个原型/角色/事（用相克链验证）
**被什么克制：** 什么克制本原型（用相克链验证）
**与谁互补：** 本原型和谁互补（用互补配对验证）
**相生什么：** 本原型催生什么/被什么催生（用相生链验证）

---

## 十元相生链（顺时针隔一格）

**阳链（事业层）：**
ZX → 生 → ZN → 生 → N → 生 → xn → 生 → XZ → 生 → ZX

**阴链（欲望层）：**
x并z → 生 → z → 生 → nz → 生 → nx → 生 → x → 生 → x并z

---

## 十元相克链（逆时针隔一格）

**阳链：**
XZ → 克 → ZN → 克 → xn → 克 → ZX → 克 → N → 克 → XZ

**阴链：**
x → 克 → z → 克 → nx → 克 → x并z → 克 → nz → 克 → x

---

## 十元互补配对（直径）

```
ZX ↔ nx
ZN ↔ x
N ↔ x并z
xn ↔ z
XZ ↔ nz
```

## 典的更新要求

典产出每个原型时，必须包含：

```markdown
## 三元关系链

**克制：** [克制了什么]
**被克制：** [被什么克制]
**互补：** [与谁互补（直径配对）]
**相生：** [催生什么/被什么催生]
```

---

## 霜的更新要求

霜在写框架时，每个维度/亚形态都要标注三元关系链。
霜的框架不只有结构，还要有：克制/被克制/互补/相生的力在哪里传导。

---

## 钧的更新要求

钧评分时，新增一条检验标准：

**5. 三元关系链是否完整？**

- 原型是否有明确的克制对象？
- 原型是否被明确的力克制？
- 原型是否有互补配对？
- 原型是否有相生关系？

这一项不单独计分，但影响"克制关系不可替换"的判断。

---

## 执行

此文件生效后，典所有新产出必须包含三元关系链（含相生）。
霜在下一版框架文件里更新。
钧即刻起在评分里执行此标准。
