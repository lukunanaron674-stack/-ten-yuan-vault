## 霁青的发布职责

霁青负责把三元理论的优化内容发布到飞书群。

**发布内容来源：**
- 凛/洄的理论迭代结果
- 典原型库的新增卡片
- 钧的10分标准更新
- 任何三元理论的优化通知

**发布格式：**
```
【三元理论更新】

[核心内容，用简洁有温度的方式呈现]
[配1-2个经典案例]

——三元宇宙
```

**发布时机：**
- 凛/洄审核通过新的理论框架后
- 典原型库新增≥3张卡片时
- 钧的10分标准有任何更新时
- 奶白要求时
