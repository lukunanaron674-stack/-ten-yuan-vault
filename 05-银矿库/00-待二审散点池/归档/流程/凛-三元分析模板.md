# 凛 · 三元分析模板

> 凛(NX) · 三元理论分析输出格式
> 版本：v1.0
> 日期：2026-04-11

---

## 使用说明

凛完成三元理论分析后，套用此模板输出结构化结论。
灼直接读取【灼的使用建议】部分，无需解读分析过程。

---

## 模板

```
【三元分析结论单】

案例名：
维度：[五维之一]
三元归属（主）：[主角色名]：[X/N/Z属性]
三元归属（次）：[次角色名]：[X/N/Z属性]
克制关系：[谁克制谁，克制关系描述]
力结构：[力在节点间的流动路径，一句话]
核心洞察：[凛追问出的本质判断，一句话]
可复用点：[其他故事可以怎么用]

━━━━━━━━━━━━━━━━━
【灼的使用建议】

适用维度：[五维之一]
这个故事的三元结构核心是：[一句话]
灼在写场面时可以抓住的点是：[具体场面建议，2-3条]
推荐配对的原型库原型：[原型编号和名称]
```

---

## 示例（套用《2046》）

```
【三元分析结论单】

案例名：2046
维度：本体型 zn+x
三元归属（主）：周慕云：XN（主动型）
三元归属（次）：苏丽珍：NZ
克制关系：X（重写过去）克制 N（2046房间/时间），N困住了X
力结构：Z在N里永远燃烧，X不可得，力在封闭空间里空转
核心洞察：周慕云的本质不是记忆，是"重写"——他想让历史按他的写法走
可复用点：所有"试图改变已发生事件"的故事，都可以用这个结构

━━━━━━━━━━━━━━━━━
【灼的使用建议】

适用维度：本体型 zn+x
这个故事的三元结构核心是：封闭空间困住了不可实现的欲望，力在燃烧中空转
灼在写场面时可以抓住的点是：
1. 周慕云在房间里写字，笔是ZX，纸是N——他写的每一个字都在试图冲破封闭
2. 苏丽珍的存在是NZ——她不张扬，但她是唯一能容纳周慕云的N
3. 结尾的呼应：开头他在写，结尾他还在写——什么都没改变，但他还在烧
推荐配对的原型库原型：001-重写困徒 / 003-X不可得者
```
