## 两种自动化

### 时间自动化

按时触发。跑完就停。等下一次触发条件。

例如：钧的批次巡查提醒、囷霜的收集报告、凛的定期审视。

触发条件 → 执行 → 输出 → 停

### 因果自动化

一直跑到结果出来，中间不停。

结果只有两种停法：
1. **结果到了**——你收到了想要的结果，流程闭环
2. **你说不要了**——"不要了，我不想知道结果"，流程强制停止

中间每一个节点都是因果链：这一步不出结果，下一步就不动。上游不到，下游不跑。

触发条件 → 执行 → 出结果？→ 没出结果就继续 → 结果到了或你说停 → 停

## 霜·灼写作链（因果自动化）

这是一条完整的从任务到结果的链。奶白不说"开始"，只等结果。

### 霜确认框架（触发点）

霜收到钧的评分（≥8.0）。
霜确认"这个框架可以写"。
→ 霜自动生成任务文件：`/workspace/三元宇宙/灼任务/框架B-他等的那个人不会来了.md`

任务文件包含：
- 框架内容（核心三元、克制关系、结尾设计）
- 情绪方向提示（冲写哪里，慢写哪里）
- 字数要求（2000-3000字）
- 截止：无（因果自动化不到结果不停）

### 灼读取任务（自动）

灼持续监控任务目录。
发现新任务文件 → 自动读取 → 开始执行。
灼不说话，不问，直接写。

灼的工作流：
```
冲：砸初稿（框架B的核心场面：男的zx冲动、女的不来）
慢：填空白（他们之间那些没说出口的时刻）
灼：收回三稿，剪裁定稿
```

### 霜架构审核（自动）

灼写完 → 霜读取定稿 → 霜判断框架是否被忠实执行。
→ 通过：发给钧评分
→ 不通过：返回灼修订（不超过2次）

### 钧评分（自动）

霜通过 → 钧读取 → 评分+评语。
≥8.0 → 归档，流程完成
<8.0 → 返回霜修订

### 奶白收到结果

鉴在流程完成时，向奶白发送通知：
"因果自动化完成：框架B → 故事已写完，钧评分X分，文件在 [路径]"

---

### 触发点总结

| 节点 | 触发条件 | 执行者 |
|------|---------|-------|
| 霜→灼 | 霜确认框架，钧评分≥8.0 | 霜自动生成任务文件 |
| 灼→霜 | 灼完成定稿 | 灼自动推送霜审核 |
| 霜→钧 | 霜审核通过 | 霜自动推送钧评分 |
| 钧→囷霜 | 钧评分≥8.0 | 钧自动通知归档 |
| 鉴→奶白 | 流程完成 | 鉴自动通知 |

**奶白全程不需要触发，只说"不要了"才能停。**

## 各角色因果自动化流程

### 凛 · 框架评判流程

```
霜提出框架
    ↓
钧收到，评判打分
    ↓
霜确认 → 得分≥8.0 → 任务分配灼
    ↓ 得分<8.0
霜修订框架 → 重新评判
    ↓
流程继续，直到分数达标或者奶白说"不要这个方向了"
```

**停的条件：**
- 分数达标，任务已分配 → 因果完成，自动停
- 奶白说"不要这个框架了" → 强制停
- 霜修订超过3次 → 通知奶白，请判断是否继续

### 灼 · 故事写作流程

```
霜分配任务（框架+情绪方向）
    ↓
灼给骨架 → 冲砸初稿
    ↓
慢填空白
    ↓
灼收回三稿，剪裁定稿
    ↓
霜架构审核
    ↓ 通过 → 钧评分
    ↓ 不通过 → 灼修订
    ↓
流程继续，直到霜通过，钧评分
奶白说"不要这个故事了" → 强制停
```

**停的条件：**
- 钧评分完成 → 因果完成，自动停
- 奶白说"不要这个故事了" → 强制停
- 霜修订超过2次仍不通过 → 通知奶白，请判断是否继续

### 钧 · 评分流程

```
收到霜的分析文档
    ↓
打分+评语
    ↓
≥8.5 → 通知囷霜：高质量案例优先归档
    ↓
<8.5 → 普通归档
    ↓
流程继续，直到所有待评判案例处理完毕
```

**停的条件：**
- 待评判队列清空 → 因果完成，自动停
- 奶白说"停止评判" → 强制停

### 囷霜 · 归档流程

```
收到新素材
    ↓
分类+标签
    ↓
凛框架更新？→ 是 → 对照修订 → 否 → 直接归档
    ↓
归档完成，更新清单
    ↓
奶白收到归档通知
    ↓
流程继续，直到归档清单无积压
```

**停的条件：**
- 无积压 → 因果完成，自动停
- 奶白说"停止归档" → 强制停

## 两种停法的区别

| 类型 | 停条件 |
|------|--------|
| 时间自动化 | 时间到就跑，跑完就停 |
| 因果自动化 | 结果到了才停，或者你说不要 |

**因果自动化的本质：**
不给你中间商赚差价的机会。
流程没有情绪，不偷懒，不会在"差不多就行了"的地方停下来。
只有两个停止开关：结果到了，或者你说不要了。
