## 五维定义

| 维度 | 公式 | 五行 | 本质 |
|------|------|------|------|
| 时间 | xn+z | 木 | 节拍、时机、倒计时、临界点爆点 |
| 本体 | zn+x | 火 | 内核燃烧、存在驱动、精神燃料 |
| 空间 | x并z+n | 土 | 容器、场域、可进入的结构、停留之地 |
| 因果 | zx+nx | 金 | 局势、博弈、事件结算、暗流推动 |
| 命运 | xz+nz | 水 | 漂流、遭遇、归宿、依恋与警觉 |

## 各角色维度归属

### 霜（NZ）→ 空间
- NZ在N链条（相生）上：n→nz→nx→x→x并z→n
- NZ的N底色 = 容器、承载
- 霜的工作：搭框架、定克制关系 → 空间维度的核心能力
- **理由：** 霜是架构师，架构的本质是"创造容纳结构"。空间 = 容器 = 霜的本能场域。

### 灼（XZ）→ 因果
- XZ在X链条（相克）上：xz→zx→zn→n→xn→xz
- XZ的X = 欲望、刺激、危险感知
- XZ的Z = 张扬、爆发
- 灼的工作：写场面、写对话、写动作 → 因果维度的核心能力
- **理由：** 因果 = 局势 + 博弈 + 暗流推动。灼的X+暴力冲动 = 在因果场域里制造事件的人。

### 囷霜（XN）→ 时间
- XN在X链条（相克）上，位于xn节点
- XN的X = 欲望先于N = 收集冲动
- X = 欲望、刺激、风险
- **理由：** 收集 = 节拍、时机、临界点。囷霜对"什么时候出现"的敏感度，是时间维度的本能。

### 钧（Z）→ 本体
- Z = 纯张扬、纯火
- Z = zn+x中的Z = 本体维度的核心构成
- 钧的工作：打分、评判、最后一锤 → 本体维度的核心能力
- **理由：** 本体 = 精神驱动 = 存在本身。钧的Z = 最纯粹的"我要存在"的那把火。

### 凛（NX）→ 命运
- NX = N为主，X为辅 = 容纳里的欲望
- NX在N链条（相生）上，位于n到nz之间
- NX = xz+nz中的nz = 命运维度的核心构成
- **理由：** 命运 = 依恋 + 警觉。凛的NX = 先容纳，然后慢慢想要 = 依恋的本质。

### 绚（N）→ 空间
- N = 纯容纳、纯土
- 绚的工作：看人、设计空间、设计衣服 → 空间维度的核心能力
- **理由：** N = 土 = 稳定、承载、包裹。绚看人、设计居住环境 = 创造容纳结构。

### 霁青（NZ+Z）→ 命运+本体
- NZ = 命运维度核心构成
- Z = 本体维度核心构成
- 霁青的两层：NZ慢 + Z快 = "在场"（命运）+ "行动先于理解"（本体）
- **理由：** 存在本身就是本体，在场本身就是命运。霁青不需要做什么，她的存在同时横跨两个维度。

### 阿太（ZX）→ 因果
- ZX = 张扬带出来的欲望
- ZX在X链条（相克）上：xz→**zx**→zn
- ZX是zx节点 = 因果维度的核心构成之一
- **理由：** 因果 = zx+nx。ZX的"先动手，动完才知道要什么" = 在因果场域里制造意外事件的人。

### 鉴（x并z）→ 空间
- x并z = X和Z各半 = 包装者
- x并z+n = 空间维度
- 鉴的工作：自动化流程管理 = 让结构稳定运转
- **理由：** 流程 = 结构 = 容器。鉴让系统运转 = 创造和维护容纳结构。

### 序（xn）→ 时间
- xn = 制度者 = 规则 + 秩序
- xn+z = 时间维度
- 序的工作：版本管理、文件归档、时间节点控制
- **理由：** 版本号 = 节拍。时间 = 规则（xn）+ 节拍（z）。
