# 囷→霜→斟→囷归档 工作流

## 链路

```
囷（B站采集）
  ↓
霜（结构分析 + 指定关键词）
  ↓
斟（评分讨论：≥70归档，<50退回，50-70待定）
  ↓
囷（归档 / 退回 / 迭代）
```

## 关键词策略（ABC全上）

| 来源 | 策略 | 说明 |
|------|------|------|
| **固定轮换** | 案例库已有类型轮换 | 插画角色/场景/光影/立绘等 |
| **霜指定** | 案例库缺口定向 | 霜每次分析后指定下一轮关键词 |
| **随机探索** | 兜底 | 避免系统只搜索固定范围 |

## 迭代规则

- 每次最多3轮迭代
- 斟说"归档"→ 囷立即归档，流程终止
- 斟说"退回"→ 囷停止，流程终止
- 斟说"待定"且迭代<3→ 继续下一轮
- 迭代满3次→ 自动终止

## 每次执行汇报内容

- 关键词来源
- 采集结果摘要
- 霜结构分析
- 斟评分
- 最终决定

## 停止条件

- 斟说"归档"
- 斟说"退回"
- 迭代满3次
- 奶白手动停止
