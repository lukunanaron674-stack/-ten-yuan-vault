​二、三大定律​
​主导律​：权重最高者决定事物性质（如Z＞50%即“颠覆性创新”）。

​博弈律​：比例冲突引发矛盾（如环保主义中X%与N%对抗），互补创造协同（如教育中Z%与N%叠加）。

​情境律​：同一事物在不同场景中比例可变（如水在饮用时N=80%，洪水时X=90%）

## 二、五行能量循环模型
### 1. 相生链（能量传递方向）
```mermaid
graph TD
XZ[水] --> ZX[木] --> ZN[火] --> N[土] --> XN[金] --> XZ
```
**逻辑**：  
水→木（掠夺驱动探索） → 木→火（探索激发协作） → 火→土（协作催生规则） → 土→金（规则催生反抗） → 金→水（反抗重构掠夺）

### 2. 相克链（能量抑制路径）
```mermaid
graph LR
XZ[水] --> ZN[火] --> XN[金] --> ZX[木] --> N[土] --> XZ
```
**逻辑**：  
水克火（资源垄断压制热情） → 火克金（狂热瓦解理性） → 金克木（制度僵化阻碍创新） → 木克土（逻辑突破颠覆规则） → 土克水（过度规范催生黑市）

## 三、阴阳对冲机制
### 1. 对冲规则表
| 阴元素 | 阳元素 | 能量转化现象               | 失衡率 |
|--------|--------|----------------------------|--------|
| NZ     | X      | 内耗型对抗（如冷战思维）    | 30%    |
| X      | Z      | 爆发型冲突（如科技竞赛）    | 30%    |
| Z      | NX     | 持续性博弈（如贸易战）      | 30%    |
| NX     | X50/Z50| 协同演化（如混合所有制改革）| 动态平衡|

### 2. 转化算法示例
```python
def yin_yang_hermetic(a, b):
    if (a, b) in [('NZ', 'X'), ('X', 'Z'), ('Z', 'NX'), ('NX', 'X50/Z50')]:
        return f"{a}→{b} (失衡率30%)"
```

## 四、主次搭配规则
1. **首字母为「主」**，次字母为「辅」（如ZN中Z主导，N辅助）。
2. **阴阳对冲时标注阴影属性**（如NZ对冲为X型，标记为`X_{shadow}`）。
