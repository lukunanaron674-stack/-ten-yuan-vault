# 兰德尔·麦克墨菲（Randle McMurphy）
> 归档：`05-银矿库/角色库/飞越疯人院_麦克墨菲.md`

---

## 1. 主十元判断

**主十元：zx（阳木·先做再想/完成即意义）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zx，麦克墨菲就是一个想逃避劳改的小混混——装疯、耍赖、在疯人院找轻松。但麦克墨菲最核心的不是"狡猾"，是**他控制不住要干点什么**。打破玻璃拿烟、组织打牌、偷船带所有人出海——他不是在反抗（那需要zz），他就是手痒了，想到了就要做。
- **第2问（反复面对什么结构）：** 反复面对「你能拿我怎么样」。护士长用规则框他、用药物控他、用电击治他——每次他都被压下去，但每次他又找到新的方法搞事。他不是在策划革命（nx），他是"我先做了，你来啊"。
- **第3问（最怕失去什么）：** 最怕「无聊/被关住动不了」。他不是怕电击（x）、不是怕被孤立（z）——他是怕"不能动了"。疯人院最让他崩溃的不是粗暴治疗，是不能打牌、不能说话、不能出去。
- **第4问（回到哪个感觉）：** 回到「和病人们一起笑」的那一刻——船上钓鱼，每个人都像正常人一样开心——他不怕死，但怕"没人再笑"了。
- **第5问（副十元服务谁）：** nz（不想结束/希望这个火焰别熄）是zx的舵——麦克墨菲的"先做"如果没有nz，就只是一个疯子在疯人院里闹。但他最后把命搭进去了。因为他的"做"不只是为自己——他把酋长唤醒了。

## 2. 副十元

**副十元：nz（阴金·不想结束/希望火焰别熄）**

**作用：** 麦克墨菲最后被切了脑叶——他变成了一个安静的人。他已经"结束"了。但酋长在他身上看到了什么——他用枕头结束了麦克墨菲的身体，然后自己举起洗漱台砸破窗户飞越了疯人院。那不是麦克墨菲的死，是nz的传递："我不能动了，但你可以替我飞出去"。

## 3. 功能十元

**功能十元：z（阴火·想被看见/被承认）——表层。** 麦克墨菲确实享受被病人们围着的感觉——"看我在干什么"、"看我是不是很厉害"。但这是副产品，不是驱动。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 蓬乱的头发、皮夹克、抽雪茄的不羁造型——"我就是来闹的"。

## 5. 动态链

```
zx（主·想到了就做/控制不住的手）
  → nz（副·不想让火焰熄掉/传递给了酋长）
  → z（功能·享受被病人们围住的感觉）
  → x并z（视觉·不羁的闹事者）
  → 进疯人院→打破规则→带出海→电击→脑叶切除
  → 酋长说：我得走了
  → 他用枕头让他走了
```

## 6. 一句话定型

麦克墨菲不是「反抗制度的英雄」，也不是「自由的象征」，而是「**手痒了就要做、做到最后把命搭进去**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** zx（主）+ nz（副）→ 因果型
**最终定位：** zx（主·先做再想/完成即意义）+ nz（副·不想结束/希望火焰别熄）→ 因果型
**最终修正理由：** 原卡zx正确，但副十元nx（算清楚再动）是麦克墨菲的反面——他不算账、不算后果、不算命。nx完全不符合。nz才是他的副十元——他最后让酋长飞越疯人院不是出于计算，是出于"自由这件事不能在这里结束"的nz本能。
