# 阿宝（Po）
> 归档：`05-银矿库/角色库/功夫熊猫_阿宝.md`

---

## 1. 主十元判断

**主十元：z（阴火·执念/被看见）**

**五问法核验：**
- **第1问（拿掉什么他就不是他）：** 拿掉z，阿宝会变成「在面馆里卖面的胖熊猫」——他没被选上神龙武士那天的生活。他爹问「你做梦都在想什么？」他说「我在想功夫。」他不是在幻想自己成为英雄的荣耀，是**他身体里有一个自己都压不住的执念在往外冒**。Z的定义不是目标——是被光点击中的时候，你控制不住要去追。
- **第2问（反复面对什么结构）：** 反复面对「所有人都觉得我不行」。太郎觉得他不行，师父觉得他不行，盖世五侠觉得他不行，他自己也觉得自己不行——但他还是站在了比武大会上。不是因为勇敢（zx），是因为馋嘴的执念已经比害怕大了。
- **第3问（最怕失去什么）：** 最怕「被证明果然不行」。所以他最痛苦的时刻不是被打败了，是爬楼梯那段——他累瘫在台阶上，说「我大概真的不是神龙武士」。那是一个z的人在问：如果我这道光其实不存在呢？
- **第4问（回到哪个感觉）：** 回到「抢包子」的那个感觉。最后跟太郎打的时候他用的不是师父教的招式，是他自己的方式——z的人最终找到的路一定是自己长出来的，不是别人教出来的。
- **第5问（副十元服务谁）：** zn（功夫=意义）给z提供了方向。阿宝不是想「成为英雄」（那太zx了），他是想「证明功夫有另一种可能」——这是信仰层面的事，不是执行层面的事。

## 2. 副十元

**副十元：zn（阳火·意义/信仰）**

**作用：** 功夫对阿宝来说不是技能，是信仰。他学功夫不是为了打败坏人——是为了「成为功夫的一部分」。所以他最后看懂的无字秘籍不是某种技巧，是他自己。

## 3. 功能十元

**功能十元：n（阳土·承载）**

**作用：** 阿宝的爹和面馆是他的n——一个永远在等他回去的承载空间。无论阿宝在外面被打得多惨，回家有面条吃。但n不是阿宝的驱动力——他每次选择离开面馆往山上跑，就是选择z而不是n。

## 4. 视觉十元

**视觉十元：无显著。** 胖和黑白是物理属性，不是十元选择。

## 5. 动态链

```
z（主·想做功夫的执念）
  → zn（副·功夫=意义）提供方向
  → n（功能·面馆承载）提供退路
  → 选了神龙武士 → 所有人否定 → 累瘫台阶上
  → 自己长出路 → 赢了
```

## 6. 一句话定型

阿宝不是「命运选中的龙武士」，而是「**做梦做到压不住、非要去追**的人」。

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**新定位：** z（主·执念/被看见）+ zn（副·意义）
**修正理由：** 旧卡把阿宝归类为命运型——「天选之人的命运」。但阿宝不是被命运推着走的。他要不是自己先做梦做到发烫，谁选他都没用。是z先存在，神龙武士的title才落在他身上。
