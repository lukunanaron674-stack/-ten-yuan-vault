# 小米（Remy）
> 归档：`05-银矿库/角色库/美食总动员_小米.md`

---

## 1. 主十元判断

**主十元：z（阴火·被光点击中后死也不放）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉z，小米就是一只聪明的老鼠——会偷东西、会逃跑、会求生。但小米最核心的不是聪明，是**他闻到食物的味道就控制不住**。第一场煮汤的戏说明一切——他不是在做菜，他是在回应那个召唤。
- **第2问（反复面对什么结构）：** 反复面对「我不该做这个但我不能停」。鼠群说"你疯了"、爸爸说"老鼠不吃人类的食物"、整个社会都在说"你不该在厨房"——但他停不下来。z的结构是：**全世界都说不行，但我的身体说行**。
- **第3问（最怕失去什么）：** 最怕「不能再做菜了」。被抓住、被杀、被赶出厨房都不如「再也尝不到那个味道」可怕。
- **第4问（回到哪个感觉）：** 回到「第一次尝到完美搭配」的那个瞬间。看见颜色、闻到气味、舌尖爆开的那个感觉——这就是他的永恒。
- **第5问（副十元服务谁）：** zx（完成/执行）服务于z——小米不是思想家，他是身体被点燃后用行动来回应。林圭宁的手是他的zx通道——"我动不了但可以通过你完成"。

## 2. 副十元

**副十元：zx（阳木·先做再想/完成即意义）**

**作用：** 小米被点燃后立刻行动。他没有"等合适时机"（nx）或"规划路线"（xn），他是被z推进厨房之后就开始做。zx让他不纠结"老鼠能不能做菜"——他已经开始做了。

## 3. 功能十元

**功能十元：xn（阴土·接受规则再找路）——表层。** 小米学会了在厨房的规则里运作（被赶出去就躲在帽子下面），但这只是手段，不是驱动。

## 4. 视觉十元

**视觉十元：x（阴水·伪装/生存）。** 躲在林圭宁帽子里——这是视觉包装，让这只老鼠看起来像"人"。

## 5. 动态链

```
z（主·被烹饪的召唤点燃/死也不放）
  → zx（副·被点燃就立刻行动）
  → xn（功能·在厨房规则里找路）
  → 跳出下水道→偷看食谱→煮汤→遇见林圭宁
  → 他在帽子底下完成了全部梦想
```

## 6. 一句话定型

小米不是「打破偏见的励志老鼠」，也不是「追求梦想的小厨神」，而是「**被味觉击中后就停不下来**」的疯子。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** z（主）+ zx（副）→ 时间型
**最终定位：** z（主·被光点击中死也不放）+ zx（副·先做再想/完成即意义）→ 时间型
**最终修正理由：** 原卡把小米当作因果型（先做再想+算清楚），但小米的行为逻辑不是"完成即意义"和"算清楚再动"。他的驱动来自z——被烹饪这件事本身点燃后无法停止。他不是通过思考"老鼠做菜的意义"来决定行动（zn），而是"我控制不住"。副十元zx是他被点燃后的自然动作。
