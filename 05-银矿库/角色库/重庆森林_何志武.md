# 何志武（223号警察 / 金城武）
> 归档：`05-银矿库/角色库/重庆森林_何志武.md`

---

## 1. 主十元判断

**主十元：nz（阴金·不想结束）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉nz，何志武就是一个被甩的警察——失恋了跑步、吃罐头、打电话。但何志武最核心的不是"失恋的男人"，是**他拒绝让任何事结束**。女朋友走了他跑了25圈，凤梨到期之前他全部买下来，一年后的生日他可以像什么都没发生过一样call机留言——他不接受"结束了"。
- **第2问（反复面对什么结构）：** 反复面对「过期了怎么办」。凤梨会过期、感情会过期、连世界都有保质期——他每天做的事就是和"过期"做对抗。
- **第3问（最怕失去什么）：** 最怕「彻底结束/一点痕迹都没留下」。他跑圈、买罐头、call机留言——不是为了让女朋友回来，是让"她存在过"这个事实不要被时间抹掉。
- **第4问（回到哪个感觉）：** 回到「还在热恋、约定还没到期」的那个状态。让他在"过期之前"活着，比"以后"更重要。
- **第5问（副十元服务谁）：** z（想被看见）服务于nz——"我在等你"和"我让你知道我在等你"是两回事。他call机从来不说话——不是不想说，是"你看到我call你了"就够了。

## 2. 副十元

**副十元：z（阴火·想被看见/但不承认）**

**作用：** 何志武在电话亭反复打call机却不说话——"你看到call了你就会知道我在等你，但我不会承认"。他需要被前女友"看见"他的存在，但不会主动去解释说"我还爱你"。

## 3. 功能十元

**功能十元：xn（阴土·在规则里找路）——表层行为。** 他在城市生活规则里找到了自己的路径：每天跑圈、每天买罐头、每月去同一家店。在繁华的香港，他找到了一种孤独但有节奏的生活方式。

## 4. 视觉十元

**视觉十元：x并z（阴木·伪装）。** 墨镜、警察制服、永远在路上——他在城市里的"机动性"是伪装：即使他其实哪里也去不了。

## 5. 动态链

```
nz（主·不接受结束/拒绝一切过期）
  → z（副·需要被看见/但不敢被确认）
  → xn（功能·在城市规则里找一条孤独的路）
  → 被甩→吃凤梨罐头→跑圈→call机留言→一年后的生日
  → 他没有等来谁，但他完成了他给自己的时限
```

## 6. 一句话定型

何志武不是「失恋的警察」，也不是「都市孤独的标本」，而是「**拒绝任何事结束、把每一秒都撑到最长**」的人。

## 旧卡修正记录

**旧定位：** xn+z（时间型）
**修正1：** nz（主）+ z（副）→ 命运型
**最终定位：** nz（主·不想结束）+ z（副·想被看见但不承认）→ 命运型
**最终修正理由：** 原卡xn正确描述了他的行为方式（在城市规则里找生存节奏），但xn是工具不是驱动。驱动何志武全部行为的是nz——他不接受"结束"这个概念。凤梨罐头的保质期（过期）、25圈跑完后（结束）、一年后的约定（期限到了）——他所有的焦虑都来自"快要没了"和"不能让它没掉"。z（想被看见）解释了他那些欲言又止的call机——他不需要挽回什么，他只需要让她知道"我还在"。
