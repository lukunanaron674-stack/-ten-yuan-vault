# 琪琪（Kiki）
> 归档：`05-银矿库/角色库/魔女宅急便_琪琪.md`

---

## 1. 主十元判断

**主十元：zx（阳木·先做再想/完成即意义）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zx，琪琪就是一个离家闯荡的小魔女——有魔法、会飞、很努力。但琪琪最核心的不是"努力"或"魔法"，是**她离开家了，然后呢？没想好，就先做吧**。魔女传统说13岁要离开家一年——她没想为什么，就走了。到了新城市不知道自己能做什么——先飞一圈看看。开了宅急便不知道能不能赚钱——先送两趟再说。
- **第2问（反复面对什么结构）：** 反复面对「这个办法不行了怎么办」。新奇的事物让人开心，但新鲜感过了之后——生意冷淡、朋友有事、魔法正在消失。每次遇到挫折她没有停下来想（xn），她是换一条路继续走。
- **第3问（最怕失去什么）：** 最怕「飞不起来了」。不是怕失败（zx的反面），是怕"不能再做这件事了"——不知道那意味着什么，但怕。
- **第4问（回到哪个感觉）：** 回到「第一次骑着扫帚飞起来」的那一刻——不是在找什么方向，是"我会飞哎"。
- **第5问（副十元服务谁）：** z（想被看见/被认可）是zx的情绪燃料——她希望城市里的人们知道"我是有用的"。帮老奶奶送鱼、给小女孩送蛋糕、在节日表演——这些不只是"完成了任务"（zx），是"你看到我有多努力了吗"（z）。

## 2. 副十元

**副十元：z（阴火·想被看见/被接受）**

**作用：** 琪琪希望融入这个城市。她穿上黑色的魔女装不是为了好看——是"魔女就该是这样"的包装。但她也希望别人看到她、认可她。魔法消失之后她最难过的不是不能飞了，是"别人会怎么看我"。

## 3. 功能十元

**功能十元：xn（阴土·接受规则再找路）——表层。** 她接受了"魔女必须离开家独自生活"的传统规则，也接受了"到新城市就要自己找工作"的社会规则，然后在这个框架里找到了一条宅急便的路。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 蝴蝶结、黑裙、红鞋、小扫帚——这是"魔女"的标准形象。琪琪不反抗这个包装，但真正让她被记住的不是这个包装，是她的笑容和她的飞行。

## 5. 动态链

```
zx（主·做了再说/先飞起来再找方向）
  → z（副·想被这个城市看见和接受）
  → xn（功能·接受魔女的传统规则在规则里找路）
  → x并z（视觉·魔女的经典包装）
  → 离开家→到大城市→开宅急便→失去魔法→找回魔法
  → 她重新飞起来的时候不是变强了，是知道自己为什么飞了
```

## 6. 一句话定型

琪琪不是「独立的小魔女」，也不是「成长的少女」，而是「**先飞起来再想降落的地方**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** zx（主）+ z（副）→ 因果型
**最终定位：** zx（主·先做再想/完成即意义）+ z（副·想被看见/被认可）→ 因果型
**最终修正理由：** 原卡zx正确，但副十元nx（算清楚再动）是琪琪的反面——她离开家没有"算清楚"，来了城市也不知道"下一步怎么走"。她的方式是"先做了，不行再换"。z更贴合她——她希望被这个新城市的人接纳和认可，这是她坚持送快递的动力之一。
