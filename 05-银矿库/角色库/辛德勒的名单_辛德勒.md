# 奥斯卡·辛德勒（Oskar Schindler）
> 归档：`05-银矿库/角色库/辛德勒的名单_辛德勒.md`

---

## 1. 主十元判断

**主十元：zn（阳土·这件事是对的）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zn，辛德勒就是一个精明的纳粹商人——会送礼、会交际、会捞钱。但辛德勒最核心的不是"聪明"或"会转身"，是**他看见了屠杀现场之后，本能知道了一件事："这不对"**。他没有在大脑中计算利益得失（nx），他就是知道——然后他用了全部身家去做"对的事"。
- **第2问（反复面对什么结构）：** 反复面对「还能不能再救一个」。名单在增长、钱在烧光、他一次次去找阿蒙·哥特——不是因为他勇敢（n），是因为"可以救"→"应该救"→"再救一个"。
- **第3问（最怕失去什么）：** 最怕「可以救的人没救到」。战争结束时他崩溃的不是"我破产了"，是"我的车能换十几条命，我的金徽章能换一条——我为什么没早想到"。
- **第4问（回到哪个感觉）：** 回到「那个人被写上名单」的那一刻。一个名字就是一个世界——他的满足感来自"这个人活了"。
- **第5问（副十元服务谁）：** z（想被看见）在辛德勒身上的演变很有趣——一开始他确实享受被纳粹军官们簇拥、享受被工厂工人仰望。但到了后期，z完全服务于zn——"我被记住不是因为我的金徽章，是因为我救的人"。

## 2. 副十元

**副十元：z（阴火·想被看见/被记住）**

**作用：** 老辛德勒一开始的事业有z的成分（想要漂亮的结局、想要被记住、享受功成名就的感觉）。但到了后期，z被zn覆盖——"我希望被记住的是我救了这些人，而不是我捞了多少钱"。

## 3. 功能十元

**功能十元：zx（阳木·执行/先做再想）——表层行为。** 辛德勒是行动派——知道了"这事对"之后立刻开始做。他没有犹豫、没有等待最完美的方案。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 西装、胸针、名酒、好车——这些都是纳粹官员的通行证。不是他，是他穿的衣服。

## 5. 动态链

```
zn（主·救人是对的/一条命就是一个世界）
  → z（副·我想被记住/但以正确的方式）
  → zx（功能·知道后就去做）
  → x并z（视觉·纳粹商人的包装）
  → 目睹屠杀→名单开始→一个接一个→倾家荡产→战争结束
  → "我本来可以救更多人"
```

## 6. 一句话定型

辛德勒不是「赎罪的纳粹商人」，也不是「反战英雄」，而是「**看见了对的事就无法假装没看见**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** zn（主）+ z（副）→ 本体型
**最终定位：** zn（主·这件事是对的）+ z（副·想被记住/以正确的方式）→ 本体型
**最终修正理由：** 原卡zx+nx完全走偏了——辛德勒不是"完成即意义"（zx）也不是"算清楚再动"（nx）。他的转变来自一个道德本能：看见屠杀之后知道"这是错的"，然后用全部资源去做"对的"。这是典型zn的驱动。副十元z解释了他早期人设的"享受被追捧"——但最终zn压倒了z。
