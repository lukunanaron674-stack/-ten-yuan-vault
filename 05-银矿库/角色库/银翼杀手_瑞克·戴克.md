# 瑞克·戴克（Rick Deckard）
> 归档：`05-银矿库/角色库/银翼杀手_瑞克·戴克.md`

---

## 1. 主十元判断

**主十元：xz（阴木·被推着走/不知道归处）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉xz，戴克就是一个冷酷的杀手——接任务、杀目标、拿钱走。但戴克最核心的不是"冷漠"，是**他不知道自己到底是谁、在哪、要去哪**。退休了被叫回去——他去不是因为想杀复制人（zn），是因为被推着走。他开始对复制人产生同情不只是因为善良（n），是因为他发现自己可能和他们一样。
- **第2问（反复面对什么结构）：** 反复面对「我还是不是人」。追杀复制人的过程就是拷问自己的过程——每一个复制人的死亡都在问：你比他们高级在哪？你的记忆是真的吗？你是人还是程序？
- **第3问（最怕失去什么）：** 最怕「发现自己只是一个产品」。不是怕死（x），是怕"我的人生全部是植入的"。
- **第4问（回到哪个感觉）：** 回到「还没有怀疑过自己是谁」的状态——一个普通的警探，周末回家，没有复制人在他面前问"我是谁"。
- **第5问（副十元服务谁）：** nz（希望那个人也在）是xz的唯一出口——他带瑞秋走不是因为爱可以拯救一切，是"现在至少有一个和我一样的人"。

## 2. 副十元

**副十元：nz（阴金·希望那个人也在/不想再失去）**

**作用：** 戴克救瑞秋不是因为英雄主义——是"你是我唯一能确定是真实的东西"。复制人有一个四年的寿命，他知道，但他还是带她走。nz在这里的表现：希望她在、希望"我们"这个故事不要结束。

## 3. 功能十元

**功能十元：xn（阴土·接受规则再找路）——表层行为。** 戴克不是反抗系统的人——他戴着警徽、接任务、按照银翼杀手的规则工作。他在规则里找路——比如放过瑞秋、比如在屋顶不杀罗伊。

## 4. 视觉十元

**视觉十元：x（阴水·透明/冰冷）。** 灰色的风衣、烟、威士忌、独居的公寓——视觉上他不像"英雄"，像一个被雨淋湿的灰色生物。

## 5. 动态链

```
xz（主·被推着走/不知道自己是谁）
  → nz（副·希望她在/不想一个人）
  → xn（功能·在系统规则里找边缘路线）
  → x（视觉·灰色风衣+雨+烟）
  → 被叫回来→追杀复制人→遇见瑞秋→罗伊的独白
  → 他带着她走了——不是因为找到了答案，是因为终于有一个人和他一样
```

## 6. 一句话定型

戴克不是「人性追问者」，也不是「赛博朋克的侦探」，而是「**不知道自己是谁、但被推着走到了最后一站**」的人。

## 旧卡修正记录

**旧定位：** zn+x（本体型）
**修正1：** xz（主）+ nz（副）→ 命运型
**最终定位：** xz（主·被推着走/不知道归处）+ nz（副·希望那个人也在/不想一个人）→ 命运型
**最终修正理由：** 原卡zn+x完全不成立——戴克没有"这件事是对的"（zn）的道德驱动，也没有zn所说的"回归本质"的倾向。他被动、模糊、不选择。xz才符合他的形态——被故事推着走、不知道自己是谁、每一步都在怀疑。nz是他抓住瑞秋的理由：不是爱本身有多深刻，是"我不想再一个人了"。
