# 赈早见琥珀主（白龙）
> 归档：`05-银矿库/角色库/千与千寻_赈早见琥珀主.md`

---

## 1. 主十元判断

**主十元：xn（阳金·规则/制度）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉xn，白龙会变成「一条记得千寻但不知道该怎么办的河」——那他谁都救不了。白龙在汤屋的存在方式不是靠武力（他不是最能打的），不是靠算计（他忘了自己是谁），不是靠感情——他靠的是**他是汤婆婆最得力的徒弟，因为他把她的规矩学得最好**。他知道油屋的每一条规则，知道怎么在规则里给千寻找到活路——签契约、安排工作、挡住汤婆婆的盘问。这是xn最经典的状态：**学通规则→用规则保护重要的人**。
- **第2问（反复面对什么结构）：** 反复面对「我不能直接反抗，但我可以在规则里操作」。他不跟汤婆婆翻脸，不跟钱婆婆硬碰，不动用暴力——他永远在制度的缝隙里做事。偷药牌、调开守卫、安排千寻去见钱婆婆——每一步都在规则之内操作。
- **第3问（最怕失去什么）：** 最怕「规则变了，我来不及找到新路」。所以当汤婆婆发现他偷药牌的时候，他最恐惧的不是被打骂，是「她的规则现在对他不透明了」。
- **第4问（回到哪个感觉）：** 回到「我记得那条河的名字」的那一刻。找回自己的名字=找回自己在这个世界的规则位置——他不是汤婆婆的工具，他是赈早见琥珀主。
- **第5问（副十元服务谁）：** nz（对千寻的依恋）是xn的方向——如果不是千寻，他不会费这么大劲去学汤婆婆的规矩。nz告诉他「为什么要在规则里做这些事」，xn告诉他「怎么做」。

## 2. 副十元

**副十元：nz（阴土·柔情停靠）**

**作用：** 白龙对千寻的守护不是责任（zx），不是信仰（zn）——是依恋。他小时候救过她，她掉进河里那次之后他就记住了。这种「小时候欠的一份情，长大了咬牙也要还」的感觉就是nz的方向。

## 3. 功能十元

**功能十元：无显著。** 白龙的角色设计非常干净——xn主+nz副，没有多余的工具位。

## 4. 视觉十元

**视觉十元：白龙形态本身不是十元的体现。** 龙是自然力量的象征，不是他的十元选择。

## 5. 动态链

```
xn（主·学通规则→用规则保护千寻）
  → nz（副·对千寻的依恋提供方向）
  → 安排工作 → 挡盘问 → 偷药牌
  → 找回名字
  → 送千寻走出去
```

## 6. 一句话定型

白龙不是「等待被救赎的河神」，而是「**把汤婆婆的规矩学透了，好在规则里给你留一扇窗**的人」。

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**新定位：** xn（主·规则/制度）+ nz（副·柔情停靠）→ 时间型
**修正理由：** 旧卡把白龙理解为「失去身份、等待救赎的漂流者」（命运型/xz+nz）。但白龙不是被动漂流的人——他非常主动地选择了在汤屋学规矩、占据一个有用的位置。他失去名字不是因为他被命运推着走，而是因为他主动进入了汤婆婆的规则系统（打工换学习）。这是xn的选择：**先接受一套规则，再在规则里找到操作空间。**
