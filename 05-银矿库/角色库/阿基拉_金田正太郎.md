# 金田正太郎（Shotaro Kaneda）
> 归档：`05-银矿库/角色库/阿基拉_金田正太郎.md`

---

## 1. 主十元判断

**主十元：zx（阳木·先做再想/完成即意义）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zx，金田就是一个飙车党老大——有兄弟、有摩托、很能打。但金田最核心的不是"能打"或"讲义气"，是**他动手之前几乎不想**。铁雄被抓走，他骑着车就去了；政府封锁消息，他翻墙就进；军队在前面，他不管。不是勇敢（n），是想到了就做了。
- **第2问（反复面对什么结构）：** 反复面对「铁雄在前面，我得追上他」。从飙车到废墟到最后的超空间——铁雄一直在往前跑，他一直在后面追。他追的不是"阻止铁雄"，是"我要跟铁雄说话"。
- **第3问（最怕失去什么）：** 最怕「铁雄不见了/变不回来了」。金田不是怕铁雄的力量（x），是怕"铁雄已经不是那个跟在我后面的人了"。
- **第4问（回到哪个感觉）：** 回到「和铁雄一起飙车」的时刻——那时候铁雄还是跟在他后面的小鬼，世界还在他们脚下。
- **第5问（副十元服务谁）：** nz（不希望结束/希望那个人还在）是zx的导航——金田的所有"先做"不是为了征服世界（zx的纯粹形式），是为了"把铁雄拉回来"。铁雄是他的方向感。

## 2. 副十元

**副十元：nz（阴金·不想结束/希望那个朋友还在）**

**作用：** 金田追铁雄的全部力量来自"不能让铁雄就这样没了"。他不是想阻止铁雄搞破坏（zn），是"铁雄是我的朋友——不管他变成什么，他都是我的朋友"。友谊是nz的一种具体形态——"我们的故事不能在这里结束"。

## 3. 功能十元

**功能十元：n（阳火·扛住/承受冲击）——表层。** 金田被打倒后总能爬起来、军队挡路就突破、在精神污染的空间里也撑住——他身体好、意志硬、扛得住。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 红色摩托、皮夹克、小团队——这些是新东京街头少年的制服，不是他的底色。

## 5. 动态链

```
zx（主·想到了就做/先飙车后问问题）
  → nz（副·铁雄不能就这样没了/我们的友谊不能结束）
  → n（功能·扛得住所有的冲击）
  → 铁雄被抓→飙车救人→闯研究所→废墟对决
  → 他喊"铁雄！"喊到最后
```

## 6. 一句话定型

金田不是「热血英雄」，也不是「反抗政府的少年」，而是「**想到了就去做、做到了再问为什么**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** zx（主）+ nz（副）→ 因果型
**最终定位：** zx（主·先做再想/完成即意义）+ nz（副·不想结束/希望那个朋友还在）→ 因果型
**最终修正理由：** 原卡zx正确。但副十元nx（算清楚再动）是金田的反面——他从来不"算清楚"，他的行动特征是"想到了就冲出"。nz才是他真正的副十元——他对铁雄的执着来自"不能让你消失"的nz结构。铁雄是他的"不想结束"。
