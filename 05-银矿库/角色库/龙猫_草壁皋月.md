# 草壁皋月（Satsuki Kusakabe）
> 归档：`05-银矿库/角色库/龙猫_草壁皋月.md`

---

## 1. 主十元判断

**主十元：n（阳火·怕死了但扛住了/不能让它塌）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉n，皋月就是一个11岁的小姑娘——上学、玩耍、和妹妹一起探险。但皋月最核心的不是"童真"，是**她扛着一个家**。妈妈住院、爸爸上班、小梅才4岁——她每天早上做便当、叫妹妹起床、放学后照顾妹妹、晚上等爸爸回来。她不是不害怕（妈妈会不会有事、妹妹会不会走丢），但没人可以替她扛。
- **第2问（反复面对什么结构）：** 反复面对「小梅不见了怎么办」。迷路、进森林、腿跑断了也要找到她——不是因为她勇敢，是因为"如果我不去找，谁会去"。
- **第3问（最怕失去什么）：** 最怕「妈妈不回来了」。她从来没有当着妹妹的面哭过——只有在龙猫巴士站等爸爸回来的那场雨里，她背着小梅，站得笔直。不是不怕，是不能在小梅面前倒下。
- **第4问（回到哪个感觉）：** 回到「妈妈还在家、一家四口在一起」的某个下午。她做的每一次便当都有妈妈的味道——她在用这种方式让妈妈"还在"。
- **第5问（副十元服务谁）：** z（想被看见/想让爸爸和妈妈知道我做得不错）是n的一点慰藉——她希望被爸妈看到"我能扛住"。但这不是驱动，是她在撑住之后偶尔期待的一个拥抱。

## 2. 副十元

**副十元：z（阴火·想被看见/被认可）**

**作用：** 皋月是一个11岁的女孩，她也想被夸、被抱抱、被说"你做得很好"。她每天做这么多事——不是因为她天生懂事（zn的判断），是因为她需要被爸妈看见："你看，我能照顾好妹妹"。

## 3. 功能十元

**功能十元：zx（阳木·先做再想/完成即意义）——表层。** 皋月没有时间去想"该怎么办"——她直接做。做饭、收拾、写信给妈妈、跑去找小梅。这些动作是先做再想的模式，但不是她的驱动。

## 4. 视觉十元

**视觉十元：x（阴水·透明/普通）。** 短发、圆脸、小裙子、光脚——她看起来就像任何一个普通的小女孩。她的不普通不在外表上。

## 5. 动态链

```
n（主·怕但扛/不能在小梅面前塌）
  → z（副·想让爸妈看见我能行）
  → zx（功能·没时间想了直接做）
  → x（视觉·普通的短发女孩）
  → 妈妈住院→做便当→照顾小梅→小梅走丢→跑去找
  → 在小梅失踪的那一晚她哭着跑了十里路
  → 找到妹妹的时候她没哭——因为妹妹不能看到姐姐哭
```

## 6. 一句话定型

皋月不是「懂事的姐姐」，也不是「童年的代表」，而是「**怕到发抖但没人可以替她扛**」的11岁女孩。

---

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** n（主）+ z（副）→ 本体型
**最终定位：** n（主·怕死了但扛住了）+ z（副·想被看见/被认可）→ 本体型
**最终修正理由：** 原卡zx+nx完全偏离——皋月不是"完成即意义"（zx）也不是"算清楚再动"（nx）。她是被责任压着但硬扛的11岁姐姐。n是她的底色——怕妈妈会死、怕妹妹有危险、怕自己扛不住，但每一次都扛住了。z解释了她为什么每天笑嘻嘻——不是因为乐观，是因为"我要让爸妈看到我很好"。
