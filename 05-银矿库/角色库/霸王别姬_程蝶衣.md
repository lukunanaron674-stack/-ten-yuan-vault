# 程蝶衣（小豆子）
> 归档：`05-银矿库/角色库/霸王别姬_程蝶衣.md`

---

## 1. 主十元判断

**主十元：z（阴火·被光点击中后死也不放）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉z，程蝶衣就是一个名角——唱得好、有名声、很多人喜欢。但程蝶衣最核心的不是"唱得好"，是**他的身体里住了一个虞姬**。从师父逼他唱出"我本是女娇娥"的那一刻，他的灵魂已经被戏点燃了。此后的每一天他不是在"扮演"虞姬——他就是。
- **第2问（反复面对什么结构）：** 反复面对「你是不是霸王」。段小楼是不是那个能保护住虞姬的霸王？菊仙是不是那个让霸王变心的女人？时代在变，但蝶衣一直在同一个问题里转：你是霸王，那我就是虞姬，虞姬就该死在霸王面前。
- **第3问（最怕失去什么）：** 最怕「你不是霸王了」。段小楼在批斗大会上揭发他、说"我不喜欢他"——那不是背叛爱情，是"你不是霸王了"的证明。如果霸王不是霸王了，那虞姬是什么？
- **第4问（回到哪个感觉）：** 回到「台上、灯下、虞姬的戏服穿在身上」的那一刻。只有那个时候，他的灵魂和身体在一个地方。
- **第5问（副十元服务谁）：** zn（这件事是对的/本该如此）是z的保护壳——"我本是女娇娥"不是疯了，是"戏是这样唱对的"。他用"对"来为"燃烧"找一个正当理由。

## 2. 副十元

**副十元：zn（阳土·这件事是对的/本该如此）**

**作用：** 蝶衣所有的"疯魔"都有一个逻辑支撑：**虞姬就该死在霸王面前，这是对的**。他不是随便自杀——他是在舞台上，穿着虞姬的戏服，唱着虞姬的唱词，用虞姬的方式结束。这不是绝望，是「本该如此」。

## 3. 功能十元

**功能十元：nz（阴金·不想结束）——表层。** 他经历了民国、日据、新政权、文革——每次时代更迭他都在失去一些东西，但他不想让"戏"结束。所以在日本的舞台上他不逃、在批斗大会上他不屈服。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 戏服、头饰、胭脂、水袖——这些都是虞姬的外壳，也是他唯一愿意自己穿的样子。没有戏服的时候，他像丢了魂。

## 5. 动态链

```
z（主·被虞姬点燃/一生脱不下这身戏服）
  → zn（副·虞姬本该死在霸王面前/这是对的）
  → nz（功能·不要让戏结束）
  → x并z（视觉·一生都在穿戏服）
  → 被逼唱"我本是女娇娥"→成名→日据→文革→最后演出
  → 他终于把虞姬演完了——在舞台上，在霸王面前
```

## 6. 一句话定型

程蝶衣不是「戏痴」，也不是「时代的牺牲品」，而是「**被虞姬点燃后再也没有离开过舞台**」的人。

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**修正1：** z（主）+ zn（副）→ 时间型
**最终定位：** z（主·被光点击中死也不放）+ zn（副·这件事是对的/本该如此）→ 时间型
**最终修正理由：** 原卡xz+nz完全走了方向——程蝶衣不是"被推着走"（xz），他是主动燃烧的。他从少年时期被点燃就再也没回头过。z描述了他最核心的状态：被虞姬这个角色点燃后无法熄灭。zn是他的行为准则——"戏该这样演，虞姬该这样死"——不是被动的接受，是主动的"这是对的"。他是时间型的z角色。
