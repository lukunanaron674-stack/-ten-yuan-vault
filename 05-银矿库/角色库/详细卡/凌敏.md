# 角色归档卡｜凌敏｜x + xz

## 1. 角色定性

- 作品：《我们一起摇太阳》
- 角色：凌敏
- 主十元：x
- 辅助十元：xz
- 主辅合成判断：x + xz
- 角色功能：求生型命运角色——被死亡逼到墙角后，用强烈求生欲反咬命运
- 命运主题位置：xz+nz 命运型——在死亡临界线上重新找到活着的关系
- 一句话判词：她不是等待被救的人，是把命运咬出牙印的人。她的 x 求生欲不是爽文式爆发，而是被 xz（病痛、透析、肾源等待）包住的爆发。

---

## 2. 主辅十元解释

| 位置   | 十元     | 内容                            | 判断                     |
| ---- | ------ | ----------------------------- | ---------------------- |
| 主十元  | x      | 强烈求生欲：征婚换肾、不服命运、拒绝被当可怜人       | 她的第一推动力不是温柔依恋，是赤裸的求生    |
| 辅助十元 | xz     | 病痛、透析、肾源等待、身体耗损、未来随时断掉        | xz 不是附加状态，是 x 燃烧的容器      |
| 角色定性 | x + xz | 在死亡包夹中爆发的求生者                 | 求生型命运角色               |

## 4. 生克补原因分析

| 关系类型 | 十元关系       | 是否成立      | 原因                           | 对凌敏 x + xz 的影响 |
| ---- | ---------- | --------- | ---------------------------- | --------------- |
| 生    | xz 生 x     | 强成立       | 死亡威胁越紧，求生欲越强                 | x 在 xz 中燃烧       |
| 克    | n 克 xz     | 中期成立      | 吕途的日常承载缓解了病痛带来的不稳定感           | xz 不再压倒一切        |
| 回染   | nz 回染 x    | 后期成立      | 从"我要活"变成"我要和你一起活"            | x 的锋利被关系软化       |

## 5. 动态链演化

`	ext
凌敏｜x + xz

xz 病痛压迫 → x 求生欲爆发
→ zx 行动：发出征婚视频
→ 吕途 nz 接入：不把她当病人
→ x并z 荒诞婚姻外壳建立
→ n 日常承载：照顾、陪透析、一起面对
→ nz 回染 x：从"我要活"变"我要和你一起活"
→ zn：活着有了关系层面的意义
`

## 6. 最短封存句

凌敏｜x + xz：
死亡逼到墙角，她打的不是温柔牌，是"我要活"。她的 x 求生欲在 xz 病痛中燃烧，zx 行动让她发出征婚视频。吕途用 n 日常和 nz 温柔接住了她，让 x 从锋利求生变成有人一起活的 zn。
