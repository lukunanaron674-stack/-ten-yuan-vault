# 角色归档卡｜张大｜zx + nz

## 1. 角色定性

- 作品：《满江红》
- 角色：张大
- 主十元：zx
- 辅助十元：nz
- 主辅合成判断：zx + nz
- 角色功能：小兵的复仇行动——用层层算计和牺牲传递满江红
- 命运主题位置：zx+nx 因果型——每一步牺牲都在链条上
- 一句话判词：他是 zx——每一步都精心算计：装死、诈降、层层设局。nz 是目的——对岳飞的精神归属。zx 是手段，nz 是尽头。最后一死，满江红传遍全军。

## 2. 剧中十元互动表

| 剧中十元 | 在剧情中的形态 | 和zx的关系 | 和nz的关系 | 对角色造成什么变化 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| n | 同伴们——每一个都是计划的节点 | n承载zx——每个人都是行动的一环 | n被nz绑定——他们都为同一首诗而死 | 每个同伴倒下，zx还在继续 | 第一个人死了——第二个人接过了刀 |
| x | 秦桧的权力、金人的威胁 | x对抗zx——权力想掐断行动链 | x无法触及nz——诗在权力之上 | zx绕过了x——不是硬碰，是接力 | 秦桧以为掌控了一切——诗已经到了最后一棒 |
| xn | 层的审查、逻辑推断 | xn想破解zx——判断系统试图解开链条 | xn不理解nz——理性解不开信念 | zx骗过了xn——每一步都预判了预判 | 他装死——所有人都信了，除了他自己 |

## 3. 动态链

nz：对岳飞的信念归属
→ zx行动：设局、牺牲、接力
→ n承载：每一个同伴
→ x对抗：秦桧的权力
→ xn审查：层的推断
→ zx层层推进——每一步都有人倒下
→ 最终：满江红传遍全军
→ nz完成：诗活了

## 4. 最短封存句

张大｜zx+nz：他不是大英雄——是一个小兵用命下的一盘棋。zx是每一步算计和牺牲，nz是尽头那首诗。每一步都有人倒下，但诗传到了最后一个人嘴里。他死了——满江红没死。
