# 角色归档卡｜心慌方群像｜多元十元集合

## 1. 角色定性

- 作品：《心慌方》
- 角色：群像（警察、医生、学生、建筑师、智障青年）
- 类型：x并z+n——封闭空间暴露人性
- 一句话判词：立方是xz筛选器——警察的x膨胀为暴政，医生的nz被暴力碾碎，学生的zn找到出路，建筑师的n被罪疚压垮。只有最纯真的z+nz走了出来——空间不奖励力量，只放过无害。

## 2. 各角色十元

| 角色 | 十元 | 功能 | 结局 | 一句话故事 |
|------|------|------|------|------|
| 警察 | x + xn | 暴力控制+规则判断——从保护者变暴君 | 被抛弃在立方中 | 他推开了所有人——最后一个人把他推开了 |
| 医生 | nz + xn | 母性关怀+理性分析——维系人性 | 被杀 | 她是唯一还在说"我们"的人——警察让她闭了嘴 |
| 学生 | zn + xn | 数学天赋+破解规律 | 逃脱 | 她算出了质数——那不是数学，是出口 |
| 建筑师 | n + xz | 承载罪恶感——参与设计却不知目的 | 死亡 | 他设计了这个立方——不是故意的，但还是他的错 |
| 智障青年 | z + nz | 纯真冲动+无条件归属需求 | 唯一真正逃脱 | 他不需要算质数——他只需要被牵着走 |

## 3. 最短封存句

心慌方群像：立方不奖励力量——警察死了、医生死了、建筑师死了。只有最无害的智障青年走了出来。这个空间不是测试智力——是测试你有没有害过人。
