# 角色归档卡｜苏丽珍｜xn + nz

## 1. 角色定性

- 作品：《花样年华》
- 角色：苏丽珍
- 主十元：xn
- 辅助十元：nz
- 主辅合成判断：xn + nz
- 角色功能：在体面和渴望之间的窄巷里反复踱步——最终选择体面
- 一句话判词：她是 xn——体面、道德、不会离婚、不会越界。nz——对周慕云的靠近、一起写小说、楼道里擦肩。xn让她在酒店门口转身，nz让她在2046房间流泪。xn赢了——但 nz 永远留在那些走廊里。
