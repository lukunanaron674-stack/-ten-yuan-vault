# 角色归档卡｜本杰明·巴顿｜xn + z

## 1. 角色定性

- 作品：《本杰明·巴顿奇事》
- 角色：本杰明·巴顿
- 主十元：xn
- 辅助十元：z
- 主辅合成判断：xn + z
- 角色功能：逆流时间中的旅人——用理性和记录判断每一次相遇的意义
- 命运主题位置：xn+z 时间型——逆流时钟是最大的判断系统
- 一句话判词：他是 xn——逆流生长，用远超年龄的理性判断世界。z——每一次对黛西的靠近都是不计后果的冲动。逆流时钟决定了相遇只能是交叉点——但z让他在每一个交叉点都义无反顾。

## 3. 动态链

xn：逆流生长——从老到幼
→ z：遇见黛西
→ xz：时间永远错位
→ 中年交汇——唯一对得上的几年
→ xz再次撕开——他变小她变老
→ nz：婴儿死在她怀里
→ zn：记不记得不重要

## 4. 最短封存句

本杰明·巴顿｜xn+z：他逆着时间生长，她顺着时间变老。xn让他知道每一次相遇都是倒计时，但z让他在每一个交叉点选择了靠近。最后变成婴儿死在她怀里——zn不在记忆里，在爱过。
