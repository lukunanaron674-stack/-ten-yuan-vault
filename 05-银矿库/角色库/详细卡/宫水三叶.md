# 角色归档卡｜宫水三叶｜nz + x

## 1. 角色定性

* 作品：《你的名字》
* 角色：宫水三叶
* 主十元：nz
* 辅助十元：x
* 主辅合成判断：nz + x
* 角色功能：被命运牵住但渴望被看见、渴望逃离
* 命运主题位置：停靠被外力牵引、最终通过共振找到归宿的一方
* 一句话判词：她想被看见、想离开故乡，这是 x；但家族、名字、身体记忆一直牵着她，这是 nz。

## 2. 主辅十元解释

| 位置 | 十元 | 内容 | 判断 |
|------|------|------|------|
| 主十元 | nz | 依恋、被牵住、故乡的引力、身体的记忆 | 三叶不是被动停留，而是被深层连接牵住 |
| 辅助十元 | x | 逃离的欲望：想去东京、想被看见、想活下来 | x 是突破力，推动她不被完全困住 |
| 角色定性 | nz + x | 被牵住但渴望挣脱 | 被引力拴住的逃离者 |

## 3. 剧中十元互动表

| 剧中十元 | 在剧情中的形态 | 和主十元 nz 的关系 | 和辅十元 x 的关系 | 对角色造成什么变化 | 一句话故事 |
|----------|----------------|---------------------|---------------------|---------------------|------------|
| n | 家族、宫水神社、传统、口嚼酒 | n 是 nz 的载体：神社和传统把连接固定下来 | n 限制 x：传统让她无法轻易离开 | nz 从"家庭负担"变成"命运的线索" | 她讨厌神社，但神社最后成了救她的钥匙。 |
| zx | 瀧的寻找、瀧的行动 | zx 喂给 nz：他的行动证明连接是真的 | zx 回应 x：有人真的在找她、在救她 | nz 从被动的牵系变成双向的连接 | 他不是在梦里想她——他真的跑来了。 |
| xz | 彗星、死亡、时间差 | xz 要切断所有连接：死亡、遗忘、三年差 | x 升级：从"逃离"变成"活下来" | nz 的牵系让她没有放弃，x 的升级让她去行动 | 她不想死了——不是怕死，是有人在找她。 |
| zn | 名字的记忆、互换生活的日记 | zn 记录 nz 的共振 | zn 最后被 xz 切断 | nz 还在，不需要 zn 来证明 | 她不记得他叫什么，但她知道那个人存在过。 |

## 4. 生克补原因分析

| 关系类型 | 十元关系 | 是否成立 | 原因 | 对三叶 nz + x 的影响 |
|----------|----------|----------|------|----------------------|
| 生 | nz 生 x | 成立 | 牵系越深，逃离欲望越强 | x 从 nz 里长出来：想挣脱才证明被牵得紧 |
| 补 | zx 补 nz | 成立 | 瀧的行动让三叶的连接不再是单向 | nz 被验证为真实的双向连接 |
| 结果 | nz 留存 | 成立 | 名字忘记后，连接还在 | nz 不依赖记忆 |

## 5. 动态链演化

```
宫水三叶｜nz + x

故乡的引力 nz
→ n 承载 nz：神社、传统、口嚼酒
→ x 从 nz 里长出：想去东京、想被看见
→ 身体互换：nz 共振生成（与瀧）
→ zx（瀧）验证 nz：他真的在找她
→ x 升级：从"逃离"变成"活下来"
→ xz 彗星威胁：要切断一切
→ zn 被 xz 切断：名字忘了
→ nz 留存：连接不依赖名字
→ n 重建：被救回的现实，多年后重逢
```

## 6. 最短封存句

宫水三叶｜nz + x：
她被故乡和身体记忆牵住，这是 nz；她想逃离、想被看见，这是 x。身体互换生成了和瀧的 nz 共振，瀧的 zx 验证了连接不是幻觉。彗星（xz）要切断一切，但 nz 已经不需要 zn（名字/记忆）来证明了——她忘了他的名字，但连接还在。最终 n 重建：她活了下来，等到了重逢。
