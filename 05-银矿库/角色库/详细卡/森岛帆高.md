# 角色归档卡｜森岛帆高｜n + z

## 1. 角色定性

- 作品：《天气之子》
- 角色：森岛帆高
- 主十元：n
- 辅助十元：z
- 主辅合成判断：n + z
- 角色功能：用离家出走的决断去承载一段超越社会规则的关系
- 命运主题位置：n+z 空间型——在陌生城市里用行动为阳菜撑出一个世界
- 一句话判词：他的核心是 n：离家出走、打工、保护阳菜，都是在为一段关系建立承载。但驱动他的不是规则和判断（xn），而是 z——一种不计算后果的冲动和信念。

| ---- | ------ | ----------------------------- | ---------------------- |
| 主十元  | n      | 为阳菜撑出一个能活下去的世界，承载这段关系         | 帆高的行动力指向"建立承载"而非"判断对错" |
| 辅助十元 | z      | 冲向东京、冲向天空、冲向阳菜——一种不计算后果的冲动信念  | z 是帆高的燃料，也是他的盲区        |
| 角色定性 | n + z  | 用冲动驱动力去承载一段不被世界允许的关系          | 冲动型承载者                |

## 4. 生克补原因分析

| 关系类型 | 十元关系       | 是否成立      | 原因                           | 对帆高 n + z 的影响 |
| ---- | ---------- | --------- | ---------------------------- | --------------- |
| 生    | nz 生 z     | 强成立       | 阳菜的温柔和停靠点燃帆高的冲动信念            | z 因 nz 而不断加码     |
| 克    | xn 克 z     | 持续但失败     | 社会规则试图约束帆高的冲动，但每次对抗都让 z 更强    | 规则越强，冲动越烈       |
| 克    | xz 反激 z    | 强成立       | 失去阳菜不是让 z 熄灭，而是让 z 推向极限       | xz 是 z 的引爆器      |
| 承载   | n 承载 nz    | 成立但被世界否定  | 帆高的 n 能承载阳菜的 nz，但世界不承认这种承载   | 形成"与世界为敌的承载"    |

## 5. 动态链演化

`	ext
森岛帆高｜n + z

离家出走 zx → 进入东京 x并z（雨水世界）
→ 遇到阳菜 nz → z 被点燃：她是晴女，她是特别的
→ n 开始承载：打工、保护、一起生活
→ xn 社会规则介入：警察追捕、法律判断
→ xn 与 n+z 对抗 → z 反而更强
→ 阳菜献身换晴天 → xz 分离
→ z 极限爆发 → zx 冲破一切阻碍 → 飞到天上
→ n 最终承载住 nz：我不要晴天，我要你
→ 世界被雨水淹没 n，但两人的 nz 被保住了
`

## 6. 最短封存句

森岛帆高｜n + z：
他离家出走不是逃避，是 n 的前奏——他要为阳菜建立一个承载。驱动他的是 z：不计算后果的冲动和信念。当世界用 xn 规则否定他的承载，用 xz 夺走阳菜，z 反而不退反烈。最终他选择用 n 承载 nz，放任整个世界被雨水淹没。
