# 角色归档卡｜李慕白｜zn + nz

## 1. 角色定性

- 作品：《卧虎藏龙》
- 角色：李慕白
- 主十元：zn
- 辅助十元：nz
- 主辅合成判断：zn + nz
- 角色功能：以武道承载生命意义，但被未完成的情感归属所困；最终以死亡完成最后的释放
- 命运主题位置：zn+x 本体型——修道者的欲望封印与释放
- 一句话判词：他是 zn——武道宗师，以剑载道，追求生命的意义和圆满。但他也是 nz——对俞秀莲二十年的沉默情感，是他唯一不圆满的缺口。玉娇龙的出现撬开了他的 x（执念），碧眼狐狸的毒针完成了他的死亡——也是他的释放。

## 5. 动态链演化

`	ext
李慕白｜zn + nz

zn 求道：闭关修行，放下青冥剑
→ nz 缺口：对俞秀莲二十年的情感未完成
→ 送出青冥剑 → 表达放下
→ x：玉娇龙的天赋撬开执念
→ zn 转向：想收玉娇龙为徒（执念替代圆满）
→ z：玉娇龙反抗 → zn 无法收服
→ xz：碧眼狐狸毒针 → 死亡降临
→ nz 完成：死前说出"我一直深爱着你"
→ zn 圆满：不在剑里，在爱里
`

## 6. 最短封存句

李慕白｜zn + nz：
他的剑求道圆满，心却被一段沉默的情感锁住。玉娇龙的野性（x）撬开了他闭关的门，但碧眼狐狸的毒针（xz）关上了它。死前他说出了二十年没说的话——原来 zn 的圆满不在剑里，在那一句话里。
