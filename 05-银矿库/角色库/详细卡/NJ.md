# 角色归档卡｜NJ｜xn + xz

## 1. 角色定性

- 作品：《一一》
- 角色：NJ
- 主十元：xn
- 辅助十元：xz
- 主辅合成判断：xn + xz
- 角色功能：中年男人的静默漂流——用理性和责任撑住一切，但内心早已漂离
- 命运主题位置：xn+z 时间型
- 一句话判词：他是 xn——用工作、责任、理性判断撑住家庭和公司。但他在 xz 里：与妻子渐行渐远、与初恋重逢的悸动、对生活意义的沉默追问。他的 xn 维持着表面的稳定，xz 却是表面下的暗流。

## 2. 动态链

xn 建立：工作、家庭、责任
→ xz 暗流：婚姻冷却、中年危机
→ z：与初恋重逢，短暂的重新燃烧
→ xn 拉回：回到家庭
→ xz 持续：生活不是问题解决了，是继续漂流

## 3. 最短封存句

NJ｜xn + xz：他用理性撑住生活，但生活在他撑住的同时悄悄漂走了。重逢初恋不是出轨的冲动，是 z 在 xz 里短暂亮了一下。然后他回到家庭——不是胜利，是继续漂流。
