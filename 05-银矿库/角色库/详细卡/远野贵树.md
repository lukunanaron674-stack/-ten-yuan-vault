# 角色归档卡｜远野贵树｜z + nx

## 1. 角色定性

* 作品：《秒速5厘米》
* 角色：远野贵树
* 主十元：z
* 辅助十元：nx
* 主辅合成判断：z + nx
* 角色功能：保存最初连接，但无法让连接变成新的生活
* 命运主题位置：执念活着但归宿永远空着的一方
* 一句话判词：他一直找明里，这是 z；但他找不到之后不是放下，而是不再开始任何新连接，这是 nx。

## 2. 主辅十元解释

| 位置 | 十元 | 内容 | 判断 |
|------|------|------|------|
| 主十元 | z | 保存最初连接：思念、约定、旧日信纸、"我们曾经通" | 贵树的核心不是行动，而是保存 |
| 辅助十元 | nx | 暗流：无法进入新现实、无法建立新关系、独自行走 | nx 是 z 过度保存后的必然结果——不放下就进不去新生活 |
| 角色定性 | z + nx | 保存过去，暗流阻止未来 | 永远在路上的寻找者 |

## 3. 剧中十元互动表

| 剧中十元 | 在剧情中的形态 | 和主十元 z 的关系 | 和辅十元 nx 的关系 | 对角色造成什么变化 | 一句话故事 |
|----------|----------------|-------------------|---------------------|---------------------|------------|
| xz | 距离、时间、火车、转学、成年后的各自生活 | xz 一直切断 z 指向的对象：明里越来越远 | xz 喂养 nx：距离越大，暗流越强，越不相信新连接 | z 在 xz 里像钉子，钉在胸口的星点——亮，但不能照路 | 每一次拉开距离，都让思念更亮，也让进入现实的通道更窄。 |
| n | 新关系、新城市、新生活 | n 永远接不住 z：z 指向过去，不在现在的 n 里 | nx 让 n 无法建成：暗流阻止任何可能的新归宿 | 贵树有日常生活，但 n 是空心的 | 他在城市里活着，但"活着"和"有归宿"是两回事。 |
| nz | 明里的思念、旧日柔情、铁道口的约定 | nz 是 z 指向的对象：明里那边还有思念 | nx 让贵树这边的 nz 无法落地：他保存的是对方过去的样子，不是真实的人 | nz 还在，但属于两个人的 nz 已经被 xz 分开 | 两个人心里都有对方，但心里的对方和现实里的对方已经对不上了。 |
| zx | 贵树主动去见明里（第一话）、贵树主动离开 | 早期 zx 让 z 有机会被满足 | 后来 zx 变成反向：贵树主动切断连接 | 唯一的行动发生在最早，之后只有保存没有行动 | 他曾经追过一次，后来再也没有为任何人跑起来。 |

## 4. 生克补原因分析

| 关系类型 | 十元关系 | 是否成立 | 原因 | 对贵树 z + nx 的影响 |
|----------|----------|----------|------|----------------------|
| 生 | xz 生 nx | 持续成立 | 距离和时间越大，暗流越强 | nx 随 xz 增长而加深 |
| 克 | z 未能克 xz | 持续成立 | z 只有保存没有行动，无法对抗现实距离 | z 在，但 xz 赢了 |
| 结果 | n 永远建不起来 | 持续成立 | z 保存过去 + nx 阻止未来 = n 没有立足之地 | 归宿空心 |

## 5. 动态链演化

```
远野贵树｜z + nx

最初的连接
→ z 开始保存：思念、约定、信
→ zx 唯一的主动：坐火车去见明里
→ xz 拉开距离：转学、时间、成年
→ z 过度保存：明里变成不可替代的记忆
→ nx 暗流生成：不再相信新连接
→ n 无法建成：新城市、新关系都是空壳
→ 铁道口：nz 还在，但 xz 赢了
→ 两人各自走开，不再回头
```

## 6. 最短封存句

远野贵树｜z + nx：
他一直保存最初连接，这是 z；但保存到无法开始任何新关系，这是 nx。xz（距离/时间）不断拉开他和明里，nx 随之加深，让 n 永远建不起来。铁道口那一幕：两人都认出了对方，但火车（xz）隔开后，他们不再回头——nz 还在，但已经不属于同一条轨道了。
