# 角色归档卡｜刘建明｜xn + x

## 1. 角色定性

- 作品：《无间道》
- 角色：刘建明
- 主十元：xn
- 辅助十元：x
- 主辅合成判断：xn + x
- 角色功能：黑帮卧底警察——用规则和身份伪装自己，但内心被欲望和恐惧驱动
- 命运主题位置：zx+nx 因果型——每一个选择都在为"想做好人"的欲望付出代价
- 一句话判词：他不是天生的恶人，他是被 x（欲望：想做好人、想活下去、想拥有正常人生）驱动的人。他用 xn（警察身份、规则、程序）来包装 x，但 x 最终撕裂了 xn。

## 6. 最短封存句

刘建明｜xn + x：
他的警察身份是欲望的面具。x 驱动他清除一切威胁，xn 帮他把罪行包装成正义。但在持续的身份撕裂（xz）中，xn 最终崩塌，留下的只有"我想做好人"这个永远无法抵达的 nz。
