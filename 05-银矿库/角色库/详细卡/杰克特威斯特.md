# 角色归档卡｜杰克·特威斯特｜z + nz

## 1. 角色定性

- 作品：《断背山》
- 角色：杰克·特威斯特 (Jack Twist)
- 主十元：z
- 辅助十元：nz
- 主辅合成判断：z + nz
- 角色功能：用不灭的渴望和温柔不断靠近恩尼斯，想要一个共同生活
- 命运主题位置：xz+nz 命运型——渴望被恐惧反复拒绝
- 一句话判词：他是 z：不断燃烧的渴望，不计算后果。他也是 nz：想要归属，想要一起生活的柔软。但恩尼斯的 xz 反复拒绝他的靠近，最终他死在了对归属的渴望里。

## 3. 剧中十元互动表

| 剧中十元 | 在剧情中的形态                     | 和主十元 z 的关系                          | 和辅十元 nz 的关系                         | 对角色造成什么变化                                     | 一句话故事                                                  |
| ---- | --------------------------- | ----------------------------------- | ----------------------------------- | --------------------------------------------- | ------------------------------------------------------ |
| n    | 恩尼斯的承载：定期见面、维持关系             | n 回应 z：恩尼斯的承载让杰克的渴望有落脚点           | n 是 nz 的对象：杰克的归属指向恩尼斯的承载            | n 越稳定，z 越烈；n 越退缩，z 越痛                         | 恩尼斯给的每一寸承载，都让杰克想要得更多。                                 |

## 4. 动态链

`	ext
杰克·特威斯特｜z + nz

断背山 z + x并z：渴望和归属在山上完整
→ 下山后恩尼斯 xz 退缩
→ z 不断靠近 → 被 xz 拒绝
→ nz 无法落地 → 痛苦积累
→ 杰克死亡（意外/仇恨）
→ nz 永未完成
`

---

## 5. 最短封存句

杰克·特威斯特｜z + nz：
他的渴望像火一样不灭，他的温柔指向一个人。但恩尼斯的恐惧（xz）是一堵墙，他的 z 撞了二十年，nz 等了二十年。最终他的死不是意外——是对归属的渴望太烈，而墙太高。
