# 角色归档卡｜苏菲｜n + z

## 1. 角色定性

- 作品：《哈尔的移动城堡》
- 角色：苏菲
- 主十元：n
- 辅助十元：z
- 主辅合成判断：n + z
- 角色功能：被诅咒变老后反而自由——用日常承载所有人的破碎
- 一句话判词：她是 n——打扫、做饭、吵架、保护所有人。z——冲进皇宫面对萨丽曼、把心脏还给哈尔。诅咒让她变成老婆婆——反而放开了"年轻漂亮"的束缚。n让城堡能住人，z让她敢面对任何魔法。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和n的关系 | 和z的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 被荒地魔女诅咒变老 | xz推动n——变老让她不再在乎外表 | xz激发z——不在乎了就敢了 | 镜子里是老婆婆——她笑了：原来老了这么自由 |
| x并z | 移动城堡——卡尔西法、马鲁克、垃圾堆 | x并z是n的容器——城堡需要她 | x并z激发z——城堡是可以飞的 | 她把垃圾堆变成了家——卡尔西法的火更亮了 |
| nz | 哈尔的心脏——被接住了 | nz被n承载——日常守护了他 | nz被z夺回——她把心脏还给他 | 她把心脏放回哈尔的胸口——不是魔法，是归还 |

## 3. 最短封存句

苏菲｜n+z：被诅咒变老婆婆——反而自由了。n把垃圾堆变成家，z冲进皇宫面对一切。心脏还给哈尔——n不是被保护，是她在保护所有人。城堡飞着——她让它落了地。
