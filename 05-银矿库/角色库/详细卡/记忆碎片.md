# 角色归档卡｜赛琳｜z + xn

## 1. 角色定性

- 作品：《爱在黎明破晓前》
- 角色：赛琳
- 主十元：z
- 辅助十元：xn
- 主辅合成判断：z + xn
- 角色功能：被陌生人的冲动点燃——在维也纳一夜里比对方更清醒也更投入

## 2. 最短封存句

赛琳｜z+xn：她下了火车——那一秒的冲动改变了一切。但她的xn比杰西更清醒——"我们不会再见面了"。清醒不影响投入——她知道天会亮，还是把这一夜过完了。

# 角色归档卡｜莱纳德｜xn + zx

## 1. 角色定性

- 作品：《记忆碎片》
- 角色：莱纳德
- 主十元：xn
- 辅助十元：zx
- 主辅合成判断：xn + zx
- 角色功能：用照片和纹身重建判断系统——但判断系统本身就是谎言
- 一句话判词：他是 xn——失忆后靠照片、纹身、便签建立判断系统。zx——每一次行动都在"复仇"。但纹身可能是他自己刻的谎言——xn不是真相的守护者，是谎言的建造师。"我要相信世界不是我想象出来的"——但他想象出了一切。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和xn的关系 | 和zx的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| x | 复仇欲望——"John G杀了我妻子" | x是xn+zx的燃料——欲望驱动判断和行动 | - | 他追了整部电影的人——可能是他自己 |
| nz | 妻子的记忆——唯一真实的归属 | nz被xn篡改——记忆不可靠 | nz被zx利用——复仇以爱之名 | 他记得妻子——但不记得是自己害了她 |
| xz | 失忆——永恒的碎片化漂流 | xz是xn的源头——失忆才需要纹身 | xz让zx无限循环——每一次都是第一次 | 每次醒来都是新的世界——旧的仇恨还在纹身上 |

## 3. 最短封存句

莱纳德｜xn+zx：纹身是他的记忆，照片是他的真相。但纹身可能是自己刻的谎言——xn不是真相的守卫，是谎言的建筑师。"我要相信"——但他信仰的一切都是自己造的。
