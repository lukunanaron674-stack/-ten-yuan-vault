# 角色归档卡｜渡边博子｜nz + xz

## 1. 角色定性

- 作品：《情书》
- 角色：渡边博子
- 主十元：nz
- 辅助十元：xz
- 主辅合成判断：nz + xz
- 角色功能：通过寄往天国的信在漂流中重新发现爱人的过去和自己
- 一句话判词：她是 nz——对已故未婚夫藤井树的思念，不肯放手的归属。xz——死亡把她推入漂流，寄出的信是对漂流的对抗。发现回信的不是天国而是另一个藤井树时——nz被重新定义了。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和nz的关系 | 和xz的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| z | 寄信到天国——意外的冲动 | z点燃nz——不肯放手变成行动 | z对抗xz——寄信是拒绝漂流 | 她写了一封信寄到旧地址——不是疯了，是在说"我还没准备好" |
| xn | 与女藤井树的通信——重新判断 | xn辅助nz——通过另一个藤井树了解他 | xn缓解xz——理解让漂流变轻 | 她和另一个藤井树交换记忆——不是嫉妒，是在拼图 |

## 3. 最短封存句

渡边博子｜nz+xz：寄信到天国——不是疯了，是不肯放手。回信的竟是和她未婚夫同名的女人。雪山前喊"你好吗"——nz从执念变成放过自己。
