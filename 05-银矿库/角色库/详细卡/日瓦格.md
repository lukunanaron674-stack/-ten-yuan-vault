# 角色归档卡｜尤里·日瓦格｜zn

## 1. 角色定性

- 作品：《日瓦格医生》
- 角色：尤里·日瓦格
- 主十元：zn
- 辅助十元：无
- 主辅合成判断：zn
- 角色功能：诗人——活着就是为了写诗，在历史暴风雪中坚持追问意义
- 命运主题位置：zn 本体型——纯粹的意义追问者
- 一句话判词：他就是 zn。不是职业是诗人——是存在方式。革命、战争、流离——这些 xz 只是他写诗的背景，不是他的结构。他对拉拉的爱、对病人的温柔——那些是 zn 的温度，也不喧宾夺主。他死在电车上，拉拉读到了他的诗。zn 不需要辅十元——诗本身就是全部。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和zn的关系 | 变化 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 革命、战争、流离、时代碾压 | xz是zn的背景——不是结构 | 时代越暴力，诗越必要 | 外面在革命，他在写诗——拉拉的名字藏在每一行里 |
| z | 对拉拉的爱 | z给zn温度——诗有了对象 | 爱让诗不是抽象的追问 | 他在雪地里写——不是给世界，是给她一个人 |
| nz | 对病人的温柔、对拉拉的归属 | nz是zn在人间的温度 | 诗人的心不是冷的 | 他救过很多人——但救不了拉拉，也救不了自己 |
| n | 冬妮娅的家庭、医学职业 | n承载zn的物质基础 | n断裂后zn更纯 | 冬妮娅带着孩子走了——他只剩诗和拉拉 |

## 3. 生克补原因分析

| 关系类型 | 十元关系 | 是否成立 | 原因 | 影响 |
| ---- | ---- | ---- | ---- | ---- |
| 克 | xz想克zn | 失败 | 时代想消灭意义，诗不死 | 诗比暴风雪活得久 |
| 留 | zn留痕 | 成立 | 诗留下来 | 拉拉读到了 |

## 4. 动态链

zn：活着就是写诗
→ xz笼罩：革命、战争——诗的背景
→ z点燃：拉拉——诗有了对象和温度
→ nz+ n：爱和家庭——诗的人间锚点
→ xz加深：一切被碾碎
→ zn更纯：只剩下诗
→ 死在电车上
→ zn不灭：拉拉读到了诗

## 5. 最短封存句

尤里·日瓦格｜zn：他不是因为战争才写诗——有没有战争他都是诗人。xz只是背景，z只是温度，nz只是锚点。去掉所有辅十元，他还是那个在雪地里写诗的人。死在电车上——拉拉读到了。诗是温柔的考古学。
