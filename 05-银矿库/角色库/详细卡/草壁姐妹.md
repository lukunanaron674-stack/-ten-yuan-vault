# 角色归档卡｜草壁姐妹｜n + x并z

## 1. 角色定性

- 作品：《龙猫》
- 角色：草壁皋月、草壁小梅
- 主十元：n（姐妹互载）
- 辅助十元：x并z（乡村自然的魔法空间）
- 主辅合成判断：n + x并z
- 角色功能：妈妈住院期间，用日常承载和自然魔法承接恐惧
- 一句话判词：皋月是 n——照顾妹妹、上学、做饭。小梅是 z——天真冲动，追龙猫。x并z——龙猫、猫巴士、大樟树——不是幻想，是两个孩子在困境中需要的魔法容器。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和n的关系 | 和x并z的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 妈妈住院——恐惧和不安 | xz是n的背景——为什么要承载 | xz被x并z缓解——自然消解焦虑 | 妈妈不知道什么时候能回家——她们在树洞里等 |
| z | 小梅的天真——追龙猫、掉进树洞 | z给n带来意外——发现魔法 | z打开x并z——孩子才能看见龙猫 | 小梅掉进了树洞——不是掉下去，是掉进去 |
| nz | 龙猫的陪伴——猫巴士、雨夜站台 | nz支撑n——魔法给日常温度 | nz通过x并z显现 | 雨夜站台上龙猫站在旁边——什么都没说，但她在笑 |

## 3. 动态链

xz：妈妈住院
→ n：皋月承载日常
→ z：小梅发现龙猫
→ x并z：自然魔法打开
→ nz：龙猫陪伴
→ x并z+n：猫巴士飞越田野
→ 妈妈安全——n完成

## 4. 最短封存句

草壁姐妹｜n+x并z：妈妈在医院，皋月撑着日常，小梅追着龙猫。x并z不是逃避——是乡村给了她们能装下恐惧的魔法容器。猫巴士在电线上跑过——所有不安被夜风吹散。
