# 角色归档卡｜史派克·斯皮格尔｜xz + nz

## 1. 角色定性

- 作品：《星际牛仔》
- 角色：史派克·斯皮格尔
- 主十元：xz
- 辅助十元：nz
- 主辅合成判断：xz + nz
- 角色功能：一只眼睛看过去一只眼睛看现在——过去是永恒的xz，Bebop号是暂时的nz
- 一句话判词：他是 xz——"我已经死过一次了"——被过去追杀的人，在宇宙里漂流。nz——Bebop号、杰特、菲、爱因——船上的人在给他一个临时的家。最后他走向红龙总部——xz赢了。但倒下前他说"砰"——那是给nz最后的告别。

## 3. 最短封存句

史派克｜xz+nz：一只眼睛看过去，一只眼睛看现在。xz是红龙的追杀，nz是Bebop号上的青椒肉丝。最后他走向了过去——倒下前说了"砰"。那不是给敌人的，是给船上的家人的。
