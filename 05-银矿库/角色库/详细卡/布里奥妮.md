# 角色归档卡｜布里奥妮｜xn + xz

## 1. 角色定性

- 作品：《赎罪》
- 角色：布里奥妮·塔利斯
- 主十元：xn
- 辅助十元：xz
- 主辅合成判断：xn + xz
- 角色功能：用一生写作赎一个童年判断犯下的罪——但罪无法赎回
- 一句话判词：她是 xn——13岁用错误判断指认罗比，毁掉姐姐和他的一生。xz——长大后知道真相，用写作试图赎罪——但xz不可逆。小说给了他们幸福结局——那是xn最后的忏悔，不是真的。

## 3. 最短封存句

布里奥妮｜xn+xz：13岁一句话毁掉两个人。一辈子写作赎罪——小说给了幸福结局。但塞西莉亚淹死在地铁，罗比死在敦刻尔克。她以为写作能赎罪——但xz不给第二次机会。
