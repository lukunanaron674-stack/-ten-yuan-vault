# 角色归档卡｜约翰·李贝特｜xn + x

## 1. 角色定性

- 作品：《怪物》
- 角色：约翰·李贝特
- 主十元：xn
- 辅助十元：x
- 主辅合成判断：xn + x
- 角色功能：用完美的判断系统操纵一切——但空洞的内心是x也填不满的深渊

## 2. 最短封存句

约翰｜xn+x：他操纵了所有人——杀人不需要动手，只需要一句话。xn是完美的——但x是空的。"我是什么？"——怪物。天马没开枪——他失望了，还是解脱了？不知道。怪物不需要被杀死——需要被看见。
