# 角色归档卡｜泰勒·德顿｜x + z

## 1. 角色定性

- 作品：《搏击俱乐部》
- 角色：泰勒·德顿
- 主十元：x
- 辅助十元：z
- 主辅合成判断：x + z
- 角色功能：杰克分裂出的暴力人格——x是欲望，z是表达
- 一句话判词：他是 x——杰克压抑的一切：暴力、自由、反叛。z是他的表达——搏击俱乐部、混乱计划、炸大楼。他不是真实的人——是杰克zn追问的x答案。杰克朝自己开枪——泰勒死了。x可以烧掉一切，但烧不掉zn。

## 2. 最短封存句

泰勒·德顿｜x+z：他是杰克不敢做的所有事。x是压抑的爆炸，z是炸的方式。搏击俱乐部、炸大楼——不是革命，是发泄。杰克朝自己开枪——泰勒死了。x烧完了，zn活了下来。
