# 角色归档卡｜姜仁浩｜nx + z

## 1. 角色定性

- 作品：《熔炉》
- 角色：姜仁浩
- 主十元：nx
- 辅助十元：z
- 主辅合成判断：nx + z
- 角色功能：用追寻真相的行动对抗体制——"我们一路奋战，不是为了改变世界，而是为了不让世界改变我们"
- 一句话判词：他是 nx——美术老师发现虐待真相后追寻正义。z——被孩子们的眼神点燃的愤怒。nx让他不停上诉，z让他在法庭外跪下来。官司输了——但nx+z没输：水炮前抱着民秀遗照喊的那句话。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和nx的关系 | 和z的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| x | 校长、警察、法院——体制的墙 | x对抗nx——体制不容追寻 | x点燃z——愤怒因不公而起 | 校长用金钱和法律砌了一堵墙——他撞了无数次 |
| nz | 孩子们——聋哑学生的信任 | nz是nx的理由——为他们追寻 | nz是z的燃料——他们的眼神就是火 | 孩子们用手语说"帮帮我们"——那是nx和z全部的起点 |
| xz | 民秀的死亡——最后的打击 | xz差点摧毁nx——追寻失去了对象 | xz让z烧到最亮——愤怒在水炮前爆发 | 民秀死在铁轨上——他抱着遗照面对水炮，没退一步 |
| zn | "我们一路奋战" | zn是nx+z的结语 | - | 官司输了——但他说的话，整个韩国都听到了 |

## 3. 最短封存句

姜仁浩｜nx+z：他不是记者不是律师——是一个美术老师。孩子们用手语说"救救我们"——他变成了战士。民秀死了，官司输了。水炮前他喊的那句话——nx没输。
