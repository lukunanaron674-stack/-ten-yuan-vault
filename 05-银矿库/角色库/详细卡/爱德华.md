# 角色归档卡｜爱德华·艾尔利克｜zn + x

## 1. 角色定性

- 作品：《钢之炼金术师》
- 角色：爱德华·艾尔利克
- 主十元：zn
- 辅助十元：x
- 主辅合成判断：zn + x
- 角色功能：用等价交换追问生命的价值——一即是全，全即是一
- 一句话判词：他是 zn——炼金术的真谛不是力量，是理解世界的法则。"一即是全，全即是一"——在宇宙里找到自己的位置。x——为救弟弟失去一手一脚、不断追寻贤者之石——欲望驱动每一步。"等价交换"不是规则，是zn+x的平衡术。最后用真理之门换回阿尔——zn的答案：生命不能用等价衡量。

| 剧中十元 | 形态 | 和zn的关系 | 和x的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 失去手脚、阿尔失去身体——"我们的错" | xz是zn的起点——为什么追问 | xz是x的代价——欲望的后果 | 他们在雨里喊妈妈——那不是炼金术，是两个孩子的绝望 |

## 3. 最短封存句

爱德华·艾尔利克｜zn+x：等价交换是炼金术的法则——但不是生命的。zn让他追问"一即是全"，x让他为阿尔失去一切。最后用真理之门换回弟弟——zn的答案：生命从来不等价。妈妈回不来了——但阿尔可以。
