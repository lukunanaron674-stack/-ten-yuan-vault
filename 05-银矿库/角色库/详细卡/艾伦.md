# 角色归档卡｜艾伦·耶格尔｜zx + nx → x

## 1. 角色定性

- 作品：《进击的巨人》
- 角色：艾伦·耶格尔
- 主十元：zx → x
- 辅助十元：nx
- 主辅合成判断：zx+nx → x（演化型）
- 角色功能：从追寻自由的少年变成毁灭世界的怪物——自由的定义在行动中扭曲
- 一句话判词：他是 zx——每一步都在行动：加入调查兵团、发动地鸣。nx——"我要自由"——从保护墙内到毁灭墙外。但 zx 和 nx 在时间线的闭环里变成了 x——灭世的欲望。"因为我出生在这个世界上"——那不是理由，是 x 最终的独白。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和zx+nx的关系 | 变化 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 墙——玛利亚之墙被破、母亲的死亡 | xz是zx的起点——必须行动 | xz永不消失——墙外的世界也是墙 | 母亲被巨人吃掉——那一天他不再哭 |
| n | 三笠、阿尔敏——最初的承载 | n承载nx——他们的信任让他是人 | n被x踩碎——"我最讨厌你"——他推开了一切 | 他对三笠说了最狠的话——不是真的，是为了让她能杀他 |
| zn | 海边——"如果杀了对面，我们就自由了吗？" | zn是nx的追问——自由到底是什么 | zn被x吞没——不再问，只做 | 他指着海对面——"那里的人"——不是敌人，是人 |
| xn | 进击的巨人——能看到未来 | xn锁死zx——未来已经注定 | xn让x变成必然——他看到了，所以做了 | 他看到自己会踩死所有人——他还是踩了 |

## 3. 动态链

zx：加入调查兵团→每一次战斗
→ nx：追寻自由
→ 地下室真相 → zn：自由是什么
→ 进击的未来记忆 → xn：一切已注定
→ zx+ nx + xn → x：发动地鸣
→ n被踩碎，nx被骂成谎言
→ x的独白："因为我出生在这个世界上"

## 4. 最短封存句

艾伦·耶格尔｜zx+nx→x：他追寻自由的每一步都在靠近灭世。zx让他战斗，nx让他不放弃——但时间线的闭环把一切变成了x。"因为我出生在这个世界上"——不是理由，是x烧尽了所有之后剩下的唯一一句话。
