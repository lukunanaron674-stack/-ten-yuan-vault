# 角色归档卡｜荻野千寻｜n + z

## 1. 角色定性

- 作品：《千与千寻》
- 角色：荻野千寻
- 主十元：n
- 辅助十元：z
- 主辅合成判断：n + z
- 角色功能：用劳动和善意在奇幻世界中承载自己和他人的救赎
- 命运主题位置：x并z+n 空间型
- 一句话判词：她的核心是 n——在油屋打工、照顾河神、拯救白龙，每一步都是在建立承载。驱动她的不是判断，而是 z——不计后果的勇敢和善良。她不是变强了，是 n 让她在这个世界里站住了。

## 2. 主辅十元解释

| 位置   | 十元     | 内容                            | 判断                     |
| ---- | ------ | ----------------------------- | ---------------------- |
| 主十元  | n      | 劳动、坚持、承载父母和白龙的救赎              | 她的成长不是能力提升，是承载能力提升      |
| 辅助十元 | z      | 不计算后果的勇敢：走进隧道、登上水上列车、直面汤婆婆     | z 是她在恐惧中仍能行动的理由         |
| 角色定性 | n + z  | 用冲动勇敢驱动日常承载                   | 成长型承载者                |

## 3. 剧中十元互动表

| 剧中十元 | 形态 | 和 n 的关系 | 和 z 的关系 | 变化 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| x并z | 油屋、汤泉、神灵世界 | x并z 是 n 的容器和考验 | x并z 激发 z：恐惧转化为行动 | 在奇幻世界里找到自己的位置 | 油屋吃了很多人——但她没被吃掉，她用劳动换回了名字 |
| x | 汤婆婆的贪婪、无脸男的吞噬 | x 威胁 n：贪婪想吞掉承载 | x 被 z 克住：她的单纯不被污染 | 她不贪，所以她不败 | 无脸男撒了一地金子——她看都没看，她在找白龙 |
| nz | 白龙的温柔、锅炉爷爷、小玲 | nz 支撑 n：善意让她承载更多 | nz 回应 z：确认勇敢是对的 | 她不是一个人在撑 | 白龙记得她的真名，锅炉爷爷给了她被子，小玲教她拧毛巾——每个人给了她一点光 |
| xz | 父母变猪、名字被夺、被困异界 | xz 是 n 要对抗的对象 | xz 被 n+z 克住 | 恐惧没压垮她，反而让她更坚定 | 父母在猪圈里哼哼——她不怕变成那样，怕的是忘记自己叫荻野千寻 |

## 4. 动态链

xz 进入异界：父母变猪，名字被夺
→ z 被恐惧激发：必须行动
→ n 建立：在油屋工作，照顾河神
→ x并z 容纳 n：异界成为道场
→ nz 支撑：白龙、锅炉爷爷、小玲
→ x 贪婪诱惑 → z 不被污染
→ n 最终承载：救回父母，找回名字

## 5. 最短封存句

荻野千寻｜n + z：不是天生的勇者，是在油屋里一点一点学会承载的人。z 让她敢走进去，n 让她能坚持到底。名字差点被吃掉——但 n 和 z 一起把它抢了回来。
