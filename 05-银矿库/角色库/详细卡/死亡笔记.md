# 角色归档卡｜夜神月｜xn + x

## 1. 角色定性

- 作品：《死亡笔记》
- 角色：夜神月
- 主十元：xn
- 辅助十元：x
- 主辅合成判断：xn + x
- 角色功能：用"正义"的判断系统包装成为神的欲望——xn是x的面具
- 一句话判词：他是 xn——"我要成为新世界的神"——正义是他的判断系统：谁该死、谁该活。x——不是正义，是成为神的欲望。xn让他的杀戮看起来像审判，x让他从正义走向暴君。"我就是正义"——xn和x的边界消失的那一刻，他输了。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和xn的关系 | 和x的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| zx | 写下一个又一个名字 | zx是xn+x的落地——判断+欲望=死亡 | - | 第一个名字写下去手是抖的——第一百个名字写下去是笑的 |
| nx | L——追寻Kira的侦探 | nx对抗xn——L的判断系统 vs 月的判断系统 | nx暴露x——L知道他不够正义 | L在他面前吃甜点——那是挑衅，也是审判 |
| nz | 父亲、妹妹——正常人的归属 | nz被xn利用——父亲是警察局长，是月的保护伞 | nz被x牺牲——为了成为神可以失去一切 | 父亲死在他面前——他问的不是"爸爸怎么样"，是"笔记本写了吗" |
| xz | 被追捕——Kira的身份漂流 | xz是xn+x的代价——不能被看见 | xz最终降临——松田开枪 | 仓库里他被松田打穿——不是L赢的，是他自己的人性输的 |

## 3. 最短封存句

夜神月｜xn+x：他用正义给杀人上色——xn是面具，x是神化的欲望。L让他露出了裂缝——当他说"我就是正义"时，xn和x已经分不清了。仓库里的血不是惩罚——是他把自己的人性一点一点写进了笔记本。

# 角色归档卡｜L｜nx + xn

## 1. 角色定性

- 作品：《死亡笔记》
- 角色：L
- 主十元：nx
- 辅助十元：xn
- 主辅合成判断：nx + xn
- 角色功能：用怪异的判断系统追寻Kira——追寻本身就是存在方式

## 2. 最短封存句

L｜nx+xn：蹲在椅子上吃甜点——不是怪癖，是他的xn不需要符合任何人的期待。nx让他追Kira——不是因为他是好人，是因为这是唯一有趣的案子。死前对月说"再见了"——他早就知道了，只是想看到最后。
