# 角色归档卡｜香田幸｜n + xn

## 1. 角色定性

- 作品：《海街日记》
- 角色：香田幸
- 主十元：n
- 辅助十元：xn
- 主辅合成判断：n + xn
- 角色功能：用护士职业和长姐责任承载三姐妹——也承载父亲的背叛带来的伤口
- 一句话判词：她是 n——照顾妹妹们、维持家的运转。xn——对父亲的怨恨和判断、对有妇之夫的感情判断。x并z——镰仓的海、梅酒、樱花——让n不干燥。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和n的关系 | 和xn的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 父亲出轨、母亲离开——家庭破碎 | xz是n的起点——必须有人承载 | xz形成xn——对父亲的怨恨 | 父亲走的时候她一个人撑起了三个妹妹 |
| zx | 接回同父异母的妹妹铃 | zx是n的扩展——承载更多人 | zx软化xn——铃是无辜的 | 她看了铃一眼——不需要道歉，只需要一个房间 |
| x并z | 镰仓——梅酒、海鲜、花火、樱花隧道 | x并z给n温度——日常有味道 | x并z缓解xn——海风吹散怨恨 | 梅酒是外婆的配方——她喝着，想起了妈妈 |

## 3. 最短封存句

香田幸｜n+xn：撑起三个妹妹的生活，继承了父亲出轨的伤口。接回铃——不是原谅父亲，是给自己重新开始的机会。梅酒每年都泡——外婆的配方，镰仓的味道。n不只是责任——是可以喝的。
