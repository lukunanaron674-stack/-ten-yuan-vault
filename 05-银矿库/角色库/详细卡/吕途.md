# 角色归档卡｜吕途｜n + xz

## 1. 角色定性

- 作品：《我们一起摇太阳》
- 角色：吕途
- 主十元：n（承载）
- 辅助十元：xz（脑瘤、死亡倒计时）
- 主辅合成判断：n + xz
- 角色功能：在死亡倒计时中承载母亲和凌敏的未来——从替别人安排到替自己求生
- 命运主题位置：xz+nz 命运型
- 一句话判词：他是 n——想在自己消失前为母亲和凌敏留下能继续生活的承载。xz 是背景：脑瘤、死亡倒计时、身体不可控。他的 n 不是软弱，是在 xz 里为别人撑住的沉默力量。凌敏的 x 反过来点燃他重新求生的欲望——n 从"替别人安排后路"变成"替自己找一个活路"。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和 n 的关系 | 和 xz 的关系 | 变化 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| xz | 脑瘤、死亡倒计时 | xz 是 n 的背景：承载在倒计时中进行 | 无 | 时间越少，n 越急迫 | 医生说还有半年——他把每一天都花在凌敏和妈妈身上，不是等死，是铺路 |
| zx | 回应凌敏的荒诞征婚、陪伴治疗 | zx 是 n 的落地：承载需要行动 | zx 对抗 xz：每一次行动都是对倒计时的反击 | n 通过 zx 实现 | 凌敏的征婚视频全网都在笑——他笑不出来，他回了私信 |
| x并z | 假婚姻外壳——荒诞的约定 | x并z 承载 n 的起点 | x并z 暂时掩盖 xz | 他们领了证像做交易——但每天一起透析、一起吃饭，假的变成了真的 | 他们用最荒唐的方式开始，走到了最真的地方 |
| z | 凌敏的 x 求生欲 | 凌敏的 x 点燃吕途的 n：从安排死亡到重新向生 | z 被 n 接住：她的锋利有地方放 | n 从"为别人"变成"为自己" | 凌敏骂他"你凭什么替我做决定"——他被骂醒了：原来我也可以想要 |

## 3. 动态链

xz 脑瘤压迫 → n 托付母亲
→ 回应凌敏的请求 → zx 行动
→ x并z 假婚姻外壳
→ n 日常承载：照顾凌敏、陪治疗
→ 凌敏的 x 点燃他的 n → 重新求生
→ zn：从安排死亡变成想继续活着

## 4. 最短封存句

吕途｜n + xz：他看起来散漫，其实在用最后的时间为两个女人铺路。n 是沉默的承载——照顾凌敏、陪治疗、为母亲安排后路。但凌敏的 x 反过来点燃了他——n 从"替别人安排"变成"替自己找一个活路"。死亡还在，但他不想只是等了。
