# 角色归档卡｜寄生虫金家｜多元十元阶级链

## 1. 角色定性

- 作品：《寄生虫》
- 角色：金家四口（金基泽、忠淑、基宇、基婷）
- 类型：zx+nx——精心设计的行动链与阶级追寻
- 一句话判词：金家不是恶人——是被 zx（伪造、替换、潜入）和 nx（向上爬）驱动的人。地下室那扇门是 zx 的反噬——他们的设计里没有留后路。

## 2. 四口人十元

| 角色 | 十元 | 功能 | 一句话故事 |
|------|------|------|------|
| 金基泽 | n + x | 承载家庭，被x阶级愤怒压垮 | 他最后捅了朴社长——不是因为恨他，是因为他捏着鼻子 |
| 忠淑 | nx + zx | 行动力最强，伪造的执行者 | 她踢开了地下室的门——那一脚是 nx 的全部愤怒 |
| 基宇 | z + nx | 冲动+向上追寻 | 他抱着那块石头走进地下室——不是武器，是执念 |
| 基婷 | xn + z | 判断最准+演技最高 | 她抽烟的样子最像有钱人——xn 让她比谁都懂阶级 |

## 3. 动态链

z+nx：基宇伪造学历进入朴家
→ xn+zx：基婷设计，全家逐步替换
→ n：金基泽成为司机
→ x并z：朴家豪宅——阶级外壳
→ xz：地下室男人——阶级真相暴露
→ x：金基泽杀死朴社长
→ xz永恒：金基泽躲入地下室

## 4. 最短封存句

寄生虫金家：zx太精妙的后果是忘了留后路。从伪造学历到全家潜入——梯子断了，所有人摔回地下室。金基泽那一刀不是杀人——是x在xz里最后的反咬。
