# AKIRA（铁雄/AKIRA 元存在）
> 归档：`05-银矿库/角色库/阿基拉_铁雄AKIRA.md`

---

## 1. 主十元判断

**主十元：zn（阳土·这件事是/回归本质）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zn，AKIRA就是一股纯能量——无意义、无方向、无意志。但AKIRA不仅仅是"爆炸的核"，它是**终极的"我是"**。它不争辩、不对抗、不选择——它就是存在本身。阿基拉不存在于过去或未来，它就是现在。铁雄被它接走的那一刻，不是被杀死，是被"接回了本源"。
- **第2问（反复面对什么结构）：** 反复面对「接纳还是拒绝」。AKIRA不强迫——它在等待。铁雄一直在抗拒它的力量，直到最后放弃抵抗。AKIRA的结构是"你准备好了就可以来"。
- **第3问（最怕失去什么）：** AKIRA没有"恐惧"——它就是力量本身。但如果一定要说它的"反面"——它最怕的是人类用恐惧去理解它。铁雄的恐惧让力量变成了毁灭。
- **第4问（回到哪个感觉）：** AKIRA不需要"回到"某个感觉——它一直在那里。电影中那个初始的"阿基拉"是一个被封印在实验室下的能量体——它在沉睡中等待。
- **第5问（副十元服务谁）：** x（存在/现象）是zn的物理面——AKIRA不是抽象的哲学概念，它是具体存在的、可以让新东京化为废墟的实际力量。x让它能被"看见"和"感知"。

## 2. 副十元

**副十元：x（阴水·存在/现象/能量本身）**

**作用：** AKIRA的x面是它作为物理力量的表现——爆炸、精神场、吞噬城市的光芒。它不选择善恶（那是zn的范畴），它只是"在"。铁雄碰触它之后获得了力量——那不是AKIRA的选择，是它作为力量的属性。

## 3. 功能十元

**功能十元：nz（阴金·延续/不结束）——表层。** AKIRA没有结束的概念——它在原爆中"存在"至今。铁雄在最后一刻被它接走，进入了另一个维度的存在。这不是死亡，是"故事在别处继续"。

## 4. 视觉十元

**视觉十元：x（阴水·透明/光/能量）。** 红色的光芒、膨胀的空间、玻璃破碎、地面裂开——AKIRA在物理世界没有形状，它是"一切开始瓦解的起点"。

## 5. 动态链

```
zn（主·存在本身/回归本源）
  → x（副·作为力量显现/可以被感知）
  → nz（功能·没有结束/在另一个维度延续）
  → x（视觉·红色光+膨胀的空间）
  → 封印在实验室→铁雄触碰→失控→接纳→带走铁雄
  → 铁雄说"阿基拉，带我走吧"——他不再抗拒了
  → 他们一起去了另一个地方
```

## 6. 一句话定型

AKIRA不是「怪物」，也不是「终极武器」，而是「**存在本身——不强求、不拒绝、你在就接住你**」。

## 旧卡修正记录

**旧定位：** zn+x（本体型）——pending-absorb 存根
**修正1：** zn（主）+ x（副）→ 本体型
**最终定位：** zn（主·这件事是/回归本质）+ x（副·存在本身/可感知的力量）→ 本体型
**最终修正理由：** 原存根仅给出了框架没有完整分析。AKIRA是十元体系中zn的终极形态——不因为正确或错误而存在，它就是"是"。x是它作为力量和现象的物理表现。本体型最适合AKIRA——它的本质不是时间不是命运也不是因果，就是"本体的return"。
