# 瑞德（Red）
> 归档：`05-银矿库/角色库/肖申克的救赎_瑞德.md`

---

## 1. 主十元判断

**主十元：nz（阴土·柔情停靠）**

**五问法核验：**
- **第1问（拿掉什么他就不是他）：** 拿掉nz，瑞德就变成了一个纯粹的监狱生存者（n·适应体制）——他会像老布一样，出去之后上吊。真正定义瑞德的不是他"在监狱里怎么活"，而是他**一直在等一个愿意让他停靠的人**。安迪出现之前他没有停靠，安迪出现之后他的nz被激活了。
- **第2问（反复面对什么结构）：** 反复面对「要不要相信一个人」的问题。从「我什么都搞得到」的中间人（不进心），到最终真正的友谊——他的整条线是从孤单到停靠的过程。
- **第3问（最怕失去什么）：** 最怕「停下来的时候发现没有人在了」。老布的死就是他的恐惧镜像——不是怕死，是怕出狱之后没有归处。所以他在假释时说的那些话——「我已经改造了」——根本不重要，重要的是他出狱后有没有人接他。
- **第4问（回到哪个感觉）：** 回到「我在等一个人」的感觉。电影最后一幕——瑞德在公路边走向安迪——那是nz的终极表达：终于等到你不走了。
- **第5问（副十元服务谁）：** n（体制适应）服务于nz——他能在监狱里活三十年、搞得到东西、认识所有人，都是因为在等一个可以停靠的契机。没有n的话他活不到遇见安迪那天。

## 2. 副十元

**副十元：n（阳土·承载/适应）**

**作用：** 瑞德的n是他在监狱里三十年练出来的生存技能——他什么都搞得到、他认识所有人、他知道哪条路走得通。这不是他的底色，是他的壳——这个壳保护了他的nz不被监狱吃掉。

## 3. 功能十元

**功能十元：nx（阴金·暗算/结算）——但微乎其微**

**作用：** 旧卡说瑞德的本质是nx，但瑞德不是算账的人。他的旁白叙事不是zx（编织因果），更不是nx（暗账结算）。瑞德的旁白是nz的视角——他从"什么都搞得到"到"希望是个好东西"的变化，是一个停靠者的视角展开。旧卡把"叙事功能"和"人物灵魂"混在一起了。

## 4. 视觉十元

**视觉十元：无显著。** 瑞德三十年穿同一号囚服，出去穿同一号西装——他的外表不定义他。

## 5. 动态链

```
n（副·体制适应）保护
  → nz（主·等待停靠）
  → 安迪出现激活nz
  → 老布的死（恐惧镜像）
  → 选择追随安迪
  → 公路边相见（停靠完成）
```

## 6. 一句话定型

瑞德不是「体制内的生存者」，而是「**用三十年学会了怎么等一个人**的人」。

## 旧卡修正记录

**旧定位：** nx（阴金·暗算/结算）→ 因果型
**新定位：** nz（主·柔情停靠）+ n（副·承载适应）→ 命运型
**修正理由：** 旧卡犯了行为标签错误——把瑞德的「叙事功能」（旁白编织故事）当成了他的十元本质，又把他「在监狱里搞得到东西」的行为当成了nx的证明。实际上瑞德不算计——他是见证者。他的核心驱动力不是算账，是**等待停靠**。
