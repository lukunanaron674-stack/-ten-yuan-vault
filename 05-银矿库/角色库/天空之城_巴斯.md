# 巴斯（Pazu）
> 归档：`05-银矿库/角色库/天空之城_巴斯.md`

---

## 1. 主十元判断

**主十元：zx（阳木·突破/执行）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zx，巴斯就是一个在矿坑里吹号的善良少年——他会帮希达，但不会追到底。但他**从救下希达那一刻就没有停下来过**：追海盗、爬铁路、闯要塞、抱着希达从天空城往下跳。他不是在「做选择」，他是在「一直被行动推着走」。zx的人最大的特征就是：**不需要想清楚，先做了再说**。
- **第2问（反复面对什么结构）：** 反复面对「没有退路但还是要往前走」。他不是勇敢到不怕——是他根本来不及怕就已经出手了。
- **第3问（最怕失去什么）：** 最怕「没做到」。所以他抱着希达念咒语那段——不是浪漫，是他怕自己接不住。
- **第4问（回到哪个感觉）：** 回到「我们做到了」的感觉。云层散开天空之城出现的那一刻，他没有膨胀——zx的人做完了就做完了，不回味。
- **第5问（副十元服务谁）：** z（对父亲的执念+对希达的光）是zx的燃料——他为什么不停？因为他心里有一个要追的光（z），zx是追的方式。

## 2. 副十元

**副十元：z（阴火·执念/被看见）**

**作用：** 巴斯心里放着一件事——他父亲见过天空之城，但没人相信。他证明天空之城存在不只是为了冒险，是为了**让父亲被证明是对的**。这是z：想让那个人被看见。

## 3. 功能十元

**功能十元：无显著。**

## 4. 视觉十元

**视觉十元：无显著。**

## 5. 动态链

```
zx（主·先做再想）
  → z（副·要证明父亲是对的）
  → 救希达→闯要塞→爬城堡→跳下去
  → 天空之城出现了
  → 做完了
```

## 6. 一句话定型

巴斯不是「善良勇敢的守护者」，而是「**来不及想就出手了**的人」。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**新定位：** zx（主）+ z（副）
**修正理由：** 旧卡的zx定位是对的，但nx是错的。巴斯不算计——他每一步都是被行动推着走的。nx（暗算/结算）在他身上不存在。
