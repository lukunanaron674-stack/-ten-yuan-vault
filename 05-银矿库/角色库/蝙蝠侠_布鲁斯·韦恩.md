# 布鲁斯·韦恩（Bruce Wayne）
> 归档：`05-银矿库/角色库/蝙蝠侠_布鲁斯·韦恩.md`

---

## 1. 主十元判断

**主十元：zn（阳土·这件事是对的）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zn，布鲁斯就是一个富家子穿了件蝙蝠衣服在哥谭打架——有钱、愤怒、夜里不睡觉。但布鲁斯最核心的不是愤怒或痛苦，是**他清楚地知道"这件事必须有人做"**。他不是因为恨小丑才当蝙蝠侠，是因为"哥谭需要一个人扛着黑暗，而我能扛"。
- **第2问（反复面对什么结构）：** 反复面对「这条线跨不跨」。不杀原则是最典型的zn结构——"即使杀了他能救人，杀人也是不对的"。他在每一次选择面前都回到同一个地方：这件事是否该做。
- **第3问（最怕失去什么）：** 最怕「再让一个孩子在小巷里失去父母」。父母已经死了，但"孩子失去父母"这件事可以再发生——他怕的不是自己的记忆（z），是怕哥谭再出现一个和他一样的人。
- **第4问（回到哪个感觉）：** 回到「父母牵着他在哥谭街头走」的那个感觉——那时候哥谭还不全是黑暗。他守护的是那个哥谭还能重现的可能性。
- **第5问（副十元服务谁）：** nz（不想结束/希望那个人也在）服务于zn——"如果父母还在"是驱动他"做对的事"的背景音。他不想让别人的父母也消失。

## 2. 副十元

**副十元：nz（阴金·不想结束/希望那个人也在）**

**作用：** 阿尔弗雷德留在他身边、罗宾成为他的继承人、他反复拯救同一个城市——这些都是nz的痕迹。"那个小巷不能是哥谭的终点"。他不希望罪恶终结哥谭，也不希望自己终结自己（像黑暗骑士崛起里他选择不杀贝恩）。

## 3. 功能十元

**功能十元：n（阳火·扛住/不能让它塌）——表层。** 布鲁斯的身体极限训练、每天晚上的巡逻、被小丑摧残后爬起来——这些都是"扛住"的动作。但他扛住的根不是恐惧（n的本质），是"这件事必须有人做"（zn）。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 布鲁斯·韦恩的花花公子形象、蝙蝠战衣、蝙蝠车——这些是包装。富家子是伪装，蝙蝠是象征。

## 5. 动态链

```
zn（主·哥谭必须有人守护/这事是对的）
  → nz（副·不想让小丑终结哥谭/不希望父母的故事再重复）
  → n（功能·扛住每一次被打倒）
  → x并z（视觉·花花公子/蝙蝠战衣）
  → 小巷之夜→11年训练→成为蝙蝠侠→守护哥谭
  → 他不是在复仇，是在做一件不能不做的事
```

## 6. 一句话定型

布鲁斯不是「复仇的黑暗骑士」，也不是「哥谭的暴力守护者」，而是「**因为这事是该做的，所以他做了二十多年**」的人。

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**修正1：** zn（主）+ nz（副）→ 本体型
**最终定位：** zn（主·这件事是对的）+ nz（副·不想结束/希望那个人也在）→ 本体型
**最终修正理由：** 原卡xz暗示布鲁斯"被推着走"——但他不是被动地被命运推着当蝙蝠侠。他是主动选择的——那么多有钱人，只有他用了11年训练自己。他的不杀原则是最纯粹的zn体现：即使是罪恶的人也不能被私刑处决，因为"杀"这件事本身是不对的。nz是他背负的背景音——那个小巷的夜晚没有结束，他让它在自己心中延续，并通过保护别人来给这个故事一个好的结局。
