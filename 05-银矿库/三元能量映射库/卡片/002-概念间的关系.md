# 002 概念间的关系

## 原书核心

经典逻辑学将概念间的关系分为五大类（基于外延是否重合）：

1. **同一关系** — 外延完全相同（如"等边三角形"和"等角三角形"）
2. **包含关系（种属/属种）** — 一个概念的外延完全在另一个之内（如"人"⊂"动物"）
3. **交叉关系** — 外延部分重合（如"青年"和"医生"：有人既是青年又是医生，有人是青年但不是医生，有人是医生但不是青年）
4. **矛盾关系** — 同一属概念下两个不相容种概念，且外延互补（如"男人"和"女人"在"人"下互补）
5. **反对关系** — 同一属概念下两个不相容种概念，外延不完全互补（如"黑色"和"白色"之间有灰色地带）

## 十元定位

**所属集合：x（现象切割中的外延分配结构）**

**理由：** 概念间的关系本质上是"x 层的外延分配"。同一是外延完全重叠，包含是外延嵌套，交叉是外延部分共享。这些关系不是 z 的切割冲动本身（那是 001 的内容），也不是 n 的应用系统，而是 x 层面事物在分类后的空间结构。一个位置关系网络——x 空间中的拓扑。

具体来说：
- 同一关系 = x 外延的完全等同映射
- 包含关系 = x 外延的容器级嵌套（类与子类）
- 交叉关系 = x 外延的部分重叠

矛盾与反对则涉及 z 的切割深浅——矛盾是补集切割完整，反对是切割不完整（留有模糊带），所以它们处于 x 与 z 的交界。

## 生克补关系

- **生（n → 002）**：没有 n 层的分类系统（生物分类学、图书馆分类法），外延不会自动呈现为有结构的关系。分类框架是概念间关系得以显现的前置条件。n 为概念提供**格**，关系就是格与格之间的位置。

- **克（z → 002）**：z 的切割越深、越精确，概念间的关系就越清晰——同一/包含/交叉/矛盾/反对一清二楚。z 切割越浅（粗糙的日常概念），关系就越模糊："青年"和"中年人"之间没有清晰界线，既不是矛盾也不是反对。**z 的锐度克制的就是关系边界的模糊度。**

- **补（nz ↔ x并z → 002）**：经典的五种关系是一种理想化模型（nz 的精确边界切割），但现实中绝大部分概念关系都是 x并z——被表象归类而非精确定义的交叉/包含。比如"垃圾食品"和"健康食品"只有松散的表象重叠，经不起精确的分类。这种张力（理想分类 vs 现实模糊）正是概念关系得以持续修订的动力。

## 体量

**值：3/10**

**理由：** 概念间的关系是对 Card 001（概念定义）的继承和扩展，但本身不是十元理论的底层元素——它描述的是 x 层的拓扑结构，而不是 z 或 n 的动力机制。在十元系统中，位置关系网络本身才是更根本的分析工具（起手十元 + 生链方向 + 克/补 + 主题），概念间的逻辑分类只是这个网络的一种简化投影。
