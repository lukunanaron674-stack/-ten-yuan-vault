# 001 概念的定义（内涵与外延）

## 要学的东西

**经典定义**（亚里士多德）：概念由内涵和外延构成。
- 内涵 = 概念所反映的事物的特有属性
- 外延 = 具有这些属性的一切事物
- 反变关系：内涵越多，外延越小

**现代补充**（索绪尔、维特根斯坦）：
- 意义来自系统中的位置差异
- 概念是"家族相似"，非共享本质

## 三元分析

**十元定位：nz**

定义同时包含两个不可分的动作：划清边界的冲动（z）和把边界固定为语言的承载（n）。没有符号固定，定义只是私人一闪念；没有切割冲动，定义根本没有产生的动力。

**生克补**

**z → nz**：概念的定义不是凭空出现的，它产生于"非要划清界限"的本能——区分人和动物、冷和热、我和你的需求在先，概念定义在后。没有这种原始的区分冲动，就不会有"人=理性动物"这一定义行为。

**nz → z**：定义一旦确立，反而加深了对边界的执着。"人=理性动物"这一定义出来之后，人会更敏感地去检查"这个算人吗？那个不算吗？"——定义没有消解边界焦虑，反而喂养了它。

**x并z → nz**：现实中被表象归类覆盖精确定义的例子比比皆是。"鲸鱼"因长得像鱼、在水里游，长期被归为鱼类——表面相似性侵蚀了生物学定义的边界。概念在使用中会不断被表象污染。

**nz → x**：一个精确的定义天然会排斥模糊地带。"正义"一旦被精确定义为"各得其所"，那些说不清道不明的灰色情感和私人欲望就被排除在概念之外了。定义越精确，排除的模糊地带越多。

**nz ↔ xz**：当概念在传播中被滥用、边界模糊到无法辨认时——比如"爱"被社交媒体稀释成点赞——这种漂移危机会反过来驱动重新定义的需求。"爱到底是什么？"这个追问重新唤起了切割边界的冲动，回到 nz 的起点。
