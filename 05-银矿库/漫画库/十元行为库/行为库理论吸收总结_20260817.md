## 2. 每元的实证原型（由行为库反推，非定义正本）

### 2.1 xn 阳金（89 条，locked 7）——"把目标压成可运行结构"

实证原型：组织计划、时间、规则、信息和资源，使结构持续运行；对象端点是"计划/资格/步骤/节点"。

- 潜入与会面节点（Eren：伪装身份、书信、接头人、行动时点）。
- 建部与报名（千早：成员、社团资格、训练与报名步骤）。
- 分段登攀程序（羽生：装备、营地、路线、时机、体能）。
- 考试准入与分组执行（芙莉莲：一级魔法使考试、捕鸟任务）。
- 分工布置（炼狱：8 节车厢守护区与斩首路线并行）。

相邻区分：xn 不直接显权（那是 zx），不单点最高化（那是 z），不沿别人方向（那是 nx）。

### 2.2 nx 阴木（66 条，locked 3）——"沿既有方向/通道/权威推进"

实证原型：不占最终方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。

- 偿债路线（电次：讨债人规定的工作、债务方向）。
- 求救交权（电次：把解决方向交给外部权威真纪真）。
- 接受引导（时行：赖重提供的庇护关系与行动路径）。

相邻区分：nx 与 zn/zx 相反（不自己定义方向）；nx 与 xn 相反（不建框架，承接/沿框架）。

### 2.3 zx 阳木（44 条，locked 3）——"直接显权并凌驾"

实证原型：主体权能公开显现、扩大，并凌驾于他者之上。

- 宣战现场变身攻击（Eren：会场、军队、敌方巨人被直接改造）。
- 地鸣持续施加（Eren：岛外人口、地表路线、巨人军势）。
- 濒死再攀打开生存路径（羽生：身体、墙面、上升与安全位置）。

相邻区分：zx 的直接性区别于 xn 的规划性；zx 的扩张区别于 nx 的借力。

### 2.4 z 阴金（49 条，locked 3）——"单点最高化，不关他事"

实证原型：把某一路线/标准提升为唯一最高中心，其他方向退出中心裁定。

- 大乔拉斯冬季单人路线（羽生 97）。
- 珠峰西南壁无氧单人（羽生 98）。
- 见证者退出后继续（羽生 96）。

关键判据：`z` 不要求被认可（认可不是必要条件）；z 与 xn 同属金轴（阳金xn ↔ 阴金z）。

### 2.5 n 阳土（40 条，locked 1）——"承载与回应"

实证原型：承载、稳定、接收并回应他者；对象端点是被承载物、需求、关系。

- 回应饮用者愿望并据此确认候选（神咲雫 96，locked）。
- 品鉴并把体验转成可比较描述（神咲雫 97，candidate）。
- 借笔记给同学（望月 95，candidate）；观看太一比赛（千早 92，candidate）。

### 2.6 zn 阳火（19 条，locked 1）——"自己成立并保存他者成立资格"

实证原型：并存赋义——自己承担/坚持，同时让被保护者继续独立成立。

- 炼狱独守车厢保护乘客（95，locked）：乘客作为独立生命主体被完整保留。
- 决战守护（93，candidate）：明知差距仍迎战，把后辈与乘客放身后。

红线：禁止用善良、牺牲、英雄或坚持原则泛化凑 zn；每一条都须证明"保存他者独立成立资格"。

### 2.7 xz 阳水（15 条，locked 3）——"进入临界/存续窗口"

实证原型：进入危险、不可逆、临界存续的状态，并维持下一段存续机会。

- 接受钻孔、亲手钻孔（名越进 97/99，locked）。
- 为自身与宇宙存续而战（John Difool 93，locked）。

### 2.8 x 阴火（11 条，locked 1）——"对象/资源/权限归我掌握"

实证原型：对象、资源、地盘、权限或关系归我掌握（含具体调用）。

- 发动始祖能力并唤醒墙中巨人（Eren 97，locked）：始祖权限、墙中巨人、城墙结构。
- 建立经营商业系统（Veidt 94）、开设拉面店（藤本 94）、资源援助与债权边界（吕太洲 95—97，candidate）。

### 2.9 x并z 阴土（8 条，locked 1）——"可识别壳/公共界面"

实证原型：为承载结构提供可识别、可进入、可持续指认的公共界面（身份壳）。

- 阳菜假扮雏子进入社会身份接口（96，locked，库内首条阴土）。
- Ozymandias 公开身份/自导袭击（95×2）、Vladek 冒充非犹太人（97）、藤本覆面（90）等候选。

### 2.10 nz 阴水（7 条，locked 1）——"关系停靠/归宿方向"

实证原型：明确回返对象、关系终点与归宿方向；关系停靠（含为保全他人而退出/带离）。

- 芙莉莲葬礼后履行旧同伴遗愿（96，locked）：旧关系转成新旅途入口。
- 阳菜压下恋情退出（97）、协作救回（96）、孝章参与带离（96）、辻中身份断裂后继续相处（96）等候选。

## 4. 行为库对理论的实证贡献

### 4.1 五轴两端齐全（首次）

金、木、火、水、土五轴现全部有 locked 证据，全部按 L1 轴名：

- 金 xn↔z：7+3 locked（Eren/千早/羽生/芙莉莲/炼狱 + 羽生）

- 水 xz↔nz：3+1 locked（名越进/John Difool + 芙莉莲）
- 火 zn↔x：1+1 locked（炼狱 + Eren）
- 土 n↔x并z：1+1 locked（神咲雫 + 阳菜）

### 4.2 相邻十元的高频混淆点已被判据分离

| 混淆对 | 判据 |
|---|---|
| z vs zn | z＝单点最高化、不关他事；zn＝自己成立并保存他者独立成立资格 |
| z vs xn | z＝集中唯一最高点；xn＝组织多节点结构 |
| zx vs nx | zx＝以自身权能直接做成；nx＝通过既有身份/关系/权限/通道借力 |
| nx vs xn | nx＝承接/沿框架；xn＝建立并维护框架 |
| x vs xz | x＝资源/权限归我掌握；xz＝进入临界存续窗口 |
| n vs x并z | n＝承载回应（内部）；x并z＝可识别公共界面（外部壳） |

### 4.3 证据强度排序（locked 数量）

xn(7) > nx(3)=zx(3)=z(3)=xz(3) > zn(1)=n(1)=nz(1)=x(1)=x并z(1)。

金轴最强（10 locked），土轴最薄（2 locked）；n/x并z/x/zn/nz 各只有 1 条 locked，是下一阶段采矿重点。

### 4.4 候选→locked 的升锁判据

- 须原卷页码或出版社公开强证据（行为库采用 `publisher-public` / `publisher-official` 等 evidence_scope 分级）。
- 锁定的是"可观察行为 + 对象端点"而非"人物整体归类"。
- 单簇证据（同一书目证据簇）降权，如小户川桦泽载客 88 单簇降权。
