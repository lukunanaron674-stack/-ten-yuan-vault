# 十元五行行为核心（15 条）v0.1

> 用途：作为"行为故事生成"实验的输入。每条核心给出一句话行为内核、触发→行动→对象→结果公式、行为库实证锚点与反证判据。五行标注一律按 L1 口径。

## A. 十元行为核心（10 条）

### ZX 阳木｜直接显权凌驾

- 一句话核心：主体权能公开显现、扩大并凌驾于他者之上，直接以自身做成。
- 公式：触发权能条件 → 主体公开施展/扩大自身力量 → 作用于目标/群体/战场 → 力量关系被直接改写。
- 锚点：Eren 宣战现场变身攻击（98）、Eren 地鸣持续施加（99）、羽生濒死再攀（98）。
- 反证：不是规划（xn）、不是借力（nx）、不是掌握资源（x）。

### NX 阴木｜沿既有方向推进

- 一句话核心：不占最终方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。
- 公式：外部给出方向/通道/权威 → 主体承接并按该方向行动 → 作用于既有关系与路径 → 沿外部通道获得继续。
- 锚点：电次偿债路线（95）、电次求救交权（96）、时行接受赖重引导（94）。
- 反证：不是自己定义方向（zx）、不是组织框架（xn）、不是单点最高化（z）。

### ZN 阳火｜并存赋义

- 一句话核心：自己成立并主动保存他者独立成立资格。
- 公式：他者成立资格受威胁 → 主体自己承担/坚持并保护他者继续成立 → 作用于他者主体与被保护物 → 他者作为独立主体被保留。
- 锚点：炼狱独守车厢保护乘客（95，locked）。
- 反证：不是"只守自己的路"（z）、不是善良/牺牲/英雄泛化——必须证明保存他者独立成立资格。

### X 阴火｜资源归我掌握

- 一句话核心：对象、资源、地盘、权限或关系归我掌握（含具体调用）。
- 公式：存在可掌握对象 → 主体取得并支配/调用该对象 → 作用于资源、权限、地盘 → 对象进入主体控制边界。
- 锚点：Eren 发动始祖唤醒墙中巨人（97，locked）、Veidt 经营商业系统（94）、藤本开设拉面店（94）、吕太洲资源援助与债权（95—97）。
- 反证：不是掌握临界风险（xz）、不是承载回应（n）。

### N 阳土｜承载回应

- 一句话核心：承载、稳定、接收并回应他者；对象端点是被承载物、需求、关系。
- 公式：他者产生需求/被承载物 → 主体接收并回应 → 作用于需求与关系 → 他者获得可继续的承载。
- 锚点：神咲雫回应饮用者愿望（96，locked）、借笔记给同学（望月 95）。
- 反证：不是映射外化界面（x并z）、不是关系停靠归宿（nz）。

### X并Z 阴土｜可识别壳/公共界面

- 一句话核心：为承载结构提供可识别、可进入、可持续指认的公共界面（身份壳）。
- 公式：需要被社会识别/进入 → 主体呈现可读外壳/身份 → 作用于社会接口与识别 → 主体以公开外壳被识别。
- 锚点：阳菜假扮雏子进入社会身份接口（96，locked，库内首条阴土）、Ozymandias 公开身份（95）、Vladek 冒充非犹太人（97）。
- 反证：不是内部真实承载（n）、不是掌握资源（x）。

### XN 阳金｜组织成结构

- 一句话核心：组织计划、时间、规则、信息和资源，使结构持续运行。
- 公式：目标需要多步骤/多节点 → 主体组织计划与执行 → 作用于资格、步骤、节点、资源 → 目标被压成可运行结构。
- 锚点：Eren 潜入马莱/方案转化（95/96）、千早建部报名（96）、羽生珠峰分段程序（97）、芙莉莲考试（95—96）、炼狱分工（94）。
- 反证：不是直接显权（zx）、不是单点最高化（z）。

### Z 阴金｜单点最高化

- 一句话核心：把某一路线/标准提升为唯一最高中心，其他方向退出中心裁定。
- 公式：存在多条路线/标准 → 主体把一条提升为最高并舍弃其余 → 作用于个人标准与取舍 → 该路线获得唯一最高优先级。
- 锚点：羽生大乔拉斯路线（97）、珠峰无氧单人（98）、见证者退出后继续（96）。
- 反证：不要求被认可（认可不是必要条件）；不是并存赋义（zn）、不是组织多节点（xn）。

### XZ 阳水｜进入临界存续

- 一句话核心：进入危险、不可逆、临界存续的状态，并维持下一段存续机会。
- 公式：面对临界/不可逆窗口 → 主体主动进入并维持存续 → 作用于自身与危险边界 → 获得下一段存续机会。
- 锚点：名越进接受钻孔（97）、亲手钻孔（99）、John Difool 为存续而战（93）。
- 反证：不是资源归我掌握（x）、不是关系停靠（nz）。

### NZ 阴水｜关系停靠归宿

- 一句话核心：明确回返对象、关系终点与归宿方向；关系停靠（含为保全他人而退出/带离）。
- 公式：关系面临断裂/终点 → 主体保存或重开回返路径 → 作用于关系对象与归宿 → 关系保有可回返空间。
- 锚点：芙莉莲葬礼后履行遗愿（96，locked）、阳菜压下恋情退出（97）、孝章参与带离（96）。
- 反证：不是承载回应（n）、不是进入临界（xz）。

## B. 五行行为核心（5 条）

### 木｜方向源与作用权（zx↔nx）

- 核心：最终方向与作用权从何而来。阳端＝自身生成并占据方向；阴端＝不占最终方向、沿既有通道续接。
- 行为判据：看"方向由谁定义"——主体发起并占方向（zx）还是承接外部方向（nx）。
- 锚点：Eren 宣战显权（zx）↔ 电次偿债沿债务方向（nx）。

### 火｜独立主体资格（zn↔x）

- 核心：对象独立成立资格与归属方式。阳端＝保留对象自身成立；阴端＝纳入掌握、调用与处分边界。
- 行为判据：看"他者/对象是否保持独立成立"——保存多方成立（zn）还是收进我的掌握边界（x）。
- 锚点：炼狱保护乘客独立成立（zn）↔ Eren 把巨人纳入调用（x）。

### 土｜内外结构（n↔x并z）

- 核心：对象跨越内外边界的方向。阳端＝外→内纳入承载；阴端＝内→外映射外化。
- 行为判据：看"对象向内承载还是向外呈现"——接收并承载（n）还是呈现可识别壳（x并z）。
- 锚点：神咲雫回应需求（n）↔ 阳菜假扮雏子呈现外壳（x并z）。

### 金｜运行权与裁定重心（xn↔z）

- 核心：运行权与裁定重心配置。阳端＝分布到规则节点流程；阴端＝收束到单一最高裁定点。
- 行为判据：看"裁定权如何分布"——多节点组织运行（xn）还是单点最高裁定（z）。
- 锚点：羽生珠峰分段程序（xn）↔ 羽生珠峰唯一最高路线（z）。

### 水｜可逆与回返（xz↔nz）

- 核心：可逆性与对象特异回返空间。阳端＝持续收窄关闭；阴端＝保存、恢复或重建回返空间。
- 行为判据：看"路径在收窄还是被保存"——进入临界收窄（xz）还是保留回返对象（nz）。
- 锚点：名越进钻孔（xz）↔ 芙莉莲履行遗愿重开旅途（nz）。

## C. 实验用途说明

- 每条核心可以直接作为"行为故事生成"的命题：写一段短剧情（1 个主角、1 个触发、1 个可观察动作、1 个对象端点、1 个结果），然后标注该故事命中的核心。
- 同一段剧情可以命中多条核心吗？可以，但须逐条行为分开写，一条行为只归一个十元（五行核心是轴级命题，十元核心是端点级命题）。
- 生成时禁止用职业、情绪、善良、牺牲、结局或作品气质倒推。
