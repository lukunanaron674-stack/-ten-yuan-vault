# 漫画行为库｜五行阴阳行为映射试验 v0.1

## 0｜试验目的

把现有漫画单行为的 `candidate_symbol` 直接映射为阴阳五行身份，检查五行相反轴能否帮助：

1. 看清同一五行的阳端、阴端分别怎样行动；
2. 发现只采到一极、另一极为空的覆盖缺口；
3. 发现旧十元归类与最新五行—人物口径之间的冲突；
4. 为后续角色创作提供“五行轴上的两种相反做法”。

本试验只增加观察层，不利用五行身份倒推十元。固定顺序仍是：

```text
先确认具体行为与改变变量
→ 唯一归入一个十元
→ 再由十元确定阴阳五行身份
```

## 1｜确定性映射

| 十元 | 五行身份 | 同行相反端 |
|---|---|---|
| `zx` | 阳木 | `nx` 阴木 |
| `nx` | 阴木 | `zx` 阳木 |
| `zn` | 阳火 | `x` 阴火 |
| `x` | 阴火 | `zn` 阳火 |
| `n` | 阳土 | `x并z` 阴土 |
| `x并z` | 阴土 | `n` 阳土 |
| `xn` | 阳金 | `z` 阴金 |
| `z` | 阴金 | `xn` 阳金 |
| `xz` | 阳水 | `nz` 阴水 |
| `nz` | 阴水 | `xz` 阳水 |

重要结果：

```text
z 与 zn 不是同一五行的阴阳两端。
z 的同行相反端是 xn。
zn 的同行相反端是 x。
```

因此，五行映射不能把 `z/zn` 简化成“同一件事的一阴一阳”。二者仍须靠行为对象、改变变量、最近邻、拿掉和反向测试区分。

## 4｜最有价值的试验：同一人物的金轴

绫濑千早当前同时具有 `xn` 与 `z` 记录，适合先观察：

### 阳金 xn

```text
招募成员
→ 建立社团
→ 安排训练与报名
→ 让验证结构可以长期运行
```

改变的是：**验证、训练与参赛过程是否被组织起来。**

### 阴金 z（按当前行为库口径）

```text
进入重要对手与正式裁定的位置
→ 把个人能力集中送到最高确认点
```

改变的是：**个人能力是否抵达并占据关键确认焦点。**

当前可得到一个试验性对照：

```text
阳金xn：组织整套判断／验证结构
阴金z：把个人焦点送入最终判断／确认位置
```

但这只是当前记录的跨行为观察，不证明 `xn` 与 `z` 在具体剧情中已经互补、克制或互相转化。千早可以在不同阶段同时出现两端，说明“阴阳相反”不是“同一人物只能二选一”。

## 5｜木轴试验

现有 `zx` 行为共同点较清楚：

- 现场变身攻击，直接改写会场；
- 持续驱动地鸣，直接压缩外部世界行动空间；
- 坠落后再次攀登，直接改变身体与岩壁位置。

这批行为都体现：

```text
阳木zx：人物占据施力方向，并把改变直接压到外部对象上。
```

但当前没有一条 `nx` 阴木记录，所以不能只凭阳木反推阴木。下一步需要采集“人物不占最终方向，沿既有安排、关系、权限或通道推进”的明确行为，再检验木轴是否稳定表现为：

```text
阳木zx：占据并施加方向
↔
阴木nx：让出方向并沿既有方向生长／推进
```

这句话目前只是采矿假设，不是理论正本新增定义。

## 6｜火轴暴露出的归类问题

按当前记录：

- `zn`阳火：内部标准裁定最终路线；
- `x`阴火：掌握并调用具体资源、权限或对象。

但用户最新人物口径指出：

```text
ZN＝你们都对，我也是对的
z＝我是最对的，你们不关我事
ZX＝我是对的，你们都是错的
```

羽生“见证者退出后仍走自己的路线”明显可能是 `z`，不一定是 `zn`。这说明五行映射不会自动修好旧分类，反而能把问题暴露得更清楚：

- 若羽生从 `zn` 改判 `z`，他的五行身份会从阳火改为阴金；
- 这不是阴阳端内部微调，而是跨五行迁移；
- 因此必须重新检查改变变量，不能只改五行字段。

## 7｜行为记录字段迁移建议

现有字段：

```text
five_element_anchor_or_interval
yin_yang_position_if_current_canon_has_it
```

已经与 v1.2 正本不兼容。后续正式迁移建议改为：

```json
{
  "five_element": "木",
  "polarity": "阳",
  "five_element_identity": "阳木",
  "same_element_opposite": "nx",
  "axis_evidence_status": "single-pole-observed",
  "axis_contrast_note": "本条只证明zx行为，不从本条反推nx"
}
```

迁移纪律：

1. `candidate_symbol` 是事实归类结果；五行字段由它确定；
2. 五行字段不得参与第一次十元判定；
3. 同行相反端只能用于最近邻与反向观察，不能自动改标签；
4. 旧“锚点／间位”字段保留到一次性迁移完成，不能半库新旧混用；
5. 羽生三条争议记录先复核十元，再迁移五行字段。

## 8｜本次试验结论

1. 五行映射可以直接覆盖全部十元记录，且不需要新增第二套标签；
2. 它最有用的功能是统计五条阴阳轴的两端覆盖，而不是给十元换名字；
3. 当前漫画行为库严重偏向阳木、阳金和阴金，水轴与土轴基本为空；
4. `z↔xn`、`zn↔x`的轴关系能防止继续把 `z/zn` 当成一对；
5. 映射暴露出羽生三条 `zn` 记录与用户最新人物口径冲突，必须重新归类；
6. 目前最适合继续做同人物相反轴测试的是千早的金轴；最需要补矿的是水轴、阴木与阴土。
