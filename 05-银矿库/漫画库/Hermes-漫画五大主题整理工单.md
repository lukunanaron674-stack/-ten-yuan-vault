# Hermes-漫画五大主题整理工单

目标：让 Hermes 接收 QQBot 指令后，调度 DeepSeek 做十元重分析，再让本地 Qwen 做低成本整理，最后归档到 Obsidian 的漫画库五大主题页。

## 1. 分工边界

### DeepSeek 十元分析

DeepSeek 只做高价值判断：

- 判断漫画主主题：本体 / 时间 / 空间 / 因果 / 命运。
- 判断十元对子或动态链。
- 检查生链、克链、补链是否成立。
- 给出评分、优先级、入库/待二审/废矿判断。
- 写出该漫画在主题里的不可替代特点。

### 本地 Qwen 整理

Qwen 只做低成本归档工作：

- 压缩 DeepSeek 长报告。
- 提取字段：漫画名、主题、评分、优先级、对子、生链、克链、补链、特点。
- 生成标准 Markdown 卡片。
- 写入待二审收集箱或主题页草稿。
- 不替代 DeepSeek 做最终理论裁判。

### Hermes / QQBot

Hermes 负责调度：

- 接收 QQBot 指令。
- 查询 Obsidian 是否已有同名卡片或评分。
- 组装 DeepSeek prompt。
- 调用本地 Qwen 压缩归档。
- 写入 Obsidian。
- 返回 QQBot 一条短摘要。

## 4. Hermes 执行流程

1. 解析漫画名。
2. 检索以下位置是否已有记录：
   - `05-银矿库/漫画库/`
   - `05-银矿库/入库卡片/漫画/`
   - `05-银矿库/标定记录/`
   - `07-Codex大脑库/千问十元待二审收集箱.md`
3. 若已有 finalized 记录，只返回已有归档摘要。
4. 若缺少主题特点或评分，调用 DeepSeek。
5. DeepSeek 返回十元分析后，调用本地 Qwen 压缩。
6. Qwen 生成标准卡片。
7. 写入：
   - 低置信度：`07-Codex大脑库/千问十元待二审收集箱.md`
   - 高置信度：对应五大主题页或 `入库卡片/漫画/漫画名.md`
8. QQBot 返回短摘要。

## 5. DeepSeek Prompt 模板

```text
你是十元漫画入库裁判。请分析漫画《{{漫画名}}》是否应归入漫画库五大主题。

候选主题：
1. 本体型 zn+x：内核燃烧 / 存在驱动
2. 时间型 xn+z：节拍压迫 / 时机精准
3. 空间型 x并z+n：场域包裹 / 停留感
4. 因果型 zx+nx：局势博弈 / 暗流推动
5. 命运型 xz+nz：漂流宿命 / 缘分遭遇

请严格输出：

[漫画名]
[主主题]
[副主题，如无则写无]
[十元对子/动态链]
[生链] 成立/不成立 + 证据
[克链] 唯一/不唯一 + 证据
[补链] 成立/不成立 + 证据
[在主主题里的特点] 一句话，必须具体到作品结构
[评分] 0-100
[优先级] S/A/B/待二审/废矿
[入库判断] 入库/待二审/不入库
[评语] 1-2句

红线：
- 不用五大主题倒推十元。
- 不因为作品名气高就高分。
- 不把战斗力、热血程度、体量当评分依据。
- 若证据不足，必须写待二审。
```

## 8. 清洗规则

以下输出不能直接入库：

- 漫画名是“无搜索结果”“抱歉无法提取漫画名称”等错误文本。
- 评分缺失或明显异常。
- 主题为空，或主题与对子证据不一致。
- 只有套话，没有作品结构证据。
- Qwen 自行改写了 DeepSeek 的理论判断。
