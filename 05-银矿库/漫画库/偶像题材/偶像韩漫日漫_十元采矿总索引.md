# 偶像韩漫日漫｜十元采矿总索引

> 目标不是做普通推荐榜，而是把“想成为偶像 / 被迫成为偶像 / 偶像产业 / 舞台身份”持续采成十元血肉、关系牙印、动态链与可复用创作模板。

## 1. 专项边界

优先收：
- 主角明确以“成为偶像 / 再次出道 / 参加选秀 / 组团 / 保住偶像身份”为主线
- 偶像产业链：练习生、选秀、公司、经纪、团内关系、粉丝、舞台、舆论、塌房、资源竞争
- 身份变化强：普通人→偶像、失败偶像→重生再出道、社畜→偶像、演员/制作人→偶像

次级收：
- 娱乐圈题材但偶像只占一部分
- 粉丝视角、偶像恋爱、偶像悬疑

不优先：
- 只有“明星”身份但几乎没有训练/舞台/团体/粉丝机制
- 单纯校园乐队、纯恋爱且职业线极弱

## 2. 第一批种子作品

### 韩漫｜S级优先
1. 《患上不出道就会死的病 / Debut or Die!》
   - 核心：不出道即死亡；练习生→选秀→成团→职业偶像
   - 采矿价值：xz命运倒计时、xn规则系统、zx强推进、z舞台认可、nz团队关系
   - 优先级：10/10

2. 《再次成为偶像 / Second Try Idol / Idol Once Again》
   - 核心：失败/受伤后回到练习生时期，再次争取出道
   - 采矿价值：xn时间回卷、x旧伤/失败残留、zx重新行动、z重新被看见
   - 优先级：9/10

3. 《全能型偶像的第二人生 / The Second Life of an All-Rounder Idol》

## 5. 专项要重点解决的问题

- 为什么“成为偶像”特别容易形成 `zn（身份） + z（认可） + xn（规则/训练） + zx（主动争夺）` 的高密度结构？
- 当“必须出道”出现时，`zx` 是自主行动，还是被 `xz/xn` 强迫后形成的伪主动？
- 团体偶像中的 `nz` 是真正对象特异关系，还是公司、共同任务与生存压力制造出的 `n/nx` 假稳定？
- 舞台认可 `z` 能否反向固定 `zn` 本体，还是会造成“公众身份吞掉私人本体”的污染？
- 粉丝的 `z` 如何生出资源、机会、关系与舆论反噬？
- 偶像职业最常见的本体链：普通人 → 练习生 → 舞台人格 → 商品化人格 → 私人本体反扑。

## 6. 自动运行规则

- 每小时优先从“当前优先采矿顺序”取尚未深挖的一部。
- 必须先查公开可信资料，再做十元分析；禁止凭标题脑补剧情。
- 每轮至少产出：1个主十元判断 + 1条动态链 + 2条关系牙印 + 3条创作模板 + 1条误判反例。
- 85分以下进入待二审；85分及以上可进入正式银矿；高价值作品再拆角色卡/场景卡/关系卡。
- 不修改十元主骨定义；新发现先作为血肉或候选关系证据。
- 新作优先级：韩漫“重生/系统/选秀/团体出道” > 日漫“偶像成长/产业结构” > 泛娱乐圈。
