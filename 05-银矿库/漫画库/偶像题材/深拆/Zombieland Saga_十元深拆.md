# Zombieland Saga｜十元深拆

## 基本信息
- 作品名：Zombieland Saga / ゾンビランドサガ
- 媒介：日本原创电视动画
- 矿级：S
- 核心类型：死者复活→被迫组成地方偶像团体→通过舞台重新获得社会身份
- 本轮新母型：**死亡后身份再社会化 / 失去人生的人通过偶像身份获得第二次公共人生**

## 偶像身份如何建立
七名来自不同时代、不同背景的少女被巽幸太郎复活为僵尸，并被组织为地方偶像团体“Franchouchou”，目标之一是通过偶像活动振兴佐贺。她们不是从“想当偶像”出发，而是先被塞进一个共同的职业身份，再在训练、演出、粉丝反馈与成员关系中逐步把这个身份活成真实。

## 十元体量
| 十元 | 体量 | 作用 |
|---|---:|---|
| xz | 10 | 死亡、复活、既定命运被强行中断并重启 |
| x并z | 10 | 死者、僵尸、艺名、地方偶像多重公众身份重叠 |
| zn | 9 | “我已经死了，我还能是谁”是持续本体问题 |
| n | 9 | 七人组合关系决定身份是否成立 |
| xn | 8 | 训练、营业、舞台、事务所与偶像职业规则 |
| nx | 8 | 初期高度被动，被制作人强制安排活动 |
| zx | 8 | 后期逐渐从被迫执行转向主动保护舞台与组合 |
| nz | 8 | 队友、粉丝、故乡与旧关系持续赋予情感意义 |
| z | 9 | 每个人的前世、死因、时代背景不断回流现在 |
| x | 7 | 各自旧职业、性格与才艺构成偶像差异化 |

## 顺序
**xz → nx → x并z → xn → n → z回流 → zn冲突 → zx → nz → 新x并z**

解释：
1. **xz**：死亡终结旧人生，又被异常复活。
2. **nx**：复活后先被巽幸太郎安排成偶像，几乎没有职业选择权。
3. **x并z**：获得“Franchouchou成员”这个外部身份，同时还保留“死者/僵尸/过去的人”。
4. **xn**：进入训练、演出、宣传、粉丝经营等偶像规则。
5. **n**：七个跨时代个体必须形成真正团队。
6. **z回流**：旧时代、旧身份、旧亲友重新撞入现在。
7. **zn冲突**：角色被迫回答“过去的我、死后的我、现在的偶像我，哪个才是真的”。
8. **zx**：逐渐主动选择继续站在舞台上。
9. **nz**：队友、粉丝、地方与旧关系产生新的情感纽带。
10. **新x并z**：偶像身份不再只是伪装，而成为第二次社会人生。

## 五维
- 时间维（xn+z）：10/10。最大价值在“来自不同年代的死者进入同一个当代偶像制度”。
- 本体维（zn+x）：10/10。死后还有没有“我”，是比普通偶像成长更尖锐的本体题。
- 空间维（x并z+n）：10/10。组合将不同年代、身份和死亡经历压进同一个公共单位。
- 因果维（zx+nx）：9/10。初期被迫，后期主动认领身份，转化清晰。
- 命运维（xz+nz）：10/10。死亡是绝对命运，关系却让她们获得第二种人生意义。

## 行业机制
- 训练：从身体协调、唱跳、临场表演到组合协作，训练同时暴露“僵尸身体”这一不可公开秘密。
- 出道：不是传统练习生晋级，而是直接被推向地方活动和小型舞台，以实战替代资格认证。
- 竞争：不是单纯淘汰制，更多来自生存压力、地方知名度、舞台事故和行业认可。
- 舞台：舞台既是职业场，也是“证明自己仍然属于这个世界”的仪式。
- 粉丝：粉丝不是只提供人气，而是给已经被世界判定“结束”的人重新提供社会承认。
- 公司/制作人：巽幸太郎同时是控制者、组织者和身份制造者。他先强行定义成员，再被成员真正长出的共同体反向约束。

## 主角欲望与代价
### 欲望
- 最初：理解复活后的处境、逃离混乱、重新获得行动感。
- 中期：让团队继续存在，不让成员关系和舞台被摧毁。
- 后期：主动站上舞台，承认“现在这个人生”值得继续。

### 代价
- 必须隐藏僵尸身份。
- 无法完整回到旧人生。
- 与旧亲友重逢时，必须承受“对方活着而自己已经死过”的时间断裂。
- 越认真成为偶像，就越难把现在当作临时状态。

## 关系结构
- 制作人 → 成员：强制定义身份。
- 成员 ↔ 成员：跨年代、跨职业形成第二家庭。
- 成员 ↔ 粉丝：公众承认让“死者”重新进入社会。
- 现在的成员 ↔ 过去的人际关系：旧身份不断要求被解释。
- 组合 ↔ 佐贺：团体身份与地方身份绑定，形成“个人复活”之外的公共任务。

## 动态链
### 主链
**死亡终止旧本体（xz） → 被强制赋予偶像身份（nx+x并z） → 行业训练持续塑形（xn） → 团队关系生成（n） → 过去回流制造本体冲突（z+zn） → 主动选择继续当偶像（zx） → 粉丝/地方重新承认其存在（nz） → 新公共身份成立（新x并z）**

### 主次
- 主符号：xz / x并z
- 次符号：zn / n
- 方向：死亡身份终结 → 第二社会身份生成
- 条件：必须持续参与公共舞台并隐藏真实身体状态
- 阶段变化：被迫表演 → 为团队表演 → 为自己选择表演

## 反咬点
1. **偶像身份原本是制作人制造的工具，最后却成为成员真正珍惜的第二人生。**
2. **复活看似撤销了死亡，实际上死亡仍通过旧亲友、时代差、身体秘密持续统治现在。**
3. **公众身份本来要求隐藏真实身份，但恰恰是这个“假身份”让角色重新获得真实关系。**
4. **越成功融入现代社会，越清楚自己不可能真正回到过去。**

## 视觉符号
- 舞台灯光 ↔ 苍白/腐败的僵尸身体
- 偶像妆容 ↔ 缝线、伤口、断裂肢体
- 现代LED舞台 ↔ 昭和/平成旧时代记忆
- 粉丝荧光棒 ↔ “重新被世界看见”的存在证明
- 团体服装 ↔ 不同时代个体被压成统一社会身份
- 佐贺地方景观 ↔ 第二人生的现实锚点

## 可复用母题
### 1. 死后职业化
“人生已经结束的人，被迫进入一种高度公共的职业。”
可迁移：亡灵演员、死者主播、复活骑士成为竞技明星、历史人物被包装成现代英雄团体。

### 2. 假身份比真身份更能制造真实关系
角色隐瞒最真实的秘密，却通过伪装职业身份建立了最真实的新关系。

### 3. 第二社会人生
复活不是回到旧生活，而是重新获得一个“社会可识别身份”。
公式：**旧人生终止 → 新标签被赋予 → 持续实践 → 关系沉淀 → 新身份真实化**。

### 4. 跨时代共同体
不同年代的人进入同一种现代制度，每个人携带不同z，最终形成共享n。

### 5. 地方振兴与个人重生同构
“救一个正在衰弱的地方”与“让已经死去的人重新活出意义”形成镜像，可用于把个人成长与公共任务绑定。

## 本轮凝结
### 新增母型名
**第二社会人生型偶像生成**

### 核心公式
**xz旧人生死亡 → nx被迫赋予职业 → xn持续实践 → n/nz关系沉淀 → zx主动认领 → 新x并z社会身份成立**

### 一句话矿核
> 偶像不是让死者重新变回活人，而是让已经失去社会位置的人，再次拥有一个被他人承认的“现在”。
