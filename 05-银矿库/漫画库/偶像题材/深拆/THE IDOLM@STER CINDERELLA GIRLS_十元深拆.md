# THE IDOLM@STER CINDERELLA GIRLS｜十元深拆

> 媒介：日本电视动画（游戏企划改编）
> 矿级：S
> 核心分类：**外部发现 / 招募点火型偶像生成**
> 本轮新增机制：**一个人尚未形成职业欲望时，先被外部评价者识别为“可能成为偶像的人”，再由机会、实践与舞台反向生产职业欲望。**

## 1. 为什么收入核心样本

官方动画介绍把 Cinderella Project 定义为：原本过着普通日常的女孩们，被选为“偶像之卵”，进入第一次看见的世界。第一话尤其形成两条相反入口：

- 岛村卯月：普通女孩，已经梦想成为偶像并在养成所训练，被 Producer 告知通过再选考。
- 涩谷凛：原本对偶像没有兴趣，甚至拒绝 Producer 的邀请，却被持续识别、邀请，最终进入项目。

因此它不是单一的“梦想→追逐”故事，而是把两个因果方向并列：

1. **内生欲望型：zn/zx 先成立 → 主动进入 xn**
2. **外部发现型：他人 x/nx 先介入 → 获得 x并z 候选身份 → 实践后才生成 zx/zn**

本卡重点研究第二条，因为它补足现有偶像库缺少的“被看见之后才产生职业可能性”。

## 2. 偶像身份如何建立

身份不是一次性获得，而分四层：

1. **被发现**：Producer 先把普通女孩看成“偶像候选人”。
2. **被纳入项目**：加入 346 Production 的 Cinderella Project，获得组织性的候选身份。
3. **被职业实践塑形**：宣材照、训练、伴舞、分组、CD出道、Mini Live、节目与活动不断把“候选”变成“从业者”。
4. **被自己认领**：角色逐渐不只是“别人说我可以”，而开始形成“我想以什么方式成为偶像”的自我定义。

## 3. 行业机制

### 训练
- 养成所 / 事务所训练
- 舞蹈、歌唱、镜头表现、摄影
- 不是抽象升级，而是把普通人的身体与表情调到职业标准

### 出道
- 项目制筛选
- 小组/Unit编成
- 宣材照 → 伴舞 → CD → Mini Live，存在明显的职业阶梯

### 竞争
- 竞争不只来自同龄候选人，还来自公司内部“什么样的偶像值得资源”的路线冲突
- 后期公司高层提出解散既有项目、重新选拔集中资源，竞争升级为**组织对偶像定义权的争夺**

### 舞台
- 舞台是身份验证器
- 第一次站上大舞台时，想象中的“成为偶像”与真实观众规模发生落差，迫使角色重新理解职业

### 粉丝
- 粉丝不是系统数值，而是社会反馈
- 观众数量、应援与现场反应会直接影响成员对“自己是否已经成为偶像”的判断

### 公司
- 346 Production 既提供入口、资源、训练和品牌，也掌握分组、企划、选择与解散权
- 因此公司同时具有 **xn（规则/制度）+ nx（外力安排）+ x并z（社会身份授予）** 三重功能

## 4. 十元体量

| 十元 | 体量 | 作用 |
|---|---:|---|
| x并z | 10 | 普通女孩、候选人、Project成员、Unit成员、正式偶像的层级身份变化 |
| n | 10 | Producer、成员、Unit、公司共同生产职业身份 |
| xn | 9 | 事务所、项目、训练、出道、公司资源与规则 |
| zx | 9 | 从被邀请/被选中转为主动争取舞台和自己的偶像路线 |
| nz | 9 | Producer信任、队友关系、粉丝支持把外部职业变成真实归属 |
| zn | 9 | “我真的想当偶像吗 / 我想成为什么偶像” |
| nx | 8 | 被发现、被邀请、被编组、被公司政策改变 |
| x | 8 | 个性、气质、歌舞与镜头能力逐渐被职业化 |
| z | 7 | 普通日常、既有性格和既往经验持续影响偶像路线 |
| xz | 5 | 有职业危机，但不是命运/死亡型强制发动 |

主元：**x并z**
次元：**n**
强承载：**xn**
关键转化：**nx → zx**

## 5. 顺序

### 主链A｜涩谷凛：被发现之后才产生职业欲望
**zn普通自我 → nx外部发现/邀请 → x并z候选身份 → xn职业实践 → n团队嵌入 → nz关系沉淀 → zx主动选择 → 新zn → 新x并z**

解释：
“我不是偶像，也没想过当偶像”并不直接跳成“我要当偶像”。中间必须经过可验证的实践与关系，职业欲望才被生产出来。

### 主链B｜岛村卯月：先有欲望，再获得入口
**zn梦想 → zx主动训练 → xn养成所/事务所 → x并z项目成员 → n共同成长 → 舞台验证 → 新zn**

两条链并置后得到：

> 偶像身份既可以由内部欲望寻找制度，也可以由外部制度先发现个体，再反过来生成欲望。

## 6. 五维

### 时间维｜xn + z：9/10
训练和项目阶梯把偶像身份做成持续过程；普通日常与过去性格不是被清空，而是在职业化过程中不断被重新解释。

### 本体维｜zn + x：10/10
核心不是“能不能唱好”，而是“被别人说适合当偶像之后，我是否愿意把这个可能性认作自己”。

### 空间维｜x并z + n：10/10
本作最强。身份来自事务所、Project、Unit、舞台、Producer和公众共同组成的社会空间。偶像不是孤立技能，而是一个被网络承认的位置。

### 因果维｜zx + nx：10/10
它同时保留“主动追梦”和“被外部发现”两种发动方式，尤其适合研究 nx 如何在不抹杀主体性的前提下转化成 zx。

### 命运维｜xz + nz：7/10
没有系统死亡惩罚式命运，但关系与职业机会会产生明显不可逆性：一旦队伍、舞台、粉丝和责任形成，退出就不再等于回到原点。

## 7. 关系结构

### Producer → 少女
最初：发现者 / 招募者 / 外部判断者
中期：资源配置者 / 职业翻译者
后期：支持者 / 与偶像共同维护项目的人

核心不是“上司命令下属”，而是：
**一个人先替另一个人看见她尚未看见的职业可能性。**

### 少女 ↔ Unit
个人气质被组合重新解释。进入 Unit 后，“我是谁”必须同时回答“我在这个组合里是什么位置”。

### 偶像 ↔ 公司
公司给予身份，也可能撤销身份；资源支持和身份控制是一体两面。

### 偶像 ↔ 粉丝
粉丝把舞台行为转化为社会承认，使“公司说你是偶像”进一步变成“社会也把你当偶像”。

## 8. 动态链

### 动态链1｜外部发现链
**普通人zn → 他人判断nx → 候选x并z → 制度xn → 实践x → 主动zx → 新zn**

条件：外部发现必须经过实践验证，否则只是被贴标签。

### 动态链2｜项目共同体链
**公司x并z → 招募多个个体 → n组合 → 共同任务xn → nz关系 → Unit新x并z → 反向强化个体zn**

核心：组织不是把已经完成的人放一起，而是先把未完成的人放进结构，结构再生产成员。

### 动态链3｜身份定义权冲突
**公司授予x并z → 高层重新定义xn → 既有项目被威胁nx → 成员/Producer zx抵抗 → n共同体强化 → x并z从“公司项目”转为“我们要守住的身份”**

## 9. 反咬点

### 反咬1：最初被别人看见，最后必须自己决定
外部评价可以开启职业，却不能完成职业本体。

**他人：“你适合当偶像。”**
→ 只是入口。

真正成立必须走到：
**自己：“我要以这种方式继续当偶像。”**

### 反咬2：公司制造项目，项目反过来产生不可随意拆解的共同体
最初 Project 只是组织工具。
但共同训练、舞台与关系沉淀后：
**行政项目 → n/nz共同体 → 成员本体的一部分。**

因此公司后来想“白纸化”时，才会遭遇身份层面的抵抗。

### 反咬3：灰姑娘的“魔法”必须变成日常劳动
视觉上是礼服、灯光、舞台；结构上却必须由训练、摄影、排练、失败、营业不断支撑。

> 魔法不是取消劳动，而是让长期劳动在舞台上一瞬间显形。

## 10. 视觉符号

- 普通制服 / 日常街道：旧zn
- 事务所大楼 / 门禁 / Project室：进入新x并z空间
- 宣材照：第一次把私人脸转成公众脸
- 舞蹈镜 / 练习服：xn塑形
- Unit服装：个人身份被组合重新编码
- 后台帘幕：普通人和公众偶像之间的阈限空间
- 舞台灯 / 观众荧光棒：社会承认
- 城堡 / 台阶 / 灰姑娘意象：身份跃迁的总符号

## 11. 本轮可复用母题

### 母题1｜被别人先看见的未来
角色自己没有职业欲望，但另一个人先判断“你可能适合”。

可迁移：
- 普通少女 → 被骑士长发现 → 骑士
- 小镇画师 → 被策展人发现 → 职业艺术家
- 路人 → 被导演发现 → 演员
- 无名士兵 → 被将军发现 → 指挥官

### 母题2｜招募者不是给予能力，而是给予入口
外部人不能替主角完成成长，只能改变她进入哪个空间。

公式：
**nx给予入口 → xn提供实践 → zx决定是否继续。**

### 母题3｜多个普通人被项目临时拼接，最后生成真实共同体
**组织标签 → 共同任务 → n/nz沉淀 → 新共同体本体。**

### 母题4｜身份授予者与身份拥有者发生定义权战争
公司创造职业身份，但当身份进入个人本体后，公司不再拥有完全解释权。

### 母题5｜榜样型与发现型的镜像
Aikatsu：
**我看见偶像 → 我想成为偶像。**

Cinderella Girls（凛）：
**别人看见我 → 别人认为我可能成为偶像 → 我才开始看见那个未来。**

这是两条互为镜像的“职业欲望生成链”。

## 12. 与现有S矿的差异

- Debut or Die!：命运强迫型
- Rogue Producer：幕后者前台化
- The Heavenly Idol：异质本体置换型
- Wake Up, Girls!：空组织身份实体化
- SELECTION PROJECT：公众裁决型
- Saving the Doomed Idols With My Touch：坏身份修复型
- Dream High：制度加工型
- ZOMBIE LAND SAGA：第二社会人生型
- Aikatsu!：憧憬感染型
- Assistant Manager Kim Hates K-Pop Idols：反职业欲望型
- **CINDERELLA GIRLS：外部发现 / 招募点火型**

## 13. 一句话矿核

> **有些职业欲望不是“我先想成为谁”，而是“有人先把我当成可能成为那种人，于是我才第一次看见那个自己”。**
