# An Insincere Idol's Blank Slate｜十元深拆

## 核心职业机制
Yoon Eden 已经作为 K-pop 偶像在无能公司中消耗多年，濒临退出时回到“出道当天”。第二次人生不是重新参加练习生选秀，而是从出道节点重新经营歌曲、概念、团体与职业路线。主角最大的可操作资源是作曲能力与上一轮失败经验。

这是“失败出道 → 回档到出道日 → 重写偶像商品与真实热情”的样本，偶像职业不是背景。

## 十元
- 主符号：xn。时间回卷与公司/出道制度共同构成第二轮职业规则。
- 次符号：z → zx。第一轮被磨灭的热情重新燃起，并转化为主动写歌、改造职业路线的行动。
- 第三层：x并z。歌曲、概念、营业形象与团体包装决定公众看到的偶像。
- 本体暗层：zn。题目中的“insincere → sincere”本身就是职业身份与真实自我的重建。

## 五维
- 时间：xn+z。回到出道日，让已经熄灭的偶像欲望获得第二次兑现窗口。
- 本体：zn+x。第一轮“我只是撑着工作的偶像”与第二轮“我愿意成为怎样的偶像”发生重写。
- 空间：x并z+n。舞台、歌曲、概念、团体品牌和公众观看共同构成偶像身份空间。
- 因果：zx+nx。主角主动用作曲和经验改变路线，但仍受公司、CEO与市场安排。
- 命运：xz+nz。失败职业史形成既定结局压力，团员协作成为把失败命运重新软化的关系条件。

## 生链
xn回档规则 → z旧热情复燃 → zx主动创作/修正路线 → x并z新概念与舞台成立 → zn重新确认“我愿意真诚地成为偶像”。

## 克链
1. xn公司规则 克 z：无能CEO、俗套歌曲和错误概念持续磨损热情。
2. zx 克 nx：上一轮经验与作曲能力让 Eden 不再只是接受公司安排。
3. zn 克 x并z：当真实创作欲望重新成立后，主角开始反过来拒绝不适合自己的商品包装。

## 5组补子
- xn + z：制度/时间必须与持续欲望结合，第二轮职业生涯才有意义。
- zn + x：真实偶像自我需要具体能力与行动来证明，而不是口头热血。
- x并z + n：概念包装只有进入舞台、团体、粉丝观看关系后才成为偶像身份。
- zx + nx：主动创作与被公司/市场选择始终同时存在。
- xz + nz：第一轮失败像既定命运，成员共同体提供改变结局的缓冲。

## 偶像职业机制评分
- 练习：8/10
- 选秀：低，不以选秀为主轴
- 出道：10/10，回档点就是出道当天
- 团体运营：9/10
- 舞台/歌曲：10/10
- 粉丝/公众反馈：8/10
- 公司/CEO：10/10
- 排名/竞争：7/10
- 作曲/作品生产：10/10

## 动态链
第一轮偶像zn
→ xn公司机制长期磨损
→ z热情衰减
→ nx接受烂歌与烂概念
→ 濒临退出
→ xn回到出道日
→ z旧热情重新出现
→ zx以作曲能力主动修正职业路线
→ x并z重新制造团体/个人公众形象
→ zn从“不真诚地营业”转向“真正认领偶像身份”。

## 可复用母型
**“不是重新获得出道资格，而是重新决定出道以后要成为什么。”**

与 Debut or Die! 的“必须出道”、My Comeback as the Youngest Member 的“重新争夺出道资格”不同，本作最有价值的是把回档点放在“出道当天”：资格已经获得，失败来自出道后的公司决策、作品生产和自我消耗。因此它适合作为“出道后经营失败 → 二周目职业路线重写”的独立母型。

## 判定
偶像职业度：10/10。
矿级：S。
理由：歌曲生产、公司概念、团体成员、出道节点和职业倦怠都直接参与主线；同时具有明显的 zn 本体修复价值，不是普通娱乐圈恋爱换皮。
