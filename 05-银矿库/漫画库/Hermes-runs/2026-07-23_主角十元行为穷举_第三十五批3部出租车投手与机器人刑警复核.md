# 主角十元行为穷举 · 第三十五批3部出租车投手与机器人刑警复核

## 本轮边界

- 扫描结果：漫画库在上一轮之后没有新增或人工修改的漫画条目；最近新增的是角色库发型 Canvas，属于非漫画范围，本轮未改。
- 本轮对象：小户川、泽村荣纯、盖吉希特。旧第三批剩余三部全部改为“动作在前、下一行唯一归类”，旧第三批因此完全历史化。
- 覆盖范围：《ODD TAXI》小学馆漫画第1卷/全5卷书目信息，动画第3话只作同源剧情交叉核验；《钻石王牌》讲谈社第1、10、20、25、44卷公开简介；《PLUTO》VIZ第1、2、5、6、8卷公开简介。
- 本报告穷举的是上述公开资料明确给出的动作，不是全作逐页穷举。出版社简介没有给出动作主体、过程或结果时，不借作品背景和群体结果给主角。
- 《ODD TAXI》五次载客都来自同一段书目简介，虽按不同作用对象分别列项，但统计主位时按单一证据簇降权，不能用五个名字虚增独立置信度。
- 一条动作只归一个十元；状态、愿望、身份、被动遭遇和调查结论不能单独构成十元时，保留“暂不归类”。

### 统计后判断

- 唯一归类统计：`nx`5 / `xz`1 / 暂不归类2，共8条。
- 主十元：`nx`88%候选。依据不是“五次计五票”，而是同一职业流程在五类不同乘客对象上重复出现；因独立来源只有一个书目证据簇，暂不升高置信。
- 次十元：未判。`xz`只有一次跨媒介同源高风险动作，只作功能位。
- 撤回旧结论：旧主`n`86%、次`xn`84%撤回。公开资料没有显示小户川主动承担关系中心，也没有明确给出他组织“收束计划”的具体动作主体与步骤。
- 关系候选：不登记。现有资料只见`nx`职业跟随与单点`xz`临界行程，尚未闭合任何生、克、补机制。
- 与作品主维关系：人物`nx`说明小户川多沿乘客目的地和出租车流程行动，不自动证明作品本体或因果主维；库内作品维度冲突继续保留。
- 原卷复核：优先漫画第3话对应卷的持枪乘客、漫画第3—5卷中是否确由小户川提出并执行收束计划，以及计划的对象、步骤和结果。

## 二、《钻石王牌 / Ace of the Diamond》｜泽村荣纯

- 行为4：校园参观期间遇到捕手御幸 → 泽村与御幸组成投捕搭档并实际投球 → 作用对象为御幸的接捕框架和投捕关系 → 这次配合重新点燃他对棒球的投入。【AD-1】

### 统计后判断

- 唯一归类统计：`nx`5 / `nz`1 / `zn`1 / `z`1 / `zx`1 / 暂不归类1，共10条。
- 主十元：`nx`94%候选。跨校园参观、投捕搭档、夏季两次接替和秋季决赛换投，稳定沿球探、教练、捕手与球队轮换给出的路线行动。
- 次十元：未判。`nz/zn/z/zx`各只有一个不同阶段节点；`zx`可保留为公开比赛功能位，不能凭单点升次位。
- 撤回旧结论：旧主`z`93%、次`zx`89%撤回。认可与公开显权均有动作，但数量和跨阶段稳定性都弱于`nx`。
- 关系候选：不登记。现有书目能确认多个十元共现，却不能证明某一十元如何改变另一十元的变量；竞争、换投与强校环境也都是第三因素。
- 与作品主维关系：人物`nx`说明泽村在球队结构中的运行方式，不等于作品时间、本体或空间主维。总索引与主题页的作品维度冲突继续待二审，本轮不裁定。
- 原卷复核：优先第1卷“御幸投捕”、第20卷危局登板、第25卷王牌竞争、第44卷川上换投至雷市对决；核对教练指令、泽村主动性和对局结果。

## 三、《PLUTO / PLUTO冥王》｜盖吉希特（Gesicht）

- 身份与阶段：欧洲刑警组织机器人刑警、“世界七大机器人”之一；只覆盖第1—6卷调查阶段。
- 来源文件：[[02-时间型 xn+z]]、[[漫画库总索引]]、[[漫画主角十元行为分析索引]]、旧第三批报告。
- 当前状态：VIZ公开书目范围穷举；第7—8卷由阿童木承接答案与终局，不把阿童木行为反算给盖吉希特。

- 行为1：蒙布朗与机器人权利倡导者先后死亡 → 欧洲刑警组织把案件交给盖吉希特 → 他接受案件并进入机构调查流程 → 两起死亡成为其正式案卷。【PL-1】
  - 归类：`nx`（单点机构路径证据，93%）。对象端点：欧洲刑警组织的任务授权、两起案件与刑警流程；调查起点由机构分配。

- 行为2：两名死者看似无关但现场都有角状痕迹 → 盖吉希特围绕共同痕迹追查两案 → 作用对象为两处现场与共同线索 → 两案被纳入同一调查结构。【PL-1】

- 行为3：调查继续推进 → 盖吉希特查到自己也是袭击目标 → 作用对象为目标名单与自身身份 → 案件范围从外部受害者扩展到调查者本人。【PL-1】
  - 归类：暂不归类（证据不足）。理由：公开简介只给出调查结论，没有写明他得知后采取了哪一种后续行动；“成为目标”本身是状态。

- 行为4：更多线索显示高性能机器人被依次锁定 → 盖吉希特推断凶手正针对世界上最强大的机器人 → 作用对象为受害者名单和目标模式 → 调查从两个案件升级为有序列的目标网络。【PL-2】
  - 归类：`xn`（主位证据，97%）。对象端点：高性能机器人名单、袭击顺序与目标模式。

  - 归类：`n`（单点承接证据，95%）。对象端点：潜在受害机器人、阿童木及其安全；重点是主动承担保护/通知责任，不重复算作名单组织。

- 行为6：案件显出人类与机器人之间的仇恨 → 盖吉希特继续深入调查这种仇恨与连环案的联系 → 作用对象为社会仇恨、受害者与案件因果 → 调查结构从凶手名单扩展到冲突背景。【PL-5】
  - 归类：`xn`（主位证据，95%）。对象端点：仇恨线索、受害者与案件因果网络。

- 行为7：外部调查开始触及自己的空白 → 盖吉希特开始解锁自己被封存、几乎遗忘的记忆 → 作用对象为自身记忆与身份答案 → 个人内部真相被纳入调查范围。【PL-5】
  - 归类：`zn`（单点内核证据，91%）。对象端点：自己的封锁记忆和身份内核；公开简介没有提供方法，暂不升次位。

### 统计后判断

- 唯一归类统计：`xn`4 / `nx`1 / `n`1 / `zn`1 / 暂不归类1，共8条。
- 主十元：`xn`96%候选。共同痕迹、目标名单、仇恨背景和多名嫌疑端点跨卷构成稳定的主动调查组织链。
- 次十元：未判。`nx/n/zn`各只有单点；旧次`zn`88%撤回，封锁记忆只能保留为内部真相功能证据。
- 关系候选：不登记。`nx`受命、`n`警告和`zn`记忆虽与`xn`共现，但公开简介不足以证明生、克、补的前后变量变化。
- 与作品主维关系：人物主`xn`可旁证时间型的组织与推进一端，但不能消解作品时间/因果/本体冲突，更不能用人物动作直接改仓。
- 主角边界：第7—8卷阿童木复活、取得答案与承担终局战均属阿童木行为；盖吉希特只统计到第6卷。【PL-8】
- 原卷复核：优先第1卷两案合并与“自身也是目标”后的选择、第2卷警告阿童木、第5卷记忆解锁主体、第6卷逼近真相的具体调查动作。
