# 主角十元行为穷举·第四十八批：推位、便当与刑罚前线校验

## 本轮边界

- 本报告把第二十三批旧报告转为现行可校验格式，覆盖`アイドラトリィ / Idolatry`、`邪神の弁当屋さん`、`判处勇者刑 / 勇者刑に処す`3部作品、3位主角、16条具体行为。
- 校验顺序严格为“先看剧情证据并列动作，再逐条归入一个十元，最后统计主次位”。旧报告的16条行为、逐条归类、人物主次位及关系候选均未改变；本轮新增证据键、来源范围和正式替代关系。
- 证据范围仅为出版社公开书目/专题与库内旧报告，不是漫画原页全卷实读。因此只称“公开资料范围穷举”，不称全作穷举；没有公开到动作主体或结果的内容保留为暂不归类。
- 人物十元与作品主题、评分和归仓分层。本轮不修改96/93/93分、旧9分驳回、作品主维、最终归仓或官方理论。

## 一、アイドラトリィ / Idolatry

### 对象与覆盖范围

- 主角：陽見循菜；偶像宅女高中生、选秀参赛者。
- 阶段：偶像团体解散后至选秀第3阶段。
- 覆盖：讲谈社第1—4卷公开书目与官方专题，非全作原页穷举。
- 当前状态：公开资料范围穷举校验完成；旧“仅1卷”记录已过期，按4卷范围；旧96分及作品空间主/因果次65%草案仍待二审。

### 具体行为穷举与逐条归类

- 行为1：得知ふわり将在团体解散后参加新选秀 → 循菜决定亲自进入同一场100人选秀 → 作用于自己的参赛位置与ふわり已选择的路线 → 两人进入同一赛程。【ID-FEATURE】
  - 归类：`nx`（次位证据，92%）。对象端点：ふわり既有的偶像目标、选秀路线和推—被推关系；方向由ふわり先给出，循菜沿该方向进入。
- 行为2：进入选秀后 → 循菜决定在节目内暗中运作，把ふわり推向顶点 → 作用于比赛流程、排名目标与ふわり的曝光 → 单纯参赛被改造成持续推位任务。【ID-FEATURE】
  - 归类：`xn`（主位证据，91%）。对象端点：排名目标、节目流程与后续行动安排；公开资料确认主动组织意图，具体步骤仍待原卷。
- 行为3：第1阶段启动 → 循菜把ふわり引导到预定排名并使其获得注意 → 作用于排名顺序与舞台曝光 → 预设结果在该阶段兑现。【ID-V2】
  - 归类：`xn`（主位证据，95%）。对象端点：第1阶段排名、ふわり曝光位置与阶段节点；她主动安排并命中预定结果。
- 行为4：第2阶段改为团队MV拍摄 → 循菜与ふわり及队友共同完成团体赛 → 作用于团队任务与晋级条件 → 队伍越过该阶段。【ID-V3】
  - 归类：暂不归类（证据不足）。官方简介只给出团队共同结果，没有说明循菜承担了哪项独立动作，不能把队友行为记给她。
- 行为5：第3阶段与ふわり分队且队内必有一人淘汰 → 循菜在正式舞台连续采用奇策 → 作用于自己的留存位置与ふわり的发光条件 → 她继续存活并维持推位方向。【ID-V4】
  - 归类：`xn`（主位证据，94%）。对象端点：淘汰规则、舞台节点、本人留存与ふわり曝光；奇策内容仍待第4卷原页。

### 穷举后统计

- `xn`3条，跨第1—3阶段，主十元95%；`nx`1条，次十元92%；暂不归类1条。
- 关系候选：`xn`与`nx`仅确认分工共现，不登记生、克、补。前者是循菜主动组织赛程，后者是她沿ふわり既有方向进入；现行关系表没有充分机制把两者自动连成关系。
- 反证：暗跃、奇策不因“隐蔽”自动归`nx`；排名变化也不自动归`x`，因为没有证据证明节目、票源或参赛者资源归循菜掌握。
- 与作品主维：人物`xn+nx`描述她怎样组织选秀并沿ふわり方向推进，不等于作品空间公式；舞台、包装与观看仍属作品/场景层。
- 待原卷复核：第1卷参赛决定是否另有个人目标；第2卷具体操作；第3—4卷奇策归属及控制的规则/资源。

## 二、邪神の弁当屋さん

### 对象与覆盖范围

- 主角：レイニー；曾是死与丰收之神ソランジュ，受罚后以人类身份经营便当摊。
- 阶段：全4卷的人类生活、便当营业、旧神殿共同劳动至最终神/人选择前。
- 覆盖：讲谈社全4卷公开书目与官方专题，非全作原页穷举。
- 当前状态：公开资料范围穷举校验完成；第4卷仅确认创世主要求其在回归神位与作为人生活之间选择，公开简介未公布结果。

### 具体行为穷举与逐条归类

- 行为1：因过去引发战争而受到惩罚 → レイニー停止原来的神之生活并以人类身份继续生活 → 作用于自身身份与惩罚后果 → 神的停职状态被接成人类日常。【JB-FEATURE】
  - 归类：`n`（主位证据，92%）。对象端点：落到她身上的人类身份与惩罚后果；她没有退出，而是把后果接入生活。
- 行为2：进入人类生活后 → 她每天在城堡附近中央广场经营便当摊 → 作用于摊位、食物与来客 → 惩罚后的生活获得可持续落点。【JB-FEATURE】
  - 归类：`n`（主位证据，94%）。对象端点：便当摊、每日来客与人类生活；重点是持续承接生活，不以普通职业本身证明`xn`。
- 行为3：制作便当时面对形状不同的食材 → 她按“做出高度、填满空隙、放入同一模具”的方法装盒 → 作用于食材、便当盒与摆放顺序 → 零散材料成为可交付便当。【JB-FEATURE】
  - 归类：`xn`（次位证据，88%）。对象端点：食材形状、装盒顺序、空隙与便当成品；她主动组织材料怎样运行成结果。
- 行为4：无依无靠的少年进入她的生活 → 她向少年教会重要事项 → 作用于少年当前生活问题 → 少年取得可继续生活的信息。【JB-V2】
  - 归类：`n`（主位证据，82%）。对象端点：落到身边的少年及其生活问题；教学内容与触发过程仍待第2卷原页。
- 行为5：北国居民到旧神殿大扫除 → 她虽不情愿仍加入既有共同劳动 → 作用于神殿、公共安排与居民关系 → 她与人群共同完成劳动并共享时间。【JB-V3】
  - 归类：`nx`（功能位，84%）。对象端点：居民已启动的清扫安排与共同劳动路线；方向不是由她设定，她沿既有群体行动加入。
- 行为6：每日营业进入下一日准备 → 她持续思考明天便当要做什么配菜 → 作用于次日菜单与经营延续 → 今天的营业获得下一节点。【JB-FEATURE】
  - 归类：`xn`（次位证据，86%）。对象端点：次日菜单、准备节点与营业连续性；公开材料未给出完整排程，置信度保守。

### 穷举后统计

- `n`3条，覆盖惩罚、人类营业与少年问题，主十元94%；`xn`2条，次十元88%；`nx`1条功能位84%。
- 关系候选：`n生xn`（84%）。人类生活与每日便当责任先被她接住，才持续提供可安排的食材、菜单和营业任务，使次日流程展开；顾客需求、市场、同住者与惩罚制度仍是第三因素，故只记候选。
- 反证：“一日一善”是原则背景，不自动归`zn`；温柔共居不自动归`nz`；普通职业劳动也不自动归`xn`，只有具体装盒与次日菜单组织算功能证据。
- 与作品主维：人物主`n`与库内空间主候选在承接端局部一致，但便当盒、摊位和旧神殿只是对象/场景，不能据此宣告人物具备完整`x并z+n`。
- 待原卷复核：第1卷具体善行、第2卷教学内容、第3卷清扫主动程度、第4卷最终选择及选择后的日常。

## 三、判处勇者刑 / 勇者刑に処す 懲罰勇者9004隊刑務記録

### 对象与覆盖范围

- 主角：ザイロ・フォルバーツ；前圣骑士团长、惩罚勇者9004队领队。
- 阶段：漫画第1—2卷的绝境战、与剑之女神テオリッタ契约及异形化煤矿任务。
- 覆盖：KADOKAWA漫画第1—2卷公开书目，非全作原页穷举。
- 当前状态：正式日文题名、漫画媒介与第1—2卷范围已锁；库内93分主记录、旧9分因果驳回及命运/因果/本体三向记录继续隔离。

### 具体行为穷举与逐条归类

- 行为1：被投入不能以死亡退出的惩罚勇者制度 → ザイロ持续带领由问题罪犯组成的9004队站在魔王现象前线 → 作用于队伍与当前战场 → 队伍仍能进入连续作战。【YK-V1】
  - 归类：`n`（次位证据，88%）。对象端点：落到他手中的9004队、战场后果与领队责任；具体指挥步骤待原卷。
- 行为2：圣骑士团在绝境中被压垮 → 他为活下去决定击倒魔王并公开宣告反击 → 作用于战斗方向与现场敌对对象 → 被压制状态出现直接反攻方向。【YK-V1】
  - 归类：`zx`（战斗功能位，84%）。对象端点：当下魔王现象与反击方向；单次宣告/行动不足以证明人物权能持续扩大并凌驾秩序。
- 行为3：自身现有手段不足以完成反击 → 他判断テオリッタ的力量不可缺少 → 作用于外部力量、权限位置与解决通道 → 反击路线转向女神关系接口。【YK-V1】
  - 归类：`nx`（主位证据，86%）。对象端点：属于テオリッタ的力量与使用许可；关键资源不在他手中。
- 行为4：确认力量属于テオリッタ → 他承认需要她并与她缔结契约 → 作用于女神权限、契约关系与战斗资源 → 他取得借力通道并脱离当下危机。【YK-V1】
  - 归类：`nx`（主位证据，92%）。对象端点：テオリッタ拥有的力量、契约许可与借力关系；这是明确通过他者权限办事。
- 行为5：脱离危机后立即收到下一道命令 → 他与其他惩罚勇者按命令前往异形化煤矿 → 作用于制度路线、队伍与任务地点 → 行动沿刑罚体系进入下一阶段。【YK-V2】
  - 归类：`nx`（主位证据，91%）。对象端点：上级命令、惩罚勇者流程与煤矿任务；方向由制度给出，他沿既有安排推进。

### 穷举后统计

- `nx`3条，覆盖女神契约与下一任务，主十元92%；`n`1条，次十元88%；`zx`1条战斗功能位84%。
- 关系候选：`nx补zx`（83%）。行为3—4通过契约取得テオリッタ的力量与许可，补足行为2直接反击所缺的战力条件，使反击功能重新成立；公开简介不足以证明`zx`是稳定人物主位。
- 反证：领队、战斗、决定反击不自动等于`zx`；愤怒与复仇不自动等于`z`，公开资料没有给出确认其存在、能力或价值的认可主体。
- 与作品主维：人物主`nx`、次`n`只说明他怎样沿刑罚方向、借女神权限并承接队伍；稳定`zx`未锁，不能据此证明作品因果主，题名中的“刑”也不能直接证明命运主。
- 待原卷复核：第1卷具体领队行为、契约条件与权限分配；第2卷煤矿任务中是否主动重排路线；复仇行动是否跨卷稳定。
