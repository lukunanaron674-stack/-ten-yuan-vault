## 一、《Dorohedoro》

### 十元判断与对象端点

- **主十元：`x` 92%**。端点不是抽象“寻找自我”，而是开曼自己的原始头部/身体、被施加的魔法状态、失落记忆所指向的身份，以及“谁有权决定这副身体是什么”的控制边界。他把解除魔法、找回原形和确认身份持续纳入“必须由我掌握”的范围。
- **次十元：`xn` 90%**。端点是魔法使样本、口中男人的辨认结果、恢复的记忆碎片、废校名册，以及潜入烟宅邸时采用的员工身份、面具和时机。开曼不是只战斗，也会把线索和进入权限组织成下一步追查。
- **功能位：`zx` 86% / `n` 84%**。对魔法使和Hole-kun的正面战斗构成直接执行，但官方梗概不足以证明他稳定追求公开凌驾与权能扩大，故`zx`不升主位；二阶堂被捕或受伤时他会接住救援负载，属于`n`功能而非稳定主骨。
- **生补克**：`x`与`xn`共现，但当前生补克表没有足够证据说明“身份归属”单独催生追查结构，或追查结构补住控制边界。魔法、二阶堂、敌方组织和恢复记忆都是强第三因素，本轮不登记正式关系。

### 可观察行为证据

1. **头部被魔法改成蜥蜴且记忆丧失 → 开曼与二阶堂持续追猎魔法使，让“口中的男人”辨认对方是否为施术者 → 作用于魔法使、身体原形与身份线索 → 每次辨认都把嫌疑人转成下一轮追查输入。**（第1卷；`x + xn`）

3. **宅邸举办派赛、二阶堂处于烟的控制下 → 开曼趁比赛把二阶堂带离 → 作用于二阶堂、控制关系与撤离路线 → 救援成功进入下一节点，但被控制的二阶堂转而与他战斗。**（第7卷；`n + xn`，脱离控制结果待原卷）
4. **零碎记忆逐渐恢复并指向过去 → 开曼忍着剧烈头痛进入废弃魔法训练学校搜查 → 作用于记忆、学校记录与“Risu”身份 → 他在名册中发现Risu之名，得到可继续核对的具体对象。**（第9卷；`xn + x`）

### 行为模式总结

自己的身体、身份或重要关系被魔法和敌人夺走控制时，开曼会先把对象锁进“必须夺回并确认”的边界，再通过反复辨认、追查记录、伪装潜入或直接战斗把控制权拉回自己一侧。

### 反证与作品主维关系

- **反证**：身体受害不自动等于`x`，必须看开曼是否持续执行“找施术者—解除魔法—确认原形”；战斗多也不自动等于`zx`，公开梗概没有证明他以凌驾世界为稳定目的。第7、23卷的二阶堂救援会把`n/nz`权重拉高，需原卷看关系是否长期压过身体身份主线。
- **作品层**：精修名单的100分来源路径写在因果型目录，总索引汇总又把Dorohedoro列为空间型；人物`x+xn`既不等于`zx+nx`，也不等于`x并z+n`。人物结论只触发维度二审，不裁仓。

## 二、《ルリドラゴン / RuriDragon》

### 分析对象与范围

- **主角**：青木ルリ（青木琉璃），突然长出角并逐步显现龙体质的高中生。
- **阶段**：第1—3卷公开书目；从长角、放电控制到体育祭执行委员/委员长阶段。
- **来源文件**：`漫画库_全名单-精修版-2026-06-02.md`、集英社[第1卷](https://books.shueisha.co.jp/items/contents.html?isbn=978-4-08-883285-2)、[第2卷](https://books.shueisha.co.jp/items/contents.html?isbn=978-4-08-884164-9)、[第3卷](https://books.shueisha.co.jp/items/contents.html?isbn=978-4-08-884415-2)。
- **当前状态**：第1—3卷主角轻筛完成；正式日文题名已锁。精修名单列96分，但引用源文件名含66.25分与“未入库”，先登记评分/状态来源冲突，不改分。

### 十元判断与对象端点

- **主十元：`n` 95%**。端点是突然长出的角、放电等龙体质、同学的注视或回避，以及体育祭委员职责。变化先落到琉璃身体和日常上，她没有把变化推出去，而是继续上学、试控、与不合拍同学共事并承接更大职责。
- **次十元：`xn` 91%**。端点是放电能力的控制方法、体育祭执行工作的分工与委员长职责。琉璃会把不可控身体反应转成试错对象，也会让陌生职责进入可持续运行的校园结构。
- **功能位：`x`候选84% / `nz`候选82%**。若原卷显示她能稳定调用角、火焰、放电等身体资源，可补具体`x`端点；与前田逐渐和解可提示`nz`关系停靠，但公开简介不足以证明关系成为稳定主骨。
- **关系候选：`n生xn` 88%**。身体异变和校园职责先落到琉璃身上，之后她才通过试错控制放电、通过委员工作组织日常，改变的是“异常能否从一次事故变成可管理运行”。学校安排、母亲说明和同学合作是强第三因素，故只记候选。

### 可观察行为证据

1. **清晨醒来发现头上长角、母亲说明父亲是龙 → 琉璃虽困惑仍照常前往学校 → 作用于新身体、家庭解释与校园日常 → 龙体质第一次被带入公共生活，而非被藏在家中。**（第1卷；`n`）
2. **同学对角表现出强烈好奇、另一种龙体质继续显现 → 琉璃留在班级日常中面对注视与身体变化 → 作用于同学关系和自身身体 → 异常没有中止她的学校生活。**（第1卷；`n`，具体应对动作待原卷）
3. **课堂中突然放电并确认新的龙体质 → 琉璃反复试错，尝试把放电控制下来 → 作用于身体能力与周围安全 → 不可控反应被转成需要测试和管理的问题。**（第2卷；`n生xn`候选，控制结果待原卷）
4. **成为体育祭执行委员并与前田起初合不来 → 琉璃继续与前田共同做委员工作 → 作用于体育祭任务和同学关系 → 两人逐渐磨合、关系由不合转向能够合作。**（第3卷；`n + xn/nz`）
5. **委员工作扩大且琉璃再次受到关注 → 她进一步承担委员长位置 → 作用于体育祭流程、班级协调与自身公共位置 → 陌生环境从被动压力转成她必须维持的运行职责。**（第3卷；`xn + n`，委员长具体分工待原卷）

### 行为模式总结

身体或校园变化落到琉璃身上时，她先让它进入自己的日常，不因异常退出；随后以试错、共同工作和承担职责，把一次性异变慢慢整理成能继续生活的运行方式。

### 反证与作品主维关系

- **反证**：性格平静、日常系氛围或“能忍”都不是`n`；本轮主位依赖“变化落身—继续上学/共事—再处理”的连续动作。放电试错若完全由母亲或学校设计，`xn`应降为`nx`功能。
- **作品层**：当前96分条目没有稳定正式主维，且源文件名仍写66.25分、未入库。琉璃的`n+xn`同时触及空间承接与时间运行，但人物层不能替作品直接归仓；先解决评分/状态来源，再做作品维度二审。
- **复核**：第1卷第二种龙体质与她的具体应对；第2卷放电控制由谁安排；第3卷委员长是否由她主动接受、怎样分工；前田关系是否形成稳定`nz`。
- **建议写入位置**：人物索引、同名冲突复审队列（题名/评分/状态来源）；正式评分和入库结论待用户二审。
