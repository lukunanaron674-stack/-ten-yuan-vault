## 一、Maus

### 来源与作品背景

- 库内来源：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-18_本体S级4部新版生克补关系轻筛.md`
- 正式评分：97，不改。
- 作品导航：本体型 `zn+x` 主、时间型 `xn+z` 次、命运辅。
- 公开书目确认作品同时编织父亲的集中营生存经历与成年父子关系；因此必须把“被访谈者如何生存”和“作者如何组织证言”分开。

### 1. Art Spiegelman（Artie）

#### 对象与十元

- **身份 / 阶段**：成年漫画作者；从重新探访父亲、记录战前经历到把父子冲突编入《Maus》。
- **主十元 `xn`（94%）**：主动组织访谈顺序、录音、记忆材料、漫画层次和出版结构，使零散证言能够持续成为作品。
- **次十元 `zn`（90%）**：把“如何忠实承担父母创伤而不把父亲美化”为内部创作准则；它会打断纯粹顺滑的叙事工程。
- **`x`功能端点（82%）**：录音带、笔记、画稿、版面选择、叙述先后及最终著作的编辑权；这是具体创作控制，不是“想知道过去”的欲望。
- **压力状态**：母亲自杀、父亲衰老及幸存者后代的负担可形成 `xz` 高压，但压力本身不自动成为人物主十元。

#### 行为证据（5条）

1. **父亲往事长期未被系统讲述** → Art主动恢复探访并请Vladek从波兰生活讲起 → 作用于父亲口述、录音与时间顺序 → 家族记忆获得可连续整理的入口。`xn`
2. **Vladek在讲述中跳时段或转去日常争执** → Art追问人物、地点和先后并把对话录下 → 作用于碎片化证言 → 口述被压成可画的事件链，而不是只保留情绪印象。`xn`
3. **母亲自杀无法由父亲的幸存叙事充分覆盖** → Art把早期作品《Prisoner on the Hell Planet》嵌入书中 → 作用于媒介层、自己的创伤和母亲缺席 → 第二代创伤被保留为独立证据，不被父亲故事吞没。`zn + xn`
4. **得知Vladek烧毁Anja日记** → Art当面追问并以极重的道德语言指责父亲 → 作用于遗失的第一人称证言及父亲的故事控制权 → “完整家族史”的组织工程被伦理缺口强制中断。`zn克xn`候选
5. **父亲既是受害者又在晚年表现出吝啬、操控和偏见** → Art把访谈现场的争执与历史回忆并置 → 作用于父亲形象和读者判断 → 成书没有把Vladek修平为单一英雄，关系难题成为作品结构的一部分。`zn + xn`

#### 行为模式总结

> 遇到无法消化的家族创伤时，Art先收集口述与遗留材料，再用漫画层次、时间顺序和自我暴露把它组织成可持续见证；一旦“好讲的故事”伤害证言伦理，他会让伦理问题反过来打断编排。

#### 关系启动与反证

- **`n生xn`（高）**：Vladek口述、照片、家庭材料先被Art接住，才形成可编排的漫画工程；目标变量是证言的连续性和可出版性。
- **`zn克xn`（中高候选）**：日记被毁、父亲形象难以美化时，Art的见证伦理压缩“顺畅成书”的自由，迫使结构保留缺口和争执。
- **反证**：Art并非稳定掌握父亲或历史；他多次被父亲的跳叙、隐瞒和情感债打乱。因此不能把作者身份直接判成主`x`，也不能把作品的本体主维直接贴回人物。

#### 与作品主维、复核位置

- **关系**：部分一致。Art的`zn`承担本体追问，但最稳定可观察动作是`xn`式采访和编排；人物主位不等于作品主维。
- **待复核**：第一册开篇访谈、`Prisoner on the Hell Planet`嵌套段、Anja日记被毁段；第二册成名压力和父亲去世后的编排段。
- **建议写入**：[[漫画主角十元行为分析索引]]、本体主题页人物摘要、总索引人物层状态。

### 2. Vladek Spiegelman

#### 对象与十元

- **身份 / 阶段**：波兰犹太幸存者、Art的父亲；战前经商、占领期逃亡、集中营生存及美国晚年。
- **主十元 `xn`（96%）**：持续组织交易、配给、藏身、身份伪装、劳动技能和人际路线，让自己与Anja在不断缩小的条件下继续运行。
- **次十元 `x`（94%）**：食物、现金、珠宝、工具、藏身点、劳动技能和家庭物品的实际掌握边界。
- **`n`（89%）**：接住突发信息、配给和他人帮助，再把它们转入下一步方案。
- **`xz`**：战争、清洗、集中营和死亡威胁属于外部危险状态；不能因为长期处在危险中就把Vladek本体判为`xz`。

#### 行为证据（6条）

1. **占领区犹太人配给被压缩** → Vladek通过黑市、交换和既有商业能力补足供给 → 作用于食物、钱和家庭成员 → 一家人在正式制度之外继续生存。`xn + x`
2. **隔都清洗逼近** → Vladek设计、寻找并切换假墙/隐蔽空间 → 作用于Anja、自身和藏身路径 → 捕捉时间被推迟，组织网络得以续接。`xn克zx`候选
3. **公开身份会立即招致逮捕** → 他使用服装、语言和路线伪装成波兰非犹太人 → 作用于检查者的识别与通行路径 → 获得短时移动和寻找下一处停靠的能力。`x并z`行为功能，不升为本体
4. **与Anja或亲属被分离** → 他用珠宝、关系和可交换资源安排消息、重聚或救援 → 作用于关系网络和稀缺通道 → 家庭连接在制度性切断下被局部恢复。`xn + x`
5. **集中营中一般劳工随时可被淘汰** → 他把英语、修鞋/钣金等技能转成对管理者有用的劳动 → 作用于岗位、口粮和保护 → 自己获得延长生存的具体位置。`x + xn`
6. **战后物资已不再极端匮乏** → 老年Vladek仍反复计算药物、食物、钱和可回收物 → 作用于家庭日常与Mala/Art的选择空间 → 战时组织机制继续运转，却转化为关系冲突。`xn`的跨场景持续证据

#### 行为模式总结

> 面对制度性剥夺或突发危险，Vladek会先盘点手中食物、钱、技能、空间和关系，再把它们排成下一条可活下去的路线；这套机制救过他，也在战后继续控制家庭日常。

#### 关系启动与反证

- **`xn克zx`（中高候选）**：长期准备的藏身、交易和身份路线压缩迫害者“立刻识别—立刻抓捕”的直接权力；目标变量是暴露概率与可行动时间。它不是终止迫害，只是阶段性限制。
- **`n生xn`（中高）**：收到的消息、配给和帮助被继续组织成方案；若没有接住外部资源，计划无法续行。
- **反证**：Vladek的精确组织并不等于稳定道德意义；他会操控家人、固守偏见。也不能把“幸存”结果倒推成每次选择都正确或高尚。

#### 与作品主维、复核位置

- **关系**：不直接一致。Vladek人物主位偏`xn+x`，作品本体主来自父子如何理解幸存、创伤和叙述权；时间次维则与他的组织行为高度相关。
- **待复核**：第一册“配给/黑市—隔都藏身—伪装逃亡”；第二册“Auschwitz技能/交换—与Anja联络—战后晚年”。
- **建议写入**：[[漫画主角十元行为分析索引]]、本体主题页人物摘要、总索引人物层状态。

## 二、地。关于地球的运动。 / Orb: On the Movements of the Earth

### 来源与作品背景

- 库内来源：[[01-本体型 zn+x]]、[[漫画库总索引]]、[[同名冲突复审队列]]、`2026-07-18_本体S级第二批4部新版生克补关系轻筛.md`
- 正式评分：中文主条96；Orb/チ。的96/93/92/87/10仍按旧批次证据隔离，不合并。
- 作品导航：本体型 `zn+x` 主、时间型 `xn+z` 次、因果辅。
- Seven Seas合订本明确把故事写成代际接力：Rafal留下研究；十年后Oczy接到石箱；Badeni组织证明；因此本轮只分析前三位接力者。

### 1. Rafal

#### 对象与十元

- **身份 / 阶段**：十五世纪欧洲的神童；从预定进入大学学习神学到落入宗教审判。
- **主十元 `zn`（95%）**：把理性能够成立的宇宙真相视为高于安全身份的内部标准。
- **次十元 `n`（88%）**：接住导师、吊坠和研究留下的知识对象。
- **`xn/x`功能**：计算、观测和寻找研究属于组织功能；对吊坠、手稿及石箱的保管属于具体控制，但证据量不足以升为人物主位。

#### 行为证据（4条）

1. **社会为他安排神学与早入大学的安全路径** → Rafal把理性推演和天文问题放在既定身份之前 → 作用于自己的学业方向和宇宙模型 → 得出地球绕太阳运行的危险结论。`zn`
2. **导师把被压制的宇宙真相交给他** → 他接受吊坠/线索并继续追索研究 → 作用于被封锁的知识对象 → 理论没有随导师退出而立即中断。`zn生n`候选
3. **宗教裁判开始追捕** → Rafal在逃亡压力下仍沿吊坠寻找研究，而不是只恢复神学生身份 → 作用于个人安全与研究路线 → 真理标准持续压过制度提供的安全流程。`zn克xn`候选
4. **第一代研究无法由本人公开完成** → 他留下装有宇宙秘密的石箱供后人发现 → 作用于研究材料的跨代可取回性 → 十年后Oczy/Gras仍能接入同一问题。`n`承载 + `xn`功能

#### 行为模式总结

> 当安全身份与可由理性确认的真相冲突时，Rafal先选择真相，再接住并留下能让真相跨过本人生命的研究对象。

#### 反证、作品关系与复核

- **反证**：Rafal并未长期经营完整研究组织；不能把后代的协作、写作和传播全部回算给他，也不能因作品有“知识传承”就把他直接判成主`xn`。
- **与作品主维**：高度一致于作品`zn`端；`x`主要落在石箱/研究保管边界，仍需原卷验证。
- **待复核**：英文合订本第1—2卷的导师交接、吊坠追索、审判和石箱留下方式。

### 2. Oczy

#### 对象与十元

- **身份 / 阶段**：Watch Guild青年成员；从与Gras发现石箱到执行Badeni计划、迎战Nowak。
- **前期主十元 `nx`（91%）**：方向最初来自Gras的兴趣、Rafal遗物和Badeni的研究路线；Oczy沿他人和关系网络进入。
- **后期`zn`候选（90%）**：从“替别人拿着危险物”迁移为愿意把自己的行动押在理论是否值得保存上。
- **`n/xn`功能**：接住石箱、携带研究、协助找合作者和执行计划。
- **`zx`节点行动**：与Nowak决斗是公开、临界执行，不自动等于稳定主`zx`。

#### 行为证据（5条）

1. **执行Watch Guild任务时意外发现石箱** → Oczy与Gras把箱子带离原处而非立即销毁 → 作用于Rafal遗留的知识对象 → 第一代研究进入第二代关系网络。`n`
2. **Gras对日心说的兴趣和希望转交给他** → Oczy接下石箱与未完成方向 → 作用于自己的行动路线 → 他最初不是提出理论，而是沿关系遗产继续。`nx`
3. **石箱既可出售又可能招致火刑** → 他抓住理论提供的微弱希望，前去寻找Badeni → 作用于石箱、研究解释权和合作者 → 危险遗物转入能解读它的人手中。`nx + n`
4. **现有证明不足** → Oczy与Badeni寻找新的女性研究协作者并参与观测/传递 → 作用于协作网络和证据规模 → 私人物件开始成为可验证的共同研究。`xn`功能
5. **Badeni的最终计划需要有人突破审判者节点** → Oczy主动前往与Nowak进行决定性对抗 → 作用于研究能否继续显影的路径 → 原本的低主导承接转成以身体承担结果的公开行动。`zn`上升 + `zx`节点

#### 行为模式总结

> Oczy先沿Gras、石箱和Badeni给出的路线接住任务；随着自己确认这份真相值得留下，他从“替人保管”转为主动承担最后的危险节点。

#### 反证、关系与复核

- **阶段迁移反证**：前段方向明显由他人与遗物提供，不能用后段决斗把全期重写成主`zx`或主`zn`。
- **关系判断**：目前只确认`n → xn`的过程事实；`nx`转`zn`是否为稳定本体重构，必须检查存在方式、核心痛苦和反复选择是否同时改变。
- **与作品主维**：人物前段更接近作品时间传承接口，后段才触及本体`zn`；二者不能合并成一个静态点位。
- **待复核**：合订本第1—4卷石箱转交/拜访Badeni；第5—6卷计划与Nowak决斗。

### 3. Badeni

#### 对象与十元

- **身份 / 阶段**：聪明而疏离的修士/研究者；从接收Oczy石箱到组织证明与最后计划。
- **主十元 `xn`（96%）**：把石箱、观测、协作者、Piast资料和风险节点组织成可证明、可继续的研究工程。
- **次十元 `zn`（92%）**：认为真知识值得超过“闭眼、塞耳、做普通人”的安全生活。
- **`x`功能端点（88%）**：对石箱、记录、计算、协作权限和研究成果解释权的具体掌握。

#### 行为证据（5条）

1. **Oczy带来无法自行解释的石箱** → Badeni接管、阅读并把内容转为待证明问题 → 作用于Rafal遗物和研究解释权 → 石箱从秘密物件变成研究工程。`n生xn`
2. **现有观测不能独立完成证明** → 他安排Oczy参与并主动寻找新的协作者 → 作用于人力、观测能力和信息分工 → 单人推理扩展为多节点验证。`xn`
3. **女性学者被时代排除在正式学术身份外** → Badeni仍把她纳入合作范围 → 作用于协作权限与证据来源 → 制度压低的知识能力被接入研究。`xn + zn`
4. **地心说权威Piast把研究资料交给他** → Badeni把对立模型的数据继续纳入推演 → 作用于观测记录和模型边界 → 证明不是只靠信念重复，而是吸收反方积累。`n生xn`
5. **宗教审判逼近、研究需要越过封锁** → Badeni制定后续计划并让Oczy执行对Nowak的关键行动 → 作用于知识保存/显影路径 → 个人研究被压成能在高压下继续运行的节点链。`xn`

#### 行为模式总结

> 面对危险但有价值的知识，Badeni会先取得解释权，再把材料、反方数据、被排除的人和行动节点编成证明计划；信念决定研究不能停，组织能力决定它如何继续。

#### 反证、关系与复核

- **`n生xn`（高）**：石箱和Piast资料被接住后，直接扩大了研究的证据规模与可验证路径。
- **`zn克xn`（中候选）**：真理优先级会压缩修会/社会为他提供的安全流程，但是否足以称为关系启动，需要原卷确认第三因素与反向解释。
- **反证**：Badeni善于组织不等于他掌握时代、审判制度或所有协作者；也不能把Oczy最后的身体对抗算成Badeni自己的`zx`。
- **与作品主维**：主`xn`高度支撑作品时间次维，次`zn`与作品本体主相接；正好说明人物层和作品层可交叉但不等号。
- **待复核**：合订本第3—4卷协作与Piast资料；第5—6卷最终计划。

### 《地。》别名与评分边界

## 三、火鸟·凤凰篇 / 火之鸟（凤凰篇）

### 来源与作品背景

- 库内来源：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-18_本体旧口径第三批4部关系复审与源范围修正.md`
- 正式评分：系列主条97，不改。
- 作品导航：本体型 `zn+x` 主、命运型 `xz+nz` 次、时间/空间为跨篇容器。
- 本轮只取官方明确列为双核心的《凤凰篇》：我王与茜丸。系列其他时代人物不参与判断。

### 1. 我王

#### 对象与十元

- **身份 / 阶段**：独眼独臂盗贼，后受良弁上人救助并成为雕刻者。
- **前期主十元 `zx`（94%）**：用直接暴力对外显影和夺取生存位置。
- **后期主十元 `zn`（95%）**：把雕刻和缓解众生痛苦内化为活着的意义。
- **`n/x`功能**：接住旅途中看见的疾病、死亡和贫困，再把石材/技术纳入雕刻掌握。
- **早期`xz`**：身体残缺与被排斥是危险状态，不自动等于人物本体。

#### 行为证据（5条）

1. **长期被排斥且以盗贼身份生存** → 我王抢夺并伤害旅途中的茜丸惯用手 → 作用于他人身体与物资 → 通过直接暴力建立短时支配位置。`zx`
2. **良弁上人没有杀死而是救下他** → 我王停止原有路线并随高僧周游诸国 → 作用于自己的行动方向和关系位置 → 暴力惯性第一次被新的承接关系截断。`nx/n`阶段功能
3. **旅途中反复看到疾病、死亡与贫困** → 他观察、承受并把这些面孔转入雕刻 → 作用于众生经验和造型材料 → 痛苦不再只触发攻击，而成为表达对象。`n → zn`过程
4. **雕刻才能被唤醒** → 我王持续制作能触及受苦者心灵的作品 → 作用于石材、技艺和观看者 → 个人生存能力被重新定向为意义实践。`zn补x`候选
5. **橘诸兄让他与茜丸竞争大佛殿鬼瓦** → 我王以作品进入公开比较，而非先以抢夺决定胜负 → 作用于鬼瓦、技艺和双方位置 → 与旧仇人的冲突暂时被转写为创作判断。`zn + x`

#### 行为模式总结

> 我王前期以直接暴力逼世界承认自己的存在；被救并见到众生苦难后，他把接住的痛苦刻进材料，以雕刻而非伤害来证明生命可以有什么意义。

#### 反证、关系与复核

- **阶段迁移**：`zx → zn`不能简化为“暴力生出信念”。良弁救助、旅行和众生苦难是强第三因素，现阶段不启动`zx生zn`。
- **`zn补x`（中高候选）**：后期生命意义为雕刻技能、材料和作品掌握提供方向；目标变量是技艺被用来伤害还是救济。
- **反证**：我王的旧罪并未因转变消失；被揭发和受刑也不能反向证明茜丸行为属于我王。
- **与作品主维**：高度一致。我王的迁移正面展开作品“生命意义—具体技艺/身体掌握”两端，但仅代表《凤凰篇》，不能替代整套《火鸟》人物分析。
- **待复核**：《凤凰篇》早期伤害茜丸、随良弁旅行、雕刻觉醒、鬼瓦竞赛及受刑后的结尾。

### 2. 茜丸

#### 对象与十元

- **身份 / 阶段**：佛像工匠；从被我王伤害惯用手、复健成名到担任东大寺大佛工程监督者。
- **主十元 `z`（94%）**：稳定把技艺价值放在师门、权贵、公共工程和竞赛的承认结构中确认。
- **次十元 `xn`（92%）**：以长期复健、修行和大型工程组织维持职业路径。
- **`x`（89%）**：对工匠身份、项目权限、赞助/庇护关系、竞赛资格与惩罚渠道的具体掌握。

#### 行为证据（5条）

1. **惯用手被我王重伤、职业资格可能终止** → 茜丸持续修行和复健 → 作用于身体、技艺与训练时间 → 恢复雕刻能力并重返工匠评价体系。`xn + z`
2. **技艺恢复后需要公共证明** → 他不断精进并接受作品评价 → 作用于作品、师门/社会认可 → 名声累积，职业位置从受伤者转为知名佛师。`z`
3. **权贵橘诸兄提供大型工程入口** → 茜丸接受其赞助/庇护并升为东大寺大佛建造监督者 → 作用于工匠身份、项目权限和生产资源 → 个人技艺获得制度规模的显影。`z + x`
4. **大佛殿鬼瓦被设置为双人竞赛** → 他把自己的名声和监督者位置投入与我王的公开比较 → 作用于作品、观众和职业等级 → 胜负开始直接威胁既有认可。`z`
5. **发现自己可能在作品比较中失败** → 茜丸揭露我王旧罪并调用权力惩罚链 → 作用于我王身体、竞赛资格和公众判断 → 我王仅剩右臂被砍，工艺判断被制度控制改写。`x克z`候选

#### 行为模式总结

> 茜丸先用复健、修行和大型工程把自己重新放回公共认可中心；当作品评价可能夺走这一位置时，他转而调用赞助/庇护关系与惩罚权控制比较结果。

#### 反证、关系与复核

- **`x克z`（高候选）**：茜丸调用对项目/权力渠道的掌握，直接压缩我王作为竞赛者被作品认可的资格；目标变量是竞赛结果和公众判断。
- **反证**：早期长期复健说明他并非只靠权力；不能用结尾的恶行抹掉前段`xn`积累，也不能因佛像题材把他自动判为`zn`。
- **与作品主维**：部分一致但方向反转。我王以`zn`给技艺`x`方向；茜丸从`xn+z`进入制度`x`，最终让掌握权压过作品判断。二者共同支持作品本体问题，但人物主位不同。
- **待复核**：《凤凰篇》受伤复健、成名、东大寺工程、鬼瓦竞赛和揭发惩罚段。
