## 本轮结论

本轮继续清理本体页中把 `x` 写成欲望、执念或流逝的旧分析：

- 《火鸟》与《Homunculus》仍可保留本体主导航，但关系端点必须重定义。

- 《本なら売るほど》旧分析不仅把 `x` 当欲望，还使用了现行位置表不存在的 `n 生 x`；官方书目同时确认作者为 `児島青`、舞台为古书店“十月堂”。别名簇可升为高置信，但本体/空间主次冲突继续保留。

本轮只更新当前摘要、机器状态、旧报告降权说明、源名/作者纠错和二审队列；97/93/91 及《本なら売るほど》94/88/87/77、十月堂95/92/83/10各批评分均不改。

## 1. 火鸟 / 火の鳥 / Phoenix

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-09_漫画分析_Hi_no_Tori_Phoenix.md`
- **当前状态**：精选入库；旧关系卡降为历史口径；新版关系复审完成
- **主维 / 次维 / 辅维**：本体型 `zn+x` / 命运型 `xz+nz` / 时间与空间容器
- **评分 / 置信度**：97 分不变；新版关系判断 90%
- **对象端点**：
  - `zn`：有限生命、生死与轮回为何有意义。
  - `x`：对火鸟血、永生、身体寿命、生命技术与统治资源的具体占有/控制。
  - `n`：承载同一生命问题的身体、文明与篇章时代。
  - `xz/nz`：战争、毁灭、轮回漂流与接受有限生命的停靠。
- **十元公式判断**：
  - `zn 生 n`（高）：生命意义问题反复生产不同身体、文明和时代载体。
  - `n 生 xn`（中高）：每个时代/文明载体继续组织其生灭、传承与轮回流程。
  - `zn 补 x`（高）：生命意义与“能否掌握永生”互相逼问；这里的 `x` 是权属和控制，不是欲望本身。
  - `x 生 x并z`（中高）：掌握火鸟血、永生或统治资源，生产“永生者/神圣统治者”的可见身份。
  - `xz 克 zn`（高）：战争、灭绝与轮回压力反复压低个体意义。
  - `nz 克 x`（中高）：接受死亡、亲情与情感停靠能够阻止对永生的纯占有。
- **动态链**：`zn → n → xn`；另一侧为 `x → x并z`；`xz 克 zn` 与 `nz 克 x` 使两条链不断回到 `zn ↔ x`。
- **五大主题关系**：命运对本体的克制显著，但作品仍以“生命为何有意义、永生是否可被掌握”组织各篇；本体主、命运次保留。
- **核心理由**：手塚治虫官方页把作品核心明确为跨越时空反复追问“生与死、轮回转生”，支持 `zn` 和跨时代载体链；旧“想永生= x”必须改成对永生资源的实际掌握关系。
- **是否需要复核**：低至中；抽查黎明篇、未来篇、复活篇，确认 `x` 是否都落到具体掌握而非仅有渴望。
- **建议写入位置**：本体主题页、总索引、任务清单；旧完整卡加“关系语义已过时”门控。

## 2. 藤本树短篇集

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`漫画库_全名单-精修版-2026-06-02.md`
- **当前状态**：精选入库；关系轻筛完成；**collection-scope / 源范围待二审**
- **主维 / 次维 / 辅维**：现存导航为本体型 `zn+x` / 时间型 `xn+z` / 因果型 `zx+nx`
- **评分 / 置信度**：93 分不变；聚合条目本体主位暂为 70%
- **源范围问题**：VIZ 官方把 `Tatsuki Fujimoto Before Chainsaw Man` 分成 `17–21` 和 `22–26` 两册。库内“藤本树短篇集”没有说明93分覆盖一册、两册，还是更大的作者短篇集合；旧源另有86.2分记录。
- **对象端点**：
  - `zn`：短篇中反复出现的身份、自我意义和“怎样成为自己”。
  - `x`：只能逐篇证明的身体、能力、创作物或亲密关系掌握边界；不能再用“创作冲动/日常欲望”统包。
  - `x并z/z`：身体变化、能力、作品或怪异身份被看见后形成的可见身份与认可位置。
  - `xz`：短篇中的灾变、异化与不可逆处境。
- **十元公式判断**：
  - `x 生 x并z`（中）：角色掌握身体/能力/关系后，才生产出可见的异常身份；必须按单篇核验。
  - `x并z 生 z`（中）：异常身份或创作物被看见后，改变角色的认可位置。
  - `xz 克 zn`（中高）：灾变和异化持续侵蚀自我意义。
  - `zn 补 x`（中、候选）：意义与具体掌握边界可能在部分短篇互补，但尚不能提升为整套合集的统一机制。
- **动态链**：候选为 `x → x并z → z`，并受 `xz 克 zn` 打断；合集层尚不能宣布单一主链。
- **五大主题关系**：本体主位可以继续作导航候选，但在合集范围和单篇证据未明确前，不应用作者风格直接替代作品级证明。
- **核心理由**：官方简介只证明两册收录藤本树早期短篇，并列出人鱼、性别转换、恶魔妹妹等不同故事入口；这些差异反而说明必须逐篇固定 `x` 对象。
- **是否需要复核**：必须；先回查旧93分源文件对应目录，再决定是保留聚合ID还是拆成17–21、22–26两个ID。
- **建议写入位置**：本体主题页、总索引、任务清单、同名/源范围复审队列。

## 3. Homunculus / ホムンクルス

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-09_漫画分析_Homunculus.md`
- **当前状态**：精选入库；新版关系复审完成；91分继续待实读二审
- **主维 / 次维 / 辅维**：本体型 `zn+x` / 命运型 `xz+nz` / 因果与空间误判防线
- **评分 / 置信度**：91 分不变；新版关系判断 84%
- **对象端点**：
  - `zn`：名越“我是谁、看见的究竟是谁”的自我意义。
  - `x`：车、脸、身体和社会身份中“哪些仍归我掌握”的具体边界。
  - `x并z/z`：被塑造的脸、身份外壳及其带来的社会认可位置。
  - `xz/nz`：流浪临界状态与被遗弃后长期凝固的情感停靠。
- **十元公式判断**：
  - `xz 克 zn`（高）：流浪、被遗弃与不可逆临界状态持续侵蚀自我意义。
  - `x 生 x并z`（高）：对脸、车、身体和身份的掌握生产出可见的社会自我。
  - `x并z 生 z`（中高）：被构造的外表/身份继续生产他人如何确认名越。
  - `zn 补 x`（中高）：自我意义与“什么还算我的脸、身体、生活”互相补足。
  - `nz 克 x`（中高）：被遗弃的凝固情感不断破坏名越自称掌握的生活边界。
  - `xz 补 nz`（高）：当下漂流与过去凝固等待构成命运互补。
- **动态链**：`xz 克 zn`；车这一 `x` 边界被剥夺后触发钻孔事件；随后显露 `x → x并z → z`，最终回收到 `xz ↔ nz`。
- **五大主题关系**：命运克本体的压力很强，但“脸、身体、车与自我究竟哪部分属于我”仍使本体主导航成立。
- **核心理由**：Seven Seas 官方简介确认名越住在车里、车被拖走后接受钻孔手术；这正好提供了具体 `x` 边界被剥夺的故事启动点。旧“荷蒙库鲁斯=欲望形状”不能直接充当现行 `x`。
- **是否需要复核**：需要；重点验证脸部改变、车与“被看见”三段是否稳定形成 `x → x并z → z`。
- **建议写入位置**：本体主题页、总索引、任务清单；旧完整卡降为历史关系卡。

## 4. 本なら売るほど / 十月堂译名簇

- **来源文件**：[[01-本体型 zn+x]]、[[03-空间型 x并z+n]]、[[漫画库总索引]]、[[🚩待实读作品清单]]、[[同名冲突复审队列]]
- **当前状态**：推定完成；高置信别名 + 评分冲突 + 本体/空间维度冲突待二审
- **主维 / 次维 / 辅维**：本体型 `zn+x` 与空间型 `x并z+n` 主次未决 / 命运弱
- **评分 / 置信度**：94/88/87/77与十月堂95/92/83/10全部不变；同作置信95%；本体主位78%、空间结构84%
- **明确纠错**：
  - 官方书目作者为 **児島青**，旧卡 `小島あお / Ao Kojima` 为作者字形错误。
  - 官方简介明确舞台为古书店“十月堂”，因此十月堂译名簇与《本なら売るほど》的同作关系可由普通 alias-conflict 升为 high-confidence-alias。
  - 旧卡核心 `n 生 x` 不在现行位置表中；现行是 `n 生 xn`、`zn 补 x`。
- **对象端点**：
  - `x`：书的所有权、保管、估价、买卖和“留下还是转手”的掌握边界。
  - `zn`：一本书对原主人、新读者及店主意味着什么。
  - `n`：书、藏书与十月堂作为承载结构。
  - `xn`：估价、收书、陈列、出售和再次相遇的重复流程。
  - `x并z`：书被整理、标价、陈列后呈现的可见商品/相遇形式。
- **十元公式判断**：
  - `zn 生 n`（高）：书的个人意义决定哪些藏书被保存、带入十月堂并继续成为故事载体。
  - `n 生 xn`（高）：书店与藏书载体生产估价、买卖、陈列和再相遇流程。
  - `zn 补 x`（高）：书的意义与所有权/去留决定互相补足。
  - `x 生 x并z`（中高）：书被接收、估价和纳入库存后，生产其公开陈列形式。
  - `n 补 x并z`（中高）：书店/书架的承载与书的陈列形式形成空间互补。
- **动态链**：`zn → n → xn`；另一侧 `zn ↔ x → x并z`，两链在十月堂相遇。
- **五大主题关系**：本体意义/权属链和空间承载/陈列链都已成立；官方“书与人再次相遇之处”的定义让空间证据略强，但不足以直接改仓。
- **核心理由**：作品不是“书店承载欲望”，而是书的意义怎样通过所有权转移、保存和重新陈列进入下一段人生。
- **是否需要复核**：必须；抽读至少4个顾客单元，比较 `zn↔x` 与 `n↔x并z` 哪一组稳定组织每话。
- **建议写入位置**：本体页、空间页、总索引、待实读清单、冲突队列；旧卡加作者纠错与关系过时门控。
