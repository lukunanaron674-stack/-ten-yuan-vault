# Gizmorizer · 十元分析

> 階層で分かれ、身分差が絶対視された世界。最下層で自由のない奴隷として働かされる少年「クロー」に、世界に抗う装具「ギズモ」が託される。階層を隔てる壁、この国に蔓延る諦念、差別、狂気を越え、少年は上へ――。誇りと自由を掴むための叛逆が始まる!!

## 0. 一句话定义

"上升即正义"——一副机械手套作为执行器官(zx)的外置，驱动一个被压迫者在垂直分层世界中一段一段往上爬，每一次攀登都是一次对"不配感"(nx)的结算式否定。

## 一、霜 · 主维归属

**霜判：因果型 (zx+nx) 主 · 命运型 (xz+nz) 次**
**置信度：78 / 10**

### 归属理由

Gizmorizer 的核心结构不是「世界为什么是这种分层」(本体型)，也不是「规则如何运行的动力学」(时间型)，更不是「空间场域的分类与调律」(空间型)。它的引擎是 **nx→zx** 的因果结算链：

- **n (容器/承载) 作为起点而非终态**：世界塔本身就是n——垂直分层的社会容器。但主角不是「守住这个位置」，而是「这个位置不该属于我，所以我爬出去」。n在这里是被否定的存在状态，不是归属。
- **zx (目标执行) 作为主驱动**：每一话的核心动作都是「爬升一段」——从最下层到下一层，每一层都有独立的对手(sx)、需要结算的旧账(nx)、需要克服的装置型障碍。zx是每一段的发动机。
- **nx (世故/结算) 作为底层恐惧**：世界塔的内在逻辑是「你生在最下层，你就该在最下层」——这是nx的判决。主角的每一次上升都是对这套判决的颠覆性结算。
- **xz (边缘/漂流) 作为背景色调**：主角的起点是命运边缘状态——孤儿、奴隶、不可动。但作品的重点不在于「可怕边缘体验」(那是命运型)，而在于「爬出去」的行动本身。

### 误判防线

| 易误判为 | 为什么不是 | 颜色等级 |
|:---------|:-----------|:--------:|
| 命运型(塔楼背景·阶层差距) | 塔楼背景只是设定燃料，核心是「爬」这个执行动词。主角不是被命运推着走(那是xz主)，而是主动找每一关、每一层的对手结算 | 🟡 |
| 本体型(奴隶获得尊严) | 故事的重点不是「我是谁」的存在追问，而是「我要去哪里」的目标执行 | 🟢 |
| 时间型(一层一层的时间压力) | 时间不是规则——每层的时间是弹性可压缩的，主角的节奏自己决定；时间型需要规则感(xn)压住z | 🟡 |

**体量：7 / 10**

### 关系对子

**主对子：zx ↔ nx (因果执行—结算互补)**

Gizmorizer 的核心力学是 zx 与 nx 的补关系在因果型中最强大的那一档：每一次「爬升」(zx)本身就是对「旧阶层判决」(nx)的否定性结算；而每一次结算完成后，新的「目标/对手」又出现在前面等待被爬升。这不是简单的「先结算再执行」——在作品中，结算和执行是同一动作的两面。

```
攀爬(zx) = 否定旧判决(nx)
↓
到新层 → 新判决(nx)出现 → 又需要攀爬(zx)
↓
回收型循环：每层一套zx-nx锁
```

**次要对子：xz → zx (边缘生执行 / 强度8)**

塔底边缘状态(xz)是作品最有效力的驱动力发生器。主角如果不生在最下层、不失去所有亲人，就不会有攀爬的需要。xz → zx 是作品「第一推力」，而之后作品靠 zx-nx 补对维持。

**潜在对子：xn 克 zx (规则克执行 / 强度7)**

世界塔的政权规则(xn)压制攀爬行为——不允许下层的人进入上层。这是主角最大的外部阻力，但他的方法是绕过规则、用执行能力打破限制。

### 动态链


## 六、可复用创作素材

1. **攀爬=结算(垂直xx否定)的叙事模板**：因果型xc的核心技巧——主角的每一次「向上」动作(xx)同时也是对旧系统判决(nx)的结算。这不是先结算再执行，是攀爬本身就在否定。

2. **阶层容器作为叙事地图(n)**：世界塔的每层是独立的规则环境(xn)+独立的对手(nx的具身化)。这个设计把一个整体的「社会压迫」拆成了可量化的关卡——每一层是一个结算锁，解锁后进入下一层。

3. **机械手套=执行器官外置(zx的可视化)**：Gizmo手套不是一个普通工具——它是「执行能力」的物理化。戴上手套，手变成了攀爬工具；不戴手套，主角是普通的奴隶。这种「执行能力被外置在装备上」的设计，是因果型角色的经典模型：装备≈zx的具身。

4. **起点=边缘状态×(xz)**：主角三个边缘条件同时打包——孤儿、奴隶、最下层。这形成了一个「不爬就死」的绝对前提，让读者不质疑「为什么要爬」。

5. **短作品的得与失**：2卷10话的优点是结构紧凑、没有水份；缺点是——意义层(zn)几乎缺席，爬到塔顶后的「然后呢」没有回答。这对于长连载来说可能致命，但对于短篇来说反而是特点。

## 七、创作模板提取

**«阶层攀登型»叙事结构骨架**

```
起点层: 边缘角色(xz) + 容器阶层(n) → 触发装备/事件
├─ 第1层: 对手A — nx判决(1) + zx攀爬(1)
├─ 第2层: 对手B — nx判决(2) + zx攀爬(2)  
├─ ...
├─ 第N层(决胜): 最终判决 + 最终攀爬
└─ 塔顶: 结算完成但意义未完(zn弱)
```

**可用场景**：
- 任何「垂直分层社会+主角从底部往上爬」的叙事
- 装备驱动型上升（装备=执行能力外置）
- 每层独立对手+独立规则的关卡设计
