## 一、葬送的芙莉莲 / 葬送のフリーレン / Frieren: Beyond Journey’s End

### 芙莉莲（Frieren）

**来源与阶段**：[[03-空间型 x并z+n]]、[[05-命运型 xz+nz]]、[[漫画库总索引]]、Hermes任务清单；讨伐魔王后五十年重逢与辛美尔葬礼，至北上旅途中进入帝都护卫阶段。

**当前状态**：VIZ系列页与第1—5、14卷书目轻筛；“重访旧地/收集民间魔法”的逐话定位待原卷复核。

**十元判断**

- 主十元：`nz`，95%。具体关系端点是辛美尔与旧勇者队、同伴遗愿、曾共同经过的地点、死者留下的记忆，以及前往灵魂安眠之地再见辛美尔的愿望；核心不是原地苦等，而是不愿让已经结束的人际联系彻底冷却。
- 次十元：`n`，92%。具体承接端点是辛美尔葬礼带来的迟到理解、海塔托付的菲伦、艾泽给出的北行建议、旧敌与各地请求；事情来到面前后，她会接住并处理。
- 状态位：`xz`，90%。长寿与人类寿命错位、旅途危险、旧敌回返会制造时间漂流与临界战斗；这些首先属于时间结构/当前状态，不能单靠“精灵长寿”反写人物稳定本体。
- 功能位：`xn`，88%。对象端点是北上路线、进入北部高原所需一级魔法使资格、队伍人员和跨年行程；但菲伦承担了大量日常时间管理，不能把全队组织力都归给芙莉莲。
- 功能位：`x`，86%。对象端点是她已经学会、可以实际调用的魔法与魔法书；只算已掌握的法术资源，不把同伴、城镇或魔法协会算作“归她所有”。

**行为证据**

1. 五十年后重见已经衰老的旧队友、随后参加辛美尔葬礼 → 芙莉莲流泪并承认自己没有真正了解他，决定重新理解人类并完成同伴遗愿 → 作用于已结束却仍有余温的旧关系 → 葬礼没有把关系封死，而被转成新的旅途方向。
2. 海塔临终把菲伦与魔法训练托付给她 → 芙莉莲先检验并训练菲伦，海塔去世后带她上路 → 作用于海塔遗愿、菲伦的生活与能力 → 一次托付被持续承接为师徒关系，支持`n/nz`。
3. 艾泽建议前往英雄灵魂安眠之地、那里也位于昔日魔王城方向 → 芙莉莲接受“与辛美尔再次对话”这一停靠目标并北上 → 作用于漂流路线与死者关系 → 时间错位获得了明确关系终点，而不是无目的旅行。
4. 北行途中昔日未完成的魔族威胁重新出现 → 芙莉莲调用旧战经验并与当前同伴处理芙拉梅/勇者队时代留下的问题 → 作用于过去选择与现在队伍的安全 → 旧时间没有只作为回忆存在，而被接入当下行动。
5. 进入北部高原必须取得一级魔法使资格 → 芙莉莲前往魔法都市参加考试，并推动菲伦一同取得通行能力 → 作用于资格、路线和队伍继续北上的条件 → 外部规则经`xn`功能成为可继续运行的旅程节点。
6. 在旅行中遇到与旧队友有关的地点、遗愿或不起眼魔法 → 芙莉莲愿意停下、收集、施法或向菲伦讲明旧事 → 作用于民间法术与关系痕迹 → 小型事件不断把“已经结束的十年旅程”传递给新队伍；具体话次待复核。

**行为模式总结**：当死亡、寿命差或旧地重现提示一段关系已经结束时，芙莉莲会先接住迟到的理解，再把遗愿、记忆与小魔法转换为重访、带徒和北上路线，让关系以新的行动形式继续存在。

**反证与关系机制**

- 她不断移动、战斗且会主动收集魔法，反驳“只在原地等”的纯`nz`判断；因此`n/xn/x`均为必要补充，但主线目标仍反复回到“理解旧同伴、再见辛美尔、保存关系痕迹”。
- “精灵长寿导致永远告别”是时间结构证据，不足以单独把人物本体锁为`xz`。本轮依对象层协议把旧卡中的“时间尺度漂流=人物行为”降为状态层证据。
- `xz↔nz`互补候选（91%）：外部长寿错位不断压缩人与人共同停留的时间，芙莉莲的重访、履行遗愿与前往灵魂安眠之地，为这种漂流补上可返回/可对话的关系目标；端点跨“时间状态—人物关系行为”，故不写成人物内部两元自动互补。
- `n生xn`候选（88%）：海塔托付、艾泽建议、旧敌与地方请求成为队伍路线/任务的输入，目标变量是“北上旅途如何继续”；菲伦与其他同伴承担组织工作的第三因素未排除，因此只记候选。

**与作品主维**：人物主`nz`直接支持命运型中的柔情停靠端；作品的`xz`主要来自寿命错位、死亡与危险旅途等时间/关系结构，不应全部贴到芙莉莲人物本体。人物分析支持“空间→命运”的旧推翻方向，但不能单独证明完整`xz+nz`，也不改96分主条。

## 二、孤独的美食家 / 孤独のグルメ

### 井之头五郎（井之頭五郎）

**来源与阶段**：[[03-空间型 x并z+n]]、[[漫画库总索引]]与现行`n`信息量卡；漫画第1—2卷的一话完结探店结构。

**当前状态**：扶桑社漫画官方站的作品说明、角色页与第2卷试读/书目信息轻筛；各餐馆与菜名页码待纸本复核。

**十元判断**

- 主十元：`n`，97%。具体承接端点是工作地点周边偶遇的餐馆、端到面前的菜、味道/温度/分量、邻桌与店内气氛；他把外部食物充分接入身体和独白，再完成消化闭环。
- 次十元：`zn`，91%。具体内部标准是“不预先查店、珍惜偶遇、独自自由地吃、按自己的美学选店选菜”；不靠榜单、陪同者或公开评分确认。
- 功能位：`xn`，89%。对象端点是菜单、点单顺序、菜与主食的组合、是否加点以及进食节奏；这是一餐内部的主动组织，不自动升级为人物主位。
- 状态位：`xz`，82%。商谈使他在不同城市移动，但移动只是进入用餐场景的外部条件；没有持续危险逼近，不能因“走街串巷”判主`xz`。
- `x`端点：不成立。餐馆、餐盘、菜品和地方风味不归五郎掌握；吃进身体是消化行为，不等于建立占有/调配边界。

**行为证据**

1. 为进口杂货生意到不同地方商谈、工作结束后饥饿出现 → 五郎不按榜单巡店，而在周边步行寻找当下愿意进入的店 → 作用于陌生街区与偶遇餐馆 → 工作路线被转换成一次自足用餐入口。
2. 面对高档/流行店与融入街区多年的大众食堂、个人店 → 五郎按自己的店铺美学选择后者并独自入店 → 作用于可选择餐馆 → `zn`内部标准先筛出“这顿饭在哪里发生”，而非求公众认可。
3. 落座后面对陌生菜单与店内信息 → 五郎观察菜名、分量、邻桌和自己的饥饿程度，再组合主食、配菜与饮料 → 作用于一餐的顺序与资源 → `xn`把外部菜目组织成可完成的进食结构。
4. 料理端上桌 → 五郎逐样入口、停顿、辨认味道与口感，并用独白处理感受 → 作用于食物、身体与个人经验 → 外部对象完成“接住—品味—消化”的`n`闭环。
5. 实吃后发现份量、搭配或味觉方向与预想不同 → 五郎重新安排吃法或追加菜品/主食 → 作用于尚未完成的一餐 → 感官反馈不是公开评价，而成为下一步点单与进食节奏的输入。
6. 吃完获得满足 → 五郎结账离店，回到工作或街道，不占有餐馆、不给店铺建立权威排名 → 作用于已完成的用餐经验 → 容器清空复位，等待下一次工作地点中的偶遇。

**行为模式总结**：工作把五郎带到陌生地方，饥饿触发他按个人美学偶遇选店；落座后，他把菜单和实际味觉组织成一餐，充分接住、消化，再清空离开。

**反证与关系机制**

- 五郎会主动选店、组合菜单并加点，反驳“什么落下都被动接”的纯`n`；但这些主动行为始终服务于接食/品味闭环，没有扩大成经营餐馆、控制资源或公开压过他者。
- 餐盘、店面和地方风味属于场景/包装对象，不得把`x并z`从餐馆直接继承给五郎。
- `zn生n`（92%）：不查店、尊重偶遇、独食自由等内部标准扩大了他愿意接入的餐馆/菜品范围，目标变量是“哪一种当下经验可以进入完整用餐闭环”。
- `n生xn`（90%）：第一口味道、分量与饱腹度改变下一轮点单/搭配/进食顺序，目标变量是“一餐能否完整而不过量地收束”；作用发生在单餐行为层。

**与作品主维**：人物主`n`支撑空间型中“内部承载/消化”一端；餐馆与餐盘的`x并z`属于场景/食物形式层。人物不是`x并z`，但人物`n`与每话店铺容器共同使作品空间主维成立，原“空间型合理”结论保持。

## 三、神之山岭 / 神々の山嶺 / The Summit of the Gods

### 深町诚（深町誠）

**来源与阶段**：[[04-因果型 zx+nx]]、[[漫画库总索引]]；尼泊尔发现旧相机线索至第5卷拍摄羽生终局。

**当前状态**：集英社文库漫画版第1—5卷官方简介轻筛；访谈对象、相机流转与具体攀登日程待原卷复核。

**十元判断**

- 主十元：`xn`，96%。对象端点是旧相机的来源、马洛里是否登顶的问题、羽生身份/经历、证人和资料、摄影器材、入山路线与拍摄位置；他持续把零散事实排成调查和见证链。
- 次十元：`n`，92%。具体承接端点是相机中可能存在的历史、羽生口述/经历、山中景象与最终攀登；摄影首先要求他让对象进入取景框并保存，而不是替对象完成攀登。
- 候选位：`z`，88%。认可端点是马洛里登顶真相与羽生极限攀登能否被历史/公众看见；由于官方简介未证明深町以个人名声为核心，只作“见证被确认”的功能候选。
- 状态位：`xz`，86%。尼泊尔追踪、绑架事件和高海拔攀登造成危险临界；他在终局能承认身体极限并下撤，说明危险状态未改写主`xn`。
- `x`端点：未锁定。旧相机的所有权和流转需原卷确认；在来源未稳前，不以“见到相机”判掌握。

**行为证据**

1. 在尼泊尔接触到一台可能解开马洛里初登顶之谜的旧相机 → 深町没有把它当普通古物，开始核对来源并追查去向 → 作用于相机、历史假说与卖家关系 → 一件物品被转成可逐步验证的调查链。
2. 追相机途中遇到被称为“毒蛇”的日本男子 → 深町继续查证其身份、在尼泊尔停留的理由与相机关系 → 作用于羽生丈二的身份资料 → 一次相遇没有直接等同结论，而进入人物履历重建。
3. 马洛里谜题与羽生线索交织、岸凉子又在追踪中遭绑架 → 深町继续寻找羽生并处理突发事件 → 作用于证人安全、调查路线与相机线索 → 外部危险压缩路径，但没有让调查对象发生偷换。
4. 得知羽生准备挑战冬季无氧单人攀登珠峰西南壁 → 深町以摄影/见证者身份进入登攀计划并携带器材上山 → 作用于羽生行动能否留下可核验记录 → 调查从书面追踪转成现场记录。
5. 高处发现自己已到身体极限 → 深町选择下撤；途中到可见山顶的岩场后，仍通过取景器寻找并拍摄羽生 → 作用于自身安全边界与羽生最后阶段的证据 → 没有用冒死逞强冒充见证，反而保住记录能力。

**行为模式总结**：遇到不确定的物证或人物时，深町会追来源、排证词、重建履历，再进入现场用摄影保存；当身体到限，他会先保住观察位置而不是把自己改写成羽生式攀登者。

**反证与关系机制**

- 他进入珠峰并不等于主`zx`：终局明确承认极限并下撤，主要功能仍是调查、观察与记录。
- 羽生决定挑战路线，深町只获得跟随/拍摄位置；不得把羽生的直接攀登权能记给深町。
- `n生xn`（94%）：相机、证词、履历和取景器中的山体事实为调查提供可排列输入，目标变量是“相机真伪/羽生行动如何被验证”。
- `xn补z`候选（88%）：来源核查与现场摄影补足历史主张和羽生攀登被看见所缺的证据，目标变量是“事件能否进入可确认的公共记录”；深町是否追求个人认可未稳，故只记候选。

### 羽生丈二

**来源与阶段**：集英社文库漫画版第1—5卷官方简介；大岩壁单独攀登时期至珠峰西南壁冬季无氧单独挑战。

**当前状态**：跨卷官方书目轻筛；早年队伍冲突、同伴事故与最终路线细节待原卷页码。

**十元判断**

- 主十元：`zn`，97%。具体内部标准是“攀登本身是自己的存在方式”，即使没有公众、奖励或安全保证，仍把人生压到未登路线；第4卷官方简介明确写其“舍弃一切”挑战。
- 次十元：`zx`，93%。对象端点是大岩壁、冰壁、未登路线与自身攀登能力；他让身体/技术直接进入墙面并扩大可通过范围，但公开名声不是主因。
- 状态位：`xz`，95%。坠落、濒死、冰壁、无氧冬季珠峰与退路缩窄构成高强度危险逼近；这是攀登阶段状态，不自动取代稳定`zn`。
- 功能位：`xn`，91%。对象端点是登攀计划、营地、路线、时机、装备与体能分配；第4卷目录和简介直接出现“登攀计划—基地营—冰瀑—冰壁”的阶段组织。
- `x`端点：未成立。山峰、路线和同行者并不归他所有；征服性语言不能代替实际归属/调配权。

**行为证据**

1. 面对大乔拉斯北壁尚无人完成的冬季单独路线 → 羽生选择挑战人类首次冬季单人攀登 → 作用于墙面与自己的能力边界 → 攀登被作为存在标准直接投入现实，而非为了别人安排。
2. 攀登中从壁上坠落、陷入濒死状态 → 羽生没有等待外部救援完成全部路径，而为生存重新组织动作并继续攀登 → 作用于退路、身体与安全位置 → `xz`危险状态直接激活`zx`求生攀登。
3. 多年后以“毒蛇”身份停留尼泊尔、远离旧社会位置 → 羽生没有退出攀登问题，而把生活收缩到下一次高峰准备 → 作用于身份与可调用生活资源 → 退隐是服务核心攀登，不是纯`nx`随环境漂流。
4. 决定挑战珠峰西南壁冬季无氧单独登顶 → 羽生舍弃其他生活，制定登攀计划、设置基地营并逐段进入冰瀑/冰壁 → 作用于装备、路线、时机与体能 → `xn`把`zn/zx`压进可运行的极限路线。
5. 深町达到极限下撤 → 羽生仍按自己的单独路线向顶峰推进，最终进入只能由远处取景器见证的阶段 → 作用于最后登顶路径与生存边界 → 他不靠深町替自己做决定，主`zn`和次`zx`保持。

**行为模式总结**：只要出现一条能把攀登推到更高极限的路线，羽生就会削减其他生活，把装备、时机和体能组织成计划，再以身体直接进入岩壁；危险越闭合，攀登作为存在标准越高显影。

**反证与关系机制**

- 濒死、孤独、危险与“征服山峰”不能单独证明`zn/zx`；主`zn`来自跨卷反复“即使无观众也把一切押给攀登”，次`zx`来自身体技术直接改变可通过路径。
- `xz生zx`（95%，状态→行为层）：坠落、濒死与退路消失通过压缩可选路径，迫使羽生把攀登能力直接推回现实；目标变量是“能否恢复上升/返回安全位置”，官方第2卷提供直接证据。
- `xn克zx`候选（89%，计划→行为层）：营地、路线、时机、装备与体能分配限制了直接攀登权能何时、在哪一段显现，目标变量是“冲顶速度与可持续路径”；天气与高海拔仍是强第三因素，故只记候选。

**与作品主维**：深町主`xn`负责调查/见证链，羽生主`zn`、次`zx`负责极限攀登链；二人共同让作品出现强因果结构，但不能把两人硬配成作品公式`zx+nx`。现有“因果主、时间次、本体辅”只作作品层背景，人物拆分后不改主维或归仓。
