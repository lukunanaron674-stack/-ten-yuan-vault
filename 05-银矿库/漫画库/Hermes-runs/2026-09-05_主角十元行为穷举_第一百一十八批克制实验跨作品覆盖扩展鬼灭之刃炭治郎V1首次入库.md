## 一、鬼灭之刃·竈门炭治郎 V1 首次入库 (xn 阳金 + zn 阳火 双主位证据)

- **主角身份**: 卖炭少年 → 全家被鬼殺 → 祢豆子变鬼 → 加入鬼殺隊训练 → 剑士 → 最终決戰击败无惨
- **证据范围**: 集英社 ジャンプ 鬼灭之刃 1-23 巻 + 維基百科 (公開範圍窮舉, 非全作逐页)
- **分析状态**: 首次入庫 (鬼灭之刃 炭治郎 此前未做过穷举, 本次为首次入库)

- 行为1: 炭治郎在多次战斗中以日之呼吸 + 全集中呼吸 + 战斗计划组织斩杀鬼, 炭治郎按日之呼吸規則、按鬼的斩杀、按组织的时辰的, 把鬼按时辰组织 → **克制维度**: xn 阳金 → 克 zx 阳木 (炭治郎 xn 战斗组织计划约束 zx 阳木鬼的显权破壞)。→ 作用于鬼的破壞 → 鬼按时辰被炭治郎组织斩杀。
  - 归类: xn (阳金, 主位证据, 95%)。对象端点: 鬼战斗组织流程 (xn 阳金 → 克 zx 阳木 鬼的显权, **第三样本, 跨作品扩展**)。
- 行为2: 炭治郎以日之呼吸的日轮刀直接斩杀鬼的身体, 炭治郎按日轮刀的戰法、按鬼身体的击杀、按戰法的时辰的, 把鬼按时辰击杀 → 作用于鬼的身体 → 击杀按时辰被炭治郎接收。
  - 归类: zx (阳木, 主位证据, 95%)。对象端点: 鬼身体直接顯权击杀 (兼 zx 克 n 阳土 鬼身体载体, **第六样本**)。
- 行为3: 炭治郎在全家被鬼殺后以冷静与意志承担家庭责任 + 加入鬼殺隊训练, 炭治郎按冷静規則、按训练的接受、按接受的时辰的, 把训练按时辰接受 → 作用于鬼殺隊训练 → 接受按时辰被炭治郎接收。
  - 归类: nx (阴金, 主位证据, 92%)。对象端点: 鬼殺隊训练既有通道。
- 行为4: 炭治郎在变鬼的妹妹祢豆子被鬼殺队規則追杀时以冷静与战斗保护祢豆子, 炭治郎按冷静規則、按祢豆子的保护、按保护的时辰的, 把祢豆子按时辰保护 → **克制维度**: zn 阳火 → 克 xn 阳金 (炭治郎 zn 阳火 保存祢豆子独立主体资格 约束鬼殺队規則 xn 阳金 流程)。→ 作用于祢豆子的独立主体资格 → 祢豆子按时辰被炭治郎保护。
  - 归类: zn (阳火, 主位证据, 95%)。对象端点: 祢豆子独立主体资格保存 (zn 克 xn 阳金 鬼殺队流程, **第九样本**)。
- 行为5: 炭治郎在加入鬼殺隊后以単点最高裁定决定保护祢豆子同时斩杀鬼, 炭治郎按単点規則、按祢豆子斩杀的双重目标、按决定的时辰的, 把目標按时辰単点 → 作用于祢豆子斩杀的双重目标 → 単点按时辰被炭治郎単点。
  - 归类: z (阴金, 主位证据, 93%)。对象端点: 祢豆子斩杀双重目標単点最高裁定。
- 行为6: 炭治郎在面对无惨的临界面介入时选择穿透无惨的身体, 炭治郎按穿透規則、按无惨的身体、按穿透的时辰的, 把无惨按时辰穿透 → 作用于无惨的身体 → 穿透按时辰被炭治郎接收。
  - 归类: xz (阳水, 主位证据, 93%)。对象端点: 无惨决战临界面介入。
- 行为7: 炭治郎在最终決戰后以别離收束与无惨的战斗, 炭治郎按别離規則、按无惨的死、按别離的时辰的, 把无惨按时辰别離 → 作用于无惨的関係 → 别離按时辰被炭治郎接收。
  - 归类: nz (阴土, 主位证据, 92%)。对象端点: 无惨関係停靠归宿。
- 行为8: 炭治郎在战斗中以日之呼吸的日轮刀图案 + 火焰呼吸作为身份标志在同伴间识别, 炭治郎按日轮刀的規則、按身份的传承、按识别的时辰的, 把日轮刀按时辰识别 → 作用于日轮刀的身份 → 识别按时辰被炭治郎接收。
  - 归类: x并z (阴木, 主位证据, 91%)。对象端点: 日轮刀的身份公共界面。

**统计**: xn×1 (日之呼吸战斗组织, **主位证据 95%, xn 克 zx 第三样本, 跨鬼灭之刃**) + zx×1 (日轮刀斩杀鬼, **主位证据 95%, zx 克 n 第六样本, 跨鬼灭之刃**) + nx×1 (鬼殺隊训练接受) + zn×1 (保护祢豆子, **主位证据 95%, zn 克 xn 第九样本, 跨鬼灭之刃**) + z×1 (祢豆子斩杀単点) + xz×1 (无惨穿透臨界) + nz×1 (无惨别離) + x并z×1 (日轮刀身份识别)。共 8 条候选进入基础库。本主角主十元候选 `xn 95% + zn 95% + zx 95%` (三主位), 次 `nx 92%`。
