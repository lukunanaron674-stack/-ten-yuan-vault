# 主角十元行为分析 · 高分第一批4部

> [!warning] 历史报告
> 《BLUE GIANT》《灌篮高手》《链锯人》已由[[2026-07-22_主角十元行为穷举_第三十二批3部爵士篮球与电锯复核]]替代；`Vagabond / 浪客行`已由[[2026-07-23_主角十元行为穷举_第三十三批3部剑路迷宫与黑医复核]]替代。本文件只保留旧“行为总结/先判主次”的历史痕迹，不再作当前人物结论。

## 本轮口径

本报告只判断主角的人物层十元和可观察行为，不把作品五大主题直接复制到主角身上。

```text
行为证据格式：
触发条件 → 主角行动 → 作用对象 → 可观察结果
```

现行四元锚点：

```text
x：对象、资源、地盘、权限或关系归我掌握
zx：直接以自己的权能决定方向并做成
xn：主动组织计划、时间、规则、信息和资源
nx：不占方向决定权，沿他人、关系或既有流程给出的方向推进
```

## 1. BLUE GIANT｜宫本大

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-18_本体S级4部新版生克补关系轻筛.md`
- **分析对象**：宫本大；仙台高中后期至东京三重奏阶段
- **当前状态**：主角十元行为轻筛完成，待逐卷定位
- **主十元**：`zn`，置信91%
- **次十元**：`zx`，置信82%
- **辅助端点**：`x`（萨克斯、音色与演奏范围的掌握）80%；`nx`（接受老师和乐队路径）72%
- **补位候选**：`zn 补 x`。爵士意义给演奏掌握确定方向；实际音色/技术又让“爵士是我”能够落地。

### 可观察行为证据

1. **高中毕业与未来不确定** → 宫本大公开立下“成为世界第一爵士乐手”的目标 → 自己的未来方向 → 没有先等升学、职业或他人认可替他决定；这是 `zn` 的内部意义定向。
2. **技术和乐理不足** → 接受由井川老师持续进行的技术/理论训练 → 既有教学路径 → 把抽象目标推进为可重复练习；这是 `nx` 行为，不说明宫本大的稳定本体是 `nx`。
3. **校庆观众偏爱摇滚与流行、爵士独奏不占优势** → 独自拿次中音萨克斯上台演奏 → 敌意或不耐烦的观众 → 直接用演奏能力抢回现场方向；这是高显影 `zx`。
4. **个人演奏不足以进入更大舞台** → 与玉田、雪祈组成三重奏并持续排练/演出 → 乐队关系与共同曲目 → 个人意义获得稳定承载，但他没有因此停在个人独奏。
5. **担任成名乐团暖场、面对冷淡观众和居高临下的前辈** → 与队友把能够演奏的力量全部释放到台上 → 大型现场 → 不通过讨好先求认可，而是先用公开能力改变现场；再次显影 `zx`。

### 主角行为模式总结

```text
内部先认定“爵士就是我要成为的人”
→ 接受能提高能力的既有训练路径
→ 把练习所得直接投到不利舞台
→ 用一次次公开演奏扩大自己能掌握的声音范围
```

### 反证与边界

- 他会接受老师训练、进入乐队、依赖共同演出，因此不是“只凭自己压过去”的纯 `zx`。
- 他面对观众会显影认可关系，但即使没有先获得认可仍继续演奏，`z` 不足以升为主十元。
- “世界第一”是一句目标，单独不能证明 `zn`；真正证据是目标在训练、敌意舞台和团队阶段持续组织选择。

### 与作品主维的关系

作品当前为本体型 `zn+x` 主导航，和宫本大的 `zn` 主十元高度一致；但作品层 `n/xn` 乐队结构不能自动算作宫本大的稳定本体。人物的次十元更接近公开显权的 `zx`，而不是作品次维“时间”。

### 下一步

逐卷补“初次接触爵士、井川训练、校庆独奏、三重奏成立、暖场演出”页码；写入[[漫画主角十元行为分析索引]]。

## 2. 灌篮高手｜樱木花道

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-18_本体S级4部新版生克补关系轻筛.md`
- **分析对象**：樱木花道；入队前期至山王战
- **当前状态**：主角阶段迁移轻筛完成，待关键话数定位
- **前期主十元**：`z`，置信90%
- **后期主十元候选**：`zn`，置信84%
- **贯穿次十元**：`zx`，置信86%
- **功能行为**：`nx` 78%（服从安西教练与球队训练结构）；`x` 76%（篮板、防守、投篮等实际责任范围）
- **补位候选**：`zx ↔ nx`。樱木先沿教练/球队给出的训练和比赛权限前进，再在上场时用身体与技术直接做成。

### 可观察行为证据

1. **连续被女生拒绝、遇到不怕他的晴子** → 因晴子介绍而进入篮球 → 晴子的认可位置 → 篮球最初被当成“让她看见我”的通道；前期是明确 `z`。
2. **与闹事者正面冲突** → 拒绝退让并直接参与冲突 → 对手与现场方向 → 用身体力量当场解决；这是 `zx` 功能，但不能单凭打架判定人物永久主十元。
3. **新人对抗赛暴露技术弱点、正式比赛临近** → 接受安西教练安排的每日500次投篮训练 → 教练给出的训练流程 → 在既有路径内反复积累基本技术；这是 `nx`，不是他主动设计训练系统的 `xn`。
4. **湘北争夺全国赛资格、队友体力和防线告急** → 主动承担防守与篮板任务 → 禁区、对手进攻和球队存续 → 从“我要出风头”转向“这个区域由我负责”；`zx` 开始落入具体 `x` 边界。
5. **山王战被换下、球队被压制** → 接受安西在场边的再部署，重新进入球队进攻 → 教练战术与自己的身体能力 → 先沿球队结构取得位置，再直接冲击对手，显出 `nx ↔ zx`。
6. **经历长期训练和终局比赛** → 明确表达对篮球本身的热爱 → 篮球意义而非单一外部认可 → `zn` 在后期上升，解释他为何愿意承担代价继续比赛。

### 主角行为模式总结

```text
先为得到某个人的认可进入篮球
→ 用直接身体能力抢占位置
→ 在失败后接受球队训练结构
→ 把力量收束为篮板、防守和投篮责任
→ 最终把外部认可内化为“我真的爱篮球”
```

### 反证与边界

- 前期主要为晴子行动，不能把全篇一开始就写成稳定 `zn`。
- 每日500球由教练安排，证明的是 `nx` 功能，不是樱木主动组织长期系统的 `xn`。
- 后期 `zn` 是否已经替代 `z` 成为稳定本体，需要“受伤后仍选择篮球”的后续阶段证据；本轮只判上升候选。

### 与作品主维的关系

作品本体型主导航更接近樱木从 `z` 向 `zn+x` 移动的完整弧线，不等于樱木开篇就是本体型人物。作品时间/空间结构主要来自球队、训练和比赛，并非樱木个人稳定十元。

### 下一步

定位第1卷入队、第16卷500球、第21卷防守、第26—31卷山王战；复核 `z → zn` 是否完成稳定迁移。

## 3. 链锯人｜电次

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-18_本体S级第二批4部新版生克补关系轻筛.md`
- **分析对象**：电次；公安篇为主
- **当前状态**：主角十元行为轻筛完成，待公安篇章节复核
- **主十元**：`nx`，置信91%
- **次十元**：`zx`，置信86%
- **辅助十元**：`nz` 79%（波奇塔、早川秋、帕瓦形成的情感停靠）；`x` 是逐渐争取的结果端点，不先判稳定主十元
- **核心补位**：`zx ↔ nx`。电次通常通过债务、契约、组织或朋友获得路径和权限，再以电锯身体直接完成战斗。
- **生位候选**：`nx 生 x`。波奇塔关系与组织路径使电次获得恶魔心脏、战斗身体和生活资源的实际掌握范围。

### 可观察行为证据

1. **继承债务、没有独立资源** → 与波奇塔一起猎杀恶魔偿债 → 债主规定的生存路径 → 电次沿外部债务结构推进，而不是自己决定人生方向；这是 `nx`。
2. **遭背叛并被杀** → 接受与波奇塔的契约并复活 → 波奇塔提供的关系/能力通道 → 获得恶魔心脏和电锯身体的具体掌握，构成 `nx 生 x` 候选。
3. **组织或他人提出奖赏/目标** → 按奖赏路径迎战蝙蝠恶魔 → 被指定的敌人与任务 → 进入战斗后直接用身体做成，表现为 `nx → zx`，不能把奖赏欲望直接判为 `x`。
4. **武士刀敌人正面夺取其心脏** → 以电锯形态正面对抗 → 敌人与自己的身体能力 → 直接扩大权能、解决当前威胁，显影 `zx`。
5. **真纪真试图完全控制其身份与生活** → 先在控制结构中失去方向，后借助剩余朋友的帮助准备最终对抗 → 朋友关系和既有能力 → 通过关系借力重新启动直接行动，形成 `nx ↔ zx`。

### 主角行为模式总结

```text
先接受别人、债务、契约或关系给出的路线
→ 从路线中取得生存资源、权限或目标
→ 一旦目标明确，就用电锯身体直接解决
→ 受控制后再借朋友关系找回行动入口
```

### 反证与边界

- `nx` 不是“软弱”或“没有行动力”；电次进入执行阶段时 `zx` 极高。
- 最终对抗真纪真显示他能够计划、拒绝和反制控制，因此不能把 `nx` 写成永恒被动状态。
- 作品中的强 `x` 主题大量属于真纪真、公安和“谁掌握电次”的关系层；不能反向判电次本人主十元就是 `x`。

### 与作品主维的关系

作品当前本体型 `zn+x` 主导航和电次主十元并不相同。作品问的是“谁掌握电次、什么生活才属于电次”；人物行为却长期以 `nx` 进入他人提供的路线，再用 `zx` 执行。电次争取 `x` 是人物弧线结果，不是起手本体。

### 下一步

按第1、2、5、9—11卷补证；重点验证“服从组织”是否始终出于 `nx`，还是后段已经稳定转成主动 `xn/x`。

## 4. Vagabond / 浪客行｜宫本武藏

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、[[同名冲突复审队列]]、`2026-07-18_本体S级4部新版生克补关系轻筛.md`
- **分析对象**：新免武藏/宫本武藏；关原战后至吉冈一门后
- **当前状态**：主角阶段迁移轻筛完成；Vagabond/浪客行别名评分继续隔离
- **前中期主十元**：`zx`，置信92%
- **次十元**：`xz`，置信88%
- **后段上升十元**：`zn`，置信85%
- **反向停靠**：`nz` 候选72%（阿通关系与“在人间生活”的可能）
- **可用关系**：
  - `xz 生 zx`：逃亡、追杀与强敌压力不断提供直接战斗启动条件。
  - `xz 克 zn`：漂泊与杀伐压缩旧“天下无双”意义的稳定性。
  - `zx 生 zn`：反复杀敌后的实际结果迫使武藏生成新的“何为强、为何活”问题。

### 可观察行为证据

1. **关原战败、成为被追捕的逃亡者** → 以野兽式警觉和暴力求生 → 追捕者与生存通道 → 外部 `xz` 压力不断生出直接 `zx` 行动。
2. **听闻宝藏院枪术强者** → 主动前往奈良挑战武僧 → 对手与剑道路向 → 不借组织或关系绕路，直接以胜负决定方向；高显影 `zx`。
3. **迎战胤舜前出现对阿通的情感牵引** → 注意和行动被关系牵动 → 阿通与当前决斗 → `nz` 提供了“离开纯杀伐”的停靠可能，是纯 `zx/xz` 的反证。
4. **追求柳生石舟斋这一“天下最强”标准** → 潜入并考虑杀死年迈、沉睡的剑豪 → 石舟斋及自己的道路正当性 → 行动临界处开始追问“杀掉他是否真的让我前进”，`zx` 开始生出 `zn`。
5. **面对吉冈一门围杀** → 单人击败七十名对手 → 吉冈战斗集团 → 直接权能达到峰值，同时把杀伐后果推到无法回避。
6. **毁灭吉冈一门之后** → 开始质疑“无敌/天下无双”和自身存在理由 → 旧意义定义 → 胜利没有稳定旧 `zn`，反而迫使人物重建意义；这是 `zx 生 zn` 的关键阶段候选。

### 主角行为模式总结

```text
外部漂泊与强敌压力出现
→ 武藏主动寻找最强者并正面切开阻碍
→ 胜利把直接权能推到峰值
→ 杀伐结果反过来摧毁“赢就是强”的旧答案
→ 开始追问力量应当为何存在
```

### 反证与边界

- 阿通关系和后段“回到人群”的可能说明武藏不是永恒的孤绝 `xz/zx`。
- “挑战强者”是 `zx` 行为；“天下无双”只是意义标签，不能直接当 `zn` 已稳定。
- 后段 `zn` 上升不等于人物本体已经彻底换元；仍需农耕/村落阶段的连续主动选择来证明。

### 与作品主维的关系

作品本体型主导航表达的是武藏最终被迫重写“何为强”的全过程；主角起手和前中期实际更接近 `zx+xz`。因此作品主维对应人物变化的终点问题，而不是人物开篇稳定十元。

### 下一步

按VIZBIG第1、2、4、11、12册补页码，并继续抽查农耕阶段是否让 `zn/n` 从状态上升为稳定人物重构。别名与98/96评分继续隔离。
