## 1. MONSTER｜天马贤三

### 1.1 对象与阶段

- 主角：天马贤三，外科医生。
- 阶段：杜塞尔多夫医院的选择至鲁恩海姆终局。
- 来源文件：[[04-因果型 zx+nx]]、[[漫画库总索引]]、[[2026-07-08_漫画分析_Monster]]、角色旧卡`角色库/详细卡/怪物.md`。
- 当前状态：作品96分、因果主/本体次/时间辅；人物层旧口径已降权，新版主角轻筛完成。

### 1.2 十元判断

| 层级 | 十元 | 置信度 | 具体对象端点 |
|---|---|---:|---|
| 主十元 | `zn` | 95% | “生命不能按权势排序”的医生信念；即使外部身份、赞誉和安全都被拿走，仍以此决定是否救人 |
| 次十元 | `n` | 92% | 落到面前的儿童、伤者、受害者与再次成为病人的Johan；天马把人接进“由我处理的患者位置” |
| 功能位 | `xn` | 88% | Nina、Johan过去、连续命案、证人和行程线索；按调查次序组织信息并持续追踪 |
| 状态位 | `xz` | 90% | 通缉、警察包围、枪与杀人风险；危险长期贴在身体和行动边缘，但不等于人物稳定本体 |

补位/克位：

- **正式启动：`zn生n`。** 源端点是“生命平等”的内在医者信念，目标端点是眼前具体病人；它改变的是“谁值得被接诊”的范围，使政治地位、罪行身份不能先取消患者资格。
- `xz克zn`仅为压力候选，未成功改写天马的信念，因此不能写成已经完成的克制。

### 1.3 行为证据

1. **医院要求优先服务权势者** → 天马停止追逐职业成功，按医生誓言救治先到的儿童Johan → 作用于医院排序与Johan的生命 → 儿童获救，天马失去原有晋升与婚姻利益。  
   - 对应：`zn→n`。
   - 定位：Perfect Edition第1卷；库内旧报告开篇事件。

2. **连环杀人显示自己救下的孩子可能成为凶手** → 天马没有把最初救人行为改写成“错误”，而是离开安稳职业路线寻找Nina与Johan真相 → 作用于Nina、Johan身份和命案线索 → 医者信念转化为长期调查责任。  
   - 对应：`zn + xn`。
   - 定位：Perfect Edition第1卷。

3. **Johan设局使天马成为连环杀人嫌犯** → 天马躲避警方追捕，同时继续追踪Johan → 作用于警方封锁、Johan行踪和潜在受害者 → 保住行动自由，并尝试阻止下一起杀人。  
   - 对应：`xz`状态下调用`xn`。
   - 定位：Perfect Edition第2卷。

4. **Nina被新纳粹势力控制** → 天马把寻找Nina置入追查顺序，沿线索进入极右组织阴谋 → 作用于Nina及把Johan塑造成政治符号的计划 → 救援目标与案件调查合流。  
   - 对应：`n + xn`。
   - 定位：Perfect Edition第2卷。

5. **需要判断Johan是否存在人格问题** → 天马主动求助犯罪心理专家Gillen，把Johan作为待分析对象交给专业判断 → 作用于Johan心理画像与连续案件解释 → 即使遭Gillen怀疑和设陷阱，调查仍获得新的验证路径。  
   - 对应：`xn`；不是把“求助”自动写成`nx`本体。
   - 定位：Perfect Edition第3卷。

6. **终局中Johan再次以伤者/病人形态落到他面前** → 天马再次执行救治，而不是用医生权限完成处决 → 作用于Johan身体与天马自己的医者边界 → 开篇的生命原则经最强反例后仍未失效。  
   - 对应：`zn→n`的回环验证。
   - 定位：结局卷；库内旧报告已有事件摘要，仍需Perfect Edition第9卷原页复核手术前后动作。

### 1.4 行为模式、反证与作品主维

**行为模式总结**：生命排序受到权力、犯罪或复仇挑战时，天马先用内在医者信念确定“仍是一个人”，再把具体生命接入诊疗/保护范围；当危险扩大时，他组织线索追到源头，却不允许追捕把自己改造成处决者。

反证：

- 他学习用枪、持续追踪并把自己置于危险中，说明人物并非只有被动承载；`xn/xz`体量很高。
- 他对Johan产生杀意和处决准备，说明`zn`不是没有摇动；主位成立的关键是最终动作仍未把“杀死患者”常态化。
- “追寻Johan”本身不能证明`nx`；若路线是天马主动组织，现行口径应优先记`xn`。

与作品主维：

- **不一致但互相解释。** 作品的因果型`zx+nx`描述选择、组织和后果如何跨人物锁死；天马本人主位则是`zn+n`。
- 作品因果链不断制造反例，人物医者信念负责回答反例；不能因为作品是因果型就把天马写成`zx+nx`。

复核与写入：

- 待复核：Perfect Edition第1、2、3、9卷，重点核对开篇手术排序、持枪却不射击、终局再手术。
- 建议写入：[[漫画主角十元行为分析索引]]、[[04-因果型 zx+nx]]人物层备注；旧角色卡与旧Hermes报告保留但标记`legacy-relation-superseded`。

书目核验：[VIZ第1卷](https://www.viz.com/manga-books/manga/monster-volume-1/product/3451)、[VIZ第2卷](https://www.viz.com/manga-books/manga/monster-volume-2/product/3456)、[VIZ第3卷](https://www.viz.com/manga-books/manga/monster-volume-3-0/product/4388)。

## 2. BILLY BAT｜Kevin Yamagata

### 2.1 对象与阶段

- 主角：Kevin Yamagata，1949年出场的日裔美国漫画家。
- 阶段：得知蝙蝠形象可能早已存在，赴日至JFK事件失败后再赴日及晚年追索。
- 来源文件：[[04-因果型 zx+nx]]、[[漫画库总索引]]。
- 范围排除：勘兵卫、Oswald、杂风、Kevin Goodman与Timmy的独立行动不算给Kevin Yamagata。
- 当前状态：作品无正式评分、因果型推定/时间次维；人物层出版社跨卷书目轻筛完成。

### 2.2 十元判断

| 层级 | 十元 | 置信度 | 具体对象端点 |
|---|---|---:|---|
| 主十元 | `nx` | 93% | “有人见过同一角色”、Billy的预言/指令、蝙蝠卷轴与时之卷指向；方向多由外部讯息或超常接口给出 |
| 次十元 | `xn` | 90% | 赴日核验、暗杀阻止方案、再赴日路线、历史线索的查证次序；把外部方向转成持续任务 |
| 行动位 | `zx` | 83% | 以自身生命介入JFK节点、尝试改变历史；属于节点执行，不足以覆盖全程 |

补位/克位：

- `nx`与`xn`在现行表中不是固定生补克关系，本轮只记为“方向来源—执行组织”两层共存。
- `nx生x`虽有几何位置，但现行表明确要求重新验收；本作不借“预言积累成欲望”套用旧解释。

### 2.3 行为证据

1. **有人指出Billy形象可能早在日本出现** → Kevin中断美国成功漫画家的既定生活，赴战后日本核验真伪 → 作用于角色来源、原作者与自身创作资格 → 一个外部指认被转成跨国调查任务。  
   - 对应：`nx`给方向，`xn`组织核验。
   - 定位：第1卷。

2. **Billy让Kevin预知JFK将遭暗杀，并给出改变历史的方法** → Kevin接受该问题并按提示寻找介入点 → 作用于预言、暗杀节点与可改变条件 → 漫画家身份转为历史干预者。  
   - 对应：`nx + xn`。
   - 定位：第5卷。

3. **得知阻止暗杀也可能提前引发更大人类悲剧** → Kevin没有简单退出，而是继续尝试处理两种后果互相冲突的方案 → 作用于JFK生死、登月时间与人类存续 → 外部预言被转成需要权衡的执行结构。  
   - 对应：`xn`，并构成人物非纯服从的反证。
   - 定位：第6卷。

4. **预言把Kevin自己的生命纳入暗杀节点** → Kevin仍进入可能以自身牺牲换取总统存活的位置 → 作用于自身身体、JFK与历史分叉 → 直接行动体量升高，但路线仍来自Billy预言。  
   - 对应：`zx`节点行动服从于`nx`方向。
   - 定位：第7卷；具体进入/退出方案待原卷复核。

5. **暗杀阻止失败，Kevin陷入失意并收到Billy再赴日指令** → 他再次前往东京奥运时期的日本追查蝙蝠卷轴 → 作用于Billy秘密、卷轴位置与历史控制机制 → 失败没有终止路线，外部指令再次启动调查。  
   - 对应：`nx→xn`的可观察前后链，但不是生补克表中的正式“生”。
   - 定位：第8卷。

6. **晚年看不见也听不见Billy，仍需要解释历史谜题** → Kevin沿“时之卷”所示前往巴斯克 → 作用于卷轴所指地点与长期谜题 → 即使原指令者消失，他仍沿遗留接口继续行程。  
   - 对应：`nx`稳定性强证据；`xn`负责实际行程。
   - 定位：第18卷。

### 2.4 行为模式、反证与作品主维

**行为模式总结**：异常信息、预言或卷轴先给Kevin方向；他随即把方向改写成核验、阻止和旅行任务，在关键历史节点用自身行动承担结果，失败后仍沿遗留线索继续。

反证：

- 第1卷“主动赴日核验”和第6卷“面对两种灾难重新权衡”显示`xn`非常接近主位；Kevin不是无条件照单全收。
- 第7卷以生命介入的行动有`zx`强度，但它是关键节点，不足以说明他全程都在公开显权并凌驾他人。
- 漫画家身份与Billy图像可能有`x并z`接口价值，但现有出版社简介不足以证明“身份壳—主体”稳定分层，本轮不硬判。

与作品主维：

- **部分一致。** 人物主`nx`是作品因果型`zx+nx`的一端，但Kevin的次位是`xn`而非自动补成`zx`。
- 作品跨时代因果网由多人、卷轴和历史事件共同成立；Kevin只是一条人物接口，不能用其点位证明全作推定。

复核与写入：

- 待复核：第5—8、18卷；尤其核对第7卷Kevin对牺牲方案的主动程度。
- 建议写入：[[漫画主角十元行为分析索引]]、[[04-因果型 zx+nx]]无评分推定行；不新建正式评分或机器归仓任务。

书目核验：[讲谈社第1卷](https://www.kodansha.co.jp/comic/products/0000013938)、[第5卷](https://www.kodansha.co.jp/comic/products/0000014080)、[第6卷](https://www.kodansha.co.jp/comic/products/0000017902)、[第7卷](https://www.kodansha.co.jp/comic/products/0000018243)、[第8卷](https://www.kodansha.co.jp/comic/products/0000018284)、[第18卷](https://www.kodansha.co.jp/comic/products/0000018748)。

## 3. 炎拳｜Agni

### 3.1 对象与阶段

- 主角：Agni，拥有再生能力、被不灭火焰持续焚烧的人。
- 阶段：村落毁灭至前往Judah的终局阶段。
- 来源文件：[[漫画库总索引]]及旧精选来源记录。
- 当前状态：库内旧条称“精选本体型96分/F12误判”，但现行五大主题正式页与机器任务缺少稳定主条；本轮只做人层分析，不补造评分与归仓。

### 3.2 十元判断

| 层级 | 十元 | 置信度 | 具体对象端点 |
|---|---|---:|---|
| 主十元 | `nz` | 90% | Luna的关系与遗言、Tena的承诺、被他当作Luna的Judah；行动反复寻找一个不让关系彻底结束的停靠点 |
| 次十元 | `nx` | 86% | Luna“活下去”的方向、Togata的电影剧本、追随者的救世主角色、Tena承诺；Agni多次沿别人给出的角色继续 |
| 状态位 | `xz` | 96% | 永不熄灭的火焰、持续再生与疼痛、对周围人的燃烧风险；危险直接贴在身体上 |
| 行动位 | `zx` | 88% | 复仇、战斗、寻找苦难源头、焚烧通往Judah的路径；直接以身体权能推进 |

补位/克位：

- **候选启动：`nz生nx`。** Luna/Tena/Judah关系先提供“继续活、守住承诺或回到她身边”的位置，Agni因而暂时不必自建终极方向，沿该关系给出的角色推进。
- 第三因素是Togata和追随者对“Fire Punch/救世主”的包装；不能把所有`nx`都归因于`nz`。
- `xz↔nz`只是几何补位候选：火焰危险与关系停靠确实形成张力，但尚缺“拿掉关系后危险状态具体改变什么变量”的原卷验证。

### 3.3 行为证据

1. **村落被毁、Luna死亡而Agni因再生留在火中** → 他承受燃烧并发誓向Doma复仇 → 作用于自己的火焰身体、Luna关系与Doma → 关系丧失被转成持续活着和直接追击的方向。  
   - 对应：`nz + xz + zx`。
   - 定位：第1卷。

2. **与Doma冲突后Agni被斩首，Togata出现** → Agni被带入Togata的拍摄与“主角”安排 → 作用于Agni身份、镜头和复仇路线 → 私人痛苦开始被外部剧本重新编排。  
   - 对应：`nx`状态/行为候选。
   - 定位：第2卷；Agni主动同意到何种程度待原卷复核。

3. **Togata改变原定电影脚本并让他面对新的强敌** → Agni继续直接战斗，并在冲突后获得新的行动决意 → 作用于敌对Blessed、电影高潮与自身路线 → 他没有完全被剧本固定，`zx`在节点上抢回执行。  
   - 对应：`zx`，也是反对“纯nx”的证据。
   - 定位：第3卷。

4. **Togata的秘密暴露使既有关系和电影框架动摇** → Agni没有停留在角色震荡中，而是转去寻找造成自己苦难根源的人 → 作用于Togata关系、Doma/苦难源头与复仇叙事 → 外部脚本失效后，他用直接寻找维持行动。  
   - 对应：`nz`受扰后调用`zx`。
   - 定位：第5卷。

5. **与Tena的承诺把他放入虚假而平静的生活** → Agni沿承诺维持表面日常，同时不断寻找逃离这一身份地狱的方法 → 作用于Tena关系、假身份与自身存在位置 → 得到暂时停靠，却没有消除内在撕裂。  
   - 对应：`nz生nx`候选，伴随`x并z`身份接口压力但不判为稳定点位。
   - 定位：第7卷。

6. **身体再次燃烧且Judah成为明确关系终点** → Agni一路焚烧阻挡者前往Judah → 作用于Judah、沿途人群与冻结世界 → 关系端点把`xz`身体状态转成高破坏性的`zx`行动。  
   - 对应：`nz`定向，`xz→zx`为事件链；是否构成正式“xz生zx”仍待拿掉测试。
   - 定位：第8卷。

### 3.4 行为模式、反证与作品主维

**行为模式总结**：每当关系被夺走或身份脚本崩塌，Agni就抓住Luna、Tena或Judah提供的下一处停靠；他常沿遗言、承诺和他人剧本活下去，而贴身燃烧的危险身体会把这条关系路线放大成复仇、战斗和毁灭。

反证：

- 第1卷自行立下复仇目标、第3卷在剧本变化后重新决意、第8卷直接焚烧推进，都表明`zx`并非弱位。
- Agni会反抗Togata剧本和追随者投射，因此`nx`不能解释全部阶段。
- 永恒火焰是最显眼的`xz`证据，但“最显眼”不等于“最稳定的方向决定机制”；它更像身体状态。

与作品主维：

- **暂不对齐。** 库内“本体型96分”来自旧精选证据，而现行正式主条缺失；人物主`nz`、次`nx`只说明Agni如何继续行动。
- 作品对身份、电影、救世主与记忆的本体问题，不能直接替代人物的关系停靠机制。

复核与写入：

- 待复核：第2—3、5、7—8卷，重点判断Togata剧本、Tena承诺与Judah/Luna替代关系中Agni的主动程度。
- 建议写入：[[漫画主角十元行为分析索引]]、[[漫画库总索引]]旧比较行的人物层备注；保持“源范围/正式主条待回查”，不新建正式评分任务。

## 4. 蓝色时期｜矢口八虎

### 4.1 对象与阶段

- 主角：矢口八虎，高中生、艺考生。
- 阶段：第一次被绘画击中至东京艺术大学二次考试。
- 来源文件：[[03-空间型 x并z+n]]创作封闭空间候选。
- 当前状态：作品无正式评分、仅列“画室”空间候选；人物层出版社第1—6卷书目轻筛完成。

### 4.2 十元判断

| 层级 | 十元 | 置信度 | 具体对象端点 |
|---|---|---:|---|
| 主十元 | `xn` | 94% | 艺考期限、练习时数、画材、技法、老师反馈、同伴比较、一次/二次考试；持续组织成可执行训练结构 |
| 次十元 | `z` | 89% | 美术老师、同伴与艺大评审构成的认可端；作品需要被看见、回应和判定 |
| 上升位 | `zn` | 85% | “我实际看见什么、想画什么”的内部意义；从技术达标逐步转向不靠标准答案的自我表达 |

补位/克位：

- **候选启动：`xn补z`。** 训练计划、材料试验和考试流程为“被老师/评审看见”提供可见作品；被改变的变量是认可端能否判断八虎的能力，而不是把勤奋直接等同认可。
- `zn克xn`只在“结构化努力反而遮住个人视角”时成为候选；第3—5卷出现压力，但尚不能断言内部意义已稳定克制训练结构。

### 4.3 行为证据

1. **成绩、朋友和日常都运转正常却感到生活乏味** → 八虎看见一幅画后主动进入美术活动并开始作画 → 作用于自己的时间分配、画材和感受表达 → 原本封闭的优等生路线被改成艺术学习目标。  
   - 对应：`zn`触发，`xn`开始组织。
   - 定位：第1卷。

2. **决定挑战竞争极高的艺大** → 他扩大观察训练，在同伴和老师帮助下持续准备第一次比赛/选拔 → 作用于眼力、技法、练习时间与竞争标准 → 抽象愿望被拆成长期学习结构。  
   - 对应：`xn`主证据，`z`提供目标端。
   - 定位：第2卷。

3. **第一次竞赛结果出来、距离考试约100天** → 八虎继续接受大叶老师的新挑战，并重新检查只靠动力、技术和努力的局限 → 作用于倒计时、反馈与作品结构 → 训练没有停，但评价标准从“做得多”转向“画面说了什么”。  
   - 对应：`xn`运行，`zn`开始上升。
   - 定位：第3卷。

4. **考试前一周仍缺少决定性表达** → 他更换材料、扩展表现范围并处理自我怀疑 → 作用于媒材选择、画面语言和剩余时间 → 用结构化试验寻找不能只靠程序复制的个人视角。  
   - 对应：`xn + zn`。
   - 定位：第4卷。

5. **通过第一次考试后必须立刻面对二次考试，工作室训练出现瓶颈** → 八虎走出画室，与朋友一起画裸体自画像 → 作用于自己的身体、相互观看与作品主题 → 把被遮蔽的自我变成可观察的画面对象。  
   - 对应：`zn`进入作品，`z`获得更真实的可见对象。
   - 定位：第5卷。

6. **二次考试前遭遇挫折与压力** → 他仍进入考试并围绕“既陌生又熟悉”的题目继续创作 → 作用于考试主题、身体状态和最终作品 → 长期组织能力在临界场景中维持行动，而非只靠一时冲动。  
   - 对应：`xn`稳定性强证据。
   - 定位：第6卷。

### 4.4 行为模式、反证与作品主维

**行为模式总结**：当某个感受需要变成画面时，八虎会把期限、材料、反馈和练习拆成可持续结构；结构把作品送到老师、同伴和评审面前，而反复受挫又逼他从“符合标准”转向“画出自己真正看见的东西”。

反证：

- 第1卷投入艺术不是由现成流程推动，而是内部感受先改变方向，说明`zn`可能在后期进一步上升。
- 第5卷走出画室、画裸体自画像，是对既有训练空间的主动突破；`xn`不是僵硬守规。
- 艺大合格与评审认可体量很高，但八虎也会在无人保证结果时继续画，因此`z`暂不升为主位。

与作品主维：

- **不一致。** 库内目前只有“画室=创作封闭空间”的空间型候选；这描述作品场景容器，不是八虎的稳定人物机制。
- 八虎人物主`xn`更接近时间组织；画室是否足以让整部作品归空间型，仍须独立作品层复审。

复核与写入：

- 待复核：第1—6卷具体章页，重点核对首次作画、100天倒计时、裸体自画像和二次考试。
- 建议写入：[[漫画主角十元行为分析索引]]、[[03-空间型 x并z+n]]候选备注；不新建评分或正式归仓。
