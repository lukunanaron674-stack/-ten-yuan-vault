## 1. 晚安Punpun / Goodnight Punpun

### 分析对象

- **主角**：小野寺雄雄 / Punpun（早期姓Punyama，后随家庭状态变化）
- **身份**：从小学到成年的普通青年
- **阶段**：童年家庭破裂 → 高中回避 → 独居停滞 → 给人生设期限 → 与爱子重逢
- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-18_本体S级第二批4部新版生克补关系轻筛.md`
- **当前状态**：跨卷官方简介轻筛完成；95/91分别保留，别名簇继续 ready-to-merge 待二审

### 主次十元

- **主十元**：`z`，置信90%
  - Punpun反复把“我是不是值得存在、能不能成为某个人”交给爱子的喜欢、想象中的神回应和关系结果确认。
- **次十元**：`nx`，置信87%
  - 家庭、学校、经济处境和爱子关系不断给出方向；Punpun多次沿外部路线继续，而不是稳定建立自己的运行方式。
- **高压状态十元**：`xz`，置信85%
  - 家庭破裂、独居停滞、爱子线的威胁与“无路可走”把他推入持续临界。
- **后段功能十元**：`x`，置信82%
  - 他把“与爱子在一起”压缩成排他的两人生活与唯一出口；具体占有/控制行为仍需第6卷原章验证。
- **补位/克位提示**：
  - `z`的补位是`xn`；本作确有“给租约设期限”的一次性组织行为，但尚不足以证明稳定补位。
  - `z`被`x`克。后段若把爱子从认可主体改造成“必须归入两人世界的对象”，才可判`x克z`启动；当前为中置信候选。

### 对象端点

| 十元 | 具体对象端点 |
|---|---|
| `z` | 爱子是否喜欢/选择他、想象中的神是否回应、自己是否成为“某个人” |
| `nx` | 父母婚姻与监护安排、学校升学路线、兼职与租约、爱子提出的关系方向 |
| `xz` | 家庭解体、孤立独居、关系威胁、共同犯下“可怕之事”后的无退路状态 |
| `x` | 与爱子的排他关系、两人共同生活及“只有这条出口”的控制边界 |

### 可观察行为证据

1. **童年还没有稳定身份答案** → Punpun设想拿诺贝尔奖、拯救世界，并希望爱子喜欢自己 → 想象中的公众位置与爱子的认可 → 把“我是谁”首先交给被看见、被喜欢来确认。`z`
2. **父母关系破裂、父亲入狱、母亲住院** → 他尝试向“神”诉说问题 → 想象中的回应主体 → 外部回答没有真正接住他，认可位置持续空缺。`z未满足 + nx`
3. **进入城里最好的高中却不愿面对生活** → 他用学习占满注意力 → 学校既有路线与自己的时间 → 行为表面像`xn`，但目的不是建立人生结构，而是沿既有轨道回避自我决定。`xn行为 / nx本体`
4. **母亲去世、父亲失能、开始独居** → 他做低质量兼职维持生活，其余时间大多躺在房间地板上 → 租约、生计和房间生活 → 只维持外部要求的最低运行，没有主动重组方向。`nx + xz状态`
5. **独居生活长期没有改善** → 他给自己设定严格期限：租约到期前必须和爱子在一起、让生活变好并成为“某个人” → 租约时间、爱子关系和身份答案 → 用一次性期限把外部认可压成最后出口；期限最终到期。`xn功能 + z`
6. **终于与爱子重逢，却发现彼此都不如记忆中的理想** → 两人仍把共同关系当作逃离庸常生活的路线，并在“做了可怕之事”后进入无路可走 → 爱子关系与共同退路 → `z`的认可需求开始向排他`x`和临界`xz`偏移；具体行为待第6卷复核。`z → x/xz候选`

### 主角行为模式总结

> **当自我价值动摇时，Punpun会把“我能否成为某个人”交给爱子或想象中的回应者确认；得不到回应时便退回学校、兼职和房间的既有轨道，后期又用期限与排他关系把唯一出口压到爱子身上。**

### 反证与误判防线

- 有愿望、恋爱和执念不自动等于`z`；本轮判`z`是因为认可主体明确为爱子、神和想象中的公众位置，认可内容明确为“值得被爱/成为某个人”。
- 学习、兼职和设租约期限是行为层，不足以把Punpun判成稳定`xn`；这些结构多用于回避或一次性逼迫自己，不能持续运行。
- 家庭不幸和抑郁气氛不自动等于`xz`；只有威胁显形、退路变窄和“无路可走”阶段才进入`xz`。
- 第6卷简介只确认重逢、幻灭、可怕事件与无退路，不能单凭书目把具体暴力和占有细节写成已实读事实。

### 生补克机制

- **`z 克 nx`（中候选）**：爱子的认可位置曾短暂给Punpun一个离开纯粹随流、主动接近关系目标的方向；但它没有形成可持续结构，不能写成长期完成。
- **`x 克 z`（中候选）**：当“与爱子在一起”从互相确认变成唯一、排他的生活边界时，爱子作为独立认可主体的空间被压缩；需第6卷关键章节验证控制行为与结果变量。
- 作品级旧结论`xz克zn`不自动继承给人物稳定本体：本轮没有把Punpun强判为稳定`zn`，因此只保留为作品关系背景。

### 与作品主维关系

作品现存导航仍是本体型`zn+x`主、命运型次。Punpun人物层却更接近`z+nx`：他不是从内部意义出发，而是把存在答案交给爱子和外部路线。后段`x/xz`行为为作品的本体—命运问题提供材料，但**人物主十元不等于作品主维**。

### 复核与写入

- **复核**：VIZ第1卷童年愿望/神回应；第3卷高中学习；第4卷独居；第5卷租约期限；第6卷爱子重逢与共同逃离。
- **建议写入**：[[漫画主角十元行为分析索引]]；[[同名冲突复审队列]]仅补“人物分析同主条计一次”，不合并95/91分。

## 2. ODD TAXI / オッドタクシー

### 分析对象

- **主角**：小户川宏 / 小戸川（Odokawa）
- **身份**：41岁个人出租车司机
- **阶段**：日常载客 → 被失踪案和地下势力卷入 → 执行收束计划
- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-17_本体A组4部十元关系轻筛.md`
- **当前状态**：正式漫画媒介确认；主角同源剧情轻筛完成；关键行动待漫画第3—5卷定位

### 主次十元

- **主十元**：`n`，置信86%
  - 异常乘客、对话和事件不断落进他的出租车与生活；他先承接、不立即甩开，再决定怎样处理。
- **次十元**：`xn`，置信84%
  - 到收束阶段，他把乘客关系、事件信息、路线与时机组织成计划，使混乱事件能够结算。
- **功能十元**：`nx`，置信82%
  - 日常工作沿乘客目的地、既有友人和案件关系网推进，方向经常不是由他起手建立。
- **高压状态十元**：`xz`，置信79%
  - 持枪通缉犯、失踪案、巨款与半黑社会势力把普通载客路线变成危险边界。
- **补位/克位提示**：
  - `n`的补位是`x并z`；出租车与动物表象是场景/视觉接口，不能反写成小户川人物本体。
  - `n`被`zx`克。外部武装和地下势力确实压缩其承接空间，但小户川本人不以公开凌驾为主。

### 对象端点

| 十元 | 具体对象端点 |
|---|---|
| `n` | 进入车内的乘客、乘客对话、突发请求及随之落到他身上的事件责任 |
| `xn` | 载客经历、人物联系、失踪案信息、出租车路线/时机与最后的收束计划 |
| `nx` | 乘客给出的目的地、医生刚力与同学柿花等既有关系、案件网络提供的通道 |
| `xz` | 持枪通缉犯、失踪女子案件、巨款、半黑社会与无法安全抽身的危险路线 |

### 可观察行为证据

1. **每天有性格、目的各异的乘客上车** → 小户川继续载客并与他们交谈 → 乘客目的地、车内对话和个人秘密 → 原本无关的人物信息逐渐在他的载客经历中汇合到失踪少女。`n + nx`
2. **一名携枪通缉犯成为乘客** → 他仍处于司机—乘客的既有路线中处理这趟车程 → 车内安全、乘客目的地和自身风险 → 普通职业承接被迫进入危险边界。`n + nx + xz`（待漫画卷次定位）
3. **小户川平时尽量不与人深交** → 他仍维持刚力医生和高中同学柿花两条长期关系 → 医疗与旧同学关系通道 → 遇事时不是凭公开权能压过所有人，而是保留可借力的既有关系。`nx功能`
4. **普通载客对话逐步连接到女子高中生失踪案** → 他没有在事件落到身上后立即切断，而是继续沿乘客、朋友与案件人物的关系推进 → 失踪案与相互交叉的人物网络 → 从“承载者”进入“被卷入的处理者”。`n → xn候选`
5. **巨款、地下势力、偶像与网络名人使事件变得混乱** → 小户川参与执行一个收束计划 → 既有人员、信息、出租车路线和行动时机 → 事件在计划启动后迅速收束。`xn`（官方电影页交叉核验；待漫画第4—5卷逐项验证）

### 主角行为模式总结

> **小户川通常先让乘客、对话和麻烦落进自己的车与责任范围；当零散关系积累成无法回避的危险网络后，他再把已有人员、信息和路线组织成计划，而不是靠公开压制解决。**

### 反证与误判防线

- 出租车是`n`场景容器，不等于司机自动是`n`；人物主位来自他反复“接住异常乘客和事件后再处理”，不是职业或车厢外观。
- 沉默、低调、少社交不能单独判`nx`；`nx`证据必须落到乘客目的地和既有关系给出的方向。
- 最后有计划不自动让小户川全程都是`xn`；前中段主要是承接与沿关系推进，`xn`在收束阶段上升。
- 小学馆漫画页使用全卷统一简介，动画/电影页只能交叉核验同源剧情；第2、4、5条必须回到漫画第3—5卷确认页内动作。

### 生补克机制

- **`n 生 xn`（中高候选）**：持续承接乘客和事件，使分散对话、关系与线索成为可组织的材料；这些材料扩大最后计划的可用信息与关系范围。
- **`zx 克 n`（中）**：持枪者和地下势力以直接威胁压缩小户川继续承接普通载客秩序的安全边界；他必须从日常容器转入计划应对。
- `n↔x并z`只保留对象层提示：出租车/动物表象补足作品的可见接口，但未证明小户川人物稳定本体带`x并z`。

### 与作品主维关系

作品现存为本体主候选、因果次、时间辅并处于主次二审。小户川人物层的`n→xn`说明他先成为事件承接点，再组织收束；这能解释因果网络和信息积累，却不能单独裁定作品是因果、时间还是本体主。

### 复核与写入

- **复核**：漫画第1卷日常载客/失踪案连接；第2—3卷持枪犯与关系网络；第4—5卷收束计划。
- **建议写入**：[[漫画主角十元行为分析索引]]；任务清单标“媒介已确认·漫画卷次待验证”，作品主次冲突继续保留。

## 3. 钻石王牌 / Ace of the Diamond

### 分析对象

- **主角**：泽村荣纯 / Eijun Sawamura
- **身份**：从地方中学队投手进入青道高校的左投手
- **阶段**：中学败北 → 赴青道 → 夏季轮换登板 → 新队王牌竞争 → 秋季决赛
- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-17_本体A组4部十元关系轻筛_第二批.md`
- **当前状态**：跨卷官方书目轻筛完成；作品本体/时间/空间维度冲突继续待二审

### 主次十元

- **主十元**：`z`，置信93%
  - 泽村反复把“我的投球是否成立、我是否配得上王牌位置”交给捕手、队友、教练和正式比赛确认；认可主体与认可内容都明确。
- **次十元**：`zx`，置信89%
  - 一旦被换上投手丘，他会以公开投球表现直接改变比赛流向，并在与强打者对决中扩大自己的队内位置。
- **补位十元**：`xn`，置信83%
  - 长期训练、投手轮换、比赛节点和与捕手的配球结构，为`z`提供反复可验证的认可场。
- **关系功能**：`nx`，置信77%
  - 他必须沿教练换投、捕手配球和球队战略行动，但这不是稳定无主见，而是竞技结构中的必要功能。
- **补位/克位提示**：
  - `z`与`xn`为补位。当前有持续训练/轮换候选，但需要原章确认双方分别补足什么。
  - `z`克`nx`。当投手认可目标让泽村离开原定家乡升学路线、主动选择青道时，关系已有中置信启动。

### 对象端点

| 十元 | 具体对象端点 |
|---|---|
| `z` | 御幸的接球与评价、教练的登板选择、队友的信任、王牌背号与比赛结果对投手能力的确认 |
| `zx` | 投手丘上的公开投球权能、对打者的压制、换投后改变比赛流向的能力 |
| `xn` | 日常训练、投手轮换、比赛赛程、配球学习、从一场登板积累到下一场的成长结构 |
| `nx` | 教练换投指令、捕手配球、球队共同战略和既定赛事流程 |

### 可观察行为证据

1. **中学全国赛梦想因自己的暴投而结束** → 泽村仍计划与原队友一起升高中后重来 → 原球队、队友与未完成的投手责任 → 败北没有让他离开认可场，而是先想在原关系中重新证明。`z + nz功能`
2. **被青道球探邀请、到名校参观** → 他与新锐捕手御幸临时组成投捕搭档 → 御幸的手套、接球反馈和青道强打者 → 一次被高水平捕手接住的体验重新点燃投球热情。`z + nx功能`
3. **原定与家乡队友一起升学** → 他向朋友告别并独自赴青道 → 家乡关系、青道竞争环境和自己的投手位置 → 明确认可目标改变了原有随行方向。`z 克 nx`
4. **夏季预选古谷体力耗尽、教练要求换投** → 泽村接替登上投手丘 → 秋川打线、队友和比赛流向 → 在公开比赛中获得用投球改变局势的机会。`nx功能 → zx + z`
5. **决赛王牌丹波倒下、青道进入危机** → 泽村再次被投入高压局面并以强心脏迎战 → 稻实打线、球队命运和教练信任 → 把“能不能接住球队”交给实际投球证明。`zx + z`
6. **古谷追逐王牌背号、新强敌刺激竞争，秋季决赛又必须面对曾造成压力的雷市** → 泽村在压力下走上投手丘正面对决 → 王牌位置、雷市、御幸手套与队伍晋级 → 以公开表现争取王牌认可，并用最坏对手检验自己的成长。`z + zx`

### 主角行为模式总结

> **当败北、换投或强敌让投手资格受到质疑时，泽村会把自己送回捕手手套和正式比赛这一认可场，用公开投球争取队友、教练和王牌位置的确认。**

### 反证与误判防线

- 想当王牌不因“目标明确”就自动判`z`；本轮有御幸、教练、队友、背号和比赛结果等明确认可主体/认可机制。
- 上场投球是`zx`行为，但泽村不是为了凌驾所有人而展示权力；公开投球主要服务“我是不是够格的投手/王牌”，因此`z`高于`zx`。
- 服从换投和捕手配球是`nx`功能，不能因为他在球队制度中行动就把人物判成`nx`主。
- 官方简介能确认登板与竞争节点，不能替代日常训练细节；`xn`补位需抽读训练、投捕会议和号码开发章节。

### 生补克机制

- **`z 克 nx`（中高）**：御幸与更高水平球队提供的认可机会改变泽村原定与家乡队友继续的升学路线，使他主动赴青道；被改变的是方向决定权。

## 4. PLUTO / PLUTO冥王

### 分析对象

- **主角**：盖吉希特 / Gesicht
- **身份**：欧洲刑警组织的顶级机器人刑警，也是“世界七大机器人”之一
- **阶段**：第1—6卷，从受命调查连环死亡到逼近凶手动机与自身被封锁记忆
- **来源文件**：[[02-时间型 xn+z]]、[[漫画库总索引]]、`2026-07-17_PLUTO与时间源名4项复审.md`
- **当前状态**：第1—6卷官方书目轻筛完成；作品时间/因果维度冲突继续待二审

### 主次十元

- **主十元**：`xn`，置信93%
  - 盖吉希特持续把尸体线索、目标名单、战争调查组、潜在受害者、凶手名与个人记忆放进调查顺序，使分散死亡成为可推进的结构。
- **次十元**：`zn`，置信88%
  - 调查后段不只问谁杀人，也逼近“机器人能否仇恨、自己的记忆为何被锁、我究竟做过什么”的主体意义。
- **功能十元**：`nx`，置信81%
  - 案件由欧洲刑警组织交付，他使用现成刑警权限、跨国制度与专家关系推进。
- **执行十元**：`zx`，置信78%
  - 警告目标、面对威胁和采取现场行动是必要执行，但他主要靠调查结构，不以公开凌驾为人物核心。
- **补位/克位提示**：
  - `xn`与`z`为补位；案件的关键节点/目标名单提供集中爆点，但`z`认可主体在盖吉希特人物层不够明确，暂不升人物次位。
  - `xn`被`zn`克。自身记忆与仇恨真相进入调查后，客观刑警流程受到结构性改写，关系为高置信候选。

### 对象端点

| 十元 | 具体对象端点 |
|---|---|
| `xn` | 两起角状尸体线索、七大机器人名单、Bora调查组成员、潜在目标、跨国调查顺序、个人被封锁记忆 |
| `zn` | “机器人是否拥有灵魂/仇恨”、盖吉希特被删除记忆中的行为与责任、刑警身份的意义 |
| `nx` | 欧洲刑警组织指派、刑警权限、专家/科学家和跨国机构提供的调查通道 |
| `zx` | 警告潜在目标、现场追查、以刑警权能直接介入危险的执行能力 |

### 可观察行为证据

1. **瑞士机器人Mont Blanc与机器人权利团体要员先后被杀，尸体旁都有角状拼接** → 盖吉希特受命后把两案并入同一调查 → 两处尸体、共同线索与受害者身份 → 从“看似无关”建立可追踪的连环案结构。`nx → xn`
2. **发现凶手可能以七大机器人为目标，自己也在名单中** → 他没有只安排自保，而是主动警告其他潜在目标，下一站包括阿童木 → 目标名单、受害顺序与跨国路线 → 把推断转成按顺序展开的预警行动。`xn + zx功能`
3. **机器人与Bora调查组成员继续接连被害** → 他把新的受害者、旧调查组与战争背景继续纳入同一案卷 → 死亡顺序、调查组名单与动机线 → 调查没有停在单个凶手身份，而是持续扩展结构。`xn`
4. **案件逐渐显示人类与机器人之间的仇恨** → 盖吉希特继续深挖，并开始解锁自己被封存、几乎遗忘的记忆 → 社会仇恨与个人记忆 → 外部案件开始改写“我是中立刑警”的自我答案。`xn → zn`
5. **Pluto、Sahad、Goji、Abullah等名字与连环案相互交叉** → 他逐项逼近凶手及动机，同时逼近自己的可怕真相 → 多个嫌疑端点、战争因果与自身记忆 → 把“查别人”推进为“自己也属于案件结构”。`xn + zn`
6. **最终卷由复活的阿童木掌握答案并承担终局战** → 本轮停止把后续行为归给盖吉希特 → 阿童木、盖吉希特等已逝机器人记忆与世界危机 → 明确主角阶段边界，避免把阿童木的`zx`执行污染盖吉希特人物结论。`对象层边界证据`

### 主角行为模式总结

> **面对分散死亡时，盖吉希特会先冻结共同线索、目标名单和调查顺序，再沿跨国权限逐一预警与追查；当线索回到自己被锁的记忆时，他仍把自身纳入案卷，而不是把个人真相排除在调查之外。**

### 反证与误判防线

- “刑警查案”是职业题材，不能单独判`xn`；主位来自他反复主动合并线索、推出目标名单、安排警告顺序并持续重组案卷。
- 受欧洲刑警组织指派只证明起点`nx`功能；接案后怎样组织调查由盖吉希特主动决定，因此不能判`nx`主。
- 他是强力机器人不自动等于`zx`；书目主线强调调查、预警和记忆解锁，公开力量压制不是稳定主骨。
- 第7—8卷阿童木接管终局，不能用阿童木的最终战证明盖吉希特`zx`或`zn`。

### 生补克机制

- **`n 生 xn`（中候选）**：盖吉希特先承接刑警案件与潜在受害者责任，再把它们组织成调查结构；被改变的是信息可排列性和案件持续条件。
- **`xn 克 zx`（中高）**：目标名单、预警顺序和跨国调查把“遇到敌人直接开战”的路径限制在必要执行位，使信息结构先于力量对撞。
- **`zn 克 xn`（高候选）**：被锁记忆和机器人仇恨真相进入案卷后，盖吉希特不能继续维持纯外部、客观的调查路径；被改变的是调查对象边界与刑警身份位置。

### 与作品主维关系

作品现存为时间型主候选、因果型次、本体型辅。盖吉希特人物`xn`强烈支持长期调查、名单与记忆积累；次`zn`支持机器人自我问题。但连环死亡“谁杀、为何杀”的因果链仍很强，人物结果不能单独结束作品维度冲突。
