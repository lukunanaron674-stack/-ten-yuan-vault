# 主角十元行为穷举 · 第七十二批3部医生燃烧与艺考采矿

## 本轮边界

扫描固定漫画库后，未发现新的漫画原页或理论正本改动。本轮按“旧报告已有逐条行为、但尚未进入单行为记录库”的优先级，选择《MONSTER》《炎拳》《蓝色时期》三个证据闭合对象。全部是出版社公开简介/指定卷次范围穷举，非全作逐页实读；不把作品主题、他人行为、世界观设定或抽象心理词冒充主角动作。

五行称呼统一按天干总框：`xn=阳金`、`nx=阴金`、`zn=阳火`、`z=阴火`、`n=阳土`、`nz=阴土`、`zx=阳木`、`x并z=阴木`、`xz=阳水`、`x=阴水`。本批未修改任何符号归类，只将既有行为证据标准化写入行为库。

  - 归类：`xn`（主位证据，94%）。对象端点：Nina、连环案线索、调查路线；主角把目标与信息组织成持续任务。

- 主十元：`xn`（95%候选）。寻人、追踪秘密过去、前往关键现场形成跨阶段调查组织链。

- 与作品主维关系：人物`xn`旁证因果作品的调查执行层，但Johan行动、群像后果和作品善恶因果不缩成天马个人十元。

## 二、《炎拳》｜Agni

- 身份：拥有再生能力、被不灭火焰持续焚烧的幸存者；阶段：村落毁灭、Doma复仇、Togata路线、虚假和平至Judah。
- 覆盖：VIZ第1—8卷公开简介范围；不是全作逐页穷举。
- 当前状态：8条行为中7条可唯一归类，1条保留证据不足。

- 行为1：能力者袭击并摧毁孤儿村 → Agni在持续燃烧中奋力求生 → 作用对象：持续燃烧的身体、死亡边界和生存路线 → 他没有在袭击后立即死亡，继续处在极端临界状态。【FP-1】
  - 归类：`xz`（功能位证据，95%）。对象端点：持续燃烧身体、死亡边界、生存路线；不把再生能力设定本身算`x`。
- 行为2：村落被毁且亲人死亡 → Agni公开立下针对Doma的复仇誓言 → 作用对象：Doma、复仇目标和后续行动方向 → 生存被转成指向Doma的公开目标。【FP-1】
  - 归类：`zx`（主位证据，93%）。对象端点：Doma、复仇目标、对外声明；誓言把自身力量公开指向他人，但不等于完成复仇。
- 行为3：Agni终于面对长期仇敌Doma → 他与Doma交战 → 作用对象：Doma、双方身体和战斗现场 → 战斗以Agni被斩首并押运告终。【FP-2】
  - 归类：`zx`（主位证据，96%）。对象端点：Doma、直接战斗、身体压制结果；不把被斩首再算`xz`。
- 行为4：Togata完成对他的“升级”后 → Agni前往Behemdorg执行对Doma的复仇 → 作用对象：Behemdorg、行进路线和Doma目标 → 他进入Togata安排的战斗场。【FP-3】
  - 归类：`xn`（功能位证据，93%）。对象端点：Behemdorg、行进路线、Doma目标；动作把复仇目标转成持续路线。
- 行为5：前往Behemdorg途中出现新的决意 → 公开资料没有说明Agni随后采取的具体动作 → 作用对象和可观察后果未闭合 → 只能确认叙事方向变化。【FP-3】
  - 归类：暂不归类（证据不足）。理由：内心变化及Togata剧本受影响不能替代主角下一步可观察动作。
- 行为6：Togata秘密曝光且痛苦话语使Agni动摇 → Agni主动寻找造成全部痛苦的源头人物 → 作用对象：源头人物、因果线索和追索路线 → 复仇与追问重新收束到具体寻人任务。【FP-5】
  - 归类：`xn`（功能位证据，95%）。对象端点：痛苦源头人物、追索信息、路线；把散乱痛苦转成寻人任务。
- 行为7：虚假和平持续折磨自身 → Agni拼命寻找逃离这种生活的出口 → 作用对象：虚假身份、日常关系和离开路线 → 他开始尝试脱离既有停靠状态。【FP-7】
  - 归类：`xz`（功能位证据，92%）。对象端点：虚假身份、生活边界、逃离路线；不把痛苦本身算行为。
- 行为8：身体再次燃烧且目标转向Judah → Agni焚毁挡路的人和物并前往Judah → 作用对象：阻路者、沿途环境和Judah方向 → 他以直接破坏清开行进路线。【FP-8】
  - 归类：`zx`（主位证据，98%）。对象端点：阻路者、沿途环境、Judah；直接外放权能改写外部对象。

### Agni统计后判断

- 归类计数：`zx`×3、`xn`×2、`xz`×2、暂不归类×1。
- 主十元：`zx`（96%候选）。复仇誓言、与Doma交战、焚毁阻路者跨越开篇、中段和后期路线，均把自身力量直接压向外部对象。
- 次十元：未判。`xn`与`xz`各两条，分别承担追索组织与临界逃离功能。
- 关系候选：`xz`生`zx`（90%候选）仅保留候选，不登记。无法退出的身体危险把生存行动转成对外施力，但Doma、Togata与Judah路线是强第三因素。
- 与作品主维关系：人物`zx`显示公开执行面，`xz`显示身体边界压力；不恢复旧作品96分正式主条，不把人物统计改写成作品本体结论。
- 原卷复核：第1—3卷求生、誓言、Doma交战与Togata路线；第5卷源头人物；第7卷寻找出口；第8卷前往Judah途中攻击对象。

## 三、《蓝色时期》｜矢口八虎

- 身份：高中生从优等生路线转入美术；阶段：初遇绘画、艺考训练、第一次竞赛及东京艺大两次考试。
- 覆盖：讲谈社第1—6卷公开简介范围；不是全作逐页穷举，作品正式评分仍未补造。
- 当前状态：9条均形成唯一归类。

- 行为1：在美术教室看见令其首次感到新型美感的画 → 八虎全身投入绘画 → 作用对象：生活方向与创作活动 → 原本空洞的优等生路线被绘画选择替换。【BP-1】
  - 归类：`zn`（次位证据，94%）。对象端点：个人生活方向、绘画价值、创作选择；内部意义改变路线，不把被画吸引单独算`z`。
- 行为2：决定冲击竞争激烈的美术大学且眼界有限 → 八虎向新同伴与大师学习构想独有作品 → 作用对象：同伴、教师/大师反馈和作品构想 → 外部关系与范例进入训练。【BP-2】
  - 归类：`nx`（主位证据，95%）。对象端点：同伴、教师/大师、反馈通道；沿外部关系与专业入口推进。
- 行为3：需要检验与艺考标准的距离 → 八虎参加第一次美术竞赛 → 作用对象：竞赛流程、作品提交与排名标准 → 作品获得外部标准评价。【BP-2】
  - 归类：`nx`（主位证据，92%）。对象端点：竞赛规则、作品提交、排名标准；进入既有评价流程。
- 行为4：第一次竞赛结果低于目标且只剩100天 → 八虎接受大叶老师挑战并投入完成 → 作用对象：教师任务、训练期限和作品答案 → 沿外部训练框架逼近考试要求。【BP-3】
  - 归类：`nx`（主位证据，96%）。对象端点：大叶老师、挑战任务、100天期限、训练流程。
- 行为5：备考需要扩大可表达范围 → 八虎把新材料纳入工具箱并拓宽表达手段 → 作用对象：自己持有和使用的画材、工具与技法 → 可调用创作资源范围增加。【BP-4】
  - 归类：`x`（功能位证据，92%）。对象端点：本人实际持有/使用的画材、工具、技法；是具体资源掌握。
- 行为6：东京艺大第一次考试出现不利状况 → 八虎调整应对并完成当场创作 → 作用对象：考试时间、现场材料和作品交付 → 在约束内完成可提交结果。【BP-5】
  - 归类：`xn`（功能位证据，91%）。对象端点：考试时间、现场材料、交付步骤；是在约束中重排资源。
- 行为7：第一次考试后偏离正常创作轨道 → 八虎在旧友帮助下走出画室并进入不同光线环境 → 作用对象：旧友关系、工作环境和观察条件 → 借外部关系与环境切换重新进入创作。【BP-5】
  - 归类：`nx`（主位证据，92%）。对象端点：旧友、画室外环境、光线条件；依靠既有关系与外部条件接回路线。
- 行为8：需要面对新的自我表现课题 → 八虎裸露身体并创作裸体自画像 → 作用对象：自身身体、个人经验和自画像 → 自身被转化为作品的直接题材。【BP-5】
  - 归类：`zn`（次位证据，96%）。对象端点：自身身体、个人经验、自画像；把内部问题转成作品。
- 行为9：第二次考试前遭遇挫折且考题含陌生与熟悉成分 → 八虎进入并应对第二次考试 → 作用对象：考试题目、创作过程和入学竞争 → 没有因挫折退出既有艺考流程。【BP-6】
  - 归类：`nx`（主位证据，94%）。对象端点：第二次考试、命题、竞争流程；沿正式流程继续行动。

### 八虎统计后判断

- 归类计数：`nx`×5、`zn`×2、`x`×1、`xn`×1。
- 主十元：`nx`（95%候选）。同伴/大师、竞赛、教师挑战、旧友环境切换和第二次考试均沿外部关系或既定流程推进。
- 次十元：`zn`（94%候选）。投入绘画与裸体自画像改变生活方向和自我表达对象，强度高但票数少于`nx`。
- 功能位：`x`92%、`xn`91%。前者是具体画材掌握，后者是考试现场资源重排。
- 关系候选：不登记。外部训练与新材料存在先后，但不足以锁定`nx`生`x`机制。
- 与作品主维关系：人物`nx+zn`解释学习接口与自我表达，不自动形成作品空间公式`x并z+n`；画室是否为作品主容器留在作品层二审。
- 原卷复核：第1卷投入绘画；第2—4卷同伴/大师、竞赛、教师挑战、新材料；第5卷第一次考试、离开画室、裸体自画像；第6卷第二次考试。
