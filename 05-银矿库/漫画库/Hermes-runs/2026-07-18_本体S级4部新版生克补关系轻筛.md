# 本体 S 级 4 部｜新版十元生克补关系轻筛

## 一、本轮为什么重做

2026-07-18 的现行正本已经锁定：

```text
x = 对象、资源、地盘、权限或关系归我掌握
xn = 主体主动组织计划、时间、规则、信息和资源，使结构持续运行
z = 精神个体需要认可主体确认自己的存在、能力或价值
```

因此，2026-07-10 预筛中的以下旧写法不能继续当正式关系依据：

```text
x = 欲望 / 吞噬
胜负欲直接判 x
身体冲动直接判 x
z 克 xn
```

本轮不重评作品分数，只把四部高分本体条目的对象层、合法关系边和反证重新写清。主维、次维、辅维仍只作导航。

- 来源文件：[[01-本体型 zn+x]]、[[漫画库总索引]]、[[【zn信息量卡v1】]]
- 当前状态：100 分精选；旧预筛完成；本轮升级为新版关系轻筛，待逐卷二审
- 导航判断：本体型 `zn+x` 主；时间型 `xn+z` 次候选；空间型 `x并z+n` 辅
- 关系置信：84%

### 对象端点

| 对象 | 对象层 | 十元候选 | 说明 |
|---|---|---|---|
| 宫本大“不吹就不是自己”的爵士意义 | 人物稳定核心 | `zn` | 内部意义不依赖外部奖励成立 |
| 自己的萨克斯、音色与演奏控制范围 | 行为/能力归属 | `x` | 不是“欲望”，而是他实际掌握并不断扩大的具体演奏领域 |
| JASS、共同排练与稳定演出单位 | 关系/承载 | `n` | 让个人意义获得持续存在的团队容器 |
| 排练、曲目、演出节点与长期训练安排 | 时间结构 | `xn` | 主动组织并积累演奏能力 |
| 乐手、观众与“世界第一”评价位置 | 认可关系 | `z` 候选 | 可证明能力被确认，但不是宫本大继续演奏的必要前提 |

### 可用关系

1. `zn 生 n`｜中高置信  
   宫本大的爵士意义促成并持续推动乐队与演出共同体形成；被改变的变量是“个人演奏能否变成可持续合作容器”。

2. `n 生 xn`｜高置信  
   乐队和演出场域使排练、曲目、演出节点与能力积累必须被持续组织；拿掉团队容器，时间结构会退回个人练习。

3. `zn 补 x`｜中高置信  
   `zn` 给“我掌握的萨克斯与声音”提供精神方向，`x` 则把抽象爵士意义落实为宫本大能够实际控制、调用和扩大的演奏范围。这里不再使用“意义补欲望”的旧解释。

4. `xn 补 z`｜暂不升强链  
   比赛、演出与训练节点确实提供认可位置，但库内既有材料同时表明宫本大并不依赖认可才继续演奏。`z` 更像阶段显影，不足以解释稳定本体。

### 动态链候选

```text
宫本大爵士意义 zn
→ 生出持续演奏共同体 n
→ 共同体生出排练与演出组织 xn
```

补位侧链：

```text
爵士意义 zn ↔ 萨克斯、音色与演奏范围的具体掌握 x
```

### 五主关系

- `本体 生 空间`：中高置信。宫本大的存在方式实际生成乐队、舞台与共同演奏空间。
- `空间 生 时间`：中置信。乐队/舞台让排练与演出节奏成为持续结构。
- 反证：如果乐队与演出节点只是偶然背景，而不是由宫本大的本体选择持续生成，则两条主题关系降为共现。

### 下一步

逐卷补证“JASS 成立、关键排练、关键演出与离队/重组”四个节点；100 分不改。

## 三、灌篮高手

- 来源文件：[[01-本体型 zn+x]]、[[漫画库总索引]]、`05-银矿库/入库卡片/漫画/灌篮高手.md`
- 当前状态：98 分精选；旧入库卡仍保留历史关系；本轮升级为新版关系轻筛
- 导航判断：本体型 `zn+x` 主候选；时间型 `xn+z` 次；空间型 `x并z+n` 辅
- 关系置信：82%

### 旧卡纠偏

旧卡写：

```text
z 克 xn
```

现行位置盘中：

```text
z 克 nx
xn 克 zx
xn ↔ z 为补位候选
```

因此“执念打破比赛时间/规则”不能继续作为 `z 克 xn` 的正式证据。比赛规则没有被执念改写；角色只是在规则内把行动推到极限。

### 对象端点

| 对象 | 对象层 | 十元候选 | 说明 |
|---|---|---|---|
| 湘北球队、板凳、教练与共同训练 | 关系/场景承载 | `n` | 让球员长期共处与重复训练 |
| 训练、轮换、比分、回合与比赛时限 | 时间结构 | `xn` | 被主动组织并持续积累的竞技结构 |
| 晴子、队友、对手与自我确认 | 认可关系 | `z` | 认可对象从“被晴子看见”逐渐转向“被球队与自己确认” |
| 篮板、禁区、防守职责与个人技术范围 | 能力归属 | `x` | 是樱木实际能够掌握和负责的具体篮球范围，不是泛化胜负欲 |
| “我真的喜欢篮球”的内部确认 | 人物/状态意义 | `zn` 候选 | 后期不再只为外部认可打球 |

### 可用关系

1. `n 生 xn`｜高置信  
   球队容器持续生出训练、轮换、战术与比赛时间结构；被改变的变量是球员行动能否积累成团队运行。

2. `xn 补 z`｜中高置信  
   训练记录、比分与比赛节点给能力认可提供明确位置；认可又让长期训练的积累获得可见反馈。这里只写互补，不写 `z 克 xn`。

3. `zn 补 x`｜中高置信、限后期  
   对篮球的内部意义与篮板、防守、身体控制等具体掌握范围互相补全。拿掉实际掌握，意义会悬空；拿掉内部意义，技术仍可能存在，但不再构成樱木后期的本体确认。

4. `z 克 nx`｜候选、不入强链  
   认可压力可能压缩人物顺着他人安排行动的空间，但当前材料不足以排除教练、队友与比赛局势等第三因素。

### 动态链候选

```text
湘北球队容器 n
→ 生出训练与比赛组织 xn
↔ 补合认可位置 z
```

本体侧链：

```text
篮球内部意义 zn ↔ 篮板、防守与技术范围的具体掌握 x
```

### 五主关系

- `空间 生 时间`：高置信候选。球队与球场使训练、轮换、比分和最后时限成为结构力量。
- 其他主题关系暂不启动；“比赛很燃”不等于本体克时间。

### 下一步

逐章核对樱木的认可主体变化和“我真的喜欢篮球”前后阶段；保留 98 分。旧 95 分入库卡不删除，只降为历史关系证据。
