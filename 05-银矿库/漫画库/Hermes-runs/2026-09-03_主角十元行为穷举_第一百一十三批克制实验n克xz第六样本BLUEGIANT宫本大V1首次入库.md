- 行为1: 宫本大每天在学校音乐室和街头坚持 sax 练习, 承接爵士生涯的临界面 (面试失敗、街头冷眼、突发技術瓶頸)、宫本大按 sax 練習規則、按临界面、按練習的时辰把临界面按时辰承接 → **克制维度**: n 阳土 → 克 xz 阳水 (爵士生涯临界面 xz 受 n 阳土 sax 载体承载约束)。→ 作用于爵士临界面 → 临界面按时辰被宫本大承接。
  - 归类: n (阳土, 主位证据, 93%)。对象端点: 爵士生涯临界面 xz 阳水 承载回应 (n 阳土 → 克 xz 阳水, **第六样本**)。
- 行为2: 宫本大在新潟家乡参加 sax 独奏并在校内演出的安排, 宫本大按演出的規則、按独奏的内容、按安排的时辰把独奏按时辰安排 → 作用于校内演出 → 安排按时辰被学校接收。

  - 归类: zn (阳火, 主位证据, 92%)。对象端点: 爵士演出的初心独立主体資格保存 (zn 阳火)。

  - 归类: xn (阳金, 主位证据, 92%)。对象端点: 乐队组织流程既有通道。
