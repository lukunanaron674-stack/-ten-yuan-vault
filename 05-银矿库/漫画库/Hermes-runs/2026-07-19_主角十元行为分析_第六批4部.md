## 1. WATCHMEN

### 1.1 Adrian Veidt / Ozymandias

#### 对象、阶段与判断

- 身份：公开退役的超级英雄、企业家、长期阴谋的组织者。
- 阶段：退出蒙面英雄活动至纽约事件完成。
- 来源：[[04-因果型 zx+nx]]、[[漫画库总索引]]、`二审/二审-因果型标准化_2026-06-03.md`。
- 当前状态：作品96分、因果主/命运次/本体辅；人物层旧`zx主`解释降权。

| 层级 | 十元 | 置信度 | 具体对象端点 |
|---|---|---:|---|
| 主十元 | `xn` | 97% | 冷战时间表、英雄名单、媒体舆论、Dr. Manhattan离场、岛上研究、传送节点与纽约执行时点；由Veidt主动排序并长期运行 |
| 次十元 | `x` | 94% | 企业资产、南极基地、岛屿、科研团队、技术、媒体与公开身份；这些对象实际由他占有、调配或封口 |
| 行动位 | `zx` | 90% | 以“世界上最聪明的人”和Ozymandias身份公开显权，在关键节点直接压过Comedian、追查者与世界政治 |
| 接口位 | `x并z` | 85% | 公益企业家/退役英雄的公开壳与秘密大规模杀戮计划分层；目前只判身份接口，不升稳定主位 |

#### 行为证据

1. **蒙面英雄即将被制度限制、个人身份可能失去主动权** → Veidt提前公开Ozymandias身份并经营商业体系 → 作用于英雄身份、企业和公众形象 → 把退役后的资源与影响力纳入自己持续调配的范围。  
   - 对应：`x + xn`。
   - 定位：原作第1—2章背景材料，待页码复核。

2. **Comedian发现岛上秘密工程** → Veidt亲自杀死Comedian并利用死亡启动错误调查方向 → 作用于知情者、警方与其他英雄 → 关键泄密端点被移除，阴谋继续运行。  
   - 对应：`xn`组织链中的`zx`执行。
   - 定位：原作第11—12章回溯。

3. **Dr. Manhattan有能力直接破坏计划** → Veidt预先安排其旧同事患癌的舆论链，把公众怀疑引向Manhattan → 作用于Manhattan的社会关系、地球停留与公众信任 → Manhattan离开地球，直接干预条件被压低。  
   - 对应：`xn`。
   - 定位：原作第3—4章。

4. **调查逐渐逼近Veidt** → 他安排针对自己的公开刺杀表象并清理中间知情者 → 作用于自己的嫌疑位置与Rorschach调查路径 → 调查者被重新导向外围线索。  
   - 对应：`xn + x并z`功能。
   - 定位：原作第5—10章，具体执行者/先后待逐章复核。

5. **需要把政治恐惧转化为可控制的共同敌人** → Veidt以岛屿、艺术家、科学家和传送技术组织出假外星事件 → 作用于研究团队、造物、传送装置与全球叙事 → 分散资源被压成一个可按时触发的结构。  
   - 对应：`xn`主证据，`x`提供掌握资源。
   - 定位：原作第10—12章。

6. **Rorschach等人到达南极准备阻止** → Veidt告知计划早已在他们到来前完成并触发纽约事件 → 作用于纽约、追查者的阻止能力与美苏关系 → 直接行动被已完成的时间结构越过，全球政治暂时转向合作。  
   - 对应：`xn克zx`强候选。
   - 定位：原作第11—12章。

#### 模式、反证与关系

**行为模式总结**：面对世界级风险，Veidt先把人物、资源、舆论和时间节点收进自己的控制边界，再让多年结构先于任何英雄的现场行动完成结果。

反证：

- 他亲自杀Comedian、躲子弹并执行终局，有很强`zx`；但单次权能服务于长期结构，暂不覆盖`xn`主位。
- 他在终局向Dr. Manhattan寻求“是否做对”的确认，出现`z`需求；这恰好说明计划完成后内部确信并不完全自足，不能反判`zn`主。
- 商业帝国证明具体`x`，但故事核心不是“拥有这些资源”，而是怎样把资源排入时间结构。

关系：

- **`xn克zx`强候选**：Veidt的多年计划通过提前完成和预先移除Manhattan，压缩其他英雄“到场即可阻止”的能力；目标变量是现场干预的有效性。第三因素冷战危机解释动机，但不能替代具体计划机制。

### 1.2 Walter Kovacs / Rorschach

#### 对象、阶段与判断

- 身份：拒绝退休的蒙面义警、Comedian命案调查者。
- 阶段：发现Comedian死亡至南极终局及日记后手。
- 当前状态：人物层旧`nx`判定作废；新版轻筛完成。

| 层级 | 十元 | 置信度 | 具体对象端点 |
|---|---|---:|---|
| 主十元 | `zn` | 96% | “真相不能因结果有利而被抹掉”的内部道德边界；不需要同伴、政府或公众同意 |
| 次十元 | `xn` | 90% | Comedian现场、退役英雄名单、Moloch、Veidt、日记与线索次序；主动建立调查结构 |
| 行动位 | `zx` | 87% | 以暴力审讯、越狱和义警身份直接压过对象；属于办案手段 |
| 状态位 | `xz` | 88% | 警方追捕、监狱围攻、南极死亡边界；危险逼近后仍在临界线上行动 |

#### 行为证据

1. **Comedian被杀且警方按普通凶案处理** → Rorschach私自进入现场、发现隐藏服装并提出“有人猎杀蒙面英雄” → 作用于犯罪现场和英雄名单 → 单一死亡被组织成需要继续验证的调查假设。  
   - 对应：`xn`行为由`zn`真相边界启动。
   - 定位：第1章。

2. **其他英雄已经退休且不接受其推断** → 他逐一警告Nite Owl、Ozymandias、Dr. Manhattan等人 → 作用于旧英雄关系网与潜在受害者 → 即使没有认可，调查方向仍不改变。  
   - 对应：`zn + xn`。
   - 定位：第1—2章。

3. **Keene法案要求义警退出** → Rorschach继续戴面具、记录街头犯罪并自行审判 → 作用于法律禁令、犯罪者和日记 → 外部合法性没有改变其“必须揭露/惩罚”的内部标准。  
   - 对应：`zn`。
   - 定位：跨章背景，待具体页码。

4. **Veidt布置线索使警方逮捕并送他入狱** → Rorschach在监狱围攻中自保，继续拒绝放弃身份 → 作用于囚犯、狱警和面具身份 → 危险提高，但调查者没有被迫改成服从流程的`nx`。  
   - 对应：`xz`状态、`zx`行动。
   - 定位：第6—8章。

5. **获救后线索指向Veidt和南极基地** → 他与Nite Owl继续追到南极，核对计划真相 → 作用于Veidt、基地与纽约事件 → 调查从谋杀案抵达世界级阴谋。  
   - 对应：`xn`。
   - 定位：第10—12章。

6. **Veidt要求所有幸存英雄以世界和平为由保持沉默** → Rorschach拒绝共同背书并试图离开公布真相；此前已把日记寄出 → 作用于终局保密协议与公众知情路径 → 他被Dr. Manhattan杀死，但计划的长期保密仍留下裂口。  
   - 对应：`zn克xn`强候选。
   - 定位：第12章。

#### 模式、反证与关系

**行为模式总结**：当制度、同伴或有利结果要求他放弃真相时，Rorschach先守住内部道德边界，再主动组织线索和后手；危险只能改变他的行动成本，不能让他认领共同谎言。

反证：

- 他会与Nite Owl合作、使用既有交通和信息，局部存在`nx`关系功能；但调查方向从未由同伴替他决定，不支持`nx`人物主位。
- 暴力和威慑带`zx`，但他并不追求公开权能扩张或统治他人。
- 黑白道德可能是病理性信念，但`zn`只判断内部意义是否自足，不判断信念善恶。

关系：

- **`zn克xn`强候选**：Rorschach的真相原则使Veidt“所有知情者保持沉默”的结构无法完全闭合；目标变量是阴谋长期保密与新秩序持续条件。日记是否最终被相信仍是未判定，不影响“保密结构被留下裂口”的事实。

### 1.3 与作品主维

- 人物层与作品因果主维**机制相关但不等号**。
- Veidt是`xn+x`，Rorschach是`zn+xn`；旧“Veidt=zx、Rorschach=nx”人物点位不再使用。
- 作品因果型来自两人的计划、调查、选择、死亡和日记后手共同构成的世界级后果链，不要求人物恰好组成`zx+nx`。
- 复核：原作第1、3—6、10—12章。
- 写入：[[漫画主角十元行为分析索引]]、[[04-因果型 zx+nx]]、任务机Watchmen行。

出版方核验：[DC《WATCHMEN》总页](https://www.dc.com/graphic-novels/watchmen-1986/watchmen)、[DC新版简介](https://www.dc.com/graphic-novels/watchmen-1986/watchmen-new-edition)、[DC终局讨论](https://www.dc.com/blog/2024/12/10/what-everyone-misses-about-the-ending-of-watchmen)。

## 2. 进击的巨人｜Eren Yeager

### 2.1 对象、阶段与判断

- 身份：墙内少年、调查兵团成员、进击/始祖巨人继承者、地鸣发动者。
- 阶段：渴望墙外至地鸣终局。
- 来源：[[04-因果型 zx+nx]]、[[05-命运型 xz+nz]]、[[漫画库总索引]]、角色旧卡`角色库/详细卡/艾伦.md`。
- 当前状态：作品91分、因果主/命运次/时间辅；人物旧`zx+nx→x`关系降权。

| 层级 | 十元 | 置信度 | 具体对象端点 |
|---|---|---:|---|
| 主十元 | `zn` | 94% | “自由是出生者应当拥有的存在条件”；即使朋友、军方和世界否定，也不依赖外部认可成立 |
| 次十元 | `zx` | 92% | 进击/始祖巨人力量、马莱战场与地鸣；把主体权能公开推到压过军队和世界的位置 |
| 功能位 | `xn` | 90% | 潜入马莱、与Zeke接触、Yeagerists、始祖接触条件与地鸣时点；主动安排路径和节点 |
| 晚期`x` | `x` | 88% | 始祖坐标、墙中巨人及其行进方向被纳入Eren实际调配范围；不是“灭世欲望” |
| 状态位 | `xz/nx` | 87% | 巨人逼近、未来记忆和Paths既定图景构成危险/外部方向压力；只记状态，不直接改写稳定本体 |

### 2.2 行为证据

1. **墙把人类限制在内部、Eren得知墙外世界存在** → 他持续要求离墙并把调查兵团作为出口 → 作用于墙、个人未来与探索路径 → “墙内安全”不能替代自由，人物方向在灾难前已经形成。  
   - 对应：`zn`，早期`zx`尚未拥有足够权能。
   - 定位：第1卷。

2. **Wall Maria被破、母亲遇害** → Eren加入军队并把巨人作为必须直接消灭的对象 → 作用于训练、巨人和自身身体 → 内部自由标准被灾难放大为持续战斗。  
   - 对应：`zx`行动上升，`xz`为外部压力。
   - 定位：第1—4卷，待具体章页。

3. **地下室笔记揭示墙外国家、历史与巨人来源** → Eren不再把敌人只限定为无意识巨人，而开始面向墙外政治现实 → 作用于敌我边界和自由路径 → 行动目标从“出墙”迁移为“怎样处理墙外世界”。  
   - 对应：`zn`锚点保持，目标对象改变。
   - 定位：第22卷。

4. **马莱公开把Paradis塑造成世界威胁** → Eren提前潜入并在Willy Tybur演说现场变身攻击 → 作用于平民、马莱军队和战锤巨人 → 主体权能公开压进政治舞台，迫使同伴跟进撤离。  
   - 对应：`zx + xn`。
   - 定位：第25—26卷。

5. **Zeke提出自己的Eldian解决方案并需要始祖接触** → Eren利用合作抵达Paths，却在获得条件后抛弃Zeke方案、争取Ymir并唤醒墙中巨人 → 作用于Zeke计划、Ymir和始祖权限 → 外部路线被Eren改写为自己的地鸣方向。  
   - 对应：`zn + xn + x + zx`；也是反对`nx`主位的强证据。
   - 定位：第31卷。

6. **地鸣已经启动、墙外生命成为自由方案的代价** → Eren继续驱动巨人群前进，直到Armin、Mikasa等人正面对抗 → 作用于墙外城市、人群、朋友关系与巨人循环 → 他成为世界最恐惧的人，内部自由标准扩张为大规模支配和毁灭。  
   - 对应：晚期`x+zx`高显影。
   - 定位：第32—34卷。

### 2.3 模式、反证、关系与作品主维

**行为模式总结**：Eren先以内部自由标准决定“不能留在笼中”，再训练、潜伏和组织接触条件；当获得始祖权限后，把墙中巨人与世界级暴力纳入自己掌握，以公开权能强迫现实进入他的自由方案。

反证：

- 未来记忆和Paths让他沿已见图景推进，形成高`nx`状态；但他背叛Zeke并重写军方路线，说明方向决定权并未稳定交给外部。
- 地鸣非常像`x`，但`x`证据必须落在始祖权限和墙中巨人的实际控制，不能再写成“欲望吞噬”。
- 他会推开朋友并让他们成为终局对手，说明`nz/n`关系并非主位。

关系：

- **`zn克xn`候选**：Eren的自由标准通过拒绝军方“有限地鸣”与Zeke方案，改写两套长期计划的路径和持续条件；第三因素包括未来记忆与世界战争威胁，因此暂不升正式关系。

与作品主维：

- 部分相关但不一致。Eren的`xn/zx`行动是作品因果链的重要发动端，但人物稳定主位更接近`zn`。
- 作品命运次维主要来自历史、继承和未来记忆对选择空间的收束；不能把它直接算成Eren人物`xz+nz`。
- 复核：第1、22、25—27、30—34卷。
- 写入：主角索引、因果页、命运次维备注、任务机两条Eren相关行；旧角色卡加降权门控。

出版方核验：[Kodansha系列总页](https://kodansha.us/series/attack-on-titan/)、[第26卷](https://kodansha.us/series/attack-on-titan/volume-26/)、[第31卷](https://kodansha.us/series/attack-on-titan/volume-31/)、[第34卷](https://kodansha.us/series/attack-on-titan/volume-34/)。

## 3. Vinland Saga｜Thorfinn

### 3.1 对象、阶段与判断

- 身份：Thors之子、复仇战士、奴隶、Vinland开拓计划组织者。
- 阶段：童年听Leif讲述Vinland至自由后组织西行计划。
- 来源：[[漫画库总索引]]的本体型93分追加证据。
- 当前状态：作品本体主候选93分、无现行机器任务；人物层阶段迁移轻筛完成。

| 阶段 | 主十元 | 置信度 | 次十元 / 对象端点 |
|---|---|---:|---|
| 复仇期 | `zx` | 92% | `xz`87%；以战斗能力直接逼近Askeladd，危险佣兵团是长期状态 |
| 农场后 | `zn` | 95% | `xn`91%、`n`86%；“真正战士不需要剑/建立无战争无奴隶之地”的内部意义，组织劳动、资金、航线和同行者 |

具体端点：

- `xn`：农场收成、赎身目标、资金、船、航线、成员与Vinland建居计划。
- `n`：同行的Gudrid、孤儿、狗以及落入队伍的具体生命；接住后继续带在路线上。

### 3.2 行为证据

1. **童年从Leif听到无战争的西方土地** → Thorfinn反复把Vinland保留为墙外世界的具体想象 → 作用于个人未来与父亲家庭记忆 → 在复仇结构之外留下另一条长期方向。  
   - 对应：后期`zn`种子，不能单凭童年幻想提前锁主位。
   - 定位：第1卷。

2. **父亲被Askeladd的佣兵团杀死** → Thorfinn留在杀父者队伍、不断战斗并争取决斗机会 → 作用于Askeladd、佣兵战场与自身技能 → 复仇目标把危险生活转成直接权能增长。  
   - 对应：早期`zx + xz`。
   - 定位：第1—4卷。

3. **Askeladd被处决，复仇对象突然消失** → Thorfinn失去行动方向并被投入奴隶劳动 → 作用于身份、战斗能力与未来路径 → 早期`zx`失去目标，人物进入低主导/高承载状态。  
   - 对应：`nx/n`状态，不证明稳定本体。
   - 定位：Deluxe第4卷所收农场篇开端。

4. **农场劳动提供以收成赎身的可能** → Thorfinn和Einar持续清林、耕作，把劳动积累成买回自由的资源 → 作用于土地、收成、时间和赎身条件 → 从即时战斗转向可持续组织。  
   - 对应：`xn`。
   - 定位：英版第5—6卷。

5. **奴隶生活与突发悲剧迫使他回答是否还想活** → Thorfinn重新理解父亲“真正战士不需要剑”，不再把杀敌当成存在方式 → 作用于自己的武力用途、敌人定义和未来 → 内部意义从复仇重构为不以暴力制造敌人。  
   - 对应：稳定主位迁移到`zn`的核心证据。
   - 定位：Deluxe第4卷/农场篇。

6. **获得自由但战争与奴隶仍持续存在** → Thorfinn决定筹资、组队并前往Vinland建立无战争无奴隶的土地；途中接纳逃离婚姻的Gudrid、孤儿和狗 → 作用于资金、航线、同行者与新聚落目标 → 内部信念被组织成跨海项目，并扩大队伍承载范围。  
   - 对应：`zn + xn + n`。
   - 定位：英版第7—8卷。

### 3.3 模式、反证、关系与作品主维

**行为模式总结**：早期Thorfinn用战斗权能追杀一个复仇对象；对象消失后，他在劳动和创伤中重建“真正战士”的内部意义，再把土地、资金、航线和同行者组织成无战争聚落。

反证：

- 复仇期长期、主动且高体量，不能用后期`zn`覆盖成“一开始就是和平主义者”。
- 后期仍需要谈判、护卫和现实资源，`xn`不是单纯服务标签，而是让信念能够落地的强次位。
- 接纳同行者可能由旅行偶发与Leif团队共同造成，`n`暂不升主位。

关系：

- **`zn生n`候选**：无敌人/无奴隶的内部意义扩大“哪些生命可以被队伍接住”的范围；目标变量是同行者的接纳边界。第三因素Leif团队和旅行偶发仍需逐卷排除。

与作品主维：

- 后期人物`zn`与作品本体主候选高度一致；早期`zx`则是作品用来制造反证的阶段。
- 人物迁移不能自动确认作品93分或正式归仓，本轮不新建机器评分。
- 复核：第1—8英版合订卷，重点农场篇与Vinland筹备段。
- 写入：主角索引、总索引本体比较行/追加说明。

出版方核验：[Kodansha系列总页](https://kodansha.us/series/vinland-saga/)、[Deluxe第4卷](https://kodansha.us/series/vinland-saga-deluxe/volume-4/)、[第7卷](https://kodansha.us/series/vinland-saga/volume-7/)、[第8卷](https://kodansha.us/series/vinland-saga/volume-8/)。

## 4. 宝石之国｜Phosphophyllite（Phos）

### 4.1 对象、阶段与判断

- 身份：最脆弱的宝石、博物志编写者、战士、月球真相调查者与后期祈祷推动者。
- 阶段：渴望参战至组建月球队伍、强迫Kongō祈祷。
- 来源：[[漫画库总索引]]命运主/本体次/空间辅比较行。
- 当前状态：作品无正式机器评分、命运主候选；人物层阶段迁移轻筛完成。

| 阶段 | 主十元 | 置信度 | 次十元 / 对象端点 |
|---|---|---:|---|
| 前期 | `z` | 92% | `nz`86%、`xz`状态；希望Sensei和同伴确认自己有用、能参战，同时想为Cinnabar找到位置 |
| 中后期 | `xn` | 92% | `zx`90%、`x并z`88%身份结构；组织真相调查、月球沟通、离队成员与祈祷方案 |

具体端点：

- `z`认可端：Kongō/Sensei、其他宝石、战斗搭档；被认可内容是“我有用、能承担任务”。
- `xn`对象：博物志任务、Cinnabar工作线、月球路线、离队者、Lunarian条件与Kongō祈祷节点。
- `x并z`结构：磷叶石身体不断被新材料、Lapis头部替换，外显“Phos”身份与内部记忆/构成出现分层；这是身份结构，不是行动欲望。

### 4.2 行为证据

1. **Phos渴望参战，却因脆弱被分配编写博物志** → 接下任务并在调查中主动接触被孤立的Cinnabar → 作用于自身有用性、博物志与Cinnabar的位置 → 一个低认可任务被转成寻找同伴新工作的关系目标。  
   - 对应：前期`z + nz`，任务组织尚处萌芽。
   - 定位：第1卷。

2. **陆地上找不到适合Cinnabar的工作** → Phos接受Ventricosus线索、转向海中继续寻找 → 作用于海域、Cinnabar工作线与自身易碎身体 → 为关系目标进入不适合宝石的危险环境。  
   - 对应：`nz`定向，`xz`风险行为。
   - 定位：第2卷。

3. **身体变化后获得新手臂和更强战斗能力** → Phos接受Bort的搭档邀请并进入战斗位置 → 作用于同伴评价、战斗资格与新身体 → “被认为有用”的认可突然上升。  
   - 对应：`z`高显影，`zx`为行动功能。
   - 定位：第4卷。

4. **与Ghost Quartz搭档时遭Lunarians持续进攻、Phos被固定无法行动** → Phos与搭档共同撑到救援条件出现 → 作用于Ghost关系、战场与自身身体 → 新搭档关系再次被战争伤亡测试。  
   - 对应：`xz`状态、`n/nz`候选；具体主动动作待第6卷原页。
   - 定位：第6卷。

5. **多次战斗和身体替换仍没有解释Lunarians与失踪同伴** → Phos主动踏上月球，尝试与一直被当作敌人的Lunarians沟通 → 作用于敌我边界、月球信息和真相路径 → 解决方式从重复战斗转成主动组织信息和谈判入口。  
   - 对应：中期`xn`，并形成`xn克zx`阶段候选。
   - 定位：第8卷。

6. **月球真相显示被带走的同伴可能复原，但需要完成Lunarians目标** → Phos组建离队宝石队伍，后来为使Kongō祈祷而回到地球发动强攻 → 作用于同伴、月球/地球阵营、Kongō和祈祷条件 → 调查结构逐步变成“无论代价也要完成节点”的组织与直接压制。  
   - 对应：`xn`主、后期`zx`高显影。
   - 定位：第9、11—12卷。

### 4.3 模式、反证、关系与作品主维

**行为模式总结**：Phos早期通过任务、战斗和同伴回应证明自己有用；身体与关系不断破碎后，认可需求转成对真相和解决方案的主动组织，最终又把组织失败推成强制祈祷的直接行动。

反证：

- 前期寻找Cinnabar工作带`nz`，说明“想被认可”不是唯一驱动。
- 后期强攻Kongō的`zx`极强，但它出现在长时间调查、组队和月球方案之后，暂不覆盖`xn`。
- 身体构成变化使`x并z`高体量，但身体被替换多由他者和战损造成，不能直接证明人物主动维持身份壳。

关系：

- **第8卷`xn克zx`阶段候选**：主动建立月球沟通与信息路线，暂时压低“见到Lunarian就直接战斗”的解决路径；目标变量是敌我处理方式。第12卷又回到强攻，关系不能跨阶段继承。

与作品主维：

- 人物`z→xn`迁移不等于作品命运型。
- 作品命运/本体证据更多来自身体持续替换、关系断裂、月地归宿和“Phos是否仍是Phos”；其中身体身份结构不能反向证明人物主`x并z`。
- 复核：第1—2、4、6、8—9、11—12卷。
- 写入：主角索引、总索引命运比较行；保持无机器评分状态。

出版方核验：[Kodansha系列总页](https://kodansha.us/series/land-of-the-lustrous/)、[第2卷](https://kodansha.us/series/land-of-the-lustrous/volume-2/)、[第8卷](https://kodansha.us/series/land-of-the-lustrous/volume-8/)、[第9卷](https://kodansha.us/series/land-of-the-lustrous/volume-9/)、[第12卷](https://kodansha.us/series/land-of-the-lustrous/volume-12/)。
