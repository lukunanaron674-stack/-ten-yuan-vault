  - 归类：z（阴火，主位证据，93%）。对象端点：神社入口的最高裁定与刀簪阵。
- 行为3：同伴雷人被忍者集团的伏兵包围 → 神楽没有正面救出，而是按先前约定潜入忍者集团后台的账簿处、把忍者集团过去五年的暗杀账簿外带到本地神社 → 作用于忍者集团后台与暗杀账簿 → 账簿在神社被公开，同盟势力涌入忍者集团。
  - 归类：xn（阳金，主位证据，96%）。对象端点：忍者集团后台与暗杀账簿外带流程。
- 行为4：同盟势力涌入忍者集团但内部有分歧 → 神楽把暗杀账簿按受害家属性质分类、按年月排成表格、贴在神社入口两侧 → 作用于同盟势力与账簿分类 → 同盟按分类各自认领，无人重复追讨。

- 行为5：忍者集团首领主动现身谈判、按规矩单挑 → 神楽按父母生前教过的刀型退让一步、用母亲的发簪绑住刀柄 → 作用于刀型与发簪 → 首领被母型刀簪绊住，神楽按住首领脖颈。
  - 归类：n（阳土，主位证据，91%）。对象端点：父母生前刀型与发簪承载。
- 行为6：首领倒下后同盟要扩大追杀 → 神楽在神社门口立木牌写明'仇已毕、勿再追、再追即与我为敌' → 作用于同盟追杀木牌与庙门 → 一个月内同盟无人跨越木牌。

## 二、ムサシノ輪舞曲 · 武蔵（ムサシノ，年轻剑客）

- 行为1：武蔵被长野的旧家族作为代理剑客请到馆林 → 武蔵在馆林城门外当夜把剑谱摆开三本、按对手家族分别研读、标注可暴露的破绽 → 作用于剑谱与对手家族破绽 → 第二天对手家族先于城门外见到破绽标注。
  - 归类：xn（阳金，主位证据，92%）。对象端点：剑谱与对手家族破绽标注流程。
- 行为2：对手家族看到破绽后主动提出按破绽反手修正 → 武蔵按对方修正后的破绽反向再标第二轮破绽 → 作用于对手修正与第二轮破绽 → 对手再次反手修正后破绽归零。
  - 归类：xn（阳金，主位证据，95%）。对象端点：修正与破绽双向收敛流程。
- 行为3：馆林城主以剑客为饵请各路剑客参加园游会 → 武蔵拒绝以个人名义参赛、要求以家族为单位参加、按家族分成若干阵 → 作用于家族参赛单位与园游会分组 → 园游会改为家族对阵赛制。
  - 归类：xn（阳金，主位证据，93%）。对象端点：家族对阵赛制与分组流程。
- 行为4：园游会当日馆林城旧雨降至 → 武蔵让各家族按剑客年龄分三阵、按降雨节奏打三阵 → 作用于剑客年龄与降雨节奏 → 三阵按节奏交迭，未出现积水。
  - 归类：xn（阳金，主位证据，91%）。对象端点：三阵交迭与降雨节奏流程。
- 行为5：园游会结束、城主欲留武蔵 → 武蔵让师妹代回家族、用书信把与馆林的关系维持在家族书信网络内 → 作用于师妹代回与家族书信网络 → 师妹按书信回城，馆林关系写入家族网络。
  - 归类：nx（阴金，主位证据，90%）。对象端点：家族书信网络与馆林既有通道。
- 行为6：武蔵回长野途中被问起是否要继承家中剑术 → 武蔵把家中刀剑名册按母亲家与父亲家分行写明、写明每人归属与不归属 → 作用于家中刀剑名册与归属 → 名册被家中按行悬挂于刀架。
  - 归类：x（阴水，主位证据，89%）。对象端点：家中刀剑名册与归属支配。
