## 一、霜 · 主维归属

**霜判：因果型 zx+nx（局势博弈 / 暗流推动）**
**置信度：9/10**

### 归属理由

Liar Game 的每一轮游戏（少数决、15人Vote、4人寻宝、病毒感染等）都是一张精心设计的因果网络——每个玩家的选择产生连锁反应，一步错步步错。秋山深一的每一个反制策略不是破坏规则，而是**在规则内部发现更深的因果链**，然后用 zx 的执行力精确拆解。

核心力学：
- **nx（结算/推算）**：每一轮游戏的核心不是谁更聪明，而是谁**先算到对方的结算路径**。秋山永远比对手多算三步——他知道对方知道他知道的递归博弈。
- **zx（执行/破局）**：算到了不等于赢了。秋山必须在精确的时机执行反制——造波、死角投票、逆向博弈，每一个动作都是 zx 的「执行即意义」。
- **x 与 x并z 作为辅力**：对手的贪婪（x）是秋山利用的杠杆；李吕（「革命的失败者」等伪装身份）体现了 x并z 的壳层。

Liar Game 不是「好人错信坏人」（本体型），也不是「命运安排的相遇」（命运型），而是**每一步选择都不可逆地在因果网络中引爆的精密推演**。

### 误判防线

| 易误判为 | 为什么不是 | 颜色等级 |
|:---------|:-----------|:--------:|
| 命运型 xz+nz | 「遇到秋山」像是命运相遇，但作品核心不是宿命，而是**因果递推**。每一轮的结果由前一轮的选择决定，没有模糊的「命运之力」。秋山能反转不是因为宿命，因为他计算到了 | 🔴 |
| 本体型 zn+x | 神崎直的「善良」容易让人想到存在/信仰驱动，但主线不是她如何燃烧，而是**她如何参与因果博弈**。最大变量不是她的内心燃烧，而是她的纯真如何改变了秋山的结算公式。本体型只存在于角色的动机层面，不在结构层面 | 🟡 |
| 时间型 xn+z | 大部分游戏有时限，但时间不是叙事结构，而是游戏规则。核心不是「在正确时刻做正确的事」，而是「在正确的关系中做正确的选择」。Liar Game 没有数到秒的节拍感，有反推几步的因果树 | 🟢 |

### 体量

**体量：9/10**

体量不是力量——Liar Game 的体量体现在它对心理博弈漫画品类的影响力。作为 Young Jump 2005-2015 的代表作之一，它定义了「规则内博弈 × 精密推演」的子类型。MAL 8.24 / 127K members 表明它在海外的持久影响力（尤其是英语读者圈）。它的续作 Roots of A（番外短篇集）MAL 7.23，体量中等。

### 关系五对查位置盘

查盘起点：zx + nx（因果型双主链）

**从 zx 出发（查5边）：**

| 关系 | 对子 | 强度 | 作品说明 |
|:----|:----|:----:|:---------|
| **生** | zx → zn | 7 | 秋山的执行（zx）生成意义（zn）——不是为了赢而赢，而是他的执行让「信任」和「公平」成为可能。最终结算时，他用zx帮神崎直把「信赖」变成现实，这个过程生出意义 |
| **被生** | xz → zx | 8 | 秋山的 xz 背景（冤狱、被社会抛弃的临界处境）生出了他的 zx——他必须精密执行才能复仇/证明清白。Liar Game 的参赛资格本身也是 xz 处境（巨债压力→被迫执行） |
| **克** | zx → n | 7 | 秋山的精密执行会打破神崎直的「平稳容器」——每当他算出精妙的反制，神崎直的常识世界就被震碎一次。zx 对 n 的克制体现在「一个人的精准是另一个人的不安」 |
| **被克** | xn → zx | 9 | Liar Game 的规则（xn）是秋山最大的约束——他不能在规定动作之外获胜。每一次反制都必须严格遵守游戏规则（否则淘汰）。xn 严格地克制着 zx 的自由度 |
| **补** | zx ↔ nx | 10 | **核心对子**。秋山如果只有 zx（执行）没有 nx（推算），他会像一头撞进迷宫的蛮牛；只有 nx 没有 zx，他只是一个纸上谈兵的数学家。zx + nx 补在一起才是 Liar Game 的神髓——「算出路径 + 精确执行」 |

**从 nx 出发（查5边）：**

| 关系 | 对子 | 强度 | 作品说明 |
|:----|:----|:----:|:---------|
| **生** | nx → x | 8 | 秋山的结算能力（nx）生出了对手的欲望（x）——他知道对手想要什么、怕失去什么，用他的nx计算激活对手的x，让对手自己把自己出卖。每一轮，对手的贪婪都是秋山用nx「生」出来的 |
| **被生** | nz → nx | 6 | 神崎直的「等待/信任」（nz）在一定程度上让秋山的结算变得复杂——他开始算神崎直的账（安全离开≠赢钱）。nz让nx从纯自保变成了包括他人的结算 |
| **克** | nx → x并z | 8 | 秋山的清算（nx）剥掉了对手的伪装（x并z）——李吕的「革命失败者」外壳被他看穿、艾莉的「疯癫小丑」面具被他识破。nx是最好的剥壳器 |
| **被克** | z → nx | 6 | 神崎直奔涌的「冲动」（z：相信秋山、相信善、相信正确的事）能够在关键时刻反过来影响秋山的结算——让他从纯nx的计算模式切换到「给信任一个机会」。z 略克 nx 的过度计算 |
| **补** | nx ↔ zx | 10 | 同前。nx 算到，zx 做到 |

### 关系对子

**主对子：zx + nx（执行 + 结算）— 平均强度 10**

这是因果型（zx+nx）的标准核心对子，Liar Game 是教科书案例。秋山做两件事：① 算出对方的一切可能性（nx）；② 在精确时机执行反制（zx）。缺一则故事不成立。

**第二对子：xn → zx（规则克制执行）— 强度 9**

每一轮游戏都有精确的规则框架（xn），秋山从不试图破坏它们——他在边界处发现规则的盲区，用规则内部的漏洞执行 zx。「少数决」中他知道规则只要求投票不要求说的话是真的，所以他用虚假的承诺换取了真实投票。

**第三对子：nx → x（结算生出欲望）— 强度 8**

Liar Game 最经典的叙事模式：秋山通过 nx 计算出对手的欲望结构，然后引诱对手在欲望驱动下自我暴露。秋山不是在对抗对手——他在引导对手对抗自己的 x。

### 动态链

```
起手(nx·秋山推算对手的结构·准度9)
↓ nx→x
第一步·引蛇出洞(强度8)：秋山用nx算出对手的欲望结构→故意暴露破绽→让对手的x被激活
↓ x→x并z
第二步·伪装剥落(强度7)：对手的欲望暴露后，伪装(x并z)剥落→露出真实的博弈位置
↓ nx→zx
第三步·路径确定(强度9)：秋山确认可执行的精确路径——他知道在哪一步做什么
↓ zx→xn(被克)
第四步·规则边界执行(强度9)：在规则的严格限制(xn)下执行反制——必须合规、必须零擦边
↓ zx→zn(生)
落点·意义生成(强度7)：赢不是终点——让神崎直的「信任」被验证、让对手被迫面对自己的选择
```

**动态链总强度：(9+8+7+9+9+7)/6 = 8.2 / 10**

**结果类型：回收型** — 每一次博弈的落点不是毁灭或停滞，而是**结算归位**：债务清零、信任被验证、游戏回归起点。秋山的行动链最终回收成一个封闭的系统——Liar Game 的终局是所有参与者都离开，没有赢家，也没有输家。

## 六、可复用素材（创作体系）

### 素材 1：nx 剥壳术（角色的结算结构）
Liar Game 的每个对手出场时都带着 x并z 的伪装（百发百中的赌徒/虔诚的宗教领袖/革命的失败者），秋山通过 nx 结算他们的行为模式，逐个剥掉伪装。**这是 nx → x并z（结算剥壳）的教科书操作**。在设计推理/博弈故事时，可以用此结构：先让对手藏（x并z），主角算（nx），找到破绽后执行（zx）。

### 素材 2：规则边界执行（xn内部的zx）
秋山最精彩的策略不是在规则之外，而是在规则边界处找到逻辑的盲区。**少数决的撒谎换票、15人Vote的故意多投、病毒游戏中「主动感染」的解药逻辑**——这些技巧的本质是：在 xn（规则）的内部找到执行（zx）的缝隙，而不是试图打破规则。这是一个极好的叙事类型：角色在严格受限的环境中，用系统的语言反杀系统。

### 素材 3：回收型动态链（付出-结算-归零）
Liar Game 的每一轮都遵循「起手nx → 对手x被激活 → 秋山zx执行 → 结果收束」。终局更精妙：不是秋山赢了大钱，而是**所有债务清零**——zx+nx 的落点是回到 n 的容器（所有人安全退出）。这正是「回收型」动态链的特征：执行不是为了获取，而是为了让系统归零。这在创作中可以作为一种「闭环叙事」模板使用。

### 素材 4：「被结算者」角色（神崎直的人物设计）
神崎直在功能上不是主角，而是**秋山计算的基础假设**。她代表了 n（诚实/容器/不被欲望侵蚀的核心），这个角色存在的意义不是做决定，而是让秋山的 nx 不能只算自己的账——他必须算她的安全。这种「被结算者」的角色类型可用于任何博弈/策略故事中：一个让主角的计算成本上升的角色，恰恰是让故事有温度的角色。

### 素材 5：对手结构的分层（x层与nx层的落差）
Liar Game 的对手可以分为两种：被自己的 x 吃掉的（前期对手，只想要钱→被秋山用钱引诱）和有自己的 nx 体系的（中期对手如李吕，能算到秋山的第三步→需要第四步）。这种分层可以作为因果关系层面的强度标尺——对手的 nx 层数决定了博弈的层级。
