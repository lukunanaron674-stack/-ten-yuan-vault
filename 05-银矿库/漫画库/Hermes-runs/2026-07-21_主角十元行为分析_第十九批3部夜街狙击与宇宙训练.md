## 一、《みいちゃんと山田さん》

### 分析对象与范围

### A. みいちゃん

#### 十元判断与对象端点

- **主十元：`nx` 94%**。端点是夜店岗位、与男友Mao的恋爱/供养关系、山田提出的同居与“普通工作”路线；方向多由工作、关系或他人给出，未衣沿该路线继续。
- **次十元：`n` 91%**。端点是识字与社交困难、嘲笑、受伤、失业/转职压力和日间工作冲突；事情反复落到她身上，她以继续工作和适应来处理。
- **补位/功能候选：`nz` 88%**。端点限于她不愿结束的Mao关系，以及后来想保留的山田共同生活；“被控制”本身不等于`nz`，需原卷确认她是否主动维持关系余温。
- **关系判断**：本轮不宣布正式生补克。`nz生nx`只存在顺序候选：不愿结束关系可能使她继续沿Mao路线，但经济依赖、暴力和生存条件都是同等强度的第三因素。

#### 可观察行为证据

1. **进入夜店却读不顺汉字、也抓不住社交暗示 → 未衣仍反复上班并尝试接客 → 作用于既定岗位和顾客关系 → 在被嘲笑/怜悯的环境里继续沿工作路线。**（第1卷；`nx + n`）
2. **未掌握店内隐私边界 → 未衣向客人说出真名、未经允许发布女孩照片 → 作用于同事与店铺规则 → 被当成“麻烦人物”并逐渐遭到回避。**（第2卷；负向边界证据，不单独证明十元）
3. **连续出错并被同事疏远 → 未衣没有立即退出，而是继续熟悉接客 → 作用于夜店流程和顾客 → 逐渐适应工作并增加客人。**（第3卷；`n`，具体适应步骤待原卷）
4. **带伤出现在店里、生活状态失控 → 未衣接受山田到家照料，并说出童年片段 → 作用于身体、住处与过去经历 → 原本封闭的伤害进入一段可被承接的关系。**（第3—4卷；`n + nx`）
5. **无法与施暴男友Mao切断 → 未衣离开原店、转入更高风险的性工作并把钱交给他 → 作用于自己的工作路线、收入和恋爱关系 → 有害关系继续规定她的行动方向。**（第4—5卷；`nx`，`nz`候选）
6. **与山田开始共同生活、被建议尝试“普通工作” → 未衣进入日间世界并在冲突中继续尝试 → 作用于新岗位与两人日常 → 外部关系给出的新路线逐渐替代旧夜街路线。**（第5—6卷；`nx + n`）

#### 行为模式总结

当工作或关系给出一条路线时，未衣会沿着它继续并吸收失败、嘲笑和伤害；旧路线很难由她独自截断，直到另一段关系提供可进入的新通道。

#### 反证

- 未衣的持续努力可以显示`n`，但公开简介没有证明她主动搭建稳定计划、流程或资源结构，因此不升`xn`主位。
- 泄露姓名和照片是规则理解/边界失败，不能反向证明“坦率”“自由”或任何十元。
- 对Mao的依附可能包含恐惧、经济和暴力控制；在未取得她主动维持关系的原页前，`nz`只保留候选。

### B. 山田さん

#### 十元判断与对象端点

- **主十元：`n` 95%**。端点是未衣的失误、受伤、童年叙述、失踪及共同生活中的摩擦；这些问题落到山田这里后，她持续看、听、照料并回应。
- **次十元：`xn` 92%**。端点是护理、住处、同居规则与日间工作路线；山田把一次次危机组织成可以继续运转的生活安排。
- **功能候选：`zn` 86% / `nz` 88%**。她在他人回避未衣时仍认真交谈，可能有不取决于回报的内部判断；她也不愿让关系断掉。但公开书目不足以锁定稳定内在信念或柔情停靠主位。
- **关系判断：`n生xn`候选93%**。未衣的问题先进入山田的承接端，再经护理、同居和工作建议变成下一步生活结构；被改变的变量是未衣可进入的日常路线。未衣自己的选择、住房和就业条件属于第三因素。

#### 可观察行为证据

1. **同事把未衣当笑料或麻烦而远离 → 山田仍与她正常交谈并持续关注 → 作用于未衣的店内关系位置 → 未衣至少保留一个不只把她当异类的回应接口。**（第1—2卷；`n`，`zn`候选）
2. **未衣打碎杯子后受挫 → 山田画图鼓励她，并给出不易打碎的杯子 → 作用于未衣的失败体验和具体工作物件 → 一次失误被转成可继续工作的条件。**（讲谈社官方编辑部介绍；`n生xn`候选）
3. **未衣带伤出现 → 山田前往她家照料 → 作用于未衣身体与生活现场 → 店内观察转成实际护理。**（第3卷；`n`）
4. **未衣断续讲出童年记忆 → 山田不抢走叙述，而是安静听下去 → 作用于未衣的过去与两人信任 → 山田成为伤害可以落下并被保留的承接位置。**（第3—4卷；`n`）
5. **未衣离店、两人各自受扭曲依赖影响 → 山田与她开始同居，并提出尝试普通工作 → 作用于住处、工作和每日安排 → 两人把夜街外的生活组织成可反复实践的新结构。**（第5—6卷；`n + xn`）

#### 行为模式总结

未衣的失误、伤害或叙述落到山田面前时，山田先接住、听和照料，再把危机压成杯子、护理、住处或工作等具体生活结构。

#### 反证

- 山田不是未衣全部变化的唯一原因；未衣自己的选择、工作制度、住房和社会支持都必须单列。
- 照顾弱者不自动等于`zn`；只有原卷能证明她在无认可、无回报甚至受惩罚时仍由同一内部意义驱动，才可提高`zn`。

### 双人物与作品主维关系

- 人物层的主链更接近“未衣沿外部关系推进并承受后果（`nx+n`）—山田承接问题并组织日常（`n+xn`）”。现有公开证据没有把两人任何一位稳定锁成`zn+x`。
- 因此，本体100分仍作为作品层历史判断保留，但人物层触发“本体公式是否来自人物存在、关系结构还是叙事主题”的二审；不改评分、不移仓。
- **复核**：第2卷隐私事件的动机；第3卷受伤与护理动作；第4—5卷离店/重逢过程；第6卷普通工作的具体安排与冲突。
- **建议写入位置**：人物索引、本体主题页、总索引100分行；章节证据补齐后再决定是否新增维度冲突队列。

## 三、《ありす、宇宙までも》

### B. 犬星類

- **次十元：`z` 90%**。端点是数学竞赛等公开成绩和太空营的比较位置；他已能获得能力确认，却也因性格被同学疏远。
- **功能位**：`n` 85%（接住Alice的身体/学习困境）；`zx`候选84%（竞赛能力公开显现，但尚无持续扩权证据）。
- **关系判断**：本轮不宣布`xn补z`。他的竞赛获胜与组织能力只在书目中并列，尚未证明计划具体补足了他自己的认可位置；对Alice的帮助也不能跨对象直接写成犬星自身`z`的补位。

#### 可观察行为证据

1. **Alice被当成语言差、学习落后 → 犬星识别双语教育中断问题，并明确提出“让她变聪明” → 作用于语言障碍和学习材料 → 模糊评价被重排成可处理的学习项目。**（第1卷；`xn`）
2. **Alice需要进入宇航员选拔工作坊 → 犬星启动能力开发项目 → 作用于训练步骤和选拔节点 → Alice的能力被导入预选到决赛的路径。**（第2卷；`xn`，项目细节待原卷）
3. **父母忌日使Alice身体/精神失调 → 犬星提出去种子岛看火箭发射，并与她处理途中障碍 → 作用于出行、时间和宇宙目标 → 失速状态被接回下一段行动。**（第3卷；`xn + n`）
4. **自身过去的人物出现、情绪受到影响 → 犬星接受Alice为鼓励他提出的意外方案 → 作用于两人的互助位置 → 单向教导暂时转成双向支持。**（第4卷；`n`功能；方案内容待原卷，不把Alice动作记给犬星）
5. **太空营进入最终个人媒体训练 → 犬星成为Alice直接面对的天才对手 → 作用于公开能力比较与候选者位置 → 他的成绩/能力再次进入外部检验场。**（第6卷；`z`；比赛结果待原卷）

#### 行为模式总结

犬星看到问题后会先命名和拆解，再把材料、训练、行程和测试排成可运行项目；当Alice进入同一认可场时，他又从组织者变成被比较、被回应的对手。

#### 反证

- “天才”“每次比赛都赢”是能力与结果，不自动证明`xn`；本轮主位主要来自他对Alice反复发起项目、安排路线的动作。
- 同学疏远说明认可关系受阻，但不等于他一定由`z`驱动；需要原卷确认竞赛认可对其自我成立的重要性。

### 双人物与作品主维关系

- Alice主`n`、次`xn`，犬星主`xn`、次`z`，人物接力明显靠近“承接压力—组织训练—进入认可场”的时间运行机制。
- 库内正式条目仍是空间主86分，无标点旧批次是本体89分；人物层不能直接改仓，但足以把“空间/本体别名冲突”升级为“别名已锁、作品空间—时间主位待二审”。宇宙不是人物十元，训练节拍也不自动等于作品时间主维。
- **复核**：第1卷学习计划分工；第2卷项目由谁组织；第3卷种子岛路线；第5卷母语沟通的具体动作；第6卷媒体训练评价与两人认可位置。
- **建议写入位置**：人物索引、空间主题页、无标点本体行、总索引86/89两行和同名冲突复审队列。
