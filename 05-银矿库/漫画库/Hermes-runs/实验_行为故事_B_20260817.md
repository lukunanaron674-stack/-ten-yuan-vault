# 行为故事生成实验（子代理 B）

子代理B实验输出，2026-08-17，L1 口径。

场景偏日常/社会/家庭，与子代理 A 的战斗冒险场景形成对照。每条故事均为原创，不引用真实漫画；一条故事只标一个核心，不"一鱼多吃"。金轴口径：阳金 xn ↔ 阴金 z。

## 一、十元行为核心（第 1–10 条）

### 1. ZX 阳木｜直接显权凌驾

- **故事标题**：消防通道的那张批复
- **剧情**：深夜物业锁死消防通道，业主群吵了一夜 → 业主代表小周在物业联席会上当场出示三年前住建批复，拍桌要求立刻开门 → 作用于物业、批复原件、全楼通行权 → 物业当众整改并道歉，全楼通行权被直接改写。
- **命中核心**：ZX 阳木
- **生成难度**：易

### 2. NX 阴木｜沿既有方向推进

- **故事标题**：父亲的面馆规矩
- **剧情**：父亲退休前把面馆规矩留给儿子：汤头熬足三小时，客人进门先迎一声 → 儿子不另起炉灶，按流程每天照做 → 作用于老顾客、既有流程与店面口碑 → 老顾客认账，面馆沿原轨道继续开下去。
- **命中核心**：NX 阴木
- **生成难度**：易

### 3. ZN 阳火｜并存赋义

- **故事标题**：署你名字
- **剧情**：课题组只剩一个汇报名额，最慢的实习生被点名要刷掉 → 老陈把自己做完的课题让出，说"署你名字，你上台讲" → 作用于实习生、课题署名、汇报资格 → 实习生独立讲完被保留进组，课题成果照旧成立。
- **命中核心**：ZN 阳火

### 4. X 阴火｜资源归我掌握

### 5. N 阳土｜承载回应

## 二、五行轴行为核心（第 11–15 条，一轴两端对照）

## 三、实验结论（子代理 B）

1. **15 条核心全部可生成具体行为故事**：是。每条都能落成一个"触发 → 动作 → 对象 → 可观察结果"的单场景。
2. **难度分布**：易 6（ZX / NX / X / N / XN / Z）、中 5（X并Z / XZ / NZ / 木轴 / 金轴）、难 4（ZN / 火轴 / 土轴 / 水轴）。
3. **最易具体化**：ZX 显权（出示批复即可）、X 资源掌握（钥匙/话筒/时间表等实权物）、XN 组织（进度表/节点清单天然是动作）。这三类动作外显强、模板多。
4. **最难具体化**：
   - ZN 并存赋义——极易滑向"牺牲/奉献"，或被误读成 N 承载；需要锚点"他者资格被并列保留且不被吞并"（本例用署名让出）。
   - 土轴——n 与 x并z 容易写成同义反复的"内在 vs 外在"；必须给 x并z 一个"被第三方识别"的结果（证件、铭牌）。
   - 水轴——xz 与 nz 容易滑成情绪化的"进/退"；必须各挂一个可观察物（卖房=收窄，钥匙=回返）。
5. **对核心表述的修改建议**：
   - ZN 建议改锚点为"他者资格与自身资格并列保存、不吞并不让渡"；
   - X 建议强制"支配物外显"（钥匙、名额、时段、话筒）；
   - NZ 建议强制"可回返物"（钥匙、字条、空位）作为对象端点，否则会写成情绪戏；
   - 五行轴（11–15）建议写成"同场景双人动作对照"，比两段独立小故事更紧凑、更能检验轴的两端是否真的对立。
