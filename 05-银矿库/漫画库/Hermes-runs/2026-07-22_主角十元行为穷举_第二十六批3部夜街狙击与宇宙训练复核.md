## 一、みいちゃんと山田さん

### 证据范围

- 人物：みいちゃん（未衣）与山田さん；2012年新宿歌舞伎町キャバクラ“Ephemere”阶段。
- 官方来源：讲谈社[官方编辑部第1卷介绍](https://news.kodansha.co.jp/comics/20151204)。
- 当前状态：官方介绍范围穷举，非全6卷穷举；100分及本体作品判断不动。

### A. みいちゃん：具体行为穷举（7条）

- 行为1：需要进入夜店工作 → 未衣来到Ephemere参加体验入店 → 作用于既有招聘与岗位入口 → 她进入店铺工作流程。
  - 归类：`nx`（主位证据，88%）。对象端点是店铺已经提供的体验入店路径和岗位流程；她未掌握方向设计权。
- 行为2：夜店要求使用源氏名与身份接口 → 未衣把真实姓名写出来并以此接客 → 作用于对客身份呈现 → 她把私人身份直接暴露在工作界面。
  - 归类：`x并z`（次位证据，87%）。对象端点是真名这一可见身份包装；本条不评价诚实或道德。
- 行为3：客人询问个人资料 → 未衣向客人公开姓名、LINE和住址 → 作用于私人信息与顾客接口 → 她的身份和联络边界被进一步公开。
  - 归类：`x并z`（次位证据，89%）。对象端点是姓名、联络方式、住址及其可见接口；公开不等于她取得`x`控制。
- 行为4：店内工作需要识字、记规则和稳定操作 → 未衣在反复被提醒后仍连续犯错 → 作用于工作步骤和物件 → 错误持续发生，但该事实只证明能力/规则理解不足。
  - 归类：暂不归类（证据不足）。失误不是稳定十元动作，不能反向包装成`n`、`zx`或`x`。
- 行为5：ココロ给她汉字练习册并开始教学习字 → 未衣参加这段学习 → 作用于别人已经安排的教材和学习过程 → 学习不到一周便中止。
  - 归类：`nx`（主位证据，84%）。对象端点是ココロ提供的练习册、教学关系和现成学习路线。
- 行为6：连续打碎店内杯子后，店里让她改用不易打碎的杯子 → 未衣接受该物件继续工作 → 作用于店铺提供的替代杯具和工作流程 → 她能够在调整后的条件下继续接客。
  - 归类：`nx`（主位证据，87%）。对象端点是店方给出的工具替代与现有岗位路线；杯子并非由她掌握和重组的资源计划。
- 行为7：山田的画使她受到鼓励 → 未衣表示要更努力工作并继续投入工作 → 作用于原有岗位和接客流程 → 后续仍出现严重麻烦。
  - 归类：`nx`（主位证据，86%）。对象端点仍是既有工作方向；“努力”不自动等于`n`，因为本条没有显示承载结构或主动组织机制。

#### 穷举后统计

- 计数：`nx`4、`x并z`2、暂不归类1。
- 主十元：`nx`90%；次十元：`x并z`86%。
- 撤回旧判：旧次`n`91%与`nz`候选主要来自“吸收伤害”“无法离开关系”等状态概括和本轮无法重新核验的后卷材料，不进入当前正本。
- 关系判断：不登记生补克。身份暴露与沿岗位推进在同一场景共现，但没有机制证明`x并z`生、补或克`nx`。

### B. 山田さん：具体行为穷举（5条）

- 行为1：夜店要求使用不直接暴露私人的工作身份 → 她以“山田”这一明显假姓在店内活动 → 作用于对客姓名和职业身份接口 → 私人身份与工作身份被分开。
  - 归类：`x并z`（身份功能证据，92%）。对象端点是假姓、工作身份和顾客可见界面。
- 行为2：面对过度干涉、具有控制性的母亲 → 山田离开原家庭，在东京独自生活 → 作用于居住地与亲子控制边界 → 她建立了与母亲分离的生活位置。
  - 归类：`zx`（行动功能证据，88%）。对象端点是离家这一主动切断动作；公开介绍不足以证明其形成持续权能扩张。
- 行为3：需要维持东京生活 → 山田在キャバクラ工作取得生计 → 作用于既有夜店岗位与收入路线 → 她以该工作继续独居。
  - 归类：`nx`（路线功能证据，86%）。对象端点是现成就业与收入流程；本条未显示她主动组织店铺规则或资源。
- 行为4：其他同事逐渐停止与未衣认真交流 → 山田仍继续和未衣正常说话 → 作用于未衣的店内关系位置 → 未衣保留一个持续回应她的人际接口。
  - 归类：`n`（主位证据，91%）。对象端点是持续承接未衣交流的稳定关系位置。
- 行为5：未衣因连续打碎杯子而改用儿童式不易碎杯具 → 山田画画鼓励她 → 作用于未衣的受挫状态和具体杯具事件 → 未衣受到鼓励并重新表示要努力工作。
  - 归类：`n`（主位证据，93%）。对象端点是未衣当下的工作受挫和关系承接；画画是具体回应，不另重复判`xn`。

#### 穷举后统计

- 计数：`n`2、`x并z`1、`zx`1、`nx`1。
- 主十元：`n`92%；次位未判，`x并z/zx/nx`均为单一功能证据。
- 撤回旧判：旧次`xn`92%依赖护理、同居和工作安排等本轮无法重新核验的后卷动作；当前官方介绍没有足够计划、时间、资源组织动作。
- 关系判断：撤回旧`n生xn`候选；当前没有有效`xn`行为链。

### 双人物与作品主维

- 当前人物层：未衣`nx+x并z`，山田主`n`。不再用后果状态替未衣证明`n/nz`，也不把山田一次具体照顾重复算作`n+xn`。
- 人物层不足以裁定作品是否为`zn+x`本体型；100分和正式归仓继续保留。
- 原卷复核：第2卷隐私事件、第3—4卷受伤与叙述、第5—6卷Mao、同居和日间工作；取得可访问原卷或重新可核验官方页后再扩展。

## 二、ミハルの戦場

### 证据范围

- 主角：ミハル，分裂日本中的天才狙击手少女。
- 覆盖：小学馆[第1卷](https://e-comi.shogakukan.co.jp/books/098540870000d0000000)、[第2卷](https://e-comi.shogakukan.co.jp/books/098542480000d0000000)、[第3卷](https://e-comi.shogakukan.co.jp/books/098543510000d0000000)、[第4卷](https://e-comi.shogakukan.co.jp/books/098545220000d0000000)公开书目。
- 当前状态：公开书目范围5条，非全作原页穷举；狙击细节、射杀主体与最终选择仍待原卷。

### 具体行为穷举（5条）

- 行为1：与无法向人开枪的原狙击手ショウ相遇 → ミハル随这段搭档关系进入关乎国家命运的战斗 → 作用于既有战争与搭档路线 → 她以狙击手身份进入公共战场。
  - 归类：`nx`（主位证据，86%）。对象端点是战争局势与ショウ关系给出的方向；“天才技术”是能力背景，不单独判`zx`。
- 行为2：F教国发动侵攻、与她有因缘的将校线索出现 → ミハル为寻找线索前往战线 → 作用于敌将线索和现有战场路径 → 私人追索进入战争路线，并造成她与ショウ关系出现裂痕。
  - 归类：`nx`（主位证据，91%）。对象端点是因缘敌将已经给出的追索方向；简介未公开她如何主动组织调查资源。
- 行为3：F教国战争结束数日后，她被派往会津训练 → ミハル进入会津训练阶段并遇见知念クミ → 作用于派遣命令和训练流程 → 她沿既定训练路线继续行动。
  - 归类：`nx`（主位证据，89%）。对象端点是派遣、训练地点和既有流程。
- 行为4：クミ严厉追问她把ショウ带回战场的责任 → ミハル面对自己的罪责并给出回答 → 作用于问责关系和自身责任位置 → 她不再只处于外部战斗，而开始处理战后责任。
  - 归类：`n`（次位证据，90%）。对象端点是落到她身上的责任负载；回答内容未公开，不补`zn`。
- 行为5：敌方基地内的カジワラ被射杀 → ミハル前往其遗属处弔问 → 作用于死亡后果和遗属关系 → 她直接进入战争后果的关系现场。
  - 归类：`n`（次位证据，92%）。对象端点是死亡与遗属形成的承接负载；书目未确认射杀者，故不把射击动作归给她。

### 穷举后统计

- 计数：`nx`3、`n`2。
- 主十元：`nx`91%；次十元：`n`90%。
- 撤回旧判：旧主`n`92%下调为次位；旧`zx`和后期`zn`候选分别来自“天才狙击技术”能力背景与“为谁战斗”疑问句，均不是已公开的具体动作。
- 关系判断：不登记关系。`nx→n`只有战斗/派遣在前、问责/弔问在后，战争和他人死亡是强第三因素。
- 与作品主维：人物`nx+n`没有形成时间公式`xn+z`；96分时间主位仍只作作品层历史判断，待原卷二审。
- 原卷复核：第1卷实际射击决定权、第2卷调查方案、第3卷回答内容、第4卷カジワラ射杀主体和最终战斗选择。

  - 归类：`nx`（主位证据，91%）。对象端点是营地已经设定的语言规则；她沿规则给出的方向调整表达。

  - 归类：`nx`（主位证据，87%）。对象端点是机构预设的任务；个人贡献份额待原卷，故不判`zx`。

  - 归类：`nx`（主位证据，90%）。对象端点是既定个人考核与对手配置；“拼命”不自动等于`n`。
- 行为9：升入初三，需要完成“明日要做的事情清单” → Alice在学校挑战清单中的任务 → 作用于已列出的学校任务和完成顺序 → 她持续推进清单。
  - 归类：`nx`（主位证据，92%）。对象端点是已存在的清单和学校任务方向；清单由谁制定仍待原卷，不抢判`xn`。

  - 归类：暂不归类（证据不足）。发现物件本身不能证明`x`掌握、`zn`意义或`nx`追索，需看她之后如何处理。

#### 穷举后统计

- 计数：`nx`7、`xn`1、`n`1、暂不归类1。
- 主十元：`nx`92%；次位未判，`xn`92%与`n`89%均只是一类单独功能动作。

### B. 犬星類：具体行为穷举（6条）

- 行为2：识别问题后 → 犬星明确表示由自己让Alice变聪明，并启动能力开发项目 → 作用于学习目标、项目角色与长期路线 → Alice进入由该项目推动的学习过程。
  - 归类：`xn`（主位证据，95%）。对象端点是项目目标、角色分工和持续计划；与行为1同属第1卷来源簇，不作两份跨卷加权。
- 行为3：Alice参加宇航员选拔工作坊并对他人能力焦虑 → 犬星在工作坊背后继续运行项目 → 作用于选拔节点和训练安排 → Alice的能力在项目中被进一步调用。

  - 归类：`xn`（主位证据，94%）。对象端点是旅行目标、地点与行动安排。
- 行为5：种子岛路线受到多种问题阻拦 → 犬星与Alice共同跨过这些障碍 → 作用于既定旅行路线 → 两人继续抵近火箭发射目标。
