# 2026-07-19 主角十元行为分析：第十三批3部剑与时雨

## 本轮口径

- 本轮处理 `剑豪生死斗 / シグルイ`、`镖人`、`泪雨与小夜曲 / 涙雨とセレナーデ` 3部独立作品。
- 《剑豪生死斗》按藤木源之助、伊良子清玄双核心分账；《泪雨与小夜曲》按片桐阳菜、本乡孝章双核心分账；《镖人》只取普通单行本1—13卷的刀马，不把“镖人金龙版”另算一个主角。
- 行为依据为官方或出版方卷级简介，不冒充逐页实读；每位人物均保留原卷复核位置。
- `xz`的失臂、失明、穿越、分离期限等先记状态；作品五大主题只作背景，不反推人物十元。

## 一、剑豪生死斗 / シグルイ

**来源文件**：[[漫画库总索引]]、[[01-本体型 zn+x]]、[[Hermes-漫画五大主题任务清单]]；外部核验采用秋田书店15卷系列页及第2、4、5、7、8、11、14、15卷。

**当前分析状态**：双核心官方卷级轻筛。藤木与伊良子在第1卷御前真剑试合及第15卷终局正面对峙，不能把两人的训练、野心和伤残混成一个“剑豪主角”。

### 藤木源之助

**人物十元**

- 主`nx`93%：虎眼流、师命、复仇命令和御前试合不断给出既有关系路线；藤木以“虎眼流剑士”的位置沿线前进。
- 次`zn`91%：他把虎眼流、武士身份和为流派复仇内化为自己必须守住的意义。
- `zx`执行功能89%：苦练、复仇试合与终局对决都由身体和剑术直接做成。
- `xz`身体/危险状态96%：失去左臂、重伤和真剑死斗是高强度状态，不自动等于人物稳定主位。

**对象端点**

- `nx`端点：虎眼流师承、师父/三重给出的关系路线、复仇与御前试合命令。
- `zn`端点：虎眼流剑士身份、武士忠诚、为流派存续与复仇而活的内部原则。
- `zx`端点：自身练成的剑术、直接交锋与以身体完成的试合节点。
- 不锁稳定`x`：道场、三重、御前试合资格和流派名望均非藤木可自由处分的私有对象。

**行为证据**

1. 师门要求身体达到虎眼流标准 → 藤木反复进行伤害自身的异常苦练 → 作用于身体、剑术与弟子资格 → 外部师承路线被他用直接训练兑现，主`nx`调用`zx`。
2. 伊良子受罚逐出、两人关系转为宿敌 → 藤木继续留在虎眼流并承担与伊良子再会的路线 → 作用于流派身份、旧同门与复仇对象 → 他没有另建生活目标，而是沿既有师门位置推进。
3. 三年后虎眼流剑士接连遇袭、伊良子归来 → 藤木与伊良子再次相遇并进入不可退让的对决轨道 → 作用于师门存续、同门伤亡与宿敌 → 流派关系把直接战斗变成必须执行的责任。
4. 复仇试合中失去一臂，且与三重准备赴死 → 藤木仍接受比死亡更残酷的上意并继续存活、备战 → 作用于残缺身体、三重关系与武士命令 → `xz`没有让路线中断，反而使`nx/zn`更尖锐。
5. 御前真剑试合临近、身体仍是手负状态 → 藤木以不完整身体继续磨炼并最终与伊良子决战 → 作用于虎眼流身份、终局试合与宿敌 → 直接剑术补足关系路线的最后执行端。

**行为模式总结**：当师门、复仇或上意给出路线时，藤木把身体压到极限去兑现；即使失臂与死亡临近，也优先维持“虎眼流剑士”这一既有位置。

**反证与边界**

- 异常苦练有主动组织成分，但目标、资格和意义长期由虎眼流关系先行规定，不能据此直接判主`xn`。
- 失臂和真剑试合是`xz`状态；他没有以漂流/危险本身作为行动目的。
- 忠诚与执念支持`zn`，但许多关键路线由师门和上意给定，纯`zn`不足以覆盖全程。

**关系判断**

- `nx补zx`候选90%：虎眼流与上意提供目标、资格和关系通道，藤木的苦练与剑术则补足“怎样把命令做成”的直接执行能力；目标变量是复仇/试合能否实际完成。三重的意志和封建上意是强第三因素，待原卷复核。

**与作品主维**：藤木次`zn`支持作品本体主的一端，但主`nx`显示人物更像被流派与上意塑形的执行者；作品中的`x`更接近道场、身体和权力归属，不属于藤木稳定掌握。

### 伊良子清玄

**人物十元**

- 主`z`95%：认可主体为岩本虎眼、三重、德川忠长及武士权力共同体；被认可内容是“天才剑士有资格上升并取代既有秩序”。
- 次`xn`90%：以入门、修炼、借势、回归和公开试合排成上升路线。
- `zx`执行功能92%：剑才、袭击与真剑交锋承担关键节点。
- `xz`身体/危险状态94%：受罚、失明与死斗属于状态压力，不把“盲目天才”直接当人物主十元。

**对象端点**

- `z`端点：虎眼与三重的承认、忠长的庇护、武士社会对其天才与地位的确认。
- `xn`端点：依靠天赋进入师门、争取上位、被逐后回归、借庇护进入更高公开舞台的顺序。
- `zx`端点：自身剑术、袭击与真剑试合的直接行动。
- 不锁稳定`x`：忠长的庇护、虎眼流、三重和社会地位都不是伊良子可稳定处分的资源。

**行为证据**

1. 进入虎眼流且把天赋视为上升资本 → 伊良子依靠剑才争取师父、三重与流派的承认 → 作用于弟子序列、婚配/继承想象和社会地位 → 持续支持主`z`。
2. 野心触碰师门边界、遭到仕置与追放 → 伊良子承受惩罚后没有退出剑士竞争 → 作用于身体、流派排斥与上升目标 → `xz`压迫没有消除认可目标。
3. 被逐三年后虎眼流剑士接连遭凶刃袭击 → 伊良子以归来和直接剑术重新进入师门视野 → 作用于旧同门、流派秩序与个人名号 → `zx`被用于夺回公开位置。
4. 得到忠长庇护、进入更高权力场 → 伊良子继续扩张野心并接受公开复仇试合 → 作用于领主认可、社会阶序与藤木这一竞争端点 → `xn`为主`z`补足借势与舞台。
5. 御前真剑试合迫近 → 伊良子以盲目之身继续备战并与藤木完成终局对决 → 作用于天才名号、宿敌和生死结果 → 最终仍通过公开较量验证“谁有资格居上”。

**行为模式总结**：一旦现有位置不足以承认他的天才，伊良子便把修炼、庇护与回归排成上升路线，并用直接剑术逼共同体重新评价自己。

**反证与边界**

- 他想取得地位不等于已经掌握地位，故不能把野心写成`x`。
- 受罚、失明和复活式归来是`xz`状态，不是“命运型人物”自动成立的证据。
- 直接剑术很强，但战斗多数服务于上位与认可，因此不判`zx`主。

**关系判断**

- `xn补z`候选91%：修炼、借忠长庇护、回归与公开试合为“天才应被承认并上升”提供持续路径；目标变量是认可的社会有效性与位置高度。天赋、三重和忠长均是第三因素，不能写成单因关系。

**与作品主维**：伊良子主`z`与作品本体主并不一致；他的上升欲和藤木的服从路线共同把作品的身份、身体归属和武士秩序问题逼到前台，但不能把双人对立压成一个`zn+x`人物。

## 二、镖人

### 刀马

**来源文件**：[[漫画库总索引]]、[[01-本体型 zn+x]]、[[02-时间型 xn+z]]、[[Hermes-漫画五大主题任务清单]]；出版方书目采用读客提供的普通中文版第1—13卷信息。

**当前分析状态**：普通单行本1—13卷跨卷轻筛；“镖人金龙版”未在公开书目中形成可独立确认的版本，本轮不重复计算刀马，版本/评分边界转入同名冲突队列。

**人物十元**

- 主`zn`95%：以自己对“游侠、欠债、护送和该不该出刀”的内部原则筛选行动。
- 次`zx`93%：谈判失败、无辜受压或护送路线受阻时，常以本人和刀直接改变局面。
- `xn`路线功能88%：把长安目的地、同行者、玉门关/敦煌等节点组织为持续护镖路线。
- `nx`任务功能84%：知世郎和护送委托提供外部目的地，但刀马会改变做法、救助旁人或对抗朝廷，不能判稳定跟随。
- `x`资源功能85%：只锁本人实际持有的刀、坐骑、赏金/护送报酬请求与旅途物资，不把小七、知世郎或整条江湖关系写成所有物。

**行为证据**

1. 面对八名通缉者且悬赏不足 → 刀马独自交涉并要求三倍赏金，冲突后直接出刀 → 作用于通缉目标、赏金请求与自身安全 → 价值判断和`zx`执行同时显影。
2. 常贵人欺压民众 → 刀马杀死常贵人并因此被朝廷追捕 → 作用于受压民众、权贵和自己的通缉状态 → 他让内部侠义边界压过制度安全，支持主`zn`。
3. 欠下人情/债务并需要护送对象赴长安 → 刀马接下知世郎的护镖，带小七进入长途路线 → 作用于承诺、护送对象、目的地和家庭责任 → 原则先使他承接责任，再由`xn`组织旅程。
4. 护送途中遇见被罗刹围困的刀客竖与燕子娘 → 刀马一行出手相助后再整合同行路线 → 作用于陌生受困者、护镖安全和队伍构成 → 他没有把合同边界当成不救人的理由。
5. 到达玉门关、护送路线被隋军封锁 → 刀马一行与守军发生战斗并继续向内地推进 → 作用于关隘、同行者与长安方向 → `zx`负责突破节点，服务于承诺而非单纯好战。
6. 昔日同袍谛听追上队伍、交手只剩生死 → 刀马接受正面对决；谛听之后仍继续经敦煌走镖，并把“刀变慢却更强”作为阶段判断 → 作用于旧同袍、个人刀法和未完成旅程 → 直接能力被关系损失重新塑形，但内部承诺未中断。

**行为模式总结**：先用自己的侠义边界决定哪一桩责任值得接，再把人和路线带向长安；遇到权贵、围困或关隘阻断时，亲自出刀清开节点，即使代价落到自身与旧同袍。

**反证与边界**

- 护送合同和长安目的地形成`nx`功能，但刀马会改路线、救助合同外对象并反抗权力，不是被动沿线。
- 赏金、债务和护送报酬不是主`x`：资源用于让旅程继续，且多数并未稳定归他控制。
- 打斗频繁支持次`zx`，但出刀前有稳定“为何出刀/为谁担责”的内部边界，因此不判`zx`主。

**关系判断**

- `zn生n`候选92%：刀马的侠义与承诺原则，使原本可以绕开的知世郎、竖/燕子娘等负担进入“由我接住”的责任范围；目标变量是责任是否被承接。
- `n生xn`候选88%：护送责任被接住后，才需要组织长安方向、同行者和关隘节点；朝廷追捕、同伴能力与历史局势是强第三因素。

**与作品主维**：刀马主`zn`高度支持作品本体主的一端；作品的`x`更可能来自朝廷通缉、家族/军队资源、护送对象归属与江湖权力边界，不自动归刀马个人。人物次`xn`与乱世时机只支持时间次维。

## 三、泪雨与小夜曲 / 涙雨とセレナーデ

**来源文件**：[[漫画库总索引]]、[[02-时间型 xn+z]]、[[Hermes-漫画五大主题任务清单]]；外部核验采用讲谈社第1—14卷官方书目。第14卷于2026-02-13发行并标明完结。

**当前分析状态**：全14卷双核心官方书目轻筛；片桐阳菜与本乡孝章分账，雏子、武虎和菊之进只作为行为对象/第三因素。

### 片桐阳菜

**人物十元**

- 主`nz`95%：穿越和分离压力下，持续维持与孝章、雏子、菊之进等人的具体关系位置，并把“能否留在身边”作为行动收束点。
- 次`xn`92%：围绕项链、身份伪装、住处/工作、救援和家族真相组织连续行动。
- `zn`88%：从“回现代”逐步转向“在这个时代如何生活并怎样爱人”的内部选择。
- `xz`时间/危险状态97%：明治40年穿越、回归线索丢失、被迫分别及危险追查是状态压力，不把穿越本身当主十元。

**对象端点**

- `nz`端点：孝章这一恋爱停靠、与雏子的替身/姐妹式关系、菊之进的照护关系及最终分别。
- `xn`端点：曾祖母项链、雏子身份接口、住处和咖啡工作、绑架救援与本乡财阀真相。
- `zn`端点：是否留在明治、如何面对自己的爱和不占用雏子位置。
- 不锁稳定`x`：雏子的身份、项链、孝章、智能手机和回归通道均非阳菜可稳定控制。

**行为证据**

1. 音乐课中突然穿越到明治40年、身份与住处中断 → 阳菜接受孝章帮助并暂住雏子处 → 作用于生存位置、雏子身份和陌生时代 → `xz`压力先把她推入关系停靠。
2. 丢失曾祖母项链且无法回去 → 阳菜假扮与自己相似的雏子，并与孝章共同寻找项链 → 作用于身份接口、回归线索和孝章关系 → `xn`组织搜索，同时不把雏子身份当自身所有。
3. 项链线索中断、对孝章的感情可能伤及雏子 → 阳菜压下恋情，离开原住处，到育儿院生活并在咖啡店工作 → 作用于雏子位置、自身生计和孝章关系 → 她用主动退出保护关系边界，支持`nz/zn`。
4. 雏子遭绑架、婚约披露宴成为冲突场 → 阳菜与孝章、菊之进合作把雏子救回 → 作用于雏子安全、三人协作和家族安排 → 关系停靠被转成具体救援方案。
5. 孝章找到她并表达感情 → 阳菜先拒绝，随后确认双方心意并明确说出自己的选择 → 作用于孝章、雏子与自己的时代位置 → 她不是单纯追求被爱，而是在关系责任校验后认领停靠。
6. 孝章受袭、家族黑幕扩大 → 阳菜与菊之进潜入病室探望，之后协助追查并控制执行者天进 → 作用于孝章安全、袭击链与离别前有限时间 → `nz`给出要守的人，`xn`组织救助与追查。

**行为模式总结**：时间错位切断原生活后，阳菜先寻找能停靠的具体关系，再把项链、身份、工作与救援排成行动；每次接近孝章，都同时校验雏子和他人的位置是否会被自己夺走。

**反证与边界**

- 穿越、回归线索和分别期限是`xz`状态，不等于阳菜“以危险为主”。
- 寻找项链与调查支持`xn`，但方案的反复改变由关系保护和留在谁身边驱动，因此不判`xn`主。
- 阳菜曾假扮雏子，却明确没有取得雏子身份的长期处分权，不能写成稳定`x并z/x`。

**关系判断**

- `xz补nz`候选94%：时代错位、回归不确定与最终分别使“能否在孝章/雏子身边停靠”成为必须回答的关系问题；反过来具体关系为漂流状态提供收束方向。目标变量是关系能否在有限时间内成立，项链与武虎的技术是第三因素。

**与作品主维**：阳菜主`nz`直接支持作品命运次维的一端，次`xn`参与时间主维；但她的穿越`xz`状态不能单独证明人物等于完整`xn+z`或`xz+nz`公式。

### 本乡孝章

**人物十元**

- 主`xn`94%：把救助、项链线索、寻找阳菜、家族黑幕、婚约与救援排成连续计划。
- 次`nz`92%：持续把阳菜、雏子置于“要找到、保护并让其有选择”的关系位置。
- `zn`89%：逐渐以自己的感情和责任判断对抗本乡家的既定婚约/血缘安排。
- `zx`执行功能85%：亲自搜寻、营救、调查和公开解除婚约，服务于组织路线。

**对象端点**

- `xn`端点：阳菜身份、项链线索、寻找路线、绑架救援、本乡财阀违法交易与婚约解除。
- `nz`端点：阳菜的恋爱关系、对雏子的保护/解除婚约责任、与家族关系的重新定位。
- `zn`端点：是否按家族安排生活、怎样对自己的爱与保护责任负责。
- 不锁稳定`x`：家族权力、婚约、阳菜、雏子和回归技术均不由孝章稳定掌握。

**行为证据**

1. 陌生女子阳菜落入明治且无处可去 → 孝章先救助并把她带入可居住的关系网络 → 作用于阳菜安全、雏子住处与自己的未婚关系 → 他先承接问题，再开始组织身份线索。
2. 阳菜以雏子身份行动并丢失项链 → 孝章与她共同搜寻，逐步识别真正吸引自己的对象 → 作用于项链、真假身份和恋爱判断 → 搜索把混乱关系拆成可核验对象。
3. 阳菜离开、切断原住处和联系 → 孝章确认她的真实身份后与雏子合作寻找 → 作用于阳菜去向、雏子的婚约位置与搜索渠道 → `xn`重组关系资源，不把雏子当阻碍清除。
4. 雏子遭绑架、家族披露宴被利用 → 孝章与阳菜、菊之进协作营救雏子，并向阳菜表明感情 → 作用于雏子安全、阳菜关系与家族安排 → 保护行动和关系认领在同一节点完成。
5. 本乡财阀旧事与连续袭击浮出 → 孝章赴横滨调查非法交易，受伤后仍继续追查至妓楼“Number Nine” → 作用于父辈罪行、袭击者和家族责任 → `xn`把私人恋情扩大为清理家族风险的持续任务。
6. 婚约继续压迫雏子、阳菜的离别时间逼近 → 孝章与雏子在双方父母前宣布解除婚约，参与救出被关的雏子，并以大提琴演奏会邀请阳菜完成告别 → 作用于婚约、雏子自由和阳菜关系 → 他用公开节点为三人的关系重新排位。

**行为模式总结**：关系混乱或家族危险出现时，孝章先把人、线索和家族责任排成可行动的顺序，再亲自寻找、营救或公开表态，使阳菜与雏子获得不被旧婚约吞没的位置。

**反证与边界**

- 他依赖本乡家身份取得部分行动渠道，但持续调查家族、解除婚约，不符合稳定`nx`跟随。
- 保护阳菜/雏子支持`nz`，但多数关系节点通过搜索、调查、协作与公开手续推进，故主位仍判`xn`。
- 家族资源并不等于孝章稳定`x`；他无法自由控制婚约、父辈交易和时代技术。

**关系判断**

- `n生xn`候选91%：阳菜穿越、项链丢失、雏子绑架和家族袭击先落成由孝章承接的具体问题，随后才生成寻找、救援与调查计划；目标变量是问题能否被排成可执行路线。阳菜、菊之进、武虎及家族权限均是第三因素。
- `xn`与`nz`同时高，但现行盘不把二者设为补位；本轮只记录协同，不虚构生补克。

**与作品主维**：孝章主`xn`明显支持作品时间主维的组织端，阳菜/雏子关系提供持续对象；但作品的`z`爆点来自相认、表白、婚约公开和告别场景，不自动变成孝章稳定主`z`。
