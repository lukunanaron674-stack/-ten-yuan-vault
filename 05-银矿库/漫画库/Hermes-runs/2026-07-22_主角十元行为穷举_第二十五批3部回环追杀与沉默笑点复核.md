# 主角十元行为穷举·第二十五批：回环、追杀与沉默笑点复核

## 本轮口径与覆盖边界

- 本轮没有用户侧新增漫画，优先把旧第二十批的“先判十元、再概括行为”改成“先穷举具体动作、再逐条唯一归类”。
- 覆盖`運命の巻戻士`クロノ、`大ダーク`ザハ＝サンコ、`妹は知っている`三木貴一郎，共3部、3位主角、15条动作。
- 只保留出版社材料能落到主角身上的动作。组织设定、被动遭遇、别人行动、抽象动机和“没有做某事”不进入十元统计。
- 每条动作只归一个十元；同一来源簇中的相邻动作可以分别登记，但统计时不把它们伪装成两份独立跨卷证据。
- 本报告是公开书目/官方介绍范围穷举，不是三部作品的全作原页穷举。

## 一、運命の巻戻士

### 对象、阶段与来源

- 主角：クロノ（Chrono），巻戻士成员。
- 覆盖阶段：第2、6—8卷公开书目；晋级考试、TOTE潜入、三时战与豪华客船任务。
- 库内来源：旧第二十批报告、`漫画库总索引.md`、`漫画库_全名单-精修版-2026-06-02.md`。
- 官方来源：小学馆[第1卷系列设定](https://e-comi.shogakukan.co.jp/books/091433990000d0000000)、[第2卷](https://e-comi.shogakukan.co.jp/books/091435510000d0000000)、[第6卷](https://e-comi.shogakukan.co.jp/books/091436870000d0000000)、[第7卷](https://e-comi.shogakukan.co.jp/books/091497490000d0000000)、[第8卷](https://e-comi.shogakukan.co.jp/books/091498550000d0000000)。
- 当前状态：公开书目范围仅能稳定锁定4条个人动作，故明确为“公开资料范围穷举，非全作穷举”。

### 公开书目范围行为穷举与逐条归类（4条）

- 行为1：クロノ参加晋级考试并接到阻止飞机事故的课题 → 他进入既定考试和事故处置流程 → 作用于晋级制度、飞机事故与考题要求 → 行动被推进到必须判断是否与赤羽协作的阶段。
  - 归类：`nx`（主位证据，90%）。对象端点是组织已经给出的晋级路径、事故目标和考题流程；公开书目没有说明由他设计整套任务。
- 行为2：以间谍身份进入TOTE、员工连续死亡之谜出现 → クロノ继续在TOTE内部调查 → 作用于潜入身份、组织内部通道和死亡事件线索 → 他接近事件核心，并承受Clock Hands反复背叛造成的阻断。
  - 归类：`nx`（主位证据，92%）。对象端点是既定间谍任务、TOTE内部路径与连续死亡线索；本条只确认沿任务方向推进。
- 行为3：TOTE潜入期间遭遇“三时”阻拦 → クロノ与チヌ、ゴロー共同交战 → 作用于拦截者及当前战斗局面 → 潜入任务由调查阶段转入直接对抗。
  - 归类：`zx`（战斗功能证据，86%）。对象端点是“三时”这一具体对手和眼前阻断；团队共同作战不等于クロノ独自设计全局。
- 行为4：豪华客船将撞上冰山并造成大量死亡 → クロノ与グレイ、灰崎组成任务组登上救援路线 → 作用于既定搭档配置、客船事故目标和组织任务 → 他开始沿事故处置流程尝试救人。
  - 归类：`nx`（主位证据，91%）。对象端点是已经给出的搭档、任务对象和救援路径；官方简介没有公开个人改线细节。

### 穷举后统计

- 行为计数：`nx`3条、`zx`1条。
- 主十元：`nx`92%。跨晋级、潜入和客船任务三阶段，都由既有组织任务或事件目标提供方向。
- 次十元：未判定；`zx`仅为战斗功能位86%。
- 撤回旧判：旧主`xn`95%与次`n`92%依赖“クロノ主动重排无数轮方案”“把失败全部承接下来”等官方书目未明确到个人的推断；第1卷只说明巻戻士组织会反复回溯，不能直接算作クロノ个人动作。
- 关系判断：撤回旧`n生xn`候选。当前没有可核验的个人`n`或`xn`动作链，更不能由组织设定代替机制。
- 与作品主维关系：人物`nx`只说明他常沿既定任务推进，不裁作品命运/时间主次，也不改102/86分。
- 原卷复核：第2卷合作决定权、第6—7卷潜入方案归属、每次回溯后是否由クロノ本人调整节点、第8卷客船救援的实际步骤。

## 二、大ダーク / Dai-Dark

### 对象、阶段与来源

- 主角：ザハ＝サンコ（Zaha Sanko），骨头被传言可实现愿望、因而在宇宙中遭追杀的少年。
- 覆盖阶段：第1—6卷公开书目；反击、潜入、受控暴走、伙伴修复与剑山战。
- 库内来源：旧第二十批报告、`漫画库总索引.md`、`漫画库_统一总索引_草稿.md`。
- 官方来源：小学馆[第1卷](https://e-comi.shogakukan.co.jp/books/091294860000d0000000)、[第2卷](https://e-comi.shogakukan.co.jp/books/098502150000d0000000)、[第3卷](https://e-comi.shogakukan.co.jp/books/098504960000d0000000)、[第5卷](https://e-comi.shogakukan.co.jp/books/098512510000d0000000)、[第6卷](https://e-comi.shogakukan.co.jp/books/098520220000d0000000)。
- 当前状态：公开书目范围穷举6条，其中1条因主体决定权被夺而保留为暂不归类；非全作穷举。

### 公开书目范围行为穷举与逐条归类（6条）

- 行为1：外星人因“得到他的骨头就能实现愿望”的传言袭击 → サンコ与アバキアン杀死袭击者 → 作用于当场攻击者和直接生存威胁 → 眼前追杀被以暴力反击终止。
  - 归类：`zx`（主位证据，91%）。对象端点是具体袭击者及即时威胁；不把“骨头传言”这一被动设定归为他的十元。
- 行为2：“四匹の害悪”被光力块盯上 → サンコ与アバキアン、死ま田共同潜入光力块飞船 → 作用于已有目标飞船、同行者和进入路线 → 三人进入敌对组织内部。
  - 归类：`nx`（次位证据，86%）。对象端点是团队已锁定的飞船和共同潜入路线；简介未说明方案由サンコ独自组织。
- 行为3：ダメ丸取得对サンコ的控制权 → サンコ在没有武器的状态下暴走并重伤 → 作用于周围目标和他自己的身体 → 身体行动造成破坏，但决定权不在サンコ本人。
  - 归类：暂不归类（主体决定权不足）。本条保留作边界证据，不把“被控制的身体动作”计为サンコ的稳定十元。
- 行为4：一行人遭光核人袭击 → サンコ随队投入战斗 → 作用于光核人和小队生存局面 → 团队勉强取胜，但アバキアン受损。
  - 归类：`zx`（主位证据，87%）。对象端点是明确攻击者和即时对抗；具体个人击杀份额待原卷复核，因此置信度低于第1卷。
- 行为5：アバキアン在上一战中损坏 → サンコ随一行前往クライ寻求修理 → 作用于受损伙伴、修复目的地和移动路线 → 团队从战斗转入修复行程。
  - 归类：`nx`（次位证据，85%）。对象端点是伙伴损坏已经给出的需求与クライ路线；未把团队决定写成サンコ个人策划。
- 行为6：ダメ丸在剑山被杀、现场冲突升级 → サンコ一行与剑山外星人进入死斗 → 作用于剑山敌对群体和当场冲突 → 故事转入直接战斗阶段。
  - 归类：`zx`（主位证据，86%）。对象端点是剑山外星人及即时冲突；“复仇意义”未获书目明确，不另判`zn`或`x`。

### 穷举后统计

- 行为计数：`zx`3条、`nx`2条、暂不归类1条。
- 主十元：`zx`90%。第1、5、6卷跨阶段均可确认他参与直接对抗；团队战细节不足使置信度不再上调。
- 次十元：`nx`86%。潜入和修复旅程都沿团队既有目标推进。
- 撤回旧判：旧主`xz`95%把“遭追杀、被控制、被夺骨头、路线受阻”等状态和遭遇当成行为；本轮全部改按他实际做了什么，`xz`不再作为主位。
- 关系判断：撤回旧`xz生zx`候选。追杀背景可能促发战斗，但第三方攻击、团队决策和武器条件同时存在，未形成稳定个人机制。
- 与作品主维关系：人物`zx+nx`不能直接裁作品因果主维，也不能推翻库内空间归仓；100分、作品维度冲突继续二审。
- 原卷复核：第2卷潜入方案归属、第3卷控制状态下的自主瞬间、第5—6卷团队战中サンコ的个人动作和结果。

## 三、妹は知っている

### 对象、阶段与来源

- 主角：三木貴一郎，26岁中途入职的系统工程师，也是广播节目常被采用的投稿者“フルーツパフェ”。
- 覆盖阶段：讲谈社官方第1卷作品介绍所展示的职场聚会、兄妹日常、广播投稿和大喜利协助。
- 库内来源：旧第二十批报告、`漫画库总索引.md`、`漫画库_全名单-精修版-2026-06-02.md`。
- 官方来源：讲谈社[官方编辑部作品介绍](https://news.kodansha.co.jp/comics/20151297)。
- 当前状态：官方介绍范围穷举5条；同一介绍页不足以替代全卷实读。

### 官方介绍范围行为穷举与逐条归类（5条）

- 行为1：公司频繁举行聚会 → 貴一郎仍会到场 → 作用于既有职场社交流程和同事关系 → 他没有切断公司交往，但参与程度有限。
  - 归类：`nx`（职场功能证据，84%）。对象端点是公司已经形成的聚会和人际流程；本条不推断其内心认同。
- 行为2：醉酒上司在聚会上长篇说教 → 貴一郎继续吃饭并较早离场 → 作用于自己的参与时间、注意力和身体边界 → 他完成最低限度参与后终止继续停留。
  - 归类：`x`（边界功能证据，88%）。对象端点是他可掌握的在场时间和注意力；与行为1同属一个来源簇，统计时不算两份跨阶段证据。
- 行为3：妹妹可能裸露上身走到阳台 → 貴一郎察觉后去拿浴巾 → 作用于妹妹当下的暴露风险和可用物品 → 他用具体物件消除眼前问题。
  - 归类：`n`（主位证据，91%）。对象端点是落到他面前的妹妹照护负载；动作止于取浴巾，不补写抽象“守护欲”。
- 行为4：深夜广播持续征集来稿 → 貴一郎以“フルーツパフェ”名义反复投稿 → 作用于稿件、广播栏目和持续投稿节奏 → 稿件多次被节目采用。
  - 归类：`xn`（次位证据，92%）。对象端点是反复生产的稿件、投稿渠道和长期运行节奏；“不是为了被认可”属于动机说明，不另归`zn`。
- 行为5：妹妹第一次参加大喜利节目却无法提出有趣答案，向他请求协助 → 貴一郎接受请求并兑现帮助 → 作用于妹妹的节目难题和具体委托 → 妹妹得到可用于节目准备的协助。
  - 归类：`n`（主位证据，89%）。对象端点是妹妹明确交给他的任务；具体答题方法和现场结果待原页复核。

### 穷举后统计

- 行为计数：`n`2条、`xn`1条、`x`1条、`nx`1条。
- 主十元：`n`91%。浴巾和大喜利协助是两个不同问题簇，均表现为具体问题落身后完成处理。
- 次十元：`xn`90%。广播投稿单条归类置信度虽高，但目前只有一个公开来源簇，因此人物位阶置信度下调并保留次位。
- 功能位：`x`88%、`nx`84%。
- 撤回旧判：旧主`zn`96%主要依赖“不靠成绩或关系证明自己”“并非为获得认可而投稿”等动机或不作为；它们不能代替具体动作，故本轮不再把`zn`列为主位。
- 关系判断：撤回旧`zn生n`候选。当前既无有效`zn`行为证据，也无从内部意义到承接动作的明确启动机制。
- 与作品主维关系：人物`n+xn`既不证明“妹妹知道＝因果链”，也不单独证明作品本体主位；98分、因果/本体二审和正式归仓不动。
- 原卷复核：聚会离场的完整语境、广播投稿频率、浴巾行为前后因果、帮助大喜利的具体步骤与结果。

## 本轮结构性修复

1. 旧16条经主体性、具体性和来源簇审核后重写为15条：クロノ4条、サンコ6条、貴一郎5条。
2. 不再把组织设定自动归给クロノ，不再把受害状态自动归为サンコ的`xz`，不再把貴一郎“不求认可”这种否定式动机当作`zn`行为。
3. 三部旧主位均撤回：クロノ`xn→nx`，サンコ`xz→zx`，貴一郎`zn→n`；相关旧关系候选一并撤回。
4. 本轮是旧批次格式复核，不新增独立作品或人物；人物索引累计仍为75部、96位人物。

- 下轮优先继续把旧报告中“单条多标签/行为概括”改成逐条唯一归类；若取得原卷，优先扩展クロノ每次回溯后的个人调整、サンコ团队战中的独立动作、貴一郎大喜利协助的具体步骤。
