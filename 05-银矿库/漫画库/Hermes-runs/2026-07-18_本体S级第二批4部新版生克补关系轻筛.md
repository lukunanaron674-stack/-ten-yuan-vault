# 本体S级第二批4部 · 新版生克补关系轻筛

## 本轮结论

本轮按新版 `x=具体归属/掌握边界` 重审四部本体型高分作品。前三部可以保留现有主次维导航，但必须删除旧 `x=欲望/身体/吞噬` 解释；《迷宫饭》旧“由空间推翻到本体”的主要理由依赖旧口径，因此重新挂入“本体/空间主次冲突”二审，不强行改仓。

本轮只更新关系摘要、追踪状态与复审队列；96/96/95/91/94 分均不改，不合并别名，不把任何条目改为 finalized。

## 1. 链锯人

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、[[Hermes-漫画五大主题任务清单]]
- **当前状态**：精选入库；新版关系轻筛完成，待章节级深分析
- **主维 / 次维 / 辅维**：本体型 `zn+x` / 命运型 `xz+nz` / 因果
- **评分 / 置信度**：96 分不变；本轮关系判断 88%
- **对象端点**：
  - `x`：对电次、恶魔、组织角色与亲密关系的具体控制/归属；电次逐渐形成“我的家、我的人、我的生活”的边界。
  - `zn`：电次关于“怎样才算我的生活”的意义核心。
  - `z`：由真纪真、同伴与公众提供或截断的认可位置。
- **十元公式判断**：
  - `x 克 z`（高）：控制把电次的独立认可压缩成“由掌控者批准才有价值”。
  - `x 生 x并z`（中高）：控制结构生产出“狗、公安猎人、Chainsaw Man 英雄”等被观看身份。
  - `x并z 生 z`（中）：公共英雄形象继续生产公众认可与恐惧位置。
  - `nz 克 x`（高）：波奇塔、帕瓦、早川秋形成的情感停驻反向破坏纯粹控制。
  - `zn 补 x`（中高）：生活意义必须落到具体关系与生活边界；具体归属又让意义获得载体。
- **动态链**：`x → x并z → z`；`nz 克 x`；随后以 `zn ↔ x` 尝试夺回“我的生活”。
- **五大主题关系**：命运中的契约/支配对本体形成强约束，但“谁掌握电次、什么才属于电次自己”仍直接命中本体公式，暂不改主维。
- **核心理由**：新版 `x` 不是“小欲望”，而是故事持续争夺的控制权、归属权与生活边界。VIZ 官方简介也以电次与波奇塔、契约及公安恶魔猎人的身份转变为入口。
- **是否需要复核**：需要；用控制篇前后各取 2—3 个关键章节验证 `x 克 z` 与 `nz 克 x`。
- **建议写入位置**：本体主题页、总索引、Hermes 任务清单；深分析卡补章节证据。

## 2. 地。关于地球的运动。

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、[[同名冲突复审队列]]
- **当前状态**：精选入库；新版关系轻筛完成；Orb / チ。高置信别名待二审
- **主维 / 次维 / 辅维**：本体型 `zn+x` / 时间型 `xn+z` / 因果
- **评分 / 置信度**：96 分不变；本轮关系判断 89%
- **对象端点**：
  - `zn`：真理及“值得为之承受代价”的精神意义。
  - `n`：手稿、观测记录、箱子与跨代传递网络。
  - `xn`：观测、抄录、藏匿、传递与审判等被组织的时间流程。
  - `x`：谁能保管、控制、定义手稿、仪器、观测数据与知识。
- **十元公式判断**：
  - `zn 生 n`（高）：真理意义不断产生手稿、记录和传承载体。
  - `n 生 xn`（高）：被保存的信息与继承网络使跨年代的观测/传递计划得以组织。
  - `zn 克 xn`（高）：真理意义迫使宗教审判和知识制度不断重组其时间流程。
  - `zn 补 x`（中高）：精神真理必须获得具体文本/数据的保管边界；掌握载体又让真理可继续燃烧。
  - `xn 克 zx`（中）：制度化追查流程持续压制知识的直接突破，需要章节级再验证。
- **动态链**：`zn → n → xn`，同时 `zn 克 xn`；围绕手稿/数据形成 `zn ↔ x`。
- **五大主题关系**：本体对时间的克制关系清楚：意义核心反复撬动时代与制度流程；时间仍保留强次维。
- **核心理由**：新版 `x` 不是“身体/信仰”，而是知识载体的保管、控制与解释权。Seven Seas 官方页确认英文正式名、作者与跨代追索真理的剧情入口。
- **是否需要复核**：别名只需用户二审后统一 ID；关系上需抽查“箱子—手稿—继承者”链的章节证据。
- **建议写入位置**：本体主题页、总索引、同名冲突队列；保留 96/93/92/87/10 各批证据。

## 3. 晚安Punpun / Goodnight Punpun

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、[[同名冲突复审队列]]
- **当前状态**：精选入库；新版关系轻筛完成；ready-to-merge 待用户二审
- **主维 / 次维 / 辅维**：本体型 `zn+x` / 命运型 `xz+nz` / 时间
- **评分 / 置信度**：中文 95、英文 91 均不变；本轮关系判断 85%
- **对象端点**：
  - `x`：亲密关系里的排他占有/控制边界，而不是一般日常欲望。
  - `z`：经爱子、“神”或他人确认自身存在的认可位置。
  - `xz`：家庭破裂、暴力、失败与漂流形成的厄运结构。
  - `zn`：Punpun 不稳定、不断空洞化的自我意义。
- **十元公式判断**：
  - `xz 克 zn`（高）：家庭与人生厄运持续侵蚀自我意义。
  - `x 克 z`（中高）：排他关系把彼此压成唯一确认者，削弱双方独立的认可位置。
  - `zn 补 x`（中）：不稳定意义与排他占有相互填补并病理化，需要关键章节二审。
  - `xz 补 nz`（中高）：漂流厄运与“想被某人留住”的情感停驻形成互补。
- **动态链**：`xz 克 zn`；`zn` 变弱后以病理性 `x` 代偿；随后 `x 克 z`。
- **五大主题关系**：命运对本体的克制非常强，但作品仍以“Punpun 的自我意义如何坍塌”作为当前主导航；命运保持强次维。
- **核心理由**：旧“日常欲望 x”不再成立，真正可落地的是亲密关系的占有边界与认可位置。VIZ 官方页确认 Goodnight Punpun 为浅野一二〇作品及其成长、家庭与爱的叙事入口。
- **是否需要复核**：需要；别名 ID 可合并，但评分证据不可自动合并；关系需以爱子线关键章节二审。
- **建议写入位置**：本体主题页、总索引、同名冲突队列；英文行继续只作别名/旧批次证据。

## 4. 迷宫饭

- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、[[Hermes-漫画五大主题任务清单]]
- **当前状态**：精选入库；新版关系轻筛完成；**本体/空间主次冲突重开**
- **主维 / 次维 / 辅维**：现存导航为本体型 `zn+x` / 空间型 `x并z+n` / 因果；本轮不改字段，只标待二审
- **评分 / 置信度**：94 分不变；本体主维暂降为 72%，空间结构证据约 88%
- **对象端点**：
  - `x`：对怪物身体、可食资源、生态知识与安全转化边界的具体掌握；不是饥饿本身。
  - `n`：冒险队伍及其承载生存、知识和协作的分布式载体。
  - `x并z`：被看见、被命名、被端上桌的菜肴/食谱形式。
  - `xn`：料理、补给、路线与探索节律的组织流程。
- **十元公式判断**：
  - `n 生 xn`（高）：队伍与生存载体生产料理、补给、路线和探索节律。
  - `n 补 x并z`（中高）：队伍承载与菜肴可见形式互相补足。
  - `x 生 x并z`（中高）：掌握怪物身体和生态知识，才生产出可食的菜肴形式。
  - `zn 补 x`（中）：理解生命/拯救同伴的意义与怪物生态的具体掌握互相补足，需全作证据。
- **动态链**：`x → x并z`；`n ↔ x并z`；`n → xn`。
- **五大主题关系**：
  - `空间 生 时间`（高）：迷宫生态、路线和队伍空间持续生产探索/料理周期。
  - `本体 生 空间`（中）：莱欧斯的理解方式把迷宫改造成食物、知识和共存空间。
- **核心理由**：旧“吃掉怪物=把外部空间转为身体存在”的判据把 `x` 当作欲望/吞噬，已失效；新版反而同时得到强 `x` 掌握链和更强的 `n→xn`、空间生时间结构。Yen Press 官方简介也把救援任务、地牢探索、怪物料理和生存规则并列为作品入口。
- **是否需要复核**：必须；按前/中/后段各取一卷，比较“本体意义争夺”和“空间—队伍—周期”谁更稳定地组织全作。
- **建议写入位置**：同名冲突复审队列新增 dimension-conflict；主题页与总索引标“本体/空间主次重开待二审”，不改94分与现存主维字段。
