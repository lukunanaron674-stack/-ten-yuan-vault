## 一、镖人 / Blade of the Wind · 刀马

- 行为1：大沙暴三天后驿站被黄沙掩埋，驿站老板宣告"再没人会走这条路" → 刀马单枪匹马走到路标下，把驿站残存的一面旧旗拔起插回路标顶部 → 作用于驿站与路标 → 旗在路标顶端迎风，路过商旅重新回到驿站过夜。
  - 归类：zx（阳木，主位证据，93%）。对象端点：路标与驿站通行权被公开扭转。
- 行为2：朝廷发下悬赏缉拿告示 → 刀马每到新镇先到告示墙下数一遍金额，写在马鞍侧的皮册上 → 作用于告示墙金额与自己马鞍 → 三个月内金额翻了两次，他仍按数写不改路线。
  - 归类：nx（阴金，主位证据，91%）。对象端点：朝廷缉拿既有方向与马鞍皮册通道。
- 行为3：西域客栈被朝廷官员深夜闯门查缉 → 刀马凌晨换装出城，把客栈所有人的通缉画像照片撕一张换一张、让守门士兵在画像前盯着断案半时辰 → 作用于客栈房间与守门士兵 → 客栈被搜查的房间没人被认出。
  - 归类：xn（阳金，主位证据，95%）。对象端点：客栈房间与守门士兵的搜查流程。
- 行为4：同伴护卫的商队被匪寨围困 → 刀马让同伴把货物卸在路边、每人沿土坎躲下、自己骑马沿匪寨方向正面冲上去、在寨门前举旗让匪寨判断"是大漠骑手单挑" → 作用于匪寨与商队 → 匪寨按约定走大漠单挑规则，商队货物原路带回。
  - 归类：z（阴火，主位证据，94%）。对象端点：匪寨战斗规则与商队货物的最高裁定。
- 行为5：朝廷招安特使送来委任状与官印 → 刀马把委任状铺在酒桌正面、把官印按在酒桌中央的茶碗里、让茶渍把委任状浸透后拿走官印退给特使 → 作用于招安委任与茶碗 → 委任状被茶渍盖掉所有正文，特使收印回朝。
  - 归类：z（阴火，主位证据，96%）。对象端点：招安最高裁定与茶碗印记。
- 行为6：大漠驿站店家被黑沙匪砍伤致残 → 刀马在驿站墙边立木牌、写明"此店由刀马护卫、外人不许动手"、把伤人匪首的刀刀刃朝外挂在木牌上 → 作用于驿站与匪首之刀 → 一个月内该驿站再未发生伤人事件。
  - 归类：z（阴火，主位证据，92%）。对象端点：驿站安全最高裁定与匪首之刀。

## 二、戦奏教室 / Bugle Call · 空もずく作 / 桃盛ひごろ画 · 主号手

- 行为1：关卡钟塔每日会传讯'楼上危险请撤'，但其他号手不知钟塔已被反派改造 → 主号手一人在关卡内用备用号吹出三段'撤、撤、撤'的变奏 → 作用于关卡内所有能听到号声的玩家 → 关卡内玩家按变奏顺序分三批撤离，反派改造失效。
  - 归类：xn（阳金，主位证据，95%）。对象端点：关卡内玩家撤离流程与号声变奏。
- 行为2：反派把钟塔钥匙分配到三位分别在不同党派的玩家 → 主号手私下召集三位、与他们谈 1 小时、把钥匙统一交到号手工会、由工会按调用规则分发 → 作用于三位玩家与钟塔钥匙 → 钥匙每天从工会取出再归还，再没被任意一方单独拿走。
  - 归类：xn（阳金，主位证据，94%）。对象端点：钟塔钥匙调用流程与号手工会。
- 行为3：反派引入限定版音乐盒能引出玩家心跳 → 主号手要求工会成员全员禁带手机与耳机进副本，工会内副本外张贴告示 → 作用于工会副本入口与告示 → 一周内反派音乐盒副本通过率归零。
  - 归类：xn（阳金，主位证据，93%）。对象端点：工会副本入口与告示流程。
- 行为4：反派与三大公会联合作战，玩家人数悬殊 → 主号手要求各公会排出各自的号声出战时间表、按战事推进动态调整 → 作用于三大公会出战时间与战事节点 → 三周内三大公会按时间表连续迎战，玩家人数差距被错开填补。
  - 归类：xn（阳金，主位证据，96%）。对象端点：三大公会出战时间表与战事节点。
- 行为5：反派首领在终关等待主角绕路 → 主号手拒绝绕路、按工会规定路线直冲终关、在终关把号吹响 → 作用于工会规定路线与终关首领 → 反派首领被号声引出正面交战，终关按工会议程收束。
  - 归类：nx（阴金，主位证据，94%）。对象端点：工会既有规定路线与终关正面交战通道。
- 行为6：战役结束后反派被公会成员留下，所有人开始内讧谁出卖了终关路线 → 主号手离开副本大门、把号放回工会仓库、独自走到湖边坐一小时 → 作用于公会仓库与公会成员 → 公会仓库当晚多了一把号，公会成员不再公开讨论此事。
  - 归类：z（阴火，主位证据，93%）。对象端点：号所有权与公会成员讨论的裁定归属。

统计：`xn`×4（候选→第八条跨作品 locked 候选）、`nx`×1（候选→与既有 3 条并列）、`z`×1（候选→新归类进入）。共 6 条候选进入基础库。本主角主十元候选 `xn` 95%，次 `nx` 92%；`xn` 行为 4（96）已具备跨作品第八条 locked 候选条件。

## 三、多聞さんのおかしなともだち / 多聞的奇怪朋友 · 多聞（中学生）

- 行为1：教室后排的窗台上不知何时多了一只巴掌大的塑料小狗 → 多聞每天上学把小狗摆在窗台同一位置、回家前把它挪到下一节课文夹里、第二天再摆回窗台 → 作用于窗台与课本 → 一个月内小狗位置始终固定。
  - 归类：xn（阳金，主位证据，87%）。对象端点：窗台小狗位置与课本夹。
- 行为2：班主任把小狗收走放进讲台抽屉 → 多聞放学前到讲台前、打开抽屉、取出小狗、放回窗台原位 → 作用于班主任抽屉与窗台 → 小狗当晚回到窗台，班主任发现后未再动。
  - 归类：n（阳土，主位证据，89%）。对象端点：班主任抽屉与窗台承载路径。
- 行为3：好友在走廊蹲下不肯进教室 → 多聞走到好友旁边蹲下、用耳语把窗台小狗的事讲一遍 → 作用于好友与窗台秘密 → 好友当晚回到自己教室。
  - 归类：n（阳土主位证据，86%）。对象端点：好友情绪与窗台秘密。
- 行为4：窗台小狗在冬季户外一夜冻裂 → 多聞用胶把裂口粘上、把小狗放回原位，并在窗台外加一层塑料盒 → 作用于窗台与塑料盒 → 小狗不再继续裂，窗台位置未变。
  - 归类：n（阳土，主位证据，87%）。对象端点：窗台载体与塑料盒。
- 行为5：好友问"小狗是不是真朋友" → 多聞把小狗从窗台取下、放到好友掌心、合上好友手指 → 作用于好友掌心与小狗 → 好友收下小狗，窗台当天空位。
  - 归类：zn（阳火，主位证据，89%）。对象端点：好友与小狗的独立成立关系。
- 行为6：好友把小狗摆在自家窗台同样位置 → 多聞到家后在自己房间窗台同样位置放一片同款塑料花 → 作用于自家窗台与塑料花 → 双方窗台各摆各自物件，一周内互相不询问但位置未变。
  - 归类：x并z（阴木，主位证据，88%）。对象端点：自家窗台对外可识别位置。

统计：`xn`×1（候选）、`n`×3（候选→与既有零条并列填补 n 阳土空缺）、`zn`×1（候选→与既有 1 条并列跨作品第二条 locked 候选）、`x并z`×1（候选→与既有 1 条并列）。共 6 条候选进入基础库。本主角主十元候选 `n` 88%，次 `zn` 87%；`n` 行为 2/3/4（89/86/87）接近 locked 门槛；`zn` 行为 5（89）接近第二条跨作品 locked。
