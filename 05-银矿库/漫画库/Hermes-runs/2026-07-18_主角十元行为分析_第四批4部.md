## 1. Jimmy Corrigan

### 分析对象

- **主角**：Jimmy Corrigan
- **身份**：36岁、独居、社交隔离的普通职员
- **阶段**：收到失联父亲邀请 → 感恩节会面 → 父亲死亡后返回芝加哥
- **来源文件**：`01-本体型 zn+x.md`、`漫画库总索引.md`、Hermes任务清单
- **当前状态**：精选91分；作品本体主、时间次、命运辅；人物层本轮首次完成
- **证据等级**：官方全书简介 + 可靠书评梗概轻筛，待原书页码复核

### 主次十元

- **主十元：`nx`，92%**
  - Jimmy长期不占据关系方向；母亲、父亲、工作场景或当下礼俗给出路线后，他才沿路线继续。
- **次十元：`z`，84%**
  - 父亲是否把他当作儿子、他人是否把他看作有能力的成年人，是其稀缺的认可位置；但多数认可只在幻想中完成。
- **状态位：`xz`，79%**
  - 见父亲、与陌生家人相处和直接谈话使他进入高度临界、退路变窄的社交状态；这是阶段压力，不是稳定本体。

### 对象端点

- `nx`端点：母亲持续来电所规定的亲子关系、父亲发出的会面邀请与周末行程、办公室现成的交往规则。
- `z`端点：父亲是否确认其“儿子”身份、同事或想象中的他人是否确认其成年能力与情感价值。
- `xz`端点：第一次父子会面、陌生家庭成员、必须开口回应的当面交流。

### 可观察行为证据

1. **母亲持续来电并控制亲子交流节奏** → Jimmy反复接听、应对，却很少主动重定关系 → 母亲设定的通话与生活路线 → 关系继续运作，但方向仍在母亲一侧。`nx`
2. **失联父亲突然邀请他见面** → Jimmy接受邀请并前往密歇根，且没有先与母亲正面协商 → 父亲给出的会面通道 → 他进入父亲规定的家庭行程，而不是自己设计一套和解方案。`nx + z`
3. **当面谈话要求他表达自己** → Jimmy发抖、口吃、常用手遮住嘴，极少主动提出新的交流方向 → 父亲与陌生人的认可位置 → 直接表达退缩，选择权重新落回对方和场景。`nx + xz状态`
4. **父子会面不断出现尴尬与不适** → 他仍跟随用餐、出行和家庭拜访，并与同父异母妹妹形成短暂而试探性的联系 → 父亲的新家庭与既定周末安排 → 没有抢回方向，但也没有直接逃离。`nx`
5. **现实社交无法给予完整认可** → Jimmy转入超级英雄、爱情或能力幻想，在想象中完成主动、被喜欢和有力量的自己 → 想象中的观众与认可主体 → `z`被保存在幻想界面，未稳定转成现实占位。`z行为`
6. **父亲突然死亡、短暂和解路线中断** → Jimmy回到芝加哥和原有生活结构 → 旧工作、独居与母亲关系 → 外部方向消失后，他没有建立新的稳定路线，重新落回既有现状。`nx`

### 主角行为模式总结

> 外部关系先给出一条路 → Jimmy沿着走却很少重定方向 → 需要被父亲或他人确认的部分退回幻想 → 现实关系一旦断开，他又回到原来的生活轨道。

### 反证与误判防线

- 他确实接受邀请并跨州见父亲，说明不是完全没有行动；但行动方向来自父亲，因此更接近`nx`而非`xn`。
- 英雄幻想具有`z/zx`表象，但现实中的权能没有公开扩大，不能据此判稳定`zx`。
- 家族谱系和页面时间结构属于作品层，不能直接把Jimmy判成`xn`。
- `z`与`nx`共现，但Jimmy的认可需求多数没有持续表达、决定和占位，因此本轮**不宣布`z克nx`已正式启动**；这是一例“关系位置存在而机制未启动”。

### 与作品主维关系

- **不一致但可解释**：作品的本体主维来自跨代父子身份与存在困境；Jimmy人物本体更像`nx`，即把方向长期让给母亲、父亲和现状。
- 人物`nx`不能反写作品为因果型，也不能取消家族时间结构。

- **辅助位：`n`，80%**

3. **“朋友”身份仍不清楚且危险逼近** → 贤知继续追查而非退回便利店日常 → 嫌疑人、旧伙伴和事件顺序 → 内部责任压过维持普通生活的现成路线。`zn + xn`
4. **组织追捕加剧、正面对抗条件尚未成熟** → 他转入地下并等待反击机会 → 自身暴露度、伙伴安全与行动时点 → 即时冲动被调查和时机结构限制。`xn克zx候选`
5. **“朋友”按童年方案发动世界级灾难** → 贤知拿起吉他、作出站起来的决定并前往演唱会面对“朋友” → 公共舞台与灾难执行者 → 内部责任进入公开行动，但没有变成个人权力扩张。`zn → zx功能`
6. **十八年后世界仍受“朋友”控制** → 被认为已经牺牲的贤知重新出现并前往东京阻止下一项计划 → 东京、旧伙伴与最终威胁 → 跨越失踪阶段后仍回到同一责任方向。`zn + zx功能`

### 主角行为模式总结

> 现实异常唤醒童年责任 → 贤知把记忆、图案、旧友与事件节点组织起来 → 必要时潜伏等待 → 节点到来便亲自进入公开风险，承担自己认为不能转交的责任。

### 反证与误判防线

- 调查、潜伏和等待具有`xn`，但它们服务的是内部责任，拿掉`zn`后贤知没有持续冒险的理由。
- 演唱会和返回东京具有`zx`行为，但他没有追求凌驾所有人的权位，不能因“救世英雄”直接判稳定`zx`。
- 作品后段神乃成为重要行动主体；其组织人群的行为不计入贤知。

### 生补克机制

- **`xn克zx`候选**：贤知先整理线索、召回旧友并潜伏等待，使直接对抗必须进入特定节点；被改变的是`zx`公开行动的时机与路径，而不是贤知本体。
- **`zn克xn`候选**：内部责任使他放弃便利店的普通运行路线，并拒绝“朋友”已经组织好的社会秩序；需原卷确认两段作用是否跨阶段持续。

### 与作品主维关系

- **部分一致**：人物次十元`xn`支持作品的时间组织；但贤知主十元是`zn`，不能因作品时间型而反推人物主`xn`。
- 作品的因果链很强，人物仍以内部责任而不是“直接权能/关系借力”作为稳定锚点。

#### 行为模式总结

> 明知原关系不可恢复 → 仍为眼前存在保留朋友位置 → 当危险逼近时，不靠否认维持关系，而是组织调查和封闭任务，让“继续同行”拥有现实条件。

#### 反证

- 危险逼近很强，但`xz`主要来自外部替换与裂隙，不能直接升级为人物稳定本体。

#### 关系候选

- **`xz↔nz`补位候选**：危险替换持续压缩关系的安全边界；佳纪的`nz`提供“不立即切断”的停靠条件，使调查路径得以形成。是否构成正式互补，需原卷确认关系并非单纯恐惧或依赖。

- `xz`端点：异界裂隙、跨界返回与身体失稳。

#### 可观察行为证据

1. **从山中回来后必须进入原光的生活** → “光”以原有脸、声音和记忆继续上学并与佳纪相处 → 原光的社会身份接口 → 内外不同，但壳实际承担了存在与关系功能。`x并z`
2. **佳纪知道替换事实且可能远离** → “光”持续寻求友谊并保护佳纪 → 佳纪的认可与安全 → 不只维持冒充，还争取作为新存在被留下。`z + nz`
3. **连它自己也不知道真实身份** → 它与佳纪共同调查村史和光留下的笔记 → 自身来源、Nounuki-sama与地方历史 → 主动把“壳下是什么”变成调查对象。`x并z + xn功能`
4. **佳纪承认它已成为独立朋友** → “光”继续以自己的关系位置与佳纪同行 → 朋友身份与日常接口 → 外壳提供的可见位置获得新的个体认可。`x并z生z候选`
5. **裂隙继续扩大、需要封闭** → “光”参与计划并准备进入充满危险的裂隙 → 异界通道与封闭任务 → 以身体承担高风险行动，暂时离开日常壳。`xz行为`
6. **封洞后被困在另一侧** → “光”为完成佳纪唯一的愿望拼命寻找返回方法 → 佳纪的愿望与回返路径 → `nz`的关系停靠推动临界回返。`nz + xz行为`

#### 行为模式总结

> 先借“光”的身份界面进入人类关系 → 在佳纪的确认中获得独立朋友位置 → 与佳纪共同调查自身 → 当关系受到裂隙威胁时，以高风险行动争取回到这个认可位置。

#### 反证

- `x并z`不是“它会骗人”的道德判断；关键是光的外形与记忆确实构成其存在界面。
- 进入裂隙具有`xz/zx`行动，但目标是封洞与回返，不是公开扩大权能或凌驾他者，不能判稳定`zx`。

#### 关系候选

- **`x并z生z`候选**：光的脸、声音和记忆先提供可见、可互动的界面；佳纪随后确认“新存在也是朋友”，改变的是“光”的被认可身份。仍需原卷排除“只因旧记忆产生的投射”这一第三因素。

## 4. Blue Box / 青之箱

### 分析对象

- **主角**：猪股大喜 / Taiki Inomata
- **身份**：高中羽毛球部员；暗恋女子篮球部前辈鹿野千夏
- **阶段**：早训与暗恋起点 → 县预选赛 → 初夏关系阶段
- **来源文件**：`02-时间型 xn+z.md`、`01-本体型 zn+x.md`、总索引、同名冲突队列
- **当前状态**：英文/中文条目均92分；同作置信96%，ready-to-merge待二审；人物层按同作一次分析
- **证据等级**：VIZ第1—6卷官方书目轻筛，待原卷章节验证

### 主次十元

- **主十元：`z`，89%**
  - 千夏是否看见并确认他的认真、能力和感情，是贯穿运动与恋爱两线的明确认可位置。
- **次十元候选：`xn`，86%**
  - 全国赛目标、长期训练和赛季节点构成稳定积累；但第2卷训练方案由针生给出，主体组织性仍需原卷复核。
- **辅助位：`nz`，83%**
  - 他常以鼓励、陪伴和照顾维持与千夏的关系，而不是直接占有。
- **关系功能：`nx`，81%**
  - 接受搭档制定的强化训练、沿校队和比赛体系推进；这是办事路径，不等于人物没主见。

### 对象端点

- `z`端点：千夏对其羽毛球能力、坚持与感情的确认；正式比赛对运动能力的公开确认。
- `xn`端点：早晨训练、针生安排的强化方案、县预选赛和全国赛目标。
- `nz`端点：鼓励千夏继续梦想、失利后为她庆生并陪伴。
- `nx`端点：针生作为双打搭档给出的训练路线，以及校队既有比赛流程。

### 可观察行为证据

1. **距离全国赛仍很远** → 大喜持续进行羽毛球训练，并把全国赛保留为长期目标 → 自己的身体、技术与赛季 → 运动能力被放入持续积累，而不是只靠一次比赛爆发。`xn候选`
2. **看见千夏独自刻苦练习并产生感情** → 他鼓起勇气告诉她不要放弃梦想 → 千夏的运动选择与对大喜的看法 → 把自己送入认可主体视野，但表达内容先是支持对方。`z + nz`
3. **新双打搭档针生制定高强度训练** → 大喜接受并完成训练 → 搭档权限、训练节奏与全国赛目标 → 沿外部专业路线借力，使长期目标变得可达。`nx功能 + xn积累`
4. **县预选赛开始、训练必须接受公开检验** → 他参加艰苦双打并面对强校 → 对手、搭档和全国赛资格 → 训练结果进入可被确认的比赛场。`z + xn`
5. **夏日祭中遇到走失女孩，同时夹在雏与千夏之间** → 大喜与千夏先帮助女孩找到母亲，随后回到等待他的雏身边 → 走失女孩和两段关系责任 → 在情感混乱时仍先完成眼前关系任务。`n行为 + nz`
6. **千夏经历艰苦败北且生日临近** → 大喜带她去海边庆生，希望让她振作 → 千夏的失落与两人关系 → 以陪伴和具体行动维持关系温度，而不是要求立即回应感情。`nz + z`

### 主角行为模式总结

> 先把千夏设为重要认可位置 → 以训练和正式比赛建立“值得被看见”的能力 → 在关系节点上更多选择鼓励与陪伴，而不是直接夺取答案。

### 反证与误判防线

- 训练很强不自动等于人物主`xn`；第2卷训练方案由针生制定，必须区分大喜主动组织与`nx`沿外部路线执行。
- 他帮助走失女孩属于`n`行为，但没有跨阶段证据证明其稳定主本体为`n`。

### 生补克机制
