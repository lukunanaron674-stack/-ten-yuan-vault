- 行为1：艾伦发动地鸣直接踏平城墙与世界地表、艾伦按地鸣規則、按城墙承载的破壞、按地鸣的时辰把城墙按时辰踏平 → **克制维度**：zx 阳木 → 克 n 阳土（城墙/世界地表 n 阳土 载体受 zx 直接破壞）。→ 作用于城墙与世界地表 → 承载按时辰被艾伦踏平。
  - 归类：zx（阳木，主位证据，96%）。对象端点：城墙与世界地表 n 阳土 载体直接破壞（zx 阳木 → 克 n 阳土）。

  - 归类：nx（阴金，主位证据，90%）。对象端点：第104期訓練兵排名既有通道。
- 行为3：艾伦在トロスト区攻防战中第一次变身巨人堵墙洞、艾伦按巨人的運用、按墙洞的封堵、按封堵的时辰把墙洞按时辰封堵 → 作用于巨人体 → 封堵按时辰被艾伦接收。
  - 归类：zx（阳木，主位证据，95%）。对象端点：巨人直接顯权封堵墙洞。
- 行为4：艾伦在训练兵中与三笠/让/阿尔敏/赫里斯塔等同僚共闘、艾伦按共闘規則、按同僚的戰法、按共闘的时辰把同僚按时辰共闘 → 作用于同僚との共闘関係 → 共闘按时辰被同僚接收。

- 行为5：艾伦在莱纳/安妮/贝尔特鲁特暴露真身时当场宣战、艾伦按宣战規則、按暴露的真身、按宣战的时辰把真身按时辰宣战 → 作用于暴露真身的铠之巨人组 → 宣战按时辰被莱纳/安妮/贝尔特鲁特接收。

  - 归类：zn（阳火，主位证据，92%）。对象端点：アクア独立主体資格保存（共闘關係）。

**统计**：zn×2（保護ルビー/共闘アクア）+ nx×1（アイ指导接收）+ xn×1（演艺舞台）+ z×1（事務所交渉単点）+ n×1（演艺危机承载回应，**首个 n 元主位证据样本**）。共 6 条候选进入基础库。本主角主十元候选 `zn` 93%，次 `n` 90%。
