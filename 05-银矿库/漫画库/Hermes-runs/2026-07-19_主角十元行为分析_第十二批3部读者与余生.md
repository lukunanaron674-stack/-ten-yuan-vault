## 一、棋魂 / Hikaru no Go

### 进藤光（Hikaru Shindo）

**来源文件**：[[漫画库总索引]]、[[01-本体型 zn+x]]、[[05-命运型 xz+nz]]、[[Hermes-漫画五大主题任务清单]]；外部核验采用VIZ第1、4、8、12、17、23卷。

**当前分析状态**：全23卷官方书目轻筛；前中期认可驱动与后期内在棋道迁移已分层，待第1—4、8—12、17、23卷页码复核。

**人物阶段**

- 前中期主`z`95%：认可主体为塔矢亮及职业棋手共同体；被认可内容是“进藤光自己的棋力”，不是佐为代下的棋。
- 后期`zn`迁移候选94%：佐为消失后，围棋逐渐从得到对手承认的竞技场，变成必须由自己继续的生活方式与传承位置。
- 次`xn`92%：以校队、院生、职业考试和正式对局组织练习、弱点与进阶路径。
- 早期`nx`功能86%：最初沿佐为给出的棋路进入围棋世界；该功能随自身棋力形成而下降。

**对象端点**

- `z`端点：塔矢亮、塔矢行洋、职业棋手共同体；认可内容是进藤光自身的棋力和棋手资格。
- `zn`端点：佐为留下的棋、围棋作为生活方式、把棋传向下一代的内部意义。
- `xn`端点：校队席位、院生训练、职业考试、正式比赛顺序与对局复盘。
- 不锁`x`：旧棋盘、佐为、塔矢亮和职业资格都没有被进藤光纳入“归我掌握”的控制边界。

**行为证据**

1. 在祖父阁楼发现染血棋盘、佐为进入意识 → 进藤光允许佐为通过自己下棋并跟随其进入围棋场域 → 作用于旧棋盘、佐为与最初对局路线 → 外部幽灵给出的方向形成早期`nx`功能，但尚不能证明稳定本体。
2. 塔矢亮把“进藤光”视为值得追逐的强敌，而光知道那盘棋实际来自佐为 → 光开始学习并要求以自己的棋力追上塔矢亮 → 作用于塔矢亮这一认可主体和“自己的棋”这一认可内容 → 借来的强者位置被改造成个人训练目标，支持`z`。
3. 叶濑围棋部与海王围棋部比赛 → 光作为队员亲自参赛并与塔矢亮进入可公开比较的对局位置 → 作用于校队席位、队伍结果和自身棋力展示 → 围棋不再只是替佐为提供身体接口，也成为光自己的公开能力场。
4. 佐为需要持续下棋却不能公开显现 → 光找到网络围棋这一匿名接口让佐为对局，同时继续观察和学习 → 作用于佐为的对局需求、匿名身份与光的学习输入 → 光不是占有佐为，而是组织一个双方都能继续运行的渠道，支持`n/xn`功能。
5. 进入院生与职业考试阶段，预赛对手专门利用其弱点 → 光仍在连续对局中修正弱点、争取职业资格 → 作用于训练顺序、对手反馈与正式资格 → `xn`把塔矢亮的认可目标转成可积累的能力路径。
6. 佐为消失、原有超自然支持中断 → 光必须独立承担职业棋手要求，并继续与塔矢亮、Ko Yong Ha等顶尖棋手对局 → 作用于佐为留下的棋与“围棋是游戏还是生活方式”的答案 → 后期行动从单纯争取认可转为守住并传递棋道，`zn`上升。

**行为模式总结**：先由佐为和塔矢亮把他送进围棋的认可场，再把对手目光拆成训练、考试与正式对局；当佐为消失后，他把原本借来的棋路内化为自己必须继续的生活方式。

**反证与边界**

- 开篇听从佐为并不等于全程主`nx`：职业考试和后期对局已出现自主组织与独立选择。
- 追逐塔矢亮支持`z`，但第23卷明确把关键比赛从个人荣耀推向围棋生活方式，因此纯`z`不足以覆盖终局。
- 围棋盘、职业资格和对手关系不归光控制，不能为迁就作品本体公式而补造人物`x`。

**关系判断**

- `xn补z`候选93%：院生训练、职业考试与持续复盘，为“被塔矢亮/职业共同体承认为真正棋手”补足实际棋力和公开资格；目标变量是认可的可信度与进入正式对局的能力。佐为和塔矢亮是强第三因素，故待原卷复核后再正式锁定。
- `z→zn`只是阶段迁移描述，不是现行生补克关系；佐为消失与职业成长均可能解释迁移，不能写成`z生zn`。

**与作品主维**：人物后期`zn`支持作品本体主候选，但人物没有稳定`x`端点，不能由人物单独证明完整`zn+x`。命运次维主要来自佐为跨时代停留和相遇结构，不自动把进藤光判成`xz/nz`。

## 二、愚者之夜 / Fool Night

### 神谷托士郎（Toshiro Kamiya / トーシロー）

**来源文件**：[[漫画库总索引]]、[[01-本体型 zn+x]]、[[Hermes-漫画五大主题任务清单]]；外部核验采用VIZ第1—8卷与小学馆第7、13卷书目信息。

**当前分析状态**：官方第1—8卷及日版后段书目轻筛；中文姓名先按日文`トーシロー`音译记“神谷托士郎”，待用户版本核对正式译名。

**人物十元**

- 主`n`95%：贫困、母亲、身体转花、Hourai受伤与Ivy问题不断落到他身上；他接住后继续处理，而非立即转交或退出。
- 次`zn`93%：持续追问剩余两年怎样活、转花是否正确、自己站在哪一边，并在与Ivy交流后重建活着的意义。
- `xn`调查功能90%：把Ivy来源、Paupertown、反转花运动与创造者线索组织成持续调查。
- `xz`身体/时间状态96%：转花藤蔓、剩余两年、身体向植物过渡属于高强度状态与倒计时，不自动升级为人物稳定本体。

**对象端点**

- `n`端点：母亲的医疗与生计、自己的转花后果、Hourai受伤、Ivy问题及转花院内部冲突。
- `zn`端点：怎样使用剩余人类时间、是否站在正确一方、生命和转花的意义。
- `xn`端点：Ivy来源、Paupertown调查、反转花组织动机与创造者追踪。
- 不锁`x`：工资、医疗、转花技术和转花院权限均不由托士郎实际掌握；接受手术反而意味着身体控制权被制度压缩。

**行为证据**

1. 母亲患病、工资不足以支付药物和食物 → 托士郎考虑用转花手术换取报酬 → 作用于家庭生计、自己的身体与剩余人生 → 他把家庭负担落到自身身体上处理，支持`n`，但贫困提供的单一路线也形成`nx/xz`状态压力。
2. 手术后只剩约两年人类时间、腹部藤蔓继续生长 → 托士郎主动思考这两年如何生活，并重新审视母亲关系与转花院工作 → 作用于剩余时间、家庭关系与职业位置 → 外部倒计时被转成内部意义审核，`zn`上升。
3. 童年朋友Hourai遭到仍能行动的灵花Ivy袭击 → 托士郎没有把事件留给机构处理，而被卷入追捕与调查 → 作用于Hourai安全、Ivy威胁和自己的剩余行动能力 → 已落到身上的关系问题经`n`进入`xn`调查链。
4. Hourai恢复期间、Ivy来源仍不明 → 托士郎继续追查并进入Paupertown → 作用于Ivy起源、贫困地区与转花制度后果 → 一次袭击被扩展为对制度来源的连续核查，而非只做报复。
5. Ivy引发支持/反对转花的社会分裂 → 托士郎与Hourai调查反转花抗议的隐藏动机，同时质疑自己是否站在正确一方 → 作用于机构立场、抗议者动机与个人伦理 → 行动与价值判断同时运行，不能只按职业归`nx`。
6. 追查Ivy创造者使自己、Hourai与转花院遭到攻击 → 托士郎仍进入更深危险，并在记忆与情感汇集的花田中与Ivy形成新的理解 → 作用于敌我边界、Ivy的生命经验与托士郎的生存意义 → 他没有把Ivy只当待消灭对象，而是接住其经验后改写自己的关系位置。

**行为模式总结**：贫困、身体倒计时或朋友受伤把负担压到他身上时，他先用自己接住，再把负担延展为调查与伦理追问；越接近完全转花，越要决定剩余生命应如何使用。

**反证与边界**

- 转花和倒计时是`xz`状态，不证明托士郎本体就是漂流/危险。
- 为获取报酬接受制度提供的手术含`nx`压力，但后续主动调查、质疑机构和理解Ivy不符合纯跟随。
- 以身体换钱不等于`x`：他没有取得身体、技术或制度的控制权。

**关系判断**

- `n生xn`候选92%：Hourai受伤和Ivy问题被托士郎接住后，为持续调查建立了对象、路径与继续条件；目标变量是调查能否启动并延续。转花院任务与Hourai自身行动是第三因素，故暂列候选。
- `zn生n`候选87%：当“怎样活/是否正确”的内部意义形成后，托士郎更愿意继续承接Ivy与转花争议；但官方书目不足以排除生存本能和机构职责。

**与作品主维**：托士郎`zn`支持作品本体追问，但人物层没有稳定`x`；作品`x`更可能来自制度对身体、技术和生存资源的归属控制。人物主`n`说明“承接身体与关系后如何处理”，不推翻作品现有本体主位。

## 三、全知读者视角 / Omniscient Reader’s Viewpoint / ORV

### 金独子（Dokja Kim）

**来源文件**：[[漫画库总索引]]、[[01-本体型 zn+x]]、[[Hermes-漫画五大主题任务清单]]、[[漫画库_全名单-精修版-2026-06-02]]；外部核验采用Ize Press漫画第1—8、10卷。

**当前分析状态**：漫画实体版第1—8卷轻筛；人物结论不借用小说后期信息。中文93分条与旧`ORV全知读者视角`73.3分来源冲突待二审。

**人物十元**

- 主`xn`97%：把独占的小说知识、场景规则、敌我角色与时间节点组织成可执行方案，反复改写原定坏结局。
- 次`zn`94%：不仅求生，还以“不接受原定悲剧/不以神王统治”的内部边界筛选方案。
- `x`资源功能90%：实际掌握的对象只限于独家TWSA知识、已取得的情报与场景奖励；世界、人物和故事本身不归他所有。
- `zx`执行功能88%：计划到关键节点时亲自进入地下城、争夺王座或迎战；直接行动服务于方案，不是稳定主位。

**对象端点**

- `xn`端点：TWSA剧情顺序、场景触发条件、队伍行动、敌我角色、坏结局与替代路线。
- `zn`端点：同伴不能按原作悲剧消耗、世界不应由绝对王座统治、读者应承担改变结局的责任。
- `x`端点：只有他掌握的小说信息、已获得奖励与临时决策权限；不包含刘众赫、同伴或整个Star Stream。

**行为证据**

1. 冷门网络小说完结后，现实立刻变成书中末日场景 → 独子确认自己掌握后续情节并从旁观读者转为行动者 → 作用于首轮场景、幸存路径与独家信息 → 小说知识被组织成现实求生方案，主`xn`显影。
2. 第一轮混乱后与队伍分离、被怪物包围 → 独子继续利用剧情知识判断局势，并进入与原作主角刘众赫相遇的节点 → 作用于自身生存、原作人物与后续路线 → 他没有机械复述小说，而是在现实偏差中重新定位。
3. 刘众赫在混乱中失踪、原作主角死亡会威胁整个世界进程 → 独子主动进入Cinema Dungeon寻找他 → 作用于刘众赫生存和世界后续场景 → 对剧情结构的判断转成直接救援行动，`xn`调用`zx`。
4. 其他熟悉TWSA的“门徒”出现，独家知识优势受到威胁 → 独子与其他读者竞争并追查其首领身份 → 作用于情报优势、敌我识别与方案保密性 → `xn/x`资源边界被迫重新校验。
5. 王之战争会导致不可逆坏结局 → 独子争取绝对王座资格，甚至与刘众赫正面对决 → 作用于王座权限、首尔结局和同伴生存路径 → 直接战斗是取得改写权限的节点，不是为了公开显权本身。
6. 获得“可以像神王一样统治”的机会 → 独子拒绝绝对王座，主动选择无王世界，即使后来必须承担失序后果 → 作用于最高控制权与世界秩序 → `zn`内部边界压过对`x/zx`权能的占据冲动，但现行关系盘不支持据此直接宣布`zn克x`。

**行为模式总结**：场景一启动，他先把原作知识、人物位置和失败结局排成模型，再组织同伴与关键节点改写路线；当方案需要取得巨大权能时，他会用内部价值边界决定哪些控制不能保留。

**反证与边界**

- 独占小说知识使`x`有功能显影，但核心不在收藏信息，而在持续把信息组织成下一场方案，因此不判`x`主。
- 刘众赫是原作路线端点，不是独子的主人或固定上级；独子不断改写原剧情，不符合稳定`nx`。
- 作品题名和“读者身份”不能直接证明`z`；当前官方卷册更稳定支持组织与改写，认可主体并不清晰。

**关系判断**

- `xn克zx`候选93%：剧情知识与场景计划通过改变交战时机、目标顺序和权限获取方式，压缩纯正面战斗的必要性；被改变变量是`zx`执行的路径和成本。小说先验与同伴战力是强第三因素，故暂列候选。
- 王座事件只证明`zn`限制了占据最高控制权的选择；因现行`zn↔x`是补位盘而非克位盘，本轮不虚构`zn克x`关系。

**与作品主维**：人物主`xn`与作品现有本体主`zn+x`并不一致；作品本体问题来自“读者如何成为故事中的存在者”和故事/权能归属，人物运行层则稳定表现为组织与改写。该差异不足以推翻93分或作品主位，但要求后续不要用作品公式倒贴金独子。
