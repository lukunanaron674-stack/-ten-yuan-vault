## 一、花牌情缘 / Chihayafuru / ちはやふる

### 绫濑千早（綾瀬千早 / Chihaya Ayase）

**来源与阶段**：[[02-时间型 xn+z]]、[[漫画库总索引]]、Hermes任务清单；小学六年级遇见新至女王战终局。讲谈社正式系列共50卷。

**当前状态**：跨卷官方书目轻筛；女王预选、负伤恢复与终局具体话次待复核。

**十元判断**

- 主十元：`z`，95%。具体认可端点是竞技歌牌的正式级位、全国赛出场、女王挑战权与女王头衔；她反复把能力放进公开比赛接受验证。
- 次十元：`xn`，93%。对象端点是读音反应训练、牌阵与身体调整、社团招募/组队、地区预选和逐级赛事安排。
- 深层候选：`zn`，90%。具体内部标准是“歌牌是自己的梦想与持续连接人的方式”，并非只为一次胜负或他人称赞。
- 功能位：`n`，88%。承接新的技术示范、读手声音、败北、伤病与队友比赛信息，再转进下一轮训练。
- `x`端点：未成立。她没有因为担任部长或争女王就实际占有整个社团、赛事权限或他人关系。

**行为证据**

1. 小学六年级看见新以极快反应取牌 → 千早亲自上场并显出被新认可的天赋 → 作用于自己的竞技能力与可见身份 → 歌牌从外部游戏转成可以公开验证的个人目标。
2. 小学毕业迫使三人分开 → 千早仍与太一、新参加最后一次团体赛，并把“继续变强再相见”作为后续路线 → 作用于分离后的共同连接 → 一次关系输入没有停在怀念，而进入长期赛事/训练方向。
3. 升入瑞泽高中、缺少现成队伍 → 千早与太一招募新成员、建立竞技歌牌部并参加东京预选 → 作用于成员、训练与参赛资格 → 以`xn`把个人目标组织成可持续团队结构。
4. 首次全国赛被迫退出团体赛 → 千早在失望中接受队友鼓励，转入个人赛并面对现任女王若宫诗畅 → 作用于正式比赛资格 → `z`没有因一次退出消失，而通过新的公开赛道继续显影。
5. 手指受伤并在全国个人赛半决赛输给诗畅 → 千早停止只盯自己的败局，转去观看太一的B级比赛；恢复后继续为女王预选训练 → 作用于比赛信息、身体与后续路线 → 败北/伤病经`n`进入新的`xn`准备，而不是直接证明人物本体改变。
6. 多年级位赛、预选和对手交锋累积 → 千早进入女王战第五局，并把最后一张决定牌纳入正式胜负 → 作用于女王头衔与自身公开能力 → 早期“被看见的天赋”最终变成可由完整竞赛结构验证的位置。

**行为模式总结**：每当分离、退赛、败北或伤病切断上场路线，千早都会把新收到的信息和关系支持重新组织成训练、组队与下一场正式比赛，持续逼近女王这一公开验证位置。

**反证与关系机制**

- 她会招募、训练和调整，反驳“只靠天赋、只要被看见”的纯`z`判断；跨多年继续比赛使`zn`存在，但目标长期仍通过公开级位/头衔显影，因此本轮保留主`z`。
- `xn补z`（93%）：社团、训练、伤病恢复和逐级预选提供她取得公开比赛资格与女王挑战权所缺的持续条件，目标变量是“可被正式验证的竞技位置”。
- `n生xn`候选（86%）：新、队友、败北和伤病提供输入，千早把它们转为社团/训练结构；太一等人的组织贡献是第三因素，故不把全部团队结构归给千早一人。

**与作品主维**：人物主`z`、次`xn`恰与作品时间型`xn+z`构成相邻，但不能反推作品主维。作品时间性还包括代际、诗歌记忆、读音先后和所有人物的长期赛事结构。

## 二、拉面发现传 / ラーメン発見伝

### 藤本浩平

**来源与阶段**：[[03-空间型 x并z+n]]、[[漫画库总索引]]、Hermes任务清单；公司职员/夜间屋台双身份至第26卷开店。

**当前状态**：第1、2、6、10、12、21、23、26卷官方简介轻筛；配方改动与最终对决话次待原卷复核。

**十元判断**

- 主十元：`xn`，96%。对象端点是白天公司/夜间屋台的排程、食材与配方试验、味道/成本/客流诊断、店铺运营和比赛准备。
- 次十元：`z`，91%。对象端点是顾客评价、料理节目、拉面比赛、职业店主标准以及芹泽这一行业认可/否定端点。
- 深层候选：`zn`，88%。具体内部标准是“以做拉面而非只评论拉面生活”，在终局落实为离职开店。
- 功能位：`x并z`85%。公司职员、屋台主与覆面参赛者是不同身份接口；这解释隐瞒/显露方式，不自动成为人物主位。
- `x`端点：84%，仅作功能。前中期实际掌握自己的屋台、配方与器具，终局才扩为正式店铺；不能把他帮助的其他店铺算作归他所有。

**行为证据**

1. 白天在大勇商事工作、夜晚经营拉面屋台 → 藤本把公司任务、采购、备料和营业放进两套时间表 → 作用于自己的时间、器具和顾客 → 双身份得以长期运行，直接支持主`xn`。
2. 在名店吃到不合格拉面 → 藤本当众说难吃并声称自己能做得更好 → 作用于店主和自己的厨师资格 → 把私人判断推入公开验证场，形成`z`节点，也招来必须实际做出的压力。
3. 芹泽试吃屋台拉面并批评“不够职业” → 藤本愤怒后精选食材、为盐味拉面对决做准备 → 作用于配方与比赛结果 → 外部否定经`n生xn`变成可检验的配方流程，同时暴露单靠好食材仍有盲点。
4. 繁盛店/旧店向他求助，或他在旅行中遇到经营问题 → 藤本查看节目、品尝汤面、追查食材/做法/顾客反应并协助调整 → 作用于味道与营业变量 → 把一次“好不好吃”拆成可修改的技术和商业链。
5. 通过拉面迷王首轮、又被店主挑衅；后续因屋台不能暴露给公司而覆面参加料理节目 → 藤本继续用作品接受公开评价，同时管理公司员工/屋台主两种身份接口 → `z`与`x并z`都显影，但不等于稳定`zx`。
6. 六麺帝最终轮有人受伤缺席 → 藤本决定代打，接受与芹泽的最终对决，以“进化系酱油拉面”汇总多年修业；胜负与离职开店绑定 → 作用于配方、职业身份和正式店铺 → 长期`xn`积累最终把`zn`方向落实为“拉面ふじもと”。

**行为模式总结**：遇到批评、经营危机或比赛主题时，藤本先拆分味道与商业变量，再安排配方/营业试验，以顾客和比赛结果校验，最终把隐藏屋台累积成正式店铺。

**反证与关系机制**

- 当众叫板、覆面参赛和终局决斗是`z/zx`行为，但他并未长期以权能压服行业；稳定主骨仍是反复诊断、试验和运营。
- `n生xn`（94%）：试吃结果、芹泽批评、店主咨询和客流反馈成为配方与运营调整的输入，目标变量是“下一版可运行方案”。
- `xn补z`（90%）：长期屋台运营与比赛准备补足公开验证所需的产品/职业能力，目标是被顾客、评委与行业承认为能开店的人。

**与作品主维**：人物主`xn`、次`z`不支持把“一碗面是便携味觉空间”直接当作作品唯一主证据。空间容器仍可保留，但跨卷商业诊断、技术试验与对决结算可能让时间/因果权重上升；本轮新增dimension-conflict待二审，不改92分或正式归仓。

## 三、神之水滴 / 神の雫 / The Drops of God

### 神咲雫（Kanzaki Shizuku）

**来源与阶段**：[[03-空间型 x并z+n]]、[[漫画库总索引]]、Hermes任务清单；父亲去世与遗嘱启动至第44卷第十二使徒确认。只分析原系列，不把续篇《Mariage》事件混入。

**当前状态**：第1—3、20、44卷官方书目与全系列简介轻筛；各使徒具体卷次/酒款待复核。

**十元判断**

- 主十元：`n`，97%。具体接收端点是香气、味道、口感、视觉联想、记忆、地域/诗歌信息以及用餐者的需求；他首先让酒进入感官和经验，再描述/处理。
- 次十元：`xn`，93%。对象端点是遗嘱中的诗性线索、候选酒比较、旅行地点、试饮顺序、餐酒搭配和十二使徒调查链。
- 深层候选：`zn`，89%。具体内部标准从“拒绝父亲的葡萄酒世界”逐步迁移为以自己的感官理解酒与父亲留下的问题。
- 开篇状态：`nx`84%。遗嘱和继承竞赛给出外部方向，但他没有一直照做；进入各轮后会主动组织调查，故不判稳定主`nx`。
- `x`端点：未成立。父亲的酒藏在解题前并不归他实际调配；争继承权不等于已经掌握酒藏。

**行为证据**

1. 为反抗父亲的葡萄酒权威而去啤酒公司做销售 → 父亲去世、遗嘱要求辨认十二使徒与“神之水滴” → 雫进入与远峰一青竞争的外部路线 → 开篇有`nx`状态，但方向冲突也说明他不是顺从父亲的纯`nx`人物。
2. 开始接触葡萄酒 → 雫用异常敏锐的味觉/嗅觉接住酒的变化，并把体验转成具体意象和语言 → 作用于候选酒的可辨认特征 → 主`n`显影；感官能力不是占有酒藏的`x`。
3. 紫野原雅打碎昂贵酒瓶 → 雫承担寻找替代酒的任务，试选可复现那段体验的酒 → 作用于朋友的损失与候选瓶 → 接收他人问题后组织替代方案，而非只炫耀品鉴。
4. 一青的严厉评论令法国餐厅濒临倒闭 → 雫与雅品尝并追查评论原因，重新寻找酒与料理的协调 → 作用于餐酒搭配和店铺生存 → 感官输入经`n生xn`变成诊断/修复流程。
5. 遗嘱把第六使徒比作弥勒佛像 → 雫前往京都，接收餐厅经营者、古诗与地域经验的启发，再把这些线索对照候选酒 → 作用于第六使徒识别路径 → 旅行不是空间主角证据，而是`xn`调查容器。
6. 多轮使徒识别累积至第44卷 → 雫与一青分别找到满足明绘和京香愿望的酒，并据此确认第十二使徒候选 → 作用于他人需求、候选比较与遗嘱进度 → 说明他的判断长期依靠“接收具体体验→组织线索→再验证”。

**行为模式总结**：收到一段诗性线索、酒的感官经验或具体人的需要后，雫会先充分接住，再通过旅行、比较、试饮与餐酒搭配把体验组织成可验证的识别答案。

**反证与关系机制**

- 遗嘱启动路线不等于稳定`nx`：雫反抗父亲、主动选取调查方法并处理他人问题；外部只给题目，没有替他组织答案。
- 争夺酒藏不等于`x`：正式掌握权尚未取得，现阶段能证明的是感官接收与调查运行。
- `n生xn`（96%）：味觉/嗅觉、诗歌、地域和用餐者愿望提供调查展开条件，目标变量是“候选酒比较与使徒识别路径”；这是本轮最稳定关系。

**与作品主维**：人物主`n`直接对应空间型`x并z+n`中的承载/接收一端，也让酒瓶内的地域、记忆和意义得以展开；但人物只有`n`不能单独证明作品完整空间公式，90分与正式空间主位保持不动。
