- 行为1：东京艺大预备校入试前夜 → 八虎把画室所有灯关掉重开、按考题重新摆放静物、用手机拍三遍实景作为构图参考 → 作用于考题布置与画室空间 → 当晚画室被调整到符合考题布局。

  - 归类：z（阴火，主位证据，94%）。对象端点：考学路径与个人作品方向的最高裁定。
- 行为3：第二次艺大考试前一天，颜料被大雨泡坏 → 八虎重新采购可替代的国产颜料、把原计划中的混合色全部按新颜料重配 → 作用于考期与配色方案 → 第二天考试的画全部按新颜料重画完毕。
  - 归类：xn（阳金，主位证据，92%）。对象端点：颜料采购流程与配色方案。
- 行为4：矢口父亲参观画室 → 八虎主动把父亲带去看所有未完成画、按作品编号逐张讲出创作动机、讲到第六张时父亲落泪 → 作用于父亲与未完成画 → 父亲当晚把家用月费直接汇给八虎。
  - 归类：x并z（阴木，主位证据，91%）。对象端点：未完成画的对外读取界面与父亲身份识别。
- 行为5：国内大学报考截止前一周 → 八虎把所有校历复印三份、按自己排序的考试日错开、把每份贴在画室、冰箱、宿舍门上 → 作用于报考截止与日程 → 三份校历一周内按错开顺序完成。
  - 归类：xn（阳金，主位证据，93%）。对象端点：报考日程节点与三处张贴流程。
- 行为6：东京艺大实地写生考试当天 → 八虎按写生指定路线在校园走三圈、用手机拍每条路线光影、按照片选定考试站位 → 作用于写生路线与站位 → 考试当天站位与光影完全匹配照片。
  - 归类：xn（阳金，主位证据，95%）。对象端点：写生路线节点与考试站位。

统计：`nx`×1（候选→接近 locked 门槛，与既有 5 条并列）、`z`×1（候选→新归类进入）、`xn`×3（候选）、`x并z`×1（候选）。共 6 条候选进入基础库。本主角主十元候选 `nx` 94%，次 `xn` 92%；`z` candidate 94 接近 locked。

## 二、钻石王牌 / Ace of the Diamond · 泽村荣纯

- 行为1：夏季甲子园第一场比赛前一天 → 荣纯把投手板按上风向、脚的位置、对方打击顺序画成图、按图把每局配球顺序写在小本子上 → 作用于配球与比赛日 → 第二天比赛开局按小本子执行。
  - 归类：xn（阳金，主位证据，96%）。对象端点：配球流程与每局执行顺序。
- 行为2：决赛前夜，对方监督更换先发打者 → 荣纯当晚重新读该打者高中三年全部数据、用荧光笔标出每个好球带 → 作用于配球笔记与打者数据 → 第二天比赛对该打者首局三球全按荧光笔记号打。
  - 归类：xn（阳金，主位证据，95%）。对象端点：打者数据流程与配球笔记。
- 行为3：御幸受伤不能捕手 → 荣纯与替补捕手花三小时对齐暗号表、把过去两年的暗号全重新讲一遍 → 作用于替补捕手与暗号 → 替补捕手当天比赛按新暗号完成全部接球。
  - 归类：xn（阳金，主位证据，94%）。对象端点：替补捕手协作流程与暗号表。
- 行为4：比赛暂停期间队内争执 → 荣纯把所有人叫到投手板前、让每位打者按顺序讲一次"我下一局会做什么球" → 作用于队伍节奏与打法 → 暂停结束后队伍回到统一节奏。
  - 归类：xn（阳金，主位证据，92%）。对象端点：队伍执行节奏与每局节点。
- 行为5：第七局两出局、比分平 → 荣纯向捕手递暗号要求按预设的内角直球投、捕手摇头、荣纯改用变速球 → 作用于暗号与捕手判断 → 变速球被打者击中但被外野手接杀。
  - 归类：nx（阴金，主位证据，96%）。对象端点：捕手既定判断与既有暗号通道。
- 行为6：比赛结束后被队友围住 → 荣纯把本子交回教练、转身独自走回宿舍 → 作用于教练与本子所有权 → 教练当晚把本子列入队史档案。
  - 归类：z（阴火，主位证据，92%）。对象端点：配球本子的最高裁定归属。

统计：`xn`×4（候选→第八条 locked 候选）、`nx`×1（候选→跨人物第三条 locked 候选）、`z`×1（候选→与既有两条并列）。共 6 条候选进入基础库。本主角主十元候选 `xn` 95%，次 `nx` 93%；`xn` 行为 5 接近第八条 locked 门槛。

## 三、Low Tide in Twilight / 물가의 밤 · 吕太洲 / Taeju

  - 归类：xn（阳金，主位证据，93%）。对象端点：懿玄在校信息通道与桌面放置。
- 行为3：家中水管半夜破裂 → 太洲当晚关总阀、联系修理工预约第二天最早时段、把一家四口的夜间用水方案贴在卫生间门 → 作用于家中水管与用水方案 → 一夜未淹水，第二天早上修理工按时到场。

  - 归类：nz（阴土，主位证据，93%）。对象端点：父亲生日记忆与家族关系停靠。
