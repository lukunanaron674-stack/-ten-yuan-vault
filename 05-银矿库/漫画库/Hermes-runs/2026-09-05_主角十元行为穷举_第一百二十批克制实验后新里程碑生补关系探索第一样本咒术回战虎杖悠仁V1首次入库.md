## 一、咒术回战·虎杖悠仁 V1 首次入库 (zn 阳火 + zx 阳木 双主位证据)

- **主角身份**: 高中生 → 爷爷死后吞下特级咒物「宿傩之指」→ 咒术高专学生 → 多次救人 → 虎宿大战
- **证据范围**: 集英社 ジャンプ 咒术回战 公开约 30 巻 + 維基百科 (公開範圍窮舉, 非全作逐页)
- **分析状态**: 首次入庫 (咒术回战 虎杖悠仁 此前未做过穷举, 本次为首次入库)

- 行为1: 虎杖在爷爷遗言「在周围人面临危机时救人」的引导下多次保护他者, 虎杖按救人的規則、按被保护的他者、按保护的时辰的, 把他者按时辰保护 → 作用于被保护的他者 → 保护按时辰被虎杖接收。
  - 归类: zn (阳火, 主位证据, 96%)。对象端点: 爷爷遗言的救人他者独立主体資格保存 (zn 阳火, **生补关系第一样本: zn 阳火保护 → n 阳土承载**)。
- 行为2: 虎杖在吞下宿傩之指后以身体承载宿傩的呪力, 虎杖按身体的承载規則、按宿傩的呪力、按承载的时辰的, 把宿傩按时辰承载 → 作用于身体 → 承载按时辰被虎杖接收。
  - 归类: n (阳土, 主位证据, 94%)。对象端点: 宿傩呪力 n 阳土载体承载 (n 阳土, **生补关系第一样本: 行为1 zn 阳火保护 → 行为2 n 阳土承载, 火生土**)。
- 行为3: 虎杖在救人中与伏黑/钉崎/野蔷薇组成组织计划, 虎杖按組織規則、按救人的计划、按组织的时辰的, 把救人按时辰组织 → 作用于救人的计划 → 组织按时辰被虎杖接收。
  - 归类: xn (阳金, 主位证据, 93%)。对象端点: 救人组织流程 (xn 阳金, **生补关系链: 行为1 zn → 行为2 n → 行为3 xn, 火生土生金**)。
- 行为4: 虎杖在战斗中以黑闪直接显权破壞咒灵身体, 虎杖按黑闪的戰法、按咒灵身体的击杀、按戰法的时辰的, 把咒灵按时辰击杀 → 作用于咒灵身体 → 击杀按时辰被虎杖接收。
  - 归类: zx (阳木, 主位证据, 95%)。对象端点: 咒灵身体直接顯权击杀 (兼 zx 克 n **第八样本, 跨咒术回战**)。
- 行为5: 虎杖在黑闪觉醒后选择继承爷爷遗言保护他者, 虎杖按继承規則、按爷爷遗言的保护、按选择的时辰的, 把遗言按时辰继承 → 作用于爷爷遗言 → 继承按时辰被虎杖接收。
  - 归类: z (阴金, 主位证据, 93%)。对象端点: 爷爷遗言単点最高裁定 (z 阴金, **生补关系: zx 黑闪显权 → zn 保护意识, 木生火**)。
- 行为6: 虎杖在宿傩出现时以臨界面介入压制宿傩, 虎杖按壓制規則、按宿傩的压制、按压制的时辰的, 把宿傩按时辰压制 → 作用于宿傩 → 压制按时辰被虎杖接收。
  - 归类: xz (阳水, 主位证据, 94%)。对象端点: 宿傩临界面介入 (xz 阳水, **生补关系: xz 临界面 → 压制宿傩显权, 水克火**)。
- 行为7: 虎杖在多次救人中以身体接受伤害保护他者, 虎杖按接受的規則、按身体的接受、按接受的时辰的, 把身体按时辰接受 → 作用于身体的接受 → 接受按时辰被虎杖接收。
  - 归类: nz (阴土, 主位证据, 93%)。对象端点: 身体接受伤害关系停靠归宿。
- 行为8: 虎杖以爷爷遗言为身份标志在同伴间识别, 虎杖按遗言的規則、按身份的传承、按识别的时辰的, 把遗言按时辰识别 → 作用于遗言的身份 → 识别按时辰被虎杖接收。
  - 归类: x并z (阴木, 主位证据, 91%)。对象端点: 爷爷遗言的身份公共界面。
- 行为9: 虎杖在面对死亡时以冷静接受继续救人, 虎杖按冷静規則、按死亡的接受、按接受的时辰的, 把死亡按时辰接受 → 作用于死亡的接受 → 接受按时辰被虎杖接收。
  - 归类: x (阴水, 主位证据, 91%)。对象端点: 死亡接受资源归我掌握 (x 阴水, **第五个 x 元样本**)。

**统计**: zn×1 (爷爷遗言保护, **主位证据 96%, 生补关系启动者**) + n×1 (宿傩承载, **主位证据 94%, 火生土链** ) + xn×1 (救人组织, **主位证据 93%**) + zx×1 (黑闪击杀, **主位证据 95%, zx 克 n 第八样本跨咒术回战**) + z×1 (遗言単点裁定) + xz×1 (宿傩压制臨界面) + nz×1 (身体接受) + x并z×1 (遗言身份) + x×1 (死亡接受, **第五个 x 元样本**)。共 9 条候选进入基础库。本主角主十元候选 `zn 96%`, 次 `zx 95%`。

**生补关系分析**:

1. **木生火 (zx 生 zn)**: 行为5 (zx 黑闪觉醒) → 行为1 (zn 保护) 启动机制: 虎杖的 zx 黑闪觉醒是 zn 保护意识觉醒的启动机制。
2. **火生土 (zn 生 n)**: 行为1 (zn 保护) → 行为2 (n 承载) 资源补完: 虎杖的 zn 保护意识驱动 n 阳土身体承载宿傩呪力。
3. **土生金 (n 生 xn)**: 行为2 (n 承载) → 行为3 (xn 战斗组织) 资源积累: 虎杖的 n 阳土身体承载驱动 xn 阳金战斗组织。
4. **金生水 (xn 生 xz)**: 行为3 (xn 战斗) → 行为6 (xz 临界面介入) 启动机制: 虎杖的 xn 战斗组织驱动 xz 阳水临界面介入 (压制宿傩)。
5. **火补木 (zn 补 zx)**: 行为1 (zn 保护) → 行为4 (zx 黑闪) 能力补完: 虎杖的 zn 保护意识补强 zx 阳木黑闪的显权能力。
6. **水克火 (xz 克 zn)**: 行为6 (xz 临界面) → 行为1 (zn 保护) 临界面阻止: 虎杖的 xz 临界面 (压制宿傩) 部分阻止了 zn 阳火继续保护他者 (宿傩出现时无法救人)。

**生补关系链核心结论**:

虎杖的十元关系呈现典型的「木生火→火生土→土生金→金生水」循环:

> zx 黑闪觉醒 → zn 保护意识 → n 身体承载 → xn 战斗组织 → xz 临界面介入 (压制宿傩) → 触发下一轮 zx 显权

这是「木→火→土→金→水」五行的生补关系循环, 在虎杖这个具体主角身上完成闭环。
