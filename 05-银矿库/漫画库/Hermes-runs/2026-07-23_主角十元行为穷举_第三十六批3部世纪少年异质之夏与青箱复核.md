# 主角十元行为穷举 · 第三十六批3部世纪少年异质之夏与青箱复核

## 本轮边界

- 扫描结果：漫画库在上一轮后没有人工新增或修改的漫画条目；角色库新改的两张 Canvas 不属于漫画范围，本轮未触碰。
- 本轮对象：远藤贤知、辻中佳纪、“光”、猪股大喜。旧第四批的 `Jimmy Corrigan` 因公开动作证据过少暂缓，旧报告只被部分替代。
- 覆盖范围：《20世纪少年》VIZ第1、2、4、20卷；《The Summer Hikaru Died / 光逝去的夏天》Yen Press已发行第1—7卷中的明确动作；《Blue Box / 青之箱》VIZ第1—3、5—6卷。
- 本报告穷举的是上述出版社公开简介明确给出的动作，不是全作逐页穷举。疑问句、愿望、身份、被动遭遇、他人行为和群体结果不借给主角。
- 《The Summer Hikaru Died》第8卷页面标注2026-10-27发行，晚于本轮；其预告动作全部排除，不把未发行卷预告当成已读剧情。
- 一条动作只归一个十元；同一动作不重复计票。行为不足以判断时保留“暂不归类”。

### 统计后判断

- 唯一归类统计：`xn`4 / `xz`1 / `zx`1 / 暂不归类1，共7条。
- 主十元：`xn`96%候选。童年书面脚本、成人调查、同伴重组和身份追索形成跨阶段的主动组织证据。
- 次十元：未判。`xz`与`zx`各一条，只作潜伏状态和公开执行功能。
- 撤回旧结论：旧主`zn`92%撤回。原报告把“责任被唤醒”这一抽象心理当成主位；公开动作真正密集的是`xn`。旧次`xn`改为主位候选。
- 关系候选：不登记。潜伏和18年后返京虽有先后，但缺少足以排除敌方压力这一第三因素的机制证据，暂不写`xn克zx`。
- 与作品主维关系：人物`xn`直接旁证库内作品时间主维的执行层；但作品的时代循环、因果扩散和群像后果不能缩成贤知个人十元。
- 原卷复核：第1—4卷确认调查发起、召集同伴与潜伏的具体章节；第20卷确认返东京的公开行动及结果。

### 统计后判断

- 唯一归类统计：`xn`2 / `x并z`1 / `n`1 / `xz`1，共5条。
- 主十元：`xn`94%候选。现有可观察动作中，调查与任务推进比身份接口有更多独立行动证据。
- 次十元：未判。`x并z`、`n`、`xz`各一条；其中`x并z`是极强身份接口，但不能以中心设定替代行为频次。
- 撤回旧结论：旧主`x并z`93%、次`z`89%撤回为“`x并z`单点身份接口 + `xn`主位候选”。旧`z`主要来自“争取独立承认”的抽象动机，公开简介没有足够具体动作单独支持。
- 关系候选：`xn生xz`94%。来源=`xn`共同调查并接入封洞任务；目标=`xz`踏入裂隙；机制=调查与任务把未知洞口转成必须亲自进入的执行节点；改变变量=身体与返程风险；第三因素=田中求助与洞口扩大；反向不成立，因为入洞并未生成之前的调查。
- 与作品主维关系：人物`xn→xz`候选同时触及调查时间链与命运临界，但不能据此改变作品主维、别名评分或归仓。
- 原卷复核：第1卷学校日常、第4—5卷调查分工、第6卷任务承接、第7卷踏入裂隙及结果。第8卷待正式发行后另行增量复核。

- 关系候选：`nx补zx`95%。来源=`nx`按针生的高强度训练制度行动；目标=`zx`进入县预选公开对抗；机制=外部训练框架补足比赛所需的技术与配合；改变变量=全国赛竞争准备度；第三因素=针生的搭档与训练权；反向不成立，因为正式比赛不生成先前训练制度。
- 与作品主维关系：人物`nx补zx`只解释训练到比赛的行动链，`n`解释关系承接；两者不自动裁定作品时间主还是本体次，也不处理英文/中文别名合并。
- 原卷复核：第1卷鼓励语境、第2卷训练主导权、第3卷比赛结果、第5卷女孩重聚与回到雏身边、第6卷海边行动及暴风雨后续。
