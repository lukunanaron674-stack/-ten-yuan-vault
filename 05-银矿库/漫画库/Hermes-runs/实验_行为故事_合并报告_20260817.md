# 实验报告：15 条行为核心 → 行为故事生成（2026-08-17）

## 0. 实验目的

验证"十元五行行为核心"（10 条十元 + 5 条五行轴）能否从抽象定义变成**可生成的具体行为故事**。两个子代理独立生成，A 偏战斗/冒险场景，B 偏日常/社会/家庭场景，形成对照。

## 1. 结果总览

| 指标 | 子代理 A | 子代理 B |
|---|---|---|
| 故事总数 | 15/15 | 15/15 |
| 场景类型 | 战斗/冒险/生存 | 日常/社会/家庭 |
| 全量生成 | 是 | 是 |
| 口径 | L1 正确 | L1 正确 |
| 难度分布 | 易5 / 中7 / 难3 | 易6 / 中5 / 难4 |

**结论：15 条核心全部可生成具体行为故事。** 从抽象定义到可生成行为故事的转换是通的。

## 2. 双方一致结论

### 2.1 最容易具体化的核心（双方都标"易"）

- **ZX 阳木**（直接显权凌驾）：A"水井重新开锁"、B"消防通道批复"——一个动作对象即可闭环。
- **X 阴火**（资源归我掌握）：A"仓库三把钥匙"、B"琴房钥匙"——钥匙/名额/时段等实权物天然可观察。
- **N 阳土**（承载回应）：A"黑板上的名字"、B"门口的菜"——生活模板多。
- **XN 阳金**（组织成结构）：B 标易（进度表天然是动作）。
- **NX 阴木**（沿既有方向）：双方都易（A 北坡铁钉、B 面馆规矩）。

### 2.2 最难具体化的核心（双方都标"难"或分歧）

| 核心 | A | B | 难点 |
|---|---|---|---|
| ZN 阳火（并存赋义） | 中 | **难** | 极易滑成"牺牲/奉献"或被误读成 N 承载 |
| 火轴 zn↔x | 难 | 难 | 双端对比，单主角只能演一端 |
| 土轴 n↔x并z | 难 | 难 | 两端易写成同义反复的"内在 vs 外在" |
| 水轴 xz↔nz | 难 | 难 | 易滑成情绪化的"进/退" |
| 金轴 xn↔z | 难 | 中 | 需"执行 vs 拍板"双人对照 |
| 木轴 zx↔nx | 中 | 中 | 两端可串成同一件事前后两段，仍可行 |

### 2.3 轴类核心（第 11–15 条）的共同问题

五条五行轴本质是"一对矛盾端"，单主角单场景只能演一端，测不出轴本身。必须：

- 双人同场景对照（B 建议），或
- 同一件事前后两段（A 建议，如"定方向→跟方向"、"钻进去→留锚绳"）。

## 3. 对核心表述的修改建议（合并双代理）

1. **ZN 阳火**：改为锚点"他者资格与自身资格并列保存、不吞并不让渡"，并强制出现第二个被保护主体，避免与 N 承载、善良牺牲混淆。
2. **X 阴火**：强制"支配物外显"——钥匙、名额、时段、话筒、账本等可观察的实权物作为对象端点。
3. **NZ 阴水**：强制"可回返物"——钥匙、字条、空位等具体对象，否则变成情绪戏。
4. **X并Z 阴土**：核心句补半句"必须被外部接口识别"，防止"只是穿了件衣服"。
5. **五行轴（11–15）**：统一改为"同场景双人/双物动作对照"写法，例如金轴表述为"同一规则由谁执行（xn）还是由谁拍板（z）"。
