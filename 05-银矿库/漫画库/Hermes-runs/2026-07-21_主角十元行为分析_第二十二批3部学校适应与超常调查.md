## 一、君と宇宙を歩くために / 为了与你在宇宙行走 / 为了与你慢步宇宙

### 分析对象与范围

- 主角一：小林，学习和工作都不易持续、常被周围视为“不良”的高中生。
- 主角二：宇野，有许多应对生活困难的“工夫”的转学生。
- 阶段：第1—3卷及第6卷公开书目；相识、备考、天文部活动、行星馆与修学旅行。
- 来源文件：漫画库_全名单-精修版-2026-06-02.md、漫画库总索引.md、讲谈社[第1卷](https://www.kodansha.co.jp/comic/products/0000382042)、[第2卷](https://www.kodansha.co.jp/comic/products/0000388972)、[第3卷](https://www.kodansha.co.jp/comic/products/0000398866)、[第6卷书目页](https://www.kodansha.co.jp/titles/1000045255)。
- 当前状态：双主角跨卷书目轻筛完成；正式日文题名已锁。中文两译名与96/95/84.62分、命运/本体旧判断转同作评分和维度二审。

### 小林：十元判断与对象端点

- 主十元：n 94%。端点是持续不了学习和兼职的困难、可疑工作邀请、考试门槛、天文部行程失序以及宇野身体不适。问题落到小林面前后，他没有继续把自己推出学校或关系，而是留下来处理并承担下一步。
- 次十元：xn 90%。端点是备考顺序、咖啡店学习环境、从宇野处观察到的应对工夫，以及行程崩溃后由自己提出的替代方案。他开始把“我做不到”拆成可安排、可尝试的运行步骤。
- 功能位：nx 87% / nz候选84%。宇野和兼职前辈山田经常提供方向或方法，小林沿既有关系接受帮助；修学旅行中陪宇野离开刺激环境显示停靠功能，但公开简介不足以升为稳定nz。
- 关系候选：n生xn 86%。困难先落到小林身上，随后他才开始备考、换学习环境、观察方法并提出方案，改变的是“困难能否进入可继续运行的日常”。宇野、山田、学校与天文部都是强第三因素，因此只记候选。

### 小林：可观察行为证据

1. 被学业和兼职反复卡住、又受前辈邀请去可疑工作 → 宇野介入帮忙后，小林没有切断这段关系，而是继续观察宇野的生活方式并开始尝试改变 → 作用于自身生活困难与同学关系 → 两人的距离缩短，改变从一次获救转入持续日常。（第1卷；n + nx）
2. 参加天文部暑期活动需要通过考试 → 小林开始应对考试，并与宇野转到咖啡店学习 → 作用于备考任务、学习环境和注意力 → 原本无法持续的学习被放进一个可继续的地点与步骤。（第2卷；n + xn）
3. 到咖啡店后仍不知道从哪里开始 → 小林接受兼职前辈山田的接近和提示 → 作用于任务起点与既有人际通道 → 学习不再停留在“不会”，而获得可沿用的下一步。（第2卷；nx功能）
4. 行星馆行程因意外打乱、宇野开始焦躁 → 小林观察宇野让自己平静下来的工夫后主动提出建议 → 作用于崩溃的行程和宇野当前状态 → 被打断的活动得到一条替代路线。（第3卷；n生xn候选）
5. 大阪水族馆修学旅行中宇野身体状况变化 → 小林陪他前往较安静的地方，并在鲸鲨前谈起自己近期的变化 → 作用于宇野身体负荷、环境刺激和两人关系 → 行程压力被转成能够停下、交流和继续相处的空间。（第6卷；n + nz功能）

### 小林：行为模式总结

困难或关系负载落到面前时，小林先不退出；随后借同伴、环境和观察到的方法，把“无法继续”转成一个能开始、能调整、也能陪别人走下去的步骤。

### 宇野：十元判断与对象端点

- 主十元：xn 95%。端点是自己为生活困难准备的多种工夫、情绪调节方法、学习场所和活动日程。宇野不是只忍耐困难，而是反复把困难转成可管理的规则、工具与步骤。
- 次十元：n 90%。端点是转学环境、小林的接近、行程意外、同学摩擦和身体状态。外部变化落下时，他会留在关系和活动中处理，而非简单中断。
- 功能位：nz候选86% / zx反证。帮助小林、与其共同学习和接受安静陪伴形成关系停靠；但没有稳定证据显示宇野要公开扩大权能或压过同学，故不判zx。
- 关系候选：n生xn 91%。生活刺激、行程失序或身体负荷先成为承接对象，宇野再调用工夫调节，改变的是“当前状态能否恢复到可继续活动”。小林、学校和环境调整仍是第三因素，所以不升正式关系。

### 宇野：可观察行为证据

1. 小林被前辈带向可疑工作 → 宇野出手帮助小林脱离当下风险 → 作用于小林、邀请关系和两人的距离 → 小林获得退出错误路线的接口，两人由陌生同学进入持续来往。（第1卷；n/nz功能）
2. 自己在日常生活中反复遇到困难 → 宇野使用多种“工夫”应对 → 作用于注意、情绪和生活步骤 → 困难被转成可重复管理的对象，也成为小林学习的可见样本。（第1—2卷；xn）
3. 小林为天文部活动备考且在家难以集中 → 宇野与小林一起到咖啡店学习 → 作用于学习场所、共同任务和同学关系 → 两人的备考获得新的持续环境。（第2卷；xn + n）
4. 行星馆计划被意外打乱 → 宇野先出现烦躁，再调用让自己平静的工夫 → 作用于情绪负荷与活动日程 → 状态开始从失序返回可讨论、可继续的范围。（第3卷；n生xn候选）
5. 水族馆修学旅行中身体状况变化 → 宇野接受小林陪同并转到安静区域 → 作用于身体负荷、环境刺激和同伴关系 → 他没有被迫独自退出整段旅行，而是在关系支持下调整活动位置。（第6卷；n/nz功能）

### 宇野：行为模式总结

刺激、计划变化或身体负荷落下时，宇野会先确认自己当前能承受什么，再调用已经准备的工夫、场所与步骤，把失序状态调回可以继续生活和与人同行的范围。

### 反证、作品主维与复核

- 反证：小林“努力改变”不能直接判xn，必须有主动安排学习环境或提出替代路线；如果关键方案均由宇野、山田或学校制定，小林的xn应降为nx功能。宇野“有小习惯”也不自动等于xn，只有工夫稳定改变困难的运行方式才成立。
- 作品层：库内同时保留96分“为了与你在宇宙行走-CVII”、95分“为了与你慢步宇宙”和84.62分“为了与你在宇宙行走”；旧判断分属命运与本体。两位人物的n/xn靠近承接—时间组织，但人物层不能裁定作品主仓。
- 复核：第1卷可疑工作中宇野的具体介入；第2卷学习方法由谁提出；第3卷小林建议的内容和宇野调节步骤；第6卷离开水族馆刺激区的决策归属。
- 建议写入位置：人物索引、总索引84.62/95两处状态、同名冲突复审队列；96/95/84.62和正式主维保持原状。

## 二、タコピーの原罪 / 章鱼嗶的原罪

### 分析对象与范围

- 主角：タコピー（Takopi），为传播快乐来到地球的Happy星人。
- 阶段：上、下两卷出版社简介；来到地球、围绕静香行动、与静香前往东京。
- 来源文件：漫画库_全名单-精修版-2026-06-02.md、漫画库总索引.md、集英社[上卷](https://www.shueisha.co.jp/books/items/contents.html?isbn=978-4-08-883049-0)、[下卷](https://www.shueisha.co.jp/books/items/contents.html?isbn=978-4-08-883104-6)。
- 当前状态：两卷官方书目预筛完成；正式日文题名已锁。公开简介只够3条粗粒度动作，时间回退、道具使用和罪行细节全部待原卷，不以常识补写。

### 十元判断与对象端点

- 主十元：nx 92%。端点是Happy星“传播快乐”的既定使命、静香是否微笑的外部反馈，以及静香去东京的既有路线。Takopi持续行动，但方向主要由外部任务和静香当前状态给出。
- 次十元：zn候选88%。端点是“只想让静香笑”的内部意义。官方上卷确实写到这一愿望，但未展示在奖励、惩罚、误解和失败下是否仍以同一内部原则自我校正，因此暂不锁稳定zn。
- 功能位：n候选84%。静香周围的残酷环境超出Takopi理解范围，他仍留在关系中行动；但“承接后怎样消化处理”缺细节，不能把受冲击直接判成n主。
- 生补克：nx与zn候选共现，但现行表没有足够机制说明任务通道生成内部意义，或内部意义补足外部路线。本轮不登记关系。

### 可观察行为证据

1. 接受“把快乐传播到地球”的既定方向 → Takopi降落地球 → 作用于地球与Happy星使命 → 他进入一个自己不了解、但任务方向已经给定的环境。（上卷；nx）
2. 静香曾帮助他、却失去笑容 → Takopi围绕“让静香重新笑”持续奔走 → 作用于静香的外部反馈与两人关系 → 宇宙使命收缩成一个具体人物的笑容，但残酷环境远超他的理解。（上卷；nx + zn候选）
3. 玛丽娜遗体被发现、暑假阶段启动且静香仍推进计划 → Takopi与静香两人前往东京 → 作用于静香的既有计划、地点路线和两人关系 → 行动由本地关系冲突进入东京阶段，后果继续扩大。（下卷；nx）

### 行为模式总结

外部使命或静香的状态给出方向后，Takopi会沿着“让她快乐”继续行动；但他缺少理解人类环境的内部校正，越是执着沿既定方向推进，越可能让善意与实际后果分离。

### 反证、作品主维与复核

- 反证：善良、天真、来自外星或“犯下原罪”都不是十元。若原卷显示Takopi主动重排时间、记录失败并改变方法，才检查xn；若他在外部方向失效后仍以独立原则行动，zn才可升主位。
- 作品层：库内92分且推定因果主。Takopi的nx只支持“沿外部方向办事”这一端；意图与后果严重错位可为作品因果主题提供高层线索，但不能由此倒推出人物稳定zx或完整zx+nx。
- 复核：上卷让静香微笑的每次具体动作、工具权限和失败后是否改变方法；下卷赴东京由谁制定计划、Takopi是否主动改写路线；终局能否通过拿掉测试确认zn。
- 建议写入位置：人物索引、总索引章鱼嗶条目状态；92分、因果推定和正式归仓不动。

## 三、ダンダダン / 胆大党 / Dandadan

### 分析对象与范围

- 主角一：綾瀬桃（Momo / 桃），相信幽灵而否定外星人的高中生。
- 主角二：高倉健（オカルン / Okarun / 厄卡伦），相信外星人而否定幽灵的怪奇爱好者。

### 桃：十元判断与对象端点

- 主十元：xn 94%。端点是验证超常现象的地点选择、解咒挑战、丢失物搜寻、团队联动训练、外星门阻断、金球去向调查和妖精资料。桃反复把超常事故转成可以调查、训练、重试或查资料的任务。
- 次十元：n 90%。端点是外星袭击、诅咒、伙伴受伤、身体缩小和团队负载。事件落到她所在关系圈时，她继续留在现场承接结果，而不是只保全自己。
- 功能位：zx 88% / nx 87%。战斗和冲向外星门属于直接执行，但不足以证明稳定公开凌驾；请Serpo、Turbo Granny等既有角色提供权限或帮助，是明确nx关系功能。

### 桃：可观察行为证据

1. 与厄卡伦争论幽灵和外星人谁存在 → 桃前往UFO目击地的废弃医院验证 → 作用于自己的否定判断、地点和可观察事实 → 争论被转换成一次现实测试。（第1卷；xn行为）
2. 厄卡伦被Turbo Granny诅咒 → 桃与厄卡伦共同向Turbo Granny发起鬼抓人挑战以解除诅咒 → 作用于诅咒、胜负规则和两人协作 → 超常伤害被转成有条件、有目标的解咒行动。（第2卷；xn + zx功能）
3. 与Turbo Granny战后遗失重要物件、Aira又因捡到物件卷入怪异 → 桃继续搜寻，并在Aira被怪异袭击时进入应战 → 作用于丢失物、Aira与怪异 → 寻物路线和救援路线合流。（第3—4卷；n + xn/zx功能）
4. 外星人再袭日期可预测 → 桃与同伴反复进行联动训练；敌人到来后与Serpo前往门的位置阻止本体进入 → 作用于团队配合、预测节点和入侵通道 → 事前训练被投入明确的阻断任务。（第12卷；xn + nx/zx功能）
5. 需要确认在派出所取得金球的人 → 桃与厄卡伦请求Turbo Granny调查；电脑操作失败后又准备重试 → 作用于警察系统、人物身份和调查通道 → 一次权限失败没有终止调查，而被转成下一次尝试。（第16卷；nx + xn）
6. 受诅咒影响缩小，并在课堂上意识到自身状态类似妖精传说 → 桃与厄卡伦等人在图书馆查阅妖精资料，随后目击小人 → 作用于自身身体、传说资料和新线索 → 身体异常被转成可检索、可验证的调查对象。（第20卷；n + xn）

### 桃：行为模式总结

怪异、诅咒或伙伴问题落到关系圈后，桃会把它从惊吓和战斗现场搬进可验证的地点、训练、调查与重试步骤；直接力量不足时，她也会借已有角色和权限通道继续推进。

### 厄卡伦：十元判断与对象端点

- 主十元：xn 95%。端点是怪异验证、解咒规则、丢失金球、变强训练、音乐室提示、外星侵略情报和研究社资料渠道。他会把失败和异常转成训练、搜寻、组织或情报节点。
