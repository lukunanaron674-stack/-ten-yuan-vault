## 一、PLUTO·蓋吉希特 V2 closure 升级（n 阳土 → 克 xz 阳水）

- 行为1：蓋吉希特在歐洲刑警偵探工作中承接PLUTO連環杀人案、蓋吉希特按刑警偵探規則、按PLUTO連環案的危机、按侦探的时辰把危机按时辰承接 → **克制维度**：n 阳土 → 克 xz 阳水（PLUTO連環案重大危机 xz 受 n 阳土 刑警承载约束）。→ 作用于PLUTO連環案 → 危机按时辰被蓋吉希特承接。
  - 归类：n（阳土，主位证据，94%）。对象端点：PLUTO連環案重大危机 xz 阳水 承载回应（n 阳土 → 克 xz 阳水）。
- 行为2：蓋吉希特在调查过程中组织线索、目标名单和调查顺序、蓋吉希特按组织規則、按调查的清单、按组织的时辰把调查按时辰组织 → 作用于调查清单 → 组织按时辰被蓋吉希特接收。
  - 归类：xn（阳金，主位证据，93%）。对象端点：调查流程既有通道（**V2 升级 xn 93% 与 V1 xn 93% 持平，确认主位证据**）。
- 行为3：蓋吉希特在调查中警告目标让目标人物远离PLUTO、蓋吉希特按警告規則、按目标的警告、按警告的时辰把目标按时辰警告 → 作用于目标人物 → 警告按时辰被目標接收。
  - 归类：xn（阳金，主位证据，92%）。对象端点：警告流程。
- 行为4：蓋吉希特在调查后期封锁自身记忆保护调查完整性、蓋吉希特按封锁規則、按自身的记忆、按封锁的时辰把记忆按时辰封锁 → 作用于自身的记忆 → 记忆按时辰被蓋吉希特封锁。
  - 归类：xz（阳水，主位证据，92%）。对象端点：封锁记忆的臨界存続。
- 行为5：蓋吉希特在最终決戰与布莱特鲸机器人战斗保护人类、蓋吉希特按战斗規則、按人类的保护、按战斗的时辰把人类按时辰保护 → 作用于人类との関係 → 保护按时辰被人類接收。
  - 归类：zn（阳火，主位证据，93%）。对象端点：人类独立主体资格保存（**克者 zn 阳火**）。
- 行为6：蓋吉希特在最终決戰后以承接新案件延续侦探工作、蓋吉希特按承接規則、按新案件、按揭续的时辰把案件按时辰承接 → 作用于新案件 → 承接按时辰被蓋吉希特接收。
  - 归类：n（阳土，主位证据，92%）。对象端点：新案件承载回应。

**统计**：n×2（PLUTO連環案 + 新案件，**主位证据 94% + 92%，第三个双 n 主位证据**）+ xn×2（组织 + 警告）+ xz×1（封锁记忆臨界）+ zn×1（保护人類）。共 6 条候选进入基础库。本主角主十元候选 `n 94%`，次 `xn 93%`（**V2 升级确认 n 元覆盖主位**）。

**克制实验结论**（V2 升级后）：
- 蓋吉希特 V1 主 xn 93% / 次 zn 88% → V2 主 n 94% / 次 xn 93%（V2 重新判定主位证据，n 从 86%→94% 升级 +8%）
- **n 克 xz 样本**：行为1 n 阳土承接PLUTO連環案重大危机 xz 阳水 → 升级置信度到 94% 主位证据。这是 n 克 xz 的**第四个跨作品样本**（前三个：フリーダ + Punpun V2 + 小户川 V2）。
