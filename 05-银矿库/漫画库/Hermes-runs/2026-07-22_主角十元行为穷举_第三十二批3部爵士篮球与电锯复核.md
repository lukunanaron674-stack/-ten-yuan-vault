# 主角十元行为穷举 · 第三十二批3部爵士篮球与电锯复核

## 本轮边界

- 分析对象：宫本大、樱木花道、电次；人物彼此分开，不把作品主题、世界观、敌人行动或其他角色心理借给主角。
- 固定顺序：先读取公开剧情事实并列行为，再在下一行给出唯一十元归类；不先定十元，也不把多条动作压缩成概括句。
- 覆盖范围：小学馆《BLUE GIANT》第1—6、9卷书目与官方专题；集英社《SLAM DUNK》第1、7、10、18、22、29、31卷书目；集英社《链锯人》公安篇第1—5、10—11卷书目。
- 本报告是“出版社公开范围穷举”，不是全作逐页穷举；简介没有公开行动、作用对象或结果的事项不补写。
- 统计只说明本批行为证据的分布。行为功能不能自动升级成人物稳定本体；主次候选还要检查跨阶段、跨情境和来源簇独立性。

## 一、《BLUE GIANT》｜宫本大

- 身份与阶段：仙台高中后期至东京三重奏时期的萨克斯手。
- 来源范围：小学馆第1—6、9卷书目与小学馆官方专题；非全卷原页。
- 当前状态：公开范围10条行为穷举完成，待日文原卷补页码与演出结果。

- 行为1：没有教师、乐队或正式舞台时 → 数年间持续独自在广濑川河边吹奏萨克斯 → 自己选择的爵士实践 → 练习在无人监督和无即时回报的条件下仍持续。【BG-1】
  - 归类：`zn`（主位证据，95%）。意义端点：爵士演奏本身；外部认可与奖励不是该行动的启动条件。

- 行为2：第一次在爵士酒吧演奏被观众误解并喝止 → 离场后没有退出爵士道路，继续进入后续练习与学习 → 外部否定与自己的演奏方向 → 否定没有中断行动路线。【BG-专题、BG-2】
  - 归类：`zn`（主位证据，92%）。意义端点：即使观众否定，仍继续作为爵士手行动。

- 行为3：一名成年乐手提出指导 → 接受其教学并迅速吸收乐理 → 教师提供的既有教学路线 → 从独练进入外部专业训练。【BG-2】
  - 归类：`nx`（功能位，91%）。方向端点：教师的知识、教学权限与训练通道；不是宫本大自行设计课程。

- 行为4：街区正举行爵士节 → 带着乐器走进街头并突然开始演奏 → 现场行人与节庆听众 → 把自己的演奏主动送入公众听觉范围。【BG-2】
  - 归类：`z`（次位证据，89%）。认可端点：街头听众；被呈现内容是他的萨克斯演奏。

- 行为5：想在学校文化祭演出 → 独自带次中音萨克斯站上舞台 → 同校观众 → 个人演奏被明确置于集体观看和评价的位置。【BG-3】
  - 归类：`z`（次位证据，93%）。认可端点：文化祭观众；被确认内容是独奏能力。

- 行为6：第一次与其他乐手进行合奏 → 在会话式演奏中全力吹奏 → 同场乐手与合奏结构 → 完成首次多人session。【BG-4】
  - 归类：暂不归类（证据不足）。公开简介未说明谁决定方向、他是否组织流程、是否获得认可或压过对象；“全力”不能单独判`zx/z/zn`。

- 行为7：决定离开故乡继续爵士道路 → 分别向朋友、老师和家人告别 → 既有生活关系与下一阶段路径 → 实际切断仙台日常并进入东京阶段。【BG-4】
  - 归类：`zn`（主位证据，91%）。意义端点：以爵士手身份继续生活；告别是内部方向落实为现实行动的结果。

- 行为8：到东京后尚无稳定乐队和舞台 → 继续独自练习萨克斯 → 新城市中的个人演奏 → 地点、关系和资源改变后，爵士实践仍没有停止。【BG-5】
  - 归类：`zn`（主位证据，94%）。意义端点：跨城市持续的爵士实践；与行为1构成跨阶段而非同场重复。

- 行为9：三人组合完成组建并迎来第一次现场演出 → 宫本大与两名队友共同上台演奏 → 首场现场观众 → 个人演奏进入乐队名义下的公开评价位置。【BG-6】
  - 归类：`z`（次位证据，90%）。认可端点：三重奏首演观众；只证明公开呈现功能，不把队友行为并入宫本大。

- 行为10：三重奏作为暖场面对规模更大且持怀疑态度的观众 → 宫本大与队友把演奏力量全部投向现场 → 大型音乐节观众 → 在不利认可环境中仍完成公开演奏。【BG-9】
  - 归类：`z`（次位证据，94%）。认可端点：对三人尚不信任的大型现场观众；该行动的直接功能是让演奏接受确认。

### 归类统计与主次

- 10条：`zn`4、`z`4、`nx`1、暂不归类1。
- 主十元候选：`zn`94%。理由不是“世界第一”这句目标，而是无观众独练、受否定后继续、离乡和异地续练四个不同条件下都由爵士意义启动行动。
- 次十元候选：`z`92%。四次公开演奏分别面向街头、学校、首演和大型音乐节观众；它们是不同阶段的认可行为，但同属“演奏给人听”这一职业行为族，数量不反压`zn`。
- 功能位：`nx`91%，只限接受教师既有训练路线；不升级为人物本体。

### 关系、反证与作品主维

- 生补克：不登记。`zn/z/nx`在不同动作中共现，但公开简介没有写出一个端点怎样改变另一个端点的能力、路径或持续条件。
- 反证：他主动进入街头和舞台，说明不是只在内部自完备；他接受教师路线，说明行动并非始终由自己建立结构。两点降低“纯`zn`”说法，但不足以推翻跨阶段`zn`主候选。
- 与作品主维：总索引当前登记作品主维为“时间”、次维为“空间”；人物的`zn+z`不构成时间公式`xn+z`，也不自动证明作品本体型。`01-本体型 zn+x.md`仍保留本作S级条目，这一作品维度口径冲突本轮不裁决。
- 原卷复核：第1卷河边练习/酒吧后续、第2卷街头演奏、第3卷文化祭、第4卷告别、第5卷东京练习、第6卷首演、第9卷暖场结果。

## 二、《灌篮高手》｜樱木花道

- 身份与阶段：湘北高中篮球队球员；入队前后至山王战。
- 来源范围：集英社第1、7、10、18、22、29、31卷书目；非全31卷逐页穷举。
- 当前状态：公开范围7条行为穷举完成；旧“前期`z`→后期`zn`”迁移降为待原卷假设。

- 行为1：喜欢上赤木晴子并被她问“喜欢篮球吗” → 进入篮球部相关行动，卷内目录明确出现“花道入部” → 晴子的认可位置与篮球部入口 → 原本与篮球无关的生活方向发生改变。【SD-1】
  - 归类：`z`（功能位，92%）。认可端点：晴子；被确认内容是“自己成为篮球人”的身份。目录级证据仍待原页核入部过程。

- 行为2：与宫城良田发生冲突 → 冲突后因共同处境而互相理解 → 宫城与二人关系 → 对立关系暂时转为同队理解。【SD-7】
  - 归类：暂不归类（证据不足）。简介没有公开樱木停止冲突、道歉、协商或接住关系的具体动作，不能只凭结果硬判`n/nz/nx`。

- 行为3：此前连续五场比赛犯满离场 → 在对翔阳比赛中把“阻止连续退场纪录”设为自己的课题 → 自己的犯规行为与上场持续时间 → 用明确规则约束当场行动。【SD-10】
  - 归类：`xn`（功能位，93%）。结构端点：犯规次数、留场时间和自我设定的行为规则；只证明这一场的组织功能。

- 行为4：替补席把反击希望交给樱木，安西教练给出指示 → 按指示拼抢进攻篮板 → 篮板、教练战术与湘北进攻 → 球队进攻节奏发生变化。【SD-18】
  - 归类：`nx`（功能位，95%）。方向端点：安西教练已有的指令和球队战术通道；结果再强也不改变“方向由教练给出”。

- 行为5：把流川枫视为需要直接比较的对手 → 主动向流川提出一对一决胜 → 流川与双方篮球能力 → 把关系推入公开的高下检验。【SD-22】
  - 归类：`zx`（主位证据，92%）。权能端点：樱木自己的身体与篮球能力；目标是直接与对手比较并压过其位置。

- 行为6：山王战巨大分差压住湘北节奏 → 以篮板表现连续改变攻防 → 山王篮下、湘北进攻与比分差 → 湘北恢复节奏，二十余分差被压缩到八分。【SD-29】
  - 归类：`zx`（主位证据，96%）。权能端点：已经公开显现的篮板能力；该能力直接改变比赛环境和双方位置。

- 行为7：背部受伤并面临继续上场可能断送选手生涯的风险 → 仍返回山王战赛场 → 自己的身体、比赛窗口与球队现场 → 在退路明显变窄的临界条件下继续比赛。【SD-31】
  - 归类：`xz`（高强度功能位，96%）。风险端点：职业生涯级伤势、当场比赛窗口和不可逆身体代价；不把“受伤”背景本身计为行动。

### 归类统计与主次

- 7条：`zx`2、`z`1、`xn`1、`nx`1、`xz`1、暂不归类1。
- 主十元候选：`zx`94%。一对一挑战和山王战篮板分别在对手关系与比赛环境中公开显权，且不是同一来源簇。
- 次十元：暂不锁定。`z/xn/nx/xz`各只有一个独立动作，不能为了Top-2格式强配第二标签。
- 旧结论处理：公开书目能够支持早期`z`行为，却没有提供足够独立动作证明后期稳定`zn`；“后期`zn`上升”改为原卷待验假设，不再作为当前人物摘要。

### 关系、反证与作品主维

- 关系候选：`zx ↔ nx`只保留候选。安西指令为樱木提供了外部方向，他随后以篮板能力改变比赛；但本轮书目没有完整公开“借入指令→权能扩大”的连续细节，不登记正式补位。
- 反证：他能按教练指令行动并自设犯规课题，不是只凭身体直接压过去的纯`zx`；早期围绕晴子认可行动，也不支持从开篇就判稳定`zn`。
- 与作品主维：总索引登记作品主维“时间”、次维“空间”。人物有一条`xn`行为，但没有稳定`z`+`xn`动态链，不能以人物行为反证作品时间主；`01-本体型 zn+x.md`仍收录本作，本轮不更改维度或评分。
- 原卷复核：第1卷入部动机、第7卷宫城冲突的具体收束、第10卷犯规控制、第18卷安西指令、第22卷一对一、第29卷篮板结果、第31卷伤后返场。

## 三、《链锯人》｜电次

- 身份与阶段：与波奇塔共生、后进入公安的恶魔猎人；本轮只覆盖公安篇第1—11卷公开简介。
- 来源范围：集英社第1—5、10—11卷书目；第二部第12—24卷不在本次对象阶段内。
- 当前状态：公安篇公开范围7条行为穷举完成；旧`nz`辅助无行为证据，降级待原卷。

- 行为1：背负父债且没有独立生活资源 → 与波奇塔一起替讨债人猎杀恶魔 → 债务人规定的工作与偿债路线 → 以外部债务方向换取生存。【CM-1】
  - 归类：`nx`（主位证据，96%）。方向端点：讨债人、债务与既有恶魔猎人工作通道；不是电次自行建立人生方向。

- 行为2：帕瓦把身体接触许诺为交换条件 → 为兑现该条件与蝙蝠恶魔激战 → 帕瓦设定的交换路线和指定敌人 → 通过外部奖赏框架进入战斗。【CM-2】
  - 归类：`nx`（主位证据，93%）。方向端点：帕瓦提出的条件与救猫路线；“欲望强”本身不自动等于`x`，战斗本身也不自动等于`zx`。

- 行为3：神秘恶魔封锁空间并要求众人杀死电次 → 在小队分裂的极限状态下想出一个“地狱般的作战” → 封闭空间、敌人和小队生存路线 → 主动提出应对方案。【CM-3】
  - 归类：`xn`（功能位，87%）。结构端点：临时作战方案；简介没有公开步骤、资源安排和结果，因此只判一次计划功能，不升级为稳定`xn`。

- 行为4：公安特异课遭袭后需要提高战力 → 与帕瓦一起在最强恶魔猎人手下开始“死亡训练” → 教官与既有训练制度 → 按他人建立的训练通道行动。【CM-4】
  - 归类：`nx`（主位证据，93%）。方向端点：教官的训练权限、训练方法和公安反击路线；不是电次主动搭建训练系统。

- 行为5：武士刀再次出现并与其正面相遇 → 再次与武士刀交锋 → 指向自己心脏的敌人 → 进入直接战斗。【CM-5】
  - 归类：暂不归类（证据不足）。简介只确认“激突”，没有公开电次是否显权扩大、压过对手或改变环境；普通战斗不能自动判`zx`。

- 行为6：与秋相关的事件令自己陷入无法处理的绝望 → 主动向真纪真求救 → 掌握公安位置与关系权力的真纪真 → 把解决方向交给外部权威，获得短暂安息。【CM-10】
  - 归类：`nx`（主位证据，96%）。方向端点：真纪真的关系位置、权威和救助通道；这是主动求人，但最终方向和权限不在电次手里。

- 行为7：真纪真的支配夺走其重要事物并把他逼入绝境 → 电次与真纪真在荒野直接厮杀 → 控制自己的上位权力与自己的电锯身体 → 以本人能力重新进入正面对抗。【CM-11】
  - 归类：`zx`（功能位，92%）。权能端点：电次/电锯身体直接对抗真纪真的支配位置；只判该场战斗功能，不由结局倒推稳定人物本体。

### 归类统计与主次

- 7条：`nx`4、`xn`1、`zx`1、暂不归类1。
- 主十元候选：`nx`95%。债务工作、帕瓦交换、教官训练和向真纪真求救跨越不同阶段与关系对象，均表现为进入别人拥有的方向、权限或解决通道。
- 次十元：暂不锁定。`xn/zx`各只有一个行为功能；战斗次数不能代替“公开显权并扩大”的独立结果证据。
- 旧结论处理：本轮没有一条公开简介动作能独立证明`nz`的“保持关系余温、不想结束”；旧`nz`辅助降为待公安篇原卷验证。

### 关系、反证与作品主维

- 关系候选：`zx ↔ nx`只作候选。多次`nx`为电次提供任务、训练或权威通道，最终有一次`zx`正面对抗；但各事件之间没有形成同一条已公开的“借力后显权”机制，不能登记正式补位。
- `nx 生 x`不登记：现行关系表明确该语义待验收，本批也没有足够行为证明电次把具体资源、地盘、权限或关系纳入“归我掌握”的边界。
- 反证：卷3主动想作战、卷11直接与真纪真厮杀，说明`nx`不是“无行动力”或永久服从；这些单点使纯被动解释失效，但尚不足以覆盖四条跨关系`nx`证据。
- 与作品主维：总索引登记作品主维“命运”、次维“因果”。电次的`nx`高频行为能旁证“沿外部通道办事”的因果功能，但单点`zx`不足以自动组成作品公式，也不证明命运主维；作品中的控制/归属`x`不能借给电次人物本体。
- 原卷复核：第1卷偿债/契约后的自主性、第2卷交换条件、第3卷作战步骤、第4卷训练中的选择、第5卷武士刀战结果、第10卷求救、第11卷最终对抗的主体与策略。
