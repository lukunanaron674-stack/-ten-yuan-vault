# 主角十元行为穷举 · 第三十三批3部剑路迷宫与黑医复核

## 本轮边界

- 扫描对象：宫本武藏、莱欧斯、间黑男；人物彼此分开，不把作品主题、世界观、配角行为或团队总结果直接借给主角。
- 固定顺序：先列公开剧情中可以观察的动作，再在下一行给出唯一十元归类；不先定十元，不把多条行为压成“行为模式”。
- 覆盖范围：VIZ《Vagabond》公开书目第1—4、8、10、12册；Yen Press《Delicious in Dungeon》第1、5、10—14卷书目；手塚治虫官网《Black Jack》作品页与6个分话简介。
- 本报告是“官方公开资料范围穷举”，不是全作逐页穷举。简介只写团队结果、心理状态或问题而没有写主角动作时，保留为暂不归类或排除，不补写场景。
- 一条行为只归一个十元；同一动作不重复证明其他十元。统计先于主次判断。

## 一、《Vagabond / 浪客行》｜宫本武藏

- 身份与阶段：由新免武藏改名宫本武藏的剑士；关原战后至吉冈一门战后。
- 来源范围：VIZ公开书目第1—4、8、10、12册；非全卷原页。
- 当前状态：公开范围6条具体行为完成；旧“前中期zx、后期zn上升”阶段迁移撤回，待原卷重建。

- 行为1：十七岁离开关原战后的原生活 → 踏上自己选择的剑道 → 自己的生活方向与“天下无双”路径 → 实际进入以剑为中心的长期行动路线。【VG-1】
  - 归类：zn（主位证据，92%）。意义端点：把剑道规定为自己接下来如何生活的内部标准；不是以一次胜负或外部承认启动。

- 行为2：把宝藏院僧兵视为下一站对手 → 前往奈良挑战宝藏院 → 宝藏院与自己的剑术位置 → 进入挑战场域，但书目没有公开该次行动的具体结果。【VG-2】
  - 归类：暂不归类（证据不足）。主动挑战不自动等于zx；未公开是否压过对手、改变权力位置，也未交代不可逆风险。

- 行为3：此前曾从胤舜面前退却 → 为再战做准备并决定即使有生命危险也不再逃跑 → 自己的退路、生命与胤舜一战 → 把可撤退选择压缩为必须正面承受的高风险节点。【VG-3】
  - 归类：xz（功能位证据，96%）。风险端点：生命危险、撤退路径和再战窗口；只判该节点，不把所有战斗都归xz。

- 行为4：把柳生石舟斋视为下一位必须面对的剑豪 → 设法向他发起挑战 → 熟睡的石舟斋与自己的剑道判断 → 抵达“是否杀死熟睡老人也算前进”的行动门槛，但书目没有确认最后动作与结果。【VG-4】
  - 归类：暂不归类（证据不足）。简介提出的是行动难题；不能把未公开的选择结果预填为zn、zx或xz。

- 行为5：第一次挑战吉冈一门一年后 → 返回京都准备完成再战 → 自己持续选择的剑道与吉冈一门 → 跨过一年时间重新进入原先未完成的路线。【VG-8】
  - 归类：zn（主位证据，90%）。意义端点：跨期持续的剑道路线；返回本身不是被外部规则或他人指令推动。

- 行为6：吉冈一门以人数围住他 → 单人迎战并击倒七十名门人 → 自己的剑术权能与吉冈一门的集体战力 → 直接改变双方力量关系，随后身体付出可能无法再行走的代价。【VG-10】
  - 归类：zx（功能位证据，98%）。权能端点：武藏公开落实的个人剑术；此处有明确压过集体战力的可观察结果，才成立zx。

### 归类统计与主次

- 6条：zn 2、xz 1、zx 1、暂不归类2。
- 主十元候选：zn 91%。早期开路与一年后返回是跨阶段、不同事件的同向行动；它们比单场战斗更能说明稳定启动端。
- 次十元：暂不锁定。zx与xz各只有一个高强度节点，不能用强度代替跨情境重复。
- 旧结论处理：撤回“前中期主zx、次xz、后段zn上升”。现有公开动作只支持zn主候选、zx/xz单点功能；卷12的“质疑无敌与存在”是心理问题，不是行为，未计数。

### 关系、反证与作品主维

- 关系候选：xz生zx只保留待验。行为3的冒险承受与行为6的显权发生在不同对手、不同事件；公开简介没有证明前者怎样生成后者的能力，因此不登记已启动关系。
- 反证：武藏两次主动找强敌，说明zn不是脱离现实的纯内省；行为6直接显权，说明zx是重要执行能力。两点限制“纯zn”，但还不足以把zx升为稳定主位。
- 与作品主维：总索引当前登记作品为命运主、因果次。人物zn主候选不等于作品主维；一次xz仅支持命运压力节点，一次zx仅支持直接权能节点，不能自动组成作品公式。
- 原卷复核：第1册出走语境、第2册挑战宝藏院结果、第3册胤舜再战、第4册柳生选择、第8册返京动机、第10册七十人战与伤势、第12册行为化转折。

## 二、《迷宫饭》｜莱欧斯

- 身份与阶段：冒险队队长；红龙团灭后重返迷宫至终局方案执行。
- 来源范围：Yen Press第1、5、10—14卷公开书目；不是14卷逐页穷举。
- 当前状态：公开范围7条具体行为完成；团队行动与莱欧斯个人贡献分开处理。

- 行为1：队伍失去金钱、补给和法琳，若立刻返回会在路上挨饿 → 提出食用迷宫怪物补充食物并继续下潜 → 可食怪物、补给缺口与救援路线 → 在没有钱粮的条件下建立可继续行动的替代方案。【DM-1】
  - 归类：xn（主位证据，97%）。结构端点：食物来源、行程持续条件与救援目标；这里是主动组织资源和路线，不是把怪物“归我所有”的x。

- 行为2：队伍追到红龙 → 莱欧斯参与队伍击败红龙并救出法琳 → 红龙、法琳与队伍 → 官方简介只确认团队结果，没有拆出莱欧斯的个人动作和独立结果。【DM-5】
  - 归类：暂不归类（证据不足）。不能把“队伍完成”自动改写成莱欧斯个人的n、zx或xn。

- 行为3：西斯尔住处的杂物妨碍寻找翼狮和备餐 → 莱欧斯与同伴一起清理杂物 → 住处杂物、搜索通道与备餐空间 → 障碍被团队处理，但个人承担比例未公开。【DM-10】
  - 归类：暂不归类（证据不足）。动作主体是团队，简介没有给出莱欧斯的独立决策或结果。

- 行为4：队伍吃饱后仍需继续救回法琳 → 莱欧斯参与队伍仓促制定营救计划 → 法琳与下一阶段行动 → 团队形成计划，但简介没有说明哪一步由莱欧斯组织。【DM-10】
  - 归类：暂不归类（证据不足）。存在计划不等于主角个人xn；需原卷定位其提案、分工与资源安排。

- 行为5：与狂乱魔术师交战、同伴倒下，自己独自面对多条致命龙 → 运用长期积累的怪物知识应战 → 龙群、自己的知识与生存窗口 → 在近乎必死的局面中扭转当下存活概率。【DM-11】
  - 归类：zx（功能位证据，96%）。权能端点：莱欧斯实际掌握并外化为战斗结果的怪物知识；只有该次明确“以自己的能力逆转”才计zx。

- 行为6：需要同时满足巨兽并救回妹妹 → 制定一个孤注一掷的进食方案 → 巨兽、法琳与可执行步骤 → 把两个目标组织成一条终局行动路线。【DM-13】
  - 归类：xn（主位证据，95%）。结构端点：巨兽的饱足条件、妹妹救援目标与执行顺序；“孤注一掷”是风险描述，计划行为本身仍归xn。

- 行为7：终局方案已经进入执行 → 以怪物化身体继续对抗恶魔并承担巨大身体代价 → 恶魔、自己的怪物形态与方案结果 → 方案一度奏效，但身体受损、迷宫崩塌且法琳仍未完全恢复。【DM-14】
  - 归类：xz（高强度功能位，98%）。风险端点：怪物形态的身体代价、迷宫崩塌和失败余地；这是执行动作，不重复归入行为6的xn。

### 归类统计与主次

- 7条：xn 2、zx 1、xz 1、暂不归类3。
- 主十元候选：xn 94%。开篇的补给替代方案与终局的双目标方案跨越作品两端，均以组织条件使行动继续。
- 次十元：暂不锁定。zx、xz各一条；三条团队行为因个人贡献不明不参与主次统计。
- 旧结论处理：保留xn主候选但由90%校正为94%；撤回次x与nz辅助。官方简介没有证明怪物、迷宫资源或关系被划入莱欧斯的稳定掌握边界，也没有独立nz动作。

### 关系、反证与作品主维

- 关系启动候选：xn生xz 93%。行为6先把终局条件排成可执行方案，行为7再沿该方案进入高代价、退路收窄的执行；前后是同一终局链中的不同动作。仍需第13—14卷原页确认具体执行主体和因果桥。
- 反证：三条团队结果不能证明他始终掌控全队；行为5显示关键时刻也会由个人知识直接做成，而非每次都靠预先组织。
- 与作品主维：总索引当前登记空间主、因果次。人物xn主要说明运行方式，不等于空间公式；单点zx也不能独立组成因果公式。旧人物x撤回后，不能再用人物层“怪物资源掌握”支撑作品空间主位。
- 原卷复核：第1卷食怪提案及分工、第5卷红龙战个人动作、第10卷清理与计划主体、第11卷龙群战、第13卷方案步骤、第14卷执行代价与最终结果。

## 三、《怪医黑杰克》｜间黑男

- 身份与阶段：无执照外科医生；单元剧全期抽取6个官方分话。
- 来源范围：手塚治虫官网作品页与第2、12、30、38、40、56话简介；不是全篇逐话穷举。
- 当前状态：官方分话范围6条具体行为完成；收费、无证身份和“天才”评价均未冒充动作。

- 行为1：被强盗绑到渔船、强盗本人受重伤 → 在受限环境中为其实施手术 → 受伤强盗与船上临时医疗条件 → 手术成功，病例得到阶段结果。【BJ-2】
  - 归类：n（主位证据，96%）。承接端点：突然落到他面前的伤者与临时手术条件；成功不自动等于zx。

- 行为2：检查一名女性并发现其体内存在完整身体部件 → 把这些部件缝合成皮诺可 → 体内部件与可存活身体 → 分散部件被处理成独立生命个体。【BJ-12】
  - 归类：n（主位证据，95%）。承接端点：检查中出现的异常病例与身体部件；官网没有公开“向谁显权或压过谁”，故不判zx。

- 行为3：发现皮诺可患白血病 → 到处寻找她的姐姐 → 皮诺可、潜在亲属与治疗入口 → 把病情转成现实搜索行动，但简介未公开是否找到或完成治疗。【BJ-30】
  - 归类：n（主位证据，91%）。承接端点：皮诺可的病情与寻找治疗相关对象的任务；结果未闭合，置信度低于手术案例。

- 行为4：皮诺可离开后失踪 → 在城里寻找她并因此错过医疗执照会议 → 皮诺可这段近亲关系与执照机会 → 把找回关系对象置于制度认可窗口之前。【BJ-38】
  - 归类：nz（功能位证据，97%）。关系端点：皮诺可本人及共同生活关系；这里有为关系停靠让渡制度机会的可观察代价。

- 行为5：医院医生因害怕报复而不愿为烧伤患者移植 → 接手移植手术 → 被其他医生搁置的患者与手术任务 → 病例从无人愿接转为由他实际处理。【BJ-40】
  - 归类：n（主位证据，96%）。承接端点：被制度性畏惧搁置的患者与移植任务；“接手”是承接，不自动等于控制权x或显权zx。

- 行为6：奇利柯准备以安乐死处理一名患者 → 从奇利柯手中接走患者并实施手术 → 患者生命、两种医疗路线与自己的医生原则 → 手术成功；其后家属事故不属于黑杰克的行为结果。【BJ-56】
  - 归类：zn（功能位证据，98%）。意义端点：以“救治而非结束生命”规定自己的医生行动；这里只归zn，不重复计为n。

### 归类统计与主次

- 6条：n 4、nz 1、zn 1。
- 主十元候选：n 96%。强盗、异常身体、白血病搜索和被放弃的移植病例分属不同情境，却都表现为病例落到面前后由他接住并推进到阶段结果。
- 次十元：暂不锁定。nz与zn各一条高质量证据，只能作功能位。
- 旧结论处理：撤回主zn、次x及zx执行位。当前6个具体动作中没有稳定的资源、地盘、权限或关系“归我掌握”端点；高难手术和高额收费也不能替代x端点。

### 关系、反证与作品主维

- 生补克：不登记。行为6能显示zn原则，但没有另一条独立动作证明该原则怎样生成更多n承接；不能用同一手术同时证明zn与n再宣称zn生n。
- 反证：行为4会为皮诺可放弃执照窗口，说明他并非只承接匿名病例；行为6由明确价值原则启动，说明n不是唯一行动来源。
- 与作品主维：总索引当前登记因果主、命运次。人物n高频说明“病例由谁接住”，不等于因果公式zx+nx；单点nz只支持关系代价节点，不能自动组成命运公式。人物主位与作品主维需继续分层。
- 原话复核：第2、12、30、38、40、56话；优先核第30话搜索结果、第40话移植结果及第56话接走患者的完整前后因果。
