  - 归类：n（阳土，主位证据，93%）。对象端点：雏子的日常身体与生活。
- 行为3：雏子因家规被禁足 → 阳菜绕到后院的杂物房，从窗下递进纸条和一小包蜜渍点心 → 作用于禁足状态与雏子位置 → 雏子在杂物房读到纸条，并没再叫苦。
  - 归类：xn（阳金，主位证据，89%）。对象端点：禁足规则下的内部通道与雏子接收。
- 行为4：雏子随口抱怨新侍女动作粗笨 → 阳菜不动声色地用雏子教过的新式绑带把头发重新扎好 → 作用于雏子的外表与侍女身份 → 雏子的发型恢复完整，没再提起换侍女。
  - 归类：x并z（阴木，主位证据，92%）。对象端点：侍女身份的可见界面与他人读取入口。
- 行为5：雏子在集会上被陌生男子当众套话 → 阳菜上前一步扶住雏子的胳膊把话头揽到自己身上，引开陌生男子走远 → 作用于雏子与陌生男子的接近距离 → 陌生男子被引走，雏子当晚未再受扰。
  - 归类：x并z（阴木，功能位证据，88%）。对象端点：雏子身份保护与外部读取转移。
- 行为6：阳菜因时空穿越的实际身份开始动摇 → 把雏子送的护身符放进妆奁底层，与来历不明的旧物放在一起，不再每日佩戴 → 作用于自我身份标识 → 护身符从每日外显转成底层保存。
  - 归类：nz（阴土，主位证据，90%）。对象端点：自身旧身份物与归宿存放。
