> 十元公式：x并z（阴木-包装/伪装） + n（阳土-家园/承载）

## 空间型5个子类型

### ⚡ 临界空间型
**代表**：间隙
**特征**：x并z（包装）与 n（承载）之间处于临界不安稳状态——包装太紧则角色被压迫，包装太松则角色感到空洞。角色在寻找那个恰好能容纳自己的空间缝隙。
**生克关系**：x并z ⚡ n（共振——空间型锐化状态），包装与承载的临界匹配产生张力。
**扩展预览**：其他临界空间型候选→来自深渊、寄生兽

### 便携空间型
**代表**：神之水滴
**特征**：空间单位是可移动的、可被传递的——一瓶酒、一碗面、一张照片，打开即创造出一个封闭的意义空间。x并z被装在一个手持容器里。
**生克关系**：x并z → 生 → n（标准模式），但便携属性使得空间的边界可以由持有着携带移动。
**扩展预览**：其他便携空间型候选→拉面发现传（一碗面）、孤独的美食家（一餐饭）

### 🩸 病理空间型
**代表**：MOAN
**特征**：x（desire/devour）渗透进入 x并z，导致空间从承载变为吞噬。封闭空间不是在保护角色，而是在消耗/榨取角色。
**生克关系**：x并z → 逆生 → n（空间型崩坏状态），x渗透x并z形成x并z(x)——包装内嵌吞噬性。
**扩展预览**：其他病理空间型候选→寄生兽、银翼杀手、部分伊藤短篇

### 创作封闭空间
**代表**：放課後ボカ研で
**特征**：封闭空间（社团教室/录音棚/画室）不是纯粹包裹角色，而是生产意义的盒子。角色进入这个空间是为了从内部产出东西（歌曲/画作/表演），产出物成为连接封闭空间与外部世界的桥梁。
**生克关系**：x并z ⊕ n → 附加zn穿透：空间有泄漏点，意义通过产出物逸出。
**扩展预览**：其他创作封闭空间候选→孤独摇滚（livehouse）、青之管弦乐（练习室）、蓝色时期（画室；2026-07-23公开动作9条=`nx`5/`zn`2/`x`1/`xn`1，矢口八虎主`nx`95%候选、次`zn`94%候选，旧`xn+z`撤回；人物学习接口不等于作品空间主维，作品仍为无评分候选）

### 零振动空间型
**代表**：Hirayasumi
**特征**：x并z+n的理想平稳状态——空间恰好容纳人，人恰好适合空间，两者之间没有多余张力。这是空间型的基准点，其他子类型都是从这个状态出发的偏移。
**生克关系**：x并z ⊕ n（最纯粹的互补关系，无摩擦，无干扰）
**扩展预览**：其他零振动空间型候选→海街diary、昭和元禄落语心中（时间型推翻前曾考虑）

## 推翻记录

### 🔄 葬送的芙莉莲：空间/命运 → 命运型（88%）
**推翻原因**：旅途被误认为空间结构。芙莉莲中空间是透明的、可随时脱离的——真正的边界是时间（精灵寿命vs人类寿命）。xz（边缘漂移）生 nz（等待/渴望），空间只是时间流逝的刻度尺。
**偏差模式**：意象当结构——把故事背景环境（旅途）当成了故事驱动力。

**2026-07-23 人物行为穷举复核**：芙莉莲7条唯一归类=`xn`3/`nx`2/`nz`1/`zx`1，主`xn`95%候选、次`nx`92%候选；旧主`nz`、次`n`与关系撤回。“精灵长寿/寿命错位”仍只作作品时间结构，不反写人物。见[[2026-07-23_主角十元行为穷举_第四十四批3部旅途饮食与山岭复核]]，空间推翻结论继续保留。

### 🔄 天使夜未眠：空间/命运 → 命运型（87%）
**推翻原因**：深夜被误认为空间结构。深夜不是空间——深夜是时间的切片，一种存在状态。xz（边缘）在时间中漂流触及空间节点，触发 nz（等待/渴望）的情感反应。
**偏差模式**：和芙莉莲平行的意象当结构——深夜≠空间，是存在状态。

**2026-07-22 人物层复核**：中文尖端版《天使夜未眠》与高河ゆん《アーシアン / EARTHIAN》高置信同作。新书馆公开书目只支持千飒2条动作（`zn/nx`各1）和影艳1条（`nx`），二人主次均未判；分离、不舍、动摇、袭击不再冒充人物动作，旧千飒`nz`及影艳`nx→nz`迁移撤回。人物证据不足不推翻作品命运归位，也不恢复空间主位。见[[2026-07-22_主角十元行为穷举_第三十一批3部逃亡影像与天使复核]]。

### 🔄 东京日日：空间 → 本体型（91%）
**推翻原因**：松本大洋式的空间处理——空间作为意义的触发点而非容器。东京不是让角色停留的空间，而是让角色穿过的通道。zn（意义/信念）生 n（精神个体），空间只是意义索引。
**偏差模式**：松本大洋系统性F12偏差——他的空间都是透明的、可穿过的，F12始终用空间型的直觉去套。建议对松本大洋全作品做系统性F12审查。
