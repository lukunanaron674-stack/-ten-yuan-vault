## 04｜三部电影：横纵一体文字构图与具体证据（第一轮）

### A｜《土拨鼠之日》：外部重复不等于人物停滞
```text
同一日初期 ───────────────────────────────────────────────
菲尔（反复自利尝试） ──→ 镇民／丽塔（被当工具或目标） ──→ 关系难以推进
       │                     ↑
       ↓（事件重置，菲尔的经验不重置）
重复日中期 ───────────────────────────────────────────────
同一天的居民不记得 ──→ 菲尔仍记得失败 ──→ 改变相处方式、反复练习
       │                                      │
       └──────────【反馈】前轮失败的记忆 ─────────┘
       ↓（持续累积的能力/关系态度）
循环出口 ─────────────────────────────────────────────────
助人、投入眼前生活 ──→ 真正有意义的互动 ──→ 新的一天
```
**主题问题：**没有未来递增时，“今天”是否还有价值？**横向关系：**居民记忆重置、菲尔经验保留，二者信息不对称；丽塔不是简单奖励。**纵向实变：**Action/Capacity/Feedback持续累计。**时间对本体：**同一天不变而人物改变，注意主题层“本体克时间”方向不能被单片经历直接颠倒。**感受候选：**厌烦→轻快的练习感→温暖；XN/Z只是尚待人类观众验证的感受预测。

### B｜《源代码》：八分钟的事件重访与不可重置的伦理选择
```text
第1轮 ───────────────────────────────────────────────────
任务系统（8分钟边界） ──→ 科尔（受限观察） ──→ 火车乘客（不知任务）
            │                    │
            ↓ 每轮重置车厢        ↓ 经验进入下一轮
第N轮 ───────────────────────────────────────────────────
旧轮线索与记忆 ────────→ 科尔重新行动 ──→ 更接近袭击者与救援方法
            ↑                    │                │
            └────────【反馈】失败或新线索 ───────┘
最终选择 ─────────────────────────────────────────────────
查明任务目标 ─────────→ 争取多于“完成任务”的行动 ──→ 主体伦理反问
```
**主题问题：**时间足够短时，执行任务之外的自主选择是否仍重要？**横向关系：**军方任务、科尔的知情权、乘客的安全不自动一致。**纵向：**世界状态重访，但主角的Knowledge/Capacity累积。**代价承担：**乘客风险与科尔身体处境分开讨论。**感受候选：**压迫→专注→主体被看见。旧稿结局“只有记忆留存”并非足够完整的结局解释，待逐场审核。

### C｜《恐怖游轮》：试图撤销后果的动作反而为循环提供因
```text
初次登船 ─────────────────────────────────────────────────
杰西（想救人/离开） ──→ 游轮重复事件（版本重叠） ──→ 同伴受害
       │                      │                          │
       ↓ 察觉不同时刻的自己    └────── 新的信息 ←──────────┘
继续循环 ─────────────────────────────────────────────────
杰西企图改变局面 ────→ 对其他版本/同伴采取行动 ──→ 制造旧场景条件
       ↑                                               │
       └─────────【反馈】选择导致似曾相识的局面 ←────────┘
终局问题 ─────────────────────────────────────────────────
形式上的“回到起点” ≠ 责任/伤害被撤销；是否真正有Undo仍待逐场核对
```
**主题问题：**“再来一次”能否抹掉负罪与行动后果？**横向关系：**多个杰西、同伴、游轮条件共同构成同一事件，非“一个人的情绪时间线”。**纵向：**试图救人/逃离→主动施加动作→动作反成回路条件。**感受候选：**迷惘→惊恐→窒息；不能把旧X→N→Z链当当前正式十元判决。

## 05｜对创作可吸收的结构（仅候选）

1. **固定世界，可变人物：**《土拨鼠之日》式外部重置／经验累积的差值，可用于同一场景多次出现但重心逐次转移。
2. **时间克因果的可视化：**本来“做了A所以会有B”，时间窗口关闭、记忆残留或跨年代延迟让B无法按预期到达；必须写清 Carrier 与真实受损变量，不直接凭公式判定。
3. **不可Undo的关系：**修改过往与Repair/Adapt区分。不要靠“时光重置＝所有伤害被取消”的廉价回收。
4. **双时钟冲突：**《星际穿越》《触不到的恋人》可进一步比较“同一关系，不同时间刻度”的承诺兑现。
5. **电影主题不等于能力设定：**影片拥有穿越装置但主问题可以是身份、责任、空间出口、道德选择；《前目的地》《意外空间》《明日边缘》必须做主/次反例审核。

**创作种子（非影片剧情）：**
- 信件每改变过去一句话，当下某人的一份关系证据便会消失；女主必须决定是否继续寄信。
- 城市里只有一个人记得昨夜的演奏，每次重复他都更了解她，她却永远第一次见他。
- 两个人共享同一首曲子，却不共享同一段时间；完成第二声部的瞬间，他们必须放弃原本可达的相遇方式。

## 07｜2026-11-01 R2：时间主题 × 十元符号反应文字（按《方志敏》三幕操作法）

> 本节接续R1旧20片，新增“XN相关影视”25项，共45条**资料索引对象**。不能宣称45部时间主主题电影：包含时间次主题、非时间反例、剧集与未核片名。  
> **公式层**：时间 = XN＋Z（用户五维预设）。**人物层**：角色身份/稳定性格是独立对象。**感受层**：十元符号写艺术刺激可能激活的观看感受；具体强度皆为AI预测，F_human=null。  
> 研究优先序：`主题问题 → 横向同事件力量 → 纵向因果 → 十元观感变化 → 影像/音响 → 反证`，不再使用“聪明= XN”“有计时器 = 时间主”“单个动作等于某十元生克”的旧捷径。
>
> “方志敏式”借用的是**第一幕给稳定状态；第二幕让作用力与环境施压；第三幕让选择及代价产生关系重排，同时镜头、光影、声音与物件复现**；不把方志敏影片内的具体历史人设或旧符号裁决硬移植给别的影片。

### 07A｜《东京教父》（2003，今敏）：一段跨年寻亲，让过去的家人重新进入现在

**对象纠正（USER 2026-11-01）**：此处应是**今敏《东京教父》（Tokyo Godfathers，2003）**，不是科波拉的《教父》（The Godfather，1972）。后者的已做分析转入`01-命运 xz+nz`，本章不再拿柯里昂家族充当《东京教父》论据。  
**主题研究定位**：【时间 XN＋Z：主要研究对象；命运 XZ＋NZ／本体 ZN＋X：强竞争解释，主次待逐场验收】。按用户主题归档，不强行宣称今敏原片“客观只有时间主题”。
**可核剧情事实**：圣诞夜，阿银（金）、小花、离家少女美由纪三名无家可归者在垃圾堆发现女婴清子。三人围绕是否报警、临时照料以及寻找她的亲生父母发生不同选择；其后受线索和巧合引导穿过东京，并不得不面对各自过去的人际断裂。前往新年之际，关于清子身份的判断发生反转，影片最终让新的“教父/教母”责任与修复亲缘关系的机会相遇。【F1：片方、电影资料馆与上海国际电影节简介；具体镜头时间码未核】

**主题问句**：**一个人已经错过了原来的家庭生活，还能不能通过照顾眼前的孩子，在新的时间里重新承担家庭责任？**

### 07C+｜《钢琴家》方志敏式十元全案 R3（2026-11-01）

#### I｜主题判断：不是“音乐赢了战争”

**主问题**：当公共身份、家庭与安全空间被连续剥夺，人能否在长期不得发声的处境里，仍保存“自己是钢琴家”的自我关系？**答案不是获救代表创伤被抹平。**

- **空间：强主候选**。电台（能公开存在）→隔都和藏室（只能隐藏）→废墟（无可持续承载）→战后电台（重新公开）。可发声/可藏身/可行动的**空间许可**是可观察的主变量。
- **命运：强主候选**。被家人分离、偶然获救、军官选择提供食物与遮护；有不可逆损失，也有他人行动与偶然性。不要将幸存写成主人公单靠意志必然创造的结果。
- **时间 XN＋Z：重要次主题候选**。数年的等待使“不能弹”不是瞬间禁令，而变成跨阶段身份压力；最终同曲回响，不等于这五年被删除。**XN是具体场景的感受假设；被动忍耐本身不证明X N端点或‘XN补Z’成立。**
- **本体：贯穿问句**。“不能出声时，仍是钢琴家吗？”身份的生存与社会承认被分离。**因果：局部强**，尤其是军官发现→询问职业→要求演奏→决定帮助，但不能把“琴声导致获救”简化为一条必然机制。

### 08A｜与原20部时间实验的符号交叉

以下所有十元箭头都表示**观看感受的预测性阶段变化**而非电影客观十元本体，也不等于正式生/克/补。一些旧条目的原始剧情和中译名未经逐场验证，依旧待核。

- **01**：`XN（病程/制度时间）＋XZ（有限窗口）→NZ（彼此陪伴）`；制度时限改变承诺的代价；不给人物固定XN人格。
- **02**：`Z（相遇惊喜）→NZ（协作亲近）→XZ（别离压力）`；时差/离别是关系阻力，不能用原表八千年推断。
- **03**：`Z（出走）＋XN（职业边界）→NZ（相守）→XZ（岁月不同步）`；时间机制由赋能关系转为消耗关系。
- **04**：`N（生存任务）→XZ（延迟失去）→XN（信息/刻度）→NZ（重见）`；延迟信息必须通过真实媒介到达彼此。
- **05**：`Z（急切享受）→XZ（倦怠）→XN（练习积累）→NZ（关怀）`；固定事件中Feedback/Capacity累加。
- **06**：`XZ（恐慌）→ZX（试图改道）→XN（重复识别）→XZ（闭环）`；回路不是十元人格；以负罪重释而非X-N-Z硬推。
- **07**：`XZ（遇害不安）→XN（线索累计）→ZX（反击）→Z（继续生活）`；死亡重置的是事件，不是反复学习的经验。

- **11**：`Z（闯入过去）→XZ（存在危机）→NX（修复计划）`；修复行为未必消除所有原始后果。
