## 04｜三部电影：横纵一体文字构图与具体证据（第一轮）

### A｜《土拨鼠之日》：外部重复不等于人物停滞
```text
同一日初期 ───────────────────────────────────────────────
菲尔（反复自利尝试） ──→ 镇民／丽塔（被当工具或目标） ──→ 关系难以推进
       │                     ↑
       ↓（事件重置，菲尔的经验不重置）
重复日中期 ───────────────────────────────────────────────
同一天的居民不记得 ──→ 菲尔仍记得失败 ──→ 改变相处方式、反复练习
       │                                      │
       └──────────【反馈】前轮失败的记忆 ─────────┘
       ↓（持续累积的能力/关系态度）
循环出口 ─────────────────────────────────────────────────
助人、投入眼前生活 ──→ 真正有意义的互动 ──→ 新的一天
```
**主题问题：**没有未来递增时，“今天”是否还有价值？**横向关系：**居民记忆重置、菲尔经验保留，二者信息不对称；丽塔不是简单奖励。**纵向实变：**Action/Capacity/Feedback持续累计。**时间对本体：**同一天不变而人物改变，注意主题层“本体克时间”方向不能被单片经历直接颠倒。**感受候选：**厌烦→轻快的练习感→温暖；XN/Z只是尚待人类观众验证的感受预测。

### B｜《源代码》：八分钟的事件重访与不可重置的伦理选择
```text
第1轮 ───────────────────────────────────────────────────
任务系统（8分钟边界） ──→ 科尔（受限观察） ──→ 火车乘客（不知任务）
            │                    │
            ↓ 每轮重置车厢        ↓ 经验进入下一轮
第N轮 ───────────────────────────────────────────────────
旧轮线索与记忆 ────────→ 科尔重新行动 ──→ 更接近袭击者与救援方法
            ↑                    │                │
            └────────【反馈】失败或新线索 ───────┘
最终选择 ─────────────────────────────────────────────────
查明任务目标 ─────────→ 争取多于“完成任务”的行动 ──→ 主体伦理反问
```
**主题问题：**时间足够短时，执行任务之外的自主选择是否仍重要？**横向关系：**军方任务、科尔的知情权、乘客的安全不自动一致。**纵向：**世界状态重访，但主角的Knowledge/Capacity累积。**代价承担：**乘客风险与科尔身体处境分开讨论。**感受候选：**压迫→专注→主体被看见。旧稿结局“只有记忆留存”并非足够完整的结局解释，待逐场审核。

### C｜《恐怖游轮》：试图撤销后果的动作反而为循环提供因
```text
初次登船 ─────────────────────────────────────────────────
杰西（想救人/离开） ──→ 游轮重复事件（版本重叠） ──→ 同伴受害
       │                      │                          │
       ↓ 察觉不同时刻的自己    └────── 新的信息 ←──────────┘
继续循环 ─────────────────────────────────────────────────
杰西企图改变局面 ────→ 对其他版本/同伴采取行动 ──→ 制造旧场景条件
       ↑                                               │
       └─────────【反馈】选择导致似曾相识的局面 ←────────┘
终局问题 ─────────────────────────────────────────────────
形式上的“回到起点” ≠ 责任/伤害被撤销；是否真正有Undo仍待逐场核对
```
**主题问题：**“再来一次”能否抹掉负罪与行动后果？**横向关系：**多个杰西、同伴、游轮条件共同构成同一事件，非“一个人的情绪时间线”。**纵向：**试图救人/逃离→主动施加动作→动作反成回路条件。**感受候选：**迷惘→惊恐→窒息；不能把旧X→N→Z链当当前正式十元判决。

## 05｜对创作可吸收的结构（仅候选）

1. **固定世界，可变人物：**《土拨鼠之日》式外部重置／经验累积的差值，可用于同一场景多次出现但重心逐次转移。
2. **时间克因果的可视化：**本来“做了A所以会有B”，时间窗口关闭、记忆残留或跨年代延迟让B无法按预期到达；必须写清 Carrier 与真实受损变量，不直接凭公式判定。
3. **不可Undo的关系：**修改过往与Repair/Adapt区分。不要靠“时光重置＝所有伤害被取消”的廉价回收。
4. **双时钟冲突：**《星际穿越》《触不到的恋人》可进一步比较“同一关系，不同时间刻度”的承诺兑现。
5. **电影主题不等于能力设定：**影片拥有穿越装置但主问题可以是身份、责任、空间出口、道德选择；《前目的地》《意外空间》《明日边缘》必须做主/次反例审核。

**创作种子（非影片剧情）：**
- 信件每改变过去一句话，当下某人的一份关系证据便会消失；女主必须决定是否继续寄信。
- 城市里只有一个人记得昨夜的演奏，每次重复他都更了解她，她却永远第一次见他。
- 两个人共享同一首曲子，却不共享同一段时间；完成第二声部的瞬间，他们必须放弃原本可达的相遇方式。
