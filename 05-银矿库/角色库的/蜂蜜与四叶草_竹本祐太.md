# 竹本祐太
> 归档：`05-银矿库/角色库/蜂蜜与四叶草_竹本祐太.md`

---

## 1. 主十元判断

**主十元：xz（阴木·被推着走/不知道归处）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉xz，竹本就是一个普通的工科男生——会做木工、脾气好、暗恋阿久。但竹本最核心的不是"温柔"，是**他永远在问"我该去哪"**。大学快毕业了不知道做什么、暗恋阿久不敢说、别人都在往前走只有他在原地——他骑自行车环游，不是因为想好了，是因为不动不行了。
- **第2问（反复面对什么结构）：** 反复面对「别人都在往前走，我该怎么办」。真山在找工作、森田在搞创作、阿久在做艺术——每个人都知道自己在做什么，只有竹本不知道。
- **第3问（最怕失去什么）：** 最怕「一直不知道」。比起被阿久拒绝（z），他更怕——很多年以后、他还在原地、还不知道自己要去哪。
- **第4问（回到哪个感觉）：** 回到「骑在车上、什么都不想、只管踩脚踏板」的那一刻。身体在动的时候，大脑就不需要问"我是谁"了。
- **第5问（副十元服务谁）：** z（想被看见/被阿久看到）是xz的一个出口——"如果我骑到了很远的地方，她会不会看见我"。但这不是驱动，是他在路上偶尔闪过的念头。

## 2. 副十元

**副十元：z（阴火·想被看见/被喜欢的人看到）**

**作用：** 竹本对阿久的感情不是热烈的追求（zx），也不是默默的承载（n），是"我希望你看到我，但我不敢告诉你"。他做的蜂蜜吐司、他说要去骑行、他回来后站在阿久面前——这些都是z的微小释放。

## 3. 功能十元

**功能十元：n（阳火·承载/保持）——表层。** 竹本在团队里的角色是"接住所有人"的那个——接住真山的疲惫、接住森田的疯狂、接住阿久的脆弱。这是他在不知道去哪时的功能。

## 4. 视觉十元

**视觉十元：x（阴水·透明/无害）。** 竹本就像一杯白水——别人很容易忽略他，但他一直在。视觉上他是最不显眼的角色。

## 5. 动态链

```
xz（主·不知道去哪但停不下来）
  → z（副·希望暗恋的人看见我）
  → n（功能·接住所有人/在团队里站位）
  → 毕业迷茫→骑自行车环游→回来后站在阿久面前
  → 他还是不知道，但他至少出发了一次
```

## 6. 一句话定型

竹本不是「青春的代表」，也不是「默默守护的暗恋者」，而是「**不知道自己要去哪但必须出发**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** xz（主）+ z（副）→ 命运型
**最终定位：** xz（主·被推着走/不知道归处）+ z（副·想被看见/被喜欢的人看到）→ 命运型
**最终修正理由：** 原卡将竹本定位为zx（先做再想）+ nx（算清楚再动），但竹本既不是"完成即意义"（zx），也不是"算清楚再动"（nx）。他是不动不行了才出发（xz）。他的骑行不是"我要做这件事"，而是"我不知道能怎么办了"的物理性释放。副十元z来自于他对阿久的暗恋结构——他希望被看见，但不会主动去追求"被看见"。
