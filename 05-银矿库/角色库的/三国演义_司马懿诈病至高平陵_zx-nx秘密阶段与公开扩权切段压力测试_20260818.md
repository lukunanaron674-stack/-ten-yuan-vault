# 三国演义｜司马懿诈病至高平陵｜zx-nx秘密阶段与公开扩权切段压力测试

## 1｜本轮问题

测试同一人物同一政治冲突中：

```text
秘密隐藏、欺骗、等待时机
→ 是否能直接判 zx？

秘密阶段结束后公开夺取决定接口
→ 是否应切成新的 zx 阶段？
```

本轮严格分第106回诈病阶段与第107回高平陵公开行动阶段，不允许后段公开夺权倒灌给前段秘密阶段。

## 2｜剧情事实

### A｜第106回：诈病隐藏

曹爽逐渐专权，兵权归爽。司马懿称病不出，二子亦退职闲居。曹爽派李胜探查司马懿病情，司马懿故意散发卧床、装耳聋、让汤流满衣襟，并假称将死，以骗取曹爽放松戒备。

李胜离开后，司马懿立即起身，明确告诉二子：李胜回报后曹爽必不再忌惮，只等待曹爽出城游猎时再行动。

### B｜第107回：高平陵公开行动

曹爽兄弟与魏帝曹芳出城后，司马懿公开起兵：

- 令高柔据曹爽营；
- 令王观据曹羲营；
- 入宫迫使郭太后同意废爽；
- 自引大军据武库；
- 控制洛水浮桥、城门与关键军政节点；
- 上表要求罢曹爽兄弟兵权。

曹爽最终交出印绶，部众因失去将印而四散；司马懿随后拘押、处置曹爽集团，魏国军政决定中心发生现实转移。

## 3｜zx 判断

### A｜秘密诈病阶段：zx 排除为主判

司马懿确实有自己的反制方向，但此时主机制是：

```text
隐藏真实能力
→ 欺骗曹爽判断
→ 等待对方放松警戒
→ 保存行动窗口
```

这一阶段没有：

- 自身权能公开进入现实；
- 曹爽集团公开围绕司马懿新增决定接口运行；
- 司马懿的实际公开决定范围上升。

因此：

`zx_secret_stage: rejected_as_primary`

最强最近邻是 `xn`：主动设计伪装、信息误导、时机与触发窗口。

### B｜高平陵公开阶段：zx 锁定

这一阶段满足 zx 准度卡硬门：

```text
主体自身军政力量公开进入现实
→ 曹爽营、曹羲营、武库、浮桥等关键节点被重新占据
→ 郭太后、曹芳、曹爽集团、军队都被迫围绕新现实重新反应
→ 曹爽交印，原部众四散
→ 司马懿决定位置与作用范围真实上升
```

因此：

`zx_public_coup_stage: evidence-locked`

这里不是“司马懿很聪明”或“最后赢了”导致 zx，而是原决定结构被公开改写，主体成为新的现实决定来源。

## 4｜nx 判断

### 秘密阶段

司马懿没有接受曹爽已经形成的政治方向并沿其继续，也没有请求曹爽或其他掌权者提供解决通道；他主动构造反向方案。因此不锁 nx。

### 公开阶段

司马懿虽然调用郭太后诏令、旧部和官僚接口，但文本中郭太后并非一个真正独立决定方向后让司马懿沿其执行的上位节点；相反，司马懿先形成方向、带兵入宫，郭太后在压力下“只得从之”。

因此本阶段的主骨仍是司马懿自身权能成为新的决定来源，不以 nx 为主判。

`nx_in_both_narrow_stages: rejected_as_primary`

## 5｜关键压力

曹爽已经夺取兵权并持续削弱司马懿的公开位置，使司马懿前期若正面行动成本极高。

该压力解释为什么出现秘密隐藏与等待，但不能把“被压制”本身直接判成 nx，也不能把“秘密筹划”直接判成 zx。

真正的 zx 显影发生在压力窗口成熟后，司马懿从隐藏切换到公开夺取决定接口。

## 6｜拿掉测试

### 拿掉诈病表演细节

拿掉耳聋、流汤、卧床等戏剧细节，只保留“隐藏真实能力→骗取对方放松→等待对方离城”，秘密阶段仍主要是 `xn` 策略邻近，不足以成立 zx。

### 拿掉最终诛杀曹爽

即使先不看曹爽最后被诛，只看到：

```text
公开起兵
→ 占营、占武库、控浮桥
→ 曹爽交印
→ 军队四散
```

就已经足够证明决定位置真实上升，因此公开阶段 zx 不依赖最终杀戮结果。

### 拿掉司马懿名位

不使用“太傅、托孤重臣”等身份词，只保留上述行动链，zx 仍成立。因此不是身份直判。

## 7｜反向测试

### 秘密阶段反向成 zx

如果司马懿诈病期间已经公开发号施令，使曹爽集团不得不围绕他的新增军政接口运行，那么才会提前出现 zx；文本没有。

### 公开阶段反向成伪 zx

如果司马懿起兵后未能控制任何关键节点，曹爽仍保有兵权、军队继续服从曹爽、司马懿也未获得新的决定位置，则只能算强烈公开行动，不能锁 zx。

### 反向成 nx

如果司马懿只能请求郭太后或另一个真正拥有最终否决权的主体决定是否削曹爽兵权，并且自己必须等待批准后照令执行，才会显著上升为 nx 权限关系。

## 8｜最近邻排除

### zx vs xn

- 诈病、欺骗李胜、等待曹爽出城：`xn` 策略与节点组织。
- 公开占营、武库、浮桥并迫使曹爽交印：`zx` 权能公开扩张。

两阶段不可混写。

### zx vs x

- 高平陵发生时：权限边界正在从曹爽一侧向司马懿扩张，优先判 `zx`。
- 夺权稳定之后：新的军政调用范围已经成为司马氏稳定持有对象，后续应转查 `x`。

### nx vs x

调用已有官僚、旧部不自动是 nx；若这些节点已处于司马懿实际可调用边界，应检查 x。只有必须经过独立外部权限主体重新批准，才支持 nx。

## 9｜第三因素冻结

冻结以下因素后主结论不变：

- 司马懿是否忠魏或篡魏的道德评价；
- 曹爽是否昏庸；
- 司马懿智谋名声；
- 最终司马氏是否篡魏；
- 人物官职和年龄；
- 后续司马师、司马昭的发展。

只检查：权能何时公开、谁控制关键决定接口、现实结构是否因此重排。

## 10｜对象层结论

- 稳定人物本体：不锁。
- 第106回诈病当前状态：`xn` 秘密策略邻近高显影；`zx` 排除为主判；`nx` 排除为主判。
- 第107回高平陵当前状态：`zx` evidence-locked；`nx` 排除为主判。
- 高平陵之后稳定权限：可进一步检查 `x`，本轮不扩大范围锁定。
- 严格 zx↔nx 补关系：不锁。

## 11｜对待审议问题的增量

本例直接支持：

> **秘密阶段与暴露后的公开扩权阶段必须切开。**

同一主体可以出现：

```text
秘密布局 / 欺骗 / 等待
= xn 高显影，伪 zx

条件成熟后公开占据关键权限节点
= zx 高显影
```

因此不能因为后段夺权成功，就把前段诈病、隐忍和秘密操盘倒灌成 zx；也不能因为前段秘密，就否认后段真实公开扩权。

这为 `待审议问题_zx秘密改结果与公开扩权边界_20260818.md` 的第4项待验证问题提供首个高纯正向切段样本。

## 12｜结论

```text
秘密筹划成功 ≠ zx。
公开成为新的现实决定来源 → zx。

同一人物前后连续发生时，必须按阶段切片。
```

本轮不修改 L1、zx/nx 信息卡、准度卡与 zx补nx_补卡。
