# 《三国演义》周瑜｜局部军务裁量与最终战区调度边界压力测试

## 1｜剧情事实

第四十四回，孙权最终决定抗曹，并授周瑜大都督等军权。第四十五回以后，周瑜在前线实际分拨军将、下寨、配置军务并组织对曹作战，表现出真实而持续的局部军务调用与运行组织能力。

第五十二回出现关键冲突测试：孙权围合肥不利，遣使命周瑜收回大军，并另拨兵赴合肥相助。小说明确写周瑜“只得班师回柴桑养病”，并令程普带战船士卒赴合肥听孙权调用。

因此对象层必须拆开：

```text
赤壁前线内部：
军将 / 营寨 / 兵力运行 / 战术配置
→ 周瑜可持续直接调用
= 局部 x + xn

更高战区层：
是否继续当前方向 / 是否班师 / 是否抽兵支援合肥
→ 孙权可直接重设
→ 周瑜必须执行
= nx 最终调度关系位置
```

## 2｜zx 判断

本窄阶段不锁 zx。

周瑜公开统军、众将听令、战果显著，都不足以证明本轮发生了新的决定范围扩张。大都督权限在授权后已经进入其既有军务调用边界；在该边界内正常分兵、下寨、作战，优先解释为 `x/xn`。

第五十二回反而提供限制证据：更高战区去留与跨战场资源重配仍可由孙权直接重设，周瑜没有把自己的决定边界公开推进到孙权保留的这一层。

结论：

`zx_in_narrow_stage: rejected_as_primary`

## 3｜nx 判断

不锁周瑜纯 nx 本体。周瑜自己有明确抗曹判断，也有极强前线组织能力。

但在“当前大军是否继续留在该战区、何时班师、是否抽调部队支援合肥”这一具体对象层，最终调度接口仍在孙权。孙权命令到达后，周瑜不能仅凭自己的战区判断让原部署继续生效，而是实际班师并拨兵。

因此锁：

`nx_final_redeployment_relation_position: evidence-locked`

## 4｜关键压力

关键压力不是曹军强弱，而是孙权在另一战场合肥受阻，需要重新配置东吴有限军力。

该压力把平时不易观察的权限上限压出来：周瑜拥有很大的前线裁量，但战区去留与跨战场重配并未完全进入他的独立处分边界。

压力只负责显影，不直接判十元。

## 5｜拿掉测试

### 拿掉“大都督”头衔

只保留“周瑜可持续直接配置前线军务，但孙权可强制班师并重新抽调兵力”，仍得到：局部 `x/xn` + 更高调度层 `nx`。

### 拿掉赤壁胜利

胜败不改变权限结构。即使周瑜未取胜，只要前线军务可由其直接组织、而战区去留仍由孙权重设，本轮结论不变。

### 拿掉孙权真实重调动作

若只剩名义上的“孙权是主公”，却没有任何证据显示他能实际推翻或重设周瑜的前线去留，则 `nx` 最终调度证据会显著下降，不能仅凭组织架构图判断。

## 6｜反向测试

### 反向成完整局部 x

若周瑜可自行决定是否班师、是否抽调兵力赴合肥，孙权只能建议而不能让调度直接生效，则该战区调度层应转查 `x`。

### 反向成更深 nx

若孙权连前线下寨、分兵、战术节点都逐项决定，周瑜只执行，则局部 `x/xn` 会下降，nx 覆盖更深。

### 反向成 zx

若周瑜公开突破孙权保留的战区调度边界，并迫使东吴体系承认其新增跨战场最终处分权，才进一步检查 zx。

## 7｜最近邻排除

- `x`：周瑜真实掌握前线军务调用边界。
- `xn`：周瑜主动组织营寨、兵力、战术与运行节点。
- `nx`：更高战区去留与跨战场重配仍由孙权决定。
- `zx`：本轮没有新的权限边界继续公开扩大。

不得因“周瑜很会打仗”判 zx，也不得因“孙权是主公”把周瑜全部军务判成 nx。

## 8｜与平儿案例的跨作品最小差异

《红楼梦》平儿玫瑰露案：主体能调查、暂缓、重设结案方案，但最终让新方案覆盖旧处分仍需凤姐真实批准。

《三国演义》周瑜赤壁统军：主体能持续组织前线军务，但最终让大军继续留场、班师或跨战场重配仍可由孙权真实重设。

两例共同支持：

> **“日常/方案/战役层裁量很大”不能自动推出“更高最终处分接口已经归主体”。发生真实冲突、撤回、重配或否决时，谁能让决定最终生效，才是更硬的权限证据。**

目前跨作品计数为 2，不单独新建待审议问题；继续积累第三部独立作品。

## 9｜第三因素冻结

冻结：周瑜智谋评价、孙权是否英明、赤壁胜负、曹军人数、人物官职声望、周瑜与诸葛亮竞争等。

这些均不能直接决定木轴分类。

## 10｜结论

```text
周瑜前线军务：x + xn
孙权保留的战区去留/跨战场重配：周瑜处于 nx 权限关系位置
本轮不锁 zx
稳定人物本体不锁
严格 zx↔nx 补关系不锁
```

本例用于强化分层授权研究，不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
