# 《三国演义》赵云博望坡诱敌｜zx-nx 被动承接通道激活压力测试

## 1｜本轮问题

当前待审议已经锁定：

> 外部方向、权限或通道客观存在，不足以自动生成 nx；还要观察主体是否真的把当前行为接上该外部方向继续。

同时《红楼梦》周瑞家的送宫花提供第一条正向控制：主体不必主动求人，只要真实承接外部既定方向并持续执行，nx 行为功能仍可成立。

本例用于验证第二部独立作品：

> 没有主动求人；人物本身有很强行动能力；外部给出明确任务终点；主体不重设该终点，并在真正执行窗口持续按令推进。

## 2｜剧情事实

诸葛亮取得刘备剑印后调度博望坡之战。关羽、张飞、关平、刘封等分别得到伏兵、纵火任务；赵云被从樊城调回，明确被命为前部，任务要求是：

```text
不要赢
只要输
```

也就是前部的真正战术功能不是击败夏侯惇，而是诱使其继续深入。

赵云随后实际进入执行窗口：

1. 出马与夏侯惇交战；
2. 数合后主动诈败后退；
3. 退十余里后回马再战；
4. 再战数合又退；
5. 夏侯惇继续追赶，最终被引入博望坡后续火攻与伏击结构。

所以不存在“口头听令、实际自己另走一套”的问题。

## 3｜对象层

本轮只测试：

> **赵云前部任务的最终战术方向：此段到底要赢，还是要诱败后退？**

不测试赵云人物整体有没有主见，也不测试他每一招枪法怎么选择。

分层：

```text
上位战术终点：诸葛亮给定
→ 诱敌，不求当场取胜

局部战斗动作：赵云可自行完成
→ 如何交手、何时回马再战存在执行自由
```

## 4｜nx 判断

### 4.1 方向是否外置

是。

“不要赢，只要输”不是赵云自己提出的战术目标，而是诸葛亮明确下达。

### 4.2 主体是否实际接入该通道

是，而且不是只停在领命入口。

真正交战后，赵云没有把任务重写为“我现在直接斩夏侯惇”，而是实际执行诈败、回战、再退，使夏侯惇继续深入。

因此正式锁：

```text
nx_behavior_function_in_tactical_task: evidence-locked
```

这证明：

> **nx 的实际通道激活不要求主体主动求人。接受外部命令，并在执行窗口持续沿该方向推进，也可以构成高纯 nx 行为功能。**

## 5｜为什么不是稳定纯 nx 本体

本例只有一个战术任务窗口。

赵云本身有很强的作战判断与行动能力，本例不能推出：

> 赵云跨场景长期不占最终方向。

因此：

```text
stable_essence_locked: false
pure_nx_stable_essence: not_inferred
```

## 6｜zx 判断

### 6.1 强战斗是否自动等于 zx

否。

赵云确实公开交战、武力很强，但本轮没有看到：

- 他夺取“博望坡战术终点”的决定权；
- 他把“诱敌”改成自己的新总方向；
- 诸葛亮、刘备或军队被迫承认一个新增的赵云战术最高接口；
- 赵云的决定范围在此窄阶段发生扩张。

所以：

```text
zx_in_narrow_stage: rejected_as_primary
```

本例专门防止：

> “能打、动作强、冲在前面 = zx”

的误判。

## 7｜nx vs xn 最近邻

赵云当然拥有局部执行自由，例如交战节奏、回马时机等。

但本轮核心不是他主动搭建一套新的计划、排程、伏兵、火攻节点。完整博望坡流程来自诸葛亮。

因此：

```text
xn_local_execution_neighbor: present_but_secondary
```

判别句：

> 局部“怎么打”可以有自主动作；但当前“打赢还是诱退”的关键方向仍由外部给定，并被实际续接，所以 nx 主判不被局部动作自由覆盖。

## 8｜关键压力

背景确有夏侯惇大军来攻的战争压力。

但本例不是靠“战争逼得赵云只能服从”来锁 nx。真正证据来自任务结构与执行对应：

```text
外部给定诱敌终点
+
赵云有能力正常交战
+
实际仍按诱敌终点诈败、再退
```

战争压力只解释任务为什么存在，不能单独证明 nx。

## 9｜拿掉测试

### 9.1 拿掉主动求人

本例本来没有主动求人。

nx 仍成立。

因此：

> 主动求人不是 nx 行为功能的必要条件。

### 9.2 拿掉诸葛亮“不要赢，只要输”的外部战术方向

如果诸葛亮只说“你去当前部，自行处理”，赵云自己决定诱敌、回战、后退并搭建整个战术，那么 nx 会明显下降，应转查 xn / x / zx。

### 9.3 拿掉实际诈败执行

如果赵云虽然领到诱敌任务，但真正遇到夏侯惇以后主动改成正面决战并拒绝退走，那么只能证明“承接入口”，不能锁当前实际执行层 nx。

## 10｜反向测试

### 反向成非 nx / xn 上升

```text
诸葛亮只给“阻敌”目标
→ 赵云自己设计诱敌路线、退却节点、伏击配合
→ 自己重构运行方式
```

此时 xn 上升。

### 反向成 zx

```text
诸葛亮要求诱退
→ 赵云公开否定该方向
→ 以自身权能改成新的战术终点
→ 军队被迫围绕其新决定重排
```

才进一步检查 zx。

## 11｜第三因素冻结

以下全部冻结，不参与主判：

- 赵云武力高低；
- 夏侯惇是否轻敌；
- 诸葛亮是否神机妙算；
- 博望坡最终胜败；
- 赵云忠诚形象；
- 刘备主公身份；
- 战争主题本身。

只问：

> 谁给当前战术终点？赵云有没有重写？真正执行窗口里是否持续沿该方向推进？

## 12｜与周瑞家的最小差异

《红楼梦》周瑞家的：

```text
外部给定对象与数量
→ 被动承接送花
→ 持续按原分配完成
= nx
```

《三国演义》赵云：

```text
外部给定战术终点“不要赢，只要输”
→ 被动领命
→ 真正交战时诈败、再退
= nx
```

两个案例领域不同：

- 日常差事；
- 战术任务。

但共同支持：

> **nx 的通道激活核心是实际续接外部方向，不是有没有主动求人。**
