# 《水浒传》鲁达逃亡五台山｜zx↔nx 通缉压力下关系通道显影

## 结论先行

本轮只锁“鲁达拳打镇关西之后成为在逃犯，遇金老、赵员外，经赵员外的庄院、檀越关系、度牒与智真长老这一既有网络进入五台山剃度”这一阶段。

结论：

> **前一阶段仓库已锁鲁达当街压倒郑屠为 `zx` 当前状态正例；本阶段在官府通缉压力下，鲁达不再继续以公开权能正面压过官府追捕，而是进入赵员外已经拥有的住所、寺院关系、度牒与收录许可网络，以 `nx` 关系功能取得安身与身份转换通道。**

这不是“鲁达从 zx 换芯成 nx”，也不锁“鲁达稳定人物本体 = nx”。本轮只说明：同一人物在不同压力条件下，木轴两端可以分阶段显影。

```text
前段：
鲁达公开设定冲突
→ 当街压倒郑屠
= zx 当前状态

后段：
郑屠死亡
→ 官府悬赏缉捕
→ 鲁达自行流亡四五十日仍无稳定安身接口
→ 金老接入赵员外
→ 赵员外提供庄院庇护
→ 通缉逼近庄院
→ 赵员外提出五台山方案
→ 调用自己与智真长老的关系、檀越身份、既有度牒与费用
→ 鲁达接受并沿此通道进入文殊院
= nx 关系功能高显影
```

---

## 1｜剧情事实

### 触发

鲁达三拳打死郑屠以后离开渭州，在外逃走四五十日。到代州雁门县时，官府榜文已经明确悬赏缉捕鲁达；金老认出他后，将他带离榜下，避免其当场被捕。

### 对象

本轮对象不是“郑屠”，而是：

- 官府通缉造成的安全与身份缺口；
- 鲁达需要一个能够长期安身、避开追捕的现实通道；
- 这一通道所需的住所、寺院关系、度牒与收录许可并不归鲁达自己掌握。

### 明确动作

1. 金老把鲁达介绍给赵员外；
2. 赵员外先把鲁达接到七宝村庄上居住；
3. 几日后公人已经到附近打听，赵员外判断庄上不能久留；
4. 赵员外提出五台山文殊院方案：智真长老是其弟兄，赵家是寺院施主檀越，且已经买有一道度牒；
5. 鲁达明确判断自己当前无处投奔，接受赵员外方案，表示愿做和尚并靠赵员外照管；
6. 赵员外准备衣服、盘缠、缎匹、礼物，并亲自带鲁达到五台山；
7. 到寺后，由赵员外向智真长老提出收录请求，并调用檀越关系、度牒与费用接口；
8. 智真长老接受，鲁达由此进入寺院剃度通道。

### 结果

鲁达没有靠自己的武力公开取得合法身份，也没有压迫官府撤销追捕。他通过赵员外已经存在的关系与权限接口，获得新的安身与身份路径。

---

## 2｜为什么当前阶段判 nx

现行 nx 核心要求：

```text
方向、权限或解决通道已经存在
→ 主体不把自己放在最终决定位置
→ 沿外部关系、身份、权限或既有秩序推进
```

本段逐项命中：

- **安身解决接口外置**：鲁达自己没有寺院收录权、度牒、檀越身份或智真长老关系；
- **赵员外掌握关键通道**：庄院、施主关系、已购度牒、费用与对长老的请托都在赵员外一侧；
- **智真长老掌握最终收录接口**：鲁达不能自己宣布“从今天起我是五台山和尚”；
- **鲁达实际沿通道推进**：接受赵员外的路线，随赵员外上山，由赵员外出面请求收录。

因此本轮锁：

`nx_relation_function_under_fugitive_pressure: evidence-locked`

但不锁稳定人物本体。鲁达仍然非常有自己的判断，甚至在赵员外说“只怕你不肯”时自己作出接受决定；这里的 nx 是某个具体问题的外部解决通道，而不是“没主见”。

---

## 3｜zx 为什么在本阶段不作为主判

鲁达此前当街压倒郑屠已经有独立 zx 证据，仓库亦有正式案例。但本阶段不能因为“鲁达本来很强”就继续自动判 zx。

面对官府通缉，鲁达没有：

- 公开逼官府撤榜；
- 强迫地方官承认自己无罪；
- 夺取寺院收录处分权；
- 以自身力量让官府与寺院围绕一个新增的鲁达决定接口重新运行。

相反，他隐藏身份、转移地点、接受赵员外提供的既有关系与权限通道。

所以本阶段记录：

`zx_in_current_fugitive_solution_stage: rejected_as_primary`

这不是 zx 被永久消失，而是“公开正面压过去”的直接路径在当前合法身份问题上失去适用性，nx 关系功能因此高显影。

---

## 4｜关键压力

关键压力是：

```text
郑屠死亡
+ 官府榜文悬赏
+ 公人已开始在赵庄附近打听
+ 鲁达本人没有合法身份转换与寺院准入接口
```

压力的作用不是“被追捕 = nx”。真正的机制是：压力使鲁达单靠自身公开武力无法低成本解决“长期安身与身份合法化”这个对象，于是既有关系与权限网络的价值上升。

因此必须冻结：

- 鲁达战斗力强弱；
- 官府是否正义；
- 郑屠是否该死；
- 出家是不是好选择；
- 鲁达后来是否守清规。

这些都不能直接判木轴。

---

## 5｜最近邻排除

### nx vs xn

鲁达并没有主动设计完整的隐藏身份系统、寺院准入流程、度牒获取步骤和关系节点。

这些关键通道已经由赵员外给出：

```text
赵庄庇护
→ 五台山文殊院
→ 智真长老
→ 檀越关系
→ 已购度牒
→ 费用与礼物
```

鲁达只是接受并进入该通道。因此主判 nx，而不是 xn。

### nx vs x

庄院、寺院关系、度牒、费用和收录权都不归鲁达稳定掌握，所以不是 x。

### nx vs nz

金老、金翠莲、赵员外确实有人情与报恩因素，但本轮关系承担的是一个非常具体的现实功能：庇护、身份转换和寺院准入。因此即使关系有情感价值，也不能替代 nx 的权限/通道判断。

### nx vs zx

“鲁达有力量”不能覆盖“这个问题的解决接口在别人手里”。本轮判断对象是安身与身份转换，而不是街头战斗。

---

## 6｜拿掉测试

### 拿掉赵员外

鲁达仍有自己的逃亡方向，但会失去：

- 七宝村庄院庇护；
- 与智真长老的直接关系；
- 檀越身份接口；
- 已购买的度牒；
- 上山请托与费用支持。

因此本轮可命名缺口是：**合法/半合法身份转换与稳定安身通道缺失。**

### 拿掉鲁达的武力

只要上述安身接口仍外置，nx 关系功能仍成立。说明不是“强者突然变弱”才判 nx。

### 拿掉官府通缉

如果鲁达没有追捕压力、可以公开自由选择住所，本轮这条关系通道的重要性会显著下降；但即便他仍主动选择出家，只要寺院收录、度牒与准入仍需赵员外/智真长老接口，仍存在一定 nx 关系功能。通缉压力强化显影，但不是 nx 定义本身。

### 拿掉智真长老的最终收录权

如果鲁达可以自行取得寺院身份，无需任何外部收录节点，则当前 nx 的核心权限证据明显下降。

## 7｜反向测试

### 反向A：持续纯 zx 版本

```text
官府通缉
→ 鲁达不进入任何关系网络
→ 公开闯入官府要求撤榜
→ 以自身权能迫使官府改变处分
```

若现实真围绕他的新增决定接口重排，才会继续高显影 zx。

### 反向B：xn 版本

```text
鲁达自行规划多地藏身
→ 自己伪造身份
→ 自己获取文书
→ 设计多个失败回退节点
→ 按阶段执行
```

则 xn 会明显上升。

### 反向C：x 版本

如果赵庄、度牒和寺院准入本来就属于鲁达自己可以稳定处分的资源，本轮就应优先检查 x，而非 nx。

---

## 8｜同人物跨阶段压力显影

仓库已有窄阶段：

```text
鲁达公开挑衅郑屠
→ 当街直接施力
→ 郑屠与周围人被迫响应
→ 鲁达成为现场更高决定力量
= zx 当前状态
```

本轮：

```text
上述公开暴力造成死亡与官府追捕
→ 公开正面路径对“合法安身”问题失效
→ 鲁达进入赵员外既有关系/权限网络
→ 通过外部节点获得寺院身份通道
= nx 关系功能高显影
```

因此最稳妥的结论不是“鲁达从 zx 变成 nx”，而是：

> **同一人物不同对象与压力下，前段 zx 当前状态和后段 nx 关系功能可以依次高显影。**

这与现行木轴分层原则一致。

---

## 9｜为什么暂不锁严格 zx↔nx 补关系

`zx补nx_补卡` 要求两端各自独立成立，而且拿掉任一端后，另一端仍成立但出现可重复、可命名缺口，补回后缺口可重复改善。

本轮虽能看到：

```text
前段 zx 直接路径
→ 引发法律追捕压力
→ 后段 nx 提供间接安身通道
```

但 zx 与 nx 主要分属连续阶段，并未充分证明“同一阶段两端反复互补、双向改善”的稳定结构。因此只锁**压力切换/显影**，不把前后相邻机械焊成严格补关系。

---

## 10｜第三因素冻结

不参与主判：

- 鲁达是英雄还是罪犯；
- 赵员外是否仗义；
- 金翠莲是否报恩；
- 出家是否真正改变鲁达性格；
- 后续大闹五台山；
- 武力、身份、职业、胜负与主题评价。

本轮只看：**谁掌握当前安身/身份转换的真实接口，鲁达是否沿该既有关系与权限通道推进。**

---

## 11｜结论

- 前段已确认 `zx` 当前状态：沿用既有正式案例，不重复造锚。
- 本段 `nx` 关系功能：`evidence-locked`。
- 本段 `zx`：不作为主判。
- 稳定人物本体：`deferred`。
- 严格 `zx↔nx` 补关系：不锁。
- 本轮没有提出理论正本修改需求。
