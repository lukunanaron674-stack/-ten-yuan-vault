# 《红楼梦》尤三姐｜柳湘莲撤回婚约后的 zx-nx 双边同意接口压力测试

## 1｜事实窗口

第66回此前已经形成一段高置信结构：尤三姐自己择定柳湘莲，贾琏代为说合，柳湘莲交鸳鸯剑为定礼，个人婚姻方向与对方同意接口一度同时成立。

随后柳湘莲因听闻宁国府相关评价，对尤三姐产生怀疑，重新找到贾琏，明确表示不愿继续婚约，并以索回祖传鸳鸯剑作为撤回定礼的现实动作。贾琏虽然反对，仍无法替柳湘莲继续维持婚约同意。

尤三姐在内室听见柳湘莲返悔，立刻判断对方已经不愿以自己为妻。她没有改口接受别的对象，也没有把原来的婚姻方向交回贾琏或家人重新安排，而是直接退回定礼，使原婚约关系在现实上终止。

## 2｜最小结构

```text
前一窗口：
尤三姐自己锁定柳湘莲
= zx 婚姻方向

柳湘莲本人同意 + 贾琏媒介
= nx 双边同意 / 关系接口

本窗口：
柳湘莲撤回同意并索回定礼
→ nx 实现接口失效

但尤三姐没有改成“我不再选择柳湘莲”或“由别人替我重选”
→ zx 原方向没有因此被外部接口自动改写

现实结果：
方向仍在主体
但双边关系无法由主体单方面维持
```

## 3｜zx 判断

正式锁定：

`zx_marriage_direction_persistence: evidence-locked`

本轮不重新证明第65—66回全部 zx 机制，只测试一个窄问题：

> 外部同意接口撤回以后，主体自己的婚姻方向是否因此自动消失？

答案是否定的。

尤三姐听见柳湘莲反悔后，并没有：

- 接受贾琏替自己再选别人；
- 把婚姻对象决定资格交给尤老娘、尤二姐；
- 把“我选择柳湘莲”改写成新的他人方向。

因此 nx 接口失败只能证明现实婚约无法继续，不能倒推主体 zx 方向此前并未存在，或此刻自动被别人取得。

这里继续只锁当前方向 / 状态，不锁稳定人物本体。

## 4｜nx 判断

正式锁定：

`nx_reciprocal_consent_endpoint_withdrawn: evidence-locked`

`nx_realization_channel_failure: evidence-locked`

这里最重要的是：

> 柳湘莲的同意权从始至终都不是尤三姐自己的 x。

前一窗口里，尤三姐必须通过贾琏说合并取得柳湘莲本人同意，才能把个人选择推进成双边婚约。

本窗口里，柳湘莲明确撤回同意，并要求收回定礼。贾琏虽主张“定者定也”，却没有最终替柳湘莲维持同意的现实权限。

因此双边同意接口是真实、可撤回、具有否决性的外部节点。

## 5｜本轮最核心边界

正式排除：

`zx_disappearance_due_to_nx_withdrawal: rejected`

最窄纪律：

> **nx 外部许可 / 同意接口撤回，不等于主体 zx 方向被克掉或消失。**

必须分开：

```text
主体是否仍决定“我要什么”
vs
外部现实是否仍允许“把它做成”
```

尤三姐本例中：

- 第一问仍由主体占据；
- 第二问因柳湘莲撤回同意而失败。

所以是“zx 方向仍在 + nx 实现接口失效”，不是“zx 被换成 nx”。

## 6｜严格 zx↔nx 补关系复核

继续不锁严格补：

`strict_zx_nx_complement_locked: false`

前案已经证明：

- nx 能补 zx 的现实实现缺口；
- 但反方向的 zx→补 nx 缺口不成立。

本轮接口撤回进一步证明：

> 即使 zx 极强，也不能单方面替代双边同意接口。

这说明两端并存和彼此有现实依赖，不自动等于严格双向补。

## 7｜拿掉测试

### 7.1 拿掉柳湘莲撤回同意

保留前一窗口的真实同意与定礼，则婚约继续有效，当前“nx 接口失效”结论消失。

说明本轮压力来自真实外部许可撤回，而不是尤三姐自己改方向。

### 7.2 拿掉尤三姐既有 zx 方向

如果尤三姐原本没有自己锁定柳湘莲，只是家人替她安排，那么柳湘莲撤回婚约只能构成普通外部安排失败，不足以承担“zx 方向仍在但实现接口撤回”的控制。

### 7.3 拿掉贾琏媒介

即便存在另一位等价媒介，只要柳湘莲本人明确撤回同意，婚约仍不能由尤三姐单方面维持。

所以真正关键接口是“对方本人同意”，贾琏只是现实媒介。

## 8｜反向测试

### 8.1 反向成 zx 被克 / 方向移交

```text
柳湘莲撤回同意
→ 尤三姐立刻放弃自己的婚姻对象判断
→ 接受家人改配别人
→ 最终方向转交外部
```

这种结构才可能使当前 zx 显著下降、nx 方向位置上升。

原文不是。

### 8.2 反向成纯 zx 能单独维持关系

```text
柳湘莲撤回同意
→ 尤三姐仍能单方面宣布婚约继续有效
→ 对方无权退出
```

原文同样不是；这也会否定双边关系对象的独立主体性。

### 8.3 反向成 x

如果柳湘莲的同意本来就在尤三姐稳定处分范围，可以由她直接调用或撤销，则才应检查 x。文本完全不支持。

## 9｜最近邻排除

### zx vs x

本轮仍不是“我拥有对方同意权”。尤三姐拥有的是自己的方向，柳湘莲拥有的是自己的同意。

### nx vs xn

贾琏怎样传话、怎样争辩、定礼怎样交还，属于过程细节；尤三姐没有主动建立替代媒介流程，也没有重排多节点结构，因此 xn 不主判。

### nx vs nz

感情专一、受辱、关系价值可以解释情绪与动机，但不能替代“柳湘莲本人拥有可撤回同意权”的木轴事实。

### zx vs xz

关系突然崩解和人生风险可以形成 xz 压力，但不能因此把“主体是否仍占自己方向”改判。

## 10｜关键压力

关键压力只有一个：

> **原本已经真实开启的双边同意接口，被对方本人撤回。**

这比“媒人办事失败”更硬，因为真正的最终关系许可节点自己说了“不”。

本轮因此能测试：

> 主体方向和现实许可是否属于两个可以独立变化的变量。

答案是肯定的。

## 11｜第三因素冻结

冻结：

- 尤三姐的死亡结局与具体方式；
- 柳湘莲之后的后悔与出家；
- 宁国府道德评价；
- 尤三姐是否刚烈、痴情；
- 婚姻伦理与时代制度；
- 贾琏是否讲理。

只问：

1. 尤三姐的婚姻对象方向此前是否由自己锁定？
2. 柳湘莲的同意是否是独立、真实、可撤回的外部接口？
3. 该接口撤回后，尤三姐是否把自己的方向资格交回外部？
4. 现实婚约是否还能由尤三姐单方面继续？

答案分别为：是 / 是 / 否 / 否。

## 12｜结论

本阶段正式锁为：

> **尤三姐面对柳湘莲撤回婚约 = zx 婚姻方向仍保持，但 nx 双边同意 / 实现接口被撤回，现实婚约因此失败；nx 接口失效不能倒推 zx 方向消失。**

最短机制：

```text
我仍决定我要谁
= zx 方向仍在

但对方撤回真实同意
= nx 外部接口失效

所以：
zx 可以保持
但关系现实不能靠 zx 单方面维持
```
