# 《西游记》猪八戒义激猴王：zx-nx 成功影响外部主体伪zx压力测试

## 1. 窄桥段

只取第三十一回：黄袍怪阶段，猪八戒在白龙马建议下到花果山请孙悟空回援；孙悟空起初不愿直接随八戒返回，八戒随后以激将方式使其改变行动并一同回去降妖。不得把后续孙悟空具体降妖方案、沙僧行动或唐僧长期人物本体倒灌到本轮。

## 2. 剧情事实

- **触发**：黄袍怪把唐僧变作老虎，沙僧被擒，白龙马救援失败并受伤，现有解决路径严重受阻；白龙马建议猪八戒去请孙悟空。
- **对象**：孙悟空是否重新进入救援，以及孙悟空本人所掌握的降妖能力。
- **明确动作**：猪八戒到花果山请求孙悟空；孙悟空追问师父灾情后仍有旧怨与离队边界；猪八戒判断“请将不如激将”，捏造黄袍怪辱骂孙悟空的话，刺激孙悟空决定同行。
- **结果**：孙悟空明确表示随猪八戒去降黄袍怪，并与其离开花果山；猪八戒达成“把外部强能力主体重新接回救援链”的目标。

主要文本依据：《西游记》第三十一回《猪八戒义激猴王　孙行者智降妖怪》。原文明确写出白龙马建议请孙悟空、猪八戒求援、孙悟空追问灾情、猪八戒自思“请将不如激将”，以及孙悟空最终决定同行。

## 3. 候选分型

- 纯 zx：**排除**。
- 纯 nx 稳定本体：**排除**。
- nx 当前关系功能 / 外部能力接口：**成立**。
- xn 最近邻：**激将策略存在，但只解释“怎样影响孙悟空”**。
- zx+nx 严格补关系：**不锁**。
- 伪 zx：**成立为反例层**，因为成功改变孙悟空行动不等于猪八戒获得孙悟空的决定权或新增现实权限。

## 4. zx 检查

### 4.1 有无自身方向
有。猪八戒明确要救唐僧，并主动去花果山寻找孙悟空，因此不能把“主动、会想办法”直接当 nx 本体。

### 4.2 有无公开扩权
没有。

猪八戒成功影响孙悟空，但没有取得以下任何新增范围：

1. 没有取得对孙悟空的长期命令权；
2. 没有取得孙悟空神通的稳定处分权；
3. 没有让取经团队以后围绕一个新增的“猪八戒最高决定接口”运行；
4. 孙悟空最终去不去，仍需要孙悟空本人作出决定。

因此不能从“我说服了你，而且你真的照做”直接推出 zx。

**结论：`zx_in_narrow_stage: rejected_as_primary`。**

## 5. nx 检查

### 5.1 为什么不是纯 nx 本体
猪八戒的救师方向并非孙悟空替他生成。他会主动求援、会选择激将策略，也会判断怎样让孙悟空重新进入救援。因此本轮不支持“猪八戒稳定本体 = nx”。

### 5.2 为什么 nx 关系功能成立
关键缺口不是“猪八戒不知道自己想干什么”，而是：

> **解决黄袍怪所需的高强降妖能力和孙悟空是否出手的决定资格，都不属于猪八戒自行处分。**

猪八戒必须通过既有师兄弟 / 取经关系，进入孙悟空这个独立能力节点，并让孙悟空本人决定重新出手。即便采用激将，孙悟空仍然具有真实拒绝窗口。

所以：

- 猪八戒拥有自己的目标；
- 但关键能力与“是否加入”的接口在外部主体；
- 猪八戒只能通过关系、请求、说服去激活该节点。

这符合 nx 的关系功能层，而不是稳定本体层。

**结论：`nx_external_agent_relation_function: evidence-locked`。**

## 6. nx vs xn 最近邻排除

猪八戒明确设计“激将”，所以 `xn` 策略邻近真实存在。

但两者回答的问题不同：

- **xn**：猪八戒怎样设计说服动作，使孙悟空改变选择？
- **nx**：为什么猪八戒必须去影响孙悟空，而不能直接调用孙悟空的能力？

拿掉“激将”这一具体方法，改成恳求、解释、谈条件，只要孙悟空仍是独立能力节点、仍拥有拒绝权，nx 关系功能就不消失。

因此不能用“猪八戒会激将”把外部能力接口的 nx 一笔抹掉。

## 7. 最近邻排除

### nz
师兄弟旧关系、孙悟空对师父的牵挂确实影响行动，但本轮关系的主功能是**接入外部能力与行动主体**。若关系本身才是最终目标，应优先检查 nz；这里的窄目标是救援和降妖。

### x
孙悟空及其神通不属于猪八戒稳定处分的资源，故不能判为 x。

### zx
成功影响他者 ≠ 取得他者权限。没有新增决定范围，故不锁 zx。

### xz
唐僧危机、白龙马受伤、团队失败构成高压条件，但压力只使外部能力缺口显影，不能直接决定 zx/nx。

## 8. 拿掉测试

### 拿掉激将话术
若猪八戒改用恳求或事实说明，只要仍必须经过孙悟空本人同意才能取得其救援能力，nx 仍成立；xn 策略显影下降。

### 拿掉孙悟空的独立拒绝权
若孙悟空本来就是猪八戒可以直接命令、随时调用的稳定下属，则本轮 nx 外部能力接口会明显下降，优先检查 x / 既有授权。

### 拿掉孙悟空这一外部能力节点
若猪八戒自己足以稳定解决黄袍怪，不需要外部主体，则当前 nx 关系功能的主要缺口消失。

### 拿掉旧关系
如果没有师兄弟 / 取经关系这一既有接入通道，猪八戒必须另寻节点；当前这条具体 nx 通道会断裂，但“关键能力外置”仍可能迫使他改走其他 nx 通道。

## 9. 反向测试

### 反向成 zx
猪八戒不只是影响孙悟空，而是在事件中取得此前没有的、可独立调用孙悟空或整个团队的新增决定权，并使现实长期承认该接口。原文没有。

### 反向成 x
孙悟空及其救援能力已经稳定归猪八戒调度，无需本人许可。原文不成立。

### 反向成更纯 nx
猪八戒连“是否救师父、找谁救、下一步做什么”都没有自己的方向，只等待孙悟空替他形成方案并照办。原文同样不成立。

## 10. 第三因素冻结

冻结以下因素后，分类仍成立：

- 猪八戒是否胆小、懒惰、好吃；
- 孙悟空是否强得离谱；
- 黄袍怪最终输赢；
- “义激猴王”标题的道德评价；
- 孙悟空是否仍怀念唐僧；
- 白龙马提出请孙悟空这一建议本身。

只保留：

> **主体自己有救援目标，但关键能力与是否出手的决定权属于另一个独立主体；主体必须通过既有关系和说服接口激活该节点。**

nx 关系功能仍成立；成功说服并不构成 zx 扩权。

## 11. 稳定本体 / 状态 / 功能 / 关系位置

- 稳定人物本体：**不锁**。
- 当前状态：主动求援、主动组织说服。
- 行为功能：接入外部强能力节点。
- 关系位置：孙悟空拥有是否出手的真实独立选择；猪八戒处于请求 / 影响位置。
- 外部压力：唐僧危机、己方连续失利使该外部能力缺口高显影。

不得从这一回反推“猪八戒整体就是 nx”，也不得因激将成功反推“猪八戒这一回就是 zx”。

## 12. 本轮增量

已有材料中，nx 外部接口大量表现为官府权限、资源所有权、组织准入、上级审批或专业方案。本例补充另一种高纯结构：

> **外部独立行动者 / 能力主体本身就是不可直接处分的解决节点。**

并压实一条案例级纪律：

> **影响一个拥有独立选择权的强主体，使其按我的目标行动，不等于我取得了这个主体的决定权。**

是否能把这一边界升级为新的待审议问题，需要至少再跨独立作品形成同型边界；本轮单例不升级理论正本。
