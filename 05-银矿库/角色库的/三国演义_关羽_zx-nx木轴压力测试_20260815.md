# 《三国演义》关羽｜zx↔nx 木轴压力测试

## 结论先行

本轮锁定一个重要的 `nx` 边界反例：

> **“暂时投降、进入他者体系、接受他者供给”不能直接判 `nx`；如果主体仍保留最终方向、否决权和退出条件，且明确规定自己何时离开、最终归向何处，则不能把表面服从当作方向让位。**

第二十五回土山被围时，关羽处于强烈生存与军事压力下。张辽提出暂降曹操以保二嫂、等待刘备消息。关羽没有无条件接受，而是提出三项条件：只降汉不降曹；二嫂待遇与门禁按其要求；一旦知道刘备去向，无论远近立即辞去。曹操最后逐项接受，甚至因关羽要求先退军三十里，让其入城告知二嫂后才完成暂时归附。

因此，这一窄阶段不满足现行纯 `nx` 的关键条件：

```text
不是：
曹操给出最终方向
→ 关羽不改写、不否决
→ 沿曹方安排继续

而是：
曹方提出“降”这一外部方案
→ 关羽重写其合法条件
→ 保留最终归向刘备的方向
→ 明确保留退出权
→ 曹操反过来接受这些条件并调整行动
```

本轮只锁 `nx_rejected_in_narrow_stage`，不把关羽稳定人物本体直接锁成 `zx`，也不把此段强行写成 `zx+nx`。

---

## 1｜原始事实

### 触发

曹操用诈降、诱敌与伏兵切断关羽退路，并攻入下邳。关羽被围于土山，多次突围未果。张辽上山劝降，提出暂降曹操、保全二嫂、等待刘备消息。

### 关羽的明确动作

关羽没有无条件接受，而是先提出三项约束：

1. 只承认归汉，不承认归曹；
2. 二嫂的供给与门禁必须按刘备家属身份处理，曹方人员不得随意入门；
3. 一旦知道刘备去向，无论千里万里，立即辞曹而去。

并明确表示三者缺一便不肯降。

张辽将条件转告曹操，曹操最终接受；关羽又要求曹操先退军，允许自己进城告知二嫂，曹操再次照办并退军三十里。

### 可观察结果

- “暂降”这个外部方案被关羽重新定义；
- 最终归向仍由关羽自己锁定为刘备；
- 退出节点由关羽自己保留；
- 曹操不是单向给出路线，而是必须回应关羽提出的条件并调整军事行动。

---

## 2｜为什么这是伪 nx 反例

现行 `nx` 的核心不是“进入别人体系”，而是：

```text
最终方向或解决通道由别人／关系／现状给出
→ 主体不主动改写
→ 不抢最终决定、否决与重设位置
→ 沿既有方向继续
```

关羽在本段恰好保留了三个与纯 `nx` 相冲突的位置：

### 最终方向仍在自己手里

他不是把长期归属交给曹操，而是提前写明：知道刘备所在即离开。

### 否决权仍在自己手里

三项条件缺一即拒绝投降。说明他不是只能沿曹方方案走，而是仍拥有“这条路是否成立”的否决位置。

### 方案被主体重写

张辽给出的只是“暂降曹操”的大框架；关羽把它改造成“有限、带条件、可退出、最终仍归刘备”的临时关系。

因此：

> **接受一个外部方案，不等于把最终方向交给外部方案。**

---

## 3｜关键压力与第三因素冻结

本段最重要的第三因素是：

```text
军事包围
+ 下邳失守
+ 二嫂安全
+ 生存风险
```

这些因素会强迫主体考虑临时妥协，因此不能由“他投降了”直接推出 `nx`。

现行 nx 准度卡本身要求先拿掉外部强迫、生存威胁、职位与一次危机，再判断主体是否仍不占最终方向。

本例由于强迫因素极高，更应该观察主体在压力中有没有保留自主窗口。结果恰好是：关羽利用剩余谈判窗口主动设条件、保留否决与退出，而不是继续把方向让给曹方。

所以外部压力不是支持 nx 的证据，反而是必须冻结的污染项。

---

## 4｜zx 在本段的位置

本段有 `zx` 局部候选，但本轮不升级成正式主分类。

支持候选的证据：

- 关羽公开提出自己的条件；
- 曹操必须回应这些条件；
- 曹操最后接受条件并退军三十里；
- 关羽在物理劣势下仍使关系规则围绕自己的要求重新调整。

但仍存在两个限制：

1. 他处于强烈 `xz` 式危险收窄环境，临时夺回决定接口可能是压力状态而非稳定 zx；
2. 本段最干净的价值是排除“投降=nx”，不是证明“谈判设条件=zx”。

因此本轮采取窄结论：

```text
nx：在“是否把最终方向交给曹方”这一窄问题上，高置信排除。
zx：局部状态／关系位置候选，不升级人物本体。
```

## 5｜最近邻排除

### nx vs zx

```text
nx：外部路线已经成立，我不占最终决定，只沿着走。
关羽本段：外部路线必须先被我重写；我保留否决和退出，最终归向仍由我定。
```

所以不能以“进入曹营”判 nx。

### nx vs xn

本段不是通过排程、记录、资源配置、流程节点来解决问题，因此不以 `xn` 为主。

“等刘备消息”也不能单判 nx 或 xn；关键是他提前把“得知刘备消息即退出”写成自己的关系条件。

### nx vs x

曹操掌握军队与生杀资源是曹操的 `x` 候选，不等于关羽是 nx。不能把对方资源优势偷换成主体方向让位。

### nx vs xz

关羽确实被军事危险严重压缩路线。若不冻结这一点，很容易把“无路可走所以暂时接受方案”误判成 nx 本体。

## 6｜拿掉测试

### 拿掉“曹操军队包围”

假设没有死亡威胁，只保留曹操邀请关羽加入。

若关羽仍提出：

```text
只接受有限关系
+ 保留最终归向刘备
+ 保留随时按约退出
+ 条件缺一即拒绝
```

则依然不能判纯 nx，因为最终方向和否决权仍在主体手中。

### 拿掉“关羽很能打”

即使不考虑武力，只看谈判结构：他仍在主动重设临时关系的成立条件。故“能打”不是本轮分类来源。

### 拿掉“后来千里走单骑”的结果

即使后续情节未知，只凭本回三项条件，已经能判断他没有把最终长期方向交给曹操。

## 7｜反向测试

若把桥段改写为：

```text
张辽：你暂时归曹，之后是否离开、何时离开，由丞相决定。
关羽：好。
曹操安排住处、家属、去留与最终归属。
关羽不提出条件、不保留否决、不保留退出，只沿曹方安排继续。
```

则 `nx` 会显著上升。

或者：

```text
曹方已经规定完整临时合作规则
→ 关羽只选择进入
→ 不改写任何条件
→ 后续去留也等待曹方决定
```

同样更符合 nx。

现实原文与这两个反向版本明显不同。

## 8｜本轮对木轴的新增价值

此前已经有：

```text
贾迎春：有自主窗口仍不占方向 → nx 正例。
鲁达：自己生成方向并公开压入现实 → zx 正例。
诸葛亮：外部给上位目标，但运行通道由自己建立 → 不是 nx，优先 xn。
```

本轮补入新的最小差异：

```text
关羽：表面进入他者体系，但自己保留最终归向、否决与退出条件
→ “进入别人体系”仍然不等于 nx。
```

因此木轴的 nx 判断现在至少需要连续问三层：

```text
1. 当前方向／通道是不是外部已有？
2. 主体有没有权改写、否决这个方向？
3. 主体有没有保留最终归向与退出权？
```

只有第一项成立，不足以判纯 nx。
