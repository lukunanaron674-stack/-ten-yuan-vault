# 范围
仅截取《水浒传》“智取生辰纲”桥段中：公孙胜说明已经打听出生辰纲从黄泥冈大路经过，晁盖补充白胜这一可用落脚点，随后吴用自行决定如何利用这些事实条件、提出并主张具体智取方案这一段。不得把此桥段倒推为吴用整个人物稳定本体。

# 剧情事实
1. 生辰纲本身、押送对象及其路数并不是吴用凭空生成的信息。公孙胜明确说自己已经打听知其来路，指向黄泥冈大路。
2. 晁盖补充了黄泥冈附近白胜这一既有人际节点，可作为落脚和协作条件。
3. 在获得这些外部事实条件以后，吴用主动判断白胜“自有用处”，决定安身点，并明确表示自己已经安排圈套。
4. 晁盖直接询问“软取还是硬取”时，吴用不是等待别人给方案，而是提出自己的计策；后文又明确说明下药等整套计较由吴用主张。
5. 因此外部主体提供的是关键事实、路径和可用条件；核心解决方案与组织方式则主要由吴用自行形成。

# 木轴判定

## zx
高纯 zx 在本窄阶段不成立。

吴用主动提出计策、获得众人赞同，说明其方案影响力很强，但没有出现其决定范围或现实权限公开扩大到新的层级。其方案被采纳不能自动等同于“自身权能骑到他者之上并形成新增决定接口”。

本段更强的最近邻是 xn：吴用把已有情报、人物、地点和行动放进一套可执行结构中。

## nx
纯 nx 本体明确排除。吴用没有把“如何取得生辰纲”的最终方案资格交给公孙胜、晁盖或刘唐。

有限 nx 关系功能是否成立，仍不锁定。

### 支持 nx 的理由
- 生辰纲路数和白胜这一关键条件真实来自外部信息节点。
- 吴用的方案成立依赖这些外部事实条件；拿掉它们，原方案无法按原样运作。

### 反对 nx 的理由
- 公孙胜和晁盖提供的是事实/条件，不是必须服从的最终方向、权限、资源处分权或完整解决方案。
- 吴用在得到条件后自行组织“用谁、在哪里、怎样取、怎样下药、怎样伪装”的方案。
- 如果凡是行动前依赖别人提供关键事实都算 nx，那么侦察、情报汇报、天气数据、医生检查结果等都会被过度 nx 化。

因此本轮继续锁定最小分歧点：

> nx 的“外部解决通道”是否包含“只提供关键事实/条件、但不占最终方案与行动权”的信息节点？

现行正本没有足够直接规则把该分歧压到 5% 以下，因此维持 candidate/deferred。

# 最近邻排除

## nx vs xn
这是本轮最强最近邻。

公孙胜告诉吴用路数、晁盖告诉吴用白胜这一条件；吴用随后把这些输入组织成具体圈套和执行方式。

因此：
- 外部信息从哪里来，是信息来源问题。
- 谁把信息组织成计划、流程和行动节点，是 xn 问题。
- 不能因为信息由别人提供，就把吴用后续的主动组织全部算成 nx。

## nx vs x
白胜本人、黄泥冈道路及生辰纲押送权都不归吴用处分。本轮不锁 x；但“可用条件存在”也不等于“权限借用”。

## zx vs 影响力
晁盖等人听到计策后高度认可，不能直接证明吴用的现实决定范围扩大。意见被采纳、方案高明与 zx 扩权必须分开。

# 拿掉测试
1. 拿掉公孙胜这个具体人物，只保留“可靠情报源提供生辰纲路线”，只要吴用仍自行形成智取方案，纯 nx 仍不成立。
2. 拿掉白胜这个具体人，原方案需要调整，但吴用仍可基于别的落脚/协作条件重新组织方案；因此白胜是条件节点，不自动等于外部解决权。
3. 拿掉外部路线情报，吴用会失去关键事实输入，现有方案无法原样落地；这证明信息重要，但不能单独证明最终解决通道外置。
4. 拿掉吴用的方案组织，只剩“生辰纲从黄泥冈经过”和“白胜可用”，事情不会自动完成，说明事实输入与完整解决方案不能直接等同。

# 反向测试
1. 若公孙胜不仅提供路线，还直接给出下药、伪装、节点和执行方式，而吴用主要照该方案推进，则 nx 专业/解决通道证据显著上升。
2. 若公孙胜或晁盖还掌握某个吴用必须请求才可使用的真实许可、资源处分或行动否决权，则 nx 权限/资源通道更清楚。
3. 若吴用通过此事取得原先没有的正式组织处分权，并让众人以后必须围绕其新增权力接口运行，才应进一步检查 zx。

# 第三因素冻结
冻结“智多星”称号、吴用聪明程度、晁盖身份、最终是否成功、杨志强弱、下药技巧、七星聚义主题及后续梁山经历，只保留：事实信息由谁提供、方案由谁形成、行动接口归谁、是否发生权限扩张。结论仍为“外部事实信息是否计入 nx 解决通道存在真实分叉”。

# 跨作品同边界
当前已有三个独立作品出现同一边界：

1. 《三国演义》曹操官渡接许攸情报：外部提供关键敌情，曹操已有方向，最终军令与行动权仍在自己。
2. 《西游记》孙悟空狮驼岭听长庚示警：外部提供危险事实，悟空自行组织后续侦察与行动。
