# 《红楼梦》刘姥姥二进荣国府：zx-nx 回礼探亲伪 nx 压力测试

## 0. 结论先行

本轮只截取第三十九回“二进荣国府”的**入府动机至贾母留住**这一窄阶段，不把第四十二回离府时获得的大量馈赠倒灌回最初动机。

结论：

```text
一进：家计困难
→ 主动寻找荣府旧亲关系
→ 关键资源与许可在荣府
→ 沿周瑞家的—平儿—王熙凤权限网络求助
= nx 关系功能高显影

二进入府：丰收后带头茬瓜果菜蔬来请安、看望、回礼
→ 没有先提出资源缺口
→ 没有以取得钱财/许可为入府方向
→ 反而由贾母主动留住、后续赠礼
= 本窄阶段 nx 关系功能不应重复锁定
```

本轮锁的是：**同一个人再次进入同一关系网络，并不因为“又去了荣府”就自动还是 nx。必须检查这一次到底有没有一个外置的关键解决通道，以及主体是否正沿该通道求人办事。**

## 1. 剧情事实

### 触发

刘姥姥第二次进荣国府时，家中当年收成较好。她带来枣子、倭瓜、野菜等田间物产，并明确说明：今年粮食、瓜果菜蔬丰盛，头一起摘下来的没有卖，特意留下来孝敬姑奶奶、姑娘们尝鲜。

因此本次入府的文本首要动机不是：

```text
家里又缺钱
→ 需要荣府解决
```

而是：

```text
此前受过照顾
+ 当年有了新鲜收成
→ 带自家能拿出的东西来请安、看望、回礼
```

### 入府后的方向变化

刘姥姥原本并未以“住大观园、拿钱、拿米”为既定求助目标。贾母听说她来了，又喜欢乡间新鲜瓜菜，主动把她留下住一两日，并让她讲乡村见闻。

也就是说，后续“留住、游园、宴饮、赠物”大量由荣府一方主动展开。

### 离府馈赠不能倒推初始 nx

到第四十二回离府时，王夫人、王熙凤、平儿、贾母、鸳鸯等确实给了刘姥姥银钱、米、果品、衣物、药物等大量东西。

但这里必须区分：

```text
获得别人主动赠与
≠
一开始就是沿外部权限通道求人取得资源
```

如果不分阶段，会把“最后拿到了东西”反向误写成“从一开始就是 nx 求助”。本轮明确禁止这种结果倒推。

## 2. nx 判断

结论：`nx_relation_function_in_entry_stage: rejected_as_primary`。

现行 nx 关系功能要求：

```text
自己的权能不能直接解决问题
→ 关键权限/资源/解决通道在别人手里
→ 主体进入既有关系、身份与权限网络
→ 请求、借力、托关系
→ 沿该外部通道把事办成
```

“一进”完全符合，所以仓库已经锁为高纯 nx 关系功能正例。

但“二进”的入府首要结构不同：

- 没有先提出新的资源缺口；
- 没有把“求钱、求许可、求救兵”作为明确方向；
- 她自己带着礼物进入关系；
- 荣府后续留客和赠物大量是对方主动发起。

因此：

> **进入旧关系网络本身，不等于 nx。**

只有当这个关系网络在当前事件里承担“主体必须借用的外部解决通道”时，才足以锁 nx 关系功能。

## 3. zx 判断

结论：`zx_in_narrow_stage: rejected_as_primary`。

刘姥姥二进时比一进自然、熟络，能说会道，也让贾母等人十分开心；但这些都不是 zx。

本段没有出现：

- 刘姥姥的权能公开扩大；
- 荣府秩序被她迫使重排；
- 她取得新的决定范围；
- 她压过原有权限主体。

所以：

```text
主动来往
+ 会应酬
+ 受到欢迎
≠ zx
```

## 4. 最近邻排除

### nx vs nz

现行 nx 准度卡已经给出边界：

```text
nx：不占方向，沿外部通道推进。
nz：关系可停靠、可退出、可回返，但不必交出判断资格。
```

本轮不正式修改水轴理论，也不锁“刘姥姥二进 = nz 本体”；但从最近邻看，二进的入府行为明显更接近：

```text
维系已有关系
+ 回应此前帮助
+ 带礼物探访
+ 关系本身具有持续价值
```

而不是：

```text
我有一个解决不了的问题
→ 必须借荣府权限把问题办成
```

因此只记录：`nz_relation_maintenance_neighbor: present_not_formally_locked`。

### nx vs n

荣府主动接待、留客、赠物可以体现对方的承接，但这不是刘姥姥自身 nx 的证据。不能跨主体偷判。

### nx vs xn

刘姥姥会选择时机、带合适乡间物产，但核心不是搭计划、排节点或持续组织流程，因此 xn 不主判。

### nx vs x

瓜果菜蔬是她自己可处分的资源；但荣府的银钱、米、衣物仍不属于她。只是本轮入府不是围绕“借荣府资源”启动，所以不能仅凭资源归属反推 nx。

## 5. 拿掉测试

### 拿掉后续大额馈赠

如果第四十二回荣府最终什么钱都没给，只保留：

```text
刘姥姥因丰收带新鲜瓜菜来请安、回礼
→ 贾母主动留她住两天
```

本轮“二进入府不以 nx 求助为主”的结论仍成立。

说明后续获赠不是本轮分类支柱。

### 拿掉贫富差距

即使双方经济差距仍很大，只要这次没有明确把关系当成解决某个资源缺口的通道，不能因“穷人访问富人”直接锁 nx。

### 拿掉旧恩

如果她与荣府没有此前关系，仅携礼物陌生拜访，那么“回礼/关系维系”证据会下降；但仍不能因此自动转成 nx，必须另外找到明确的外部解决目标。

## 6. 反向测试

### 反向成高纯 nx

若第二次进府前文本明确出现：

```text
家中又遇到资源困难
→ 刘姥姥决定再次去荣府求钱/求粮
→ 通过周瑞家的等权限接口请求
→ 最终由凤姐/王夫人裁度
```

那么会重新接近“一进”的 nx 结构。

### 反向成 zx

若刘姥姥进入荣府后以自己的公开权能迫使荣府改变资源处分或家内安排，并扩大自己的决定范围，才检查 zx。

原作没有。

## 7. 第三因素冻结

冻结：

- 刘姥姥贫穷；
- 年龄；
- 乡村身份；
- 她善于逗趣；
- 贾母喜欢她；
- 大观园宴饮的喜剧性；
- 最后拿到多少银子和物品；
- 荣府是否“怜贫惜老”。

只检查：

```text
本次入府的初始方向是什么？
有没有一个必须借用的外部解决通道？
她是否以求人办事为当前主路径？
后续馈赠是她主动求取，还是对方主动展开？
```

结论仍然是：二进入府这一窄阶段不应重复锁 nx 关系功能。

## 8. 与“一进”的同人物最小差异

```text
【一进】
生活困难
→ 明确要解决家计
→ 荣府资源与许可在外部
→ 主动走旧亲/周瑞家/凤姐权限网络
= nx 关系功能

【二进】
当年丰收
→ 留下头茬瓜果菜蔬
→ 带来请安、看望、回礼
→ 荣府主动留客并馈赠
= 入府阶段伪 nx
```

因此可以锁一条案例级纪律：

> **同一段关系网络，不会因为过去曾承担过 nx 求助通道，就永久变成 nx。每次都要重新检查当前事件里关系究竟是在“解决外部缺口”，还是“维系关系本身”。**

## 9. 结论

本轮不锁人物稳定本体，不锁严格 `zx↔nx` 补关系。

正式结论：

```text
刘姥姥二进荣国府的“入府动机—被留住”阶段
= 伪 nx 反例

获得馈赠
≠ 自动说明此前沿外部权限求助

进入旧关系
≠ 自动 nx

当前关系若主要用于回礼、探访与维系
→ 应排除 nx 关系功能的关键词直判
→ 最近邻可检查 nz，但本轮不跨轴正式锁定
```
