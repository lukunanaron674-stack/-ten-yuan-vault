# 水浒传｜呼延灼征梁山｜zx-nx 分层授权压力测试

## 结论摘要

本轮锁定第二个独立作品中的“分层授权”结构：**主体在局部战役层拥有真实、可独立调用的统辖权限，但最高战略任务与目标仍由外部权力接口给定。**

高俅明确要求呼延灼等回州拣选精锐军马、约会起程、收剿梁山泊；这个“征剿梁山”的最高任务方向不是呼延灼自己建立。呼延灼接受任务并沿朝廷／殿帅府给出的合法军令方向推进，因此在“最高战略任务来源”这一对象层，出现 `nx` 关系位置。

但进入战役运行层以后，呼延灼并非薛宝钗式只能照看、遇事仍须逐项回报的弱代理。他能够举保韩滔、彭玘为先锋，提出甲仗不足问题，获准从甲仗库选领装备；回州后调集三路兵马、分配甲仗，打造连环铁铠，并把三军组织为前军、中军、后军投入战役。战场中连环马的布置与本部军马的调度也由其实际统辖。因此局部存在真实 `x` 权限邻近，同时战役组织方式明显高显影 `xn`。

本轮不锁 `zx`。虽然呼延灼获得并使用了战役统辖权限，但在所截取的阶段，最强因果仍是“上级设定征剿目标并授予战役权限 → 呼延灼承接并在权限内组织运行”。这足以证明局部实权，却不足以证明呼延灼以自身权能突破原权限边界、迫使更高秩序围绕自己新增的决定中心重排。**真实授权不等于授权发生后自动成为 zx；zx 仍须另证决定范围的公开扩张。**

本轮不锁“呼延灼稳定人物本体 = nx/x/xn/zx”，也不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实、触发、对象、动作、结果

### 触发

梁山势力扩大后，高俅会同枢密院筹划征剿，要求呼延灼等领军收剿梁山泊。

### 最高方向与权限层级

```text
最高战略目标：征剿梁山泊
来源：高俅／朝廷军令接口

局部战役统辖：
- 举保先锋
- 调集三路兵马
- 分配甲仗与战马
- 编排前中后三军
- 布置连环马与本部作战
主体：呼延灼
```

### 呼延灼的明确动作

1. 在高俅询问先锋人选时，呼延灼主动举保韩滔、彭玘作为正副先锋。
2. 高俅明确要求三人回州拣选精锐马步军，约会起程，收剿梁山泊。
3. 呼延灼指出衣甲不足、可能误期，向高俅提出资源缺口。
4. 高俅允许其进入京师甲仗库“不拘数目”选取所需衣甲军器，并另拨战马。
5. 呼延灼实际选领铁甲、马甲、头盔、长枪、滚刀、弓箭、火炮等军器。
6. 回州后，呼延灼调韩滔、彭玘各起本州军马会合，并把装备分配到三军，打造连环铁铠。
7. 出军时，呼延灼把三军编排为韩滔前军、自己中军主将、彭玘后军催督，率军攻梁山。
8. 交战中，其本部连环马军构成关键作战接口，并由呼延灼收转、下寨、继续组织战役。

### 可观察结果

- “征剿谁”由外部最高军令给定；
- “战役内部怎样配置先锋、兵马、装备、阵型与行动”存在明显由呼延灼直接调用的局部权限；
- 呼延灼不是逐项等待高俅批准每一个战术动作；
- 但也没有证据显示他获得了重设最高政治／战略目标的资格。

## 2｜nx：锁在最高战略任务关系位置

本轮不能把“奉命打仗”三个字直接等同于 nx，必须限定对象层。

呼延灼自己有军事判断，也会主动提出先锋、装备和部署方案，所以不支持“纯 nx 本体＝没主见”。

但在本轮最高对象层：

```text
征剿梁山泊
↓
由高俅／朝廷军令给定
↓
呼延灼接受任务
↓
没有把“是否征剿、征剿对象是否改变”改成自己的最终方向
↓
沿外部合法军令接口继续
= nx 战略关系位置
```

因此锁定：

- `nx_strategic_mission_relation_stage: evidence-locked`
- `pure_nx_essence: rejected`

这里的 nx 不是普通“听话”，而是**最高任务方向与合法军事接口仍位于外部权力体系，呼延灼在该层不占最终重设位置。**

---

## 3｜局部 x：战役统辖权真实可调用

呼延灼并非只有一个空头职位。

在战役内部，他可以实际：

- 提出并使用先锋人选；
- 调集三路军马；
- 分配上级授权领取的甲仗与战马；
- 编排前中后三军；
- 组织、使用连环马军；
- 收军、下寨与继续战役运行。

因此：

- `x_local_campaign_command_neighbor: evidence-locked`

此处的 `x` 只指**交接后已经归其处分的局部战役接口**，不外推为“最高战略方向也归呼延灼”。

本轮进一步支持：

> **一个主体可以在高层方向上处于 nx 关系位置，同时在较低对象层真实拥有 x 权限。**

---

## 4｜xn：局部组织高显影，但不能吞掉 nx

呼延灼的战役行为中存在大量主动组织：

```text
选先锋
→ 补资源
→ 调三路兵马
→ 分配装备
→ 编前中后三军
→ 打造／运用连环马
→ 组织战役推进
```

这些行为优先检查 `xn`，因为主体在主动搭建运行结构、人员配置和战术组织。

但 `xn` 不能反向抹掉战略层 nx：

```text
xn：解释“拿到任务后，战役怎么组织”。
nx：解释“为什么最高征剿目标不是呼延灼自己重设，而是沿外部军令继续”。
```

对象层不同，不冲突。

---

## 5｜zx：授权与统辖不自动等于扩权

本轮最危险的误判是：

```text
呼延灼当主将
→ 能调很多兵
→ 战场上别人听他
→ zx
```

这不满足现行 zx 的硬门。

zx 需要进一步证明：

1. 主体自身权能成为新的现实决定来源；
2. 原有决定边界被主体公开向外推大；
3. 他者或秩序不得不围绕这一新增边界重新反应；
4. 主体决定位置或范围真实上升，而不是只在已获授权内正常运行。

本轮文本更清楚地显示：

```text
高俅给征剿目标
+ 高俅／军令系统提供战役合法性与资源入口
→ 呼延灼获得局部统辖空间
→ 在该空间内主动组织
```

所以本轮锁：

- `zx_in_delegated_campaign_stage: rejected_as_primary`
- `delegated_real_authority_not_automatic_zx: evidence-locked`

若另一个时间片显示呼延灼突破原任务边界、取得原本不属于自己的更高军政处分权，并迫使朝廷或更高军令体系承认其新增位置，应另切阶段检查 zx，不能倒灌到本轮。

---

## 6｜关键压力

本轮关键压力是**不同层级的权限归属不一致**：

```text
最高战略方向：外部
战役合法资源入口：外部授予
战役内部统辖：呼延灼真实掌握
运行组织：呼延灼主动建立
```

若只问“呼延灼有没有权”，答案会失真。必须继续问：

> **在哪一层有权？哪一层不能重设？哪一层只是授权后正常调用？**

## 7｜拿掉测试

### 拿掉“名将／呼延赞之后”身份

只保留：

```text
上级给征剿目标
+ 主体获得局部战役统辖权
+ 主体能独立组织战役内部运行
```

仍得到“战略层 nx + 局部 x/xn”结构。血统、威名不参与判定。

### 拿掉战斗胜负

即使呼延灼最终没有击败梁山，只要最高目标仍来自外部、局部战役权限仍真实归他调用，分类不变。胜负不是 zx/nx 判据。

### 拿掉“连环马”这个著名战术标签

只要呼延灼仍能独立配置先锋、三军、装备与局部作战事务，局部 x/xn 仍成立。不能把一个著名阵法当成唯一证据。

### 拿掉局部统辖权

如果高俅把先锋、兵马、装备、阵型、进退都逐项写死，呼延灼只能逐条照办，则局部 `x/xn` 会显著下降，整个案例会更接近覆盖面更广的 nx 执行关系。

---

## 8｜反向测试

### 反向成宝钗式弱代理 nx

如果呼延灼只能“照看军队”，遇到先锋、装备、阵型或进退问题都必须回报高俅等待逐项批准，那么局部 x 消失，nx 会覆盖更多对象层。

### 反向成周瑜式 zx 上升

如果呼延灼获得局部军权后，进一步公开取得原来没有的更高战略处分范围，使高俅／朝廷的原有决定边界必须围绕他重新调整，并且新增权限可由其独立调用，则 zx 上升。

### 反向成纯 x/xn

如果“征不征梁山、打谁、最高战略目标如何改变”也长期归呼延灼独立处分，上级不再保留最高任务边界，那么战略层 nx 会退出，应优先检查 x/xn/zx。

## 9｜最近邻排除

### nx vs xn

```text
nx：最高征剿目标由外部给定，主体沿其合法方向推进。
xn：主体在既定任务下主动搭建先锋、三军、装备、阵型和战役运行结构。
```

本轮两者分属不同对象层，因此不能因为呼延灼很会组织就说“既然有 xn 就没有 nx”。

### nx vs x

```text
最高战略目标：外部 → nx关系位置
局部战役统辖：授权后真实归呼延灼 → x邻近
```

这是本轮最重要的分层。

### x vs zx

```text
x：授权完成后，这一块局部战役权限已经归我正常调用。
zx：我的决定边界正在向原先不属于我的范围公开扩大。
```

本轮只有前者硬证据，后者不足。

### 强／能打／主将身份冻结

呼延灼的武艺、战绩、主将身份、御赐战马、连环马威力都不能单独成立 zx。若冻结这些戏剧性因素，权限层级结构仍然清晰。

当前独立作品支持数：`2`。

尚未达到跨至少 `3` 个独立作品门槛，因此：

- 不创建新的待审议问题；

- 不修改 zx/nx 信息卡；
- 不修改准度卡；
- 不修改 `zx补nx_补卡`。
