# 《西游记》小白龙鹰愁涧归队｜zx↔nx 纯 nx 功能压力测试

## 0｜本轮结论

本轮锁定的是**小白龙在鹰愁涧被观音重新接入取经队伍之后的当前行为功能与关系位置**，不是锁定“小白龙整个人物稳定本体=nx”。

最窄结论：

```text
取经方向、角色用途与行动通道均已由外部建立
→ 小白龙不争夺西行目标的最终重设权
→ 接受观音“为唐僧做脚力”的既定安排
→ 化马、承载唐僧，沿取经路线继续西行
= 高纯度 nx 当前行为 / 关系位置
```

它是“纯 nx 功能正例”，不是“稳定纯 nx 人物本体正例”。后者按 nx 准度卡必须有跨场景复现，本桥段单独不足。

## 1｜剧情事实

### 触发

孙悟空与鹰愁涧小龙交战后，从山神土地处得知：观音此前已救下这条玉龙，并把他留在此地等候取经人。金头揭谛随后请来观音。

### 对象

- 主体：小白龙 / 玉龙三太子
- 上位方向与权限主体：观音
- 被服务对象：唐僧
- 已存在的任务通道：西天取经队伍、唐僧脚力位置

### 明确动作

观音说明自己曾向玉帝讨下小龙，目的就是让他“与唐僧做个脚力”；小龙本人也说明自己一直在此等候取经人。辨明孙悟空正是取经人大徒弟后，小龙接受观音处置。观音将其化为白马，并再次要求其用心还业障、功成取正果；小龙“心心领诺”。随后悟空将龙马领给唐僧，唐僧骑上龙马，队伍继续向西。

### 结果

小白龙正式进入已经存在的取经结构，承担脚力角色；西行方向、服务对象和整体任务均不是由小白龙重新建立。

## 2｜zx / nx 四类候选判断

### 纯 zx

**reject。**

归队后的窄阶段里没有看到小白龙以自身权能重新定义取经方向，也没有公开扩大自己的决定范围，使取经秩序围绕自己的力量重新组织。

### 纯 nx

**accept，但仅锁当前行为功能 / 关系位置。**

满足：

```text
方向已存在：西天取经
角色已存在：唐僧脚力
权限接口已存在：观音安排 + 取经队伍
主体不重设方向
主体沿既有角色与路线续接
```

### zx+nx

**reject（本桥段）。**

本段没有足够独立 zx 端证据。不能因为小龙此前能战、敢与孙悟空交手，就把那一段力量表现偷接到“归队化马”阶段，拼出 zx+nx。

### 压力显影 / 伪对子

本例主要价值不是压力切换，而是给“纯 nx 当前功能”提供一个低歧义正例，并同时阻止“承接任务=人物稳定 nx”的过度升级。

## 3｜木轴核心变量检查

L1 v1.6 的木轴变量为：

```text
最终方向与作用权来源
zx：自身生成并占据方向
nx：不占最终方向、沿既有通道续接
```

小白龙归队后的该变量非常清楚：

- “去不去西天取经”不是他建立的问题框架；
- “为谁服务”已经由观音指定为唐僧；
- “以何身份进入结构”已经给定为脚力；
- 他没有重设这些端点，而是接受并续接。

因此本段更靠 nx，而非 zx。

## 4｜最近邻排除

### nx vs xn

本段不优先 xn。小白龙没有在接到目标后主动搭建计划、排程、节点、资源分配或新的运行流程；核心动作是接受既定角色并沿路线前进。

### nx vs x

小白龙不掌握整个取经任务、唐僧、路线许可或观音权限；不存在“对象与调用边界归我”的证据。

### nx vs zx

战斗能力不是 zx 的充分条件。归队阶段没有权能扩大、夺位或迫使整体取经秩序围绕小白龙重新反应。

### nx vs nz

接受观音安排和服务唐僧的核心证据是方向与角色通道，而非“关系可停靠、可退出、可回返”的情感关系变量。

### nx vs n

“驮唐僧”从字面很像承载，但十元不能按动词直判。此处研究变量是：小白龙是否占据最终任务方向。作为木轴案例，最强证据仍是沿外部既定取经方向与角色通道续接；不由物理承载动作反推 n。

## 5｜拿掉测试

### 拿掉“观音”这个具体人物

若换成另一个真实掌握取经角色授权的上位接口，只要“西行目标 + 唐僧脚力位置”仍已外部建立，而小白龙仅接受并续接，nx 结构仍成立。

### 拿掉“化成白马”的视觉形式

即使不变马，只要小白龙接受已经设定的护送 / 脚力职责，沿取经队伍的既有方向前进，nx 仍成立。因此“马”不是判据。

### 拿掉“赎罪 / 正果”奖惩压力

即便不强调还业障和最终正果，只保留“小白龙确认取经人后，自愿接入已存在的取经任务与角色”，当前 nx 行为仍成立。奖惩解释动机强度，不构成 nx 本身。

### 拿掉此前与孙悟空战斗

归队后的 nx 结构完全不受影响；这进一步说明不能把此前战斗能力借来制造 zx+nx。

## 6｜反向测试

若改写为：

```text
小白龙确认取经人后
→ 主动否决观音原方案
→ 自己重新决定取经路线、服务对象或队伍运行方式
→ 要求唐僧与孙悟空围绕自己的新方向重组
```

则 nx 会显著下降，并应检查 zx / xn / x。

若只是：

```text
观音给定目标
→ 小白龙主动设计每天路线、补给、节点、轮换与风险流程
```

则不能继续写成纯 nx，应优先检查 xn。

## 7｜第三因素冻结

冻结以下因素后，结论不变：

- 他是龙王之子；
- 他会战斗；
- 他曾犯天条；
- 观音救过他；
- 最终能否取得正果；
- “白马”这一视觉身份；
- 唐僧是师父还是乘骑者。

只保留：

```text
谁给最终方向？
谁给角色接口？
主体有没有重设？
主体是否沿既有通道继续？
```

仍得到 nx。

## 8｜对象层分离

- **稳定人物本体：不锁。** 单一桥段不足以满足 nx 准度卡的跨阶段 / 跨场景复现要求。
- **当前状态：nx 高显影。** 进入取经队伍既定安排。
- **行为功能：nx 高显影。** 接受角色、沿既定路线续接。
- **关系位置：nx 高显影。** 任务方向和角色授权位于观音 / 取经结构，不在小白龙。
- **外部压力：** 赎罪、正果与观音救命恩情可强化接受动机，但冻结后当前 nx 结构仍可成立，因此不以强迫替代十元判断。

## 10｜本轮研究价值

当前案例库已有大量“求人 / 借权 / 伪 nx / zx+nx”边界材料，而纯 nx 端容易被误缩成“性格没主见”。本例补充另一种更干净的功能形态：

> **主体可以有能力、甚至此前很能战；只要当前问题的最终方向、角色接口和运行通道均已由外部建立，而主体不重设、只沿既有结构续接，这一段仍可以是高纯度 nx 行为 / 关系位置。**

同时保留红线：

> **一次高纯度 nx 行为，不足以把整个人物锁成稳定纯 nx 本体。**
