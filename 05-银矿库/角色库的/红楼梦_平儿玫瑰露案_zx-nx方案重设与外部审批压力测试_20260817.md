# 《红楼梦》平儿玫瑰露案｜方案重设与外部审批压力测试

## 结论先行

本轮锁定：

> **主体真实重设关键处置方案，只会使“方案运行层”的 nx 下降并使 xn 上升；如果新方案最后仍必须经过另一个真正掌握最高处分权的主体批准，那么“最终审批权限层”的 nx 关系位置仍可独立成立。**

平儿不是机械执行凤姐原令。凤姐先给出“柳家母女各打四十板、柳家的撵出、五儿交庄子或卖配”的严厉处分；平儿随后暂缓、复查证据、组织替代说法并形成从轻结案路线。因此在“如何处理案件”这一方案层，平儿拥有真实重设行为，`xn` 高显影。

但平儿没有直接宣布原处分作废。她先明确表示“等明儿我回了奶奶，再做道理”；形成新方案后也再次回凤姐说明，凤姐起初仍主张继续严查，直到被平儿劝服，明确让平儿自行发放，平儿才正式放人结案。因此在“新方案是否能正式替代凤姐原处分”这一最终批准对象层，关键权限仍在凤姐，锁 `nx` 关系位置。

这不是 `zx` 扩权：平儿成功说服凤姐，不等于家内最高处分权转移给平儿，也没有证据表明以后同等级事件可以绕开凤姐由平儿独立裁决。

本轮不锁平儿稳定人物本体，不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实

### 原处分与触发

柳五儿因玫瑰露、茯苓霜等物被怀疑盗窃，事情经探春转到平儿回凤姐。凤姐听后立即给出严厉处分：

```text
柳家的：打四十板、撵出、永不许进二门
五儿：打四十板、交庄子，或卖或配人
```

平儿最初把命令传出，但五儿随后跪诉芳官赠露、舅舅得霜等来源。

### 平儿没有按原令直接结案

平儿听出案情存在重大疑点后，没有立即把凤姐原处分执行到底，而是：

1. 暂缓最终处分，把五儿先交上夜人看守；
2. 明确表示第二天查问芳官后再判断；
3. 主动访问袭人、芳官等，核实玫瑰露来源；
4. 继续处理茯苓霜、彩云与宝玉愿意揽责等相互牵连问题；
5. 考虑若彻查会牵连赵姨娘、探春等人的关系后果；
6. 最终组织出“缩小追查、避免扩大牵连、从轻放人”的替代结案方式。

这已经超过“外部方案预留的普通执行自由度”。原方案的关键处分结果本身被平儿重设。

### 新方案没有由平儿单方面生效

平儿在第一次暂缓时就说：

```text
等明儿我回了奶奶，再做道理
```

形成替代方案后，她仍回到凤姐处，把案情按新的说明汇报。

凤姐并未自动同意。她起初仍明确主张继续细查，甚至提出让相关丫头在太阳下跪磁瓦、断茶饭逼供，并认为柳家的即使不是盗贼也可革出不用。

平儿随后继续劝凤姐“得放手时须放手”，指出不必为小事结怨、过度操劳。凤姐最后才改变原处分，明确让平儿去发放处理。

平儿在获得这一批准后，才出去逐一放人结案。

### 最终结果

```text
凤姐原严厉处分
↓
平儿暂缓
↓
平儿复查并重设从轻方案
↓
新方案回到凤姐最终审批
↓
凤姐先坚持严查
↓
平儿说服凤姐
↓
凤姐批准放手
↓
平儿正式发放结案
```

## 2｜nx 判断

### 纯 nx 本体：排除

平儿拥有低成本重设窗口，并且真实使用了。

她没有把凤姐原命令机械执行到底，而是在新证据出现后主动改变调查和结案结构。因此不能由“她是凤姐助手”“最后还要回凤姐”反推稳定纯 nx 本体。

`stable_essence_locked: false`

### 最终审批权限层：成立

但在“谁有权让新方案正式覆盖原处分”这一对象层，凤姐仍是有效的最终批准节点。

关键反证是：

- 平儿自己明确说要再回凤姐；
- 凤姐第一次听新说法后并非自动点头，而是继续主张严查；
- 只有凤姐最终明确放权后，平儿才正式发放。

因此锁：

`nx_final_approval_relation_position: evidence-locked`

这里的 nx 不是“方向全部由凤姐给出”，而是**关键处分批准权仍在外部，平儿必须沿这个真实权限接口让自己的替代方案生效**。

## 3｜xn 最近邻

本轮最强最近邻是 `xn`。

平儿主动：

- 暂缓原处分；
- 补充调查；
- 核对多个证人和物证来源；
- 重新组织责任叙事；
- 衡量继续深挖会造成的关系后果；
- 形成新的从轻结案流程。

因此在“怎样处理这件案子”这一运行/方案层，锁：

`xn_plan_rewrite_neighbor: evidence-locked`

这与现行 nx 准度卡一致：外部目标或权限存在，不会自动覆盖主体自行搭建、重设的下位流程。

## 4｜zx 检查

本段很容易因为“平儿把凤姐说服了”“最后按平儿意见办”误判 `zx`。

但现行 zx 需要：

```text
主体自身权能公开进入现实
+ 他者/秩序围绕其力量重新反应
+ 主体决定范围或凌驾位置真实上升
```

本案没有证明：

- 凤姐的最高家内处分权转移给平儿；
- 平儿取得以后可独立调用的新增裁决范围；
- 贾府同类案件以后稳定围绕平儿的新增权力接口运行。

因此：

`zx_in_narrow_stage: rejected_as_primary`

> **说服掌权者改变决定，不等于自己成为新的掌权者。**

## 5｜关键压力

本轮至少有四层压力：

1. 凤姐已经下达严厉处分，形成既有上位命令；
2. 五儿被软禁，案件有即时处置压力；
3. 玫瑰露、茯苓霜来源牵连多人，事实结构复杂；
4. 若继续追查会牵动赵姨娘、探春等关系位置。

这些压力解释平儿为什么需要重设处理方式，但不能直接判任何十元。

## 6｜拿掉测试

### 拿掉“平儿贤惠、善良”的人物评价

只保留：

```text
上级已下严厉处分
→ 主体发现证据问题
→ 暂缓并重设方案
→ 新方案仍回上级批准
→ 上级批准后才正式生效
```

`xn方案层 + nx最终审批层`仍成立。

### 拿掉宝玉替人揽责

即使没有宝玉主动承担，平儿仍已经发现柳五儿案存在证据疑点，并主动复查。具体替代叙事会变化，但“方案重设 + 外部批准”的结构仍在。

### 拿掉凤姐最终批准

如果凤姐坚持原处分不改，平儿按当前权限结构不能仅凭自己的替代方案合法完成正式结案。

这说明外部批准不是装饰性签字，而是具有真实否决能力的权限节点。

### 拿掉平儿的重设

如果平儿只把凤姐原令原样执行，则 `xn` 方案重设消失，本桥段会更接近普通 `nx` 授权执行。

## 7｜反向测试

### 反向成更纯 nx

```text
凤姐定处分
→ 平儿无替代调查/方案
→ 直接照令执行
```

则运行层也更偏 nx。

### 反向成 x / xn

如果平儿本来就有独立撤销、减免、结案权限，无需再回凤姐，那么最终审批层 nx 明显下降；她的方案重设应主要检查 `x/xn`。

### 反向成 zx

如果平儿借此案取得此前不存在且之后可独立调用的更高家内处分范围，并使贾府相关人员稳定围绕她的新裁决接口运行，才应进一步检查 zx。

原文没有这种权限转移。

## 8｜最近邻排除

### nx vs xn

```text
xn：平儿重新决定“怎么查、怎么收束、怎么结案”。
nx：平儿不能独立决定“这套新结案方案是否正式覆盖凤姐原处分”。
```

二者对象层不同，可以同时成立。

### nx vs x

平儿在日常事务中确有相当执行权限，但本案文本直接证明最高处分更改仍需回凤姐，因此不能把一般管理能力偷换为“本案最终处分权归平儿”。

### zx vs x

即使平儿在凤姐授权后可以实际放人，那也是本案批准后的执行接口；没有证明她的长期决定范围扩张，所以不是 zx。

### nz / z / xz 冻结

平儿同情五儿、顾惜探春体面、凤姐对平儿信任、案件处罚风险，都可解释动机和压力，但不替木轴回答“谁重设方案、谁掌握最终批准”。

## 9｜与当前待审议问题的关系

本案直接回应：

`07-Codex大脑库/待审议问题_nx外部方案存在与主体重设边界_20260816.md`

其中后续验证需求第3项：

> 主体真正重设方案以后，又是否因上级逐项审批而重新表现 nx 权限关系？

本案给出高置信正例：

```text
主体方案重设
→ 该方案层 nx 下降、xn 上升

同时

最终批准权仍在外部
→ 该权限层 nx 关系位置成立
```

因此不能写成：

```text
只要主体会改方案
→ 全部 nx 自动消失
```

正确的对象层纪律是：

> **重设方案只会打掉相同方案层上的 nx；不会自动消除其他仍真实外置的权限层 nx。**

本轮只增加案例证据，不修改 L1、信息卡、准度卡或补卡。

## 10｜严格 zx↔nx 补关系检查

本案不锁严格补关系。

平儿的 `xn` 方案重设与 `nx` 审批关系可以并存，但这不是 `zx` 与 `nx` 两端分别独立成立并互补缺口。

因此：

`strict_zx_nx_complement_locked: false`

## 13｜下一轮建议

优先换到《西游记》或《水浒传》寻找第二个同型最小差异：

```text
主体真实重设关键方案
+ 新方案不能直接生效
+ 必须经过另一个真实拥有否决权的外部权限节点批准
```

重点不是再证明“会改方案”，而是检查**外部批准是否具有真实可用的否决能力，而不是名义签字**。
