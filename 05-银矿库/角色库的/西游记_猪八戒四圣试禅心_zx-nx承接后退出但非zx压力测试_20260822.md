# 《西游记》猪八戒四圣试禅心｜zx-nx 承接后退出但非 zx 压力测试

## 0｜研究问题

本轮只测一个窄问题：

> 主体已经真实承接一个外部给定方向（nx），后来在执行窗口主动不再续接该方向，是否就自动转成 zx？

结论：**不是。**

本例最适合作为上一轮“沙悟净接受观音安排、等待并继续跟随取经人”的最小反向控制：

```text
沙悟净：
外部给方向 → 接受 → 等待 → 正确接口出现 → 继续
= nx

猪八戒：
已随取经队西行 → 遇到招赘诱惑 → 主动不再续接西行终点
= 当前 nx 退出

但：
没有取得新的公共决定范围
没有把自己的权能扩张成新的现实处分接口
≠ zx
```

## 1｜剧情事实

第二十三回开头，猪八戒已经是唐僧徒弟，随师徒西行，承担行李等实际取经职责；孙悟空还明确提醒他既已“秉正沙门”，就必须随队吃苦修行。

当四圣化作母女，以庄园、财富和婚姻招赘师徒时，唐僧拒绝，沙悟净也明确表示受菩萨劝化、已拜唐僧为师，宁死也要继续西行。

猪八戒则在听到富贵美色后明显动摇。更关键的是，他随后主动绕到后门与“妇人”私下商议招赘，明确表示唐僧等人奉唐王旨意不肯留下，但自己是否还俗、是否招赘“都在于我”，并继续推进婚配。

他最终进入内堂、拜“丈母”、尝试完成婚配，直到四圣试验结束、被绷住受罚，才在第二天求师父等人解救并继续同行。

因此当前窗口不是“猪八戒仍然沿取经方向，只在途中休息”，而是：

```text
既有取经方向真实存在
→ 猪八戒此前真实承接
→ 招赘诱惑出现
→ 本人主动尝试退出西行 / 出家方向
→ 转向留下成婚
```

## 2｜nx 判断

### 2.1 前一阶段：nx 成立

取经这一最高方向不是猪八戒在本阶段自行建立的。观音劝化、唐僧收徒以及既有取经队伍共同给出了“随唐僧西行”的上位方向；猪八戒此前已真实承接并履行。

因此：

`nx_prior_pilgrimage_direction_relation: evidence-locked`

### 2.2 当前招赘执行窗口：nx 退出

面对“四圣”提供的婚姻与富贵方案时，猪八戒没有继续把“是否仍随师父西行”交给唐僧决定。

他反而明确表达：

> 自己是否干这件事，由自己决定。

并且真的离开师徒共同决策，私下推进招赘。

所以在“继续西行还是留下成婚”这个当前终点层：

`nx_in_marriage_choice_execution_window: rejected_as_primary`

这里的结论只作用于当前窗口，不能倒写成“猪八戒从此人物本体不是 nx”。

## 3｜zx 判断

**排除为主判。**

最容易误判的是：

```text
原来听师父安排
→ 现在自己说了算
→ 所以 zx
```

这不够。

现行 zx 要求的不只是“我不听了”，而是主体自身权能公开进入现实，使他者 / 环境被迫围绕其新增决定位置重新响应，并且决定范围或作用位置真实上升。

猪八戒本轮没有：

- 取得取经队最高方向权；
- 让唐僧、悟空、沙僧改为围绕他的“留下招赘”路线行动；
- 建立新的持续组织接口；
- 获得超过原来个人选择边界的新处分范围。

相反，他的个人选择最终没有成功，四圣试验结束后仍回到既有取经队伍。

因此：

`zx_in_narrow_stage: rejected_as_primary`

核心纪律：

> **退出 nx ≠ 自动 zx。**

## 4｜最近邻排除

### 4.1 x：个人选择边界邻近

猪八戒说“干与不干，都在于我”，最直接支持的是：在自己是否愿意还俗、婚配这一私人选择层，他试图调用自身选择边界。

因此记录：

`x_personal_choice_boundary_neighbor: present_but_not_primary`

但本轮不专门锁 x，因为研究对象是“已承接外部方向后是否继续续接”，而不是建立完整的个人婚配权模型。

### 4.2 xn：排除主判

猪八戒没有重新设计一套持续替代路线：

- 没有重排取经人员；
- 没有建立新流程；
- 没有配置新的长期资源；
- 没有重写一个可持续运行的替代系统。

他只是从现有西行方向退出，转而尝试接受眼前婚配机会。

所以：

`xn_new_route_replanning: rejected_as_primary`

### 4.3 zx：拒绝 / 背离不是扩权

“我不照原方向走”只说明原 nx 续接停止；如果没有现实决定范围上升，不能拿拒绝动作替 zx 过门槛。

## 5｜关键压力

本轮压力是：

- 长途取经劳累；
- 富贵、庄园、婚姻与美色诱惑；
- 既有取经戒律与个人欲望冲突。

压力只负责让既有 nx 是否持续续接显影，不能直接判符号。

第三因素冻结：

- 猪八戒好色 / 懒惰的性格评价；
- 四圣的宗教寓意；
- 唐僧是否严厉；
- 最终受罚；
- 取经最终是否成功。

只看：**原方向来自谁、当前是否继续沿它走、退出以后有没有形成新的扩权现实。**

## 6｜拿掉测试

### 拿掉诱惑强度

即使把财富、美色描写削弱，只要仍存在：

```text
已承接西行
→ 当前主动不再续接
→ 尝试留下成婚
```

当前 nx 退出仍成立。

### 拿掉猪八戒主动私下推进

如果他只是嘴上抱怨，却仍随唐僧继续西行，那么只能算欲望 / 状态波动，不能锁当前 nx 已退出。

### 拿掉现实扩权证据

本例本来就没有新增公共决定范围；因此 zx 仍不能成立。

## 7｜反向测试

### 真正持续 nx

```text
四圣提出招赘
→ 猪八戒虽动心但仍接受唐僧 / 取经方向
→ 不另立当前终点
→ 继续西行
= nx 继续
```

### 真正 zx

```text
猪八戒退出取经方向
→ 进一步让取经队 / 庄园关系围绕他的决定重新组织
→ 取得此前没有的更大处分位置
→ 外部稳定承认新增决定接口
= 才检查 zx
```

原文没有。

### 真正 xn

```text
退出原取经方案
→ 主动建立一套替代生活 / 组织路线
→ 配置人员、资源、节点与长期运行规则
= xn 上升
```

原文同样没有。

## 8｜与沙悟净形成最小差异

上一轮沙悟净“流沙河归顺”锁定：

```text
外部给定取经方向
→ 接受
→ 等待正确节点
→ 节点出现
→ 继续执行
= nx
```

猪八戒本轮则是：

```text
外部给定取经方向
→ 已承接
→ 新诱惑出现
→ 主体不再续接
= nx 下降 / 退出

但没有扩权
= 非 zx
```

因此可形成非常窄的案例级纪律：

> **nx 判断必须持续追踪“当前对象层是否仍在实际续接外部方向”。曾经承接过，不代表以后每个窗口都永久 nx；反过来，退出 nx 也不等于自动跃迁为 zx。**
