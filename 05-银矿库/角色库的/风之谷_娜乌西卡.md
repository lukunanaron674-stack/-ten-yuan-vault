# 娜乌西卡（Nausicaä）
> 归档：`05-银矿库/角色库/风之谷_娜乌西卡.md`

---

## 1. 主十元判断

**主十元：zn（阳土·这件事是对的）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zn，娜乌西卡就是一个会飞的公主——勇敢、善良、爱护小动物。但娜乌西卡最核心的不是"善良"，是**她知道"生命是应该被理解的"**，这个信念比她自己的生命重要。她冲向王虫群、站在腐海中心、用自己的血去安抚愤怒的虫——不是因为不怕死（x），是因为"这是对的事"。
- **第2问（反复面对什么结构）：** 反复面对「杀还是不杀」。多鲁美奇亚要屠杀、培吉特要复仇、风之谷的人想自保——每个人都有理由去恨、去杀。但娜乌西卡每次都在同一个地方停下来："还有别的办法"。
- **第3问（最怕失去什么）：** 最怕「人类和王虫之间永远无法理解」。不是怕战争（n），是怕"杀到最后，没有谁理解了谁"。
- **第4问（回到哪个感觉）：** 回到「和狐松鼠初遇」的那一刻——她没有用刀（虽然她带了），她选择了用手去接住它。被咬的时候不退缩——因为"它会懂的"。
- **第5问（副十元服务谁）：** n（怕死了但扛住了）是zn的执行引擎——娜乌西卡站在王虫群前面的时候其实在发抖，但她不后退。不是因为她不怕，是因为"怕但该站的地方还是要站"。

## 2. 副十元

**副十元：n（阳火·怕死了但扛住了/不能退）**

**作用：** 娜乌西卡的"勇敢"不是没有恐惧——她每次冲向虫群都是在克服巨大的恐惧。但恐惧不会让她退，只会让她站得更直。她在金色草原上救助小王虫时是抖的，但手是稳的。

## 3. 功能十元

**功能十元：nz（阴金·不希望结束/希望大家都活着）——表层。** 她的救世主特质里有一部分是"不想让任何一个生命没被理解就结束了"。这是她对死亡的本能抗拒。

## 4. 视觉十元

**视觉十元：x（阴水·透明/纯净）。** 蓝色的衣服、光脚、和王虫对话时的眼神——她不需要盔甲或装饰，她的"武器"是理解和连接。

## 5. 动态链

```
zn（主·理解生命是对的/杀不是答案）
  → n（副·怕但不会退/该站的地方就站）
  → nz（功能·不想让任何一条生命没被理解就消失）
  → x（视觉·蓝衣+光脚+透明的勇气）
  → 坠入腐海→发现王虫的秘密→站在王虫群前→金色草原
  → 她没有被压死——王虫救了她
  → 因为"我在这里，我理解你们"
```

## 6. 一句话定型

娜乌西卡不是「女英雄」，也不是「和平使者」，而是「**这件事是对的所以不会退，哪怕站在王虫群前面**」的人。

---

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**修正1：** zn（主）+ n（副）→ 本体型
**最终定位：** zn（主·理解生命是对的）+ n（副·怕但不会退）→ 本体型
**最终修正理由：** 原卡xz+nz完全不适用——娜乌西卡不是"被推着走"的，她是主动选择去理解的。她也不是"命运型"——她的行动不是由命运决定，是由"我知道什么是对的"决定。zn描述了她的核心驱动：理解生命、寻求和解——不是因为被选中，是因为"这是唯一该做的事"。n描述了她面对恐惧的方式——她在恐惧中站住了。
