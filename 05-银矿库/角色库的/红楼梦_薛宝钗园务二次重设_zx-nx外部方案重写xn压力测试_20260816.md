# 《红楼梦》薛宝钗园务二次重设｜zx-nx 外部方案重写 / xn 最近邻压力测试

## 1｜本轮问题

本轮专门检验：

```text
外部已经存在明确改革方案，
主体不是机械执行，
而是对关键归账、收益分配与激励机制进行实质重设，
是否应使 nx 下降、xn 上升？
```

只判断第五十六回园务改革这一明确阶段，不外推宝钗稳定人物本体。

## 2｜剧情事实

### 触发

探春提出大观园园务改革：从园中老妈妈里挑选懂园圃者，分片料理竹木、稻地、香草等资源；让其获得部分收益，同时节省花匠、打扫与买办等开支。

### 已经存在的外部方案

在宝钗进一步介入前，探春已经形成一套明确方案：

1. 由园内合适婆子分片管理；
2. 管理者可以从园中产出获得收益；
3. 年终仍存在归账问题；
4. 探春担心若归外头账房，会重新受旧管事盘剥，因此提出改为“归到里头来”。

这说明宝钗面对的不是“没有方案”，而是一个已经能运行、但仍存在归账与分利缺口的既有方案。

### 宝钗的明确重设动作

宝钗并未只表示赞同，而是连续改写关键运行结构：

1. 否定探春“年终归到里头来”的归账办法，主张里头也不必归账；
2. 把原本要进入账房/里头账目的若干园内日常支出，改为由各分管婆子直接承担；
3. 明确计算头油、胭粉、香、纸、笤帚、撮簸、禽鸟粮食等支出如何被现有收益抵消；
4. 主张不能把全部馀利收归公中，而应让实际管理者保留一部分收益；
5. 进一步提出给未直接承包园地、但长期看守园子的其他老妈妈共同分润，以减少内部怨气和偷摘破坏；
6. 在人选上，否定让莺儿母亲直接承包香草区域的方案，改推老叶妈，再让老叶妈私下向莺儿母亲请教，以规避利益与闲话污染。

这些不是单纯“顺着探春说”，而是对资金流、激励、分配、人员接口与利益冲突防线进行二次设计。

### 结果

探春、李纨、平儿认可并采用宝钗的调整；众婆子在新分配规则下接受安排并表现出明显积极回应。

本轮不以改革最终长期成败作为十元判据，只看当下谁拥有运行方案的实际重设行为。

## 3｜zx / nx / xn 候选判断

### nx：rejected as primary for the rewritten operational layer

表面 nx 诱因：

- 宝钗参与的是王夫人委托下的家务协理；
- 园务改革最初由探春提出；
- 宝钗没有改写“要治理大观园、兴利除弊”这一上位目标。

但现行 nx 准度卡要求主体不主动改写方向，也不抢最终否决与重设位置；而本轮宝钗恰恰在“园务收益如何归账、如何分配、如何建立激励与人选接口”这一运行层主动否定并替换既有关键方案。

因此：

```text
上位治理目标：外部既定
下位运行机制：宝钗实际重设
```

不能用上位目标外置，覆盖下位运行层的自主重组。

### zx：rejected as primary

宝钗的方案确实被采用，众婆子也围绕新机制回应，但本轮没有足够证据显示：

- 宝钗因此取得此前不存在的更高家内处分范围；
- 王夫人、凤姐或整个贾府权力结构必须围绕宝钗新增权能运行；
- 宝钗把自身决定边界公开扩张到原授权之外并获得制度性承认。

所以“意见被采纳、设计很聪明、众人听从”不能自动锁 zx。

### xn：最近邻高显影

本轮最稳定结构是：

```text
已有改革方案
→ 主体识别归账、分利与利益冲突缺口
→ 否定既有关键运行环节
→ 重设资金流
→ 重设收益分配
→ 重设人员接口
→ 用新的激励结构维持持续运行
```

这明显优先于 nx 的“沿既有方案续接”。

## 4｜关键压力

本轮最有价值之处在于：宝钗不是因为外部没有方案才自由发挥。

```text
探春已有可运行方案
+ 平儿已准备去回凤姐
+ 具体承包人也开始讨论
→ 宝钗仍对关键运行环节作二次替换
```

因此这是比“只给总目标，我自行规划”更强的方案重写证据。

## 5｜拿掉测试

### 拿掉“宝钗聪明、通人、贤”之人物评价

只留下“已有归账方案 → 主体明确否定 → 改成不归账并重设费用与分利结构”，当前运行层 nx 仍下降，xn 仍上升。

### 拿掉探春这个具体人物

换成任何先提出园务改革方案的主体，只要宝钗仍对既有运行结构作实质替换，结论不变。

### 拿掉最终众人欢喜

即使新方案后来效果一般，只要宝钗实际完成了关键运行机制重写，nx/xn 边界判断仍然成立；结果好坏不是判据。

### 拿掉王夫人委托

若没有上位委托，宝钗是否具备家务合法介入位置会变化，但“她是否主动重设既有方案”这一 xn 证据仍在；委托影响关系合法性，不决定方案是不是她重写的。

## 6｜反向测试

### 反向成 nx

如果探春已经把归账、支出、分利、人选和冲突处理全部定好，宝钗只表示同意并按既有安排协助执行，不主动替换关键结构，则 nx 当前行为会上升。

### 反向成更纯 xn

如果王夫人/探春只给“把园子管好、少浪费”这个抽象目标，所有承包、归账、激励、分配和人员接口均由宝钗独立设计，则 xn 证据更纯。

### 反向成 zx

如果宝钗不仅重设运行机制，还借此取得原本不属于自己的更高家内处分权，使王夫人、凤姐等以后必须围绕她新增的决定接口运行，才应提高 zx。

## 7｜最近邻排除

### nx vs xn

本轮核心：

```text
别人已有方案，我沿着执行 → nx候选
别人已有方案，我主动否定并重设关键运行机制 → xn优先
```

### zx vs x

宝钗有王夫人委托下的协理位置，但这种位置并不等于本轮发生了权力边界扩张；授权内的判断与建议不能自动上升为 zx。

### zx vs z

众人认可宝钗方案、称赞她“全大体”，属于认可表象，不能代替 zx 的权能扩大。

### nx vs nz

宝钗与探春、李纨等合作关系良好，但本轮关键变量是运行方案是否由她重设，不是关系本身是否可停靠、可回返。

## 8｜第三因素冻结

冻结：

- 宝钗“贤、识大体”评价；
- 探春改革能力；
- 凤姐此前是否想到类似方案；
- 众婆子是否喜欢宝钗；
- 贾府最终是否衰败；
- 节省金额多少；
- 宝钗婚姻与人物结局。

只保留：

```text
是否已有明确方案？
宝钗是否拥有真实否决/重设窗口？
她是否实际否定旧方案？
是否重设资金、分利与人员结构？
是否只是沿原方案执行？
是否扩大了自身权力边界？
```

结论仍为：当前运行层伪 nx、伪 zx，xn 最近邻高显影。

## 9｜人物本体 / 状态 / 行为 / 关系分层

- 稳定人物本体：不锁。
- 当前状态：参与外部既定园务改革，但主动改写关键运行结构。
- 行为功能：分析缺口、重设资金流、分配、激励与人选接口，偏 xn。
- 关系位置：上位家务目标仍来自王夫人/既有管理结构，但当前运行方案并非被动承接。
- 外部压力：贾府费用重叠、旧账房盘剥风险、婆子利益冲突；这些推动重设，但不等于 zx 或 nx 本身。

## 10｜跨作品边界复现

本轮与两部已有作品构成第三个独立同型：

1. 《水浒传》杨志押送生辰纲：外部给任务与原方案，杨志否定旧运输结构，重设人员与时间节点 → nx 下降 / xn 上升。
2. 《三国演义》马谡守街亭：外部给任务与明确下寨约束，马谡主动否定并建立山上屯军方案 → nx 下降 / xn 上升。
3. 《红楼梦》宝钗园务二次重设：探春已有园务方案，宝钗否定归账与分利环节并重设资金、激励与人员接口 → nx 下降 / xn 上升。

三者共同指向：

> **外部目标甚至外部方案已经存在，都不能单独成立 nx。若主体拥有真实重设窗口，并实际替换关键运行结构，应优先检查 xn；上位方向外置与下位运行自主必须分层。**

达到三作品阈值，另建 pending-review，不直接修改 L1 或十元核心定义。
