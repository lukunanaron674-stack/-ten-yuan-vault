# 《水浒传》鲁智深野猪林救林冲｜zx↔nx 纯 zx 公开介入压力测试

## 1｜剧情事实

对象截面限定在野猪林行刑即将发生、鲁智深公开介入并取得现场主导位置这一桥段，不外推鲁智深整个人物稳定本体。

事实链：

1. 董超、薛霸把林冲绑在树上，明确准备按高俅一方的安排杀死林冲。
2. 薛霸举棍即将下手时，鲁智深从林中公开出现，以禅杖直接隔开水火棍并准备攻击两名公人。
3. 林冲请求不要杀董超、薛霸，鲁智深停止击杀，但立即割断绳索、扶起林冲。
4. 鲁智深随后公开威慑董超、薛霸，要求二人搀扶林冲并继续同行；两名公人不敢反抗。
5. 后续路途中，原本掌握押解过程的董超、薛霸反而必须顺着鲁智深的要求行走、休息和照料林冲，原有“押解途中秘密杀人”结果被实际阻断。

触发：林冲即将被秘密杀害。

对象：董超、薛霸所代表的当前押解/杀害执行接口，以及林冲的即时生死结果。

明确动作：公开介入、隔棍、解除束缚、威慑执行者、重定同行规则。

结果：林冲未被杀；董超、薛霸的原执行方向被迫停止，并开始围绕鲁智深的现场力量重新行动。

## 2｜zx / nx 主判

### zx：evidence-locked

本桥段满足现行 zx 硬门：

```text
主体自己的力量与判断明确
→ 公开进入现实
→ 原执行者被迫回应
→ 原有杀害结果被阻断
→ 主体从外部观察者上升为现场实际决定力量
```

关键不是“鲁智深很能打”，而是他的自身权能成为新的现实作用来源：董超、薛霸原本可以按既定安排处置林冲；鲁智深介入后，他们无法继续原结果，并必须按照鲁智深提出的现场边界行动。

因此锁定：

`zx_current_state_stage: evidence-locked`

只锁当前状态 / 行为功能 / 关系位置，不锁“鲁智深稳定本体 = 纯 zx”。

### nx：rejected

本窄阶段没有出现：

- 向现有官府接口请求放人；
- 借高层许可改变押解决定；
- 通过关系网络求人替自己出手；
- 承认董超、薛霸的杀害方向并沿其继续。

鲁智深不是沿现有通道解决，而是直接以自身权能切断原执行结果，因此：

`nx_in_narrow_stage: rejected`

## 3｜关键压力

外部压力来自林冲已被绑缚、杀害动作即将落地。

但“危急”“救人”“能打”本身都不是 zx 判据。真正判据是：危机出现以后，谁成为新的现实决定来源，以及原执行者是否因此被迫重新排列行为。

## 4｜最近邻排除

### zx vs x

鲁智深原本并不拥有官府押解或犯人处分权，所以不是“已有权限正常调用”的 x。

本段恰恰是：原处分接口不在他手里，但他公开把自己的作用权压入现场，使原执行结果失效，因此更符合 zx 当前状态。

### zx vs xn

鲁智深此前跟踪董超、薛霸、提前到林中等待，确有计划、观察与节点选择，可形成 xn 准备层邻近。

但拿掉“何时跟踪、在哪里等待”等准备细节，只保留：

`公开介入 → 原杀害执行被打断 → 两名公人被迫按其要求重新行动`

zx 仍独立成立。因此 xn 不是本轮主判。

### zx vs nz

鲁智深与林冲的情义可以解释“为什么救”，但关系动机不能替木轴回答“谁成为现场作用权来源”。冻结友情后，公开介入造成现实重排的结构仍成立。

### zx vs xz

林冲即将死亡是高压条件，但危险只解释为什么此时必须行动，不自动生成 zx。zx 仍需由公开权能、他者被迫响应和位置上升独立证明。

## 5｜拿掉测试

### 拿掉“鲁智深武艺高强”标签

不使用人物评价，只保留文本结果：他公开阻断杀害、解除林冲束缚、使两名执行者不敢继续并改按其要求行动。zx 仍成立。

### 拿掉最终长期护送

即使只截到野猪林当场，只要原执行已被公开阻断、两名公人失去当场处置能力，zx 当前状态仍有充分证据。

### 拿掉林冲与鲁智深的友情解释

动机变弱，但“主体公开介入并重排现场作用关系”的木轴结构不变。

## 6｜反向测试

### 反向成 nx

如果鲁智深发现阴谋后不直接介入，而是去请求开封府、上级官员或另一个真实掌权者下令保护林冲，并只能等待外部许可生效，则 nx 权限关系明显上升。

### 反向成 x

如果鲁智深本来就是本次押解的合法最高负责人，有权直接命令董超、薛霸停止并释放林冲，那么优先检查 x，而不是 zx。

### 反向成伪 zx

如果鲁智深冲出来叫骂、挥杖，但董超、薛霸仍完成杀害，且现场决定结构没有围绕鲁智深发生有效重排，则只能算强烈行动，不足以锁 zx。

## 7｜稳定本体 / 状态 / 行为 / 关系 / 压力分层

- 稳定人物本体：不锁。
- 当前状态：zx 高显影，锁定。
- 行为功能：公开介入、阻断原结果、重定现场行为。
- 关系位置：从外部观察/跟随者跃迁为现场更高实际决定力量。
- 外部压力：林冲即将被杀，仅作显影条件。

## 8｜严格 zx↔nx 补关系检查

本轮不锁严格补关系。

原因：当前桥段的主机制是 zx 直接切断现有执行接口，并没有一个独立成立、同时为 zx 补入必要外部权限/关系通道的 nx 端。不能因为林冲请求鲁智深不要杀两名公人，就把普通关系互动硬焊成 nx。

因此：

`strict_zx_nx_complement_locked: false`


本轮最小纪律：

> zx 不是“动作很猛”，而是主体自身权能公开进入现实以后，原执行者和结果结构真的被迫围绕主体重新排列，并使主体的实际作用位置上升。

与“李逵扯诏反招安”伪 zx 可形成反向控制：同样强烈介入，若核心路线并未转到主体手里，则不能锁 zx；野猪林中，原杀害结果和执行者行为确实被鲁智深改写，因此属于真 zx 当前状态。
