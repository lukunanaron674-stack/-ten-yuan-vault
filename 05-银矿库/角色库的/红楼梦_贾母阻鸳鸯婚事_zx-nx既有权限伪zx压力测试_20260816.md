# 《红楼梦》贾母阻鸳鸯婚事｜zx-nx 既有权限伪 zx 压力测试

## 0｜结论

本桥段最适合锁为：

```text
贾母本来就掌握鸳鸯是否被贾赦讨去的关键家内处分接口
→ 鸳鸯当众陈情后，贾母公开调用这一既有权限阻断安排
→ 贾赦最终无法继续，只得另买嫣红
= x 最近邻高显影

不是：
公开震怒 + 对方退让 = 自动 zx
也不是：
通过别人权限办成 = nx
```

因此本轮对木轴的价值是一个高置信边界反例：**“已有权限被公开成功行使”不能自动升级为 zx；当关键权限本来就在主体手里，也不能判 nx 关系功能。**

本轮只锁当前行为/关系位置的边界，不锁贾母稳定人物本体；不锁严格 zx补nx。

## 1｜剧情事实、触发、对象、动作、结果

### 触发

贾赦欲纳鸳鸯为妾，先由邢夫人、鸳鸯兄嫂等多路劝逼。邢夫人一开始就担心“老太太不给”，说明鸳鸯并不是贾赦可以绕过贾母直接处分的人。

鸳鸯在兄长再次转达贾赦威胁后，要求回禀贾母；随后当众向贾母说明整个过程并明确拒绝。

### 对象

- 主体：贾母。
- 受保护对象：鸳鸯。
- 冲突方向主体：贾赦及邢夫人一侧。
- 关键问题：谁真正拥有“鸳鸯能否被讨去作妾”的家内许可/阻断接口。

### 明确动作

1. 贾母听完鸳鸯陈情后公开震怒，明确把鸳鸯视为自己身边不可被夺走的人。
2. 她当场追责相关家内成员，并明确表达“这个丫头不能给”的立场。
3. 第四十七回进一步说明她要人传话给贾赦：其他人可以另外买，唯独鸳鸯不能给。
4. 贾赦随后“无法”，又含愧，不敢见贾母，最终另买嫣红。

### 结果

贾赦原先的纳妾方向被实际阻断；但这不是贾母在本事件中临时夺取一项原本不属于她的权限，而是她调用原本已经存在的家内最高长辈/鸳鸯所属关系中的处分与否决位置。

## 2｜zx 检查

### 支持 zx 的表象

这段非常容易被表面判成 zx：

- 贾母公开震怒；
- 王夫人等人立即不敢辩；
- 贾赦最后退让；
- 现实确实围绕贾母的决定改变。

但现行 zx 必须继续问最后一层：**主体的决定范围、影响位置或凌驾程度是否新增或上升。**

### 为什么高纯 zx 不成立

本段此前已经有两条反向证据证明关键权限本就属于贾母：

1. 邢夫人最初就担心“老太太不给”；
2. 鸳鸯即使面对贾赦威胁，仍要求“回声老太太”。

这说明冲突发生前，贾母已经是必须经过的许可/否决节点。

因此本段是：

```text
已有权限
→ 公开调用
→ 对方服从/退让
```

而不是：

```text
原本无该权限
→ 主体以自身权能夺取/扩大决定范围
→ 新秩序围绕新增权力重排
```

结论：

```text
zx_in_current_narrow_stage: rejected_as_primary
x_existing_authority_neighbor: evidence-locked
```

## 3｜nx 检查

`nx` 同样不成立为贾母本人的主要机制。

nx 关系功能要求关键权限仍在外部，主体必须通过别人、旧交、身份网络或既有通道借力。

本段恰好相反：

- 贾母不是去求人替自己否决；
- 她不需要借另一个更高家内主体的批准；
- 她本人就是鸳鸯这一事件中的关键许可/阻断接口。

因此：

```text
nx_relation_function_for_jia_mu: rejected
```

这与同一事件中的鸳鸯形成直接反向：鸳鸯需要进入贾母权限接口，所以鸳鸯有 nx 关系功能；贾母本人拥有该接口，所以不能再判 nx。

## 4｜最近邻排除

### zx vs x

这是本轮最重要的最近邻。

```text
x：权限和处分边界本来归我，我调用它。
zx：我的权能公开显现并扩大，决定范围真实上升。
```

贾母本段显然更接近前者。

### nx vs x

```text
nx：权限在别人手里，我沿关系通道借用。
x：关键权限本身就在我手里。
```

同一事件中：

- 鸳鸯 → 权限在贾母 → nx 关系功能成立；
- 贾母 → 权限就在自己 → x 最近邻成立。

### 排除 xn

贾母没有通过排程、节点、流程设计解决事件；核心是直接调用既有家内否决权。

### 排除 z

王夫人、贾赦等人对贾母的尊重与不敢违逆可以是认可/等级背景，但不替代“权限本来归谁”这一核心变量。

## 5｜拿掉测试

### 拿掉贾母的愤怒强度

即使把“气得浑身乱战”、当众责骂等戏剧性动作全部拿掉，只保留：

```text
鸳鸯归贾母使用/处分
+ 邢夫人事前知道必须过贾母这一关
+ 贾母明确不给
+ 贾赦因此无法继续
```

`x` 仍成立，`zx` 仍不需要成立。

### 拿掉贾赦最终羞愧

只要纳鸳鸯一事确实被贾母的既有权限阻断，木轴判断不变。羞愧只是结果外观，不是十元判据。

### 拿掉“老太太”身份词

换成任何一个本来就拥有某对象最终处分/否决资格的主体，只要其只是公开使用已有权限而没有扩大权限边界，仍优先判 x 而非 zx。

## 6｜反向测试

### 反向成真 zx

若贾母原本没有权阻止贾赦处分鸳鸯，却通过本次冲突第一次夺取了这项决定权，并让贾府之后承认她新增的处分范围，则 zx 才明显上升。

### 反向成 nx

若贾母自己也无权阻止贾赦，必须去求另一个真正掌权者、借其身份或制度接口才能让贾赦停止，则 nx 关系功能才成立。

### 反向成普通意见表达

若贾母只是反对，但贾赦仍可不受约束地继续纳鸳鸯，则连 x 的实际处分证据也会下降，只剩态度表达。

## 7｜第三因素冻结

冻结以下因素：

- 贾母年龄与“老祖宗”称号；
- 贾赦的人品与好色；
- 王夫人是否无辜；
- 贾母发怒的戏剧强度；
- 鸳鸯是否以死相逼；
- 贾赦最后是否觉得丢脸；
- 封建家庭伦理主题。

只保留：

```text
冲突发生前谁拥有鸳鸯的关键许可/否决接口？
主体是否需要借别人权限？
本次行动是否新增主体的决定范围？
对方是否因该既有权限而实际改变行为？
```

结论仍为 x 最近邻，zx/nx 均排除为主要解释。

## 8｜与鸳鸯既有案例的最小差异

仓库已有“鸳鸯拒婚 zx+nx 压力显影正例”：

```text
鸳鸯：
自己的婚姻方向不让
→ zx 当前状态

但让贾赦真正停手的家内权限不在自己
→ 进入贾母接口
→ nx 关系功能
```

本轮补上同一事件的权限另一端：

```text
贾母：
关键许可/阻断接口本来就在自己
→ 直接调用已有权限
→ 贾赦退让
= x 最近邻
≠ nx
≠ 新增扩权型 zx
```

所以可以形成一条案例级判定纪律：

> **判断 nx 时，不要只看“谁帮谁”；要顺着权限链一直追到真正持有接口的人。对借接口者可判 nx 关系功能，对接口持有者则优先检查 x；只有权限边界本身发生公开扩大，才进一步检查 zx。**

## 9｜稳定本体 / 状态 / 行为 / 关系 / 压力分层

- 稳定人物本体：不锁。
- 当前状态：既有家内权限被公开调用。
- 行为功能：明确否决并阻断贾赦安排。
- 关系位置：关键权限持有者，不是权限借用者。
- 外部压力：贾赦通过邢夫人、兄嫂等路径持续试图取得鸳鸯。
- 主判最近邻：x。
- zx：表象强，但缺新增决定范围。
- nx：缺“权限在外部并需借用”这一核心条件。
