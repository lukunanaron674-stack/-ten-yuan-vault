# 《红楼梦》王熙凤毒设相思局｜zx↔nx 秘密操纵伪 zx 压力测试

## 1｜剧情事实

本轮只截取第十二回凤姐两次设局惩治贾瑞的连续桥段，不把贾瑞后来照风月宝鉴、最终死亡的全部结果归因给凤姐。

事实链：

1. 贾瑞对凤姐越界示好后，凤姐表面顺应，约其夜间到西边穿堂等候，并声称已把上夜小厮放假、关门后无人。
2. 贾瑞按约进入穿堂后，两边门被倒锁，在腊月夜里被困一夜，几乎冻死；凤姐没有公开以家内处分权正面处罚，而是通过假约会与封锁空间使结果发生。
3. 贾瑞仍未醒悟，再次来找凤姐；凤姐再次约其到空屋，并“点兵派将，设下圈套”。
4. 贾瑞进入后，实际遇到贾蓉、贾蔷，被设计羞辱并被逼写下两张欠契；随后又被引到台阶下，遭粪尿浇身后逃回家。
5. 贾瑞后来因相思、受冻、受罚、负债等多重因素病倒；本轮只把“设局造成受困、受辱、负债等具体结果”归入凤姐布局，不把后续死亡单因果归给凤姐。

触发：贾瑞持续越界纠缠。

对象：贾瑞的行动结果，以及凤姐是否通过自身公开权能取得新的处分位置。

明确动作：假意迎合、约定地点、封锁空间、再次诱导、调用贾蓉贾蔷设局、制造羞辱与债务。

结果：凤姐预期的惩治结果真实发生，但主要依靠隐蔽欺骗与诱导完成；并未公开取得一个此前不存在、被贾府承认的新处分权接口。

## 2｜zx / nx 主判

### zx：rejected_as_primary

本桥段不能因为“凤姐设局成功、贾瑞受了重罚”就判 zx。

现行 zx 要求主体自身权能公开进入现实，使他者/秩序围绕主体重新反应，并且主体位置、影响或决定范围扩大。

本段的主方法却是：

```text
隐藏真实意图
→ 诱导对象误判
→ 借空间、同谋与假信息改变结果
→ 对象受困/受辱/负债
```

凤姐没有公开宣布并建立“我现在拥有新的对贾瑞处分权”，贾府制度也没有围绕一个新增凤姐接口运行。她改变的是具体结果，而不是公开扩大的决定边界。

因此锁定：

`zx_in_secret_manipulation_stage: rejected_as_primary`

### nx：rejected

本轮也不是 nx。

凤姐没有承认关键处分权在另一个主体手里，然后通过请求、托关系、批准网络去推进。她是在秘密设计局面并诱导贾瑞进入，而不是沿一个外部既有权限通道申请解决。

贾蓉、贾蔷参与执行，属于凤姐方案中的协作节点；本轮没有证据显示凤姐必须等待他们掌握的独立最终权限批准。因此不以 nx 为主判。

## 3｜关键压力

关键压力是：凤姐若公开处理贾瑞，会暴露丑闻并牵动家内关系，所以她选择隐蔽惩治。

压力只解释为什么采取秘密路径，不直接决定 zx/nx。

## 4｜最近邻排除

### zx vs xn

本轮最强最近邻是 xn：凤姐主动设计诱饵、地点、时机、同谋和连续两轮圈套。

`xn` 解释“怎样把惩治过程组织起来”；
`zx` 则要求“自身权能是否公开扩大并成为新的现实决定来源”。

拿掉具体骗术，只保留“秘密布局成功改变结果但无公开扩权”，伪 zx 结论仍成立。

### zx vs x

凤姐在荣府原本有一定管理位置，但本轮没有证据说明她通过这次事件新增了对贾瑞的稳定正式处分边界。因此不能把已有家内地位或办事能力偷换为 zx 扩权。

### nx vs nz

贾蓉、贾蔷与凤姐的关系只是执行协作条件，不是本轮需要借用一个外部独立权限主体的 nx 结构；关系动机也不是主判。

## 5｜拿掉测试

### 拿掉最终“贾瑞后来病死”

只保留两次设局造成受困、受辱、负债，仍足以证明“秘密改变结果但没有公开扩权”。因此本轮从一开始就不把死亡作为 zx 证据。

### 拿掉贾蓉、贾蔷具体姓名

换成其他可协作执行者，只要凤姐仍通过隐藏方案诱导对象、而不是公开取得新处分权，结论不变。

### 拿掉凤姐原有管家身份

只留下“主体秘密设局使结果改变，但现实没有承认新增决定位置”，仍不能锁 zx。身份不是判据。

## 6｜反向测试

### 反向成真 zx

如果凤姐公开宣布对贾瑞的处分要求，原本不属于她的处分范围被她以自身权能强行取得，而且贾府人员与规则开始承认并围绕这个新增接口运行，则 zx 明显上升。

### 反向成 nx

如果凤姐必须向王夫人、贾母或其他真实掌权者请求处理贾瑞，并等待批准后沿该权限通道执行，则 nx 关系功能上升。

### 反向成 x

如果对贾瑞的同等级处分权原本已稳定属于凤姐，她只是公开正常调用，则优先检查 x，而不是 zx。

## 7｜稳定本体 / 状态 / 行为 / 关系 / 压力分层

- 稳定人物本体：不锁。
- 当前状态：不锁 zx；秘密操纵路径高显影。
- 行为功能：诱导、欺骗、布局、组织同谋，xn 最近邻高显影。
- 关系位置：未形成新增公开处分权。
- 外部压力：避免公开丑闻与家内冲突，仅作路径选择条件。

## 8｜严格 zx↔nx 补关系检查

本轮不锁严格补关系。桥段内既没有独立成立的 nx 外部权限通道，也没有满足 zx 公开扩权硬门。

`strict_zx_nx_complement_locked: false`

## 9｜跨作品边界

同类边界现已跨三部独立作品：

1. 《西游记》孙悟空偷桃偷酒偷丹：秘密绕过资源权限，结果改变但未公开取得新增处分权。
2. 《三国演义》周瑜蒋干盗书：秘密制造假情报，诱使曹操误用自己的处分权，周瑜未取得曹营处分权。
3. 《红楼梦》王熙凤毒设相思局：秘密诱导、布置圈套改变贾瑞结果，但未公开形成新增处分权。

因此达到“三作品同类边界”阈值，应另建 pending-review，但不得直接改 L1、zx/nx 信息卡、准度卡或补卡。
