# 《西游记》孙悟空三打白骨精后被逐｜内心异议与实际续接压力测试

## 结论先行

本轮锁定：

> **内心不同意、口头申辩、情绪抵抗，都不能单独排除 nx。真正要看的是关键决定窗口出现后，主体是否实际使用否决/重设位置。**
>
> 三打白骨精后，孙悟空明确认为唐僧错怪自己，也不愿半途离开取经队伍；但当唐僧最终写下贬书、明确解除师徒关系后，孙悟空接下贬书，停止继续争夺“是否仍作为徒弟同行”的最终位置，完成拜别并离开。因此在“是否继续保留师徒/同行资格”这一窄关系对象层，锁 nx 当前关系位置与行为功能。
>
> 这不等于“孙悟空稳定本体 = 纯 nx”。齐天大圣的稳定 zx+nx 锚不改，本轮只锁一个关系处分窗口。
>
> 同时，本段也不新增 zx：申辩、悲愤、最后离开都没有扩大孙悟空的现实决定范围。

本轮不锁严格 zx↔nx 补关系。

## 1｜剧情事实

### 触发

孙悟空连续三次打杀白骨精变化之身。唐僧认定孙悟空滥杀无辜，并受八戒言语影响，坚持要逐走孙悟空。

孙悟空并非没有自己的判断。他明确认为对方是妖魔、自己是在除害，并多次说明若自己离去，唐僧后续可能无人保护。

因此本段不是：

```text
孙悟空没有意见
→ 唐僧说走
→ 孙悟空机械离开
```

而是存在明确的内部判断冲突与口头反对。

### 真正关系决定窗口

唐僧最终取纸笔写下贬书，明确表示不再要孙悟空做徒弟，并把这份关系处分交给孙悟空。

孙悟空接下贬书，表示自己离开；此后仍请求最后一拜、叮嘱沙僧保护唐僧，但不再把“我必须继续作为你的徒弟同行”强压回关系现实。

唐僧继续拒绝回心转意后，孙悟空最终离开，返回花果山。

### 结果

```text
孙悟空有自己的判断
+ 明确不愿被逐
+ 反复申辩
↓
唐僧最终解除师徒关系
↓
孙悟空接下贬书
↓
没有强行保留徒弟位置
↓
按解除关系后的方向离开
```

因此，“心理反对”与“实际占据最终否决位置”必须分开。

## 2｜nx 判断

### 纯 nx 稳定本体：不锁

孙悟空显然不是长期没主见型人物。现行 nx 正本也已经把孙悟空锁作强 zx 人物中高频出现 nx 关系功能的标准锚，而不是纯 nx 本体。

本轮只问一个窄问题：

> 在“师徒关系是否继续、孙悟空是否仍以徒弟身份同行”这个关系对象层，最后谁拥有让关系继续成立的关键许可位置？

唐僧明确撤回收徒/同行许可；孙悟空虽然希望继续、反复申辩，却最终承认该外部关系处分，并按其结果离开。

因此锁：

`nx_current_relation_position: evidence-locked`

`nx_behavior_function_in_expulsion_stage: evidence-locked`

### 为什么“我不同意”不能排除 nx

nx 准度卡要求看的不是脑内态度，而是：

```text
最终方向 / 权限 / 解决通道是谁的？
主体有没有抢最终决定、否决与重设位置？
关键窗口出现后，主体实际怎样做？
```

孙悟空本轮拥有自己的观点，但没有把“师徒关系必须继续”变成自己单方面可决定的现实接口。

所以：

> **意见不同 ≠ 最终方向仍由我占据。**

这与“被迫完全不能反抗”也不同。孙悟空拥有极强现实能力，文本中也没有一个物理封锁使他无法继续跟随；真正发生的是他最终承认唐僧对当前师徒关系的退出决定。

## 3｜zx 判断

### 申辩很强，但 zx 不成立

孙悟空的情绪、能力、过去功劳和战斗力都很强，但现行 zx 要求：

```text
主体自身权能公开进入现实
→ 他者/秩序被迫围绕主体重新反应
→ 主体决定范围、影响位置或凌驾程度上升
```

本段没有出现：

- 唐僧因为孙悟空的权能被迫恢复师徒关系；
- 取经队伍承认孙悟空新增的“不可被逐”决定权；
- 孙悟空取得对师徒关系的更高处分位置；
- 组织以后必须围绕一个新增的孙悟空关系裁决接口运行。

相反，他最终离开了原关系位置。

因此锁：

`zx_in_expulsion_stage: rejected_as_primary`

并记录：

> **强意见、强情绪、强能力、强功劳诉求 ≠ zx 扩权。**

## 4｜最近邻排除

### nz

本段明显有深厚师徒情感与不舍，孙悟空离开前仍请求拜别、叮嘱沙僧保护唐僧。

这些可以解释他为什么难舍关系，但 nz 不能代替木轴回答：

> 最终关系继续资格是否仍由孙悟空自己占据？

答案是否定的。

因此：

`nz_relation_attachment: high_neighbor`

但不覆盖 nx 当前关系位置。

### x

唐僧对“是否继续认孙悟空为徒弟”的关系许可在本段是关键既有处分接口；孙悟空并不掌握这块接口。

因此孙悟空一端不以 x 为主解释。

### xn

孙悟空没有在本轮建立新的持续流程、排程或节点结构。申辩、请求拜别、叮嘱沙僧都不是 xn 主骨。

### xz

紧箍咒、取经失败、关系破裂都构成压力背景，但这些压力不是本轮 nx 判定的唯一来源。

即使冻结紧箍咒，只保留“唐僧撤回师徒关系许可 → 孙悟空最终接受并离开”，nx 当前关系位置仍成立。

## 5｜拿掉测试

### 拿掉紧箍咒

如果唐僧不再拥有紧箍咒，只是明确解除师徒关系，而孙悟空仍接下贬书、接受不再作为徒弟同行并离开，则本轮 nx 关系位置不消失。

因此本轮不是靠身体强迫锁 nx。

### 拿掉八戒谗言

无论唐僧为什么形成错误判断，只要最后关系许可确实由唐僧撤回，孙悟空虽反对却最终接受这一处分，木轴结论不变。

八戒只影响触发，不决定最终权限结构。

### 拿掉孙悟空的悲伤与眼泪

只留下：

```text
主体反对外部决定
→ 外部关系主体最终撤回许可
→ 主体接收处分
→ 不再强占原关系位置
→ 实际离开
```

nx 当前关系位置仍成立。

### 拿掉最终回花果山

只要孙悟空停止以唐僧徒弟身份继续同行并承认贬书效力，nx 已经在关系处分层成立；回到哪里只是后续去向。

## 6｜反向测试

### 反向成华容道式“实际否决”

如果孙悟空在唐僧写下贬书后：

```text
明确不承认关系解除
→ 拒绝接收/承认贬书效力
→ 仍以徒弟身份强行同行
→ 迫使唐僧或取经关系结构围绕自己的决定重排
```

那么本轮 nx 会明显下降，需重新检查 zx/x/nz 等。

### 反向成更纯 nx

如果孙悟空连申辩和替代判断都没有，唐僧一说离开便立刻照办，则更接近纯粹的 nx 行为，但仍不足以单独锁稳定人物本体。

### 反向成 zx

如果孙悟空不但拒绝被逐，而且凭自身权能取得此前没有的“取经队伍最终关系处分权”，让唐僧及队伍以后都必须接受这个新增接口，才是 zx 决定范围上升。

当前文本没有。

## 7｜第三因素冻结

冻结以下变量：

- 白骨精究竟如何变化；
- 唐僧判断是否正确；
- 八戒是否挑拨；
- 孙悟空功劳有多大；
- 孙悟空武力多强；
- 紧箍咒是否公平；
- 师徒感情是否深厚；
- 后来是否再次召回孙悟空；
- 取经最终是否成功。

只保留四问：

```text
主体是否有自己的不同判断？      是
外部关系处分是否明确？            是
主体是否在最终窗口实际否决处分？  否
主体是否按处分结果离开原位置？    是
```

因此：

```text
nx 当前关系位置：成立
zx 当前扩权：不成立
```

## 8｜与华容道形成最小差异

### 关羽华容道

```text
外部军令明确
+ 主体知道军令
+ 主体私人判断不同
↓
真正执行窗口出现
↓
主体实际否决外部方向
↓
承担违令后果
= nx 最终执行层排除
```

### 孙悟空被逐

```text
外部关系处分明确
+ 主体明确不同意
+ 主体反复申辩
↓
真正关系决定窗口出现
↓
主体最终接受处分
↓
按处分结果离开
= nx 当前关系位置成立
```

两者共同锁出：

> **nx 不能看“心里是否赞成”，要看关键窗口里谁真正占据最终决定/否决位置，以及主体最后是否沿外部方向续接。**

这条差异仍属于现有 nx 准度卡能够解释的范围，本轮不修改 L1 或核心定义。

## 9｜与同事件唐僧案例的对象分层

同一“三打白骨精逐悟空”事件中，已有唐僧案例已经用于检验“已有师徒处分权的公开执行 ≠ 自动 zx 扩权”。

本轮换到孙悟空一端，只检查：

```text
唐僧：既有关系处分接口的持有者
孙悟空：关系继续许可被撤回的一方
```

所以同一事件允许出现不同对象层结论，不能把唐僧的 x 权限归到孙悟空，也不能把孙悟空的反对情绪倒灌成 zx。
