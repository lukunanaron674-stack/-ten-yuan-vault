# 《明史》海瑞释狱复故官｜zx-nx 官方授权接口恢复 x 压力测试

## 1｜史料事实

海瑞在嘉靖四十五年以户部主事身份上疏后，被世宗下诏狱，随后移刑部论死。进入诏狱后，其原有户部官职虽仍可作为名义身份被史料称呼，但现实行政调用已经被监禁切断，不能继续正常行使户部主事的官署职责。

世宗去世、穆宗即位后，朝廷释放海瑞。《明史·穆宗本纪》明确记载“释户部主事海瑞于狱”；《海瑞传》进一步记载海瑞与何以尚获释后，“既释复故官”，不久又改调、升迁。

因此本轮只测试一个很窄的权限状态链：

```text
原阶段：
海瑞任户部主事
→ 官署职责与对应调用位置真实存在
= 局部 x

下诏狱
→ 人身自由与官署实际履职接口被切断
= 原 x 退出

穆宗即位
→ 朝廷释放
→ 外部最高官僚授权恢复原职
= nx 官方授权 / 任命接口

海瑞复故官
→ 原官职调用位置重新成立
= x 恢复
```

## 2｜nx 判断

本例的 `nx` 不在“海瑞有没有自己的政治判断”。恰恰相反，上疏本身体现很强的自主判断。

`nx` 只锁在“旧官职能否重新成为现实有效职位”这一权限入口层：

- 海瑞不能单方面宣布自己恢复户部主事；
- 官职恢复需要经过皇权 / 朝廷正式释放与复官接口；
- 该恢复方向并非由海瑞自己生成并直接压成现实；
- 海瑞接受恢复后重新进入既有官僚职务通道。

因此锁定：

`nx_external_official_restoration_relation: evidence-locked`

本例同时验证现行 pending-review 的正向控制：`nx` 通道激活不要求主体先主动求人。被动接受正式任命、职责或恢复，只要实际重新进入外部既定权限结构并持续履职，同样可以形成 `nx` 行为 / 关系功能。

## 3｜x 判断

必须分前、中、后三个状态。

### A｜入狱前

海瑞以户部主事身份实际处于官署职责位置，因此当前职务范围内存在局部 `x`。

### B｜下诏狱后

监禁不是普通请假或暂时离岗。海瑞失去现实进入官署、调用职位职责和执行行政事务的能力，因此原局部 `x` 在实际调用层退出。

锁定：

`x_prior_authority_lost_in_imprisonment: evidence-locked`

### C｜穆宗复故官后

史料直接写“复故官”，说明不是只解除监禁，也不是只给荣誉名义，而是把原官职状态重新恢复。随后海瑞又很快调任、升迁，但不影响“旧官职已经先被恢复”这一窄事实。

锁定：

`x_official_authority_restored_after_external_authorization: evidence-locked`

因此本轮链条为：

`x丢失 → nx官方授权接口 → x恢复`

## 4｜zx 判断

本阶段排除 `zx` 为主判。

海瑞复职当然改变了他的现实位置，但这个变化来自穆宗 / 朝廷对既有官职的恢复，并没有证据显示海瑞在这一恢复窗口把自己的决定范围公开推进到原有户部主事边界之外。

同时，恢复后的最初结果只是“复故官”，即回到此前已经拥有过的官职边界，而不是新取得一个更大的权力范围。

因此：

`zx_in_restoration_stage: rejected_as_primary`

关键纪律：

```text
恢复旧职位 x
≠ 自动 zx 扩权

外部正式复职
≠ 主体自身公开夺取新权限
```

后续“改兵部、升迁大理寺”等属于新的任命 / 升迁窗口，应另行分段，不能倒灌成本轮复故官的 zx 证据。

## 5｜关键压力

关键压力不是“海瑞忠直”或“皇帝昏聩”，而是：

- 海瑞原本拥有真实官职；
- 下诏狱切断现实履职接口；
- 海瑞不能自行恢复官职；
- 新皇帝 / 朝廷掌握真实释放与复官权限；
- 正式复官后，旧官职状态才重新成为现实有效位置。

这组压力足够测试 `nx → x恢复`，但不用于推人物稳定本体。

## 6｜拿掉测试

### 拿掉穆宗 / 朝廷正式复官接口

海瑞即使继续认为自己应当任职，也不能凭个人判断让户部主事职位重新成为现实有效官职。

留下明确缺口：

> 旧 x 无法合法、现实地恢复。

因此外部官方授权接口不是装饰。

### 拿掉“复故官”

如果史料只写“释放海瑞出狱”，却没有恢复官职，则只能锁人身自由恢复，不能锁旧官职 `x` 已恢复。

### 拿掉入狱前真实官职

如果海瑞此前从未任户部主事，那么后续授官就是新获得权限，不属于“旧 x 恢复”，需要另查 `nx入口 / x新建 / zx`。

## 7｜反向测试

### 反向成 zx

```text
海瑞原有职位已失
→ 他不依赖朝廷正式授权
→ 以自身公开力量强行恢复并扩大官署处分范围
→ 朝廷被迫承认新增决定位置
= 才检查 zx
```

史料不是。

### 反向成非 nx 的自主恢复

```text
官职恢复接口已经稳定归海瑞自己处分
→ 无需皇权 / 朝廷重新授权
→ 可自行恢复职位
= 转查 x / zx
```

明代官职结构显然不支持这种情况。

## 8｜最近邻排除

### nx vs x

- `nx`：谁掌握让“复故官”正式生效的外部授权接口。
- `x`：复职以后，原官职是否重新进入海瑞现实可履行的职位边界。

因此：

`nx 是恢复入口，x 是恢复后的当前控制状态。`

### nx vs xn

海瑞没有主动设计一套复杂复职流程、节点和资源配置；本轮核心是正式外部授权，不以 `xn` 为主。

### nx vs zx

海瑞有很强自主政治判断，不影响本轮在“复职权限入口”上必须经过外部正式授权。强主体仍可在局部问题上出现 `nx` 关系功能。

### x vs zx

旧职位重新有效，只证明旧 `x` 恢复；没有扩大到新边界，就不能自动收成 `zx`。

## 9｜第三因素冻结

冻结：

- 海瑞忠直、清廉等人物评价；
- 嘉靖、隆庆政治评价；
- 上疏内容是否正确；
- 世宗是否本来就不打算杀海瑞；
- 海瑞后来升迁、巡抚应天与政治成败；
- 后世“海青天”声望。

只问：

1. 入狱前是否有真实官职位置？
2. 入狱是否切断实际履职接口？
3. 复职权限是否在外部皇权 / 朝廷？
4. 海瑞是否通过该正式恢复进入官职通道？
5. 结果是否恢复原职位，而非主体自行扩张到新范围？

五项均高置信成立。

## 10｜严格 zx↔nx 补关系检查

不锁。

本例高置信成立的是 `nx` 官方授权关系功能与 `x` 恢复；海瑞在本窄复职窗口没有独立 `zx` 端，因此严格补卡第一道“两端独立成立”即失败。

不能写成：

> 海瑞很刚 + 皇帝复职 = zx+nx 严格补。

## 11｜与施恩案例的最小差异

《水浒传》施恩：

`x丢失 → nx外部强制能力（武松） → x恢复`

本例海瑞：

`x丢失 → nx外部官方授权（穆宗 / 朝廷） → x恢复`

两例说明“`nx` 作为恢复旧 `x` 的外部接口”并不只限于借武力；至少已出现：

- 外部强制能力接口；
- 外部正式授权 / 任命接口。

目前只有两类独立材料，不新建待审议问题，不修改理论正本。

## 12｜结论

本轮锁定：

> **海瑞释狱复故官 = `x 丢失 → nx 官方授权接口 → x 恢复`。**

案例级纪律：

> **恢复旧 `x` 所需的 nx 接口可以是正式制度 / 任命权限，而不只是真人武力或救兵；恢复旧 `x` 本身仍不能自动判为 `zx`。**

不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
