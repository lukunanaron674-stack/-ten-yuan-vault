# 《三国演义》赵云长坂坡救阿斗｜局部自主与终点续接压力测试

## 结论先行

本轮锁定：

> **局部执行高度自主，不等于主体已经改写外部给定的最终任务方向。**
>
> 刘备在长坂前明确安排赵云“保护老小”。乱军冲散后，赵云没有等待新的逐步指令，而是自行搜索、问讯、救甘夫人、再折返寻找糜夫人与阿斗，并自行决定具体战斗、撤离和护送方式；但其反复自述的任务终点始终是“寻主母与小主人”，最终也确实把阿斗交还刘备。
>
> 因此在“上位托付终点”这一对象层，`nx` 行为/关系位置仍可成立；在“如何完成搜索与救援”这一局部运行层，`xn` 邻近高显影。不能因为执行过程中自主性极高，就把上位 `nx` 一锅端掉。

本轮不锁赵云稳定人物本体，不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实

### 外部任务

刘备一行被曹军追击前，组织分工明确：关羽去江夏求援，张飞断后，**赵云保护老小**。

这给出了本轮上位任务的外部来源：

```text
刘备集团给定任务
→ 赵云负责保护刘备家小
```

### 压力触发

曹军夜袭后队伍溃散。赵云与刘备失联，同时失去甘、糜二夫人与阿斗的位置。

赵云自己回忆：主人把两位夫人与小主人托付给自己，如今失散，必须寻找。

### 主体的局部自主动作

失散以后，没有新的上级逐步指令。赵云自行：

1. 在乱军中搜索；
2. 询问简雍、护送军士和百姓以获得位置线索；
3. 先找到甘夫人，并救出糜竺、护送甘夫人到长坂桥；
4. 明知刘备已在前方，仍主动折返寻找糜夫人与阿斗；
5. 找到糜夫人与阿斗后，自行处理救援与突围；
6. 抱阿斗杀出重围，最终回到刘备处。

这说明具体运行方式不是别人逐节点给定，而是赵云在危机中持续组织。

### 最终结果

第四十二回，赵云到达刘备处，把阿斗从怀中取出并亲手交还刘备。

因此：

```text
外部托付：保护刘备老小
↓
局部路径：大量自主变化
↓
最终结果：仍把阿斗带回刘备
```

上位任务终点没有被主体改成相反方向。

## 2｜nx 判断

### 上位任务层：成立

`nx` 在本轮不是“赵云没主见”。

赵云显然拥有大量自主判断，甚至在失散后自己决定搜索、折返、突围。

但在本轮锁定的上位对象层：

```text
最终托付目标：保护刘备家小
来源：刘备集团既有分工
赵云是否重设为另一个最终目标：没有
赵云是否最终沿该方向完成：是
```

因此锁：

`nx_upper_task_endpoint_continuity: evidence-locked`

这只证明当前行为功能/关系位置，不证明赵云稳定人物本体为纯 nx。

## 3｜xn 最近邻

本轮最强最近邻是 `xn`。

赵云没有机械执行一条固定路线。他必须不断：

- 搜索信息；
- 选择方向；
- 分开“先送甘夫人”和“再折返找阿斗”的阶段；
- 根据敌情调整突围路径；
- 调整局部资源和人员。

因此：

> `xn` 解释“赵云怎样在失控环境中重新组织完成任务的过程”。
>
> `nx` 解释“为什么这一整套自主组织仍服务于外部既定的上位终点”。

二者对象层不同，可以同时存在。

## 4｜zx 检查与污染冻结

赵云在长坂坡有大量强烈战斗行为，甚至曹操看到其勇猛后下令不得放冷箭、要活捉赵云。

这些可以形成 `zx` 行为/状态污染，不能假装不存在。

但本轮的问题不是“赵云战斗是否有 zx 显影”，而是：

> **执行过程高度自主，是否就足以推翻上位任务层的 nx？**

冻结战斗传奇性，只保留：

```text
外部托付目标
→ 主体自行组织搜索与护送
→ 最终把阿斗交还刘备
```

上位 `nx` 结论仍成立。

因此本轮不以战斗 zx 作为主判，也不由战斗强度反推稳定人物 zx。

## 5｜拿掉测试

### 拿掉战斗能力

假设赵云不是绝世武将，只要仍存在：

```text
外部给定保护任务
→ 失散后主体自行想办法
→ 最终仍完成同一托付终点
```

上位 nx 仍成立。

### 拿掉具体搜索路线

无论先找谁、从哪条路走，只要主体没有改写最终托付方向，局部路线变化不能单独打掉上位 nx。

### 拿掉刘备的托付

如果不存在“赵云保护老小”的既有分工，而完全由赵云自己第一次提出“我要救阿斗并把他送给刘备”，那么本轮上位 nx 的证据会明显下降，应重新检查主体自生方向与 `xn/zx/nz`。

## 6｜反向测试

### 反向成朱仝式结果否决

如果赵云表面继续执行保护任务，但真正找到阿斗后主动决定不把阿斗交还刘备，而带往别处、交给第三方或另设最终去向，那么上位终点被主体实际改写，nx 应下降或排除。

### 反向成更纯 nx

如果赵云失散后停在原地等待刘备逐步告诉他去哪里找、先救谁、怎么撤离，且自己不组织新运行方式，则 `xn` 大幅下降，行为更接近纯 nx 执行。

### 反向成 zx 主判

如果赵云借这次行动取得此前不存在的、可稳定独立调用的更高组织决定权，并使刘备集团以后围绕这一新增权力接口运行，才应进一步锁 zx 扩权。

## 7｜与朱仝案例的最小差异

### 朱仝私放雷横

```text
外部方向：押送雷横到济州
→ 表面沿流程
→ 最终主动放走雷横
→ 关键终点被改写
→ nx最终结果层排除
```

### 赵云长坂救阿斗

```text
外部方向：保护刘备老小
→ 执行过程大量自主重组
→ 最终把阿斗交还刘备
→ 关键终点保持
→ 上位nx可继续成立
```

因此本轮锁住：

> **判定 nx 时，不能把“执行过程是否自主”与“最终方向是否被主体改写”混成一个问题。**
>
> 局部运行自主可以让 `xn` 上升；只有主体真正改写同一对象层的最终方向/结果，才直接削弱该层 nx。

## 8｜第三因素冻结

以下全部不作为木轴主判：

- 赵云武力高低；
- “单骑救主”英雄主题；
- 曹操是否欣赏赵云；
- 阿斗后来历史评价；
- 糜夫人投井；
- 张飞是否怀疑赵云投曹；
- 战斗胜负与杀敌数量。

冻结这些后，仍只看：

```text
谁给上位任务？
主体是否自行改写最终终点？
局部运行方式是谁组织？
最终结果是否仍沿原终点完成？
```

## 9｜结论

- 事实置信：99
- 分类置信：97
- `nx`：上位任务终点续接，evidence-locked
- `xn`：局部运行自主，neighbor evidence-locked
- `zx`：存在战斗行为污染，但不是本轮端点主判
- 稳定人物本体：不锁
- 严格 `zx↔nx` 补关系：不锁

本轮不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
