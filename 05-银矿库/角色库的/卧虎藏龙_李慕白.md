# 李慕白
> 归档：`05-银矿库/角色库/卧虎藏龙_李慕白.md`

---

## 1. 主十元判断

**主十元：zn（阳火·意义/信仰）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zn，李慕白就是一个武当山上的高手——剑法好、名气大、无欲无求。但李慕白不是无欲无求的，他**一生都在跟自己打：** 想要得道的是他，放不下俞秀莲的也是他。「道」这个东西如果对他不重要，他根本不会痛苦。zn在他身上不是一种品质，是一种**持续了一辈子的自我质问**——「我到底该做人还是做道？」
- **第2问（反复面对什么结构）：** 反复面对「握剑还是放下」。每次他以为自己可以放下了（把青冥剑送给贝勒爷），又会被拉回来。不是江湖不放他，是他自己放不下那个「我还没走完这条路」的感觉。
- **第3问（最怕失去什么）：** 最怕「这辈子没有真正活过」。所以他最后一刻说出了那句话——不是破戒，是他终于选了做人不做道。
- **第4问（回到哪个感觉）：** 回到「我选了」的感觉而不是「我做到了」——临终的释然不是因为剑法大成，是因为他终于承认了自己是一个人。
- **第5问（副十元服务谁）：** z（被点燃的冲动）是zn的出口——他的zn（道/意义）压了他一辈子，最后是z（对俞秀莲的情感冲动）替他做了决定。z帮zn找了一条活路。

## 2. 副十元

**副十元：z（阴火·执念/被看见）**

**作用：** 李慕白的z是他一生都在压但压不住的东西——他对俞秀莲的感情，他在竹林上与玉娇龙对峙时那一瞬间的认真。z在他身上是「我想被看见，作为一个活人而不是一座雕像被看见」。

## 3. 功能十元

**功能十元：无显著。**

## 4. 视觉十元

**视觉十元：x并z（阴木·包装/身份）。** 长衫、青冥剑、武当掌门的身份——这些都是视觉包装。换掉这些，他的核心还在。

## 5. 动态链

```
zn（主·一生在追问「做人还是做道」）
  → z（副·对俞秀莲的感情压了一辈子）
  → x并z（视觉·大侠的包装）
  → 送出青冥剑→被拉回江湖→中毒→说出那句话
  → 「我选了」
```

## 6. 一句话定型

李慕白不是「得道的大侠」，而是「**一辈子都在想自己该不该做一个人**的人」。

## 旧卡修正记录

**旧定位（双人卡）：** 本体型 zn+x（和俞秀莲一起）
**新定位：** zn（主·意义/信仰）+ z（副·执念）
**修正理由：** 旧卡把李慕白理解为一个「知道什么是道但无法成为道」的zn核心，这个判断是对的。但旧卡把他的困境归结为x（欲望），这不够精确——他对俞秀莲的感情不是x（深欲/占有），是z（被看见的执着）。他最后说出那句话，不是因为欲望压不住了，是因为他终于愿意被一个人看见了。
