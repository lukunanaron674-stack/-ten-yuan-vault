# 三国演义｜诸葛亮智激孙权｜zx-nx 外部裁决者游说压力测试

## 结论摘要

本桥段锁定：**诸葛亮自身有明确联吴抗曹方向，但“东吴是否出兵、是否与刘备联合”的最终军政裁决权仍在孙权。诸葛亮通过鲁肃引介、江东政治接口和对孙权的游说推动结果，因此 `nx` 在关系功能 / 权限位置层成立；其言辞强烈、成功改变孙权判断，并不等于诸葛亮取得了东吴出兵裁决权，所以高纯 `zx` 在这一窄变量上排除。**

这不是“诸葛亮没主见”。稳定本体不锁。

## 1｜剧情事实

1. 曹操南下，孙权收到曹操檄文，江东内部对战与降仍在争议中，孙权本人对如何应对尚未形成稳定执行路线。
2. 鲁肃把诸葛亮引入江东政治现场；诸葛亮先与张昭等群儒交锋，再进入与孙权的直接谈判。
3. 诸葛亮通过激将使孙权重新请其入后堂详谈，并进一步分析曹军远来疲惫、不习水战、荆州人心未附等条件，提出孙刘协力抗曹路线。
4. 诸葛亮最后明确把最终裁定留给孙权，以“惟将军裁之”收束。
5. 孙权随后表示自己主意已决，将商议起兵共灭曹操，并命鲁肃把此意传达文武。

对象层必须保持清楚：

```text
诸葛亮的战略方向：联吴抗曹
东吴是否出兵的最终权限：孙权
诸葛亮的现实推进方式：进入鲁肃—孙权既有政治/权限网络并游说
最终吴国内部命令接口：仍由孙权发出
```

## 2｜zx / nx 分类

### nx 关系功能：成立

符合现行 nx 的关系功能定义：

```text
我自己知道希望事情往哪里走
↓
但关键权限不在我
↓
我必须进入已有身份、关系与权力接口
↓
说服真正掌权者
↓
由掌权者调用其权限完成推进
```

诸葛亮不能直接命令东吴起兵，也不能自行调用孙权军队。他必须通过鲁肃进入吴廷，并把方案提交给孙权裁决。因此锁：

- `nx_current_relation_function: evidence-locked`
- `nx_relation_position: evidence-locked`

### 高纯 zx：排除

诸葛亮的言辞具有强烈主动性，甚至成功使孙权改变判断；但现行 zx 的硬门不是“我让别人改变主意”，而是**我的自身权能成为新的公开决定来源，主体决定范围/位置真实扩大**。

本段中：

- 东吴军政最高裁决权没有转移给诸葛亮；
- 孙权仍可以裁、可以不裁；
- 起兵命令仍由孙权发出；
- 诸葛亮没有获得一个可独立调用的“东吴出兵决定接口”。

因此：

`zx_in_narrow_decision-variable: rejected`

## 3｜关键压力

关键压力是曹军南下与东吴内部降战分歧。诸葛亮必须让自己的战略方向通过一个**不归自己掌握的东吴最终裁决接口**才能落地。

压力没有把他变成“无主见”；反而更清楚地暴露：

```text
方向可以来自自己
≠
最终作用权也一定在自己
```

## 4｜拿掉测试

### 拿掉诸葛亮的雄辩与激将戏剧性

只保留：

```text
刘备方希望联合东吴
→ 东吴出兵权属于孙权
→ 诸葛亮必须进入吴廷说服孙权
→ 孙权批准后才能形成吴方行动
```

`nx` 权限关系功能仍成立。

### 拿掉最终孙权真的同意这一胜负结果

即使孙权最后拒绝，只要诸葛亮仍处于“必须通过孙权权限接口请求吴国出兵”的结构，`nx` 关系位置仍成立；结果成功不是 nx 判据。

### 拿掉鲁肃这个具体中介

若换成另一名能把诸葛亮带到孙权面前的吴臣，只要真正最终裁决权仍在孙权，结构不变。鲁肃是入口，不是 nx 本体本身。

## 5｜反向测试

### 反向成 zx

若诸葛亮在吴廷中取得此前不存在的独立军政决定位置，可直接命令吴军出兵，孙权与江东群臣反而必须围绕诸葛亮新增的决定接口运行，则 `zx` 才明显上升。

### 反向成 x

若东吴军队本来就属于诸葛亮长期处分，他只是调用自己已有兵权，则应优先检查 `x`，而不是 nx 或新扩权 zx。

### 反向成 xn

若最终目标由别人给定，而诸葛亮的核心贡献只是设计谈判流程、时间节点、人员分工，主变量才应转向 `xn`。本段确有话术与策略组织，但它不能消除“东吴出兵权限仍在孙权”这一 nx 核心变量。

## 6｜最近邻排除

### nx vs xn

诸葛亮明显有策略设计，尤其知道“孙权只可激不可说”，因此 `xn` 邻近真实存在。

但拿掉激将技巧和话术结构后，他仍必须通过孙权这个外部军政裁决接口；所以：

- `xn` 解释“怎么说服”；
- `nx` 解释“为什么必须说服这个掌权者，而不能自己直接决定”。

### nx vs x

孙权的军队、吴国的战和权限不属于诸葛亮处分，因此不是 x。

### nx vs zx

诸葛亮影响了最终决策，却没有成为最终决策者。**影响权限主体 ≠ 取得权限。**

### 第三因素冻结

冻结以下因素后结论仍成立：

- 诸葛亮“神机妙算”人物印象；
- 舌战群儒的戏剧性；
- 孙权性格；
- 曹操兵力夸张；
- 赤壁最终胜负；
- 刘备、诸葛亮的历史/道德评价。

只看“谁拥有吴国出兵裁决权、谁需要通过谁”，仍是 nx 关系功能。

## 7｜与既有吕布辕门射戟案例的最小差异

### 吕布辕门射戟

```text
原双方路线冲突
→ 吕布自己建立新的裁决规则
→ 双方接受并按其结果停战
→ 吕布临时成为新的实际裁决中心
= zx
```

### 诸葛亮智激孙权

```text
诸葛亮有明确抗曹方向
→ 但吴国是否起兵仍由孙权裁决
→ 诸葛亮进入既有政治接口游说
→ 孙权本人作出并发布决定
= nx关系功能
```

因此锁定案例级边界：

> **“我成功影响了有权的人”不等于“我成为了有权的人”。**
>
> 通过真实掌权者让方向落地，优先检查 `nx` 关系功能；只有主体自身取得并公开扩大决定接口，才进一步检查 `zx`。

## 8｜层级结论

- 人物稳定本体：不锁。
- 当前战略方向：诸葛亮自主生成/保持。
- 当前行为功能：主动游说。
- 当前关系位置：东吴出兵权限在孙权，诸葛亮沿吴廷既有接口推进，`nx` 成立。
- zx：在“吴国出兵最终裁决权”这一窄变量上排除。
- xn：话术/谈判组织邻近存在，但不是木轴主判。
- 严格 zx↔nx 补关系：不锁。本例只证明 nx 权限通道，不证明两端互补缺口被反复改善。
