# 珊（San）
> 归档：`05-银矿库/角色库/幽灵公主_珊.md`

---

## 1. 主十元判断

**主十元：xz（阴木·被推着走/找不到归处）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉xz，珊就是一个保护森林的女战士——很纯粹、很坚定。但珊最核心的不是"她是战士"，是**她不知道自己是人还是狼**。她不属于铁镇，也不完全属于森林。她咬断绳索、砍黑帽大人、最后拒绝阿席达卡——不是因为她恨，是因为她不知道该去哪。
- **第2问（反复面对什么结构）：** 反复面对「我该站哪边」。人类不认她（遗弃），狼族给了她身份但不是她的族（她是人）。她每次战斗都在问同一个问题：我到底是谁？
- **第3问（最怕失去什么）：** 最怕「两边都不要我了」。被人类遗弃过一次，她不能再被森林遗弃。所以她对阿席达卡的示好反复推开——不是不爱，是不敢再信。
- **第4问（回到哪个感觉）：** 回到「妈妈（莫娜）还在、我属于这里」的那一刻。在山兽神被砍头之前，她还有一个可以回去的地方。
- **第5问（副十元服务谁）：** z（想被看见）是xz的出口——她希望阿席达卡"看到"她不是怪物。最后她选择留在森林，但阿席达卡那句"我会住在铁镇，你偶尔来看我"——她知道有人看见她了，这就够了。

## 2. 副十元

**副十元：z（阴火·想被看见）**

**作用：** 珊的愤怒不只来自仇恨，来自"你没看到我也是人"。阿席达卡说"你好美"——不是赞美容貌，是这句话戳进了她的z。她一直以为别人只看到"狼女"、"幽灵"、"怪物"，阿席达卡是第一个看到她的人。

## 3. 功能十元

**功能十元：n（阳火·承载/扛）——表层行为。** 她用战斗来承载身份的焦虑。打铁镇、挡炮弹、护森林——这些是她的动作，不是她的底层。

## 4. 视觉十元

**视觉十元：xn（阴土·规则内找路）。** 狼皮面具、武器、吼叫——这些都是她在两个世界的规则之间找到的生存方式。

## 5. 动态链

```
xz（主·被两个世界推着走/不知道归处）
  → z（副·想要有人看见我）
  → n（功能·战斗是她的承载方式）
  → 被遗弃→被狼收养→遇见阿席达卡→选择留下
  → 仍然不知道归处，但知道有人看见了她
```

## 6. 一句话定型

珊不是「自然的守护者」，也不是「复仇的幽灵」，而是「**不知道归处但停不下来**」的人。

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**修正1：** xz（主）+ z（副）→ 命运型
**最终定位：** xz（主·被推着走/不知归处）+ z（副·想被看见）→ 命运型
**最终修正理由：** 原卡xz正确，但副十元nz（希望那个人也在）不是珊的核心。她的深层驱动不是"希望那个人也在"（nz），是"我希望你看见的是我而不是我的面具"（z）。阿席达卡的角色定位不是她等待的人，而是她敢于卸下武装的唯一窗口。
