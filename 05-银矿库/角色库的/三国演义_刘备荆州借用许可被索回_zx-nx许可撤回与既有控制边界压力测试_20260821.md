# 《三国演义》刘备｜荆州借用许可被索回后的 zx-nx 权限撤回压力测试

## 1｜事实窗口

《三国演义》第52回以后，东吴与刘备集团围绕荆州形成了“借住/暂占、以后归还”的明确关系框架。鲁肃与诸葛亮谈判时，已经把“刘琦在则暂守、刘琦不在则另议归还”作为现实条件；到第56回，孙权更直接以“昔日保借荆州与刘备，今迁延不还”为由，命鲁肃再来索取。

第56回鲁肃到荆州时，刘备并没有因为东吴重新索还而立即交割。相反，刘备、诸葛亮继续维持荆州现有军政控制，并以取西川等理由延缓归还。与此同时，荆州城内已经出现广聚粮草、调练军马、远近之士归附的稳定控制事实。

本轮只测试一个窄问题：

> 原先存在的外部借用许可 / 保借接口被东吴明确收回以后，刘备当前对荆州的实际控制是否立即消失？这时应判 nx、x 还是 zx？

## 2｜最小结构

```text
前一阶段：
荆州借用 / 暂占关系需要东吴同意与鲁肃作保
= nx 外部许可关系

本阶段：
孙权明确索还
→ 原借用许可被撤回 / 终止

但：
刘备集团仍实际控制荆州城池、军队、粮草与政务
→ 当前调用边界没有立即退出
= x 仍在

同时：
刘备只是继续维持既有控制
没有证明其决定范围在此刻继续扩大
→ zx 不自动成立
```

## 3｜nx 判断

正式锁定：

`nx_prior_borrowing_permission_relation: evidence-locked`

`nx_borrowing_permission_withdrawn: evidence-locked`

这里的 nx 不表示刘备“没主见”。

前一阶段真正外置的是：

> 荆州以何种合法 / 联盟关系继续由刘备集团占用。

东吴作为原借出 / 保借一侧，拥有真实的许可与索还位置；鲁肃也承担现实中介与担保功能。因此这一层属于 nx 关系功能：刘备的现实立足点曾经需要借助东吴已有联盟、土地与许可接口。

第56回孙权明确要求索还，说明这个外部许可不是永久不可撤回的背景，而是一个真实可终止的关系端点。

## 4｜x 判断

正式锁定：

`x_current_territorial_control_persists: evidence-locked`

许可被索回以后，刘备集团并没有立刻失去：

- 荆州城池；
- 驻军；
- 粮草；
- 人员归附；
- 当前军政调用边界。

所以必须区分：

```text
外部许可是否仍存在
vs
对象是否已经进入主体当前稳定控制边界
```

前者在本阶段下降，后者仍然存在。

这说明：

> **nx 许可接口撤回，不会机械地让已经形成的 x 当前控制在同一瞬间消失。**

## 5｜zx 判断

正式排除：

`zx_in_revocation_stage: rejected_as_primary`

刘备拒绝立即归还、继续占据荆州，不能仅凭“坚持自己的方向”就判 zx。

本阶段没有看到新的：

- 决定范围继续向外扩大；
- 新的更高军政权限被公开夺取；
- 东吴或其他秩序承认一个新增的刘备决定接口；
- 原有控制边界在本窄窗口继续上升。

所以本阶段更准确的是：

> **已有 x 继续保持，原 nx 许可关系失效。**

而不是：

> **nx 一撤回，刘备坚持不还，因此自动变 zx。**

## 6｜关键压力

关键压力只有一个：

> 东吴从“允许 / 保借 / 暂借”转为“明确索还”。

它把三个对象层强行分开：

1. 合法 / 联盟许可是否继续；
2. 实际控制是否继续；
3. 主体决定范围是否继续扩大。

只有第三项出现真实上升，才继续检查 zx。

## 7｜拿掉测试

### 7.1 拿掉东吴索还

如果东吴继续允许刘备暂占，那么本轮“nx 许可撤回”压力消失，但刘备对荆州的 x 当前控制仍可存在。

说明许可与控制是两个变量。

### 7.2 拿掉刘备当前实际军政控制

如果孙权一索还，刘备集团便立刻撤军、交城、失去军政调用，那么 `x_current_territorial_control_persists` 不成立。

本轮之所以能锁 x，正因为现实控制并未随许可撤回同步退出。

### 7.3 拿掉“坚持不还”情绪与台词

只保留客观结构：许可被索回，但当前城池、军队、粮草仍由刘备集团持续控制，x 结论仍成立；zx 仍不能凭空出现。

## 8｜反向测试

### 8.1 反向成持续 nx

```text
孙权索还
→ 刘备承认东吴最终许可位置
→ 按索还要求交割城池
→ 当前占用继续沿外部许可决定
= nx 上升，x 退出
```

### 8.2 反向成 zx

```text
原本只是借用荆州
→ 东吴索还
→ 刘备公开把控制边界继续推出原借用范围
→ 新增占领 / 决定范围被现实秩序重新承认
= 才继续检查 zx
```

当前第56回窄窗口不足以锁这一层。

### 8.3 反向成纯 x

如果完全拿掉东吴曾经的保借 / 索还关系，只保留“荆州已稳定归刘备集团军政处分”，则更接近纯 x 当前控制，不再承担 nx 许可撤回压力测试。

## 9｜最近邻排除

### nx vs x

- `nx`：原借用合法性 / 联盟许可在东吴手里。
- `x`：城池、军队、粮草和当前调用边界已经在刘备集团手里。

同一对象可以在不同层同时出现“许可外置”与“现实控制内置”。

### x vs zx

- `x`：已经掌握并继续使用。
- `zx`：公开显权、扩权，决定位置继续上升。

本阶段主要是维持已有控制，不足以证明扩权。

### nx vs xn

刘备、诸葛亮如何拖延、解释、安排答复存在 xn 邻近，但这些只回答“怎样应对索还”，不回答荆州许可与控制到底属于谁。

## 10｜第三因素冻结

冻结：

- 刘备是否仁义；
- 东吴索还是否道德上合理；
- 历史上“借荆州”叙事是否完全符合史实；
- 周瑜、鲁肃、诸葛亮个人评价；
- 后续单刀赴会与荆州最终失守；
- 刘备后来是否取得益州。

本轮只按《三国演义》文本内部事实判断：

1. 是否存在外部借用 / 保借许可关系；
2. 该许可是否被东吴明确索回；
3. 许可撤回时，刘备集团现实控制是否同步退出；
4. 当前决定范围是否继续扩大。

答案分别为：是 / 是 / 否 / 未证明。

## 11｜严格 zx↔nx 补关系复核

不锁：

`strict_zx_nx_complement_locked: false`

原因：本轮研究的是许可状态与现实控制状态分离，并没有同时证明高纯 zx 端与 nx 端形成双向缺口修复。

尤其不能把：

> 刘备不还荆州 + 东吴曾经借地

机械焊成严格 zx↔nx 补关系。

## 12｜结论

本阶段正式锁为：

> **东吴索回荆州 = 原 nx 借用许可关系被撤回；但刘备集团对荆州的现实军政控制仍继续，因此当前更接近 x 持续，而不是许可一撤回就使控制自动消失，也不是“坚持不还”自动升级为 zx。**

最短机制：

```text
许可在外
= nx关系

许可被撤回
≠
现实控制立即消失

现实控制仍在
= x

只有决定范围继续公开扩大
才继续检查 zx
```
