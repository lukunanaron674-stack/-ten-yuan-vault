# 《三国演义》诸葛亮｜zx↔nx 木轴压力测试

## 结论先行

本轮锁定一个重要的木轴反例：

> **“接受托孤、忠于先帝留下的大方向”不能直接判 `nx`。**

在第八十五回“五路伐蜀”这一窄阶段，刘备确实把“辅后主、安邦定国”的上位任务托付给诸葛亮；但魏军五路压境后，具体问题如何拆分、谁守哪一路、何处用疑兵、何处用书信、何处只守不战、如何设置救应、怎样处理东吴一路，全部由诸葛亮主动组织并形成跨步骤运行结构。

因此：

```text
外部给出上位目标（辅后主、保蜀）
≠
外部给出解决方向与通道

诸葛亮自己拆问题
→ 自己配置人员、路线、书信、疑兵、守关、救应
→ 多路行动按他的结构同时运行
→ 再挑选邓芝完成东吴外交接口
= xn 高显影
```

本例对 `nx` 的价值不是正例，而是**高置信边界反例**：

> **听命、忠臣、承接遗志、在既有政权中办事，都不足以判 nx；只要主体仍掌握“事情具体怎样持续运行”的组织权，就必须优先检查 xn。**

本轮不把诸葛亮稳定人物本体直接锁成 `xn`，也不把本段强行写成 `zx+nx`。

---

## 1｜原始事实

### 触发一：白帝托孤

刘备临终明确把后主与国家大事托付诸葛亮，并要求其辅佐刘禅。诸葛亮接受托付，承诺尽忠。

这一事实只能证明：

- 上位政治目标来自先帝遗命；
- 诸葛亮承认既有君臣与政权关系；
- 不能仅凭“听先帝的话”直接判 `nx`。

### 触发二：魏军五路犯蜀

刘禅即位后，魏方组织五路兵马攻蜀。朝臣慌乱，后主亲自到相府求计。

### 诸葛亮的明确动作

诸葛亮说明自己已经提前处理四路，并继续处理第五路：

1. 针对羌兵一路，预先令马超守西平关，并设四路奇兵轮换；
2. 针对南蛮一路，令魏延以左右往复的疑兵方式制造不确定；
3. 针对孟达一路，利用孟达与李严关系，伪作李严书信使其推病不进；
4. 针对曹真一路，调赵云守阳平关，坚持不出战，以守待退；
5. 另调关兴、张苞各领兵作为多路救应；
6. 对东吴一路，不立刻硬碰，而是判断孙权会观察其余四路成败，再决定需要一名能言之士出使；
7. 从群臣中识别邓芝，次日奏准后主，派其出使东吴。

### 可观察结果

多个不同对象、不同时间窗口、不同资源与不同处理方法，被诸葛亮组织成同时运转的防御结构；后主此前不知道细节，朝臣也没有给出这套解决通道。

因此本段被改变的核心变量不是“是否服从先帝”，而是：

> **谁主动决定这场危机具体怎样跨步骤、跨人员、跨路线持续运行。**

## 2｜为什么不是 nx 主证据

现行 `nx` 要求：

```text
方向、权限或解决通道已经由别人、关系、流程或现状给出
→ 主体不占最终方向决定位置
→ 沿已有通道继续
```

本段只满足最表层的一项：诸葛亮承接了刘备留下的上位目标。

但关键的“解决方向与通道”并没有由刘备、刘禅或朝廷预先给出：

- 没有人告诉诸葛亮五路分别怎样退；
- 没有人给出马超、魏延、李严、赵云、关兴、张苞的组合方案；
- 没有人给出疑兵、伪书、闭关不战、预备救应这一组运行方法；
- 东吴一路的判断与邓芝人选也是诸葛亮自己形成。

因此：

> **“目标来自别人”不等于“方向与通道来自别人”。**

如果把“承接遗命”直接判成 `nx`，会把大量主动组织者、总负责人、项目负责人错误吸进 `nx`。

---

## 3｜为什么 xn 高显影

现行 `xn` 的必要骨架是：主体主动组织时间、计划、流程、资源、节点与分工，使分散行动形成可持续运行结构。

本段逐项命中：

- **主动组织**：诸葛亮不是等后主逐项下令，而是在朝臣未知时已先行部署；
- **多对象分工**：马超、魏延、李严／孟达、赵云、关兴、张苞、邓芝各承担不同功能；
- **多路径结构**：守关、疑兵、书信、救应、外交不是同一种动作重复；
- **时间与节点**：羌兵轮换、曹真长期不战待退、东吴观察四路结果后再动，均包含时间判断；
- **跨阶段保存**：安排在后主亲临相府之前已经启动，并继续影响之后各路局势。

所以这不是“军师身份=xn”，而是原文直接给出了一套由主体主动搭建的运行结构。

---

## 4｜zx 在本段的位置

本段存在 `zx` 局部候选，但不足以把整个窄阶段判成“纯 zx”或稳定 `zx+nx`：

### 支持 zx 的部分

- 诸葛亮实际占据危机解决方向的最高来源；
- 后主与群臣最终围绕他的判断重新行动；
- 他选择邓芝并推动出使方案进入现实。

### 为什么不把 zx 锁成主证据

本段最强、最独立、最反复的可观察变量是“组织多路运行结构”，不是当下公开显权、扩权、以自身权能正面压退竞争方向。

大量关键部署甚至刻意隐藏于朝臣和后主之外。

所以本轮采取窄结论：

```text
xn = 高显影，97
zx = 局部状态/关系位置候选，不升级为本轮主分类
nx = 在“五路危机解决方式”这一窄阶段被排除
```

---

## 5｜伪 zx+nx 为什么容易出现

如果只看人物叙述，很容易这样误判：

```text
诸葛亮有巨大权能、决定军事方向 → zx
同时忠于先帝、辅后主、接受遗命 → nx
所以 zx+nx
```

问题在第二步。

“忠于先帝”说明的是目标、伦理与政治关系来源；`nx` 要求的是**最终方向或解决通道不由主体建立**。

本段恰恰相反：解决结构主要由诸葛亮建立。

因此本例是一个有用的伪对子反例：

> **外部目标 + 主体自主组织，不自动构成 nx；必须继续问“具体解决通道是谁建立的”。**

---

## 6｜最近邻排除

### nx vs xn

这是本轮最重要的最小差异：

```text
nx：老板不仅给目标，而且已有方向/通道，我沿着走。
xn：老板只给目标，我自己拆步骤、排人、设节点、搭运行方式。
```

五路危机明显更接近第二种。

### nx vs zx

诸葛亮并非在本段“把最终方向交出去”。相反，危机处理方向高度集中于他。

但本段仍不以 `zx` 为主，因为核心证据是多路组织而不是公开扩权。

### xn vs x

诸葛亮拥有很高实际权限，但本例不是因为“资源归他掌握”才判；关键证据在于他如何主动配置与组织这些资源持续运行。

### xn vs z

后主对诸葛亮的尊重、称“相父”不是本轮变量。拿掉认可与称谓，多路组织结构仍然成立。

---

## 7｜拿掉测试

### 拿掉“先帝遗命”

假设同样的五路危机发生在没有白帝托孤背景的政权中，只保留：

```text
主体自己拆五路
→ 分配不同将领
→ 设计不同策略
→ 设置轮换、等待、救应与外交节点
```

结果：`xn` 仍高度成立。

说明“托孤”不是 xn 分类来源。

同时，这也削弱“因为承接遗命所以 nx”的误判。

### 拿掉丞相职位

若主体没有“丞相”称号，但仍实际完成上述跨路组织、资源配置和节点设计，`xn` 仍成立。

### 拿掉最终成功

即使五路中有一路失败，只要这套主动组织结构真实存在，`xn` 仍可成立；胜利不是分类条件。

## 8｜反向测试

若把本桥段改写为：

```text
刘禅／刘备遗诏已经逐项写好：
马超守哪里、魏延怎样疑兵、赵云如何闭关、谁给孟达写信、谁出使东吴
→ 诸葛亮只照既定部署执行
```

则 `xn` 会显著下降，`nx` 会明显上升。

若改成：

```text
后主只说“保住蜀国”
→ 诸葛亮仍自己搭全部运行结构
```

则与原文结构相近：`xn` 仍高，不能因为目标由君主给出就判 `nx`。

---

## 9｜第三因素冻结

### 忠诚

忠臣身份不是 nx 判据。忠诚回答“为什么接受目标”，不回答“具体方向与通道由谁建立”。

### 官职与制度

身处君臣制度不自动等于 nx。必须看主体是否只是沿既有制度通道推进。

### 智谋

聪明、多谋也不是 xn 判据；只有当智谋落实为时间、流程、分工、资源、节点的可持续组织时，才支持 xn。

### 战争胜负

能退五路不是分类理由；如何组织退五路才是。

### 刘备遗命

遗命提供上位目标与责任边界，是本段最容易造成 nx 误判的第三因素，必须与“解决通道来源”分开。

## 12｜对木轴研究的新增价值

前两轮得到：

```text
贾迎春：
有自主窗口仍不成为方向源
→ nx 正例

鲁达：
自己生成公开冲突方向并直接施力
→ zx 正例
```

本轮补上最关键的第三类：

```text
诸葛亮：
接受别人给的上位目标
但具体方向、流程、人员、节点全部自己组织
→ 不能判 nx
→ 优先 xn
```

于是木轴的一个误判防线可以暂时写成研究结论：

> **判断 nx 时，不能只问“目标是谁给的”，必须问“最终方向与解决通道是谁建立的”。**

目前只有本轮一个四大名著高置信反例，不升级十元核心定义；等待至少另外两部独立作品出现同类结构后，再考虑形成跨作品待审议问题。
