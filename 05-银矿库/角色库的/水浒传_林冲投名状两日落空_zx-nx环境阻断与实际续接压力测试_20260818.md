# 水浒传｜林冲投名状两日落空｜zx↔nx 环境阻断与实际续接压力测试

## 1｜剧情事实

王伦把“取得投名状”设为林冲加入梁山的准入条件，并限定三日。

第一日，林冲按条件下山，从朝至暮等待，没有遇到一个适合下手的孤单客人；他因此未能取得投名状，当晚返回山寨。

第二日，林冲清早再次主动带刀下山，换到南山路继续等待。午间虽有三百余人结队经过，但不构成可行目标，林冲没有贸然出手；当天仍未完成投名状，再次回寨。

文本因此连续展示：

```text
外部任务仍然存在
→ 第一天因环境无目标而未完成
→ 次日仍再次进入同一任务
→ 第二天仍因目标条件不合而未完成
→ 任务终点没有被林冲主动改写
```

## 2｜nx 判断

### nx_actual_continuation_behavior: evidence-locked

这一段不能把“没有完成任务”误写成“没有续接外部方向”。

林冲两日均实际下山、等待目标，并保持“完成王伦投名状条件以取得梁山准入”的同一终点。第一日无孤单行人，第二日遇到的是数百人结队；失败首先来自环境条件，而不是林冲主动否定任务。

因此本轮锁定：

> **实际续接与实际完成必须分开。**
>
> nx 行为功能要求主体仍沿外部方向推进，但不要求每一个执行窗口都成功完成；如果失败来自环境、资源或机会缺失，而主体没有主动改写终点，并在后续窗口继续沿原方向推进，不能仅凭“本次没做成”排除 nx。

这只锁当前行为功能 / 关系位置，不锁林冲稳定人物本体。

## 3｜zx 判断

### zx_in_narrow_stage: rejected_as_primary

林冲第二日面对三百余人没有贸然出手，也没有因为任务受阻而夺取梁山准入权、改写王伦规则或迫使山寨围绕自己的新增决定接口运行。

因此：

```text
任务失败
≠ zx
再次尝试
≠ zx
武力强但选择不打三百人
≠ zx
```

本段缺少 zx 所需的公开扩权与决定位置上升。

## 4｜关键压力

关键压力是：

- 三日期限；
- 合适目标并不由林冲控制；
- 第一日完全无孤单客人；
- 第二日只有不适合下手的大队客人。

这些压力使本例适合区分：

```text
A. 环境阻断：我仍想做、仍沿原终点推进，但暂时没有可执行条件。
B. 主体否决：我主动停掉、改掉或伪造原任务结果。
```

A 不能当成 B。

## 5｜拿掉测试

### 拿掉王伦后续催促
即使不使用王伦当晚的追问作为证据，只保留“第一日未遇目标 → 第二日清早林冲再次下山继续寻找”，仍能证明第一次未完成不等于主体退出。

### 拿掉三日期限
如果仍然存在“准入条件在外部、林冲第一次因环境失败后继续沿同一条件推进”，nx 实际续接结构仍成立；期限只提高压力。

### 拿掉林冲武力
只保留“外部准入条件 → 环境暂时无法满足 → 主体继续尝试”，结论不变。

## 6｜反向测试

### 反向成“实际不续接”
如果林冲第一日回来后主动决定不再做投名状，第二日不再下山，或者另行伪造已完成结果，则同一执行层 nx 应下降或排除。

### 反向成 xn
如果林冲在失败后主动重建整个准入方案、改写目标、设计新的组织路径，并以自己方案替换王伦条件，应转查 xn。

### 反向成 zx
如果林冲因王伦条件受阻而公开夺取准入处分权、迫使梁山承认新的决定接口，才检查 zx。

## 7｜最近邻排除

### nx vs xn
林冲第二日换到南山路等待，只是局部执行路线变化；投名状的目标、准入逻辑和三日条件仍由王伦设定，不能把“换一条路找目标”夸大成主体重建运行结构。

### nx vs x
梁山准入权没有转到林冲手里。

### nx vs zx
坚持继续完成外部条件，不等于自身权能扩大。

## 8｜第三因素冻结

冻结以下因素后结论不变：
- 林冲是否英雄、是否悲情；
- 是否擅长武艺；
- 王伦是否嫉贤妒能；
- 最终是否遇到杨志；
- 后续是否火并王伦；
- 三百余人是否理论上能打赢。

只保留：

```text
任务终点是谁给的？
失败原因来自环境还是主体否决？
主体下一窗口是否仍沿原方向推进？
```

## 9｜与“承接入口 vs 实际续接”待审议的关系

现有待审议已经证明：
- 口头接受后实际违背，不能锁执行层 nx；
- 入口拒绝后条件冻结、最终实际跟随，后段 nx 可以成立。

本例补充第三种必须分开的情况：

```text
入口接受
→ 实际尝试
→ 因环境条件不具备而失败
→ 后续再次实际尝试
```

这种“未完成”不是“实际不续接”。

候选限制：

> **判断 nx 的实际续接时，应优先区分“主体主动否决/改写”与“环境导致暂时未完成”。只有前者能直接构成同对象层 nx 的反证；后者若伴随持续重试，反而支持方向连续性。**

本条只作为案例级证据，不修改 L1、zx/nx 信息卡、准度卡或 zx补nx 补卡。

## 10｜结论

- nx 当前实际续接行为：evidence-locked
- 环境阻断不等于主体退出：evidence-locked
- zx 当前扩权：rejected_as_primary
- 稳定 nx 人物本体：not locked
- 严格 zx补nx：not locked

本例不是新的“林冲 = nx”人物标签，而是时间层边界：**任务暂时做不成，与主体停止沿该方向，是两回事。**
