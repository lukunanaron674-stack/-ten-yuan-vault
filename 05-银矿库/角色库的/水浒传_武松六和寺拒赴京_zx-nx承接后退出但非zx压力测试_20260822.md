# 《水浒传》武松六和寺拒赴京｜zx-nx 承接后退出但非 zx 压力测试

## 0｜研究问题

本轮只测一个窄问题：

> 主体此前已经真实承接外部给定的招安—征讨—班师体系，后来在“是否继续赴京朝觐”这一执行窗口主动退出，是否就自动进入 zx？

结论：**不是。**

本例与《西游记》猪八戒“四圣试禅心”形成第二部独立作品的最小差异复验：

```text
此前承接外部方向
→ 当前主动不再续接
= nx 当前执行层退出

但：
没有扩大公共决定范围
没有让组织围绕主体新增权力接口运行
≠ zx
```

## 1｜剧情事实

第一百十九回时，梁山军已经完成朝廷征方腊任务并回到杭州。武松在征战中折臂，仍属于宋江麾下存活将领之一。

宋江看视武松时，武松明确表示自己已经残疾，“不愿赴京朝觐”，请求宋江造册时不要把自己列入进京人员；同时将身边金银赏赐留在六和寺，决定留寺做清闲道人。宋江答应“任从你心”。

随后朝廷天使到来，正式命宋江等班师回京；宋江与其余将领收拾军马返京，而武松不再进入这条班师—朝觐—受封路径，自此留在六和寺。

因此当前阶段不是普通休息，而是：

```text
既有朝廷/宋江任务体系真实存在
→ 武松此前已随军完成征讨
→ 班师回京与朝觐路径继续开启
→ 武松明确拒绝继续该当前终点
→ 实际留寺，不进京
```

## 2｜nx 判断

### 2.1 前一阶段：nx 上位方向关系成立

武松此前已经进入招安后的朝廷征讨体系，跟随宋江军队完成方腊战役。最高政治—军事任务并非由武松个人建立，而是来自朝廷诏命与宋江先锋体系；武松实际承接并执行。

因此记录：

`nx_prior_court_campaign_direction_relation: evidence-locked`

这里只锁上位任务/关系位置，不推稳定人物本体。

### 2.2 当前赴京窗口：nx 退出

到“是否随军回东京朝觐”这一具体终点层，武松没有继续沿现成班师与朝觐通道推进。

他明确要求：

- 自己不赴京；
- 造册不要写自己进京；
- 留在六和寺；
- 实际退出后续朝觐/受封执行路径。

所以：

`nx_in_return_to_capital_execution_window: rejected_as_primary`

关键纪律：**曾经承接 nx，不代表以后每个执行窗口永久 nx。**

## 3｜zx 判断

**排除为主判。**

最容易误判的是：

```text
朝廷让大家回京
→ 武松说“我不去”
→ 自己做决定
→ 所以 zx
```

不够。

武松没有：

- 取得班师路线的最高决定权；
- 让宋江或其余将领跟着自己留寺；
- 扩大自己在朝廷、军队中的处分范围；
- 建立一个新的公共命令接口；
- 让朝廷秩序围绕他的新增权能重新组织。

宋江只是允许其个人退出。

因此：

`zx_in_narrow_stage: rejected_as_primary`

核心纪律：

> **拒绝继续 nx，不等于 zx。个人退出与公共扩权是两个变量。**

## 4｜x 最近邻

武松在“自己是否继续赴京、是否留寺”这一私人选择层存在 `x` 邻近：他对自己后续去留提出明确决定，而且宋江认可其个人退出。

因此记录：

`x_personal_exit_choice_boundary_neighbor: present_but_not_primary`

但本轮不把这扩大成稳定 x 本体，也不把个人去留权误写成军队/朝廷方向权。

## 5｜xn 排除

武松没有在退出后重新搭建一套持续的替代组织运行结构：

- 没有重排梁山人员；
- 没有配置新的军事资源；
- 没有建立新的班师节点；
- 没有重新定义全军成功条件；
- 没有组织一个替代政治路线。

他只是退出当前班师—朝觐路径，留寺生活。

所以：

`xn_new_route_replanning: rejected_as_primary`

## 6｜关键压力

本轮压力包括：

- 征方腊后重伤折臂；
- 朝廷班师回京与朝觐路径已经开启；
- 后续存在受封与恩赐机会。

但这些压力不能直接判十元。

第三因素冻结：

- 武松是否厌恶官场；
- 残疾本身的悲剧性；
- 宋江是否忠君；
- 后来朝廷仍封武松“清忠祖师”；
- 武松人物总体豪侠气质。

只看：**原方向来自谁、武松当前是否继续续接、退出后是否扩大公共决定范围。**

## 7｜拿掉测试

### 拿掉残疾因素

如果仍保留：

```text
已承接朝廷征讨体系
→ 当前班师回京路径开启
→ 主体明确拒绝继续
→ 实际留寺
```

则当前 nx 退出仍成立。

残疾解释“为什么退出”，不是分类支柱。

### 拿掉实际留寺

如果武松只是嘴上说不想去，最终仍随军赴京朝觐，那么不足以锁执行层 nx 已退出。

### 拿掉公共扩权

本例本来就没有新增公共决定范围；因此 zx 不能成立。

## 8｜反向测试

### 真正持续 nx

```text
朝廷命班师
→ 武松虽残疾但继续随军赴京
→ 接受朝觐/受封路径
= nx 继续
```

### 真正 zx

```text
武松拒绝赴京
→ 进一步迫使宋江及其他将领改变班师方向
→ 朝廷/梁山承认武松新增最高决定位置
→ 决定范围真实扩大
= 才检查 zx
```

原文没有。

### 真正 xn

```text
退出原班师路径
→ 主动组织一套新的持续政治/军事路线
→ 配置人员、资源、节点、规则
= xn 上升
```

原文同样没有。

## 9｜最近邻排除

```text
nx：是否继续沿朝廷/宋江现成班师与朝觐方向推进？
x：武松本人是否拥有个人去留选择边界？
xn：退出后是否主动重建运行结构？
zx：退出是否带来公共决定范围扩张？
```

本例最窄判断：

```text
前段 nx 上位任务关系成立
→ 当前班师执行窗口主动退出
→ x 私人选择邻近
→ 无 xn 结构重建
→ 无 zx 扩权
```

## 10｜与《西游记》猪八戒形成第二部独立作品复验

《西游记》猪八戒“四圣试禅心”：

```text
已承接取经方向
→ 当前尝试退出西行、留下招赘
→ nx 退出
→ 无公共扩权
→ 非 zx
```

《水浒传》武松六和寺：

```text
已承接朝廷征讨体系
→ 当前拒绝班师赴京朝觐
→ nx 退出
→ 无公共扩权
→ 非 zx
```

共同支持案例级候选：

> **nx 退出只说明主体不再续接当前外部方向；是否出现 zx，必须另过“主体自身权能公开显现并扩大决定范围”的硬门。**
