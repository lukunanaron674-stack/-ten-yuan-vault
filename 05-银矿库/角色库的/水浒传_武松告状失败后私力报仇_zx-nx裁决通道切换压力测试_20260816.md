# 《水浒传》武松告状失败后私力报仇｜zx↔nx 裁决通道切换压力测试

## 结论先行

本轮锁定一个高质量的 **`nx 外部裁决通道失败 → zx 临时裁决扩权`** 压力切换正例，但不锁武松稳定人物本体，也不把它直接升级成严格 `zx补nx` 补关系案例。

最小链条：

```text
武松自己形成“查明武大死因并追究凶手”的方向
↓
县衙掌握正式拿问、审理与裁决接口
↓
nx 关系功能：携证人与物证到县厅，请知县“作主”
↓
西门庆行贿，县衙拒绝启动正式裁决
↓
外部通道失效
↓
武松不再把裁决接口留在县衙
↓
自行控制现场、逼取口供、形成书面证词、决定并执行报仇
↓
zx 当前状态高显影：主体把原本不属于自己的调查／裁决／执行接口临时压入现实
```

本例的价值不在“武松杀人很猛”，而在于：**同一个最终方向先尝试通过外部正式权限通道推进；当该通道被人为封死后，主体转而公开扩大自己的实际决定范围，从申请裁决者变成临时裁决与执行中心。**

## 1｜剧情事实、触发、对象、动作与结果

### 触发

武松回阳谷县后发现兄长武大郎已死，进一步从何九叔取得中毒骨殖、西门庆所给十两银子等证物，又从郓哥取得捉奸与武大受伤经过的证言。

方向源在武松自己：

```text
查明哥哥死因
→ 找出责任人
→ 追究并报仇
```

这不是县衙替武松生成的目标。

### 阶段A：nx 外部裁决通道

武松带何九叔、郓哥到县厅，明确请求知县“作主”。这一阶段的关键并不是武松没主见，而是：

```text
正式拿问权
正式审理权
正式司法裁决权
= 在县衙／知县手里

武松有方向与证据
但不能自行调用正式司法接口
→ 必须进入既有县衙权限通道
```

知县先推说证据不足；西门庆随后使人向官吏行贿。次日武松再次催逼拿人，知县仍不准所告，并把骨殖、银子退还。

因此，本阶段可锁 `nx` **关系功能／关系位置**：解决问题所需的正式裁决权限属于他者，武松必须承认并请求该接口。

### 阶段B：外部通道明确失败

如果县衙愿意正常拿问、审理，武松原先可以继续沿正式权限通道推进。但文本明确给出：

```text
西门庆行贿
→ 官吏通同
→ 知县拒绝拿问
→ 正式解决通道被封死
```

这构成本轮关键外部压力，而不是把“政府存在”泛泛当成 nx。

### 阶段C：zx 临时裁决扩权

告状失败后，武松立即改变运行方式：

- 召集王婆、潘金莲及四家邻舍到场；
- 命土兵把门，禁止参与者自行离开；
- 公开持刀要求众人作证；
- 强制潘金莲、王婆逐项招认；
- 让胡正卿把口供写下，并让相关人画字作证；
- 随后自行决定对潘金莲、西门庆实施报仇；
- 最后携人头、王婆和书面口词再投县衙。

这里真正支持 `zx` 的不是暴力本身，而是**决定接口发生了公开迁移与扩大**：

```text
原位置：向县衙申请调查／裁决
↓
县衙拒绝
↓
新位置：武松自己建立事实确认、强制取供、裁决与执行接口
↓
潘金莲、王婆、邻舍、土兵、西门庆都被迫围绕这一临时决定中心反应
↓
主体实际决定范围上升
= zx 当前状态高显影
```

## 2｜为什么前半段是 nx 关系功能，不是纯 nx 本体

纯 nx 本体要求主体长期不占最终方向、反复让别人或现状决定路线；本段并非如此。

武松从头到尾都有明确方向。他进入县衙，不是把“要不要追究”交给知县，而是承认：**正式拿问与裁决的权限不属于自己。**

因此必须分层：

```text
人物稳定本体：本轮不锁
最终方向：武松自有
正式司法权限：在县衙
通过县衙请求裁决：nx 关系功能
```

这与 `nx v2.5` 的“强主体也可以使用 nx 权限／关系功能”一致。

---

## 3｜为什么后半段是 zx，而不是“普通暴力”

现行 zx 准度卡禁止把“很能打、战斗、赢了”直接判为 zx。本段额外满足的是：

1. 武松自己的决定接口公开进入现实；
2. 原本不属于他的事实确认、强制取供与最终处置被他临时接管；
3. 多个对象被迫围绕他的决定重新行动；
4. 相比“只能向县衙申请”的位置，他的实际决定范围明显上升。

所以判据是：

```text
不是：杀了人 → zx
而是：从申请裁决者 → 自建裁决与执行中心 → 决定范围扩大 → zx
```

## 4｜最近邻排除

### nx vs xn

告状失败后的确有很强 `xn` 邻近成分：武松准备酒席、安排土兵、把门、安排书写口供、设置见证人，明显带有计划、流程和节点组织。

但 `xn` 只能解释：

```text
这套取供程序怎么被组织起来
```

不能解释：

```text
为什么武松从无正式裁决权的人
变成现场所有人不得不服从的临时决定中心
```

拿掉酒席、时辰、座次等流程细节，只保留“县衙拒绝 → 武松公开接管事实确认与处置 → 他者被迫服从”，`zx` 仍独立成立。因此 `xn` 是辅因，不吞掉 `zx`。

### zx vs x

武松虽是阳谷县都头，也能调用若干土兵，但县衙已经明确拒绝启动该命案的正式拿问与裁决。这说明“杀嫂、杀西门庆、强制取供”的处分边界并非原本就属于他的常态职位权限。

若这些权限本来就长期归武松正常调用，更应检查 `x`；原文恰好反证了这一点，因此本阶段支持的是**越过原权限边界后的 zx 扩权**，不是日常 `x`。

### zx vs xz

兄长被害、官府不理确实形成强烈风险与终局压力，但 `xz` 只能解释为什么安全／合法路径收窄，不能替代“武松实际取得更高决定位置”这一木轴变化。

### nx vs 普通求助

本段不是“找人说句话”。正式司法裁决的关键权限确实在县衙，拿掉知县许可后原正式路径无法继续，因此达到 nx 关系功能的权限归属门槛。

## 5｜拿掉测试

### 拿掉武松的武艺名声

只保留：

```text
正式裁决权在县衙
→ 主体携证据请求启动
```

前半段 `nx` 关系功能仍成立。

后半段只要仍发生：

```text
外部接口失败
→ 主体公开接管原本无权处分的事实确认与处置
→ 对象被迫服从
```

`zx` 仍成立。武艺只是让这一扩权能够执行，不是分类本身。

### 拿掉西门庆最终死亡

即使武松没有最终杀死西门庆，只要他已从申请者转成现场事实确认与强制裁决中心，并迫使相关对象围绕其决定重排，`zx` 仍可成立。胜负结果不是必要条件。

### 拿掉“兄弟报仇”主题

把对象换成任意重大侵害，只要结构仍是“正式裁决接口在他者 → 请求失败 → 主体自行取得更大决定接口”，木轴判断不变。

### 拿掉县衙拒绝

如果知县正常受理、拿问、审理，武松继续沿正式程序推进，那么后续 zx 临时裁决扩权的触发条件会消失，`nx` 权限通道反而可能持续高显影。

## 6｜反向测试

### 反向A：持续 nx 版本

```text
县衙不准
→ 武松仍不自行处分
→ 改向东平府、上级官府或另一正式权限节点申诉
→ 继续沿既有司法通道推进
```

则 `nx` 关系功能持续，`zx` 明显下降。

### 反向B：普通 x 版本

```text
武松原本就是本案拥有完整拿问、定罪和执行权的正式裁决者
→ 按职位常规办案
```

则优先检查 `x/xn`，不能因命令成功判 zx。

### 反向C：纯 xn 版本

```text
武松只设计取证流程
→ 所有强制处分仍交由合法裁决者决定
```

则流程组织可以高 `xn`，但不会产生本轮的 zx 决定位置扩张。

## 8｜与现有样本的最小差异

### 对比吕布辕门射戟

吕布是：

```text
原战争路线存在
→ 主动建立第三方新裁决接口
→ 双方接受
→ 临时决定位置上升
= zx
```

武松则是：

```text
先承认并进入既有正式裁决接口
= nx 关系功能
↓
该接口被封死
↓
主体把裁决位置重新夺回并扩大
= zx
```

因此本例不是重复“临时裁决 = zx”，而是补出**裁决权来源发生切换**的动态：

> `外部正式权限可用时 → nx；外部接口失效后，主体若自行把处分权压回现实 → zx 上升。`

### 与孙悟空红孩儿／孙策借兵不同

孙悟空、孙策是 `zx 直接路径受阻 → nx 借外部资源／权限 → zx 再行动`。

武松恰好反向：

```text
先 nx 走外部裁决通道
→ 外部通道失败
→ zx 接管并推进
```

因此它补足了木轴压力切换的另一方向，但目前只作为案例级动态证据，不直接修改补卡。

## 9｜是否构成严格 zx补nx

本轮 **不锁严格补关系**。

原因：`zx补nx_补卡` 要求拿掉任一端，另一端仍独立成立但出现可命名缺口，并且补回后缺口可重复改善。本例中县衙 nx 通道实际上失败，后续 zx 更接近**替换失败通道**而非利用 nx 已获得的资源／权限完成互补。

因此只锁：

```text
nx 外部裁决通道失败
→ zx 临时裁决扩权高显影
```

不把“先后出现”偷写成“严格互补”。

## 11｜本轮新增判定纪律

仅作为案例级纪律记录：

> **“先走外部裁决通道”可以是 nx 关系功能；如果该通道失败后，主体不再继续寻找外部权限，而是公开取得原本不属于自己的裁决／处分位置，并迫使对象围绕其决定重排，则 zx 可以在压力下高显影。**

同时必须防止两种误判：

```text
杀人／暴力很强 ≠ zx
设计取供流程 ≠ 自动 xn 吞掉 zx
```

真正要看的是**裁决权来源与决定范围是否发生迁移**。
