# 《三国演义》曹操陈留借卫弘家资｜zx↔nx 补关系压力测试

## 0｜结论

本轮锁定一个高置信的 `zx + nx` 补关系案例，但只锁当前阶段与行为/关系功能，不锁曹操稳定人物本体。

最小链：

```text
zx：曹操自己形成“力扶社稷、反董起兵”的方向
↓
直接权能缺口：自家资财不足，难以形成可公开运行的军队
↓
nx：进入卫弘这一外部财富/资助接口，请求其以家资相助
↓
卫弘自愿提供家资，置办衣甲旗幡
↓
zx：曹操公开发矫诏、招集义兵、竖旗、调练军马，并让各镇诸侯响应
```

这符合 `zx补nx_补卡`：

- `nx 补 zx`：补入曹操自身暂时缺失的外部资源接口，使其不必只靠现有自有财力硬推。
- `zx 补 nx`：卫弘提供的家资没有停留在“有人帮助”层，而被曹操重新转成公开募兵、军队形成、檄文传播与现实扩张。

## 1｜剧情事实

### 触发
曹操逃至陈留后向父亲说明前事，提出散家资、招募义兵。曹嵩明确指出自家资财不足，单靠现有资源恐怕不能成事，并提出当地富户卫弘可能提供帮助。

### 对象
- 曹操：方向主体与后续公开行动主体。
- 卫弘：家资与资助接口持有者。
- 曹嵩：指出资源缺口并介绍可接入的外部节点。
- 后续应募者、夏侯惇/夏侯渊、曹仁/曹洪、各镇诸侯：公开扩张后的现实响应者。

### 明确动作
1. 曹操明确表达“欲力扶社稷”，并明确承认“恨力不足”。
2. 曹操设宴拜请卫弘，请求相助。
3. 卫弘本人表示愿以家资相助，说明该资源不是曹操既有可直接处分财产。
4. 曹操随后发矫诏、招募义兵、竖“忠义”旗。
5. 卫弘进一步尽出家财，置办衣甲旗幡；曹操调练军马。
6. 乐进、李典、夏侯惇、夏侯渊、曹仁、曹洪等陆续加入，各镇诸侯亦因檄文起兵响应。

### 结果
外置财富接口被曹操成功接入，并被转换成公开军事组织与政治动员。曹操没有把最终反董方向交给卫弘；卫弘也没有替曹操决定打谁、为何起兵。

## 2｜zx 判定

本轮 `zx` 不能仅凭“曹操有大志”成立。真正的高质量证据出现在外部资源补入以后：

```text
自身方向明确
+ 公开发矫诏
+ 公开招募义兵
+ 形成并调练军队
+ 诸将与各镇现实响应
= zx 当前状态/行为功能高显影
```

符合 `zx_准度卡_v0.1`：主体自身决定接口明确，权能进入公开现实，他者被迫或主动围绕新力量重新反应，主体影响位置与军事决定范围上升。

不锁曹操稳定纯 zx 本体，因为本轮只是一个阶段。

## 3｜nx 判定

`nx` 成立在“资金/装备形成军队”这个关系功能层，不成立在最终方向层。

关键事实：

```text
曹操有方向
但现有家资不足
卫弘家资不归曹操
曹操必须请求卫弘本人同意
卫弘可以不提供
卫弘同意后资源才进入曹操行动链
```

因此锁 `nx_external_finance_relation_function: evidence-locked`。

这不是 `x`：卫弘的家财与处分权没有预先归曹操。
这也不是 `xn`：曹操后续会组织募兵，但“资源为什么能进入行动链”首先是外部接口问题，而非排程问题。

## 4｜严格补关系测试

### 4.1 拿掉 nx 端
拿掉卫弘及等价外部资助接口，只保留曹操自己的反董方向：

- `zx` 的方向资格仍成立；
- 但文本明确出现“资少恐不成事”的可命名缺口；
- 招募、装备、军队成形会受到直接物质限制。

缺口名称：`公开军事扩张所需启动资本/装备接口不足`。

### 4.2 补回 nx 端
卫弘的家资进入后，缺口得到直接改善：衣甲旗幡开始置办，募兵与军队组织得以扩张。

### 4.3 拿掉 zx 端
只保留卫弘“有钱、愿意资助”，但拿掉曹操的自生方向、公开募兵与军政推进：

- `nx` 的外部资源接口仍存在；
- 但资源不会自动变成一支以明确方向运行的公开力量。

缺口名称：`外部资源缺少被主体转化为公开决定与行动的落地权能`。

### 4.4 补回 zx 端
曹操把资金转成募兵、装备、调军、发檄文，各镇与将领开始围绕其行动响应，资源由“可用”变成“现实扩张”。

因此本例通过补卡红线：两端分别独立成立，拿掉任一端另一端仍存在但留下可命名缺口，补回后缺口明确改善。

## 5｜为什么不是普通协作/资源相加

如果只是“卫弘给钱，曹操拿钱办事”，仍不足以锁严格补关系。

本例之所以过线，是因为原文明写：

1. 曹操的最终政治方向先于卫弘介入而存在；
2. 曹操/曹嵩明确识别出自身资源不足；
3. 卫弘掌握独立外部资源接口并有真实同意门；
4. 该接口正好补曹操公开扩张的明确缺口；
5. 资源进入后马上被转成公开募兵与军政作用；
6. 去掉任一端都能指出另一端留下的具体结构性缺口。

因此不是“强者+有钱人”机械拼接。

## 6｜最近邻排除

### nx vs xn
曹操如何发檄文、募兵、调军属于 `xn` 邻近；但卫弘的钱是否进入曹操体系，不是曹操自己通过排程生成的，须经资源持有人同意，因此资助环节优先 `nx`。

### nx vs x
卫弘家资不在曹操原有处分边界，故不是 `x`。

### zx vs x
军队逐步形成后，曹操对已招募部众的持续调用可进一步出现 `x`；但本轮 `zx` 锁的是“从力不足到公开形成并扩大现实军政作用”的显权/扩张过程，不把稳定后的已有调用权继续重复算 zx。

### zx vs xn
募兵组织有 `xn`，但仅靠流程不能替代“曹操自身权能公开进入现实并形成新的军事影响位置”这一 zx 证据。

## 7｜关键压力

关键压力不是“董卓很强”，而是曹操自己明确面临：

```text
已有政治方向
+
自有财力不足
→ 方向无法直接转换为足够规模的公开军事实力
```

因此 nx 高显影的触发点是“自身直接权能存在资源缺口”，不是人物突然变成没主见。

## 8｜反向测试

### 纯 zx 版本
若曹操已有充足自有家资、装备和直属军队，无需任何外部同意即可起兵，则卫弘环节消失，中段 nx 显著下降。

### 纯 nx 版本
若卫弘不仅给钱，还决定曹操是否起兵、打谁、以何政治方向行动，曹操只接受资助与命令，则 zx 自生方向显著下降，转向 nx 主位。

### xn 主位版本
若真正难点不是外部资源，而是曹操如何长期排程募兵、补给、节点和联盟流程，则应转查 xn，不能把“组织得好”写成 nx。

## 9｜第三因素冻结

以下均不得直接判十元：

- 曹操是历史强人；
- 卫弘富有；
- 曹操后来是否成为魏王；
- 矫诏是否合法；
- 讨董最终胜负；
- 曹操善恶评价；
- 夏侯氏、曹氏与曹操的亲缘；
- 各镇诸侯的政治动机。

冻结后仍保留：`自身方向 → 明确资源缺口 → 外部资源同意门 → 公开扩张`。

## 10｜稳定本体 / 当前状态 / 行为功能 / 关系位置

- 稳定人物本体：不锁。
- 当前状态：`zx` 高显影。
- `zx` 行为功能：公开发矫诏、招兵、调军、扩大现实军政影响。
- `nx` 关系功能：通过卫弘这一独立财富接口取得关键启动资源。
- `xn` 最近邻：后续募兵、调练、联络诸侯的组织过程。
- `x` 最近邻：军队形成后，对已纳入自身系统的人马与资源的稳定调用。

## 11｜与既有样本的关系

同一《三国演义》中，孙策“以玉玺质兵→渡江图江东”已经提供 `zx→nx→zx` 高质量样本。本例为同作品、不同人物、不同资源结构的内部复验：

- 孙策：兵马与正式军权接口外置于袁术。
- 曹操：启动资本与军需资源外置于卫弘。

两例都支持“zx 主体在直接权能存在明确缺口时，可通过 nx 外部接口补足，再由 zx 将资源转回公开推进”。但由于二者属于同一作品，不把跨作品支持数从2提高到3，也不因此新建待审议问题。
