# 《红楼梦》周瑞家的送宫花｜zx-nx 纯 nx 行为功能压力测试

## 结论先行

本轮只锁第7回“送宫花”这一窄行为层：**高纯 nx 行为功能成立**；不锁周瑞家的稳定人物本体，也不锁严格 `zx↔nx` 补关系。

薛姨妈直接给出完整任务终点：十二枝宫花，三位姑娘各一对，黛玉两枝，凤姐四枝。周瑞家的接过花匣以后，依次送到迎春、探春、惜春、凤姐、黛玉等处，并说明来由。她没有改写“送不送”、受赠对象、数量配置或最终分配权。

因此在这一窄对象层：

```text
方向 / 对象 / 数量已经由薛姨妈给出
+
周瑞家的不占最终重设位
+
沿贾府既有房舍、人际与传递通道逐项送达
= nx 行为功能高显影
```

## 1｜剧情事实

薛姨妈拿出十二枝宫制堆纱花，明确吩咐：贾府三位姑娘每人一对，黛玉两枝，其余四枝给凤姐。周瑞家的接过匣子后执行送达。

她先顺路到迎春、探春处，再送惜春；随后到凤姐处，把四枝交给平儿，平儿又从中分出两枝送秦可卿；最后周瑞家的把黛玉的两枝送到。

触发：薛姨妈临时想起宫花闲置，决定分送。
对象：迎春、探春、惜春、黛玉、凤姐。
明确动作：接花匣、按既定对象送达、说明缘故。
结果：原分送任务基本按外部既定方向完成。

## 2｜nx 判断

### 当前行为功能：成立

本轮符合 `nx 准度卡 v0.5` 的行为功能层：方向已经存在，主体没有主动改写最终任务，也没有抢受赠对象与数量的重设位置，而是沿现成家内关系和空间通道继续。

这里锁的是：

`nx_behavior_function_in_delivery_stage: evidence-locked`

不是：

`pure_nx_stable_essence: locked`

一次执行不能反推稳定人物本体。

## 3｜zx 判断

`zx` 排除为主判。

周瑞家的在贾府内熟门熟路、能直接进出多个房间，也会说话办事，但没有因此取得新增决定范围，没有公开迫使薛姨妈、王夫人或贾府人员围绕她的新权能重排。

```text
会把差事办完 ≠ zx
熟悉关系网络 ≠ zx
```

因此：

`zx_in_narrow_stage: rejected_as_primary`

## 4｜nx vs xn 最近邻

周瑞家的确有“顺路先送谁”的局部路径选择，也会在途中停留、询问、闲谈。

但这些没有改变关键运行结构：

- 谁收花；
- 每人分多少；
- 为什么送；
- 最终要把花送完。

所以局部路线自由只属于低强度执行自由，不足以把主判推成 `xn`。

反向若出现：她自行重新分配对象和数量、改变任务目的、建立新的分发规则，则 `xn/x` 才明显上升。

## 5｜拿掉测试

### 拿掉“周瑞家的很熟悉贾府”

只要仍存在“别人明确给出分送方向，她按该方向完成”，nx 行为功能不变。

### 拿掉沿途闲谈与顺路选择

nx 更纯，说明这些不是分类支柱。

### 拿掉薛姨妈明确的对象与数量

如果只说“这些花你看着送吧”，而周瑞家的自行决定全部对象、数量和顺序，那么当前高纯 nx 会明显下降，应重新检查 `xn/x`。

## 6｜反向测试

### 反向成 xn

薛姨妈只给“把十二枝花送出去”这个抽象目标，周瑞家的自行设计受赠对象、数量、规则并持续组织分配。

### 反向成 zx

周瑞家的原本没有分配处分权，却公开取得并扩大这块决定范围，使薛姨妈或贾府人员以后围绕她的新分配接口运行。

当前文本均不支持。

## 7｜第三因素冻结

冻结：

- 周瑞家的身份、阶层、年龄；
- 黛玉对“别人挑剩下”的不满；
- 王夫人与薛姨妈关系；
- 周瑞家的女婿官司；
- 她是否势利、圆滑、会办事；
- 宫花本身的审美与象征。

只看：任务方向由谁给、主体有没有真实重设、最终是否沿既有通道续接。
