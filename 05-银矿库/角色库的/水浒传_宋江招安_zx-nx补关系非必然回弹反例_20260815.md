# 《水浒传》宋江招安｜zx↔nx补关系非必然回弹反例

## 一、本轮问题

现行 `zx↔nx` 补卡写明：`nx` 可给 `zx` 补入外部权限、关系通道与非正面解决方案；`zx` 又可把借来的资源和通道重新转成公开行动。

本轮专门压力测试一个容易被机械化的推论：

```text
zx 方向受阻
→ nx 借外部接口
→ 是否必然 zx 再显影？
```

结论：**不必然。** 外部接口一旦成功接入，也可能同时改写后续“最终方向来源”，使主体进入外部授予的新方向。`nx补zx`不能自动画成固定 `zx→nx→zx` 回弹链。

## 二、剧情事实

### 1. 第七十一回：招安方向由宋江自己公开提出

菊花会上，宋江公开表达“早招安”的愿望。武松、李逵反对后，他仍明确坚持自己主张招安、希望归为国家臣子并报国。

这一段至少证明：

```text
招安这一阶段目标
不是别人临时塞给宋江的
而是宋江自己公开提出并维持
```

因此在“是否追求招安”这个窄变量上，宋江存在 `zx` 候选：方向由自己提出，并试图让梁山内部围绕这一方向调整。

### 2. 第八十二回：真正取得招安必须进入皇权与人情权限网络

燕青通过李师师接触皇帝，又见宿太尉；招安最终由皇帝诏敕完成。无论宋江本人愿望多强，赦免、合法身份与正式招安权限都不在梁山自己手中。

此处关键变量是：

```text
赦免权 / 招安批准权 / 合法身份授予权
= 皇帝与朝廷权限
```

梁山必须通过既有人情、身份与宫廷权限接口取得结果，因此这一段形成强 `nx` 关系功能。

### 3. 第八十三回：招安成功后，下一项具体方向由皇帝诏令给出

招安后，辽国入侵，皇帝依宿太尉建议，亲书诏敕，命宋江为破辽都先锋，率众征辽。

这意味着后续“去不去征辽”这一具体上位方向已经不是宋江自行建立，而是来自皇帝诏令。

宋江之后当然可以在执行层重新组织路线、兵力和战术，这些可另判 `xn/zx` 状态；但不能因为前一阶段“招安目标由宋江自己提出”，就把招安后的每个行动继续自动算作同一条 `zx` 回弹。

## 三、zx / nx 分层

### zx 证据

第七十一回窄阶段：

- 宋江主动公开提出招安方向；
- 面对武松、李逵等反对仍维持该方向；
- 尝试使梁山群体接受并进入这一方向。

因此：

```text
招安目标的提出与公开坚持
= zx 状态 / 关系位置候选
```

但本轮**不把宋江稳定人物本体锁成纯 zx**。

### nx 证据

第八十二回：

- 招安批准权不属于宋江；
- 必须经李师师、宿太尉、皇帝等既有关系与权限网络；
- 最终合法性与赦免由皇权授予。

因此：

```text
外部权限接口不可替代
+ 主体必须承认并进入该接口
= nx 关系功能高显影
```

### 关键反例点

第八十三回：

```text
招安成功
≠
宋江自动重新成为所有后续方向源
```

征辽的上位任务由皇帝诏令给出。故本例反对机械公式：

```text
zx → nx → zx（必然）
```

更准确应为：

```text
阶段A：zx 自设招安方向
→ 阶段B：nx 借皇权/人情接口取得招安
→ 阶段C：重新判断新问题的方向来源
   ├─ 若主体重新自设并公开推进：zx 可再显影
   └─ 若上位方向由外部授予：不得自动写 zx
```

## 四、关键压力

- 梁山自身没有合法赦免权；
- 朝廷内部存在高俅、童贯等阻塞；
- 宋江想把“招安”变成现实，必须跨越外部皇权接口。

压力造成的不是“宋江突然没主见”，而是：

```text
自己的方向存在
但关键许可不在自己手里
```

这正是 `nx` 关系功能最干净的使用场景之一。

## 五、最近邻排除

### nx vs xn

燕青等人的联络、说项可以包含步骤，但本轮最关键变量不是持续排程，而是**合法批准权在皇帝及朝廷接口手里**，所以核心优先 `nx`。

### nx vs x

宋江并不拥有皇帝的赦免权和合法身份授予权，因此不是 `x`。

### zx vs xn

第七十一回宋江公开坚持招安方向，可有 `zx` 状态；第八十三回具体征辽之后的战术组织应另行检查 `xn`，不能借前段 `zx` 一路覆盖。

### zx vs “胜利结果”

招安成功不能单独证明 `zx`。成功结果来自外部皇权授予；必须拆方向来源与权限来源。

## 六、拿掉测试

### 拿掉李师师

若仍存在另一条可接触皇帝并取得赦免的既有权限通道，`nx` 关系功能仍可成立；因此 `nx` 不依赖李师师个人，而依赖“外部许可必须通过他者权限网络取得”这一结构。

### 拿掉皇帝/朝廷批准权

若宋江自己即可合法赦免梁山并授予国家身份，则本轮关键 `nx` 会显著下降。

### 拿掉招安成功

即使最终失败，只要宋江仍必须通过李师师、宿太尉、皇帝等外部接口尝试取得批准，`nx` 关系功能仍成立。

## 七、反向测试

若改写为：

```text
宋江自身拥有合法化梁山的最高权限
→ 自己决定赦免、身份与国家归属
→ 他者只能围绕宋江的决定反应
```

则 `nx` 明显下降，转而检查 `x/zx`。

若招安后宋江明确拒绝皇帝给出的新任务，并重新建立自己的下一阶段方向，再迫使外部秩序围绕其方向反应，则新的 `zx` 才能独立成立。

## 八、第三因素冻结

- **忠君价值观**：只能解释宋江为什么想招安，不能替代方向/权限归属判断。
- **梁山首领身份**：不能直接判 `zx`。
- **朝廷强权**：解释外部权限位置，但不能因此把宋江稳定人物本体判 `nx`。
- **燕青能力**：燕青是关键中介执行者，不能把燕青的具体行为全部借给宋江个人；本轮只判断宋江所处的关系接口结构。
- **招安结果成功**：结果不能倒推端点。

## 九、本轮结论

状态：`evidence-locked`

事实置信：99
分类置信：97

锁定母句：

> **`nx补zx`表示外部关系/权限通道可以补足主体直接突破的缺口，但不保证通道成功后主体必然重新成为下一阶段的最终方向源。每进入一个新问题，必须重新判断“方向从谁那里来”。**

因此，`zx→nx→zx` 是一种可复现动态链候选，不是 `zx↔nx` 补关系的必然时序公式。

## 十一、下一轮建议

不继续机械寻找第三个 `zx→nx→zx`，优先寻找：

```text
同一主体借到 nx 外部接口后
A. 重新取得最终方向源（zx再显影）
vs
B. 接受外部新方向（nx/xn继续）
```

做一组最小差异对照，验证“接口成功后方向源是否回归”才是决定是否进入第二个 zx 的关键变量。
