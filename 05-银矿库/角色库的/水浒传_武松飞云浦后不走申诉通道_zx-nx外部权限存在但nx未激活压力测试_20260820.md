# 水浒传｜武松飞云浦后不走申诉通道｜zx-nx 外部权限存在但 nx 未激活压力测试

## 1. 剧情事实

张都监、张团练与蒋门神合谋陷害武松。赃物被预先放入武松住处，知府在受贿和伪证影响下逼迫武松招认，最后把他刺配恩州。文本同时写到叶孔目等人知道武松受陷，知府后来也逐渐知道张都监收受贿赂、设局害人，因此司法体系内部并非完全不存在能够重新评价案件的人与权限节点。

刺配途中，张都监一方又买通押送公人，并派蒋门神徒弟准备在飞云浦杀死武松。武松识破后直接反杀四人。脱离即时死亡威胁后，武松没有转向知府、叶孔目、官府复审或其他申诉通道，而是在桥上明确决定返回孟州，直接寻找张都监、张团练、蒋门神报复。随后血溅鸳鸯楼，继续逃亡。

事实来源：施耐庵《水浒传》第三十至三十一回；公开原文互校以维基文库、中国哲学书电子化计划等为主。

## 2. 触发、对象、动作、结果

- 触发：武松被构陷并刺配；飞云浦途中遭第二次预谋杀害。
- 当前对象层A：是否通过现存官府/申诉节点纠正被诬案件。
- 当前对象层B：飞云浦脱险后如何处理张都监等直接加害者。
- 明确动作：武松在飞云浦自行杀死执行暗杀者；随后不进入司法申诉通道，而是主动返回孟州实施报复。
- 结果：外部司法纠正权限客观仍存在，但在这一后续阶段没有被武松实际调用；其行动转为自行直接处理加害者。

## 3. 样本槽判断

本桥段锁定为：**“外部权限存在，但主体不沿该通道推进”反向控制。**

- 纯 zx 稳定人物本体：不推断。
- zx 当前直接行动状态：存在，但不作为稳定本体结论。
- nx 关系功能：在“飞云浦脱险后如何处理冤案/加害者”这一阶段排除为主判。
- xn：有返回孟州、潜入、寻找目标等局部策略邻近。
- zx+nx 严格补关系：不锁。

本轮真正新增的案例级边界是：

> **外部权限/申诉节点存在，并不自动激活 nx。只有主体实际承认并沿该权限、关系或流程通道推进时，nx 关系功能才成立。**

## 4. nx 证据与排除

现行 nx v2.5 将关系功能定义为：自己的权能不能直接解决问题时，进入已经存在的人际、身份与权限网络，求人、借力、请救兵、托关系，沿他者拥有的角色和通道把事情办成。

武松本段恰好提供反向控制：

1. 官府中确实存在知府、叶孔目等重新评价案件的现实节点。
2. 武松已经知道自己被张都监设计陷害。
3. 飞云浦脱险以后，他没有请求这些节点重新裁决，也没有等待司法许可生效。
4. 他主动把处理方式切换为直接复仇与逃亡。

因此正式锁：

`nx_in_post_escort_escape_stage: rejected_as_primary`

这不是说武松“没有外部权限环境”，而是：**这个外部权限环境在当前行动链里没有被主体作为解决通道实际使用。**

## 5. zx 证据

飞云浦与鸳鸯楼阶段存在明显 zx 当前状态邻近：武松自己决定反杀与返回复仇，并以自身强制能力直接改变现场结果。

但本轮不把它升级成稳定人物本体，也不把“杀得多人、动作强烈”直接当 zx。真正可观察的是：

- 当前行动方向由武松自己建立；
- 他没有等待外部许可；
- 自身强制能力直接进入现实并改变加害者的行动结果。

因此只记录：

`zx_direct_retaliation_state: present_but_not_stable_essence`

## 6. 关键压力

关键压力包括：被诬、被刺配、押送途中遭预谋灭口，以及对官府公正性的信任大幅下降。

这些压力解释了武松为何不继续走官府通道，但压力本身不能替代木轴判断。核心仍是：**主体有没有实际沿外部权限接口推进。**

## 7. 拿掉测试

### 7.1 拿掉外部司法节点

即使完全删除知府、叶孔目等潜在纠正节点，只保留“飞云浦脱险后武松自行返回复仇”，当前非 nx 结论仍成立。

### 7.2 拿掉武松的复仇动作，只保留‘知道有外部权力’

如果武松什么都不做，仅仅处于“案件最终裁决权在官府”的关系位置，也不能自动判 nx；还需要看到他真的请求、上诉、托关系或沿流程推进。

### 7.3 拿掉对官府的不信任

如果武松在脱险后转而向知府、叶孔目或更高官府申诉，并把翻案希望放在这些外部节点的许可与裁决上，则 nx 关系功能会显著上升。

## 8. 反向测试

### 8.1 真 nx 版本

```text
飞云浦脱险
→ 武松不自行处分张都监
→ 转向叶孔目 / 知府 / 更高官府申诉
→ 必须等待外部权限重新裁定
→ 沿该结果继续
= nx 关系功能
```

### 8.2 更纯 zx 版本

如果武松不仅直接复仇，而且进一步公开夺取本不属于自己的司法处分接口，使官府体系承认其新的决定位置，zx 才会从当前强行动进一步上升为真正扩权。原文没有。

### 8.3 xn 版本

如果主要证据变成武松设计长期潜逃、身份伪装、时间节点、路线与备用方案，则应优先检查 xn；本段有局部策略，但不是主判。

## 9. 最近邻排除

### nx vs xn

返回孟州、潜入鸳鸯楼属于行动方案与路径组织，解释“怎么做”；是否进入官府既有申诉/裁决通道，才是 nx 问题。

### nx vs zx

不使用外部权限不自动等于 zx。只有主体自身作用权真正压入现实并改变结果时，才检查 zx。本段飞云浦反杀与后续复仇具备这种当前状态邻近，但仍不推稳定本体。

### nx vs xz

被追杀、刺配、生死压力很强，只能解释为什么主体急于处理，不能回答他选择了哪一种权限路径。

### nx vs nz

施恩、叶孔目等人对武松的照顾属于关系背景，但当前阶段武松并未把这些关系用作翻案权限通道，不能因此锁 nx。

## 10. 与吕布白门楼形成跨作品最小差异

### 吕布

```text
最终生死权限在曹操
+ 本人主动求刘备说情、向曹操归服求生
→ nx 关系功能成立
```

### 武松

```text
司法纠正权限仍在官府体系
+ 本人飞云浦脱险后不再沿该通道推进
+ 改走直接复仇 / 逃亡
→ 外部权限存在，但 nx 当前功能未激活
```

因此当前跨作品支持数：2（《三国演义》《水浒传》）。尚未达到三作品阈值，不建立待审议问题。

## 11. 第三因素冻结

以下全部冻结，不作为十元直判：

- 武松是否侠义；
- 张都监等人是否罪有应得；
- 官府是否腐败；
- 武松武力强弱；
- 最终杀了多少人；
- 复仇是否合理；
- 后续是否落草。

只看：**外部权限节点是否存在 + 主体是否实际沿该通道推进 + 自身作用权是否直接进入现实。**

## 12. 结论

本轮结论：

> **“权限在别人手里”只能证明权限外置或关系位置不对等，不能单独证明 nx 行为功能。nx 还要求主体实际沿那个外部关系、权限、流程或通道续接。**

本例与吕布白门楼形成第二部独立作品复现，但尚未达到跨三作品门槛，因此不修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡。
