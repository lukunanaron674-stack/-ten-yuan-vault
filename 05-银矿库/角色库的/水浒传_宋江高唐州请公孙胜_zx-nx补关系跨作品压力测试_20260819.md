# 《水浒传》宋江高唐州请公孙胜｜zx↔nx 补关系跨作品压力测试

## 0｜结论

本轮锁定：**严格 `zx + nx` 补关系正例**，只锁高唐州这一阶段的当前状态、行为功能与关系位置，不锁宋江稳定人物本体。

最小链：

```text
zx：宋江自己占据“救柴进、破高唐”的公开军事方向，并以梁山军力推进
↓
直接权能缺口：高廉妖法使普通军力与宋江现有法术路径无法稳定解决
↓
nx：进入公孙胜／罗真人这一外部专属法术与许可接口
↓
罗真人先拒绝，后真实放行公孙胜并授予五雷天心/天罡正法
↓
zx：宋江重新传令拔寨进军，把外部取得的破解条件转回公开军事推进，最终高廉被破、高唐州被攻入
```

符合现行 `zx补nx_补卡` 的双向缺口：

- `nx 补 zx`：外部专属法术、师门许可与处理接口补入，解决宋江直接军力无法跨过的妖法边界。
- `zx 补 nx`：公孙胜与罗真人提供的条件没有取代宋江的整场方向；宋江继续作为公开主将传令、组织全军并把破解条件兑现为破敌与占城。

## 1｜剧情事实

### 触发

柴进陷于高唐州后，宋江率梁山军救援。高廉使用妖法与三百神兵，多次令梁山军受挫。宋江曾依据天书尝试破法，但仍未形成稳定解决。

### 对象

- 宋江：救柴进与进攻高唐州的方向主体、公开军事推进主体。
- 高廉：以妖法形成专属能力阻断。
- 吴用：识别“需请公孙胜”这一解决节点，属于判断/方案邻近。
- 戴宗、李逵：承担寻找与请回公孙胜的执行通道。
- 公孙胜：梁山当前缺失的专属法术能力节点。
- 罗真人：公孙胜能否离山以及新法术能否授予的真实外部许可／师门接口。

### 明确动作

1. 高廉妖法使梁山军大败，形成直接军事推进缺口。
2. 吴用提出只有寻公孙胜方能破法，宋江随即派戴宗、李逵前往蓟州寻人。
3. 公孙胜见戴宗、李逵后并未自行立即下山，而是明确表示需禀问师父。
4. 罗真人第一次真实拒绝公孙胜下山，说明该许可不是装饰性节点。
5. 戴宗继续请求后，罗真人才允许公孙胜暂去，并进一步授予可破高廉的五雷正法。
6. 公孙胜回到高唐州后，宋江、吴用与其商议；宋江重新传令拔寨推进。
7. 公孙胜以专属法术压制高廉妖法；梁山军继续公开进攻，高廉被杀，高唐州被攻入，宋江入城后再组织安民并搜救柴进。

### 结果

外部专属处理接口被成功接入，但最终“救柴进、破高唐”的上位方向并未转交给罗真人或公孙胜。外部法术条件被重新纳入宋江的公开军事行动链。

## 2｜zx 判定

本轮 `zx` 不靠“宋江是梁山首领”成立，也不靠单纯胜利成立。

高质量证据集中在：

```text
宋江自己确定并承担救援／攻城方向
+
公开率军进入高唐州冲突
+
在获得外部破解条件后重新传令全军推进
+
高廉原有阻断结构被压破
+
梁山现实作用范围推进到高唐州城内
= zx 当前状态／行为功能高显影
```

这里的 `zx` 锁的是“公开军事推进并把影响范围压入高唐州”这一扩张过程，不把宋江已有的梁山主帅职位本身重复算作 `zx`。

## 3｜nx 判定

`nx` 只成立在“破高廉妖法所需专属法术与师门许可”这一关系功能层，不成立在最终攻城方向层。

关键结构：

```text
宋江已有明确方向
但普通军力／现有手段无法跨过高廉妖法
公孙胜的专属法术不归宋江直接制造
公孙胜又受罗真人师门许可约束
罗真人真实拥有拒绝权，并曾实际拒绝
经请求后罗真人才放行并授法
```

因此锁：

`nx_external_specialist_and_permission_relation_function: evidence-locked`

这不是 `x`：公孙胜的师门许可与罗真人新授正法不在宋江原有处分边界。

这也不是 `xn`：戴宗、李逵怎样寻找人属于流程；“关键能力与许可为什么必须经过公孙胜／罗真人”是外部专属接口问题。

## 4｜严格补关系测试

### 4.1 拿掉 nx 端

拿掉公孙胜、罗真人及等价的专属破法接口，只保留宋江自己的救援方向和梁山军：

- `zx` 的方向与公开军事力量仍成立；
- 但高廉妖法已经在文本中证明能让普通军力失效或严重受挫；
- 宋江现有直接路径留下可命名缺口。

缺口名称：`面对专属妖法阻断时，公开军力缺少可稳定穿透的专属破解接口`。

### 4.2 补回 nx 端

罗真人放行公孙胜并授予正法后，梁山获得此前不能直接制造的有效处理条件，高廉妖法被真正压制。

### 4.3 拿掉 zx 端

只保留罗真人愿意放公孙胜下山、公孙胜拥有破法能力，但拿掉宋江的救援方向、公开主将位置和全军推进：

- `nx` 的外部专家／许可接口仍然存在；
- 但这些条件不会自动变成“梁山攻入高唐、救出柴进”的完整公开现实结果。

缺口名称：`外部专属破解条件缺少被主体转化为持续公开军事推进与结果收束的落地权能`。

### 4.4 补回 zx 端

宋江传令拔寨、组织全军重新进入战场，并在公孙胜破法后继续完成攻城、安民、搜救，外部条件被兑现成现实推进。

因此本例通过补卡红线：两端分别独立成立，拿掉任一端另一端仍在，但会留下具体结构性缺口；补回以后缺口被直接改善。

## 5｜为什么不是普通“请高手帮忙”

普通协作不足以锁严格补关系。本例过线的原因是：

1. 宋江自己的最终方向在公孙胜介入前已成立；
2. 高廉妖法已经用实际败阵证明宋江直接路径存在特定能力缺口；
3. 公孙胜的专属法术无法由宋江加大兵力自行生成；
4. 公孙胜能否离山又受罗真人真实许可控制，且罗真人实际拒绝过；
5. 罗真人后来不仅放行，还授予针对该缺口的新法；
6. 公孙胜回归后没有取代宋江的整场主将方向，宋江重新把外部条件纳入公开军队推进；
7. 双向拿掉都能留下可命名缺口。

所以这不是“宋江+法师=互补”的机械拼人。

## 6｜最近邻排除

### nx vs xn

吴用判断“请公孙胜”、戴宗与李逵寻找路线、来回传报都具有 `xn` 邻近性；但拿掉具体寻找流程，只要公孙胜／罗真人仍是必须经过的外部专属接口，`nx` 关系功能仍成立。

```text
怎么把人找回来 = xn 邻近
为什么必须经过这个人／师门 = nx
```

### nx vs x

宋江拥有梁山军的既有指挥边界属于 `x` 邻近；但罗真人的师门许可、五雷正法与公孙胜的专属法术并不因此归宋江。

### zx vs x

宋江已有梁山主帅军令权是 `x`；本轮 `zx` 不锁“可以命令梁山军”，而锁“以这套公开权能继续突破高廉的外部阻断并把现实影响推进到高唐州”。

### zx vs xn

攻城布置、派将、搜救都有 `xn`；但只靠流程不能替代“宋江作为公开方向主体把梁山力量压进新的现实范围”这一 `zx` 证据。

## 7｜关键压力

关键压力不是“高廉很强”或“宋江打输了”，而是：

```text
宋江已经拥有公开军事力量
+
高廉的妖法属于普通军力无法稳定处理的专属能力边界
→ 继续增加常规兵力不能直接补这个缺口
```

压力使 `nx` 关系功能高显影，但没有把宋江的人物本体换成 `nx`。

## 8｜反向测试

### 纯 zx 版本

若宋江已有可稳定压制高廉妖法的自有能力／直属法术节点，无需外部许可与专家接口即可破法，则中段 `nx` 显著下降。

### 纯 nx 版本

若公孙胜、罗真人不仅提供破法条件，还决定是否救柴进、是否攻城、全军如何推进，宋江只等待他们安排，则 `zx` 主体方向显著下降。

### xn 主位版本

若真正难点只是如何搜索公孙胜、安排时间、分派戴宗李逵、设置联络节点，而专属权限与法术本身并不构成外部边界，则应转查 `xn`，不能锁高纯 `nx`。

### 普通协作版本

若公孙胜本来就在军中、其能力已稳定归宋江直接调用，也没有罗真人许可门，那么更偏既有 `x` 调用／团队协作，而不是本轮的严格 `nx` 补入。

## 9｜第三因素冻结

不得直接判十元：

- 宋江是否英雄、是否义气；
- 高廉善恶与法术是否“真实”；
- 公孙胜是否梁山好汉；
- 罗真人的宗教／神仙身份；
- 戴宗、李逵的个人勇武；
- 柴进是否值得救；
- 高唐州最终胜负；
- 角色职业、身份、绰号。

冻结后仍保留：`自身公开方向 → 专属能力缺口 → 外部许可／专家接口 → 重新公开推进`。

## 10｜稳定本体／状态／行为／关系位置

- 稳定人物本体：不锁。
- 当前状态：`zx` 高显影。
- `zx` 行为功能：公开率军、重新传令推进、把影响范围压入高唐州。
- `nx` 关系功能：请求并接入公孙胜／罗真人这一外部专属能力与许可接口。
- `xn` 最近邻：吴用判断、戴宗李逵寻找、战役组织与搜救流程。
- `x` 最近邻：宋江已有梁山主帅军令权、公孙胜回归后已进入当前行动系统的部分调用。

## 11｜跨作品意义

现行正式机制已有《西游记》孙悟空红孩儿／青牛精等 `zx→权限边界→nx→zx` 锚；《三国演义》已有孙策借兵、曹操借卫弘家资等高质量复验。

本例把同一双向缺口结构扩展到第三部独立作品《水浒传》，且外部缺口从“法宝／兵马／资本”扩展到“专属能力 + 师门许可”。

因此当前可以记录：

```text
跨作品高质量支持：西游记 + 三国演义 + 水浒传
```

但这只是对现有已锁关系的跨作品强复验，不是新的边界问题；本轮不修改 L1，不新建 pending-review，也不空涨补卡版本。
