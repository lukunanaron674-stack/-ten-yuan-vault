# 《水浒传》施恩借武松夺回快活林｜zx-nx 外部强制接口恢复 x 压力测试

## 1｜剧情事实

施恩原先在快活林经营酒肉店，并实际控制当地店家、赌坊等收益接口；蒋忠到孟州后凭武力夺走快活林，并把施恩打伤。施恩说明自己若再起人冲突，还会受到张团练一方正军牵制，因此自己无法低成本恢复原控制。

施恩随后请求武松替自己报怨、夺回快活林。武松接受后前往快活林，公开击败蒋门神，并提出三项条件，其中核心是让蒋门神立即把快活林家火什物交还原主施恩、向施恩赔话，并离开快活林。施恩随后重新进入快活林控制位置。

结构：

```text
原阶段：
快活林经营 / 收益接口归施恩稳定调用
= x

蒋门神武力夺取
→ 施恩原 x 丢失

施恩无法自己恢复
→ 请求武松这一外部强制能力接口
= nx 关系功能

武松击败蒋门神并强制交还
→ 快活林重新归施恩调用
= x 恢复
```

## 2｜nx 判断

本阶段 `nx` 高纯成立在“恢复快活林现实控制”的关系功能层。

施恩自己有明确目标：夺回原来的快活林，并没有把“要不要夺回”这个方向交给武松。真正外置的是解决当前阻断所需的强制能力：蒋门神的武力与张团练背景使施恩原有路径失效，施恩必须通过武松这一不属于自己稳定调用范围的外部能力接口推进。

因此锁定：

`nx_external_force_relation_function: evidence-locked`

这符合 nx v0.5：人物可以很有主意，但某件事的关键能力、资源或解决通道在别人手里，于是通过请求、关系或既有通道取得。

## 3｜x 判断

本例必须把 `x` 分成前后两个阶段。

前段施恩对快活林的经营、店家与收益接口曾经真实处于其稳定调用范围，所以原局部 `x` 成立；蒋门神夺取后，该控制边界真实退出。

武松完成外部强制以后，蒋门神不是仅口头认错，而是被要求交还家火什物、退出快活林，施恩重新成为原控制主体。因此：

`x_control_restored_after_external_intervention: evidence-locked`

这里是“旧 x 恢复”，不是新的 zx 扩权。

## 4｜zx 判断

本窄阶段排除 `zx` 为主判。

施恩虽然最终重新获得现实控制，但没有证据显示其决定范围超过此前已经拥有的快活林边界；现实压制主要由武松公开完成，施恩本人没有凭自身权能把新的、更大处分范围压入现实。

因此：

`zx_in_narrow_stage: rejected_as_primary`

关键纪律：

```text
恢复旧 x
≠ 自动 zx

借别人完成恢复
≠ 借来的公开显权倒算成主体 zx
```

## 5｜关键压力

关键压力不是“施恩比较弱”，而是：

- 原控制已经被蒋门神实际夺走；
- 施恩曾正面反抗但被打伤；
- 蒋门神背后还有张团练正军关系；
- 当前恢复控制所需强制接口真实不在施恩手里。

这组压力让 `nx` 关系功能显影，但不证明施恩稳定人物本体是纯 nx。

## 6｜拿掉测试

### 拿掉武松这一 nx 外部接口

施恩仍有“夺回快活林”的目标，但文本已经证明他自己缺少足以穿透蒋门神与张团练保护结构的现实强制能力。留下明确缺口：

> 原 x 无法恢复。

所以 nx 对恢复 x 的功能是真实的。

### 拿掉施恩原有 x

如果施恩从来没有经营、控制过快活林，只是想借武松去夺取一个原本不属于自己的新地盘，那么结果就不能判“x 恢复”，需要重新检查新夺取、zx 或其他权限结构。

### 拿掉武松击败后的真实交还

如果武松只是打赢蒋门神，但快活林控制、家火和经营接口没有回到施恩，不能锁 x 恢复。

## 7｜反向测试

### 反向成 zx

```text
施恩原来只控制快活林一部分
→ 本轮通过自身公开权能进一步夺取更大地盘 / 新处分接口
→ 周边秩序承认新增边界
= 才检查 zx
```

原文没有。

### 反向成非 nx

```text
施恩自己已经拥有足以稳定调用的武力 / 军力
→ 无需经过武松等外部接口
→ 自行恢复快活林
= 转查 x / zx / xn
```

原文不是。

## 8｜最近邻排除

### nx vs x

- `nx`：恢复控制所需关键强制能力在武松手里，施恩通过关系请求借用。
- `x`：恢复完成后，快活林本身重新进入施恩稳定调用边界。

因此同一链可以发生：

`x丢失 → nx借力 → x恢复`

### nx vs xn

施恩并没有主动搭建复杂流程、重新配置多节点资源；关键动作是请求武松这一外部能力接口，因此不是以 xn 为主。

### nx vs zx

武松的公开压制不能倒算成施恩自己的 zx。zx 要求主体自身权能公开显现并使自身决定范围上升；本例施恩主要恢复旧 x。

## 9｜第三因素冻结

冻结：

- 武松武力值；
- 施恩与武松是否结拜；
- 蒋门神善恶；
- 快活林经营是否合法；
- 最终谁更受读者喜欢；
- 后续张都监反击与飞云浦事件。

只问：

1. 原控制是否曾归施恩？
2. 是否被蒋门神实际夺走？
3. 恢复所需关键强制接口是否在武松？
4. 施恩是否实际沿该关系接口推进？
5. 结果是否恢复旧控制，而非扩大到新范围？

五项均高置信成立。

## 10｜严格 zx↔nx 补关系检查

不锁。

本例只有 `nx` 关系功能与 `x` 恢复被高置信锁定；施恩自身 `zx` 独立端未成立，因此严格补卡第一道“两端独立成立”即失败。

不能写成：

> 武松很强 + 施恩求人 = zx+nx 严格补。

## 11｜结论

本轮锁定：

> **施恩夺回快活林 = `x 丢失 → nx 外部强制接口 → x 恢复`。**

案例级纪律：

> **nx 不只能够帮助主体取得新资源，也可以作为恢复既有 x 的外部解决接口；而“恢复旧 x”本身不自动构成 zx。**

不升级理论正本；不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
