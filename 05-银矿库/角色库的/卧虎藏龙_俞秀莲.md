# 俞秀莲
> 归档：`05-银矿库/角色库/卧虎藏龙_俞秀莲.md`

---

## 1. 主十元判断

**主十元：n（阳土·承载/适应）**

**五问法核验：**
- **第1问（拿掉什么他不是她）：** 拿掉n，俞秀莲就是一个武功高强的女侠——但她没有「必须撑住谁」的理由。她对谁都好——帮李慕白送剑、照顾玉娇龙、承接镖局的压力——不是因为她心软，是因为**她从来都是那个不让东西塌下来的人**。整个卧虎藏龙里最稳定的存在不是青冥剑，是俞秀莲这个人。
- **第2问（反复面对什么结构）：** 反复面对「所有人都可以任性，我不行」。李慕白可以闭关、玉娇龙可以逃跑、碧眼狐狸可以复仇——只有俞秀莲一直在原地，接住所有人。n的人不是没有欲望，是她们选择不让自己塌。
- **第3问（最怕失去什么）：** 最怕「她撑住的东西最后发现不值得」。所以李慕白临终表白那场戏最痛的其实不是李慕白，是俞秀莲——她等了那么多年，他终于说了，然后他就死了。n的人不怕等，怕等到的时候已经没有时间了。
- **第4问（回到哪个感觉）：** 回到「我还能继续走」。李慕白死后她没有留在原地崩溃——她回了镖局。n的人哭完还是会把碗洗了。
- **第5问（副十元服务谁）：** xn（规矩/镖局的制度）是n的管理工具。俞秀莲在镖局按规矩办事不是因为她信奉制度，是因为没有规矩她撑不住这么大的摊子。

## 2. 副十元

**副十元：xn（阳金·规则/制度）**

**作用：** 俞秀莲做事有章法、按规矩来。这不是她的人格底色，是她撑住局面的方法。

## 3. 功能十元

**功能十元：zx——偶尔使用。** 追玉娇龙出逃的时候她有过一次突破常规的行动，但只是一次。

## 4. 视觉十元

**视觉十元：无显著。** 朴素的着装是她选择不定义自己。

## 5. 动态链

```
n（主·不让任何人塌下去）
  → xn（副·规矩是撑住局面的方法）
  → 接住李慕白 → 接住玉娇龙 → 接住镖局 → 接住离别
  → 李慕白死了
  → 回了镖局——继续走
```

## 6. 一句话定型

俞秀莲不是「江湖中克制隐忍的女侠」，而是「**所有人都可以倒，她不行**的人」。
