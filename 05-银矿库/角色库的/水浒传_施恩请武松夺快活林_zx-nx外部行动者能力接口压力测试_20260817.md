# 《水浒传》施恩请武松夺快活林｜zx-nx 外部行动者能力接口压力测试

## 0｜本轮问题

近期案例已经形成一条行动者调用边界：

- 猪八戒请已离队孙悟空回援：对方保有真实“是否出手”资格，需请求/激将，锁 `nx` 外部行动者关系功能。
- 诸葛亮北伐点将：诸将已处于既有军令调用边界，优先 `x + xn`，不能因“用了别人能力”判 `nx`。
- 孙悟空被逐前后：组织/关系内日常任务能否直接等价为 `x` 稳定调用边界仍保留灰区。

本轮换《水浒传》，检查施恩与武松是否能提供第二部作品的高纯“外部独立行动者能力接口”证据。

## 1｜剧情事实

施恩说明自己原先经营快活林，后来蒋忠依仗张团练势力夺走其道路；施恩曾与蒋门神冲突并被打伤，自己也明说“力薄艺疏，便敌他不过”。

施恩随后向武松说明此事，并直接请求武松替自己报仇雪恨。这里不存在施恩对武松的既有稳定命令关系：施恩不能直接处分“武松是否必须替自己打蒋门神”。

武松听完以后自行判断蒋门神并非不可战，明确表示愿意立即同施恩前往，并愿自行承担拳重打死后的后果。施恩父子之后反而需要劝武松稍缓、探听蒋门神是否在家，说明武松仍保有实际行动决定权。

第二十九回中，武松又自己规定“无三不过望”的出行方式，最后还让施恩留在别处，自己进入快活林处理蒋门神。施恩提供目标与关系背景，但武松并未转化为施恩可直接调用的既有下属资源。

## 2｜触发、对象、动作、结果

- 触发：施恩自身力量及现有营中关系无法稳定解决蒋门神与张团练这一对手结构。
- 对象：武松作为独立行动者的战斗能力与“是否出手”决定界面。
- 施恩动作：说明利益受损、能力缺口与对手情况，向武松请求帮助。
- 武松动作：自行评估、本人同意，并进一步自行决定行动时间与具体打法。
- 结果：施恩成功接入武松这一外部能力节点，但没有取得对武松的稳定处分权。

## 3｜nx 判断

本轮高置信锁 `nx` 关系功能，而不是纯 nx 本体。

施恩的方向很明确：他要夺回快活林、报蒋门神之仇。因此“没主见型 nx”不成立。

但关键缺口在于：

```text
施恩自己有目标
↓
自身能力/原有力量无法解决
↓
武松的战斗能力属于武松本人
↓
施恩必须通过结交、请求、说明利害让武松本人同意
↓
武松保有真实拒绝与重新决定怎样行动的资格
= nx 外部行动者能力接口
```

正式锁：`nx_external_agent_relation_function: evidence-locked`。

这与 nx v2.5 的关系功能相符：自己的权能不能直接解决问题时，进入已有关系网络，请求、借力、请救兵或借用他者力量推进。

## 4｜zx 判断

本轮不锁施恩高纯 `zx`。

施恩最终确实因武松出手而重新取得快活林，但“结果有利于施恩”不等于“施恩自己的权能公开扩张”。

本桥段没有证明：

- 施恩自身战斗或处分权公开压过蒋门神；
- 武松的行动能力转移成施恩可独立调用的稳定权限；
- 施恩取得一个此前不存在的新组织决定接口；
- 外部秩序因施恩自己的新增权能而围绕他重排。

因此 `zx_in_narrow_stage: rejected_as_primary`。

武松实际击败蒋门神所产生的强 zx 行为/状态，不得跨人物归因给施恩。

## 5｜x 最近邻排除

本轮与“诸葛亮北伐点将”最大的差异就在 `x vs nx`。

### 若是 x 调用边界

应看到：武松已经进入施恩的稳定组织处分范围，施恩可以直接分配其战斗任务，不需要武松本人重新决定“是否替我出手”。

### 本文实际

- 施恩明确“央”武松帮忙；
- 武松本人评估后同意；
- 武松对什么时候去、怎样去、怎样打拥有显著独立决定资格；
- 施恩甚至无法让武松按自己希望的“休养、探听后再去”节奏行动。

所以 `x_existing_command_boundary_for_wusong: rejected`。

## 6｜xn 最近邻

施恩父子确实考虑探听蒋门神是否在家、安排后援；武松也自行设计饮酒、独自接近等具体打法。这些可以分别形成各自的 `xn` 行为邻近。

但 `xn` 回答“怎样组织这次行动”，不能替代本轮的核心：

> 为什么施恩不能直接调用武松，而必须让武松本人同意？

因此 nx 外部行动者关系功能独立成立。

## 7｜拿掉测试

### 拿掉施恩受伤与“打不过”描述

只要武松仍是施恩不能直接处分、必须本人同意是否出手的独立行动者，nx 关系功能仍存在；只是能力缺口的强度会下降。

### 拿掉拜兄弟、酒食和恭敬礼仪

若只保留“施恩有目标 → 武松是外部独立能力节点 → 施恩需要请求其本人同意”，nx 仍成立。因此人情礼仪不是判据，只是接入通道。

### 拿掉武松本人同意

如果武松拒绝，施恩无法直接命令其出手，这恰好反向证明关键行动接口没有归施恩。

### 拿掉武松

施恩原有能力缺口重新暴露，快活林问题不能按同一方案解决，证明武松不是普通装饰性协作，而是关键外部能力节点。

## 8｜反向测试

### 反向成 x

如果武松本来就是施恩麾下受其稳定军令处分的人员，施恩可以直接安排“去击败蒋门神”，武松只决定具体打法，那么应优先检查 `x + xn`，不是 nx。

### 反向成 zx

如果施恩不是借武松出手，而是在事件中以自己的新增权能公开压过蒋门神、张团练并扩大现实决定范围，才应提高 zx。

### 反向成纯 nx

若施恩连“是否夺回快活林”都不自己决定，而完全等待父亲、武松或其他人替他定方向，才接近纯 nx 本体。本桥段不支持。

## 9｜第三因素冻结

冻结：

- 武松武力高低与英雄评价；
- 施恩是否经营灰色利益；
- 蒋门神是否恶人；
- 张团练背景；
- 快活林最终赚钱多少；
- 双方结拜情义；
- 最终胜负。

只保留：

`施恩是否拥有自己的方向 → 武松能力是否已归施恩调用 → 武松是否保有本人出手决定权 → 施恩是否必须通过关系请求接入`。

结论仍指向 nx 关系功能。

## 10｜与已有案例的最小差异

### 《西游记》猪八戒义激猴王

已离队孙悟空保有“帮不帮”的真实决定资格，八戒只能请求/激将 → `nx` 外部行动者关系功能。

### 《三国演义》诸葛亮北伐点将

诸将军务行动已经处于既有统帅调用边界，可直接分职拨兵 → `x` 调用边界 + `xn` 组织，排除 nx。

### 本轮《水浒传》施恩请武松

武松不是施恩现有下属，施恩必须说明利害并请求，武松本人决定是否出手及具体行动 → `nx` 外部行动者关系功能。

因此当前跨作品支持：

```text
独立行动者保有真实“是否出手”资格
+ 主体必须通过关系请求接入
→ nx 外部行动者关系功能增强
```

目前高纯正向证据来自《西游记》《水浒传》2部；反向 `x` 对照来自《三国演义》。尚未达到同类正向3作品阈值，不新建待审议问题。

## 11｜结论

```text
施恩：目标自己有
武松：关键能力与出手决定仍属于武松本人
施恩无法直接处分该能力
→ 必须请求/结交/借力
→ nx 关系功能 evidence-locked

借到武松并成功夺回快活林
≠ 施恩自身 zx 扩权
```

本轮不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
