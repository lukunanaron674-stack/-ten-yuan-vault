# 《红楼梦》平儿玫瑰露案｜方案真实重设后，外部审批接口仍可保留 nx 关系位置

## 结论先行

本轮锁定一个位于“纯执行自由度”与“完整方案重写”之间的中间样本：

> 凤姐最初已经给出明确处分方案：重罚柳家母女并逐出。平儿没有沿原方案机械执行，而是继续调查、核对芳官与宝玉等信息，形成“不要扩大追查、从轻放过”的替代处置；但平儿最终仍需要回到凤姐这一真实处分接口，通过劝说取得放行，之后才“一一发放”。

因此本轮应拆成两个对象层：

```text
处置方案怎么改
→ 平儿主动调查、判断、重设
→ xn 最近邻高显影

最终能不能推翻凤姐原处分
→ 仍需凤姐同意
→ nx 权限关系仍成立
```

结论不是“只要重写方案，nx 就全部消失”，而是：

> **主体可以在运行方案层取回重设权，同时在最终批准/处分层仍处于 nx 关系位置。对象层必须拆开。**

本轮不锁平儿稳定人物本体，不锁严格 zx↔nx 补关系。

## 1｜剧情事实

### 触发

玫瑰露、茯苓霜被发现后，林之孝家的将柳五儿带到凤姐一边。凤姐听报后直接给出严厉处分方向：柳家母女受打、逐出，并要求继续追究。

### 平儿没有直接沿原处分方案执行

平儿没有把“凤姐已下令”当作终点，而是继续：

- 听柳五儿说明玫瑰露来源；
- 去核对袭人、芳官的说法；
- 与宝玉等进一步核实；
- 识别玫瑰露、茯苓霜两件事背后的不同来源与牵连；
- 评估继续追查会误伤何人、扩大多少内部矛盾；
- 形成“得放手时须放手”的替代处置判断。

这已经超过外部方案预留的普通执行自由度。它直接改变了：

- 是否继续追查；
- 是否执行原重罚；
- 是否扩大牵连；
- 最终如何结案。

因此在“怎么处理这一案”这个运行层，平儿不是单纯 nx 执行者。

### 但最终处分接口仍在凤姐

关键证据同样明确：平儿最后仍需要把自己的从轻方案带回凤姐处。凤姐一开始仍主张继续严查，平儿再次劝说后，凤姐才表示“随你们罢”，平儿随后出来逐一放人、结案。

因此：

```text
平儿能形成替代方案
≠ 平儿原本就拥有最终处分权
```

原方案的真正撤销仍经过凤姐这个外部批准接口。

## 2｜zx 判断

本轮高纯 zx 排除。

理由不是平儿“不够强”，而是现行 zx 要求：

```text
主体自身权能公开进入现实
→ 他者/秩序围绕主体重新反应
→ 主体决定范围或凌驾位置真实上升
```

本段里，平儿确实成功影响凤姐并改变结案结果，但没有证据显示：

- 凤姐的家内最高处分权转移给平儿；
- 平儿以后可以绕开凤姐独立决定同等级处分；
- 贾府秩序承认一个新增的“平儿最高处分接口”。

所以：

> **成功说服掌权者修改决定 ≠ 自己取得更高决定权。**

本轮 `zx_in_narrow_stage: rejected_as_primary`。

## 3｜nx 判断

### 纯 nx 本体排除

平儿显然不是在这一桥段“没主见、安排什么就做什么”。恰恰相反，她在获得低成本重设窗口后主动调查、形成替代判断，并真正改变了原方案。

因此不能锁纯 nx 本体。

### nx 权限关系保留

但在“最终处分是否生效”这一对象层，权限仍属于凤姐。

最小结构：

```text
凤姐给出原处分
↓
平儿自行调查并重设方案
↓
平儿不能仅凭自己判断直接废掉凤姐决定
↓
回到凤姐处劝说
↓
凤姐放行
↓
平儿执行新的结案方案
```

所以本轮锁：

`nx_final_approval_relation_position: evidence-locked`

这不是“方向全由凤姐决定”，而是“最终批准接口仍在凤姐”。

## 4｜nx vs xn 最近邻

这是本轮核心。

### xn 回答

```text
谁主动调查？
谁重组证据？
谁形成替代处置？
谁改变追查与结案方式？
```

答案主要是平儿。

因此运行方案层 `xn` 高显影。

### nx 回答

```text
谁拥有推翻原正式处分的最终批准接口？
```

答案仍是凤姐。

因此不能写成：

```text
主体一旦改方案
→ nx 在所有层级全部归零
```

更准确的对象分层是：

```text
方案组织权回到主体
→ xn 上升 / 该运行层 nx 下降

最终批准权仍在外部
→ nx 权限关系仍保留
```

## 5｜拿掉测试

### 拿掉凤姐

如果平儿原本就拥有独立结案、减免处分的完整权限，不需要任何上级确认，那么本轮 nx 权限关系会显著下降，优先转查 `x/xn`。

### 拿掉平儿的主动调查与替代方案

如果平儿只是把凤姐原令原样传下去，那么 `xn` 下降，整个桥段更接近普通 nx 行为执行。

### 拿掉最终“随你们罢”的批准

如果凤姐拒绝，平儿不能合法完成当前从轻结案。这说明最终批准接口并未在平儿手中稳定成立。

## 6｜反向测试

### 反向成更纯 nx

凤姐给出处分方案后，平儿不调查、不重设、不提出替代处理，只负责传令和执行。

### 反向成更纯 xn/x

凤姐只给“查清此事”这个总目标，平儿拥有独立调查、定案、处分和结案权，无需逐项回报批准。

### 反向成 zx

平儿在原本没有该处分权的情况下，通过事件公开取得更高家内裁决位置，之后同等级案件都可由她独立决定，贾府人员围绕这一新增接口运行。

本段没有达到这一条件。

## 7｜第三因素冻结

冻结以下因素后，主结论不变：

- 平儿“贤惠”“聪明”“会做人”的人物评价；
- 凤姐身体状况；
- 柳五儿是否最终完全无过；
- 宝玉主动揽事；
- 彩云、赵姨娘等人物牵连；
- 谁更善良、谁更残酷的道德判断；
- 最终有没有人受罚。

只保留：

```text
原方案来自谁
主体是否实际重设关键处理结构
最终批准权属于谁
主体能否绕开该批准接口
```

结论仍成立。

## 8｜与现有待审议问题的增量

现有待审议已锁定：

```text
外部方案存在
+ 主体实际重设关键运行结构
→ 当前运行层 nx 下降
→ xn 应优先检查
```

上一轮孙悟空红孩儿诱敌又锁定反例：

```text
只改局部执行动作
+ 不动关键节点/资源/最终接口
→ 不足以叫方案重写
→ nx 仍可保持
```

本轮进一步增加第三档：

```text
主体真的改了关键方案
但最终批准/处分接口仍在外部
→ 运行方案层 xn 上升
+ 批准权限层 nx 仍可并存
```

因此当前连续谱可以暂记为：

```text
A. 外部方案 + 仅局部动作自由
   → nx 维持

B. 外部方案 + 主体重设关键运行结构
   → 该运行层 nx 下降，xn 上升

C. 主体重设关键运行结构
   + 最终批准/处分接口仍外置
   → xn 方案层 + nx 权限关系层并存
```

这只是案例级纪律，不修改 L1。
