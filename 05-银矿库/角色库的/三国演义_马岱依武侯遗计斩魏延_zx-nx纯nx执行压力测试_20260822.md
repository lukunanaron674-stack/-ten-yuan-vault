# 《三国演义》马岱依武侯遗计斩魏延｜zx↔nx 纯 nx 执行压力测试

## 0｜结论先行

本轮只锁：诸葛亮临终前把马岱单独召入帐中授以密计，马岱接受；诸葛亮死后，马岱依计潜伏在魏延身边，直到杨仪按锦囊把魏延诱到预设口令，马岱才从背后斩杀魏延这一窄阶段。

结论：

> **这是一个高纯 `nx` 当前行为 / 关系位置正例。**
>
> 最终处理方向、潜伏关系、触发条件和执行时点均已由诸葛亮预先设定，马岱没有重写最高终点，而是实际沿既有密计持续推进；虽然最后一刀公开、强烈并直接改变结果，但没有形成马岱自身决定范围的扩大，所以 `zx` 排除；执行窗口也没有由马岱重新搭建流程，因此 `xn` 不作主判。

不锁“马岱稳定人物本体 = 纯 nx”。一次高度服从的密计执行，只能锁当前行为与关系位置。

```text
诸葛亮预设密计
→ 马岱接受
→ 依计潜伏魏延身边
→ 等待预设触发窗口
→ 杨仪按锦囊诱发口令
→ 马岱按约定时点斩魏延
= nx 当前行为高显影
```

---

## 1｜剧情事实

### 触发

诸葛亮临终前预计魏延死后可能生变，先召马岱入帐，附耳授以密计，并明确嘱咐“我死之后，汝可依计行之”。随后又给杨仪锦囊，要求魏延真正反叛、临阵对敌时方可拆开。

### 对象

本轮对象不是“马岱是否勇猛”，而是：

- 魏延反叛后由谁决定最终处置方向；
- 马岱是否自己建立潜伏、诱导、触发和斩杀流程；
- 马岱最后公开杀魏延是否构成自己的 `zx` 扩权。

### 明确动作

1. 马岱接受诸葛亮密计；
2. 诸葛亮死后，马岱仍待在魏延身边，表面表示愿意相助；
3. 魏延军心溃散后，马岱继续维持潜伏位置，甚至顺着魏延“取汉中、图两川”的话继续取得信任；
4. 杨仪到预定对阵时才拆锦囊，并按计要求魏延连叫“谁敢杀我”；
5. 魏延第一声尚未完，马岱即按预设触发从背后斩杀；
6. 原文随后明说：诸葛亮临终时已经授马岱密计，“只待魏延喊叫时，便出其不意斩之”。

### 结果

魏延被杀，蜀军内部这场叛乱危机被终止；马岱后来因讨逆有功获封，但这个后续奖赏来自后主重新授予，不能倒灌成“斩魏延当刻马岱完成 zx 扩权”。

---

## 2｜为什么当前阶段判 nx

现行 nx 核心要求：

```text
方向、权限或解决通道已经存在
→ 主体不把自己放在最终决定位置
→ 沿外部安排、关系、流程或既有秩序推进
```

马岱逐项命中：

- **最高方向外置**：是否处置魏延、何时处置，不是马岱临场自行决定；
- **关系位置外置**：马岱的“假意相助魏延”是诸葛亮密计的一部分；
- **触发条件外置**：不是“我觉得现在差不多可以杀”，而是等到杨仪依锦囊把魏延诱入指定口令；
- **实际续接**：马岱并非口头领计，之后持续维持潜伏，直到真正执行预定终点。

因此锁：

`nx_behavior_function: evidence-locked`

`nx_relation_position: evidence-locked`

但不锁稳定人物本体。

---

## 3｜zx 为什么排除

马岱最后的动作极醒目：公开斩杀魏延，直接改变危机结果。

但现行 zx 不能由“动作强、杀了重要人物、战果大”直接推出。必须继续检查：

```text
主体自己的权能是否公开扩大？
外部系统是否围绕马岱新增的决定接口重新运行？
马岱的决定范围是否比行动前更大？
```

本段答案均不足：

- 马岱没有夺取诸葛亮、杨仪或后主的最终处分权；
- 斩魏延正是在执行预设授权，而不是把既有权限推到新范围；
- 后续受封是后主对功劳的重新授予，属于另一个对象层与时间窗口；
- 如果只看“谁让魏延必须在这个节点被杀”，最终方向来源仍是诸葛亮预设结构。

因此：

`zx_in_execution_stage: rejected_as_primary`

最小纪律：

> **公开完成一个决定性动作，不等于主体取得了决定这个动作是否发生的最高位置。**

---

## 4｜nx vs xn

这是本轮最重要的最近邻。

表面上马岱做了潜伏、欺骗、等待、临场斩杀，很容易把“复杂执行”误写成 `xn`。

但现行 `xn` 更强调主体主动组织流程、节点、资源、记录与持续运行结构。

本段决定性骨架已经在外部：

```text
诸葛亮授密计
→ 马岱潜伏
→ 等魏延反叛
→ 杨仪临阵拆锦囊
→ 诱发“谁敢杀我”口令
→ 马岱执行斩杀
```

马岱没有重写：

- 目标对象；
- 潜伏角色；
- 启动条件；
- 触发口令；
- 最终处置路径。

所以：

`xn_in_execution_stage: rejected_as_primary`

这不是说马岱完全没有临场判断，而是说**局部执行判断没有替换决定性运行骨架**。

---

## 5｜关键压力

关键压力是：

```text
诸葛亮死亡
+ 魏延与杨仪冲突公开化
+ 魏延烧栈道、率军争夺
+ 蜀军需要在不提前暴露马岱的情况下终止叛乱
```

这些压力解释密计为什么需要潜伏和延迟触发，但不能直接判十元。

冻结：

- 马岱武力强弱；
- 魏延是否真的“反”；
- 诸葛亮预测是否神机妙算；
- 谁道德上正确；
- 马岱后来得到什么爵位；
- 斩杀动作是否英勇。

只问方向、流程和最终处分来源。

---

## 6｜拿掉测试

### 拿掉诸葛亮的密计

如果没有预先授计，只剩：

> 马岱自行判断魏延危险 → 自行假投 → 自行等待 → 自行寻找机会斩杀。

那么当前 `nx` 核心证据会显著下降，转而必须检查 `xn / x / zx`。

### 拿掉杨仪的锦囊触发

只要仍能证明诸葛亮已把具体触发条件交给马岱，`nx` 仍可存在；但现文本由“杨仪锦囊 + 马岱密计”形成双端闭合，使证据更强。

### 拿掉最后斩杀成功

如果马岱一直按密计潜伏并等待预设触发，却最终失手，`nx` 行为功能仍然成立。

因此：

> **胜负不是 nx 的判据。**

### 拿掉后续封爵

当前分类完全不变。说明后主奖励不是 `zx` 成立支柱。

## 7｜反向测试

### 真 xn 版本

```text
诸葛亮只说“提防魏延”
→ 马岱自己设计假投
→ 自己安排接近方式
→ 自己设触发信号
→ 自己安排最终斩杀窗口
= xn 显著上升
```

### 真 zx 版本

```text
诸葛亮没有给处置授权
→ 马岱公开夺取魏延处置权
→ 凭自身权能改变蜀军最高处分结构
→ 众将必须承认马岱新增决定位置
= 才检查 zx
```

### 持续 nx 版本

原文就是：

```text
外部给定决定性方案
→ 主体不重写最高终点
→ 长时间维持角色
→ 到触发点执行
= nx
```

---

## 8｜最近邻排除

### nx vs xn

- `nx`：别人已经把决定性结构给出来，我沿它继续。
- `xn`：我自己搭流程、设节点、重排运行结构。

本段主判 `nx`。

### nx vs x

马岱没有稳定拥有“谁可以被认定为叛将并处死”的最高处分范围；因此不是正常调用既有 `x`。

### nx vs zx

“手起刀落、改变结果”只是动作结果；没有证明决定范围扩大。

### nx vs z

魏延对马岱的信任只解释潜伏为何有效，不是本轮木轴核心。

---

## 9｜严格 zx↔nx 补关系

不锁。

本例当前只有高纯 `nx` 执行端，马岱自身 `zx` 端没有独立成立，因此严格补关系第一门即失败。

---

## 10｜稳定本体纪律

本轮只记录：

- 当前状态；
- 行为功能；
- 关系位置。

不记录：

> 马岱稳定人物本体 = 纯 nx。

要锁稳定本体仍需跨场景、跨对象反复证明其长期不占最终方向，且在低强迫自主窗口下仍保持这一模式。

---

## 11｜结论

本轮可靠结论：

> **马岱依武侯遗计斩魏延，是高纯 `nx` 当前执行正例。决定性方向、潜伏结构与触发条件来自外部，马岱真实续接并完成；动作再强也不能倒推 `zx`，复杂执行也不能替换为 `xn`。**

进一步压成：

```text
别人预设终点 + 节点 + 触发
→ 我真实承接并持续执行
= nx

我亲手完成最后一击
≠ zx

执行过程有欺骗、等待和临场动作
≠ 自动 xn
```

本例不修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡。
