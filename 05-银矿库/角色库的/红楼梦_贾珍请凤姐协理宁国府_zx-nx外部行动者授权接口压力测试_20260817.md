# 《红楼梦》贾珍请凤姐协理宁国府｜zx↔nx 外部行动者授权接口压力测试

## 1｜本轮问题

测试一个独立行动者的能力何时属于 `nx` 外部关系接口，何时只是主体既有 `x` 调用边界。

本轮主体只取 **贾珍**，阶段只取 **秦可卿死后，贾珍需要王熙凤协理宁国府丧事**。

不把凤姐后来协理宁国府时自身的 `zx/xn` 高显影倒灌给贾珍。

## 2｜剧情事实

1. 秦可卿死后，宁国府内务繁重，贾珍需要一个能实际料理内务的人。
2. 王熙凤并非贾珍在宁国府内可以直接调令的普通下属，她属于荣府一侧，且王夫人对她是否过去协理拥有真实授权位置。
3. 贾珍为此向王夫人苦苦请求，希望凤姐过去帮忙。
4. 王夫人最初担心凤姐没有办过丧事、料理不好，并未直接自动放行。
5. 凤姐本人听到贾珍请求后，心中愿意，并主动向王夫人表示可以承接。
6. 王夫人进一步向凤姐确认是否能办；凤姐明确答应。
7. 贾珍随后才交出宁国府对牌，明确允许凤姐在宁府内部调用所需资源。
8. 王夫人仍提醒凤姐，有重要事项要询问贾珍、尤氏等，说明授权具有明确对象与边界，而不是贾珍天然拥有对凤姐本人的全面命令权。

## 3｜触发—对象—动作—结果

```text
触发：宁国府丧事内务出现管理能力缺口
对象：王熙凤这个独立行动者及其管理能力
动作：贾珍向王夫人请求授权，同时请求凤姐本人承接
结果：王夫人放行 + 凤姐本人答应后，凤姐进入宁府并获得对牌开始协理
```

## 4｜nx 判断

### 4.1 主体自己有方向，不是纯 nx

贾珍的目标很明确：把秦可卿丧事和宁国府内务料理好。

因此不能写成：

```text
贾珍没主见
→ 找凤姐替他决定做什么
= 纯nx
```

本轮不锁贾珍稳定人物本体。

### 4.2 nx 成立在“外部行动者能力接口”

关键问题是：**王熙凤的管理能力是否已经处在贾珍稳定可直接调用的边界内？**

文本给出的答案是否定的。

贾珍不能直接一句军令式命令让凤姐进入宁府。他必须：

```text
自己有明确目标
↓
但关键管理者不在自己的稳定命令边界
↓
向王夫人请求授权
+
让凤姐本人答应承接
↓
两道外部门通过以后
↓
才能把凤姐接入宁国府运行
```

因此锁：

`nx_external_agent_relation_function: evidence-locked`

这符合 nx 的关系功能：主体有自己的目标，但关键解决行动者、权限或通道在外部，需要沿既有人际和授权网络取得。

## 5｜双重门结构

本例比普通“求人”更硬，因为存在两种不同门：

### A｜制度/家庭授权门

王夫人可以不让凤姐过去，且文本真实出现犹豫与能力担忧。

因此：

`external_authorization_gate: evidence-locked`

### B｜行动者本人承接门

凤姐本人明确表现出“愿不愿意、能不能”的自主确认。王夫人也直接问她是否能办。

因此：

`external_actor_consent_gate: evidence-locked`

这说明外部行动者 nx 不是“这个人属于谁”的人格所有权问题，而是：

> **在这个具体行动上，主体能不能绕开对方本人和相关授权节点，直接使其行动生效。**

## 6｜zx 判断

本轮 `zx` 排除为主判。

贾珍主动求人、成功把凤姐请来，不能证明自己的决定范围扩大。

真正发生的权限变化反而是：

```text
贾珍把宁国府内部的一部分实际管理调用权
通过对牌交给凤姐
```

并没有出现：

- 贾珍取得对凤姐新的长期人身/行动处分权；
- 荣府以后必须围绕贾珍新增的命令接口运行；
- 王夫人的授权位置被贾珍夺走；
- 凤姐本人的承接资格被取消。

所以：

`zx_in_narrow_stage: rejected_as_primary`

成功请来强者，不等于主体自己的 `zx` 权能扩张。

## 7｜最近邻排除

### nx vs x

`x` 需要“这一行动调用边界已经稳定归主体掌握”。

如果凤姐原本就是贾珍宁府内的直接下属，贾珍可以在职责范围内直接派她料理丧事，无需王夫人许可，也无需重新取得凤姐承接，那么应优先检查 `x/xn`。

本例恰恰相反，所以：

`x_existing_command_boundary_for_wang_xifeng: rejected`

### nx vs xn

贾珍本身当然参与丧事组织，但本轮核心不是“他如何排流程”，而是“为什么他必须经过外部门才能调用凤姐这名关键行动者”。

因此 `xn` 不能替代本轮 nx。

### nx vs nz

亲族关系、旧情可以解释为什么请求更容易成功，但本轮关系被用作 **能力/授权通道**，而不是关系本身成为终点，因此主判仍是 nx 关系功能。

## 8｜拿掉测试

### 拿掉凤姐的个人姓名

换成任何一个不在贾珍稳定命令边界、但拥有关键管理能力的人，只要仍必须取得相关授权与本人承接，nx 结构不变。

### 拿掉王夫人

如果没有王夫人这一层，但凤姐本人仍拥有真实的“帮不帮”决定资格，外部行动者 nx 仍然存在，只是双重门退化成单门。

### 拿掉凤姐本人同意

如果王夫人可以把凤姐作为完全无自主拒绝权的内部资源直接调过去，则“独立行动者本人承接门”消失，结构会更接近组织 `x` 调用边界。

### 拿掉贾珍的目标

如果贾珍自己连“要不要找人协理”都没有方向，只等别人替他决定，则会另增纯 nx 本体证据；当前文本不支持这种写法。

## 9｜反向测试

### 反向成 x

```text
凤姐已经属于贾珍稳定职责调用边界
→ 同类内务任务可直接分派
→ 无需重新求王夫人
→ 无需重新取得凤姐本人承接
= 优先检查 x / xn
```

### 反向成 zx

```text
贾珍原本无权调动荣府人员
→ 本事件后公开取得并长期控制这一新增跨府调用权限
→ 荣府必须围绕贾珍新增接口运行
= zx 才会上升
```

当前文本不支持。

## 10｜第三因素冻结

冻结以下因素后结论不变：

- 贾珍的家主身份；
- 凤姐“能干”的人物评价；
- 秦可卿丧事规模；
- 贾琏是否在外；
- 贾珍与凤姐亲属称谓；
- 后续凤姐协理宁国府是否成功；
- 凤姐后来在宁府出现的 `zx/xn` 行为。

本轮只看：

> **关键行动者能否被主体直接调用，还是必须经过对方本人/外部授权节点重新放行。**

当前同边界独立作品数：`3`

诸将已经进入既有军令调用边界，诸葛亮可以直接分职、拨兵，主判为 `x + xn`，不是 nx 外部行动者。

## 12｜结论

正式锁定：

```text
独立行动者的能力可以成为 nx 外部接口。
判定关键不是“我用了别人”，而是：
在该具体行动上，对方是否仍保留本人重新同意/拒绝的资格，
或是否存在主体无法绕开的真实外部授权门。
```

反向：

```text
若该行动已经真实纳入主体稳定命令/职责调用边界，
则“使用别人能力”不应自动判 nx，优先检查 x/xn。
```

本轮不修改 L1、zx/nx 信息卡、准度卡或 zx补nx 补卡。跨三作品后仅允许形成待审议问题。
