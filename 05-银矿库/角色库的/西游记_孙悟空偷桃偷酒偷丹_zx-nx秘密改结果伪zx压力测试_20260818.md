# 《西游记》孙悟空偷桃偷酒偷丹｜zx↔nx 秘密改结果伪 zx 压力测试

## 1｜剧情事实

对象截面限定在第五回中孙悟空代管蟠桃园后，秘密偷食蟠桃、潜入瑶池偷饮御酒、误入兜率宫偷食金丹，并因担心获罪而隐身逃回花果山这一连续桥段；不把随后天庭发现、调十万天兵围剿以及孙悟空公开迎战的阶段倒灌回来。

事实链：

1. 玉帝授孙悟空“权管蟠桃园”的职责，园中土地、力士等在该职责范围内向其见礼并接受管理。
2. 孙悟空想吃成熟蟠桃时，先支开随从，脱冠爬树偷食；此后又反复设法偷桃。
3. 得知蟠桃会未请自己后，孙悟空定住七仙女，骗走赤脚大仙，变作其模样潜入瑶池；又使造酒等人员睡去，偷吃御酒与宴物。
4. 误入兜率宫后，趁太上老君与仙官不在，进入丹房，把葫芦中的金丹吃掉。
5. 酒醒后孙悟空判断“若惊动玉帝”将获罪，于是不用旧路，以隐身法逃出天门，返回花果山。
6. 直到七仙女、造酒人员、太上老君、齐天府仙吏与赤脚大仙分别奏报，天庭才查明事件并开始公开追捕；这是后续阶段。

触发：对蟠桃、宴会、御酒、金丹的欲求，以及未受邀蟠桃会后的不满。

对象：蟠桃、御酒、金丹等资源的实际结果，以及天庭资源处分边界。

明确动作：支开人员、隐匿身份、定身、欺骗、使人睡去、偷食、偷饮、隐身逃离。

结果：资源结果被实际改变，但改变主要通过隐匿与绕开权限完成；在本截面结束时，天庭并未承认孙悟空获得这些资源的新增处分权，孙悟空本人也因预期追责而逃离。

## 2｜zx / nx 主判

### zx：rejected_as_primary

本桥段确实“成功改变了结果”，但不满足现行 zx 的关键硬门：

```text
成功取得/消耗资源
≠
自身权能公开显现并扩大决定范围
```

偷桃、偷酒、偷丹的核心方式是支开、隐身、伪装、趁无人、使执行人员失去知觉后绕开原处分边界。孙悟空没有在这一阶段公开宣布“这些资源现在由我处分”，也没有让王母、老君、玉帝或天庭资源体系当场围绕一个新增的孙悟空权限接口运行。

相反，孙悟空自己明确预期“惊动玉帝”会获罪，并选择隐身逃走。说明当前结果改变并未转化为被现实结构承认或被迫正面围绕的新增决定位置。

因此锁定：

`zx_in_secret_theft_stage: rejected_as_primary`

注意：后续天庭查明后，孙悟空公开迎战天兵，属于新的公开对抗阶段，可另行出现 zx 高显影；不得倒灌到本轮“秘密取得资源”的阶段。

### nx：rejected

本轮也不是 nx。

孙悟空没有向王母申请蟠桃、向瑶池请求御酒、向老君借金丹，也没有承认这些资源必须由既有权限节点批准后再沿通道取得。

他采取的是绕开权限而非沿权限通道借用，因此：

`nx_in_secret_theft_stage: rejected`

## 3｜关键压力

压力主要来自：

- 蟠桃园与瑶池存在明确资源边界；
- 孙悟空未被列入蟠桃会受邀者；
- 御酒、金丹不属于其正常处分范围；
- 一旦被发现存在追责风险。

这些压力只负责让“公开夺权”和“秘密绕权”之间的差异显影，不能直接判十元。

## 4｜最近邻排除

### zx vs x

孙悟空在蟠桃园确实有“代管”这一已有局部职责，园内人员会向其见礼，因此存在 `x_authorized_garden_management_neighbor`。

但“管理果园”不等于“可自行无限食用王母蟠桃”，更不能覆盖瑶池御酒与老君金丹。偷食行为明显越过了被授予的正常处分边界，所以不能把全部行为简单归成 x。

本轮最重要的反向纪律是：

```text
已有局部管理权
+ 越界秘密取用
≠ zx扩权
```

### zx vs xn

孙悟空确实使用支开、变身、定身、隐身等办法，有策略性；但这些主要说明如何秘密取得资源，不构成“持续组织运行结构”的主骨。即使冻结具体骗术，只保留“绕开权限、秘密改结果、事后逃离”，伪 zx 结论仍成立。

### zx vs xz

被发现会受罚、预期玉帝追责属于风险压力，但风险只解释为什么要逃，不说明 zx/nx 端点。

### nx vs nz

与众仙的朋友关系、齐天大圣名号等都没有被用作真正的许可通道；本轮是绕开而非借关系推进，所以不以 nx/nz 为主。

## 5｜拿掉测试

### 拿掉最终“偷成功”结果

如果只看过程：支开人员、隐身、趁无人取物，本身仍缺少公开扩权与位置上升，因此 zx 不成立。

### 拿掉后续十万天兵围剿

本轮结论反而更纯：在偷取发生时，现实结构并没有围绕孙悟空新增权限运行。后续围剿是事情暴露后的新阶段，不能作为本轮 zx 证据。

### 拿掉齐天大圣头衔

只保留“主体秘密越过资源边界并逃离追责”，仍然不能证明 zx。身份高不是判据。

### 拿掉蟠桃园已有管理职责

即使没有代管果园，秘密偷桃、偷酒、偷丹仍然只是越过既有权限边界，不会因此自动变成 zx。

## 6｜反向测试

### 反向成真 zx

如果孙悟空在资源持有人面前公开要求取得蟠桃、御酒或金丹，对方明确拒绝后，他仍以自身权能迫使其改变态度，使天庭资源分配规则当场围绕他的新增决定位置重排，那么 zx 明显上升。

### 反向成 nx

如果孙悟空通过王母、老君、玉帝、旧交或正式职位接口请求并获得许可，再沿该权限通道取得资源，则 nx 关系功能上升。

### 反向成 x

如果这些资源本来已经稳定归孙悟空自行处分，他只是正常调用，则优先检查 x，而不是 zx。

## 7｜稳定本体 / 状态 / 行为 / 关系 / 压力分层

- 稳定人物本体：不锁；继续沿用仓库已有孙悟空 `zx+nx` 锚。
- 当前状态：本轮“秘密取得资源”不锁 zx。
- 行为功能：秘密绕权、欺骗、潜入、越权取用。
- 关系位置：未取得王母、老君、玉帝资源处分接口。
- 外部压力：未受邀、资源边界、追责风险，仅作显影条件。

## 8｜严格 zx↔nx 补关系检查

本轮不锁严格补关系。

原因：秘密偷取阶段既没有独立成立的 nx 关系通道，也没有满足 zx 公开扩权硬门，不能因为人物总体是 `zx+nx` 锚就把该稳定人物结论倒灌进本桥段。

`strict_zx_nx_complement_locked: false`

```text
事实置信：99

```

本轮最小纪律：

> 成功改变具体资源结果，不足以证明 zx。若改变主要依靠隐匿、绕开、伪装和逃避追责，主体没有公开取得新增决定范围，也没有让现实秩序围绕其新增权能运行，应排除“成功 = zx”的误判。

> zx 要看的不是“我有没有把东西拿到手”，而是“我的自身权能有没有公开成为新的现实决定来源，并使我的作用位置上升”。
