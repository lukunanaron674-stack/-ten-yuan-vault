# 《三国演义》刘禅｜zx↔nx 伪纯 nx 人物本体压力测试

## 结论先行

本轮不锁“刘禅 = 纯 nx 人物本体”。相反，第115回与第118回构成直接反证：刘禅面对同一个谯周的意见，并非稳定地把最终方向让给谯周；他会拒绝，也会采纳，并在存在明确替代路线时自行作出最终选择。

```text
第115回：
谯周劝止姜维出师
→ 刘禅不从

第118回：
谯周主降
+ 刘谌主战
→ 刘禅选择谯周路线
→ 斥退刘谌
→ 下令作降书、交玺、令姜维降
```

因此：

> 经常听臣下意见、昏弱形象、最终采纳某位谋臣建议，都不能直接推出“长期不占最终方向”的纯 nx 本体。

---

## 1｜剧情事实

### 第115回｜拒绝谯周

姜维上表再度出师。谯周以天象和战争风险劝刘禅下诏阻止姜维。刘禅没有照办，而是表示先看此行结果；谯周再三劝谏仍不被采纳。

### 第118回｜采纳谯周，但同时拒绝另一条路线

邓艾逼近成都，谯周主张投降。刘禅采纳这一意见。随后北地王刘谌公开提出另一条完整方向：成都尚有兵、姜维仍在剑阁，应背城一战，即使势穷也应君臣同死社稷。刘禅明确驳回刘谌，坚持投降，并下令谯周作降书、遣使奉玺，随后又敕令姜维归降。

关键不是“谯周说了什么”，而是：刘禅面对不同意见时保留了采纳、拒绝和最终落槌的位置。

---

## 2｜nx 判断

### 纯 nx 人物本体：排除

现行 nx 准度卡要求稳定人物本体至少满足：

1. 最终方向持续由外部给出；
2. 主体不主动占据最终决定、否决和重设位置；
3. 在低成本自主窗口中仍反复等待别人决定；
4. 跨阶段复现。

本组材料直接破坏第2与第4项。

```text
同一谯周
→ 第115回意见被刘禅拒绝
→ 第118回意见被刘禅采纳
```

说明“谯周是顾问”并不等于“谯周拥有刘禅的最终方向资格”。

第118回还存在刘谌的反向完整方案，刘禅不是在“没有替代路线”的情况下机械跟随，而是在冲突路线中作出最终选择。

因此：

`pure_nx_stable_essence: rejected`

### nx 行为功能：不作为本轮主判

第118回可以记录“听取谯周方案”的行为事实，但一次采纳建议不满足纯 nx；而且现行 nx 卡明确规定“因专业信息差听从专家”不是充分条件。

## 3｜zx 判断

`zx` 在两段都不作为主判。

刘禅拥有最终批准位置，不等于其权能在本轮发生公开扩大。第115回拒谏和第118回决定投降，都没有让他的决定范围从原有皇帝权限进一步向外扩张。

因此：

`zx_in_compared_stages: rejected_as_primary`

不能把“我最后拍板”直接写成 zx；若权限本来就在主体手中，应优先检查 `x` 最近邻。

---

## 4｜最近邻排除

### nx vs x

本轮最重要的最近邻是 `x`：

> 刘禅作为蜀汉最高决策者，最终采纳/否决接口在当前文本中仍由自己实际调用。

这里不锁“刘禅稳定本体 = x”，只锁：

`x_final_choice_neighbor: evidence-locked`

用来排除“听建议 = 纯 nx”。

### nx vs xn

谯周负责提出方案；刘谌负责提出反方案。方案设计不能偷给刘禅判 `xn`。刘禅在本轮最明确的是选择与否决，而不是自己搭建战争或投降流程。

### nx vs xz

邓艾逼近成都带来极强生存压力，但压力只能解释为什么必须快速决策，不能直接推出 nx。第115回在较低紧迫度下刘禅已经展示过拒绝谯周意见的能力。

---

## 5｜拿掉测试

### 拿掉“昏庸后主”传统评价

只保留文本动作：

```text
同一顾问提出意见
→ 一次拒绝
→ 一次采纳
→ 另有反向方案时主体自己选择
```

纯 nx 仍然不能成立。

### 拿掉谯周身份

换成任何顾问，只要主体拥有真实拒绝窗口，并在不同场景中实际拒绝/采纳不同建议，就不能从“听顾问”反推稳定 nx。

### 拿掉第115回

若只看第118回，刘禅采纳谯周的事实会更像 nx 候选；但刘谌反方案和刘禅明确拒绝仍然说明最终选择权没有完全外置。第115回则进一步提供跨阶段反证。

---

## 6｜反向测试

若要锁高纯稳定 nx，应看到类似：

```text
不同场景中
→ 顾问/近臣持续给方向
→ 刘禅没有真实替代判断
→ 即使存在安全、低成本自主窗口
→ 仍默认让他人决定
→ 很少或不能实际否决
```

当前文本反而出现真实否决，因此不满足。

若要锁 zx，则需要：

```text
刘禅原本没有某项决定范围
→ 通过自身权能公开取得
→ 群臣/军政体系围绕新增接口重新排列
```

本组材料没有。

---

## 7｜第三因素冻结

以下全部不得直接参与十元主判：

- 刘禅“昏庸”“懦弱”的传统人物印象；
- 蜀汉最终灭亡；
- 谯周是否“正确”；
- 刘谌是否“忠烈”；
- 邓艾军力强弱；
- 皇帝身份本身。

本轮只看：谁拥有真实采纳/否决窗口，以及这个位置是否跨场景实际被主体使用。

## 9｜本轮贡献

本轮新增的案例级纪律：

> **“经常听别人意见”与“最终方向资格长期外置”必须分开。**
>
> **只要主体在真实替代方案之间仍拥有并实际使用采纳/否决窗口，就不能因为人物显得弱、软、依赖谋臣而直接锁纯 nx。**

它与贾迎春第73回形成反向控制：贾迎春在较低压场景中明确退出处置位、让他人处理，是干净的 nx 行为/状态正例；刘禅则在跨两场景中实际使用最终否决与选择位置，因此“弱人物外观”不能作为纯 nx 判据。
