# 《三国演义》张飞长坂桥｜zx↔nx 纯 zx 当前状态压力测试

## 0｜结论

本桥段锁定为：**纯 zx 当前状态 / 行为功能高显影正例；nx 在该窄桥段排除。**

不据此锁定“张飞稳定人物本体 = 纯 zx”。本轮只锁第四十二回长坂桥这一明确阶段。

核心原因：张飞以自己的公开威势与决定接口直接占据桥头，主动向曹军发出挑战；曹军、曹操及阵势实际围绕他的公开权能重新反应并后退。决定与影响范围在当场显著扩大。关键效果不是沿他者既有关系、权限、流程或通道取得，而是由张飞自身公开作用产生。

## 1｜剧情事实：触发—对象—动作—结果

### 触发

赵云突围后从长坂桥通过，曹军追兵逼近；张飞留在桥头承担阻截。

### 对象

- 直接对象：追至长坂桥的曹军及曹操。
- 保护对象：刘备集团撤离方向。

### 明确动作

1. 张飞挺矛立马桥上，正面占据公开接触面。
2. 曹军诸将到桥前后因张飞与疑似伏兵而停住阵脚。
3. 曹操亲至后，张飞连续公开喝问、邀战。
4. 张飞观察到曹军阵脚移动后继续施压，而不是等待他者给出行动方向。

### 结果

- 夏侯杰受惊坠马。
- 曹操回马而走。
- 曹军众将随之西退、阵势溃动。
- 曹操撤退后仍处于对张飞威势的反应状态，随后才派张辽、许褚回探桥上情况。

原文核验：维基文库《三国演义》第四十二回，尤其桥头段落（约页面行 123-137）。

## 2｜样本槽判断

### 纯 zx

**成立，高置信。**

现行 zx 准度卡要求：主体自身力量 / 决定接口明确；公开进入现实；他者或秩序实际被迫回应；主体决定范围或凌驾位置上升；不能只凭普通战斗成立。

本桥段中，张飞不是单纯“很能打”。决定性证据是：

```text
自身公开威势与挑战
→ 曹军停止推进并围绕其反应
→ 曹操产生退意并实际退走
→ 整体阵势随之移动、溃退
```

因此 zx 的对象不是“武力标签”，而是**自身权能公开压入现实并改写对方当场行为方向**。

### 纯 nx

**排除。**

长坂桥这一窄桥段没有出现：

- 方向由他者给定后张飞只沿着执行；
- 关键权限掌握在他者手里，张飞必须求人借力；
- 沿既有关系网络或流程通道续接结果。

即使阻截的大目标服务于刘备集团撤离，也不能把“团队目标存在”直接判 nx。此处张飞如何形成桥头对抗、如何公开施压、何时继续喝问，均未表现为沿外部权限接口办事。

### zx+nx

**本桥段不成立。**

没有足够证据证明张飞需要一个独立外部权限 / 关系通道来补足其桥头权能。

### 压力显影

**可记录为外部高压下 zx 状态显影，但不锁为“被克后另一端显影”的严格链。**

曹军追击和兵力悬殊构成外部压力，但本轮只证明压力环境中 zx 高显影；不把压力本身擅自写成某一十元的已锁生克机制。

### 伪对子候选

**“刘备集团给了撤退任务，所以张飞是 nx”属于伪 nx 读法。**

上位共同目标不等于当前运行通道由他者给定。必须继续检查主体在具体作用层是否仍自己占据公开决定接口。

## 3｜zx 端点核验

按照 L1 木轴，核心变量是：最终方向与作用权来源。

本桥段中：

- 当场桥头如何作用：来源在张飞自身；
- 威势是否公开：是；
- 对象是否被迫正面回应：是；
- 决定 / 影响范围是否扩大：从一人守桥扩大到迫使曹军整体暂停、后退；
- 是否必须借他者权限才能使结果发生：否。

因此本桥段高匹配 zx。

## 4｜nx 端点核验

nx 要求主体不占最终方向决定权，并沿别人、关系、流程、秩序或现状已经给出的方向与通道推进。

张飞此处不满足核心端点：

- 没有等待曹军或刘备决定他的桥头具体动作；
- 没有通过请求、身份、旧交、职位接口借到决定性外部权能；
- 没有把桥头当场的否决与施压位置让给他者。

因此 nx 在本桥段排除。

## 5｜拿掉测试

### 拿掉“张飞很勇猛 / 很能打”的标签

只保留事实：主体公开站到接触面、主动发出挑战，对方阵势和最高指挥者实际后退。

→ zx 仍成立。

### 拿掉最终“曹军败退”的胜负标签

只保留曹军诸将停住阵脚、曹操产生退意、阵形因张飞公开施压发生移动。

→ 仍满足“他者围绕主体公开权能重新反应”，zx 不依赖最终胜负词。

### 拿掉关羽昔日对张飞的评价

曹操恐惧程度可能下降，但只要保留桥头公开对峙中曹军实际停阵、退意和阵脚变化，zx 端点仍可成立；该评价是效果放大因素，不是 zx 本体判据。

### 拿掉树林扬尘疑兵

疑兵会影响曹军风险判断，但第三喝后曹操与军阵对张飞本人公开威势的反应仍是独立证据。故疑兵属于辅助因素，不足以替代主体 zx。

## 6｜反向测试

若改写为：

```text
刘备 / 诸葛亮规定张飞必须站哪、何时喝、何时退；
张飞没有否决与重设位置，只逐项照办；
真正让曹军停止的是既有命令、制度或外部权限，而非张飞公开权能。
```

则 zx 会下降，并应重新检查 nx / xn。

若张飞只是接受“守桥”这个上位任务，但自己主动决定现场作用方式并公开迫使对方重排，仍不能仅凭“接受任务”判 nx。

## 7｜最近邻排除

### zx vs nx

- zx：本段决定性作用直接来自张飞自身公开权能。
- nx：未见沿他者权限 / 关系通道借力。

→ zx 优先，nx 排除。

### zx vs xn

张飞此前使用马尾树枝制造扬尘，存在策略 / 组织成分，但决定性桥头显影并非排程、节点、流程持续组织；核心是公开当场施压。

→ xn 可解释局部辅助手段，不解释主变量。

### zx vs x

张飞没有“拥有曹军、桥梁或某套权限网络”的处分结构；重点不是已有资源归属，而是权能公开显现后使对方重新反应。

→ 不优先 x。

### zx vs xz

曹军追兵逼近属于高危险压力，可能构成 xz 场景 / 状态变量，但危险只解释为什么此刻必须阻截，不解释“为何曹军围绕张飞本人威势重新反应”。

→ 冻结危险后，zx 机制仍可单独成立。

### zx vs z

曹操并非在“认可张飞价值”后使其成立；曹军的恐惧与后退是被迫响应，不是重要认可主体给予确认。

→ 不优先 z。

## 8｜第三因素冻结

冻结以下因素后重新判：

- 张飞职业 / 武将身份；
- “万人敌”名声；
- 刘备集团的总体撤退目标；
- 曹军人数优势；
- 关羽旧评价；
- 树林扬尘疑兵；
- 夏侯杰坠马这一夸张结果；
- 后续拆桥成败。

只保留：

```text
主体公开占据作用界面
→ 以自身权能直接施压
→ 对方最高指挥与阵势实际围绕其力量改变行为
```

zx 仍成立。

## 9｜对象分层

- 稳定人物本体：**不锁。** 单一桥段不足以推出张飞长期纯 zx。
- 当前状态：**zx 高显影，锁。**
- 行为功能：**zx，锁。**
- 关系位置：**张飞在桥头成为对方必须正面回应的公开决定力量，锁。**
- 外部压力：曹军追击、兵力悬殊；只作为触发 / 放大，不直接判十元。
