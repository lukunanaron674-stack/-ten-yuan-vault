# 《西游记》真假美猴王｜zx↔nx 外部裁决持续压力测试

## 结论先行

本轮锁定 **`nx` 关系功能持续正例**：孙悟空自己的目标始终明确——辨明真假、恢复真实身份与取经位置；但“谁有资格/能力判明真假”这一关键识别与裁决接口持续位于外部。观音不能辨、天庭照妖镜不能辨、唐僧紧箍咒不能辨、地府簿册不能辨后，孙悟空没有自行宣布“由我裁定”，而是继续升级寻找更高外部接口，最终到如来处完成辨识。

这与武松“县衙裁决失败后自行接管事实确认、裁决与执行接口”的 `nx→zx` 切换形成反向最小差异。

## 1｜剧情事实、触发、对象、动作与结果

触发：真假两个孙悟空外貌、声音、兵器、神通高度一致，单凭战斗无法辨认。

明确动作链：

```text
南海观音辨认失败
→ 去天庭请众神/玉帝辨认
→ 照妖镜仍无法判别
→ 回唐僧处用紧箍咒试验，仍无法判别
→ 去地府查生死簿，仍无结果
→ 谛听虽能知真假，但因风险不敢当面说破
→ 地藏建议去雷音寺如来处
→ 两者继续前往如来求辨
→ 如来识出六耳猕猴并以金钵擒住
```

结果：关键“真假识别”并不是由孙悟空自己取得最终裁决权完成，而是由更高外部识别/权威接口完成。

## 2｜nx 证据

本段不是纯 nx 本体，因为孙悟空并未失去自己的方向。他从头到尾都明确要求辨明真假，并主动选择继续推进。

`nx` 成立在关系功能与权限位置：

```text
方向：孙悟空自有
关键识别/裁决能力：在外部主体
前一接口失败：不自行夺取裁决权
处理方式：继续寻找更高既有权限/识别通道
```

因此可锁：`nx_relation_function_stage: evidence-locked`。

## 3｜为什么不锁 zx 裁决接管

孙悟空一路都在战斗，也多次强闯天门、地府、雷音，但“动作猛烈”不能替代 zx 的扩权条件。

在核心问题“谁是真、谁是假”上，他始终请求外部主体辨识：观音、玉帝/照妖镜、唐僧、地府/谛听、如来。即使前一节点失败，他也没有把自己变成最终裁决中心。

所以：

```text
强行进入一个外部接口
≠ 自己取得该接口的最终裁决权
```

如来道破六耳猕猴并将其罩住后，孙悟空才执行击杀；但这属于外部裁决已经完成后的行动，不反向证明前面的辨真阶段是 zx 裁决扩权。

## 4｜最近邻排除

### nx vs xn

孙悟空确实主动选择“下一站去哪里”，有路径搜索和阶段推进，但他没有建立一套自己拥有的真假识别规则、流程与节点。核心缺口仍是外部识别/裁决能力，因此 `xn` 不吞掉 `nx`。

### nx vs zx

`zx` 要求主体自身权能成为新的现实决定来源并扩大决定范围。本段孙悟空虽强，但真假问题的最终识别资格没有转移到他自己手里，因此不锁 zx 裁决接管。

### nx vs x

观音慧眼、天庭照妖镜、地府簿册、谛听识别、如来遍识周天种类，都不是孙悟空可以长期独立调用和处分的自有权限；因此不是 x。

## 5｜拿掉测试

拿掉孙悟空的武力与齐天大圣身份，只保留“主体有辨真方向，但关键识别能力在外部；一个接口失败后继续找下一接口”，`nx` 关系功能仍成立。

拿掉某一个中间接口（例如玉帝或唐僧），只要仍存在“外部接口失败→升级寻找另一外部接口”，结构不变。

拿掉最终如来成功辨识，则会变成一个未完成但仍持续的 nx 外部裁决搜索过程，不会因此自动转成 zx。

## 6｜反向测试

### 反向A：武松式 zx 接管

```text
观音/天庭辨不出
→ 孙悟空停止寻找外部裁决者
→ 自己建立真假判定标准
→ 强迫其他主体接受其判定
→ 自己成为最终裁决中心
```

则 zx 明显上升，nx 持续下降。

### 反向B：普通 xn

若外部只给一个“辨真假”的目标，而真假识别流程、证据标准、阶段节点全部由孙悟空自己设计并运行，则 xn 上升。

## 7｜第三因素冻结

冻结：六耳猕猴的神通、孙悟空武力、紧箍咒戏剧性、照妖镜道具、佛教主题、最终击杀、取经正统身份、如来地位。

只保留：

```text
谁拥有最终识别/裁决接口？
前一接口失败后，主体是自己接管，还是继续寻找外部接口？
```

结论仍是：本阶段 `nx` 关系功能持续，zx 裁决接管不成立。

## 8｜与武松案例的最小差异

```text
武松：县衙拒绝裁决
→ 自行接管事实确认/取供/裁决/执行
→ zx 上升

孙悟空：观音/天庭/唐僧/地府连续无法裁决
→ 继续升级到更高外部识别/权威接口
→ nx 关系功能持续
```

因此本轮新增的案例级纪律是：

> 外部权限/裁决接口失败，并不会自动触发 zx。真正要看主体接下来是“夺回并扩大决定接口”，还是“继续沿既有外部权限网络寻找更高节点”。
