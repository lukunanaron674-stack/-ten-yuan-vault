# 《三国演义》诸葛亮北伐点将：zx-nx 既有指挥调用伪nx压力测试

## 1｜窄桥段

只取第九十一回诸葛亮上《出师表》获准北伐之后，回府点将、分拨军职，并处理赵云请为先锋这一段。不得把诸葛亮长期人物本体、后续街亭失败、斩马谡或北伐成败倒灌到本轮。

本轮专门反测一个近期边界：

> **“我让另一个强角色行动”不自动等于 nx。若该角色已经处于主体真实、稳定、可直接调用的组织指挥边界内，应优先检查 x / xn；只有仍需进入一个外部独立节点、让对方本人重新批准其能力是否出手时，才支持 nx 外部能力接口。**

## 2｜剧情事实、触发、对象、动作与结果

### 触发

诸葛亮完成南征、司马懿被削职后，上《出师表》请求北伐。后主虽先担忧其劳顿，但最终允许出师。

### 对象

本轮只看：**北伐军中已经纳入诸葛亮军令系统的将领、兵力与岗位，是否属于诸葛亮需要逐个求人才能接入的“外部独立能力节点”，还是已在其既有指挥调用边界内。**

### 明确动作

1. 诸葛亮受诏归府后，直接“唤诸将听令”。
2. 他按前督部、前军都督、牙门将、后军、左右军、运粮、监军、护卫等位置分拨大量文武。
3. 分拨完成后，又安排李严等守川口，形成北伐前后的职责结构。
4. 赵云因未被列为先锋而主动请战，诸葛亮起初以其年高为由再三劝阻。
5. 赵云坚持请为先锋后，诸葛亮接受其请求，但不是让赵云自行决定整个先锋结构，而是明确要求须有一人同去；邓芝应声后，诸葛亮再拨精兵五千、副将十员，命赵云、邓芝同为前部先锋。
6. 随后北伐军按这套组织结构出师。

### 结果

诸葛亮并非通过私人请求、旧交、人情或激将，逐个取得魏延、王平、马岱、邓芝、关兴、张苞等人的“是否愿意把能力借给我”的许可。文本把他们直接置入“诸将听令—分拨—出师”的军令结构。

赵云的主动请战反而提供了一个很有价值的控制变量：**将领可以保留自己的意见和主动性，但一旦进入既有军令边界，其具体岗位与兵力配置仍由统帅处分。** 这不能倒推成“每个被调用的人都是外部 nx 节点”。

## 3｜候选分型

- 纯 zx：排除。
- 纯 nx：排除。
- zx+nx 严格补关系：不锁。
- nx 外部能力接口：在本轮既有军令调用层排除。
- x 最近邻：成立，指向“既有军令调用边界已经归主体掌握”。
- xn 最近邻：高显影，解释点将、岗位配置、兵力分配与出师组织。
- 伪 nx：成立，专门反驳“用了别人的能力 = nx”。
- 伪 zx：成立，专门反驳“能直接命令很多人 = zx”。

## 4｜nx 检查

### 4.1 为什么表面像 nx

诸葛亮当然是在“使用别人”的能力：魏延、王平、赵云、邓芝等都是独立人物，并非诸葛亮本人能力的延伸。

若只用字面规则：

```text
别人出手
→ 我借别人能力
→ nx
```

会得到错误结论。

### 4.2 为什么本轮 nx 外部能力接口排除

现行 nx 的关系功能要求：**关键能力、权限或解决通道仍掌握在外部主体手里，主体必须承认并沿那个独立位置去请求、借用或说服。**

本桥段却是：

```text
北伐军职与兵力已经进入诸葛亮的统帅组织接口
↓
诸葛亮唤诸将听令
↓
直接分岗位、兵力与职责
↓
将领按军令进入行动结构
```

对比猪八戒义激猴王：猪八戒没有孙悟空的命令权，孙悟空去不去必须由孙悟空本人重新决定；猪八戒必须通过师兄弟关系和激将接入这个独立能力节点，因此 nx 成立。

诸葛亮本轮则无需对每名将领重新求人、谈条件或取得私人许可。他调用的是**已经在军令边界内的组织能力**。

因此：

- `nx_external_agent_relation_function: rejected_in_narrow_command_layer`
- 不得从“用了别人”直接推出 nx。

## 5｜x 最近邻

本轮最重要的最近邻是 `x`。

现行 nx 准度卡区分：

```text
nx：权限和资源在别人手里，我沿通道借用。
x：对象、资源、权限和调用边界归我掌握。
```

这里不能把“将领本人”写成诸葛亮私人所有物；判断对象是**组织关系中的军令调用边界**。

在这条窄对象层上：

- 谁担任哪个军职；
- 哪支兵力拨给谁；
- 谁与谁共同担任先锋；
- 哪些将领随军、哪些留守；

均由诸葛亮在既有统帅权限内处分。

所以正式锁：

`x_existing_command_boundary_neighbor: evidence-locked`

这不是人物稳定本体 `x`，只是当前组织权限层的最近邻正例。

## 6｜xn 最近邻

点将、编组、分前后左右军、配置运粮与护卫，本身明显是 `xn` 的组织运行显影。

因此：

```text
x：解释“这些军令调用边界是否已经归诸葛亮掌握”。
xn：解释“诸葛亮如何把人、岗位、兵力组织成北伐结构”。
nx：若必须逐个进入外部独立节点求人借力，才解释“为什么能力仍在外部”。
```

本桥段主结构更接近 `x + xn`，而不是 nx。

## 7｜zx 检查

诸葛亮能号令大量将领，看起来十分强势，但不能因此锁 zx。

现行 zx 准度卡要求：

1. 自身决定接口明确；
2. 权能公开进入现实；
3. 他者或秩序实际响应；
4. **主体决定范围、影响位置或凌驾程度上升**；
5. 不是普通执行、战斗或职业行为。

本轮的军令权已经由既有丞相/统帅结构和本次受诏出师提供。只看“受诏后在既有范围内点将”，不足以证明诸葛亮又取得了一个此前不存在的更高决定范围。

因此：

`zx_in_narrow_stage: rejected_as_primary`

若要锁 zx，需要另找“原本没有这块调用范围 → 公开取得 → 组织开始围绕新增接口重排”的权限扩张过程，不能把统帅正常点将重复制造成扩权。

## 8｜关键压力

关键压力不是魏军强弱，而是**把‘使用独立人物的能力’与‘调用已经纳入自己组织处分边界的人力’切开**。

同样是“让另一个强角色出手”：

### 猪八戒 → 孙悟空

```text
孙悟空是否出手仍由孙悟空本人决定
↓
八戒必须请求 / 激将
↓
外部能力接口
= nx关系功能
```

### 诸葛亮 → 北伐诸将

```text
诸将已进入军令系统
↓
诸葛亮直接点将、分职、拨兵
↓
无需逐个重新取得私人出手许可
= x既有调用边界 + xn组织
```

## 9｜拿掉测试

### 拿掉诸葛亮“丞相、武乡侯”等头衔

只保留：文本中存在真实“诸将听令—主体分拨岗位与兵力—军队按结构出师”的调用关系。

`nx` 外部能力接口仍不成立，`x/xn` 最近邻仍在。因此不是拿官名直判。

### 拿掉赵云的主动请战

即便删去赵云这一段，诸葛亮对大量将领的直接军令配置仍然成立。

赵云只是额外证明：下属可以有自己的判断和请求，但这不等于其组织能力因此重新变成外部 nx 节点。

### 拿掉具体某一员将

换成任何同样已经纳入北伐军令系统的将领，只要调用边界不变，结论不变。

### 拿掉既有军令调用权

若诸葛亮没有正式指挥这些将领的权限，每次都必须通过私交、请求、许诺或另一个真正掌权者批准才能让他们行动，则 `x` 下降，`nx` 外部能力接口上升。

## 10｜反向测试

### 反向成猪八戒式 nx

赵云已经脱离蜀军指挥关系，是一个完全独立行动者；诸葛亮想让他参战，必须重新请求，而赵云可以低成本拒绝且诸葛亮没有组织处分手段。

此时赵云本人会成为真正外部能力节点，nx 上升。

### 反向成 zx

诸葛亮原本无权调动某支独立军队，却通过本事件公开取得这支军队的新增处分权，且整个组织从此围绕该新增接口运行。此时才进一步检查 zx 扩权。

### 反向成更纯 xn

若本轮只讨论“如何分前后左右军、如何配置运粮、如何安排先锋与留守”，而完全不讨论权限边界，则主轴会进一步转向 xn。

冻结以下因素后，结论仍成立：

本轮只按《三国演义》第九十一回文本的当前组织关系判断：

> **调用边界已经处在主体的军令处分范围，主体直接组织部署，不需要重新进入一个外部独立行动者的关系接口。**

## 12｜稳定本体 / 当前状态 / 行为功能 / 关系位置

- 稳定人物本体：不锁。
- 当前状态：受诏北伐后的统帅组织阶段。
- 行为功能：点将、分拨、配置兵力。
- 关系位置：对北伐军内既有军令调用边界处于处分位。
- 外部压力：战争任务使组织权限高显影，但战争本身不是十元判据。

不得由本轮推出“诸葛亮整体 = x / xn”，也不得由“他能命很多人”推出稳定 zx。

## 13｜与近期案例的最小差异

### 《西游记》猪八戒义激猴王

关键能力属于孙悟空这一外部独立主体；孙悟空保留是否出手的现实决定权，八戒必须通过关系与说服激活。锁 `nx` 外部能力接口。

### 《三国演义》诸葛亮北伐点将

将领在当前阶段已经进入诸葛亮的军令组织调用边界；诸葛亮直接分配岗位、兵力和任务。锁 `x` 既有调用边界邻近与 `xn` 组织，排除该层 `nx`。

因此新增案例级纪律：

> **“使用他人的能力”不是 nx 判据。先问这个人的行动能力在当前关系中是否仍是需要本人/外部节点重新批准的独立接口，还是已经进入主体真实可调用的组织权限边界。**

当前仅形成《西游记》与《三国演义》两部作品的最小差异，不建立新待审议问题。
