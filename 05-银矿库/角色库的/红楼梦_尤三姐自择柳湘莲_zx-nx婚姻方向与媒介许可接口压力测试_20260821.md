# 《红楼梦》尤三姐自择柳湘莲｜zx-nx 婚姻方向与媒介许可接口压力测试

## 1｜事实窗口

《红楼梦》第66回，尤二姐向贾琏说明尤三姐已经自己择定柳湘莲；尤三姐随后亲自确认：若柳湘莲回来，她便嫁他；若长期不来，她宁可等待甚至终身不嫁，并以折簪表达自己的决定不会改变。

因此，“嫁给谁”这一当前婚姻方向不是贾琏、贾珍、尤老娘替她决定，而是尤三姐本人锁定。

但婚约要从个人选择进入现实，尤三姐并不能单方面让柳湘莲成为自己的未婚夫。贾琏外出途中遇见柳湘莲，向其提出婚事；柳湘莲本人表示同意，并交出家传鸳鸯剑作为定礼。贾琏再把定礼带回，尤三姐收下后，婚约才进入双方已经确认的现实状态。

## 2｜最小结构

```text
zx：
尤三姐自己决定“只嫁柳湘莲”
→ 家人只能依她的选择寻找柳湘莲
→ 她的个人方向进入家庭现实安排

nx：
柳湘莲本人同意权不在尤三姐手里
+ 实际说合与定礼传递通过贾琏既有关系通道完成
→ 尤三姐沿外部媒介 / 对方同意接口把自己的方向推进成婚约
```

## 3｜zx 判断

正式锁定：

`zx_marriage_direction_state: evidence-locked`

不是因为尤三姐“痴情”“刚烈”，而是：

1. 婚姻对象由她自己选定；
2. 她公开把该方向说死，并拒绝让家人改写；
3. 贾琏、尤二姐等人的后续行动实际围绕她指定的对象展开；
4. 她的婚姻决定位置从“可被家人安排”推进为“家庭必须围绕她自己的选择办事”。

因此这里延续第65回已经锁定的 zx 当前状态，但对象层从“拒绝被贾珍贾琏安排”推进到“正面指定自己要嫁的人”。

本轮仍不锁：

`尤三姐稳定人物本体 = 纯 zx`

## 4｜nx 判断

正式锁定：

`nx_matchmaking_and_reciprocal_consent_relation: evidence-locked`

这里的 nx 不是“尤三姐没主见”。最高婚姻对象方向仍由她自己占据。

nx 只成立在现实实现层：

- 柳湘莲是否接受婚约，不由尤三姐单方面处分；
- 贾琏承担了实际说合、传递承诺与定礼的关系通道；
- 尤三姐没有夺取柳湘莲的同意权，而是沿对方真实同意与媒介关系把自己的选择推进为婚约。

因此这是典型的“强主体有自己的方向，但关键关系 / 同意接口在外部”的 nx 关系功能。

## 5｜严格 zx↔nx 补关系测试

本轮不锁严格补：

`strict_zx_nx_complement_locked: false`

### 5.1 拿掉 nx

拿掉贾琏媒介与柳湘莲同意接口：

- 尤三姐“只嫁柳湘莲”的 zx 方向仍然成立；
- 但个人选择无法单方面变成双方婚约。

因此：

`nx_repairs_zx_gap: supported`

nx 确实补了 zx 在“把个人婚姻方向变成双边现实关系”上的外部同意 / 媒介缺口。

### 5.2 拿掉 zx

不能把尤三姐最低限度的婚姻意愿也全部删掉，否则等于删除研究对象。应只拿掉 zx 的“公开、自主锁定对象并使家庭围绕其选择行动”这一高显影端点。

保留最低限度的“愿意接受柳湘莲婚约”，贾琏说合 + 柳湘莲同意 + 交定礼这套 nx / 双边接口仍足以使婚约形成。

因此没有出现：

> 外部关系与同意通道已经存在，但没有尤三姐 zx 就无法让它落地。

正式记录：

`zx_repairs_nx_gap: rejected`

所以本例是 zx 与 nx 同时成立，但只有 nx → 补 zx 缺口清楚，反方向不成立；属于普通“自主方向 + 必要社会 / 双边同意接口”，不是严格双向补。

## 6｜最近邻排除

### 6.1 zx vs x

尤三姐拥有自己婚姻意愿的个人边界，但本段重点不是静态“这件事归我”，而是她的自定方向真实进入家庭安排，并迫使贾琏等人围绕其指定对象行动，因此 zx 当前状态高于纯静态 x。

### 6.2 nx vs xn

贾琏怎样在路上遇到柳湘莲、怎样提出婚事属于过程细节；尤三姐本人没有主动搭建复杂媒介流程、排程或多节点组织，所以 xn 不主判。

### 6.3 nx vs nz

情感、专一与关系价值可以解释她为什么锁定柳湘莲，但不能替代“柳湘莲的同意权与说合通道不在她手里”这一权限事实。

### 6.4 nx vs x

柳湘莲的同意权和贾琏媒介关系从未稳定归尤三姐调用，因此实现层不是 x。

## 7｜关键压力

关键压力不是抽象“封建婚姻”，而是两个具体瓶颈：

1. 家庭此前试图替她安排婚姻对象；
2. 即使她自己选定柳湘莲，双边婚约仍必须经过对方同意与现实媒介接口。

前者使 zx 高显影，后者使 nx 关系功能显影。

## 8｜拿掉测试

### 拿掉家人此前的安排压力

只保留“尤三姐明确自择柳湘莲并让家庭照其选择寻找”，zx 仍可成立，只是受压复位色彩降低。

### 拿掉贾琏这个特定媒介

如果存在另一位等价媒介，且仍必须取得柳湘莲本人同意，nx 关系功能仍成立。说明核心不是“必须是贾琏”，而是外部双边同意 / 关系通道。

### 拿掉柳湘莲真实同意

即使贾琏再会说合，只要柳湘莲不同意，婚约就不能成立。说明真正的外部接口具真实否决性。

## 9｜反向测试

### 反向成纯 nx

```text
家人替尤三姐选择对象
→ 尤三姐不占婚姻对象决定位置
→ 按家人说合结果接受
= nx 上升，zx 下降
```

### 反向成更纯 zx

```text
尤三姐不仅自己选定对象
→ 还能单方面让婚约生效
→ 不需要对方同意或任何外部关系接口
```

文本不存在这种结构；双边婚约天然保留对方真实决定位置。

### 反向成严格 zx↔nx 补

必须进一步证明：

```text
nx 获得关系 / 同意接口后
→ 若没有尤三姐 zx 的公开落地权能，接口自身不能形成婚约结果
```

本段证据不足，故不锁严格补。

## 10｜第三因素冻结

冻结：

- 尤三姐后来因柳湘莲退婚自刎；
- 柳湘莲后来出家；
- 尤三姐是否痴情、刚烈；
- 贾府道德评价；
- 婚姻制度主题；
- 柳湘莲是否“配得上”。

只问：

1. 当前婚姻对象方向是谁定？
2. 家庭是否真实围绕她的选择行动？
3. 对方同意与媒介接口是否在外部？
4. 尤三姐是否实际沿这些外部接口把方向推进成婚约？
5. 双向拿掉是否都留下对方不可替代的缺口？

前四问为高置信“是”，第五问为“否”。

## 11｜结论

本阶段锁为：

> **尤三姐自择柳湘莲 = zx 当前婚姻方向 + nx 媒介 / 双边同意关系功能并存，但不是严格 zx↔nx 双向补关系。**

最短机制：

```text
我自己决定要嫁谁
= zx

但婚约不能由我单方面成立
→ 需要对方真实同意 + 外部媒介通道
= nx

nx 能补 zx 的现实实现缺口
但 nx 通道不需要 zx 才能完成其自身许可 / 媒介功能
→ 非严格双向补
```
