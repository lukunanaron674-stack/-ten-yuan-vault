# 《三国演义》刘备自领益州牧｜zx↔nx 真扩权压力测试

## 结论先行

本轮锁定：

> **第六十五回刘备入成都、自领益州牧并随即处分刘璋去向、擢用降臣、重定旧部官职、开仓赈民，是高纯度 `zx` 当前状态／行为功能／关系位置正例。**

本轮不锁“刘备稳定人物本体 = 纯 zx”。

此桥段专门与“已有职位或关系权限被执行”区分：刘备不是只在旧授权边界内下令，而是从此前的外来盟军、入蜀作战者位置，实际进入成都最高决定位置，并把新增决定权公开压入益州的人员、官职、资源与秩序中。主体决定范围发生了可观察的扩大。

---

## 1｜剧情事实

### 触发

刘璋决定投降，交出印绶文籍，与刘备同车入城。成都既有最高权力中心发生交接。

### 对象

- 刘璋及其家属去向；
- 益州原有文武官员；
- 刘备旧部；
- 成都军民与府库资源；
- 益州最高行政／军政位置。

### 刘备的明确动作

1. 入成都公厅升堂，郡内诸官拜于堂下；
2. 在诸葛亮建议后，最终决定将刘璋迁往南郡公安；
3. 自领益州牧；
4. 对投降文武重新定拟名爵、擢用六十余人；
5. 对诸葛亮、关羽、张飞、赵云、黄忠、魏延、马超及旧部重新升赏定职；
6. 调用府库资源赏赐将士；
7. 开仓赈济百姓。

### 结果

- 刘备从入蜀军事行动的主体变成益州最高公开决定主体；
- 原益州官员开始围绕刘备的新处分位置重新排列；
- 刘璋的去向、官员名爵、旧部官职、府库资源和赈济均进入刘备可公开处分范围；
- 其影响范围由军队与盟友关系扩展到一州行政、人事与资源秩序。

## 2｜zx 证据

现行 `zx` 要求：

```text
主体自己的力量或决定接口明确
→ 权能公开进入现实
→ 他者／环境／秩序被迫回应
→ 主体决定范围或凌驾位置上升
→ 不是普通职位执行
```

本段逐项满足：

### 2.1 自身决定接口明确

“自领益州牧”不是抽象身份描写，后续立刻跟随真实处分：迁刘璋、定官职、擢用降臣、赏赐旧部、调用府库、赈济军民。

### 2.2 权能公开进入现实

刘备升堂，益州诸官拜于堂下；其新位置不只存在于名义，而被原有官僚与军民公开承认并进入运行。

### 2.3 他者与秩序重新反应

原刘璋体系中的文武被重新任用和定位；刘备旧部也被重新配置到新的益州权力结构中。

### 2.4 决定范围真实扩大

此前刘备没有对整个益州官僚、府库和百姓的常态处分权；入成都后这些对象进入其现实决定范围。这是本轮最关键的 `zx` 证据。

因此本段不是“有权”，而是：

```text
原决定范围较窄
→ 权力中心完成交接
→ 刘备成为新的最高公开决定主体
→ 决定范围扩到一州人员、官职、资源和秩序
= zx 高显影
```

## 3｜nx 证据与排除

本段不能因为刘备此前借诸葛亮、法正、马超等人之力，或因为刘璋交出印绶，就把当前阶段判成 `nx`。

现行 `nx` 要求关键方向、权限或解决通道仍由他者掌握，主体不占最终重设位置，并沿已有通道续接。

但本桥段的核心事实恰好相反：

- 刘备已经进入最终处分位置；
- 刘璋不再是益州最高决定主体；
- 官职、人事、府库与行政安排由刘备一方重新决定；
- 没有出现“必须向另一个仍掌握益州最高权限的人申请后才能执行”的结构。

因此：

> **“权力交接来自别人让出” ≠ 当前阶段仍是 nx。**

关键要检查交接完成后，最终决定接口到底归谁。

本段 `nx` 在这一窄变量上排除。

## 4｜关键压力

本轮外部压力包括：

- 成都刚刚完成投降，旧秩序需要重新安置；
- 刘璋仍在场，存在“一地二主”的结构风险；
- 大量降臣与旧部需要重新配置；
- 军民需要资源与秩序稳定。

这些压力提供了显影窗口，但不能单独判 `zx`。真正支持 `zx` 的是刘备在压力下取得并公开扩大了实际决定范围。

## 5｜拿掉测试

### 5.1 拿掉“益州牧”头衔

只保留：

```text
刘备决定刘璋去向
+ 重定一州官员职位
+ 配置旧部
+ 调用府库赏赐
+ 开仓赈民
```

仍能观察到决定范围从局部军政主体扩大到一州秩序，因此 `zx` 不依赖头衔关键词。

### 5.2 拿掉战争胜利

即使不强调“攻取西川成功”，只看权力交接后的处分行为，仍可判断决定范围扩大。胜负不是判据。

### 5.3 拿掉诸葛亮建议

刘备对“是否立即迁走刘璋”一度有不同判断，最后接受诸葛亮意见。但这只说明信息／建议输入，不等于诸葛亮掌握益州最终权限。拿掉这一段建议，刘备对人事、资源与行政的新增处分范围仍成立。

## 6｜反向测试

### 反向成 x 而非 zx

如果刘备早已长期拥有益州全部处分权，本段只是在常规批官、发赏、赈济，没有任何决定范围新增，则应优先判 `x` 的既有掌握，而不是 `zx`。

### 反向成 nx

如果刘璋仍保留最高否决权，刘备只能提出人事与资源方案，必须等待刘璋批准后照批示执行，则 `nx` 会明显上升。

### 反向成 xn

如果关键变化只是刘备接手一个既定目标后设计官僚流程、排程和节点，而最终权限层级没有上升，则应优先检查 `xn`。

## 7｜最近邻排除

### zx vs x

```text
x：权限已经归我，当前只是使用。
zx：决定范围和凌驾位置正在公开扩大。
```

刘备此段不是静态持有益州，而是刚完成权力中心迁移，并立即把新增权能压入全州秩序，因此优先 `zx`。

### zx vs xn

任官和治理包含组织成分，但核心不是“如何排流程”，而是“谁取得了原先没有的一州最终处分范围”。所以 `xn` 只能是次级污染变量。

### zx vs nx

刘备此前入蜀过程中可能多次借力，但当前桥段最高权限已经落到刘备自身位置，故不能把前阶段的 `nx` 关系功能带进本段。

### zx vs z

郡内诸官拜于堂下可形成被承认的表象，但即使拿掉礼仪与认可，后续真实处分行为仍成立，故不是以 `z` 为主。

### zx vs xz

新政权稳定压力存在，但危险本身不能解释为何刘备获得并扩大决定范围；`xz` 不是本段主变量。

## 9｜与既有边界的最小差异

### 唐僧逐悟空：已有权限执行

```text
原本已经拥有师徒处分接口
→ 公开执行逐出
→ 决定范围没有新增
→ 不能仅凭下令成功判 zx
```

### 刘备自领益州牧：真实新增决定范围

```text
此前不掌握益州整体处分权
→ 权力中心交接
→ 自领益州牧
→ 重新处分官员、旧主、府库和军民
→ 决定范围显著扩大
→ zx 高显影
```

由此锁定案例级纪律：

> **“公开用权”与“公开扩权”必须分开。`zx` 的硬证据不是命令被执行，而是主体决定范围、影响位置或凌驾程度真实上升，并迫使更大现实秩序围绕其权能重新反应。**

本纪律已直接符合现行 zx v2.3 与 zx 准度卡 v0.1，因此本轮不修改 L1 或信息卡。
