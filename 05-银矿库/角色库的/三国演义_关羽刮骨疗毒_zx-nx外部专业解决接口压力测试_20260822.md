# 三国演义｜关羽刮骨疗毒｜zx-nx 外部专业解决接口压力测试

## 0｜结论先行

本段锁为：**关羽在“毒已入骨、右臂不能运动→华佗诊断并刮骨去毒→右臂恢复”这一治疗对象层，存在高纯 `nx` 专业解决接口关系功能。**

关键不在“华佗告诉关羽一个医学事实”，而在：华佗掌握关羽当下不能自行完成的诊断、手术、去毒、敷药与缝合能力，并且该外部接口直接修复同一个当前现实瓶颈。

因此本例可作为“外部信息输入 ≠ nx解决通道”待审议的反向高纯控制：

```text
只给事实 / 情报
≠ 自动 nx

外部主体掌握不可替代的专业处理能力
+ 主体实际接受并沿该专业接口处理
+ 同一个现实问题被直接修复
→ nx 关系功能显著成立
```

本段不锁关羽稳定纯 nx 本体，不锁 zx，不锁严格 zx↔nx 补关系。

## 1｜事实链

樊城战中关羽右臂中毒箭。拔箭后毒已入骨，右臂青肿不能运动；众将四方访求名医。华佗到营后查看伤臂，判断乌头药毒已透入骨，并提出割肉至骨、刮去箭毒、敷药缝合的具体治疗办法。

关羽接受该治疗。华佗实际下刀、刮尽骨毒、敷药缝合。治疗后关羽明确表示右臂重新伸舒如故。

对象、动作、结果高度闭合：

```text
对象：关羽右臂毒伤
触发：毒入骨、右臂不能运动
外部接口：华佗专业诊断与手术能力
动作：诊断→割开→刮毒→敷药→缝合
结果：右臂恢复活动
```

## 2｜nx 判断

关羽在“继续攻樊城”这一军事方向上非常自主，但这不能覆盖治疗对象层。

在“怎样把已经入骨的箭毒从右臂中处理掉”这一问题上：

- 决定性专业能力不在关羽稳定调用范围；
- 关平与众将此前寻常调理不能解决；
- 华佗提供的不只是信息，而是直接执行治疗；
- 关羽真实把当前治疗过程接入华佗的专业解决通道；
- 同一毒伤瓶颈被该接口直接修复。

所以：

```yaml
nx_professional_solution_relation: evidence-locked
external_professional_solution_interface: evidence-locked
same_problem_directly_repaired_by_external_interface: true
```

这只是当前关系/行为功能，不推出“关羽没主见”。

## 3｜zx 判断

本治疗窗口排除 `zx` 主判。

关羽忍痛、饮酒、弈棋、拒绝麻醉式束缚都很强，但这些只证明其意志与耐受，不证明：

- 他取得新的医学处分权；
- 他公开扩大自己的决定范围；
- 华佗或军中医疗结构被迫承认新的关羽专业接口。

治疗后恢复到原有右臂功能基线，也不是新的权限扩张。

所以：

```yaml
zx_in_treatment_stage: rejected_as_primary
```

## 4｜xn 最近邻排除

关羽没有自己搭建诊疗流程、选择刀法、配置药材、设计手术节点。决定性运行骨架由华佗给出并执行。

因此不能因为关羽“主动选择接受治疗、自己决定不用柱环”就锁 `xn`。这些属于接受接口后的局部配合自由。

```yaml
xn_in_treatment_stage: rejected_as_primary
```

## 5｜关键压力

压力是毒入骨、右臂不能运动，以及若不治疗则手臂可能失用。

但压力本身不判 nx；真正判据是：当前同对象的解决能力外置，并被主体实际接入。

## 6｜拿掉测试

### 拿掉华佗专业接口

保留关羽继续作战的意志、耐痛与军队资源，当前“毒已入骨”仍缺少被文本证明有效的直接治疗路径，右臂恢复不能按原事实链成立。

→ nx 专业接口是真缺口。

### 拿掉“华佗实际治疗”，只保留诊断信息

如果华佗只说“这是乌头毒，需刮骨”，随后治疗完全由关羽自己或军中已有医生完成，则本例会退回“外部信息输入是否足以构成 nx”的灰区。

原文恰恰不是：华佗本人实施了关键解决动作。

### 拿掉恢复结果

如果华佗治疗后并未改善右臂，则最多能锁“外部专业接口被调用”，但不能锁“同问题被该接口直接修复”。

## 7｜反向测试

### 仅信息输入型

```text
华佗只告知毒物与风险
→ 关羽自行设计并完成治疗
→ 优先检查信息输入 + x/xn
→ 不自动锁 nx 解决通道
```

### 高纯 nx 专业接口型

```text
主体当前问题无法自行处理
→ 外部专业者掌握关键诊断/操作能力
→ 主体实际接受该接口
→ 外部专业者直接处理同一对象
→ 当前瓶颈被修复
= nx关系功能强成立
```

本例属于后一种。

## 8｜最近邻排除

- `nx vs 信息输入`：华佗不仅告诉答案，而是亲自完成决定性治疗。
- `nx vs xn`：关羽没有重搭治疗方案。
- `nx vs x`：治疗能力未进入关羽稳定调用边界；伤愈后也不能自行重复调用华佗医术。
- `nx vs zx`：恢复旧身体功能不等于扩大公共决定范围。
- `nx vs 强弱`：不是“关羽弱、华佗强”，而是专业解决能力属于不同对象层。

## 9｜第三因素冻结

冻结：关羽忠义、勇猛、忍痛能力、华佗名医声望、战役胜负、史实真伪、文学夸张。

只检查：

```text
当前具体问题是什么？
谁掌握直接解决能力？
主体是否实际接入？
外部接口是否直接改变同一个对象？
```

结论不变。
