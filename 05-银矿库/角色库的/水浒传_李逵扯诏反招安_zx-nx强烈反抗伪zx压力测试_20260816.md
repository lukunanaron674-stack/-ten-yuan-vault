# 《水浒传》李逵扯诏反招安｜zx-nx 强烈反抗伪zx压力测试

## 1｜剧情事实

- 朝廷第一次派陈宗善至梁山宣读招安诏，诏书要求梁山交出钱粮、军器、马匹、船只，拆毁巢穴并赴京受招安。
- 萧让读罢后，宋江以下众人已有怒色。
- 李逵从梁上跳下，夺诏并扯碎，继而欲殴陈宗善，又殴打李虞候，公开辱骂招安与皇帝。
- 宋江、卢俊义等人当场抱住并制止李逵，众人将其推下堂去。
- 这一轮招安没有成功，但李逵本人没有取得梁山招安路线的最终决定位置；后续梁山仍继续推进招安，并在第二次招安中接受朝廷安排。

## 2｜样本候选

- 纯 zx：排除。
- 纯 nx：排除。
- zx+nx：排除。
- 压力显影：存在强烈反抗行为，但未达到 zx 的权能扩张门槛。
- 伪对子：锁定“强烈反抗 ≠ zx”的反例。

## 3｜zx 检查

李逵的行为极其公开、强烈，并短暂打断现场宣诏流程，但现行 zx 要求的不只是“敢反抗”或“造成骚乱”，而是主体权能公开进入现实后，使他者、环境或等级秩序围绕其力量重新反应，并使主体的决定范围、影响位置或凌驾程度上升。

本段中：

- 李逵没有获得“招不招安”的最终路线决定权；
- 宋江、卢俊义等核心决定者没有围绕李逵的方向重新排列；
- 李逵反而被当场制止并推下堂；
- 后续梁山总体路线仍继续向招安推进。

因此，本段可以锁定“强烈反抗行为”，但不能锁定高纯 zx。

## 4｜nx 检查

李逵也不符合 nx：

- 他没有顺着外部招安方向继续；
- 没有等待宋江或朝廷替自己形成意见；
- 他明确持有反招安方向并主动否决。

所以本段不是“被别人带着走”的 nx 状态。

## 5｜关键压力

外部压力来自朝廷正式招安诏、梁山头领层的路线选择，以及宋江对招安方向的长期倾向。这个压力很强，但李逵的反向立场并没有因此转化为新的实际决定位置。

## 6｜拿掉测试

### 拿掉暴力和辱骂

若只保留“李逵明确反对招安，但宋江集团不把最终路线交给他”，zx 仍不能成立。说明拳打、扯诏、辱骂不是 zx 的必要核心。

### 拿掉最终第一次招安失败结果

即便第一轮招安当场中止，只要李逵没有因此获得持续的路线决定权，也不能把“现场效果”直接升级为 zx。

### 拿掉李逵武力与莽撞人物标签

只看决定结构：主体强烈反对，但核心路线仍由别人掌握，主体位置未上升。结论不变。

## 7｜反向测试

### 反向成 zx

若李逵的公开反抗迫使宋江、吴用、卢俊义等核心头领改变梁山总体方向，取消招安路线，并使李逵由普通头领上升为新的路线决定中心，则 zx 明显上升。

### 反向成 nx

若李逵虽然不满，但最终不再提出替代方向，只按宋江与朝廷给出的路线执行，则 nx 当前行为会上升。

## 8｜最近邻排除

### zx vs 普通强烈行为

“动作猛烈、声量巨大、现场被打断”只能证明行为强度，不能证明决定范围扩大。

### zx vs x

李逵既没有长期掌握梁山路线权限，也没有取得招安事务处分权，因此不能转判 x。

### nx vs xn

本段没有计划、节点、流程设计主变量，不属于 xn。

### 第三因素冻结

冻结李逵武力、莽撞性格、反招安主题、诏书侮辱性、宋江忠君倾向、第一次招安是否成功等因素后，只检查“谁掌握最终路线、李逵是否取得新增决定位置”，结论仍是伪 zx。

## 9｜结论

本段锁定：

> **强烈反抗、公开破坏甚至短暂中断流程，都不自动等于 zx。zx 还必须看到主体的实际决定位置或决定范围上升。**

李逵在本段拥有清晰自主方向，因此不是 nx；但其方向没有压成新的梁山最终路线，也没有取得更高处分位置，因此不锁 zx。

这与《红楼梦》探春抄检大观园形成反向最小差异：探春的公开反击使执行组真实调整并恢复其局部边界，形成 zx 当前状态高显影；李逵虽动作更猛烈，却没有取得新的路线决定位置，因此是“强烈反抗伪zx”反例。

## 10｜理论处理

- 不修改 L1。
- 不修改 zx/nx 信息卡。
- 不修改 zx/nx 准度卡。
- 不修改 `zx补nx_补卡`。
- 不锁李逵稳定人物本体。
- 本例仅作为现有 zx 门槛的高质量反例证据。

## 11｜2026-08-27 新增研究用途：nx 任务层激活反向护栏

本轮不重判人物，而把同一已锁事实用于检验 `nx任务层同人相邻off-on激活开关边界` 的反向门：

```text
朝廷招安方向已明确发出
→ 梁山钱粮、军器、马匹、船只纳官
→ 拆毁巢穴、赴京受招安
→ 外部方向已真实进入关系场

但李逵：
→ 夺诏扯碎
→ 公开否定招安
→ 不接受赴京/纳官方向
→ 不沿朝廷招安通道续接
```

因此在“李逵是否承接朝廷招安方向”这一窄对象层：

```yaml
external_direction_present: true
subject_actual_acceptance: false
subject_actual_continuation: false

```

### 拿掉测试

拿掉扯诏、殴打、辱骂等强烈动作，只保留“招安方向已发出 + 李逵明确拒绝承接”，该对象层 nx 仍不成立。说明行为强度不是本结论支柱。

### 反向测试

若李逵虽然不满，却接受朝廷招安方向，随后按“纳官、拆寨、赴京”继续，则当前招安对象层 nx 明显上升。

### 最近邻排除

- `nx vs zx`：拒绝外部方向不自动等于 zx；本案既有结论仍是强烈反抗不足以锁 zx。
- `nx vs xn`：扯诏不是运行骨架设计，本轮不以 xn 为主。
- `nx vs 强迫/命令强度`：圣旨、天兵威胁、组织压力都不能替代主体真实承接。

### 第三因素冻结

冻结李逵武力、诏书措辞侮辱性、宋江招安倾向、第一次招安最终是否失败，只保留：

```text
外部招安方向是否明确发出？
主体是否真实承接？
主体是否沿该方向继续？
```

结论不变。

### 新增用途结论

> **外部任务/方向明确发出，甚至来自最高权威并伴随惩罚威胁，也不能自动把 nx 切到 on；主体真实承接与续接仍是必要门。**
