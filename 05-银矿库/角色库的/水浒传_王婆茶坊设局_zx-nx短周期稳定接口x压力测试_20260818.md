# 《水浒传》王婆茶坊设局：zx-nx 短周期稳定接口 x 压力测试

## 1. 剧情事实

对象：王婆。
阶段：第二十四回，西门庆窥见潘金莲后，到王婆茶坊打听并求王婆撮合；王婆以自己的茶坊、邻里位置与会面安排为接口，逐步制造西门庆与潘金莲接触机会。

明确动作链：

1. 王婆先观察西门庆反复在武大家门前徘徊，并主动判断其意图。
2. 西门庆进入茶坊后，王婆掌握茶坊空间和邻里信息，并以此控制双方何时接触。
3. 王婆收银后主动设计会面条件，使潘金莲进入自己的空间，再安排西门庆在场。
4. 王婆负责茶、酒、离席、留二人独处等关键接触节点。
5. 西门庆与潘金莲关系发生实质变化，结果由王婆设计的秘密会面结构显著推动。

原文的硬证据不是“王婆会说媒”这一职业标签，而是茶坊、邻里观察、会面入口、离席窗口等关键接口在这段时间内反复由王婆实际控制。

## 2. zx 判断

结论：`rejected_as_primary`。

王婆确实成功改变了事件结果，但她没有公开取得新的贾府、县衙、婚姻或人身处分权，也没有让外部秩序承认一个新增的王婆决定接口。

主要手段是：观察、诱导、隐藏真实意图、制造接触条件、控制场景与时机。

因此：

```text
秘密设局成功改结果
≠
主体权能公开扩张
```

最强最近邻是 `xn`，不是 `zx`。

## 3. nx 判断

结论：`rejected`。

不能因为王婆用了西门庆、潘金莲两个人，或因为她收钱帮西门庆办事，就写成“借别人 = nx”。

本段真正的关键接口——茶坊空间、接触入口、会面安排与离席窗口——并不是王婆需要向别人申请后才能调用的外部权限；这些局部接口在当时就是她稳定掌握并直接调度的。

她也没有沿一个更高权限主体给定的方向等待批准，而是在主动设计这条秘密路径。

## 4. x 最近邻

正式锁：`x_local_interface_control_neighbor: evidence-locked`。

这里的 x 不是“王婆拥有西门庆或潘金莲”，也不是锁定人物稳定本体。

只锁一个窄对象层：

```text
茶坊空间
+ 邻里观察位置
+ 会面入口
+ 接触节奏
+ 场景切换
```

在这一短周期事件内反复由王婆直接掌握，因此更接近“已有调用边界归我”的 x，而不是 nx。

## 5. xn 最近邻

正式锁：`xn_secret_strategy_neighbor: evidence-locked`。

王婆主动观察、判断、设局、分阶段制造接触、选择离席窗口，明显属于计划、节点和流程组织。

所以：

- `x` 回答：这些局部接口归谁实际掌握；
- `xn` 回答：王婆怎样组织这些接口形成连续圈套；
- `zx` 回答：她有没有公开扩大现实决定范围；没有；
- `nx` 回答：她是否必须沿别人已有权限通道推进；本窄层没有。

## 6. 拿掉测试

### 拿掉“媒婆/开茶坊”职业标签

只保留“主体稳定掌握一个会面空间与接触入口，并主动设计节点”，结论仍是 `x + xn` 邻近，zx/nx 不成立。

### 拿掉最终偷情结果

即使两人最后没有发生关系，只要王婆仍能反复调用自己的空间、会面与接触接口，`x` 邻近仍成立；所以不能用“最终成功”反推 zx。

### 拿掉茶坊控制

如果王婆没有稳定空间与接触接口，每一步都必须向另一个真正掌权者请求使用场地、见面许可或人员调动，则 x 会下降，nx 才可能上升。

## 7. 反向测试

### 反向成 nx

王婆想撮合，但会面地点、人员接触许可都在另一个主体手里；她必须求人批准、借权限后才能安排双方接触。

### 反向成 zx

王婆原本没有某项公开处分权，但在事件中凭自身权能公开取得并扩大该权力，使相关人物或制度以后必须围绕她新增的决定接口运行。

本段均不满足。

## 8. 第三因素冻结

冻结：

- 王婆贪财；
- 西门庆好色；
- 潘金莲婚姻评价；
- 武大弱势；
- 后续杀人案；
- 道德主题；
- 最终悲剧结果。

只检查“谁掌握局部接口、谁设计流程、是否公开扩权、是否沿外部权限通道”，结论不变。

## 9. 结论

本段不锁人物稳定本体，不锁严格 `zx↔nx` 补关系。

案例级纪律：

```text
秘密设局并成功改结果，不自动是 zx；
调用自己稳定掌握的局部空间/接触接口，优先检查 x；
主动设计会面、时机与流程，优先检查 xn；
只有关键接口真实在外部且必须沿其权限推进，才检查 nx。
```

本例只能作为“短周期稳定局部接口”的 x 证据，不能冒充“长期幕后稳定控制”第二个跨作品锚，因此不增加该待审议边界的跨作品计数。
