# 清太（Seita）
> 归档：`05-银矿库/角色库/萤火虫之墓_清太.md`

---

## 1. 主十元判断

**主十元：n（阳火·怕死了但扛住了）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉n，清太就是一个在战争中死了妈妈的大男孩——他能干活、会照顾妹妹、能在废墟里找到吃的。但清太最核心的不是"会照顾"，是**他每一步都在硬撑**。妈妈死了他没当着节子的面哭、亲戚冷眼他没吵、饿到快死也没去偷——他不是不会"生存"（x），是他不能当着节子倒下。
- **第2问（反复面对什么结构）：** 反复面对「撑不住了，但必须撑」。取存款时被拒、食物越来越少、节子开始生病——每一个节点都在说"你认输吧"，但他硬生生扛到了最后一口饭。
- **第3问（最怕失去什么）：** 最怕「节子看到我没用」。不是怕饿死（x），是怕饿死这件事被妹妹看到。他宁愿在山洞里自己少吃，也要让节子觉得"哥哥有办法"。
- **第4问（回到哪个感觉）：** 回到「妈妈还在、家里还有笑声」的那一天。他在废墟里捡起妈妈烧焦的遗物时，不是找食物，是找那个感觉。
- **第5问（副十元服务谁）：** z（想被看见/想被妹妹视为可靠的哥哥）服务于n——"我不能倒下"的动力来源是"我要让节子觉得哥哥还能撑"。

## 2. 副十元

**副十元：z（阴火·想被看见/被需要）**

**作用：** 清太的所有力气来自节子看他的那个眼神。他煮好饭、分食物、编故事——这些动作不是在执行任务（zx），是在"你在看着我，我得让你觉得我很好"。

## 3. 功能十元

**功能十元：xn（阴土·在规则里找路）——表层行为。** 他知道他不能去偷、不能去抢、不能把妹妹寄养在别人家——他在战争的社会规则内小心翼翼地走钢丝，但这不是他的驱动。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** "哥哥有办法"——他在节子面前的表情、语气、承诺，都是包装。外壳比核重要——因为外壳碎了，节子的世界就碎了。

## 5. 动态链

```
n（主·怕死了但扛住了/不能当着节子倒下）
  → z（副·必须在妹妹眼里是可靠的）
  → xn（功能·在战争规则里找生存缝隙）
  → 妈妈死了→搬去山洞→粮食见底→节子生病
  → 他扛到了最后一刻——节子死的时候他才终于倒下了
```

## 6. 一句话定型

清太不是「战争的受害者」，也不是「守护妹妹的好哥哥」，而是「**怕死了但必须扛着，因为有人看着你**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** n（主）+ z（副）→ 本体型
**最终定位：** n（主·怕死了但扛住了）+ z（副·想被妹妹看见是可靠的）→ 本体型
**最终修正理由：** 原卡将清太定位为zx（先做再想）+ nx（算清楚再动），但他不是靠"完成即意义"驱动，也不是靠"看清了再动"。他是硬撑——每一步都怕到发抖，但没有选择。n是他的底色（怕死了但扛住了），z妹妹持续需要的眼神是他的燃料。他在节子死后彻底塌了，说明他的全部力量来自"不能让妹妹看到我扛不住"——这是n+z的典型形态。
