# 《三国演义》诸葛亮草船借箭｜关键节点重设与终点续接压力测试

## 结论先行

本轮锁定：

> **外部给定最终任务终点，不等于主体在所有下位运行层都属于 nx。**
>
> 周瑜给出的上位结果是“取得十万枝箭以供水战”，诸葛亮接受这一结果要求并最终交付十余万枝，因此在“上位任务终点”对象层可锁 `nx` 续接；但在“何时完成、怎样取得”这一运行层，诸葛亮不仅没有沿周瑜预设的监造路径继续，反而主动把十日改为三日，并自行重设船只、草束、人员、雾夜、接近曹营和受箭方式，因此该运行层 `nx` 下降，`xn` 最近邻高显影。
>
> 这不是 `zx` 扩权：诸葛亮没有因此取得东吴新增军令处分范围，也没有让吴军以后围绕一个新增的诸葛亮权力接口运行。

本轮不锁诸葛亮稳定人物本体，不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实

### 外部任务与触发

周瑜以水战缺箭为由，请诸葛亮“监造十万枝箭，以为应敌之具”，并先提出十日内完成。

这给出了明确的外部任务终点：

```text
为东吴水战取得十万枝箭
```

### 主体主动改写关键节点

诸葛亮没有照“十日监造”的运行框架推进，而是主动判断十日会误军机，并自行提出“三日即可交纳十万枝箭”，还主动立下军令状。

这不是局部动作微调，因为它直接改变了任务最关键的时间节点。

### 主体主动替换实现方法

周瑜随后命军匠故意拖延、不把造箭材料配齐，显然仍把诸葛亮置于“监造箭枝”的常规路径中。

诸葛亮却完全跳出这一路径，转向鲁肃请求二十只船、每船三十余军士、青布幔与大量草束；第三日利用大雾，把船连结驶近曹军水寨，让曹军集中放箭，最终把箭带回。

因此真正的运行结构由诸葛亮自行建立：

```text
借船与人员
→ 草束布置
→ 等第三日大雾
→ 夜航近曹营
→ 制造受敌错觉
→ 承接曹军箭矢
→ 运回交付
```

### 最终结果

船回岸后，共得十余万枝箭，周瑜已经派五百小军在江边搬取，诸葛亮完成了原本要求的“十万枝箭”终点。

因此：

```text
外部终点：十万枝箭
↓
关键期限：主体改写
↓
实现方法：主体重设
↓
最终交付：仍完成同一上位终点
```

## 2｜nx 判断

### 上位任务终点层：成立

本轮 `nx` 不是“诸葛亮没主见”。

在“最终要交付什么”这一对象层，十万枝箭是周瑜／东吴军事需求给出的既有任务，诸葛亮没有把它改成另一个最终目标，并且最后确实按这个终点交付。

因此锁：

`nx_upper_task_endpoint_continuity: evidence-locked`

这只证明当前任务关系位置与行为功能，不证明诸葛亮稳定人物本体为纯 nx。

### 运行方法层：排除

在“怎样完成”这一对象层，诸葛亮没有沿外部已有运行方式继续。

他主动：

- 把十日改成三日；
- 放弃常规监造；
- 另找鲁肃资源接口；
- 自行建立草船、草束、人员、天气与敌军射击组成的新运行结构。

因此锁：

`nx_in_operational_method_layer: rejected`

上位终点的 nx 不能覆盖下位运行层。

## 3｜xn 最近邻

本轮最强最近邻是 `xn`。

`xn` 解释的是：

> **主体怎样把一个外部任务重新组织成可运行的阶段、节点、资源配置与方法。**

诸葛亮不仅临场自由发挥，而是改写了关键时间节点和核心实现机制，因此比赵云长坂坡“执行中高度自主但未必重写既有方案”的案例更进一步。

锁：

`xn_key_node_method_rewrite_neighbor: evidence-locked`

## 4｜zx 检查

本段很容易因为“诸葛亮把周瑜都算计了”“周瑜叹服”而误判 `zx`。

但现行 `zx` 要求：

```text
自身权能公开进入现实
+ 他者或秩序实际重新反应
+ 主体决定范围 / 凌驾位置真实上升
```

草船借箭证明诸葛亮有极强的方案能力，却没有证明他因此取得新的东吴军令处分权。

周瑜仍是都督，吴军最高军事接口没有转移给诸葛亮；鲁肃提供船与军士，也是一次具体资源协助，不等于东吴资源处分边界归诸葛亮长期掌握。

因此：

`zx_in_narrow_stage: rejected_as_primary`

> **方案惊人、任务成功、别人叹服，都不能代替“决定范围扩大”。**

## 5｜关键压力

本轮存在三层外部压力：

1. 周瑜设置军务任务；
2. 三日军令状形成高成本时间压力；
3. 周瑜暗令工匠与材料故意拖延，常规监造通道被人为削弱。

这些压力解释了为什么诸葛亮需要重设运行方式，但不能直接判十元。

尤其不能写成：

```text
压力大
→ 诸葛亮很强
→ zx
```

木轴仍只看方向、终点、运行重设与决定范围。

## 6｜拿掉测试

### 拿掉“神机妙算”人物评价

只保留：

```text
外部给十万箭终点
→ 主体把十日改三日
→ 主体替换监造方法
→ 最终仍交十万余箭
```

“上位 nx + 运行层 xn”仍成立。

### 拿掉“三日”这个具体数字

如果时间节点不再是三日，但主体仍完全放弃外部常规监造路径、自行建立草船取箭方案，运行层 `xn` 仍成立。

因此三日不是唯一证据，只是关键节点重设的强证据。

### 拿掉诸葛亮自己的方法重设

如果周瑜不仅给十万箭终点，还把船只、草束、时机和取箭方法全都安排好，诸葛亮只照流程执行，则运行层 `xn` 会显著下降，`nx` 会覆盖更多对象层。

### 拿掉外部任务终点

如果没有周瑜／东吴先给“十万箭”这一任务，而完全由诸葛亮自己首次提出“我要取得十万箭并组织实施”，则本轮上位 `nx` 证据明显下降，应重新检查主体自生方向。

## 7｜反向测试

### 反向成更纯 nx

```text
周瑜给十万箭目标
+ 周瑜给十日监造方案
+ 周瑜给具体材料 / 人员 / 制造节点
→ 诸葛亮不重设，只照做
```

则运行层也会明显偏 `nx`。

### 反向成终点否决

如果诸葛亮不接受“取得十万箭”这个上位任务，改成完全不同的最终结果，则同一上位终点层的 `nx` 应下降或排除，接近朱仝私放雷横那种“最终结果被主体改写”的结构。

### 反向成 zx

如果诸葛亮借本次事件取得此前没有、以后可独立调用的东吴军令或资源处分范围，使吴军组织稳定围绕他的新增权力接口运行，才应进一步锁 `zx`。

原文没有这种权限转移。

## 8｜最近邻排除

### nx vs xn

```text
nx：十万枝箭这个上位终点来自外部，并被继续完成。
xn：三日、船只、草束、天气节点和取得方式由主体重新组织。
```

二者对象层不同，可以同时成立。

### nx vs x

鲁肃借出的二十只船、军士和布幔并不归诸葛亮长期处分。诸葛亮通过鲁肃取得这些资源，可以形成一次 `nx` 资源关系功能，但不能判为 `x`。

### zx vs x

即使诸葛亮在行动内部拥有现场调度权，也只是本次方案运行所需的局部接口；没有证据显示他的正式军政决定范围向外扩张，所以不能由局部掌握偷换成 zx。

### z / xz / nz 冻结

周瑜的妒忌与认可、军令状的风险、诸葛亮与鲁肃的信任都可以解释动机和压力，但不替木轴回答“谁给终点、谁重设运行、谁拥有最终权限”。

## 9｜与相邻案例的最小差异

### 赵云长坂坡

```text
外部给保护老小终点
→ 执行过程高度自主
→ 最终终点保持
→ 上位 nx + 局部 xn
```

### 诸葛亮草船借箭

```text
外部给十万箭终点
→ 主体主动改关键期限
→ 主体替换核心实现方法
→ 最终终点保持
→ 上位 nx + 运行层 nx 下降 + xn 高显影
```

### 朱仝私放雷横

```text
外部给押送终点
→ 主体最终把终点改掉
→ 该结果层 nx 排除
```

因此三档可以进一步压清：

```text
只在执行中自主调整
→ 上位 nx 基本不受影响

真正重设关键中间节点 / 方法，但终点保持
→ 上位 nx 可保留；运行层 nx 下降，xn 上升

连最终终点也实际改掉
→ 同一终点层 nx 排除
```

## 10｜第三因素冻结

以下全部不作为木轴主判：

- 周瑜是否嫉妒诸葛亮；
- 诸葛亮是否“神机妙算”；
- 大雾是否属于超常预测；
- 曹操是否谨慎；
- 草船借箭最后是否成为名场面；
- 周瑜是否叹服；
- 赤壁大战最终胜负；
- 诸葛亮身份与历史声望。

冻结这些后，仍只检查：

```text
谁给最终任务终点？
谁改写关键时间节点？
谁设计实现方法？
最终终点有没有被改写？
主体决定范围有没有真实扩大？
```

## 11｜结论

- 事实置信：99
- 分类置信：98
- `nx`：上位任务终点续接，evidence-locked
- `nx`：运行方法层 rejected
- `xn`：关键节点与实现方法重设，neighbor evidence-locked
- `zx`：本窄阶段 rejected as primary
- 稳定人物本体：不锁
- 严格 `zx↔nx` 补关系：不锁
