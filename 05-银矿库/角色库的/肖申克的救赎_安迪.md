# 安迪·杜弗兰（Andy Dufresne）
> 归档：`05-银矿库/角色库/肖申克的救赎_安迪.md`

---

## 1. 主十元判断

**主十元：zx（阳木·突破/执行）**

**五问法核验：**
- **第1问（拿掉什么他就不是他）：** 拿掉zx，安迪会变成「一个在监狱里等死的好人」——那他就不再是安迪了。他不只是不认命，他是**用行动在改命**：建图书馆、放音乐、挖隧道、换身份。没有这些执行，他的希望只是空想。
- **第2问（反复面对什么结构）：** 不断在封闭系统里打开口子。监狱是一个绝对的封闭系统（n+xn 的极致），安迪的zx就是在铁板上找裂缝，然后用二十年把裂缝凿成通道。
- **第3问（最怕失去什么）：** 最怕的不是出不去——是「失去执行的机会」。如果有一天他老到挖不动了，那才是真正的死刑。所以他在得知可能翻案的人被杀之后，没有崩溃而是提前了越狱计划——他不是伤心，是立刻切换执行方案。
- **第4问（回到哪个感觉）：** 回到「我在做事」的感觉。越狱成功后在雨中张开双臂——那不是自由的狂喜，是「我完成了」。zx的人最爽的一刻不是拥有结果，是行动闭环的那一刻。
- **第5问（副十元服务谁）：** 副十元全部服务于zx。z（被看见的希望）给zx提供燃料，nx（算计/规划）给zx提供路径——但引擎永远是zx。

## 2. 副十元

**副十元：z（阴火·执念/被看见）**

**作用：** 安迪的zx需要z作为燃料。不是「我要出去」这个目标驱动他——是「我要让监狱里的人看见希望」这个执念。他放莫扎特不是为了自己，是为了让所有人听到（被看见）。他建图书馆也不是为自己——他已经有书看了。z提供的是：**这件事做了之后会被看见**。

## 3. 功能十元

**功能十元：nx（阴金·暗算/结算）**

**作用：** 越狱计划本身是一套完整的nx结算——记账、算账房位置、算管道走向、算天气、算谁盯夜班。这是整部电影里最精密的一段算计，但它只是zx的执行工具，不是安迪的底色。他算计不是为了算计本身，是为了**完成越狱这个行动**。

## 4. 视觉十元

**视觉十元：无显著。** 安迪在监狱里穿囚服时和出狱后穿西装时都是同一个人——他的十元不靠视觉定义。

## 5. 动态链

```
zx（主·用执行打破封闭系统）
  → z（副·让希望被看见）为zx提供燃料
  → nx（功能·越狱算计）为zx提供执行路径
  → 二十年挖通隧道
  → 雨中张开双臂（行动闭环）
```

## 6. 一句话定型

安迪不是「在绝望中保持希望的人」，而是「**必须用行动把希望凿通**的人」。

## 旧卡修正记录

**旧定位：** 因果型 zx+nx
**新定位：** zx（主）+ z（副）
**修正理由：** 旧卡把安迪的nx（越狱算计）和zx（执行突破）放在同等位置，但灵魂判断后确认：nx是zx的执行工具，不是同等引擎。拿掉nx安迪还是安迪（会换一种方式越狱），拿掉zx安迪就不是安迪了——他变成在监狱里等死的好人。同时旧卡遗漏了z（被看见的希望）这个关键副十元——安迪放莫扎特、建图书馆这些行为的底层驱动不是「我想出去」，而是「让所有人知道我们还在」。
