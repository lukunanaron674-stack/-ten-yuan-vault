# 三国演义｜赵云锦囊入吴｜zx-nx 外部节点纯 nx 压力测试

## 1｜剧情事实

- 诸葛亮判断刘备入吴需要预设应对方案，明确说自己已定三条计策，并把三个锦囊交给赵云，要求“依次而行”。
- 到南徐后，赵云不是自己重新设计第一阶段，而是确认“军师分付三条妙计，依次而行”，随后开启第一锦囊，照其中计策安排五百军士并推动刘备见乔国老。
- 到年终，赵云回忆诸葛亮预设的开启条件：到南徐开第一，年终开第二，危急无路时开第三；随后依节点开启第二锦囊并照计行动。
- 因而，本桥段中“何时开启下一阶段、关键节点如何定义、核心解决方案从哪里来”的来源均在诸葛亮预设方案，而非赵云当场生成。

外部文本核验：
- 《三国演义》第五十四回，维基文库：https://zh.wikisource.org/zh-hans/三國演義/第054回
- 《三国演义》第五十五回原文检索页：https://m.gushiwen.cn/guwen/bookv_eb249019d072.aspx

## 2｜样本候选判断

### 纯 zx

排除。

赵云能统领五百军士、能保护刘备、能具体下达执行命令，但这些都发生在诸葛亮已给定的计策和阶段接口之内。本段没有出现赵云公开重设整个行动方向，也没有使原有决策秩序围绕赵云自身权能重新排列，因此不满足 zx 的“自身权能公开显现、扩大并使他者或秩序重新反应”的必要条件。

### 纯 nx

锁定在当前行为功能 / 关系位置层。

关键不是“赵云听诸葛亮的话”，而是：

```text
关键方向与阶段方案已由诸葛亮预设
+ 开启节点也由诸葛亮预设
+ 赵云不重设这些关键节点
+ 到节点后读取并沿既有方案推进
= nx 高纯度行为功能
```

不锁“赵云稳定人物本体 = nx”。

### zx+nx

本桥段不锁。赵云具有执行力，但执行力本身不等于 zx；本轮没有足够证据证明 zx 独立成立后再与 nx 互补。

### 压力显影

不是主结论。东吴环境有风险，但本轮分类不依赖危机强迫，而依赖预设方向、节点与通道的归属。

### 伪对子

主要排除“因为赵云实际组织了五百军士，所以应判 xn”的伪近邻。

## 3｜nx vs xn 最近邻

本轮最重要的最小差异：

```text
诸葛亮：预先设计三阶段、开启条件与关键方案 → xn 高度可疑/高显影
赵云：到外部节点后读取方案并执行 → nx 行为功能
```

赵云确实在第一锦囊开启后具体分付军士，但“分付执行”不能反向夺走方案与节点设计权。

判断问题必须问：

- 谁决定什么时候开下一步？诸葛亮。
- 谁设计关键阶段？诸葛亮。
- 赵云是否取消原节点并另建运行结构？没有。
- 赵云是否只是把既有方案落实到具体人员？是。

所以本桥段优先 nx，而不是 xn。

## 4｜拿掉测试

### 拿掉“诸葛亮”这个人物名

只保留“外部规划者预先给定三阶段方案与开启条件，执行者到节点才读取并推进”，赵云位置仍为 nx。

### 拿掉胜利结果

即使最后联姻或脱身失败，只要赵云仍不占关键阶段与开启条件的设计权，而按外部节点推进，nx 判断不变。

### 拿掉武将身份与能力

即使执行者不是赵云，只要结构仍是“别人设计节点与方案，我按节点开启并推进”，nx 仍成立。

## 5｜反向测试

### 反向成 xn

如果诸葛亮只给“保护刘备安全回荆州”这个总目标，而赵云自己设计南徐造势、年终撤离、危急脱身三个阶段，并自己设定开启条件，则 xn 应明显上升，nx 下降。

### 反向成 zx

如果赵云公开否决诸葛亮预设方案，以自己的权能重新决定整个入吴行动方向，并迫使刘备、随行军士乃至原计划围绕自己的决定重排，则 zx 才明显上升。

## 6｜第三因素冻结

冻结以下因素后，结论仍成立：

- 赵云武力与忠勇形象；
- 刘备主公身份；
- 诸葛亮“神机妙算”主题；
- 东吴危险程度；
- 最后是否成功脱身；
- 锦囊这一视觉道具本身。

只保留“方向/阶段/节点是谁设计、谁拥有重设资格、执行者是否沿外部预设继续”，仍得到 nx。

## 7｜与现有案例的最小差异

- 黄忠定军山：法正掌握红白旗启动时机，黄忠按外部信号行动 → nx。
- 杨志押送生辰纲：外部只给总目标，杨志主动否定旧方案并重设运输流程和时间节点 → xn 最近邻优先，伪 nx。
- 赵云锦囊入吴：外部不仅给目标，还预先给阶段与开启条件；赵云到节点读取并执行 → nx。

因此本轮进一步压实：

> “接到外部目标”本身不能区分 nx 与 xn；真正高价值的变量是关键运行节点与重设权归谁。
