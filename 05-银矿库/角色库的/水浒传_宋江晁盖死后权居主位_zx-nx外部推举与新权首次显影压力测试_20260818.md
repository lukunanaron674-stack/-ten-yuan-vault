# 《水浒传》宋江晁盖死后权居主位｜zx-nx 外部推举与新权首次显影压力测试

## 1｜剧情事实

晁盖临终留下条件：捉得史文恭者，可立为梁山泊主。晁盖死后，宋江每日举哀，无心管理山寨。林冲、公孙胜、吴用等众头领商议后，主动推宋江为梁山泊主，并说明山寨不可一日无主、诸人愿拱听号令。

宋江最初并未直接接受。他明确引用晁盖遗言，认为晁盖尸骨未寒、仇未报，不应立即居主位。吴用随后提出折中方案：先“权且尊临此位”，以后再依晁盖遗言另作计较。宋江接受这一外部提出的临时承接方案，明确表示“权当此位”。

真正坐上第一把交椅后，宋江马上公开运行新获得的山寨最高接口：将聚义厅改为忠义堂，把山寨人马分为六寨，重新分配各头领岗位、关隘与水陆守备。众头领参拜并按新分配进入组织运行。

## 2｜对象层拆分

```text
【承接入口】
谁先提出宋江做山寨之主？
→ 林冲 / 吴用 / 公孙胜等众头领

宋江最初：
→ 真实拒绝立即居位

吴用提出：
→ 先权居主位

宋江：
→ 接受这一外部承接方向
= nx 承接入口关系功能

【授权完成后的首次运行】
此前：
→ 宋江没有晁盖死后这套最高山寨处分接口

权居主位后：
→ 坐第一把交椅
→ 改聚义厅为忠义堂
→ 分六寨
→ 重排众头领岗位与守备
→ 众人围绕新接口运行
= zx 新获权限首次公开显影

【稳定以后】
新主位权限已进入宋江实际掌握范围
→ 后续普通调用优先检查 x / xn
```

## 3｜nx 证据

本例的 `nx` 只锁在“是否承接寨主位置”的入口层，不锁宋江纯 nx 本体。

宋江不是自己先宣布“我要做梁山泊主”，而是众头领先提出方向。他甚至先依据晁盖遗言拒绝，最后接受的是吴用提出的“权居主位”方案。

因此入口层结构为：

```text
外部群体提出承接方向
→ 主体拥有否决窗口并先拒绝
→ 外部提出新的临时承接方案
→ 主体最后沿该方案进入新位置
= nx 当前承接行为 / 关系位置
```

这不能反推“宋江稳定人物本体 = nx”。

## 4｜zx 证据

本例的 `zx` 不锁在“别人推举宋江”这一瞬间，而锁在**新权限真实进入主体并被首次公开运行**以后。

1. 新决定接口真实进入宋江：他从晁盖以下的重要头领，上升到“权居主位”的最高组织位置。
2. 权能公开进入现实：不是只得到名义称号，而是立即主持山寨大事。
3. 他者/秩序围绕新接口重新反应：众头领参拜，六寨、关隘、水军和岗位重新分配。
4. 决定范围真实上升：此前没有的山寨最高组织处分范围，现已能由宋江公开调用。

因此：`zx_new_authority_first_public_operation: evidence-locked`。

## 5｜为什么不是“被推举，所以只有 nx / x”

外部推举只能解释新权限的来源，不会自动消灭授权完成后的主体扩位事实。

如果宋江只是被众人叫一声“寨主”，但实际不能重排山寨、众头领仍不服从其新接口，则只能算名义升位，zx 证据不足。

本段却在承接后立即出现：

```text
新主位成立
→ 新最高处分接口实际可调用
→ 组织围绕它重新排列
```

所以与仓库“周瑜受剑拜都督”同型：授权前可有 nx，授权真实完成并首次公开运行时可出现 zx，稳定后再转查 x。

## 6｜为什么不是董卓式 x→zx

董卓案例的方向来源不同：董卓先有军队控制 `x`，随后主动把已有军事实力越界压入皇帝废立层，属于主体自己把边界向外推。

宋江本例则是：

```text
众头领先推举 / 授位
→ 宋江接受
→ 新权限进入主体
→ 主体首次公开运行
```

因此两例不能混成一个机制：

- 董卓：`x已有局部控制 → 主体主动越界扩权 → zx`
- 宋江：`nx承接入口 → 新权限真实转入 → zx首次显影 → x稳定持有`

## 7｜关键压力

关键压力是晁盖死亡造成山寨最高组织接口空缺，同时晁盖遗言又对正式继位形成限制。

这会把三个对象层同时显影：

- 谁提出临时承接方向；
- 谁最后接受；
- 新位置进入主体后是否真的可公开运行。

“晁盖死了”本身不是 zx，也不是 nx；它只是制造结构窗口。

## 8｜拿掉测试

- 拿掉宋江声望：只要众头领仍真实推举、宋江接受后取得并公开运行新最高接口，本结构仍成立。
- 拿掉“第一把交椅”文字：只要宋江实际能重排六寨和头领岗位，zx 仍成立，不靠座位称号判定。
- 拿掉后续重排山寨：若只有推举和称号，没有真实新增处分范围公开运行，zx 会明显下降，更接近“nx承接 + 名义授权候选”。
- 拿掉众头领推举：若宋江自己先夺位并迫使众人承认，则入口层 nx 消失，应转查主体主动扩权型 zx。

## 9｜反向测试

### 反向成只有 nx / 名义授权

众头领推宋江暂居其位，但所有重大事务仍必须由吴用、林冲等共同批准，宋江不能独立重排山寨，则新增权限未真正进入主体，zx 不锁。

### 反向成静态 x

如果宋江在晁盖死前已经正式、稳定拥有同等最高处分范围，本轮只是继续用原权，则优先检查 x，不制造 zx。

### 反向成董卓式 zx

如果宋江主动否定晁盖遗言、强行夺取主位，并以已有势力迫使山寨承认新的最高边界，则入口机制改为主体主动越界扩权，不再是本例的 nx 承接入口。

## 10｜最近邻排除

### nx vs xn

吴用提出临时方案、宋江之后设计六寨分工，都有 `xn` 组织邻近；但 nx 只回答“新主位承接方向最初是不是由宋江自己建立”，zx 只回答“新权进入后是否成为主体公开的新作用来源”。

### zx vs x

`zx` 是从原来没有这套最高处分范围，到新权第一次公开成为自身作用接口的跃迁；`x` 是这套权限稳定以后已经归主体掌握的状态。

### zx vs nx

同一桥段可以分阶段成立，不能把入口的 nx 倒灌到授权后的运行层，也不能用后段 zx 抹掉前段外部推举事实。

## 11｜第三因素冻结

不以这些因素直判十元：宋江是否权谋、金圣叹批语、晁盖遗言的道德评价、宋江个人声望、李逵拥戴、后续招安、卢俊义后来上山、梁山最终命运。

只问：

1. 新主位方向最初由谁提出；
2. 宋江是否实际承接；
3. 承接后新决定范围是否真的进入主体并公开运行。
