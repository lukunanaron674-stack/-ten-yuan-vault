# 三国演义｜周瑜受剑拜都督｜zx-nx 游说后权限转移压力测试

## 结论摘要

本桥段锁定一条与“诸葛亮智激孙权”直接相反的最小差异：**在孙权正式决策以前，周瑜同样必须说服真正掌握东吴最高军政裁决权的孙权，此层为 `nx` 关系功能；但孙权随后不仅采纳意见，而且把剑与大都督职位及对诸将的军令处分接口真实授予周瑜。周瑜随即公开调用这套新增权限，命诸将到行营听调、设置违令处分、分派先锋与各队，连原本不服其位次的程普也转而服从。此时周瑜的实际决定范围相较说服前真实扩大，因此 `zx` 当前状态成立。**

同时，授权完成以后这套军权已成为周瑜可以独立调用的实际权限，故 `x` 作为“新获权限已经归我掌握”的最近邻真实存在；但本轮关注的是从未拥有到公开取得并使军中秩序围绕新接口重排的**扩权过程**，因此主判为 `zx` 状态上升，而不是静态 `x`。

不锁“周瑜稳定人物本体 = zx”或“= nx”，也不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实、触发、对象、动作与结果

### 触发

曹操大军南下，孙权内部战降未决。周瑜回到江东后明确主张抗曹，并向孙权分析曹军的多项不利条件，请求数万精兵进屯夏口破曹。

### 对象与原始权限归属

```text
东吴是否正式抗曹：孙权最终裁决
东吴军队的最高授权来源：孙权
周瑜在授权前：可主张、可建议、可请求领兵，但不能自行把整个吴军纳入自己新设的最高军令接口
```

### 明确动作

1. 周瑜公开向孙权提出抗曹判断并请求精兵出战。
2. 孙权明确决定抗曹，以剑断案示决心。
3. 孙权将佩剑授予周瑜，并封其为大都督，程普为副都督、鲁肃为赞军校尉；同时明确赋予周瑜对不听号令者依剑处分的权限。
4. 周瑜受剑后当众宣布次日诸将到江畔行营听调，迟误者按军令处分。
5. 次日周瑜在中军帐实际调度：任命先锋、分列各队、配置巡警使并规定行军与军纪。
6. 程普起初因年长且位在周瑜之下而不服，见周瑜调兵有法后亲自到行营谢罪，军中对新决定接口形成现实响应。

### 结果

周瑜从“必须影响孙权才能推动东吴出兵”的位置，进入“可独立调度诸将、实施军令处分”的大都督决定位置；决定范围真实扩大，且新增权限在后续行动中被公开调用。

## 2｜zx / nx 分类

### A. 授权前：nx 关系功能成立

周瑜自己的主战方向很明确，因此不是纯 nx 本体。但“东吴是否开战、是否将军队正式交由其统辖”的最终权限仍在孙权手里。

```text
我有自己的抗曹方向
↓
但吴国是否开战、是否授军权不由我最终决定
↓
必须向孙权陈述、说服并请求兵权
↓
由孙权调用最高权限完成授权
= nx关系功能
```

锁定：

- `nx_relation_function_before_grant: evidence-locked`
- `pure_nx_essence: rejected`

### B. 授权后：zx 当前状态上升成立

关键不是“孙权听了周瑜的话”，而是**权限真的转移并扩展到了周瑜本人**。

周瑜在说服前没有“对东吴诸将整体下达最高战区军令、以授剑处分违令者”的完整决定范围；受剑拜都督后，这个接口新增到他身上，并立即公开进入现实。

符合 zx 准度卡：

1. 主体自己的决定接口明确：受剑后周瑜拥有大都督军令接口。
2. 权能公开进入现实：当众发令、次日升帐调兵。
3. 他者与秩序实际回应：诸将按其分派行动，程普的关系位置也发生调整。
4. 决定范围真实上升：从建议/请求者扩大为可独立调度吴军诸将的战区决定者。
5. 不是普通职业行为：本轮锁的是**新增授权与位置跃迁**，不是“都督平常下命令”。

因此：

- `zx_current_state_after_grant: evidence-locked`

## 3｜关键压力

关键压力不是曹军强弱本身，而是**周瑜自己的战略方向必须先经过孙权这一最高军政接口，随后才发生真正的权限转移**。

这让同一桥段中两个状态可以拆开：

```text
授权前：权限在外部 → nx关系功能
授权发生：决定接口真实迁移/扩大
授权后：自身新增权能公开运行 → zx状态上升
```

不能把前段的 nx 擦掉，也不能因为后段获得军权就倒推“周瑜从来无需孙权授权”。

## 4｜拿掉测试

### 拿掉“周瑜很会说服人”

只保留：

```text
最高开战与授军权接口在孙权
→ 周瑜必须获得孙权批准
```

授权前的 nx 关系位置仍成立。

### 拿掉“大都督”这个头衔文字

只保留：

```text
此前不能独立处分全军诸将
→ 之后获得可独立调兵、处分违令者的新接口
→ 并立即公开调用
```

zx 状态上升仍成立。因此不是靠官名直判。

### 拿掉最终赤壁胜负

即使后续战争结果未知，只要权限真实新增、公开运行且军中围绕周瑜的新接口重新组织，zx 仍成立。胜负不是判据。

### 拿掉孙权授剑与授权

若孙权只说“你说得有道理”，却不把军队决定接口授给周瑜，那么周瑜仍只是成功影响最高决策者，结构会退回类似诸葛亮智激孙权的 nx 关系功能，不足以锁本轮 zx。

## 5｜反向测试

### 反向成“只有 nx，无 zx”

孙权采纳周瑜意见，但仍亲自逐项决定军队调度；周瑜只能继续提交建议并等待批准。则权限不转移，`nx` 持续，`zx` 不成立。

### 反向成静态 x，而非 zx

若周瑜在本事件开始以前就长期拥有对整个吴军的同等独立处分范围，本轮只是在正常调用已有军权，则应优先判 `x`，不能再把普通用权写成 zx。

### 反向成 xn

若孙权已把军权完整授予周瑜，而本轮只分析周瑜如何分先锋、排队列、设巡警、定军纪，核心会转向 `xn` 的运行组织。当前 zx 锁定的是**新增决定范围的跃迁**，不是具体编组技术。

## 6｜最近邻排除

### zx vs x

这是本轮最重要的最近邻。

```text
x：授权完成后，这套军令权限已经归周瑜掌握。
zx：从原先没有这整套独立处分范围，到公开获得并让军中秩序围绕新接口重排的扩权过程。
```

因此同一事件可以阶段分层：

- 授权瞬间及随后的首次公开运行：`zx` 状态高显影；
- 权限稳定以后日常调用：更接近 `x/xn`。

### nx vs xn

周瑜后续分兵、设先锋和规定军纪明显有 xn 邻近。但 nx 只锁在授权前“必须经过孙权取得军政接口”的关系位置；两者不冲突。

### nx vs zx

不能写成“周瑜说服孙权，所以 zx”。真正使 zx 成立的是**说服之后发生权限转移，并且新增权限成为周瑜自己的公开决定接口**。

### 第三因素冻结

冻结以下因素后结论仍成立：

- 周瑜历史名将光环；
- 赤壁最终胜利；
- 诸葛亮激将二乔的戏剧效果；
- 周瑜与程普个人恩怨；
- 孙权是否英明；
- 官职名称本身；
- “剑”这一象征道具。

只看“权限原来在哪、后来是否真实转移、主体能否独立调用、组织是否围绕新增接口重排”，仍支持本轮分类。

## 7｜与诸葛亮智激孙权的最小差异

### 诸葛亮

```text
自己有联吴抗曹方向
→ 必须说服孙权
→ 孙权作出吴国决定
→ 吴军权限没有转给诸葛亮
= nx关系功能
```

### 周瑜

```text
自己有抗曹方向
→ 同样必须说服孙权
→ 孙权决定抗曹
→ 进一步把军令剑、都督权与违令处分接口授予周瑜
→ 周瑜立即独立调度诸将
→ 军中围绕新决定接口重新组织
= nx关系功能起手 → zx当前状态上升
```

因此锁定案例级边界：

> **“最高决策者采纳我的意见”只证明影响成功；“最高决策者进一步把新的可独立调用权限真实转给我，并使我的决定范围公开扩大”，才出现 zx 扩权证据。**

## 8｜严格 zx↔nx 补关系检查

本轮不锁严格补关系。

理由：虽然时间链上出现 `nx → zx`，但现行补卡要求证明两端各自独立成立，并且拿掉任一端会出现可命名缺口、补回后缺口可重复改善。本例更直接证明的是**阶段切换与权限转移**，尚不足以证明稳定的“nx 补 zx / zx 补 nx”互补机制。

因此：

- `strict_zx_nx_complement_locked: false`

## 9｜层级结论

- 稳定人物本体：不锁。
- 周瑜个人战略方向：自主明确。
- 授权前关系位置：关键最高军政接口在孙权，`nx` 关系功能成立。
- 授权后当前状态：新增独立军令决定范围并公开运行，`zx` 成立。
- 授权稳定后的静态权限：`x` 最近邻真实存在。
- 具体调兵排程：`xn` 邻近存在，但不是本轮木轴主判。
- 严格 zx↔nx 补关系：不锁。
