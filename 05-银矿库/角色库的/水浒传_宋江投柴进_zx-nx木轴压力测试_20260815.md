# 《水浒传》宋江杀惜后投柴进｜zx↔nx 木轴压力测试

## 结论先行

本轮锁定一个高价值 **nx 关系功能正例**：

> 宋江杀阎婆惜后被官府海捕，仍然主动选择去向、安排出逃，也不是“没主见”。但他当前真正缺失的是合法安全的落脚地、藏身保护与对抗追捕的庇护接口，这些关键条件不在宋江自己手里。宋江先列出柴进、花荣、孔太公三处既有关系网络作为候选，随后与宋清商议后主动选择柴进；到庄后明确说明自己“无处安身，特来投奔”。最终能否藏身、获得庄院庇护、衣食与对官府追捕的保护，仍由柴进掌握并明确承诺。因此本段成立 **nx 关系功能高显影**，而不是稳定人物本体 nx。

最小结构：

```text
主体自己决定必须离开原地
+
主动筛选可投奔的人情网络
+
关键庇护、落脚地与保护权限并不归主体
→ 沿既有书信/声望/江湖关系接口进入柴进庄
→ 请求并获得柴进接纳
→ 沿他者掌握的庄院与保护能力继续生存
= nx 关系功能高显影
```

这直接支持：

```text
主动 ≠ 排除 nx
有主见 ≠ 排除 nx
会自己选目标 ≠ 关键解决通道一定属于自己
```

## 1｜原始事实

### 触发：杀惜后被追捕，原有生活接口失效

宋江杀阎婆惜后，知县最终被迫发海捕文书。朱仝到宋家庄搜索时暗中放走宋江，并明确提醒地窨子不能久藏。这里的压力是现实性的：

```text
官府追捕
+ 原居地不能长期安全停留
→ 当前稳定落脚与保护接口缺失
```

但“被追捕”本身不是 nx，只是触发因素。

### 宋江并非没有自己的判断

朱仝问宋江准备投哪里，宋江主动列出三个安身之处：柴进庄、花荣处、孔太公庄，并表示尚在权衡。随后他与宋清在路上继续讨论，最终决定投柴进。

因此这一段并不是：

```text
别人替宋江规定去哪里
→ 宋江只机械照办
```

相反，宋江有明确的选择与判断。

### 但关键庇护接口仍然外置

宋江和宋清选择柴进的理由，是柴进已有“仗义疏财、专一结识天下好汉、救助遭配的人”的声望，而且宋江与柴进此前常有书信往来。两人于是沿这个已经存在的江湖关系与声望通道前往柴庄。

到庄后，宋江直接说明自己“做出一件没出豁的事”，兄弟二人“无处安身”，所以“特来投奔”。

这个表述把变量说得很清楚：

```text
宋江能决定“我要去找谁”
但不能单方面决定“柴进必须收留我”
```

### 可观察结果

柴进明确接纳宋江，并表示即使犯下重罪，也敢把他藏在庄里；随后提供住宿、衣服、饮食和庄院保护。

所以实际改变的是：

```text
无稳定安全落脚
→ 进入已有江湖关系与声望接口
→ 柴进作出接纳决定
→ 获得庄院庇护、衣食与暂时保护
```

决定性的保护资源与许可在柴进一侧，符合现行 nx “权限和解决通道在他者手里，主体沿既有关系接口借力推进”的关系功能。

## 2｜为什么这是 nx 关系功能，而不是纯 nx 本体

纯 nx 本体要求人物长期不占最终方向，反复让别人决定路线。这个窄阶段并不支持这样判断宋江。

宋江实际上完成了多次主动判断：

- 认识到原地不能久留；
- 列出三个可投奔对象；
- 与宋清讨论后主动选择柴进；
- 到达柴庄并主动说明求庇护的原因。

因此必须分层：

```text
人物稳定本体：本轮不锁 nx
当前解决路径：nx 关系功能高显影
```

关键不在“他是否主动”，而在：**当前问题的关键资源、最终接纳许可与保护能力是否属于他自己。**

---

## 3｜为什么这里不优先判 zx

本段宋江很主动，也有江湖名望，但本轮核心结果并不是：

```text
宋江以自身权能公开压服柴进
→ 柴庄秩序被迫围绕宋江重新运行
→ 宋江扩大自己对柴庄的决定范围
```

实际是：

- 宋江主动前往求助；
- 他需要柴进接纳；
- 庄院、住宿、衣食、藏匿与对官军的保护能力都属于柴进；
- 柴进可以接受，也理论上可以拒绝；
- 宋江最终得到的是柴进提供的外部庇护条件。

所以：

```text
主动逃难 ≠ zx
有江湖名望 ≠ zx
自己选择求人对象 ≠ 解决通道由自己掌握
```

本轮最强变量仍是沿既有人情与声望网络取得外部庇护，因此优先 nx 关系功能。

## 4｜最近邻排除

### nx vs zx

`zx` 要求主体自身权能公开进入现实并扩大决定范围。本例的关键庇护决定、庄院资源与保护接口都在柴进手里，因此不优先 `zx`。

### nx vs xn

宋江确实比较了三个去处，并与宋清商议，但本段没有形成复杂排程、节点、流程或持续组织结构。最核心动作是进入已有江湖关系网络、请求别人提供庇护，因此优先 `nx`，而非 `xn`。

### nx vs x

柴庄、衣食、住宿与保护能力都不归宋江掌握，所以不是 `x`。

### nx vs xz

官府海捕与被抓风险构成高强度外部压力，`xz` 可以解释“为什么必须尽快离开”，但不能解释“为什么最终通过柴进的关系和权限通道获得保护”。危险是触发，nx 是当前解决路径。

## 5｜拿掉测试

### 拿掉“杀阎婆惜”这一具体原因

如果改成其他原因导致宋江急需安全落脚，只要仍然满足：

```text
自己没有可直接调用的安全庄院
→ 选择柴进这一既有关系接口
→ 必须由柴进决定是否接纳
→ 沿柴进提供的资源获得保护
```

nx 关系功能仍然成立。

因此“杀惜”是触发，不是 nx 本体。

### 拿掉“江湖名望/书信关系”

若宋江与柴进毫无已有书信、声望或江湖接口，只是随机敲门求住，本例“走既有关系网络”的纯度会明显下降，最多保留一般求助候选。

### 拿掉柴进的许可与资源所有权

如果庄院、保护、衣食本就归宋江自己处分，他无需柴进批准即可直接调用，那么本例 nx 会明显下降，优先检查 `x/zx/xn` 等其他端点。

## 6｜反向测试

### 反向A：zx 版本

```text
宋江直接占用柴庄
→ 以自身势力迫使柴进和庄客接受
→ 自己掌握并扩大对庄院与保护体系的决定权
```

这会显著提升 zx。

原作没有发生。

### 反向B：纯人物本体 nx 版本

```text
宋江自己完全没有去向判断
→ 别人指定他去柴进庄
→ 他长期都只等别人告诉他下一步去哪
```

这才更支持稳定人物本体 nx。

原作不满足。

### 反向C：xn 版本

```text
宋江制定多阶段逃亡计划
→ 分配人员、钱粮、时序、伪装、多个备用落脚点
→ 设置连续节点并主动维持运行
```

此时应优先检查 xn。

原作本段的主变量并不是这种运行结构。

## 7｜第三因素冻结

本轮冻结以下因素，不允许直接判十元：

- 宋江杀过人；
- 宋江被官府追捕；
- 宋江名气很大；
- 柴进崇拜或敬重宋江；
- 宋江此前当过押司；
- 柴进很有钱；
- 最后宋江成功住进柴庄；
- 宋江在全书其他阶段的领导身份。

真正支持 nx 的证据只有：

```text
关键安全落脚与保护资源在柴进手中
+
宋江承认自己“无处安身”
+
主动沿既有书信、声望和江湖关系接口去投奔
+
最终通过柴进的接纳取得庄院庇护
```

## 8｜木轴压力测试结果

```text
zx：局部人格气质与主动性不能代替“自身权能扩大”的必要条件，本段不锁。
nx：关系功能高显影，evidence-locked。
xn：仅有选择去处与简单商议，不足以成为主分类。
x：庇护资源不归宋江掌握，排除。
xz：高压触发存在，但不替代当前解决通道分类。
```

本轮最小结论：

> **一个人物完全可以主动、有主见、自己选择求助对象，同时仍然出现高纯度 nx 关系功能；判断关键不是“他积极不积极”，而是关键资源、最终许可与解决通道是否仍然外置，以及主体是否必须沿既有关系网络进入。**

## 9｜跨作品复验：达到待审议门槛

此前已有两个独立作品支持同型边界：

```text
《红楼梦》刘姥姥：
主动决定进荣国府求助
→ 钱财与进入许可在荣府
→ 沿周瑞家的、平儿、王熙凤这一既有权限关系链推进
→ nx 关系功能

《三国演义》刘备：
本人长期政治方向明确
→ 荆州驻留与保护许可在刘表
→ 沿汉室宗亲、孙乾说项这一既有政治关系接口请求接纳
→ nx 关系功能
```

本轮加入：

```text
《水浒传》宋江：
主动决定逃离并自己选择柴进
→ 庄院、藏匿、衣食与对官府追捕的保护接口在柴进
→ 沿书信、名望和江湖关系网络投奔
→ nx 关系功能
```

因此同一边界已跨 3 部独立作品稳定复现。

### 待审议问题｜pending

建议后续审议 `nx` 准度卡时，把以下边界句作为候选强化项，而非立即改核心定义：

```text
“主动、有主见、长期方向明确”不能单独排除 nx 关系功能。
必须继续检查具体问题中的关键资源、最终许可或解决通道是否仍在他者手里。
若主体主动选择进入已有关系、身份、声望或权限网络，并依赖他者掌握的接口取得帮助，则这一段仍可成立 nx 关系功能。
```

当前只形成 `pending` 待审议问题，不修改 L1、zx/nx 信息卡或准度卡。
