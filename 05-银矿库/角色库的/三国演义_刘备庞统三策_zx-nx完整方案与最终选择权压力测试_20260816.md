# 范围
仅截取《三国演义》第六十二回中：刘备与刘璋关系破裂后向庞统问策，庞统提出上、中、下三条完整战略方案，刘备明确比较并选择中策，随后按中策推进的阶段。

不得把本段倒推为刘备稳定人物本体 nx；也不得把“刘备是主公、有最终选择权”直接反推为 zx。

# 剧情事实
1. 刘璋只给刘备老弱军四千、米一万斛后，刘备毁书发怒，与刘璋原有合作关系实质破裂。
2. 庞统指出刘备此前的仁义姿态已难继续维持，刘备随即询问“如此，当若何”。
3. 庞统明确提出三条可执行方案，并让刘备“自择而行”：
   - 上策：选精兵昼夜兼程，直袭成都；
   - 中策：佯称回荆州，引杨怀、高沛来送，擒杀二将、夺涪关，再进成都；
   - 下策：退白帝、回荆州，徐图进取。
4. 刘备没有机械接受庞统的第一建议，而是明确评价上策太急、下策太缓，选择中策。
5. 随后刘备写信佯称回荆州，并按中策推进；杨怀、高沛果然来送，之后被擒杀，涪关被夺。
6. 在后续执行中，庞统仍继续提供具体警戒、判断与组织建议，但“上中下三策究竟采用哪一条”的最终选择由刘备本人作出。

# 木轴候选判定

## zx｜本窄阶段不作为主判
刘备有最终选择权、会比较方案、最后也按选定路线行动，但这些事实不足以成立 zx。

本段没有出现：
- 刘备取得此前不存在的更高战略处分范围；
- 庞统或军中秩序因为刘备新增权能而被迫重新排列；
- 刘备从原本无权决定的人上升为新的现实决定中心。

刘备本来就是本集团最高战略批准者。选择中策更接近既有决定权的使用，而不是公开扩权。

因此：
- “有最终选择权” ≠ zx；
- “选择成功方案并获胜” ≠ zx；
- zx 在本窄阶段 rejected_as_primary。

## nx｜关系功能存在真实分叉，暂不正式锁定
支持 nx 的证据：
- 刘备遭遇战略难题后明确向庞统问策；
- 三条可执行解决方案均由庞统生成；
- 刘备最终实际沿庞统提供的中策推进；
- 拿掉庞统这一外部专业解决节点，刘备在文本中失去现成的三方案结构与后续具体推进方案。

反对直接锁 nx 的证据：
- 庞统不是唯一给出一个“必须沿用”的方案，而是明确把三策交给刘备“自择”；
- 刘备拥有真实、低成本的否决与选择资格；
- 刘备实际拒绝上策与下策，选择中策；
- 在“最终采用哪条战略”这一对象层，最终方向资格仍在刘备；
- 现行 nx 核心口径强调主体“不占最终决定位置”，而本段刘备恰恰占据最终选择位。

因此当前最小分歧为：

> 当外部专家提供多个完整、可执行的解决方案，而主体拥有并实际使用低成本否决/最终选择权，但没有自行重设计所选方案时，这是否仍足以成立 nx 的“外部解决通道”关系功能？

现行正本尚不足以把这一边界压到 ≥95%，故保留 candidate/deferred。

# 与弥勒—黄眉正式 nx 锚的最小差异

## 孙悟空遇弥勒
- 弥勒提供完整方案；
- 提供关键“禁”字法术；
- 掌握宝物处分权；
- 掌握黄眉主仆关系中的最终收伏接口；
- 孙悟空主要沿单一完整解决链执行；
- 该案例已正式锁 nx 关系功能。

## 刘备听庞统三策
- 庞统提供多个完整方案；
- 没有掌握刘备军队的最终战略批准权；
- 刘备可真实拒绝任一方案；
- 刘备实际比较并选择中策；
- 庞统掌握专业方案生成，但最终战略选择仍在刘备。

所以不能仅凭“外部给完整方案”就机械复制弥勒案例结论。

# 最近邻排除

## nx vs xn
三套战略方案及其中的欺敌、擒将、夺关等组织结构，主要由庞统设计，因此这一层的 xn 方案设计应归庞统，不能偷算给刘备。

刘备本段的核心动作是比较、否决与选择，而不是自己从零搭建完整流程。

## nx vs x
刘备本来就拥有本集团战略批准权，因此“最终选择归刘备”更接近已有决定权限的 x 邻近，而不是新获得权限。

但本轮不把刘备稳定 x 本体锁定，只用它排除“选择本身就是 zx”。

## zx vs x
如果刘备只是正常使用已有战略批准权，就是 x 邻近；只有把决定范围从原边界继续公开推大，才检查 zx。本段无新增扩权硬证据。

# 拿掉测试

## 拿掉庞统
拿掉庞统及其三策，刘备仍保有“是否继续取川”的领导决定资格，但失去文本中现成的三套专业方案与中策执行结构。

说明庞统确实补足“方案生成缺口”，但这还不能自动证明刘备把最终方向交给了庞统。

## 拿掉刘备的最终选择权
如果改成庞统只给一条方案，刘备没有真实否决窗口、主要照方案执行，则 nx 会显著上升，接近“弥勒给完整方案”的高纯关系功能。

## 拿掉上策、下策，只保留中策
如果文本只剩庞统直接给中策、刘备照做，那么现有“低成本真实否决/选择”证据明显变弱，nx 置信会提升。

# 反向测试

## 反向为更高纯 nx
外部专家不仅生成完整方案，而且主体不占最终重设位，或没有真实低成本否决窗口，只能沿该方案推进。

## 反向为 xn
专家只提供目标/若干事实，主体自己重新设计战略、节点和运行方式，则应转查 xn。

## 反向为 zx
主体借事件取得此前没有的更高战略处分范围，并迫使组织围绕其新增决定接口运行，才锁 zx。

# 第三因素冻结
冻结以下因素后，结论不变：
- 刘备“仁义”人物主题；
- 庞统“凤雏”智谋评价；
- 后续是否成功取川；
- 杨怀、高沛被杀这一激烈结果；
- 刘备主公身份的价值评价；
- 庞统是否比刘备更聪明。

只保留：
1. 谁生成完整方案；
2. 谁拥有最终否决/选择资格；
3. 主体是否实际使用否决资格；
4. 选中方案后是否主要沿外部方案执行；
5. 是否发生决定范围新增。

# 分层结论
- 稳定人物本体：不锁。
- 刘备当前 zx：本窄阶段不作为主判。
- 刘备纯 nx：排除。
- 刘备 nx 关系功能：candidate，存在真实边界分叉。
- 庞统 xn 方案设计：最近邻高显影，但不作为刘备木轴主判。
- 严格 zx↔nx 补关系：不锁。

# 结论状态
事实置信 99%。
分类置信 94%。

因“外部完整方案”与“主体保留最终选择权”同时成立，且现行 nx 对“最终决定位置”的要求与“外部解决通道”关系功能在此产生真实张力，本轮不得升为 evidence-locked。

正式状态：candidate/deferred。

# 治理结论
1. 不修改 L1 十元—五行正本。
2. 不修改 zx/nx 信息卡。
3. 不修改 zx/nx 准度卡。
4. 不修改 zx补nx_补卡。
5. 不新增待审议问题；本例先作为现有“nx外部信息源与解决通道边界”之后的进一步边界候选。
6. 后续优先跨作品寻找：外部专家给多个完整方案，主体保留真实最终选择权；以及外部给完整方案后主体大幅重设计的反向样本。

# 一句话压缩

> 外部专家给出完整方案，并不自动等于主体把最终方向交给外部；当主体拥有并实际使用真实否决/选择权时，是否仍构成 nx 关系功能，需要继续把“方案来源”与“最终决定位置”拆开验证。
