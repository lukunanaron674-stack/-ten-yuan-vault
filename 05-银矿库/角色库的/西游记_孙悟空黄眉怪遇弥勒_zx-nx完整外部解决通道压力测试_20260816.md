# 范围
仅截取《西游记》第六十六回中：孙悟空多次外援失败、弥勒现身说明黄眉身份与宝物归属，随后给出完整诱敌方案并最终亲自收伏黄眉怪这一段。不得把本桥段倒推为孙悟空稳定人物本体 nx；孙悟空原有 zx+nx 人物锚保持不变。

# 剧情事实
1. 孙悟空此前已多次请来外援，但黄眉的人种袋持续压制外援，孙悟空陷入“百计千方难救”的困境。
2. 弥勒主动现身，明确黄眉是自己面前的黄眉童儿，并说明人种袋、敲磬槌等关键宝物原本属于自己。
3. 弥勒没有只提供“黄眉是谁”这一事实，而是直接设计完整可执行方案：自己在山坡设瓜田；孙悟空诱敌；交战时许败不许胜；孙悟空变熟瓜；弥勒把熟瓜交给黄眉吃；孙悟空入腹折腾；弥勒趁机取走人种袋并收妖。
4. 弥勒还在孙悟空掌上写“禁”字，解决“黄眉会使用人种袋、不肯跟来”的关键执行障碍。
5. 孙悟空明确“欣然领教”，随后依此方案实施：单独叫战、放开“禁”字、诈败、把黄眉引到瓜田、变成熟瓜、入腹折腾。
6. 黄眉受制后向弥勒称“主人公”求饶；弥勒亲自取走后天袋与敲磬槌，并要求孙悟空饶命；最后黄眉被弥勒装入袋中带走。
7. 因而，弥勒不仅提供情报，还同时掌握完整方案、关键法术、宝物处分权、主仆关系中的最终收伏接口；孙悟空在本段主要沿这一外部解决通道执行。

# 木轴判定

## nx｜关系功能锁定
本桥段锁定 nx 的不是“孙悟空没主见”，而是决定性解决通道真实外置。

孙悟空自己的最高目标始终存在：救唐僧、制服黄眉、继续取经。他没有把“要不要救师父”交给弥勒决定，因此纯 nx 本体不成立。

但在“怎样稳定破解黄眉的人种袋并完成最终收伏”这一对象层：
- 关键宝物属于弥勒；
- 黄眉与弥勒存在直接主仆处分关系；
- 完整诱敌方案由弥勒设计；
- 关键“禁”字法术由弥勒提供；
- 最终收伏、取回宝物与带走黄眉也由弥勒完成；
- 孙悟空主要沿弥勒给出的步骤执行。

因此符合现行 nx 关系功能：主体有自己的目标，但关键解决方案、权限与不可替代接口在外部，只能沿该外部通道推进。

## zx｜本窄阶段不作为主判
孙悟空在黄眉腹内拳脚折腾、主动诱敌和执行计划，均使用了自身已有能力，但本阶段没有证据表明他因此取得了新的最终收伏权限、宝物处分权或更高决定范围。

黄眉真正停止抵抗、交还宝物并被带走，是因为弥勒这个原权属与主仆接口重新进入现实。孙悟空并未把“谁有权最终收伏黄眉”这一接口变成自己的。

所以：
- zx 行为外观存在；
- zx 当前扩权不锁；
- 不得用“悟空很能打、能钻肚子、最后赢了”直接判 zx。

# 与“外部信息源”待审议边界的最小差异

## 狮驼岭长庚候选
长庚只提供妖魔危险事实；孙悟空随后自行决定侦察、变化、接近与盘问小钻风。那里“信息来自外部”是否足以构成有限 nx 关系功能存在真实分叉，因此为 candidate/deferred。

## 黄眉怪弥勒本例
弥勒提供的不只是事实，而是：
1. 妖怪身份与宝物归属；
2. 一整套必须沿用的诱敌方案；
3. 关键法术；
4. 不可替代的宝物与主仆处分接口；
5. 最终收伏动作。

因此本例达到高纯 nx 关系功能门槛，可作为“外部信息源 vs 外部解决通道”待审议问题的反向正锚。

# 最近邻排除

## nx vs xn
方案的关键节点不是孙悟空自己搭出来的，而由弥勒明确设计：诱敌、许败不许胜、引到瓜田、变熟瓜、被吃、腹内折腾、弥勒夺袋收妖。

孙悟空确有执行层机动，但不能把弥勒的流程设计归给孙悟空判 xn 主显影。

## nx vs x
人种袋、敲磬槌与黄眉童儿的处分关系均不属于孙悟空稳定掌握。孙悟空无法独立调用这些资源和主仆权限，因此不是 x。

## nx vs zx
孙悟空没有通过自身权能取得最终收伏权；真正决定性接口仍在弥勒。自身强力执行不能替代“权限是否转移”的检查。

## nx vs nz
弥勒与黄眉的主仆关系在本轮是处分与解决接口，不是关系本身成为停靠、回返或情感目标，因此不以 nz 为主解释。

# 拿掉测试
1. 拿掉“弥勒告诉黄眉身份”这一条信息，但保留完整诱敌方案、禁字法术与最终收伏接口，nx 关系功能仍成立。说明本例不是靠“外部信息输入”锁 nx。
2. 拿掉弥勒的完整方案，只保留“黄眉是我的童儿、人种袋是我的”这一事实，孙悟空仍缺乏稳定可执行破解路径；本例会退回更接近“外部信息/归属事实输入”的边界，nx 解决通道证据显著下降。
3. 拿掉弥勒对人种袋、黄眉的最终处分接口，即便保留若干战术提示，最终稳定收伏链也不再完整，nx 的不可替代外部接口证据下降。
4. 拿掉孙悟空自身执行能力，弥勒方案难以按原步骤落地；这只能证明执行端重要，不足以把孙悟空本段升级为 zx，也不足以锁严格 zx补nx。

# 反向测试
1. 若弥勒只说“黄眉是我的童儿、人种袋是我的”，随后孙悟空自己设计诱敌、破解宝物并独立完成收伏，则应向“外部信息输入 + 孙悟空 xn/x”移动，nx 解决通道下降。
2. 若孙悟空本来就掌握人种袋处分权与黄眉最终处置权，只是在使用自己已有资源，应优先检查 x/xn，而不是 nx。
3. 若孙悟空通过自身公开权能夺取原本属于弥勒的最终收伏与处分接口，并让现实围绕自己的新增决定权重排，才应提高 zx。

# 第三因素冻结
冻结孙悟空武力、齐天大圣身份、弥勒佛祖身份、黄眉强弱、法宝神奇程度、最终胜负、取经主题与喜剧性，只保留：谁拥有解决方案、谁设计节点、谁提供关键法术、谁拥有宝物/主仆处分权、谁完成最终收伏。结论仍为 nx 关系功能高显影。

# 分层结论
- 人物稳定本体：不锁。
- 当前状态：孙悟空处在外部完整解决通道中。
- 行为功能：按弥勒方案诱敌、诈败、变瓜、入腹执行。
- 关系位置：最终解决方案、关键权限与收伏接口在弥勒一侧。
- 外部压力：此前多次外援被人种袋压制，自身路径无法稳定闭环。

# 治理结论
- 本轮事实置信 99，分类置信 98，达到正式案例门槛。
- 正式锁定 nx 关系功能，不锁孙悟空稳定人物本体。
- 本例作为“外部信息源 vs 外部解决通道”待审议问题的反向高纯正锚。
- 不修改 L1、zx/nx 信息卡、zx/nx 准度卡或 zx补nx_补卡。
- 不锁严格 zx↔nx 补关系：本轮虽有孙悟空执行与弥勒通道协作，但孙悟空的 zx 端在此窄阶段未独立达到扩权门槛。
