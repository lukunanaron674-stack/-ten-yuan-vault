# 《西游记》猪八戒平顶山巡山｜口头承接与实际不续接压力测试

## 结论先行

本轮锁定：

> **口头说“我去”、形式上接受任务、甚至已经离开队伍进入执行路径，都不能单独锁 nx。木轴仍要追到真正执行窗口：主体是否实际沿外部方向把任务推进。**
>
> 猪八戒在平顶山明确接受“巡山、打听妖怪与山洞信息”的任务，也确实拿钯进山；但走出一段后，他主动决定不巡山，转而睡觉，并计划回去含糊谎称已经巡过。于是“接受任务”与“实际续接方向”发生分离。截在第一次偷懒被悟空揭穿前，实际执行层不能以 nx 为主判。
>
> 同时，这也不是 zx：八戒没有因此取得新的队伍决定范围，没有让唐僧、悟空或取经秩序围绕一个新增的八戒权能接口运行。他只是逃避任务并试图伪造完成外观。

本轮不锁猪八戒稳定人物本体，不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实

### 触发

平顶山前，孙悟空判断山中可能有妖怪，需要有人深入山中查明：

- 有多少妖怪；
- 是什么山；
- 是什么洞；
- 以便取经队伍判断如何通过。

孙悟空给八戒“看师父”或“巡山”两个任务选项。八戒比较后选择巡山，并明确表示这个任务较容易，随后持钯进山。

因此前段确实存在：

```text
外部给任务方向
→ 八戒自行选择其中一项
→ 口头承接
→ 实际进入山中
```

### 真正执行窗口

八戒走出七八里后，却主动停下，把钉钯放下，抱怨取经队伍让自己辛苦巡山，并明确形成替代方案：

```text
不继续巡山
→ 找地方睡觉
→ 睡够后回去
→ 含糊说“巡过了”
→ 以谎报完成外部任务
```

他随后真的找到草坡睡下。

孙悟空暗中跟随，听到其计划并把他弄醒；八戒起初还试图编造一套假的山、洞、妖怪信息，被悟空识破。

因此不能把前面的“我去巡山”当作终点证据。

### 后续切段

悟空揭穿后，在惩罚压力下要求八戒重新巡山；八戒第二次出发，后来真正遇到银角一方并被擒。

这属于新的阶段：

```text
第一次：口头承接 → 主动不执行 → 准备伪造结果
第二次：被揭穿/加压后 → 重新巡山 → 实际进入任务路径
```

本轮只锁第一次偷懒阶段，不把第二次的实际巡山倒灌回来覆盖第一次。

## 2｜nx 判断

### 口头承接存在，但不是决定性证据

可以记录：

`nx_verbal_acceptance_behavior: present_but_not_decisive`

因为：

- 任务方向来自悟空；
- 八戒没有自己创造“巡山”这个目标；
- 他口头接受并进入山路。

但这些只说明**承接入口**，不能证明实际执行层继续沿外部方向。

### 实际执行层：nx 排除

真正要判的对象是：

> **八戒是否在第一次出发后，实际把“巡山、取得敌情”这个外部方向继续推进。**

答案是否定的。

他主动选择睡觉，并准备以虚假报告替代真实任务结果。因此锁：

`nx_in_actual_execution_layer: rejected`

案例纪律：

> **口头服从 ≠ 方向续接。进入流程 ≠ 结果层仍然让出否决位置。**

## 3｜zx 判断

### 不执行任务也不等于 zx

八戒确实把外部任务“停掉”了，但现行 zx 要求：

```text
主体自身权能公开进入现实
→ 他者/秩序围绕主体重新反应
→ 主体决定范围、影响位置或凌驾程度上升
```

第一次巡山偷懒阶段没有：

- 八戒取得取经队伍新的任务分配权；
- 悟空失去任务组织位置；
- 唐僧团队承认“以后巡不巡由八戒最终决定”；
- 八戒的公开决定范围扩大。

他反而必须隐藏真实行为并准备用谎报掩盖。

因此锁：

`zx_in_narrow_stage: rejected_as_primary`

> **违命、偷懒、绕开任务、成功骗一时，都不等于 zx 扩权。**

## 4｜最近邻排除

### xn

八戒形成了一个很小的规避方案：睡觉、拖时间、回去编谎。这具有简单的策略/节点组织外观，因此记录：

`xn_evasion_strategy_neighbor: present`

但它解释的是“怎样逃避任务”，不能替木轴回答“是否沿外部任务方向继续”。

### x

八戒没有稳定掌握“是否需要巡山”这一队伍任务决定权，因此不能以 x 解释其停工。

### nz

师兄弟关系、被针对感受可以解释八戒为什么抱怨，但不能替木轴判定其实际执行方向。

### xz

妖怪风险、被悟空惩罚的风险属于压力变量。尤其第一次偷懒发生在真正遇妖之前，因此不能用“被强迫/太危险”替他的不续接自动找 nx 或 zx。

## 5｜拿掉测试

### 拿掉八戒“懒惰”人物标签

只保留：

```text
接受巡山任务
→ 进入山中
→ 主动停止执行
→ 准备伪造完成结果
```

`nx` 实际执行层仍然排除。

### 拿掉“睡觉”这个具体动作

即便改成躲在安全处消磨时间，只要主体仍不获取敌情并准备谎报，结论不变。

### 拿掉悟空暗中跟踪

只要八戒自己的明确计划仍成立，第一次巡山阶段仍不是实际 nx 续接；悟空跟踪只是让证据被文本直接展示。

### 拿掉后续第二次真巡山

第一次阶段结论不变。不能因为后来被抓回任务路径，就倒推第一次其实一直在续接。

## 6｜反向测试

### 反向成真 nx

八戒选择巡山后，虽然心里抱怨、害怕妖怪，但仍继续深入山中，真实搜集山名、洞名、妖怪数量，并把信息带回队伍。

则可形成：

```text
外部给任务方向
+ 主体不喜欢
+ 实际仍把任务做成
= nx 当前行为功能明显上升
```

### 反向成 zx

八戒不只是拒绝巡山，而是公开取得新的队伍任务决定权，使悟空、唐僧以后必须围绕他的新增权限重排“谁巡山、是否巡山”。原文完全没有。

## 7｜第三因素冻结

本轮不从以下因素直接判十元：

- 八戒懒惰、贪睡、怕妖怪的性格标签；
- 孙悟空是否故意捉弄八戒；
- 唐僧偏袒谁；
- 后续八戒是否被银角抓住；
- 猪八戒战斗强弱；
- 喜剧效果。

冻结后仍剩：

```text
外部任务明确
→ 主体口头承接
→ 实际执行窗口主动不续接
→ 准备伪造结果
```

足以支持本轮分类。

## 8｜跨作品最小差异

### 《三国演义》关羽华容道

外部军令明确，关羽也领令并立军令状；但真正执行窗口出现时实际放走曹操。

结论：最终执行层 `nx` 排除。

### 《水浒传》朱仝私放雷横

接受押解任务并进入司法押解流程；但关键结果窗口主动开枷放人。

结论：最终结果层 `nx` 排除。

### 本轮《西游记》猪八戒巡山

口头接受巡山并实际进山；但第一次执行阶段主动停止任务并准备谎报完成。

结论：实际执行层 `nx` 排除。

三部作品共同指向：

> **“接受外部方向”只能证明入口层。要锁 nx 行为功能，必须继续检查主体在真正执行/结果窗口是否仍把该外部方向实际做成。**
