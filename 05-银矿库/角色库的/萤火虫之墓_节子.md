# 节子（Setsuko）
> 归档：`05-银矿库/角色库/萤火虫之墓_节子.md`

---

## 1. 主十元判断

**主十元：x（阴水·活下去压倒一切/孩子的本能）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉x，节子就是一个聪明的小女孩——会说、会笑、会记住妈妈的样子。但节子最核心的不是"可爱"或"纯真"，是**她在最脆弱的状态下用最原始的方式求生**。她不知道战争的含义、不知道死亡、不知道贫穷——她只知道"我饿"、"我疼"、"我怕"。
- **第2问（反复面对什么结构）：** 反复面对「没有了」。妈妈没有了、糖果没有了、吃的越来越少了、最后连力气都没有了。她的世界在一点点消失，她每次都在问："那个东西去哪了"。
- **第3问（最怕失去什么）：** 最怕「哥哥也不见了」。妈妈走了、爸爸不在、阿姨不友善——哥哥是她唯一的锚。在她半睡半醒的弥留之际，她喊的不是妈妈，是"哥哥"。
- **第4问（回到哪个感觉）：** 回到「妈妈给糖果、一切还好好的」那一天。她捡弹珠当糖果的戏，就是在复刻那个感觉——即使陨石也当糖含在嘴里。
- **第5问（副十元服务谁）：** nz（希望那个人也在）是x的容器——她在等爸爸回来、等哥哥回来。孩子用"等待"来对抗消失的世界。

## 2. 副十元

**副十元：nz（阴金·希望那个人也在）**

**作用：** "爸爸回来就有好吃的了"、"哥哥去拿钱就回来了"、"妈妈也会回来的"——这些是x（求生本能）在上面搭建的希望结构。孩子没有行动能力，她用等待来活下去。

## 3. 功能十元

**功能十元：z（阴火·想被看见/被关注）——表层。** 她用笑容、懂事、甚至疼痛来让哥哥关注她——"哥哥你看"、"哥哥你摸摸"。孩子需要被看见才能确认自己还活着。

## 4. 视觉十元

**视觉十元：x（阴水·透明/纯真）。** 她不需要伪装——她是最脆弱状态下的生命。苍蝇在脸上爬、瘦得皮包骨、最后在医院吐出的最后一口气——没有任何包装。

## 5. 动态链

```
x（主·要活下去/最原始的生存本能）
  → nz（副·等那个人回来/用等待对抗消失）
  → z（功能·被哥哥看见才能确认存在）
  → 从家到山洞→食物越来越少→身体越来越弱→萤火虫的光
  → 死前最后一句：谢谢哥哥
  → x的回答：我已经不疼了
```

## 6. 一句话定型

节子不是「战争中的无辜牺牲品」，也不是「纯真的象征」，而是「**在最脆弱的状态下用本能活下去**」的孩子。

---

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**修正1：** x（主）+ nz（副）→ 时间型
**最终定位：** x（主·生存压倒一切/孩子的本能）+ nz（副·希望那个人也在/用等待活着）→ 时间型
**最终修正理由：** 原卡xz暗示节子有"被推着走"的能动性，但一个4岁的孩子没有"被推"的能力——她是在原地被世界抽离。x才是她的底色：饿就要吃、怕就要哭、疼就要喊，这些是超越一切的价值判断的本能。nz是孩子面对消失之物的自然反应——"他还会回来的"。
