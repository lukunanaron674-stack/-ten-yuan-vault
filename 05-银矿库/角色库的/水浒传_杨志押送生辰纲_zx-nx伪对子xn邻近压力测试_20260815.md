# 《水浒传》杨志押送生辰纲｜zx-nx 伪对子 / xn 最近邻压力测试

## 1｜本轮问题

同样是“上级给出目标”，主体究竟属于 nx，还是接到目标后主动重组运行方式而更接近 xn？同时排除“能指挥别人 = zx”的误判。

本轮只判断《水浒传》第十六回中杨志接下押送生辰纲任务后，重设运输、人员、时间与行程方案这一明确阶段，不外推杨志整个人物稳定本体。

## 2｜剧情事实

### 触发

梁中书准备把生辰纲送往东京，原先提出以太平车、军健护送的公开运输方式，并把押运任务交给杨志。

### 对象

- 外部目标：把生辰纲安全送到东京。
- 关键运行对象：运输形式、人员配置、行军时段、沿途停歇与指挥接口。

### 杨志的明确动作

1. 杨志并未照收原始运输方案，而是明确指出公开车运与增派军校并不能解决风险。
2. 他提出把礼物改装成十余条担子，众人扮作客商与脚夫，减少显眼程度并秘密押送。
3. 当梁中书又加入谢都管和两个虞候时，杨志再次提出：若这些人不受自己提调，任务就无法可靠执行。
4. 梁中书因此当面授权众人一路早行晚行、住歇皆听杨志安排。
5. 真正上路后，杨志根据地段风险主动改变行军时段：安全地段趁早凉行，进入强人出没地带后改为辰牌起身、申时休息，并持续催促队伍按照他的风险判断行动。

### 结果

杨志没有改写“必须把生辰纲送到东京”这一上级目标，但显著重组了该目标的实际运行方式、人员服从关系与时间节点。最终任务失败不能反推前述结构不存在；胜负不是本轮十元判据。

## 3｜zx / nx / xn 候选判断

### nx：rejected（本阶段不锁）

表面诱因是：

- 任务来自梁中书；
- 杨志仍服务于外部既定目标；
- 他没有取消押送任务。

但现行 nx 准度卡明确区分：

> 老板给目标，员工主动排程、搭流程、分配资源、预判节点，优先检查 xn，而不是因为“目标来自老板”直接判 nx。

杨志在本阶段没有单纯沿原方案续接，而是主动否决旧运行方式、提出替代结构并占据运行重设位置。因此“外部目标 = nx”在此不成立。

### zx：rejected（本阶段不锁）

杨志确实公开指挥军健、改变行军方式，也会强制执行自己的安排，但这些权力来自梁中书为完成既定押运任务而授予的执行接口。

本阶段没有证据显示：

- 杨志把自身权能扩大到押送任务之外；
- 梁中书或更高秩序必须围绕杨志个人力量重新排列；
- 杨志的决定范围、等级位置或凌驾程度因此上升。

所以“会命令别人、执行强硬”不足以成立 zx。

### xn：最近邻高显影

本阶段真正稳定的变量是：

```text
外部给出最终目标
→ 主体否掉原运行方案
→ 主动设计隐蔽运输方式
→ 重设人员服从接口
→ 根据路段风险重排时间节点
→ 持续组织运行
```

这更符合 xn 的流程、计划、节点与运行组织，而不是 nx 的沿既有方向与通道续接。

## 4｜拿掉测试

### 拿掉“梁中书是上级”

只保留“别人给出必须完成的总目标”，如果杨志仍主动否掉旧方案、搭建新运输结构并重排时间节点，则 nx 仍不能因外部目标自动成立，xn 最近邻仍保留。

### 拿掉“杨志很强硬、会打骂军健”

只保留“改车运为挑担伪装、缩减人员、要求统一提调、按风险重排行程”，本阶段依旧不是纯 nx；同时也更清楚地排除了把强势气质误写成 zx。

### 拿掉最终失败结果

即使生辰纲最终成功送达，结构判断也不变：成功与失败都不能决定 zx/nx。

## 5｜反向测试

### 反向成 nx

若梁中书不仅给出“送到东京”的目标，也给定运输形式、人员配置、每日行程与停歇节点，杨志只按既有方案执行，不提出替代结构，也不占重设位置，则 nx 行为明显上升。

### 反向成 zx

若杨志不仅组织押运，而是借此公开夺取更高决定权，使梁府、军政层级或他者必须围绕他的个人权能重新排列，并扩大自己原本没有的决定范围，则才应提高 zx。

## 6｜最近邻排除

### nx vs xn

本轮最关键边界：

```text
外部给目标 + 我照已有路线继续 = nx候选
外部给目标 + 我主动重设运行方式、时间与节点 = xn优先
```

杨志属于后者。

### zx vs x

杨志在押运途中获得具体处分与提调接口，不等于这些权限长期归他所有；因此不能直接锁 x，更不能由“有临时授权”升级为 zx。

### zx vs xz

盗贼风险、危险路段和酷热都是外部压力，会解释为什么杨志改变时段，但它们不能替代对“谁组织流程”的判断。冻结风险语义后，杨志主动重排运行方式仍然存在。

### nx vs n

杨志承担押送任务，不等于形成 n 的承载结构；本轮只讨论方向、权限和运行组织。

## 7｜第三因素冻结

冻结以下因素：

- 青面兽身份；
- 武艺强弱；
- 对军健的粗暴态度；
- 最终生辰纲被劫；
- 梁中书赏识；
- 官职与个人命运主题。

只保留：

```text
谁给最终目标？
谁能否决原运行方案？
谁重设运输方式？
谁重排人员与时间节点？
是否沿既有通道照做？
是否扩大了主体原有决定范围？
```

结论仍为：本阶段伪 nx、伪 zx，xn 最近邻高显影。

## 8｜人物本体 / 状态 / 行为 / 关系分层

- 稳定人物本体：不锁。
- 当前状态：主动承担既定任务后重组运行结构。
- 行为功能：计划、排程、重设流程与节点，偏 xn。
- 关系位置：最终任务目标仍来自梁中书，但运行接口由杨志主动争取并组织。
- 外部压力：盗贼风险、路线危险与酷热推动他调整方案，但不等于 nx 或 zx 本身。

> “最终目标来自别人”不是 nx 的充分条件。若主体接到外部目标后主动否决旧方案、搭建新的流程和节点，应优先检查 xn。

> “拥有临时指挥权、能强硬命令别人”也不是 zx 的充分条件。若权限只是为执行既定任务而被授予，且主体没有扩大决定范围，应排除 zx。

## 10｜与黄忠定军山样本的最小差异

黄忠定军山：法正观察、法正掌握红白旗启动节点，黄忠等别人给信号再行动，因此该战术接口锁 nx 当前行为。

杨志押送生辰纲：梁中书只给最终押运目标，杨志自己否决旧运行方式、重设人员与时间节点，因此不是同型 nx，而更接近 xn。

这组对照直接加强：

```text
等别人给节点 → nx可成立
自己设计节点 → xn优先
```
