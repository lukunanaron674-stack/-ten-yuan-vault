# 《三国演义》刘备拒取荆州｜zx-nx 木轴中间区反例

## 0｜结论先行

本桥段不能因为刘备在强敌压境前仍坚持自己的伦理判断，就把“有主见、敢否决”直接判成 `zx`；也不能因为诸葛亮已经提出明确可行的行动方向，就把刘备视为沿军师既定路线续接的 `nx`。

最窄结论：

```text
外部给出高价值、现实可行的替代方向：趁刘表病危取荆州
→ 刘备拥有真实否决窗口
→ 明确拒绝该方向
→ 最终方向资格仍由刘备保留
→ nx 不成立

同时
→ 刘备只是守住自己的取舍边界
→ 没有因此公开扩大自身权能
→ 没有让荆州、刘表集团或曹军秩序围绕其力量重排
→ zx 不成立
```

因此本例锁定为 **伪 zx+nx 反例 / 木轴中间区**，只锁当前桥段，不锁刘备稳定人物本体。

本例与《西游记》唐僧女儿国、《水浒传》鲁智深拒官构成第三个独立作品同型证据，达到“跨至少3个独立作品形成待审议问题”的触发阈值；但本文件不修改 L1、信息卡、准度卡或补卡。

## 1｜剧情事实

来源：罗贯中《三国演义》120回本第四十回。维基文库可核对。

### 触发

曹操大军将南下，刘备所据新野难以久守。诸葛亮明确建议：刘表病危，可趁此机会取荆州作为安身与拒曹之地。

### 对象

- 刘备；
- 诸葛亮；
- 刘表与荆州；
- 曹军南下的外部军事压力；
- “取荆州拒曹”这一现实可行替代路线。

### 明确动作

1. 诸葛亮指出新野不可久居，并提出趁刘表病危取荆州；
2. 刘备先承认方案在军事上“甚善”；
3. 但以受刘表之恩、不忍图取荆州为由拒绝；
4. 诸葛亮再次指出若不取将后悔；
5. 刘备仍明确表示宁死也不做负义之事，未采用该路线。

### 结果

- “取荆州”不是模糊意见，而是面向曹军压力的明确、高收益、现实替代方向；
- 刘备没有把最终取舍权交给诸葛亮；
- 他实际否决了军师提出的方向；
- 同时没有因为这一拒绝获得更高公开权能，也没有扩张自己的现实决定范围。

## 2｜四类候选判断

### 2.1 纯 zx：rejected

刘备此段有明确意志并敢于否决，但现行 `zx` 要求自身权能公开进入现实、迫使他者或秩序重排，并扩大决定范围。

本段缺少这些端点：

- 刘备没有夺取荆州；
- 没有取得新的公开决定接口；
- 没有让刘表集团、荆州秩序或曹军围绕自己的扩张权能重新排列；
- 其动作只是拒绝一种扩张方案、守住自己的选择边界。

因此：

```text
有主见 + 坚持伦理选择
≠ 公开显权与扩权
≠ zx
```

### 2.2 纯 nx：rejected

诸葛亮已经给出清晰路线，但刘备没有沿军师方向执行。

关键事实：

- 他能听懂并承认方案效用；
- 他拥有现实否决窗口；
- 他没有等待诸葛亮替自己决定；
- 在诸葛亮二次施压后仍不采用该路线。

因此：

```text
接受建议输入
≠ 把最终方向交给建议者
≠ nx
```

### 2.3 zx+nx：rejected

本桥段没有形成“自身公开扩权 + 进入他者权限网络借力”的双端闭环。

刘备既没有通过诸葛亮、刘表或其他权限接口借力完成自己的方向，也没有把借来的资源转为自身公开扩张；相反，他直接否决了取荆州方案。

### 2.4 压力显影 / 伪对子候选：confirmed

```text
曹军南下压力
+ 高价值替代方案：取荆州
→ 刘备仍保留最终否决资格
→ nx 被排除

同时
→ 只守住自己的选择边界
→ 未公开扩权、未扩大决定范围
→ zx 被排除
```

本例支持木轴两端之间存在合法中间区：主体保留最终方向资格，但既没有外置方向，也没有达到 zx 的公开扩权阈值。

## 3｜木轴核心检查

### zx 检查

问题：主体是否以自身权能公开进入现实，使他者、环境或等级秩序围绕其力量重新反应，并扩大决定范围？

答案：**否。**

刘备只是拒绝“取荆州”，没有把自身力量压到外部秩序之上。

### nx 检查

问题：主体是否不占最终方向，沿别人、关系、流程、秩序或现状给出的方向与通道推进？

答案：**否。**

诸葛亮给出的路线被刘备明确否决，最终取舍权没有外置。

## 4｜最近邻排除

### vs xn

诸葛亮的建议具有战略与计划成分，但本轮对象是刘备。刘备没有主动排程、搭流程、设节点来执行“取荆州”方案，不能把军师的 xn 机制借给刘备。

### vs x

刘备没有取得荆州资源、地盘或权限的实际掌握与处分；恰恰是拒绝去取得，因此不能判 `x`。

### vs xz

曹军南下显著构成安全窗口收窄与外部危险压力，但它只解释为什么“取荆州”方案变得紧迫，不自动解释刘备的木轴位置。冻结曹军压力后，只保留“诸葛亮提供一条高收益路线，刘备拥有否决并拒绝”，排除 nx 仍成立；同时未扩权，排除 zx 仍成立。

### vs z

刘备是否获得诸葛亮、刘表或天下人的认可不是本轮变量。伦理评价、仁义名声全部冻结后，木轴结构仍成立。

### vs nz

刘备与刘表的恩义关系可在其他轴另作分析，但本轮不靠“恩义”本身判十元，只看：谁拥有最终路线否决权，以及是否公开扩张决定范围。

## 5｜拿掉测试

### 拿掉“刘表之恩”这一具体伦理理由

将拒绝理由替换为任意刘备自己认可的原则，只要诸葛亮给出明确替代路线而刘备仍能真实否决，`nx` 仍不成立。

### 拿掉曹军南下

即使没有迫近军事压力，只保留“军师给出高收益扩张路线 → 主体拒绝”，最终方向资格仍在刘备，排除 `nx`；同时拒绝本身仍不产生公开扩权，排除 `zx`。

### 拿掉“刘备很仁义”的人物标签

只留下行为结构：

```text
方案A由他人提出
主体理解方案
主体拥有否决资格
主体否决方案A
主体没有扩大对外决定范围
```

木轴中间区判断保持。

### 拿掉后续历史结果

无论后来刘备是否取得其他地盘，本轮节点都不能由后续成败反推。当前桥段的方向资格与扩权状态已经独立成立。

## 6｜反向测试

### 反向成 nx

若刘备在该节点不保留是否取荆州的最终资格，只因诸葛亮已定战略便照办，且没有独立否决与重设位置，则 `nx` 明显上升；若接到目标后主要负责排程和组织运行，则继续检查 `xn`。

### 反向成 zx

若刘备不仅坚持自己的选择，还主动以自身权能夺取荆州、使刘表集团和荆州秩序围绕自己重新排列，并扩大自己的决定范围，则 `zx` 才明显上升。

本段均未发生。

## 7｜第三因素冻结

冻结：

- 刘备“仁德”主题；
- 汉室宗亲身份；
- 诸葛亮军师身份；

- 是否错失战略机会；
- 最终是否取得荆州相关地盘；
- 人物强弱、胜负、名望。

剩余最小变量：

```text
外部提供明确路线；
主体是否有最终否决/重设资格；
主体是否把自身权能扩大到外部秩序。
```

答案：

```text
最终否决资格：有 → 排除 nx
公开扩权：无 → 排除 zx
```

## 9｜跨作品价值

本例与两个已锁案例构成第三个独立作品同型复现：

1. 《西游记》唐僧女儿国：拒绝留下、婚姻与王位替代方向；保留西行方向，但不扩权。
2. 《水浒传》鲁智深拒官：拒绝还俗为官与名刹僧首；保留个人去向，但不扩权。
3. 《三国演义》刘备拒取荆州：拒绝军师提出的高收益扩张路线；保留最终取舍，但不扩权。

共同最小结构：

```text
存在真实替代方向
→ 主体拥有并使用否决资格
→ nx 不成立

主体只守住自身取舍边界
→ 没有公开扩张对外决定范围
→ zx 不成立
```
