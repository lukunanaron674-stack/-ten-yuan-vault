# 水浒传｜林冲投梁山｜zx↔nx 外部准入条件压力测试

## 1｜剧情事实

### 触发
林冲火烧草料场后遭官府追捕，在柴进庄上暂避。因追捕日紧，林冲主动提出离开，以免连累柴进，并希望另寻栖身处。

### 对象与权限位置
- 林冲自己的目标：寻找能够长期安身的去处。
- 柴进掌握：盘缠、关系介绍、过关协助与梁山荐书。
- 王伦掌握：是否允许林冲正式加入梁山的山寨准入权。
- 林冲不掌握：梁山成员准入、头领席位和山寨内部最终收留决定。

### 明确动作
1. 柴进提出梁山为去处，并写荐书；林冲接受这一外部关系通道。
2. 林冲借柴进与守关军官的熟识安全出关。
3. 到梁山外围后，林冲通过朱贵、柴进荐书进入山寨内部准入流程。
4. 王伦先以粮少、屋宇不整等理由推拒林冲。
5. 林冲请求收录，但没有宣布自己拥有入寨资格，也没有夺取准入权。
6. 王伦改设“投名状”条件，并限定三日；林冲接受条件，下山寻找目标以完成准入要求。

### 结果
在这一窄阶段里，林冲的“我要安身”方向仍属于自己，但“能否成为梁山成员”的关键权限始终在外部。即使王伦拒绝并附加条件，林冲仍继续沿既有准入接口推进，而没有把该权限改造成自己的决定接口。

## 2｜zx / nx 分类

### nx：evidence-locked（关系功能 / 关系位置）
成立理由：

```text
自己的安身方向已经形成
→ 但梁山准入权限在王伦一侧
→ 通过柴进荐书、朱贵引入进入既有关系网络
→ 王伦拒绝后仍接受其准入条件
→ 沿外部权限接口继续推进
= nx 关系功能高显影
```

这不是“林冲没主见”的证明。方向层面林冲有明确目标；nx 锁定的是：关键解决权限不在自己手里，必须承认并沿他者已有位置、关系与准入规则推进。

### zx：rejected（本窄阶段）
林冲武艺高、敢杀人、此前刚刚反击高俅体系，都不能倒灌成本段 zx。

本段没有出现：
- 林冲公开取得梁山准入处分权；
- 王伦、杜迁、宋万必须围绕林冲新增的权能重新排列；
- 林冲的决定范围从“申请加入”上升到“决定谁能加入、山寨怎样运行”。

因此不能因为林冲能打、坚持入伙、甚至接受投名状去杀人，就判 zx。

## 3｜关键压力

关键压力不是单纯“被官府追捕”，而是：

> 外部权限节点并未顺利接受主体，而是先拒绝、再附加高成本准入条件。

这使本案例可以检验：

```text
外部接口受阻
≠ 自动转 zx
```

林冲没有因为王伦拒绝就自行宣布入寨，也没有夺取山寨准入权，而是继续沿王伦设定的外部接口行动。

## 4｜拿掉测试

### 拿掉柴进姓名
只要仍存在“第三方关系人提供荐书 / 介绍 → 真正准入权属于另一个组织首领”，nx 关系结构仍成立。

### 拿掉林冲武力
即使不知道林冲是八十万禁军教头，只保留“目标自定、准入权外置、通过荐书与审批条件推进”，nx 仍成立。

### 拿掉官府追捕
如果林冲只是主动想加入某组织，只要该组织是否收留仍由他者决定，他必须沿其准入接口推进，nx 关系功能依然存在。追捕只提高压力，不是 nx 的本体来源。

### 拿掉王伦的投名状条件
只要“是否收留”仍由王伦决定，nx 仍成立；投名状只是把外部权限接口显得更清楚，而不是 nx 唯一证据。

## 5｜反向测试

### 反向成 zx
若王伦拒绝后，林冲以自身力量强行取得头领位置、改写山寨准入规则，并迫使山寨围绕他的新增决定权运行，则 zx 上升。

### 反向成 x
若林冲原本就是梁山头领，已有成员准入处分权，只是在正常处理入寨事务，应优先检查 x，而非 zx。

### 反向成纯 nx 本体
若林冲连“要不要离开柴进庄、要去哪里安身”都持续让别人替他决定，自己不提出替代方向，才更支持纯 nx 本体。现有文本不支持这一点。

## 6｜最近邻排除

### nx vs xn
林冲等待三日、下山寻找投名状对象，存在时间节点和执行过程，但节点不是林冲设计的，是王伦设定的。

```text
自己设计三日计划和准入流程 → xn 候选
别人设定三日条件，我按条件推进 → nx
```

因此不得把王伦的流程设计借给林冲判 xn。

### nx vs x
梁山准入权不属于林冲；柴进荐书也只是关系凭证，不会把山寨处分权转移给林冲，因此不是 x。

### nx vs nz
柴进对林冲的情义真实存在，但本轮判定变量不是“关系本身是否重要”，而是“关系是否作为进入外部权限网络的通道”。拿掉情感浓度、只保留荐书与准入权限归属，nx 仍成立。

## 7｜第三因素冻结

冻结以下因素后，结论不变：
- 林冲是否英雄、是否悲情；
- 高俅迫害主题；
- 林冲武力强弱；
- 王伦人格好坏；
- 是否真的完成投名状；
- 梁山最终政治走向；
- 后续林冲火并王伦。

只保留：

```text
谁定个人目标？
谁掌握组织准入？
接口受阻后主体是否夺取权限？
还是继续沿外部条件推进？
```

结论仍为 nx 关系功能高显影，zx 在本窄阶段排除。

## 8｜人物稳定本体 / 当前状态 / 行为功能 / 关系位置

- 稳定人物本体：不锁。
- 当前状态：处于高压逃亡与求安身阶段。
- 行为功能：接受荐书、请求收录、接受外部准入条件。
- 关系位置：申请者，不占梁山最终准入决定权。
- 外部压力：官府追捕 + 王伦拒绝 / 附条件。

不得把这一阶段回写成“林冲稳定是 nx”。其后续跨阶段存在明显主动反击与位置变化，需要独立判断。

## 9｜与近期案例的最小差异

### 对武松告县失败案
- 武松：外部司法接口失败 → 自行接管取供 / 裁决 / 执行 → zx 上升。
- 林冲：外部准入接口受阻 → 不接管准入权 → 接受外部附加条件继续推进 → nx 持续。

这构成一组有价值的压力差：

```text
外部接口失败 / 受阻后
A. 主体夺取并扩大决定接口 → zx 上升
B. 主体继续承认外部接口并按其条件推进 → nx 持续
```

### 对真假美猴王 / 贾芸谋差事
真假美猴王、贾芸案例强调“换到另一个外部节点”；本案例增加另一种结构：

> 不换节点，也不夺权，而是在原权限节点附加新条件后继续沿该节点推进。

因此“外部接口受阻后的 nx 持续”不只表现为换节点，也可表现为承认原节点的新准入条件。

## 10｜结论

**锁定：**
- nx 关系功能 / 关系位置：evidence-locked
- zx 当前扩权：rejected
- 稳定 nx 人物本体：not locked
- 严格 zx补nx：not locked

**案例级纪律：**

> 外部权限接口拒绝或附条件，不会自动触发 zx。若主体仍不占该权限的最终决定位置，而继续承认并沿外部准入条件推进，nx 关系功能可以持续。

该纪律目前只作为案例级证据，不修改 L1、zx/nx 信息卡、准度卡或 zx补nx 补卡。
