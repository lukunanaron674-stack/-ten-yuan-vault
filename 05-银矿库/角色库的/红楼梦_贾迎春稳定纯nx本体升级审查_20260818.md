# 《红楼梦》贾迎春｜稳定纯 nx 人物本体升级审查

## 结论先行

本轮**不把贾迎春升级为“稳定纯 nx 人物本体”**。

现有证据足以继续保留：

> 第七十三回“累金凤”事件 = `nx` 高置信行为 / 状态 / 关系位置正例。

但按照 `nx 准度卡 v0.5`，稳定人物本体必须跨场景反复出现低强迫自主窗口，并在有能力形成替代路线时仍不占最终方向、否决与重设位置。当前第74、80回不能提供同质量的第二、第三组独立低压证据。

因此本轮锁定的是：

```text
第73回 nx 行为/状态正例：保留
稳定纯 nx 人物本体：继续 deferred
```

分类置信度仅给 92，不满足95%正式升级门槛。

---

## 1｜现有高质量证据：第73回累金凤

既有正式案例已经证明：

- 乳母聚赌、累金凤被典当后，处置窗口已经打开；
- 绣桔、探春、平儿等多次要求或等待迎春给出处置方向；
- 迎春不主动追责、不提出替代方案，并多次表示不愿把事情升级；
- 平儿直接问她如何处理时，她仍不占最终裁决位置；
- 该桥段没有孙绍祖式暴力、生存威胁等高强迫因素。

所以第73回继续是一个非常干净的 `nx` 行为 / 当前状态样本。

本轮不推翻这一结论。

---

## 2｜第74回不能作为第二个稳定本体证据

第74回抄检大观园到迎春处时，文本明确写迎春已经睡着，凤姐还吩咐“不必惊动姑娘”。真正被搜的是司棋等丫鬟的箱物。

因此这一段缺少稳定本体所需的关键变量：

```text
自主窗口是否出现？
迎春有没有被要求给方向？
她有没有形成或放弃替代路线？
她有没有把最终决定交出去？
```

这些都没有被充分展示。

所以：

> “迎春没出来处理司棋事件”不能直接当作第二个 nx 独立证据。

否则会把“睡着 / 未参与 / 镜头缺席”误判成“稳定不占方向”。

---

## 3｜第80回存在 nx 外观，但被高强迫污染

第80回迎春回娘家后，明确诉说孙绍祖的酗酒、好色、辱骂、威胁与暴力；文本又明确写她最后“不愿去”，只是因为惧怕孙绍祖之恶，才勉强回去。

这类结构不能用于证明稳定纯 nx 本体：

```text
外部暴力 / 婚姻支配 / 生存风险
→ 主体选择空间被强压缩
→ 表面继续沿外部方向
```

按照 nx 准度卡，必须先拿掉暴力、惩罚与生存威胁，观察主体是否仍然不占最终方向。

因此第80回只能证明：

> 外部强迫下迎春的现实选择空间很窄。

不能证明：

> 即使没有强迫，她长期也会主动把方向让给别人。

---

## 4｜第80回还出现了不能忽视的自主反证

同一回里，迎春并非完全没有自己的判断与局部选择：

- 她主动向王夫人陈述婚姻处境；
- 对“这是你的命”这种解释，她明确反驳自己不相信命就这样坏；
- 王夫人问她想住哪里时，她主动选择回紫菱洲旧房住三五天；
- 她明确表达不愿回孙家。

这些行为不能直接锁为 zx/x，也不足以推翻第73回 nx 行为正例；但它们至少说明：

> “懦弱”并不等于人物完全不存在判断、否决或局部方向。

因此不能用回目中的“懦弱迎春”或传统人物评价替代十元判定。

---

## 5｜纯 nx 必要条件逐项复核

按 nx 准度卡 v0.5，稳定人物本体至少满足五项中的四项，第1、2项不可缺。

### 条件1：方向、权限或解决通道由外部给出

第73回：成立。

跨场景稳定性：目前不足。

### 条件2：主体不主动改写，也不抢最终决定 / 否决 / 重设位置

第73回：成立。

第80回：在婚姻最终去留上有外部暴力强迫污染；在局部居住与自我判断上仍出现自主表达。

因此不能稳定外推。

### 条件3：没有明确强迫时仍倾向等待安排

第73回：有支持。

目前缺第二个同等质量低强迫桥段。

### 条件4：跨阶段、跨场景反复出现

未达到高置信。

第74回不是有效自主窗口，第80回又有高强迫。

### 条件5：提供低成本自主窗口后仍不形成替代路线

第73回：有支持。

跨场景证据不足。

结论：

> 纯 nx 稳定本体升级条件尚未满足。

## 6｜最近邻排除

### nx vs xn

第73回没有主动组织处理流程，所以偏 nx。

但稳定人物本体不能因为“没有组织流程”就成立；还必须证明跨场景不占最终方向。

### nx vs nz

迎春重视姐妹、旧居与关系安全，不等于 nx；第80回她想回紫菱洲住几天更接近关系/回返需求的邻近变量，但本轮不越轴正式锁 nz。

### nx vs x

第73回她没有表现出稳定掌握物件、乳母与家务处分边界，所以不是 x 主判。

但第80回出现局部自选居所，不可把“局部有选择”错误理解为稳定 x。

### nx vs zx

迎春没有公开扩大决定范围、压过他者或让秩序围绕自己的权能重排，所以没有足够 zx 本体证据。

这不等于 nx 稳定本体自动成立。

## 7｜拿掉测试

### 拿掉孙绍祖暴力

第80回最强的“被迫返回”证据随之失效，因此不能用该段支持稳定 nx。

### 拿掉第73回单一桥段

剩余材料无法独立达到稳定纯 nx 人物本体95%门槛。

这说明当前本体判断高度依赖第73回，证据独立性不足。

### 拿掉人物传统评价

去掉“懦弱”“二木头”等标签，只保留动作事实，仍然只能锁第73回行为/状态 nx，不能自动升级人物本体。

---

## 8｜反向测试

若未来找到至少两个新的低强迫桥段，均满足：

```text
迎春拥有明确且低成本的自主窗口
→ 别人等待她给方向
→ 她仍不提出替代路线
→ 不使用否决 / 重设位置
→ 默认让他人或现状继续决定
```

则稳定纯 nx 本体置信度可重新上调。

反之，若找到低压力场景中她主动提出替代路线、持续使用否决权或主动组织关键决策，则应继续降低稳定纯 nx 候选。

---

## 9｜第三因素冻结

不得把以下因素直接写成 nx：

- 女性身份；
- 封建婚姻制度；
- 父权 / 夫权；
- 孙绍祖暴力；
- “懦弱”“二木头”等评价；
- 悲剧结局；
- 不争不吵的视觉或性格印象。

这些都只能作为压力、背景或体感，不能替代“最终方向与否决位置”证据。

## 11｜本轮贡献

本轮不是新增“迎春 = 纯 nx”的结论，而是锁住一条研究纪律：

> **一个高质量低压 nx 场景，不足以单独升级稳定纯 nx 人物本体。**

同时：

> **强迫场景里的顺从不能用来补足跨场景稳定性。**

当前更准确的写法仍然是：

> 贾迎春是目前最干净的纯 nx 行为 / 状态候选之一；但稳定纯 nx 人物本体尚缺足够独立低强迫证据。

## 下一轮建议

优先寻找第二个真正可作为“稳定纯 nx 人物本体”的候选，但筛选门槛提高：

- 至少两个以上低强迫独立场景；
- 每次都有真实自主窗口；
- 主体仍反复不占最终方向；
- 不靠身份、职位、暴力、婚姻、一次求人或单次服从；
- 必须排除 xn / x / nz 最近邻。
