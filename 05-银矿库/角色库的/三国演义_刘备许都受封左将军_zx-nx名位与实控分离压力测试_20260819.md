# 《三国演义》刘备许都受封左将军｜zx↔nx 名位与实控分离压力测试

## 1｜剧情事实

第20回，汉献帝认刘备为皇叔，并拜刘备为左将军、宜城亭侯。名位明显上升，但曹操回府后明确表示：刘备虽然名义上接近天子，实际上仍在自己的掌握之内。

第21回，刘备想脱离许都控制，并没有仅凭“左将军/皇叔”身份自行调兵离开，而是主动向曹操提出截击袁术。曹操表示次日奏帝，随后由曹操令刘备总督五万人马，并另派朱灵、路昭同行。刘备离许后，曹操又派许褚追请其回；刘备此时才在外军事实践中拒绝回撤。

因此本轮只截取“受封后至获准离许”这一对象层，不把离许后拒绝召回、据徐州等后续行为倒灌回来。

## 2｜触发、对象、动作与结果

```text
触发：刘备在许都受封高名位，但希望取得脱离许都与出兵的现实窗口
对象：离许许可、五万人马调用、当前军事实践入口
动作：向曹操提出讨袁术 → 曹操奏帝/授权 → 配兵并派朱灵路昭同行
结果：刘备得以合法离许并获得军队；关键入口不是仅凭头衔自行生效
```

## 3｜zx 判断

### 结论

`zx_in_narrow_stage: rejected_as_primary`

“左将军、宜城亭侯、皇叔”都不是 zx 的充分证据。

现行 zx 要求主体自身权能公开进入现实、他者/秩序被迫回应，并且主体决定范围真实扩大。当前窄阶段虽然刘备名位上升，但文本同时给出强反证：曹操认为刘备仍在其掌握中；刘备要取得离许与五万人马调用，仍需经过曹操/朝廷接口。

因此不能写成：

```text
名位上升
→ 权力一定扩大
→ zx
```

本轮只锁“名位不能替代实际独立处分接口”。

## 4｜nx 判断

### 结论

`nx_exit_and_army_permission_relation: evidence-locked`

刘备并非没有自己的方向。他明确想寻找脱身机会，并主动提出截击袁术，因此不锁纯 nx 本体。

但在“能否离开许都并取得五万人马执行该行动”这个具体对象层，关键权限与资源仍在曹操/朝廷体系。刘备必须进入这个既有政治与军令接口，得到授权后才能以正式任务离许。

所以这里成立的是：

> **强主体自己的目标明确，但关键行动入口、军队资源和合法调用边界仍在外部，因此出现 nx 权限/关系功能。**

## 5｜x 最近邻

### 结论

`x_formal_title_not_equivalent_to_independent_command: evidence-locked`

这里不是说刘备“完全没有任何权”。他有自己的随从、关张等既有力量，也获得正式将军名位。

本轮只检查更窄的一层：

> **左将军/皇叔名位本身，是否已经足以证明刘备拥有独立离许、独立调用朝廷五万人马的稳定处分边界？**

文本答案是否定的。

因此：

```text
正式头衔 / 高名位
≠ 自动形成该对象层的 x
```

只有实际对象、资源、人员和决定接口已经可由主体稳定独立调用，才应锁局部 x。

## 6｜关键压力

关键压力是曹操对许都政治与军令体系的现实控制。

但“曹操很强”不是十元判据。真正有效的证据是：

- 曹操自己明确描述刘备“实在吾掌握之内”；
- 刘备要离许不是直接凭左将军身份行动，而是先提出任务；
- 曹操/朝廷决定是否批准；
- 五万人马由曹操实际配置，并附朱灵、路昭同行。

这些事实让“名位”和“实际调用边界”被强制拆开。

## 7｜拿掉测试

### 拿掉“皇叔、左将军、宜城亭侯”称号

只保留：

```text
主体看似地位很高
→ 但离开中心、调用大规模军队仍须通过另一现实控制者授权
```

本轮 nx 权限关系与“名位不等于 x”的结论仍成立。

### 拿掉曹操实际授权门

如果刘备可以仅凭既有职位自行调五万人马、自由离许，曹操既不能批准也不能阻止，那么 nx 会明显下降，局部 x 上升。

### 拿掉五万人马，只保留离许

只要离开许都这一关键行动仍须借曹操/朝廷授命才能合法发生，nx 关系功能仍存在。

## 8｜反向测试

### 反向成局部 x

```text
左将军职位真实附带独立调兵与离许处分权
→ 刘备无需重新请求
→ 可直接调用资源并行动
```

则局部 x 成立。

### 反向成 zx

```text
刘备原本没有这块独立范围
→ 在公开冲突中把军令/政治决定边界推过曹操控制
→ 朝廷与军队开始承认新的刘备独立接口
```

才进一步检查 zx。

### 反向成更纯 nx

如果连“截击袁术”这个目标本身也完全由曹操指定，刘备没有自行提出脱身/行动方向，只能奉命执行，则 nx 覆盖会更深。

## 9｜最近邻排除

### nx vs xn

刘备主动提出“截击袁术”并把它当脱身机会，存在策略邻近；这是 `xn` 解释“怎么找出口”的部分。

但 `nx` 回答的是：

> **为什么这个出口必须经过曹操/朝廷的真实授权接口才能变成可执行现实。**

二者不能互相覆盖。

### nx vs x

```text
名位属于我
≠
该对象层的实际调用边界属于我
```

### x vs zx

即使后续某一阶段刘备取得独立军事实权，也必须另切阶段判断；不能把后来的据徐州、拒绝召回倒灌到当前受封阶段。

## 10｜第三因素冻结

本轮不以以下因素判十元：

- 刘备是不是皇叔；
- 刘备仁义/权谋评价；
- 曹操是否奸雄；
- 后来刘备是否据徐州；
- 左将军官阶高低；
- 最终谁赢；
- 衣带诏政治主题。

只看一个问题：

> **受封以后，当前关键行动/资源接口是否已经真实进入刘备可独立处分边界？**

## 11｜与现有分层授权反向控制的最小差异

### 《红楼梦》薛宝钗

```text
有协助职责
→ 冲突后仍回王夫人
→ 无独立处分 x
```

### 《西游记》齐天大圣空衔

```text
有高名位与府署
→ 连实际职掌都没有
→ 无局部 x
```

### 《三国演义》刘备许都受封

```text
有真实正式高名位
+ 有自身既有力量
→ 但离许与大规模军队调用仍受曹操/朝廷真实控制
→ 该对象层不能仅凭名位锁 x
→ 仍出现 nx 权限关系
```

三例共同说明：

> **授权/头衔的名称、级别、排场都不能替代对象层的真实独立处分接口。**
