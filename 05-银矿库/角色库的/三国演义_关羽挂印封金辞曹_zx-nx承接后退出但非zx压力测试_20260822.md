# 《三国演义》关羽挂印封金辞曹｜zx-nx 承接后退出但非 zx 压力测试

## 0｜研究问题

本轮只测一个窄问题：

> 主体此前已经真实承接一个外部给定的暂时服务方向，后来按既定退出条件主动不再续接，是否就自动转成 zx？

结论：**不是。**

本例与《西游记》猪八戒“四圣试禅心”、《水浒传》武松六和寺拒赴京形成第三部独立作品的同型控制：

```text
曾经真实承接外部方向 / 任务
→ 当前明确停止续接
= nx 当前窗口退出

但：
没有扩大公共决定范围
没有让组织围绕主体新增权力接口运行
≠ zx
```

## 1｜剧情事实

第二十五回，关羽在土山被围后，经张辽劝说，同意在三项明确条件下暂时进入曹操体系：只降汉帝、不降曹操；保护刘备二夫人；一旦知道刘备所在，不论远近即辞去。曹操最终接受三约，关羽由此卸甲并暂时进入曹操控制下的军事体系。

其后关羽确实执行曹操方面的现实任务，包括白马、延津等战事；他本人又明确表示，会先立功报曹操之恩，然后离去。因此这里不是纯口头“人在曹营心在汉”，而是实际承接过一段外部任务关系。

第二十六回，关羽得到刘备确切消息后，多次到相府辞谢而不得见。他最终写信告辞，把曹操所赐金银封存，把汉寿亭侯印悬于堂上，只带原有随从和二夫人北行。曹操的门禁、回避和后续留人意图没有让关羽继续停留。

所以当前窄阶段是：

```text
前阶段：
三约成立
→ 暂时进入曹操体系
→ 真实承接并执行任务
= nx 关系 / 任务位置成立

当前阶段：
刘备下落确认
→ 原约定退出条件触发
→ 关羽正式告辞并实际离开
= 当前 nx 续接停止
```

## 2｜nx 判断

### 2.1 前一阶段：成立

关羽并没有把曹操体系的军事任务整体改造成自己的最高方向；在暂留期间，他真实进入并执行曹操提供的任务与军事通道。

因此记录：

`nx_prior_temporary_service_relation: evidence-locked`

但这只是暂时服务关系位置，不等于稳定人物本体纯 nx。

### 2.2 当前离开窗口：退出

一旦“已知刘备所在”这一三约条件触发，关羽没有继续沿曹操的留用方向推进：

- 多次主动辞谢；
- 曹操回避不见后，仍不改变离意；
- 写信正式告辞；
- 封存曹操所赐金银；
- 悬回侯印；
- 实际率原随从与二夫人离开。

因此：

`nx_in_departure_execution_window: rejected_as_primary`

关键纪律：**此前真实承接过 nx，并不意味着退出条件触发后仍永久 nx。**

## 3｜zx 判断

**排除为主判。**

关羽此时“自己决定离开”不能直接判 zx。

他没有：

- 取得曹操军队或许都的更高决定权；
- 迫使曹操集团围绕关羽形成新的公共权力接口；
- 把自身决定范围扩大到他人的任务与去留；
- 让曹操正式承认一个超过三约既有退出条件的新权限边界。

相反，关羽主要是在执行此前已经明示、并被曹操接受的“知刘备所在即可辞去”条件。

因此：

`zx_in_departure_stage: rejected_as_primary`

核心纪律：

> **退出 nx ≠ 自动 zx。使用既有退出边界，与公开扩张决定范围是两个变量。**

## 4｜x 最近邻

本例比猪八戒、武松更适合加入一个窄 `x` 邻近：关羽的离开条件并非临时抢来的，而是第二十五回三约中事先提出并得到曹操接受。

因此：

`x_preagreed_exit_choice_neighbor: evidence-locked`

这意味着当前行为更像：

> 在预先保留的个人退出边界中停止续接外部任务。

它仍不能扩大成曹操体系的公共方向权。

## 5｜xn 排除

关羽离开后当然要护送二夫人、选择路线并应对关卡，但“挂印封金、辞曹”这一窄窗口本身没有重建一套新的组织运行系统：

- 没有重排曹军人员；
- 没有重配曹操资源；
- 没有设计新的持续政治组织；
- 没有改写曹操体系成功条件。

所以：

`xn_new_route_replanning: rejected_as_primary`

后续过五关的路线与通关冲突应另开对象层，不倒灌进本轮。

## 6｜关键压力与第三因素冻结

压力包括：

- 刘备下落终于被确认；
- 曹操持续厚待并希望留下关羽；
- 曹操多次回避关羽的辞谢请求；
- 关羽需要保护二夫人北行。

第三因素冻结：

- 忠义人物评价；
- 曹操善恶；
- 后续过五关斩六将；
- 关羽武力；
- 刘备阵营最终胜负。

只看：**前段是否真实承接、当前是否继续续接、退出后是否扩大公共决定范围。**

## 7｜拿掉测试

### 拿掉后续过五关强制突破

只保留“挂印封金、写信告辞、离开许都”，当前 nx 退出且 zx 不成立的判断仍成立。

因此后续武力不是本轮分类支柱。

### 拿掉曹操的挽留

即使曹操不回避辞谢，关羽在退出条件触发后正式离开，仍然属于当前 nx 续接停止；曹操挽留只增强压力，不创造分类。

### 拿掉三约中的预先退出条件

如果关羽此前无任何退出边界，却通过当前行动强行取得一项此前不存在的离开权，才需要重新检查 x / zx 边界。原文不是。

## 8｜反向测试

### 真正持续 nx

```text
得知刘备下落
→ 仍接受曹操留用方向
→ 继续执行曹操任务
= nx继续
```

### 真正 zx

```text
关羽离开
→ 进一步夺取曹操体系中的更高决定范围
→ 曹操及其组织被迫承认新增公共权力接口
→ 决定边界真实扩大
= 才检查zx
```

### 真正 xn

```text
退出曹操体系
→ 主动建立一套新的持续组织方案
→ 配置人员、资源、节点、规则
= xn上升
```

本轮窄阶段均无此证据。

## 9｜最近邻排除

```text
nx：当前是否仍沿曹操任务 / 留用方向推进？
x：三约中是否已经保留个人退出边界？
xn：是否重新组织一套持续运行结构？
zx：是否把自身决定范围公开推出原边界？
```

本例最窄判断：

```text
前段 nx 暂时服务关系成立
→ 三约退出条件触发
→ 当前 nx 退出
→ 既有个人退出边界 x 邻近
→ 无 xn 结构重建
→ 无 zx 扩权
```

## 10｜跨作品复验

《西游记》猪八戒四圣试禅心：

```text
已承接取经方向
→ 当前尝试退出西行
→ nx退出
→ 无公共扩权
→ 非zx
```

《水浒传》武松六和寺：

```text
已承接朝廷征讨体系
→ 当前拒绝班师赴京
→ nx退出
→ 无公共扩权
→ 非zx
```

《三国演义》关羽挂印封金：

```text
已承接曹操暂时任务体系
→ 退出条件触发后正式离开
→ nx退出
→ 无公共扩权
→ 非zx
```

三部独立作品共同支持：

> **nx 退出只说明主体不再续接当前外部方向；zx 是否出现，必须重新独立检查主体权能是否公开进入现实并扩大决定范围。二者不是自动跷跷板。**
