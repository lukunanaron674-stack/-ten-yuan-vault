# 红楼梦｜宝钗受托照看大观园｜zx-nx 名义授权未转移压力测试

## 结论摘要

本桥段锁定一个与“周瑜受剑拜大都督”直接相反的最小差异：**王夫人确实把“照看园中、发现不妥及时处理/报告”的任务交给宝钗，但原文同时明确限制了宝钗的权限边界——若下人不听，宝钗需要“来回我”，也就是回到王夫人这个真正的最终处分节点。** 因此，这不是“受托以后实际决定范围已经独立扩大”的 `zx`；更接近在外部授权框架下承担观察、提醒与协助的 `nx` 关系位置，并伴有局部 `xn` 组织/判断邻近。

本轮不锁“宝钗稳定人物本体 = nx”，也不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实、触发、对象、动作与结果

### 触发

凤姐因病不能理事，王夫人先让李纨暂协理，又命探春合同李纨裁处。因为园中人多，担心照管不足，王夫人另外请宝钗协助照看。

### 原始权限结构

原文对权限边界写得非常清楚：

```text
王夫人：大事仍由自己主张；拥有更高家内处分与最终回报接口
李纨、探春：暂时协理/裁处日常事务
宝钗：受托照看、发现问题可说；若对方不听，仍须回报王夫人
```

### 明确动作

1. 王夫人主动邀请宝钗帮助照看园中。
2. 王夫人授权宝钗发现问题时可以指出、提醒。
3. 同一句授权中又明确设限：若相关人“不听”，宝钗应回报王夫人。
4. 宝钗接受这一受托位置。

### 结果

宝钗获得了观察、提醒、协助管理的角色，但没有取得一个可以脱离王夫人独立调用的最终强制处分接口。真正的“不听以后怎么办”仍回到王夫人。

## 2｜zx / nx 分类

### A. zx：伪授权型反例

表面上很容易误判：

```text
王夫人请宝钗照看园子
→ 宝钗进入管理位置
→ 好像权力扩大
→ zx？
```

但现行 `zx` 要求的是：

```text
主体自身权能公开进入现实
+ 他者/秩序围绕主体重新反应
+ 主体决定范围或凌驾位置真实上升
```

本段最关键的反证正是王夫人自己给出的权限边界：**若下人不听，宝钗需要回报王夫人。** 这说明最终强制与处分接口没有真正转移给宝钗。

因此锁定：

- `zx_in_current_narrow_stage: rejected_as_primary`
- `nominal_delegation_without_independent_authority: evidence-locked`

不是说宝钗毫无新增功能，而是说“受托协助”没有达到 zx 所要求的独立决定范围跃迁。

### B. nx：关系位置 / 行为功能成立

宝钗并非纯 nx 本体。她完全可能有自己的判断和管理意见。

但在这一窄桥段中，她真正能够让问题获得更高处分的路径是：

```text
发现问题
↓
可以提醒、说出
↓
如果对方不听
↓
回报王夫人
↓
由王夫人调用更高权限
```

因此关键作用权仍在外部，宝钗沿王夫人已经建立的家内权限接口推进。这符合 `nx` 关系功能/关系位置，而不是“没主见”。

锁定：

- `nx_relation_position_stage: evidence-locked`
- `pure_nx_essence: rejected`

## 3｜与周瑜授权案例的最小差异

### 周瑜

```text
授权前：必须经过孙权
↓
孙权正式授剑、授都督军令处分接口
↓
周瑜可以独立调度诸将、处分违令者
↓
军中实际围绕新增接口运行
= zx 当前状态上升
```

### 宝钗

```text
王夫人请其照看
↓
宝钗可提醒、可报告
↓
下人若不听
↓
仍须回到王夫人
↓
最终强制处分接口未转移
= nx 关系位置 / 伪 zx
```

因此，本轮最小差异不是“有没有得到一个新称呼或任务”，而是：

> **授权后，主体是否拥有此前没有、且可独立调用的最终决定/处分接口。**

## 4｜最近邻排除

### nx vs xn

宝钗后续参与园中管理时，可能出现组织、协调、判断与制度建议，这些可检查 `xn`。

但本轮截面只验证王夫人的初始授权边界。即使拿掉所有后续组织动作，只保留：

```text
受托照看
+ 不听时回报王夫人
```

`nx` 权限关系仍成立。

因此：

- `xn_neighbor: possible_but_not_primary_in_this_stage`

### nx vs x

如果宝钗拥有了对园中下人的独立常态处分权，不必再回报王夫人，那么应进一步检查 `x`。

文本恰恰明确说明这一强制接口仍在王夫人，因此不能把“能提醒人”扩大成“处分权归我”。

### zx vs x

本段连稳定 `x` 都不能高锁，更不能仅凭“受托管理”直接跳到 `zx`。

## 5｜拿掉测试

### 拿掉“宝钗很聪明/很稳妥”

只保留“王夫人委托照看，但不听时必须回来报告”，权限仍然外置，结论不变。

### 拿掉“宝钗是亲戚/客居贾府”

换成任何受托协助者，只要最终处分仍需回到授权者，仍不能判真 zx 扩权。

### 拿掉后续改革情节

本轮仍成立，因为初始授权边界已经在王夫人话中直接写明。

## 6｜反向测试

### 反向成真 zx

如果王夫人说：

```text
园中这些人的处理以后由你独立决定，
不必再回我；
你的处分对相关人直接生效。
```

并且随后园中人员实际围绕宝钗这个新增接口运行，那么才形成“权限真实转移 → 决定范围扩大”的 zx 硬证据。

### 反向成纯 nx

如果宝钗不仅没有处分权，而且连观察标准、问题判断和是否报告也长期完全等待别人指令，那么纯 nx 本体候选才会上升。

## 7｜第三因素冻结

冻结以下因素后结论仍成立：

- 宝钗性格评价；
- 宝钗是否“妥当”；
- 凤姐生病；
- 探春的能力；
- 李纨的管理风格；
- 宝钗后续是否参与园中改革；
- 贾府身份等级；
- 读者对宝钗的好恶。

只看：

```text
谁给任务？
谁拥有最终强制处分接口？
受托者能否在“不听”的情况下独立生效？
是否仍须回到授权者？
```

结论不变。

## 8｜对象分层

```text
稳定人物本体：不锁
当前状态：受托协助状态
行为功能：观察、提醒、报告、沿授权接口推进
关系位置：最终处分权在王夫人，宝钗沿此权限接口工作
外部压力：凤姐病后管理缺口
```

## 9｜与现行正本的关系

本案不要求修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。

现行准度卡已经能够解释：

- `zx`：必须有决定范围真实扩大，不能只看被授权、被任命或能说话；
- `nx`：人物自己可以有判断，但关键权限仍在别人手里时，可以沿外部权限接口推进；
- `xn`：若后续自行搭建流程、节点、组织结构，应另行检查，不得倒灌成本轮 nx 或 zx。

## 10｜案例级判定纪律

本案支持但不升级为新正本：

> **“被授权做事”与“权限真正转移”必须分开。**
>
> **受托者若在关键不服从/冲突节点仍必须回到授权者，说明最终处分接口未转移；不能仅凭名义管理身份判 zx。**

与周瑜案例共同构成当前最小差异：

```text
名义/协助授权，但最终接口仍在上级 → nx关系位置 / 伪zx
真实权限转移，可独立调用并使秩序围绕新接口运行 → zx上升
```

当前不形成新待审议问题；先保留为案例级压力测试结果。
