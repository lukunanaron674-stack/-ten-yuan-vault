# 《西游记》孙悟空任弼马温｜zx↔nx 分层授权压力测试

## 结论先行

本轮锁定一个“分层授权”正例：

> **上位职责与任务方向由外部给定，可以形成 `nx` 当前关系位置；与此同时，任务内部的局部对象、人员与调用边界可以真实交给主体，形成 `x` 最近邻。二者对象层不同，可以同时成立。被授予真实局部权限本身仍不自动等于 `zx`，除非主体进一步把决定边界公开推到原授权之外，并迫使外部秩序围绕新增权能重排。**

本段只截取孙悟空到任弼马温、实际管理御马监、尚未得知官阶之前。后续得知“未入流”后反出天庭属于另一压力阶段，不倒灌进本段判定。

---

## 1｜剧情事实

### 触发

玉帝命群臣查看天宫何处缺职。武曲星君指出御马监缺正堂管事，玉帝遂任命孙悟空为弼马温，并命木德星官送其到御马监上任。

因此，“进入御马监、承担管理天马职责”这一上位任务不是孙悟空自行生成，而是由天庭已有官职体系给出。

### 明确动作

孙悟空到任后：

1. 会集监丞、监副、典簿、力士及御马监大小官员；
2. 查明御马监事务并核对天马数量；
3. 在既有人员分工中实际承担正堂管理职责；
4. 持续照料、督理天马，不分昼夜；
5. 其管理结果可观察为天马状态明显改善，养得肥壮。

### 结果

孙悟空不是“挂名弼马温却什么也不能管”。在御马监这一局部对象域内，他真实进入管理中心，能够召集下属、查事务、核对象并持续调用既有人员体系完成养马任务。

---

## 2｜nx：锁在上位职责与关系位置

现行 `nx` 的核心不是“弱”或“听话”，而是：

```text
方向、权限或解决通道已由外部给出
→ 主体在这一对象层不占最终重设位置
→ 沿既有安排继续
```

在本段的“为什么进入御马监、最高任务是什么”这一层：

```text
天庭已有官职体系
→ 玉帝任命弼马温
→ 上位任务 = 管理御马监天马
→ 孙悟空到任并承接
```

因此锁：

`nx_upper_task_relation_position: evidence-locked`

这不是说孙悟空稳定本体没主见。相反，后续得知官阶低后他立即拒绝并离开，正说明不能由本段受命反推稳定纯 `nx`。

---

## 3｜x：局部真实权限已经归入调用边界

现行 `nx vs x` 的区分是：

```text
nx：权限和资源在别人手里，我沿通道借用。
x：对象、资源、权限和调用边界已经归我掌握。
```

御马监内部并非每一步都要回灵霄殿逐项请示。孙悟空到任后能够会集所属官员、核查事务与马匹，并持续统理养马工作。至少在“御马监日常管理”这一局部对象层，实际调用边界已经交到弼马温职位手中。

因此锁：

`x_local_authority_neighbor: evidence-locked`

这里的 `x` 是局部职务权限，不等于私人占有天马，也不等于孙悟空获得天庭最高方向权。

---

## 4｜为什么不是 zx

最容易出现的误判是：

```text
获得新职位
→ 获得一批下属和对象
→ 权力变多
→ zx
```

现行 `zx` 不允许这样直判。`zx` 还要求：

- 主体自己的权能公开成为更高决定来源；
- 他者或秩序被迫围绕主体重新反应；
- 主体决定范围或凌驾位置发生公开扩大；
- 不是普通受权后的职业执行。

在本段截面里，最明确的因果仍是：

```text
玉帝设置/授予职位
→ 孙悟空进入已有御马监体系
→ 在授权范围内真实管理
```

没有证据显示孙悟空此时已经把御马监权限向天庭其他部门公开扩张，或迫使天庭承认一个超出弼马温职掌的新决定边界。

所以：

`zx_in_narrow_stage: rejected_as_primary`

后续反出天庭、要求“齐天大圣”属于另一个阶段，不能拿后来的 `zx` 替本段受权管理补证。

---

## 5｜关键压力

本段最有价值的压力不是危险，而是“名位与实权错位”。

孙悟空此时：

```text
官阶：极低，甚至后来才知未入流
局部管理权：真实存在
```

因此可与仓库已有“齐天大圣空衔”案例形成反向最小差异：

```text
弼马温：名位低，但御马监局部权限真实可调用
齐天大圣空衔：名位极高，但最初无实际职掌
```

这进一步证明：

> **身份高低不能替代权限归属；称号不能替代对象层上的实际调用边界。**

---

## 6｜拿掉测试

### 拿掉“孙悟空很强”

换成任何被任命为御马监正堂管事的人，只要最高任务仍由天庭给定、但御马监内部管理边界真实交给他，仍可得到：

```text
上位任务 nx 关系位置
+
局部 x 权限
```

所以武力不是本轮判据。

### 拿掉“弼马温”这个官名

只保留：

```text
上级指定你负责某部门
→ 部门内人员和对象确实由你日常管理
→ 最高任务仍不能由你自行改写
```

结论不变。说明不是职位词直判。

### 拿掉局部独立调用权

如果孙悟空每一次召集下属、调度养马、处理事务都必须先回报玉帝逐项批准，那么 `x_local_authority_neighbor` 会明显下降，更接近宝钗式代理 `nx`。

---

## 7｜反向测试

### 反向成更纯 nx

若玉帝不仅规定“去御马监”，还逐项规定所有人员调度、每日流程、对象处理，孙悟空只能按指令执行且不能独立调用部门权限，则局部 `x` 下降，`nx` 覆盖更深。

### 反向成 zx

若孙悟空在弼马温任内公开突破原职掌，把自身权能推到其他天庭部门，迫使天庭承认其新增处分范围，使更多秩序围绕他的新增决定接口运行，才应锁 `zx` 上升。

### 反向成纯 x

若“管理御马监”本身就是孙悟空长期自有、无需外部任命与上位任务约束的对象域，则上位 `nx` 会下降，只剩局部 `x/xn`。

---

## 8｜最近邻排除

### nx vs xn

孙悟空确实持续料理马匹，但本段没有足够证据证明关键的新流程、时间节点与制度结构主要由他主动设计。即使存在局部组织行为，也不能取消“上位任务由天庭给定”的 `nx` 对象层。

### nx vs x

两者并非互斥于整个角色，而是对象层不同：

```text
为什么做这件事、最高职责从哪里来？ → nx
部门内部哪些对象和调用边界已经交给我？ → x
```

### x vs zx

```text
x：御马监这块权已经交到我手里，我可以调用。
zx：我把自己的决定范围继续公开推大，超出原来的边界。
```

本段只有前者证据充分。

## 9｜第三因素冻结

以下全部冻结，不参与木轴主判：

- 孙悟空的齐天大圣后续身份；
- 神通、武力和战斗胜负；
- 官阶“未入流”的羞辱感；
- 后续反出天庭；
- 天上一日、地下一年的时间设定；
- 养马结果好坏。

只保留：

```text
上位任务谁给？
局部权限谁能独立调用？
主体是否能重设最高方向？
主体是否把权限公开推到原授权边界之外？
```

结论仍稳定。

## 10｜跨作品复现与新增价值

1. 《三国演义》关羽受印守荆州：上位战略方向外置，荆州局部统辖权真实交给关羽；

3. 《西游记》孙悟空任弼马温：上位职位与任务由天庭给定，御马监内部存在真实局部管理权。
