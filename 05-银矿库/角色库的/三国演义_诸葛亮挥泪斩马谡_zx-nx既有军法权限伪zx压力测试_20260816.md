# 《三国演义》诸葛亮挥泪斩马谡｜zx-nx 既有军法权限伪 zx 压力测试

## 0｜结论

本桥段最适合锁为：

```text
诸葛亮本来就是北伐军最高统帅/军法处分主体
→ 马谡违令失街亭后，诸葛亮公开调用既有军法接口
→ 蒋琬求情不能改变其依法处置
→ 马谡被斩、首级示营
= x 最近邻高显影

不是：
公开下令 + 对象被处决 = 自动 zx
也不是：
通过他人权限办成 = nx
```

更强的反向证据是：处置完成后诸葛亮自作表文，请后主将自己贬三等；后主实际下诏贬为右将军、仍行丞相事。这一结果说明本桥段不是主体借军法行动扩大自身正式决定范围。

因此本轮的木轴价值是第三部独立作品上的高置信边界复现：**已有权限被公开成功行使，不自动升级为 zx；关键权限原本就在主体手里，也不能判 nx 关系功能。**

本轮只锁当前状态/行为功能/关系位置的边界，不锁诸葛亮稳定人物本体；不锁严格 zx补nx。

## 1｜剧情事实、触发、对象、动作、结果

### 触发

街亭失守。王平解释自己曾反复劝马谡当道筑城而马谡不从；诸葛亮随后召马谡入帐，认定其违令导致败军折将、失地陷城。

### 对象

- 主体：诸葛亮。
- 被处分对象：马谡。
- 劝阻者：蒋琬。
- 上位正式君主：后主刘禅。
- 关键问题：诸葛亮是在扩大自身军法决定范围，还是在调用本已拥有的统帅/军法处分权限。

### 明确动作

1. 诸葛亮在军帐中依据既有军律认定马谡应受处分，并命左右推出斩首。
2. 蒋琬赶到后明确请求留人，诸葛亮以“用法明”“若须废法，何以讨贼”为由拒绝改变处分。
3. 马谡被斩，首级献于阶下并遍示各营。
4. 诸葛亮随后安葬马谡、抚恤其家小。
5. 诸葛亮自作表文，请后主因街亭失误将自己贬三等；后主最终下诏贬其为右将军、行丞相事。

### 结果

马谡被依法处置，军法接口得到实际执行；但没有出现诸葛亮借此取得此前不存在的更高军法或国家处分权。相反，其正式品秩随后因自请处分而下降。

## 2｜zx 检查

### 支持 zx 的表象

本段极易出现四个表面误判：

- 诸葛亮公开下令；
- 蒋琬劝阻无效；
- 马谡确实被处决；
- 全军必须承认军令结果。

这些只能证明权力真实有效，不能单独证明 zx。

### 为什么高纯 zx 不成立

现行 zx 必须继续检查：

```text
主体的决定范围、影响位置或凌驾程度是否新增/上升？
```

本桥段中：

1. 诸葛亮在街亭战前已经拥有调将、下令和军法处分的北伐统帅接口；
2. 斩马谡是对违令失军行为调用既有军法，而非本次冲突后新夺取一套处分范围；
3. 蒋琬求情被拒，证明该接口真实归诸葛亮调用，但不能证明接口边界因此扩大；
4. 处置后诸葛亮反而自请贬三等，后主实际贬其官位，进一步排除“借此扩权”的主解释。

因此：

```text
zx_in_current_narrow_stage: rejected_as_primary
x_existing_authority_neighbor: evidence-locked
```

## 3｜nx 检查

`nx` 同样不成立为本桥段诸葛亮的主要机制。

nx 关系功能要求关键权限仍在他者手里，主体必须沿外部身份、关系、权限或通道借用。

本段相反：

- 军法裁处并非由蒋琬掌握；
- 诸葛亮不需要请求另一位现场军法主体批准才能斩马谡；
- 蒋琬反而是向诸葛亮请求改变决定；
- 后主对诸葛亮自贬的批准属于另一问题层，即诸葛亮本人官位处分，而非马谡军法处分的外部借权路径。

因此：

```text
nx_relation_function_for_zhuge_liang: rejected
```

## 4｜最近邻排除

### zx vs x

这是本轮最重要的最近邻：

```text
x：权限、对象和处分边界本来归我，我调用它。
zx：我的权能公开显现并扩大，决定范围真实上升。
```

本桥段明显更接近前者。

### nx vs x

```text
nx：权限在别人手里，我沿通道借用。
x：关键权限本身就在我手里。
```

马谡军法处分接口在诸葛亮的统帅位置内，所以不能因“执行者是左右武士”就判 nx。执行者替主体完成动作，不等于最终处分权在执行者手里。

### zx vs xn

军法程序、审问、示首各营都有流程性，但这些只是既有军法的运行；本轮核心不是诸葛亮新搭流程、设节点，而是他调用已经存在的处分接口。若研究程序组织，应另查 xn，不能反过来替 zx 证明扩权。

### zx vs z

将士“服其论”、军法获得认可可有 z 邻近表象，但重要认可并不替代权力边界是否扩大这一问题。

## 5｜拿掉测试

### 拿掉“挥泪”“痛哭”等戏剧强度

只保留：

```text
统帅已有军法处分权
+ 部将违令导致重大失败
+ 主体依法下令处分
+ 求情不能改变决定
+ 决定被执行
```

x 最近邻仍成立，zx 仍不需要成立。

### 拿掉马谡最终被杀的结果冲击

把极端刑罚替换成任何主体本来就有权作出的军法处分，只要没有新增决定范围，仍优先检查 x，而不是 zx。

### 拿掉“丞相”“武侯”等身份词

换成任何原本已经拥有某组织处分权的负责人，只要本轮只是正常调用原有边界，结论仍不变。

### 拿掉诸葛亮后来自贬

即使不使用自贬作为反向证据，仅凭“处分权在冲突前已经存在”也足以排除高纯 zx；自贬只是进一步加强“本轮没有正式扩权”的证据。

## 6｜反向测试

### 反向成真 zx

若诸葛亮原本无权独立处分马谡，却在街亭败后公开夺得该处分权，并让蜀汉军政体系以后承认其新增的独立裁决范围，则 zx 才明显上升。

### 反向成 nx

若马谡最终生杀处分权实际掌握在另一个主体手里，诸葛亮只能提出处分建议、等待其批准，再沿该外部权限执行，则 nx 关系功能才上升。

### 反向成普通意见表达

若诸葛亮只有“应该斩”的意见，但没有实际处分接口，蒋琬或其他主体可以不受约束地否决，则连 x 的已有权限证据也会下降。

## 7｜第三因素冻结

冻结以下因素：

- 诸葛亮神机妙算或历史名望；
- 马谡是否人才；
- 失街亭的军事严重程度；
- 诸葛亮与马谡的私人感情；
- “挥泪斩马谡”的戏剧性；
- 蒋琬是否求情合理；
- 后世对诸葛亮严明军法的评价；
- 北伐成败主题。

只保留：

```text
冲突发生前谁拥有军法处分接口？
主体是否需要借别人权限？
本次行动是否新增主体决定范围？
对象是否因该既有权限而实际改变状态？
```

结论仍为 x 最近邻，zx/nx 均排除为主要解释。

## 8｜跨作品最小差异与第三例复现

仓库已有两部独立作品的同型案例：

```text
《西游记》唐僧逐悟空：
已有师徒处分接口被执行
→ 没有新增决定范围
→ 伪 zx，优先查 x

《红楼梦》贾母阻鸳鸯婚事：
已有家内许可/否决接口被执行
→ 贾赦退让
→ 伪 zx，优先查 x
```

本轮加入：

```text
《三国演义》诸葛亮斩马谡：
已有军法处分接口被执行
→ 马谡被处置
→ 没有新增决定范围，之后自身正式官位反而下降
→ 伪 zx，优先查 x
```

因此同一边界已经跨至少三部独立作品稳定复现，达到“形成待审议问题”的仓库运行门槛。

## 9｜稳定本体 / 状态 / 行为 / 关系 / 压力分层

- 稳定人物本体：不锁。
- 当前状态：既有统帅/军法权限被公开调用。
- 行为功能：审责、拒绝求情、依法处分。
- 关系位置：军法处分接口持有者，而非权限借用者。
- 外部压力：街亭重大失败、军心与军纪压力。
- 主判最近邻：x。
- zx：表象强，但缺新增决定范围。
- nx：缺“关键处分权限在外部并需借用”这一条件。
