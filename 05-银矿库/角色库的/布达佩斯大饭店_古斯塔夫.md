# 古斯塔夫（Gustave H.）
> 归档：`05-银矿库/角色库/布达佩斯大饭店_古斯塔夫.md`

---

## 1. 主十元判断

**主十元：zn（阳土·这件事是对的）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zn，古斯塔夫就是一个精明的饭店经理、乱世中求生的人。但古斯塔夫最核心的不是聪明或求生——是**他必须按规矩做对的事**。香水、诗歌、完美的服务、在囚车上还喊"检查我的指甲"——这些不是表演，是他骨子里认为"文明人就该这样"。
- **第2问（反复面对什么结构）：** 反复面对「文明在崩溃但我不能跟着崩」。越混乱他越要擦皮鞋、念诗、保持仪态。zn的结构是：**在所有人都放弃的时候，我还是要做对的事**。
- **第3问（最怕失去什么）：** 最怕「失了体面」。不是怕死（x），是怕死的时候姿势不对。火车上被SS盘查还坚持把香水塞给零，那不是英雄主义，是他认为"香水不能断"。
- **第4问（回到哪个感觉）：** 回到「一切还在运转让客人满意」的那一刻。管家在继承遗产前的那个完美服务的早晨，就是他最想维持的状态。
- **第5问（副十元服务谁）：** n（承载/扛）服务于zn——古斯塔夫不是冲动的热血人，他是zn推着走：这件事必须做，因为它是对的，哪怕要搭上命。

## 2. 副十元

**副十元：n（阳火·承载/不能让它塌）**

**作用：** 古斯塔夫不是不知道时代变了。他的n让他扛住所有——贵族世界的崩塌、自己被追杀、饭店被没收——他不退，因为"这是我该站的地方"。

## 3. 功能十元

**功能十元：z（阴火·包装/被看见）——表层。** 他的香水、诗、制服都是包装，但这些是zn的外壳，不是zn本身。

## 4. 视觉十元

**视觉十元：n（阴水·坚定/承重）。** 永远笔挺的身姿，永远从容的脚步——这不是表演，是承重的姿势。

## 5. 动态链

```
zn（主·这件事是文明人该做的）
  → n（副·扛住，不能让它塌）
  → z（功能·香水/制服是文明的包装）
  → 火车盘查→送香水给零→在悬崖上念诗
  → 文明的最后一个人
  → 死在列车上，姿势没有倒
```

## 6. 一句话定型

古斯塔夫不是「旧时代的幸存者」，也不是「乱世中的优雅象征」，而是「**这事是文明人该做的，所以我就做了**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** zn（主）+ n（副）→ 本体型
**最终定位：** zn（主·对的事）+ n（副·不能让它塌）→ 本体型
**最终修正理由：** 原卡把古斯塔夫当作因果型（先做再想+算清楚），但他行动的逻辑不是"完成即意义"（zx）也不是"看清了再动"（nx）。他的一切行为来自一个信念：**文明人应该这样做**。香水、礼仪、服务——不是为了好看（z），也不是为了完成（zx），是因为"这是对的"（zn）。副十元n是他扛住文明崩塌的力量——不是因为勇敢，是因为他在那个位置上。
