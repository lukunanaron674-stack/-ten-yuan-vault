# 《三国演义》马谡守街亭｜zx-nx 外部方案重写 / xn 最近邻压力测试

## 1｜本轮问题

上一轮刘备面对庞统三策，只能锁到“外部完整方案输入 + 主体拥有最终选择权”的灰区，因为刘备虽然拒绝两策，却没有重新设计一套新的战略方案。

本轮专门找更硬的反向材料：

```text
外部不仅给总目标，
还给出明确运行约束和协同要求；
主体到场后却主动否定这些约束，
自己重新组织关键运行方式。
```

若该结构成立，则不能因为“上级给任务、给指示”就把主体当前行为判成 nx；应优先检查 xn，zx 另做独立排除。

## 2｜剧情事实

### 触发

司马懿、张郃将取街亭。诸葛亮认定街亭是蜀军咽喉，马谡主动请命守街亭，并立军令状。

### 外部给出的既定约束

诸葛亮拨马谡二万五千精兵，并令王平相助；随后明确嘱咐：

1. 下寨必须在要道之处，使魏军不能轻易通过；
2. 安营之后绘制四至八道地理图本回报；
3. 凡事与王平商议停当，不可轻易自专。

这不是只有“守住街亭”一个抽象目标，而是已经包含明确的运行位置、协同接口和回报约束。

### 马谡到场后的明确动作

1. 到街亭后，马谡主动否定“当道下寨”，转而主张在侧边孤山屯军。
2. 王平提出在五路总口下寨，并指出山上断水风险；马谡拒绝。
3. 王平退一步提出分兵山西另下一寨、形成犄角；马谡仍不采纳，只拨五千兵让王平自行去寨。
4. 马谡以自己对兵法的理解重新定义了街亭的运行方式：把原本“守交通要道”的部署改成“占高地、诱敌围山、置之死地而后生”。

### 结果

王平另寨并将图本报诸葛亮；马谡山上主力随后被魏军围困并断绝汲水，街亭失守。

失败结果不决定十元分类，但能够反向确认：马谡确实没有沿诸葛亮给定的关键运行约束推进，而是实际使用了自己重设后的方案。

## 3｜zx / nx / xn 候选判断

### nx：rejected for current operational method

表面 nx 诱因：

- 守街亭任务来自诸葛亮；
- 马谡仍服务于蜀军既定战略；
- 他没有取消“守街亭”这一总目标。

但现行 nx 准度卡要求主体不主动改写方向，也不抢最终否决与重设位置；而 nx 与 xn 的最近邻边界又明确写明：外部给目标后，主体若主动排程、搭流程、设节点、重组运行方式，应优先检查 xn。

马谡在本轮不是沿既有方案续接，而是直接否定关键下寨位置、协同要求与运行方式，并建立新的战术组织。因此在“如何守街亭”这个对象层，nx 应排除为主判。

这里仍可承认更高层的外部任务事实：

```text
最高任务：守街亭 —— 来自诸葛亮
具体运行方式：马谡主动重设
```

但不能用上位目标外置去覆盖下位运行层的自主重组。

### zx：rejected as primary

马谡确实公开压过王平意见，并以主将身份让大部分兵力按自己的方案上山，但这些兵力与临时指挥接口原本就由诸葛亮授予。

本阶段没有足够证据显示：

- 马谡取得了此前不存在的更高军政决定范围；
- 诸葛亮或蜀军整体秩序必须围绕马谡新增权能重新排列；
- 马谡把自己的权限边界公开扩大到原授权之外并获得制度承认。

所以“敢违令、能压副将、主意很大”都不能自动锁 zx。

### xn：最近邻高显影

马谡本轮最稳定的结构是：

```text
外部给任务 + 明确运行约束
→ 主体否定既定运行方式
→ 主体依据自己的规则模型重新选位置
→ 主体重设兵力分布与协同接口
→ 主体承担新方案结果
```

这比 nx 的“沿既有方向/通道继续”更接近 xn 的主动组织运行方式。

## 4｜关键压力

本轮压力不是普通自由发挥，而是：

```text
上级给出的方案约束非常明确
+ 同行副将持续提出纠错
+ 主体仍拥有并使用低成本重设窗口
```

因此它比“别人只给一个总目标，我自行规划”的案例更强：马谡不是因为外部没有方案才自己组织，而是在外部方案已经存在时主动替换。

## 5｜拿掉测试

### 拿掉“诸葛亮是上级”

只保留“另一个有指挥资格的主体已经给出明确下寨位置与协同要求”，若马谡仍主动否定并重设运行方式，则当前运行层 nx 仍下降，xn 仍上升。

### 拿掉最终失败

即使马谡山上屯军最终获胜，只要事实仍是他主动否定既有运行约束、重设位置与协同方式，nx/xn 边界判断不变。

### 拿掉马谡自负、熟读兵书等性格描写

只留下“外部已有方案 → 主体实际否定 → 主体另建方案”，仍可排除当前运行层的 nx，因此不能靠傲慢性格词判十元。

### 拿掉王平的反对

证据会略弱，但诸葛亮出发前已经明确给出要道下寨与商议要求；马谡仍然实际改变关键运行方式，所以核心结论仍在。

## 6｜反向测试

### 反向成 nx

如果马谡到街亭后按诸葛亮要求在要道下寨，与王平商议后执行，不主动改写下寨位置、兵力结构与关键流程，则当前行为明显向 nx 上升。

### 反向成更纯 xn

如果诸葛亮只给“守住街亭”这个抽象目标，所有下寨位置、兵力分配、协同方式、观察与回报节点都由马谡自行设计，则 xn 证据会更纯。

### 反向成 zx

如果马谡不只是重设战术，而是借此公开夺取此前不属于自己的更高军事决定范围，使诸葛亮和蜀军体系以后承认并围绕这一新增权限运行，才应锁 zx。

## 7｜最近邻排除

### nx vs xn

本轮是核心：

```text
别人给目标/方案，我沿着执行 → nx候选
别人已有方案，我主动否定并重组运行方式 → xn优先
```

### zx vs x

马谡已经拥有本次守街亭的主将指挥接口，但这是任务授权内已有的局部权限。正常调用或误用已有权限，不自动等于 zx 扩权。

### zx vs xn

马谡“重设山上屯军方案”首先解释的是运行结构重组，而不是决定范围扩大，因此优先 xn，不应因为他强势压过王平就转判 zx。

### nx vs xz

司马懿逼近、街亭危急属于外部危险压力，只解释为什么必须迅速部署，不解释谁拥有运行重设权。冻结危险后，马谡改写方案的事实仍然存在。

## 8｜第三因素冻结

冻结：

- 马谡傲慢、自负、熟读兵书；
- 诸葛亮知人善任与否；
- 街亭最终胜负；
- 王平能力高低；
- 军令状、生死处分；
- 蜀魏正邪与历史评价。

只保留：

```text
谁给最高任务？
谁给出已有运行约束？
主体有没有真实否决窗口？
主体有没有实际重设关键运行方式？
主体是否沿既有通道继续？
主体决定范围有没有扩大？
```

结论仍为：当前运行层伪 nx、伪 zx，xn 最近邻高显影。

## 9｜人物本体 / 状态 / 行为 / 关系分层

- 稳定人物本体：不锁。
- 当前状态：受外部任务约束，但主动重设关键运行方式。
- 行为功能：否定旧部署、重新选择位置、重新分配兵力与协同，偏 xn。
- 关系位置：最高任务仍来自诸葛亮；具体运行重设位置由马谡主动占据。
- 外部压力：司马懿、张郃逼近以及街亭战略重要性。

## 10｜与既有案例的最小差异

### 与刘备—庞统三策候选

刘备面对的是多个完整外部方案，拥有并使用最终选择权，但他最终仍从庞统的方案集合中选择中策，因此“外部完整方案 + 最终选择权”仍保留 nx 关系功能分叉。

马谡则更进一步：

```text
外部已有明确运行约束
→ 不只是选择其中一个
→ 而是直接否定并建立新的运行方式
```

因此本轮可以高置信支持：

> 实际重设方案，比“在外部方案中做最终选择”更强地排除当前运行层 nx，并提高 xn 最近邻。

### 与《水浒传》杨志押送生辰纲

杨志案例已锁：外部给最终目标，但杨志主动否定旧运输方案、重组人员与时间节点，故伪 nx、xn 高显影。

马谡提供第二部独立作品的同型支持，而且外部约束更明确：并非没有现成方法，而是主动替换现成方法。

当前同类边界跨作品支持数：2。
