# 《水浒传》鲁智深拒官｜zx-nx 木轴中间区反例

## 0｜结论先行

本桥段不能因为鲁智深明确拒绝宋江与朝廷提供的两条路线，就把“有自己的方向”直接判成 `zx`；也不能因为他仍处在宋江集团、朝廷班师与僧门身份这些既有结构中，就把他判成 `nx`。

最窄结论：

```text
外部提供两条高价值方向
→ 主体均能明确否决
→ 最终方向资格仍在主体手里
→ nx 不成立

但主体没有借此扩大现实决定范围
也没有迫使朝廷、宋江集团或僧门秩序围绕自己的权能重排
→ zx 不成立
```

因此本例锁定为 **伪 zx+nx 反例 / 木轴中间区**，只锁当前桥段，不锁鲁智深稳定人物本体。

本例与《西游记》唐僧女儿国构成第二个独立作品同型证据；尚未达到跨三部作品阈值，因此不建立“待审议问题”，不修改 L1 与十元核心定义。

## 1｜剧情事实

来源：施耐庵《水浒传》120回本第一百十九回《鲁智深浙江坐化 宋公明衣锦还乡》。原文可在维基文库核对。

### 触发

鲁智深生擒方腊后，宋江认为此功足以奏闻朝廷，先劝其还俗为官；在鲁智深拒绝后，又提供第二条路线：若不还俗，可进京住持名山大刹，做一僧首。

### 对象

- 鲁智深；
- 宋江；
- 朝廷功名／官职接口；
- 名山大刹住持／僧首接口；
- 鲁智深自己所选的“净了”去处与安身立命方向。

### 明确动作

1. 宋江提出“还俗为官”路线，并以功名、荫子封妻、光耀祖宗等现实收益说明其价值；
2. 鲁智深明确回答自己“不愿为官”，只求一个“净了”去处安身立命；
3. 宋江随即提供第二条外部路线：不还俗，也可进京住持名山大刹，成为僧首；
4. 鲁智深再次明确拒绝，表示这些都不要；
5. 宋江没有强行替他改写方向，桥段结束时鲁智深仍保留自己的去向判断。

### 结果

- 两条现实可行且社会价值很高的外部方向都被鲁智深否决；
- 没有证据表明最终方向被宋江、朝廷或僧门职位结构接管；
- 同时也没有出现鲁智深把自己的决定扩张成对他人、朝廷、军队或僧门秩序的统治与重排。

## 2｜四类候选判断

### 2.1 纯 zx：rejected

鲁智深在本段有明确判断、有拒绝能力，但“有主见”“敢拒绝”“不贪功名”都不是 `zx` 的充分条件。

现行 `zx` 准度要求主体自身权能公开显现并扩大，使他者、环境或等级秩序围绕其力量重新反应，并出现决定范围、影响位置或凌驾程度上升。

本段没有这些关键端点：

- 鲁智深没有夺取新的公开决定接口；
- 没有扩大对朝廷、宋江集团或僧门的处分范围；
- 宋江只是接受其拒绝，并非被鲁智深的扩张权能迫使重组秩序；
- 拒官只守住个人去向，不等于把个人权能压到外部系统之上。

因此：

```text
能够拒绝别人给的方向
≠ 公开扩权
≠ zx
```

### 2.2 纯 nx：rejected

本段虽然存在朝廷、宋江、班师流程与僧门职位等强大既有结构，但鲁智深并没有把最终去向资格交给它们。

关键事实：

- 宋江连续提供两条明确方案；
- 鲁智深对两条方案均拥有实际否决窗口；
- 他不是等待宋江替自己挑其中一个；
- 也不是沿着朝廷已给路线继续；
- 他明确给出自己的去向标准：“不愿为官”“只图寻个净了去处”。

因此：

```text
身处朝廷/军队/僧门结构
≠ 不占最终方向
≠ nx
```

### 2.3 zx+nx：rejected

本段没有形成“自身显权扩大 + 沿他者权限通道借力”的双端闭环。

鲁智深既没有借宋江或朝廷权限去实现自己的拒官方向，也没有把借来的资源重新转成公开扩权；两条外部路线反而被他直接否决。

### 2.4 压力显影 / 伪对子候选：confirmed

本段最适合作为木轴中间区压力样本：

```text
高价值官职方向出现
+ 高价值僧首方向出现
→ 主体均保留否决资格
→ nx 被排除

同时
→ 主体只守住个人去向
→ 决定范围没有向外扩大
→ zx 被排除
```

说明在 `zx ↔ nx` 同一变量两极之间，存在“主体保留最终方向资格，但未公开扩权”的合法中间区。

## 3｜木轴核心检查

### zx 检查

问题：主体是否把自身权能公开压入现实，并使他者或秩序围绕其力量重排、决定范围扩大？

本段答案：**否。**

鲁智深的动作是拒绝外部方向、守住自己去向；不是取得更高决定位置，也不是扩大对别人的决定权。

### nx 检查

问题：主体是否不占最终方向，沿他人、关系、权限、流程或现状给出的方向继续？

本段答案：**否。**

宋江连续给出两条现成路线，鲁智深均不沿用，而是保留并执行自己的否决资格。

## 4｜最近邻排除

### vs `xn`

本段没有主动排程、搭流程、设置节点、分配资源或通过等待组织行动。拒绝两条方案不能因为“做了决定”就写成 `xn`。

### vs `x`

鲁智深没有掌握、调用或处分朝廷官职系统与寺院住持资源；他只是拒绝进入这些已有位置，因此不是 `x`。

### vs `z`

宋江的肯定、朝廷可能给予的功名可以构成认可背景，但本段核心不在“重要主体确认鲁智深价值后他才成立”，而在他是否保留最终去向资格。

### vs `xz`

鲁智深说“心已成灰”“只得个囫囵尸首”等语言带有生命终局与窗口收窄色彩，可能在水轴上另有高密度意义。但冻结这些生死措辞以后，只保留“官职路线A / 僧首路线B / 主体均否决”，木轴中间区判断仍成立。因此 `xz` 不能替代本轮木轴结论。

### vs `nz`

出家、安身、归宿、净了等可在命运/关系回返空间上另作分析，但本轮不靠这些词判定，只看最终方向资格与权能扩张情况。

## 5｜拿掉测试

### 拿掉宋江个人身份

把宋江替换成任何能真实提供官职或僧首通道的中介，只要主体仍可以明确否决两条路线，`nx` 仍不成立。

### 拿掉“官职”的荣誉色彩

把第一条路线改成另一种高收益职业安排，只要外部方向真实可行，而鲁智深仍保留最终拒绝与另择去向资格，木轴判断不变。

### 拿掉“心已成灰”“囫囵尸首”等终局语言

只保留：

```text
方案A：还俗为官
方案B：住持名刹
鲁智深：A、B均拒绝，另保留自己的去向
```

则：

- `nx` 仍因最终方向资格未外置而不成立；
- `zx` 仍因没有公开扩权而不成立。

### 拿掉最终坐化结果

即使后续不发生坐化，只看本次选择节点，主体是否保留最终去向资格的证据已经成立；因此不能用结局反推本段分类。

## 6｜反向测试

### 反向成 nx

若鲁智深面对宋江两条路线时没有否决与重设资格，只能等待宋江或朝廷决定自己做官、住持或继续班师，然后沿被指定通道执行，则 `nx` 明显上升。

### 反向成 zx

若鲁智深拒官之后，不仅决定自己的去向，还以自身公开权能迫使宋江集团、朝廷授官体系或寺院秩序围绕他重排，取得更大的决定范围或凌驾位置，则 `zx` 才明显上升。

本段均未发生。

## 7｜第三因素冻结

冻结以下因素：

- 鲁智深很强、很能打；
- 生擒方腊的战功；
- 花和尚身份；
- 佛教悟道主题；
- 宋江是否喜欢功名；
- 朝廷官职高低；
- 后续是否坐化；
- “心灰”“囫囵尸首”等终局措辞；
- 作品对功名的价值判断。

剩余最小变量：

```text
外部真实提供方向A、B；
主体是否拥有否决/重设资格；
主体是否把自己的权能扩大到外部秩序。
```

答案：

```text
否决/重设资格：有 → 排除 nx
公开扩权：无 → 排除 zx
```

## 8｜人物分层

- 稳定本体：本轮不锁。
- 当前状态：最终去向资格高度保留。
- 行为功能：连续否决两条外部高价值路线。
- 关系位置：宋江可建议、朝廷可授职，但本节点没有取得鲁智深的最终去向决定权。
- 外部压力：不是强迫型压力，而是功名、地位与名刹住持等高收益诱因。

## 9｜与唐僧女儿国样本的最小差异

共同结构：

```text
外部给出高价值替代方向
→ 主体能真实否决
→ 最终方向资格留在主体
→ nx 不成立

主体只是守住自己的方向
→ 没有向外扩张决定范围
→ zx 不成立
```

差异：

- 唐僧：拒绝婚姻、王位与留国，继续既有西行使命；
- 鲁智深：拒绝官职与名刹僧首，不接受宋江给出的两个后续安置方向。

因此本轮不是复制同一作品同一角色，而是在第二个独立作品中复现同一边界。

## 10｜理论价值

本例继续支持案例级红线：

> **主体拥有最终方向资格，只能排除“方向已外置”的 nx；它不能自动证明“自身权能公开扩大”的 zx。**

以及：

> **拒绝外部安排 ≠ zx；身处既有制度 ≠ nx。**

## 12｜下一轮建议

优先在《三国演义》或《红楼梦》中寻找第三个独立作品的同型中间区：

- 外部给出真实可行方向；
- 主体拥有低成本或真实否决窗口；
- 主体明确保留最终方向资格；
- 但没有公开扩权、凌驾或扩大对他人的决定范围。

若第三个独立作品仍稳定复现，再形成“木轴中间区判定纪律”待审议问题，但仍不得直接修改 L1 或十元核心定义。
