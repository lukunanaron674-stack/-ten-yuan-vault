# 《三国演义》孙策借兵取江东｜zx↔nx 木轴压力测试

## 结论先行

本轮锁定一个高价值的 **zx→nx→zx 压力切换正例**：

> 孙策长期目标不是由袁术替他设定。他明确想继父志、离开“久困人下”的状态，并把图取江东作为自己的方向。问题在于，他当前缺少足够兵马，直接以自身权能完成该方向的能力不足。于是孙策不是放弃方向，而是进入袁术已有的兵权与军马资源接口，以传国玉玺作质，主动请求借兵。关键兵马与授予权限在袁术手里，因此这一段成立 nx 关系功能；借得三千兵、五百马及职位接口后，孙策立即把外部资源重新转成自己设定方向的行动，渡江扩张并最终取得江东地面，zx 再次高显影。

最小链：

```text
zx：自己要继父志、图江东，不愿久困人下
↓
直接权能缺口：当前兵力不足
↓
nx：以玉玺质当，进入袁术既有兵权/资源接口借兵
↓
获得三千兵、五百马及正式军职
↓
zx：立即领兵渡江，按自己的方向扩张并取得江东
```

这与现行 `zx补nx_补卡` 的双向机制高度吻合：

```text
nx 补 zx：补入外部权限接口、关系通道与非正面解决路径
zx 补 nx：把借到的资源与通道重新转成实际行动、公开决定与结果推进
```

## 1｜原始事实

### 触发：孙策有自己的方向，但被资源缺口卡住

第十五回写孙策在袁术席间受轻慢，回营后因想到父孙坚英雄、自己却“沦落至此”而痛哭。朱治随后直接提出：既然不愿“久困于人之下”，不如向袁术借兵，名义上救吴璟，实际图取大业。

这说明本轮的最终方向并不是袁术给的：

```text
继父志
+ 不愿久困人下
+ 图取江东大业
= 方向源仍在孙策自身
```

### 资源与权限缺口真实存在

吕范指出袁术未必肯借兵。孙策于是提出把亡父留下的传国玉玺作为质押物。

这一步不是普通“求建议”，而是承认一个明确事实：

```text
我有方向
但我当前没有足够兵马
关键军队资源掌握在袁术手里
```

### nx 关系功能：进入袁术既有兵权接口

孙策次日正式向袁术请求借“雄兵数千”，并以玉玺为质。袁术最终决定借兵三千、马五百，并给孙策折冲校尉、殄寇将军名义。

因此这一段的关键变量是：

```text
军马资源与正式授权不归孙策
→ 孙策必须经过袁术这一既有权力接口
→ 以玉玺作交换条件取得兵马和职位
= nx 关系功能
```

### zx 再显影：借来的资源被转回自己的方向

孙策并没有停留在“成为袁术的执行者”。借到兵马后，他随即带朱治、吕范、程普、黄盖、韩当等渡江起兵。到本回末尾，文本明确写到孙策“尽得江东地面”，并且袁术后来抱怨孙策“借我军马起事”。

这说明借兵并没有改写方向源：

```text
资源来自袁术
≠
方向来自袁术

资源借入
→ 被孙策重新纳入自己的征服方向
→ 公开扩大决定范围与现实影响
= zx 再显影
```

## 2｜为什么不是“孙策变成 nx 人物”

稳定 nx 本体要求主体长期不占最终方向、反复让别人决定路线。本段恰恰相反：

- 孙策不满久困袁术之下；
- 自己要继父志；
- 自己选择图江东；
- 借兵只是解决资源缺口；
- 借到资源后立即按自己的方向发动扩张。

因此必须分层：

```text
人物阶段主位：zx
中间办事路径：nx 关系功能
结果推进：zx 再显影
```

不能把“求人借兵一次”反推成稳定人物本体 nx。

---

## 3｜为什么这里的 nx 不是 xn

孙策和朱治、吕范确实有商议，但本段最关键的改变并不是：

```text
主体建立复杂排程、节点、流程和长期运行结构
```

而是：

```text
关键兵力资源与正式军权在袁术手里
→ 孙策通过既有政治/军权接口请求并取得
```

所以借兵环节优先判 `nx` 关系功能，而不是 `xn`。

后续渡江作战中当然可能出现 xn 组织行为，但不属于本轮最小证据链。

## 4｜为什么开头与结尾成立 zx

### 开头 zx 候选

孙策的核心问题不是“别人要我做什么”，而是：

```text
我不愿继续处在人下
我要继父志
我要取得自己的大业
```

这提供了明确的自身方向源。

### 结尾 zx 高显影

借兵后，孙策把外部取得的兵马转为自己主导的公开军事扩张，并在现实中扩大领地、影响与决定范围，最终取得江东地面。

满足现行 zx 准度卡关键条件：

- 主体自身方向明确；
- 权能进入公开现实；
- 他者与环境被迫回应；
- 决定范围与影响位置扩大；
- 不是仅仅照章执行袁术命令。

## 5｜拿掉测试

### 拿掉传国玉玺

若换成其他可让袁术愿意出借军马的关系、质物或交换条件，只要仍满足：

```text
兵马资源在袁术手中
→ 孙策必须通过袁术接口取得
```

中段 nx 关系功能仍成立。

所以玉玺是具体媒介，不是 nx 本体。

### 拿掉袁术的兵马所有权

若这些兵马本就归孙策自由调用，不需要袁术批准，那么借兵环节的 nx 会明显下降。

### 拿掉江东最终胜利

即使孙策渡江后未能最终占领江东，只要他仍把借来的军马公开用于自己设定的方向、迫使现实围绕其权能重新反应，后段 zx 仍可成立；胜利结果只提高显影，不是唯一判据。

## 6｜反向测试

### 反向A：纯 nx 版本

```text
袁术决定孙策去哪里、打谁、为何而战
→ 孙策只接受兵马和命令
→ 按袁术既定路线执行
```

这会显著提高 nx，降低 zx。

原作不满足。

### 反向B：纯 zx 版本

```text
孙策已有足够直属兵马
→ 无需袁术许可和资源
→ 直接渡江扩张
```

这会减少中段 nx，只剩 zx 直接路径。

### 反向C：xn 版本

```text
借兵不是关键
→ 重点改成孙策建立多阶段征伐排程、补给系统、节点和资源流程
```

此时应优先检查 xn。

## 7｜第三因素冻结

以下因素不直接判十元：

- 孙策年轻、勇猛；
- 袁术喜欢孙策；
- 孙策有传国玉玺；
- 孙策是将领；
- 孙策最后打赢；
- 孙坚是其父；
- 袁术授予正式官职；
- 孙策有野心。

真正支持本轮结构的证据只有：

```text
最终方向仍由孙策自己生成
+
兵马与正式军权接口外置于袁术
+
孙策主动通过该既有接口借力
+
借到资源后重新按自己的方向公开推进并扩大决定范围
```

## 8｜与孙悟空红孩儿阶段的跨作品复验

两条链的表面题材完全不同，但木轴结构一致：

```text
《西游记》孙悟空：
zx 正面降妖
→ 自身权能被三昧真火卡住
→ nx 找龙王/观音借外部权限与能力
→ zx 按新接口重新诱敌、推进结果

《三国演义》孙策：
zx 自己要图江东
→ 自身兵力不足
→ nx 向袁术借兵、借正式军权接口
→ zx 把借来的军马重新转成自己的江东扩张
```

共同母型：

> **强 zx 主体在直接权能不足时，可以暂时调用 nx 关系功能取得外部权限、资源或能力；只要最终方向没有外置，获得接口后又重新由主体公开推进，人物主位并未因此变成 nx。**

目前跨作品支持数为 2，尚不足以形成新的正式待审议问题；继续寻找第三部独立作品复验。
