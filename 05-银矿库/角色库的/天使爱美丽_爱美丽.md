# 爱美丽（Amélie Poulain）
> 归档：`05-银矿库/角色库/天使爱美丽_爱美丽.md`

---

## 1. 主十元判断

**主十元：nz（阴土·柔情停靠）**

**五问法核验：**
- **第1问（拿掉什么他不是她）：** 拿掉nz，爱美丽就是一个爱搞小动作的怪女孩——她帮邻居、整水果摊老板、偷父亲的公仔——这些事zx的人也会做。但她做这些事的底层不是「我想改变世界」（zx），不是「我在计算因果」（nx），是她**见不得别人觉得「不被在乎」**。那个在窗台上种草莓的姿势、偷偷帮楼下盲人过马路时描述街景的语气——那是她把自己的温柔偷偷塞到别人口袋里。她做所有事的理由都是一个：**让某个人觉得世界上还有人挂念他**。
- **第2问（反复面对什么结构）：** 反复面对「我想靠近你，但我不敢」。她对尼诺的感情不是「我一定要追到他」——她是绕着圈子递线索、藏照片、让他猜。她不是不敢爱，她是怕爱了之后那个人不在她身边。nz的人最典型的动作就是：**先给，然后退一步观察**。
- **第3问（最怕失去什么）：** 最怕「一个人待着也没人注意到」。所以她做那么多事——不是为了被感谢，是为了证明自己和世界之间还有一根线牵着。
- **第4问（回到哪个感觉）：** 回到「我也能被接住」的感觉。电影最后尼诺推开她家门那一下——她不是赢了，是发现自己也有人愿意等。
- **第5问（副十元服务谁）：** z（执念/被看见）是nz的发动机——她的nz想做很多温柔的事，但没有z的推动她会永远停在「想」的阶段。z帮她跨出去。

## 2. 副十元

**副十元：z（阴火·执念/被看见）**

**作用：** 爱美丽不是被动等别人好的类型——她主动出击，但出击的方式是温柔的、悄悄的。z让她有执行力，但她的执行力永远在为nz服务。

## 3. 功能十元

**功能十元：无显著。**

## 4. 视觉十元

**视觉十元：无显著。** 她的造型是电影美学的一部分，不是她的人物定义。

## 5. 动态链

```
nz（主·见不得有人觉得自己不被在乎）
  → z（副·推动她执行那些温柔的计划）
  → 帮盲人过马路→整水果摊老板→给尼诺留线索
  → 自己躲起来看结果
  → 尼诺推开门——她被接住了
```

## 6. 一句话定型

爱美丽不是「帮别人找到幸福的天使」，而是「**偷偷往别人口袋里塞温柔，然后假装什么都没发生**的人」。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**新定位：** nz（主·柔情停靠）+ z（副·执念）→ 命运型
**修正理由：** 旧卡把爱美丽定位为「每一个善举带来连锁反应」的因果型。但爱美丽做那些事的时候不算因果账——她不关心对方会不会回报她，她甚至不希望对方知道是她做的。她做只是因为「见不得那个人难过」。这是nz（想让别人感觉到被在乎），不是nx（暗算/结算）。
