# 《西游记》孙悟空被逐前后｜zx-nx 行动者调用边界灰区压力测试

## 0｜本轮问题

上一轮已形成两端：

- 猪八戒请已离队的孙悟空回援：对方拥有真实“是否出手”决定权，必须请求/激将，锁 `nx` 外部行动者关系功能。
- 诸葛亮北伐点将：诸将军务行动处于既有军令调用边界，优先 `x + xn`，排除“用了别人能力就算 nx”。

本轮检查同一孙悟空在关系断裂前后，行动能力调用边界是否发生结构变化。

## 1｜剧情事实

### A｜被逐前：第二十七回白虎岭化斋

唐僧直接要求悟空去化斋。悟空先说明荒山无人家，但在唐僧继续要求后接受任务，自行寻找替代食物并离队摘桃。此时“为师父寻找食物、继续护送西行”仍处于既有师徒/取经角色关系中。

### B｜关系断裂：第二十七回逐走

唐僧随后明确表示不要悟空再做徒弟，关系处分发生，悟空最终离开取经队伍回花果山。

### C｜被逐后：第三十一回重新求援

唐僧遭黄袍怪之难后，八戒必须前往花果山重新请求悟空。悟空起初并非处于可被直接命令回队的位置；八戒需要说明灾情并使用激将，悟空最终自己说“我和你去”，且八戒明确表示报仇后“来与不来，任从尊意”。

## 2｜触发、对象、动作、结果

- 触发：师徒关系从成立到被正式解除。
- 对象：孙悟空的“是否承担取经队行动任务”这一行动调用界面。
- 被逐前动作：唐僧直接提出任务要求，悟空在既有角色关系中承接并自行组织执行。
- 被逐后动作：八戒无法直接调用，必须重新请求/说服；孙悟空保留是否回援的明确选择资格。
- 结果：文本强烈支持“关系断裂后调用接口外置”，但“关系成立时该接口是否已达到 `x` 的稳定调用边界”仍有真实分叉。

## 3｜zx 判断

本轮不锁高纯 `zx`。

理由：

- 被逐前执行化斋任务，没有新增决定范围。
- 被逐后选择回援，也只是恢复/重新进入行动，不等于公开取得新的更高决定范围。
- 悟空的战斗能力与齐天大圣稳定 zx 锚不得倒灌替本轮回答“调用边界归谁”。

结论：`zx_in_narrow_stage: rejected_as_primary`。

## 4｜nx 判断

### 被逐后

证据很硬：

- 悟空已离开原取经队伍；
- 八戒必须进入旧师兄弟关系请求/激将；
- 悟空本人保留真实拒绝和重新加入的资格；
- 八戒不能把悟空当作稳定可直接调用的人力资源。

因此“被逐后外部行动者 `nx`”与既有猪八戒案例一致，本轮不重复制造新锚。

### 被逐前

这里存在真正分叉。

支持 `x-like 调用边界`：

- 师徒/取经角色已经成立；
- 唐僧可以直接提出任务，不需要像八戒第三十一回那样重新求援；
- 悟空接受任务后自行组织执行，类似“组织内任务调用 + 局部 xn”。

反对直接锁 `x`：

- 孙悟空仍是具有强独立意志的人，不是普通资源对象；
- 文本中他会争辩、拒绝判断、甚至违逆唐僧的具体判断；
- 师徒关系中的“可直接分配日常任务”是否足以等价于 nx 卡所说“调用边界归我掌握”的 `x`，正本目前没有压到足够窄。

因此只能写：`pre_expulsion_role_call_boundary: candidate_x_like`，不能正式锁 `x`。

## 5｜最近邻排除

### x vs nx

本轮核心。

- `x` 候选：关系内部已有稳定任务调用边界，不必每次重新请求对方加入。
- `nx`：对方仍作为外部独立节点保有“我帮不帮你”的重新批准权，主体只能通过关系请求。

### xn

悟空被逐前接受化斋任务后，自己判断无人家、改为摘桃，这是局部运行组织；它解释“怎么完成”，不决定“唐僧是否有任务调用边界”。

### nz

师徒感情、旧恩解释关系维持和回援动机，但不能替代“行动调用接口是否内置/外置”的权限问题。

### zx

齐天大圣、战斗、强势均冻结，本轮不以能力强弱判木轴。

## 6｜拿掉测试

### 拿掉紧箍咒

如果只保留师徒角色与日常任务分工，唐僧仍能提出“去化斋”这类任务，因此被逐前并非完全靠强迫建立调用。

但拿掉紧箍咒后，也更能看出悟空保留真实自主性，故不能据此把整个人格/全部行动处分写成 `x`。

### 拿掉师徒关系

若两人从未形成师徒/取经角色关系，唐僧要悟空去化斋就更接近对独立行动者请求，`nx` 外部接口明显上升。

### 拿掉正式逐走

如果悟空仍保持取经队成员身份，第三十一回八戒就未必需要重新去花果山请他，说明“关系解除”确实改变了行动接口可达性。

## 7｜反向测试

### 真 x 版本

若文本明确显示：在师徒关系内，唐僧对悟空承担的护送/侦察/化斋等职责具有稳定指派权，悟空不能在该职责层重新决定“是否承担”，只可决定“怎样完成”，则可正式锁“角色任务层 x + 局部 xn”。

### 真 nx 版本

若即使师徒关系尚在，唐僧每次需要悟空行动都必须重新请求，悟空可低成本拒绝是否出手，而不是仅对方法与判断争辩，则应判为持续外部行动者 `nx`，不存在 x-like 内置调用。

## 8｜第三因素冻结

冻结：

- 孙悟空是否忠义；
- 唐僧是否苛刻；
- 紧箍咒强迫；
- 黄袍怪强弱；
- 最终是否救回唐僧；
- 齐天大圣稳定 zx 锚；
- 师徒感情浓度。

只保留：

`关系角色是否成立 → 任务是否可直接分配 → 对方是否还需要重新批准“是否行动” → 关系解除后接口是否外置`。

## 9｜最小分歧点

> **“组织/关系内可以直接分配日常任务”是否已经足以构成 `x` 的行动调用边界？**

当前正本对军令、资源、权限已有较清晰 `x` 边界，但对具有独立人格的关系成员，其“职责调用权”与“本人最终行动同意权”可能同时存在不同对象层。

因此分类置信度锁 94%，保留 `candidate/deferred`。

## 10｜结论

```text
被逐后：
孙悟空明确成为需要重新请求的外部行动者
→ nx 关系功能证据硬

被逐前：
已有师徒/取经角色使日常任务可以直接分配
→ x-like 调用边界候选
但孙悟空仍保留强自主性
→ 尚不足 95% 正式锁 x
```

本轮不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
