# 《水浒传》宋江征辽｜zx↔nx 木轴压力测试

## 结论先行

本轮锁定第三个独立作品中的同型 `nx` 边界反例：

> **外部给出上位目标、职责或任务，不等于主体已经进入 `nx`。若外部只规定“要做什么”，而具体“怎么做、如何拆路线、怎样配置人员资源、如何设置节点与协同方式”主要由主体主动建立，则应优先检查 `xn`，不能把“受命办事”偷换成“沿既有通道续接”。**

第八十三回中，朝廷确实给宋江下达了明确上位目标：领军征辽。但抵近辽境后，宋江并没有得到一套现成的完整作战通道。他主动与吴用讨论“分兵还是攻城”，接受“不分兵、先攻城池”的方案；随后询问熟悉北路的段景住，确定檀州及潞水条件；再命戴宗催促水军，约定日期，组织水陆并进。

因此本段不是：

```text
朝廷下诏征辽
→ 已经把路线、分兵、目标城、水陆协同全部规定好
→ 宋江只照既定流程执行
= nx
```

而是：

```text
朝廷给上位战争目标
→ 宋江进入现场后主动确定解决方式
→ 讨论分兵/攻城方案
→ 选择檀州为当前突破点
→ 调集水军、约定日期、水陆协同
→ 运行通道由宋江集团主动组织
= nx 排除，优先 xn
```

本轮只锁 `nx_rejected_in_narrow_stage`，不把宋江稳定人物本体直接锁成 `xn`、`zx` 或其他十元。

## 1｜原始事实

### 触发

辽军入侵，朝廷最终下诏，任命宋江为破辽都先锋、卢俊义为副先锋，要求宋江等领军征辽。

### 宋江的明确动作

抵近辽境后，本回连续出现以下可观察动作：

1. 宋江主动提出当前核心方案问题：面对辽兵四路侵犯，是分兵征讨，还是集中攻城；
2. 吴用提出不要分兵，优先攻取城池，以迫使辽军收兵；宋江明确采纳该方案；
3. 宋江再询问熟悉北路的段景住，取得前方檀州、潞水和水路条件信息；
4. 根据段景住提供的地形与水军需求，宋江立即命戴宗催促李俊等水军到潞水会合；
5. 宋江整点人马与船只，约定日期，组织水陆并行进军檀州。

### 可观察结果

- 朝廷只给出“征辽”这一上位目标，并未在本段直接给出完整战术运行方式；
- 分兵与否、先攻何处、水军何时到位、水陆如何协同，均在宋江集团现场讨论和组织；
- 具体运行方式不是简单延续一个朝廷已给的既有通道；
- 宋江实际进入了方案选择、资源调动、时间节点和协同组织位置。

## 2｜为什么这是伪 nx 反例

现行 `nx` 要求的核心不是“别人给过命令”，而是：

```text
方向、权限或解决通道已经存在
→ 主体不主动改写
→ 不占最终决定、否决与重设问题的位置
→ 沿既有关系、流程、秩序或现状续接
```

宋江本段确实接受朝廷给出的上位目标，但并没有沿一个已经完整给定的作战通道机械续接。

真正被重新建立的是“目标如何转成可运行行动”的中间结构：

```text
征辽
→ 是否分兵
→ 先攻城池
→ 选择檀州
→ 判断潞水水军需求
→ 催水军到位
→ 约定日期
→ 水陆并进
```

这套运行方式的建立更接近 `xn` 的组织计划、资源、步骤、节点和持续推进，而不是 `nx` 的“不占最终方向、沿已有通道继续”。

因此：

> **外部给“上位目标”不等于外部给“完整运行通道”。**

---

## 3｜关键压力与第三因素冻结

本段必须冻结：

```text
皇帝诏令
+ 宋江已经接受招安
+ 宋江拥有都先锋职权
+ 军事行动本身存在上下级命令
```

这些因素能解释“为什么必须征辽”和“为什么宋江有合法调兵位置”，但不能直接证明 `nx`。

真正要检查的是两个不同层次：

```text
谁给上位任务？
≠
谁建立具体运行方式？
```

如果把二者混为一谈，任何军队、企业、官僚体系中的下级执行者都会因为“上面给目标”而被粗暴归入 `nx`，从而吞掉大量本应属于 `xn` 的主动组织行为。

---

## 4｜zx 在本段的位置

本段存在 `zx` 局部候选，但不作为主结论。

支持候选的地方：

- 宋江拥有公开军事决定位置；
- 其决策直接改变大军行动方向；
- 他能够调动戴宗、水军和整支军马进入新行动。

但本段最强的可观察变量仍然是：

```text
方案选择
+ 分兵判断
+ 路线选择
+ 人员与兵种配置
+ 会合日期
+ 水陆协同
```

所以优先归 `xn`。不能因为“统帅”“调兵”“打仗”这些表面词就直接判 `zx`。

---

## 5｜最近邻排除

### nx vs xn

```text
nx：上位目标之后，具体通道也主要由外部既定，主体沿着继续。
宋江本段：上位目标由朝廷给，但具体作战通道由现场主动组织。
```

所以 `nx` 在这一窄阶段排除，`xn` 高显影。

### nx vs zx

若本段核心是宋江公开扩权、压服他者、让秩序围绕自身权能重新反应，才应以 `zx` 为主。实际文本重心更集中在如何把任务组织成可运行军事结构，因此 `zx` 只保留局部候选。

### nx vs x

先锋职权与军队调用权不自动等于 `x`。本轮不讨论宋江是否长期掌握这些资源，只判断征辽任务下具体运行通道的生成方式。

## 6｜拿掉测试

### 拿掉“皇帝诏令”

只保留以下动作：

```text
面对四路敌军
→ 主动判断是否分兵
→ 选择攻城路径
→ 调查前方地形
→ 调集水军
→ 约定会合日期
→ 组织水陆并进
```

主动组织运行结构仍然清楚成立。因此本段的 `xn` 证据不依赖“奉诏”本身。

### 拿掉“都先锋身份”

换成任何获得临时指挥窗口的人，只要其仍实际完成方案拆解、资源配置和节点组织，也仍不能仅因上位目标来自别人就判 `nx`。

### 拿掉最终胜负

即使最终攻打檀州失败，只要上述运行方式确实由主体主动建立，`nx` 排除仍成立。胜负不是本轮十元判据。

## 7｜反向测试

如果改写成：

```text
朝廷诏令已经逐项规定：
- 不得分兵
- 必须先打檀州
- 戴宗何时催水军
- 李俊何日到潞水
- 水陆何日并进

宋江只负责逐项照办
```

那么 `nx` 会明显上升。

或者：

```text
宋江每遇到路线、兵种、会合日期问题都不自行组织，
只等待朝廷下一道具体指令。
```

也更接近 `nx`。

原文与这两种反向版本明显不同。

## 8｜跨作品复验：达到待审议门槛

此前已有两个独立作品的同型证据：

```text
《三国演义》诸葛亮：
刘备给上位职责/目标
→ 五路危机的具体处理方式由诸葛亮主动组织
→ nx 排除，优先 xn

《红楼梦》探春：
王夫人给协理职责
→ 旧支出、分工、收益与回流接口由探春主动重组
→ nx 排除，优先 xn
```

本轮加入：

```text
《水浒传》宋江：
朝廷给征辽目标
→ 分兵判断、攻城路径、兵种调度、日期与水陆协同由现场主动组织
→ nx 排除，优先 xn
```

因此同一边界已跨 3 部独立作品稳定复现：

> **外部给上位目标／职责，不等于 `nx`；判断 `nx` 必须继续追问“具体运行通道是否也由外部既定”。若主体接到目标后主动建立计划、流程、节点、人员或资源组织方式，则优先检查 `xn`。**

### 待审议问题｜pending

建议后续审议 `nx` 准度卡时，把以下边界句作为候选强化项，而非立即改核心定义：

```text
“上位目标/职责来自外部”只能证明任务来源外置，不能单独证明 nx。
必须继续检查：具体解决通道、运行方式与否决/重设位置由谁建立。
若主体主动建立计划、流程、节点、分工或资源配置，则优先检查 xn。
```

当前只形成 `pending` 待审议问题，不修改 L1、zx/nx 信息卡或准度卡。
