# 三国演义｜关羽受印守荆州｜zx-nx 分层授权压力测试

## 结论摘要

本桥段锁定一个此前授权案例尚未充分覆盖的中间结构：**主体确实获得了一块可独立调用的局部实际权限，但任务的最高战略方向与边界仍由外部主体给定。**

刘备先把荆州托付给诸葛亮并让其量才委用；诸葛亮据刘备书意选择关羽，正式交割印绶，并配置马良、伊籍、向朗、糜竺、糜芳、廖化、关平、周仓等文武辅佐关羽同守荆州。由此，关羽取得的不是薛宝钗式“只能照看、冲突仍须回报”的弱代理位置，而是荆州守备范围内真实、可运行的统辖接口。

但同一桥段又明确显示：**“守住荆州”这一最高任务方向不是关羽自建；面对曹操、孙权两面压力时，诸葛亮进一步给出“北拒曹操，东和孙权”的战略约束，关羽明确接受。** 因此，在“荆州守备的最高战略方向”这一对象层，关羽处于 `nx` 关系位置；在“荆州本地文武、守备资源与日常统辖”对象层，则出现真实 `x` 邻近。

本轮不锁 `zx`。理由不是关羽没有新增权限，而是第六十三回这个交接截面尚未出现足够独立的“关羽自身权能公开扩张、迫使外部秩序围绕其个人力量重新反应”的 zx 硬证据。**被授予真实局部权限，不等于授权发生这一刻就自动成为 zx。** 若后续关羽以该权限主动扩大原战略边界，应另切阶段重新判断。

本轮不锁“关羽稳定人物本体 = nx/x/zx”，也不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实、触发、对象、明确动作和结果

### 触发

刘备入川后，需要安排荆州留守。刘备书中把荆州托给诸葛亮，并让诸葛亮自行选择适任者。诸葛亮从刘备遣关平送书这一动作判断，刘备实际希望关羽承担荆州重任。

### 对象与原始权限

```text
最高任务来源：刘备集团既定的“保守荆州”
战略边界设定：诸葛亮代表当前最高战略接口提出“北拒曹操，东和孙权”
荆州印绶与本地统辖接口：交割后真实交给关羽
荆州文武辅佐体系：被配置到关羽守备体系下
```

### 明确动作

1. 诸葛亮公开说明刘备托付荆州并选择关羽承担重任。
2. 关羽不推辞，明确领诺。
3. 诸葛亮设宴交割印绶，关羽双手接印。
4. 诸葛亮询问曹操来攻、曹孙齐攻时如何应对；关羽先提出自己的军事回答。
5. 诸葛亮否定“两面分兵硬拒”的方案，提出“北拒曹操，东和孙权”八字战略。
6. 关羽明确表示接受并牢记这一战略约束。
7. 诸葛亮正式给印，并配置一批文武辅佐关羽同守荆州，自己随后率兵入川。

### 结果

关羽获得了荆州守备范围内真实的局部统辖权，但并没有因此成为刘备集团最高战略方向的来源。局部权限归属与最高方向来源被同一桥段明确拆开。

## 2｜zx / nx / x 分类

### A. nx：锁在“最高战略方向”关系位置

关羽并非纯 nx 人物。他在面对曹操、孙权问题时立即提出自己的军事判断，说明并不是没有主见。

但就本轮严格对象“荆州守备的最高任务与外交方向”而言：

```text
守荆州：外部既定任务
↓
诸葛亮进一步给出“北拒曹操，东和孙权”
↓
关羽接受这一战略边界
↓
在该层不占最终重设位置
= nx关系位置 / 当前行为功能
```

锁定：

- `nx_strategic_direction_relation_stage: evidence-locked`
- `pure_nx_essence: rejected`

这里的 nx 不是“听军师一句话”本身，而是：**最高方向与战略边界属于刘备集团既有决策接口，关羽作为受托守备者沿此方向运行。**

### B. x：锁为局部真实权限最近邻

与薛宝钗“受托照看大观园”不同，本段的关羽不是只有观察、提醒和回报权。

诸葛亮把印绶正式交给关羽，并将一批文武人员配置给他同守荆州。交接完成后，荆州守备范围内存在一块真实、可以由关羽调用的统辖权限。

因此：

- `x_local_command_authority_neighbor: evidence-locked`

这说明：

> **同一主体可以在一个对象层拥有实际权限（x），同时在更高战略对象层仍处于外部方向接口之下（nx关系位置）。**

不能因为局部有权就把最高方向也自动算成自己的；也不能因为最高方向来自上级，就把主体所有局部权限都抹成 nx。

### C. zx：本桥段不锁

表面诱饵很强：

```text
关羽受印
→ 成为荆州主将
→ 决定范围扩大
→ zx？
```

但现行 zx 准度卡要求的不只是“新拿到权限”，还要看到主体自身权能公开进入现实、使他者或秩序围绕其力量重新反应，并形成位置/决定范围的扩张显影。

第六十三回交接截面里，最明确的因果仍是：

```text
刘备/诸葛亮选择并授权
→ 关羽受印承接
→ 文武被配置给他守荆州
```

此处足以证明“权限真实交割”，却不足以独立证明“关羽自己的权能正在公开扩张并压过原有秩序”。因此：

- `zx_in_handover_stage: rejected_as_primary`
- `delegated_real_authority_not_automatic_zx: evidence-locked`

若后续出现关羽主动突破既定战略边界、以自身权能让荆州或外部势力重新围绕其个人决定运行，应另切时间片判断，不能倒灌进本轮。

## 3｜关键压力

关键压力是**授权层级不一致**：

```text
最高战略方向：仍在刘备集团外部接口
局部守备统辖权：真实交给关羽
```

因此本轮不是简单的“有权/没权”二分，而是检查：

> 权限究竟在哪一个对象层属于谁？

这一压力能够检验木轴判定是否会错误地把一个复杂授权关系压成单一标签。

## 4｜拿掉测试

### 拿掉“关羽名将/武圣”光环

只保留：

```text
上级给定守备任务与战略边界
+ 正式交割本地印绶和人员统辖权
```

仍然得到“战略层 nx + 局部 x”结构。人物威名不是判据。

### 拿掉“印绶”这个象征物

只要仍能证明本地文武、守备事务已由关羽实际统辖，局部 `x` 仍成立；因此不是看见印章就机械判权力。

### 拿掉“北拒曹操，东和孙权”八字原句

只保留“刘备集团把守荆州作为既定任务交给关羽”，战略方向外置仍存在；但外交边界证据会变弱。因此八字战略是本轮 nx 关系位置的重要加强证据。

### 拿掉局部统辖权限

如果关羽只被要求“帮忙看守”，任何不服从都必须回报诸葛亮或刘备才能生效，那么案例会退化为更接近宝钗式纯代理 nx；本轮新增的“局部 x”层会消失。

## 5｜反向测试

### 反向成周瑜式 zx

若关羽受印以后立即以新增军权公开重设原本不属于他的战略范围，使刘备集团或荆州文武必须围绕他自己新建立的最高方向运行，并且该边界得到现实承认，则 zx 上升。

### 反向成宝钗式代理 nx

若关羽只负责观察与传话，发生军政冲突时仍须逐项回报诸葛亮、没有独立调动荆州文武的权限，则局部 `x` 消失，nx 关系位置会覆盖更多对象层。

### 反向成纯 x

若“守不守荆州、如何处理曹孙关系、是否改变整个战略”全部都由关羽独立长期处分，上级不再保留方向边界，则应主要检查 `x/xn/zx`，而不是本轮战略层 nx。

## 6｜最近邻排除

### nx vs xn

关羽后续守备必然涉及排兵、调将、守城和节点组织，这些可出现 `xn`。

但本轮只看交接时的最高战略方向：`守荆州 + 北拒曹操、东和孙权` 由外部决策接口给出，关羽承接。拿掉任何具体排程与战术细节，这一 nx 关系位置仍成立。

### nx vs x

本轮最重要的不是二选一，而是分对象层：

```text
战略方向来源：外部 → nx关系位置
本地守备统辖：交割后归关羽 → x邻近
```

如果不写对象层，很容易出现两种反向错误：

- “关羽有印，所以一切都是 x/zx”；
- “关羽受刘备命令，所以一切都是 nx”。

两者都过度压扁文本。

### zx vs x

`x` 只需证明这块权限已经归主体掌握；`zx` 还要求看见主体自身权能公开扩张并让现实围绕其力量重新排列。

本轮可以锁“局部权限真实转移”，但没有足够独立证据锁交接截面的 zx。

## 7｜第三因素冻结

冻结以下因素后，结论不变：

- 关羽武力；
- 桃园结义；
- 关羽后来的荆州得失；
- 后世忠义/武圣评价；
- 刘备是否偏爱关羽；
- 诸葛亮是否判断正确；
- 官职名号和印绶的象征意义；
- 最终败走麦城的结局。

只看：

```text
谁给最高任务？
谁能重设战略边界？
本地人员和守备权限是否真实交割？
关羽在本截面是否用自身权能进一步扩大了最高决定范围？
```

仍得到：

```text
战略层 nx关系位置
+ 局部 x真实权限
+ zx在交接截面不锁
```

## 8｜对象分层

```text
稳定人物本体：不锁
当前状态：受托成为荆州守备主将
行为功能：接受战略方向、承接本地统辖
关系位置：最高战略方向仍在刘备集团；局部守备权限已交给关羽
外部压力：曹操、孙权两面威胁与刘备集团入川后的留守缺口
```

## 9｜与现有授权案例的最小差异

### 宝钗受托照看大观园

```text
有管理任务
↓
但“不听以后怎么办”仍须回王夫人
↓
最终处分接口未转移
= nx关系位置 / 伪zx
```

### 关羽受印守荆州

```text
最高守备战略来自刘备/诸葛亮
↓
但荆州本地印绶、文武统辖真实交割
↓
战略层仍nx，局部权限已x
↓
交接本身仍不足以锁zx
```

### 周瑜受剑拜都督

```text
授权前必须经过孙权
↓
完整军令处分接口真实转移
↓
周瑜立即公开独立调用
↓
军中围绕新接口重排
= zx当前状态上升
```

三者因此形成一个案例级连续谱：

```text
宝钗：任务授权，但最终强制接口不转移
→ 关羽：真实局部权限转移，但最高战略方向仍外置
→ 周瑜：新增权限真实转移，并立即公开扩张运行
```

这个连续谱目前只作为案例级判定工具，不修改 L1。

## 10｜严格 zx↔nx 补关系检查

本轮不锁严格补关系。

理由：战略层 nx 与局部 x 可以同时成立，但本轮没有证明 `zx` 端独立成立，更没有通过 `zx补nx_补卡` 要求的“双端各自有缺口、补回后可重复改善”的拿掉测试。

因此：

- `strict_zx_nx_complement_locked: false`

## 11｜案例级判定纪律

本案支持但不升级正本：

> **木轴必须按对象层切权限。主体在局部拥有真实权限，不意味着最高方向也归主体；最高方向来自外部，也不意味着主体所有局部行为都是 nx。**

> **“真实授权”仍需继续区分：局部权限转移、最高方向转移、以及主体自身权能公开扩张，是三个不同问题。**

当前只有这一轮专门锁定“局部 x + 战略 nx”的授权灰区，不达到跨三部作品待审议阈值，因此不新建待审议问题，不修改 L1、信息卡、准度卡或补卡。
