# 《三国演义》刘备投刘表至托孤：zx-nx 关系通道退出压力测试

## 0｜结论先行

本轮只检查刘备与刘表这一条关系，在两个明确阶段是否仍承担同一种木轴功能。

```text
第三十一回：
刘备败走、缺少安全落脚与地盘
→ 主动投奔刘表
→ 刘表掌握荆州接纳、住所与驻屯资源
→ 刘备沿既有宗亲/政治关系取得庇护
= nx 关系功能高显影

第四十回：
刘表病危
→ 主动请刘备托孤，并提出死后可自领荆州
→ 刘备拒绝把关系转成自领荆州的资源取得
→ 承诺辅佐刘表之子
= 当前关系不再以“刘备借刘表解决自身缺口”为主
= 对刘表这条关系的 nx 解决通道功能退出
```

本轮锁的是：**关系本身不会永久继承 nx。只有当当前事件里，对方仍是主体所需的外部方向、权限、资源或解决接口时，关系 nx 才成立。**

---

## 1｜剧情事实

### 阶段A｜投刘表

刘备在汝南失利后前往荆州投奔刘表。刘表不顾蔡瑁反对，决定接纳刘备，亲自出郭迎接，安排院宅居住；后续又使刘备屯新野。

对象与权限结构：

```text
刘备当前缺口：安全落脚、驻屯空间、政治庇护
刘表掌握：荆州接纳权、住所、驻屯与地方资源
刘备动作：投奔、接受安置
结果：取得在荆州/新野立足条件
```

因此这一阶段不是“认识刘表所以 nx”，而是**刘表确实承担了刘备无法独立取得的外部庇护/驻屯接口**。

### 阶段B｜刘表病危托孤

第四十回刘表病危，主动请刘备来托孤，并提出自己死后刘备可以自领荆州。刘备没有把这次关系行为转成“继续从刘表那里取得地盘”的路径，而是明确拒绝自领，表示愿尽力辅佐刘表之子。

此时关系方向发生反转：

```text
不是：
刘备有缺口
→ 刘表提供外部解决接口

而是：
刘表临终有托付与继承危机
→ 刘备成为被托付者
→ 刘备承诺维护刘表后续家族/政治安排
```

因此，不能因为“还是刘备—刘表这条关系”就把第三十一回的 nx 标签机械继承到第四十回。

## 2｜nx 判断

### 阶段A

`nx_relation_function_toward_liu_biao_in_refuge_stage: evidence-locked`

符合 nx 关系功能：

```text
自身不能直接解决当前落脚/庇护缺口
→ 外部资源和许可属于刘表
→ 进入既有关系/政治网络
→ 请求并接受安置
→ 沿该外部接口继续
```

### 阶段B

`nx_relation_function_toward_liu_biao_in_deathbed_stage: rejected_as_primary`

刘表此时不是刘备借用来解决自己当前缺口的接口，反而是提出托孤与让州的一方。刘备拒绝自领荆州，并把关系行为落到“辅佐其子”的承诺上。

所以：

> **过去曾通过这个人取得庇护，不等于后来每一次与这个人的往来都还是 nx。**

必须重新问：

```text
当前事件里，我究竟在借用他的权限/资源解决自己的问题，
还是在维护、回报、承接、保护这条关系本身？
```

---

## 3｜zx 判断

结论：`zx_in_narrow_stage: rejected_as_primary`。

阶段A投刘表显然没有新增公开扩权；阶段B刘备拒绝自领荆州，也不能因为“有自己的判断、敢拒绝”就判 zx。

现行 zx 要求：

```text
自身权能公开进入现实
+ 他者/秩序被迫重排
+ 主体决定范围或凌驾位置真实扩大
```

本轮核心只是关系功能发生变化，没有足够证据证明刘备因此取得新增决定范围。

---

## 4｜关键压力

阶段A压力：曹操军事追击、刘备缺少稳定地盘与安全驻屯点。

阶段B压力：刘表病危、继承与托孤问题逼近。

压力只负责让关系功能显影，不直接判十元：

- 败走本身不等于 nx；
- 病危、托孤本身不等于 nz；
- 拒绝荆州本身不等于 zx。

---

## 5｜拿掉测试

### 拿掉宗亲称谓

即使不强调刘备、刘表同宗，只要刘表仍掌握刘备所缺的接纳与驻屯接口，阶段A nx 仍成立。

### 拿掉“刘表让荆州”这一高价值资源

只保留“刘表病危托孤，刘备承诺辅佐其子”，阶段B仍然不是刘备通过刘表解决自己的资源缺口，nx 关系功能仍不应成为主判。

### 拿掉刘备仁义评价

只保留动作事实：早期投奔并接受安置；后期拒绝自领并承诺辅佐。结论不依赖“仁义”人物标签。

---

## 6｜反向测试

### 阶段B反向成真 nx

若刘备在刘表病危时再次处于严重资源/安全缺口，并明确请求刘表给兵、给地、给许可，且必须等待刘表裁决，才会重新出现对刘表的 nx 关系功能。

### 反向成 zx

若刘备借刘表病危之机公开夺取原本不属于自己的荆州处分权，迫使荆州官僚与军政秩序围绕他的新增决定接口重排，才应检查 zx。

原文中刘备反而拒绝这一自领路径。

---

## 7｜最近邻排除

### nx vs nz

本轮不越轴正式锁 nz，但阶段B明显更接近：

```text
关系对象本身仍重要
+ 对既有恩义/托付作回应
+ 不以取得对方资源解决自身缺口为主
```

因此记录：`nz_relation_maintenance_neighbor: present_not_formally_locked`。

### nx vs x

阶段A刘表的地盘、住所与接纳权并不归刘备直接处分，所以不是 x。

阶段B刘备也没有因为被提出“可自领荆州”就实际取得并稳定掌握荆州，所以不能反向判 x。

### nx vs xn

刘备后续如何经营新野、如何辅佐刘琦可以另查 xn；本轮只看关系是否承担外部解决通道功能。

## 8｜第三因素冻结

冻结：

- 刘备“仁义”主题评价；
- 刘表能力高低；
- 蔡氏集团阴谋；
- 曹操后续南征；
- 荆州最终归属；
- 刘备后来是否取得荆州地盘。

只保留：

```text
阶段A：谁掌握刘备所缺的接纳/驻屯接口？
阶段B：刘备是否仍在通过刘表解决自己的当前缺口？
```

结论不变。

## 9｜跨作品复现

当前同边界已有三部独立作品：

1. 《红楼梦》刘姥姥：一进求助 = nx；二进回礼探访 = 当前 nx 退出。
2. 《水浒传》宋江：早期投柴进求庇护 = nx；后来主动救柴进 = 当前 nx 退出。
3. 《三国演义》刘备：早期投刘表求庇护 = nx；刘表病危托孤时关系转为被托付/辅佐承诺 = 当前 nx 退出。

共同边界：

> **关系存在不是 nx 的充分条件；同一关系过去承担过 nx 解决通道，也不能永久继承。每次必须检查：当前关系是否仍承担主体所需的外部解决接口。**

达到三作品阈值后，应形成待审议问题，但仍不得直接修改 L1、zx/nx 信息卡、准度卡或补卡。
