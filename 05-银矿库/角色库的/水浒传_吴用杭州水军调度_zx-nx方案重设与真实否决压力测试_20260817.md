# 《水浒传》吴用杭州水军调度｜方案设计与真实否决压力测试

## 结论先行

本轮锁定：

> **主体主动设计关键方案，不会自动消灭其他对象层上的 nx。吴用拥有“怎么从杭州南面制造水路扰乱”的方案设计权，`xn` 高显影；但当水军人选与兵力配置出现资源冲突时，宋江实际否决“张横、三阮全去”，吴用随即缩减为张横、阮小七并另带侯健、段景住。由此可直接证明：在最终水军配置这一对象层，吴用并不占最高否决位置，`nx` 权限关系位置仍成立。**

本轮不锁吴用稳定人物本体，不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实

### 背景与触发

梁山军进攻杭州前，多路兵力需要同时展开。吴用向宋江提出一条南面水路扰乱方案：利用钱塘江与海路，让少量水军驾小船从海边进入赭山门附近，到南门外江边放号炮、竖号旗，使城中产生慌乱。

这说明南面水路扰乱的行动构想首先由吴用主动提出，而不是宋江逐项给出。

### 人员配置出现冲突

吴用提出方案并询问水军头领谁愿前往后，张横、三阮同时表示都愿去。

此时宋江没有机械批准，而是直接指出：

```text
杭州西路同样靠湖，仍需要水军使用，不能全部调去南面。
```

因此明确否决“全部出动”这一配置。

### 吴用根据否决重新配置

宋江提出限制后，吴用立即将配置缩减为：

```text
张横 + 阮小七
并带侯健、段景住
```

随后四人带水手、火炮、号旗出发执行。

### 最终结果

```text
吴用主动设计南面水路扰乱方案
↓
张横、三阮提出全部参加
↓
宋江因西路仍需水军而明确否决“全去”
↓
吴用接受这一约束
↓
重新配置执行人选
↓
方案在新的资源边界下继续执行
```

## 2｜nx 判断

### 纯 nx 本体：排除

吴用并不是等待宋江替自己形成行动方案。他主动观察杭州水陆结构，提出从赭山门方向制造扰乱，并进一步配置执行人员。

因此不能因为宋江拥有最高军令位置，就反推：

```text
吴用稳定人物本体 = 纯 nx
```

`stable_essence_locked: false`

### 水军最终配置层：nx 关系位置成立

关键证据不是“宋江是主帅”这个身份词，而是文本真实发生了一次否决：

```text
张横、三阮：都去
↓
宋江：不可都去，西路仍需水军
↓
吴用：缩减并重新配置
```

所以在“梁山有限水军到底可以调走多少、哪些人可以被配置到南面行动”这一对象层，吴用没有占据最终否决位置。

锁：

`nx_force_allocation_veto_relation_position: evidence-locked`

这属于 nx 的权限关系功能，而不是没主见。

## 3｜xn 最近邻

吴用主动完成：

- 识别杭州南面钱塘江与海路的行动价值；
- 设计从海边进赭山门的路径；
- 设计号炮、号旗造成城中慌乱的运行方式；
- 在宋江限制水军规模后重新配置执行人员。

这些行为回答的是：

> **方案怎么运行？**

因此锁：

`xn_plan_design_neighbor: evidence-locked`

现行 nx 准度纪律要求：外部目标或权限存在，不能覆盖主体自行组织流程、节点与资源配置的下位层。

## 4｜zx 检查

吴用的方案被采用，也实际参与梁山军的大规模军事决策，但本桥段没有证明他的最高决定范围扩大。

相反，水军配置发生冲突时，宋江能直接限制吴用方案的资源调用边界，吴用随后在该边界内重配。

没有证据显示：

- 吴用取得宋江原有的最高军令权；
- 水军全部处分权转移给吴用；
- 梁山军事秩序开始围绕吴用新增的最高权力接口运行。

因此：

`zx_in_narrow_stage: rejected_as_primary`

> **设计出有效方案、让方案被采用，不等于取得更高的最终军令权。**

## 5｜关键压力

本轮的外部压力是多战线资源竞争：杭州南面需要水路扰乱，西面湖泊同样需要水军。

这个压力使“谁真正拥有有限水军的最终配置权”变得可观察。

但资源紧张本身不能直接判十元；它只是把权限边界显影出来。

## 6｜拿掉测试

### 拿掉宋江的“主帅”身份标签

只保留事实：

```text
吴用方案需要一批水军
→ 另一主体能够真实否决全部调用
→ 吴用必须按该否决重新配置
```

最终配置层的 nx 仍成立。

所以不是从职位词倒推十元。

### 拿掉宋江的实际否决

如果宋江只是形式上听取汇报，从不改变吴用的人选与资源配置，吴用想调谁就调谁，那么本轮最硬的 nx 权限证据会明显下降，应进一步检查 `x/xn`。

### 拿掉吴用的方案设计

如果南面路径、号炮、号旗、人选全部由宋江提前规定，吴用只照办，则 `xn` 明显下降，而 nx 行为层会变得更强。

### 拿掉战争胜负

本轮分类不依赖杭州最终是否攻克。方案是否成功，不决定权限到底属于谁。

## 7｜反向测试

### 反向成更纯 nx

宋江不仅决定兵力上限，还把路径、时间、人员、信号方式全部规定好，吴用只负责传达执行。

### 反向成 x/xn

吴用本来就拥有可独立调用全部水军的稳定权限，宋江不能实际否决；吴用自行决定资源配置与运行结构。

### 反向成 zx

吴用原本没有最高水军处分权，却通过本次行动公开取得这一新增决定范围，并使宋江及全军以后稳定承认该新增接口。

原文没有出现。

## 8｜最近邻排除

### nx vs xn

```text
xn：吴用决定南面扰乱方案怎么设计、怎么调整。
nx：水军最终可调用范围受到宋江真实否决，吴用沿这个权限边界继续推进。
```

两者属于不同对象层，可以同时成立。

### nx vs x

若水军调用边界稳定归吴用本人掌握，应优先 `x`。本桥段宋江能够实际否决“全部出动”，因此吴用在最终资源配置层不能锁 `x` 为主。

### zx vs x

即使吴用在军师职责中拥有部分既有计划权，也不等于 `zx`。`zx` 还需要新增决定范围、公开扩权和秩序围绕新增权能重排。

### 第三因素冻结

冻结以下因素后结论不变：

- 吴用“智多星”名号；
- 宋江“先锋/主帅”身份词；
- 谁更聪明；
- 杭州最终战果；
- 水军头领个人勇武；
- 梁山内部私人感情。

核心只剩：

```text
谁设计方案？
谁能够真正否决关键资源配置？
否决以后方案是否必须重配？
主体决定范围有没有因此扩大？
```

## 9｜与平儿案的跨作品最小差异

《红楼梦》平儿玫瑰露案已经锁定：

```text
平儿重设结案方案 = xn
凤姐拥有真实最终处分否决权 = nx权限关系
```

本轮《水浒传》吴用则是：

```text
吴用设计/调整水路行动方案 = xn
宋江实际否决全部水军出动 = nx资源配置权限关系
```

二者共同支持：

> **主体能够主动设计或重设方案，不等于所有权限层上的 nx 都消失。只有同一对象层的最终否决/处分权真实回到主体手里，那个对象层的 nx 才应下降。**

当前这一更窄的“方案设计 + 外部真实否决”结构已跨《红楼梦》《水浒传》两部独立作品出现，尚未单独达到新的三作品阈值。

## 11｜下一轮建议

优先从《西游记》寻找第三个同型样本：

```text
主体主动设计/重设方案
+
关键资源或最终处分仍须外部主体批准
+
外部主体在文本中实际否决或修改过主体方案
```

若第三部独立作品仍稳定复现，再考虑把“真实否决能力而非名义审批”作为现有 pending-review 的增强证据；仍不得直接修改 L1。
