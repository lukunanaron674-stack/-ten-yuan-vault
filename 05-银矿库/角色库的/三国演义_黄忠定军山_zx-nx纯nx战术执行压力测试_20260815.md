# 《三国演义》黄忠定军山｜zx-nx 纯 nx 战术执行压力测试

## 1｜本轮问题

只判断第七十一回黄忠夺取对山后，按照法正红白旗号等待、出击并斩夏侯渊这一明确桥段。

不判断黄忠整个人物稳定本体；不因其武力、老将身份、最终胜利或斩将结果直接判十元。

本轮目标是检查：

1. 强战斗执行者是否会因为“很能打、亲手完成结果”被误判为 zx；
2. 等待时机是否会因为“有计划、有节点”被误判为 xn；
3. 当关键战术方向和启动节点由另一主体明确掌握时，执行者是否形成 nx 当前行为/关系位置。

## 2｜剧情事实

### 触发

黄忠逼近定军山后，与法正商议。法正先指出定军山西侧高山可俯瞰敌军虚实，建议先夺此山。黄忠夜间率军夺取对山。

### 对象与明确安排

夺山后，法正明确分配位置与信号：

- 黄忠守在半山；
- 法正居山顶观察敌情；
- 法正举白旗时，黄忠必须按兵不动；
- 待曹军疲倦无备，法正改举红旗；
- 红旗出现后，黄忠才下山进攻。

黄忠明确接受该方案，“从其计”。

### 实际动作

夏侯渊率军到来并辱骂挑战后，法正举白旗。黄忠没有因为挑衅自行改变时机，而是保持不战。

午后法正判断曹军疲倦、锐气下降，举起红旗。黄忠随即率军冲下山，追击夏侯渊并将其斩杀。

### 结果

战斗获胜，夏侯渊被黄忠斩杀；但本桥段中决定“何时不战、何时发动”的关键战术判断与启动接口明确掌握在法正手里。

## 3｜样本类型判断

结论：

```text
纯 nx 当前行为功能正例
+ nx 关系位置正例
+ 伪纯 zx 反例
```

不锁：

```text
黄忠稳定人物本体 = nx
```

也不主张本桥段完全不存在黄忠自身行动能力；本轮只锁木轴上“战术方向/启动时机”的最终决定位置。

## 4｜nx 证据

现行 nx 要求：方向、权限或解决通道已经由别人、关系、流程或现状给出；主体不占最终否决/重设位置，并沿该通道推进。

本段逐项满足：

1. **战术方向已经存在**：法正给出“据高观察—白旗不战—红旗出击”的完整方向。
2. **关键启动节点外置**：何时由等待转为进攻，不由黄忠现场自行裁定，而由法正观察后以旗号触发。
3. **主体按外部信号续接**：夏侯渊辱骂时黄忠仍不出；红旗出现后立即出击。
4. **结果执行很强，不改变方向归属**：黄忠亲手斩夏侯渊，证明其执行权能强，但不能把战术方向反推成由他生成。

因此本桥段的 nx 不是“没能力”，而是：

```text
法正掌握观察与时机决定
→ 旗号给出当前方向
→ 黄忠不抢回重设位置
→ 按信号完成强执行
= nx 当前行为/关系位置高显影
```

## 5｜zx 证据与排除

黄忠有极强的公开战斗力量，并且最终造成敌军秩序崩溃。这些表面上很容易被误判为 zx。

但 zx 准度卡要求的不只是强、公开、成功，还要求主体自己的决定接口明确，且主体决定范围/影响位置发生扩大。

本段关键战术变量中：

- 是否等待，由法正决定；
- 是否发动，由法正红旗触发；
- 黄忠没有把自己的判断压过法正方案；
- 黄忠没有重设这套战术运行方式。

因此：

```text
强执行 ≠ zx
亲手斩将 ≠ zx
公开战斗 ≠ zx
```

黄忠冲锋与斩将可以视为强行动显影，但不足以把“当前战术方向与作用权来源”锁为纯 zx。

本轮对“黄忠此桥段纯 zx”判定为 rejected。

## 6｜nx vs xn 最近邻排除

这是本轮最关键的最近邻。

表面上出现：

- 等待；
- 时机；
- 白旗/红旗节点；
- 以逸待劳流程。

这些非常像 xn。

但 xn 要求主体主动组织时间、计划、流程与节点。这里组织这些节点的人是法正，不是黄忠。

对黄忠本人：

```text
等待不是为了执行自己设计的节点
而是等待法正给节点
= nx
```

若把法正的计划能力直接归给黄忠，就会犯“团队机制借给个人”的单人物归因错误。

因此本桥段：

- 法正的行为可另行检查 xn；
- 黄忠在该战术接口上的行为优先锁 nx。

## 7｜其他最近邻排除

### nx vs x

黄忠掌握自己的武器、部队与战斗执行，但并不掌握山顶观察接口和红白旗启动标准，因此不能以“他带兵”直接判 x 覆盖整个战术机制。

### nx vs zx

若黄忠无视法正信号，自行判断敌情、决定何时攻击，并迫使整个战术部署围绕其决定重排，zx 才明显上升。本段事实相反。

### nx vs xz

夏侯渊进逼和战场危险构成外部压力，但危险只说明为何需要选择时机；它不能解释为什么最终启动判断在法正而不在黄忠。因此 xz 压力冻结后，nx 仍成立。

## 8｜拿掉测试

### 拿掉“黄忠很能打”

只保留：

```text
法正定等待/出击规则
→ 白旗时主体不动
→ 红旗时主体发动
```

nx 仍成立。

### 拿掉“最后斩杀夏侯渊”

即使黄忠冲锋后没有亲手完成斩将，只要他仍按法正的旗号进入/退出战斗，木轴方向归属不变。

### 拿掉“红白旗”这一具体视觉符号

只要存在一个由法正掌握的等价启动接口，例如口令、传令兵或其他信号，且黄忠不占其最终重设权，nx 仍成立。

## 9｜反向测试

### 反向成为 xn

若刘备只给“击败夏侯渊”这一目标，而黄忠本人主动设计：

- 先夺高地；
- 什么时候等待；
- 什么时候出击；
- 如何设置观察与信号节点；

则对黄忠应优先检查 xn，而不是 nx。

### 反向成为 zx

若法正建议等待，但黄忠公开否决并自行选择攻击时机，而且整个部署被迫围绕黄忠的决定重新调整，则 zx 上升。

### 反向仍是普通执行

若只有“接令冲锋”而没有清楚的方向/时机外置结构，则只能判普通执行候选，不能因为服从一次就自动锁 nx。本段之所以达到 98% 分类把握，是因为红白旗机制把最终战术启动位置写得异常清楚。

## 10｜第三因素冻结

本轮冻结以下变量，不允许参与十元直判：

- 黄忠年龄与老将身份；
- 武力高低；
- 是否勇猛；
- 夏侯渊最终死亡；
- 胜负；
- 刘备阵营身份；
- “以逸待劳”作为兵法名词；
- 法正是否比黄忠聪明。

冻结后只保留：

```text
谁观察并决定时机？
谁拥有启动接口？
黄忠是否能自行否决/重设？
实际行动是否沿该接口发生？
```

答案仍稳定指向 nx 当前行为/关系位置。

## 11｜人物分层

- **稳定人物本体**：不锁。单桥段不能证明黄忠跨阶段长期不占方向。
- **当前状态**：nx 高显影。
- **行为功能**：按法正既定战术与旗号执行，nx 锁定。
- **关系位置**：法正占据观察/启动接口，黄忠沿该接口推进，nx 锁定。
- **外部压力**：夏侯渊逼战、辱骂、战场危险存在，但不是 nx 的来源，只是测试黄忠是否抢回时机决定权的压力。

## 12｜结论

```text
《三国演义》第七十一回黄忠定军山这一桥段：

事实置信：99%
分类置信：98%
状态：evidence-locked

锁：黄忠在法正红白旗战术中的 nx 当前行为功能 / 关系位置。
拒绝：因黄忠能打、公开冲锋、斩杀夏侯渊而判纯 zx。
拒绝：把法正设计的等待与节点组织借给黄忠判 xn。
不锁：黄忠稳定人物本体为 nx。
```

本例补出的最小判定纪律：

> **谁设计并掌握节点，就把 xn 先归给谁；谁只是等待他人节点再行动，即使执行极强，也可在该接口上是 nx。**

以及：

> **执行结果来自我的刀，不等于最终战术方向来自我。**

本轮不修改 L1、zx/nx 信息卡、准度卡或 zx↔nx 补卡。
