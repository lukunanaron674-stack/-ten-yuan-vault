# 《红楼梦》探春｜zx↔nx 木轴压力测试

## 结论先行

本轮锁定一个新的 `nx` 边界反例：

> **“受上级委托、接手别人原有职责”不能直接判 `nx`；如果主体接到上位职责后主动发现旧流程缺口、取消旧支出、建立新的分工与收益机制，并重新配置运行通道，则应优先检查 `xn`，不能把“受命办事”偷换成“沿已有方向续接”。**

第五十五回中，王夫人因凤姐病中不能理事，命李纨协理，并命探春共同裁处。这个“协理荣府”的上位职责确实来自外部授权。但第五十六回探春并不是照抄凤姐旧流程，而是主动识别重复开支、提出蠲免买办项目、参照赖大家花园经营方式，设计大观园内部承包与专责机制，选择具体婆子负责竹林、稻地等区域，并继续讨论收益如何回流、如何避开旧账房再剥一层。

因此本段不是：

```text
王夫人给职责
→ 探春沿旧流程执行
→ 既有通道决定方法
= nx
```

而是：

```text
王夫人给上位职责
→ 探春发现旧流程重叠与浪费
→ 主动取消旧项目
→ 自行设计新的分工、责任、收益与回流通道
→ 让运行方式重组
= nx 排除，优先 xn
```

本轮只锁 `nx_rejected_in_narrow_stage`，不把探春稳定人物本体直接锁成 `xn`、`zx` 或其他十元。

## 1｜原始事实

### 触发

凤姐因病不能理事。王夫人先令李纨协理家中琐事，又命探春与李纨共同裁处，属于明确的外部职责授权。

### 探春的明确动作

第五十六回中，探春连续做出以下可观察动作：

1. 主动发现头油脂粉等费用存在重复支出；
2. 提出直接蠲掉原有买办这一项开支；
3. 从赖大家花园的经营方式推导大观园也可把现有资源转为持续收益；
4. 提议从园内老妈妈中挑选懂园圃者，分片专责；
5. 将“谁管哪一片、哪些产出可取、家中定例先留多少、余者如何处理”变成新的运行规则；
6. 进一步发现若年终仍归账房，会重新落回旧权力链，于是主动提出改变收益回流路径，避免再被旧账房抽取。

### 可观察结果

- 原有费用与买办流程被主动取消；
- 园内原本分散、无人专责的资源被重新分配给具体人员；
- 责任、收益、维护与激励被放进新流程；
- 旧账房路径不再被默认视为唯一通道；
- 新制度由探春等人主动讨论、筛选、配置和落地，而不是等待王夫人逐项指示。

## 2｜为什么这是伪 nx 反例

现行 `nx` 要求：

```text
方向、权限或解决通道已经由别人、关系、流程或现状给出
→ 主体不主动改写
→ 不占最终决定、否决与重设问题的位置
→ 沿既有方向继续
```

探春本段只满足“上位职责由王夫人授予”，却不满足后续关键条件。

### 她没有沿旧通道继续

她首先做的就是发现旧流程重复、低效，然后删掉一部分旧流程。

### 她主动重设运行方式

她不是问“凤姐以前怎么做，我照着做”，而是建立园圃分片负责、收益激励、专责维护等新的运行结构。

### 她具备否决旧方案与改写接口的能力

最典型的是年终收益若仍交账房，她主动判断这会让旧体系重新“剥一层皮”，于是提出换回流路径。

因此：

> **外部给“职责”不等于外部给“解决通道”。**

这一点与现行 nx 准度卡 `nx vs xn` 的最小差异完全一致：可接外部目标，但只要主体主动组织运行方式、重组结构，`nx` 就应下降，优先检查 `xn`。

---

## 3｜关键压力与第三因素冻结

本段需要冻结三个第三因素：

```text
王夫人的上级授权
+ 凤姐暂时退出管理
+ 探春原本没有常设最高管家职位
```

如果只看“她是受命管理”，极易误判为 `nx`。

但这些因素只解释她为什么获得了处理窗口，不解释具体的运行方式从哪里来。

真正需要判断的是：

```text
职责由谁给？
≠
方法由谁组织？
```

本例中职责外置，方法与流程重组主要由探春主动生成。

因此上级授权不能作为 nx 的决定性证据。

---

## 4｜zx 在本段的位置

本段存在 `zx` 局部候选，但本轮不升级。

支持候选的地方：

- 探春的判断公开改变了原有家务处理方式；
- 平儿、李纨、婆子等都围绕新方案重新反应；
- 她拥有一定公开裁处权，并能够否决旧费用与旧接口。

但本段最强的可观察变量不是“权能公开扩大并凌驾他者”，而是：

```text
流程重组
+ 分工
+ 责任节点
+ 收益路径
+ 运行持续性
```

因此优先归 `xn`，而不是为了木轴对跑硬凑一个 `zx+nx`。

## 5｜最近邻排除

### nx vs xn

```text
nx：接到职责后沿已有安排、权限和流程继续。
探春：接到职责后主动删除旧项、建立新规则、重配人员与收益通道。
```

所以本段 `nx` 排除，`xn` 高显影。

### nx vs zx

探春确实公开行使裁处权，但核心变化不是“主体骑到他者之上、扩大公开凌驾位置”，而是让复杂家务进入更有效的持续运行结构，因此不以 `zx` 为主。

### nx vs x

她并未把园中资源变成私人“归我掌握”，反而是重新设计公共管理与收益分配；故不能因为她暂时有管理权限就判 `x`。

### nx vs n

她处理的是流程与职责配置，不是把对象纳入内部长期承载并承担负荷；`n` 不是本段主变量。

## 6｜拿掉测试

### 拿掉“王夫人授权”

若只保留探春发现重复开支、设计分片负责、重设收益通道这些行为，仍然可以观察到明显的主动流程组织结构。

所以本段的 `xn` 证据不依赖“被上级安排”。

### 拿掉“探春身份”

换成一个普通临时代理人，只要其仍主动：

```text
发现旧流程问题
→ 删除旧项
→ 新建分工
→ 设责任与收益规则
→ 改回流接口
```

依旧不是纯 `nx`。

### 拿掉“改革结果被接受”

即使最终实施失败，只要这些主动重组动作真实发生，仍足以证明她不是单纯沿旧通道续接。

## 7｜反向测试

若改写为：

```text
王夫人：凤姐以前的账、买办、园子分工都照旧，你替她每天按旧例批下去。
探春：好。

→ 不删旧项
→ 不重设分工
→ 不改收益通道
→ 遇到问题继续等王夫人或凤姐决定
```

则 `nx` 会明显上升。

或者：

```text
王夫人已经逐项规定谁管园子、钱归哪里、哪些项目取消；
探春只负责把既定命令传达并执行。
```

也更符合 `nx` 行为。

现实原文与这两个反向版本明显不同。

## 8｜本轮对木轴的新增价值

此前已有：

```text
贾迎春：有自主窗口仍不占方向 → nx 正例。
鲁达：自己生成方向并公开压入现实 → zx 正例。
诸葛亮：外部给上位目标，但运行通道由自己建立 → 不是 nx，优先 xn。
关羽：进入他者体系但保留最终归向、否决与退出 → 不是 nx。
```

本轮新增一条跨作品验证：

```text
探春：外部给职责，但主体主动重组流程、分工与接口
→ “受命办事”不等于 nx
→ 优先检查 xn
```

这与诸葛亮“五路犯蜀”形成第二个独立作品的同型边界：

```text
外部给上位目标／职责
≠
外部给完整运行通道
```

当前跨独立作品数量为 2（《三国演义》《红楼梦》），尚未达到“至少 3 部独立作品”升级待审议问题的门槛，因此本轮不修改 nx 核心正本。
