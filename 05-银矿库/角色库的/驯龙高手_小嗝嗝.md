# 小嗝嗝（Hiccup Horrendous Haddock III）
> 归档：`05-银矿库/角色库/驯龙高手_小嗝嗝.md`

---

## 1. 主十元判断

**主十元：zn（阳土·这件事是对的）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zn，小嗝嗝就是一个瘦小的维京少年——会发明、很机灵、在部落里格格不入。但小嗝嗝最核心的不是"聪明"或"不合群"，是**他知道"杀龙不是答案"**。当整个部落的信仰是"杀龙夺荣耀"时，他看到一个受伤的龙的第一反应不是举刀——是"它疼"。
- **第2问（反复面对什么结构）：** 反复面对「杀还是不杀」。父亲说"龙是怪物"、族人说"杀了它证明你是维京人"、整个文化都在说"杀了一头龙你才算长大"。但小嗝嗝每次都停在同一个地方：它不咬我。
- **第3问（最怕失去什么）：** 最怕「无牙被杀死」。不是怕自己受伤（x），是怕"我知道它不是怪物，但没人相信我"。
- **第4问（回到哪个感觉）：** 回到「第一次伸出手无牙没咬他」的那一刻——他那一刻知道了一件事："它不是怪物。我知道它是谁，这就够了"。
- **第5问（副十元服务谁）：** zx（先做再想/完成即意义）是zn的执行器——小嗝嗝不是空想家，他明白了"对的事"之后立刻动手：造了鞍、造了尾翼、教会了无牙飞。他先做了——zn说了方向，zx给了速度。

## 2. 副十元

**副十元：zx（阳木·先做再想/动手了再说）**

**作用：** 小嗝嗝是发明家——他看见无牙飞不起来不是想"怎么办"（xn），而是直接去画图、砍木头、打铁。他造了尾翼让无牙飞起来——不是等父亲批准、不是等准备好了，是已经开始了。

## 3. 功能十元

**功能十元：n（阳火·扛住/撑住不被认可的压力）——表层。** 全族人都觉得他没用、父亲对他失望、训练场上他被打倒——他撑住了。不是因为不怕（n的反面），是因为"我知道我在做什么"。

## 4. 视觉十元

**视觉十元：x（阴水·透明/弱）。** 瘦、黑眼圈、摔跤就站不稳——他和"维京人"的块头完全不搭。但正是他的"看起来弱"让他有机会去"理解"而不是"杀"。

## 5. 动态链

```
zn（主·杀龙不是答案/理解是对的）
  → zx（副·造尾翼/动手了再说）
  → n（功能·撑住被否定的压力）
  → x（视觉·弱小的外表）
  → 遇见无牙→不杀→造尾翼→教会飞→改变世界
  → 他证明了：理解比力量更强大
```

## 6. 一句话定型

小嗝嗝不是「驯龙的维京人」，也不是「和平的使者」，而是「**知道这件事是对的、做不到就不走**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** zn（主）+ zx（副）→ 本体型
**最终定位：** zn（主·这件事是对的）+ zx（副·动手了再说）→ 本体型
**最终修正理由：** 原卡zx正确描述了他行动方式（先做再想），但主十元不对——驱动小嗝嗝的全部行动的不是"完成即意义"（zx），而是"理解而不是杀戮"（zn）。他做那些事（造尾翼、训练、战斗）是因为他知道那是唯一该走的路。zx是他如何做的描述，zn才是他为什么做的原因。
