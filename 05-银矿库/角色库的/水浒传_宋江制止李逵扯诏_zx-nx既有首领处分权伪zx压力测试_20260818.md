# 《水浒传》宋江制止李逵扯诏｜zx-nx 既有首领处分权伪zx压力测试

## 1｜本轮问题

本例专门测试：

> 主体公开、强势地阻止另一人，现场结果也真实改变，是否就能判 `zx`？

与仓库最新《三国演义》“赵云截江夺阿斗”案例形成反向控制。赵云案例锁定的关键是：小说文本没有先明确赋予赵云“阿斗能否离境”的最终处分权，而赵云在冲突中公开把自身作用权压入该对象层，使现实结果围绕其判断重排，因此 `zx` 当前状态高显影。

本例反过来检查：若主体在冲突前已经稳定占有相关组织指挥/处分接口，本轮只是公开调用它，是否应优先判 `x` 而非 `zx`。

## 2｜剧情事实

《水浒传》120回本第七十五回：

- 朝廷派陈宗善到梁山宣读首次招安诏，宋江主持迎接、点集头领并安排宣诏现场。
- 萧让读完诏书后，李逵从梁上跳下，抢过诏书扯碎，又要殴打陈太尉。
- 宋江、卢俊义当场横身抱住李逵，不许其继续下手；众头领随后把李逵推下堂去。
- 李逵又攻击李虞候，仍被众人解拆、制止。
- 宋江随后直接安抚陈太尉，保证现场不会再出差池，并继续主持御酒与后续处置。

本轮只截取：

> 李逵公开破坏宣诏 → 宋江公开制止 → 梁山人员围绕既有首领接口恢复处置。

不把后续招安是否最终成功、宋江后来的政治路线全部倒灌进这一窄阶段。

## 3｜候选分类

- 纯 `zx`：排除。
- 纯 `nx`：排除。
- `zx+nx`：排除。
- `x` 最近邻：锁定为高质量正例。
- 样本主类型：**既有首领处分权公开调用，不等于 zx 扩权。**

## 4｜zx 检查

宋江在本段确实满足若干 `zx` 外观：

- 公开介入；
- 对李逵形成强制制止；
- 李逵的现场行为被改变；
- 众人实际围绕宋江、卢俊义等头领的处置继续行动。

但现行 `zx v2.3 / zx准度卡 v0.1` 还有一道硬门：

> 主体的决定范围、影响位置或凌驾程度必须**真实上升**，不能只是把已经属于自己的权限公开用出来。

本段没有证据显示：

- 宋江此前无权约束梁山头领，而本次冲突后第一次取得该权；
- 宋江通过制止李逵获得了新增的梁山最高路线权限；
- 原有组织边界被推向一个此前不存在的更大宋江处分范围。

相反，文本从冲突前就已经呈现宋江作为梁山主要主持者：迎太尉、点众头领、组织宣诏；冲突发生后，他只是继续调用这个既有组织接口。

因此锁定：

```text
公开强制有效
+
他者服从
≠
自动 zx

若决定接口本来已经稳定归主体
→ 优先检查 x
```

`zx_in_narrow_stage: rejected_as_primary`。

## 5｜x 最近邻检查

本段最匹配的是 `x` 的“已有权限 / 调用边界归我掌握”。

关键不在“宋江是寨主”这个身份标签，而在实际结构：

- 冲突前，宋江已经能够主持梁山对外正式事务；
- 冲突发生时，宋江可以直接介入并约束李逵，而不是先向另一个梁山最高节点申请；
- 其他头领实际加入制止、把李逵推下堂，说明这套处置接口在组织中已经可运行；
- 事后宋江继续恢复现场秩序和对外接待，不需要通过本次冲突重新取得权限。

因此锁定：

`x_existing_leader_authority_neighbor: evidence-locked`

但不由这一场反推“宋江稳定人物本体 = x”。本轮只锁窄对象层的既有组织处分接口。

## 6｜nx 检查

本段不以 `nx` 为主判。

宋江没有：

- 向另一个梁山权限主体请求“请替我制止李逵”；
- 借外部关系网络取得制止李逵的许可；
- 等待别人决定是否恢复现场秩序。

卢俊义与其他头领参与制止属于组织内部协同行动，不能因为“用了别人”就判 `nx`。若相关调用边界已经在现成组织权限中，应优先检查 `x/xn`。

因此：

`nx_in_narrow_stage: rejected_as_primary`

## 7｜关键压力

压力来自：

- 朝廷正式招安诏进入梁山；
- 李逵突然公开撕诏、攻击使者；
- 梁山对外事务存在立即失控风险。

但压力只负责让宋江的既有处分接口显影，不能直接生成十元结论。

本轮真正观察的是：

> 压力到来后，宋江是在**取得新的决定范围**，还是**调用已经拥有的组织接口**？

答案偏后者。

## 8｜拿掉测试

### 8.1 拿掉宋江“寨主/哥哥”身份词

只保留以下事实：

```text
冲突前主体已经主持该组织正式事务
→ 冲突时可直接约束成员
→ 其他成员按该处置接口行动
→ 冲突后继续恢复原组织运行
```

仍然更接近既有 `x` 权限，而不是新生 `zx`。

说明本轮不是用身份标签直判。

### 8.2 拿掉李逵的暴力强度

即使李逵只是拒绝宣诏、扰乱现场，只要宋江仍是在原有组织处分范围内制止并恢复流程，`x` 主判不变。

### 8.3 拿掉第一次招安最终失败

第一次招安后来没有成功，不能反推宋江当场制止李逵时发生了 `zx` 扩权。胜负、路线结果不是本轮分类支柱。

## 9｜反向测试

### 9.1 反向成真 zx

如果文本结构是：

```text
宋江原本无权约束李逵或其他头领
→ 本次危机中公开夺取该组织处分权
→ 原有头领体系被迫承认新的宋江决定接口
→ 以后该新增范围可持续调用
```

则 `zx` 明显上升。

### 9.2 反向成 nx

如果宋江必须先请求卢俊义、吴用或另一个真实最高节点批准，才能制止李逵、恢复接待，那么应检查 `nx` 权限关系。

### 9.3 反向成纯普通行为

如果宋江只是上前拉架，但没有组织处分接口、其他成员也不围绕其位置行动，则 `x` 证据会下降，只剩普通行为。

## 10｜最近邻排除

### zx vs x

这是本轮主边界：

```text
x：这块决定/处分接口本来就在我这里，我公开调用。
zx：这块决定范围原本不在我这里，我的权能公开把边界推过去并扩大。
```

宋江本段优先前者。

### x vs xn

恢复接待、安排人员、处理现场流程可有 `xn` 组织邻近；但本轮首先回答的是“谁已有权制止并处分组织成员”，因此以 `x` 为主。

### x vs nx

其他头领协同不等于外部借权；已有组织调用网络归主体可用时，不判 `nx`。

### 第三因素冻结

冻结以下因素：

- 宋江是否赞成招安；
- 李逵是否莽撞；
- 宋江个人威望；
- 朝廷诏书是否侮辱梁山；
- 第一次招安最后是否失败；
- 后续梁山是否最终接受招安。

只检查“制止李逵这一处分接口在冲突前是否已经存在，以及本轮有没有新增决定边界”，结论仍为 `x` 邻近而非 `zx`。

## 11｜与既有案例的最小差异

### 李逵扯诏

仓库既有正式案例锁定：

> 李逵动作极强、公开破坏并短暂打断宣诏，但没有取得梁山招安路线决定权，反而被宋江等制止，所以是“强烈反抗伪 zx”。

### 宋江制止李逵

本轮进一步说明：

> 宋江确实成功改变李逵的现场行为，但成功不是因为本次新增扩权，而是因为其既有梁山首领处分/指挥接口被公开调用。

### 与赵云截江夺阿斗

赵云案例锁定：小说没有预先清楚赋予赵云“阿斗能否离境”的最终处分权，赵云却在冲突中公开把自身作用权压入该对象层，并使现实结果围绕其判断重排，因此 `zx` 当前状态成立。

本轮宋江则是：

> 冲突前已有相关组织调用边界 → 冲突中公开行使 → 结果改变，但决定边界没有新增。

所以形成最小差异：

```text
公开强制 + 结果改变
        ↓
先问：权限原来有没有？

原来已有 → x
原来没有，冲突中边界真实上升 → zx
```

## 12｜严格 zx↔nx 补关系检查

不锁。

本段没有独立成立的 `nx` 端，也没有证明“拿掉 nx 后 zx 出现稳定缺口、补回后可重复改善”。普通组织协作不满足 `zx补nx_补卡 v0.1` 的严格补关系要求。

## 13｜结论

本轮正式锁定：

> **公开、强势、有效地改变现场结果，仍不能自动判 zx。若主体只是公开调用原本已经稳定掌握的处分/指挥接口，应优先检查 x；只有决定边界本身在冲突中新增、上升，才进入 zx。**

结论状态：`evidence-locked`。

## 14｜理论处理

- 不修改 L1。
- 不修改 zx/nx 信息卡。
- 不修改 zx/nx 准度卡。
- 不修改 `zx补nx_补卡`。
- 不锁宋江稳定人物本体。
- 本例作为“公开强制但既有权限 = x，非 zx”的反向控制材料入库。
