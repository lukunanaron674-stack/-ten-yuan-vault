# 《三国演义》吕布辕门射戟｜zx-nx 临时裁决扩权压力测试

## 1｜剧情事实

- 袁术遣纪灵率军进攻小沛刘备；刘备兵少，向吕布求救。
- 吕布判断袁术若吞并刘备，将进一步威胁自己，于是带兵来到小沛附近，并同时请纪灵、刘备赴宴议和。
- 吕布先直接要求双方罢兵，纪灵以奉袁术之命为由拒绝。
- 在双方原有方向仍是“纪灵攻刘备 / 刘备应战”的情况下，吕布自行提出新的临时裁决规则：若自己一箭射中辕门外画戟小枝，两家罢兵；若不中，各自回营交战；不服从者，吕布将以自身力量介入。
- 纪灵与刘备均接受这一临时裁决条件。
- 吕布一箭射中画戟小枝后，再次宣布两家罢兵；纪灵表示不敢不听，只担忧回去无法向袁术交代，吕布承担写信说明。
- 次日三处军马皆散，原本即将发生的战斗路线被实际终止。

来源：罗贯中《三国演义》第十六回“吕奉先射戟辕门 曹孟德败师淯水”。

## 2｜样本候选

- 纯 zx：锁当前状态 / 行为功能 / 关系位置高显影，不锁稳定人物本体。
- 纯 nx：排除。
- zx+nx：本窄桥段不锁。
- 压力显影：存在。外部已有双方战争方向，吕布将自身权能插入并改写局部决定结构。
- 伪对子：不是“强烈动作=zx”，而是“新增临时裁决位置并使双方实际改线”的真 zx 对照。

## 3｜zx 检查

本段满足现行 zx 的五项必要门槛：

1. **主体自己的决定接口明确**：新的“射中则罢兵、射不中则交战”裁决不是袁术、纪灵或刘备给出的，而由吕布主动提出。
2. **权能公开进入现实**：吕布不是幕后劝说，而是在双方将领面前公开设定条件，并明确不从者将面对自己的力量介入。
3. **他者实际被迫回应**：纪灵原先拒绝罢兵，但在吕布设定的新条件下接受；刘备也接受。
4. **主体决定位置上升**：吕布从原本战争之外的第三方，临时上升为决定“此刻战还是不战”的实际裁决中心。
5. **现实路线被改写**：射中之后纪灵不再按袁术原命令继续攻击，次日三军散去。

因此，本段不是因为“吕布武力强、箭术高”判 zx，而是因为：

```text
双方已有冲突方向
→ 吕布以自身权能公开插入
→ 自行建立新的临时裁决条件
→ 双方必须围绕该条件重新反应
→ 原战斗路线真实终止
→ 吕布的局部决定位置上升
= zx 当前状态高显影
```

## 4｜nx 检查

本段 nx 排除：

- 吕布没有沿袁术给出的“按兵不动”方向继续；
- 也没有仅沿刘备求救给出的“替我击退纪灵”方向行动；
- 他没有把“是否交战”的最终局部决定继续留在纪灵、刘备或双方既有流程里；
- 相反，他主动生成第三条路线，并让双方接受自己的裁决接口。

所以这里不是“借别人权限办事”的 nx 关系功能，也不是“不占最终方向”的纯 nx 状态。

## 5｜关键压力

外部压力有三层：

1. 袁术已命纪灵进攻刘备；
2. 刘备兵少并向吕布求救；
3. 吕布自身担心袁术吞并刘备后继续威胁徐州。

这些压力解释吕布为什么要介入，但不能直接生成 zx。zx 的成立仍依赖他是否把自己的权能公开压入现实，并取得新增的局部决定位置。

## 6｜拿掉测试

### 拿掉“神射”与武力传奇

若不强调吕布箭术多强，只保留：

```text
双方原本要交战
→ 第三方公开设定新的裁决条件
→ 双方接受
→ 裁决结果使双方停止交战
```

只要这个裁决位置确实由吕布自身权能支撑，zx 仍成立。箭术是实现裁决的具体载体，不是 zx 的唯一判据。

### 拿掉“刘备是受救者”

即使把刘备替换成另一个与吕布存在战略利益关系的弱方，只要吕布仍不是沿其求救方案执行，而是自己取得新增裁决位置并使双方改线，zx 仍成立。

### 拿掉最终赞诗、英雄评价与胜负光环

只检查谁提出规则、谁有不从后的实际作用力、双方是否服从、战争路线是否改变，结论不变。

## 7｜反向测试

### 反向成非 zx / 普通协调

如果吕布只是提出“请双方给我面子罢兵”，双方自行权衡后独立决定，他本人没有新增裁决位置，也没有能力使不从者承担来自他的现实后果，则 zx 明显下降，更接近普通协调或关系行为。

### 反向成 nx

如果吕布只按刘备给出的求救路径行动，或必须等待袁术、纪灵授予权限后才能办事，自己不能重设“战或不战”的决定条件，则 nx 上升。

### 反向成 x

如果纪灵、刘备本来就是吕布直接辖属，停战权限早已稳定归吕布掌握，他只是正常行使既有处分权，则优先检查 x，而不是 zx。本段双方并非其普通下属，因此新增的临时裁决位置才具有 zx 价值。

## 8｜最近邻排除

### zx vs xn

本段确有 xn 邻近污染：吕布设计了一个明确程序与判定节点，“射中 / 射不中”决定后续两条路径。

但 xn 解释的是**裁决程序如何被设计**；zx 解释的是**为什么这个程序能成为双方必须围绕的新决定接口**。

拿掉“画戟、一百五十步、一箭”等具体流程细节，只保留吕布公开建立由自己权能担保的临时裁决、双方接受且路线改变，zx 仍独立成立。因此不把 xn 的程序设计偷算成 zx，但也不因存在 xn 手段而排除 zx。

### zx vs x

x 是既有对象、资源或权限本来归我掌握；本段纪灵与刘备的战争决定权并不预先归吕布稳定处分。吕布是在冲突中临时取得更高的局部决定位置，因此比普通 x 更接近 zx 状态显影。

### zx vs z

双方对吕布力量的承认只是辅助现象。核心不是“被看见、被认可”，而是其权能实际改变双方军事路线，因此不以 z 为主判。

### 第三因素冻结

冻结吕布个人好恶、救刘备的战略利益、箭术传奇、勇力名声、纪灵对袁术的服从、刘备对吕布的感谢后，只保留“新增裁决接口是否由主体建立并使双方实际改线”，zx 结论仍成立。

## 9｜与李逵扯诏形成最小差异

### 李逵扯诏

```text
公开反抗很强烈
→ 现场流程被打断
→ 但梁山招安路线没有交给李逵决定
→ 李逵本人被制止
→ 决定位置未上升
= 强烈反抗伪 zx
```

### 吕布辕门射戟

```text
公开介入
→ 自己建立新的裁决条件
→ 原本拒绝罢兵的一方接受
→ 裁决结果被双方执行
→ 战争路线真实改变
→ 主体局部决定位置上升
= zx 当前状态正例
```

因此进一步锁定案例级纪律：

> **zx 不看动作多猛烈，而看主体的权能是否真的成为新的现实决定来源，并使他者或秩序围绕它重新排列。**
