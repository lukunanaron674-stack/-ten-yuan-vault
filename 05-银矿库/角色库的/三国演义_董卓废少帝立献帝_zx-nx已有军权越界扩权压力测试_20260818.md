# 《三国演义》董卓废少帝立献帝｜zx-nx 已有军权越界扩权压力测试

## 1｜剧情事实

第3回先给出一个已存在的实际控制层：董卓招诱何进兄弟部曲，兵马逐步归其掌握。这足以支持“军队调用/控制接口已经在董卓手里”的 `x` 邻近，但不能据此直接推出他原本拥有皇帝废立权。

随后董卓主动提出废少帝、立陈留王。在温明园召百官议废立时，丁原、卢植等明确反对，董卓以武力和生死威胁压制异议。第4回进一步发展为：董卓规定反对废立者以军法从事，百官震恐；九月朔大集文武，直接推动废少帝为弘农王、立陈留王协为帝，并在新秩序中升为相国，权势位置明显上升。

## 2｜对象层拆分

```text
冲突前：
军队/部曲的实际调用范围
→ 董卓已经掌握
= x 邻近

冲突中：
皇帝废立、朝廷最高政治方向
→ 原本不是董卓既有军队处分权的自然对象
→ 董卓主动把自身军事实力压入该层
→ 百官被迫响应
→ 少帝被废、陈留王被立
→ 董卓自身政治决定位置继续上升
= zx
```

因此本例不能写成“董卓本来就有权，所以只是 x”，也不能写成“董卓很强，所以 zx”。真正的判据是：**原有军队控制边界被公开推到了原先不属于该边界的皇位废立与朝廷最高方向层。**

## 3｜zx 证据

1. **方向来源在主体**：废少帝、立陈留王由董卓主动提出并持续推进。
2. **自身权能公开进入现实**：召集百官、带剑议政、以军法与武力压制反对，不是秘密绕权。
3. **他者/秩序真实响应**：百官震恐，反对者被压制，朝廷不得不围绕董卓提出的废立方向作出反应。
4. **决定范围真实扩大**：董卓原有的军队控制被推进到皇帝废立、朝廷政治方向与人事秩序；第4回废立实际完成，董卓随后为相国，现实位置进一步上升。

结论：`zx_authority_boundary_expansion: evidence-locked`。

## 4｜nx 证据

本窄阶段 `nx` 排除。

董卓没有沿一个更高外部权限节点申请废立，也没有把“废不废、立谁”交给另一主体最终裁决；他调用李儒、吕布、部曲和百官，只是围绕自己已经形成的方向组织实施，不能把执行者或协作者偷算成董卓的 nx。

结论：`nx_in_narrow_stage: rejected`。

## 5｜关键压力

关键压力是汉廷权力真空、何进已死、军队重新聚集以及百官缺乏统一强制中心。这些条件给了董卓扩边窗口，但**权力真空本身不是 zx**。只有当董卓把自身既有军事实力公开压入皇位废立层，并使现实真的重排，zx 才成立。

## 6｜最近邻排除

### zx vs x

`x` 解释：董卓已经能调动自己掌握的军队。

`zx` 解释：董卓把这个已有控制力继续推到皇帝废立和朝廷最高政治方向层，并使新边界实际成立。

因此本例是当前待审议问题要求的“**已有局部权限 + 本轮真实越界扩权**”反向正锚。

### zx vs xn

李儒建议把握时机、召百官、有不从者斩之，董卓也进行连续组织，存在 `xn` 策略邻近；但拿掉这些具体流程，只保留“原有军权 → 公开压入废立层 → 朝廷结构重排”，zx 仍独立成立。

### zx vs nx

使用部下、百官、李儒、吕布，不等于沿别人的权限通道。最终废立方向不是外部给董卓的。

## 7｜拿掉测试

- 拿掉“董卓残暴/奸臣”评价：只看权限前后边界，zx 仍成立。
- 拿掉战斗胜负：本例不靠一场战斗判 zx。
- 拿掉“相国”这一最终头衔：只要废立真的完成、原朝廷必须围绕董卓新增决定接口重排，zx 仍成立；相国只是额外加强位置上升证据。
- 拿掉废立实际完成：若董卓只在宴会上大喊但朝廷拒绝、少帝仍稳坐帝位、董卓也未取得新增政治决定位置，则 zx 会显著下降，可能退化为强烈威胁/未遂扩权候选。

## 8｜反向测试

### 反向成 x

如果董卓在冲突前已经正式、稳定拥有皇帝废立处分权，本轮只是照常调用，则应优先判 `x`，不应制造 zx。

### 反向成 nx

如果董卓只能向太后、群臣或另一最高节点申请废立，最终必须等待其批准，自己不占最终重设位，则检查 `nx`。

### 反向成伪 zx

如果董卓只靠军威提出废立，但反对者阻止成功、朝廷秩序不改变、董卓位置不升，则“动作强/威胁强”不足以锁 zx。

## 9｜第三因素冻结

不以这些因素直判十元：董卓善恶评价、残暴程度、吕布武力、袁绍后续起兵、汉室衰微主题、最终董卓之死、历史真实合法性争论。

本轮只问：**董卓是否把原有军队控制边界公开推入原本不属于它的皇位废立层，并让现实承认这个新增作用范围。**
