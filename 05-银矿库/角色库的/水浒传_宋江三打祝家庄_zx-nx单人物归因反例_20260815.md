# 《水浒传》宋江三打祝家庄｜zx↔nx 单人物归因反例

## 结论先行

本轮不把“三打祝家庄”计入第三个 `zx→nx→zx` 单人物正例。

表面上它很像：

```text
梁山正面攻庄
→ 两次受阻
→ 借孙立与栾廷玉的既有关系接口进入庄内
→ 里应外合破庄
```

但把这整条链写到宋江一个人身上会发生严重的团队结果借用：

- 正面攻庄与继续破庄的总体方向主要由宋江承担；
- 利用同门关系进入祝家庄的关键接口属于孙立；
- 该潜入方案由孙立主动提出；
- 吴用接受并整合孙立方案；
- 孙立、孙新、顾大嫂、乐和、解珍、解宝等人在庄内承担内应执行；
- 庄外再由宋江一方发动攻势完成里应外合。

因此，**团队层可以观察到“直接路径受阻→调用既有关系接口→重新完成突破”的结构，但现有证据不足以把中段 nx 关系功能稳定归属于宋江本人。**

本轮正式锁定的是一个归因红线：

> **跨人物分工形成的 zx/nx/zx 团队链，不得为了凑单人物对子样本，把孙立拥有的关系接口、吴用的整合计划和梁山群体执行整体借给宋江。**

---

## 1｜原始事实

### A. 宋江的直接路径确实受阻

第四十八回回顾前次进兵时，宋江明确总结祝家庄地利复杂，己方已有杨林、黄信、王英、秦明、邓飞等人被擒或受创，并表示若不能破庄救人便无颜回山。

这一段可以支持：

```text
宋江仍坚持破祝家庄这一方向
+
原有正面军事路径连续受阻
```

但“受阻”本身不自动生成 nx。

### B. 关键关系接口属于孙立，而非宋江

第四十九回，孙立在得知梁山两次失利、栾廷玉镇守祝家庄后，主动指出自己与栾廷玉同师学艺，并提出假作调任经过、进入庄内，再做里应外合。

关键变量是：

```text
能让祝家庄放下吊桥并接受来客的私人信任接口
= 孙立与栾廷玉的同门关系
```

这不是宋江自己持有的关系权限。

### C. 吴用接受并组织该方案

孙立献计后，吴用明确接受，请孙立等暂不上梁山，先去祝家庄执行此事。

所以方案组织也不是简单的“宋江主动去求人并借孙立通道”。现存文本呈现的是：

```text
孙立主动提出入口
→ 吴用认可并部署
→ 孙立团队执行潜入
```

### D. 第三次进攻依靠庄内外多人协同完成

第五十回中，孙立利用栾廷玉对自己的同门信任进入祝家庄，并通过假意助战、活捉石秀等动作取得信任；随后其同伴摸清门户、向被俘梁山好汉传递消息。第三次交战时，庄内内应放火、救人、守吊桥，与庄外军马共同完成破庄。

因此“成功”是明确的团队协同结果，而不是宋江单独借到一个接口后再次以自身权能完成全部结果。

---

## 2｜zx 证据：宋江在哪一层成立

本轮可以高置信支持宋江的 zx 状态候选：

- 破祝家庄这一总体方向没有由祝家庄或外部人物替他设定；
- 两次失利后，他没有退出方向；
- 第三次进攻仍由梁山一方公开发动；
- 破庄后现实格局被实际改变。

但应保持边界：

```text
宋江的zx候选
≠
梁山全体所有公开行动都自动算宋江个人zx证据
```

最终胜利只能辅助显影，不能把每个执行者的行为都借给主帅。

---

## 3｜nx 证据：为什么不能直接归宋江

现行 nx 准度卡允许：

```text
关键权限/关系通道在他者手里
→ 主体承认并借用该位置
→ 通过既有身份、旧交、关系网络取得帮助
```

“三打祝家庄”确实存在这样的关系接口，但本轮文本中最直接的主体是孙立：

```text
孙立拥有与栾廷玉的同门旧交
→ 孙立主动提出利用这条关系
→ 孙立亲自进入并取得信任
```

宋江方面没有同等清晰的：

```text
宋江主动选择关系接口
→ 宋江请求孙立开放该接口
→ 宋江沿该接口取得许可
```

所以若直接写“宋江 nx 高显影”，会把团队协作误写成个人关系功能。

---

## 4｜最近邻排除

### nx vs xn

本段吴用对多路行动的整合、里外配合、时机安排明显带有 `xn` 组织功能候选。

如果只看到“换策略、安排内应”就全部判 nx，会把“利用关系接口”与“主动组织运行方式”混为一谈。

### nx vs x

孙立与栾廷玉有旧交，不等于孙立“掌握祝家庄”。真正能开的只是一个信任入口，不是对庄内资源与权限的完整处分权。

### zx vs 团队胜利

破庄成功不能单独证明宋江的个人 zx。zx 仍需检查其自身决定接口、公开作用与决定范围，而不是把集体战果当个人属性。

---

## 5｜拿掉测试

### 拿掉孙立—栾廷玉同门关系

若孙立与栾廷玉没有既有信任，祝家庄就不会因“师兄弟来访”自然开放后门并接纳这一行人，中段关系入口明显消失。

说明该关系接口真实重要。

### 拿掉宋江本人

如果改由另一名梁山统帅继续执行同一套吴用—孙立里应外合计划，中段关系接口仍可成立。

这证明：

> 该 nx 型接口并不依赖宋江本人持有。

因此不能把它作为宋江个人 nx 的独立证据。

### 拿掉孙立本人

若没有孙立这个与栾廷玉具有直接同门关系的接口持有者，仅保留宋江继续正面攻庄，现有文本中的第三次潜入方案会失去关键入口。

这进一步证明中段功能的主体不能偷换。

---

## 6｜反向测试

### 反向A：真正的宋江个人 zx→nx→zx

若文本写成：

```text
宋江自己的正面突破失败
→ 宋江主动找到一个他必须承认的外部权限主体
→ 宋江亲自请求并沿该主体既有关系/权限接口取得资源或通道
→ 宋江再把该接口重新转成自己的公开推进
```

才适合计入宋江个人 `zx→nx→zx` 正例。

### 反向B：团队链

现有文本更接近：

```text
宋江/梁山：维持破庄方向
→ 孙立：提供并持有关系入口
→ 吴用：整合方案
→ 孙立团队：庄内执行
→ 宋江一方：庄外配合
→ 团队破庄
```

这是一条跨人物分工链，不是同一个人物内部的 zx/nx 切换。

## 7｜第三因素冻结

以下均不得直接判十元：

- 宋江是梁山首领；
- 吴用是军师；
- 孙立武艺高；
- 梁山最终获胜；
- 祝家庄地势险要；
- 前两次有人被俘；
- 孙立与栾廷玉是同门；
- “里应外合”四个字本身。

真正支持本轮结论的是：

```text
关系接口的实际持有人是谁
+
谁主动提出并调用该接口
+
谁组织运行方式
+
谁公开推进结果
```

只有四项主体归属不被偷换，才能把 zx/nx 动态链写到单个人物身上。

## 8｜跨作品计数处理

此前两条可作为单人物链继续保留：

```text
《西游记》孙悟空·红孩儿：
zx直接路径受阻
→ 本人进入龙王/观音既有权限网络
→ 本人重新诱敌与推进

《三国演义》孙策·借兵取江东：
zx自身方向受兵力缺口限制
→ 本人向袁术借军权/兵马接口
→ 本人重新渡江扩张
```

本轮《水浒传》三打祝家庄不计入第三条，因为：

```text
中段关系接口主体 = 孙立
组织主体 = 吴用/梁山集体
庄外方向与进攻主体 = 宋江一方
```

因此：

```text
cross_work_support_count_for_single_actor_zx_nx_zx_chain = 2
```

不建立“三作品已验证”的待审议问题。
