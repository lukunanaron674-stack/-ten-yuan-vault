# 历史｜诸葛亮建兴元年开府治事｜zx-nx 名义上级伪 nx 压力测试

## 1｜本轮问题

待审议问题已经连续锁到三类正向证据：当关键审批、资源或配置接口真实掌握在外部，而且外部主体能够实际拒绝、修改、不放行时，该对象层的 nx 证据明显增强。

本轮专门做反向测试：

> 如果名义上仍有更高君主，但史料直接记载日常政务实际由主体自行裁决，是否还能仅凭君臣层级判 nx？

结论：不能。

## 2｜剧情 / 史实事实

### 触发

章武三年刘备去世，刘禅继位，蜀汉进入新君与托孤辅政结构。

### 对象

本轮只检查“蜀汉日常政务的实际决策接口”，不扩大到君臣名分、皇位归属、祭祀礼制或诸葛亮稳定人格。

### 明确动作与结果

《三国志·蜀书·诸葛亮传》记建兴元年：

- 诸葛亮封武乡侯；
- 开府治事；
- 随后领益州牧；
- “政事无巨细，咸决于亮”。

同段还直接记载诸葛亮面对南中叛乱时自行判断新遭大丧、暂不加兵，并遣使聘吴、结为与国，显示其并非只持一个空名或逐项等待外部批准。

《资治通鉴》卷七十同样记载刘禅即位后封诸葛亮武乡侯、领益州牧，“政事无巨细，咸决于亮”，随后诸葛亮约官职、修法制。

结果不是“皇帝名义在上，所以所有政务最终都必须重新回刘禅批准”，而是史料直接把政务实际裁决位置写在诸葛亮一侧。

## 3｜zx / nx 分类

### 纯 nx：排除

如果只看形式层：

```text
刘禅 = 皇帝
诸葛亮 = 丞相
```

很容易机械推出：诸葛亮仍须沿皇帝权限通道推进，因此是 nx。

但本轮真正需要检查的是实际对象层：

```text
蜀汉日常政务
↓
史料直接记“无巨细，咸决于亮”
↓
诸葛亮可以开府治事、约官职、修法制、处理外交与叛乱节奏
↓
实际决策接口稳定落在诸葛亮
```

所以在“日常政务实际裁决层”锁：

`nx_in_state_affairs_decision_layer: rejected`

名义上存在更高君主，不足以证明关键权限真实外置。

### x 最近邻：锁定

本阶段最硬的不是 nx，而是 x：

> 这块政务处分权已经在现实运行中稳定归诸葛亮调用。

因此锁：

`x_actual_authority_neighbor: evidence-locked`

### zx：不在本轮锁高纯

“开府治事、领益州牧、政事咸决于亮”确实带有决定范围上升的表象，但本轮没有把刘备在世末期诸葛亮已有权限、托孤安排、刘禅正式授权以及建兴元年的实际扩张过程逐项冻结到足以区分“授权后的 x”与“主体自身权能向外扩张的 zx”。

所以：

`zx_transition_expansion: not_locked`

不能因为权很大，就反手把 x 又误判成 zx。

### 严格 zx+nx：排除

本轮没有证明两端各自独立成立，更没有证明拿掉任一端会出现可重复的补缺结构，因此不锁严格 zx↔nx 补关系。

## 4｜关键压力

关键压力不是“刘禅年轻”或“诸葛亮威望高”，而是：

> **名义最高权位与实际日常决策接口出现分离。**

这种分离正好压力测试待审议中的四问：

1. 谁名义上拥有最高权位？刘禅。
2. 谁在当前对象层实际作出日常政务决定？诸葛亮。
3. 是否有文本证据显示每项关键政务都必须回到刘禅并受其真实否决？本段相反，直接记“咸决于亮”。
4. 因此能否仅凭“君臣层级”判 nx？不能。

## 5｜拿掉测试

### 拿掉“皇帝 / 丞相”头衔

只保留：

```text
名义组织层仍有上级
但实际日常事务无巨细由主体裁决
```

nx 仍然不能成立；x 实际权限仍可成立。

### 拿掉诸葛亮“忠臣 / 权臣 / 名相”评价

只看谁实际决定政务，结论不变。因此道德评价、历史立场不参与分类。

### 拿掉“政事无巨细，咸决于亮”

如果只剩“刘禅任命诸葛亮为丞相、益州牧”，证据会大幅退化成名义授权，无法高置信排除 nx。说明这句关于实际决策接口的记载是本轮核心硬证据。

## 6｜反向测试

### 反向成真 nx

若史料呈现：

```text
诸葛亮只能拟议
↓
关键政务必须逐项奏刘禅
↓
刘禅会真实拒绝、修改、不放行
↓
诸葛亮必须按刘禅裁决重配
```

那么该政务对象层的 nx 会明显上升。

### 反向成 zx

如果能够进一步证明：诸葛亮原本不拥有某一决定范围，却依靠自身权能公开突破原边界，使刘禅及蜀汉制度被迫承认这一新增接口，那么才应在该扩权过程锁 zx。

本轮没有跨这一步。

## 7｜最近邻排除

### nx vs x

这是本轮核心最近邻：

- nx：关键权限真实在外部，我沿外部接口推进。
- x：关键权限已经稳定归我自行调用。

“政事无巨细，咸决于亮”直接把本段主判推向 x，而不是 nx。

### x vs zx

- x：这块权已经归主体实际处分。
- zx：主体正在把决定边界向原本不属于自己的范围公开推大。

本轮能高置信锁前者，不能偷锁后者。

### nx vs xn

诸葛亮约官职、修法制有组织运行成分，可检查 xn；但 xn 解释“怎么治理”，不回答“政务最终决策接口实际在谁手里”。

## 8｜第三因素冻结

全部冻结：

- 刘禅年龄；
- 诸葛亮忠奸评价；
- 托孤道德叙事；
- 诸葛亮个人能力与声望；
- 后续北伐成败；
- 皇帝与丞相的名义等级；
- “权臣 / 名相”主题标签。

只保留“谁实际作出政务决定、外部节点是否真实可否决”，结论仍成立。

## 9｜与 pending-review 的关系

本轮是当前“nx 真实外部权限需具可否决性”待审议问题的第一条高纯反向案例：

```text
正向：
外部节点能真实否决 / 修改 / 不放行
→ nx 权限关系证据增强

反向：
仅有名义上级
但实际事务稳定由主体自行裁决
→ 不能仅凭名义层级锁 nx
→ 优先检查 x
```

这支持把待审议问题继续理解为“证据纪律”，而不是简单增加一个身份判断规则。

## 10｜结论

本轮锁定：

- 事实置信：99
- 分类置信：97
- 日常政务决策层 nx：rejected
- x 实际权限邻近：evidence-locked
- zx 扩权过程：not_locked
- 稳定人物本体：不锁
- 严格 zx↔nx 补关系：不锁

最短纪律：

> **名义上有人在你上面，不等于关键权限真的在外面。判 nx 要看外部节点是否还能真实说“不”；若现实长期是“事情都由你决定”，优先检查 x，而不是拿组织架构图替权限事实作证。**
