# 《西游记》沙悟净流沙河归顺｜zx↔nx 木轴压力测试

## 结论先行

本轮锁定一个高纯 **nx 当前行为 / 关系位置正例**，但不升级为沙悟净稳定纯 nx 本体。

最小结构：

```text
观音给定未来方向：
等取经人 → 做徒弟 → 西天取经 → 功成免罪
        ↓
沙悟净明确接受
        ↓
不自行改写目标，不另建替代路线
        ↓
“洗心涤虑，再不伤生，专等取经人”
        ↓
木叉在流沙河明确指出取经人已经到达
        ↓
沙悟净确认身份后沿原安排归顺唐僧
= nx 当前行为 / 关系位置高纯成立
```

本轮不锁 `zx+nx` 严格补关系，也不把“曾经能战斗”倒灌成 zx。

## 1｜剧情事实、触发、对象、动作、结果

### 第八回：外部方向先被明确给定

沙悟净因天庭旧罪被贬流沙河，观音路过时劝他停止伤生，等待取经人，跟随取经人做徒弟上西天求经；并把“功成免罪、复其本职”作为后续结果。沙悟净明确回答愿意皈正，并担心取经人是否能到流沙河。观音进一步要求他挂着九个骷髅等待。其后文本明确写他“洗心涤虑，再不伤生，专等取经人”。

这意味着：

- 最终上位方向不是沙悟净自行设计；
- 等待不是为了自己搭建一个时间计划，而是沿观音给定的未来节点等待；
- 他真实改变行为，并长期维持等待状态。

### 第二十二回：通道被识别并激活

唐僧师徒到流沙河时，沙悟净最初并不知道他们就是取经队伍，因此与八戒交战。孙悟空去见观音后，木叉奉命来到流沙河，直接以“悟净”法名呼唤，并指出“取经人在此”。

沙悟净听见法名与取经人信息后立即出来确认。木叉说明观音先前安排仍然有效：早跟唐僧做徒弟、以骷髅和葫芦结法船渡唐僧。沙悟净随后进入唐僧队伍。

所以触发变量不是“被打输了”，而是：

```text
原外部任务一直存在
→ 当前对象身份终于被确认
→ 主体接上此前已经接受的方向
```

## 2｜nx 判断

本轮 `nx_behavior_function` 与 `nx_relation_position` 均锁定为 `evidence-locked`。

原因：

1. **方向外置**：等待谁、加入谁、往哪里走，均由观音预先给出；
2. **主体不抢最终重设位**：沙悟净没有在取经人到达后重新提出另一套人生方向；
3. **实际续接**：不是口头答应后继续原样吃人，而是停止伤生、等待，并在身份确认后归顺；
4. **通道真实存在**：木叉是观音指令的现实确认节点，唐僧是被指定的取经主体；
5. **无须主动求人**：本例再次证明 nx 不以“求人姿态”为必要条件，接受并持续沿外部方向推进同样可以成立。

本轮最短定义：

> **方向不是沙悟净定的；他认领并沿观音已经给出的取经通道继续。**

## 3｜为什么等待不是 xn

`xn` 的等待必须是主体为了自己组织的计划、节点和排程而主动等待。

本例则是：

```text
观音规定“等取经人”
→ 沙悟净按该节点等待
```

他没有：

- 自己决定取经人什么时候来；
- 主动设计取经路径；
- 建立识别、接应、排程系统；
- 重写取经任务的节点和成功条件。

因此：

`xn_in_waiting_and_joining_stage: rejected_as_primary`

这是非常典型的：

> **因为方向不在我，我等外部节点到来 = nx**

而不是：

> **为了我自己的计划主动等待 = xn**。

## 4｜zx 判断

第二十二回归顺窗口不锁 zx。

沙悟净此前确实有武力，也能与八戒交战，但：

- 武力强不是 zx；
- 在不知道对方身份时交战，不等于在归顺阶段扩大自身决定范围；
- 木叉点明取经人后，沙悟净没有公开推翻观音安排，也没有迫使取经队围绕新的“沙悟净方向”重排。

因此：

`zx_in_joining_stage: rejected_as_primary`

若只因为“他之前打得很凶”就把后续归顺写成 zx+nx，等于把相邻镜头当成同一对象层。

## 5｜最近邻排除

### nx vs xn

- `nx`：观音给出未来节点，沙悟净沿该节点等待并续接；
- `xn`：若沙悟净自己设计一个等待、识别、接应和取经运行方案才上升。

本例明显偏 nx。

### nx vs x

取经方向、唐僧徒弟资格与功成免罪的最终安排都不在沙悟净自己稳定处分范围，因此不是 x。

### nx vs zx

归顺后没有扩大决定范围，没有使取经结构围绕其新增权能重排，因此不锁 zx。

### nx vs 外部强迫

观音确实用“停止飞剑、功成免罪”提供强烈利益与压力背景，但沙悟净不是在当场暴力压制下被机械推进。他先明确接受，再持续等待，第二十二回身份确认后继续沿原通道。因此压力解释动机，不替代 nx 的方向来源证据。

## 6｜拿掉测试

### 拿掉飞剑惩罚和复职奖励

只保留：

```text
观音给定等待取经人的方向
→ 沙悟净明确接受
→ 停止伤生并持续等待
→ 取经人到达后沿原安排归顺
```

nx 行为结构仍成立，只是动机强度下降。

### 拿掉木叉的身份确认

唐僧队伍到河边时，沙悟净此前不知道他们就是取经人，因此仍交战。说明“当前通道是否被识别”为真实激活条件。

### 拿掉观音此前安排

如果第二十二回只剩“木叉临时叫他加入唐僧”，则仍可能是一次 nx 行为，但本例最有价值的“预先给定方向 → 等待 → 节点到来后续接”证据会消失。

## 7｜反向测试

### 反向成 xn

```text
观音只说“以后自寻出路”
→ 沙悟净自己设计何时、如何识别取经人
→ 自己安排接应、渡河、加入与行程节点
= xn 上升
```

### 反向成 zx

```text
木叉要求按观音安排归顺
→ 沙悟净公开拒绝并重新定义取经方向
→ 唐僧队伍被迫围绕他的新增决定位置运行
= 才检查 zx
```

### 反向成伪 nx

若沙悟净只是因为被八戒打败才被迫投降，而没有观音既有方向、没有等待、没有身份确认后的主动续接，则不能用本案证明当前 nx。

## 8｜第三因素冻结

冻结：

- 沙悟净战斗力；
- 卷帘大将身份；
- 飞剑惩罚强度；
- 是否善良；
- 取经最终成功；
- 佛教主题；
- 后期沙悟净是否沉默听话。

只问：

```text
最终方向从哪里来？
主体是否重写？
等待属于谁的节点？
身份确认后是否实际续接？
```

四项均支持本轮 nx。
