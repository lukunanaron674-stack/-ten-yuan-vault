# 角色归档卡｜约翰·基廷｜zn + z

## 1. 角色定性

- 作品：《死亡诗社》
- 角色：约翰·基廷
- 主十元：zn
- 辅助十元：z
- 主辅合成判断：zn + z
- 角色功能：用诗歌点燃学生对生命意义的追问——反叛是教学法
- 命运主题位置：zn 本体型——意义启蒙者与体制的对抗
- 一句话判词：他是 zn——教诗歌不是教文学，是教人如何活着。z 是教学法：站上桌子、撕掉教科书、让学生叫他船长——用冲击打破麻木。体制（x）赶走了他，但学生站上了桌子——zn 的种子被 z 传递了。

## 4. 最短封存句

约翰·基廷｜zn+z：他教诗歌是教人活着。z是教学法——站上桌子、撕掉教科书。体制赶走了他，但托德站上了桌子。zn的种子被z传递了——不需要他在场。
