# 角色归档卡｜聂隐娘｜x + xz

## 1. 角色定性

- 作品：《刺客聂隐娘》
- 角色：聂隐娘
- 主十元：x
- 辅助十元：xz
- 主辅合成判断：x + xz
- 角色功能：被训练成刺杀工具的女人——在杀与不杀之间收回自己的意志
- 命运主题位置：zx+nx 因果型——放下剑不是投降，是选择
- 一句话判词：她是 x——被道姑训练成刺客，欲望是完成任务后获得自由。但她活在 xz 里：与田季安的过往是一道未愈的伤口，让她在刺杀时犹豫。最终 x（刺客本能）被 nz（残存的情感归属）克住——她放下剑，不是为别人，是为自己。

## 3. 动态链

被道姑带走 → x 建立：训练成刺客
→ xz：对田季安的未愈合伤口
→ zx：潜伏、接近、刺杀任务
→ nz 残影：不忍下手
→ xn 施压 → 与 nz 对峙
→ 放下剑 → xz 转化为自由
→ nz 新方向：磨镜少年

## 4. 最短封存句

聂隐娘｜x + xz：她是一把被造出来杀人的剑。但面对曾经属于过的人，x 被 nz 的残影克住了。道姑说杀，她说不了。放下剑不是投降——是第一次为自己做选择。xz 的伤口还在，但不再是枷锁——是让她能走开的理由。
