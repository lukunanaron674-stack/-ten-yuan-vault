# 角色归档卡｜山音麦｜n + xn

## 1. 角色定性

* 作品：《花束般的恋爱》
* 角色：山音麦
* 主十元：n
* 辅助十元：xn
* 主辅合成判断：n + xn
* 角色功能：把爱情变成可持续、可规划、可被现实接住的二人生活
* 命运主题位置：归宿被现实重判的一方
* 一句话判词：他想让爱被现实接住，这是 n；但他用判断、规划、工作和现实节奏来证明爱能持续，这是 xn。

## 2. 主辅十元解释

| 位置 | 十元 | 内容 | 判断 |
|------|------|------|------|
| 主十元 | n | 让关系被现实接住，成为可持续的二人生活 | 麦的核心不是工作，而是"承载关系" |
| 辅助十元 | xn | 判断关系是否可持续，并用工作、收入、规划、结婚逻辑维持关系 | xn 是麦判断关系成立的方式，后期会反客为主 |
| 角色定性 | n + xn | 用现实承载关系，用判断和规划证明关系可持续 | 现实化归宿者 |

## 3. 剧中十元互动表

| 剧中十元 | 在剧情中的形态 | 和主十元 n 的关系 | 和辅十元 xn 的关系 | 对角色造成什么变化 | 一句话故事 |
|----------|----------------|-------------------|---------------------|---------------------|------------|
| z | "我们一样"的共同趣味、共同审美、共同语言 | 和 n 不是直接点燃关系；n 只是后来接收这个判断，把关系放进生活承载 | z 点燃 xn。共同趣味被麦读成"我们同频，所以关系可持续"的证据 | 早期 z 让麦相信关系可以被规划和维持；后期 xn 反过来压缩 z | 共同趣味没有直接变成归宿，而是先变成麦判断关系可持续的证据；后来这个判断系统接管关系，把最初的亮点压成回忆。 |
| nz | 被理解、同类感、停靠感、两人在一起的柔软归属 | nz 是 n 想接住的对象：麦想把这份停靠变成长期生活 | xn 会把 nz 翻译成"这段关系能不能稳定运行" | nz 从感受性归宿，逐渐被麦翻译成现实可持续性 | 麦不是只想沉浸在停靠感里，他想把这份停靠做成能长期运行的生活。 |
| x并z | 书、电影、音乐、共同审美、生活气味、两人的共同世界外壳 | x并z 补足 n，让生活不只是生活，而像"我们的世界" | xn 后期压缩 x并z：没时间共享、没精力更新 | 早期让 n 有温度；后期衰退后，n 变成干燥现实结构 | 书影音曾经给生活裹上一层"我们的世界"，后来这层外壳褪掉，麦留下的只是能运转的日常。 |
| zx | 找工作、做现实选择、进入社会轨道、最后分手决定 | zx 改写 n：每一次行动选择都重塑两人的生活承载 | zx 强化 xn：行动越多，规则越强，规划越像唯一答案 | 生活更稳，关系更硬，麦越来越相信现实选择本身 | 每一次"为了未来"的选择，都让生活更稳一点，也让关系更硬一点。 |
| xz | 停靠失效、分离、错过、漂流感 | n 没能接住 nz，最终滑向 xz | xn 过强后，反而制造 xz：稳定结构还在，归宿感不在 | 麦越想稳定关系，越把关系推向漂流式分离 | 他想用稳定克住漂流，最后漂流从稳定里长出来。 |

## 4. 生克补原因分析

| 关系类型 | 十元关系 | 是否成立 | 原因 | 对山音麦 n + xn 的影响 |
|----------|----------|----------|------|------------------------|
| 生 | n 生 xn | 强成立 | 麦想让关系稳定，自然生出工作、收入、规划、结婚逻辑 | xn 从辅助 n，逐渐接管 n |
| 补 | n 需要 x并z 补 | 早期成立，后期衰退 | n 需要共同审美、生活气味、关系外壳，才能不变成普通稳定 | 补位衰退后，n 变干燥 |
| 克 | zx 克 n | 中后期成立 | 主动现实选择不断改写原本柔软的生活承载 | 生活更稳，关系更硬 |
| 结果滑落 | n 未能克住 xz | 后期成立 | n 被 xn 接管后失去温度，无法继续接住 nz | 关系从停靠滑向漂流 |

## 5. 动态链演化

```
山音麦｜n + xn

共同趣味 z
→ z 点燃麦的 xn 判断：我们同频，所以关系可持续
→ n 接收这个判断，把关系放进现实生活
→ n 生出 xn：工作、收入、职业节奏、未来规划
→ xn 逐渐接管 n
→ x并z 补位衰退：共同审美和生活气味变弱
→ zx 现实选择不断改写 n
→ n 变成干燥现实结构，接不住 nz
→ 关系滑入 xz 分离
```

## 6. 最短封存句

山音麦｜n + xn：
他想让爱被现实接住，这是 n；共同趣味 z 没有直接点燃 n，而是点燃了他的 xn 判断，让他相信"我们同频，所以关系可持续"。随后 n 接收这个判断，把关系放进现实生活。但 xn 后期反客为主，压缩 z 和 x并z，使 n 变成干燥结构，最终接不住 nz，关系滑入 xz 分离。
