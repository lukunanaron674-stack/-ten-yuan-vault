# 角色归档卡｜库珀｜n + xz

## 1. 角色定性

- 作品：《星际穿越》
- 角色：约瑟夫·库珀
- 主十元：n
- 辅助十元：xz
- 主辅合成判断：n + xz
- 角色功能：用行动承载对女儿的承诺——在时空漂流中守住回家的约定
- 命运主题位置：xn+z 时间型——时间膨胀是最残酷的距离
- 一句话判词：他是 n——离开地球不是为人类，是为墨菲能活下去。但他活在 xz 里：时间膨胀一小时=地球七年、星系漂流、与墨菲的时间线错位。不是引力方程让他回家，是 nz（对墨菲的爱）穿透了五维空间——n 的承诺跨越了时间。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和 n 的关系 | 和 xz 的关系 | 变化 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| z | 离开地球的决定、进入黑洞的选择 | z 点燃 n：每一次出发都是 n 的冒险 | z 对抗 xz：明知时间膨胀还要去 | n 从务农到宇航员——z 打开了一条不归路 | 他本可以留在地球陪墨菲长大——但z让他飞向了星空，也飞向了错过 |

## 3. 动态链

xz：地球末日 → n 承载：为墨菲出发
→ z：进入太空——每一次决定都在加注
→ xn：科学判断辅助——Plan A还是Plan B
→ x：曼恩背叛——人性黑暗面
→ xz 加深：一小时=23年——错过墨菲的成长
→ 坠入黑洞 → 五维空间
→ nz 穿透维度：爱=引力
→ n 完成：墨菲拯救人类，老年墨菲床前重逢

## 4. 最短封存句

库珀｜n + xz：他飞向太空是为了让女儿活下去。但 xz 是最残酷的距离——一小时就是地球上的23年。曼恩背叛了他，但墨菲的爱把他从五维空间拉回来。他在未来见到了老去的女儿——n 的承诺跨越了时间和维度。
