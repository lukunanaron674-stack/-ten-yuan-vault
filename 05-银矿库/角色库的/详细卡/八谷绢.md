# 角色归档卡｜八谷绢｜nz + z

## 1. 角色定性

* 作品：《花束般的恋爱》
* 角色：八谷绢
* 主十元：nz
* 辅助十元：z
* 主辅合成判断：nz + z
* 角色功能：守住共同感受，判断这段关系还配不配叫归宿
* 命运主题位置：停靠被现实稀释后选择重判的一方
* 一句话判词：她想让爱保持柔软，这是 nz；她用审美和判断来验证柔软还在不在，这是 z。

## 2. 主辅十元解释

| 位置 | 十元 | 内容 | 判断 |
|------|------|------|------|
| 主十元 | nz | 依恋、停靠、两人在一起时不被打散的柔软归属 | 绢的核心不是占有，而是感受性的停靠 |
| 辅助十元 | z | 判断停靠是否还在：书、漫画、舞台剧、共同审美是她的检测器 | z 是绢验证 nz 是否还成立的方式 |
| 角色定性 | nz + z | 用感受维系停靠，用判断验证停靠 | 停靠的守门人 |

## 3. 剧中十元互动表

| 剧中十元 | 在剧情中的形态 | 和主十元 nz 的关系 | 和辅十元 z 的关系 | 对角色造成什么变化 | 一句话故事 |
|----------|----------------|---------------------|---------------------|---------------------|------------|
| xn | 麦的工作节奏、结婚逻辑、现实规划 | xn 不直接攻击 nz，而是让 nz 失去承接对象 | xn 和 z 不共振：麦的规则判断和绢的精神判断无法对频 | nz 依然在，但麦不再回来承接；z 持续验证，验证结果越来越负面 | 麦把爱变成规则系统，绢用审美继续检测：系统在运转，但停靠没了。 |
| xz | 东京、就业压力、时间流逝、漂流感 | xz 侵蚀的不是 nz 本身，而是 nz 赖以存在的 n 容器 | xz 让 z 的检测标准越来越严：停靠还在吗？什么时候消失的？ | nz 满溢但 n 容器空了，最终滑向 xz 分离 | 不是不爱了，是爱找不到地方停。 |
| x并z | 同居的家、书影音、共同审美世界 | x并z 是 nz 的容器外壳，让停靠有形状 | x并z 喂养 z：共同审美不断更新，z 就有东西可判断 | x并z 衰退后，nz 只剩感受没有形状，z 只剩下"还在不在"这个空问题 | 书影音曾经是两个人共用的语言，后来只剩一个人在翻旧书。 |
| n | 家的物理空间、日常生活的稳定结构 | n 本该承接 nz，但麦离开后 n 变成空容器 | z 检测到 n 空了：规则还在，归宿不在 | nz 在空 n 里积累到满溢，最终只能重判 | 她留在家里，但家已经不是"一起"的了。 |

## 4. 生克补原因分析

| 关系类型 | 十元关系 | 是否成立 | 原因 | 对绢 nz + z 的影响 |
|----------|----------|----------|------|---------------------|
| 生 | z 生 nz | 始终成立 | 共同审美越被验证，停靠感越真实 | z 持续喂养 nz，让绢相信关系还活着 |
| 补 | nz 需要 x并z 补 | 早期成立，后期衰退 | 停靠需要共同世界的形状来承载 | x并z 衰退后，nz 变成无处安放的感受 |
| 克 | xn 克 nz | 间接成立 | 麦的规则系统让 n 容器空掉，nz 失去承接 | nz 还在，但找不到对象 |
| 结果 | z 重判 nz | 后期成立 | z 持续检测，最终判定停靠已失效 | 绢主动结束关系——不是放弃，是重判 |

## 5. 动态链演化

```
八谷绢｜nz + z

共同趣味 z
→ z 持续喂养 nz：每一次审美共振都在确认"我们还在一起"
→ nz 在 x并z 的容器里被稳稳承接
→ 麦的 xn 接管关系，n 容器逐渐变空
→ z 持续检测，发现 nz 失去了承接对象
→ x并z 衰退，nz 只剩感受没有形状
→ z 做出重判：这段关系不再配叫归宿
→ nz 完成最后的依恋，放手
→ 关系滑入 xz 分离
```

## 6. 最短封存句

八谷绢｜nz + z：
她想让爱保持柔软，这是 nz；她用共同审美持续验证柔软还在不在，这是 z。麦把关系改写成规则系统后，z 的检测结果越来越负面，nz 在空容器里满溢。最终 z 重判：停靠已失效。绢放手——不是不爱了，是归宿的定义不再成立。
