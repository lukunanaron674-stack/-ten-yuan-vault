# 角色归档卡｜周慕云｜xn + xz

## 1. 角色定性

- 作品：《2046》
- 角色：周慕云
- 主十元：xn
- 辅助十元：xz
- 主辅合成判断：xn + xz
- 角色功能：用写作和回忆归档情感——活在过去的判断和永恒的漂流之间
- 命运主题位置：xn+z 时间型——被过去的判断锁住，漂流变成家
- 一句话判词：他是 xn——用写作分析每段感情、用"不承诺"保护自己。但他活在 xz 里：从苏丽珍的错过开始，进入永恒的漂流。和一个又一个女人靠近，但永远不进入她们的 2046 房间。2046 不是目的地——是他选择不进入的房间。

## 3. 最短封存句

周慕云｜xn + xz：他不是浪子，是档案管理员——用 xn 给每段感情盖章归档，然后继续漂流。2046 不是目的地，是他选择不进入的房间。在 xz 里待久了，漂流变成了家。苏丽珍是第一个也是最后一个——xn 锁住的门，z 再也敲不开。
