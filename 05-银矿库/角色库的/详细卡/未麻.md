# 角色归档卡｜未麻｜zn + x

## 1. 角色定性

- 作品：《未麻的部屋》
- 角色：雾越未麻
- 主十元：zn
- 辅助十元：x
- 主辅合成判断：zn + x
- 角色功能：偶像转型演员——在镜头和被窥视中追问"哪个是我"
- 一句话判词：她是 zn——"我是谁？"——偶像未麻、演员未麻、网站上的"真正的未麻"。x——被凝视的欲望、被占有、被复制——x让她成为所有人的幻想，唯独不是自己。最后镜子里——"我是真的哦"——zn找到了答案？还是xn造了另一个幻觉？

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和zn的关系 | 和x的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 转型——从偶像到演员，身份的撕裂 | xz是zn的容器——追问在撕裂中发生 | xz被x加深——每一个角色都在剥掉一层她 | 她拍了被强暴的戏——那不是角色，是她自己的一部分死掉了 |
| xn | "未麻的部屋"网站——另一个"我"在写日记 | xn挑战zn——谁在写？谁是真的？ | xn被x利用——窥视者掌握了叙事 | 网站上的未麻知道她每天穿什么——那比镜子里的更像真的 |
| zx | 杀戮——一个个死去的人 | zx是x的落地——被压抑的暴力爆发 | - | 摄影师死了、编剧死了——是她杀的吗？她不知道 |

## 3. 最短封存句

未麻｜zn+x：她转型演员，但镜头比镜子更残酷。网上有另一个未麻在写她的日记——比她更了解她。最后镜子里她笑了——"我是真的哦"。zn找到了答案——还是xn造了另一个自己？你看不出来——她也看不出来。
