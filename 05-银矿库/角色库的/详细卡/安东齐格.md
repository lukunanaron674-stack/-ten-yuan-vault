# 角色归档卡｜安东·齐格｜xn + x

## 1. 角色定性

- 作品：《老无所依》
- 角色：安东·齐格
- 主十元：xn
- 辅助十元：x
- 主辅合成判断：xn + x
- 角色功能：用硬币决定生死——规则包装下的纯粹暴力
- 一句话判词：他是 xn——抛硬币决定杀不杀你：这是规则，不是情绪。x——杀人不是手段，是存在方式。xn让暴力像自然法则，x让他成为因果链里无法预测的变量。

## 3. 最短封存句

安东·齐格｜xn+x：他杀你不是因为恨——是硬币反面。x是最纯粹的暴力，xn是用规则包装它的皮。猎人在追他——但他不是猎物。他是因果链里那颗不按物理定律飞的子弹。
