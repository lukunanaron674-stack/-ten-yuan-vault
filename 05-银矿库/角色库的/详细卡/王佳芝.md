# 角色归档卡｜王佳芝｜z + xz

## 1. 角色定性

- 作品：《色戒》
- 角色：王佳芝
- 主十元：z
- 辅助十元：xz
- 主辅合成判断：z + xz
- 角色功能：被理想点燃的学生——在扮演和真情之间漂流至毁灭
- 命运主题位置：zx+nx 因果型——一个冲动毁掉全部计划
- 一句话判词：她是 z——被爱国热情点燃，入戏越来越深。xz 是扮演的代价——学生/麦太太/情人三重身份的撕裂。鸽子蛋不是爱情——是 z 在 xz 里最后一次不受控制的冲动。代价是所有人的命。

## 2. 剧中十元互动表

| 剧中十元 | 在剧情中的形态 | 和z的关系 | 和xz的关系 | 对角色造成什么变化 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| zx | 暗杀计划——每一次靠近易先生 | zx是z的落地——冲动变成任务 | zx加深xz——扮演越深撕裂越重 | 从演戏变成入戏 | 她第一次和易先生上床——那是任务，但身体不会撒谎 |

## 3. 动态链

z：爱国热情 → 加入暗杀
→ zx：扮演麦太太
→ xz：身份撕裂开始
→ x：易先生的占有——暴力与占有
→ nz：在邝裕民和易先生之间
→ xn：组织催促动手
→ z冲破xn：快走！
→ xz永恒——所有人死
→ z的代价：六个人，一颗六克拉

## 4. 最短封存句

王佳芝｜z+xz：她以为自己是演员。z让她入戏，xz让她出不来。鸽子蛋不是爱情——是z在xz里最后一次不受控制的冲动。他走了，她死了，六个人陪葬。那颗钻石是真的——但代价也是。
