# 角色归档卡｜杰西｜z + xn

## 1. 角色定性

- 作品：《爱在黎明破晓前》
- 角色：杰西
- 主十元：z
- 辅助十元：xn
- 主辅合成判断：z + xn
- 角色功能：用一夜的冲动对抗所有现实判断——维也纳的黎明是xn的边界
- 命运主题位置：xn+z 时间型——一夜的z能否对抗黎明的xn？
- 一句话判词：他是 z——在火车上说服赛琳下车：不是计划，是冲动。xn——知道明天就要飞回美国、知道距离、知道概率。但 z 让他在维也纳走了一整夜。黎明时在火车站——xn 说再见，z 说六个月后这里见。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和z的关系 | 和xn的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| x并z | 维也纳——唱片店、摩天轮、河边、咖啡馆、深夜街头 | x并z是z的容器——城市为冲动提供了舞台 | x并z暂时屏蔽xn——在异国现实暂停了 | 他们在唱片店的试听间里——音乐和眼神，没人说话 |
| nz | 赛琳的回应——她也下了车 | nz被z点燃——一个人的冲动变成两个人的夜晚 | nz对抗xn——归属感让现实显得不重要 | 她说"你也该下车"——不是他一个人的冲动 |
| zx | 手相、写诗、打电话——每一个小游戏 | zx是z的延伸——用行动填满时间 | zx延迟xn——每一次行动都在推迟黎明 | 他让她假装打电话给朋友——其实是说给对方听 |

## 3. 动态链

z：说服赛琳下车
→ x并z：维也纳一夜
→ zx：手相、写诗、深夜游戏
→ nz：两人的默契——归属在建立
→ xn倒计时：黎明逼近
→ 火车站：xn说再见，z约六月后
→ zn：不知道会不会来——但约了

## 4. 最短封存句

杰西｜z+xn：一夜的维也纳。z让他敢拦下火车上的陌生人，xn告诉他天快亮了。他们在唱片店没说话，在河边喝酒，在凌晨的街头假装打电话。火车站——六个月后这里见。不知道会不会来，但冲动值得。
