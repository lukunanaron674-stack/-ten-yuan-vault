# 角色归档卡｜陈永仁｜nz + xz

## 1. 角色定性

- 作品：《无间道》
- 角色：陈永仁
- 主十元：nz
- 辅助十元：xz
- 主辅合成判断：nz + xz
- 角色功能：卧底警察——在黑暗里守住对光明的归属感
- 命运主题位置：xz+nz 命运型——漂流在黑暗中，靠内心归属撑住
- 一句话判词：他的核心是 nz——想做回一个好人，想被承认是警察。但他活在 xz 里：身份漂流、不被承认、随时暴露。nz 是他在 xz 里不塌的理由。

## 5. 动态链演化

`	ext
陈永仁｜nz + xz

警校被开除 → 进入 xz 卧底漂流
→ nz 被 xn 锚定：黄sir和警队是他归属的证明
→ zx 不断加深 xz：做恶以隐藏身份
→ x 黑暗世界时刻威胁
→ 黄sir坠楼 → xn 锚点断裂
→ nz 只剩内心坚守
→ 最终在天台被刘建明射杀
→ nz 未完成：想做回好人的愿望，死前都没实现
`

## 6. 最短封存句

陈永仁｜nz + xz：
他是想做回好人的卧底。nz 是他在黑暗里不塌的理由，xz 是他每天的生存状态。黄sir是他的锚，锚断了，他还在撑。最后在天台，他对刘建明说"我想做一个好人"——这是 nz 在 xz 里最后的呐喊。
