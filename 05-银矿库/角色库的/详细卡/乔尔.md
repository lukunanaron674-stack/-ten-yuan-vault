# 角色归档卡｜乔尔｜xn + xz

## 1. 角色定性

- 作品：《暖暖内含光》
- 角色：乔尔
- 主十元：xn
- 辅助十元：xz
- 主辅合成判断：xn + xz
- 角色功能：在记忆删除中重新判断爱情——删除是xn，逃跑是xz
- 一句话判词：他是 xn——删除记忆是一个判断：不值得记住。但在记忆里拉着克莱门汀跑过所有崩塌的场景——xz 在说舍不得。最后雪地里重新认识——知道会受伤，还是再来一次。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和xn的关系 | 和xz的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| z | 记忆里的克莱门汀——太鲜活了 | z对抗xn——记忆删不掉 | z点燃xz——不想让她消失 | 他在记忆里拉着她跑——不是逃避删除，是逃避没有她的世界 |
| x并z | 蒙托克海边、查尔斯河、雪地 | x并z是xz的容器——记忆的场景 | - | 他们在雪地里重新认识——场景没变，人也没变 |
| nz | 重新相遇——再来一次 | nz被xn质疑——知道结局 | nz被xz接受——受伤也可以 | 她说"我们可能会再恨对方"——他说"没关系" |

## 3. 最短封存句

乔尔｜xn+xz：删除记忆（xn）——不值得。在记忆里拉着她跑过崩塌的一切（xz）——舍不得。雪地里重新认识。知道结局——还是说"没关系"。
