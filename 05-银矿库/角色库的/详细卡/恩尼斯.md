# 角色归档卡｜恩尼斯·德尔马｜n + xz

## 1. 角色定性

- 作品：《断背山》
- 角色：恩尼斯·德尔马 (Ennis Del Mar)
- 主十元：n
- 辅助十元：xz
- 主辅合成判断：n + xz
- 角色功能：用沉默的承载守护一段不可能的关系，但恐惧让承载永远残缺
- 命运主题位置：xz+nz 命运型——被时代和恐惧切断的归属
- 一句话判词：恩尼斯是 n——他能承载关系，能维持日常。但 xz（社会压力、童年创伤、恐惧）像一把刀悬在头顶，让他永远不敢把承载变成真正的停靠。

| 辅助十元 | xz     | 社会恐惧、童年目睹同性恋被杀的创伤、无法公开的漂流状态   | xz 不是附加，是他生命的底色          |
| 角色定性 | n + xz | 在恐惧和压迫中勉力承载一段不能见光的关系          | 恐惧型承载者                |

## 5. 动态链演化

`	ext
恩尼斯·德尔马｜n + xz

童年创伤 x → 形成 xz 恐惧系统
→ 断背山 z + x并z：暂时克住 xz，n 第一次完整承载
→ 下山后 xz 回归：社会恐惧笼罩
→ 杰克 nz 不断靠近 → 恩尼斯 xz 不断退缩
→ n 只能残缺：四年见一面，短暂承载
→ 杰克死亡 → n 彻底断裂
→ 最终：两件衬衫叠在一起，n 只能在记忆里完整
`

## 6. 最短封存句

恩尼斯·德尔马｜n + xz：
他不是不爱，是不敢。n 能承载关系，但 xz（恐惧、创伤、社会暴力）让承载永远残缺。断背山是唯一 xz 被暂时克住的地方。杰克死后，他把两件衬衫叠在一起——那是 n 最后的、只存在于记忆里的完整承载。
