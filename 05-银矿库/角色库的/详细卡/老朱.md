# 角色归档卡｜老朱｜n + x并z

## 1. 角色定性

- 作品：《饮食男女》
- 角色：老朱
- 主十元：n
- 辅助十元：x并z
- 主辅合成判断：n + x并z
- 角色功能：用每周豪华家宴承载三个女儿——直到他自己打破规矩
- 命运主题位置：x并z+n 空间型——厨房和餐桌是家庭意义的容器
- 一句话判词：他是 n——妻子早逝后，用周日家宴把三个女儿绑在一起。x并z 是 n 的表达——东坡肉、蟹粉小笼、佛跳墙——每一道菜都是说不出口的爱。当他在饭桌上宣布娶锦荣——z 炸掉了所有人对"父亲"的判断。

## 3. 动态链

n周日家宴——承载家庭的仪式
→ x并z每一道菜——爱的容器
→ xn女儿们的判断——父亲不可以
→ xz味觉退化——表达被削弱
→ z宣布娶锦荣——炸掉所有判断
→ nz女儿们理解和祝福
→ n+x并z重组——家宴还在，但不再是规矩

## 4. 最短封存句

老朱｜n+x并z：做了几十年菜，没说过一句爱。周日家宴是n的仪式，每一道菜是x并z的表达——东坡肉、佛跳墙——那是他唯一的语言。味觉没了，但他还有话说——"我要娶锦荣"。他不是疯了，是饿了一辈子，终于给自己做了一道菜。
