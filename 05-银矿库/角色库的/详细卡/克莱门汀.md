# 角色归档卡｜克莱门汀｜z + xz

## 1. 角色定性

- 作品：《暖暖内含光》
- 角色：克莱门汀
- 主十元：z
- 辅助十元：xz
- 主辅合成判断：z + xz
- 角色功能：用冲动和变化对抗无聊——冲动也是她漂流的根源
- 一句话判词：她是 z——染蓝头发、说走就走。xz——变化不是自由，是不知道自己要什么的漂流。先删了乔尔，又在蒙托克海边重新遇到他。z让她不停靠近又远离——xz让她永远在路上。

## 2. 最短封存句

克莱门汀｜z+xz：染蓝头发、冲动删除记忆、在蒙托克海边重新出现。z让她像扑不灭的火，xz是火下面看不见的漂流。不是善变——是没找到能停下来的理由。但她还在找。
