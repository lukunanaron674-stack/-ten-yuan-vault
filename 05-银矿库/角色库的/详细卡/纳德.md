# 角色归档卡｜纳德｜xn + n

## 1. 角色定性

- 作品：《一次别离》
- 角色：纳德
- 主十元：xn
- 辅助十元：n
- 主辅合成判断：xn + n
- 角色功能：用原则和承载守护父亲和女儿——原则在现实面前变成枷锁
- 一句话判词：他是 xn——"我没有撒谎"——坚守原则。n——照顾老年痴呆的父亲、守护女儿的未来。但在法庭上 xn 和 n 相撞：承认就意味着坐牢，n 就崩溃了。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和xn的关系 | 和n的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 保姆流产、法庭审判 | xz测试xn——你是否真的没撒谎 | xz威胁n——家庭可能碎裂 | 保姆从楼梯上摔下去——他没推她，但他知道她怀孕了，没说 |
| nx | 西敏想出国——对女儿未来的追寻 | nx质疑xn——你的原则在毁掉家庭 | nx与n同向——都是为女儿 | 西敏说"跟我走"——他说"父亲需要我" |
| z | 女儿在法官面前等他 | z是xn的裂缝——为了女儿可以说谎 | z是n的终极守护 | 女儿在法官面前看着他——他知道她希望他说什么 |

## 3. 最短封存句

纳德｜xn+n：他为父亲擦身（n），为女儿争取未来（n）——但他不能说谎（xn）。女儿在法官面前等他——xn 第一次裂了。不是不够爱——是两种爱撞在了一起。
