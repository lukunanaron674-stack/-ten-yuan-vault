# 角色归档卡｜市子｜n + x并z

## 1. 角色定性

- 作品：《小森林》
- 角色：市子
- 主十元：n
- 辅助十元：x并z
- 主辅合成判断：n + x并z
- 角色功能：用日常劳作和自然节奏承载自己——从逃离到真正回归
- 命运主题位置：x并z+n 空间型——小森林是用劳作和季节治愈漂流的容器
- 一句话判词：她最初是逃离——xz 逃避城市和失败的关系。但小森林给了她 n：种地、做饭、四季循环——用劳作承载自己。x并z（稻米、番茄、果酱、雪、蝉鸣）不是装饰，是让 n 有温度、有味道、有意义的容器。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和 n 的关系 | 和 x并z 的关系 | 变化 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| xz | 城市失败、关系破裂、逃离 | xz 是 n 的起点：因为漂流才开始承载 | xz 被 x并z 治愈：自然节奏消解焦虑 | 从逃回来变成住下来 | 她回来时以为只是暂住——种完了第一季稻子，她已经不想走了 |
| z | 妈妈的料理记忆、尝试新菜品 | z 点燃 n：记忆驱动劳作 | z 通过 x并z 实现：妈妈的菜谱需要食材和季节 | n 从应付变成享受 | 她复刻了妈妈每一道菜——不是想家了，是想懂她 |
| zn | "我为什么在这里？"的追问 | zn 检验 n：劳作是因为逃避还是选择 | zn 被 x并z 回答：四季本身就是答案 | 秋天收了稻子，冬天铲了雪——春天再回来时，她知道这就是家了 | 春天又来了——她不再问为什么留下 |

## 3. 动态链

xz：城市失败 → 逃回小森林
→ n 建立：种地、做饭、自给自足
→ z：妈妈的记忆、尝试复刻
→ x并z 补 n：四季食材让劳作的果实可以品尝
→ zn 追问：我为什么在这里？
→ x并z 回答：春天又来了——这就是理由
→ n 从逃离变成回归

## 4. 最短封存句

市子｜n + x并z：她逃回来时以为自己是失败者。但种地、做饭、四季轮回——n 慢慢把她接住了。x并z 不只是食物和风景，是让 n 变得可以品尝的东西。春天又来了——她不再问为什么留下。
