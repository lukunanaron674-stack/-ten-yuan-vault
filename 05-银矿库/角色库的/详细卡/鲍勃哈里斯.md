# 角色归档卡｜鲍勃·哈里斯｜xn + xz

## 1. 角色定性

- 作品：《迷失东京》
- 角色：鲍勃·哈里斯
- 主十元：xn
- 辅助十元：xz
- 主辅合成判断：xn + xz
- 角色功能：过气明星在异国漂流中遇见同类——短暂的交汇
- 一句话判词：他是 xn——中年危机、婚姻冷却——用幽默和理性判断处境。xz——东京霓虹、语言不通——彻底的漂流者。夏洛特是另一个漂流者——两个在xz里的人短暂互相接住了。

## 3. 最短封存句

鲍勃·哈里斯｜xn+xz：东京霓虹里找不到位置。夏洛特也找。不是相爱——是在同一个xz里认出了彼此。最后的耳语谁也没听到——那是两个漂流者之间的nz。
