# 角色归档卡｜楚门｜zn

## 1. 角色定性

- 作品：《楚门的世界》
- 角色：楚门·伯班克
- 主十元：zn
- 辅助十元：无
- 主辅合成判断：zn
- 角色功能：在被设计好的人生中追问真实——帆船戳破天空
- 命运主题位置：zn 本体型——"我是真实的吗？"
- 一句话判词：他就是 zn。"早上好，如果再见不到你，下午好，晚上好"——微笑下面是追问。全世界都是布景——xz 只是他 zn 的背景。帆船戳破天空那一幕，不是他变勇敢了——是 zn 终于比背景大了。鞠了一躬，走进黑暗——zn 不需要完美的世界，只需要真的。

| x | 导演克里斯托弗——控制一切的欲望 | x对抗zn：不要追问，留在这里 | zn击败x | 帆船戳破了天空——那不是墙，是画 |

## 3. 动态链

zn追问：我是真实的吗？
→ xz：全世界都是布景
→ zx：一次次尝试逃离
→ x：导演阻止
→ zn穿透xz：帆船戳破天空
→ zn胜利：走出那扇门
→ 观众nz释放：我们也是楚门

## 4. 最短封存句

楚门｜zn：他的世界是假的，追问是真的。xz只是背景——帆船戳破天空时碎了一地。他鞠了一躬，不是对导演，是对真实的自己。门外的黑暗不可怕——虚假的蓝天才可怕。
