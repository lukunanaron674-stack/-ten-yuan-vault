# 角色归档卡｜威廉·沙摩塞｜xn + nx

## 1. 角色定性

- 作品：《七宗罪》
- 角色：威廉·沙摩塞
- 主十元：xn
- 辅助十元：nx
- 主辅合成判断：xn + nx
- 角色功能：用经验和判断解读连环杀手的因果链——在罪恶面前选择不放弃
- 一句话判词：他是 xn——即将退休的老警探，用经验和理性判断每一起命案。nx——对正义的执着追寻。"这世界是美好的，值得为之奋斗"——他说同意后半句。xn看清了黑暗，nx选择继续点亮灯。

## 3. 最短封存句

威廉·沙摩塞｜xn+nx：他看过太多黑暗，差点退休。但nx让他留下来——不是为抓凶手，是为证明黑暗不是全部。约翰·杜设计了完美的布道，但沙摩塞走后说了句："我同意后半句"——世界值得奋斗。
