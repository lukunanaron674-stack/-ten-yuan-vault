# 角色归档卡｜篠原明里｜nz + n

## 1. 角色定性

* 作品：《秒速5厘米》
* 角色：篠原明里
* 主十元：nz
* 辅助十元：n
* 主辅合成判断：nz + n
* 角色功能：保留思念但让现实生活覆盖它
* 命运主题位置：停靠被现实承接后放下的一方
* 一句话判词：她一直保存那份柔情，这是 nz；但婚约和新生活覆盖了它，这是 n。

## 2. 主辅十元解释

| 位置 | 十元 | 内容 | 判断 |
|------|------|------|------|
| 主十元 | nz | 思念、约定、樱花树下的吻、旧日柔情 | 明里保留了柔软，但没有让柔软控制生活 |
| 辅助十元 | n | 婚约、新生活、现实稳定 | n 压住了 nz——不是删除，是覆盖 |
| 角色定性 | nz + n | 柔情还在，但现实更强 | 放下的幸存者 |

## 3. 剧中十元互动表

| 剧中十元 | 在剧情中的形态 | 和主十元 nz 的关系 | 和辅十元 n 的关系 | 对角色造成什么变化 | 一句话故事 |
|----------|----------------|---------------------|---------------------|---------------------|------------|
| xz | 转学、距离、时间 | xz 切断 nz 的通道：她无法见到贵树 | xz 反而成全 n：距离让她必须建立新生活 | nz 从"可以实现的约定"变成"只能保存的回忆" | 距离把可能变成了不可能，她接受了这个转变。 |
| z | 共同约定、旧信、对方的存在 | z 喂养 nz：每一次想起都让柔情活着 | z 和 n 不冲突：她的生活里有柔软的记忆，但柔软不占领生活 | nz 一直在，但不再指向"在一起" | 她记得，但记得不等于必须回去。 |
| zx | 她继续生活、结婚、有自己的轨道 | zx 补足 n：每一次现实选择都巩固新生活 | zx 不攻击 nz：她不是主动忘记，而是主动继续 | 她走着走着，就走远了——不是故意，是自然 | 她没有"切断"什么，她只是继续生活了。 |

## 4. 生克补原因分析

| 关系类型 | 十元关系 | 是否成立 | 原因 | 对明里 nz + n 的影响 |
|----------|----------|----------|------|----------------------|
| 补 | n 补 nz | 始终成立 | n 给 nz 一个位置：心里有，生活里也有 | nz 没有消失，只是被 n 承接下来 |
| 克 | n 克 nz | 后期成立 | 婚约和生活覆盖了"必须回到贵树身边"的可能 | nz 还在，但不再指向回去 |

## 5. 动态链演化

```
篠原明里｜nz + n

最初的连接
→ nz 生成：约定、樱花树下的吻、信
→ xz 拉开距离：转学、各自成长
→ n 开始生成：新环境、新生活
→ nz 从"可实现的约定"变成"保存的记忆"
→ n 逐渐覆盖 nz：婚约、稳定
→ 铁道口：nz 认出贵树，但 n 没有回头
→ 她走了——不是放弃，是 n 已经接住了 nz
```

## 6. 最短封存句

篠原明里｜nz + n：
她保存了最初连接，这是 nz；但新生活覆盖了它，这是 n。距离（xz）让 nz 从"可实现的约定"变成"只能保存的记忆"。她不是忘记贵树，而是 n 接过 nz，让柔软成为心里的一页，而不是唯一的方向。铁道口她没有回头——因为她的归宿已经在另一边了。
