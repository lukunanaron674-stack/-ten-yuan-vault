# 角色归档卡｜1900｜zn

## 1. 角色定性

- 作品：《海上钢琴师》
- 角色：1900
- 主十元：zn
- 辅助十元：无
- 主辅合成判断：zn
- 角色功能：88个琴键定义全部生命意义——在有限中弹奏无限
- 命运主题位置：zn 本体型——意义在边界内完成
- 一句话判词：他就是 zn。钢琴不是职业，是存在的全部。88个键是有限的，音乐是无限的。陆地太大、琴键太多——那不是他能驾驭的无限。爱情（z）差点让他下船——但他停在舷梯上。zn 不需要被世界看见，只需要被自己完成。船爆炸时他还在弹。

## 3. 动态链

zn：88个键=全部意义
→ z：舷梯上的女孩——差点下船
→ zn克z：停在舷梯上
→ x：陆地=无限=无法驾驭
→ zn选择xz：不下船
→ nz：麦克斯的见证
→ zn与船同沉——意义在边界内完成

## 4. 最短封存句

1900｜zn：他的世界只有88个琴键。爱情差点让他走下舷梯——但zn说不用。陆地太大——那不是他的钢琴。和船一起爆炸，麦克斯记得他。zn不需要陆地来证明——88个键够了。
