# 角色归档卡｜玉娇龙｜x + z

## 1. 角色定性

- 作品：《卧虎藏龙》
- 角色：玉娇龙
- 主十元：x
- 辅助十元：z
- 主辅合成判断：x + z
- 角色功能：被压抑的贵族少女——用野性欲望冲破一切束缚，燃尽后坠入虚无
- 命运主题位置：zx+nx 因果型——每一个反叛都把自己推向更深的孤独
- 一句话判词：她是 x——被官家小姐身份压制的野性欲望。z 是表达——偷剑、逃婚、独闯江湖。她不是在找自由——是烧笼子。李慕白为她而死——x被罪疚反噬。武当山纵身一跃——不是殉情，是x燃尽后的虚无。

## 3. 动态链

x被压抑：官家小姐的笼子
→ z爆发：偷剑
→ zx：逃婚、闯江湖
→ zn·李慕白：想收服她
→ z拒绝：不要师父
→ xz：李慕白为她而死
→ x被罪疚反噬
→ 武当山——x燃尽
→ z停下——纵身一跃

## 4. 最短封存句

玉娇龙｜x+z：她不是找自由——是烧笼子。x让她不服从一切，z让她不计后果。李慕白为她死了——那是她第一次停下来。武当山那一跳——不是殉情。x已经烧完了，笼子空了，人也没了。
