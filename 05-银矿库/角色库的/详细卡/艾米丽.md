# 角色归档卡｜艾米丽·普兰｜nz + xz

## 1. 角色定性

- 作品：《天使爱美丽》
- 角色：艾米丽·普兰 (Amélie Poulain)
- 主十元：nz
- 辅助十元：xz
- 主辅合成判断：nz + xz
- 角色功能：给予型温柔归宿者——用 nz 柔软缝合他人伤口，用 xz 警觉感知他人痛苦
- 命运主题位置：xz+nz 命运型——漂流中的温柔缝合者
- 一句话判词：她是给予型 nz，温柔、缝合、帮完就走；但她不是纯软，她有很强的 xz 警觉，能精准感知别人伤口，却不会把自己的伤口交出去。

## 5. 动态链演化

`	ext
艾米丽·普兰｜nz + xz

童年孤独 → 形成 xz 警觉（躲在暗处观察世界）
→ xz 感知他人伤口 → 生出 nz 温柔缝合冲动
→ zx 行动力让 nz 落地：设计小善举
→ 巴黎 n 承载位提供舞台和安全感
→ 但 xz+nz 断归属：能接住别人，不交自己的伤口
→ 尼诺出现：同为 xz+nz 漂流者，互相接住
→ nz 终于有了归属对象
`

## 6. 最短封存句

艾米丽·普兰｜nz + xz：
她是给予型 nz，用温柔缝合他人伤口；她的 xz 警觉让她精准感知痛苦，zx 行动力让温柔落地。但她不会把自己的伤口交出去，直到遇到同为 xz+nz 漂流者的尼诺——他不是恋人，是接住她的人。巴黎是承载这一切的 n 容器。

## 7. 归档规则封存

角色卡先定：角色名｜主十元 + 可选辅十元
剧中其他十元不进入角色名，只进入互动表。
生克补只写原因，动态链放最后总结演化。
