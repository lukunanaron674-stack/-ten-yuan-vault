# 角色归档卡｜小林大悟｜n + x并z

## 1. 角色定性

- 作品：《入殓师》
- 角色：小林大悟
- 主十元：n
- 辅助十元：x并z
- 主辅合成判断：n + x并z
- 角色功能：用入殓仪式承载逝者尊严和生者告别
- 一句话判词：他是 n——大提琴手变入殓师，从演奏生命变成承载死亡。x并z——每一次入殓都是一场仪式：擦拭、穿衣、化妆——把死亡变成可以被接住的告别。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和n的关系 | 和x并z的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 乐团解散、回乡——失去身份 | xz推动n转向——从音乐到入殓 | xz被x并z转化——死亡变成仪式 | 大提琴卖了——下一个要碰的不是琴弦，是死者的手 |
| z | 妻子的不理解——"你不干净" | z冲击n——最亲近的人不接受 | z被x并z逆转——她看他入殓后哭了 | 妻子说"脏"——直到她看到他为澡堂奶奶入殓 |
| nz | 父亲最后一面——石头从手里掉下来 | nz是n的完成——承载了最重的人 | nz通过x并z完成——亲手为父亲入殓 | 他掰开父亲僵硬的手指——石头掉下来，他哭了 |

## 3. 最短封存句

小林大悟｜n+x并z：从拉大提琴变成给死者化妆。x并z让入殓不是收尸——是给告别一个能站着的仪式。亲手为父亲入殓——石头从手指里掉出来时，n终于完成了。
