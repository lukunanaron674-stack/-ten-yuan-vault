# 角色归档卡｜朴斗满｜nx + x

## 1. 角色定性

- 作品：《杀人回忆》
- 角色：朴斗满
- 主十元：nx
- 辅助十元：x
- 主辅合成判断：nx + x
- 角色功能：用直觉和暴力追寻连环杀手——追寻本身变成消耗
- 命运主题位置：zx+nx 因果型——每一轮逼近都在远离真相
- 一句话判词：他是 nx——用原始直觉和暴力审讯追寻凶手。x——愤怒、挫败、想用拳头打出真相。nx让他不停追，x让他不停失控。十七年后回到水沟旁——nx还在，但x烧成了凝视镜头的空洞。

| zx | 审讯、追捕、蹲点 | zx是nx+x的落地——每次行动都在靠近又远离 | zx被x驱动——暴力审讯是x的表达 | 每一次暴力审讯都让他更不像警察 | 他把嫌疑人按在水里——不是在审，是在发泄 |

## 3. 动态链

nx追寻：连环杀手
→ x暴力直觉：打、逼、压
→ zx行动：每一次出击
→ xn理性辅助：DNA、证据
→ xz凶手逃逸——水沟、隧道
→ nx+x被消耗——越来越远
→ 十七年后重返
→ zn：他长什么样？——普通

## 4. 最短封存句

朴斗满｜nx+x：他用拳头找答案。nx让他不停追，x让他不停失控。十七年后水沟旁——小女孩说凶手很普通。他盯着镜头——nx还在，但x已经烧空了眼睛。
