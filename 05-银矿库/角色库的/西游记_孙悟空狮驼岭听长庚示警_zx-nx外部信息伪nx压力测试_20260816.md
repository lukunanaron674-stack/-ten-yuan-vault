# 范围
仅截取《西游记》第七十四回“长庚传报魔头狠，行者施为变化能”中：长庚星君向取经队伍提供狮驼岭危险事实，到孙悟空自行决定侦察、变化并从小钻风处继续取得情报这一段。不得把此桥段倒推为孙悟空整个人物稳定本体。

# 剧情事实
1. 长庚星君提供狮驼岭妖魔危险、妖怪势力等外部事实信息，使孙悟空获得此前缺少的敌情输入。
2. 长庚并未替孙悟空取得通关许可，也未掌握孙悟空行动的最终军令或处分权。
3. 得到示警后，孙悟空自行决定进一步侦察，并使用变化、接近和盘问小钻风等方式继续补充敌情。
4. 侦察流程、变化方式、盘问信息等操作并非长庚提供的一套完整可执行解决方案。
5. 因此本段最清晰的外部贡献是“事实信息输入”，而非“外部主体占据最终方向/权限并要求孙悟空沿其通道执行”。

# 木轴判定

## zx
高纯 zx 在本窄阶段不成立。

孙悟空主动侦察、变化和盘问，能证明其行动主动性与自身能力，但没有出现新的决定范围、权限边界或凌驾位置公开扩大。不能把“主动、能打、会变、敢侦察”直接判为 zx。

本段更接近：主体使用自己已有能力解决问题；若讨论组织侦察方式，最近邻优先检查 xn。

## nx
纯 nx 本体明确排除。孙悟空并未把“是否西行、是否调查、怎样处理狮驼岭”这些最终方向交给长庚决定。

有限 nx 关系功能是否成立，暂不锁定。支持与反对理由如下：

### 支持 nx 的理由
- 关键敌情最初真实掌握在外部信息节点长庚手中。
- 孙悟空通过外部主体取得此前缺少的信息，降低了行动不确定性。

### 反对 nx 的理由
- 长庚提供的是事实输入，而非必须沿用的最终方向、权限、资源调用权或完整解决方案。
- 孙悟空得到信息后仍自行设计侦察与取情报方式，最终行动接口始终在自己一侧。
- 若凡“别人告诉我一个关键事实”都归 nx，则侦察、天气信息、诊断结果、普通情报输入都会被过度 nx 化。

因此本轮最小分歧点锁为：

> nx 的“外部解决通道”是否包含“只提供关键事实信息、但不占最终方案与行动权”的信息节点？

在正本没有足够直接规则前，不越过 95% 门槛。

# 最近邻排除

## nx vs xn
孙悟空得到外部示警后，主动决定怎样侦察、怎样变化、怎样盘问小钻风。这里“自己设计运行方式”更接近 xn；不能因为起点信息来自别人，就把后续组织能力算成 nx。

## nx vs x
孙悟空的变化、行动能力等属于自身已有可调用能力，不因长庚提供信息而发生权限转移。本轮不以 x 为主判，但需要冻结“已有能力”与“外部情报来源”两层。

## zx vs 主动性
主动进入危险区域、主动侦察并不自动意味着决定范围扩大。没有新增的现实决定接口，就不能仅凭主动性锁 zx。

# 拿掉测试
1. 拿掉长庚这一个具体人物，换成任何只提供同等可靠敌情的信息源，只要最终方案、侦察和行动权仍由孙悟空掌握，纯 nx 依然不能成立。
2. 拿掉长庚提供的敌情，孙悟空的信息缺口明显增大，但仍可以自行设计侦察方案。这说明长庚补的是信息缺口，而不当然等于提供完整解决通道。
3. 拿掉孙悟空自己的侦察组织与变化盘问，只剩长庚的警告，狮驼岭问题并不会自动被解决。因此外部事实信息与外部解决方案不能直接等同。

# 反向测试
1. 若长庚不仅提供敌情，还给出一套关键路线/节点/处置方案，而孙悟空主要沿该方案执行，则 nx 专业/解决通道证据会明显上升。
2. 若长庚掌握通关许可、必要资源或实际行动否决权，孙悟空必须经其授权才能推进，则 nx 权限通道会更清楚。
3. 若孙悟空从一个外部掌权节点夺取原本不属于自己的决定接口，并迫使现实秩序围绕自己的新增权能重排，才应检查 zx 上升。

# 第三因素冻结
冻结孙悟空武力、齐天大圣身份、最终胜负、狮驼岭妖怪强弱、长庚仙人身份、取经主题与后续战斗结果，只保留：信息由谁掌握、方案由谁形成、行动权归谁、是否发生权限扩张。结论仍为“外部事实信息是否计入 nx 解决通道尚有真实分叉”。
