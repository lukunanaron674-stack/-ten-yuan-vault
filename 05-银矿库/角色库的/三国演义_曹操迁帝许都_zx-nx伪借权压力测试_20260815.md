# 《三国演义》曹操迁帝许都｜zx↔nx 伪借权压力测试

## 一、本轮问题

本轮测试一个很容易被误判成 `zx+nx` 的结构：

```text
主体使用一个原本属于他者的高位权威名义
→ 是否必然属于 nx“借权限 / 借通道”？
```

结论：**不必然。**

如果关键权限仍由独立他者掌握，主体必须请求、等待、取得许可，才支持 `nx` 关系功能；若该权限接口已经被主体实际掌握，甚至可以自行决定、调用、伪造或代行，则不能再仅凭“用了他者名义”判 `nx`。

曹操迁献帝至许都后的窄阶段正好形成高纯度反例：

```text
表面：借天子 / 朝廷名义
实际：赏罚听曹操处置；朝廷大务先禀曹操；曹操可利用诏命接口推进自己的政治方向
→ nx rejected
→ zx 当前状态 / 关系位置高显影
→ 最近邻优先检查 x（权限与调用边界已归主体掌握）
```

本轮只锁这一阶段，不把曹操整个稳定人物本体直接锁成某一十元。

## 二、剧情事实

### 1. 触发：汉献帝回洛阳后朝廷残破，曹操以自身军力进入护驾与朝廷重建

第十四回中，献帝回到洛阳后宫室、城郭与供给严重破败，又面临李傕、郭汜威胁。朝廷此前已召曹操入朝。曹操随后以自己的军队击退李傕、郭汜，并取得更高朝廷位置。

这里不能因为“奉诏而来”就直接判 `nx`：奉诏只说明进入场景的一个合法接口，不能证明后续最终方向和权限仍在天子手里。

### 2. 明确动作：曹操决定推动迁驾许都

董昭提出迁驾许都后，曹操明确表示这本就是自己的方向，随后持续与谋士密议迁都，并亲自向献帝提出迁驾许都。

献帝“不敢不从”，群臣也因惧怕曹操势力而无人提出异议。

因此这一动作不是主体沿别人已经给出的具体方向继续，而是：

```text
主体形成迁都方向
→ 主体以自身军政力量推进
→ 天子与群臣被迫围绕其决定重新行动
```

支持 `zx` 当前状态 / 关系位置高显影。

### 3. 结果：迁许后，朝廷赏罚与重大事务实际先经过曹操

迁至许都并建立宫室、衙署等机构后，原文明确写出：

```text
赏功罚罪，并听曹操处置
自此大权皆归于曹操
朝廷大务，先禀曹操，然后方奏天子
```

这里是本轮最关键的 `nx` 排除证据。

如果曹操只是“借皇帝权威办事”，则应满足：

```text
皇帝 / 朝廷仍独立掌握许可
→ 曹操需要请求
→ 获得批准后才能调用
```

但实际结构已经反转：

```text
重大事务先过曹操
→ 再到天子
```

所以“天子名义”仍在，不等于“权限仍在天子手里”。

### 4. 后续验证：曹操利用朝廷诏命接口推进自己对刘备、吕布的布局

曹操担忧刘备与吕布联合，采纳荀彧“二虎竞食”方案，先通过朝廷诏命正式授刘备徐州牧等职，再附自己的密书要求刘备杀吕布。

这里更接近：

```text
主体已经控制 / 掌握朝廷接口
→ 用该接口包装并推进自己的方向
```

而不是：

```text
主体没有权限
→ 请求独立的朝廷主体替自己解决
```

因此不能把“用了诏命”机械记成 `nx`。

## 三、zx / nx 分层判断

### zx 证据

这一窄阶段满足：

- 迁许方向由曹操主动推动；
- 献帝和群臣的现实行动被曹操的军政力量重新组织；
- 迁许后重大朝廷事务先经过曹操；
- 曹操可以把朝廷接口转化成自己政治布局的现实工具；
- 决定范围从军阀自身势力扩大到中央朝廷决策层。

因此：

```text
曹操迁帝许都后的当前状态 / 行为功能 / 关系位置
= zx 高显影
```

注意：不是因为“曹操很强”“官大”“最后赢了”而判 `zx`，而是因为**主体成为现实方向与作用权的实际来源，并迫使原有高位结构围绕其权能重排。**

### nx 证据审查

表面上可见：

- 奉诏入朝；
- 使用天子名义；
- 使用朝廷诏命；
- 借汉室合法性影响诸侯。

这些都容易让人联想到 `nx` 的“借权限 / 走既有通道”。

但现行 `nx` 准度卡要求：

```text
权限和资源在别人手里，我沿通道借用
```

本段关键事实却是：

```text
权限接口已经实际被曹操掌握
```

因此：

```text
“使用外部名义” = nx 表象
“关键权限仍由独立他者掌握” = 不成立
→ nx 关系功能在这一窄变量上 rejected
```

## 四、关键压力

本段存在真实外部压力：

- 汉廷残破；
- 李傕、郭汜威胁；
- 洛阳粮运困难；
- 曹操需要中央合法性来扩大诸侯间的政治作用范围。

这些因素解释了曹操为什么选择“天子 / 朝廷”这一高价值接口。

但它们不能自动证明 `nx`。

真正决定分类的是：

```text
接口最终由谁决定、谁能调用、谁能否决、谁能重设方向
```

## 五、最近邻排除

### nx vs x

现行 `nx` 准度卡明确：

```text
nx：权限和资源在别人手里，我沿通道借用。
x：对象、资源、权限和调用边界归我掌握。
幕后控制网络是 x，不是 nx。
```

因此本段“朝廷大务先禀曹操、赏罚听曹操处置”使最近邻首先转向 `x` 检查，而不是继续把“天子名义”算成 `nx`。

本轮不额外锁定稳定 `x` 本体，只记录：**x 是排除 nx 时最强最近邻。**

### nx vs xn

曹操确有谋划、密议、安排等 `xn` 候选动作，但本轮核心变量不是排程和节点，而是**谁实际掌握中央权限接口**，所以不以 `xn` 解释本段主机制。

### zx vs 身份 / 权位

曹操被授官、封爵本身不能证明 `zx`。

只有当：

```text
自身权能成为方向源
+ 原有权力结构被迫围绕其重排
+ 现实决定范围扩大
```

才支持 `zx`。

本段正是因为这些条件同时出现才成立。

## 六、拿掉测试

### 对 zx 的拿掉测试

拿掉：

- “曹操”名人光环；
- 大将军、侯爵等身份标签；
- 战争胜负；
- 奸雄主题；
- 天子作为神圣符号的叙事滤镜。

只保留：

```text
主体决定迁移中央权力中心
→ 原中央主体不能有效拒绝
→ 重大事务先经过主体
→ 主体可把中央接口用于自己的现实布局
```

`zx` 当前状态仍成立。

### 对 nx 的拿掉测试

拿掉“天子”这一具体身份，只保留一个高位授权接口。

如果该接口已经完全由主体控制，主体无需向独立他者请求许可，则 `nx` 仍然不成立。

这说明“外部权威的名义”不是 nx 的充分条件。

## 七、反向测试

把剧情反向改写为：

```text
献帝保有独立否决权
→ 曹操提出迁都 / 任命 / 调度方案
→ 必须等待献帝独立判断
→ 献帝可拒绝或重设方案
→ 曹操只能沿获批后的权限通道执行
```

此时 `nx` 关系功能会明显上升。

再进一步，如果朝廷主动给出完整方向，曹操只是执行，则 `nx` 更强。

实际剧情并非如此，所以当前“借天子”不能高置信写成 `zx+nx`。

## 八、第三因素冻结

本轮冻结：

- 曹操官职；
- 皇帝身份自带的名义权威；
- 曹操军事实力的“强者”印象；
- 是否成功统一北方；
- 忠汉 / 篡汉政治主题；
- 对曹操的道德评价。

冻结后只看：

```text
方向源
权限实际归属
调用权
否决权
现实重排
```

分类仍然稳定。

## 九、稳定本体 / 状态 / 功能 / 关系位置区分

### 稳定人物本体

本轮不锁。

### 当前状态

曹操在迁许及控制朝廷接口阶段，`zx` 高显影。

### 行为功能

- 推动迁许：zx 行为功能；
- 用朝廷接口推进布局：表面像 nx，实际因接口受控而排除 nx；
- 谋划、密议：可有 xn 候选，但不是本轮主变量。

### 关系位置

曹操相对献帝与朝廷，从“被召入朝的外臣”快速转为重大事务的先决接口与实际处置中心。

### 外部压力

汉廷残破、军事威胁与合法性需求，是为何选择中央接口的压力条件，不是十元判定本身。

## 十、本轮结论

```text
样本类型：伪 zx+nx 反例

表面：
曹操借天子 / 朝廷权威
→ 看似 nx 关系功能

实际：
朝廷赏罚听曹操处置
+ 重大事务先禀曹操
+ 曹操以自身方向推动迁许并调用中央接口
→ 权限并未真正外置
→ nx rejected
→ zx 当前状态 / 关系位置高显影
→ 最近邻优先检查 x
```

### 可复用红线

> **“借用了别人的名义”不等于 `nx`。只有关键权限、资源或解决通道仍由独立他者掌握，主体必须沿其接口取得许可，才支持 `nx` 关系功能。若主体已经控制该接口，则优先排除 `nx`，检查 `x / zx`。**

这一条目前只作为本案例可靠结论，不直接修改 L1 或核心定义。
