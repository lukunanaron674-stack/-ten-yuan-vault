# 《水浒传》鲁达｜zx↔nx 木轴压力测试

## 结论先行

本轮只锁定“鲁达公开挑衅郑屠 → 郑屠持刀扑来 → 鲁达在当街直接压倒、三拳击溃郑屠”这一窄阶段，作为 `zx` 的高置信行为/状态/关系位置正例；不直接升级为“鲁达稳定纯 zx 人物本体”。

```text
方向由鲁达自己设定
→ 主动把冲突拉到公开现实
→ 郑屠、邻舍、伙计与路人被迫围绕其力量反应
→ 鲁达直接成为现场更高决定力量
→ 不依赖他者权限或既有通道完成最终压制
= zx 高显影
```

本轮刻意切掉前面的筹钱、等待两个时辰、假借“经略相公钧旨”消遣郑屠等准备段，避免 `nx/xn` 关系功能与组织行为污染这个纯 zx 切片。

---

## 1｜原始事实

### 触发

此前鲁达得知郑屠强骗金翠莲，决定介入。但本轮不把“救人动机”直接当十元证据，只从公开冲突开始判断。

### 窄阶段起点

郑屠质疑鲁达故意消遣，鲁达公开承认自己就是特地来消遣他，并把肉馅掷向郑屠。郑屠持剔骨尖刀冲出肉案，鲁达主动来到当街迎接冲突。

### 明确动作与结果

1. 鲁达公开把私人意图变成现场冲突，不隐藏、不等待第三方裁决；
2. 郑屠持刀扑来，鲁达直接按住、踢倒，并踏住其胸口；
3. 鲁达公开否定郑屠“镇关西”的地位，并以自己的经历与力量重新规定双方高下；
4. 连续三拳使郑屠失去反抗能力；
5. 邻舍、伙计与围观者因为惧怕鲁达，无人敢上前干预。

可观察变量不是“鲁达很能打”，而是：**现场方向与作用权由鲁达自己生成并占据，其他对象被迫围绕他的公开权能重新反应。**

---

## 2｜为什么判 zx

现行木轴阳端要求：

```text
最终方向与作用权来源由主体自身生成并占据
→ 主体权能公开进入现实
→ 他者、环境或秩序被迫回应
→ 主体决定范围或凌驾程度上升
```

本桥段逐项命中：

- **方向源在鲁达**：不是执行上级命令，也不是等郑屠提出解决方案；公开冲突由鲁达主动设定。
- **权能公开显现**：从挑衅、迎战到压倒都发生在当街众目之下。
- **他者被迫回应**：郑屠从店主位置被拉入鲁达设定的冲突，邻舍、伙计、路人则因鲁达力量而退出干预。
- **决定位置上升**：鲁达最终直接决定冲突如何继续、何时停止，郑屠失去对抗与现场控制能力。

因此本例不是“有目标/战斗/胜利=zx”，而是完整出现了“自身方向源 → 公开施力 → 他者重排 → 决定位置扩大”。

---

## 3｜为什么不是 nx

在本轮窄切片内，不存在：

- 等待他人给出最终方向；
- 通过求人、旧交、权限网络取得最终解决；
- 承认他者已有决定位置并沿其通道推进；
- 把最终处置权交给现成流程。

相反，冲突一旦公开化，最终作用权完全来自鲁达自己。

注意：前段“奉经略相公钧旨”消遣郑屠具有借既有权威接口的色彩，可能涉及 `nx` 关系功能；因此它被本轮主动切出，不能拿来反驳本窄阶段的纯 zx 判定。

---

## 4｜最近邻排除

### zx vs xn

不是 `xn` 主证据。

前段等待父女走远、设计肉馅拖延具有明显组织时间与步骤的 `xn` 候选；但本轮从公开挑衅开始，核心不再是排程、节点和流程，而是当下直接公开施力并扩大现场决定权。

### zx vs x

不是 `x` 主证据。

鲁达并没有稳定拥有郑屠的店铺、人员、财物或处分边界。本轮变化发生在公开凌驾与现场决定权，而不是“对象归我掌握”。

### zx vs xz

不是由危险逼近被迫抢临时决定空位。危险虽然在郑屠持刀后出现，但冲突本身是鲁达主动公开制造、主动迎接；方向并非由危险迫使生成。

### zx vs z

本例核心不是要求郑屠或围观者确认鲁达价值，而是让自身力量直接改变现场关系与反应。

## 5｜拿掉测试

### 拿掉“鲁达很能打”这一性格标签

只保留结构：主体主动公开设定冲突、直接施力、迫使对象与围观者重排、取得现场最高决定位置。

结果：`zx` 仍成立。

说明“能打”只是行为载体，不是分类理由。

### 拿掉官职身份

若不强调“提辖”身份，仍保留当街主动挑衅、迎战、压倒郑屠以及围观者不敢干预的事实。

结果：`zx` 仍成立。

### 拿掉胜利结果

即使假设最后没有把郑屠打死，只要鲁达的权能已经公开进入现实并迫使郑屠、伙计与围观者围绕他的力量重新反应，`zx` 仍可高显影。

## 6｜反向测试

若把同一桥段改写为：

```text
鲁达不公开挑衅
→ 去找经略府、官差或地方豪强
→ 请求对方以已有权限处理郑屠
→ 自己沿他们给出的通道等待结果
```

则 `zx` 会显著下降，`nx` 关系功能会上升。

若改写为：

```text
鲁达接到上级“逮捕郑屠”的明确任务
→ 自己只按既定流程执行
```

则需重点检查 `xn/nx/x`，不能自动判 `zx`。

原文窄阶段没有发生这两种反向结构。

## 7｜第三因素冻结

### 动机正义性

“替金翠莲出头”“嫉恶如仇”不是十元判据。即使把动机替换成私人争执，只要结构仍是主体自己生成方向、公开施力并迫使现场重排，`zx` 判断仍可成立。

### 武力优势

力量强弱不是充分条件。关键是力量是否成为公开作用权来源并改变关系位置。

### 提辖官职

身份高也不是充分条件。本例并非“因为他是官所以 zx”，而是他在窄阶段没有沿官府流程执行，而是直接把自身权能压入现场。

### 前段计划与借权威

等待两个时辰、让郑屠剁肉、假借经略相公钧旨都可能引入 `xn/nx`。本轮全部从正式判据中隔离，只作为阶段边界说明。

## 10｜与上一轮贾迎春 nx 的木轴正反对照

```text
贾迎春·累金凤：
处置窗口已经存在
→ 自己不成为最终方向源
→ 让别人/家务秩序继续决定
= nx

鲁达·拳打镇关西窄阶段：
自己生成冲突方向
→ 自身权能公开压入现实
→ 他者和现场围绕其力量重新反应
= zx
```

这组对照比“强者 vs 弱者”更干净：

> **真正相反的变量是最终方向与作用权来源在自己，还是在外部既有通道。**

## 11｜本轮没有升级的结论

- 不把“嫉恶如仇”写成 zx 定义。
- 不把“能打、三拳打死”写成 zx 充分条件。
- 不把鲁达整个人物直接锁为稳定纯 zx。
- 不把前段假借经略相公权威直接锁为 nx；该段同时有计谋、时间组织和权威接口，需要单独跑。
- 不修改 L1、zx/nx 信息卡或准度卡。
