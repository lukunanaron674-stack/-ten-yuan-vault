# 《红楼梦》王熙凤日常受命 vs 跨府协理｜zx↔nx 行动类型调用边界压力测试

## 1｜本轮问题

测试同一个行动者在不同任务类型下，是否可以出现不同的调用边界：

```text
日常职责可被直接分派
但重大、跨组织任务需要本人重新承接
```

本轮主体只取王熙凤，直接对照两个明确桥段：

- 第五十一回：王夫人在荣府日常事务中命凤姐“酌量去办理”袭人回家探母，凤姐答应后自行组织车辆、随行人员与衣物等执行细节。
- 第十三回：贾珍请求凤姐跨府协理宁国府丧事，王夫人先犹豫并询问凤姐“你可能么”，凤姐本人明确表示可以承接；之后贾珍交对牌、王夫人放行，凤姐才进入宁府管理。

不把两个任务层级机械混成“凤姐是下属，所以所有行动都可直接调用”。

## 2｜剧情事实、触发、对象、动作、结果

### A｜荣府日常职责

触发：袭人母亲病重，家人请求接袭人回家探望。

对象：王夫人需要把这项家内事务交给凤姐处理。

明确动作：王夫人叫来凤姐，告诉情况，并命她酌量办理；凤姐直接答应，回去后自行安排周瑞家的、随行媳妇、丫鬟、车辆、衣物与手炉等细节。

结果：任务进入凤姐既有家内管理职责并被执行。

### B｜跨府协理宁国府

触发：秦可卿死后，宁国府内务缺乏强管理者，贾珍请求凤姐跨府协理。

对象：凤姐是否从荣府既有职责跨入宁国府，承担新的大型丧事管理任务。

明确动作：贾珍向王夫人请求；王夫人并未直接把凤姐当普通家内差事一样派过去，而是先犹豫，再看凤姐态度并问“你可能么”；凤姐本人明确表示能办并愿意承接。随后贾珍交出宁府对牌，王夫人才让凤姐照看。

结果：本人承接门 + 外部授权门通过后，凤姐进入宁府并获得新的局部管理调用边界。

## 3｜nx 判断

### 3.1 日常职责层：nx 当前行为成立

第五十一回中，任务方向由王夫人给出：处理袭人回家探母的具体家内事务。

凤姐没有重新决定“要不要处理这件事”，而是承接以后主动组织运行细节。

因此应拆成：

```text
上位任务方向：王夫人给出
→ nx 当前行为/关系位置

具体怎么安排车辆、人员、衣物：凤姐自己组织
→ xn 局部执行邻近
```

锁：

`nx_daily_duty_behavior: evidence-locked`

但不由此反推王熙凤稳定人物本体为纯 nx。

### 3.2 跨府重大任务：不能沿用“日常可调用”自动判 nx

第十三回出现真实的重新承接窗口：

```text
贾珍提出跨府需求
↓
王夫人没有直接命令凤姐必须接
↓
王夫人确认凤姐能否承接
↓
凤姐本人明确表示可以
↓
授权与对牌随后生效
```

这说明“荣府日常家内职责可直接分派”并没有自动扩张为“任何跨府重大行动都已进入稳定调用边界”。

锁：

`major_cross_house_consent_gate: evidence-locked`

因此本轮支持：

> 调用边界必须按具体行动类型、组织范围与权限层级判断，不能只凭“她平时是管家/下属”整体打包。

## 4｜授权后的 x / xn 邻近

凤姐正式承接宁府任务后，贾珍交出对牌，允许她在约定范围内调用宁府资源；凤姐随后自行识别宁府五项管理弊病并组织整顿。

因此：

```text
进入任务之前：需要本人重新承接 + 外部授权
进入任务之后：局部资源/管理调用边界真实形成
```

锁：

`x_local_execution_boundary_after_authorization: evidence-locked`

执行组织层另有明显 `xn`，但本轮不重复制造凤姐协理宁国府的 zx/xn 既有案例结论。

## 5｜zx 判断

跨府任务被批准并不自动等于 zx。

在“承接入口”这一窄阶段，没有证据显示凤姐通过自身权能夺取了原本不属于自己的更高决定范围；真正发生的是：

```text
本人愿意承接
+
王夫人放行
+
贾珍交付宁府对牌
→ 新任务权限正式建立
```

所以：

`zx_in_entry_stage: rejected_as_primary`

后续凤姐在宁府重设规则、公开让秩序围绕她运行的 zx/xn 显影属于另一个阶段，不倒灌到“是否承接”的入口判断。

## 6｜最近邻排除

### nx vs x

- 日常荣府事务：任务可直接落入凤姐既有职责，表现为承接外部方向的 nx 行为，并伴随局部管理 x/xn。
- 跨府宁府事务：在授权完成前，并不属于凤姐已经稳定持有的调用/职责边界；需要本人承接与真实外部授权。
- 授权完成后：宁府局部对牌和管理资源进入凤姐可调用范围，x 上升。

因此“是不是 x/nx”不能脱离任务入口、组织范围与授权阶段。

### nx vs xn

凤姐在两段中都很会组织具体执行，但 `xn` 解释“怎么做”，不能替代 `nx` 回答“任务方向和承接入口由谁决定”。

### nx vs zx

主动、能干、被信任、承担大事都不是 zx。必须另查是否发生真实扩权和现实秩序围绕新增权能重排。

## 7｜拿掉测试

### 拿掉凤姐能干的人物评价

只保留“日常任务直接分派；跨府任务需要本人重新承接”，行动类型边界仍成立。

### 拿掉跨府属性

若第十三回任务本来就是凤姐在荣府已有职责内的普通事务，而且同类事情长期可被直接分派，则本人重新承接门的重要性会明显下降，结构更接近日常调用。

### 拿掉凤姐本人明确承接

若王夫人和贾珍可以完全绕过凤姐本人意愿，直接使其跨府重大行动生效，则本轮“独立行动者本人承接门”证据会显著下降。

### 拿掉王夫人/贾珍的授权门

如果凤姐自己可以随意进入宁府并取得对牌与管理资源，则任务入口会更接近她自己的 x/xn，而不是当前双重门结构。

## 8｜反向测试

### 反向成完全既有调用 x-like

```text
无论普通日常事务还是跨府大型任务
王夫人都可直接分派
凤姐本人没有重新承接/拒绝窗口
相关权限自动生效
→ 更接近稳定既有调用边界
```

### 反向成完全外部行动者 nx

```text
连荣府日常事务也必须每次重新请求凤姐本人
她可独立决定帮不帮
→ 更接近完全外部行动者接口
```

当前文本位于两者之间：

```text
日常职责可直接分派
重大跨府任务需重新承接与授权
```

## 9｜第三因素冻结

冻结：

- 凤姐强势、聪明、好揽事等性格评价；
- 贾珍与凤姐的亲属称谓；
- 丧事规模和秦可卿身份；
- 凤姐后来协理成功与否；
- 王夫人是否偏爱凤姐；
- 宁荣两府礼法评价。

只保留：

> 同一行动者，在日常职责和跨组织重大任务中，是否需要重新取得本人承接与外部授权。

结论仍成立。

## 10｜与待审议问题的增量

现有待审议已锁三部正向：

- 猪八戒请求已离队孙悟空；
- 施恩请求武松；
- 贾珍请求凤姐；

以及诸葛亮直接调北伐诸将这一反向控制。

本轮不是第四个正例，而是补出第一个高纯“按行动类型分层”的灰区：

```text
同一个王熙凤
荣府日常家内任务：可直接承接上位分派
宁府跨府重大任务：本人重新承接 + 外部授权后才进入
```

因此支持候选纪律：

> `x ↔ nx` 调用边界可能不是“这个人整体属于内部/外部”的单开关，而要按具体行动类型、组织范围和权限层级拆分。

本轮不修改 L1、zx/nx 信息卡、准度卡或 zx补nx 补卡，只作为 pending-review 的增强证据。

## 11｜结论

正式锁定：

```text
日常职责可直接分派
≠
所有重大行动都已进入同一调用边界。

同一行动者可以出现：
日常任务层 nx承接/既有职责运行
+
重大跨组织任务层本人重新承接门
+
授权后局部x/xn运行
```

因此判断“用了这个人到底是 nx 还是 x”，必须先问：

> **究竟是哪一种行动，是否跨出了原有职责/组织/权限边界，以及对方本人是否需要重新放行。**
