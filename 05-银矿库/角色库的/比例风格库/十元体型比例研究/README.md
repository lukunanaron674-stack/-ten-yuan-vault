# 十元体型比例研究

> 状态：研究中 / 可用于灰色体膜实验  
> 目标：建立“十元 → 数字比例组合 → 可观察身体变量 → 灰色体膜模板”的稳定规则。

## 核心数字体系
本库恢复并提高以下数字比例体系权重：

- 331
- 575
- 851
- 931
- 971
- 853

这些数字是主要结构约束和核心解释语言之一。  
**禁止**把它们简化成固定单义标签，例如“931=宽”“971=长腿”“331=节点”。数字必须结合身体区域、主辅权重、出现顺序与上下半身分布解释。

## 当前研究重点
1. XN-A 圣职瘦长型 vs X 瘦高型分界。
2. 验证头、肩、胸腔、腰腹、骨盆、上臂、前臂、手、大腿、小腿、脚的数字映射。
3. 验证腿长、肩宽、胸腔长度、骨盆宽、腿躯比、手脚末端、关节体量与整体收束/扩张。
4. 继续整理 XN 分支：
   - 圣职瘦长型
   - 现代病弱型
   - 未成熟失衡型
   - 审判官硬直型

## 研究原则
- 外部角色设定稿、三视图、体型模板、动画/游戏角色设计只用于验证、补充与修正。
- 外部素材与数字体系冲突时记录冲突，不直接推翻数字体系。
- 优先寻找局部变量和组合关系解释冲突。
- 现代病弱 XN：头比旧模板小一档，但**不因缩头自动拉长腿**。
- 灰膜实验必须优先控制变量，避免服装、脸、发型、姿势干扰。
