# 灰色体膜模板规范

## 目的
用于验证十元身体比例，不做角色设计展示。

## 视觉规范
- 白或极浅灰背景
- 无脸
- 无头发
- 无服装
- 无武器
- 无饰品
- 无皮肤纹理
- 无性征细节
- 不画写实肌肉
- 不用动态姿势制造差异
- 以大块形状和比例为主

## 推荐版式
### 单体实验
- 正面中立站姿为主
- 必要时补侧面
- 同一批实验保持等高、同姿势、同镜头

### 分支卡
推荐2×4：
- 左：正面灰膜
- 中：小型侧面
- 右：3个简单几何块
- 顶部仅写类型名
- 薄灰分隔线
- 禁止做成复杂角色海报

## 身体记录顺序
头 / 肩 / 胸腔 / 腰腹 / 骨盆 / 上臂 / 前臂 / 手 / 大腿 / 小腿 / 脚 / 整体

手可继续拆：
掌 / 指

腿可继续拆：
大腿 / 小腿 / 脚

## 数字记录格式
每一部位写：
- 数字
- 主/辅/局部
- 是否跨上下半身重复
- 是否造成局部回弹

示例：
- 肩：331 主
- 胸：851 辅
- 腰：575 辅
- 骨盆：331 主
- 大腿：851 辅
- 小腿：575 辅
- 脚：331 局部

## 控制变量硬规则
一次实验最多改1~2个变量。

禁止同时修改：
- 头身
- 肩宽
- 胸长
- 骨盆宽
- 腿长
- 手脚大小
- 姿势

否则无法判断差异来源。

## 现代病弱XN专规
- 头缩小一档
- 不补腿
- 不加长小腿
- 不放大脚做视觉平衡
- 总高允许轻微下降

## 参考优先级
1. 用户给定角色原图比例
2. 用户数字比例体系
3. 十元类型
4. 标准人体/外部参考

若原图与类型理论冲突，先忠实复刻原图，再记录冲突，不擅自“修正”成标准人体。
