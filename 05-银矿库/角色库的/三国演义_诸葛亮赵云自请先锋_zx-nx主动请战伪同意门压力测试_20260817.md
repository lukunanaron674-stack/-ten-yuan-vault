# 《三国演义》诸葛亮—赵云自请先锋｜zx↔nx 主动请战伪同意门压力测试

## 1｜剧情事实

第九十一回中，诸葛亮受诏北伐，先在丞相府公开点将、分职、配置各军。赵云起初未被安排为先锋，原因不是诸葛亮无权调用，而是诸葛亮顾虑赵云年高，担心有失会损其一世英名与蜀军锐气。

赵云随后主动请为前部先锋，并以强烈措辞坚持。诸葛亮仍先劝阻，最后才同意，并附加“须得一人同去”的条件；邓芝自愿同行后，诸葛亮直接拨精兵五千、副将十员给赵云、邓芝，二人随即出发。

## 2｜核心问题

表面容易出现一个错误推论：

```text
赵云主动说“我愿意去”
→ 诸葛亮等赵云本人同意后才使用其能力
→ 赵云是外部行动者接口
→ nx
```

这个推论不成立。

文本更直接支持：

```text
赵云本来就在蜀军军令系统
→ 诸葛亮原本决定“不让他当前锋”
→ 赵云主动申请改变岗位
→ 诸葛亮仍拥有批准/拒绝与附条件的分配权
→ 同意后直接拨兵、配副将
```

因此，“赵云主动请战”只能证明行动者本人有意愿与主动性，不能证明诸葛亮缺少既有军令调用边界。

## 3｜nx 判断

本窄层 `nx_external_agent_relation_function` 排除。

若是 nx 外部行动者接口，应看到：

- 赵云不在诸葛亮既有军令边界；
- 诸葛亮必须通过私人关系、请求、说服等重新接入赵云；
- 赵云拒绝后，诸葛亮不能依靠既有军令关系重新分配相关军事行动。

本段没有这些证据。相反，诸葛亮掌握岗位是否授予、附加何种条件、拨多少兵与副将等现实接口。

因此：

> **主动请战 ≠ 结构上必须重新取得本人同意。**

## 4｜x / xn 最近邻

### x

在“北伐军内岗位和兵力调用”这一对象层，优先检查既有军令调用边界 `x`。

诸葛亮并不是借赵云这个外部资源，而是在已有统帅边界内决定是否使用、如何使用赵云。

### xn

“谁任先锋、谁同行、拨多少兵、配多少副将”属于角色与资源组织，因此有 `xn` 邻近。

但这不能反过来证明 `nx`。

## 5｜zx 判断

本段不锁高纯 `zx`。

赵云激烈请战没有让诸葛亮取得新的军事决定范围；诸葛亮批准并拨兵也属于现有统帅范围内的正常用权。没有新增权能边界，因此 `zx_in_narrow_stage: rejected_as_primary`。

## 6｜拿掉测试

### 拿掉赵云主动请战的激烈措辞

只保留“诸葛亮决定是否任用赵云、可附条件、可拨兵”，既有军令调用边界仍成立。

### 拿掉赵云的武勇与名将身份

只要对象仍处于诸葛亮实际军令系统，岗位和兵力由诸葛亮决定，结论仍不变。

### 拿掉军令关系

若赵云已经脱离蜀军，不受诸葛亮军令约束，诸葛亮必须凭旧交去请求赵云本人重新加入，那么才接近《西游记》猪八戒请已离队孙悟空式的 nx 外部行动者接口。

## 7｜反向测试

真“本人同意门”需要出现：

```text
任务超出现有调用边界
→ 上级无法仅凭既有职位使行动生效
→ 必须重新询问本人
→ 本人有真实拒绝权
→ 拒绝后既有命令接口不能覆盖
```

本段没有证明这一结构。

## 8｜第三因素冻结

冻结：

- 赵云年老；
- 赵云勇猛；
- 诸葛亮惜将；
- 北伐最后胜负；
- 赵云是否自愿冒险；
- “先锋”职位荣誉感。

只看调用边界，结论仍是：诸葛亮掌握军内岗位与兵力配置接口；赵云主动请战是意愿输入，不是外部权限事实。

## 9｜对待审议问题的增量

本例不是第二个“行动类型分层”正例，而是给现有待审议加一条必要限制：

> **不能把“行动者主动请战 / 主动承接”本身当作‘上级必须重新取得本人同意’的证据。**

判断本人同意门必须看到：

1. 原有职责/命令边界无法直接覆盖该行动；
2. 本人拒绝具有真实阻断力；
3. 上级不能靠原有调用权让行动继续生效。

否则，“主动愿意”只能证明意愿，不证明 nx 外部行动者接口。

## 10｜结论

```text
赵云主动请战
≠
诸葛亮必须重新取得赵云本人同意

既有军令边界仍在
→ x / xn 最近邻
→ nx 外部行动者关系功能排除
```

本例不锁诸葛亮或赵云稳定人物本体，不锁严格 zx↔nx 补关系，不修改 L1 或十元核心定义。
