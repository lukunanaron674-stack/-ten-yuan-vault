# 哈尔（Howl）
> 归档：`05-银矿库/角色库/哈尔的移动城堡_哈尔.md`

---

## 1. 主十元判断

**主十元：z（阴火·执念/被看见）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉z，哈尔就是一个很强的魔法师——漂亮、强大、到处逃。但哈尔最核心的那一面不是强大，是**他极度在意自己「在别人眼里是什么样的」**。染金头发那段戏是全部关键——染坏了他在房间里崩溃大哭，不是因为头发，是因为「我连被看见的方式都搞砸了」。他的恐惧不是怕死（x），是怕「变成一个不好看的东西被看见」。
- **第2问（反复面对什么结构）：** 反复面对「我不想让你们看到我这副样子」。逃避战争、躲进城堡深处、把自己关在房间里——他不是怕打仗，是怕别人看到他狼狈的样子。z的结构是：**你必须在我最好的时候看到我**。
- **第3问（最怕失去什么）：** 最怕「被看到不好的版本」。所以他在苏菲面前崩溃的时候用黑色黏液把自己包起来——不是要攻击她，是不要让她看到里面那个混乱的自己。
- **第4问（回到哪个感觉）：** 回到「我可以让你看见了」的那一刻。苏菲把他的心脏放回去之后，他没有变得更强——他只是不再躲了。
- **第5问（副十元服务谁）：** zx（执行/突破）是z的工具——当被看见的执念被满足了之后，他就可以出手了。最后变成大鸟去挡炮弹的那一次不是他变勇敢了，是他终于不怕被看到不好的样子了。

## 2. 副十元

**副十元：zx（阳木·突破/执行）**

**作用：** 哈尔不是天生勇敢的人。但他的zx会在被逼到一定程度的时候弹出来——变成大鸟、挡炮弹、跟荒野女巫对峙。zx是他被z推动时偶尔展露的锋芒。

## 3. 功能十元

**功能十元：x（阴水·深欲/生存）——表层。** 哈尔的「怕死」是表象，不是底层。心脏不在身上所以他恐惧——但恐惧的根不是「保命」，是「保住了命之后也没人看见」的孤独。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 金发、长袍、城堡内部的花哨装饰——这些都是包装。哈尔用它们来「让自己值得被看见」，但它们不是他。

## 5. 动态链

```
z（主·极度在意自己怎么被看见）
  → zx（副·被逼到绝路就出手）
  → x并z（功能·金发+漂亮衣服是包装）
  → 染坏头发→崩溃→遇见苏菲→心脏放回去
  → 不怕被看见了→出手挡炮弹
```

## 6. 一句话定型

哈尔不是「怕死的魔法师」，也不是「等待救赎的漂流者」，而是「**一定要在最漂亮的时候被看见**的人」。

## 旧卡修正记录

**旧定位（第一次）：** xz+nz（命运型）
**修正1（我的错误）：** x（主）+ nz（副）→ 本体型
**最终定位：** z（主·执念/被看见）+ zx（副·突破/执行）→ 时间型
**最终修正理由：** 我第一次犯了两个错误——把哈尔的恐惧当成了底色（x），又把他的交易行为当成了生存选择。但哈尔的核心不是怕死（x），是怕「死得不好看」（z）。染头发崩溃那场戏才是他的灵魂——不是「我在乎外表」，是「我在乎我在你眼里是什么样子的」。x（深欲）是他表面的恐惧，z（被看见的执念）才是驱动他整个人的发动机。
