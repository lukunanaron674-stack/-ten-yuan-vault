# 《三国演义》赵云截江夺阿斗｜zx↔nx 公开强制与既有职责边界压力测试

## 结论先行

本轮只锁《三国演义》第六十一回：赵云巡哨归来，听闻孙夫人未报诸葛亮而私自携阿斗离开荆州，立即追船、登船，并在孙夫人明确反对、吴兵阻挡的情况下直接夺回阿斗；张飞随后会合，二人最终留下阿斗而放孙夫人归吴。

结论：

> **本窄阶段锁 `zx` 当前状态高显影。赵云不是因为“很能打”而成立 zx，而是他在没有得到新的现场命令、且孙夫人公开否定其干预资格的情况下，把自己的保护判断直接压入现实，强制改变“阿斗是否离开荆州”的最终结果，并使孙夫人、吴兵及后续现场行动围绕这一新事实重新反应。**

同时：

- `nx_in_narrow_stage: rejected`
- `x_existing_authority_neighbor: present_but_not_sufficient_in_novel_text`
- 不锁赵云稳定人物本体；
- 不锁严格 `zx↔nx` 补关系。

历史材料《赵云别传》记赵云“领留营司马”“特任掌内事”，可作为“既有职责 x”反向控制；但本轮研究对象是《三国演义》小说桥段，不能用历史官职反向覆盖小说自身没有明确给出的权限边界。

## 1｜剧情事实

### 触发

孙权、张昭设计让周善秘密入荆州，以国太病危为由接孙夫人回吴，并要求将阿斗一并带回。孙夫人未报诸葛亮便携阿斗上船。

赵云巡哨回来后才听到消息，当场吃惊，只带四五骑沿江追赶。

### 对象

本轮对象不是一般“护主忠诚”，而是一个非常窄的现实决定：

> **阿斗是否可以被孙夫人带离荆州。**

当时：

- 孙夫人以母亲与主母身份坚持带走阿斗；
- 周善与吴兵负责让船离开；
- 刘备本人不在场；
- 诸葛亮没有先下达一个“赵云去夺回阿斗”的即时命令；
- 赵云必须在现场自行判断并承担后果。

### 明确动作

1. 赵云沿江追船；
2. 找到渔船后追上吴船；
3. 面对吴兵放箭与枪刺，直接登上大船；
4. 进入船舱质问孙夫人为何不报军师、为何带走阿斗；
5. 孙夫人明确以“主母”身份否定赵云干预资格；
6. 赵云明确提出：夫人可以走，但必须留下阿斗；
7. 孙夫人拒绝后，赵云直接从其怀中夺回阿斗；
8. 赵云一手抱阿斗、一手持剑，吴兵不敢近；
9. 张飞随后会合并截船，二人商议后只留下阿斗，放孙夫人归吴；
10. 诸葛亮随后率船接应，见阿斗已经夺回而大喜。

### 结果

原本已经启动的“孙夫人携阿斗离荆”结果被直接切断。

阿斗最终留在刘备集团一侧；孙夫人单独归吴。

## 2｜为什么本阶段判 zx

现行 zx 的硬门不是“动作强”，而是：

```text
主体自己的力量或决定接口明确
→ 权能公开进入现实
→ 他者或秩序被迫回应
→ 主体决定范围、影响位置或凌驾程度上升
→ 不是普通执行或职业行为
```

本段逐项命中。

### 2.1 方向来自赵云当前判断

赵云没有等新的现场命令，而是听闻消息后立即判断“阿斗不能被带走”，并把这个判断推进到底。

这不是“老板明确叫我夺回阿斗，我照做”的普通 nx 执行。

### 2.2 权能公开进入现实

赵云不是秘密偷回阿斗，也不是事后求人追讨，而是正面追船、登船、与孙夫人公开争执，并直接把阿斗从其怀中夺走。

### 2.3 他者被迫重新反应

- 吴兵由原本护送离境转为被赵云压退、不敢近身；
- 孙夫人原本掌握“带走阿斗”的现实事实，被迫失去阿斗；
- 张飞到场后围绕“已经夺回阿斗”继续截船与收束结果；
- 诸葛亮随后接应的是一个已经由赵云改写过的现场结果。

### 2.4 决定位置在当前对象层真实上升

冲突前：

```text
孙夫人 / 周善控制船与离境事实
```

冲突后：

```text
赵云实际决定“阿斗不能离开”
→ 这个决定已经进入现实并成立
```

因此，本窄对象层出现了清晰的作用权迁移。

正式锁：

`zx_current_state_stage: evidence-locked`

## 3｜为什么不能只判 x

本轮最危险的最近邻是 `x`。

如果小说明确写出：

> 刘备事先正式授予赵云“孙夫人及阿斗离境事项的最终处分权”，赵云本次只是在照章调用既有权限，

那么应优先判 `x`，而不能把普通已有权限的执行重复制造成 zx。

但《三国演义》第六十一回现场文本反而提供了一个重要反证：孙夫人直接以“主母”身份质问赵云凭什么管她家事，而赵云依然把自己的判断压进去，并承担“纵然万死”也不放阿斗离开的风险。

小说本段没有先给出一个足以覆盖“强制从主母怀中夺走少主”的明确既有处分授权。

因此在小说自身证据层：

`x_existing_authority_neighbor: present_but_not_sufficient`

### 历史控制材料

《三国志·赵云传》裴注引《赵云别传》记载赵云“领留营司马”“特任掌内事”，并记其与张飞勒兵截江取回后主。

这说明在历史材料中，“既有职责 x”解释会明显增强。

但该材料只能作为控制：

> **同一事件若放入不同文本体系，权限前提不同，分类可能不同。**

不得把历史设定倒灌进《三国演义》小说作为未明示前提。

## 4｜nx 为什么排除

现行 nx 要求：

```text
关键方向、权限或解决通道在外部
→ 主体不占最终决定位置
→ 沿既有关系、身份或权限接口推进
```

赵云本段没有：

- 先找诸葛亮申请是否可以追；
- 找刘备回令；
- 请求孙夫人自行留下阿斗；
- 沿东吴或荆州既有许可流程等待处理；
- 借另一个外部掌权者替自己完成结果。

他在关键窗口直接成为决定事实的主体。

因此：

`nx_in_narrow_stage: rejected`

张飞后续加入属于协同，不应倒推赵云先前追船、登船、夺阿斗的决定来源来自张飞。

## 5｜关键压力

关键压力包括：

- 刘备本人远在益州方向；
- 孙夫人已经上船；
- 船正在顺流离开，时间窗口快速缩小；
- 吴兵公开护送；
- 孙夫人拥有主母身份压力；
- 阿斗一旦入吴，会成为东吴控制刘备的重要筹码。

但这些压力不能直接判 zx。

真正使 zx 成立的是：

> **在压力出现后，赵云把自己的决定与力量公开压进现场，并使现实结果围绕自己的判断发生变化。**

## 6｜拿掉测试

### 拿掉赵云“武艺高强”标签

只保留：

```text
公开追上
→ 当面对抗原决定主体
→ 直接阻断离境结果
→ 夺回阿斗
→ 原执行方无法恢复原结果
```

zx 仍成立。

说明不是“能打 = zx”。

### 拿掉张飞

赵云在张飞出现前已经：

- 追上吴船；
- 登船；
- 公开否定带走阿斗；
- 从孙夫人怀中夺回阿斗；
- 以剑护住阿斗，使吴兵不敢近。

因此赵云自己的 zx 证据独立成立；张飞强化了最终脱船与收束，但不是赵云 zx 的唯一来源。

### 拿掉历史“掌内事”资料

《三国演义》小说内部的公开介入、资格冲突、强制夺回与现实改写仍完整存在。

因此历史资料不是本轮 zx 的支柱。

### 拿掉最终成功

如果赵云登船、争执后仍被吴兵制住，阿斗最终被带回东吴，则 zx 会明显下降，因为主体没有形成足够稳定的现实决定位置。

## 7｜反向测试

### 反向A：纯 x 版本

```text
刘备事先明确授予赵云阿斗离境最终处分权
→ 孙夫人离境必须经赵云批准
→ 赵云本次只是按现成职权拦截
```

应优先判 `x`，而不是 zx。

### 反向B：nx 版本

```text
赵云发现孙夫人携阿斗离境
→ 不敢自行处理
→ 先找诸葛亮或刘备请示
→ 必须等待其命令
→ 再沿该权限执行
```

则 `nx` 明显上升。

### 反向C：伪 zx 版本

```text
赵云公开追船、争执、挥剑
→ 但阿斗最终仍被带走
→ 吴兵与孙夫人不需要围绕赵云重新调整
```

则只剩强烈行动，不能锁高纯 zx。

## 8｜最近邻排除

### zx vs x

本轮核心难点。

```text
x：本来就有这块处分权。
zx：在冲突中让自身作用权公开进入原先未清楚属于自己的决定层，并使现实围绕它重排。
```

小说证据更支持后者；历史控制材料则提醒该边界必须按文本前提切开。

### zx vs xn

赵云追船、找渔船、登船有即时行动组织，但没有持续计划、排程、节点系统；主机制是公开作用权改变现场，而非流程组织。

### zx vs nx

没有走外部权限通道，而是直接成为现场决定来源。

### zx vs nz

忠义、护主、对刘备父子的关系可以解释动机，但不回答“谁实际决定阿斗能否离境”。

### zx vs xz

船已离岸、时间紧迫确有危险窗口缩窄，但危险只是压力；真正木轴判据仍是赵云的作用权是否进入现实并扩大。

只看：

> **在“阿斗是否离开荆州”这一窄对象层，最终方向与作用权来源发生了什么变化。**

## 10｜人物本体、状态、行为功能、关系位置

```text
稳定人物本体：不锁
当前状态：zx 高显影
行为功能：公开追击、强制夺回
关系位置：赵云从“帐下武夫”争议位置临时进入阿斗离境的实际决定位置
外部压力：离境窗口缩小 + 吴兵护送 + 主母身份压力
```

因此严禁把本轮写成：

> “赵云稳定本体 = 纯 zx”。

本轮只证明该阶段、该对象层的 zx。

## 13｜本轮压出的案例级纪律

> **“这本来可能是我的职责”不能只靠身份印象去排 zx。**
>
> 若文本没有证明主体原本就拥有该对象层的最终处分权，而冲突中主体公开把自己的决定压入现实、迫使原执行者退让，并让自身实际决定位置上升，则仍可锁 `zx` 当前状态。

同时反向保留：

> **若文本明确证明该处分边界本来已经稳定归主体，则应优先判 `x`，不能把普通履职重复制造成 zx。**

当前材料不要求修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
