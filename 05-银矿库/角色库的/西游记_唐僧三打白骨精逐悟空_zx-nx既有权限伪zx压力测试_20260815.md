# 西游记｜唐僧三打白骨精逐悟空｜zx-nx 既有权限伪 zx 压力测试

## 1｜剧情事实

- 第二十七回中，白骨精连续变化人物接近唐僧，孙悟空三次识破并击打；唐僧因所见与八戒言语等因素，持续认为悟空滥杀。
- 冲突升级后，唐僧主动取纸笔写下贬书，明确解除师徒关系，并要求孙悟空离去。
- 孙悟空接下贬书后仍请求拜别，并试图保留师徒情分；唐僧持续拒绝改变决定。
- 最终孙悟空离开取经队伍，返回花果山。

外部文本核验：
- 《西游记》第二十七回，中国哲学书电子化计划：https://ctext.org/wiki.pl?chapter=666552&if=gb&remap=gb
- 《西游记》第二十七回，识典古籍：https://www.shidianguji.com/book/NA11023/chapter/1k2ght724lfza

## 2｜样本候选判断

### 纯 zx

排除。

本段很容易因为“唐僧公开下命令、写贬书、悟空最后真的离开”而被误判为 zx。但现行 zx 要求的不只是行使权威，而是主体自身权能公开显现并扩大，使他者或秩序围绕主体力量重新反应，且主体决定范围、影响位置或凌驾程度上升。

本桥段中，唐僧使用的是师父位置本来已经拥有的处分接口：是否继续收孙悟空为徒、是否允许其继续随行。写贬书是把既有关系边界执行出来，并没有证据表明唐僧因此获得了一个此前没有的更高决定位置，也没有让更大的取经秩序围绕其新增权能重新组织。

所以：

```text
公开命令
+ 命令被执行
≠ 自动 zx
```

本轮不锁高纯 zx。

### 纯 nx

排除。

在“是否继续让悟空留队”这一窄变量上，唐僧没有把最终方向交给八戒、悟空、外部制度或其他权限主体。他自己写贬书、自己坚持逐走，并在悟空请求后仍不改变决定。

因此本段不满足 nx 的核心：主体不占最终方向，而沿别人、关系、流程或现状已经给出的方向继续。

八戒的言语和唐僧对事件的误判会影响信息输入，但“信息受到他人影响”不能等价为“最终方向资格外置”。

### zx+nx

排除。

本段既没有足够证据锁 zx，也没有 nx 的方向外置结构，因此不能把“唐僧受八戒影响 + 唐僧又下命令”拼成 zx+nx。

### 压力显影

存在外部压力，但不是主结论。连续出现的疑似杀人事件、八戒言语和唐僧持戒判断共同形成压力；这些因素解释唐僧为什么作出逐走决定，却不自动决定木轴端点。

### 伪对子

锁定为伪 zx+nx 反例，最近邻优先检查 x：

```text
权限本来就在主体位置内
→ 主体把既有处分边界执行出来
→ 不等于 zx 扩权
→ 也不等于 nx 借外部权限
```

## 3｜最近邻排除

### zx vs x

这是本轮最重要的边界。

- zx：自身权能公开显现并扩大，决定范围或凌驾位置上升。
- x：对象、权限、调用与处分边界已经归主体掌握，主体在既有边界内使用。

本段的“写贬书逐徒”更接近后者：唐僧不是先缺乏处分接口、随后公开夺得这个接口；而是直接调用既有师徒关系中的处分资格。

因此不能因为孙悟空最终离开，就把“已有权限被成功执行”升级为 zx。

### nx vs 受建议/受信息影响

唐僧确实受到八戒言语、自己所见和戒杀原则影响，但最终逐走决定仍由唐僧作出并维持。

```text
别人影响我的判断
≠ 别人占有我的最终方向资格
```

只要主体仍能否决、重设并承担最终决定，不能因为信息来源在外就判 nx。

### nx vs xn

本段没有以计划、排程、节点和持续运行结构为核心，故 xn 不是主解释。

## 4｜拿掉测试

### 拿掉八戒的挑拨

只保留“唐僧相信悟空滥杀 → 自己写贬书 → 自己坚持逐走”，最终方向仍由唐僧占据，nx 仍不成立。

### 拿掉孙悟空强弱与名气

即使被逐者不是孙悟空，只要主体调用的是自己原已拥有的关系处分接口，且没有新增、更高的决定范围，zx 仍不能仅凭命令成功成立。

### 拿掉最终离队结果

即使悟空没有真的离开，只要唐僧仍只是使用既有关系权限，而未发生权能范围扩大，zx 判断仍不能仅靠“下命令”成立。

## 5｜反向测试

### 反向成 nx

如果唐僧本人没有逐留决定权，只能等待观音、朝廷或另一个真正掌握权限的主体裁决，然后沿该裁决执行，则 nx 会明显上升。

### 反向成 zx

如果唐僧原本没有对悟空的处分资格，却通过公开权能夺得更高决定位置，迫使取经团队或更大的制度承认其新增裁定范围，则 zx 才明显上升。

### 反向成纯 x

若只讨论“师徒关系是否继续”这一对象权限，而不讨论木轴，现行结构更应优先检查 x：既有关系边界和处分接口是否归唐僧掌握。

## 6｜第三因素冻结

冻结以下因素后，本轮木轴结论仍成立：

- 唐僧是否判断正确；
- 白骨精确实是妖怪这一读者信息；
- 八戒是否有挑拨动机；
- 戒杀、慈悲等宗教主题；
- 孙悟空的武力与主角地位；
- 后续是否重新收徒；
- 逐走行为在剧情中的后果。

只保留“最终逐留决定是谁作出、权限此前归谁、主体是否扩大决定范围、是否借用外部权限”，仍得到：nx 排除、zx 不足，x 为最近邻。

## 7｜与现有案例的最小差异

- 曹操迁帝许都：表面使用皇帝名义，但关键中央权限接口已被曹操实际控制 → 伪 nx，优先检查 x/zx。
- 王熙凤协理宁国府：受托之后主动重设规则并让宁府运行围绕她重新组织 → zx 状态高显影。
- 唐僧逐悟空：主体确实拥有关系处分接口并公开使用，但没有证据显示决定范围因此扩大 → 不应把“已有权限成功执行”自动写成 zx。

因此本轮进一步压实一条边界纪律：

> 有权并把权用出来，不等于扩权。zx 必须检查决定范围是否真的上升；若只是调用原有处分边界，优先检查 x 或普通权限行为。
