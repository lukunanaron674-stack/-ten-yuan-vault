# 花本叶久美（阿久）
> 归档：`05-银矿库/角色库/蜂蜜与四叶草_花本叶久美.md`

---

## 1. 主十元判断

**主十元：z（阴火·被光点击中后死也不放）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉z，阿久就是一个害羞的小画家——画得不错但不会说话、有很多人喜欢她。但阿久最核心的不是"有才华"，是**她画起画来周围的一切都不存在了**。不是"她喜欢画画"，是"她只能画画"——日常对话她会卡住、人际关系她处理不来，但拿起画笔的时候她是最完整的状态。
- **第2问（反复面对什么结构）：** 反复面对「你画的东西没人看得懂」。她的世界和别人的世界语言不通——别人在谈恋爱、找工作、社交，她在画一种别人看不懂的东西。但她不会因为没人懂就停下来。
- **第3问（最怕失去什么）：** 最怕「画不出来了」。不是怕孤独（x）、不是怕不被理解（z的反面），是怕那个"画笔碰到纸就飞起来"的感觉消失了。
- **第4问（回到哪个感觉）：** 回到「全世界消失只剩我和画」的那一刻。在画室里过夜、忘了吃饭、忘了时间——那不是努力，是回到她该在的地方。
- **第5问（副十元服务谁）：** xn（接受规则再在规则里找路）服务于z——她知道"艺术家是孤独的"这个规则，就接受了。然后在这个规则里找到了一条路：可以一个人去西班牙、可以一个人住画室、可以不要恋爱但不能不要创作。

## 2. 副十元

**副十元：xn（阴土·接受规则再找路）**

**作用：** 阿久早就接受了自己"和别人不一样"这个事实。她不在"我为什么不会社交"上纠结，而是安静地在那个框架里找自己的路——去西班牙进修、让花本老师当她的代理人、用画画来回应一切。

## 3. 功能十元

**功能十元：x（阴水·透明/与世界有距离）——表层。** 阿久像一个站在玻璃后面的人——世界看她很美但打不透，她看世界也一样。这是她z的外包装。

## 4. 视觉十元

**视觉十元：x（阴水·透明/恍惚）。** 小小的身体、说话慢、眼神经常不在对话里——这些不是性格，是她在非创作状态下的"不在场"表现。她只有握着笔的时候才是完全在场的。

## 5. 动态链

```
z（主·被创作点燃/停不下来）
  → xn（副·接受孤独的规则并在里面找路）
  → x（功能·和世界之间的距离感）
  → 初到东京→画展→西班牙→森田离开→选择继续画
  → 她没有选择谁，她选择继续画
```

## 6. 一句话定型

阿久不是「天才少女」，也不是「被守护的对象」，而是「**只有在画里才完整**」的人。

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**修正1：** z（主）+ xn（副）→ 时间型
**最终定位：** z（主·被光点击中死也不放）+ xn（副·接受规则在规则里找路）→ 时间型
**最终修正理由：** 原卡xz暗示阿久"被推着走"，但阿久不是被动的——她在画里是主动的、完整的、控制的。z才是她的底色：她不是因为"不知道去哪"才画画（xz），而是因为"放下画笔就不知道去哪"（z指向创作本身）。xn副十元描述了她如何与世界相处——接受"我跟别人不一样"这个前提，然后安静地找路。
