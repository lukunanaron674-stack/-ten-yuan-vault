# 《红楼梦》贾芸谋差事｜zx↔nx 外部权限节点转接压力测试

## 结论先行

本轮锁定 **`nx` 关系功能持续正例**：贾芸自己的目标非常明确——在荣府谋得一个可做的差事；但“谁有权把园内工程差事真正派给他”这一关键权限并不在贾芸手中。他先求贾琏没有办成，随后没有自行创造或夺取派差权，而是转向凤姐这一真正有效的既有权限节点，通过家族关系、人情、礼物与请求进入该接口，最终由凤姐批准并通过领票、对牌、银库流程落地。

因此，本段不是“没主见型纯 nx”，而是**强烈自主目标下的 nx 权限关系功能**。

## 1｜剧情事实、触发、对象、动作与结果

触发：贾芸需要在荣府谋一个差事，以取得收入与立足机会。

明确动作链：

```text
贾芸先求贾琏谋差事
→ 事情没有办成
→ 贾芸借倪二银子购买冰片、麝香
→ 转而接近凤姐，奉承并送香料
→ 凤姐得知贾芸此前求贾琏未成
→ 贾芸明确表示不再走贾琏节点，改求凤姐
→ 凤姐说明园内尚有种花木工程可派
→ 贾芸请求先把这一差事派给自己
→ 凤姐同意
→ 贾芸随后领票、领对牌、到银库领银
→ 次日采购花木并进入实际监工准备
```

结果：关键派差权没有转移给贾芸本人，而是由凤姐这一既有家内管理权限节点完成批准；贾芸沿该接口取得实际工作与资源。

## 2｜nx 证据

本段不支持“贾芸纯 nx 本体”。他的目标从头到尾都是自己形成的：要谋差事、要取得工作。他也会主动观察谁真正掌握资源，并调整求人的对象。

`nx` 成立在关系功能与权限位置：

```text
目标：贾芸自己有
关键派差权限：在荣府管理者手里
第一节点：贾琏，未能办成
处理方式：不夺权，而是改走凤姐这一已有权限接口
落地方式：通过家族身份、人情、请求、领票与对牌流程完成
```

因此锁：`nx_relation_function_stage: evidence-locked`。

## 3｜为什么不锁 zx 权限接管

贾芸非常主动，也会设计接近凤姐的方法，但“主动求人、会做人情、能把事情办成”不能自动判 zx。

在核心问题“谁有权把园内工程派给贾芸”上，最终决定接口始终不属于贾芸。他没有公开取得新的派差权，没有让荣府工程管理秩序围绕自己的权能重新排列，也没有扩大到可以自行给自己或别人分派工程的决定范围。

所以：

```text
我很主动地寻找有效权限节点
≠ 我取得了这个权限节点
```

凤姐同意之后，贾芸只是沿领票、对牌、银库和采购流程执行已获批准的差事；这不能反向证明他在前面发生了 zx 扩权。

## 4｜最近邻排除

### nx vs xn

贾芸确实会筹钱、买香料、选择接近时机并调整策略，这些行为存在 `xn` 邻近成分。但拿掉“具体怎样送礼、何时接近”的计划细节，只保留：

```text
派差权限不在自己
→ 一个权限节点没办成
→ 转向另一个已有权限节点
→ 请求并沿其批准流程落地
```

`nx` 仍独立成立。

`xn` 解释“他如何组织谋差事的过程”；`nx` 解释“关键许可为什么必须来自别人以及他为何要沿外部权限网络推进”。

### nx vs x

凤姐的派差权、荣府领票/对牌、银库资源都不归贾芸长期独立处分，因此不是 `x`。

### nx vs zx

如果贾芸通过一次操作就取得园内工程的实际派差权，并让其他人必须围绕他的决定领取工程，才会出现 zx 上升；原文没有这一变化。

### nx vs nz

贾芸与凤姐存在亲族、人情与奉承互动，但本轮关键变量不是“关系本身是否亲近”，而是**通过这段关系进入凤姐实际掌握的派差权限接口**，因此优先为 nx 关系功能。

## 5｜拿掉测试

拿掉“贾芸穷”“需要挣钱”这一经济压力，只要他仍有某个需要荣府批准的目标，而实际派差权在别人手里，转向有效权限节点的 nx 结构仍成立。

拿掉冰片、麝香这一具体礼物，只保留“先求A未成→转向真正掌权的B→通过关系请求→B批准”，nx 仍成立。礼物只是进入关系接口的手段，不是十元判据。

拿掉凤姐姓名，换成任何真正掌握园内工程派差权的人，结构同样成立。

若拿掉外部权限结构，让贾芸本来就可以自行决定自己承包哪项工程、直接调用银库和人员，则 nx 会显著下降，优先检查 x/xn。

## 6｜反向测试

### 反向A：zx 接管

```text
贾琏未办成
→ 贾芸不再找任何外部批准者
→ 自己取得或强行建立园内派差权
→ 荣府相关人员必须接受由他分派工程
```

则 zx 明显上升。

### 反向B：纯 nx 本体

若贾芸连“我要谋差事”这一目标也不主动形成，只等待贾琏、凤姐或家族随意安排给自己什么，就更接近纯 nx 本体；原文不是如此。

### 反向C：xn 主导

若贾芸已经取得可独立调用的工程权限，之后重点变成自己设计工期、采购、节点、人员和预算，则应转查 xn，而不是继续用 nx 解释全部行为。

## 7｜第三因素冻结

冻结：贫穷、倪二仗义、送礼伦理评价、凤姐喜奉承、贾芸聪明、亲族身份、最后是否赚钱、后续与小红情节。

只保留：

```text
最终派差权限是谁的？
第一个外部节点失效后，主体是夺取权限，还是改走另一个已有权限节点？
```

结论仍是：本阶段 `nx` 关系功能持续，zx 权限接管不成立。

## 8｜与《西游记》真假美猴王案例的跨作品最小差异/同型复现

```text
孙悟空：外部辨真接口连续失败
→ 不自行成为最终辨真裁决者
→ 继续升级寻找更高外部接口
→ nx关系功能持续

贾芸：贾琏这一求职权限节点未办成
→ 不自行取得派差权
→ 转向凤姐这一实际有效的既有权限节点
→ nx关系功能持续
```

两案共同支持一个案例级边界：

> **一个外部接口失效，不会自动把主体推成 zx。若关键权限仍在外部，而主体选择重新路由到另一个既有权限节点，则 nx 关系功能可以持续。**

当前该边界已在《西游记》《红楼梦》两部独立作品中复现，尚未达到三部作品阈值，因此不新建待审议问题，不修改 L1 或核心定义。

## 9｜严格 zx补nx 关系检查

本轮不锁严格 `zx补nx`：虽然贾芸有自主目标与主动行动，但本段没有足够独立证据证明高纯 zx 端先独立成立并存在可命名缺口，再由 nx 补入后反复改善。按照 `zx补nx_补卡` 红线，“求人一次、普通协作或资源相加”不足以锁补关系。

## 10｜结论状态

- 事实置信：99

- `zx`：本阶段“自行接管派差权限” rejected
- `xn`：邻近辅助机制，不吞掉 nx
- 稳定人物本体：不锁
- 严格 `zx补nx` 补关系：不锁
