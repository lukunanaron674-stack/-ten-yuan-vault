# 《宋史》李纲被罢后复尚书右丞｜zx↔nx 外部正式复任恢复 x 压力测试

## 1｜事实、触发、对象、动作、结果

对象截面只取靖康元年二月李纲由尚书右丞被罢、数日后由宋钦宗恢复尚书右丞并重新领京城守御这一窄窗口，不外推李纲整个政治生涯。

事实链：

1. 靖康元年正月，李纲被任为尚书右丞，并承担京城守御相关实际职责；此时“尚书右丞这一正式官职权限”真实处于其可履职边界内。
2. 二月姚平仲夜袭失利后，朝廷为向金人谢罪，正式罢李纲，并废亲征行营司；李纲原有尚书右丞官职权限随罢免退出。
3. 太学生陈东等及京城士民数万人伏阙，请求复用李纲、种师道。皇帝最终下令复李纲右丞，并重新授予京城防御/守御职责。
4. 李纲复任后重新进入正式守城、节制相关军务的履职链。

触发：对金议和与夜袭失败导致李纲被罢；随后大规模士民伏阙要求复用。

被测试对象只取：`尚书右丞这一正式职位及其对应现实履职权限`。

结果：旧职位权限先真实退出，后由皇帝正式复任重新启用；属于同对象 x 恢复。

## 2｜x：旧权限先存在、后真实退出、再恢复

### 原 x 存在

李纲任尚书右丞并实际参与守城决策与军务，说明不是空名位，而是正式官职权限进入现实调用。

`x_prior_official_authority_boundary: evidence-locked`

### 原 x 退出

“罢李纲”是正式罢职，不是口头批评。该职位权限不再由李纲正常调用。

`x_prior_official_authority_lost: evidence-locked`

### 同对象 x 恢复

后续文本明确为“复纲右丞”，恢复的正是先前被罢的尚书右丞对象层；李纲又重新承担京城守御职责。

`x_same_office_authority_restored: evidence-locked`

## 3｜nx：外部正式复任入口成立

李纲不能凭自己判断宣布“我恢复尚书右丞”。让该官职重新生效的最终正式接口在皇帝/朝廷。

虽然士民伏阙构成重要触发压力，但对李纲本人而言，职位恢复仍必须经过外部正式任命接口；他接受复任并重新履职。

因此锁：

`nx_external_official_restoration_entry: evidence-locked`

这属于 nx 关系/权限功能，不代表李纲稳定人物本体没有主见。

## 4｜zx：恢复旧边界不自动等于扩权

本窄窗口中，李纲恢复的是自己此前已经拥有的尚书右丞职位。没有证据表明其决定范围因为“复职”而超过被罢前边界。

因此：

`zx_in_restoration_stage: rejected_as_primary`

最小纪律：

> 恢复旧 x 与扩出新 zx 是两个变量。旧权限重新启用，除非同时证明主体决定范围超过原基线，否则不得从“复职/复权”直接判 zx。

## 5｜关键压力

- 夜袭失败、对金议和导致正式罢免；
- 士民伏阙形成强烈政治压力；
- 皇帝仍掌握最终正式复任接口。

压力解释为什么权限状态变化，但不能替代 zx/nx/x 的对象判定。

## 6｜拿掉测试

### 拿掉皇帝/朝廷正式复任

只保留士民要求复用李纲，尚书右丞职位不会仅靠民意自动重新成为李纲现实官职。

所以外部正式 nx 接口是真缺口。

### 拿掉“复纲右丞”同对象恢复

如果后来只是给李纲另一个新官，而未恢复尚书右丞，则只能判新授权，不足以作为“旧 x 同对象恢复”正例。

### 拿掉被罢前实际职位

如果旧 x 从未真实存在，后续任命就是新建 x，不是恢复。

## 7｜反向测试

### 反向成 zx

```text
原尚书右丞权限被罢
→ 李纲凭自身公开权能强行恢复并进一步取得超出原职位的新决定范围
→ 朝廷被迫承认新增边界
= 才检查 zx
```

史料不支持。

### 反向成非 nx 的自主恢复

如果职位恢复权本来就在李纲自己手里，不需要任何外部正式任命，则 nx 会下降。史料不支持。

## 8｜最近邻排除

### nx vs x

- nx：谁能让复职入口正式生效？皇帝/朝廷。
- x：复任后该官职权限是否重新进入李纲现实调用边界？是。

### x恢复 vs zx

- x恢复：回到既有基线。
- zx：超过旧基线并形成新的、更大决定范围。

### nx vs xn

士民组织伏阙、朝廷调度属于过程结构；李纲本人当前分类不依赖他主动搭复职流程，因此不以 xn 主判。

## 9｜第三因素冻结

冻结：

- 李纲主战还是主和；
- 士民伏阙是否正当；
- 金军压力；
- 李纲历史评价；
- 后续知枢密院事及再次被罢。

只问：

1. 同一职位权限原来是否真实存在？
2. 是否被正式切断？
3. 恢复是否必须经过外部正式接口？
4. 恢复后是否回到同一对象层？
5. 是否超过旧权限边界？

答案：是、是、是、是、未见。

## 12｜跨材料位置

现有高纯正向控制：

1. 《水浒传》施恩：快活林 x 丢失 → nx 武松直接迫使交还 → 同对象 x 恢复。
2. 《明史》海瑞：原官职 x 丢失 → nx 朝廷正式复故官 → 同对象 x 恢复。
3. 《宋史》李纲：尚书右丞 x 丢失 → nx 皇帝正式复任 → 同对象 x 恢复。

三份材料共同支持：

> nx 可以作为恢复旧 x 的外部实现接口；恢复旧 x 本身不等于 zx 扩权。

同时必须保留反向控制：外援只解决旁支危机、未直接恢复同一对象时，不得写成 nx→x恢复。
