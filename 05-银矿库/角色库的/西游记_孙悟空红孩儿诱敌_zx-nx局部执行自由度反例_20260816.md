# 《西游记》孙悟空红孩儿诱敌｜局部执行自由度不等于方案重写

## 结论先行

本轮锁定一个对“nx 外部方案存在与主体重设边界”的反向样本：

> **观音已经规定关键运行骨架：掌心写“迷”→孙悟空去索战→“许败不许胜”→把红孩儿引到指定位置→观音完成最终收伏。孙悟空在执行中自行选择打破洞门、叫阵、激将、假装怕火等具体动作，但这些变化没有改写关键节点、资源归属、最终收伏接口与总体解决方向。**

因此：

```text
外部方案骨架仍在
+ 主体拥有局部执行自由度
+ 主体没有改写关键节点与最终接口
= nx关系功能仍成立
≠ 自动转为xn方案重写
```

本轮只锁当前行为/关系层，不新增孙悟空稳定人物本体结论。

## 1｜剧情事实

### 触发

孙悟空此前正面突破红孩儿失败，请观音出手。观音来到号山后，先清空周边生灵、布置水域与莲台陷阱，再在孙悟空手心写“迷”字。

### 外部明确给出的关键方案骨架

观音明确命令孙悟空：

```text
去与红孩儿索战
→ 许败不许胜
→ 把红孩儿引到观音所在位置
→ 由观音使用既有法力与陷阱完成收伏
```

因此以下关键变量并不在孙悟空手里重新设计：

- 诱敌而非正面击杀的总体方法；
- 必须“败退”的关键战术约束；
- 最终引向何处；
- 莲台/天罡刀陷阱；
- 最终收伏与处分接口。

### 孙悟空拥有的局部执行自由度

回到火云洞后，孙悟空并非机械逐字执行。他自行：

- 叫阵；
- 对方不开门时打破洞门；
- 与红孩儿短暂交战；
- 故意败退；
- 用“怕你放火”等话术激怒、诱导红孩儿继续追击；
- 最终把红孩儿带到观音布置位置。

这些动作真实存在，但全部仍服务于外部已经设定的关键骨架。

## 2｜nx判断

本轮nx锁在“外部解决方案/权限通道”的当前关系功能层。

关键理由不是“悟空听观音话”，而是：

```text
决定性解决办法由观音建立
+ 关键失败/引导节点由观音规定
+ 最终资源与收伏接口属于观音
+ 孙悟空主要负责把对象送入该通道
```

孙悟空当然有自己的救师方向，因此不锁纯nx本体；但在“如何稳定收伏红孩儿”这一窄对象层，解决通道仍然外置。

## 3｜为什么局部动作变化不足以判xn方案重写

现行nx准度卡区分：

```text
nx：沿别人、关系或已有通道推进
xn：主体主动搭流程、设节点、分资源、重组运行方式
```

本轮的关键不是“孙悟空有没有自己想动作”，而是：

> **他有没有改变决定性运行结构。**

打门、叫阵、激将属于执行层手段替换；但“许败不许胜”“引到观音处”“由观音完成收伏”三个核心节点没有变化。

因此：

```text
局部战术自由度
≠ 关键流程重设权
```

这正好构成对待审议问题里“看似修改但仍在外部方案预留自由度内”的高纯反例。

## 4｜zx判断

本阶段不锁高纯zx。

孙悟空确实公开叫阵、打门、战斗，但本轮主问题是“解决红孩儿的最终接口是否迁回孙悟空”。答案是否定的：

- 莲台陷阱不是孙悟空建立；
- 天罡刀与净瓶资源不归孙悟空；
- 最终制服、受戒与处分由观音完成；
- 孙悟空没有借执行过程取得新的决定范围。

所以普通强动作不能倒推zx扩权。

## 5｜拿掉测试

### 拿掉“打破洞门”

只要孙悟空仍按“索战→败退→引敌”的骨架执行，nx解决通道不受影响。

### 拿掉“怕你放火”等激将话术

换成其他诱敌手段，只要核心节点和最终接口不变，仍不是方案重写。

### 拿掉观音设定的“许败不许胜”

如果这个关键约束不存在，悟空可自行决定正面打、绕路、诱敌、求援等整体运行结构，则xn重设空间明显上升。

### 拿掉观音最终收伏接口

若观音只给一句泛泛建议，最终陷阱、资源与收伏方法都由悟空自己设计，则当前nx证据会显著下降，需转查xn/x/zx。

## 6｜反向测试

### 真正方案重写版本

如果孙悟空听完观音方案后明确否定“许败不许胜”，另建一套新路线，例如自行设计新的诱捕地点、资源配置、节点与最终处置方式，并实际按新方案推进，则：

```text
当前运行层nx下降
→ xn上升
```

这才接近杨志、马谡、宝钗三个“外部方案已存在但主体真实重设”的既有样本。

### 更纯nx版本

若连叫阵、诱导话术、临场动作都由观音逐项规定，悟空只机械执行，则nx更纯，局部xn邻近进一步下降。

## 7｜最近邻排除

### nx vs xn

- 关键方案骨架：观音设计；
- 局部执行方式：悟空自行调整；
- 最终处分接口：观音掌握。

所以本段不是“悟空自己重新搭了一套流程”，而是“在别人给出的骨架里选择具体动作”。

### nx vs x

观音的法力、净瓶、天罡刀、莲台陷阱和最终处分权都不归悟空调用，因此不是x。

### nx vs zx

悟空没有通过临场自由动作取得新的决定范围，因此局部执行主动性不等于zx扩权。

## 8｜第三因素冻结

冻结以下因素后结论仍成立：

- 孙悟空战斗力强；
- 红孩儿最后被收服；
- 孙悟空会七十二变；
- 观音身份高；
- 唐僧是师父；
- 取经主线；
- 打门、辱骂、激将等戏剧强度。

只保留：

```text
谁设计关键运行骨架？
谁掌握关键资源与最终接口？
主体是否真正改写关键节点？
```

结论仍为：外部方案通道保持，局部执行自由度不足以构成方案重写。

## 9｜与现有待审议问题的关系

当前待审议文件已有三部作品支持：

```text
外部方案存在
→ 主体实际否定并重设关键运行结构
→ nx下降
→ xn上升
```

本轮提供反向限制：

```text
外部方案存在
→ 主体只在方案允许的执行层自由发挥
→ 关键节点、资源、最终接口不变
→ nx不因局部变化自动下降
```

因此后续审议若要收紧规则，不能把“主体做了与原方案文字不完全相同的动作”直接当成重设。应检查的是：

> **决定性流程、节点、资源配置、协同接口或最终处置权是否被主体实际替换。**
