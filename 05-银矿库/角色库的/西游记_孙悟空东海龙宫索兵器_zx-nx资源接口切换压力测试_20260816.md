# 《西游记》孙悟空东海龙宫索兵器｜zx↔nx 资源接口切换压力测试

## 0｜本轮结论

本桥段锁定为：

> **nx 关系功能起手 → 外部资源接口不足/拒绝 → zx 当前状态上升。**

不锁“孙悟空稳定人物本体 = 纯 zx”或“纯 nx”。保留仓库既有孙悟空 `zx+nx` 锚。

同时不锁严格 `zx补nx` 补关系：本桥段更像外部资源接口不能满足后，主体改由自身权能强行扩大取得范围，而不是 nx 与 zx 两端同时互补改善缺口。

## 1｜剧情事实

### 1.1 触发

孙悟空为花果山群猴整备兵器后，发现自己的刀不趁手。四老猴指出东海龙宫可能有合适兵器，孙悟空于是主动前往。

### 1.2 对象与初始动作

进入龙宫后，孙悟空先以“邻居”身份向东海龙王明确“告求一件”兵器。

龙王随后依次提供大杆刀、九股叉、方天戟。孙悟空逐件试用并以“不趁手”“太轻”为由要求继续寻找。

此阶段的关键结构是：

```text
孙悟空自己有目标：取得趁手兵器
↓
龙宫兵器/资源处分接口在龙王
↓
孙悟空先进入既有关系与资源接口请求
↓
龙王提供资源
= nx 关系功能起手
```

### 1.3 金箍棒阶段

龙婆、龙女提出海藏中的定海神珍铁。龙王将孙悟空引到海藏，由孙悟空自行取出并确认如意金箍棒与自己相应。

这一段本身不能仅凭“取得金箍棒”直接锁 zx，因为龙王主动引导其前往，且宝物本身对孙悟空产生适配。资源转移已经明显超出普通赠刀，但仍存在“龙王主动让其取用”的许可成分。

因此单独这一小段不作为本轮 zx 的最硬证据。

### 1.4 披挂阶段：决定性切换

取得金箍棒后，孙悟空继续要求龙王提供披挂。

龙王明确表示没有，并建议孙悟空去其他海域寻找。孙悟空拒绝离开，坚持由东海龙王解决；在龙王仍称没有后，孙悟空直接以手中金箍棒相威胁。

龙王因此改变原先的处理方式，紧急擂鼓撞钟召集另外三海龙王。其他龙王提出发兵擒拿，也被东海龙王以孙悟空力量过强为由否决。最终四海龙王共同凑出凤翅紫金冠、锁子黄金甲、藕丝步云履交给孙悟空，目的明确是把他送走。

最小事实链：

```text
龙王：没有披挂，建议你另找
↓
孙悟空：拒绝离开，要求仍由此接口解决
↓
龙王再次拒绝
↓
孙悟空以自身力量公开施压
↓
龙王改变行为，召集另外三海龙王
↓
四海资源网络围绕孙悟空的新要求重新组织
↓
孙悟空取得原先并未承诺给他的整套披挂
```

## 2｜zx 判断

### 2.1 不是“能打所以 zx”

本轮不能以孙悟空武力强、拿着金箍棒、吓坏龙宫作为直接判据。

真正支持 zx 的是：

1. 孙悟空在龙王明确不能/不愿继续满足后，不再只是沿原资源接口接受可给范围；
2. 他把自身力量直接压入现实，建立新的结果约束：不满足则不离开，并以动手作为现实担保；
3. 原先拥有资源处分权的一方因此改变行为；
4. 东海龙宫进一步调动三海资源网络，围绕孙悟空的要求重新配置；
5. 孙悟空实际取得的资源范围超过最初普通“求一件兵器”的许可边界。

因此本轮锁：

```yaml
zx_current_state_stage: evidence-locked
zx_layer: 当前状态 / 行为功能 / 关系位置
```

### 2.2 决定范围上升在哪里

参考点不是“孙悟空从弱变强”，而是资源关系中的位置变化：

```text
起初：请求者，只能等龙王提供
↓
后段：自己的力量成为新的现实约束
↓
龙王及三海资源节点必须围绕其要求重排
```

所以 zx 上升发生在“资源处分关系中的实际决定位置”，不是职位、身份或战斗胜负。

## 3｜nx 判断

### 3.1 nx 在前段成立为关系功能

孙悟空最开始明确通过“邻居”关系进入龙宫，并向龙王请求兵器。兵器库与海藏资源不属于孙悟空，他需要龙王这一外部资源节点提供。

因此：

```yaml
nx_relation_function_initial_stage: evidence-locked
```

这不意味着孙悟空“没主见”。目标“我要趁手兵器”一直是他自己生成的。

这里的 nx 只解释：

> **资源调用权在别人手里，我先沿既有关系/权限接口取得。**

### 3.2 nx 在后段为什么下降

当龙王明确表示披挂没有、建议孙悟空另找时，如果孙悟空继续去南海、西海、北海逐个请求，那么 nx 关系功能会持续。

但文本实际是：孙悟空拒绝重新路由，要求当前节点解决，并用自身力量迫使该节点主动召集其他资源节点。

因此后段已经不再是单纯“我沿外部接口找资源”，而变成“我让外部接口围绕我的权能重新组织”。

## 4｜最近邻排除

### 4.1 nx vs xn

孙悟空确实有明显行动组织，但本轮关键不是计划、排程、节点设计。

拿掉“先刀、再叉、再戟”的顺序，仍然存在：

```text
外部资源权在龙王
→ 先请求
→ 请求边界不足
→ 主体公开施压
→ 资源网络被迫重排
```

所以 xn 不是主解释。

### 4.2 zx vs x

龙宫兵器、披挂和三海资源在事件开始前并不属于孙悟空长期可自行处分的资源，因此不能判为 x 的正常调用。

如果孙悟空原本就拥有龙宫武库的合法调用权，只是来取自己可取的装备，则优先检查 x，而不是 zx。

### 4.3 nx vs nz

孙悟空称龙王为“邻居”，但这里关系本身不是目标。邻里身份的功能是进入资源接口，因此属于 nx 关系功能，不锁 nz。

### 4.4 武力/身份冻结

冻结“美猴王”“仙圣”“神通广大”等身份与能力标签，只保留“资源权在外部 → 请求 → 拒绝/不足 → 自身权能迫使资源网络重新配置”，结论不变。

## 5｜拿掉测试

### 拿掉关系身份

拿掉“邻居”称呼，只要孙悟空最初仍需要资源持有人批准，nx 关系功能仍成立；只是进入接口的便利度下降。

### 拿掉金箍棒传奇性

把金箍棒换成任何足以形成现实威慑的自身权能，只要孙悟空仍以自己的力量迫使龙王改变资源处分行为，zx 后段仍成立。

### 拿掉三海龙王

如果东海龙王自己有一套披挂并在威压后交出，zx 仍成立；三海龙王只是把“外部资源网络围绕主体重排”显示得更清楚。

### 拿掉龙王拒绝

如果龙王从一开始就主动赠送兵器和披挂，孙悟空只接受，则后段 zx 的关键扩张证据大幅下降，主要剩 nx/x 的资源转移问题。

## 6｜反向测试

### 反向成纯 nx 持续

```text
东海龙王没有披挂
→ 孙悟空接受建议
→ 去南海/西海/北海逐个请求
→ 谁掌握资源就向谁申请
```

则应锁 nx 关系功能持续，而非 zx。

### 反向成 x

如果孙悟空在事件发生前就拥有四海装备的合法处分权，只是正常调用，则应优先锁 x。

### 反向成纯 zx

如果孙悟空一开始根本不请求、不承认龙王资源接口，直接以自身力量闯入武库并强迫龙宫按其需求重新配置，则 nx 起手会消失，桥段更接近纯 zx 状态。

## 7｜第三因素冻结

冻结以下因素后结论仍成立：

- 孙悟空后来大闹天宫；
- 齐天大圣身份；
- 最终取经命运；
- 金箍棒象征意义；
- 龙王后来上天告状；
- 孙悟空是否道德上合理；
- 单纯“强/弱、能打、赢了”。

本轮只检查：

1. 资源处分权最初在谁；
2. 主体是否先沿外部接口；
3. 外部接口不足后主体如何行动；
4. 自身权能是否成为新的现实决定来源；
5. 外部资源网络是否因此被迫重排。

## 8｜与既有案例的增量关系

### 与武松告县失败后私力报仇

武松案例：

```text
外部司法裁决接口失败
→ 主体自行接管取供/裁决/执行
→ zx 上升
```

本轮孙悟空：

```text
外部资源接口先被使用
→ 接口不足/拒绝继续满足
→ 主体以自身权能迫使原节点调动更大资源网络
→ zx 上升
```

两者共同支持“nx 外部接口受阻后可能转向 zx”，但对象域不同：

- 武松：司法裁决权；
- 孙悟空：资源处分权。

因此不是重复样本。

### 与真假美猴王

真假美猴王案例：

```text
外部辨真接口失败
→ 继续找另一个外部接口
→ nx 持续
```

东海龙宫案例：

```text
外部资源接口不足
→ 不再换接口请求
→ 迫使当前节点主动扩大资源网络
→ zx 上升
```

这构成非常清楚的压力分叉。
