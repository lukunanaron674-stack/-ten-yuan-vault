# 荻野千寻
> 归档：`05-银矿库/角色库/千与千寻_荻野千寻.md`

---

## 1. 主十元判断

**主十元：n（阳土·承载/适应）**

**五问法核验：**
- **第1问（拿掉什么她不是她）：** 拿掉n，千寻就只剩害怕——一个会哭的小女孩误入异世界，然后就没有然后了。但千寻怕归怕，**她撑住了**。不是因为她勇敢（zx），不是因为她聪明（nx），不是因为她有信念（zn）——就是因为她扛得住。腐烂神来的时候所有人都跑了，她没跑。不是想好了对策，是活已经接下来了，就得做完。
- **第2问（反复面对什么结构）：** 反复面对「我不知道该怎么办但我要把眼前的事做完」。千寻不做长远规划，不思考人生意义，不想「我要成为什么样的人」——她就做眼前的事：抬水、洗浴池、治河神、找钱婆婆。一件做完再做下一件。**n的人就是这样：不规划，但也不停。**
- **第3问（最怕失去什么）：** 最怕「撑不住的时候没有人在旁边了」。所以她拼命救白龙、救无脸男、救爸爸妈妈——不是因为她伟大，是因为她需要他们也在。n的核心恐惧是「容器空了」——如果身边没有人了，她承载的东西就没有意义了。
- **第4问（回到哪个感觉）：** 回到「我能走回去了」的平静。千寻走出汤屋的时候没有特别激动——n的人做完一件大事不庆祝，他们只是检查一下还有没有落下什么，然后默默走开。
- **第5问（副十元服务谁）：** xn（规则适应）是n的工具。千寻必须学汤屋的规矩才能活下去，但规矩不是她的驱动力——撑住了才是。xn负责帮她找到活路，n负责在她还没找到活路的时候不让她倒下。

## 2. 副十元

**副十元：无显著副十元。** 千寻是一个极其干净的角色——她不靠第二驱动力运转。xn是她借来用的工具，不是她的一部分。

## 3. 功能十元

**功能十元：zx（执行）——极少使用。** 去找钱婆婆是千寻唯一一次打破规则的行动。她一辈子可能只会做这么一次。

## 4. 视觉十元

**视觉十元：无显著。**

## 5. 动态链

```
n（主·怕死了但扛住了）
  → 签契约 → 抬水 → 洗浴池 → 治河神
  → 接住无脸男 → 找钱婆婆
  → 救出爸妈
  → 走出汤屋——不回头
```

## 6. 一句话定型

千寻不是「在冒险中成长的勇敢女孩」，而是「**怕得要死但该做的事一件没落**的人」。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** xn（主）+ n（副）→ 时间型（错误）
**最终定位：** n（主·承载/适应）
**最终修正理由：** 我把千寻想复杂了。她不是规则适应者（xn）——xn的人会主动研究规则、利用规则。千寻不研究规则，她只是忍着。腐烂神来的时候她没跑，不是因为想好了怎么应对（xn），也不是因为勇敢（zx）——只是因为她接了这份工。这是n最干净的样子：**怕得要死，但扛着不放手。**
