# 《水浒传》林冲火并王伦｜zx↔nx 准入权夺取压力测试

## 1｜本轮对象

只截取第十九回：晁盖等人投梁山，王伦再次以“粮少房稀”等理由拒绝收留；林冲公开反对、杀王伦，随后拒坐第一把交椅，并主张由晁盖出任山寨之主。

本轮不判“林冲整个人物 = zx”，只判断这一窄阶段的当前状态、行为功能与关系位置。

## 2｜剧情事实

- 晁盖等人投梁山，王伦持续支吾，不愿收留。
- 林冲此前已经明确不满王伦狭隘，并表示若王伦再有不当言语，“尽在林冲身上”。
- 吴用看出林冲已有火并王伦之意，并准备在席间以言语和暗号推动局面；晁盖等人也有协助，因此不能把全部事件单因归给林冲。
- 王伦正式以银两送客后，林冲公开质问其前后同样以“粮少房稀”拒人的做法，继而拔刀杀王伦。
- 王伦死后，杜迁、宋万、朱贵等原梁山头领屈服；吴用曾推林冲坐第一位，林冲明确拒绝，并提出由晁盖出任山寨之主。
- 梁山首领结构因此从“王伦拥有准入与首领决定权”转为新的领导结构。

文本依据：
- 《水浒传》100回本第十九回，维基文库 / 中国哲学书电子化计划。
- 关键段落包括林冲事前表态、吴用判断其已有火并意图、林冲杀王伦、原头领屈服，以及林冲拒第一位并另推晁盖。

## 3｜样本类型判断

锁定：

```text
上一阶段：梁山准入权在王伦
→ 林冲作为申请者/山寨成员承认外部准入接口
→ nx 关系位置成立

本阶段：王伦再次拒绝晁盖等人
→ 林冲不再沿王伦准入接口续接
→ 公开否定王伦作为首领的资格
→ 直接清除原最高决定节点
→ 梁山首领结构被迫重排
→ 林冲临时成为新结构的关键决定来源
= zx 当前状态高显影
```

当前窄阶段 `nx`：rejected。

## 4｜zx 证据

按 zx v2.3 / zx 准度卡 v0.1：

### 4.1 主体自身决定接口明确

林冲并非只表达不满。他公开宣布王伦“不做得山寨之主”，随后亲自执行清除，并在王伦死后参与决定新的首领结构。

### 4.2 权能公开进入现实

行动发生在梁山核心头领与晁盖集团共同在场的公开场合，不是内部意愿或秘密掌握。

### 4.3 他者与秩序被迫回应

王伦旧部无法维持原秩序；杜迁、宋万、朱贵等屈服，第一把交椅与首领排序重新确定。

### 4.4 决定位置真实上升

上一阶段林冲面对王伦时只能请求被收留、接受投名状等准入条件；本阶段他已经能够否定原准入者本身，并实际参与重建“谁做寨主、谁能留下”的组织决定结构。

因此这里不是“杀人很猛 = zx”，而是：

```text
原最高决定接口被主体公开推翻
+ 组织必须重新围绕主体造成的新事实排列
+ 主体取得此前没有的结构性决定位置
= zx 状态成立
```

## 5｜nx 证据与排除

当前窄阶段不再满足 nx：

- 林冲没有继续等待王伦批准晁盖入伙；
- 没有换另一个外部准入节点求人；
- 没有接受王伦新增条件继续推进；
- 而是直接否定并清除原权限节点。

所以不能把“吴用参与、晁盖协助”反推成 nx。是否有人协助，与“最终组织决定接口是否仍属于外部他者”是两回事。

## 6｜与上一阶段林冲投梁山的同人物对照

上一案例《水浒传_林冲投梁山_zx-nx外部准入条件压力测试_20260816》已经锁：

```text
王伦掌握梁山准入权
→ 林冲接受投名状条件
→ 沿原权限接口推进
= nx 关系功能持续
```

本轮：

```text
同一个王伦 / 同一个梁山准入结构
→ 王伦再次拒绝新的强者进入
→ 林冲不再承认该接口为最终决定点
→ 清除王伦并重排寨主结构
= zx 决定位置上升
```

这属于同人物跨阶段压力显影，不应写成“林冲换芯”。

## 7｜最近邻排除

### 7.1 zx vs xn

吴用确实有明显的预判、语言诱导、暗号和协同安排，属于强 `xn` 邻近污染；这些设计不能偷算成林冲的 xn。

把吴用的暗号、晁盖等人的协助方案全部冻结，只保留：

```text
林冲公开否定王伦首领资格
→ 亲自清除最高节点
→ 原头领结构无法继续
→ 林冲参与重定新寨主
```

zx 仍独立成立。

### 7.2 zx vs x

如果林冲原本就拥有梁山最高准入与寨主处分权，只是正常撤换下属，优先检查 x。

但上一阶段恰好证明最高准入权不在林冲，而在王伦；因此本轮存在真实的决定位置跃迁，支持 zx 而不是普通 x。

### 7.3 zx vs nx

有人协助林冲，不等于关键决定接口仍属于别人。吴用推动局势，但王伦被清除后，林冲并非沿吴用既有权限办事；吴用也并非梁山原有准入权主体。

## 8｜拿掉测试

### 拿掉“武力强”

只保留“主体公开清除原最高决定节点，并使组织首领结构重排”，zx 仍成立。

### 拿掉“吴用煽动”

林冲在席前已经自主表达对王伦的不满，并承诺若王伦再有不当言语由自己承担；吴用的推动提高触发概率，但不是林冲 zx 成立的必要来源。

### 拿掉“林冲是否自己当寨主”

即使林冲拒绝第一位，只要他已经取得了足以废除旧首领、决定新结构的实际位置，zx 仍成立。zx 看决定位置是否扩大，不要求主体最终把最高职位长期占为己有。

## 9｜反向测试

### 反向成 nx

若王伦拒绝晁盖后，林冲仍承认王伦拥有最终准入权，只继续劝说、找中间人、接受新条件或寻找另一个外部批准节点，则 nx 关系功能继续。

### 反向成普通强烈反抗但非 zx

若林冲只是怒骂、拔刀或制造混乱，却被立即压回，王伦仍保有寨主与准入决定权，则只能是强烈反抗，不足以证明 zx。可与“李逵扯诏反招安”伪 zx 案对照。
