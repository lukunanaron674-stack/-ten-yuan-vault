# 《三国演义》刘备穰山败后投刘表｜zx↔nx 木轴压力测试

## 结论先行

本轮锁定一个高价值 **nx 关系功能正例**：

> 刘备在穰山败后并没有丢掉自己的政治方向，也不是“没主见”。但他此时兵败、无立锥之地，关键的驻留空间、军粮、安全与继续活动许可都不在自己手里。孙乾提出投刘表后，刘备明确担心“但恐不容”，随后派孙乾先行说项；孙乾以“同为汉室宗亲”这一既有身份关系作为接口，请刘表接纳。刘表最终决定接纳并出郭相迎，分拨院宅居住。这个阶段的关键解决通道与最终许可明确在刘表一侧，因此成立 **nx 关系功能高显影**，而不是稳定人物本体 nx。

最小结构：

```text
主体仍有自己的长期方向
+
当前直接权能不足以提供立足点
→ 识别既有宗亲/政治关系接口
→ 派使者先行请求接纳
→ 等待外部权力主体决定是否放行
→ 获得驻留与继续行动条件
= nx 关系功能高显影
```

本轮进一步支持：

```text
有主见 ≠ 排除 nx
强主体 ≠ 排除 nx
长期方向由自己坚持 ≠ 每一段解决通道都必须由自己建立
```

---

## 1｜原始事实

### 触发：穰山败后失去直接立足条件

刘备在汝南一带遭曹军压制，汝南失守，部众被分割包围，后虽与关羽、张飞、赵云重新会合，但败军已不足千人。到汉江边暂时安营时，刘备感叹自己“身无立锥”，担心继续拖累部下。

这一步说明当前压力是现实性的：

```text
兵力大损
+ 原据点失去
+ 曹军威胁仍在
→ 自身直接提供驻留、安全和补给的能力不足
```

但“败了”本身不等于 nx，只是触发条件。

### 主体仍保留自己的长期方向

此前刘备仍公开以汉室宗亲、奉诏讨贼的方向与曹操对抗；败后也不是改成“谁收留我我就完全听谁”。因此本轮不把刘备整体人物判为没主见型 nx。

关键要观察的是：**这一具体问题——下一处合法、安全、可持续立足点——由谁拥有许可。**

### 孙乾提出进入既有关系接口

孙乾指出荆州刘表兵强粮足，而且与刘备同为汉室宗亲，建议前往投奔。刘备没有说“我直接占荆州”或“我自己建立新据点”，而是回答“但恐不容”。

这句话非常关键：

```text
刘备有行动目标
但是否能进入荆州
并不由刘备自己决定
```

于是孙乾主动提出先往说之，使刘表出境相迎。刘备接受，并派孙乾星夜先行。

### 求助路径明确沿既有身份与权限网络运行

孙乾到荆州后并非强行要求，而是向刘表说明：

```text
刘备新败
+
刘备与刘表同为汉室宗亲
+
不应舍亲而向疏
→ 因此先来拜白
→ 最终听刘表裁定
```

蔡瑁反对接纳，甚至主张杀孙乾献曹；孙乾只能辩护，最终仍由刘表拍板。

所以整个接口结构非常清楚：

```text
刘备/孙乾提出请求
→ 宗亲与政治关系提供“可请求”的通道
→ 刘表掌握是否接纳的最终许可
```

### 可观察结果

刘表最终叱退蔡瑁的反对，决定接纳刘备，并亲自出郭迎接，随后分拨院宅让刘备一行居住。

这说明实际改变变量是：

```text
无稳定立足接口
→ 经既有宗亲/政治关系通道获得刘表许可
→ 获得荆州驻留与继续活动条件
```

这与现行 nx “关键权限与解决通道在他者手里，主体沿既有关系接口借力推进”的关系功能高度吻合。

## 2｜为什么这是 nx 关系功能，而不是纯 nx 本体

纯 nx 本体要求人物长期不占最终方向，反复让别人决定路线；本例不支持这一点。

刘备在这一阶段仍然保留自己的长期政治方向，只是在“下一处立足点”这一具体问题上：

```text
荆州地盘不是他的
驻留许可不是他的
粮草与保护接口不是他的
是否接纳由刘表决定
```

因此应分层：

```text
人物稳定本体：本轮不锁 nx
当前解决路径：nx 关系功能高显影
```

这与现行 nx 信息卡中“强主体也可以使用 nx 功能”完全一致。

---

## 3｜为什么这里不优先判 zx

刘备此时仍有意志、有目标，也曾主动征战，但本轮窄阶段的关键结果并不是：

```text
自身权能公开扩大
→ 刘表或荆州秩序被迫围绕刘备重排
→ 刘备直接取得更高决定位置
```

实际发生的是：

- 刘备担心刘表“不容”；
- 必须由孙乾先行请求；
- 蔡瑁可以公开反对；
- 最终接不接纳仍由刘表决定；
- 刘备获得的是别人批准的驻留条件。

因此：

```text
主动寻找出路 ≠ zx
身份显赫 ≠ zx
曾经很能打 ≠ zx
```

本轮最强变量是“通过既有关系网络取得外部许可”，故优先 nx 关系功能。

## 4｜最近邻排除

### nx vs zx

`zx` 要求自身权能公开进入现实并扩大决定范围；本例的驻留决定权始终在刘表侧。刘备不能绕过许可直接让荆州接受自己，因此优先 `nx`。

### nx vs xn

孙乾“先去说项”存在顺序设计，但没有形成复杂排程、流程、节点或资源组织系统。本段核心变量不是运行结构，而是利用已有宗亲政治接口取得一次关键许可，因此不优先 `xn`。

### nx vs x

荆州地盘、院宅、资源、驻留许可不归刘备掌握，故不是 `x`。

### nx vs xz

穰山败后的危险压力确实很强，`xz` 可作为外部压力候选；但危险只解释“为什么必须尽快找出路”，不能替代“实际通过谁的权限通道获得立足条件”。所以本轮记录压力，但不让压力偷走 nx 的行为/关系归类。

## 5｜拿掉测试

### 拿掉“穰山战败”

如果换成别的原因导致刘备没有合法驻留地，只要仍然是：

```text
荆州许可在刘表
→ 刘备必须通过宗亲/政治关系与使者请求
→ 刘表决定是否接纳
```

nx 关系功能仍成立。

因此战败是触发因素，不是 nx 本体。

### 拿掉“汉室宗亲”关系

如果没有同宗这一既有身份接口，刘备仍可以请求刘表，但本例最清晰的“沿既有关系网络”证据会显著下降，可能只剩一般求助行为候选，纯度降低。

### 拿掉刘表的许可权

如果荆州本来就归刘备处分，他可自行驻军、调用粮草，无需刘表批准，那么本例 nx 会明显下降，优先检查 x / zx / xn 等其他端点。

这说明“最终许可外置”是本例的核心条件。

## 6｜反向测试

### 反向A：真正 zx 版本

```text
刘备兵败后直接进入荆州
→ 以自身力量迫使刘表与荆州秩序接受
→ 自己取得并扩大对荆州的决定权
```

此时 zx 会显著上升。

原作没有发生。

### 反向B：纯人物本体 nx 版本

```text
刘备长期没有自己的政治方向
→ 每到一地都只等当地权力者告诉他下一步做什么
→ 获得自主窗口后仍不提出自己的路线
```

这才更支持稳定人物本体 nx。

原作并不满足，因此本轮禁止由“投奔刘表”倒推“刘备整个人没主见”。

### 反向C：xn 版本

```text
刘备接到一个外部目标
→ 自己设计多阶段迁移计划
→ 配置人马、补给、时序、备用路线并持续组织运行
```

此时重点应转向 xn，而不是 nx。

## 7｜第三因素冻结

本轮冻结以下因素，不允许直接判十元：

- 刘备是汉室宗亲；
- 刘备此前多次投奔他人；
- 他此刻兵败；
- 他部众不足千人；
- 刘表对他礼遇；
- 蔡瑁反对；
- 刘备最后成功住进荆州；
- 刘备个人英雄气质或历史评价。

真正支持 nx 的证据只有：

```text
关键立足资源与许可在刘表手中
+
刘备承认自己不能直接决定“是否被容纳”
+
通过孙乾与同宗身份这一已有政治关系接口请求接纳
+
最终沿刘表的许可取得驻留条件
```

## 8｜木轴压力测试结论

本轮与《红楼梦》刘姥姥“一进荣国府”形成跨作品同型对照：

```text
刘姥姥：
主动发现问题、主动进城求人
→ 钱财与进入许可在荣府
→ 沿旧亲/周瑞家的/平儿/凤姐通道
= nx 关系功能

刘备：
长期政治方向仍由自己坚持
→ 但当前立足空间与许可在刘表
→ 沿宗亲/使者/政治接纳通道
= nx 关系功能
```

因此得到第二部独立作品支持：

> **主动性、有主见、长期方向明确，都不能直接排除 nx。只要某个关键问题的解决通道与最终许可确实外置，主体必须进入已有关系、身份或权限网络借力，该段仍可成立高纯度 nx 关系功能。**

当前跨作品支持数：2（《红楼梦》刘姥姥；《三国演义》刘备）。尚未达到“跨至少3部独立作品形成待审议问题”的门槛，本轮不新建 pending，不修改理论正本。

### 锁定

```text
《三国演义》第三十一回刘备投刘表
= nx 关系功能高显影正例
= 行为功能 / 关系位置 / 当前状态层证据
```

### 不锁定

```text
刘备稳定人物本体 = nx
刘备稳定人物本体 = zx+nx
投奔别人 = 自动 nx
兵败 = nx
宗亲身份 = nx
```

## 10｜下一轮最有价值目标

优先从《水浒传》寻找第三个“强主动主体主动求人/借权，但关键许可与资源仍在他者手里”的高纯度样本。

若第三部独立作品仍复现，可形成待审议问题：

```text
主动性不排除 nx；
人物总体有主见，也可稳定使用 nx 关系功能；
nx 的核心应继续放在关键方向/权限/解决通道的外置，而不是被动程度。
```
