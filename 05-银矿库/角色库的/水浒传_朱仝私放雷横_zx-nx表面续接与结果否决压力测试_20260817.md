# 《水浒传》朱仝私放雷横｜表面续接与结果否决压力测试

## 结论先行

本轮锁定：

> **表面继续执行外部命令、进入既有流程、甚至维持“押解中”的外观，都不能单独锁 nx。真正要看关键结果窗口出现后，主体是否仍沿外部方向把结果做成。**
>
> 朱仝奉命押解雷横赴济州，前段确实进入既有司法押解流程；但途中他主动把雷横带到僻静处开枷放走，又故意延迟追赶，给雷横争取逃亡时间。于是“把雷横送交上级司法机关”这一最终结果并没有沿外部方向完成，而是被朱仝实际否决并改写。
>
> 因此，在“押解结果是否完成”这一窄对象层，`nx` 排除；但这也不构成 `zx`，因为朱仝没有取得新的正式释放权、没有扩大自己的制度决定范围，反而因故放犯人承担刑罚。

本轮不锁朱仝稳定人物本体，不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实

### 触发

雷横打死白秀英后，知县最终把案件做成死案，限满断结，要把雷横解上济州。主案押司先带文卷前行，朱仝被安排负责押送雷横。

朱仝此前已经设法替雷横说情、走人情，但知县不肯放松，因此正式司法方向已经明确：

```text
雷横在押
→ 朱仝负责押解
→ 送往济州继续司法处分
```

### 表面续接

朱仝带着十数个小牢子押雷横离开郓城县，表面上确实沿既有司法流程前进。

如果只截这一层，很容易写成：

```text
上级给任务
→ 朱仝接受
→ 按押解流程走
= nx
```

但这不是最终决定窗口。

### 关键结果窗口

行出十余里后，朱仝借在酒店停留之机，独自把雷横带到僻静处，亲手开枷，明确让雷横赶快回家接老母、逃往别处，并表示自己愿承担后续官司与赔偿。

雷横离开后，朱仝又把空枷丢在草里，对小牢子谎称雷横逃走；众人要追时，他故意延迟，等雷横走远后才回县出首。

因此朱仝不是“押解途中不小心失手”，而是主动形成并执行了相反结果：

```text
正式方向：把雷横送到济州
↓
朱仝知道该方向
↓
在真正结果窗口主动开枷
↓
故意创造逃亡时间
↓
押解结果被主体实际改写
```

### 结果

雷横成功带母亲逃走并投梁山。朱仝则因故放雷横受到追究，最终被杖责、刺配沧州。

这证明外部司法方向仍有强制力，但不能反推朱仝在关键结果层实际沿它续接。

## 2｜nx 判断

### 前段：存在表面流程续接，但不是端点决定证据

朱仝确实接受了押解任务，也实际走进既有司法流程。因此可以记录：

`nx_surface_procedure_behavior: present_but_not_endpoint_decisive`

但现行 nx 准度卡要求检查：

- 最终方向是谁的；
- 主体是否抢回否决与重设位置；
- 真正自主窗口出现时是否仍沿外部方向推进。

朱仝在最关键窗口实际做了相反动作，因此不能用前面的流程服从覆盖后面的结果否决。

### 最终结果层：nx 排除

本段真正要判的对象是：

> **雷横最终是否被朱仝按外部司法方向送交济州。**

答案是否定的，而且否定来自朱仝主动设计与执行。

因此锁：

`nx_in_final_outcome_layer: rejected`

这说明：

> **程序上看起来在服从，不等于结果层仍然不占否决位置。**

## 3｜zx 判断

### 私放成功，但不构成扩权

朱仝确实改变了现实结果，而且雷横成功逃脱。但现行 zx 不能由“我成功违令”“我造成大结果”直接推出。

zx 仍要求：

```text
主体自身权能公开进入现实
→ 他者/秩序被迫围绕主体重新反应
→ 主体决定范围、影响位置或凌驾程度上升
```

朱仝恰恰没有获得新的正式决定范围：

- 他没有取得合法释放犯人的处分权；
- 县衙、济州司法体系没有承认新的“朱仝可决定放人”接口；
- 他必须把行为伪装成犯人逃脱；
- 行为暴露后，他受到杖责与刺配。

因此锁：

`zx_in_narrow_stage: rejected_as_primary`

> **偷偷改掉结果 ≠ 现实承认我的新增权力。**

## 4｜最近邻排除

### xn

朱仝确实有局部设计：选酒店停留、单独带雷横到僻静处、开枷、故意拖延追赶。这些带有计划与节点组织成分，可视为 `xn` 行为邻近。

但拿掉具体酒店、路线和拖延技巧，只保留：

```text
外部要求押送
→ 关键窗口主体主动放人
→ 最终结果被改写
```

`nx` 的排除仍成立。

因此 `xn` 解释“怎样完成私放”，不能替代木轴回答“最终结果有没有继续沿外部方向”。

### nz

朱仝与雷横的义气、友情明显解释了他为什么愿意承担代价去救雷横，但 `nz` 属于动机/关系对象层，不能替木轴回答最终方向与结果资格。

### x

朱仝作为押解者拥有部分看守与执行权限，但没有正式释放雷横的处分权。若该释放权本来归他正常掌握，才优先检查 `x`；文本恰恰以他被追责证明该权限并不属于他。

### xz

故放犯人的法律后果、可能受罚属于明显压力，但压力不能直接判 nx 或 zx。高成本下仍实际否决外部结果，反而强化“最终结果层不是 nx”的证据。

## 5｜拿掉测试

### 拿掉“义气”评价词

只保留“受命押解 → 主动开枷 → 故意拖延 → 雷横逃走”，`nx` 最终结果层仍被排除。

### 拿掉雷横最后上梁山

即使只知道雷横成功脱离押解，而不知道后续去向，朱仝已经完成了结果改写，结论不变。

### 拿掉酒店与具体手法

如果换成途中任何安全窗口，只要朱仝仍主动释放并阻止有效追赶，结论仍然成立。

### 拿掉惩罚

即使朱仝后来侥幸未受罚，也不能把私自改写押解结果变成 nx；惩罚只是证明外部制度边界仍存在。

## 6｜反向测试

### 反向成真 nx

朱仝心里同情雷横，也曾替他求情，但真正押解窗口出现后仍把雷横完整送交济州，不私放、不改结果。

这时可以形成：

```text
内心不同意
+ 先尝试说情
+ 最终仍沿外部司法方向完成押解
= nx 当前行为/关系位置明显上升
```

### 反向成 zx

朱仝不仅放人，而且因此公开取得了原本没有的释放处分权，县衙或更大司法秩序以后必须承认并围绕他的新增决定接口运行。

文本没有这种结构，所以本段不能判 zx。

## 7｜与现有锚的最小差异

### 孙悟空被逐：异议但实际续接

已入库《西游记》孙悟空被逐案例：

```text
不同意唐僧逐走
→ 反复申辩
→ 最终仍接贬书并离队
= nx 当前关系位置成立
```

### 关羽华容道：公开实际否决

已入库《三国演义》关羽华容道案例：

```text
知道军令
→ 曹操到达关键窗口
→ 公开/实际放行
→ 愿承担军法后果
= nx 最终执行层排除
```

### 朱仝私放雷横：表面续接、秘密改结果

本轮新增中间形态：

```text
接受押解任务
→ 表面沿流程执行
→ 在关键结果窗口秘密开枷放人
→ 还故意维持“意外逃脱”外观
= 表面程序续接
≠ 最终结果层 nx
```

因此目前可形成三档案例级纪律：

```text
心理/口头反对，但最终按外部方向完成结果
→ nx 可成立

表面执行，但关键结果被主体暗中改写
→ 必须以实际结果层重判，不能按表面服从锁 nx

明确在关键窗口实际否决外部方向
→ nx 排除
```

这只是案例级纪律，不修改 L1 或 nx 核心定义。

## 8｜稳定本体、状态、功能、关系位置与压力分层

- 稳定人物本体：不锁朱仝为 zx 或 nx。
- 当前状态：存在司法压力与高成本违令窗口。
- 行为功能：前段有表面流程执行，后段有主动结果改写。
- 关系位置：朱仝仍是司法体系中的押解执行者，不拥有正式释放处分权。
- 外部压力：知县、济州司法流程、故放犯人的刑罚风险。
- 木轴结论：最终押解结果层 `nx` 排除；`zx` 不成立。

## 9｜严格 zx↔nx 补关系检查

不锁。

本轮没有出现“两端各自独立成立并互补缺口”的稳定结构。表面程序服从不能拿来和后段结果否决硬焊成 `zx+nx`；朱仝也没有形成 zx 扩权。
