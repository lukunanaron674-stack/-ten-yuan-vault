# 《水浒传》李逵接母：zx-nx 关系价值与许可通道双功能压力测试

## 0｜结论先行

本轮只检查李逵—宋江这一条关系在“李逵回乡接母”事件中，是否能同时存在：

```text
A｜关系本身有持续价值 / 信任 / 牵挂
B｜当前事件又真实承担外部许可与组织资源通道
```

结论：可以。

```text
李逵自己生成方向：我要回乡接母
→ 不是纯nx本体

但：
离山行动仍受梁山核心组织许可约束
→ 宋江先明确拒绝
→ 李逵抗议后，宋江仍掌握是否放行的实际接口
→ 只有接受三项条件后才“放你去”
= nx 当前许可关系功能成立

同时：
宋江称李逵“兄弟”，对其安危持续担忧
→ 放行后仍主动另派朱贵探听消息
= 关系不是一次性工具关系
```

本轮因此锁定：

> **关系本身有持续价值，不能反向推出当前 nx 必然退出。只要同一关系在当前事件里仍承担主体必须经过的真实外部许可 / 权限接口，nx 关系功能仍然可以成立。**

本轮不越轴正式锁 nz，只记录 `nz_relation_value_neighbor: present_not_formally_locked`。

## 1｜剧情事实

### 触发

宋江父子团聚、公孙胜又提出回乡省母后，李逵触景思母，在关下放声大哭，明确提出自己也要回乡把老母接到梁山。

### 对象

- 李逵：自己生成“回乡接母”这一方向；
- 宋江：在梁山当前组织关系中，拥有对李逵此次离山行动的真实放行 / 限制位置；
- 李逵母亲：李逵当前行动目标，不是提供权限的节点；
- 朱贵：宋江放行后另行调用的安全保障 / 探听节点。

### 明确动作

1. 李逵提出回乡接母；
2. 宋江先明确阻止，理由包括李逵性急、官府追捕和路途风险；
3. 李逵公开抗议，指出宋江能接父亲，自己也应接母亲；
4. 宋江没有因此失去放行位置，而是改成条件式许可：只有依三件事，才“放你去”；
5. 第四十三回，李逵逐项接受条件后下山；
6. 宋江仍放心不下，另遣朱贵回乡探听李逵消息。

### 结果

李逵成功离山回乡，但行动入口不是他单方面决定后直接生效，而是经过宋江先否决、再条件放行后进入现实。

## 2｜nx 判断

结论：`nx_leave_permission_relation_function: evidence-locked`。

注意：这不是“李逵没主见”。

他的方向非常明确：

```text
我要接母亲上山
```

所以纯 nx 本体不能由此成立。

真正的 nx 对象层是：

```text
这次离山行动是否能在梁山组织关系中放行
```

文本给了非常硬的真实否决证据：

```text
李逵提出
→ 宋江先说使不得 / 不许立即去
→ 李逵抗议
→ 宋江仍保留许可接口
→ 条件满足后才“放你去”
```

因此不是名义上的“哥哥说一句话”，而是一个在冲突中实际表现出：

- 能拒绝；
- 能附加条件；
- 条件被主体接受后才放行；

的真实外部权限节点。

这符合 nx 准度卡关系功能层：人物可以自己有方向，但某项关键权限、资源或通道在他者手里，必须沿既有关系 / 组织接口推进。

---

## 3｜zx 判断

结论：`zx_in_narrow_stage: rejected_as_primary`。

李逵抗议很强烈，甚至直接指责宋江“不平心”，但：

```text
强烈抗议
≠
取得新的决定范围
```

结果并不是宋江的放行接口被李逵夺走，而是宋江从“暂不许去”转为“满足三项条件便放你去”。

李逵没有因此取得：

- 自己以后可以无条件决定所有离山行动的权限；
- 对其他梁山人员离山的许可权；
- 一个新的组织最高决定位置。

所以本轮不能把“吵赢一部分 / 最后获准”写成 zx 扩权。

---

## 4｜关键压力

外部压力包括：

- 李逵是江州劫法场后被追捕人物；
- 宋江担心其性急、饮酒、携斧惹事；
- 路程远，若出事梁山难以及时得知。

这些压力解释宋江为什么先拒绝、为什么设置条件，但不直接判 nx。

真正支持 nx 的仍是：

> **冲突发生后，宋江拥有真实可使用的拒绝 / 条件放行接口，而李逵最终必须通过这个接口才能按当前组织关系下山。**

---

## 5｜关系价值与 nx 通道为什么可以同时成立

这轮是当前 pending-review 的第二部独立作品反例。

如果只看 nx，很容易误写成：

```text
宋江只是一个组织许可节点
```

但原文同时写出：

- 李逵一直称宋江“哥哥”；
- 宋江称李逵“兄弟”；
- 宋江并非放行后就不管，而是明确“放心不下”；
- 他主动寻找李逵同乡朱贵，另派其探听消息；
- 朱贵后来也明确告诉李逵，自己是因宋公明担心其惹事而被派来。

因此同一关系至少存在两个对象层：

```text
A｜关系 / 信任 / 牵挂层
宋江—李逵不是一次性工具交换

B｜当前许可通道层
李逵此次离山仍须经过宋江真实放行接口
= nx 关系功能
```

所以：

> **关系有持续价值 ≠ nx 自动退出。**
>
> **关系是否有感情，与当前是否承担现实权限 / 资源 / 解决接口，是两个不同问题。**

本轮只在木轴正式锁 nx；`nz` 仍只作最近邻提示，不越轴锁定。

## 6｜拿掉测试

### 拿掉“哥哥 / 兄弟”称谓

只保留：

```text
主体想离山
→ 组织许可主体先拒绝
→ 设置条件后才放行
```

nx 许可关系仍成立。

说明关系亲密不是 nx 必要条件。

### 拿掉宋江的许可权

如果李逵本来可以完全自行离山，宋江只能表达担忧但不能阻止、附条件或放行，那么本轮最强 nx 证据消失。

说明 nx 不是靠“宋江关心李逵”成立，而是靠真实权限接口成立。

### 拿掉宋江后续担忧与派朱贵

nx 仍成立，但“这条关系本身有持续价值”的反例证据明显变弱。

因此关系价值与 nx 权限功能是两套可独立拿掉的变量。

## 7｜反向测试

### 反向成非 nx

李逵提出接母后，不需任何人批准，直接自行离山；宋江最多事后担心，但无法阻止、修改或附加条件。

则当前许可层 nx 应下降。

### 反向成更纯 nx

李逵连“要不要接母”都不自己形成，完全等宋江决定是否回乡、什么时候回乡、是否接母，再照做。

则纯 nx 本体 / 行为证据会明显增强。

### 反向成 zx

李逵不但突破宋江限制，还因此取得新的、可持续的离山处分权或组织决定位置，并使梁山以后围绕这个新增接口运行。

原文没有。

---

## 8｜最近邻排除

### nx vs nz

- `nx` 回答：这次离山是否必须经过宋江现实许可接口？答案是是。
- `nz` 候选回答：宋江—李逵关系本身是否具有持续价值、牵挂与回返性？文本有明显外观，但本轮不越轴锁定。

两者可以在不同对象层并存，不能互相排斥。

### nx vs xn

宋江设置三项条件、安排朱贵探听，有运行与风险控制意味，可检查宋江一端的 xn；但李逵这一对象层的 nx 证据来自“是否放行”的外部权限，不会被这些流程设计取代。

### nx vs x

离山许可如果已经完全归李逵自己，才检查 x；本段实际存在宋江可拒绝、可附条件的外部接口，所以不是 x。

## 9｜第三因素冻结

冻结以下变量后，结论不变：

- 李逵是否孝顺；
- 宋江是否偏心；
- 李逵武力强弱；
- 官府追捕是否最终抓到李逵；
- 李逵后来是否遵守不饮酒、不带板斧；
- 老母后续命运；
- 李逵“黑旋风”身份与人物主题。

木轴只看：

```text
方向是谁生成？
当前许可接口在谁手里？
冲突时能不能真实拒绝 / 附条件？
主体最终是否沿该接口取得放行？
```

## 10｜最终锁定

```text
李逵稳定人物本体：不锁
李逵接母方向：本人生成
当前离山许可关系：nx evidence-locked
zx 当前扩权：rejected_as_primary
nz 关系价值：present_not_formally_locked
严格 zx↔nx 补关系：不锁
```

本轮新增的案例级纪律：

> **有关系 ≠ 自动 nx；有关系价值 ≠ 自动非 nx。当前事件中，这条关系是否真实承担可拒绝、可放行的外部许可 / 权限 / 资源接口，才决定 nx 关系功能是否成立。**
