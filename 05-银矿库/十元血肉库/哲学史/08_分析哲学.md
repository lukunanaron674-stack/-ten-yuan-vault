# 哲学史大脉络 ⑧ · 分析哲学

## 一句话定位

> **不讨论"存在的意义"这种大问题，转而分析"这句话到底在说什么"——哲学是概念的澄清，不是真理的宣告。**

## 物象映射

**物象：维特根斯坦的梯子**

```text
x = 传统哲学的空洞——"哲学家说了太多无意义的话"
n = 逻辑分析、语言分析——作为哲学的唯一合法工具
z = 哲学不是给答案，而是治疗——让问题消失
```

**物象强度：9/10**

## 封存句

> **分析哲学不是不关心"大问题"——它只是想说：在你追问"存在的意义"之前，先搞清楚"存在"这个词到底是什么意思。**
