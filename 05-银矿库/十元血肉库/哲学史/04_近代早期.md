# 哲学史大脉络 ④ · 近代早期

## 一句话定位

> **不再问"世界是什么"，转而问"我能知道什么"——认识论取代本体论成为哲学的第一问题。**

## 物象映射

**物象：笛卡尔的烛火照破黑暗**

```text
x = 旧知识体系的崩塌（宗教改革、科学革命、地理大发现）——一切都不可靠
n = 我思（cogito）作为知识的新基石——唯一不可怀疑的确定性
z = 现代科学的哲学奠基——知识大厦重建
```

**物象强度：9.5/10**
