# 哲学史大脉络 ⑤ · 德国唯心论

## 一句话定位

> **主体不再是被动接受世界，而是主动构造世界——连"物自体"都只是意识的设定。**

## 物象映射

**物象：从自我出发的螺旋阶梯**

```text
x = 康德留下的"物自体"残局——世界的终极不可知
n = 绝对自我/绝对精神：一个能够包含一切的终极主体
z = 封闭的哲学体系——理性不需要外部来担保自己的完整性
```

**物象强度：8/10**
