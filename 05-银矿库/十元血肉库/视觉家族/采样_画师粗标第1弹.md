# 画师粗标索引表 · 第1弹（1-16）

## 高饱和发光系

### 01 ASK
| 维度 | 内容 |
|------|------|
| 色彩规则 xn | 高饱和红/蓝/紫主色调 + 白色光晕/逆光处理；互补色（红vs紫蓝）统一在暖色系中 |
| 人物处理 | 半厚涂+高光边缘；眼睛大、亮、用多个发光色层叠加；表情淡漠/疏离 |
| 情绪倾向 nz+zn | 守望+梦幻——角色不跟你对视、在看画面外某个地方；有「某人不在的地方」的感觉 |
| 十元粗位 | xn(色光规则)+nz(守望姿态) |
| 归仓 | 命运 xz+nz（强烈的「等待被带走」感） |

### 02 Mika Pikazo
| 维度 | 内容 |
|------|------|
| 色彩规则 xn | 极端高饱和——荧光粉/亮蓝/亮黄直接压在一起；颜色拼接比ASK更硬更直 |
| 人物处理 | 厚涂+硬边切色；色彩构成像平面设计一样的块面切割；表情活泼/大胆 |
| 情绪倾向 z+zx | 冲动+行动——角色不是在看远方，是在看「你」，像是在邀请你玩游戏 |
| 十元粗位 | xn(极端色彩规则)+z(大胆向前的冲动) |
| 归仓 | 时间 xn+z（活泼、瞬间感强） |

### 03 藤ちょこ（藤原）
| 维度 | 内容 |
|------|------|
| 色彩规则 xn | 高饱和但透气——颜色多但都压在一个灰粉/浅紫的基调中；场景用大量的反光面/透光材质 |
| 人物处理 | 厚涂+精致线稿混合；眼睛是画面焦点的玻璃感；姿势动态不大但有分量 |
| 情绪倾向 nz+zn | 守望+梦幻——非常安静，像是在对场景本身说话 |
| 十元粗位 | xn+nz |
| 归仓 | 空间 x并z+n（角色与场景融为一体，环境充满意义） |

## 米山舞系（厚涂+赛璐珞混合）

### 04 米山舞
| 维度 | 内容 |
|------|------|
| 色彩规则 xn | 自然光下的中间色——不过分饱和也不灰度；白色/米色/浅蓝灰色域多；暖光+冷阴的过渡细腻 |
| 人物处理 | 厚涂打底+赛璐珞切割阴影线——有体积感又有动画感；表情生动自然；动态感强 |
| 情绪倾向 nz+z | 守望+有冲力——人物在运动中带一点回头的感觉 |
| 十元粗位 | nz(捕捉瞬间)+zx(执行到位的中性美) |
| 归仓 | 时间 xn+z（「某一刻」被冻住了） |

## LAM式 / 装饰线系

### 07 LAM
| 维度 | 内容 |
|------|------|
| 色彩规则 xn | 高饱和+复杂图案的堆叠——衣服上/背景上的图案比主角还丰富；红/黑/金/白是主色 |
| 人物处理 | 厚涂+黑色装饰线（比动画线粗，非轮廓线）；角色的脸部饱和度低、身体和服装饱和度高 |
| 情绪倾向 xz+zx | 边缘+行动——角色带有街头/地下/战斗感 |
| 十元粗位 | xn(装饰规则)+xz(不主流/亚文化感) |
| 归仓 | 空间 x并z+n（表面和里面的分裂感） |

### 08 neco
| 维度 | 内容 |
|------|------|
| 色彩规则 xn | 纯黑/白/灰+单色点缀（红/蓝/紫）；像版画一样的强对比 |
| 人物处理 | 厚涂+硬边切割+机械结构设计；人物表情冷/无表情 |
| 情绪倾向 x | 吞噬——高对比像刀锋 |
| 十元粗位 | xn(对比)+x(吞噬) |
| 归仓 | 因果 zx+nx（设计精密，每一个黑块都是算过的） |
