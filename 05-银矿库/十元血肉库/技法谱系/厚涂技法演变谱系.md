# 厚涂技法演变谱系 · 油画史

## 0. 一句话定义

**「厚涂 = 不以稀释颜料为主、让颜料本身在画布上留下体积和痕迹的技法。」它不是一种画派，是所有「想让颜料本身说话」的画家的共同语言。**

## 1. 起源：威尼斯画派（1500s）

| 维度 | 内容 |
|------|------|
| 历史位置 | 油画技法刚成熟——达·芬奇用薄涂/sfumato（晕涂）、威尼斯派开始堆颜料 |
| 代表 | 提香（Titian）——晚年的笔触越来越粗放，颜料不再是「用来调色的」，是「用来堆的」 |
| 十元粗位 | **zx+nx**——执行（堆颜料）+计算（光影结构仍然精密） |
| 一句话 | 「提香晚年不用小笔画边缘了——他用手指和刮刀。颜料不是覆盖颜色的，是覆盖空间的。」 |

## 2. 巴洛克厚涂（1600s）

| 维度 | 内容 |
|------|------|
| 历史位置 | 卡拉瓦乔的阴影+鲁本斯的肉体=厚涂在这个时代变成「戏剧性的物质」 |
| 代表 | 鲁本斯（Rubens）——肉体的光泽、衣服的褶皱、头发的卷曲全部用厚涂推出来 |
| 代表2 | 伦勃朗（Rembrandt）——他的厚涂不是「堆颜色」，是 **「堆光」** 。鼻子的高光用厚厚的铅白直接戳上去 |
| 十元 | **鲁本斯：x+z（肉体的欲望+戏剧的冲动）/ 伦勃朗：nz+x（守望到某一束光时，把光用厚颜料钉在画布上）** |
| 一句话 | 「伦勃朗的厚涂是为光服务的——光从厚的颜料上反射到你眼睛里，比薄涂更亮。因为颜料本身就是光的载体。」 |

## 3. 浪漫主义厚涂（1800s初）

| 维度 | 内容 |
|------|------|
| 历史位置 | 浪漫主义的激情需要一个更「暴烈」的笔触——厚涂变成情绪的速度 |
| 代表 | 德拉克罗瓦（Delacroix）——颜料不是用来填形的，是用来扫的 |
| 十元 | **z（燃烧的冲动）** |
| 一句话 | 「看德拉克罗瓦的画不看局部——看整体时他堆上去的颜料像在动。」 |

## 4. 印象派厚涂（1870s-1880s）

| 维度 | 内容 |
|------|------|
| 历史位置 | **印象派是厚涂的「解放时刻」**——他们不调色（纯色并置），每一笔颜料从管子里挤出来直接上画布 |
| 代表 | 莫奈的《印象·日出》——纯橙红色没有调、直接涂上去 |
| 代表2 | 梵高——厚度不是技术是情绪。他把颜料管直接挤在画布上，然后用笔刷/手指/刮刀推 |
| 十元 | **莫奈：x（光流动的速度）/ 梵高：z（燃烧不经过滤的形态）** |
| 一句话 | 「印象派之前的厚涂是为了「物质感」——印象派之后的厚涂是为了「速度」和「温度」。」 |

## 5. 后印象派 + 分叉（1880s-1900s）

| 维度 | 内容 |
|------|------|
| 方向A | **塞尚的「结构厚涂」**——用平行的短笔刷层层推、一笔一笔像砌墙一样建结构。十元：zx+nx |
| 方向B | **梵高的「情绪厚涂」**——线条是螺纹/漩涡/火焰，厚度就是他的z |
| 方向C | **修拉的「点彩厚涂」**——每一个色点是一小坨颜料堆在画布上，远看是颜色、近看是颜料粒。十元：xn+nx |
| 一句话 | 「塞尚砌墙、梵高烧墙、修拉算墙——同一个厚涂工具，三种不同的人。」 |

## 6. 表现主义厚涂（1900s-1910s）

| 维度 | 内容 |
|------|------|
| 历史位置 | 表现主义继承了梵高的「情绪厚涂」方向和方向推——不只是情绪，是焦虑+恐惧+呐喊 |
| 代表 | 蒙克、席勒、凯尔希纳——颜料被笔刷刮上去、堆上去、像伤口 |
| 十元 | **z+x（燃烧+吞噬）** |
| 一句话 | 「表现主义不是画情绪，是把情绪刮在画布上。」 |

## 7. 抽象表现主义厚涂（1940s-1960s）

| 维度 | 内容 |
|------|------|
| 历史位置 | 厚涂的「终极形态」——不是画图像，是画动作。颜料不是涂的，是甩的/倒的/挤的 |
| 分支A | **波洛克（动作派）**——颜料从罐子里直接倒/甩到地上的画布，厚度不可控、不修正 |
| 分支B | **德·库宁**——颜料用刮刀/刷子刮上去，女性的身体被颜料刷碎 |
| 分支C | **罗斯科（色域派）**——看起来不厚，但他是用多层极薄的颜料堆叠出来的「看起来不厚但实际厚」 |
| 十元 | **波洛克：z（燃烧的轨迹）/ 德·库宁：x+z（欲望+冲动一起刮）/ 罗斯科：nz（多层的守望）** |
| 一句话 | 「抽象表现主义让厚涂第一次没有「图像」了——颜料本身就是存在。」 |

## 8. 当代厚涂插画（2000s-今）

| 维度 | 内容 |
|------|------|
| 方向A | **韩系游戏原画厚涂**（金亨泰、Pike）——数字模拟厚涂。图层不是颜料，但光影/体积/金属质感是模拟油画的「堆砌感」 |
| 方向B | **欧美概念艺术厚涂**（Craig Mullins、James Paick）——用大笔刷+堆叠的色块来建体积。是数字模拟「刮刀」 |
| 方向C | **日系插画厚涂**（米山舞的部分、ask的部分、LAM的部分）——二次元角色的厚涂不是「全厚涂」是「半厚涂」：体积用厚涂建但线稿/高光用赛璐珞语言 |
| 十元 | **韩系厚涂：x+nx（欲望+计算）/ 欧美概念系：zx+nx（目标+计算）/ 日系半厚涂：nz+zx（瞬间+执行）** |
| 一句话 | 「数字厚涂不牺牲颜料的物质感——它牺牲了「真的厚」，换来了「看起来厚」的控制力。」 |

## 9. 演化路线总图

```
威尼斯派(提香·zx+nx)
  ↓
巴洛克(鲁本斯·x+z | 伦勃朗·nz+x)
  ↓
浪漫主义(德拉克罗瓦·z)
  ↓
印象派(莫奈·x)
  ↓
后印象派分叉:
  ├── 结构厚涂(塞尚·zx+nx) → 立体派
  ├── 情绪厚涂(梵高·z) → 表现主义 → 抽象表现主义(波洛克·z)
  └── 点彩厚涂(修拉·xn+nx) → 新印象派
         ↓
当代数字厚涂分叉:
  ├── 韩系厚涂商业(x+nx)
  ├── 欧美概念厚涂(zx+nx)
  └── 日系半厚涂(nz+zx)
```

## 10. 封存句

「厚涂不是一种技法——是一个人站在画布前，决定不说「画得像」、要说「这里有东西」的证据。从提香的手指到金亨泰的数位笔，变的只有工具，不变的是「我要在这个地方留下颜料的痕迹」的冲动。」
