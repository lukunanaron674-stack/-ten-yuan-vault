# 日韩偶像题材母库增量 R37

## 《Re:Stage! Dream Days♪ / Re:ステージ！ドリームデイズ♪》
- 媒介：日本TV动画 / 多媒体企划
- 核心样本：式宫舞菜（Mana Shikimiya）
- 矿级：S
- 本轮新增机制：**梦想复燃 / 被放弃职业欲望再启动型**
- 核心判定：不是“第一次想成为偶像”，而是“曾经想成为偶像→主动压下梦想→进入新关系/新空间后，旧梦想重新取得行动权”。

---

## 1. 为什么进入核心偶像样本

舞菜具有优秀歌唱与舞蹈能力，也曾拥有偶像梦想，但因为过去经历放弃梦想，转学后试图过普通生活。她在新学校遇见濒临废部的谣舞社（实质为偶像活动社团），在伙伴与舞台实践中重新拾回原本压下的梦想，并以 Prism Stage 为明确竞技目标。

因此它符合“为了成为偶像持续行动”的硬条件：偶像欲望不是恋爱附庸，也不是娱乐圈背景，而是主角重新训练、组队、比赛、登台的长期行动目标。

---

## 2. 偶像身份如何建立

### 初始状态
- 舞菜：有偶像能力基础，但已经主动退出偶像路线。
- 社会身份：普通转学生。
- 内部状态：旧偶像欲望仍存在，但被压到“不做了”的区域。

### 身份入口
1. 进入新学校。
2. 偶然接触谣舞社。
3. 通过与纱由等人的唱跳互动，旧能力被重新调用。
4. 社团“必须存续”提供外部行动理由。
5. Prism Stage 提供清晰职业目标。
6. 多次训练/演出把“曾经的梦想”重新压成现实履历。

身份不是一次授予，而是：

**旧梦想残留 → 新环境触发 → 试做一次 → 能力记忆返回 → 关系拉住 → 重复实践 → 主动重新认领偶像身份。**

---

## 3. 行业/职业机制

### 训练
- 歌唱与舞蹈训练
- 团体配合
- 舞台排练
- 个人短板修正

### 出道/身份形成
- 学校偶像社团作为第一职业容器
- 不是公司正式“签约出道”，而是先通过团体、演出与竞赛把偶像身份做实

### 竞争
- Prism Stage：以顶级中学生偶像团体为目标的明确竞赛机制
- 强敌团体形成外部参照标准

### 舞台
- 校内Mini Live
- 正式团体舞台
- 竞赛舞台
- 舞台承担“旧梦想是否仍属于我”的验证功能

### 粉丝/观众
- 观众不是单纯奖励，而是让舞菜重新体验“自己站在公众面前也可以成立”的社会反馈

### 公司/组织
- 主要承载不是事务所，而是学校社团制度
- 社团濒临废部，为团队提供存续压力
- 组织危机与个人梦想复燃形成双重发动机

---

## 4. 主角欲望与代价

### 欲望
表层：帮助社团、参加 Prism Stage。

深层：重新确认“曾经被自己放弃的偶像梦想是否仍然属于现在的我”。

### 代价
- 必须重新进入自己曾经逃离的舞台情境
- 必须重新面对过去失败/退缩带来的本体压力
- 重新追梦意味着推翻自己此前“普通生活就好”的决定
- 一旦重新投入，过去用来保护自己的退路会逐渐消失

---

## 5. 十元分析

| 十元 | 体量 | 作用 |
|---|---:|---|
| **z** | **10** | 被放弃的旧梦想、旧经历持续留存并回流 |
| **zx** | **10** | 从“我不做了”重新转为主动追逐舞台 |
| **zn** | **9** | “现在的我还算不算那个想成为偶像的人” |
| **xn** | **9** | 训练、社团、Prism Stage等重复规则重新塑形 |
| **n** | **9** | 伙伴关系成为旧梦想复燃的承载器 |
| **x并z** | **9** | 普通学生→谣舞社成员→KiRaRe偶像成员 |
| **nz** | **9** | 纱由等人的吸引、支持与共同梦想提供关系火种 |
| **x** | **8** | 原本就存在的歌舞才能重新被调用 |
| **nx** | **8** | 社团存续、比赛标准、过去心理阴影形成反压 |
| **xz** | **6** | 命运压强存在，但不是系统/死亡式绝对强迫 |

主元：**z + zx**
次元：**zn + n/nz**
承载：**xn + x并z**

---

## 6. 顺序

### 主链

**z → zn封存 → nz触发 → x回流 → nx犹豫 → zx试做 → n加入 → xn重复实践 → z被重新解释 → 新zn → 新x并z**

翻译：

曾经有梦想
→ 因过去经历把梦想压下
→ 遇到新的伙伴/社团
→ 旧能力重新出现
→ 仍想逃回普通生活
→ 主动尝试一次
→ 进入共同体
→ 被训练和比赛反复验证
→ 过去不再只是“失败原因”，而变成“曾经真的想过”
→ 重新承认自己仍想成为偶像
→ 新偶像身份成立。

---

## 7. 五维

### 时间维 xn + z：10/10
本作最强维度之一。过去的梦想没有消失，只是被压住；新的训练时间不断重新解释旧历史。

### 本体维 zn + x：10/10
核心不是“能不能唱跳”，而是“那个曾经想站上舞台的我，还是不是现在的我”。

### 空间维 x并z + n：9/10
新学校、谣舞社、KiRaRe和竞赛空间为被放弃的职业身份提供了重新生长的位置。

### 因果维 zx + nx：10/10
过去与心理压力让她退出，伙伴与舞台又让她重新主动。全程都是“退出力”和“再进入力”的拉扯。

### 命运维 xz + nz：8/10
关键推动不是绝对命运，而是关系性遭遇：如果没有新伙伴，旧梦想可能继续沉睡。

---

## 8. 关系结构

### 舞菜 ↔ 纱由
- 纱由不是单纯队友，而是“让舞菜再次行动的人”。
- 关系功能：**nz唤醒zx**。

### 舞菜 ↔ 姐姐/强者模板
- 前代成功者形成z压力与比较。
- 既是“我曾经想成为的未来”，也是“我为什么退缩”的反面压力。

### 舞菜 ↔ 谣舞社
- 社团最开始需要她来存活。
- 但反过来，舞菜也需要社团让自己的旧梦想存活。

形成对子：

> **我救社团 ↔ 社团救回我的梦想**

---

## 9. 动态链

### 动态链A｜梦想封存—复燃链
**zx旧欲望 → z失败/退缩 → zn自我否定 → 普通生活x并z → nz新关系 → x旧能力回流 → zx再启动**

### 动态链B｜组织互救链
**社团nx濒危 → 舞菜zx加入 → n团体成立 → xn实践 → 社团存续 → 反过来为舞菜zn提供偶像归属**

### 动态链C｜过去重估链
**旧z = 我已经放弃 → 新zx持续行动 → xn新履历累积 → 旧z被改写为“曾经中断而非真正结束”**

---

## 10. 反咬点

### 反咬1：为了逃离旧梦想而选择普通生活，普通生活反而提供了旧梦想复燃的新入口
转学本来是退出机制，却让她遇到谣舞社。

公式：

**逃离A → 进入B → B产生新关系 → 新关系重新打开A**

### 反咬2：帮助濒危社团只是一个低风险理由，最后却逼她承认真正想帮助的是自己
初期可以说：“我是为了社团。”

长期实践后这个借口越来越站不住：

**为别人行动 → 自己越来越快乐/投入 → 必须承认自己仍然想当偶像。**

### 反咬3：放弃过一次的人，再次追梦反而比第一次更重
第一次梦想可以只是幻想；第二次追逐意味着角色已经知道失败、羞耻或退缩是什么，却仍再次选择。

因此：

> **二次zx的本体重量 > 初次zx。**

## 11. 视觉符号

- 转学生制服 / 普通生活状态
- 空荡、濒临废部的社团教室
- 入社申请书
- 第一次重新唱跳时身体记忆被唤醒
- 练习服 ↔ 舞台服
- 小型校内舞台 ↔ Prism Stage正式竞技舞台
- 停在门口不进入 ↔ 主动站上舞台中央
- 姐姐/强敌海报或舞台影像 ↔ 自己的舞台
- 零散成员 → KiRaRe完整站位

最适合做故事解释图的视觉对子：

**“把舞台门关上” → “别人重新推开门” → “自己主动走上台”**

---

## 12. 可复用母题

### ① 被放弃梦想复燃
角色不是没有梦想，而是已经把梦想判死刑。

### ② 新关系唤醒旧职业
**nz不是支持已有zx，而是直接把沉睡的zx重新生出来。**

### ③ 组织互救
个人救一个濒危组织；组织反过来给个人一个可以重新成为自己的空间。

### ④ 二次选择比第一次更重
第一次追梦来自无知；第二次追梦来自知道代价后仍然选择。

### ⑤ 过去失败重新定性
新行动不能删除旧z，但能把“失败结束”改写成“暂时中断”。

### ⑥ 退路反转成入口
为了退出旧人生而进入的新空间，反过来把旧欲望重新送回来。

- 放弃绘画的少女 → 转学加入濒危美术社 → 再次成为画师
- 退役运动员 → 为帮助校队临时训练 → 重新成为选手
- 不再写作的人 → 帮朋友经营杂志 → 重新成为作者
- 放弃骑士梦想的平民 → 临时救濒危骑士团 → 再次拿剑
- 退出直播的人 → 帮朋友救频道 → 再次被观众看见

通式：

> **旧zx → z创伤 → zn封存 → 新空间 → nz触发 → x记忆回流 → 二次zx → xn实践 → 新zn。**

## 14. 与现有偶像母型的区别

- 《Aikatsu!》：第一次被榜样点燃职业欲望。
- 《Dream High》：制度长期加工，产生职业认领。
- 《Love Live!》：为了外部危机自己创造职业入口。
- 《Kirarin Revolution》：私人关系先点火，职业后来变成自己的目标。
- 《SHINE POST》：已有偶像身份面临撤销，重新证明资格。
- 《Re:Stage! Dream Days♪》：**职业欲望已经死过一次，再被新关系和新组织重新唤活。**

所以本轮正式新增分类：

# 「梦想复燃 / 被放弃职业欲望再启动型」

---

## 15. 本轮矿核

> **有些成长故事不是“终于找到梦想”，而是“终于承认自己一直没有真正放下梦想”。**

十元凝结：

> **z保存被压下的旧欲望，nz提供重新启动的关系火种，x让身体/能力先于语言记起，zx第二次启动后，经xn持续实践，把“已经结束的我”重新写成“只是中断过的我”。**

这条可直接并入：
- 本体库：旧我复燃 / 被封存本体回流
- 时间库：旧z被新行动重估
- 关系库：nz生zx
- 动态链库：退出空间反转为再进入入口
