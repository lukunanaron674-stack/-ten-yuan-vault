# 日韩偶像题材_母库增量_R35

## 《IDOL: The Coup / 아이돌 : The Coup》
- 媒介：韩国电视剧（JTBC，2021）
- 矿级：S
- 核心分类：**退出资格悖论 / 失败身份终局证明型**
- 核心样本资格：是。不是普通娱乐圈恋爱，主轴是失败女团 Cotton Candy 在被公司宣布解散后，持续训练、争舞台、争排名，并把“最后一次成功”作为职业终局目标。

---

## 1. 偶像身份如何建立

Cotton Candy 已经出道多年，却长期被公众视作“失败偶像”。她们形式上拥有偶像身份，但社会承认与职业结果不足，导致 x并z 身份逐渐空壳化。

真正的第二次身份建立不是“再次出道”，而是：

**失败偶像标签 → 主动选择最后一战 → 用一次真实成功重新定义整个职业史。**

这意味着本作研究的不是“如何得到偶像身份”，而是：

> **一个被判定为失败的职业身份，能否在结束前重新夺回解释权。**

---

## 2. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 训练
- 已有职业基础，不是零起步训练。
- 训练功能从“学会成为偶像”转为“证明自己仍有资格作为偶像站上舞台”。

### 出道
- 过去已完成。
- 当前问题不是 debut，而是 **职业合法性的终局再证明**。

### 竞争
- 与市场淘汰、公司资源分配、同期成功团体和音乐节目排名竞争。
- 竞争结果直接决定“失败偶像”标签能否被重写。

### 舞台
- 舞台不只是曝光，而是最终判决空间。
- “音乐节目一位”被设为她们能够自己决定解散方式的关键阈值。

### 粉丝
- 粉丝既是过去失败的见证者，也是最后一次身份翻案所需的社会承认来源。
- nz 不只回血，而是参与 x并z 身份合法化。

### 公司
- 公司拥有解散、续约、资源分配、保留单个成员等权力。
- 公司逻辑是：失败项目应止损。
- 成员逻辑则变成：可以结束，但结束方式不能完全由公司替我定义。

---

## 3. 主角欲望与代价

### 欲望
表面目标：拿到一次音乐节目第一，再由自己宣布解散。

深层目标：

> **不是继续当多久偶像，而是证明“我们并不是只能以失败者身份被删除”。**

### 代价
- 必须重新投入已经消耗多年的职业劳动。
- 必须再次承受公众羞辱和失败可能。
- 必须把队友情感重新压回竞争和绩效体系。
- 成功本身会制造新问题：如果真的成功，还要不要解散？

---

## 4. 十元

| 十元 | 体量 | 作用 |
|---|---:|---|
| x并z | 10 | “偶像 / 失败偶像 / 即将解散团”多重公众身份 |
| zn | 10 | “我们究竟算不算真正的偶像” |
| nx | 10 | 公司解散、市场淘汰、公众轻视持续反压 |
| zx | 10 | 成员主动争取最后一次成功与解散方式 |
| xn | 9 | 合同、音乐节目、排名、资源规则 |
| n | 9 | 团体共同体决定谁能坚持到最后 |
| nz | 9 | 成员情感、粉丝支持、共同历史 |
| z | 9 | 六年失败史不断压回当前 |
| x | 8 | 已积累的唱跳、舞台、职业能力 |
| xz | 8 | 解散作为不可回避的终局临界 |

### 主元
**zn + x并z + nx + zx**

---

## 5. 顺序

**x并z → nx → zn → zx → xn → n → nz → z回流 → zx终局行动 → 新x并z**

解释：

已有偶像身份
→ 被公司和市场判定为失败
→ 本体受到否定
→ 主动决定“结束也要自己决定方式”
→ 重新进入排名、舞台、宣传规则
→ 团体重新凝聚
→ 粉丝与成员关系回填意义
→ 六年失败史不断反咬
→ 用最后一次成功夺回解释权
→ “失败偶像”被重写成“曾经成功并主动结束的偶像”。

---

## 6. 五维

### 时间：xn + z = 10/10
六年失败历史不是背景，而是每一次新行动的债务。过去越长，最后一次舞台越有重量。

### 本体：zn + x = 10/10
核心不是能力是否存在，而是：长期没有结果时，一个人还能不能继续认领“我是偶像”。

### 空间：x并z + n = 10/10
公司标签、团名、舞台、公众、成员共同决定偶像身份是否仍成立。

### 因果：zx + nx = 10/10
公司要删除她们，反而迫使她们第一次真正主动决定如何结束。

### 命运：xz + nz = 9/10
解散像终局命运，关系却让她们不愿被无意义地抹掉。

---

## 7. 关系结构

### 公司 ↔ 团体
**项目所有者 ↔ 身份真正承担者**

公司认为自己有权终止项目；成员则认为真正承担失败六年的人，应拥有结束方式的决定权。

### 队友 ↔ 队友
**共同失败者 → 最后一战共同体**

关系不是纯温暖，而是“你要不要再陪我赌一次”。

### 偶像 ↔ 粉丝
**失败标签见证者 ↔ 身份翻案见证者**

粉丝的意义从支持转成社会承认。

---

## 8. 动态链

### 链A｜删除威胁生出主动权
**x并z已有身份 → nx解散威胁 → zn危机 → zx主动夺回结束权**

规则：
> 当身份即将被外部删除时，主体可能第一次真正主动认领它。

### 链B｜失败史反向增值
**z长期失败 → x并z“糊团”标签 → zx最后成功 → z被重新解释 → 新x并z**

规则：
> 过去失败不能被抹掉，但一次终局成功可以改变过去失败的意义。

### 链C｜成功与退出发生冲突
**为了体面退出而追求成功 → 成功制造新粉丝/新机会 → nz与x并z重新增长 → 退出成本上升**

规则：
> 为了结束一个身份而完成的行动，可能恰好重新激活这个身份。

---

## 9. 反咬点

### 反咬1：为了退出，必须先证明自己配留下
最核心悖论：

**想结束偶像生涯 → 必须成功一次 → 成功又证明你可能值得继续。**

### 反咬2：公司说“失败所以删除”，成员却要“成功以后自己删除”
争夺的不是单纯职业存续，而是 **删除权 / 解释权**。

### 反咬3：失败越久，最后一次成功越有价值
六年失败本是负 z；一旦完成最后翻盘，这六年反而成为传奇叙事的重量来源。

---

## 10. 视觉符号

- 空荡或冷清的小舞台 ↔ 音乐节目正式舞台
- 过时团体海报 / 无人关注的宣传物
- 公司会议室里的解散通知
- 单独留下成员的合同提案
- 五人重新集合的练习室
- 排名板 / 一位候补数字
- 失败新闻标题 ↔ 最终舞台灯光
- 解散公告纸 ↔ 奖杯 / 舞台麦克风

最强视觉对子：

> **“解散通知” 与 “第一名奖杯”同时出现。**

前者代表外部删除，后者代表主体夺回删除资格。

---

## 11. 可复用母题

### ① 退出资格悖论
**必须先证明自己有资格继续，才有资格主动结束。**

可迁移：
- 退役运动员必须赢最后一场才能自己宣布退役
- 落魄剧团要卖满最后一场才能解散
- 失败画师必须办成一次个人展才肯封笔
- 被撤编的骑士团必须完成最后任务才能自行解散

### ② 结束权争夺
谁创造/雇佣了你，不等于谁拥有完整解释你人生的权力。

### ③ 最后一次成功重写全部失败
不是删除失败，而是改变失败在时间链中的意义。

### ④ 终局行动再激活身份
为了结束而行动，行动本身却重新生产关系、能力和公众承认。

### ⑤ 失败共同体
共同失败本身也能形成比成功更牢固的 n。

## 12. 与现有样本边界

- 《SHINE POST》：身份保级，目标是继续存在。
- 《Saving the Doomed Idols With My Touch》：外来者修复失败团。
- 《Wake Up, Girls!》：组织求生而制造团体。
- 《IDOL: The Coup》：**成员已经接受终局，但要求先用成功夺回“如何结束”的主动权。**

因此正式新增：

# 「退出资格悖论 / 失败身份终局证明型」

母链：

**长期失败 → 外部删除 → 主体拒绝被动结束 → 设定终局成功阈值 → 再投入职业劳动 → 成功重新激活身份 → 结束与继续重新发生冲突。**

## 一句话矿核

> **有些职业成长不是为了继续，而是为了获得“我可以自己决定什么时候结束”的资格；但最残酷的反咬在于，为了获得这个退出资格而完成的成功，恰好又会让这个身份重新值得继续。**
