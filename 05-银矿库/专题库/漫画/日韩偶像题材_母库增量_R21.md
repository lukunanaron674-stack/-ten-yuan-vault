# 日韩偶像题材｜母库增量 R21

## 1. 神クズ☆アイドル / Phantom of the Idol｜日漫｜S

### 基础核验
- 作者：いそふらぼん肘樹 / Hijiki Isoflavone。
- 官方/授权来源：一迅社、Kodansha US。
- Kodansha US 当前标记 Ongoing，已列 8 卷。
- 仁淀ユウヤ是男子偶像双人组 ZINGS 成员。官方简介明确：他跳舞敷衍、对观众态度差，经纪人准备把他踢出行业；后台遇到已经死亡、仍强烈渴望继续表演的女偶像最上アサヒ后，职业状态被重新启动。
- 一迅社第5卷官方简介继续确认 ZINGS 进入“ネクストくるアイドル大賞”并取得高位，仁淀随后获得电视剧出演等扩张工作。因此偶像职业不是背景，而是持续的演出、粉丝评价、经纪管理、奖项与跨媒体工作链。

### 新母型
**职业人格外包 / 表演主体分裂型。**

不是“灵魂进入偶像身体”那么简单。真正的结构是：
**同一个公众偶像身体，被两个完全相反的职业人格轮流使用。**

- 仁淀：想靠脸轻松赚钱，对唱跳、营业、粉丝服务缺乏职业诚意。
- アサヒ：已经死亡，却仍拥有极强舞台欲望和完整偶像人格。
- 公众只看见同一个“仁淀ユウヤ”，无法直接看见职业人格是谁。

因此问题从“我是不是偶像”升级成：
**公众承认的偶像，到底属于身体、名字、表演行为，还是实际完成表演的主体？**

### 十元
- 主符号：**x并z**。仁淀这个公众偶像身份由外观、舞台行为、粉丝观看共同成立。
- 次符号1：**zn**。真实仁淀与アサヒ形成两个职业自我。
- 次符号2：**nx**。仁淀不断把本应由自己承担的职业行动让给アサヒ。
- 次符号3：**zx**。アサヒ借同一身体主动完成舞台、营业与职业推进。
- 暗层：**xn**。经纪、演出、行业评价、奖项与工作机会持续规定“偶像该怎么做”。

### 体量
x并z10 / zn10 / nx9 / zx9 / xn8 / n8 / nz8 / x8 / z7 / xz5

### 顺序链
**zn → xn → nx → x → zx → x并z → n/nz → zn**

### 五维
- 时间：**xn+z**。持续演出、评价、工作推进，逼迫原本没有长期职业意志的仁淀产生新的时间方向。
- 本体：**zn+x**。两个职业人格共享一个现实身体，构成本体核心。
- 空间：**x并z+n**。舞台、粉丝、经纪体系决定“仁淀偶像”这一公众身份是否成立。
- 因果：**zx+nx**。仁淀逃避行动，アサヒ代行行动；被动让渡与主动表演彼此咬合。
- 命运：**xz+nz**。死亡把アサヒ从原职业人生中切断，但她通过与仁淀的关系重新连接舞台与粉丝。

### 生链
1. **nx → zx**：仁淀越不愿做，越给アサヒ留下行动空间。
2. **zx → x并z**：アサヒ的高质量表演强化“仁淀”这一公众偶像身份。
3. **x并z → n/nz**：公众身份提升带来粉丝、奖项与职业关系扩张。
4. **n/nz → zn**：越多人真心认可“仁淀”，真实仁淀越无法继续把成功完全当作与自己无关。

### 克链
1. **xn 克 zn**：行业不在乎仁淀内心有没有职业热情，只按舞台结果评价他。
2. **zx 克 nx**：アサヒ主动代行，让仁淀原本的职业逃避不断失效。
3. **x并z 克 zn**：公众越来越相信“仁淀是优秀偶像”，反过来压迫真实仁淀的自我定义。
4. **zn 反克 x并z**：一旦真实仁淀拒绝、停摆或无法继续让渡身体，公众身份就失去稳定表演来源。

### 反咬点
**最强反咬不是“被鬼附身”，而是职业成功的归属权。**

如果アサヒ替仁淀完成优秀表演，而粉丝、奖项、经纪机会全部记在“仁淀ユウヤ”名下，那么成功是谁的、粉丝爱的是谁，就会成为本体问题。职业身份由“我表演所以我是偶像”，变成：
**“公众认定这个名字是偶像，所以不管里面是谁，职业身份都先成立。”**

### 5组补子
- xn+z：行业制度与长期职业意志互补；制度先要求，意志后来才逐渐长出来。
- zn+x：真实职业人格必须通过共享身体行动；身体却无法告诉公众里面是谁。
- x并z+n：同一个偶像名号依赖舞台与粉丝网络承认。
- zx+nx：一人逃避、一人代行，是整个职业推进发动机。
- xz+nz：死亡切断アサヒ职业命运，而与仁淀的关系又临时接回舞台。

### 偶像职业机制
已出道团体 / 舞台演出 / 唱跳 / fan service / 粉丝评价 / 经纪淘汰 / 奖项排名 / 电视剧工作 / 双人团体关系均成立。偶像职业度 **10/10**。

### 欲望与代价
- 仁淀：想低成本赚钱和享受偶像红利。
- アサヒ：即使死亡也想继续站上舞台。
- 成功代价：公众成功记在仁淀名下，真实劳动主体与公众身份持有人分离。
- 失败代价：仁淀被行业淘汰；アサヒ再次失去舞台与粉丝连接。

### 与已有样本差异
- vs《The Holy Idol》：后者是陌生灵魂继承现成偶像身体；本作是**两个主体长期共享同一个偶像身体与职业名号**。
- vs《My Second Life as an Idol》：后者是旧经验进入新身体重新成功；本作是**成功劳动与公众署名分属两个主体**。
- vs《我推的孩子》：后者是“真实自我 vs 公众包装”；本作更极端，**完成公众包装的人甚至可能不是公众以为的那个人**。

### 视觉符号
后台镜面 / 同一身体两种营业状态 / 舞台聚光灯与后台死气 / 粉丝名牌 / 解雇通知 / 奖项排名 / 新工作邀约。

### 可复用母题
**职业人格可以被外包，但公众身份不会自动跟着外包。**

### 矿级
**S**。偶像职业链完整，而且补出母库目前没有的“劳动主体 ≠ 公众身份持有人”结构。

### 核验来源
- Kodansha US《Phantom of the Idol》系列页。
- 一迅社《神クズ☆アイドル》1卷官方页。
- 一迅社《神クズ☆アイドル》5卷官方页。

## 2. 31☆アイドリーム / Idol Dreams｜日漫｜A

### 基础核验
- 作者：種村有菜 / Arina Tanemura。
- 官方/授权来源：VIZ Media；版权归 Hakusensha。
- 主角出口千影31岁，通过实验药物把外表恢复为15岁，以“Akari”这一年轻形象追求错失的人生机会与偶像成功。
- VIZ 官方系列页直接定义为：31岁的Chikage恢复15岁外表，追求“success as an idol”。
- 第6卷官方简介确认，她已经以Akari身份写新歌歌词，并有制作人Hibiki，说明职业线至少进入音乐制作/制作人协作阶段。

### 新母型
**年龄门槛伪装 / 双年龄职业身份型。**

不是回到过去，也不是身体彻底换人，而是：
**现实时间仍是31岁，社会可见身体却被临时改写成15岁，因此偶像资格建立在“年龄外观伪装”上。**

### 十元
- 主：**x**。
- 次：**x并z + zn + zx**。
- 暗层：**xn**。

### 体量
x10 / x并z9 / zn9 / zx8 / z8 / xn7 / n6 / nx6 / nz6 / xz5

### 顺序链
**zn → z → x → zx → x并z → xn → zn**

### 五维
- 时间：xn+z。现实年龄继续增长，但旧执念重新进入职业时间。
- 本体：zn+x。31岁心理/人生经验与15岁可见身体错位。
- 空间：x并z+n。Akari只有在娱乐行业和观众观看中才成立。
- 因果：zx+nx。主动利用药物重选人生，同时被动维护伪装带来的职业条件。
- 命运：xz+nz。原本关闭的人生路径因偶然获得第二入口。

### 生链
z → x → zx → x并z → xn。

### 克链
- xn 克 zn：行业按可见年龄与公众定位识别她。
- x并z 克 zn：Akari越成立，31岁千影越难简单合并两种人生。
- x 克 xn：身体外观变化直接绕过原先关闭的年龄入口。
- zn 反克 x并z：真实年龄、关系史与成年人经验持续可能让Akari身份出现裂缝。

### 反咬点
**她不是重新变年轻，而是得到一张只能靠年轻外观使用的职业通行证。**

如果公众只认可年轻版本的我，那么成功究竟是在补偿31岁的我，还是再次否定31岁的我？

### 5组补子
- xn+z：行业年龄结构限制旧人生，错失执念推动重入职业时间。
- zn+x：成年人自我与少女外观共存。
- x并z+n：Akari靠观众与行业网络稳定。
- zx+nx：主动追梦伴随被动维护年龄伪装。
- xz+nz：偶然机会改变封闭路径，并与过去/现在关系纠缠。

### 偶像职业机制
偶像目标 / 公众艺名身份 / 音乐创作 / 制作人协作 / 行业身份包装成立；公开官方简介对长期训练、团体、排名证据较弱。偶像职业度 **7.5/10**。

### 欲望与代价
- 表层欲望：追回错失的青春、爱情和成功。
- 职业欲望：以年轻身份获得原本关闭的偶像机会。
- 成功代价：职业认同可能只落在15岁外表，而不是31岁真实自我。
- 失败代价：第二次机会被证明只是短暂伪装，旧的“我已经错过了”判断再次成立。

### 与已有样本差异
- vs《Who’s That Girl?》：后者通过社会识别身份变化绕过污名；本作是**年龄/身体外观改变，重开被时间关闭的职业入口**。
- vs《This Life's Universal Superstar》：后者修复技能资格；本作修复的是**社会认定的年龄资格**。
- vs《A Doomed Girl Group's Do-Over》：后者真正重新从新人层重考；本作没有回到过去，而是**31岁人生继续存在，只把可见身体退回15岁**。

### 可复用母题
**社会只允许某个年龄版本的我进入职业，于是我伪造一个被允许的自己。**

### 矿级
**A**。本体/身体/职业资格结构很新，但官方公开简介对训练、粉丝、团体、排名等职业全链支持弱于S级样本，因此不虚高。

### 核验来源
- VIZ《Idol Dreams》官方系列页。
- VIZ《Idol Dreams》Vol.1官方页。
- VIZ《Idol Dreams》Vol.6官方页。

## R21 去重结论
1. “换身体/身份”继续拆细：The Holy Idol＝陌生灵魂继承现成偶像身体；My Second Life as an Idol＝旧经验进入新身体；Who’s That Girl?＝社会识别身份重置绕过污名；Idol Dreams＝现实人生未回档，只伪装成更年轻身体取得职业资格；Phantom of the Idol＝同一偶像身体被两个职业人格共享，劳动主体与公众署名分离。
2. 新增母型：**职业人格外包 / 表演主体分裂型**；**年龄门槛伪装 / 双年龄职业身份型**。
3. 下一阶段继续优先合同、毕业、成员更替、成功后退出受阻，减少只有身体交换却没有职业全链的样本。
