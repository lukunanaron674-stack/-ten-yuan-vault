# 日韩偶像题材｜母库增量 R42

## 1. UniteUp!｜日本原创TV动画 / 多媒体偶像企划｜S

### 基础核验
- 主角清瀬明良是喜欢唱歌的普通高中生，原本并没有明确的“我要成为偶像”目标。
- 他的歌声以歌い手“KIKUNOYU”的名义出现在视频投稿网站上，sMiLea Production听到后主动发出招募。
- Sony Music Group官方访谈进一步说明：明良的歌声实际上是朋友擅自上传到网络，由此触发星探；他最初没有明确目标，只是顺势开始偶像活动，后来才在活动中找到“让大家露出笑容的偶像”这一目标。
- 与同样从网络歌手出身的直江万里、五十铃川千纮组成PROTOSTAR，从“歌い手”转入真正偶像职业。
- 第一季官方剧情明确包含：事务所组团、lesson、首次公开/披露Live、无观众网络直播、首次有观众Live、center选择与联合Live等。
- 第二季官方剧情确认PROTOSTAR已经CD出道、获得“新人男性偶像Festival”优胜，随后进入事务所内部Release Battle、地方PR活动、巡演/祭典、合宿与联合Live等更完整职业循环。

### 本轮新母型
**私人能力被替你公开 / 非自愿可见性职业化型。**

核心不是“网络歌手成为偶像”这么普通，而是：

> 主角本来只拥有私人能力x，并没有主动把它转换成公共职业身份；另一个人替他完成了“公开”这一步，于是行业先看见他，职业机会反而先于职业欲望出现。

与平台自发行型不同：
- Pri☆Chan：本人主动开频道，zx先于公众身份。
- UniteUp!：朋友代上传，**他人zx先把主角的x变成可被社会检索的x并z线索**，随后公司nx招募，主角自己的zx最后才生成。

因此新增一个非常重要的职业欲望次序：

**能力先存在 → 可见性被别人制造 → 职业机会到来 → 本人才开始决定是否认领职业。**

### 十元
- **x：10**。歌声/唱歌兴趣是最初真正属于明良自己的东西，在“偶像”出现之前就存在。
- **x并z：10**。KIKUNOYU网络人格、PROTOSTAR成员、公众偶像身份持续递进。
- **nx：9**。朋友代上传、事务所招募、组团安排、行业工作要求都先于主角明确职业欲望。
- **zx：10**。最初较弱，后期从“试试看”转为主动维护团队、舞台和“让大家笑”的职业目标。
- **xn：10**。事务所、lesson、披露Live、CD、Festival、Release Battle、地方活动、联合Live构成完整职业制度。
- **n：9**。PROTOSTAR三人并非天然组合，而是同为歌い手出身后被事务所组装，再通过持续共同实践形成团体。
- **nz：9**。原歌い手粉丝、现场观众、队友、前辈与地方观众持续把职业行为转成意义。
- **zn：9**。“我只是喜欢唱歌”逐渐变成“我是怎样的偶像”，属于本体后生成。
- **z：8**。网络歌手时期、普通高中生活、过去兴趣不断成为新职业的前史资产。
- **xz：6**。不存在死亡/穿越式强命运，但偶然暴露和被传奇偶像创办的事务所发现带有明显转轨节点。

### 体量
**x10 / x并z10 / zx10 / xn10 / nx9 / n9 / nz9 / zn9 / z8 / xz6**

主元：**x + x并z**  
发动元：**他人zx / nx → 本人zx**  
承载元：**xn + n**

### 顺序链
**x → 他人zx → x并z(网络可见) → nx(行业招募) → x并z(候选偶像) → xn → n → nz → zn → 本人zx → 新x并z**

拆解：
1. **x**：明良本来只是喜欢唱歌。
2. **他人zx**：朋友擅自把歌声上传网络。
3. **x并z①**：KIKUNOYU成为一个可被陌生人检索、观看的公共符号。
4. **nx**：事务所根据公共痕迹找上门。
5. **x并z②**：获得“被招募的歌い手 / 偶像候选人”身份。
6. **xn**：进入事务所、lesson、组团、舞台、发行等规则。
7. **n**：与万里、千纮形成PROTOSTAR。
8. **nz**：粉丝、队友、前辈和现场观众给予正反馈与责任。
9. **zn**：开始追问自己作为偶像真正想做什么。
10. **本人zx**：从“成り行きでやってみる”变成主动选择继续。
11. **新x并z**：PROTOSTAR偶像身份由外部授予转成自己认领并持续生产。

### 五维
#### 时间｜xn + z：10/10
网络歌手只是前史，真正偶像身份必须经过lesson、披露Live、首次有观众舞台、CD出道、Festival胜出、Release Battle与持续活动累积，职业时间非常完整。

#### 本体｜zn + x：10/10
作品最有价值的本体转化不是“不会唱→会唱”，而是：
**“唱歌是我喜欢做的事” → “唱歌开始代表我在社会上是谁”。**

#### 空间｜x并z + n：10/10
私人卡拉OK、网络账号、事务所、PROTOSTAR、Live舞台和粉丝共同把一个私人声音压成公众职业身份。

#### 因果｜zx + nx：10/10
本作的因果尤其值得入库：
**别人替我公开 → 公司来找我 → 我先被动进入 → 长期实践后主动选择。**
不是简单的“主动追梦”或“被迫出道”，而是主动权发生转手。

#### 命运｜xz + nz：8/10
偶然公开改变人生方向，而人与人之间的连接让这次偶然转轨不断被加固。

### 偶像身份如何建立
不是一次完成，而是四级递进：

1. **私人歌者**：喜欢唱，但没有职业意图。
2. **匿名/网名歌い手 KIKUNOYU**：能力第一次拥有公共可见性。
3. **事务所候选 / PROTOSTAR成员**：被行业组织正式命名。
4. **CD出道与舞台成绩后的职业偶像**：由持续工作、观众与本人认领共同坐实。

因此本作特别适合证明：

> **职业身份并不一定从职业欲望出生，也可以先从“可见性”出生。**

### 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制
- **训练**：事务所lesson、团体配合、合宿、Live演出准备。
- **出道**：歌い手三人先组PROTOSTAR，经历披露Live，后续完成CD出道。
- **竞争**：第二季进入事务所内部Release Battle；此前亦有新人偶像Festival并取得优胜。
- **舞台**：首次披露Live因台风取消后转为无观众网络直播；之后首次有观众Live、联合Live、地方PR活动、祭典舞台等。
- **粉丝**：歌い手时期已经存在网络粉丝，偶像化后要把旧线上支持迁移为现场/团体支持；第二季还进一步让地方观众与既有粉丝成为职业目标的一部分。
- **公司**：sMiLea负责发掘、组团、训练、活动设计和竞争机制；传奇偶像Anela由舞台主体转成培养者/制作方，形成前代→后代的职业传递。

偶像职业度：**10/10**。

### 主角欲望与代价
#### 初始欲望
不是“我要当偶像”，只是**我喜欢唱歌**。

#### 中段欲望
“既然被邀请，就试试看。”职业欲望仍是弱zx，更多由nx与环境推动。

#### 后段欲望
通过团队、舞台和观众形成明确方向：**想成为能让大家露出笑容的偶像。**

#### 代价
- 私人兴趣一旦职业化，就要接受评价、训练、团体责任与公开曝光。
- 原本“我想唱就唱”的x，被xn改造成“别人期待我在某时某地唱好”的职业责任。
- 网络人格与现实自我开始合并，主角越来越难把唱歌重新退回纯私人领域。

### 关系结构
#### 朋友 → 职业发动者
朋友最初的“擅自上传”改变了明良人生。这里出现一种罕见关系：
**最先替你做职业决定的人，不是公司、父母或导师，而是熟悉你能力的朋友。**

#### 同类陌生人 → 团队
三个歌い手分别拥有自己的网络人格，但被公司压进同一组合；n的作用是把三条私人创作线改造成一个共同职业单位。

#### 前代偶像 → 制度建造者
Anela不只作为榜样nz存在，而是把自己的职业经验转成事务所xn，直接创造后来者的职业入口。

#### 粉丝 → 身份连续性
歌い手时代的粉丝证明“偶像之前的你已经有人愿意听”；偶像粉丝则把这种支持进一步转换成团体和公共职业承认。

### 动态链
#### 链1｜私人能力公共化
**x私人能力 → 他人zx上传 → x并z网络符号 → nx行业发现 → 新职业入口**

#### 链2｜被发现转主动认领
**nx招募 → xn实践 → n共同劳动 → nz反馈 → zn职业理解 → zx主动继续**

#### 链3｜兴趣职业化反咬
**x自由兴趣 → x并z公众标签 → xn工作义务 → nz期待 → nx责任 → zn重定义**

#### 链4｜网络身份实体化
**网名KIKUNOYU → 线上观看 → 公司识别 → 真人组团 → 现场Live → CD/比赛成绩 → 社会职业实体**

### 生链
1. **x 生 x并z**：私人歌声一旦被公开，开始生成公共身份。
2. **他人zx 生 nx**：朋友的主动上传，制造了事务所对明良的外部推动。
3. **nx 经 xn 可转 zx**：招募本身不能产生职业欲望，但长期实践和关系回填可以让被动进入者主动认领。
4. **n/nz 生 zn**：队友和观众使“偶像”从公司标签进入自我定义。
5. **zn 反生 zx**：一旦明确“我要成为让大家笑的偶像”，行动不再只靠公司推动。

### 克链
1. **xn 克 x**：职业规则限制私人唱歌的自由性；兴趣被时间表、舞台标准和团体要求加工。
2. **nx 克 zn**：在本人还没想清楚之前，社会已经先叫他“偶像候选人”。
3. **x并z 克 zn**：公共KIKUNOYU/PROTOSTAR身份越强，普通高中生自我越难保持完全分离。
4. **zx 反克 nx**：后期本人主动制定职业目标后，外部安排不再是唯一发动机。

### 反咬点1｜别人替你公开，别人也可能替你启动人生
最初朋友只是把“好听的歌声”发出去。

但互联网的公共化具有不可逆的职业潜力：
**上传 → 被看见 → 被搜索 → 被公司判断 → 产生现实邀请。**

所以：

> **私人能力一旦进入公共检索空间，就可能在本人尚未形成职业欲望前，被别人先当成职业资本。**

### 反咬点2｜“被发现”越成功，私人兴趣越难保持私人
一开始唱歌只是自由的x。

职业成功以后：
- 要按时间训练；
- 要配合队友；
- 要面对观众；
- 要回应原有粉丝；
- 要参加发行、比赛和宣传。

于是：
**被发现本来扩大了唱歌空间，却也缩小了“不想职业化时就不职业化”的自由。**

### 反咬点3｜他人的判断可以比本人更早看见职业可能性，但不能替本人完成本体
朋友认为“这个声音值得公开”。
事务所认为“这个人值得做偶像”。

两者都可能判断正确。

但：

> **“别人觉得你能成为”只能创建入口，不能替你生成“我愿意成为”。**

因此最完整转换必须经过：

**他人判断 → 社会入口 → 本人实践 → 关系意义 → 本人认领。**

### 反咬点4｜匿名人格本来是缓冲层，成功后却变成职业履历
KIKUNOYU原本只是网络名字。

但这个名字留下的播放、粉丝和声音记忆，成为事务所判断和后续偶像身份的前履历。

于是：

> **匿名并不等于没有社会重量。一个网名只要积累了足够多的行动记录，也会成为真实职业历史的一部分。**

### 视觉符号
- 普通高中生 / 家中澡堂 / 放学后卡拉OK：私人生活与私人能力。
- 手机录音、投稿页面、KIKUNOYU网名、播放数字：x第一次转成公共x并z。
- 突然到来的事务所邮件：nx职业入口。
- 三个不同歌い手账号并列 → 三人站成PROTOSTAR：从私人网络人格到团队职业身份。
- 练习室镜墙 / 排练服：xn对身体和表达的加工。
- 因台风取消的空舞台 → 无观众网络直播：旧网络身份与新舞台职业的桥。
- 首次有观众Live：nz从屏幕另一侧进入现实空间。
- CD封面 / Festival奖项 / Release Battle：职业履历逐渐硬化。
- “KIKUNOYU”文字淡出，“PROTOSTAR”团名占据画面：公众身份迁移。

### 可复用母题
1. **别人替你公开的天赋**：角色从未打算职业化，朋友/家人/路人把作品公开后引来行业。
2. **可见性先于欲望**：先被社会看见，再慢慢决定自己要不要成为那种人。
3. **匿名履历实体化**：网名、匿名账号或假名积累的成果最终变成现实职业资本。
4. **被发现后的自由损失**：机会扩大行动空间，同时把私人兴趣变成职业责任。
5. **他人先看见你的未来**：别人能提前识别可能性，但最终认领权仍属于本人。
6. **网络到现实的身份压实**：线上“有人听”→现实“有人来”→行业“有人雇”→本人“我愿意继续”。

### 与已有样本差异
- **vs《THE IDOLM@STER CINDERELLA GIRLS》**：都是被外部发现，但灰姑娘女孩由Producer直接发现本人潜质；UniteUp!多了一层**朋友先把私人能力转成公共数据，行业再沿数据找到本人**。
- **vs《Kiratto Pri☆Chan》**：Pri☆Chan是本人主动自发行；UniteUp!的关键恰恰是**本人没有做第一次公共化决定**。
- **vs《Aikatsu!》**：Aikatsu!先产生职业欲望，再进入制度；UniteUp!先发生职业机会，欲望后生成。
- **vs《SideM》**：SideM已有成熟旧职业再转职；明良只有私人兴趣/网络歌手身份，属于兴趣被社会职业化。
- **vs《22/7》**：22/7是黑箱系统直接授予偶像资格；UniteUp!的外部选择具有可追溯证据：公开歌声就是被发现的原因。

### 5组补子
- **xn + z**：新职业制度把过去的网络歌手经历重新编码为正式履历。
- **zn + x**：最初“我只是喜欢唱歌”通过长期实践扩张为“我是偶像”。
- **x并z + n**：个人网名最终并入PROTOSTAR组合社会身份。
- **zx + nx**：别人先推动我进入，我后来主动决定继续。
- **xz + nz**：偶然上传改变路线，真实关系让偶然逐渐变成稳定命运。

### 矿级
**S。**

理由不是题材稀有，而是它补出一个目前母库很缺的职业生成顺序：

> **x私人能力 → 他人zx公共化 → x并z可见身份 → nx行业机会 → xn实践 → n/nz意义回填 → zn职业本体 → 本人zx。**

这证明职业欲望并不总是故事第一因。有时**“别人先让世界看见你”**才是第一因，而真正的成长发生在角色随后夺回自己人生的解释权：从“别人觉得我适合”走到“我自己决定我要继续”。
