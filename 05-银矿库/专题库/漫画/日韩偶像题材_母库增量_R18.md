# 満月をさがして / Full Moon wo Sagashite｜日漫→TV动画｜S
作者：种村有菜。原作连载于集英社《りぼん》，2002年改编TV动画，全52话。

## 官方/平台核验
- Apple TV 日本页：12岁神山满月热爱唱歌并梦想成为歌手，但身体虚弱，甚至无法大声歌唱；死神告知余命一年后，タクト把她变成16岁少女“フルムーン”，命运由此改变。
- U-NEXT：明确将本作描述为“余命1年的少女借死神力量变身为16岁，成为梦想中的偶像歌手”的成功成长故事；第1话写明她以16岁身体参加歌手选秀。

## 本轮新母型
**身体门槛绕行型 / 双重公众身份型：真实身体无法进入职业，先制造一个“可被行业接受的身体与身份”，再用这个替身完成真正的职业人生。**

核心不是普通“变身少女”，而是：

12岁病弱身体 + 喉病 + 年龄门槛 → 无法参加职业选秀 → 借死神力量获得16岁健康身体 → 以“Full Moon”之名进入行业 → 经纪、录音、工作、舞台持续把替身身份做实 → 替身职业人生反过来成为最真实的自我证明。

## 十元
- 主符号：**x并z**。神山满月 / 16岁Full Moon / 私人少女 / 公众歌手同时成立，身份叠层极强。
- 次符号1：**xz**。余命一年与死亡逼近，直接压缩职业时间。
- 次符号2：**zx**。明知身体和寿命都不允许，仍主动参加选秀、持续唱歌。
- 次符号3：**xn**。选秀、经纪、录音、首次工作、职业日程不断把梦想制度化。
- 暗层：**zn**。真正的“我”究竟是病弱12岁少女，还是舞台上被所有人承认的Full Moon？

## 体量
x并z10 / xz10 / zx10 / xn9 / zn9 / z9 / x8 / nx8 / nz7 / n7。

## 顺序链
**xz → zn → zx → nx → x并z → xn → n → nz → 新zn**

死亡期限xz → “我还能不能成为歌手”的本体危机zn → 主动坚持唱歌zx → 身体/年龄限制nx → 借变身建立职业可用身份x并z → 进入选秀、经纪、录音、工作xn → 接入行业与观众网络n → 歌与关系获得真实回应nz → Full Moon反过来成为自我成立的新证据zn。

## 五维
- 时间 xn+z：职业流程和余命倒计时完全捆绑，每一次工作都带着“还剩多久”。
- 本体 zn+x：真实自我与可工作的替身身体发生尖锐冲突；身体条件不等于欲望本体。
- 空间 x并z+n：只有16岁Full Moon这个社会可接受身份，才能进入经纪、录音、舞台、观众组成的职业空间。
- 因果 zx+nx：主角主动追梦，但年龄、疾病、身体和死亡期限持续强迫她换路径。
- 命运 xz+nz：死亡构成绝对终点；与重要之人的约定、歌曲被听见的愿望使职业行动获得命运方向。

## 偶像/歌手机制
- 训练/选秀：有明确选秀入口，职业成立并非凭空授予。
- 出道：通过16岁身份参加选秀后进入正式歌手活动。
- 公司/经纪：很早进入经纪人管理与工作安排。
- 录音/作品：录音棚、作词、歌曲制作是持续职业机制。
- 舞台/公众：Full Moon必须作为被观看、被听见的公众身份成立。
- 竞争：不是生存秀式排名主轴，核心竞争是“有限生命 vs 持续职业实践”。
- 粉丝/受众：观众的听见与承认，使Full Moon身份从魔法伪装变成社会事实。

## 欲望与代价
- 表层欲望：成为歌手，让自己的歌被重要之人听见。
- 深层欲望：在死亡之前证明“我的人生不是由病弱身体定义的”。
- 进入代价：必须隐藏真实年龄、真实身体和死亡状态，公众成功依赖一个无法永久维持的替身身份。
- 成功代价：Full Moon越真实、越被行业与观众承认，神山满月越难把它当作临时魔法外壳。
- 最终风险：如果替身消失，职业人生是否也会被一起撤销？

## 关系结构
1. 满月↔タクト：限制执行者/死亡使者，却同时成为职业入口提供者。
2. 满月↔经纪/行业：行业只接受“16岁Full Moon”，不接受真实12岁病弱身体。
3. 满月↔观众：观众并不知道全部真实，却对她的歌产生真实回应。
4. 满月↔过去约定：私人关系提供最初方向，但职业实践逐渐长出独立价值。

## 生链
1. xz生zx：死亡期限不是让她停止，而是逼她立刻行动。
2. zx生x并z：为了唱歌，主动接受双重身份。
3. x并z生xn：替身身份获得行业合法性后，职业流程才能启动。
4. xn生n：连续工作把个人拉入经纪、制作、受众网络。
5. n/nz反生zn：别人真的听见并承认Full Moon，使这个原本“假的身份”成为真实自我证据。

## 克链
1. nx克x：病弱身体、年龄门槛直接压制原本歌唱能力。
2. xz克xn：余命会切断长期职业路径，任何规划都可能来不及完成。
3. x并z克zn：公众越只认识Full Moon，真实满月越可能被遮蔽。
4. zn反克x并z：如果她不把歌手身份认作自己，再完美的16岁外壳也只是伪装。
5. zx反克xz：行动不能取消死亡，却能夺回“剩余时间如何被使用”的决定权。

## 最大反咬
**为了绕过身体限制制造了一个“假的职业身体”，结果这个假身体承载了最真的人生。**

起点：
真实身体 = 不能唱、不能参赛、不能被行业接纳。

中段：
魔法身体 = 可以选秀、录音、工作、登台。

反咬：
持续职业实践以后，社会关系、作品和观众记忆都附着在Full Moon身上。

于是：
**假的是身体条件，真的却是由它完成的行动与关系。**

这使本作成为非常强的本体题材样本：
**x并z替身 → xn实践 → n/nz承认 → 反写zn。**

## 视觉符号
- 12岁病弱身体 ↔ 16岁舞台身体
- 病房/药物 ↔ 麦克风/录音棚
- 倒计时 ↔ 演出日程表
- 真实姓名“神山满月” ↔ 艺名“Full Moon”
- 无法大声歌唱的房间 ↔ 被全场听见的舞台
- 死神 ↔ 经纪人，两种“安排你未来的人”形成奇异镜像

## 5组补子
- xn+z：职业流程与余命历史/倒计时互补，时间本身就是压力装置。
- zn+x：身体事实与自我愿望冲突，身体不能直接决定本体。
- x并z+n：替身身份必须进入行业和公众网络才会社会化。
- zx+nx：主动追梦与被身体、年龄、死亡限制同时存在。
- xz+nz：死亡终点与“想被某人听见”的关系愿望共同锁定命运方向。

## 可复用母题
1. **职业替身身体**：真实身体不满足职业门槛，只能借另一个身体/形态进入。
2. **假身份承载真人生**：社会身份是假的，但完成的作品、关系、责任全是真的。
3. **有限寿命职业化**：别人规划十年，她只能规划一年，因此每次行动价值被放大。
4. **身体不等于本体**：职业能力受身体限制，但职业欲望来自更深层zn。
5. **公众只认识替身**：越成功，越必须回答“如果真相曝光，我的职业成果还算不算我的？”

可迁移：
- 残疾少女→远程机甲竞技明星
- 老人→年轻虚拟主播形象
- 怪物→人类伪装歌手
- 无法露脸的人→虚拟偶像
- 被禁止登台的王女→假名演员

## 与已有样本差异
- vs《The Heavenly Idol》：后者是异质灵魂被塞进既有偶像身体；本作是主角为了职业主动获得第二身体。
- vs《ZOMBIE LAND SAGA》：后者是死后重建社会位置；本作是在死亡到来前，用替身身体抢救尚未实现的人生。
- vs《Crown of Love》：后者用偶像身份跨越人与人的社会距离；本作用第二身体跨越“身体资格与职业门槛”的距离。
