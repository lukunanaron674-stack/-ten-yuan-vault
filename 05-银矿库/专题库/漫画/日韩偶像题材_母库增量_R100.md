# 日韩偶像题材母库增量 R100

## 《Kizuna no Allele / キズナのアリル》

- 媒介：日本原创TV动画 / 虚拟艺人企划
- 年代：2023
- 矿级：S
- 核心归类：虚拟身份职业化 / 可编辑人格迭代型
- 核心对象：Miracle

## 1. 为什么收入核心样本

Miracle以传奇虚拟艺人Kizuna AI为憧憬，明确希望成为同样的Virtual Artist。她起初没有歌唱和舞蹈经验，进入ADEN Academy后从零训练，以Virtual Grid Award最高荣誉Lapin d'Or为目标。职业成长线持续覆盖：校内首次表演、指定曲改编、视频发布、直播、播放量与排名、Top 15晋级、团队成立、Unit Battle、强队挖角、竞争、合作、最终赛与评价标准争议。

这不是普通“虚拟世界校园青春”。职业身份的建立与“数字人格怎样被持续修改”直接咬合，适合作为虚拟偶像/VTuber职业库核心样本。

## 2. 偶像身份如何建立

起点并非现实演艺公司直接出道，而是：

普通学生 / 无歌舞经验
→ 进入ADEN Academy
→ 第一次虚拟舞台
→ 创建并持续发布自己的Virtual Artist内容
→ 参加Virtual Grid Award
→ 播放、排名、竞争让个人账号获得公共识别
→ 组建PathTLive
→ 从个人Virtual Artist升级为拥有团队历史与公众识别的职业身份。

因此本作的职业身份不是一次“被选中”，而是靠：

账号 + Avatar + 内容历史 + 观看数据 + 舞台 + Unit + 关系网络

逐渐压实。

## 3. 行业机制

### 训练
- ADEN Academy提供持续训练与首次校内表演。
- Miracle无歌舞经验，从试错开始。
- 直播谈话能力、歌词改写、舞台呈现都必须单独补。

### 出道 / 职业入口
- 先作为虚拟艺人学生公开行动，再通过Virtual Grid Award持续获得行业合法性。
- 职业入口更像“公开账号→持续发布→数据与赛事共同验证”，而不是传统事务所一次性出道。

### 竞争
- 第一轮指定歌曲，允许改词。
- 必须进入Top 15。
- 第二季进入ADEN Seed Finals与Unit Battle。
- 高排名成员组成强Unit，对现有团队产生挖角压力。

### 舞台 / 内容
- 校内表演
- 视频发布
- Live Streaming
- Collaboration Live
- Unit Battle
- Virtual Grid Award舞台

### 粉丝 / 数据
- 播放量上涨不等于排名自动上涨。
- 观看数据成为职业反馈，但不是唯一评价标准。
- 公众可见性、排名、同行评价并存。

### 公司 / 学院 / 平台
- ADEN同时承担学校、职业孵化器、赛事入口与评价制度。
- Headmaster与评审者甚至会对“应该按什么标准评价虚拟艺人”产生分歧，说明评价规则本身不是天然客观。

## 5. 顺序

**nz → zx → x并z → xn → x → nx → zx → n → z → zn → 新x并z**

解释：

憧憬Kizuna AI
→ 主动进入虚拟艺人道路
→ 创建初级公众身份
→ 学院/赛事开始评价
→ 能力显影
→ 排名与批评反压
→ 主动迭代内容
→ 团队关系进入职业结构
→ 数字历史持续累积
→ 从模仿榜样转成自我定义
→ 新Virtual Artist身份成立。

## 6. 五维

### 时间维 xn + z：10/10
职业历史以非常数字化的方式连续留下：视频、直播、播放量、排名、比赛、Unit变化都不会因为下一场开始而清零。

### 本体维 zn + x：10/10
重点从“我想像Kizuna AI”逐步转向“我到底要成为怎样的Virtual Artist”。能力成长和人格定义同步发生。

### 空间维 x并z + n：10/10
Avatar、账号、虚拟学院、Unit、观众共同构成职业空间。社会身份高度依赖数字空间，但关系与履历是真实累积的。

### 因果维 zx + nx：10/10
角色不断主动修改内容，但排名、评价、强队挖角、赛事规则又持续反推她们。

### 命运维 xz + nz：8/10
Kizuna AI作为“消失的传奇前代”提供方向与精神压力，但不是绝对命运系统。

## 7. 本轮新增母型：虚拟人格可编辑职业化

本作最值得留下的不是“虚拟偶像”三个字，而是：

> 数字职业人格并不是一次完成的头像，而是一个可以被不断修改、测试、比较、分流、组队和版本化的公开自我。

传统偶像常见：
现实身体 → 训练 → 舞台 → 公众身份。

本作更接近：
现实主体 → Avatar/账号 → 发布内容 → 数据反馈 → 修改人格表现 → 再发布 → 新版本公众身份。

因此职业成长第一次可以被理解为：

**人格版本迭代。**

## 8. 动态链

### 动态链A｜榜样复制 → 自我版本化
Kizuna AI的完成品形象
→ nz憧憬
→ zx模仿起步
→ 真实比赛暴露差距
→ x不足显影
→ 主动修改表达方式
→ z积累
→ zn从“像她”转向“这是我的Virtual Artist方式”。

### 动态链B｜数据反馈 → 内容迭代
发布视频
→ 播放量增加
→ 期待排名同步上涨
→ 排名未如预期
→ nx反馈打破直觉
→ 分析内容缺口
→ 改歌词/谈话/直播形式
→ 再发布。

### 动态链C｜个人身份 → 团队身份 → 团队反锁
个人Virtual Artist
→ n组建PathTLive
→ Unit公共身份形成
→ 比赛强制Unit Battle
→ 强队向成员挖角
→ “个人最佳机会”与“团队连续性”冲突
→ n不再只是加成，而成为职业选择成本。

## 9. 关键反咬

### 反咬1：数字人格越可编辑，越容易产生“哪一个版本才是我”的问题
虚拟身份的优势是：可以调外观、表达、内容、合作方式。

但越能调整：
- 越容易为了排名优化自己；
- 越容易把成功版本固定成公众期待；
- 越容易把“有效版本”误认为“真实版本”。

公式：
**x并z可编辑性↑ → zx优化空间↑ → nx数据压力↑ → zn真实性冲突↑**

### 反咬2：数据越清晰，越容易把“可测量”误当成“有价值”
播放量与排名提供明确反馈，但播放量上升并不保证排名同步上升；作品也明确出现评审标准之争。

因此：
> 平台能量化表现，不代表平台已经正确量化了职业价值。

### 反咬3：个人最优选择可能伤害团队连续性
被强队邀请，对个人来说可能是更高排名、更强资源。

但：
**个人x并z升级**
可能同时造成
**原n断裂 + 原Unit z历史中断**。

所以：
> 职业升级不是单变量上升。

### 反咬4：虚拟空间降低身体门槛，却提高持续内容门槛
虚拟形象让外形、现实空间等部分门槛下降，但竞争转移到：
- 持续发布
- 内容差异
- 谈话能力
- 自我运营
- 排名与数据

即：
**身体门槛↓ → 内容更新门槛↑**

## 10. 关系结构

### Miracle ↔ Kizuna AI
榜样 / 缺席前代关系。
功能：提供职业欲望，但后期必须脱离单纯复制。

### Miracle ↔ Chris / Noelle / Riz / Quan
同行、队友、批评者、竞争者不断转换。
功能：n不是固定“友情”，而是直接参与能力诊断与职业路线选择。

### PathTLive ↔ BRT5等Unit
团队身份之间竞争。
功能：让“我去哪一个Unit对我更好”与“我和谁一起成为谁”发生冲突。

### 学院 / 评审 ↔ 学生
培养者同时拥有评价权。
功能：xn既提供成长工具，也规定何种成长可以被看见。

## 11. 主角欲望与代价

### 欲望
从“成为像Kizuna AI一样的Virtual Artist”开始，逐渐发展成“找到自己的表达与伙伴，并走向Lapin d'Or”。

### 代价
- 持续公开失败；
- 接受播放量与排名的即时比较；
- 自我表达被不断量化；
- 团队与个人机会冲突；
- 成功版本逐渐形成公众期待，压缩试错自由。

## 12. 视觉符号

- 初始普通Avatar / 初始账号 ↔ 成熟舞台人格
- 空播放量/低排名 ↔ 数据不断上涨
- 视频编辑/直播界面 ↔ Virtual Grid Award正式舞台
- 单人头像 ↔ PathTLive Unit Logo
- 榜单Top15
- Kizuna AI旧影像 ↔ Miracle自己的Live
- 多个可切换的虚拟造型
- 单人直播窗口 → 多人协作窗口 → Unit Battle大舞台
- 强队邀请界面 / 原团队合照并置

## 13. 可复用母题

1. **可编辑人格职业化**：职业身份不是固定外观，而是持续版本更新。
2. **算法/排名人格塑形**：角色开始为了可量化反馈修改自己。
3. **数据清晰≠价值清晰**：越容易测量，越容易误把指标当本体。
4. **数字履历不可清零**：每次发布都形成可检索职业历史。
5. **虚拟空间降身体门槛、升内容门槛**。
6. **个人升级 vs Unit连续性**：更强平台/组合邀请可能破坏原共同体。
7. **榜样提供第一版，主体必须自己迭代第二版。**
8. **职业人格版本债务**：公众越熟悉某个版本，之后偏离成本越高。

## 14. 与已有样本边界

- 《Kiratto Pri☆Chan》：平台自发行，重点是“先发布再职业化”。
- 《Innocent Blue for Dearly Stars》：网络成熟者迁移到现实舞台，重点是媒介迁移。
- 《Himitsu no AiPri》：秘密职业人格代偿现实社交失能。
- 《TECHNOROID OVERMIND》：生存劳动后生成职业意义。
- 《Kizuna no Allele》：**数字职业人格本身作为可编辑、可量化、可组队、可版本化的对象持续成长。**

## 15. 本轮矿核

> 虚拟职业真正改变的，不只是“人不用真实身体站上舞台”，而是职业人格第一次变成一个可以持续编辑的公开对象。角色能根据播放量、排名、同行评价和团队关系不断修改自己的版本；可一旦某个版本成功，公众又会开始要求这个版本持续存在。于是成长不只是“我变强了”，而变成“我应该把自己改到什么程度，才不会在优化职业表现的过程中，把‘我是谁’也一起交给数据和平台定义”。
