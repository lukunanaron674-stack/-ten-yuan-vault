# 日韩偶像题材母库增量 R48

## THE IDOLM@STER MILLION LIVE! / アイドルマスター ミリオンライブ！

- 媒介：日本多媒体企划 / TV动画
- 核心研究对象：春日未来、最上静香、伊吹翼与 MILLIONSTARS 39人
- 矿级：S
- 新增母型：**职业空间共建 / 未完成共同体孵化型**
- 去重结论：当前专题库未检出本作独立深拆；与 Wake Up, Girls!、Love Live!、IDOLiSH7 有邻近结构，但核心机制不同。

---

## 1. 偶像身份如何建立

本作最重要的不是“39个少女加入事务所”本身，而是：

> **她们成为偶像时，承载这个身份的765 Pro Live Theater本身还没有完成。**

春日未来起初甚至不知道自己的明确梦想。她观看 765PRO ALLSTARS 的 Live 后，第一次真正看见“偶像”这种未来；第2话进入 audition，第3话成为 MILLIONSTARS 一员时，765 Pro Live Theater 仍处于施工状态。

因此身份成立顺序不是：

`成熟公司/成熟舞台 → 新人进入 → 新人职业化`

而是：

`职业欲望出现 → audition → 候选偶像身份 → 未完成剧场 → 成员共同活动 → 剧场完成 → 正式职业共同体成立`

也就是：

> **人和空间同时职业化。**

官方设定：
- 第1话：未来尚未找到“自己的梦想”，在观看偶像 Live 后开始改变。
- 第2话：进入 audition。
- 第3话：成为 MILLIONSTARS 成员时，765 Pro Live Theater 仍在建设中。
- 第4话：剧场还要两个月才开，未来提出在旁边空地先办 Live。
- 第5话：成员自己准备“原っぱライブ”，甚至亲手搭建舞台帐篷。

# 2. 十元体量

| 十元 | 体量 | 作用 |
|---|---:|---|
| x并z | 10 | MILLIONSTARS、765 Pro Live Theater、Team、团体身份逐层生成 |
| n | 10 | 39人不是背景人数，而是共同制作舞台与共同体 |
| xn | 10 | audition、lesson、团队分组、顺次出道、Live、剧场开幕 |
| zx | 10 | 未来不断在“还没有准备好”时先发起行动 |
| nz | 9 | 前辈、伙伴、观众给予职业意义与继续行动的理由 |
| x | 9 | 每人能力、个性在团队和舞台中显影 |
| zn | 9 | “我的梦想是什么”“我想成为怎样的偶像” |
| nx | 8 | 未完成设施、时间不足、人数过多、工作安排持续反压 |
| z | 8 | 前辈765PRO ALLSTARS的既有历史成为新人参照 |
| xz | 6 | 命运强迫较弱，以现实机会与偶遇为主 |

### 主元
**x并z + n + xn**

### 次元
**zx + zn**

# 3. 顺序

## 主链

**nz → zx → x并z → xn → n → nx → zx → x并z扩张 → zn → 新x并z**

解释：

1. **nz**：观看前辈舞台，被他人的闪耀点燃。
2. **zx**：主动参加 audition、决定向偶像方向行动。
3. **x并z**：先取得 MILLIONSTARS 候选/成员标签。
4. **xn**：进入 lesson、活动、分组、出道制度。
5. **n**：39人形成共同劳动网络。
6. **nx**：剧场没建好、时间不够、成员难以全员集合、资源有限。
7. **zx**：不等待“完美条件”，主动提出空地 Live、自建临时舞台。
8. **x并z扩张**：临时活动把“纸面组合”压成真实社会共同体。
9. **zn**：成员逐渐明确自己为何要站上舞台。
10. **新x并z**：正式剧场、正式Team、正式出道与 MILLIONSTARS 公共身份成立。

# 4. 五维

## 时间维 xn + z：10/10

职业不是一次 audition 完成，而是：

`看Live → audition → lesson → 空地Live → Team分组 → 顺次出道 → 剧场开幕 → 39人公演`

尤其“剧场从施工到完成”提供了一条非常直观的物理时间轴。

## 本体维 zn + x：9/10

未来的核心问题是：

> “我真正想做的事情是什么？”

她不是从明确职业欲望开始，而是在行动过程中把模糊欲望压成偶像本体。

## 空间维 x并z + n：10/10

这是本作最强维度。

**场地不是背景，而是身份生成器。**

空地、帐篷、施工中的剧场、正式剧场分别对应不同程度的社会实体化。

## 因果维 zx + nx：10/10

最典型的循环：

`条件不够 → 不等 → 先做一个小版本 → 小版本产生真实结果 → 结果推动正式版本成立`

## 命运维 xz + nz：8/10

前辈舞台与偶然相遇提供起点，但之后主要依靠关系与主动行动推进。

# 5. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

## 训练
- audition 后进入舞蹈 lesson。
- 39人能力、个性差异逐渐显影。
- 后期分 Team 进行职业化活动。
- 正式剧场公演前还要处理“39人难以全员到齐”的大型团队协调问题。

## 出道
- 不是39人同一时刻统一出道。
- Live Theater Project 通过 Team 分批、顺次 debut。
- “成为 MILLIONSTARS”与“实际完成职业出道”分成两个阶段。

## 竞争
- 本作不是淘汰赛中心。
- 核心压力更偏向：**时间、完成度、团队协调、前辈标准、舞台质量**。
- 因此它提供了偶像题材里很重要的非零和成长样本。

## 舞台
本作舞台有清楚的三级：

1. **前辈成熟舞台**：让新人看见未来。
2. **原っぱ临时舞台**：新人自己制造“现在就能站”的空间。
3. **765 Pro Live Theater**：职业共同体最终获得稳定据点。

## 粉丝
- 观众不是一开始就存在的巨大资源。
- 原っぱ Live 先通过小规模公开活动制造真实观众关系。
- 正式剧场再把临时注意力变成长期公共身份。

## 公司
765 Production 在这里不是全知全能的成熟机器。

Producer 也在学习如何带39人的新项目；剧场和项目本身都处在生成阶段。

所以：

> **培养者、项目、成员、场地一起成长。**

# 6. 主角欲望与代价

## 欲望
春日未来的特别之处是：

> 她不是“早就知道自己一定要成为偶像”，而是先被舞台点亮，再通过做事确认这就是自己的梦想。

## 代价
- 必须接受训练与专业标准。
- 个人行动进入39人大型共同体后，不再只对自己负责。
- “想做”会逐渐变成“要协调、要完成、要对成员和观众负责”。
- 越接近正式职业，个人自由越多地被共同时间表和团队目标绑定。

# 7. 关系结构

## 前辈 → 后辈
765PRO ALLSTARS 是可见的职业未来。

**前辈 x并z → 新人 nz → 新人 zx**

## 同期成员 ↔ 同期成员
39人并不是简单友情群像，而是：

**每个人的一小部分劳动，合起来才能制造一个完整舞台。**

因此：

**n = 共同生产关系**

而不只是情感关系。

## Producer ↔ MILLIONSTARS
不是单向“专业大人训练新人”。

更接近：

**成员提出可能性 → Producer 把可能性转成可执行结构 → 成员再共同完成。**

是 zx 与 xn 的双向翻译。

---

# 8. 动态链

## 链A：未完成条件催生行动

**nx条件不足 → zx不等待 → 先做临时版本 → n共同劳动 → nz真实反馈 → x并z提前实化**

核心例：剧场没开，先办原っぱLive。

## 链B：临时空间变职业胚胎

**空地 → 帐篷舞台 → 临时Live → 共同记忆z → 正式剧场意义增加**

即：

> **临时空间不是正式空间的劣化替代，而可以成为正式空间的精神原型。**

## 链C：空间反写共同体

**成员共同造舞台 → 舞台记录共同劳动 → 场地获得记忆 → 场地反过来维持团体身份**

得到：

**n → x并z → z → 反哺n**

---

# 9. 最大反咬点

## 反咬1：等待“准备完成”反而可能阻止职业真正开始

通常逻辑：

`设备齐全 → 开始表演`

本作反过来：

`先开始表演 → 才知道自己需要怎样的设备、团队和剧场`

因此：

> **职业空间有时不是行动的前提，而是行动的结果。**

## 反咬2：临时版本越成功，正式版本责任越大

原っぱLive成功并不会让正式剧场变得不重要。

反而会生成：

`临时成功 → 观众期待 → 团队自信 → 正式公演标准提高`

所以：

**zx先行成功 → nz增加 → nx责任同步增加。**

## 反咬3：共同体越大，个人越不能只靠个人热情

未来可以靠冲动发起原っぱLive。

但39人长期职业化之后：

**个人zx必须进入xn协调**。

因此成熟不是“永远保持冲劲”，而是：

> **把冲劲翻译成别人也能一起行动的结构。**

# 10. 视觉符号

- 前辈完整大型舞台 → 新人台下仰望
- 施工围挡 / 未完工765 Pro Live Theater
- 空地
- 自制帐篷舞台
- 手工准备、搬运、搭建
- 练习服 → Team服装 → 正式舞台服
- 少数成员 → 39人逐渐汇聚
- 空剧场 → 开幕剧场 → 全员舞台
- 临时帐篷在后期再次出现，成为共同记忆符号

最适合做一组三联视觉：

**施工中的剧场 → 空地帐篷Live → 正式剧场39人公演**

对应：

**未成立 → 先行动 → 社会实体化**

# 11. 可复用母题

## ① 职业空间共建
角色不是进入一个已经成熟的行业据点，而是一边成为职业者，一边参与建设这个职业据点。

迁移：
- 新演员 + 尚未开张的剧院
- 新骑士 + 尚未建成的骑士团驻地
- 新画师 + 初创工作室
- 新主播 + 刚建立的平台频道

## ② 临时版本先行

> **没有正式条件，也先做一个能工作的最小版本。**

这可以成为强 zx 正例。

## ③ 场地获得本体
长期共同劳动会让场地从“容器”变成共同体的一部分。

## ④ 行动生产条件

`缺条件 → 行动 → 行动吸引资源/关系 → 条件反而被行动生产出来`

## ⑤ 大共同体需要把个人zx翻译成xn
39人不能靠39份冲动长期运作，必须把个人愿望转成排期、Team、分工、练习与正式项目。

## ⑥ 未完成共同体
成员、公司、Producer、剧场、观众都处在“还没完全成为”的状态，却通过共同实践同步完成。

# 12. 与已有样本的边界

- **Wake Up, Girls!**：事务所濒死，为求生先制造偶像团。重点是“组织为了活命创造空身份”。
- **Love Live!**：学生为了救学校，自己创建 School Idol 团体。重点是“危机工具真实化”。
- **IDOLiSH7**：淘汰逻辑被团队互补反转。重点是“关系最优胜过单体最优”。
- **THE IDOLM@STER MILLION LIVE!**：**偶像项目与物理剧场同时未完成，成员用临时舞台和共同劳动把职业空间提前做出来，最终人与场地一起完成职业化。**

因此正式新增分类：

# 「职业空间共建 / 未完成共同体孵化型」

母链：

> **看见成熟职业 → 产生欲望 → 获得候选身份 → 发现正式空间尚未完成 → 不等待 → 自建临时空间 → 共同劳动产生真实舞台 → 舞台制造共同记忆与观众 → 正式空间完成 → 职业共同体实体化。**

---

# 13. 本轮矿核

> **有些职业并不是先有一个完整舞台，人才被允许上去；恰恰相反，是一群还不完整的人先在不完整的地方开始行动，临时舞台、共同劳动、观众回应和共同记忆不断堆积，最后才把“我们是偶像”以及“这里是我们的剧场”同时变成事实。**

这一型最重要的十元规则：

> **zx 可以在 x并z 尚未成熟时先行动；持续 zx 经 n 共同劳动与 nz 外部反馈，可以反向生产新的 x并z。**

即：

**zx → n → nz → x并z**

这是本轮相对现有偶像库真正新增的结构。
