# 1. 作品名与媒介

**《おちこぼれフルーツタルト / Dropout Idol Fruit Tart》**
- 原作：日本漫画
- 改编：2020年TV动画，全12话
- 核心单位：新人偶像团体 **Fruit Tart**
- 矿级：**S**

S的理由：偶像职业不是恋爱背景，而是剧情发动机。作品连续处理结团、写歌、CD出道、Live、物贩、粉丝反馈、销量KPI、节目收视、公司命令和大型企划；职业结果会直接决定宿舍、组合及成员的生存状态。

# 2. 偶像身份如何建立

桜衣乃是少数“正向偶像欲望”入口：她主动为了成为偶像上京。

但Fruit Tart整体不是纯新人团，而是：
- 衣乃：主动追梦的新入行者
- ロコ：卖不动的前童星
- はゆ：音乐人
- 仁菜：模特

也就是：

**不同旧职业身份 → 在原赛道失效/边缘化 → 被同一事务所重新编组 → 获得“新人偶像团”新公共身份。**

因此本作偶像身份不是从零制造，而是对旧职业残余进行再利用。

# 4. 顺序

**`z → nx → n → x并z → xn → x显影 → zx → nz → z重估 → zn → 新x并z`**

1. **z**：成员带着各自在艺能界的失败履历进入ネズミ荘。
2. **nx**：宿舍拆除危机与事务所经营压力逼迫重组。
3. **n**：不同旧职业者被拼成同一组合。
4. **x并z**：先得到“Fruit Tart新人偶像团”的公司身份。
5. **xn**：进入写歌、CD、Live、物贩、电视、销量等职业规则。
6. **x显影**：旧童星、音乐、模特等残余能力在新职业中重新估价。
7. **zx**：成员主动调整演出、宣传和工作方式。
8. **nz**：粉丝、观众、同学等真实回应开始回流。
9. **z重估**：旧失败不再只是“证明不行”，而成为新组合差异来源。
10. **zn**：成员逐渐从“被剩下的人”转成“我是Fruit Tart的一员”。
11. **新x并z**：组合从求生企划变成有独立公众认知的偶像单位。

# 6. 偶像职业机制

## 训练
不是纯练歌练舞，而是“把旧职业能力重新编进偶像任务”。成员能力来源异质，因此训练更像职业再编译。

## 出道
第2话直接通过企划进入CD出道路线；职业身份建立得很早，但社会承认远远没跟上。

## 舞台
第3话第一次Live甚至只是停车场，而且到场后还先做物贩列整理，明确展示新人偶像职业最底层的杂务与资源不足。

## 粉丝
第一次Live后没有新闻曝光，但衣乃收到粉丝信。这里粉丝的价值不是大数字，而是第一次证明“公共身份已经开始被具体的人记住”。

## 公司
公司并不是纯培养者。它既提供企划、出道和工作，也会下达极端KPI。第10话要求当日卖出1000张以上CD，把职业合法性直接压成销量结果。

## 销量
第9话完成首张单曲，却一次收到3000张实体CD库存；第10话立刻出现单日1000张销量任务。偶像职业不是抽象“人气”，而是库存和现金流。

## 节目/曝光
第11话甚至出现关键改编期收视率0%的危机。曝光本身不是奖励，它也可能成为可量化失败证据。

## 竞争
后期被拉入大型偶像企划，团队必须继续在更大的职业空间中证明自己。

# 7. 主角欲望与代价

## 欲望
衣乃最初是纯粹：**想成为偶像。**

其他成员则复杂得多：她们已经被旧娱乐职业磨损，被重新拼进偶像团以后，首先面对的不是梦想，而是“这个新职业能不能成为第二次机会”。

## 代价
- 必须接受“吊车尾”公开身份
- 做与理想舞台差距巨大的低资源工作
- 把私人生活与宿舍生存绑进职业成绩
- 承受公司销量/收视KPI
- 旧职业失败会被反复比较

真正代价是：
> **第二次职业机会并不会把第一次失败清零。它要求主体带着旧失败继续公开工作。**

**旧职业z → 单体失败标签 → n重新配置 → xn新职业规则 → 旧x功能改变 → 新x并z**

核心：

**宿舍危机nx → 结团zx → x并z空团名 → xn真实工作 → nz支持 → 团体社会实化**

**旧z失败 → zn“我不行” → 新配置产生有效结果 → 新z成功证据 → zn重写**

## D｜KPI反咬链
**公司给机会 → 产生职业身份 → 公司要求销量/收视 → nx上升 → zx必须优化表现 → 成功后又进入更高KPI**

**资源不足 → 无法复制标准大偶像模式 → 被迫使用成员已有异质能力 → 差异化风格形成 → x并z识别度提升**

# 10. 反咬点

## 1. 被判失败的人，换配置后可能不再失败
旧体系说：
**A不红 / B没位置 / C没上升空间。**

但这并不能推出：
**A+B+C组成新职业单位仍然失败。**

所以正式得到：
> **单体失败不能直接外推到新关系结构。**

## 2. 公司救你，也可以拿生存压力压你
事务所给她们第二次机会，同时会把库存、销量、收视、宿舍问题全部转化成工作KPI。

因此：
**培养者 = 机会提供者 + 压力传导者。**

## 3. 旧职业失败不是废数据
前童星、音乐人、模特的过去，不只是伤疤，也在新偶像职业里提供可再利用的能力。

公式：
**旧z失败史 + 旧x残余能力 + 新xn = 新职业资产。**

## 4. “吊车尾”可以从羞辱标签变成品牌
初期“おちこぼれ”意味着被行业筛剩。

但当组合真的持续行动以后：
**失败者共同体 → 坚持/怪异/亲近感 → 识别度 → 品牌故事。**

也就是：
> **负面x并z经过真实z历史，可以被重新占有。**

## 5. 生存目标会制造职业真实性
最初组团很功利：救宿舍。

但为了救宿舍，她们必须真的写歌、Live、卖CD、面对粉丝、承受收视率。

所以：
**工具性出发 → 真劳动 → 真关系 → 真履历 → 真身份。**

# 12. 5组补子

### 1. x + xn｜旧能力 ↔ 新职业规则
同一能力在旧职业里失败，换到偶像组合里可能重新有用。

### 3. zx + nx｜主动求生 ↔ 公司KPI

### 4. z + zn｜旧失败 ↔ 自我定义

### 5. nz + xz｜粉丝支持 ↔ 生存危机
外部危机越强，真实支持越能从情绪奖励升级成继续存在的条件。

# 13. 可复用母题

## ① 跨职业失败者拼团
一群在不同岗位失败的人，被重新编成另一种职业单位。

可迁移：
- 失败演员 + 乐手 + 模特 → 新剧团
- 落选骑士 + 斥候 + 医师 → 新冒险队
- 被裁程序员 + 美术 + 策划 → 独立游戏组

## ② 职业残余资产
旧职业没有成功，不代表旧训练没有价值。

> **失败的职业 ≠ 无效的人生。**

## ③ 配置失败而非个人失败
某个人长期表现差，有时是被放错位置、放错队伍、放错评价体系。

## ④ 生存任务生成职业真实性
为了救宿舍、还债、救组织而临时开始的职业，只要承担足够多真实劳动，也会长出真实身份。

## ⑤ 低资源强迫差异化
没有预算复制标准模板时，成员只能使用自己最异质的能力，反而更容易形成识别度。

## ⑥ 量化公众承认
CD库存、销量、收视率把“有没有人喜欢我们”从抽象感受压成具体数字，适合作为职业成长视觉刻度。

# 15. 本轮矿核

> **职业失败有时只是“这个人放在这个位置上不成立”，并不等于“这个人没有可用价值”。当一批来自不同失败路径的人被重新配置进新的关系和规则系统时，旧职业留下的碎片能力可以重新互补，原本被行业判成剩余的人，也可能共同制造出一个过去任何单人都无法成立的新职业身份。**
