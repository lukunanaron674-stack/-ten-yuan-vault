# 日韩偶像题材｜母库增量 R02

本轮只收两部已由官方漫画平台确认、且偶像职业机制真正进入主叙事的作品。

## 1. Second Try Idol｜韩漫 / Webtoon｜A+

### 官方核验
- 官方英文漫画：Tapas，MAY STUDIO / HaeRyang / Lee Ye Rin / Tinta。
- 状态：Completed，165 episodes。
- 官方简介确认：Hyunwoo 原本是即将出道的偶像团成员，拍摄事故造成严重伤疤后放弃明星梦想，后来成为偶像训练师；飞机事故后回到19岁练习生时期，重新参加音乐人才竞演，带着训练师时期积累的舞台经验再次争取出道。
- 官方前期章节标题直接出现 My Life As An Idol Trainee、Showtime、Front and Center、The Performance、Everyone's Watching Us、Dorm Life，说明训练、舞台、站位、公开观看、宿舍团体生活等职业机制持续参与剧情，不是“偶像”皮套。

### 偶像身份如何建立
它的关键不是简单“失败后回归”，而是职业位置发生了一个完整回环：
**准偶像 → 因伤被迫退出 → 偶像训练师 → 回到练习生 → 用幕后训练经验重新塑造前台偶像自己。**

主角不是只带着“未来记忆”回来，而是带着曾经站在后台训练别人的职业视角回来。

### 十元
- 主符号：xn（时间回归 + 练习生制度 + 再次走职业流程）
- 次符号1：zx（主动重新争取出道，并利用训练师经验调整团队与舞台）
- 次符号2：zn（曾经失败的自我与第二次偶像自我发生重写）
- 暗层：x并z（重新被舞台、节目、观众定义为“可出道偶像”）

### 五维
- 时间 xn+z：回到19岁，职业成长流程被重启，但旧经验保留。
- 本体 zn+x：曾经被伤疤和失败定义的“不能成为偶像的人”，重新建立能站上舞台的自我。
- 空间 x并z+n：练习室、竞演舞台、中心位、宿舍、观众视线构成新的偶像身份空间。
- 因果 zx+nx：主角主动用经验改变训练与表演，却仍受节目、选拔、团体位置与评价安排。
- 命运 xz+nz：第一次人生的事故像既定失败命运；第二次人生通过团队关系与共同成长把它软化。

### 体量
- xn：9/10
- zx：8/10
- zn：8/10
- x并z：7/10
- nz：6/10

### 顺序链
**xn → zn → zx → x并z → nz → zn**

时间回归重新打开职业入口 → 旧失败本体重新出现 → 主角主动用训练师经验介入 → 舞台/节目重新制造公众身份 → 团体关系逐渐稳定 → 新的“我是偶像”本体成立。

### 生链
**xn 重置职业时间 → zx 经验性行动 → x并z 新公众身份 → zn 新本体。**

### 克链
1. **旧 zn 克新 zn**：第一次人生的伤疤、退出与失败经验会不断告诉他“你本来不该再站上舞台”。
2. **zx 克 nx**：训练师经验让他不再只是被选拔规则筛选，而能主动调整舞台与团队。
3. **xn 克 xz**：回归本身让第一次人生近似命定的失败结局失效。

### 反咬点
**后台经验越强，第二次成为偶像就越不像第一次那个“只靠梦想冲”的自己。**

他成功的方式，是把自己也当成曾经训练过的“对象”进行修正。第二次成功因此会反问：现在这个更成熟、更会计算舞台与团队的人，还是不是原来那个想当偶像的自己？

### 条件变化
- 第一次：身体事故 → 退出偶像路径 → 转入幕后。
- 中间态：幕后训练师获得系统性职业经验。
- 第二次：时间回归 → 后台经验被带回前台 → 偶像职业从“梦想”变成“可被分析和经营的技术”。

### 5组补子
- xn + z：回归给了第二次时间，但真正让第二次职业线成立的是持续训练、复盘、积累。
- zn + x：旧失败者本体与19岁健康身体重新结合，允许“我还能不能当偶像”再次被回答。
- x并z + n：中心位、舞台、节目、宿舍与观众共同制造偶像身份。
- zx + nx：主角主动带队、调整表演，同时仍受选拔与公开评价约束。
- xz + nz：第一次事故像命运封口；第二次团体关系成为改变结局的缓冲结构。

### 偶像职业机制
- 练习：强
- 选秀 / 竞演：强
- 出道：核心目标
- 团体：强
- 舞台：强
- 粉丝 / 观众：中强
- 公司 / 训练体系：强
- 排名 / 中心位 / 评价：强
- 再出道：本质上是第二次职业尝试

### 欲望与代价
- 表层欲望：这一次一定要出道。
- 深层欲望：推翻“事故之后我已经没有资格成为偶像”的旧人生判决。
- 成功代价：必须把第一次失败和幕后训练师经验内化，第二次的自己因此不再纯粹。
- 失败代价：不仅是第二次没出道，而是证明第一次放弃似乎就是正确答案。

### 与已有样本差异
- 不同于《Second Life Millionaire》：重点不是单纯“回到年轻时重新组团”，而是**中间经历过偶像训练师职业，幕后知识再流回前台**。
- 不同于《My Second Life as an Idol》：没有换身体，本体冲突来自“同一个人被失败与幕后经验彻底改写”。
- 不同于《The Rogue Producer Survives as an Idol》：后者是外部操盘者被迫成为规则对象；本作是**曾经的规则对象成为训练者，再主动回到规则对象位置**。

### 可复用母题
**“被淘汰的人学会如何训练别人，再回来训练过去的自己。”**

可迁移：运动员→教练→回到少年选手；演员→表演老师→回到新人演员；作者→编辑→回到新人作者。

### 视觉符号
伤疤 / 镜子 / 练习室 / 中心位贴纸 / 舞台灯 / 评分表 / 训练师视角笔记 / 旧伤与19岁脸的对照。

### 矿级
**A+。**
职业机制密度高，并且“前台→后台→前台”的职业回环形成了现有库中独立的新母型。

## 2. The Holy Idol｜韩漫 / Webtoon｜A

### 官方核验
- 官方漫画：LINE WEBTOON / WEBTOON ORIGINAL。
- 改编：studioM；作画：AXA；原作：mythology jin。
- 状态：官方页面标记 Completed。
- 官方简介确认：大祭司 Rembrary 与魔王战斗时，醒来进入一名不红的韩国偶像身体，被迫面对“如何回去”以及“是否必须适应偶像生活”。官方分类包含 Body Takeover / Entertainment Industry。

### 偶像身份如何建立
这里不是“想成为偶像”，而是：
**完整而强固的神职本体 → 突然被塞入失败偶像身体 → 必须履行原身体的公众职业。**

因此偶像职业不是愿望入口，而是身体交换后必须承担的社会身份。

### 十元
- 主符号：zn（大祭司自我极强，且与偶像身体身份冲突）
- 次符号1：x并z（公众偶像身份、被观看的职业外壳）
- 次符号2：xn（娱乐工业与团体日程要求身体继续履职）
- 暗层：nx（主角最初处于被身体、公司、团体、公众身份安排的位置）

### 五维
- 本体 zn+x：灵魂/人格与身体社会身份错位。
- 空间 x并z+n：舞台、镜头、偶像团体与娱乐行业空间重新定义他是谁。
- 时间 xn+z：偶像日程与职业流程要求他持续扮演这个身份，不能只靠一次伪装混过去。
- 因果 zx+nx：他会主动寻找回去的方法，但现实中又被偶像工作牵着走。
- 命运 xz+nz：身体交换把两个世界与两种身份硬性绑在一起；团体关系成为逐渐软化这种错位的可能。

### 体量
- zn：10/10
- x并z：9/10
- xn：7/10
- nx：7/10
- zx：6/10

### 顺序链
**zn → x → x并z → xn → nx → zx → zn**

原本稳定的大祭司本体 → 被换入陌生身体 → 社会立刻把身体识别成偶像 → 职业规则开始运转 → 被迫履职 → 主角主动寻找适应/脱离方式 → 新旧身份互相改写。

### 生链
**身体交换 x → x并z 偶像社会身份 → xn 职业规则 → 新 zn。**

### 克链
1. **x并z 克 zn**：社会不承认“我是大祭司”，只认这张脸属于某个韩国偶像。
2. **zn 克 x并z**：大祭司人格又不断破坏原偶像应该呈现的行为模板。
3. **xn 克 zx**：即使主角想优先解决回归问题，工作、团体、娱乐工业日程仍会把行动拉回偶像职业。

### 反咬点
**他越成功适应偶像身份，就越难把这段人生解释成纯粹的“错误身体”。**

最危险的不是演砸，而是演得太好：一旦新的公众关系、团体关系、职业能力成立，原先“我只需要回到大祭司身份”会被新的生活反咬。

### 条件变化
- 初始：神职身份绝对稳定。
- 交换：身体身份先于人格被社会识别。
- 职业化：偶像规则强迫人格持续配合身体社会身份。
- 后期结构：偶像身份从外壳逐渐变成新的关系网络与本体证据。

### 5组补子
- xn + z：偶像日程、练习、持续曝光需要时间维持，不能只靠一次临场表演。
- zn + x：大祭司灵魂与偶像身体构成最直接的本体错位。
- x并z + n：公众偶像身份必须在团体、舞台、镜头、粉丝观看空间中成立。
- zx + nx：主角主动寻找适应和回归办法，同时不断被职业身份安排。
- xz + nz：身体交换构成命运锁；团体和人际关系可能让“必须回去”逐渐从绝对命令变成可重新选择的问题。

### 偶像职业机制
- 练习：有，但不是唯一发动机
- 选秀：非核心
- 出道：已处在失败/不红偶像位置
- 团体：强
- 舞台 / 表演：中强
- 粉丝 / 公众观看：强
- 公司 / 娱乐工业：强
- 排名：非核心
- 身份营业：极强

### 欲望与代价
- 表层欲望：找到回原世界/原身份的方法。
- 深层欲望：维持“我是大祭司，不是这个偶像”的本体确定性。
- 成功代价：越能履行偶像职业，越会生成这个世界的新关系和新身份证据。
- 失败代价：不仅拖垮原偶像团体，也会让他失去在新世界安全行动与寻找答案的社会位置。

### 与已有样本差异
- 不同于《My Second Life as an Idol》：后者是失败偶像进入另一具身体继续追求偶像成功，本作是**完全非娱乐行业人格被迫承担偶像身体的既有职业**。
- 不同于《The Rogue Producer Survives as an Idol》：后者懂娱乐工业并主动反操盘，本作恰恰因为完全不懂偶像逻辑而产生强烈本体/职业错位。
- 不同于《我推的孩子》：不是“真实自我被公众包装侵蚀”，而是**社会先认身体身份，迫使陌生灵魂补做这份职业**。

### 可复用母题
**“社会认识你的身体，比认识你的灵魂更快。”**

变体公式：
拥有极强旧身份的人 → 进入带有现成社会职业的陌生身体 → 外界不允许他从零定义自己 → 必须先履行这个身体已经签下的人生。

### 视觉符号
祭司礼服 ↔ 偶像舞台服 / 神圣手势 ↔ 营业手势 / 圣堂 ↔ 舞台 / 神谕目光 ↔ 摄像机镜头 / 原人格自称与偶像名牌。

### 矿级
**A。**
本体错位非常强，且官方明确将其置于偶像与娱乐工业生活中；但与高职业机制密度的选秀/练习生成长作相比，偶像制度本身不是唯一主发动机，因此不升 S。

## R02 新母型

### 母型3｜前台失败者 → 后台训练者 → 回到前台
代表：《Second Try Idol》。
核心：不是简单二周目，而是职业知识在前台/后台之间完成一次闭环。

### 母型4｜身体社会身份先于灵魂本体
代表：《The Holy Idol》。
核心：身体已经属于一个公众职业，陌生人格必须先履行这份“已经存在的人生”，才能争夺自己的定义权。

## R02 去重结论
- 《Second Try Idol》与现有回归偶像样本的差异成立，新增“前台→后台→前台”闭环，不重复《Second Life Millionaire》。
- 《The Holy Idol》与现有身体交换/公众身份样本的差异成立，新增“非行业人格继承现成公众职业”的结构，不重复《My Second Life as an Idol》或《Rogue Producer》。
