# 日韩偶像题材母库增量 R113

## 《イキヅライブ！ LOVELIVE! BLUEBIRD / IKIZULIVE! LOVELIVE! BLUEBIRD》

- 媒介：日本多媒体偶像企划 / X / YouTube短剧 / 音乐 / Live
- 矿级：S
- 本轮核心母型：**分布式校园共同体 / 无共同实体空间的职业生成型**
- 次级母型：**数字原生スクールアイドル / 共同空间后生成 / 公众参与组织共建**

## 1. 为什么进入核心样本

本作最重要的不是“又有一批学生做School Idol”。

Love学院高等学校（L高）本身就是全国拥有多个Satellite校的Internet High School。官方开场直接强调：没有传统制服、教室、操场、食堂、保健室；学生拥有的是自由安排的课程、分散的生活地点和在线学习环境。高桥Polka因高中入学考试失败进入L高，在这里接触到过去曾存在的School Idol文化。随后来自日本各地Satellite校的10名学生，为了让L高更有活力，开始School Idol活动。

因此它把Love Live系列最基础的一条默认前提拆掉了：

> **School Idol一定要先有一个所有成员每天共同生活的“学校空间”吗？**

这里反而是：

**先有分散学生 → 通过网络、Satellite校、音乐与活动建立关系 → 共同身份成立 → “L高”这个原本稀薄的学校共同体才开始被她们的活动变得可感知。**

所以不是“学校孕育偶像”，而是：

> **偶像活动反过来帮助一个缺乏传统实体校园感的学校生成共同体。**

## 2. 偶像身份如何建立

Polka并不是已经成熟的练习生。她最初只是一个因数学极差、高中升学失败而进入Internet High School的15岁少女，并在L高“发现”School Idol这一旧文化。

职业身份生成链：

**升学失败 / 进入Internet High School → 发现过去的School Idol概念 → zx主动重新利用这一旧职业形式 → 跨Satellite校寻找/汇聚成员 → 形成“いきづらい部！” → X / YouTube /歌曲 / Live持续公开 → 公众与L高生参与 → “School Idol”从过去式重新变成现在进行时。**

所以本作有两次x并z生成：

1. **成员个人：普通L高学生 → School Idol成员。**
2. **组织层：分散Internet High School → 拥有可共同识别的校园文化共同体。**

这比普通“学生加入偶像社”多出一层：

> **成员不仅获得职业身份，还在生产承载这个身份的学校社会空间。**

## 3. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 训练与实践
- 10名成员并非来自一个传统校园，而来自不同Satellite校与不同生活背景。
- 个人原始目标高度分散：有人偏程序与数据、有人想当职业运动员、有人想做和服事业、有人想成为糕点师、有人原本想做声优。
- 因此偶像活动不是把“本来都想当偶像的人”集合起来，而是把多个已有个人目标的人拉入一个新的共同职业实践。
- 训练重点天然包含跨地点协调、内容生产、团体合作与公开表达。

### 出道 / 公共身份
- 企划从2025年5月正式启动，主要通过角色X账号、YouTube短剧、自我介绍视频、歌曲等推进角色社会存在。
- 2025年7月30日发行1st Single《What is my LIFE?》。
- 随后10名成员连续发行Solo Single，并开展Free Live、特典会等现实活动。
- 到2026年7月，官方音乐媒体总结其启动一年内已公开29首包含Group / Solo / Unit的歌曲。

### 舞台
- 2025年开始有Release Event / Free Live。
- 2026年2月14–15日在幕张Event Hall完成首次One-Man Live《What is my L ?》。
- 2026年9月已确定举办2nd Live。
- 因此职业链已从网络人格与内容发布，发展到实体大型现场。

### 粉丝 / 公众机制
本作特别重要的一点是，公众不只是“观看完成品”。官方已多次让用户直接参与：
- 成员Color名称募集与最终投票。
- Unit组合/Unit名称等用户参与企划。
- Live后继续启动新的Unit分组投票。

所以公众不仅产生nz，还进入部分xn组织过程：

**用户意见 / 投票 → Unit或品牌符号变化 → 后续商品、活动与组合结构被写入。**

这使粉丝从“消费者”进一步变成**共同体规则与符号的参与建造者**。

### 组织机制
- 没有传统固定校园作为日常共同空间。
- L高通过全国Satellite校＋在线学习维持学校制度。
- 角色活动又主要通过X与YouTube持续公开。
- 因此本作的职业组织不是“所有人每天坐在同一间部室”，而是**数字网络＋周期性实体汇流**。

## 4. 主角欲望与代价

Polka的起点首先是“升学失败后进入一个和传统学校完全不同的环境”。School Idol因此不是她从小学就已经规划好的单一路线，而是进入新环境后发现的一种可能性。

核心欲望可以概括为：

> **既然传统校园里该有的东西这里都没有，那就自己制造一个能让大家连接起来的东西。**

代价是：

1. 共同体缺乏每天自然相遇的物理基础，关系必须靠主动维持。
2. 成员原本各有独立梦想，偶像活动不能无限吞掉个人目标。
3. 网络可见性让职业进入更快，但也要求持续发布、持续回应、持续在线。
4. 公众参与越深，团体越像“大家共同拥有的项目”，主体单方面控制身份的自由会下降。
5. Digital-first共同体如果缺少周期性实体汇流，n可能停留在弱连接层。

## 6. 顺序 / 动态链

**升学失败z → 进入新x并z（Internet High School）→ 发现旧School Idol文化 → zx主动重启 → 跨地域n连接 → x并z“いきづらい部！”成立 → xn数字内容/音乐/Live持续实践 → nz公众与L高生参与 → 共同体符号和Unit反向被公众共建 → z职业历史增厚 → zn重新认领 → 更大的实体Live汇流 → 新x并z学校共同体增强**

压缩公式：

> **x并z稀薄 → zx主动连接 → n分布式生成 → xn数字实践 → nz共同参与 → 新x并z共同体实体化**

这是本轮最值得进入十元总库的动态链。

## 7. 五维

### 空间维 x并z+n：10/10
绝对主维。

本作直接把“没有统一实体校园”的问题摆在School Idol之前。

传统校园天然提供：
- 每日共处
- 教室
- 部室
- 操场
- 校园文化
- 偶遇与弱关系

L高没有这些标准配置，所以必须用：

**Satellite校 + 网络平台 + 共同内容 + 周期性实体Live**

重新制造共同空间。

因此得到：

> **社会共同体不一定先有稳定物理空间，再产生关系；关系与共同实践也可以反过来制造“我们所在的空间”。**

### 因果维 zx+nx：10/10
“没有什么”不是终点，而是zx发动机：

**缺学校感 / 缺传统设施 → 自己造活动 → 连接更多成员 → 公众加入 → 新结构出现。**

但成功以后也会出现反压：

**公众参与↑ / 发布频率↑ / 大型活动↑ → nx责任↑。**

### 时间维 xn+z：10/10
School Idol在设定中本来是“过去曾经存在”的文化。

Polka等人不是复制一个正在正常运转的制度，而是在新的Internet High School环境里重新激活旧职业形式。

因此：

**旧z文化 → 新xn环境 → zx重新解释 → 新z继续写。**

### 本体维 zn+x：9/10
成员很多并不是以偶像作为唯一人生目标。

所以成长不是把其他欲望全部删除，而是：

> **“我的原梦想”与“我现在作为School Idol获得的能力和关系”如何并存？**

这非常适合“复合本体”支线。

### 命运维 xz+nz：8/10
升学失败等断点改变人生路径，但真正把它转成新职业的不是宿命，而是关系与持续行动。

## 8. 最大反咬点

### 反咬①：没有固定空间，所以每一次“在一起”都必须主动生产

传统学校：

**同一学校 → 每天自然见面 → n低成本维持。**

L高：

**成员分散 → 没有自然共处 → 不主动连接就不会自动产生共同体。**

因此：

> **空间基础越弱，n越依赖zx。**

但反过来，一旦成员反复主动连接：

**网络交流 / 内容共作 / Unit / Live → z累积 → n变厚。**

所以：

> **主动连接可以把弱空间补成强共同体。**

### 反咬②：网络降低组团门槛，同时提高“持续存在”门槛

Digital-first环境让跨地域组团更容易：

**不用每天在同一校舍 → 仍能公开、传播、组织。**

但代价是：

**不更新 / 不回应 / 不上线 → 社会存在快速变薄。**

所以：

> **实体距离门槛下降，持续可见性门槛上升。**

这可直接迁移到VTuber、远程乐队、网络画师社群、远程游戏团队。

### 反咬③：粉丝共建越成功，团体越不完全只属于成员

用户可以参与颜色命名、Unit相关投票等。

早期：

**公众参与 → nz增强 → 共同体更有生命。**

长期：

**公众参与越多 → 公众对结果拥有更强心理产权 → 成员/运营自由度下降。**

所以：

> **nz参与可以生成xn，但生成后的xn也会反过来约束主体。**

这是本轮非常值得补进十元总库的一条。

### 反咬④：旧职业文化复活以后，必须学会适应新社会结构

“School Idol”是过去曾经存在的形式。

如果只是照搬：

**旧学校 / 旧部室 / 旧校园赛事逻辑**

到Internet High School，会直接失配。

真正的继承是：

**保留“学生自己做偶像”的核心 → 改变组织和传播方式 → 生成数字时代版本。**

所以：

> **传统要复活，必须允许载体变形。**

## 9. 关系结构

本轮n不是一个标准的“九人同校团”。

更接近：

**多个Satellite小节点 → 通过数字网络连接 → 形成全体10人网络 → 周期性Unit分组 → 实体Live重新汇流。**

可以正式收一个新的关系拓扑：

### **分布式n**

特点：
1. 成员不需要长期物理共处。
2. 关系通过内容生产和周期性汇流维持。
3. 局部Unit可以不断重组。
4. 粉丝/L高生本身也作为外围节点进入网络。

这与“固定团体所有人每天在同一空间”的n完全不同。

## 10. 视觉符号

- 空荡的网络高校界面 / 没有传统校舍生活的学生。
- 日本地图上多个Satellite校节点。
- 10个角色头像分散在不同城市 → 线路逐渐连接。
- X时间线 / YouTube短剧 / 线上会议窗口。
- 每个人在不同地方发布内容。
- Unit小组从大网络中临时聚合。
- 全国不同Release Event地点。
- 最终所有分散节点汇聚到幕张大型舞台。

最强视觉链：

> **地图上十个分散光点 → 网络线连接 → 形成“いきづらい部！”Logo → 线下Live时十个真人位置第一次进入同一实体舞台 → 观众席再作为第十一层网络节点亮起。**

## 11. 可复用母题

1. **无实体校园的校园偶像**：职业定义与传统承载空间脱钩。
2. **分布式共同体**：成员跨地域，通过数字工具建立稳定n。
3. **关系反向制造空间**：先有共同实践，再产生“我们所在的地方”。
4. **Digital-first职业生成**：先在线存在，再周期性实体化。
5. **传统载体变形**：旧职业文化在新社会基础设施中重新实现。
6. **升学失败→新职业入口**：旧路径失败不是终止，而是把主体推入新x并z。
7. **多梦想成员组团**：成员不必先把偶像当唯一人生目标。
8. **持续可见性门槛**：远程组团容易，持续存在更难。
9. **公众参与生成制度**：nz参与投票/命名后可转成xn结构。
10. **数字弱连接→实体强关系**：线上互动通过共同历史和Live逐渐变厚。
11. **周期性实体汇流**：远程共同体需要稳定线下节点同步n。
12. **学校共同体由活动反向生成**：偶像活动不只是代表学校，也在制造学校感。

## 12. 与现有矿边界

### vs R48《THE IDOLM@STER MILLION LIVE!》
R48：正式剧场还没建好，成员用临时舞台把职业空间提前做出来。

R113：不是“建筑尚未完成”，而是**学校本来就以分布式Internet High School存在，不需要一个统一实体校舍作为共同体前提。**

### vs R60《Idol Time PriPara》
R60：某个地区缺乏女偶像职业生态，需要从零把新人、观众、商店、比赛养出来。

R113：行业并非不存在，重点是**成员和校园本身没有统一空间，要重建跨地域共同体。**

### vs R68《虹咲学园School Idol同好会》
R68：多个完整个人偶像在同一学校里并列，不必熔成同一种团体人格。

R113：进一步把**同一学校、同一物理校园**也拆掉，研究多个地理节点怎样连接成一个职业共同体。

### vs R83《Idol Angel Yokoso Yoko》
R83：主体主动搬去机会密集城市，让职业事件发生概率提高。

R113：反方向，**成员不必集中搬到同一职业中心，而是通过数字网络让职业共同体跨地域成立。**

## 13. 本轮新增十元规则

### 规则A：空间基础越弱，关系越依赖主动生产

> **x并z实体共处↓ → zx连接需求↑ → n必须由持续行动生成。**

### 规则B：关系可以反向制造社会空间

> **n + xn共同实践 + z历史 → 新x并z共同体。**

不是所有社会空间都先于关系存在。

### 规则C：公众参与可由nz升级为xn

> **nz支持 → 投票/命名/分组参与 → xn共同规则生成。**

### 规则D：数字化不删除门槛，只重分配门槛

> **距离门槛↓ → 持续内容/协调/可见性门槛↑。**

### 规则E：旧职业传统若要复活，必须允许载体改变

> **旧z核心价值 + 新xn基础设施 → 新x并z职业形式。**

## 14. 矿级判断

**S矿。**

理由不是因为它挂着Love Live品牌，而是机制确实新增：

1. 角色是从普通Internet High School学生开始生成School Idol身份。
2. 成员不依赖统一校园作为共同体前提。
3. 数字内容、Satellite校、Unit与实体Live共同构成职业基础设施。
4. 粉丝已被正式纳入颜色命名、Unit等共同建构环节。
5. 作品从2025年启动到2026年已完成Single、29首曲目积累、Release Event、First One-Man Live并继续向Second Live扩张，职业履历足够实。

## 15. 本轮矿核

> **过去的School Idol默认先有学校、部室和每天见面的同学，再在这个空间里长出偶像；《イキヅライブ！》反过来证明，一个共同体也可以先没有统一教室、操场甚至固定物理中心。只要分散的人持续主动连接、共同生产内容、接受公众回应并周期性汇入真实舞台，n与z就会反过来把一个稀薄的社会空间压实。此时偶像活动不只是在代表学校，而是在帮助“学校作为共同体”本身真正发生。**
