# 1. Who’s That Girl?｜S

## 基础核验
- 平台：WEBTOON ORIGINALS。
- 作者：Song Geukjang。
- 2026-08-17 官方页已更新到 Ep.58，持续连载。
- 官方设定：Sanghyeon Kim 有成为 K-pop star 的能力与欲望，却因虚假校园霸凌指控被反复拒绝；大型娱乐公司负责人给出的神秘浴球使其变成前世的女性身体，由此获得第二次进入偶像业的机会。
- 官方章节直接出现：Monthly Evaluations、Team Assignments、Rehearsals、Main Stage、Vocal Training、Body Composition Check，以及“A Female Idol”等职业节点。
- 结论：不是“变身恋爱漫画顺带偶像”，而是持续进入练习生考核、舞台、声乐、身体管理等偶像职业机制，正式升S。

## 新母型
**职业准入偏见 → 身体身份重置型**。

不是“能力变强后重新获得资格”，而是：
**能力与梦想原本已经存在，但社会履历/公众污名封死入口；身体与社会身份被重置后，同一职业欲望重新获得被评估资格。**

## 十元
- 主符号：x并z——女性新身体与新的可被娱乐工业识别/包装的候选偶像身份。
- 次符号1：xn——娱乐公司、练习生、月末评价、分组、排练、主舞台、声乐训练、身体管理。
- 次符号2：zn——“昨天还是Sanghyeon Kim，今天我以谁的身份追同一个梦”的本体连续性。
- 次符号3：zx——在新身份下重新进入公司评价机器并主动竞争。
- 暗层：xz——旧身份的霸凌污名像命运封印一样阻断原职业路径。

## 体量
x并z10 / xn10 / zn9 / zx8 / x8 / nx7 / xz7 / z7 / n6 / nz6。

## 顺序链
**z → xz → nx → x → x并z → xn → zx → zn**

原本的偶像欲望z → 被校园霸凌污名xz锁死职业入口 → 进入“再努力也只能被拒绝”的nx → 身体/社会身份x被重置 → 新候选偶像身份x并z成立 → 进入公司训练与月末评价xn → 用zx主动争取舞台和职业资格 → 持续逼问zn：追梦的人到底还是不是原来的我。

## 五维
- 时间：xn+z。长期练习、月末评价、训练阶段让梦想被时间制度化。
- 本体：zn+x。身体改变，但职业欲望和记忆连续，本体因此发生强错位。
- 空间：x并z+n。公司、练习室、评价舞台把“可被观看的偶像身份”制造出来。
- 因果：zx+nx。旧身份被动遭拒，新身份重新获得主动竞争资格。
- 命运：xz+nz。旧污名封锁命运，而新同伴/关系网络提供新的承载与缓冲。

## 生链
1. x身体身份重置 → 生x并z新社会身份。
2. x并z新身份 → 生xn训练/评价入口。
3. xn评价制度 → 逼出zx竞争行动。
4. zx持续职业行动 → 反过来加厚x并z公众候选偶像身份。

## 克链
1. xz旧污名克z偶像梦想：不是缺能力，而是“社会已经给你定罪”。
2. x并z新身份克xz旧身份封锁：社会识别对象被换掉，旧污名暂时失效。
3. xn公司规则克zn私人本体：系统只评价当前可见身体与表现，不关心灵魂连续性。
4. zn反克x并z：记忆与旧自我不断提醒“这个成功身份并不等于我的全部”。

## 反咬点
**第二次机会成立的前提，恰恰是社会不再把他当成原来的那个人。**

如果新身份越成功，问题会越来越尖锐：成功是在证明“原来的Sanghyeon本来就有资格”，还是在证明只有换掉身体/身份，社会才愿意承认这份才能？成功本身会反向证明旧身份遭到的结构性否定。

## 5组补子
- xn+z：梦想必须进入训练、月评、声乐与舞台节奏才能兑现。
- zn+x：记忆/人格连续，但身体与社会身份改变。
- x并z+n：新偶像身份必须依靠公司、练习室、评价舞台与他人观看成立。
- zx+nx：旧身份只能被拒绝，新身份重新取得主动竞争权。
- xz+nz：旧污名锁死职业命运，新关系网络为第二次职业路径提供缓冲。

## 偶像职业机制
练习生：强；公司：强；月末评价：强且多轮出现；分组/团队任务：有；排练：强；Main Stage：强；Vocal Training：强；身体管理：有 Body Composition Check；竞争/对手：持续存在。偶像职业度10/10。

## 成为偶像的欲望与代价
- 表层欲望：重新获得成为K-pop star的机会。
- 深层欲望：证明旧身份被拒绝并不等于自己没有资格。
- 成功代价：职业成功越来越依赖“社会承认的新身体/新身份”。
- 失败代价：不仅失去第二次机会，还可能再次确认“原来的我永远无法进入这个职业”。

## 与已有样本差异
- vs《Wanna be a Star!》：后者是同一身体能力被不同偶像分类赋予相反价值；本作是社会污名先封死职业入口，再通过身体/身份重置绕过封锁。
- vs《This Life's Universal Superstar》：后者是身体技能获得强化；本作核心不是技能增强，而是社会识别身份变化。
- vs《The Holy Idol》：后者是陌生灵魂继承现成偶像身体；本作是原追梦者保留连续欲望与记忆，用新身体重新参加职业准入竞争。

## 可复用母题
**“能力没有被修复，社会识别对象被换掉了。”**

# 2. A Doomed Girl Group's Do-Over｜S

## 基础核验
- 平台：Tapas，官方授权漫画，Published by TAPAS ENTERTAINMENT 2025。
- 原题：망할 운명의 걸그룹 리더가 되었습니다。
- Season 1 已于2026-04-09结束，官方页列41话，等待第二季。
- 官方设定：顶级solo idol Baek Nokha 在领奖时错过母亲临终，接受第二次机会后，以Yoon Chung身份从底层重新开始，成为idol competition show中的trainee；想再次见到母亲，必须实现Yoon Chung“第一名出道”的愿望。
- 结论：练习生 + 偶像竞演节目 + 第一名出道硬目标 + 旧职业知识再利用，偶像职业机制构成主发动机，正式升S。

## 新母型
**顶点职业者 → 底层资格重考型**。

不是“失败者重来”，而是：
**已经站到行业顶点的人，被剥夺原有名气、身体与职业资本，必须以另一个人的身份重新参加最底层准入考试。**

## 十元
- 主符号：xz——“想再见母亲，就必须让Yoon Chung第一名出道”的强命运交换条件。
- 次符号1：xn——偶像竞演节目、练习生身份、排名、出道位。
- 次符号2：x并z——从顶级solo idol公众身份坠落为无名trainee，再重新制造新公众身份。
- 次符号3：zx——利用声音与行业知识主动竞争第一名。
- 暗层：zn+x——Baek Nokha的职业自我进入Yoon Chung的新身份载体。

## 体量
xz10 / xn10 / x并z9 / zx9 / zn8 / x8 / z8 / nx7 / n7 / nz7。

## 顺序链
**zn → xz → x → x并z → xn → nx → zx → n → zn**

顶级solo idol旧职业自我zn → 母亲死亡与再见条件xz → 进入Yoon Chung新载体x → 从零建立trainee公众身份x并z → 被塞回竞演/排名xn → 先接受“过去顶级身份全部作废”的nx → 用旧知识与声音发动zx → 在节目、队友、观众关系n中重新积累职业资本 → 形成新的偶像zn。

## 五维
- 时间：xn+z。竞演赛程把“再见母亲”的愿望压缩成明确职业倒计时。
- 本体：zn+x。顶级solo idol经验仍在，但身体/名字/职业履历全部归零。
- 空间：x并z+n。节目舞台、排名与观看系统重新生产Yoon Chung这个偶像身份。
- 因果：zx+nx。她必须先接受从底层被评价，再利用旧行业经验主动翻盘。
- 命运：xz+nz。亲缘愿望是硬条件，新的团队/关系则逐渐改变纯工具性的出道目标。

## 生链
1. xz再见母亲条件 → 生xn“必须第一名出道”的职业规则。
2. xn竞演规则 → 生nx被排名、被评价、被淘汰风险。
3. 旧职业zn + zx主动知识 → 生x并z新的候选偶像身份。
4. x并z成功 → 生n公众/团队职业资本。

## 克链
1. xz克z：私人悔恨把第二次人生锁成唯一目标。
2. xn克zn：节目不承认“你以前是顶级solo idol”，只认当前trainee成绩。
3. nx克x并z：排名与评价可以随时把新身份打回无名。
4. zx反克nx：旧行业知识让她能比普通新人更主动理解舞台和竞争。
5. 新zn反克旧zn：一旦Yoon Chung的人际与职业身份真实成立，旧Baek Nokha的“工具性重来”逻辑会被反咬。

## 反咬点
**她必须证明一个已经成功过的人，在失去所有“成功证明”后仍然值得成功。**

越靠旧经验拿第一，就越会出现本体问题：这是Yoon Chung的成功，还是Baek Nokha借壳复现自己的成功？她是在完成别人的愿望，还是重新把别人活成自己？第一名因此不只是排名，而是“新身份能否成为真正主体”的判决。

## 5组补子
- xn+z：竞演赛程把再见母亲的欲望职业化。
- zn+x：旧顶级偶像自我进入新身体/名字，从零重建。
- x并z+n：新偶像身份依靠节目、观众、队友与排名被重新制造。
- zx+nx：先被节目规则评估，再用旧经验主动反制。
- xz+nz：亲缘命运是硬驱动，新团体关系可能逐渐软化“只为母亲而出道”的单一目的。

## 偶像职业机制
练习生：核心；偶像竞演节目：核心；排名：核心，目标明确到“第一名出道”；出道位：核心；舞台/表演：核心接口；行业知识：主角核心优势；团体：标题与竞演结构指向女团形成，后续持续追踪成员运营。偶像职业度10/10。

## 成为偶像的欲望与代价
- 表层欲望：第一名出道，换取再次见到母亲。
- 深层欲望：修复“职业成功夺走最后私人时间”的悔恨。
- 成功代价：必须再次把人生交给曾经已经吞掉她私人时间的偶像职业机器。
- 失败代价：失去与母亲再见的机会，也否定Yoon Chung的出道愿望。

## 与已有样本差异
- vs《My Comeback as the Youngest Member》：后者是被淘汰者用失败人生重进同一选秀；本作是已经站过顶点的人失去全部职业资本后重考底层资格。
- vs《My Second Life as an Idol》：后者是失败偶像在新身体里再次成功；本作旧身份不是失败者，而是顶级solo idol，重来是“顶点→底层”的倒置。
- vs《Debut or Die!》：都是强条件出道，但前者“不出道自己死”，本作是“必须第一名出道才能修复亲缘遗憾”，死亡压力被替换成亲缘交换条件。

## 可复用母题
**“把冠军的奖杯全部拿走，再问冠军还会不会赢。”**

# R14去重结论
1. 职业资格修复继续细分：This Life's Universal Superstar＝身体技能修复；Who’s That Girl?＝社会识别身份重置，绕过旧污名。
2. 回归再出道继续细分：My Comeback as the Youngest Member＝失败者重进同一选秀；Second Try Idol＝失败者先成为训练师再回前台；A Doomed Girl Group's Do-Over＝顶级成功者失去全部职业资本，从trainee重新考第一名。
3. 下一轮仍优先寻找：合同续约、成员毕业/更替、明确退出受阻、收入/事务所压榨；减少继续堆“系统回归男偶像”。
