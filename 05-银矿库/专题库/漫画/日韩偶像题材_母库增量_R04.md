# 日韩偶像题材｜母库增量 R04

## Wanna be a Star!｜韩漫｜A+

### 官方核验
Tappytoon 授权官方漫画，作者 Hyeonsook，Completed。官方简介明确：Soh 从小热爱唱歌，进入大型娱乐公司成为练习生；随着成长，她的声音变得低哑、体格变宽，在女团路线中停滞，新成员 Sena 加入后进一步挤压她的位置。她一度放弃 K-pop 梦想，之后发现自己崇拜的男偶像 Yujin 正在为男团招募新成员，于是利用偏中性的外形与声音、借用双胞胎兄弟证件参加现场 audition。

官方来源：https://www.tappytoon.com/en/book/wanna-be-a-star

### 是否真正进入偶像职业机制
是。不是“明星恋爱”外皮，而是连续出现：大型娱乐公司练习生 → 女团内部竞争/成员替换压力 → 放弃原出道路线 → 男团公开 audition → 以另一套偶像身份分类重新争取出道。

偶像职业度：9/10。

### 核心机制
**同一份唱歌能力，在“女偶像”分类里被判定为不合格，却在“男偶像”分类里重新成为优势。**

职业系统不是简单阻碍主角，而是在用身体、声音、性别包装和团体定位给她分类。主角不是退出系统，而是主动切换分类入口。

### 十元
- 主符号：x并z（公众偶像身份/性别化职业包装）
- 次符号1：zn（“我想成为歌手/偶像”的真实职业自我）
- 次符号2：xn（公司、练习生、女团/男团、audition 等职业制度）
- 次符号3：zx（借兄弟身份、主动参加男团 audition）
- 暗层：x（现实身体、声音、外形条件）

### 体量 1–10
- x并z：10。故事真正的门不是“会不会唱”，而是“系统把你包装成哪一种偶像”。
- zn：9。主角一直没有放弃唱歌/成为 K-pop star 的内核，只是职业自我找不到可成立的位置。
- xn：9。公司训练、团体位置、audition、性别化分组持续决定她有没有入口。
- zx：8。她最终不是等待被重新发现，而是主动换身份、换赛道、重新竞争。
- x：8。嗓音变低、体格变宽等现实身体变化直接改变职业评价。
- nx：7。前半段长期承受公司与女团结构的被动筛选。
- z：7。持续的唱歌执念让她在放弃后仍会重新行动。
- n：6。团体位置与其他成员构成她被评价的关系场。
- xz：4。没有死亡/系统硬命运，更多是职业结构压力。
- nz：5。偶像崇拜、团体关系提供重新行动的关系支点。

### 五维
- 时间 xn+z：成长导致声音/身体变化，长期练习与迟迟不能出道共同消耗执念。
- 本体 zn+x：主角的“我是能唱歌的人/我要做偶像”与现实身体被行业如何读取发生冲突。
- 空间 x并z+n：女团与男团是两套不同的被观看空间，同一人进入不同空间就得到不同职业意义。
- 因果 zx+nx：先被公司分类和淘汰逻辑安排，后主动利用另一套分类规则反击。
- 命运 xz+nz：硬命运较弱；更像关系/偶像榜样提供替代入口，而非不可逃避的命运锁。

### 顺序链
**zn → xn → x → nx → zx → x并z → zn**

想成为偶像的职业自我 zn
→ 进入公司制度 xn
→ 身体/声音变化 x 被制度重新读取
→ 在女团路线陷入被筛选 nx
→ 主动借身份参加男团 audition zx
→ 建立新的公众偶像包装 x并z
→ 反过来重新证明原来的职业自我 zn。

### 生链
**x现实条件 → xn分类规则 → x并z新包装可能性 → zx主动换入口 → zn职业自我重新成立。**

关键不是身体本身生出失败，而是身体经过制度分类后才产生“失败/优势”的不同意义。

### 克链
1. **xn 克 zn**：制度告诉她“想当偶像”不等于“你适合这个女团位置”。
2. **x 克 x并z（旧包装）**：成长后的声音和体格破坏既有女偶像包装匹配。
3. **zx 克 nx**：主动参加另一类别 audition，摆脱只等待女团公司评价的被动状态。
4. **x并z（新包装）反克 xn**：同样的身体与声音进入男团分类后，原先的缺点可能成为职业资产。

### 反咬点
**她越靠“假身份”获得真实职业认可，就越可能发现：职业系统认可的不是“真正的她”，而是被正确分类后的她。**

因此成功并不自动解决本体问题。成功甚至会把问题放大：到底是“我终于被看见”，还是“只有我假装成另一类人时，系统才愿意看见我”？

### 5组补子
- xn+z：公司/练习/团体/audition 规则 + 不肯熄灭的唱歌执念。
- zn+x：真实职业自我 + 被行业重新读取的身体/声音条件。
- x并z+n：男/女偶像公众包装 + 对应团体与舞台关系场。
- zx+nx：主动切换身份参赛 + 前期被公司/女团分类筛选。
- xz+nz：硬命运较弱；以偶像榜样与团体关系作为替代性“路径牵引”。

### 偶像机制
- 练习生：强。
- 公司：强，大型娱乐公司直接决定职业入口。
- 团体：强，女团位置与男团新成员招募都直接参与剧情。
- audition：极强，是第二职业入口。
- 舞台/唱歌能力：强。
- 公众包装：极强，性别化偶像身份是核心机制。
- 粉丝：中，现有官方简介未显示粉丝机制为主要发动机。
- 排名/淘汰：中，明确存在竞争与位置压力，但不是生存节目型排名机器。

### 成为偶像的欲望与代价
- 表层欲望：继续唱歌并真正出道成为 K-pop star。
- 深层欲望：证明自己的声音和身体不是职业失败本身，只是原先分类不允许它成立。
- 成功代价：必须用假身份进入正确职业类别，真实身份与成功身份发生分裂。
- 失败代价：不仅失去出道机会，还会被迫接受“我的身体不适合我的梦想”这一制度判断。

### 与已有样本差异
与《AKB49～恋爱禁止条例～》形成非常有价值的镜像对照：两者都有跨性别偶像包装，但《AKB49》更偏“男性进入女性偶像制度、体验规则并维持秘密身份”；本作则是**已经处在女性练习生制度内部的人，因为身体/声音与分类标准错位，被迫切换到男性偶像入口求职业生存**。

因此新矿点不是“性别伪装”，而是：
**职业系统通过分类制造失败，而主角通过切换分类重新让同一能力成立。**

### 可复用母题
**“不是我没有能力，是系统把我放进了错误的职业类别。”**

可迁移到：女声/男声歌手、演员类型、模特体型、体育级别、职业年龄层、角色声线、审美赛道等。

### 矿级
**A+。**
理由：偶像职业机制密度高，而且与 AKB49 能形成成对母型；之所以暂不升 S，是公开官方简介足以确认职业入口与核心冲突，但还不足以核验后续长期粉丝、公司运营、舞台排名等全链路密度。

## To You Who Swallowed a Star｜韩漫｜B观察

### 官方核验
Tappytoon 授权官方漫画，作者 ARI，Completed。官方简介确认：Jiu 搬入小公寓后认识楼下被忽视的 Hajun 与 Hayul；随后 Hajun 收到 scouting offer，进入 idol survival program，Jiu 鼓励他参加 audition，而这个决定改变了所有人的人生轨迹。

官方来源：https://www.tappytoon.com/en/book/to-you-who-swallowed-a-star

### 暂定十元
- 主：zx（“去参加 audition”这个选择成为关系网络的因果开关）
- 次：xn（idol survival program 的规则机器）
- 次：x并z（Hajun 从私人少年转为公众偶像候选身份）
- 暗层：nz（Jiu/Hajun/Hayul 关系被职业变化重新排列）

### 五维与顺序
- 时间 xn+z：进入节目后人生路径被阶段化。
- 本体 zn+x：Hajun 从私人身份转入偶像候选身份。
- 空间 x并z+n：节目/舞台成为新的被观看空间。
- 因果 zx+nx：Jiu 的鼓励与 Hajun 的 audition 行动启动职业机器，随后个人受节目规则安排。
- 命运 xz+nz：职业选择重写原有关系网络，但官方简介不足以证明硬命运机制。

顺序链：**nz → zx → xn → x并z → nz**。

### 反咬点
“鼓励一个人追逐机会”看似是关系支持，但一旦他进入公众职业机器，成功本身可能改变原先私人关系成立的条件。

### 5组补子
- xn+z：生存节目阶段规则 + 出道/改变人生的持续欲望。
- zn+x：私人少年自我 + 被职业重新读取的现实身份。
- x并z+n：偶像候选公众形象 + 节目/舞台观看空间。
- zx+nx：主动 audition + 随后接受节目筛选。
- xz+nz：人生轨迹改变 + 原关系网络被重新排序。

### 为什么只留 B观察
官方资料明确证明“scouting → idol survival program → audition”，所以它不是普通明星恋爱；但当前公开官方简介仍不足以确认练习、排名、公司运营、粉丝、舞台等职业机制是否长期作为全作主发动机。作品官方分类仍是 Romance，因此暂不越级。

### 可复用母题
**“我替你推开职业入口，却也因此失去原来那个只属于私人关系中的你。”**
