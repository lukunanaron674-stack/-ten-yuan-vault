# 日韩偶像题材｜母库增量 R69

> 本轮去重后新增《アイドル事変 / Idol Incidents》。不把普通娱乐圈恋爱作品计入核心样本。本作虽然是架空政治题材，但主角从普通农村少女进入“偶像议员”职业，持续经历选拔、竞选、歌舞舞台、党派协作、公共议题处理与公众承认，偶像成长链足够硬，收入核心样本。

## 《アイドル事変 / Idol Incidents / 偶像事变》｜日本原创TV动画＋漫画｜S

### 1. 基础卡
- 媒介：2017日本原创TV动画；另有漫画版与游戏企划。
- 主角：星菜夏月，16岁，新潟出身，原本是农家少女，后成为ヒロイン党的偶像议员。
- 偶像身份如何建立：党首为补选寻找候选人时发现夏月；她先取得政党候选入口，再通过与前辈合作、歌舞表现和选举赢得议席，成为“偶像＋国会议员”的复合职业者。
- 核心职业矛盾：公众必须同时承认她“值得看”与“值得授权”。粉丝承认不能直接替代选票，选票也不能替代偶像舞台能力。
- 矿级：S。

### 2. 本轮新增母型
**双重合法性职业化 / 粉丝承认＋选民授权型**

不是普通：
`素人 → audition → 出道 → 粉丝`

而是：
`普通人 → 被政党发现 → 候选人 → 舞台/竞选 → 当选 → 偶像议员 → 公众问题处理 → 再次接受公众评价`

核心公式：

**职业身份成立 = 表演合法性 × 公共授权合法性**

任意一边接近0，完整“偶像议员”身份都不成立。

### 3. 十元
- **x并z 10**：农家少女、偶像、政党成员、国会议员多重社会身份叠加；“偶像议员”本身就是复合身份。
- **zx 10**：夏月主动参选、解决问题、合作、登台、争取公众支持。
- **xn 10**：选举、议员研修、党派、议会、公共事务与偶像舞台构成双制度。
- **n 9**：前辈议员、同党成员、跨党派合作直接影响行动成败。
- **nz 9**：选民、粉丝、地方居民的支持既是情感关系也是合法性来源。
- **nx 9**：党派规则、补选、对手阻挠、公共问题持续反压主角。
- **zn 9**：从“让大家开心的普通女孩”变成“我是否有资格代表别人”的本体升级。
- **x 8**：歌舞、笑容、沟通与行动力被职业化使用。
- **z 8**：每次竞选、公共问题与舞台结果形成政治＋偶像双履历。
- **xz 7**：国家困境、政治腐化等宏观环境制造高压命运背景，但不是超自然硬锁。

主元：**x并z + xn**
次元：**zx + nz**
反压：**nx + zn**

### 4. 顺序链
**x → nz → nx → zx → x并z → xn → n → nz扩大 → zn → 新zx → 新x并z**

普通农家少女的亲和力与行动力 x
→ 被党首/地方关系发现 nz
→ 补选与政治规则 nx 把她推到职业门口
→ 主动参选、登台、争取支持 zx
→ “偶像议员候选人”身份 x并z 出现
→ 选举、议员研修、公共问题、歌舞活动 xn 持续加工
→ 与前辈及其他党派形成 n
→ 粉丝/选民/地方居民 nz 扩大
→ 追问“我到底只是会让人开心，还是能代表别人” zn
→ 主动承担公共结果 zx
→ “真正的偶像议员”新 x并z 成立。

### 5. 五维
#### 时间｜xn + z：10/10
竞选不是一次舞台；当选后还要持续处理垃圾、环境、地方问题和议员研修。职业身份靠连续公共履历维持。

#### 本体｜zn + x：10/10
核心问题从“我能不能唱跳、让大家开心”升级为“我是否有资格代替别人作决定并承担结果”。

#### 空间｜x并z + n：10/10
舞台、选区、政党、国会、地方现场是完全不同的社会空间，却都共同生产同一个“偶像议员”身份。

#### 因果｜zx + nx：10/10
主角主动行动，但补选制度、党派竞争、公共问题、对手阻挠不断规定行动边界。

#### 命运｜xz + nz：9/10
宏观社会危机提供高压背景，最终却必须靠具体人与公众关系把宏观问题转成可执行行动。

### 6. 偶像职业机制
- **训练**：新人议员研修＋歌舞/舞台表现，职业要求不是单轨技能。
- **出道**：通过地方补选与公开活动同时建立“议员＋偶像”双身份。
- **竞争**：政党竞争、补选竞争、不同偶像议员之间的公共影响力竞争。
- **舞台**：歌唱与舞蹈不是装饰，而是公开沟通、凝聚支持、解决冲突的职业工具。
- **粉丝**：粉丝支持与政治支持重叠但不完全相等；喜欢可以产生注意力，授权才产生公职合法性。
- **公司/组织机制**：政党承担事务所＋组织＋政策平台三重功能，既培养偶像，也分配候选资格与政治资源。

### 7. 主角欲望与代价
- 表层欲望：让大家露出笑容，帮助遇到困难的人。
- 职业欲望：成为能真正解决问题、得到公众信任的偶像议员。
- 深层欲望：证明“让人开心”不只是表演魅力，也能转化为承担公共责任的资格。
- 成功代价：越受欢迎，越不能把舞台后果理解成私人行为；个人形象会直接影响政党、选民与公共决策。
- 失败代价：不只是掉粉，而可能失去席位、公共信任与代表资格。

### 8. 关系结构
**党首/招募者 → 夏月**：提供入口，但不能替她赢得合法性。

**鬼丸靜 ↔ 夏月**：前辈与新人；前辈一开始不认可，合作过程把“被组织塞来的候选人”变成“值得并肩的职业者”。

**夏月 ↔ 其他党派偶像议员**：竞争者也可能在具体公共问题上形成跨党 n。

**夏月 ↔ 选民/粉丝**：同一公众同时拥有“观看我”和“授权我”两种完全不同的权力。

### 9. 动态链
#### 链A｜双重合法性
**舞台x → nz注意 → x并z偶像认知 → 选举xn → nz/nx公众裁决 → 公职x并z成立**

舞台可以让人愿意听她，但必须经过选举制度，喜欢才能转成代表权。

#### 链B｜魅力工具公共化
**x个人魅力 → zx公开行动 → nz支持 → 公共问题进入 → nx责任增加 → zn升级**

越能动员别人，越必须对动员后产生的公共后果负责。

#### 链C｜竞争者转协作者
**n同位竞争 → 公共问题nx → 单党不足 → 跨党合作zx → n关系升级 → 公共结果**

制度把她们做成竞争者，现实问题却可能要求这些竞争者共同解决。

### 10. 最大反咬点
#### 反咬1｜粉丝越多，越不能只做“让大家开心”的人
一开始，笑容和歌舞是优势。

但支持规模扩大后：
**人气↑ → 代表性↑ → 公共期待↑ → nx责任↑**

于是：
> **nz支持达到一定体量，会转化为nx责任。**

#### 反咬2｜被喜欢 ≠ 被授权
一个人可以拥有大量粉丝，却未必适合替别人作公共决定。

因此：
> **nz情感承认不能直接替代xn制度合法性。**

这条可直接用于主播、意见领袖、公众专家、社区领袖等题材。

#### 反咬3｜政治职位反而需要偶像能力保持“可沟通性”
进入公职后，看似应该摆脱偶像身份。

但如果公众问题复杂、制度语言封闭，歌舞、表演、亲和力反而成为把抽象政策重新翻译给公众的工具。

即：
**偶像能力不是入场皮肤 → 它可能成为公共沟通技能。**

#### 反咬4｜竞争制度会制造必须合作的对手
政党结构要求争夺席位；垃圾、环境等现实问题却可能跨地区、跨党派。

因此：
**xn竞争 → nx现实问题 → n跨党合作 → xn局部重写。**

### 11. 五组补子
1. **偶像人气 nz ↔ 选举授权 xn**：喜欢你与授权你代表我，不是同一件事。
2. **个人魅力 x ↔ 公共职位 x并z**：魅力能开门，但职位要求持续责任。
3. **主动参选 zx ↔ 制度约束 nx**：越主动进入公职，越必须接受规则限制。
4. **党派竞争 n ↔ 跨党合作 n**：同位关系可在不同公共问题上从竞争切为协作。
5. **私人“让大家开心”zn ↔ 公共“替大家承担结果”新zn**：职业成长不是把旧性格删除，而是给它增加责任维度。

### 12. 视觉符号
- 农田中的普通少女 ↔ 国会/竞选台上的候选人
- 偶像舞台麦克风 ↔ 议员演讲麦克风
- 荧光棒 ↔ 选票
- 粉丝欢呼 ↔ 开票结果
- 舞台服 ↔ 议员徽章/党派标识
- 单人演出 ↔ 多党共同站在地方问题现场
- 巨大应援人群 ↔ 具体居民向她提出真实诉求

最强视觉对子：
> **“为我欢呼的人群” → “要求我负责的人群”。**

### 13. 可复用母题
- **双重合法性职业**：一个身份必须同时通过两套评价系统才成立。
- **粉丝→选民**：情感支持必须经过制度转换才能成为授权。
- **魅力公共化**：私人魅力变成公共沟通工具，同时制造公共责任。
- **注意力责任化**：关注越大，退出私人空间的代价越大。
- **竞争者公共合作**：职业竞争不能取消共同问题上的合作义务。
- **职业身份双栈**：偶像＋议员两套身份不是互相替换，而是同时成立、互相约束。

### 14. 可迁移结构
- 网红 → 地方议员：流量不等于治理合法性。
- 英雄明星 → 骑士团长：受欢迎不等于拥有指挥权。
- 知名画师 → 艺术协会代表：审美影响力不等于制度代表权。
- 主播 → 社区领袖：粉丝关系转成公共责任需要第二套授权。
- 圣女偶像 → 神殿行政首领：信徒爱戴与制度任命必须双重成立。

### 15. 与已有样本差异
- vs《SELECTION PROJECT》：公众投票直接生产偶像资格；本作则把**情感支持与正式政治授权拆成两层**。
- vs《Macross Δ》：后者是偶像能力具有公共功能后责任化；本作更进一步，公共责任本身由**选举/议员制度**授予。
- vs《Dream High》：制度加工职业者；本作同时存在**艺能制度＋政治制度**，主角要在两套规则里同时成立。
- vs《虹咲》：后者研究多个完整个体如何并列共存；本作研究一个主体如何同时拥有两个会互相约束的公共职业身份。

### 16. 本轮矿核
> **公众“喜欢你”与公众“授权你”是两种不同的社会力量。偶像可以靠舞台获得注意力和情感，但一旦职业身份进一步承担公共决策，喜欢就必须经过制度转换才能成为合法权力；而当一个人真的获得这种权力以后，原本用来让大家开心的魅力，也会反过来变成必须对大家负责的债。**

## R69 增量结论
正式新增谱系：

# **「双重合法性职业化 / 粉丝承认＋选民授权型」**

**私人能力 → 公众注意 → 偶像身份 → 制度竞选 → 公共授权 → 双职业实践 → 支持转责任 → 新本体。**

本轮对十元系统最有价值的新规则：

> **nz可以制造关注与情感承认，但不能自动制造制度合法性；当nz需要转化为公共权力时，必须经过xn。反过来，一旦xn授予权力，原本作为奖励的nz又会变成责任来源，形成 nz → xn → nx 的反咬链。**
