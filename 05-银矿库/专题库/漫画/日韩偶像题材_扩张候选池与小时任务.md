# 日韩偶像题材｜扩张候选池与每小时十元任务

## 目标
持续寻找“主角/核心角色真正进入偶像职业机制”的日漫、韩漫、Webtoon。重点不是泛娱乐圈，而是练习生、选秀、出道、再出道、团体运营、舞台、公演、粉丝、排名、公司规则、毕业/退出与偶像身份塑形。

## 优先母题
1. 必须成为偶像：死亡条件、系统任务、现实强制、交换条件。
2. 再来一次当偶像：重生、回归、失败后重启、二周目职业线。
3. 幕后者/外行业变偶像：制作人、经纪人、作曲家、训练师、企业经营者进入前台。
4. 偶像身份反噬本体：真实自我 vs 被观看/包装的公众身份。
5. 团体共同体：个人欲望被团体、粉丝、公司、排名重新定义。
6. 选秀竞争：舞台、票数、淘汰、镜头、剪辑权、舆论构成因果机器。
7. 职业分类错位：同一能力被不同偶像分类赋予相反价值。
8. 职业诚意耗损：已出道，但公司/经营长期磨掉“为什么当偶像”。
9. 职业资格修复：现实技能缺口曾否定梦想，条件变化后入口重开。
10. 惩罚性职业改造：职业不是梦想而是惩罚；成功后公众承认反过来锁死身份。
11. 糊团经营/再生：重点不是个人出道，而是成员关系、经营、comeback、市场再承认。
12. 低优先级单位长期经营：从边缘工作一步步建立持续职业共同体。
13. 粉丝劳动外置：粉丝不进入职业，但购买/应援/传播直接制造偶像职业资本。
14. 成员毕业/更替：成员离开后，团体本体是否仍然连续。
15. 合同/收入/恋爱禁令：现实制度直接限制偶像本体与私人生活。
16. 职业存续资格：已经出道，仍须反复用Live、销量、曝光等量化指标证明“配继续存在”。
17. 生存资产绑定：职业收入直接决定宿舍、债务、共同生活资产能否继续存在。
18. 职业准入偏见：能力没有消失，但污名/身份标签先决定“你有没有资格被评价”。
19. 顶点职业者重考：成功者失去既有名气与资本后，从新人准入层重新证明自己。

## 每轮固定模板
每轮至少深拆1部，最多3部；宁可少而深，不做标题堆积。
- 基础：作品名 / 地区媒介 / 连载状态 / 进入偶像业触发点 / 职业机制 / 是否真正当偶像。
- 十元：主符号 / 次符号 / 暗层 / 五维 / 体量1-10 / 顺序链。
- 生克：生链 / 克链 / 反咬点 / 条件变化。
- 5组补子：xn+z / zn+x / x并z+n / zx+nx / xz+nz。
- 偶像专用：成为偶像原因、公司/节目、粉丝、团体、本体变化、成功代价、失败代价、视觉符号、可复用母题、矿级。
- 每新增1部，至少和母库1部写一句差异，禁止重复矿点。
