# 日韩偶像题材｜扩张候选池与每小时十元任务

## 目标
持续寻找“主角/核心角色真正进入偶像职业机制”的日漫、韩漫、Webtoon。
重点不是泛娱乐圈，而是：练习生、选秀、出道、再出道、团体运营、舞台、公演、粉丝、排名、公司规则、偶像身份塑形。

## 优先母题
1. 必须成为偶像：死亡条件、系统任务、命运锁定、交换条件。
2. 再来一次当偶像：重生、回归、失败后重启、二周目职业线。
3. 幕后者变偶像：制作人、经纪人、作曲家、导演、记者进入前台。
4. 偶像身份反噬本体：真实自我 vs 被观看/包装的公众身份。
5. 团体共同体：个人欲望被团体、粉丝、公司、排名重新定义。
6. 选秀竞争：舞台、票数、淘汰、镜头、剪辑权、舆论构成因果机器。

## 每小时十元分析固定模板
每轮至少深拆1部，最多3部；宁可少而深，不做标题堆积。

官方核心：可化为人形的动物世界中，热门偶像团体 Marigold 由小型可爱动物组成，新成员 Youngwoong 却疑似是肉食动物；官方标签包括 Idol/Actor、Secret identity。

#### 初判十元
- 主符号：zn，真实物种身份不能公开。
- 次符号：x并z，作为“可爱偶像成员”的公众包装。
- 暗层：xn，团体既有形象与偶像规则要求他维持可接受身份。
- 生链：zn隐藏 → x并z偶像包装 → n团体观看空间维持身份。
- 克链：真实肉食动物身份 zn 持续威胁公众偶像形象 x并z；反过来 x并z 也压制真实本体表达。
- 反咬点：越融入“可爱小动物偶像团”，越需要否认最不能被团体接受的真实身份。

#### 5组补子
- xn + z：偶像团体规则需要持续营业与时间维护。
- zn + x：真实物种本体与可被接受的人形/成员身份冲突。
- x并z + n：可爱偶像形象必须在团体与粉丝观看空间中成立。
- zx + nx：主角主动适应团体，但始终被既有形象要求约束。
- xz + nz：秘密暴露可能构成命运性破局；团体关系是软化暴露后果的关键。

#### 为什么暂不升A
公开官方简介可以确认“偶像团体 + 新成员 + 秘密身份”，但暂不足以证明练习、舞台、排名、公司、粉丝等职业机制是持续叙事发动机。先作为**本体/公众身份型偶像边缘样本**保留，不因标题有 idol 就给高矿，免得理论库被词面骗得团团转。

## 每小时回填规则
1. 搜索新作品与官方来源。
2. 排除只有明星恋爱/演员线、无偶像职业机制者。
3. 每轮选1-3部。
4. 完成十元+五维+生克+5组补子。
5. 写出与已有样本的差异，禁止重复矿点。
6. S/A级进入母库或母库增量文件；B/观察继续留在候选池。
7. 每10轮做一次去重与母型归并。
8. 发现新的高价值母型时，单独写“母型卡”，不要埋在作品简介里。
