# 日韩偶像题材｜扩张候选池与每小时十元任务

## 目标
持续寻找“主角/核心角色真正进入偶像职业机制”的日漫、韩漫、Webtoon。重点不是泛娱乐圈，而是练习生、选秀、出道、再出道、团体运营、舞台、公演、粉丝、排名、公司规则、偶像身份塑形。

## 优先母题
1. 必须成为偶像：死亡条件、系统任务、命运锁定、交换条件。
2. 再来一次当偶像：重生、回归、失败后重启、二周目职业线。
3. 幕后者变偶像：制作人、经纪人、作曲家、导演、训练师进入前台。
4. 偶像身份反噬本体：真实自我 vs 被观看/包装的公众身份。
5. 团体共同体：个人欲望被团体、粉丝、公司、排名重新定义。
6. 选秀竞争：舞台、票数、淘汰、镜头、剪辑权、舆论构成因果机器。

## 每轮固定模板
每轮至少深拆1部，最多3部；宁可少而深，不做标题堆积。
- 基础：作品名 / 地区媒介 / 连载状态 / 进入偶像业触发点 / 职业机制 / 是否真正当偶像。
- 十元：主符号 / 次符号 / 暗层 / 五维 / 体量1-10 / 顺序链。
- 生克：生链 / 克链 / 反咬点 / 条件变化。
- 5组补子：xn+z / zn+x / x并z+n / zx+nx / xz+nz。
- 偶像专用：成为偶像原因、公司/节目、粉丝、团体、本体变化、成功代价、失败代价、视觉符号、可复用母题、矿级。
- 每新增1部，至少和母库1部写一句差异，禁止重复矿点。

## 已完成｜R02

### Second Try Idol｜A+
Tapas 官方漫画，Completed，165话。主角原为准出道偶像，事故毁容后退出并成为偶像训练师，之后回到19岁练习生时期，在音乐竞演中再次争取出道。
主：xn；次：zx + zn；暗层：x并z。
主结构：**xn → zn → zx → x并z → nz → zn**。
新母型：**前台失败者 → 后台训练者 → 回到前台。**
与《Second Life Millionaire》去重：不是普通回归组团，而是“训练别人的后台经验”返回过去训练自己。
详见：`日韩偶像题材_母库增量_R02.md`

### The Holy Idol｜A
WEBTOON ORIGINAL，Completed。大祭司 Rembrary 进入一名不红韩国偶像的身体，被社会直接识别为现成偶像成员并被迫适应该职业生活。
主：zn；次：x并z + xn；暗层：nx。
主结构：**zn → x → x并z → xn → nx → zx → zn**。
新母型：**身体社会身份先于灵魂本体。**
与《My Second Life as an Idol》去重：不是偶像换身体继续追星途，而是完全非行业人格继承一个已经存在的公众职业。
详见：`日韩偶像题材_母库增量_R02.md`

## 回填规则
1. 只使用能核验到的官方/授权公开来源做正式升级。
2. 排除只有明星恋爱、演员线、标题含Idol但无职业机制的作品。
3. 每轮1-3部，完成十元+五维+体量+顺序链+生克+5组补子。
4. S/A写入母库增量；B/观察留候选池。
5. 已完成作品必须移出当前候选，防止下轮重复。
6. 每10轮去重一次，并把重复母型归并。
7. 新母型单独命名，不埋在剧情简介里。
