# 1. アイドル失格 / Idol Shikkaku｜日漫｜S

## 基础核验
- 漫画：空神セイ；原作：安部若菜（NMB48）。KADOKAWA 正式漫画化，全3卷完结。
- 核心偶像：4人组“テトラ”中心成员実々花。集团人气持续上升，并接近 major debut。
- 第2卷官方简介明确：実々花因与核心粉丝ケイタ的暧昧关系陷入动摇，随后发生“center陥落”；两人最终跨越 idol / fan 的边界。
- 第3卷官方简介明确：她已经意识到恋心，同时“作为偶像继续存在”本身开始令她痛苦，约会又被团体成员发现。
- 结论：不是普通“偶像配角恋爱”，职业身份、center位置、粉丝边界、恋爱禁忌与团体关系直接参与主冲突。

## 新母型
**私人关系侵蚀职业资格型：偶像越承认私人感情，越可能失去作为公共偶像的职业位置。**

这不是“偶像不能恋爱”一句标签，而是：
公众身份越依赖粉丝对“可接近但不可真正占有”的想象，私人关系越真实，就越可能成为职业结构中的破坏变量。

## 十元
- 主：x并z（center / 偶像 / 被观看的公众身份）。
- 次1：nz（偶像与粉丝之间逐渐越界的私人情感）。
- 次2：xn（团体、center、职业边界与偶像规则）。
- 次3：zn（“我真正想要什么”与“偶像该是什么”冲突）。
- 暗层：nx（作为偶像必须接受公众期待、成员视线与职业位置变化）。

## 体量
x并z10 / nz10 / xn9 / zn9 / nx8 / n8 / z7 / zx6 / x6 / xz5。

## 顺序链
**x并z → nz → zn → xn → nx → x并z崩动 → zx → 新zn**

公众center身份成立 → 与核心粉丝产生真实私人关系 → 本体开始承认恋爱欲望 → 团体/职业规则介入 → center位置与公众身份受损 → 主角必须主动选择继续扮演偶像还是承认私人自我 → 新本体成立。

## 五维
- 时间 xn+z：偶像职业、团体成长与关系积累同步推进。
- 本体 zn+x：私人少女与公众偶像身份持续争夺“真正的我”。
- 空间 x并z+n：center身份只有在团体、粉丝、活动与公众观看网络中成立。
- 因果 zx+nx：她可以主动接近/选择关系，但结果被职业结构、舆论和成员关系强烈限制。
- 命运 xz+nz：私人关系一旦成立，就开始决定职业命运。

## 生链
1. x并z生nz：持续偶像活动使固定粉丝关系从单向应援变成可识别的个人关系。
2. nz生zn：私人感情迫使実々花回答自己真正想要什么。
3. zn生zx：承认欲望后产生越界行动。
4. zx反生职业危机：私人行动进入公众职业系统后，触发center位置与团体关系变化。

## 克链
1. xn克nz：偶像制度要求私人感情不能轻易改写公共角色。
2. x并z克zn：越是被当作“center idol”观看，越难只按私人自我行动。
3. nz反克x并z：恋爱关系一旦具体化，公众偶像身份的幻想结构被侵蚀。
4. n克zn：成员、粉丝、行业关系使个人选择不能只承担个人后果。

## 反咬点
**粉丝原本是支撑偶像身份的人；当其中一个粉丝变成“私人爱人”，最强支持关系反而可能成为摧毁偶像身份的力量。**

即：
应援nz → 强化x并z
但
私人化nz → 反克x并z。

同一个“关系”在边界变化后，功能完全反转。

## 5组补子
- xn+z：长期偶像活动与感情积累共同推进。
- zn+x：私人少女身体/生活与公众偶像本体冲突。
- x并z+n：center身份依赖团体与粉丝公共网络。
- zx+nx：主动越界与职业后果同时存在。
- xz+nz：私人关系直接改变职业命运。

## 偶像机制
- 团体：明确，4人组テトラ。
- center：强，第2卷直接出现center陥落。
- 粉丝：极强，核心关系就是 idol / fan 边界。
- major debut：官方资料明确团体人气上升并接近major debut。
- 公司/行业规则：存在，但不是经营细节主轴。
- 舞台/活动：职业环境持续存在。
- 恋爱禁忌/私人生活：核心发动机。
- 偶像职业度：9/10。

## 欲望与代价
- 表层欲望：获得作为普通少女被爱、被理解的私人关系。
- 深层欲望：确认“公众偶像之外的我”是否也有资格存在。
- 成功代价：私人关系越真实，center与偶像职业位置越不稳定。
- 失败代价：若完全服从职业身份，就可能保住偶像，却持续压抑私人本体。

## 与已有样本差异
### vs AKB49
- AKB49：恋爱禁止更偏制度与身份伪装。
- Idol Shikkaku：从女偶像主体出发，重点是“粉丝关系私人化之后，原本支撑公众身份的关系如何反过来腐蚀职业身份”。

### vs 我推的孩子
- 我推的孩子：公众形象/谎言与真实自我广义撕裂。
- Idol Shikkaku：把冲突收窄到一个非常具体的职业边界——**center偶像能否与自己的核心粉丝建立真实恋爱关系。**

## 可复用母题
**公共关系必须保持“半距离”才能维持职业价值；一旦关系真正私人化，职业身份的支撑结构就开始塌。**

## 矿级
**S。**

# 2. SELECTION PROJECT｜日漫｜A+

## 基础核验
- 日本原创企划漫画版，共2卷完结；原作 SELECTION PROJECT，作画东皓司。
- 官方设定：全国偶像 audition reality show，是想成为偶像的少女最大的“登龙门”。
- 9个地区预选胜者进入本选，节目以纪录影像 / LIVE 配信持续公开。
- 胜负由观看 reality show 的用户投票决定；胜出者获得正式偶像 debut。
- 漫画第1卷明确：天泽灯参加第一届选秀，顺利通过预选，却被指出“只开心唱歌并不足以成为偶像”。第2卷继续补其他挑战者的参赛前史。

## 新母型
**公众投票授予职业资格型：偶像资格不是公司单独判定，而由“被观看群众”直接以票数生产。**

选手不是先成为偶像再获得粉丝，而是：
**先成为被观看、被评价、被投票的候选人，之后才可能获得“偶像”这一职业身份。**

## 十元
- 主：xn（全国赛制、地区预选、本选、投票规则）。
- 次1：x并z（reality show中的候选人公众形象）。
- 次2：n（海量观众/投票用户组成职业裁决网络）。
- 次3：zx（少女主动参赛、争取表现）。
- 暗层：zn（“我想当偶像”必须被节目重新定义成“什么样的人才配当偶像”）。

## 体量
xn10 / x并z10 / n10 / zx8 / nx8 / zn8 / z7 / nz6 / x6 / xz5。

## 顺序链
**z → zx → xn → x并z → n → nx → zn → 新zx**

梦想z → 主动报名zx → 进入赛制xn → 被纪录/直播塑造成候选人x并z → 观众网络n投票 → 候选人被结果安排nx → 失败/评价迫使重审“偶像是什么”zn → 新一轮行动zx。

## 五维
- 时间 xn+z：预选、本选、阶段比赛与梦想持续性绑定。
- 本体 zn+x：个人“喜欢唱歌”与职业要求的偶像本体之间发生差距。
- 空间 x并z+n：候选人身份依赖节目、直播、观众与投票网络成立。
- 因果 zx+nx：主动参赛，但胜负直接受外部投票结果决定。
- 命运 xz+nz：出道命运通过公众关系/支持被锁定。

## 生链
1. z生zx：偶像梦想催生参赛。
2. zx生xn：报名使梦想进入制度流程。
3. xn生x并z：节目规则要求每个参赛者成为可被观看的“候选偶像”。
4. x并z生n：直播/纪录把候选人送入公众网络。
5. n反生职业资格：票数反过来决定谁能获得正式出道身份。

## 克链
1. xn克zx：个人表现必须服从节目阶段、规则与赛制。
2. n克zn：公众票数可以否定个人对“我适合当偶像”的自我判断。
3. x并z克zn：节目中的可见形象可能覆盖选手私人自我。
4. zn反克x并z：只有本人真正形成自己的偶像理解，才不会完全被票数形象吞掉。

## 反咬点
**偶像本应通过“成为自己”吸引粉丝，但在投票制里，越想获得职业资格，就越必须先把自己改造成“最容易被公众投票认可的版本”。**

因此形成：
zn → x并z → n投票 → xn资格 → 再反写zn。

## 5组补子
- xn+z：长期梦想被拆成明确比赛阶段。
- zn+x：真实自我与职业可用能力/身体条件对照。
- x并z+n：候选公众形象完全依赖节目与观众网络。
- zx+nx：主动竞争与被票数安排并存。
- xz+nz：职业命运由公众支持关系决定。

## 偶像机制
- 选秀：核心。
- 地区预选 / 本选：明确。
- reality show：核心。
- LIVE配信 /纪录影像：明确。
- 用户投票：决定胜负的唯一机制。
- 出道：胜出后正式出道。
- 竞争：极强。
- 团体长期运营：漫画版不是主轴。
- 偶像职业度：9/10。

## 欲望与代价
- 表层欲望：赢下选秀、获得出道。
- 深层欲望：证明“我的歌/我的人格值得被公众选中”。
- 成功代价：必须把私人自我持续公开、比较、量化。
- 失败代价：不只是一次考试失败，而是公众票数以规模化方式否定其职业资格。

## 与已有样本差异
### vs Idol × Idol Story!
- Idol × Idol Story!：重心在失败者重新进入大型选拔、修复偶像本体。
- SELECTION PROJECT：重心在**公开投票机器如何直接生产出道资格**。

### vs MAVE: Another World
- MAVE更重“失败连坐 + 第二次与灾难关联者共同参赛”。
- SELECTION PROJECT更纯粹，可作为“reality audition = 公众职业裁决机器”的基础样本。

## 可复用母题
**你不是先成为职业者，再接受公众评价；而是必须先被公众评价，才有资格成为职业者。**

## 矿级
**A+。**
原因：职业机制极纯、选秀结构非常清楚，但漫画版重点偏前日谭，长期团体运营与出道后职业链不如S级样本完整。

# R19新增理论摘要

## 新母型 O｜私人关系侵蚀职业资格
《アイドル失格》：应援关系原本生x并z；一旦粉丝关系私人化，nz功能翻转，开始反克x并z。

## 新母型 P｜公众投票授予职业资格
《SELECTION PROJECT》：z梦想 → zx参赛 → xn赛制 → x并z候选形象 → n公众投票 → 出道资格。

## 本轮去重结论
- 不再增加“系统死亡条件/重生再出道”样本。
- 本轮专门补两个此前缺口：
  1. **偶像私人生活如何直接破坏职业身份。**
  2. **观众如何直接成为职业资格授予者。**
