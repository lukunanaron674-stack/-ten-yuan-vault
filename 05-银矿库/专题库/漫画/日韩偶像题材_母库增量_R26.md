# 1. 《22/7》｜日本原创TV动画｜S

## 基础
- 主视角：滝川みう等8名少女。
- 职业入口：收到艺能事务所 G.I.P. 的神秘信件，被集中到地下极秘设施，直接被告知将作为偶像组合进行 major debut。
- 决策核心：神秘“墙”持续吐出指令牌，命名组合、安排审查、初Live、活动，甚至后期直接下令解散。
- 是否真正进入偶像职业：**是，而且训练、审查、Live、写真、Festival、媒体活动、粉丝、事务所、解散会见均进入主线。**

## 新母型
### 黑箱选拔 / 不透明权威授予型偶像生成

核心不是“我想当偶像，所以参加公开选拔”，而是：

**一个不解释标准、也不接受质疑的权威先宣布：你被选中了。**

公式：
**nx黑箱选中 → x并z身份先授予 → xn连续实践 → n/nz关系沉淀 → zn追问 → zx主动认领 → 新x并z**

矿核：
> **黑箱可以宣布“你是谁”，却不能替你完成“你为什么要继续成为这个人”。**

## 顺序
**`nx → x并z → xn → n → nz → zn → zx → nx反咬 → zx维护 → 新x并z`**

1. nx：神秘信件把成员召集到完全陌生的职业入口。
2. x并z：先被告知“你们将作为偶像组合major debut”，身份先成立。
3. xn：第二道指令就是审查，随后训练、初Live、写真、Festival持续加工。
4. n：原本只是同样“被选中”的陌生人逐渐形成组合结构。
5. nz：队友与粉丝关系让22/7不再只是行政项目。
6. zn：成员开始问“这个身份对我究竟意味着什么”。
7. zx：从照做转成自己选择维护组合。
8. nx反咬：“墙”突然直接下令解散，证明创造身份的权力也想垄断删除权。
9. zx维护：即使最初并非以偶像梦想入行，成员仍不接受组合被一键抹掉。
10. 新x并z：22/7开始从“墙的造物”变成“成员自己认领的共同身份”。

## 偶像身份如何建立
1. **身份先于欲望**：みう甚至还无法想象“偶像的自己”，却已经被纳入出道项目。
2. **权威直接命名**：“墙”吐出的金属牌直接为8人命名“22/7”。
3. **制度先授予位置**：成员尚未证明能力，先获得偶像候选/组合成员的外部社会身份。
4. **实践补做合法性**：审查、训练、初Live、活动与粉丝回应才慢慢把空标签做实。

## 偶像职业机制
### 训练
初披露Live日期由“墙”指定后，成员进入连续高强度训练；被指定为center的みう因跟不上而暴露“职位先到、能力后补”的张力。

### 出道
不是公开海选竞争后获得资格，而是先由黑箱权威宣布将major debut，再通过后续审查与训练验证。

### 竞争 / 审查
第二条墙指令即“举行审查会”。成员面对成年评审者，能力差距立即显形。重点不是单纯淘汰，而是**必须满足一套自己看不到完整标准的评价系统**。

### 舞台
初披露Live、Idol Tokyo Festival、写真拍摄等活动都由墙指令驱动。舞台既是成长场，也是黑箱系统的实验场。

### 粉丝
最初是系统生产出的观看者，后来却成为真实关系。到了被命令解散时，粉丝记忆已经无法随制度命令一起删除。

### 公司 / 权力
G.I.P. 是执行层，“墙”才是最终决策层。其权力来源不可见、规则不可解释，甚至工作人员本身也服从命令。

偶像职业度：**9.5/10**。

## 主角欲望与代价
### 初始欲望
みう并非典型“我要成为顶级偶像”的梦想型起手。她在审查阶段甚至仍无法想象偶像状态下的自己。

### 欲望生成
本作最值得留的是：

**职业并非由成熟欲望启动，反而是职业实践逐渐生成欲望。**

`先被选中 → 先做 → 做久 → 形成关系 → 开始在乎 → 最终产生“即使没人命令，我也不愿失去”的主动欲望。`

### 代价
- 必须接受不可解释的评价与命令。
- 个人意愿经常让位于系统要求。
- 公众身份越强，越难回到原来的封闭生活。
- 团队与粉丝关系一旦成立，退出就不再只是离职，而是切断真实共同体。

## 关系结构
- **墙 → 成员：nx/xn极强**。授予身份、下达任务、决定职位，甚至宣布解散。
- **G.I.P. → 成员：制度中介**。负责执行，但并不掌握最终定义权。
- **成员 ↔ 成员：n → nz**。从被系统拼在一起，转为真正共同体。
- **成员 ↔ 粉丝：x并z ↔ nz**。观看赋予公众身份社会真实性，真实回应又提高成员的退出成本。
- **成员 → 墙：zx反向夺权**。后期成员开始争夺“22/7究竟属于谁”的定义权。

## 动态链
### A｜黑箱授予链
**nx召集 → x并z命名 → xn审查 → xn训练 → 舞台验证 → n/nz公众承认**

### B｜被动转主动链
**被选中 → 不理解 → 被迫执行 → 形成关系 → 开始在乎 → 主动维护**

核心规则：
**nx并不只会压制zx，长期实践与关系沉淀也可能反过来孵化zx。**

### C｜造物反叛链
**系统制造组合 → 系统持续命令 → 组合长出n/nz → 系统宣布用毕/解散 → 造物拒绝被删除**

公式：
**外部x并z → n真实化 → zn认领 → zx夺回定义权**

## 反咬点
### 1. 选拔合法性反转
开始：
**“墙选中了你，所以你有资格成为偶像。”**

后来：
**“你持续行动真正成为偶像，所以反过来证明墙当初没有选错。”**

黑箱权威反而需要被选中者用后续人生为它补做合法性。

### 2. 创建身份的系统，也要求拥有删除身份的权力
第10话“墙”直接下达22/7解散命令，G.I.P.关闭，成员被迫开解散会见。

因此显性问题是：
> **创建者是否天然拥有删除一个已经真实化身份的权力？**

### 3. 实验对象产生不可撤销关系
第12话揭示，成员过去的一切活动都是“墙”的实验，她们被宣告“用済み”。但实验可以结束，已经形成的友情、粉丝记忆、舞台历史却不能被一键撤销。

**制度结束 ≠ 社会事实消失。**

## 视觉符号
- 神秘信件：外部选择第一次侵入日常。
- 地下极秘设施：职业入口被放在不可见权力空间。
- “墙”：无脸的决定权。
- 墙吐出的金属指令牌：xn/nx最直接的物质化符号。
- 八名陌生少女并排：组织先于共同体。
- 审查会成人目光：被评价位置。
- center站位：被指定责任。
- 解散会见稿：甚至“如何描述自己的消失”也被机构规定。
- 空事务所 vs 成员重聚：制度空间可以消失，关系空间仍能重建。

## 可复用母题
### ① 黑箱选拔
算法、神谕、AI、委员会、遗物等突然宣布“你就是候选者”。

### ② 身份先于欲望
角色先成为某职业成员，之后才追问自己究竟想不想成为。

### ③ 不透明评价社会
角色必须适应一套永远无法看见完整评分标准的规则。

### ④ 造物获得主体性
机构临时拼出来的团队，经长期共同实践后获得自己的意志与关系。

### ⑤ 创造权 ≠ 删除权
机构可以创建职位、团队、项目，却未必有权把已经形成的社会身份完全抹除。

### ⑥ 黑箱只能授予入口，不能完成本体
最终公式：
**nx选中 → x并z先授予 → xn实践 → n/nz沉淀 → zn追问 → zx认领 → 新x并z**

## 矿级
# S

理由：
1. 从非偶像进入偶像职业的链条清楚。
2. 训练、审查、Live、Festival、写真、粉丝、公司、解散均参与主线。
3. “黑箱决定职业身份”是此前母库中尚未独立成型的发动机制。
4. 创建身份与删除身份由同一系统掌握，天然产生强反咬。
5. 可直接迁移到算法招聘、神谕勇者、AI配职、秘密特工、学校分班、实验项目等非偶像题材。

## 本轮一句话矿核
> **黑箱可以先宣布“你是谁”，但只有持续行动、关系和主动认领，才能把判词变成本体；而一旦本体成立，创造它的系统也未必还拥有删除它的权力。**
