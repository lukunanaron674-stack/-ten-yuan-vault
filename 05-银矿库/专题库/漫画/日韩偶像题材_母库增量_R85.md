# 1. AKB0048｜日本原创TV动画｜S

## 作品与媒介
- 日本原创TV动画，2012年首季，后续《next stage》。
- 主角群：本宫凪沙、园智惠理等77期研究生。
- 核心前提：宇宙时代由DGTO实施“芸能禁止法”，多数地区禁止歌唱、偶像与娱乐活动。AKB0048以高风险游击Live继续活动。

## 偶像身份如何建立
凪沙等少女小时候在禁娱地区看见AKB0048的非法/游击Live，先由“被看见的禁忌舞台”产生职业憧憬；得知AKB0048举行audition后，主动离开原生活空间参加选拔。二次审查甚至不是普通唱跳，而是护卫真实游击Live；合格后成为研究生，再经历剧场前座、强袭Live、研究生公演、综艺、总选举等职业过程。

所以职业入口不是：
**喜欢唱歌 → 找公司 → 正常出道。**

而是：
**看见被禁止的职业 → 明知风险仍主动进入 → 先学会在敌对社会条件下让职业行为存活 → 再成为偶像。**

## 新母型
### 禁止职业 / 抵抗职业化型

公式：
**xn社会禁令 → nz禁忌舞台感召 → zx越界选择 → x并z非法候选身份 → xn内部训练制度 → x职业能力增长 → n共同体绑定 → nx外部镇压升级 → zx继续公开行动 → 新x并z抵抗型职业身份。**

核心不是“职业很辛苦”，而是：
> **这个职业本身被外部制度判定为不该存在。**

于是“成为偶像”同时意味着：
1. 学会唱跳、舞台、粉丝营业；
2. 学会在警戒、抓捕、战斗与撤离条件下继续表演；
3. 接受自己每一次公开职业行为都可能同时成为政治/社会事件。

## 十元体量
- xn｜10：外部禁娱法 + 内部研究生/audition/剧场/总选举/袭名等双重制度。
- zx｜10：明知非法与危险仍主动参加、继续演出。
- nx｜10：法律、军队、抓捕、封锁、舆论操控持续反压。
- x并z｜10：普通少女→研究生→AKB0048成员，同时获得“被禁止但被公众辨认”的社会身份。
- n｜9：研究生、正式成员、护卫、粉丝共同体使职业能够在敌对环境中持续。
- nz｜9：幼年舞台感召、粉丝支持、被压制地区观众的期待不断提供意义。
- x｜9：唱跳、现场应变、护卫/生存能力都进入有效职业能力。
- zn｜9：问题从“我想不想当偶像”升级为“我愿不愿承担这种职业所代表的公共意义”。
- z｜9：被禁止地区、前代游击Live、每次镇压都不断积累职业历史。
- xz｜8：宏观政治环境与暴力风险构成强命运压力。

**体量：`xn10 / zx10 / nx10 / x并z10 / n9 / nz9 / x9 / zn9 / z9 / xz8`**

## 顺序链
**`xn禁令 → nz感召 → zx越界 → x并z候选 → xn内部训练 → x增长 → n共同体 → nx镇压 → zx再确认 → 新zn / 新x并z`**

1. 外部社会先宣布“娱乐不该存在”。
2. 主角却被一次禁忌Live打动。
3. 感情承认转成主动职业欲望。
4. 她跨过法律与家庭/地域限制参加audition。
5. 进入AKB0048内部研究生制度。
6. 能力从“喜欢偶像”变成“能执行偶像工作”。
7. 团体和粉丝使职业获得持续性。
8. 外部镇压升级，职业风险越来越高。
9. 角色必须再次选择：知道真实代价以后还做不做。
10. 第二次选择把偶像从梦想转成职业本体。

## 五维
### 时间｜xn+z：10/10
法律制度与AKB内部制度双线长期作用；每次游击Live、研究生公演、总选举都累积为不可撤销职业史。

### 本体｜zn+x：10/10
角色最终不能只回答“我会不会唱跳”，而要回答：当唱跳本身会招致追捕、会影响他人时，我还认不认领“偶像”作为自己的身份。

### 空间｜x并z+n：10/10
合法娱乐区、完全禁娱星球、AKB剧场、游击Live现场不是背景差异，而是直接决定同一职业行为是工作、犯罪还是公共抵抗。

### 因果｜zx+nx：10/10
主角越主动公开行动，外部镇压越强；镇压越强，又越逼迫她确认职业欲望是不是只停留在憧憬。

### 命运｜xz+nz：9/10
宏观禁娱制度制造命运压力；粉丝与成员关系则让主体产生继续冒险的理由。

## 偶像职业机制
- audition：极强，且二次审查直接包含真实游击Live护卫。
- 训练：极强，唱跳与战斗/生存训练并存。
- 研究生制度：强。
- 剧场前座/研究生公演：强。
- 强袭/游击Live：本作核心。
- 粉丝：强，既是情感支持，也是被禁娱乐传播的目标群体。
- 综艺/摄影/总选举：明确存在，说明即使处于抵抗结构中，偶像工业内部的商业/公众评价机制仍继续运行。
- 公司/组织：AKB0048同时承担艺能事务所、训练机构、行动组织三重功能。
- 竞争：研究生、选拔、总选举、center/袭名竞争并存。
- 舞台：不是安全终点，而是高风险行动现场。

## 主角欲望与代价
### 欲望
最初是“我也想成为那些在黑暗中发光的人”。

### 代价
- 离开原本安全生活；
- audition过程即遭武装力量追捕；
- 职业训练同时承担战斗/撤退风险；
- 家庭、故乡与职业选择发生冲突；
- 成功越高，越成为外部权力明确打击对象。

## 关系结构
### 偶像→少女
先是nz感召：禁忌舞台把“偶像可能性”传给下一代。

### 研究生↔研究生
n共同体 + 同位竞争：共同承担危险，又争取舞台、选拔与位置。

### 偶像↔粉丝
不是单纯消费关系。被禁娱地区的粉丝可能冒风险观看，偶像也冒风险去送达舞台。

所以形成：
**双方共同承担“让这个职业存在”的成本。**

### 偶像↔外部制度
不是普通公司管理，而是职业存在权本身的冲突。

## 动态链
### 生链1：禁令反向制造职业意义
**`xn禁止 → 稀缺/禁忌化 → nz感召增强 → zx越界 → x并z抵抗身份`**

### 生链2：关系把高风险职业维持住
**`n/nz → zx持续 → z共同历史 → zn职业认领`**

### 克链1
**外部xn/nx 克 x并z**：法律直接试图删除偶像身份的社会存在空间。

### 克链2
**zx 克 nx**：主动游击Live不是取消法律，而是在法律压迫下硬制造临时职业空间。

### 反咬链
**`xn越禁止 → 职业越象征化 → x并z公共意义越强 → 外部nx镇压再升级`**

即：禁止本来想让偶像消失，结果反而把普通娱乐职业塑造成抵抗象征；越成为象征，越会被当局视为威胁。

## 最大反咬点
### 1. 禁止职业，反而扩大职业意义
如果偶像只是普通娱乐，舞台主要负责快乐与商业结果。

一旦被禁：
**唱一首歌 = 公开拒绝“这个东西不该存在”的制度判断。**

所以：
> **xn试图删除x并z，反而让x并z获得更高社会象征密度。**

### 2. 职业成功同时提高被打击价值
**观众越多 → 影响越大 → 职业越成功 → 当局越需要阻止。**

因此成功不只生nz，也同步生nx。

### 3. 舞台从“展示能力”变成“制造临时自由空间”
在完全禁娱星球，Live持续的几十分钟，本身就是临时改变当地规则现实：原本不能公开唱、不能公开观看，现在观众和偶像共同让这件事发生。

所以舞台可以定义为：
**zx + n/nz 暂时克服外部xn，生成临时x并z空间。**

### 4. 训练标准被环境重写
普通偶像训练：唱、跳、表情、营业。
AKB0048：还必须面对警报、护卫、撤离、战斗与突发中断。

得到：
> **职业环境改变，不只提高难度，还会改变“什么算职业能力”。**

## 视觉符号
- 黑暗禁娱城市 / 熄灭招牌 ↔ 突然点亮的游击舞台。
- 荧光棒观众 ↔ 武装DES军包围。
- audition号码牌 ↔ 护卫装备。
- 漂亮舞台服 ↔ 战斗/撤退场景。
- 舞台聚光灯穿透警戒线。
- 研究生剧场前座 ↔ 完全禁娱星球强袭Live。
- 粉丝伸手应援 ↔ 军队试图把人群驱散。

## 可复用母题
1. **被禁止的职业**：职业本身被法律/宗教/组织判定不应存在。
2. **职业即抵抗**：正常完成工作动作就已经是对制度的反抗。
3. **高风险舞台**：舞台不是安全展示区，而是职业与外部权力真正冲突的现场。
4. **禁令反向增值**：越禁止，职业越获得象征意义。
5. **成功生双反馈**：成功同时生成nz支持与nx打击。
6. **临时自由空间**：公开职业行为短暂创造一个与外部规则不同的小社会。
7. **职业能力环境化**：当外部环境恶化，职业能力定义本身会扩张。

## 与已有样本边界
### vs R25《AKB0048 EPISODE0》
R25：职业名号继承、袭名制、职位跨代连续。
R85：**娱乐被禁止后，成为偶像本身就是越界行动；核心是职业存在权。**

### vs R44《Macross Δ》
R44：歌唱具有公共功能，因此成功带来公共责任。
R85：歌唱不一定天然拥有公共功能，**是外部禁止把普通娱乐行为政治化/抵抗化。**

### vs R20《PriPara》
R20：现实空间禁止儿童参加，第二空间允许，重点是双重规则空间。
R85：不是换到合法空间，而是**主动进入被禁止地区继续完成职业行为。**

## 5组补子
- xn禁令 ↔ zx越界：规则越封闭，主动行动越具有方向性。
- x并z偶像身份 ↔ zn私人认领：社会把她定义为非法娱乐者，主体却重新定义“偶像为何值得成为”。
- nz粉丝支持 ↔ nx当局镇压：同一成功同时从两边增加压力。
- n共同体 ↔ x个人能力：团队既保护个人，也把个人能力放进高风险公共行动。
- z前代游击史 ↔ 新zx：前代已经证明职业能活下来，后来者必须重新决定自己是否继续。

## 矿级
# S

理由：
1. “成为偶像”从第一话audition动机开始贯穿，职业成长不是装饰。
2. audition、研究生、剧场、强袭Live、综艺、总选举等行业机制密度高。
3. 新机制与R25明显分离：不是袭名继承，而是**职业存在权冲突**。
4. 可复用到大量职业题材：地下乐队、禁书作家、被封杀画师、非法剧团、被禁止的宗教歌者、被政权封锁的主播/记者等。
5. 对十元尤其有价值：外部xn并非只塑造职业，而可能试图删除职业；zx+n/nz可以在局部重新制造职业空间。

## 本轮矿核
> **最极端的职业成长，不是“别人觉得你不够好”，而是整个社会规则宣布“这种职业本来就不应该存在”。这时成为职业者不再只是学会技能，而是反复在禁止中把工作真正做出来；每一次成功既增加支持，也增加镇压力度。职业因此从谋生和梦想，升级成对“这个社会允许什么样的人存在”的直接回答。**
