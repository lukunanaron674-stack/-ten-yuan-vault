# 1. 《トラペジウム / Trapezium》｜日本小说→动画电影｜S

## 一、偶像身份如何建立
主人公东ゆう从一开始就明确抱有“绝对要成为偶像”的欲望，但她没有先去等待星探、事务所或选秀给入口，而是自己制定四条行为规则：不做SNS、不交男友、在学校不显眼、主动去结识位于东南西北不同学校的漂亮女孩。

她真正隐藏的计划是：

> **先人为制造一个具有强识别度的“东南西北四人组”，再把这个组合推入媒体与艺能工业。**

因此职业身份建立链不是：

`素人 → 被选中 → 组合`

而是：

`个人职业欲望 → 自己设计组合概念 → 主动寻找成员 → 制造共同活动与社会可见性 → 媒体注意 → 艺能事务所/出道项目介入 → 偶像身份正式化`

这是母库此前较少见的**“主体先做制作人，再把自己生产成产品成员”**。

| 十元 | 体量 | 本作功能 |
|---|---:|---|
| zx | **10** | 主角从零主动设计整个偶像计划，是绝对发动元 |
| n | **10** | 她必须主动生产四人关系，组合不是现成制度分配 |

| xn | **9** | 媒体、事务所、工作与偶像行业规则接手并反压 |

| nz | **9** | 友情、公众好感与真实情感不断和最初的工具关系缠在一起 |

**主元：zx + n + x并z**

这是一个非常纯的：

> **主动性生产关系，关系再生产公共身份。**

## 三、顺序

主链：

**zx → n → x并z → z → nz → xn → nx → zn冲突 → zx再选择 → 新x并z**

展开：

1. **zx**：ゆう决定绝对要成为偶像，并制定长期计划。
2. **n**：她不是等待队友，而是主动跨学校挑选并接近三名女孩。
3. **x并z**：人为制造“东南西北四位美少女”的可传播组合概念。
4. **z**：机器人比赛、文化祭、志愿活动等共同经历不断累积。
5. **nz**：原本带有企划目的的接近，逐渐长出真实友情。
6. **xn**：电视节目、制作人员、艺能事务所开始把四人正式纳入娱乐工业。
7. **nx**：工作、公众评价、成员承受力和项目期待开始反过来约束主角。
8. **zn**：主角必须回答“她们到底是我的朋友，还是我为了偶像梦挑中的资源”。
9. **zx再选择**：不能再只靠最初的计划强推，而必须重新决定自己如何面对梦想与他人。
10. **新x并z**：职业身份从“我设计出来的偶像计划”转成“现实社会已经承认并产生后果的偶像身份”。

## 四、五维

### 时间维｜xn + z：9/10
主角不是通过一次audition偶然入行，而是从高一开始长期执行计划。重要的是：

> **最初为了企划刻意制造的共同经历，时间久了以后会变成真的共同历史。**

这使“假自然”与“真关系”越来越难区分。

### 本体维｜zn + x：10/10
核心本体问题：

> **如果我是真心喜欢这些朋友，但我最初确实是因为她们适合我的偶像计划才接近她们，这段友情到底真不真？**

它把“职业野心”直接插入关系本体。

### 空间维｜x并z + n：10/10
四个人来自东、西、南、北四个不同学校。主角把地理差异主动包装成组合识别度。

这说明：

> **空间差异本身可以被zx重新编码成x并z品牌资产。**

### 因果维｜zx + nx：10/10
前半几乎全是主角zx推动；真正成功以后，因果反向：

`我控制项目 → 项目成功 → 项目开始控制我`

### 命运维｜xz + nz：8/10
没有系统或超自然强迫，真正产生“不可回头感”的，是已经形成的友情、公众认知和职业机会。

## 五、训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 训练
本作不以传统练习室训练为起点，前期更重要的是：
- 社交组织能力
- 角色观察
- 组合概念设计
- 四人共同活动的持续经营
- 让彼此关系足够自然、足够具有媒体可见性

这本身就是一种**“出道前项目开发”**。

### 出道
不是直接audition中选，而是：

`地方共同活动 → 媒体发现 → 工作逐渐增加 → 事务所所属 → 正式偶像Debut Project启动`

官方STORY明确写到四人因志愿活动受到关注、获得电视出演机会，遇见节目制作AD后逐渐得到工作，最后正式启动“东南西北”的偶像出道项目。

### 竞争
核心竞争不是传统排名，而是：
- 与成熟娱乐工业标准的竞争
- “能否承受职业化”的成员内部差异
- 主角的偶像欲望与其他成员自身人生目标之间的冲突

### 舞台
舞台不是第一推动，而是项目正式职业化以后对前期设计的真实性检验。

### 粉丝 / 公众
公众最初并不知道四人关系和组合概念是被主角主动设计的，因此公众反馈会进一步强化：

**人为企划 x并z → 被公众当成自然组合 → nz增长 → x并z社会实化**

### 公司 / 媒体
媒体与事务所不是创造项目的第一主体，而是**识别并放大一个已经由主角自行搭好的雏形**。

这是本作区别于传统星探故事的关键。

## 六、主角欲望与代价

### 欲望
**“我绝对要成为偶像。”**

而且不是模糊愿望，而是会主动设计多年行动路径的高强度zx。

### 代价
她真正付出的不只是训练时间，而是：

> **为了让梦想成功，她开始把人与关系也纳入自己的计划。**

于是职业欲望会侵入：
- 交朋友的动机
- 选择朋友的标准
- 对朋友未来的想象
- 对他人是否必须一起成为偶像的期待

这就是最重要的代价：

> **职业计划开始殖民私人关系。**

## 七、关系结构

### ゆう → 其他三人
初始：
**zx企划者 → n目标成员**

中期：
**企划关系 + 真友情并存**

后期：
**真友情反过来审判最初的企划动机**

### 工藤真司
属于“知道主角企划、协助其执行”的共谋型n。

功能不是替主角决定，而是让主角的zx更容易落到现实。

### 媒体/事务所
从外部观察者转成职业放大器：

**发现既有社会素材 → 包装 → 工作化 → 偶像化。**

## 八、动态链

### 动态链A｜自我企划职业生成
**zx职业欲望 → n主动选人 → x并z组合概念 → z共同经历 → 媒体发现 → xn职业化 → 新x并z偶像团**

### 动态链B｜工具关系真实化
**为了计划接近别人 → 长期共同生活/活动 → nz真实友情 → 原始工具动机被关系反咬 → zn冲突**

### 动态链C｜项目反控主体
**我设计项目 → 项目成功 → 工作/公众/成员期待形成 → nx上升 → 我开始失去单方面修改项目的自由**

### 动态链D｜品牌概念反噬成员
**东南西北四美少女概念 → 公众容易识别 → 项目成功 → 成员被固定成“组合角色” → 各自原本人生目标受到挤压**

## 九、最大反咬点

### 反咬1｜为了成为偶像而交朋友，最后朋友不能再被当作“偶像材料”
最初：

**选成员是计划。**

后来：

**成员已经成为真实朋友。**

因此：

> **n一旦通过z长期沉淀成真实关系，就会反过来限制最初产生它的zx。**

即：

**zx生n → n成熟 → n反约束zx**

这是本轮最重要的新十元规则。

### 反咬2｜项目越成功，企划者越失去绝对控制权
只在纸面计划阶段，ゆう可以决定所有事。

但一旦：
- 成员产生自己的意愿
- 公司投入资源
- 公众形成期待
- 工作真实发生

这个项目就成为社会事实。

因此：

> **创建权 ≠ 永久控制权。**

### 反咬3｜“为别人设计梦想”会触碰本体边界
ゆう相信这些漂亮女孩如果成为偶像会闪耀。

问题是：

> **“我认为你适合成为谁”，并不等于“你自己想成为谁”。**

所以外部识别x与主体zn之间会冲突。

### 反咬4｜高zx也可能伤害n
十元里zx通常容易被理解成积极行动力，本作给出一个很好的阴影面：

> **主动性过强时，会把关系中的别人逐渐视为因果链零件。**

因此：

**zx过量 → n工具化 → nz受损 → zn反噬**

## 十、视觉符号

1. **东/西/南/北四所学校与地图方位**：把空间差异视觉化成品牌结构。
2. **主角的四条自律规则**：职业欲望先侵入私人生活。
3. **主角独自观察/挑选成员 ↔ 四人真正笑在一起**：工具关系→真实关系。
4. **机器人比赛、文化祭、志愿活动**：刻意制造的共同事件逐渐变成真实z。
5. **地方普通活动 ↔ 电视镜头**：社会可见性跃迁。
6. **四人普通学生服 ↔ 统一偶像舞台形象**：x并z职业包装形成。
7. **镜头中心的ゆう ↔ 其他成员疲惫/迟疑**：主角zx与他人zn错位。
8. **东南西北四点汇聚成一个中心舞台**：最适合作为本母型的总视觉符号。

## 十一、可复用母题

### 1. 自我企划型职业生成
不是等别人发现我，而是：

**我先创造一个值得被行业发现的项目，再让自己成为项目成员。**

可迁移：
- 画师自己组建创作社团，再以主创身份职业化
- 乐手先组概念乐队，再找厂牌
- 游戏开发者先拼团队/做Demo，再找发行
- 演员自己组剧团，再进入正式演艺网络

### 2. 主体既是产品又是制作人
角色同时拥有：

**“我想被看见”**
与
**“我知道怎么让这个组合被看见”**。

### 3. zx生产n，n反约束zx
这是本轮最值得跨题材复用的一条：

> **主动建立的关系一旦变真，就会获得自己的道德重量和行动惯性。**

### 4. 人被企划化
将成员的学校、性格、地理位置、外貌差异重新编码成组合卖点。

反咬：

> **标签能增加可传播性，也会压缩成员被允许变化的空间。**

### 5. 计划成功反而制造失控
项目越失败，企划者越能随时撤销。

项目越成功，牵涉的人越多，越不能单方面结束。

### 6. “我知道你适合什么”不等于“你想要什么”
适合做偶像是x/x并z判断；想不想做偶像是zn/zx问题。

两者必须分开。

## 十二、与既有母型边界

### vs Aikatsu!
Aikatsu!：
**看见榜样 → 产生偶像欲望 → 进入既有培养制度。**

Trapezium：
**已经有极强偶像欲望 → 不等制度入口 → 自己先设计组合项目。**

### vs Love Live!
Love Live!：
**为了救学校创造校园偶像团，职业最初是解决外部危机的工具。**

Trapezium：
**成为偶像本身就是主目标，因此主动创造组合只是为了制造自己的职业入口。**

### vs Wake Up, Girls!
WUG：
**事务所为了生存先创造偶像团。**

Trapezium：
**候选偶像本人先承担了部分制作人功能，自己创造可被事务所接手的团体雏形。**

### vs Aikatsu Friends!
Aikatsu Friends!：
**已有两个偶像通过关系生成第三个组合身份。**

Trapezium：
**主角从素人阶段就有意识地设计n，以n制造未来x并z。**

## 十三、矿级

**S矿**

理由：
1. “成为偶像”是主角明确且持续的核心欲望，不是娱乐圈恋爱附属线。
2. 作品完整研究了从非偶像到组合企划、媒体曝光、事务所与正式出道项目启动的过程。
3. 新机制与现有母库差异足够大：重点不是训练制度，而是**职业者自己预先承担制作/组队/品牌设计功能**。
4. “关系工具化→关系真实化→真实关系反咬职业野心”具有很高的跨题材复用价值。

# 本轮新增正式母型

## 「自我企划 / 先造项目再把自己职业化型」

母链：

**强职业欲望 → 自己设计项目 → 主动选人 → 制造关系与概念 → 累积共同历史 → 获得媒体可见性 → 行业接手放大 → 项目正式职业化 → 成员真实意愿反咬最初计划 → 主体重新处理梦想与关系**

## 本轮矿核

> **有些人不是先被行业选中才开始成为职业者，而是先把自己当成制作人：设计团队、设计概念、设计被看见的路径，直到行业终于注意到这个已经长出雏形的项目。可真正危险的地方也从这里开始——项目里的人一旦成为朋友、拥有自己的欲望和共同历史，他们就不再是计划表里的零件。主体亲手制造的n，最后会获得足够重量，反过来限制最初那个无比强大的zx。**
