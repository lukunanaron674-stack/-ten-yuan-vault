# 日韩偶像题材母库增量 R88｜Tokyo 7th Sisters

## 作品信息
- 作品：**Tokyo 7th Sisters / Tokyo 7th シスターズ**
- 媒介：日本手游 → 动画电影 / 多媒体偶像企划
- 核心样本等级：**S矿**
- 本轮新增母型：**职业退潮复兴 / 被宣布过时的职业再生成型**
- 去重说明：与 R60《Idol Time PriPara》的“地方市场冷启动”、R80《少年Hollywood》的“固定剧场重复实践”、R85《AKB0048》的“禁止职业”区分。

## 一、偶像身份如何建立
故事发生在2034年的“偶像冰河期”。传奇国民偶像 Seven Sisters 于2032年突然引退后，社会普遍形成“偶像已经结束”“偶像已经过时”的判断。次世代剧场型工作室 777（Nanastar）也门可罗雀。

主角侧并不是进入一个仍然繁荣的偶像产业，而是在**职业本身已经失去时代合法性**的环境里重新寻找新人、训练、组织 Live，并逐步让“新一代偶像”重新成为可被社会认真看待的职业身份。

典型入口：二代支配人与经理 Connie 外出进行 Scout。第一位重要候选春日部 Haru 甚至是来应聘清扫兼职的普通16岁少女，面对偶像邀请直接说“最讨厌偶像”。这说明职业欲望并不是所有成员的预设起点，而可能在实际活动、关系与公众反馈后生成。

## 二、十元

### 主元
- **z：10** —— 前代黄金期、Seven Sisters 引退、产业衰退史持续压住现在。
- **x并z：10** —— “偶像”已被社会贴成过时职业；Nanastar、777☆SISTERS需要重建公共职业位置。
- **zx：10** —— 在行业退潮时仍主动 Scout、训练、办 Live、救剧场。
- **xn：10** —— Scout、Lesson、Live、剧场运营、出道、舞台与市场反馈持续形成职业制度。

### 次元
- **n：9** —— 新一代 Sisters 的共同体不是继承来的，需要重新组织。
- **nz：9** —— 少量观众、粉丝与旧偶像记忆重新转成对新人的支持。
- **nx：9** —— 市场冷却、“过时”标签、空场、剧场经营压力、设施危机持续反压。
- **zn：9** —— “这个时代还需要偶像吗”“我为什么还要成为偶像”进入本体。
- **x：9** —— 歌、舞、表达、舞台能力必须在低期待环境中重新证明有效。
- **xz：7** —— 宏观时代衰退与前代突然退场形成强命运背景，但非纯超自然强迫。

## 三、体量排序
**z10 / x并z10 / zx10 / xn10 / n9 / nz9 / nx9 / zn9 / x9 / xz7**

### 核心主次关系
**主：z + x并z**

社会历史先宣布：
> “偶像已经是过去式。”

角色的行动则必须重新回答：
> “这个职业还能不能拥有未来？”

### 主链
**z行业黄金史/终结 → x并z过时职业标签 → nx市场冷却 → zx重新招募 → n新人共同体 → xn训练/Live → x能力显影 → nz观众回流 → 新z职业历史 → zn职业认领 → 新x并z下一代偶像身份**

## 四、顺序
1. 传奇偶像 Seven Sisters 引退，职业黄金时代结束。
2. 社会形成“偶像已经结束”的公共判断。
3. Nanastar 在冷清状态下继续存在，但职业空间几乎空壳化。
4. 支配人与经理主动外出 Scout，而不是等待成熟练习生送上门。
5. 普通少女被拉进候选体系，其中部分人起初甚至排斥偶像职业。
6. Lesson、组团、Live、出道等实践开始生产新的职业履历。
7. 少量粉丝与观众重新出现，职业身份获得第一批社会回填。
8. 新一代偶像不再只是“过去职业的模仿者”，而开始形成自己的共同体和时代语言。
9. 动画《我们化作青空》中，已经出道的 777☆SISTERS 又面对旧大型剧场 HAKKAKU 关闭危机，并试图靠 Live 满场救下它。
10. 由“新人证明自己”升级为“新人反过来维护偶像职业的历史基础设施”。

## 五、五维

### 时间维｜xn + z = 10/10
前代黄金期并未随着 Seven Sisters 引退消失，而成为一种持续作用的历史压力。新人的每场 Live 都是在“偶像已经结束”这条旧z上写新的z。

核心：
**旧z宣布职业终结 → 新xn重复实践 → 新z累积 → 旧z被重新解释。**

### 本体维｜zn + x = 10/10
成员并非都从“我天生就想当偶像”开始。职业能力和职业欲望都需要在实践中形成。

核心问题：
**当整个时代都说这职业过时，我为什么还愿意成为这种人？**

### 空间维｜x并z + n = 10/10
Nanastar、HAKKAKU、Live现场都不是普通背景，而是“偶像是否仍有社会位置”的物理载体。空剧场与满场直接对应职业合法性的变化。

### 因果维｜zx + nx = 10/10
市场退潮越强，主动行动越难；但只要持续做出真实舞台，社会反馈又会反过来削弱“职业已死”的判断。

**nx职业退潮 → zx继续做 → nz出现 → 新x并z成立。**

### 命运维｜xz + nz = 9/10
前代突然消失造成时代断层，新一代不能复制前代，只能从旧粉丝记忆和新关系中重新找职业未来。

## 六、训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 训练
- Scout后进入 Nanastar 候选/培养体系。
- Lesson 与反复舞台实践承担真正职业化，不靠一次“被选中”完成身份。

### 出道
- 777☆SISTERS 已从候选人成长到正式出道组合。
- 出道并不自动解决时代问题：她们仍处于“偶像冰河期”，必须持续证明职业还有观众。

### 竞争
- 既有同行/组合之间存在舞台与成长竞争。
- 更大的对手其实是**时代判断本身**：大众注意力已经离开这个职业。

### 舞台
- Live 是最关键的职业验证器。
- 动画电影进一步把“能否让 HAKKAKU 满场”设为剧场是否能继续存在的硬条件。

### 粉丝
- 粉丝不是天然存在的资源。
- 新人必须重新让人愿意走进剧场、停留、再次出现。
- 粉丝回流同时证明两件事：这个组合有价值；偶像这个职业仍可能有价值。

### 公司 / 组织
- Nanastar 在行业低谷仍维持 Scout、培养、舞台与组合生产。
- 组织本身承担“保存一个过时职业的火种”的功能。
- HAKKAKU 的关闭危机又显示：职业历史依赖物理基础设施保存，场地消失会切断共同记忆。

## 七、主角欲望与代价

### 欲望
- 支配人/经理：不是维护旧偶像，而是“如果旧偶像时代结束，那就做新的偶像”。
- 新人：从被发现、排斥、犹豫到逐渐拥有自己的职业理由。

### 代价
- 在一个被社会认为“已经没前途”的行业投入青春与时间。
- 必须面对低观众、低资源、旧时代比较和职业本身的合法性怀疑。
- 成功后又要承担维护旧剧场、旧历史和新观众期待的责任。

## 八、关系结构

### 关系1｜前代 ↔ 新人
不是直接师徒。

**前代通过z缺席作用于新人。**

Seven Sisters 的传奇一方面证明偶像曾经可以成立，另一方面又让新人更像“旧时代残余”。

### 关系2｜支配人/经理 ↔ 候选少女
**发现者 → 入口提供者 → 组织者**。

但他们不能替新人生成职业欲望，只能先制造实践条件。

### 关系3｜新人 ↔ 新人
单个候选人很难对抗整个行业退潮，只有形成 n 共同体，才能稳定地产生足够多的舞台、作品和公众事件。

### 关系4｜新人 ↔ 粉丝
粉丝不是成熟产业直接分配来的，而是要从近乎零重新生成，因此每一批早期观众都具有“职业复兴见证者”的意义。

## 九、动态链

### 动态链A｜职业死亡叙事反转
**前代退出z → “职业已死”x并z → 市场nx → 新人zx → Live xn → nz回流 → 新z → 新x并z**

### 动态链B｜怀旧反咬
**前代传奇z → 新人借历史获得注意 → 怀旧nz → 比较nx → 新人若只复制前代则zn被压 → zx形成新表达 → 新x并z**

### 动态链C｜空场到满场
**空剧场x并z → nx低认可 → zx持续演出 → 少量nz → z重复历史 → 观众增长 → 场地社会意义恢复**

### 动态链D｜过时职业的新人欲望后生成
**nx被Scout/被推进入口 → xn真实实践 → x能力增长 → n/nz意义回填 → zn重估 → 新zx“我想继续做”**

## 十、反咬点

### 反咬1｜越依赖怀旧，越难证明职业还有未来
旧偶像历史能帮助新人被注意，但如果新人永远靠“当年的偶像多好”，就只能证明过去有价值，不能证明现在有价值。

**旧z越强 → 初始nz越容易 → 新x并z独立性越难。**

### 反咬2｜复兴职业成功，会让新人承担保存职业历史的责任
新人原本只需要证明“我们能不能当偶像”。

一旦成功，她们又会开始面对剧场、前辈记忆、旧粉丝、行业火种的保存问题。

**职业复兴成功 → 责任范围扩大。**

### 反咬3｜“行业结束”可能变成自我实现预言
没人投资 → 舞台减少 → 新人减少 → 观众更少 → 大家更相信行业已死。

因此第一批复兴者必须用 zx 人工打断这个循环。

### 反咬4｜行业不是靠证明“过去错了”复兴，而是靠生产新历史
不能靠辩论让社会相信偶像仍有价值。

只能：
**再Scout一次、再训练一次、再Live一次、再让一个观众回来一次。**

## 十一、视觉符号
- **Seven Sisters 旧海报 / 旧录像** ↔ **新生777☆SISTERS练习服**
- **门可罗雀的 Nanastar** ↔ **逐渐出现观众的Live**
- **空椅子** ↔ **满座观众**
- **“过时”城市广告与冷清街道** ↔ **新Live灯牌/应援**
- **旧大型剧场 HAKKAKU** ↔ **面临关闭的铁门/收购通知**
- **旧时代的传奇舞台** ↔ **新人在同一职业类型里制造完全不同的新舞台**

## 十二、可复用母题
1. **职业退潮复兴**：社会认为某职业已经没有未来，新人重新让它成立。
2. **职业死亡叙事**：不是角色失败，而是整个行业先被判死刑。
3. **怀旧既是燃料也是牢笼**：前代历史能提供第一批注意，也会制造复制压力。
4. **第一批新人承担双重任务**：既要成为职业者，又要证明职业本身值得存在。
5. **空场→满场作为职业合法性量尺**。
6. **旧基础设施保存职业记忆**：剧场、工作室、社群空间可以成为z的外置存储。
7. **新历史反写旧历史**：无法改变前代退出，但可以改变“那是不是整个职业的终点”。
8. **复兴成功→保存责任**：越成功，越开始承担保护行业生态与历史资产的责任。

## 十三、与既有矿的边界

### vs R60《Idol Time PriPara》
R60：地方缺少职业生态，需要冷启动市场。

R88：不是某地没有市场，而是**整个时代认为这个职业过时**。

### vs R80《少年Hollywood》
R80：已有剧场和团名，新人靠固定剧场反复实践压实自己的身份。

R88：连“偶像是否仍是一个值得做的职业”都需要重新证明。

### vs R85《AKB0048》
R85：职业被法律禁止，因此职业行为成为抵抗。

R88：没有法律禁止，最危险的是**社会已经懒得禁止，因为它认为这个职业自己就会消失**。

### vs R51《LEMON ANGEL PROJECT》
R51：继承一个前代已经成功的品牌名号。

R88：不直接继承前代品牌，而是在前代结束后的行业废墟里重新生产“下一代偶像”。

## 十四、本轮正式分类
# **职业退潮复兴 / 被宣布过时的职业再生成型**

母链：
**前代黄金史 → 职业退潮 → 社会宣布过时 → 基础设施空壳化 → 少数人继续Scout/训练 → 新共同体出生 → 真实Live反复发生 → 第一批观众回流 → 新职业历史累积 → 职业未来重新成立。**

## 十五、矿核
> **最难的“成为偶像”，不一定发生在竞争最激烈的黄金年代；也可能发生在所有人已经懒得竞争、因为他们觉得这个职业根本没有未来的时候。此时新人每一次训练和Live，都不仅是在证明“我配不配成为偶像”，还在证明“偶像这件事有没有资格继续存在”。真正的复兴不是复刻旧黄金时代，而是在旧时代结束之后重新生产一批让人愿意回到现场的新理由。**
