# 1. AKB0048 EPISODE0｜日漫｜S

## 基础
- 地区 / 媒介：日本漫画，讲谈社《なかよし》系。
- 状态：全7卷完结。
- 主角：星名ふれあ。
- 职业入口：AKB学院研究生 → 袭名 audition → 继承“前田敦子”这一传奇 center 名号。
- 是否真正进入偶像职业：**是，且职业机制密度很高。**

讲谈社官方第1卷直接确认：未来的 AKB0048 为维持初代神话性采取“袭名制”；研究生星名ふれあ参加袭名 audition 失败，却意外成为“前田敦子”的继承者。第2卷继续出现宇宙 Live rehearsal、center 替补；第3卷出现后辈对 center 资格的否定；第6卷出现成员退团、转入其他组合并以 center 再出道，以及ふれあ的“前田敦子引退宣言”。

这使它不只是“少女成为偶像”，而是：

**一个人的职业身份，不再完全属于这个人，而被制度设计成可以跨身体、跨世代继承的公共职位。**

## 新母型
### 职业名号继承 / 团体本体制度化连续型

公式：
**前代偶像名号 → 制度保存 → 新成员袭名 → 新身体承担旧公众身份 → 粉丝/团体继续承认 → 个人本体与职位本体发生冲突。**

重点不是“成员替换”本身，而是：
> **团体为了保证自己不会随着成员离开而死亡，把偶像身份从“人”拆成了“可继承职位”。**

成员会毕业、退团、失败、转团，但“前田敦子”这一位置可以继续存在。

## 十元
### 主符号
**x并z｜10/10**
“前田敦子”不是单纯名字，而是被公众观看、被团体历史制造、被制度继承的职业身份壳。新成员进入后，先继承一个已经拥有历史重量的公众形象。

### 次符号
**xn｜10/10**
袭名制、研究生、audition、center、Live、退团、继任，全部由职业制度规定身份如何获得、维持和退出。

**zn｜9/10**
核心本体问题不是“我能不能当偶像”，而是：
**“作为星名ふれあ的我”与“作为前田敦子的我”是不是同一个职业主体？**

### 第三层
- n｜8/10：团体、后辈、粉丝、全宇宙直播与市场承认共同维持袭名身份。
- nx｜8/10：ふれあ并非完全主动选择传奇名号，而是被制度/位置推入继承者角色。
- zx｜8/10：真正站稳 center、组织 Live、回应质疑，都需要个人主动实践把继承来的身份做实。
- xz｜7/10：传奇名号本身形成强烈既定命运压力，继承后个人会被前代历史锁定评价。
- nz｜7/10：幼驯染、成员、粉丝等关系不断决定职业身份是否被真正承认。
- z｜6/10：个人偶像欲望存在，但不是最强发动机。
- x｜6/10：身体是名号的临时承载者，重要但不如制度与公众身份本身。

### 体量
`x并z10 / xn10 / zn9 / n8 / nx8 / zx8 / xz7 / nz7 / z6 / x6`

## 顺序链
**`zn → xn → x并z → nx → zx → n → zn`**

1. 原本只是“星名ふれあ”这一私人本体 zn。
2. 进入袭名制度 xn。
3. 获得“前田敦子”这一既存公众身份 x并z。
4. 继承者被旧名号、center位置与组织期待推入 nx。
5. 必须通过训练、Live、center实践发动 zx。
6. 粉丝、成员、团体、直播观众 n 持续承认这个身份。
7. 公众承认反过来改写她对“自己是谁”的 zn。

## 五维
- 时间｜xn+z：袭名制把历代成员串成职业时间链；个人欲望必须进入代际制度才能继续。
- 本体｜zn+x：真实的人会变，身体会更替，但同一职业名号被当作“同一个偶像位置”延续。
- 空间｜x并z+n：舞台、center位置、团体与粉丝网络共同制造“前田敦子”这一公共身份。
- 因果｜zx+nx：成员一方面被继承制度推入既定位置，另一方面必须靠自己的职业行动证明不是空壳继任。
- 命运｜xz+nz：继承传奇位置意味着背负前代历史与他人期待；关系共同体既可能压迫继承者，也可能让新版本真正成立。

## 生链
**`xn → x并z → n → 新x并z`**
袭名制度产生可继承公众身份；公众和团体承认它；承认又让该职业名号跨世代继续存在。

第二条：
**`zx → n → zn`**
个人通过Live、center实践和职业判断赢得承认，外部认可逐渐反写私人本体。

## 克链
1. x并z 克 zn：传奇公众名号压过继承者原本的私人名字与个体性。
2. xn 克 zn：制度先规定“这个位置应该是谁”，再要求具体的人适应它。
3. n 克 zn：后辈、成员、粉丝会拿“你配不配当这个center”持续评价个人。
4. zx 克 nx：个人职业行动可以把“被迫继承”转化为“我主动完成的身份”。

## 反咬点
**制度原本为了保护团体和传奇偶像的连续性，却可能通过“继承成功”消耗继承者自己的名字。**

如果继承失败：个人被判断为“不配这个名字”。
如果继承成功：公众可能越来越只看见“前田敦子”，而不是星名ふれあ。

所以形成双重陷阱：
**失败 → 名号排斥你。**
**成功 → 名号吞掉你。**

## 条件变化
- 初期：袭名只是制度给予的职业位置。
- 中期：center竞争、Live、后辈质疑让继承者必须真正劳动，位置开始被个人实践重新解释。
- 后期：成员可以脱离原团体、在别团以center重新出道；ふれあ也出现“前田敦子引退宣言”。此时“人是否能退出名号”“名号离开此人后是否继续”成为显性问题。

## 5组补子
- xn+z：袭名、研究生、audition、center制度把私人偶像欲望转成可执行的职业路线。
- zn+x：同一名号跨不同身体继续存在，使“人是谁”与“身体是谁”被拆开观察。
- x并z+n：继承名号只有在团体、粉丝、舞台与社会观看持续承认时才真正成立。
- zx+nx：继承者既被制度选中/推入位置，也必须用主动职业行动证明自己。
- xz+nz：传奇前代形成命运重量，成员与粉丝关系则决定这个重量是变成压迫还是支持。

## 成为偶像的欲望与代价
### 欲望
从“不适合偶像”的研究生位置，获得真正被承认的舞台位置，并证明自己能承担传奇center身份。

### 成功代价
成功越彻底，个人越可能被历史名号、公众期待和团体制度覆盖。

### 失败代价
不是简单“没出道”，而是被证明“不配继承这个职业身份”，个人失败会被放大成对整个传奇名号的失败。

## 与已有样本差异
### vs AKB49
《AKB49》重点是：**个人以秘密身份进入高制度密度偶像体系。**
《AKB0048 EPISODE0》重点是：**制度主动把一个已经存在于历史中的公众偶像身份，安装到新的成员身上。**

### vs U149
U149研究边缘单位如何长期经营并建立职业共同体；本作研究的是**成员替换后，团体/center/偶像名号如何保持本体连续性**。

### vs IDOLY PRIDE类前代影子继承
若前代影子是情感/精神意义上的继承，本作更进一步：**继承被制度正式编码成职业职位和名字本身。**
