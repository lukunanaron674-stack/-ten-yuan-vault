# 日韩偶像题材母库增量 R38

## THE IDOLM@STER SideM｜前职业转译 / 二次职业本体型

- 作品名：THE IDOLM@STER SideM / アイドルマスター SideM
- 媒介：日本偶像养成游戏 → TV动画 / 多媒体企划
- 矿级：S
- 核心研究价值：不是“少年少女第一次寻找职业”，而是成年人已经拥有一套成熟旧职业本体后，主动或半主动转职为偶像，并把旧职业留下的能力、伦理、创伤、身体习惯、关系方式重新翻译到新职业。
- 新增母型：前职业转译型 / 二次职业本体型

## 1. 偶像身份如何建立

315 Production 招募来自不同前职的人。动画官方简介明确列出元律师、元外科医生、元飞行员等人物，他们带着各自理由“转职”为偶像。

天道辉的入口尤其典型：原本做律师，因工作受挫，酒后签下偶像合约；一开始根本没有认真想当偶像，在事务所见到同样被招募的元外科医生樱庭薰、元飞行员柏木翼后，又去观看 Jupiter Live，才开始真正理解这种职业可能性。

因此不是：

> 无职业身份 → 偶像

而是：

> 已完成旧职业身份 → 旧职业出现断裂/不足 → 被招募进入新职业 → 新规则重新评价旧能力 → 主动认领第二职业本体

## 2. 十元体量

| 十元 | 体量 | 作用 |
|---|---:|---|
| zn | 10 | “我原来是谁”与“我现在为何成为偶像”的持续本体对照 |
| x | 10 | 旧职业能力、人格、身体经验成为新职业原材料 |
| x并z | 10 | 律师/医生/飞行员/教师/运动员等旧身份与偶像新身份叠压 |
| zx | 9 | 最终必须由本人主动决定继续走偶像道路 |
| xn | 9 | 事务所、lesson、合宿、营业、Live构成新的职业规则 |
| z | 9 | 旧职业经历不是背景，会持续进入现在的行动逻辑 |
| n | 9 | 单人转职最终被编入Unit与315 Production共同体 |
| nx | 8 | 招募、身体事故、职业受挫、事务所安排等外力推动转轨 |
| nz | 8 | 同伴、Producer、前辈、粉丝为新身份提供社会确认 |
| xz | 7 | 事故、退役、职业断裂等命运节点改变原人生轨道 |

主元：**zn + x并z + x**
次元：**zx + xn**

## 3. 顺序

**z旧职业 → zn旧本体 → x旧职业资产 → nx断裂/招募 → x并z候选偶像身份 → xn新职业实践 → n组队 → zx主动认领 → nz公众回流 → 新zn + 新x并z**

## 4. 五维

### 时间维 xn + z：10/10
旧职业历史始终跟着角色进入偶像活动；新职业又通过lesson、工作、合宿和Live持续制造第二份履历。

### 本体维 zn + x：10/10
核心不是“能不能唱跳”，而是：如果我已经当过律师/医生/飞行员，那么偶像是逃离过去，还是过去的另一种完成方式？

### 空间维 x并z + n：10/10
旧社会身份进入315 Production后，被Unit与事务所重新编排，产生复合社会位置。

### 因果维 zx + nx：10/10
很多人物的入口来自职业受挫、身体问题、招募等nx，但是否真正成为偶像，最终仍必须转成zx。

### 命运维 xz + nz：9/10
事故、退役、人生失败关闭旧路线；新的伙伴和公众关系却把关闭点转化成另一条命运路径。

## 5. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 招募
不是只寻找唱跳完成品，而是识别“旧职业中已经成熟、但能被重新解释的特征”。

### 训练
动画第8话安排315 Production合宿，为联合Live克服弱点而分组训练。训练不是单纯补数值，而是成熟旧职业者重新接受新身体规则。

### 出道 / 营业
游戏官方介绍明确以营业、lesson、Live等工作把成员导向顶级偶像。新身份依靠重复工作逐步实化。

### 竞争
竞争不是唯一主发动机，更重要的是各Unit之间、前辈Jupiter与新人之间形成专业标准差。

### 舞台
第13话以315 Production联合Live为阶段性完成点。多个完全不同前史的人最终被压进同一个“315 STARS”公共舞台。

### 粉丝
粉丝不是角色起点，而是第二职业成立后的社会回声：先有转职，再通过公开舞台得到身份确认。

### 公司
315 Production承担“职业翻译器”功能。它不是把所有人清零成统一练习生，而是把不同过去重新组合成市场可识别的偶像Unit。

## 6. 主角欲望与代价

### 欲望
- 天道辉：旧职业的正义感无法顺利兑现后，寻找另一种公共表达与帮助他人的方式。
- 樱庭薰：强目标导向，把偶像工作当作实现私人目标与自我证明的道路。
- 柏木翼：原飞行员身份中断后，寻找新的可持续人生轨道。
- W：职业足球受伤/退役危机后，将身体竞技者的协作能力转入舞台职业。

### 代价
1. 必须放弃“旧职业才是真正的我”这种单一本体安全感。
2. 已经形成的成年人能力，在新行业可能重新变成新人等级。
3. 旧职业优势不能直接等价兑换，必须经过xn翻译。
4. 新职业成功越多，就越难再把偶像解释成“临时绕路”。

## 7. 关系结构

### Producer → 职业可能性发现者
Producer不是单纯训练老师，而是识别：这个人在旧职业里形成的东西，能否进入偶像职业后产生另一种价值？

### 前职业者 ↔ 前职业者
成员不是同一起跑线的练习生。每个人带着不同社会史，因此Unit组合本质上是：

**不同z + 不同x → 同一xn → n重新组合**

### 前辈 Jupiter → 新职业标准
新人需要通过观看成熟Live理解“偶像到底是什么”，即先建立外部职业尺度，再重新评价自己。

### Unit → 本体转换器
个人无法只靠“我以前是谁”完成转职。Unit要求角色将个人履历转译成团队功能。

## 8. 动态链

### A｜前职业资产转译
**旧z → 旧x → 换xn → 旧能力失去原意义 → zx重新使用 → 新x → 新x并z**

### B｜身份降级后再升级
**成熟职业者 → 新行业新人 → nx挫败 → xn训练 → 新x增长 → 再次获得专业者身份**

核心：**转职意味着主动接受一次社会等级下降。**

### C｜旧本体反咬
**新职业成功 → 旧职业记忆回流 → zn比较 → “我是不是逃跑” → zx重新解释过去 → 新zn**

### D｜Unit翻译
**多个不同旧x → n冲突/互补 → xn共同训练 → 差异功能化 → 团体x并z成立**

## 9. 反咬点

### 反咬1｜过去越强，转职成本越高
普通素人进入新行业只是“我不会”；成熟职业者还多一层：“我以前明明是专业人士，现在为什么又要从零被评价？”

### 反咬2｜转职不是逃离过去，而是把过去带得更深
**想逃离旧身份 → 新职业不断调用旧身份留下的纪律、责任、观察、身体性 → 旧身份反而成为新身份骨架。**

### 反咬3｜第二职业成功后，旧职业不再拥有唯一解释权
形成：**旧zn + 新实践 → 复合zn**。

### 反咬4｜专业成熟 ≠ 可直接跨行业
**能力可以继承，评价标准不能继承。**

## 10. 视觉符号

1. 旧职业服装 → 偶像舞台服：西装/白大褂/制服/运动服与演出服并置。
2. 旧职业道具 → 麦克风：公文包、听诊器、飞行装备、足球与麦克风进行功能替换。
3. 名片 / 合同：旧社会身份与315 Production名片形成职业入口对子。
4. 训练镜墙：成熟成年人重新作为新人纠正身体。
5. 多职业者同框：完全不同年龄、旧职业、人格的人最后穿统一演出服站上同一舞台。
6. Jupiter观众席 → 自己的Live舞台：从观看专业标准到成为专业标准。

## 11. 可复用母题

### ① 二次职业本体
角色不是寻找第一份梦想，而是在已经成为某种人以后，再主动成为另一种人。

### ② 前职业资产转译
**旧职业x → 换xn → 重新解释 → 新职业x**

### ③ 专业者重新当新人
最残酷的成长不是“我什么都不会”，而是：**我已经知道专业意味着什么，却必须接受自己在这里仍然是新人。**

### ④ 旧失败成为新职业材料
在A领域证明“不适合继续”的经历，在B领域可能成为唯一不可替代的角色差异。

### ⑤ 复合本体
职业成长不是新zn杀死旧zn，而可以形成：**旧zn + 新实践 → 复合zn**。

### ⑥ 转职不是清零
可信的转职故事必须回答：旧职业留下什么、哪些失效、哪些被重新估值、哪些成为新的负担。

## 12. 与已有偶像矿的区别

- Dream High：素人进入训练制度，被制度加工成职业者。
- CINDERELLA GIRLS：外部发现潜力后，个体开始看见自己的偶像可能性。
- Extreme Hearts：原职业道路被封，通过异质制度绕道换回舞台。
- Re:Stage!：已经放弃的旧梦想重新启动。
- THE IDOLM@STER SideM：**已经拥有完整旧职业身份的人，主动把人生转入第二职业，并要求旧职业历史参与新身份建造。**

## 13. 新增正式分类

# 「前职业转译 / 二次职业本体型」

母链：

> **成熟旧职业 → 旧路径断裂/不足 → 招募或主动转职 → 社会等级暂时下降 → 新规则重新评价旧能力 → 旧资产被翻译 → 新团队与公众确认 → 第二职业成立 → 复合本体生成**

## 14. 本轮矿核

> **真正的转职故事，不该让角色进入新行业后突然失忆。过去的职业既不是要删除的废档案，也不是能原封不动搬过去的外挂；它更像一套必须重新编译的旧程序。新职业真正改变的不是“角色有没有过去”，而是过去的每一项能力、失败和价值观，在新的规则里到底还能叫什么。**
