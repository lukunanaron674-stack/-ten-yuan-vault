# 日韩偶像题材｜母库增量 R01

> 本批次只收入已核验官方漫画/平台信息且达到 S/A 的样本。B/观察留在候选池。

## 7. The Youngest Must Become an Idol｜막내는 아이돌이 되어야 한다｜韩漫 / Webtoon｜S

### 基础卡
- 官方核验：Kakao Webtoon / KakaoPage 漫画版存在并已完结；Tapas 有英文版。
- 核心触发：Bong Taeyoon 曾是准备出道的练习生。原时间线里团队遭遇车祸，他成为唯一幸存者；被拉回过去后，本想退出注定失败的出道组，却遭遇系统硬规则：**退出出道组，成员会死亡。**
- 是否真正当偶像：是，且偶像职业不是装饰，而是维持成员生存的硬条件。
- 偶像机制：练习 / 出道组 / 团体 / 舞台 / 投票 / 任务 / 排名 / 粉丝 / 系统。

### 十元
- 主符号：xz，命运锁。离队与成员死亡绑定，主角不能自由退出。
- 次符号1：xn，系统与出道规则把命运锁转成可执行条件。
- 次符号2：zx，主角必须主动留队、完成舞台与任务、改变失败未来。
- 暗层：nz，团体成员关系既是命运压力，也是主角继续行动的缓冲和意义来源。

### 五维
- 时间 xn+z：回归到事故/失败尚未彻底发生的时间点，旧记忆持续推动新选择。
- 本体 zn+x：主角原本把自己定义为“会拖累团队、应该退出的人”，系统逼他重新定义自己为“必须留在团体里的成员”。
- 空间 x并z+n：出道组、舞台、节目和投票场把个人绑定为可被观看、评价、淘汰的偶像单位。
- 因果 zx+nx：他主动改变舞台和团队结果，但同时被系统与既定未来不断推回被动位置。
- 命运 xz+nz：死亡条件是硬命运；成员共同体是唯一能把“强迫留下”逐渐改写为“我愿意留下”的软化力量。

### 体量 1-10
- xz：10
- xn：9
- zx：9
- nz：8
- zn：7
- x并z：7
- nx：6

### 顺序链
**xz → xn → nx → zx → nz → zn**

过去的死亡命运 xz
→ 系统把命运写成退出即死亡的规则 xn
→ 主角无法离队而进入 nx
→ 被迫转为 zx，主动经营出道、舞台、团队结果
→ 与成员关系 nz 不再只是“要保护的人”，而成为共同体
→ 最终反过来重写 zn：我不是应该消失的拖累，而是团体不可删掉的一员。

### 生链
**xz 命运压力 → xn 系统规则 → zx 主动保团 → nz 团体关系加深 → zn 新成员本体。**

### 克链
1. xz 克 zx：主角最初不能自由选择退场，命运直接封死行动出口。
2. xn 克 zn：系统不承认“我不适合当偶像”的自我判断，只认是否属于出道组。
3. zx 克 nx：主角从被规则绑住，逐步转为利用任务、舞台和未来经验主动改局。
4. nz 软化 xz：成员不再只是“死了就失败”的任务对象，而成为让主角自愿承担命运的人。

### 反咬点
**主角一开始是为了救成员才不得不当偶像，但越成功，他越不能再把“离开”理解成单纯的自我牺牲。**
原本的退队逻辑是“我消失，大家会更好”；系统把这套自我牺牲直接反咬成“你消失，大家会死”。

### 5组补子
- xn + z：系统规则只有通过持续训练、任务、舞台和时间推进才会兑现。
- zn + x：主角的“失败偶像/拖累者”自我，与被强制赋予的“团体必要成员”身份冲突并重建。
- x并z + n：偶像身份必须在舞台、节目、投票、粉丝观看空间中成立。
- zx + nx：他既是被系统留下的人，又必须主动改舞台、排名与团队未来。
- xz + nz：成员死亡是命运锁，团体感情把硬锁逐渐转化为主动承担。

### 欲望与代价
- 为什么必须成为偶像：退出会触发成员死亡，偶像职业直接成为团体存续条件。
- 表层欲望：让成员活下来，让团体成功出道。
- 深层欲望：修正“只有我活下来”的旧时间线，证明自己的存在不必以退出/消失来成全别人。
- 成功代价：每一次成功都会让他与团体绑得更深，失去“我随时可以退出”的心理退路。
- 失败代价：不只是事业失败，而可能回到成员死亡、团体毁灭的命运。
- 成为偶像后我是谁：从“应该退出的幸存者”变成“必须参与、必须被别人依靠的团体成员”。

### 与已有样本差异
- vs《Debut or Die!》：都是死亡条件驱动，但《Debut or Die!》是**主角自己不出道就死**；本作是**主角退出，别人会死**。命运压力从自保转为团体责任。
- vs《Second Life Millionaire》：后者重来是把失败经验变资产；本作的回归首先是创伤和责任，不行动就可能重演成员死亡。

### 可复用母题
**“自我牺牲被系统判定为杀死同伴。”**

### 视觉符号
- 空着的团体站位 / 被重新补上的最小成员位
- 出道名单
- 系统死亡提示
- 投票数字与排名
- 事故夜 / 舞台灯光的时间对照
- 主角站在退场门口却被队友拉回

### 矿级
**S**。
新增价值：它不是重复“死亡系统逼出道”，而是提供了新的命运结构：**我的退出 = 别人的死亡**。非常适合十元里 xz+nz 与 zx+nx 的联动。

### 核验来源
- Kakao Webtoon：漫画《막내는 아이돌이 되어야 한다》，官方页面可检索，已完结。
- KakaoPage：漫画版官方页面，已完结。
- Tapas：英文版《The Youngest Must Become an Idol》，公开简介明确主角曾是即将出道练习生、事故唯一幸存者并回到过去；公开章节可见 Opening Stage / The Voting System 等职业机制。
- Naver Series / KakaoPage 原作简介进一步明确：主角试图退出出道组时收到“退出出道组，成员死亡”的系统条件。

## 8. My Second Life as an Idol｜韩漫 / Webtoon｜A+

### 基础卡
- 官方核验：Manta Comics 官方发行，39 话，Season 1 completed。
- 核心触发：失败偶像 Yongmin 死亡后，在外貌、资源、嗓音条件更好的 Ian 身体里获得第二次人生；神秘灵魂 Jin 被安排引导 Ian 成为明星。
- 是否真正当偶像：是。核心问题不仅是重生，而是旧偶像经验如何在新身体、新公众身份中重新职业化。
- 偶像机制：重新进入明星/偶像职业、表演能力、公众形象、秘密身份、职业成长。

### 十元
- 主符号：zn，旧自我与新身体的本体错位。
- 次符号1：x并z，新身体 Ian 逐渐形成新的公众明星身份。
- 次符号2：xn，第二次人生给失败职业线重新开局。
- 暗层：zx，Yongmin 的旧经验必须被主动转化为新身体可执行的职业优势。

### 五维
- 时间 xn+z：死亡后的第二次人生使旧失败经验持续作用于新职业路线。
- 本体 zn+x：最核心，意识/经验属于 Yongmin，身体与社会身份属于 Ian。
- 空间 x并z+n：舞台、媒体、粉丝看到的是 Ian 的身体与被包装的新明星身份。
- 因果 zx+nx：主角主动利用过去经验，但新身体、神秘引导者与职业环境也不断规定他能如何行动。
- 命运 xz+nz：死亡和转生带来不可逆命运置换；新关系让他逐步把“借来的第二人生”活成自己的。

### 体量 1-10
- zn：10
- x并z：9
- xn：8
- zx：7
- x：8
- nx：6
- xz：6

### 顺序链
**xn → zn → x → zx → x并z → zn**

死亡重启 xn
→ 旧意识 zn 进入新身体 x
→ 主角调用失败偶像经验 zx
→ 建立 Ian 的新公众明星身份 x并z
→ 新身份成功越高，越反过来逼问 zn：现在被喜欢、被认可的这个偶像，到底是谁？

### 生链
**xn 二周目 → 旧经验 z → zx 主动职业化 → x并z 新公众身份。**

### 克链
1. x 克 zn：新身体条件直接改变“我能成为怎样的偶像”。
2. x并z 克 zn：公众认识的是 Ian，而不是已经死去的 Yongmin。
3. zn 克 x并z：旧失败记忆与职业经验不断撕开“我是天生优秀新人”的表层形象。
4. zx 克 nx：主角利用旧经验减少第二次人生中的纯被动试错。

### 反咬点
**第二次人生看似补偿旧失败，但越成功，成功越可能证明“过去失败的是我的身体/条件，而不是我的职业判断”，同时也让主角无法确认别人究竟是在认可 Yongmin，还是 Ian。**

### 5组补子
- xn + z：第二人生只有携带旧失败记忆，才真正构成职业二周目。
- zn + x：旧意识/经验与新身体互相补强，也互相争夺“谁才是本人”。
- x并z + n：新的偶像/明星身份必须在公众观看与职业舞台上成立。
- zx + nx：主角主动利用旧经验，但身体、身份与引导者仍不断给他外部条件。
- xz + nz：死亡/转生是不可逆命运，新的关系使第二人生逐渐从借壳变成可归属的人生。

### 欲望与代价
- 为什么想成为偶像：第一次职业人生以失败和死亡结束，第二次人生给了重新验证自己能力与愿望的机会。
- 表层欲望：把新身体 Ian 推成真正的明星。
- 深层欲望：证明旧人生没有证明成功的“我”仍有价值。
- 成功代价：公众认同集中到 Ian 这个新身份，旧自我更可能被彻底隐藏。
- 失败代价：第二次机会也被浪费，旧失败无法被重新解释。
- 成为偶像后我是谁：从“失败偶像 Yongmin”变成“以 Ian 身体被世界认可的偶像”，本体与公众身份开始分裂。

### 与已有样本差异
- vs《Second Life Millionaire》：两者都是二周目偶像，但后者偏**时间回归 + 经验重用**；本作增加了**身体置换 + 公众身份错位**，因此 zn+x / x并z+n 更强。
- vs《我推的孩子》：后者是公众形象与真实自我撕裂；本作更极端，连身体和社会身份都不是旧自己的。

### 可复用母题
**“第二次成功发生在别人的身体上。”**

### 视觉符号
- 镜子里的新脸
- 旧舞台失败记忆 vs 新舞台高光
- 粉丝喊的是 Ian 的名字
- 灵魂/身体双层构图
- 旧偶像证件或记忆与新公众照片并置

### 矿级
**A+**。
价值：职业机制没有《Debut or Die!》那样硬，但本体矿非常纯，补足了现有偶像库中“经验是我的、身体和公众身份却不是我的”这一型。

### 核验来源
- Manta 官方《My Second Life as an Idol》：Fantasy/Sci-Fi · Modern，39 Episodes，Season 1 completed。
- Manta 官方简介明确：失败偶像 Yongmin 死亡后，在 Ian 的身体中获得第二次人生，Jin 负责引导 Ian 成为明星；官方标签含 Transmigration/Reincarnation、Idol/Actor、Secret identity。

## 本批次母型增量

### 母型1｜退出等于杀死同伴
主：xz；次：xn → zx；缓冲：nz。

不是“我必须成功，否则我死”，而是：
**我退出 / 消失 / 自我牺牲 → 他人死亡或共同体崩坏。**

这会把 nx 式自我让渡强行逼回 zx：你不能通过消失解决问题，你必须留下并行动。

### 母型2｜成功发生在别人的身体上
主：zn；次：x → x并z；推动：xn → zx。

旧经验属于我，成功载体却不是旧的我。
由此制造：
**能力归属 ≠ 身体归属 ≠ 社会身份归属 ≠ 粉丝认同归属。**

- A+：《My Second Life as an Idol》
