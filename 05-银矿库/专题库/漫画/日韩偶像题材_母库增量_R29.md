# 日韩偶像题材_母库增量_R29

## 本轮新增

### 《Extreme Hearts》
- **媒介**：日本原创 TV 动画（2022）
- **矿级**：**S**
- **核心类型**：**竞技绕道型职业重建 / 非本职赛道换取舞台资格**
- **去重说明**：仓库检索未发现既有《Extreme Hearts》独立条目，本轮作为新机制增量收录。

## 1. 作品入口与偶像身份如何建立

主角叶山阳和并非从“普通人想成为偶像”起步，而是已经作为高中生歌手细小地维持职业活动，却长期得不到市场评价并被事务所解除合约。她仍不愿放弃“靠唱歌工作”的目标，于是接受一个极不直观的新入口：参加由音乐公司主办、面向艺能人的 Hyper Sports 大赛“Extreme Hearts”。

这个制度的关键规则是：**在体育赛事中持续胜出，可以获得活动舞台、Live 等音乐曝光机会。**

因此职业重建不是：

> 练歌 → 试镜 → 公司录用 → 出道

而是：

> **职业失败 → 失去原入口 → 进入异质竞技规则 → 为了舞台训练陌生能力 → 赢得曝光 → 重建艺能团队与歌手身份**

随后为了让有体育经验的咲希、纯华能够合法参赛，RISE 不能只是临时体育队，而必须作为**艺能团队**持续活动。阳和甚至成立“叶山艺能事务所”，把自己家开放为事务所据点。

也就是说，原本只是为了比赛临时拉来的同伴，被制度反过来逼成真正的艺能组合。

> **主体为了保住旧梦想，主动接受一个原本与梦想无关的新制度。**

## 3. 顺序

### 主链

**z → nx → zn → zx → xn → n → x并z → x → zx → nz → 新x并z**

解释：

1. **z**：作为职业歌手长期低迷。
2. **nx**：被事务所解除合约，原职业通路关闭。
3. **zn**：遭遇“是不是已经不适合继续当歌手”的本体危机。
4. **zx**：仍决定继续找能唱歌的工作。
5. **xn**：进入 Hyper Sports 这一完全陌生的规则体系。
6. **n**：朋友从旁观者、教练、支持者逐渐进入正式队伍。
7. **x并z**：RISE 从临时参赛队变成艺能团队；阳和从歌手变成队长兼事务所所长。
8. **x**：体育能力在训练与分工中被补出，音乐能力继续作为原核心。
9. **zx**：团队开始不只是“帮阳和一次”，而是主动赢比赛、办Live。
10. **nz**：成员与观众形成真实支持关系。
11. **新x并z**：职业身份不再依赖旧事务所授予，而由自己建立的新组织和公共成绩重新成立。

## 4. 五维

### 时间维：xn + z = **10/10**
过去的“职业失败”不会消失，而是转化为必须从新赛道重新积累成绩的压力。每场比赛、每次Live都在重写履历。

### 本体维：zn + x = **9/10**
核心不是“我有没有音乐才能”，而是：

> **外部职业体系宣布我失败以后，我是否仍能继续把自己定义成歌手。**

### 空间维：x并z + n = **10/10**
个人歌手被迫重新组织成 RISE；家变成事务所；体育队又必须成为艺能团队。空间与组织不断生产新的公共身份。

### 因果维：zx + nx = **10/10**
本作最强维度之一：

**外部封路 nx → 主体绕路 zx → 新制度继续 nx → 主体继续适应 zx。**

它不是纯被迫，也不是纯主动，而是连续的“被封路→主动绕行”。

### 命运维：xz + nz = **9/10**
职业被切断是一种命运性坠落；但真正让主角重新上升的不是奇迹，而是已有粉丝、朋友、后来队友逐步转化成支持网络。

## 5. 偶像产业机制记录

### 训练机制
- 主角原本有音乐经验，却几乎没有 Hyper Sports 经验。
- 训练重点因此是**跨职业补课**：音乐人学习体育，体育出身成员学习艺能活动。
- 团队形成“异质能力互补”，不是全员从同一练习生流水线出来。

### 出道 / 再出发机制
- 阳和不是零起点新人，而是**被行业淘汰后重新找入口**。
- RISE 的艺能身份是在比赛资格规则中被迫建立，随后通过实际活动变真。

### 竞争机制
- 一场比赛一种体育项目，要求团队持续改变训练内容和阵容使用。
- 与普通偶像番的“唱跳实力对决”不同，竞争结果通过体育胜负产生。

### 舞台机制
- **舞台不是起点，而是竞技胜利的奖励。**
- 体育成绩直接兑换音乐曝光。

### 粉丝机制
- 小鷹咲希最初就是阳和的粉丝，却逐渐成为队友。
- 因此出现少见转化：**粉丝 → 劳动者 / 队友 / 共同身份拥有者**。

### 公司机制
- 原事务所先删除主角的职业位置。
- 主角之后干脆建立自己的微型事务所，完成从“被公司选择”到“自己生产组织入口”的翻转。

## 6. 主角欲望与代价

### 欲望
**不是非要成为顶级偶像，而是不愿失去“靠唱歌工作”的人生。**

这点很重要：目标是保存核心职业本体，而非追逐明星标签。

### 代价
- 必须花大量时间训练与音乐完全不同的体育能力。
- 必须承担受伤和比赛失败风险。
- 必须从个人创作者转成团队领导者。
- 必须承担事务所经营、音乐负责人、队长、比赛选手等多重责任。
- 为了继续唱歌，反而必须暂时把大量精力花在“不是唱歌”的事上。

→ **被支持者 ↔ 支持者**
→ **队友 ↔ 队友**

这是本轮最重要的关系转化之一。

### 阳和 ↔ 纯华
**体育外行 ↔ 体育经验者**
→ 教导/被教导
→ 并肩参赛
→ 共同经营团队。

### 阳和 ↔ RISE
开始时：

> 团队是为了让阳和获得舞台而存在。

后期：

> 阳和也必须为了让团队继续存在而行动。

于是单向工具关系反转为双向责任。

## 8. 动态链

### 动态链 A｜封路后绕道

**原职业路径 xn₁ → nx解约 → zx拒绝退出 → 进入异质 xn₂ → 新技能 x → 获得原职业资源 → 新x并z**

核心：

> **职业道路被堵死，不等于职业欲望消失；主体可以通过完全不同的制度重新接回原目标。**

---

### 动态链 B｜工具团队真实化

**为参赛临时组队 → xn要求艺能资格 → x并z被迫成为艺能团队 → n长期协作 → nz沉淀 → 团队获得独立价值 → 主角反过来承担维护义务**

核心：

> **为了完成目标制造的临时组织，一旦共同劳动足够久，就会反过来成为新的目标。**

---

### 动态链 C｜异质能力互译

阳和：

**音乐 x强 / 体育 x弱**

咲希、纯华等：

**体育 x强 / 艺能 x弱**

进入同一 xn 后：

**双方互补 → n稳定 → 每个人都被迫跨职业学习 → 新的组合型x形成**

即：

> **团队并非寻找同类，而是把彼此的缺口变成组队理由。**

---

## 9. 反咬点

### 反咬 1｜为了继续唱歌，必须不断做“不唱歌”的事

这是本作最值钱的一条。

**音乐梦想**
→ 需要曝光
→ 曝光被赛事控制
→ 为了赢赛事必须大量训练体育
→ **保存职业核心，反而要求暂时远离职业核心。**

公式：

**zn目标 → xn绕道 → 非核心x投入 → 重新获得核心x的发挥空间**

---

### 反咬 2｜粉丝越支持，越可能失去“纯粉丝”位置

咲希原本只是“喜欢阳和歌曲的人”。

但支持不断升级：

**听歌 → 鼓励 → 帮助训练 → 下场比赛 → 共同承担职业结果**

最终：

> **nz支持关系跨过阈值后，可以转化成 n共同劳动关系。**

这是很适合入十元库的新规则。

---

### 反咬 3｜公司淘汰主角，反而逼主角获得组织权

原公司解除合约，本意相当于：

> “市场判定你没有继续投资价值。”

结果：

**失去公司 x并z**
→ 自建事务所
→ 组建 RISE
→ 同时取得队长、所长、音乐负责人等位置。

因此：

> **失去被组织承认的身份，反而可能迫使主体获得创造组织的能力。**

## 10. 视觉符号

- **解约通知 / 空掉的事务所位置**：旧职业通路死亡。
- **吉他 + 运动装备并置**：两个不相干职业规则被强行接轨。
- **一个人训练 → 三人穿同一队服 → 五人团队**：n逐步实体化。
- **住宅门牌→“叶山艺能事务所”**：私人空间转化成职业组织空间。
- **球场记分板→Live舞台灯光**：体育成绩兑换艺能曝光。
- **汗水、伤痕、麦克风同时出现**：为了唱歌而支付的非唱歌成本。
- **空场/小型Live→全国配信活动舞台**：公共承认体量递增。

## 11. 本轮新增可复用母题

### ① 竞技绕道职业化

> 想成为A，但A的入口关闭，只能先在B体系获胜，再换取A的资格。

迁移：
- 画师失去出版社→通过游戏比赛赢宣传资源→重新获得出版机会。
- 无资格骑士→通过竞技大会取得觐见权→进入骑士团。
- 歌手→体育赛事→舞台。

---

### ② 非核心努力保存核心梦想

> **为了不失去最重要的东西，必须长期做大量看起来与它无关的事。**

这能制造非常真实的职业成长感。

---

### ③ 粉丝升级为共同生产者

**nz → n**

支持达到一定强度后，粉丝不再只是消费、应援，而进入作品或职业生产链。

可迁移：
- 粉丝→乐队成员
- 读者→编辑
- 玩家→开发者
- 信徒→圣女的战友

---

### ④ 被淘汰者自建入口

**组织拒绝我 → 我自己建立一个组织。**

这与 Love Live! 的“为了危机主动造组织”不同：

- Love Live!：**没有入口，所以主动创造。**
- Extreme Hearts：**旧入口明确把我淘汰，于是绕道并自建。**

---

### ⑤ 异质规则交换资源

> **在B领域赢得的成绩，可以被制度兑换成A领域的机会。**

这是非常强的剧情机器：它强迫角色学习与核心愿望不直接相关的能力，同时又不会把支线变成无意义跑题。

---

## 12. 与既有偶像谱系的边界

- **Dream High**：已有训练制度加工新人。
- **SELECTION PROJECT**：公众投票裁决身份。
- **Love Live!**：普通人为外部危机自建偶像入口。
- **PriPara**：两个规则空间争夺同一主体。
- **Kiratto Pri☆Chan**：开放平台允许先公开、后职业化。
- **Extreme Hearts**：**原职业入口失败后，在异质竞技制度里获胜，兑换重新登台的资格。**

因此本轮正式新增：

# 「竞技绕道 / 异质制度兑换型职业生成」

标准母链：

> **原职业失败 → nx封路 → zn仍不放弃 → zx接受异质规则 → xn跨域训练 → n组队互补 → B领域胜利 → 兑换A领域曝光 → 新x并z职业身份成立**

## 13. 一句话矿核

> **真正稳定的职业欲望，不一定表现为一直做“本职”；当正门关闭时，它会驱使人学习完全陌生的规则，用另一个世界的胜利重新买回自己的舞台。**

### 矿级结论
**S矿。**

理由：它同时提供了“职业失败后的身份重建”“异质制度资源兑换”“粉丝→队友”“临时队→真实艺能共同体”“被公司淘汰→自建组织”五条可迁移机制，并且与现有偶像生成谱系边界清晰。
