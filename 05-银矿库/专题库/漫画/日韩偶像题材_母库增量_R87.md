# 日韩偶像题材_母库增量_R87

## 《アイドル×戦士 ミラクルちゅーんず！ / Idol × Warrior Miracle Tunes!》
- 媒介：日本特摄偶像剧 / 女童向真人剧
- 年代：2017–2018
- 矿级：S
- 本轮新增母型：**双职业循环 / 偶像活动作为第二职业系统能源型**

## 1. 偶像身份如何建立
主人公一ノ瀬カノン原本就是以成为偶像为目标的小学生。她为了和憧憬的顶级偶像神咲マイ进入同一组合，参加偶像团体 audition，并进入最终审查；最终与天才舞者橘フウカ一起被选入 Miracle²。

但 audition 同时打开了第二层身份：成员不仅要作为偶像活动，还被要求成为“偶像战士 Miracle Tunes”，利用歌舞与音乐之力对抗被 Negative Jewel 污染的人。

因此身份不是单线生成，而是：

**素人 → audition → 偶像成员 → 偶像战士 → 偶像/战士双重职业身份**

## 2. 十元
### 主元
- **xn = 10**：偶像录音、Live、广播、媒体工作 + 战斗/任务两套规则同时存在。
- **zx = 10**：カノン主动参加 audition、主动追逐偶像目标，后续持续承担双重工作。
- **x并z = 10**：普通学生、Miracle²成员、Miracle Tunes战士多重社会身份叠加。

### 次元
- **n = 9**：三人后扩为五人，偶像组合关系同时也是战斗协作结构。
- **nz = 9**：对前辈的憧憬、队友信任、粉丝/观众反馈都能继续推动行动。
- **nx = 9**：任务会打断录音、广播、Live；偶像日程反过来也限制战斗行动。
- **x = 9**：歌、舞、舞台表现既是职业技能，也是战斗能力来源。
- **zn = 9**：角色必须同时回答“我是偶像”与“我是守护别人的战士”。
- **z = 8**：一场场录音、公开工作、Live、任务共同沉淀成双职业履历。
- **xz = 8**：音乐王国危机与魔王构成长期外部命运压力。

## 3. 体量
**xn10 / zx10 / x并z10 / n9 / nz9 / nx9 / x9 / zn9 / z8 / xz8**

## 4. 顺序
**nz憧憬 → zx参加 audition → x并z偶像候选 → xn最终审查 → x并z正式偶像 → nx第二职业使命介入 → n双重团队成立 → xn偶像工作/战斗并行 → x歌舞能力双重调用 → nz公众与伙伴回流 → zn双职业认领 → 新x并z稳定**

## 5. 五维
- **时间 xn+z：10/10**：录音、广播、Live、记者会、巡演与一次次任务共同形成连续职业史。
- **本体 zn+x：10/10**：同一套歌舞能力既证明“我是偶像”，也证明“我是战士”。
- **空间 x并z+n：10/10**：学校、宿舍、事务所、录音棚、Live现场、战斗现场构成双层职业空间。
- **因果 zx+nx：10/10**：主动追梦不断被任务打断；任务又必须借偶像能力完成。
- **命运 xz+nz：9/10**：宏观危机强制存在，但前辈、队友、观众关系持续给予继续行动的意义。

## 6. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制
### 训练
- audition 与最终审查。
- 录音、歌舞、组合磨合。
- 日常偶像工作与战斗经验同步积累。

### 出道
- カノン与フウカ通过 audition，加入マイ所在的新团 Miracle²。
- 偶像身份不是战斗结束后的奖励，而是一开始就正式运转的职业线。

### 竞争
- 后续出现从美国回国的高水平姊妹偶像组合“カリカリ”，形成舞台表现与职业水准上的同位压力。

### 舞台 / 工作
- 录音。
- 电台直播。
- 新歌Live。
- 满场公开活动。
- 五人重组后的记者会与再录音。
- Live Tour 等持续职业活动。

### 粉丝
- 偶像公开活动制造公众关注、支持与职业合法性。
- 公众不是纯背景，双职业成立需要“白天真的有人把她们当偶像看”。

### 公司 / 经纪
- 经纪与正式偶像工作持续存在，战斗并不会让现实职业日程消失。
- 因此角色经常面对“任务必须立刻处理，但录音/直播也不能随便取消”的冲突。

## 7. 主角欲望与代价
### 欲望
カノン最初的欲望很纯：
**成为偶像，并和憧憬的マイ站在同一组合。**

### 代价
真正达成以后，她得到的不是单纯舞台，而是双重责任：
- 偶像工作不能敷衍；
- 世界危机也不能不管；
- 两套身份会互相争夺时间、体力与注意力。

所以：
**愿望实现 → 责任倍增**。

## 8. 关系结构
### カノン → マイ
**偶像憧憬 nz → 同队 n → 同职业伙伴 n → 共同战斗 n**

### カノン ↔ フウカ
同场 audition 竞争者 → 同组合成员 → 战斗伙伴。

### Miracle² ↔ カリカリ
职业对手 → 相互刺激 → 后续关系重组。

### 偶像 ↔ 粉丝
公众承认形成偶像身份，同时公众活动又构成歌舞能力持续实践的真实场域。

## 9. 动态链
### 链A｜偶像欲望生成第二职业
**nz榜样 → zx追梦 → xn audition → x并z偶像身份 → nx战士使命 → 新x并z双职业身份**

### 链B｜同一能力跨职业复用
**歌舞x → 偶像舞台xn₁ → 公众承认nz → 战斗场景xn₂ → 歌舞x再次调用 → 公共结果生成**

### 链C｜双职业互相打断
**偶像日程xn₁ → 战斗nx插入 → zx临时切换 → 完成任务 → nx时间压力 → 返回偶像日程xn₁**

### 链D｜职业成功制造更多责任
**偶像成功 → x并z知名度↑ → nz支持↑ → 社会依赖↑ → nx责任↑**

## 10. 本轮最大反咬
### 反咬1：副职业不是支线，而会占用主职业的现实时间
战斗发生时，录音、直播、Live不会自动暂停。

因此：
**第二职业越重要 → 第一职业越容易被打断；第一职业越成功 → 越不能随意失约。**

### 反咬2：同一项能力越有价值，越不再完全属于私人兴趣
歌舞一开始是“我喜欢做”。
后来同时关系到：
- 偶像工作结果；
- 团队成员；
- 粉丝；
- 战斗与公共安全。

形成：
**私人x → 职业x → 公共功能x → nx责任化**

### 反咬3：团队既是组合，也是战斗单位
成员关系出问题，不只是Live不好看，还可能直接影响另一职业系统。

所以：
**n故障 → 两套xn同时受损。**

## 11. 本轮新增十元规则
### 规则A｜同一x可以被两个xn同时调用
**x单能力 × xn₁职业规则 × xn₂第二职业规则 → 双重职业价值**

### 规则B｜双职业不是简单相加，而是资源竞争
**职业A责任↑ + 职业B责任↑ → nx时间/体力冲突↑**

### 规则C｜一个职业可以成为另一个职业的能力训练场
偶像舞台持续训练歌、舞、合作、临场表现，这些能力直接提高战斗端有效输出。

### 规则D｜能力公共功能化后，会产生退出成本
当别人真正依赖这项能力时：
**“我不想做了”**就不再只是个人职业决定。

## 12. 与既有矿边界
### vs R44《Macross Δ》
R44：歌唱职业本身天然具有宏观公共功能，重点是**能力公共化 → 公共责任**。

R87：角色同时承担**偶像职业 + 战士职业**，重点是**两套职业系统如何共享同一能力并争夺同一主体资源**。

### vs R41《Lapis Re:LiGHTs》
R41：为了保住魔女职业，引入舞台能力，最后两种职业定义融合。

R87：两套职业始终保持可区分性，但持续互相调用、互相打断。

### vs R76《Waccha PriMagi!》
R76：两个主体共同合成一个职业能力。

R87：一个主体/一个组合同时承担两套职业结构。

## 13. 视觉符号
- 普通校服 → 偶像服 → 战士变身服。
- 录音棚红灯亮起 ↔ 紧急任务突然插入。
- 电台直播麦克风 ↔ 变身道具。
- Live舞台灯光 ↔ 战斗中的音乐能量。
- 粉丝欢呼 ↔ 世界危机的阴影。
- 三人组合 → 五人组合，舞台阵型与战斗阵型对应。
- Live Tour海报与任务现场并置。

## 14. 可复用母题
1. **双职业循环**：主职业与第二职业共享同一核心能力。
2. **职业资源争夺**：两套职业同时争夺主体时间、体力、关系与承诺。
3. **工作技能公共功能化**：表演能力同时能解决现实危机。
4. **职业成功责任膨胀**：越成功越不能只按私人意愿退出。
5. **团队双重用途**：同一n既是工作团队，也是任务/战斗团队。
6. **被打断的职业日常**：真正的双身份不是换套衣服，而是两个日程表互相撞车。

## 15. 正式分类
# 「双职业循环 / 同一能力跨制度复用型」

母链：
**职业欲望 → 取得职业A身份 → 第二职业B介入 → 同一核心能力被A/B共同调用 → 两套团队与规则互相耦合 → 成功同时扩大价值与责任 → 主体必须建立双职业本体。**

## 16. 矿核
> **有些角色不是从一个职业跳到另一个职业，而是同一项能力突然被两个社会系统同时需要：舞台要求她唱得更好，另一份责任也要求她继续唱。真正的成长因此不只是“我会不会”，而是当两个职业都开始依赖我以后，我怎样分配时间、责任与身份，并承认这两种工作都已经成为我是谁的一部分。**
