# 日韩偶像题材｜母库增量 R81

> 本轮去重后新增《リミテッドアイドル / Limited Idol》。它不是把“偶像”当恋爱背景，而是明确以女偶像候选人的训练、选秀、候选人关系和舞台资格为核心。小学馆官方直接将其定位为“ガールズアイドル・サバイバルストーリー”，并强调现实偶像选秀背后的候选人友情与葛藤。

## 《リミテッドアイドル / Limited Idol》｜日漫｜S

### 1. 基础卡
- 作者：藤原ゆか。
- 连载/出版：小学馆・マンガワン女子部；单行本第1卷于2025-12-19发行，192页；截至检索时单话版已至少形成7个配信单元。
- 核心角色：擅长舞蹈的リコ，以及体弱的双胞胎ミコ。
- 职业起点：リコ为了两个人共同的“成为偶像”梦想持续接受舞蹈训练，并正式挑战偶像 audition。
- 异常压力：悲剧发生后，“死神”ヒヅキ出现；作品把“改变命运/未来”与继续站上偶像舞台绑定。
- 官方职业证据：小学馆明确称其为“ガールズアイドル・サバイバルストーリー”，编辑推荐又明确指出作品描绘现实偶像 audition 背后的候选人友情与葛藤。
- 核心偶像职业度：9.5/10。
- 十元采矿：93/100。
- 矿级：S。

### 2. 新母型
## **命运限时舞台 / 悲剧后仍继续职业化型**

不是：
`遭遇悲剧 → 放弃梦想`

也不只是：
`死亡威胁 → 被迫出道`

而是：
`共同偶像梦想 → 长期训练 → 悲剧切断原人生 → 命运/死神进入 → 主体仍选择 audition → 候选人关系与职业评价继续发生 → 舞台成为对命运的现实反证`

核心公式：

> **xz 命运压缩 × z 未完成愿望 → zx 继续行动 → xn audition 规则 → x并z 偶像候选身份**

与《Debut or Die!》最重要的区别：
- 《Debut or Die!》：系统规则明确规定“不出道就死”，职业是生存条件。
- 《リミテッドアイドル》：悲剧/死亡首先破坏人生，角色仍把“继续站上舞台”当作自己对命运的主动回答，职业并非单纯外部强制任务。

### 3. 主符号 / 次符号
- **主：xz** —— 悲剧、死神、未来被压缩，命运压力直接改变职业路径。
- **次：z → zx → xn** —— 共同梦想没有被悲剧抹掉，转为主动 audition 与训练，再进入选秀规则。
- **强层：n + nz** —— 双胞胎共同梦想、候选人友情/葛藤使“成为偶像”不是孤立个人项目。
- **职业显影：x并z** —— 从“练舞的少女”到“被 audition 与舞台读取的偶像候选人”。
- **本体反咬：zn + x** —— 舞蹈能力与真实职业行动会重新回答“悲剧之后的我还能是谁”。
- **反压：nx** —— 评价、竞争、候选人关系以及无法控制的命运持续反推主体。

### 4. 十元体量
- xz：10 —— 悲剧/死神/未来变化构成最大不可控压力。
- z：9 —— 与双胞胎共同拥有的偶像愿望持续作为历史动力。
- zx：9 —— 训练、参加 audition、继续站上舞台是明确主动行为。
- xn：9 —— 偶像选秀、候选资格、评价构成职业制度。
- n：9 —— 候选人之间的友情与冲突被官方明确作为故事重点。
- nz：9 —— 双胞胎共享梦想形成最初职业意义网络。
- x并z：9 —— “候选偶像/舞台上的人”逐渐成为可被社会读取的身份。
- zn：8 —— 悲剧之后是否仍能把“偶像”纳入自我定义。
- x：8 —— 舞蹈训练与舞台能力必须被真实职业现场验证。
- nx：8 —— 选秀评价、竞争以及命运限制持续构成反压。

### 5. 顺序链
**`nz共同梦想 → z长期愿望 → x舞蹈训练 → xz悲剧切断 → zn本体动摇 → zx仍选择继续 → xn进入偶像audition → n候选人关系 → nx竞争/评价反压 → x并z候选偶像身份 → zn重新成立`**

简式：

> `nz → z → x → xz → zn↓ → zx → xn → n/nx → x并z → 新zn`

### 6. 五维
#### 时间｜xn + z：9/10
旧愿望不会因悲剧自动失效；训练史与 audition 规则把“过去共同梦想”转成之后每一步职业选择的参照。

#### 本体｜zn + x：9/10
重点不是有没有舞蹈技能，而是悲剧之后这些技能还能否继续代表“我想成为什么人”。

#### 空间｜x并z + n：9/10
从姐妹共同练习的私人空间，进入 audition、候选人网络与舞台公共空间；社会位置改变后，“想当偶像”变成“正在接受偶像职业判断的人”。

#### 因果｜zx + nx：10/10
越主动继续训练与参赛，越必须接受评价、竞争、失败可能与命运反压。

#### 命运｜xz + nz：10/10
悲剧压缩未来，但双胞胎共享的愿望关系让角色没有简单退出；关系意义与命运压力直接对咬。

### 7. 生链
1. **nz生z**：双胞胎共同梦想使“偶像”成为长期愿望，而非短期兴趣。
2. **z生zx**：未完成愿望推动リコ继续训练并参加 audition。
3. **zx生x并z**：主动训练/参赛让“想成为偶像”逐步变成职业候选身份。
4. **xn生n**：选秀制度把孤立追梦者组织成候选人竞争/合作网络。
5. **n反生zx**：友情、比较与葛藤反过来提高行动强度。
6. **x并z反生zn**：舞台与职业承认把新的社会身份写回自我。

### 8. 克链
1. **xz克z**：悲剧首先试图切断原有偶像愿望的时间连续性。
2. **xz克zn**：命运事件直接破坏“原来那个我”的成立条件。
3. **xn克zx**：主动追梦进入 audition 后，不再由本人单方面决定成功。
4. **nx克zx**：评价、竞争、候选人冲突持续压制主动行动。
5. **x并z克旧zn**：真正被职业系统读取为偶像候选后，“我只是替两个人守着一个梦想”的旧解释会越来越不够。
6. **新zn反克xz**：若角色在悲剧之后仍通过舞台建立新的职业本体，就形成对“命运已经决定人生”的反证。

### 9. 5组补子
1. **xn + z｜规则 × 愿望**：愿望需要 audition 制度才能从私人梦想变成职业资格。
2. **zn + x｜本体 × 能力**：悲剧后“我是谁”必须通过舞蹈/舞台能力重新证明。
3. **x并z + n｜公众身份 × 候选人网络**：偶像身份不是单人成立，必须在同行、评审、舞台关系里被读取。
4. **zx + nx｜主动训练 × 评价反压**：越主动前进，越进入更强的比较与淘汰环境。
5. **xz + nz｜命运压力 × 共同梦想关系**：命运想切断人生，关系意义却把角色继续拉回舞台。

### 10. 最大反咬点
#### 反咬1｜最初是“两个人的梦想”，最后必须由一个人的职业行动承担
共同梦想提供强动力，但如果现实只允许一方站上 audition 舞台：

**`nz共享梦想 → zx单人执行 → x并z个人职业身份 → zn个人化`**

越成功，越必须回答：
> 这是“我们的梦想”，还是已经成为“我的职业”？

#### 反咬2｜悲剧越想终止时间，职业训练越要求持续时间
悲剧的结构是“突然切断”；偶像职业的结构却是“重复练习、评价、继续上台”。

于是：

**`xz瞬间切断 ↔ xn/z持续累积`**

职业劳动本身成为抵抗命运断裂的时间装置。

#### 反咬3｜为了改变未来，必须先接受一个更残酷的现实评价系统
角色面对超自然命运，却不能靠命运设定直接获得偶像资格。

仍然必须：
`练习 → audition → 候选关系 → 评价 → 舞台`

因此：
> **命运可以给你理由，但不能替你通过职业考试。**

#### 反咬4｜候选人友情越真实，淘汰就越不再只是个人失败
官方把候选人友情与葛藤明确放进职业核心后：

**`xn制造n → n增强职业意义 → xn又通过竞争威胁n`**

制度先让候选人互相成为重要的人，再用同一制度比较、筛选她们。

### 11. 视觉符号
- 双胞胎并肩练舞 ↔ 单人站上 audition 舞台
- 训练镜墙 ↔ 黑暗中的死神
- 未完成的双人梦想 ↔ 单人姓名牌/候选编号
- 练习服汗水 ↔ 正式舞台灯光
- 姐妹私密空间 ↔ 候选人大群像
- 倒下/中断的身体 ↔ 再次站立的舞台身体

最强视觉对子：

> **“命运说这里该结束” ↔ “职业动作要求下一次练习继续开始”。**

### 12. 与现有样本差异
- vs《Debut or Die!》：不是外部规则规定“必须出道才能活”；而是命运先破坏人生，角色主动把继续职业化当作反击。
- vs《IDOL×IDOL STORY!》：后者是失败后重新选择偶像；本作多一层“共同梦想 + 悲剧/死神 + 命运改写”。
- vs《Girl Crush》：后者更强在月评/多级资格漏斗；本作更强在命运压力与关系意义怎样把人持续拉回舞台。
- vs《星を継ぐアイドル》：后者研究学校制度如何长期认证/降级偶像；本作研究悲剧如何试图终止职业时间，而 audition 继续把时间接回去。

### 13. 当前判断
- 核心偶像职业度：**9.5/10**。
- 十元采矿：**93/100**。
- 矿级：**S**。
- 强项：女偶像成长、舞蹈训练、正式 audition、候选人友情/葛藤、命运压力与职业持续性的对咬。
- 后续观察：若后续进一步出现明确排名、淘汰、组团、公司合同、正式出道、粉丝与公演，可再补“制度漏斗/组合运营”第二阶段。
