# 日韩偶像题材_母库增量_R106

## 作品
**《THE IDOLM@STER.KR》｜韩国真人偶像成长剧｜S矿**

## 一句话矿核
一个原本属于竞技体育、因双胞胎明星姐姐死亡而停下来的跑者，被制作人拉入偶像体系；她必须把“耐力、节奏感、竞争习惯、身体纪律”从运动员规则重新编译成偶像职业能力，同时在新人组与既有练习生的关系冲突中，重新生成自己的职业欲望。

## 新增母型
### 「前领域身体资本重编译 / 非艺能者职业再新人化型」
不是“零能力素人突然学会唱跳”，也不是“成熟职业者直接转职”。重点是：主角在旧领域已经拥有一套高度训练过的身体与竞争结构，但进入偶像行业后，这些旧能力必须被另一套xn重新解释，才能成为有效x。

## 顺序
**xz → z → zn封闭 → nx招募 → zx试入 → x并z候选偶像 → xn模拟测试/生存赛 → x旧身体资本重编译 → n队伍冲突/协作 → nz关系回填 → 新zx → 新zn / 新x并z**

解释：
1. 姐姐死亡让原有运动员人生失去意义。
2. 已故明星姐姐的职业历史持续压在主角身上。
3. 制作人提出“成为偶像”，主角先被外力推进新入口。
4. 真正进入825后，模拟测试、练习、生存赛开始用新职业标准重新评价她。
5. 跑步形成的耐力、节奏和身体控制并不会直接等于偶像能力，但在舞蹈、训练和竞争中被重新调用。
6. 与原练习生的冲突迫使她学习“个人能力如何进入团队”。
7. 新职业欲望不是第一天就完整存在，而是在实际训练、比较与关系里后生成。

## 五维
### 时间 xn+z：10/10
旧运动员经历和姐姐的明星历史都没有消失。进入偶像训练后，旧z被新xn持续重新解释。

### 本体 zn+x：10/10
核心问题不是“她会不会跳舞”，而是：旧身体能力属于过去的我，还是可以成为新职业的我？

### 空间 x并z+n：10/10
跑道、兼职生活、825练习室、Debut Team/Rookie Team、生存舞台是不同社会空间；同一个人换空间后，能力价值和身份解释都会改变。

### 因果 zx+nx：10/10
姐姐死亡和制作人招募先推动她进入；真正留下则必须从被推动转成主动实践。

### 命运 xz+nz：9/10
姐姐死亡是强换轨点，姐妹关系又持续作为职业动机和比较压力存在。

## 偶像身份如何建立
- 起点：马拉松运动员，不是偶像练习生。
- 断裂：双胞胎姐姐Suah作为顶级明星死亡，主角停下原运动路线。
- 入口：制作人Shinhyuk邀请她“成为偶像”。
- 半职业身份：进入825 Entertainment，和其他女孩一起接受模拟测试。
- 正式加工：被分入Debut Team / Rookie Team的生存竞争，训练唱跳与团队协作。
- 身份实化：不是靠“姐姐是明星”直接继承，而是通过一轮轮真实训练、竞争和团队结果重新获得职业合法性。

---

## 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制
### 训练
- 一周模拟测试准备。
- 对零基础或跨领域成员暴露舞蹈、配合、表达短板。
- 旧运动能力只能解决部分身体问题，不能免掉偶像训练。

### 出道
- 不是一次星探决定，而是“进入候选体系→考核→生存竞争→团队形成”的连续过程。

### 竞争
- 既有练习生与新加入成员之间存在明显经验差。
- Debut Team / Rookie Team把“谁已经接近职业者、谁仍是新人”制度化。

### 舞台
- 舞台是旧运动能力被新职业验证的地方：耐力和节奏只能在真正表演中证明是否有效。

### 粉丝
- 本作粉丝机制不是最强轴，主要作用在职业结果与社会承认回流。

### 公司
- 825不仅提供训练，还掌握考核、分组、资源与出道路径。
- 制作人既是入口提供者，也是让旧能力跨领域翻译的人。

## 主角欲望与代价
### 初始欲望
原本不是“我从小要当偶像”，而是已经失去原运动目标。

### 欲望后生成
被推进偶像训练后，随着身体能力重新找到用途、与队友产生竞争与关系，新的zx逐渐形成。

### 代价
- 必须接受自己重新成为新人。
- 旧运动员的熟练感不能直接带进新行业。
- 必须面对姐姐留下的明星标准。
- 必须从个人竞技逻辑转向团队协作逻辑。

## 关系结构
### 姐姐Suah：z + nz + nx
既是失去的人，也是明星职业的比较坐标。

### 制作人Shinhyuk：nx → xn接口
不是单纯导师，而是把主角从旧人生推进新职业空间，并用新规则重新解释她的能力。

### 原练习生 / 新成员：n + nx
她们不是温柔陪练，而是直接让主角看到“身体好”和“会当偶像”之间还有多远。

### 团队：n
主角必须把过去“我自己跑得快”转换成“我在团队里怎样让整体成立”。

## 动态链
### 链1｜身体资本重编译
**旧xn运动训练 → x耐力/节奏/纪律 → 换xn偶像体系 → nx新标准暴露缺口 → zx重新训练 → 新x偶像化**

### 链2｜新人化
**旧领域熟练者 → 新领域零资历 → x并z新人标签 → zn落差 → xn重复实践 → 新职业本体成立**

### 链3｜个人竞技→团队职业
**个人x强 → n协作要求 → nx冲突 → zx调整 → 团队结果 → x价值重新定义**

### 链4｜死者坐标反咬
**姐姐z/nz → 进入偶像行业 → 比较增加 → nx压力 → zn冲突 → 必须从“替姐姐继续”转为“我自己选择”**

## 反咬点
### 1. 旧领域越熟练，进入新领域越容易感到自己突然变笨
成熟身体经验是资产，也是新人羞耻的来源。

### 2. 体能优势会让人误以为“偶像身体”也解决了
实际上偶像还要求表情、节奏呈现、镜头感、团队同步与公众表达。

### 3. 个人竞技的优点可能成为团队职业的缺点
跑者习惯“自己完成成绩”；偶像团要求成员彼此配合，单人最优不等于团队最优。

### 4. 死去的成功者会变成无法更新的职业标准
姐姐已经不能失败、改变、退步，因此越容易被神圣化，持续侵蚀主角自己的zn。

### 5. 被招募不等于职业欲望已经形成
**nx入口 → xn实践 + x增长 + n/nz意义 → 新zx**，中间过程不能省略。

---

## 本轮新增十元规则
1. **有效x = 旧x × 新xn适配率**：能力可以跨职业带走，但不能原样兑换。
2. **旧领域熟练度越高，新领域新人化冲击越强**。
3. **个人竞技型x进入团队职业后，必须经过n重新估值**。
4. **死者z可以长期作为职业比较标准，持续产生nz与nx**。
5. **nx提供职业入口，不等于自动生出zx；必须经过真实实践与意义回填。**
