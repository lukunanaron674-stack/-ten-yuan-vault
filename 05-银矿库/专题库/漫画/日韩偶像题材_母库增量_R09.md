# R09｜女偶像选秀双样本

## 1. アイドラトリィ / Idolatry｜日漫｜S
讲谈社官方：女子高中生阳见循菜原本是狂热偶像粉丝。推槻城ふわり所在团体解散后，ふわり参加新的偶像选秀；循菜为了把推送到顶点，自己也进入100人选秀。第3、4卷继续明确MV拍摄、团队战、舞台考试与强制淘汰。

### 十元
- 主：nz（推与被推者的关系绑定）
- 次：zx（主动操盘/攻略选秀）→ xn（选秀规则）→ x并z（舞台可见身份）
- 暗层：z（极端推欲）+ zn（本人是否真的想成为偶像）
- 顺序：z → nz → zx → xn → n → x并z → zn
- 生链：z生nz，极端推欲把粉丝关系升级为共同命运；nz生zx，为了推的成功主动进入并操纵选秀；zx生x并z，策略行动最终必须通过舞台/MV/镜头成为可见成绩。
- 克链：xn克zx，100人选拔、团队赛与必淘汰规则限制个人操盘；nz克zn，主角“为推而成为偶像”的动机持续压过“我自己想成为什么”的本体问题。

### 五维
- 时间 xn+z：多阶段选秀规则不断消耗并强化推欲。
- 本体 zn+x：参赛者身体能力/舞台能力最终逼问“她本人是不是偶像”。
- 空间 x并z+n：MV、舞台、队伍和镜头把私人推活转成公众竞争。
- 因果 zx+nx：循菜极强主动操盘，但必须服从节目分组与淘汰安排。
- 命运 xz+nz：团体解散是命运断裂，循菜把自己与ふわり重新绑成共同晋级命运。

### 5组补子
1. xn+z：选秀制度 + 推的执念。
2. zn+x：偶像自我 + 实际舞台能力/身体。
3. x并z+n：舞台/MV公众身份 + 队伍/观众关系。
4. zx+nx：主动攻略规则 + 被节目规则安排。
5. xz+nz：原团解散/淘汰风险 + 与ふわり的共同命运。

- 偶像职业度：10/10
- 矿级：S
- 新母型：**粉丝反向入场型**。不是“我梦想成为偶像”，而是“为了让我的推成为偶像，我自己必须先成为选秀参与者”。粉丝端nz直接穿透职业边界，最后反咬zn：工具性偶像身份会不会长成自己的真实身份？

## 2. MAVE: Another World｜韩漫/Webtoon｜S
Tapas官方：Lee Zena本来已经准备出道，却因同公司前女团成员Ju Siu的丑闻连带导致团体被取消；随后系统提示，她唯一的出道希望是和Siu一起参加生存偶像节目“To Be Dol”。全51话，已完结。

### 十元
- 主：xn（公司/生存节目/系统规则）
- 次：xz（出道被外部事件截断）→ nz（被迫与风险人物绑定）→ zx（重新争夺出道）
- 第三层：x并z（节目舞台与公众评价）
- 顺序：z → xz → xn → nx → nz → zx → x并z → zn
- 生链：xz生xn，第一次出道被丑闻截断后，新的生存节目成为唯一职业通道；xn生nz，规则强迫Zena与Siu成为利益共同体；nz生zx，共同命运迫使两人合作争夺出道。
- 克链：xz克z，个人长期出道愿望被他人丑闻直接切断；xn克zx，主角不能自由选择路线，只能进入指定生存节目；nz反克xz，原本造成职业灾难的人际关联也可能成为第二次出道的修复力量。

### 五维
- 时间 xn+z：第一次待出道→团体取消→生存节目第二通道。
- 本体 zn+x：职业能力与“我是否还能成为偶像”的资格重建。
- 空间 x并z+n：节目、舞台、公司与成员关系共同生产公众偶像身份。
- 因果 zx+nx：主动再竞争建立在“唯一出路”的被迫框架中。
- 命运 xz+nz：Siu的丑闻先连坐摧毁Zena，再由两人绑定共同争夺第二次出道。

### 5组补子
1. xn+z：公司/节目规则 + 出道愿望。
2. zn+x：偶像资格认同 + 训练/表演能力。
3. x并z+n：生存节目公众舞台 + 团体/观众关系。
4. zx+nx：主动竞争 + 唯一通道的被迫性。
5. xz+nz：丑闻连坐命运 + 与Siu的强制共同体。

- 偶像职业度：10/10
- 矿级：S
- 新母型：**丑闻连坐→仇因共同体修复型**。同一个人际关联先作为xz毁掉职业入口，再作为nz成为第二次出道必须依赖的关系。

## R09结论
这轮优先补女性样本，不再继续堆韩国男性回档偶像。新增两个此前母库缺失的结构：
1. 粉丝为了推而亲自进入偶像选秀，nz从观众席跨进职业系统。
2. 同公司他人丑闻造成出道连坐失败，第二次机会又必须与“灾难源”共同参赛，形成xz↔nz反转。
