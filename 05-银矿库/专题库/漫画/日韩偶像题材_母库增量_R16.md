## 新母型
**关系通行证职业化：为了进入某个人所在的社会世界，把自己改造成与对方同一种公众身份。**

起点不是“我有偶像梦”，而是：
普通粉丝无法进入偶像的社会空间 → 为了接近她，自己也成为偶像 → 工具性职业开始获得独立市场成功 → 成功后的公众身份反过来改变最初私人关系。

## 十元
- 主符号：**nz**。私人关系欲望是职业入口和最初发动机。
- 次符号1：**x并z**。偶像是被经纪、媒体和公众制造并承认的社会身份。
- 次符号2：**zx**。主动跨越“粉丝→偶像”的边界。
- 次符号3：**xn**。经纪、广告、演艺工作逐渐把临时手段制度化为职业。
- 暗层：**zn**。当偶像事业获得独立价值后，“我只是为了她才做”开始失效。

## 体量
nz10 / x并z9 / zx8 / xn8 / zn8 / n7 / z7 / nx6 / x6 / xz4。

## 顺序链
**z → nz → zx → xn → x并z → n → zn**

对 Rima 的持续执念z → 私人关系指向nz → 主动成为偶像zx → 被经纪和职业流程xn接管 → 建立公众身份x并z → 进入演艺/观众网络n → 工具身份反问真实自我zn。

## 五维
- 时间：**xn+z**。执念提供长期方向，职业流程把方向切成广告、工作与事业成长。
- 本体：**zn+x**。普通少年与明星身份逐渐重叠并冲突。
- 空间：**x并z+n**。只有成为被观看者，才能进入 Rima 所在的演艺社会空间。
- 因果：**zx+nx**。他主动入行，但入行后越来越受经纪、工作与公众评价安排。
- 命运：**xz+nz**。偶遇具有命运触发性，但持续锁住行动的是私人关系欲望。

## 生链
1. nz 生 zx：为了靠近 Rima，产生“我也成为偶像”的行动。
2. zx 生 xn：主动入行后，职业规则开始接管生活。
3. xn 生 x并z：商业工作持续制造明星公众身份。
4. x并z 生 n：公众身份扩大娱乐圈和观众网络。
5. n 反生 x并z：市场越认可，偶像身份越不能再被当成临时工具。

## 克链
1. **x并z 克 nz**：原本为了接近 Rima 建立的公众身份，成功后却让两人变成同行与竞争者，并制造新的情感距离。
2. **xn 克 nz**：职业工作不能永远服从私人接近目的。
3. **n 克 zn**：公众越承认“明星 Hisayoshi”，私人自我越难单方面决定这只是一场工具性扮演。
4. **zx 反克 nx**：他不是纯粹被经纪人摆布，自己的选择和能力使职业身份真正长出来。

## 反咬点
**为了缩短人与人之间的距离而成为偶像，职业成功本身却重新制造了距离。**

普通粉丝→偶像原本存在社会距离；成为 fellow idol 后进入同一职业空间，看似解决距离问题。但事业继续增长后，同职业空间又生成竞争、公众关注与独立事业，于是：

**nz → zx → x并z → xn/n → 反克原始nz。**

## 5组补子
- xn+z：私人执念必须经过连续职业工作才能兑现。
- zn+x：现实中的普通少年与被行业塑造出的明星身份争夺“真正的我”。
- x并z+n：偶像身份只有在经纪、广告、媒体、观众、同行网络中才获得社会真实性。
- zx+nx：主动选择成为偶像；进入后又必须接受工作安排、曝光和评价。
- xz+nz：偶遇提供命运触发，私人关系欲望让命运持续运转。

## 偶像机制
- 经纪人/职业入口：强，前经纪人直接负责身份转换。
- 商业工作：明确，第2卷已有首个 commercial。
- 明星成长：明确，官方简介确认 star potential 与 blossoming career。
- 同行业竞争：明确，Rima 很快将他视作竞争者之一。
- 公众身份：强，普通粉丝必须先变成“被观看者”才能进入同一社会空间。
- 练习/选秀/排名：不是主发动机。
- 职业持续性：成立，跨多个卷持续发展而非一次性噱头。

## 成为偶像的欲望与代价
- 表层欲望：接近 Rima。
- 深层欲望：把“只能远远观看的人”变成“与我处于同一世界的人”。
- 成功收益：获得同行接触资格，并建立真实明星资本。
- 成功代价：职业身份产生独立价值，不再服从最初私人目的；越成功，越可能把最初想接近的人重新变成竞争者和遥远公众人物。
- 失败代价：既无法接近 Rima，也会证明“粉丝与偶像属于两个世界”的旧边界不可跨越。

## 与已有样本差异
### vs Idolatry
- Idolatry：粉丝进入偶像选秀，目的是把自己的“推”送上顶点；职业身份是应援工具。
- Crown of Love：粉丝成为偶像，目的是取得与偶像处在同一社会空间的关系资格；职业身份是“接近通行证”。

**我当偶像，是为了让你成功。**
vs
**我当偶像，是为了终于能站到你身边。**

### vs 推しが武道館いってくれたら死ぬ
- 推武道馆：粉丝留在职业外，通过购买、应援、传播制造偶像资本。
- Crown of Love：粉丝认为职业外部永远跨不过身份距离，于是直接把自己职业化，进入内部。

## 视觉符号
粉丝席↔后台通行证；观看者↔被观看者；经纪人递出的工作机会；广告摄影棚；两名偶像并列但视线错开。

## 可复用母题
**为了进入某个人的世界，我把自己改造成那个世界认可的人；等我真的被认可时，我已经不再只是为了那个人而存在。**

## 矿级
**S。**

它补出母库此前没有的一种“成为偶像原因”：**偶像职业作为私人关系的社会通行证**。更重要的是，职业成功越真实，最初的私人目的越无法继续支配这个身份。
