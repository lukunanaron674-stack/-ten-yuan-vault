# 日韩偶像题材_母库增量_R32

## 《IDOLiSH7 / アイドリッシュセブン》｜日本游戏→TV动画/多媒体企划｜S矿

### 1. 样本价值
核心不是普通“公司招七个人组男团”，而是：公司一开始要求七名候选者通过内部选拔，只能留下三人出道；但实际观察中，七个人的个性与功能形成互补，选拔逻辑从“找最强个体”被改写成“保留完整组合”。因此偶像身份不是单个人赢得名额，而是成员彼此构成以后才成立。

### 2. 偶像身份如何建立
- 第一阶段：七名“偶像之卵”被小鸟游事务所聚集，尚未真正出道。
- 第二阶段：内部 audition 原设定只能留下3人，职业入口带有强淘汰结构。
- 第三阶段：通过选拔与相处，七人的差异被重新理解为组合资源，最终以 IDOLiSH7 全员身份起步。
- 第四阶段：开始共同生活、lesson、宣传、Live，以真实工作把“临时拼出的七个人”压成公共团体。
- 第五阶段：从小型起步逐步扩展到网络节目、影视、组合活动、与顶级团体竞争，公众身份持续加厚。

### 3. 行业机制
- 训练：共同 lesson，早期甚至通过暂停活动、观看顶级团 TRIGGER 的 Live 来建立职业自觉。
- 出道：不是个人单点出道，而是先解决“到底谁能留下”的内部选择，再形成完整组合。
- 竞争：既有成员内部差异，也有与 TRIGGER 等成熟团体的外部职业标尺。
- 舞台：初 Live、后续演出、节目、活动持续构成成长量尺。
- 粉丝：不是一开始就有稳定粉丝盘，而要靠宣传、Live、网络节目逐渐积累公众注意。
- 公司：小鸟游事务所既提供入口，也最初设置“只能3人”的筛选规则；管理者对组合价值的判断可以反过来改写制度初始方案。

### 4. 主角欲望与代价
群体主欲望：作为 IDOLiSH7 一起成立，而不只是各自抢到一个出道名额。
代价：训练、宣传、职业自觉、个人目的冲突、角色分工、公众评价，以及为了团体完整性放弃“只优化个人胜率”的选择。

### 5. 十元体量
- n：10｜七个人之间的互补关系不是装饰，而是职业身份成立的核心材料。
- x并z：10｜个人候选身份→七人团体身份→公众偶像身份逐层叠加。
- xn：10｜audition、lesson、Live、宣传、节目、事务所规则持续加工。
- zx：9｜成员从被选拔逐步转为主动维护团体、职业与舞台。
- nx：9｜最初“只能3人”、职业标准、成熟对手、市场反馈持续反推。
- nz：9｜成员互相认可、经理支持、粉丝反馈让临时组合沉淀为真实共同体。
- x：9｜七人个性与能力差异成为组合资源，而非单纯优劣表。
- zn：8｜“我为什么当偶像”与“我属于这个团吗”持续发生个体本体追问。
- z：8｜各成员过去与各自目的不断进入当前团体关系。
- xz：6｜有重大压力与转折，但不是系统死亡/超自然命运强迫型。

主元：n + x并z
次元：xn + zx

### 6. 顺序
**nx → x并z(候选) → xn选拔 → x差异显影 → n互补 → zx保全整体 → x并z(团体) → xn持续职业化 → nz公众/队友沉淀 → 新zn**

解释：
公司先用淘汰规则把七人置于竞争 → 每人先只是候选偶像 → audition 与共同实践显露差异 → 差异没有只被排序成强弱，而是被重新解释为互补 → “留下谁”变成“为什么不能七个都留下” → IDOLiSH7 这个团体身份成立 → 通过 Live、宣传、节目继续职业化 → 团体与公众关系沉淀 → 个体开始把“IDOLiSH7成员”认领成本体的一部分。

### 7. 五维
- 空间维 x并z+n：10/10｜本作最强维度；偶像不是个人属性，而是七人关系结构+团名+事务所+舞台共同生成的社会单位。
- 时间维 xn+z：10/10｜一次选拔不能完成偶像身份，持续 lesson、Live、节目与过去经历共同沉淀职业历史。
- 因果维 zx+nx：10/10｜淘汰规则先压人，成员与管理者再主动改写“谁该留下”的判断。
- 本体维 zn+x：9/10｜个人差异最终必须从“我不如别人”转成“我在这个组合里是什么”。
- 命运维 xz+nz：8/10｜外部压力存在，但真正使角色留下的是关系与共同实践，而非单一命运锁死。

### 8. 关系结构
- 七名成员 ↔ 七名成员：竞争者→互补者→共同体成员。
- 成员 ↔ 小鸟游紡：被管理者与识别组合价值的管理者。
- IDOLiSH7 ↔ TRIGGER：新人整体与成熟职业模板的外部比较。
- 个人 ↔ 团体：个人优势不能脱离团体价值单独解释。
- 团体 ↔ 粉丝：公众注意逐渐把内部组合变成社会事实。

### 9. 动态链
#### 链A｜反淘汰组队
**nx限定名额 → 个体竞争 → xn选拔 → x差异显影 → n互补价值出现 → zx改写选择逻辑 → 全员x并z团体化**

#### 链B｜偏差转资源
**成员A的强项/弱项 → 与成员B形成错位 → 单人评价里是缺陷 → 放入n结构后成为互补 → 团体整体x大于单人排序结果**

#### 链C｜空团名实体化
**公司命名/组队 → 只有形式x并z → lesson/宣传/Live反复实践 → nz队友/粉丝沉淀 → 团名获得历史 → 新zn与新x并z成立**

#### 链D｜职业自觉生成
**拥有偶像标签 → 尚无职业自觉 → xn暂停/观摩成熟Live → nx差距刺激 → zx重新投入 → “想出道”升级为“知道职业意味着什么”**

### 10. 反咬点
1. **淘汰制度本来用于找“最好的人”，却可能因为忽略互补性而删掉“最好的组合”。**
2. **成员越不同，内部摩擦越大；但正是这些差异让团体比同质化精英更有完整功能。**
3. **团体最初只是公司安排，长期实践以后却会变成不能轻易拆分的共同体。**
4. **个人最弱的部分，在单人评价里是负资产，放到团队关系里却可能成为别人发挥作用的接口。**

### 11. 视觉符号
- 七人并列 audition vs “只留下3人”的名额压力。
- 个人站位/编号 vs 七人完整队形。
- 练习室镜面中的七个不同轮廓。
- 约3000人规模初Live场地与新人宣传传单，形成“巨大舞台/尚小知名度”的反差。
- TRIGGER成熟舞台 vs IDOLiSH7新人观摩视角。
- 七人宿舍/共同空间：从陌生人拼装到日常共同体。
- 团名Logo逐渐出现在海报、节目、Live与公众视野里，表示x并z体量增长。

### 12. 可复用母题
1. **反淘汰组队**：制度要求选出少数最优者，故事证明完整组合比精英裁剪更强。
2. **互补性胜过排行榜**：角色价值不只由个人分数决定，而由放进关系网络后的边际贡献决定。
3. **差异资源化**：性格冲突与偏科不是必须修平，而可被编排成团队结构。
4. **空团名实体化**：先有行政/商业名字，再靠共同实践把名字活成真实共同体。
5. **职业自觉二次出道**：拥有职业标签不等于拥有职业意识；看到成熟同行后，才真正明白自己选择了什么。
6. **弱项接口化**：一个人的缺口可以成为另一个人的作用空间，从而使n关系产生大于单体之和的价值。

### 13. 与既有样本区分
- 《Wake Up, Girls!》：濒死事务所先制造一个空偶像团，再由成员共同把组织活成实体。
- 《SELECTION PROJECT》：公众投票决定谁获得偶像资格，评价权在外部观众。
- 《Pretty Rhythm: Aurora Dream》：偏科成员通过团队暂时互补，并最终补全复合职业能力。
- 《IDOLiSH7》：**公司内部原本要从七人裁到三人，但共同实践揭示“成员之间的组合价值”无法由单人淘汰赛表达，因此选拔逻辑本身被反转。**

### 14. 新增正式分类
## 「反淘汰组队 / 互补性职业生成型」

母链：
**有限名额 → 个体比较 → 差异显影 → 关系互补 → 拒绝单体裁剪 → 团体身份成立 → 长期职业化 → 个体本体回写**

矿核：
> 某些职业身份不是“选出最强的几个人”就能制造。真正的组合价值只会在成员彼此作用以后出现；如果只按单体评分裁剪，制度可能恰好删掉那个让整体成立的人。

### 15. 矿级
**S矿**

理由：训练、选拔、Live、粉丝、事务所与团体关系全部直接参与“偶像如何成立”；更重要的是，它新增了此前库里较弱的“单体评价 vs 关系价值”机制，可迁移到乐队、战队、创业团队、骑士团、创作团队等大量群像职业题材。

### 16. 外部核验来源
