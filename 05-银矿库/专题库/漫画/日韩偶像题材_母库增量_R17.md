# 日韩偶像题材｜母库增量 R17

## となりの席の深美くんがアイドルになるかもしれない｜日漫｜S
- 作者：原作 青山はるの / 作画 ちづはるか
- 核验：集英社 S-MANGA。第1卷 2026-02-25，第2卷 2026-07-23。
- 职业机制：知名偶像选秀；目标为“选秀第1名出道”；自我PR、炎上、一次审查、练习生均已进入正文。
- 偶像职业度：9/10。

### 十元
- 主：xn（选秀制度、审查、排名、出道资格）。
- 次：nz → zx（选秀宅茜音与深美的支持关系转化为攻略赛制的主动策略）。
- 第三层：x并z（自我PR、公众形象、炎上、被观看与排名）。
- 暗层：z + zn（深美原先并不想当偶像的本体，与被推向偶像身份之间的冲突）。

### 五维
- 时间 xn+z：选秀阶段推进迫使模糊愿望不断被重新确认。
- 本体 zn+x：私人学生自我与可训练、可展示的偶像候选身体发生重叠。
- 空间 x并z+n：节目曝光把私人关系放入练习生、观众、排名的公共网络。
- 因果 zx+nx：茜音主动提供策略，两人同时受审查、赛制和排名支配。
- 命运 xz+nz：两人关系越深，职业选秀结果越可能反过来决定关系走向。

### 顺序链
nz → zx → xn → nx → x并z → n → zn

### 生链
1. nz生zx：理解与支持催生具体选秀攻略。
2. zx生x并z：策略直接改造自我PR、形象管理和公众可见性。
3. xn生n：赛制把个人拉入练习生竞争网络。
4. x并z生zn：持续被公众当作偶像候选人观看，反过来塑造职业本体。

### 克链
1. xn克zx：个人策略必须服从审查、排名与节目规则。
2. x并z克zn：炎上和节目形象可能覆盖私人真实自我。
3. nz反克xn：茜音对生存选秀语法的理解可以帮助深美利用制度。
4. zn反克x并z：若深美始终不认领偶像身份，再成功的节目包装也无法完全成立职业本体。

### 5组补子
- xn+z：制度进程补足真实职业愿望。
- zn+x：私人本体与现实训练/展示条件互补。
- x并z+n：公众形象依靠节目、练习生和观众关系网成立。
- zx+nx：主动攻略赛制与被赛制规定同时存在。
- xz+nz：职业结果与关系命运互相绑定。

### 新母型｜外部“选秀宅”代理制作人型
熟悉生存选秀语法的普通观众不亲自参赛，而把长期观看积累的规则知识转化成候选人的职业资本：
**外部观看经验(nz/xn知识) → 策略(zx) → 候选人公众表现(x并z) → 排名/出道资格(xn)**。

与《アイドラトリィ》形成对子：后者是粉丝本人跨入100人选秀；本作是选秀宅留在系统外，以策略影响系统内候选人。

### 反咬点
茜音越擅长把深美“做成一个能赢选秀的人”，越可能制造一个符合节目规则、却偏离深美私人本体的偶像形象。帮助他成为偶像的能力，也可能成为改写他的力量。
