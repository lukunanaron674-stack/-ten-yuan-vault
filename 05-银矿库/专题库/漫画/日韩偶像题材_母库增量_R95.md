# 日韩偶像题材母库增量 R95

## 《MAVE: 또 다른 세계 / MAVE: Another World / MAVE：另一个世界》

- 媒介：韩国 WEBTOON（Kakao Webtoon / KakaoPage；Tapas 英文版）
- 状态：已完结，英文版 51 episodes（含 Episode 0）
- 核心样本等级：**S矿**
- 新增母型：**连带污名 / 风险源强制组队型**
- 次级母型：**职业资格受关系网络污染 / 被迫与污名来源共同自证**
- 排除误判：核心不是普通娱乐圈恋爱，而是“出道组被取消 → 生存节目再竞争 → 强制与争议人物组队 → 重新争夺职业资格”的偶像成长线。

---

## 一、作品入口｜偶像身份如何建立

主角李泽娜（Lee Zena / 이제나）本来已经进入女团出道组 Clear，职业身份几乎走到正式出道前最后一步，却因为同公司前辈女团 Arose 成员 Ju Siu（주시우）的暴力争议引发反弹，整个出道计划被取消。

泽娜没有因此退出偶像道路，而是独自准备偶像生存节目《To Be Dol》，再次争取出道资格。随后神秘对象“T”与任务窗口出现，系统反复要求她必须与自己认定为“毁掉第一次出道的人”Siu组队参赛。

因此本作真正的职业问题不是：

> “我有没有能力成为偶像？”

而是：

> **“为什么别人的丑闻能先夺走我的出道资格，而我第二次争取资格时，又必须和这个风险源绑定在一起？”**

这形成了一个此前母库中相对缺失的结构：

**职业身份不是只由个人能力决定，它还会被公司、团队、前辈、舆论等关系网络连带污染。**

**n + xn + nx + x并z**

> **个人能力x已经存在，但职业资格要先穿过关系n、制度xn、舆论nx和公众身份x并z四层过滤。**

## 三、顺序感谱

### 主链顺序

**z（231） → nx（213） → zn（132） → zx（312） → x并z（213） → xn（213） → n（123） → nz（慢123） → 新zx（312） → 新x并z（213）**

解释：

1. **z｜231**：第一次出道被取消成为强历史爆点。
2. **nx｜213**：他人丑闻、公司判断与舆论先把后果压到泽娜身上。
3. **zn｜132**：开始出现“我明明没做错，为什么我的职业身份被一起判死”的本体裂缝。
4. **zx｜312**：不接受第一次失败结论，主动转入《To Be Dol》。
5. **x并z｜213**：从“被取消出道者”改写成“生存节目候选练习生”。
6. **xn｜213**：节目任务、组队、评级与公开竞争重新决定资格。
7. **n｜123**：与Siu的关系从纯风险源变成必须真实协作的职业结构。
8. **nz｜慢123**：新信任与观众理解逐渐累积，旧污名不再是唯一解释。
9. **新zx｜312**：从“为了证明我没错”升级成“我主动决定怎样一起出道”。
10. **新x并z｜213**：新的偶像身份不再只是逃离旧丑闻，而由新关系与新舞台重新坐实。

## 五、训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 1. 训练
- 泽娜不是零基础素人，而是已经进入过出道组的练习生。
- 重点不是“第一次学唱跳”，而是旧能力如何在第二套竞争制度中重新被读取。
- 因此训练承担的是**再验证**，不是单纯补课。

### 2. 出道
- 第一次：Clear 出道组已接近正式成立，却因同公司争议被取消。
- 第二次：通过《To Be Dol》重新争夺出道资格。
- 出道由一次线性过程变成：**资格获得 → 连带撤销 → 资格再争夺**。

### 3. 竞争
- 生存节目把个人能力、团队表现与公开评价重新绑定。
- 主角无法只证明“我比别人强”，还必须证明“我和这个团队可以成立”。

### 4. 舞台
- 舞台承担“重新记账”功能：每一次真实表演都在给新的职业身份增加z履历。
- 旧舆论说“她属于那场丑闻的失败者”，新舞台则不断生产相反证据。

### 5. 粉丝 / 公众
- 公众既可能是旧污名的放大器，也是新身份的重新承认者。
- 因此 nz 与 nx 同时来自同一公众网络：
  - **公众相信负面关联 → nx**
  - **公众重新理解并支持 → nz**

### 6. 公司 / 节目
- 公司并非只评价个人能力，还会因整体品牌风险取消整个项目。
- 生存节目则提供第二套合法性机制，把被公司取消的职业资格重新开放给公开竞争。

## 六、主角欲望与代价

### 初始欲望
**我要出道。**

而且不是抽象梦想，她已经走到出道组阶段，所以第一次取消造成的是：

> **“几乎已经属于我的职业未来，被一个不是我做出的事件夺走。”**

### 代价
- 必须重新从候选身份开始。
- 必须重新接受公众审视。
- 必须和自己认定的风险源Siu绑定。
- 必须允许“我对她的判断也可能需要重新验证”。

因此职业代价不仅是训练辛苦，而是：

> **重新进入一个曾经证明‘个人无辜也可能被关系连坐’的系统。**

## 七、关系结构

### 核心对子

**泽娜 ↔ Siu**

初期：

**受害者认知 ↔ 风险源认知**

职业上却被迫变成：

**队友 ↔ 队友**

因此n不是温柔友情，而是一个强制职业接口。

### 关系变化

**旧z事件**
→ 泽娜把Siu固定成“毁掉我未来的人”
→ 系统强制组队
→ xn要求共同完成职业任务
→ 双方真实行动逐渐产生新证据
→ 旧标签不能完整解释现在
→ n从风险绑定转成真实协作
→ nz开始生成

这里得到一条重要规则：

> **关系标签可以先于关系本身成立，但长期共同实践会反过来审判标签。**

## 八、动态链

### 动态链A｜连带污名链

**他人事件z**
→ **公司/公众nx扩散**
→ **主角x并z职业身份被撤销**
→ **zn受损**
→ **zx重新争资格**

矿核：

> **职业风险可以沿n网络传播，不需要主体本人做错任何事。**

---

### 动态链B｜风险源强制组队链

**旧z把B定义为风险源**
→ **xn强制A与B合作**
→ **n被迫成立**
→ **共同任务产生新z**
→ **新z与旧z冲突**
→ **zn重新判断B**
→ **n真实化**

矿核：

> **最强的关系重估，不是听解释，而是被迫和“你认为有问题的人”一起承担真实职业结果。**

---

### 动态链C｜公众重新记账链

**旧舆论x并z**
→ **新舞台zx**
→ **xn公开评价**
→ **nz新支持**
→ **z新履历**
→ **新x并z覆盖旧单一标签**

矿核：

> **舆论不能被一句澄清清零，但可以被长期新结果逐渐改写。**

## 九、最大反咬点

### 反咬1｜“无辜”并不能自动保住职业资格

主角个人没制造争议，但公司项目仍然被取消。

所以：

> **职业世界判断的不只是‘你有没有错’，还会判断‘你所在的关系网络是否值得继续投资’。**

得到：

**个人无责 ≠ 职业无风险**

这条可迁移到：
- 乐队成员丑闻拖累整团
- 游戏主创争议导致整个项目被撤
- 工作室成员违规影响所有合作
- 运动队一人禁赛改变全队资格

---

### 反咬2｜为了摆脱某个人造成的阴影，反而必须和那个人绑定

常规解决方案应该是：

**离风险源越远越好。**

但系统偏偏要求：

**想重新出道 → 必须和Siu组队。**

于是：

> **逃离路径被切断，主体只能通过共同实践重新判断因果。**

这比“误会解除”更有职业重量。

---

### 反咬3｜一次争议会把关系事实压扁成公众标签

公众很容易把复杂结构压成：

**“她们是同公司的人。”**

然后：

**同公司 → 同风险 → 一起取消。**

于是：

> **x并z公众分类会把复杂n关系压缩成简单连带关系。**

职业者真正需要争夺的不只是清白，而是：

**“请重新区分我们分别做过什么。”**

---

### 反咬4｜新合作成功会削弱“我只是受害者”的本体位置

一开始泽娜的自我解释很稳定：

**我的未来被别人毁了。**

但如果她后来和Siu共同完成真正的舞台、任务与竞争：

**新事实越多**
→ **旧受害者叙事越不够完整**
→ **zn必须扩大**

于是：

> **被伤害的历史是真的，但它不能永远垄断主体全部职业身份。**

## 十、视觉符号

1. **已准备好的出道组宣传照 / 名牌 → 被划掉或撤下**：x并z被行政删除。
2. **空掉的练习室站位**：第一次职业未来突然中止。
3. **生存节目号码牌**：身份从“准出道成员”降回“候选人”。
4. **泽娜与Siu被迫站进同一队形**：n由冲突强制成立。
5. **手机负面舆论 / 热搜 → 新舞台观众反馈**：nx与nz来自同一公众网络。
6. **两人背对背 → 同步舞台动作**：关系从风险绑定转成职业协作。
7. **旧组合Clear标识 → 新节目/新团队标识**：社会身份重新记账。

最强视觉母题：

> **第一次：两个人的名字因为同一场丑闻被绑在一起。第二次：两个人在同一个舞台上主动把这条绑定关系改写。**

## 十一、可复用母题

### 1. 连带污名
一个人的事件沿组织关系传播，夺走无关成员的资格。

### 2. 风险源强制组队
想脱离某个风险，却必须和风险来源共同完成任务才能继续前进。

### 3. 关系网络职业风险
职业价值不仅属于个人，也取决于“你和谁绑定”。

### 4. 公开身份重新记账
不能删除旧历史，只能靠新结果不断增加相反证据。

### 5. 被害者身份反咬
受害历史提供合理愤怒，但如果永远只用这一解释理解自己，会妨碍新职业本体生成。

### 6. 公司风险管理 vs 个人公平
公司从品牌安全角度做出的“合理”决定，可能对具体无辜者极不公平。

### 7. 强制共同实践重估关系
解释和道歉无法解决的标签，通过共同承担真实结果重新审判。

## 十二、与旧矿边界

- 《SELECTION PROJECT》：公众投票直接生产偶像资格。
- 《IDOL x IDOL STORY!》：同行、公众、制作人等多评价主体轮换。
- 《Who’s That Girl?》：主体自己的名字被虚假污名污染，只能建立新社会账户重新竞争。
- 《MAVE: Another World》：**主体本人没有核心污名，却因为同公司/团队关系被他人争议连坐；第二次出道时，又被迫与这个“风险源”直接组队。重点是职业风险沿n关系网络传播，以及n如何通过长期共同实践被重新定义。**

因此本轮不是“个人洗白型”，而是：

# **「连带污名 / 风险源强制组队型」**

---

## 十三、最终矿核

> **职业世界并不只评价一个人本身，也会评价他所在的关系网络。别人制造的丑闻可以沿公司、团队与公众标签传播，直接夺走无辜者的职业未来；而更残酷也更有戏剧性的成长，是主体第二次争夺资格时，不能简单切断关系，而必须和自己认定的风险源一起训练、竞争、登台，用新的共同结果重新回答：这段关系究竟只意味着拖累，还是也可能成为新的职业共同体。**
