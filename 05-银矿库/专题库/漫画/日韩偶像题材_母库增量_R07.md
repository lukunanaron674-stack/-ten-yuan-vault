# 日韩偶像题材｜母库增量 R07

## 1. The Youngest Must Become an Idol / The Maknae Has to Be an Idol｜韩漫/Webtoon｜S

### 职业证据
Tapas官方英文漫画共57话并标为Completed series。主角Bong Taeyoon五年前是即将出道的idol trainee，车祸后成为唯一幸存者，神秘来电把他送回关键时间点。官方章节名直接出现 The Showcase、The Performance、Opening Stage、The Voting System、Last Place、A Different Ranking，说明职业机制不是背景，而是持续进入展示、舞台、投票、排名。

### 新母型
**“退出职业 = 队友死亡：个人失败判断被团体命运强行否决。”**

### 十元分析
- 主：xz（死亡历史 + 队友生死条件锁定）
- 次：xn（回到五年前、出道组规则、投票排名）
- 次：zx（为了保住成员主动重做职业路线）
- 强关系层：nz（hyung/团体成员的命运共同体）
- 本体层：zn（“我是注定失败的偶像”被迫重新验证）
- 包装层：x并z（showcase、performance、opening stage、公众排名）
- 被动层：nx（不能自由退出；退出会触发死亡）

### 五维
- 时间 xn+z：回到事故前，旧失败记忆与未完成偶像执念进入第二轮。
- 本体 zn+x：旧自我定义“失败偶像/不该留在团里”与重新具备的年轻身体、技能条件冲突。
- 空间 x并z+n：showcase、舞台、投票与排名把个人能力放入公众/团体关系场确认。
- 因果 zx+nx：主动训练、表演、保团，与“不能退出”的强制条件持续咬合。
- 命运 xz+nz：成员死亡条件与hyung关系直接绑定，职业选择变成共同命运。

### 生链
**xz事故与死亡历史 → xn时间回归 → nx退出被禁止 → nz队友关系成为责任 → zx重新参加展示/舞台/排名 → x并z职业承认增长 → zn重新定义“我是否该成为偶像”。**

### 克链
1. xz克nx式退出：原本“我退出对大家更好”的退让，被死亡条件彻底否决。
2. nz克个人zn：自我评价不再足以决定职业去留，队友生命把本体选择外部化。
3. zx克nx：主动训练和舞台执行逐步夺回被系统锁死的选择权。
4. xn排名反克zn：投票/排名会把“失败偶像”的自我判断变成可被现实重新验证的数据。

### 5组补子
- xn+z：时间回归/职业规则 + 没有消失的偶像执念。
- zn+x：失败偶像自我 + 回到可重新出道的现实身体条件。
- x并z+n：舞台包装/排名 + 团体与观众关系场。
- zx+nx：主动重做职业路线 + 无法退出的强制条件。
- xz+nz：死亡命运 + 队友/兄长关系，是本作最强补子。

### 偶像职业度
**10/10｜S矿。**

### 与 Debut or Die! 的关键差异
Debut or Die! 是“我不出道，我死”；本作是**“我退出，队友死”**。前者把职业成功绑定个人生存，本作把职业坚持绑定关系网络，因此 xz+nz 的体量显著更高。

## 2. Feeding the Lives of Failing Idols / Saving the Doomed Idols With My Touch｜韩漫/Webtoon｜S

### 去重
两英文名及 Save a Failed Idol's Life 均为同一作品，不重复建卡。

### 职业证据
Tapas官方漫画85话，已完结。Hyunsung原是餐饮企业家/厨师，死后必须以Climax队长Cheon Yise身份，把失败偶像团体Climax救活并实现successful comeback，才能获得复仇机会。职业目标直接是“经营一个失败团体并让其重新成功”。

### 新母型
**“把偶像团当濒死企业经营：后台经营能力转译为前台团体生存力。”**

### 十元分析
- 主：zx（经营、整顿、救团的主动因果）
- 次：xz（死亡后特殊任务/复仇条件）
- 次：n（团体作为必须被维系的关系场）
- 次：x并z（comeback、偶像形象与公众重新承认）
- 规则层：xn（偶像团运营与回归路径）
- 本体层：zn（厨师/企业家进入偶像队长身份）
- 现实能力层：x（餐饮、经营技能被跨职业迁移）

### 五维
- 时间 xn+z：失败团已有五年耗损史，职业规则与“必须翻盘”的执念叠加。
- 本体 zn+x：企业家/厨师能力进入偶像队长身份，形成跨职业本体错位。
- 空间 x并z+n：回归包装必须重新激活团体、粉丝与市场关系场。
- 因果 zx+nx：主角主动经营救团，但复仇资格迫使他必须完成偶像任务。
- 命运 xz+nz：死亡/复仇任务把他与Climax成员绑定成命运共同体。

### 生链
**xz死亡与复仇条件 → zn进入偶像队长身份 → x旧经营能力迁移 → zx整顿失败团 → n成员关系重新组织 → xn执行回归职业路径 → x并z公众偶像身份复活。**

### 克链
1. zx克团体nx：主动经营打断“糊团只能继续糊”的惯性。
2. x跨职业克xn：偶像行业内部解决不了的问题，被外部企业经营能力突破。
3. n反克个人zx：团体不是餐厅，成员意志与关系不能完全按CEO逻辑管理。
4. x并z反克zn：当Cheon Yise真正成为成功偶像队长，原本“只是借身份复仇”的本体会被新职业反向改写。

### 5组补子
- xn+z：偶像回归规则 + 必须翻盘的目标执念。
- zn+x：厨师企业家自我 + 可迁移的现实经营能力。
- x并z+n：回归包装/公众形象 + Climax团体关系。
- zx+nx：主动救团经营 + 特殊任务强制牵引。
- xz+nz：死亡复仇条件 + 与失败团成员绑定的共同命运。

### 偶像职业度
**10/10｜S矿。**

### 与 Rogue Producer 的差异
Rogue Producer偏“幕后制作人被推上前台成为偶像”；本作更偏**“外行业经营者进入一个已经失败的偶像团，目标不是先获得出道资格，而是修复团体经营并完成comeback”**。因此它补的是“糊团再生/团体经营”而非“个人出道”。

## R07结论
本轮不是简单再塞两个重生男偶像，而是补齐两块此前薄弱机制：
1. **关系命运型**：The Youngest Must Become an Idol，把“必须当偶像”从个人生死升级为队友生死。
2. **糊团经营型**：Feeding the Lives of Failing Idols，把偶像职业拆成团体经营、关系修复、回归包装与市场再承认。
