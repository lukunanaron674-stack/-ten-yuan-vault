# 日韩偶像题材｜母库增量 R11

## Who's That Girl?｜韩漫/Webtoon｜S

### 收录理由
Sanghyeon Kim 有成为K-pop明星的能力与动力，却因虚假的校园霸凌指控持续遭到行业拒绝；大型娱乐公司负责人给予的神秘道具使其变成前世的女性身体，由此获得第二次进入偶像职业系统的机会。WEBTOON连载内容已经明确进入 vocal training 等职业训练环节，因此不是普通娱乐圈恋爱背景，而是“职业资格被社会标签封锁→身体/公众分类改变→重新争取偶像资格”的核心偶像叙事。

### 十元分析
- 主符号：x并z（公众可见身份/职业包装与社会分类）。
- 次符号：xz → x → xn → zx；暗层：zn。
- 顺序链：xz（霸凌污名封路）→ nx（反复被拒）→ x（身体条件改变）→ x并z（公众分类改变）→ xn（重新进入公司训练规则）→ zx（主动训练/竞争）→ zn（重新确认“我能否成为偶像”）。
- 生链：xz生nx；x生x并z；x并z生xn；xn生zx；zx生zn。
- 克链：xz克zx（污名让能力无法兑现）；x并z克旧xz（新外形/新身份暂时绕过旧标签）；xn克个人自由但提供职业入口；zx反克nx（训练与行动结束被动淘汰）。
- 反咬点：职业机会不是因为能力突然出现，而是因为“社会看到的是谁”发生变化。若同一能力只有换身体/换公众分类后才被行业承认，则成功反过来证明旧失败并非纯粹能力问题。

### 五维
- 时间：xn+z——长期被拒与第二次机会，把旧梦想重新压回职业时间线。
- 本体：zn+x——“我是谁”与“我以什么身体/条件被看见”直接冲突。
- 空间：x并z+n——娱乐公司、公众形象、训练场与观众网络决定职业可见性。
- 因果：zx+nx——主动追梦长期被污名压成被动失败，身体改变后重新取得行动权。
- 命运：xz+nz——过去的社会指控持续绑定未来，新的职业关系网络则可能改写这条命运。

### 体量
x并z10 / x9 / xz9 / xn9 / zx8 / zn8 / nx7 / z7 / n6 / nz5。

### 5组补子
1. xn+z：职业制度/训练规则 + 持续成为偶像的愿望。
2. zn+x：真实自我 + 被行业读取的身体条件。
3. x并z+n：公众偶像包装 + 公司/观众/行业关系网络。
4. zx+nx：主动训练竞争 + 被污名造成的长期被拒。
5. xz+nz：过去污名命运 + 新职业关系能否解除旧命运。

### 判定
- 核心偶像职业度：10/10。
- 矿级：S。
- 新母型：**社会污名封锁职业资格 → 换身体/公众分类绕行 → 同一能力重新被承认**。
- 与《Wanna be a Star!》差异：后者是身体/声线导致“女团不适配→男团分类反而适配”；本作更狠，先有社会污名直接封锁职业，再通过身体与公众身份变化重新取得入口，核心是“能力没有消失，但谁拥有这份能力会改变行业判决”。

## R11结论
本轮不重复加入已有的回档出道型作品。Who's That Girl? 补入的是目前母库较少的“污名/社会身份 → 职业资格”机制，可并入母型谱系 E「职业资格与分类」，同时与《Wanna be a Star!》《This Life's Universal Superstar》形成三分：职业分类改变 / 身体技能改变 / 社会身份读取改变。
