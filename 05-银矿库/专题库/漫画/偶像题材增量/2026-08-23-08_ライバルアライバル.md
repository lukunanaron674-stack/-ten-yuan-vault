# ライバルアライバル｜十元增量

- 地区：日本
- 作者：永田さんずい
- 状态：连载中；2026-06-05 第1卷发行（196页）；2026-08 已推进至第9话附近
- 判定：核心偶像职业度 9.5/10｜95分｜S矿

## 职业机制
61岁的久美华与永亚曾是风靡一时的偶像组合「フォーエバーズ」。两人在20代争吵分离，久美华退出艺能界，永亚继续成为超人气偶像并在引退后进入职场。永亚被宣告余命5年后提出“再做一次偶像”，久美华最初因年龄与不愿展示衰老而拒绝，后来接受，两人以真实的60代身体重新进入偶像职业，并面对年龄标签、体力与社会偏见。

## 十元
- 主符号：xz（余命5年、旧组合终结、年龄不可逆）
- 次符号：nz → zx → n → x并z
- 强层：x + zn
- 规则层：xn
- 暗层：nx + z

### 顺序链
xz余命/旧职业终结 → nz旧搭档关系重新接通 → z再次站上舞台 → x真实61岁身体成为持续职业条件 → zx主动复出 → n重建双人偶像共同体 → xn重新进入当代偶像职业规则 → x并z重新获得公众观看与偶像身份 → zn重写“61岁之后我是谁”。

## 五维
- 时间：xn + z——剩余时间被主动改造成第二次职业时间。
- 本体：zn + x——61岁身体、母亲/前偶像/职业女性等旧身份，与“现在仍是偶像”发生冲突。
- 空间：x并z + n——两人重新以组合身份进入公众舞台与粉丝空间。
- 因果：zx + nx——主动复出与年龄、体力、标签等现实限制持续对抗。
- 命运：xz + nz——余命与旧搭档关系共同迫使“结束”重新变成职业起点。

## 生链
xz生z → nz生zx → zx生n → n生x并z → x并z反生zn。

## 克链
xz克旧z；x克zx（年龄/体力摩擦）；xn克zx（当代职业规则）；x并z克旧zn（公众重新把她们读取为偶像）；新zn反克年龄标签。

## 5组补子
1. xn + z：限时第二职业计划
2. zn + x：61岁真实身体与偶像本体
3. x并z + n：公众舞台与重组双人单位
4. zx + nx：主动复出与现实阻力
5. xz + nz：余命终点与旧搭档关系

## 新母型
**不年轻化的老年偶像复职 / 余命倒计时再职业化型**。

与《祖母ドル》不同：后者通过身体年轻化重新打开职业入口；本作拒绝身体重置，61岁本身就是持续存在的职业条件。与《永久少年 Eternal Boys》也不同：后者是中年人的第一次偶像职业/第二职业转入；本作是曾经成功过的偶像在几十年后重新取得同一职业身份，属于“职业中断后的超长周期复职”。

## 反咬点
最初复出可以被解释为“余命5年最后做一次旧梦”，但一旦新的观众、舞台和职业关系成立，x并z会反过来改写zn：她们不再只是怀旧地扮演过去的自己，而是在61岁这个身体条件下制造新的偶像事实。于是作品有机会反向修改xn层面的默认规则：偶像职业是否天然属于年轻身体。
