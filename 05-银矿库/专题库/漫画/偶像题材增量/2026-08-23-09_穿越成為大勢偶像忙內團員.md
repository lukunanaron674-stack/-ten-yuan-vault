# 穿越成為大勢偶像忙內團員｜十元增量

- 英文常用名：My Comeback as the Youngest Member
- 核心职业：K-pop 练习生 / 生存选秀 / 团体出道
- 矿级：S
- 核心偶像职业度：10/10
- 官方证据：LINE WEBTOON。都书韩曾参加《STARDUST Project》，最终7人出道，他以第8名淘汰；八年后事故回到八年前，重新争夺舞台，并可能改写团体命运。

## 十元
- 主符号：xz
- 次符号：xn → zx → x并z
- 强层：z + zn + n
- 暗层：nx + nz

## 核心动态链
xz第8名淘汰/八年失败历史 → xn回到选秀时间点 → z第二次出道愿望 → zx利用失败经验重新竞争 → n重新进入STARDUST候选关系网 → x并z争取前7名与正式团体身份 → zn由“第8名落选者”改写为“出道成员”。

## 五维
- 时间：xn+z
- 本体：zn+x
- 空间：x并z+n
- 因果：zx+nx
- 命运：xz+nz

## 生链
xz生z → xn生zx → z生zx → zx生x并z → n生zx → x并z反生zn。

## 克链
xn克旧xz → zx克nx → x并z克旧zn → xz克z → 新zn反克“永远第8名”的命运标签。

## 5组补子
xn+z / zn+x / x并z+n / zx+nx / xz+nz

## 新母型
**临门一位失败 / 第8名回档补位型**。

与普通“失败后重来”相比，本作的职业伤口被量化得非常具体：7人出道，而主角正好第8。第二次人生不是抽象地“变成功”，而是必须跨过那一个席位差。职业制度先用排名把失败写进本体，回档后主角再用同一制度反证旧判决。

## 反咬点
如果第二次成功，问题不是单纯“我终于变强”，而是：八年前的失败究竟来自能力不足、一次舞台误差、节目规则，还是团体组合需求？当主角进入前7名，原本出道的七人结构也会改变，因此个人修复会进一步侵入 n（团体关系）与 xz（他人命运）。
