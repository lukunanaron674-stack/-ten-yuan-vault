# さよなら僕のアイドル｜十元深拆

## 职业证据
- 集英社《周刊Young Jump》官方：舞台为高中“偶像研究会”；偶像宅男高中生角田满月身体变成女性后，遇到已经离开舞台的原推，两人一起以顶点为目标。
- 2025年第49号开始连载；单行本第1卷2026-03-18、第2卷2026-06-18发行。
- 第2卷已经明确进入“初Live→争取新成员”，目录进一步出现“第一次营业/媚び、第一次Live、第一次伙伴、新闻、化妆、自我肯定、秘密”。
- 因此不是偶像恋爱背景，而是从粉丝/退役偶像重新组建活动单位、Live、招募成员与公众包装的职业成长。

## 十元判定
- 主符号：x（身体/性别载体变化）
- 次符号：nz → zx → x并z
- 强层：zn、n、xn
- 暗层：z、xz、nx
- 核心顺序：nz旧推关系 → x身体变化 → zn身份错位 → n与退役推结成活动共同体 → zx主动组建/举行Live → xn接受校园/偶像活动规则 → x并z舞台、化妆、新闻与公众身份成立 → zn被新职业实践反写。

## 五维
- 时间：xn + z｜从偶像宅观看经验、旧推历史进入实际活动规则。
- 本体：zn + x｜“我是男偶像宅”与女性身体/偶像职业身份冲突。
- 空间：x并z + n｜Live、妆造、新闻曝光与成员共同体共同制造偶像可见性。
- 因果：zx + nx｜主动举行Live、招募成员，同时受学校/社团制度与外部阻力限制。
- 命运：xz + nz｜原本已经离开舞台的推重新出现，旧粉丝关系把主人公拖进同一职业轨道。

## 生链
1. nz 生 zx：想与旧推一起重新站上舞台，关系驱动实际偶像行动。
2. x 生 zn：身体改变迫使旧自我定义重新解释。
3. n 生 x并z：两人/新成员形成单位后，才产生Live、妆造、新闻等公众偶像包装。
4. zx 生 x并z：真正上台和营业，把“玩偶像”做成可被观看的职业事实。
5. x并z 反生 zn：公众越来越把满月识别成偶像，新身份开始获得真实性。

## 克链
1. x 克旧zn：身体变化直接破坏原有性别/自我稳定性。
2. xn 克zx：学校、生徒会、社团规则可阻断Live和成员扩张。
3. x并z 克旧zn：妆造、舞台、新闻越成功，越难继续只把自己理解成“偶像宅”。
4. nz 克zn：最初为了推而行动，会压低“我自己究竟想不想成为偶像”的自我欲望。
5. zn 反克x并z：若拒绝新身份，职业包装就无法彻底内化。

## 5组补子
1. xn + z：偶像/社团规则 + 对偶像的长期欲望。
2. zn + x：真实自我 + 改变后的身体载体。
3. x并z + n：舞台公众包装 + 偶像单位/成员共同体。
4. zx + nx：主动办Live/招募 + 被学校与外部条件限制。
5. xz + nz：退役推重新出现这一命运事件 + 旧粉丝关系重新绑定。

## 新母型
**粉丝换体后与退役推共同再职业化型。**

与《アイドラトリィ》的区别：后者是粉丝为了把推送上顶点，主动进入既有100人选秀机器；本作是粉丝先发生身体/身份改变，再与已经离开舞台的推一起从校园偶像活动重新搭建职业共同体。

与《満月をさがして》的区别：后者借替身身体绕过年龄/疾病职业门槛；本作的身体变化不是单纯准入工具，而会持续制造“旧性别本体—新身体—偶像公众身份”三层冲突。

## 反咬点
最初的逻辑是“我只是推偶像的人”；但真正办Live、营业、化妆、招募成员、被新闻和观众观看之后，x并z会反向生成zn：职业实践越真实，主人公越无法把新偶像身份解释成一次临时事故。

## 评分
- 核心偶像职业度：9.5/10
- 十元采矿：94/100
- 矿级：S
- 高价值原因：把粉丝关系、退役偶像再起、身体/性别本体变化、校园单位经营和Live职业化压在同一条链上，补足现有库中“与退役推共同从零再建偶像单位”的缺口。
