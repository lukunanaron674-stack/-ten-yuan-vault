# ニセドル｜十元分析

## 职业事实
昴为了寻找已经成为顶级偶像、却忘记自己并抹去过去经历的青梅竹马，接受朋友建议，以女装身份亲自进入偶像职业路线。秋田书店官方已出版2卷（2025-11-07、2026-03-06），核心不是偶像恋爱背景，而是“为了进入已经职业化的旧关系所在世界，自己也成为偶像”。

## 十元
- 主符号：x并z（女装偶像身份、公众职业包装）
- 次符号：nz → zx → xn
- 强层：zn + x
- 暗层：xz + z
- 顺序链：nz旧关系 → x身体/性别呈现加工 → x并z女装偶像身份 → xn进入偶像职业规则 → zx主动追赶/调查 → n形成职业关系网 → zn旧自我被新公众身份反写

## 五维
- 时间：xn + z｜旧约定与当前职业制度之间的时间断裂。
- 本体：zn + x｜“我是昴”与“被社会读取为女性偶像的身体/呈现”冲突。
- 空间：x并z + n｜只有取得偶像包装和职业位置，才能进入青梅竹马所在的社会空间。
- 因果：zx + nx｜主动女装追赶，但必须接受行业规则、审查和身份隐瞒。
- 命运：xz + nz｜旧关系被对方遗忘/履历抹除，迫使关系通过职业化重新连接。

## 生链
1. nz 生 zx：旧约定与寻找青梅竹马的关系目标，产生主动追赶。
2. zx 生 x并z：追赶必须制造“女偶像”可被行业读取的职业身份。
3. x并z 生 n：公众身份成立后，才能进入偶像圈层和关系网络。
4. xn 生 x并z：职业规则持续塑造妆造、行为、舞台与身份一致性。
5. x并z 反生 zn：假身份被持续实践后，开始制造新的真实自我解释。

## 克链
1. x并z 克 zn：为了靠近旧关系，必须压住原本男性/旧自我身份。
2. xn 克 zx：个人调查目的必须服从偶像行业规则。
3. xz 克 nz：青梅竹马失忆与履历抹除切断旧关系的直接通路。
4. nz 克 zn：为了追回“我们过去是谁”，主角不断牺牲“我现在是谁”的稳定性。
5. zn 反克 x并z：真实身份一旦暴露，职业包装可能崩坏。

## 5组补子
1. xn + z：行业制度 ↔ 旧约定/执念。
2. zn + x：真实本体 ↔ 身体与性别呈现。
3. x并z + n：偶像包装 ↔ 职业关系网络。
4. zx + nx：主动追赶 ↔ 被行业与伪装约束。
5. xz + nz：失忆/过去被抹除 ↔ 青梅竹马旧关系。

## 新母型
**关系追踪职业化 / 伪装身份通行证型**：不是因为想当偶像而成为偶像，而是旧关系已经被职业阶层隔开，只能把自己改造成同一职业者，才能重新取得接近、调查和对话资格。

## 反咬点
最初的女装偶像身份只是进入青梅竹马世界的“通行证”。但训练、舞台、粉丝与行业关系一旦持续累积，假的 x并z 会获得真实社会后果，最终可能反过来要求 zn 回答：如果所有人都把这个身份当真，而且自己也真正完成了偶像劳动，它还只是伪装吗？

## 与已有样本差异
- Crown of Love：普通粉丝为了接近推而职业化；本作是青梅竹马旧关系断裂后，为追索被抹除的过去而职业化。
- Who’s That Girl?：身体/社会身份重置绕过旧污名；本作主动制造女装公众身份作为职业通行证。
- AKB49：身份伪装发生在高密度偶像制度内部；本作把伪装首先作为“追回旧关系”的进入手段。
