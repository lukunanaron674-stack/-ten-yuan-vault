# TRAINEE 51｜十元初拆

## 职业证据
WEBTOON 官方简介明确：50名参赛者竞争新 K-pop 团体 ZENITH PRISM 的席位。2026-03-03 发布 Prologue；当前公开体量仍很薄，因此只升观察矿，不升核心 S/A。

## 十元判定
- 主符号：xn（选秀/席位/出道规则）
- 次符号：zx（主动竞争）→ x并z（舞台与出道身份）
- 支撑：n（50人竞争/组团关系）、z（成为偶像愿望）
- 暗层：nx（受赛制支配）、xz（淘汰/职业未来被切断）、zn（偶像本体待成立）

## 五维
- 时间：xn + z
- 本体：zn + x
- 空间：x并z + n
- 因果：zx + nx
- 命运：xz + nz

## 顺序链
z想出道 → xn进入50人选拔制度 → nx接受赛制 → zx竞争席位 → n形成竞争/潜在团体关系 → x并z获得ZENITH PRISM成员身份 → zn偶像本体成立；落选则由xz切断该职业未来。

## 生链
- z 生 zx：偶像愿望推动主动参赛。
- xn 生 n：同一选秀制度制造50人的竞争关系网。
- zx 生 x并z：竞争表现争取可见舞台与团体席位。
- x并z 生 zn：被正式选入新团后，公众职业身份反过来确认“我是偶像”。

## 克链
- xn 克 zx：个人行动必须服从选拔规则。
- xz 克 zn：淘汰可阻断偶像本体成立。
- n 克 zx：其他49名参赛者直接压缩个人成功空间。
- nx 克 zx：参赛者不能自行定义评价标准与名额。

## 5组补子
1. xn + z：选秀规则 / 出道愿望
2. zn + x：偶像本体 / 身体与能力载体
3. x并z + n：团体席位与舞台身份 / 50人竞争网络
4. zx + nx：主动竞争 / 被赛制评价
5. xz + nz：淘汰命运 / 与未来团体成员的关系绑定

## 核心母型
**固定团体席位竞争型：50人 → 新K-pop团体ZENITH PRISM。**

与 Girl Crush 的“公司月评→更高级 audition”不同，本作目前公开的核心是单一大型参赛池直接争夺新团成员席位；与 Debut or Die! 不同，目前没有死亡/回档等外部强制，职业机器本身就是主要压力源。
