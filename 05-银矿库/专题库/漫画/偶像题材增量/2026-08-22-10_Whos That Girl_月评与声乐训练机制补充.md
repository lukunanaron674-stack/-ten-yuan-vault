# Who’s That Girl?｜月评→主舞台→声乐训练机制补充

## 新证据
LINE WEBTOON 2026年3月30日至4月20日公开章节连续出现：
- Ep.38 Monthly Evaluation : Rehearsals
- Ep.39-41 Monthly Evaluation : The Main Stage
随后 2026年5月25日、6月1日进入：
- Ep.46 Vocal Training (1)
- Ep.47 Vocal Training (2)

这说明作品的偶像职业机制已经从“换身份后重新获得准入资格”继续深入到公司内部的周期评价、彩排、正式舞台与专项声乐训练。

## 十元修正
- 主符号：xn（公司评价/训练制度）
- 次符号：x并z → zx
- 强层：x + zn
- 暗层：nx + z + n

## 五维
- 时间：xn + z——周期月评把长期愿望切成一轮轮可考核节点。
- 本体：zn + x——同一追梦者借不同身体/社会读取方式继续职业化。
- 空间：x并z + n——主舞台把私人训练转成可被公司、同伴与观众读取的职业表现。
- 因果：zx + nx——主动训练与被迫接受公司评价并存。
- 命运：xz + nz——旧污名造成的职业封锁仍作为第二次机会的背景压力。

## 生链
x身体/社会分类变化 → xn重新取得训练资格 → zx专项训练 → x并z主舞台表现 → n形成公司内部职业位置 → zn偶像本体进一步成立。

## 克链
- xn克zx：个人努力必须通过月评制度才能兑换成职业前进。
- nx克zx：评价、训练安排与公司节奏限制个人自由路线。
- x并z克旧zn：新身份越能在主舞台被承认，旧身份“同样有能力却被拒绝”的矛盾越尖锐。
- zn反克x并z：角色仍需回答成功属于真实自我还是新社会身份。

## 5组补子
1. xn + z：规则评价 × 持续愿望
2. zn + x：本体 × 身体载体
3. x并z + n：公众舞台 × 职业关系
4. zx + nx：主动训练 × 被动考核
5. xz + nz：旧污名命运 × 社会关系牵连

## 职业度与矿级
- 偶像职业度：10/10
- 矿级：S
- 维持核心矿，不新建重复作品卡。

## 新增母型
### “身份绕行成功后，仍必须重新接受职业机器认证”
换身体/换社会分类只解决“让我进门”；真正成为偶像仍需经历：

`准入恢复 → 月评彩排 → 月评主舞台 → 专项声乐训练 → 下一轮职业评价`

因此身体奇迹没有直接兑换成偶像资格。x 只能打开入口，xn 才决定能否留下，zx 才决定能否继续前进，x并z 才把能力变成可见职业事实。
