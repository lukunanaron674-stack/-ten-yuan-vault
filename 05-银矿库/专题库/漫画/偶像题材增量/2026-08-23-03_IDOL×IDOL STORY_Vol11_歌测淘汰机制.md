# IDOL×IDOL STORY! Vol.11｜歌测淘汰与候选池收缩

## 新证据
2026-08-03发行的第11卷官方/出版社书志简介确认：所有队伍完成发表后，“我们的歌测试”公布淘汰者，候选人收缩至13人，并继续进入下一轮审查。

这使本作从“重新参加偶像选秀”的一般结构进一步明确为：

团队发表 → 歌唱专项测试 → 明示淘汰 → 候选池缩至13人 → 下一审查

## 十元判定
- 主符号：xn
- 次符号：zx → x并z
- 强层：n + z
- 暗层：nx + xz + zn

## 五维
- 时间：xn + z
- 本体：zn + x
- 空间：x并z + n
- 因果：zx + nx
- 命运：xz + nz

## 顺序链
z偶像愿望 → zx训练/团队发表 → n形成临时团队 → xn歌测规则 → x并z舞台输出 → nx接受不可控评价 → xz淘汰切断部分候选人的未来 → xn候选池压缩至13人 → 下一审查继续重排职业资格 → zn偶像候选本体被反复认证

## 生链
- z 生 zx：愿望转成训练与参赛行动。
- zx 生 x并z：训练必须通过可被观看、可被评分的表演外化。
- n 生 x并z：团队协作共同生产舞台结果。
- xn 生 xz：评价规则把差异转成“继续/淘汰”的职业命运。
- x并z 生 zn：反复通过审查后，“偶像候选人”逐渐成为真实本体。

## 克链
- xn 克 n：团队刚完成共同表演，制度马上按测试结果重新切分共同体。
- xz 克 z：被淘汰者即使愿望仍在，也会被制度切断当前出道路线。
- nx 克 zx：努力无法控制评价与席位数量。
- xn 克 zn：候选人不能仅靠“我想当偶像”维持职业身份，必须持续被制度重新认证。

## 5组补子
1. xn + z：选秀规则给愿望提供时间与审查轨道。
2. zn + x：偶像自我必须落在身体、声音与现场表现上。
3. x并z + n：个人舞台身份由团队关系共同生产。
4. zx + nx：主动训练与被动接受评价互补。
5. xz + nz：淘汰命运与候选人之间的关系/承诺互相放大。

## 新母型
**专项测试 → 明示淘汰 → 候选池收缩型**。

不是一次 audition 决定全部，而是职业机器不断把“暂时合格者”重新变成“待认证者”。团队发表刚结束，歌唱测试立刻制造淘汰，13名幸存者也没有获得稳定身份，只获得进入下一审查的资格。

关键反咬：

n团队成立 → x并z共同舞台 → xn专项测试 → xz淘汰 → n被重新切开。

制度需要候选人先合作生产好舞台，又利用专项评价不断拆散刚形成的共同体。
