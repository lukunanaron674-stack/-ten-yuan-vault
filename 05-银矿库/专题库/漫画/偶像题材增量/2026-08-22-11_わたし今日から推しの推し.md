# わたし今日から推しの推し！｜十元深拆

## 职业证据
- 33岁偶像宅日景隅子在原推武道馆公演因成员不祥事取消后，遇到路上偶像千歌并决定推她；事故后两人身体交换。
- 官方将作品定位为“偶像与オタク携手向顶点前进”的偶像故事，并归入工作/体育类。
- 已展开：团体概念设计、路上Live、为下一场Live募集30名粉丝、宣传发传单、Festival、反复Live、正式Audition。
- 2026-07-26 / 2026-08-09 已进入「運命のオーディション」；后续路线指向公认野外Live与武道馆。

## 十元判定
- 主符号：x（身体/职业载体交换）
- 次符号：nz → zx → n → x并z
- 强层：xn + zn
- 暗层：xz + z + nx

## 五维
- 时间：xn + z——从粉丝经验、失败武道馆记忆，到新的职业规划与持续目标。
- 本体：zn + x——“我是偶像宅”与“我正在用偶像身体劳动”直接冲突。
- 空间：x并z + n——团体概念、Live、粉丝数、舞台与成员共同体共同制造职业身份。
- 因果：zx + nx——主动经营、拉客、演出、选秀，对抗身体交换和职业现实强加的被动局面。
- 命运：xz + nz——原推武道馆失败、与新推的事故绑定，把应援关系推进到共同职业命运。

## 顺序链
xz旧推武道馆失败 → nz遇见新推 → x身体交换 → zn粉丝/偶像本体错位 → zx以粉丝知识主动经营 → n形成共同体 → xn接受Live/选秀规则 → x并z通过粉丝数与舞台获得职业确认 → zn被真实职业劳动反写。

## 生链
- x 生 zx：身体交换让粉丝知识第一次能直接变成偶像行动。
- nz 生 zx：想把千歌推上去，驱动隅子亲自经营职业路线。
- zx 生 n：经营、训练、Live把个人愿望变成团队协作。
- n 生 x并z：共同体产出团体概念、舞台和可被观看的职业形象。
- xn 生 x并z：Live门槛、粉丝数、Audition把公众形象转成制度可承认的职业事实。
- x并z 反生 zn：被观众持续当作偶像观看后，临时身体身份开始生成真实职业本体。

## 克链
- x 克 zn：身体交换破坏“粉丝”和“偶像”原有本体边界。
- xn 克 z：职业门槛把单纯的喜欢改造成粉丝数、Live、Audition等指标。
- nx 克 zx：交换事故和现实资源限制压缩主动选择。
- x并z 克旧 zn：公众越承认当前身体里的她是偶像，旧“我只是粉丝”的解释越站不住。
- zn 反克 x并z：原本的粉丝伦理与经验也会拒绝纯粹把偶像当商品经营。

## 5组补子
1. xn + z：职业规划/规则 + 偶像执念。
2. zn + x：粉丝自我/偶像自我 + 被交换的身体载体。
3. x并z + n：团体包装/舞台身份 + 成员与粉丝共同体。
4. zx + nx：主动经营、演出、选秀 + 被迫换体与现实限制。
5. xz + nz：武道馆失败/事故命运 + 推与被推的关系绑定。

## 新母型
**粉丝与偶像换体后共同经营职业 / 应援知识内置化型。**

与《推しが武道館いってくれたら死ぬ》的差异：后者是粉丝劳动始终在职业系统外制造偶像资本；本作直接把粉丝的知识、判断和应援经验塞进偶像身体，让“消费者知识”变成“生产者能力”。

与《Idolatry》的差异：后者是粉丝以自己的身体主动跨进选秀；本作先发生x身体交换，再让粉丝被迫从台下视角转成台上执行者。

## 反咬点
粉丝最初以为自己最懂“怎样推偶像”，但真正进入偶像身体后，必须面对团体概念、拉新粉、Live、选秀等生产侧约束。越成功把千歌推向武道馆，越证明自己已经不是单纯的粉丝，而是实际承担偶像职业的人。最终形成：

nz应援 → x换体 → zx经营 → xn职业认证 → x并z公众偶像 → zn新本体。
