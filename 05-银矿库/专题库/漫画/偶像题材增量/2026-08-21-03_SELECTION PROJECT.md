# SELECTION PROJECT｜偶像题材十元增量

- 媒介：日本原创TV动画 / 偶像×选秀×真人秀结构
- 矿级：S
- 核心类型：从“偶像志愿者”到“被公众承认的偶像”
- 本轮新母型：**公众投票把“成为偶像”变成可量化、可实时撤销的社会身份**

## 1. 偶像身份如何建立

主角美山铃音并非既成偶像，而是怀着“像天泽灯那样给别人勇气”的愿望参加全国偶像选秀真人秀 SELECTION PROJECT。全国九个地区的候选人先过地区预选，再进入全国本选；节目通过纪录影像与LIVE直播持续公开她们的表现，胜负最终由观看节目的用户投票决定。

身份建立不是“我想当偶像→公司宣布出道”，而是：

**私人愿望 → 参加选秀 → 被镜头持续公开 → 被观众比较/投票 → 通过阶段任务 → 获得可被社会承认的偶像身份。**

## 2. 十元体量（1–10）

| 十元 | 体量 | 本作功能 |
|---|---:|---|
| x并z | 10 | “候选偶像/偶像”完全依赖公众观看与社会承认而成立 |
| nx | 9 | 去留高度依赖观众投票，个人无法独占结果 |
| xn | 9 | 地区赛、本选、组队任务、直播目标等规则不断塑形 |
| zx | 9 | 主角持续主动参赛、练习、表演、争取留下 |
| n | 9 | 九名少女既是战友又是竞争者，关系本身改变选择 |
| nz | 8 | 粉丝的“应援”从数字逐渐变成情感支持与共同体 |
| z | 8 | 舞台、镜头、排名、淘汰制造持续外部压力 |
| zn | 7 | “我为什么想成为偶像”不断被比赛逼着重新确认 |
| xz | 6 | 身体限制、偶像前辈遗产与关键突发事件形成命运压力 |
| x | 6 | 个体天赋、身体、性格是竞争底盘，但不是唯一胜负因素 |

主元：**x并z**
次元：**nx**

本轮关键关系：**x并z + nx**。公众身份越强，个体对公众评价的依赖也越强。

## 3. 顺序

**nz → zx → x并z → xn → n → nx → z → 新x并z → zn回写**

1. nz：先被前代偶像给予勇气，产生“我也想把勇气给别人”的关系愿望。
2. zx：主动报名、参赛、练习、争取舞台。
3. x并z：一旦进入节目，立刻成为可被观看、讨论、排名的“候选偶像”。
4. xn：比赛规则把愿望切割成一轮轮可验收任务。
5. n：竞争者在共同训练中形成关系，单纯敌我结构被打破。
6. nx：最终结果交给观众票数，候选人必须承受外部选择。
7. z：淘汰、票数、直播指标反过来压迫个体。
8. 新x并z：若跨过临界值，“候选人”被社会重新命名为真正偶像。
9. zn回写：经历公开竞争后，重新回答“我要成为怎样的偶像”。

## 4. 五维

### 时间维｜xn + z：9/10
成长被节目赛程离散化。训练不再是模糊的“慢慢变强”，而是下一轮之前必须完成的倒计时成长。

### 本体维｜zn + x：7/10
核心不是身份错位，而是比赛不断迫使少女确认：我是为了赢、为了偶像称号，还是为了把某种感情传出去？

### 空间维｜x并z + n：10/10
最强维。演播厅、直播间、舞台、宿舍、团队把九个个体压缩成一个公开可见的社会空间。她们既互为竞争者，又共同形成“这一届候选人”的整体身份。

### 因果维｜zx + nx：10/10
极强矛盾：**必须主动努力，但结果又不能由自己决定。** 这是选秀偶像题材最核心的发动机。

### 命运维｜xz + nz：7/10
前代偶像的影响、粉丝应援与身体条件把“我要成为偶像”从职业选择推向人生意义。

## 5. 行业机制拆解

### 训练
- 不是背景蒙太奇，而是为具体审查任务服务。
- 训练结果必须立刻被镜头、舞台和观众验证。
- 团队任务会迫使角色解决“自己突出”与“团队成立”的矛盾。

### 出道
- 出道不是故事开场，而是明确终点奖励。
- 身份必须跨过公众认可阈值才成立。
- 最终直播将“梦想”转成可观测目标。

### 竞争
- 竞争者同时是共同生活、共同训练的伙伴。
- 最好的冲突不是互害，而是：**我喜欢你，但你的成功可能等于我的失败。**

### 舞台
- 舞台是阶段审判场，不只是视觉高潮。
- 每次舞台都承担“当前身份是否成立”的验证功能。

### 粉丝
- 粉丝不是背景欢呼声，而是制度中的投票者。
- 粉丝关系同时具有 nz 情感支持 与 nx 外部支配两面。

### 公司/节目机制
- 节目平台承担传统事务所部分“选人权”。
- 镜头、剪辑、直播、赛制把少女转换成可比较的公众产品。
- 偶像身份由机构、候选人、观众三方共同生产。

## 6. 主角欲望与代价

### 欲望
不是单纯“想红”，而是想成为曾经帮助自己的那种人：通过歌声和舞台把勇气传给别人。

### 代价
1. 私人梦想进入公共评分系统。
2. 自己的价值被暂时压缩成票数与晋级结果。
3. 真正喜欢上的伙伴可能正是必须击败的人。
4. 失败不只意味着工作失败，还会伤及“我是否有资格成为那种人”的本体判断。

## 7. 关系结构

**前代偶像 → 主角**：nz，理想与救赎来源。

**主角 ↔ 竞争者**：n + zx，既合作又竞争。

**候选人 ↔ 观众**：nz + nx，情感支持同时也是生杀权。

**候选人 ↔ 节目制度**：xn + z，被规则塑形并承受公开压力。

**九人 → 新组合身份**：n → x并z，多人的关系最终可能长成高于个人胜负的新实体。

## 8. 动态链

### 主链
**zx → x并z → xn → n → nx → 新x并z**

- 主符号：x并z
- 次符号：nx
- 方向：私人主动欲望 → 公开候选身份 → 赛制塑形 → 战友关系生成 → 公众裁决 → 新社会身份
- 起点：尚未被社会认可的偶像志愿者
- 终点：通过公众共同承认而成立的偶像/组合
- 条件：必须把个人欲望持续转化为可公开观看的行动

### 阶段变化
前期：zx > nx，角色相信“努力就能赢”。
中期：nx上升，角色意识到努力与结果不等价。
后期：n、nz上升，关系开始对抗单纯淘汰逻辑。
终局：x并z不再只等于“节目给的候选标签”，而变成角色、伙伴、观众共同生产的新身份。

## 9. 反咬点

### 反咬A：越努力，越暴露于评价
主动追梦 zx 本来是为了建立身份，但每前进一步都让自己更彻底进入 x并z 的公共视线，并增强 nx 对外界判断的依赖。

### 反咬B：竞争制造了最不该产生的关系
赛制要求互相淘汰，长期共同训练却产生 n。于是制度的成功运转反而制造出反制度的情感。

### 反咬C：粉丝既“生”偶像，也能“撤销”偶像
nz 给角色勇气，但投票机制又使其变成 nx。**给予存在感的人，同时掌握否定存在感的能力。**

## 10. 视觉符号

- 九地区地图 / 九名代表：大量候选者被压缩成有限席位。
- 直播框、票数、应援数：把情感可视化成数字。
- 聚光灯：从私人少女到公众对象的边界。
- 候场暗处 ↔ 舞台亮处：未被承认 ↔ 正在接受社会验证。
- 同一套舞台服装：个体 x 被压入组合 x并z。
- 镜头/手机屏幕：观众并不在现场，却能决定现场人物命运。

## 11. 可复用母题

### S级母题：被观看才能成立的职业
职业身份不是拿到证书就成立，而必须持续得到陌生人的注意、投票或消费。

可迁移：
- 竞技直播选手
- 公选圣女
- 全民投票英雄
- 由城市居民票选产生的守护者
- 必须获得“信仰值”才能保持神格的神明

### S级母题：努力权与决定权分离
**角色拥有行动权，却没有结果决定权。**

这是 zx 与 nx 的高价值矛盾结构。越认真行动，越必须面对“别人仍可以说不”。

### A级母题：竞争机器生产共同体
制度本来设计来筛掉人，但被筛选者在共同受压中形成关系，最终可能共同拒绝原有零和规则。

## 12. 本轮结论

《SELECTION PROJECT》最值得收入十元库的不是“偶像选秀”表皮，而是一个非常纯的因果结构：

> **我必须拼命证明自己，但我无法亲自宣布证明成立。**

这使“成为偶像”天然成为：

**zx主动行动 × nx外部裁决 × x并z公众身份**

三者互相生克的故事机器。
