# 31☆アイドリーム｜十元增量

## 收录理由
31岁的出口千影借“アイドリーム”药物把外表变回15岁，并以少女身份进入偶像职业。白泉社官方第6卷明确写明她正在过“アイドルとOLとの二重生活”；第5卷进一步出现偶像CD销量竞争，因此并非只有明星恋爱背景，而是真正存在制作、作品销售与偶像职业身份。

## 十元判定
- 主符号：x（身体/年龄载体被重置）
- 次符号：x并z → zn
- 强层：xn + zx
- 支撑：n + nz
- 暗层：xz + z + nx

## 五维
- 时间：xn + z——31岁人生与15岁职业窗口叠置，旧愿望重新获得时间入口。
- 本体：zn + x——31岁OL本体与15岁偶像身体/外观长期并存。
- 空间：x并z + n——“あかり”作为公众偶像被制作、观看，并进入制作人与竞争者网络。
- 因果：zx + nx——主动追求错过的人生，但职业活动又迫使她维持双重身份。
- 命运：xz + nz——错过青春/职业机会的既定人生，被旧关系与第二次机会重新改写。

## 顺序链
xz错过的人生 → z重新想活一次 → x身体年龄重置 → xn建立OL/偶像双时间规则 → zx进入偶像职业 → x并z“あかり”公众身份成立 → n进入制作/竞争网络 → zn旧本体与新职业本体互相反写。

## 生链
- x 生 x并z：年轻身体让新的偶像公众身份可被行业读取。
- z 生 zx：对错过人生的遗憾转化为主动职业行动。
- zx 生 x并z：真正参与制作与活动，使“少女偶像”不再只是伪装。
- x并z 生 n：公众身份带来制作人、竞争者、粉丝与行业关系。
- x并z 反生 zn：持续职业实践开始生成“我也是偶像”的真实本体。

## 克链
- x 克旧 zn：15岁身体直接破坏“我只是31岁OL”的单一本体解释。
- xn 克 zx：双重生活规则限制职业行动与私人生活。
- x并z 克 zn：公众越相信15岁偶像あかり，31岁出口千影越难维持单一本体。
- zn 反克 x并z：成年经验、旧关系与真实年龄不断威胁偶像包装。
- xz 克 z：已经错过的年龄与人生阶段持续压迫第二次梦想。

## 5组补子
1. xn + z：双重时间规则 × 重活青春/偶像人生的愿望。
2. zn + x：31岁真实自我 × 15岁身体载体。
3. x并z + n：偶像公众身份 × 制作/竞争/粉丝关系网。
4. zx + nx：主动成为偶像 × 被双重身份与职业要求约束。
5. xz + nz：错过的人生命运 × 旧同学/制作人与新职业关系重新接线。

## 新母型
**成年失败时间线 → 年龄载体重置 → 双职业并行型。**

它与《満月をさがして》不同：后者是疾病与年龄封锁职业入口，替身身体帮助少女完成原本就明确的偶像梦想；《31☆アイドリーム》则是31岁成人先拥有完整失败/错过的人生，再以15岁身体进入偶像职业，并长期维持OL与偶像双重生活。

最值得采的是：**x身体重置并没有删除旧zn，反而让两个社会年龄、两个职业身份同时成立。** 偶像成功越真实，“15岁あかり”越不再只是工具；但她又不能像普通15岁新人一样把过去清零。

## 职业机制证据
- 白泉社第6卷：明确为“アイドルとOLとの二重生活”。
- 白泉社第5卷：出现あかり与ゆこのCD销量对决。
- 白泉社官方系列页：确认31岁千影通过药物变成15岁外表，是持续性的“逆・変身少女”结构。
