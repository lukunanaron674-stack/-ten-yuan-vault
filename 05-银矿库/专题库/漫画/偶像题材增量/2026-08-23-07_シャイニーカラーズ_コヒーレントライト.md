- 次符号：zx → x并z
- 强层：xn + zn
- 暗层：nx + xz + nz

## 五维
- 时间：xn + z

- 因果：zx + nx
- 命运：xz + nz

## 新母型
**已出道组合内部 rival 共生型 / 竞争不是淘汰前置，而是组合长期运营燃料。**

与 Girl Crush、IDOL×IDOL STORY! 的选秀阶段不同，本作的关键不是“竞争后谁获得出道资格”，而是已经组成偶像 unit 的成员把彼此明确视为 rival；竞争、冲突和磨合反而持续生产组合的职业强度。

核心反咬：`n → zx → x并z → zn`。团体需要成员彼此竞争才能变强，但竞争过强又可能破坏 n；而公众越把 Straylight 当成一个完整组合，成员个人 zn 越必须在团体 x并z 内重新解释自己。

## 与专题库差异
补足当前母库偏弱的“出道后长期团内竞争/组合运营”方向，不依赖重生、系统、换体或一次性选秀。
