# ひかるイン・ザ・ライト！｜十元深拆

## 收录理由
荻野ひかる是喜欢唱歌的中学三年生，进入世界级制作人 M・葉山主导的大型女偶像选秀「ガールズ・イン・ザ・ライト」。核心不是偶像恋爱背景，而是从普通少女进入公开选秀、生存竞争、舞台评价并争夺偶像资格的职业过程。

## 十元判定
- 主符号：zx（主动进入选秀、训练、竞争、舞台证明）
- 次符号：xn → x并z
- 强层：z + n
- 暗层：nx + xz + zn
- 顺序链：z → zx → xn → n → nx/xz → x并z → zn

## 五维
- 时间：xn + z｜梦想被选秀阶段、训练与评价节奏制度化。
- 本体：zn + x｜普通中学生的自我与“偶像候选人”的身体/能力要求发生重构。
- 空间：x并z + n｜舞台、镜头、观众可见性与选手共同体共同制造职业位置。
- 因果：zx + nx｜主动参赛、训练与临场表现，对抗淘汰、排名与被动规则。
- 命运：xz + nz｜有限席位把同伴关系转化为共同梦想与竞争命运。

## 生链
- z 生 zx：喜欢唱歌/偶像愿望推动真正报名参赛。
- zx 生 x并z：训练和舞台行动制造可见的偶像候选身份。
- xn 生 n：统一赛制把陌生少女组织成同一竞争共同体。
- n 生 zx：同伴与竞争者反过来刺激行动强度。
- x并z 生 zn：被观众、制作人和赛制持续观看后，“我是候选偶像”从包装逐渐变成本体。

## 克链
- xn 克 zx：个人想怎么表现必须服从审查、赛制和阶段规则。
- xz 克 n：有限出道席位使共同体天然存在淘汰与分离。
- nx 克 zx：排名、评价、临场事故等被动条件压缩个人选择。
- x并z 克 zn：镜头中最有效的偶像形象可能压过普通少女原本的自我。
- n 克 zn：与更成熟/更强选手比较，会迫使主角重新定义“我是否配成为偶像”。

## 5组补子
1. xn + z：梦想 ↔ 选秀阶段/训练规则。
2. zn + x：普通少女本体 ↔ 被训练与评价的职业身体。
3. x并z + n：舞台可见性 ↔ 选手/组合关系。
4. zx + nx：主动训练竞争 ↔ 被排名淘汰。
5. xz + nz：有限出道席位 ↔ 同伴共同命运。

## 新母型
**普通少女直接进入大型女偶像生存选秀 / 纯职业成长型。**

它的重要性在于没有重生、系统、换体、救人任务等外部强制器。故事只靠“我想唱、我去参加、我被评价、我必须和别人竞争”把职业链跑起来，因此适合作为专题库的基准样本：复杂奇幻机制都可以与它比较，判断究竟是偶像职业本身在驱动剧情，还是外挂在驱动。

## 反咬点
最初 zx 是愿望的直接实现，但进入制度后，xn/xz 会把“喜欢唱歌”拆成可排名、可淘汰、可比较的职业指标。于是形成：

z（喜欢唱） → zx（主动参赛） → xn（制度评价） → x并z（偶像形象） → zn（我是谁）

职业化越成功，越需要回答：自己追求的是唱歌本身，还是被制度承认为偶像。

## 与已有样本差异
- 对 Girl Crush：Girl Crush 更偏长期练习生制度、月评与多级资格漏斗；本作更纯粹地以大型公开女偶像生存选秀为入口。
- 对 Idolatry：Idolatry 的入场动力是“为了推”；本作的入场动力更直接，是本人自己的歌唱/偶像愿望。
- 对 Debut With You：没有未来信息、系统和帮助推的工具性目标，更适合作为零外挂职业基线。
