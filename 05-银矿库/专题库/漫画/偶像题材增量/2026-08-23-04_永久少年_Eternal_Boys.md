# 永久少年 Eternal Boys｜十元分析

## 收录理由
满福艺能Production为公司再起启动“中年偶像企划”，6名处于人生/职业悬崖边的中年男性跨越年龄与体力壁垒，以真正成为偶像为目标。漫画明确标注“お仕事”，并持续推进职业活动，因此不是偶像恋爱背景。

## 十元判定
- 主符号：x（身体/年龄条件）
- 次符号：xz → zx → xn → n → x并z
- 强层：zn、nx
- 支撑：z、nz

## 五维
- 时间：xn + z——中年既有时间线与重新成为偶像的愿望发生冲突。
- 本体：zn + x——“中年失意者/原职业者”的自我，与不符合传统偶像想象的年龄身体互相定义。
- 空间：x并z + n——六人团体及公众舞台把私人失败者转成可见偶像单位。
- 因果：zx + nx——主动训练、演出、经营，对抗年龄、体力与现实处境的被动限制。
- 命运：xz + nz——原人生职业轨道已进入危机，新的团体关系提供第二职业命运。

## 顺序链
xz旧职业/人生危机 → x年龄与体力成为职业门槛 → z产生第二职业愿望 → zx参加中年偶像企划 → xn接受事务所与偶像职业规则 → n六人团体成立 → x并z公众偶像身份形成 → zn被第二职业重新定义。

## 生链
- xz 生 z：旧人生走到悬崖，反而生成重新开始的愿望。
- z 生 zx：愿望转成训练、参加企划与舞台行动。
- zx 生 n：共同职业行动生成六人团体。
- n 生 x并z：团体让个体获得可被公众读取的偶像身份。
- x并z 反生 zn：被作为偶像观看后，旧“我已经过了能当偶像的年龄”的本体解释被改写。

## 克链
- x 克 zx：年龄与体力限制行动强度。
- xn 克 z：传统职业时间表与行业规则否定“中年重新当偶像”的合理性。
- nx 克 zx：现实处境与身体限制持续压制主动职业化。
- x并z 克旧zn：公众偶像身份成立后，旧失败者身份无法独占“我是谁”。
- zn 反克 x并z：既有年龄经验与旧职业人格也会拒绝被完全包装成传统偶像。

## 5组补子
1. xn + z：职业年龄规则 ↔ 第二次愿望。
2. zn + x：中年自我 ↔ 年龄身体。
3. x并z + n：公众偶像身份 ↔ 六人团体共同体。
4. zx + nx：主动职业化 ↔ 身体/现实限制。
5. xz + nz：旧人生危机 ↔ 新团体共同命运。

## 新母型
**年龄越界再就业 / 中年第二职业偶像型**。

不是回档成年轻人，也不是换身体绕过年龄门槛，而是保留中年身体、履历与失败时间线，直接要求偶像职业接纳“已经不在传统适龄期的人”。

## 反咬点
最初偶像企划像是公司和六名失意者的再起手段；一旦Live、团体关系与公众承认成立，偶像就不再只是“第二职业方案”。反过来，成员原本积累的年龄、旧职业经验和中年人格也会改变“偶像应该是什么”的职业定义。

## 与已有样本差异
- 《祖母ドル》：通过身体年轻化重新打开偶像职业入口；本作不年轻化，直接携带中年身体进入职业。
- 《IDOROLL》：年轻失败者更换舞台职业载体；本作重点是年龄/体力门槛与中年再就业。
- 《31☆アイドリーム》：年龄载体重置并维持双职业；本作没有超自然年龄重置。
