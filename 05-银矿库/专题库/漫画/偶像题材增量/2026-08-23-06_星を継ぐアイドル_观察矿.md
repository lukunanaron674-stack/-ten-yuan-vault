# 《星を継ぐアイドル》｜观察矿（S潜力）

- 原作：猫にゃん
- 作画：橘夏々
- 连载：白泉社《ヤングアニマル》，2026-07-24 开始连载；2026-08-12 已到连载第3回。
- 官方定位：トップスタァを目指す偶像少女たちのアイドル学園サバイバル／命を燃やすアイドルサバイバル。
- 收录理由：核心就是少女进入偶像学园并在生存式制度中争夺“トップスタァ”，不是偶像恋爱背景。

## 十元

- 主符号：xn
- 次符号：z → zx → x并z
- 强层：n + zn
- 暗层：nx + xz

### 核心链

`z被偶像光辉点燃 → zx主动追逐偶像道路 → xn进入偶像学园/生存制度 → nx受制度评价与淘汰约束 → n形成偶像少女竞争网络 → x并z舞台/排名身份成立 → zn“我是不是偶像”被职业实践重写`

## 五维

- 时间：xn + z
- 本体：zn + x
- 空间：x并z + n
- 因果：zx + nx
- 命运：xz + nz

## 生链

`z生zx → zx生x并z → xn生n → n反生zx → x并z生zn`

## 克链

`xn克zx → nx克zx → xz克z → x并z反克旧zn`

## 5组补子

1. xn + z
2. zn + x
3. x并z + n
4. zx + nx
5. xz + nz

## 评级

- 核心偶像职业度：9.5/10
- 十元采矿：86/100
- 矿级：观察矿（S潜力）

暂不直接升 S：截至本卡建立时仅连载3回，官方已确认“偶像学园生存”“トップスタァ”“天赋”“学园晋级/竞争”的职业骨架，但训练、舞台评价、排名、淘汰、组合运营、粉丝与公司机制仍需后续章节验证。

## 新母型

**偶像学园生存 / 职业教育制度化型**

与普通公开 audition 不同，职业竞争被长期封装进“学园”本身：进入学校不是获得偶像资格，而只是获得持续接受职业认证的场所。后续重点追踪 `xn学校规则 → zx训练 → x并z舞台/排名 → xz淘汰 → zn偶像本体` 是否真正展开。

## 后续追踪

优先检查第4回以后是否出现：课程/训练、班级或等级、舞台考核、排名、淘汰、组合编成、粉丝反馈、事务所或出道通道。一旦出现两项以上硬职业机制，建议升 A+/S。
