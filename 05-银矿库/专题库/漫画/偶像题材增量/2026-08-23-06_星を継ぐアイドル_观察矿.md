# 《星を継ぐアイドル》｜观察矿（S潜力）

- 原作：猫にゃん
- 作画：橘夏々
- 连载：白泉社《ヤングアニマル》，2026-07-24 开始连载；2026-08-12 已到连载第3回。
- 官方定位：トップスタァを目指す偶像少女たちのアイドル学園サバイバル／命を燃やすアイドルサバイバル。
- 收录理由：核心就是少女进入偶像学园并在生存式制度中争夺“トップスタァ”，不是偶像恋爱背景。

## 十元

- 主符号：xn
- 次符号：z → zx → x并z
- 强层：n + zn
- 暗层：nx + xz

### 核心链

`z被偶像光辉点燃 → zx主动追逐偶像道路 → xn进入偶像学园/生存制度 → nx受制度评价与淘汰约束 → n形成偶像少女竞争网络 → x并z舞台/排名身份成立 → zn“我是不是偶像”被职业实践重写`

## 五维

- 时间：xn + z
- 本体：zn + x
- 空间：x并z + n
- 因果：zx + nx
- 命运：xz + nz

## 生链

`z生zx → zx生x并z → xn生n → n反生zx → x并z生zn`

## 克链

`xn克zx → nx克zx → xz克z → x并z反克旧zn`

## 5组补子

1. xn + z
2. zn + x
3. x并z + n
4. zx + nx
5. xz + nz

## 评级

- 核心偶像职业度：9.5/10
- 十元采矿：88/100（原86，2026-08-23补证后上调）
- 矿级：观察矿（S潜力）

暂不直接升 S：官方已确认“偶像学园生存”“トップスタァ”“天赋”“学园晋级/竞争”的职业骨架；第3回读者记录进一步显示败者会被降为“黑子/后台角色”，并出现与学园最上位班级直接对战的制度，但这一细节目前尚缺出版社可检索文本二次确认，因此先作为高可信待官方复核机制，不把观察矿提前吹成S。

## 2026-08-23 新机制补证：败者职业降级 / 黑子化

白泉社对第3回的官方宣传继续明确为“凭天赋在学园向上攀升／燃烧生命的偶像生存战”。同期阅读记录进一步指出：**败北的偶像会被制度降为黑子（后台/陪衬角色），并出现与学园内最上位班级对战。**

这使原本抽象的“生存”第一次出现可能的职业后果：

`xn学园等级制度 → zx对战 → x并z胜负可见化 → xz败北 → xn强制职业降级 → zn从“偶像主体”被改写为“支撑别人发光的人”`

值得单独建立母型：**“败者不退出行业，而被降级为不可见职业劳动者”**。

它比普通淘汰更有矿：淘汰只是把人赶出职业系统；黑子化则把失败者留在系统内部，却夺走其被观看的资格。于是形成非常强的：

`x并z（被看见） ↔ xn（制度分配可见性） ↔ zn（我是不是偶像）`

如果后续官方章节确认该制度长期存在，可直接把本作升到 S，并新增“职业可见性阶级 / 败者后台化”母型。

## 新母型

**偶像学园生存 / 职业教育制度化型**

与普通公开 audition 不同，职业竞争被长期封装进“学园”本身：进入学校不是获得偶像资格，而只是获得持续接受职业认证的场所。后续重点追踪 `xn学校规则 → zx训练 → x并z舞台/排名 → xz淘汰/降级 → zn偶像本体` 是否持续展开。

## 后续追踪

优先检查第4回以后是否出现：课程/训练、班级或等级、舞台考核、排名、淘汰/黑子化、组合编成、粉丝反馈、事务所或出道通道。若“败者黑子化”得到官方文本确认，优先升 S。
