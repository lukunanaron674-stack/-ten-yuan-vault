# 日韩偶像题材增量 R03

## Girl Crush｜日漫｜S
作者：Midori Tayama。

核心职业机制：女主进入韩国式偶像练习生体系；训练、月度评价、企划组、新三社联合偶像团 audition 都直接决定角色能否继续向出道推进。VIZ 2026-06-09 发售的 Vol.7 明确写到 Tenka 与 Sua 进入 LJH special-project team 后，还必须通过下一次 monthly evaluation 才能取得新偶像团 audition 的席位。

### 十元
- 主符号：zx（主动争取舞台与出道资格）
- 次符号：xn（练习生制度、月评、选拔规则）→ x并z（偶像形象与舞台成立）
- 暗层：zn（“我是否真能成为偶像”的身份确认）

### 五维
- 时间 xn+z：训练周期、月评、选拔节点把梦想切成阶段。
- 本体 zn+x：从普通少女/练习生逐渐认领“偶像”身份。
- 空间 x并z+n：练习室、评价舞台、企划组与正式舞台不断改变被观看的位置。
- 因果 zx+nx：主动训练竞争，同时接受公司、导师、评审与排名筛选。
- 命运 xz+nz：失败可能终止职业路线，伙伴关系与共同成长缓冲淘汰压力。

### 生链
z想成为偶像 → zx主动训练/竞争 → xn月评与选拔确认能力 → x并z获得更高层级舞台位置 → zn偶像本体逐渐成立。

### 克链
xn 克 zn：评价制度可以直接否定“我认为自己适合当偶像”的自我认定。
z / zx 反克 nx：欲望与训练把“等待公司选择”重新转成主动争位。

### 5组补子
xn+z / zn+x / x并z+n / zx+nx / xz+nz。

### 职业度
10/10。

### 矿级
S。女偶像成长样本价值极高。不是“偶像已经出道后谈关系”，而是把练习、评价、竞争、企划组、audition 本身当主剧情。

### 可复用母型
**能力强 ≠ 已经成为偶像。**
能力必须经过制度评价、舞台观看与团队位置三重确认，才能从“会唱跳的人”转成“成立的偶像”。

## Audition in Disguise｜韩漫 / LINE WEBTOON｜S
作者：GOHADA（编剧）、YUNSOOP（作画）。已完结。

核心：Lee Chohee 梦想成为偶像，却因中性外貌与坏运气反复被踢出 debut group；最后参加偶像生存节目 High Teen Universe，并以男性身份进入竞争。职业线直接包含 trainee、survival audition、debut group、竞争与身份伪装。

### 十元
- 主符号：x并z（外貌/性别呈现/偶像可见身份）
- 次符号：z（成为偶像的持续执念）→ zx（最后一次主动参赛）
- 强规则层：xn（出道组筛选、生存节目规则）

### 五维
- 时间 xn+z：反复失败仍持续追逐出道，最终进入“最后一次机会”。
- 本体 zn+x：真实自我与被迫采用的男性公开身份形成核心裂缝。
- 空间 x并z+n：舞台与镜头要求她以可被行业接受的形象存在。
- 因果 zx+nx：她主动报名，但进入节目后必须接受规则、排名与他人观看。
- 命运 xz+nz：职业道路近乎被外貌条件封死，练习生友情/关系提供新的连接可能。

### 生链
z偶像执念 → zx最后一次报名 → xn生存赛规则 → x并z男性偶像身份成立 → 舞台成绩反过来逼问zn真实身份。

### 克链
x并z 克 zn：能让她获得职业机会的“男性偶像外形”，同时遮蔽真实自我。
xn 克 z：行业筛选长期压制她成为偶像的愿望。
z 生 zx：执念没有消失，最终重新发动行动。

### 5组补子
xn+z / zn+x / x并z+n / zx+nx / xz+nz。

### 职业度
10/10。

### 矿级
S。

### 可复用母型
**“只有变成不是我的样子，我才被允许成为我想成为的人。”**
这是非常强的偶像本体矛盾：职业身份成立与真实身份成立互相冲突，而不是普通女扮男装噱头。
