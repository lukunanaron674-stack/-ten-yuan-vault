# アイドラトリィ｜舞台与舞蹈战机制补充

## 新证据
2026年官方 Comic DAYS 连载章节已经明确推进到：
- #22 Lesson（2026-03-17）
- #26 Dance Battle（2026-06-17）
- #28 On the Stage（2026-06-17）

这使本作不再只能概括为“粉丝为了推进入100人偶像选秀”，而可以确认职业实践已经从参赛动机进入“训练→舞蹈对抗→正式舞台”的第二阶段。

## 十元修正
- 主符号：nz
- 次符号：zx → xn → x并z
- 强层：n + z
- 暗层：zn + nx + xz

## 五维
- 时间：xn + z
- 本体：zn + x
- 空间：x并z + n
- 因果：zx + nx
- 命运：xz + nz

## 顺序链
z推之执念 → nz与推绑定 → zx亲自进入选秀并训练 → xn接受Lesson/赛制 → n与其他候选形成竞争协作网 → zx Dance Battle → x并z On the Stage职业可见性 → zn“我只是粉丝”被职业实践反写。

## 生链
- z 生 nz：推的执念制造关系绑定。
- nz 生 zx：为了推而主动进入职业系统。
- zx 生 x并z：训练和舞蹈对抗制造可被观看的舞台身份。
- xn 生 n：赛制把100名候选组织成竞争/协作网络。
- x并z 反生 zn：舞台上的真实职业劳动开始制造新的自我认定。

## 克链
- xn 克 zx：Lesson、比赛规则限制个人策略。
- n 克 nz：候选人共同体与竞争关系稀释单一“为了推”的关系目标。
- x并z 克旧 zn：公众越把循菜读取为偶像候选人，“我只是粉丝”的旧解释越不够。
- xz 克 nz：淘汰风险随时可能切断与推共同前进的路线。

## 5组补子
1. xn + z：选秀规则 ↔ 推的执念
2. zn + x：粉丝本体 ↔ 真正承担训练的身体
3. x并z + n：舞台身份 ↔ 候选人关系网络
4. zx + nx：主动攻略/训练 ↔ 被赛制与评价支配
5. xz + nz：淘汰命运 ↔ 与推共同前进的关系绑定

## 新母型
**应援动机职业技能化：粉丝知识只是入口，真正的Lesson、Dance Battle、Stage会把“为了推才参赛”逐渐改造成独立职业能力。**

## 反咬点
最初是 nz 驱动 zx：为了推才训练；但职业实践持续发生后，zx → x并z → zn。即使未来“推”不再需要帮助，已经形成的舞台能力、竞争关系和公众身份仍可能要求主角继续作为偶像存在。

## 与旧卡差异
旧卡主要确认“粉丝亲自进入100人选秀”；本卡补实第二阶段：Lesson → Dance Battle → On the Stage，证明职业身份不是工具性报名，而正在通过真实职业劳动独立成立。
