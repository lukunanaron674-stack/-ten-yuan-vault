## 十元判定
- 主符号：xn
- 次符号：x → zx → x并z
- 强层：zn
- 暗层：nx + z + n
- 偶像职业度：10/10
- 矿级：S（维持）

## 五维
- 时间：xn + z
- 本体：zn + x
- 空间：x并z + n
- 因果：zx + nx
- 命运：xz + nz

## 顺序链
xz旧身份污名封路 → x身体/社会分类改变 → xn重新取得练习生准入 → zx训练 → xn月评 → x并z主舞台评价 → zx声乐专项训练 → xn身体组成检查 → x身体被职业指标化 → zn继续被“偶像身体标准”反写。

## 生链
1. x生xn：身体/社会分类改变，让被封死的职业入口重新打开。
2. xn生zx：公司训练、月评和专项课程持续要求主动训练。
3. zx生x并z：训练成果通过主舞台被转译为公司可读取的职业表现。
4. xn生x：Body Composition Check把身体重新编码成可测量、可管理的职业资本。
5. x并z反生zn：持续被作为练习生/偶像候选人观看与评价，逐步做实新的职业本体。

## 克链
1. xz克zn：旧污名让“有能力成为偶像的我”无法获得社会承认。
2. xn克zx：主动努力必须服从公司月评、训练与身体管理规则。
3. xn克x：身体不再只是私人载体，而成为职业制度检查对象。
4. x并z克旧zn：新身份越被认可，旧身份“同样有能力却被拒绝”的矛盾越尖锐。
5. zn反克xn：若角色坚持真实自我与身体边界，最终可能反抗职业制度对身体的全面定义。

## 5组补子
1. xn + z：职业规则补持续成为偶像的愿望。
2. zn + x：真实自我与身体载体互相补证。
3. x并z + n：舞台可见性与公司/练习生关系网络互补。
4. zx + nx：主动训练与被动接受评价/检查形成因果张力。
5. xz + nz：旧污名命运与新的职业关系共同决定能否继续前进。

## 新母型
### 身体职业化 / 准入之后的身体再认证
身体变化最初只是让角色重新进入公司，但进入以后，公司并没有停止读取身体；相反，身体又被纳入训练、月评、声乐与Body Composition Check的连续职业认证。

链：
`x改变准入 → xn进入制度 → zx训练 → x并z舞台认证 → xn身体检查 → x被职业指标化 → zn被反写`

关键反咬：
**身体曾经是绕过旧社会污名的逃生门，进入偶像制度后却又变成制度最直接的管理对象。**

## 与已有样本差异
- 《満月をさがして》：替身身体主要解决年龄/疾病造成的职业入口封锁。
- 《祖母ドル》：年轻化身体重新打开被年龄关闭的职业可能。
- Who’s That Girl?：身体先解决准入，随后又被公司通过月评、声乐训练、身体组成检查重新制度化；因此形成“身体解放职业入口 → 职业制度重新占领身体”的双阶段结构。

## 结论
不新增作品卡，维持S矿；新增“身体职业化 / 身体再认证”机制，作为Who’s That Girl?第二阶段职业链的重要补充。
