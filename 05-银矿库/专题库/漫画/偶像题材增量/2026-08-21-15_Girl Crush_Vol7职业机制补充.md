# Girl Crush｜Vol.7 职业机制补充

## 新证据
VIZ Media《Girl Crush》Vol.7（2026-06-09）官方简介明确：为了取得“三家公司新偶像团体 audition”的参赛席位，角色必须先通过下一次 monthly evaluation；Sua 同时面对作为 idol trainee 的既有经验、评价压力，以及可能造成 career-ending 后果的职业选择。

这使本作不应只标记为“女性偶像竞争/舞台成长”，而应增加一条高密度职业链：

**公司内月度评价 → 跨公司联合新团选拔资格 → audition → 出道席位**

## 十元增量判定
- 主符号：xn（公司评价、资格门槛、选拔制度）
- 次符号：zx（训练、竞争、主动争取席位）
- 第三层：x并z（舞台表现、被看见、职业形象）
- 暗层：z + zn + xz（偶像愿望、自我认同、职业终止风险）

## 五维
- 时间：xn + z——持续月评把长期愿望切成阶段性职业门槛。
- 本体：zn + x——“我是练习生/未来偶像”必须由身体能力和稳定表现反复证明。
- 空间：x并z + n——个人表现被放进公司、同期练习生与联合选拔关系网中比较。
- 因果：zx + nx——主动训练竞争，但评价制度决定何时、以何种标准被筛选。
- 命运：xz + nz——一次高压选择可能直接终止职业路线，同时同伴/竞争关系改变选择代价。

## 生链
z偶像愿望 → zx训练竞争 → xn月度评价确认/淘汰 → x并z表现获得可见性 → xn获得三公司联合audition资格 → zn偶像本体进一步成立。

## 克链
xn评价规则克zx自由发挥；xz职业终止风险克z长期愿望；x并z公开表现压力反克zn自我稳定；zx若为了短期评价过度行动，也可能反生xz职业风险。

## 5组补子
1. xn + z：制度门槛补长期偶像愿望。
2. zn + x：偶像本体补身体/技能承载。
3. x并z + n：舞台可见性补练习生竞争关系。
4. zx + nx：主动训练补被评价、被筛选。
5. xz + nz：职业终止风险补同伴/竞争关系带来的命运压力。

## 职业度与矿级
- 核心偶像职业度：10/10
- 矿级：S
- 机制增量价值：9.5/10

## 新母型
**多级资格漏斗型：公司内部评价不是终点，而是取得更高层跨公司选拔资格的前置门槛。**

链条不是简单“训练→出道”，而是：
`训练 → 月评 → 取得audition资格 → 联合选拔 → 新团出道席位`。

这补强了专题库目前较少的“职业制度逐层放行”结构，也让 Girl Crush 成为研究女练习生制度化成长时比单纯舞台竞赛更重要的样本。
