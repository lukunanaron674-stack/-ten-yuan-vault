# IDOROLL｜十元分析

## 为什么入库
一ノ瀬一乃原本追逐摇滚/音乐人道路，梦想受挫后成为22岁自由职业女性；她在秋叶原遇到附带舞台的女仆咖啡店，从“失败音乐人”重新开始，真正进入现场偶像（ライブアイドル）职业。集英社官方将其概括为“从御宅族圣地走向世界的Live Idol疾走剧”，单行本章节直接包含《向き不向き》《向き合う覚悟》《泥まみれのアイドル》《選んだ道は》，职业实践不是背景恋爱装饰。

## 十元判定
- 主符号：z（旧音乐愿望/舞台执念）
- 次符号：zx → x并z
- 强层：xn + zn
- 支撑层：n + nx
- 暗层：xz

## 五维
- 时间：xn + z —— 旧音乐梦想失败后，职业路线被重新定义。
- 本体：zn + x —— “我是音乐人”失败后，必须回答“偶像是不是另一种假的我，还是新的我”。
- 空间：x并z + n —— 女仆咖啡、秋叶原现场、观众与偶像共同构成职业舞台空间。
- 因果：zx + nx —— 主动重新选择舞台，同时承受不适性、底层工作与现实反馈。
- 命运：xz + nz —— 原职业失败构成断裂，新的观众/同伴关系提供第二条职业命运。

## 顺序链
z旧音乐梦想 → xz原路线失败 → nx成为22岁自由职业者/负起点 → n进入秋叶原现场偶像环境 → zx选择重新站上舞台 → xn接受偶像职业规则与适性判断 → x并z通过Live/公众观看建立偶像身份 → zn重新定义“我到底是什么表演者”。

## 生链
- z 生 zx：没有被原职业失败烧掉的舞台愿望，推动重新行动。
- n 生 zx：新场域和职业同伴提供重新开始的实际通道。
- zx 生 x并z：真实Live劳动制造公众可见的偶像身份。
- x并z 生 zn：被观众当作偶像观看后，职业实践反过来生成新的自我解释。
- xn 生 zx：职业规则把模糊梦想拆成可执行的训练、工作和舞台行动。

## 克链
- xz 克 z：摇滚道路失败直接切断原梦想实现方式。
- nx 克 zx：底层现实、适性与工作条件限制主动性。
- xn 克 z：偶像职业规则迫使“我想做音乐”接受另一种职业形式。
- zn 克 x并z：旧“音乐人”本体会抵抗被定义成偶像。
- x并z 反克 zn：一旦Live劳动和观众承认持续成立，“偶像只是替代品”的旧解释越来越难维持。

## 5组补子
1. xn + z：新职业规则补旧舞台愿望，让失败后的愿望重新获得执行路径。
2. zn + x：职业本体补现实身体/年龄/处境，22岁负起点仍能被重新解释为表演者。
3. x并z + n：舞台公众身份补现场关系网络，没有观众与场域就没有Live Idol。
4. zx + nx：主动重启补被动失败，行动不是删除失败，而是在失败条件中继续做。
5. xz + nz：旧职业断裂补新关系命运，失败切断一条路，新共同体接出另一条路。

## 新母型
**旧梦想换职业载体 / 负起点现场再就业型**。

不是“失败后回档重来”，也不是“被系统强迫当偶像”。角色保留原本想站在舞台上的愿望，但承认原来的“摇滚音乐人”职业载体已经失败，转而从女仆咖啡/秋叶原Live Idol这种更低、更小、更现实的入口重新职业化。

核心反咬：
> 一开始把偶像当作原梦想失败后的替代路线；但如果真正的舞台劳动、观众与职业承认都在偶像身份里发生，那么所谓“替代品”会不会反过来成为更真实的本体？

十元短链：**z → xz → nx → n → zx → xn → x并z → zn**。

## 与已有样本差异
- vs Second Try Idol：不是回到过去修复同一职业，而是失败后留在现实时间线更换职业载体。
- vs Girl Crush：不是从练习生制度逐级晋升，而是从秋叶原小型现场/女仆咖啡的底层舞台重新就业。
- vs SHINEPOST：不是已出道团体证明存续资格，而是尚未成立的职业本体从负起点生成。
- vs Debut or Die!：没有死亡系统；职业压力来自普通而持续的现实失败，因此适合作为“零外挂再职业化”基准样本。
