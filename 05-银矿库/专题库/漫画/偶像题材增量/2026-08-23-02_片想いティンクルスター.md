# 片想いティンクルスター｜十元分析

## 收录判断
收录。虽然BL/恋爱权重较高，但职业主线不是背景装饰：月与阳都明确以偶像出道为目标；阳已是练习生，月长期参加 audition 落选；两人为进入同一组合而共同参加偶像生存选秀。2026-07-24发行单行本，职业链具备“练习生/反复落选/生存选秀/同团出道目标”。

## 十元判定
- 主符号：nz（两名幼驯染“要一起出道”的关系绑定）
- 次符号：zx → xn → x并z
- 强层：z + n
- 暗层：nx + xz + zn

## 五维
- 时间：xn + z｜长期练习与反复 audition，把愿望压进职业时间线。
- 本体：zn + x｜“我是能否成为偶像的人”持续被落选/练习生差距重写。
- 空间：x并z + n｜生存节目把私人幼驯染关系公开化为选手、竞争者与未来团员关系。
- 因果：zx + nx｜主动训练/参赛与被评价、被淘汰互咬。
- 命运：xz + nz｜“一起出道”的关系愿望被名额、竞争与第三者关系持续威胁。

## 顺序链
z想成为偶像 → nz约定一起出道 → xz月反复落选/阳先成为练习生 → zx再次参赛 → xn进入偶像生存选秀规则 → n形成选手竞争网络 → x并z争夺同团出道身份 → zn重新回答“我是偶像，还是只是为了和你在一起才成为偶像”。

## 生链
- z 生 nz：共同梦想把幼驯染关系变成职业共同目标。
- nz 生 zx：为了和阳同团，月持续报名、训练、再挑战。
- zx 生 x并z：职业行动制造舞台、节目与候选人身份。
- xn 生 n：生存选秀制度生成竞争、合作与淘汰关系网。
- x并z 生 zn：一旦被节目/观众作为偶像候选人观看，职业身份开始反写自我。

## 克链
- xz 克 z：连续落选削弱最初偶像愿望。
- xn 克 nz：选秀名额与评价规则不保证“关系好的两个人一起出道”。
- n 克 nz：新选手/旧恋人等关系介入，破坏原本封闭的两人职业共同体。
- nx 克 zx：评价与淘汰把主动努力转成被制度裁决。
- x并z 反克 zn：越成为“节目中的偶像候选人”，越不能只把职业解释成接近幼驯染的工具。

## 5组补子
1. xn + z：选秀规则/训练时间 ↔ 偶像愿望
2. zn + x：偶像自我 ↔ 实际能力与身体实践
3. x并z + n：公开候选身份 ↔ 选手/团体关系
4. zx + nx：主动训练参赛 ↔ 被评价淘汰
5. xz + nz：落选/分离风险 ↔ 一起出道的关系绑定

## 新母型
**关系共同目标被职业竞争拆开型 / 一起出道悖论**

两人因为“一起成为偶像”而进入同一个职业系统，但生存选秀的核心恰恰是有限名额与比较评价。也就是：

`nz一起出道 → zx共同参赛 → xn选秀制度 → n竞争网络 → xn反克nz`

关系把两个人送进职业机器，职业机器随后获得把两个人拆开的权力。

## 与已有样本差异
- 不同于《Idolatry》：不是粉丝为推入场，而是两个偶像志愿者共享“同团出道”目标。
- 不同于《Debut With You》：没有未来信息/系统辅助，关系本身就是职业驱动力。
- 不同于普通偶像恋爱：恋爱关系直接参与练习生差距、选秀竞争与出道名额，因此会改变职业结果。
