## 十元判定
- 主符号：zx（主动转轨、报名、争取新职业资格）
- 次符号：zn → xn → x并z
- 支撑：z + x + n
- 暗层：xz + nx + nz

### 五维
- 时间：xn + z——旧棒球时间线被切断，新的偶像职业规则开始组织未来。
- 本体：zn + x——“高中球员的我”必须与新的偶像候选身体/表演身份重新对齐。
- 空间：x并z + n——从球场共同体转入选秀、舞台和候选人关系空间。
- 因果：zx + nx——主动报名与被选拔规则约束同时存在。
- 命运：xz + nz——旧道路为何失效、关系如何推动转轨，是目前最值得继续观察的命运层。

### 顺序链
`zn棒球少年 → xz旧职业道路发生断裂/偏转 → z出现偶像愿望 → zx报名GENSEKI audition → xn接受选拔规则 → x并z偶像候选身份成立 → zn重新回答“我要成为什么人”`

### 生链
- xz 生 z：旧道路失效，制造新的职业愿望空间。
- z 生 zx：愿望转化为报名与行动。
- zx 生 xn：主动报名后进入正式选拔制度。
- xn 生 x并z：制度评价制造“偶像候选人”这一可被社会读取的身份。
- x并z 反生 zn：持续参加选秀后，新公众身份开始改写旧自我定义。

### 克链
- xz 克 zn：旧“我是棒球少年”的稳定本体被打断。
- xn 克 zx：报名之后不能只按个人意愿行动，必须服从选拔规则。
- x并z 克旧zn：一旦被作为偶像候选人观看，旧运动员身份不再独占“我是谁”。
- zn 反克 x并z：旧运动员经验、价值观可能抵抗被包装成标准偶像人格。

## 5组补子
1. xn + z：选拔规则 ↔ 新职业愿望
2. zn + x：旧运动员本体 ↔ 新职业身体/表演载体
3. x并z + n：候选公众身份 ↔ 新选手关系网络
4. zx + nx：主动报名 ↔ 被制度筛选
5. xz + nz：旧道路断裂 ↔ 推动转轨的人际/命运关联

## 新母型
**运动职业转轨 → 偶像选秀型**。

价值不在“普通人突然想当偶像”，而在于主角已有一套强职业本体——高中棒球运动员。若后续真正展开训练、排名、舞台、出道，则会形成清楚的 `旧职业zn → xz断裂 → zx跨职业行动 → xn新制度 → x并z新职业身份 → zn重建`。

## 与现有样本差异
- 不同于《IDOROLL》的“音乐梦想失败后换舞台职业载体”，这里是**体育职业/社团身份 → 偶像职业**的跨域转轨。
- 不同于《From Acting Genius To Top Idol!》的“演员能力被强制迁移到偶像”，目前没有超自然强制任务，转轨原因仍由人物现实经历推动。
- 不同于《ひかるイン・ザ・ライト！》的零外挂普通少女选秀基线，本作的起点已有成熟的运动员/球员本体，因此本体迁移价值更高。
