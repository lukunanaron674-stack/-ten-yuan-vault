# A Doomed Girl Group's Do-Over｜异名与女团救活机制补充

## 异名锁定
以下名称为同一作品，不得重复建矿：
- A Doomed Girl Group's Do-Over
- I Became the Cursed Idol Leader
- Became the Leader of a Girl Group Destined to Fail
- I Became the Leader of a Doomed Girl Group
- 망할 운명의 걸그룹 리더가 되었습니다

## 新确认职业机制
主角白鹿河/ Baek Nokha 原本已经是出道10年的韩国顶级女性solo偶像，在事业顶峰得知母亲死亡。为了救母亲接受神秘契约后，回到约10年前并进入另一个人的身体，成为注定失败/解散的女团 Still Blue（译名存在差异）的成员/领导位置。任务不是简单“重新拿一次出道资格”，而是把一个已被判定会失败的女团从职业死亡线上救活。

因此本作应从“顶级solo失去资本后重考出道”进一步修正为：
**成熟solo职业经验 → 换体进入失败女团 → 领导/运营/训练/关系修复 → 阻止团体解散 → 以团体存续换取亲缘命运修复。**

## 十元分析
- 主符号：zx（成熟职业经验被重新调用，主动救团）
- 次符号：xz → x → n → xn → x并z
- 强暗层：nz + zn

### 五维
- 时间：xn + z｜十年职业经验与回归后的第二次职业时间
- 本体：zn + x｜顶级solo旧自我进入新人女团成员的新身体
- 空间：x并z + n｜公众女团身份、舞台与成员共同体
- 因果：zx + nx｜主动救团，但受系统任务/失败命运强制
- 命运：xz + nz｜母亲死亡与女团解散命运被亲缘目标绑定

### 顺序链
xz母亲死亡 → nz救母绑定 → x换体 → zn身份错位 → nx接受任务 → zx调用十年solo经验 → n重建女团共同体 → xn重做职业流程 → x并z团体公众身份恢复 → zn从“借身体完成任务”转向“真正承担团体领导者身份”。

### 生链
- xz 生 nz：母亲死亡制造救援关系目标。
- nz 生 zx：为了救母亲，必须主动救活女团。
- x 生 zn：换体直接制造本体错位。
- zx 生 n：成熟经验被用于组织、训练与修复成员关系。
- n 生 x并z：团体关系稳定后才能形成可持续舞台/公众形象。
- xn 生 x并z：职业制度、训练和活动把团体重新做成可被市场承认的偶像单位。

### 克链
- x 克 zn：新身体否定旧solo身份的直接连续性。
- xz 克 n：既定失败/解散命运持续破坏团体共同体。
- xn 克 zx：行业制度限制个人经验不能直接兑换成功。
- n 克旧zn：团队责任压制“我只是在借身份完成私人任务”的解释。
- x并z 反克 zn：当新女团真的获得公众承认，新偶像身份反过来要求主角承认这段人生并非临时任务。

## 5组补子
1. xn + z：第二次职业时间补回最初“为何继续当偶像”的愿望。
2. zn + x：旧solo本体与新人身体互补，形成经验/载体错位。
3. x并z + n：公众女团身份必须由成员共同体承载。
4. zx + nx：主动救团与系统/命运强迫同时存在。
5. xz + nz：母亲死亡命运与亲缘救援关系互锁。

## 新母型
**顶级solo → 失败女团领导者 / 个人成功经验团队化型**

与普通回档偶像最大的差异：不是“我怎样再次成功”，而是“一个已经知道怎样成功的人，能否把个人成功经验转译成团队成功”。solo经验越强，越可能与女团需要的协作、成员差异和共同成长发生冲突。

## 反咬点
最初女团只是救母任务的工具；但主角越真正承担成员、训练、舞台和解散风险，n/x并z 越会反写 zn。最终问题会从“怎样救活这个团”变成“如果母亲已经能被救，我还会不会继续把这些成员当成自己的团”。
