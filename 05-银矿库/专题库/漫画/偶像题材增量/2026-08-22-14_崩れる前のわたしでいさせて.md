# 崩れる前のわたしでいさせて｜出道后“转生”/换团职业连续性

## 官方核验
KADOKAWA カドコミ于2026-07-06发布读切。官方简介明确：地下偶像“るる”已经从原团体转入另一团体（地下偶像语境中的“転生”），并逐渐获得人气；在拍摄现场面对一群比自己等级更高的偶像时，因为职业层级差距产生强烈自卑与紧张，无法正常行动，随后由发型/化妆工作人员古賀介入。

官方来源：https://comic-walker.com/detail/KC_019408_S

## 为什么入库
本作不是“从零成为偶像”的典型，而是当前母库明显偏缺的出道后职业连续性样本：
- 已经进入地下偶像职业；
- 离开旧团体后并未退出行业，而是换团继续职业生命；
- 新团体重新积累人气；
- 拍摄现场把不同等级偶像放进同一职业空间，形成明确的行业层级读取；
- 公众人气增长并没有自动消除职业自卑，反而把角色送进更高压力的比较环境。

因此它补的是“出道以后怎么继续当偶像”，而不是再复制一次选秀入口。

## 十元判定
- 主符号：x并z（公众身份/职业包装/被行业读取的偶像等级）
- 次符号：xn → n → zn
- 强层：xz + nx
- 支撑：zx + z

### 体量
x并z10 / xn9 / zn9 / n8 / xz8 / nx8 / zx7 / z6 / nz5 / x5

### 顺序链
旧团体职业身份x并z → xz旧轨道中断/换团 → xn进入新团体职业规则 → zx重新营业/积累人气 → x并z新团体中的公众身份增长 → n进入更高等级偶像共同拍摄空间 → nx被职业比较压制 → zn“我够不够格当偶像”发生动摇。

## 五维
- 时间：xn + z——职业连续性依靠重新进入新团体日程/规则维持，个人愿望让职业线没有随旧团体终止。
- 本体：zn + x——身体本人没有发生超自然变化，但“我是怎样等级的偶像”不断被新环境重写。
- 空间：x并z + n——新团体、拍摄现场、格上偶像共同出现的职业空间决定她被怎样观看与比较。
- 因果：zx + nx——主动重新积累人气，与被高等级职业环境压住同时存在。
- 命运：xz + nz——旧团体职业轨道终止后，通过新的关系/工作人员支持建立第二条职业轨道。

## 生链
- xz生zx：旧团体轨道中断，迫使她主动重新建立职业位置。
- zx生x并z：持续活动与人气积累，让新团体中的公众偶像身份重新成立。
- x并z生n：人气提升把她送进与更高等级偶像共同工作的职业网络。
- n生nx：进入格上职业空间后，比较与层级反而产生压制。
- nx反生zn：无法行动的职业挫败迫使她重新回答“我是否配得上这个身份”。

## 克链
- xz克旧x并z：离开旧团意味着原团体包装/位置失效。
- xn克zx：换团后必须重新遵守新团体与行业工作规则，个人行动不能完全自由。
- x并z克zn：外部等级与人气比较可以压过本人对自身职业能力的判断。
- nx克zx：紧张、自卑直接阻断职业行动。
- zn反克x并z：如果她无法重新确认自己的职业本体，再多新团人气也可能只是一层脆弱包装。

## 5组补子
1. xn + z：新团体职业规则 × 继续当偶像的愿望。
2. zn + x：偶像本体确认 × 现实身体/本人承载。
3. x并z + n：公众偶像等级 × 新团体/拍摄现场职业关系网。
4. zx + nx：主动换团再经营 × 格上比较造成的行动瘫痪。
5. xz + nz：旧职业轨道中断 × 新关系支持与第二职业轨道。

## 新母型
### “换团转生 / 职业连续性重建型”
不是退团=偶像人生结束，而是：

旧团体退出 → 换团 → 新团重新积累公众资本 → 进入更高等级职业空间 → 旧自卑重新爆发。

这里的“转生”不是超自然转生，而是地下偶像行业内部的换团职业再出生。它非常适合补母库目前缺少的“成员更替/退团后职业身份是否连续”方向。

## 最大反咬
**成功重建x并z，反而把角色送进更强的n/xn职业比较系统。**

她换团以后逐渐有人气，本来说明第二次职业路线成功；可正因为人气上升，她才进入与格上偶像共同拍摄的空间。于是成功不是解决自卑，而是把自卑升级成新的职业门槛：

zx重新经营 → x并z人气增长 → n职业圈层升级 → nx被等级压制 → zn再次崩动。

## 与已有样本差异
- 与《A Doomed Girl Group's Do-Over》不同：没有时间回档/换体，不是从顶级重考新人资格，而是现实时间线上退旧团、进新团。
- 与《SHINEPOST》不同：不是事务所设定整体解散阈值，而是个人职业身份跨团体连续。
- 与《U149》不同：重点不在同一事务所单位长期经营，而在“离开旧组织后，偶像本体是否能随本人迁移”。
- 与《Dropout Idol Fruit Tart》不同：不是现金流保住所，而是换团与职业层级比较。
