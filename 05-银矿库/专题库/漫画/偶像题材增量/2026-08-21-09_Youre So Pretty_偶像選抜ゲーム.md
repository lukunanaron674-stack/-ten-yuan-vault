# R15｜女性偶像强制出道与死亡选拔

## 1. You're So Pretty｜韩漫/Webtoon｜S
来源核验：WEBTOON ORIGINALS。Seyo遭朋友Minchae利用后发生事故，进入昏迷少女Kkotbi的身体；神明要求她在一年内完成Kkotbi“成为偶像”的命运，否则失去一切。官方简介明确写“learn the ropes of K-pop stardom”，作品已完结。

- 主符号：xz（限时命运条件 / 不完成则失去一切）
- 次符号：x → xn → zx → x并z；暗层 zn
- 顺序链：xz → x → zn错位 → xn → nx → zx → x并z → zn重建
- 生链：xz生xn（死亡/失去条件制造职业规则）；x生x并z（新身体提供新的公众可见条件）；xn生zx（期限与职业训练逼出行动）；zx生x并z（训练与竞争形成偶像公众身份）。
- 克链：xz克z（梦想被强制期限化）；x并z克旧zn（社会先承认新身体/新身份）；zx反克nx（从被迫执行转成主动掌握职业）。
- 五维：时间 xn+z；本体 zn+x；空间 x并z+n；因果 zx+nx；命运 xz+nz。
- 5组补子：xn+z / zn+x / x并z+n / zx+nx / xz+nz。
- 反咬点：若只有借用Kkotbi的身体才能成功成为偶像，成功究竟证明Seyo的能力，还是证明行业首先认可的是可被观看的身体/身份？
- 偶像职业度：10/10
- 矿级：S
- 新母型：**借体履约型**。不是单纯“换身体再就业”，而是“替另一具身体完成其偶像命运”，职业成功同时承担本体债务。

## 2. 偶像選抜ゲーム ～これから推しが他界します～｜日漫｜S
来源核验：小学馆 Big Comics 官方连载页。2025-08-29起连载。527名因各种原因离开舞台的偶像收到偶像选拔「THE FINAL」邀请，为重新站上舞台参加“不保证生命”的选拔。

- 主符号：xz（职业失败与死亡风险重叠）
- 次符号：xn → z → zx；强层 n/x并z
- 顺序链：xz旧职业断裂 → z再次发光愿望 → xn THE FINAL规则 → nx被死亡规则限制 → zx竞争 → n大量偶像临时关系 → x并z舞台确认 → zn偶像身份再成立/死亡
- 生链：xz生z（失去舞台反而强化重返愿望）；z生zx（愿望转为参赛行动）；xn生x并z（选拔制度生产可见排名/舞台位置）。
- 克链：xn克zx（选手主动性被死亡规则和赛制框定）；xz克zn（淘汰可能直接终止本体与生命）；zx反克xz（只有继续竞争才可能夺回舞台）。
- 五维：时间 xn+z；本体 zn+x；空间 x并z+n；因果 zx+nx；命运 xz+nz。
- 5组补子：xn+z / zn+x / x并z+n / zx+nx / xz+nz。
- 反咬点：她们为了证明“我仍是偶像”而进入一个可能杀死自己的制度，职业身份的恢复与生命保存第一次成为直接竞争关系。
- 偶像职业度：10/10
- 矿级：S
- 新母型：**退役/失格偶像死亡再选拔型**。与 Debut or Die 的“新人不出道就死”不同，这里是“已经失去舞台的人，为重新取得偶像资格主动进入死亡选拔”。

## 与母库已有样本差异
- Debut or Die：未来死亡条件迫使新人获得第一次出道资格。
- You're So Pretty：身体替换 + 一年履约，必须替新身体完成既定偶像命运。
- 偶像選抜ゲーム：已经离开舞台的527名旧偶像，以生命重新竞价职业资格。

## 本轮排除/观察
- Mr. Choi is a Part Time K-Pop Idol：职业机制命中，但截至2026-07仅公开极少章节，先观察，不升核心矿。
- A Day in the Life of Rookie Idols!：有Debut Showcase/Fancall/Vocals等职业细节，但为小体量CANVAS四格，暂B/观察。
- My First Love is K-POP IDOL：核心更偏偶像与普通人的恋爱重逢，不符合“成为偶像职业机制优先”，排除核心库。
