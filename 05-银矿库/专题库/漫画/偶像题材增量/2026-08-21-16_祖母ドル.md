## 为什么进入核心库
这不是“家人是偶像”的旁观型故事。祖母原本是孙女的粉丝/亲属，在余命压力与身体年轻化之后，关系位置从“台下支持者”发生职业位移，成为能够与孙女共同进入偶像活动的一方。核心不是一次选秀，而是：年龄、身体、亲属关系、粉丝身份与偶像职业身份被同时重排。

## 生链
1. xz 生 z：余命越有限，“继续陪伴/完成未竟关系”的愿望越强。
2. x 生 zx：年轻化身体重新提供行动与职业进入能力。
3. nz 生 n：原本祖孙/粉丝关系转为同团或同职业协作关系。
4. n 生 zx：共同体要求她不再只是看，而要真正做职业行动。
5. zx 生 x并z：训练、营业、舞台等行动生成新的公众偶像身份。
6. x并z 反生 zn：被持续当作偶像观看，新的职业本体逐渐成立。

## 克链
1. xz 克 x：衰老与余命原本直接关闭职业身体可能性。
2. x 反克 xz：年轻化暂时绕开原有年龄/寿命对行动空间的封锁。
3. nz 克 zn：祖母身份与“孙女的粉丝”身份限制她把自己看作偶像主体。
4. xn 克 zx：地下偶像规则、团体要求与营业结构规定个人行动。
5. x并z 克旧zn：公众越承认她是偶像，旧的“我只是祖母/粉丝”本体越难维持完整。

## 五维
- 时间：xn + z —— 有限余命与职业时间表共同压缩行动窗口。
- 本体：zn + x —— 老年祖母本体与年轻身体、偶像身体发生错位。
- 空间：x并z + n —— 台下亲属/粉丝的位置被改造成舞台/团体共同体位置。
- 因果：zx + nx —— 一方面主动成为偶像，一方面又被身体奇迹、寿命与关系条件推动。
- 命运：xz + nz —— “可能很快死去”的命运与祖孙关系绑定，决定职业行动为何必须现在发生。

## 5组补子
1. xn + z：职业日程/规则 ↔ 想在有限时间里完成陪伴与舞台愿望。
2. zn + x：祖母身份 ↔ 年轻化身体/偶像身体。
3. x并z + n：公众偶像位置 ↔ 祖孙/团体共同体。
4. zx + nx：主动进入偶像活动 ↔ 被余命、身体变化与关系环境推入新位置。
5. xz + nz：余命终点 ↔ 与孙女的命运关系。

## 新母型
### 「代际粉丝 → 同台职业者 / 年龄重置职业化」
原本的关系是：
祖母（粉丝/亲属） → 台下支持 → 孙女（偶像）。

身体年轻化以后变成：
祖母身体重置 → 进入偶像活动 → 与孙女形成同职业共同体 → 公众身份开始反写亲属身份。

它和《Idolatry》《Debut With You》的区别：
- 《Idolatry》：粉丝主动参加选秀帮助推。
- 《Debut With You》：未来粉丝以练习生身份帮助推，最后自己也走向出道。
- 《祖母ドル》：粉丝同时还是血缘长辈，先被年龄/余命排除在职业之外，再通过身体重置进入与“推”相同的职业层，导致代际关系、身体年龄和职业身份三者一起错位。

## 最大反咬
她越成功成为偶像，越不能只用“我是她祖母，所以我支持她”解释自己的行动。职业实践会制造一个不依赖血缘的新身份：

nz（祖孙/粉丝） → x（身体重置） → n（同职业共同体） → zx（职业行动） → x并z（公众偶像） → zn（新的“我是谁”）

最终最有价值的问题不是“祖母能不能当偶像”，而是：当身体年龄、社会观看和职业实践都把她定义为偶像时，原本以年龄和亲属位置成立的“祖母本体”还能否独占她是谁。
