# Assistant Manager Kim Hates K-Pop Idols｜职业机制补充

## 新确认机制
LINE WEBTOON 中文官方简介明确补出此前母库摘要没有钉死的一层：金二月的目标并不是“成为偶像并长期成功”，而是为了改写姐姐死亡，必须以 spArk 成员身份成功出道；一旦满足出道条件，他的主观计划却是“立刻退团重获自由”。失败则会被迫回到原公司，并且一辈子不能离职。

这让本作从普通“强制出道救亲人”进一步变成：**职业资格必须成立，但主体同时计划在资格成立瞬间退出职业。**

## 十元判定
- 主符号：xz
- 次符号：xn → nx → zx
- 强层：nz + zn
- 反咬层：x并z
- 偶像职业度：10/10
- 矿级：S

## 顺序链
xz姐姐死亡 → xn时间回归/任务规则 → nx被迫进入偶像职业 → nz救姐姐绑定 → zx用职场与追星经验争取出道 → x并z“spArk成员”公众身份成立 → zn立即要求退出该身份 → 职业实践与关系反过来阻止身份被简单丢弃

## 五维
- 时间：xn + z｜回到九年前，旧职场与旧追星经验成为第二人生资源。
- 本体：zn + x｜“我讨厌偶像/我不是偶像”与实际完成偶像劳动发生冲突。
- 空间：x并z + n｜spArk成员身份、公司、团体、公众共同把偶像身份社会化。
- 因果：zx + nx｜外部任务逼迫入行，主体用职场能力主动攻略职业。
- 命运：xz + nz｜姐姐死亡把亲缘关系直接变成职业命运条件。

## 生链
1. xz 生 nz：死亡历史把救姐姐变成不可回避的关系目标。
2. nz 生 zx：为了姐姐，主动调用人事/职场/代理追星经验。
3. zx 生 x并z：职业行动最终生产“spArk成员”的公众身份。
4. xn 生 n：出道评价、公司制度与团体规则制造新的职业共同体。
5. x并z 反生 zn：一旦真的被成员、公司、粉丝承认为偶像，旧“我只是完成任务”的自我定义开始松动。

## 克链
1. xn 克 zx：任务规定必须以指定团体成员身份出道，主体不能自由换路线。
2. nx 克 zn：主体不想当偶像，却必须先成为偶像。
3. nz 克 zn：救姐姐的关系目标压过“我讨厌偶像”的个人本体判断。
4. zn 克 x并z：主角计划在出道成立后立即退团，主动否认刚取得的公众身份。
5. x并z 反克 zn：如果职业关系、粉丝和团体身份已经真实成立，“立刻退出”就不再只是删除一个任务标签。

## 5组补子
1. xn + z：九年前的时间回归规则 + 五年职场/追星旧经验。
2. zn + x：拒绝偶像的自我定义 + 实际偶像能力与劳动。
3. x并z + n：spArk公众成员身份 + 公司/团体承载。
4. zx + nx：主动攻略出道 + 被任务强迫入行。
5. xz + nz：姐姐死亡命运 + 亲缘救援绑定。

## 新母型
**“出道即退出悖论 / 资格瞬时成立型”**：

> 我必须让“我是偶像”在制度与公众层面真实成立，但我的原始目标恰恰是在它成立的第一刻把它取消。

它区别于《Debut or Die!》：后者把出道当生存终点，本作则把出道当“退出职业之前必须先完成的资格条件”。因此最值得追踪的反咬是：**工具性职业身份是否会因为真实劳动、团体关系和公众承认，而拒绝被主体按计划瞬间注销。**
