# アイドル転生－推し死にたまふことなかれ－｜十元分析

## 收录判定
小学馆官方资料确认：主角“かい”原本为女性，转生为男性后，为了拯救自己的推“ジナン”，与其一起以练习生身份朝K-POP偶像出道前进。全20话完结。不是普通偶像恋爱背景，职业入口、练习生、出道目标与身份改写直接构成主线。

## 十元判定
- 主符号：nz
- 次符号：x → xn → zx
- 第三层：x并z
- 暗层：xz + zn + z
- 体量：nz10 / x9 / xn9 / zx9 / x并z8 / xz8 / zn8 / z8 / nx6 / n6

## 五维
- 时间：xn + z｜转生后的职业时间与“救推/出道”执念共同推进。
- 本体：zn + x｜女性旧自我进入男性新身体，职业成功持续追问“谁在成为偶像”。
- 空间：x并z + n｜K-POP练习生/偶像公众身份必须在公司、组合与舞台关系中成立。
- 因果：zx + nx｜主动训练与救援行动不断撞上身体、公司、职业制度的被规定性。
- 命运：xz + nz｜推的死亡/危险命运与主角关系绑定，关系本身把主角推入偶像职业。

## 顺序链
xz（推之死亡/危险） → nz（必须救推） → x（转生为男性身体） → zn（本体错位） → xn（进入K-POP练习生制度） → nx（接受训练/出道规则） → zx（主动训练、竞争、救援） → x并z（偶像公众身份逐渐成立） → zn（新偶像身份反写旧自我）

## 生链
1. xz 生 nz：死亡威胁把普通“推活关系”升级成必须介入对方命运的绑定。
2. nz 生 zx：为了救推，关系直接催生主角亲自进入职业系统的行动。
3. x 生 xn：新男性身体打开新的K-POP练习生职业路径。
4. xn 生 x并z：训练、评价、出道制度持续生产可被公众读取的偶像身份。
5. zx 生 zn：真正参与训练和舞台后，“为了救人而假装当偶像”可能长成真实职业自我。

## 克链
1. xz 克 z：推的死亡风险压过单纯追星愿望。
2. xn 克 zx：公司、练习生、出道规则限制个人救援行动。
3. x 克 zn：身体性别变化直接冲击旧本体连续性。
4. x并z 克 zn：公众越承认男性偶像“かい”，旧女性自我的社会可见性越被覆盖。
5. nz 反克 xn：救推关系会迫使主角突破纯职业最优解，做出制度不鼓励的选择。

## 5组补子
1. xn + z：职业制度 ↔ 成为偶像/救推执念。
2. zn + x：旧自我 ↔ 新男性身体。
3. x并z + n：偶像公众身份 ↔ 组合/公司/舞台关系网络。
4. zx + nx：主动训练救援 ↔ 被转生与职业规则规定。
5. xz + nz：死亡命运 ↔ 推与被推的关系绑定。

## 与已有样本差异
- 对比《アイドラトリィ》：两者都是“为了推，自己进入偶像职业”。但《アイドラトリィ》是粉丝保留原身体/原身份，主动潜入选秀；本作则先发生转生与性别身体替换，再与推一起成为练习生。
- 对比《Who’s That Girl?》：后者换身体/社会身份主要用于绕过旧污名、重新取得职业准入；本作换身体不是职业优化本身，而是“救推命运”驱动下的载体重置。
- 对比《Assistant Manager Kim Hates K-Pop Idols》：后者为了救妹妹被迫进入自己厌恶的偶像团；本作是粉丝nz把“支持推”升级为“和推一起成为偶像”。

## 新母型
### 推活关系 → 转生换体 → 同职业共命型
粉丝不再只支持、购买、投票，也不只是潜入选秀帮推，而是通过转生获得新身体后，直接与推共享“练习生→出道”的同一职业轨道。

核心公式：
`xz推之命运危机 → nz救推绑定 → x换体 → xn共同练习生制度 → zx共同职业行动 → x并z偶像身份 → zn本体反写`

## 反咬点
最值得继续采的是：主角最初“成为偶像”只是救推的手段，但训练、舞台和公众承认会逐渐把工具身份变成真实身份。于是会出现：**为了让推活下去而成为偶像，最后却必须回答“没有推，我还要不要继续当偶像？”**
