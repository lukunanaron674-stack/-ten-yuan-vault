# トラペジウム / Trapezium｜十元深拆

## 入库理由
2026-03-19 发行漫画版。女高中生东ゆう明确以“绝对成为偶像”为目标，并主动给自己制定四条生活规则：不使用SNS、不交男友、在学校不显眼、寻找东南西北四名美少女成为伙伴。核心不是偶像恋爱背景，而是从零主动组建偶像候选共同体、把日常生活改造成职业准备。

## 十元判定
- 主符号：zx（为了成为偶像，主动设计路径、寻找成员、组织行动）
- 次符号：xn → n → x并z
- 强层：z + zn
- 暗层：nx + xz

## 五维
- 时间：xn + z｜长期规则化自我管理服务于“成为偶像”的执念。
- 本体：zn + x｜“我要成为偶像”的自我定义必须由真实身体、能力与持续行动承载。
- 空间：x并z + n｜四名少女组成可被观看、可被社会识别的偶像单位。
- 因果：zx + nx｜主动策划推进梦想，同时伙伴与现实会反过来限制个人方案。
- 命运：xz + nz｜个人梦想一旦绑定四人共同体，成员关系变化会成为职业命运变量。

## 顺序链
z偶像愿望 → xn四条自律规则 → zx主动寻找“东南西北”伙伴 → n四人共同体成立 → x并z偶像组合形象出现 → xn/xz现实职业压力进入 → zn重新回答“偶像到底是什么、我为何要成为偶像”。

## 生链
- z 生 xn：愿望制造自律规则。
- xn 生 zx：规则把模糊梦想转成持续行动。
- zx 生 n：主动搜寻并组织伙伴。
- n 生 x并z：关系共同体被包装成可观看的偶像单位。
- x并z 反生 zn：被社会当作偶像后，职业身份开始塑造真实自我。

## 克链
- xn 克 z：为了职业资格，个人青春与自由被主动压缩。
- n 克 zx：伙伴不是棋子，成员意志会限制主角的单向策划。
- x并z 克 zn：越接近理想偶像形象，真实自我越可能被公众身份覆盖。
- xz 克 z：现实职业后果迫使“想成为偶像”从幻想变成代价问题。

## 5组补子
1. xn + z｜规则 ↔ 愿望：想成为偶像，所以把青春规则化。
2. zn + x｜本体 ↔ 身体/能力：偶像身份必须由现实的人承担。
3. x并z + n｜公众包装 ↔ 团体关系：四人只有同时作为关系共同体与可观看单位才成立。
4. zx + nx｜主动策划 ↔ 被动受限：主角能组织路线，却不能完全控制伙伴与行业。
5. xz + nz｜职业后果 ↔ 关系命运：团体关系一旦裂开，职业未来也随之改变。

## 新母型
### “先把人生偶像化，再把人组成偶像团”型
与普通 audition 型不同，职业机制从进入事务所之前就开始。主角先用 xn 把私人生活改造成职业准备，再用 zx 主动寻找成员，使 n 逐渐生成 x并z。也就是说：职业制度尚未正式接纳她，她已经先在生活层面制造了一套“准偶像制度”。

## 反咬点
最初四条规则是为了保护偶像梦想，但规则越成功，越会把青春生活、友情与伙伴工具化。于是出现 xn → zx → n → x并z → zn 的反咬：为了成为理想偶像而设计的人生，最后会迫使她重新回答“偶像是我的愿望，还是已经变成控制我的规则？”

## 与已有样本差异
- Girl Crush：更偏练习生制度、月评和选拔资格漏斗；本作把职业化前移到“进入行业之前的自我规训与组团”。
- Idol × Idol Story!：偏失败后重新选择偶像梦想；本作强调第一次追梦时就主动把青春结构化。
- Idolatry：为了推而进入100人选秀；本作首先是自己的偶像愿望，并主动寻找伙伴制造团体条件。
- SHINEPOST：已出道后的职业存续阈值；本作研究出道前的“自建准职业系统”。

## 结论
偶像职业度：9.5/10
