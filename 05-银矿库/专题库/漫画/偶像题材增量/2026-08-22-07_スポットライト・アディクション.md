# スポットライト・アディクション｜十元分析

## 收录理由
大学生星野湊原本是偶像团体「ロデシア」成员ルカ的粉丝，因为迷恋偶像而长期练舞。团体公开招募新成员后，他参加 audition 并实际合格，从台下粉丝直接进入推所在的偶像团体。作品重心明显含恋爱，但“粉丝→练舞→新成员选拔→合格→成为同团偶像”的职业转换是剧情成立的必要机制，因此收 A+，不升 S。

## 十元判定
- 主符号：nz（粉丝—推的关系绑定）
- 次符号：zx → xn → x并z
- 强层：n + zn
- 暗层：nx + z
- 偶像职业度：8.5/10
- 矿级：A+

## 五维
- 时间：xn + z｜长期追星与练舞积累，在新成员招募节点转成职业机会。
- 本体：zn + x｜“我是粉丝”被实际偶像劳动改写为“我是团员”。
- 空间：x并z + n｜台下观看关系进入同一团体、同一后台与同一舞台。
- 因果：zx + nx｜主动练舞/报名，与合格后必须承担团体职业要求并存。
- 命运：xz + nz｜原本不可跨越的粉丝—偶像距离，被一次成员招募重写。

## 顺序链
nz推关系 → z想靠近推 → zx长期练舞/报名 → xn新成员 audition → x并z获得新人偶像身份 → n进入同团职业关系 → zn“粉丝”本体被职业身份反写。

## 生链
- nz 生 z：对推的关系投入催生接近愿望。
- z 生 zx：愿望转为练舞与报名。
- zx 生 x并z：行动通过 audition 生成可见的新人偶像身份。
- xn 生 n：选拔制度把原本台上/台下的两人编入同一职业共同体。
- x并z 生 zn：被观众与团体当作偶像，开始重写自我认定。

## 克链
- xn 克 nz：进入同团后，职业规则不允许只按私人粉丝关系行动。
- n 克旧nz：同事/团员关系覆盖单纯“推与粉丝”的单向关系。
- x并z 克 zn：公众新人偶像身份压迫旧“普通大学生/粉丝”本体。
- nz 反克 xn：最初的追星目的可能干扰职业边界，被推质疑“是否为了私联而入团”。

## 5组补子
1. xn + z：招募/选拔规则 + 想接近推的愿望。
2. zn + x：普通大学生/粉丝自我 + 实际身体训练与偶像劳动。
3. x并z + n：新人偶像公众身份 + 同团成员关系。
4. zx + nx：主动练舞报名 + 合格后被职业义务约束。
5. xz + nz：原本遥远的职业阶层 + 粉丝关系改变命运入口。

## 新母型
**粉丝直接补位入团 / 单向应援关系职业同事化。**

与《アイドラトリィ》《Debut With You》不同，本作不是为了帮助推赢选秀而自己参赛，而是“推所在的既有团体出现成员空缺”，粉丝通过新成员 audition 直接补位，瞬间从消费者/观看者变成生产者/同事。

## 反咬点
真正有价值的是 nz → xn → n 的关系改写：越成功成为同团偶像，越不能继续用“我是你的粉丝，所以我要靠近你”的方式处理关系。职业成功不是把粉丝愿望简单兑现，而是消灭原先那种安全的单向粉丝位置。

## 证据
- Hulu Comic：作品现列7卷；简介明确星野湊因推ルカ而练舞，在ロデシア新成员招募时参加 audition 并合格，随后作为新人偶像进入同团。
- BookLive：电子版自2026-04-10开始发行，作品定位为“大型新人偶像×孤独偶像”，同样确认新成员 audition 与合格机制。

## 与专题边界
恋爱权重较高，因此不作为“纯职业成长”S级基准；但职业入口本身不可删除，若删掉 audition、入团与同团身份，核心关系冲突也无法成立，故高于普通偶像恋爱背景，收 A+。
