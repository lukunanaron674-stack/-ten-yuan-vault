# One Year Idol Contract｜十元观察卡

## 收录判断
WEBTOON 官方简介确认：Berem 是明确想成为偶像的女性追梦者，长期参加娱乐公司 audition 却持续被拒；随后神秘招募者提出一份为期一年的偶像契约，代价被描述为“Everything”。截至 2026-02-09 共更新至 Episode 5，当前仍属于 DRAFT VERSION，体量不足，因此不升核心矿。

## 十元
- 主符号：xz（高代价契约 / 职业命运条件）
- 次符号：z → zx → xn
- 支撑：zn + x并z
- 暗层：nx + n
- 顺序链：z偶像愿望 → zx反复试镜 → xz连续失败/机会封闭 → xn一年契约建立规则 → nx被契约代价约束 → zx继续职业行动 → x并z若成功则取得偶像公众身份 → zn重新定义“我愿意为偶像身份付出什么”

## 五维
- 时间：xn + z｜一年契约把愿望压进明确期限。
- 本体：zn + x｜成为偶像是否值得以未知的“Everything”交换。
- 空间：x并z + n｜娱乐公司、audition、公众偶像位置与行业关系。
- 因果：zx + nx｜主动追梦与契约强制并存。
- 命运：xz + nz｜职业机会以高代价条件化；关系层目前证据较薄。

## 生链
- z 生 zx：愿望驱动反复 audition。
- zx 生 xn：持续行动终于进入契约化职业入口。
- xn 生 x并z：若履约，规则将生产正式偶像身份。
- xz 生 zn：代价迫使角色重新回答“偶像对我意味着什么”。

## 克链
- xz 克 zx：反复拒绝和契约代价压缩自由追梦空间。
- xn 克 z：一年期限把纯愿望改造成必须完成的职业任务。
- nx 克 zx：签约后行动不再完全自由。
- zn 反克 xn：若代价越过自我底线，本体可能拒绝职业契约。

## 5组补子
1. xn + z：一年职业契约 ↔ 成为偶像的愿望。
2. zn + x：真实自我 ↔ 可被行业使用/包装的职业载体。
3. x并z + n：偶像公众位置 ↔ 公司/同行/观众关系。
4. zx + nx：主动试镜 ↔ 契约后的被迫履约。
5. xz + nz：高代价命运条件 ↔ 后续关系责任，暂待更多章节验证。
