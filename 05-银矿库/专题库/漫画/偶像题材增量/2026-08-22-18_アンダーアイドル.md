# アンダーアイドル｜十元分析

## 收录理由
职业适性测试能从遗传/测试判定适合职业。犬塚めい梦想成为顶级偶像，却被制度判定为“无职S”；宇佐美优成则被判定“偶像制作人S”。两人组成制作人—偶像搭档，直接挑战制度判定。2026-05-12 已发行单行本第1卷；2026-08仍在《月刊少年ガンガン》连载，官方连载已出现 summer live。

## 十元
- 主符号：xn（职业适性制度/评价规则）
- 次符号：z → zx（被制度否定仍坚持愿望，并主动进入偶像职业实践）
- 强层：zn + x并z（“我想成为偶像”的自我定义，与社会可见的偶像身份）
- 支撑：n（制作人—偶像搭档）
- 暗层：nx + xz（先天判定造成的被动限制与职业命运封锁）

## 五维
- 时间：xn + z——制度给出未来职业轨道，愿望拒绝服从预测。
- 本体：zn + x——“我是谁/能做什么”与被测试读取的身体/才能条件冲突。
- 空间：x并z + n——舞台、公众身份由制作人与偶像协作生成。
- 因果：zx + nx——主动训练/制作对抗被动接受适性判决。
- 命运：xz + nz——被制度预先写死的职业命运，由搭档关系共同改写。

## 顺序链
xn职业适性判定 → xz“无职S”封锁偶像未来 → z仍想成为顶级偶像 → n遇到“制作人S”宇佐美 → zx两人主动挑战职业系统 → x并z通过Live/职业实践制造偶像可见性 → zn用真实职业结果反证制度定义。

## 生链
- z 生 zx：愿望催生对制度的主动挑战。
- n 生 zx：制作人—偶像搭档把个人愿望转化成可执行职业行动。
- zx 生 x并z：训练、制作、Live把“想当偶像”变成公众可见的偶像事实。
- x并z 反生 zn：如果舞台与观众承认成立，职业实践重新定义“我是谁”。

## 克链
- xn 克 zn：制度先于本人定义“你不适合任何职业”。
- xz 克 z：适性判决把愿望压成被社会判定不可能的未来。
- zx 克 xn：真实行动尝试推翻抽象测试的职业结论。
- x并z 克旧xn：若公众舞台成立，现实职业结果反证适性制度。
- xn 反克 zx：后续每次制度评价都可能继续证明“无职S”并非一句开场设定，而是长期阻力。

## 5组补子
1. xn + z：职业适性判定 vs 顶级偶像愿望。
2. zn + x：自我认定 vs 被遗传/测试读取的身体才能。
3. x并z + n：偶像公众身份由制作人—偶像关系共同制造。
4. zx + nx：主动挑战 vs 接受“你没有才能”的被动位置。
5. xz + nz：被写死的职业命运 vs 搭档共同改命。

## 新母型
**职业适性判决反抗型 / 制度说你不适合，但职业实践反证制度。**

与《Wanna be a Star!》不同：后者是能力存在但性别/职业分类错位；本作是社会拥有一套看似科学、能提前决定职业命运的测试，女主从源头就被判定“没有职业才能”。因此核心不是绕过分类，而是让真实偶像劳动与舞台结果去攻击分类系统本身。

## 反咬点
最有价值的链是：`xn → xz → z → zx → x并z → zn → 反克xn`。如果“无职S”的人最终真的成为被公众承认的偶像，那么被证明错误的不只是一次考试，而是整个“才能可以提前决定职业”的世界规则。
