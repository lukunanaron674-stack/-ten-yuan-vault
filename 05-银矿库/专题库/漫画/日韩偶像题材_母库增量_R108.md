# 日韩偶像题材_母库增量_R108

## 作品
**《칠전팔기 구해라 / Persevere, Goo Hae-Ra / 七颠八起具海拉》｜韩国Mnet音乐成长剧｜A矿，核心机制S级**

## 一句话矿核
具海拉为了让已故父亲留下的歌曲被世人听见，和两位青梅竹马参加《Superstar K 2》式电视选秀；她们在节目里与其他参赛者被临时编成一组，却在关键阶段被淘汰，各自回到普通生活。几年后，这批“被节目判定失败的人”重新汇流、自己组成团队并获得出道机会。真正的新矿不是“失败后再努力”，而是：**节目为了淘汰而临时制造的n关系，在节目结束后没有消失，反而成为制度外重新职业化的种子。**

## 新增母型
### 「赛制淘汰后的关系残留 / 临时赛队脱离节目自组织型」

普通生存节目：
`参赛者 → 临时组队 → 评价 → 输掉 → 组合消失`

本作更值得抽的是：
`临时组队 → 共同失败 → z共同历史残留 → 节目关系结束 → 成员各自散开 → 新事件使旧n重新接通 → 脱离原节目重新组团 → 自己制造第二条出道路`

所以制度虽然淘汰了“这一次表演”，却意外培养出了未来真正能长期存在的职业共同体。

---

## 一、偶像/歌手身份如何建立

### 起点
具海拉不是现役偶像，而是明确的歌手志愿者。她的职业欲望来自私人而具体的目标：**把无名作曲家父亲留下的音乐推向公众。**

### 第一入口：全国电视选秀
- 与青梅竹马一起参加歌唱选秀；
- 通过地区预选；
- 在Super Week被与其他参赛者编为一组；
- 接受公开评价、竞争、镜头和淘汰规则；
- 最终团队失败，第一条制度化出道路被切断。

### 第二入口：失败者重新汇流
- 节目失败后成员并未立即成为职业者；
- 各自回到普通生活；
- 后来因新的事件重新聚集；
- 原先只是“节目临时组”的关系被重新激活；
- 开始把旧共同经验转成真正团队，最终争取正式出道。

**身份生成不是一次通过审查，而是“先被制度拼成临时组合，再由失败者自己把临时关系活成真正职业共同体”。**

## 二、训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 训练
- audition准备；
- 合唱与团队排练；
- 临时组队后的协调；
- 节目失败后继续进行音乐实践；
- 重组后再次准备正式职业舞台。

### 出道
本作不是“一次选秀=直接职业合法性”。
第一阶段选秀失败，第二阶段才通过成员重组和新的行业机会得到真正的Debut机会。

### 竞争
- 公开选秀；
- 地方预选；
- Super Week；
- 临时组队竞争；
- 节目淘汰；
- 后续行业资源和公司阻挠继续制造职业压力。

### 舞台
- audition舞台负责第一次公开能力验证；
- 临时团队舞台第一次制造n共同实践；
- 后来的Debut Stage负责证明：**同一批曾被淘汰的人，在脱离原评价结构后是否能重新成立。**

### 粉丝/公众
公众最初是选秀节目中的评价与观看者；进入第二阶段后，公众不再只是一次性淘汰票，而成为验证新团队是否拥有持续职业价值的外部关系。

### 公司机制
公司和电视节目掌握第一次入口与淘汰权，但无法完全控制被淘汰者之后形成的新关系网络。后续大型娱乐公司仍会制造资源差与阻碍，因此“退出原赛制”不等于退出整个行业权力场。

## 三、十元体量

| 十元 | 体量 | 本轮作用 |
|---|---:|---|
| **n** | **10** | 临时赛队失败后仍保留关系资本，最终重新组团 |
| **z** | **10** | 一次共同淘汰成为未来重组的共同历史 |
| **zx** | **10** | 失败后重新选择音乐与出道，而不是接受赛制最终定义 |
| **xn** | **10** | 选秀规则、淘汰制、公司资源与正式出道机制 |
| **x并z** | **9** | “淘汰者”标签→新团队/正式歌手身份 |
| **nx** | **9** | 淘汰、行业资源差、公司阻挠持续压迫 |

| **xz** | **7** | 死亡与意外事件形成不可逆转折，但不是主制度 |

### 主元
**n + z + zx**

### 承载元
**xn + x并z**

### 反咬元
**nx + zn**

## 四、顺序

**nz → zx → xn → n → nx → z → zn → zx → n再接通 → x并z → nz**

拆开：

1. **nz**：父亲留下的音乐和亲密关系先产生职业意义；
2. **zx**：主动参加全国选秀；
3. **xn**：进入电视赛制；
4. **n**：制度临时拼出团队；
5. **nx**：淘汰规则切断当次职业路径；
6. **z**：共同失败变成成员共享历史；
7. **zn**：角色开始面对“失败是不是说明我不行”；
8. **zx**：重新选择音乐道路；
9. **n再接通**：旧临时关系重新变成真实团队；
10. **x并z**：新的职业组合/歌手身份生成；
11. **nz**：公众与成员关系重新确认这个身份。

---

## 五、五维

### 时间维｜xn + z：10/10
第一次选秀不是被删除的失败支线，而是未来真正团队的前史。**失败本身成为职业资产。**

### 本体维｜zn + x：10/10
“节目淘汰我”与“我有没有成为歌手的能力”必须拆开。制度只判断某一轮结果，不能自动完成本体判决。

### 空间维｜x并z + n：10/10
电视选秀临时队、散开的普通生活、后来重组的团队、正式舞台，是不同社会空间对同一批人的重新命名。

### 因果维｜zx + nx：10/10
制度先封路，主体再重新造路；真正的主动性出现在**第一次正规路径已经明确失败之后**。

### 命运维｜xz + nz：9/10
父亲死亡和后续重大事件都不可逆，但正因为不可逆，音乐与成员关系才获得持续行动的重量。

## 六、关系结构

### 1. 父亲 → 海拉
**缺席的关系生成持续职业欲望。**
父亲无法继续行动，但其作品通过z持续要求被完成。

### 2. 海拉 ↔ 临时赛队成员
最初由节目规则强行拼接；失败以后，这段关系却没有随赛程一起失效。

### 3. 成员 ↔ 选秀制度
制度拥有当轮淘汰权，但不拥有成员未来全部职业解释权。

### 4. 成员 ↔ 后续公司/行业
即使离开选秀，职业资源仍受行业组织控制，因此“自组织”不是幻想式完全自由，而是换一个谈判位置。

---

## 七、动态链

### 动态链A｜临时关系残留
`xn临时组队 → n共同实践 → nx淘汰 → x并z临时团队解除 → z共同失败残留 → n重新接通 → 新x并z`

**规则：制度可以解除组织形式，但不能自动删除已经形成的共同历史。**

### 动态链B｜淘汰结果去本体化
`xn判负 → z失败累积 → zn“我不行”风险 → zx再次行动 → x重新验证 → 新zn`

**规则：评价结果只属于具体xn，不应直接压成zn。**

### 动态链C｜失败者自组织
`原xn封路 → zx退出原路径 → n旧关系再利用 → 新xn最小职业结构生成 → x并z重新职业化`

**规则：被制度淘汰的人，可以把制度曾经制造的关系与经验拿出去，反过来搭建第二条职业入口。**

---

## 八、反咬点

### 反咬1｜节目为了淘汰而组队，却替未来竞争者孵化了团队
选秀节目的临时组队本意只是方便比较和淘汰。

但：
**共同排练 → 共同舞台 → 共同失败**
会产生真实z和n。

所以：
> **xn为了筛人制造的n，可能在离开xn以后获得自己的生命。**

### 反咬2｜一次公开失败越大，重组后的共同体反而越有黏性
共同失败意味着成员共享别人没有的：
- 被淘汰的记忆；
- 对赛制的理解；
- 对彼此能力的真实认识；
- “我们都没有被留下”的共同位置。

于是负z可能转成n的黏合剂。

### 反咬3｜出道失败不等于职业失败
选秀节目只能回答：
**“你们有没有在这套规则下赢。”**

不能完整回答：
**“你们能不能在别的结构里成为职业者。”**

所以：
> **xn判定 ≠ zn真理。**

### 反咬4｜离开节目后，自由增加，但资源减少
脱离大赛制以后：
- 自主权↑；
- 资源、镜头、宣传、舞台渠道↓。

因此第二条路不是“逃离制度以后一路顺利”，而是：
**用更大的zx换更少的现成资源。**

## 九、视觉符号

1. **选秀号码牌 → 被淘汰后摘下号码牌**
2. **Super Week临时六人站位 → 数年后同样几个人再次排成真正团队队形**
3. **电视演播厅巨大Logo → 淘汰后各自回到狭小普通生活空间**
4. **落选名单/熄灭舞台灯 → 后来小型Debut Stage重新亮灯**
5. **第一阶段由节目工作人员安排队形 → 第二阶段成员自己围在排练室决定谁唱哪一段**
6. **父亲旧乐谱 → 第一次audition曲 → 后来正式职业舞台**

最强视觉对子：
> **“节目宣布你们结束” ↔ “几年后同一批人自己重新站成一排”。**

## 十、可复用母题

### 1. 临时组织脱壳
制度临时拼出的队伍，在制度结束后反而变成真实共同体。

### 2. 失败关系资本
共同失败不是纯负债，也可能成为只有这一批人拥有的信任与理解。

### 3. 评价去本体化
某一套赛制判你失败，不等于主体整体失败。

### 4. 淘汰者二次编团
被同一场比赛淘汰的人，后来离开比赛重新组队。

### 5. 制度外重组→制度内回流
先离开第一套选拔结构自证，最终仍需重新接入正式发行、舞台和公司网络。

### 6. 被筛选关系反噬筛选者
选秀节目无意中培养了一个后来脱离它也能成立的组合。

## 十一、矿级

### 作品整体：A矿
理由：
- 职业主线明确：歌手志愿→电视选秀→淘汰→重组→出道；
- audition、临时组队、舞台、公司阻挠均实际参与因果；
- 但全剧同时有明显爱情、家庭与青春剧情，因此不升为纯偶像成长S矿。

### 核心机制：S级
**「赛制淘汰后的关系残留 / 临时赛队脱离节目自组织型」**具有很高迁移价值，而且与已有“失败练习生重组”“制度外自证”不同：这里最关键的是**第一套制度亲手制造了后来会脱离自己的n关系。**

## 最终矿核

> **制度可以宣布一次比赛结束，却不能保证它在比赛过程中制造的人际关系、共同失败和职业经验也一起消失。最有意思的失败者故事，不是“下一次再参加同一个考试”，而是被淘汰的人把旧赛制留在自己身上的关系与经验拿出去，重新组织成一个原赛制没有预料到的新职业入口。**
