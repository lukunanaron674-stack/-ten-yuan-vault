# 日韩偶像题材｜母库增量 R22

## 《IDOLY PRIDE / アイドリープライド》｜日本原创TV动画｜S矿

## 1. 为什么进入核心样本
这部不是普通“女孩子组成偶像团”的泛样本。官方故事页明确给出完整职业链：星见Production重新举办新偶像成员选拔；长濑麻奈的妹妹长濑琴乃、拥有与麻奈极相似歌声的川咲樱等人参加；10名成员进入事务所宿舍共同生活；之后接受基础训练、组合拆分、声乐与舞蹈训练、媒体出演、宣传照、Debut Live、Live Battle、3个月预选、NEXT VENUS大奖赛本选与决赛。

因此它符合本专题最重要条件：**从候选人进入偶像职业制度，并持续为了成为更强偶像而行动。**

本轮真正新增的不是“选秀”，而是：

> **新人不是从零开始被评价，而是被一个已经死去的顶级前代不断定义。**

琴乃因为是麻奈的妹妹被比较；樱因为歌声像麻奈而被公众称为“麻奈再来”；甚至竞争者也在追逐或超越麻奈。于是“成为偶像”同时变成“怎样从前代的影子里长出自己的身份”。

## 2. 偶像身份如何建立
- 起点：琴乃、樱等人以新人身份参加星见Production新成员选拔。
- 入门：通过audition后马上开始lesson，并入住事务所宿舍。
- 组织生成：最初多人被视为一个新偶像项目，随后因成员特质被拆成两个group。
- 职业化：持续基础训练、舞蹈、vocal training、媒体出演、宣传照拍摄。
- 出道：两组分别以「月のテンペスト」与「サニーピース」完成Debut Live。
- 竞争：参加Live Battle与NEXT VENUS Grand Prix，从预选一路进入本选、半决赛、决赛。
- 社会承认：关注度、媒体舆论、竞争组评价与大量现场粉丝共同确认偶像身份。

## 3. 十元
### 主元：zn｜10
本轮核心不是技能，而是“我到底是不是前代的复制品”。琴乃与樱的职业身份持续被麻奈这一旧模板侵入。

### 次元：xn｜10
选拔、训练、分组、Debut Live、Live Battle、VENUS Program、Grand Prix构成极强职业规则机器。

### 次元：x并z｜9
“麻奈妹妹”“麻奈再来”“月のテンペスト成员”“サニーピース成员”都是公众标签，决定她们首先被怎样看见。

### 次元：n｜9
十人宿舍、团队拆分、leader、成员互补与共同训练构成稳定承载。

### 次元：zx｜9
新人不是只被规则推着走。进入大奖赛、拒绝继续借麻奈之歌、决定用自己的歌登顶，都是主动夺回定义权。

### 次元：z｜9
死亡前代、出道Live、预选、本选、半决赛、决赛等节点持续让身份冲突显影。

### 次元：nx｜8
公众舆论、前代比较、比赛制度、父辈/事务所判断与排名不断形成外部压力。

### 次元：nz｜8
姐妹关系、队友关系、已故麻奈对众人的影响，以及粉丝支持让职业成长不只是排名。

### 次元：x｜8
歌声、舞蹈、领导力、个人风格需要从“像前代”里重新提纯出来。

### 次元：xz｜8
麻奈死亡是整个职业世界重新排列的命运断点，也让“继承”始终带着无法回到过去的危险。

### 体量总表
`zn10 / xn10 / x并z9 / n9 / zx9 / z9 / nx8 / nz8 / x8 / xz8`

## 4. 顺序
### 入场链
**xz（前代死亡） → z（遗留影响） → x并z（妹妹/相似歌声标签） → zx（参加选拔） → xn（训练制度）**

### 成长链
**xn → n → x → x并z强化 → nx公众比较 → zn冲突 → zx主动去影 → 新x并z**

### 总动态链
**xz → z → x并z → zx → xn → n → x → nx → zn → zx → 新x并z**

一句话：
> **前代留下名字与评价标准，新人先靠这道影子进入公众视野，再必须主动杀死“复制品身份”，才能真正成为自己。**

## 5. 五维
### 本体维｜zn + x = 10/10
全作最强。琴乃被说成“麻奈的劣化复制”；樱被舆论说成“麻奈再来”。能力越接近前代，本体问题越尖锐。

### 时间维｜xn + z = 10/10
前代历史持续回流；当前职业制度又用比赛和阶段节点不断逼新人给出新答案。

### 空间维｜x并z + n = 10/10
事务所、宿舍、两组合、舞台和观众把个体变成社会性的“偶像单位”。

### 因果维｜zx + nx = 9/10
新人主动参加、主动练习、主动参赛，但每一步都被排名、舆论、前代标签回压。

### 命运维｜xz + nz = 9/10
麻奈死亡切断旧时代，但人与她的关系继续决定后来者如何前进。

## 6. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制
### 训练
官方第3话写明成员为出道每天进行基础训练；第4、5话继续有外部强团指导、分组后单独lesson；第6话明确有编舞和vocal training。

### 出道
两组在星见祭特设舞台完成Debut Live。出道被明确作为“向偶像顶点迈出第一步”，不是背景略过。

### 竞争
VENUS Program以AI判定偶像实力并进行rank；之后有Live Battle和NEXT VENUS Grand Prix，3个月预选、本选、半决赛、决赛持续推进。

### 舞台
舞台不是装饰，而是身份验证器：训练结果、leader分工、成员风格、与强团比较都最终必须在Live中兑现。

### 粉丝 / 舆论
后期大众开始讨论樱是不是“麻奈再来”；决赛现场有大量粉丝。粉丝既提供nz支持，也参与x并z标签制造。

### 公司
星见Production负责audition、lesson、宿舍、分组、leader选择、媒体出演、宣传照与赛事路径。公司同时是职业入口和身份加工机器。

## 7. 主角欲望与代价
### 琴乃
欲望：成为偶像并到达姐姐曾抵达、甚至未能抵达的位置。
代价：她越靠近麻奈，越容易被看成麻奈的复制品，而不是琴乃。

### 樱
欲望：以自己的歌声与团队到达顶点。
代价：拥有“像麻奈”的天赋会带来关注，却同时夺走她作为独立新人的解释权。

### 共通代价
> **继承前代越多，越容易获得职业资本；获得越多，越必须证明自己不是前代的容器。**

## 8. 关系结构
### 麻奈 → 琴乃
已故姐姐是z/xz历史原点，也是琴乃的zn镜子。

### 麻奈 → 樱
相似歌声让樱获得强x并z公共标签，却同时制造本体侵蚀。

### 琴乃 ↔ 樱
两人既共享“麻奈影子”，又通过不同group与leader路线形成分叉：一个更直接承受血缘继承，一个承受声音继承。

### 十名成员 ↔ 两个group
n不是固定不动的容器，而是通过分组重构。分组本身就是“怎样让不同x发光”的组织设计。

### 新人 ↔ 老牌强团
TRINITYAiLE、LizNoir承担nx压力与能力镜子；她们迫使新人知道“不是像麻奈就够了”。

## 9. 核心动态链
### 链A｜前代影子殖民链
`xz前代死亡 → z传奇历史 → x并z继承标签 → nx公众比较 → zn被侵蚀`

前代虽然不在场，却通过名字、声音、排名历史继续控制新人的社会解释。

### 链B｜继承资本反咬链
`前代标签 → 曝光/关注 → 职业机会 → 比较加剧 → 新人被固定成复制品`

原本帮助新人进入职业世界的资本，反过来限制新人生成自己的身份。

### 链C｜去影成名链
`zn冲突 → zx拒绝复制 → x提纯个人风格 → xn用新歌/比赛验证 → 新x并z成立`

樱明确宣布不再依赖麻奈的歌、要用Sunny Peace自己的歌登顶，是这一链最干净的正例。

### 链D｜共同体拆分增益链
`大n十人项目 → xn判断差异 → 拆成两个n → 每组x更清晰 → x并z品牌增强`

不是所有“团结”都要把所有人塞在同一组。拆分本身也可以强化共同体。

## 10. 反咬点
### 反咬1｜最像前代的人，反而最难成为自己
相似歌声、血缘、本领都是职业资本；资本越强，公众越不愿意重新认识新人。

### 反咬2｜继承是最快入口，也是最难脱身的身份牢笼
一开始：`前代名望 → 关注`。
后来：`关注 → 比较 → 复制品标签 → 本体压迫`。

### 反咬3｜想超越前代，就必须先停止复制前代
单纯把前代做到更像，不会产生新zn。真正突破发生在“我不用她的歌、我要用自己的组合与自己的歌到顶点”。

### 反咬4｜公司为了发挥个人差异而拆团，拆分反而生成更强团队本体
一个大团并不天然比两个分化团队更n。结构匹配比人数多更重要。

## 11. 视觉符号
- 已故顶级偶像的海报 / 排名记录：z历史压在新人头上。
- 妹妹站在姐姐旧舞台位置：zn继承压力。
- 两张相似歌声的波形 / 麦克风：能力相似导致身份误认。
- 旧曲谱被放下 → 新曲谱被拿起：去影成名。
- 十人宿舍 → 两组分站：n拆分。
- AI排名屏 / VENUS Program：xn把偶像价值量化。
- “麻奈再来”舆论标题：x并z公众标签。
- 决赛舞台两组对立又互相鼓励：竞争机器内部长出共同体。

## 12. 可复用母题
### ① 前代影子继承
传奇前辈已离场，新人却被迫在其名字里开始职业人生。

### ② 相似即侵蚀
你越像一个成功模板，越容易获得入口，也越容易失去自己的名字。

### ③ 继承资本反噬
血缘、作品、名号、技术、粉丝盘都能继承，但继承越多，新主体越难被独立承认。

### ④ 去影成名
真正的成长不是“达到前代水平”，而是让评价标准第一次必须用你的名字来描述。

### ⑤ 组织拆分生成身份
大团队中模糊的个体，通过重新分组获得更明确的功能、风格与品牌身份。

可迁移：
- 名画家之子成为画家。
- 传奇英雄妹妹进入英雄学院。
- 老国王私生子继承军队。
- 已故歌姬的替唱者成为歌手。
- 大师AI模型的继承模型试图摆脱“仿品”标签。

## 13. 与已有矿点差异
### vs《Aikatsu!》
Aikatsu是“榜样产生职业欲望”；IDOLY PRIDE是“榜样/前代已经变成评价标准，反过来殖民新人身份”。

### vs《ZOMBIE LAND SAGA》
ZLS是死者自己通过偶像身份获得第二社会人生；这里是**死者不再行动，但她的社会身份继续控制活人的职业道路**。

### vs《Phantom of the Idol / 神クズ☆アイドル》
Phantom是“两个主体共享一个偶像身体，劳动主体与公众署名错位”；这里是**不同身体的新偶像被公众强行塞进旧偶像模板**。

### vs《SELECTION PROJECT》
Selection Project重点是公众投票生产身份；本作虽也有比赛，但更核心的是**公众拿前代作为尺子，决定新人有没有独立身份**。

## 14. 矿级
**S矿。**

理由：
1. 完整覆盖audition→lesson→宿舍→分组→Debut Live→Live Battle→大奖赛→粉丝/舆论的偶像职业链。
2. 核心角色真正持续行动以成为更强偶像，而不是恋爱戏借偶像当布景。
3. 补出此前母库没有的“前代影子继承 / 继承资本反噬”机制。
4. zn、xn、x并z三层咬得非常紧，特别适合十元体系继续扩展。

## 15. 本轮矿核
> **继承一个传奇，最先得到的是入口；最后必须付出的，却是把那个传奇从自己身上剥下来。**
