# Love Live! / ラブライブ！｜S

## 基础核验
- 媒介：日本多媒体企划，核心分析以2013年TV动画第一期为主。
- 核心人物：高坂穗乃果、南小鸟、园田海未及后续μ's成员。
- 起点不是职业事务所招募，而是音乃木坂学院面临废校危机；穗乃果决定以“校园偶像”活动提升学校关注度、吸引报考者。
- 官方系列定义本身即为“通过在学校活动的校园偶像，描绘女高中生实现梦想”的项目；官方/日升资料也明确记载穗乃果“决定阻止音乃木坂废校”。
- 结论：属于非常纯的“普通学生 → 自建偶像组织 → 持续训练/招募/演出/竞争 → 偶像身份成立”样本。

## 本轮新增母型
**危机工具 → 自建职业身份型**。

普通“成为偶像”是：
愿望 → 进入已有公司/学校/节目 → 被制度加工。

Love Live! 更特别：
**先有要解决的外部危机，再由主角自己发明/选择“偶像”作为解决危机的工具；随后这个工具在持续实践中反过来成为真正的自我与共同体。**

一句话矿核：
> 我不是因为先想当偶像才组团，而是为了救某个更大的东西开始当偶像；但做着做着，“偶像”本身变成了不能随意丢弃的身份。

## 十元
- 主符号：zx——穗乃果主动提出“做校园偶像救学校”，发动整个职业链。
- 次符号1：n——μ's不是先存在的机构，而是一个人一个人拉出来的共同体。
- 次符号2：x并z——“普通学生”逐渐叠加“μ's成员 / 校园偶像 / 被公众观看者”的社会身份。
- 次符号3：xn——训练、排练、Live、Love Live!赛事、学校规章等把热情变成持续职业实践。
- 次符号4：nz——同伴、学生、观众与粉丝的支持，使工具性行动沉淀成真实归属。
- 暗层：xz——废校危机为整个故事提供无法忽视的命运压力。

## 体量
zx10 / n10 / x并z9 / xn9 / nz9 / xz8 / zn8 / x8 / nx6 / z7。

## 顺序链
**xz → zx → n → x并z → xn → nx → zx → nz → zn → 新x并z**

学校废校危机xz → 穗乃果主动提出校园偶像方案zx → 从3人开始组织n → “μ's / 校园偶像”公共身份x并z出现 → 训练、排练、演出、比赛xn把身份制度化 → 成员受到校方、能力、身体状态、观众反馈等nx限制 → 不断以zx修正并继续行动 → 粉丝与伙伴关系nz沉淀 → “我为什么还要继续做偶像”的zn本体问题浮现 → 即使原危机阶段性解除，μ's作为真实身份仍继续成立。

## 五维
- 时间维（xn+z）：9/10。偶像活动必须通过练习、招募、Live、比赛与学期推进积累，不存在一键成立。
- 本体维（zn+x）：9/10。最初“为了救学校”的工具性动机，逐渐转成“我自己为什么想继续站上舞台”。
- 空间维（x并z+n）：10/10。普通学生必须借由组合、学校、舞台、观众共同制造“校园偶像”社会位置。
- 因果维（zx+nx）：10/10。极强zx发动，同时不断受现实能力、成员意愿、规则与失败反馈限制。
- 命运维（xz+nz）：9/10。废校压力启动故事，但真正维持行动的是后续建立的成员/观众关系。

## 偶像身份如何建立
1. 普通学生，没有现成娱乐公司身份。
2. 把“校园偶像”当作救校传播方案。
3. 从小规模自发组织开始，先有行动，后有组织合法性。
4. 通过招募成员、排练、服装、歌曲、公开Live让社会身份逐渐可见。
5. 观众与学校开始承认μ's，外部承认反过来加固内部认同。
6. 进入Love Live!等更大的校园偶像竞争空间后，“自发活动”升级成完整偶像身份。

## 职业机制
### 训练
- 歌唱、舞蹈、体能、队形、排练持续出现。
- 技能不足不是设定一句话带过，而会直接影响舞台成立。

### 出道/首次公开
- 不是公司正式“出道发布”，而是先通过校内公开Live完成最初社会暴露。
- 因此它提供了一个不同于职业事务所的“低门槛自建出道”模型：先公开行动，再逐步获得承认。

### 竞争
- 后续进入校园偶像赛事与其他组合竞争。
- 竞争的功能不是单纯排名，而是迫使μ's回答“我们和别的偶像有什么不同”。

### 舞台
- 舞台是身份生成器：排练中的人仍只是“想当偶像的人”，真正站到观众面前后，x并z才被社会看见。

### 粉丝
- 粉丝/学生最初是“救校所需的人气资源”，之后转化为真实的nz支持关系。
- 这正构成反咬：原本把观众当结果指标，最后观众的情感反过来成为继续活动的理由。

### 公司/组织
- 没有传统经纪公司作为核心发动机。
- 学校、学生会、社团许可、成员自治共同代替“公司”。
- 这是本作最重要的结构差异：**偶像组织本身由主角群从零创建。**

## 主角欲望与代价
### 初始欲望
救学校，不想让熟悉的生活空间消失。

### 中期欲望
让μ's被更多人看见、让团队真正成立。

### 后期欲望
不再只是“为了学校”，而是自己也想与成员继续站在舞台上。

### 代价
- 时间：学业与高强度训练冲突。
- 身体：体能、疲劳、健康直接成为行动边界。
- 关系：招募与共同目标要求不断协调成员不同欲望。
- 本体：一旦“偶像”从工具变成自我，就不能在原任务完成后轻易退出。

## 关系结构
### 穗乃果 → μ's
zx发动者 → n组织形成。

### μ's成员 ↔ 成员
最初目标不完全一致，通过xn共同实践转成nz真实关系。

### μ's ↔ 学校
一开始：偶像是救校工具。
后来：学校也成为μ's身份来源与记忆载体。

### μ's ↔ 观众/粉丝
一开始：需要关注度。
后来：被观看、被记住、被支持成为偶像继续存在的理由。

## 动态链
### 链1｜危机生产职业
**xz学校危机 → zx提出偶像方案 → n组团 → x并z校园偶像身份**

重点：职业欲望并非先验存在，而是由解决危机的行动生成。

### 链2｜工具反咬主人
**偶像=救校工具 → xn长期实践 → nz成员/粉丝沉淀 → zn认领 → 偶像不再只是工具**

这是本轮最高价值链。

### 链3｜个人行动制造制度
**个人zx → 拉入n → 形成x并z组合 → 参加更大xn赛事/规则 → 原先的个人冲动被制度化**

### 链4｜外部目标完成后，内部目标继续
**外部危机减弱 → 原发动理由失效 → nz/zn开始接管驱动力 → 新zx继续舞台行动**

## 生链
1. xz危机生zx主动方案。
2. zx主动方案生n自建组织。
3. n共同体生x并z公共身份。
4. x并z公共身份生xn训练/赛事要求。
5. xn长期实践生nz关系沉淀。
6. nz关系反过来生zn“我真正想成为偶像”的自我认领。

## 克链
1. nx现实能力/规则克zx冲动：想做并不等于做得到。
2. xn训练要求克x普通学生状态：身体、技术必须被改造。
3. n成员差异克个人zx：一个人的冲动必须被团队协商。
4. zn后期自我问题克早期工具逻辑：当“救学校”不再足够，必须重新定义继续行动的理由。

## 反咬点
### 反咬1｜救学校的工具变成独立目标
最初逻辑：
**学校 > 偶像。**

长期实践后：
**学校危机 → 偶像活动 → 团队/粉丝/舞台经验 → 偶像本身获得价值。**

于是原目标完成并不会自动终止职业链。

### 反咬2｜为了制造关注而登台，最后被关注改变
最初粉丝只是“招生宣传所需的注意力”。
后来观众的期待与支持成为真实关系，公众不再只是数字。

### 反咬3｜自己创建的身份反过来约束自己
因为不是公司塞给她们的身份，所以最初退出成本看似很低；但越是自己创造、自己拉人、自己投入，退出时承担的责任反而越重。

## 视觉符号
- 校门 / 招生告示 / “学校要消失”的空间危机。
- 屋顶：普通学生空间逐渐被改造成练习/偶像空间。
- 训练服 → 舞台服：x普通状态向x并z公共身份的视觉切换。
- 空座位 → 有观众的舞台：身份承认度增长的最直观符号。
- 九人集合：n共同体完成。
- 学校制服 + 舞台服并置：学生/偶像双重身份。
- 海报、Live、比赛会场：私人愿望被公开社会化。

## 5组补子
- xn+z：练习、演出、比赛让一次冲动积累成长期职业活动。
- zn+x：普通学生的自我逐渐能够认领“我也是偶像”。
- x并z+n：μ's公共身份只能通过九人共同体、学校与舞台成立。
- zx+nx：强主动发动持续受到现实能力、制度与关系限制。
- xz+nz：废校危机启动行动，真实关系最终接替危机成为长期承载。

## 可复用母题
1. **救机构而自建职业**：学校要倒闭 → 学生自己造出偶像团；可迁移为村庄、剧团、神殿、骑士团、公司。
2. **工具身份真实化**：为了任务临时扮演某身份，长期实践后身份反过来成为本体。
3. **个人冲动组织化**：一人的zx不断拉人，最终生成n与x并z组织实体。
4. **任务完成后欲望续航**：外部目标结束，但关系与本体已生成新的行动理由。
5. **自建出道**：没有公司授予资格，先通过公开行动制造事实，再让社会承认身份。
6. **空间救援与身份生成同构**：想救“学校这个空间”，结果这个空间反过来成为偶像身份成立的根。

## 与已有S矿差异
- vs Wake Up, Girls!：WUG是濒死事务所先制造偶像团救组织；Love Live!是普通学生自己提出偶像方案并自建组织。前者更偏“组织→人”，本作更偏“人→组织”。
- vs Aikatsu!：Aikatsu!是被榜样点燃后主动进入已有偶像教育制度；本作先为外部危机行动，再自己创造职业入口。
- vs Dream High：Dream High由艺校制度加工偶像；本作前期几乎没有现成职业机构，制度是边做边生成的。
- vs SELECTION PROJECT：后者由公众投票裁决身份；本作首先靠自组织和实际公开舞台制造身份事实。

## 矿级
**S矿。**

S的理由不是历史影响力，而是它补出一条目前偶像生成谱系中非常独立的结构：

**xz外部危机 → zx自行发明职业方案 → n自建组织 → x并z公开身份 → xn长期实践 → nz关系沉淀 → zn真正认领 → 原工具目标被反咬。**

它尤其适合放进“从非偶像变成偶像”核心样本，因为角色并非一开始就以职业偶像为既定人生目标，而是在解决现实问题的过程中，亲手把偶像身份造出来。

## 本轮增量结论
新增正式分类：

### **自建职业 / 危机工具真实化型**

公式：
**xz危机 → zx发明解决方案 → n组人 → x并z临时公共身份 → xn持续实践 → nz真实关系 → zn身份认领 → 新zx自主继续。**

它与“公司招募型 / 制度加工型 / 公众裁决型 / 命运强迫型”不同：**职业入口本身就是主角亲手造出来的。**
