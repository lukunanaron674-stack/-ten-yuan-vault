# 日韩偶像题材｜日漫·韩漫

## 专题定义
只收“主角或核心角色真正进入偶像职业机制”的作品：练习生、选秀、出道、组合运营、舞台、公演、粉丝、公司、排名、再出道、毕业/退出。
不把普通娱乐圈恋爱、单纯明星恋爱、只出现偶像配角当核心偶像题材。

## 十元分析最低要求
每部至少记录：主符号 / 次符号 / 五维 / 体量 / 顺序链 / 生链 / 克链 / 反咬点 / 5组补子 / 偶像职业度 / 与已有样本差异 / 矿级。

## 母型谱系
### A. 必须成为偶像
1. 自保型：《Debut or Die!》——自己不出道，自己死。
2. 团体连坐型：《The Youngest Must Become an Idol》——自己退出，队友死。
3. 亲缘救援型：《Assistant Manager Kim Hates K-Pop Idols》——为了改写妹妹死亡，必须进入指定偶像团。
4. 惩罚改造型：《Back Street Girls》——现实权力者把偶像职业当惩罚，身体/公众身份被一起职业化。

### B. 再来一次当偶像
- 《Second Try Idol》：前台失败者→后台训练师→回到前台。
- 《My Comeback as the Youngest Member》：失败人生经验重新进入同一选秀机器。
- 《An Insincere Idol's Blank Slate》：不是争出道资格，而是夺回被长期错误经营磨掉的职业诚意。

### C. 换载体/本体错位
- 《The Holy Idol》：陌生灵魂继承现成偶像身体的社会身份。
- 《My Second Life as an Idol》：旧职业经验在新的身体/声音/社会资本中重新成功。
- 《Back Street Girls》：同一旧自我被迫把现实身体/外形职业化，新公众身份又因成功获得社会真实性。

### D. 幕后/外行业进入偶像
- 《The Rogue Producer Survives as an Idol》：制作人→偶像，懂规则的人变成规则对象。
- 《Feeding the Lives of Failing Idols》：企业经营/餐饮能力→失败偶像队长，重点是糊团经营与 comeback。
- 《Second Try Idol》：训练师经验回流前台。

### E. 职业资格与分类
- 《Wanna be a Star!》：能力没变，职业分类变了，价值随之改变。
- 《This Life's Universal Superstar》：职业分类没变，身体技能条件改变，关闭的职业入口重新打开。

### F. 公众身份反噬本体
- 《我推的孩子》：被观看的公众偶像身份与真实自我撕裂。
- 《Back Street Girls》：被迫身份如果成功，成功本身会成为新的牢笼。

## R08新增｜Back Street Girls｜日漫｜S
Kodansha 官方漫画，Complete，共12卷。三名黑道成员在强势老板控制下被迫彻底改造，以女性偶像三人组 Gokudols 出道；官方后续卷简介明确出现毕业、社媒涨粉、一天五场演唱会、姐妹团、海外拓展、最终演唱会与职业退出问题。

### 新母型
**惩罚性职业改造：被强迫进入的职业，因公众成功而反过来成为社会真实。**

### 十元摘要
- 主：x并z（被制造/被观看的Gokudols公众身份）
- 次：xn（老板与职业制度）+ zn（旧黑道自我）+ x（身体/外形职业化）
- 暗层：nx（职业起点与重大安排均被强制）
- 体量：x并z10 / xn10 / zn9 / nx9 / x9 / n8 / zx7 / xz7 / nz6 / z5
- 顺序：**xz → xn → x → x并z → nx → n → zn → zx → x并z**
- 核心循环：**被迫成为 → 被公众承认 → 因成功继续被要求成为。**
- 偶像职业度：10/10。

### 五维
- 时间 xn+z：演出、运营、毕业与退出形成长期职业时间。
- 本体 zn+x：旧自我与已职业化的现实身体/外形直接冲突。
- 空间 x并z+n：舞台、粉丝、社媒、姐妹团、海外市场把新身份社会化。
- 因果 zx+nx：在无法自由退出的框架里，只能有限主动求生与应付职业后果。
- 命运 xz+nz：惩罚/改造锁定命运，三人共同体与真实粉丝关系逐渐成为缓冲。

### 5组补子
- xn+z：强制职业制度 + 想保留旧人生/获得自由的欲望。
- zn+x：原黑道自我 + 已职业化身体/外形。
- x并z+n：公众偶像包装 + 粉丝/舞台/社媒/姐妹团/海外市场。
- zx+nx：职业内部主动应付 + 外部强制控制。
- xz+nz：惩罚性改造 + 团体/粉丝关系。

### 反咬点
**最强反咬不是被迫当偶像，而是被迫当的偶像真的成功了。**
如果公众不相信，身份只是外部强迫；一旦粉丝、舞台和市场持续承认Gokudols，社会开始反过来证明“你就是偶像”，假职业获得比旧身份更强的现实性。

### 与已有样本差异
- vs《Debut or Die!》：超自然死亡条件 vs 现实权力惩罚 + 身体职业化 + 社会成功反锁身份。
- vs《The Holy Idol》：陌生灵魂继承现成偶像身体 vs 同一旧自我被迫制造一个此前不存在的新偶像载体。
- vs《AKB49》：主动策略性跨身份进入制度 vs 从起点就是强制，而且成功会反向锁死退出。
- vs《Wanna be a Star!》：主动换职业分类寻求承认 vs 被强制换类，成功本身继续固定被迫身份。
