# 日韩偶像题材｜日漫·韩漫

## 专题定义
只收“主角或核心角色真正进入偶像职业机制”的作品：练习生、选秀、出道、组合运营、舞台、公演、粉丝、公司、排名、再出道。
不把普通娱乐圈恋爱、单纯明星恋爱、只出现偶像配角当核心偶像题材。

## 十元分析重点
每部至少记录：主符号/次符号、五维、生链、克链、5组补子、偶像职业度0-10、矿级。

## 新增深拆｜From Acting Genius To Top Idol!｜韩漫/Webtoon｜S
官方 Tapas：Paik Hyeon 原是顶级演员，飞机事故濒死后回到年轻时期；第二次生命并非免费，他若想重新成为演员，必须先成为成功的 K-pop 偶像。官方简介明确把 fierce competition、demanding schedules、fake smiles 写成职业障碍。截至核验时 Tapas 页面列 93 话并处于 hiatus。

### 核心机制
这不是“演员顺便做偶像”，而是“旧职业目标必须穿过一个自己原本不需要的职业身份才能重新成立”。偶像身份既是生存门槛，也是返回演员身份的中间态。

### 十元
- 主符号：xz（第二次生命附带成功偶像的命运条件）
- 次符号1：xn（回归时间、寿命/职业路径、严苛日程）
- 次符号2：zx（把演员能力主动迁移到偶像竞争）
- 第三层：x并z（舞台营业、公众形象、fake smiles）
- 暗层：zn（“我是演员”与“我必须成为偶像”的本体冲突）

### 五维
- 命运 xz+nz：活下去/重返原人生目标被偶像成功条件锁定；新团体关系成为命运缓冲。
- 时间 xn+z：回到年轻时期并受有限时间约束，旧演员执念持续推动执行。
- 因果 zx+nx：主角主动迁移演技优势，但必须服从偶像行业的训练、竞争和日程。
- 空间 x并z+n：舞台、镜头、营业表情把一个演员重新包装成可被观看的偶像。
- 本体 zn+x：旧“演员自我”与现实中的“偶像身份”必须重新缝合。

### 生链
xz第二生命条件 → xn职业路径限制 → zx能力迁移/主动竞争 → x并z偶像公众身份成立 → zn旧演员自我被迫重写。

### 克链
1. xz克zn：主角不能只按“我是演员”行动，生存条件强迫职业改道。
2. xn克zx：再强的个人能力也必须通过训练、日程与行业程序兑现。
3. zx克nx：演员经验让他从被迫当偶像转为主动利用表演能力争位置。
4. x并z克zn：营业表情和公众偶像身份越成功，越可能覆盖他原本只认领的演员身份。

### 5组补子
- xn+z：时间/职业规则 + 重返演员道路的执念。
- zn+x：演员自我 + 现实偶像身体与职业位置。
- x并z+n：公众偶像包装 + 舞台/镜头/粉丝观看空间。
- zx+nx：主动迁移能力 + 被行业规则与日程安排。
- xz+nz：强制职业命运 + 新团体关系/共同成长缓冲。

### 偶像职业度
9.5/10。官方直接定义“必须先成为成功 K-pop 偶像”，并明确竞争、严苛日程、营业表情等职业机制。扣0.5是因为深层终点仍保留“重新成为演员”的外部目标。

### 反咬点
最有价值的不是“演员技能让偶像开挂”，而是：为了重新成为原来的自己，他必须先把另一个职业身份做得足够真实。若偶像身份最终比旧演员身份更能被现实承认，手段会反过来改写目的。

### 可复用母题
**“把不想成为的职业做到成功，才有资格回到真正想成为的人。”**
动态链：zn旧职业自我 → xz强制改道 → xn新职业规则 → nx被迫适应 → zx旧技能迁移 → x并z新身份成立 → 新身份反咬zn。

### 矿级
S。它补充的是“职业中间态反客为主”母型，与 Debut or Die! 的死亡强制出道、Rogue Producer 的幕后转前台、Assistant Manager Kim 的救亲人强制出道均不同。

- Tapas 官方作品页：https://tapas.io/series/from-acting-genius-to-top-idol/info
- 韩国 Webtoon Guide 对韩文原作/漫画发行信息的交叉核验。

## R04新增｜Wanna be a Star!｜韩漫｜A+
官方 Tappytoon 授权漫画，Completed。Soh 原是大型娱乐公司练习生，但成长后声音低哑、体格变宽，在女团路线中逐渐失去位置；她放弃后得知男团正在公开招募新成员，于是借双胞胎兄弟证件，以偏中性的外形与声音参加现场 audition。

### 新母型
**“不是能力失败，而是被放进了错误的职业分类。”**
同一份声音/身体条件在女偶像分类中被判成缺点，切换到男偶像分类后重新变成职业资产。

### 十元
- 主：x并z（性别化公众偶像包装）
- 次：zn（真实职业自我）+ xn（公司/练习生/团体/audition制度）+ zx（主动切换职业入口）
- 暗层：x（现实身体与声音）
- 体量：x并z10 / zn9 / xn9 / zx8 / x8 / nx7 / z7 / n6 / nz5 / xz4

### 五维
- 时间 xn+z：长期练习与成长中的身体变化持续消耗、重燃执念。
- 本体 zn+x：职业自我与现实身体如何被行业读取发生冲突。
- 空间 x并z+n：女团/男团是两套不同的被观看空间。
- 因果 zx+nx：从被公司分类筛选转为主动换入口竞争。
- 命运 xz+nz：硬命运弱，更多依赖偶像榜样和团体关系提供路径牵引。

### 顺序链
**zn → xn → x → nx → zx → x并z → zn**

### 生链
**x现实条件 → xn分类规则 → x并z新包装可能性 → zx主动换入口 → zn职业自我重新成立。**

### 克链
1. xn克zn：想当偶像不代表制度承认当前分类中的你。
2. x克旧x并z：成长后的声音与体格破坏旧女偶像包装匹配。
3. zx克nx：主动参加另一类别 audition，摆脱单向等待筛选。
4. 新x并z反克旧xn判断：同样身体进入另一职业分类后，缺点可能变资产。

### 反咬点
**越靠“假身份”得到真实职业认可，越会暴露一个更狠的问题：系统认可的是她本人，还是被正确分类后的她？**

### 5组补子
- xn+z：公司/练习/audition规则 + 唱歌执念。
- zn+x：真实职业自我 + 身体/声音条件。
- x并z+n：男/女偶像包装 + 团体/舞台关系场。
- zx+nx：主动换身份参赛 + 前期被制度筛选。
- xz+nz：硬命运弱，以偶像榜样/团体关系作路径牵引。

### 与已有样本差异
与《AKB49》构成镜像，但不重复矿点：《AKB49》偏“男性进入女性偶像制度并维持秘密身份”；本作是**女性练习生已经在制度内部，却因身体/声音与女性偶像分类错位，转入男性偶像入口求职业生存**。核心不是“变装”，而是“分类如何制造职业失败”。
