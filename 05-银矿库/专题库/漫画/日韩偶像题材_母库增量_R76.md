# 日韩偶像题材_母库增量_R76

## 《Waccha PriMagi! / ワッチャプリマジ！》

- 媒介：日本原创TV动画 / 偶像多媒体企划
- 核心类型：从非偶像到偶像 / 搭档共演型 / 双主体职业生成
- 矿级：S
- 本轮新增母型：**搭档共演 / 双主体能力合成型**

## 1. 偶像身份如何建立

阳比野まつり原本只是憧憬PriMagi的普通中学生。她一直希望有一天能参加PriMagi，但真正的职业入口不是单人报名，而是魔法使みゃむ突然出现并邀请她进入这一世界。官方设定把PriMagi定义为由歌、舞蹈、时尚与真正的魔法共同组成的娱乐形式；官方角色资料也明确把みゃむ、チムム、きゃろん、ぱたの等定义为各自PriMagista的“伙伴魔法使”。

因此这里的职业身份不是单人生成：

**人类表演者A + 魔法伙伴B + PriMagi制度xn → 完整职业主体C**

A和B都不是单独意义上的完整职业单位，二者的协作本身才是舞台能力的一部分。

## 2. 十元定位与体量

| 十元 | 体量 | 功能 |
|---|---:|---|
| n | 10 | 人类与魔法伙伴的长期耦合，是能力和职业身份的基础 |
| x并z | 10 | PriMagista不是单纯个人标签，而是搭档关系被社会识别后的公共身份 |
| xn | 10 | PriMagi舞台、赛事、训练、魔法规则持续加工二人 |
| zx | 9 | まつり从“憧憬但不敢迈出一步”转成主动参赛和挑战 |
| nz | 9 | 搭档信任、竞争者、观众回应不断给职业行动赋义 |
| x | 9 | 歌舞、身体、时尚与魔法协作后显影为有效能力 |
| nx | 9 | 搭档冲突、赛事规则、顶级对手与职业标准反压 |
| zn | 9 | “我的舞台是我一个人的，还是我们两个人共同完成的”成为本体问题 |
| z | 8 | 一场场比赛和共同经历将偶然组队压成职业历史 |
| xz | 7 | 魔法世界与Grand Festival等高位规则带有命运压力 |

**主元：n + x并z + xn**

## 3. 顺序

**nz憧憬 → nx被搭档邀请 → zx迈出第一步 → n搭档成立 → x并z候选PriMagista → xn训练/比赛 → x共同能力显影 → nx搭档裂缝/赛事反压 → zx重新选择彼此 → nz观众/伙伴回流 → 新x并z职业身份实化 → zn回写**

## 4. 五维

- 时间维 xn+z：10/10
  - 第一场PriMagi只是偶然入口，之后持续训练、比赛、Grand Festival与反复磨合才形成职业历史。
- 本体维 zn+x：10/10
  - 能力不是“我的能力”这么简单，而要追问哪些部分来自自己、哪些来自搭档，以及共同完成的成果究竟属于谁。
- 空间维 x并z+n：10/10
  - 人类世界、魔法世界、PriMagi舞台与搭档关系共同构成职业空间。
- 因果维 zx+nx：10/10
  - まつり主动追梦，但搭档、规则、强敌不断反向规定她能怎么继续。
- 命运维 xz+nz：9/10
  - 魔法规则提供超常入口，但真正让职业成立的是搭档关系与持续选择。

## 5. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 训练
- 人类表演者必须训练歌舞、身体与舞台表现。
- 搭档魔法使也需要学习如何支持、判断和配合人类表演者。
- 所以训练单位不是“一个人升级”，而是**两个人同步校准**。

### 出道 / 初次职业成立
- まつり并不是第一话就完全主动，她想参加却缺最后一步；みゃむ的招募将愿望变成真实入口。
- 初舞台成功后，她在第二话明确决定继续PriMagi，完成从外部推动到自身zx的转换。

### 竞争
- 有强校、前辈、现役顶级PriMagista与大型赛事。
- 竞争不只检验个人实力，还直接检验搭档协同质量。

### 舞台
- PriMagi是歌、舞蹈、时尚和魔法共同生成的舞台。
- 因此“魔法伙伴”不是经纪人或辅助角色，而是职业输出链的组成部分。

### 粉丝 / 观众
- 观众承认把一次共演压成社会身份。
- 观众看到的是完整舞台C，而未必能拆清A和B分别贡献多少。

### 公司 / 制度
- PriMagi执行委员会、赛事和舞台规则承担xn。
- 制度承认的不是单一能力，而是“能否作为PriMagi搭档持续产出完整舞台”。

## 6. 主角欲望与代价

### 欲望
- 初始：我想参加自己一直憧憬的PriMagi。
- 中期：我想赢过更强的对手。
- 后期：我想和这个具体的伙伴一起完成属于我们的PriMagi。

### 代价
- 必须把原本属于个人的职业欲望，部分交给一段关系共同承担。
- 搭档状态会直接影响自己的职业结果。
- 越成功，越不能随意把关系视为可替换部件。

## 7. 关系结构

**まつり ↔ みゃむ**不是传统“偶像 ↔ 经纪人”。

更接近：

**主体A + 主体B → 共同行动单位C**

并且C会反过来约束A、B。

其他PriMagista也具有对应魔法伙伴，因此整个职业制度默认“人类主体 + 魔法主体”双人协同。

## 8. 动态链

### 链1｜双主体职业生成
**A个人欲望 → B伙伴介入 → n成立 → xn共同实践 → x共同输出 → x并z职业身份C成立**

### 链2｜关系故障直接变成职业故障
**n失衡 → x有效调用下降 → 舞台结果受损 → nx压力增强 → zn怀疑 → zx重新协调 → n升级**

### 链3｜共同成功反锁双方
**共同成功 → z共同履历 → nz观众/伙伴承认 → x并z双人身份增强 → 单人退出成本提高**

## 9. 反咬点

### 反咬1｜伙伴既是增益，也是单点故障
职业结构越依赖搭档，搭档越能放大能力；但一旦关系失衡，同一关系也会成为职业系统最脆弱的位置。

**n增益↑ → 共同输出↑ → n依赖↑ → n故障代价↑**

### 反咬2｜共同成果越成功，越难回答“这是谁的能力”
舞台是两人共同制造的。社会只看最终结果，因此个人能力产权会逐渐模糊：

**共同x → 公众x并z → zn所有权问题**

### 反咬3｜搭档不能只做可替换工具
如果B只是“装备”，职业系统很容易写成外挂。但作品反复赋予魔法伙伴独立欲望、情绪、竞争和选择，因此：

**把伙伴当工具 → n恶化 → x下降 → 职业结果反噬**

真正高阶的职业化要求承认伙伴本身也是主体。

### 反咬4｜第一层主动性可以来自别人，第二层必须由自己生成
第一话是みゃむ把まつり推进去；第二话以后まつり才明确决定继续。

因此：

**他人zx / nx提供入口 ≠ 主体zx永久成立**

必须经由真实实践后重新认领。

## 10. 视觉符号

- 普通中学生服装 → PriMagi舞台服
- まつり与みゃむ并列 / 牵引 / 同方向动作
- 人类舞步 + 魔法特效同时显现
- 双人争执时舞台光效或协作失衡
- 搭档重新对视 / 握手 / 同步动作后舞台恢复
- 两个世界的入口、Prism Stone店铺、赛事舞台
- 顶级PriMagista与新人搭档的高低位对照

视觉核：

**一个人的舞台画面，背后其实一直站着第二主体。**

## 11. 本轮新增可复用母题

### ① 双主体能力合成
单个人都不完整，职业成果必须由两个主体同时完成。

可迁移：
- 骑士 + 契约兽
- 歌手 + 实时AI声场伙伴
- 驾驶员 + 有人格机体
- 魔法师 + 精灵
- 主播 + 独立人格虚拟角色

### ② 伙伴即职业基础设施
伙伴不是情感附件，而是能力调用条件。

### ③ 关系故障即职业故障
关系冲突不只伤感情，而会直接降低职业输出。

### ④ 共同成果的能力产权
A和B共同制造的作品、战果、舞台，社会究竟应该算谁的能力。

### ⑤ 依赖越高，退出成本越高
强关系提高职业上限，也同步制造职业脆弱性。

### ⑥ 双主体同步成长
成熟职业弧不是A变强、B原地不动，而是双方都必须升级合作方式。

## 12. 与已有矿的边界

- 《Aikatsu Friends!》R56：两个偶像主体共同生成第三个“搭档品牌身份”，重点是**关系生成第三社会主体**。
- 《IDOLiSH7》R32：多人能力互补，重点是**团队配置价值高于个人排名**。
- 《Lapis Re:LiGHTs》R41：歌舞能力与魔法职业融合，重点是**副领域进入主职业定义**。
- 《Waccha PriMagi!》R76：**职业输出从制度设计上就需要两个异质主体共同完成，伙伴既是关系主体，也是能力系统的一部分。**

## 13. 本轮矿核

> **有些职业关系不是“有人支持我，所以我表现得更好”，而是没有这个具体的第二主体，完整的职业行为本身就无法成立。此时n已经不只是情感连接，而成为能力结构；关系越强，职业上限越高，但关系一旦故障，职业系统也会一起故障。真正的成长因此不是学会独自完成一切，而是把“我会什么”升级成“我们怎样才能共同稳定地做到”。**
