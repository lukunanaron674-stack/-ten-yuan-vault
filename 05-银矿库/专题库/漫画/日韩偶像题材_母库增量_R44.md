# 日韩偶像题材母库增量 R44

## 《Macross Δ / マクロスΔ》｜日本原创TV动画｜S矿

### 新分类
# 公共功能舞台 / 高风险职业化型

## 入库理由

芙蕾雅·维恩原本只是来自银河边境、喜欢唱歌并憧憬 Walküre 的少女。官方设定明确，她为了参加 Walküre 的选拔主动离开故乡；Walküre 则被官方定义为“战术音乐组合”，歌声在故事世界中不仅承担娱乐与舞台表达，还具有镇静 Vár 症候群、支援公共任务的实际作用。

因此本作的偶像成长不是贴皮：普通少女→候选者→组合成员→承担公共结果的职业歌者，身份生成完整。

## 核心母型

> 喜欢唱歌 → 憧憬职业榜样 → 主动离乡参加选拔 → 进入高风险公共职能组合 → 舞台行为产生真实社会结果 → 职业身份与责任绑定。

普通偶像舞台失败常对应排名、销量、出道机会；本作把舞台结果升级成公共任务是否成功，因此“唱歌”从私人表达转化成必须承担结果的职业行为。

| z | 9 | 故乡、过去、种族与历史持续回流 |
| xz | 9 | 宏观冲突与生命期限压力 |

主元：zx + xn + x并z
次元：n + xz

## 顺序

**nz → zx → x并z → xn → n → nx → xz → zn → 新zx → 新x并z**

1. nz：先憧憬 Walküre。
2. zx：主动离开故乡参加选拔。
3. x并z：获得候选/成员公共身份。
4. xn：接受专业组合与任务规则。
5. n：与成员和协作单位形成关系。
6. nx：职业责任反压个人欲望。
7. xz：宏观冲突和生命风险提高代价。
8. zn：从“我想唱”转向“我的歌为什么必须存在”。
9. 新zx：知道代价后仍继续选择舞台。
10. 新x并z：真正成为承担公共结果的职业歌者。

## 五维

- 时间维 xn+z：10/10。持续训练、任务与历史回流把偶然加入压成职业履历。
- 本体维 zn+x：10/10。核心从“我会唱”升级到“我的能力对别人意味着什么”。
- 空间维 x并z+n：10/10。私人少女进入组合、组织与公众空间，社会位置持续扩张。
- 因果维 zx+nx：10/10。主动追梦进入职业后被责任反推，再生成第二次主动选择。
- 命运维 xz+nz：10/10。宏观命运压力与伙伴、公众关系共同争夺未来。

## 行业机制

### 训练
不是单纯唱跳，而是歌唱稳定、声部协同、在高压环境持续发挥，以及与协作单位保持节奏。

### 出道
真正的身份认证不是一次商业发布，而是被允许以 Walküre 成员身份承担真实任务。

### 竞争
竞争重心从“同行排名”转为“能否完成公共功能”，个人表现必须服从整体结果。

### 舞台
舞台不再是与现实后果隔离的安全空间，而是直接与公共事件重合。

### 粉丝
粉丝机制由普通支持 nz 升级为公共信任 nz：人们不仅喜欢组合，还相信她们的歌能在危机中发挥作用。

### 公司/组织
事务所功能被扩大为训练、调度、协作、风险分配与公共任务管理。

## 主角欲望与代价

初始欲望：我喜欢 Walküre，我想加入，我想唱歌。

职业化后：我不只想唱，我必须让歌真正起作用。

代价包括离开故乡、持续高压任务、承担团队责任、私人情绪受职业要求限制，以及生命时间本身进入职业成本。

## 关系结构

- 芙蕾雅 ↔ Walküre：粉丝/偶像 → 候选者/前辈 → 同队成员，是 nz→n 的完整转化。
- 芙蕾雅 ↔ 协作单位：表演者与保护/支援者互相依存，属于高强度互补 n。
- 芙蕾雅 ↔ 公众：被观看者同时成为被公众依赖的人。
- 芙蕾雅 ↔ 故乡：过去的 z 与当前职业 x并z 持续冲突。

## 动态链

### A. 憧憬升级为公共责任
**nz憧憬 → zx追梦 → xn训练 → x并z职业化 → nx责任压迫 → n共同体 → 新zx承担**

### B. 可见性反咬
**舞台曝光 → x并z增强 → 公共功能增强 → 外部压力同步提高 → nx增加 → zx仍选择登台**

结论：被看见不只是奖励，也会提高职业风险与责任。

### C. 私人能力公共化
**x歌声 → nz影响他人 → xn制度化使用 → 产生公共结果 → zn所有权冲突**

一个人的天赋一旦被证明能帮助很多人，就很难继续只被理解成私人兴趣。

### D. 第二次主动选择
**xz高代价 → nx退出诱因 → zn重新估值 → n/nz意义回填 → zx主动继续 → 新zn**

## 反咬点

### 1. 最自由的表达，变成最严格的职责
唱歌起初是最个人的快乐；职业化后变成任务、结果和责任。

### 2. 越成功，越无法只为自己决定
能力越被社会证明有用，公众期待越强，个人自由反而受到更强 nx 约束。

### 3. 团队既保护主体，也绑定主体
n 越强，成员越安全；但队友越依赖你，退出成本也越高。

### 4. 被看见同时生成价值与压力
**x并z可见性↑ → nz支持↑，同时 nx责任↑。**

## 视觉符号

- 乡下少女服装 → Walküre舞台服
- audition场地 → 公共任务舞台
- 聚光灯 ↔ 高风险警示光
- 五人并列歌唱 ↔ 协作单位编队
- 麦克风/耳麦 ↔ 专业通讯装备
- 观众应援光 ↔ 任务区域信号光
- 歌声波纹 ↔ 公共状态变化
- 故乡苹果/传统意象 ↔ 现代职业服装

最强视觉对子：

> **聚光灯 = 风险标记。**

最被看见的人，也承担最高的公共责任。

## 可复用母题

1. **公共功能偶像**：娱乐能力同时承担治疗、安抚、公共服务等现实功能。
2. **天赋公共化**：私人才能被证明有公共价值后，社会开始要求主体持续提供。
3. **舞台高风险化**：职业曝光越大，风险同步增大。
4. **兴趣责任化**：我喜欢做 → 我擅长做 → 大家需要我做 → 我必须决定是否承担。
5. **粉丝信任升级**：喜欢从消费关系升级为公共信任。
6. **团队保护/绑定双重性**：n 同时降低风险与提高退出成本。
7. **第二次主动选择**：真正高体量的 zx，是知道代价后仍主动继续。

## 与已有样本边界

### vs R41《Lapis Re:LiGHTs》
R41 是为了保住魔女职业而借入舞台能力，最后舞台能力进入魔女定义；R44 是歌唱职业本身已经拥有公共职能，核心是责任化与高风险化。

### vs R29《Extreme Hearts》
R29 是在B领域取得成绩以换回A领域舞台；R44 中舞台与公共任务本身重合，不需要兑换。

### vs R30《Pretty Rhythm》
R30 强调复合职业技能补完；R44 强调个人表达被社会功能化后，职业责任反过来重写本体。
