# 日韩偶像题材｜母库增量 R12

## SHINEPOST / シャインポスト｜日漫｜S

### 官方核验

- 第1卷官方简介：弱小偶像组合 TiNgS 的春、杏夏、理王长期没有起色，事务所为其安排“最强经理人”日生直辉，并突然告知“解散条件”。
- 第2卷官方简介把条件明确为：**Sunshine City 喷水广场 Live 无法满员，则 TiNgS 解散。**
- カドコミ官方漫画页确认漫画化、TiNgS、经理人与解散条件。

### 核心机制
这不是“还没成为偶像”的故事，而是：
**已经进入偶像职业 → 事务所把继续存在的资格设为可撤销 → 团体必须用指定Live的市场结果证明自己值得继续作为偶像存在。**

新母型：**职业存续资格 / 解散阈值型**。

### 十元
- 主符号：**xn**——事务所规则、经理人制度、明确解散条件、指定舞台指标。
- 次符号1：**xz**——“解散”作为硬失败命运。
- 次符号2：**nz**——成员共同体、成员与经理人的关系是承载压力的核心结构。
- 次符号3：**zx**——训练、调整、舞台行动、争取观众。
- 第三层：**x并z + n**——TiNgS作为公众偶像身份，必须在舞台与观众场中被验证。
- 暗层：**zn**——当职业存续被量化，“我们为什么是偶像”会被指标重新定义。

### 体量
xn10 / xz9 / nz9 / zx8 / x并z8 / n8 / z7 / zn7 / nx6 / x5。

### 顺序链
**z → xz → xn → nx → nz → zx → x并z → n → zn**

梦想z原本只是想成为更耀眼的偶像；解散威胁xz把梦想变成职业生存；事务所用xn把威胁量化成指定Live满员；成员先落入被条件规定的nx；再靠团体与经理人nz重新组织；发动zx训练与舞台行动；形成更强的x并z公众身份；由观众n给予现实承认；最后逼出zn：我们是因为梦想成为偶像，还是因为达标后才被允许继续成为偶像？

### 五维
- 时间：**xn+z**——梦想被压入阶段性职业目标与期限。
- 本体：**zn+x**——偶像本体必须依托成员真实能力，同时不断回答“凭什么继续成立”。
- 空间：**x并z+n**——Live会场、舞台、观众席是公众身份被验证的空间。
- 因果：**zx+nx**——先被事务所条件安排，再通过主动训练与演出改变结果。
- 命运：**xz+nz**——解散是团体命运威胁，成员共同体与经理人关系提供对抗力量。

### 生链
1. **xz → xn**：解散威胁催生明确可执行的职业条件。
2. **xn → nz**：硬指标迫使成员与经理人重新组织协作。
3. **nz → zx**：共同体稳定后产生主动训练与舞台行动。
4. **zx → x并z**：职业行动塑造TiNgS的公众偶像身份。
5. **x并z → n**：公众身份再转化为观众与市场承认。

### 克链
1. **xz 克 z**：解散风险把自由梦想压成“先活下来”。
2. **xn 克 zx**：主动性先被事务所设定的目标框住。
3. **nx 克 zn**：若只按条件行动，偶像本体会退化成“有没有达标”。
4. **nz 反克 nx**：成员与经理人关系把被动考核重组为共同选择。
5. **zx 反克 xz**：只有主动职业行动才能反转解散命运。

### 反咬点
**最强反咬不是解散，而是“成功后，职业价值被量化逻辑进一步合法化”。**

如果这次靠“满场”证明自己值得继续存在，那么下一次系统就更有理由用销量、曝光、Live规模等新指标继续定义她们是否配当偶像。

循环：
**xz解散威胁 → xn量化条件 → zx行动 → x并z/n市场验证 → 更强xn。**

### 5组补子
- **xn+z**：梦想必须进入事务所规则、阶段目标与期限，才能获得职业持续性。
- **zn+x**：偶像本体依赖成员真实能力与身体/性格差异，不能只靠抽象品牌。
- **x并z+n**：偶像包装必须在舞台、Live与观众关系网中得到验证。
- **zx+nx**：成员既被解散条件安排，又必须主动训练和经营改变结果。
- **xz+nz**：团体解散命运由成员共同体承担，关系既是风险载体也是抵抗力量。

### 偶像职业机制
- 练习：强。
- 事务所：极强，直接提出存续条件并配置经理人。
- 经理人：极强，是职业能力转化接口。
- 团体：极强，TiNgS整体接受解散判定。
- 舞台/Live：极强，指定Live满员直接决定存续。
- 粉丝/观众：强，人数成为职业资格验证。
- 排名/选秀：非主机制。
- 毕业/退出：以“团体解散”形式成为硬失败条件。
- 偶像职业度：**10/10**。

### 欲望与代价
- 表层欲望：保住TiNgS，并继续向“绝对偶像”前进。
- 深层欲望：证明自己的职业存在不是事务所可以随时撤销的失败项目。
- 成功代价：一旦接受“外部指标证明职业价值”，未来会被更深地量化。
- 失败代价：不是一次演出失败，而是**团体职业身份整体被制度取消**。

### 与已有样本差异
- 对《Feeding the Lives of Failing Idols》：后者是外行业经营者进入失败偶像团队，用经营能力做 comeback；本作是**原成员不换身份，由外部经理人和事务所硬指标迫使既有女团证明存续资格**。
- 对《U149》：U149是边缘单位长期积累职业资本；本作是**明确阈值考核下的短期存亡战**。
- 对《Debut or Die!》：前者是“个人不出道就死”；本作是“组合已经出道，但不能证明市场价值就整体消失”。

### 视觉符号
指定Live会场 / 空席与满席 / 舞台聚光灯 / 事务所会议 / 解散通知 / 经理人与成员站位 / 观众人数 / 团体合照。

### 可复用母题
**职业存续资格型：已经进入职业，并不意味着职业身份永久成立；系统会不断要求你用外部指标证明自己值得继续存在。**

可迁移到偶像团、创作团队、体育队、公司部门、学术项目等“可被绩效撤销存在资格”的共同体。

### 矿级
**S**。

理由：填补母库此前缺少的“已出道 → 被制度要求再次证明存续资格”结构。不是重生、换身体、粉丝入场或单纯长期运营，而是**职业身份本身被设成一张可撤销许可证**。

## R12结论
真正新增的理论差异：
- 《Debut or Die!》：没成为偶像前，职业资格就是生死门槛。
- 《SHINEPOST》：已经成为偶像后，职业资格仍会被制度重新审查并撤销。

因此“成为偶像”不是一次完成的状态，而可能是一张需要持续续签的许可证。
