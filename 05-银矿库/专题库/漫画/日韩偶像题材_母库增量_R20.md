# 日韩偶像题材母库增量 R20

## 新增样本：《PriPara / プリパラ / 美妙天堂》
- 媒介：日本原创TV动画 / 偶像多媒体企划
- 核心研究对象：真中啦啦（真中らぁら）
- 矿级：S
- 新增母型：**禁止身份 / 双重空间职业化型**
- 去重说明：仓库检索未发现《PriPara / プリパラ》独立十元样本；R19已有《Idol Shikkaku》《SELECTION PROJECT》，故本轮另建R20，避免覆盖。

## 1. 为什么进入核心样本
《PriPara》的核心不是普通娱乐圈恋爱，而是非常纯粹的“普通学生如何持续成为偶像”。官方设定中，PriPara 是每天举行歌舞与时尚选拔、通过电视和网络向世界传播的偶像主题空间；持有 PriTicket 的女孩可以进入并参加舞台竞争。主人公啦啦本来只是小学五年级学生，憧憬 PriPara，却受学校规则限制，小学生被禁止参加。她因偶然事件进入 PriPara，并直接卷入试镜舞台，由此开始偶像生涯。

核心矿：
> **现实制度禁止一个身份，另一套空间制度却允许同一个人生成第二职业身份。**

因此偶像成长不只发生在技能层，而发生在“两个规则空间争夺同一主体”的结构里。

## 2. 偶像身份如何建立
- 现实初始身份：普通小学女生 / 学生。
- 职业资格：无。
- 欲望：对偶像世界有明确憧憬，但现实学校规则压制入口。
- 身份入口：获得 PriTicket，进入 PriPara。
- 身份成立：进入专属空间 → 接受空间规则 → 登台 → 被观看 → 反复参加活动 → 形成队伍 → 获得粉丝 → 偶像身份稳定化。

这是一种非常纯的 **x并z 身份空间生成**。

## 3. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制
### 训练
与队友共同练习歌舞与舞台表现。早期啦啦无法完全满足みれぃ的严格要求，明确表现“普通人进入职业规则后的能力落差”。

### 出道
第一次偶然进入后即被卷入试镜 Live。“出道”并非传统公司签约，而是第一次被偶像系统公开承认。

### 竞争
PriPara 持续举行 audition live / 各类竞赛。竞争对象既是其他偶像，也是排行、资格、团队完整性与规则更新。

### 舞台
舞台是身份认证场，不只是表演奖励。现实中的啦啦只是学生；舞台上的啦啦才被公众看作偶像。

### 粉丝
粉丝提供 nz 的依恋与回应，也强化 x并z 的公众身份。第一批粉丝尤其重要，因为它证明“偶像身份不只存在于系统里，也存在于他人心里”。

### 公司 / 制度
本作关键不是传统经纪公司，而是 PriPara 这个整体制度空间。它同时承担：入口、服装、舞台、评选、观看、身份等级、组合规则。

因此“公司机制”被扩展为 **平台制度机制**。

## 4. 主角欲望与代价
### 欲望
1. 想进入自己憧憬的偶像世界。
2. 想和伙伴继续登台。
3. 想遵守和伙伴的约定。
4. 后期从“想进去看看”成长为“我要作为偶像继续行动”。

### 代价
1. 与现实学校规则冲突。
2. 需要切割现实身份与偶像身份。
3. 必须接受训练和舞台评价。
4. 进入团队后，个人自由受到组合关系约束。
5. 越成功，第二身份越难再被当成游戏或临时体验。

核心代价：
> **第二身份越真实，两个生活空间之间的冲突越大。**

# 5. 十元分析
## 主元
- 主元：**x并z**
- 次元：**xn**
- 强冲突：**nx ↔ zx**
- 本体回收：**zn**

本作不是 zn 默认起手。第一推动来自外部空间资格与制度冲突，因此应从 x并z / nx 读起。

## 体量
| 十元 | 体量 | 作用 |
|---|---:|---|
| x并z | 10 | 现实学生 / PriPara偶像双身份、两个社会空间 |
| xn | 10 | 入场券、试镜、团队、舞台、排名与系统规则 |
| zx | 9 | 主角从偶然进入转为主动继续登台 |
| n | 9 | 组合、伙伴、团队承载偶像成长 |
| nz | 9 | 伙伴、粉丝、约定使第二身份产生真实停靠 |
| nx | 9 | 学校禁令、规则、比赛条件不断限制主角 |
| zn | 8 | “现实中的我 / 偶像中的我哪个更真”逐渐出现 |
| x | 8 | 大嗓门、活力、舞台天赋被重新评价 |
| z | 7 | 每次演出、比赛、规则变化形成显影节点 |
| xz | 6 | 身份暴露、资格失效、团队危机等临界危险 |

# 6. 顺序
### 起手顺序
**x并z → nx → z → zx**

普通学生 / 偶像世界的空间分裂 → 学校禁令 → 偶然入口 → 主角主动站上舞台。

### 成长顺序
**zx → xn → n → nz → x并z强化 → zn**

主动继续参加 → 被职业规则塑形 → 组成团队 → 关系沉淀 → 偶像身份被社会确认 → 新身份开始进入本体。

### 总动态链
**x并z → nx → z → zx → xn → n → nz → 新x并z → zn → zx再选择**

# 7. 五维
| 五维 | 组合 | 体量 | 解释 |
|---|---|---:|---|
| 空间 | x并z+n | 10 | 两个生活空间 + 团队共同体是全作核心 |
| 因果 | zx+nx | 10 | 想继续登台与学校/系统限制持续对撞 |
| 时间 | xn+z | 9 | 长期训练、排名、比赛与一次次舞台节点 |
| 本体 | zn+x | 9 | 原本被视作缺点的大嗓门转化为舞台能力；第二身份反写自我 |
| 命运 | xz+nz | 8 | 失去资格/暴露风险与伙伴、粉丝停靠形成对照 |

最强五维：**空间 + 因果**。

# 8. 关系结构
### 啦啦 ↔ みれぃ
みれぃ承担 xn：训练、要求、职业规范；啦啦承担 zx：用直觉和主动行为突破僵硬规则；两人互补后形成 n：组合承载。

### 啦啦 ↔ 学校 / 校长
学校是现实 xn / nx；PriPara 是另一套 xn；主角处在两套规则夹缝中。

### 啦啦 ↔ 粉丝
粉丝从观看者转成 nz，证明偶像身份不是虚拟系统自说自话，而是产生真实社会关系。

### 啦啦 ↔ 舞台人格
初期：现实自我 ≠ 偶像自我。
中期：现实人格能力被偶像身份重新解释。
后期：二者开始互相渗透。

# 9. 核心动态链
## 链A：禁止身份生成链
**现实x并z → xn禁令 → nx压制 → z偶然入口 → zx越界 → 新x并z偶像身份**

外部规则越明确禁止某身份，第一次越界取得该身份时，身份生成强度越高。

## 链B：第二空间真实化链
**PriPara空间x并z → xn重复实践 → n团队 → nz粉丝/伙伴 → zn回写**

一个起初像“游戏空间”的职业世界，只要持续产生真实行动、关系与代价，就会反过来获得现实性。

## 链C：缺点转职业资产链
**现实x负评价（嗓门太大） → 新xn舞台环境 → x重新估值 → zx主动使用 → x并z明星特征**

同一能力在旧规则下是缺点，在新规则下可以变成职业资产。

## 链D：双规则夹击链
**现实xn ↔ 偶像xn → 主角nx受压 → zx寻找缝隙 → 两边身份同时强化**

主角不是逃离规则，而是在两套相互冲突的规则之间生成行动性。

# 10. 反咬点
### 反咬1：秘密身份越成功，越难隐藏
**登台越多 → 粉丝越多 → 公共身份越强 → 被现实发现的风险越大。**

解决问题的机制本身制造新的危险。

### 反咬2：第二空间越像游戏，产生的关系却越真实
**人工/特殊空间 → 真约定 → 真团队 → 真失败 → 真粉丝 → 真本体。**

外壳越人工，内部关系反而越能证明真实性。

### 反咬3：规则禁止偶像，反而强化偶像欲望
**nx压制 → zx反弹。**

禁止本身成为欲望放大器。

### 反咬4：现实缺点被职业空间重新定义
**旧xn下的负x → 新xn下的正x。**

# 11. 视觉符号
1. PriTicket：资格 / 门槛 / 第二身份钥匙。
2. 学校校门 ↔ PriPara入口：两个制度空间的视觉对子。
3. 普通校服 ↔ 偶像服装：x并z身份切换。
4. 小学生现实形态 ↔ 舞台偶像形态：身份空间对身体外显的改写。
5. 空舞台 ↔ 被粉丝观看的舞台：社会承认增长。
6. 风纪规则 / 禁止告示 ↔ Live舞台：xn对xn。
7. 票券扫描 / 门开启：从现实规则进入另一规则系统的 z 节点。
8. 组合站位：个人身份转共同体身份。

最强视觉对子：
> **校门禁止线 ↔ 舞台入场门。**

两扇门分别决定“你不能成为什么”和“你可以成为什么”。

# 12. 可复用母题
## 母题1：禁止职业身份
**xn禁止 → nx压制 → 隐秘入口 → zx越界 → 第二x并z。**

可迁移：禁止魔法的学校→秘密魔法师；贵族少女→地下拳手；圣女→匿名歌手；军人→夜间演员。

## 母题2：第二空间职业化
现实世界没有你的职业位置，于是另一个空间给你位置。
可迁移：虚拟世界主播、地下剧场演员、梦境竞技者、秘密城市中的英雄。

## 母题3：环境重估天赋
**旧xn：x=- → 换空间 → 新xn：x=+。**

这是“换环境而非加能力”成长机制。

## 母题4：秘密身份必然公开化
职业本身依赖被看见，秘密却依赖不被看见：
> **偶像越成功，秘密越失败。**

## 母题5：人工空间生成真实本体
**人工x并z → xn重复 → n/nz沉淀 → zn真实化。**

# 13. 与已有S矿区分
- 《Aikatsu!》：憧憬感染型。
- 《CINDERELLA GIRLS》：外部发现 / 招募点火型。
- 《Dream High》：制度加工型。
- 《Love Live!》：危机工具真实化型。
- 《Full Moon wo Sagashite》：身体门槛绕行型。
- 《Idol Shikkaku》：私人关系侵蚀职业资格型。
- **《PriPara》：现实制度禁止身份，另一个制度空间允许身份生成，属于“禁止身份 / 双重空间职业化型”。**

本轮新增不是“偶像学校”的换皮，而是：
> **两个规则空间争夺同一主体。**

# 14. 矿级
**S矿。**

理由：普通人→偶像身份建立过程纯；训练、舞台、竞争、粉丝、组合、制度均为长期主机制；不是娱乐圈恋爱伪样本；新增“禁止身份 + 第二空间”机制；可迁移到大量非偶像题材；视觉符号与结构高度一致。

# 15. 本轮增量矿核
> **当现实空间不允许你成为某种人时，另一个空间可以先让那个身份成立；但一旦在那里产生了真实行动、关系、观众与代价，这个“第二身份”就会反过来要求进入现实。**

十元压缩式：
**x并z(现实身份) → xn禁令 → nx → z入口 → zx → x并z(第二身份) → xn实践 → n/nz → zn回写 → 两套xn冲突升级**

可进入：偶像题材母型库 / x并z空间身份库 / zx-nx因果对冲库 / 环境重估x动态链库 / 双重身份视觉符号库。
