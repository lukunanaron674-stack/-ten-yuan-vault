# 日韩偶像题材｜母库增量 R06

## 1. An Insincere Idol's Blank Slate｜韩漫/Webtoon｜S
授权来源：Tapas Entertainment；KAKAO WEBTOON Studio。Tapas 于2024-11-14上线英文漫画，当前页面列82话并标示Hiatus Announcement。

### 进入偶像机制
Yoon Eden 已经在一个平庸公司当了多年K-pop偶像，因无能CEO、差劲概念与职业消耗而濒临退出，随后回到自己出道当天。他不是“第一次争取出道”，而是已经知道这套职业机器会怎样把自己和团体磨损，于是利用作曲能力与旧经验改写同一条职业路线。

### 新母型
**“回到出道日，不是为了重新得到职业资格，而是为了夺回被职业机器磨掉的诚意。”**

### 十元
- 主符号：xn（时间回归 + 已知职业流程）
- 次1：zx（主动改写歌曲、概念、团体路线）
- 次2：zn（七年后的职业自我与刚出道时的自我发生重叠）
- 次3：x并z（公众概念、偶像包装、团体形象）
- 暗层：nx（弱公司、无能CEO、既定概念对成员的安排）
- 情感底层：z（对真正成为“好偶像”的执念重新点燃）

### 体量
xn 10 / zx 9 / zn 9 / x并z 9 / nx 8 / z 8 / nz 7 / n 6 / x 5 / xz 4。

### 五维
- 时间 xn+z：最大驱动是回到出道日，用多年失败经验重新点燃已经耗尽的职业执念。
- 本体 zn+x：成熟失败偶像的自我进入刚出道身体，形成“现在的我到底是新人还是已经被行业磨过七年的人”。
- 空间 x并z+n：公司概念、歌曲、舞台、团体公众形象构成被观看空间；成员关系决定新包装能否稳定。
- 因果 zx+nx：Eden 主动以作曲与经验反制CEO的错误判断，但仍必须在公司体系内部行动。
- 命运 xz+nz：回归本身提供强命运改写窗口，真正让新路线成立的是团体成员一起重新形成的共同体。

### 顺序链
**xn → zn → nx → zx → x并z → nz → zn**

旧职业失败记忆随时间回归进入新人身体 → 已知公司与路线会把团体耗死 → 再次遭遇同样的管理压制 → 用作曲和经验主动改写 → 新团体形象与职业路线成立 → 成员共同体重新生长 → Eden 重新回答“我为什么还要当偶像”。

### 生链
**xn回归 → z旧执念复燃 → zx主动改写歌曲/概念 → x并z新公众身份 → nz团体关系被修复 → zn职业自我重新成立。**

### 克链
1. xn克旧结局：回归切断“七年后被磨到想退出”的线性结局。
2. nx克zn：无能CEO与既定概念不断压缩成员真正想成为的偶像形态。
3. zx克nx：Eden 用未来经验、作曲能力、记忆主动反制错误经营。
4. x并z反克zn：新的“成功偶像形象”一旦成立，也可能再次要求真实自我服从公众期待。

### 反咬点
**如果第二次人生只是把“错误包装”换成“更成功的包装”，那他究竟找回了真诚，还是学会了更高明地经营自己？**

### 5组补子
- xn+z：七年职业记忆 + 已经熄灭又重新燃起的偶像执念。
- zn+x：成熟失败偶像自我 + 刚出道时的身体与起点。
- x并z+n：歌曲/概念/公众形象 + 团体与舞台关系场。
- zx+nx：主动改写职业路线 + 仍受公司、CEO、市场安排。
- xz+nz：回归的强命运窗口 + 团体成员共同体提供真正的新结果。

### 偶像职业机制
- 已出道偶像：强
- 公司/CEO管理：极强
- 歌曲与作曲：极强
- 团体成员协作：强
- 概念/公众形象：强
- 舞台/成绩/知名度：强
- 再出道/时间回归：核心机制

偶像职业度：10/10。

### 欲望与代价
- 表层欲望：改写失败事业、让团体真正走红。
- 深层欲望：确认自己是否还能“真心”当偶像，而不是只把职业熬下去。
- 成功代价：越懂行业，就越容易把自己与队友当成可以优化的职业对象。
- 失败代价：再次走回七年后被行业耗空、最终想退出的旧结局。

### 与已有样本差异
- 《Second Try Idol》：重点是失败者先去当训练师，再回前台；本作没有“后台职业转换”，而是**七年偶像本人回到出道日重写同一家公司与同一团体**。
- 《My Comeback as the Youngest Member》：重点是重进淘汰型选秀机器；本作重点是**已出道后的长期经营错误与职业诚意耗损**。

### 可复用母题
**“失败不是没出道，而是出道成功后，被错误经营慢慢变成自己不想成为的人。”**

### 来源
- Tapas官方漫画页：https://tapas.io/series/an-insincere-idols-blank-slate/info

## 2. This Life's Universal Superstar｜韩漫/Webtoon｜A+
别名：In This Life, the Greatest Star in the Universe。
授权来源：Tapas Entertainment；原作版权标注 Sol, Son Yoon / D&C MEDIA。Tapas 英文漫画自2025-03-14上线，当前官方页列93话并持续每周更新。

### 进入偶像机制
Sun Woojoo 原本因舞蹈能力差而放弃偶像梦想，准备过普通生活；事故后获得“看一次就能精确复制动作”的能力，原先阻断出道的身体技能缺陷被突然修复，于是重新回到偶像道路。

### 新母型
**“不是回到过去，而是职业资格缺口被超自然能力直接补齐，迫使被放弃的梦想重新变得现实。”**

### 十元
- 主符号：x（身体技能条件突然变化）
- 次1：z（已经放弃却未彻底消失的偶像梦想）
- 次2：zx（重新选择行动、训练、登台）
- 次3：xn（偶像成长、练习、出道的职业路径）
- 包装层：x并z（舞台明星身份）
- 本体层：zn（“我原本是不适合当偶像的人”这一自我定义被推翻）

### 体量
x 10 / z 9 / zx 9 / xn 8 / zn 8 / x并z 8 / n 7 / nz 6 / nx 5 / xz 5。

### 五维
- 时间 xn+z：梦想曾经中断，能力改变后重新进入职业成长路径。
- 本体 zn+x：核心是身体技能变化迫使旧自我定义失效；“我不能当偶像”不再成立。
- 空间 x并z+n：舞台、团体、观众把新能力转化成真正明星身份。
- 因果 zx+nx：获得能力不是成功本身，仍要主动训练和抓住职业机会，同时接受公司/行业筛选。
- 命运 xz+nz：事故与能力像命运突然开门，后续能否成立则依赖团队与持续关系。

### 顺序链
**z → x → zn → zx → xn → x并z → zn**

梦想因能力缺陷被压下 → 身体能力突变 → 原自我判断崩塌 → 再次主动选择偶像 → 重进职业成长路径 → 舞台明星身份成立 → 重新定义“我是谁”。

### 生链
**x能力修复 → z旧梦想复燃 → zx重新行动 → xn职业训练路径 → x并z舞台身份。**

### 克链
1. x旧缺陷曾克z：舞蹈短板让梦想无法兑现。
2. 新x反克旧zn：能力改变后，“我不适合当偶像”的自我定义失效。
3. zx克nx：主角重新采取行动，避免继续被原先失败结论安排人生。
4. x并z反克zn：越成功被认作天才明星，越可能让他必须持续证明这个新身份不是偶然能力造成的假象。

### 反咬点
**如果一个人只是因为突然获得“完美复制动作”的能力才终于有资格追梦，那么成功是在证明他本人，还是在证明那项外挂？**

### 5组补子
- xn+z：偶像成长路线 + 被放弃后复燃的梦想。
- zn+x：旧“不适合偶像”的自我定义 + 新身体技能条件。
- x并z+n：舞台明星身份 + 团体/观众/娱乐圈关系场。
- zx+nx：重新主动追梦 + 仍受行业筛选与职业规则。
- xz+nz：事故/特殊能力的命运转折 + 团队关系把偶然转成稳定人生。

### 偶像职业机制
- 练习/舞蹈：核心
- 出道：核心目标
- 舞台：核心
- 团体成长：强
- 娱乐行业升级：强
- 特殊能力：进入职业的关键触发器

偶像职业度：9/10。

### 欲望与代价
- 表层欲望：重新成为偶像并在舞台上发光。
- 深层欲望：证明过去被一个身体短板否定的自己，并不等于整个自我没有职业价值。
- 成功代价：越依赖特殊能力，越难区分“努力成长”与“能力替自己完成成长”。
- 失败代价：再次确认自己只有在外挂存在时才有资格做梦。

### 与已有样本差异
- 《Wanna be a Star!》：同一身体能力因职业分类不同被赋予相反价值；本作是**身体技能本身发生改变，直接改写职业资格**。
- 《Idol × Idol Story!》：失败后凭旧执念重新选择舞台；本作多了一层“原本客观技能缺口被突然修复”的现实条件翻转。

### 可复用母题
**“当现实终于允许你做曾经被迫放弃的梦，你还是原来那个追梦的人吗？”**

## R06结构新增
1. **职业诚意耗损型**：《An Insincere Idol's Blank Slate》——问题不是没资格成为偶像，而是已经成为偶像后被错误经营磨空。
2. **职业资格修复型**：《This Life's Universal Superstar》——梦想早已被现实技能缺口判死刑，身体条件突然改变后职业可能性重新打开。

二者都不是单纯“重生爽文”：前者研究职业系统如何耗损本体，后者研究现实资格条件如何决定梦想是否能成立。
