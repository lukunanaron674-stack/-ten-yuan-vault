# R61｜U149｜未成年职业资格延迟 / 偶像未满型

## 1. 核心样本判定
官方把第3芸能課的少女直接描述为“没有Producer、没有工作、偶像未满的少女”。她们已经被选进大型事务所的新项目，却一度只有训练没有工作；之后才逐步获得宣传照、直播、综艺、短片试镜、伴舞、Runway等具体工作，并最终获得出道曲与正式Debut机会。

本作真正的新机制不是“儿童也能当偶像”，而是：

> **职业身份可以先被机构授予，但因为年龄、身高、监护、工作资格和市场判断，主体长期处于‘拥有职业标签，却没有完整职业行动权’的延迟状态。**

因此它补的是“职业资格分阶段成熟”。

## 2. 十元体量

| 十元 | 体量 | 作用 |
|---|---:|---|
| xn | 10 | 事务所、监护同意、年龄限制、工作安排、出道流程、演出资格构成核心制度 |
| x并z | 10 | 第3芸能課成员已被叫作偶像，却长期处于“偶像未满”的半成立社会身份 |
| nx | 10 | 年龄、身高、家长同意、没有工作、无法登台持续限制行动 |
| zx | 9 | 少女与新人Producer不断主动争取工作、直播、试镜、舞台与正式出道 |
| zn | 9 | “我是孩子，还是职业偶像”“大人与孩子究竟差在哪里”不断进入本体 |
| n | 9 | 第3芸能課作为低优先级小组，通过共同实践逐渐形成真正团队 |
| nz | 9 | 家长、Producer、前辈、粉丝的承认决定她们能否继续扩大职业行动权 |
| x | 9 | 每个人的个性、表演能力、兴趣必须被翻译成真实工作价值 |
| z | 8 | 长期只训练没工作的等待史，会积累成职业焦虑与自我怀疑 |
| xz | 7 | 项目能否真正出道与能否登上正式舞台形成高压，但不是超自然宿命 |

主元：**xn + x并z + nx**
次元：**zx + zn + n**

## 3. 顺序

**x并z半授予 → nx资格延迟 → xn持续训练 → z等待累积 → zx争取工作 → x显影 → n/nz承认增长 → xn扩大行动资格 → 新x并z正式化 → zn回写**

解释：

先被选进事务所项目
→ 形式上已经是偶像候选/成员
→ 却没有工作、没有完整行动权
→ 只能持续训练与等待
→ 主动争取具体工作
→ 真实能力被不同场景检验
→ 队友、家长、Producer、前辈与粉丝开始承认
→ 事务所逐渐给出更大的职业权限
→ 正式Debut与Live让“偶像未满”转成真正社会身份
→ 主体开始真正认领“我就是偶像”。

## 4. 五维

### 时间｜xn + z：10/10
“被选中”与“真正出道”之间存在漫长延迟。训练、无工作期、小型工作、SNS积累、Debut曲、正式Live形成清楚的职业成熟史。

### 本体｜zn + x：10/10
不是简单问“我会不会唱跳”，而是问：**儿童身份和职业偶像身份能不能同时成立？**职业实践不断扩张她们对“自己能做到什么”的定义。

### 空间｜x并z + n：10/10
第3芸能課本来只是公司行政分组，靠共同训练、共同找工作、共同演出，逐渐长成真正职业共同体。

### 因果｜zx + nx：10/10
年龄、监护、公司安排等nx不断限制；Producer和成员则通过争工作、争舞台把职业行动权一点点夺回来。

### 命运｜xz + nz：9/10
家长是否同意、Producer是否支持、粉丝是否承认，会直接影响职业路线是否能继续。

## 5. 偶像职业机制

### 身份如何建立
不是一次选秀结束就完成，而是：
**被机构选入 → 获得半职业标签 → 长期训练 → 取得第一批真实工作 → 获得公众反馈 → Debut正式化。**

### 训练
早期最突出的是“只有Lesson、没有工作”。训练不是成功证明，而是一种等待资格成熟的过渡状态。

### 出道
第10话以后正式进入Debut曲与出道准备，第11话明确“Debut决定”，第12话又遭遇年龄导致无法参加前辈联合Live，最终才获得出演机会。

### 竞争
竞争不只来自其他偶像，更来自“哪些工作愿意交给小学生”“谁被认为足够成熟可承担工作”的隐性筛选。

### 舞台
舞台既验证表演能力，也验证公司是否愿意把公共风险交给未成年成员承担。

### 粉丝
SNS和直播逐渐制造公众承认；粉丝不是只给人气，而是在证明“这些孩子不是事务所内部自娱自乐，她们已经形成真实市场关系”。

### 公司/监护机制
公司提供入口却长期不给足工作；监护人拥有现实同意权。职业行动权因此被拆成：
**机构承认 + 家庭许可 + 实际工作机会 + 公众承认。**

## 6. 主角欲望与代价

核心欲望：
**我想真正站上舞台，而不只是被叫作偶像。**

代价：
- 必须在儿童生活与职业纪律之间切换；
- 必须接受成年人对风险、形象和资格的判断；
- 必须比成熟艺人更早面对公众评价；
- 越证明自己“能工作”，越容易被要求承担更接近成人职业者的责任。

所以出现核心反咬：

> **为了摆脱“你还只是孩子”的限制，必须证明自己能承担职业责任；可证明得越成功，童年被职业占据得越多。**

## 7. 关系结构

### 少女 ↔ 新人Producer
双方都是“不成熟职业者”。Producer也不是经验丰富的成年人，因此形成：
**小偶像 + 小Producer → 共同职业化。**

### 少女 ↔ 家长
家长不是单纯阻碍者，而是掌握现实风险许可权的人。孩子的zx必须经过家庭nx/nz才能进入职业空间。

### 第3芸能課 ↔ 前辈偶像
前辈既是职业模板，也是资源接口。直播教学、伴舞机会等让成熟职业网络把经验向下传递。

### 第3芸能課 ↔ 公司
公司先命名她们为项目成员，却迟迟不给足工作；于是形成“标签先行、权限滞后”的结构。

## 8. 动态链

### 链A｜半职业身份成熟
**x并z先授予 → nx限制行动权 → xn持续实践 → zx争取机会 → nz公众承认 → 新x并z正式化**

结论：
> **身份可以先成立50%，再由实践与社会许可把剩余50%补完。**

### 链B｜资格延迟反咬
**年龄小 → 工作少 → 履历少 → 公司更不敢给大工作 → 更难证明自己**

形成负循环。

破局：
**小工作 → 真结果 → 公众/前辈承认 → 更大工作 → 职业资格扩大。**

### 链C｜儿童身份与职业身份互咬
**儿童zn → 被保护 → nx限制职业行动**
同时：
**偶像x并z → 要求专业 → xn提高责任标准**

主体被夹在：
**“你还是孩子” ↔ “你既然是偶像就要专业”**
之间。

## 9. 反咬点

### 反咬1｜被公司选中，不等于公司愿意真正使用你
公司能给名分，却可能不给工作。于是：
**职业标签 ≠ 职业行动权。**

### 反咬2｜越证明成熟，越可能失去儿童豁免
为了得到舞台，必须表现得可靠；一旦被证明可靠，外界就会提高对她的职业要求。

### 反咬3｜保护机制既保护，也延迟成长
家长同意、年龄限制、防风险规则都合理，却会延迟职业履历生成。

### 反咬4｜没有工作时，训练可能从成长变成怀疑
**xn训练长期没有z结果**时，主体会开始问：
“我们到底是不是偶像？”

### 反咬5｜真实职业价值会反审年龄标签
如果成员能完成直播、试镜、伴舞、Runway、Live，那么实践结果会反过来迫使制度重新判断：
**年龄究竟是在筛风险，还是在误判能力？**

## 10. 视觉符号

- 空荡练习室 / 反复Lesson ↔ 真正有观众的Live
- 身高标尺“U149” ↔ 巨大正式舞台
- 家长同意书 ↔ Debut曲
- 小学生书包 / 暑假作业 ↔ 宣材照 / 麦克风 / 舞台服
- 第3芸能課小房间 ↔ 大型事务所前辈舞台
- 只能看台下 ↔ 最终站到联合Live灯光里
- 成人Producer/前辈的视线高度 ↔ 小成员仰视构图

最强视觉母题：
> **很小的身体站进很大的职业空间。**

## 11. 可复用母题

1. **职业资格延迟**：已经被录取，却还没有完整行动权。
2. **标签先于权限**：社会先叫你职业者，资源和责任随后才逐步开放。
3. **低风险工作阶梯**：先从小任务积累可信度，再换大舞台。
4. **保护即限制**：合理保护机制同时制造职业延迟。
5. **成熟证明悖论**：越想证明“不只是孩子”，越被职业要求提前成熟。
6. **双新人共同成长**：不成熟成员与不成熟管理者共同完成职业化。
7. **年龄标签反审**：真实结果迫使制度重新区分年龄风险与真实能力。

## 12. 与旧矿边界

- **CINDERELLA GIRLS（R外部发现型）**：重点是“别人先发现职业可能性”。
- **Dream High**：重点是教育制度加工新人。
- **Creamy Mami R52**：借成熟身体绕过儿童年龄，形成职业人格时间错位。
- **U149 R61**：**不绕过儿童身份，而是在保留儿童身份的前提下，一点点争取职业行动权。**

因此本轮正式新增：

# 「未成年职业资格延迟 / 偶像未满型」

母链：
**机构先授予半职业身份 → 年龄/监护/市场限制行动权 → 长期训练与等待 → 小工作验证 → 关系与公众承认累积 → 职业权限扩大 → 正式出道 → 儿童本体与职业本体重新协商。**

## 13. 矿核

> **“成为职业者”并不总是一道门。有些人先被允许拥有这个名字，却没有全部行动权，只能靠一件件小工作、一层层信任和一段段真实结果，把社会原本暂缓交给他的职业资格慢慢拿回来。最尖锐的反咬是：为了证明自己不只是需要被保护的孩子，他必须越来越像一个可靠的成年人；而一旦证明成功，职业也就开始真正占用他的童年。**
