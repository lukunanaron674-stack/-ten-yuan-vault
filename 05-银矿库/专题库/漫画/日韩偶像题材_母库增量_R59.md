# 日韩偶像题材｜母库增量 R59

> 本轮去重：仓库未检索到《Who’s That Girl? / 오늘의 한요일은 여자다 / 反转练习生》的既有独立条目。
> 核心筛选标准：偶像职业必须是主线，不以普通娱乐圈恋爱为主。该作虽然平台分类含 Romance，但公开章节持续出现练习生生存、月评、主舞台、声乐训练等职业机制，且主角的核心目标始终是重新取得偶像出道资格，因此纳入核心样本。

## 59. Who’s That Girl?｜오늘의 한요일은 여자다｜反转练习生｜韩漫 / WEBTOON｜S

### 一、基础卡
- 作者：Song Geukjang（송극장）。
- 媒介：韩国 WEBTOON；英文官方版《Who’s That Girl?》，日版《美少女アイドル練習生の俺、メンバーに正体がバレそうです》。
- 偶像身份如何建立：Sanghyeon Kim 原本一直想成为 K-pop 偶像，也有能力与行动欲望，但因“校园霸凌加害者”的虚假指控，在现实社会身份层面被行业连续拒绝。大型娱乐公司负责人给他一种能变成“前世身体”的神秘道具，他变成外貌极强的女性身体，以新的练习生身份重新进入偶像培养体系。
- 核心职业问题：**能力没有消失，职业欲望也没有消失；真正被封死的是原身份的社会信用。主角不是重练能力，而是换一个社会载体重新获得被评价资格。**

### 二、行业机制
- 训练：公开章节明确有 Vocal Training、适应期、专长研究等。
- 出道：主角目标始终是偶像出道，当前阶段以练习生生存与评价为核心。
- 竞争：练习生之间持续存在位置、能力、信任与身份秘密压力。
- 舞台：公开章节明确出现 Monthly Evaluation、Rehearsals、Main Stage。
- 粉丝：当前主线仍处练习生阶段，粉丝机制尚未达到成熟偶像样本的体量，暂列次级变量。
- 公司：公司既提供重新进入行业的机会，又掌握主角新身份的秘密与培养规则，是入口提供者也是潜在控制者。
- 评价：月评、主舞台、声乐能力构成持续职业验证，说明“换身体”只能解决进入，不会自动解决留下。

### 三、主角欲望与代价
- 表层欲望：重新获得偶像出道机会。
- 深层欲望：证明“被社会污名化的旧身份”并不等于“我没有成为偶像的资格”。
- 原始代价：旧社会身份因虚假校园暴力指控失去行业信用。
- 新代价：必须隐藏原本性别/身份，长期维持新的女性练习生社会身份。
- 成功代价：新身份越成功，新的关系、成绩、职业履历越多，未来揭开旧身份时需要解释的社会成本越高。
- 失败代价：不仅失去第二次偶像机会，还可能同时证明“换身份也无法成立”，进一步伤害本体。

## 六、顺序

### 故事动态顺序
**z → nx → zn → zx → xz → x并z → xn → x → n/nz → nx反咬 → 新zn / 新x并z**

解释：
1. **z**：旧校园暴力冤案已经形成社会记录。
2. **nx**：行业不断拒绝原身份。
3. **zn**：主角开始面对“是不是这个身份已经不可能当偶像”的本体压迫。
4. **zx**：仍不肯放弃偶像欲望。
5. **xz**：神秘道具让身体/人生轨道异常换位。
6. **x并z**：女性练习生新社会身份成立。
7. **xn**：进入真正练习生训练与月评。
8. **x**：能力在新评价环境中重新显影。
9. **n/nz**：新关系和信任开始积累。
10. **nx反咬**：越成功，身份秘密越危险。
11. **新zn / 新x并z**：最终必须解决“社会承认的是谁”以及“我是否能用真实身份继续拥有这些职业结果”。

### 顺序感谱提醒
- zx：312 —— 主角职业欲望的第一反应仍是“先行动”。
- x并z：213 —— 新身份的意义并非一开始完全理解，而是在职业实践中后知后觉地变重。
- zn：132 —— 本体问题不断要求先确认“我是谁”，再处理社会互动。
- xn：213 —— 职业规则不接受主观辩解，最终看评价结果。
- nx：213 —— 污名和暴露风险通常不是第一秒爆发，而是在行动末端收刀。
- z：231 —— 旧事件作为持续爆点，不断从过去冲回现在。

## 七、五维

### 时间维｜xn + z：10/10
旧冤案 z 没有因为变身消失。新身份必须通过训练、月评和职业履历 xn 持续累积，才能制造与旧记录对抗的新历史。

### 本体维｜zn + x：10/10
能力 x 是同一个主体在发挥，但承载能力的身体、性别表现和社会身份已经变化。核心问题：**“职业结果属于执行它的主体，还是属于被公众看见的那副身份？”**

### 空间维｜x并z + n：10/10
旧身份在原社会空间被拒绝；新身份进入练习生空间后重新得到位置。练习室、宿舍、月评舞台和公司体系共同把新包装压成真实职业关系。

### 因果维｜zx + nx：10/10
主角主动追梦，但旧污名、秘密和公司权力持续反推。最清楚的结构是：**主动性不够解决社会资格问题，因此 zx 被迫先改造 x并z 才能重新行动。**

### 命运维｜xz + nz：8/10
变身提供命运转轨；真正决定新人生能不能被主体认领的，则会越来越依赖新关系是否接受真实的他。

## 八、关系结构

### 1. 主角 ↔ 公司负责人
**机会提供者 / 秘密掌握者**
- 对方让主角重新获得行业入口。
- 同时掌握身份转换秘密，因此帮助与控制天然并存。

### 2. 主角 ↔ 其他练习生
**竞争者 / 新共同体 / 身份风险源**
- 一起训练使 n 增长。
- 越亲近，越难长期隐瞒真实身份。
- 所以 n/nz 的增长会直接增加 nx 暴露成本。

### 3. 旧公众身份 ↔ 新公众身份
**同一主体的两套社会账户**
- 旧账户背负污名。
- 新账户累积成绩。
- 最终冲突不是“哪一个是假”，而是：**社会是否允许把新账户的成绩重新归还给旧主体。**

## 九、核心动态链

### 链1｜社会信用重置链
**z污名 → nx封路 → x并z换壳 → xn重新评价 → x重新显影 → 新职业资格**

关键规则：
> **职业能力可以存在，但社会身份失去信用时，能力甚至得不到被检验的机会。**

### 链2｜假入口真考试链
**伪装/换身取得入口 → 月评/训练不认伪装 → 真实能力决定留下 → 职业身份部分真实化**

关键规则：
> **x并z可以骗过入口，却骗不过长期xn。**

### 链3｜新身份成功反锁链
**新身份成功 → z新履历累积 → n/nz关系增加 → x并z社会重量增加 → 身份暴露成本上涨**

关键规则：
> **替代身份越成功，越不能把它当一次性工具。**

### 链4｜社会账户归属链
**旧主体行动 → 新身份记账 → 公众承认新身份 → 真实主体要求取回结果归属**

关键规则：
> **“谁完成了行动”与“社会把成绩记给谁”可以分裂。**

## 十、反咬点

### 反咬1｜换身份解决污名，却制造真实性债务
旧问题：
**大家错误地认为我做过坏事。**

新方案：
**换一个没人认识的身份重新开始。**

新问题：
**大家现在喜欢的身份，也并不知道真正的我是谁。**

所以：
> **为了逃离一场假的社会叙事，主角不得不制造另一场不完整的社会叙事。**

### 反咬2｜社会标签能让能力失效，而不是让能力消失
主角原本有偶像驱动力与才能，但“校园暴力加害者”标签让公司连验证都不愿验证。

因此：
**x存在 ≠ x能进入职业因果链。**

需要：
**x + 可接受x并z + xn评价入口 → 职业有效x。**

### 反咬3｜新历史越厚，旧身份越难回去
如果新身份只存在一天，恢复原身份容易。

但随着：
**月评、舞台、朋友、训练、成绩**持续累积，
新身份获得 z。

于是：
> **返回真实身份，可能意味着主动切断自己亲手积累的新职业历史。**

### 反咬4｜证明清白仍不足以自动取回职业人生
即使旧冤案未来被澄清，也不代表：
- 新身份的关系会自动转移；
- 公司会接受身份真相；
- 练习生伙伴会无成本接受隐瞒；
- 公众会把新身份成绩全部重新记给旧主体。

所以真正终局问题比“洗清冤屈”更难：
> **如何把被分裂成两个社会账户的人生重新合并。**

## 十一、视觉符号
- 同一双眼睛 / 两副身体的镜面并置。
- 旧身份 audition rejection 邮件堆叠 ↔ 新身份练习生合格通知。
- 校园暴力相关新闻/搜索词 ↔ 新身份月评排名。
- 男性旧证件照 ↔ 女性练习生资料卡。
- 镜子：私下看见“我是谁”；摄像机：社会看见“我是谁”。
- 更衣室 / 宿舍 / 化妆台：秘密身份最危险的空间。
- 月评舞台灯：说明最终还是要由能力接受真实检验。
- 两套名字分别累积不同履历的视觉档案墙。

## 十二、可复用母题

### 1. 污名封路 / 换壳重考
**能力没失败，身份信用先失败。**

可迁移：
- 被诬陷作弊的画师换笔名重回比赛；
- 被封杀演员戴面具重新登台；
- 被逐出骑士团者以新身份参加王国选拔。

### 2. 社会账户分裂
同一主体在两个名字下分别拥有“污名历史”和“成功历史”。

### 3. 假入口真考试
身份伪装只解决准入，长期职业规则仍会把真假能力筛出来。

### 4. 新身份成绩归属权
**真正做事的人与被社会记账的人不是同一个名字。**

### 5. 清白不能自动恢复人生
撤销错误判决，只能删除旧污点，不能自动重建错失的训练、关系、粉丝与职业历史。

### 6. n/nz增厚秘密债务
越交到真朋友，越难继续用假身份面对他们。

## 十三、与已有样本边界

### vs R40《K-POP Extreme Survival》
R40：真实身份因性别门槛不能进入男团，因此伪装性别，核心是**资格规则不合理 → 绕规则 → 用能力反审规则**。

R59：主角原本的职业资格主要被**社会污名/信用崩坏**封死，不是纯性别门槛；换身的作用是建立一个“没有旧污点的社会账户”。核心是**声誉身份与能力身份分裂**。

### vs R36《AKB49》
R36：主角为了帮助别人主动制造女性偶像人格，假身份长期职业化。

R59：主角本来就想成为偶像；换身份主要是为了绕过对旧人格的社会封杀。重点不是“假人格如何变真”，而是**旧人格被错误社会叙事冻结后，职业成果被迫记到新人格名下。**

### vs R46《You’re So Pretty》
R46：主体进入别人的身体，替别人完成尚未实现的偶像命运。

R59：主体没有替别人履约，而是在新的身体/社会账号中继续完成自己原本就有的职业欲望。

## 十四、矿级

**S矿。**

新增价值不在“TS偶像”表皮，而在四条可独立复用的结构：
1. **社会信用可以先于能力淘汰一个职业者。**
2. **换身份能恢复评价资格，却会造成职业成果归属分裂。**
3. **假入口无法代替长期真评价。**
4. **洗清污名 ≠ 自动恢复被分裂/丢失的人生。**

## 十五、本轮凝结母型

# 「污名封路 / 社会账户重置型」

母链：

**旧身份污名 z**
→ **行业 nx 拒绝**
→ **主体 zx 不肯放弃**
→ **通过 xz 异常手段制造新 x并z**
→ **重新进入 xn 评价体系**
→ **真实 x 被验证**
→ **n/nz 与新履历持续增长**
→ **新身份反锁**
→ **zn 面临两套社会账户合并问题**

### 一句话矿核
> **有时一个人不是没有成为职业者的能力，而是社会先判定“这个名字不配被评价”。他只能换一个名字重新参加考试；可当新名字真的训练过、登台过、交到朋友、积累成绩以后，问题就不再只是洗清旧名的污点，而是怎样把两个名字下面已经分裂的人生重新合成同一个“我”。**
