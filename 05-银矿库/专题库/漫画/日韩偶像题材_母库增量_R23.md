# 日韩偶像题材｜母库增量 R23

本轮避开已饱和的“系统/回档男偶像”，补两个此前较弱的结构：**公共机构直接生产偶像职业**，以及**死亡之后由偶像身份承担第二次社会存在**。

## 1. 普通の女子校生が【ろこどる】やってみた。 / Locodol｜日漫｜S

### 基础核验
- 一迅社官方特设页确认漫画长期出版；一迅社杂志官方页确认该作连载十年后完结。
- 日本コロムビア官方作品页注明原作来自一迅社漫画，并明确：奈々子受叔叔请求成为地方偶像，与ゆかり组成流川ガールズ；工作包括当地商店街采访、低预算有线电视、百货屋顶Live，报酬甚至直接来自市民税金。
- 一迅社官方活动页将流川ガールズ与“流川市ふるさと振興課”绑定；第5卷官方书籍页确认1周年Live等持续职业活动。
- 官方来源：
  - https://www.ichijinsha.co.jp/special/palette/locodol/
  - https://www.ichijinsha.co.jp/palette/2022/02/22/
  - https://columbia.jp/locodol/anime.html
  - https://data.ichijinsha.co.jp/detail/75808264

### 进入偶像业触发点
奈々子不是先有“我要成为顶级偶像”的强欲望，而是被在地方行政体系中工作的叔叔叫去帮忙，随后成为流川市的地方偶像。

真正发动机不是选秀或经纪公司，而是：
**地方公共机构需要一种人格化宣传媒介。**

### 偶像职业机制
地方行政/公共宣传：极强；商店街采访、地方电视、地方Live、周年Live、地域吉祥物协作、团体活动均持续成立。
偶像职业度：**10/10**。

### 十元
- 主：**xn**——市役所/地方宣传工作、活动安排、公共任务构成稳定职业规则。
- 次1：**x并z**——普通女高中生被包装为城市代表性公众形象。
- 次2：**n**——城市、商店街、居民、地方媒体构成职业网络。
- 次3：**zx**——从被叫去帮忙逐渐转为主动完成Live与宣传劳动。
- 暗层：**zn**——私人学生身份与“城市代表”身份长期共存。

### 体量
`xn10 / x并z9 / n9 / zx8 / zn8 / nx7 / nz7 / z6 / x6 / xz4`

### 顺序链
**nx → xn → x并z → n → zx → nz → zn**

被安排帮忙 → 公共工作制度化 → 成为城市公众形象 → 地方网络建立 → 主动承担职业 → 关系深化 → 公共/私人双本体稳定。

### 五维
- 时间：**xn+z**——周年Live与长期地方活动把一次兼职变成职业时间。
- 本体：**zn+x**——普通学生自我与被赋予的公共偶像载体并存。
- 空间：**x并z+n**——只有在城市、居民、媒体、活动网络中“流川ガールズ”才成立。
- 因果：**zx+nx**——最初被安排，后来主动承担。
- 命运：**xz+nz**——没有死亡式硬锁，但地方关系越深，退出的现实牵连越强。

### 生链
`xn → x并z → n → nz → zx`

公共需求制造偶像身份；公众身份连接地方网络；网络生成真实关系；关系反过来提升主动职业投入。

### 克链
- **xn 克 zn**：公共工作持续侵占普通学生私人时间。
- **x并z 克 zn**：越成为城市代表，越难只做无名普通学生。
- **zx 反克 nx**：主动承担职责后，最初的被安排状态逐渐改写。

### 反咬点
**最初只是地方政府找来的兼职，但一旦她真的成为城市公共形象，“临时工作”会获得比私人学生身份更强的社会持续性。**

成功越高，地方社会越需要她继续代表城市；成功本身因此提高退出成本。

### 5组补子
- `xn+z`：公共任务通过长期活动与周年节点职业化。
- `zn+x`：普通学生自我与公共偶像载体互相定义。
- `x并z+n`：地方偶像身份依赖城市、居民、媒体、活动网络成立。
- `zx+nx`：从被安排兼职到主动职业劳动。
- `xz+nz`：关系越深，退出牵连越强。

### 欲望与代价
- 初始欲望：帮忙/兼职，并非顶级偶像梦。
- 后续欲望：把地方活动做好，回应搭档与居民期待。
- 成功代价：私人学生身份不断被公共代表身份覆盖。
- 失败代价：不再只是个人失败，还伤及地方活动、搭档与共同体期待。

### 与已有样本差异
- vs U149：U149是**事务所内部低优先级单位职业化**；本作是**地方公共机构把普通学生变成城市宣传劳动者**。
- vs SHINEPOST：SHINEPOST靠市场KPI决定存续；本作职业合法性首先来自**地方公共服务需求**。
- vs 推武道馆：后者由粉丝消费制造职业资本；本作的第一组织/资金入口来自**公共部门与地方社会**。

### 可复用母题
**公共机构把人格变成城市品牌。**

普通人 → 被公共组织临时征用为宣传媒介 → 公众身份产生真实社会关系 → 社会关系使临时身份持续化 → 本人也无法再把它当作一次兼职。

### 矿级
**S**。
理由：母库已有事务所、选秀、粉丝经济、现金流、解散KPI，却缺“地方政府/公共宣传直接生产偶像职业”的稳定样本。

## 2. ゾンビランドサガ / Zombie Land Saga 漫画版｜日漫｜A+

### 基础核验
- BOOK☆WALKER官方电子书页确认《ゾンビランドサガ サガ覚醒編》为漫画化作品，原作“広報広聴課ゾンビ係”、漫画空路恵，版权明确标注Cygames/小学馆/制作委员会。
- 官方简介确认：源さくら死亡后以僵尸复活，为拯救衰退中的佐贺“なぜかご当地アイドルに”，并由制作人巽幸太郎率领。
- 后续《サガ懐古浪漫編》官方简介明确Franchouchou是“为让佐贺振兴而复活的僵尸偶像”，并继续为更进一步成长行动。
- 官方来源：
  - https://bookwalker.jp/decfa8ea43-53e0-4872-90ce-7a274b1c15c6/
  - https://bookwalker.jp/de5a813043-61ba-44f7-b2fb-aba035e53589/
  - https://bookwalker.jp/de5ff95064-8351-49d9-af32-969808d62925/

### 进入偶像业触发点
源さくら先死亡，再被复活；她与其他来自不同时代的死者被制作人组织起来，以地方偶像身份承担“拯救佐贺”的任务。

结构是：
**旧人生终止 → 身体被复活 → 制作人赋予新职业 → 新职业成为第二次社会存在的入口。**

### 偶像职业机制
制作人、团体Franchouchou、地方偶像、地区振兴任务、Live/表演、团体成长、公众身份遮蔽真实身体状态均成立。
偶像职业度：**9/10**。

注：漫画化版本较动画本篇更偏佐贺地方文化/制作人视角，因此职业细节密度低于纯训练/选秀漫画，不机械给10。

### 十元
- 主：**zn**——旧人生已死亡，新“我”必须在复活身体与偶像社会身份之间重新成立。
- 次1：**x**——僵尸身体是职业成立必须被遮蔽/管理的物质载体。
- 次2：**x并z**——公众看到的是地方偶像，不是“已死亡者”。
- 次3：**xn**——制作人、团体安排、地方复兴任务规定行动。
- 暗层：**xz**——死亡是不可逆的旧命运。

### 体量
`zn10 / x10 / x并z9 / xn8 / xz8 / n8 / nz8 / zx7 / nx7 / z6`

### 顺序链
**xz → x → xn → nx → x并z → n → nz → zn → zx**

死亡锁死旧人生 → 僵尸身体复活 → 制作人规定地方偶像任务 → 先被安排 → 包装成公众偶像 → 地区/观众网络成立 → 成员共同体形成 → 新本体稳定 → 主动认领职业行动。

### 五维
- 时间：**xn+z**——旧人生终止与第二职业人生形成强断裂；职业任务提供新时间轴。
- 本体：**zn+x**——“我已经死了”与“身体仍在行动”直接冲突。
- 空间：**x并z+n**——只有在舞台、公众、地方社会网络中，她们才以偶像而非尸体存在。
- 因果：**zx+nx**——最初被制作人拉入计划，之后逐渐主动承担团体/地区使命。
- 命运：**xz+nz**——死亡锁死旧命运，团体关系为第二人生提供新的方向。

### 生链
`xz → x → x并z → n/nz → zn → zx`

死亡产生异常身体；真实身体状态逼出可被公众接受的包装；公众与团体关系持续承认后，新本体开始成立，并进一步生出主动职业行动。

### 克链
- **xz 克 zn**：死亡不断否定“回到旧人生”的可能。
- **x 克 x并z**：真实僵尸身体随时可能撕破公众偶像包装。
- **xn 克 zn**：制作人的地区复兴目标先于成员自己的第二人生选择。
- **nz 反克 xz**：团体关系不能取消死亡，却能让死亡后的存在重新获得方向。

### 反咬点
**偶像身份原本只是遮住“死人事实”的职业包装，但一旦被观众、地区和成员关系持续承认，这个包装反而会成为死亡之后最真实的新身份。**

假身份为生存服务 → 社会承认积累 → 假身份比已经终止的旧人生更有现实连续性。

### 5组补子
- `xn+z`：制作人任务把死亡后的空白时间重新组织成职业时间。
- `zn+x`：死者本体通过仍活动的身体重新回答“我是谁”。
- `x并z+n`：公众偶像形象依赖舞台、地区和观众网络。
- `zx+nx`：从被制作人组织到逐渐主动认领偶像行动。
- `xz+nz`：死亡不可撤销，团体关系为第二人生提供新命运结构。

### 欲望与代价
- 初始欲望：并非成员自主统一选择，更多来自制作人赋予的地区复兴使命。
- 后续欲望：在第二人生中获得行动目标、同伴与公众承认。
- 成功代价：公众身份越成功，越必须持续隐藏真实身体/死亡事实。
- 失败代价：不只失去职业，也可能失去第二次被社会承认的存在方式。

### 与已有样本差异
- vs The Holy Idol：后者是**陌生灵魂占据现成偶像身体**；本作是**同一死者以复活身体获得全新的偶像社会身份**。
- vs Back Street Girls：后者是活人被现实权力强制身体改造；本作是**旧人生已死亡，新职业成为第二社会生命的容器**。
- vs Locodol：两者都有地方振兴，但前者是**活着的普通人进入公共宣传岗位**；本作是**死亡后的新本体借地方偶像职业重新进入社会**。

### 可复用母题
**职业成为死后第二身份。**

旧人生终止 → 身体异常继续存在 → 社会无法接受真实状态 → 制造职业公众身份 → 职业身份获得真实关系与社会承认 → 从伪装变成新本体。

### 矿级
**A+**。
理由：本体机制很强且与现有样本明显不同，但漫画版职业制度细节不如纯偶像职业漫画集中，因此保留A+。

## R23新增母型
### Q. 公共机构人格化宣传
代表：《普通の女子校生が【ろこどる】やってみた。》

`公共需求xn → 公众身份x并z → 地方网络n → 真实关系nz → 主动职业zx → 公共/私人双本体zn`

核心问题：**当偶像是公共服务岗位时，“我是谁”有多少属于自己，有多少属于城市需要？**

### R. 死后职业第二身份
代表：《ゾンビランドサガ》漫画版

`死亡xz → 异常身体x → 被规定职业xn → 公众包装x并z → 社会网络n → 新本体zn`

核心问题：**当旧人生已经结束，社会为了接受你而制造的职业身份，会不会反而成为新的真实自我？**

## 本轮去重结论
- 不新增“系统逼出道/回档重考”样本。
- Locodol补的是**公共部门/地方行政直接生产偶像职业**。
- Zombie Land Saga补的是**死亡之后，偶像职业充当第二社会生命容器**。
- 两者都有“地方偶像/地区振兴”，但本体机制完全不同，不合并成同一标签。
