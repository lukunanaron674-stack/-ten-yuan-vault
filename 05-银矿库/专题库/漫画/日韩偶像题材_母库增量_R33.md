- 媒介：日本轻小说→TV动画 / 多媒体企划
- 核心样本属性：偶像成长、失败组合修复、团队存续危机、经理介入
- 矿级：S

## 一、偶像身份如何建立

TiNgS并非“还没出道的素人”，而是已经拥有偶像身份、却无法把身份做实的弱势组合。官方设定明确：她们怀抱很大的梦想，却只能取得很小的成果；第一话更直接收到“考虑让TiNgS解散”的通知。公司给出的存续条件是：如果能让中野サンプラザ演唱会满员，就撤回解散决定。

因此本作不是单纯的“从0获得偶像标签”，而是：

**已有x并z偶像标签 → 公众承认不足 → 身份濒临失效 → 以舞台结果重新证明身份**。

这补充了现有偶像谱系中的一个独立分支：

> **身份保级 / 职业合法性再证明型。**

不是“怎么得到职业资格”，而是“已经得到的职业资格，怎样避免被现实撤销”。

## 三、顺序

主链：

**x并z → nx → zn → xn → x显影 → n重组 → zx修正 → nz回流 → 新x并z**

解释：

1. 已经拥有“偶像组合”这个外部身份；
2. 公司与市场用“解散”证明该身份可能是空壳；
3. 成员开始产生“我是否真的配当偶像”的本体危机；
4. 票房、训练、Live规则把危机转成具体问题；
5. 原本被隐藏或压制的真实能力逐渐显影；
6. 团队结构重新调整；
7. 成员从模糊的“继续努力”转向有针对性的主动行动；
8. 粉丝与竞争者的真实反馈回流；
9. 偶像身份不再只是公司登记，而是被舞台结果重新坐实。

## 四、五维

### 1. 本体维 zn+x：10/10

本作最强的不是技能升级，而是：

> **角色常常已经有能力，却因为恐惧、自我压缩、错误定位而无法把能力作为“我”公开出来。**

职业问题于是转成：

**不是“我会不会”，而是“我敢不敢承认我会、敢不敢让别人看见真实的我”。**

### 2. 时间维 xn+z：10/10

旧失败、过去的决定和长期形成的自我限制不会被一次训练抹掉。每一次Live、售票、排练都在重新写履历。

### 3. 空间维 x并z+n：9/10

事务所、组合、舞台、竞争团、粉丝共同决定TiNgS能否继续存在。

### 4. 因果维 zx+nx：10/10

核心循环：

**市场/公司反推 nx → 暴露问题 → 主动修正 zx → 更高标准再次反推 nx**。

### 5. 命运维 xz+nz：9/10

“满场否则解散”制造强命运压力；而最终能对抗这一压力的，不只是能力，还有队友、经理、竞争者和粉丝形成的真实关系网络。

## 五、训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 训练
- 不只是唱跳技术训练，更重要的是针对个人心理锁与舞台定位进行修正。
- “稳定但只有稳定”“有能力却不让自己真正发光”成为典型问题。

### 出道
- 已出道，但处于“职业身份没有被市场坐实”的状态。
- 因此本作把“出道”拆成两层：行政出道 / 社会出道。

### 竞争
- 竞争团体与更成熟偶像提供外部标准，不只是敌人，也是“你还缺什么”的镜子。

### 舞台
- 舞台不是成果展示，而是职业合法性审判场。
- 中野サンプラザ满场条件把“被看见”直接量化为团体存续权。

### 粉丝
- 粉丝不是装饰性的nz回血，而是x并z身份是否成立的社会证据。

### 公司
- 公司同时是资源提供者与删除权持有者。
- 它可以给出偶像标签，也可以因为市场失败撤回组织支持。

## 六、主角欲望与代价

### 欲望
表层：不想解散、想让更多人喜欢偶像。

深层：

> **希望自己真正成为一个值得被别人喜欢、并且敢于发光的人。**

### 代价
- 必须暴露过去一直隐藏的真实能力或真实欲望；
- 必须面对“全力以赴以后仍可能失败”的风险；
- 必须接受被粉丝、竞争者、经理真实评价，而不能躲在“我已经很努力了”后面。

## 七、关系结构

### 成员 ↔ 成员
**n互补 + nx互压**。

队友既提供支持，也会让彼此无法继续用旧借口逃避。

### 成员 ↔ 经理
经理不是简单“替她们赢”，而是负责识别：

**角色说出来的目标 ≠ 角色真正的欲望。**

所以经理承担的是一种“本体诊断者”功能。

### 成员 ↔ 粉丝
粉丝从结果端反向证明：角色是否真的把自己传递出去。

### 成员 ↔ 竞争者
竞争者提供高标准镜像，让“稳定但普通”这种隐性缺陷被显影。

## 八、动态链

### 动态链1：空壳职业身份再实化

**已有x并z → 低市场承认 → nx解散压力 → xn考核 → zx主动修正 → nz粉丝回流 → 新x并z**

### 动态链2：隐藏能力反咬

**x真实能力 → zn恐惧/自我压缩 → 主动隐藏x → 舞台表现安全但平庸 → nx外部评价压迫 → zx决定暴露 → x重新进入公共身份**

### 动态链3：努力幻觉拆解

**“我很努力” → xn结果仍失败 → 努力无法自证 → 必须定位具体问题 → zx精准行动 → 新结果**

这条非常适合进入职业成长总库：

> **努力不是因果终点；如果结果持续失败，系统会逼角色把“努力”拆成可验证的具体行动。**

---

## 九、反咬点

### 反咬1：越怕失败，越会把真正能力藏起来

角色为了避免“全力以后失败”的痛苦，会下意识保留实力。

于是：

**怕证明自己不够好 → 不敢真正投入 → 结果真的不够好 → 更加证明自己不够好。**

形成自证循环：

**zn怀疑 → nx自我压制 → x无法释放 → 外部失败 → zn怀疑加深。**

### 反咬2：解散威胁反而让“偶像”第一次变成真正需要主动选择的身份

如果没有解散危机，成员可以继续惯性活动。

危机出现后：

**身份可能被删除 → 才必须回答“我到底要不要它”。**

即：

> **失去的可能性，反而制造身份认领。**

### 反咬3：经理越能看穿真实问题，角色越无法继续靠漂亮话维持自我解释

这使“被理解”不再只是nz安慰，而可以成为强nx。

> **真正看懂你的人，也可能是最难糊弄的人。**

## 十、视觉符号

- 空荡或未售罄的观众席 → x并z社会承认不足
- 中野サンプラザ座席 → 职业合法性的量化终点
- 练习服 ↔ 正式舞台服 → 私下能力与公共身份切换
- 售票 / 海报 / 小型Live → 偶像身份如何被一点点卖给社会
- “不出错但不发光”的舞台 → 安全人格视觉化
- 聚光灯下真正放开表演 → 隐藏x进入公共x并z
- 经理观察成员时的“识破感” → 本体被看穿
- 空场 → 人群 → 满场，作为x并z成立度的直接视觉量尺

## 十一、本轮新增可复用母题

### 1. 职业身份保级
已经是某种职业，并不等于这个身份永远有效。

**身份 → 结果不足 → 资格危机 → 再证明。**

### 2. 行政出道 ≠ 社会出道
公司可以宣布你是偶像，但观众未必承认。

### 3. 隐藏天赋自证失败
为了避免失败而保留能力，最终恰好制造失败。

### 4. 被看穿型导师
导师的核心能力不是教技能，而是识别角色自己都不愿承认的欲望与借口。

### 5. 失去可能性生成欲望
长期拥有一个身份时，人可以麻木；当身份要被删除时，才第一次知道自己究竟要不要它。

### 6. 精准努力替代模糊努力

**“继续努力” → 无效 → 定位缺口 → 针对性修正 → 结果变化。**

## 十二、与既有矿的边界

- 《Saving the Doomed Idols With My Touch》：外来者接盘并修复已经失败的组合。
- 《Wake Up, Girls!》：濒死事务所为了生存制造偶像组合。
- 《IDOLiSH7》：从选拔逻辑转向关系互补的团体生成。
- 《SHINE POST》：**成员本身已经处于职业内部，但偶像身份因缺乏结果而濒临失效；核心是“如何重新证明自己配得上已有身份”。**

因此正式新增分类：

# 「身份保级 / 职业合法性再证明型」

母链：

**已有职业标签 → 社会承认不足 → 删除威胁 → 本体危机 → 精准诊断 → 暴露真实能力 → 关系与舞台重新验证 → 职业身份再实化**

---

## 十三、矿核

> **成为某种人不是一次性事件。一个职业身份如果长期得不到结果、关系与公众承认的持续回填，就会逐渐空壳化；而真正的成长，有时不是“得到身份”，而是在身份即将被撤销时，第一次主动证明自己愿意为它付出什么。**
