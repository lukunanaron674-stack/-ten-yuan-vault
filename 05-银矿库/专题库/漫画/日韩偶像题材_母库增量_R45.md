# R45｜《人生二周目偶像的幸运计划》十元深拆

## 0. 去重
- GitHub 以韩文原名与 Lucky Plan 检索均未发现既有独立条目。
- 与《Second Try Idol》《My Comeback as the Youngest Member》《An Insincere Idol's Blank Slate》均有“重来一次”亲缘，但本轮重点不是“第二次更强”，而是：**上一世失败留下的不是纯能力，而是一张“哪些成功路径会把我送回灾难”的负路线图。**

## 1. 作品与职业入口
元有河原本错失爆款生存节目机会，之后在失败偶像团里苦撑五年；成员接连出事，自己又因车祸被判定无法继续表演。就在他决定“再也不要当偶像”时，回到六年前、正是当年让出《Design Your Idol》机会的分岔点，并出现系统/轮盘机制。

第二次人生中，他重新进入偶像生存节目。职业机制包括：
- trainee等级与再评价
- center候选
- 队伍组建
- concept/producing评价
- 节目剪辑与PD pick
- 观众投票/排名/淘汰
- 体能、表演、舞台、数字音源
- 公司出身带来的初始关注

## 2. 本轮新增机制
### 失败经验避障 / 反成功路线型
普通二周目：
> 过去失败 → 我知道正确答案 → 这次更快成功。

本作更有价值的结构是：
> 过去失败 → 我知道哪些“看起来成功”的路径其实会把人送进下一场灾难 → 第二次不是只追最高分，而是主动避开未来的坏因果。

所以二周目经验的核心不是“答案库”，而是**禁区地图**。

## 3. 十元体量
| 十元 | 体量 | 作用 |
|---|---:|---|
| z | 10 | 五年失败团、成员丑闻、车祸、错失机会作为巨大历史压强 |
| zx | 10 | 第二次主动抢回分岔点、不断改路线 |
| xn | 10 | 生存节目、等级、排名、制作任务、投票、剪辑规则 |
| nx | 10 | 旧未来、系统任务、节目暗线、公司资源持续反推 |
| x并z | 9 | “KRM练习生/成长型/center候选”等公众身份被节目包装 |
| zn | 9 | “我再也不当偶像”与“我为什么又在认真做”冲突 |
| x | 9 | 旧经验、舞台能力、判断力、制作与团队功能逐步显影 |
| n | 9 | 队伍构成、训练关系、旧队友/新队友的再组织 |
| nz | 8 | 粉丝投票、队友信任、被重新给予机会的情感回填 |
| xz | 8 | 回归本身、事故未来与不可控系统带来的命运压力 |

主元：**z + zx + xn + nx**

## 4. 顺序
**z → zn封闭 → xz回归 → nx旧未来警告 → zx抢回机会 → xn生存节目 → x并z公众包装 → n组队 → x经验显影 → nz反馈 → zx主动改写 → 新zn**

一句话：
> 先被失败历史压住，再回到分岔点；不是照着成功模板跑，而是在每次节目选择中同时问“这一步能不能赢”和“这一步会不会把未来重新推回灾难”。

## 5. 五维
- **时间 xn+z：10/10**：过去不是背景，而是持续参与现在每次选择的第二套时间线。
- **因果 zx+nx：10/10**：主角主动改写，但旧未来、节目规则、系统、剪辑不断形成反作用。
- **本体 zn+x：10/10**：真正问题是“一个已经发誓退出的人，为何又逐渐像职业偶像一样行动”。
- **空间 x并z+n：9/10**：节目、公司、队伍、center位置与公众叙事共同生产第二人生的身份。
- **命运 xz+nz：9/10**：回归提供改命机会，关系与投票又决定哪些人能被带出旧结局。

## 6. 主角欲望与代价
### 欲望
最初不是“我要当顶级偶像”，而是：
1. 不重复上一世失败；
2. 不再让自己被同样的职业结构碾碎；
3. 在可控范围内重新取得人生主动权。

### 代价
- 必须重新进入自己已经厌恶/恐惧的行业；
- 每一次为了避灾而改变路线，都可能失去上一世熟悉的人际结果；
- 旧知识并不保证新时间线仍然成立；
- 为了避免被节目过度包装，反而可能必须压低自己的排名/曝光欲望。

## 7. 关系结构
- 主角 ↔ 旧未来：不是回忆，是持续的负导师。
- 主角 ↔ 新队友：他知道一些人的“未来版本”，但现在的他们还没成为那样的人。
- 主角 ↔ PD/节目：既要利用节目叙事，又要防止被叙事反过来利用。
- 主角 ↔ 粉丝：需要票，又不能只追求最短期流量。

## 8. 动态链
### 链A｜失败史变成避障图
**z失败 → nx未来警告 → zx路线修改 → 新xn路径 → 新结果**

### 链B｜节目包装反咬
**x表现 → x并z“成长型/center候选”标签 → nz关注 → nx复制期待 → zn被标签挤压**

### 链C｜旧知识失效
**z记忆 → zx提前行动 → 因果变化 → 原未来失效 → nx信息优势下降 → 必须重新判断**

关键规则：
> 二周目越成功改变过去，二周目的“攻略优势”就越快失效。

## 9. 最大反咬点
### 反咬1：成功会破坏自己的预知优势
第一次改变结果后，后续世界不再完全等于记忆里的世界。

因此：
> **成功改命 → 未来偏移 → 旧知识贬值。**

这比“重生后永远知道答案”更有张力。

### 反咬2：为了避免再次成为偶像，反而必须把偶像做得更专业
主角若想安全穿过节目、保护自己和关系，就必须：
训练、读规则、组队、做舞台、看剪辑、判断票盘。

于是：
**拒绝偶像zn → 为了退出而执行偶像zx → x越来越职业化 → 新zn反写。**

### 反咬3：最危险的不一定是失败，而是错误的成功
上一世“进入失败团”当然是失败；但第二世更值得研究的是：
某些高曝光、center、PD pick、爆点剪辑，短期看像成功，却可能制造长期被控制、被固定、被攻击的路径。

所以新增母题：
> **坏成功 / 有毒成功路径。**

## 10. 视觉符号
- 同一舞台的“上一世灰暗记忆版 / 第二世高亮现实版”叠影
- 排名榜上升，但主角表情反而更警惕
- 轮盘/系统界面与节目排名屏并置：两套xn同时评判
- 过去车祸、失败团宿舍、空观众席作为z闪回
- center座位像诱饵而不是奖杯
- 剪辑时间线/镜头框把人物切成“节目角色”

## 11. 可复用母题
1. **失败经验避障**：过去经验不告诉你怎么赢，而告诉你哪里不能再走。
2. **坏成功**：短期高分可能是长期灾难入口。
3. **改命越多，攻略越失效**：成功本身削弱先知优势。
4. **退出者二次职业化**：为了安全退出，必须重新做到专业。
5. **未来版本污染关系**：你知道某人未来会变坏/失败，但现在的他还没有做那些事。
6. **双评价系统**：节目公开规则 + 系统/未来暗规则同时作用于同一主体。

## 12. 与既有样本边界
- 《Second Try Idol》：训练师经验回流，偏“正能力复用”。
- 《My Comeback as the Youngest Member》：被淘汰者重回同一选秀，偏“重考资格”。
- 《An Insincere Idol's Blank Slate》：回到出道日修复职业诚意，偏“错误经营修复”。
- 《天才偶像的演艺圈攻略法》：被行业伤害后再次认领职业，偏“知道代价后的第二次选择”。
- **本作R45**：重点是**过去失败形成负路线图，而且每次改命都会让旧攻略逐渐失效。**

## 13. 矿级
**S矿。**
理由：在“二周目偶像”已经容易同质化的韩漫里，它仍提供了一个可迁移度很高的新机制：

> **二周目真正宝贵的不是知道正确答案，而是知道哪些看起来很好的选择最后会杀死你；更残酷的是，只要你开始成功改变过去，这份知识本身也会一点点过期。**
