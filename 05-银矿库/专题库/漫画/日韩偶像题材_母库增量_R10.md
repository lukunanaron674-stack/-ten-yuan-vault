# 1. THE IDOLM@STER Cinderella Girls U149｜日漫｜S

## 基础核验
- 官方漫画平台：サイコミ（Cygames）。
- 官方连载页当前列出全300话。
- 2025年4月15日发行第18卷；2026年8月14日起官方又启动新装版再刊。
- 官方第2卷简介已明确出现“第3芸能课”“新人制作人”“游乐园巡游”“伴舞”等工作；第18卷进一步出现短篇电视剧工作、跨单位联合Live企划、制作人与成员之间的运营裂痕。
- 来源：
  - https://cycomi.com/title/46
  - https://cycomi.com/book/706
  - https://cycomi.com/book/20303
  - https://cycomi.com/info/1364

## 是否真正进入偶像职业机制
**是，职业度 10/10。**
它不是“有偶像设定的少女群像”，而是把弱势小单位放进真实的艺能事务所结构里长期运营：制作人、接工作、伴舞、巡游、电视、联合Live、单位协作、成员成长与公众舞台共同构成发动机。

## 新母型
**低优先级单位长期经营型：不是争一次出道，而是把“边缘小单位”经营成可持续的职业共同体。**

和现有《Feeding the Lives of Failing Idols》不同：后者偏“外行业经营者拯救失败团体 / comeback”；U149不是临危接管，而是从弱小起点持续积累工作、舞台、成员关系与制作能力，重点是**长期职业化本身**。

## 十元
- 主符号：**xn** —— 事务所、工作分配、制作流程、舞台机会等职业规则长期规定成长节奏。
- 次符号1：**nz** —— 制作人与成员、成员之间的共同体关系是规则真正能运转的缓冲层。
- 次符号2：**zx** —— 从被分配小工作，到主动争取更大企划、跨单位Live，行动逐步扩大。
- 次符号3：**x并z** —— “小女孩”被职业空间塑造成可被观众承认的偶像身份。
- 暗层：**zn + x** —— 每个成员如何在职业角色中形成“我是谁”，并处理年龄/身体条件与偶像资格之间的关系。

## 体量 1–10
- xn：10
- nz：9
- zx：8
- x并z：8
- n：8
- zn：7
- x：7
- nx：6
- z：6
- xz：4

## 顺序链
**xn → nx → nz → zx → x并z → n → zn**

解释：
第3芸能课先以xn划定低优先级职业位置 → 成员承受小工作/被安排的nx → 制作人与成员形成nz共同体 → 共同体生出主动争取舞台的zx → 公众偶像身份x并z逐渐成立 → 跨单位关系n扩大职业空间 → 每个人的zn在长期职业中被重新定义。

## 五维
- 时间：**xn + z** —— 小工作、积累、升级、企划推进构成长周期职业时间。
- 本体：**zn + x** —— 年龄、身体、个人能力与“我能否成为偶像”互相定义。
- 空间：**x并z + n** —— 事务所、舞台、游乐园、电视、联合Live形成被观看与协作空间。
- 因果：**zx + nx** —— 一方面被事务所安排，一方面成员/制作人逐渐主动创造机会。
- 命运：**xz + nz** —— “小单位/低优先级”的结构压力，由稳定共同体持续软化。

## 生链
1. **xn → nz**：职业制度把成员与制作人绑在同一单位，迫使共同体成立。
2. **nz → zx**：信任与协作产生更主动的职业行动。
3. **zx → x并z**：实际工作与舞台积累，制造更稳定的公众偶像身份。
4. **x并z → n**：身份被外部承认后，才有跨单位、电视、联合Live等更大关系网络。

## 克链
1. **xn 克 zx**：单位层级与工作分配限制个人/团体能主动做什么。
2. **nx 克 zn**：长期只能接受小工作，会让成员怀疑自己的偶像资格。
3. **nz 反克 nx**：制作人和成员共同体把“被安排”转成“共同完成”。
4. **zx 反克 xn**：主动企划和职业成果最终能扩大制度允许的空间。

## 反咬点
**长期运营越成功，团体越不能只靠“关系好”成立。**
第18卷官方简介已经直接出现：成员因为太亲密而被外部指出问题，制作人主动推动跨单位Live时又与不安成员产生裂痕。也就是说，nz共同体曾经是成长引擎，规模扩大后却可能反过来妨碍更高阶职业化。

这形成：
**nz生职业 → 职业扩大 → xn/n要求更复杂协作 → 原有nz被迫重构。**

## 5组补子
- **xn + z**：职业规则只有经过长期积累与持续梦想才产生成长，而不是一次选秀即完成。
- **zn + x**：成员的自我认同必须通过现实年龄、身体、能力与工作反馈落地。
- **x并z + n**：偶像公众身份必须在舞台、电视、联合单位等关系空间被反复确认。
- **zx + nx**：偶像既主动争取机会，也永远处于被事务所、制作与市场安排的位置。
- **xz + nz**：低优先级/弱势单位的结构压力，需要稳定的制作人—成员共同体抵抗。

## 偶像机制
- 练习：有。
- 事务所/制作人：极强。
- 工作分配：极强。
- 舞台/Live：极强。
- 团体运营：极强。
- 电视/外部工作：有。
- 跨单位合作：有。
- 粉丝/公众承认：持续存在。
- 长期成长：核心。

## 成为偶像的欲望与代价
- 欲望：让原本处于弱势位置的小成员真正被作为偶像承认。
- 成功代价：职业规模越大，原先靠亲密关系维系的小共同体越必须接受制度化、专业化与关系重排。
- 失败代价：不仅是“没有出道”，而是长期处在事务所内部却始终无法从边缘工作升级为真正职业身份。

## 视觉符号
- 第3芸能课办公室
- 小型工作现场
- 游乐园巡游/伴舞
- 制作人站位与成员队形
- 联合Live舞台
- 后台与前台之间的门
- 多单位交叉站位

## 与已有样本差异
- vs《Idol × Idol Story!》：后者重“重新选择偶像梦想/选拔”；本作重“出道后的长期事务所经营”。
- vs《Feeding the Lives of Failing Idols》：后者是糊团危机再生，本作是弱势单位从低阶工作持续升级。
- vs《AKB49》：后者制度密度高但核心有秘密身份与研究生规则，本作更纯粹研究“制作人与女团长期职业化”。

## 矿级
**S。**
理由：补足当前母库最明显的“女团长期运营”缺口，而且不是靠系统/回归推动，是少见的持续职业结构样本。

# 2. If My Favorite Pop Idol Made It to the Budokan, I Would Die｜日漫｜S
（日文：推しが武道館いってくれたら死ぬ）

## 基础核验
- 英文授权出版社：TOKYOPOP。
- 官方第1卷：地下偶像团体 ChamJam；Maina 是团内最低人气成员，Eripiyo 用大量购买与活动参与持续支持她。
- 官方第5卷：新粉丝增加、团体前往东京、从地下偶像向全国曝光过渡；成功同时制造粉丝与成员的不安。
- 官方第8卷：CD、粉丝见面会、视频频道、电视节目、与高人气 Maple Dolls 合作、病毒式涨粉等职业机制明确存在，并直接提出“爆红中容易失去自己”。
- TOKYOPOP 2026年发行表列第11卷于2026年4月28日发行。
- 来源：
  - https://tokyopop.com/products/9781427873408_if-my-favorite-pop-idol-made-it-to-the-budokan-i-would-die-volume-1
  - https://tokyopop.com/products/9781427875341_if-my-favorite-pop-idol-made-it-to-the-budokan-i-would-die-volume-5
  - https://tokyopop.com/products/9781427878144_if-my-favorite-pop-idol-made-it-to-the-budokan-i-would-die-volume-8
  - https://tokyopop.com/pages/release-calendar

## 是否真正进入偶像职业机制
**是，职业度 10/10。**
主视角虽大量来自粉丝，但 Maina/ChamJam 是持续职业主体，且作品明确展示地下偶像如何通过销售、见面会、视频、电视、合作、粉丝增长与城市扩张改变职业位置。

## 新母型
**粉丝劳动外置型：粉丝不进入职业，却以购买、应援、活动参与和传播直接构成偶像职业基础设施。**

这与R09《Idolatry》形成非常干净的镜像：
- 《Idolatry》：**粉丝nz → 自己跨入职业xn/x并z**。
- 本作：**粉丝始终留在职业外部，却持续为偶像制造n/x并z/市场价值。**

## 十元
- 主符号：**nz** —— 粉丝与偶像之间的持续关系，是职业机器最重要的能量源。
- 次符号1：**x并z** —— 偶像作为被观看、被消费、被传播的公众身份。
- 次符号2：**xn** —— CD、见面会、地下偶像运营、视频、电视、合作等职业规则。
- 次符号3：**n** —— 粉丝群扩大、东京市场、与其他团体合作构成网络扩张。
- 暗层：**zn** —— 当最低人气成员突然爆红，“我是谁”开始被新公众认知反向改变。

## 体量 1–10
- nz：10
- x并z：10
- n：9
- xn：9
- zn：8
- nx：7
- zx：7
- z：7
- x：6
- xz：5

## 顺序链
**nz → xn → nx → zx → x并z → n → zn**

解释：
粉丝—偶像关系nz持续投入 → 通过地下偶像规则xn转化为购买/活动/曝光 → Maina最初处于低人气nx → 团体持续职业行动zx → 公众身份x并z扩大 → 新粉丝、东京、电视、合作形成n → 爆红反过来逼出zn本体问题。

## 五维
- 时间：**xn + z** —— 长期应援、活动、职业积累把“想让推成功”的执念转成可见成长。
- 本体：**zn + x** —— 偶像本人如何在现实性格/日常自我与公众角色之间保持连续。
- 空间：**x并z + n** —— 地下场馆、东京、电视、视频频道、合作团体共同构成被观看空间。
- 因果：**zx + nx** —— 团体主动营业与粉丝主动应援，同时又受市场热度和人气排序支配。
- 命运：**xz + nz** —— 低人气/爆红带来的职业波动，由长期粉丝关系提供稳定锚点。

## 生链
1. **nz → xn**：粉丝关系通过CD、周边、见面会等制度化消费转成职业收入与热度。
2. **xn → x并z**：运营机制把成员持续包装/曝光成公众偶像身份。
3. **nz → n**：一个核心粉丝的长期应援逐渐扩散为更大的粉丝网络。
4. **n → x并z**：粉丝越多、合作与媒体越广，偶像公众身份越强。

## 克链
1. **nx 克 zn**：长期低人气会让成员难以建立稳定职业自信。
2. **x并z 克 zn**：爆红后，公众认知又可能覆盖日常的自己。
3. **n 克 nz**：粉丝群扩大后，最初极私密的一对一支持关系被稀释。
4. **nz 反克 x并z**：长期核心粉丝关系可以在爆红时帮助偶像保持自我锚点。

## 反咬点
**粉丝最成功的应援，可能正是摧毁“我和偶像之间原有关系”的东西。**

当偶像从地下小团走向全国曝光，原本“我支持一个没人看见的人”的nz关系，被更多粉丝、媒体与市场n接管。粉丝希望偶像成功，但成功意味着自己从“重要支持者”变成“众多粉丝之一”；偶像则从“被少数人理解的自己”变成必须维持更厚公众身份x并z的人。

因此形成强反咬：
**nz生成功 → 成功生n/x并z → n/x并z反克原始nz。**

## 5组补子
- **xn + z**：偶像梦想和粉丝执念必须通过一次次活动、销售、曝光才能累计。
- **zn + x**：偶像需要在真实日常自我与职业身体/表现之间维持自我连续。
- **x并z + n**：公众偶像身份只有在粉丝群、媒体、其他团体和城市网络里才成立。
- **zx + nx**：偶像/粉丝都主动应援与营业，却又受人气、市场与平台反向支配。
- **xz + nz**：职业热度高度不可控，稳定关系成为抵抗波动的情感锚。

## 偶像机制
- 地下偶像团体：核心。
- CD/周边购买：强。
- 粉丝见面会：强。
- 线下应援：强。
- 人气高低：核心。
- 新粉丝增长：核心。
- 视频频道：有。
- 电视节目：有。
- 高人气团合作：有。
- 地方→东京/全国曝光：有。

## 成为偶像的欲望与代价
- 偶像侧欲望：被更多人看见，让团体进入更高层级舞台。
- 粉丝侧欲望：让“推”获得她应有的成功。
- 成功代价：规模扩大稀释原始亲密关系，并让偶像承担更厚的公众人格。
- 失败代价：长期停留地下/低人气，职业存在本身可能依赖极少数核心粉丝支撑。

## 视觉符号
- 小型地下Live场
- CD堆/周边
- 握手/粉丝见面会排队
- 单个粉丝与空旷队列
- 人气成员队列长度差
- 东京城市/更大舞台
- 视频频道界面
- 电视镜头
- “一人应援”逐渐变成“人海”

## 与已有样本差异
- vs《Idolatry》：本作粉丝不进入偶像职业，研究的是**外部粉丝如何成为职业基础设施**。
- vs《我推的孩子》：后者更偏公众形象与娱乐工业谎言；本作更细致呈现地下偶像—核心粉丝—人气扩大之间的关系经济。
- vs《U149》：U149从事务所/制作人内部看长期运营；本作从粉丝端看职业价值如何被购买、应援和传播制造。

## 矿级
**S。**
理由：不仅是“追星恋爱/百合感”，而是能补出当前母库缺少的**粉丝经济→职业身份→关系反噬**完整闭环。

# R10母型新增
1. **低优先级单位长期经营型**：边缘小单位不是靠一次逆袭，而是在事务所制度中通过工作积累、制作协作、Live与跨单位关系慢慢职业化。代表：U149。

# R10对理论库的新增价值
R09解决的是“粉丝进入职业系统”；R10补全了另一半：**粉丝留在系统外部，也能通过市场行为塑造偶像本体。**
同时，U149把研究尺度从“怎么出道”推进到“出道以后如何长期成为一个职业共同体”。
