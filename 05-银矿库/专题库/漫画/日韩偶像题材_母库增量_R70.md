# 日韩偶像题材｜母库增量 R70

> 本轮去重后新增《Pretty Rhythm: Dear My Future》。本作核心样本选择韩国留学生5人组 PURETTY：她们不是无职业欲望的素人，而是带着明确的日本出道目标跨市场进入 Pretty Top，在异国训练、等待出道、接受大舞台与竞赛检验。重点不是“外国人设”，而是“旧能力跨市场后必须重新合法化”。

## 《Pretty Rhythm: Dear My Future / プリティーリズム・ディアマイフューチャー》｜日本TV动画｜S

### 1. 基础卡
- 媒介：2012—2013，日本TV动画，全51话。
- 核心样本：韩国5人留学生组 PURETTY（ヘイン、シユン、ジェウン、チェギョン、ソミン）。
- 偶像身份如何建立：5人在韩国已经以日本出道为目标接受训练，跨国来到 Pretty Top 留学；她们一边适应新环境、一边持续训练，直到以 PURETTY 正式出道，并在 P-nation、Symphonia Selection 等舞台持续竞争。
- 核心职业矛盾：在原环境里“会唱、会跳、是练习生”不等于进入另一市场后立刻拥有有效职业身份；旧能力必须经过新市场的规则、观众、舞台和关系重新确认。
- 矿级：S。

### 2. 本轮新增母型
## **跨市场出道 / 职业能力重新合法化型**

不是：
`素人 → 训练 → 出道`

而是：
`已有训练/明确职业欲望 → 跨国迁移 → 旧能力进入新市场 → 重新训练/适应 → 延迟出道 → 新观众/新竞争 → 本地职业身份成立`

核心公式：

> **旧x × 新xn适配率 × 新nz承认 = 新市场有效职业能力**

因此：
**能力可以携带，职业合法性不能原样携带。**

### 3. 十元体量
- **xn 10**：留学、训练、出道、舞台、赛事、中心位、服装/节目规则构成新市场职业制度。
- **x并z 10**：韩国练习生/留学生/日本市场新人/PURETTY成员多重社会身份叠加。
- **zx 9**：主动跨国、持续训练、争夺舞台与排名。
- **n 9**：5人内部关系、Prizmmy☆竞争与友谊、教练和设计师关系共同塑造成长。
- **nz 9**：新市场观众、同业认可、伙伴反馈持续为新身份回填承认。
- **x 9**：歌唱、舞蹈、舞台表现以及成员差异化能力。
- **nx 9**：出道延迟、陌生环境、大舞台压力、新市场评价标准持续反压。
- **z 8**：韩国训练史、留学经历、日本舞台结果共同构成跨市场履历。
- **zn 8**：从“我是来日本出道的人”转向“我究竟凭什么在这里成为顶级Prism Star”。
- **xz 6**：宏观命运压力较弱，主要压力来自职业制度和关系网络。

主元：**xn + x并z**
次元：**zx + n/nz**
反压：**nx + zn**

### 4. 顺序链
**z旧训练 → zx跨市场 → x并z留学生候选身份 → xn本地规则 → nx出道延迟 → x重新显影 → n/nz本地关系 → zx持续竞争 → 新x并z → zn回写**

韩国训练史 z
→ 主动赴日 zx
→ “韩国留学生/候选偶像”身份 x并z
→ Pretty Top训练、舞台与竞赛 xn
→ 迟迟未定出道的 nx 压力
→ 唱跳与个体长处 x 在新环境重新显影
→ 与 PURETTY、Prizmmy☆、教练、观众形成 n/nz
→ 主动继续竞争 zx
→ PURETTY作为日本市场职业单位成立
→ “我不仅是外来练习生，而是在这里真正成立的偶像”进入 zn。

### 5. 五维
#### 时间｜xn + z：10/10
重点不是一天“海外出道”，而是韩国训练史 → 日本留学 → 出道延迟 → 正式出道 → 大型舞台 → 连续赛事。旧履历和新履历连续，而不是换国家就清零。

#### 本体｜zn + x：9/10
真正的问题不是“我会不会唱跳”，而是“这些能力在新的职业世界里能不能继续代表我”。

#### 空间｜x并z + n：10/10
韩国原训练环境、Pretty Top、P-nation、各地比赛构成不同职业空间；同一主体的社会位置会随市场变化重新计算。

#### 因果｜zx + nx：10/10
主动跨国追梦，但新市场不会因为旧努力自动发放出道资格；越主动进入陌生市场，越要接受新规则的反压。

#### 命运｜xz + nz：8/10
决定路线的更多是伙伴、对手、教练、观众和公司关系，而非超自然命运。

### 6. 偶像职业机制
- **训练**：跨国留学后继续课题曲、歌唱、舞蹈和舞台训练；不是把韩国训练直接兑换成日本出道。
- **出道**：前期长时间处于“已经来日本追梦、但仍未决定出道”的悬置状态；之后以 PURETTY 正式出道。
- **竞争**：与 Prizmmy☆ 等在 Symphonia Selection 等连续赛事中竞争。
- **舞台**：P-nation 等大型舞台承担“新人是否能承受顶级现场”的公开检验功能。
- **粉丝**：新市场的公众承认必须重新累积，旧训练背景不能替代新观众关系。
- **公司**：韩国所属事务所与日本训练/舞台环境共同决定职业路线，形成跨组织职业链。

### 7. 主角欲望与代价
- 表层欲望：在日本正式出道并成为下一代顶级 Prism Star。
- 深层欲望：证明“从别的市场来”不是临时访客，而能真正成为这里的一员。
- 代价：原有能力必须接受陌生标准重新检验；身份差异本身会制造更高可见度，也会制造更高比较压力。
- 失败代价：不仅是某场比赛输掉，还可能意味着跨国迁移本身被解释为“没有适配成功”。

### 8. 关系结构
**PURETTY内部**：同为跨市场迁移者，共享适应压力；n同时承担情感支持与职业互补。

**PURETTY ↔ Prizmmy☆**：竞争者 + 同代参照组。对方既制造 nx，也提供“新市场到底要求什么”的实时反馈。

**事务所/教练 → PURETTY**：旧公司保留职业期待，新环境负责把期待转成具体训练和舞台标准。

**PURETTY ↔ 日本观众**：真正决定“留学生组合”是否转化成“本地成立的职业偶像”的社会确认层。

### 9. 动态链
#### 链A｜能力重新合法化
**旧x → 换xn → 有效x下降/失配 → zx适应 → 新nz确认 → 新x并z**

能力没有消失，只是失去原环境的默认支撑。

#### 链B｜外来差异双刃化
**x并z外来身份 → 可见性↑ → 比较↑ → nx↑ → 差异x重新包装 → 新识别度**

“外国留学生”可以带来注意力，也会让每次失误更容易被归因于“不适应”。

#### 链C｜竞争者作为本地校准器
**n同代竞争 → nx差距显影 → x修正 → zx追赶 → nz尊重/友谊 → n升级**

对手不只是障碍，也告诉角色自己到底离本地标准还有多远。

### 10. 最大反咬点
#### 反咬1｜旧训练越扎实，越容易误判“我应该马上成立”
长期训练会制造合理自信，但跨市场以后，如果迟迟未能出道，会产生更强落差：
**旧z努力↑ → 预期↑ → 新市场延迟↑ → zn怀疑↑**。

> 旧资本越厚，不代表迁移成本越低；有时只是让失配更刺眼。

#### 反咬2｜跨市场成功会反过来改写“原本的自己”
一旦新市场里的舞台、观众和竞争关系成立：
**新xn实践 → 新z → 新nz → 新x并z → 反写旧zn**。

最后角色不再只是“韩国来的练习生”，而会把跨市场经历本身纳入自己的职业本体。

#### 反咬3｜适应得太彻底，也可能损失差异资本
如果为了本地化把所有外来特征磨平：
**适配↑ → 同质化↑ → 独特识别度↓**。

真正成熟的迁移不是完全复制本地，而是：
**保留旧x差异 + 学会新xn表达方式**。

#### 反咬4｜竞争对手越像“本地标准”，越容易从敌人变成老师
Prizmmy☆既是同位竞争者，也是最直接的本地职业参照。

于是：
**n竞争 → nx压力 → x学习 → zx追赶 → nz尊重**。

竞争关系本身成为非正式训练制度。

### 11. 五组补子
1. **旧市场能力x ↔ 新市场规则xn**：能力能带走，评价语法必须重学。
2. **外来身份x并z ↔ 本地承认nz**：身份差异制造注意力，但承认必须重新累积。
3. **主动迁移zx ↔ 出道延迟nx**：越主动跨出去，越要承担陌生规则的反推。
4. **同代竞争n ↔ 同代学习n**：竞争者也是最准确的本地标准校准器。
5. **保留差异zn ↔ 适应环境xn**：完全不适应会失败，完全同化又会失去独特性。

### 12. 视觉符号
- 韩国练习室 ↔ 日本 Pretty Top 训练空间
- 行李箱/机场/留学服装 ↔ 正式舞台服
- “未定出道”的训练期 ↔ PURETTY正式团体Logo/舞台
- 两组新人并排练习 ↔ 同台竞争
- 小训练室镜面 ↔ P-nation大型舞台灯海
- 韩语/日本语环境切换、陌生城市街景
- 五人一起训练的背影 ↔ 面向日本观众的正面舞台

最强视觉对子：
> **“带着旧履历来到新世界的人” → “被新世界重新承认的人”。**

### 13. 可复用母题
- **跨市场职业迁移**：职业者换国家/行业生态后重新当新人。
- **能力重新合法化**：能力本身没变，但必须通过新制度重新证明。
- **外来差异双刃化**：差异既是曝光资产，也是比较压力。
- **竞争者作为本地校准器**：对手承担非正式导师功能。
- **适应不等于同化**：真正成功是保留旧差异并学会新环境的表达语法。
- **职业身份跨空间重建**：旧身份不能直接复制，新社会必须重新给出承认。

### 14. 与既有矿的边界
- **R64《Innocent Blue》**：媒介迁移，网络成熟者进入现实舞台，重点是“媒介改变有效能力”。
- **R43《Chance Pop Session》**：正规制度封路后去制度外自证，再回流。
- **R38《SideM》**：成熟旧职业转译成第二职业。
- **R70《Dear My Future》**：同一职业目标不变，但跨国家/市场后，旧训练与旧职业资本必须重新适配新的规则、竞争、公司和公众。

### 15. 本轮矿核
> **职业能力并不是装在身体里、走到哪里都自动等值兑换的货币。换一个市场，同样的唱功、舞蹈、经验和野心会被新的规则重新定价。真正的跨市场成长，不是把旧自己全部丢掉去模仿本地，而是学会新的职业语法，同时保住只有旧路径才能提供的差异。**
