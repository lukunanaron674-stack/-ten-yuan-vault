# 日韩偶像题材母库增量 R98

## 《ミリオンドール / Million Doll》

- 媒介：日本WEB漫画 → TV动画
- 核心对象：地方偶像「イトリオ」、地下偶像「マリ子」、在宅偶像宅「すう子」、现场系偶像宅「リュウサン」
- 矿级：**A矿；核心机制S级**
- 核心分类：**粉丝中介职业化 / 注意力经纪型**
- 去重：2026-08-24 检索仓库，未发现既有独立条目

---

## 1. 为什么进入核心增量

《Million Doll》不是典型的“主角本人从练习生一路出道”的单线故事，而是把偶像职业成长拆成两端同时运行：

1. 偶像本人持续Live、争夺观众、提高舞台与知名度；
2. 粉丝不只是消费和投票，而会主动写博客、组织应援、制造话题、把注意力从一个小圈层搬运到更大的公共空间。

官方简介明确写出：引きこもり偶像宅“すう子”擅长仅靠博客让女性偶像走红；她此前曾把地下Solo偶像鎌倉ひなみ推到Major Debut，之后又盯上福冈地方偶像イトリオ，并用自己的热门博客帮助她们扩大话题。与她相对的现场系偶像宅リュウサン，则用现场应援网络去推地下偶像マリ子。

因此本作最适合补的不是“粉丝喜欢偶像”，而是：

> **粉丝如何成为职业注意力的中介节点。**

---

# 2. 偶像身份如何建立

イトリオ和マリ子都不是零身份素人，她们已经拥有地方/地下偶像身份，但这个身份的社会体量很小。

因此真正的成长目标不是：

> 非偶像 → 偶像

而是：

> **小圈层偶像 → 更大公共空间中的职业偶像。**

身份扩张依赖四层共同作用：

- **x**：本人舞台、歌、角色识别度；
- **xn**：Live、唱片、事务所、Major Debut等行业规则；
- **nz/n**：粉丝、现场组织者、博客传播者形成支持网络；
- **x并z**：网络话题度、地方偶像/地下偶像/主流偶像等公众标签。

所以：

> **职业能力存在，不等于职业可见性存在。**

偶像必须先被一个足够大的社会网络持续看见，能力才有机会进入更高层职业因果链。

# 3. 十元体量

| 十元 | 体量 | 本轮功能 |
|---|---:|---|
| **nz** | **10** | 粉丝情感不是终点，而是推广行为发动机 |
| **n** | **10** | 在宅粉丝网络、现场粉丝网络直接形成职业传播结构 |
| **x并z** | **10** | 地方/地下/主流偶像身份取决于被多少社会空间识别 |
| **zx** | **9** | 偶像本人和核心粉丝都持续主动扩大职业空间 |
| **xn** | **9** | Live、Major Debut、行业机会决定职业升级 |
| **x** | **9** | 真正舞台表现决定注意力能否留住 |
| **nx** | **9** | 曝光竞争、粉丝竞争、市场注意力稀缺持续反压 |
| **z** | **8** | 每次Live、传播、粉丝积累形成不可逆职业历史 |
| **zn** | **8** | 偶像与粉丝都必须回答“我为什么继续做这件事” |
| **xz** | **6** | 强宿命弱，主要靠社会传播机制推进 |

主元：**nz + n + x并z**

次元：**zx + xn**

---

# 4. 顺序

核心顺序：

**nz → zx → n → x并z → xn → x → nz扩大 → nx反咬 → 新x并z**

展开：

1. 某个粉丝被小偶像真正打动（nz）；
2. 不满足于自己喜欢，开始主动推广（zx）；
3. 博客读者、现场粉丝、应援圈形成传播网络（n）；
4. 偶像从“小范围存在”变成“越来越多人知道的名字”（x并z）；
5. 更大的关注带来新Live、Major机会、行业比较（xn）；
6. 偶像必须用真实舞台能力把注意力留下（x）；
7. 新观众变成新粉丝（nz扩大）；
8. 公众期待、粉丝派系、竞争叙事开始反压偶像与支持者（nx）；
9. 偶像身份被重新放大、重新定义（新x并z）。

---

# 5. 五维

## 时间维 xn + z：9/10

偶像不会因为一次“爆文”自动完成职业升级。

网络话题只能制造入口，真正职业化仍然依赖：

- 多次Live；
- 粉丝持续出现；
- 新观众留下；
- 行业持续关注；
- 过去成绩不断沉淀。

所以：

> **热点可以制造瞬时可见性，只有z才能把可见性压成职业历史。**

## 本体维 zn + x：9/10

粉丝可以告诉全世界：

> “这个偶像值得看。”

但不能替偶像完成舞台，也不能永久决定偶像应该成为什么样的人。

因此本体问题是：

> **公众最先认识我的那个版本，究竟是不是我愿意长期成为的版本？**

## 空间维 x并z + n：10/10

这是本轮绝对主维。

小Live现场、地方商场、地下偶像圈、博客、SNS式扩散、大型公众空间不是背景，而是职业升级链本身。

同一偶像在不同空间里会被解释成：

> 无名地方偶像 → 小圈层热门 → 网络话题对象 → 更大职业候选。

## 因果维 zx + nx：10/10

粉丝主动推人（zx），但平台注意力、粉丝竞争、行业机会又不断产生nx。

职业成长表现为：

> **主动制造曝光 → 曝光带来更大的评价与压力 → 再主动回应。**

## 命运维 xz + nz：8/10

没有强超自然命运，关系偶然性却很强：

> 某个真正有传播能力的人偶然在某个小现场看见你，可能改变整条职业路线。

---

# 6. 训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

## 训练

作品不把训练做成传统学院式主线，而更强调真实Live中持续校正：

- 小舞台反复表演；
- 现场反馈；
- 人气变化；
- 竞争偶像带来的比较压力。

## 出道 / 升格

重点不是“第一次成为偶像”，而是：

> **地方/地下身份如何向Major身份升级。**

鎌倉ひなみ已经提供过“网络粉丝推动 → Major Debut”的前例，因此职业升级的社会传播机制被直接放进世界观。

## 竞争

不是只有偶像A vs 偶像B。

还有：

> **支持A的粉丝网络 vs 支持B的粉丝网络。**

职业竞争因此扩张为：

**舞台竞争 + 注意力竞争 + 传播网络竞争。**

## 舞台

舞台负责回答：

> **网络给你送来了人，你能不能让这些人下次还来？**

所以舞台是把“借来的注意力”转成“自己的粉丝”的转换器。

## 粉丝

这是本轮核心。

粉丝存在至少四层：

1. 消费者；
2. 评价者；
3. 应援者；
4. **传播中介 / 注意力经纪人。**

第四层是本轮真正新增。

## 公司 / 行业

正式行业并没有消失。

网络与现场粉丝可以制造足够大的职业信号，但Major Debut、唱片与大型行业资源仍由正式xn承接。

因此：

> **粉丝网络可以迫使行业重新看见某个人，却不能完全替代行业基础设施。**

---

# 7. 主角欲望与代价

## すう子

欲望：

> “我要让自己发现的偶像被更多人看见。”

代价：

- 情绪越来越绑定偶像成绩；
- 推广成功后偶像会进入自己无法控制的更大社会；
- 容易产生“是我把你推上去的”式所有权幻觉。

## イトリオ / マリ子

欲望：

> 从地方/地下阶段进入更大职业空间。

代价：

- 更多曝光意味着更多比较；
- 粉丝帮助塑造公众标签，也可能固定公众标签；
- 职业越大，越无法只对最初的小圈层负责。

---

# 8. 关系结构

核心不是单纯“偶像 ↔ 粉丝”。

而是：

**偶像A ← 推广者A ← 粉丝网络A**

对

**偶像B ← 推广者B ← 粉丝网络B**

因此一个粉丝也可能拥有自己的n中心性。

すう子与リュウサン不是正式Producer，却分别承担部分：

- 宣传；
- 组织；
- 议题制造；
- 粉丝动员；
- 注意力搬运。

可以暂称：

> **非官方Producer / 分布式推广者。**

---

# 9. 动态链

## 动态链A｜粉丝中介职业化

**nz喜欢 → zx推广 → n传播网络 → x并z可见性 → xn行业机会 → 新x并z职业升级**

核心：

> **nz不只提供情感，可以通过zx与n进入职业生产。**

## 动态链B｜借来的注意力转成自己的粉丝

**推广者带来曝光 → 新观众出现 → 舞台x接受检验 → 一部分观众留下 → 新nz形成**

核心：

> **传播者只能把人带到门口，偶像本人必须让人留下。**

## 动态链C｜支持反锁

**核心粉丝帮助成功 → 偶像公众身份扩大 → 核心粉丝产生所有权感 → nx控制欲上升 → 偶像zn受压**

核心：

> **帮助你成功的人，不因此拥有你的职业所有权。**

---

# 10. 反咬点

## 反咬1｜把你推红，也把你推远

最初粉丝希望：

> “更多人认识她。”

真正成功后：

**更多人认识**
→ 更大公司/舞台介入
→ 更复杂公众关系
→ 原核心粉丝不再特殊。

所以：

> **推广成功，本身会破坏最初那种“小圈层亲密感”。**

## 反咬2｜“我发现了你”容易滑成“你属于我”

推广者可能逐渐把：

> “我帮过你。”

错误转换成：

> “所以你应该按照我理解的方式继续发展。”

正式规则：

> **助推权 ≠ 解释权 ≠ 所有权。**

## 反咬3｜网络最先放大的特征，会变成职业牢笼

博客传播最适合抓一个简单卖点。

一旦某个特点爆红：

**传播效率↑ → 标签固定↑ → 公众期待↑ → nx↑**

于是：

> **最容易让新人被看见的标签，也可能成为以后最难脱掉的标签。**

## 反咬4｜流量可以制造入口，不能制造全部职业能力

网络能把100个人带到Live。

但：

> **第二次还有没有100个人来，只能由真实职业结果回答。**

因此：

**传播能力 ≠ 偶像能力。**

两者必须接起来，职业身份才稳定。

---

# 11. 本轮新增十元规则

### 规则1｜nz可以职业生产化

> **nz私人喜欢 → zx公开推广 → n传播网络 → x并z扩大。**

粉丝关系不只消费结果，也可以参与制造结果。

### 规则2｜注意力是中介资产

> **拥有注意力分配能力的人，即使没有公司职位，也可能取得部分xn功能。**

### 规则3｜传播权不等于身份所有权

> **能帮助别人获得公众身份，不等于拥有这个公众身份的解释权。**

### 规则4｜舞台是注意力转化器

> **外部流量 → x真实表现 → nz留存。**

曝光只能借，粉丝必须重新挣。

### 规则5｜粉丝网络也存在竞争结构

> **偶像竞争可以向外扩张成“谁的支持网络更能组织注意力”的竞争。**

---

# 12. 视觉符号

最适合入视觉库的符号：

- 黑暗房间里的电脑屏幕 ↔ 明亮的小型Live舞台；
- 一个博客帖子 ↔ 越来越多人挤进现场；
- 地方超市/小活动场 ↔ 初次One-Man Live；
- 空旷观众区 ↔ 荧光棒逐渐增多；
- 屏幕上的名字/搜索热度 ↔ 舞台上真正的人；
- すう子在电脑后敲键盘 ↔ リュウサン站在人群前组织应援；
- 同一位偶像同时被“网络流量”和“现场声浪”拉向两个方向。

最强视觉对子：

> **粉丝坐在舞台之外，却通过一台电脑或一群人的应援，改变舞台上谁会被更多人看见。**

---

# 13. 可复用母题

1. **粉丝→非官方Producer**：没有正式职位，却能分配注意力。
2. **小圈层→大众职业升级**：能力已经存在，真正缺的是社会可见性。
3. **网络传播→现实舞台验证**：线上把人带来，线下决定人能否留下。
4. **帮助成功→失去特殊性**：偶像越红，早期核心粉丝反而越普通。
5. **注意力所有权幻觉**：推广者错误认为“我让你成功，所以我有权决定你”。
6. **支持网络竞争**：偶像之间的战争向粉丝组织层扩散。
7. **标签先于本体成熟**：网络先给新人固定一种公众解释，人物之后才发现自己被标签追着跑。

# 14. 与已有母型的边界

- **SELECTION PROJECT**：粉丝/公众主要作为**投票裁决者**。
- **Dream Festival!**：粉丝应援直接进入舞台，属于**观众共演**。
- **I★CHU**：购买量被学校计入资格，属于**市场考官**。
- **Kiratto Pri☆Chan**：主体自己经营平台账号，属于**平台自发行**。
- **Million Doll**：

> **偶像之外出现独立的粉丝推广者，通过博客、现场组织与粉丝网络，把注意力主动搬运给某个偶像，承担部分传统Producer/宣传功能。**

因此本轮正式新增分类：

# **「粉丝中介职业化 / 注意力经纪型」**

# 15. 矿级判定

## 作品整体：A矿

原因：

- 偶像成长、地下/地方→更高职业层级非常真实；
- Live、粉丝、传播、Major Debut与竞争机制足够硬；
- 但主叙事视角大量放在偶像宅/粉丝端，并非纯“新人偶像本人一路成长”。

## 核心机制：S级

“粉丝成为注意力经纪节点”在当前母库中具有明确独立性。

---

# 16. 本轮矿核

> **偶像职业并不是“本人有能力，公司就会自动发现”的封闭因果链。很多职业跃迁发生在中间层：有人先看见你，然后主动把自己的注意力、话语权和关系网络借给你，让更多人有机会看见你。可这种帮助真正成熟的前提，是推广者最终承认：自己可以帮一个偶像获得舞台，却不能因此拥有这个偶像。**
