# 日韩偶像题材母库增量 R30

## 本轮新增

- 作品：**《Pretty Rhythm: Aurora Dream / プリティーリズム・オーロラドリーム》**
- 媒介：日本原创TV动画 / 跨媒体偶像企划
- 矿级：**S**
- 核心新增机制：**复合职业拼图型 / 偏科补完型偶像生成**
- 核心问题：当一个职业不是单项技能，而是由多个彼此冲突的能力域组成时，一个只在其中一项有天赋的普通人，如何被迫补齐其余能力，最终长成完整职业身份？

## 一、偶像身份如何建立

春音爱良最初只是喜欢时尚的普通中学生，性格内向、运动能力很差。她并不把自己理解成舞台型人物。因为穿搭协调感被事务所经理发现，又在原定艺人缺席的情况下被半强制推上Prism Show舞台，才第一次获得“Prism Star候选者”的公共身份。

关键不是“她天生就是全能偶像”，而是她只带着**时尚判断**这一块职业拼图入场，唱、跳、滑冰、舞台胆量、竞技经验都需要后补。

身份生成顺序：

**普通中学生 → 被发现局部天赋 → 临时上台 → 候选Prism Star → 正式出道 → 持续比赛/训练 → 团体MARs成员 → Prism Queen竞争者 → 独立职业本体**

## 二、职业机制

### 训练
Prism Show不是单一歌舞，而是把**滑冰、舞蹈、歌唱、时尚搭配、舞台表现**绑成同一个职业制度。爱良运动神经差，因此必须长期训练原本并不擅长的身体能力。

### 出道
爱良并非标准 audition 起步，而是因服装搭配能力被发掘，在活动现场被临时推上舞台，之后事务所直接让她继续作为Prism Star活动。

### 竞争
存在Tiara Cup、Summer Queen Cup、Winter Queen Cup、Prism Queen Cup等连续赛事。职业身份不是一次出道完成，而是在反复公开排名中持续验证。

### 舞台
舞台本身同时考核穿搭、舞蹈、滑冰和“Prism Jump”。视觉效果不是包装附加项，而是评分和职业能力的一部分。

### 粉丝
粉丝与观众提供社会承认，但真正决定角色职业成长的不是单纯人气，而是“能否不断用新的完整表演兑现期待”。

### 公司
Pretty Top负责发掘、安排出道、训练、比赛与组合。机构拥有入口权，但成员最终需要靠持续实践把机构授予的标签变成自我认领。

### 主次

- 主元：**x + xn**
- 次元：**zx + n**
- 包装结果：**x并z**

### 顺序感谱

**x → nx → x并z → xn → n → zx → z → nz → zn → 新x并z**

解释：

局部天赋先被看见 → 短板立即暴露 → 获得临时职业标签 → 被复合职业制度持续加工 → 团队互补 → 主动追赶 → 赛事节点显影成长 → 关系稳定 → 自我认领 → 完整职业身份成立。

## 四、五维

### 时间维 xn + z：10/10
训练规则与一轮轮赛事共同把“偶然上台”压成真正履历。

### 本体维 zn + x：10/10
核心不是“有没有天赋”，而是：只有一块局部天赋的人，能不能承认并制造一个更完整的自己。

### 空间维 x并z + n：10/10
职业身份必须在事务所、组合、比赛、舞台、观众共同构成的社会空间里成立。

### 因果维 zx + nx：10/10
角色不断处于“短板压我 → 我主动补”的循环，是本作最稳定的成长发动机。

### 命运维 xz + nz：8/10
传奇Prism Jump、顶点竞争提供命运方向，队友与榜样提供关系回收。

## 五、主角欲望与代价

初期欲望并不是“我要成为偶像”，而是对时尚、偶像、美音等已有闪耀对象的兴趣。职业实践之后，欲望被重写为“我要作为Prism Star继续变强”。

代价不是单一辛苦，而是：

**必须把自己最不擅长的身体/竞技能力也纳入自我。**

一个人不能只守着“我擅长这个，所以我就只做这个”，因为职业定义本身要求她接受陌生能力域。

## 六、关系结构

- 爱良：时尚强 / 运动弱
- 律舞：运动强 / 时尚弱
- 美音：初期近乎全能、成熟模板

三人形成非常清楚的互补结构：

**偏科x₁ + 偏科x₂ + 完成模板x₃ → n团队 → 互相暴露短板 → 互相补全 → 三个独立职业本体**

所以n不是“友情装饰”，而是能力拼图的加速器。

## 七、动态链

### 链1：局部天赋扩张成完整职业
**x局部优势 → nx短板暴露 → xn复合职业要求 → zx补短 → 新x能力集合 → x并z完整职业身份**

### 链2：被迫入场转为自主追逐
**nx临时推上舞台 → x并z候选身份 → xn持续实践 → n/nz关系沉淀 → zn认领 → zx主动争冠**

### 链3：团队互补反向生成个人完整性
**x差异 → n组队 → 差异冲突 → 互相学习 → 各自新x → 新zn**

## 八、最大反咬点

### 反咬1：天赋是入口，也是暴露短板的机器

爱良因为时尚天赋被发现。

但越往职业深处走，越证明：

> **单项天赋越亮，其他缺口反而越显眼。**

所以：

**x优势 → 获得入口 → 进入更高xn → nx暴露更多不足 → 必须扩张x**

天赋不是免训练券，而是把人送进更苛刻评价体系的门票。

### 反咬2：职业会逼人纳入自己原本拒绝的部分

爱良最初可以说“我运动不好，所以舞台不是我的世界”。

但一旦要真正成为Prism Star，她不能把运动短板永远划为“这不是我”。

于是：

> **职业成长 = 本体边界扩张。**

不是单纯技能树加点，而是“原本不属于我的东西”逐渐变成“我也可以是这样的人”。

### 反咬3：互补团队最终要求成员独立

团队最初可以靠彼此补短，但顶级竞争终究要求每个人独立完成自己的舞台。

因此：

**n互补 → 暂时弥补x缺口 → xn提高要求 → 无法继续代打 → 个体必须生成新x**

团队不是替你永远遮住短板，而是给你时间把短板长出来。

## 十、可复用母题

### 1. 复合职业拼图
职业本身要求多个不相干能力域：

`画师 = 造型 + 色彩 + 叙事 + 商业沟通`
`导演 = 视觉 + 表演 + 管理 + 技术`
`偶像 = 唱 + 跳 + 外形 + 表达 + 竞技`

故事发动机不是“某项能力从0到100”，而是**多个偏科能力被逼着拼成完整职业人格**。

### 2. 偏科即入口
主角只需要一块特别亮的x，就能进入行业；故事后半段再让行业把剩下的缺口全部追债。

公式：

**尖锐单项x → 获得入口 → xn放大缺陷 → zx补短 → 复合x成立**

### 3. 天赋反噬
天赋把你带到更高层，而更高层开始要求你证明自己不仅只有那项天赋。

### 4. 团队是临时外置器官
队友可以暂时补你的短板，但长期目标是把“外置能力”内化成自己的能力。

### 5. 职业扩张本体边界
真正的成长不只是“我更强”，而是：

> **我过去认为绝不可能属于我的能力和位置，现在也被纳入‘我是谁’。**

## 十一、与既有样本的边界

- 《Aikatsu!》：憧憬先生成职业欲望。
- 《CINDERELLA GIRLS》：别人先发现你的潜力。
- 《Dream High》：制度加工新人。
- 《Extreme Hearts》：通过B领域胜利换回A领域舞台。
- **《Pretty Rhythm: Aurora Dream》：职业A本身就是多个异质能力域的合成体，主角必须从偏科者变成复合职业者。**

所以正式新增分类：

## 「复合职业拼图型 / 偏科补完型」

**局部天赋被发现 → 获得职业入口 → 复合规则暴露其余短板 → 团队暂时互补 → 主体主动补短 → 多项能力合流 → 完整职业本体成立。**

## 十二、矿核

> **真正的职业成长，不是把最擅长的那一项无限放大，而是进入行业以后，被迫把那些原本“不像自己”的能力也一点点长进本体里。**

## 十三、来源核验

- Tatsunoko Production官方作品页：Prism Show是冰舞与音乐剧/走秀融合的复合竞赛，主角们成长为Prism Star。
- TV Tokyo官方角色页：爱良是喜欢时尚的普通中学生，内向、运动不擅长；律舞运动强；美音则在舞蹈、时尚、歌唱上都非常突出。
- TV Tokyo第1话：爱良因穿搭协调能力被经理发现，并被半强制推上活动舞台。
- TV Tokyo第6-7话：爱良运动能力依旧薄弱，在持续训练中反复跌倒，却被事务所正式安排出道。
- TV Tokyo后续赛事：Tiara Cup、Summer Queen Cup、Winter Queen Cup、Prism Queen Cup不断把职业能力公开量化并验证。
