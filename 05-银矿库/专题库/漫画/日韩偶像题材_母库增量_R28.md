# 1. 《Kiratto Pri☆Chan》｜日本TV动画/偶像多媒体企划｜S

## 基础
- 主角：桃山未来、萌黄绘萌，后与青叶铃花形成核心三人组。
- 初始身份：普通中学生，不隶属于传统偶像经纪公司，也不是先通过艺能学校筛选。
- 进入偶像业触发：因为校内既有热门 Pri☆Chan 偶像带来的刺激/对抗，自己开频道，直接开始内容生产与舞台配信。
- 偶像身份如何建立：**不是先被公司承认，而是先创建频道、发布内容、获得观看与人气，再由平台内竞赛、称号与持续活动把“频道主”压成“偶像”。**
- 核心成长目标：从“试试看做频道”升级为“成为顶级 Pri☆Chan Idol”。

## 新母型
### 平台自发行型偶像生成 / 去守门人职业化

传统偶像结构：
**素人 → audition → 公司/学校筛选 → trainee → debut → public**

本作结构：
**素人 → 开频道 → 公开发布 → 观众立即可见 → 内容迭代 → 人气/比赛 → 偶像身份成立**

矿核：
> **职业入口不再由公司先批准，而由“我先公开做出来”启动；社会承认发生在生产之后，而不是生产之前。**

这条与《CINDERELLA GIRLS》的“被 Producer 发现”、与《Dream High》的“制度先训练”、与《SELECTION PROJECT》的“公众投票授予资格”不同：Pri☆Chan 先把发布权下放给普通人，之后才通过流量、比赛、合作和称号继续分层。

## 偶像职业机制
### 训练
不是单一训练学校，而是“做中学”：企划、拍摄/配信、舞台、审美、表演与团队协作在一次次公开发布中迭代。

### 出道
**开频道本身就是微型出道。**
职业入口被拆小：不是一次大型 debut 决定“你是不是偶像”，而是第一次公开发布就开始承担公众身份。

### 竞争
既有热门频道、同龄偶像、Jewel Audition、Princess Cup 等形成多层竞争。竞争不只比唱跳，也比企划、频道吸引力与持续运营。

### 舞台
Live 不是脱离频道的另一个系统，而是频道内容的一部分；“表演”和“传播”合并。

### 粉丝
粉丝不是出道后的附属品，而是从职业早期就存在的身份确认机制。频道越有人看，公众身份越快成立。

### 公司/平台
本作最关键的制度差异是：**平台先提供基础设施，不先垄断资格。**
它不像传统公司先选人再生产，而是允许大量普通人先生产，再通过流量、赛事、称号继续分层。

## 主角欲望与代价
### 欲望
初期：因为竞争/刺激，“我也想做频道”。
中期：希望频道变得更好、组合更有名。
后期：主动追求顶级 Pri☆Chan Idol 与更高称号。

### 代价
- 必须持续公开自己，而不是只在私域试错。
- 每次成长都会留下可比较的公共履历。
- 粉丝与流量既提供存在感，也制造持续更新压力。
- “任何人都能开始”会带来更密集竞争，入口越开放，供给越多。

因此可抽象成：
**低准入成本 → 高持续成本。**

## 反咬点
### 1. 去掉守门人，不等于去掉权力
开始时看起来最自由：任何人都能开频道。
但职业一旦成长，权力会从“公司筛选”转移到：
**平台规则 + 排名 + 观众注意力 + 数据反馈。**

公式：
**守门人消失 → 评价权分布化 → 权力从一次性准入转成持续性算法/公众压力。**

### 2. 入口越容易，持续成为偶像越难
人人能开始意味着竞争者数量暴增。
因此平台时代的新门槛不是“能不能进去”，而是：
> **你能不能连续做出值得别人再次点开的东西。**

即：
**准入门槛下降 → 留存门槛上升。**

### 3. 被看见本来是奖励，后来会变成义务
最初：有人看 = 开心/成功。
后来：已经有人等你更新 = 责任。

**nz支持 → z期待累积 → nx更新压力。**

关系会从燃料反咬成职业义务。

### 4. 自我表达越成功，越可能被成功模板固定
某类内容爆红后，平台与粉丝会希望继续复制。
于是：
**x真实特征 → 成功内容 → x并z公众标签 → nx“请继续这样” → zn被模板挤压。**

成功本身会制造新的模仿压力。

## 5组补子
### 1. xn + z｜平台规则 + 频道历史
平台要求持续生产，旧视频/舞台/比赛结果形成履历；“一直做过什么”逐渐决定频道是谁。

### 2. zn + x｜自我风格 + 可表演能力
个人闪光点必须从模糊性格转成可重复、可传播的内容能力，最终形成自己的频道人格。

### 3. x并z + n｜账号/组合身份 + 关系网络
公众看到的是频道和组合名，但这个身份内部靠成员分工、竞争者、粉丝与平台共同维持。

### 4. zx + nx｜主动发布 + 反馈反推
先拥有前所未有的发布主动权，随后被数据、观众与比赛不断反向塑造。

### 5. xz + nz｜弱命运 + 强关系点火
没有生死强迫，故事主要靠“看见别人、被别人回应、与别人竞争/协作”持续点火，因此 nz 成为替代强 xz 的发动机。

## 可复用母题
### 1. 无守门人职业生成
不必先被选中，先做出来再说。
- 素人画师 → 直接公开连载 → 职业漫画家
- 普通人 → 直播 → 主播
- 无名音乐人 → 自发行歌曲 → 歌手
- 野生研究者 → 公开实验日志 → 被学界承认

公式：
**zx先行 → 作品公开 → nz社会回应 → x并z职业身份。**

### 2. 微型出道
把“出道”从一次仪式拆成很多小节点：
第一条公开作品、第一批粉丝、第一次合作、第一次商业任务、第一次大型舞台。

### 3. 低门槛高持续
入口越平等，竞争越密集；真正的资格从“被选中”转成“能持续”。

### 4. 反馈塑形
观众并非只判断成品，而是在创作过程中实时参与塑造职业人格。

### 5. 自建公众身份
账号、频道、昵称、头像、固定栏目、组合名，本质上都是自己先搭起来的 x并z 容器；持续行动再往里面填本体。

### 6. 平台反咬创作者
平台最初释放 zx，后期通过规则、流量与受众期待制造 nx。

## 与既有S矿的差异
- **CINDERELLA GIRLS**：Producer 先发现你 → 外部招募型。
- **Dream High**：学校先训练你 → 制度加工型。
- **SELECTION PROJECT**：观众投票决定你是否过关 → 公共裁决型。
- **PriPara**：进入另一个制度空间后获得偶像资格 → 双重空间职业化。
- **Love Live!**：为了救学校自己组偶像团 → 自建组织型。
- **Kiratto Pri☆Chan**：**平台把“开始生产”权限直接下放，先公开做，再让社会决定它能否长成职业。**

因此本轮正式新增谱系：

## 「平台自发行 / 去守门人职业生成型」
**关系刺激 → 主动公开 → 自建频道身份 → 持续生产 → 观众反馈 → 平台竞争 → 风格形成 → 职业认领。**

---

## 矿级
**S矿。**

理由不是作品单纯“可爱、偶像、直播”而升S，而是它给整个偶像生成谱系补了一条现代职业机制：
> **传统偶像先取得资格再面向公众；平台偶像可以先面向公众，再用持续行动反过来取得资格。**

这条机制对 VTuber、短视频创作者、独立音乐人、网文作者、独立游戏开发者同样成立，跨题材复用价值极高。

## 本轮矿核
> **当职业入口从“被机构选中”变成“任何人都能发布”以后，职业权力不会消失，只会从一次性的准入权，迁移成持续的注意力、数据和反馈权。**
