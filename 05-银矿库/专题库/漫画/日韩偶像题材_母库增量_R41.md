# 日韩偶像题材母库增量 R41

## 《Lapis Re:LiGHTs / ラピスリライツ》

- 媒介：日本原创TV动画 / 多媒体企划
- 核心样本资格：S矿
- 归类：复合职业制度型 / 职业功能实用化型
- 去重：仓库检索未发现既有独立《Lapis Re:LiGHTs》条目

## 一、本轮新机制

### 魔法职业与偶像职业不是并列，而是同一套制度的两面

本作世界里，使用辉砂/辉石、通过咒语与旋律发动魔法的少女被称为“魔女”；魔女不仅讨伐魔兽，也进行歌唱活动，并因此受到公众憧憬。Tiara进入Flora女学院，本来追求的是“成为优秀魔女”，但她所属小组因低分与退学危机，逐渐把Orchestra（魔法演唱会）变成职业突破口。

因此核心不是“魔法少女顺便当偶像”，而是：

> 唱歌本身就是职业能力的一部分，舞台同时生产公众承认与魔法效能。

这形成现有偶像母库中较少见的“双制度共用同一行动”结构。

## 二、十元体量

| 十元 | 体量 | 作用 |

| xn | 10 | 学院积分、退学制度、魔法训练、Orchestra规则共同塑形 |
| x并z | 10 | 学生/魔女/表演者/组合成员多重公众身份叠合 |
| zx | 9 | Tiara主动提出Orchestra方案、争取许可、带队训练 |
| n | 9 | LiGHTs五人共同承担积分、训练与舞台结果 |
| x | 9 | 魔法、歌唱、体能、知识、舞台表现都作为职业资产 |
| nx | 9 | 退学威胁、积分不足、学院规则持续反推行动 |
| zn | 9 | “我要成为怎样的魔女”逐渐扩展成“我要以何种方式成为魔女” |
| nz | 8 | 队友、观众、前辈与城市共同回填职业意义 |

次元：zx + n + x

## 三、顺序

主链：

**zn → xn → nx → zx → n → x并z → x → nz → xn反咬 → 新zn / 新x并z**

展开：

1. Tiara先拥有“成为优秀魔女”的本体愿望（zn）。
2. 进入Flora女学院，接受学院积分、训练和班级制度（xn）。
3. 小组低分并进入退学危机（nx）。
4. Tiara观看其他组合Orchestra后，主动提出用舞台突破危机（zx）。
5. 五人必须共同训练和承担失败（n）。
6. LiGHTs从普通学习小组向舞台组合身份转化（x并z）。
7. 歌唱、魔法、身体控制、编排等能力被重新组合成完整职业能力（x）。
8. 观众反应、队友关系、前代团体意义进入职业认同（nz）。
9. 即使Orchestra成功，积分仍可能不足，制度继续拥有淘汰权（xn反咬）。
10. 角色重新回答：魔女到底只是通过考试的人，还是能通过自己的方式给他人带来希望的人（新zn），并重新建立LiGHTs社会身份（新x并z）。

## 四、五维

### 时间维 xn + z：10/10
学院积分、训练、Orchestra和前代Ray历史叠加。角色不是一次舞台就完成职业，而是在连续制度时间中把“临时小组”压成职业履历。

### 本体维 zn + x：10/10
Tiara最初想成为“魔女”，后来职业实践迫使她扩展定义：唱歌、舞台、给人希望同样可以是魔女能力的一部分。

### 空间维 x并z + n：10/10
学院、组合、城市、舞台和公众共同定义“魔女偶像”的社会位置。LiGHTs身份不是五个人私下自称，而是经共同实践和公共舞台成立。

### 因果维 zx + nx：10/10
退学与积分制度压迫（nx）逼出Orchestra方案（zx）；主动成功以后，制度仍可能判定不够，形成“主动突破但规则不自动让步”的循环。

### 命运维 xz + nz：9/10
退学、故乡、前代与魔兽威胁形成不可忽视的命运压力，队友与城市关系则让个人职业选择拥有超出个人梦想的意义。

## 五、偶像身份如何建立

不是传统事务所签约型。

### 建立路径

**魔女见习生 → 低分小组成员 → Orchestra发起者 → LiGHTs组合成员 → 被公众观看与认可的魔女表演者**

关键点：

- 初始职业目标是“魔女”，不是“偶像”。
- Orchestra最初是解决退学危机的方法。
- 长期训练后，舞台不再只是救分手段，而进入职业本体。
- 偶像身份不是替代魔女身份，而是扩张“魔女应该做什么”的定义。

---

## 六、训练 / 出道 / 竞争 / 舞台 / 粉丝 / 公司机制

### 训练
- 魔法基础学习
- 小组共同任务
- Orchestra前专项训练
- 歌唱、编排、舞台合作
- 多种个人能力被压进同一个职业输出

### 出道
没有传统唱片公司“签约即出道”。第一次Orchestra相当于公共职业验证：从学院内部小组第一次变成被公众观看的表演单位。

### 竞争
竞争重点不是单纯排名，而是学院积分、能力等级和其他成熟组合形成的标准压力。

### 舞台
Orchestra同时承担三种功能：
1. 公众娱乐
2. 学院评价/职业验证
3. 魔法能量与世界功能

### 粉丝 / 公众
观众不是纯情感奖励，他们的观看与被鼓舞本身验证“魔女通过歌声给人带来希望”的职业价值。

### 公司 / 组织
本作核心组织是Flora女学院而非经纪公司。因此资源、许可、积分和职业合法性由教育制度掌控。

---

## 七、主角欲望与代价

### 欲望
Tiara想成为像姐姐一样优秀、能够给人希望的魔女。

### 代价
- 接受学院严格规则
- 承担整个小组的退学风险
- 必须学习原本没有被她单独定义为“魔女核心”的舞台能力
- 个人职业梦想被转换成团队责任
- 成功演出也不保证制度立即承认

核心：

> 她不是为“想红”而登台，而是在寻找一种让自己的魔女理想真正有效的方法。

---

## 八、关系结构

### Tiara ↔ LiGHTs成员
从同班/同组关系转为共同职业体。一个人的失误能导致全组被扣分，关系不只是友情，而是职业因果绑定。

### Tiara ↔ Eliza / Ray
前代成功模板既提供榜样，也制造“怎样才算真正魔女”的历史标准。

### LiGHTs ↔ 其他组合
其他组合不只充当敌人，还是职业可能性的示范者。Sugar Pockets的Orchestra直接触发Tiara的新行动路线。

### LiGHTs ↔ 学院
学院既提供成长资源，又拥有淘汰权，是典型“培养者+裁决者”双重关系。

### LiGHTs ↔ 城市/观众
职业最终不是只对学院交作业，而是对公共空间产生效果。

---

## 九、动态链

### 动态链A：制度压力生成新职业方式

**xn学院规则 → nx退学危机 → zx寻找新解法 → Orchestra → 新x并z**

不是退出规则，而是在规则内部发明一种此前没有被小组真正使用的职业路径。

### 动态链B：非核心能力进入本体

**zn“我要成为魔女” → xn实践 → 唱歌/舞台成为必要x → zx持续使用 → 新zn“舞台也是我的魔女方式”**

### 动态链C：成功不等于合法性自动成立

**zx成功演出 → nz观众认可 → 以为身份成立 → xn积分仍不足 → nx再次淘汰 → zn重新定义职业价值**

## 十、反咬点

### 反咬1：最像“副业”的东西，最后变成主职业能力

开始时舞台只是解决积分/退学问题的方案。

但：

**应急手段 → 反复训练 → 真正能力 → 公共作用 → 职业本体**

因此：

> 一个职业为了生存临时借来的能力，可能反过来改写这个职业本身的定义。

### 反咬2：舞台越成功，越证明学院原本评价维度不完整

如果LiGHTs能通过Orchestra真正影响公众，却仍因积分被判退学，那么故事会反向提出：

> 制度分数究竟是在测量职业本身，还是只测量制度方便量化的部分？

公式：

**xn评价体系 → 排除主体 → 主体在真实空间创造价值 → 真实价值反向审判xn**

### 反咬3：培养制度同时也是淘汰制度

学院提供资源、知识和伙伴，但也拥有删除身份的权力。

> 给你成为某种人的地方，也可能是最先宣布你“不够资格成为这种人”的地方。

### 反咬4：偶像身份没有替换魔女身份，而是扩张魔女身份

不是：

**魔女 → 偶像**

而是：

**旧魔女定义 → 职业实践 → 偶像/舞台能力进入 → 更大的魔女定义**

这是典型“职业本体扩容”，不是职业替换。

- 学院积分 / 等级标识：xn量化评价
- 退学通知：nx删除压力
- 普通校服 → Orchestra舞台服：x并z身份跨层
- 辉石 / 光粒：职业输出具象化

- 前代Ray舞台 / 影像：z前代标准

## 十二、可复用母题

### 1. 双制度共用同一动作
一个动作同时满足两个完全不同的系统。

例如：
- 唱歌 = 娱乐 + 魔法
- 绘画 = 艺术 + 封印术
- 舞蹈 = 表演 + 战斗阵法
- 直播 = 娱乐 + 城市供能

### 2. 应急能力职业化
为了保住主职业临时学的东西，最后进入主职业定义。

### 3. 真实价值反审制度评分
角色在制度外/公共空间证明价值，迫使原评价体系暴露盲区。

### 4. 职业本体扩容
不是换职业，而是把原职业从单一功能扩展成复合功能。

### 5. 培养者/裁决者同体
同一个机构既训练你又决定你是否有资格继续存在。

### 6. 团队劳动直接产生世界功能
团队不是为了“更好看”，而是多人同步本身能产生单人无法实现的结果。

---

## 十三、与既有母型边界

- 《Dream High》：制度加工人，目标职业本身早已明确。
- 《Pretty Rhythm》：复合职业本身要求多个技能域。
- 《Extreme Hearts》：在B领域获胜，以兑换A领域舞台。
- 《Love Live!》：为了救学校主动创造偶像组织。
- 《Lapis Re:LiGHTs》：**原职业在危机中吸收另一套职业实践，并因此改写自身定义；同一舞台行为同时服务公众、学院和魔法世界。**

因此正式新增：

# 「复合职业制度型 / 职业功能实用化型」

母链：

> **已有职业理想 → 制度淘汰危机 → 借入异质实践 → 团队共同训练 → 公共舞台验证 → 异质实践变成核心能力 → 原职业定义扩容**

矿核：

> **最有价值的跨界成长，不一定是换职业，也不一定是拿B领域成绩兑换A领域机会；更狠的一种情况，是角色为了保住A临时借来B，做久以后发现A如果没有B，反而已经不完整。**
