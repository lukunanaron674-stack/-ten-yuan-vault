# 日韩偶像题材_母库增量_R57

## 作品
- 作品名：《Aikatsu Planet! / アイカツプラネット！》
- 媒介：日本原创TV动画 / 实写×动画 / 多媒体偶像企划
- 矿级：S
- 核心判定：符合“从非偶像变成偶像”核心样本。主角音羽舞桜原本是普通高中生，因原顶级偶像“ハナ”突然消失，被要求顶替成为ハナ，并在持续工作、舞台、粉丝关系与公开身份中完成真正职业化。

## 一、新增母型
### 既有顶级身份继承 / 虚拟人格再所有化型
不是“我先努力成为顶级偶像”，而是：

> 一个已经拥有顶级知名度、粉丝和社会位置的偶像壳先落到普通人身上，主体必须在别人已经认识这个名字的情况下，补做能力、责任、关系和本体认领。

区别于普通二代继承：这里继承的不是抽象品牌，而是一个正在被公众当作“具体偶像人格”观看的身份。

## 二、偶像身份如何建立
1. 舞桜原本只是普通高中生，有古典芭蕾经验，但不是职业偶像。
2. 原本的顶级偶像“ハナ”突然消失。
3. 舞桜被要求代替原ハナ，以同一偶像身份继续活动。
4. 她必须保密自己的现实身份，同时承担“顶级偶像”已经存在的公众期待。
5. 经过杂志摄影、服装、Battle Stage、粉丝活动等持续实践后，ハナ不再只是借来的壳。
6. 第10话她主动向粉丝公开自己就是现在的ハナ，并选择不是按公司准备好的方式，而是亲自在粉丝活动中说明真相。
7. 因此最终身份不是“成功模仿前任”，而是“同一社会名字被新主体重新所有化”。

## 三、行业机制
- 训练：舞台表现、造型、Pose、芭蕾旧能力转译、Dressia协同。
- 出道：不是从零出道，而是直接接管顶级偶像现成位置。
- 竞争：Battle Stage、顶级偶像位置竞争。
- 舞台：Aikatsu Planet虚拟舞台，现实主体通过Avatar进入公众空间。
- 粉丝：粉丝最初爱的是“ハナ”这个既有公众人格，而未必知道里面的主体已经替换。
- 公司/运营：运营方先维持品牌连续性，要求舞桜保密；后期主体争回解释权。

## 四、主角欲望与代价
### 初始欲望
不是“我要成为偶像”，而是被要求承担一个突如其来的顶级身份。

### 中段欲望
从“完成代役”变成“我想把ハナ做好”。

### 后段欲望
从“维持别人留下的身份”变成“让粉丝知道现在站在这里的人是谁”。

### 代价
- 必须维持秘密现实身份。
- 必须承担一个远高于自身资历的顶级标准。
- 成功越多，越难继续说“这个身份不是我的”。
- 一旦公开真实主体，既有粉丝关系和品牌连续性都可能受损。

## 五、十元体量
| 十元 | 体量 | 作用 |
|---|---:|---|
| x并z | 10 | 普通高中生 / ハナ / 现实身体 / 虚拟偶像多重身份叠压 |
| zn | 10 | “我是谁”与“ハナ是谁”的核心本体冲突 |
| xn | 10 | 偶像运营、舞台、工作、秘密规则持续塑形 |
| nx | 9 | 被要求接管身份、被既有顶级标准反压 |
| zx | 9 | 从被动代役转成主动承担、最终主动公开 |
| z | 9 | 前任ハナ留下的既有历史与公众期待 |
| nz | 9 | 粉丝和伙伴让借来的身份产生真实关系 |
| x | 8 | 芭蕾、学习能力、舞台能力逐渐转译为偶像能力 |
| n | 8 | 同伴、竞争者与运营关系帮助身份稳定 |
| xz | 7 | 前任突然消失导致命运式换位，但非纯超自然强制 |

### 主元
**x并z + zn**

### 次元
**xn + nx + zx**

## 六、顺序
**nx → x并z → xn → z反压 → x成长 → n/nz沉淀 → zn冲突 → zx夺回解释权 → 新x并z**

解释：

被要求顶替
→ 先得到既有顶级偶像身份
→ 进入真实职业实践
→ 前任留下的历史持续压住新人
→ 主体能力补齐
→ 粉丝与伙伴关系变真
→ “现在的ハナ到底是谁”
→ 主体主动公开并承担结果
→ 同一个名字被新主体重新拥有。

## 七、五维
- 时间维 xn+z：10/10。最关键不是从零累积履历，而是在别人已经拥有的历史上继续写新历史。
- 本体维 zn+x：10/10。旧公众人格与现实主体争夺“谁是ハナ”。
- 空间维 x并z+n：10/10。现实学校、偶像运营空间、虚拟舞台和粉丝共同制造双重身份。
- 因果维 zx+nx：10/10。入口由外界强推，后期解释权必须由主体主动夺回。
- 命运维 xz+nz：9/10。偶然换位改变人生，而粉丝关系让这个偶然身份逐渐无法轻易退出。

## 八、关系结构
1. 舞桜 ↔ 前任ハナ：继承 / 替代 / 历史压力。
2. 舞桜 ↔ 粉丝：粉丝先爱公共人格，后逐渐面对真实主体。
3. 舞桜 ↔ 运营方：运营方提供身份，同时控制秘密与公开方式。
4. 舞桜 ↔ 同行：同行既是竞争者，也是帮助她理解职业规则的人。

## 九、动态链
### 链1｜借壳实化
**旧x并z → 新主体进入 → xn真实实践 → nz关系沉淀 → 新zn → 新x并z**

### 链2｜品牌历史反压
**旧z越强 → 新人入场越容易 → nx标准越高 → zn越难独立 → zx必须主动偏离旧模板**

### 链3｜秘密职业身份反锁
**保密保护入口 → 职业成功 → 粉丝增长 → x并z社会重量上升 → 保密成本上升 → 主体必须公开承担**

## 十、核心反咬
### 1. 接管顶级身份看似是捷径，实际上是跳过新人保护期
普通新人可以犯新人错误。
顶替顶级偶像的人一开始就必须接受顶级评价。

**入口成本下降 → 标准成本暴增。**

### 2. 越成功，越不能继续把身份说成“只是代替”
如果她真的工作、训练、登台、被粉丝喜欢，那么社会事实会不断把ハナ记到她身上。

**借来的x并z → 真行动 → 真历史 → 真关系 → 反写zn。**

### 3. 公司可以决定什么时候保密，却不能永久垄断“我是谁”的解释权
第10话舞桜选择在粉丝活动中用自己的话说明真相，而不是完全接受准备好的发布会方式。

因此：
**组织拥有运营权 ≠ 组织永久拥有本体解释权。**

### 4. 粉丝爱的是名字还是人
如果粉丝先爱“ハナ”，后来才知道内部主体发生变化，就会逼出：

> 公众关系究竟附着于品牌，还是附着于真正执行这个身份的人？

## 十一、视觉符号
- 普通高中制服 ↔ ハナ偶像形象
- 镜面 / Mirror In变身
- 现实真人 ↔ 虚拟Avatar
- 同一个“ハナ”名字下的不同主体
- 粉丝活动中的公开告白
- 秘密后台 ↔ 公开舞台
- 芭蕾动作 ↔ 偶像Battle动作
- 顶级偶像既有Logo / 服装 ↔ 舞桜自己的表现细节

## 十二、可复用母题
1. **顶级账号继承**：新人直接接手已有百万粉丝账号。
2. **职业人格换芯**：社会身份连续，但内部主体变化。
3. **借壳跳过新人期**：获得高位入口，同时失去犯错缓冲。
4. **品牌关系转人物关系**：公众先喜欢名字，后来才认识真正的人。
5. **解释权夺回**：组织替角色维持身份，角色最终必须亲自定义身份。
6. **同名异主体**：一个名字可以跨主体延续，但每一任都会重新改写名字的意义。

## 十三、与旧矿边界
- 《LEMON ANGEL PROJECT》：第二代继承的是整个团体品牌，新成员集体重建品牌合法性。
- 《IDOLY PRIDE》：前代传奇的影子压住后辈，但不是直接接管同一具体偶像人格。
- 《AKB49》：自己主动制造假身份，假身份被长期实践活真。
- 《Aikatsu Planet!》：**别人把一个已经处于顶级、拥有既有粉丝与历史的具体偶像人格直接套到普通人身上，新主体再通过真实行动夺回这个人格的所有权。**

## 十四、正式分类
# 「既有顶级身份继承 / 虚拟人格再所有化型」

母链：

**普通主体 → 被塞入成熟公众人格 → 直接承担顶级评价 → 用真实实践补齐职业能力 → 粉丝关系沉淀 → 借来的人格社会实化 → 本体冲突 → 主动公开真实主体 → 同一名字重新归属。**

## 十五、矿核
> 一个新人最容易的成长方式，是从零开始；最残酷的成长方式之一，则是第一天就被要求站在别人已经爬到顶点的位置。借来的名字能让她立刻被看见，却也让她没有“慢慢成为”的资格。真正的完成，不是把前任演得足够像，而是让世界接受：同一个名字，现在已经被另一个人真实地活过一遍。
