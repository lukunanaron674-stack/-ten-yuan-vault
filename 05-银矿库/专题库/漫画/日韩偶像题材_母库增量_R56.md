# 日韩偶像题材母库增量 R56

## 《Aikatsu Friends! / アイカツフレンズ！》
- 媒介：日本原创TV动画 / 偶像多媒体企划
- 矿级：S
- 本轮新机制：**双人共同身份 / 搭档耦合型职业生成**
- 核心样本：友希爱音（友希あいね）× 湊美绪（湊みお）＝ Pure Palette

## 1. 为什么进入核心样本
官方设定中，友希爱音最初只是 Star Harmony 学园普通科学生，因为遇到顶级偶像湊美绪，第一次进入偶像舞台；之后她转入偶像科、加入同一事务所并正式展开偶像活动。作品的职业目标并不止于“个人成为偶像”，而是两人组成二人组“Friends”，以成为顶点“Diamond Friends”为目标。

这意味着本作的职业身份存在两层：
1. 个人偶像身份；
2. 必须由两人共同维持的 Friends 身份。

官方第二季角色资料确认：爱音与美绪组成 Pure Palette，并赢得 Diamond Friends Cup，成为顶点 Diamond Friends。

## 2. 偶像身份如何建立
### 爱音
普通科学生 → 偶然与美绪同台 → 对偶像活动产生兴趣 → 转入偶像科 → 加入事务所 → 独立偶像实践 → 与美绪组成 Pure Palette → Diamond Friends。

### 美绪
已经是成熟个人偶像 → 感到“还缺少某样东西” → 主动把普通人爱音拉进偶像世界 → 与爱音建立 Friends → 从个人顶级偶像转换为“双人职业身份”的一半。

因此两人的生成方向是反向的：
- 爱音：**非偶像 → 偶像 → 搭档偶像**
- 美绪：**成熟个人偶像 → 放弃单体完结 → 进入共同身份**

## 3. 行业机制
- 训练：偶像科、日常练习、双人磨合
- 出道/工作：加入事务所、节目、宣传、演出等
- 竞争：Friends之间的二人组竞争
- 舞台：单人能力之外，更强调二人的整体表现
- 粉丝：个人知名度与 Friends 名号同时积累
- 公司/学校：偶像科、事务所为职业化提供规则与资源
- 顶点制度：Diamond Friends Cup 将“最佳搭档”制度化为可竞争的稀缺职位

官方第39话明确进入 Diamond Friends Cup，Pure Palette 与 Honey Cat 竞争；官方角色资料则明确 Pure Palette 最终成为 Diamond Friends。

## 4. 十元体量
- n：10
- x并z：10
- zx：9
- xn：9
- nz：9
- zn：9
- x：8
- nx：8
- z：8
- xz：6

### 主元
**n + x并z**

本作最强的不是“我个人有多强”，而是：
> 两个人之间的关系能否生成一个第三身份。

Pure Palette 不是“爱音 + 美绪”的简单加法，而是一个可被公众单独识别、被比赛单独评价、拥有独立历史的共同社会身份。

## 5. 顺序
**nz → zx → x并z（个人偶像）→ xn → n → x并z（Friends）→ nx → zn → zx再认领 → 新x并z**

解释：
1. 爱音因美绪这一关系入口被点燃；
2. 主动进入偶像活动；
3. 得到个人偶像身份；
4. 接受训练、事务所、节目规则；
5. 与美绪形成稳定搭档；
6. Pure Palette 作为新的公共身份出生；
7. 比赛、差异、搭档期待开始反压两人；
8. “我是我，还是某人的搭档？”产生本体问题；
9. 双方重新主动选择彼此；
10. 搭档身份从行政/组合标签升级为真正共同体。

## 6. 五维
### 时间维 xn+z：9/10
一次同台不能生成真正搭档，必须经过训练、工作、暂时停摆、再次选择、比赛与共同历史沉淀。

### 本体维 zn+x：10/10
两人必须解决：
- 我作为个人偶像是谁；
- 我作为“Pure Palette的一半”又是谁。

### 空间维 x并z+n：10/10
全作最强维度。双人关系直接生成一个新的社会单位，并被学校、事务所、比赛、粉丝共同承认。

### 因果维 zx+nx：10/10
“我主动选择搭档”与“搭档身份反过来限制我”持续循环。

### 命运维 xz+nz：8/10
没有强超自然命运，主要由关系、榜样、竞争与共同承诺推动人生路线。

## 7. 关系结构
### 爱音 → 美绪
- 初期：被顶级偶像带入职业世界
- 中期：学生/新人对成熟偶像的学习
- 后期：同位搭档、共同竞争主体

### 美绪 → 爱音
- 初期：发现普通人身上的职业可能性
- 中期：利用自己的资源和经验带她入行
- 后期：必须接受“搭档不是自己的附属物”

### Pure Palette → 两个成员
一旦组合成立，它会反过来要求两个人：
- 同步行动
- 保持信任
- 处理差异
- 对共同品牌负责

因此出现：
> **人创造组合，组合再约束人。**

## 8. 动态链
### 链A：关系生成职业
**nz相遇 → zx尝试 → xn实践 → x显影 → x并z个人偶像成立**

### 链B：两人生成第三身份
**个人x并z₁ + 个人x并z₂ → n长期协作 → 新x并z₃（Pure Palette）**

这是本轮最关键的新链。

### 链C：共同身份反咬个人
**新x并z₃变强 → 粉丝/比赛期待上升 → nx同步要求上升 → zn个人边界受压 → 必须重新谈判关系 → zx再次选择搭档**

## 9. 最大反咬点
### 反咬1：搭档越成功，个人越难自由变化
组合成功后，任何一个人的：
- 风格变化
- 工作路线
- 能力差距
- 私人选择

都不再只是个人问题，因为会影响另一个人的公共身份。

所以：
> **n提供增益，也制造联动风险。**

### 反咬2：帮助别人进入职业，可能改变自己的职业定义
美绪最初是已经成立的个人偶像，她把爱音带进来；但爱音真正成长后，美绪自己也不再只是“独立顶级偶像”，而成为 Pure Palette 的一半。

公式：
**我改变你 → 你成长 → 我们的关系改变 → 关系反过来改变我。**

### 反咬3：共同身份不能靠惯性维持
官方第31话明确写到，爱音与美绪一度暂停 Friends 活动，并认为不能以半吊子的心态恢复，必须重新认真确认后才能再启动。

所以：
> **关系身份不是成立一次就永久有效；它需要双方重复认领。**

## 10. 本轮新增十元规则
### 规则一：n 可以直接生出新的 x并z
不是“关系帮助个人获得身份”，而是：
> **两个人的关系本身，可以成为第三个被社会承认的身份主体。**

公式：
**x并z₁ + x并z₂ + n长期实践 → x并z₃**

### 规则二：共同身份具有独立惯性
Pure Palette 一旦拥有粉丝、荣誉、历史，就不再等于两个成员随时可拆的简单组合。

**z共同历史 + nz公众承认 → x并z₃惯性增强**

### 规则三：个人成长可能成为关系危机
如果一方成长速度、方向发生变化：
**x差异↑ → n张力↑ → x并z共同身份不稳定**

因此“我变强”不一定单向利好。

### 规则四：关系需要二次主动确认
**第一次组队zx**只是建立关系；
**经历冲突后再次选择zx**才完成更深层的共同本体。

## 11. 视觉符号
- 单人舞台 → 双人并肩舞台
- 两套不同个人风格服装 → Pure Palette 配对服装
- 两人相向/背靠背构图
- 双人手势、握手、并肩进入聚光灯
- Friends 名称/Logo作为“第三主体”符号
- 暂停活动时的空双人位置
- 重新并肩时，两束单独聚光汇成一个舞台光区
- Diamond Friends Cup奖杯/冠位作为共同身份的制度确认

## 12. 可复用母题
1. **双人共同职业身份**：两个个体必须共同成立一个职业单位。
2. **关系生产第三主体**：A+B不是A+B，而是生成C。
3. **搭档增益/绑定双重性**：关系提高能力，也提高退出成本。
4. **个人成长反噬共同身份**：成员变化越大，旧关系越需要重新谈判。
5. **二次组队**：第一次组队靠兴趣，第二次组队靠知道代价后仍选择。
6. **导师被学生反向改写**：把新人带入职业的人，最终自己的职业定义也被新人改变。

## 13. 与已有样本边界
### vs IDOLiSH7
IDOLiSH7强调多人团队中“个人排名不等于整体价值”，核心是关系互补和反淘汰。

Aikatsu Friends! 强调：
> **两个已经可以独立成立的人，共同生成一个必须双方持续维护的第三职业身份。**

### vs Wake Up, Girls!
WUG是公司先制造团体壳，再让成员把它活真。

Aikatsu Friends!则是：
> **两个人先产生真实关系，再把关系职业化、品牌化、制度化。**

### vs Aikatsu!
Aikatsu!核心是“看到榜样 → 产生职业欲望”。

Aikatsu Friends!进一步推进：
> **成为偶像以后，还必须学会与另一个主体共同拥有一个职业身份。**

## 14. 正式分类
# 「双人共同身份 / 搭档耦合型」

母链：
**关系相遇 → 个体职业化 → 双方组队 → 长期协作 → 第三身份生成 → 公众与制度确认 → 共同身份反锁个人 → 冲突/暂停 → 双方再次主动确认 → 更强共同本体**

## 15. 矿核
> **最强的搭档故事不是“两个强者一起工作”，而是两个人长期行动以后，世界开始承认一个既不是A、也不是B的第三名字；从那一刻起，任何一个人的成长、退场或改变都会同时撼动另一个人的职业身份。关系因此不再只是支持，而变成一种共同拥有、共同承担、必须反复确认的社会本体。**
