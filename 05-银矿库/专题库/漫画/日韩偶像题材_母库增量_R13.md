# R13｜おちこぼれフルーツタルト / Dropout Idol Fruit Tart

## 收录结论
- 地区：日本
- 形式：漫画（四格连载）
- 核心偶像职业度：10/10
- 矿级：S
- 新母型：**生存资产绑定型 / 糊团现金流型**
- 与已有样本差异：不是“获得出道资格”，而是“已经组成新人偶像团后，必须把节目、唱片、Live、赞助、比赛转化成真实现金流，否则宿舍这一共同生活资产消失”。比 SHINEPOST 的“Live满员→组合存续”更进一步，把职业表现直接连接到居住资产与债务。

## 事实核验
主角樱衣乃为了成为偶像来到东京，与前童星、音乐人、模特等事业不顺的少女住进 Mouse House。宿舍面临被拆/出售，她们组成新人偶像团 Fruit Tart，以偶像活动挽救共同居所。漫画长期描写服装、摄影、录音、出道CD纪念Live、销售活动、电视节目、赞助、Idol Battle 等职业环节。2026年5月官方相关消息确认漫画将在2026年7月28日发售的9月号完结，连载超过10年。

## 十元判定
- 主符号：**n** —— 团体共同体与共同居所是职业发动机，成员不是各自追梦，而是被同一生存资产绑定。
- 次符号：**xz → xn → zx → x并z**
- 暗层：**nz + zn**

### 顺序链
`z偶像愿望 → xz宿舍消失/债务威胁 → n失败艺人被绑定成团 → xn事务所/节目/赞助/比赛规则 → nx接受商业任务 → zx主动营业与表演 → x并z曝光/销量/舞台可见性 → nz团体依赖加深 → zn“失败艺人”被改写成职业偶像`

## 五维
- 时间：`xn + z` —— 梦想必须经过持续排期、节目与职业周期兑现。
- 本体：`zn + x` —— “过气/失败艺人”身份能否被新的职业能力和劳动改写。
- 空间：`x并z + n` —— 舞台、节目、唱片曝光与团体共同体共同制造职业空间。
- 因果：`zx + nx` —— 被迫接下商业生存任务，再主动把任务做成职业成果。
- 命运：`xz + nz` —— 宿舍消失的外部命运把成员关系锁成共同命运。

## 生链
1. `xz → n`：共同资产危机迫使边缘艺人组成真正的团体。
2. `n → zx`：团体关系提供持续行动能力。
3. `xn → x并z`：节目、CD、活动与比赛制度生产公众可见性。
4. `zx → x并z`：主动训练、营业、演出转化为曝光和销售。
5. `x并z → zn`：反复被市场看见，使“失败艺人”逐步成立为“偶像”。

## 克链
1. `xz 克 z`：现实债务/宿舍危机压住纯粹梦想。
2. `xn 克 zx`：节目档期、赞助、事务所规则限制个人想怎么做就怎么做。
3. `nx 克 zn`：为了生存被迫营业，会让“我到底想不想这样当偶像”产生本体磨损。
4. `n 反克 xz`：团体协作把原本必然失去宿舍的危机变成可经营问题。
5. `zx 反克 nx`：成员把被迫任务做成自己的舞台，重新夺回主动性。

## 5组补子
1. `xn + z`：职业制度补梦想，让“想当偶像”变成持续可执行的工作。
2. `zn + x`：旧身份由实际技能、身体劳动、录音与表演重新证明。
3. `x并z + n`：公众曝光补团体，团体又让曝光拥有稳定主体。
4. `zx + nx`：被迫接任务与主动把任务做好形成因果闭环。
5. `xz + nz`：共同危机补强成员关系，关系又提供抵抗危机的韧性。

## 反咬点
最有价值的不是“欠债所以当偶像”这个表层，而是：**偶像职业成功被直接换算成共同生活空间的存续。** 当销量、节目、赞助和比赛不再只是名气，而是决定“大家还能不能继续住在一起”，`x并z` 的公众价值会直接反咬 `n/nz` 的私人关系。团体越像商业产品，越有能力保护作为私人共同体的家；但越依赖商业成功，私人共同体也越被市场指标绑架。

## 与现有母型的区分
- SHINEPOST：`Live满员 → 组合是否解散`，属于**职业存续资格**。
- Feeding the Lives of Failing Idols：外行业经营者进入失败团，属于**经营者救糊团**。
- U149：低优先级单位在事务所内长期积累，属于**边缘单位长期经营**。
- Dropout Idol Fruit Tart：`偶像现金流 → 宿舍/共同生活资产是否存在`，属于**职业收入保护共同资产**。

因此新增母型：

> **L. 生存资产绑定 / 糊团现金流型**：职业表现不是为了抽象排名，而是直接承担共同体的住房、债务或生存资产；市场成功越强，共同体越能活，但共同体也越被市场量化。
