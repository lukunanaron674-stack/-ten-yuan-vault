# 1.8.7 艺术批评的方法

## 原版概括

传记批评法、社会历史批评法、形式分析法、接受美学法、比较分析法

## 三元分析

**各方法 = nx的不同工具**：<br>**传记法** = 用创作者的zn解释作品的z（他经历了什么→为什么这样画）<br>**社会历史法** = 用时代的x解释作品的zn（社会问题→作品回应）<br>**形式分析法** = 只看xn（不管作者不管社会，就看技法好不好）<br>**接受美学法** = 从n（接受者）出发看意义生成（观众怎么读比作者怎么想重要）<br>**比较分析法** = 用A的z对比B的z来找差异
