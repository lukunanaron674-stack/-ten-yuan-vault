# 曹操（曹孟德）

## 1. 主十元判断

**主十元：zx（阳木·突破/开局）**
**理由：拿掉zx，曹操就不成立。** 他每一个历史关口的底层选择都是先出牌再算账——官渡是先赌后赢，挟天子是先出手后收网，赤壁是先打再想退路。如果把zx从他身上拿掉，剩下的是一个擅长结算的官僚（nx纯体），那就不是曹操了——那是司马懿。

**五问法核验：**
- 第1问（拿掉什么他就不是他）：拿掉zx，曹操变成一个会在官渡退兵的人 → 那就不叫曹操
- 第2问（反复面对什么结构）：反复在绝境中撕开口子——这是他一生重复了无数次的行为结构
- 第3问（最怕失去什么）：最怕「没有局可以下了」——曹丕称帝后他最落寞的时刻不是因为没打赢，是因为大局已定
- 第4问（回到了哪个感觉）：回到「棋局还在」的感觉——赤壁输了之后他没有颓废，是因为棋没下完
- 第5问（副十元服务谁）：nx（结算/冷酷）服务于zx（突破）——不是他冷酷所以他能突破，是他要突破所以必须冷酷

## 2. 副十元

**副十元：nx（阴金·暗算/结算）**
**作用：** nx是曹操zx的刹车和收尾工具。zx负责把棋局打开，nx负责在打开后不让局面失控。杀吕伯奢不是zx（那是结算），杀荀彧不是zx（那也是结算）。曹操的zx需要nx来收尾，否则他的突破会把一切都烧光。

## 3. 功能十元

**功能十元：x并z（阴木·包装）**
**作用：** 挟天子以令诸侯是x并z操作——用汉室的外壳包装魏的合法性。这是曹操用过的最大规模的一次包装操作，但它不是他的底色，只是他为zx服务的一个工具。

## 4. 视觉十元

**视觉十元：无。** 曹操没有视觉层面的九币标识——他不靠外观定义自己。

## 5. 动态链

```
zx（主·突破开局）
  → nx（副·冷酷结算）为zx收尾
  → x并z（功能·挟天子包装）为zx提供合法性外壳
  → 赤壁撞墙（zx被xn克）
  → 继续下棋（因为棋局还在）
```

## 6. 一句话定型

曹操不是「统一天下的枭雄」，而是「**必须要有一盘棋可以下**的人」。
