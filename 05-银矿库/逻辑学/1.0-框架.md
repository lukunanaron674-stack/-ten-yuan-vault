# 《逻辑学导论》框架

## 精读范围

按用户指令，优先精读 **概念定义** 和 **概念关系** 相关内容。

## 子域清单

### 1.1 概念的定义

**精读内容：** 概念的内涵（intension）与外延（extension）、定义的方法（属加种差、列举定义、操作定义等）、定义的规则

**预期原子卡数：** 3-6 张

可能的原子卡：
- 1.1.1 内涵与外延
- 1.1.2 属加种差定义法
- 1.1.3 定义的规则与常见错误
- 1.1.4 概念的分类（单独/普遍/集合/非集合）

### 1.2 概念的关系

**精读内容：** 概念之间的逻辑关系（相容/不相容）、包含/被包含、交叉、全异、矛盾/反对、种属关系

**预期原子卡数：** 3-5 张

可能的原子卡：
- 1.2.1 概念的相容关系
- 1.2.2 概念的不相容关系
- 1.2.3 概念关系矩阵

### 1.3 概念与语词

**精读内容：** 概念与语词的对应关系、多义性、歧义

**预期原子卡数：** 2-3 张

### 1.4 概念在命题与推理中的角色

**精读内容：** 概念作为命题的基本单元、概念清晰度对推理的影响、定义在论证中的作用

**预期原子卡数：** 2-3 张

## 读取顺序

1. 1.1 → 1.2 → 1.3 → 1.4
2. 先完成 1.1（概念定义），再读 1.2（概念关系）
3. 每完成一个子域，等用户确认后再继续
