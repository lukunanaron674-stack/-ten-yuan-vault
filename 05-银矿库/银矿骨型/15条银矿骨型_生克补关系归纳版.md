# 15条银矿骨型｜生克补关系归纳版

归档时间：2026-05-13  
归档用途：银矿二审小炉 R1-R21 后续归档 / 动态骨型按生克补关系重整

---

## 0. 总规则

| 关系 | 在链条里的作用 |
|---|---|
| 生 | A 生成 B，B 是 A 的自然后果或下一层展开 |
| 克 | A 压制 / 破坏 / 限制 B，使 B 失效或变形 |
| 补 | A 与 B 互相缺口吸附，常形成“互相需要但不稳定”的结构 |
| 桥 | A 与 B 无直连，必须经最少污染的中介连接 |
| 污染桥 | A 与 B 无直连，但通过表象、包装、制度、观看、符号等强行接通，链条会被染色 |

核心提醒：

> 这 15 条不是都按“纯生链”跑的。真正结构是：有些靠生生成结果，有些靠克制造破裂，有些靠补形成吸附，有些靠污染桥把不直连的十元强行接起来。

| 11 | 善意反咬链 | 因果补位反噬 | nx 生 x | x 反咬 zn | zx 补 nx；x 补 zn | 善意 zx 触发暗账 nx，nx 生出失控 x，最终逼出本体审判。 |

## 2. 按关系类型重新归档

### A. 以“生”为主的链

这些链条不是靠爆裂，而是靠一个十元自然生出下一个十元。

| 骨型 | 核心生关系 | 说明 |
|---|---|---|
| 单点封存链 | z 生 nz | 一个记忆亮点 z 被提纯后，生出永恒停靠 nz。 |
| 解码换时链 | x并z 生 z → z 补 xn | 符号外壳生出关键刺激点，再与时间结构互补。 |
| 作品吞生链 | x并z 生 z | 作品外壳不断生出细节点，再被排练机制吞入。 |
| 善意反咬链 | nx 生 x | 暗线判断位积累后，生出失控的 x。 |

一句话：

> 生链负责“长出来”。小点长成停靠，符号长成时间，暗账长成怪物。

---

### B. 以“克”为主的链

这些链条的力量来自压制、破坏、失效、反制。

| 骨型 | 核心克关系 | 说明 |
|---|---|---|
| 擦除回吸链 | xn 克 zx | 主动擦除 zx 被程序规则 xn 接管，人物反悔也停不下来。 |
| 解码换时链 | nx 克 x并z；xn 克 zx | 语义判断拆开符号外壳，时间结构反过来改写行动选择。 |
| 包装空间破壳链 | nx 克 x并z | 异常识别克破观看包装。 |
| 暗线空洞链 | xz 污染并切断 nx | 严格说不是标准克边，而是命运漂流污染判断位，使因果不可结算。 |
| 停靠错认断链 | nz 克 x 失败 | nz 本应安抚 / 制住 x，但错认停靠导致 x 爆裂。 |
| 临时家庭生成链 | n 克 xz | 外部稳定制度 / 血缘秩序克制临界漂流家庭。 |

一句话：

> 克链负责“咬断”。规则咬行动，判断咬表象，制度咬漂流，失败的克制会变成爆裂。

---

### C. 以“补”为主的链

这些链条靠互相缺口吸附，最容易形成命运感、关系感、空间感。

| 骨型 | 核心补关系 | 说明 |
|---|---|---|
| 单点封存链 | xn 补 z | 时间规则需要一个记忆亮点来封存人生。 |
| 包装空间破壳链 | x并z 补 n | 包装外壳 + 承载空间组成完整观看世界。 |
| 空间寄生爆裂链 | x并z 补 n | 伪装与空间容器互补，但补位被阶级污染。 |
| 暗线空洞链 | zx 补 nx | 调查行动需要暗线判断补完，但补位失败。 |
| 善意反咬链 | zx 补 nx；x 补 zn | 善意行动打开暗账，失控 x 逼问本体意义 zn。 |
| 临时家庭生成链 | xz 补 nz | 漂流者和停靠感互相吸附，生成临时家庭。 |
| 停靠错认断链 | xz 补 nz | 失归青春寻找停靠，但补位错认。 |
| 双重归属重判链 | xz 补 nz；zx 补 nx | 亲缘错位先生成双重停靠，再进入因果审判。 |

一句话：

> 补链负责“吸住”。最温柔，也最危险，因为互补一旦错位，就会长出撕裂。

---

### D. 以“污染桥”为主的链

这些链条最适合做高级创作模板，因为它们不是直连，而是被包装、观看、制度、符号强行接通。

| 骨型 | 污染桥 | 说明 |
|---|---|---|
| 表象夺身链 | x并z → zn+x | 表象外壳本不该直接等于主体，但偶像机制让外壳夺身。 |
| 作品吞生链 | x并z → z → xn → x并z | 作品外壳通过细节和排练循环吞生活。 |
| 人格切割殖民链 | xn → x并z → zn+x | 制度先切割人格，再用职业外壳殖民本体。 |
| 语言围栏逃逸链 | xn → x并z+n → zn+x | 命名规则把现实包装成空间围栏，再封闭本体。 |
| 童年暗账放大链 | zx → x并z → nx | 童年行动被符号组织化后，变成暗账回流。 |

一句话：

> 污染桥负责“变质”。本来不直连的东西，被外壳、制度、符号、作品接上电，整条链就开始发黑光。

## 3. 按五大主题重新看主关系

### 时间仓：xn / z / nz 的处理链

| 骨型 | 主关系 |
|---|---|
| 擦除回吸链 | xn 克 zx，xn 补 z，z 生 nz |
| 解码换时链 | nx 克 x并z，x并z 生 z，z 补 xn |
| 单点封存链 | xn 补 z，z 生 nz |

时间仓核心：

> 时间主题不是“时间很多”，而是 xn 如何处理 z，z 又如何生出 nz。

时间仓最硬公式：

> 规则处理瞬间，瞬间生成停靠。

---

### 本体仓：zn+x 被外壳 / 制度 / 作品夺取

| 骨型 | 主关系 |
|---|---|
| 表象夺身链 | x并z 污染 zn+x |
| 作品吞生链 | x并z 生 z，z 补 xn，xn 循环吞主体 |
| 人格切割殖民链 | xn 压 zn+x，x并z 职业外壳殖民主体 |

本体仓核心：

> 本体主题不是“我是谁”的台词，而是谁有资格占据 zn+x。

本体仓最硬公式：

> 外壳越能被观看，越可能夺走主体。

---

### 空间仓：x并z+n 的补位稳定与爆裂

| 骨型 | 主关系 |
|---|---|
| 包装空间破壳链 | x并z 补 n，nx 克 x并z |
| 空间寄生爆裂链 | x并z 补 n，但补位被污染后爆裂 |
| 语言围栏逃逸链 | xn 规则命名，x并z 补 n 形成现实围栏 |

空间仓核心：

> 空间主题不是“有房子/城市”，而是 x并z 如何包装 n，n 又如何决定谁能停留。

空间仓最硬公式：

> 包装 + 承载 = 空间；污染 + 承载 = 爆裂空间。

---

### 因果仓：zx+nx 的补位成败

| 骨型 | 主关系 |
|---|---|
| 暗线空洞链 | zx 补 nx 失败 |
| 善意反咬链 | zx 补 nx，nx 生 x，x 补 zn |
| 童年暗账放大链 | zx 经 x并z 污染桥进入 nx |

因果仓核心：

> 因果主题不是“发生了什么”，而是 zx 的行动能不能被 nx 结算。

因果仓最硬公式：

> 行动需要暗线补完；暗线一坏，行动就会反咬。

---

### 命运仓：xz+nz 的补位错位

| 骨型 | 主关系 |
|---|---|
| 临时家庭生成链 | xz 补 nz，n 克 xz |
| 停靠错认断链 | xz 补 nz，nz 克 x 失败 |
| 双重归属重判链 | xz 补 nz，zx 补 nx 进入资格审判 |

命运仓核心：

> 命运主题不是“很惨”，而是 xz 漂流者能不能找到正确 nz 停靠。

命运仓最硬公式：

> 漂流需要停靠；停靠一错，命运就断链。

## 5. 入库总句

> 时间仓靠 xn 与 z 的补生，空间仓靠 x并z 与 n 的补位，本体仓多靠 x并z / xn 对 zn+x 的污染桥，因果仓靠 zx 与 nx 的补位成败，命运仓靠 xz 与 nz 的互补错位。

银矿哥压缩句：

> 生让东西长出来，克让东西断开，补让东西吸住，污染桥让不该相连的东西变成怪物。
