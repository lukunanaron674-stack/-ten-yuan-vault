# 面语法

## 原版概括

**面 = z**（主体、承载、空间）

### 面的作用
| 作用 | 十元 | 说明 |
|------|------|------|
| 分割 | ？nx | 大面积分割版面，作用最明显 |
| 深化主题 | z | 面的内容强化核心信息 |
| 视线引导 | z | 大面积色块牵引视线 |
| 承载信息（文字） | n | 文字放在面上可读性更好 |
| 提升整体感 | z | 统一调性 |
| 字面 | — | 文字本身作为面的形态 |
| 空间 | nx | 面之间的负空间 |

### 面的形态
- 色块面 → 区域的边界定义
- 图片面 → 主体视觉叙事
- 字面 → 文字组排形成灰色块
- 负空间面 → 留白形成的隐形面

## 三元分析

- **x（现象）**：封面上的色块、图片区域、文字块——大面积的视觉区域
- **z（本质）**：面是版面的"地"，定义了区域归属和视觉重量
- **n（应用）**：面分割版面（横向/纵向/斜向），面承载信息增强可读性

## 关键语法规则
- 面分割 = 最强烈的版面操作（？nx），因为面定义了"这里有内容"的边界
- 图片面 → 视觉主力，决定封面调性
- 字面 → 灰度控制，文字排列越密面越实
- 负空间面 → 隐形对抗，正负形的博弈
