# 点语法

## 原版概括

**点 = n**（承载、接收、对齐）

### 点的多种形态
| 形态 | 十元 | 作用 |
|------|------|------|
| 多点 | n | 丰富、点缀、信息填充 |
| 焦点 | z | 核心视觉落点、视觉重心 |
| 点分散 | nx | 消化感、均匀分布、不集中 |
| 点重复 | n | 节奏、韵律、秩序感 |
| 文字图形点化 | n→zx | 把文字当点处理，功能化标注 |

### 点的作用清单
1. 丰富信息，点缀版面（n）
2. 减少留白（z）
3. 突出重点/标注（zx）
4. 视线引导（n）
5. 对齐、平衡（n）
6. 交叉：焦点（z）= 圆面？球？

## 三元分析

- **x（现象）**：封面上的小元素——装饰圆点、文字首字、标签、图标、标注符号
- **z（本质）**：点的大小、位置、疏密决定了视觉节奏；焦点的位置决定阅读入口
- **n（应用）**：点的重复创造韵律（文字图形点化 → 把文字当圆点排列），点的分散创造呼吸感

## 关键语法规则
- 点的分散 = 消化（nx）——点太集中是z，均匀分散是nx
- 点重复 = 节奏（n）——同一元素多次出现，建立识别的基底
- 文字图形点化 → 标注 zx——文字不再被阅读，而是被"看"成图形
