# 图文关系

## 原版概括

### 三种图文模式
| 模式 | 十元 | 说明 |
|------|------|------|
| **文字为主** | nx | 规则、秩序、排版型封面 |
| **图文混排** | x并z | 表面是图+文字，实质是视觉交织——图不是背景，文字不是附庸 |
| **纯图 / 全图加少文** | n？ | 以图叙事，文字只做点缀或不出 |

### 图文 x 版面 x 留白 的三元结构
1. **图文中的"图"** = 图片/插画/图像
2. **版面** = 边框，封面的边界和区域划分
3. **留白** = 白色区域的大小——正负空间的博弈

## 三元分析

- **x（现象）**：封面上文字和图片的分布——密集/稀疏/重叠/分离
- **z（本质）**：图与文谁主导视觉——图主导时叙事型，文主导时信息型
- **n（应用）**：根据书籍类型选择图文比例——小说偏图，学术偏文，设计偏混

## 关键语法规则
- 文字 = nx（规则、秩序）
- 图文 = x并z（表面≠内在——图和文的视觉关系往往不是它们看起来那样）
- 纯图 = n（承载、接收——读者接收画面的信息）
- 图文交叉时：图片可以文字化（做底纹/灰度），文字可以图形化（做点/做面）
