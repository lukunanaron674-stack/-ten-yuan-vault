# 深渊圣所 · 裂隙网络（完整设计）

**体量：15-25人团队 / PC为主 / 每次30分钟-1小时 / 中等规模独立游戏**

**一句话：** 不是一座圣所——是一整片裂隙地下的圣所网络。你和朋友各自经营自己的圣所，通过「裂隙走廊」连接起来。你的守护兽可以去朋友的圣所探险，朋友的兽也会来你家串门。深渊不是一个人的——是你们所有人的。

---

## 核心公式

```
n（裂隙网络）
  ├── 你的圣所 = 你的私有空间容器
  ├── 朋友的圣所 = 邻居空间
  └── 裂隙走廊 = 连接空间的空间
      ↓
xn（网络产出规则）
  ├── 你的圣所离线产出 = 个人基础
  ├── 连接数越多 → 全网络产出加成
  └── 整个盟约的产出 = 成员产出的总和 × 网络系数
      ↓
z（社交爆点）
  ├── 看到朋友的兽在你家 = 惊喜
  ├── 联合探索带回来神话材料 = 成就感
  └── 朋友给你留了礼物 = 温暖
```

**空间生时间（n→xn）在这里变成：社交网络生时间。**

## 一、裂隙网络 · 拓扑结构

### 圣所即节点

每座圣所在「裂隙地图」上是一个节点。节点之间的连接称为「裂隙走廊」。

```
        [玩家A] ———1级走廊——— [玩家B]
            |                      |
        2级走廊                 1级走廊
            |                      |
        [玩家C] ———1级走廊——— [玩家D]
            |
        3级走廊
            |
         [深渊中心] ← 盟约的核心出口
```

**走廊等级规则（xn）：**
- **1级走廊**：相邻圣所，基础连接，产出加成 +5%
- **2级走廊**：隔一个节点，需消耗灵质加固，产出加成 +10%
- **3级走廊**：跨越整个网络，需高阶符文维持，产出加成 +20%

走廊等级越高，兽串门的路程越短、带回的特产越多、但维护成本越高。

### 网络系数公式

```
全盟约产出 = Σ（每个成员个人产出）×（1 + 0.05 × 有效连接数）
```

- 2人盟约：2个连接点 → 系数 1.10 → 总产出 +10%
- 4人盟约：8个连接点（满连接）→ 系数 1.40 → 总产出 +40%
- 8人盟约：28个连接点（满连接）→ 系数 2.40 → 总产出 +140%

**但人越多，每个人的资源投入也越多**——走廊维护、裂隙加固、联合探索的门槛都会上升。这不是纯收益——是规模经济的代价（zx设计：你要决定网络多大才有效率）。

## 二、社交系统 · 大框架

### 2.1 裂隙盟约（核心社交单元）

**2-8人**，以裂隙地图上的物理位置为基础，自愿连接。

| 盟约功能 | 效果 | 解锁条件 |
|:--------|:-----|:---------|
| 基础连接 | 兽串门 + 礼物互换 | 走廊开通 |
| 共享祭坛 | 全盟产出加成 +5%/座 | 至少3座圣所连入 |
| 联合深渊 | 2-4只守护兽组队深层探索 | 盟约成员兽均≥10级 |
| 裂隙市场 | 盟约内自由交易（无税） | 自动开启 |
| 盟约银行 | 公用灵质池——成员可以存/取/借贷 | 至少2座圣所开通2级走廊 |

### 2.2 兽串门（核心社交行为）

**不是你主动派兽去朋友家——是兽自己想去。**

每只守护兽有「好奇心」属性（nz的反面：不是等——是想出去看）。好奇心累积到阈值时，兽会自动沿裂隙走廊去附近朋友的圣所串门。

| 串门状态 | 触发条件 | 效果 |
|:---------|:---------|:-----|
| 好奇萌发 | 超过8小时没兽来串门 | 兽在祭坛边转圈——暗示你"我想出去玩" |
| 出门探险 | 你在线时点它 → "去吧" | 兽离开1-2小时后回来，带回朋友圣所特产 |
| 留宿过夜 | 朋友家有空卧榻 + 兽的忠诚度不够你 | 兽在朋友家过夜——次日带回双倍特产，但你需要去朋友家领它回来 |
| 带特产回家 | 串门结束 | 带回的物资由：朋友圣所产出种类 × 走廊等级 × 随机系数 决定 |

**兽串门的体验示例：**
你上线，发现裂隙狐不在祭坛上。打开裂隙地图——它在朋友B的圣所里蹲着。你点一下它，它的气泡说「这里有好东西，帮我多带点！」。你去朋友家的祭坛上看到它嘴里叼着一块发光的符文石——那是朋友家深层深渊出的稀有材料，你这边不出这个。你摸了它的头，它跟你一起回家。

**不是系统发邮件——你亲眼看到你的兽在别人家、别人的兽在你家。**

### 2.3 共享祭坛

盟约内部所有圣所的祭坛可以连锁。

连锁后，你供奉给自家古神的灵质，**5%会流向盟约其他成员的祭坛**。同理，别人供奉的也会流向你。

效果：
- 全盟获得一个小额常驻加成（约5-15%，看盟约规模）
- 你灵质多得放不下时，不再浪费——自动分流给缺灵质的队友
- 灵质流向在裂隙地图上可视化——你可以看到「谁的祭坛在发光」

### 2.4 盟约银行

| 功能 | 说明 |
|:----|:------|
| 存款 | 把你的多余灵质/材料存入盟约公用池 |
| 取款 | 从公用池提取——需要盟约半数以上成员同意（或设定自动配额） |
| 借贷 | 急用时借出——需在7天内归还，否则产生「裂隙债务」（产出惩罚） |
| 捐献给新成员 | 新成员加入时，盟约可以自动给他一份启动资源包 |

**设计意图：** 盟约银行让裂隙网络不仅仅是一个社交聊天群——它有了**经济实体的功能**。成员之间的信任和互助会变成可见的。

### 深渊层连接规则

深渊层不是线性推图——是**树状连接**。

每层的出口有2-3个选择：
- 有些通往下一层（推进度）
- 有些通往同层的隐藏区域（资源丰厚但需要特定兽种）
- 有些通往你的盟约成员的圣所（跨空间传送）

**示例：第7层的分支：**
```
第6层 → 第7层
          ├── 继续往下 → 第8层（推进度）
          ├── 裂隙裂缝 → 影蛇巢穴（隐藏区域，需要影蛇才能进入）
          └── 盟约裂隙 → 玩家B的圣所（如果走廊等级≥2）
```
