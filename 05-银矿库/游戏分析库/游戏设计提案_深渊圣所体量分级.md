# 深渊圣所 · 体量分级设计

## 核心概念（跨所有体量）

**你有一座自己的地下圣所。你不在的时候——它自己活着。**

守护兽探索深渊、祭坛自动产出、符文自行运转。你上线是「来看看今天带了什么回来」，而不是「开始今天的劳动」。

**空间生时间（n→xn）是这个系列所有体量的共同引擎。**

---

# 微型级 · 深渊圣所：口袋版

**体量：1-2人 / 手机竖屏 / 5分钟收一次 / 作者一个人3个月能做完**

## 一句话

**一个竖屏手机游戏：你有一座祭坛、一只守护兽、五层深渊。祭坛每2小时产出一次「灵质」，守护兽自动探索下一层，你上线摸摸它、收收菜、看看它捡到的故事碎片。**

跟电子宠物差不多——但电子宠物不会给你带回来金币。

## 核心参数

| 项目 | 内容 |
|:----|:------|
| 开发体量 | 1个人，3个月，Unity/Cocos |
| 画面风格 | 像素风（16-32px）——像《Stardew Valley》简化版 |
| 核心屏幕 | 竖屏单页：上面是圣所剖面图，下面是守护兽状态+收菜按钮 |
| 离线时长 | 2小时满产出，超过上限不再积累 |
| 留存设计 | 守护兽每次探索带回的「记忆碎片」拼成完整故事（zn） |

## 十元结构

| 十元 | 内容 | 强度 |
|:----|:----|:----:|
| n（祭坛+小圣所） | 一个小环境——祭坛在哪层决定了产出速度 | 9 |
| xn（2小时产出规则） | 固定2小时周期，不可加速 | 9 |
| z（收菜+守护兽互动） | 上线点祭坛→灵质弹出+守护兽摇尾巴 | 8 |
| nz（兽等你） | 你离线时守护兽趴在祭坛旁边等你——它会发「寂寞」状态 | 7 |
| zn（记忆碎片拼图） | 碎片拼完是一个「深渊守护者」的短篇故事 | 6 |

## 变现

- 免费+广告：收菜时看广告双倍产出
- 皮肤：守护兽的挂件/颜色/光环——纯装饰，影响产出
- 少量内购：解锁深渊深层（单次解锁，非抽卡）

## 为什么有人玩

因为它像养电子宠物但你不用喂——它会**自己养自己**。你上线是去收惊喜，不是去打工。

# 轻量级 · 深渊圣所：静寂石室

**体量：5-10人团队 / 横屏手机+PC / 每次10-20分钟 / 小型独立游戏**

## 一句话

**你继承了祖先留下的地下石室——空荡荡的、黑的、只有一座中央祭坛还在微弱发光。你挖新房间、放祭坛、召唤守护兽、布置家具。每间房自己产出资源，守护兽替你探索裂隙。你不是冒险家——你是这座石室的**最后一个守护者**。**

## 核心参数

| 项目 | 内容 |
|:----|:------|
| 开发体量 | 5-10人，6-8个月 |
| 画面风格 | 低多边形+柔和灯光——像《Hollow Knight》的圣巢风格+PS1低模质感 |
| 核心玩法 | 建造+挂机+收集故事碎片 |
| 离线时长 | 8小时满产出 |
| 故事长度 | 主线20-30小时深渊探索+拼图故事 |

## 圣所房间系统

你最初的石室只有一间大厅。你可以向四个方向挖掘：

```
         [深渊裂隙·北]
              |
    [西·符文室]——[中央大厅]——[东·祭坛室]
              |
         [深渊裂隙·南]
```

每个新房间配一个**功能**：

| 房间 | 功能 | 解锁条件 |
|:----|:-----|:---------|
| 中央大厅 | 守护兽的家——兽的忠诚度和产出在这里决定 | 自带 |
| 祭坛室（东） | 供奉古神→改变掉落池 | 需：50灵质+3天等待 |
| 符文室（西） | 合成素材→制作探索装备 | 需：祭坛室建好 |
| 下层挖掘 | 解锁新深渊层 | 每次下层需大量灵质+前置房间达标 |

## 守护兽进阶

不是只有一只——你可以在不同房间放不同的兽，每只兽有自己的探索倾向：

| 兽 | 倾向 | 离线行为 | 互动方式 |
|:---|:-----|:--------|:--------|
| 🐉 **岩龙幼崽** | 矿石/材料 | 往深层探，带回稀有矿石 | 喂矿石→它舔你 |
| 🦊 **裂隙狐** | 古物/记忆碎片 | 往裂隙边缘探，带回故事 | 摸耳朵→它咕噜叫 |
| 🐦 **静寂歌鸮** | 灵质/能量 | 停在祭坛上，加速灵质产出 | 唱歌→它跟着唱 |
| 🐍 **影蛇** | 暗黑系材料 | 往腐化层探，带回诅咒材料 | 喂灵质→它缠在你手上 |

## 深渊异象

跟口袋版比，异象更丰富：

| 异象 | 效果 | 触发条件 |
|:----|:-----|:---------|
| 星陨之时 | 全掉落翻倍，持续4小时 | 随机，每周最多2次 |
| 古王苏醒 | 第3层的Boss上浮到第1层 | 解锁第5层后概率触发 |
| 裂隙风暴 | 所有产出品质+1级 | 解锁2只守护兽后概率 |
| 万物沉寂 | 产出归零但故事碎片掉落率翻3倍 | 玩家长时间不上线后回归触发 |

## 变现

- 买断制（$9.99）+一个DLC（新深渊层+新兽种，$4.99）
- 没有抽卡、没有体力、没有每日任务

# 中量级 · 深渊圣所：裂隙网络

**体量：15-25人团队 / PC为主 / 每次30分钟-1小时 / 中等规模独立游戏**

## 一句话

**不是一座圣所——是一整片裂隙地下的圣所网络。你和朋友各自经营自己的圣所，通过「裂隙走廊」连接起来。你的守护兽可以去朋友的圣所探险，朋友的兽也会来你家串门。深渊不是一个人的——是你们所有人的。**

## 核心参数

| 项目 | 内容 |
|:----|:------|
| 开发体量 | 15-25人，12-18个月 |
| 画面风格 | 2D手绘+动态光影——像《Hollow Knight》美术升级版 |
| 核心玩法 | 建造+挂机+社交+合作探索 |
| 离线时长 | 24小时满产出（但需要你和朋友之间的圣所连接维持） |
| 社交核心 | 裂隙盟约——2-8座圣所组成的共生网络 |

## 圣所网络

每座圣所有独立的物理位置在「裂隙地图」上。圣所之间的距离由玩家经营决定——走的裂隙越远，能连接的圣所越多，但运输成本越高。

```
        [玩家A的圣所] ———裂隙走廊——— [玩家B的圣所]
              |                              |
         [深层裂隙]                    [深层裂隙]
              |                              |
        [玩家D的圣所] ———裂隙走廊——— [玩家C的圣所]
```

## 社交系统

**裂隙盟约：** 2-8人结成盟约，共享部分探索资源

| 社交功能 | 效果 | 解锁条件 |
|:--------|:-----|:---------|
| 兽串门 | 你的兽去朋友圣所→带回朋友圣所专属产出 | 裂隙走廊开通 |
| 共享祭坛 | 盟约内所有圣所的祭坛互连→全盟产出加成 | 至少3座圣所连入 |
| 联合深渊 | 多个守护兽组队探索深层裂隙 | 盟约所有成员的兽都到达一定等级 |
| 裂隙贸易 | 在盟约内交换深渊产出 | 自动开启 |

**兽串门的体验：** 你上线时看到朋友家的裂隙狐蹲在你的祭坛上——它带了朋友那边的符文石给你。你知道你的岩龙现在也在朋友家的下层挖矿。不像陌生人交易——像邻居互送。

## 更深的深渊

深渊总共20层，最后5层需要盟约联合探索：

| 深渊层 | 产出 | 特点 |
|:------|:-----|:-----|
| 1-5（浅层裂隙） | 基础灵质/低级材料 | 单人可通 |
| 6-10（中层裂隙） | 中级符文/古物碎片 | 单人可通但慢 |
| 11-15（深层裂隙） | 稀有材料/完整古物 | 推荐盟约配合 |
| 16-20（崩解深渊） | 神话材料/最终叙事 | 必须盟约联合——至少3只守护兽同时进场 |

## 变现

- 买断制（$19.99）+ 1-2个DLC
- 皮肤/装饰（不影响数值）

# 重量级 · 深渊圣所：崩解深渊Online

**体量：40-80人团队 / 全平台（PC+主机+手机联动） / 持续运营**

## 一句话

**深渊圣所的大型MMO版本。世界地表已经被静寂瘟疫彻底吞噬——数万玩家各自经营自己的地下圣所，形成覆盖整个星球深渊网络的「庇护国」。守护兽是玩家在这个世界的身份——你的兽就是你的角色。**

## 核心参数

| 项目 | 内容 |
|:----|:------|
| 开发体量 | 40-80人，2-3年 |
| 画面风格 | 手绘+动态光照——2.5D俯视角 |
| 核心玩法 | 建造圣所+挂机养成+大型世界探索+玩家经济+全球深渊事件 |
| 离线时长 | 48小时满产出（数值由圣所等级决定） |
| 经济系统 | 玩家驱动的产出市场——所有材料/古物可交易 |
| 全球事件 | 全球玩家共同对抗「深渊潮汐」——周期性大事件 |

## 玩家驱动经济

所有深渊产出都是玩家生产的——游戏没有NPC商店。

- 你产出的「时之砂」可以卖给其他玩家做升级材料
- 你找到的「古物碎片」可以交易给建筑型玩家解锁特殊圣所装饰
- 你的守护兽探索的路线可以做成「探索地图」**卖给新玩家**——省了他们探路的时间

**核心差异：** 玩家的离线时间不只是自己的资源——是全球经济的输入。你睡得越久，你产出的材料越多→放入市场→其他玩家买来升级→市场活络→你的时间更有价值。

## 全球深渊事件

| 事件 | 周期 | 内容 |
|:----|:----|:------|
| 深渊潮汐 | 每月一次，持续72小时 | 全深渊怪物强度翻倍+掉落大幅提升——全球玩家合作防守圣所网络 |
| 裂隙开拓 | 每季度一次 | 开放新的深渊层——第一批进入的玩家定制该层的命名和产出池 |
| 古王远征 | 每年一次 | 所有玩家联合挑战最终深渊——成功则全服获得永久加成 |

## 圣所国度

玩家可以组成「庇护城」——共享圣所网络形成一座地下城市：

- 你的圣所可以是「住宅区」→产出情感/叙事价值（故事碎片交易）
- 你的圣所可以是「工坊区」→产出装备/符文
- 你的圣所可以是「交易所」→产出流通性/市场活力
- 你的圣所可以是「深渊港」→产出探索路线/新地图数据

**每座圣所都是城市的一部分。每座圣所的产出决定了城市的经济结构。**

## 变现

- 本体买断（$39.99）
- 月卡（$4.99/月）：扩展离线上限+专属装饰
- 皮肤/兽装饰（不影响数值）
- 无抽卡、无体力、无强制每日任务
- 经济系统完全玩家驱动——不打乱供需曲线

# 体量总览

| 级别 | 名称 | 团队 | 开发周期 | 离线时长 | 社交 | 售价 |
|:----|:-----|:----|:--------|:--------|:----|:----|
| 🐣 **微型** | 口袋版 | 1人 | 3个月 | 2h | 无 | 免费+广告/内购 |
| 🐥 **轻量** | 静寂石室 | 5-10人 | 6-8个月 | 8h | 弱（排行榜） | $9.99买断 |
| 🦅 **中量** | 裂隙网络 | 15-25人 | 12-18个月 | 24h | 强（盟约系统） | $19.99买断+DLC |
| 🐉 **重量** | 崩解深渊Online | 40-80人 | 2-3年 | 48h | MMO级（全球） | $39.99+月卡 |

## 一句话区分

| 级别 | 你卖的是什么 |
|:----|:------------|
| 口袋版 | **电子宠物的升级版**——比电子宠物会赚钱 |
| 静寂石室 | **一座属于你的地下庇护所**——拆礼物一样的惊喜 |
| 裂隙网络 | **你和朋友的地底王国**——邻居互送式社交 |
| 崩解Online | **一个让离线时间变钱的平行世界**——全球玩家社群的经济网络 |
