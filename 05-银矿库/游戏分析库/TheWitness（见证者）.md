# The Witness（见证者）· 十元分析

## 0. 一句话定义

**一个岛上到处都是线谜题。你解完一条线——门开了。你走进下一间屋子——又是线谜题。你以为你在学怎么解谜——其实你是在学**看的规则**。**

每个谜题的答案都藏在环境里——但你要先学会「看」。

## 一、霜判：xn（规则型）

**置信度：9.5/10**

### 归属理由

**xn（规则系统/看的规则）**
- 整个游戏就是一套关于「如何看」的规则教学——太阳的倒影、树的形状、墙壁上的阴影……每个谜题的规则是从环境里**学来的**，游戏从不告诉你
- 每种新谜题类型=一套新的xn规则让你自己发现
- 环境本身是线索：第一人称视角看到的东西本身就是解谜

### 误判防线

| 易误判为 | 为什么不是 |
|:---------|:-----------|
| nx 计算型 | 不是算——是**理解规则**。你知道规则后谜题就不难了 |
| 空间型 n | 空间感很强但不是容器——空间是规则教学的载体 |

**主对子：xn↔nx** — 你遇见新规则(xn)→你尝试理解(nx)→你懂了→新的xn出现。这个循环就是The Witness的全部。

**动态链：**
```
xn（遇到新谜题/不知道规则）→ nx（观察/试错/推导规则）→ xn（懂了/规则清晰了）→ n（小岛展开/更多谜题等着你）
```
