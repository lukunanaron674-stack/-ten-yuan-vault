# 信念因果 vs 能力因果 · 因果型新分类轴

## 来源

第46轮 · Slay the Princess（斩杀公主）分析

## 核心发现

在已有的因果型子类划分体系（动作因果/杠杆因果/具身因果/闭合因果）之外，Slay the Princess 揭示了因果型的第五条子类分化轴：**玩家在循环中强化什么**。

### 能力因果（Power Causality）

| 属性 | 内容 |
|:----|:------|
| 定义 | 玩家在循环中积累操作精度、build强度或资源量 |
| 子类型 | 加法叠加（动作因果）、乘法叠加（杠杆因果）、物理可见（具身因果）的因果放大均属此类 |
| 代表 | Hades（熟练度+天赋）、杀戮尖塔（卡组构筑）、XCOM（装备+技能）、Balatro（倍率乘法） |
| 特征 | 因果链终点可量化（通关/分数/时长），玩家变强的信号在外在可见 |
| 后遗症 | 循环越多→玩家越强→后期因果计算逐渐被数值碾压替代 |

### 信念因果（Belief Causality）

| 属性 | 内容 |
|:----|:------|
| 定义 | 玩家在循环中不强化数值——只改变自己的信念方向 |
| 子类型 | 闭合因果的叙事级应用 |
| 代表 | Slay the Princess（每一次选择定义身份而非堆叠能力）、Undertale（部分） |
| 特征 | 因果链终点不可量化（你是谁/你相信什么），玩家「变强」的信号完全内隐 |
| 后遗症 | 循环越多→选择越重→后期因果计算更复杂而非更简单 |

## 与已有分类轴的关系

信念因果与已有四轴（因果链长度/因果闭合度/抽象vs具身/加法vs乘法杠杆）正交互补，形成因果型分析的五维坐标系：

```
因果型五维坐标系：
  1. 因果链长度（XCOM 2 长链 → Into the Breach 短链/密链）
  2. 因果闭合度（闭合 → 开放 → 混沌）
  3. 因果抽象度（抽象脑内计算 → 具身物理可见）
  4. 因果放大率（加法动作因果 → 乘法杠杆因果）
  5. 因果强化方向（能力因果 → 信念因果） ← 新增
```

## 判断方法

| 问题 | 能力因果 | 信念因果 |
|:----|:--------|:--------|
| 循环中你变强了吗？ | 是（数值/熟练度/资源） | 否（认知/信念/身份变化） |
| 变量的类型是什么？ | 可量化的数值 | 不可量化的信念 |
| 游戏问的问题 | "你还能更强吗？" | "你相信自己是什么？" |
| 后期体验 | 因果计算被强度碾压 | 因果计算被选择的重量替代 |

## 迁移价值

信念因果模式可迁移至以下设计方向：
1. **叙事选择游戏** — 选择的意义不在分支数量，在选择的信念回应性（每个选择让玩家更清楚自己是谁）
2. **角色扮演游戏的"伪数值化"选择** — 当所有选择都有"最优解"时（如《巫师3》的帮A/B），信念因果失效——玩家是在"找正确答案"而非"选择信念"
3. **元叙事设计** — 当玩家意识到自己在"选什么类型的玩家"时，信念因果开始运作
4. **反收集癖设计** — 信念因果天然对抗"我要看完所有内容"的强迫倾向，因为选择某一信念意味着主动放弃其他可能

## 已知案例表

| 游戏 | 能力/信念 | 判断依据 |
|:----|:---------:|:---------|
| Hades | 能力 | 循环中武器等级+天赋提升 |
| 杀戮尖塔 | 能力 | 卡组构筑是数值累积 |
| XCOM 2 | 能力 | 装备+士兵等级可量化 |
| Balatro | 能力 | 倍率叠加是数值放大 |
| Into the Breach | 能力 | 飞行员技能+装备可量化 |
| **Slay the Princess** | **信念** | 玩家不变强，只改变信念 |
| Undertale | 混合 | 数值部分（战斗）是能力因果，道德路线（杀/饶）是信念因果 |
| 最后生还者（TLOU） | 混合 | 游戏玩法是能力因果（资源收集+战斗），叙事选择是信念因果（乔尔的最后选择） |
