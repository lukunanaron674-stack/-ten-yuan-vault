# 跨屏本体与 n 隐式度光谱

第52轮从 Spelunky 2 分析中提取。

## 核心论点

当因果链（zx）强度足够大时，因果型游戏不需要稳定的本体（n）。Spelunky 2 的探险者几乎没有存在感（无名字/无对话/无技能树），但游戏的核心体验并未受损——因为本体不在角色里，在角色与程序世界之间的交互平面上：每次按键瞬时创造（脉冲式 n）、每次按键消失。

## n 隐式度光谱

| 级别 | 示例 | n 的显式强度 | 说明 |
|:----|:-----|:----------:|:-----|
| n 高度显式 | Hades | 9/10 | Zagreus 有完整人格/家庭/情感弧，因果链是 n 的载体 |
| n 中度显式 | Into the Breach | 5/10 | 飞行员有技能和背景但可牺牲替换 |
| n 半隐式 | Slay the Spire | 3/10 | 角色仅有初始遗物和外观，玩家投射 |
| n 极隐式 | **Spelunky 2** | **1/10** | 角色几乎不存在，因果链即本体 |
| n 完全隐式 | 围棋 | 0/10 | 无角色，因果纯抽象 |

## 迁移价值

1. **roguelike/causal 游戏的 n 设计决策参考**：当因果系统足够深层时，可以省略角色塑造的开销。
2. **判断因果型游戏「本体溢出」的校准工具**：如果因果型游戏的角色被设计得过于丰富（如 Hades 的完整家族关系），这说明游戏可能在往本体型偏移——即因果链不是目标，角色塑造才是。
3. **类型边界识别工具**：n 隐式度低于 3/10 的游戏必然属于因果型。如果 n 低于 3/10 但不是因果型，一定存在某种设计矛盾。
