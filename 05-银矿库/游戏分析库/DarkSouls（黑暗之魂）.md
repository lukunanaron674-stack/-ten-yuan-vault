# Dark Souls（黑暗之魂）· 十元分析

## 0. 一句话定义

**你死了。你活了。你死了。你活了。世界是灰的、暗的、没有人告诉你该去哪里。每一场Boss战你都会死十几次——但每一次你都学到了什么。**

不是难——是**公平的难**。你死的每一次都是因为你没学会。

## 一、霜判：xz+nz（命运型）

**置信度：9.5/10**

### 归属理由

**xz（边缘/临界/陨落的世界）**
- 罗德兰本身就是xz——一个在火之时代和黑暗时代之间的「正在熄灭」的世界
- 每一场Boss战你都在死亡边缘——差一刀、差一瓶药、差一次翻滚
- 不死人的诅咒=xz的人格化：你不属于生者也不属于死者，你卡在中间

**nz（等待/守望）**
- 篝火=等待的物理化——你坐在那里等自己恢复、等下一场战斗、等不知道什么时候会来的第二次机会
- 每个NPC都在等：索拉尔在等太阳、基亚兰在等她的王、洋葱骑士在等一个能和他碰杯的人
- 整个故事是关于等待的：灭火=等着一切结束、传火=等着继续燃烧

### 误判防线

| 易误判为 | 为什么不是 |
|:---------|:-----------|
| 因果型 | 你死了不是因为「我选错了build」——是因为你还没学会Boss的节奏 |
| 时间型 | 有死亡惩罚但不是核心——时间不是规则，是循环 |

## 二、钧

| 十元 | 内容 | 强度 |
|:----|:----|:----:|
| xz | 临界状态/陨落世界/死亡边缘 | 10 |
| nz | 等待/篝火/循环 | 9 |
| z | 不想放弃的冲动 | 7 |
| zx | 执行——翻滚/背刺/弹反 | 8 |
| n | 罗德兰世界的连通地图 | 8 |

**体量：10/10**

**主对子：xz ↔ nz** — 你在边缘(xz)等(nz)一个机会。边缘越危险，等待越漫长，但翻盘的那一瞬间越值得。

**动态链：**
```
起点：xz（活尸化/不死诅咒/被遗忘的使命）
  → nz（坐篝火/等恢复/等第二次机会）
    → z（不想变成活尸/再试一次）
      → zx（练翻滚/练弹反/记住了Boss的每一招）
        → xz（丝血过Boss/站在胜利和死亡的边界上）
          → n（世界看到了你/你传火了/你灭火了/你成了新的边缘）
```

**核心动态：xz→nz→z→zx→xz→n**
