# Omori · 十元分析

## 0. 一句话定义

一次创伤记忆的十元级具象化——玩家不必打败深层悲剧，只需与它共存。表面是 RPG 冒险，实则是本体型（n）用命运型锁（xz）包裹内心世界（zn），再通过时间型结构（x 并 z）展开的嵌套创伤叙事。

## 一、霜 · 主维归属

**霜判：本体型（创伤本体）+ 命运型（内心锁）+ 时间型（结构壳）**
**置信度：8/10**

### 归属理由

1. **本体为核** — Omori 的终极答案是「n（本体）＝ 记忆的总和」。玩家的目标不是打败最终 BOSS，而是面对自己压抑的真相。游戏的全部系统（战斗、探索、解谜）都服务于「你是谁」这个问题。
   
2. **命运为锁** — 白色空间（White Space）中的 Omori 角色代表了 nz 被封锁后的残存状态。Headspace 循环重复的日常（xz 中的永恒轮回）不是因果型的技能升级，而是命运型的等待觉醒——玩家被困在「重复知道这是梦但无法醒来」的状态。

3. **时间型为壳** — 游戏使用空间时间型的结构（x 并 z）来展开叙事：现实世界（Faraway Town）的三天线性推进，与 Headspace 的循环日常形成对照。这不是 Outer Wilds 式的 xn（时间本身就是内容），而是 x 作为结构容器承载本体内容。

4. **创伤记忆驱动全部设计** — 从战斗系统（情绪机制替代血量条）到叙事分支（结局取决于是否「记住」），一切设计都直接源自「如何面对不可承受的记忆」这一本体问题。

### 误判防线

| 易误判为 | 为什么不是 | 颜色等级 |
|:---------|:-----------|:--------:|
| 因果型（RPG 有战斗升级） | 战斗系统不驱动因果——情绪（Emotion）机制不是技能树，而是情境反应。升级并不增加选择自由度，而是让玩家在已知路径上走得更远。真正的因果链锁发生在叙事层（真相揭露），而非战斗层。 | 🔴 |
| 空间型（有探索/迷宫） | 探索不是目标而是容器。Headspace 的空间不是因为探索有趣才存在的，而是因为「记忆空间的形态反映了心理防御机制的结构」。这与 P5/Undertale 的空间型的区别在于：空间本身没有自己的逻辑——它是本体的投影。 | 🟡 |
| 命运型（有重复/轮回） | Headspace 的重复确实是命运型的特征（xz），但这是表层结构（包装纸），不是内核（礼物）。终极叙事落点是 n（你接受了自己）而非 xz（你打破了轮回）。命运型是手段，本体型是目的。 | 🟡 |

### 体量

**8/10** — Omori 不是一部体量巨大的游戏（主线约 20-30 小时），但它的内容密度极高。Headspace 的每个区域都是心理防御机制的隐喻，每个角色都是 Sunny 自我的一部分。体量不在于「可做内容的数量」，而在于「解读深度」的层级。

### 关系对子

**主对子：n（创伤本体）↔ zn（内心世界）**

这是 Omori 最核心的一对关系——也是十元体系中罕见的「本体型内部对子」。

在大多数本体型游戏中，n（本体）与外部世界（x/nz）相互作用。但在 Omori 中，n 创造了自己的子世界（zn），这个世界有独立的物理法则、历史、生态系统和日常循环。这一点在十元框架中是非典型的：

- **GRIS/Journey 等标准本体型**：n（情感状态）通过 zn（艺术化世界）来表述，但 zn 是单向的（n→zn，玩家的情感投射到世界上）。
- **Omori**：zn 拥有自己的「意志」——Headspace 的角色（投影朋友们）拒绝被唤醒。Basil 在 Black Space 中的被投射形象是一个被折磨的恐惧存在，它独立于 Sunny 的清醒意志运行。

这意味着 Omori 在十元上创造了 **n→zn→nz→n 的闭环**：创伤创造内心世界 → 内心世界拒绝被现实打破 → 现实逼迫面对 → 面对重新定义创伤。在这个闭环中，zn 不是被动容器，而是主动参与者。

这一发现可能提示一个更大的结构：**本体型游戏可以分作「单层本体型」（n→nz 单向，如 GRIS）和「递归本体型」（n↔zn↔nz↔n 闭环，如 Omori）**。递归本体型总是关于创伤记忆的，因为只有创伤才能创造出一个足够自洽以至于可以反噬其创造者的内心世界。

### 动态链

起点（失去 Mari 的创伤）→ 创造 Headspace 逃避 → 日常循环维持内心世界稳定 → 现实世界时间在推进 → 循环被第一次「回到现实」打破 → 真相碎片浮现 → Bad Ending（无法面对）→ Good Ending（接受开放结局）

**核心动态：n（创伤）→ zn（逃避世界）→ xz（循环锁）→ x并z（线性推进）→ nz（现实面对）→ n·改（接纳）→ nx（开放未来）**

## 三、值得记的发现

### 发现一：「情绪生克」作为 n（本体）直接接管战斗系统

Omori 的战斗系统用「情绪三态」（Happy/Angry/Sad）替代了传统的 HP/MP 系统——这个被很多玩家视作「有趣的 RPG 机制创新」的设计，在十元框架下有一个更深层的解读：

**这是 n（本体）直接吃掉 z（战斗机制）的罕见案例。**

在 Hades 中，玩家通过 zx（技能搭配）来达成 nx（通关），n 是副产物（角色关系）。在 Undertale 中，战斗本身可以被完全规避（x并z 覆盖 z）。但在 Omori 中，战斗系统本身就是本体的一部分——你无法区分「你在战斗中处于 Happy 状态」和「你作为 Sunny 在内心深处体验快乐的感觉」，因为它们在系统层面是同一个东西。

这形成了一个极其特别的十元映射：**本体型游戏的战斗系统不应该是本体型之外的独立系统，而应该是本体的直接外化。** 情绪克制表（Happy > Angry > Sad > Happy）不是游戏设计者对「平衡」的追求，而是对「心理防御机制如何互相克制」的模型化。

这一设计模式可以被提炼为 **「本体接管公式」**：当一个游戏的战斗系统不使用传统的「血量条+伤害值」而是使用「情感/信念/身份状态」时，它很可能正在发生 n→z 的本体接管。这一公式可迁移至任何试图把「你是谁」而非「你多强」作为战斗核心的游戏。

### 发现二：Omori 位置——在 Undertale 与 Silent Hill 2 之间的本体型光谱

Omori 在十元框架中的位置极其有趣：它夹在 Undertale（空间型，x并z 为主导）和 Silent Hill 2（空间型内嵌本体，x并z+n 为主导）之间。

```
Undertale ───────────── Omori ────────────── Silent Hill 2
  x并z >> n              n >> x并z            x并z + n（平衡）
  空间叙事               创伤本体                空间内嵌创伤
  战斗可规避             战斗是本体外化            战斗是命运对峙
  元叙事觉醒              记忆觉醒                 内疚觉醒
```

Omori 的独特性在于它是三者中唯一「不依赖外部环境产生意义」的——Undertale 需要地底世界作为舞台，SH2 需要寂静岭作为镜子，但 Omori 的 Headspace 完全由创伤创造，没有独立存在的理由。它是最「本体型」的心理恐怖游戏。

### 发现三：「递归本体型」的定义条件

从 Omori 的分析中可以提炼出「递归本体型」（Recursive Entity Type）的识别条件：

1. **n 产生 zn** — 创伤/记忆创造出一个自洽的内心世界（不仅是隐喻或风格化的外部世界）
2. **zn 具有反噬能力** — 内心世界的逻辑压倒了 nz 的逻辑（玩家不想面对现实因为 Headspace 更舒服）
3. **战斗系统被 n 接管** — 情绪状态 = 角色状态 = 战斗状态，三者无法区分
4. **结局取决于对 n 的态度** — 不是「你打败了什么」而是「你接受/逃避了什么」

已分析的游戏中，除了 Omori 外，**只有 Hellblade（感知解锁框架）部分满足这些条件**——但 Hellblade 的 zn 是外部强加的精神疾病（客观存在），而非由创伤创造的自生世界（主观存在）。Omori 在当前 56 部游戏中是递归本体型的唯一完整案例。

## 四、典 · 评分

| 标准 | 评分 | 验证 |
|:----|:---:|:-----|
| 十元自洽性 | 9.0/10 | n→zn→xz→x并z→nz→n→nx 的动态链逻辑严丝合缝。每种子类型都能找到游戏中的明确对应物。唯一的扣分点：战斗系统的情绪克制表（z 层面的生克）与叙事层面的生克是否完全对应，需要进一步验证。 |
| 分析覆盖度 | 8.5/10 | 涵盖了本体、命运、时间三条主线，以及情绪战斗、记忆时间两个支线。但 Omori 中还有一些微妙的十元关系未充分展开：Basil 在 Black Space 中的角色（可能是 xn→x 的附加链？），以及游戏末尾的「门」选择（n→nz 还是 n→xn 的分叉点）。 |
| 误判防线力 | 9.0/10 | 三条防线的区分强度很高，尤其「情绪生克不等于因果升级」的论证有说服力。递归本体型与单层本体型的区分增加了分类的精细度。 |
| 实用迁移性 | 8.5/10 | 「本体接管公式」可直接迁移至任何情感驱动的战斗游戏（尤其日式 RPG）。递归本体型的四条件可作为心理恐怖游戏的设计模板。但「递归本体型」作为一种子类型的普及度仍取决于是否有更多案例出现。 |

**总评：8.8/10**

## 四、封存句

不是每个游戏都希望玩家看到一切；Omori 是第一个让「选择不看到」也成为本体一部分的游戏。在它创造的世界里，遗忘不是弱点——有时遗忘是为了让记住变得更重。
