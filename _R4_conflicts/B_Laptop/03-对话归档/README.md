# 对话归档

这里保存长对话的本地归档轮次，用来对抗长时间聊天后的上下文遗忘。

入口：

- [[当前会话状态]]
|- [[2026-05-13-归档轮次-001]]
|- [[2026-07-09_游戏分析Batch漫画归档+cron工作流升级]]
|- [[长期记忆协议]]
- [[总入口]]
- [[F12总控载体蓝图]]
- [[v0.3-工单断点]]

## 使用方式

当一次对话开始变长，先更新 [[当前会话状态]]。

当完成一个阶段、做出关键决定、或即将进入下一批任务时，新建一个归档轮次，例如：

```text
2026-05-13-归档轮次-002.md
2026-05-13-归档轮次-003.md
```

每个归档轮次都要能让下一次对话直接恢复工作，不需要重新解释全部历史。
