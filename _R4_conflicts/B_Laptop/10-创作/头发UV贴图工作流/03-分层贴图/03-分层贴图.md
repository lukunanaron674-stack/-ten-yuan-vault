# 03 分层贴图

## 目标

把已经对齐的柔粉头发贴图拆成可以单独修改的颜色、发丝和高光三层。每一层保持相同的 2048 × 2048 画布、真实 UV 坐标和 20 px 外扩，重新叠加后必须与 Maya 使用的最终贴图一致。

## 图层顺序

从上到下：

```text
03 高光图层
02 发丝图层
01 颜色图层
```

三层均使用普通叠加、100% 不透明度；发丝层和高光层通过自身 Alpha 控制实际强度。

## 三层职责

| 图层 | 内容 | Alpha |
|---|---|---|
| 颜色图层 | 基础粉色、根梢渐变、宽发束明暗、岛边压暗 | UV 与外扩区域不透明 |
| 发丝图层 | 顺发根到发梢方向的深浅细丝 | 透明背景，局部半透明 |
| 高光图层 | 全头世界空间亮带、辫子分节亮带 | 透明背景，局部半透明 |

## 合成规则

每个透明层使用标准 Alpha 合成：

```text
输出颜色 = 下层颜色 × (1 - Alpha) + 当前层颜色 × Alpha
```

发丝层同时包含浅色发丝和深色发丝。两类发丝先在同一层中按 Alpha 合并，再整体压到颜色层上。高光层最后叠加，因此调高或调低亮带不会破坏基础颜色和发丝线。

## 当前关键参数

| 项目 | 当前值 |
|---|---:|
| 画布 | 2048 × 2048 |
| UV 像素连通区 | 111 |
| 边缘外扩 | 20 px |
| 全头共用亮带 | 世界 Y = 126.6152 |
| 发丝方向 | 发根 → 发梢 |
| 图层模式 | Normal |
| 图层顺序 | 高光 / 发丝 / 颜色 |

## 为什么亮带不能逐岛单独画

逐个 UV 岛计算亮带会让相邻发片在模型接缝处出现高度错位，侧面看起来像亮带卡住。当前处理方式是：

```text
头部所有发片
    ↓
共用世界空间 Y = 126.6152
    ↓
亮带跨 UV 接缝连续通过

辫子
    ↓
按每一节自己的发流方向旋转高光
```

## 外扩规则

三张图层都必须各自保留 20 px 外扩，不能只给最终合成图外扩。否则单独导入图层后，Maya 缩小采样时仍会在 UV 边缘产生黑缝。

## 使用方法

### 分开的 PNG

在绘图软件中按原始尺寸导入三张 PNG，不进行自动裁剪或缩放。按“颜色 → 发丝 → 高光”的顺序从下到上放置。

### ORA 分层文件

`hair_soft_pink_layers.ora` 是真正包含三层和图层名称的 OpenRaster 文件，可在支持 ORA 的绘图软件中直接打开。归档中同时保留独立 PNG，避免软件不支持 ORA 时无法编辑。

## 验收结果

- 三层重新合成文件与 Maya 当前贴图字节一致。
- 111 个 UV 连通区内部没有黑洞。
- 发丝层和高光层均为 RGBA 半透明图层。
- ORA 容器结构和内部图片校验通过。
- 正、背、左、右四个视图均成功渲染。
- 左右侧头部亮带连续，没有在发片接缝处卡住。
