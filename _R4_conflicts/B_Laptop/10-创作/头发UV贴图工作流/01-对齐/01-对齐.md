# 01 对齐

## 目标

把模型上的每一个面、每一个 UV 岛和每一条发流方向固定下来，使后续图片生成、二分和上色都严格回到 `头发.ma` 的原始 0–1 UV 坐标。

## `.ma` 与 `.mb`

- `.ma` 是 Maya ASCII 文本，可以直接读取顶点、面、UV 索引、材质和贴图路径。
- `.mb` 是 Maya 二进制，不能用普通文本方式可靠读取；需要 Maya 打开后转存 `.ma`，或通过 Maya API 导出数据。
- 因此，本流程的稳定入口是 `附件/头发_原模型.ma`。

## 坐标规则

UV 原点在左下，PNG 像素原点在左上。2048 图的转换是：

```text
pixel_x = round(u × 2047)
pixel_y = round((1 - v) × 2047)
```

必须保持：

- 完整 0–1 UV 空间。
- 2048 × 2048 尺寸。
- 不裁剪、不缩放画布、不移动或重排 UV 岛。
- 最终绘制只在真实 UV 遮罩内生效。

## 对齐过程

1. 从 `.ma` 读取可见 mesh、顶点、面、UV 坐标和 UV 索引。
2. 把每个面按原 UV 多边形栅格化，生成精确 UV 遮罩。
3. 对遮罩做 8 邻域连通区编号，得到 UV 岛 ID。
4. 记录每个 Maya 面对应的 mesh、face index、vertex indices、UV indices、UV 多边形、世界坐标质心和 UV 岛 ID。
5. 对每个 UV 岛计算主轴和截面宽度，建立沿长度方向的局部坐标。
6. 用模型顶点的世界 Y 与 UV 主轴投影做相关性判断，确定发根和发梢哪一端。
7. 把来源图沿发流主轴和每段实际宽度变形到目标岛，而不是只按外接框拉伸。
8. 用真实 UV 岛重新裁切，并向边缘外扩 20 px。

## 发根到发梢

每个岛的主轴由像素协方差的主特征向量得到。方向判断规则：

```text
UV 顶点沿主轴的位置 t
        ↓ 与世界坐标 Y 做相关性
相关为正：主轴最大端是发根，方向取 -major
相关为负：主轴最小端是发根，方向取 +major
```

方向检查图中：

- 黄色圆点：发根。
- 青色箭头：指向发梢。
- 极小残片仍记录在数据中，但不绘制容易误导的方向箭头。

## 验收条件

- 输出必须是 2048 × 2048。
- 所有 3698 个面都能对应到 UV 岛。
- UV 岛内部不能出现意外黑洞。
- UV 线框叠回后，边缘和尖端不得越岛或错岛。
- 发根到发梢箭头必须和模型实际方向一致。
- 贴图边缘必须有 20 px 外扩。
