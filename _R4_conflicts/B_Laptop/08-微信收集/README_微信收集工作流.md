# 微信收集工作流

目标：把微信里的聊天、图片、文件、链接收集到 Obsidian，再由 Codex 整理成可用笔记。

## 分工

```text
影刀：打开微信、复制聊天、保存图片/文件
Codex：去重、分类、提炼待办、写入 Obsidian
```

## 固定目录

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\08-微信收集
```

子目录：

```text
inbox        原始聊天文本
attachments  图片、文件、语音导出等附件
已整理        Codex 整理后的笔记
workflows    影刀流程说明
outbox       影刀执行结果
```

## 最小流程

1. 你打开微信电脑版，进入目标聊天。
2. 影刀复制当前聊天窗口可见内容或搜索结果。
3. 影刀保存到 `inbox`。
4. 你告诉 Codex：“微信收集好了”。
5. Codex 扫描 `inbox`，整理成 Markdown。

## 安全规则

- 不破解微信数据库。
- 不读取登录凭证。
- 不自动发送消息。
- 不删除微信消息。
- 只处理你在微信界面中可见、可复制、可另存的内容。

## 推荐文件名

```text
微信_联系人或群名_主题_YYYY-MM-DD_HH-mm.txt
```

示例：

```text
微信_画师群_角色设定讨论_2026-07-10_0105.txt
```
