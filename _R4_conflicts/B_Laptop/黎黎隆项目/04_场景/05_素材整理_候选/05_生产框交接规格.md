# 场景整理→生产框交接规格

> [!warning] 接口边界
> 这是整理框给生产框的候选输入协议。它不提交生图、不启动 H3、不锁定结果，也不把“整理通过”当成“理论通过”或“生产通过”。

## 可接收的候选场景结构

- `NZ连续生体/遗留大骨架`：弧面、肋条、椎节、拱架，承担空间主方向。
- `Z局部接口`：卡箍、锁环、挂点、桥板、维修池、环形工位；只放在需要维护/承力/转运的节点。
- `三层纵深`：近景重复件 + 中景主体/接口 + 远景暗腔/拱架/边界。
- `单一主动作`：穿行、检修、卡接、悬挂回弹、桥板落位、校准中的一个。
- `点色`：一个功能色只标操作节点；其余环境色保持克制。

## 每个生产子任务必须携带

1. `source_image_ids`：至少一个 IMAGE-ID / I04-IMG-ID。
2. `source_paths` 与 SHA256：引用真实文件，不只写文件名。
3. `world_claim_level=CANDIDATE_NOT_FROZEN`。
4. `style_claim_level=CANDIDATE_NOT_FROZEN`。
5. `approved_background=false`，除非后续有独立用户验收回执。
6. `keep_elements`：要保留的大形、接口和层级。
7. `avoid_elements`：IP 造型、逐根照片纹理、全景机械覆盖、无证据的编号/权限/队列制度。
8. 结果回写：候选路径、生成状态、人工审核状态、SHA256；不覆盖原图。

## 生产前硬门

- `endpoint → position → mechanism_lifecycle → observed_relation → chain_causality → chain_quality` 逐层通过后才可扩大镜头用途。
- 位置合法不等于机制可调用；机制候选不等于真实事件；真实事件不等于高质量动态链。
- 任何生产图先标 `CANDIDATE/STAGING`；没有人工验收不能锁定或交付。
- 本轮缺失与版本冲突（seed 图、v3 参考墙、D03 活动版）不得作为默认输入。

## 恢复项可选输入

六张已实际解码并做联系表检查的候选可作为附加输入：`IMAGE-013`（峭壁构筑）、`IMAGE-069`（设备示意）、`IMAGE-091`（悬置平台）、`IMAGE-109`（有机巨构氛围）、`IMAGE-139`（棚架工坊）、`IMAGE-340`（悬浮远景）。

它们仍是 `UNVERIFIED / CANDIDATE`，生产任务必须携带对应 SHA256，并在结果回写中保留来源。23 个 relocated exact-hash 来源可回查但仍保持 UNVERIFIED；IMAGE-306 空文件禁止进入输入清单。详见 [[06_不可读恢复核验]]。

## 交接状态

- 整理层：`PARTIAL_PASS / RESEARCH_DELIVERABLES_READY`。
- 生产层：可领取上述候选规格，但需自行生成、验收和回写；本文件不代表已生成。
- 用户确认缺失/版本冲突前，不得把 v4、归档 D03 或任何外部图替换为 canonical。
