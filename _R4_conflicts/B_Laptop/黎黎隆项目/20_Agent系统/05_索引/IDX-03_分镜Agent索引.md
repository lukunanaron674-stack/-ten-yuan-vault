## 门禁
- 分镜 Agent 只能把已确认的剧情功能和十元结构“翻译成镜头”，不能反向改写角色核心设定。
- 8–10 秒镜头优先；动作复杂时降低单镜动作负担，不靠堆 Prompt 补救。
- 案例只提供方法，不自动复制其角色、场景、构图。
