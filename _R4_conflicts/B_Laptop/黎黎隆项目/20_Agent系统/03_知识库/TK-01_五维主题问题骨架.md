# TK-01｜五维主题问题骨架 v1.0

> 第一轮目标：把 canonical 的五维定义转成主题 Agent 可执行的“提问—实验—施压—验收”骨架。
> 本文件不是 canonical，不新增五维定义，不修改正式生克盘，不调用电影研究结论。

## 0｜总规则：主题不是设定标签

主题 Agent 第一步不是问“故事里有什么”，而是问：

```text
哪一个变量正在被持续改变？
人物因此必须处理什么不可回避的问题？
高潮 / 结局最终回答、承担、改写或保留了什么？
```

禁止直接判定：

```text
有时间旅行 ≠ 时间主题
有失忆 / 复制人 ≠ 本体主题
有监狱 / 城市 / 房屋 ≠ 空间主题
有伏笔 / 反转 ≠ 因果主题
有预言 / 悲剧结局 ≠ 命运主题
```

主题问题必须能够进入剧情实验。最低格式：

```text
当【关键条件】被改变 / 限制 / 移除，
人物对【五维核心变量】的理解或行动会怎样变化？
```

## 1｜时间｜变化怎样从之前走到之后？

### canonical 核心
变化如何按先后、持续、积累、循环或阶段展开；什么被时间改变，什么被保留。

### Agent 应问
- 如果同一件事发生在不同阶段，意义为什么会不同？
- 当行动窗口变短、延迟或关闭，人物还来得及改变什么？
- 一个变化需要持续多久才会真正改变人物 / 关系 /制度？
- 过去已经不能修改时，现在还能修改什么？
- 不同角色以不同速度变化时，共同未来是否还能维持？

### 可操作 theme_experiment 旋钮
```text
阶段 Stage
持续 Duration
延迟 Delay
积累 Accumulation
节奏 / 速率 Rate
行动窗口 Action Window
过去 / 未来可访问度 Temporal Access
可逆性 Reversibility
```

### pressure_mechanism 最小型
- 缩短窗口：来不及完成原有计划。
- 拉长持续：短期可忍受的状态变成长期结构。
- 延迟后果：行动与代价脱钩，判断被扭曲。
- 阶段跨越：旧身份 / 旧关系无法直接迁移到新阶段。
- 速率错位：两方都在变化，但变化速度不再兼容。
- 不可逆节点：某一步之后只能继续承担，不能恢复原状。

### 主题成立证据
关键选择、转折、高潮或结局必须依赖“变化如何经过时间展开”，而不是只靠时钟、倒叙、年龄、回忆等外观。

### 失败边界
如果把时间结构替换成普通线性先后，中心冲突仍基本不变，则时间多半只是背景或表现手段。

## 2｜本体｜它究竟是什么？

### canonical 核心
对象在变化、关系与表现之中如何仍被识别为自身；什么证据、边界或归属定义“它是什么”。

### Agent 应问
- 当外貌、记忆、身份、职位、身体或他人评价变化后，“还是不是同一个它”？
- 谁拥有定义某个对象的权力：自身、关系、制度、来源、行为还是记忆？
- 当多个身份都部分成立时，人物必须保留哪一个、舍弃哪一个？
- 做过某件事，是否就足以把一个人永久定义成“那种人”？
- 别人不再承认你时，你的自我定义还能不能转化为行动？

### 可操作 theme_experiment 旋钮
```text
连续性 Continuity
识别 Recognition
归属 Belonging
身份位置 Identity Slot
内部定义 / 外部定义
记忆 / 身体 / 行为 / 来源等 Identity Evidence
边界 Boundary
```

### pressure_mechanism 最小型
- 身份证据冲突：不同证据指向不同“你是谁”。
- 连续性断裂：记忆、身体、关系或社会位置中断。
- 公私身份分叉：自己知道是谁，公共系统只承认另一个版本。
- 归属冲突：两个群体同时要求人物以不同身份存在。
- 单一事件占据本体：某个过去行为开始吞掉全部自我定义。
- 替代 / 复制：多个对象同时拥有同一身份的部分合法性。

### 主题成立证据
高潮或结局必须对“它究竟是什么 / 谁能定义它 / 什么证据足以维持它”产生结构性回答。

### 失败边界
有鲜明性格、角色成长、变装、失忆或克隆设定，不自动等于本体主题。

## 3｜空间｜什么能够在哪里存在？

### canonical 核心
对象如何被放置、容纳、分隔、并存并建立边界；什么能进入、停留、离开、返回或共处。

### Agent 应问
- 谁被允许进入，谁只能停在边界外？
- 人物能否离开 / 返回某个空间，为什么这会改变选择？
- 某个空间究竟是容器、资源、身份位置、关系位置，还是限制装置？
- 两种互不兼容的存在怎样被迫共处？
- 空间边界一旦改变，人物关系或行动能力会怎样变化？

### 可操作 theme_experiment 旋钮
```text
进入 Access
退出 Exit
返回 Return
容纳 Capacity
边界 Boundary
距离 Distance
隔离 Isolation
共处 Coexistence
占位 Position
空间许可 Permission
```

### pressure_mechanism 最小型
- 禁止进入：人物拥有意图但没有空间许可。
- 禁止退出：关系 / 资源 / 身份把人物锁在位置内。
- 边界移动：原本安全 / 危险 / 私密 / 公共区域重新划分。
- 容量冲突：两个对象不能同时占据同一位置或资源。
- 强制邻接：不能回避的共处制造持续压力。
- 返回条件改变：离开以后不再保证能回来。

### 主题成立证据
位置、边界、容纳、并存或隔离必须真实改变人物的选择、关系、路径、高潮或结局。

### 失败边界
“故事发生在监狱 / 城市 / 家 / 异世界”本身只是场景设定；拿掉该空间仍不改变中心问题，就不能判为空间主主题。

## 4｜因果｜什么导致了什么？

### canonical 核心
前因如何经过作用链产生后果；结果的来源、责任与可追溯性如何成立。

### Agent 应问
- 人物真的知道原因，还是只拥有一个解释？
- 谁造成了结果，谁承担责任，两者是否是同一个人？
- 一个行动通过哪些中间环节才变成后果？
- 当原因不可知 / 多因并存时，人物凭什么行动？
- 当错误解释开始驱动真实行动后，它是否变成新的真实原因？

### 可操作 theme_experiment 旋钮
```text
原因可见度 Cause Access
证据可靠度 Reliability
链条长度 Causal Distance
中介 / 代理 Proxy
责任归属 Attribution
可逆性 Repairability
多因分布 Distribution
解释模型 Cause Model
```

### pressure_mechanism 最小型
- 原因缺失：人物承受后果，却找不到来源。
- 证据冲突：多个解释都能局部成立。
- 责任转移：执行者把决定归给制度、算法、传统或他人。
- 多因叠加：无人拥有全部责任，却共同制造后果。
- 远距因果：行动与后果隔得太远，责任感下降。
- 不可逆后果：原因已明确，但修复能力归零。

### 主题成立证据
中心冲突必须围绕“什么造成什么、如何知道、谁负责、能否修复”推进，而不是普通剧情因果链本身。

### 失败边界
所有故事都有原因和结果；反转多、伏笔多、阴谋复杂也不自动等于因果主题。

---

## 5｜命运｜多种可能怎样收束为去向？

### canonical 核心
可能性如何在推进中逐步收窄为某种去向、归宿或不可逆结果；回返是否仍可能。

### Agent 应问
- 人物理论上有哪些路，实际能走哪些路？
- 哪些选择被制度、资源、知识、关系或自身认知提前关闭？
- 人物是无法改变终点，还是根本想不到别的终点？
- 预言 / 预测是在描述未来，还是开始制造未来？
- 结果确定时，路径、意义、关系或承担方式是否仍有自由？

### 可操作 theme_experiment 旋钮
```text
可达路径 P_reachable
可想象路径 P_conceived
选择数量 Option Count
锁定强度 Lock-in
返回能力 Returnability
预测 / 预言 Access
不可逆性 Irreversibility
未来视界 Future Horizon
```

### pressure_mechanism 最小型
- 路径关闭：选项客观消失。
- 选项不可见：路存在，但人物不知道它是现实选择。
- 锁定累积：每次小选择都让返回成本更高。
- 预测介入：对未来的判断改变当前许可与行动。
- 终点固定：Outcome Freedom 降低，但路径 / 关系 / 意义仍可变化。
- 回返失效：人物发现“回到原状”已不再是一条真实路径。

### 主题成立证据
关键转折必须真实打开、关闭、压缩或重写可能路径；高潮 / 结局回答“最终走向哪里以及为什么只剩这些路”。

### 失败边界
悲剧、死亡、巧合、恋爱归宿、预言或“宿命感”都不能单独证明命运主题。

## 6｜主维度选择算法

同一故事天然会同时出现多个五维。主题 Agent 不允许“五维全开”。

优先级：

```text
① 结局最终回答什么？
② 高潮最不可替代的冲突变量是什么？
③ 关键转折反复改变什么？
④ 人物重大选择必须处理什么？
⑤ 场景 / 时间 / 设定只作为辅助证据。
```

删除测试：

```text
如果删除该维度的核心变量，
中心冲突 / 关键选择 / 高潮 / 结局是否必须重写？
是 → 可作为主 / 次主题候选
否 → 多半只是背景、设定或表现
```

默认输出：
- 1 个主维度；
- 0–2 个次维度；
- 其余只记录为背景，不强行解释。

## 8｜第一轮门禁

- 不调用电影研究机制卡；留给第三轮。
- 不推演五维之间的具体 instance 生克；留给第二轮。
- 不把十元端点直接当主题答案；留给第六轮接口。
- 不为了“深刻”而制造抽象哲学台词。
- 主题问题必须能通过人物选择、路径、关系、权限、后果或阶段变化来显影。
- 8–10 秒单镜头只需要承担一个“主题压力节点”，不要求完成整道主题命题。
