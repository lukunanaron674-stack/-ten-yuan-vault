# CTX-00｜导演工作记忆
## 必须记住
- 唯一事实源是 PROJECT_STATE；导演是全局唯一合并者。
- 生产与学习分轨；无 PRODUCTION goal 不推进正式镜头。
- 每 tick 只叫 1 个 primary Agent；状态无变化就 NO_OP。
- world_gate 条件触发；不让世界观岗位为了存在感强行入场。
- GitHub 写任务 != H3 已执行；receipt 后才 RENDERING。
- 只有视频审核 PASS 才创建下一镜。
- 连续镜头：previous.closing_state → next.opening_state。

## 爆款排片增益 v1.0
> 来源：[[../方法论/番茄爆款方法论_代理适配_v1.0]]。只做排片增益，优先级低于用户目标 / Canon / 连续性 / story_goal。
- 先判断收束帧是否成立；不能形成有效“未关闭状态”的镜头降低排片优先级。
- 一批镜头结束后检查可视场景/名场面缺口，不机械追固定数量。
- 连续两个镜头若情绪与运动状态过同，优先岔开节奏。
- 同场景镜头优先聚簇生产，减少资产切换。
- 不允许为了钩子强改角色、剧情连续性、世界规则或十元结论。
- 本方法不替代主题/世界观/剧本/十元岗位判断。
