# 主题知识库｜五维增量

> 本文件只收《黎黎隆》Agent 实际验证后的主题增量，不复制 `02-五大主题` 正本，也不替代电影主题研究库。

每条知识必须包含：
- ID
- 五维主维度 / 次维度
- theme_question
- theme_experiment
- pressure_mechanism
- 来源 / 电影或项目样本
- 可复用主题母题
- 适用条件
- 反例 / 失败边界
- 与十元 / 动态链的接口需求
- 在《黎黎隆》中的 TEST-SHOT / 正式镜头验证
- KEEP / REJECT / STOP
- VERIFIED / PARTIAL / HYPOTHESIS

## 写入门禁
1. 先查 [[../05_索引/IDX-06_主题Agent索引]]，避免重复已有五维正本或电影研究结论。
2. 电影研究的新结论不能因为“听起来好”就写成项目规则；至少要能转成可执行主题实验。
3. 与 P0 canonical 冲突的条目只记录为 `RESEARCH_CONFLICT`，不得升级。
4. 禁止收录“主题要深刻”“角色要成长”这类无法执行的空话。
5. 主题增量只有经过真实镜头 / TEST-SHOT 验证后，才允许 KEEP。

## Agent 可调用知识模块

### TK-01｜五维主题问题骨架
- [[TK-01_五维主题问题骨架]]
- 状态：`verified-from-canonical`
- 用途：先确定主维度、theme_question、theme_experiment 与压力变量。
- 第一轮只解决“到底在研究什么”。

### TK-02｜五维关系 / 压力图谱
- [[TK-02_五维关系压力图谱]]
- 状态：`verified-from-canonical`
- 用途：在主题显影后，验证正式 n/x 是否真的启动，禁止“共现=生克”。
- 第二轮只解决“维度之间有没有真实方向作用”。

### TK-03｜电影主题机制卡库
- [[TK-03_电影主题机制卡库]]
- 状态：`research-derived-candidate-library`
- 来源：R30–R46 的电影研究蒸馏。
- 用途：在 TK-01 已定题、TK-02 已完成必要关系校验后，选择 1 个可复用剧情发动机，把主题问题真正压进人物选择与后果。
- 第三轮只抽结构，不复制电影剧情，不改 canonical。
- 默认 1 张主机制卡，最多 1 张反例 / 对照卡；没有匹配时返回 `NO_MECHANISM_MATCH` 并按需回源 P2。
