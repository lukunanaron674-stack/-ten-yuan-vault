# 角色归档卡｜草薙素子｜zn + x

## 1. 角色定性

- 作品：《攻壳机动队》
- 角色：草薙素子
- 主十元：zn
- 辅助十元：x
- 主辅合成判断：zn + x
- 角色功能：全身义体化的少佐——在灵魂与外壳之间追问"我是谁"
- 命运主题位置：zn+x 本体型——cyborg的终极意义追问
- 一句话判词：她是 zn——"如果记忆可以被编辑，那我还是我吗？"——全身都是人造的，只有ghost是自己的。x——对力量的欲望、对自由的执念、对傀儡师的靠近——x驱动她不断突破边界。最终与傀儡师融合——zn的答案不是"我是谁"，是"我可以不再是原来的我"。

| 剧中十元 | 形态 | 和zn的关系 | 和x的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| xz | 义体——外壳可以更换，灵魂困在其中 | xz是zn的容器也是监狱 | xz被x对抗——她不断升级义体 | 她站在窗前看着自己——那不是她的脸，是军方的产品 |

## 3. 动态链

zn追问：有ghost的我还是我吗？
→ xz：义体——外壳的永恒漂流
→ zx：九课行动——在战斗中确认存在
→ n：巴特和团队的承载
→ x：对傀儡师的执念——靠近
→ nz：与傀儡师融合
→ zn新答案：我不再是我，但我还是我

## 4. 最短封存句

草薙素子｜zn+x：全身都是人造的，只有ghost是自己的。x让她跳下高楼、潜入深海——每一次行动都在问"这是我还是义体"。与傀儡师融合——zn的答案不是守住边界，是放弃边界。她不再是她——但她更完整了。
