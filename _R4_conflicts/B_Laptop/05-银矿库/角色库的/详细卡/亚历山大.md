# 角色归档卡｜亚历山大｜zn

## 1. 角色定性

- 作品：《永恒和一日》
- 角色：亚历山大
- 主十元：zn
- 辅助十元：无
- 主辅合成判断：zn
- 角色功能：将死诗人在最后一天通过一个阿尔巴尼亚男孩完成与世界的和解
- 命运主题位置：zn 本体型——死亡倒计时中的意义追问
- 一句话判词：他就是 zn。一生追问词语和意义。绝症只是倒计时——不是他的结构。最后一天救了一个流浪男孩——不是慈善，是 zn 在公交车上找到了答案：意义不在诗里，在三个词里。

## 3. 动态链

zn追问：词语和意义
→ xz倒计时：最后一天
→ z冲动：救下流浪男孩
→ nz陪伴：公交车上的三个词
→ x并z：海边老房子——记忆的容器
→ zn回答：明天是什么？永恒加一日

## 4. 最短封存句

亚历山大｜zn：一辈子追问意义，最后一天找到了——不在诗里，在公交车上。一个阿尔巴尼亚男孩、三个词。"明天是什么？""永恒加一日。"zn不在永恒里——在明天。
