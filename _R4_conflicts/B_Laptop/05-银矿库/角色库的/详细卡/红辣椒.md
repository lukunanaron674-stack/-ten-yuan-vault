# 角色归档卡｜红辣椒/千叶敦子｜zn + x

## 1. 角色定性

- 作品：《红辣椒》
- 角色：红辣椒/千叶敦子
- 主十元：zn
- 辅助十元：x
- 主辅合成判断：zn + x
- 角色功能：心理治疗师在梦中分裂出另一个自我——梦与现实的追问
- 一句话判词：她是 zn——千叶是理性科学家，红辣椒是梦的化身。"哪个是真正的我？"——不是分裂，是追问。x——理事长的欲望想控制所有人的梦——x想吞掉zn。最后千叶和红辣椒合为一体——zn的答案不是选一个，是接受所有。

## 2. 最短封存句

红辣椒｜zn+x：千叶在现实里克制，红辣椒在梦里飞。x是理事长的黑梦——想吞掉所有人的潜意识。"我是谁？"——不是分裂，是追问。最后她不再是千叶也不是红辣椒——是完整的自己。梦和现实都不可怕——分裂才可怕。
