# 角色归档卡｜麦克墨菲｜z + zn

## 1. 角色定性

- 作品：《飞越疯人院》
- 角色：麦克墨菲
- 主十元：z
- 辅助十元：zn
- 主辅合成判断：z + zn
- 角色功能：用反叛的冲动点燃精神病院所有人——让他们记起自己是谁
- 一句话判词：他是 z——装疯进精神病院，教病友打篮球、赌牌、出海钓鱼。zn——他不是在胡闹，是用z问每个人"你还记得你是谁吗"。酋长最后举起水泥台——不是复仇，是把zn捡起来了。"我试过了"——z失败了，zn赢了。

## 2. 最短封存句

麦克墨菲｜z+zn：装疯进来——但他比所有人都清醒。z是篮球、钓鱼、掀翻护士台，zn是问"你为什么在这里"。瑞秋把他切成了空白——但酋长举起了水泥台。z死了，zn砸穿了窗户。
