# 角色归档卡｜玛丽安｜xn + z

## 1. 角色定性

- 作品：《燃烧女子的肖像》
- 角色：玛丽安
- 主十元：xn
- 辅助十元：z
- 主辅合成判断：xn + z
- 角色功能：画家用凝视判断和记录——却在凝视中被点燃
- 一句话判词：她是 xn——画家用画笔判断和记录艾洛伊兹的每一寸。z——被反问"你看着我时我在看什么"时，xn被击穿。俄耳甫斯回头不是神话——是她选择不克制。画廊里第28页的折角——nz藏在xn里。

## 2. 剧中十元互动表

| 剧中十元 | 形态 | 和xn的关系 | 和z的关系 | 一句话故事 |
| ---- | ---- | ---- | ---- | ---- |
| nz | 篝火夜晚——裙子着火也不回头 | nz被z点燃——凝视变成爱 | nz穿透xn——画家爱上了模特 | 篝火那晚她的裙子着了火——不是意外，是她忘了动 |
| xz | 时代规则——艾洛伊兹必须嫁人 | xz克nz——她们不可能 | xz被z对抗——在有限的时间里燃烧 | 她知道她要走——所以每一眼都当最后一眼 |
| zn | 第28页的折角——暗号 | zn是xn+nz的封存——只有她们懂 | - | 画廊里那幅画——她没写名字，只折了第28页 |

## 3. 最短封存句

玛丽安｜xn+z：她以为自己是观察者。但艾洛伊兹看回来了。俄耳甫斯回头——她选了回头。画廊里第28页的折角——nz在xn里，只有她们懂。
