# 角色归档卡｜罗伊｜z + xz

## 1. 角色定性

- 作品：《坠入》
- 角色：罗伊
- 主十元：z
- 辅助十元：xz
- 主辅合成判断：z + xz
- 角色功能：瘫痪特技演员——用故事诱惑小女孩，在虚构与坠落之间选择活
- 一句话判词：他是 z——用天马行空的故事点燃小女孩的想象，也点燃自己残存的求生欲。xz——瘫痪、失去爱人、想死。故事是z和xz的战场——最后小女孩从床上摔下来，他发现自己不想她死。

## 3. 最短封存句

罗伊｜z+xz：他编故事骗小女孩偷药——故事骗了她，也骗了自己。z在xz里烧出想活的念头。她从床上摔下来——他不想她死。那一刻他不想死了。
