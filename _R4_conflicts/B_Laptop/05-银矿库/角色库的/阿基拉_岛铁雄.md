# 岛铁雄（Tetsuo Shima）
> 归档：`05-银矿库/角色库/阿基拉_岛铁雄.md`

---

## 1. 主十元判断

**主十元：xz（阴木·被推着走/不知道归处但停不下来）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉xz，铁雄就是一个获得了超能力的少年——很强、很失控、很危险。但铁雄最核心的不是"力量"或"失控"，是**他驾驭不了这个力量，但也没办法放下来**。他不是选择了被力量吞噬，是被选中的那种——"为什么是我"的问题他一次也没想明白，但他已经飞起来了。
- **第2问（反复面对什么结构）：** 反复面对「为什么金田总是比我强」。从小被保护→被压制→渴望独立→力量失控→发现自己控制不了→更愤怒→更失控。他不是在和世界对抗，他是在和金田的影子对抗——但金田其实是他唯一的朋友。
- **第3问（最怕失去什么）：** 最怕「我还是那个窝囊废」。不是怕死（x），是怕"当力量消失之后我又变回那个没人看得起的小鬼"。所以他拼命抓住力量，哪怕它正在吞噬他。
- **第4问（回到哪个感觉）：** 回到「第一次感受到力量涌上来」的那一刻——病房里尖叫震碎玻璃，第一次有人因为他而恐惧。那一刻他不是"被看见"（z），他是"让人恐惧地看见了他"。
- **第5问（副十元服务谁）：** z（想被看见/想被当作独立的人）是xz的燃料——"我要让你们都看到我不是跟在金田屁股后面的那个废物"。但这个渴望太大，他也驾驭不了。

## 2. 副十元

**副十元：z（阴火·想被看见/被承认/不想再被无视）**

**作用：** 铁雄的终极渴望很原始：**让你们都看见我**。从小被无视（连名字都常被忽略），被金田的光芒遮盖。他拥有了一切的最终目的不是统治世界——是为"铁雄"这个名字争一口气。但可悲的是，当他真的被全世界看见的时候，他已经不是"铁雄"了。

## 3. 功能十元

**功能十元：x（阴水·生存本能/力量即生存）——表层。** 铁雄不要力量的理由（zn），也不要力量的意义（nz）——他要力量是因为有力量就不会被欺负。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 手臂上的机械装置、暴涨的肌肉、最后变成肉块的形态——他的每一次"升级"都是对外包装的追求——"你们看到我有多强了吧"。

## 5. 动态链

```
xz（主·力量推着我走/我不知道怎么停下来）
  → z（副·终于有人看见我了/但这个人不是我）
  → x（功能·力量就是不被欺负的保障）
  → x并z（视觉·越膨胀越虚张声势）
  → 车祸→觉醒→实验室→失控→吞噬一切→被AKIRA接走
  → 他想要的从来不是毁灭，是"你们终于看到我了"
```

## 6. 一句话定型

铁雄不是「失控的超能力者」，也不是「悲剧的怪物」，而是「**不知道自己要什么但已经被推到了毁灭的终点**」的人。

---

## 旧卡修正记录

**旧定位：** xz+nz（命运型）
**修正1：** xz（主）+ z（副）→ 命运型
**最终定位：** xz（主·被推着走/不知道归处）+ z（副·想被看见/被承认）→ 命运型
**最终修正理由：** 原卡xz正确。但副十元nz（希望那个人也在）不对——铁雄不"希望某人在"，他是"希望所有人看过来"。nz的"不希望结束"也不符合他——铁雄恰恰是在毁灭中寻找某种终结。副十元应该是z——那个小小的、被金田光芒掩盖的少年铁雄的原始驱动：先被看见，被当作独立的人。
