# 立花泷（Taki Tachibana）
> 归档：`05-银矿库/角色库/你的名字_立花泷.md`

---

## 1. 主十元判断

**主十元：zx（阳木·突破/执行）**

**五问法核验：**
- **第1问（拿掉什么他就不是他）：** 拿掉zx，泷会变成「有缘分但不会去追的人」——那他画三年东京地图、闯神社、喝口嚼酒的这些事情就全没了。泷的核心不是「被光点燃」（z），是**「被点燃之后必须做到底」**。三叶给的那根绳结系在他手上——这是因。他找了三年的东京每一个角落——这是果。整个故事是因果链的闭环：欠债→追债→还债。
- **第2问（反复面对什么结构）：** 反复面对「我还差一点就找到了」。不知道名字、不知道地方、没有人相信他——但他没停。不是因为他浪漫，是因为他欠的账还没还。
- **第3问（最怕失去什么）：** 最怕「欠的那笔账再也对不上」。所以他手上写的是「喜欢你」不是名字——那一刻他不是怕失去恋爱，是怕因果链断在她那里。
- **第4问（回到哪个感觉）：** 回到「对上了」的感觉。楼梯上回头问「你的名字是？」——那不是浪漫，是账本翻到最后一页、发现两边的数字终于对上了。
- **第5问（副十元服务谁）：** nz（对三叶的依恋）是zx的方向——如果不是三叶这个人值得追，他不会有动力去执行。nz提供「为什么」，zx提供「怎么做到」。

## 2. 副十元

**副十元：nz（阴土·柔情停靠）**

**作用：** 泷追三叶不是功利的，是依恋。手上写「喜欢你」而不是名字——那是nz的动作：我想让你记住的是这个感觉，不是这个地址。

## 3. 功能十元

**功能十元：nx（阴金·暗算/结算）——微量**

**作用：** 泷不算计。他找到三叶靠的不是策略是莽。nx在他身上只有工具位：规划去系守町的路线、查资料。这些是执行计划的一部分，不是他的灵魂。

## 4. 视觉十元

**视觉十元：无显著。**

## 5. 动态链

```
zx（主·欠债必须还）
  → nz（副·依恋提供方向）
  → nx（功能·规划路线）
  → 画三年地图 → 闯神社 → 喝口嚼酒
  → 手上写「喜欢你」
  → 五年后回头——账对上了
```

## 6. 一句话定型

立花泷不是「命运中的追寻者」，而是「**欠了债就必须还，翻遍东京也要还**的人」。

## 旧卡修正记录

**修正记录1（第一轮——错误）：** z（主）+ zn（副）→ 本体型
**修正记录2（第二轮——定稿）：** zx（主）+ nz（副）→ 因果型
**最终修正理由：** 第一轮我犯了同一个错误——把泷的「追光」当成了他的底色。但你一句话钉住了：他是因果型。他不只是被光点燃，他**欠三叶一条命从她出生之前就开始了**。那根绳结不是在东京系的，是在三叶生下来那天就系上的。泷追的不是光——是笔旧账。
