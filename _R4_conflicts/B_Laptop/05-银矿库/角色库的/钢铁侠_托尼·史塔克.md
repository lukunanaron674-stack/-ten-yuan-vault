# 托尼·史塔克（Tony Stark）
> 归档：`05-银矿库/角色库/钢铁侠_托尼·史塔克.md`

---

## 1. 主十元判断

**主十元：zx（阳木·先做再想/完成即意义）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉zx，托尼就是一个有良心的亿万富翁——聪明、有钱、想做好事。但托尼最核心的不是"聪明"或"有良心"，是**他控制不住要先动手**。山洞里一堆废铁拼出第一代战衣、从纽约大战回来后一夜做了几十套战甲、奥创说造就造——他不是做之前想好了所有后果（nx），他是"我先做出来再说"。
- **第2问（反复面对什么结构）：** 反复面对「我做出来的东西又失控了」。武器被恐怖分子拿去用、奥创反过来毁灭世界、蜘蛛侠被他拉进战争后差点死掉——每一次都"先做→出问题→后悔→再做更强的→又出问题"。
- **第3问（最怕失去什么）：** 最怕「来不及/不够强/又有人因为我而死」。所以他不睡觉、造新装甲、从木星拉那颗陨石——他要确保不会再发生他控制不住的事情。
- **第4问（回到哪个感觉）：** 回到「我在山洞里焊出第一块铁片」的时候——他那一刻不是在想"做一件改变世界的东西"，他就是想焊。
- **第5问（副十元服务谁）：** n（怕死了但扛住了）是zx的刹车和燃料——托尼的每一次"先做"之后被n抓住：他事后恐惧，但恐惧不会让他停下，只会让他更疯。

## 2. 副十元

**副十元：n（阳火·怕死了但扛住了/必须扛）**

**作用：** 托尼在《钢铁侠3》里焦虑症发作是n最明显的出口——他怕自己扛不住、怕来的不是他一个人能解决的事。但n不会让他逃跑，只会让他穿上更多的盔甲。

## 3. 功能十元

**功能十元：z（阴火·想被看见/被承认）——表层。** 托尼确实享受镁光灯——"I am Iron Man"的发布会，每次庆功宴上的笑脸，和小辣椒说他有多厉害。但这是他的外壳，不是他的燃料。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 西装、名车、摩天大楼、香槟——这些是他"看起来"的样子。真正的他是那个在地下室焊到凌晨三点的人。

## 5. 动态链

```
zx（主·先做再想/停不下来的手）
  → n（副·怕死了所以停下来之后造更多）
  → z（功能·享受被看见的虚荣）
  → x并z（视觉·天才/花花公子的包装）
  → 被劫持→造战衣→钢铁侠→奥创→内战→打响指
  → 最后那句话：I am Iron Man
  → 从第一秒就开始做了，一直做到最后一秒
```

## 6. 一句话定型

托尼不是「英雄」，也不是「自大狂」，而是「**手停不下来、做了再说、后果后面补**」的人。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）
**修正1：** zx（主）+ n（副）→ 因果型
**最终定位：** zx（主·先做再想/完成即意义）+ n（副·怕死了但扛住了/不能让它塌）→ 因果型
**最终修正理由：** 原卡zx正确，但副十元nx（算清楚再动）是托尼的反面——托尼从来不"算清楚"才动。他全部的错误都来自"没算清楚就先动了"。n才是他的副十元——每一次他做完之后被后果追上时的恐惧驱动他做更多。这不是"算清楚"（nx），是"怕死所以做得更多"（n）。
