# 大白（Baymax）
> 归档：`05-银矿库/角色库/超能陆战队_大白.md`

---

## 1. 主十元判断

**主十元：n（阳火·承载/不能让你受伤）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉n，大白就是一个充气机器人——会飞、会打架、会卖萌。但大白最核心的不是"会保护你"，是**他存在的方式就是"你需要什么，我来给"**。他的第一条程序不是"战斗"也不是"完成任务"，是"减少病人的不适"。这是n的原始形态——没有自我，只有承载。
- **第2问（反复面对什么结构）：** 反复面对「病人需要什么」。从量体温、处理擦伤，到后来陪小宏潜入工厂——他不是在选择做什么，他是在回应"病人"的需求。病人在哪里，他就在哪里。
- **第3问（最怕失去什么）：** 最怕「帮不到你」。他不是怕死（x），是怕"死之前没完成任务"——他的恐惧维度是"没能照顾好你"。
- **第4问（回到哪个感觉）：** 回到「你说"I am satisfied with my care"」的那一刻。他的程序设定里最满足的状态不是打赢了谁，是确认病人安全了。
- **第5问（副十元服务谁）：** zn（这件事是对的）是n的进化版——大白从"被程序推着走"进化到"主动选择拯救"：牺牲自己不是因为被命令，是因为"救你这件事是对的"。

## 2. 副十元

**副十元：zn（阳土·这件事是对的/主动选择）**

**作用：** 大白最后选择牺牲自己把小宏推回安全区——这个动作已超出了医疗程序的边界。这是zn：不是程序要求，是灵魂在说"这事是应该做的"。

## 3. 功能十元

**功能十元：z（阴火·被看到/被需要）——表层。** 大白用"拳头碰拳头"来获得确认、用"Fist bump"来连接——他需要被小宏"看到"他在这里。

## 4. 视觉十元

**视觉十元：x（阴水·透明/无害）。** 白色、充气、圆圆的、走路像企鹅——他的视觉设计就是"我不会伤害你"。这是x的物理表现。

## 5. 动态链

```
n（主·你在我就不会让你受伤）
  → zn（副·主动选择救你是对的事）
  → z（功能·需要被小宏确认存在）
  → x（视觉·无害的白色充气球）
  → 被启动→遇到小宏→进入战场→选择牺牲
  → 最后那句"I am satisfied with my care"——任务完成
```

## 6. 一句话定型

大白不是「医疗机器人」，也不是「卖萌的充气伙伴」，而是「**你在，我就在**」的存在。

## 旧卡修正记录

**旧定位：** zn+x（本体型）
**修正1：** n（主）+ zn（副）→ 本体型
**最终定位：** n（主·承载/不能让你受伤）+ zn（副·救你是我该做的）→ 本体型
**最终修正理由：** 原卡zn+x定位正确的一部分（zn确实是大白后期的维度），但n才是他的原始底色。大白在电影前半段没有"选择"——他是程序在运转，程序的核心是n（承载/减少不适）。后期进化出zn（主动选择救小宏）是成长弧线，但底色不变。x（透明/无害）是他视觉层面的表现，不是驱动。
