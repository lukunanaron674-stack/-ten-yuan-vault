# 卡尔·弗雷德里克森（Carl Fredricksen）
> 归档：`05-银矿库/角色库/飞屋环游记_卡尔.md`

---

## 1. 主十元判断

**主十元：nz（阴金·不想结束/希望那个人还在）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉nz，卡尔就是一个倔老头——脾气差、不喜欢小孩、拒绝搬家。但卡尔最核心的不是"倔"，是**他活在过去里**。艾莉的相册、她的椅子、她的照片、他们的约定——他不是被回忆困住，是不想和艾莉的故事"结束"。
- **第2问（反复面对什么结构）：** 反复面对「该放下了」。房子太重飞不起来、小罗闯进来、遇到了危险的鸟和查尔斯——每一步都在逼他面对同一个问题：你是要继续飞还是落地。
- **第3问（最怕失去什么）：** 最怕「艾莉的约定没有完成」。他把飞屋带到仙境瀑布——不是因为他自己想冒险，是因为"艾莉想去"。
- **第4问（回到哪个感觉）：** 回到「和艾莉一起坐在沙发上看云、她会把手放在我手心里」的那个感觉。他不想要冒险，他想要那个感觉。
- **第5问（副十元服务谁）：** n（扛住/放手也是扛）是nz的出口——当他终于把房子落在仙境瀑布、翻开艾莉的相册看到她留下的"I'VE GONE ON AN ADVENTURE"时，他知道他该放下了。放下那个约定不是背叛，是"我扛住了你不在之后的自己"。

## 2. 副十元

**副十元：n（阳火·扛住/放手也是扛）**

**作用：** 卡尔飞屋飞了一路最后把房子扔掉——这是全片最难的一步。他不是"放下"了艾莉，他是"扛住了之后的世界"。n让他在失去一切之后还能坐下来和小罗吃冰淇淋。

## 3. 功能十元

**功能十元：z（阴火·想被看见/被记住）——表层。** 卡尔不想被当作"那个孤老头"——他希望在别人眼里是一个"实现了和妻子的约定"的人。但这是他的外壳，不是驱动。

## 4. 视觉十元

**视觉十元：x并z（阴木·包装）。** 四方的眼镜、手杖、领结——这些让他看起来是"不能惹的老头"。但里面的他是怕孤单的。

## 5. 动态链

```
nz（主·不想结束/希望艾莉还在的故事）
  → n（副·扛住失去/最后放手也是扛）
  → z（功能·不想被当成孤老头/希望被看到"我做到了"）
  → x并z（视觉·倔老头的包装）
  → 艾莉去世→拒绝搬家→飞屋起飞→仙境瀑布→看相册→放下房子
  → 艾莉说"去经历新冒险吧"——nz被n接住了
```

## 6. 一句话定型

卡尔不是「倔老头」，也不是「为了约定冒险的老人」，而是「**不想让她的故事结束，所以扛着房子飞了一路**」的人。

## 旧卡修正记录

**旧定位：** xn+z（时间型）
**修正1：** nz（主）+ n（副）→ 命运型
**最终定位：** nz（主·不想结束/希望那个人还在）+ n（副·扛住/放手也是扛）→ 命运型
**最终修正理由：** 原卡xn+z不准确——卡尔不是"接受规则再在规则里找路"（xn）的人，他是"不接受你走了"（nz）的老头。他的xn体现在"接受了艾莉已死"这个规则后开始新生活——但那是他的终点，不是起点。驱动他的始终是nz：不想让艾莉的故事结束。副十元n解释了他在终点时如何扛住。
