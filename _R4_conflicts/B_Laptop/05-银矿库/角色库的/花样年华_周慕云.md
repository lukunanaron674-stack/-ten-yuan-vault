# 周慕云
> 归档：`05-银矿库/角色库/花样年华_周慕云.md`

---

## 1. 主十元判断

**主十元：nz（阴金·不想结束）**

**五问法核验：**
- **第1问（拿掉什么他不是他）：** 拿掉nz，周慕云就是一个出轨未遂的男人——稍微有点道德、有点懦弱。但周慕云最核心的不是道德，是**他在每个该结束的地方卡住了**。写小说、反复排练、最后去吴哥窟说秘密——他做的一切都是为了让这段感情不要真的结束。
- **第2问（反复面对什么结构）：** 反复面对「该退回去了」但不想退。每次见面、每次排练、每个擦肩而过的瞬间，他都知道应该结束了——但他硬是撑到了最后一刻。
- **第3问（最怕失去什么）：** 最怕「彻底结束了」。不是怕被社会发现（x），不是怕被拒绝（z），是怕"连做邻居的机会都没了"。所以他选择离开，不是因为勇敢——离开是让这个故事不至于当场死亡。
- **第4问（回到哪个感觉）：** 回到「她还在隔壁、明天还能在走廊遇见」的那个状态。什么都可以不做，但不能没有这个可能。
- **第5问（副十元服务谁）：** z（想被看见/但不敢被全部看见）是nz的燃料——他写小说给她看，但不说那是写给她看的。他希望她能看见他，但不要看见全部。

## 2. 副十元

**副十元：z（阴火·想被看见/但不承认）**

**作用：** 周慕云写小说是z的释放——"你从小说里看到我了吗？"，但当面他不敢承认。他和苏丽珍的对话永远有两个层次：表面的得体，底下的"你看出来了吗"。

## 3. 功能十元

**功能十元：xn（阴土·接受规则再找路）——表层行为。** 他知道社会的规则（不能出轨、不能越界），他在规则里面小心翼翼地走边缘——租房间、排练、说半句话。

## 4. 视觉十元

**视觉十元：x（阴水·伪装/得体）。** 西装、领带、每天出门的体面——这些是他在社会上站的姿势，不是他。

## 5. 动态链

```
nz（主·不想结束/卡在结束的地方）
  → z（副·想被她看见/但不承认）
  → xn（功能·在社会规则里踩边）
  → 走廊擦肩→共同排练→写小说→吴哥窟
  → 故事没有结束：他把它藏起来了
```

## 6. 一句话定型

周慕云不是「克制的情人」，也不是「遗憾的符号」，而是「**不想结束所以永远不走到终点**」的人。

## 旧卡修正记录

**旧定位：** xn+z（时间型）
**修正1：** nz（主）+ z（副）→ 命运型
**最终定位：** nz（主·不想结束）+ z（副·想被看见但不承认）→ 命运型
**最终修正理由：** 原卡的xn（接受规则再找路）描述了周慕云的行为方式——他的确在规则里周旋。但xn是他的工具，不是他的驱动。驱动他的是nz——他反复排练、反复擦身、最后去吴哥窟，全是"不想让这段感情彻底结束"。z是他不敢直接表达但真实存在的渴望：希望苏丽珍"看见"他藏在小说里的心意。
