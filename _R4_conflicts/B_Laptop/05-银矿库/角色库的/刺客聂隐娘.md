# 聂隐娘
> 归档：`05-银矿库/角色库/刺客聂隐娘.md`

---

## 1. 主十元判断

**主十元：nx（阴金·暗算/结算）**

**五问法核验：**
- **第1问（拿掉什么他就不是她）：** 拿掉nx，聂隐娘会变成一个「武艺高强但不知道为什么要打的人」——那她就是一个会轻功的普通人。她整个存在方式就是**看穿因果链条，然后选择在链条的哪一环停下来**。师父让她杀田季安——她看到了更长的链。不是她不会杀，是她算过账之后觉得杀了不划算。这个"看穿然后不执行"是nx最独特的状态——**结算完成了，但选择不收网**。
- **第2问（反复面对什么结构）：** 反复面对「要不要动手」。每一次她藏在暗处、盯着目标、手已经摸到刀柄——她在算。不是zx那种「先杀了再说」——是nx的「先看清楚再决定动不动」。
- **第3问（最怕失去什么）：** 最怕「看不清」。如果她有一天看不清因果链条了、不知道谁该杀谁不该杀了，那她就失去了存在轴心。她不怕杀人，也不怕不杀人——她怕的是**没有判断的依据**。
- **第4问（回到哪个感觉）：** 回到「我看穿了」的那个瞬间。选择不杀时没有情绪波动——因为对于nx来说，算清楚了就是算清楚了，不需要感慨。
- **第5问（副十元服务谁）：** zn（某种冷澈的道义感）是nx的方向——她为什么选择不杀田季安？不只是因为算过账了，而是因为她相信（zn）「稚子不可杀」这条底线。nx告诉她「杀了会有什么后果」，zn告诉她「什么不能做」。

## 2. 副十元

**副十元：zn（阳火·意义/信仰）——冷澈版**

**作用：** 聂隐娘的zn不是「我相信人间有正义」——太烫了。她的zn是冷的：「有些线不能过。」她选择不杀不是软弱，是她信的东西告诉她：杀了孩子，你的因果链就脏了。

## 3. 功能十元

**功能十元：zx（阳木·执行/突破）——微乎其微 

**作用：** 她是刺客，武艺高强，但她不靠行动定义自己。zx在她身上是最薄的一层——她可以杀人，但杀人不是她的驱动力。旧卡说她「不执行因果」所以是zx的另一种形态——但zx不执行的zx不是zx。

## 4. 视觉十元

**视觉十元：x并z（阴木·伪装）。** 她穿黑衣、藏在暗处、不发声音——这是刺客的包装，是视觉接口，不是本体。换掉这些视觉，她的核心还在。

## 5. 动态链

```
nx（主·看穿因果链条）
  → zn（副·冷的底线）为nx提供方向
  → x并z（视觉·刺客伪装）是外部包装
  → 看穿→选择不杀→离开
```

## 6. 一句话定型

聂隐娘不是「被因果裹挟的刺客」，而是「**算清楚了但选择不结账**的人」。

## 旧卡修正记录

**旧定位：** zx+nx（因果型）——「不执行的ZX」
**新定位：** nx（主·暗算/结算）+ zn（副·冷澈底线）
**修正理由：** 旧卡把聂隐娘定位为「不执行的zx」，认为「看穿因果后选择不参与」是zx的特殊形态。但这不是zx——zx的本质是执行本身即意义，不执行的zx不是zx。聂隐娘的核心存在方式是**看穿（nx）然后选择不参与**——她算过账了，账单摆好了，但她不收。这是nx最独特的状态：结算完成但不收网。
