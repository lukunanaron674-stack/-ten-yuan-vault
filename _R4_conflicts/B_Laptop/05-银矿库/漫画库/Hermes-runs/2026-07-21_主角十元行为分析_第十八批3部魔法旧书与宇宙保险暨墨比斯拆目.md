2. **水森具有辨谎能力且卷入事件 → 穂村把他接入COSMOS的信息/工作路线 → 作用于水森角色和公司入口 → 水森由旁观高中生转成受训成员。**（第1—2卷；`xn`，具体招募权限待原卷）
3. **SS级婴儿绑架案出现 → 穂村与水森共同处理 → 作用于受害对象、案件风险和搭档分工 → 将高等级事件推进到公司行动。**（第2卷；`n + xn`，个人分工待复核）
4. **过去的双胞胎客户提出保险选项咨询 → 穂村与水森接受并提供临终支援 → 作用于客户选择、时间逆生状态与生命终点 → 把私人死亡难题组织成可被陪伴的保险服务。**（第6卷；`n生xn`候选）

#### 行为模式总结

穂村把落入眼前的外星人风险或客户请求接入COSMOS制度，拆成身份确认、调查、保险选择和支援步骤，再把身边的人组织进这条处理路线。

#### 反证

- 多数案件由团队完成，不能把水森、调查员或公司制度的动作归给穂村。
- 她拥有岗位权限不等于稳定`x`主位；本轮只把具体案件资料/服务权限记作功能端点。

### 双人物与作品主维关系

- 水森的`n + nx`和穂村的`xn + n`能解释“事件/客户进入公司流程”的人物接力，但二人并不自动组成作品公式。库内因果主`zx+nx`仍需证明公开行动如何与外部路线形成稳定机制，而不是只因战斗与任务共现。
- 人物层支持因果型为强候选，也显示空间/服务制度与生命终点材料；不改91.8、12、6分，不合并三个别名行。
- **复核**：第1卷穂村如何让水森进入COSMOS；第2卷绑架案个人分工；第3卷水森调查步骤；第6卷双胞胎咨询与临终支援；第7卷单轨选择及结果。
