# 2026-07-22 主角十元行为穷举：第二十八批3部菌林蟲毒与废物价值复核

- 固定顺序：先把当前可核验证据中的具体动作列完，再逐条归入一个十元；不从预设十元反找证据。

## 一、Toxy Noxy Foresty Forest

**主角与阶段**：官方公开材料未公布姓名的菌菇少女；第1卷开篇村落覆灭、发现幸存者至追凶启程。

**证据覆盖**：Yen Press第1卷正式简介与22页官方试读。以下是该公开范围内的行为穷举，不是210页全卷穷举。

### 具体行为与后置归类

- 行为1：恶性菌菇屠灭村落后 → 她独自在废墟和尸体间寻找父母、朋友及幸存者 → 被毁村落与原有人际关系 → 试读随后把她带离废墟，未显示父母或朋友回应。
  - 归类：`n`（主位证据，90%）。对象端点：落到她面前的村落覆灭事实、家人与朋友失联；她没有绕开现场，而是先搜索和核实。

- 行为2：她在森林里发现一名被吊起、看似失去反应的长发菌菇 → 上前触碰并检查对方 → 可疑“尸体”与潜在幸存者 → 对方恢复动作，确认仍然活着。
  - 归类：`n`（主位证据，92%）。对象端点：突然落到她面前的未知个体；动作闭环是接近、检查、确认，而非占有或路线支配。

- 行为3：幸存者跟随并询问村落发生了什么 → 她回答父母和朋友都被那只菌菇杀死 → 幸存者与村落死亡信息 → 私人损失经问答成为两人共享的信息。
  - 归类：`nx`（关系功能，84%）。对象端点：由对方提问开启的既有会话通道；这条动作的方向由询问给出，她沿通道回应，不把“说出事实”硬判为`zn`或`z`。

- 行为4：两人抵达有栅栏、守卫和被囚对象的地点 → 她停下观察并辨认场所 → 关押区、守卫、被囚菌菇 → 当前试读只显示她取得场所认识，未显示后续处理、组织或控制结果。
  - 归类：暂不归类（证据不足）。这是一条可观察动作，但单次观察不足以证明`xn`的持续组织，也没有`x`的掌握权或`zx`的权能扩张。

- 行为5：村落、父母与朋友遭到杀害 → 她离开原地，踏上寻找并消灭恶性菌菇的旅程 → 凶手与未知森林路线 → 主角从已毁村落进入持续存在危险的追踪路径。
  - 归类：`xz`（危险路径功能，91%）。对象端点：杀害全村的恶性菌菇、未知森林与追踪路线；成立点是危险已经显形且她沿临界路径行动，不是“目标明确就算`z`”。

### 归类统计后的判断

- 计数：`n`2、`nx`1、`xz`1、暂不归类1。
- 主十元：暂定`n`90%。两条高质量动作都呈现“事情落到面前→接近、检查、核实”；但只覆盖开篇，仍待全卷验证。
- 次十元：未判定。`xz`只有一次高辨识度启程动作，先记功能位91%；`nx`只记问答关系功能84%。
- 关系候选：不登记正式生、补、克。旧`xz↔nz`候选撤回，因为本轮没有独立`nz`动作；村落惨案先发生、搜索后发生，也不足以直接把场景危险宣布为人物`xz生n`。
- 反证：复仇不自动等于`zn`；有目标不等于`z`；进入危险森林不等于她掌握森林或凶手的`x`。
- 与作品主维：人物暂定`n`只贴近作品空间公式的承接端；没有人物`x并z`行为，也没有稳定`zn+x`，因此不裁作品本体/空间/命运主次。
- 待复核：第1卷全卷确认人物名、关押区后的处理动作，以及追踪过程中是否反复出现`xz`或其他十元。

## 二、イクサガミ / Last Samurai Standing

**主角与阶段**：嵯峨愁二郎；漫画第1卷赴京都天龙寺至第7卷浜松会面和岛田宿乱战。

**证据覆盖**：讲谈社漫画第1—7卷正式书目；第7卷已于2026-06-23发行。以下为公开卷册简介范围穷举，不是原页全作穷举。

### 具体行为与后置归类

- 行为1：报纸招募武技高强者并给出巨额奖金机会 → 愁二郎按指定日期前往京都天龙寺 → 招募信息、集合日期与地点 → 他进入由招募方预先建立的行动入口。
  - 归类：`nx`（主位证据，96%）。对象端点：报纸招募、指定时间、天龙寺集合通道；方向不是他建立，他沿外部入口行动。

- 行为2：槐宣布参赛者必须夺札并通过东海道七处 → 愁二郎进入“蟲毒”并沿东京方向推进 → 木札、七个通过点与东海道路线 → 后续移动持续受既定规则和检查点约束。
  - 归类：`nx`（主位证据，97%）。对象端点：槐制定的规则、木札与七个通过点；没有证据显示愁二郎重写规则或主动搭建新的持续结构，因此不判`xn`。

- 行为3：旅途中出现唯一的12岁少女参赛者双叶 → 愁二郎与她同行并保护她 → 双叶的生命与共同路线 → 双叶的安全成为他在求生之外持续处理的负载。
  - 归类：`n`（承接功能，93%）。对象端点：落到同行关系中的双叶安危；动作是接住并持续保护，不凭“温柔”直接判`nz`。

- 行为4：持异能或剑术的强敌连续拦截 → 愁二郎交战、保命并争取继续前进所需的札 → 强敌、双叶、木札与下一通过点 → 他在危险已显形、退路变窄的条件下继续移动。
  - 归类：`xz`（次位证据，92%）。对象端点：正在逼近的夺札者、战斗现场与临界路线；普通能打不等于`zx`，这里成立的是“不行动就会被截断”的危险路径。

- 行为5：冈部幻刀斋成为个人难以解决的强敌 → 愁二郎与京八流旧同门的兄弟妹联手 → 幻刀斋、旧同门关系与他者战力 → 他借用既有同门关系和他人能力共同过关。
  - 归类：`nx`（主位证据，92%）。对象端点：既有流派关系、同伴位置与联合通道；书目未显示他把合作排成长期流程，故不判`xn`。

- 行为6：线索指向“蟲毒”背后的明治政府大人物 → 愁二郎通过电报联系前岛密，并在浜松邮便局与其会合 → 电报系统、前岛密的身份/信息权限与邮局会面通道 → 他经既有通信和身份网络取得幕后者信息。
  - 归类：`nx`（主位证据，95%）。对象端点：电报、前岛密的政府位置、浜松邮便局；解决通道属于现成网络，不属于愁二郎个人掌握。

- 行为7：前岛密告知幕后者为警视局长川路利良后，东海道路线仍有猛者阻挡 → 愁二郎一行继续抵达岛田宿并投入乱战 → 岛田宿、众多参赛者与继续东进的路线 → 新信息没有解除临界处境，他再次通过战斗维持路线。
  - 归类：`xz`（次位证据，90%）。对象端点：岛田宿乱战、逼近的参赛者与被截断风险；这是跨卷再次出现的危险路径动作，不把胜负或剑术强度自动写成`zx`。

### 归类统计后的判断

- 计数：`nx`4、`xz`2、`n`1。
- 主十元：`nx`95%。从招募、比赛规则到同门协力、电报会面，跨阶段高频动作都沿外部规则、关系与权限通道推进。
- 次十元：`xz`91%。第2—4卷和第7卷均出现危险显形后必须以临界战斗维持路线的动作。
- 功能位：`n`93%，只限承接双叶安危；单条高质量关系动作不足以继续保留旧主位。
- 关系候选：不登记正式生、补、克。`nx`与`xz`共现不是现行补位对子；本轮也没有可独立成立的`zx`去启动`zx↔nx`。
- 反证：沿七个检查点不是自己组织流程的`xn`；能打、击退强敌也不自动构成权能公开扩大并凌驾秩序的`zx`。
- 与作品主维：人物主`nx`只支持因果公式的一端，人物次`xz`只支持命运公式的一端；两者不能相加后直接裁定作品主维，原92分及因果/命运/时间冲突继续二审。
- 待复核：原卷核对双叶保护是否持续由愁二郎主动承担、同门联手中谁制定方案、以及第7卷岛田宿战斗的动作主体。

## 三、Gachiakuta / ガチアクタ

**主角与阶段**：Rudo（鲁道）；第1卷被诬陷投入深渊至第4卷觉醒物件能力并追查border。

**证据覆盖**：Kodansha USA第1—4卷正式书目。官方英文版截至2026-07-21已发行第11卷，但第5—11卷本轮未逐卷提取Rudo动作，故不把“有新卷”冒充人物新证据。

### 具体行为与后置归类

- 行为1：Rudo被诬陷杀害养父并投入深渊，地表空气有毒且垃圾兽出没 → 他在深渊继续求生，并寻找发现真相、复仇及返回上层的路径 → 有毒地表、垃圾兽和回程可能 → 他没有停在受害状态，而是进入必须持续移动的危险环境。
  - 归类：`xz`（危险路径功能，93%）。对象端点：深渊、有毒空气、垃圾兽与返回路线；成立的是危险显形后的临界行动，不用抽象“复仇执念”硬判`zn`或`z`。

- 行为2：单独行动无法返回上层，而Cleaners首领可能掌握信息 → Rudo学习新力量并加入Cleaners → 新力量、Cleaners组织与首领的信息权限 → 他通过既有组织入口取得生存、训练和调查通道。
  - 归类：`nx`（主位证据，94%）。对象端点：Cleaners的组织位置、首领权限与既定清扫通道；方向和解决接口已经存在，并非Rudo自行搭建。

- 行为3：Rudo到达Cleaners总部后发现首领外出 → 他决定参加组织现有的一项工作并尝试使用新能力 → Cleaners任务、同伴与能力训练场景 → 等待首领的空档被转为沿组织任务继续行动。
  - 归类：`nx`（主位证据，92%）。对象端点：Cleaners已经给出的工作、团队位置与训练通道；主动报名不等于主动组织整个流程的`xn`。

- 行为4：Raiders在任务中袭击并企图夺走Rudo → 他在战斗中觉醒，发现物件价值并把潜能完整引出，用其击退Raiders → 具体物件、Instrument与袭击者 → 物件被转化为Rudo可调用的战斗资源并产生击退结果。
  - 归类：`x`（对象掌握功能，96%）。对象端点：被Rudo触碰和调用的具体物件、Instrument能力及使用权；这是“对象归我掌握”，而非仅凭胜利判`zx`。

- 行为5：敌人透露Instrument属于一个系列，并存在连接上层与地面的border → Rudo带着线索出发调查谜团 → Instrument系列、border信息与返回路线 → 他沿他者提供的线索进入下一段调查。
  - 归类：`nx`（主位证据，88%）。对象端点：敌人给出的系列情报和border线索；公开简介未显示他怎样排程、记录或组织长期调查，故不判`xn`。

### 归类统计后的判断

- 计数：`nx`3、`xz`1、`x`1。
- 主十元：`nx`93%。第1—4卷范围内，加入组织、接任务和沿外部线索调查构成最多且跨卷的行动结构。
- 次十元：未判定。`x`是高辨识度对象掌握功能96%，但当前只有第4卷一条明确动作；`xz`是开篇危险路径功能93%。
- 关系候选：不登记正式生、补、克。现行表中的`nx生x`语义仍标“待验收”，本轮不能因三条`nx`与一条`x`先后出现就宣布关系启动。
- 反证：被当作垃圾投入深渊不等于人物`x并z`；复仇目标不自动等于`zn`；击退Raiders不自动等于`zx`，因为书目强调的是物件潜能被调用，而非Rudo的权能公开扩大并凌驾秩序。
- 与作品主维：人物主`nx`支持因果公式的关系通道端；一次`x`动作强化“物件价值—掌握—结果”链，但不等于作品空间容器`x并z`。7/72及其他评分与作品主维继续隔离。
- 待复核：第3卷任务中Rudo是否自行安排训练步骤；第4卷各物件的具体名称、调用边界及border调查的后续组织方式；第5—11卷另开新证据批次。

## 本轮撤回与保留

1. 撤回Toxy旧主`zn`、次`xz`及`xz↔nz`候选：复仇总述不足以证明内在意义本体，当前只稳得开篇`n`和一次`xz`功能。
2. 撤回愁二郎旧主`n`、次`xn`及`n生xn`候选：四条跨阶段动作更直接属于`nx`；检查点、同门和电报均不是他建立的结构。
3. 撤回Rudo旧主`x`、次`zn`及`zn↔x`候选：`x`动作虽精确但只有一条；三条跨卷组织/线索动作属于`nx`，现阶段不能用抽象复仇意义补`zn`。
4. 保留所有正式评分、作品主维、最终归仓与作品ID；只更新人物层导航、冲突说明和旧报告状态。
