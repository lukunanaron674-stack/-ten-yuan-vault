# 主角十元行为穷举·第二十四批：身体异变与身世追索复核

## 本轮口径与覆盖边界

- 本轮没有新增漫画，优先把旧第二十一批的“行为概括+多标签”改造成逐条行为穷举。
- 覆盖对象：`Dorohedoro`开曼、`ルリドラゴン`青木琉璃、`ダーウィン事変`查理，共3部、3位主角、13条具体行为。
- 旧报告原列16条。本轮删除3条：一条只是同学关注和身体变化的背景；一条只是“面对社会问题”的抽象总述；一条把《达尔文事变》第8卷同一追踪来源重复拆成独立证据。删除项不用于十元统计。
- 每条只归入一个十元；关系、作品主题和评分另层处理。无法从公开书目确认的计划细节、心理动机、主动性和结果不补写。
- 本报告只穷举指定出版社书目明确公开的行为，不是三部作品的全作穷举。

## 一、Dorohedoro / 异兽魔都

### 对象、阶段与来源

- 主角：カイマン（Kaiman / 开曼），被魔法改变头部且失去记忆的Hole居民。
- 覆盖阶段：第1、7、9、23卷公开书目；从追查施术者到终局挑战Hole-kun。
- 库内来源：旧第二十一批报告、`漫画库_全名单-精修版-2026-06-02.md`、`漫画库总索引.md`。
- 官方来源：小学馆[第1卷](https://e-comi.shogakukan.co.jp/books/091882710000d0000000)、[第7卷](https://e-comi.shogakukan.co.jp/books/091882770000d0000000)、[第9卷](https://e-comi.shogakukan.co.jp/books/091882790000d0000000)、[第23卷](https://e-comi.shogakukan.co.jp/books/091886930000d0000000)。
- 当前状态：公开书目范围穷举，非全23卷穷举；100分和因果/空间作品主维冲突继续隔离。

### 公开书目范围行为穷举与逐条归类（5条）

- 行为1：头部被魔法变成蜥蜴且记忆丧失 → 开曼与二阶堂持续猎取魔法使，并让“口中的男人”辨认对方是否为施术者 → 作用于自己的原始头部、身体状态和施术者候选 → 每次辨认都缩小“谁控制了这副身体”的追查范围。
  - 归类：`x`（主位证据，93%）。对象端点是开曼自己的头部、身体原形和所受魔法；他把解除他人对身体的控制、重新掌握身体边界作为行动目标。
- 行为2：二阶堂被烟一伙抓走且开曼已被敌方认脸 → 开曼借用Restaurant Tanba员工身份，戴面具、女装并以“Pie Man”化名潜入烟宅邸 → 作用于伪装、员工角色、进入时机和宅邸权限 → 他成功进入敌方内部并获得接近二阶堂的通道。
  - 归类：`xn`（次位证据，91%）。对象端点是身份伪装、角色配置、潜入时机和进入路径；这是主动组织多个条件形成可运行方案。
- 行为3：烟等人在评判派对比赛、二阶堂仍被控制 → 开曼趁评审注意力转移时把二阶堂带离 → 作用于二阶堂和撤离节点 → 救援进入下一阶段，但二阶堂随后因受控状态向他发起战斗。
  - 归类：`n`（功能位证据，89%）。对象端点是落到开曼身上的朋友救援负载；该动作的主要功能是接住并转移二阶堂，不重复用它证明潜入计划。
- 行为4：恢复的记忆把开曼引向魔法训练学校 → 他忍受剧烈头痛进入废校搜查并查看记录 → 作用于记忆指向、既有学校档案和“栗鼠”线索 → 他从名册中得到可继续核对的具体名字。
  - 归类：`nx`（功能位证据，88%）。对象端点是恢复记忆已经给出的地点方向和学校既存记录；本条确认他沿线索推进，未见足够资料证明由他主动设计整套调查结构。
- 行为5：二阶堂挑战Hole-kun失败并遭斩首 → 开曼为报仇并夺回二阶堂的头重新站起、挑战Hole-kun → 作用于二阶堂的具体身体、双方关系边界和敌方控制 → 终局行动围绕夺回这一具体对象展开。
  - 归类：`x`（主位证据，94%）。对象端点是二阶堂的头及“重要关系不能继续由敌方占有”的边界；本条只按具体夺回对象归类。

### 穷举后统计

- 行为计数：`x`2条、`xn`1条、`n`1条、`nx`1条。
- 主十元：`x`93%。起始追查与终局夺回跨阶段指向具体身体和关系控制边界。
- 次十元：`xn`91%。第7卷潜入是高质量主动组织证据，但当前只有一个独立阶段，不升主位。
- 功能位：`n`89%、`nx`88%。未单列稳定`zx`，因为终局战斗已经按具体夺回对象归入`x`。
- 关系判断：不登记生、克、补。四类动作存在于不同问题簇，没有证据证明其中一个十元通过明确机制改变另一个十元的目标变量。
- 与作品主维关系：人物`x+xn`既不自动生成因果`zx+nx`，也不自动生成空间`x并z+n`；100分及因果/空间冲突继续待二审。
- 原卷复核：第1卷辨认规则、第7卷潜入方案归属、第9卷搜查主动性、第23卷夺回目标与直接战斗的主次。

## 二、ルリドラゴン / RuriDragon

### 对象、阶段与来源

- 主角：青木ルリ（青木琉璃），逐步显现龙体质的高中生。
- 覆盖阶段：第1—3卷公开书目；长角、放电控制、体育祭执行委员与委员长阶段。
- 库内来源：旧第二十一批报告、`漫画库_全名单-精修版-2026-06-02.md`、`漫画库总索引.md`。
- 官方来源：集英社[第1卷](https://books.shueisha.co.jp/items/contents.html?isbn=978-4-08-883285-2)、[第2卷](https://books.shueisha.co.jp/items/contents.html?isbn=978-4-08-884164-9)、[第3卷](https://books.shueisha.co.jp/items/contents.html?isbn=978-4-08-884415-2)。
- 当前状态：公开书目范围穷举4条，非全作穷举；96分、源名66.25分和“未入库”状态继续隔离。

### 公开书目范围行为穷举与逐条归类（4条）

- 行为1：清晨发现头上长角、母亲说明父亲是龙 → 琉璃虽然困惑，仍然前往学校 → 作用于突然变化的身体和原有校园日常 → 龙体质被带入她必须继续生活的公共环境。
  - 归类：`n`（主位证据，92%）。对象端点是已经落到她身上的身体变化和日常负载；动作重点是承接变化并维持生活，而不是龙角这一外观本身。
- 行为2：课堂中突然放电并确认新的龙体质 → 琉璃反复试错，尝试控制放电 → 作用于身体能力、控制方法和周围安全 → 不可控反应被转成能够持续测试的问题。
  - 归类：`xn`（次位证据，90%）。对象端点是试错过程、控制方法和能力运行条件；这是公开书目中最明确的主动组织行为。
- 行为3：琉璃与前田共同成为体育祭执行委员且起初不合拍 → 琉璃继续履行共同委员工作 → 作用于体育祭职责和合作关系 → 两人在共同工作中逐渐能够相处。
  - 归类：`n`（主位证据，86%）。对象端点是已经落身的委员职责和不顺的合作负载；公开书目未说明具体分工，因此只确认承接功能，不补写她如何组织体育祭。
- 行为4：委员工作扩大、陌生环境和公众关注持续增加 → 琉璃进一步担任委员长 → 作用于体育祭执行责任和她的公共位置 → 她从普通委员进入承担更大责任的位置。
  - 归类：`n`（主位证据，88%）。对象端点是更大的执行责任；主动竞选、被推举或临时替补仍待原卷确认。

### 穷举后统计

- 行为计数：`n`3条、`xn`1条。
- 主十元：`n`92%。第1卷身体异变与第3卷公共职责跨阶段都表现为承接已经落身的负载。
- 次十元：`xn`88%。放电试错是清楚的组织行为，但当前只有一个独立来源簇，较旧报告91%下调。
- 关系判断：不再登记旧`n生xn`88%候选。第1卷继续上学与第2卷控制放电存在先后，但母亲说明、学校环境和能力自然显现均是强第三因素，无法锁定“n通过何种机制生xn”。
- 与作品主维关系：人物`n+xn`只提供人物层材料，不裁作品空间/时间候选，也不处理96/66.25评分与入库状态冲突。
- 删除项：旧“同学好奇、另一种龙体质显现”只有背景和他人反应，没有琉璃独立动作，故不列入行为清单。
- 原卷复核：第2卷试错由谁设计；第3卷委员工作细节、委员长产生方式和琉璃的主动程度。

## 三、ダーウィン事変 / 达尔文事变

### 对象、阶段与来源

- 主角：チャーリー（Charlie / 查理），半人半黑猩猩的Humanzee。
- 覆盖阶段：第1、8—9、11卷公开书目；入学、追查出生来源、潜入ALA据点并救回Lucy。
- 库内来源：旧第二十一批报告、`漫画库_全名单-精修版-2026-06-02.md`、`漫画库总索引.md`。
- 官方来源：讲谈社[第1卷](https://www.kodansha.co.jp/comic/products/0000346125)、[第8卷](https://www.kodansha.co.jp/r/comic/product?item=0000399631)、[第9卷](https://afternoon.kodansha.co.jp/comics/2025/05/0000412865.html)、[第11卷](https://www.kodansha.co.jp/comic/products/0000427613)。
- 当前状态：公开书目范围穷举4条，非全作穷举；95/85评分来源继续隔离。

### 公开书目范围行为穷举与逐条归类（4条）

- 行为1：结束长期隔离生活并被安排进入高中 → 查理进入学校并与Lucy相识 → 作用于既有教育流程和同学关系 → 他开始沿人类校园制度生活。
  - 归类：`nx`（主位证据，88%）。对象端点是父母和学校已经给出的教育路线、学生身份与校园流程；现有资料没有显示该方向由查理自行建立。
- 行为2：为了知道Humanzee为何被制造、遗传父亲Grossman成为既有线索 → 查理与Lucy等人前往纽约追寻Grossman → 作用于遗传关系、父亲线索和调查地点 → 身世问题沿既有关系线进入纽约阶段。
  - 归类：`nx`（主位证据，92%）。对象端点是Grossman这一既有关系端点及其给出的路线；查理主动移动，但方向来自现存父子关系和外部线索。
- 行为3：听到Galton公司可能知道Grossman去向 → 查理继续沿该公司线索推进，最终与Grossman面对面 → 作用于企业信息通道和遗传父亲 → 追踪抵达直接会面节点。
  - 归类：`nx`（主位证据，90%）。对象端点是企业已有的信息网络和关系通道。行为2与行为3同属第8卷来源簇，虽为先后两个动作，但置信度计算时不当作两个独立来源加权。
- 行为4：ALA绑架Lucy → 查理追踪ALA、潜入据点并救回Lucy → 作用于Lucy、敌方藏身处和追踪路线 → 他完成阶段性救援，但第11卷确认Lucy仍出现异常状态。
  - 归类：`nx`（主位证据，95%）。对象端点是绑架事件已经给出的目标、ALA既有组织路线和据点通道；出版社简介没有展开计划、分工或直接权能。

### 穷举后统计

- 行为计数：`nx`4条；其中行为2—3属于同一第8卷来源簇，不作为双倍独立支持。
- 主十元：`nx`94%。校园、遗传父亲、公司与ALA四种外部路径均先给出方向，查理随后沿既有关系、身份或组织通道推进。
- 次十元：未判定。旧`n`89%来自“他承接了压力/关系后果”的概括；在一条行为只归一元后，没有独立动作足以稳定保留次`n`。
- 关系判断：只有一个已收束点位，不启动生、克、补。
- 与作品主维关系：人物`nx`只覆盖因果公式的一端，不补造稳定`zx`，不据此确认或推翻作品因果主维；95/85评分继续隔离。
- 删除项：旧“与Lucy面对学校、舆论、歧视和恐怖事件”是抽象总述，缺少具体动作；旧“联系公司社长”未被当前官方书目明确写出，故不列行为。
- 原卷复核：第1卷入学中的主动选择；第8卷纽约行和Galton接触由谁组织；第9—11卷追踪、潜入、救援的计划与执行分工。
