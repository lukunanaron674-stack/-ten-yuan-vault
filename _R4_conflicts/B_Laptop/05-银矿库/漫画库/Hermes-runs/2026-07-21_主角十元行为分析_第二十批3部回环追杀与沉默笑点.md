## 二、《大ダーク》

### 分析对象与范围

- **主角**：ザハ＝サンコ（Zaha Sanko），14岁、骨头被传为能够实现任何愿望，因此遭全宇宙追杀。
- **阶段**：第1—7卷公开书目；从与Avakian漂流、反杀追兵，到潜入、伙伴损坏、Kenzan战及骨骼被夺。
- **来源文件**：`漫画库总索引.md`、`漫画库_全名单-精修版-2026-06-02.md`、`漫画库_统一总索引_草稿.md`、小学馆[第1卷](https://e-comi.shogakukan.co.jp/books/091294860000d0000000)、[第2卷](https://e-comi.shogakukan.co.jp/books/098502150000d0000000)、[第3卷](https://e-comi.shogakukan.co.jp/books/098504960000d0000000)、[第5卷](https://e-comi.shogakukan.co.jp/books/098512510000d0000000)、[第6卷](https://e-comi.shogakukan.co.jp/books/098520220000d0000000)、[第7卷](https://e-comi.shogakukan.co.jp/books/098530960000d0000000)。
- **当前状态**：主角跨卷书目轻筛完成；正式日文题名已锁，作品空间/因果旧记录冲突待二审。

### 十元判断与对象端点

- **主十元：`xz` 95%**。端点是全宇宙追杀、光力塊飞船与教团圣区域、Kenzan和Cry等不断切换的危险地点，以及被捕、重伤、骨骼被夺等临界边界。Sanko长期不是在固定容器里成立，而是在危险显身后必须继续找下一条路。
- **次十元：`zx` 90%**。端点是袭击他的宇宙人、敌船与教团战斗；他会以闇之力和直接杀伤把追杀者压回去。但卷3存在被Damemaru操纵的无武器暴走，说明“发生大破坏”不总等于Sanko自己的稳定权能。
- **功能位：`x`候选88% / `n`84%**。`x`端点只限Sanko自身的闇の皮、骨骼边界及可调用力量；Avakian是伙伴，不按“归我道具”计算。伙伴故障后转向修理地点，显示有限承接功能，但不足以锁`n`主位。
- **关系候选：`xz生zx` 88%**。公开追杀与临界路径不断迫使Sanko用直接战斗打开下一步，改变的是“能否脱离当前危险并继续移动”。同伴作战、敌人主动袭击和Damemaru操纵都是同等强度第三因素，故不宣布正式关系。

### 可观察行为证据

1. **全宇宙人因“他的骨头能实现愿望”而袭击 → Sanko与Avakian跨宇宙移动，并把来袭者逐个杀掉 → 作用于追杀者、身体边界与移动路线 → 每次反击都为下一段漂流争取空间。**（第1卷；`xz + zx`）
2. **“四匹害恶”持续被全宇宙厌恶和追杀 → Sanko、Avakian与Shimada Death潜入光力塊宇宙船 → 作用于敌方飞船、追踪路线与失散同伴Damemaru → 主角从被追位置主动进入敌方场域。**（第2卷；`xz`，潜入计划归属待原卷）
3. **Damemaru以能力操纵Sanko → Sanko在没有武器的状态下于敌船大闹，随后重伤并被带往教团寺院 → 作用于身体、敌船与控制边界 → 破坏结果出现，但主体决定权被夺走。**（第3卷；`xz`状态；这是`zx`反证，不当成稳定权能证据）
4. **敌方秘密兵器“光核人间”突然袭击 → Sanko一行迎战并险胜；Avakian受损后，一行改道前往闇之世界Cry维修 → 作用于敌人、伙伴与目的地 → 战斗结果立刻改写后续移动路线。**（第5卷；`zx + xz`，团队战果不独占给Sanko）
5. **伙伴Damemaru在Kenzan被杀 → Sanko一行与Kenzan星人进入死斗 → 作用于伙伴死亡、当地敌对势力与自身生存 → 失去伙伴把漂流路线推入正面冲突。**（第6卷；`xz生zx`候选，具体行动分工待原卷）

### 行为模式总结

危险一旦显形并切断原路，Sanko就继续移动、潜入或直接反击；伙伴受损、被捕或身体边界遭夺时，他的路线会立刻转向下一处战斗或修复节点。

### 反证与作品主维关系

- **反证**：宇宙、飞船和星球属于场景层，不能把人物自动判为空间十元；卷3暴走由他人操纵，不能用来提高稳定`zx`。若原卷显示大部分战斗由团队/闇之道具决定，`zx`应降为行为功能。
- **作品层**：当前总索引汇总把Dai-Dark列为空间型，旧统一草稿却列因果主、空间次。Sanko的`xz+zx`只说明人物在危险路径上直接反击，不裁作品主维；出版社正式题名与跨星场域足以锁别名，却不足以消解空间/因果冲突。
- **复核**：第1卷闇の皮/闇のニーモツ的调用权；第2卷潜入由谁决定；第3卷操纵前后主体权限；第5卷维修路线；第6—7卷Damemaru死亡、被捕与骨骼被夺后的行动。
- **建议写入位置**：人物索引、总索引“仅分析/空间池”说明、同名冲突复审队列；100分和正式主仓保持原状。

- **来源文件**：`漫画库总索引.md`、`漫画库_全名单-精修版-2026-06-02.md`、讲谈社[官方编辑部作品介绍](https://news.kodansha.co.jp/comics/20151297)。
- **当前状态**：单主角轻筛完成；作品旧“妹妹知道真相＝因果链核心”判法触发本体/因果维度二审。

### 十元判断与对象端点

- **主十元：`zn` 96%**。端点是貴一郎不依赖职场评价的个人节奏、持续写广播投稿的幽默实践，以及对妹妹的内部关怀标准。官方材料明确指出他并非为了被认可才做明信片投稿人，这给出稳定的反`z`证据。
- **次十元：`n` 91%**。端点是频繁的公司酒会、周围人的误解、妹妹的安全与节目请求；事情落到他这里后，他通常不扩大冲突，而是安静处理并让日常继续。
