# 2026-07-22 主角十元行为穷举：第三十批3部宇宙遗物、器官与少年回声复核

- 扫描时间：2026-07-22 17:19—18:20（Asia/Shanghai）。17:19批次尚未落库时收到18:20心跳，合并为同一轮，不重复生成两份报告。

- 本轮重做旧第十五批的`The Incal`、`器官拼图 / Rest in Pieces`、`黎明前的回声 / The Echo Before Dawn`，共3部、5个人物对象、20条行为。

## 一、The Incal

### John Difool

- 身份与阶段：低阶私家侦探；发现Incal后至六卷合订本所概括的宇宙生存任务。
- 证据范围：Humanoids六卷数字合订本官方简介，301页合订范围的宏观剧情动作；非逐卷、非逐页穷举。

- 行为1：作为低阶侦探生活时 → 发现古老神秘遗物Incal → 作用于突然落到自己身上的遗物输入 → 原有生活被彻底改道。
  - 归类：`n`（功能位证据，94%）。对象端点：被发现并落入当前事件链的Incal及其带来的任务负载。
- 行为2：Incal成为各方争夺的贵重对象后 → 搜寻Incal → 作用于遗物目标 → 进入持续争夺，但官方简介没有公开他的搜索路线、步骤或实际控制结果。
  - 归类：暂不归类（证据不足）。对象端点：Incal是目标，不因“寻找”一词自动判`nx/xn/x`。
- 行为3：冒险把他带到Metabaron面前时 → 与Metabaron发生对抗 → 作用于直接阻路的强敌 → 生存与前进窗口被压缩为即时冲突。
  - 归类：`xz`（主位证据，90%）。对象端点：已出现的Metabaron威胁和被压缩的行动窗口。
- 行为4：Technopope势力成为阻碍时 → 继续与Technopope对抗 → 作用于宗教权力敌手 → 宇宙任务进入新的危险节点。
  - 归类：`xz`（主位证据，89%）。对象端点：已公开显现的Technopope阻碍和继续行动的临界路径。
- 行为5：自身与宇宙的存续同时受威胁时 → 为两者的生存而战 → 作用于生存危机 → 以直接行动维持下一段存续机会。
  - 归类：`xz`（主位证据，93%）。对象端点：John自身及宇宙存续的临界窗口。

**归类统计**：`xz`3、`n`1、暂不归类1。暂定主`xz`91%；次位未判；`n`为功能证据。旧主`nx`93%、次`n`89%及`x`功能撤回：官方简介没有公开稳定外部路线或John实际掌握Incal的持续结果。

**关系候选**：无。`n`与`xz`只有事件先后，未显示现行生、补、克机制。

**反证与作品主维关系**：普通对抗不自动算`zx`；搜寻贵重遗物不自动算`x`。人物的临界应战`xz`不等于作品现存本体主位，94分、主维和归仓均不动。

**复核与写入**：下一步抽原作第1、2、4、6卷，确认“寻找Incal”的具体路线以及John是否实际取得、失去或转交对象。当前正本写入本报告，人物导航写入[[漫画主角十元行为分析索引]]。

## 二、器官拼图 / Rest in Pieces

- 对象范围：药岛的11篇短篇合集；不存在可安全合并的“全书主角”。本轮仍只处理公开资料较明确的〈宇宙的幽灵〉与〈幻肢〉，其余9篇不外推。
- 证据范围：CCC创作集作者专题、CCC篇目访谈与Openbook书评；公开资料范围穷举，非原篇逐页穷举。

### 〈宇宙的幽灵〉无名女太空人

- 身份与阶段：能见亡灵的女性；从为离开地球而成为太空人，到返地改任清洁工作。

- 行为1：地球上的亡灵持续进入视野时 → 选择成为太空人并离开地球 → 作用于自己与亡灵的距离 → 把生活路线推向太空。
  - 归类：`xz`（主位证据，93%）。对象端点：已显现的亡灵逼近及她试图拉开的安全边界。
- 行为2：进入太空后 → 继续看见数量更多的亡灵 → 作用于异常视觉输入 → 原先作为避难处的太空被新的亡灵信息占据。
  - 归类：`n`（次位证据，86%）。对象端点：落入感知并被持续接收的太空亡灵输入。
- 行为3：上升的亡灵群经过视野时 → 在其中辨认出母亲 → 作用于母亲的身份与存在确认 → 旧关系对象被具体识别出来。
  - 归类：`z`（功能位证据，90%）。对象端点：被她确认身份的母亲亡灵；这是辨认行为，不把“母女问题”抽象词当动作。
- 行为4：巨大宇宙幽灵吞噬其他亡灵、令任务无法继续时 → 返回地球 → 作用于已经失效的太空任务与安全路线 → 离开无法承受的现场。
  - 归类：`xz`（主位证据，92%）。对象端点：扩张中的宇宙幽灵、终止的任务与收窄的生存边界。
- 行为5：返地后无法继续原太空任务时 → 改任清洁工作 → 作用于可用的职业通道 → 进入新的地面生活路线。
  - 归类：`nx`（功能位证据，84%）。对象端点：返地后可进入的清洁岗位与日常流程；公开资料未给她主动设计职业体系，故不判`xn`。
- 行为6：全球异常进一步吞没社会时 → 在清洁生活中冷眼观看异常蔓延 → 作用于持续出现的社会异变 → 保持观察而未公开改变其扩张。
  - 归类：`n`（次位证据，85%）。对象端点：持续落入视野的全球异常与社会变化。

**归类统计**：`xz`2、`n`2、`z`1、`nx`1。暂定主`xz`92%、次`n`86%；`z/nx`为功能位。旧次`nz`86%撤回：辨认母亲更直接支持`z`，资料未给出持续关系维护动作。

**关系候选**：无。换职业与承接异常分属不同节点，当前资料不足以启动生、补、克。

**反证与作品主维关系**：精神失序是结果而非主动行为，未列入行为清单。人物`xz+n`只支持这篇的身体/幽灵临界经验，不代表11篇合集主角，也不裁作品本体主位。

### 〈幻肢〉无名车祸幸存者

- 身份与阶段：车祸后失去左腿的幸存者；住院阶段。

- 行为1：失去左腿后的睡眠中 → 梦见左腿与其他截肢、灵体融合 → 作用于梦中的身体边界 → 形成群体化的幻肢图景。
  - 归类：暂不归类（证据不足）。对象端点：梦中幻肢图景；梦是非自愿事件，不能仅凭象征画面硬判`x并z/n`。
- 行为2：梦境结束并回到清醒住院阶段时 → 独自站在医院走廊观看日出 → 作用于改变后的身体与当下环境 → 以现有身体停留到清晨。
  - 归类：`n`（功能位证据，87%）。对象端点：落到自己身上的不可逆身体变化与清醒现场。

**归类统计**：`n`1、暂不归类1。公开资料仅2条，主十元、次十元均未判；旧主`n`87%降为单条功能证据。

**关系候选**：无。

**反证与作品主维关系**：车祸、失去左腿是背景事件，不是主角动作；梦象不自动证明`x并z`。两条资料仅支持〈幻肢〉的身体变化端，不外推合集主维。

**复核与写入**：两篇当前正本写入本报告；合集继续保留`collection-scope`。下一步实读原篇，优先核〈幻肢〉梦醒后的连续动作及〈宇宙的幽灵〉返地、转职和观察异常是否为不同场景。

## 三、黎明前的回声 / The Echo Before Dawn

- 作品与人物范围：狼七单行本；拆分王宥杰、颜一辰，覆盖相识、救援、共同停靠与路线分岔的公开资料。
- 证据范围：Openbook专题、BIOS作者访谈，以及博客来书目页所收读者书评。书目页读者书评所支持的动作降低置信度；本轮不是184页全书实读。

### 王宥杰

- 身份与阶段：少年双主角之一；从看见一辰遇袭到尝试离开原有黑暗路线。

- 行为1：看见颜一辰遭殴打、抢夺时 → 介入并把他救出 → 作用于一辰与现场危险 → 一辰离开即时受害处境。
  - 归类：`n`（功能位证据，88%）。对象端点：当面落到王宥杰面前的一辰危机与救援负载。
- 行为2：一辰需要暂时安全处时 → 把他带到自己的工作地点 → 作用于既有工作/帮派通道 → 一辰进入王宥杰已经在用的生活路线。
  - 归类：`nx`（功能位证据，86%）。对象端点：王宥杰既有工作地点、关系通道和进入路线；资料未显示他重新设计该系统，故不判`xn`。
- 行为3：两人需要面对各自家庭与生活处境时 → 在河堤边向一辰敞开心事 → 作用于两人的关系接口 → 孤立经验获得可被对方接住的共同停靠。
  - 归类：`nz`（功能位证据，90%）。对象端点：与一辰继续维持并加深的朋友关系。
- 行为4：自身生活再度发生变化、旧路线后果显现时 → 决定回到正轨 → 作用于自己后续选择 → 公开资料把他的道路写成与一辰开始分岔。
  - 归类：`zn`（功能位候选，82%）。对象端点：由本人作出的路线边界；具体戒断、退出步骤与结果仍待原书。

**归类统计**：`n/nx/nz/zn`各1。四种证据均未形成跨阶段重复，主十元、次十元均未判；旧主`n`96%、次`zn`93%撤回。

**关系候选**：无。当前资料只显示相识、带路、敞开心事与分岔的顺序，未隔离第三因素，也未达到正式关系机制。

**反证与作品主维关系**：原生家庭、帮派与毒品环境是背景结构；不能替代王宥杰动作。人物层目前只提供命运作品中的承接、通道、关系与自定边界端点，不能拼成稳定`xz+nz`。

### 颜一辰

- 身份与阶段：少年双主角之一；从接受宥杰帮助到形成关系停靠。

- 行为1：获救后王宥杰提供工作地点作为暂时去处时 → 跟随宥杰进入该地点 → 作用于宥杰既有的工作/帮派通道 → 自己进入新的生活路线。
  - 归类：`nx`（功能位证据，86%）。对象端点：由王宥杰关系提供的地点、群体与行动通道。
- 行为2：两人需要面对各自生活处境时 → 在河堤边向宥杰敞开心事 → 作用于朋友关系 → 把孤立经验放入双方可共同承接的关系位置。
  - 归类：`nz`（主位证据，90%）。对象端点：被继续维持和加深的王宥杰关系。
- 行为3：两人以抽烟排遣寂寥时 → 与宥杰传递香烟 → 作用于双方共享的关系仪式 → 以具体往返动作维持当时的同伴停靠。
  - 归类：`nz`（主位证据，87%）。对象端点：通过双方往返动作维持的同伴关系。此项与河堤谈心同属关系场景簇，统计数量但不作两份独立来源加权。

**归类统计**：`nz`2、`nx`1。暂定主`nz`89%；次位未判；`nx`为功能证据。旧次`nx`90%降为单条功能证据。

**关系候选**：不登记`nz生nx`。公开资料没有锁定关系停靠与进入帮派通道的先后机制，也未排除家庭/环境第三因素。

**反证与作品主维关系**：遭殴打、被抢与陷入帮派是颜一辰的遭遇/状态，不直接计为行为。人物主`nz`只支持作品命运关系端，作品`xz`仍主要来自外部危险结构，不把作品主维倒贴给人物。

**复核与写入**：当前正本写入本报告。下一步实读定位巷口救援、工作地点、河堤谈心、传烟与两条路线分岔，确认谁先发起、动作是否同场以及退出/留在旧路线的实际步骤。

## 结构修正与风险边界

1. 旧第十五批25条旧式“行为证据”降为历史稿；本轮保留20条逐条唯一归类，未获当前来源支持的家庭照料、赚钱供养、主动戒断、稳定掌握Incal等旧推断不再进入人物结论。
2. `器官拼图 / Rest in Pieces`仍为11篇合集的`collection-scope`；两篇人物不合并，其余9篇不借用本轮结论。
3. `黎明前的回声`的书目页读者评论仅作低权重公开线索；未把评论写成全书逐页事实。
4. 本轮不登记任何正式生、补、克关系；共现或剧情先后不足以启动关系。
5. 未修改The Incal 94分、器官拼图93分、黎明前的回声93分，未改作品主维、最终归仓、作品ID、精选结论或官方理论文件。
