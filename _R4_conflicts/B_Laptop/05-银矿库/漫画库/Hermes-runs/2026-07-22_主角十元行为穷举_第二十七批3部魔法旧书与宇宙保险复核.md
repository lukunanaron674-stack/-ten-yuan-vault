# 主角十元行为穷举·第二十七批：魔法、旧书与宇宙保险复核

## 本轮口径与范围

- 本轮未发现用户侧新增漫画或人工修改；继续处理旧报告中的“单条多标签/行为概括”。
- 重做《魔男のイチ / Ichi the Witch》《本なら売るほど / 十月堂旧书事》《COSMOS》，共3部、4位人物、22条具体动作。
- 每条动作只归一个十元；战斗、职业、能力称谓、危险状态和团队结果不能自动证明人物点位。
- 《魔男のイチ》现已出版到第8卷，但第8卷书目明确行动主体为时操、デスカラス等人物，未借给伊奇；伊奇动作仍覆盖第1—5卷。
- 《本なら売るほど》现有第1—3卷；《COSMOS》现配信到第9卷，但第8—9卷书目重心是鉄ソプラノ、Sunny等人物，水森/穂村动作仍覆盖第1—3、6—7卷。

## 一、魔男のイチ / Ichi the Witch

### 对象与证据范围

- 主角：イチ（伊奇）；山中猎人进入魔女队伍的阶段。
- 主要来源：集英社[第1卷](https://www.shueisha.co.jp/books/items/contents.html?jdcn=08X10000000057314400)、[第2卷](https://www.shueisha.co.jp/books/items/contents.html?jdcn=08X10000000059602100)、[第3卷](https://www.shueisha.co.jp/books/items/contents.html?jdcn=08X10000000062751600)、[第4卷](https://www.shueisha.co.jp/books/items/contents.html?jdcn=08X10000000064279000)、[第5卷](https://www.shueisha.co.jp/books/items/contents.html?jdcn=08X10000000065906900)。
- 范围检查：集英社[第8卷](https://www.shueisha.co.jp/books/items/contents.html?jdcn=08X10000000071298600)已确认，但书目没有可独立归给伊奇的新动作。
- 当前状态：第1—5卷公开书目范围穷举，非全作原页实读；96.15/99/92/75/70/6/3评分簇不动。

### 伊奇：具体行为穷举（6条）

- 行为1：山中魔女与“王之魔法”交战并启动试炼 → 伊奇以猎人身份进入试炼并取得该魔法 → 作用于可被狩猎的具体魔法对象 → 魔法进入伊奇能够调用的范围。
  - 归类：`x`（主位证据，92%）。对象端点是通过试炼取得的具体魔法及使用权；“男性成为魔女”是结果，不另判`zx`。
- 行为2：加入デスカラス队伍并接到冰鲨狩猎任务 → 伊奇沿魔女协会给出的目标进入冻结村落 → 作用于既定任务、地点和试炼 → 他进入协会已经规定的狩猎路线。
  - 归类：`nx`（路线功能证据，87%）。对象端点是协会任务、队伍和冻结村落；方向并非由伊奇建立。
- 行为3：冰鲨试炼使正面处理受阻 → 伊奇提出秘密方案并安排下一步 → 作用于试炼条件和队伍行动顺序 → 狩猎获得一条新的可执行路径。
  - 归类：`xn`（组织功能证据，88%）。对象端点是方案、顺序和试炼条件；单次奇策不足以直接判为稳定主位。
- 行为4：反世界魔法出现在狩猎竞赛中 → 伊奇调用先前狩猎取得的魔法迎战 → 作用于已掌握魔法与当前敌手 → 已取得对象被再次投入实际使用。
  - 归类：`x`（主位证据，90%）。对象端点是伊奇已经取得并可调动的魔法；普通迎战不自动证明权能凌驾的`zx`。
- 行为5：爆神夺走悲伤并威胁国家，戈库拉克进入战局 → 伊奇决定与戈库拉克共同应战 → 作用于同伴关系与受威胁人群 → 他接下共同战斗和救援负载。
  - 归类：`n`（次位证据，87%）。对象端点是同伴及救援责任；“决定战斗”不足以单独判`zx`。
- 行为6：戈库拉克吸收悲伤后失控 → 伊奇相信同伴并协助其从噩梦中重新行动 → 作用于戈库拉克的失控状态和伙伴位置 → 戈库拉克重新成为可并肩的行动者。
  - 归类：`n`（次位证据，90%）。对象端点是落到伊奇面前的同伴负载；同一协助动作不再重复判`zn/zx`。

### 穷举后统计

- 计数：`x`2、`n`2、`xn`1、`nx`1。
- 主十元：`x`91%；次十元：`n`88%；`xn/nx`只作功能位。
- 撤回旧判：旧次`zx`90%主要把“战斗、迎战、救援”直接当权能扩张；现行`zx`要求公开显权、扩大并凌驾，当前书目没有稳定证据。
- 关系判断：不登记`x↔zn`或其他生补克。公开材料没有独立的`zn`动作；`x/n`并存也没有可核验的作用机制。
- 与作品主维：人物`x`只支持本体公式的一端，不能补出作品`zn+x`；`nx/xn`功能也不能自动裁因果或时间主维。
- 原卷复核：第1卷魔法取得边界、第2卷秘密方案、第3卷具体调用、第4—5卷救援分工。

## 二、本なら売るほど / 十月堂旧书事

### 对象与证据范围

- 主角：十月堂店主；出版社仍只称扎发的年轻店主，姓名未知。
- 来源：KADOKAWA[第1卷专题](https://www.kadokawa.co.jp/topics/13099/)、[第2卷专题](https://www.kadokawa.co.jp/topics/13695/)、[第3卷信息](https://www.kadokawa.co.jp/topics/16680/)。
- 当前状态：第1—3卷公开书目范围穷举，非短篇逐页实读；中文译名、评分与本体/空间维度冲突继续隔离。

### 十月堂店主：具体行为穷举（7条）

- 行为1：街区需要一家持续营业的旧书店 → 店主经营十月堂并维持日常开店 → 作用于营业时间、店务和来客入口 → 十月堂持续成为人与书能够进入的场所。
  - 归类：`xn`（次位证据，90%）。对象端点是营业流程和持续运行；“拥有店铺”本身不在本条重复判`x`。
- 行为2：常客或对阅读兴趣不安的高中女生进入店内 → 店主接待并听取其与书有关的需求 → 作用于来客和阅读问题 → 需求进入十月堂的对话与选书接口。
  - 归类：`n`（主位证据，89%）。对象端点是落到店主面前的来客需求；具体推荐结果待原页。
- 行为3：男子把不再需要的书带到店里处理 → 店主接受书与处理请求 → 作用于来书和处置委托 → 私人弃置问题进入旧书店的判断范围。
  - 归类：`n`（主位证据，91%）。对象端点是书与委托形成的承接负载；成交结果未公开。
- 行为4：寡妇带来亡夫藏书并提出出售 → 店主接下整批藏书和委托 → 作用于遗留书籍与丧偶关系历史 → 遗物进入可以被判断、流通的书店接口。
  - 归类：`n`（主位证据，94%）。对象端点是亡夫藏书及委托负载；未把书的情感意义另判`nz`。
- 行为5：顾客要求一本“读完前舍不得死”的有趣书 → 店主从店内书籍中作出具体选择 → 作用于由其保管和调取的库存 → 抽象要求被落实为一册可交付的书。
  - 归类：`x`（对象功能证据，90%）。对象端点是十月堂实际掌握并可选择的库存书；一次选择不扩成所有阅读意义的控制权。
- 行为6：书架需要让书继续等待下一位读者 → 店主调整店内书架和陈列 → 作用于库存位置与展示顺序 → 店内书籍获得新的可见和流通位置。
  - 归类：`xn`（次位证据，91%）。对象端点是陈列顺序和持续流通结构。
- 行为7：难缠访客打断十月堂日常 → 店主应对该访客并继续营业 → 作用于来客和店内秩序 → 访客问题被纳入店铺可以继续运行的范围。
  - 归类：`n`（主位证据，88%）。对象端点是突然落入店内的来客负载；具体处理结果待第3卷原页。

### 穷举后统计

- 计数：`n`4、`xn`2、`x`1。
- 主十元：`n`94%；次十元：`xn`90%；`x`只作库存对象功能。
- 关系判断：撤回旧`n生xn`93%候选。当前公开材料能分别证明接待与营业/陈列，但尚未证明同一输入经店主动作稳定生出持续组织结构。
- 反证：书本内容、顾客之间的偶遇和来客自身选择不能归给店主；“书连接人”是作品结果，不是店主单人动作。
- 与作品主维：人物`n`贴近空间承接端，`xn`显示营业和陈列的持续组织；仍不能裁本体78%与空间84%的作品冲突。
- 原卷复核：第1卷四类来客的处理结果、第2卷选书书名和理由、第3卷调架与难缠访客的独立动作。

## 三、COSMOS

### 对象与证据范围

- 双核心：水森楓与穂村燐。
- 来源：小学馆[第1卷](https://e-comi.shogakukan.co.jp/books/091577840000d0000000)、[第2卷](https://e-comi.shogakukan.co.jp/books/091577980000d0000000)、[第3卷](https://e-comi.shogakukan.co.jp/books/091578230000d0000000)、[第6卷](https://e-comi.shogakukan.co.jp/books/091578820000d0000000)、[第7卷](https://e-comi.shogakukan.co.jp/books/091578980000d0000000)。
- 范围检查：[第8卷](https://e-comi.shogakukan.co.jp/books/091582160000d0000000)主述鉄ソプラノ，[第9卷](https://e-comi.shogakukan.co.jp/books/091582270000d0000000)主述铁乐人、Sunny等人；其动作不计入水森或穂村。
- 当前状态：水森/穂村的第1—3、6—7卷公开书目范围穷举；91.8/12/6评分和三个题名入口继续隔离。

### A. 水森楓：具体行为穷举（5条）

- 行为1：朋友相泽失踪，穂村说明其外星人身份和COSMOS事实 → 水森沿穂村给出的说明进入案件 → 作用于朋友去向和公司入口 → 他从普通高中生活进入外星保险事件。
  - 归类：`nx`（主位证据，90%）。对象端点是穂村提供的信息、关系和处理通道。
- 行为2：COSMOS提供加入与学习路线 → 水森进入公司并跟随工程师阿贺里、前辈砂上工作 → 作用于公司角色、训练和权限流程 → 他由被告知者转为受训成员。
  - 归类：`nx`（主位证据，93%）。对象端点是公司既定岗位和前辈路线；未显示水森组织公司流程。
- 行为3：SS级婴儿绑架案被交给队伍 → 水森与穂村进入案件处理 → 作用于公司任务和被绑架对象 → 他沿任务路线参与救援调查。
  - 归类：`nx`（主位证据，88%）。对象端点是公司分派的高等级案件；团队结果不重复计给两人。
- 行为4：盗窃保险案出现，公司安排他与鉄ソプラノ组队 → 水森随搭档调查失窃线索 → 作用于保险案件和搭档通道 → 调查沿外部分派的路线推进。
  - 归类：`nx`（主位证据，94%）。对象端点是案件、搭档和公司权限；旧`xn`功能撤回，因为公开简介未显示他主动搭建调查流程。
- 行为5：双胞胎客户提出保险选择咨询 → 水森与穂村接下委托并参与临终支援 → 作用于客户选择与生命终点 → 异常生命条件进入可被陪伴和处理的服务关系。
  - 归类：`n`（承接功能证据，91%）。对象端点是客户委托和临终负载；团队中的个人步骤待原卷。

#### 穷举后统计

- 计数：`nx`4、`n`1。
- 主十元：`nx`93%；次位未判，`n`仅为一次承接功能。
- 剔除旧证据：第7卷公开简介只写水森面对“乘客生命/地球危机”两难，未公开他采取什么动作及结果；该项是局势，不计人物行为。
- 撤回旧判：旧主`n`95%把案件和两难“落到身上”本身当作主角动作；按当前口径，水森更稳定地沿穂村、公司、前辈和搭档给出的路线推进。

### B. 穂村燐：具体行为穷举（4条）

- 行为1：相泽失踪且真实身份被遮蔽 → 穂村确认相泽是外星人并向水森说明COSMOS → 作用于身份信息和案件定义 → 普通失踪被重排为可进入公司流程的外星事件。
  - 归类：`xn`（主位证据，93%）。对象端点是身份信息、案件分类和处理入口。
- 行为2：水森具有辨谎能力并卷入事件 → 穂村把水森接入COSMOS的工作路线 → 作用于水森角色和公司入口 → 水森进入受训成员位置。
  - 归类：`xn`（主位证据，91%）。对象端点是人员接入和公司流程；具体招募权限待原卷。
- 行为3：SS级婴儿绑架案由公司启动 → 穂村与水森进入案件处理 → 作用于公司任务和救援对象 → 她沿既有保险调查路线参与行动。
  - 归类：`nx`（路线功能证据，86%）。对象端点是公司分派任务；个人组织份额未公开，不重复判`xn`。
- 行为4：过去的双胞胎客户提出保险选择咨询 → 穂村接受委托并参与临终支援 → 作用于客户选择和生命终点 → 私人死亡难题进入可被陪伴的服务接口。
  - 归类：`n`（承接功能证据，90%）。对象端点是客户委托和临终负载；同一动作不再同时判`xn`。

#### 穷举后统计

- 计数：`xn`2、`nx`1、`n`1。
- 主十元：`xn`92%；次位未判，`nx/n`均为单一功能证据。
- 关系判断：撤回旧`n生xn`候选。当前`xn`发生在身份确认/人员接入，`n`发生在双胞胎临终服务；不是同一事件中的已验证前后机制。

### 双人物与作品主维

- 当前人物层：水森主`nx`、穂村主`xn`；两人团队行动分别记账，不能互借行为。
- 人物`nx/xn`共现不等于作品因果公式`zx+nx`，也不构成时间公式；作品91.8分因果候选继续二审。
- 原卷复核：第1卷招募与权限、第2卷绑架案个人分工、第3卷水森调查方案、第6卷双胞胎支援步骤、第7卷水森实际选择与结果。

## 本轮结构性修复

1. 旧22条多标签材料改为22条具体动作和22条后置唯一归类：伊奇6、十月堂店主7、水森5、穂村4。
2. 伊奇撤回`zx`次位，改为主`x`、次`n`；战斗不再自动算权能公开扩大。
3. 十月堂店主保留主`n`、次`xn`，但撤回没有闭合动作链的`n生xn`候选。
4. 水森由旧主`n`改主`nx`；穂村保留主`xn`但撤回旧次`n`和`n生xn`关系。
5. 本轮为旧批次格式复核，不新增作品/人物累计；人物索引仍为75部、96位人物。
