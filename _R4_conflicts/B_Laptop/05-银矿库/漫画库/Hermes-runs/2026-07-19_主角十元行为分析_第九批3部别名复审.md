### 金懿玄（Kim Euihyun）

**当前状态**：开篇—第2卷书目轻筛；待原作话次与后期阶段复核。

**十元判断**

- 主十元：`nx`候选，88%。自己的方向被父亲遗留债务、弟弟生存需要和债权人提供的路线持续规定；这里不是“暗中谋划”。
- 次十元：`nz`，86%。具体关系端点是需要由他带在身边、安置并保护的弟弟；这是让他停下或改道的关系位置。
- 状态/行动：`xz`危险态96%，`zx`节点行为78%。投海与高压暴力是危险状态和直接行动，暂不足以升为稳定主位。
- `x`端点：未成立。住房、工作、资金与医疗费的实际掌握者不是懿玄，不能因为他“需要”这些资源就记作`x`。

**行为证据**

1. 父亲失踪、债务与无处安置弟弟叠加 → 懿玄带弟弟走向海中，准备结束两人生命 → 作用于自己与弟弟的身体/生存路线 → 进入`xz`极端危险态；这也是`nz`的反证，不能把他美化成稳定照护者。
2. 被太洲从水中拉回、得到住处/工作/生活费方案 → 懿玄没有建立独立资源系统，而是进入对方给出的路线 → 作用于弟弟的住宿与两人的生计 → `nx`承接外部方向，`nz`使他暂时留在生存路线。
3. 黑帮冲突升级 → 懿玄把对方打到需要住院 → 作用于威胁者身体 → 当场解除压力，却新增医疗费与债务问题；这是`zx`节点行为，不等于他长期掌控局面。
4. 太洲结清医疗费并再次提出帮助 → 懿玄知道其中有操控性，仍因负担暂被接走而松动并留下 → 作用于债务、住处和弟弟安全 → 再次显示外部资源路线压过自主定向。

**行为模式总结**：自主路线崩溃时，懿玄会沿债权人/保护者提供的路径继续生存，以便让弟弟有位置可留；压力突破阈值时又会转成伤及自己或他人的直接行动。

**反证与关系机制**

- 投海同时危及弟弟，反驳“稳定`nz`照护者”的单线判断；殴打对方也反驳“全程被动”的简化。
- 不启动正式“`nx`生`x`”关系：现行表中该几何语义尚未验证，而且资源掌握端点实际在太洲一侧。

**与作品主维**：人物`nx/nz/xz`能解释债务路线与命运压力，但不能据此把作品正式裁为因果主或命运主；92分双维冲突继续保留。

### 吕太洲（Taeju）

**当前状态**：开篇—第2卷书目轻筛；保护与占有的后期比例待实读。

**十元判断**

- 次十元：`zx`，86%。公开直接介入投海、债务与冲突后果，让他人路线进入自己的安排。
- 补位候选：`nz`，82%。救人和提供安置具有照护效果，但现阶段与交易/控制并存，不能直接判为无条件关系守位。

2. 识别债务、无家可归与工作缺口 → 提供住处、工作、生活费/零用安排 → 作用于生计资源 → 把多个`x`端点集中到自己的调度边界内。

**行为模式总结**：太洲先用直接行动截断危险，再把债务、住房、工作和善后资源并入自己可调度的边界，使保护与掌握同时发生。

**反证与关系机制**

- “救人/给钱”只能证明有照护效果，不能单独证明稳定`nz`；交易条件说明其中有清楚的`x`掌握。
- 现阶段只记录“太洲的`x`资源压缩懿玄的自主定向”为观察机制，不宣布未验证的十元生补克关系。

**与作品主维**：太洲的`x/zx`使债务结算链可运行，但人物掌握资源不等于作品就是`zx+nx`因果主；作品层主次维仍待全篇二审。

## 二、排球少年 / Haikyu!!

### 日向翔阳（Shoyo Hinata）

**来源与阶段**：[[03-空间型 x并z+n]]、[[漫画库总索引]]、Hermes任务清单；从看见“小巨人”至巴西沙排修行。仅分析日向，不把影山的传球、训练决定或比赛判断记给日向。

**当前状态**：跨卷官方书目轻筛；待卷内话次复核。

**十元判断**

- 主十元：`zn`，95%。具体内部标准是“不因身高而退出球场，要以自己的方式持续成为能留在场上的选手”。
- 次十元：`xn`，93%。对象端点是训练时间、助跑/起跳、接球脚步、观察记录、健康管理与沙排身体控制等持续运行结构。
- 早期高位：`z`，90%。具体认可端点是“小巨人”形象、正式球员资格、上场位置和与强者对抗时被看见。
- 功能位：`n`，88%。承接败北、教练反馈、场边观察和身体警报，再转进训练。

**行为证据**

1. 看见“小巨人”在全国赛跃起 → 日向把“矮个也能站上大赛球场”作为自身方向，并凑人参加初中首战 → 作用于球队与上场资格 → 外部形象先触发`z`，随后沉淀成不轻易放弃的`zn`。
2. 首战败给影山 → 日向立下再战目标并进入乌野；发现影山成了队友后，仍为取得球队认可参加合作考验 → 作用于队内位置 → 把对手关系转成获得球场资格的行动。
3. 怪人快攻要求闭眼起跳、个人可控性受限 → 日向拒绝永远闭眼，和影山冲突并主动向木兔等人求教 → 作用于自己的助跑、视野和击球选择 → 重新组织训练，不满足于只做现成战术的零件。
4. 未获青年强化集训邀请 → 日向闯入集训；被拒绝参训后接受球童位置 → 作用于场边观察、脚步和接球信息 → 把“不能上场”的输入经`n生xn`转成可持续学习结构。
5. 春高因发热被迫离场 → 日向服从身体警报，在场外看完比赛 → 作用于健康与参赛资格 → 失败输入迫使他把“长期能上场”纳入训练，而不只追逐一次跳跃。
6. 高中毕业后发现室内技术边界 → 日向赴巴西学习沙排，与Heitor搭档训练 → 作用于球感、身体控制、力量和生存节律 → 用新的`xn`训练环境扩大可上场范围。

**行为模式总结**：每当上场资格被身高、技术缺口、选拔或身体状态阻断，日向就把失败与场边信息转成新的训练结构，再以更完整的能力回到球场。

**反证与关系机制**

- 跳得高、扣球直接并不自动构成主`zx`：日向长期目标不是支配他人，而是持续取得参与比赛的能力与位置。
- `n生xn`：败北、教练限制、球童观察和发热警报先被接住，随后成为训练内容与健康管理。
- `xn补z`：训练结构为他补充可公开验证的能力，目标端点是正式上场/被承认为能打完整比赛的选手；不是因为二者共现就宣告补。

**与作品主维**：人物主`zn`、次`xn`不等于作品空间主`x并z+n`。日向不断争取“留在场上”，反而让球场边界、位置规则和球队容器变得可见；人物机制与作品空间主题相关但分层。
