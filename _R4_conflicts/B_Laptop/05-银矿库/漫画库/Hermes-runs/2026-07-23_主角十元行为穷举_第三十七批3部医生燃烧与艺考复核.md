# 主角十元行为穷举 · 第三十七批3部医生燃烧与艺考复核

## 本轮边界

- 扫描结果：上一轮后没有人工新增漫画；最近变化仍是自动化报告、人物索引、任务清单和台账的同步写入。
- 本轮对象：天马贤三、Agni、矢口八虎。旧第五批的 `BILLY BAT` 因长期群像与时代切换下的主角边界仍需单独锁定，本轮暂缓，旧报告只被部分替代。
- 覆盖范围：《MONSTER》VIZ完全版第1、2、3、5、6、7卷公开简介；《炎拳》VIZ第1—8卷公开简介；《蓝色时期》讲谈社第1—6卷公开简介。

- 一条动作只归一个十元；同一动作不重复计票。行为不足以判断时保留“暂不归类”。

### 统计后判断

- 唯一归类统计：`xn`3 / `xz`2 / `nx`2 / `zn`1 / `n`1，共9条。
- 主十元：`xn`95%候选。寻人、追踪秘密过去和前往关键现场形成跨卷、重复且可观察的调查组织动作。
- 次十元：未判。`xz`与`nx`各两条但分别承担逃亡边界和外部信息通道，证据权重不足以压过另一方；`zn/n`各为一条高强度功能证据。
- 撤回旧结论：旧主`zn`95%、次`n`92%撤回。医疗誓言与寻找Nina仍成立，但旧卡把价值和责任的叙事重要性当成行为频次；本轮公开动作实际最密集的是`xn`。
- 关系候选：不登记。调查与逃亡交替出现，但通缉、国境和Johan反制都是强第三因素，尚不能证明稳定的`xn生xz`单向机制。
- 与作品主维关系：人物`xn`可旁证因果作品的调查执行层，`xz/nx`显示执行受到追捕与外部证言制约；但作品的善恶因果、Johan行动和群像后果不能缩成天马个人十元。
- 原卷复核：完全版第1卷手术选择；第2卷逃亡、追踪与Nina救援；第3卷Gillen接入；第5—7卷跨境、旧楼证言和红玫瑰宅邸的具体页码；第9卷结局动作须原卷复核后再增量写入。

### 统计后判断

- 唯一归类统计：`zx`3 / `xn`2 / `xz`2 / 暂不归类1，共8条。
- 主十元：`zx`96%候选。复仇誓言、与Doma交战、焚毁阻路者三条跨越开篇、中段与终局路线，均将自身力量直接压向外部对象。
- 次十元：未判。`xn`与`xz`各两条，分别承担追索组织与临界逃离功能；公开简介不足以确认哪一个稳定居次。
- 撤回旧结论：旧主`nz`90%、次`nx`86%撤回。失去亲人、承诺与虚假身份是重要关系背景，但公开动作中没有足够多独立`nz`行为；Togata拍摄与外部脚本也不能直接算成Agni的`nx`。
- 关系候选：`xz生zx`90%候选。来源=`xz`在不灭火与毁村后的生存边界中持续行动；目标=`zx`立誓、交战与焚毁清路；机制=无法退出的身体危险把“活下来”转成对外直接施力；改变变量=从承受火焰到主动让火焰作用于敌人与阻路者；第三因素=Doma、Togata与Judah路线；反向存在，因为复仇也会制造新危险，故仅保留候选。
- 与作品主维关系：人物`zx`显示强烈公开执行面，`xz`显示身体边界压力；二者不能自动证明或推翻作品旧本体主记录，更不能恢复旧96分正式主条。
- 原卷复核：第1—3卷拆分求生、誓言、Doma交战与Togata路线；第5卷确认“源头人物”；第7卷确认寻找出口的实际动作；第8卷确认前往Judah途中各次攻击对象。

- 次十元：`zn`94%候选。投入绘画和裸体自画像分别改变生活方向与自我表达对象，强度高但次数少于`nx`。
- 功能位：`x`92%、`xn`91%各一条，分别对应具体画材掌握和现场资源重排。
- 撤回旧结论：旧主`xn`94%、次`z`89%撤回。训练持续性没有消失，但公开动作显示大部分方向由同伴、教师、竞赛和考试流程给出，更贴近`nx`；“被画击中/想被看见”不足以直接证明稳定`z`。
- 关系候选：不登记。现行表虽列`nx生x`，但机制仍待补全；本轮只观察到外部训练之后取得新材料这一先后，不越权把它写成正式生链。
- 与作品主维关系：人物`nx+zn`解释学习接口与自我表达，单点`x`解释画材；这些人物动作不自动形成作品空间公式`x并z+n`，画室是否为作品主容器仍需作品层独立二审。
- 原卷复核：第1卷投入绘画的具体动作；第2—4卷同伴/大师、竞赛、教师挑战和新材料的取得主体；第5卷第一次考试、离开画室和裸体自画像；第6卷第二次考试的挫折与应对。
