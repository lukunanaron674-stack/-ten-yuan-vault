  - 归类：`nx`（次位证据，92%）。对象端点是ふわり既有的偶像目标、选秀路线和推—被推关系；方向由ふわり的选择先给出，循菜沿该方向进入。

  - 归类：`xn`（主位证据，91%）。对象端点是排名目标、节目流程和后续行动安排；证据确认主动组织意图，但具体步骤待原卷。
- 行为3：第1阶段启动 → 循菜把ふわり引导到预定排名并使其获得注意 → 作用于排名顺序和舞台曝光 → 预设结果在该阶段兑现。
  - 归类：`xn`（主位证据，95%）。对象端点是1st stage排名、ふわり曝光位置和阶段节点；她主动安排并命中预定结果。

  - 归类：暂不归类（证据不足）。官方简介只给出团队共同结果，没有说明循菜承担了哪一个独立动作，不能把队友行为记给她。
- 行为5：第3阶段与ふわり分队、队内必有一人淘汰 → 循菜在正式舞台连续采用奇策 → 作用于自己的留存位置与ふわり的发光条件 → 她继续存活，同时维持推位方向。
  - 归类：`xn`（主位证据，94%）。对象端点是淘汰规则、舞台节点、本人留存与ふわり曝光；具体奇策内容仍待第4卷实读。

### 穷举后统计

- `xn`：3条高质量主动组织证据，跨第1—3阶段，主十元95%。
- `nx`：1条稳定方向归属证据，次十元92%。

### 关系、反证与作品层

## 二、邪神の弁当屋さん

### 对象、阶段与来源

- 主角：レイニー，曾是死与丰收之神ソランジュ，受罚后以人类身份经营便当摊。
- 阶段：全4卷；人类生活、便当营业、旧神殿共同劳动至最终神/人选择前。
- 库内来源：`漫画库_全名单-精修版-2026-06-02.md`、`漫画库总索引.md`。
- 官方来源：讲谈社[第1卷](https://www.kodansha.co.jp/comic/products/0000404585)、[第2卷](https://www.kodansha.co.jp/comic/products/0000415367)、[第3卷](https://www.kodansha.co.jp/comic/products/0000420295)、[第4卷](https://www.kodansha.co.jp/comic/products/0000422725)、[官方专题](https://news.kodansha.co.jp/comics/20151239)。
- 当前状态：全4卷官方书目轻筛完成；第4卷只确认创世主要求其在“回归神位/作为人生活”之间选择，公开简介没有公布选择结果，故结局不补写。

### 公开书目范围行为穷举与逐条归类（6条）

- 行为1：因过去引发战争而受到惩罚 → レイニー停止原来的神之生活，以人类身份继续生活 → 作用于自身身份和惩罚后果 → 神的停职状态被接成人类日常。
  - 归类：`n`（主位证据，92%）。对象端点是落到她身上的人类身份与惩罚后果；她没有退出，而是把后果接入生活。
- 行为2：进入人类生活后 → 她每天在城堡附近中央广场经营便当摊 → 作用于摊位、食物和来客 → 惩罚后的生活获得可持续落点。
  - 归类：`n`（主位证据，94%）。对象端点是便当摊、每日来客和人类生活；重点是持续承接生活，不以普通职业本身证明`xn`。
- 行为3：制作便当时面对形状不同的食材 → 她按“做出高度、填满空隙、放入同一模具”的方法装盒 → 作用于食材、便当盒和摆放顺序 → 零散材料成为可交付便当。
  - 归类：`xn`（次位证据，88%）。对象端点是食材形状、装盒顺序、空隙与便当成品；她主动组织材料怎样运行成结果。
- 行为4：无依无靠的少年进入她的生活 → 她向少年教会重要事项 → 作用于少年当前生活问题 → 少年取得可继续生活的信息。
  - 归类：`n`（主位证据，82%）。对象端点是落到身边的少年及其生活问题；具体教学内容和触发过程仍待第2卷。
- 行为5：北国居民到旧神殿大扫除 → 她虽不情愿仍加入既有共同劳动 → 作用于神殿、公共安排与居民关系 → 她与人群共同完成这段劳动并共享时间。
  - 归类：`nx`（功能位，84%）。对象端点是居民已启动的清扫安排和共同劳动路线；方向并非由她设定，她沿既有群体行动加入。
- 行为6：每日营业进入下一日准备 → 她持续思考明天便当要做什么配菜 → 作用于次日菜单与经营延续 → 今天的营业获得下一节点。
  - 归类：`xn`（次位证据，86%）。对象端点是次日菜单、准备节点与营业连续性；公开材料未给出完整排程，故置信度保守。

### 穷举后统计

- `n`：3条承接—处理证据，覆盖惩罚、人类营业与少年问题，主十元94%。
- `xn`：2条材料/次日组织证据，次十元88%。
- `nx`：1条沿公共安排加入的功能行为，84%。
- “一日一善”只作为原则背景保留；官方简介没有列出对应具体善行，因此不把抽象口号单独伪造成行为。

### 关系、反证与作品层

- 关系候选：`n生xn`（84%）。人类生活与每日便当责任先被她接住，才持续提供可被安排的食材、菜单和营业任务，使次日流程能够展开；顾客需求、市场、同住者和惩罚制度都是第三因素，故只记候选。
- 最近邻排除：“一日一善”不自动等于`zn`，公开材料没有证明她用一套价值原则跨冲突自我校正；温柔共居也不自动等于`nz`，未见“不愿关系结束而保持原位”的稳定证据。普通职业劳动也不自动等于`xn`，本轮只把重复装盒、菜单与次日准备归为功能证据。
- 与作品主维：人物主`n`与库内空间主候选在“承接”端局部一致；便当盒、摊位与旧神殿是对象/场景层，不能据此宣告人物具备完整`x并z+n`，也不能由人物反改作品主仓。
- 待复核：第1卷“一日一善”的具体行为；第2卷教少年什么、由谁触发；第3卷神殿清扫中的主动程度；第4卷最终选择及选择后便当日常是否继续。
- 建议写入：人物索引、总索引待定行；93分、空间主记录和归仓保持原状。

- 库内来源：`漫画库_全名单-精修版-2026-06-02.md`、`漫画库总索引.md`、`04-因果型 zx+nx.md`、`二审-命运型_xz+nz.md`。

- 当前状态：漫画2卷官方书目轻筛完成；正式日文题名与漫画媒介已锁。库内93分主记录、旧9分因果驳回和命运/因果/本体三向记录继续隔离。逐条穷举后人物主位由旧概括版`n`调整为`nx`。

### 公开书目范围行为穷举与逐条归类（5条）

- 行为1：被投入不能以死亡退出的惩罚勇者制度 → ザイロ持续带领由问题罪犯组成的9004队站在魔王现象前线 → 作用于队伍与当前战场 → 队伍仍能进入连续作战。
  - 归类：`n`（次位证据，88%）。对象端点是落到他手中的9004队、战场后果与领队责任；具体指挥步骤待原卷。
- 行为2：圣骑士团在绝境中被压垮 → 他为活下去决定击倒魔王并公开宣告反击 → 作用于战斗方向和现场敌对对象 → 被压制状态出现直接反攻方向。
  - 归类：`zx`（战斗功能位，84%）。对象端点是当下魔王现象和反击方向；只有一次宣告/行动节点，不足以证明人物权能持续扩大并凌驾秩序。
- 行为3：自身现有手段不足以完成反击 → 他判断テオリッタ的力量不可缺少 → 作用于外部力量、权限位置和解决通道 → 反击路线转向女神关系接口。
  - 归类：`nx`（主位证据，86%）。对象端点是属于テオリッタ的力量和使用许可；关键资源不在他手中。
- 行为4：确认力量属于テオリッタ → 他承认需要她并与她缔结契约 → 作用于女神权限、契约关系与战斗资源 → 他取得借力通道并脱离当下危机。
  - 归类：`nx`（主位证据，92%）。对象端点是テオリッタ拥有的力量、契约许可和借力关系；这是明确通过他者权限办事。
- 行为5：脱离危机后立即收到下一道命令 → 他与其他惩罚勇者按命令前往异形化煤矿 → 作用于制度路线、队伍和任务地点 → 行动沿刑罚体系进入下一阶段。
  - 归类：`nx`（主位证据，91%）。对象端点是上级命令、惩罚勇者流程和煤矿任务；方向由制度给出，他沿既有安排推进。

### 穷举后统计

- `nx`：3条高质量外部方向/权限证据，覆盖女神契约和下一任务，主十元92%。
- `n`：1条持续领队承载证据，次十元88%。
- `zx`：1条直接反击功能证据，84%；不升稳定人物主位。
- “理想消失、愤怒未消”是状态/动机背景，不是可独立分类的具体动作，故不拿它制造`z`证据。

### 关系、反证与作品层

- 关系候选：`nx补zx`（83%）。行为3—4通过契约取得テオリッタ的力量与许可，补足行为2直接反击所缺的战力条件，使反击功能重新成立；公开简介不足以证明`zx`是稳定人物主位。
- 最近邻排除：领队、战斗、决定反击和“很能扛”都不自动等于`zx`；目前没有足够证据显示其权能持续公开扩大并凌驾秩序。愤怒与复仇也不自动等于`z`，公开材料没有给出确认其存在/能力/价值的认可主体。

- 待复核：第1卷ザイロ作为队长具体处理哪些队员/命令；契约条件由谁提出、权限如何分配；第2卷煤矿任务中他是照令推进还是主动重排路线；复仇对象与行动是否跨卷稳定。
- 建议写入：人物索引、总索引待定行、同名/评分/维度复审队列；93/9分、主维和归仓保持原状。
