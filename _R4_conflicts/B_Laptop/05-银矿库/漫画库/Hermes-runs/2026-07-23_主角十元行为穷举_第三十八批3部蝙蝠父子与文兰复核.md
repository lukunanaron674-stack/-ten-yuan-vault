# 主角十元行为穷举 · 第三十八批3部蝙蝠父子与文兰复核

## 本轮边界

- 扫描结果：第三十七批后没有人工新增漫画；本轮依优先级继续清理仍使用“行为总结/单条多标签”的旧第四、第五、第六批人物记录。
- 本轮对象：Kevin Yamagata、成年Jimmy Corrigan、Thorfinn。群像人物、作者经历、世界观设定和他人行动不借给三位主角。
- 覆盖范围：《BILLY BAT》讲谈社第1、5—8、18卷公开简介；《Jimmy Corrigan》Penguin Random House全书介绍与三篇可靠书评；《Vinland Saga》讲谈社系列页及第5—12卷公开简介。
- 本报告只对上述公开材料明确给出的动作负责，不是全作逐页穷举。公开材料只给心理、假设、结果或群体动作时，保留“暂不归类”或直接排除，不用常识补场景。
- 一条动作只归一个十元，同一动作不重复计票；人物行为层统计不自动改作品评分、主维、归仓或官方理论。

## 一、《BILLY BAT》｜Kevin Yamagata

- 身份与阶段：日裔美国漫画家；覆盖发现蝙蝠形象来源疑点、JFK预言干预、失败后再赴日及晚年巴斯克追索。
- 来源文件：[[04-因果型 zx+nx]]、[[漫画库总索引]]、[[漫画主角十元行为分析索引]]、旧第五批报告。
- 当前状态：讲谈社指定卷次公开范围穷举；勘兵卫、Oswald、杂风、Kevin Goodman与Timmy的独立行动均已排除。

- 行为1：有人指出同一蝙蝠形象可能早已在日本出现 → Kevin中断美国漫画工作并前往战后日本核验 → 作用对象为图像来源、原作者线索与自身创作资格 → 一个外部疑点被建立为跨国调查路线。【BB-1】
  - 归类：`xn`（次位候选证据，95%）。对象端点：图像来源、赴日路线和核验步骤；问题来自他人，但赴日核验是Kevin主动建立的解决结构。

- 行为2：Billy让Kevin预见JFK暗杀并给出改变历史的方法 → Kevin按提示寻找可介入的暗杀节点 → 作用对象为预言、JFK与指定干预条件 → 他沿超常接口给出的方向进入历史事件。【BB-5】
  - 归类：`nx`（主位候选证据，94%）。对象端点：Billy提供的方法、暗杀节点与可介入条件；方向和通道由Billy给出，Kevin沿既有路线办理。

- 行为3：阻止暗杀与不阻止暗杀都可能导向灾难 → Kevin继续比较两条历史分支及其介入后果 → 作用对象为JFK生死、登月时间与人类存续 → 冲突预言被维持为需要持续权衡的执行问题。【BB-6】
  - 归类：`xn`（次位候选证据，92%）。对象端点：两条历史分支、介入条件和后果比较；此条只记主动组织判断，不把预言内容本身算成Kevin行为。

- 行为4：暗杀阻止失败且Billy再次指示他赴日 → Kevin前往东京奥运时期的日本追查蝙蝠卷轴 → 作用对象为Billy指令、卷轴位置与调查路线 → 失败后的调查被外部指令重新启动。【BB-8】
  - 归类：`nx`（主位候选证据，95%）。对象端点：Billy的再赴日指令、蝙蝠卷轴和既有调查通道；路线不是Kevin从零建立。

- 行为5：晚年已看不见也听不见Billy但“时之卷”仍指向巴斯克 → Kevin沿卷轴指向前往巴斯克寻找答案 → 作用对象为时之卷、指定地点与长期谜题 → 原指令者消失后，遗留接口仍继续规定他的行程。【BB-18】
  - 归类：`nx`（主位候选证据，96%）。对象端点：时之卷、巴斯克地点和遗留调查方向；实际行动明确，但方向仍来自既有接口。

### 统计后判断

- 唯一归类统计：`nx`3 / `xn`2，共5条。
- 主十元：`nx`94%候选。Billy的方法、再赴日指令和时之卷跨中晚期反复提供最终方向，Kevin主要沿外部接口继续办理。
- 次十元：`xn`92%候选。首次赴日核验和两分支权衡表明他会主动建立调查与判断结构，并非纯粹被推着走。
- 旧结论处理：保留旧`nx`主、`xn`次的大方向，但撤回“每一条行为同时证明`nx+xn`”的重复计数，也撤回第7卷Kevin主动进入牺牲位置的动作证据；公开简介只确认牺牲假设和Oswald的保护行动。
- 关系候选：不登记。`nx`给方向与`xn`组织执行在行为上相邻，但现行关系表没有二者的锁定生克补，且卷轴、预言和历史事件都是强第三因素。
- 与作品主维关系：Kevin的`nx`可旁证作品因果型的一条人物接口，`xn`解释他如何把接口变成调查；跨时代因果网仍由多人物、卷轴与历史事件共同成立，不能缩成Kevin个人。
- 原卷复核：第1卷赴日决定；第5—6卷干预方法与分支权衡；第8卷失败后再赴日；第18卷巴斯克启程。第7卷只有在原页确认Kevin的主动选择后才可增量补写。

- 当前状态：PRH全书简介与可靠书评范围穷举；评论中涉及作者Chris Ware本人父亲的经历已剔除，不借给Jimmy。

- 行为1：母亲持续打电话并规定亲子交流节奏 → Jimmy反复接听并应对来电 → 作用对象为母亲、通话关系与日常安排 → 亲子关系按母亲发起的路线继续运作。【JC-G07】

- 行为3：当面谈话要求Jimmy回应父亲与陌生人 → Jimmy说话时把手挡在嘴前并断续回应 → 作用对象为当面交流、自己的发声方式与对方注意 → 交流仍发生，但公开材料不足以确定遮挡动作是在跟随、隐藏身份还是调节恐惧。【JC-G07】

- 行为5：现实交流持续受阻 → Jimmy在页面中构造自己成为英雄、恋人或有能力者的幻想段落 → 作用对象为想象中的自己、观众与关系结果 → 叙事呈现了替代现实的内部场景，但没有形成现实中的身份壳或公开认可结果。【JC-G07】
  - 归类：暂不归类（证据不足）。理由：幻想是可见的叙事动作，但不是现实关系中的稳定`z`表达或`x并z`身份接口，不能借想象结果给人物计票。

### 统计后判断

- 唯一归类统计：`nx`3 / 暂不归类2，共5条。
- 主十元：`nx`95%候选。母亲来电、父亲邀请和父亲安排的团聚在不同关系窗口里都先给方向，Jimmy随后回应或跟随。
- 次十元：未判。遮嘴和幻想虽重要，却没有唯一行为功能；旧次`z`84%撤回，不再把“想被认可”的主题解释当成现实动作计票。
- 反证边界：Jimmy接受邀请并跨州行动，反证“完全无行动”；但主动行动不等于主动建立方向，仍可归`nx`。社交沉默也不能当作`nx`的额外正证，只记已有显影机会下的行为限制。
- 关系候选：不登记。现行`z克nx`仍未锁定，且本轮没有现实`z`动作端点，不能从幻想倒推出关系启动。
- 与作品主维关系：人物`nx`不等于作品本体主维。作品的家族身份、跨代创伤和页面时间结构属于作品层；Jimmy的行为统计只说明他在现实关系中如何沿别人给出的路线行动。
- 原书复核：母亲来电页；父亲邀请与出发；首次会面谈话中的遮嘴动作；感恩节团聚流程；英雄、爱情和能力幻想分别所在页。父亲死亡后返芝加哥因现有在线评论混入作者经历，本轮不计动作。

## 三、《Vinland Saga》｜Thorfinn

- 身份与阶段：Thors之子、复仇战士、奴隶与Vinland开拓计划组织者；覆盖复仇期、农场劳动、自由后筹资及Jomsborg救援。

- 当前状态：讲谈社系列页及第5—12卷公开书目范围穷举；主角个人动作与“队伍整体”结果分开。

- 行为1：父亲被Askeladd的佣兵团杀死 → Thorfinn留在杀父者队伍并不断战斗以争取决斗机会 → 作用对象为Askeladd、佣兵战场和自己的战斗能力 → 复仇被维持为直接对抗路线。【VS-1】

  - 归类：`nx`（功能位证据，92%）。对象端点：主人规定的土地、劳动流程和任务方向；此阶段的清林动作尚未单独证明Thorfinn建立规则。

- 行为3：农场允许以可盈利收成买回自由 → Thorfinn与Einar把清林耕作持续推进到赎身目标 → 作用对象为土地、收成、时间和自由价格 → 被规定的劳动被重新组织为可积累的赎身项目。【VS-6】
