# 2026-07-22 主角十元行为穷举：第三十一批3部逃亡影像与天使复核

## 本轮口径与覆盖边界

- 本轮重做 `逃げ上手の若君 / 擅长逃跑的殿下`、`1秒24帧的人生 / １秒２４コマのぼくの人生`、`天使夜未眠 / アーシアン / EARTHIAN` 3部作品、4个人物对象。
- 固定顺序是先从出版社公开材料中抽取具体动作，再逐条唯一归类；没有动作就不以愿望、感受、背景危险或作品主题补足。
- 本报告只穷举当前取得的出版社卷册简介、出版社样张说明和书目材料中的可观察动作，共23条；不是逐页实读，也不是全作穷举。
- 一条动作只记一个十元。多人共同动作只在公开材料明确把主角包含在行动主体内时保留；不能确定的集体战果不归到主角。
- 本轮不修改作品评分、五大主题主次维或最终归仓；人物十元只用于解释人物行动层。

## 一、逃げ上手の若君 / 擅长逃跑的殿下

**人物与身份**：北条时行；北条本家嫡子、逃若党核心人物。

**覆盖范围**：集英社第1、7、9、20、21、23卷公开书目，覆盖1333年镰仓失陷后至打出浜战局的离散节点。不是第1—23卷逐页穷举。

**来源文件**：[[漫画库总索引]]、[[02-时间型 xn+z]]、[[05-命运型 xz+nz]]、[[同名冲突复审队列]]、[[Hermes-漫画五大主题任务清单]]。

### 具体行为穷举

- 行为1（第1卷）：失去家族与故乡、诹访赖重邀请他之后 → 接受赖重的引导，开始以逃亡求生并走向英雄的路线 → 赖重提供的庇护关系与行动路径 → 从孤立失势转入一条可继续行动的外部路线。
  - 归类：`nx`（主位证据，94%）。对象端点：赖重这一外部引导者，以及由其开启的庇护、逃亡和再起路线。

- 行为2（第7卷）：天皇暗杀计划需要先解决脱出问题 → 主动调查逃生路线 → 暗杀地点周边的出入口与撤离条件 → 计划获得可执行的撤离信息。
  - 归类：`xn`（功能位证据，94%）。对象端点：路线信息、出入口和执行步骤；这是组织行动条件，不等于已经成功逃脱。

- 行为3（第7卷）：需要学习逃跑的要领 → 独自进入楠木正成宅邸求取逃跑之道 → 楠木正成的经验与既有权威渠道 → 接入一条外部知识路线。
  - 归类：`nx`（主位证据，91%）。对象端点：楠木正成这一外部专家及其经验渠道；“独自进入”不另计第二条动作。

- 行为4（第7卷）：吹雪提出足利高氏暗杀方案 → 与同伴按该方案展开暗杀行动 → 吹雪设计的步骤和足利高氏这一任务目标 → 主角进入由他人方案规定的执行位置。
  - 归类：`nx`（主位证据，90%）。对象端点：吹雪提供的行动方案、同伴分工和任务路线；公开书目未单列时行个人战果。

- 行为5（第9卷）：离开信浓前需要明确政治身份 → 当众宣告自己是北条本家嫡子 → 追随者、敌军与政治秩序 → 隐匿身份转为公开、可被承认或敌对的政治身份。
  - 归类：`z`（功能位证据，91%）。对象端点：认可主体是追随者、敌军与政治秩序；认可内容是“北条本家嫡子”。

- 行为6（第20卷）：败走吉野并受托携带北畠显家的遗奏 → 带着遗奏直接向后醍醐天皇进言 → 遗奏所承载的败因与天皇这一权力对象 → 把受托信息送到最高权力面前，同时承担触怒天皇和被判死罪的后果。
  - 归类：`n`（功能位证据，92%）。对象端点：北畠显家交付的遗奏、败因信息和传达责任。

- 行为7（第21卷）：小笠原贞宗再度构成阻碍、高坂高宗提出回到信浓 → 接受建议并返回信浓 → 高坂提出的路线与信浓这一行动节点 → 重新进入可与贞宗决战的外部路径。
  - 归类：`nx`（主位证据，89%）。对象端点：高坂高宗的建议、返回信浓的路径和由此恢复的行动位置。

- 行为8（第21卷）：返回信浓后需要终结与贞宗的对立 → 主动向贞宗发起最终决战 → 贞宗及其控制的战场门槛 → 自愿进入可能造成败亡的高风险临界局面。
  - 归类：`xz`（功能位证据，88%）。对象端点：贞宗、最终决战和生死/败亡临界；普通交战不另行扩写为`zx`。

- 行为9（第23卷）：足利直冬阵营的师冬以野心推进战局 → 时行使出“鬼心仏刀”斩断师冬的野心 → 师冬这一直接对手及其进攻意志 → 以个人招式公开压倒对方的推进。
  - 归类：`zx`（功能位证据，90%）。对象端点：师冬这一可直接对抗、可被个人技术压制的对象。

### 归类统计与人物结论

- 统计：`nx`4条，`xn`1条，`z`1条，`n`1条，`xz`1条，`zx`1条。
- 暂定主十元：`nx`95%。跨卷重复的是“接入外部人物、方案或路线后进入下一行动位置”。
- 次十元：暂不判定。其余十元各只有1条动作，列为功能位，不以单点材料制造稳定次位。
- 关系判断：本轮不启动生、补、克。`nx`、`xn`、`xz`和`zx`分别来自不同动作与不同卷册，公开书目没有证明它们构成连续机制链。
- 反证/旧结论撤回：逃亡危险经常存在，但可观察动作中`xz`仅1条；因此撤回旧“主`xz`96%、次`xn`93%、`xn生xz`”人物结论。第9卷书目只提出能否躲过追击的问题，不把疑问句当成已完成逃脱动作。
- 与作品主维关系：人物主`nx`只说明他常借外部渠道续接行动，不能直接证明作品的时间主维或命运次维。作品90分、90/13同名冲突和维度二审均保持原状。
- 待复核：第7卷需要拆清“调查路线、入宅学习、执行暗杀计划”的具体页码及参与度；第23卷需核“鬼心仏刀”的动作主体和结果画面。

## 二、1秒24帧的人生 / １秒２４コマのぼくの人生

**人物与身份**：りんたろう；以本人职业经历为叙事对象的自传主人公。

**覆盖范围**：河出书房新社书目、出版社样张页说明及出版宣传列出的少年期、东映动画/虫制作职业节点、代表作和自传制作过程。不是全书逐页穷举。

**来源文件**：[[漫画库总索引]]、[[01-本体型 zn+x]]、[[02-时间型 xn+z]]、[[同名冲突复审队列]]、[[Hermes-漫画五大主题任务清单]]。

### 具体行为穷举

- 行为1（少年期/样张第90页）：想让影像动起来 → 制作幻灯机和纸制胶片 → 纸张、图像、放映结构与制作步骤 → 零散材料被组织为能够放映的装置。
  - 归类：`xn`（主位证据，92%）。对象端点：材料顺序、装置结构和制作流程。

- 行为2（少年期/样张第90页）：装置完成后 → 用自制幻灯机和纸胶片举行放映 → 已掌握的装置、胶片和观看界面 → 制作物被转成他人可以观看的影像呈现。
  - 归类：`x并z`（功能位证据，88%）。对象端点：他亲手掌握的幻灯机、纸胶片及其向观众呈现的界面包装。

- 行为3（1958年/样张第120页）：进入动画行业 → 加入东映动画并承担完成检查工作 → 既有制片厂、岗位规范和生产流程 → 进入外部组织规定的职业路线。
  - 归类：`nx`（次位证据，90%）。对象端点：东映动画这一组织、完成检查岗位及其既有工作路线。

- 行为4（1962年/样张第144页）：职业路线发生转换 → 加入虫制作并在该组织中与手冢治虫相遇 → 虫制作的组织入口与职业关系 → 接入新的制作网络。
  - 归类：`nx`（次位证据，88%）。对象端点：虫制作这一组织入口及由此建立的职业关系；“相遇”不另归第二个十元。

- 行为5（1963年）：获得《铁臂阿童木》第26话的执导机会 → 完成该话导演工作 → 单话镜头、作画与制作流程 → 首次以导演身份交付成片。
  - 归类：`xn`（主位证据，92%）。对象端点：第26话的制作流程、镜头安排和成片交付。

- 行为6（《森林大帝》阶段）：承担总导演职责 → 统筹《森林大帝》的系列制作 → 系列各环节与持续生产节奏 → 多环节被纳入统一的导演流程。
  - 归类：`xn`（主位证据，93%）。对象端点：系列制作流程、团队环节和持续交付节奏。

- 行为7（《银河铁道999》阶段）：接下电影导演工作 → 执导《银河铁道999》 → 电影项目的镜头、人员与工序 → 项目被组织为完成影像。
  - 归类：`xn`（主位证据，94%）。对象端点：该电影项目的制作步骤、镜头和交付结果。

- 行为8（《幻魔大战》阶段）：承担导演工作 → 执导《幻魔大战》 → 电影项目的制作环节 → 项目按导演流程形成成片。
  - 归类：`xn`（主位证据，91%）。对象端点：该电影项目的制作环节与成片交付。

- 行为9（《大都会》阶段）：与大友克洋的讨论促成项目后 → 执导《大都会》 → 已启动的电影项目与生产体系 → 项目被推进为完成影像。
  - 归类：`xn`（主位证据，93%）。对象端点：该电影项目的制作流程和最终成片；讨论是触发条件，不另算主角动作。

- 行为10（自传制作阶段）：需要把长期职业经历转成漫画 → 用六年收集记忆、像拼图一样排列，再逐格绘制 → 个人记忆、时间节点和漫画画格 → 分散经历被组织为可阅读的自传漫画。
  - 归类：`xn`（主位证据，96%）。对象端点：记忆材料、时间顺序、画格和六年制作流程。

- 行为11（日文版制作阶段）：法文版内容需要进入日文版 → 亲自重写日文版拟声词 → 画面中的声音文字与日文阅读界面 → 译版的声音表现得到逐项调整。
  - 归类：`xn`（主位证据，89%）。对象端点：拟声词文本、画面位置和日文版制作环节。

### 归类统计与人物结论

- 统计：`xn`8条，`nx`2条，`x并z`1条。
- 暂定主十元：`xn`95%。从童年装置、单话/系列/电影执导到六年自传制作，均以组织材料、步骤和交付为重复动作。
- 暂定次十元：`nx`89%。证据仅来自两次进入既有制片组织，强度明显低于`xn`。
- 功能位：`x并z`88%，只对应把自制装置和胶片转成观看界面的单点动作。
- 关系判断：本轮不启动生、补、克。`nx`是进入组织，`xn`是组织项目，公开材料没有把两者写成现行关系表所要求的完整启动链；旧`xn补z`撤回。
- 反证/旧结论撤回：出版社材料反复出现的是制作和执导动作，没有足够具体行为证明稳定`zn`、`z`、`x`或`n`；因此撤回旧“主`zn`96%、次`xn`94%”人物结论。电影热爱和生命意义只作叙事动机，不冒充动作。
- 与作品主维关系：人物主`xn`为作品时间维提供人物执行层旁证，但不自动解决库内本体主/时间次的维度冲突，也不能单独补足时间公式中的`z`。作品93分和现有归仓不改。
- 待复核：回查第90、120、144、227页及代表作章节，确认每一节点在漫画中由何种画格呈现；正式日文/法文题名继续按版本范围复审。

## 三、天使夜未眠 / アーシアン / EARTHIAN

**人物与身份**：千飒（加分调查员）与影艳（减分调查员）；双核心人物分别计数。

**覆盖范围**：新书馆Wings Comics日版第1、3、4、5卷公开书目。第3—5卷简介主要提供分离、动摇、袭击等状态，缺少可唯一归到人物的动作，所以本轮只保留第1卷可核验的3条动作。不是全5卷逐页穷举。

**来源文件**：[[漫画库总索引]]、[[03-空间型 x并z+n]]、[[05-命运型 xz+nz]]、[[同名冲突复审队列]]、[[Hermes-漫画五大主题任务清单]]。

### 千飒：具体行为穷举

- 行为1（第1卷）：希望拯救地球人 → 选择成为给地球人寻找加分的调查员 → 调查岗位及其评价方向 → 把个人价值判断落实为承担“加分调查”的角色。
  - 归类：`zn`（功能位证据，92%）。对象端点：其内部认可的“拯救地球人”原则，以及与该原则一致的岗位选择。

- 行为2（第1卷）：开始执行调查任务 → 与影艳一同降落地球 → 天使方分配的调查路线与地球这一任务地点 → 进入既定任务渠道。
  - 归类：`nx`（功能位证据，88%）。对象端点：调查员职务、同行搭档和由制度规定的地球调查路线。

### 千飒：归类统计与人物结论

- 统计：`zn`1条，`nx`1条。
- 主十元、次十元：均暂不判定。两条动作分属一次岗位选择和一次任务执行，没有跨阶段重复证据。
- 关系判断：不启动关系。岗位选择与执行任务尚不足以证明`zn`与`nx`之间的现行生、补、克机制。
- 反证/旧结论撤回：第3—5卷书目中的“不想离开”“动摇”“感情萌生”属于心理状态；“被强制拆散”“基地遭袭”是他人/背景事件，不能证明千飒稳定`nz`或`xz`。撤回旧主`zn`96%、次`nz`94%及其关系判断。

### 影艳：具体行为穷举

- 行为1（第1卷）：以减分调查员身份开始任务 → 与千飒一同降落地球 → 天使方分配的职务、搭档和调查路线 → 进入既定的减分调查渠道。
  - 归类：`nx`（功能位证据，90%）。对象端点：减分调查员职务、千飒这一搭档和地球调查路线。

### 影艳：归类统计与人物结论

- 统计：`nx`1条。
- 主十元、次十元：均暂不判定。只有一个公开可观察动作。
- 关系判断：不启动关系。
- 反证/旧结论撤回：分离后的不舍属于心理状态，出版社书目未给出影艳主动追随、拒绝拆伙或重新选择阵营的具体动作；撤回旧“前`nx`94%→后`nz`95%”迁移及`nz生nx`判断。

### 双主角与作品维度关系

- 当前人物层只有千飒`zn/nx`各1条、影艳`nx`1条，不能用人物动作支持作品命运公式`xz+nz`，更不能把作品的灭亡阈值、审判、袭击直接算到人物身上。
- 这只说明现有出版社书目不足以完成主角判断，不推翻作品命运归位，也不恢复空间主位；96分、别名、日版5卷/中文合订/OVA边界均保持待二审。
- 待复核：必须进入漫画原卷，逐页寻找千飒与影艳在拆伙、基地袭击和最终局面中各自主动做了什么；若只有内心独白，仍不得当作行为。

## 四、本批结论与写入边界

- 23条动作逐条唯一归类：北条时行9条，りんたろう11条，千飒2条，影艳1条；没有删除证据不足造成的不整齐结果。
- 稳定人物主位只暂定两项：北条时行`nx`95%，りんたろう`xn`95%；りんたろう次`nx`89%。千飒、影艳因动作太少不判主次。
- 所有旧关系判断均撤回；本批没有任何生、补、克关系达到启动标准。
- 本报告替代[[2026-07-20_主角十元行为分析_第十四批3部逃亡影像与天使]]的人物层结论。旧报告只作方法变更历史记录，不再作为当前人物索引依据。
- 未修改正式评分、最终入库结论、五大主题公式和官方理论文件。
