### 夏驰

#### 对象与十元

- **身份 / 阶段**：学生、端脑游戏参与者；从晴知失踪、收到异常来信到持续进入关卡并追索系统秘密。
- **主十元 `xn`（91%）**：主动把规则、数字/空间线索、时间限制、队友信息和前轮结果组织成可执行方案，使自己能连续过关。
- **次十元 `zx`（87%）**：方案收束后会亲自进入高风险节点、下注并执行，而非只停留在推理。
- **`zn`（84%）**：寻找晴知并追到系统真相构成长期内部方向；但需原作确认“救人”何时转成独立真相准则。
- **`x`功能端点（82%）**：游戏道具、积分/资格、关卡通行权限、队伍可调度信息；这是具体资源掌握，不是“想赢”的欲望。

#### 行为证据（5条）

1. **晴知失踪且异常线索以“地狱的来信”出现** → 夏驰沿来信、数字和空间线索继续调查并进入游戏 → 作用于失踪线索与自身行动路线 → 私人失踪案被转成可持续追踪的关卡入口。`zn + xn`
2. **“游戏开始 / 三选一”把选择压进封闭规则** → 他先拆分选项、约束条件和可验证线索，再决定下注 → 作用于关卡规则和生存概率 → 随机选择被压成有依据的行动方案。`xn`
3. **“以一敌十”“不败的路径”等关卡让对手或路径优势看似不可突破** → 他复盘已出现结果、比较对手行为并寻找规则允许的例外 → 作用于对手直接优势与关卡路径 → 对方“马上用力量/人数结束比赛”的窗口被缩小。`xn克zx`候选
4. **单人信息不足、队友同时受威胁** → 他交换线索、分配观察/执行位置并调用可用道具或资格 → 作用于队伍信息、关卡资源和时间窗口 → 多人行动被合成同一破局节奏。`xn + x`
5. **局部关卡与晴知失踪逐步指向更大的端脑系统** → 他没有在单次获胜后退出，而是继续进入升级关卡核验系统关联 → 作用于个人安全与系统真相 → 救援路线扩展成对宇宙级秘密的持续追索。`zn + zx`

> 第2—4条为跨关卡行为模式轻筛，必须回到原作话次确认动作顺序和具体道具，不能当作已完成逐格实读。

#### 行为模式总结

> 当封闭关卡把选择压到临界点时，夏驰先把规则、线索、队友和资源排成可检验方案，再在关键节点亲自执行；一个关卡的结果又成为下一轮追索晴知与系统真相的输入。

#### 关系启动与反证

- **`xn克zx`（中高候选）**：规则分析、角色分工和时序安排压缩对手直接以人数、力量或先手结束关卡的机会；目标变量是“对方直接行动成功率”，第三因素是关卡规则。
- **反证**：读规则、猜对手不等于`nx`。夏驰多数场景主动设定自己的解法与分工，不能沿用旧卡“nx=暗线推理”。但他也会被系统给定的关卡路径强制推进，因此不是稳定掌握整个游戏的主`x`。

#### 与作品主维、复核位置

- **关系**：机制相关但不等号。作品因果主来自每个选择的后续结算；人物最稳定行为是`xn`式组织，`zx`只在方案收束后承担执行。
- **待复核**：第1—6话对象建立；“以一敌十”“不败的路径”“天塌”“单挑博卞”关卡的规则拆分、分工和执行节点。
- **建议写入**：[[漫画主角十元行为分析索引]]、因果主题页人物摘要、总索引人物层状态。

### 欧迈尼斯（Eumenes）

#### 对象与十元

- **身份 / 阶段**：卡尔迪亚养子、奴隶/漂泊者、博阿村防卫组织者，后受腓力二世雇用并进入马其顿政治军事系统。
- **主十元 `xn`（96%）**：持续把地形、人力、情报、身份规则和行动时点组织成能运行的防卫、潜入或宫廷方案。
- **次十元 `n`（90%）**：接住希腊教育、身份崩塌、旅途信息和上级任务，再转成下一轮组织能力。
- **`zx`（87%）**：在初阵、潜入和阻止暗杀等关键节点亲自执行。
- **`zn`（85%）**：在“王的左腕”与欧律狄刻婚姻问题出现时选择引退，显示个人内部标准开始限制职位组织；尚不足以升为全期主位。
- **`x`功能端点**：防卫部署权、受腓力委任的任务权限、少数同行者、情报和宫廷行动接口；他并不掌握整个王国。

#### 行为证据（6条）

1. **养父遇害、出身暴露并被降为奴隶** → 欧迈尼斯没有丢掉已学的语言、历史和判断方法，而是在身份崩塌中继续观察人和制度 → 作用于希腊教养与新身份 → 被动遭遇被转成后续逃生和判断的可用输入。`n`
2. **被卖上奴隶船、行动权被夺走** → 他观察船上权力、环境和可利用的突发节点，抓住机会脱离奴役 → 作用于守卫、航行环境和自身自由 → 从被运输对象恢复为能选择路线的人。`n → xn`（具体话次待核）
3. **收留自己的博阿村遭受进攻** → 他盘点地形、村民能力和敌方进入路线，组织第一次防卫 → 作用于村庄、守军分工和敌军路径 → 小村以结构化部署获得抵抗能力。`xn克zx`
4. **返回卡尔迪亚并遇到隐去身份的腓力二世** → 他用观察和应答识别局面，随后接受雇用进入马其顿系统 → 作用于自身身份、职位与王的任务接口 → 漂泊者获得可持续的行动权限。`n + xn`
5. **奉安提帕特命令赴雅典开展工作** → 他带少数人员潜入并安排接触/情报路线 → 作用于有限人手、城市身份和政治目标 → 大规模军力被替换为低暴露的工作方案。`xn`
6. **欧律狄刻遭遇暗杀计划** → 他调查并组织阻断，使计划未能实施；此后得知她将成为腓力王妃且自己被选为“王的左腕”时决定引退 → 作用于宫廷安全、职位和私人边界 → 先完成保护任务，再让个人标准限制职位继续扩张。`xn + zx`，末段`zn克xn`候选

#### 行为模式总结

> 身份、任务或战场突然改写时，欧迈尼斯先接住新信息，再把地形、人力、规则和权限排成低成本方案；方案成立后亲自推动关键节点，若职位开始越过个人底线，则选择退出。

#### 关系启动与反证

- **`n生xn`（高）**：希腊教育、奴隶经历、上级任务与新情报被接住后，持续扩大他可组织的方案空间；目标变量是“在新环境中形成可运行路线”。
- **`xn克zx`（高候选）**：博阿村防卫与阻止暗杀通过预先部署限制攻击者直接完成目标；目标变量是敌方突击成功率，第三因素为地形/宫廷规则。
- **`zn克xn`（中候选）**：第11卷引退决定显示个人标准压缩继续担任“王的左腕”的组织路线；需核对决定是否持续、是否被后续推翻。
- **反证**：欧迈尼斯会借用腓力/安提帕特授予的权限，不能把王国资源视为他的稳定主`x`。旧二审中的“杨”不是本作主角，且“看透历史暗线”不能直接判`nx`。

#### 与作品主维、复核位置

- **关系**：高度支撑但不相等。欧迈尼斯的`xn`让因果链可被主动改写；作品因果主维还包含时代、王权和多方后果，不属于人物个人。
- **待复核**：奴隶船段；第4—5卷博阿防卫战；第9卷雅典工作；第11卷引退决定；第12卷阻止暗杀。

### 1. 雨宫一彦（Kazuhiko Amamiya）

#### 对象与十元

- **身份 / 阶段**：出狱后处于身体前台的侦探人格；与伊园犯罪研究所合作调查关联案件并追索核心人格。
- **主十元 `xn`（94%）**：把犯罪现场、死者模式、条码、旧案与组织线索编成跨案件谜题，并持续安排调查。
- **次十元 `zn`（88%）**：追问“哪个人格才是真正核心/真实声音”，为跨案调查提供内部方向。
- **`n`功能（86%）**：接住每个新案、研究所信息和其他人格显影，再纳入更大的关联模型。
- **身体`x`端点不稳定**：雨宫多数时间在前台，但共享身体会被其他人格夺取，不能写成稳定掌握。

#### 行为证据（5条）

1. **小林无法继续承受创伤/压力且人格切换** → 雨宫取得多数时间的前台身份并以新的名字行动 → 作用于共享身体、社会身份和行为责任 → 调查者人格获得暂时连续性。`x并z`表层功能，非稳定主位
2. **出狱后伊园犯罪研究所邀请协助案件** → 他加入团队并用问题解决能力参与连续凶案调查 → 作用于案件资料、研究所协作和行动路线 → 私人创伤被接到可持续调查结构上。`n生xn`
3. **东京出现女学生连续死亡** → 他与研究所人员逐一调查现场、比较死法与共同线索 → 作用于多起现场和受害者信息 → 分散案件被压成同一问题集合。`xn`
4. **新嫌疑人与自己的旧日事件发生联系** → 他把白发人物、旧案、口吃受害者和“条码谜题”并置核验 → 作用于跨年代证据与组织线索 → 单案调查扩展为可追踪的关联网络。`xn`
5. **其他人格可能在压力下夺取身体** → 他一边调查外部案件，一边试图识别、约束其他人格并寻找核心人格 → 作用于身体控制、人格边界与真实身份 → 外部罪案链和内部责任链被同时纳入追索。`xn + zn`

#### 行为模式总结

> 新罪案或人格显影出现时，雨宫先接住现场和身份信息，再把它们并入条码、旧案与组织线索的跨案模型；同时不断核验谁在使用共享身体、谁才是核心人格。

#### 关系启动与反证

- **`n生xn`（高）**：新现场、研究所资料和人格显影被接住后，直接扩大雨宫的跨案模型与后续调查路线。
- **`xn克zx`（低至中候选）**：雨宫试图用调查、人格识别和控制程序限制西园直接暴力显影；但两者的具体前后顺序、第三因素和反向解释尚未完成原卷核验，本轮不登记为已启动关系。
- **反证**：雨宫多数时间在前台不等于永久掌握身体；不能把西园的暴力、村田的行为或小林前史混入他的证据。多重人格也不是`nx`定义。

#### 与作品主维、复核位置

- **关系**：部分一致。雨宫`xn`把分散案件组织成作品因果链，但作品本体次维来自“谁是行为者/真实人格”的边界，不等于雨宫个人主`zn`已确定。
- **待复核**：第1卷出狱、加入研究所和人格切换；第2卷连续死亡、白发人物与条码谜题。

### 2. 西园伸二（Shinji Nishizono）

#### 对象与十元

- **身份 / 阶段**：与雨宫/小林共享身体的高危人格；只在明确由其处于前台的暴力节点记行为。

- **证据限制**：出版方短介只稳定支持“冷酷人格、另一人格实施暴力、压力下切换”；具体场景和责任仍需逐卷核对。
