## 1. 迷宫饭

### 分析对象

- **主角**：莱欧斯·托登（Laios Touden）
- **身份**：冒险队队长、法琳的哥哥
- **阶段**：红龙团灭后重新下潜，至迷宫深层再次规划法琳救援
- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-18_本体S级第二批4部新版生克补关系轻筛.md`
- **当前状态**：主角跨卷书目轻筛完成；作品本体/空间主次冲突继续待二审

### 主次十元

- **主十元**：`xn`，置信90%
  - 莱欧斯反复主动组织救援目标、下潜路线、补给周期、怪物信息和队伍行动，使探索能够持续。
- **次十元**：`x`，置信87%
  - 他把已经遭遇或击败的怪物身体、可食部分、生态知识和安全处理方法纳入队伍可调配的资源边界。
- **辅助十元**：`nz`，置信81%
  - 法琳是救援路线的情感停靠；队伍是否完整返回也是其持续行动的情感底线。
- **功能十元**：`zx` 76%
  - 战斗和队长决断是直接执行功能，但他并不长期追求公开凌驾或权能扩张。

### 对象端点

| 十元 | 具体对象端点 |
|---|---|
| `xn` | 法琳救援时限、下潜路线、食物补给、队伍分工、怪物生态情报、下一阶段行动方案 |
| `x` | 已击败或可处理的怪物身体、可食部位、烹饪用途、风险知识和队伍可安全使用的资源 |
| `nz` | 妹妹法琳的关系位置、队伍一起活着离开迷宫的停靠条件 |
| `zx` | 莱欧斯作为战士和队长直接处理战斗、当场决定前进方案的权能 |

### 可观察行为证据

1. **红龙击溃队伍、法琳失散且钱粮耗尽** → 莱欧斯决定尽快重新下潜，并提出“吃怪物”解决补给 → 法琳救援路线与地牢怪物 → 在缺钱缺粮条件下建立可持续行动方案。`xn + x`
2. **持续下潜面临饥饿、部分楼层缺少普通食物** → 他继续观察并学习迷宫生态，和同伴把可用怪物转成食物 → 怪物身体、生态知识和队伍补给 → 队伍适应地牢资源并继续深入。`x + xn`
3. **击败红龙并暂时救回法琳** → 他没有把“打赢”当作任务结束，而是继续要求全队安全、吃饱地返回 → 队伍生存条件与完整撤离 → 救援目标从单点胜利转为持续照料。`nz + xn`
4. **接近迷宫底层、疯法师与翼狮信息互相冲突** → 莱欧斯继续搜集关于迷宫主人、翼狮和精灵队伍的知识 → 迷宫权力结构与下一步路线 → 不用一次冲锋代替判断，保留行动连续性。`xn`
5. **到达西斯尔居所、环境混乱且法琳仍未真正脱困** → 他和队伍先清理、进食，再迅速制定下一轮救援计划 → 临时空间、体力资源和法琳救援 → 把“吃饭”纳入行动流程，而不是从主任务中脱离。`xn + x`

### 主角行为模式总结

> **救援或生存受阻时，莱欧斯会先重新组织路线、信息和补给，再把怪物身体与生态知识转成队伍可使用的资源，使整支队伍继续向法琳推进。**

### 反证与误判防线

- 他对怪物的兴趣若没有明确认可主体，不能按旧卡仅凭“好奇/执念”判 `z`。
- “吃怪物”不是欲望 `x`；只有怪物身体、食材和知识被实际掌握、调配和安全转化时才成立 `x`。
- 他会直接战斗，但整体解决方式依赖路线、补给和知识组织，`zx` 不足以上升为稳定主十元。

### 生补克机制

- **`x 生 x并z`（高）**：莱欧斯掌握怪物身体与处理知识，扩大“可以被安全做成菜”的对象范围，因而生产出可见菜肴与食谱形式。
- **`xn 克 zx`（中候选）**：初次团灭后，他用补给和路线方案限制“立即靠战斗硬闯”的直接行动范围，使队伍能持续下潜；仍需核对具体战斗篇章。
- **`zn 补 x`（中候选）**：救回法琳、理解迷宫生命的意义，可能给怪物资源掌握提供边界；反向由具体知识让该意义能够落地。作品全卷未抽读前不升为正式人物链。

### 与作品主维关系

现存作品导航仍为本体型 `zn+x` 主、空间型次，但已重开主次冲突。莱欧斯的人物主十元却更接近 `xn`：他稳定地通过计划、路线、食物和信息使队伍运行。人物结果支持作品强烈的“空间—时间运行层”，但**不自动把作品改仓**。

### 复核与写入

- **复核**：第1卷第1—7章、第5卷第29—35章、第9卷第57—62章、第10卷第63—69章。
- **建议写入**：[[漫画主角十元行为分析索引]]；作品维度冲突继续保留原队列。

## 2. Homunculus / ホムンクルス

### 分析对象

- **主角**：名越进（Nakoshi Susumu）
- **身份**：34岁、以汽车为住所的边缘者，钻孔实验对象
- **阶段**：合订本第1—10卷，从车被拖走到自我钻孔
- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、`2026-07-09_漫画分析_Homunculus.md`、`2026-07-18_本体旧口径第三批4部关系复审与源范围修正.md`
- **当前状态**：主角全套书目轻筛完成；旧关系卡继续降权；91分仍待实读二审

### 主次十元

- **主十元**：`x`，置信90%
  - 名越持续围绕车、脸、身体、感知和社会身份中“什么仍由我掌握”行动。
- **次十元**：`xz`，置信88%
  - 他长期处于无固定居所、不可逆手术、感知失稳和身份滑脱的危险边缘。
- **辅助十元**：`zn`，置信84%
  - “我是谁、我看到的究竟是谁”是他不断追问的意义端点。
- **功能十元**：`zx` 80%、`nx` 74%
  - 他会正面介入他人荷蒙库鲁斯；车被拖走后也会沿伊藤提供的金钱/手术路线推进。

### 对象端点

| 十元 | 具体对象端点 |
|---|---|
| `x` | 爱车与住所、接受手术的身体决定权、旧脸与现有外表、感知方式、社会身份和生活边界 |
| `xz` | 无家状态、钻孔风险、身体异变、他者特征转移、自我钻孔的不可逆危险 |
| `zn` | “真实的自己是谁”“所见畸形是他人还是自己”的意义判断 |
| `zx/nx` | 正面介入他人的权能；使用伊藤提供的实验、金钱与医学路线 |

### 可观察行为证据

1. **没有固定住所、白天混在无家者之间** → 名越夜晚仍回到自己的车里生活 → 爱车、住所和生活边界 → 把汽车维持为最后一个“由我掌握”的具体容器。`x + xz`
2. **医学生伊藤以金钱邀请他接受奇异手术** → 名越最初拒绝 → 自己的身体与手术许可 → 在资源诱惑前先保留身体决定权。`x`
3. **爱车被拖走、最后的住所边界被剥夺** → 他改为接受报酬并躺上手术台 → 身体、金钱与伊藤的实验路线 → 以高风险身体交换重新进入可用资源通道。`x失位 → nx/xz`
4. **钻孔后只有部分人呈现畸形、自己的左臂也出现机器人形态** → 他持续观察并追问显影规律 → 他人形象、自己的身体感知 → 把失控感知转成关于“为何看见”的调查。`xn功能 + zn`
5. **面对机器人黑道和由符号构成的女高中生** → 名越正面介入，使其畸形特征消退 → 他者荷蒙库鲁斯与自己的身体 → 他者特征反而转移到名越身上，控制尝试扩大了自身失稳。`zx + xz`
6. **他者荷蒙库鲁斯消失，只剩面孔不断变化的女人纠缠** → 名越自行实施钻孔以逼近双方真相 → 自己的头颅、感知和身份答案 → 把身体控制推到不可逆极端。`x + xz + zn`

### 主角行为模式总结

> **当车、脸、身体或感知边界失控时，名越先保护或拒绝；一旦边界被夺走，他就用更高风险的身体介入和正面对质，试图重新夺回对“自己是谁”的控制。**

### 反证与误判防线

- 名越接受伊藤提供的金钱和手术路线，说明他存在 `nx` 关系功能；不能把所有行动都写成纯粹自主 `x`。
- 住车和做危险手术只证明临界状态，不能单独判 `xz` 为主；主位来自他反复争夺车、身体、脸和身份的掌握边界。
- 旧卡把压抑欲望直接当 `x` 已失效；他者荷蒙库鲁斯只有在改变名越自身掌握边界时，才能进入人物 `x` 证据。
- 他不追求公开骑到他者之上，`zx` 只是介入行为，不升人物主位。

### 生补克机制

- **`x 生 x并z`（高）**：名越对脸、身体和身份的塑造/掌握，生产可被社会看见的外表与身份外壳。
- **`xz 克 zn`（高）**：流浪、钻孔和身体感知失稳持续压缩“我是谁”这一意义判断的稳定条件。
- **`zn 补 x`（中高）**：自我意义为“哪些脸、身体、生活仍算我的”提供判断目标；反向由具体掌握边界让抽象自我能够被检验。
- 旧卡的 `xz ↔ nz` 涉及更深童年证据，本轮官方书目不足，暂不写为已启动人物链。

### 与作品主维关系

作品本体型 `zn+x` 主导航与人物层部分一致：名越人物主位更靠具体 `x`，作品则以 `zn+x` 的互相逼问组织全作；人物强 `xz` 同时解释作品命运次维。不能把名越的身体控制行为直接等同作品全部本体问题。

### 复核与写入

- **复核**：合订本1—2卷“车被拖走—初次钻孔”；5—6卷“介入他者—特征转移”；7—8卷“旧脸”；9—10卷“自我钻孔”。
- **建议写入**：[[漫画主角十元行为分析索引]]；旧完整卡继续保留 `legacy-relation-superseded`。

## 3. 怪医黑杰克

### 分析对象

- **主角**：间黑男 / Black Jack（Hazama Kuroo）
- **身份**：无执照但技术卓越的外科医生
- **阶段**：单元剧全期；本轮抽取官方目录中的第2、12、30、38、40、56话
- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、手塚治虫官网作品页与分话目录
- **当前状态**：主角跨单元书目轻筛完成；仍需选定中文版/日文版卷次定位

### 主次十元

- **主十元**：`zn`，置信93%
  - “医生应尽力救活病人”是跨病人、费用和制度冲突仍保持的精神核心。
- **次十元**：`x`，置信89%
  - 他把诊疗判断、是否接案、收费条件、诊所、手术工具和治疗权限牢牢留在自己掌握范围。
- **功能十元**：`zx` 86%
  - 在他人放弃、畏惧或无能为力时，他直接接管手术并做成。
- **辅助十元**：`nz` 80%
  - 对皮诺可、恩师和少数病人的长期情感停靠会改变他的选择优先级。

### 对象端点

| 十元 | 具体对象端点 |
|---|---|
| `zn` | 医生身份的精神意义、救命优先、生命不可只由价格或制度决定 |
| `x` | 自己的诊疗判断、接案权、费用条件、诊所、手术工具、治疗方案与手术执行权限 |
| `zx` | 在现场直接接管手术、压过退缩者或既有治疗判断的专业权能 |
| `nz` | 皮诺可、恩师及具体患者形成的情感停靠和保护关系 |

### 可观察行为证据

1. **在海上被武装抢劫者绑架，伤员又缺乏正常医疗条件** → 黑杰克仍完成手术 → 被绑架者的伤口与船上有限资源 → 即使失去自由和设备，仍把救命执行置于身份冲突之前。`zn + zx`
2. **发现女性患者体内有足以组成一人的畸胎组织** → 他把未发育部位人工补齐并组成皮诺可 → 身体组织、人工部件和新生命 → 医术不只切除病灶，而是主动承担一个生命的诞生与后续照料。`zx + nz`
3. **皮诺可罹患白血病、唯一方案需要寻找其双胞胎姐姐** → 黑杰克四处寻找对应供血者 → 亲属关系、血液和治疗路径 → 为特定关系对象主动动员资源。`nz + xn功能`
4. **国际医学协会愿破例给他执照，但皮诺可失踪** → 他放弃约会并在城中寻找皮诺可 → 官方执照认可与皮诺可安全 → 关系停靠在该事件中优先于外部认可，证明 `z` 不是主骨。`nz + z反证`
5. **黑帮孩子严重烧伤，医院因害怕报复不敢做皮肤移植** → 黑杰克接管手术 → 患者身体、父亲皮肤和医院退缩留下的治疗空缺 → 用个人专业权能重新打开救命路线。`zx`
6. **桐子医生准备为瘫痪患者实施安乐死，家属要求救治** → 黑杰克把患者带走并手术 → 患者生命与两种医疗判断 → 明确用救命原则对抗“结束生命也是治疗”的路线。`zn + x`

### 主角行为模式总结

> **当制度、医生、家属或危险环境准备放弃一条生命时，黑杰克会把病例重新纳入自己的诊疗权限，按自己设定的条件直接手术，并用救活结果维护“医生是什么”的精神核心。**

### 反证与误判防线

- 高额收费不能直接判旧“欲望x”；现行 `x` 证据是他通过费用和接案条件维护诊疗自主权。
- 单次神奇手术是 `zx` 行为；跨话不变的是救命原则与自主诊疗边界，因此 `zx` 不升主位。
- 医疗社会否认他、执照机会也不是最终驱动；第38话甚至选择皮诺可而错过执照，反证稳定 `z` 主位。
- 他并非每个病例都无条件治疗，拒绝、定价与苛刻条件说明 `zn` 必须通过 `x` 边界运行。

### 生补克机制

- **`zn 补 x`（高）**：救命原则给接案权、费用和手术自主设定意义边界；自主诊疗权又补足无执照状态下让原则落地的执行条件。
- **`zx 生 zn`（高）**：一次次在无人能救或无人敢救时完成手术，使“我是医生/医生要救命”的精神核心获得现实成立条件。
- **`x 克 z`（中高）**：掌握诊疗路线和诊所资源，使医学协会是否认可他不再是行动前提；第38话错过执照是明确反证点。

### 与作品主维关系

人物 `zn+x` 与作品本体型主维高度一致。作品的因果次维来自大量“病情—手术—结果”单元结构，人物层则表现为 `zx` 执行功能；不能因为每话都有医疗因果就把黑杰克判为因果型人物。

## 4. 恶魔人

### 分析对象

- **主角**：不动明（Fudo Akira）
- **身份**：保有人类心灵、掌握恶魔身体与力量的 Devilman
- **阶段**：Classic Collection 第1—2册，从获得恶魔力量到末日战争
- **来源文件**：[[01-本体型 zn+x]]、[[漫画库总索引]]、Seven Seas 两册官方简介
- **当前状态**：主角官方书目预筛完成；**待原卷章节验证**

### 主次十元

- **主十元**：`zn`，置信91%
  - 身体成为恶魔后仍保有人类心灵，并持续用这一意义决定力量方向。
- **次十元**：`zx`，置信87%
  - 他以恶魔权能直接对抗恶魔，并在战争升级后扩大为集体战斗力量。
- **功能十元**：`x` 84%、`nx` 74%
  - `x` 是恶魔身体与力量仍由不动明掌握；`nx` 是末期必须借助盟友和既有同盟路线。
- **辅助十元**：`xz` 79%
  - 人魔融合、社会渗透、背叛和末日战争构成持续临界压力。

### 对象端点

| 十元 | 具体对象端点 |
|---|---|
| `zn` | “即使拥有恶魔身体仍保有人心”的身份意义、保护人类的价值方向 |
| `zx` | Devilman 的身体强度、战斗能力及其对恶魔敌人的公开压制 |
| `x` | 被不动明而非恶魔意志掌握的身体、力量和行动方向 |
| `nx/xz` | 盟友提供的集体战斗通道；恶魔渗透、背叛与末日战争的危险轨道 |

### 可观察行为证据

1. **恶魔开始夺取人类宿主、普通人无法对抗** → 不动明取得并承受恶魔力量 → 自己的身体、恶魔力量与人类身份 → 成为能以恶魔之力反击恶魔的 Devilman。`x + xz`
2. **强大身体可能反向吞没人格** → 他持续保有人类心灵，并让力量服从人类方向 → 恶魔身体与行动目的 → 没有把“拥有力量”变成“接受恶魔支配”。`zn 补 x`
3. **恶魔直接威胁人类** → 他公开使用 Devilman 权能战斗 → 恶魔敌人与现实战场 → 把内在人心转成能改变战局的直接力量。`zx 生 zn`
4. **恶魔渗透社会并准备发动末日战争** → 不动明不再只靠个人战斗，而进入寻找、联合强力盟友的路线 → 其他 Devilman 与集体战力 → 个人权能转入关系网络。`nx功能`
5. **可信关系出现背叛、战争目标扩大为支配全人类** → 他仍站在反对恶魔统治的一侧继续作战 → 人类/Devilman阵营与末日战场 → 外部临界不断侵蚀人性意义，但未立刻把方向交给恶魔。`xz 克 zn`下的`zx`

### 主角行为模式总结

> **当恶魔力量或末日局势试图决定“他是什么”时，不动明把恶魔身体重新纳入自己掌握，并以人类心灵规定力量方向，再用直接战斗和盟友路线反击恶魔支配。**

### 反证与误判防线

- 有强大战斗力不自动判 `zx` 主位；主位来自他为何使用力量——维持人类心灵，而非追求凌驾。
- `x` 不是“想要力量”，而是恶魔身体和力量实际上仍由不动明掌握、调动。
- 官方简介只能证明大段结构，不能精确证明每次联盟、背叛后的具体选择；本轮不得升为深析完成。
- 他不是为了获得公众承认而战，缺少稳定认可主体，`z` 不进入主次位。

### 生补克机制

- **`zn 补 x`（高）**：人类心灵为恶魔身体的掌握提供目的和限制；受控的恶魔力量又让保护人类这一意义具备行动能力。
- **`zx 生 zn`（高候选）**：反复以恶魔权能保护人类，使“有恶魔身体但仍是人”的意义获得现实成立条件；需原卷定位。
- **`xz 克 zn`（中高）**：社会渗透、背叛和末日战争持续破坏人性意义成立的外部条件。

### 与作品主维关系

人物 `zn` 主、`x/zx` 次功能与作品本体型 `zn+x` 主导航高度一致；作品命运次维对应末日和背叛压力，人物则以 `zx` 抵抗。人物匹配作品主题，但仍不能把作品五大主题直接当人物判定过程。

### 复核与写入

- **复核**：Classic Collection 第1册“获得力量—保持人心—首次对抗恶魔”，第2册“寻找盟友—背叛—末日战争”。
- **建议写入**：[[漫画主角十元行为分析索引]]，状态保持“官方书目预筛·待原卷章节验证”。
