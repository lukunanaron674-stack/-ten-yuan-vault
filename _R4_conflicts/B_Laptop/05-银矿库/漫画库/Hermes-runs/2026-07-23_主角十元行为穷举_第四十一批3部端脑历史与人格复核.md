# 主角十元行为穷举 · 第四十一批3部端脑历史与人格复核

## 本轮边界

- 第四十批后没有人工新增漫画，本轮修复旧第八批《端脑》《历史之眼》《MPD Psycho》的多标签和混合动作。
- 覆盖：旧报告保存的行为证据；《端脑》正版页第1—6话及公开列名关卡；《历史之眼》讲谈社作品页、第4—5卷防卫战与第12卷；《MPD Psycho》第1—2卷书目。不是三部全作逐页穷举。
- 《MPD Psycho》按人格对象分开：雨宫一彦与西园伸二分别计票；共享身体不是第三名混合主角，小林洋介承担的法律后果不倒算为西园以外人格的动作。
- 判读字段：行为完成后再给主十元、次十元、关系候选、与作品主维关系；一条行为只归一个十元。

## 一、《端脑》｜夏驰

- 身份与阶段：学生、端脑游戏参与者；晴知失踪至追查端脑系统真相。
- 当前状态：正版平台确认全244话和开篇第1—6话；中后段为旧报告保存的跨关卡证据，仍待原作话次。

- 行为1：晴知失踪且“地狱的来信”出现 → 夏驰沿来信、数字和空间线索调查并进入真人游戏 → 作用对象为失踪线索与行动路线 → 私人失踪案形成可继续追查的关卡入口。【DN-1】
  - 归类：`xn`（主位证据，95%）。对象端点：来信、数字/空间线索、调查顺序与游戏入口。
- 行为2：“三选一”把选择压进封闭规则 → 夏驰拆分选项、约束和可验证线索后再下注 → 作用对象为关卡规则与选择结果 → 随机选择被压成有依据的行动方案。【DN-2】
  - 归类：`xn`（主位证据，94%）。对象端点：选项、约束条件、验证步骤和下注时点。
- 行为3：“以一敌十”“不败的路径”等关卡形成明显对手优势 → 夏驰复盘已有结果、比较对手行为并寻找规则例外 → 作用对象为人数/路径优势与规则缺口 → 对手直接结束比赛的窗口被缩小。【DN-3】
  - 归类：`xn`（主位证据，93%）。对象端点：历史结果、对手行为、规则例外和行动窗口。
- 行为4：单人信息不足且队友同时受威胁 → 夏驰交换线索、分配观察与执行位置并调用可用道具 → 作用对象为队友、信息、道具和时间窗 → 多人行动进入同一破局节奏。【DN-4】
  - 归类：`xn`（主位证据，92%）。对象端点：队友分工、可用道具、线索和执行次序。
- 行为5：局部关卡逐渐指向更大的端脑系统 → 夏驰没有在一次获胜后退出，而是继续进入升级关卡核验关联 → 作用对象为个人安全、晴知线索和系统秘密 → 救援路线持续延伸到系统真相。【DN-5】
  - 归类：`zn`（功能位证据，92%）。对象端点：寻找晴知/核验真相的内部方向与继续承担风险的选择。

### 统计后判断

- 唯一归类统计：`xn`4 / `zn`1。主十元`xn`95%候选；次十元不判，旧次`zx`及`zn`稳定次位撤回。
- 关系候选：`xn克zx`92%。第3条的复盘和规则例外压低对手直接以人数或先手结算的成功率；关卡规则是第三因素，故仅候选。
- 与作品主维关系：夏驰`xn`负责在单个关卡内组织方案，作品因果主维还包括系统设定、选择结算和跨关卡后果，二者不等号。
- 复核：第1—6话；“以一敌十”“不败的路径”“天塌”“单挑博卞”的具体话次、分工及道具。

## 二、《历史之眼 / Historie》｜欧迈尼斯

- 身份与阶段：卡尔迪亚养子、奴隶/漂泊者、博阿村防卫组织者及马其顿受雇者。
- 当前状态：讲谈社明确主角生平起点、博阿村防卫战和第12卷阻止暗杀；奴隶船、雅典与引退细节待原卷。

- 行为1：养父遇害、出身暴露并被降为奴隶 → 欧迈尼斯保留已学语言、历史和判断方法并继续观察制度 → 作用对象为希腊教养与新身份环境 → 被动遭遇被保存为后续判断输入。【HS-1】
  - 归类：`n`（功能位证据，93%）。对象端点：已学知识、制度信息及其承接责任。
- 行为2：被卖上奴隶船且行动权被夺走 → 欧迈尼斯观察船上权力和环境，抓住突发节点逃离 → 作用对象为守卫、航行环境和自身路线 → 从被运输对象恢复为能选择路线的人。【HS-2】
  - 归类：`xn`（主位证据，93%）。对象端点：守卫位置、环境节点、逃离时机与路线。
- 行为3：收留自己的博阿村遭受进攻 → 欧迈尼斯盘点地形、村民能力和敌军入口并组织防卫 → 作用对象为村庄、守军分工和敌军路径 → 小村获得结构化抵抗能力。【HS-3】
  - 归类：`xn`（主位证据，97%）。对象端点：地形、村民、守军位置和敌军路线。
- 行为4：返回卡尔迪亚并遇到隐去身份的腓力二世 → 欧迈尼斯识别局面后接受雇用 → 作用对象为职位、王的任务接口和自身路线 → 漂泊者进入马其顿行动体系。【HS-4】
  - 归类：`nx`（功能位证据，92%）。对象端点：腓力提供的职位、任务方向与外部系统入口。
- 行为5：奉命赴雅典工作且只能携少数人员 → 欧迈尼斯安排潜入、接触和情报路线 → 作用对象为有限人手、城市身份和政治目标 → 大规模军力被替换为低暴露方案。【HS-5】
  - 归类：`xn`（主位证据，95%）。对象端点：同行者、潜入身份、接触顺序和情报路线。
- 行为6：欧律狄刻遭遇暗杀计划 → 欧迈尼斯调查并组织阻断 → 作用对象为暗杀链、宫廷安全和执行者 → 杀害计划未能实施。【HS-6】
  - 归类：`xn`（主位证据，98%）。对象端点：暗杀信息、阻断步骤、宫廷人员与行动时点。
- 行为7：得知欧律狄刻将成为腓力王妃且自己被选为“王的左腕” → 欧迈尼斯决定引退 → 作用对象为职位扩张、私人关系和个人边界 → 完成保护后不继续沿权位路线前进。【HS-7】
  - 归类：`zn`（功能位证据，94%）。对象端点：个人边界、王的职位与是否继续任职。

### 统计后判断

- 唯一归类统计：`xn`4 / `n`1 / `nx`1 / `zn`1。主十元`xn`96%；次十元不判，旧次`n`撤回为功能位。
- 关系候选：`n生xn`93%，承接的教育和制度信息扩大可组织方案的范围；`xn克zx`95%，博阿防卫与暗杀阻断降低攻击者直接完成目标的概率。两者仍待原卷时序核验。
- 与作品主维关系：人物`xn`高度推动因果链，但时代、王权与其他人物造成的历史后果属于作品层，不能倒算给欧迈尼斯。
- 复核：奴隶船；第4—5卷博阿防卫；第9卷雅典；第11卷引退；第12卷阻止暗杀。

## 三、《MPD Psycho》｜雨宫一彦

- 身份与阶段：共享身体中多数时间处于前台的侦探人格；出狱后与伊园犯罪研究所合作至条码谜题。
- 当前状态：第1—2卷公开资料范围穷举，非全作穷举。

- 行为1：创伤和压力导致人格切换 → 雨宫取得前台并以“雨宫一彦”身份行动 → 作用对象为共享身体、社会身份和行为接口 → 调查者人格获得暂时连续性。【MP-A1】
  - 归类：`x并z`（功能位证据，91%）。对象端点：前台身体权限、公开姓名和社会可读身份；不是永久掌握。
- 行为2：出狱后伊园犯罪研究所邀请协助案件 → 雨宫加入团队并接受调查路线 → 作用对象为研究所、案件资料和工作方向 → 私人创伤被接入外部犯罪调查系统。【MP-A2】
  - 归类：`nx`（功能位证据，92%）。对象端点：研究所提供的职位、案件和外部方向。
- 行为3：东京发生女学生连续死亡 → 雨宫与研究所人员逐一调查现场、比较死法与共同线索 → 作用对象为多个现场和受害者资料 → 分散案件形成同一问题集合。【MP-A3】
  - 归类：`xn`（主位证据，96%）。对象端点：现场序列、死法、受害者信息和比较步骤。
- 行为4：新嫌疑人与旧日事件发生联系 → 雨宫把白发人物、旧案、口吃受害者和条码理论并置核验 → 作用对象为跨年代证据与组织线索 → 单案扩展为可追踪的关联网络。【MP-A4】
  - 归类：`xn`（主位证据，97%）。对象端点：白发人物、旧案、受害者、条码及关联顺序。
- 行为5：其他人格可能在压力下夺取身体 → 雨宫在调查外部案件的同时识别并限制其他人格 → 作用对象为人格边界、身体前台和案件责任 → 外部罪案链与内部责任链进入同一调查框架。【MP-A5】
  - 归类：`xn`（主位证据，94%）。对象端点：人格名单、切换迹象、前台权限和责任追踪。

### 统计后判断

- 唯一归类统计：`xn`3 / `x并z`1 / `nx`1。主十元`xn`96%；次十元不判，旧次`zn`撤回。
- 关系候选：不登记。调查结构可能限制西园暴力，但公开材料不足以排除人格切换机制和外部刺激等第三因素。
- 与作品主维关系：雨宫的`xn`把分散案件组织成因果网络；作品本体次维来自“谁是行动者”的整体问题，不是雨宫个人`zn`。
- 复核：第1卷出狱、加入研究所与切换；第2卷连续死亡、白发人物及条码谜题。

## 四、《MPD Psycho》｜西园伸二

- 身份与阶段：共享身体中的高危人格；仅取第1卷前史和出版社明确的高压显影范围。
- 当前状态：公开资料范围仅3条，明确“非全作穷举”；不以“冷酷”性格词替代动作。

- 行为1：小林遭遇女友被连环杀手残害、心理承载崩溃 → 西园显影并取得身体行动权 → 作用对象为共享身体和现场接口 → 原警探身份连续性中断。【MP-S1】
  - 归类：`x`（主位候选证据，86%）。对象端点：共享身体的前台控制和即时行动权限；仅为阶段占用。
- 行为2：直接面对造成创伤的目标 → 西园以暴力处置目标 → 作用对象为目标身体和现场威胁 → 目标被直接清除，而小林随后承担法律后果。【MP-S2】
  - 归类：`zx`（功能位证据，88%）。对象端点：目标身体、暴力实施与可观察伤害结果。
- 行为3：后续压力使雨宫无法稳定维持前台 → 西园再次夺取身体和行动权限 → 作用对象为雨宫前台身份与外部目标接口 → 调查者的连续控制被中断。【MP-S3】
  - 归类：`x`（主位候选证据，84%）。对象端点：身体前台、切换时点和行动权限。

### 统计后判断

- 唯一归类统计：`x`2 / `zx`1。主十元`x`85%低置信候选；次十元不判，`zx`仅为单点高强度功能。旧主`zx`、次`x`顺序撤回。
- 关系候选：不登记。身体控制与公开身份显影可能存在`x克z`，但缺逐卷前后机制，不能正式启动。
- 与作品主维关系：西园制造责任错位，但作品因果来自多个人格、案件与组织共同结算；不能把共享身体内所有暴力都算给他。
- 复核：第1卷创伤触发、实际暴力实施者和法律责任；后续明确报出西园身份并夺取前台的卷次。
