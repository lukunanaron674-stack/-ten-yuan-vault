# 主角十元行为穷举 · 第三十四批3部孔洞恶魔与Punpun复核

## 本轮边界

- 扫描对象：名越进、不动明、Punpun；不把作品主题、环境状态、配角动作或概括性评价借给主角。
- 固定顺序：先列公开剧情中可观察的具体动作，再在下一行给出唯一十元归类；不先定十元，不把多条动作压成行为总结。
- 覆盖范围：Seven Seas《Homunculus》合订本1—10卷；讲谈社《新装版 デビルマン》第1—4卷、Seven Seas Classic Collection第1—2册及可靠书目总述；VIZ《Goodnight Punpun》第1—7卷公开页。
- 本报告只穷举上述公开资料明确写出的动作，不是全作逐页穷举。《恶魔人》书目最粗，仅有3条可保留动作；《晚安Punpun》第7卷没有公开具体动作，未强行补写。
- 一条行为只归一个十元；同一动作不重复证明其他十元。不能归类的动作保留，统计完成后才判断主次。

## 一、《Homunculus / ホムンクルス》｜名越进

- 身份与阶段：三十四岁、以车为居所的实验受试者；从术前生活到最终自行钻孔。
- 来源范围：Seven Seas五册合订本公开简介，覆盖原作1—10卷；不是原页逐格实读。
- 当前状态：公开范围8条具体行为完成；旧主`x`次`xz`改为主`xz`候选、次`x`，`n`保留功能位。

- 行为1：没有固定住所 → 白天与无家者相处、夜间持续睡在自己的车里 → 车辆与最低居住边界 → 把车辆实际用作仍由自己支配的生活容器。【HM-12】
  - 归类：x（次位证据，93%）。对象端点：名越实际占用和支配的车辆、夜间居住边界；“无家可归”状态本身不计证据。

- 行为2：伊藤以现金邀请他接受头部钻孔实验 → 明确拒绝该提议 → 自己的身体处置权与伊藤的实验权限 → 首轮交易没有获得进入他身体的许可。【HM-12】
  - 归类：x（次位证据，96%）。对象端点：自己身体的处置权限；拒绝只证明边界，不把现金欲望写成x。

- 行为3：赖以居住的车被拖走 → 改变决定、接受报酬并躺上手术台 → 头部钻孔、身体安全与现金交易 → 让外部实验真正进入身体，承担不可逆医疗风险。【HM-12】
  - 归类：xz（主位证据，97%）。风险端点：钻孔手术、身体损伤与未知感知后果；这次同意不重复归入`nx`或`x`。

- 行为4：看见“机器人”形态的黑道成员 → 正面介入该对象 → 对方的怪异特征与名越自身 → 对方失去怪异特征，但相应属性转移到名越身上。【HM-56】
  - 归类：n（功能位证据，92%）。承接端点：该人的怪异特征及其处理结果；简介没有公开显权方式，故不判`zx`。

- 行为5：看见由符号构成的女高中生 → 正面介入该对象 → 女生的怪异特征与名越自身 → 对方恢复，相关属性同样转移到名越身上。【HM-56】
  - 归类：n（功能位证据，92%）。承接端点：第二个独立对象的怪异特征；与行为4分属不同对象，但都不重复判为`zx`。

- 行为6：处理他人怪异特征后想接近自身与新现实的真相 → 转而正面面对最初启动实验的伊藤之荷蒙库鲁斯 → 伊藤、实验来源与自我真相 → 把追查从陌生对象推进到实验关系核心。【HM-56】
  - 归类：zn（功能位证据，91%）。意义端点：名越对“自己是谁、眼前现实为何如此”的内部解释；只作单点功能，不据此锁主位。

- 行为7：继续追查自己是谁 → 把调查起点放在自己过去的脸上 → 旧面孔、双方谎言与身份线索 → 名越与伊藤之间的谎言开始逐项显露。【HM-78】
  - 归类：xn（功能位证据，88%）。结构端点：以旧脸作为调查入口并逐项揭露谎言；书目没有公开更细步骤，因此置信低于其他动作。

- 行为8：其他荷蒙库鲁斯消失、只剩不断换脸的女人纠缠 → 为查明自己和她的真相，亲手对自己实施头部钻孔 → 自己的头部、生命安全与最后答案 → 主动进入可能无法存活的不可逆程序。【HM-910】
  - 归类：xz（主位证据，99%）。风险端点：自我手术、生命与退路；“寻找真相”是动机，不把同一动作再归`zn`。

### 归类统计与主次

- 8条：xz 2、x 2、n 2、zn 1、xn 1。
- 主十元候选：xz 96%。首次接受他人钻孔与终局自行钻孔跨越前后期，均把身体推入不可逆风险；比同属开篇的两条x边界动作更具跨阶段重复。
- 次十元候选：x 92%。车的居住边界与身体许可边界是两个具体端点，但集中在开篇；暂不高于跨期xz。
- 功能位：n 91%；zn、xn均为单点，不锁位。
- 旧结论处理：撤回“主x90%、次xz88%、zn辅助”的先验排序；不再把脸、感知或身份失控状态本身当成x行为。

### 关系、反证与作品主维

- 关系候选：`xz克zn` 90%。行为3的钻孔风险随后造成感知扭曲与自身手臂异化，使“我是谁、现实为何如此”的解释稳定性被持续破坏；这是风险结果侵蚀自我意义的候选链，仍需原卷确认因果桥。
- 反证：行为1—2显示名越会守住具体掌握边界；行为4—5显示他也会承接并处理他人的怪异特征。因此人物不是“纯xz”，x与n均不能删除。
- 与作品主维：库内作品仍登记本体主、命运次。人物xz主候选只支持命运压力的一端；zn仅一条功能动作，不能由人物层反推作品本体公式成立或失效。
- 原卷复核：1—2卷车/拒绝/初次钻孔；5—6卷两次介入与伊藤对质；7—8卷旧脸调查；9—10卷自我钻孔及其结果。

## 二、《恶魔人 / Devilman》｜不动明

- 身份与阶段：由心软少年成为保有人心的Devilman；从知晓恶魔入侵到末日战争阶段。
- 来源范围：讲谈社《新装版》1—4卷、Seven Seas Classic Collection 1—2册与可靠书目总述；官方简介大多只写危机，不是全作行为清单。
- 当前状态：公开范围仅3条可保留动作；不足以锁定主次，旧主`zn`、次`zx`撤回为待原卷假设。

- 行为1：得知恶魔族苏醒并准备夺回地球 → 与飞鸟了尝试让自己同恶魔合体以获得反制能力 → 自己的身体、意识与恶魔融合 → 实际成为同时具有恶魔身体和人类心灵的Devilman。【DV-1】
  - 归类：xz（高强度单点，96%）。风险端点：身体和意识可能被恶魔吞没、融合失败与死亡；获得力量的结果不让同一动作重复归`x`。

- 行为2：恶魔侵入人类社会并夺取宿主 → 运用已获得的恶魔力量反击恶魔 → 恶魔敌人与Devilman身体能力 → 把内在力量落实为现实战斗手段。【DV-SS1】
  - 归类：zx（高强度单点，94%）。权能端点：不动明公开使用的Devilman力量及其对恶魔的反制；简介没有逐战结果，置信不升至锁位级。

- 行为3：蜘蛛恶魔袭击美树与学校学生、并控制人类意识 → 不动明以Devilman身份进入对抗 → 被控制者、蜘蛛恶魔与学校现场 → 官方简介只提出“如何战斗”的问题，没有公开他的具体战法或结果。【DV-3】
  - 归类：暂不归类（证据不足）。普通“进入战斗”不自动等于`zx`；也不能把美树受袭或人类被控制算成不动明的行为。

### 归类统计与主次

- 3条：xz 1、zx 1、暂不归类1。
- 主十元：暂不锁定。两条高质量动作各落在不同十元，公开书目没有第二个独立同向行为。
- 次十元：暂不锁定。
- 旧结论处理：撤回主`zn`91%、次`zx`87%、`x/nx/xz`功能。保有人心是人物状态与价值前提，不是单独可观察动作；“需要盟友”“可能遭背叛”也不是已经发生的主角动作。

### 关系、反证与作品主维

- 关系候选：`xz生zx` 94%。行为1先通过高风险融合取得Devilman身体，行为2随后把该身体能力外化为反击恶魔的行动；这是同一能力链中前后分开的两个动作。仍需原卷确认主动融合过程和首次战斗桥。
- 反证：保有人心限制恶魔力量方向，但当前没有独立的价值选择动作可判`zn`；行为3又缺具体战法和结果，不能仅凭题材把`zx`升为主位。
- 与作品主维：库内作品登记本体主、命运次、因果辅。人物当前只能确认一条xz和一条zx，既不能证明人物主`zn`，也不能代替作品本体公式。
- 原卷复核：新装版第1卷融合过程、第2卷西琳封锁变身时不动明的主动动作、第3卷蜘蛛恶魔战、第4卷盟友组织与终局选择。

## 三、《晚安Punpun / Goodnight Punpun》｜Punpun

- 身份与阶段：从家庭崩裂中的儿童成长为独居青年；覆盖童年、高中、独居、期限与爱子重逢阶段。
- 来源范围：VIZ系列页与第1—7卷公开简介；第7卷只写“终点”，没有可提取具体动作。
- 当前状态：公开范围6条具体行为完成；旧主`z`改为主`nx`候选，次位暂不锁定，别名评分继续隔离。

- 行为1：父亲入狱、母亲住院并改由叔叔照料 → 尝试向“神”谈论自己的问题 → “神”的回应位置与家庭困境 → 形成求取外部回应的行动，但问题没有因此被解决。【PP-S】
  - 归类：z（功能位证据，93%）。认可端点：被Punpun当作回应者的“神”及其对问题的回应；不把抽象希望本身计为行为。

- 行为2：升入当地最好的高中后不愿面对生活 → 持续把注意力投入学习 → 学校课程、成绩路径与既有升学秩序 → 用现成学生路线占满注意力并维持日常推进。【PP-3】
  - 归类：nx（主位证据，95%）。路径端点：学校已经给出的课程、好学生位置与升学秩序；学习并非他自建的新结构。

- 行为3：母亲死亡、父亲无法依靠且开始独居 → 持续做低质量兼职 → 现有劳务岗位与最低生活路线 → 依靠社会既有工作接口维持独居生活。【PP-4】
  - 归类：nx（主位证据，92%）。路径端点：外部提供的兼职岗位和最低生活秩序；简介未公开收入资源的掌握结果，故不判`x`。

- 行为4：兼职之外没有明确去处 → 长时间躺在自己房间的地板上 → 房间与空余时间 → 形成可观察的停滞日常，但没有明确对象端点或阶段结果。【PP-4】
  - 归类：暂不归类（证据不足）。停滞不是自动的`xz`、`nz`或`n`；没有临界风险、关系停靠或承接结果。

- 行为5：租期将结束、生活仍未改变 → 给自己设下严格期限，要求租约到期前与爱子在一起、改善生活并“成为某个人” → 租约时间、爱子关系与行动截止点 → 把模糊愿望改成有截止日的自我约束。【PP-5】
  - 归类：xn（功能位证据，98%）。结构端点：租约截止时间、关系目标与失败条件；只归组织动作，不把爱子同时归`z`或`x`。

- 行为6：期限阶段之后 → 与爱子重新相聚 → 爱子关系与两人后续处境 → 官方简介确认重逢结果，却未公开由谁寻找、提出或组织重逢。【PP-6】
  - 归类：暂不归类（证据不足）。结果落在两人之间，Punpun的个人动作和贡献比例未公开，不能硬判`nz`、`z`或`x`。

### 归类统计与主次

- 6条：nx 2、z 1、xn 1、暂不归类2。
- 主十元候选：nx 93%。高中学习与成年兼职分属不同阶段、不同制度接口，却都沿既有秩序维持生活；这是当前唯一跨阶段重复。
- 次十元：暂不锁定。z和xn各一条；关系占有、共同逃亡或第6卷“可怕事件”的具体动作均未由官方简介公开。
- 旧结论处理：撤回主`z`90%、次`nx`87%以及`xz/x`阶段功能。童年的多个愿望不是行动；“两人做了可怕的事”没有拆开Punpun个人动作，不计。

### 关系、反证与作品主维

- 生补克：不登记。行为1的求回应与行为2的学习之间没有公开因果桥，不能用跨卷相邻性宣称`z克nx`；行为5也没有被证明由nx直接生出。
- 反证：行为5显示Punpun并非始终被动沿路线走，他能主动设置期限；行为1又显示认可回应曾直接启动行动，因此nx不是唯一功能。
- 与作品主维：库内作品仍登记本体主、命运次、时间辅。人物nx主候选是其日常运行方式，不等于作品本体或命运公式；单条xn只能旁证时间组织节点。
- 原卷复核：第1卷“神”对话动作、第3卷学习节律、第4卷兼职与房间停滞、第5卷期限执行、第6卷重逢主体与共同事件、第7卷终局主动动作。
