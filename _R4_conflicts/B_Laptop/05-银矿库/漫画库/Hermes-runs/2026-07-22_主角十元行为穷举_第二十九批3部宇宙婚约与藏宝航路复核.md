# 2026-07-22 主角十元行为穷举：第二十九批3部宇宙婚约与藏宝航路复核

## 本轮口径与覆盖范围

- 本轮复核《呪術廻戦≡（モジュロ） / Jujutsu Kaisen Modulo》《超深宇宙より愛をこめて / 超深宇宙之恋》《新寳島 / 新宝岛》3部作品、4位人物对象，共保留12条可观察行为。
- 固定顺序是先从官方公开剧情文字提取行为，再逐条归入一个十元；不能归类的行为原样保留，不用主题公式补答案。
- 本轮全部属于“官方公开资料范围穷举”，不是全作或全卷穷举。《呪術廻戦≡》覆盖第1、3卷梗概；《超深宇宙》覆盖作品页与第2卷书目；《新寳島》覆盖手塚官网剧情、人物与版本说明。
- 《呪術廻戦≡》的乙骨忧花仍缺足量独立主动行为；《超深宇宙》的Lulu公开资料只有2条可核主动动作；不借他人行为补数。
- 96/91/90分、作品主维和最终归仓均不改。

## 一、《呪術廻戦≡（モジュロ）》 / Jujutsu Kaisen Modulo

**对象**：乙骨真剑；日本咒术师、乙骨忧花之兄。

**阶段与来源**：第1卷京都诱拐调查、第3卷营救忧花；集英社作品页及第1、3卷官方梗概。共3条，非全作穷举。

- 行为1：外星难民要求特使同行咒术师任务，京都又发生诱拐案 → 真剑与忧花在监察者Maru陪同下进入调查 → 失踪儿童、协同任务与监察路线 → 兄妹沿外部给定的案件通道开始办案。
  - 归类：`nx`（功能位证据，95%）。对象端点：咒术师任务、Maru监察关系、京都诱拐调查路线；方向和通道由案件与既有职责给出。
- 行为2：大规模战局令忧花进入必须立即救援的处境 → 真剑尝试救出忧花 → 忧花及当下救援窗口 → 手足危机不再只是背景，而被他亲自接下处理。
  - 归类：`n`（功能位证据，93%）。对象端点：落到真剑身上的妹妹危机与救援责任。
- 行为3：Maru阻断真剑继续救援忧花的路线 → 真剑与Maru交刃 → Maru、救援通道与迫近危险 → 他以当场战斗争取穿过阻断、继续救人。
  - 归类：`xz`（功能位证据，92%）。对象端点：已经显现的阻断者、被压缩的救援窗口及必须行动的危险路径。

**归类统计**：`nx`1、`n`1、`xz`1。三类各1条且只覆盖两个梗概节点，主十元、次十元均暂不判；旧“主`zx`91%·次`n`88%”撤回。

**反证**：单次交刃只能证明真剑进入危险路径，不能单凭“战斗”证明权能向外扩张并支配环境。

**关系候选**：不宣布。三条行为分别受咒术师职责、手足关系和战局压力驱动，现有公开文字不足以完成第三因素排除。

**与作品主维关系**：人物执行层没有形成稳定`zn+x`，也没有稳定`zx+nx`；这不推翻作品本体主候选，只说明公开人物证据暂时不能支撑旧主十元。

**复核位置**：第1卷第1—7话、第3卷第17—25话原页；乙骨忧花另立行为清单。

## 二、《超深宇宙より愛をこめて》 / 超深宇宙之恋

**对象与阶段**：寺馆天、Lulu；天的孤立校园生活至第2卷文化祭临近。

**来源**：一迅社作品页与第2卷官方书目。寺馆天4条、Lulu 2条；均为公开资料范围穷举，非第1—2卷全卷穷举。

### 寺馆天

- 行为1：中学经历留下创伤 → 天主动与人保持距离，独自度过学校生活 → 同学关系与日常接触面 → 她缩小了与他人的现实往来。
  - 归类：暂不归类（证据不足）。官方简介只确认她主动缩小往来，没有交代当前触发与后续作用机制。
- 行为2：Lulu来到她的生活现场并提出婚约 → 天决定成为Lulu的未婚伴侣 → Lulu、婚约与后续共同生活 → 原先封闭的单人日常转成双方确认的持续关系。
  - 归类：`nz`（主位证据，94%）。对象端点：天与Lulu之间已经确认的婚约关系及持续相处时间。
- 行为3：两人的星球与生活差异令天惊讶 → 天仍继续与Lulu相处 → Lulu及双方文化差异 → 关系没有因差异中断，双方逐渐更在意彼此。
  - 归类：`nz`（主位证据，89%）。对象端点：没有因差异中断的相处关系；该条待原卷核对具体动作和页码。
- 行为4：与Lulu的相处改变原先封闭的校园节奏 → 天逐渐开始与同学发生交流 → 同学及班级关系通道 → 她从独处状态重新进入多人校园关系。
  - 归类：`nx`（功能位证据，86%）。对象端点：由Lulu关系与现有班级环境打开的社交通道；官方文字未说明天自行组织社交计划。

**归类统计**：`nz`2、`nx`1、暂不归类1。寺馆天暂定主`nz`92%；次十元不判，`nx`仅记功能位86%。

**关系候选**：`nz生nx`候选86%。Lulu提供可停靠的关系位置后，天不必先自创社交方向，得以沿校园关系继续进入同学交流；但文化祭与同学主动程度尚未排除，故不锁正式关系。

### Lulu

- 行为1：她原本位于遥远异星 → Lulu来到天的生活现场 → 星际距离、天与相遇地点 → 遥远的两人进入可以当面互动的范围。
  - 归类：暂不归类（证据不足）。官方简介没有交代出发机制、途中选择和抵达后的独立结果。
- 行为2：Lulu见到长期与人疏离的天 → 她当面告诉天，自己要成为天的新娘 → 天及双方关系位置 → 明确的长期关系提案进入天的校园生活，并推动后续婚约。
  - 归类：`nz`（功能位证据，92%）。对象端点：Lulu主动提出与天持续相处的伴侣关系。

**归类统计**：`nz`1、暂不归类1。公开资料只有2条主动动作，低于主次判定阈值；Lulu主十元、次十元均暂不判，旧“主`nz`92%·次`zx`88%”撤回。

**反证**：提出婚约只证明关系停留意向，不证明Lulu掌握天或使用王女权限控制关系。

**关系候选**：不宣布。一次抵达和一次求婚不足以证明任一生、补、克链。

**与作品主维关系**：寺馆天的`nz`支持命运型关系停靠端，Lulu只提供一条`nz`功能证据；两人都没有在公开范围形成稳定`xz`，更没有人物`zn+x`。人物结果只触发作品本体/命运主次二审，不改91分或归仓。

**复核位置**：第1—2卷逐页核对Lulu出发、抵达、求婚、文化差异与文化祭节点；补足Lulu至少3条独立主动行为后再判主次。

## 三、《新寳島》 / 新宝岛

**对象**：Pete；亡父藏宝图的发现者与航海参与者。

**阶段与版本**：发现父亲地图至登船；另列讲谈社全集重构版“救Pan”开篇。手塚官网公开资料共3条；跨版本共通2条、重构版专属1条，非全书穷举。

- 行为1：Pete在亡父文件箱中见到旧岛图 → 他取出查看并把它判断为藏宝岛地图 → 父亲遗物、地图与未知岛屿 → 一个落到手中的旧文件被处理成明确线索。
  - 归类：`n`（主位候选证据，93%）。对象端点：由亡父留下、被Pete接住并解释的地图输入。
- 行为2：地图给出可能的藏宝岛方向 → Pete登船，与父亲的朋友船长共同出海寻宝 → 地图、船长关系与航海通道 → 他沿遗产线索和父辈关系进入既有航路。
  - 归类：`nx`（功能位证据，94%）。对象端点：亡父地图给出的方向、父亲友人船长及船只航路。
- 行为3：**仅讲谈社全集重构版**，Pete去码头途中遇见流浪狗 → 他救下Pan → Pan及同行关系 → Pan脱离流浪处境并加入旅程。
  - 归类：`n`（主位候选证据，93%）。对象端点：途中落到Pete面前的流浪犬困境；该动作在1947初版被删，不能跨版计数。

**未列为行为**：被海盗俘虏、随风暴漂流、被岛民抓获均是落在Pete身上的事件，官方简介没有给出对应主动动作，因此不冒充“Pete继续组织航路”。

**反证**：持有地图不等于掌握宝藏或岛屿；公开文字也没有显示Pete自行组织长期流程。

**归类统计**：跨版本共通范围为`n`1、`nx`1，主次均不判；若只看全集重构版则为`n`2、`nx`1，可暂定主`n`93%，次十元仍不判，`nx`仅为单条功能证据94%。旧“跨版本主`xn`91%·次`nx`88%”撤回。

**关系候选**：不宣布。地图输入之后确有登船，但行为2更符合沿遗产与船长通道推进的`nx`，不足以证明Pete把流程组织成稳定`xn`，故旧`n生xn`候选撤回。

**与作品主维关系**：Pete的`n/nx`人物证据不等于作品层“漫画语言如何构成本体”的`zn+x`。版本差异只限定证据范围，不改90分、本体主候选或精选结论。

**复核位置**：分别回查1947初版与讲谈社全集重构版的地图、登船和Pan开篇页码；先锁90分评分卡实际使用版次。

## 本轮结构性修复

1. 把第十六批旧报告标记为`legacy-superseded`，由本报告承接当前人物结论。
2. 撤回乙骨真剑旧主`zx`、Lulu旧主`nz`/次`zx`及Pete旧主`xn`；公开动作不足时改为主次未判。
3. 《新寳島》跨版本共通证据只保留地图处理和沿图登船；Pan救援继续隔离为全集重构版专属。
4. 被俘、漂流、被抓等背景事件不再改写成Pete的主动行为。
