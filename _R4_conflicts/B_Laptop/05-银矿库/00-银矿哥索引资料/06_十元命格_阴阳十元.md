## 一、十元命格总览

十元命格把人性分为 **5大元素 × 阴阳两仪**，共10个基本人格节点。

| 元素 | 阳干（外显/功能） | 阴干（内隐/动机） |
|------|-----------------|-----------------|
| **木**（创造/突破） | ZX 突破者、开局者 | x并z 包装者、洞察者 |
| **火**（表达/情绪） | ZN 热情者、领导者 | z 执念者、被看见渴求者 |
| **土**（关系/稳定） | N 稳定者、结构者 | nz 柔情者、依恋者 |
| **金**（规则/边界） | xn 制度者、权力执行者 | nx 算计者、暗流操控者 |
| **水**（欲望/风险） | XZ 危险感知者、敏感者 | x 深欲者、隐匿贪婪者 |

## 二、阳链与阴链（相生·成长方向）

### 阳链（事业/外显层）
```
ZX → ZN → N → xn → XZ → ZX
突破 → 热情 → 稳定 → 规则 → 危险感知 → 再突破
```

### 阴链（欲望/内隐层）
```
x并z → z → nz → nx → x → x并z
包装 → 执念 → 柔情 → 算计 → 深欲 → 再包装
```

**注：** 阴链终端不是循环回到起点，而是 x（深欲）作为最终驱动力，牵引整个欲望层。

## 三、相克链（逆向冲突）

### 阳链相克
- XZ（水）克 ZN（火）：危险感知压制热情
- ZN（火）克 xn（金）：激情打碎规则
- xn（金）克 ZX（木）：制度限制突破
- ZX（木）克 N（土）：创新颠覆秩序
- N（土）克 XZ（水）：稳定压制危险波动

### 阴链相克
- x（水）克 z（火）：深欲压制执念
- z（火）克 nx（金）：执念压制算计
- nx（金）克 x并z（木）：算计压制包装
- x并z（木）克 nz（土）：包装压制柔情
- nz（土）克 x（水）：柔情压制深欲

## 五、十元在故事创作中的定位

### 十元是三元的人格化底层
三元理论讨论"谁在经历什么"，十元讨论"这个人是什么人"：
- **Z（内隐信念）** → 阳面：ZN / 阴面：z、nx、x并z
- **N（稳定基准）** → 阳面：N / 阴面：nz
- **X（外显行动）** → 阳面：ZX、xn、XZ / 阴面：x、x并z

### 十元与五大型的对应关系

| 五大型 | 主要十元 | 创作角色时 |
|--------|----------|----------|
| 命运型 xz+nz | nz（依恋）+ xz（欲望安排） | 深情型主角、被命运拆散 |
| 时间型 xn+z | z（执念）+ xn（规则） | 循环执念、规则执行者 |
| 因果型 zx+nx | ZX（突破）+ nx（算计） | 布局者、复仇者 |
| 本体型 zn+x | ZN（热情）+ x（深欲） | 燃烧者、自我追逐 |
| 空间型 x并z+n | N（稳定）+ x并z（包装）+ z（执念） | 隐居者、旁观者 |

## 六、十元诊断工具（创作角色时用）

**问自己这个角色最害怕什么：**
- ZX角色怕：还没突破就被秩序吞没
- x并z角色怕：包装被撕开、真实能力被看穿
- ZN角色怕：热情无人响应、被冷漠对待
- z角色怕：被忽视、自己的偏激不被理解
- N角色怕：结构崩塌、关系断裂
- nz角色怕：被抛弃、情感依托消失
- xn角色怕：规则被突破、失控
- nx角色怕：算计曝光、失去利益
- XZ角色怕：危险来临时自己无力反应
- x角色怕：欲望永远无法满足

## 七、十元 × 五大型 × 角色阵容（实用速查）

### 命运型（xz+nz）
- 主角核心：nz（依恋深情） + xz（命运捆绑）
- 对手：N（稳定）或 xn（规则）造成分离压力
- 常用配对：zx-nx（突破者被算计者阻挡）
- 故事问题：能不能在一起？分开后还能相遇吗？

### 时间型（xn+z）
- 主角核心：z（执念） + xn（规则执行）
- 对手：XZ（危险感知）打破循环
- 常用配对：xz-nz（欲望温柔）制造欲罢不能
- 故事问题：逃出循环还是接受命运？

### 因果型（zx+nx）
- 主角核心：zx（突破） + nx（算计）
- 对手：ZN（热情）或 nz（柔情）成为软肋
- 常用配对：zx克n（突破者颠覆秩序）
- 故事问题：布局者最终被什么反噬？

### 本体型（zn+x）
- 主角核心：zn（热情） + x（深欲）
- 对手：nx（算计）利用或抑制
- 常用配对：xz克nx（欲望对抗算计）
- 故事问题：燃烧之后剩下什么？

### 空间型（x并z+n）
- 主角核心：n（稳定）+ x并z（包装）+ z（执念）
- 对手：XZ（危险敏感）入侵平静
- 常用配对：n克xz（稳定压制欲望）
- 故事问题：空间崩塌时，身份还能维持吗？
