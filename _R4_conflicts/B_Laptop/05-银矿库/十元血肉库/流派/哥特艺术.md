# 哥特艺术（Gothic Art，约1140-1500）｜三元物象映射教学

## 0. 一句话定义

**光和石头一起向上飞——哥特不是一种建筑风格，是一种「把人的视线拉到天上」的操作。彩色玻璃的颜色不是装饰，是把圣经翻译成光。**

## 1. 三元粗拆

| 三元 | 内容 | 物象 |
|------|------|------|
| **zn（意义/信念）** | 玻璃上的圣经故事不是画是光——彩色玻璃把神的话语转化成光打进教堂里 | 一句写在光线里的句子 |
| **x（欲望/吞噬）** | 教堂往上飞的尖拱和飞扶壁——不是结构需要，是一种「往上拽」的力量 | 一只手把你从地面拉起来 |

## 3. 体量

**体量 = 7 / 10**

体量不是力量——哥特统治了400年，虽然被文艺复兴反动了，但它是「要让上帝住在美里」这件事的最极致建筑版本。

## 4. 动态链

```
起手(罗马式建筑的厚重/封闭——太沉了)
→ 第一作用(zn·要把上帝的故事画成光——玻璃不是墙)
→ 转向(x·建筑要往上飞——尖拱/肋拱/飞扶壁)
→ 承载(xn·结构规则的精密系统)
→ 落点(你走进教堂——光线从四面八方的彩色玻璃里打进来，你不知道自己在哪——在天上？)

```

**动态链总强度：7.5/10**
**结果类型：循环型**——光→石头→意义→光。

## 6. 封存句

「彩色玻璃不是装饰（x并z），是把圣经翻译成光（zn）。教堂的尖顶不是建筑需要（xn），是把你从地面拽上去的手（x）。哥特艺术不画上帝，它让上帝住在光里。」
