# 未来主义（Futurism，约1909-1920）｜三元物象映射教学

## 0. 一句话定义

**一群崇拜速度、讨厌博物馆、想烧掉图书馆的人——他们不画安静的风景，他们画车、飞机、噪音、奔跑的人。**

## 1. 三元粗拆

| 三元 | 内容 | 物象 |
|------|------|------|
| **zx（突破/破门）** | 速度+运动+机器——不画静止的物，画「物在运动中留下的痕迹」 | 一辆车不是车的照片，是车跑过去留下的风 |
| **x（欲望/吞噬）** | 对旧文化的吞噬——「我们要烧掉博物馆！图书馆！」 | 一张嘴，在吃整个19世纪 |

## 3. 体量

**体量 = 7 / 10**

体量不是力量——未来主义十年就结束了，但它的影响辐射到装饰艺术、构成主义、甚至今天的赛车和广告视觉。它和法西斯主义的关系也让它争议终身。

## 4. 动态链

```
起手(新技术——车/飞机/电灯/电影——生活变了但画没变)
→ 第一作用(z·对速度和机器的狂热崇拜——不再崇拜月亮，崇拜车灯)
→ 转向(xn·先写宣言——未来主义是唯一先有理论再有画的流派)
→ 执行(zx·画运动——狗不是一只狗，是狗在不同位置上的叠影)
→ 冲突(x·吞噬旧文化——「博物馆是墓地！」)
→ 落点(运动中的物在画面上的痕迹——你同时看见了起点、中间、终点)

```

**动态链总强度：7.5/10**
**结果类型：断链型**——随着一战爆发和法西斯上台，未来主义的内在矛盾让它自己中断了。

## 6. 封存句

「一辆车不是车，是车跑过去留下的风（zx）。博物馆是墓地（x），要烧掉。一只狗在画布上不是一张狗的照片，是狗的12个运动瞬间的同框（zx+nx）。——速度是现代的美（x）。」
