# 笛卡尔（René Descartes，1596-1650）｜三元物象映射教学

## 0. 一句话定义

**近代哲学的奠基人——他用「普遍怀疑」这把刀把一切不可靠的知识斩尽，在废墟上找到了唯一不可怀疑的东西：我在怀疑这件事本身。**

## 1. 三元粗拆

| 三元 | 内容 | 物象 |
|------|------|------|
| x | 经院哲学的教条、感官的不可靠、一切知识的不确定性 | 一座被蛀空了地基的老房子 |
| n | 我思故我在（cogito ergo sum）—思想作为唯一确定的承载点 | 一块在流沙中唯一踩实的石头 |
| z | 心物二元论—灵魂与身体的分离，人既是思考的实体也是占空间的实体 | 一把把世界劈成两半的刀 |

## 3. 体量

**体量 = 9 / 10**

体量不是力量——笛卡尔被称为近代哲学之父不是因为他最强，而是因为他开了新方向。他之后的所有哲学家都在回应他的问题：知识如何可能？身心如何统一？他的在场密度不亚于柏拉图在古希腊的地位。

## 6. 动态链

```
起手(x·一切知识的不可靠) → 第一作用(nx介入·普遍怀疑) → 
生成(z·对绝对确定性的执念) → 冲突(x并z·梦与现实的表面不可辨) → 
转向(n·我思作为唯一确定基点) → 承载(zx·重建知识体系) → 
结算(zn·我思故我在作为近代哲学的起点) → 落点(心物二元论·劈开世界)

```

| 段落 | 位置关系 | 强度 |
|------|---------|:----:|
| x → nx | x被nx控 | 知识的不可靠逼迫使用普遍怀疑这把刀 | 8 |
| nx → x并z | 克 | 怀疑拆穿了「我看到的=真实的」这个伪装 | 8 |
| nx → n | 生→转向 | 普遍怀疑→我思（唯一不可怀疑的） | 9 |

**动态链总强度 = 8.2 / 10**

**结果类型：换芯型**—经院哲学的知识核心被换成了「我思」这个新核心。外壳还是哲学，芯从上帝变成了人。

## 8. 误判检查

| 误判 | 修正 |
|------|------|
| 把我思故在当成逻辑推理 | 不是推理（大前提：凡思考者存在→小前提：我思考→结论：我存在），是直觉 |
| 把笛卡尔的怀疑当成虚无主义 | 怀疑不是目的，是方法。笛卡尔是有信仰的怀疑者 |
| 把心物二元论当成笛卡尔的全部 | 他还有大量物理学、生理学、伦理学著作 |
