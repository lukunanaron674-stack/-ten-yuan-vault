# 休谟（David Hume，1711-1776）｜三元物象映射教学

## 0. 一句话定义

**哲学的拆弹专家——他用「印象」的原石砸碎了因果必然性的链条，把所有「必然真理」降级为「心理习惯」，然后乐观地说：既然理性解决不了，那就去打牌。**

## 1. 三元粗拆

| 三元 | 内容 | 物象 |
|------|------|------|
| x | 形而上学的狂热、因果必然性的自大、人类理性的过度自信 | 一座建立在沙滩上的城堡 |
| n | 经验主义的人性论（印象→观念→习惯→信念） | 一根把全部知识从感官拉到观念的运输管道 |
| z | 「习惯是人生的伟大指南」—没有必然性，只有习惯，但这不妨碍你照常生活 | 一个拆掉所有承重墙后发现房子没塌的人的微笑 |

## 3. 体量

**体量 = 8 / 10**

体量不是力量——休谟的经验论不是最强的哲学，但它的破坏力是最大的之一。它把康德从独断论的睡梦中惊醒。他的因果律批判至今仍是科学哲学的起点。

## 6. 动态链

```
起手(x·经验的直接性/印象) → 第一作用(nx介入·拆穿因果必然性) → 
生成(x并z·「必然性」只是习惯的伪装) → 冲突(z·寻求确定性的执念vs无必然性的真相) → 
承载(xn·印象→观念→习惯→信念的规则链) → 结算(n·人性论作为新承载) → 
落点(消解了焦虑但踏实生活)

```

| 段落 | 位置关系 | 强度 |
|------|---------|:----:|
| x → nx | x被nx分析 | 经验的本质被因果批判揭示 | 8 |
| nx → x并z | 克 | 因果必然性的伪装被拆穿—它只是习惯 | 8 |
| x并z → z | 生→冲突 | 「必然性=习惯」这个发现消解了追求绝对真理的执念 | 7 |
| z → xn | 被克→转向 | 执念消解后，经验的规则成为好的替代 | 7 |
| xn → n | 补→承载 | 规则补足了人性论作为经验论的完整框架 | 7 |

**动态链总强度 = 7.4 / 10**

**结果类型：扭曲型**—因果关系从「必然真理」被扭成了「心理习惯」。知识还是原来的知识，但它的性质变了。

## 8. 误判检查

| 误判 | 修正 |
|------|------|
| 把休谟当成彻底的怀疑论者 | 他是「温和的怀疑论」—承认理性的局限，但不否认人可以正常生活 |
| 把休谟当成反理性 | 他不是反理性，是指出理性的界限。「理性是激情的奴隶」—理性服务于情感 |
| 把休谟的因果批判当成对科学的否定 | 科学照常运作，只是科学的基础不是「必然性」而是「概然性」 |

## 9. 封存句

「用印象（x）的原石砸碎因果链条（nx），在习惯（n）的沙丘上建起人性论帐篷，将所有必然性标记为习惯的伪装（x并z）—然后去打牌。」
