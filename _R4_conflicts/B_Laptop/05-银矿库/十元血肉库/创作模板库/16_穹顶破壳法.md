# 创作模板 ⑯ · 穹顶破壳法

**符号**：x并z+n → xz → z → 破壳
**主题仓**：空间
**源作品**：楚门的世界

## 核心结构
1. x并z的材质——不能是铁幕/高墙，必须是柔软的、温暖的、爱意的包装（糖果色/花园/永远安全的环境）
2. n的设计——容器必须承载对系统的真实情感
3. 裂缝序列——三道裂缝递进：外部人闯入→系统技术故障→信任体系崩塌
4. 容器检测场景——主角主动测试边界（开车冲向桥洞、用钥匙划车）
5. 系统最后通牒——控制者直接对话："留下来，这里更好"
6. 破壳方向——不是摧毁系统，而是离开系统
7. 结局张力——离开这个动作本身，不交代"外面"

## 可替换组件
| 组件 | 可替换选项 |
|:----|:----------|
| x并z包装 | 完美家庭/理想社区/虚拟现实/宗教社区/主题公园 |
| n容器 | 被保护者/孩子/皇帝/AI/实验对象 |
| 裂缝 | 陌生人/故障物/偶然闯入者/内部信息来源 |
| 破壳 | 物理出门/删除账号/觉醒/逃离/自杀 |

## 适用场景
反乌托邦、觉醒叙事、超现实、身份怀疑
