# 流派：存在主义

## 0. 一句话定义

> **存在先于本质——人首先被抛入世界，再通过行动定义自身，而非像物一样先有定义再存在。**

## 1. 三元粗拆

- **存在先于本质** → 人无预设，自我铸造
- **自由即重负** → 自由是诅咒也是恩赐
- **荒诞与本真** → 世界无意义，人需创造意义
