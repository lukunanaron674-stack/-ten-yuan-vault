# 哲学史大脉络 ⑥ · 19世纪

## 一句话定位

> **黑格尔体系崩塌后，哲学不再相信"绝对真理"——转向个体、意志、欲望、历史、物质、存在。**

## 物象映射

**物象：在虚无中锻造自己的锤子**

```text
x = 黑格尔体系崩塌、上帝已死、工业革命——传统的意义供给失效
n = 无——没有一个统一的承载容器，每个哲人自己就是自己的地基
z = 多元的回答：意志、权力、阶级斗争、个体信仰、荒诞
```

**物象强度：9/10**
