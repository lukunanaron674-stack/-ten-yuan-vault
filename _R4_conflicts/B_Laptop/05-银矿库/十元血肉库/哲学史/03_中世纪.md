# 哲学史大脉络 ③ · 中世纪

## 一句话定位

> **哲学成了神学的婢女——但不甘心只是婢女，她不断追问"上帝存在能用理性证明吗？"**

## 物象映射

**物象：教堂的彩色玻璃窗**

```text
x = 信仰的危机：异端、伊斯兰哲学冲击、理性与信仰的张力
n = 教会、修道院、大学——承载思想的制度容器
z = 经院哲学体系（总和）：用希腊哲学的概念工具为信仰做理性辩护
```

**物象强度：8/10**
