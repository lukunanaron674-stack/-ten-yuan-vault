# 哲学史大脉络 ② · 希腊化与古罗马

## 一句话定位

> **城邦解体后，哲学不再追问"什么是善的城邦"，而是追问"在这个乱世里，一个人如何获得内心的平静"。**

## 物象映射

**物象：从广场退入花园/内心城堡**

```text
x = 城邦的崩塌、帝国的扩张、战乱不断——人失去了公共生活的安全感
n = 内心城堡：通过哲学修炼建立不被外界撼动的内在根基
z = 不动心（ataraxia）：在任何情况下都能保持心灵平静的能力
```

**物象强度：8.5/10**

## 封存句

> **希腊化哲学不是在追问真理，而是在战乱中给自己造一座风吹不倒的内心堡垒——在什么都可能失去的时代，教你如何不失去自己。**
