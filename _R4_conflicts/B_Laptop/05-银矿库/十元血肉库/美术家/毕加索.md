# 毕加索（Pablo Picasso，1881-1973）｜三元物象映射教学

## 0. 一句话定义

**一个不是画家、是视觉系统黑客的人——他把世界拆成零件再重新组装，拆解的不是物体本身，是「人怎么看物体」这一机制。他一生换了无数种风格，因为他在每个风格的火候到了时就换新的牌局。**

## 1. 三元粗拆

| 三元 | 内容 | 物象 |
|------|------|------|
| x | 现实太单调、怎么看都是老样子、传统的观看方式没意思 | 一个所有人都在同一个角度看的房间 |
| n | 立体主义的拆解-重组方法 — 从不同角度同时看到一个物体 | 一台把西瓜切成四块、每块从不同方向被看见的机器 |
| z | 《格尔尼卡》《亚威农少女》—被炸成碎片的现实，如何在画面中重新组装起来 | 一张被打碎后重新拼起来但仍然残缺的脸 |

## 3. 体量

**体量 = 10 / 10**

体量不是力量——毕加索可能是20世纪最有名的艺术家名字。立体主义、拼贴、蓝色时期、玫瑰时期、超现实主义时期……他一个人走了其他人几辈子的路。他不等风格来找他，他制造风格。

## 6. 动态链

```
起手(x·传统的观看方式的单调) → 第一作用(nx·拆解「怎么看」的机制) → 
生成(z·必须找到新方式的冲动不断爆发) → 承载(n·立体主义/拼贴/各种方法) → 
冲突(x并z·表面伪装被拆穿—一张脸不是一张脸) → 结算(nx+z·视觉系统被重新编程) → 
落点(z·终身换风格，永不重复)

```

| 段落 | 关系 | 强度 |
|------|------|:----:|
| x → nx | x被nx对抗 | 传统的单调被计算拆解 | 8 |
| nx → x并z | 克 | 计算拆穿表面的伪装 | 9 |
| nx → z | 被克 | 计算被冲动推着走 | 8 |
| z → n | 生→承载 | 冲动找到了方法论的承载 | 7 |
| n → zx | 补→执行 | 方法论补足了执行的持续 | 7 |

**总强度 = 7.8 / 10 — 结果：换芯型（每一个时期换一个新的芯，外壳还是毕加索）**

## 8. 误判检查

| 误判 | 修正 |
|------|------|
| 把毕加索当成zx（目标执行体系化） | 立体主义对他来说只是**一个工具**—他随时可以换。zx的人一辈子在一个体系上迭代，毕加索不断重建体系。这是nx（换牌局）和zx（打好这把牌）的根本区别 |
| 把立体主义当成毕加索的风格 | 立体主义只是一个时期—他还有蓝色时期、玫瑰时期、新古典主义、超现实主义… |

## 9. 封存句

「我不是画我看到的东西（nx），我画我看它的方式（z）——《格尔尼卡》（x并z）不是轰炸，是被轰炸后现实如何在脑中重构的过程：牛的脸不是牛，是暴行本身的冷漠。」
