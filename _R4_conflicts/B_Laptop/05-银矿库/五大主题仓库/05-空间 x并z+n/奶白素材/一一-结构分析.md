## 三、主题分析

### 主题1：x并z + n = 空间（主主题）

**维度解释：** 场域、容器——家庭作为n空间如何承载每个人的困境

**分析：**

**空间1：台北城市（x并z空间）**

- x：城市的规则、压力、中产阶级的困境
- z：突破的可能性、机会、变化
- 台北是x和z同时存在的空间

**空间2：家庭（n空间）**

- n：稳定、承载、不变
- 婆婆卧床——n的象征，她承载着家庭，但她在失去功能
- 她的倒下打破了n的稳定

**n容器里的内容：**

| 角色 | 在n里装的东西 |
|------|---------------|
| NJ | 职场的厌倦，初恋的回忆 |
| 敏敏 | 职场+家庭压力，灵修的空虚 |
| 婷婷 | 初恋的失败，内疚 |
| 洋洋 | 童年视角，对世界的好奇 |

**婆婆的病倒的意义：**

婆婆卧床，让每个人不得不直面自己。她无法说话——她的沉默让每个人被迫说出来。

这是n容器打破后的效果：被承载的东西终于被看见。

---

### 主题2：nz + x = 本体

**维度解释：** 精神驱动与欲望如何耦合

**分析：**

**NJ（nz）：**

- nz：对初恋阿瑞的依恋，40年没有消失
- x：现实压力，家庭责任，不能离开
- 他的nz在x的框里，一直被压着

**婷婷（n+nz）：**

- n：家庭的压力，乖女孩的规范
- nz：初恋的萌芽，被破坏
- 她的n+zn是典型的少女状态

---

### 主题3：zx + nx = 因果

**维度解释：** 事件如何推进

**分析：**

本片不是事件驱动的，而是**状态驱动**的。

因果来自于：
- 婆婆的病倒 → 每个人开始面对自己
- 婷婷的初恋 → 失败的恋爱
- NJ去日本出差 → 和初恋重逢

这些事件不是"发生了什么"，而是"谁的状态发生了变化"。

---

## 四、核心公式

**《一一》的核心公式：**

> **x并z+n（空间）是主主题——台北城市是x并z的空间，家庭是n的空间，婆婆的病倒打破了n容器，迫使每个人直面自己。n里装的东西各不相同：NJ的是初恋，敏敏的是空虚，婷婷的是初恋失败，洋洋的是对世界的好奇。这就是"一一"——每个人都有一个自己的故事，但都发生在同一个n里。**
