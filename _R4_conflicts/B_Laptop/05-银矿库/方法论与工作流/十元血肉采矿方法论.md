# 十元血肉采矿方法论

> **不要让 AI 跑"影评/漫评/乐评"，要让 AI 跑"十元信息量采矿"。**

## 核心理念

**骨架 + 血肉 = 可回填到符号卡的组织**

- **主骨架**：每个十元的不可动摇的核心语义（骨头，不能乱改）
- **血肉**：从作品中提取的体感、人物、空间、视觉、声音、动态链、误判反例

> 不要问"这个作品好在哪里"，要问"这个作品给哪个十元增加了哪些体感、行为、空间、视觉、声音、动态链、误判反例"。

---

## 第一步：先定主骨架

这个案例主要补**哪个十元／哪个关系／哪个五大主题**？

例：xz 的主骨架

```text
xz = 临界行动 + 风险路径 + 来不及
```

这是骨头，不能乱改。然后血肉从作品里长出来。

---

## 第二步：拆血肉

| 血肉类型 | 采什么 | 来源 |
|---------|--------|------|
| 人物血肉 | 这个十元的人的形态／体感 | 影视／动画 |
| 行为血肉 | 这个十元怎么动、怎么做决定 | 影视／动画 |
| 空间血肉 | 这个十元在什么空间里存在 | 影视／动画 |
| 视觉血肉 | 这个十元看起来什么样 | 动画／漫画最强 |
| 声音血肉 | 这个十元的声音特质 | 音乐最强 |
| 叙事血肉 | 这个十元在故事里怎么被结构 | 影视最强 |

例：xz 的血肉填充

```text
xz 的角色血肉：
逃亡者 / 猎手 / 失位少年 / 被时代推着走的人 / 站台边缘的人

xz 的空间血肉：
渡口 / 断桥 / 雨夜街口 / 逃生通道 / 边境线 / 末班车站台

xz 的视觉血肉：
逆光 / 切线 / 冷边 / 风损 / 断裂构图 / 闪断镜头

xz 的音乐血肉：
不稳定节拍 / 悬置和弦 / 突然断拍 / 高音冷刺 / 低频追赶感

xz 的动态血肉：
xz → nz：漂流寻找停靠
xz → x：危险被欲望污染
xz → xn：临界行动被规则捕获
xz → n：危险进入承载结构
```

---

## 第三步：找关系牙印

- 谁作用谁？
- 谁污染谁？
- 谁克谁？
- 谁补谁？
- 谁被改写？

这些是"关系血肉"——比单符号血肉更有价值。

---

## 第四步：找动态链

```
起手 → 作用 → 承载 → 冲突 → 结算 → 落点
```

音乐最能补"力的变化时间和顺序感谱"：

```text
n  = 稳定低密度铺底
xz = 不稳定中高密度悬置
zx = 短促强推进爆发
nz = 软化、拖尾、余韵
xn = 节拍、规训、循环
z  = 高亮爆点
x  = 低频吞没、欲望拖拽
```

---

## 第五步：回填信息量卡

新发现必须写进对应十元卡，而不是停在作品分析里。

---

## 第六步：提炼创作模板

这个结构以后怎么偷走？

例——生活磨损型爱情：

```text
两个人因共同趣味相遇，进入同居承载，
生活结构逐渐接管欲望，
最后不是不爱，而是爱的形态被现实换芯。
```

---

## 各媒介侧重点

| 媒介 | 最适合补的血肉 |
|------|--------------|
| 🎬 影视 | 关系血肉 + 五大主题血肉（角色关系、命运结构、本体变化、空间承载、因果链条） |
| 🎨 动画／漫画 | 视觉血肉 + 动态姿态血肉（形状、姿态、构图、表情、动作节奏） |
| 🎵 音乐 | 顺序感谱 + 力的变化 + 时间血肉（什么时候压、放、停、爆、回收） |

---

## 三大会产库

### A. 十元血肉库

每个十元下面挂素材：

```text
xz：
  影视血肉：
  动画血肉：
  音乐血肉：
  视觉血肉：
  空间血肉：
  误判反例：
```

### B. 十元关系牙印库

```text
n → x：生活承载慢慢磨损欲望
x并z → zn+x：表象外壳反噬主体
xz → nz：漂流寻找停靠
xn → z：规则压出执念爆点
```

### C. 创作模板库

可直接复用的情节原型、角色原型、空间原型。

## 总比喻

```text
十元 = 骨架
案例 = 血肉
动态链 = 筋膜
五大主题 = 器官系统
创作模板 = 可复活的身体
```

---

## 最佳提问模板

❌ 不要这样问：

```text
分析《花束般的恋爱》
```

✅ 要这样问：

```text
用十元信息量采矿方式分析《花束般的恋爱》。
目标不是影评，而是提取：
1. n 的生活承载血肉
2. x 被现实磨损的血肉
3. nz 停靠退化的血肉
4. n+x 角色动态链
5. 可回填到十元信息量卡的素材
```

---

## 没用的跑法（避坑）

❌ 分析剧情
❌ 总结主题
❌ 夸作品
❌ 给评分
❌ 写一堆感受
❌ 最后没有回填到十元

> 这种就是"看起来很努力，实际没入矿"。

---

## 完整执行流程

```text
Step 1: 定主骨架
→ 这个案例补哪个十元/关系/五大主题？

Step 2: 拆血肉
→ 人物/行为/空间/视觉/声音/叙事

Step 3: 找关系牙印
→ 作用/污染/克/补/改写

Step 4: 找动态链
→ 起手→作用→承载→冲突→结算→落点

Step 5: 回填信息量卡
→ 写进对应十元卡

Step 6: 提炼创作模板
→ 以后怎么偷走
```
