# 线语法

## 原版概括

**线 = x**（方向、分割、规则）

### 线的两种气质
| 类型 | 符号 | 十元 | 特性 |
|------|------|------|------|
| 横线构图 | 丨x | x | 规则、划分、理性、稳定 |
| 斜线/手写感 | ✍xz | xz | 边缘、漂移、不规整、动感 |

### 线的四大作用

1. **空间塑造（z, zn, n）**
   - 方向流动 → 延续空间
   - 深度 → 透视引导
   - 广度 → 横向延展

2. **分割（xn）**
   - 版面比例划分（黄金分割/网格系统）
   - 图文分割
   - 区域分割

3. **视线引导（z）**
   - 带着读者眼睛走
   - 线的起点 = 视觉入口
   - 线的终点 = 信息重点

4. **联系边缘对齐**
   - 连接零散元素
   - 建立隐形网格

## 三元分析

- **x（现象）**：封面上可见的线条——书脊/腰封边界、文字排版的基线、装饰线条、手写线条、切割线
- **z（本质）**：线是方向的确定性——决定阅读动线和版面骨骼
- **n（应用）**：横线分割比例、斜线制造动感、线的重复形成面

## 关键语法规则
- 丨x（理性线）→ 适合学术/经典/商务封面
- ✍xz（感性线）→ 适合文艺/实验/手作感封面
- 线密度越高 → 分割感越强 → 越xn
- 线流动越自由 → 越xz → 漂流感
