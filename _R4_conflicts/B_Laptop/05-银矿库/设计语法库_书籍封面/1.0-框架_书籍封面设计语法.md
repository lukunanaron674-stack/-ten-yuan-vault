# 书籍封面设计语法框架

## 核心结构

146、210对齐重复对比亲密——**书籍封面四大语法支柱**

### 一、版面体系（总量的控制框架）
| 维度 | 极左 | 极右 | 十元映射 |
|------|------|------|----------|
| 版面率 | 低（z） | 高 | 越少越z，越多越nx |
| 留白率 | 少（z） | 多（nx） | z不留白，nx留白 |
| 图文关系 | 纯图（n？） | 全图加少文 | 文字=nx，图文=x并z |

> 可以通过**颜色统一**降低留白率（颜色填充替代物理留白）

### 二、对比/密度体系（操作的引擎）
| 层级 | 十元映射 | 关键概念 |
|------|----------|----------|
| **点** | n | 多点、丰富点缀、减少留白、突出重点标注zx、视线n、对齐平衡 |
| **线** | x | 横线构图丨x，✍xz |
| **面** | z | 分割？nx、深化主题、承载信息、字面、空间 |
| **体** | nx | 三维空间塑造 |

### 三、点线面体详细语法

#### 点（n）
- 多点
- 焦点（z）→ 圆面？球？
- 丰富信息点缀版面（n）
- 减少留白（z）
- 突出重点/标注（zx）
- 视线引导（n）
- 对齐/平衡（n）
- 点的分散 = 消化（nx）
- 点重复（n）
- 文字图形点化

#### 线（x）
- 横线构图（丨x）
- 斜线/手写感（✍xz）
- 作用：
  1. 空间塑造——方向流动 / 延续空间 / 深度广度（z, zn, n）
  2. 分割——版面比例划分、图文分割、区域分割（xn）
  3. 视线引导（z）
  4. 联系边缘对齐

#### 面（z）
- 分割（？nx）——作用明显
- 深化主题
- 摄像视线引导
- 承载信息（文字）
- 提升整体感
- 字面
- 空间

### 四、版面留白（独立一章）
- 分析补充
- 留白率：越少越z，越多越nx
- 图文 x 板面 x 留白的三元关系：
  1. **图片**（图文中的图）
  2. **版面** = 边框
  3. **留白** = 白色区域大小

### 五、10元映射总表
| 视觉元素 | 十元 | 说明 |
|----------|------|------|
| 版面率低 | z | 紧凑、满、不留余地 |
| 版面率高 | nx | 松弛、消化、空间感 |
| 留白少 | z | 填充型设计 |
| 留白多 | nx | 呼吸型设计 |
| 文字 | nx | 规则、秩序、可读性 |
| 图文混排 | x并z | 表面≠内在，图文交织 |
| 纯图 | n | 承载、接收、画面叙事 |
| 点 | n | 点缀、重复、对齐、承载视线 |
| 焦点 | z | 目标、核心视觉落点 |
| 点分散 | nx | 消化、消散、均匀分布 |
| 标注/突出重点 | zx | 目标执行，功能指向 |
| 线（横）丨x | x | 划分、方向、规则 |
| 线（斜/手写）✍xz | xz | 边缘、漂移、不规整 |
| 分割 | xn | 规则建立、区域划分 |
| 面 | z | 承载体、主体、空间 |
| 体（三维） | nx | 深度、消化空间 |
