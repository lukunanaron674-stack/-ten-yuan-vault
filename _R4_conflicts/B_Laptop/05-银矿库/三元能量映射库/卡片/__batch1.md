# 001 概念的定义（内涵与外延）

## 原书核心

经典逻辑学定义：概念 = 内涵（Intension）+ 外延（Extension）的不可分割对偶体。
- **内涵**：概念的核心属性总和，即"什么是 X"的充要条件
- **外延**：概念覆盖的全体对象，即"哪些是 X"的边界

现代转向：索绪尔（意义来自系统差异而非实指）、维特根斯坦（家族相似，无单一本质）

## 十元定位

**所属集合：zx（阳木·突破者）**

理由：概念的本质不是静态容器，而是 z（执念/切割冲动）切分 x（现象世界）的突破行为。先有"必须切"的执着，再用这个执着去划界、命名、分类。这正好是 zx 的核心动作——先动手，先切分，开第一条线。

## 生克补关系

- **生（顺生）**：→ **zn（阳火·精神表达）** — 概念切割成功后滋养精神个体，"我懂了"——先切割才有语言，有语言才有表达
- **克（逆克）**：→ **n（阳土·承载结构）** — 新概念的定义是对旧分类体系、旧框架的一次推倒重建
- **补（灵魂对子）**：↔ **nx（阴金·算计者）** — 概念定义需要逻辑自洽的自我结算来确认边界不矛盾。没有 nx 清算的概念是伪概念
- **被克**：**xn（阳金·秩序维护）** → — 旧制度、已有术语体系会反向约束概念的产生，"这不符规范"

## 体量

值：2/10
理由：最小不可绕过砖块，不直接参与叙事推动，但所有下游推理依附于此。最底层的元工具。

# 002 概念间的关系（同一/包含/交叉/矛盾/反对）

## 原书核心

基于外延是否重合，概念间关系分为五大类：
1. **同一关系** — 外延完全相同（如"等边三角形"和"等角三角形"）
2. **包含关系（种属/属种）** — 一个概念的外延完全在另一个之内（如"人"⊂"动物"）
3. **交叉关系** — 外延部分重合（如"青年"和"医生"）
4. **矛盾关系** — 同一属概念下两个不相容种概念，外延互补（如"男人"和"女人"在"人"下互补）
5. **反对关系** — 同一属概念下两个不相容种概念，外延不完全互补（如"黑色"和"白色"之间有灰色地带）

## 十元定位

**所属集合：x（阴水·深层欲望）**

理由：概念间的关系本质上是"x 层的外延分配"。同一/包含/交叉/矛盾/反对——这些说的都是外延（现象集合）之间的空间拓扑关系。不是 z 的切割冲动本身（那是 001），也不是 n 的承载系统，而是 x 层面事物在分类后的空间结构。

## 生克补关系

- **生**：→ **nz（阴土·柔情停靠）** — 关系区分让人能"找到自己的位置"，产生归属感
- **克**：**z（阴火·执念）** → — z 的精确切割越清晰，关系边界越分明；粗糙的概念留下模糊地带
- **补**：↔ **n（阳土·稳定承载）** — 概念关系需要分类框架（n）才能呈现结构
- **被克**：**nz（阴土·柔情）** → — 强烈的情感依恋会模糊概念边界，"舍不得分那么清"

## 体量

值：3/10
理由：对 001 的继承和扩展，描述 x 层拓扑结构，不是十元底层动力机制。
