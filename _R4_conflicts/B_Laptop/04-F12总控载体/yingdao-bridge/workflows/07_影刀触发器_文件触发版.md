## 流程核心逻辑

影刀触发后只做一轮，不需要无限循环：

1. 读取 `command.json`
2. JSON 解析
3. 如果 `status != RUN_NOW`，直接结束
4. 根据 `action` 执行对应动作
5. 写 outbox 结果
6. 把 `command.json` 改回 idle

这样比无限循环更省资源，也更稳定。

## command.json 空闲格式

执行完成后写回：

```json
{
  "action": "idle",
  "status": "idle",
  "updatedAt": "2026-07-13T00:00:00+08:00"
}
```
