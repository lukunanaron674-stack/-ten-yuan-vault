# 三方向总蓝图

## 来源

来自用户对 vault 未来结构的原始判断：

> 可以搞成 3 个方向：一个是为 AI 用的素材库，一个是给用户用的动态链凝结母题库，第三个是能力蓝图。

根目录原本存在一个超长文件名空文件，已被本页吸收为清晰短名入口。

## 方向一：AI 用素材库

目标：

让 Codex 学会十元语义位置关系、五大主题、动态链力流。

核心内容：

- 十元语义。
- 三元底色。
- 五大主题。
- 生补克关系。
- 银矿案例。
- 反例与误判。

判断标准：

- 是否能训练 Codex 的判断准度。
- 是否能减少默认 zn、默认 n、五维倒推十元。
- 是否能提供清晰字段。

## 方向二：给用户用的创作脑库

目标：

把用户看到的、吸收的、画到的东西，凝成动态链母题。

核心内容：

- 动态链母题。
- 插画线稿。
- 动画场景。
- 建模动态。
- 角色关系。
- 故事种子。

判断标准：

- 是否能帮助用户创作。
- 是否能变成故事一句话。
- 是否能变成角色姿态、场景构图、视觉风格。

## 方向三：能力蓝图

目标：

记录未来要解锁的能力，并用 F12 自动化持续补足。

核心内容：

- AI 视觉能力。
- 没有 AI 味的可控风格。
- 故事能力。
- 一句话故事生产。
- F12 自动化。
- 游戏交互研究。
- 能力解锁计划。

判断标准：

- 是否能变成下一轮可执行任务。
- 是否能被 F12 多框采集。
- 是否能沉淀为 Codex skill / workflow / prompt / 案例库。

## Codex 当前判断

三方向不应该分裂，而应该形成循环：

```text
AI 用素材库
-> 训练 Codex 判断力
-> 生成创作脑库
-> 推出能力缺口
-> F12 自动采集
-> 回流 AI 用素材库
```

## 下一步

1. 建立 F12 多框补脑任务。
2. 让每个框对应一个 brain slot。
3. 只回传归档轮、审稿轮、反例轮。
4. Codex 根据回传结果更新大脑库。
