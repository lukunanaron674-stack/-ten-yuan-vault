# 给你看的大脑报告

## 我现在怎么理解这个库

这个 vault 不是单一知识库，而是三层系统：

1. **十元语义训练层**
   - 让我学会 x / z / n 和十元关系。
   - 重点不是记术语，而是学会判断力怎么流。

2. **动态链与银矿案例层**
   - 用作品、场景、角色、关系来验证十元。
   - 重点是找可复用母型，不是做普通赏析。

3. **能力蓝图层**
   - 把你未来要解锁的东西排成路线。
   - 包括 AI 视觉、故事、插画、动画、建模、F12、游戏交互、自动归档。

## 我需要你继续喂什么

最有价值的不是大段解释，而是这些东西：

1. 你突然觉得“这个东西很像某个十元”的例子。
2. 你画图时想要的感觉、姿态、场景、光线、角色关系。
3. 你觉得某个 AI 输出“不对味”的地方。
4. 你看作品时感到“这里有力在流”的片段。
5. 你想要 F12 帮你自动研究的方向。

## 我会怎么吸收

我会把输入分成四类：

- 能直接进规则库。
- 只能进素材库。
- 需要 F12 多轮验证。
- 应该降权或删掉。

## 我会怎么回报给你

我会逐渐给你生成：

- 十元语义地图。
- 动态链母题库。
- 银矿案例库。
- 插画 / 场景 / 角色风格蓝图。
- AI 能力解锁路线。
- F12 多框自动研究任务。
- 给你看的阶段总结。

## 当前最重要的蓝图

F12 应该变成多个框同时补脑：

```text
一个框找十元关系。
一个框找动态链母型。
一个框找五大主题归仓。
一个框找视觉风格。
一个框找故事一句话。
一个框专门找反例和误判。
```

Codex 不必看所有普通轮。

Codex 最该看：

- 归档轮。
- 审稿轮。
- 承载包。
- 反例清单。
- 下一轮任务建议。
