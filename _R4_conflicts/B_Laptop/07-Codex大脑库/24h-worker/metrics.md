# 量化指标

## 仓库清洁度

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| 空文件数 | 内容为空的 .md 文件数 | → 0 |
| 重复文件数 | 内容相似度 > 90% 的文件对 | 越少越好 |
| 缺字段文件数 | YAML frontmatter 缺必要字段 | → 0 |
| 路径错误数 | 文件放错目录 | → 0 |

## 训练数据

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| pending_review 样本数 | 每日新增弱标签数 | 稳定增加 |
| gold_dataset 样本数 | 人工升级数 | 只由人工增加 |

## F12 产出

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| CarryPacket 数 | 每 5 轮 1 个 | = N/5 |
| 任务完成率 | done / total | ≥ 80% |
| 污染风险标记数 | 被标出的可疑内容 | 被标出不混入 |

## 自检

| 指标 | 计算方式 |
|------|----------|
| 废话率 | 无信息增量输出占比 |
| 重复率 | 与前批重复的输出占比 |
| 有效产出率 | 有明确标记的输出占比 |
