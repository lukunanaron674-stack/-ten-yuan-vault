# 每日 6 工位排班

## 工位 1: 数据体检工 (08:00-10:00)

**输入**: 整个 vault
**输出**: `reports/data_audit_YYYY-MM-DD.md`
**动作**:
- 扫描所有 .md 文件
- 检查空文件 (文件大小 < 50 字节)
- 检查重复文件 (相似度 > 90%)
- 检查 YAML frontmatter 缺字段
- 检查文件路径规范
- 检查同名归档
- 输出分类清单

## 工位 2: 废矿清理工 (10:00-12:00)

**输入**: data_audit 结果 + 全库扫描
**输出**: `reports/delete_candidates_YYYY-MM-DD.md`
**动作**:
- 找重复规则
- 找低价值 F12 输出
- 找过时任务卡
- 找旧版本污染
- 找只有情绪没有结构的材料
- 按风险三级分类

## 工位 3: 十元语义训练集工 (12:00-14:00)

**输入**: 作品分析、角色分析、动态链、F12归档
**输出**: `training_data/pending_review/semantic_candidates_YYYY-MM-DD.jsonl`
**动作**:
- 抽样分析片段
- 生成弱标签 (十元候选、五大主题、证据、误判风险)
- 只写 pending_review
- 不改 gold_dataset

## 工位 4: F12 任务生成工 (14:00-16:00)

**输入**: 缺口分析结果
**输出**: `04-F12总控载体/runtime/tasks/tasks_next.txt`
**动作**:
- 统计各十元/动态链/五大主题覆盖
- 发现最薄环节
- 生成多框任务 (A框/B框/C框...)
- 每框 5-10 轮
- 用 ---TASK--- 分隔

## 工位 5: 归档自检工 (16:00-17:00)

**输入**: F12 输出、归档目录
**输出**: `reports/self_review_YYYY-MM-DD.md`
**动作**:
- 检查 CarryPacket 生成情况
- 检查归档完整性
- 检查污染风险
- 生成下批建议

## 工位 6: 日报工 (17:00-18:00)

**输入**: 今日所有输出
**输出**: `reports/daily_report_YYYY-MM-DD.md`
**动作**:
- 汇总今日产出
- 更新指标
- 列出待确认项
- 建议明日任务
