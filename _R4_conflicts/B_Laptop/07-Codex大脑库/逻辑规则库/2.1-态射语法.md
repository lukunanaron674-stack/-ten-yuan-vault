# 态射语法

## 原版概括

范畴论中，**态射（morphism）** 是一个箭头 A → B，表示从对象 A 到对象 B 的关系/映射。每个态射必须满足：
1. 有明确的**源（domain）**和**目标（codomain）**
2. 每个对象都有一个**恒等态射** id: A → A
3. 态射可以**复合**：如果 f: A → B 且 g: B → C，则 g∘f: A → C

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | 十元分析中，你经常写 "nz 生 nx"、"nx 补 zx"——这些"生"和"补"本身就是箭头 |
| **z（本质）** | 将十元关系统一为**箭头语法**：所有关系（生/克/补/主从）都是带不同语义标签的箭头。箭头本身不承载数值，只承载方向。 |
| **n（应用）** | 用统一的箭头语言取代零散的关系描述。不再分"生/克/补"三种话术，而是统一写为 `A ─生─→ B`、`A ─克─→ B`、`A ─补─→ B` |

## 十元理论应用规则

> **规则 R23（箭头化）**：十元理论中所有二元关系必须能用箭头表示。无法用箭头表示的关系说明关系定义不清晰。
>
> **规则 R24（源与目标明确）**：每个箭头必须有明确的源十元和目标十元。不允许"Z 产生了某种影响"这种模糊表述——必须是"zx → zn"。
>
> **规则 R25（恒等态射保留）**：每个十元都有"自我维持"的箭头（id: A → A），代表这个命格在没有外部作用时的稳定状态。

## 十元箭头的统一表示法

```
生箭头：   A ──生──→ B    例：nz ─生─→ nx
克箭头：   A ──克──→ B    例：n  ─克─→ z
补箭头：   A ──补──→ B    例：nx ─补─→ zx
主从箭头： A ──主─→ B    例：z  ─主─→ x （在 zx 中）
恒等箭头： A ──→ A        例：n  ──→ n（n 的自我维持态）

箭头方向永远从"作用方"指向"被作用方"：
  A ─生─→ B  = A 生 B
  A ─克─→ B  = A 克 B
  A ─补─→ B  = A 补充能量给 B
```
