# 🧭 三根基 = 三个映射坐标轴

> 核心观点：三根基不是一个分类系统（把人装进三个盒子），而是一个**映射系统**（把现象投射到三个坐标轴上）。

**状态说明**：此框架已和用户讨论确认通过。

## 坐标轴一：X-N 轴（边界大小）

```
X（小边界）←——————————————————→ N（大边界）
  具体                             抽象
  物质                             精神
  利己                             利他
  分析/切割                       包容/承载
  楚庄王"楚国人"                  孔子"人"→老子"自然"→高僧"空"
```

- 这个轴只有一个、两端命名不同
- 任何现象都可以在这个轴上找到自己的位置
- 越往 X 走越具体清晰，越往 N 走越抽象包容

## 坐标轴二：Z 轴（自我确认强度）

```
弱 Z（存在感稀薄）←——————————→ 强 Z（自我确认冲动）
  随波逐流                         认定'我'必须要做什么
  不需要被看见                     必须要被看到
  被环境淹没                       自我意志压过环境
  高僧"空"（无我）                杰西"不接受死亡"的暴力爆发
                                    凯奇"我要学会战斗"的觉醒
```

- **Z 轴独立于 X-N 轴**——它衡量的是"我"的确认冲动
- Z 强 ≠ X 或 N 的任何一端——你可以是强Z且高X，也可以是强Z且高N
- Z 弱的人：融入环境、不反抗、不坚持、不需要被认可

## 三轴映射的使用方式

分析一个人的某个现象时，不是问"他是X型还是N型？"
而是问：**这个现象在三个轴上的投影分别在哪里？**

```
例：《恐怖游轮》杰西的暴力行为
  X-N 轴：偏 X（具体行为：不接受儿子死亡的真相）
  Z 轴：偏强 Z（"我不要！"的自我意志爆发）

例：《前目的地》主角的穿越行为
  X-N 轴：偏 X（存在性缺失感驱动，不是归属感驱动）
  Z 轴：偏弱 Z（几乎没有"我要！"——霜分析：XN型）

例：高僧说"空"
  X-N 轴：极 N（边界无限大 → 消解边界）
  Z 轴：极弱 Z（无我）
```

## 这个框架解决的问题

1. **Z 的定义**：Z 不是一个需要"本质定义"的东西——Z 就是一个坐标轴的名称
2. **Z/X/N 的关系**：它们不是互斥的类，而是独立的维度
3. **共存问题**：Z 和 N 可以共存——不同轴上的测量值
4. **划分穷尽**：任何现象都可用"边界大小+自我确认强度"描述
