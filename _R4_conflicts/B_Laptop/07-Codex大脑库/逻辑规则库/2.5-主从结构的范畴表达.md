# 主从结构的范畴表达

## 原版概括

在范畴论中，复合结构的态射可以有不同的拓扑形式：
- **积（product）**：A × B，两个对象并行存在的结构
- **余积（coproduct）**：A + B，两个对象以"或"的方式组合
- **拉回（pullback）**：从 A 和 B 到同一个 C 的箭头交汇

对一个复合符号（如 `zx`）来说，它既不是"Z 和 X 的积"，也不是"Z 或 X 的余积"——它是**Z 为主、X 为从的定向复合**。

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | "zx" = Z 主导的 X 方向——这里的"主导"是箭头拓扑问题 |
| **z（本质）** | 每个派生十元 `mn`（m 为根基，n 为方向）本质上是一个**非对称箭头对**：m → n，其中 m 是主元，n 是从元。箭头方向永远从主指向从。 |
| **n（应用）** | 用箭头拓扑区分 `zx` 和 `xz`——前者是 Z 主 X 从，后者是 X 主 Z 从。箭头方向不同，本质不同 |

## 十元理论应用规则

> **规则 R34（主从箭头）**：每个派生十元可以表达为一个箭头：`主元 ─方向─→ 从元`。`zx` = `z ─x方向─→ x`，`xz` = `x ─z方向─→ z`。
>
> **规则 R35（方向标签）**：箭头上的标签"方向"确定了从元以什么方式被驱动——`zx`中 x 被 z 驱动来"突破"，`xn`中 n 被 x 驱动来"管理"。
>
> **规则 R36（箭头不可交换）**：`zx ≠ xz`。如果你把箭头反转，得到的是完全不同的派生十元。

## 主从箭头的拓扑表示

```
zx (Z主X从)：        xz (X主Z从)：
  z ──x驱动──→ x       x ──z驱动──→ z

zn (Z主N从)：        nz (N主Z从)：
  z ──n驱动──→ n       n ──z驱动──→ z

nx (N主X从)：        xn (X主N从)：
  n ──x驱动──→ x       x ──n驱动──→ n

全元（原点）：
  (无箭头)          所有方向的平衡态，箭头拓扑为"空"
```
