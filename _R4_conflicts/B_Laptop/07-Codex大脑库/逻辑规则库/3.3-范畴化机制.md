# 范畴化机制

## 原版概括

大脑如何将具体经验归入抽象类别？侯世达认为**范畴化不是匹配"固定原型"，而是动态激活"概念的核心—边缘结构"**：

- **核心（core）**：不可动摇的本质属性（如果缺失，这个概念就不成立）
- **边缘（periphery）**：可变的上下文相关属性（在不同场景下可以被忽略或替换）

例如"母亲"概念的核心是"生育或养育关系"，边缘包括"性别女、成年人、有子宫"等——这些边缘属性在某些上下文中可以被突破（如养母）。

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | "他是 Z 型"——这个判断意味着他表现出 Z 的"核心"特征，但不一定表现出 Z 的所有"边缘"特征 |
| **z（本质）** | 每个十元命格的范畴化应该区分**核心属性**（不可动摇）和**边缘属性**（可变）。当一个人被标定为 Z 型时，他必须满足 Z 的核心属性，但可以缺失部分边缘属性。 |
| **n（应用）** | 为每个十元命格制定"核心属性清单 vs 边缘属性清单"，避免"他有点 Z 但又不完全 Z"这种模糊判断 |

## 十元理论应用规则

> **规则 R41（核心-边缘分离）**：每个十元的定义必须明确标注：哪些属性是核心（缺失则不能归入此类），哪些是边缘（缺失不影响归类）。
>
> **规则 R42（归类门槛）**：一个人要归入某个十元命格，必须满足该命格的全部核心属性。边缘属性满足 50% 以上即可。
>
> **规则 R43（家族相似性）**：同一根基的不同派生（如 zx 和 zn）共享该根基的核心属性，但因为方向不同而有不同的边缘属性。

## Z 命格的核心-边缘示例

```
Z（执念根基）
  核心属性：
    - 能量驱动型（非理性驱动）
    - 自我意志投射
    - 时间方向指向"往前/突破"
  
  边缘属性：
    - 外显强度（Z可以低体量而存在）
    - 破坏性（Z可以表现为建设性的"我要这样"）
    - 不可控性（高体量Z不可控，低体量Z可控）

zx（突破行动）
  核心属性（在Z的基础上追加）：
    - 主动向外部释放能量
    - 目标导向（有一个明确的"去做什么"）
  
  边缘属性：
    - 成功或失败（zx的"突破"失败了仍然是zx）
    - 是否被接纳（zx不依赖外界反馈来定义自身）

zn（精神信念）
  核心属性（在Z的基础上追加）：
    - 向内部凝聚能量
    - 意义导向（不是"去做什么"，而是"相信什么"）
  
  边缘属性：
    - 是否被验证（zn的"信念"不需要证据支撑）
    - 是否影响行为（zn可以只存于内心）
```
