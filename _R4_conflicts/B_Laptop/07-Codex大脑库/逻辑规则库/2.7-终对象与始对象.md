# 终对象（1）与始对象（0）

## 原版概括

**终对象（Terminal Object）**：记作 1，对任意对象 A，存在唯一箭头 A → 1。
- 在集合范畴 Set 中，终对象是**单点集**（singleton）{*}
- 终对象的"元素"（global elements）等价于从 1 到 A 的箭头，这给了你"把元素当箭头"的视角

**始对象（Initial Object）**：记作 0，对任意对象 A，存在唯一箭头 0 → A。
- 在 Set 中，始对象是**空集** ∅
- 空集到任何集合都有唯一箭头——"真空的函数"

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | 你的"全元/原点"概念——在十元范畴中，它接近**终对象和始对象的统一体**：从全元出发到任何十元都有唯一箭头，任何十元到全元也有唯一箭头 |
| **z（本质）** | 全元 = 十元范畴中的**零对象（zero object）**——既是始对象又是终对象。这解释了你为什么把全元称为"原点"：它不像其他十元那样有方向性，而是所有方向的起点和终点。 |
| **n（应用）** | 全元的"中性"不是空无，而是**结构上的零对象属性**：从全元到任何命格的箭头是唯一的（没有歧义的起始状态），从任何命格到全元的箭头也是唯一的（回归平衡） |

## 规则

> **规则 R47（全元=零对象）**：全元在十元范畴中是零对象（既是始对象又是终对象）。这意味着：从全元出发到任何十元的箭头唯一，从任何十元回到全元的箭头也唯一。
>
> **规则 R48（全元不是"缺失能量"）**：全元不是"弱"或"空"——它是结构上的原点，类似于数学中的空集（0）和单点集（1）的统一。

## 十元范畴的零对象图示

```
    全元 (1/0)
    ↗  ↓  ↖
   /   |   \
  zx  nz   zn ...
  (从全元到任何十元的箭头：唯一——"从原点出发"只有一种方式)
  
  zx  nz   zn ...
   \   |   /
    ↘  ↓  ↙
    全元 (1/0)
  (从任何十元到全元的箭头：唯一——"回归原点"也只有一种方式)
```
