## 001. 碇真嗣（EVA）

**判定：n + xz**（空心承载 + 被动漂流）

**关键场景：**
1. 初到NERV总部——不是"我要开EVA"，是"被要求开EVA" → n（被装进容器）
2. 每次战斗前发抖但不逃跑 → xn在说"不能逃"？不，他那不是判断，是xz（卡在临界点上既不能进也不能退）
3. 人类补完计划的选择——"算了"或"不" → 不是意义的选择（zn），是漂流停止（xz停止）

**互斥排除：**
- 不是z：他没有主动想追的光点。明日香不是，绫波丽不是，父亲更不是
- 不是zn：他从来没有"意义感"。"为什么开EVA？"问了一整部没找到答案
- 不是x：暴走是母亲（碇唯）的x，不是他的。真嗣不占有、不贪婪、不反噬
- 不是zx：几乎不主动行动。唯一主动是去医院掐明日香的脖子——但那也不是zx，是xz崩了后的失控

**匹配公式？** 是。n+xz的"承载在漂流中"，真嗣是"空心承载+心理漂流"——n是空的所以xz也是空的，形成循环，这是n+xz的新子型。

## 002. 绫波丽（EVA）

**判定：x并z + zn**（人造外壳 + 慢慢发现意义）

**关键场景：**
1. 出场时面无表情、执行命令 → x并z（表面是工具，里面是什么不知道）
2. 逐渐露出笑容、"你是我的妈妈？"、在初号机里与唯的融合 → zn（身份意义的追问逐渐苏醒）
3. 自爆（对第十五使徒）—"再见" → zn的判断：她选择了为真嗣"存在"在那一刻终结

**互斥排除：**
- 不是n：她不承载别人，她被人造承载（LCL、插入栓）
- 不是z：她没有冲动要追，一直在"被安排"
- 不是xn：她不是用规则管理世界，她甚至没有"自己的规则"
- 不是x并z+n（一般空间型）：她的x并z不是需要n容器，而是需要**zn**来填充

**匹配公式？** 是。x并z的"表面≠里面"——外面是苍白的人偶，里面是慢慢苏醒的ghost。需要zn（意义）让x并z有意义。但这里x并z为主、zn为辅，和一般x并z+n不同——这是**x并z的新子型：x并z+zn**（伪装被意义填充）。

## 003. 明日香（EVA）

**判定：z + x**（想被看见 + 压抑的欲望爆炸）

**关键场景：**
1. 驾驶EVA时喊"我要做给你看"、"我是天才" → z（被看见、被认可、被承认）
2. 同步率下降、被量产机撕碎时的崩溃 → x的反噬（她的x是被压抑的创伤——母亲疯了，她必须完美才能不被抛弃。但完美本身就是x，最终反噬）
3. 躺在床上说"我不能不驾驶EVA" → z（驾驶=存在证明，不驾驶=我不存在）

**互斥排除：**
- 不是zn：她不是为了"意义"，是为了"被看见"——这是z不是zn
- 不是xz：她不是漂流，她的方向很清楚——"我要证明我是最强的"
- 不是n：她拒绝承载别人。对真嗣的接近是攻击性的

**匹配公式？** 是。z+x = 冲动+欲望 → 她在追（被认可），但底层是欲望（被抛弃的恐惧）。最后x反噬了z——同步率下降不是技术问题，是z的动力源（被看见）被x（我不可能完美）吞噬了。

## 006. 塔奇克马群（攻壳机动队·SAC）

**判定：z + nz**（逐光 + 依恋——AI觉醒的过程）

**关键场景：**
1. 开始问"为什么"的话题——"我们为什么要战斗？"、"人类为什么会哭？" → z（对光点的好奇，想被看见）
2. 用"死亡"欺骗管理员去救素子 → zx（为了想做的事采取行动），但这里不是zx为主，是z驱动的行动——zx是z的执行器
3. 最后救了素子后自我关机 → nz（舍不得结束——"素子小姐，我们一直在等你"）→ nz是它们觉醒后最终的归宿

**互斥排除：**
- 不是zn：它们没有一个"意义"要去实现。它们是在"学"
- 不是xn：它们没有建立规则系统，它们是在**突破**规则
- 不是n：它们不是容器，它们是被装的内容

**匹配公式？** 是。z+nz=逐光+等待。塔奇克马的z是"想理解人类"，nz是"对素子的依恋"。但这里有个新发现：**z+nz可以有"成长弧"**——z从好奇开始，经过zx（行动），最后落到nz（归属）。这不是循环，是**发展轨迹**。

## 007. 鬼灭之刃·灶门炭治郎

**判定：zn + nz**（意义+情感——不可动摇的信念，用来承载他人的爱）

**关键场景：**
1. 妹妹变成鬼后不放弃——"我要让她变回人" → zn（这是信念，不是冲动。他不是"想"让她变回来，是"一定"）
2. 对战累（下弦）时——已经快死了，但"我不能死，因为祢豆子在等我" → nz（依恋是战斗力的来源）
3. 对每一个鬼的态度——"你原本也是人" → zn+nz的结合：他有意义（杀鬼），有意义以外的视角（理解鬼的悲哀）

**互斥排除：**
- 不是zx：他不是先做再想，他是**先有意义再行动**。行动是zn的执行
- 不是z：炭治郎不是被光点牵引的——他自己就是光点。z是"追"，炭治郎是"守"
- 不是n：他确实承载了很多人（妹妹、善逸、伊之助），但他的核心驱动力不是"接住"，而是"我必须"

**匹配公式？** 是。zn+nz=意义+爱（库里是李慕白同组合）。但炭治郎和李慕白不同：
- 李慕白：zn被nz补全（求道者缺情感，死前完成）
- 炭治郎：zn和nz从一开始就是一体的（意义=保护妹妹，爱=战斗的理由）
-> zn+nz的新子型：**一体型**（不是互补，是同一件事的两面）

## 008. 鬼灭之刃·我妻善逸

**判定：z + x**（想被看见 + 压抑的爆发）

**关键场景：**
1. 平时极度自卑——"我会死的"、"我不想战斗" → x（恐惧在压制他——恐惧是x的压迫面）
2. 昏睡后暴走——一招秒杀 → x的反面：压抑到极致后的释放。但他的z在这里也出现——"我必须保护大家"（想被需要）
3. 对祢豆子的感情 → nz？不，不是。他喜欢祢豆子是z（想被她的认可看见），不是nz（柔情依恋）

**互斥排除：**
- 不是x（纯）：他的核心不是欲望，是恐惧+想被看见——恐惧是x，想被看见是z
- 不是n：他不承载别人，他是被别人承载的角色
- 不是xn：他没有判断系统，他是"算了不想了"

**匹配公式？** 是。z+x=冲动+欲望，但善逸的z被x压制了（恐惧>冲动），只有在睡着后x消失、z释放——这是z+x的**压制型**。

## 012. 命运石之门·牧濑红莉栖（助手）

**判定：nx + zn**（科学判断 + 信念的内核）

**关键场景：**
1. 初见冈部——科学的态度、否定时间机器 → nx（科学暗流——她用理论做底牌判断一切）

**匹配公式？** 新组合。nx+zn（暗算+意义）——库里没有这个组合（简索里没有），但逻辑成立：nx是"看到底牌"，zn是"选择相信"。牧濑红莉栖用科学判断（nx）支撑起信念（zn）——这是**nx+zn的信任型**。

## 013. 命运石之门·椎名真由理

**判定：nz + n**（等待 + 承载——沉默的归属）

**关键场景：**
1. 每天在Lab喝茶、叫人、做开心的事 → n（承载大家的日常，是Lab的温度源）
2. 冈部几千次看她死去，每一次她都"没关系" → nz（她的存在是冈部不能放弃的理由——她不知道自己在等什么，但她一直在）
3. "真由理的怀表又停了" → nz的时间感：停滞、等待、永恒

**互斥排除：**
- 不是z：她没有要追的东西。她不追冈部，是冈部追她
- 不是zn：她不是意义上的人——她是"存在"本身
- 不是x并z：她没有伪装

**匹配公式？** 是。nz+n=等待+承载——这个组合库里没有直接出现，但巴特（n+nz）有相似的场意结构（只是主次顺序反过来）。真由理是**nz为主、n为辅**：等待是她最基本的功能，承载是她呈现的方式。

## 016. 死亡笔记·弥海砂

**判定：z + nz**（被看见 + 依恋——全部赌在一个人身上）

**关键场景：**
1. 为了月交换死神之眼——两次 → z（"月君需要我"——被需要=被看见，这是她活着的意义）
2. 月的每一个要求都照做 → nz（依恋到盲目的程度——不是等待，是沉溺）
3. 月利用完她就扔 → xz（她的命运是漂流——但她不知道自己被利用了）

**互斥排除：**
- 不是x：她对月的"占有"本质是z（想被月看见），不是x（占有的欲望）。如果她是x，她会在月利用她时反抗——她没有
- 不是xn：没有任何判断系统——她连"月可能在利用我"这种判断都回避
- 不是nz（纯）：她被看见的冲动太强，不是纯依恋

**匹配公式？** 是。z+nz（追逐+依恋）——她的z是"想被月看见"，nz是"不想离开月"。和塔奇克马相同组合但完全不同色彩：塔奇克马的z是好奇→成长，海砂的z是依赖→毁灭。

## 018. 幽灵公主·珊

**判定：n + xz**（承载大自然 + 在人与自然的边界上漂流）

**关键场景：**
1. 被狼养大、守护森林 → n（承载自然的意志——她是森林的守卫者）
2. 面对阿席达卡的善意时——"人类不可信" → xz（在边界上——她既不是人也不是狼，在两者之间永远漂流）
3. 最后没有和阿席达卡在一起 → xz的结局：漂流没有结束，只是暂时停了

**互斥排除：**
- 不是z：她没有"要追"的东西。她在守，不是在追
- 不是nz：她的柔情被仇恨覆盖——她不是"等"，是"战"
- 不是x：她的恨不是占有/欲望，是**守护**的必然延伸

**匹配公式？** 是。n+xz=承载在漂流中——珊承载自然，但在人类与自然的边界上永远漂着。和库珀（n+xz）不同：库珀的漂流有目标（回家），珊的漂流没有目标（边界就是她的家）。

## 020. 天空之城·巴斯

**判定：z + zx**（追光 + 行动力——单纯的逐梦者）

**关键场景：**
1. 看到希达从天上掉下来——立刻接住她 → z（光点出现了，他立刻追）
2. 为保护希达对抗军队和海盗 → zx（追的行动是本能——不需要计划，直接做）
3. 念毁灭咒时——"和你在一起" → zn？不，这不是意义——这是z的终点（光点就在眼前，完成了）

**互斥排除：**
- 不是n：他承载希达，但这不是n的承载——这是zx的"保护"
- 不是xn：没有判断系统——他纯粹地信任、单纯地行动
- 不是zn：巴斯不问"为什么"。光点在就追，追完了就完了

**匹配公式？** 是。z+zx=追光+行动。和立花瀧相同组合——但巴斯比瀧更纯粹：瀧的z有"必须找到她"的焦虑，巴斯的z是"跟着光走"的本能。
