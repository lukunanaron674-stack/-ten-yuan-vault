## 021. 降临·露易丝·班克斯

**判定：zn + nx**（意义 + 看到了底牌后选择相信）

**关键场景：**
1. 学外星语言——不是"我要知道它们在说什么"，是"我要知道为什么" → zn（意义驱动，不是任务驱动）
2. 学语言后看到非线性时间——她知道女儿会死、丈夫会离开 → nx（看到了底牌——所有的信息她都有了）
3. 依然选择生下女儿 → zn的完成：知道结局，依然选择走进去

**互斥排除：**
- 不是zx：不是先做再说。她先学了、懂了、看到了——然后选择走进去。这是选择了之后的"做"，不是zx的无脑行动
- 不是xn：建立语言系统是工具，不是她的本质
- 不是nz：她不是在等谁。依恋不是她的核心

**匹配公式？** 是。zn+nx——意义被"知道结局"挑战。库里没有这个组合的案例（首个）。

## 023. 肖申克的救赎·瑞德

**判定：xz + n**（一开始在体制内漂流，后来被承载）

**关键场景：**
1. 在监狱四十年——"这里让我觉得我是个重要的人" → xn？不，他是在**适应**监狱（xz——在体制的边界上活下来）。xn是监狱本身，不是他
2. "希望是危险的东西" → xz的判断——他不敢要希望，怕被失望击碎
3. 出狱后不适应→差点自杀 → xz（出了边界才发现自己只能在边界内活）
4. 最后去芝华塔尼欧找安迪 → n（被安迪承载——最后的归属感）

**互斥排除：**
- 不是xn：他不是建立规则的人，他是**被规则驯化**的人
- 不是n（开头）：第一幕他不想承载任何人，只想活到出狱
- 不是nz：他等过什么吗？没有。他只是活着

**匹配公式？** 是。xz→n（从漂流到承载——动态变化）。瑞德是xz的子型：**体制化型漂流**——不是在物理空间漂流，是在制度里被驯化到失去自我。

## 027. 星际穿越·墨菲

**判定：zn + nx**（意义 + 解码——和露易丝相同的组合，不同的应用）

**关键场景：**
1. "我爸不会抛下我" → zn（信念——她相信库珀会回来，即使所有人说不会）
2. 研究引力方程 → nx（解码宇宙的底牌——她在算，不是在想）
3. 最后在书架上发现"STAY"——是库珀留给她的 → zn+nx同时成立：她解码了（nx）父亲给她的信息（zn的信念被验证）

**互斥排除：**
- 不是xn：她不是建立制度。她是在解码宇宙的规则，不是创造规则
- 不是z：她的驱动力不是冲动——是**信念**
- 不是x：不占有、不反噬

**匹配公式？** 是。zn+nx——和露易丝相同组合。不同点：露易丝的nx是"看到了结局"，墨菲的nx是"解码了信息"——**nx有不同的子型**。

## 028. 盗梦空间·柯布

**判定：z + nz**（执念 + 放不下——这就是他的核心冲突）

**关键场景：**
1. 躲藏多年、避开通缉 → z（"我要回家"是光点，不是意义——他不问"为什么回家"，他就是要回）
2. 梅尔的投影一直在——他在梦里保留了她 → nz（放不下、舍不得结束——即使那是幻象）
3. 最终放下梅尔、回到现实 → z完成了（他回家了），nz被"切断"了（他在旋转陀螺面前离开）

**互斥排除：**
- 不是zn：柯布不问意义。他的目标很具体（回家），不是抽象的信念
- 不是zx：他的行动是**被迫的**（被斋藤推着），不是自发的突破
- 不是xn：他没有建立规则管理梦境——阿里阿德涅（迷宫设计师）做的是xn，不是他

**匹配公式？** 是。z+nz=追光+等待。但这里不是z在追的时候nz在等——而是**z在追一个目标，nz在拉他回到过去**。所以z+nz可以是**冲突性组合**：z往前，nz往后，撕裂。

## 031. 搏击俱乐部·泰勒·德顿

**关键场景：**
1. 炸大楼、建立搏击俱乐部 → zx（先做再说，每件事都是突破）

3. 最后杰克开枪打了自己——泰勒消失 → x被zn（杰克找到的自我意义）消灭了

- 不是zn：没有意义——毁灭不需要意义
- 不是zx（纯）：他的zx服务于他的x——先做再说，做的是释放欲望的事

**匹配公式？** 是。x+zx=欲望+行动（铁雄相同组合）。泰勒和铁雄的区别：铁雄是被力量吞噬的弱者（不想但撑不住），泰勒是主动拥抱毁灭的强者（想要，这就是我）。

## 033. 美丽人生·圭多

**判定：z + x并z**（冲动+伪装——用欢乐包装恐惧，保护孩子）

**关键场景：**
1. 追多拉——从屋顶浇水、假扮督学 → z（被光点（多拉）牵引，不按常理出牌地追）
2. 集中营里——"这是一场游戏，第一名得坦克" → x并z（用谎言包装现实——这不是恶意伪装，是爱的伪装）
3. 最后让约舒亚藏在铁箱里——自己演士兵被带走 → x并z到最后一刻——伪装是保护

**互斥排除：**
- 不是n：他不是在承载别人——他是在**骗**别人（保护性的骗）
- 不是zn：他不需要意义——他只需要"多拉"和"约舒亚"好好的
- 不是zx：他的行动不是突破——他的行动是**表演**

**匹配公式？** 是。z+x并z=冲动+伪装——库里没有这个组合。理解方式：z让他去追、去保护，x并z让他用"包装"来实现保护。这是**爱的x并z**——和市子（n+x并z）的"用表象包裹真实"同根但不同花：市子的x并z是"面对"，圭多的x并z是"保护"。

## 034. 被嫌弃的松子一生·川尻松子

**关键场景：**
1. 小时候扮鬼脸让父亲笑 → nz（用附属的方式换取温情，这就是松子所有的行为公式）
2. 每一段感情——作家、理发师、黑道男友 → nz（她等他们给她"爱"），但对方全是x（欲望、暴力、利用）→ nz被x反复碾压

## 035. 阿甘正传·阿甘

**判定：n + z**（承载+被冲动推着走——但他接住了所有被推向他的人和事）

**匹配公式？** 是。n+z=承载+冲动。阿甘是被z推（跑、参军、捕虾），用n接住（接珍妮、接布巴的愿望、接儿子的抚养权）。和娜乌西卡（n+z）相同组合——但娜乌西卡的z是"举起来的力量"，阿甘的z是"被推着跑的惯性"。

## 036. 教父·维托·柯里昂

**判定：n + x**（承载家族 + 用暴力保护——"我会给他一个无法拒绝的提议"）

**关键场景：**

## 037. 教父2·迈克·柯里昂
