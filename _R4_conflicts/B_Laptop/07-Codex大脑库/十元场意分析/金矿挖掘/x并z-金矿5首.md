# x并z 金矿 · 伪装/包装型

x并z的难点：最难自己成金矿的十元——因为"包装"需要包装底下的东西——如果底下没有金矿级的zn/x/nz把它撑起来,包装就只是包装。

## x并z-金01. YOASOBI — 《アイドル》

- 克制关系不可替换？✅ YOASOBI的极致编曲+アイドル主题——换一个歌手唱"我愛你"就不是偶像包装——是表白
- 无一笔浪费？✅ 每八拍都不一样——"包装"需要精致——精致就不允许空白
- 结尾呼应开头？✅ 开头"アイドル"——结尾"アイドル"——但开头是"我是偶像所以我会说爱你"，结尾是"我装得太好了所以我爱你是真的吗？"
- 选择与失去同步？✅ 越精致——同步失去"真实"的可能。包装越完美，越不可能卸妆

**动态链：** x并z(包装/偶像的表演) → zn(底下真的有"我"吗) → x(被消费/欲望被看见了) → zn空心(包装还在，"我"没了)

**总分：3/3 ✅ 金矿**
