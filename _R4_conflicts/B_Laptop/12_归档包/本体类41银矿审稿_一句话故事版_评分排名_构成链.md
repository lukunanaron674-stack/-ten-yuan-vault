## 6. 可直接用于创作的高分种子

### 种子1｜表象夺身

```text
一个人被自己被观看出来的外壳替换，必须抢回“谁才是真我”的资格。
```

来源：《未麻的部屋》  
链条：`x并z外壳 → 观看反噬 → nx审查失稳 → zn+x崩裂`

### 种子2｜制度切身

```text
一个人被制度切成两个互不相识的自我，两个半身最终都发现自己不是完整的人。
```

来源：《人生切割术》  
链条：`xn制度切割 → x并z职业外壳 → 双我断裂 → zn+x反咬`

### 种子3｜作品吞生

```text
一个创作者为了证明自己活过，把生活做成作品，最后作品取代了他的生活。
```

来源：《纽约提喻法》  
链条：`x并z作品外壳 → 生活作品化 → xn无终排练 → zn+x被替换`

### 种子4｜意识残余

```text
当身体、记忆、来源都能被制造，一个人只能用选择证明自己仍然算人。
```

来源：《攻壳机动队》《银翼杀手2049》《机械姬》《月亮》  
链条：`xn制造/义体制度 → nx记忆审查 → 可替换外壳 → zn+x自证`

### 种子5｜非人生成主体

```text
一个本来只是外壳的非人存在，在身体经验里第一次长出“我”的感觉。
```

来源：《皮囊之下》  
链条：`x并z外壳 → xz漂流 → 身体经验 → zn+x萌生`
