# 15步模板分析：「牺牲（Sacrifice）」——完整映射强度分析

## 1. 一句话定义

**牺牲 = 为某个目标/意义/他人而让渡自身所有物（时间、资源、身体、尊严、生命）——是有方向的自愿或不自愿损失。核心不是失去本身，而是"失去为了什么"。**

- 主动牺牲：有方向的自愿让渡（zx主导）
- 被动牺牲：被外力迫夺（x主导）
- 日常牺牲（付出）：小范围、可接受的持续让渡（n/zn支撑）

---

## 2. 三元粗拆（x/z/n）

| 三元面 | 对应内容 | 说明 |
|:-----:|:--------|:-----|
| **x** | 被吞噬之物、损失的物质面 | 牺牲中"被拿走"的部分——时间、资源、身体、生命、机会。现象之流中的损耗 |
| **z** | 为何牺牲的冲动、执念 | 驱动牺牲行动的能量——爱、恨、信仰、责任。有边界的执念让人"愿意" |
| **n** | 承载牺牲的主体、日常付出的容器 | 承受持续让渡的"基底"——为家庭付出的父母、为工作妥协的普通人 |

---

## 3. x/z/n 分别细化为十元候选

### x面细化

| 十元候选 | 理由 |
|:-------:|:-----|
| **x〔锚点〕** | 被吞噬之物——牺牲中"被拿走的"就是x本体：时间、金钱、资源、精力、身体。现象之流中被消耗的那部分 |
| **xz** | 被动牺牲的临界面——被外力逼迫的牺牲，"不牺牲就活不下去"的临界选择。结构性压迫下的被迫让渡 |
| **nx** | 牺牲的结算——算账式的牺牲，"我给了你多少，你欠我多少"。有借有还的牺牲 |
| **zx** | 执行牺牲的动作——"我决定给出"。主动让渡的行为本身 |

### z面细化

| 十元候选 | 理由 |
|:-------:|:-----|
| **z** | 牺牲的冲动——"我愿意"背后的原始驱动力。爱到愿意失去、恨到愿意两伤。无私冲动和毁灭冲动是一体两面 |
| **zn** | 牺牲的意义——"这样做是对的"、"值得的"。意义赋予牺牲以方向，没有zn的牺牲只是损耗 |
| **nz** | 牺牲的依恋——"为了等到ta回来"、"为了守住这个"。守望型的持续付出 |

### n面细化

| 十元候选 | 理由 |
|:-------:|:-----|
| **n** | 承载牺牲的容器——日常付出的基底：父母为孩子持续让渡、打工人为家庭承受消耗。n的承载是牺牲的最小单位 |
| **xn** | 牺牲的规则化——社会规则要求你牺牲："孝道要求"、"职业道德"、"集体利益高于个人" |
| **x并z** | 牺牲的表演——"看，我为你牺牲了这么多"。把牺牲变成叙事工具，用付出索取认可 |

## 4. 体量 1-10

**体量 = 9.0**

牺牲不是局部概念——它覆盖了人类经验的三个层次（主动/被动/日常），与生、死、爱、战争等底层结构紧密耦合。从父母为孩子省下一个蛋的日常付出，到殉道者的完整生命让渡，牺牲横跨从最小到最大的损失光谱。但牺牲不是底层操作单元（比欲望/死亡低半层），它是**方向性让渡**——是已有所有物的重组游戏，不是源动力。

## 10. 跑动态链

### 主链（正向生成——牺牲的完成路径）

**zx〔9〕→ zn〔8〕↔ x〔8.5〕→ n〔7〕**

```
  zx（执行牺牲）
   │ 生〔8.0〕
   ↓
  zn（牺牲的意义）
   │ 补〔8.5〕──↔── x（被吞噬之物）
   │                     │
   │                生〔7.5〕
   ↓                     ↓
  n（日常承载——扛住后果）
```

**路径解释**：
1. zx决定了"做"的主动面——没有zx，牺牲只是被抢
2. zx执行之后产生zn——意义从行动中溢出（**zx生zn 8.0**）
3. zn与x之间是牺牲最核心的补关系（**zn↔x 8.5**）——损失越大意义越重，意义越大损失越被接受
4. zn补到x后，x的损失被承载到日常n（**zn生n 7.5**）——意义撑住了代价

### 克链（压制/反抗——牺牲的耗竭路径）

**x〔8.5〕→ z〔8〕→ zx〔9〕→ n〔7〕**

```
  x（被吞噬之物积累）
   │ 克〔7.5〕
   ↓
  z（冲动被消磨）
   ├─ 冲动枯竭 → 牺牲停止
   ├─ 或 →
   │    z 克 nx〔7.0〕→ Nx算账逻辑打破
   │                     → "我不要再牺牲了"
   ↓
  zx（执行牺牲的甲板塌陷）
   │ 克〔7.0〕
   ↓
  n（日常承载被压垮——牺牲者的耗竭崩盘）
```

**路径解释**：
1. x积累到一定阈值开始克z——损失过大消磨原始冲动
2. z被克后有两种可能：要么枯竭停止牺牲，要么用z打破nx算账逻辑
3. 如果继续执行牺牲（zx），zx克的n中的日常承载——过度执行压垮了主体的存续能力
4. 牺牲者耗竭——不是不愿意牺牲了，是"已经没什么可以牺牲的了"

### 补链（互济——牺牲的延续路径）

**xz→zn（克）→ zn→n（生）→ n→xn（生）→ xn→xz（生）→ 循环**

```
  xz（被动牺牲）
   │ 克〔7.5〕zy
   ↓
  zn（意义被质疑）
   │ 要么意义崩塌 → 牺牲无意义
   │ 要么
   │ 生〔7.5〕
   ↓
  n（日常承载——扛住没有意义的牺牲）
   │ 生〔6.0〕
   ↓
  xn（规则保护——"不行，不能这样了"）
   │ 生〔6.5〕
   ↓
  xz（新的被动牺牲→ 结构产生新的临界者）
```

**路径解释**：
1. 被动牺牲（xz）一开始克zn——"凭什么是我"摧毁意义
2. 但n（日常承载）在意义部分坍塌时还能扛一阵（zn生n的惯性）
3. 扛久了产生制度需求（n生xn）——社会规则被创造来减少被动牺牲
4. 但制度本身又制造新的被动牺牲者（xn生xz）——保护规则不可能覆盖所有人

这是一条"不得不走但走不出去"的循环链——**牺牲的制度化减少了个体牺牲却制造了结构牺牲**。

| **命运型** | xz + nz | **7.0** | 被动牺牲和守望付出是牺牲的重要但非核心维度 |
| **时间型** | xn + z | **6.0** | 规则化牺牲和冲动牺牲在场但非主导 |
| **空间型** | x并z + n | **5.5** | 表演和日常承载的边缘存在 |

### 归仓排序

```
因果型(9.0) > 本体型(8.5) > 命运型(7.0) > 时间型(6.0) > 空间型(5.5)
```

## 14. 误判检查

| 误判类型 | 自查 | 纠正 |
|:--------|:-----|:-----|
| **把行为当本质** | 牺牲表现为"失去"行为 → 推到x？ | ❌ 牺牲的本质不是失去，是"有方向的让渡"。失去是x，但牺牲的核心是zx（执行让渡）+ zn（让渡的意义）。仅x的"失去"只是亏损 |
| **把局部当整体** | 崇高牺牲=zn主导 → 牺牲=zn？ | ❌ 日常妥协式的"付出"（父母省钱、工作忍让）不含显著zn，但确实是牺牲。n（日常承载）也是牺牲的重要形态 |
| **把意象当结构** | 牺牲=流血/死亡 → 牺牲的结构=死亡 | ❌ 死亡是牺牲最激烈的形式，不是结构。日常牺牲可能只是让出几块钱、少睡一小时——结构的核心是zx执行让渡 |
| **主动×被动混淆** | 牺牲=自愿 | ❌ 被动牺牲也是牺牲——被抢走的和被献出的在"失去"层面相同。区别在于xz（被临界）而非zx（主动执行）。文件通过zx(9)和xz(6.5)的强度差已区分 |
| **日常牺牲应归类为n而非zx** | 日常付出的行为不像"决策性"的zx | 但日常付出的每一步都是"决定继续给出去"。n是承载者，但做出"给出去"这个动作的仍是zx——只是zx被降低到了7而非9的版本。zx强度9涵盖了主动决策型牺牲（殉道、献祭），zx强度5-7涵盖了日常维持型牺牲 |

## 15. 封存句（带映射强度版）

**牺牲 = zx〔9〕的主动执行向 zn〔8〕的意义出口 生补 x〔8.5〕的被吞噬之物——核心张力在"为什么给出"（zn↔x 补8.5）与"给出本身"（zx生zn 生8.0）之间。主动牺牲走主链（zx→zn↔x→n 7.9），被动牺牲跌入克链（x→z→zx→n 7.3），日常牺牲由n〔7〕的日常承载支撑。最终主归因果型〔9.0〕> 本体型〔8.5〕——牺牲不是损失，是**有方向的价让渡**。**
