# 概念映射：战争

## 第1步：定义

**战争**：有组织的大规模暴力冲突，通常是国家、民族、政治集团或武装势力之间，为争夺利益、领土、意识形态控制或生存资源而采取的极端对抗手段。其特征是系统性暴力、集体性牺牲、规则破坏与秩序重构。

### 动态链1：战争爆发链（爆发端→暴力端）

```
战争意识形态(zx) →[生8]→ 战争动员机制(zn) →[生9]→ 战争暴力实体(n) →[补7]→ 战争战术执行(nx)

### 动态链2：战争终结链（暴力端→结束端→后遗症端）

```
战争暴力实体(n) ↔[补8]→ 战争创伤与记忆(x∪z)

**描述**：暴力实体与创伤记忆构成双向强化（暴力越大创伤越深，创伤记忆又合法化下一轮暴力），同时战术胜利达成终止条件，终止释放并固化创伤记忆。
