# 15步概念映射：容器（Container）

## 1. 一句话定义

**容器 = 承载·容纳/包裹/存储的空间原型**——不是隔离物（那是墙），不是围合物（那是边界），而是「某物可以在其中存在而不流失」的空间功能单元。容器是空间主题中最基础的原型概念：所有空间关系的基础是「某物容纳某物」。物理容器（盒子/房间/建筑）、社会容器（家庭/社区/国家）、心理容器（记忆/信念/人格）共享同一个底层结构——能装、能留、能保护。

---

## 2. 三元粗拆（x/z/n）

| 三元 | 容器在该轴上的表达 | 说明 |
|:----|:----------------|:-----|
| **x** | 容器的形式面——壳、外壳、边界、包装、形状 | 容器作为"被看见的边界"——容器的物理界限、材料、表面、封装方式。没有x面的容器是无形的 |
| **z** | 容器的能量面——容纳行为、边界维护、执行的冲动 | 容器不是被动存在的——它需要被"做出来"（制造/建造）、被维持（维护边界）、被使用（装进去/取出来）。z是容器之所以是"功能"而非"物体"的驱力 |
| **n** | 容器的载体面——承载、容纳、存储、保护 | 容器的本质——能装住东西不流失。n是容器的"存在理由"：一个空的容器仍然是容器，因为它可以承载。n是容器最核心的语义内核 |

**三元定位特征**：容器是n最纯粹的空间表达——容器就是"能装东西的n"。x提供容器的可见边界（壳/包装），z提供容器被使用/被维护的功能动力（装/取/封），但n才是容器之所以为容器的本体——一个没有边界的容器还是容器吗？是，如果它仍然能承载（如引力场、磁场）。一个没有容纳功能的壳还是容器吗？不是，它只是装饰。

---

## 3. x/n/z分别细化为十元候选

### x面细化
| 十元候选 | 与容器的关系 | 说明 |
|:--------|:------------|:-----|
| **x并z** | **容器的解剖面——壳·外壳·边界·包装** | 容器的可见面——让容器"看起来像容器"的东西。盒子有盒壁、房间有墙、国家有边境、记忆有遗忘边界。x并z是容器最容易被"看到"的面——别人首先看到的是壳而不是容纳功能 |
| **x** | 容器被占有/消耗——"这是我的容器" | 容器的物质性诱发占有欲——占有容器不是为了它的容纳功能，是为了"拥有一个容器"的满足感。箱子、房子、领土作为财产对象 |
| **xn** | 容器的规则化——"被规定容量的容器" | 容器被制度化——规定的容量、标准的尺寸、规范的封装。"集装箱"是xn的容器——放什么、装多少、怎么堆叠都被规格化 |

### z面细化
| 十元候选 | 与容器的关系 | 说明 |
|:--------|:------------|:-----|
| **zx** | **容器的执行面——容纳行为·边界维护** | 容器不是天然的——它需要被维护。zx是"执行容纳"的动作——装进去、盖盖子、封口、加固边界。"我把它收入囊中"、"维护国家领土完整"、"守护家庭"都是容器中的zx |
| **z** | 对容器的执念——"我需要一个容器" | 想要一个容器的冲动——"需要一个家"、"需要一个归属"、"需要一个身份"的冲动本身。z驱动了容器的寻找和建造但不等同于容器本身 |
| **nz** | 容器中的等待——"容器在等该来的人" | 容器被"准备好"但还没被使用——空房间等住客、空盒子等礼物、空国家等归属感。nz是容器的"已就绪未填充"状态 |

### n面细化
| 十元候选 | 与容器的关系 | 说明 |
|:--------|:------------|:-----|
| **n** | **容器的核心——承载·容纳·存储·保护** | **容器的本体。** n就是"能装东西的空间功能"。物理容量、心理容量、社会容量——全是n。容器的所有其他面都服务于n的这一核心功能 |
| **xz** | 容器被破坏/穿透——"容器失效" | 壳被打破、边界被突破、容纳功能丧失。"泄漏"（容器坏了）、"入侵"（容器被穿了）、"崩溃"（容器塌了）——容器的反面定义了容器 |
| **nx** | 容器的暗账——"容器里藏了什么" | 容器可以藏东西——看不见的内部就是"暗账的空间"。黑箱、密室、隐藏文件、不可见的心理创伤——nx在容器中表现为"内部不可见的内容" |

## 4. 体量 1-10

**体量：9.5**

容器不是某个十元的附属概念——**它是空间主题的根概念**。所有空间型概念（家、领土、舞台、场所、领域……）都以容器为基础语义。任务上下文明确定义：「容器是空间主题中最基础的原型概念——所有空间关系的基础是'某物容纳某物'」。没有容器就没有空间型——空间型的公式x并z+n本身就是「壳+容器」。

体量9.5的理由：容器跨越三个领域（物理/社会/心理），是n（核心承载）和x并z（壳）和zx（边界维护）的三角融合，且是整个空间主题的原型基石。体量略低于"真理"(10)级但并不比"欲望"(9.5)或"死亡"(9.5)少——因为容器不是抽象理论结构，它是空间存在的先决条件。

## 5. 每个十元点位的映射强度

| 十元 | 映射强度 | 理由 |
|:----|:-------:|:------|
| **n** | **10** | **锚点。** 容器的第一本体——n的定义就是"承载·容纳/包裹/存储"。在十元体系中，n本身就是"容器"的十元化表达。没有n的概念就没有容器——n是容器语义的核心 |
| **x并z** | **9** | **锚点。** 容器的壳——盒子壁、房间墙、国家边界、人格面具。容器必须有边界才能是容器，x并z提供这个边界的可见性。空间型的公式x并z+n就是「壳+容器」——x并z与n配成完整容器 |
| **zx** | **8** | **强。** 容器的执行面——容纳不是被动的，需要维护动作。装进去(zx)、封起来(zx)、加固边界、守护完整性。容器是一个功能系统不是一块惰性材质——zx让容器"工作" |
| **xz** | **6.5** | **可用。** 容器的反面/临界面——容器被穿透/泄漏/崩塌。xz定义了"容器什么时候不是容器"——壳破了、容纳功能失效。xz是容器空间的"失效临界" |
| **nz** | **5.5** | **可用。** 容器的等待状态——空容器准备着。空房间、空盒子、未写入的记忆空白。nz是容器的"待填充张力" |
| **z** | **4.5** | **辅助。** 寻找/建造容器的冲动——"我需要一个家/一个身份/一个归属"。z是容器生成的驱力而非容器本身 |
| **x** | **4** | **辅助。** 容器作为占有对象——领土扩张、收藏癖。容器的物质性被欲望吞噬 |
| **xn** | **3.5** | **弱辅助。** 容器被规格化——标准尺寸、规定容量。这是容器制度的衍生面 |
| **nx** | **3** | **弱。** 容器内部的暗账——藏东西的可计算性。容器内部不可见内容的管理 |
| **zn** | **2.5** | **弱。** 容器被赋予意义——"这个容器代表什么"。但容器不需要意义就能工作 |

**映射强度排序**：n(10) > x并z(9) > zx(8) > xz(6.5) > nz(5.5) > z(4.5) > x(4) > xn(3.5) > nx(3) > zn(2.5)

## 6. 查位置盘生成关系五对

### 补对子（双向）

| 对子 | 容器中的意义 | 强度 |
|:----:|:------------|:----:|
| **n ↔ x并z** | **容器的核心对子。** n（容纳功能）与x并z（壳·边界）互为条件——没有壳的容纳是敞开的（算不上容器），没有容纳功能的壳是装饰。容器=有壳的n=能装的x并z | **10** |
| **xn ↔ z** | 规则化的容器(xn)与建造容器的冲动(z)——规格促成了建设冲动，冲动催生规格 | 4 |
| **zx ↔ nx** | 容器的执行(zx)与容器的暗账(nx)——维护边界的动作与内部不可见内容的管理互济 | 5 |
| **zn ↔ x** | 容器的意义(zn)与容器的被占有(x)——意义赋予容器价值，占有让容器实存 | 3 |
| **xz ↔ nz** | 容器的崩溃(xz)与容器的等待(nz)——"容器坏了就没法等了" 与 "容器等着所以害怕它坏" 的张力互补 | **7.5** |

### 克关系

| 克 | 内容 | 强度 |
|:-:|:----|:----:|
| **n 克 xz** | **容器消解崩溃——稳定的容纳让崩溃不可能** | **7.5** |
| **x并z 克 nz** | 外壳闭合消解等待——"盒子盖上了就不用等了" | 6 |
| **zx 克 n** | 过度维护破坏承载——"管得太死装不下东西" | 5.5 |
| **x 克 z** | 占有欲望压过建造冲动——"我已经有一个了，不需要再建" | 4 |
| **nx 克 x并z** | 暗账击穿壳——"内部的东西太多，壳装不住了" | 4.5 |
| **nz 克 x** | 容器的等待消解占有——"空着就还有希望"克制了"这是我的" | 5 |
| **xz 克 zn** | 容器崩溃否定意义——"容器都坏了还有什么意义" | 6 |

### 生关系

| 生 | 内容 | 强度 |
|:-:|:----|:----:|
| **n 生 x并z** | 容纳功能生出壳——"因为有东西要装，所以需要壳" | **8** |
| **x并z 生 z** | 壳激发建造/维护冲动——"有了壳就想让它完整" | 5 |
| **n 生 xn** | 承载行为制度化——"经常装东西就规定了容量标准" | 3.5 |
| **zx 生 zn** | 维护行为赋予意义——"因为我一直在维护它，所以它有价值" | 3.5 |
| **xz 生 x** | 容器残骸诱发占有——"空壳也能拿来用" | 3 |
| **xn 生 xz** | 规则太死导致崩溃——"制度化的容器僵化到破裂" | 3 |

## 8. 组合关系对子

基于强度≥5的十元（n10, x并z9, zx8, xz6.5, nz5.5, z4.5, x4, xn3.5, nx3, zn2.5），高强度点位为n10, x并z9, zx8, xz6.5, nz5.5，组合核心对子：

| 对子 | 组合 | 在容器中的角色 |
|:----:|:----|:-------------|
| **n ↔ x并z** | 容纳功能+壳 | **核心主轴。** 容器的本体——能装+有边界。没有这对，容器不成立 |
| **n ↔ zx** | 容纳+维护 | 容器的功能性：能装(zx把东西装进去)+能保持(n不让东西流失) |
| **n ↔ xz** | 稳定vs崩溃 | 容器存在vs容器失效的张力——n克xz是容器最关键的防御机制 |
| **x并z ↔ zx** | 壳+维护 | 边界需要被维护——壳的存在要求持续的边界工作 |
| **nz ↔ xz** | 等待vs失效 | 容器在等时最怕坏——nz的柔情与xz的崩塌恐惧的张力 |
| **x并z ↔ nz** | 闭合vs等待 | 壳合上=等待结束——容器闭合与等待状态的互斥关系 |
| **zx ↔ xz** | 维护vs崩溃 | 维护动作本身就是对抗崩溃——"不断修补以防漏出来" |

## 10. 跑动态链

### 主链（容器的形成与运转）

```
n(10) ─生→ x并z(9) ─补→ zx(8) ─生→ zn(2.5) ─生→ n(10)
   │                │                │                │
   │ 容纳需求       │ 壳的存在需要   │ 维护赋予意义   │
   │ 生出壳         │ 被维护         │ 意义回归承载   │
   │ "有东西要装   │ "壳被打破了    │ "这个容器是    │
   │  所以需要容器"  │  需要修补"    │  重要的，要    │
   │                │                │  好好保存"     │
   └─ 容器诞生 ────┴─ 容器运转 ────┴─ 容器升华 ────┘
```

**容器的主链**：容纳需求(n)生出壳(x并z)→壳的存在需要被维护(zx)→维护动作产生了对容器意义的认知(zn)→意义让容纳行为更稳定(n的增强)。这是容器从"原始容纳"经过"边界的建立与维护"到"容器具有了超越功能的价值"的完整路径。

链强度：(10 + 8 + 9 + 7 + 8 + 3.5 + 2.5 + 3.5 + 10) / 9 = **6.9**

### 克链（容器的危机与失效）

```
xz(6.5) ─被克→ n(10) 失效       xz(6.5) ─克→ zn(2.5)
   │                │                │                │
   │ 容器面临       │ 但承载仍在     │ 崩溃否定意义   │
   │ 崩溃风险       │ 坚持           │ "容器都坏了    │
   │ "壳裂了"       │ "还能装"       │  还有意义吗"   │
   │                │                │                │
   │      └── n克xz 7.5 ──┘         └── xz克zn 6 ──┘
   │                                         │
   │                                         ▼
   │                                  zn被否定 → n失去意义 → 容器瓦解
   │                                         │
   └─────── 如果n克xz失败 → xz侵蚀全部 ──────┘
```

**容器的克链**：容器面临失效临界(xz)但被n的承载力度暂时压制(n克xz7.5)。如果压制不住，xz的崩溃力蔓延到zn(意义)"容器都坏了还有什么意义"——意义的丧失进一步侵蚀n(承载的意志)，最终容器瓦解。

另一种情景：x并z(9)克nz(5.5)时——壳闭合得太彻底，等待的状态被消解。"盒子盖上=不再等任何人"，容器从"有人用的活容器"退化为"封存的无主容器"。

链强度：(6.5 + 7.5 + 10 + 6 + 2.5) / 5 = **6.5**

### 补链（容器的互济循环）

```
n(10) ↔ x并z(9) ────→ zx(8)
   │                  │
   │ 容纳(10)         │ 壳需要维护(8)
   │ 与壳(9)          │ 维护需要容纳(10)
   │ 互为条件         │
   └── 补10 ────┘     │
                       │
                       ▼
          zx(8) ↔ xz(6.5)
            │       │
            │ 维护   │ 维护本身对抗崩溃
            │ 动作   │ "一直在修就不会坏"
            │ 抵抗   │
            │ 崩溃   │
            └── 补7 ─┘
                       │
                       ▼
          xz(6.5) ↔ nz(5.5)
            │       │
            │ 坏掉   │ 等待让崩溃更可怕
            │ 的恐惧 │ 崩溃让等待更珍贵
            │ 与等   │
            │ 待的   │
            │ 交替   │
            └── 补7.5 ┘
```

**容器的补链**：n↔x并z（补10）是容器最根本的互济——有壳才能容纳，能容纳才有壳的意义。这组互济流向zx(8)——壳需要维护才能持续工作。zx↔xz(补7)——维护动作本身就是对抗崩溃。xz↔nz(补7.5)——崩溃恐惧与等待柔情的互济。这是一个从"容器本质"到"容器维护"到"容器的恐惧与柔情"的完整互济循环。

链强度：(10 + 9 + 10 + 8 + 7 + 6.5 + 7.5 + 5.5) / 8 = **7.9**

### 总动态强度

| 链 | 强度 | 说明 |
|:--|:----:|:------|
| 主链（形成与运转） | 6.9 | 容器的正向生命周期——形成→运转→意义化。强度中等因为容器是"基础设施"而非"冒险叙事"——它一直在那里，不需要剧烈变化 |
| 克链（危机与失效） | 6.5 | 容器面对失效的防御与挣扎。强度略弱于主链——容器不容易崩，一旦崩了就是大事件 |
| 补链（互济循环） | **7.9** | **容器最强链。** 容器不是一个单向进程，而是一个系统——n与x并z互济、zx与xz互济、xz与nz互济。补链的高强度说明容器是一个"保持平衡的系统"而不是"推进的叙事" |

**总动态强度**：(6.9 + 6.5 + 7.9) / 3 = **7.1**

---

## 11. 动态链总强度

**7.1**——中上等。容器作为空间主题的根基概念，其动态链强度处于"稳健但不激烈"的位置。不是欲望(9+)那种高张力概念，但比信任(6+)等温和概念更有结构性。补链7.9的高强度揭示了一个关键特征：**容器本质上是空间层面的"系统维护"**——它的第一属性不是变化（主链不高），不是危机（克链不高），而是"各面之间的平衡互济"（补链高）。容器的强度来自它的系统性，不是它的戏剧性。

## 12. 归入五大主题

| 主题 | 公式 | 容器的累计强度 | 计算 |
|:----|:----:|:-------------:|:-----|
| **空间** | x并z + n | 9 + 10 = **19** | 空间型的公式本身就是「壳+容器」——容器的绝对主场 |
| **命运** | xz + nz | 6.5 + 5.5 = **12** | 容器的失效(xz)与等待(nz)——容器在时间和不确定性中的状态 |
| **时间** | xn + z | 3.5 + 4.5 = **8** | 容器被规格化(xn)和被建造的冲动(z)——边缘 |
| **因果** | zx + nx | 8 + 3 = **11** | 容器维护(zx)与容器暗账(nx)——容器的工作面 |
| **本体** | zn + x | 2.5 + 4 = **6.5** | 容器的意义(zn)与被占有(x)——极弱 |

**主归判断**：空间(19)>>命运(12)>因果(11)>时间(8)>本体(6.5)

## 13. 五大主题归仓强度

| 主题 | 综合强度 | 排序 | 理由 |
|:----|:-------:|:----:|:-----|
| **空间** | **10** | **第一** | **容器的绝对归属。** 空间型的公式x并z+n就是「壳+容器」——容器是空间主题最基础的原型。没有容器就没有空间型——所有空间关系（边界、隔间、场所、领地）都以容器为底层结构 |
| **命运** | **6.5** | 第二 | 容器确实有命运面——容器会失效(xz)、容器会等待(nz)。但命运是容器在"时间中的状态"而非容器本身 |
| **因果** | **6** | 第三 | 容器有维护(zx)和暗账(nx)的操作面——但因果不是容器的本体结构 |
| **时间** | **4.5** | 第四 | 容器的规格化时间维度——容量标准化、时限。但容器可以不依赖时间存在 |
| **本体** | **3.5** | 第五 | 容器不需要被赋予"意义"(zn)就能工作——一个空箱子就是空箱子，不需要理由 |

**结论**：容器主归**空间主题〔10〕**——空间型的公式x并z+n本身就是容器结构。容器是空间主题的根概念，不是某个"空间型概念的案例"而是空间型概念的**原子和模型**。次归命运〔6.5〕——容器的失效与等待维度。

## 14. 误判检查

| 潜在误判 | 自查 | 结论 |
|:--------|:----|:-----|
| **把容器等同于n** | 容器≈n(10)+x并z(9)+zx(8)——n是核心但不是全部。没有x并z的n是"地面/开放空间"不是容器。没有zx的n是"静态容纳"不是"工作容器" | ✅ 已覆盖三角结构：n(容纳)+x并z(壳)+zx(维护) |
| **把容器等同于盒子** | 物理盒子只是容器的子类型——社会容器（家庭/国家/社区）和心理容器（记忆/信念/人格）同样是容器，共享"能装能留"的底层结构 | ✅ 步骤1明确覆盖三类容器，步骤3候选表各维度均兼顾 |
| **把容器等同于边界** | 边界(x并z)是容器的面但不是容器本身。没有容纳功能的边界是"围栏/篱笆/隔离带"——围栏不是为了装东西，是为了不让东西进来。容器=有容纳功能的壳≠有边界功能的壳 | ✅ n(容纳功能)与x并z(壳)在第一步就明确区分：隔离物≠容器 |
| **把行为当本质** | "建房子"是zx(建造容器的动作)但不是容器本身。"维护家庭"也是zx。容器的本质是"能装能留"的功能状态(n)而不是"正在被维护"的行为状态(zx) | ✅ 步骤1定义锁定在"空间功能单元"而非"行为" |
| **把外壳当本体** | x并z(9)是容器的可见面但n(10)才是本体。一个透明的容器没有可见的外壳（玻璃）但它仍然是容器。一个壳装饰（花瓶只放一边）看起来是容器实际不工作 | ✅ n(10)>x并z(9)正确反映了容纳功能优先于壳 |
| **忘记容器的维护面** | 容器天然需要zx(8)——边界不会自己维持。国家需要军队维护领土完整、家庭需要经营、心理边界需要维护。被动地只看到"容器存在"而不看到"容器需要被维护"是常见疏漏 | ✅ zx=8在步骤5和动态链中已充分覆盖 |
| **把3D拆解当概念映射** | 任务明确说"不要做三维拆解"——不把容器拆成"长宽高/内部外部/顶底侧面" | ✅ 完全没有做3D拆解，保持在语义结构层面 |
| **三维拆解** | 容器确实有物理三维性（长宽高）但这不是十元体系的分析方式。任务明确禁止三维拆解 | ✅ 已遵守——全部在十元语义结构中分析 |

## 15. 封存句（带映射强度版）

> **容器 = n〔10〕锚点的承载·容纳原型补向x并z〔9〕的壳·边界和zx〔8〕的边界维护动作，被xz〔6.5〕的失效临界与nz〔5.5〕的等待状态反向定义其命运张力——本质不是「被隔离的空间」(墙/边界)，而是「某物能在其中存在而不流失」的空间功能单元（能装能留能保护）。容器=空间主题的原型概念——x并z+n〔空间型公式10〕的活体示范，补链系统强度7.9揭示其「系统维护优先于戏剧推进」的结构本质。物理、社会、心理三个层面的容器共享同一个十元指纹：n承载 + x并z包覆 + zx维护。主归空间主题〔10〕，次归命运主题〔6.5〕，总动态强度7.1。**
