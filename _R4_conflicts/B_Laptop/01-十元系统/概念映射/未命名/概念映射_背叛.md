# 15步模板分析：「背叛」——完整映射强度分析

## 1. 一句话定义

背叛 = 关系性承诺的破裂——不是一个人的行为，是两个人之间「信任账户」被结算为负数的瞬间。

---

| 三元 | 内容 |
|:----|:----|
| x = 形式面 | 背叛的表象——背叛那一刻的行为、背叛的外壳 |
| z = 能量面 | 背叛的动力——为什么要背叛、背叛的冲动 |
| n = 载体面 | 背叛的承载——被背叛的人、破裂的关系 |

## 10. 跑动态链

### 主链（背叛的发生）
```
x并z(7.5) → nx(9) → 结算 → nz(8.5) 穿透
```
- 伪装下暗账在积累。暗账到了负数时，信任关系被结算干净。nz的等待被击穿。
- 链强度：(7.5+7.5+9+9.5+8.5)/5 = **8.4**

### 克链（背叛的压制）
```
zn(6) → 克 → x(7) 欲求被克制 → xn(5.5) → 克 → xz(8) 临界行为被压制
```
- 信仰克制欲望，制度克制临界。但这两个压制都很弱——背叛一旦发生很难被阻止。
- 链强度：(6+5+7+5.5+5.5+8)/6 = **6.2**

### 补链（背叛的循环）
```
nx(9) ↔ xz(8) ↔ x并z(7.5) ↔ nx(9)
```
- 暗账→临界→伪装→暗账继续积累。背叛不是一次性事件，是系统的循环。
- 链强度：(9+8+8+7.5+7.5+9)/6 = **8.2**

### 总动态强度
(8.4 + 6.2 + 8.2) / 3 = **7.6**

## 11. 动态链总强度

**7.6**——上等。背叛是一个高能量概念，它的主链和补链都很强（8.4和8.2），但克链弱（6.2），说明**背叛一旦发生就很难被阻止**。

## 14. 误判检查

1. ❌ **背叛 = xz** — 错。xz是被背叛后的行动（逃/临界），不是背叛本身
2. ❌ **背叛 = nx** — 近似但不精确。nx是背叛发生的机制（暗账结算），背叛是nx与nz交互的结果
3. ❌ **背叛是一次性事件** — 错。背叛往往有前置的伪装（x并z）、积累（nx）、触发（xz）
4. ❌ **背叛=伤害** — 错。伤害是x（欲望/情绪），背叛是信任结构破裂——比伤害更深层
5. ❌ **背叛=道德错误** — 错。道德定性是zn层面的事，背叛的本质是关系对子的破裂
