# 位置对子使用实践 v0.1

> 归档：`01-十元系统/位置对子使用实践_v0.1.md`
> 核心方法：**双链夹主题**——不是一条链吃到底，而是显链+暗链两条脊柱咬合，交汇处生成主题链。

---

## 核心流程

```text
先判点位 → 再查位置 → 再组对子 → 最后解释剧情
```

不是看到剧情就直接写关系，而是先过一遍标准位置盘，确认合法生克补边。

### 关键区别：不能跳点

错误：`nx 生 x并z`
正确：`nx 生 x → x 生 x并z`

**中间点不能省。** 跳过合法边会断掉位置盘的可验证性。

---

## 术语层级

| 名称 | 是什么 | 例子 |
|------|--------|------|
| **位置关系** | 单条合法边 | nx 生 x |
| **位置对子** | 多条合法边组合 | nx → x → x并z → z |
| **动态链** | 位置对子落到作品里运行的力流 | 小人物低位隐忍，生出欲望，再借壳显现 |
| **主题解释** | 动态链最后抽出的意义 | 普通人为什么要借壳显现 |

---

## 双链夹主题结构

不是一条链覆盖整部作品。而是**两条链分别跑不同层面**，在交汇处生成主题链：

```
【显链】：普通人的借壳显现链  → nx → x → x并z → z
【暗链】：主角的行动破局链     → xz → zx → zn → xn
【主题链】：显链和暗链交汇合流 → z 克 nx → nx 补 zx → zx 生 zn
```

---

## 显链：普通人的借壳显现链

```text
nx → x → x并z → z
```

对应关系：
```text
nx 生 x
x 生 x并z
x并z 生 z
```

标准盘位置：阴链生环（nx 生 x、x 生 x并z、x并z 生 z）。

**文字解释：**

这条是**普通人的显链**。

小妖怪一开始是 `nx`：低位、隐忍、不敢显现、觉得自己不配。
但 `nx` 不会让欲望消失，反而会生出 `x`：我也想出去、我也想被承认、我也想不是一只无名小妖。

可是这种 `x` 不能直接站出来——没有正统身份、没有英雄资格。所以 `x` 生出 `x并z`：假扮取经人、借英雄外壳、用表象包装自己。

然后 `x并z 生 z`：装着装着，开始真的想被看见；演着演着，开始真的想成为那种人。

**显链的核心不是"虚伪"，而是：普通人因为不敢直接显现，所以先借壳显现。**

> **封存句：** 显链 = nx 的小人物不配感，生出 x 的改命欲望；欲望生出 x并z 的英雄外壳；外壳最终生出 z 的真实显现。

---

## 暗链：主角的行动破局链

```text
xz → zx → zn → xn
```

对应关系：
```text
xz 生 zx
zx 生 zn
zn 克 xn
```

标准盘位置：阳链生环（xz 生 zx、zx 生 zn）+ 阳链克环（zn 克 xn）。

**文字解释：**

这条是**主角真正走的暗链**。

`xz` 是压迫和临界：真假取经人之间、妖怪和英雄之间、底层和主角之间、被识破就会坠落的危险边界。

`xz 生 zx`：越被压迫、越站在临界点，就越必须行动。不行动就永远是小妖怪，行动了才可能改写身份。

`zx 生 zn`：行动不是为了热闹，行动最后生出意义。主角不是先有伟大意义才出发，而是因为做出了行动，才开始生成"我为什么走"、"我到底是谁"、"我能不能拥有自己的路"。

`zn 克 xn`：这里的 `xn` 是高阶级反派、正统规则、等级制度、"你不配"的身份判决。当 `zn` 成立后，旧规则就被克掉了——"你说我只是小妖怪，但我已经走出了自己的路。"

> **封存句：** 暗链 = xz 的压迫临界逼出 zx 行动，zx 行动生出 zn 意义，zn 意义最终克制 xn 的高阶规则与身份压迫。

## 主题链：两条链交汇合流

```text
z 克 nx
→ nx 补 zx
→ zx 生 zn
```

这条不是单独剧情链，而是**显链和暗链交汇后的主题链**。

### 第一步：z 克 nx

显链最后生成了 `z`——"我想被看见、我想成为真的、我想不再只是小妖怪"。
这个 `z` 反过来克 `nx`。想显现的愿望开始克制原来的退缩、不配感、自我压低。

> 主题第一刀："我不配"被"我想成为真的"烧穿。

### 第二步：nx 补 zx

只靠 `z` 不够。只想被看见没有行动，就会变成空喊。

`nx` 是普通人的低位判断——"我知道自己弱、我知道规则很重、我知道世界不会轻易承认我。"
`zx` 是主角的行动——"但我还是走、还是做、还是出发。"

两者补起来，才不是乱冲，也不是永远缩着。

### 第三步：zx 生 zn

最后，行动生成意义。**不是先有意义再行动，而是在行动中生成意义。**

小妖怪的意义不是天生的，不是正统赐予的，也不是高阶级规则批准的。
它来自：
> 我明知道自己不配，但我还是做了选择。
> 我明知道自己是假冒，但我真的走过了这段路。

## 三链合体结构图

```
【显链：普通人的借壳显现】
nx → x → x并z → z

【暗链：主角的行动破局】
xz → zx → zn → xn

【主题合链】
z 克 nx → nx 补 zx → zx 生 zn
```

更压缩：
```
显链负责：普通人为什么要借壳显现
暗链负责：主角如何在压迫中行动并克制高阶规则
主题链负责：不配感如何被行动突破
```

## 5. 主题总解释

《浪浪山小妖怪》的真正主题不是"小妖怪逆袭成英雄"，而是：

> 一个本来没有资格显现的普通人，先借壳让自己出现，再在压迫临界中做出行动，最后用行动生成意义，克掉"你不配"的旧规则。

核心不是爽文式胜利，而是**资格的自我生成**：

```
不是因为我被承认，所以我能走。
而是因为我真的走了，所以我开始拥有被承认的重量。
```

## 五条核心经验

### 经验一：不能乱连点，要让点通过合法边过渡

错误：`nx 生 x并z`
正确：`nx 生 x → x 生 x并z`

**中间点不能省。** 省掉中间点分析会顺嘴，但位置盘会断。

### 经验二：位置正确还不够，要有内容解释

`x并z 生 z` 位置上是对的。但还要解释为什么在作品里成立——"假扮取经人的外壳，让小妖怪逐渐产生真的显现欲望。"

**位置对子不是查表结束，而是查表开始。**

### 经验三：一部作品可以有多个位置对子（双链夹主题）

不是一条链吃完整部作品。不同位置对子解释不同问题，两条链各自独立又交汇咬合：

| 链 | 位置对子 | 解释的问题 |
|----|---------|---------|
| **显链** | nx → x → x并z → z | 小人物为什么要借壳显现 |
| **暗链** | xz → zx → zn → xn | 主角如何行动并克制高阶规则 |
| **主题链** | z → nx → zx → zn | 不配感如何被行动突破 |

**位置对子不是唯一主链，而是分析工具组；双链夹主题让分析有骨架咬合感。**

### 经验四：补关系用来连接"心理"和"行动"

最关键的补关系：`nx 补 zx`。

- 如果只有 `nx`：会判断、会退缩、会算后果，但不会真正破局。
- 如果只有 `zx`：会行动、会冲出去，但可能没有代价感和判断。

`nx 补 zx` 让人物从"低位判断"进入"有判断的行动"。

### 经验五：主题不是凭感觉拔高，而是从位置对子里长出来

主题不能直接写"普通人也可以成为英雄"——太飘。

要先跑位置对子 `z 克 nx → nx 补 zx → zx 生 zn`，再提炼：
> 想被看见的愿望克制不配感，低位判断由行动补全，行动生成意义。

这样主题就不是口号，而是有位置关系支撑的结算。

## 最终封存

```text
《浪浪山小妖怪》的位置关系分析采用双链夹主题法：

显链是"nx → x → x并z → z"，
表现普通小妖怪从低位隐忍出发，生出改命欲望，
再借取经人的英雄外壳完成初步显现。

暗链是"xz → zx → zn → xn"，
表现主角在真假身份和阶层压迫的临界中被逼出行动，
行动生成自我意义，最终以新的意义克制高阶规则和身份压迫。

两条链合流后形成主题链："z 克 nx → nx 补 zx → zx 生 zn"——
想被看见的显现欲望克制了自卑和退缩，
低位者的判断由真正行动补全，
最终行动生成意义。

影片因此表达的不是传统英雄的胜利，
而是普通人在不配感中借壳出发，
并通过行动生成自身价值的过程。
```

更短：
```text
位置对子 = 合法边的组合。
双链夹主题 = 显链+暗链各自跑不同层面，交汇处生成主题链。
动态链 = 位置对子落到作品后的力流。
主题 = 动态链结算出的意义。
```
