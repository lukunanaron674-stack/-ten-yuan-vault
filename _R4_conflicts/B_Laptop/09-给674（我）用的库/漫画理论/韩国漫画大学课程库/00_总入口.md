## 三、什么叫完全十元知识化

每个专业知识点都按以下结构重新理解：

```text
原专业含义
→ 作用对象
→ 对象当前状态
→ 主十元
→ 条件十元
→ 结果十元
→ 已锁定／待确认关系
→ 启动机制和被改变变量
→ 体量、顺序、阶段和第三因素
→ C动态链
→ 五维归纳
→ 误判、拿掉和反向测试
→ 创作训练
```

只写“可能对应x、n、zx”不算完成；课程名、对象名、动词、色调、镜头和气氛都不能直接等于十元。

## 五、R6 C模式

```text
选择R6知识点
→ 对象状态
→ 关系位置
→ 主十元与条件十元
→ 行为／表现／制作操作
→ 对方或系统独立回应
→ 正本生克补候选
→ 收益、代价和被改变变量
→ 结果十元
→ 新对象状态与新关系
→ 下一轮
```

A模式用于分析已有作品；B模式用于配置条件；C模式用于实际运行。R6正文内部已经同时保存三种用途，不需要再开第二张说明卡。

## 七、五维归纳

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

五维只在动态链运行后归纳。单个知识点或两个十元共现不能自动生成主主题。
