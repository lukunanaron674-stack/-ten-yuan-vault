# 色彩字体与拟声词｜R6

## 1. 本章总判断

色彩、字体、气泡和拟声词是作品的公开感知界面。它们组织对象可见性、阅读顺序、观看中心、声音距离和体量，使已经成立的十元关系被读者识别。

```text
对象与关系机制
→ 决定哪些信息应被看见、延迟、遮蔽或强调
→ 用明度、色相、字形、气泡和声音界面组织顺序
→ 让行为、回应和代价获得可读体量
```

视觉或声音气氛不等于十元。红色不自动等于`zx`，暖光不自动等于`n`，低饱和也没有义务承担全世界的`xz`。

## 2. 色彩四层的十元理解

### 2.1 固有色

固有色维持人物、服装、道具和场景的可识别性，是`x并z`公开界面候选。只有当第三方能稳定识别、调用或归因时，才提供有效证据。

### 2.2 光源色

光源色显示时间、天气、空间运行和观看条件：

- 时间变化可显影`xn/z`；
- 光源控制者可影响可见性与信息对象`x`；
- 被照亮不自动等于获得`z`认可；
- 黑暗不自动等于`xz`危险。

### 2.3 空间色

前中后景的明度、纯度、冷暖和对比组织进入、距离、遮挡和中心位置，可显影`x/x并z/n/xz`空间条件。

### 2.4 叙事色

叙事色是对对象意义和动态链阶段的有意偏移：

- 关系接近后共享色温；
- 关系断裂后色域分离；
- 身份揭露前后识别色转义；
- 危险窗口收窄时对比与可见路径变化；
- 回忆色在不同轮次中由纪念转成证据、债务或误判。

叙事色必须对应真实对象或关系变化。

## 3. 色彩脚本的十元结构

长篇色彩脚本不只记录“这一话悲伤”，而要记录端点分配和阶段变化：

```yaml
章节/话数:
主要对象:
对象状态:
主十元:
条件十元:
结果十元:
关系七变量:
时间与天气:
主光源及控制者:
主色相:
明度与纯度范围:
角色/背景分离方式:
信息显示与隐藏:
关系变化:
体量与顺序:
色彩伏笔及后续转义:
五维显影:
```

### 色彩回收

高潮和结尾的色彩回收必须对应：对象重新归属、关系回返、身份确认、原则改变、危险解除或流程终止。仅把第一话颜色再用一次，不算回收，只算软件记得色值。

## 4. 明度与观看权

手机快速滚动时，明度先分配读者注意力。

检查：

- 谁拥有最高对比，是否与当前行动或回应中心一致；
- 关键对象是否因`x`掌握而被隐藏；
- 认可对象是否获得正确归因，而非被他人视觉劫持；
- 气泡是否遮住表情、手、道具和关系证据；
- 夜景是否仍保留路线、边界和人物位置；
- 特效是否让`zx`动作显眼，却吞掉代价和回应。

高对比是观看中心，不是权力关系本身。

## 5. 色彩与关系七变量

| 关系变量 | 色彩可显影方式 | 不能替代的证据 |
|---|---|---|
| 信任 | 共享光源、减少遮挡、稳定色彩回应 | 实际信息与选择权是否开放 |
| 权力差 | 一方控制主光、对比和色域 | 资源、规则和最终决定权 |
| 情感距离 | 色温、明暗和局部色逐步靠近或分离 | 行为上的接近、拒绝与边界 |
| 依赖 | 一方色彩系统受另一方持续影响 | 离开后实际损失与替代路线 |
| 债务 | 反复出现的对象色、伤痕色或赠礼色 | 谁获得收益、谁承担代价 |
| 信息差 | 局部遮色、剪影、异色线索 | 谁掌握和能证明信息 |
| 定义权 | 谁的色彩系统覆盖关系场景 | 谁能公开命名和决定关系 |

## 6. 五种高频关系色彩误判

- 共享暖色＝`n/nz`：错误，可能只是同一灯泡；
- 冷暖对立＝敌对：错误，需看目标和变量；
- 红色入侵＝`zx`：错误，可能只是美术强调；
- 低明度＝`xz`：错误，需证明路径、时间窗或安全停留下降；
- 固定角色色＝`x并z`成立：错误，需证明身份壳被世界识别和调用。

## 7. Webtoon上色生产的十元知识

推荐结构：

```text
线稿
├─ 人物底色：识别人物与身份壳
├─ 场景底色：空间状态和权限
├─ 固有阴影：体块与材质边界
├─ 光源：观看与信息条件
├─ 环境色：人物是否进入同一承载系统
├─ 特效：动作体量与冲击
├─ 气泡文字：话语界面与阅读顺序
└─ 最终校色：全话端点与体量一致性
```

建立色板、图层命名、光照模板、设备检查和色盲可读性，不只是提高效率，也是维护`xn`生产结构和`x并z`统一界面。

生产规范不能反过来压扁剧情差异。模板是服务，不是殖民。

## 8. 气泡的十元结构

气泡同时是声音对象、公开界面和阅读流程。

### 气泡功能

- 普通对白：公开互动；
- 内心独白：读者获得角色未公开的信息；
- 旁白：组织时间、解释或反差；
- 电子声音：通过设备与制度界面传播；
- 低语：限制可见对象和关系范围；
- 喊叫：扩大公开体量，但不自动形成`zx`；
- 远处声音：建立空间距离；
- 画外音：分离声音主体与可见主体。

### 气泡检查

```yaml
说话者:
目标对象:
言语行为:
公开范围:
谁能听见:
谁不能听见:
信息对象:
阅读顺序xn:
确认节点z:
关系变量变化:
```

气泡尾巴、位置、字量和遮挡都必须服务于说话主体、阅读顺序与关系证据。

## 9. 字体的十元结构

字体是声音和身份的`x并z`候选界面：

- 字重和字形组织体量；
- 角色特殊字体建立可识别声音壳；
- 同类声音保持一致，形成稳定接口；
- 字体突变应对应身份、状态或传播媒介变化；
- 中韩英数字标点必须共享阅读系统；
- 纸书和手机端尺寸影响可见性与节奏。

授权、许可和可修改性属于现实`x/xn`生产条件。免费按钮不是版权神谕。

## 10. 拟声词与拟态词

### 拟声词

模拟撞击、脚步、雨、呼吸、机械和爆炸，显影音源、材质、距离、方向、持续时间和冲击体量。

### 拟态词

模拟摇晃、悄悄、突然、黏稠和闪烁，显影状态变化与动作过程。

### 十元设计维度

- 字形：公开界面`x并z`；
- 大小：体量；
- 方向：行动路线和`zx/nx`方向候选；
- 位置：谁受影响、谁能感知；
- 边缘与透明度：距离、持续和可见性；
- 与动作线关系：行为先后；
- 与画格关系：是否越界、侵入或持续到下一格；
- 反应镜头：证明声音是否改变对象或人物策略。

巨大拟声词不自动证明巨大剧情。字体并不持有最终解释权，虽然设计师偶尔会这么想。

## 11. 本地化的十元理解

本地化不是替换文字，而是把一个公开界面重新接入另一套语言、文化和关系系统。

检查：

- 气泡能否容纳不同长度而不破坏阅读`xn`；
- 竖排、横排和阅读方向是否改变顺序；
- 拟声词翻译、重绘或保留是否维持冲击与材质；
- 敬语、称谓和身份关系是否丢失`x并z/z/n`信息；
- 图像文字能否分层编辑，谁掌握修改权`x`；
- 字体是否覆盖目标语言并有授权；
- 本地化是否误改人物主十元和关系定义。

## 13. 五维归纳

- 时间：色彩脚本、昼夜、重复、气泡顺序、声音持续；
- 本体：角色识别色、声音身份、边界和真实自我；
- 空间：光源、色域、气泡位置、声音距离与承载；
- 因果：动作音效、回应、冲击和代价；
- 命运：颜色回返、声音残留、危险信号与最后窗口。

这些只在动态链后归纳。

## 14. 常见错误

- 全格高纯度，体量没有主次；
- 固有色不受光源和空间影响；
- 夜景用蓝滤镜统一掩埋信息；
- 特效只强化动作，不显示回应与代价；
- 气泡顺序要求读者猜谜；
- 拟声词只填空，不连接音源和结果；
- 字体无授权；
- 用色彩气氛直接判十元。

## 15. 训练

1. 同一场景清晨、正午、黄昏、夜晚四版，标出`xn/z`时间节点；
2. 只用明度突出关键对象，并解释其观看中心与真实关系的区别；
3. 为两名角色制作接近、控制、停靠、断裂四种关系色彩脚本；
4. 重做一页对话，标注气泡顺序、言语行为和关系变量；
5. 建立20种拟声词视觉字典，每项记录音源、方向、距离、冲击和回应；
6. 本地化韩文拟声词，说明保留了哪些体量与关系信息；
7. 为一话建立色板、字体、授权、图层和十元显影表；
8. 对一个“暖色关系场景”做拿掉测试，证明关系不靠色温成立；
9. 做一组视觉误判：画面像`xz/n/zx`，机制实际不成立；
10. 将同一段动态链分别制作时间、本体、空间、因果、命运五种色彩与声音版本。
