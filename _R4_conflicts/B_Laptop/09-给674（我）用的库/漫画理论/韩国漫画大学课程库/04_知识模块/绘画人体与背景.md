# 绘画人体与背景｜R6

## 1. 本章总判断

人体与背景不是“画得像”的两项技术，而是让人物的能力、边界、关系位置、行动路线和承载条件可见。

```text
十元机制已经在对象与关系中成立
→ 身体显示意图、支撑、方向和代价
→ 背景显示权限、路线、中心、遮挡和风险
→ 人物与空间共同证明谁能行动、停留、控制、返回或被接住
```

姿势、透视和环境只负责显影，不能凭一个强势站姿就宣布`zx`，也不能凭一间温暖房子就宣布`n`。

## 2. 观察与速写的十元顺序

```text
动作方向
→ 重心与支撑
→ 身体大体块
→ 关节与比例
→ 衣服受力
→ 手、脸、道具
→ 空间路线与他人回应
```

- 动作方向：人物准备改变哪个对象或端点；
- 重心：身体是否已经承诺行动，还是仍保留撤回；
- 支撑：谁或什么承担重量，可能显影`n/nx/x`；
- 体块：身体边界和行动能力；
- 关节：动作可达范围与限制；
- 衣褶：力量、速度、材质和持续时间；
- 手脸道具：信息、控制、确认和关系接触；
- 空间路线：是否存在进入、退出、绕行、返回或最后窗口。

30秒、2分钟和10分钟速写分别训练主方向、结构证据和完整关系场。

## 3. 人体结构的十元知识

### 骨架

头、脊柱、胸廓、骨盆、肩带、髋部与关节决定人物的现实行动边界。它们属于身体对象的`x`条件，不等于角色人格中的`x`。

### 肌肉

肌肉负责解释发力、抗力、压缩、拉伸和恢复：

- 主动发力可显影`zx`行为候选；
- 持续稳定可显影`xn`过程候选；
- 承担他人重量可提供`n/nx`证据；
- 受伤和疲劳改变后续可用端点；
- 身体极限收窄行动路线时提供`xz`条件。

肌肉名称不是十元。会背拉丁文也不会自动拥有剧情。

## 4. 动作、重量与十元策略

每个动作至少判断：

```yaml

动作后惯性:

```

### 常见身体倾向

| 身体表现 | 可能端点 | 必须验证 |
|---|---|---|
| 占据空间、动作直接 | zx/x | 是否真的获得决定权或掌握边界 |
| 收紧、防护躯干 | x/n | 是保护自我边界还是承载他人 |
| 重心反复、动作未完成 | z/xz/x | 是等待确认、临界犹豫还是保留退出 |
| 支撑点增加、动作延迟 | n/nx/xn | 是被接住、承担还是流程性疲劳 |
| 同步方向、允许触碰 | n/nz/nx | 是互相承载、自愿停靠还是方向外包 |

身体语言只能提出候选，必须由对象与关系结果判定。

## 5. 面部、视线与手

### 面部

表情要显示人物如何解释当前端点：

- 眉眼口、头部、肩颈和呼吸共同构成反应；
- 强烈动作后保留恢复和残余，证明代价进入下一轮；
- 同一表情在不同身份、信息和权力位置下意义不同。

### 视线

视线分配信息与关系：

- 看对象：确认其价值或威胁；
- 看对方：请求`z`确认、`n`接收或监测`zx`行动；
- 避开：保护`x`边界、隐藏信息或拒绝关系定义；
- 追随：可能是`nx`方向跟随，也可能只是观察。

### 手

手部可以显影：

- `x`：握住、放开、扣留、归还；
- `z`：指认、签字、确认；
- `n/nz`：支撑、触碰、保留共同物；
- `zx`：执行、推开、击打、下令；
- `nx`：接过任务、沿他人动作继续；
- `xz`：在最后窗口前抓住或失手。

## 6. 服装与道具

服装同时是身体对象和公开身份壳：

- 材质、重量和活动范围限制行动；
- 制服、徽章、礼服可形成`x并z`候选界面；
- 损耗和穿着方式显示阶层、流程和生活；
- 服装被剥夺不自动等于身份消失，需检查第三方是否仍用该壳识别主体。

道具必须记录尺寸、重量、握法、使用流程、放置位置、控制者和功能变化。道具至少经历两次功能转义，例如工具→证据→债务→纪念。

## 7. 透视的十元作用

透视建立共同现实：

- 视平线决定观看者位置；
- 灭点组织空间方向；
- 人物尺度证明谁共享同一场景；
- 门窗、楼梯和重复结构显示`xn/x并z`秩序候选；
- 机位高低只改变观看关系，不自动改变十元关系。

### 透视训练的十元任务

1. 一点透视室内：标出中心、边界、出入口和可停留位置；
2. 两点透视街角：标出路线、盲区和最后窗口；
3. 高低机位：比较观看权与实际权力差；
4. 同一房间五机位：证明关系机制不依赖单一镜头；
5. 平面图重建：验证动作路线与对象位置。

## 8. 背景不是背景

背景是行动权限和关系承载的分配器。

### 背景的十元功能

- `x`候选：谁占有、使用、封锁、退出；
- `x并z`候选：空间名称、身份界面、制度入口；
- `n`候选：是否真实接收、保护、补给并持续维持；
- `nz`候选：是否保存共同时间和自愿回返；
- `xn`候选：路线、工序、值班、交通和日常运行；
- `zx`候选：谁能公开调动空间与成员；
- `xz`候选：危险可到达性、退路和时间窗；
- `z`候选：谁在空间中被看见和确认；
- `nx`候选：人物是否沿空间既定方向推进；
- `zn`候选：主体为何愿意守护、建设或离开此地。

## 9. 场景连续性与动态链

每轮动作必须改变至少一项：

- 人物位置；
- 对象控制权；
- 可见与不可见信息；
- 出入口和安全路线；
- 身体能力或伤势；
- 人物距离和关系变量；
- 空间的接收、排斥或封锁能力。

背景若只在第一格出现，之后人物漂进虚空，空间就没有参与动态链，只是完成了出勤签到。

## 10. 3D与SketchUp

3D工具属于`xn/x并z`生产接口候选：它组织可重复结构、尺度和机位，不自动产生叙事空间。

适合：

- 保持复杂场景连续；
- 测试机位、焦距和人物高度；
- 重复使用建筑、道具和光源；
- 降低周更成本。

不能替代：

- 选择哪个端点显影；
- 决定观看中心；
- 设计行为与回应；
- 风格化和信息删减；
- 真实建筑、职业与生活逻辑。

## 11. 常见误判

- 解剖准确＝人物有力量：错误，需证明现实行动能力；
- 仰视＝zx：错误，需证明公开决定位置；
- 大房子＝n：错误，需证明真实接收和保护；
- 狭窄空间＝xz：错误，需证明路径和窗口收窄；
- 两人靠近＝nz：错误，需证明共同时间和自愿回返；
- 制服＝x并z已经成立：错误，需证明第三方识别和接口运行；
- 3D透视正确＝场景有效：错误，空间仍可能不影响任何行为。

## 13. 五维归纳

- 时间：动作准备、持续、恢复、流程和节点；
- 本体：身体边界、身份与主体选择；
- 空间：公开壳、承载、出入口与位置；
- 因果：发力、执行、承担和后果；
- 命运：危险路径、停靠、错过和回返。

五维只在完整动作与场景链后归纳。

## 14. 训练

1. 100个30秒动态，标注动作方向与主十元候选；
2. 20个职业动作流程，标注`xn`步骤与实际权限；
3. 同一角色8种重心状态，分别写可撤回性和关系位置；
4. 一间房五机位，证明十元机制不依赖镜头；
5. 12格无台词搬重物，显示支撑、承担和代价；
6. 24格复杂空间追逐，逐轮更新路线、对象和`xz`窗口；
7. 用3D搭景后重新手绘，删掉不服务端点的结构；
8. 为同一空间制作安全地、权力场、秘密场和逃生场四版；
9. 找三个“视觉像某十元但机制不成立”的误判例；
10. 完成一话人物、背景、对象和关系连续性审计。
