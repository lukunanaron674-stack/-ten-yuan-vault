# 世界观与资料调查｜R6

## 1. 本章十元总判断

世界观不是十元之外的背景资料，而是十元发生所需的**对象、权限、边界、承载、流程、认可位置和临界路径**。

世界规则必须经过：

```text
现实事实
→ 对象化
→ 状态化
→ 谁掌握、谁承载、谁被排除
→ 人物可选行为变化
→ 十元端点显形
→ 生克补与体量顺序
→ 场景动态链
```

一条设定如果不能改变对象状态、人物权限、关系位置或下一步行动，就还没有进入十元系统。

## 2. 世界规则的十元化语法

原专业问题与十元理解：

| 原问题 | 十元化理解 |
|---|---|
| 谁从规则中获益 | 谁获得`x`的实际掌握、`x并z`的公开接口或`z`的认可位置 |
| 谁付出代价 | 谁进入`nx`方向让位、被转移成本，或进入`xz`临界路线 |
| 谁能绕过规则 | 谁利用现有`xn`流程、`x`权限或`nx`通道改变结果 |
| 规则如何进入日常 | 规则是否成为可重复、跨时间运行的`xn`结构 |
| 违反会发生什么 | 是否出现`z`确认、`xz`风险、`zx`公开处置或资格退出 |
| 怎样改变关系 | 是否改变接收能力`n`、停靠证据`nz`、主体资格`zn`或掌握边界`x` |

### 世界规则卡

```yaml

现实来源:
对象层: 人物 / 身份 / 制度 / 空间 / 资源 / 信息 / 道具

第三因素:

```

## 3. 世界观六层的十元归整

### 3.1 自然层

地理、气候、资源、生物、灾害、昼夜和季节首先是对象状态，不天然等于任何十元。

十元化检查：

- 地理是否限制可用路线，形成`xz`候选临界；
- 资源是否被某主体实际掌握，形成`x`候选；
- 聚落是否真实接收、保护和补给，形成`n`候选；
- 季节和昼夜是否持续组织生活与行动窗口，形成`xn`条件；
- 灾害是否让既有决定中心失效，并使公开权能显形，可观察`xz→zx`候选，但不得擅自锁定；
- 安全结构是否真正降低危险可到达性，可正式检查已锁定的`n克xz`。

**已锁定可用关系：**

```text
n形成真实接收、保护与持续维持能力
→ 危险可到达性、继续移动紧迫度下降
→ n克xz
```

房屋、城墙和山洞本身不是`n`。只有它们实际运行接收与保护，才可能成为`n`端点。

### 3.2 技术／魔法层

能力来源、条件、成本、上限、失败方式和垄断者，必须拆成：

- `x`：谁实际掌握能力、资源或使用权；
- `x并z`：能力如何被身份、证照、制服、门派或公共界面识别；
- `xn`：训练、规则、冷却、流程和重复运行；
- `z`：资格确认、认证、阶段节点和失效确认；
- `nx`：谁通过已有身份、通道或他人权限借力；
- `xz`：使用失败是否缩窄安全路线；
- `zn`：能力为何值得使用、拒绝或守护；
- `zx`：能力是否转化为公开决定权和显权行动。

**可直接调用：**

- `x生x并z`：实际掌握需要公共壳、职位、名称或接口；
- `x并z生z`：公开壳为认可提供清晰对象；
- `xn克zx`：长期规则和流程限制即时显权；
- `xn生xz`：规则把偏离识别并持续处理，压缩安全路径；
- `zn克xn`：主体撤回“应当维护”资格，使结构的自愿执行和复制下降。

### 3.3 制度层

法律、阶级、学校、军队、宗教、企业、平台和家庭制度必须拆为：

```text
内部承载n
＋公开身份壳x并z
＋持续流程xn
＋实际掌握x
＋认可节点z
＋公开执行zx
```

它们不是一个统一“制度十元”。要分清：

- 谁设规则；
- 谁能否决；
- 谁执行；
- 谁被接收；
- 谁被推出；
- 谁获得身份；
- 谁承担隐性成本；
- 谁能通过既有通道推进。

**重点关系：**

- `n补x并z`：内部承载与公开界面互补；
- `x并z克nz`：身份壳污染关系证据归因并降低可信回返；
- `zx克n`：公开显权改变成员资格或接收边界，使承载断裂；
- `xn克zx`：程序与前置结构限制单次命令；
- `zn克xn`：意义撤回使持续结构失去维护资格。

制度存在不代表这些关系自动运行。必须具体到一次准入、处罚、开除、身份确认、资源扣留或规则撤回。

### 3.4 经济层

生产、分配、稀缺、交换和贫富形成可拆为：

- `x`：资源掌握和最终否决；
- `xn`：生产、结算、积累和跨时间运行；
- `nx`：通过既有职位、关系、信用和渠道借力；
- `zx`：公开分配或剥夺权；
- `n`：共同体是否能接收并承担内部负荷；
- `xz`：资源断裂是否使安全选项收窄；
- `nz`：共同时间是否形成自愿停靠和回返证据。

例如“穷人没有钱”不是十元关系。要写：谁掌握住房入口，谁失去替代路线，谁被迫沿现有流程继续，谁的返回位置失效。

### 3.5 文化层

礼仪、禁忌、服装、饮食、节庆、语言、审美和死亡观分为：

- `x并z`候选：公开身份壳、可识别形式和社会接口；
- `z`候选：被确认、被承认或被否定的位置；
- `xn`条件：重复仪式、传统和跨代复制；
- `n`条件：共同实践是否承载真实成员；
- `nz`候选：共同时间是否形成不愿结束的停靠；
- `zn`候选：主体是否以内部意义决定遵守或退出。

传统不是天然`xn`，节日不是天然`nz`，制服不是天然`x并z`。它们必须实际改变行为和关系。

### 3.6 日常层

上班、吃饭、恋爱、出行、治病、获得信息和处理垃圾，是世界规则显影最可靠的位置。

日常十元化：

```text
谁重复维护流程xn
谁实际承担内部负荷n
谁掌握钥匙、钱、时间和否决权x
谁获得公开身份与接口x并z
谁被认可或忽视z
谁借他人关系与渠道推进nx
谁在危险路径中失去退路xz
谁仍愿意留下与返回nz
谁基于内部意义重新定义自己zn
谁公开决定他人条件zx
```

## 4. 资料调查流程的十元化

原流程升级为：

```text
提出创作问题
→ 确定要观察的十元变量
→ 建立关键词与来源清单
→ 找一手资料
→ 把事实拆成对象、状态、权限和流程
→ 访谈实际行为、回应与代价
→ 建立对象卡和C动态链
→ 标注关系是已锁定还是待确认
→ 做第三因素、拿掉和反向测试
→ 只保留能改变场景的材料
```

### 调查的十元变量

- `x`：实际掌握、排他使用、最终否决；
- `x并z`：公开身份、名称、职位、制服和接口；
- `z`：谁被谁确认，确认什么；
- `xn`：流程怎样跨时间稳定运行；
- `n`：谁被接住、保护、补给并允许停留；
- `nz`：什么共同时间证明仍愿意回返；
- `nx`：谁沿既有通道而非自己决定方向；
- `zx`：谁公开显权并改变成员或运行条件；
- `xz`：哪些路线、窗口和退路正在缩窄；
- `zn`：主体为何认为某事值得维护、拒绝或承担。

## 5. 来源等级与十元证据

### 一级来源

法律、档案、技术标准、当事人记录、原始史料和现场观察，用于证明对象、权限、行为和后果真实存在。

### 二级来源

论文、教材、调查报告和专业采访，用于解释机制和比较规律。

### 三级来源

新闻综述、通俗书、纪录片和从业者博客，只能提供候选与检索方向。

### 表现参考

漫画、电影和游戏只能证明一种表现方法，不能证明现实关系，也不能证明十元关系。

```text
画面像zx ≠ zx成立
色调像xz ≠ xz端点成立
角色看起来nz ≠ 有自愿停靠与回返证据
```

## 6. 职业调查的十元归整

职业调查原字段全部转为：

| 原字段 | 十元问题 |
|---|---|
| 工作目标 | 当前要改变哪个对象状态 |
| 日常流程 | `xn`如何运行，谁维护 |
| 常用工具 | 谁掌握`x`，谁只能借用`nx` |
| 行业术语 | 是否构成`x并z`公共接口 |
| 空间布局 | 谁进入`n`，谁被排除，危险路线`xz`在哪里 |
| 权力关系 | `x/zx/xn/x并z`分别由谁承担 |
| 新手错误 | 哪个端点误判、哪个流程未成立 |
| 风险压力 | 哪些安全选项被缩窄为`xz`候选 |
| 伦理 | `zn`如何补充或克制结构维护 |
| 典型冲突 | 哪两个端点不能同时维持 |
| 身体动作和声音 | 十元作用如何显影，不作为定义 |

## 7. 访谈提纲的十元化

除“一天从什么开始”外，必须追问：

- 谁能决定先后顺序；
- 谁有最终否决权；
- 谁只是在执行别人路线；
- 谁替系统承担看不见的成本；
- 出错后谁公开负责，谁实际付费；
- 什么情况下流程压不住即时显权；
- 哪些人被接收，哪些人永远在门外；
- 哪种身份壳与真实关系不一致；
- 哪个危险窗口一旦错过就没有替代路线；
- 哪种内部意义会让人拒绝继续维护制度。

## 8. 历史人物改编的十元化

仍保留三栏：史料确认、合理推断、创作虚构。

但每个虚构场景必须检查：

```text
当时人物实际拥有的x
当时公开身份壳x并z
当时可进入的流程xn
当时可获得的认可z
当时真实承载关系n
当时可用通道nx
当时危险路径xz
当时共同时间nz
当时主体意义zn
当时公开权能zx
```

现代人拥有的权限、信息和价值不能倒灌给历史人物。十元判断也必须受时代对象和资源约束。

## 10. 道具对象库的十元化

道具功能逐项重读：

- 工具：改变能力，但不自动等于`zx`；
- 身份标志：可形成`x并z`候选；
- 关系纪念：只有共同时间与自愿回返成立才可能显现`nz`；
- 秘密载体：改变信息差和行动权限；
- 权力资源：谁实际掌握、能否否决，检查`x`；
- 伏笔：属于信息与时间组织，不自动等于`xn/z`；
- 行动障碍：是否缩窄路线，检查`xz`；
- 主题象征：只属于表现层，不替代十元证据。

重要道具必须经历至少两次端点转义，例如：

```text
钥匙作为实际掌握x
→ 被制服身份壳x并z代表
→ 交给囚犯后改变逃生路线xz
→ 被用来救人时重新进入n或zx候选
```

## 11. 世界观压力测试的十元版

1. 普通人靠什么`xn`流程生活；
2. 穷人如何通过`nx`通道、漏洞或关系借力；
3. 权贵掌握哪些`x`和`zx`；
4. 哪些身份壳`x并z`代表真实内部，哪些只是表面；
5. 谁被`n`接住，谁被推出；
6. 哪些认可`z`被掌握者`x`门控；
7. 哪些安全路线正在变成`xz`；
8. 哪些关系仍有`nz`回返证据；
9. 哪种`zn`会让人物拒绝维护现有`xn`；
10. 规则失效后，端点由谁接管；
11. 拿掉主角后世界系统是否仍运行；
12. 拿掉世界规则后，主角欲望是否仍必须发生。

## 12. 从资料到故事的C动态链

```text
事实对象化
→ 状态、权限和关系位置明确
→ 人物按自身欲望解释对象
→ 主十元与条件十元显形
→ 人物行动
→ 制度、空间或他人独立回应
→ 收益、代价和被改变变量
→ 结果十元出现
→ 世界规则在下一场以新状态运行
```

## 13. 五维归纳

- 时间：规则、流程、历史材料和节点怎样组织`xn+z`；
- 本体：人物为何维护或拒绝世界边界，归纳`zn+x`；
- 空间：公开制度壳与真实承载如何组合，归纳`x并z+n`；
- 因果：公开行动与代价承担如何循环，归纳`zx+nx`；
- 命运：危险路径与可返回关系如何拉扯，归纳`xz+nz`。

五维只在多个场景的动态链后判显影等级。

## 14. 误判红线

- 城市、家、医院、监狱不天然是`n`；
- 法律、制度和训练不天然是`xn`；
- 制服、徽章和建筑不天然是`x并z`；
- 灾害和黑暗不天然是`xz`；
- 传统和节日不天然是`nz`；
- 反抗、攻击和战争不天然是`zx`；
- 信仰与口号不天然是`zn`；
- 有钱不等于`x`，必须有实际掌握和否决；
- 被看见不等于`z`，必须有明确认可主体和对象；
- 资料里的共现不能证明生克补。

## 15. 全量十元化课程作业

1. 为一个职业建立30张对象卡，每张写主、条件、结果十元；
2. 做一次真实采访，画出`xn流程—x掌握—nx借力—zx公开处置`结构；
3. 为历史人物建立“时代可用十元端点表”；
4. 为城市的交通、住房、食物和阶级建立对象权限图；
5. 设计一条魔法规则，写出至少三轮C动态链；
6. 同一场景做白天、夜晚、灾后三版，比较端点变化而非只换气氛；
7. 找一个`n克xz`正例、一个假安全反例；
8. 找一个`zx克n`案例，写清成员资格或接收边界怎样被改变；
9. 对一条制度做`zn克xn`拿掉测试；
10. 把资料包压缩为8页短篇，每场至少改变一个对象状态和一个关系变量。
