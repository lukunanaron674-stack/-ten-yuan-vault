# 漫画分镜与Webtoon演出｜R6

## 1. 本章总判断

分镜不是把剧本切成格子，而是决定读者在什么顺序、距离和时间中看见哪些十元端点，以及何时才看见关系已经变化。

```text
已成立的对象与关系机制
→ 选择观看位置、景别、角度和信息量
→ 安排行为与回应的先后
→ 用画格、翻页或滚动显影体量与顺序
→ 让读者看见被改变变量
→ 把代价送入下一格、下一页和下一话
```

分镜负责显影十元，不负责凭镜头制造十元。仰拍不自动等于`zx`，长空白不自动等于`xz`，两人同框也不自动等于`n`。

## 2. 分镜管理的七类十元证据

### 2.1 空间证据

谁能进入、退出、靠近、占据中心、躲藏、封锁或返回。主要显影`x/x并z/n/nz/xz`，但必须有现实权限和关系结果支持。

### 2.2 时间证据

动作持续多久、流程是否累积、节点何时确认、窗口是否关闭。主要显影`xn/z/xz`。

### 2.3 信息证据

谁看见、谁不知道、谁掌握对象、谁拥有公开界面、谁完成确认。主要显影`x/x并z/z`。

### 2.4 行为证据

谁实际行动、谁只是等待、谁公开决定、谁借既有通道做成。主要用于区分`zx/xn/nx/x`。

### 2.5 回应证据

动作后的反应决定目标端点是否真的被改变。没有回应，很多所谓关系变化只是作者自我感动。

### 2.6 体量证据

格子大小、留白、重复、运动距离和视觉中心可以表现体量，但不能替代体量形成的现实机制。

### 2.7 顺序证据

先看行为还是先看结果，先给对象还是先给人物反应，会改变读者对源端点、目标端点和因果方向的理解。

## 3. 最小画格的十元任务

每格最好只承担一个主任务：

| 画格功能 | 十元化任务 |
|---|---|
| 建立地点 | 交代场景权限、出入口、承载与危险路径 |
| 交代位置 | 明确谁占据中心、边界、距离和行动路线 |
| 展示动作 | 显示行动者如何尝试改变目标端点 |
| 展示反应 | 证明变量是否真的变化 |
| 给出信息 | 改变信息对象的掌握、确认或公开界面 |
| 隐藏信息 | 保留信息差并制造后续代价 |
| 强调道具 | 说明对象当前功能、控制者和关系绑定 |
| 改变节奏 | 调整体量与顺序，不等于自动改变关系 |
| 制造转折 | 让端点、对象状态或关系位置重新分配 |

## 4. 景别的十元理解

### 远景

用于建立场景系统、路径和体量：人物是否被空间吞没、是否有安全停留、是否处于`xz`路线收窄。远景只提供证据，不自动定义危险。

### 全景／中全景

用于显示身体、距离、方向、进退和占位，特别适合验证`x`边界、`n`靠近、`nz`停留、`zx`公开行动和`nx`跟随方向。

### 中景

用于两人互动，能同时显示台词、手部、道具和距离变化，是关系七变量最常用的结算景别。

### 近景

用于暴露信息、微反应和选择前的停顿。连续近景会切断空间证据，导致关系像漂浮在虚空里。

### 特写

只有在改变对象功能、认可归因、选择权或下一步策略时才有意义。手握钥匙、撕毁信件、移开戒指和未按下按钮分别是不同端点变化，不是“细节很有感觉”就算完成。

## 5. 角度与权力

俯视、仰视、平视、倾斜、背面和主观镜头都是观看位置，不是十元词典。

使用时必须回答：

- 谁拥有观看权和解释权；
- 镜头是否代表角色、制度或作者；
- 角度是否对应现实权力差；
- 下一镜是否证明被看者的选择、边界或成员资格改变；
- 拿掉角度后，关系机制是否仍成立。

仰视可显影`zx`公开权能，也可能只是建筑很高。请勿让摄影机替理论撒谎。

## 6. 动作连续性的十元链

```text
意图
→ 预备
→ 发力
→ 接触
→ 结果
→ 反应
→ 代价
```

- 意图：人物希望增强、保护或削弱哪个端点；
- 预备：调用资源、流程、身份或关系；
- 发力：实际行为发生；
- 接触：行为抵达目标对象；
- 结果：对象状态变化；
- 反应：目标端点和独立回应显形；
- 代价：端点重新分配。

### 快动作

减少中间步骤，强化`zx`显权或`xz`窗口感，但仍需结果与反应证明机制。

### 慢动作

增加阶段、停顿和细节，适合显示`xn`累积、`nz`不愿结束、`z`确认或人物在两端点间选择。

## 7. 对话场景的十元化

对话不是交换台词，而是争夺对象、关系定义和行动方向。

每场检查：

```yaml
谁想得到什么对象或回应:
谁掌握信息x:
谁拥有公开界面x并z:
谁等待确认z:
谁控制规则或话题xn/x:
谁试图公开决定zx:
谁沿对方方向nx:
谁需要n接收或nz停靠:
谁面临xz窗口:
场末哪个变量变化:
```

避免头像墙的方法不是随机加手势，而是让移动、道具、视线、停顿和距离服务于真实端点变化。

## 8. 反应镜头

反应镜头是十元关系的验收节点：

- 谁最先反应，说明谁把事件视为关键对象；
- 谁隐藏反应，说明信息、边界或身份存在成本；
- 谁误读，说明对象意义和真实机制分离；
- 谁改变行动，说明变量已进入下一轮；
- 谁完全不受影响，可能证明前一动作体量不足。

重大动作没有反应，就像系统弹出“复制完成”，文件倒是动了，关系没人认领。

## 9. 页面漫画的十元组织

### 页面单位

页面要组织：视觉中心、阅读路径、画格体量、信息差和翻页前后的端点变化。

### 翻页

翻页适合让以下内容跨越阈值：

- `z`确认：身份、证据或目标被明确；
- `zx`显权：行动结果或人物登场；
- `xz`临界：危险全貌或窗口关闭；
- `n/nz`变化：关系转折、离开或返回；
- `x并z`变化：真实身份壳或制度界面出现。

### 画格大小

- 大格：提高停留和体量；
- 小格：表现重复、流程、碎片和快速策略；
- 规则网格：显影`xn/x并z`稳定结构；
- 破格：显影结构被侵入，但不自动证明关系被克；
- 无框：可表现记忆、梦、边界扩散，必须标清现实层级。

## 10. Webtoon竖屏的十元组织

### 屏幕单位

每屏只承担一个主十元任务：建立对象、显示行为、给出回应、结算变量、制造端点重分配或保留停顿。

### 滚动距离

- 短距离：连续动作、`zx`执行或`xn`步骤压缩；
- 中距离：正常场景转位；
- 长距离：等待、下降、隔离、`xz`临界或`nz`不愿结束。

长空白若不改变读者预期、时间感或关系证据，只是在让拇指加班。

### 竖向运动

坠落、攀登、高楼、楼梯和追踪可以显影路径、体量和权力位置。仍需区分现实空间变化与象征性构图。

### 横向限制

多人、战场和建筑全貌必须拆成连续屏或纵深关系，否则对象、行动方向和回应者会混成一锅视觉粥。

## 11. 首话结构

首话需建立：

```text
作品的主对象与世界约束
→ 主角稳定十元策略
→ 一次具体触发和行为
→ 核心关系的独立回应
→ 至少一个变量变化
→ 一个由前述代价产生的下一话问题
```

设定不必讲完。读者来追连载，不是来参加制度入职培训。

## 12. 话尾钩子

新人物、身份揭示、目标失败、背叛、危险、规则推翻和不可逆选择，必须来自本话动态链：

```text
本话行为
→ 回应
→ 代价
→ 新对象状态或端点缺口
→ 话尾钩子
```

陌生人每话踹门属于门的职业伤害，不属于因果。

## 13. 类型演出的十元化

### 恐怖

```text
建立可依赖的n／xn正常结构
→ 小异常使规则可信度下降
→ 人物试验边界
→ 安全路径收窄为xz
→ 身体、身份或空间边界x被侵入
→ 反应与余波重新分配端点
```

### 爱情

亲密由共同时间、可撤回接近、边界尊重、共享对象和自愿回返构成。要区分`n`承载、`nz`停靠、`nx`方向让位和`x`控制，脸红与跌倒不足以完成这项艰苦工作。

### 动作

先画目标、障碍、位置、出入口、道具和失败代价。每轮至少改变位置、武器、信息、伤势、目标或同盟之一，并重新判断`x/zx/xn/nx/xz`端点。

## 14. 色彩、气泡、字体和拟声词接口

- 气泡顺序属于信息与时间组织；
- 字体和气泡形状属于`x并z`公开界面候选；
- 拟声词表现冲击、距离、材质和持续时间；
- 旁白可以补时间跨度和主观解释，但不能重复画面；
- 视觉界面只显影机制，不能替行为与回应作证。

## 16. 检查表

- 不看文字能否理解对象、行为和回应；
- 空间权限和人物路线是否清楚；
- 重要动作是否有意图、结果、反应和代价；
- 镜头是否只在营造气氛，未显示变量变化；
- 景别、角度和格子大小是否与体量一致；
- 翻页和滚动是否来自动态链顺序；
- 话尾是否来自本话后果；
- 十元判断是否来自正本而非镜头关键词；
- 五维是否在链条后归纳，而非开场贴标签。

## 17. 训练

1. 8格无台词日常，显示一次关系变量变化；
2. 16格追逐，每轮重分配一个对象或端点；
3. 12格两人对话，禁止连续三格同景别，并标每格行为功能；
4. 4页翻页揭示，区分信息`x`、公开界面`x并z`和确认`z`；
5. 40格恐怖短篇，证明`n/xn`怎样失效并进入`xz`；
6. 60格爱情场景，区分`n/nz/nx/x`；
7. 80格动作场景，记录`zx`行动与`xn`结构的关系；
8. 为同一场景制作三版：A分析版、B设计版、C运行版；
9. 找一组“镜头看似某十元但机制不成立”的误判样本；
10. 用拿掉测试检验：去掉机位、色彩或留白后，十元关系是否仍成立。
