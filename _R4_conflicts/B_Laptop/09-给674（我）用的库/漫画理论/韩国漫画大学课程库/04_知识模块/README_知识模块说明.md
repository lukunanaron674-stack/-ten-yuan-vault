# 知识模块说明｜R6全量十元知识化

## 1. 本文件夹现在是什么

`04_知识模块`不再只是韩国漫画专业课程的普通摘要，也不再在章节末尾附一段十元接口。R6把每个专业知识点重新组织为：

```text
专业事实与方法
→ 作用对象
→ 对象状态
→ 主十元／条件十元／结果十元
→ 正本生克补
→ 体量与顺序
→ C动态链
→ 五维归纳
→ 误判与反证
→ 创作训练
```

原版完整保存在：

```text
backup/course-library-pre-R6-20260723
```

## 2. 两种知识身份必须同时保留

### 专业课程事实

回答韩国漫画、Webtoon、动画和产业训练中“需要懂什么、练什么、交付什么”。它提供真实对象、行为、制作方法、媒介限制和评价标准。

### 十元重建知识

回答这些专业知识进入人物、关系、对象、场景和时间结构后，怎样显现十元、怎样形成生克补、怎样进入动态链，并最终显影五维主题。

二者关系不是：

```text
课程名＝某个十元
```

而是：

```text
课程知识提供可观察证据
→ 十元正本判断实际作用
```

## 4. 十元不是关键词字典

以下写法全部禁止：

- “攻击＝zx”；
- “等待＝nz”；
- “规则＝xn”；
- “家＝n”；
- “边界＝x”；
- “分镜课＝z”；
- “背景课＝空间”；
- “画面危险＝xz”；
- “角色有信念＝zn克xn”。

动词、对象和画面只能提出候选。必须说明它改变了谁的控制权、选择权、接收能力、认可位置、关系停靠、长期结构或临界路线。

## 6. C模式是默认学习方式

每个专业知识点都必须进入一次运行，而不是看完定义就算学会：

```text
对象状态
→ 关系位置
→ 当前十元端点
→ 专业行为／表现／制作操作
→ 对方或系统回应
→ 收益与代价
→ 被改变变量
→ 端点重分配
→ 下一轮
```

A模式用于拆作品，B模式用于设计条件，C模式用于实际推进。

- [[04_知识模块/角色心理与行为库]]：把欲望、恐惧和错误信念转换为稳定十元策略及压力转位；

## 8. 五维归纳

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

五维只能在动态链运行后归纳。单章知识点可以提供显影证据，但不能因为出现对应两个十元就宣布主主题成立。

## 9. 完成标准

一章只有在以下条件全部满足时才算R6完成：

1. 原知识点没有被简单删除；
2. 每个知识点都有作用对象和状态；
3. 主十元、条件十元、结果十元分开；
4. 生克补注明正本状态；
5. 写出机制和被改变变量；
6. 写出体量、顺序和成立阶段；
7. 进入C动态链；
8. 有五维归纳但不倒推；
9. 有误判、拿掉测试和反向测试；
10. 训练能产出可验证案例。

## 10. 更新边界

- 课程事实必须保留来源等级；
- 十元判断来自用户理论，不归因于韩国学校；
- 法律、平台、AI和产业规则按使用当天重新核验；
- 未锁定关系只能写候选，不得为了让表格漂亮而宣布成立；
- 所有旧版原文以备份分支为准。
