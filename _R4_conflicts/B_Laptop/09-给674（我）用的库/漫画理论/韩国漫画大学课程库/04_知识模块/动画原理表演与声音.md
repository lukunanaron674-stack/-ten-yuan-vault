# 动画原理表演与声音｜R6

## 1. 本章总判断

动画把十元从静态位置变成可观察的时间过程：人物怎样准备、发力、迟疑、承受、恢复，关系怎样通过表演和声音进入下一阶段。

```text
人物当前端点与对象状态
→ 形成动作意图和策略
→ Timing、Spacing、身体力学与镜头组织过程
→ 他人和环境回应
→ 声音标记接触、距离、重量与余波
→ 代价改变身体、关系和下一步能力
```

动作快不等于`zx`，慢不等于`xn/nz`，静默也不天然属于`xz`。时间和声音只显影机制。

## 2. 动画原理的十元知识

| 动画原则 | 十元化理解 |
|---|---|
| 挤压与拉伸 | 身体对象在受力后的边界变化，显示冲击与恢复 |
| 预备动作 | 人物调用资源、支撑和策略，暴露行动方向 |
| 演出重点 | 决定读者何时看见主对象与端点变化 |
| 连贯与跟随 | 显示动作代价、材料惯性和影响持续 |
| 缓入缓出 | 显示行为承诺程度、犹豫和体量 |
| 弧线运动 | 保持身体和对象的空间逻辑 |
| 次要动作 | 暴露隐藏目标、压力或关系反应 |
| Timing | 动作占用时间、流程和窗口 |
| Spacing | 加速、减速、重量和失控 |
| 夸张 | 放大已成立的体量，不负责创造机制 |
| 体积稳定 | 维护身体对象的连续`x`边界 |
| 吸引力与清晰 | 组织`x并z`可识别界面和观看中心 |

## 3. Timing与Spacing

### Timing

Timing决定动作持续多久，以及端点变化经过多少阶段：

- `xn`候选：训练、流程、持续组织和反复执行；
- `z`候选：明确接触、确认和终止节点；
- `nz`候选：不愿结束、停顿和共同时间；
- `xz`候选：剩余时间、最后窗口与来不及；
- `zx`候选：即时公开行动。

### Spacing

同一时长可表现突然启动、犹豫、沉重、轻快和失控。Spacing只说明运动方式，必须结合对象、目标、回应和结果判断十元。

### 时间记录

```yaml
动作目标:
动作前主十元:
总时长:
预备时长:
发力节点z:
持续流程xn:
可撤回窗口:
不可逆节点:
结果与恢复:
```

## 4. Body Mechanics的十元链

```text
目标对象
→ 支撑点
→ 发力点
→ 重心移动
→ 关节传递
→ 接触
→ 惯性
→ 结果、回应与恢复
```

- 支撑点可显影`n`承载或`nx`借力，但要看谁决定方向；
- 发力与接触可显影`zx`行动候选；
- 持续搬运和重复训练可提供`xn`证据；
- 受伤、疲劳和失衡改变身体对象的可用`x`边界；
- 安全路线与恢复能力下降可进入`xz`条件。

走、跑、跳、推、拉、举、抛、坐、起、跌倒、搬运、搀扶、拥抱和搏斗，都必须写清力和关系落到谁身上。

## 5. 角色表演的十元结构

角色不是“悲伤地说话”，而是：

> 试图让对方留下，同时保护自己的`x`边界，不公开承认`nz`停靠需求，并避免进入`nx`方向让位。

### 表演六层

1. 场景目标：想改变哪个对象或端点；
2. 当前策略：主十元如何行动；
3. 策略失败：目标端点怎样回应；
4. 身体与语言差异：公开界面与真实意义是否分离；
5. 关键想法变化：对象意义是否重解释；
6. 余波：结果十元和下一轮条件。

### 表演卡

```yaml
场景前主十元:
目标对象:
目标端点:
隐藏需求:
公开策略:
身体策略:
语言行为:
对方回应:
策略调整:
关键想法:
被改变变量:
结果十元:
```

## 6. 关键姿势

关键姿势必须同时可读：人物在做什么、力的方向、情绪、关系位置和动作前后连续性。

### 轮廓与十元

- 展开轮廓可能显影公开占位`zx/x`，也可能只是动作幅度；
- 收缩轮廓可能显影保护边界、恐惧或疲劳；
- 两人轮廓重叠可能是`n/nz`接近，也可能是`x/zx`压制；
- 身体方向一致可能是`nx`跟随或平等协作。

涂黑测试只验动作清晰，不验理论真伪。

## 7. Storyboard与Animatic

### Storyboard

记录镜号、景别、机位、动作、摄影机、台词、声音、时长和转场，同时补：

```yaml
主十元:
条件十元:
行为目的:
独立回应:
对象状态变化:
候选关系:
被改变变量:
```

### Animatic

Animatic将镜头放入真实时间，检查：

- `xn`流程是否拖沓或缺阶段；
- `z`节点是否清楚；
- `zx`行动是否有预备、结果与回应；
- `nz`停顿是否有共同时间证据；
- `xz`危险是否来自窗口收窄而非音乐吓人；
- 镜头复杂度是否超过资源`x`和生产`xn`。

## 8. 摄影与布局

- 先建立人物、对象和出入口；
- 摄影机运动必须有观看动机；
- 焦段改变距离感，不自动改变关系；
- 人物与摄影机同时运动时，必须保留对象、方向和回应；
- 布局需给动作、反应和代价留空间；
- 镜头中心与现实决定中心可能不同，必须标明。

## 9. 声音五层的十元知识

### 9.1 对白

对白是言语行为：请求、拒绝、试探、定义、威胁、交换、隐瞒或承诺。它可改变`z`确认、`x`解释权、`n`信任和`zx`公开处置，但台词内容本身不等于结果。

### 9.2 环境声

环境声维护空间、时间和运行连续性：机器、交通、风雨、人群和室内设备可提供`xn/x并z/n`场景证据。环境声突然消失可能表示结构失效，也可能只是混音偷懒。

### 9.3 动作音效

动作音效证明接触、重量、材质、方向和距离，帮助读者判断行为是否真正抵达对象。

### 9.4 音乐

音乐组织体量、顺序和五维显影，不能替人物承担行为和回应。删掉音乐后机制仍应成立。

### 9.5 静默

静默是对预期声音的撤回：

- 可强调`z`决定节点；
- 可延长`nz`停靠；
- 可显示`xz`危险逼近；
- 可暴露`n`承载断裂；
- 也可能只是没有配音预算。

## 10. 声音视点与关系

声音视点回答“谁能听见”：

- 主观听觉：读者进入角色信息位置；
- 画外声：声音主体与可见主体分离；
- 隔墙声：空间边界`x`和信息差；
- 广播、电话和平台提示：`x并z/xn`界面；
- 近距离呼吸：身体距离和关系边界；
- 声音被压制：公开权能、成员资格或表达通道可能受限。

## 12. 漫画中的动画知识

- 预备动作决定下一格的行动方向；
- Timing转为画格数量、重复和留白；
- Spacing转为位置差和动作阶段；
- 关键姿势显示主十元策略；
- 跟随动作显示冲击持续和代价；
- 拟声词、气泡和格边显示音源、距离和体量；
- 反应格证明目标端点是否改变。

## 14. 五维归纳

- 时间：Timing、Spacing、流程、节点和重复；
- 本体：身体边界、表演策略、主体意义；
- 空间：布局、摄影、声音距离和承载；
- 因果：发力、接触、回应和承担；
- 命运：窗口、失控、停顿、余波和回返。

## 15. 常见错误

- 肢体移动但没有重心和对象；
- 情绪只靠脸，身体策略为空；
- 每个镜头同长度，端点无体量差；
- 摄影机无观看动机地乱动；
- 音乐从头铺到尾，掩盖表演不足；
- 对白重复画面；
- 复杂度超过资源与流程；
- 用速度、姿势或声音直接判十元。

## 16. 训练

1. 5秒不同重量搬运，记录支撑、`n/nx`候选和身体代价；
2. 无对白犹豫表演，明确两个不能同时维持的端点；
3. 两人权力变化关键姿势组，区分视觉强势与真实`zx/x`；
4. 30秒Storyboard与Animatic，逐镜标主／条件／结果十元；
5. 同一Animatic做三种声音设计，比较五维显影而不改变事实机制；
6. 删除音乐，检查关系是否仍成立；
7. 把动画动作转成12格漫画，保留预备、结果、反应和代价；
8. 2至3分钟短片，每个序列完成端点重分配；
9. 找一段“动作很大但zx不成立”的误判例；
10. 对静默做拿掉测试，判断它是机制证据还是气氛装饰。
