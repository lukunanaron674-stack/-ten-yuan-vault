# 字体设计的十元总树

> **文字在版面里承担什么功能：显现、阅读、承载、压迫、装饰、破格、仪式、沉默。**
> 字体系统最核心不是 z，而是 **z + xn + n + x并z + nx** 五元协同。

---

## 总强度盘

| 十元 | 总强度 | 在字体系统里的作用 |
|-----|:-----:|------------------|
| **z** | **9** | 主标题、片名、Logo、第一眼显现 |
| **xn** | **8.5** | 小字、信息、阅读秩序、字距行距 |
| **n** | **8** | 字体作为结构、标题压舱、网格对齐 |
| **x并z** | **7.5** | 手写字、纹理字、装饰字、背景文字 |
| **nx** | **6.5** | 小字退后、低对比、克制、冷感 |
| **x** | **6.5** | 粗重、压迫、冲击、黑体块 |
| **xz** | **6** | 扭曲、破损、错位、失衡 |
| **zn** | **5.5** | 碑文、圣像标题、古典衬线、竖排仪式感 |
| **zx** | **4.5** | 斜排、速度感、方向引导 |
| **nz** | **3.5** | 手写柔软、亲密文案、温情注释 |

**总公式：**
```
字体系统 = z 显现 + xn 阅读 + n 承载 + x并z 造型 + nx 克制
```

## 1. 信息角色｜文字先承担什么身份？

```
信息角色
├─ 主标题
├─ 副标题
├─ 作者 / 品牌 / 系列名
├─ 日期 / 地点 / 编号
├─ 注释说明
└─ 装饰文字 / 氛围文字
```

| 分支 | 十元强度 | 分析 |
|------|:--------:|------|
| **主标题** | z 9.5 / n 7 / x 6 | 负责命名主题，是第一显现点。粗大时偏 x，居中或底部时偏 n |
| **副标题** | xn 7 / nx 5.5 / z 4.5 | 负责解释主标题，声音要低，不能抢王位 |
| **作者 / 品牌 / 系列名** | xn 7 / n 5.5 / z 4 | 属于身份信息，偏规则和归属 |
| **日期 / 地点 / 编号** | xn 8 / nx 5 / n 5 | 最典型的信息字，越清楚越好 |
| **注释说明** | xn 7.5 / nx 6 / nz 3 | 低声解释，适合细字、小字、低对比 |
| **装饰文字 / 氛围文字** | x并z 8.5 / xz 5.5 / xn 4 | 字开始不完全为了阅读，而是变成视觉皮肤 |

**核心：z + xn** — 字体先解决「谁是标题？」和「信息怎么读？」

## 12. 可读性与风险｜字体系统怎么崩？

```
可读性与风险
├─ 识别度
├─ 阅读顺序
├─ 主次关系
├─ 字图冲突
├─ 字体过多
├─ 装饰过量
├─ 风格不统一
└─ 情绪污染
```

| 风险点 | 十元问题 | 表现 |
|--------|:--------:|------|
| **识别度低** | x并z 过量 / xz 过量 | 字太花、太碎、太扭，看不清 |
| **阅读顺序乱** | xn 不足 / z 分散 | 不知道先看哪个字 |
| **主次关系乱** | z 过多 | 每个字都想当标题 |
| **字图冲突** | n 不足 | 字和图没咬住，只是贴上去 |
| **字体过多** | x并z 过量 | 字体像菜市场，风格散 |
| **装饰过量** | x并z 失控 | 文字变脏，主题变浅 |
| **风格不统一** | n / xn 不足 | 古典、赛博、手写乱混 |
| **情绪污染** | 十元误配 | 想要 nx，结果用了太多 x / x并z |

**风险判断：**
```
xn 管可读
n 管统一
z 管主次
x并z 管风格
xz 管异常
```
