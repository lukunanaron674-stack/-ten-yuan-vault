# 奇幻学院转生流｜可画内容实例

## 使用约束

- 每条实例只使用《名词对象库》的对象 ID 与《题材配方》的通用行为槽 ID。
- 本文件不分配主十元，不从题材、身份、服装、地点或动作表面反推十元。
- 下列公式是可画瞬间的装配测试，不是人物性格或生克补结论。

## 试运行判定

以上十条均能由“名词对象 ID + 通用行为槽 ID”独立还原为可画瞬间。下一阶段若接入十元行为库，必须另行补充角色阶段、触发处境、改变变量、行为依据和最近邻排除；不得直接把本文件的通用动作槽升级为十元行为。
