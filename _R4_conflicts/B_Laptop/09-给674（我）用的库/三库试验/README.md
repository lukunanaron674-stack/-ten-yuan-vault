# 三库试运行

本试验验证两种复合题材：

1. `W奇幻世界 + D学院 + M转生`
2. `W现代社会 + D城市公共系统/传送门管理机构 + M传送门`

## 三库边界

- 1号名词对象库：只保存可画对象、可见状态和中性动作钩子。
- 2号十元行为库：只保存人物主动行为、作用对象、变量变化及漫画依据。
- 3号题材分析库：保存题材配方、作品、角色阶段、章节场景和行为拍。

## 合流

`题材配方ID + 名词对象ID + 行为模式ID = 可画内容实例`

## 禁止

- 不从题材、职业、服装、场景或道具反推人物十元。
- 不把被转生、被传送、遭袭、获救、获胜等事件/结果冒充人物主动行为。
- 不为复合题材复制共享名词；复合专有对象进入 Bridge 模块。
