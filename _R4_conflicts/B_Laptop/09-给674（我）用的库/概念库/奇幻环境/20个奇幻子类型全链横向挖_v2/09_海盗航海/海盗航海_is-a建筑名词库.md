# 海盗航海 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：盐风、自由、危险的水域、船才是真正的家。

---

## v0 空间母体层

### 黑帆港
is-a 海盗港口
歪斜的木制码头延伸到灰绿色的海水中——桅杆密集如森林、旗帜与衣物在绳索上随风飘动、地面是混着贝壳碎片的泥土
可用于场景：海盗城镇全景 / 停靠补给 / 港口交易

### 雾海沉船湾
is-a 沉船聚集海湾
终年笼罩着浓雾的U形海湾——浅水区露出数十艘半沉的船骸、桅杆断裂且覆满藤壶、雾中海鸟的声音空洞
可用于场景：沉船探索 / 雾中航行 / 船坟

### 海盗酒馆
is-a 海盗聚集酒馆
低矮的木造建筑——大门歪斜、窗玻璃被震碎后用纸糊上的、内部昏暗只有壁炉与蜡烛、空气中混着麦酒与汗味
可用于场景：斗殴/赌博/情报交易 / 海盗社交 / 冲突起点

### 船长舱
is-a 海盗船指挥室
狭窄但精致的木质舱室——桌上的航海图已被翻到卷边、挂着磨损的指南针与弯刀、舱壁有嵌着弹孔
可用于场景：船长决策 / 密谋 / 发现隐藏地图

### 诅咒海峡
is-a 危险狭窄水道
两侧是锯齿状的黑色礁石——水道宽仅能通过一艘船、水流湍急、水下可见暗礁的阴影、岸上有沉船的残骸作为警示
可用于场景：险象航程 / 通过考验 / 地貌标志

### 宝藏岛洞穴
is-a 海盗藏宝洞
隐藏在瀑布后面的海蚀洞——洞内干燥处有木质宝箱残片、洞壁上刻着指向性符号（后继者加刻的）、地面散落着锈蚀的银币
可用于场景：寻宝高潮 / 洞穴探秘 / 发现宝藏/发现是空的

### 风暴灯塔
is-a 海岸灯塔
建在险峻礁石顶端的白色石塔——灯光旋转扫过海面、塔身有被风暴击打的裂缝、塔底的门常年被浪打湿
可用于场景：灯塔看守人 / 风暴中的光 / 最后的希望

### 海上集市
is-a 浮动交易市场
多艘大船用木板连接成的浮在水面的集市——每艘船卖不同的货物（武器/布料/食物/地图）、船与船之间用灯笼照明
可用于场景：水上交易 / 异国商品 / 渔火通明

### 破船墓场
is-a 废弃船只堆放地
在一片平坦的沙滩上排列着被拖上岸的废弃船只——船体被拆解只剩骨架、龙骨像肋骨一样指向天空、沙滩上散布着铁钉与碎木
可用于场景：船之墓地 / 拆船现场 / 海洋文明的遗骸

### 礁石要塞
is-a 海上防御堡垒
建在珊瑚礁盘上的黑色石堡——低矮、厚重、被海浪常年拍打、要塞的炮口指向所有方向、底层常年浸泡在海水中
可用于场景：海上堡垒 / 海盗的据点 / 易守难攻

## v1 典型空间层（以黑帆港为上位）

### 黑帆港废墟
is-a 废弃海盗港（上位：黑帆港）
码头栈桥断裂、木桩歪斜地立在水中、港口的仓库屋顶坍塌、地面堆积着被遗弃的货物箱与破碎的陶器
可用于场景：港口废弃 / 海盗散去 / 只剩下空壳

### 黑帆港圣所
is-a 废弃海神祭堂（上位：黑帆港）
港口的祈祷堂——供奉的不是海神而是"航海者之母"——神像的面部已被风化成模糊的轮廓、祭台上散落着贝壳与干燥的海星
可用于场景：无人祭拜的海神 / 风化神像 / 航海者的信仰遗忘

### 黑帆港大厅
is-a 废弃港口大厅（上位：黑帆港）
港口的交易大厅——木制柜台还在但桌面被撬走了一块、墙上钉着的海图被撕去一半、地面上有散落的骰子与碎酒杯
可用于场景：赌局散场 / 交易的残骸 / 只剩骰子

### 黑帆港回廊
is-a 废弃栈桥（上位：黑帆港）
连接码头与陆地的木质栈道——木板松动缺失、踩上去有咯吱声、有些地方完全断裂、下方是拍打的海水
可用于场景：险行栈道 / 脚下的海 / 废弃的连接

### 黑帆港祭坛
is-a 废弃起航祭台（上位：黑帆港）
港口尽头的石头平台——出航前最后祭风的地方——台上有一根刻满文字的木桩（记录每次出航）——最后一笔刻到一半
可用于场景：未完成的起航记录 / 最后一笔 / 出航中断

### 黑帆港庭院
is-a 废弃港口空地（上位：黑帆港）
港口被烧毁的仓库遗迹——焦黑的木桩与碳化的货物残留、地面覆盖着一层黑色的灰、雨水在地上积成灰水潭
可用于场景：烧毁的仓库 / 火后废墟 / 焦土

### 黑帆港钟楼
is-a 废弃港口警塔（上位：黑帆港）
港口入口处的圆木瞭望塔——塔顶的钟还在但绳已断、塔身倾斜约15度（地基被海浪淘空了一半）
可用于场景：歪斜的瞭望塔 / 钟哑 / 最后一次警报

### 黑帆港地下层
is-a 废弃走私隧道（上位：黑帆港）
港口下方有秘密的地下通道——通往海边的隐蔽洞穴、隧道狭窄潮湿、墙壁上有烛火烧出的黑斑
可用于场景：走私隧道 / 秘密运输 / 地下海路

### 黑帆港入口
is-a 废弃港口大门（上位：黑帆港）
由两根巨大鲸鱼骨构成的"凯旋门"——鱼骨已经开裂变黄、门柱上挂着褪色的黑色海盗旗
可用于场景：鲸骨门 / 海盗标志 / 进入遗弃之港

### 黑帆港核心区
is-a 废弃商船残骸（上位：黑帆港）
港口中央搁浅着一艘大船的半截残骸——船体从中间断裂、前半截已沉入泥沙、后半截如同雕塑般竖立、船尾的名字清晰可见
可用于场景：搁浅的残船 / 船的名字还在 / 最后的旗舰

## v2 状态侵蚀层（以黑帆港废墟为上位）

注意：海盗航海的侵蚀——盐/风/水/时间对所有木质结构的攻击。

### 黑帆港废墟被花蔓侵蚀
is-a 盐花（上位：黑帆港废墟）
不是真正的花——是盐分在木桩上结晶成的白色盐花簇群——像花一样开在腐朽的木头上、一碰就碎成粉末
可用于场景：盐之花 / 木头发花 / 化学的美丽

### 黑帆港废墟被荆棘缠绕
is-a 铁索藤（上位：黑帆港废墟）
生锈的铁链与绳索被水中的生物/海水腐蚀后交缠成尖刺状的"藤蔓"——硬冷的、覆满藤壶与贝壳
可用于场景：铁棘索 / 锈蚀的封锁 / 不再是绳而是刺

### 黑帆港废墟被树根穿刺
is-a 红树根入侵（上位：黑帆港废墟）
红树林的支柱根从水下伸入码头栈桥的缝隙——根将木板顶起变形、像无数从水中伸出的手指
可用于场景：红树吞港 / 水根入侵 / 潮间带的复仇

### 黑帆港废墟被苔藓覆盖
is-a 海苔覆盖（上位：黑帆港废墟）
绿色的海藻与苔藓混合覆盖了所有露出水面以上但潮湿的木质表面——滑腻的、腥味的、将木材包裹在绿色的壳中
可用于场景：绿苔包裹 / 港口穿绿衣 / 潮湿的腐朽

### 黑帆港废墟被菌丝寄生
is-a 船蛆菌丝（上位：黑帆港废墟）
真菌在浸水的木头上长出白色或淡黄色的菌丝网络——它们分解着木材、菌丝的表面聚着水滴（港口在"出汗"）
可用于场景：菌丝分解船体 / 港口在出汗 / 微生物的消化

### 黑帆港废墟被黑雾吞没
is-a 海雾（上位：黑帆港废墟）
与别处的黑雾不同——这里的雾是白色的/灰色的、浓到三步之外不见人、带着咸湿的味道、从海面包裹而来
可用于场景：海雾封锁 / 雾中港 / 迷失方向

### 黑帆港废墟被冰晶封存
is-a 盐结晶（上位：黑帆港废墟）
不是冰——是散落在木桩和绳索上的白色盐结晶、盐像霜一样附着在表面、在傍晚的光线下闪闪发光
可用于场景：盐霜 / 晚霞中的盐光 / 海盐如冰

### 黑帆港废墟被血迹污染
is-a 铁锈血（上位：黑帆港废墟）
木地板上的深红色——不是血迹了已经氧化到颜色与铁锈无异——分不清是锈还是血的地方曾是打斗最激烈处
可用于场景：血锈不分 / 战斗记忆 / 木纹中的暗红

### 黑帆港废墟被月光空壳化
is-a 月下船影（上位：黑帆港废墟）
月光洒在废弃港口——所有颜色褪去只剩下黑色与银灰、破损的船壳在月光下像巨兽的肋骨架
可用于场景：月照废港 / 银色与黑色 / 黑白海港

### 黑帆港废墟被星尘异化
is-a 星辉水母（上位：黑帆港废墟）
夜晚海水中漂浮着发光的水母群——水母涌入了港口的废弃水域、在漆黑的木桩之间发出幽幽的蓝光
可用于场景：发光水母 / 星光一样的海 / 水母入侵码头

## v3 内部功能空间层（以黑帆港废墟被花蔓侵蚀为上位——这里的"花蔓"=盐花）

### 黑帆港废墟被花蔓侵蚀中央空间
is-a 盐花广场（上位：黑帆港废墟被花蔓侵蚀）
港口的空地——地面上所有的木桩/石板边缘都覆满了白色的盐花结晶——像广场铺了一层白色的雪
可用于场景：盐花广场 / 白色覆盖码头 / 盐的领土

### 黑帆港废墟被花蔓侵蚀祭坛空间
is-a 盐花祭台（上位：黑帆港废墟被花蔓侵蚀）
祭台石板上盐花最密——像有人刻意在那里堆放了盐——盐花形成了波浪状的纹路
可用于场景：盐祭台 / 海盐的祭品 / 白色的祭物

### 黑帆港废墟被花蔓侵蚀回廊空间
is-a 盐花栈道（上位：黑帆港废墟被花蔓侵蚀）
栈道的栏杆上挂满了盐花——像冰挂一样垂下来、但在阳光下闪闪发光比冰更亮
可用于场景：盐花栏杆 / 闪闪发光的水边通道

### 黑帆港废墟被花蔓侵蚀洗礼池
is-a 盐池（上位：黑帆港废墟被花蔓侵蚀）
港口的浅水区——盐度极高、水面上漂浮着白色的盐膜反射着虹彩光、把手伸进水里拿出来手上全是白色细盐
可用于场景：高盐池塘 / 彩虹水面 / 手沾盐

### 黑帆港废墟被花蔓侵蚀祈祷室
is-a 盐花神龛（上位：黑帆港废墟被花蔓侵蚀）
祈祷堂的角落——盐花堆积在神像的底座周围像海浪的形状、神像的脚也被盐覆盖（像站在白色的水中）
可用于场景：神像被盐围住 / 海神的回应是盐

### 黑帆港废墟被花蔓侵蚀花窗大厅
is-a 盐窗（上位：黑帆港废墟被花蔓侵蚀）
木质窗户的玻璃上凝结着盐——盐在玻璃上结晶出像冰花一样的花纹、透过盐窗看到的外面世界是磨砂的模糊的
可用于场景：盐花玻璃 / 看出去模糊的世界 / 被盐封住的窗

### 黑帆港废墟被花蔓侵蚀地下墓穴
is-a 盐封舱（上位：黑帆港废墟被花蔓侵蚀）
走私隧道的一部分已被盐结晶完全封死——盐像石笋一样从顶部垂下、从地面长出、形成了白色的柱林
可用于场景：盐晶洞 / 白色钟乳 / 盐封的通道

### 黑帆港废墟被花蔓侵蚀钟楼
is-a 盐钟（上位：黑帆港废墟被花蔓侵蚀）
瞭望塔的木结构上挂满了盐花——远看像涂了一层白色的漆——钟面上也结了盐、覆盖了原本的刻字
可用于场景：白盐塔 / 钟被盐盖住 / 自然的白色外衣

### 黑帆港废墟被花蔓侵蚀圣像墙
is-a 盐雕墙（上位：黑帆港废墟被花蔓侵蚀）
墙上的浮雕被盐覆盖后所有细节都被抹平——只是一个白色的平面——但手指刮掉盐层下面浮雕还在
可用于场景：盐墙 / 掩盖之下 / 刮盐见雕刻

### 黑帆港废墟被花蔓侵蚀忏悔室
is-a 盐室（上位：黑帆港废墟被花蔓侵蚀）
只有半人高的盐堆积成的天然小隔间——像被盐包住了、蹲在里面能听到外面的海水声但看不到
可用于场景：盐的囚笼 / 白色的压缩空间 / 听力增强

## v4 最终复合场景层（中央空间10种变体）

### 黑帆港废墟被花蔓侵蚀中央空间复合场景
is-a 盐花中心标准版（上位：中央空间）
废弃广场上盐花以中央水洼为中心呈放射状结晶、水洼倒映着灰白色的天空、地面像被白色的经纬线画过
可用于场景：盐晶放射 / 白色广场 / 标准大全景

### 黑帆港废墟被花蔓侵蚀中央空间镜面版
is-a 盐花中心倒影版（上位：中央空间）
高盐水面的倒影比实物更清晰——天空在水中加倍地蓝、盐的白色在水中加倍地白——水总是在美化
可用于场景：盐水骗眼 / 加倍的颜色 / 倒影更好看

### 黑帆港废墟被花蔓侵蚀中央空间沉水版
is-a 盐花中心水淹版（上位：中央空间）
涨潮时海水漫入了广场——盐花全部泡在水中但不会被溶解（因为是高盐环境）、白色斑点在水面下像海底的星星
可用于场景：潮淹广场 / 水中盐星 / 脚下是大海

### 黑帆港废墟被花蔓侵蚀中央空间月光版
is-a 盐花中心月夜版（上位：中央空间）
月光洒在盐花上——盐晶体折射月光、整个广场像洒了一层碎银、比白天更亮
可用于场景：碎银广场 / 盐比月更亮 / 银色世界

### 黑帆港废墟被花蔓侵蚀中央空间黑水版
is-a 盐花中心油污版（上位：中央空间）
不知从哪泄漏的黑色焦油与海水混合涌入了广场——盐花被黑色物质包裹、白色晶体上覆着一层油亮亮的黑
可用于场景：油裹盐花 / 黑油入侵 / 白色消失

### 黑帆港废墟被花蔓侵蚀中央空间环形祭坛版
is-a 盐花中心仪式版（上位：中央空间）
有人在盐花中用小石子摆了一个锚的形状——海盗的临时祭奠痕迹、石子围成一个圆圈中间插着一根折断的舵柄
可用于场景：石头锚祭 / 海盗纪念 / 临时仪式

### 黑帆港废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 盐花中心淡水版（上位：中央空间）
广场地面裂开涌出淡水——淡水的涌入冲破了盐花层——在白色盐地上冲刷出一条透明的路径、像切开白色蛋糕
可用于场景：淡水破盐 / 清流穿白 / 新生

### 黑帆港废墟被花蔓侵蚀中央空间白花漂浮版
is-a 盐花中心浪花版（上位：中央空间）
浪花打上广场干燥后留下了泡沫的白色痕迹——泡沫在木桩和石头上形成新的盐花层、像泡沫开的花
可用于场景：泡沫之花 / 浪的礼物 / 潮水留下的白

### 黑帆港废墟被花蔓侵蚀中央空间枯井版
is-a 盐花中心井口版（上位：中央空间）
广场中央有一口古井——井口厚厚的盐花覆盖、扒开盐花向下看——井里不是水而是干的、井底有堆积的白骨（鱼的）
可用于场景：干井白骨 / 盐封的井口 / 遗忘的井

### 黑帆港废墟被花蔓侵蚀中央空间终帧版
