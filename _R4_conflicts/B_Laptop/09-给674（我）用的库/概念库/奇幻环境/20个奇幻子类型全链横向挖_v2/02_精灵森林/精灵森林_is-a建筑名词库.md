## v0 空间母体层

### 古老森林
is-a 原始林地空间
参天古木树冠遮天蔽日、林下只有斑驳的碎光、地表覆盖着厚厚的腐殖层与苔藓、空气中弥漫着湿润的木质香
可用于场景：深入禁林 / 精灵领地 / 自然朝圣

### 月泉林地
is-a 月华泉水森林
林间空地被月光笼罩的清澈泉水池塘、水面上浮着银色睡莲、泉底有发光的白色矿石、周围环绕着银色叶片的树木
可用于场景：精灵沐浴 / 月夜治愈 / 净水仪式

### 树冠城市
is-a 精灵树冠聚落
由巨大古树的枝干与藤蔓编织而成的空中聚落、树屋之间以藤编吊桥相连、树叶间漏下星点的天光
可用于场景：空中行走 / 精灵日常生活 / 俯瞰森林

### 精灵圣殿
is-a 精灵宗教建筑
由活树的枝干自然长成的拱形殿堂、树皮上刻满了精灵铭文、圣殿中央有生命之树的根系形成的天然王座
可用于场景：精灵王接见 / 圣物存放 / 祭祀活动

### 藤桥村落
is-a 精灵林间聚落
散布在溪谷两侧的低矮树屋群落、以藤蔓编织的吊桥连接两岸、房屋半嵌入古树根际或岩石中
可用于场景：村落实景 / 溪谷俯瞰 / 穿行邻里

### 银叶庭院
is-a 精灵林间庭院
人工修剪过的低矮树篱围合出规整的几何庭院、地面铺着白色卵石、中央种着一棵银叶古树——叶子的背面是银白色的
可用于场景：精灵贵族生活 / 静谧对话 / 宴会场

### 林间祭坛
is-a 精灵自然祭坛
露天的圆形石台、被一圈古树环抱、祭台上刻有日月的纹路、四周的树根自然地攀上石台形成台阶
可用于场景：精灵祭祀 / 日月观测 / 自然之力显现

### 隐雾溪谷
is-a 精灵溪谷地貌
终日笼罩着薄雾的溪谷、溪水清澈见底、两岸长满了蕨类与野花、雾中能听到水声但看不清对岸
可用于场景：神秘遭遇 / 涉水前进 / 雾中穿行

### 星光树屋
is-a 精灵高塔居所
建在森林最高大的古树顶端的树屋、露台可望见整片森林的天际线、屋顶用某种半透明的茧膜覆盖（透入星光）
可用于场景：精灵居室内景 / 夜空观测 / 高处视角

### 永生树根庭
is-a 精灵地下根茎空间
古树的巨大根系形成的天然地下厅堂、树根如巨柱般支撑着穹顶、根缝间渗出闪光的树汁、空气中弥漫着古老的生命气息
可用于场景：通往树心 / 根茎迷宫 / 最古老的精灵遗迹

## v1 典型空间层（母体→废墟，以古老森林为上位）

### 古老森林废墟
is-a 废弃林地遗迹（上位：古老森林）
森林深处的古老精灵建筑遗迹——石质拱门与柱廊半埋在苔藓与落叶中、断续的石阶通向不知何处、石面被雨水冲刷得光滑
可用于场景：发现遗迹 / 探秘入口 / 岁月痕迹

### 古老森林圣所
is-a 废弃林地圣殿（上位：古老森林）
半塌的圆形石殿、穹顶已坍塌大半、但中央的精灵神像仍完好伫立、藤蔓从神像的肩膀垂落像是披风
可用于场景：精灵圣地 / 发现神迹 / 旧日荣光

### 古老森林大厅
is-a 废弃林地集会厅（上位：古老森林）
由古树根支撑的天然大厅、石铺地面已碎裂、破碎的精灵陶器与枯叶混在一起、树根从墙壁的裂缝中渗入
可用于场景：森林集会遗迹 / 隐藏信息 / 残垣断壁

### 古老森林回廊
is-a 废弃林地走廊（上位：古老森林）
两侧生长着扭曲的古树形成天然柱廊、树冠在头顶交错形成拱形隧道、光从树叶缝隙中洒下形成光斑小径
可用于场景：林间漫步 / 光影隧道 / 秘密通道

### 古老森林祭坛
is-a 废弃林地祭台（上位：古老森林）
中央的石制祭台已碎裂成数块、周围的精灵文字被苔藓覆盖大半、能看出原本是一个环形祭祀场
可用于场景：遗失的仪式 / 触发机关 / 自然收复

### 古老森林庭院
is-a 废弃林地庭院（上位：古老森林）
被矮墙围合的长方形庭院、中间的喷泉已干涸、庭院的地面被草皮和野花完全覆盖、墙边有残破的石凳
可用于场景：短暂休憩 / 遮阴处 / 林间光影

### 古老森林钟楼
is-a 废弃林地塔楼（上位：古老森林）
石造尖塔从树冠中穿出、塔身已被藤蔓完全包裹、塔顶的钟已不知去向、只余钟绳在风中空荡
可用于场景：攀爬灯塔 / 瞭望森林 / 风中的空响

### 古老森林地下层
is-a 废弃林地地下室（上位：古老森林）
树根盘绕的地下空间、根须像帘幕一样从天花板垂下、泥土中混杂着碎石与碎骨、空气中的菌味很重
可用于场景：地下隐藏 / 深根迷宫 / 隐秘仪式

### 古老森林入口
is-a 废弃林地大门（上位：古老森林）
两棵巨大的古树自然形成的拱门状入口、树皮上刻有年代久远的精灵文——大部分已模糊不清、地上的藤蔓形成门槛
可用于场景：踏入未知 / 进入禁地 / 庄严入口

### 古老森林核心区
is-a 废弃林地中枢（上位：古老森林）
最深处——所有古树的根系在此交汇形成一个巨大的根系网络中心、中央地面有塌陷的深坑通向更深层
可用于场景：精灵中枢 / 世界树根 / 通往地下世界

## v2 状态侵蚀层（废墟→自然/超自然改造，以古老森林废墟为上位）

### 古老森林废墟被花蔓侵蚀
is-a 花蔓覆盖林地废墟（上位：古老森林废墟）
粉紫色的野花从石缝中涌出、花蔓像彩带般挂在残垣上、石面被晒暖——花与石的温柔共生
可用于场景：浪漫古林 / 花开无声 / 精灵归来

### 古老森林废墟被荆棘缠绕
is-a 荆棘封锁林地废墟（上位：古老森林废墟）
黑铁色的粗荆棘像铁链一样缠绕着残石与枯木、尖刺如钩、空气中透着被封锁的窒息感
可用于场景：无法通行 / 黑暗封锁 / 危险逼近

### 古老森林废墟被树根穿刺
is-a 树根破坏林地废墟（上位：古老森林废墟）
新生古树的巨根直接贯穿了石砌结构、石墙被根系撕裂成碎石堆、树根如蛇般在地面蜿蜒
可用于场景：新旧更替 / 自然不可抗拒 / 森林重新占领

### 古老森林废墟被苔藓覆盖
is-a 苔藓林地废墟（上位：古老森林废墟）
绿色、金色、深褐色的苔藓如同地毯般覆盖了所有表面、踩上去柔软而安静、空气中弥漫着雨后泥土的气息
可用于场景：静谧绿意 / 精灵后花园 / 时间的厚度

### 古老森林废墟被菌丝寄生
is-a 真菌林地废墟（上位：古老森林废墟）
荧光蓝色的菌丝从石缝中蔓延出蛛网状的光网、蘑菇群在废墟中形成同心圆阵列、孢子发光体在暗处照明
可用于场景：发光森林 / 精灵魔法残留 / 超现实画面

### 古老森林废墟被黑雾吞没
is-a 黑雾林地废墟（上位：古老森林废墟）
与龙与魔法的黑雾不同——这里的黑雾更像是沼泽瘴气、呈灰绿色而非纯黑、贴着地面涌动、有腐木的气味
可用于场景：毒雾区 / 瘴气林 / 有危险的未知

### 古老森林废墟被冰晶封存
is-a 冰封林地废墟（上位：古老森林废墟）
冰晶从树根与石缝中生长出来、将枝叶与碎石一起冻成了玻璃般的雕塑、光线在冰晶中折射出斑斓
可用于场景：反常冰封 / 时间停止 / 精灵休眠期

### 古老森林废墟被血迹污染
is-a 血迹林地废墟（上位：古老森林废墟）
褐色的陈旧血迹溅在白色石面和树根上、血迹呈飞溅状和拖拽状——不只是伤势而像是某种献祭的痕迹
可用于场景：狩猎现场 / 献祭遗迹 / 精灵堕落

### 古老森林废墟被月光空壳化
is-a 月光异化林地废墟（上位：古老森林废墟）
月下的废墟如同褪色——所有颜色在月光下变成灰蓝与银白、树皮呈现骨质的哑光白、整个场景仿若静态遗骸
可用于场景：月下梦境 / 精灵冥想 / 半透明异界

### 古老森林废墟被星尘异化
is-a 星尘林地废墟（上位：古老森林废墟）
银绿色的星尘散落在树皮与石面上微微发光、地面出现了不自然的几何裂纹、裂缝中渗出光——不是自然的
可用于场景：天外来客 / 神力降临 / 精灵的远古协助者
