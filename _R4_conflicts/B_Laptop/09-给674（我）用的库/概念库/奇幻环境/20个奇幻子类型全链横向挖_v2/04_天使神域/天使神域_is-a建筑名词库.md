# 天使神域 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

---

## v0 空间母体层

### 云上圣堂
is-a 云端神圣殿堂
浮于云海之上的纯白大理石教堂——成排的白色穹顶与尖塔穿透云层、所有表面洁白无瑕、金色阳光从云隙中如圣光般照亮
可用于场景：天堂大门 / 圣城全景 / 天使降临

### 光之神殿
is-a 纯光神圣空间
没有实体墙壁——由凝聚的光柱围合出的环形空间、光柱之间流动着半透明的能量膜、地面是光可鉴人的白色大理石
可用于场景：光之领域 / 天使议事 / 神谕之地

### 天阶广场
is-a 白色台阶广场
由一层层通向天际的白色大理石台阶构成的广场——台阶无限延伸至云端、每一级台阶宽度刚好、两侧有天使雕塑
可用于场景：登天之路 / 神圣行进 / 仰望苍穹

### 审判穹顶
is-a 云端审判空间
半圆形白色穹顶建筑、穹顶内壁有全视之眼的浮雕、正中央圆环下方是审判之座、光线从穹顶中央的窗口垂直射下
可用于场景：天使审判 / 罪孽陈述 / 裁决时刻

### 白石回廊
is-a 白色柱廊空间
排列着白色科林斯柱的弧形回廊——柱子间距精确相等、以半圆形式延伸消失在云中、柱间是翻涌的云海背景
可用于场景：天使漫步 / 思考踱步 / 秩序之美

### 羽翼钟楼
is-a 天使钟楼
高耸的白石钟楼——钟楼的四个角上各有一座展翅天使的白色雕塑指向四方、钟楼的钟声传播时云层会裂开
可用于场景：钟响云裂 / 天使报时 / 俯瞰云海

### 圣歌庭院
is-a 天使歌唱庭院
被弧形回廊围合的圆形露天庭院、中央有喷泉（喷出的水在阳光中形成彩虹）、空气中持续有微弱的圣歌回响
可用于场景：天使合唱 / 圣水喷洒 / 和平景象

### 光柱祭坛
is-a 光柱祭台
没有实体祭台——而是从天而降的一道光柱照亮地面上的金色光环位置、光柱内部可见飘浮的细微金色颗粒
可用于场景：神迹降临 / 祈祷场所 / 超自然之光

### 天门平台
is-a 云上入口平台
云海之上凸出的白色平台——平台边缘有巨大的金色门框（没有门扇）、跨过门框即是虚空云海、像跨越生死的边界
可用于场景：进入神域 / 告别凡间 / 边界之门

### 云端王座厅
is-a 天使王座空间
最高处的拱形大厅——白色王座由凝固的光与白色石构成、王座背后是整面半透明的光墙（像彩色玻璃但由纯光组成）
可用于场景：天使之王 / 至高权力 / 神圣王座

## v1 典型空间层（以云上圣堂为上位）

### 云上圣堂废墟
is-a 废弃云上殿堂（上位：云上圣堂）
白色的石柱断裂倾颓、部分建筑断裂面漂浮在云层中——不是重力坍塌而是被某种力量切断的、断裂面平滑如镜
可用于场景：天界陨落 / 神圣废墟 / 断壁浮空

### 云上圣堂圣所
is-a 废弃天使圣所（上位：云上圣堂）
封闭的小型祈祷室——墙壁上天使浮雕的面部已被磨去（不是风化而是被刻意抹除）、室内的圣光已经熄灭变成灰蒙蒙的
可用于场景：被遗忘的圣所 / 面目被抹去的天使 / 失落的神性

### 云上圣堂大厅
is-a 废弃天界大厅（上位：云上圣堂）
主厅的穹顶还在但部分碎裂、碎石像星星一样漂浮在半空（该区域重力异常）、地面的大理石拼花图案依然完好
可用于场景：重力异常的残厅 / 浮石环境 / 残缺的壮丽

### 云上圣堂回廊
is-a 废弃柱廊（上位：云上圣堂）
柱子整齐排列但部分已断、断裂的柱头漂浮在原本的位置——像停留在时间被冻结的时刻、柱间云海翻涌依旧
可用于场景：柱间漫步 / 凝固的崩溃 / 历史一幕

### 云上圣堂祭坛
is-a 废弃祭坛（上位：云上圣堂）
光柱祭坛已熄灭——地面上只余一个金色的圆环痕迹、圆环内的光芒消失后留下的是与周围一模一样的大理石面、像是从未有过光
可用于场景：神已离去 / 空祭坛 / 光之火熄

### 云上圣堂庭院
is-a 废弃圣庭院（上位：云上圣堂）
被回廊围合的庭院——喷泉已干涸、池底有干裂的白石泥、庭院中散落着白色碎裂的天使塑像残肢
可用于场景：破碎的天使 / 干枯的圣泉 / 静默之所

### 云上圣堂钟楼
is-a 废弃钟楼（上位：云上圣堂）
钟楼依然耸立但顶部的天使雕塑已断翅、断翅的残片插在塔身的白色石面中——像一支巨大的白箭
可用于场景：断翅天使 / 塔楼孤影 / 云中灯塔

### 云上圣堂地下层
is-a 废弃圣堂地下室（上位：云上圣堂）
云上圣堂居然有地下层——白色大理石阶梯向下通向昏暗、墙壁上不是天使浮雕而是人形的暗影浮雕（像是天使的反面）
可用于场景：天使的背面 / 暗面 / 神圣之下的阴影

### 云上圣堂入口
is-a 废弃圣堂大门（上位：云上圣堂）
巨大的金色双门半开——但门已经褪色变成暗铜色、门上天使的羽翼浮雕被划伤、门槛处堆积着从外面吹来的云絮
可用于场景：踏入失落天堂 / 门后半是光半是暗 / 边界

### 云上圣堂核心区
is-a 废弃圣堂中心（上位：云上圣堂）
曾经最神圣的地方——如今地面中央有一道裂口直穿云层可以望见下方的大地、裂口边缘的光芒像被撕裂后仍在挣扎
可用于场景：天堂之裂 / 光泄漏 / 天界被贯穿

## v2 状态侵蚀层（以云上圣堂废墟为上位）

注意：天使神域被侵蚀的特殊性——不是被自然占领（这是堕落/衰退过程），而是**神圣材质被异化**。

### 云上圣堂废墟被花蔓侵蚀
is-a 花蔓侵蚀神圣废墟（上位：云上圣堂废墟）
白色大理石表面生长出银色叶片的藤蔓——不是自然的藤蔓而是像光丝凝固成的植物形态、月光下闪着柔和的银光
可用于场景：神圣侵蚀 / 银色藤蔓 / 光之寄生

### 云上圣堂废墟被荆棘缠绕
is-a 暗棘缠绕神圣废墟（上位：云上圣堂废墟）
黑色的荆棘从圣堂的裂缝中疯狂生长——荆棘的刺上凝结着黑色的水滴（不是水），像鲜血但更浓
可用于场景：黑暗入侵 / 神圣被污 / 荆棘锁圣堂

### 云上圣堂废墟被树根穿刺
is-a 树根穿刺神圣废墟（上位：云上圣堂废墟）
巨大的灰色树根从石块中爆裂而出——树根的物质不同于木头、更接近凝固了的灰色光、像某种介于植物与光之间的东西
可用于场景：光之树根 / 神圣与自然的混合 / 异化结构

### 云上圣堂废墟被苔藓覆盖
is-a 金银苔藓废墟（上位：云上圣堂废墟）
苔藓不是绿色——是金与银交织的金属色苔藓、覆盖在大理石表面像一层活的金属皮、在光下闪烁
可用于场景：金属苔原 / 奢华腐朽 / 活力金属

### 云上圣堂废墟被菌丝寄生
is-a 光菌寄生废墟（上位：云上圣堂废墟）
白色的菌丝像棉絮一样从大理石的裂缝中涌出——不是蘑菇而是像凝固的光的菌丝体、在黑暗中发出苍白的冷光
可用于场景：光菌扩散 / 苍白的寄生 / 被光吞噬

### 云上圣堂废墟被黑雾吞没
is-a 暗雾吞没废墟（上位：云上圣堂废墟）
黑雾与云上圣堂的白色形成极端对比——雾是纯黑的、流动的、有重量的、像倒置的星云沉淀在圣堂的低洼处
可用于场景：光与暗交界 / 雾分黑白 / 暗界侵略

### 云上圣堂废墟被冰晶封存
is-a 寒冰封存废墟（上位：云上圣堂废墟）
冰晶不是透明而是半透明白色——与白色大理石融为一体难以区分、冰包裹的圣堂像被封印在琥珀中、时停
可用于场景：被时停的圣堂 / 白色中的白色 / 极寒天堂

### 云上圣堂废墟被血迹污染
is-a 血迹污染神圣废墟（上位：云上圣堂废墟）
金色与红色交织的血迹洒在白色地面上——这是天使的血吗？金色血迹在白色石面上格外刺眼、像某种罪证的烙印
可用于场景：天使之血 / 堕落现场 / 金色罪证

### 云上圣堂废墟被月光空壳化
is-a 月光漂白废墟（上位：云上圣堂废墟）
——但圣堂本身就是白色，月光下白色叠加白色变成了一种异常：所有的白色变成发蓝的冷白、大理石质感消失变成石膏般的哑光白
可用于场景：白到失真的月下 / 颜色被抽走 / 幽灵圣堂

### 云上圣堂废墟被星尘异化
is-a 星尘异化废墟（上位：云上圣堂废墟）
金色的星尘沾染在白色大理石表面——大理石像被镀了一层金、金色的纹路像血管一样在石面蔓延、仿佛圣堂有了心跳
可用于场景：星尘镀金 / 神圣金化 / 天界的第二次呼吸

## v3 内部功能空间层（以云上圣堂废墟被花蔓侵蚀为上位）

### 云上圣堂废墟被花蔓侵蚀中央空间
is-a 银色藤蔓中央厅（上位：云上圣堂废墟被花蔓侵蚀）
银色叶片的藤蔓从穹顶垂下来形成银色的幕帘、中央地面被银色藤蔓编织出一张天然地毯——像被光网包裹
可用于场景：银色光网 / 被笼罩的中心 / 光丝阵

### 云上圣堂废墟被花蔓侵蚀祭坛空间
is-a 银色藤蔓祭坛（上位：云上圣堂废墟被花蔓侵蚀）
祭坛被银色藤蔓缠成一个茧状——透过藤蔓的缝隙可见内部的祭坛表面已经变成了灰色、像光被吸走了
可用于场景：被包裹的圣坛 / 失去光芒 / 藤蔓之茧

### 云上圣堂废墟被花蔓侵蚀回廊空间
is-a 银色藤蔓柱廊（上位：云上圣堂废墟被花蔓侵蚀）
银色藤蔓沿着柱身螺旋向上生长、柱子之间藤蔓交织成拱形——让人分不清是人的建筑还是植物长成了建筑
可用于场景：光蔓之廊 / 自然与神圣交融 / 银光隧道

### 云上圣堂废墟被花蔓侵蚀洗礼池
is-a 银色藤蔓洗礼池（上位：云上圣堂废墟被花蔓侵蚀）
水池中的水被银色藤蔓的汁液染成了银灰色——水面呈金属镜面效果、倒映出的像不是彩色而是黑白的
可用于场景：银水之镜 / 黑白倒影 / 失色的洗礼

### 云上圣堂废墟被花蔓侵蚀祈祷室
is-a 银色藤蔓祈祷室（上位：云上圣堂废墟被花蔓侵蚀）
银色藤蔓在祈祷室的四面墙上织出了一个完整的人形轮廓——像是银植物以自己的方式重新绘制了祈祷者的形象
可用于场景：藤蔓绘人 / 自然的祈祷 / 无人的祈祷室

### 云上圣堂废墟被花蔓侵蚀花窗大厅
is-a 银色藤蔓花窗厅（上位：云上圣堂废墟被花蔓侵蚀）
银色藤蔓将原有的彩色玻璃花窗的缝隙全部填满——但透过藤蔓的光变成了银白色、原本的彩色消失了
可用于场景：银光花窗 / 色彩被替换 / 单一色的光

### 云上圣堂废墟被花蔓侵蚀地下墓穴
is-a 银色藤蔓地宫（上位：云上圣堂废墟被花蔓侵蚀）
地下墓穴的白色石棺被银色藤蔓像网一样缠住——藤蔓的根钻入石棺的缝隙、从里面长出的银色叶片在棺盖上微微发光
可用于场景：天使墓穴 / 光丝缠绕遗骸 / 银色安息

### 云上圣堂废墟被花蔓侵蚀钟楼
is-a 银色藤蔓塔楼（上位：云上圣堂废墟被花蔓侵蚀）
银色藤蔓从塔楼窗口倒垂下来形成银色的瀑布状、铜钟被藤蔓包裹成银色球体——敲响时发出的声音像银色在振动
可用于场景：银钟塔 / 钟声如银 / 被自然改装的钟

### 云上圣堂废墟被花蔓侵蚀圣像墙
is-a 银色藤蔓浮雕墙（上位：云上圣堂废墟被花蔓侵蚀）
墙上的天使浮雕被银色藤蔓沿着轮廓覆盖——浮雕像被贴上了银箔、天使的轮廓在银色下依然可见、像被镀了一层银
可用于场景：银箔天使 / 镀银浮雕 / 神圣镀层

### 云上圣堂废墟被花蔓侵蚀忏悔室
is-a 银色藤蔓隔间（上位：云上圣堂废墟被花蔓侵蚀）
狭小的木质隔间已被银色藤蔓从内部撑开变形——藤蔓从木板缝隙中挤出、忏悔室的窗格被银叶封死
可用于场景：藤蔓忏悔 / 被自然见证 / 银蔓囚室

## v4 最终复合场景层（中央空间10种变体）

### 云上圣堂废墟被花蔓侵蚀中央空间复合场景
is-a 银色藤蔓中心标准版（上位：中央空间）
银色藤蔓从穹顶到地面拉出无数条银色细线、像竖琴的琴弦——光在这些线之间跳动、中央地面有银色藤蔓织成的圆形王座
可用于场景：银光竖琴 / 光弦振动 / 标准大全景

### 云上圣堂废墟被花蔓侵蚀中央空间镜面版
is-a 银色藤蔓中心倒影版（上位：中央空间）
地面的银灰色积水完全静止——倒映出银色藤蔓和穹顶的裂缝、上下颠倒后仿佛又一座倒置的圣堂在镜面中展开
可用于场景：镜中圣堂 / 倒置天堂 / 对称梦境

### 云上圣堂废墟被花蔓侵蚀中央空间沉水版
is-a 银色藤蔓中心水淹版（上位：中央空间）
银色液体漫过了地板——不是水而是银色藤蔓分泌的汁液累积成的浅池、液面平稳如镜、银色藤蔓从液面中长出
可用于场景：银液池塘 / 涉过银水 / 水面下的藤蔓

### 云上圣堂废墟被花蔓侵蚀中央空间月光版
is-a 银色藤蔓中心月夜版（上位：中央空间）
月光下银色藤蔓发出极亮的银白色光——整个空间被自身的银色光照亮、大理石和藤蔓的界限消失，只剩下银白色的轮廓
可用于场景：银光自发光 / 月色银爆 / 天堂之月

### 云上圣堂废墟被花蔓侵蚀中央空间黑水版
is-a 银色藤蔓中心黑化版（上位：中央空间）
银色藤蔓变成灰黑色、叶片枯萎卷曲、地面的积水变成黑色、银色光消失了——被某种力量熄灭了
可用于场景：银色熄灭 / 黑化圣堂 / 光之死

### 云上圣堂废墟被花蔓侵蚀中央空间环形祭坛版
