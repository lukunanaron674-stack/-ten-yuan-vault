# 运转中

## 一句话定义

空间正在被使用，规则在运行。这是空间的默认状态——它正在做它被设计来做的事。

## 十元映射强度

| 项目 | 内容 |
|---|---|
| 主点位 | xn |
| 副点位 | 无 |
| 点位强度 | 3 / 10 |
| 关系五对 | 无（单点位） |
| 关系强度 | - |
| 动态链强度 | 2 / 10 |
| 五大主题归仓 | 时间型（xn+z） |
| 归仓强度 | 4 / 10 |
| 判断理由 | 运转中是一个空间的默认状态，十元在场感最弱——就像呼吸一样自然。点位强度3不是因为不重要，是因为太正常了。 |

## 视觉元素

- 正常运作的痕迹——灯光亮着/设备运行/人进出
- 维护的痕迹——清洁/维修/更新
- 活力的痕迹——声音/温度/气味/运动

## 典型场景

- 正在使用的办公室：电脑亮着/咖啡杯/电话响
- 运转中的工厂：机械声/传送带/工人操作
- 活跃的街道：行人/车流/店铺营业

## 可组合对象

①所有空间母体 ②所有题材 ④所有功能 ⑤所有氛围（根据具体空间不同）

## 误判检查

🔴 运转中=无聊 -> 运转中的活力本身就是一种氛围

## 封存句

运转中的空间不需要被注意——它只是在那里，正常地活着。
