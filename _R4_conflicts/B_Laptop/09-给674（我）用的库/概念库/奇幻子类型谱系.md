# 🧙 奇幻环境设计 · 完整子类型谱系

## 核心公式

奇幻 = xz（边缘/不可能）+ zn（新意义体系）

所有子类型都是 xz 与 zn 的不同配比，再加入第三个十元作为风味。

---

## 一、光明侧（zn占主导）

| 子类型 | 十元结构 | 一句话 | 能否分化黑暗面？ |
|:------|:--------|:-------|:--------------:|
| 🐉 龙与魔法 | zn+ALL | 全十元调度，史诗级世界观 | 可→黑龙/邪龙（x侵蚀zn） |
| 🧝 精灵/森林 | zn+n | 永生的栖息地，神性有形状 | 可→堕精灵/黯精灵（zn被nx替代） |
| 🌳 自然之灵 | zn+ nz | 森林本身的意志，不为人存在 | 可→腐化森林（nz被x污染） |
| 🕊️ 天使/神域 | zn+ zx | 神圣秩序的世界，光即法则 | 可→堕天使领域（zn被xn取代） |
| 🌅 远古/创世 | zn+ xz | 世界诞生之初，意义还未被定义 | 黑暗面即"意义被遗忘之后" |
| 🏛️ 乌托邦/仙境 | zn+ x并z | 看起来完美——但那是壳 | 黑暗面天然内置（完美是伪装） |

**光明侧 = zn在50%以上，世界有"对"的方向感。**

## 二、中性侧（zn与xz平衡）

| 子类型 | 十元结构 | 一句话 | 能否分化黑暗面？ |
|:------|:--------|:-------|:--------------:|
| 🗿 矮人/地底 | xn+zx | 矿物与锻冶文明，地下的秩序王国 | 可→矮人废墟（xn坍塌→nx） |
| 🔮 秘术/学院 | xn+zn | 规则与意义共存，知识即力量 | **可**→见下方独立分化 |
| ⚓ 海盗/航海 | xz+zx | 边缘世界的执行力，游离于秩序之外 | 可→诅咒之海（zx被x替代） |
| ⏳ 时间/古代遗迹 | xz+ nz | 被遗忘的文明在等被重新发现 | 可→时间诅咒（nz被x污染） |
| 🛡️ 骑士/王国 | zx+ xn | 封建秩序的荣耀与执行 | 可→堕落的骑士团（zx被nx替代） |
| 🎪 游牧/流浪 | xz+ n | 不在任何地方扎根，容器是流动的 | 可→被诅咒的流浪者（n被xz吞噬） |
| ⛰️ 巨人/山脉 | n+ xz | 巨大沉默的承载者，边缘的守护 | 可→被腐蚀的山脉（n被x污染） |

**中性侧 = zn和xz配比接近，风味由第三个十元决定。**

## 三、秘术/学院的分化（你问的）

**秘术/学院** = xn+zn（规则+意义）——这是奇幻中最特殊的类型，因为它的核心不是空间，而是**知识体系**。

### 它可能的分化方向：

```
🔮 秘术/学院（xn+zn 规则+意义）
  │
  ├── 🏛️ 正统学院派（xn主导）
  │    魔法有严格的体系/考试/等级
  │    规则重于一切
  │    如：霍格沃茨、魔法学院的日常
  │
  ├── 🔥 禁忌秘术派（x潜入xn）
  │    看似有规则，但底层是欲望驱动
  │    黑魔法/禁书/献祭
  │    如：咒术回战的束缚、钢炼的等价交换
  │
  ├── 🤫 隐秘结社派（xn+nx）
  │    知识是权力的暗账
  │    秘密比魔法更强大
  │    如：共济会/玫瑰十字会的奇幻版
  │
  ├── 🌌 上古传承派（zn主导）
  │    秘术不是学来的
  │    是血脉/使命/宿命
  │    如：降世神通、Dune的贝尼·杰瑟里特
  │
  └── 💀 秘术学院的黑暗面
       ├── 知识有代价→x（每一页书都是献祭）
       ├── 知识即诅咒→xz（知道太多的人被放逐）
       └── 知识是谎言→x并z（学院本身就是骗局）
```

## 五、还有多少分支没列？

我已经列了 **6（光明侧）+ 7（中性侧）+ 7（黑暗侧）= 20个子类型**。

可以继续细分的还有：

| 待展开 | 十元推测 | 说明 |
|:------|:--------|:-----|
| 🧜 人鱼/深海 | xz+ nz | 深海的边缘与等待——但不属于陆地 |
| 🏜️ 沙漠/荒原 | xz+ n | 巨大的空旷容器，边缘得不能再边缘 |
| 🌋 火山/熔岩 | x+ z | 欲望的爆发与显现——大地的怒火 |
| 🧊 冰原/北境 | nz+ xz | 寒冷中的等待，一切都是静止的 |
| 🌙 月下/梦境 | nz+ zn | 介于两者之间——意义在梦中显现 |
| 🦋 妖精/幻象 | x并z+ zn | 看起来美丽但不可信任，表面≠里面 |
| ⚙️ 机械/魔法朋克 | xn+ zx | 规则被物化为齿轮——魔法的工业化 |
| 🧬 血肉/生物朋克 | x+ xz | 欲望长出了身体——魔法的肉体化 |
| 🧠 心像/精神空间 | n+ zn | 世界是内心投射的容器——意义即现实 |
| 🎭 假面/伪装世界 | x并z+ n | 整个世界的表面——没有什么是真实的 |

**总计约30个可展开子类型。** 每个都可以有一张子画布。

## 六、建议的展开优先级

如果你想要我做新的canvas子画布，按这个顺序推荐（从最"有料"的开始）：

1. 🔮 秘术/学院（xn+zn）← 你问的，且有丰富分化
2. 🗿 矮人/地底（xn+zx）← 特殊的中性规则型
3. 💀 亡灵/诅咒（nx+x）← 黑暗侧最经典
4. 🌊 深渊/混沌（xz+x）← 黑暗奇幻的源头
5. ⛪ 哥特奇幻（zn+xz）← 你原始链里已经走到这了
6. 🔥 末世废土（xn+x）← 规则的彻底崩塌
