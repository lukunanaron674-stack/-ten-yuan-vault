# 原子卡模板

## 文件名命名规则

`N.N.N-概念名.md`，从大到小编号：

- `1.0-框架.md` — 主题级框架
- `1.1-子域.md` — 子域级
- `1.1.1-原子概念.md` — 原子级

每个原子卡 YAML 头部需包含 index 和 parent 字段。

## 原子卡结构

每张原子卡包含两个核心模块：

### 1. 原版概括（Pure Knowledge）
该概念的原始知识，精炼后的核心内容。包含：
- 定义/说明
- 关键示例
- 核心要点

### 2. 三元分析（Ten-Yuan Interpretation）
用十元体系（x/z/n）重新解剖：

- **x（现象）**: 看得见的具体表现
- **z（本质）**: 底层原理和结构
- **n（应用）**: 与其他概念的连接和应用
