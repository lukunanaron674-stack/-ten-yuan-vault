# 08｜组合生成器

> 用来从零生成故事种子，也用来检查已有想法究竟是“题材”还是几个漂亮词挤在同一张海报上。

# 一、十步生成法

```text
01 选主题材：最终回报属于哪种欲望
02 选驱动题材：每话靠什么持续发生事件
03 选调味题材：职业、视觉与生活质感
04 选主角主体：他有什么行动资格和缺口
05 选对手主体：谁更有资格得到同一对象
06 选关系对象：为什么两人不能简单分开
07 选资源/秘密：什么能改变权力并被公开
08 选场域规则：违反规则会受到什么惩罚
09 选行为链：中段怎样发生位置反转
10 选季终回报：哪项对象状态永久改变
```

# 二、主题材选择表

| 最终想让读者获得什么 | 优先主题材 | 常用大回报 |
|---|---|---|
| 被明确选择 | 契约婚姻、禁忌恋、旧爱重逢 | 公开站队、去掉契约后返回 |
| 被承认为有资格 | 继承、职场、学院、艺术 | 夺回身份、署名、席位 |
| 看弱者翻盘 | 回归、猎人、复仇、创业 | 越级击败、证据反杀 |
| 改变注定失败的结局 | 回归、穿书、恶役、循环 | 旧节点被改写、预言失效 |
| 破解真相 | 悬疑、腐败、怪谈 | 真凶、结构或规则显形 |
| 找到归属 | 临时家庭、乡村、邻里 | 留下位置、主动称为家人 |
| 夺回自主权 | 控制关系、机构异能、政治联姻 | 归还钥匙、拒绝命令、重订规则 |
| 在失去后继续生活 | 疗愈、家庭、宠物、旧爱 | 告别、建立新节奏 |

# 三、驱动题材选择表

| 需要的连载发动机 | 驱动题材 | 可重复事件单元 |
|---|---|---|
| 每话有任务 | 系统、猎人、公会、职业剧 | 接任务→执行→奖励/惩罚 |
| 每话有社交冲突 | 豪门、贵族、职场、娱乐圈 | 宴会/会议→羞辱→站队→舆论 |
| 每话有线索 | 悬疑、腐败、怪谈 | 异常→调查→误导→新证据 |
| 每话有关系推进 | 同居、契约、保镖、宿敌 | 越界→反制→照料→重新设限 |
| 每话有成长指标 | 学院、体育、电竞、登塔 | 训练→测试→排名→新对手 |
| 每话有生存选择 | 末日、生存游戏、囚禁 | 资源不足→分配→背叛→迁移 |
| 每话有经营结果 | 创业、美食店、领地经营 | 客户/订单→生产→评价→扩张 |
| 每话有命运偏差 | 回归、穿书、循环 | 预测→干预→意外变化→知识失效 |

# 四、对象组合矩阵

## 1. 主体 + 目标对象

| 主体 | 最适合争夺的目标对象 |
|---|---|
| 被逐继承人 | 合法身份、股份、家族真相、民意 |
| 负债普通人 | 生存资金、契约退出权、职业机会 |
| 恶役/污名者 | 叙述权、无罪证明、独立资源 |
| 回归者 | 关键时间点、旧友生存、未来资源 |
| 高位继承人 | 真诚信任、继承控制权、私人选择 |
| 隐藏强者 | 不被工具化的自由、队伍主导权 |
| 间谍/共犯 | 真实忠诚、证据、退出路线 |
| 临时监护者 | 监护资格、稳定生活、被需要感 |

## 2. 关系 + 资源

| 关系对象 | 推荐资源对象 | 会自然产生的行为 |
|---|---|---|
| 契约婚姻 | 合同、住所、继承条件 | 谈判、演戏、维护、解除 |
| 上司下属 | 项目、绩效、推荐 | 指派、偏袒、拒绝、离职 |
| 宿敌 | 排名、名额、导师认可 | 挑战、拆台、救场、承认 |
| 共犯 | 证据、赃物、逃亡路线 | 分工、掩护、要挟、顶罪 |
| 救命债 | 承诺、治疗资源、保护资格 | 偿还、服从、免债、返回 |
| 临时家庭 | 住所、饭桌、监护权 | 收留、分工、争吵、留下 |
| 政治联姻 | 领地、军权、婚约 | 抗拒、改约、结盟、共治 |
| 机构与能力者 | 执照、药物、任务档案 | 登记、监控、逃亡、揭露 |

# 五、行为配置规则

一条主线至少选择四种行为功能，而不是四个动作姿势：

```text
接近行为 × 1
试探或控制行为 × 1
反抗或揭露行为 × 1
修复或重新选择行为 × 1
```

标准关系推进：

```text
建立许可 → 使用许可 → 越界 → 对方反制 → 支付代价 → 重新申请许可
```

标准权力推进：

```text
强者配置资源 → 弱者发现规则漏洞 → 强者加码惩罚 → 弱者获得公开权
→ 群体重新评价 → 双方重订规则
```

标准悬疑推进：

```text
异常对象 → 初始解释 → 证据支持 → 证据来源异常 → 新嫌疑主体
→ 利益对象显形 → 真正因果链公开
```

# 六、单季结构生成器（24—40话）

| 阶段 | 话数参考 | 任务 | 必须改变的对象 |
|---|---:|---|---|
| 入口 | 1—3 | 建立缺口、绑定与首个钩子 | 关系许可/任务对象 |
| 试运行 | 4—8 | 展示题材日常发动机 | 小资源、初步信任 |
| 第一次越界 | 9—12 | 优势方滥用权力 | 边界、名誉、自由 |
| 中段反转 | 13—18 | 弱势方获得反制对象 | 证据、选择权、能力 |
| 外部升级 | 19—25 | 场域规则公开惩罚 | 职位、身份、组织关系 |
| 代价兑现 | 26—32 | 旧谎言/旧行为反噬 | 信任、盟友、资源 |
| 季终选择 | 33—40 | 去掉旧绑定后重新选择 | 身份、关系或世界规则永久改变 |

# 七、12个组合示例

## G01｜契约婚姻 × 财阀继承 × 职场设计

```yaml
主题材: 契约婚姻
驱动题材: 财阀继承
调味题材: 艺术设计
主角: 被剽窃署名的负债设计师
对手: 必须结婚才能继承公司的继承人
关系对象: 一年期假婚
资源对象: 品牌旧档案、股份、署名证据
秘密对象: 主角才是集团经典图案的原作者
场域规则: 董事会只承认婚姻稳定的继承人
行为链: 假关系变真关系 + 被逐者夺回资格
季终回报: 女主夺回署名，男主在失去继承优势后仍选择公开婚姻
```

## G02｜回归 × 猎人 × 公会职场

```yaml
主角: 上一世被队友弃援的低级治疗者
目标: 让原队伍成员活过大型裂隙
信息优势: 知道关键副本机制
限制: 每次改变未来都会丢失一段记忆
行为核心: 抢先、组队、隐瞒、交出指挥权
季终回报: 不依赖未来记忆也能由新队伍完成攻略
```

## G03｜恶役千金 × 领地经营 × 临时家庭

```yaml
主角: 知道自己会因虐待继子被处刑的恶役公爵夫人
目标: 退出宫廷争夺并修复荒废领地
关系对象: 对她极度戒备的继子与管家
资源对象: 土地、税收、旧账本
行为核心: 放权、公开账目、收留、拒绝原婚约
季终回报: 她不再需要“善良女主”认证，也被领民主动承认为管理者
```

## G04｜校园暴力复仇 × 心理追踪 × 匿名创作者

主角用匿名漫画记录校园暴力，作品爆红后，加害者开始追查作者；主角必须在继续取证和保护现实身份之间选择。季终不是打一顿，而是让校方、家长与平台共同保护加害者的结构曝光。

## G05｜保镖 × 敌对阵营 × 政治阴谋

被雇来保护候选人的保镖其实属于对立阵营；保护任务逐渐证明自己阵营的刺杀理由是伪造的。核心行为链为“利用目标产生感情”与“机构工具反叛”。

## G06｜顶流 × 身份交换 × 职场群像

过劳顶流与默默无名的替身演员交换身份。两人替对方处理工作后，发现一个被人格商品化，一个被彻底隐形。最终回报是双方分别夺回停工权与署名权。

## G07｜怪谈 × 合租屋 × 旧爱重逢

分手情侣因低价房被迫合租，规则要求“夜里听见对方叫名字时绝不能回应”。两人的旧误会与怪谈记忆互相覆盖，真相是房子复制了历任住客未完成的告别。

## G08｜美食店 × 家族秘密 × 真假继承人

两名被迫竞争遗产的姐妹必须共同经营祖母的小店一年。菜谱中的修改痕迹逐步证明，两人都不是“唯一正统”，祖母真正留下的是共同经营权。

## G09｜电竞 × 天才失能 × 宿敌

曾经的天才选手手伤后改做分析师，必须指导自己的宿敌战队。成长回报不是手伤奇迹恢复，而是他创造新战术并主动交出赛场中心位置。

## G10｜异能机构 × 囚禁逃生 × 共犯

能够删除记忆的女主被机构关押，负责看守她的人其实是被删掉过身份的前搭档。两人必须决定恢复全部记忆是否比现在的自我更重要。

## G11｜乡村疗愈 × 创作者 × 重逢

创作崩溃的漫画家回乡暂住，发现旧友正在把村落故事做成商业旅游项目。冲突不是城市坏、乡村好，而是谁有权使用共同记忆创作。

## G12｜法律 × 豪门复仇 × 禁忌关系

律师接下针对财阀的旧案，却发现关键证人是自己的秘密恋人。公开证词能赢案件，也会摧毁对方现有身份。最终选择必须同时回应正义与主体权。

# 八、生成结果审计

```text
[ ] 主角有可执行的动词，而不是只有悲惨背景
[ ] 对手对同一对象拥有更强或更合法的资格
[ ] 关系对象解释了双方为何持续相遇
[ ] 至少一个资源能发生转移
[ ] 至少一个秘密拥有明确公开权
[ ] 场域规则能实施具体惩罚
[ ] 中段发生过一次权力位置反转
[ ] 季终回报永久改变某个对象状态
[ ] 调味题材没有抢走主题材的结局
```
