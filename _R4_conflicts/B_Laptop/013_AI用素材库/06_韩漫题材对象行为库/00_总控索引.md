# 韩漫题材对象行为库｜总控索引

> 目标：把韩漫题材从模糊标签拆成可调用、可组合、可采矿、可验证的生产系统。

## 一、当前定位

本库是**常见商业韩漫生产结构基线**，可以用于生成故事、分析作品与建立采矿卡；它尚未通过足量作品样本证明自己已经穷尽全部韩漫。

```yaml
library_version: 1.1
structural_status: 可使用
empirical_status: 待120部作品验证
claim_allowed: 常见商业韩漫生产结构基线
claim_not_allowed: 已覆盖全部韩漫题材与行为
```

## 二、核心公式

```text
题材 = 欲望场域 + 主体身份 + 目标对象 + 阻碍对象 + 高频行为 + 情绪回报

剧情单元 = 主体 → 对对象采取行为 → 对象反制 → 对象状态改变 → 权力/关系改变 → 回报或新钩子

单话闭环 = 承接钩子 → 目标显形 → 行动升级 → 局部结果 → 更大钩子
```

题材库回答“故事在哪一种欲望里发生”；对象库回答“谁和什么值得争夺”；行为库回答“角色怎样作用于对象”；状态机回答“对象究竟改变了什么”；回报库回答“读者为什么继续翻下一话”。

## 四、对象五层模型

| 层级 | 定义 | 示例 |
|---|---|---|
| 主体对象 | 能主动行动、回应、拒绝并承担后果的角色 | 财阀继承人、回归猎人、恶役千金 |
| 关系对象 | 把多个主体持续绑定的结构 | 契约婚姻、师徒、债务、共犯 |
| 资源对象 | 能交换、分配、消耗或改变权力的东西 | 遗产、证据、技能、名额、药物 |
| 秘密对象 | 由知情差、证据化和公开权产生力量的信息 | 血统、真实任务、旧案真凶 |
| 场域/规则对象 | 决定准入、许可、惩罚和退出代价的环境 | 皇宫、公司、公会、平台算法 |

“阻碍对象”不是独立对象类型，而是任一对象在当前目标中的功能角色。

## 五、规范ID

跨文件引用必须使用命名空间，短码只用于所属文件内部显示：

```text
T- 题材
S- 主体
R- 关系
O- 资源
M- 秘密
F- 场域
B- 行为
C- 行为链
P- 回报
H- 钩子
VB-S 言语行为
VB-M 微动作

```

例如：题材`A01`写作`T-A01`；行为`A01`写作`B-A01`。

## 六、条目最小标准

### 题材条目

- 欲望核心与主体缺口
- 主目标对象与阻碍对象
- 关系、资源、秘密、场域对象
- 高频行为与典型反制
- 对象状态变化
- 中段权力反转
- 核心回报与篇幅模型
- 平台标签、关系取向与内容分级
- 失效风险与真实作品证据

### 行为条目

- 行动者与承受者
- 直接对象
- 显性目标与隐藏目标
- 触发条件与动作形式
- 许可、知情、资源或评价变化
- 对象状态前后
- 代价与不可撤回后果
- 对方接受、拒绝、误读或反制
- 风险标记与后续钩子

## 七、组合约束

1. 不把动作姿势当行为。接吻、拥抱、壁咚必须注明其功能与同意状态。
2. 不把身份名词或平台标签当生产题材。财阀、奇幻、BL都不能单独回答剧情怎样运行。
3. 不只写主角想要什么，还要写谁有资格拒绝他。
4. 每个强行为必须留下代价，否则只剩无重量爽点。
5. 每条链至少产生一次对象反制和三次对象状态变化。
6. 题材混合采用“1个主题材 + 1个驱动题材 + 1个调味题材”。
7. 危险行为可以成为冲突，但不能不经审计直接作为浪漫回报。
8. 未经真实作品验证的条目标记为`draft`，不进入默认生成池。

## 八、推荐使用流程

```text
选择主题材
→ 配置平台标签、关系取向、世界外壳与分级
→ 抽取主体与关系对象
→ 配置资源、秘密与场域
→ 设定对象初始状态和目标状态
→ 选择高频行为、言语行为与微动作
→ 选择行为链与篇幅模型
→ 配置每3—5话中回报和季终大回报
→ 运行伦理风险审计
→ 用十元接口检查感觉走向
→ 记录作品与场景证据
```
