# 0｜用途

本文件只做一件事：

> 把《黎黎隆》总览里已经存在的视觉母方向、P00 五色、角色硬门，翻译成**头像尺度可判定**的规则。

不得另起一套审美标准；不得把“漂亮”“有感觉”当判定词。

评分统一为 0 / 1 / 2：

- **0 = FAIL**：目标特征基本不存在，或被相反特征主导
- **1 = PARTIAL**：能看见，但不稳定 / 不足以承担识别
- **2 = PASS-CANDIDATE**：特征稳定、可观察、可被他人复核

> 注意：2 分不是最终审美 PASS。最终“还是不是原来那套画风”仍由 674 拍板。

# 1｜八维评分表

## D1｜line_block_language｜线面语言

**来源原文：**
- “线面：墨线、炭笔、干刷、薄水粉、可见草稿线。”
- “目标不是精致商业立绘。”

**头像尺度看什么：**
- 轮廓线不是统一机械描边；
- 线有轻重、断续、回笔、干刷或手工摩擦感；
- 局部能看到草稿/修正痕迹，而不是所有边缘都被清理成矢量线；
- 色块与线不是完全贴死，允许手绘偏差。

**0：** 干净矢量 / 统一描边 / 商业精修感主导。  
**1：** 有松动线，但大部分仍是标准完成线稿。  
**2：** 墨线/炭笔/干刷/草稿痕迹在缩小后仍可稳定辨认。

---

## D2｜face_language｜脸部形体语言

**来源原文：**
- “形体：大块面、清晰剪影、局部不对称。”
- 角色层“身份锚：脸、姿态、身高比例、一个重复动作。”

**头像尺度看什么：**
- 脸型先于小五官成立；
- 额头 / 颧 / 下颌 / 鼻口区域以大块关系组织；
- 不依靠睫毛、饰品、发色才区分人物；
- 局部不对称能服务识别，而不是随机歪斜。

**0：** 同一基础脸模板换眼睛/头发。  
**1：** 脸型有差，但主要识别仍靠发型/配饰。  
**2：** 去掉发型与配饰后，脸部大形仍有明显角色差异。

---

## D3｜edge_handling｜边缘处理

**来源原文：**
- “可见草稿线。”
- “旧纸、修补、磨损。”
- “轻量、可维护。”

**头像尺度看什么：**
- 轮廓边缘是否有手绘开合；
- 发梢、衣领、机械边缘是否存在少量未完全闭合 / 叠线 / 破边；
- 破边不能发展成满屏噪点。

**0：** 所有边缘都像钢笔矢量；或相反，被颗粒/飞溅淹没。  
**1：** 只有少数局部松动。  
**2：** 主轮廓清楚，同时在次级边缘保留稳定手绘痕迹。

---

## D4｜head_silhouette_diversity｜头部主剪影差异

**来源原文：**
- “角色群应共享世界材料，但不共享轮廓和器官逻辑。”
- “形体：大块面、清晰剪影。”

**头像尺度看什么：**
只看外轮廓，不看颜色，不把耳环、项链、细流苏当主剪影差异。

有效差异包括：
- 头骨宽窄 / 长短；
- 兜帽 / 宽帽 / 面罩形成的大形；
- 机械头整体体块；
- 真正改变外轮廓的角、耳、羽冠、器官；
- 年龄造成的头脸体块变化。

**0：** 主要是同头型换配饰。  
**1：** 有少数强差异，其余仍同族化。  
**2：** 一组角色在纯黑剪影下仍能明显分组。

---

## D5｜structural_diversity｜结构 / 器官逻辑差异

**来源原文：**
- “角色、道具、场景都要从身体问题和实际用途长出来。”
- “先写真实问题 → 再写动作因果 → 再画身体 → 最后补服装和装饰。”
- “角色群应共享世界材料，但不共享轮廓和器官逻辑。”

**头像尺度适配：**
头像不要求展示全身机制，但**可见头颈结构必须至少有一个可解释用途**。

可接受：
- 感知器 / 接口 / 呼吸 / 保护 / 通讯 / 维护 / 负重连接；
- 生体结构改变视野、听觉、呼吸或佩戴关系；
- 机械头、面罩、器官接口能说明“为什么必须长这样”。

不接受：
- 只为了差异加角；
- 随机尖耳；
- 枝杈、羽毛、蘑菇只作装饰；
- “怪物感”本身充当理由。

**0：** 大多数异质结构无法回答用途。  
**1：** 一部分结构有用途，一部分仍是造型装饰。  
**2：** 主要异质结构均能关联身体问题 / 职业 / 世界机制。

---

## D6｜information_density｜信息密度

**来源原文：**
- “质感：旧纸、修补、磨损、半透明膜、陶瓷和软体组织。”
- “目标不是精致商业立绘，是可画、可拍、可维护。”

**头像尺度看什么：**
不是“细节越多越好”，而是主次是否稳定。

机器指标可记录：
- edge_density；
- whitespace_ratio；
- 局部高频纹理占比。

人工解释：
- 主脸部不能被纹理吃掉；
- 信息集中在结构节点，而非平均铺满；
- 修补/磨损要依附结构，不是粒子滤镜。

**0：** 过空导致无信息，或过密导致脏 / 粒子化。  
**1：** 主次基本成立，但质感信息偶尔漂移。  
**2：** 大形清晰，细节集中于少数结构节点，缩略仍可读。

---

## D7｜palette_behavior｜P00 五色行为

**来源原文：**
- 深墨青 #142A34
- 灰紫 #855D8F
- 暗红 #913840
- 青绿 #69D4CE
- 淡青灰 #CDE7E6
- 禁止黄、橙、土黄、草绿、纯蓝、粉色、肤色等第六独立色相。

**头像尺度看什么：**
- 不要求五色全上；
- 看主导关系与分布，不只看“有没有这些颜色”；
- 颜色必须参与结构：轮廓 / 生物重音 / 危险焦点 / 技术接口 / 留白。

机器记录：
- 五色近邻像素占比；
- 禁色占比；
- 主导色；
- 高饱和异常色比例。

**0：** 独立禁色主导，或完全读不出 P00。  
**1：** 大体落在 P00，但分布或近似色漂移明显。  
**2：** 去掉文字后仍明显是 P00 体系，且无独立禁色主导。

---

## D8｜template_collapse｜模板塌缩

**来源：**
- 674-149 负样本：长脸 / 半垂眼 / 三分之二视角 / 黑白长发 / 围巾垂饰 / 长耳反复复用。
- 总览：“角色群共享世界材料，但不共享轮廓和器官逻辑。”

**必须分开检查：**
1. face_shape_repeat_rate
2. eye_type_repeat_rate
3. view_angle_diversity
4. silhouette_variance
5. accessory_overlap

**关键原则：**
- 颜色差异不算结构差异；
- 配饰差异不算脸型差异；
- 同一世界共享材料是允许的，但不能共享同一头骨 + 同一眼型 + 同一姿态模板。

**0：** 明显“同脸换饰品”；结构差异主要来自颜色和配件。  
**1：** 已有结构差异，但某一脸型 / 眼型 / 视角仍占多数。  
**2：** 多个维度共同维持差异，不存在单模板主导整板。

# 2｜五问在头像阶段的正确解释

总览五问保持不变，但头像不能机械套全身标准。

## Q1｜去掉文字仍能认出 P00 五色吗？
直接执行，不改。

## Q2｜有没有明确身体 / 功能问题？
头像版解释为：

> **头颈可见范围内，是否存在一个由身体、职业或世界机制产生的可观察问题 / 约束？**

不能要求头像必须解释全身。

## Q3｜生体结构是否有用途？
头像版解释为：

> **所有被当成“核心识别”的角、耳、面罩、机械头、器官、接口，能否说明用途？**

普通发型不需要硬编功能；只有被当作世界异质结构的部分需要。

## Q4｜是否保留手绘、轻量、怪奇感？
直接执行，不改。

## Q5｜换成普通中世纪人类后还能完全成立吗？
头像版解释为：

> 若去掉所有世界专属结构后，这个头像仍没有任何身份 / 机制损失，则世界特征不足。

不是要求每一个 NPC 都必须长成怪物，而是整批不能只靠“中世纪人 + 奇幻耳朵”。

# 3｜评分与硬门关系

五问是硬门，8 维是诊断。

**禁止用总分覆盖硬门。**

流程：

```
五问
  ├─ 任一关键硬门明确 FAIL
  │      ↓
  │   不进入最终 PASS
  │
  └─ 五问通过 / 可解释
         ↓
       8维记录
         ↓
     定位漂移变量
```

# 4｜template_collapse 阈值修正

674-149 现有 0.5 阈值可作为**报警线**，不应单指标直接判死。

建议正式判塌缩满足以下任一条件：

### HARD-COLLAPSE
- `face_shape_repeat_rate >= 0.5` **且** `eye_type_repeat_rate >= 0.5`
- 或 `silhouette_variance` 低 **且** `view_angle_diversity <= 2`

### SOFT-COLLAPSE
- 只有 accessory_overlap >= 0.4
- 或只有单一脸型超过 0.5

SOFT-COLLAPSE 只触发人工复核，不自动 FAIL。

原因：单个世界族群允许共享眼型、围巾或材料；真正的“模板塌缩”应当是**多个结构变量一起收缩**。
