# Codex 跑图总说明 v2.0

> **给 Codex 的一句话命令**：
> 读取本文件 + `黎黎隆项目/00_总览/00_扩展接口_全项目.md` + `黎黎隆项目/00_总览/P00_项目统一色卡_v1.0.md`，按 §3 缺图清单顺序执行；参考图从 §2 索引取；产出按 §5 入库；每图过 §4 验收；写执行报告。

## 1｜硬约束（继承 v1.3，全程有效）

1. **P00 五色锁优先**：参考图原色不继承，只借构图/质感/结构。五色 = `#142A34` 墨青 / `#855D8F` 灰紫 / `#913840` 暗红 / `#69D4CE` 青绿 / `#CDE7E6` 淡青灰
2. **暗红不铺满**（仅状态样本）、青绿=接口灯光、灰紫=活体膜、淡青灰=雾与留白
3. **验收五问**：换普通中世纪人画面仍成立 = 失败重跑
4. 禁止打开 Pinterest / Behance 等登录页；搜图只用 Openverse + Wikimedia（API 走代理 `http://127.0.0.1:7890`）
5. 找不到合格图记 `NO_MATCH`，不得伪造完成
6. 单 GPU 串行，禁止并发跑图任务

## 2｜参考图库用法（42 张 / 9 类）

**库位置**：`黎黎隆项目/04_场景/04_视觉参考/外部参考_用户收集/`
**索引**：同目录 `00_外部参考索引.md`——每图有「内容 + 适用场景」字段

**Codex 选图流程**：
1. 接到任务（如「跑白骨营地」）→ grep 索引的 `适用场景` 字段
2. 命中图片 → 按 `路径` 取文件 → 作为**构图/质感参考**喂给出图流程（img2img 低权重 / or prompt 描述其结构）
3. 参考图只借三样：**结构、比例、材质**；颜色一律换算成 P00 五色
4. 类目速查：01 巨构骨骼（骨骼空港/白骨营地）｜02 接口街景（维护街/市井/识别站）｜03 垂直聚落（城内带/城外聚落）｜04 港口水道（自由锚港）｜05 人物尺度（角色×场景融合）｜06 菌林活膜（R6 粉色生态带）｜07 黑金工业（R3 黑金海域）｜08 巨物迁徙（R4 天上巨鲸）｜09 异种村落（异种村庄）

## 4｜验收（每张图必过，报告登记）

1. 五色合成：画面所有色可溯源到 P00 母色（吸色检查）
2. 验收五问通过
3. 暗红面积不铺满；灰紫只出现在活体/膜结构
4. 尺度锚：人物在巨构中保持极小（对照参考图比例）
5. 主观审：用户过目，不满意即停（用户保留终审权）

## 5｜产出入库（按扩展接口铁规则）

1. 图 → `04_场景/01_五色视觉系统/` 对应子夹（**正本**，不放图包）
2. 更新 `00_图包索引.md`（如需外发再拷图包）
3. **在 `场景总Canvas.canvas` / `角色总Canvas.canvas` 对应区加节点**（不新建 canvas）
4. 划掉 §3 清单对应行，写执行报告 `04_场景/04_视觉参考/跑图执行报告_<日期>.md`

## 6｜跑图命令模板（给 Codex 的三种起手式）

- **按缺图跑**：`读取 Codex跑图总说明_v2.0.md，执行 SC-01，参考图按 §2 取，产出按 §5 入库`
- **按参考跑**：`用 外部参考_用户收集/01_巨构骨骼/ 的图做构图参考，按 P00 五色锁出「骨骼空港·内部通道」概念图`
- **批量清缺**：`读取缺图清单 §3，从 P0 开始逐个执行，每完成 3 张停下来等我验收`
