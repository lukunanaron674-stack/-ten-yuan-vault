# 3｜子问题因果（谁必须先成立）

```
SUB-01-01 最小视觉语法
   │
   └─► SUB-01-02 必要 vs 偶然
          │
          └─► SUB-01-03 固定输入模板
                 │
                 ├─► SUB-01-04 跨聊天框 ─┐
                 ├─► SUB-01-05 跨轮次  ─┼─► SUB-01-07 漂移检测
                 └─► SUB-01-06 跨角色  ─┘        │
                                                  └─► SUB-01-08 冻结基准集
                                                         │
                                                         └─► SUB-01-09 同画风审核器
```

**因果说明（不是依赖偶然性）**

- 01→02：不确定成功必需的维度，就无法判定某个输入是必要还是蹭上的
- 02→03：不知道哪些输入必要，模板就是凭手感拼的，不可复现
- 03→{04,05,06}：三个「跨」维各自独立，但都必须在同一份冻结模板下进行才有可比性
- {04,05,06}→07：没有多组样本数据，就没有漂移可言，更谈不上检测
- 07→08：不知道什么算漂移，就不知道基准集该排除什么
- 08→09：审核器需要基准集做 ground truth，否则又退回「主观好不好看」
