# 黎黎隆｜项目视觉与世界统一规则 v1.0

> 本规则属于《黎黎隆》项目 00 级总控。角色、道具、场景、参考吸收图和动画画面候选都必须回到这里验收。

## 一、风格核心不是单一画法

《黎黎隆》不要求角色和场景使用完全相同的笔触，也不把“高细节概念背景”强行改成角色原稿的画法。项目的统一性来自三件事共同成立：

1. **角色语言**：保留手绘原稿的线条、夸张比例、简化色块、局部不对称和异质感；不得被生图模型同化为普通精致幻想角色。
2. **场景语言**：保留氛围概念背景的空间纵深、可拍路径、材质层次和环境功能；场景必须能脱离主角独立成立。
3. **世界桥接**：角色与场景共享同一套色卡、光线逻辑、材质关系、空间尺度和可观察的功能动作。

因此，目标是：

> **氛围概念背景 + 手绘异质角色 + 统一的生体机械世界规则。**

## 二、P00 五色是项目风格核心

正式色卡入口：[[P00_项目统一色卡_v1.0]]。本节保留快速查看版，生产和新建素材以正式色卡为准。

P00 五色不是装饰色，也不是角色标签；它是全项目的统一视觉母色。画法可以变，颜色集合不能变。

| 色名 | 色值 | 主要用途 |
| --- | --- | --- |
| 深墨青 / 近黑 | `#142A34` | 轮廓、结构、暗部、维护件 |
| 灰紫 | `#855D8F` | 奇异感、生体结构、局部重音、活体膜 |
| 暗红 | `#913840` | 危险、生命、警示、视觉焦点；不得无理由铺满墙面 |
| 青绿 / 青蓝绿 | `#69D4CE` | 技术、能量、接口、灯光、交互反应 |
| 淡青灰 | `#CDE7E6` | 大面积亮部、雾感、留白、钙化结构 |

允许同色变亮、变暗、透明叠加、五色混合和纸白留白；一张图不要求五色全部出现，但不得引入第六种独立主色相统治画面。

颜色可以在视觉脚本层面提示或编码十元关系倾向，但不能把单一颜色当作十元关系本体。十元判断仍必须由形体、空间、受力、动作、事件和后果共同支持；具体具象映像见 [[P00_项目统一色卡_v1.0]]。

## 三、角色进入场景的统一规则

- 角色身份优先于场景风格；不得为了“融入”而抹掉原稿的脸型、比例、帽子、器官和线条特征。
- 场景优先作为背景底图生成；角色优先作为独立的手绘层进入场景。
- 只给角色补环境光、接触阴影、遮挡、水面反光和局部色彩反射，不把角色重绘成场景 CG 材质。
- 角色与场景必须共享至少一项可观察的世界机制：接口反应、维护动作、身体尺度、受力路径、通行规则或生体结构用途。
- 角色不是贴纸：必须有脚下受力、遮挡关系、光照方向、空间比例和对环境的动作反馈。
- 场景不是角色插画背景：环境必须有独立用途、结构状态和可拍的运动路径。

## 四、场景生产验收门

每张角色—场景融合候选至少检查：

1. 去掉角色后，场景是否仍然是一个可使用的空间？
2. 去掉场景后，角色是否仍保留原稿身份锚？
3. 两者是否共享 P00 色卡，而不是只靠整体滤镜统一？
4. 是否有真实的接触、遮挡、受力和光线关系？
5. 是否出现模型擅自补全的服装、身体、道具或身份设定？

如果前两项成立但后三项不成立，标记为“场景成立 / 角色成立 / 世界融合未通过”，不得冻结。

## 五、当前制作边界

- 候选图、失败图、需复核图、人工确认图和正式冻结图必须分开记录。
- 不用新生成图反向替代角色原稿，不把场景候选写入角色正式卡。
- 角色原稿缺失时，只能做文字约束候选，不能声称完成身份校准。
- 不启动 H3，不覆盖原始素材，不自动替换正式 Canvas。
