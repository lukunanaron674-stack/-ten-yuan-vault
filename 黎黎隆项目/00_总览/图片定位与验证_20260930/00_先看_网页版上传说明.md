# 黎黎隆图片定位与验证包

用途：把图片交给网页版查看时，同时用索引定位回本地资料库/仓库中的原文件、文字笔记和 Canvas 节点。

## 内容

- 角色库：235 张图片
- 场景库：279 张图片（其中用户收集的外部参考 42 张，已在索引单独标注）
- 总计：514 张，源文件合计约 749.3 MiB
- 图片分成三个 ZIP 卷；上传时请同时附上图片定位与验证总索引.csv。

## 用索引定位

- GitHub仓库相对路径：从黎黎隆项目根目录开始的路径，仅用于文字定位；不代表 GitHub 上存在对应图片文件。
- 直接引用文字文件：当前 Markdown 中直接嵌入/链接这张图的文件。
- 文字定位入口：没有直接引用时，给出最近的目录索引/说明文件，只用于导航，不代表文件正文逐张解释了图片。
- 主Canvas直接节点 / 其他Canvas直接节点：Canvas 文件相对路径加节点 ID；括号中的邻近文字是 Canvas 布局附近标签，供定位参考。
- Canvas定位状态：区分主 Canvas 有直链、只有其他 Canvas 有直链、或当前未找到图片节点；Canvas总览入口给出应检查的主图。
- SHA256、字节数、宽高和解码状态用于确认具体图片文件；相同 SHA 表示内容完全相同。

## 描述和状态边界

简短描述由文件名和目录层级整理，目的是辨认/定位；不是对每张图逐张人工视觉解读。ZIP 包含原始图片，网页版可以直接看图复核。打包过程不改变角色或场景的候选、STAGING、锁定状态；以原资料中的索引和卡片为准。

场景中的用户收集参考图被作为独立来源类别标注；其来源或授权状态没有在本次重新核实。

## 校验

打包时逐张计算 SHA-256；栅格图片做解码校验，SVG 做 XML 解析；生成后再检查 ZIP CRC，并将压缩包内每张图片的 SHA-256 与索引比较。请勿用 ZIP 内文件覆盖原库；需要回写时按仓库相对路径逐项定位。

本说明最初描述本地交接包，其中的图片 ZIP 留在本地。本次 GitHub 同步只包含本说明、定位索引、SHA-256 清单和校验报告等文字文件；不上传 ZIP 或任何图片，也不修改源图片或 Canvas。
