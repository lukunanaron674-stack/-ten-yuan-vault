## 3. 数据类型

- **RULE**：冻结规则 / XN / Canon / 生产约束。
- **STATE**：当前唯一有效状态包。
- **TASK**：Linear 执行任务与依赖。
- **EVIDENCE**：来源、实验、审核、失败族、receipt。
- **ASSET_REF**：asset_id / path / SHA256 / version / locator。
- **DECISION**：用户确认、PASS/FAIL、冻结与否。
- **HUMAN_SNAPSHOT**：只给 674 的压缩结果。

## 4. 冲突优先级

```text
用户最新明确决定
> 已冻结 Canon / VERIFIED_XN
> 当前 canonical Markdown / Canvas
> Linear 当前状态 + receipt
> 历史聊天 / 旧候选
```

任何冲突必须登记，不允许静默覆盖。
