## 5｜674-173：USER AUTHORITY GATE

唯一 USER 角色审核入口。

需要 USER 的情况：
- 新身份是否是这个角色；
- 主参考变更；
- 红心/核心角色选择；
- Canon / 作者意图；

允许继承旧 PASS：
exact asset_id + SHA 未变，主参考未变，审核语义没有被新规则/Canon改变，且 293 能找到原 review receipt。
此时记录 INHERITED_PASS，不重复找 USER 审同一字节资产。

## 10｜STALE / 失效

任一变化会让旧 Ready Packet 自动 STALE，286 禁止继续使用：
- main_reference 改变；
- 绑定资产 SHA/version 改变；
- 282 semantic_version / identity_core / frozen anchors 改变；
- 173 对相关资产做出新的 FAIL/RERUN/主参考变更；
- 与本镜相关的角色 Canon 改变；
- 当前镜头需求超出原 h3_scale_coverage。

STALE 后由 293 重新机械编译；不自动重新问 USER。仅当旧 receipt 不再适用且 user_gate.required=true 才进 173。

## 11｜失败分流

- 缺 path/SHA/version/资产找不到 → 293
- 缺所需景别但角色规则已锁 → 124 补图 → 293
- 身份/Canon/冻结项冲突 → 282
- 必须作者裁决 → 173
- AG-06 静态失败 → 124 定向返工；重复稳定失败证据 → 282
- USER FAIL/RERUN → 124；USER_NX → 282；资产状态 → 293
- H3 镜头需求超资产覆盖 → 286 → WAIT_ASSET → 293/124
- H3 动作/镜头/连续性失败 → 286，不回写成 282 静态规则
