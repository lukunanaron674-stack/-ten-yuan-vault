# 三层架构与同步协议 v1.0

更新时间：2026-10-07 20:54 +08:00

## A. 固定架构

```text
674
  ↓
Human View：674总览.canvas
  ↕  Human Snapshot Translator
AI Execution：问题Canvas + Linear
  ↕
AI Database：规则 / 状态 / 证据 / 资产引用 / 索引
```

### Human View
- 默认入口。
- 不承载完整问题树。
- 不显示内部 prompt、agent 字段、失败日志、SHA 列表。
- 一屏优先；最多 2 个 active tasks。

### AI Execution
- 负责 Z → XN → PATH → 执行 → 反馈。
- Linear = 调度与 receipt；Canvas = 关系与导航。
- 任何 DONE 必须能追到 evidence / changed_files / commit 或真实结果。

### AI Database
- 不复制第二套事实。
- 只索引 canonical source，并保存机器需要的 schema / map / lookup。
- 同一事实只有一个 authority；其它地方只引用。

## B. 同步方向

### AI → 674
状态变化后：
1. 对账 canonical source；
2. 识别对用户真正有意义的变化；
3. 生成 Human Snapshot；
4. patch `674总览.canvas`；
5. 只有 `needs_user=true` 才打断用户。

### 674 → AI
用户一句话 / 点选 / PASS/FAIL：
1. 记录原始决定；
2. 编译成结构化 Decision；
3. 写回对应 Q / Linear /资产审核；
4. 触发下一执行步；
5. 不要求用户自己维护后台。

## C. 每小时闭环

```text
→ Human Snapshot → 674总览.canvas
```
