更新时间：2026-10-07 21:12 +08:00


## 第一层
总控看全局；三个分控各看一屏。

分控允许字段：
- goal
- subgoals
- volume_1_10
- feasibility_1_10
- progress
- next
- needs_user
- nx_top1

分控禁止字段：
- XN全集
- NX列表
- PATH细节
- SHA / seed / prompt全文
- 执行日志
- 完整 evidence

## 第二层
所有机器细节都在后台；不再新建 AI 工作 Canvas。

## 同步
后台执行完成或状态变化
→ 选择当前 top-1 NX
→ 更新对应分控
→ 总控只汇总三个分控
→ needs_user=false 则人在环外继续

## 用户输入
用户在总控/分控作出决定
→ 编译成后台 Decision
→ 写回 Markdown / Linear / Review
→ 继续执行
