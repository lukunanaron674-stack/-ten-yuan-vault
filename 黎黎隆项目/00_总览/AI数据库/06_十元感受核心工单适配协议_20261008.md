## 5｜674-105：感受关系 / 动态时间曲线

105 负责：

### G3｜生克补感受关系
研究一种感受如何：
- 增强另一感受
- 压制另一感受
- 补足/完成另一感受

关系记录必须保持：
source / target / operation / condition / changed_variable / strength / result / residue / next_affordance / evidence status。

禁止：
- 五轴相反 = 自动生克补
- 旧对象关系直接搬成感受铁律

### G4｜动态链
动态链 = 人的感受结构随时间变化的可观察曲线。

最小结构：
stage / feeling_profile / relation_event / changed_variable / before / after / residue / next_affordance。

Micro / Meso / Macro 均可，但必须保留时间顺序。

旧“克→生→再克→补”等链型可以继续作为高价值候选/节奏模板；是否稳定产生目标审美感受，由 106 的实验与 HUMAN GATE 提供证据。

## 8｜HUMAN GATE

任何声称“人产生了某种感受”的正式证据，最终必须来自真实人的反馈。

AI允许：
- 预注册预测
- 编码自由描述
- 聚类
- 比较感受谱
- 生成候选
- 计算误差

AI不得：
- 用自己的自评分冒充人的体验
- 生成图后自己判“成功制造目标感受”并直接升级 E5
