## 证据案例 A｜CH-004 青色路域勘察员

证据源：`黎黎隆项目/03_角色/角色库/角色卡/CH-004_青色路域勘察员.md`。

1. **世界机制承担**：角色职业直接存在于青色文明的“X并Z异常关系 → Z机能化 → 路域维护”机制中。删除青色路域机制后，她的职业、能力与事件入口会同时失去成立条件。
2. **世界问题承担**：她专门处理“系统参数正常，但对象之间真实关系已经改变”的失配。
3. **机制→能力**：长耳用于感知微振动、回声、节律与关系漂移；能力来源与职业问题同源。
4. **机制→事件**：官方路域显示正常 → 她发现征兆不对 → 要求改道/进入未登记路径。
5. **避免说明书**：承担者必须拥有一个由世界机制制造的“必须做决定的现场”。

## 证据案例 B｜CH-003 逃票魔法学徒

证据源：`黎黎隆项目/03_角色/角色库/角色卡/CH-003_逃票魔法学徒.md`。

### 与 CH-004 不同的验证价值

CH-004 偏“异常处理职业”；CH-003 则把世界机制压进**生活成本、公共服务使用方式与个人寻找目标**，因此可用于验证“世界生活承担者”是否也能满足世界必要性，而不是只有专业职业才能成立。

1. **生活接口**：角色“没钱购买高价魔法服务”，因此研究城市魔法服务的未覆盖路径。这不是背景装饰，而是直接决定其日常移动/设施使用方式。
2. **机制依赖 A**：若删除“城市魔法服务 + 标准使用流程 + 收费门槛”，其“逃票/找漏洞”的当前行动方法就失去对象；角色仍可保留寻找老师的目标，但会失去当前世界特有的行动形态。
3. **问题依赖 B（局部）**：资源不足与标准服务门槛制造持续摩擦；系统升级、陌生设施、帽子的自主意志都能成为限制。失踪魔法塔是否属于同一世界问题链尚未定稿，因此不计为已验证强证据。
4. **事件依赖 C**：已选相遇方向是“不付钱进入收费魔法建筑/传送设施 → 黎黎隆跟随 → 两人从规则外路径进入异常区域”。世界规则直接改变事件路径。
5. **个人目标**：表层目标是使用城市设施并寻找遗失线索；深层目标是找回失踪老师、查明魔法塔消失原因。说明“世界承担”不必取代个人欲望，反而可以成为个人目标的阻力/路径。
6. **避免说明书**：观众不需要先听“本城魔法服务很贵”的解释；只要先看到角色因付不起费用而采用非标准路径，生活规则已经通过行为显影。

## 工作判据 v0.2｜世界必要性 + 生活承担修正

角色“必须存在于这个世界”继续采用 A/B/C 三项，但经过 CH-003 交叉验证后补一条“移植测试”：

- A｜**机制依赖**：职业/能力/工具/日常生存方式中至少一项只有在该世界机制下才成立。
- B｜**问题依赖**：角色反复处理的摩擦或冲突由该世界独有规则制造；不要求一定是宏大危机，价格、通行、服务、住房、资源等生活摩擦也可以。
- C｜**事件依赖**：角色能把世界规则转成可观察的选择、代价或行动差异。
- **通过门槛**：A/B/C 至少满足两项，且必须包含 A 或 B。
- **移植测试**：把角色原封不动搬到普通现代城市或另一个世界，如果只需改名词/皮肤就能继续同样行动，则世界必要性不足；如果必须重写其职业、日常生存方法、冲突来源或事件路径，说明依赖较强。

CH-003 说明 A 不应只写“职业/能力/工具”，还必须包含**日常生存方式**。这使判据能覆盖世界生活承担者，而不是天然偏向职业型 NPC。

## NEGATIVE / PSEUDO

- “给角色写一个世界观职业名”不等于角色必须存在于该世界。
- “角色能解释世界设定”不等于承担成立；若没有由机制产生的行动/冲突，只是说明书角色。
- 视觉上带有世界配色、机械件或装饰，不作为 MAIN-05 的文字结构证据。
- “生活承担”不等于必须是路人或纯日常 NPC；关键是世界规则是否改变其吃住行、消费、服务使用、工作或关系方式。
