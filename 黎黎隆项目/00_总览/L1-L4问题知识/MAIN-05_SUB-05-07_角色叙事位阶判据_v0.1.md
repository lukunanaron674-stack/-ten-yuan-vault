# MAIN-05 / SUB-05-07｜角色叙事位阶判据 v0.1

> 本文件是 MAIN-05 的证据附页，不创建新 Q，不建立平行问题树。状态仍由 `MAIN-05.md` 与唯一 canonical Canvas 导航。

## 本轮问题

如何区分“关键 NPC / 主要角色 / 功能角色”，避免只按戏份多少或视觉完成度判断？

## 已核 canonical 证据

### CASE A｜CH-001 澈

现有 Agent 压测把 `narrative_level` 判为 `KEY`：拥有独立世界接口与潜在主事件功能，但不是主角。角色卡同时表明，他拥有自主守护判断、城市系统冲突和可独立改变事件条件的能力。

**可观察变量：**
- 是否拥有独立于主角的目标/判断权：有。
- 是否能改变主事件条件，而非只提供一次工具：有。
- 是否承载独立世界接口：有。
- 是否必须是主角：否。

### CASE B｜CH-003 逃票魔法学徒

现有 Agent 压测把 `narrative_level` 判为 `RECURRING`：具备独立“失踪老师/魔法塔”线，可以反复进入主线，但当前证据不足以锁成全局 KEY。

**可观察变量：**
- 独立目标：有。
- 可重复进入事件：有。
- 是否已证明能改变全局主事件条件：未证明。
- 因此不能仅因有个人故事或多次登场就升级 KEY。

### CASE C｜CH-004 青色路域勘察员

角色卡明确为“A级关键 NPC / 世界探索型 NPC”；Agent 压测对应 `narrative_level=KEY`。其核心功能不是决定世界，而是“带人物穿过世界”，并通过路域判断改变人物进入世界的路径。

**可观察变量：**
- 世界接口强：有。
- 对主事件的作用：改变进入路径/信息条件。
- 角色身份仍可为 NPC；KEY 不等于主角。

## 判据 v0.1

叙事位阶不按“出场分钟数”单变量判断，先检查四个变量：

1. **Goal Autonomy｜目标自主度**：角色是否拥有不依附主角指令的持续目标/判断。
2. **Event Leverage｜事件杠杆**：角色的选择是否会改变主事件的条件、路径、资源、关系或结果，而非只完成一次局部功能。
3. **World Interface｜世界接口强度**：角色是否稳定承担一个主角无法等价替代的世界机制/生活/问题接口。
4. **Recurrence Necessity｜重复必要性**：再次登场是否来自未完成的目标/关系/世界职责，而不是“作者想让他再出现”。

### KEY｜关键 NPC / 关键角色

满足：`Event Leverage` 强，并且 `Goal Autonomy` 或 `World Interface` 至少一项强。是否是主角、是否战斗力高、视觉是否华丽均不构成必要条件。

### RECURRING｜反复角色

拥有独立目标或未完关系，因此存在重复进入主线的必要性；但尚未证明其选择能稳定改变全局主事件条件。CH-003 当前属于这一档。

### FUNCTIONAL｜功能角色

当前 canonical 样本中**尚未找到已明确标注 FUNCTIONAL 的真实角色案例**，因此只保留操作性假设，不宣称验证通过：若角色主要完成一次局部信息/服务/阻力/通行功能，移除后可由同类角色或机制低成本替代，且没有持续独立目标与事件杠杆，则倾向 FUNCTIONAL。

## 反例约束

- 出场多 ≠ KEY。
- 有个人背景 ≠ KEY。
- 世界观职业名很特殊 ≠ KEY。
- 视觉完成度高 ≠ KEY。
- 战斗力强 ≠ KEY。
- NPC 与 KEY 不冲突；“NPC”是角色位置描述，“KEY/RECURRING/FUNCTIONAL”是叙事杠杆层级。

## 本轮结论

`SUB-05-07` 从“只有 CH-004 单案例的 PARTIAL PASS”推进为：

**PARTIAL PASS / CRITERIA_v0.1 / FUNCTIONAL_SAMPLE_MISSING**

已有 CH-001、CH-003、CH-004 三例足以区分 `KEY ↔ RECURRING`，并证明“关键 NPC”不能等同“主角”；但 FUNCTIONAL 仍缺 canonical 正例，故本 SUB 不关闭。
