# Q-SCENE-001｜SC-001 森林背景批准来源是否已定位核验

## 为什么是问题

SC-001 的背景生产依赖真实、获准且版本可追溯的场景输入。当前记录中存在参考图、候选研究图和场景说明，但 Linear 674-54 明确要求不能把它们混作用户批准的森林背景母图。缺少可核验基准时，后续无法可靠声明使用了哪份输入或判断候选与批准范围是否一致。

## 因果链

参考/候选/研究卡并存且批准原件未被本地核验 → 下游可能误把候选当批准基准 → 场景制作来源不可追溯 → SC-001 场景验收受阻。

## 当前结论与边界

- 状态为 `BLOCKED`，阻塞的是批准原件定位与来源核验。
- 不代表场景构思失败，也不代表某张候选图质量不合格。
- 不授权本轮生成新图、修改 Canvas、移动素材或将候选升格。

- 暂无。先验证最小输入条件，暂不拆分。
