# 扩展接口｜素材与信息进库规程 v1.0

> **一句话：所有新东西走下面这张表进库；总 Canvas 永远只有两张，扩展=往里加节点，绝不新建文件。**

## 1｜两张总 Canvas（唯一可视化入口，永不新建）

| Canvas | 位置 | 组织轴 |
|---|---|---|
| `角色总Canvas.canvas` | 03_角色/角色库/ | 颜色 × 组织/地区 |
| `场景总Canvas.canvas` | 04_场景/ | 五色 × 地区 + 总/分地图 + 外部参考 |

**铁规则**：新内容 = 在对应总 Canvas 里**加节点/加分组**；版本演进靠节点更新，不靠开新文件。旧版本一律进 `99_归档/canvas旧版/`。

## 2｜新素材进库路径

| 你有什么 | 放哪里 | 然后做什么 |
|---|---|---|
| 外部参考图（网上找的/截图） | `04_场景/04_视觉参考/外部参考_用户收集/<类目>/`，命名`内容_风格.png` | 跟 AI 说一声 → 补进 `00_外部参考索引.md` + Canvas 外部参考区 |
| AI 生成的场景资产 | `01_五色视觉系统/` 对应 R 夹（正本）；要发外发再拷进 `02_场景资产图包/` | 更新 `00_图包索引.md` |
| 新角色卡 | `03_角色/角色库/01_角色卡/`（CH 线）或 `03_线A_S卡19人/`、`04_线B_60池/` | 更新 `00_角色总索引.md` + 角色总 Canvas 对应桶 |
| 新分桶/新组织设定 | `自由意志世界观/` 对应编号 md | 更新对应桶角色行 md |
| 新地图 | `02_场景资产图包/08_地图与全景/` | Canvas 顶部地图区加节点 |
| 故事/分镜 | `05_故事/` 或 `07_持续发散/<日期>/` | 发散池自动化会扫 |

## 3｜重复品纪律（防再乱）

1. **色卡/色规范正本只在 `00_总览/P00_项目统一色卡_v1.0.md`**——任何夹里不再放副本
2. 图包（02_场景资产图包）只存**图**，md 一律引用 01_五色视觉系统 正本（09_风格研究文件已清空删除）
3. 新文件入夹前计算哈希并登记重复组；**同哈希只证明字节相同，不代表可删**。不得自动删除或仅凭文件名清理；必须先核对全部路径、引用、来源和状态，再走 `[[素材代理_接入总控_20261001#8｜素材管理循环与三方审核（默认只读，不自动清理）|素材管理清理门禁]]`。
4. `_中间版本`、`垃圾桶` 类内容先登记来源与引用；经授权后才可移入 `99_归档/` 或可恢复隔离区，保留原路径映射，不直接盲移。

## 4｜AI 扩展动作清单（每次用户说「加素材/扩展」时）

1. 判断类型 → 按 §2 路径入夹（md5 查重）
2. 更新对应索引 md（外部参考索引/图包索引/角色总索引）
3. 在对应**总 Canvas** 加节点（不新建 canvas）
4. 汇报：加了什么、放哪了、Canvas 更新了哪个区
