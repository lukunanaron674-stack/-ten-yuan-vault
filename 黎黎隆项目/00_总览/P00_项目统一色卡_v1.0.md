# 黎黎隆｜P00 项目统一色卡 v1.0

> 这是《黎黎隆》项目所有视觉输出的统一颜色入口。角色、场景、道具、参考吸收图、动画背景和生成候选都以本色卡为颜色边界。

## 五个项目母色

| 编号 | 色名 | 色值 | 主要职责 |
| --- | --- | --- | --- |
| P00-01 | 深墨青 / 近黑 | `#142A34` | 轮廓、结构、暗部、骨架、平台、维护件和前景遮挡 |
| P00-02 | 灰紫 | `#855D8F` | 生体膜、菌脉、异常边界、奇异感和局部重音 |
| P00-03 | 暗红 | `#913840` | 生命脉搏、危险、警示、裂口、冲突焦点和状态转折 |
| P00-04 | 青绿 / 青蓝绿 | `#69D4CE` | 技术、能量、接口、导航、灯光和交互反应 |
| P00-05 | 淡青灰 | `#CDE7E6` | 大面积亮部、雾、湖面、远景、留白和钙化结构 |

## 使用规则

1. 本项目所有图都使用 P00 五色作为统一色彩母系；可以改变明度、透明度、面积和同色混合方式，但不能引入第六种独立主色相统治画面。
2. 一张图不要求五色全部出现。颜色是否成立，要看它是否附着在具体对象、结构、动作或状态上。
3. 深墨青负责承重和轮廓；淡青灰负责空间呼吸和远近层次；灰紫必须优先附着于生体或异常结构；青蓝绿必须有真实接口、供能或导航对象；暗红优先作为局部状态变量，不默认铺满环境。每种颜色都要继续落到可看见的物件、结构、动作和后果上，不能只停留在氛围形容词。
4. 颜色可以在“视觉脚本”层面等同或编码 NZ、X并Z、Z 的关系倾向，但不能把单一颜色当成关系本体或唯一证据。关系最终仍要由形体、空间、受力、动作、事件和后果共同证明。

### 三组关系的色彩脚本

- **NZ**：优先用“灰紫生体结构 + 青蓝绿接口/回流 + 深墨青共同支点”形成互相维持；不能只用灰紫滤镜表示 NZ。
- **X并Z**：优先用“深墨青承重结构被切开 + 暗红断口或危险状态 + 淡青灰空隙/后果”表示拆离、断裂或不可逆错层；不能只用暗红表示 X并Z。
- **Z**：优先用“深墨青结构底座 + 青蓝绿接口/供能 + 淡青灰冷却或恢复层”表示技术化维持；灰紫可作为生体维修层，但不能把青蓝绿直接当作 Z。

因此，允许在色彩脚本里写“NZ 倾向”“X并Z 倾向”“Z 倾向”，也允许用这些颜色先做构图发散；验收时必须补齐关系所对应的对象、力链、动作和结果。
5. 角色进入场景时，保留角色原稿的身份锚；只用环境光、接触阴影、遮挡、水面反射和局部色彩反射完成融合，不用滤镜抹平角色差异。

## 明确禁止

- 不使用黄、橙、棕、金色、草绿、纯蓝、粉色、肤色作为独立主色相。
- 不把五色做成统一赛博朋克霓虹滤镜。
- 不用颜色替代世界机制、角色身份、空间用途或事件因果。
- 不为了补色擅自修改已确认角色、世界观或原始参考图。

## 生产检查

每张候选图在进入 Canvas 或动画前，至少检查：

- 是否能指出画面中每个主色承担的对象或功能？
- 是否仍然看得出轮廓、路线、受力和负空间？
- 灰紫、暗红、青蓝绿是否被限制在有理由的结构或状态上？
- 是否出现第六种独立主色相？
- 角色是否保留原稿身份锚，且与场景有接触、遮挡和光线关系？
