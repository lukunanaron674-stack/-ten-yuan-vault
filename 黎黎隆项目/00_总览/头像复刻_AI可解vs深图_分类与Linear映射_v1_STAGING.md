## 6.6｜一轮消元的标准循环

```
整理层：确认输入项清单 + SHA + 固定测试角色
   ↓
codex：按模板出图（单变量，一轮只改一项）→ output_path + SHA + seed
   ↓
chat大脑：按 8 维 + 五问判读 → 出判定表 + 结论
   ↓
整理层：回写 manifest / 评分记录 / 阈值文件
   ↓
674：拍板 PASS / RERUN / REJECT（仅审美项）
   ↓
下一轮：只改一个变量
```

**注意**：代码跑图（codex）与判读（chat）必须分离。codex 不判定，chat 不生图。
