# Character Style Grammar v0.1｜黎黎隆

## 核心句
**奇幻生物感的大形 + 后加的科技模块 + 少量灾变改写痕迹 + 强剪影 + 动画友好复杂度。**

---

## 1. Shape Grammar
- 先大形，后中形，再小形
- 每角色 1 个主剪影符号
- 大形不得被小结构切碎
- 非对称优先于均匀对称
- 复杂结构必须可在远景降级

## 2. Line Grammar
- 外轮廓清楚
- 内部线条少于外轮廓
- 成人角色更硬、更少
- 年轻角色更柔、更有弹性
- 机械刻线只存在于功能节点

## 3. Face Grammar
- 表情优先
- 眼眉承担主要情绪
- 鼻嘴简化
- 不统一成同一种动漫脸

## 4. Costume Grammar
- 服装先承担身份，再承担装饰
- 装饰集中，不平均铺开
- 布料与机械必须存在清晰交界

## 5. Material Grammar
- NZ：软 / 旧 / 活 / 手工
- Z：冷 / 模块 / 接口 / 包覆
- X并Z：缺口 / 错位 / 侵入 / 黑紫

## 6. Color Grammar
- 1主色 + 1结构辅色 + 1焦点色
- 大面低饱和
- 红 = 生命/主观性
- 青 = 系统/科技
- 黑紫 = 灾变改写
- 灰白 = 中介/旧结构

## 7. Mechanical Grammar
- 大壳体 > 中型关节 > 小接口
- 包裹 / 咬合 / 套接 / 折叠 / 滑移
- 禁止串珠
- 禁止均匀重复
- 禁止用零件数量代替结构设计

## 8. Animation Grammar
- 中远景仍认得
- 动作时主轮廓不崩
- 机械展开前后主形相关
- 尾巴/机械臂必须参与表演

---

# 角色专用规则

## 大叔
- 瘦长、松弛、非对称
- 单侧巨臂是第二主身体
- 暗红人物色 + 淡青机械色
- 人松 / 机械重
- 承载链必须合理

## 黎黎
- 红发 + 高表情
- 小上身 + 大尾体
- 尾巴是第二身体
- 嵌合包裹式机械
- 野生、灵活、不完全工业化

## 奇美拉
- 翼臂 + 胸腔 + 后肢形成主结构
- 所有异形结构围绕飞行/抓取/压制服役
- 冷灰/灰青主体 + 紫翼
- 不靠尖刺堆威胁

---

# Negative Grammar
- 不要赛博霓虹
- 不要平均复杂
- 不要串珠机械
- 不要同脸
- 不要细节先于轮廓
- 不要十种参考平均融合
- 不要纯半写实
- 不要全身高饱和
