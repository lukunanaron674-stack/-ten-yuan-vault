## 画风影响

- 从“干净数字动画设定稿”转向“灰纸墨线水彩角色设定稿”。
- P00 五色仍是母色，但允许被灰化、透明叠色、纸感留白和水彩脏边处理。
- 线稿不追求矢量干净；需要粗细不均、轻微手抖、断续边、干笔边缘。
- 阴影以灰紫、灰黑、淡青灰水彩薄涂为主，不使用硬边赛璐璐高光或随机白斑。
- 黑色服装不做纯黑平涂；应是灰黑水彩块面，少量 purposeful folds，避免密集黑色碎线。
- 四格仍可保留：全身比例稿、全身 45°稿、头部表情稿、头部 45°稿；但格子应像手绘稿模块，不像工业化模板。

## 生成提示修正

优先写：

```text
灰纸底、手绘墨线、透明水彩洗色、粗细不均的黑色轮廓、干笔边缘、低饱和灰紫与淡青灰叠色、纸感颗粒、角色设定稿小模块。
```

避免写成主导词：

```text
clean digital animation line art, vector clean, orthographic production model sheet, hard cel shading, glossy highlight, P00 only flat color.
```

## 使用边界

- 适用于 CH-003 以及后续需要“小图设定稿、角色四格、表情与转面”的角色探索。
- 不自动套用到所有主角。高壮冒险者、澈、小和尚、大叔、奇美拉仍需保留各自比例与身份差异。
- 不新增独立色相；黄色、橙色、土黄、草绿、纯蓝、粉色仍不进入主调。
- 不把资料页排版强制带入所有图。作者已确认“不需要 4”，即不需要完整资料墙、故事块、关系小镜头和道具目录。
