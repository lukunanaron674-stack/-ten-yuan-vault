# 角色批量全身图任务书 v1.0

## 0｜执行方式（给 GPT 的话）

逐角色跑，每角色产 **1 张 9:16 四格参考卡**，不许跳步、不许合并角色。每张完成即按 §5 命名落盘并登记状态，下一张继续。遇到规格冲突，以本任务书 > 角色卡 > 任何口头描述。

## 1｜一致性硬约束（每张都要过）

1. **五色**：主色只从 `#142A34 墨青 / #855D8F 灰紫 / #913840 暗红 / #69D4CE 青绿 / #CDE7E6 淡青灰` 取（P00_项目统一色卡_v1.0.md），角色个人色=五色内配比，不引入新色相
2. **比例锁定**：同一角色四格内身高/头身比/肩胯/尾/角比例必须一致；黎黎隆系（红发小上身+巨尾）不得画成等身比例
3. **识别件**：角色卡里列的识别件（角套/机械臂/官帽/面罩/尾根模块…）四格全部出现，位置一致
4. **生体×机械**：自然结构与旧机械嵌合承重，不是纯机械甲也不是纯生物
5. **验收五问**：①识别件在 45° 转面还认得出吗 ②比例和左上一致吗 ③配色越界了吗 ④性别/年龄感漂移了吗 ⑤换成普通中世纪人类还成立吗（成立=重做）

## 2｜四格规范（9:16 角色魅力 B 端卡）

| 位置 | 内容 | 锁定目标 |
|---|---|---|
| 左上 | 全身比例稿（正面） | 身高、头身比、肩胯、四肢/尾长度；不强调脸 |
| 右上 | 全身 45° 稿 | 胸背厚度、服装层级、道具与身体空间关系 |
| 左下 | 头部表情稿 | 脸型、发型、识别件、表情范围 |
| 右下 | 头部 45° 稿 | 五官空间、转面、识别件转面位置 |

底色用淡青灰 `#CDE7E6` 或墨青 `#142A34` 纯色，不加场景、不加文字水印。
