## 使用规则

1. `visual_id`（H/N/S/NPC）只是视觉候选编号，不自动改成 CH，也不自动成为 LLL-CHAR。
2. 角色 Agent 审：身份、世界位置、十元、冻结部位、是否与现有角色重复。
3. 素材 Agent 审：真图重同步、path、SHA、视图类型、重复组、风格/H3绑定。
4. 正式角色主 ID 只有在双方 PASS 后才分配/关联。
5. 用户当前明确排除 `CH-*` 与黎黎隆正式生产，本表用于“新角色”入口。
6. 旧“青桶/红桶”只保留为历史候选桶证据，**不等于** P00 五色 C01–C05，也不等于世界区域。
7. 当前所有 `production_ready=false`，直到真图重新落到 current main 或执行端可验证位置。

## 当前最重要的缺口

不是“没有新角色”，而是：

```
历史/本地视觉资产
    ↓
全库清单 + SHA 有记录
    ↓
current main 图片子目录缺失
    ↓
角色正本只有 4 张 CH 卡
```

所以正确工作不是再发明角色，而是先把高优先候选的真图重新同步并认领身份。
