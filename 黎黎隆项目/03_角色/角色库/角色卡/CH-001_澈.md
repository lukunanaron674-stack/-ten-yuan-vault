# 角色卡｜澈

> **一句话**：城市建立之前就存在的纯粹能量生命。他自愿守护城市，却拒绝让城市替他决定什么生命值得守护。
>
> 名称「澈」为本次工作命名，尚待作者最终确认；不是旧设定中已定稿的名字。

## 一、身份与核心

- 男性；外观为清冷的少年／青年，实际存在时间早于城市建立，具体年龄不设定。
- 他既非城市制造的英雄，也非魔法学院培养的守护者；不是机器人、神明或受封印的武器。
- 最初没有固定的身体。为了与城市居民交流，逐渐学会语言、规则和人形生活方式。
- 身体、意识与能量本为连续一体；魔法对他不是外部工具，而是其生命本身的形态。
- **极致之人**：探索自身形态与力量的极限；**最为纯粹之人**：力量和意志不由外部制度定义；**力量的极端**：不依靠装备，直接改变自身能量形态、密度与流向。
- 纯粹不是无情、永远正确、没有欲望，也不等于无限魔力。

## 二、守护关系与角色矛盾

他曾自愿帮助居民应对危险，与城市中的生命建立关系；城市逐渐将其能力接入自动防护系统，试图预设威胁分类、处理程序和行动命令。他可以理解规则、参与城市运行，却不把自己的判断权交给系统。

**具体冲突候选（剧情未锁）**：城市将某类未伤害人的古老奇幻生命归为必须清除的异常。他拒绝照办，主动从防护系统中重新组织、收回自身能量。他并不因此放弃城市居民，而是选择保护系统遗漏或排斥的生命。

- 他守护的是城市中的生命及其继续存在的可能，不是无条件维护现行系统。
- 他拥有拒绝命令的权利，也承担自己选择带来的后果。
- 最终登场必须是他自主作出的决定；避免成为主角困境里自动启动的终极武器。

## 三、能力与边界

1. **整体能量化**：整个人形由连续的青白色能量构成；不是穿上发光装甲。
2. **自发改形**：可在意识与能量连续的前提下凝聚人形、改变密度、流向、局部延伸及身体尺度。
3. **接入与退出**：能够将自身能量接入相容的魔法／城市结构，并保留主动重组、退出及改变作用方向的权利。
4. **极致凝聚与展开**：可把力量集中于小体积，也可短时扩展为大尺度人形或防护结构。

**尚待确定的限制**：持续时间、可达范围、与不相容能量的相互作用、重新凝聚的代价，以及如何在城市规模施力时保留对个体的感知。不得直接写成无限能量、绝对无敌或完全无代价。

- 保留：浅青白色不对称蓬松发型、头顶小翘发束、偏灰紫的面部、平静而集中的单眼视觉重心、原稿颈肩的青白色质感。
- 从脖子到肩、胸、腹、双臂、双腿、脚均延续原稿颈部同一套连续的青白色能量材质。
- **不设计衣服**；不增加铠甲、机械核心、魔法阵、武器、模块化硬壳、固定翅膀或多余挂件。正常状态保持完整清晰的人形与少年体态。
- 画风遵循作者原稿：简化平涂／薄涂、干净但保留手绘感的轮廓、清楚的头发大块关系；不改成长大衣、华丽游戏立绘或高写实概念图。
- 功能亮色：青白、薄荷青；灰紫用于头面暗部。能力强不等于全画面过曝、淹没五官与轮廓。
- **待设计**：正／侧／背三视图；凝聚、流动、局部延伸、完整释放的分层设计；与建筑／黎黎隆同框的尺寸关系。

## 五·新增设定｜纯粹的 Z × 洞悉阴谋政权的 X并Z（2026-09-21，作者追加）

> 本轮用户称其为「策」；因现存角色卡、此前对话中的“无比纯粹之人”对应角色「澈」，本次按**同一角色的设定更新**记录；在明确改名之前，保留原卡名、编号、视觉锚点，不私自把「澈」改名为「策」。

### 作者明确提出的角色内核（设定层，予以保留）

- **Z｜无比纯粹之人。** 他的意志、判断与存在不因外界的权力叙事而改变；纯粹不是无知、天真、道德绝对正确或没有复杂行动能力。可允许他明知代价仍坚持自身所确认的核心，但不能推定他永远知道所有事实。
- **X并Z｜对阴谋政权无比了解之人。** 他熟悉这个虚构政权的表面名义、公共身份、信息呈现、权力层级如何对外显现，以及这些外在形式怎样与实际运作、秘密安排发生差异。他不是第一次进城才发现“系统有问题”的懵懂少年；其了解应在行为上留下证据：辨认一个公开名义背后的具体行动主体、区分公共表象与内部路径、预测被某项公开决定调动的对象、识别谁实际掌握一次公开呈现。**知识储备本身不能直接证明标准 X并Z 端点或生克补关系已经启动**，这些是把作者给出的 X并Z 人物构成进一步具体化的候选显影，仍须按新端点卡与事件变量逐项核验。
- **人物张力：** 纯粹与洞悉并存。他知道阴谋及运作细节，却不因此天然认同其逻辑；但也不是一见制度就一定反对。理解、利用、拒绝某种机制是三个不同的行动状态，必须由具体选择证明。

### 角色行动与剧作红线

1. 不写成“被黎黎隆告知城市阴谋后才觉醒”；他对政权已有深层理解，黎黎隆的 Z、ZX 应通过**创造他未预见的行动条件或改变关系位置**发挥不可替代作用。
2. 不写成万能预言者、权谋家或随时可以暴露全部真相的讲解员；他知道的范围、证据入口、无法确认处和公开表态的现实后果都需在具体事件中说明。
3. 他守护城市生命的自主决定，与熟知政权的运作可以同时成立；保护对象、保护方式、公开身份是否被调用应分别记录，不把“纯粹”自动等同“保护所有人”。
4. 既有原生能量生命身份、连续一体的身体、无衣装视觉、独立守护权保留；此次只更新人物十元与人物认识，不擅改人物原稿。
5. 暂以 **Z 核心 + X并Z 重要构成** 为创作输入，二者的 1–10 体量、主次差值与标准生克补边尚待角色行为和作者后续校准；不得用旧的 NZ→Z→X、ZX→X→N 阶段顺序覆盖本次新增的同时构成。

### 与黎黎隆的可检验关系入口（非正史故事）

- 澈掌握一份关于虚构政权公开防护壳与真实运行状态的对象级知识；黎黎隆从具体现场行动得到一个与“公开叙述”不吻合的现象。
- 澈有能力辨认其幕后运作，却未必掌握使某个现实状态改变的直接行动条件；黎黎隆可以改变现场，但不能代替他决定如何使用已知信息。
- 需选定同一个**被改变变量**（例如某一生命是否继续被实际保护、某个公开身份是否能代表真实主体），区分：角色固有构成 / 当前行为 / 世界运作 / 直接标准边 / 多步间接结果。
- 音乐研究先比较 Z 的稳定内核与 X并Z 公开层反复变形的**两条叙事线**，不得凭音色明亮标 Z、凭阴谋歌词标 X并Z；音量和情绪不能自动折算十元体量。
