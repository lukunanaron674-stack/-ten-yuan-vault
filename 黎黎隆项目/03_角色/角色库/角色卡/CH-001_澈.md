# 角色卡｜澈

> **一句话**：城市建立之前就存在的纯粹能量生命。他自愿守护城市，却拒绝让城市替他决定什么生命值得守护。
>
> 名称「澈」为本次工作命名，尚待作者最终确认；不是旧设定中已定稿的名字。

## 一、身份与核心

- 男性；外观为清冷的少年／青年，实际存在时间早于城市建立，具体年龄不设定。
- 他既非城市制造的英雄，也非魔法学院培养的守护者；不是机器人、神明或受封印的武器。
- 最初没有固定的身体。为了与城市居民交流，逐渐学会语言、规则和人形生活方式。
- 身体、意识与能量本为连续一体；魔法对他不是外部工具，而是其生命本身的形态。
- **极致之人**：探索自身形态与力量的极限；**最为纯粹之人**：力量和意志不由外部制度定义；**力量的极端**：不依靠装备，直接改变自身能量形态、密度与流向。
- 纯粹不是无情、永远正确、没有欲望，也不等于无限魔力。

## 二、守护关系与角色矛盾

他曾自愿帮助居民应对危险，与城市中的生命建立关系；城市逐渐将其能力接入自动防护系统，试图预设威胁分类、处理程序和行动命令。他可以理解规则、参与城市运行，却不把自己的判断权交给系统。

**具体冲突候选（剧情未锁）**：城市将某类未伤害人的古老奇幻生命归为必须清除的异常。他拒绝照办，主动从防护系统中重新组织、收回自身能量。他并不因此放弃城市居民，而是选择保护系统遗漏或排斥的生命。

- 他守护的是城市中的生命及其继续存在的可能，不是无条件维护现行系统。
- 他拥有拒绝命令的权利，也承担自己选择带来的后果。
- 最终登场必须是他自主作出的决定；避免成为主角困境里自动启动的终极武器。

## 三、能力与边界

1. **整体能量化**：整个人形由连续的青白色能量构成；不是穿上发光装甲。
2. **自发改形**：可在意识与能量连续的前提下凝聚人形、改变密度、流向、局部延伸及身体尺度。
3. **接入与退出**：能够将自身能量接入相容的魔法／城市结构，并保留主动重组、退出及改变作用方向的权利。
4. **极致凝聚与展开**：可把力量集中于小体积，也可短时扩展为大尺度人形或防护结构。

**尚待确定的限制**：持续时间、可达范围、与不相容能量的相互作用、重新凝聚的代价，以及如何在城市规模施力时保留对个体的感知。不得直接写成无限能量、绝对无敌或完全无代价。

## 四、视觉冻结与待设计项

**以作者上传的原稿头部为唯一当前造型锚点。** 前期 AI 生图只是结构探索，不作为最终定稿三视图。

- 保留：浅青白色不对称蓬松发型、头顶小翘发束、偏灰紫的面部、平静而集中的单眼视觉重心、原稿颈肩的青白色质感。
- 从脖子到肩、胸、腹、双臂、双腿、脚均延续原稿颈部同一套连续的青白色能量材质。
- **不设计衣服**；不增加铠甲、机械核心、魔法阵、武器、模块化硬壳、固定翅膀或多余挂件。正常状态保持完整清晰的人形与少年体态。
- 画风遵循作者原稿：简化平涂／薄涂、干净但保留手绘感的轮廓、清楚的头发大块关系；不改成长大衣、华丽游戏立绘或高写实概念图。
- 功能亮色：青白、薄荷青；灰紫用于头面暗部。能力强不等于全画面过曝、淹没五官与轮廓。
- **待设计**：正／侧／背三视图；凝聚、流动、局部延伸、完整释放的分层设计；与建筑／黎黎隆同框的尺寸关系。

## 五、十元动态（假设，非评分定论）

- **生命线 NZ → Z → X**：最初自由存在的连续生命 → 学会理解人类语言与魔法规则 → 明确自身形态与行动的决定权。
- **守护线 ZX → X → N**：主动处理迫近的危险 → 拒绝由城市接管自身判断 → 与具体生命建立自主的守护联系。
