# 角色卡｜CH-003 逃票魔法学徒（暂用身份名）

> **一句话**：戴着老师留下的活体魔法帽、外表安静却满脑子奇怪点子的孩子，利用城市魔法服务的漏洞寻找失踪的老师与魔法塔。
>
> 本卡合并作者选择的 **06「城市里的逃票魔法师」** 与 **08「被遗忘的魔法学徒」**；两者是**同一角色的现在与过去**，不是两个新角色。正式姓名、性别与准确年龄均待作者确认。

## 一、当前身份与性格｜06

- 在城市里生活的孩子；看着安静、乖巧，实则机灵、古灵精怪、喜欢出其不意。
- 没钱购买高价魔法服务，于是研究别人没想到的使用方法与系统没有覆盖的路径。
- 他并非「什么都不懂的笨小孩」，也不是把所有规则当成敌人；会观察、试探、记住失败的办法，再临时变招。
- 表层目标：在城市中用自己的办法使用魔法设施、寻找遗失的线索。
- 深层目标：找回失踪的老师，并弄清魔法塔消失的原因。

## 二、过去与活体魔法帽｜08

- 曾与一位魔法师共同生活，是其学徒；一次失败的时空魔法后，老师和整座魔法塔消失。
- 老师留下的一顶帽子拥有生命；它可用帽檐、顶部羽毛状物件的动作表达感受，偶尔会替孩子作出决定或制止他继续前进。
- 帽子既是同伴，也是过去留下的线索。它究竟保存了老师的意识、记忆、某种魔法记录，还是独立生命，**均未定稿**。
- 孩子利用城市服务漏洞寻找失踪事件的相关异常，并不必然是「为占便宜而逃票」。

## 三、视觉依据与冻结项

### 作者原稿（最高优先级）

- 大圆脸、偏小的五官、黑色短发与略不对称刘海；脸颊有淡紫色圆斑；安静、略困惑的视线。
- 头顶为**紫色不对称大帽檐＋浅色斜向帽带＋一根细长羽毛状顶部结构**。
- **当前原稿仅画了上半身**；下方黑色区域**不能擅自认定为斗篷**，也不能由此认定全身长度、下摆或腿部比例。
- 继续探索以原稿的头部比例、脸型、帽子剪影、黑色身体区域的已知边界为约束，不把角色随手变成标准 Q 版、传统法师袍或机械兵。
- 当前聊天中作者原稿与 AI 探索图均已出现，**尚未核对到 GitHub 图片资产**；不得将其写成已存在的 Vault 嵌入图片。

### 允许发散，尚未冻结

- 活体帽子：帽檐开合、羽毛摇摆、触碰/拽住孩子等可表演的动作；浅色帽带里的工具与可弯曲万能钥匙均为**探索方案**，不是定稿机械设定。
- 服装与下半身：根据原稿头身节奏提出多个全身方案，先校准比例与剪影，再做局部工具/随身物品。

## 四、能力机制与限制｜待验证

- 候选能力 A：识别城市魔法服务中没有被标准使用流程覆盖的路径，借既有设施完成常人必须付费才能完成的行为。
- 候选能力 B：帽子可感知失踪魔法塔相关异常，以动作提醒、保护或阻拦孩子。
- 候选能力 C：顶部羽毛可变成弯曲的「钥匙」或魔法感应结构；具体是魔法生物能力还是小道具，尚未决定。
- 不能默认他可随意破解全部系统或免于付出代价。系统升级、陌生设施、帽子的自主意志、寻找老师与自身安全的冲突都可成为真实限制。

## 五、与黎黎隆的相遇｜已选方向，细节待锁

1. 黎黎隆发现他可以**不付钱进入收费魔法建筑／传送设施**，因好奇跟随。
2. 两人借规则之外的路径进入异常区域；黎黎隆偏主动试验与临场出招，孩子偏寻找入口和隐藏路径。两人都机灵，但行动方式不应完全同质。
3. 进入某处后，帽子突然主动制止孩子；当黎黎隆触碰帽子，羽毛指向她的机械龙尾或其中某个部件。
4. 帽子似乎认出了黎黎隆身上的某种异常。它为何认出、与老师/魔法塔有什么关系，**留作悬念，尚未定稿**。
