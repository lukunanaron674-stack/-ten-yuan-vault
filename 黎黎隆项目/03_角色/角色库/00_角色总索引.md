# 《黎黎隆》角色库｜总索引

> 主 ID `LLL-CHAR-###` 保持稳定。角色另外使用 P00 五色桶 C01–C05 排序；五色桶不是世界区域，也不是十元。

## 判定口径

- **世界归属**：cyan / red / pink / cross_region / unassigned
- **世界同化**：PASS / PARTIAL / CONFLICT / UNASSIGNED
- **五色视觉桶**：C01 深墨青 / C02 灰紫 / C03 暗红 / C04 青蓝绿 / C05 淡青灰
- **READY_VISUAL**：素材端确认身份匹配的四宫格、全身、中全景或中景角色设定图，角色设计层可用
- **HEAD_ONLY_DESIGN_PENDING**：只有单头像，仍是待设计
- **ASSET_UNVERIFIED**：素材端尚未确认真实可定位图

正式生产仍需额外通过风格审核、H3绑定等门禁。

## 素材端完成后如何迁移

AG-04 / 本地 Codex 对账结果返回后：
1. 真四宫格 + 身份匹配 → `READY_VISUAL`
2. 真全身 / 中全景 / 中景 + 身份匹配 → `READY_VISUAL`
3. 只有单头像 → `HEAD_ONLY_DESIGN_PENDING`
4. 无真图 → `ASSET_UNVERIFIED`
5. 按真实主参考分配 C01–C05 与 `color_sort_id`
6. AG-11 更新本索引，不移动原角色卡路径
