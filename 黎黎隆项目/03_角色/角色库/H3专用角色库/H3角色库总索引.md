# H3 专用角色库

> [!info] 用途
> 这是面向 MiniMax H3 / Ref2VA 的角色参考库，不替代正式世界观角色卡。每个角色以后使用一张 **9:16 角色魅力 B 端角色卡**，固定提供四类参考：全身比例、全身 45°、头部表情、头部 45°。

## 四格规范

| 位置 | 参考图 | 锁定目标 |
| --- | --- | --- |
| 左上 | 全身比例稿 | 不强调脸；锁身体比例、身高、肩胯关系、四肢长度 |
| 右上 | 全身 45°稿 | 保留结构；锁胸背厚度、服装层级、道具与身体的空间关系 |
| 左下 | 头部表情稿 | 锁脸型、发型、帽子／角／耳等识别件、表情范围 |
| 右下 | 头部 45°稿 | 锁五官空间、头部转面、识别件在转面中的位置 |

## 工作状态定义

- `待四格`：已有正式角色卡或素材，但尚未补齐四格 H3 参考。
- `四格候选`：四格已补齐，但仍是候选，不能当作定稿。
- `待人工确认`：需要确认比例、脸型、识别件或服装结构。
- `H3可用`：四格齐全、路径真实可读、经过人工确认，可用于 Ref2VA。
- `已锁定`：用户确认后保留独立版本；不得覆盖原始素材。

## 建卡验收

- [ ] 画布为 9:16 卡面，四格顺序固定，不把动作姿态稿当成比例稿。
- [ ] 全身比例稿能看清身高、肩宽、胸背、手脚和服装下摆。
- [ ] 全身 45°稿能看清前后层级、背部轮廓、道具占位和空间关系。
- [ ] 头部表情稿能看清脸型、识别件和至少 3 种可用表情。
- [ ] 头部 45°稿能看清五官转面和识别件的透视位置。
- [ ] 四个参考均为真实文件路径；未准备好时使用文字占位，不伪造 `type:file`。
- [ ] 候选、待确认、H3可用、已锁定状态分开记录。
- [ ] 不覆盖正式角色卡、原始素材或统一风格 Canvas。
