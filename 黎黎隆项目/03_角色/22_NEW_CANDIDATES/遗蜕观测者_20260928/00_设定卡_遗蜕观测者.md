# 遗蜕观测者｜设定卡

> 来源：作者 2026-09-28 口述设定（基于两张设定图第一眼观感反推世界观解释）。
> 定位修正：**不是粉色区魔法师**，是粉色区里偏怪异、偏古老生命体系的一支。

## 1｜核心概念：遗骸生态带

粉色区深处存在大量已死亡、休眠或只剩局部活性的**古老巨型生命**。它们死后不会完全腐烂——骨骼、眼睛、神经、皮膜、甚至某些**记忆**，会继续生长在森林与岩层中。

本角色所属族群寻找这些**「遗蜕」**，让遗蜕重新寄生在自己身体上。

## 2｜视觉设定（按设定图逐项解释）

| 视觉元素 | 世界观解释 |
|---|---|
| 白色骨壳（头上） | **古生物遗蜕**——不是帽子也不是头盔，是「活着的头骨」 |
| 红紫圆眼（3 枚） | 古生物残留的**副眼/感知器官**——不是机械镜头、不是灯、不发光 |
| 黑色裂缝（发际线） | 神经与骨壳的连接处 |
| 长耳（白色垂瓣） | 粉色区原生种族特征 |
| 灰紫肤色 | 长期与遗蜕共生后的身体变化 |
| 红黑领口/绑带 | 人工制作的**固定/隔离结构** |

> 反直觉原则：人类看到圆形结构就安"摄像头/机械眼"，神秘感即死。本角色一切"机械感"部件必须反向解释为**古生物残留器官**。

## 3｜能力：借眼（不做普通施法）

她自己看到的世界很普通；**闭上一只眼，可以选择让头骨上的某枚"眼睛"睁开**。不同的眼看到的东西完全不同：

| 眼 | 能力 |
|---|---|
| 第一只眼 | 看见附近生命**最近经历过的强烈情绪** |
| 第二只眼 | 看见已死亡生命**残留的行动轨迹** |
| 第三只眼 | 看见某地**原本的生态状态** |

效果：走过荒废城市，现实里什么都没有；但她眼里——巨兽仍从街道上经过、死去的人仍坐在窗边、几百年前的森林覆盖着今天的建筑。

> 设计理由：能力直接**产生场景和故事**，不是"发射魔法弹"式人类朴素想象。

## 4｜性格（反神秘化）

视觉已经够神秘，性格**不做沉默冷酷谜语人**（否则长成标准奇幻 NPC）：

- 表面冷淡，实际**有点嫌麻烦、容易走神的年轻遗骸采集员**
- 头骨上的眼睛各有一点**残余意识**，经常擅自东张西望
- 名场面：她："别看了。" → 左眼继续盯路人 → 她伸手按回去 → 右眼又睁开

## 6｜梦核设定（2026-09-28 作者口述·第二层）

**整个村子，活在巨物的梦里。**

- 村民不知道。他们以为肋骨峡谷就是世界。
- 她因为头骨与她**共生**（不是戴上，是长在一起），成为全村**唯一知道这件事的人**。
- 她只要把巨物**叫醒**，整个村就会消失掉。
- S02 的"古兽翻身"因此获得第三层解释：不是地震、不是迁移——**是梦快碎了**。她那句"它只是睡觉翻身"是全片唯一一句真话。

**十元落点（作者判，两个符号）**：诡秘粉色 × `x并z` + `nz`——共生遗蜕=梦的接口；沉默守护=不应醒的梦。

**我的审读意见（AI）**：成立，且是三层咬合：
1. **回接 S02**：翻身=梦里翻身，成片的淡定从"性格 cool"升级为"全村唯一知情人"，一遍看完和二刷完全是两个片子
2. **接住红2**：叫醒权=自由意志问题（谁知道真相/谁有权决定/说出口算不算决定）——她出生不是红桶，红色张力自己长出来，不用改底色
3. **纯粉不渗青**：梦不可测量、不可接口化管理、不可标准化——正是粉桶"诡异魔法"的本体论，青色技术在她面前天然失灵
4. **咬合借眼**：第三只眼（看见某地原本生态状态）可顺势升级为「看见梦的边缘」——梦开始变薄的地方，就是巨物快醒的地方

⚠️ 铁边界建议（防滥用）：巨物**只能翻身、不能醒**——"醒"是终局级事件（纪元级），任何单集不得真的叫醒；她与梦的关系是**守夜人**，不是持有解除按钮的人。
