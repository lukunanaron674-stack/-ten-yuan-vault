# 《黎黎隆》世界母设定

> status: WORKING_CANON  
> confirmed_by_user: 2026-10-01  
> scope: 整个《黎黎隆》世界，不等同于任一单独色区  
> note: 本文件登记项目世界观使用口径，不修改十元系统 Canon。

## 1｜统一直观印象

> **一个美丽、完整、古老的奇幻世界，但现实关系随时可能悄悄“接错”；文明一直在试图理解它，却永远只能理解一部分。**

第一眼必须首先读到完整奇幻自然，而不是工业异常区或纯恐怖世界。

第二层才出现：
- 关系错接；
- 性质嫁接；
- 身份替换；
- 异化；
- 空间/生命/归属发生不完全可解释的偏移。

文明随后才以观察、记录、判断、利用、制度化去处理其中一部分。

## 2｜整个世界统一主次十元

### 主：NZ
**工作权重：8**

承担：
- 完整奇幻自然；
- 长期生态；
- 生命关系；
- 古老而自洽的生活世界；
- “当地生命本来就是这样活着”的自然感。

### 次：X并Z
**工作权重：6**

承担：
- 未知错接；
- 异化；
- 身份/关系替换；
- 性质嫁接；
- 原有完整结构内部出现“不完全属于它”的新关系。

X并Z不是世界全部未知的同义词。只有发生真实错接、嵌合、归属改变等结构时才进入该判定。

### 小量：Z
**工作权重：3**

承担文明面对未知之后的：
- 观察；
- 命名；
- 判断；
- 分类；
- 记录；
- 利用；
- 标准化与制度化。

Z重要，但不能压过NZ成为世界第一印象，否则世界会退化为研究所/制度世界。

## 3｜世界母链

```text
NZ
完整奇幻自然 / 长期共生 / 原生生活世界

↓ 内部持续出现

X并Z
错接 / 嵌合 / 异化 / 身份与关系偏移

↓ 文明尝试理解并利用其中一部分

Z
观察 / 命名 / 分类 / 复验 / 规则 / 机能化
```

母链简写：

> **NZ → X并Z → Z**

解释：
- 不是“NZ被破坏后由Z修复”；
- 而是完整奇幻自然中持续出现无法完全解释的错接与异化，文明再尝试把其中一部分理解、调用、制度化；
- Z化永远不能保证彻底吃掉未知。

## 4｜世界未知与资源的边界

世界本身存在大量尚未完全理解的异律现象。

```text
世界未知 ≠ X并Z
世界未知 ≠ 资源
```

只有当异律被文明发现、可利用时，才进入“资源”讨论。

当前资源推理顺序：

```text
自然
→ 异律
→ 可利用异律
→ 资源
→ 可复现
→ 机能
```

因此：
- 基础资源仍包括食物、水、土地、矿物、普通生物材料；
- 原生奇幻资源来自本世界稳定生命/生态；
- 高战略价值来自可利用的异律；
- 青色尤其擅长把异律的一部分转成可重复机能。

## 5｜三色与世界母设定的关系

三色不是三个平行的“资源类型”，而是面对同一世界母问题形成的不同文明战略。

### 粉色
> **把变化长期活成新的完整自然。**

倾向：
- NZ主；
- 保持、适应、延续完整生命关系；
- 异常经过长期生活可以重新成为当地自然。

### 青色
> **把变化提炼成可重复机能。**

倾向：
- Z × X并Z；
- 对异常关系进行观察、复验、分类、工程化；
- 现有核心对子保持：X并Z → 生Z。

### 红色
> **确保变化仍由主体选择和声明。**

倾向：
- Z + ZN；
- 面对身体、身份、关系、组织被改变时，维护主体的选择、退出、重新确认与表达。

三色并非严格同层镜像，不强行做三等分：
- 粉色更偏“生命如何存在”；
- 青色更偏“文明如何获得机能”；
- 红色更偏“主体如何决定”。

## 6｜世界统一诡异感

目标不是“到处闹鬼”，而是：

> **世界总体稳定，但稳定建立在许多并未完全理解的东西上。**

建议直观比例：

```text
约90%：正常生活、工作、旅行、城市与生态
约10%：没人真正知道为什么某些规则必须这样运行
```

真正的诡异感来自：
- 居民习以为常；
- 文明已有应对方法；
- 但没有人能够保证这些规则永远不会重新改写其余部分。
