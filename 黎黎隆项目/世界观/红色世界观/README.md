# 《黎黎隆》红色世界观文库

> 状态：建立中  
> 核心：**Z + ZN**  
> 用途：沉淀《黎黎隆》红色世界观的正式设定、审核通过条目与影响力体量。

## 核心口径

- **Z**：自主选择、转向、灵活决定、行动方向、主体意志与身体主权。
- **ZN**：表达、号召、感染、热度、群体共振、把意志外显。
- 允许标注：`ZN` / `Z` / `Z的ZN` / `ZN的Z` / `Z+ZN两者都有`。
- 不满足 Z / ZN 核心的设定不进入正式文库。

## 影响力体量

- **1–3**：局部器物、习俗、个人层。
- **4–6**：行业、组织、城区层。
- **7–8**：城市或广域文明结构。
- **9–10**：改变整个红色体系运行逻辑或时代结构。

## R0｜首批正式条目

### 1. 自决契约
- **分类**：Z
- **影响力体量**：8
- **定义**：重要关系与长期契约必须保留周期性的退出、改投与重议权；“还能重新选择”本身被视为权利。
- **Z部分**：主体可改变既定行动方向，不被一次承诺永久锁死。
- **ZN部分**：非必要。
- **影响范围**：劳动、合作、师徒、组织归属与长期社会关系。
- **审核结论**：通过。核心变量是“是否仍拥有重新选择权”。

### 2. 公共宣意场
- **分类**：ZN的Z
- **影响力体量**：7
- **定义**：城市设有公开表达个人选择、退出、改志与新承诺的公共空间，个人决定通过公开见证获得社会效力。
- **Z部分**：个人先作出真实选择。
- **ZN部分**：通过公开表达、群体见证与传播让选择进入社会结构。
- **影响范围**：城市空间、仪式、纠纷处理与公共生活。
- **审核结论**：通过。底层是 Z，外层由 ZN 放大并制度化。

### 3. 临时旗团
- **分类**：Z的ZN
- **影响力体量**：6
- **定义**：人们可围绕一个明确短期目标自发结成旗团，任务完成后默认解散、改组或重新选择去向。
- **Z部分**：自主聚散与目标转换。
- **ZN部分**：依靠旗帜、口号、现场号召与情绪感染形成短期共振。
- **影响范围**：救援、运输、节庆、冒险与临时协作组织。
- **审核结论**：通过。Z主导组织生灭，ZN负责快速聚合。

### 4. 身体签名
- **分类**：Z+ZN两者都有
- **影响力体量**：5
- **定义**：服装、发型、纹样与可逆身体改造被视为公开声明“此刻我选择成为什么人”的社会语言。
- **Z部分**：身体归属与自我决定。
- **ZN部分**：身份被外显、传播并被他人识别。
- **影响范围**：服饰、礼仪、身份文化、视觉设计与代际冲突。
- **审核结论**：通过。选择权与表达功能同等重要。

## R1｜制度与日常层增量

### 5. 试誓期
- **分类**：Z
- **影响力体量**：7
- **定义**：加入长期组织、职业团体或伴侣关系前，存在一段明确的试誓期；期满必须再次主动确认，沉默不视作续约。
- **Z部分**：把“持续选择”而非“一次选择”写进制度。
- **ZN部分**：非必要。
- **影响范围**：职业、组织、亲密关系与教育制度。
- **去重/冲突**：与“自决契约”同源但不重复；自决契约规定退出权，试誓期规定进入与续约机制。
- **审核结论**：ACCEPT。

### 6. 领声人
- **分类**：ZN
- **影响力体量**：6
- **定义**：一种专门把分散意见整理成可被群体听见、回应和共同参与的职业；领声人无权替群体决定方向。
- **Z部分**：必须保留每个参与者最终选择权，防止职业滑向代理统治。
- **ZN部分**：核心功能是放大、组织、传递群体表达并形成共振。
- **影响范围**：集会、庆典、灾难动员、公共协商与大型劳动现场。
- **去重/冲突**：与“公共宣意场”互补；前者是职业，后者是空间/制度。
- **审核结论**：ACCEPT。

### 7. 改旗市
- **分类**：Z的ZN
- **影响力体量**：5
- **定义**：定期市集允许个人与小团体现场重绘旗帜、徽记和服装标识，用视觉变化公开宣布新的目标、关系或阶段身份。
- **Z部分**：先发生身份、目标或归属的主动转向。
- **ZN部分**：再通过公开视觉符号让转向被群体识别。
- **影响范围**：市集、手工业、服饰、节庆、青年文化与视觉生产。
- **去重/冲突**：与“身体签名”部分重叠，因此限定为公共市集与群体标识层，不重复个人身体表达。
- **审核结论**：ACCEPT（限域）。

### 8. 回声宴
- **分类**：ZN的Z
- **影响力体量**：4
- **定义**：重大共同事件结束后，人们轮流公开讲述“我接下来要做什么”，旁人只能回应、见证或加入，不能替发言者决定。
- **Z部分**：每个人最终声明自己的下一步方向。
- **ZN部分**：群体情绪与回应帮助个人意志被看见，并可能形成新的同行关系。
- **影响范围**：家庭、街区、临时旗团解散、远行与灾后生活。
- **去重/冲突**：不是公共宣意场的正式法律仪式，而是日常生活仪式。
- **审核结论**：ACCEPT。

### 9. 活结建筑
- **分类**：Z+ZN两者都有
- **影响力体量**：6
- **定义**：红色聚落的重要公共建筑大量使用可拆、可转向、可重新组合的门廊、台阶、旗架与活动平台，使空间能随群体选择快速改变用途，并把变化直接展示出来。
- **Z部分**：空间允许使用者改变行动路径与用途。
- **ZN部分**：空间变化本身成为公开信号，让群体立即看见“这里现在要做什么”。
- **影响范围**：城市形态、广场、市场、组织据点、节庆和临时协作。
- **去重/冲突**：与既有条目无直接重复；首次把 Z+ZN 落到地域/建筑层。
- **审核结论**：ACCEPT。

## 本轮淘汰

### “热血竞技场”
- **结论**：REJECT
- **原因**：竞争、兴奋、观众欢呼本身不能证明 Z 或 ZN；容易退化成泛红色审美。

### “领袖点燃全城意志”
- **结论**：REJECT
- **原因**：只有单向感染时更像中心化控制；若群体不能拒绝、改向或重新组织，会压制 Z。

### “红色燃料会随情绪升温”
- **结论**：REJECT
- **原因**：只是资源的情绪反应，没有自主选择或意志外显的必要结构。

## R1 合并/修订结论

- **自决契约 + 试誓期**：保留为上下位制度关系，不合并。前者管退出/改投，后者管进入/续约。
- **公共宣意场 + 领声人**：保留为“场所制度 + 职业”的配套关系。
- **身体签名 + 改旗市**：限制边界后保留。前者是个人身体语言，后者是公共视觉生产与群体标识。
- **临时旗团 + 回声宴**：不合并；回声宴可作为旗团结束后的生活仪式，但不限于旗团。
- **三色边界检查**：本轮条目均以主体选择/表达为核心；没有把生命奇异性当核心（避免滑入粉），也没有把接口、工业控制与技术系统当核心（避免滑入青）。
