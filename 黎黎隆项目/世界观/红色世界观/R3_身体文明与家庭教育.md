# R3｜红色世界观：身体文明与家庭教育

> 核心：Z + ZN
> 状态：ACCEPTED 增量
> 前置去重：已对照 README 中 R0–R2 的自决契约、公共宣意场、临时旗团、身体签名、试誓期、领声人、改旗市、回声宴、活结建筑、自留份、反声席、拆誓师、双火线。

## A｜新增正式条目

### 14. 留门家
- **分类**：Z
- **影响力体量**：7
- **定义**：红色家庭把“成年后可离家、改姓、换职业、另组家庭，且仍保留回访资格”视为基本亲缘伦理；父母的责任不是替孩子决定道路，而是确保他真的有路可选。
- **判定依据**：核心不是亲情温暖，而是家庭制度是否保留成员改变人生方向的权利。
- **影响范围**：家庭结构、成年礼、继承、迁徙、婚恋与代际冲突。
- **去重/冲突**：与“自决契约”同属 Z，但自决契约处理契约关系；留门家处理无法简单视作契约的血缘关系。
- **审核结论**：ACCEPT。

### 15. 反师日
- **分类**：ZN的Z
- **影响力体量**：6
- **定义**：学徒或学生每阶段必须有一次公开反驳导师、拒绝既定训练路线或提出自定课题的机会；导师只能回应和辩护，不能以“忘恩”取消其资格。
- **判定依据**：先通过公开表达形成 ZN 场，再保护学生真实改变方向的 Z。
- **影响范围**：教育、师徒制、工坊、武艺传承、学术与青年文化。
- **去重/冲突**：不同于“反声席”的公共政治异议；本条限定教育权力关系。
- **审核结论**：ACCEPT。

### 16. 换身节
- **分类**：Z的ZN
- **影响力体量**：5
- **定义**：一年一次，人们可以主动停用旧服装标记、称号、发式或身体装饰，并在街区共同制作新的外观；重点不是狂欢，而是允许身份发生一次被公开承认的改写。
- **判定依据**：Z 是身份转向的起点，ZN 是把新身份公开化并获得群体识别。
- **影响范围**：服饰、节庆、手工业、身体文化、青年亚文化与视觉设计。
- **去重/冲突**：与“身体签名”合并理解为上下位关系；身体签名是日常语法，换身节是周期性集中仪式，因此保留为其大型社会事件层。
- **审核结论**：ACCEPT（与身体签名建立上下位关系）。

### 17. 无主伤疤
- **分类**：Z+ZN两者都有
- **影响力体量**：5
- **定义**：红色社会认为伤疤的意义归伤者本人决定。伤者可以展示、遮盖、装饰、改写故事，也可以拒绝解释；他人不得替伤者把伤疤定义成荣耀、耻辱或忠诚证明。
- **判定依据**：身体解释权属于 Z；展示、遮盖和重新叙述又直接构成 ZN。
- **影响范围**：医疗之后的生活、战争记忆、身体审美、亲密关系、退役者与公共叙事。
- **去重/冲突**：补足“身体签名”未覆盖的非自愿身体变化；前者主要是主动造型，本条处理身体已经被事件改变后谁拥有解释权。
- **审核结论**：ACCEPT。

### 18. 退名权
- **分类**：Z
- **影响力体量**：8
- **定义**：个人有权停止使用家族、组织、职业或荣誉赋予的旧称号，并选择新名字；旧名可作为历史记录存在，但不得被强制作为现实身份继续使用。
- **判定依据**：命名不是装饰，而是“谁有权决定我现在是谁”的主体权问题，因此 Z 为核心。
- **影响范围**：法律身份、家庭、组织、职业、档案、婚恋与政治冲突。
- **去重/冲突**：与“拆誓师”相邻但不重复；拆誓师是协助退出的职业，退名权是普遍制度权利。
- **审核结论**：ACCEPT。

## B｜本轮淘汰

### “红色人从小必须公开演讲”
- **结论**：REJECT
- **原因**：强制表达会把 ZN 变成纪律，并直接损伤 Z；会说话不等于拥有表达自主权。

### “成年必须纹上家族火纹”
- **结论**：REJECT
- **原因**：不可拒绝的永久身体标记与身体主权冲突；红色视觉感很强，但结构上反红。

### “孩子必须继承父母最擅长的职业”
- **结论**：REJECT
- **原因**：把传承变成路径锁定，直接压制 Z。

## C｜合并 / 修订

- **身体签名 → 换身节**：建立“日常身体表达语法 → 周期性身份重写仪式”的上下位关系，不制造两个同义系统。
- **身体签名 + 无主伤疤**：前者处理主动塑造身体；后者处理身体被动改变后的解释权，保留两者。
- **拆誓师 + 退名权**：职业服务与制度权利分离，避免“只有找职业中介才能改变身份”的错误暗示。
- **反声席 + 反师日**：前者是公共异议基础设施，后者是教育关系中的定期反权威机制。
- **三色边界**：本轮不以生物奇异性为核心，避免滑入粉；不依赖接口、算法、工业控制，避免滑入青。

## 本轮结构结论

R3 把红色从“公共制度与群体冲突”推进到私人生活：家庭不能天然拥有成员，老师不能天然拥有学生路线，社会不能天然拥有伤疤解释权，旧身份也不能永久拥有一个人。

因此红色世界的 Z + ZN 可以形成更稳定的一条文明母题：**我有权改变自己，也有权决定这种改变是否、何时、以什么方式被别人看见。**
