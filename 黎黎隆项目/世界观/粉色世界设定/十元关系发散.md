# 《黎黎隆》粉色世界｜十元关系发散

> 视觉锚点：P00 灰紫 `#855D8F`（暗阳粉）。颜色只负责生体/异常/奇异感提示，不直接决定十元。
> 本轮规则：先让元素成立，再判【主十元 + 次十元】；随后把十元关系落成 NZ ↔ X并Z 的具体世界事件。取消“必须属于NZ/X并Z才能通过”的旧筛选。
> 设定等级与影响力体量分开：**S=可成为粉色世界标志性母设定；A=能稳定长出角色/场景/故事；B=优秀局部设定；C=补充性细节。**

## 01｜换路日：今天的异常，是五十年后的老街

祖冠树在雨季暴长，新根会穿屋、封门、抬桥，把居民几十年形成的回家路线、邻里关系和市场动线突然错接。王城不会立刻砍根复原，而是在第一天宣布“换路日”：居民先临场寻找新路径，随后承根匠给新根补上桥板、吊台、阶梯和灯，让原本的空间异常逐渐变成新的正式街道。

- **主十元：Z｜次十元：N**
- **十元证据：** Z负责危机中的即兴转向、先行动再定路线；N负责给已经发生的错接提供可居住、可通行的承载。
- **主动态链：** `NZ稳定生活关系 → X并Z克NZ（空间错接） → Z缓解危机（临场换路） → N补X并Z（承载异常连接） → 新日常形成`
- **NZ具象：** 居民、店铺、邮兽、学校与道路几十年形成的对象特异生活关系。
- **X并Z具象：** 新根把原本不相连的房屋/街区接在一起，把原本相连的生活关系强行拆开。
- **关系判断：** 【X并Z克NZ】+【N补X并Z】。X并Z通过改变空间归属，使“熟悉关系→可正常使用”变成“熟悉关系→失效”；N再把“异常但不可用→异常且可生活”。
- **概念→具象：** 关系错位不是一句哲学话，而是“你家门还在，但门外已经不是你原来的街”；补关系则变成工匠真的在错接根系下搭出新城市。
- **视觉钩子：** 暗阳粉巨根穿过二楼；礼服官员翻藤梯进宫；旧门牌悬在已经没有道路的墙上。
- **设定等级：S**
- **粉色世界观影响力体量：9/10**

## 02｜错季田：一块田同时活在三个季节

王城西郊一次古老魔法事故把三块不同季候农田的“季节归属”错接到同一片土地：左半边结霜，中段开花，右侧已经结果。农民没有把它恢复正常，而是用轮作沟、遮棚兽和迁花蜂把三个季节重新承载起来，最终发展出一年十二次小收成的农业体系。

- **主十元：N｜次十元：ZN**
- **十元证据：** N主导对冲突季候的承载与并置；ZN体现在不同季节留下不同地方性作物、饮食和农户习惯。
- **主动态链：** `NZ土地-季节关系 → X并Z克NZ（季节错接） → N补X并Z（三季并置承载） → ZN沉淀地方差异`
- **NZ具象：** 土地、作物、昆虫、农户原本按当地季节共同生长。
- **X并Z具象：** “春/秋/冬”从各自土地关系中被剥离后错误归到同一田块。
- **关系判断：** 【X并Z克NZ】后【N补X并Z】。原先单一生态节律被破坏，但N没有消灭错接，而是让三套生态同时有位置可待。
- **概念→具象：** 同一幅农田里可以同时画结霜麦穗、灰紫花田和成熟果架，中间不是渐变，而是清楚的季节断层。
- **视觉钩子：** 一步跨过春冬边界；迁花蜂背着暗阳粉花粉囊；农舍挂三套不同季节农具。
- **设定等级：A**
- **粉色世界观影响力体量：6/10**

## 03｜失主门：房子开始把陌生人当成死去的主人

王城老宅的门不认钥匙，只认长期从这里回家的人。主人死后，门仍会在每天傍晚开启一次。有人发现，只要穿死者旧衣、走他的旧路线、使用他的杯子足够久，门会逐渐把“身份痕迹”错认成“那个人本人”。因此王城出现了专门调查住宅是否被身份壳欺骗的“归门师”。

- **主十元：XN｜次十元：NZ**
- **十元证据：** XN主导“门依据何种规则确认你是谁”；NZ是门与居住者多年共同生活形成的对象特异关系。
- **主动态链：** `NZ对象关系 → X并Z克NZ（身份壳替位） → XN重新校验归属规则 → NZ关系被重新确认`
- **NZ具象：** 门记住具体人的脚步、气味、回家时间和共同生活史。
- **X并Z具象：** 衣物、路线、杯子等外部身份壳取代本人，承接原本属于人的关系。
- **关系判断：** 【X并Z克NZ】。变量从“认识具体对象”变成“识别一组可复制痕迹”；XN通过增加对象校验规则缓解这种替位。
- **概念→具象：** 一扇门真的会给陌生人开门，而屋内所有家具却对他保持陌生。
- **视觉钩子：** 暗阳粉门缝主动亮起；陌生人穿旧主人外套；归门师让屋内植物、门和餐具分别认人。
- **设定等级：S**
- **粉色世界观影响力体量：5/10**

## 04｜借腿巡林人：把沼泽兽的一段“走法”借到自己身上

巡林人要穿过吞人的软沼时，会向长脚兽借一段步态。借来的不是实体腿，而是“身体怎样在这种泥里移动”的能力，使用时人的膝盖、重心和脚趾会短暂改变。老练巡林人会在任务结束后把步态完整还回去；黑市则试图永久截留这种能力。

- **主十元：ZX｜次十元：X并Z**
- **十元证据：** ZX主导明确目标下的主动突破；X并Z是把依附完整生命的行动能力抽离并临时接给另一身体。
- **主动态链：** `NZ兽-沼泽完整能力 → X并Z剥离/转接 → ZX利用错接完成突破 → 归还后NZ恢复`
- **NZ具象：** 长脚兽的步态来自身体、族群学习和沼泽生态共同形成。
- **X并Z具象：** “走法”脱离原身体成为可暂时移接的能力段。
- **关系判断：** 【X并Z克NZ】是潜在风险，但受限时可被ZX短时利用；永久截留会使原兽失去部分对象特异行动能力。
- **概念→具象：** 人的膝盖在暗阳粉纹路亮起后改变弯折方向，用明显“不属于人”的步态跨沼。
- **视觉钩子：** 人兽同步抬腿；膝部灰紫生体纹；归还时步态像影子一样从人脚下走回兽群。
- **设定等级：A**
- **粉色世界观影响力体量：4/10**

## 05｜空名军：战争不杀守军，先让城墙忘记守军是谁

边境战争中有一种旧术，会把敌军徽记、口令、脚步和气味的“归属”接到一批无主甲壳上。城墙上的活体防御仍然完整，却开始把真正守军当入侵者，把空甲壳当主人。守城方只能临时放弃制服和既有通行方式，用现场约定的新动作重新组织防线。

- **主十元：ZX｜次十元：Z**
- **十元证据：** ZX是围绕明确攻防目标争夺城防；Z是守军在身份系统失效后迅速改动作、改路线、改协作方式。
- **主动态链：** `NZ守军-城墙长期识别 → X并Z克NZ（身份归属错接） → Z危机转向 → ZX重建可行动防线`
- **NZ具象：** 活城墙通过多年共同驻守认识具体守军。
- **X并Z具象：** 守军身份痕迹被剥离后接到无主甲壳，关系被错误承载。
- **关系判断：** 【X并Z克NZ】；Z缓解的变量是“既有身份无法行动→通过临时新规则重新行动”。
- **概念→具象：** 城墙完好、士兵完好，战争却因为“城墙认错人”突然翻面。
- **视觉钩子：** 暗阳粉城墙眼纹对守军张开；空甲列队却被城门欢迎；士兵扔掉制服后用手势重新结阵。
- **设定等级：S**
- **粉色世界观影响力体量：8/10**

## 06｜回声学院：学生毕业时必须把学会的魔法重新“长回自己身上”

粉色世界最古老的魔法学院允许学生暂借老师、魔兽或植物的能力来学习，但借来的能力只能算“回声”。毕业考试不是展示威力，而是切断所有借用接口，要求学生根据自己的身体、性格、生活地和关系重新长出一个不完全相同的版本。复制得越像老师，反而越可能不及格。

- **主十元：ZN｜次十元：NZ**
- **十元证据：** ZN强调能力最终必须形成个体自身的独特形态；NZ要求能力重新嵌回完整生命与生活关系。
- **主动态链：** `X并Z临时抽离能力 → 学习期可用 → ZN拒绝纯复制 → NZ重新内生 → 新个人魔法成立`
- **NZ具象：** 魔法最终必须依赖学生自己的身体、地方、伙伴与长期经验。
- **X并Z具象：** 教学阶段允许把他者能力暂时抽成“回声”接入学生。
- **关系判断：** 【X并Z→NZ转生】。变量从“外来的可调用能力”变成“由自身生命关系重新长出的能力”。
- **概念→具象：** 同一老师教出的十名学生，毕业时魔法外观、动作甚至功能都会分叉。
- **视觉钩子：** 暗阳粉回声法术像薄膜包在手臂外；毕业仪式上薄膜碎裂；每个学生身体里长出不同形态的新法术。
- **设定等级：S**
- **粉色世界观影响力体量：8/10**

## 07｜共餐兽：宴席只有在“这群人真的互相认识”时才会熟

王城大型宴会不用火灶，而把食材放在一种温顺的共餐兽背部。它会根据围桌人的关系升温：真正熟悉、愿意共同承担食物的人越多，菜越快成熟；临时冒名、被强行塞进关系的人会让某一区域始终生冷。因此贵族曾试图用身份花签骗过共餐兽，却发现它认的是长期共同生活而不是名字。

- **主十元：NZ｜次十元：N**
- **十元证据：** NZ直接以真实共同关系决定烹饪；N体现一桌人和一只生物共同承载宴席的结构。
- **主动态链：** `NZ真实关系 → X并Z尝试身份替位 → NZ反穿X并Z（生体不认身份壳） → N维持共同承载`
- **NZ具象：** 共餐兽长期感知具体人的共同生活、照料与共享行为。
- **X并Z具象：** 花签、假名和身份壳试图替代真实关系。
- **关系判断：** 【NZ反穿/抵抗X并Z】。身份替位成功改变社会称谓，却无法改变共餐兽对真实对象关系的生体判断。
- **概念→具象：** 一桌豪华宴席中，冒名者面前那块肉永远是冷的。
- **视觉钩子：** 巨兽背上铺长桌；暗阳粉热纹沿真正亲友之间连接；假身份者面前热纹断开。
- **设定等级：A**
- **粉色世界观影响力体量：5/10**

## 08｜无旗镇：镇民故意不让任何建筑拥有永久用途

王城与驮城之间有一座贸易镇，历史上多次被不同势力通过“改名、换旗、改机构归属”接管。后来镇民干脆形成传统：学校晚上可以变旅馆，神殿雨季变粮仓，议事厅每月换一次位置。外来的归属术很难控制它，因为没有稳定的“建筑身份壳”可供替换。

- **主十元：Z｜次十元：XN**
- **十元证据：** Z是主动变化用途、避免被固定；XN是镇民有意识设计“用途规则不绑定建筑身份”的制度。
- **主动态链：** `X并Z通过身份壳控制地方 → Z持续变换功能 → XN制定非固定归属规则 → NZ地方共同生活保留下来`
- **NZ具象：** 镇民、市场、照料关系与地方生活仍连续存在。
- **X并Z具象：** 外部势力试图用旗帜、机构名和建筑用途替换原有地方归属。
- **关系判断：** 【Z缓解X并Z克NZ】+【XN限制X并Z接口】。变量从“身份壳一换，地方关系随之被接管”变成“身份壳无法稳定锁定真实功能”。
- **概念→具象：** 同一座暗阳粉穹顶建筑，上午孩子上课，晚上商队睡觉，雨季里面堆满粮袋。
- **视觉钩子：** 建筑门牌每天翻面；旗杆永远空着；居民推着可移动祭台穿街。
- **设定等级：A**
- **粉色世界观影响力体量：6/10**

## 09｜遗蜕园：被剥下来的器官没有死，反而彼此长成了新的生态

古代巨型生命死亡后，部分器官、骨膜和神经被后人切离使用。某处废弃采集场里，大量失去原主的遗蜕在数百年间彼此接触、寄生、供养，最终形成一座没有“完整原生个体”却拥有完整食物链的新园林。当地人不再把它叫废料场，而认为它已经是另一种生命共同体。

- **主十元：X并Z｜次十元：NZ**
- **十元证据：** 起点是典型剥离与异质拼接；长期结果却形成自洽生态、繁衍关系与地方生活。
- **主动态链：** `X并Z剥离原生命 → 大量遗蜕并置 → 相互依赖 → NZ重新长成`
- **NZ具象：** 遗蜕之间已经形成长期供养、繁衍、捕食、庇护和地方季节关系。
- **X并Z具象：** 所有初始组成物都曾从完整巨型生命中被剥下，且来源彼此不同。
- **关系判断：** 【X并Z→NZ转生】。变量从“脱离主体的残余部件”变成“能够自行维持关系网络的新生态主体”。
- **概念→具象：** 一块古老肺膜成为林冠，一束神经变成藤蔓，骨腔里有新的小型族群筑巢。
- **视觉钩子：** 暗阳粉半透明肺膜遮天；神经藤在风里发光；骨骼水池里生活着新生小兽。
- **设定等级：S**
- **粉色世界观影响力体量：8/10**

## 10｜“第二故乡”病：归枝没有坏，它只是同时认了两个家

长期跨地区生活的人偶尔会发现自己的归枝开始同时指向两个方向。过去王城把这视为导航异常，后来才发现并非所有情况都是错接：旅人可能真的在第二座城建立了足够深的生活关系。真正危险的是有人把另一座城的“故乡痕迹”强行接给旅人，使归枝在没有真实生活史的情况下产生假方向。因此守路人必须区分“新关系自然长成”和“身份归属被强行替换”。

- **主十元：NZ｜次十元：XN**
- **十元证据：** NZ主导多地真实关系自然生长；XN负责判断两个方向背后的归属规则究竟是真关系还是伪接口。
- **主动态链：** `NZ原故乡关系 → 新NZ关系自然生长 / X并Z伪造归属 → XN辨别机制 → 保留真双归属、切断假错接`
- **NZ具象：** 两座城市都可能通过多年生活成为真实故乡，不要求关系只能唯一。
- **X并Z具象：** 外部把“故乡痕迹”剥离后接给没有生活史的人，制造假归属。
- **关系判断：** 【NZ与X并Z需要辨析而非二选一】。同样是“两条归路”，变量来源不同：真实长期关系增长属于NZ；无生活史却出现归属指向属于X并Z错接。
- **概念→具象：** 一根归枝自然分成两根健康枝条，与一根被缝上去、接口处泛暗阳粉薄膜的假枝形成视觉对照。
- **视觉钩子：** 双向生长的归枝；守路人把两座城的土放在旅人脚边；假归枝接口像愈合失败的皮膜。
- **设定等级：S**
- **粉色世界观影响力体量：7/10**

# 第三轮｜力量体系、司法、资源与节庆

> 本轮新增约束：粉色世界的力量底盘进一步明确为“**力量是关系长出来的功能**”。工作名暂记为【生契】。它不是额外第十一种十元，而是NZ在粉色世界力量体系中的主要具象机制；X并Z负责剥离/错接已长成的能力，Z可在危机中改道，N可为异常能力提供新承载。该机制只作为世界设定，不替代逐条十元判定。

## 11｜生契：魔法不是学会的，是你和世界相处久了以后长出来的

粉色世界最传统的力量不储存在“魔力池”里。一个人、一个地方、一种伴生物或一个家族长期共同生活后，关系本身会逐渐产生可观察的功能：渡河家族能在水中感知亲属位置；照料火兽数代的人身体逐渐耐热；守同一片林地几十年的巡林人能听见树根传来的方向。能力越脱离原身体、地方和关系，通常越弱。

- **主十元：NZ｜次十元：ZN**
- **十元证据：** 能力由具体生命、地方、时间与共同生活共同长成，且最终形成对象特异的个人/家族差异。
- **主动态链：** `长期共同生活 → NZ关系增厚 → 功能从关系内部生长 → ZN形成个体化能力`
- **NZ具象：** 身体、伴生物、地方、生活史缺一不可，力量不是可随意拆卸的独立技能。
- **X并Z具象：** 此条本身X并Z弱；它主要提供后续“离契/错契”可被剥离的完整对象。
- **关系判断：** 【暂无线性冲突】；本条先定义NZ力量的正常态。
- **概念→具象：** 魔法纹不是施法时凭空亮起，而是像老茧、树纹、共生器官一样随着多年关系逐渐长在身体和环境上。
- **视觉钩子：** 暗阳粉纹路从人的手臂延伸到伴生兽；河边家族皮肤出现水脉纹；老巡林人的脚边根须会主动偏向回家方向。
- **设定等级：S**
- **粉色世界观影响力体量：10/10**

## 12｜离契猎人：他们不杀魔兽，而是偷走魔兽和世界之间的一项能力

边境出现一种危险职业，专门从活体生契中剥离“功能段”。猎人可以不伤害一只悬崖兽的身体，却把它“知道哪里能落脚”的能力抽走，装进自己的靴底；兽仍活着，却开始在自己生活了一生的山壁上失足。王城因此把未经允许的离契视为比普通偷窃更严重的罪。

- **主十元：X并Z｜次十元：ZX**
- **十元证据：** 核心行为是把属于完整生命-环境关系的功能剥离后接给另一主体；ZX体现猎人以明确目标主动夺取能力。
- **主动态链：** `NZ兽-山壁关系 → X并Z剥离能力 → 原主体关系功能下降 / 新主体获得外来功能 → ZX利用`
- **NZ具象：** 悬崖兽的落脚能力来自身体、山壁和长期行动史共同形成。
- **X并Z具象：** “落脚判断”被从原关系中抽出，改由靴子承担。
- **关系判断：** 【X并Z克NZ】。变量从“完整关系可正常产出功能”变成“关系仍在但功能被抽空”；外壳得到能力，原生命失去能力对应的现实结果。
- **概念→具象：** 一只没有受伤的兽突然不会走自己的山，而猎人的靴底长出暗阳粉的陌生趾垫。
- **视觉钩子：** 兽在熟悉岩壁上犹豫；猎靴踩出非人足迹；剥离瞬间能力像薄膜从兽脚与岩面之间被揭下。
- **设定等级：S**
- **粉色世界观影响力体量：8/10**

## 13｜归契庭：司法不先问“谁拥有力量”，而先问“这项力量从哪段关系长出来”

王城处理能力争议时，由“归契庭”同时召来人、伴生物、原地点和相关器物。法官不是看契约纸，而是让能力在不同对象面前显形：若一段力量只在某片河岸、某只伴生兽或某家人的声音出现时恢复完整，就说明它仍与原生关系相连。法院可以判令归还被剥离的能力，也可以承认某些经过多年共同生活后已经形成的新生契。

- **主十元：XN｜次十元：NZ**
- **十元证据：** XN负责建立“能力归属如何被验证”的规则；NZ提供归属判断的真实关系证据。
- **主动态链：** `能力归属争议 → XN拆分证据 → NZ关系现场显形 → 区分原生/新生/伪造归属 → 判决`
- **NZ具象：** 能力会对真正共同生活过的对象、地方和生命产生特异反应。
- **X并Z具象：** 离契、假身份壳、能力移接都可能制造“表面使用者=所有者”的错觉。
- **关系判断：** 【XN限制X并Z】。变量从“谁当前能用谁就像主人”变成“必须追溯能力的关系来源与后续真实生长史”。
- **概念→具象：** 法庭中央不是证人席，而是一块活地：河水、土、兽、旧器物一起被带进来让力量自己认亲。
- **视觉钩子：** 暗阳粉能力纹只在原河水触碰时完整闭合；法官身后挂着多层关系谱；被盗能力朝原伴生兽方向拉出细丝。
- **设定等级：S**
- **粉色世界观影响力体量：8/10**

## 14｜承契器：粉色世界的装备不是增强器，而是给“装错地方的力量”一个能活下来的身体

当某种能力因灾难、救援或合法移接暂时离开原主体时，承契师会制作活体容器。它们通常由骨白结构、暗阳粉生体膜和使用者自身材料共同长成，不负责增加威力，只负责让外来能力不把新宿主撕裂。长期使用后，容器甚至会和新宿主共同变化，最后可能不再需要原来的外壳。

- **主十元：N｜次十元：X并Z**
- **十元证据：** N核心是给已经发生的异质能力错位提供现实承载；X并Z是能力不在原本所属身体中的状态。
- **主动态链：** `能力被迫离契/错接 → 新宿主不相容 → N补X并Z（承契器提供承载） → 长期共同生活 → 可能形成新NZ`
- **NZ具象：** 长期使用后容器、宿主、能力之间可能真正长出新的稳定关系。
- **X并Z具象：** 能力最初属于别的身体/关系，却被接到当前宿主。
- **关系判断：** 【N补X并Z】并可能【X并Z→NZ转生】。变量从“外来能力不可承受”变成“异常能力有位置可待”，再可能变成“新关系可自我维持”。
- **概念→具象：** 装备不是金属法杖加宝石，而像一块专门为陌生能力搭出的临时器官。
- **视觉钩子：** 暗阳粉半透明膜包住手臂外来火焰；承契器随使用者呼吸；旧容器最后像蜕皮一样脱落。
- **设定等级：S**
- **粉色世界观影响力体量：9/10**

## 15｜断契刑：最重的刑罚之一不是关押，而是禁止一个人继续使用被证明为掠夺所得的关系

归契庭确认某项力量来自强行离契后，可以执行“断契刑”：不是消灭能力，而是让被告与被盗能力之间的错误接口失效。执行过程必须同时保护原关系残余，否则粗暴切断会让能力两边都死亡。因此断契师往往需要数月让原主体、地点或后代逐渐重新接回功能。

- **主十元：NX｜次十元：XN**
- **十元证据：** NX体现在切断既成错误连接、把行动权从掠夺接口中撤回；XN负责司法边界和验证程序。
- **主动态链：** `X并Z非法错接 → XN确认来源 → NX切断错误接口 → NZ原关系逐步回收功能`
- **NZ具象：** 原主体和地方仍保留部分关系残余，可作为恢复能力的根。
- **X并Z具象：** 被盗功能由错误宿主持续承载，形成事实占有。
- **关系判断：** 【NX克X并Z】。机制不是摧毁异常物，而是撤销错误连接的继续权；变量从“错接稳定可用”变成“错接无法继续维持”。
- **概念→具象：** 刑场没有斩首台，只有两端活体关系被缓慢分开，暗阳粉接口像缝线一样一根根松开。
- **视觉钩子：** 能力丝从罪犯手臂退回旧树；断契师用多层软夹固定接口；原主体第一次重新做出失去多年的动作。
- **设定等级：A**
- **粉色世界观影响力体量：7/10**

## 16｜无契矿：越急着把它挖出来，它越快失去价值

北方有一种灰紫矿物并不天然储存魔力。矿脉只有与周围菌群、地下水、根系和采矿村共同维持多年后，才会产生能稳定魔法的“缓冲性”。整块暴力切走后，矿石数周内就退化成普通石头。因此当地采矿不是把矿搬走，而是让建筑、工具和运输兽逐渐与矿脉建立小型关系后再分离少量成熟矿片。

- **主十元：X｜次十元：NZ**
- **十元证据：** X体现矿物作为明确、独立、可辨识的物质单元；但其有价值功能并非单体自足，而来自NZ关系网络。
- **主动态链：** `X矿体存在 → NZ生态/村落长期关系赋予功能 → 暴力X并Z剥离则功能衰减 → 温和分离保留关系痕迹`
- **NZ具象：** 菌、水、根、矿工生活和矿体共同产生缓冲功能。
- **X并Z具象：** 工业式切离试图把“有功能的矿”当成与原关系无关的独立商品。
- **关系判断：** 【NZ限制X并Z剥离收益】。剥离越彻底，原关系痕迹越少，矿物功能越弱；这不是道德惩罚，而是力量机制本身。
- **概念→具象：** 真正值钱的矿场看起来反而不像矿坑，而像地下村庄与菌林共同包围的一条活矿脉。
- **视觉钩子：** 暗阳粉矿脉旁长菌灯；矿工住宅直接贴着岩壁生长；被暴切的矿片在运输车上迅速褪灰。
- **设定等级：S**
- **粉色世界观影响力体量：8/10**

## 17｜百家灯节：王城最大的节庆不是点同一种灯，而是让每家的关系长成不同的光

每年一次，居民会把过去一年最重要的一段关系带到祖冠树附近：有人带伴生兽，有人带一盆故乡土，有人带共同修过的旧器物。祖冠树不会统一赐福，而让这些关系短暂显形成不同形状的光。王城因此没有两盏完全相同的节灯；复制别人灯形被认为毫无意义，因为没有对应关系就只能得到空壳。

- **主十元：ZN｜次十元：NZ**
- **十元证据：** ZN强调每段关系最终显形成独特样式；NZ是显形能力的真实来源。
- **主动态链：** `NZ一年生活关系积累 → 节庆集中显形 → ZN生成不可复制的个体光形 → 城市共同观看`
- **NZ具象：** 光形必须由真实共同经历、对象和生活史触发。
- **X并Z具象：** 弱；市场上存在复制灯壳，但没有原关系只能亮出僵硬外形。
- **关系判断：** 【NZ生ZN】。变量从“关系不可直接看见”变成“关系产生对象特异的视觉形式”；X并Z复制外壳无法复制关系生成机制。
- **概念→具象：** 大型节庆的视觉奇观来自十万种不同关系显形，而不是十万盏同款粉灯。
- **视觉钩子：** 暗阳粉只是共同底色，不同家庭灯形像兽、枝、河纹各异；祖冠树下整城光形互不重复；假灯整齐漂亮却僵直无变化。
- **设定等级：S**

## 18｜留伤墙：边境防御会故意保留上一次被攻破的位置

粉色边境城墙不是每次受损都恢复原样。守城者会让破口周围的活墙组织与那次攻击留下的材料共同愈合，使城墙“记住”敌人的穿透方式。下一次相似攻击到来时，旧伤区域会提前收缩、转硬或改变通道。不同边境城因此长着完全不同的伤痕和防御反应。

- **主十元：XZ｜次十元：NZ**
- **十元证据：** XZ体现对既成压力的高反应性与反制；NZ让防御反应来自城墙、守军、旧伤和地方战争史长期共同形成。
- **主动态链：** `外来攻击造成破口 → NZ保留攻击关系痕迹 → XZ针对同类压力形成反应 → 新防御能力长成`
- **NZ具象：** 防御不是预装模块，而由具体城市遭遇过的敌人与守军修复史共同形成。
- **X并Z具象：** 敌军若试图把另一座城的“伤口记忆”移植过来，会出现不匹配的错误防御反应。
- **关系判断：** 【NZ生XZ】；真实经历使城墙获得针对性反应。X并Z移植只能复制伤痕外壳，无法完整复制当地攻击-修复关系。
- **概念→具象：** 城墙最强的地方不是最光滑的新墙，而是那些暗阳粉旧伤像肌肉一样会提前绷紧的位置。
- **视觉钩子：** 城墙布满不同年代的灰紫缝合疤；箭雨来临前旧伤自行闭合；假移植伤口朝错误方向硬化。

## 19｜换声议会：非人种族的代表权不是“一个种族一个席位”，而是谁真正维持了那段共同生活

王城议会曾按种族固定席位，后来发现这会让某些早已离开原生态的贵族仍替整个族群发言。现在部分席位采用“换声制”：河栖族议题可能由一名人类摆渡人、一只老河兽和河栖族母亲共同发言，因为三者都实际维持着那条河的生活关系。席位会随关系变化而更替，而不是永久绑定血统外壳。

- **主十元：XN｜次十元：N**
- **十元证据：** XN重写政治代表规则；N强调多个不同主体共同承载同一公共对象。

- **NZ具象：** 谁长期照料河、与族群共同生活、承担实际后果，谁就拥有关系证据。
- **X并Z具象：** 固定族名、贵族头衔可能成为替代真实关系的身份壳。
- **关系判断：** 【XN限制X并Z】并【N补政治承载】。变量从“身份标签自动获得代表权”变成“代表权必须持续由真实关系和共同承担支撑”。
- **概念→具象：** 议会席位不是一把椅子，而是一组可拼合座台，不同生命围绕同一条活水渠发言。
- **视觉钩子：** 河水穿过议会中央；人、兽、非人代表坐在同一组合席；暗阳粉席纹随真实发言关系亮起。

## 20｜返生战场：战争结束后，胜负并不决定这片土地最后属于谁

粉色世界一些古战场会在战后几十年里重新“选择关系”。双方遗留的盔甲、尸骨、营地植物、当地水系和返乡居民彼此影响，最后可能形成与任何一方战时旗帜都不同的新地方生态。王城法律因此承认：占领只能改变短期控制，不能自动证明土地已经与新统治者形成生契。

- **主十元：NZ｜次十元：NX**
- **十元证据：** NZ主导战后土地与真实生活重新形成关系；NX体现在战争结束后对旧控制链条的撤销与退出。
- **主动态链：** `战争强制占领/错接归属 → NX终止持续控制 → 土地与留下的生命重新共同生活 → NZ生成新地方关系`
- **NZ具象：** 谁真正留下、耕作、照料水源、与战场新生态共同生活，关系才逐渐形成。
- **X并Z具象：** 战时旗帜、占领文书、移植地标可以强行给土地套上新的归属外壳。

- **概念→具象：** 战争遗物没有被清空，而是长进新村落和生态里，几十年后形成既不属于旧敌也不复制旧王城的第三种地方。
- **视觉钩子：** 暗阳粉藤从两军盔甲共同长出；旧旗杆成为新水井支架；孩子在双方废弃盾牌围成的菜园里玩耍。
