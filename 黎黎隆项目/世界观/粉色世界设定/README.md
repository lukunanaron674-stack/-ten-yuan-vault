# 《黎黎隆》粉色世界设定

> 状态：持续增量发散  
> 视觉锚点：P00 灰紫 `#855D8F`（用户称“暗阳粉”），不是纯粉。  
> 十元底盘：**NZ 主，X并Z 次**。  
> 规则：这里是完整奇幻世界，不是单一“粉色生态区”；王城、城镇、种族、魔法、生活、组织、职业、交通、信仰、资源与遗迹都必须能独立成立。X并Z作为剥离、错接、嵌合、身份/关系接口错置等异常渗入，不默认等同邪恶或工业技术。

## 分类口径

- **【NZ】**：核心依赖完整生命、长期关系、地方生态、共同生活与可回返关系自然长成。
- **【X并Z】**：核心是剥离、错接、替位、嵌合或稳定身份壳/归因接口改变原本关系。
- **【X并Z的NZ】**：先发生X并Z改变，之后长出新的NZ生命、生态或传统。
- **【NZ的X并Z】**：整体仍是NZ世界，但内部局部出现X并Z式剥离、错接或嵌合。
- **【两者都有】**：两种机制同时强且无法明确主从时才使用。

### 影响力体量

`1–3` 个人/器物/局部习俗；`4–6` 组织/街区/城镇/区域；`7–8` 王城或广域文明结构；`9–10` 改变整个粉色世界的时代结构或跨区域秩序。

## 第一轮｜王城与生活骨架

### 01｜王城不是建在土地上，而是围着“祖冠树”一圈圈长出来

王城中心是一株比城史更老的巨大冠木。最初的居民在树根空腔中生活，后来桥、市场、神殿、住宅和城墙顺着每一代新根向外扩张；旧根死去后不会拆掉，而会成为地下街、墓园和蓄水道。因此王城地图每隔几十年都会自然改变，老居民认路靠“哪一代根”，而不是门牌。

- **判定：【NZ】**
- **判定依据：** 城市结构由生命成长、世代居住和地方生态共同长成，没有先发生剥离或错接。
- **粉色世界观影响力体量：8/10**
- **视觉钩子：** 暗阳粉树冠压在王城上空；骨白石屋嵌进巨根；夜间根脉透出低饱和灰紫微光。
- **抽象规则：** 粉色王城的“建筑史”可以直接等于某种生命的“生长史”。

### 02｜王城每年会举行一次“借名节”，人们把自己的名字暂时借给陌生人

节日期间，居民把写有真名的花签交给另一个人，一天内以对方名字生活、赴约、买东西、参加宴席。原本只是确认“即使名字换了，熟悉的人仍能认出你”的古老关系仪式；但部分旧花签长期保存后，会继续替原主人承接邀请、债务甚至婚约，形成专门处理“名字留下了，人却已经走了”的法庭。

- **判定：【NZ的X并Z】**
- **判定依据：** 节日本体是NZ的关系确认与共同生活传统，但真名花签形成稳定替位接口后，会把关系证据错误归给身份壳，出现X并Z式污染。
- **粉色世界观影响力体量：7/10**
- **视觉钩子：** 满街悬挂暗阳粉花签；陌生人佩戴别人的名字；王城旧法院堆满多年未归还的姓名牌。
- **抽象规则：** X并Z不必来自机器，传统仪式本身也可能制造稳定的身份错位。

### 03｜“花背邮兽”只会把信送到它真正认识的人那里

粉色世界没有完全依赖地址的邮路。花背邮兽从幼年起与一个街区共同生活，会记住居民气味、脚步、家门植物和亲属关系。即使收件人搬家，它也会沿熟人关系一路追过去；因此最重要的信件反而写得很少，邮兽认识谁比信封写什么更重要。

- **判定：【NZ】**
- **判定依据：** 功能来自动物与社区长期共同生活形成的对象特异关系，而非可抽离的通用能力。
- **粉色世界观影响力体量：5/10**
- **视觉钩子：** 背部长着灰紫花冠的小兽；屋檐间的藤桥邮路；信袋上不是地址而是家族植物枝叶。
- **抽象规则：** 粉色世界的基础设施可以依赖“认识”而不是依赖坐标。

### 04｜“离枝街”出售从原生魔法中剥下来的短命能力

王城边缘有一条合法但名声微妙的旧街。匠人能把某些生命能力从完整主体上短暂剥离，例如从会夜视的兽眼中取出“一夜的暗视”、从鸣花中取出“一首歌的回声”。这些能力装在暗阳粉半透明囊膜里，只能维持几小时，而且使用者会沾上一点原主人的习性。它不是工业产品，每件都带着原生命的差异。

- **判定：【X并Z】**
- **判定依据：** 核心动作就是把原本依附完整生命的性质剥离并临时接给另一主体，X并Z占主导。
- **粉色世界观影响力体量：5/10**
- **视觉钩子：** 肉质半透明能力囊；旧木摊位上悬着会自行收缩的灰紫薄膜；买下夜视的人瞳孔短暂变成兽形。
- **抽象规则：** 传统X并Z可以是手工、短命、不可标准化的奇幻技艺，不必赛博化。

### 05｜被错接的“雨鳃”后来繁衍成了一个真正的新族群

很久以前，山地居民为了熬过连续洪灾，把河兽的呼吸组织嫁接给人。最初只是应急异术，但部分后代天生长出颈侧雨鳃，并逐渐形成自己的婚俗、歌声、饮食和河岸聚落。如今他们已经不是“接受改造的人”，而是拥有完整生活史的新族群，甚至反对别人继续复制最初的嫁接术。

- **判定：【X并Z的NZ】**
- **判定依据：** 起点是跨主体错接，但长期繁衍后形成自洽生命、族群关系与生活生态，结果转为NZ。
- **粉色世界观影响力体量：7/10**
- **视觉钩子：** 颈侧暗阳粉鳃瓣；河岸层层垂落的湿布住宅；雨天全族在露天广场合唱。
- **抽象规则：** X并Z造成的异常经过足够长时间，可以重新长成新的NZ，而不是永远保持“异常物”。

### 06｜王城“暮光市”每天只在太阳落入城墙缺口后的四十分钟存在

一段古城墙与祖冠树枝叶恰好形成固定暮光带，只有这四十分钟，一批依赖低温花粉醒来的商贩、食材和小型生物才会活动。居民不是去一个固定建筑买东西，而是等光、风、花粉与生物同时到位后，市场自己出现。错过时间，摊位上的活物会重新闭合，第二天再见。

- **判定：【NZ】**
- **判定依据：** 市场功能由地方空间、时间、植物、生物与居民习惯长期耦合产生，是完整关系网络。
- **粉色世界观影响力体量：4/10**
- **视觉钩子：** 暗阳粉斜光切过旧城墙；花瓣摊位在四十分钟内同时张开；太阳落下后整条街迅速闭合。
- **抽象规则：** 粉色世界的商业与公共生活也可以被生态时间直接塑形。

## 本轮审核

- **通过新增：6 条**。
- **合并/淘汰：2 条候选未入库。**
  - 淘汰“季节盒”：与既有“切走一段季节保存”的机制高度接近，仅换载体。
  - 淘汰“伴生兽遗留法术”：与既有“伴生兽在主人死亡后保留部分魔法并转接”的机制高度接近。
- **冲突检查：** 未把 `#855D8F` 锁死为单一剧情含义；仍遵守P00“主色需与物体、空间、动作共同判断”的原则。
- **关系边界：** “借名节”明确要求长期保存的花签成为稳定替位接口后才进入X并Z，不把一次换名或普通误会误判为X并Z。

## 下一轮优先缺口

优先补：**王城权力结构 / 粉色世界信仰 / 远离王城的城镇与荒野 / 非人种族 / 交通与旅行风险**。避免连续只长“植物生态”，否则又会把一个世界种成大型花店。
