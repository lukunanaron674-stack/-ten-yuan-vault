# 《黎黎隆》粉色世界设定

> 状态：持续增量发散  
> 视觉锚点：P00 灰紫 `#855D8F`（用户称“暗阳粉”），不是纯粉。  
> 十元底盘：**NZ 主，X并Z 次**。  
> 规则：这里是完整奇幻世界，不是单一“粉色生态区”；王城、城镇、种族、魔法、生活、组织、职业、交通、信仰、资源与遗迹都必须能独立成立。X并Z作为剥离、错接、嵌合、身份/关系接口错置等异常渗入，不默认等同邪恶或工业技术。

## 分类口径

- **【NZ】**：核心依赖完整生命、长期关系、地方生态、共同生活与可回返关系自然长成。
- **【X并Z】**：核心是剥离、错接、替位、嵌合或稳定身份壳/归因接口改变原本关系。
- **【X并Z的NZ】**：先发生X并Z改变，之后长出新的NZ生命、生态或传统。
- **【NZ的X并Z】**：整体仍是NZ世界，但内部局部出现X并Z式剥离、错接或嵌合。
- **【两者都有】**：两种机制同时强且无法明确主从时才使用。

### 影响力体量

`1–3` 个人/器物/局部习俗；`4–6` 组织/街区/城镇/区域；`7–8` 王城或广域文明结构；`9–10` 改变整个粉色世界的时代结构或跨区域秩序。

## 第一轮｜王城与生活骨架

### 01｜王城不是建在土地上，而是围着“祖冠树”一圈圈长出来

王城中心是一株比城史更老的巨大冠木。最初的居民在树根空腔中生活，后来桥、市场、神殿、住宅和城墙顺着每一代新根向外扩张；旧根死去后不会拆掉，而会成为地下街、墓园和蓄水道。因此王城地图每隔几十年都会自然改变，老居民认路靠“哪一代根”，而不是门牌。

- **判定：【NZ】**
- **判定依据：** 城市结构由生命成长、世代居住和地方生态共同长成，没有先发生剥离或错接。
- **粉色世界观影响力体量：8/10**
- **视觉钩子：** 暗阳粉树冠压在王城上空；骨白石屋嵌进巨根；夜间根脉透出低饱和灰紫微光。
- **抽象规则：** 粉色王城的“建筑史”可以直接等于某种生命的“生长史”。

### 02｜王城每年会举行一次“借名节”，人们把自己的名字暂时借给陌生人

节日期间，居民把写有真名的花签交给另一个人，一天内以对方名字生活、赴约、买东西、参加宴席。原本只是确认“即使名字换了，熟悉的人仍能认出你”的古老关系仪式；但部分旧花签长期保存后，会继续替原主人承接邀请、债务甚至婚约，形成专门处理“名字留下了，人却已经走了”的法庭。

- **判定：【NZ的X并Z】**
- **判定依据：** 节日本体是NZ的关系确认与共同生活传统，但真名花签形成稳定替位接口后，会把关系证据错误归给身份壳，出现X并Z式污染。
- **粉色世界观影响力体量：7/10**
- **视觉钩子：** 满街悬挂暗阳粉花签；陌生人佩戴别人的名字；王城旧法院堆满多年未归还的姓名牌。
- **抽象规则：** X并Z不必来自机器，传统仪式本身也可能制造稳定的身份错位。

### 03｜“花背邮兽”只会把信送到它真正认识的人那里

粉色世界没有完全依赖地址的邮路。花背邮兽从幼年起与一个街区共同生活，会记住居民气味、脚步、家门植物和亲属关系。即使收件人搬家，它也会沿熟人关系一路追过去；因此最重要的信件反而写得很少，邮兽认识谁比信封写什么更重要。

- **判定：【NZ】**
- **判定依据：** 功能来自动物与社区长期共同生活形成的对象特异关系，而非可抽离的通用能力。
- **粉色世界观影响力体量：5/10**
- **视觉钩子：** 背部长着灰紫花冠的小兽；屋檐间的藤桥邮路；信袋上不是地址而是家族植物枝叶。
- **抽象规则：** 粉色世界的基础设施可以依赖“认识”而不是依赖坐标。

### 04｜“离枝街”出售从原生魔法中剥下来的短命能力

王城边缘有一条合法但名声微妙的旧街。匠人能把某些生命能力从完整主体上短暂剥离，例如从会夜视的兽眼中取出“一夜的暗视”、从鸣花中取出“一首歌的回声”。这些能力装在暗阳粉半透明囊膜里，只能维持几小时，而且使用者会沾上一点原主人的习性。它不是工业产品，每件都带着原生命的差异。

- **判定：【X并Z】**
- **判定依据：** 核心动作就是把原本依附完整生命的性质剥离并临时接给另一主体，X并Z占主导。
- **粉色世界观影响力体量：5/10**
- **视觉钩子：** 肉质半透明能力囊；旧木摊位上悬着会自行收缩的灰紫薄膜；买下夜视的人瞳孔短暂变成兽形。
- **抽象规则：** 传统X并Z可以是手工、短命、不可标准化的奇幻技艺，不必赛博化。

### 05｜被错接的“雨鳃”后来繁衍成了一个真正的新族群

很久以前，山地居民为了熬过连续洪灾，把河兽的呼吸组织嫁接给人。最初只是应急异术，但部分后代天生长出颈侧雨鳃，并逐渐形成自己的婚俗、歌声、饮食和河岸聚落。如今他们已经不是“接受改造的人”，而是拥有完整生活史的新族群，甚至反对别人继续复制最初的嫁接术。

- **判定：【X并Z的NZ】**
- **判定依据：** 起点是跨主体错接，但长期繁衍后形成自洽生命、族群关系与生活生态，结果转为NZ。
- **粉色世界观影响力体量：7/10**
- **视觉钩子：** 颈侧暗阳粉鳃瓣；河岸层层垂落的湿布住宅；雨天全族在露天广场合唱。
- **抽象规则：** X并Z造成的异常经过足够长时间，可以重新长成新的NZ，而不是永远保持“异常物”。

### 06｜王城“暮光市”每天只在太阳落入城墙缺口后的四十分钟存在

一段古城墙与祖冠树枝叶恰好形成固定暮光带，只有这四十分钟，一批依赖低温花粉醒来的商贩、食材和小型生物才会活动。居民不是去一个固定建筑买东西，而是等光、风、花粉与生物同时到位后，市场自己出现。错过时间，摊位上的活物会重新闭合，第二天再见。

- **判定：【NZ】**
- **判定依据：** 市场功能由地方空间、时间、植物、生物与居民习惯长期耦合产生，是完整关系网络。
- **粉色世界观影响力体量：4/10**
- **视觉钩子：** 暗阳粉斜光切过旧城墙；花瓣摊位在四十分钟内同时张开；太阳落下后整条街迅速闭合。
- **抽象规则：** 粉色世界的商业与公共生活也可以被生态时间直接塑形。

## 第二轮｜王权、信仰、远境与旅行

> 本轮优先补上一轮明确留下的缺口：**王城权力结构 / 粉色世界信仰 / 远离王城的城镇与荒野 / 非人种族 / 交通与旅行风险**。  
> 视觉继续遵守 P00：`#855D8F` 是生体、异常、奇异感的主锚点之一，但颜色本身不直接证明十元；判定仍以生命、关系、空间和实际变化为准。

### 07｜王城没有固定“王座”，十二个旧家族分别照料祖冠树的一种生命功能

王城最早不是由一位君主独自建立，而是由十二个与祖冠树共同生活的旧家族维持：有人照料根部蓄水，有人维护授粉兽群，有人记录树皮裂纹，有人负责让死去旧根安全转成地下街。如今王庭仍保留这套结构，所谓“王”更像十二种生命关系之间的最终调停者。若某一家失职，最先出现的不是政治文书，而是王城某一部分开始枯萎、积水或拒绝开门。

- **判定：【NZ】**
- **判定依据：** 权力合法性直接长在王城、祖冠树、旧家族和长期照料关系里，政治秩序本身是完整共同生活关系的产物。
- **粉色世界观影响力体量：8/10**
- **视觉钩子：** 十二家代表围坐在活根形成的环形议厅；灰紫树液印章只在活木上显色；宫殿墙面随祖冠树健康状态出现不同纹路。
- **抽象规则：** 粉色王城的政治权力可以不是“拥有土地”，而是“持续维持某段生命关系的资格”。

### 08｜“回声圣所”不供奉神像，而负责让已经持续数百年的关系不要断掉

粉色世界的许多古老圣所只守一件事：让某条河仍记得某个族群的歌，让某种夜兽仍在固定月份穿过村庄，让一种只会在特定家族葬礼上开放的花没有消失。祭司每天做的不是解释教义，而是喂养、清路、唱旧歌、修桥、照顾伴生生物。若关系真的断掉，圣所会被认为“失去神”，即使建筑本身毫发无损。

- **判定：【NZ】**
- **判定依据：** 信仰核心是对象特异、跨世代持续的生命与地方关系，神圣性来自关系仍然活着，而非抽离后的符号或功能。
- **粉色世界观影响力体量：7/10**
- **视觉钩子：** 暗阳粉旧织带从神殿一路系到河岸与兽径；没有主神像的空祭台；祭司与迁徙巨兽在同一座桥上完成年度仪式。
- **抽象规则：** 粉色世界的宗教可以把“维持一段古老关系”本身当成神迹。

### 09｜“背庭族”每个人背上都天然生着一座只属于自己的微型生态

背庭族出生时肩胛之间只有一小块软质灰紫皮膜，随着成长会逐渐长出苔、细枝、孢子囊、小虫和伴生花。不同人的“背庭”受居住地、饮食、亲密关系和季节影响，成年后几乎没有两个人一样。背庭不是装饰，族人靠它调节体温、储存气味、吸引伴生虫群，并通过观察背庭的变化判断一个人是否长期离开了熟悉环境。

- **判定：【NZ】**
- **判定依据：** 身体能力、个体成长、环境和伴生生态从出生开始共同形成，功能无法脱离完整生命单独成立。
- **粉色世界观影响力体量：6/10**
- **视觉钩子：** 肩背生长暗阳粉半透明叶片；微型飞虫停在人体背部“花园”；旅行者的背庭因离乡逐渐变薄失色。
- **抽象规则：** 一个种族自身可以就是一座随人生变化的小生态，而不是“人形角色加一个奇幻器官”。

### 10｜远离王城的“驮城”建在一头终生迁徙的巨大甲兽背上

北部荒原没有足够稳定的水源建永久城市，一支居民便世代生活在巨型驮城兽背部的甲壳谷地里。兽群每年沿古老路线迁徙，居民的农田、学校、墓园、集市和神殿也随之移动。孩子学习地理时首先背的不是国界，而是“兽今年会经过哪些山、哪一处泉水会停几天”。王城只能在驮城兽主动靠近时与这座移动城市交换货物和消息。

- **判定：【NZ】**
- **判定依据：** 城市、居民与巨兽的生活周期长期耦合，交通、经济和社会结构都从完整迁徙生态中自然长成。
- **粉色世界观影响力体量：7/10**
- **视觉钩子：** 巨甲裂缝间长着灰紫住宅与布棚；整座城市随兽群跨越浅湖；远看城灯像长在巨兽背上的暗阳粉星群。
- **抽象规则：** 粉色世界的“城市”不必绑定固定土地，它可以绑定一个活着的迁徙主体。

### 11｜旅行者会携带一截“归枝”，它本来负责把人带回熟悉的森林，却偶尔会接上错误的故乡

许多远行者出发前会从家乡守路树上取下一小截归枝。正常情况下，归枝在迷雾或荒野里会朝着母树方向生长，帮助旅人找到回路；但少数归枝在经历强烈魔法环境后，会与另一片拥有相似气味、土壤或旧关系的森林发生“错误认亲”，直接把道路引向从未去过的地方。当地人因此发展出专门判断“这条归路还是不是你的归路”的守路职业。

- **判定：【NZ的X并Z】**
- **判定依据：** 归枝原本是家乡与旅人之间的NZ回返关系；当它把关系归属错接到另一片森林时，局部出现X并Z式错误归属，但整体仍建立在NZ旅行传统上。
- **粉色世界观影响力体量：5/10**
- **视觉钩子：** 行囊外伸出暗阳粉细枝指向雾中；一条道路在林间突然分叉成两种季候；守路人用两盆故乡土测试归枝到底认谁。
- **抽象规则：** 粉色世界的旅行风险可以不是“怪物袭击”，而是关系本身发生错误指向。

### 12｜“倒悬谷”最初是一场重力错接事故，如今已经长成完整的新生态与城镇

数百年前，一名古代异术师把某种天空巨兽用于浮升的内脏性质错误接入整片山谷，山壁、瀑布和部分植物开始朝不同方向生长。最初这里被视为无法居住的灾区，但几代生命逐渐适应：鸟类在横向瀑布中筑巢，树根长成天然吊桥，人们发展出上下颠倒的屋舍、婚俗、道路和采集方式。现在的倒悬谷居民反而把“恢复正常重力”视为毁灭家园。

- **判定：【X并Z的NZ】**
- **判定依据：** 起点是将不属于山谷的生命性质错误嫁接给空间，属于X并Z；经过长期适应后，新的生态、生活与地方关系已经形成自洽NZ世界。
- **粉色世界观影响力体量：8/10**
- **视觉钩子：** 暗阳粉植物从侧向岩壁成片垂生；瀑布横着穿过村镇；居民沿“墙面街道”行走，屋门朝向彼此不同的重力方向。
- **抽象规则：** 粉色世界允许“异常先发生，生命再把异常活成正常”，这类地区不应永远被当作灾后遗址。
