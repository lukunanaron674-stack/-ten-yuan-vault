# 《黎黎隆》青色世界观正本

> 核心十元：Z × X并Z
> 核心动态对子：X并Z → 生Z
> 原则：奇幻是自然，机能是文明。青色文明不只标准化对象，也把“对象之间能够稳定产生什么功能”作为知识、工程与制度对象。

## 入库规则

只收与 Z 或 X并Z 存在直接十元关系的设定。其他十元只有在能够明确说明其生、克、补、承接、约束、放大、抑制、标准化、去标准化、技术化、知识化、接口化、维护或调用关系时进入。未冻结关系必须标“待验证”，不得硬编。

设定价值与十元映射分开评分。巨物生体组织利用只保留少量高体量结构，不作为青色世界观的万能答案。

## KEEP-01｜原境供养网

**一句话定义：** 异质生命材料离开原生态后，仍保留湿度、菌群、矿物、气压、周期或共生关系依赖；文明把这些依赖测量、拆解、标准化为可运输、可计量、可维护的城市公共供养。

- 主标签：X并Z的Z
- 十元关系：X并Z → 生Z
- X并Z：对象被拆走，但产生其功能的生态关系没有被完全拆走。
- Z：把关系依赖转成参数、管网、配额、维护流程与公共标准。
- 直接后果：原境管网、街区微生态、运输容器、配额、维护职业、断供风险。
- 青色世界观影响力：8/10
- 状态：KEEP（沿用既有正本，不重写核心）

## KEEP-02｜功能配方库

**一句话定义：** 青色文明发现许多“功能”并不属于某个器官、材料或生物，而只在若干普通对象以特定顺序、比例和环境建立关系时出现；文明因此把可重复的关系组合记录成可以调用的“功能配方”。

### 1｜关系审核

- 主标签：X并Z → Z
- 主关系：**X并Z → 生Z**（既有最高优先级冻结动态对子）
- 次关系：XN补Z（仅用于长期记录、复验与版本历史；沿用已确认关系）

### 2｜最初的 X并Z

野外存在一种低温保存现象：某种菌膜本身不制冷，矿物粉末本身不制冷，某种小型软体生命的呼吸液也不制冷；但三者在特定湿度、排列顺序和接触面积下，会持续吸走局部热量。

因此“低温”不是任何单体的属性，而是：

> 菌膜 × 矿粉 × 呼吸液 × 湿度 × 排列关系 → 低温功能

只带走其中任何一个对象都得不到功能，所以它属于 X并Z，而不是“发现了一种神奇制冷生物”。

### 3｜遭遇 → 观察 → Z化

最初商旅只是偶然利用这种环境保存食物；把菌膜带回城市后却完全失效，于是开始记录失败条件。

反复试验后，人们发现可重复的不是某个“材料”，而是：

- 对象必须以什么顺序接触；
- 比例落在哪个窗口；
- 环境湿度必须维持多久；
- 哪个对象先退出会导致功能崩溃；
- 功能衰减前会出现什么关系征兆。

随后 Z 将这些可重复部分提取为：

> 关系事故 → 组合记录 → 复验 → 功能分类 → 配方编号 → 接入顺序 → 维护窗口 → 失配警告 → 工程许可 → 可调用功能配方

文明由此不再只问“这个东西有什么功能”，而开始问：

> **“要让这个功能出现，需要让哪些东西发生什么关系？”**

### 4｜Z 的文明衍生

- **角色：** 技师携带的不是万能工具，而是一组能临时拼出所需功能的普通对象。
- **生活：** 家庭可以按照低等级配方组合清洁、保鲜、照明、除湿等功能；功能结束后，各对象仍可拆开继续使用。
- **组织：** 出现功能配方审定所、复验师、失配调查员、关系维护师。
- **技术：** 工程设计从“制造一个专用机器”增加为“设计一段可稳定复现的关系”。
- **城市：** 同一套公共对象在不同时间按不同配方重新组合，承担季节性功能，减少永久专用设施。
- **剧情：** 一个对象全部合法、单独无害的组合，可能产生未登记功能；犯罪和事故因此可以发生在“关系”而不是物品本身。

### 5｜核心概念具象映射

核心概念：**功能属于关系，不一定属于对象。**

1. **配方环牌**：记录接入顺序、比例和维护窗口。承载 Z 对 X并Z 的知识化。
2. **关系试验台**：多个普通对象在可替换槽位中组合，观察是否出现目标功能。承载 X并Z → Z 的复验阶段。
3. **失配纹**：功能即将崩溃时，连接面出现可识别纹理。承载尚未被完全标准化的 X并Z。
4. **功能配方册/公共库**：不是“物种百科”，而是按目标功能索引关系组合。承载 Z。
5. **临时功能架**：同一组槽位今天组合为保鲜，明天组合为除湿。承载 Z 对关系的调用。
6. **封存组合袋**：事故现场不只保存物证，还保存对象之间原本的距离、顺序和微环境。承载“关系也是证据”。

### 6｜Z 没有吃掉的 X并Z

配方只能覆盖已经复验过的关系。新的菌株、身体、矿源、季节和排列方式会改变结果；甚至同一配方在长期使用后可能出现此前不存在的副功能。

因此形成持续循环：

> X并Z异常功能 → 观察 → Z配方 → 大规模调用 → 新对象/新环境进入 → 新X并Z → 配方失效或产生副功能 → 再Z

### 7｜评分

- 十元映射强度：10/10
- 设定价值：10/10
- 青色世界观影响力：9/10
- 理由：它能同时改变知识分类、工具观、生产、家庭生活、城市设施和剧情事故，并把 X并Z→Z 从“异常被技术化”推进到“关系本身成为可设计、可调用的技术对象”。
- 状态：KEEP

## KEEP-03｜关系工程学

**一句话定义：** 当功能配方不再只用于单个工具，而被扩展到建筑、农田、身体、交通和街区尺度后，青色文明形成一门专门“设计关系而非制造单体”的工程学：工程师规定哪些对象在什么时序、距离、环境和退出条件下相遇，让目标功能从关系中出现。

### 1｜关系审核

- 主标签：X并Z → Z
- 主关系：**X并Z → 生Z**（冻结最高优先级动态对子）
- 次关系：**N补X并Z**（冻结关系；工程必须为关系提供发生与维持的空间/承载位）
- 辅助关系：**X克Z**（冻结关系；对象生长、迁移、扩张会破坏既定工程标准并制造新X并Z）
- 主次：X并Z→Z为母机制；N只负责承载，X只负责解释标准为何会被现实继续冲破，不另起平行体系。

### 2｜最初的 X并Z：会“换功能”的潮田

沿海低地原本有一种失败农田：盐生草、浅水软体生物、矿泥和季节性孢子单独都没有稳定的净水能力，但雨季四者以特定水位、密度和先后顺序共存时，田里的浑水会快速澄清；旱季同一片田却失去净水功能，反而开始积累可供燃烧的干性菌毯。

这里不存在“净水植物”或“燃料生物”。功能来自：

> 盐生草 × 软体生命 × 矿泥 × 孢子 × 水位 × 季节时序 → 某一阶段功能

所以它不是单体属性，而是典型 X并Z：对象、环境与时间关系共同决定功能。

### 3｜遭遇 → 观察 → 工程化

最初居民只是把这类田当成反复失灵的怪地：有几年水特别干净，有几年却完全无效。后来维护者发现，失败并非某个物种“坏了”，而是播入顺序、水位下降速度、软体生命迁入时间发生了偏移。

可重复部分逐渐被记录：

- 哪个对象必须先进入；
- 两种生命要保持多大距离；
- 水位下降到哪个窗口才允许第三对象接入；
- 功能出现后谁必须退出；
- 关系持续过久会出现什么副功能；
- 哪些空间必须故意留空，避免关系过度扩张。

Z由此把偶然关系提炼成工程语言：

> 异常共生/失败 → 关系日志 → 时序复验 → 空间关系图 → 接入/退出节点 → 承载位标准 → 维护周期 → 工程等级 → 施工许可 → 关系工程

关键变化是：**施工图不再只画“东西放在哪里”，还画“东西何时开始发生关系、关系维持多久、何时必须结束”。**

### 4｜文明衍生审核

- **角色：** 关系工程师不是万能科学家，而是负责安排对象相遇、退出和维护窗口；现场仍需要养护者、迁移员、失配调查员。
- **生活：** 一处住宅的除湿、保温、照明可能由不同季节的微生态组合轮换承担，居民会按关系日历调整生活，而不是永久安装一套专机。
- **组织：** 出现关系工程审定、现场复验、关系事故追溯与对象退出管理；功能配方库成为它的基础知识库，而不是被新体系取代。
- **技术：** 工程参数增加“距离、时序、接入顺序、退出顺序、承载空间、关系寿命”，技术对象从零件扩展到关系过程。
- **城市：** 某些街区会保留可周期更换对象的关系带，同一空间随季节承担净水、降温、蓄养或分解功能；这不是万能变形建筑，而是按已验证关系轮换。
- **剧情：** 敌人不必破坏任何设备，只需让一个对象提前一天进入、让某个共生者晚半小时退出，就可能使整段城市功能失配；事故证据因此包含“顺序”与“关系史”。

### 5｜核心概念具象映射

核心概念：**工程设计的对象从“物”升级为“关系发生的过程”。**

1. **关系施工图**：除位置外标出接入时刻、持续期、退出节点；承载 Z 对 X并Z 的过程标准化。
2. **空位槽/空生态带**：故意不填满的空间，等待关系发生或给对象退出；承载 N补X并Z。
3. **接入环**：只有达到前置条件才开放下一对象进入；承载 Z 的时序控制。
4. **关系日历**：居民或维护者按季节更换参与对象，而非更换整套机器；承载 Z 对关系的调用。
5. **退出标记**：明确某对象何时必须离开，否则原功能会转成副功能；承载 Z 对X并Z的约束。
6. **关系剖面窗**：建筑/田地留出可观察共生层的窗口，维护者读的是对象之间的状态；承载 X并Z 可视化。
7. **失序封条**：事故现场封存的不只是物体，还包括原距离、排列、湿度与进入顺序；承载“关系也是工程证据”。

### 6｜Z没有吃掉的X并Z

关系工程只能工程化已知组合。生命会生长，菌群会漂移，季节会变，新的身体和物种会进入；同一套关系被放大到街区尺度后，还可能出现小尺度实验中从未存在的反馈。

于是形成：

> 自然X并Z → 功能配方Z → 关系工程Z → 大尺度/长期调用 → X生长与新对象介入 → 标准被冲破 → 新X并Z → 新日志/新工程规则

因此青色工程不是“彻底消灭异常”，而是不断把一部分异常变成可维护关系，同时承认系统边缘永远会继续长出未知。

### 7｜评分

- 十元映射强度：10/10
- 设定价值：10/10
- 青色世界观影响力：10/10
- 理由：它不是新增一件科技产品，而是把功能配方库上升成青色文明的工程范式，可统一解释建筑、农业、身体、工具和城市微生态，同时保留X并Z持续制造未知的空间。
- 状态：KEEP

## MERGE-01｜失配事故

**一句话定义：** 配方中的对象都仍然完好，但关系条件偏移后，原本的功能消失、反转或产生副功能。

- 十元关系：X克Z；并改变既有X并Z。
- 核心作用：证明青色工程的故障不一定发生在对象上，也可能只发生在关系上。
- 具象：对象全部检测正常但系统无功能；事故现场必须保存排列与微环境；维护员先查“关系漂移”再换零件。
- 十元映射强度：9/10
- 设定价值：8/10
- 影响力：6/10
- 状态：MERGE → 功能配方库，不独立升母设定。

## MERGE-02｜潮田轮作

**一句话定义：** 同一片青色农田通过季节性更换参与生命、水位和矿泥关系，依次产生净水、蓄养与燃料菌毯等不同功能。

- 十元关系：X并Z → Z；N补X并Z。
- 核心作用：作为关系工程学的农业样本，证明同一空间可以通过改变关系而非更换整套设施切换功能。
- 十元映射强度：10/10
- 设定价值：8/10
- 影响力：6/10
- 状态：MERGE → 关系工程学，不独立升母设定。

- Z映射：9/10
- 设定价值：3/10
- 结论：LOW。若能直接预测所有组合，会删除 X并Z 持续产生未知关系的空间，只能作为有限工具存在。

### 巨兽器官功能站
- 关系可以成立，但 REJECT。
- 原因：再次用巨物组织承担城市基础功能，会让巨物生体利用吞掉青色主体比例；现阶段不需要。

### 万能关系施工机
- Z映射：9/10
- 设定价值：3/10
- 结论：REJECT。若单台机器能自动安排、预测并维护全部关系，会把关系工程重新压扁成普通万能科技，删除职业分工、维护风险和未知X并Z。

### 会变功能的神奇田
- X并Z映射：5/10
- 设定价值：4/10
- 结论：REJECT。若只写“田地随季节自动变化”，只是奇观；必须明确功能来自哪些对象、环境与时序关系，才能进入青色关系网。

## 当前母原则增量

1. 青色文明不仅标准化对象，也标准化关系。
2. 青色文明不仅维护关系，也开始把关系设计成可重复调用的功能。
3. **功能不一定属于东西；功能可以属于“东西之间”。**
4. **工程也不一定是在制造对象；工程可以是在设计“对象何时、何地、以什么顺序发生关系”。**
5. N在青色关系工程中的价值不是“温柔/陪伴”，而是为X并Z提供可发生、可退出、可缓冲的承载空间。
6. X并Z→Z 永远不是终点：标准化关系的大规模调用，会把更多对象带进系统，从而继续制造新的 X并Z。

## 下一研究母设定

**关系基础设施**：当关系工程从单个项目扩展到城市公共层，哪些“承载关系发生”的空间、时间窗口和公共对象应该成为基础设施？重点研究N补X并Z与X并Z→Z如何共同塑造街道、住宅、交通与公共维护，但不得退化成万能接口城市。
