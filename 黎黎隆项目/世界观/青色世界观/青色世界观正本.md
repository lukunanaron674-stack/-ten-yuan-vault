# 《黎黎隆》青色世界观正本

> 核心十元：Z × X并Z
> 核心动态对子：X并Z → 生Z
> 原则：奇幻是自然，机能是文明。青色文明不只标准化对象，也把“对象之间能够稳定产生什么功能”作为知识、工程与制度对象。

## 入库规则

只收与 Z 或 X并Z 存在直接十元关系的设定。其他十元只有在能够明确说明其生、克、补、承接、约束、放大、抑制、标准化、去标准化、技术化、知识化、接口化、维护或调用关系时进入。未冻结关系必须标“待验证”，不得硬编。

设定价值与十元映射分开评分。巨物生体组织利用只保留少量高体量结构，不作为青色世界观的万能答案。

## KEEP-01｜原境供养网

**一句话定义：** 异质生命材料离开原生态后，仍保留湿度、菌群、矿物、气压、周期或共生关系依赖；文明把这些依赖测量、拆解、标准化为可运输、可计量、可维护的城市公共供养。

- 主标签：X并Z的Z
- 十元关系：X并Z → 生Z
- X并Z：对象被拆走，但产生其功能的生态关系没有被完全拆走。
- Z：把关系依赖转成参数、管网、配额、维护流程与公共标准。
- 直接后果：原境管网、街区微生态、运输容器、配额、维护职业、断供风险。
- 青色世界观影响力：8/10
- 状态：KEEP（沿用既有正本，不重写核心）

## KEEP-02｜功能配方库

**一句话定义：** 青色文明发现许多“功能”并不属于某个器官、材料或生物，而只在若干普通对象以特定顺序、比例和环境建立关系时出现；文明因此把可重复的关系组合记录成可以调用的“功能配方”。

### 1｜关系审核
- 主标签：X并Z → Z
- 主关系：**X并Z → 生Z**（既有最高优先级冻结动态对子）
- 次关系：XN补Z（仅用于长期记录、复验与版本历史；沿用已确认关系）

### 2｜最初的 X并Z
野外存在一种低温保存现象：某种菌膜本身不制冷，矿物粉末本身不制冷，某种小型软体生命的呼吸液也不制冷；但三者在特定湿度、排列顺序和接触面积下，会持续吸走局部热量。

> 菌膜 × 矿粉 × 呼吸液 × 湿度 × 排列关系 → 低温功能

只带走其中任何一个对象都得不到功能，所以它属于 X并Z，而不是“发现了一种神奇制冷生物”。

### 3｜遭遇 → 观察 → Z化
最初商旅只是偶然利用这种环境保存食物；把菌膜带回城市后却完全失效，于是开始记录失败条件。反复试验后，人们发现可重复的是对象接触顺序、比例窗口、湿度持续时间、退出顺序与功能衰减征兆。

> 关系事故 → 组合记录 → 复验 → 功能分类 → 配方编号 → 接入顺序 → 维护窗口 → 失配警告 → 工程许可 → 可调用功能配方

文明由此开始问：**“要让这个功能出现，需要让哪些东西发生什么关系？”**

### 4｜Z 的文明衍生
- 角色：技师携带能临时拼出功能的普通对象。
- 生活：家庭按低等级配方组合清洁、保鲜、照明、除湿等功能。
- 组织：功能配方审定所、复验师、失配调查员、关系维护师。
- 技术：工程从制造专机扩展为设计稳定关系。
- 城市：同一套公共对象按不同配方承担季节性功能。
- 剧情：单独合法无害的对象组合可能产生未登记功能。

### 5｜核心概念具象映射
1. 配方环牌：Z对X并Z的知识化。
2. 关系试验台：X并Z→Z的复验。
3. 失配纹：尚未被完全标准化的X并Z。
4. 功能配方册/公共库：Z。
5. 临时功能架：Z对关系的调用。
6. 封存组合袋：关系也是证据。

### 6｜Z没有吃掉的X并Z
> X并Z异常功能 → 观察 → Z配方 → 大规模调用 → 新对象/新环境进入 → 新X并Z → 配方失效或产生副功能 → 再Z

### 7｜评分
- 十元映射强度：10/10
- 设定价值：10/10
- 青色世界观影响力：9/10
- 状态：KEEP

## KEEP-03｜关系工程学

**一句话定义：** 当功能配方扩展到建筑、农田、身体、交通和街区尺度后，青色文明形成专门“设计关系而非制造单体”的工程学：规定哪些对象在什么时序、距离、环境和退出条件下相遇，让目标功能从关系中出现。

### 1｜关系审核
- 主标签：X并Z → Z
- 主关系：**X并Z → 生Z**（冻结最高优先级动态对子）
- 次关系：**N补X并Z**（冻结关系）
- 辅助关系：**X克Z**（冻结关系）
- 主次：X并Z→Z为母机制；N负责承载，X解释标准为何会被现实继续冲破。

### 2｜最初的 X并Z：会“换功能”的潮田
盐生草、浅水软体生物、矿泥和季节性孢子单独都没有稳定净水能力，但雨季四者以特定水位、密度和先后顺序共存时净水；旱季同一片田又可能积累燃料菌毯。

> 盐生草 × 软体生命 × 矿泥 × 孢子 × 水位 × 季节时序 → 某一阶段功能

### 3｜遭遇 → 观察 → 工程化
居民逐渐发现失败来自播入顺序、水位下降速度、迁入时间等关系偏移，于是记录接入顺序、距离、水位窗口、退出条件、关系寿命与必须留空的空间。

> 异常共生/失败 → 关系日志 → 时序复验 → 空间关系图 → 接入/退出节点 → 承载位标准 → 维护周期 → 工程等级 → 施工许可 → 关系工程

关键变化：**施工图不仅画东西在哪里，还画关系何时开始、持续多久、何时必须结束。**

### 4｜文明衍生审核
- 角色：关系工程师、养护者、迁移员、失配调查员。
- 生活：住宅功能由季节微生态组合轮换承担。
- 组织：关系工程审定、现场复验、事故追溯、退出管理。
- 技术：参数增加距离、时序、接入/退出顺序、承载空间、关系寿命。
- 城市：街区保留可周期更换对象的关系带。
- 剧情：只需改变对象进入或退出时间就可能令城市功能失配。

### 5｜核心概念具象映射
1. 关系施工图：Z对X并Z的过程标准化。
2. 空位槽/空生态带：N补X并Z。
3. 接入环：Z的时序控制。
4. 关系日历：Z对关系的调用。
5. 退出标记：Z对X并Z的约束。
6. 关系剖面窗：X并Z可视化。
7. 失序封条：关系也是工程证据。

### 6｜Z没有吃掉的X并Z
> 自然X并Z → 功能配方Z → 关系工程Z → 大尺度/长期调用 → X生长与新对象介入 → 标准被冲破 → 新X并Z → 新日志/新工程规则

### 7｜评分
- 十元映射强度：10/10
- 设定价值：10/10
- 青色世界观影响力：10/10
- 状态：KEEP

## KEEP-04｜关系缓冲带

**一句话定义：** 青色城市主动保留一批暂时没有固定用途的生态空带，让陌生身体、未知共生和新关系先在可隔离、可退出的条件下发生与观察，再决定是否接入正式城市系统。

### 1｜关系审核
- 主标签：N补X并Z → X并Z生Z
- 主关系：**N补X并Z**（冻结关系；空间先为未知关系提供承载）
- 次主关系：**X并Z → 生Z**（冻结最高优先动态对子；事故被观察后形成城市标准）
- 主次：N负责让关系有地方发生，X并Z→Z负责把反复事故转成公共基础设施规则。

### 2｜最初的X并Z
一种旅居软体生命、街边除湿菌膜和当地矿尘各自无害；但旅居生命连续数晚停留后，其分泌物、菌膜、矿尘与停留时间共同长出新的吸水组织。某街区因此意外消除积水，另一街区却因矿物比例不同长出堵塞供养口的硬膜。

> 旅居生命 × 城市菌膜 × 当地矿尘 × 停留时间 × 空间距离 → 未知X并Z

危险与功能都不属于任何单体，而属于首次发生的城市关系。

### 3｜遭遇 → 观察 → Z化
早期城市以禁止陌生生命接近公共生态设施来止损，但这也同时扼杀有价值的新关系。长期事故记录后，维护者发现虽然不能预测未知关系会产生什么，却能标准化它发生时的边界条件：接触距离、共同停留时间、独立排放、退出顺序、与主供养网的隔离、异常后的恢复能力。

> 未知相遇/事故 → 地点与关系记录 → 重复观察 → 安全距离 → 停留时间窗 → 独立退出条件 → 缓冲等级 → 公共维护规范 → 关系基础设施Z

关键原则：**Z不标准化“里面会发生什么”，而标准化“未知关系在哪里、多久、以什么边界发生才不会拖死整个城市”。**

### 4｜文明衍生审核
- 角色：关系观察员、缓冲带养护员、退出员、未知关系记录师。
- 生活：异种居民的新器官、宠物、共生体先在住宅附近的未定义空间适应，而非直接接入主生态。
- 组织：城市按未知关系承受能力划分缓冲等级并维护独立排放与退出条件。
- 技术：城市技术增加“未知关系的安全发生条件”，而不是追求万能适配。
- 城市：街道出现空带、软边界、临时生态槽和可隔离小广场；先进地区反而敢于留空。
- 剧情：商业区认为缓冲带浪费土地；异种居民则认为没有缓冲带的城市只允许“已经被Z理解的身体”存在。

### 5｜核心概念具象映射
核心概念：**城市为尚未知道会发生什么的关系预留承载空间。**

1. **街道空生态带**：故意不装固定设施，承载N补X并Z。
2. **半开放关系槽**：陌生生命短期进入，承载关系发生空间。
3. **独立排放沟**：隔离新关系产物，承载Z对X并Z的约束。
4. **退出门/脱离口**：参与对象可分别撤离，承载N的可退出性。
5. **关系时标环**：记录陌生对象共同停留时间，承载Z的时序标准化。
6. **观察窗**：观察对象之间是否生成第三结构，直接承载X并Z。
7. **缓冲等级牌**：只标可承受的未知关系体量，不预测具体功能，承载Z分类。

### 6｜Z没有吃掉的X并Z
缓冲带只能控制边界，不能保证内部发生什么。已认证对象携带新菌群、第三对象临时进入、关系拒绝按规定时间结束，都可能生成新异常。

> 未知X并Z → 事故 → Z缓冲规范 → 关系缓冲带 → 更多安全相遇 → 新X并Z → 新事故/新功能 → 再Z

反向结果是：**Z为了管理X并Z而建设缓冲带，缓冲带反而让更多原本不会相遇的对象能够相遇，从而扩大X并Z。**

### 7｜评分
- 十元映射强度：10/10
- 设定价值：10/10
- 青色世界观影响力：9/10
- 理由：它把N补X并Z从理论句子落实成城市空间语言，并让青色城市通过“主动留空”区别于普通高密度赛博城市。
- 状态：KEEP

## KEEP-05｜最高正确工程

**一句话定义：** 青色文明允许一段已经被验证有效的 X并Z 关系压缩、转移乃至牺牲局部个体利益，只要这种损耗能够稳定提高整体系统的生存率、通过率、功能上限或可复现性；Z 再把这种“局部损耗换全局最优”测量、论证、标准化成可执行制度。

### 1｜核心不是“恶”，而是“正确”
- 主标签：X并Z × Z
- 核心关系：**X并Z → 生Z**
- X并Z：多个生命、身体、资源、环境与接口被组织成一个能够产生更高功能的整体；收益与损耗不必平均分配。
- Z：把整体收益、局部代价、失败率、替代率、可持续性与复验结果转成指标、阈值、许可与维护规范。
- 关键原则：**“最高的正确”不是道德上的善，而是系统目标下可证明、可复验的全局最优。**
- 因此青色最危险的时刻，不是有人发疯，而是所有步骤都合理、数据都正确、流程都合规，但某些人的利益正被持续当成系统成本。

### 2｜压榨如何发生
青色文明面对某种深层环境、未知生命或高风险区域时，常发现：
- 让少数个体承受更高身体损耗，可以显著提高整条路线的存活率；
- 把某些人的身体改造成长期接口，可以让更多人安全通过；
- 抽取少数人的特殊关系、器官、记忆或适应结果，可以换来可复制的公共技术；
- 保留个体完整性，会降低整体效率；允许局部牺牲，则系统功能急剧上升。

于是 X并Z 不只是“关系产生功能”，还可能出现：
> **关系整体获得更高功能，但参与关系的某些个体被持续压榨。**

### 3｜Z 如何把它变成文明
文明不会把这种做法描述成残酷，而会建立：
- 损耗阈值
- 通过率表
- 接口寿命
- 替代周期
- 牺牲上限
- 受益规模
- 失败回收流程
- “是否值得继续”的复验标准

于是“牺牲一个人救十个人”不再只是一次道德抉择，而会被转成一门可以持续运行的工程。

### 4｜具象映射
1. **正确率牌**：显示某套方案对整体目标的提升幅度。
2. **损耗槽**：把个体身体、寿命、关系或资源损失记录为系统成本。
3. **收益-损耗天平**：不是伦理象征，而是实际工程审核界面。
4. **替代席**：当一个接口个体损耗过高时，由下一位接替，系统不中断。
5. **复验床**：验证某种身体损耗是否真的换来了更高整体收益。
6. **最优线**：城市、路线或实验设施中标示“当前被证明最正确”的运行方案。

### 5｜文明后果
- 青色文明可能真诚地照顾被牺牲者，同时仍继续牺牲他们。
- 技术人员可以非常温柔，因为问题不在恶意，而在目标函数。
- 个体的痛苦不会被否认，只会被计入成本。
- 一旦新的 X并Z 关系证明“更少损耗也能达到同样结果”，旧方案会立刻被 Z 淘汰；因此青色并不崇拜牺牲本身，而崇拜**更高的正确率**。
- 反过来，如果某种牺牲被证明是当前唯一能达到最高结果的方法，文明会产生极强的正当化压力。

### 6｜与普通反乌托邦区分
这不是“公司为了利润压榨人”，也不是“科学家喜欢伤害实验体”。

青色真正的恐怖在于：
> **他们可能不贪钱、不撒谎、不享受痛苦，甚至愿意亲自承担同样损耗；但只要全局结果更正确，他们就会继续。**

因此：
- **正确 ≠ 善**
- **可复验 ≠ 可接受**
- **整体最优 ≠ 每个参与者都得到利益**
- **X并Z 产生更高功能时，也可能同时制造更深的个体代价**

### 7｜评分
- 十元映射强度：10/10
- 设定价值：10/10
- 青色世界观影响力：10/10
- 状态：KEEP
- 注：此条定义青色的价值逻辑，不用于反推新的十元 Canon。

## KEEP-06｜未定形地域与试路者

**一句话定义：** 世界存在尚未被文明稳定理解、进入与复现的“未定形地域”；青色文明必须让真实的人进入其中，以身体、关系与生存代价测试未知，再把幸存、伤亡、异变和失败转成路线、技术与公共标准。被要求承担这种代价的不是某个固定阶级，而是任何被“更大的正确”选中的普通人。

### 1｜他们探索的不是宝藏，而是“未知怎样变成可生活的世界”
未定形地域不是普通地图空白，而是关系本身尚未稳定：
- 同一条路第二次进入可能不再保持同一关系结构；
- 某些生命、材料或器官只有在特定人群、顺序、湿度、距离、停留时间下才产生功能；
- 人与环境长期接触后，身体可能出现新器官、新依赖或新接口；
- 某些区域只有真实生命参与时才会暴露规则，远程设备无法替代；
- 某些“资源”不是矿物，而是只有在关系成立时才出现的功能。

因此青色探索的核心问题是：
> **哪些未知关系可以被经历、记录、复验，最后转成文明能够调用的 Z？**

### 2｜普通人为什么必须进去
很多未知关系无法靠机器预先完成，因为“活人真正进入并承担后果”本身就是关系条件的一部分。

第一批试路者可能只是：
- 运输员
- 维修员
- 医护
- 护送者
- 学生
- 城市居民
- 临时征召者
- 自愿参与者

他们不是天然英雄，也不是某个“穷人阶级”的固定牺牲品。任何普通人都可能因为当时的灾难、任务、名额、公共需要或规则被要求成为第一批进入者。

关键不在“谁比较穷”，而在：
> **文明可以用“这是为了更多人”把具体的人变成试验条件。**

### 3｜四类探索任务
1. **试路**：寻找哪些身体、顺序、队形、时间窗能让一条路线稳定成立。
2. **试关系**：确认陌生生命、材料与环境组合能否产生可重复功能。
3. **试身体**：记录人在未知区域中会被怎样改变，以及哪些改变能够被后续利用。
4. **试边界**：判断文明究竟能把多少未知变成可居住、可维护、可复制的世界。

### 4｜“最高正确”如何吞掉个人选择
青色文明的论证可能完全真实：
- 这批人进去，下一批会少死很多；
- 一个人成为接口，可以让一整条路线稳定；
- 一次不可逆身体改造，可以换来全城长期安全；
- 某些牺牲目前确实没有替代方案。

因此最危险的句子不是谎言，而是：
> **“总得有人先进去。”**

以及：
> **“如果你不承担这次代价，后来的人会死得更多。”**

这里直接接 KEEP-05“最高正确工程”：牺牲不是被歌颂，而是被证明为当前整体最优。

### 5｜青色如何生出红色意志
当“更大的正确”开始替普通人决定是否应当牺牲时，红色意志出现。

青色的问题是：
> **怎样让最多的人活下来？**

红色的问题是：
> **谁有权决定谁应该为此付出身体、方向甚至生命？**

由此形成世界观历史张力：
> 未知 X并Z → 普通人试路 → 伤亡/异变被 Z 化 → 路线越来越安全 → 牺牲逐渐制度化 → 个体开始夺回“是否牺牲”的决定权 → 红色 Z 出现 → 个体意志彼此感染并公开表达，形成 ZN。

**注意：** 上述为世界观历史/价值因果链，不用于反推新的十元生克 Canon。

### 6｜核心青红冲突
- 青色：**如果牺牲你能让更多人活下来，那么这项牺牲在系统上可能是正确的。**
- 红色：**即使如此，是否牺牲也必须由我决定。**

因此红色并不是反对“正确”，而是反对：
> **正确替你做决定。**

### 7｜文明视觉与场景
- 试路墙：记录每一批进入者留下的身体参数与失败位置。
- 回程床：按探索层级准备不同规格的修复、卸载与替换接口。
- 空名格：路线已经成熟，但最初试路者的名字只剩编号或缺口。
- 通过率灯：每一批牺牲后，下一批的存活率上升。
- 试路门：门内是未知关系，门外是已经被 Z 化的安全世界。
- 红色拒签：后来出现的个人声明，表示“我承认公共目标，但拒绝由系统替我决定牺牲”。

## 当前母原则增量

1. 青色文明不仅标准化对象，也标准化关系。
2. 青色文明不仅维护关系，也开始把关系设计成可重复调用的功能。
3. **功能不一定属于东西；功能可以属于“东西之间”。**
4. **工程也不一定是在制造对象；工程可以是在设计“对象何时、何地、以什么顺序发生关系”。**
5. N在青色关系工程中的价值不是“温柔/陪伴”，而是为X并Z提供可发生、可退出、可缓冲的承载空间。
6. X并Z→Z永远不是终点：标准化关系的大规模调用，会把更多对象带进系统，从而继续制造新的X并Z。
7. **城市基础设施不只服务已知功能，也必须为尚未被Z理解的关系保留安全发生的空位。**
8. **青色城市的先进程度不等于功能密度；敢于留空、允许未知关系安全发生，本身就是一种文明能力。**
9. **青色允许 X并Z 的整体功能压缩局部个体利益，只要这种损耗能够被证明稳定提升系统目标；Z 会把这种交换测量、复验并制度化。**
10. **“最高的正确”不是道德真理，而是当前目标函数下的全局最优。青色最危险之处，是流程可以完全正确，而某些生命仍被正确地牺牲。**
11. **青色不崇拜牺牲本身，而崇拜更高的正确率：若能以更低个体损耗获得同等或更高整体结果，旧牺牲方案必须被淘汰。**
12. **青色探索的不是“宝藏”，而是如何把未定形地域中的未知关系转成可进入、可复验、可维护的文明世界。**
13. **第一批试路者首先是普通人，不是固定阶级英雄或牺牲阶层；“更大的正确”可以把任何具体的人变成系统代价。**
14. **红色不是反对正确，而是反对“正确替个人决定是否应当牺牲”；青色与红色因此形成核心价值冲突。**
