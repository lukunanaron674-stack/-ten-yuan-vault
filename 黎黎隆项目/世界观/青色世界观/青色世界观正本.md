# 《黎黎隆》青色世界观正本

> 核心十元：Z × X并Z
> 核心动态对子：X并Z → 生Z
> 原则：奇幻是自然，机能是文明。青色文明不只标准化对象，也把“对象之间能够稳定产生什么功能”作为知识、工程与制度对象。

## 入库规则

只收与 Z 或 X并Z 存在直接十元关系的设定。其他十元只有在能够明确说明其生、克、补、承接、约束、放大、抑制、标准化、去标准化、技术化、知识化、接口化、维护或调用关系时进入。未冻结关系必须标“待验证”，不得硬编。

设定价值与十元映射分开评分。巨物生体组织利用只保留少量高体量结构，不作为青色世界观的万能答案。

## KEEP-01｜原境供养网

**一句话定义：** 异质生命材料离开原生态后，仍保留湿度、菌群、矿物、气压、周期或共生关系依赖；文明把这些依赖测量、拆解、标准化为可运输、可计量、可维护的城市公共供养。

- 主标签：X并Z的Z
- 十元关系：X并Z → 生Z
- X并Z：对象被拆走，但产生其功能的生态关系没有被完全拆走。
- Z：把关系依赖转成参数、管网、配额、维护流程与公共标准。
- 直接后果：原境管网、街区微生态、运输容器、配额、维护职业、断供风险。
- 青色世界观影响力：8/10
- 状态：KEEP（沿用既有正本，不重写核心）

## KEEP-02｜功能配方库

**一句话定义：** 青色文明发现许多“功能”并不属于某个器官、材料或生物，而只在若干普通对象以特定顺序、比例和环境建立关系时出现；文明因此把可重复的关系组合记录成可以调用的“功能配方”。

### 1｜关系审核

- 主标签：X并Z → Z
- 主关系：**X并Z → 生Z**（既有最高优先级冻结动态对子）
- 次关系：XN补Z（仅用于长期记录、复验与版本历史；沿用已确认关系）

### 2｜最初的 X并Z

野外存在一种低温保存现象：某种菌膜本身不制冷，矿物粉末本身不制冷，某种小型软体生命的呼吸液也不制冷；但三者在特定湿度、排列顺序和接触面积下，会持续吸走局部热量。

因此“低温”不是任何单体的属性，而是：

> 菌膜 × 矿粉 × 呼吸液 × 湿度 × 排列关系 → 低温功能

只带走其中任何一个对象都得不到功能，所以它属于 X并Z，而不是“发现了一种神奇制冷生物”。

### 3｜遭遇 → 观察 → Z化

最初商旅只是偶然利用这种环境保存食物；把菌膜带回城市后却完全失效，于是开始记录失败条件。

反复试验后，人们发现可重复的不是某个“材料”，而是：

- 对象必须以什么顺序接触；
- 比例落在哪个窗口；
- 环境湿度必须维持多久；
- 哪个对象先退出会导致功能崩溃；
- 功能衰减前会出现什么关系征兆。

随后 Z 将这些可重复部分提取为：

> 关系事故 → 组合记录 → 复验 → 功能分类 → 配方编号 → 接入顺序 → 维护窗口 → 失配警告 → 工程许可 → 可调用功能配方

文明由此不再只问“这个东西有什么功能”，而开始问：

> **“要让这个功能出现，需要让哪些东西发生什么关系？”**

### 4｜Z 的文明衍生

- **角色：** 技师携带的不是万能工具，而是一组能临时拼出所需功能的普通对象。
- **生活：** 家庭可以按照低等级配方组合清洁、保鲜、照明、除湿等功能；功能结束后，各对象仍可拆开继续使用。
- **组织：** 出现功能配方审定所、复验师、失配调查员、关系维护师。
- **技术：** 工程设计从“制造一个专用机器”增加为“设计一段可稳定复现的关系”。
- **城市：** 同一套公共对象在不同时间按不同配方重新组合，承担季节性功能，减少永久专用设施。
- **剧情：** 一个对象全部合法、单独无害的组合，可能产生未登记功能；犯罪和事故因此可以发生在“关系”而不是物品本身。

### 5｜核心概念具象映射

核心概念：**功能属于关系，不一定属于对象。**

1. **配方环牌**：记录接入顺序、比例和维护窗口。承载 Z 对 X并Z 的知识化。
2. **关系试验台**：多个普通对象在可替换槽位中组合，观察是否出现目标功能。承载 X并Z → Z 的复验阶段。
3. **失配纹**：功能即将崩溃时，连接面出现可识别纹理。承载尚未被完全标准化的 X并Z。
4. **功能配方册/公共库**：不是“物种百科”，而是按目标功能索引关系组合。承载 Z。
5. **临时功能架**：同一组槽位今天组合为保鲜，明天组合为除湿。承载 Z 对关系的调用。
6. **封存组合袋**：事故现场不只保存物证，还保存对象之间原本的距离、顺序和微环境。承载“关系也是证据”。

### 6｜Z 没有吃掉的 X并Z

配方只能覆盖已经复验过的关系。新的菌株、身体、矿源、季节和排列方式会改变结果；甚至同一配方在长期使用后可能出现此前不存在的副功能。

因此形成持续循环：

> X并Z异常功能 → 观察 → Z配方 → 大规模调用 → 新对象/新环境进入 → 新X并Z → 配方失效或产生副功能 → 再Z

### 7｜评分

- 十元映射强度：10/10
- 设定价值：10/10
- 青色世界观影响力：9/10
- 理由：它能同时改变知识分类、工具观、生产、家庭生活、城市设施和剧情事故，并把 X并Z→Z 从“异常被技术化”推进到“关系本身成为可设计、可调用的技术对象”。
- 状态：KEEP

## MERGE-01｜失配事故

**一句话定义：** 配方中的对象都仍然完好，但关系条件偏移后，原本的功能消失、反转或产生副功能。

- 十元关系：X克Z；并改变既有X并Z。
- 核心作用：证明青色工程的故障不一定发生在对象上，也可能只发生在关系上。
- 具象：对象全部检测正常但系统无功能；事故现场必须保存排列与微环境；维护员先查“关系漂移”再换零件。
- 十元映射强度：9/10
- 设定价值：8/10
- 影响力：6/10
- 状态：MERGE → 功能配方库，不独立升母设定。

## 当前母原则增量

1. 青色文明不仅标准化对象，也标准化关系。
2. 青色文明不仅维护关系，也开始把关系设计成可重复调用的功能。
3. **功能不一定属于东西；功能可以属于“东西之间”。**
4. X并Z→Z 永远不是终点：标准化关系的大规模调用，会把更多对象带进系统，从而继续制造新的 X并Z。

## 下一研究母设定

**关系工程学**：当“功能配方”从个别技术扩展成完整工程学后，青色文明如何设计建筑×生物、身体×工具、农田×异兽、城市×微生态之间的关系，而不滑成万能科技。
