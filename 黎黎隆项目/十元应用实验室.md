# 《黎黎隆》十元应用实验室

> 项目应用层唯一研究载体。只验证十元是否真正改变《黎黎隆》的创作决策；不修改、不覆盖 L1/L2 canonical、十元信息卡、准度卡、正式生克补或动态链正本。

## 锁定设定

- 黎黎隆 = `zx8 + xn3`
- 塔汀 = `nz8 + nx6 + x3`
- 世界：`nz` 为基底，经历过 `x并z` 级毁灭，之后 `z` 科技化
- 世界核心：**奇幻是自然，机能是文明**
- 文明母题：**生命怎样改变自己的身体，才能继续进入更远的地方？**
- 禁止把十元退化成颜色、性格、职业、胜负、战力或视觉标签；禁止滑向普通赛博朋克。

## 文件治理

- 项目级长期有效结果只写入本文件与 `黎黎隆项目/00_世界观发散树.canvas`。
- Canvas 只保留最终 KEEP 节点和必要连接；三候选、IR、淘汰推理放在本文件。
- 本文件的“最近机制账本”只保留最近 8 个有效轮次用于反偏科硬门；更早实验保留在历史记录中，但不参与当前硬门。
- `source_commit: SELF` 表示“引入该条记录的本次提交”，实际 SHA 以 Git 历史及当轮汇报为准。

# 历史有效实验

## A｜角色｜夺路尾 v0.1

**真实问题：** 巨尾已有第三支点、配重、制动、锚定、感知、工具平台等功能，但这些都能安装给普通探索者。问题是 `zx8 + xn3` 怎样真正改变黎黎隆使用尾巴的方式。

**必要 IR 摘要：** `object=下一条可通行路线`；`changed_variable=谁决定方向，以及方向怎样从个人选择变成后方可重复使用的现实路径`；`decision_right=黎黎隆`；`reality_anchor=少量实体锚点+后方人员真实改走新路`。

**三候选：**
- A 强力破拆尾：删十元仍成立，`TENYUAN_DECORATIVE_ONLY`。
- B 全程规划尾：更像高 xn 测绘员，逆转黎黎隆体量关系。
- C 夺路尾：先留最小锚序，再让环境/人流围绕自己选定方向重排；已布结构真实限制临时改向。

**KEEP：** `KEEP_PROJECT_APPLICATION_A_LILI_ROUTE_AUTHORITY_v0.1`。删十元测试 PASS。

## B｜角色关系｜回路锁 v0.1

**真实问题：** 塔汀不能只是“谨慎副手/后勤”。

**必要 IR 摘要：** `object=P0旧路/P1新路/R回返窗口`；黎黎隆拥有 P1 最终方向决定权；塔汀不生成新方向，只在回返接口即将被永久切断时拥有局部有效拒绝，保存对象特异回返条件。

**三候选：**
- A 稳重副手：普通性格模板，淘汰。
- B 塔汀另开安全路线：把 nx 误写成第二个 zx，淘汰。
- C 回路锁：黎黎隆负责让前路成为现实；塔汀负责不让已存在过的后路被他的前进顺手抹掉。

**KEEP：** `KEEP_PROJECT_APPLICATION_B_LILI_TATIN_RETURN_LOCK_v0.1`。删十元测试 PASS。

**真实问题：** 奇美拉不能只做随机动物拼接与高攻击力。

**必要 IR 摘要：** `object=探索队留下的公共调用锚与对象特异回返关系`；`changed_variable=第三方实际把哪个东西识别为合法后路`。

- C 归巢拟态：在真锚上/附近长稳定生体套壳，复制第三方识别和调用特征；攻击在队伍主动返程时闭合。

**KEEP：** `KEEP_PROJECT_APPLICATION_C_CHIMERA_RETURN_ANCHOR_MIMIC_v0.1`。删十元测试 PASS。

## D｜文明｜返身断点文明 v0.1

**真实问题：** 为什么高度成熟的标准接口文明反而大量保留快拆、外置、可撤断点与个体差异。

**必要 IR 摘要：** 公共标准 `S_public` 只负责让文明识别/调用身体；对象特异返身链 `R_body` 负责让身体仍属于自身连续历史；高风险改造必须保留 `B_cut`。

**三候选：**
- A 更严格的统一接口公会：普通工业标准化，淘汰。
- B 器官身份钥匙：只解决鉴权，不解决返身，淘汰。
- C 返身断点：曾发生“公共壳仍能调用人，但人回不到自己的身体关系”的灾难，灾后公共调用与返身资格拆账。

**KEEP：** `KEEP_PROJECT_APPLICATION_D_RETURN_BREAKPOINT_CIVILIZATION_v0.1`。删十元测试 PASS。

## E｜剧情｜返身权转交事件 v0.1

**真实问题：** 怎样避免“身体强化后可能回不来”退化成普通力量副作用。

**必要 IR 摘要：** 同一身体结构 B0 同时承担返身断点与下一阶段任务器官基底；进入 P1 必须把 B0 改写为 B1。`decision_right` 仍属于黎黎隆；`reentry_right` 必须从本人身体拆出并由塔汀维护在 `R_tatin`。

**三候选：**
- A 救人还是撤退：普通任务/安全冲突，淘汰。
- B 强化后变不回来：普通“力量有代价”，淘汰。
- C 返身权转交：塔汀只能阻止无交接切断；黎黎隆先把返身部分实体交给塔汀，再把 B0 改成 B1 继续前进。

**KEEP：** `KEEP_PROJECT_APPLICATION_E_REENTRY_RIGHT_TRANSFER_v0.1`。

**反证：** 若 B0 不必改写即可进入 P1、塔汀获得 P1 最终方向、任意公共门站能恢复 B0、或 R_tatin 毁掉却仍可原样返回，则结构 FAIL。

## G｜AI审核｜结构反事实审核器 v0.1

**真实问题：** AI 不能靠“zx感强/nz氛围好”冒充结构审核。

**三候选：**
- A 十元审美打分器：普通情绪/风格评分，淘汰。
- B 对象清单审核器：资产都在也可能权利与对象连续性全错，淘汰。
- C 结构反事实审核器：`Expected IR → Observed IR → Evidence → Removal → Reverse → Verdict`。

**四硬门：**
1. `OBSERVABLE_EVIDENCE`：必须有可定位对象/动作/环境响应。
2. `STRUCTURAL_CAUSALITY`：要求的 changed_variable 必须由目标主体/关系真实改变。
3. `TENYUAN_REMOVAL`：删十元仍原样成立则 `TENYUAN_DECORATIVE_ONLY`。
4. `REVERSE_SENSITIVITY`：交换权利来源/对象归属/关键路径后必须从 PASS 翻为 FAIL。

**失败码：** `TENYUAN_DECORATIVE_ONLY`、`FAIL_IR_EVIDENCE_MISSING`、`FAIL_CAUSAL_RESPONSE_MISSING`、`FAIL_RIGHTS_COLLAPSE`、`FAIL_OBJECT_IDENTITY_BROKEN`、`FAIL_TEMPORAL_CONTINUITY`、`FAIL_REVERSE_INSENSITIVE`、`FAIL_STYLE_ONLY`。

**KEEP：** `KEEP_PROJECT_APPLICATION_G_STRUCTURAL_COUNTERFACTUAL_AUDITOR_v0.1`。

## A2｜角色第二圈｜锚序锁身 v0.2

**真实问题：** “夺路尾”已经改变用法，但身体本身仍可能只是普通多功能工程尾。

**必要 IR 摘要：** `object=巨尾关节自由度 + 外部可重复路线`；`changed_variable=tail_internal_dof ↔ route_external_constraint`。每枚真正成为公共路线节点的锚，都要求对应尾关节从自由运动切成承力锁止。

**三候选：**
- A 多模块换头尾：普通装备，淘汰。
- B 路线记忆尾：SLAM/轨迹记录换皮，淘汰。
- C 锚序锁身：外部路线越稳定，主体内部可即时改向的自由度越低；拔锚恢复自由，同时旧路线失稳。

**身体硬规则：** 自由关节组/承力锁组可读；锚点有可见力链；最小锚序 1–3 个；路线成立后轮廓由柔软曲线变成承力折线；锚稳但自由度不降则 G 审核 FAIL。

**KEEP：** `KEEP_PROJECT_APPLICATION_A2_LILI_ANCHOR_LOCKED_BODY_v0.2`。

# 2026-09-15｜A3 角色层｜外脑不再只是透明头壳：映脑窗 v0.1

## 1｜独立真实问题

当前主 Canvas 已经把“外脑 / 外露结构 / 透明腔体”列为世界形状语言，并明确要求器官外显必须回答用途、维护与姿态；街边停靠位甚至已经出现“外脑使用者的冷却靠点”。但这仍留下一个真实空缺：

> **透明脑人如果只是玻璃头里看得到大脑，它仍然只是很强的造型。能不能让“内部神经工作状态怎样真实外化到身体外层”直接改变角色姿态、设备使用和可见动作？**

本轮不把 `x并z` 贴成角色性格。这里只把土轴的 `内→外映射外化` 作为身体设计操作器：若内部变化不能稳定生成对应外部结构，单纯“看得见大脑”不算通过。

## 2｜为什么不是最近路/锚/回返族重复

- `object`：外脑使用者的活动皮层与透明脑腔外显区，而不是路线/锚/返身接口。
- `changed_variable`：某一内部神经功能是否形成可工作的外部身体表面，而不是谁拥有前进权/回返权。
- `core_mechanism`：内部功能状态 → 对象特异外部几何映射 → 外部维护行为真实依赖该映射。
- `mechanism_family`：`internal_to_external_mapping / x并z`。

与最近两轮 G/A2 只在 `output_asset=角色/审核可用资产` 上最多重合一项，不触发 `MECHANISM_OVERCONVERGENCE`。

## 3｜必要 Semantic IR

```yaml
actor: 外脑使用者（项目身体类型；不因此给人物固定十元人格标签）
object: 持续高负荷的具体神经功能区及其在透明脑腔外层形成的“工作窗”
object_layer: body / internal_function_to_external_surface_mapping
current_window: 某项感知或计算任务进入持续高负荷，到该任务退出或切换为另一神经功能
changed_variable:
  - active_neural_region: 哪一组脑组织正在持续承担主要任务
  - external_work_window: 外层哪一块实体表面成为该内部功能的对应维护/散热位置
relation_source: x并z 只读设计操作——内部状态必须产生稳定、对象可解析的外部映射；外部可见本身不等于外化成立
relation_shape: 内部高负荷区域通过悬液压力、软膜与神经束牵引靠近对应透明壳段，使该壳段形成可触摸、可冷却、可维护的实体工作窗；任务切换时旧窗撤回，新窗在另一位置形成
path_set: null
decision_right: null
reentry_right: null
future_endpoint: 透明脑从造型信息变成可直接动画化、可维护、可审核的身体工作机制
reality_anchor:
  - 活动脑区与外层工作窗位置存在一一可追踪映射
  - 工作窗形成时透明腔液位/膜张力/神经束位置真实变化
  - 外部冷却片、触觉罩或维护夹具只能在当前工作窗生效
  - 任务切换后旧窗退回、外部工具必须重新换位
```

无法可靠判断的 `decision_right/path_set/reentry_right` 明确为 null，不硬猜。

## 4｜三个候选

### 候选 A｜透明玻璃头 + 可见大脑

大脑一直清晰可见，配少量气泡、液体、神经线，视觉很有识别度。

- nearest-neighbor：与透明头骨/标本式科幻角色完全相邻。
- removal：删掉十元后造型原样成立。

**结论：`TENYUAN_DECORATIVE_ONLY`。**

### 候选 B｜脑区按情绪发不同颜色

紧张红、冷静蓝、思考紫，让观众直接看到心理状态。

- nearest-neighbor：情绪灯/脑波可视化。
- removal：用“情绪UI”即可完整解释，而且直接踩中“十元不能退化成颜色情绪标签”的禁区。

**结论：`TENYUAN_DECORATIVE_ONLY`。**

### 候选 C｜映脑窗：内部高负荷功能必须“长到表面”才能被文明持续维护

透明脑腔不是恒定展示柜。大脑通过柔性悬液与神经牵带保持在中央；当某一神经功能进入持续高负荷，对应皮层/神经叶会沿透明腔中的可见牵引膜靠近特定壳面，挤出一个浅薄、明确的实体“工作窗”。

工作窗不是发光 UI。它会真实改变：

1. **脑腔几何**：该侧液体被排开、膜层绷紧、脑组织与壳面距离缩短；
2. **外部维护位置**：冷却片、压力罩、感知放大附件只能贴在当前工作窗，贴错位置效果明显下降；
3. **角色姿态**：为了持续高负荷工作，角色会主动把对应头侧贴向街边冷却靠点/工作台夹具，而不是“站着开技能”；
4. **任务切换动作**：旧脑区撤回中央，外部工作窗消失，另一侧重新形成；附件必须随之换位。

因此“内部功能 → 外部可工作的身体表面”是一条可观察、可反转的因果链。

## 5｜四项检查

**nearest-neighbor：** 不是普通透明头，也不是脑电图。最近邻只提供“看见内部”，本候选强制内部功能生成一个外部第三方工具实际依赖的实体位置。

**removal：** 删掉 `x并z` 约束后，最自然的角色仍可拥有透明头壳和可见大脑，却没有理由要求“持续功能必须形成对象特异外显窗，且外部维护只能在该窗生效”。核心机制会塌缩成造型。

**reverse：** 若外部冷却片在任何头部位置都一样有效，或任务切换后工作窗完全不换位，则映射因果不存在，必须 FAIL。

**counterexample：** 一个漂亮透明脑角色、一个脑区发光角色、一个普通戴散热帽的角色，都不能推出“内部当前功能区决定外部唯一有效维护位置，并随任务切换重构外层几何”。

**结论：通过。**

## 6｜最终保留｜映脑窗 v0.1

> **外脑使用者的透明头不是展示柜。持续高负荷的内部神经功能必须在透明脑腔外层形成一个对象特异的实体工作窗；文明的冷却、维护与功能附件只在当前工作窗真正有效。**
