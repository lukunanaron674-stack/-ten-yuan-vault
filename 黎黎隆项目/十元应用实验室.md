# 《黎黎隆》十元应用实验室

> 项目应用层记录。只验证十元是否真正改变《黎黎隆》的创作决策；不修改、不覆盖 L1/L2 canonical、十元信息卡、准度卡或正式关系卡。

## 锁定设定

- 黎黎隆 = `zx8 + xn3`
- 塔汀 = `nz8 + nx6 + x3`
- 世界：`nz` 为基底，经历过 `x并z` 级毁灭，之后 `z` 科技化
- 世界核心：**奇幻是自然，机能是文明**
- 文明母题：**生命怎样改变自己的身体，才能继续进入更远的地方？**
- 禁止把十元退化成颜色、性格、职业、胜负标签；禁止滑向普通赛博朋克。

## 2026-09-14｜A 角色层｜黎黎隆的巨尾怎样真正体现 zx8 + xn3

### 当前真实问题

现有 Canvas 已锁定“人工探索体”“巨尾是核心探索器官”，并给出第三支点 / 配重 / 制动 / 锚定 / 感知 / 工具平台等功能，但这些功能仍然可以完整安装到一个没有十元结构的普通探索者身上。

因此当前缺口不是“巨尾还能加什么功能”，而是：

> **为什么偏偏是黎黎隆，会以一种只有 `zx8 + xn3` 才自然推得出的方式使用这条尾巴？**

### 必要 Semantic IR

```yaml
actor: 黎黎隆
object: 未知区域中的“下一条可通行路线”以及队伍能否沿该路线继续进入
object_layer: body_to_route / local_exploration_route_authority
current_window: 进入未知区、第一条既有路线失效，到队伍获得新的稳定通过路径
changed_variable: 谁决定下一步方向，以及该方向怎样从个人选择变成可重复通过的实体路径
relation_source: 黎黎隆自身巨尾的承力、锚定、感知与路径重组能力
relation_shape: 主体先留下最小运行结构，再公开扩大自己的方向决定范围，使环境与后方行动围绕该方向重组
path_set:
  - 既有安全路线
  - 黎黎隆新选路线
  - 由尾部锚点组织出的可重复通过路径
decision_right: 黎黎隆拥有“选下一条路并把它压成现实路线”的主动决定权
reentry_right: 不作为本轮主判据；只检查已布锚点是否形成真实前置结构
reality_anchor:
  - 尾部实体锚点
  - 承力点
  - 感知记录
  - 后方人员必须实际使用的新路线
```

十元只读依据：`zx` 要求主体权能公开显现并扩大，让环境/他者围绕其力量重新反应；`xn` 要求主体主动把行动放入顺序、节点、记录与可持续结构。正式关系 `xn 克 zx` 要求前置结构真实限制即时显权扩张，而不是普通拖延。

### 三个候选

#### 候选 A｜“巨尾强行开路”

黎黎隆遇到障碍就用巨尾撞碎、推开、压住地形，表现极强的突破力。

**检查：**
- nearest-neighbor：与“力气大 / 战斗强 / 工程破拆”几乎无差异；没有证明决定范围扩大。
- removal：删掉 `zx` 后，“强力探索尾巴”仍原样成立。

**结论：`TENYUAN_DECORATIVE_ONLY`。拒绝。**

#### 候选 B｜“全程规划型探索尾”

巨尾一路自动记录地图、排节点、计划补给、预演风险，黎黎隆严格按最优流程前进。

**检查：**
- reverse：如果把 `zx8` 拿掉，只保留强 `xn`，设计仍更顺；说明它实际上把黎黎隆改成了高 xn 规划型角色。
- counterexample：一个谨慎的研究院测绘员也能完整拥有这套行为，不需要“公开夺取方向决定权”。

**结论：不符合 `zx8 + xn3` 的体量关系。拒绝。**

#### 候选 C｜“夺路尾：最小锚序 → 路线改写”

黎黎隆进入未知区时，巨尾不会先做一整套长规划，而是只留下**少量、必要、实体化的承力 / 感知锚点**。这些锚点把刚走过的动作变成一个短小但真实存在的运行结构。

锚点一旦成立，黎黎隆随即把高 `zx` 推到现实：巨尾前段不只是“通过地形”，而是主动改变局部通过条件，让后方人员的挂点、绳路、跨越动作乃至门站结构被迫围绕**他选中的方向**重新组织。于是“我决定往哪走”不再只是队长发命令，而是被身体压成一条别人实际能走的路。

同时，先前留下的锚点会真实限制他的即时转向：若突然改路，他必须重排、回收或舍弃已布锚点，不能凭一次爆发无代价取消前置结构。这一限制对应 `xn 克 zx`，但由于 `xn` 只有 3，结构保持为“最小必要锚序”，不会把人物拖成流程型规划者。

**检查：**
- nearest-neighbor：不是普通 `x`（占有装备/资源），不是 `z`（由单一最高裁定点批准），也不是纯力量破拆；关键变量是“主体把自己的方向扩大成他人和环境必须围绕的现实路径”。
- removal：若删掉“方向决定范围扩大 + 最小前置结构限制即时扩张”这组十元机制，最自然的设计会退化成普通多功能探索尾，失去“先留下最少结构，再把路变成自己的路”这一使用规律。
- reverse：若前置锚点被移除，黎黎隆应能更快临时改向；若锚点已形成，则改向成本上升。符合 `xn 克 zx` 的反向测试。
- counterexample：仅有强壮、勇敢、队长身份或高科技尾巴，都不能推出“个人选路 → 实体锚序 → 后方路线被迫重组”这条链。

**结论：通过。**

### 最终保留｜夺路尾

**项目级定义：**

> 黎黎隆的巨尾是“夺路器官”。他先用少量锚点把行动变成最小可重复结构，再用巨尾前段把自己的方向选择压成环境与队伍都必须实际使用的新路线；已布锚点又会反过来限制他的临时转向。

这给《黎黎隆》增加的不是一个新名词，而是四个原本没有的创作决策：

1. **身体结构改变**：尾部必须同时存在“前段开路 / 改写通过条件”与“后段留锚 / 维持短路径结构”两套不同分工，不能再做均匀重复的机械节。
2. **习惯改变**：黎黎隆不是谨慎规划到万无一失，也不是无脑冲。他的固定习惯是“先留下最少够用的结构，然后强行把方向变成现实”。
3. **选择代价改变**：临时换方向时，他必须处理自己已经留下的锚点，因此高 zx 不是免费瞬移式的万能突破。
4. **剧情 / 镜头接口出现**：可以直接拍“尾尖先留下锚点 → 黎黎隆越过未知边界 → 后方挂点和人流转向他的新路径”的连续动作，十元进入动作与空间关系，而不是贴在角色简介上。

### 删掉十元测试

结果：**PASS**。

不是因为文案里保留了 `zx/xn` 字样，而是因为一旦移除两条结构约束：

- 主体必须把自己的方向扩大成他者 / 环境的现实运行方向；
- 先前主动组织出的实体锚序必须真实限制下一次即时扩张；

“夺路尾”就会坍缩成普通多功能探险尾。十元因此改变了因果、身体分工、动作顺序与选择代价。

### 状态

`KEEP_PROJECT_APPLICATION_A_LILI_ROUTE_AUTHORITY_v0.1`

## 2026-09-14｜B 角色关系层｜黎黎隆 × 塔汀：谁负责“往前”，谁保证“还能回来”

### 当前真实问题

上一轮已经让黎黎隆的 `zx8 + xn3` 真正进入“夺路尾”：他把个人方向压成队伍实际能走的新路线。但当前 Canvas 对塔汀仍只有“同批实验体 + nz8/nx6/x3”的锁定，二人关系没有结构机制。

如果只写成“黎黎隆冲、塔汀稳”“一个开路一个辅助”，删掉十元以后完全成立，只是常见冒险搭档模板。因此本轮只解决一个真实空缺：

> **黎黎隆把新路变成现实之后，塔汀为什么不是普通后勤，而是会结构性地改变他能不能继续夺路？**

### 必要 Semantic IR

```yaml
actors:
  - 黎黎隆: zx8 + xn3
  - 塔汀: nz8 + nx6 + x3
object: 探索队正在使用的“前进路线 / 已退出路线 / 可回返窗口”
object_layer: inter_character_route_authority_and_reentry
current_window: 黎黎隆刚把一条新方向压成现实路线，到旧路线即将因环境变化或撤锚而失效
changed_variable:
  - 新方向是否继续扩大
  - 被放弃路线是否仍保留对象特异的回返可能
  - 谁能在旧路彻底关闭前要求暂停/改接
decision_right:
  lili: 决定并现实化下一条前进方向
  tatin: 不夺取最终方向，但在“回返接口将被切断”时拥有有效的接口性拒绝/改接权
path_set:
  - P0: 已走过、正在退出的旧路径
  - P1: 黎黎隆夺取并现实化的新路径
  - R: 塔汀维持的对象特异回返接口，不等于第三条独立前进路线
reentry_right: 塔汀负责保存/恢复“还能回到 P0 的现实窗口”，而不是替黎黎隆决定 P1
reality_anchor:
  - 黎黎隆留下的实体锚点
  - 塔汀接管/保留的撤退接口、生命痕迹或可逆连接
  - 旧路关闭前的明确失效条件
```

只读依据：木轴 `zx↔nx` 的核心变量是“最终方向与作用权来源”；水轴 `xz↔nz` 的核心变量是“可逆性与对象特异回返空间”。因此塔汀的高 `nx` 不能被写成“偷偷当第二个队长”，高 `nz` 也不能只是温柔、治愈或怀旧。

### 三个候选

#### 候选 A｜稳重副手

塔汀负责提醒风险、检查补给，黎黎隆负责大胆开路；她偶尔劝他不要太冒险。

**检查：**
- nearest-neighbor：与“谨慎副手 / 莽撞队长”完全重合。
- removal：删掉 `zx/nx/nz` 后，角色关系几乎不变。

**结论：`TENYUAN_DECORATIVE_ONLY`。拒绝。**

#### 候选 B｜塔汀拥有第二套更安全路线

黎黎隆开危险近路，塔汀总能提供一条安全备选路线，二人争论该走哪条。

**检查：**
- reverse：这实际上把塔汀推成另一个“最终方向来源”，会把她的高 `nx` 反写成高 `zx`。
- counterexample：任何双队长路线争夺戏都能成立，不需要 `nz8 + nx6`。

**结论：结构错位。拒绝。**

#### 候选 C｜“回路锁”：黎黎隆夺路，塔汀保留撤路

黎黎隆把 P1 压成新的现实方向时，塔汀不与他争夺“下一步往哪走”。她做的是另一件事：把刚被放弃的 P0 中仍然属于这支队伍的可逆条件接住，维持一个**对象特异的回返接口 R**。

R 不是万能传送门，也不是第二条前进路线。它只能保存“这批人/这批锚点/这一段身体状态仍可回到 P0”的现实条件，而且会随时间、伤势、环境变化逐渐失效。

当黎黎隆准备回收某个关键锚点、继续扩大 P1，而这个动作会让 R 提前永久关闭时，塔汀的 `nx6` 才进入关系：她不夺取最终方向，却可以在这个外部接口节点上让“继续扩张”暂时失败，迫使黎黎隆先改接、转移或明确放弃回返权。她的 `x3` 只允许她直接掌握少量已交到手里的锚具/接口，因此她不能无限扣住整个队伍。

于是二人的关系不是“一个冲一个拉”，而是：

> **黎黎隆负责让不存在的前路变成现实；塔汀负责让已经存在过的后路不要被他的前进顺手抹掉。**

两人互相需要，也会真实互相恼火：黎黎隆若没有塔汀，夺路越快，累计不可逆损失越大；塔汀若没有黎黎隆，只能保存回返可能，却不能凭 `nz/nx` 自己生成新的前进方向。

### 检查

- **nearest-neighbor**：这不是“治疗者”“谨慎副手”“导航员”。塔汀不提供新方向，核心变量是回返窗口是否仍存在，以及她对“切断接口”的局部否决是否有效。
- **removal**：移除 `zx/nx/nz` 的结构约束后，最自然的写法会退化成普通“先锋 + 后勤”；不会自然得到“前路现实化越成功，后路反而更需要被另一角色主动保存”的关系机制。
- **reverse**：若塔汀真的开始替队伍决定下一条前进路线，关系应判定跑偏；若黎黎隆撤回夺路决定、重新开放旧方向，她的接口否决应解除。二者证明权能没有互换。
- **counterexample**：只给塔汀高治疗能力、温柔性格、谨慎性格或地图知识，都不能推出“对象特异回返接口 + 在切断节点拥有有效拒绝权”。

**结论：通过。**

### 最终保留｜回路锁关系 v0.1

项目级关系定义：

> 黎黎隆用夺路尾把自己的方向变成现实路径；塔汀不与他争夺前进方向，而是接住被放弃路径中的可逆条件，维护队伍对象特异的回返接口。黎黎隆若要继续扩张并切断该接口，必须先处理塔汀维持的回路；塔汀可以让“直接切断”失败，却不能替他决定新的前进方向。

它具体改变了四项创作决策：

1. **关系冲突来源改变**：争吵不再是性格冲突，而是“继续夺路是否值得永久烧掉某条回返权”。
2. **塔汀的能力用途改变**：她的高 `nz` 必须对应可观察的回返保存/恢复机制；高 `nx` 只在接口节点产生真实拒绝，不得写成第二队长。
3. **黎黎隆的代价改变**：他越成功地把前路压成现实，越可能制造不可逆的后路损失，因此 `zx8` 会主动制造关系债务。
4. **剧情接口出现**：可以构造“前方即将开启，但旧路只剩一次回返窗口”的选择，让二人不靠误会就发生结构性冲突。

### 删掉十元测试

结果：**PASS**。

删掉 `zx/nx/nz` 后，“先锋 + 后勤”仍可成立，但“前进方向现实化 → 旧路回返条件被消耗 → 塔汀在切断接口处拥有有效拒绝 → 黎黎隆必须处理回返权才能继续扩大方向”这一整条关系链不会自然保留。因此十元改变了关系的因果、权利边界、冲突发生点与剧情代价。

### 状态

`KEEP_PROJECT_APPLICATION_B_LILI_TATIN_RETURN_LOCK_v0.1`

## 2026-09-14｜C 怪物层｜奇美拉怎样真正攻击“夺路 + 回路锁”

### 当前真实问题

当前 Canvas 只确认世界天然存在“奇美拉式生命”，但没有任何一只奇美拉拥有项目级交互规则。若只做“多种动物器官拼接、攻击力强、会伏击”的怪物，即使视觉很漂亮，也与《黎黎隆》刚建立的“夺路尾 / 回路锁”毫无结构关系。

本轮真实问题因此是：

> **能不能让奇美拉攻击的不是血量，而是探索队赖以确认“这条路是我们的、这个锚能把我们带回去”的身体接口？**

这同时回应现有世界的“奇幻是自然，机能是文明”：怪物本身仍是自然生态，危险来自它恰好会利用文明为了远行而制造的身体接口，而不是突然变成黑客病毒。

### 必要 Semantic IR

```yaml
actor: 归巢拟态奇美拉（项目候选名）
objects:
  - 黎黎隆留下的路线锚点
  - 塔汀维护的对象特异回返接口 R
object_layer: frontier_ecology_to_callable_body_interface
current_window: 队伍离开锚点后，到下一次尝试调用该锚点返回之前
changed_variable:
  - 第三方实际把“哪个东西”识别为这支队伍的合法回返锚
  - 回返证据是否仍准确归属于原锚点
relation_shape: 奇美拉不伪装成队员，而是在锚点表面生长稳定、可重复识别的拟态组织壳，复制其压力纹、气味膜、发光腔或机械扣位等公共调用特征，使后续身体/工具把错误对象当成合法回返接口
path_set:
  - P1: 黎黎隆继续推进的新路线
  - R0: 原始真实回返锚
  - Rm: 奇美拉生成的拟态锚壳
  - Ptrap: 由 Rm 引向奇美拉巢体/捕食区的错误回返
reentry_right: 仍属于原队伍与 R0 的对象特异关系；奇美拉只能污染“怎样被找到/调用”，不能凭空拥有这段共同历史
decision_right: 奇美拉不决定黎黎隆下一步往哪走；它夺取的是回返接口的公共识别入口
reality_anchor:
  - 被覆盖后仍保持稳定形状的生体套壳
  - 可被多人/多件装备重复误认的调用特征
  - 原锚仍存在但被错误壳截获的实际返回行为
```

十元只读依据：`x并z` 的主骨是稳定公共壳，使对象可被第三方识别、调用、归因、进入；`nz` 在本项目已被锁进对象特异回返窗口。正式 `x并z 克 nz` 关系卡锁定的是“稳定壳持续替真实主体承接关系证据，导致真实主体退出可信回返位置”。本项目仅借用这一已锁定机制做**怪物应用假设**，不反向声称所有空间锚点都自动属于该理论关系，也不修改 canonical。

### 三个候选

#### 候选 A｜拼接猎食型奇美拉

拥有不同动物的爪、甲、嗅觉器官和爆发肌肉，会在狭窄地形伏击探索者。

**检查：**
- nearest-neighbor：与任何“高适应性猛兽 / 拼接怪”完全重合。
- removal：删掉全部十元标签后攻击逻辑、场地和失败条件原样成立。

**结论：`TENYUAN_DECORATIVE_ONLY`。拒绝。**

#### 候选 B｜环境换体型奇美拉

进入水域长鳃、进高热区更换散热囊、钻洞时收缩骨架，逼队伍不断换装备追逐。

**检查：**
- nearest-neighbor：这是非常适合本世界“身体适配”母题的生态设计，但本质仍是环境适应型怪物。
- removal：没有十元也会自然从“生命通过改变身体进入更远地方”推出，十元不是必要生成条件。

**结论：世界观可另收，但不能作为本轮十元有效产出。`TENYUAN_DECORATIVE_ONLY`。**

#### 候选 C｜归巢拟态奇美拉：不追人，先吃掉“回去的方法”

这种奇美拉会追踪探索队留下的实体锚点，但它首先不破坏锚。它分泌可硬化的薄层生体组织，沿锚点的扣位、压力纹、气味膜、温度腔与低分辨状态光生长，把自己塑成一个**稳定可调用的“合法锚外壳”**。

它真正危险的地方在于：队伍离开后，Rm 会持续存在，并且能被不同队员、外置器官或返程工具重复识别。于是塔汀维持的“这是我们刚才留下、还能回去的那个对象”并没有凭空消失，但寻找它的公共入口被另一个稳定壳截获。返程时，队伍可能不是“迷路”，而是正确执行了自己熟悉的回返动作，却被错误接口带进奇美拉的捕食区。

怪物因此形成三个可拍、可做关卡的阶段：

1. **采样**：接触弃置锚、绳结、尾部留痕或维护膜，记录可识别接口；
2. **套壳**：在原锚附近或另一位置长出 Rm，稳定复制可调用特征；
3. **截返**：只有队伍主动调用“回去”时陷阱才真正闭合，怪物不是追逐者，而是等待文明自己完成最后一步。

**失败条件**不再是“被咬死”，而是：队伍已经无法证明当前调用的锚仍然是 R0；此时继续沿既有回返动作会把整个队伍送进 Ptrap。

**破解条件**也不等于发现“哪个长得不像”。必须建立一条拟态壳无法代替的对象特异验证，例如塔汀现场重新接回只有这批身体与 R0 共同留下的可逆证据；或者黎黎隆放弃已污染锚序，承担代价重新夺出一条不依赖旧公共壳的新路。具体破解方式留给剧情/关卡层继续验证，本轮不把未锁定关系硬写成万能解法。

### 检查

- **nearest-neighbor**：它不是普通拟态怪。普通拟态骗的是“看起来像谁”；本候选必须稳定复制“第三方怎样调用这个锚”，且多人/多工具能重复误认，攻击对象是公共调用壳而不是视觉相似。
- **removal**：删掉 `x并z/nz` 的结构约束后，设计最自然会退化成“伪装成路标的捕食者”。它不会必然要求“原锚仍存在、对象特异回返关系仍存在，但公共调用入口被稳定壳截获”这一层，也不会自然生成“正确执行返程动作反而失败”的失败条件。
- **reverse**：若拟态组织只长得像锚，但任何身体/工具都不会把它当作合法接口，则怪物机制应立即失效；若移除拟态壳后原 R0 可再次被准确调用，回返能力应部分恢复。
- **counterexample**：单次幻觉、一次性诱饵、会变脸的怪、毁路怪都不够。它们没有稳定跨时间调用壳，也没有污染“回返证据归因到哪个锚”的结构。

**结论：通过。**

### 最终保留｜归巢拟态奇美拉 v0.1

项目级定义：

> 边境存在一种奇美拉，会在探索队留下的身体/路线锚点上生长稳定拟态壳，复制文明用于“识别并调用回返接口”的实体特征。它不必摧毁后路，只需让队伍把错误对象持续当成自己的后路；真正的攻击在队伍主动返程时完成。

它具体给《黎黎隆》增加了五项原本没有的东西：

1. **怪物攻击对象改变**：从身体血量转向“回返接口的可信归因”。
2. **场地关系改变**：越依赖标准锚点的成熟探索路线，反而越容易给怪物提供可复制的公共壳；文明进步本身产生生态弱点。
3. **黎黎隆机制被反咬**：夺路尾留下越多可重复使用的锚，奇美拉可采样的入口越多，`zx8 + xn3` 的优点不再只是爽点。
4. **塔汀机制被具体攻击**：她维护的不是抽象“安全感”，而是必须不断确认“回返证据到底属于哪个真实锚”的对象特异关系。
5. **怪物视觉从机制长出**：其身体应大量出现贴附膜、接口套壳、重复扣位、仿压力纹、半透明采样囊，而不是为了猎奇随机拼动物头。

### 删掉十元测试

结果：**PASS**。

删掉十元后仍可保留“拟态怪”，但无法保留本设计的核心因果：

`稳定公共调用壳被复制 → 回返证据被错误对象承接 → 队伍正确执行返程动作仍进入错误目标 → 原后路未被毁却失去可信调用位置`。

十元因此改变了怪物的攻击逻辑、交互对象、失败条件、场地风险和对两名主角既有机制的反制方式，而不是给怪物贴一个 `x并z` 标签。

## 2026-09-14｜D 世界 / 文明层｜为什么这个文明的“标准接口”必须故意留下一块不能标准化的身体

### 当前真实问题

当前 Canvas 已经有一条清楚但仍偏通用的历史：异体自然时代 → 身体工艺时代 → 机能标准化时代 → 外显器官与探索体时代。城市也已经长出门槛带、维护缝、多层柜台、可翻折天气层等身体文明细节。

真正的断链在这里：项目锁定了“世界以 `nz` 为基底、经历过 `x并z` 级毁灭、之后 `z` 科技化”，但这三件事目前还没有真实改变**为什么接口要这样设计、为什么身体改造要保留某种边界、为什么现代城市会出现当前这些维护空间**。如果只是补一句“过去发生过灾难，所以后来制定安全规范”，十元照样可以全部删掉。

因此本轮只问一个文明级问题：

> **这个世界为什么没有沿着机能标准化一路走向“所有身体都能被同一套万能接口永久接管”，反而形成了今天这种大量快拆、外置、保留个体差异的身体文明？**

### 必要 Semantic IR

```yaml
actor: 灾后身体文明（工坊 / 维护所 / 门站 / 探索机构构成的长期共同体）
object: 高风险身体改造与标准接口之间的连接方式
object_layer: civilization_body_modification_and_reentry
current_window: 机能标准化时代后期，到当前“外显器官与探索体时代”形成
changed_variable:
  - 公共标准壳是否足以代表一个身体的全部接入资格
  - 身体为了远行而改变后，是否仍保留回到对象特异原身关系的现实位置
  - 谁/什么能确认“现在连接的仍是这个身体、这个状态、这个回返目标”
relation_shape: 公共接口负责让世界识别和调用，个体返身链负责维持对象特异回返；二者被文明故意拆开，任何单一公共壳都不得独占不可逆身体接入
path_set:
  - S_public: 可跨人群复用的标准接口 / 快拆 / 状态窗
  - R_body: 只属于该身体及其真实改造历史的返身链
  - B_cut: 改造前预留的物理断点 / 可撤接口
  - Z_confirm: 在关键不可逆节点上，由明确认可主体确认“这个身体 / 这次改造 / 这条返身目标”的确认位置
  - P_far: 为进入未知环境而采用的任务身体状态
  - P_return: 完成任务后可重新接近的对象特异身体状态
decision_right: 文明可以规定关键接口怎样被调用，但不能把“符合公共规格”直接等同于“这个身体已经被正确接回”
reentry_right: 必须由 R_body 保留；公共标准 S_public 只提供可调用入口，不拥有替代对象特异返身关系的资格
reality_anchor:
  - 快拆与可见断点
  - 非通用的身体特异接触面 / 组织痕 / 旧连接位
  - 改造前保存的返身基线
  - 需要具体人 / 小组 / 机构在明确阶段作出的确认记录或实体见证
```

只读依据只取三条，不反向修改理论：

1. `x并z` 是稳定公共壳，使第三方能识别、调用、归因或进入对象；
2. `nz` 的主骨是对象特异、可验证的回返与修复位置，而不是“温暖颜色”；
3. 正式 `x并z 克 nz` 已锁定“稳定公共壳持续替真实主体承接证据，真实主体退出可信回返位置”的机制。本项目只把它作为文明灾难的结构参考，不宣称身体接口本身自动等同理论关系。

项目锁定的“`z` 科技化”在本轮只落实为**确认功能被技术化承载**：关键身体接入不靠系统自动宣布真伪，而是把“谁确认、确认哪个身体状态、在哪个阶段有效”做成可见的维护窗口、实体见证位与状态记录。规则和设备本身不判成 z；只有明确认可主体形成的具体确认才是 z 端点。

### 三个候选

#### 候选 A｜“灾后成立统一接口公会，标准做得更严”

过去接口混乱导致事故，于是公会统一尺寸、颜色、扣具、维护流程与认证等级，所有城市都遵守同一套规范。

**检查：**
- nearest-neighbor：与普通工业标准化 / 安全规范完全重合。
- removal：删掉 `x并z/nz/z` 后，历史、制度和城市结果几乎原样成立。
- counterexample：现实中的铁路、医疗接口、航空维修同样会自然推出这套结构。

**结论：`TENYUAN_DECORATIVE_ONLY`。拒绝。**

#### 候选 B｜“每个器官都有不可复制的身份钥匙”

所有人工器官和探索模块都植入不可复制的生物标记，只有原主人能通过，借此防止奇美拉拟态和错误接入。

**检查：**
- nearest-neighbor：本质是生物识别 / 防伪 / 双因素认证，只是把密码换成组织。
- removal：删掉十元以后依然是一套完整的防盗安全设计。
- reverse：就算身份钥匙百分之百安全，它也无法保证一个经历巨大改造的身体仍保留“能回到此前身体关系”的路径；它只证明“这是同一个人/器官”，不证明“还能返身”。

**结论：解决了鉴权，却没有解决本项目真正的回返结构。`TENYUAN_DECORATIVE_ONLY`。拒绝。**

#### 候选 C｜“返身断点”：公共接口越成熟，越必须故意保留不能被公共壳替代的一段身体关系

机能标准化时代后期曾发生一类灾难：文明把“符合标准接口”逐渐当成“已经正确接回这个身体”的充分条件。标准壳极其成功，以至于城市、维护所、探索机构都能继续识别、调用和服务一个已经发生巨大内部变化的身体。

问题也正因此出现：**公共壳还在正常工作，身体却失去了回到自身旧状态的对象特异路径。** 有些远行者并非死亡，也不是设备报错；他们仍能被门站识别、被工坊维护、被同规格模块继续调用，却再也无法安全卸下任务身体、恢复原来的触觉比例、器官协作或生活姿态。文明“还能使用他们”，但他们已经失去了“回到自己”的位置。

灾后没有取消标准化，而是反着做了一件很怪、也很关键的事：

> **任何越接近不可逆身体改变的技术，越不能只靠公共标准完成闭环。**

于是形成“返身断点”：

1. **出发前先定义返身位**：高风险探索改造开始前，不只记录装备清单，而是留下这个身体当下可验证的姿态、组织连接、感觉比例与关键对象关系，形成 `R_body`。
2. **公共层只负责让世界使用你**：标准扣具、状态窗、模块尺寸继续存在，甚至比过去更成熟，但它们只承担 `S_public`，不能单独证明“已经正确回到本人”。
3. **关键改变必须预留 B_cut**：外肺、巨尾、感知囊、任务骨架在设计时就要有明确可撤断点。不是因为文明害怕改造，而是因为“能继续变”与“还能回来”被视作同一个技术问题的两面。
4. **返身时必须重新确认对象**：在卸除或重接关键器官时，明确的技师、伙伴或机构作为认可主体，只确认一个具体命题：“眼前这条连接是否重新对应这具身体的返身基线？”这就是 `z` 科技化在本项目里的一个落点；设备承载确认，不替确认主体凭空生成 z。
5. **如果公共壳与返身链冲突，优先停机而不是强行兼容**：系统宁愿让一个标准模块暂时“不能用”，也不允许它仅凭规格正确就覆盖身体特异关系。

这条文明原则会沿着历史直接压到当代生活：

`x并z 级公共壳灾难 → 公共调用与对象特异返身被拆账 → z 的确认位置被做成实体维护节点 → 技术开始大量使用快拆、断点、外置器官与可见返身窗 → 城市出现返身位 / 卸装槽 / 回接床 → 冒险与研究职业必须同时训练“进入陌生身体状态”与“把人带回来”。`

### 检查

- **nearest-neighbor**：不是普通模块化。普通模块化追求的是更容易互换；返身断点反而规定“越关键的层，越必须保留一块不能被通用规格完全替代的对象特异连接”。
- **removal**：删掉“公共壳只负责可调用、对象特异返身另算、确认主体只确认具体返身状态”三条约束后，设计会自然退化成快拆模块 + 安全认证，不再必然产生“故意不让万能接口闭环”的文明哲学。
- **reverse**：如果未来某种万能接口重新被允许仅凭规格就完成任何人的不可逆身体接入，那么 `R_body` 会再次被 S_public 吞掉，文明应重新出现“系统仍认得你，但你回不到自己”的灾害模式；如果公共壳被拿掉但对象特异返身链仍在，个体会变得难以被城市高效调用，却不必失去返身资格。
- **counterexample**：一套绝对安全、绝不被伪造的标准接口，只要没有对象特异返身链，仍不满足本设计；反过来，一套很笨、很手工的接口，只要确实保留该身体的返身位，就可能比万能标准更符合当前文明。

**结论：通过。**

### 最终保留｜返身断点文明 v0.1

项目级定义：

> 《黎黎隆》的身体文明在经历“稳定公共壳可以继续调用一个人，却不能保证这个人还能回到自己”的灾难后，把公共标准与对象特异返身彻底拆账。所有高风险身体改造都必须预留返身位与可撤断点；标准接口负责让文明使用身体，返身链负责让身体仍属于它自己的连续历史；关键回接必须由明确认可主体在具体阶段完成确认。

它具体改变了六层世界设计：

1. **历史**：`x并z` 级毁灭不再只是背景名词，而是“公共可调用性成功到足以替代真实返身关系”的文明级事故。
2. **制度**：最重要的不是审批等级，而是“公共标准不得单独闭合不可逆身体接入”的底线。
3. **科技**：快拆、断点、外置器官、身体特异接触面、低分辨状态窗都有了共同来源，不是近未来装饰。
4. **身体观**：这个文明真正先进的不是“能把人改得多离谱”，而是**能让人进入陌生身体状态后仍保有回来的资格**。
5. **城市 / 职业**：门站与维护所自然出现卸装槽、返身位、回接床；专业人员的核心能力之一变成维护返身链，而不仅是安装器官。
6. **日常生活**：普通人会把任务器官“穿上再脱下”，永久融合反而需要非常明确的个人选择；城市因此保留大量个体差异，而不是最终收敛成统一机体模板。

### 删掉十元测试

结果：**PASS**。

删掉符号名字当然仍能写“模块化身体文明”，但无法几乎原样保留这条核心因果：

`稳定公共壳取得巨大成功 → 公共可调用性开始替代对象特异返身证据 → 人仍能被文明正常使用却失去回到自身的资格 → 灾后文明主动拆开公共调用与返身链 → 技术因此故意保留不可标准化的返身断点 → 关键重接必须重新确认对象。`

这不是给现成世界史贴 `x并z/nz/z` 标签，而是十元直接解释了为什么《黎黎隆》的现代身体技术会长成“高度标准化，同时又拒绝彻底标准化”的矛盾形态。
