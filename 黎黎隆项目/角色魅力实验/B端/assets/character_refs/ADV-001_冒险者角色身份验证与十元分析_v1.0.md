## 3. 冒险者身份锁定

### 必须保持

- 宽厚、沉重、扎实的成年男性体型
- 短黑发、浓胡须、疲惫但有经验的眼神
- 深墨青/黑色多层披风与破损布边
- 紫色布片、红色围巾和红色交叉背带
- 白色金属肩部/胸前支架
- 背包、卷起的装备和背部负重
- 腰带、扣具、链条与悬挂的青蓝灯具
- 厚重手套、厚重靴子和青蓝功能色
- 整体“走过很多路、带着很多东西继续走”的视觉感觉

### 禁止改变

- 不与黎黎隆合并
- 不与澈合并
- 不改成纤细少年或干净贵族骑士
- 不删除背包、背带、灯具和披风层次
- 不把披风换成整洁现代装甲
- 不新增角、尾巴、翅膀或无来源的大型武器
- 不抹掉疲惫、沉重和长期旅行留下的痕迹

## 4. H3 验证内容

将原始 JPEG 与本 MD 一起交给 WorkBuddy，用原图作为唯一角色参考。

验证：

1. 正面、45°和近景是否仍是同一个冒险者。

3. 披风层次、红围巾、紫色布片和红色背带是否连续。
4. 背包、卷筒、腰带和扣具是否仍然连接在正确位置。
5. 青蓝灯具是否仍挂在腰部，并保持为可识别的道具/光源。
6. 行走、转身、抬灯或举手时，装备是否随身体合理运动。
7. 表情可以变化，但不能变成另一个脸型或年龄。

## 5. 十元图像初判

本节是基于当前角色图的初判，不是最终冻结人设。故事、姓名、关系对象和具体世界观尚未提供，所以十元强度需要在动作实验后继续校准。

### 主十元：XN｜强度 8/10

冒险者的身份不是“一个穿装备的人”，而是被长期道路、经历和积累塑造出来的人：

- 装备不是一件新衣服，而是许多次旅行后的积累
- 背包、卷筒、扣带和灯具暗示持续移动
- 身体姿态像承受过重量，也熟悉如何继续前进
- 脸部疲惫感使角色带有时间沉淀

因此当前把 **XN** 放在第一位：他的魅力来自“走过之后留下的东西”。

### 次十元：X｜强度 8/10

角色的视觉识别高度依赖装备结构：

- 交叉背带切分身体
- 金属扣具形成明确节点
- 肩部支架、腰带、链条和灯具形成模块系统
- 披风、手套、靴子和背包都有清晰边界

X 让这个角色具有可靠、可生产、可连续保持的结构骨架。

### 中心肉身：N｜强度 7/10

沉重体量、宽厚肩背、疲惫眼神和破损布料使“身体正在承受”成为可见内容。N 不是软弱，而是肉身重量和现实存在感。

### 潜在冲突：NX｜强度 6/10

装备既是能力，也是负担：

```text
携带越多
→ 能做的事情越多
→ 身体越沉
→ 每一次行动都要付出代价
```

这给冒险者提供了很好的矛盾：他不是没有能力，而是能力本身压在身上。

### 关系入口：NZ｜强度 5/10

青蓝灯具是最重要的关系道具。它可以从“我自己的照明工具”转化成：

- 给同伴照路
- 在黑暗中保护某个生命
- 暂时建立安全空间
- 证明冒险者仍然愿意为别人承担重量

当前 NZ 只是可激活方向，需要通过角色与他人的互动验证。

### 组合结构：X并Z｜强度 5/10

冒险者的身体与装备、灯光和环境可以形成一个临时行动系统。若后续实验出现“用背带固定自己、用灯具探路、用披风遮挡危险”等行为，这个十元会增强。

## 7. 推荐动态链

### 首轮推荐：XN → X → NX → NZ

```text
走过很多路
→ 装备形成行动系统
→ 装备同时变成身体负担
→ 冒险者把负担转化为照路和保护
```

适合的动作：

- 冒险者背着沉重装备在黑暗空间中前进
- 背带卡住或灯具摇晃，迫使他停下整理装备
- 他没有丢下灯，而是把灯举高给后方同伴照路
- 最后站在入口处，用身体和披风挡住危险

### 第二候选：X → Z → X并Z

```text
装备原本按固定方式携带
→ 突发障碍迫使他临时改装
→ 身体、装备和环境组成新的行动结构
```

### 第三候选：N → NX → NZ

```text
身体已经疲惫
→ 负重让行动变得困难
→ 他仍用灯具为别人保留一条安全路径
```
