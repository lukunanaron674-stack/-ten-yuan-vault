# B端 → 云端 Work｜H3 图像验证交接与单角色叙事规范 v1.1

> 继承 `B端_Work验证交接与澈MV风格基准_v1.0.md` 中真实原图、三名角色身份/视图、Picture 和待验证状态的**事实性核验内容**；覆盖其 D/E 的 MV 风格和镜头/音乐要求。旧文档仅供历史追溯，新轮次以本文件为准。

## 本轮运行模式（Work 必看）

- 输出：单角色连续叙事短片；**禁止 MV、音乐卡点蒙太奇、多人角色轮播和为展示多个视图而分屏**。如果需要声音，只作为环境和事件音效。
- 一条任务只选择一个 character_id。即使 B端轮换角色，也不得把两轮的角色图片混绑到同一条视频。
- Picture 1/2 的角色全身、半身、正面、45°、四宫格都属于**同一个角色的参考视图**；Picture 3（如有）是场景。不可按参考图个数生成相同数量的人物。
- 全片同一时刻最多一个角色实体；**不出现第二个人物，更不能同屏复制同一人物**。禁止分身、同屏正面+侧面、画中画、完整人物镜像/倒影、残影双人、复制的角色影子或海报屏幕人物。允许切镜头、单人转身和出画后重入，前提是身份、服装、动作、空间关系连续。
- 场景作为环境阻碍，道具作为行动对象；不引入第二个具人形身份的主体。不以复制人物表达十元生克补关系。

## 每轮 WORK_VALIDATION.md 增加的验收项目

```yaml
video_mode: single_character_narrative
on_screen_character_count_max: 1
other_characters_allowed: false
duplicate_instance_allowed: false
style_reference_version: null
image_validation: pending_image_validation
render_claim_from_b_end: not_rendered_by_b_end
```

- [ ] 检查真实原图、ID、素材视图及 Picture 映射正确：所有人物参考都为同一名被选角色。
- [ ] 检查首帧、中间镜头、尾帧：始终只有一个人物实体；没有第二个角色、克隆、镜中/水中重复的完整人物、分屏和误将四宫格多视图变成多人。
- [ ] 跨镜头同一张脸、同一服装与身体结构、动作方向连续；若出现第二个角色实体则失败并在 Work 端修复/重跑。
- [ ] 不调用旧版澈 MV 风格/配乐/镜头卡点任务模板；画风和氛围根据本轮角色原图、所选场景和项目色卡确定。

Work 自行验证并决定是否渲染；B端不因待验证停止继续写下一轮描述词。没有实测凭据时不能报通过。
