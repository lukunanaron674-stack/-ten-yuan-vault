# 黎黎隆角色魅力实验｜B端

本目录是 B 端的唯一交接入口：用角色十元结构、场景十元结构和动态链，生成可交给 C 端/H3 的视频描述词。

## 核心链路

角色素材与场景素材
→ 十元关系
→ 动态链变化
→ 可观察动作
→ MV镜头语言
→ H3视频描述词

## 云端 B 端每小时任务

1. 读取 `tasks/inbox/*.json`。
2. 读取任务中的角色、场景、动态链与 `must_keep`。
3. 读取仓库中的角色卡、场景卡和动态链规则。
4. 生成一份结构化视频描述词 JSON，写入 `prompts/generated/`。
5. 将已处理任务移动到 `tasks/done/`，并把运行记录追加到 `logs/B_worker.jsonl`。
6. 每轮提交并推送 GitHub main。

## 本轮任务

- 输入：`tasks/inbox/LILLONG_MV_TEST_002.json`
