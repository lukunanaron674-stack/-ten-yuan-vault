## 0. 先说清楚：什么叫“对标”

**创作链**：我希望观众对这个人产生的感受（具体人际句） → 提出一个或多个**十元候选**（内部解释，并记录竞争解释） → 从下文挑选可拍摄的**景别／光影／天气／构图／动作／声音方案** → 用已有角色图＋场景图做 H3 实验动画 → 不告知意图与十元，让观察者描述实际感受 → 按画面证据与感受反馈保留、修订或否定十元候选。

**观测链**：已有画面 → 先记录“我具体感到什么、感到谁在怎样对待谁” → 再记录画面证据 → 才尝试十元分析；不允许从天气、机位、颜色、职业或角色装备直接反推出十元。

这里的“十元是什么景别／天气／光影”在执行上等于：**当目标感受的十元假设是某个候选时，哪些镜头手段值得尝试？在什么人、什么事件下可能奏效？哪些反例能推翻？** 不是“某一十元只能使用某一种镜头”。

一个十元可尝试全部景别、全部光影、全部天气；一个景别／天气也可能服务多种十元感受。下面的候选只帮助选择实验，不代替回看画面。

## 1. 人对人的五层感受：先锁研究对象

| 层次 | 记录的是什么 | 询问方式 |
|---|---|---|
| 背景感受 | A 长期处于什么样的关系／生活环境，习惯怎样对待别人 | “他为什么会把这样做当作正常？”不得凭服饰、身份猜测背景 |
| 表达意图 | A 想让 B 感受到什么 | “他想让对方觉得被照顾、被尊重，还是被要求服从？” |
| 实际行为 | A 实际做了什么，客观上改变了什么 | “谁掌握出口，谁退让了，物品有没有递到手？” |
| 接收感受 | B 基于自身背景，**实际上**怎么理解 A 的行为 | “A 觉得自己在保护，B 是否反而觉得被控制？”在单角视频中 B 可为画外对象，但实际的 B 感受若未表现，必须标记推测 |
| 观众感受 | 观众此刻对 A／B／双方关系产生什么印象 | “这个人让我觉得可靠、亲近、有威胁、可怜，还是读不懂？” |

**人物意图 ≠ 接收者的感受 ≠ 观众的感受 ≠ 角色稳定十元。** 当这些层次错位，错位本身是实验变量和剧情动力，而不是“标错了就强行纠正”。

## 2. 十元候选 × 人际感受 × 可尝试的镜头方案（不是定性词典）

下表每条“我感觉”只是创作测试的**候选感受句**，实际仍需核实核心操作。不要将“可靠＝XN”“温暖＝NZ”“阴影＝XZ”等写成等号。

| 十元候选 | 观察者可能说出的具体感受句（待验证） | 必须进一步检查的关系／行动事实 | 景别／光影／天气／声音**可试**方案 | 必试反例／误判 |
|---|---|---|---|---|
| ZX | “他不等别人同意就替所有人决定，我既被他带动又有点害怕。” | 主体自身权能是否真的占据方向源、公开施加并压退竞争方向 | 全身中景见其越过他者决定位置；低机位＋清楚的选择后果；逆光／晴天／暴雨均可试 | 低机位也可能是在拍弱小者；一次果断行动不证明长期 ZX |
| NX | “他明明有自己的想法，却还是顺着对方的路走，我感到他很委屈，或很安心。” | 最终方向由谁决定？主体是否沿既有关系、权限、路线续接 | 保留既有路径的宽中景；视线跟随画外方向；漫射光或坚硬侧光做对照 | 顺路行走不等于让出方向；服从可能被读为信任，也可能被读为压抑 |
| ZN | “他知道自己为什么不肯让步，但没有把别人也当作无价值的人。” | 是否保留自己与他者独立意义、选择、成立资格 | 平视中近景保留他人与退路的空间；稳定侧光或低反差光两版本；保留短停顿 | 正面居中可能只是自拍感；一次坚持不能直接等于 ZN |
| X | “他把东西和界限攥在手里，我不确定他是在守护还是占有。” | 资源、地盘、权限或对象是否实际进入可掌握与处分边界 | 手与物件的近景→全身交代控制范围；窄／宽空间两版；硬／软光两版 | 拿起物品不一定实际控制；柔光不自动代表善意 |
| N | “他真的给我留下位置，愿意承受我带来的麻烦，我能待下来了。” | 对象是否进入内部，负荷是否被真实接住并持续承担 | 全景交代可进入的空间→中景见持续处理；遮风的室内暖光／阴雨室外的有效庇护做对照 | 只有暖灯和房屋而未接住任何人，不能判 N |
| X并Z | “我看得懂他向外展示的身份，却不知道那层外壳能否代表真实的他。” | 是否存在稳定可识别／调用／代表／进入的公共壳及内外映射 | 远景先识别身份界面→近景检验内外一致；正面照明或局部遮挡分别测试 | 制服、门牌、面具只是外观，不自动形成稳定公共接口 |
| XN | “他不是临时逞强，而是把事情一环一环安排得能持续运转，我觉得踏实，或觉得喘不过气。” | 主体是否主动组织顺序、规则、信息和资源，使结构跨时间运行 | 稳定中全景呈现处理顺序＋局部细节；均匀光／机械脉冲／雨天流程持续三个候选 | 对称、监控感、机械设施可能被读为压迫；被动遵守既有制度不等于 XN |
| Z | “他只认那一个最重要的对象／判断，对其他人的反应几乎不再在意。” | 是否有一对象成为判断中心，其他对象是否被排出此中心；认可仅在满足条件时作子型 | 目光定向的近景与另一个可选对象同框／反打；孤立光源或均匀光对照 | 特写和聚光不能替代选择证据；“想被夸奖”不直接判 Z |
| XZ | “他再不做决定就没路了，我感觉他随时可能失去返回的机会。” | 路线、时间窗、退路或可逆空间是否真的收窄 | 宽景先建立出口→中景显示退路变化；晴／雨／雾三个版本；光从明到暗或始终明亮对照 | 只有黑暗、奔跑和危机音乐，缺少实际退路变化，不足判 XZ |
| NZ | “他和那里／那个人好像还有未断的牵挂，我觉得他会回来，或至少舍不得就这样结束。” | 是否存在对象特异的回返、修复或连接路径被保存／重开 | 环境中景保留原位置→角色回望同一具体对象；夕照／冷月／雨后晴光交叉测试 | 暖色、怀旧滤镜、单次善意不自动判 NZ；没有可信回返对象时要悬置 |

说明：景别、天气和光影列**不宣称实验效果**；每一行都应当留至少一个相反手段的对照，例如“晴天下的危险”“暴雨中的被接住”“特写中的放手”。核心关系事实来自上游十元正本，表内人际口吻只是给观众盲审设计的起始假设。

## 3. 全候选视觉／听觉轴：把“所有可能性”变成能排列组合的参数池

**“全”指先覆盖可操作的候选轴和基本选项，不声称把所有电影语言、天气物理条件或所有轴的笛卡尔积一次穷尽。** 不对每个参数预先贴十元；每次只挑能服务**目标感受**的几个可执行候选，并保留不同路径。

| 轴 | 候选选项（可新增） | 必须观察的人际感受差异 |
|---|---|---|
| 景别 | 大远景、远景、全景、中全景、中景、中近景、近景、特写、局部物件特写 | 我看见这个人被环境包裹、我被迫贴近他，还是能看清他对物件和对方做了什么？ |
| 机位 | 平视、略俯、略仰、极俯、极仰、主观视角、过肩、侧面、背面、45° | 我与角色像平等面对面、旁观、仰视、窥视，还是跟随？角度也受角色动作影响 |
| 镜头运动 | 固定、缓推、缓拉、横移、跟拍、轻摇、主观转向、切镜／不切镜 | 我是接近、被拒之门外、失去对角色的把握，还是看清关系？ |
| 构图 | 居中／偏置、对称／非对称、封闭／开放空间、疏密、高／低留白、前景遮挡、出口在画内／外、角色与物的距离 | 谁占了空间，谁有出口，谁在替谁承担；不可把“留白”当孤独等号 |
| 人物与物件 | 身体朝向、距离、看／回避目光、伸手／收手、让路／封路、接物／不接、靠近／后退、停顿／连续、回返／离开、负重变化 | 他想表达的、他实际做的、对方可能感到的，有没有错位？ |
| 光源与方向 | 正面、侧面、逆光、顶光、底光、轮廓光、环境反射光、局部点光、多光源 | 我更能看清他的脸、边界或动作，还是因为看不清而不安？ |
| 光比与质地 | 高／中／低光比、硬／柔光、亮部细节保留／剪影、静止／闪烁、广域／局部光、均匀／不均匀照明 | 他显得可接近、难以读懂、被保护或暴露？结果必须看片，不由参数决定 |
| 色彩 | 单一色铺满、双／三／五色主导、不同面积比例、低／高饱和、暖冷并置、交互色、角色色与背景色分离／融合 | 角色是被看见、被吞没，还是与场景发生关系？优先读取项目色卡规则，不强制五色固定占比 |
| 天气与空气 | 晴、阴、薄云、厚云、雾、薄雾、细雨、大雨、雨后、雪、风、静风、沙尘／烟尘（仅场景允许）、湿地反光 | 角色是否因天气改变了选择、距离、退路、照顾方式或可见性？天气自身不属于某十元 |
| 时间／环境 | 黎明、早晨、正午、黄昏、夜间；室内／室外；城市、森林、湖岸、村落、机械空港 | 人是否因为时间窗、空间或已有关系而对角色改变看法？不得只靠“黄昏＝怀旧” |
| 节奏／声音 | 快／慢起步、停顿长度、环境声前后景、近远脚步／机械声、沉默、情绪音有／无、弱／强混响 | 哪一个**实际可听可见的节点**使感受发生变化？声音辅助，不做 MV 音乐卡点 |

参数组合规则：**先保护身份、地理、事件、角色动作与十元候选的可观察关系证据；再选择一个目标视觉轴进行 A/B 控变量；确认初步稳定后才尝试双轴交互、景别＋天气＋光影复合方案。** 如果天气变化要求新增原图未存在的几何或破坏原场景身份，应拒绝该试次或标记需要补场景。

## 4. 十元候选 → 视听参数选取表（每张实验卡必须填）

| 字段 | 填写规范 |
|---|---|
| `target_viewer_feeling` | “看完这个人，我觉得……因为……”；不用十元术语；写清感受对象是角色还是双方关系 |
| `ten_yuan_primary / secondary` | 候选主／次和上游正本对应核心操作；`competing_hypothesis` 必填，允许无法判断 |
| `relationship_evidence` | 人物／物件／路径／意义／边界实际有什么变化；十元要靠这个成立，不靠光线名称 |
| `scene_id / character_id` | 已入索引真实 ID，源路径和哈希；验证图像真实存在后绑定 Picture 1/2 |
| `shot_options` | 至少两种不同景别或机位选择，并分别写可能改变的**观众感受**及其反例 |
| `light_options` | 至少两种光源方向／光比方案；写画面可见性与关系作用，不填固定十元 |
| `weather_options` | 当前场景可行的天气版本（含“保持原天气”对照）；若变更场景拓扑则禁止 |
| `performance_cue` | 实际做了什么、停在哪一帧、如何让人看出选择结果 |
| `expected / observed / competing` | 创作期望、成片观察、竞争解释三栏分开，缺项填 pending |
| `viewer_blind_response` | 不告知十元／目标感受，记录自由描述、证据时刻及相反读法 |
| `next_action` | 保留／换一种镜头／只调一个变量／修正十元假设／素材或技术失效后重跑 |

**同一十元主候选至少收集两种不同视听参数组合、两个不同角色或情境，才开始讨论是否具有跨情境可重复性；没做盲审之前，只能称“候选对标”，不能称“十元感受已验证”。**

### 首轮可执行实验：角色不变，验证“看似冷漠 vs 其实留出位置”

- 素材：`ADV-001` 冒险者 ＋ `SCENE-05` 机械空港，或验证已有更合适的机械空港图后换用真实 scene_id；原图是否真的包含门、通道、入口和落脚空间必须由 Work 目视核对，**没有就换成画面实际存在的障碍**。
- 人际感受目标：观众起初认为“他只顾自己、冷静到不近人情”；后来看见他为一个**已在画面中有迹可循**的画外对象留出安全通过的位置，产生“他没有说好听的话，但愿意让我先走”的新印象。若没有画外对象的可信存在证据，目标改为角色面对**真实负重／空间阻碍时**的谨慎与可靠，不伪称“他在照顾另一人”。
- 十元候选（**尚未判定**）：如果行为是放弃即时决定权、沿可通行路径行动，可测试 NX；如果确实接住另一个对象的负荷和持续位置，可测试 N；如果只维持自己的负重安排，可考虑 XN 或普通谨慎。**不能因为镜头变暖就判 N/NZ。**
- A/B 景别试次：A 固定中全景，画清人物、可用路径与其留出的空间；B 在**同一段真实事件**中从中全景缓慢推至中近景后保留空间与物件关系。若希望真正测试景别效应，A/B 使用相同人物／场景／动作／天气／光影／提示词公共部分，且尽量固定 seed；每个条件分别 run_A/run_B，比较每一条件独立成片。不要拿不同 seed 的两帧直接宣称“景别导致感受变化”。
- 验证：盲看者不读词卡，自由回答“这个人让你想到怎样的人”“从哪个动作或时刻改变了看法”“还可能怎样解释”。若只被读为“负重后停一下”，则**感受目标未证明**，先修动作事实／视听证据，再考虑换景别或十元解释。
- 进入下一轮前，先核验当前视频参数、参考图 SHA、输出 SHA、关键帧真实性；风格稳定、动作成立、感受达成、十元关系成立**四项分开判**。

## 6. 分轮实验矩阵：避免“跑出了图就算验证”

| 轮次 | 控制与变化 | 回答什么问题 | 合格证据 |
|---|---|---|---|
| R0 真实素材基线 | 锁角色图、场景图、版本号与输入哈希；低动作低风险 | 角色和场景在 H3 中是否稳定存在？ | 原始素材 ID／路径／SHA、真实输出／首中尾帧 |
| R1 感受基线 | 同一角色与事件，固定基础镜头／光影／天气，双抽 | 不提示十元时，观众**实际**感到什么？ | 原句反馈＋指认的画面时刻；与创作预期分开 |
| R2 景别 | 保持角色、场景、动作、天气、光照不变；只改景别或机位 | 哪一版本更容易传达目标人际感受？ | 每条件独立双抽；原图几何与角色未被破坏 |
| R3 光影 | 固定其它条件，只改一个可执行光照因素 | 感受变化能否由光影单独解释？ | 记录亮暗、脸／手／路径可见性与观众真实读法 |
| R4 天气 | 固定其它条件，只改天气或保持原天气 | 天气是否改变了观众对**这个角色的行为**的理解？ | 角色动作与场景身份仍匹配；不许凭新增虚构门路过关 |
| R5 交互 | 在 R2–R4 有初步证据后再做景别×光影等组合 | 哪些组合相互加强、抵消或产生反向读法？ | 同变量对照、样本数、生成失败分开记 |
| R6 跨场景／角色 | 使用另一张真实场景或另一角色重复核心关系，允许感受不同 | 是普遍视听手段的影响，还是仅该角色／场景成立？ | 正反例、不同背景观众反馈、十元假设修订记录 |
| R7 动态链 | 经验证的两个或多个感受节点起→变→终；核验上游正式生克补机制 | 感受**之间的关系**是否成立，而非“十元标签按时出现”？ | 逐节点可观察关系事实＋盲审感受变化；生成后允许链条不成立 |

**样本记录**：单一观众印象只能记个案；多人样本记录人数、匿名背景相关因素（仅在自愿且必要时）、原始描述、分歧与不确定性。主观感受可能因文化、经历、画风偏好而不同，不能强迫统一。失败分为技术失败／角色身份失败／情节信息不足／感受不符／十元关系不成立，不能合并成一项“模型失败”。
