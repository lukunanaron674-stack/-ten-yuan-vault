# 《黎黎隆》B端｜角色感受实验总规 v1.0

生效：2026-09-24 起新增轮次。旧文件、旧轮次、原始输出及验收证据保留，不回写或伪造历史结论。

## 0. 研究目标与命名

本端对外名称为「B端｜角色感受实验」；「角色魅力」是长期研究目标，不以讨喜、好感或单一情绪代替全部魅力。核心研究对象是**一个观众面对一个角色时，产生怎样的感受，以及这种感受为何、如何变化**。角色自己感受什么，与观众对角色感受什么，分别记录，不得混写。可观察画面事实、创作预期、观众反馈与十元解释必须分层。

优先顺序：观众初见感受假设 → 观众感受变化目标 → 可观察的角色行为、外部条件和镜头 → 十元生/克/补动态关系假设及可证伪线索 → H3实拍/生成 → 不提示标签的观众反馈 → 复核归因与迭代。十元不是先验答案，也不能把装备特征或动作完成直接判定为某种观众感受。

## 1. 每轮起点：感受假设卡

每轮先填以下字段；必须用人对人的日常表达，允许好奇、信任、疏离、怜惜、敬畏、担忧、厌恶等不同方向；不得把感受写成十元标签或要求观众学会术语。

- `viewer_first_impression`：初看这个人，我觉得他/她是怎样的人？一两句可感的关系印象。
- `viewer_shift_trigger`：哪个具体可见时刻可能改变我对这个人的看法？只写候选触发，不假称已生效。
- `viewer_final_impression`：片段结束时，我可能怎样看待这个人？允许感受并存、矛盾或没有变化。
- `character_internal_state_hypothesis`：角色自身情绪/意图的创作假设，明确与观众感受不同；无法从画面确认时标注推测。
- `observable_cues`：为初见→变化→结束各自列出身体姿态、视线、停顿、物件关系、空间阻碍和镜头证据。
- `disconfirming_cues`：如果观众看不懂、只觉得在机械做动作、解读相反或画面发生身份漂移，应怎样判定假设不成立。

不要求每轮都出现强烈情绪反转；「感受一直未变」同样可作为研究结果。禁止把单个描述词的意图等同于实际观众体验。

## 2. 十元关系：解释层，不代替感受层

保留现有角色十元冻结项、动态链主/次、方向、生/克/补、体量和阶段变化；仅在内部结构字段写明：`ten_yuan_hypothesis`、`relation_shape`、`chain_start/change/end`、`evidence`、`alternative_interpretations`。十元推论不得由单一动作、服装或关键词直接推出；不得把未验证的感受映射写成冻结定义。B端对 H3 的最终可执行正文只保留可拍到、可听到的动作、条件与节奏，不直接命令模型呈现抽象标签。

## 3. B1→B4 的职责

- B1 素材：直接使用已核实的角色参考图与场景原图或素材路径，筛选身份、适配、镜头用途；轻量索引即可，不强制逐图文字百科。图像供云端4090D/Work真实绑定，文字任务只引用真实ID、路径/哈希，不假称已取图。
- B2 感受与十元：先写观众感受假设、触发点及替代读法，再形成十元关系和动态链候选，逐阶段给出可见证据与证伪信号。
- B3 H3编译：把「可能引发感受」转为可观察连续事件和镜头，确保角色身份、场景、物件拓扑、情绪节奏与音效服务叙事；禁止MV式卡点，禁止第二角色和分身；不将心理形容词当成模型可以直接执行的镜头指令。
- B4 双层审核：第一层为技术/画面事实（身份、装备、镜头、空间、动作、帧连续、真输出）；第二层为不向观众透露预期或十元标签的主观感受反馈（初见、变化、最终、具体触发画面）。B4分别记录「预期」「观察」「解释」「不支持/歧义」，不可用自产任务的自评代替真实观众盲审。

## 4. H3 执行约束，不因改名撤销

- 视频输出沿用当前生产规则：10–11秒（目标11秒）、16:9横屏；9:16仅为角色参考四宫格，不得套用到成片。每条描述词独立双抽 `run_A`、`run_B`；需按现实服务可用参数执行，不伪造seed、帧率、成片、音轨。
- 镜头时间按真实变化节点分配，不机械切成两秒一段。以可见动作驱动景别变化；声音为 `ambient_soundscape`、`emotional_sound_cue`、`audio_role`，只辅助动作和情绪，不做MV。H3不支持生成音频时仅记录后期音效需求。
- 角色必须单实例且身份、装备和动作连续；Picture 1锁角色，Picture 2锁场景空间/色彩而不锁死实际景别。参考图是否真实存在、Work绑定及视觉几何核验独立记录。角色卡9:16不代表视频9:16。
- 真实视频可存云端；GitHub优先传首/中/尾关键帧、对应源视频SHA-256、真实运行ID/路径、质量反馈；若节点驱动抽帧更有代表性，可补充pre/onset/peak/post帧并说明取帧原因。未经核验不得宣称「已生成」「风格稳定」「审核通过」或「已回传」。

## 5. 下一轮任务的最小字段与验收

新增结构字段：`viewer_impression_hypothesis: {first, shift, final, trigger, alternative, disconfirming_cue}`；`ten_yuan_explanation`（内部）；`visual_execution_cues`（给H3）；`blind_viewer_feedback: {first, shift, final, moment, ambiguity, reviewer_type}`；`comparison: {intent_vs_observation, technical_status, human_feedback_status}`。未取得观众反馈时，`blind_viewer_feedback` 必须标记 `pending`，不得生成虚拟观众结论。
