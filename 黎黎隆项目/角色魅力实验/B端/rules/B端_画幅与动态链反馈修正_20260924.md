## 1. 画幅纠正（必须立即执行）
- 角色参考图可使用 9:16 竖图及现有四宫格，这是输入素材的比例，不是视频输出比例。
- H3 成片及其首/中/尾帧输出必须为 16:9 横屏。使用实际工作流支持的横屏尺寸，核对 width > height；目标比例约 16/9，记录真实宽高及偏差，勿无理由重渲旧片。
- 删除/停用所有把动画输出设为 `vertical 9:16`、要求 `width < height`、把横屏拒跑的规则和提示词。旧 B4 把 R35 的 1280×736 因横屏判 FAIL 是错误结论，撤销；1280×736 虽然是横屏，但不等于精确 16:9，应仅单列比例偏差，不作“竖屏失败”。旧的真实渲染和哈希记录不改。
- 若输入图为 9:16，须在横屏成片内合理安排角色，不可把原图比例错当成输出比例；不得为了画幅而改角色身份。

## 3. 反馈必须服务十元动态链研究，不只服务画质
B2 在渲染前先冻结一个可反驳的预注册假设：主体/次级十元、起始体量、方向明确的生/克/补关系、环境刺激、角色动作、终局状态，逐阶段列 `predicted_visible_cue` 及 `disconfirming_cue`。H3 执行 prompt 只含可见故事动作，不出现十元标签。

4090 每个 run 的 3 帧按独立时间点登记这些可观察事实（仅观察，不能自动由画面反推十元）：`stage_visible`（起点/变化/结果）、`character_action`、`environment_change`、`spatial_relationship`、`action_consequence`、`identity_and_camera_continuity`、`visible_evidence`（具体像素证据）、`unobservable_steps`（如声音触发、两帧间的先后顺序）、`alternative_explanation`、`visual_observation_status`（OBSERVED/NOT_OBSERVED/AMBIGUOUS）。另记录各动作预期阶段是否落在采样窗口内；若中帧采不到决定性动作，标 `SAMPLING_MISS`，不能算动态链失败。

B4 分开给出：`INPUT_BINDING`（素材真实加载）、`RENDER_EXECUTION`（真实双抽）、`KEYFRAME_VISUAL`（画面）、`ACTION_SEQUENCE`（离散动作阶段）、`CHAIN_HYPOTHESIS`（推断层）。链假设只能评估 `SUPPORTED_BY_KEYFRAMES / CONTRADICTED_BY_KEYFRAMES / INDETERMINATE`，不得声称三张帧证明十元规律真实成立或全视频动作顺序；未能观看像素则为 `NOT_REVIEWED`。原始观察与解释分开保存，禁止为符合十元预设改写观察。
