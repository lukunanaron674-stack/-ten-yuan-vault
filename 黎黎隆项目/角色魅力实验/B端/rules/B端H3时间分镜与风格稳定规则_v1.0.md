# B端H3时间分镜与风格稳定规则 v1.0

## 固定生产方式

每条任务只使用：

- 一个角色参考图
- 一个场景参考图
- 一个主角
- 一个场景
- 一条连续时间分镜

不做 MV 式多人发散，不出现分身、重复角色或第二个表演主体。

## 时间分镜

视频描述词按时间顺序写：

```text
0–2秒：起始状态
2–4秒：唯一外部刺激或关系变化
4–6秒：角色身体先出现局部反应
6–8秒：角色做出一个小回应
结尾：动作停住，形成清楚结果
```

每个时间段只改变一个小变量。动作必须有因果：前一状态导致后一动作。

## 风格稳定优先级

脸型与身份  
→ 体型比例与剪影  
→ 发型与识别件  
→ 服装结构  
→ 材质与颜色  
→ 动作和镜头

当成片风格不稳定时，先缩小动作幅度，不重设角色，不先修改颜色。

## 默认镜头

固定机位、固定景别、固定光线。默认禁止推镜、摇镜、转场、换天气和突然改色。每条最多一个主要运镜，且必须有明确叙事作用。

## 动作幅度

```text
静止
→ 视线变化
→ 局部先动
→ 轻微转头
→ 小幅抬手或迈步
```

先验证角色画风和脸部稳定，再逐轮增加动作幅度。

## 澈案例吸收范围

吸收澈的生产结构：

- 角色图＋场景图
- 单角色
- 固定镜头优先
- 清楚线面
- 软光
- 连续身份
- 小幅可观察动作

不复制澈的角色造型、颜色、性格或构图。

## 最终H3描述词限制

最终描述词只写：人物、场景、动作、变化、结果。十元和动态链只在 B 端内部使用，不直接写进 H3提示词。
