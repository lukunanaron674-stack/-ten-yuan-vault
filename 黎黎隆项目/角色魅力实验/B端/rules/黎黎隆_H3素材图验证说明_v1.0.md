## 3. 身份锁定（Picture1 承担）

### 3.1 必须保持

- 长机械龙尾的**上 / 中 / 下节奏**
- 红白黑机械装甲 + 青蓝功能信号色
- 红色长发与尖锐好胜的表情
- 机械化身体模块与**机械龙爪脚**
- 单条长机械龙尾（不分叉、不变成双尾）
- 脸型与头身比例与素材图一致

### 3.2 禁止改变

- 不重设角色身份，不新增未确认结构
- 不新增第二角色、分身、镜像完整人物
- 不新增翅膀、武器、额外肢体
- 不改服装主色（红白黑 + 青蓝关节）
- 不把机械龙爪脚换成普通鞋脚
- 不把长机械龙尾缩短、删除或改成普通尾巴
- 不把表情改成另一个脸型或年龄段

## 4. H3 出片验证清单（worker / 审核用）

逐条核对，任一条不通过即 `FAIL`，不得记为 PASS：

1. 全程只有黎黎隆一个角色，无第二角色 / 分身 / 镜像人。
2. 脸型、头身比、红色长发与素材图一致。
3. 机械龙爪脚在各帧都保持机械爪结构，不退化成普通脚。
4. 长机械龙尾始终为**单条、分节、机械质感**，长度与存在感不丢失。
5. 红白黑装甲与青蓝关节配色连续，不出现服装改色。
6. 场景构图与导演选定的 `selected_scene_view` 一致，湖面反光 / 岸线关系连续。
7. 动作幅度在素材图可支撑范围内：不做翅膀飞行、无来源武器、无 3D 塑料质感。
8. 无字幕、Logo、水印、镜头切换、跳帧、闪烁。
