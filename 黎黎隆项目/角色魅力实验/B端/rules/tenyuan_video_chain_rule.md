# 十元动态链驱动视频描述词规则

## 1. 角色核心

黎黎隆的冻结十元结构：

- 主元：ZX
- 中元：Z
- 小元：XN
- Z必须表现为：古灵精怪、机灵、跳脱、出其不意、灵活变通。
- 不把 Z 固定解释成“追查、理解、转译、接口化”。

必须保留的视觉身份：

- 长机械龙尾，保留上/中/下节奏和关节感。
- 机械龙爪脚。
- 两片头盔卡扣。
- 原有脸型、比例和角色身份。
- 不改造成普通龙、普通少女或全新概念角色。

## 2. 动态链编译

`主元 → 受克/受限 → 主元变招 → 关系新状态`

本轮：

`ZX主动发起 → XN结构限制 → Z机灵改道 → NZ与环境重新建立关系`

每一段都必须写清楚：

- 当前状态
- 谁/什么施加限制
- 角色可观察的动作
- 镜头如何表现变化
- 变化后的关系状态

## 3. 生成约束

- 动态链是视频结构，不是标签堆叠。
- 每个十元关系必须落到动作、空间或镜头变化。
- 角色魅力来自“想赢导致局面复杂，再用机灵变招”。
- 场景使用暖天空、冷湖面、森林；场景不能吞掉角色剪影。
- 禁止画面文字、字幕、logo、随机符号。
- 禁止新增未授权服装、武器、翅膀或身体结构。
- 输出必须包含开场、压制、改道、魅力展示、收束五段。

## 4. 评价重点

1. 黎黎隆身份是否稳定。
2. 长机械龙尾是否持续可见并参与动作。
3. ZX→XN→Z→NZ 是否能被看懂。
4. 好胜、机灵、行动力是否通过动作而不是形容词出现。
5. 镜头是否有 MV 节奏且服务动态链。
