## A｜理论层：十元为什么能辅助世界观架构

### A.1 命题

- **十元 = 单一宏量对象的十个划分映射**：任何宏量对象（一个世界、一个区域、一个场景、一个角色、一件道具）都可以投影为十元十个刻度上的感觉分布。
- **世界观元素也是宏量的**：发散产生的元素池（场景词库、职业群、诡异渗出点、服装母题……）天然量大而无序。
- 两者**同构** → 十元可以充当世界观的"感觉坐标系"：一边收（把宏量元素归位），一边放（沿某个刻度定向发散）。

### A.2 三个作用

| 作用 | 方向 | 操作 |
|---|---|---|
| **① 覆盖审计（收敛）** | 元素池 → 十元投影 | 把已有元素逐个标注落在哪一元；某元空格 = 世界感觉缺一个维度，不是错误，是缺口提示 |
| **② 定向发散（生成）** | 十元刻度 → 新元素 | 发散不再随机：选定感觉偏弱的元作为当轮发散轴，沿它生成场景/职业/事件素材 |
| **③ 分层同构（统一感）** | 递归投影 | 世界级 → 区域级 → 场景级 → 角色/道具，每层都做同一张十格投影；层间同构 = 世界感觉统一的来源，层间错格 = 张力素材 |

### A.3 边界（防滥用）

1. 十元概括**感觉与动态**，不概括**事实**——地理、经济、历史事件仍需正面搭建；映射 ≠ 领土。
2. 五大主题（因果/本体/空间/时间/命运）是十元在叙事领域的 is-a 狭义聚合（见 `02-五大主题` 正本 v1.1），本文件不另造第二套映射。
3. 铁边界 #2 / #6 / #8 原样生效：头像不证明十元；五色不当十元本体；端点必须有「谁→对谁→机制→变量前后态」行动证据。

## C｜四个实操接口

### C.1 行为审计（对应总卷 §12 指导层）

- 写前：每章/每镜一句十元动态链（黎黎隆 zx 想 → xn 变招 → 被 nz 克）。
- 写后：对照锁定点位强度（黎黎隆 zx8+xn3 / 塔汀 nz8+nx6+x3）查跑元。
- 与视觉验收五问并列成**双 gate**：五问拦"画错"，十元拦"演错"。

### C.2 60 人池生克配平（待办 2/3）

- 逐人填十元候选句，格式强制 = 铁边界 #8：`谁 → 对谁 → 机制 → 变量前后态`。
- 群级配平：8 个职能群（维护/记录/门站/道路/居住/生态/表演/生计）各自检查生、克、补三向覆盖；缺克向的群 = 全员服务型工具人风险，优先补。
- 本文件 B 节的 zn 缺口提示同样适用于池级：表演/社交群可适度加重 zn 感。

### C.3 S 线映射旁证（待办 1，最大悬案）

- 十元指纹只作**合并的辅助证据**：S 卡与 H/N 编号须"十元句一致 + 行为证据一致"双条件才允许认领。
- 单独十元一致 ≠ 证据（铁边界 #2/#8 直接引用）。
- 79 人潜在重叠先过双条件筛，把候选合并对数压到最小再人工裁决。

### C.4 异证回环 z 调度标注（线A 机制候选）

- 异证回环本质 = z（主体资格确认）的公共化调度。六步逐步标注变量前后态：

| 步 | 十元标注（候选） |
|---|---|
| 1 私域发生 | x 在私人边界内成立 |
| 2 异证相遇 | 多个 z 的 x 描述冲突，先记录不裁定 |
| 3 暂时共证 | n 接管：可撤回的公共记录 |
| 4 有限决定 | z 有限让渡 + 写明退出（可逆） |
| 5 生活回响 | 后果成为新 x，回流 |
| 6 回听或封存 | xz：封存可重开，z 资格可再议 |

- 用途：线A 写作时任何"证词/记录/决定"情节都可对照本表查机制不崩；待办 4（独立世界 or 反补旧正本）拍板前仅作观察轴。
