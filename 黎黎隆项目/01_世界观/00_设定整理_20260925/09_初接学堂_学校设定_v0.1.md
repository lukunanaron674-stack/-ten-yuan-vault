# 初接学堂｜学校设定 v0.1

> **一句话**：这个世界唯一一个"还没回答问题的人"被集中保管的地方。
> 白桶 = 未回答者。学校 = 回答发生之前的地方。**毕业考 = 第一次身体决定。**

## 1｜定位

- **谁办**：名义城立（门站带旁），实际**无桶**——见 §4 校长铁律
- **收谁**：觉醒前年龄的白桶孩子；也收各桶送来的"回炉生"（定了桶又想重新想的成年人，学费翻倍）
- **为什么建在门站带**（SC-06）：返身门站管"人回来"，身份门站管"人是谁"——**初接学堂管"人第一次成为谁"**。三站一线，城里的身份流水线

## 2｜三科课程

| 科 | 内容 | 谁来教 |
|---|---|---|
| **身体常识** | 接口怎么装/怎么拆/坏了什么样/黑市场货和登记货差在哪 | O1 教派外派技师（领课时费，课上不许传教） |
| **桶见学** | 五桶各见学一周：船队漂一周、哑区住一周、菌林守一夜、维护站跟班、庭旁听一场审判 | 各组织接待（O2 只收自愿者，不收整班） |
| **自决课** | 唯一必考课。作业只有一道题：**写出"我的身体谁做主"的答案**。答案没有对错，只判"你想过没有"——抄来的答案不给分 | 校长亲自上（全校唯一校长任教科目） |

## 3｜毕业考 = 第一次身体决定

1. **接入**：装第一枚基础接口 → 定青桶方向（O1/O6 二选一签约）
2. **空手**：零接入离校 → 进 O2 哑区 пути或独立生活（红桶船队常来码头接人）
3. **延后**：保留白桶身份一年，**最多延三次**——三次用完还不选，档案转黑桶"不可知"（校方唯一的强制项，也是全校争议最大的规则）

- O6 在校内设**奖学金**：签接入合同抵学费——O3 盯着这条：合同附强制条款即构成"闭决"罪。每年毕业季庭都派人来旁听签约
- O2 认为学校本身就是组织化的"替人决定"——但每年照旧来接走几个空手毕业生

## 4｜校长铁律（全校唯一的硬制度）

**校长终身不得定桶。**

- 校长必须从白桶中选出，任职期间保持未觉醒、零接入——保证学校不属于任何桶
- 校长说不出"哪个桶更好"——这是资格，不是缺陷
- 现任校长已任职年数不明（档案在身份门站，校方拒绝查询——为什么拒绝，是悬案）

## 5｜边界事件（故事素材，可直接用）

1. **逃考季**：毕业考当天翻墙走的孩子——墙外等他的是 O6 的合同贩子（免费生命周期维护，签二十年）
2. **反向答案**：孩子写的自决课答案与父母桶位相反，父母到校要求"改答案"——校长引用铁律拒绝，家庭矛盾变成 O3 的潜在案子
3. **觉醒事件**：某个白桶孩子在菌林见学夜里长出了第一片活膜——白转粉，学校建校以来第三次；O5 来接人，O1 来登记，学校只负责盖了个"到站"章
4. **校长的十元**：传闻校长的答案卷写的是"没有人做主，包括我"——交了白卷却拿了满分

## 6｜与既有设定的咬合

- **晞棠（CH-014）**：遗蜕共生者当年就是初接学堂的逃考生——她的毕业考答案卷至今留在校长抽屉里，写的什么没人知道
- **O3 判例**：前述"母亲擅自给失明孩子装眼"判例就发生在毕业季——庭的巡回庭每年在校门口开庭一次
- **主导色**：淡青灰（中性世界色——学校不属于任何桶，画面留白最大化，五桶色只出现在各见学区）

## 7｜场景与素材挂点

- **新增场景槽位 SC-11：初接学堂**（主导色淡青灰）——单幅 + 四宫格（四格：①全景校舍 ②自决课教室 ③毕业考签约台 ④极端态：逃考夜的墙）
- 每小时故事发散可用：毕业季/逃考/定桶日/回炉生/觉醒事件 五类前提种子
