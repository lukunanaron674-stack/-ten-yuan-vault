# 六组织设定 v0.1

> 全部组织挂在世界观唯一核心议题上：**谁有权决定你的身体**。每个组织就是对这个问题的不同答案——组织间冲突不需要阴谋，答案不同就够了。

## 0｜立场总表（一张图看懂）

| 组织 | 桶 | 对"谁决定你的身体"的回答 |
|---|---|---|
| O1 钢铁教派 | 青 | **维护者**——身体是设施，按规程维护即自由 |
| O6 青色商会 | 青 | **市场**——接入权可以买，谁付费谁决定 |
| O4 船队 | 红 | **本人**——航线与身体一样，只走自己选的 |
| O3 审判之庭 | 红 | **本人，但越界者受审**——替别人决定是重罪 |
| O2 佛教 | 红 | **无人有权**——身体完整性是修行前提，植入即破戒 |
| O5 生态共生 | 粉 | **双方**——共生须两个生命都同意（对人、对遗蜕皆然） |
| 诡异魔法 | 粉 | **不可回答**——每个人的术法只属于自己，无法标准化 |
| 白桶 | 白 | **还没想过**——未觉醒者，各组织的潜在争夺对象 |
| 黑桶 | 黑 | **不可知**——拒绝被回答的人 |


## O1 钢铁教派（青）

- **一句话**：把维护做成宗教的工程纪律团——身体是设施，设施就该有年检。
- **信条**：接入即圣礼，维护即修行；**可拆卸 = 可自由**。
- **职能/地盘**：维护街带（热维护站、排雾渠）、东门/门站值守；城里一切接口的"保修章"。
- **铁规则**：
  1. 一切改造**必须登记且可拆卸**——不可逆改造是异端
  2. 维护配额按人头发，**不得转让**（防商会收配额放贷）
  3. 黑市永久改造者不烧不逐，**只拒绝维护**——让身体自己慢慢出问题（冷暴力式惩罚）
- **可测试边界事件**：年检季——某人的接口是黑市场货，报不报？报=他被教派除籍，不报=违反教规。
- **代表角色**：H06 接口复核员（I级核心）、CH-011 壳缝检修员。
- **对其他组织**：与 O6 争夺"接入定价权"（教派定维护价，商会定接入价）；与 O5 世仇——**活膜不可维护**，直接否定了教派的整个前提。

## O2 佛教（红）

- **一句话**：唯一把"不改造"修成法门的组织——苦修抑制，拒绝植入。
- **信条**：身体完整性 = 修行前提；**绝植入**（仅约束僧侣/佛教徒自身，不强迫外人——红派反对的是"替人决定"，僧侣替自己决定不植入恰恰是自决的极端形式）。
- **职能/地盘**：山门苦修地、拒绝接口者的收容所、临终看护；城内一处不通接口的"哑区"。
- **铁规则**：
  1. 僧侣终身零植入，**连维护接口也不要**——生病靠苦修与草药硬扛
  2. 收容所来去自由，**不劝入教**（劝=替人决定，自打嘴脸）
  3. 接受遗蜕自然附生**不算植入**——古生命自己长来的，不是人决定的（与 O5 的暧昧地带，教派内部为此吵了几十年）
- **可测试边界事件**：一个濒死的僧侣，唯一的活路是临时接入一台外部器官——接 = 破戒，死 = 守戒。庭（O3）无权裁，这是每个僧侣自己的关。
- **代表角色**：CH-007 小和尚、ZY04 苦修僧人·无名者。
- **对其他组织**：O3 的安全阀（逃进佛门=庭不再追）；O1 视其为"拒保户"；O5 是天然盟友兼论敌——都尊重身体，一个靠共生一个靠空无。

## O3 审判之庭（红）

- **一句话**：只审一种罪的组织——**替别人决定身体**。
- **信条**：边界即法律；审判必须公开，判罚必须可协商。
- **职能/地盘**：共鸣庭旁的裁决厅；流动性巡回庭（跟 O4 船队走水路）。
- **罪目（仅此三类，防组织膨胀）**：
  1. **强决**：强制/欺骗他人改造（含对未成年人与未觉醒者）
  2. **窃体**：摘取、盗用他人器官/遗蜕/接口
  3. **闭决**：以断供、扣配额等方式**逼人**做身体决定（专门用来咬 O6）
- **铁规则**：
  1. 庭无权判定"该不该改造"——只判"是不是本人决定的"
  2. 判罚可协商：公开服役、除籍、**反向同置**（体验被决定的感觉）
  3. 不追进哑区（O2 地界）与梦深处（O5 领海）——**管辖权让位于庇护权**
- **可测试边界事件**：母亲擅自给失明的孩子装了偷来的眼——救了人，犯了"强决"。审不审？（本世界观最有名的判例，尚未判）
- **代表角色**：S12 红罩关键人物（撤离路线勘绘者——庭的现场调查员气质）。
- **对其他组织**：O6 的天敌（闭决罪专为商会设计）；O4 是它的腿（巡回）；O2 是它的盲区。

## O4 船队（红）

- **一句话**：水上的自由迁徙共同体——船是身体，航线是自决。
- **信条**：离船不需要理由；上船只需要同意。
- **职能/地盘**：自由锚港（SC-02 离船权码头）+ 全水系航线；红桶人口的流动底盘。
- **铁规则**：
  1. **离船权**：任何人在任何码头可无条件下船，船队不得挽留、不得追问（唯一"无理由出走"受制度保护的地方）
  2. 船上议事全员一票——船长的权力只有航行时的紧急裁量
  3. 身体改造自决，但**改造后不能上深水线**（深水压强会挤坏非标接口——安全规约，不是自由限制，这个区别船队内部也天天吵）
- **可测试边界事件**：有人下了船又想回来——三次。接不接？（离船权保护出走，不保护反复）
- **代表角色**：S09 赤罩主角（海港背景）、H05 折层递送者（边境线送件——半个船队编外）。
- **对其他组织**：O6 的商业对手+运输合作方（船队运货、商会付钱，互相看不顺眼谁也离不开谁）；O3 的载体。

## O5 生态共生（粉）

- **一句话**：和古生命遗骸做生意的共生会——不争霸，只谈同意。
- **信条**：共生须**两个生命都同意**——对人如此，对遗蜕也如此。
- **职能/地盘**：菌林（R6）与生态边缘的活膜养殖、遗蜕保管库、记忆寄存（把记忆寄养在活膜里，比存在接口里踏实——粉桶式的"云"）。
- **铁规则**：
  1. **遗蜕采集须"应答"**：敲击遗蜕，有回应才可取；无回应=死物，自由取用
  2. 共生体享有**终止权**——任何一方可终止共生，终止仪式由 O5 主持（这是 O3 管辖权不进粉区的原因：粉区有自己的终止法）
  3. 记忆寄存**不设密码**——但看了别人的记忆，你的名字会被寄存进对方那段记忆里（社会性约束替代技术约束）
- **可测试边界事件**：一段寄存记忆里出现了寄存者已死的画面——是他自己存的遗言，还是活膜在替他记？
- **代表角色**：CH-014 晞棠（遗蜕观测者——借眼即 O5 系术法）、CH-010 潮膜采集员。
- **对其他组织**：O1 的世仇（前提互斥）；与 O2 论敌+盟友（都尊重身体自主，路线相反）；O3 承认其内部终止法。

## 诡异魔法（粉·流派而非机构）

- **一句话**：无法标准化的个人术法总称——每个人的法只长在自己身上。
- **特征**：借眼（晞棠）、潮膜听振（S06 的陶窑垂饰）皆属此类。**不可教学、不可复制、不可量产**——能教的那叫手艺，归 O1 管。
- **与五桶关系**：粉桶出生为主，偶发于白桶未觉醒者（觉醒事件=白桶入粉桶的唯一通道，极罕见）。
- **边界**：O3 对诡异魔法罪案的判例——**术法后果本人承担，术法本身无罪**。

## 组织关系速记（冲突引擎）

| 对 | 冲突/合作 |
|---|---|
| O1 ↔ O6 | 接入定价权之争（教派定维护价 vs 商会定接入价）——日常摩擦源 |
| O3 ↔ O6 | 天敌（闭决罪为其定制）——商会养着整个庭的案源 |
| O4 ↔ O6 | 运输合作 + 观念互斥（离船自由 vs 一接入皆计价） |
| O3 ↔ O2 | 追与逃的默契（哑区=庭的盲区） |
| O5 ↔ O1 | 前提互斥的世仇（活膜不可维护 vs 万物皆可维护） |
| O5 ↔ O2 | 论敌+盟友（尊重身体的两个极端路线） |
| 全部 ↔ 白桶 | 潜在争夺对象——未觉醒者是唯一还没回答问题的人 |

## O7 塔脊集会（粉·2026-09-30 增）｜传统奇幻组织的正身

- **一句话**：看起来最像传统奇幻法师公会的组织——因为它确实就是：集会制、师徒制、有名册、有一座塔。只是会员是粉的，塔是活的
- **信条**：术法用人，人用术法，**双方都自愿**（O5 "双方同意"的术法版）
- **塔**：城内最古老的遗蜕——**巨物的一段站立脊椎**。集会住在里面；每月"梦最薄之夜"在塔顶集会（所以集会也是全城最早察觉 T1 梦变薄的人，他们只记不说）
- **结构**：**十三席**——每位诡异魔法觉醒者一席（粉桶 13 人，席位数与桶位天然对齐）；主持人称**祖母**，不比席位高，只比谁记得多——祖母的记忆是集会的备份
- **入会**：不可报名。术法觉醒后集会来找你；入会礼=你的术法在名册上**自己写下名字**（名册是活膜页，字是长出来的，手写无效）
- **会费**：每个集会日交"一段新鲜事"——讲给塔听。**塔吃故事，不吃饭**
- **立场**：对"谁决定你的身体"——术法与人互为宿主，谁也没替谁决定；O6 想给术法者建"能力名册"计价 → **集会名册 vs 商会名册**之争（粉青新冲突线）
- **钩子**：
  - CH-003 逃票魔法学徒 = 没走觉醒通道就长出术法的**逃票者**——集会追着补票三年（她帽子上活体紫帽写的名字，名册认了）
  - 晞棠的席**空置**——集会留席她拒了，理由："眼睛不是我的"
  - 塔偶尔"应答"——应答的内容从不重复，祖母说塔在换梦
