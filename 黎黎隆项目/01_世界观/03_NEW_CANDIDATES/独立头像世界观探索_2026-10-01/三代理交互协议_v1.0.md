# 三代理交互协议 v1.0

> 适用范围：独立头像世界观探索（含第二批及以后各批）。三代理均为 AI 角色分工，最终拍板权在 674。

## 一、代理职责边界

| 代理 | 读 | 写 | 禁 |
|---|---|---|---|
| 素材代理 | 色卡页原图、切图 | 登记卡「素材代理登记」节、切图索引、五色归类表、canvas 图墙 | 不写设定、不改编号（B 编号=稳定ID） |
| 世界观代理 | 已转正人物卡、登记卡钩子节 | 登记卡「世界观代理钩子」节、宏观上推文档 | 不替用户挑选、不直接定稿人物 |
| 十元代理 | 登记卡假说节、能量桶/五色归类 | 登记卡「十元代理假说」节、外貌因果与主十元反证文档 | 不虚高评分、改假说须注明改了什么 |

## 二、状态机（每枚候选）

```
STAGING_CANDIDATE（入库登记）
  → SELECTED（674 报编号挑选）
  → FIVE_VERSE（十元代理+世界观代理各写五版互斥，互不可见对方结论）
  → CROSS_CHECK（交叉反证：钩子与假说冲突即退回重写，冲突点写入登记卡）
  → SYNTH（合成综合候选一版）
  → WORLD_MERGED（并入个人小世界；世界观代理以已入选共性反推宏观，宏观变化回写钩子）
  → LOCKED（674 拍板转正，建立正式人物卡；未选者永久留在候选区）
```

## 三、交互回路

1. **入库回路**：素材代理切图→编号→五色归类→挂 canvas 图墙，产出登记卡骨架（三代理各一空节）。
2. **挑选回路**：674 报编号（如「B03 B06 转正」）→ 状态置 SELECTED → 十元代理与世界观看代理并行开工（并行 sub-agent 提速）。
3. **反证回路**：十元假说必须能被「外貌因果」检验；世界观钩子必须能被「已转正人物共性」检验。任一反证失败 → 退回上一状态并在登记卡记录退回原因（可审计）。
4. **宏观回路**：每转正满 5 人，世界观代理跑一次共性反推，更新宏观候选文档；若宏观与既有设定冲突，停下报 674，不静默改原典。
5. **素材回路**：转正后素材代理把该角色从候选图墙迁入正式人物卡区（canvas 内移动节点，不删不重建），色卡页原图永远留档溯源。

## 四、审计要求

- 每次代理写节，在文内注明 `[代理名] [日期] [改动摘要]`。
- 状态变更只前进或退回一格，跳格视为违规，674 可指令回滚。
- 保守结论优先：假说一律带「待反证」标，未过反证不得进入正式文档。
