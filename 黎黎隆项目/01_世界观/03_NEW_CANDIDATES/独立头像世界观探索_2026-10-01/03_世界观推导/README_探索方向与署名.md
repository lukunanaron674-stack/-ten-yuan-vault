## 从个体到整体的推导法

`一个人怎样感知与生活 → 他/她能做什么、不能做什么 → 哪些对象/规则改变其路径 → 与谁发生持续依赖或冲突 → 多个小世界出现交集/冲突/互补 → 组织如何形成并改变成员的选择 → 城市尺度如何承接或压迫这些路径 → 更高尺度向量`

“N个人就是N个世界”在此作为创作方法：每个人拥有自己的现实边界、时间节律、资源、禁忌、行动能力和可返回路径。汇总时不把角色平均成同一种生活，也不因同住一地就假定他们已有共同制度。批次仅表示创作顺序，不预设同城或彼此认识。

## 每个头像的交付单元

每个进入当前名单的角色独立一份 Markdown，结构固定（当前已有19份）：

1. 头部可见锚点与当前身份假设；
2. 五个真正不同的文字设定版本；
3. 五版对照后的一份综合候选（不是自动选出的正史）；
4. 该人物本人的小世界观：感知、生活地点、时间、资源、关系、规则、风险、可行路径与回返方式；
5. 把个人经验放入新提出的[[03_世界观推导/02_异证回环_新世界动态链与组织层级|异证回环]]中检验：生活事件怎样成为异证、怎样进入有限决定、决定后果又怎样返回公共议程；
6. 未知、冲突和待作者裁决项。

人物编号严格按三轮用户选择顺序，不按未选中的整页候选图编号。复合选图在索引里拆为单人概念，但原始参考不裁切、不重绘；具体边界不清处标作待复核，不靠生成提示词猜身份。

## 向上推，不预设高层答案

- **组织层**：从多人的持续依赖、协作成本、争议、权限、退出/返回条件中推出组织。组织不是自动对应一个十元；按异证回环里各组织真实召集、授边、运作、受影响与回听的方式逐个观察。
- **城市层**：从多个组织之间真实共享或争夺的路径、资源、规则和基础设施推出城市向量。
- **更高层**：只有当城市间/区域间出现持续机制、残余和新的可供性，才上推更高尺度；不能从一张头像直接发明帝国、联盟或宇宙法则。
- 十元端点先逐阶段取证；`XN`、`ZN`、`NZ` 等都只是可能候选，不由“组织”“个体”或“世界观”这些名词直接决定。阶段相邻不等于生克补。
