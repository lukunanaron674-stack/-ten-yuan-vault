### 组织 R-16｜不归局（O4 船队 下设·启航裁定行）

- **一句话**：裁定"他不会回来了"的窗口——船要开，缺席的人必须先被全船记成「不归」，而出走明明是不需要理由的。
- **信条**：「船队不挽留任何人，但船的航线是一百个身体选的——等不等一个人，一百个身体也有权选。」
- **职能与地盘**：O4 下设，柜面开在自由锚港的调度棚（与 R-03 三返簿房隔水相望）。管「不归认定」：船员离船逾期未归、船要启航，须全船公议记「不归」方可除名开船；局里存不归簿与滞港台账。
- **铁规则**：
  1. **离船不得挽留、不得追问（O4 铁律原样保留）**——但记「不归」必须问清"他到底回不回来"才能落笔：规则第一条与职责第一条当面对撞，局里自己的章程互相打架
  2. **「不归」须全船公议、一票不得代投**——缺席者那一票悬空，不补投也不销毁
  3. **程序外的告别不算数**——不记「不归」就把人当走了，档上仍是"全员在册"，船成了载着一个空名字航行的证物
- **可测试边界事件**：某船滞港四十天等一名缺席船员，公议记「不归」三次未过；第四天全船不再投票，直接把他的铺盖寄回他下船的码头——程序外的「不归」，O3 翻遍三罪目定不了罪（没人替他决定什么，只是不再等），可 O4 内部已有半数船照此办理。
- **与其他组织冲突**：
  1. 与 R-03 三返簿房：簿房要**理由**才准回，不归局要**证据**才准走——同一张离船，两套反向追问，撞在"谁有权定义一次出走的完成"上
  2. 与 O3 审判之庭：程序外寄铺盖算不算"替人决定"——庭说没动他的身体就不算，局说船开了他的名字就回不来了
- **代表角色**：S09 赤罩主角（海港背景，主持过一次全票通过的「不归」公议，从此拒绝再主持）；H05 折层递送者（船队编外，替不归者送铺盖——送的不是行李，是"船队不再等你"的公文）。
- **「谁决定身体」**：O4 答"航线与身体一样，只走自己选的"。不归局答"船的航线也是一百个身体选的"——记一个人「不归」，是一百个身体替一个身体决定：你的出走，到此为止。

- **三色归属**：红（BEND 与 N26 的同进退自决 × 制度强分主从）；青（O6 附随费 × 应答顺序定身份）。

### 组织 P-17｜共食灶（O5 生态共生 下设·人膜同灶供膳行）

- **一句话**：管"膜吃什么"的灶——人吃什么膜就吃什么，可灶从没问过膜，也没问过要绝食的人。
- **信条**：「膜不拒食，不代表它同意——不拒只是它唯一会说的句子。」
- **职能与地盘**：O5 下设，灶口开在潮膜晾场下风的洼地（与 P-10 潮膜晾场共滩）。管人膜同灶的份例：每人报餐，灶按人份划出膜份；存份例簿与绝食台账。
- **铁规则**：
  1. **人餐必留膜份**——扣留膜份记苛待共生体；可膜从不拒食也无从表达不满，"苛待"的认定标准，永远是灶自己说了算
  2. **绝食者膜份照供**——承认人与膜的食欲是两回事，但份例多少由灶定：你饿你的，它吃它的，谁也别拿谁要挟
  3. **膜份剩余归灶，不得转赠**——防止有人用吃食给别家的膜"行贿"，换一声好听的应答
- **可测试边界事件**：一位绝食第四天的人要求"我饿，也给膜停膳"——灶方按规拒绝，理由是"停膜份是替膜决定饿死"。可照供的结果是：人一天天垮下去，膜一天天饱着——测试点：饿死自己养肥膜，算不算另一种替膜做的主？O5 内部为这条吵到把"供养与自决孰先"写进了下一季共议。
- **与其他组织冲突**：
  1. 与 O1 钢铁教派：O1 主张连餐配也上账（吃多少都该登记），共食灶坚持灶口不记账——"吃"一旦入册，绝食就成了销账
  2. 与 P-15 续膜堂：嫁接的膜认旧主的口味——新主报什么菜它都不碰，续膜堂要求灶按膜不按人配餐，共食灶的份例簿根本没这一栏
- **代表角色**：MOUSE 鼠耳突变体（天然突变非接口，没膜可喂，却在灶上帮工——唯一不领膜份的灶工，份例簿上没有他的格子）；S06（兼职报餐员，替哑了三天的人按旧食量报餐，报多报少都是她替人定的胃口）。
- **「谁决定身体」**：O5 答"共生即互相养着"。共食灶答"养着就得喂"——可膜不点菜、人不绝食都不被听见：灶替膜定了口味，台账替人定了还能饿几天，最后连"一起活着"都是份例簿说了算。

- **关系类型**：讣膜（O5 旧例——活膜枯死视同公亡，须三日内置讣开祭；逾期不发，膜骸按无主之物由 P-05 拾蜕行收走处理）

### 人物关系 P-R146｜唤芽（我用你丢掉的声音，唤醒了长在你膜上的名字）

- **关系类型**：唤芽（O7 育名坊旧例——膜上名芽须以旧音唤醒；唤者签保声状，芽记唤者之声为「首音」）
- **A ↔ B**：S12（持有 N30 失声前的旧音刻片）↔ N30（名芽当户——膜上生了一枚芽，三年未醒）
- **张力**：N30 膜上的芽蹲了三年，育名坊判"再不唤就要枯"。S12 手里有 N30 失声前刻的旧音——唯一可能唤醒它的声音。唤，芽就醒了，可按坊规它记住的"首音"是 S12：从此这名字每次被念起，都得从 S12 的声纹里过一道。不唤，芽枯在膜上——不叫，就是眼看着它死。

### 人物关系 P-R147｜分蜕（一片遗蜕劈成两半，谁先落葬，谁就替对方决定"另一半不算了"）

- **关系类型**：分蜕（O5 拾蜕行旧例——遗蜕分裂的，两半各归拾得方；落葬须两地同刻，先葬者记"全蜕处理"，另一方落葬权自动作废）
- **A ↔ B**：H25（拾得半蜕·所持半片已开始潮霉）↔ H05 折层递送者（持另一半·仍在折层间赶路）
- **张力**：同一具遗蜕当年被劈成两半，两人各持一片。落葬规矩是"同刻同葬"——可 H25 那半片已经开始发潮霉斑，P-05 的规矩紧跟着压下来：霉变过线的蜕按无主之物收走处理。H05 的半片还在折层里没运到。H25 等下去，自己这半会被收走；先葬，等于替 H05 决定了"你那半不算了"——他的落葬权会随着 H25 的第一铲土自动作废。
- **可测试场景**：霉斑爬过线的前夜，H25 下葬了——但只埋了半片里的"可葬层"，故意留一截膜梢翘在土外。拾蜕行的册子翻遍，没有"葬了一半"这个写法：记全蜕=说谎，记未葬=霉变收走。那截翘在土外的膜梢，成了 O5 台账上第一笔"葬到一半"的悬账——制度管不到"我用留一半的方式，不替你做主"。
- **三色归属**：粉（遗蜕分持 × 同刻落葬之礼）；红（H25 在收走与替决之间给自己凿出的第三条路——"不完成"作为自决）。
- **「谁决定身体」**：O5 答"蜕亡同葬，是给遗蜕的全礼"。可"同刻"本身就是一道二选一的替决题：等=看着它烂，葬=抹掉对方那一半。H25 用一截不肯入土的膜梢回答——谁有权决定你的身体，连死了的膜，都不该由活人替它说"完整"。

## 02:00 场次 · 青桶

### 组织 C-17｜悔保行（O6 青色商会 下设·反悔权承保行）

- **一句话**：卖"反悔权"的柜面——它不替你决定，它替你的犹豫标价。
- **信条**：「想好了再决定是本事，决定完了还能想是商品。」
- **职能与地盘**：O6 下设，柜面开在 C-01 配额当铺隔壁。承保"缓期保全险"：已作出的身体决定可在保期内反悔一次，逾期不悔视同终决；存保单与悔价簿。
- **铁规则**：
  1. **只保"已决定"，不保"没想好"**——没想好的人没有可保标的。于是柜面教人：先随便定一个，再来买悔。制度在亲手制造它承保的犹豫
  2. **悔价按决心市价浮动**——旁人越盼你反悔，保费越贵：你的反悔权，行情握在盼着你反悔的人手里
  3. **出保即终决**——保期到了没悔，保单自动转"终决公证"，效力比本人亲口更硬：你最后的机会，以一张过期的保单为证
- **可测试边界事件**：某人投保后真的反悔了，赔付条款却写明"悔后须自行恢复原状"——他要反悔的那个决定，其原件早已随 C-08 报废流程销毁。悔保行照章赔付"反悔成立"，人却永远回不到悔之前：全城第一笔"赔了后悔、赔不回从前"的保单，O6 把它裱在了柜面。
- **与其他组织冲突**：
  1. 与 R-10 缓决庐：庐判"缓期"是庭权，行卖"缓期"是商品——同一个"缓"字，一边当刑罚一边当货卖
  2. 与 O3 审判之庭：悔保单能不能当"被胁迫决定"的证据——庭说保单只证明买过犹豫，不证明为何犹豫

### 组织 R-17｜吃水公议行（O4 船队 下设·深水载量公议行）

  2. **非标者公议票照投，票权不计入载量**——「你反对，但你的反对压不了舱」：自决权按吃水分量折算
  3. **全员通过则「自愿超载」全员签押**——出了事责任均摊，把"敢不敢带他"折成一页签字；拒签者以后无权再议载量

### 组织 R-19｜钉舱棚（O4 船队 下设·风暴封舱裁定棚）

- **一句话**：风暴夜封舱保命——舱门从外钉死，按「会走动的货」处置；可每道门留一根从内可拔的活钉，等于它自己承认：这场替你决定活着，它没资格。

- **职能与地盘**：O4 下设，随各主船配一名钉舱匠（与 R-17 吃水公议行的点算员、R-07 深水验体棚的验体员并称船队三只手）。管风暴封舱令的下达与解除、舱内应答记录、开舱验人。
- **铁规则**：
  1. **封舱令只钉「会自己走动的」**——真货物从不封舱；在钉舱棚的账上，人比货危险，因为货不会自己决定跳海
  2. **每门留一根内拔钉**——拔是舱内人的自决，钉是甲板上的公断；两下互不通气，拔了不算抗命，钉着不算囚禁
  3. **舱内三叩不应按货记档**——恢复人籍须舱外两人具签；自己喊破喉咙不算数，被钉者连「证明自己是人」都得借别人的手
- **可测试边界事件**：某夜封舱后整夜无应答，晨开舱：人不在，钉完好。按规则只能记「货自行离舱」——没有应答记录的身体，连出走资格都不被承认。档案上第一次出现一栏空着的「离舱方式」，钉舱棚宁可空着也不补：补哪种，都是替那个不在场的人答。
- **与其他组织冲突**：

  2. 与 O2 佛教：僧团指钉舱即囚禁；棚反问「眼睁睁看他跳海才是慈悲？」僧团答「至少他跳的时候，是他自己的」

- **职能与地盘**：自由锚港各码头的「空舱登记桩」；管候由册（每个空舱须填「留给谁」或「谁也不留」）；风暴夜按空龄调度空舱。
- **铁规则**：
  1. **满舱开船是耻**——每船至少留一个舱位空着，空舱不载货不载人，违者除名
  2. 空舱须填「候由」——留给谁、留多久；候由满百日自动转公舱（给付不起票的人）——**你替一个没来的人留的位子，一百天没等来他，制度就替他决定改等别人**
  3. 不许用空舱涨票价——留空不是稀缺是良心；但泊务行已经开始给「长空龄舱」标价
- **可测试边界事件**：风暴夜，一条空舱主义船按例留着三个空舱拒载码头的逃难者——船员说：「舱里坐着所有没来的人。」岸上的人站在水里。空龄最长那个舱的候由栏，写着一个死了七年的人的名字。

### 组织 C-21｜拒维科（O1 钢铁教派 下设·冷惩罚执行行）

- **职能与地盘**：维护街带深处的窄门柜台，管「拒维名单」：黑市永久改造者、不可拆卸件持有者入册，名单每季誊抄分发全城维护站——入册者面前，所有保修章同时关闭。

  3. **急救豁免每人一生一次**——破例维护的仁慈做成配额，用完即终
- **可测试边界事件**：名单上的人昏迷送进维护站——分不清他"拒绝维护"还是"没来得及拒绝"。查名单要一刻钟，人只剩一刻钟：查，还是先修？
