### 组织 P-08｜塔膳讲事房（粉 · O7 塔脊集会下设·讲事编排行）

- **一句话**：替塔排「今日食谱」的厨房——十三席都在塔里讲事，讲事房决定谁的故事先被吃。
- **信条**：塔吃故事不吃饭；新鲜事要新鲜，讲事人要不知情。
- **职能 / 地盘**：塔脊集会下设，占塔底层膜室与回声廊。编「讲单」（讲事顺序）、采买名册活膜页、按塔的「回味」（讲完后塔应答的时长）调整下一季讲单。
- **铁规则**：
  1. **只排顺序，不改内容**——但「哪个先讲」决定塔先记住谁；排序本身就是改写（本房自认的最大裂缝）
  2. **讲事人不得知道自己的故事入选**——知情的记忆会变味，塔只吃不知情的
  3. **塔连续三夜不应答即封灶**——封灶期间全城新鲜事一律不收，谁也不许问为什么
- **可测试边界事件**：一个讲事人在讲单上看见自己的名字——讲自己的故事，算交会费还是算泄露他人？（他得先回答「我的经历归不归我」）
- **与其他组织冲突**：
  1. 与 O6 青色商会——商会想给「被塔吃掉的故事」计价（故事也是接入品）；讲事房坚称讲事是喂食不是交易
  2. 与 P-03 膜谱馆——同一片名册活膜页，谱牒行记名字、讲事房记故事；两个账本对不上时以谁的为准？
- **代表角色**：CH003 逃票魔法学徒（全城唯一讲事房不追的粉桶——她的票钱被塔「预吃」了三年，讲单上一直留位）；S06 赤发垂饰者（兼任「试味员」，潮膜听振听塔的回味）。
- **对「谁有权决定你的身体」的答案**：你的经历是你这具身体的产出——塔先尝为敬。讲事房替塔决定吃谁的，会员替塔决定经历什么，塔替所有人决定什么值得被记住；三方都自称「只是转述」。

### 人物关系 P-R64｜遗蜕认养（不登记的亲）

- **关系类型**：遗蜕认养（单方面认领无主遗蜕当家人）

- **「谁决定身体」**：最温柔的替决——喂它、搬它、给它过节，认养者替遗蜕做了「你还没死」的决定；而遗蜕从没应答过。

### 人物关系 P-R65｜问名（名字比人先觉醒）

- **关系类型**：问名（替集会向觉醒前兆者求证名字）
- **A ↔ B**：S06 赤发垂饰者 ↔ CH003 逃票魔法学徒

- **可测试场景**：回声廊里 S06 念了半句就停——CH003 接了下半句，念得比她还准。S06 回去怎么报：名字被认领了，还是名字早就自己在跑？集会名册上，那页活膜当晚自己多长了一个字。
- **三色归属**：粉（O7 名册认字不认人）× 红（本人不认＝替决边界的粉红骑缝）。
- **「谁决定身体」**：制度在审一个还没存在的东西——名字先于人觉醒，问名等于让制度抢在人前面替他定了性。

### 人物关系 P-R66｜代眠（膜替人值夜，人不在场）

- **关系类型**：代眠（用别人的膜替自己的膜值夜应答）
- **A ↔ B**：BEND（身上附生活膜）↔ N30 顺巢漂居者
- **张力**：N30 漂居不定，P-06 并眠坊的年检只查「膜应答连续」，不查床上睡的是谁。N30 漂走前把 BEND 的膜借去陪自己的膜睡几夜——两片膜互相替对方作证「人还在」。如果膜在替睡着的宿主圆谎，那膜就在替宿主决定「他没走」；而膜没被骗，它是配合演的。
- **可测试场景**：并眠坊抽查夜宿，看见 N30 的膜应答如常、BEND 在旁边打盹——记录上这是两个人各自在场，实际上两个人都不在各自的床上。坊吏问 BEND：你替谁值夜？BEND 说：替膜，不是替人——制度里没有「替膜」这个说法。
- **三色归属**：粉（活膜应答制度 × 并眠坊年检）× 粉（P-06 并眠坊互文）。
- **「谁决定身体」**：应答制度只问膜不问人，人正好用自己的器官给别人当不在场证明——最后是膜替所有人决定了「谁在场」。

## 02:00 场次 · 🟢 青桶（O1 钢铁教派 · O6 青色商会 · 接口/维护/登记）

### 组织 C-08｜报废听证处（青 · O1 下设·报废认定行）

- **一句话**：全城唯一有权宣布一具身体「不值得再修」的地方——用一页技术文书，回答一个技术答不了的问题。
- **信条**：维护即修行；资源有限，报废即超度。
- **职能 / 地盘**：维护街带末端一间没有窗户的听证室，年检季巡回各维护站。出《报废认定书》，认定件移交拆件流程（下游接 C-03 无主件招领所），认定前档案封存（接 C-05 复护堂）。
- **铁规则**：
  1. **听证只审「还能不能修」，不受理「还想不想活」**——后者标注「非技术问题」退回本人；但认定书生效的那一刻，两个问题被一并回答了（本处自认的最大裂缝）
  2. **三签制**：报废认定须三名与该件无维护关系的检修员联签——三人领同一份季结津贴，废得越快结算越快
  3. **报废件不得再受教派维护**，本人自备材料自己动手的「自维」不在禁止之列——因为规程里没写过「人对自己的件算不算维护」
- **可测试边界事件**：一条被认定报废的腿，主人靠它挑担讨生活。他不要撤销认定，只要求「自维」——听证处翻遍规程立不了案：他对自己行使决定权，反而没有任何条文接得住。
- **与其他组织冲突**：
  1. 与 O6 青色商会——商会把报废认定书当采购目录（废件低价收、翻新转租），教派的死刑判决成了商会的进货单
  2. 与 C-04 拆许司——拆许司说「可拆卸即可自由」，报废处说「报废即不可装回」；一具身体可以同时压着两张相反的文书，以哪张为准无人能裁
- **代表角色**：H06 接口复核员（※已定核，非白名单——联签人之一，签过自己师父的腿）；CH-011 壳缝检修员（※已定核，非白名单）。
- **对「谁有权决定你的身体」的答案**：它答「修不修是技术问题，技术听规程」——可把一个人写进报废栏的那支笔，从来不是他握的。

### 人物关系 P-R67｜追认（制度追认一个它没批准过的存在）

- **关系类型**：追认（对已发生、未经登记的身体事实补发合法性）
- **A ↔ B**：CH003 逃票魔法学徒 ↔ S12 红罩关键人物
- **张力**：CH003 的术法长在档案制度之前——紫帽上的名字是长出来的，不是登记来的。年检季 O1 要她签「自愿追溯登记书」，S12 以庭方调查员身份在场见证：签了，等于替三年前没人问过她一嘴的那次「接入」盖章为「本人意愿」；不签，她仍是全城挂账最大的黑件。追认不问当初，只问现在肯不肯认账——制度用一句「自愿」把没发生过的同意补进了过去。
- **可测试场景**：S12 依法只做事实记录不做劝说，却问了一句程序外的话：「三年前你几岁？」——记录纸上这句话没有栏目可填，复核员只好让它空着；空着的那栏后来被上级批注「见证人诱导」。
- **三色归属**：青（O1 档案追认制）× 红（S12 庭方在场，替决边界的骑缝）。
- **「谁决定身体」**：追认制度发明了一种新的替决——不是替你决定将来，而是替你决定「过去那个你已经同意了」。

### 人物关系 P-R68｜留底（把别人的名字存进自己的身体）

- **三色归属**：青（O6 证明链制度）× 红（O4 编外之人被纸约束，庭的书证规则骑缝）。
- **「谁决定身体」**：制度管不到留底人本身的去留——却让他人的身体成了存放自己合法性的器官。

### 人物关系 P-R69｜陪审（唯一中立的，恰好不被制度承认）

- **关系类型**：陪审（报废听证的第三方身体评议）
- **A ↔ B**：MOUSE 鼠耳突变体 ↔ S11 青角红发者
- **张力**：C-08 新设陪审席，要求「身体完整且与双方无利害」。S11 被荐为常任——她红青两桶出身都沾；MOUSE 被荐为候补——他天然突变、无档无接口无共生，看起来是全城唯一没被任何制度碰过的人。可问题恰恰在这：制度连「天然」这个类别都没登记过，没人能证明他是「完整」的——他得先提交一份自己身体的来历，才配评议自己同类的案件。
- **可测试场景**：听证一件鼠系共生腿的报废案，MOUSE 投票前被要求先申报耳的来历——申报表上「接口 / 共生 / 突变」三栏，突变栏是空白的，笔填不进去；S11 提议「填『无来源』」，庭书记说无来源=来路不明，按来路不明不能入席。
- **三色归属**：青（C-08 评议规程）× 红（S11 出走者背景）× 粉（天然突变落在共生世界的边缝）。
- **「谁决定身体」**：陪审本该由「不被制度决定的人」来监督制度——可制度要求他先交出一份自己从未参与撰写的身体档案。

## 03:00 场次 · 🔴 红桶（O4 船队 · O3 审判之庭 · O2 佛教 · 出走与自决）

### 组织 R-08｜尾票房（红 · O4 船队下设·航行裁量事后追认行）

- **一句话**：全红桶唯一合法的「先替人决定」——船长的紧急裁量——在下一个锚港补一箱尾票，就算走完了程序。
- **信条**：航行不容商量，锚港必须补票。
- **职能 / 地盘**：每艘深水线船尾部一间半舱，泊港时开门收票；票封由编外送件人递送（接 O4 与商会的运输链）。
- **铁规则**：
  1. **船长紧急裁量须在下一锚港入尾票房追认**，全员一票，追认不过按 O3「强决」罪目移送
  2. **仍在航行中开票的，缺席票一律计「默许」**——全船队唯一的「缺席=同意」条款，与「离船不追问」的「缺席=自由」互为反面
  3. **同一航次裁量只记总账不记次数**——救十次人和救一次人，过一样的票
- **可测试边界事件**：船长为避风暴强行拖走一个喊「我要留在这片水」的人。人救回来了，尾票他投「不追认」——追认不过，代决罚款按船规平摊到全船人头，被救的人一夜之间成了全船的债主。
- **与其他组织冲突**：
  1. 与 O3 审判之庭——庭只审「是否本人决定」，可船长改一次航就替全船的身体定了去处；庭每次都立案，尾票房每次都追认，两本账永远互相抵消
  2. 与 R-07 深水验体棚——验体棚「一次验体定终身」，尾票房「一次一票清零」；同一具身体在船头船尾活在两种时效里
- **代表角色**：S09 赤罩主角（海港背景——投过最多「不追认」票的人）；H05 折层递送者（O4 编外送件——替尾票房送票封，送票人自己永远不投票）。
- **对「谁有权决定你的身体」的答案**：它答「船长人事先、全员人事后、你自己在水里的那句话算第三票」——三票轮空时，以缺席计默许收场。

### 人物关系 R-R70｜抗辩（自证清白的每一步，都在教庭如何替人决定）

- **关系类型**：抗辩（庭判罚协商制下唯一允许的反驳程序——须自证「决定链上没有我」）

- **可测试场景**：协商桌上 S12 把三页底单压进案底夹层，记录员例行问「底单齐全吗」，她答「齐全」——庭记下的是她作伪证，不是 H05 无罪；H05 在旁看见了全部，却不能开口，他开口补的每一个字都会把那三页重新抬上桌。
- **三色归属**：红（O3 协商制 × O4 编外之人）× 青（底单文书规则骑缝）。
- **「谁决定身体」**：抗辩制要求你自证没替人决定过——可证明材料本身，得由另一个人替你决定交不交。

### 人物关系 R-R71｜绝罚（用替人决定，惩罚替人决定）

- **关系类型**：绝罚（收容所「来去自由」里唯一一道不许再进的门）
- **A ↔ B**：CH-007 小和尚（※已定核，非白名单）↔ N26 褪地迁路人
- **张力**：O2 铁律「劝=替人决定」，绝罚却是山门替个人做的唯一一个决定。CH-007 替一名濒死俗众按下接入外器的决定——救了人，犯了山门眼里最大的替决，绝罚出寺。更裂的一层：N26 明知替人指路是在帮一个被制度开除的人继续「替人指路」，他还是指了——红桶没有不许帮人的法，山门也没有不许记恨的戒。
