### 组织 R-22｜压舱人公所（O4 船队 下设·压舱登记行）

- **一句话**：把"用身体稳船"做成一份可签名册的窗口——进去是自愿，出来要全船批准。
- **信条**：「身体是自己的，压舱是自愿的；自愿进去，公议出来。」
- **职能与地盘**：O4 下设，柜面开在自由锚港底舱磅房。管压舱名册、配重测算、压舱津贴发放；深水线各泊通用。
- **铁规则**：
  1. **压舱须亲签，津贴按潮季结算**——签期内身体位移一律登记，连翻身都是配重变动
  2. **起舱须在舱本人申请＋全船公议通过**——「你上舱是自己的事，下舱是全船的事」
  3. **压舱人不占载量、不算人头**——公所与 R-17 吃水公议行打架的条款：同一具身体，在两张表上一张算人、一张算石头
- **可测试边界事件**：某压舱人夜里为旧伤挪了半尺，磅房记「位移违约」，触发全船公议——表决的不是"放不放他走"，而是"他还愿不愿意被压着"。本人列席，无表决权：全船投票替他回答他的意愿。
- **与其他组织冲突**：
  1. 与 R-17 吃水公议行——公议行要把压舱人算进载量与票权，公所坚持"压舱不是载、是配重"；一具身体在制度里同时是乘客与货物
  2. 与 O3 审判之庭——压舱人递退舱状，庭翻遍罪目无所适从：自愿签的，退不出，没有谁强迫谁
- **代表角色**：H29 多身共鸣体（五具身体只押一具，其余四具联名替第五具申请起舱——公所驳回：申请人须为"在舱本人"。四具身体加起来，不够一个"本人"）。
- **规则自相矛盾的裂缝**：加入是个人决定，退出是集体决定——制度用"自愿"把人请进来，再用"公议"把人留住。名为登记行，实为全城唯一"进得去、出不来"的自愿窗口。
- **「谁决定身体」**：O4 答"自愿与公议两清"——而票箱回答的是：你的意愿由别人的票代持。

### 人物关系 C-R196｜顶载（用身体替人顶一个载位）

- **A ↔ B**：CH-007 小和尚（※已定核，非白名单——绝植入者，一身从不需检、不需档的身体，是深水线最"稳"的压舱料）↔ N30 顺巢漂居者（巢与巢之间漂着住，走得比谁都勤）

- **「谁决定身体」**：青答"在册者按册行事"——制度管不到：**受伤的身体得先冒充别人，才轮得到被维护；册子替所有人决定"存在的唯一合法形状是一个名字"。**

### 人物关系 C-R198｜验声（认声不认脸——声纹即人到庭）

- **关系类型**：验声（O3 庭例兼年检规程——雾城脸不可靠，认声不认脸；声纹与在册本人一致，人即到庭）
- **A ↔ B**：H25 灯影演者（B 类白名单——以替人应声为业，一副声纹是替几十个缺席者磨出来的）↔ H06 接口复核员（※已定核，非白名单——年检声纹复核岗）

- **可测试场景**：H06 在复核单上第一次写下"声纹属本人，且不止一人"——系统无此格，他划掉，改盖"验讫"。当晚 H25 替一个缺席者应了最后一次答，把声戒了半年。次年检讫：读数"与在册本人一致"。H06 盖章的手，比去年慢了半拍。
- **三色归属**：红（声即人到庭——庭替所有人决定"声音必须单一才是本人"）；青（声纹档、复核规程）。
- **「谁决定身体」**：青答"声纹一致即本人"——制度管不到：**制度要的不是他的声，是一个从没替人活过的声；验声验的不是人到没到，是他够不够"只有一个"。**

### 组织 P-23｜补票棚（O7 塔脊集会 下设·会费追补行）

- **一句话**：把"不可报名"倒过来开成追讨窗口——法是长出来了，账也得跟着长。
- **信条**：「术法用人，人用术法，双方自愿；自愿了三年，没付过一天账。」
- **职能与地盘**：O7 下设，棚口开在塔基背风耳房，只进不出。管逃票者认定、会费追补、瞒年折价、"法已长成"三席验定；集会日之外的六天歇棚——歇棚不歇账，瞒照算。
- **铁规则**：
  1. **不可报名，补票不算报名**——但补完算不算成，由名册自己长（棚只管收账，不管名册认不认）
  2. **会费追补按瞒年翻倍**——"新鲜事"过夜就馊，瞒得越久，能顶账的旧事越不值钱
  3. **"法已长成"须三席连署**——三席各按自己的术法验，三个结论可以同时成立；棚录三案，不裁对错
- **可测试边界事件**：CH003 补票当日——她交足三年会费，塔的名册拒收银钱，只认帽子上活体紫帽自己长出来的名字。棚里台账写不下去：记"补成"，等于承认"名册不收会费"这规矩破了；记"未成"，钱已经收了。两头都违棚规，案卷悬在梁上（与 CH003 逃票年份同岁）。
- **与其他组织冲突**：
  1. 与 O6 青色商会——补票棚的"瞒年台账"就是商会想买的能力名册底稿；祖母只回了一句"塔吃故事，不卖名字"
  2. 与 O3 审判之庭——"瞒年折价"把一个人的过去按年标价，庭疑其滑向"闭决"边缘；棚抗辩：价钱是补票人自己报的
- **代表角色**：CH003 逃票魔法学徒（全城唯一公开挂账的逃票者——帽子上的名字比她先入册）。
- **规则自相矛盾的裂缝**：棚的存在建立在一个它自己天天违反的规矩上——"不可报名"，可补票窗口一开三十年。补成＝变相报名，补不成＝逃票坐实，棚两头都是错的，所以只收账、不断案。
- **「谁决定身体」**：O7 答"术法与人互为宿主，谁也没替谁决定"——补票棚答漏了一截：**它替每个人决定了"你身上的法从哪一天起才算你的"，而那一天，你本人未必记得。**

- **关系类型**：目债（O5 灰色地带旧例——借眼须两愿：本人愿、眼愿；借期内眼之所见按"目债"记账，归还时一并清算）

- **「谁决定身体」**：粉答"双方同意"——制度管不到：**借出去的器官以本人的名义见证世界，但眼看到的每一件事，本人都是在"已经被看见"之后才被知会；同意借的那一下，替之后所有的看见点了头。**

### 人物关系 P-R200｜认滩（膜先应了谁，滩就是谁的）

- **关系类型**：认滩（O5 潮膜采集行规——采集滩位不立契，凭"膜先应谁"归属：潮头夜里把手或贴身物伸进水线，膜应了即认主）
- **A ↔ B**：S06 红发垂饰者（A 类白名单——陶窑垂饰听振，潮夜常替膜"捎声"）↔ CH-010 潮膜采集员（※已定核，非白名单——手常年泡在滩里，比谁都熟每片膜的脾气）
- **张力**：某夜大潮，S06 的垂饰与 CH-010 的手同时进水，同一片膜同时应了两个。行规没写"同应"怎么办——CH-010 说膜应的是手（膜认的是常年泡它的那具身体），S06 说膜应的是声（垂饰替膜记着旧音）。**膜的应答被当成滩的地契，可没人问过滩：膜到底是在同意，还是只是在应潮？**
- **可测试场景**：两人把膜抬到 P-03 膜谱馆请求"重应"——誊谱官把膜晾干再放回水里，膜这次谁都没应。行规只认"应"不认"不应"：不应＝死物＝谁都能取，可这片膜明明前夜还活着。判决写不下：认 CH-010，等于承认"熟"可以替代"同意"；认 S06，等于承认器物可以替人受膜。
- **三色归属**：粉（应答归属、膜谱馆重应）；青（滩位旧账、采集配额底册）；红（两人都拒绝让第三方替膜答——宁可对峙一夜）。
- **「谁决定身体」**：粉答"两个生命都同意"——制度管不到：**半个身体（膜）的应答替两个活人决定了生计归属，而膜自己那晚可能只是在换气；把应答读成同意的那一下，就是替膜做了主。**

- **关系类型**：援例（无成文法——粉桶旧习：一案不成，援另一案的"没算数"当挡箭牌；先例效力靠双方公认，无处登记）

- **可测试场景**：O6 的柜员把两案并卷上呈："同一原理，两种待遇"。O3 被请来断"援例算不算抗辩"——庭翻遍罪目：两人谁也没替谁决定什么，只是把各自的"没被决定"借给了对方。案卷归档，批语只有一句：先例不护人，护的是先例。
- **三色归属**：粉（集会"是法"认定、旧习公认）；红（两具身体都靠"没人替我决定过"活着）；青（O6 名册、O1 基线检的文书攻防）。
- **「谁决定身体」**：红答"没人有权"——制度管不到：**援例的人把身家押在别人一个从没说出口的理由上；先例一旦被两家各取所需地用旧，就反过来替他们决定"今后不许再变"。**

### 组织 C-22｜度准房（O1 钢铁教派 下设·度量校准行）

- **一句话**：全城的"正常"从这里出厂——它替每具身体定义误差，却禁止自己被修。
- **信条**：「身体可以坏，基准不许动。」
- **职能与地盘**：O1 下设，柜面开在维护街最深处的恒温廊。管全城接口检测仪的校准、年检基准发放、"行准"巡借（把可移动的基准件借给各分站）；东门识别站与年检季都按它的允差表判合格。
- **铁规则**：
  1. **原器永不维护**——基准一修就不再是原样；原器坏了只能封存换新，换新之日全城检测仪重校一遍
  2. **一切身体判定以原器为准**——本人申诉"我没错"，须先在文书上承认自己是"待判误差"
  3. **行准外借期间，借入站一切检修暂停**——标准不在场，不准动手（这条被 C-13 叫号堂骂了十年）
- **可测试边界事件**：年检季前夜，原器被发现磨了半丝。封存换新，重校季三千份年检作废；不换，全城照着一个越来越错的"正常"生活。房里的做法是把这半丝记进"允差"——用修改定义的方式宣布原器没坏。
- **与其他组织冲突**：
  1. 与 O5 生态共生——活膜的长势天天越出允差，O5 拒交"膜基准"：膜不是设施，没有误差一说
  2. 与 C-08 报废听证处——报废认定书引用度准房基准；基准一换，已判"可报废"的件要不要重审？两张公文互相等待

- **关系类型**：沉证（两人私契——证物沉水，并誓「谁也不捞」；水底不在任何管辖里：O3 不进梦深处，O1 管不到水下，O5 说沉底无应答的膜即死物）
- **A ↔ B**：N26 褪地迁路人（B 类白名单——当年那段证物牵着他的一桩旧案，翻案就能还他名）↔ CH-014 晞棠（※已定核，非白名单——遗蜕观测者，全城唯一看得清水底那片「死物」还做不做梦的人）
- **张力**：当年一起沉下去的，是一片应答过的膜——里头存着能翻案也能杀人的记忆。如今 N26 旧案重提，翻案须取证，证在水底。CH-014 看得见：那片膜在水底还做着梦。捞=毁誓，把死者的梦拖上庭给人围观；不捞=N26 自己背着永远翻不了的名。**制度管不到：水底没人管，可誓在岸上；毁誓立不了罪目（O3 管不了私誓），但有比罪更老的东西管着。**
- **可测试场景**：N26 带着庭的取证函走到水边——函在制度里合法，水在制度里空白。CH-014 只说了一句：「它梦见你来了。」N26 把函折成小船放进水里，函漂了三步，沉了。两人站在岸上，替一片膜守着「不许被审判」的待遇：**直到哪天潮自己把它送上滩——海从不签任何人的誓，认浮棚的规矩也管不到海的心意。**
- **三色归属**：红（沉与捞都是自决，誓是两个意志的私法）；粉（水底的活膜与它的梦——梦深处边缘，庭的盲区）；青（取证函、翻案程序——岸上制度的徒劳）。
- **「谁决定身体」**：O3 答「证据须在庭上说清」——沉证答漏了：**有一类证物的本体就是一具身体（膜）；捞它上来作证，等于让死者再死一次给活人看。两个人用一场私誓，替制度划出了它自己划不出的界。**
