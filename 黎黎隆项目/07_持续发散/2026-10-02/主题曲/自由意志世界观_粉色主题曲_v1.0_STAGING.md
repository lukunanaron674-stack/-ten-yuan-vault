# 粉色主题曲 v1.0 ·《它死透了，还养着我们》（名待拍板）

> ⚠️ **2026-10-02 纠偏**：本文「十元代理判定 nz+x+xz」与「逐段十元表」**已作废，降级为未判定/待二审**——「粉＝nz+x」属颜色/阵营直接映射十元，违反 AGENTS.md 语义禁令 1（详见 `../十元理解纠偏报告_20261002_STAGING.md`）。**歌词文本、Suno 投喂与三色歌单对位不受影响，仍有效。**

> **十元代理判定（本首歌结构）：`nz + x`（+ 一点 `xz`）**
>
> | 十元 | 在粉里是什么 |
> |---|---|
> | **`nz`**（主） | **遗骸的余温与守墓的柔情**：巨物死了骨头还挂在天上，古老派守着它过日子——「不争霸、不逃、不想结束」。粉是三色里唯一**向后看**的：它的一切价值都来自"已经死掉的巨大事物" |
> | **`x`**（主） | **诡异的失控生机**：粉矿长在骨缝里像未愈的伤口；顺着人的梦往上长；谁靠太近咬谁一口——反噬 = x 的失控强度。粉受助却反噬青，正是 x 咬到伸过来的手 |
> | **`xz`**（一点） | **采粉人的命运不稳**：天赋门槛 + 冒险采集 +「带得走的发不了财，发了财的回不了家」 |
>
> **一句话内核**：**它死透了，还养着我们；我们守着它活，它咬我们一口——谁都不走。**
>
> **三色十元对照（现在三首齐了）**：
> 青 = `x并z`（规矩/计量/压榨）· 红 = `z`（拒绝只被观看）· **粉 = `nz + x`（遗骸的依恋 + 诡异的失控）**
> → 粉为什么反噬青：**x（失控）反咬 xn 化的青**（速览卡"青粉半帮半克"的十元根基）

## 一、逐段十元表

| 段落 | 十元 | 行动证据 |
|---|---|---|
| Intro | `n` | 巨物深鸣 + 晶体微光 + 骨原野的风：生态承载先立 |
| Verse 1 | `n`+`x` | 影子里生火提纯嫁人（n=生活在遗骸下继续）；粉矿像未愈的伤口、天赋门槛（x=欲望与稀缺） |
| Pre-Chorus | `x`+`nz` | 青开车来收、帮提纯；「我们收下帮助，也收下反噬 / 这不怪他们，也不怪粉」——**半帮半克的柔情版** |
| **Chorus** | `nz`+`x` | 「它死透了，还养着我们」「守着它慢慢地过」（nz）；「顺着你的梦往上长，长成你不敢说的形状」（x 失控） |
| Verse 2 | `xz` | 采粉人规矩：不带走一粒不属于他的光；带得走的发不了财，发了财的回不了家（命运不稳） |
| Pre-Chorus 2 | `nz`+`n` | 迁徙季天会低、关矿睡觉听它走过——「像听一头老朋友打鼾，它没踩下来就是善意」 |
| **Bridge** | `xz`+`nz`+`x` | 定义句：「是死掉的天，没凉透 / 是活着的人，不肯搬走 / 是这座世界最软、也最咬人的地方」 |
| Outro | `xz`→`nz` | 「像它翻了个身，梦见我们还在」——临界里收出依恋 |

**五大主题入仓**：主仓 **命运**（`xz + nz`：守候、失归、余温）；副仓 **本体**（`zn + x`：粉是什么——不在起手，只在 Bridge 做定义句）。
红线自检：✅ 未默认 zn 起手 ✅ 未用结局倒推 ✅ 端点均有行动证据。
