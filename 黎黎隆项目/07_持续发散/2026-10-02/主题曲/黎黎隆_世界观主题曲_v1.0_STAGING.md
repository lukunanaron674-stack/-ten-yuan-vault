## 一、母题 → 歌曲内核（先把为什么这样写讲清楚）

世界观母题只有一句：**「生命怎样改变自己的身体，才能继续进入更远的地方？」**
张力轴只有一对：**「去得更远」 vs 「还能回来」。**

这两句本身就是一首歌的主歌和副歌——所以主题曲不做"世界介绍"，只做**这道题的听觉化**。

核心机制（速览卡 §4 黎黎隆 zx8+xn3）：

| 机制 | 速览卡原文要点 | 落到歌里 |
|---|---|---|
| 留锚点 | 进未知区先留锚点（**xn3**） | 主歌：把一节自己刻在门站刻度里交给别人 |
| 路线重排 | 尾部改变通过条件，路线围绕自己重排（**zx8**） | 导歌：尾扫过的地方通道让边 |
| 锚点锁止 | 每当一枚锚成为他人依赖的公共节点，对应尾关节必须锁止 | **副歌核心句**：每留一个锚，就锁住我一节 |
| 拔锚代价 | 拔锚恢复自由，旧路线失去稳定 | 尾奏副歌：二选一，没有第三行 |
| 返身断点 | 公共接口仍正常，却失去了卸下任务身体、恢复原有器官协作的「对象特异返身路径」 | **桥段核心句**：回接床空着，只是找不到回身角落 |

**歌的内核一句话**：
> 他去更远的方法，正好是让他回不来的原因。

## 二、十元对齐讨论（和十元代理对齐的部分）

按《三元十元语义融合总表》第 6 节口令执行：**三元定底座 → 十元定结构 → 生补克定关系 → 五大主题定入仓**。
十元是**结构标签**，不用结局倒推；以下每一段都给了「谁→对谁→机制→变量前后态」的行动证据（铁边界 8）。

### 1. 这首歌整体的十元结构

**主十元：`zx + xn`**（去更远 / 留锚）
**副十元：`nz`**（停靠、不想结束）
**克位：`xz`**（返身断点 = 临界、失归、不能回头的轨道）

三元比例：
- `x`（醒）占比最高——歌词里几乎全是**物**：刻度、冷却液、承重带、润滑、插槽、壳、油、尾托。这是"醒"的质地：具体、物质、可维护。
- `z`（主体资格/确认）集中在副歌与尾奏——"被挂在别人的灯上"、"被叫开路者/遗物"，是**被看见**的执念结构。
- `n`（耐）落在 Outro 的门站与回接床——空间承载与安顿。

### 2. 逐段落十元表

| 段落 | 十元落点 | 为什么（行动证据） | 生 / 补 / 克 |
|---|---|---|---|
| Intro（门站自检音） | `n` | 空间承载：门站/维护所的稳定运转状态，先立"容器" | — |
| 主歌 1 | `xn3` | **黎黎隆把一节自己交给门站保管**：谁→门站与依赖路线的人；机制→尾尖接冷却液并按刻度留节；前后态→从"完整一体"变为"可被他人持有的公共节点" | 生位生 `z`（他人因此依赖他）；补位缺 `zx`（只有留锚没有开路） |
| 导歌 | `zx8` | **夺路**：谁→尾；机制→改变通过条件使路线重排；前后态→通道从"不可通行"变"围绕他通行" | 克位即 `xn`：每开一次路就多一枚要锁的锚 |
| **副歌** | `nz + z` | **锁止与不想结束**：谁→黎黎隆；机制→锚成为公共节点即锁尾关节；前后态→改向自由度下降；叠加"被挂在灯上"（z=被看见） | 克位 = `xz`：锁到极限就是回不来 |
| 主歌 2 | `x` | **欲望与代价**：更干净的骨头换一年的油；旧壳不降解夜里朝雾区爬（反噬意象） | x 的失控强度，被 `zx` 拖着走 |
| 导歌 2 | `xn` 变体 | 旧壳朝维护街爬 = 留出去的东西反过来找主人（xn 的污染） | 污染桥 |
| **桥段** | `xz` | **返身断点**：谁→远行者；机制→公共接口正常但对象特异返身路径消失；前后态→"能出"变"不能回" | 这是整首歌的**克位落点**，也是灾变本身 |
| 尾奏副歌 | `zx + xn` 合流 | 二选一：拔锚（恢复自由/旧路线坍塌）or 保灯（路线稳/自己锁死）。没有第三行 | 生补克同时摊开，主张力句 |
| Outro | `n` | 卸装槽里躺着一具不属任何任务的身体，尾托托住它 = 承载与安顿，回到 Intro 的容器 | `n` 收束，但不给答案 |

### 3. 五大主题入仓（这首歌属于哪一仓）

`命运`（`xz + nz`）为主仓：漂流、停靠、失归、归属重判。
副仓 `本体`（`zn + x`）：身体被改写者的主体资格。

### 4. 十元红线自检（对齐银矿红线）

- [x] 没有默认 `zn` 起手（起手是 `zx + xn`）
- [x] 没有默认 `n` 承载（`n` 只在 Intro/Outro 做容器，未提升为高级）
- [x] 没有用五大主题倒推十元，没有用结局倒推结构
- [x] 十元端点全部有行动证据（见上表）
- [ ] 不确定项：`xz` 作为克位是否需要在世界观侧固化为"返身断点的十元位置"——**待人工二审**

## 三、完整歌词

### Intro（器乐 · 无人声）
门站自检音：三声低频「嘀—嘀—嘀」；尾托液压排气；状态灯由青绿转墨青。

### 主歌 1
进雾之前，我先留一个名字
刻在门站那面墙的第三格刻度里
尾尖垂下来，接上青蓝的冷却液
他们说往前走的人，不必留证据

我把自己的一节，放在你门口
等路线稳了，你再把灯提在右手
承重带勒进肩膀，转身半径要够
异体的街口，从来不留窄口

### 导歌
可我的尾在长，长过你们画的线
它扫过的地方，通道就得让一边
他们管这叫开路，又叫不回头
只有我知道，哪节关节开始生锈

### 副歌
每留一个锚，就锁住我一节
路线越稳，我越是不能改向
把我的名字，挂在别人的灯上
我就成了那条，撤不回来的网

去得更远，是我说的
还能回来，是他们说的
中间只隔着一节尾骨的锁
和一张回接床上，没人躺的角落

### 主歌 2
第二片雾里，有更干净的骨头
他们说拔下来，能换一整年的油
保养身体的匠人，替我换了新口
旧的壳不降解，夜里朝雾区走

### 导歌 2
我听见它爬，像听见我自己
被丢在维护街，第三级台阶那里

### 副歌（重复）

### 桥段
公共接口是好的，插槽还亮着
卸装槽排着队，回接床空着
只是远行的人，再也找不到
那条只属于自己的，回身的角落

他们管它叫断点，管它叫进步
管我叫开路者，管我叫遗物

### 尾奏副歌（双声部 + 童声哼鸣）
要我把锚全拔了，你们就自由

只有尾骨一节一节地回答

### Outro（n · 安顿）
雾散了，门站亮起青绿
卸装槽里躺着，一具不属任何任务的身体
尾托托住它，像托住一句
没有说完的——我回来了

### 人声设计
- 主唱：气声、近麦、克制，不炫技；**不喊高音**（异体世界不唱"燃"）。
- 童声哼鸣只在桥段与尾奏出现 = 黎黎隆的小孩体态（只用声音暗示，不点破）。
- 尾奏双声部 = `zx`（去）与 `xn`（留）两个自我的对话，不是合唱。
