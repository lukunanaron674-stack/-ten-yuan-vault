# 黎黎隆世界观主题曲 v2.0 ·《门口与灯》（名待拍板）

> **定位区分**：
> - v1.0 = **黎黎隆个人主题曲**（`zx + xn`，锚与锁，被 `xz` 克住）——保留不动
> - **v2.0 = 世界观主题曲**（674 拍板结构：`nz + x并z + 一点z`）——本文件
>
> **一句话内核**：
> **身体是门口——世界从这进来、也从这看你是谁；换掉的是壳，换不掉的是里面那盏想被看见、一直有人等的灯。**

---

## 一、十元结构（674 拍板 → 十元代理落实）

| 十元 | 语义 | 在这首歌里是什么 |
|---|---|---|
| **`nz`**（主） | 依恋、停靠、柔情、不想结束 | 世界的底色：回接床铺着单、卸装槽温着水、钥匙留给要回来的人、共鸣庭的和声。**身体文明对每一具身体的舍不得** |
| **`x并z`**（主） | 表象、包装、被观看、身份接口 | **身体本身**：具体物（x）同时是主体资格的外显接口（z）。具象锚 = 角套/零件/刻度/接口/识别带/状态灯/透明窗——「识别带认你，认的是那盏灯，认得比名字还早」 |
| **`z`**（一点） | 执念、光点、追光、想被看见 | 两处提升位：副歌「那盏想被看见的灯没换过」；桥段「雾区留白是留给还没被看见的你」——对应世界观硬要求「世界必须始终留有解释不了的地方」 |

**与母题的关系**：母题问「生命怎样改变自己的身体，才能继续进入更远的地方？」
- 黎黎隆主题曲（v1.0）回答的是**代价**（锚与锁）
- **世界观主题曲（v2.0）回答的是底气**：改的是壳（`x并z`），不变的是停靠（`nz`）和想被看见的那点亮（`z`）——**所以才敢一直改、一直去更远**

**与 v1.0 的关系**：v1.0 是这道题的`zx+xn`解法（个人、剧烈、被克）；v2.0 是世界本身`nz+x并z`的温度（共同体、日常、托底）。**两首是一对**：v2.0 是世界，v1.0 是走进雾里的那个人。

## 二、逐段十元表（带行动证据）

| 段落 | 十元 | 行动证据（谁→对谁→机制→前后态） |
|---|---|---|
| Intro | `n` | 门站晨间自检音：容器的日常状态先立住 |
| Verse 1 | `x并z`+`nz` | 匠人→身体：换角套、上油（x=零件）；「壳要常修，里面的别乱动」（nz=对内核的依恋）；识别带→人：认灯不认名（x并z=身份接口） |
| Pre-Chorus | `nz` | 门站→远行者：卸装槽温水、回接床铺单、壳存第三格、钥匙留给任何要回来的人（**不想结束**的直接证据） |
| **Chorus** | `nz`+`x并z`+`z` | 核心句：身体=门口（x并z）→世界从这看你；灯亮着就有人等（nz）；换壳没换灯（z 不灭） |
| Verse 2 | `n`+`nz`+`z` | 共同体：新人装外置耳朵、全街灯调亮半格（z=被看见的仪式）；旧壳捐工坊做教具（n=安顿，壳会退役不被丢弃） |
| Pre-Chorus 2 | `nz` | 共鸣庭一人哼、全街和——共同体的不想结束，声音化的 nz |
| **Bridge** | `z` | 雾区留白：「不是忘了画，是留给还没被看见的你走过来」——世界的追光，**一点z** 的全部重量 |
| Final Chorus | 三者合流 | 「你换上的每一具新身体，都是同一句话：我回来了，我还在」——`x并z`（新身体）+`nz`（回来了）+`z`（还在=被看见） |
| Outro | `n` | 整排灯亮起，门站说「欢迎回来」——收在容器，不收在答案 |

**五大主题入仓**：主仓 **空间**（`x并z + n`：门口、容器、进入与停留）——世界观歌天然是空间歌；副仓 **命运**（`nz`：停靠与归属）。
（对比：v1.0 主仓命运、副仓本体；v2.0 主仓空间、副仓命运——**个人走向命运，世界停在空间**。）

**红线自检**：✅ 未用五大主题倒推 ✅ 未默认 `zn` 起手 ✅ 十元端点均有行动证据 ✅ 未借 v1.0 的锚/锁机制（两首歌不混设定）

## 四、曲式与速度

| 段落 | 速度 | 织体 |
|---|---|---|
| Intro | 68 | 门站晨铃 + 液压呼吸声 + 暖 Pad |
| Verse 1 | 68 | 钢琴为主，「里面的别乱动」一句几乎清唱 |
| Pre-Chorus | 72 | 弦乐进入，水声质感 |
| Chorus | 84 | 全弦乐 + 心跳样低频（很轻） |
| Verse 2 | 72 | 抽掉弦乐，「为他调亮半格」处加一声玻璃共振 |
| Pre-Chorus 2 | 76 | **哼鸣合唱进入**（共鸣庭 = nz 的声音化） |
| Bridge | 62 | 近乎清唱 + 童声哼鸣，「留了白」后停一拍 |
| Final Chorus | 84 | 多声部叠 + 哼鸣合唱，最暖处 |
| Outro | 68→自由 | 灯逐盏亮的音效，收在长尾 |

**与 v1.0 的听感区别**：v1.0 冷（E 多利亚、大提琴、锁）；v2.0 暖（C 大调+Lydian 微光、弦乐群、哼鸣合唱）。两首连播 = 世界与人对话。
