# 其他角色十元发散｜每小时任务

## 目的

为大叔、塔汀、奇美拉、裂缝听者建立自己的十元关系候选，并通过文字变量逐小时验证角色身体机制。大叔与奇美拉的组合按用户修正；小和尚暂不定组合。黎黎隆专属十元 `zx + z + 点 xn` 已锁定，不得复制给其他角色。

## 当前候选分配

| 角色 | 专属候选组合 | 核心身体机制 | 暂不借用 |
|---|---|---|---|
| 大叔 | `xn + n`（旧阶段：`xn + X并Z`） | 瘦长松人体 + 单侧巨臂承载链 | 黎黎隆尾部路线/尾部情绪 |
| 塔汀 | `z→n→x` | 回返膜保存并拒绝错误回接 | 黎黎隆尾根/锚定 |
| 奇美拉 | `x + xz` | 翼臂、胸腔、后肢服务飞行抓取压制 | 黎黎隆大尾体 |
| 小和尚 | 未定 | 先观察服装、仪式动作、旧装置回应 | 不强行借用任何角色组合 |
| 裂缝听者 | `z→x→n` | 模块发令、裂缝改写、活体补偿 | 黎黎隆自由尾巴 |
| 透明人 | 暂不分配 | 缺正式原稿 | 不伪造 |

## 执行规则

- 每小时只写一个角色、一个变量。
- 所有输出标记为 `CANDIDATE_TEXT_ONLY`。
- 不改正式角色 Canvas，不自动升级为 canonical。
- 不启动 H3、ComfyUI 或批量生图。
- 透明人等正式原稿，不用占位设定强行分配十元。
