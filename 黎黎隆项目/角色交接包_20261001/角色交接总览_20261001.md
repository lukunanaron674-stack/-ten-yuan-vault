- **桶位**：红桶｜自由意志·失踪归来引路人

**一句话角色卡**：红色远征队失踪归来的引路人，身体正在被能够记录"已经发生之状态"的青色晶体逐渐替换；他靠晶体寻找失踪者，却每救一个人，就离原来的自己更远一点。

**头部冻结项（必保，禁止漂移）**：黑乱发(粗发束/边缘破碎) / 冷灰紫肤色 / 成年男性脸+略疲惫克制神态 / 下颌面颊短胡茬 / **青白晶体自额头跨一眼向面颊垂落的结构关系(不可重排)** / 未遮眼冷青白 / 深暗红围巾(头肩最大身份色块) / 原稿粗粝手绘感(脏线干笔薄涂破边)。
禁止漂移：3D厚涂、珠宝式晶体、幼化眉眼、改晶体覆盖区、全身赛博化、字幕画进图。

**中全景可发散**：深色破损旅行层/短披肩/旧布/束带/包扎、实用裤装旧靴手套、红围巾长度破口动态、青晶向前臂手部有限扩散、少量搜救挂件。**不再强制继承旧版大背包/青蓝腰灯/白胸架/宽厚重装体型。**

**赤途远征队**：红色区流动型危险区域行动组织（非军队）。任务=失联聚落重寻通路/青色侵蚀带搜救/回收生命与社会价值物件/地图不可信时以人重建可走的路。红=主动选择·继续行动·把约定带过危险区；岑烬失踪留的红围巾既是组织痕迹也是"仍认自己是原来那人"的证据。

**青色异常·记忆晶（X并Z 型生物青结构）**：青色区域搜救失踪→数月后独归，左头面与部分肢体青白晶化。非矿物非机械植入，记录接触对象"已发生状态"（动作/物理/路线/声音残留/部分意识记忆）；越深入越把人体当可记录/保存/替换对象。
- 残迹视觉：晶体侧读空间残留→见过去行动，适合寻人/追踪/重建原通路；偶给"不应属过去"画面仅记待研究，不锁预知。
- 状态复现：晶化臂接触物体短时复现已记录局部状态（硬度/一次动作）；非无限复制。

**代价**：使用越频晶化越扩散，顺序 脸/眼→臂→肩→胸腔→深层神经记忆。真危险=晶体开始替他保存自己的记忆（己忘晶体能重放/己记版与晶体版不一致/晶体比本人更准"记得"/"哪个记忆才算我"持续冲突）。

**核心句**：他靠晶体寻找失踪者，却每救一个人，就离原来的自己更远一点。
**赤途↔青晶冲突**：组织越不敢相信他，越不得不依赖他。（内部分裂：应隔离 vs 唯一可靠导航；官方禁一线，大规模失联仍秘密调用）

**角色主题·本体**：若记忆/习惯/动作/判断都能完整保存，原来那人还必须存在吗？青晶越完整岑烬本人越现缺口。红围巾=关系/选择/仍是谁；青晶=保存/功能化/替代。红青长期共存不简化好坏。

**十元落点**：ZN(靠承诺关系"我是谁"维持连续，本体主入口) / X(身体边界·晶体与原本人分界) / X并Z(青资源+肉身组新行动系统·外部侵蚀) / NX(能力越有效主体越被代价压缩) / NZ(搜救把保存自己与保住别人拉同选择)。强度须经事件验证，不因其红组织写死。
