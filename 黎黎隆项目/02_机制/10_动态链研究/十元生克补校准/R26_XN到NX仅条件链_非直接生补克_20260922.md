# R26｜XN 到 NX：仅条件链，非直接生补克

## 本轮问题

检验 `XN克ZX → 自主路径闭合失败 → NX出现` 中，XN 对 NX 究竟只是前置条件，还是存在直接的生／克／补关系。

## 用户已确认／当前正本

- 黎黎隆：ZX主 / Z中 / 小XN。
- `XN 克 ZX` 已确认。
- NX：主体不占据方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。
- 当前十元位置表中：NX 被 NZ 生；被 Z 克；与 ZX 互补；NX 克 X并Z；NX 生 X。XN 与 NX 没有直接生／克／补配对。

## 支持案例

城市 XN 把黎黎隆过去的即兴改道记录并转成新的前置结构，使 ZX 的即时改写范围下降。若此后黎黎隆为了继续任务，暂时沿维护员已经掌握的检修权限与既有路线推进，则 NX 可以在后段成立。

这里 XN 的直接作用仍然落在 ZX：压低即时显权与单次改写长期结构的能力。NX 的成立还需要额外条件：外部既有方向／权限／通道真正接管本段推进。

因此可写成条件链：

`XN 克 ZX → 单主体原路径闭合失败 → 外部既有方向/通道成为必要条件 → NX成立`

不能缩写为 `XN 生 NX`。

## 反例／边界

XN 克制 ZX 后，黎黎隆仍可：

1. 用 Z 找到另一处规则漏洞并独自绕行；
2. 缩小目标，继续以自身行动完成局部任务；
3. 暂停任务而不进入任何他者通道。

这些情况下 `XN 克 ZX` 已成立，但 NX 完全不出现。因此 XN 不是 NX 的充分生成条件。

反向边界同样成立：NX 可以在没有 XN 压制 ZX 的情况下出现，例如主体主动选择沿既有身份、关系、权限或通道借力推进。因此 XN 也不是 NX 的必要条件。

## 判定

### 本轮推论

`XN → NX` 不判直接生、克或补。当前只能保留为条件链中的前置事件之一。

主次与作用方向：

- 主作用：`XN ─克→ ZX`
- 次级条件变化：ZX 原有自主路径可能闭合失败
- NX成立的直接门：方向／权限／解决通道外置，主体实际沿其推进

### 置信边界

高置信否定“XN直接生NX”以及“XN克ZX必然转NX”。依据是当前正本位置表不存在 XN↔NX 的直接关系，且支持案例中 NX 需要额外变量，反例中 XN克ZX可在无NX情况下完整成立。

本轮不修改十元定义，也不新增 canonical 关系。

## 《黎黎隆》应用

由于 `XN → NX` 直接关系未成立，本轮不把它包装成新的生克补制作零件。

可保留的审核结构：

`XN克ZX → 自主方案失败` 之后必须重新判断：

- 若黎黎隆仍自行重设方向：不是 NX；
- 若仅借一次资源但仍掌握最终方向：不是 NX；
- 若外部既有方向／权限／通道接管本段推进，黎黎隆沿其完成行动：NX 才成立。
