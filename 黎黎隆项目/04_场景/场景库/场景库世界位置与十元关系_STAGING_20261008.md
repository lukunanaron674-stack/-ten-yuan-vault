# 场景世界位置与十元关系｜候选映射

> [!warning] 状态边界

## 映射口径

1. 当前场景库有 **17 个 SC 编号地点**，对应图像由 [[场景库总索引]] 列出；仓库另有其他实验板、角色背景、参考图等，不能仅因入库就算作新地点。
2. 世界地理的稳定锚点目前是模块化生活城、遗骨之地、R5 自由锚港、R6 粉色生态带及未知边境等；候选地图中的具体方位、河道、山脊和边界不视为已锁定。
3. 下表“十元区域参照”仅转录 [[黎黎隆项目/20_Agent系统/03_知识库/上下文提炼/CTX-10_世界观]] 中的**三色区域发散方向**：青 `Z × X并Z`（优先 `X并Z→生Z`），红 `Z + ZN`（未规定主次），粉 `NZ主 / X并Z次`。它表示区域设定参照，不是该地点的客观十元，也不是已经测得的人的感受谱。
4. 按现行 [[三元十元感受模型_核心正本_v1.0_20261007]]，十元描述具体语境中人的关系性感受；最终体验定义仍在迁移中。没有人类反馈、具体事件和感受强度谱时，地点层的“十元主次/生克补关系”统一记作 **未测 / 待证**。不得从颜色、职业、表情或建筑名直接推定。

## 十元关系记录：先留证据槽，不先填答案

对某个具体场景建立地点级十元关系，需补齐以下记录后再判断主次：

| 字段 | 记录要求 |
|---|---|
| 体验对象 | 谁在什么具体故事/镜头/交互中体验该场景；不同角色可分开记录。 |
| 具体语境 | 时间、行动、关系、场景变化；同一建筑在不同事件中可能激活不同感受。 |
| 直接感受 | 人类体验者的描述或盲测反馈；不能由图像颜色、组织标识、职业或 AI 推断替代。 |
| 十元强度谱 | X / Z / N / ZN / NZ / XN / NX / ZX / XZ / X并Z 各记 1–10；无数据则留空。 |
| 主次 | 由本次强度谱得 Top1 / Top2 / Top3；这是该语境下的主次，不是地点永久属性。 |
| 关系 | 依据具体变化和感受反馈检验生、克、补张或动态链；没有变化证据时不填关系结论。 |

## 组织与区域关系速记

- **青色城市服务层**：O1 钢铁教派负责维护、检修和门站值守；O6 青色商会负责接入交易与签约。两者同层竞争，不写成上下级。
- **红色流动/边界层**：O4 船队支撑锚港与水路迁徙；O3 审判之庭沿固定裁决空间及巡回路线办案；O2 佛教哑区是庭明确让位的庇护地。三者不是统一红色政权。
- **粉色生态层**：O5 的菌林、活膜、遗蜕和记忆寄存构成生态/设施网络；诡异魔法是个人术法类别，不自动等于 O5 组织成员。O7 塔脊集会有独立设定，不能因“塔站”同名而并入 O1。
- **未知边境/交界**：SC-01、03、08、10、18 当前没有足够材料锁定组织辖区或区域十元参照，继续保持未分配。
