# 黎黎隆场景视觉共性 v0 候选规则

以下规则来自当前联系表、13 张代表图全图核验、现有场景/世界观 Canvas 和十元应用实验室。每条都分为“图中可见事实”和“可复现操作”；它们是候选规则，不是用户最终批准的全片风格。外部参考只抽象操作，不继承 IP 造型、原配色或现实地点身份。

## 1. 先读结构，再读材质

- **图中事实**：D01/D02 候选图依靠拱门、环线、主管、中心台和维护臂架读空间；I04 骨架图依靠中轴、肋骨重复和人物尺度读空间。
- **可复现操作**：先做前景遮挡/门槛、中景功能主体、背景入口或高差路径三层灰度草图；结构读不通时不加纹理和发光。
- **验收**：缩小到缩略图，仍能回答“人在哪里、设备服务什么、入口/通路在哪里”。

## 2. 公共维护必须成为空间语法

- **图中事实**：D01 有工具架、低位水池、卡箍、管线和维修台；D02 有环形工位、等距机械臂和中心生体；IMG-263/196 把锚件与夹具拆成局部模块。
- **可复现操作**：每个主要场景至少保留一个可见维护位、一个接触/挂点和一个维护后继续运行的空间结果；不要只画“设备存在”。
- **验收**：观众能看出谁在维护什么、从哪里接入、维护是否改变可通行路线或身体状态。

## 3. 用重复形状建立跨场景一致性

- **候选形状词**：拱、环、分段管/骨节、低位平台、垂直挂点、可接入窗口。
- **可复现操作**：森林、室内、城市都可用同一形状家族，但按功能改变尺度；不要用同一张背景或同一套纹理复制场景。
- **状态**：候选；需要三场景对照验证。

## 4. 角色/背景的信息量要分层

- **图中事实**：候选设定板把机制拆成白底多角度；场景候选把大结构、功能件和局部细节放在四格中；外部参考常常细节很满。
- **可复现操作**：远景只保留主剪影、路线和焦点；中景增加维护位与尺度锚；近景才显示锁件、接口、材质裂痕。不要把外部参考的细节密度直接搬进动画背景。

## 5. 色彩的功能优先于题材色

- **已有项目规则**：D03 Canvas 已写入 P00 五色锁：深墨青、灰紫、暗红、青绿、淡青灰；允许明度/透明度/叠色变化，禁止新增独立色相成为系统色。
- **首轮图中事实**：D01/D02 候选确实反复出现灰白主体、灰紫生体、暗红带、青色接口；外部参考墙则出现深绿、金黄、棕色、写实灰等不同色彩体系。
- **可复现操作**：把 P00 作为项目候选功能色系统；外部参考只借明暗和色块关系，不把外部色板当作黎黎隆定稿。

## 6. 自然与技术要有可观察关系

- **图中事实**：D01 的紫色生长物穿过建筑/管线；D02 的生体中心和机械臂共同构成公共空间；IMG-120 的骨骼由支架托住；IMG-168 的龙与塔楼嵌合但没有生活动作。
- **可复现操作**：每次引用自然形体时，补一个“它改变了什么功能/维护/通行”的动作证据；没有关系变化的自然形体只标“氛围参考”。
- **验收**：删掉十元术语后，画面仍保留可观察的自然—技术关系，而不是只剩漂亮生物。

## 7. 模块必须能拆层、能连续

- **建议层级**：底层空间大面 / 结构轮廓 / 功能接口 / 生体异常 / 少量气氛。
- **适合拆层的对象**：环形轨道、支撑臂、卡箍、挂带、入口拱、骨节、工作窗、标识圆章。
- **不适合直接复用的对象**：复杂写实砖纹、单张图独有的光束、带完整文字的外部图表、过多微型工具。

## 8. 当前需要做的最小验证

不用 H3。用 `IMG-171` 或 `IMG-271` 任选一个场景候选，与用户批准的黎黎隆原稿做静帧四宫格：

1. 角色站位与尾尖接触点；
2. 自由尾 / 正在挂接 / 已锁止三种状态；
3. 维护位是否改变人物活动区；
4. 同一 P00 颜色功能是否仍能读出主体、异常和接口。

只改“锚点与空间尺度”一个变量。若四项中至少两项无法无文字回答，维持 `FAIL_IR_EVIDENCE_MISSING`，不进入 H3。
