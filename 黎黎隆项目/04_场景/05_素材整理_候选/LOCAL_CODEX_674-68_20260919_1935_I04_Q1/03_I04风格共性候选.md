# I04 骨骼空港：风格共性候选

> 仅基于本轮指定的 6 张 q1 图片。以下是可复现规则草案，全部标记为 `CANDIDATE_NOT_FROZEN`，不构成 canonical 资产、批准结论或正式任务卡。

## 1. 共同视觉语法

- **形状概括**：用“长弧条 + 连续节段 + 扇形肋条 + 拱形框架 + 细悬线”组成 I04 的主形状语法。局部近景强调缝隙和重叠，远景强调长轴、拱顶和悬挂关系。`CANDIDATE_NOT_FROZEN`
- **线/块密度**：主体骨骼的线密度高于环境；环境用大块砖墙、黑腔、地面留白承接。近景可以高密度，广角大厅必须保留可读的空区和人物尺度锚点。`CANDIDATE_NOT_FROZEN`
- **分层**：至少三层：前景的拱架/玻璃/粗大骨面，中景的主骨骼与缆线，后景的墙、窗、黑色空区、展板或地面动线。不同层用清晰的遮挡和明暗分开，不把所有骨条压成一张平面。`CANDIDATE_NOT_FROZEN`
- **材质抽象**：骨材用哑光、略粗糙的灰白或冷灰蓝；风化局部可进入灰棕和暗褐；砖石/建筑用暖棕块面；玻璃用低透明度边线和局部反光；缆线用细、亮、低纹理线。材质以色块、边缘和少量纹理表达，不追求逐根写实。`CANDIDATE_NOT_FROZEN`
- **功能点色**：冷青/青蓝作为航道、状态、编号和张力提示；暖金作为环境照明与停泊节点；红色仅作为异常或危险的稀有标记。功能色面积要小，避免改变骨材和建筑的主色关系。`CANDIDATE_NOT_FROZEN`
- **镜头/构图**：三种可复用构图：①近景沿重复条带斜向滑行；②大厅中心轴慢推/抬头，利用拱顶和长轴建立方向；③从地面人物或散落节段切入，沿对角线或缆线升高。广角须保留人物尺度，近景须保留缝隙节奏。`CANDIDATE_NOT_FROZEN`

## 2. 动画可复现规则

1. **重复件先动，主体后动**：先让光、阴影或小节段沿重复骨条逐格传递，再让大型骨骼或门框发生缓慢位移；不要让整个骨架无差别摆动。`CANDIDATE_NOT_FROZEN`
2. **悬挂件遵守张力**：缆线先拉紧、连接点再稳定，主体只产生小幅延迟摆动；以一到两次可读的回弹表达重量，不做持续漂浮。`CANDIDATE_NOT_FROZEN`
3. **通行以遮挡表现**：利用肋条、拱门、玻璃边界和黑腔形成连续门框；角色或光点逐层被遮住再出现，形成空间深度。`CANDIDATE_NOT_FROZEN`
4. **地面链条以对位表现**：散落节段可拖、转、嵌入主链条，动作终点必须落在明显的缝隙或节点上；适合低机位跟拍和短促功能色反馈。`CANDIDATE_NOT_FROZEN`
5. **人只作尺度与方向锚点**：人物保持小比例、动作简洁，承担“抬头、经过、检查、搬运、等待”等可读行为；不把参考图中的人物身份或活动解释为项目设定。`CANDIDATE_NOT_FROZEN`

## 3. 十元动态链候选库

以下每条都采用“可观察结构 → 候选机制 → 可拍事件”三段式，且均不是冻结分类：

- **链 A**：重复肋条与窄缝 → 分格通行/信息逐格传递 → 冷青光沿缝隙推进，角色穿过一组连续门框；`CANDIDATE_NOT_FROZEN`
- **链 B**：地面连续节段与旁侧散件 → 拆分、搬运、重新对位 → 角色将散件拖回主链，节点闭合后打开下一段路线；`CANDIDATE_NOT_FROZEN`
- **链 C**：顶部悬线连接大型骨骼 → 张力校准/方向稳定 → 缆线依次拉紧，骨骼小幅摆动后对准空港航向；`CANDIDATE_NOT_FROZEN`
- **链 D**：玻璃隔挡、展台和开放地面 → 观察区与维护区分层 → 镜头沿玻璃横移，检修光点隔着边界完成扫描和交接；`CANDIDATE_NOT_FROZEN`
- **链 E**：拱顶、长轴、楼梯与小人物 → 高差动线/公共汇聚 → 地面人流经过时，上方骨骼阴影移动并把注意力导向下一层入口；`CANDIDATE_NOT_FROZEN`
