# 世界观可吸收机制候选

本页只把已存在素材中可观察的结构，映射到既有 Canvas 已经存在的世界观分支。它不新增人物、不改十元标注、不重做故事动态链。每条都分成：可观察事实 → 候选机制 → 可拍事件。没有足够证据的部分明确标为 `CANDIDATE`。

## 既有约束

- `黎黎隆_世界观总纲_v2.0.canvas`：奇幻是自然，机能是文明；身体维护、接口、返身和探索是世界的技术主轴。
- `黎黎隆_世界观发散树_R5_全量_v1.0.canvas`：当前 focus 是“继续活下去”，相关既有分支为 `A2 技术承担维护与替代`、`A3 异常被日常吸收`、`C1 接口成为生态条件`、`C3 对象分类开始失效`。
- `黎黎隆_场景风格视觉化_R1-R6_本地全量_v1.3.canvas`：P00 五色锁、前中后景、功能接口和“参考图只借明确部分”是视觉约束；外部参考的颜色与 IP 不继承。

## 候选机制卡

### M-01｜身体维护是公共基础设施

**证据**：`IMAGE-171` D01 公共尾部维护站、`IMAGE-271` D02 环形公共身体维护台。两张候选板都能看到维护位、环线/拱门、接触点、工具或机械臂，以及维护完成后空间仍能继续被使用的关系。

**可观察事实 → 候选机制 → 可拍事件**

`生体/身体结构占据空间 → 维护位、夹具、冷却/供水和等待位围绕它生长 → 角色进入、接入、卸载，维护位置或公共通路随状态变化。`

**已有链条关联**：直接承接 `A2` 与 `A3`，也与总纲的“身体服务缝 / 停靠与休息 / 身体维护所”一致。不是新增设定。

**动画用途**：街边几分钟维护、尾部维修站建立镜头、维护后人流改道、日/夜同一空间连续性。

**边界**：D01/D02 是项目生成候选，不是 canonical。不能由漂亮渲染推出“所有公共设施都长成环形”。

### M-02｜尾部锚定会改变公共路线

**证据**：`IMAGE-263` D01 巨尾锚序锁身组件；它把自由节、锁止节、挂点、承力腿和卸载动作拆成可读状态。`黎黎隆_世界观总纲_v2.0.canvas` 的 `lili_route_authority` 已明确“锚稳但尾巴仍全自由”即失败。

**可观察事实 → 候选机制 → 可拍事件**

`分段尾/管与环件接触并锁止 → 锚点承力，部分关节自由度下降 → 原本不稳定的桥带/挂点/人流获得可用路径；拔锚后旧路线失稳、尾部自由度恢复。`

**已有链条关联**：只把既有 `夺路尾 / 锚序锁身` 的力链变成可画道具状态，不改事件顺序。

**动画用途**：自由 / 正在挂接 / 已锁止 / 拔锚失稳四状态近景；同时让背景中的路线或人流发生一项可见变化。

**边界**：不能把锚序组件升级为最终角色模型，也不能把尾巴写成武器或通用机械臂。

### M-03｜天然巨构先存在，人造系统后来挂接

**证据**：`IMAGE-187` 自然历史博物馆骨架大厅、`IMAGE-110` 骨架大厅/展陈结构、`IMAGE-120` 鲸骨结构近景；另有 I04 Canvas 的 `seed_I04`：“远古巨兽的肋骨成为飞行器停靠架，机械环沿骨骼结构嵌合生长”。

**可观察事实 → 候选机制 → 可拍事件**

`连续肋骨/脊柱与拱顶形成大尺度方向线 → 人工平台、支撑或停靠件选择少数骨节挂接 → 人物沿自然间距穿行或检修，技术层不必替换整个生体结构。`

**已有链条关联**：与 `NZ + Z` 的 I04 场景种子一致；只补充空间结构证据，不把现实博物馆身份写进世界史。

**动画用途**：骨骼空港大全景、肋骨间穿行、挂接点特写、前景粗骨—中景平台—后景入口三层构图。

**边界**：照片没有给出黎黎隆世界的历史因果、人物尺度或具体停靠动作；这些必须在原创镜头里重新设计。

### M-04｜高负荷身体功能必须有对象特异的外部工作窗

**证据**：`IMAGE-196` D02 外脑映脑窗冷却夹具；图中可观察到夹具开合、半透明膜、脑组织接触和冷却方向。`黎黎隆_世界观总纲_v2.0.canvas` 的 `external_brain_work_window` 已规定工作窗随功能切换而换位，附件不能对任意壳面同样有效。

**可观察事实 → 候选机制 → 可拍事件**

`透明膜/脑组织与夹具形成局部接触 → 冷却与维护只在当前工作窗有效 → 角色切换任务时旧窗撤回、夹具换位，错误接入会导致维护失败或返身风险上升。`

**已有链条关联**：对应总纲的映脑窗与 `A3` 外显维护候选，也能与既有塔汀回返条件链对接；本轮不新增塔汀能力。

**动画用途**：夹具贴合、工作窗换位、错误接入对照、维护完成后释放。

**边界**：道具候选图不证明正式角色的器官比例和位置；禁止把半透明膜直接当翅膀或纯 HUD。

### M-05｜接口会成为生态条件，也可能让对象分类失效

**证据**：`IMAGE-079` 生物混合机器人研究图展示生命材料、人工材料、制造和控制模块的拆分；`IMAGE-181` 物种分类圆章展示统一边框、剪影和规格标识；既有发散树已有 `C1 接口成为生态条件` 与 `C3 对象分类开始失效`。

**可观察事实 → 候选机制 → 可拍事件**

`生命/材料/控制被拆成模块和接口 → 接口可能从工具变成身体或环境的一部分 → 维护站、居住空间或公共标识必须面对“这是生物、器官、设备还是第三类对象”的实际操作问题。`

**动画用途**：维护规格标识、接口不兼容导致的分流、软体生物依附设备的近景。

**边界**：两张图没有证明黎黎隆已有分类制度或权利制度；只能作为机制研究和标识语言候选，不能直接写成社会设定。

### M-06｜X并Z 的可视重点是路径连续性被切断，而非“废墟气氛”

**证据**：`IMAGE-016` `ref_05.webp` 的洞穴—遗迹—中央石台构图提供“自然空间吞入旧结构”的结构参考；现有场景 Canvas 的 R04 规则已写为“连续→中断、路径→截断、空洞、错层”，并明确不是黑色/恐怖的同义词。

**可观察事实 → 候选机制 → 可拍事件**

`连续洞体与遗迹方向线被中央体量和暗部切开 → 路径不再闭合，但空间仍保留可利用的台面、入口或残余结构 → 角色必须改变路线、寻找新挂点或判断哪一段仍可返回。`

**已有链条关联**：只强化既有 `X并Z 撕裂` 的视觉证据；不把参考图当作新的灾难事件。

**动画用途**：入口建立、路线突然截断、前景黑块—中央承力物—后景遗迹三层构图。

**边界**：该参考偏写实高细节，不能直接作为黎黎隆背景完成度或主色标准。

## 吸收优先级

1. **优先可进入场景生产**：M-01 公共维护、M-02 尾部锚定、M-03 巨构挂接。它们已有本地候选图、既有 Canvas 链条和明确动作接口。
2. **需要角色/道具验证后再用**：M-04 工作窗。机制链已有，但需要对象特异位置和错误接入的静帧证据。
3. **保持研究状态**：M-05 分类/接口生态、M-06 X并Z路径截断。它们适合继续做单变量构图或机制卡，不应直接冻结为世界规则。
