# 《黎黎隆》场景氛围概念背景｜常用描述词

> [!important] 备用风格档案
> 这套描述词只用于备份本轮已经跑通的“氛围概念背景”语言，方便未来需要时调用。本轮 R1 不受它反向限制，后续也不要求每张图完全复制；具体生成仍按场景需要自由发挥。

## 核心画面语言

**粗粝克制的二维平涂概念背景，手绘边缘，清晰剪影，前景/中景/远景三层，适合动画背景分层；不是写实摄影，不是3D。**

## 常用描述词

```text
Use case: stylized-concept
Asset type: 《黎黎隆》二维动画场景背景板 / 世界观氛围概念图
Style/medium: 粗粝克制的二维平涂概念背景，手绘边缘，清晰剪影，前景/中景/远景三层，适合动画背景分层；不是写实摄影，不是3D。
Composition/framing: 16:9 wide establishing shot, eye-level slightly elevated camera, stable horizontal horizon, clear foreground framing, readable midground subject, atmospheric background, generous negative space for character placement.
Lighting/mood: 单一漫射光源，雾、反射和明度层次服务空间阅读；安静、陌生、可居住，但没有糖果感和廉价奇幻感。
Materials/textures: 纸面颗粒、粗线稿边缘、湿石、薄雾、水面反射、旧结构与生体表面；材质变化服从剪影和空间层次。
Animation use: 背景能拆成前景/中景/远景，角色位置有可用留白，水平线和主要结构稳定，不能只追求单张海报效果。
```

## 场景拼装模板

```text
Scene/backdrop: 黎黎隆的异种[场景名称]，[自然结构]与[旧机械/生体结构/生活设施]自然共存；[一句具体世界机制]。画面像被长期使用过的地方，而不是展厅或普通风景插画。
Subject/environment: 前景是[可走位结构]；中景是[主要空间/事件容器]；远景是[尺度参照和雾中结构]。让结构关系本身说明世界如何运作。
Constraints: 不生成未指定角色，不加入文字、标志或水印；不复制外部作品的角色、IP、原构图或原配色；保留角色可放置的负空间。
```

## P00 五色变量

只使用：`#142A34` 深墨青、`#855D8F` 灰紫、`#913840` 暗红、`#69D4CE` 青蓝绿、`#CDE7E6` 淡青灰。允许单色、双色、三色和五色；不要求平均分布。

- 深墨青：轮廓、结构、暗部
- 灰紫：生体、异常、奇异重音
- 暗红：生命、危险、警示、焦点
- 青蓝绿：技术、能量、接口、灯光
- 淡青灰：雾、湖面、亮部、留白

颜色只是入口，十元关系仍需由形体、空间、动作和事件判断。

## 已跑通的四种用法

- R1-01 单色：安静空镜、暗部空间
- R1-02 双色：常规场景底板，空间层次最稳
- R1-03 三色：灰紫菌丝/生体重音，森林生命感
- R1-04 五色：暗红与青蓝绿作为具体结构上的小面积重音，适合机制和事件镜头

对应素材位于 `R1_场景配色/assets/`；生成时曾登记为候选，当前逐图状态以 [[R1-R6_39图审核结果_v1.0]] 为准。
