# 黎黎隆｜场景视觉参考本地化

## 目的

把场景风格 Canvas 里的外部参考图全部下载到 Vault 本地，改成 Obsidian Canvas 原生 `type:file` 节点。

这样就不会再出现：

- Pinterest 登录墙
- Behance / 外站 iframe 空白
- 需要逐个网页登录
- 断网后参考图全部失效

## 使用 Skill

`07-Codex大脑库/skills/Canvas参考图本地化/`

文件：

- `SKILL.md`
- `reference_manifest.json`
- `scripts/localize_canvas_refs.py`
- `run_localize.ps1`

## Windows 一键执行

在 Vault / Git 仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\07-Codex大脑库\skills\Canvas参考图本地化\run_localize.ps1" `
  -Canvas ".\黎黎隆项目\你的场景风格Canvas.canvas"
```

默认图片写到：

```text
黎黎隆项目/场景视觉参考/assets/references/
```

脚本默认生成：

```text
原Canvas名_LOCAL.canvas
```

## 正确节点形式

```json
{
  "type": "file",
  "file": "黎黎隆项目/场景视觉参考/assets/references/ref_style_A01.jpg"
}
```

网页来源 URL 只保留在文字说明里，不再作为图片显示节点。

## 固定规则

1. Pinterest 页面 URL 不进入 Canvas 预览节点。
2. 已有 `i.pinimg.com` 直链时直接下载图片。
3. direct URL 失败才调用 `baoyu-fetch --download-media`。
4. 本地化后抽查至少 5 张图，离线状态也必须可见。
5. P00 五色配色母版继续使用本地 file 节点。
