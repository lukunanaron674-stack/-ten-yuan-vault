# R6｜场景生产规范 v1.0

状态：`FROZEN_SCENE_RULES｜场景规则已冻结；角色身份与 R5-02 严格盲测仍保持开放`

研究收束报告：[[R6_研究收束报告_v1.0]]

本稿从实际生成候选和 39 图审核结果中提取场景生产规则。冻结范围仅包括场景结构、P00 五色职责、R4 动态色彩脚本和 R5 关系判据；未完成角色设计不在冻结范围内。

逐张审核结果：[[R1-R6_39图审核结果_v1.0]]

## 一、目前最稳定的画面骨架

- 16:9 宽幅建立镜头；前景／中景／远景至少三层。
- 前景用深墨青承重和遮挡，中景承载事件或角色走位，远景用淡青灰压缩尺度。
- 机械结构必须沿生体结构嵌合，不能像贴纸一样覆盖在奇幻背景上。
- 轮廓、路线、负空间先成立，纹理和局部发光后置。
- 候选图以“可拆成动画背景层”为目标，不以精修插画细节量为验收标准。

## 二、P00 色彩职责（已冻结的场景规则）

| 色 | 当前从候选中观察到的有效职责 | 生产注意 |
| --- | --- | --- |
| `#142A34` 深墨青 | 轮廓、骨架、平台、机械暗部；R2-01 最能稳住结构 | 过量会吞掉角色手脚和尾巴 |
| `#855D8F` 灰紫 | 生体膜、菌脉、异常边界和修补痕迹 | R2-02 需审核面积，不能变成均匀紫滤镜 |
| `#913840` 暗红 | 裂口、警示、生命脉搏、冲突焦点 | R2-03/R4-03 显示其更适合状态重音，不宜默认铺满常态背景 |
| `#69D4CE` 青蓝绿 | 接口、能量流、导航、稳定回路；R2-04/R4-02 证据清楚 | 必须附着真实接触点，不能代替十元关系 |
| `#CDE7E6` 淡青灰 | 雾、远景、空间留白和事件结束后的恢复 | 过量会削弱骨骼重量，需由深墨青托底 |

颜色不是十元标签。关系必须由形体、空间、动作和事件变化承担。

## 三、R4 色彩脚本（已冻结的场景动态规则）

候选链：

`R4-01 安静生命 → R4-02 真实接触 → R4-03 连续结构被切断 → R4-04 稳定修补结果`

- 起：低对比、青蓝绿与暗红退到背景功能位。
- 承：青蓝绿集中到接口和接触点，不能全画面霓虹化。
- 转：暗红与青蓝绿一起服务“切断／警报／机械施力”的具体位置。
- 合：淡青灰重新打开空间，青蓝绿降低成稳定回路，暗红退为余热或残留警示。
- 四张已完成场景连续性与事件因果审核；角色身份稳定性仍属于角色研究，不在本次场景冻结范围内。

## 四、R5 关系判据（已冻结的场景判据）

- NZ 互依：必须看到双方之间的真实接口和双向维持；表面覆盖不够，彼此分离才是负样本。
- X并Z 分割：必须看到真实断口、模块空隙或不可逆错层；表面接缝不够，完整延展才是负样本。
- XN 路径约束：必须看到共同装置改变多体型路径；有绕行分流的是对照，没有共同门禁和统一路线的是负样本。
- 盲审时先遮住编号和十元标签；若只凭颜色就能猜出答案，说明关系设计不够结构化。

已知边界：R5-02 的关系设定符合对照，但与 R5-01 的镜头尺度漂移；已决定保留为“关系成立但盲测可比性不足”的对照，不纳入严格盲测统计，也不重跑本轮。
