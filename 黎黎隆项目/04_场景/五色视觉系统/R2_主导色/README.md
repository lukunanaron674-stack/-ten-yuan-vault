## R2-01｜深墨青主导

- 文件：`assets/R2-01_机械空港_深墨青主导.png`
- 输入：无外部图像参考；依据 I04「骨骼空港」世界节点和备用氛围描述词生成。
- 固定变量：机械空港建立镜头、前景骨架/平台、中景停靠环、远景骨脊与雾、横向通行路线。
- 变化变量：主导色；`#142A34` 约70%。
- 辅助色：`#CDE7E6` 远景和雾约20%；`#855D8F` 生体交界约5%；`#69D4CE` 接口约3%；`#913840` 警示约2%。
- 初步观察：深墨青让骨架、平台和机械结构成为主体，青蓝绿与暗红保持具体小面积功能点；适合测试“结构先于灯光”。
- 状态：`CANDIDATE｜待人工审核`
- 生成通道：内置 imagegen；不是 H3，不是本地 scene_focus LoRA。
