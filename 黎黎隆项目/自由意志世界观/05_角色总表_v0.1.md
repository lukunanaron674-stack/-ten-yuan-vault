# 角色总表 v0.1

## 0｜编号规则

- 格式：**ZY-两位数**（ZY=自由，防与黎黎隆 H 批/N 批/S 卡撞号）。⚠️ H02 系 ChatGPT 落卡时的旧号，保留但**停用新发**，H02 已注 ZY-02 别名
- **阵营归档（2026-09-27 674 定）**：正式角色必须挂进三能量桶（粉/青/红，挂靠 O1-O6）；**不属于三能量的角色进黑或白桶**——黑=墨青位（世界底/骨/暗面），白=淡青灰位（雾/中立/未觉醒），对应 P00 两个中性母色
- 每个正式角色必须有：编号 / 名字 / 能量桶（粉青红黑白）/ 阵营挂靠 / 觉醒档位 / 一句话卡
- 聊天记录里的新人物不自动进表
