# 自由意志世界观｜动态链条总表 v0.1（生克补版）

> **设计纪律（生补克表 v2.12 §9 生效）**：✅=语义已锁定（zx克n、xn生xz，可直接调用）；🔶=语义待验收（只有候选，不得凭箭头生成心理故事，调用须带端点+变量+排除）；◇=纯几何位（只表位置）。锁定关系每次调用仍须过端点与排除检查。

## 1｜力学→十元映射（谁在链上跑）

| 力学 | 十元位置 | 世界对应 |
|---|---|---|
| 青·标准化/组织 | **xn**（+x 资源侧） | 钢铁教派、商会、基因钢铁产业、植入标准 |
| 红·显权/资格 | **zx**（+z 节点确认） | 出海者、船长、裁决者、"最后一步我自己迈" |
| 青·代价/畸变 | **x并z** | 苔藓怪、青皮人、畸形改造人、粉色生态诡异面 |
| 红·守卫/回返 | **nz** | 佛教（身体不可被永久占用）、离船权、回港者 |
| 资源/掌握 | **x** | 黑金、基因金属、外置件、契约 |
| 危险/封存 | **xz** | 巨物海域、遗骨之地🔶、史前遗留、临界出走 |
| 意义/聚光 | **zn** | 船团信条、佛教教义、聚光事件（发散轴A） |
| 借力/通道 | **nx** | 商会通道、港口人情、代笔与中介 |
| 承载/协调 | **n** | 自由锚港、船团共同体、港务制度 |

> 巨物迁徙/黑金产出为**生态底盘循环**，不是生克链本身，是链条运转的燃料线（见 §5）。

## 2｜链 A：大航海主循环（生环实例化，顺时针）

> 阳半生环 `zx→zn→n→xn→xz→zx` 的落地。**这就是"大航海时代停不下来"的机制。**

```text
① xn生xz【✅锁定】
   教派/商会标准化结构持续运行 → 植入标准收口、离岸许可收紧、偏离者被识别
   → 出走的窗口逐条关闭，临界状态成形
② xz生zx【🔶待验收：显影倾向】
   危险压到临界 → 规则失效形成决定空位 → 出海者当众迈出"最后一步"（红色显权）
③ zx生zn【🔶待验收·窄：跨主体见证内化】
   先行者的自证被后来者内化 → 船团信条/新意义成形
④ zn生n【🔶待验收：意义扩大承接边界】
   "什么必须由我方接住"扩大 → 自由锚港、离船权等承载制度出现
⑤ n生xn【◇几何位】
   锚港的接纳与互信稳定运行 → 自身长出新的流程（港务、黑金交易规范）
→ 回到 ①：制度再次开始收窄出口。
```

## 3｜链 B：越线-裁决克环（阵营冲突引擎）

> 阳半克环 `xn→zx→n→xz→zn→xn` 的落地。**两条已锁定关系首尾相连，是全世界最硬的冲突引擎。**

```text
① xn克zx【✅锁定】
   标准化结构压过个体即时显权：公告、流程、前置审批使个人裁决无效
② zx克n【✅锁定】（入口A资格取消 / 入口B运行中断）
   觉醒者公开显权 → 公开脱离教派籍 / 裁决某共同体停止接收照顾
③ n克xz【◇几何位】
   锚港/船团承载接住危险中的人 → 命运失稳被兜住（回返可能性恢复）
④ xz克zn【🔶待验收】
   长期临界把无条件原则压成生存条件（"我佛慈悲"在饥荒海况下的动摇）
⑤ zn克xn【🔶待验收】
   意义/教义反过来克制结构（佛教用青武器打青人 → 反青教义用青武器 = 僵持点的机制化解释）
→ 回到 ①。钢铁教派 vs 佛教"打不死也停不了"，就是 ①②（锁定）带动 ④⑤（候选）的循环。
```

## 4｜链 C：身体-资源小克环（市井引擎）

> 阴半克环 `x→z→nx→x并z→nz→x` 的落地。**苔藓怪/植入纠纷/黑金买卖的日常摩擦面，接发散轴 B（nx 人情）。**

```text
① x克z【◇几何位】商会用契约与矿权买断选择权（资源掌控压资格）
② z克nx【🔶待验收】船长公开认诺船员 → 被借力者重新认领方向，不再沿商会通道走
③ nx克x并z【🔶待验收】不完成背书接口 → "苔藓怪"标签对该主体的吸纳与解释范围下降
④ x并z克nz【◇几何位】青斑扩散/寄生加深 → 侵蚀回返能力（回不了原来的身体）
⑤ nz克x【◇几何位】"身体不可被永久占用"直接否决基因金属买卖（守卫克资源）
→ 回到 ①。
```

## 5｜生态底盘燃料线（非生克链，供以上三条取用）

巨物生→死→坠落（巨鲸落日）→黑金/天空之骨→采集与激发→巨物迁徙改道→港镇随迁。三色链的全部物质流从这里来。

## 6｜补位稳定器（世界不散架的五对张力）

| 补对 | 主题 | 本世界形态 | 强度 |
|---|---|---|---|
| **xz ↔ nz** | 命运 | 漂流危险 ↔ 回港归宿：**离船权 = 全世界情感核心** | ✅ 主轴 |
| n ↔ x并z | 空间 | 锚港承载 ↔ 苔藓怪显形：谁被城接住、谁被城看见 | ◇ |
| xn ↔ z | 时间 | 制度积累证据 ↔ 认可节点确认：教派年表 vs 命名礼/授戒 | ◇ |
| zx ↔ nx | 因果 | 自己做成 ↔ 借通道做成：船长路线 vs 商会路线 | ◇ |
| zn ↔ x | 本体 | 船团信条 ↔ 船与装备的归属：旗与船 | ◇ |
