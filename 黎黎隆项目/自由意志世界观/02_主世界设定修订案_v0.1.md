# 主世界设定修订案 v0.1

## 0｜生成逻辑（为什么组织长这样）

力量门槛决定组织形态，这是本世界一切设定的第一因：

| 能量 | 门槛 | 必然长出的组织形态 |
|---|---|---|
| 青（改造） | 最低、可量产 | **人口最多 → 科层化巨型组织**：国教化教派 + 资本商会联合体 + 改造军团 |
| 红（觉醒） | 最高、稀有、个人 | **英雄级个体 → 无法科层化**：松散裁决网络 + 寺庙据点网 + 流动船团社会 |
| 粉（天赋结晶） | 资源在险地、需天赋 | **资源垄断 → 古老静态文明**：遗骨矿区王国/行会，不参战、只签契约 |

## 1｜政治版图（🔶采用"军事政治=红青两极，经济=三足"分层，待拍板）

### 青极｜基因钢铁联盟
- **国家群**：人类宜居地的大部分；国教=**钢铁教派**（"让世界基因钢铁化"）
- **实际驱动力=资本商会联合体**：黑金产业链所有者；教派激进（要同化一切）、商会逐利（要市场）——两者目标重合但内部有张力 🔶（教权 vs 商权，可作为青极内乱引线）
- **军事**：改造军团 + 机械怪物 + 基因钢铁生态武器（注入青色能量催生的钢铁生态圈，兼作国土防线）

### 红极｜自由意志阵营（无固定领土）
- **审判之庭**（松散）：流动裁决机构，类"海上巡回法庭"；裁决基因改造罪责，持续清算改造热潮遗留
- **佛教**（系统化）：山门据点网络；苦修抑制红色能量；慈悲不杀但会用青色外设打青色的人
- **大航海船团**：出走者的流动社会——船即国籍，船团即城市

### 粉极｜古老文明（不动员、不可征服）
- **遗骨之地王国/矿盟**：盘踞天空之骨粉矿区；"打不死我也不争霸"
- 对青：签**采矿与提纯契约**（垄断上游）；对红：传统默契（都反植入）；对所有人：反噬条款（青色介入粉系生态越深，反噬越重）

## 2｜地域结构（W 编号，适配巨物生态）

| 编号 | 地域 | 说明 |
|---|---|---|
| W1 | 人类环带 | 稀缺宜居地，青极领土，城邦链 |
| W2 | 巨物生态海 | 大航海主场，占世界绝大部分；巨鲸级生物巡游，红船团的活动场 |
| W3 | 天空之骨·遗骨之地 | 巨物骨骼结晶落地成粉矿区；粉极领土；冒险者淘晶热土 |
| W4 | 黑金海田 | 古代魔法生物坟场层，黑金（魔法石油）产区；青极资本必争 |
| W5 | 史前战争遗迹 | 🔶挂起：史前战争设定展开后启用 |

命名建议（口子5）：**巨鲸骨=天空之骨，落地矿区=遗骨之地**——分层用，"天空遗骨"弃用。

## 3｜经济三足（黑金产业链为轴）

```
粉极·遗骨之地          青极·资本商会              消费端
魔法生物尸骸/粉矿  →   黑金(魔法石油)开采  →  科技激发  →  青色能量  →  基因金属/钢铁生态
   (W3 险地采集)        (W4 油田)              (提纯垄断)        (全员刚需)
        ↑______________________冒险者行会(持证穿越巨物生态)______________________↓
```
- **冒险者行会** = 粉青之间的持证桥梁（穿越 W2 的唯一合法通道）🔶（新提议组织，待拍板）
- 佛教经济：不碰产业链，靠外用科技市场 + 信众供养
