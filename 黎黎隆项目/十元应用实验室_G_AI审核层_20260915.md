# 《黎黎隆》十元应用实验室｜G AI 审核层增量

> 项目应用层记录。只验证十元是否真正改变 H3 / 生图 / 分镜 / 剧情输出的可审核结构；不修改 L1/L2 canonical、十元定义、生克补或动态链正本。

## 本轮应用层

G｜AI 审核

## 当前真实问题

A-F 已经分别得到：夺路尾、回路锁、归巢拟态奇美拉、返身断点文明、返身权转交事件、双权位分叉镜头。当前真正缺口不再是“还缺哪条设定”，而是：

> AI 生成一张图、一段 H3 视频、一组分镜或一段剧情后，怎样自动判断它是真的执行了这些十元结构，还是只保留了颜色、气质、道具、角色站位和十元名词？

如果审核器只会输出“zx 感强 / nz 氛围好 / 很符合设定”，它本身就是 TENYUAN_DECORATIVE_ONLY。

---

## 必要 Semantic IR

```yaml
actor: AI审核器
object: H3视频 / 生图 / 分镜 / 剧情候选及其对应的项目应用卡
object_layer: structural_audit / evidence_to_mechanism
current_window: 从候选输出进入审核，到给出 PASS / FAIL 与可定位失败码
changed_variable:
  - 候选是否存在可观察的十元结构证据
  - 十元结构是否真实改变因果、空间、权利、路径、对象连续性或阶段转移
  - 删除/反转关键十元机制后，候选是否仍几乎原样成立
relation_shape: 先从候选提取观察 IR，再与目标应用卡的 expected IR 对比；必须通过证据门、因果门、删十元门和反转门，任何硬门失败均不得用审美总分补回
path_set:
  - expected_ir: 项目应用卡要求的结构
  - observed_ir: 候选画面/剧情中实际可观察到的结构
  - alt_explanation: 不用十元即可解释该结果的最近邻方案
  - counterfactual: 删除或反转关键机制后的候选
  - verdict: PASS_STRUCTURAL_TENYUAN 或明确失败码
decision_right: 审核器只能判“是否满足已存在的项目应用规则”，无权反向改写 canonical 或把单项目案例升级成理论定义
reentry_right: 失败候选可以回到生成环节重跑，但不得通过改名、补十元标签或提高审美分直接回到 PASS
future_endpoint: 形成可用于 H3 / 生图 / 分镜 / 剧情的统一结构审核接口
reality_anchor:
  - 可指认的画面对象与连续动作
  - 角色/环境实际响应
  - 对象身份连续性
  - 权利来源与作用对象
  - 路径开闭与失效条件
  - 前后帧/前后事件的状态变化
```

### 十元只读约束

- Semantic IR 固定字段仍以现行 schema 为准：actor / object / object_layer / current_window / changed_variable / relation_source / relation_shape / decision_right / path_set / reentry_right / future_endpoint / reality_anchor。
- “人物有某十元”不等于关系启动；共现、先后、对照、视觉相似不等于生克补机制启动。
- 已锁定关系只作为审核参照，不从《黎黎隆》案例反向扩写十元正本。

## 三个候选

### 候选 A｜十元审美打分器

对每张图/视频输出：zx 8.5、nz 7.2、nx 6.8，再附“压迫感、回流感、冲突感”等自然语言解释。

**nearest-neighbor：** 与普通美术风格打分、情绪分类器几乎相同。

**removal：** 删除十元定义后，仍可用“霸气 / 温柔 / 被动 / 冷暖 / 构图张力”等普通标签完成同样评分。

**reverse：** 即使把 zx 与 nx 的方向权来源反过来，模型也很可能只调整分数，不会判结构错误。

**结论：`TENYUAN_DECORATIVE_ONLY`。拒绝。**

---

### 候选 B｜对象清单审核器

检查画面是否出现：巨尾、锚点、塔汀、返身器官、两个人分开、怪物套壳、门站等；对象越齐全，越符合设定。

**nearest-neighbor：** 与 continuity checklist / 道具核对表相同。

**counterexample：** 一张图可以同时画出黎黎隆、塔汀、R_tatin、巨尾和两个方向，却让 R_tatin 跟着黎黎隆移动、让塔汀决定前方路线；对象齐全但十元结构完全错误。

**removal：** 把十元全部删掉，清单仍能作为角色资产一致性检查使用。

**结论：`TENYUAN_DECORATIVE_ONLY`。拒绝。**

---

### 候选 C｜结构反事实审核器：Expected IR → Observed IR → Counterfactual Gate

审核器不先问“像不像 zx”，而是先问：

1. 目标应用卡要求哪个 `changed_variable` 被改变？
2. 候选里实际是谁改变了它？
3. 这个变化有没有 `reality_anchor`，还是只存在于文字说明？
4. 把十元机制删除，候选是否仍几乎原样成立？
5. 把关键权利来源 / 路径 / 对象连续性反转，审核结果是否必须翻转？

只有同时通过下面四个硬门才允许 PASS。

#### Gate 1｜OBSERVABLE_EVIDENCE

每个目标机制至少存在一条可指认现实证据：

- 视频/分镜：具体帧段、动作、对象转移、环境响应；
- 单图：明确空间关系、对象归属、作用来源和结果；
- 剧情：明确事件前后状态、谁有决定权、谁承担代价、路径怎样关闭/开启。

只有色彩、表情、职业、服装、台词自述、十元标签，不算证据。

失败码：`FAIL_IR_EVIDENCE_MISSING`。

#### Gate 2｜STRUCTURAL_CAUSALITY

要求 `expected_ir.changed_variable` 在候选中真实改变，并且改变源可归因到目标主体/关系。

例如双权位分叉：
- `R_tatin` 必须停留在塔汀侧并维持可回接关系；
- P1 的现实重排必须由黎黎隆动作触发；
- 两者不能靠构图左右位置替代。

失败码：`FAIL_CAUSAL_RESPONSE_MISSING` / `FAIL_RIGHTS_COLLAPSE`。

#### Gate 3｜TENYUAN_REMOVAL

执行删十元反事实：

> 若删除目标十元机制，只保留角色、道具、世界观和审美，候选能否几乎原样成立？

若能，则强制：`TENYUAN_DECORATIVE_ONLY`。

此门为一票否决，任何审美高分不得补回。

#### Gate 4｜REVERSE_SENSITIVITY

自动构造至少一个反转：

- 交换 decision_right 来源；
- 让 R_tatin 跟随黎黎隆移动；
- 让怪物只模仿外观、不截获公共接口归因；
- 让夺路尾只有破坏力、不引起后方路线重组；
- 让前置锚点不再限制下一次转向。

若反转后审核结果没有从 PASS 变为 FAIL，说明审核器没有真正识别机制。

失败码：`FAIL_REVERSE_INSENSITIVE`。

### 最近邻防伪

在给出 PASS 前，审核器必须输出一个不用十元的最近邻解释，例如：

- “普通勇敢开路”
- “谨慎副手提醒风险”
- “拟态怪物伪装路标”
- “高风险身体强化”
- “离别构图 + 信物”

并指出目标候选比最近邻**多出的那条不可替代结构约束**。如果说不出来，不得 PASS。

### 统一输出

```yaml
verdict: PASS_STRUCTURAL_TENYUAN | FAIL
failure_codes: []
expected_ir: {...}
observed_ir: {...}
evidence:
  - anchor: "可定位帧/镜头/事件/对象"
    supports: "哪个字段"
nearest_neighbor: "不用十元的最近邻解释"
non_substitutable_constraint: "为什么目标设计不能被最近邻原样替代"
removal_test: PASS | TENYUAN_DECORATIVE_ONLY
reverse_test: PASS | FAIL_REVERSE_INSENSITIVE
confidence: 0.0-1.0
```

`confidence` 只表示证据充分度，不允许把硬门失败加权成 PASS。

### 检查

**nearest-neighbor：** 与一般“画面质量审核 / 角色一致性审核”不同，本方案审核的是 IR 变量是否发生指定结构变化，并要求最近邻防伪。

**removal：** 删除十元机制后，审核器将失去 removal gate、reverse sensitivity、decision_right / reentry_right 等判定核心，无法原样退化成普通审美评分器。

**reverse：** 只要把关键权利来源或对象连续性反转，正确审核器必须改变结论；因此可用对抗样本直接回归测试审核器本身。

**counterexample：** 一张极美、角色正确、道具齐全、配色完美的“双人离别图”，若没有 R_tatin 对象连续性和 P1 环境响应，应明确 FAIL，而不是“整体符合十元美学”。

**结论：通过。**

## 最终保留｜结构反事实审核器 v0.1

### 一句话

> AI 不审核“像不像十元”，而审核：目标 IR 中哪个现实变量被谁改变了；若删掉或反转十元机制，候选是否必须发生结构性失效。

### 第一批项目级失败码

- `TENYUAN_DECORATIVE_ONLY`：删掉十元后候选仍几乎原样成立。
- `FAIL_IR_EVIDENCE_MISSING`：只有标签/解释，没有可观察 reality anchor。
- `FAIL_CAUSAL_RESPONSE_MISSING`：主体动作没有引起要求的环境/关系/路径响应。
- `FAIL_RIGHTS_COLLAPSE`：decision_right 与 reentry_right 被错误合并或互相替代。
- `FAIL_OBJECT_IDENTITY_BROKEN`：B0 / R_tatin / 真实锚等对象连续性丢失。
- `FAIL_TEMPORAL_CONTINUITY`：视频/剧情只给首尾象征，没有过程证据。
- `FAIL_REVERSE_INSENSITIVE`：反转关键机制后仍被判通过。
- `FAIL_STYLE_ONLY`：只通过色彩、构图气质、服装或表情表达十元。

### A-F 回归样本最低要求

1. **A 夺路尾**：必须看见“最小锚序成立 → 黎黎隆导致路线现实重排”；纯破拆 FAIL。
2. **B 回路锁**：必须看见“黎黎隆决定 P1 / 塔汀只在回返接口切断点拥有有效拒绝”；谨慎副手 FAIL。
3. **C 归巢拟态奇美拉**：必须攻击公共接口归因并让真后路退出可信调用位置；只拟态外观 FAIL。
4. **D 返身断点文明**：必须区分公共可调用性与对象特异返身资格；普通模块化安全规范 FAIL。
5. **E 返身权转交**：必须发生 decision_right / reentry_right 的真实拆分；“力量有代价” FAIL。
6. **F 双权位分叉**：必须存在 R_tatin 空间连续性 + 黎黎隆侧 P1 环境重排；离别构图 FAIL。

### 它具体改变《黎黎隆》的创作决策

1. 生图/H3 不再因为“风格对、角色像”就自动合格。
2. 每个 Prompt / 分镜卡必须能够指出 expected_ir，否则无法进入十元结构审核。
3. 每个视频至少需要一个过程性 reality anchor；首尾帧仅表达象征时不能冒充动态链成立。
4. 审核器必须保留失败原因，允许生成端针对结构重跑，而不是只输出一个总分。
5. 十元应用从“创作者脑内判断”变成可回归测试：给审核器故意制造反转样本，若它仍判 PASS，就说明审核器本身坏了。

### 删掉十元测试

**PASS。**

如果删掉十元，本方案可以退化成普通视觉 QA，但无法保留“目标 IR → 结构证据 → removal → reverse → 最近邻防伪”的硬门组合；尤其无法解释为什么一张更漂亮、更完整的图会因为权利来源或路径归因错误而被一票否决。
