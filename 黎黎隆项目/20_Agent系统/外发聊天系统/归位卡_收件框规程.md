# 归位卡｜收件框使用规程

## 循环（四步）

```
① 复制外发卡（A/B/C/D 任一）整份 → 贴进任何 AI 框
② 在那个框里聊，产出自带【归位标记】
③ 把带标记的产出段复制回来，粘给主 AI（本框）
④ 主 AI 按下表归位 → 更新文件 → Canvas 加节点 → 回「✅ 已归位 + 路径」
```

## 标记 → 归位路由表

| 产出标记 | 归位到 | 动作 |
|---|---|---|
| 【世界观更新】 | 自由意志世界观/01_收拢稿（或新建修订节） | 条目入表，标定版/提案；Canvas 底盘节点更新 |
| 【角色·红桶/粉/青/黑/白】 | 10_角色/ + 07_分桶表 + 05_角色总表 | 新角色给 ZY 编号入总表；Canvas 对应桶加节点 |
| 【故事·前提】 | 05_故事/发散池_自动/（人工场次） | 入前提池，★置顶；撞钩子去重 |
| 【场景·出图】 | 04_场景/ 或 imggen 流水线队列 | 描述词过五色验收 → 可直接进出图 |
| 【待拍板】 | 00_总工作单_v1.0.md | 追加拍板口，等你拍 |

## 无标记的粘贴怎么办

粘贴内容没有【标记】时：主 AI 先读内容 → 判断属于哪类 → **给出建议标记让你确认** → 确认后才归位。不确认不落盘。

## 已归位回执格式

```
✅ 已归位
- 【世界观更新】×2 → 收拢稿 v0.3 §9（新增节）
- 【角色·红桶】×1 → ZY-05 已入总表（青桶位空缺提醒）
- Canvas：红桶 +1 节点，青桶 G 链 +1 节点
```
