## 索引读取规则
1. P0 冲突时，以更明确的“正本 / canonical-current / 总入口”优先。
2. 十元关系不得从世界观案例反推；必须回 P0 十元 Canon。
3. 角色/场景只读取实际存在且可追溯的条目，不把聊天附件当资产。
4. 检索到同名旧版时先判断路径与状态，不自动采用更新时间最新者。
5. 世界观新结论先写增量知识库，KEEP/MERGE 后才回写三色正本。
