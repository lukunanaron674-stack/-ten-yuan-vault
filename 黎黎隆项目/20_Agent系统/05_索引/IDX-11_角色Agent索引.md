## P2｜按需方法
- 当前角色相关的比例/体型研究；
- 当前角色相关的四宫格、三视图或动作探索规则；
- 已验证同类角色案例。

这些只用于解决具体造型问题，不得覆盖作者原稿与角色正本。

## P3｜默认禁止
- 已废弃角色旧卡、备份、Rxx 临时版；
- 未归档聊天附件；
- 仅因名字相似命中的别项目角色；
- 未经作者确认的 AI 图；
- 把风格参考当身份参考，或把身份参考当风格正本。

## 查询顺序
`PROJECT_STATE → 角色总索引 → 目标角色卡/查重 → 当前 region world_result/正本 → tenyuan_result/Canon → 真实视觉资产 → 必要 P2`

## 查重规则
新建角色时先比较：
- 身份功能；
- 世界机制位置；
- 与主事件关系；
- 十元行为结构；
- 剪影/核心视觉结构。

只换名字、发色或组织名而核心功能相同，优先 MERGE，不新建。
