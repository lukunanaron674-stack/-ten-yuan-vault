## 读取优先级
- **P0 正本**：定义、门禁、项目锁定规则。发生冲突时优先。
- **P1 生产规则**：当前《黎黎隆》B端、角色、场景、世界观、H3 实际执行规则。
- **P2 方法/案例**：用于解决具体问题、举反例、做镜头验证。
- **P3 归档/旧版**：默认禁止自动调用；仅做历史追溯。

## 内容决策顺序
`导演目标 → 五维主题问题 → 剧本人物困境/事件 → 十元力量映射 → 动态链/分镜 → 生产执行`

- 五维负责：故事研究什么问题。
- 十元负责：问题内部有哪些力量、力量是什么性质。
- 动态链负责：力量如何连续作用、反作用、收敛、回写。

## 强制规则
1. 不因文件名相似就把旧版当正本。
2. 有 `canonical-current` / 正本 / 总入口时，优先通过其路由读取。
3. 归档、备份、旧版默认不进入自动推理。
4. Agent 新学到的内容先写“增量/交叉知识”，不覆盖原正本。
5. 新结论经过真实镜头验证后，才允许提议回写正式理论库。
6. 主题 Agent 不直接拿十元符号生成主题；十元 Agent 不反向覆盖主题问题。
7. 电影主题研究属于 P2 研究层，与五维 P0 正本冲突时必须以 P0 为准。
8. 世界观 Agent 只通过索引读取世界总纲、三色正本与十元 Canon；不得复制整库或从案例反推 canonical。
