# 主题知识库｜五维增量

> 本文件只收《黎黎隆》Agent 实际验证后的主题增量，不复制 `02-五大主题` 正本，也不替代电影主题研究库。

每条知识必须包含：
- ID
- 五维主维度 / 次维度
- theme_question
- theme_experiment
- pressure_mechanism
- 来源 / 电影或项目样本
- 可复用主题母题
- 适用条件
- 反例 / 失败边界
- 与十元 / 动态链的接口需求
- 在《黎黎隆》中的 TEST-SHOT / 正式镜头验证
- KEEP / REJECT / STOP
- VERIFIED / PARTIAL / HYPOTHESIS

## 写入门禁
1. 先查 [[../05_索引/IDX-06_主题Agent索引]]，避免重复已有五维正本或电影研究结论。
2. 电影研究的新结论不能因为“听起来好”就写成项目规则；至少要能转成可执行主题实验。
3. 与 P0 canonical 冲突的条目只记录为 `RESEARCH_CONFLICT`，不得升级。
4. 禁止收录“主题要深刻”“角色要成长”这类无法执行的空话。
5. 主题增量只有经过真实镜头 / TEST-SHOT 验证后，才允许 KEEP。


## Agent 可调用知识模块

### TK-01｜五维主题问题骨架
- [[TK-01_五维主题问题骨架]]
- 状态：`verified-from-canonical`
- 用途：主题 Agent 在进入任何电影机制、项目增量或十元映射前，先据此确定主维度、主题问题、主题实验和压力变量。
- 第一轮只建立问题骨架，不写入电影机制，不改 canonical。


### TK-02｜五维关系 / 压力图谱
- [[TK-02_五维关系压力图谱]]
- 状态：`verified-from-canonical`
- 用途：在 TK-01 已确认主题显影后，判断五维之间的正式 n/x 是否真正启动，并记录源主题、目标主题、被改变变量与决定性证据。
- 第二轮只建立关系判断，不调用电影机制，不改 canonical。


### TK-03｜电影主题机制卡库 R30–R46
- [[TK-03_电影主题机制卡库_R30-R46]]
- 状态：`research-candidate`
- 用途：在 TK-01 / TK-02 已确定主题问题与关系后，从 R30–R46 蒸馏机制中选择 1 张主机制卡（必要时 +1 张修正卡），把抽象主题压力变成可执行剧情发动机。
- 未经过《黎黎隆》TEST-SHOT 的卡不得升级 KEEP。
