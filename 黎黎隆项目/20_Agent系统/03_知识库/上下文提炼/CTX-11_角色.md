# CTX-11｜角色工作记忆

## 必须记住
- 角色 Agent负责“这个人是谁、为什么行动、在世界中处于什么位置、视觉上什么不能改”，不替十元/世界观/剧本/生图 Agent越权。
- 新角色默认 STAGING；LOCKED 必须有作者明确确认。
- 三色：青 Z×X并Z；红 Z+ZN；粉 NZ主/X并Z次。颜色不是十元标签。
- 十元必须落到行为证据；职业、颜色、善恶、强弱不能直接当十元判据。
- 新生克补无 Canon 证据 → NEEDS_TENYUAN_REVIEW。
- 角色视觉优先“头像 + 中全景/中景四宫格”，9:16 2×2；至少两格读比例，一格锁头，一格45°半侧。
- identity_anchor 锁角色是谁；style_anchors 锁作者画法。风格锚点优先从真实已确认资产筛 3–6 张，不能纯文字代替。
- 生图后必须 AG-06 审核；角色一致性40 / 项目风格30 / 生产可用性20 / AI异常10；<80 不进入 approved。
- 核心冻结项被改直接 REPLAN。
- GitHub角色库只登记真实存在的路径/asset_id，不伪造聊天附件路径。
