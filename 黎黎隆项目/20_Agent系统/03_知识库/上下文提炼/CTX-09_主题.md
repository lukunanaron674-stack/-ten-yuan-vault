# CTX-09｜主题工作记忆
## 必须记住
- 五维回答“故事研究什么问题”，不是设定标签。
- 默认 1 个主维度 + 0–2 个次维度。
- 输出 theme_question / experiment / pressure / dilemma_target。
- 先证明主题显影，再判断维度关系；共现不等于生克。
- 电影研究不能直接当规则；优先用 TK-03 的机制卡，不整篇读取 R30–R46。
- 机制卡按“目标变量怎么变”匹配，不按电影相似度匹配。
- 默认只用 1 张主机制卡，最多 1 张对照卡。
- TK-03 无匹配时才回源原始电影研究；不复制电影人物和剧情皮肤。
- 不拿十元反推主题，不写完整剧本。
- 8–10 秒只显影一个主题压力节点即可。
## 按需回源
先用 TK-01 定题；需要关系时用 TK-02；需要剧情发动机时用 TK-03。只有定义/关系冲突才打开五维 Canon，只有机制缺口/反例核查才打开 1 个 P2 原始电影研究。
