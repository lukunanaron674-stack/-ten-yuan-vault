# CTX-10｜世界观工作记忆
## 必须记住
- 治理与扩展同级：AG-10 不只发散，也负责归并、去重、层级、正本索引与角色同化。
- 世界治理结构统一为：区域 → 地理 → 组织/制度 → 资源/产业 → 生活方式 → 职业生态位 → 角色。
- 角色必须核 world_region / geography / organization / world_mechanism_refs；缺口输出 PASS/PARTIAL/CONFLICT/UNASSIGNED。
- P00 五色是视觉分类，不是世界区域；当前世界正本仍只明确青/红/粉三套。
- 世界硬门：NZ 基底 → X并Z 级毁灭 → Z 科技化；奇幻是自然，机能是文明。
- 世界观只回答“世界允许怎样发生”，不能改主题或十元 Canon。
- 普通镜头 world_gate=BYPASS；只有依赖规则时才 WORLD_CHECK。
- 新高体量规则必须 WORLD_PROPOSAL → 十元复核 → 导演裁决 → Canon。
- 三色：青 Z×X并Z（优先 X并Z→生Z）；红 Z+ZN；粉 NZ 主/X并Z 次。
- **粉色主方向冻结：遗蜕生态带 / 尸骸世界。** 古老巨型生命死亡后，器官、骨骼、神经、皮膜与部分功能仍持续生长或工作，后代文明在其上居住、寄生、照料、使用并形成新生态。
- 粉色发散优先级：**70% 遗蜕实体/生态/城市/资源/职业/危险/生活；20% 共生/错接机制；10% 关系制度/伦理。** 已有关系真实性、单向余真、续生关系、关系遗产等保留为深层逻辑，不再作为主发散入口。
- 粉色防漂移：不是植物奇幻区，也不是生物赛博区；优先古老、半死、仍在工作、被后代继续使用的生物结构。若新设定无法落成地貌/器官设施/职业/资源/危险/日常动作，默认 LOW 或 MERGE。
- 发散先机制后命名，重复设定 MERGE，不换皮造新词。
