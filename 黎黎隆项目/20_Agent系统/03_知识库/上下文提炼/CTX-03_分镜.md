# CTX-03｜分镜工作记忆
## 必须记住
- 只把 theme/script/tenyuan 已确认结果翻译成可见镜头。
- 当前默认 8–10 秒；复杂动作减负，不靠堆 prompt。
- 单镜优先单角色、单场景、一个核心变化。
- 镜头变化必须服务可观察变化，不能为了“有镜头感”乱切。
- 输出必须能提供 opening/closing state 所需的可见状态。
- H3 prompt 不直接塞十元术语。

## 爆款分镜增益 v1.0
> 来源：[[../方法论/番茄爆款方法论_代理适配_v1.0]]。
- 每条短镜至少有一次明确的可观察变量变化：状态 A → 状态 B。
- 默认三阶段是 DEFAULT_PATTERN，不是 HARD_RULE：
  - 0–3s：主体 + 空间 + 当前压力；允许静态，禁止无任务空镜。
  - 3–7s：默认承担核心行动。
  - 7–10s：确认变化，并尽量留下一个未关闭状态/视觉钩。
- 连续单镜变量链若更清楚，可以偏离三阶段，不为模板强切。
- 收束帧优先表现“已经变化，但尚未完全结束”。
- 参考图只作可证实视觉依据，不脑补未确认设定。
- 关键变量若天然有可听事件，应同步 soundscape；禁止凭空气氛特效。

## 按需回源
需要执行参数才打开当前 H3 规则；需要方法参考时最多打开 1 个相似镜头案例。爆款规则争议时回源 [[../方法论/番茄爆款方法论_代理适配_v1.0]]。

- 提示词只将已确认分镜转为可执行描述；需含任务要求的时间线、可观察变化与声音字段。
- 自评只用于候选筛选；轮转、名单和分数门槛为日期快照，执行前查当前任务卡。
- 提示词生产不等于渲染提交/开始；边界见 [[../增量/2026-10-01_20代理库并入记录]]。
