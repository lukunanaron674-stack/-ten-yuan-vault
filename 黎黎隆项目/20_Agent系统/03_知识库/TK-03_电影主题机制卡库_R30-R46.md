# TK-03｜电影主题机制卡库 R30–R46 v1.0

> 把 R30–R46 蒸馏为主题 Agent 可调用的剧情机制。全部为 research-candidate，不覆盖 canonical。

## 调用顺序
```text
TK-01 判主题问题
→ TK-02 判五维关系
→ TK-03 选机制
→ 剧本 Agent 转成事件
→ THEME_AUDIT 验证主题变量是否真的改变
```

默认 1 张主机制卡，必要时最多加 1 张修正卡。设定相似不等于机制匹配。

## MC-01｜固定终点 / 可变意义
R30/R34/R44。Outcome 锁定，但 Path / Relation / Meaning 仍可变化。回答“结果不能改时，选择还改变什么”。

## MC-02｜预知同意
R34。Future Outcome 可提前 Access，人物仍可拒绝路径。核心：Foreknowledge ≠ Fate。

## MC-03｜Normality Lock
R41。Institutional Repetition + Alternative Access低 + Recognition一致 → P_conceived收缩。人物不是没路，而是无法把别的路想成真实选项。

## MC-04｜概率固化 / 施行性预测
R40。Prediction → Category → Permission → Opportunity → Experience → Outcome。Prediction + Authority + Enforcement 才可能制造 Fate-like Structure。

## MC-05｜Future Horizon Collapse
R44。Future Horizon↓ → Long-term Consequence Weight↓ → Present Investment↓ → 长期制度与关系短视化。

## MC-06｜全局锁死 / 局部仍活
R44。Global Horizon = 0 时，Local Horizon 仍可改变 Experience / Relation / Meaning。

## MC-07｜责任真空 → 归因收敛
R31。Cost 强 + Cause Source 不可达 + 不能无限等待 → 弱证据聚集到一个可达解释对象 → Action 先于 Truth Closure。

## MC-08｜解释迟于行动
R31/R45。Cause Model 未完成，但 Action Window 缩短，行动阈值先于真相阈值被越过。

## MC-09｜错误解释 → 真实后果
R31/R45。Event A → False Explanation B → Action C → Real Consequence D。误解本身可成为下一轮真实 Cause。

## MC-10｜Causal Proxy
R45。主体把决定交给规则、算法、抽签、传统等程序，并用程序包装责任。检查谁可拒绝、谁有最终执行权。

## MC-11｜Distributed Responsibility
R46。Multi-Cause Event → Responsibility Share 分散。Causal Contribution ≠ Total Moral Identity。

## MC-12｜Evidence Reversal
R30。旧身份判断不变的终局中，一个关键行动成为新 Identity Evidence，迫使本体解释更新。

## MC-13｜来源失效
R32。Origin 只决定初始分类；持续 Experience / Persistence 可产生更强当前本体证据。Cause Source ≠ Identity Authority。

## MC-14｜Identity Slot Scarcity
R35。两个 Carrier 都有合法 Identity Evidence，但社会位置容量为 1，导致 Legitimacy Conflict。

## MC-15｜Identity Divergence
R35。Shared Past → Different Experience → Different Action → Different Recognition → Identity Divergence。

## MC-16｜Externalized Causality / Identity Prosthesis
R36。Internal Memory 断裂 → External Record 承担 Cause Anchor；Context Loss 可让真实证据制造错误 Cause Model。稳定 Mission 可临时维持本体连续性。

## MC-17｜Identity Compression
R37。Life Archive↑ + Retention Capacity有限 → Selection Pressure↑ → 少数事件获得高 Representative Weight → Identity Summary 被压缩。

## MC-18｜Recognition Echo Chamber
R38。多个 Carrier 在同一空间重复同一 Recognition → Identity Summary 收敛 → 行动可预测性提高 → Path Convergence。

## MC-19｜短时高塑形
R43。Duration 短不等于 Identity Weight 小。Attention Density 与 Mutual Recognition 足够高时，短关系也可留下持续本体后果。

## MC-20｜Single-Cause Identity Lock
R46。High-impact Cause → Responsibility 内化 → “我做过 X”逐渐变成“我只能是这种人” → Future Self Range 收缩。

## MC-21｜Access ≠ Possession
R39。Temporary Access 提高短期 Actionability，但 Possession / Permission 未改变，Access 可被撤回。

## MC-22｜被允许的突破
R39。人物沿系统允许路径突破，P_reachable 局部扩大，但 System Exit 仍为 0。Spatial Mobility ≠ Fate Mobility。

## MC-23｜本体不等于行动自由
R42。Identity / Subjectivity → Intention → Access + Permission + Resource → Actionability → P_reachable。觉醒不自动等于自由。

## MC-24｜Retrospective Meaning Causality
R32。E1 已发生 → E2 提供新解释 → Meaning(E1) 改变 → E1 对当前 Identity / Action 的作用改变。

## MC-25｜高密度揭露
R32。一个新事实同时重写多个旧事件 → 多条 Cause Model 改写 → Identity 与 P_conceived / P_reachable 一起变化。

## MC-26｜Anchor Lag
R33。External Anchor 在 t1 消失，Internal Identity 仍持续引用，直到 t2 才真正 detach。Anchor Persistence ≠ Carrier Persistence。

## MC-27｜锚点交叉验证崩溃
R33。地点、关系、记忆、时间连续性原本互相校验；多个 Anchor 同时失真后，Cause Model / Identity 无法稳定。

## MC-28｜删记录，不删塑形
R41。删除 Memory Access ≠ Undo Event ≠ Undo Learning ≠ Undo Identity Update。

## MC-29｜Growth-Rate Divergence
R42。Shared Attention → Mutual Change → Growth Rate Divergence → Relationship Model Divergence → Shared Future 失配。

## MC-30｜认证陷阱
R42。B 需要 A 认证，A 用自身欲望定义标准，B 利用标准获得 Access 后退出体系。Recognition Authority ≠ Existence Authority。

## MC-31｜指控本体化
R43。Ambiguous Claim → Authority 放大 → Recognition Network 同步 → Public Identity 重写 → Permission / Access 下降。Truth Repair ≠ Identity Repair。

## MC-32｜责任解释桥
R45–R46。Action / Contribution → Responsibility Attribution → Accepted / Rejected / Distributed → Identity Interpretation → Identity Change。
核心：Accept Responsibility ≠ Repair Consequence ≠ Forgiveness ≠ Identity Repair。
