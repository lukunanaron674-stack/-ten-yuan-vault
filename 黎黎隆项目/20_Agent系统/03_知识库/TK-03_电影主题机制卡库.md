# TK-03｜电影主题机制卡库 v1.0

> 第三轮目标：把 R30–R46 从“电影研究笔记”蒸馏成主题 Agent 可以直接调用的剧情发动机。
> 本文件不复述电影剧情，不升级任何研究结论为 canonical，不新增正式五维生克方向。

## 0｜调用顺序

主题 Agent 只能按这个顺序使用：

```text
TK-01：先确定主维度 / theme_question / variable
→ TK-02：若涉及多维作用，再验证 canonical n/x 是否真的启动
→ TK-03：最后才选择一个可复用机制，把问题压进剧情
```

禁止：
- 先看电影机制，再倒推主题；
- 因为“某电影像当前项目”就整段照搬；
- 一次同时套 3 个以上机制，把故事做成理论拼盘；
- 用 TK-03 改写 canonical 正本。

默认：
- 1 张主机制卡；
- 最多 1 张反例 / 对照卡；
- 没有合适卡就返回 `NO_MECHANISM_MATCH`，再按需回源 P2 电影研究。

## 1｜机制卡选择键

不要按片名检索，按“你希望哪个变量发生什么变化”检索。

```yaml
need:
  primary_dimension: ""
  target_variable: ""
  desired_change: 打开|关闭|压缩|延迟|重写|分叉|错位|固化|解绑|承载
  story_position: 起点|转折|中段|高潮|结局
  pressure_type: 信息|身份|空间|期限|制度|关系|责任|预测|记忆
```

匹配成功后只输出：
- 机制名；
- 触发条件；
- 中介链；
- 预期改变的五维变量；
- 人物困境；
- 失败边界。

# 2｜十四张核心机制卡

## MC-01｜固定终点 / 可变意义
**来源：** R30、R34、R44  
**适合：** 命运主维；时间 / 本体次维。  
**当你需要：** 终点不能改，但又不想把人物写成“完全没得选”。

```text
Outcome Freedom↓
→ Path / Relation / Meaning仍可变化
→ 人物对已知代价作出知情选择
→ 结果不变
→ 结果“证明了什么”被改写
```

**可施压变量：** Future Horizon、Consent、Meaning、Local Horizon。  
**人物困境：** “既然结局不变，我还要不要选择这条路？”  
**失败边界：** 如果人物只是机械接受终点，没有可拒绝路径或价值取舍，本卡不成立。

## MC-02｜解释作者权 / 回溯意义
**来源：** R30、R32  
**适合：** 因果 / 本体。  
**当你需要：** 过去事件不能 Undo，但人物对过去的解释仍能改变未来。

```text
Past State不变
→ New Evidence出现
→ Cause Model更新
→ Past Meaning更新
→ Internal Identity更新
→ Future Action改变
```

**可施压变量：** Cause Model、Interpretive Agency、Identity Evidence。  
**人物困境：** “过去没变，但如果它从来不是我理解的那样，我现在是谁？”  
**失败边界：** 新信息只增加知识量、没有重写旧事件意义时，不用本卡。

## MC-03｜因果真空 / 解释迟于行动
**来源：** R31、R45  
**适合：** 因果主维；时间 / 命运次维。  
**当你需要：** 真正原因不可知，但人物仍必须行动。

```text
Strong Consequence
+ Cause不可验证
→ Explanation Hunger↑
→ Cause Candidate收敛
→ Time.horizon下降
→ 不完整Cause Model跨过行动阈值
→ Action
→ New Consequence
```

**可施压变量：** Cause Access、Reliability、Blame Target、Actionability。  
**人物困境：** “我必须先知道为什么，还是必须先决定怎么办？”  
**失败边界：** 如果谜底很快揭晓且错误解释没有制造新后果，本卡只是普通悬疑。

## MC-04｜锚点滞后 / 锚点网络失校
**来源：** R33  
**适合：** 本体主维；空间 / 时间次维。  
**当你需要：** 外部关系、地点或身份位置已经消失，但旧本体仍继续运行。

```text
Anchor Carrier消失
→ Internal Identity继续引用旧Anchor
→ 行为仍围绕旧位置运行
→ 多个Anchor交叉验证失效
→ 本体漂移
→ detach anchor 或建立新Anchor
```

**可施压变量：** Anchor、Continuity、Recognition、Temporal Continuity。  
**人物困境：** “证明我是过去那个我的东西都没了，我为什么还在照旧活？”  
**失败边界：** 只是怀旧，不影响重大选择与身份稳定，不成立。

## MC-05｜双重合法者 / 身份槽位稀缺
**来源：** R35  
**适合：** 本体 + 空间。  
**当你需要：** 冲突双方都“是真的”，但社会位置只能容纳一个。

```text
Shared Identity Evidence
→ 两个Carrier同时合法
→ Experience开始分叉
→ Identity Slot容量=1
→ Legitimacy Conflict
```

**可施压变量：** Identity Slot、Recognition Authority、Belonging、Possession。  
**人物困境：** “不是谁是假货，而是谁有资格继续占这个位置？”  
**失败边界：** 最后只靠揭晓“谁才是真的”解决，则退化成真假谜题。

## MC-06｜外置因果 / 上下文丢失
**来源：** R36  
**适合：** 时间 + 因果 + 本体。  
**当你需要：** 记录比记忆更持久，但记录不等于完整因果。

```text
Internal Memory断裂
→ External Record成为Anchor
→ Context被压缩
→ Record Authority↑
→ Future Self把记录当Cause Truth
→ Action重复 / 被操纵
```

**可施压变量：** Reliability、Context、External Record、Mission。  
**人物困境：** “我相信的是事实，还是一个被压扁后的事实？”  
**失败边界：** 如果记录只是单纯假证据，直接归入普通欺骗，不必用本卡。

## MC-07｜身份压缩 / 自我保护型重写
**来源：** R37  
**适合：** 本体 + 时间 + 因果。  
**当你需要：** 人生材料太多，人物必须选择“哪一段最代表我”。

```text
Life Archive巨大
→ Retention / Attention有限
→ Selection Pressure↑
→ 少数事件获得高代表权
→ Identity Summary收敛
→ 不可承受证据被重新排序或排除
```

**可施压变量：** Representative Weight、Access、Salience、Identity Summary。  
**人物困境：** “我是在总结自己，还是把自己压成一个方便活下去的版本？”  
**失败边界：** 只是回忆蒙太奇、没有改变身份解释，不成立。

## MC-08｜承认回音室 / 公共身份重写
**来源：** R38、R43  
**适合：** 本体 + 空间 + 命运。  
**当你需要：** 社会反复把人物当成某种人，最终限制人物还能怎么行动。

```text
多个Carrier重复Recognition R
→ Public Identity向R收敛
→ Permission / Access随R改变
→ 行动样本越来越单一
→ Internal Identity受压
→ Fate-like Path Convergence
```

**可施压变量：** Recognition、Public Identity、Permission、Action Range。  
**人物困境：** “当所有人都只允许我作为X存在，我还能证明自己不是X吗？”  
**关键修正：** Truth Repair ≠ Identity Repair。  
**失败边界：** 只有舆论压力，没有改变许可、关系、选择或本体，不成立。

## MC-09｜Access ≠ Possession / 被允许的突破
**来源：** R39  
**适合：** 空间 + 命运。  
**当你需要：** 人物能进入高价值空间，却不能真正拥有那个位置或改变规则。

```text
Temporary Access
→ Actionability短期提高
→ Permission / Possession未改变
→ 外部冲击
→ Access可被撤回
→ “移动了”但Fate Mobility未提高
```

或：

```text
不断突破系统内部路径
→ P_reachable局部扩大
→ 抵达中心
→ 发现突破路径本身属于系统控制
→ 真正破局必须退出 / 改写系统边界
```

**可施压变量：** Access、Permission、Possession、P_reachable、Retainability。  
**人物困境：** “我是真的上去了，还是只是被允许暂时进去？”  
**失败边界：** 空间移动同时真实获得控制权，则无需本卡。

## MC-10｜施行性预测 / 概率固化
**来源：** R40  
**适合：** 命运 + 因果 + 空间。  
**当你需要：** 预测不是旁观未来，而是通过制度参与制造未来。

```text
Prediction
→ Authority采纳
→ Category
→ Permission / Resource差异
→ Experience差异
→ Outcome接近预测
```

**可施压变量：** Prediction Access、Authority、Enforcement、P_reachable。  
**人物困境：** “这个未来是被预测出来的，还是被预测系统做出来的？”  
**失败边界：** 预测没有改变任何现实资源 / 权限 / 行动，则只是信息，不构成施行性预测。

## MC-11｜删记录，不删塑形 / 正常性锁定
**来源：** R41  
**适合：** 本体 + 命运 + 因果。  
**当你需要：** 删除记忆、压制信息或正常化制度，却不真正 Undo 已经形成的行为与身份。

```text
Event塑形人物
→ 删除Event可访问记录
→ Cause Model断裂
→ 行为倾向仍残留
→ 人物重复旧选择
```

或：

```text
制度规定终点F
→ 教育 / 语言 / 空间把F解释为正常
→ Alternative Model缺失
→ P_conceived收敛
→ Fate Resistance下降
```

**可施压变量：** Memory Access、P_conceived、Normality、Behavior Residue。  
**人物困境：** “我没被锁住，为什么我连逃跑都想不到？”  
**失败边界：** 角色明确知道替代路径，只是成本太高，应转用空间 / 命运许可机制。

## MC-12｜异速关系 / 认证陷阱
**来源：** R42  
**适合：** 时间 + 本体 + 空间。  
**当你需要：** 双方都没有背叛，但成长速度 / 存在方式 / 认证结构使共同未来失配。

```text
Shared Attention
→ Mutual Change
→ Growth Rate Divergence
→ Relationship Model Divergence
→ Shared Future失配
```

认证侧：

```text
主体B需要A认证
→ A定义认证标准
→ B学习并利用标准
→ 获取Access
→ B离开认证体系
→ Recognition Authority失去控制
```

**可施压变量：** Rate、Mutual Recognition、Access、Recognition Authority。  
**人物困境：** “关系真实成立过，是否就必须永远同步？”  
**失败边界：** 冲突完全来自第三者 / 背叛 / 普通误会，不用本卡。

## MC-13｜未来视界坍缩 / 局部视界
**来源：** R44  
**适合：** 时间 + 命运 + 因果。  
**当你需要：** 长期未来不再被相信，导致当前投资、建设、责任都失去权重。

```text
Future Horizon↓
→ Long-term Consequence Weight↓
→ Present Investment↓
→ 制度 / 关系短视化
```

反向：
```text
Global Horizon = 0
→ Local Horizon仍存在
→ 人物把自由压缩到最后仍可改变的关系 / 体验 / 意义
```

**可施压变量：** Future Horizon、Investment、Local Actionability。  
**人物困境：** “如果没有以后，今天为什么还要为以后付钱？”  
**失败边界：** 只是普通倒计时、目标仍完全是“阻止末日”，不成立。

## MC-14｜责任本体化 / 分布式责任 / 有限承载
**来源：** R34、R46  
**适合：** 因果 + 本体。  
**当你需要：** 人物承担责任，但“承担”既不能自动赎罪，也不该自动吞掉全部身份。

```text
High-impact Cause
→ Responsibility Attribution
→ Accepted / Rejected / Distributed
→ Identity Interpretation
→ Integrated / Totalized / Externalized
```

分布式：
```text
Cause A + B + C + D
→ Consequence
→ 无单一Total Cause Holder
→ Responsibility Share分散
```

**可施压变量：** Responsibility、Identity Interpretation、Irreversibility、Capacity Limit。  
**人物困境：** “我确实做错了，但这件事有权定义我的全部吗？”  
**失败边界：** 承认错误后立刻恢复、被原谅、重新开始，没有剩余因果债，不适合本卡。

# 5｜第三轮门禁

- TK-03 只提供“怎么施压”的候选，不负责决定主题是什么。
- 机制卡必须服务 TK-01 已确定的 theme_question；不能为了套卡改题。
- 机制卡若涉及正式五维 n/x，仍必须通过 TK-02。
- 默认 1 主卡；最多 1 张对照卡。
- 不复制电影人物、剧情、世界观皮肤，只抽结构。
- 若机制只是让故事“更惨 / 更复杂 / 更反转”，却没有改变目标变量，直接 REJECT。
- R47 及之后研究不属于本轮冻结样本；后续需另做增量蒸馏。
