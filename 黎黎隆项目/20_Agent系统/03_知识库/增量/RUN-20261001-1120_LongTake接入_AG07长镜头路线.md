## 4. 踩坑记录（冒烟排障实录，四条教训）

1. **input 目录陷阱**：手拷文件到 `D:\H3\git\ComfyUI\input\` 无效——运行实例用 `--input-directory D:\H3\comfyui_input`。视频/图片一律放 `D:\H3\comfyui_input\`。
2. **`prompt` 字段必填**：H3LongTakeRender 的 `prompt` 是 required，接了 prompt_text socket 也必须给值（给全文最稳），缺失直接 400。
3. **提交失败先读完整 error body**：本次三条校验错（prompt 缺失 / 视频路径 / 图片路径）全在 body 里，一次定位。
4. **`int8_linear() got an unexpected keyword argument 'input_act_weight'` = comfy-kitchen 版本落后于 core**：core 0.38 master 调 `quant_ops.ck.int8_linear(..., input_act_weight=...)`（ck = comfy-kitchen 包），requirements.txt 却仍钉 0.2.31。修复 = `pip install comfy-kitchen==0.2.36`（master 自带 requirements.txt 是权威：kitchen 0.2.36 + aimdo 0.5.5）。**core 升级后必须按 master 的 requirements.txt 对齐依赖**，然后重启 ComfyUI（旧模块在内存里，不重启不生效）。

## 6. AG-07 路由建议

- **≤11s 短镜**：走现有单次渲染路线（264f 闸内）。
- **>11s 长镜 / 多段分镜**：路由 LongTake——每段 ≤243f（10.1s，17k+5），段间 keyframe 锚定 + color 接缝；原始音频可经 Stitch `audio_file` 回贴。
- **每段帧数闸门仍然生效**：`clip_frames` 上限 362 但**必须 ≤264**（本机内存墙）；推荐 124 或 243 两档。
- **断点续渲**：mode=continue 天然支持停/续；单段翻车用 redo_one + 换 seed，不重跑全片。
- 项目目录在输出盘（D 盘 output），成片名 `output_name`，完整 workflow 图随 mp4 内嵌，可回拖复原。
