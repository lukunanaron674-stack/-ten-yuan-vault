## 剧本 Agent｜研究问题
**如何在 8–10 秒里让“外部结构限制人物”成为剧情，而不是只有一个障碍画面？**

### 来源
- P0：`故事写作知识体系 R6`：事件必须改变对象/关系变量；冲突升级不是声音更大，而是未来选项损失增加。
- P1：CH-003 角色卡：角色会观察、试探、记住失败办法，再临时变招；不能默认随意破解全部系统。

### 新增可执行规则：反应后置
短镜头不要在刺激出现后立刻让角色完成解决。先让观众看见“旧策略仍被角色尝试”，再让结构性反馈证明旧策略失效，最后只给一个**未完成的小回应**。这样 8–10 秒能同时留下：人物策略、外部独立回应、下一镜必要性。

结构：`惯常策略 → 结构回声 → 旧策略失效 → 小回应停住`。

### 反例
`门关上 → 角色惊讶 → 立刻找到新入口 → 成功离开`：结果太快，结构没有真正改变未来选项，只是障碍+解题。

### 适用条件
- 需要表现制度/流程/历史记录的持续作用；
- 角色有可识别的惯常策略；
- 下一镜需要承接未完成选择。

## 分镜 Agent｜镜头语言问题
**怎样让观众看见“过去行动已经变成现在结构”，而不是靠拍更多监控器？**

### 新增规则：结构回声镜头
重复一个已知动作/路径，但让环境在角色动作完成前先响应。镜头不急着切，保留角色与入口同框，使“她还没做完，系统已经预判”成为画面证据。
