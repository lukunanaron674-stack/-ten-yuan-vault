## 2026-10-01｜青色｜关系身份

```yaml
date: 2026-10-01
region: 青色
candidate: 关系谱系
status: KEEP-CANDIDATE
primary_relation: X并Z → 生Z
source_refs:
  - 世界观/青色世界观/青色世界观正本.md
novelty: 把“同一性”从对象编号改成关系连续性；允许参与对象全部替换但关系仍被判定为同一关系。
conflicts: []
next_test: 研究关系身份在继承、身体改造、商品与法律中的边界案例
promoted_to:
```

### KEEP-CANDIDATE｜关系谱系
**一句话定义：** 青色文明不只给对象登记身份，还会给长期X并Z关系建立“谱系”；判断它是否仍是同一关系，不看参与对象是否还是原件，而看关键交换、接续与转化是否保持连续。

- 主标签：X并Z → 生Z。
- 主关系：**X并Z → 生Z**（冻结最高优先动态对子）。
- 辅助：XN补Z仅用于长期记录、版本历史与接续证据；不新增十元 canonical。
- X并Z部分：功能与身份存在于对象之间持续发生的交换、依赖和接续，不属于任何单体。
- Z部分：把“关系有没有连续”提取成可记录、可审计、可继承、可认证的谱系标准。
- 青色世界观影响力：9/10。理由：它会同时改变身体改造、商品、物流、遗产、组织资格与法律责任。
- 十元映射强度：10/10。
- 设定价值：10/10。
- 生长性：10/10。

#### X并Z → Z 完整链
1. **最初异常：** 一组共生净化体长期运行时，旧参与者会自然衰老，新个体逐步接入；几十年后原始个体已全部消失，但净化关系从未中断。
2. **为什么是X并Z：** 净化功能与“它是不是原来那套系统”的身份都不属于某个个体，而属于持续的交换结构、接续顺序和依赖链。
3. **早期遭遇：** 城市维修者发现两种极端：对象全换了但系统仍稳定；对象一个没换，但关键交换断过一次后，功能虽然恢复，却出现不同副产物。
4. **可重复观察：** 可追踪的是关键交换是否连续、替换是否存在重叠接续、关系断裂持续多久、断裂后是否需要重新驯化、功能副产物是否改变。
5. **Z化：** 关系日志 → 接续节点 → 重叠替换规范 → 断裂等级 → 谱系图 → 关系认证 → 继承/责任规则。
6. **文明改变：** 身体改造不再只问“换了多少器官”；商品不再只问“是不是原件”；组织设施可继承一段仍连续的关系；出现关系谱系师、接续公证员、断链调查员。
7. **残余X并Z：** 两段谱系可以意外融合；一次极短断链可能没有功能变化却引发身份争议；新的共生者加入后可能慢慢改变关系性质，迫使Z持续更新“连续到什么程度仍算同一关系”的标准。

> X并Z连续关系 → 观察替换/断裂 → Z谱系标准 → 大规模接续与继承 → 更多关系被长期维持和交叉 → 新X并Z → 再Z

#### 核心概念具象映射
1. **关系年轮**：长期共生界面留下分层纹理，承载X并Z的历史连续性，而不是普通身份证。
2. **接续桥**：旧参与者退出前，新参与者必须与其短期重叠，承载Z对连续性的标准化。
3. **断链痕**：关系曾中断的位置留下可检验变化，承载Z的审计证据。
4. **谱系图**：记录“谁接替了谁、哪段交换未断”，承载XN补Z的历史记录作用。
5. **关系继承证**：认证被继承的是持续关系而非某个对象，承载Z制度化。
6. **谱系师 / 断链调查员**：判断关系是否连续，承载Z职业化。

#### 文明衍生
- 角色：一个角色可以更换大量身体组件，却因关键共生关系连续而仍被制度认定为“同一身体谱系”。
- 生活：家庭长期养护的共生设施可跨代接续，继承的是关系而非旧器官。
- 组织：公共设施维修必须设计重叠接续期，不能简单拔掉旧件换新件。
- 技术：出现断裂等级、接续窗口、谱系认证与关系复原训练。
- 城市：老城区的“古老设施”可能没有一件原始材料，但关系谱系已经连续数百年。
- 剧情：原件全部存在却因关系断裂被判定为“已死亡”；赝品使用连续接续反而可能获得合法谱系，引发身份与所有权冲突。

### MERGE-CANDIDATE｜关系继承证
并入“关系谱系”。它只是Z制度层的下位应用，不独立升母设定。

### LOW｜关系身份证
- 十元映射：Z 9/10。
- 设定价值：3/10。
- 原因：如果只是给关系发编号，本质仍是普通身份证换皮，没有回答“参与对象全部替换后为什么还是同一关系”。

### REJECT｜绝对连续算法
- 原因：若算法能无争议判断所有关系是否同一，会抹掉X并Z持续产生的边界问题；只能存在有限标准与争议区。

### REJECT｜原件崇拜制度
- 原因：把“原始材料是否还在”设为唯一身份标准，会把关系身份重新退回单体对象身份，违背本轮母机制。

### 下一研究母题
**关系分叉**：一段被认证的X并Z如果同时接续成两条都保持连续的关系，哪一条继承原身份？重点研究X并Z如何产生“一个谱系分成两个都合理”的异常，并迫使Z建立分叉、责任与所有权规则。

## 2026-10-01｜红色｜身体主权的持续确认

```yaml
date: 2026-10-01
region: 红色
candidate: 反签身体协作
status: KEEP-CANDIDATE
primary_relation: Z（身体主权 / 持续自主选择）；ZN 为外显确认层
source_refs:
  - 世界观/红色世界观/README.md
novelty: 把红色既有“可退出关系”推进到身体正在被治疗、改造、共生或借用时仍可实时撤回；不是一次签字即永久授权。
conflicts:
  - 与“自决契约”同源，但后者是长期社会关系退出权，本条只处理身体过程中的持续授权。
  - 与“身体签名”不同，后者是身份表达，本条是身体边界与操作权限。
next_test: 身体协作在急救、昏迷、战斗与共生器官中的代理边界
promoted_to:
```

### KEEP-CANDIDATE｜反签身体协作
**一句话定义：** 红色文明认为“允许别人开始改变我的身体”不等于“允许他一直做完”；治疗、临时共生、义体接入、仪式性改造等过程必须保留可见、可执行的中途撤回机制。

- **主标签：Z。** 核心变量是身体过程中的选择权是否仍由本人持有。
- **次标签：ZN。** 撤回、继续、改方案必须能被现场明确表达并被所有操作者同时识别；ZN只负责把Z外显，不替代决定。
- **关系证据：** 红色正本已把Z定义为“自主选择、转向、行动方向、主体意志与身体主权”，把ZN定义为“表达、号召、感染、群体共振、把意志外显”。本条不新增十元生克关系。

#### 机制
身体协作开始前只确认“允许开始”；过程被拆成若干可停节点。本人可在任一节点继续、暂停、换操作者、改目标或终止。技术和职业必须围绕“撤回后如何安全退出”设计，而不是把撤回当事故。

#### 具象映射
1. **反签扣**：治疗台、共生接口、改造器上的本人侧机械扣；拉开即进入安全退出流程，承载Z的实际撤回能力。
2. **双向操作位**：操作者有工作控制，身体主人有独立停止控制；空间结构直接显示“谁都不能单方面完成全过程”。
3. **阶段纹**：皮肤贴片/器具刻度显示当前只授权到哪一步，承载Z的分段选择。
4. **撤回灯语**：继续/暂停/换方案的公共可视信号，承载ZN对本人选择的外显。
5. **退接师**：专门研究如何在不中伤身体的情况下终止共生、义体或治疗过程，承载身体主权催生的职业。
6. **安全退接间**：医院、工坊、旅团必须配置的退出设施，承载Z从价值变成城市基础设施。

#### 文明后果
- **角色**：角色可以在改造做到一半时改变主意，身体留下“选择转向”的真实后果，而不是只有接受/拒绝二选一。
- **生活**：纹身、治疗、义体、共生服装等服务报价必须同时包含“安全退出成本”。
- **职业**：退接师、身体见证员、分段治疗师出现；高水平不只是“接得上”，而是“随时退得掉”。
- **组织**：军队、工团、医疗机构不能以任务未完成为由锁死身体接口。
- **技术**：所有长期身体接口被迫发展反向拆解、降载、过渡供能和恢复训练。
- **城市**：大型医疗/改造设施出现独立退接通道，而不是把退出者塞回普通急诊。
- **剧情**：一个组织可能口头允许退出，却使用“拔掉就会死”的接口设计；红色冲突因此从口号层落到工程层。

- **十元映射强度：10/10**。
- **设定价值：9/10**。把“身体主权”从服饰表达推进到医疗、技术、职业和基础设施，且能直接制造剧情冲突。
- **世界影响力：8/10**。会系统改变医疗、义体、共生技术、军队与劳动制度。
- **继续生长性：9/10**。可继续研究昏迷代理、儿童、战时急救、不可逆步骤和多人共生的授权冲突。

### MERGE-CANDIDATE｜代声授权
**机制：** 群体可临时授权某人代为表达，但授权范围可撤回、可改写。
- 十元映射：Z+ZN 9/10；设定价值：5/10。
- 结论：并入既有“领声人 + 自决契约”。单独建条目只是把两条旧机制拼在一起，没有形成新的文明层。

### LOW｜转向赔偿表
**机制：** 改变承诺时按统一表格支付退出成本。
- 十元映射：Z 7/10；设定价值：4/10。
- 原因：可作为“自决契约”的局部制度细节，但若标准化过强，会把重新选择变成只有有资源者才买得起的权利。

### REJECT｜不可撤回英雄誓
- 原因：以“公开说过所以永远不能改”为荣，会让ZN的公开表达反过来锁死Z，与红色正本“持续选择/可转向”核心直接冲突。

### 下一研究母题
**失去表达能力时，身体主权由谁承接？** 聚焦昏迷、失语、被共生体接管感官、战场急救等状态。重点不是再造代理人职业，而是研究红色文明怎样避免“无法表达 = 自动失去Z”。
