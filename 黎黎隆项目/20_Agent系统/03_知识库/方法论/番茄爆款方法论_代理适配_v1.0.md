# 番茄爆款方法论｜代理适配 v1.0

> 原始蒸馏稿已完成三轮审核。本文不是“爆款定律”，而是《黎黎隆》代理系统的项目级生产增益规则。
> 优先级始终低于：用户目标 > Canon > 连续性 > 当前 story_goal > 已验证素材/状态。

## 1. 总工作假设

**单位时间新信息密度 × 情绪兑现率** 可作为排片/写作/短镜头的工作假设。
它用于发现“没有变化、没有兑现、没有未关闭状态”的弱任务，不作为普遍文学定律或自动评分真理。

## 2. 导演 Agent｜正式规则

1. 先判断收束帧是否成立；收束帧不能形成有效未关闭状态时，降低排片优先级。
2. 一批镜头结束后检查可视场景/名场面缺口，不机械追求固定数量。
3. 连续两个镜头若情绪和运动状态过同，优先岔开节奏。
4. 同场景镜头优先聚簇生产，减少角色/场景参考切换。
5. “钩子”不得覆盖 Canon、连续性、角色核心设定或当前 story_goal。
6. 只把本方法用于排片/增益，不用它替代主题、世界观、十元和剧本岗位判断。

## 3. 剧本 Agent｜正式规则

1. 开篇尽快出现冲突、决策或新动作；禁止纯环境铺垫占据入口。
2. 每个故事单元必须存在至少一个“不可跳过的下一步”。
3. 收尾优先留下明确钩子：危机/反转/身份/倒计时/悬念/利益/情感等均可，但不得机械套词。
4. 爽点定义为“价值兑现可被观察”，不靠固定反应词。
5. 对话保持短促；30–45%与单句≤30字只作为项目经验区间，不是硬门禁。
6. 删除无新信息过渡句与固定 AI 套话。
7. 工具评分只做 QA，不替代故事判断。
8. 8–10 秒镜头只承载一个核心变化时，剧本不得为了“信息密度”塞入多个并列事件。

## 4. 分镜 Agent｜正式规则

### 默认三阶段（DEFAULT_PATTERN，不是 HARD_RULE）
- 0–3s：建立主体、空间、当前压力。允许静态，但禁止无任务空镜。
- 3–7s：默认承担核心行动。
- 7–10s：确认变化，并尽量留下一个未关闭状态/视觉钩。

### 强规则
1. 一条短镜至少出现一次**可观察变量变化**：状态A → 状态B。
2. 镜头变化必须服务变量变化，不为“电影感”乱切。
3. 收束帧优先留“事情已经变化，但尚未完全结束”的状态。
4. 连续单镜变量链若更清楚，可合法偏离三阶段。
5. 参考图只提供可证实视觉信息，不从参考图脑补未确认设定。
6. 关键视觉变化若天然有可听事件，应同步 soundscape；禁止为增强气氛凭空堆能量音/爆音/闪光。

## 5. H3 Agent｜执行前 QA

H3 不重写剧情，只检查当前 prompt 是否满足：
- 有明确主体/空间/压力；
- 有至少一次可观察变量变化；
- 收束状态可读；
- 若使用三阶段，时间划分服务动作而非机械切段；
- soundscape 与动作/空间变化同步，不驱动无意义剪辑；
- 偏离三阶段时，只要连续动作链更清楚即可 PASS。

## 6. 不进入创作上下文的工具规则

以下只保留在 TOOL_CHECK / QA：
- hook_density 阈值；
- quality_selfcheck 阈值；
- 钩词距句号距离；
- “却/然而/突然/就在这时”等脚本识别细节。

禁止 Agent 为过检测器而反向写作。

## 7. 三轮审核记录

### R1｜逻辑审核
- PASS_WITH_REVISIONS。
- 修正“0–3秒必须动作”与“0–3秒静态建立”的冲突。
- 将通用规律、项目经验、脚本限制分层。

### R2｜岗位拆分
- 导演：排片/钩子/节奏/资产聚簇。
- 剧本：冲突/下一步/兑现/去空话。
- 分镜/H3：变量变化/收束钩/默认三阶段/soundscape。
- 工具阈值移出创作上下文。

### R3｜现有任务回放
对 LLL R05、CH-003 R07、MOUSE R44 做 prompt/结构级回放验证：
- LLL R05：适合压缩为“路线收紧→失衡→反向甩尾方案出现”。
- CH-003 R07：方法可明显提前核心变化，减少前段等待。
- MOUSE R44：原连续单镜变量链更清楚，证明三阶段不得硬套。

> 注：R3 为现有任务的结构/提示词回放，不等同于同模型、同素材、同 seed 的受控渲染 A/B。后续真实渲染数据可继续提高证据等级。

## 8. STOP 条件

当前 v1.0 已足够进入代理使用。
除非真实 H3/故事生产出现以下情况，否则不继续扩规则：
- 连续 3 次同类失败；
- 新规则与 Canon/连续性冲突；
- 有可重复的渲染 A/B 数据证明某条规则失效或需升级。
