# STORY_TENYUAN_CROSS_VERTICAL_PROTOCOL｜十元 × 剧本横纵动态链联合流程

## 目的
把“十元结构”用于发现故事动力，而不是把剧情硬套成十元公式。

适用：
- 一句话故事发散
- 角色主题曲 / 电影 / 案例启发后的故事转译
- 黎黎隆及其他角色的短剧情实验

不适用：
- 未经听音/逐段分析就断言某首音乐本体拥有某条十元动态链。
- 用十元标签替代人物目标、因果、选择与后果。

---

## 核心区分

### 1. 横向构图
同一阶段内，同时存在的力量与关系：
- 角色内部构成：如 ZX主 + Z中 + 小XN
- 角色 ↔ 对手 / 伙伴 / 世界
- 生 / 克 / 补的直接作用
- 多个十元可同时存在，不等于必须按顺序互相变成

### 2. 纵向动态链
沿时间推进，状态真实发生改变：
- T1 起始状态
- T2 作用 / 受克 / 获得条件
- T3 选择 / 改道 / 升级 / 失控
- T4 不可逆后果
- T5 回收后的新状态

横向关系必须能够改变纵向发展；纵向变化也应重新排列横向关系。

### 3. 构成 ≠ 转换
“ZX主 + Z中 + 小XN”是角色内部构成，不得机械写成：
ZX → Z → XN。

只有人物行为、能力、关系或决定权真的发生变化时，才登记为纵向变化。

## 联合工作顺序

### STEP 0｜输入
可来自：
- 角色正本
- 世界观正本
- theme_result
- 一首歌曲 / 一个电影案例 / 一个叙事机制

若来源是音乐或外部案例：
- 先提炼“叙事机制候选”，例如：双轨竞争、受克后改道、多点联动、循环失控、关系转移、自主选择。
- 未经正式验证，不把候选机制写成“该音乐已验证十元动态链”。

### STEP 1｜十元 Agent：先搭横纵结构
输出：
1. 角色内部构成
2. 横向关系图
3. 纵向动态链候选
4. 生 / 克 / 补直接作用
5. 哪些是 VERIFIED，哪些是 HYPOTHESIS
6. 一条“禁止机械化”提醒

要求：
- 先说明谁改变了谁、改变了什么。
- 删除任何“只贴标签但不改变后续”的关系。
- 不替剧本写完整事件。

### STEP 2｜剧本 Agent：把结构变成人物事件
基于 STEP 1，先发散 6–10 条一句话故事。

每条必须包含：
- 主角主动想要什么
- 第一行动由角色性格产生
- 阻碍具体改变行动路径
- 至少一次选择或变招
- 一个可见后果
- 结尾状态与开头不同

禁止：
- “世界出事，所以主角被迫行动”作为唯一发动机
- 为了凑十元而让人物突然变性格
- 用抽象词代替事件，如“获得成长”“理解自由”“完成蜕变”

### STEP 3｜十元 Agent：反审故事
逐条检查：
1. 横向关系是否真的进入因果？
2. 生 / 克 / 补是否产生不同后果？
3. 删除某关系后，故事是否完全不变？
   - 若不变：该关系只是装饰，不登记为有效动态链。
4. 角色主十元是否被剧情抹掉？
5. 是否出现“自己制造自己的克制”等更有价值结构？
6. 是否存在动态链断裂、假回收、伪关系？

输出只做结构审查，不重写完整故事。

### STEP 4｜剧本 Agent：二次改写
根据反审结果：
- 修掉装饰关系
- 强化人物主动性
- 让代价由角色此前选择产生
- 保留意外与不完全可控性
- 不把所有故事收束成同一模板

从中保留 3 个“机制不同”的骨架，例如：
- 世界关系 × 人物关系双层回收
- 角色内部构成冲突
- 双向竞争 / 循环失控转关系变化

### STEP 5｜联合验证
最终每个骨架都要回答：

**横向**
- 同一时刻有哪些力量？
- 谁生 / 克 / 补谁？
- 直接改变是什么？

**纵向**
- T1 到 T5 每一步什么状态改变？
- 哪一步是不可逆变化？
- 结尾怎样回收到开头矛盾？

**角色**
- 主角仍然像这个角色吗？
- 主十元是否仍主导？
- 次十元是否通过行为而非标签显现？

## 六种可复用叙事构图候选

这些只是“叙事机制模板”，不是音乐本体的已验证十元结论。

1. **双轨竞争型**
   - 横向：主角 ↔ 对手；Z 作为变招方式
   - 纵向：挑衅 → 回应 → 变招 → 升级 → 关系重排

2. **受克后改道型**
   - 横向：XN 克 ZX；Z 提供另一条路径
   - 纵向：争取 → 受阻 → 失败 → 改道 → 以新方法争取

3. **多点联动型**
   - 横向：ZX / Z / N / NZ 等多方同时作用
   - 纵向：一个动作 → 连锁反应 → 意外 → 借势 → 新关系

4. **循环失控型**
   - 横向：ZX 与阻力相互升级
   - 纵向：争取 → 受克 → 加码 → 再受克 → 失控 → 后果

5. **关系转移型**
   - 横向：个人目标与 N / 伙伴关系共同变化
   - 纵向：为自己争取 → 关系建立 → 行动伤害关系 → 修复 → 共同目标

6. **世界规则 × 自主选择型**
   - 横向：NZ / X并Z / XN 与角色 ZX+Z 形成多层关系
   - 纵向：自由状态 → 被定义 / 工具化 → 发现另一种可能 → 重新争取决定权

## STOP 条件
一次联合发散满足以下条件即可停：
- 已有 ≥ 6 条一句话故事
- 至少 3 种不同机制
- 已完成一次十元反审
- 已保留 3 个机制不同的骨架
- 每个骨架都有横向关系 + T1–T5 纵向变化
- 没有把未验证的音乐映射伪装成正式十元结论
