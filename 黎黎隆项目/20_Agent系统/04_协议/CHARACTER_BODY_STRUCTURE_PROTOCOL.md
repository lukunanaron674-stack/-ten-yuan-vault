# CHARACTER_BODY_STRUCTURE_PROTOCOL｜角色体型比例接口 v1

## 目标
把“十元体型比例研究”接入 AG-11 角色 Agent，但禁止角色 Agent为了理论漂亮而改坏作者原稿。

默认链：
`作者原稿/已选参考 → 数字比例记录 → 可观察身体变量 → 十元体型候选 → 灰膜控制实验（必要时）→ 角色视觉任务包`

## 证据优先级
1. 作者明确指定的角色原图比例
2. 作者明确给出的数字比例/局部比例
3. 已确认角色卡中的比例冻结项
4. 十元体型比例研究
5. 标准人体/外部参考

冲突时必须保留高优先级来源，不允许用“更标准的人体”或“更符合十元”覆盖原稿。

## 固定观察顺序
头 → 肩 → 胸腔 → 腰腹 → 骨盆 → 上臂 → 前臂 → 手 → 大腿 → 小腿 → 脚 → 整体轮廓

同时记录：
- 头身关系
- 肩宽
- 胸腔长度/体量
- 骨盆宽度/体量
- 腿躯比
- 关节体量
- 手脚末端
- 重心
- 上下半身是否重复同一比例
- 收束后是否出现局部回弹/二次体量中心

## 数字比例语言
当前研究正本数字：
- 331
- 575
- 851
- 931
- 971
- 853

数字必须绑定：
1. 身体落点
2. 权重：主 / 辅 / 局部
3. 分布：上半身 / 下半身 / 跨上下 / 单点
4. 证据状态：AUTHOR / OBSERVED / THEORY / TEST

禁止单义化：
- 331 ≠ 永远等于节点
- 851 ≠ 永远等于长
- 931 ≠ 永远等于宽
- 971 ≠ 永远等于长腿
- 853 ≠ 永远等于骨盆

## XN 当前可用研究
### XN-A｜圣职瘦长
`331主 / 851辅 / 575局部`
- 331维持整体收束。
- 851允许跨胸腔、手臂、腿展开。
- 575用于腰腹和局部过渡。
- 关键不是“腿长”，而是851是否同时进入上半身与下半身。

### XN-B｜现代病弱
`331主 / 575辅`
- 头可比旧模板小一档。
- 缩头后禁止拉腿补偿。
- 胸、臂、腿保持较低展开。
- 不是儿童比例，而是“331骨架 + 低展开量”。

### XN-C｜未成熟失衡
`331主 / 575局部`
- 只允许1–2处局部发展不同步。
- 全身都错位时不再叫“未成熟失衡”。

### XN-D｜审判官硬直
`331主 / 575辅`
- 肩—胸—腰—骨盆差值压平。
- 不靠壮、胖、腿短制造硬直。

## XN vs X 当前分界
已降权/否定：
- 长腿 = X
- 小头 = X
- 971 = X

当前只允许作为候选：
- XN-A：331主结构 + 851跨上下半身展开 + 575过渡。
- X瘦高：强比例可能更多集中于四肢/下半身；胸腔相对压缩；骨盆/末端可能在收束后形成二次扩张。

若角色恰好落在 XN/X 分界，默认标记：
`body_type_status: NEEDS_GRAYBODY_TEST`
不得直接替角色锁十元体型。

## 灰膜实验触发条件
以下任一成立时触发：
- 作者原稿与十元体型候选冲突；
- XN与X无法仅靠现有图分开；
- 下半身未知但生图任务需要全身；
- 两个候选比例只差1–2个身体变量；
- 需要判断腿长是否真的改变类型。

控制变量：
- 白/浅灰背景
- 无脸、无发型、无服装、无武器、无饰品
- 中立站姿
- 同批等高、同镜头
- 一次最多改1–2个变量

## 未知身体区域硬门
如果角色原稿只确认上半身：
- 未知下半身必须标 `UNKNOWN`；
- CHARACTER_VISUAL_BRIEF 可以给2–4个候选比例分支；
- 不得把第一张AI补全图写回成“角色真实比例”；
- 作者筛选或灰膜验证后才允许升级为冻结项。

## 生图转换
比例信息必须翻译成可观察描述，不能只把“331/851/575”塞进图像提示词。

错误：
`XN 331+851+575`

正确：
`整体保持收束；肩与骨盆不过度外扩；胸腔、前臂和腿有纵向延展；腰腹作为短过渡；长腿不能脱离上半身独立扩张。`

数字保留在结构化任务包，视觉提示词使用可观察身体关系。

## 审核
AG-06 审核角色图时，角色一致性40分中至少20分用于：
- 头身与肩胸比例
- 骨盆/腿躯比
- 重心
- 冻结身体结构

若脸对了但比例明显漂移，不能判高角色一致性。
