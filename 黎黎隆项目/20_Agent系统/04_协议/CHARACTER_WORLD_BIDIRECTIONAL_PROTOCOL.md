# CHARACTER_WORLD_BIDIRECTIONAL_PROTOCOL｜角色 × 世界观双向生成协议 v1

## 核心
角色与世界观不是单向包含关系，而是双向生长：

```text
世界观 → 地理/组织/资源/制度/生活 → 角色生态位 → 角色设定
角色图/角色设定 → 个体异常/需求/重复模式 → 世界观候选 → 世界审核
```

## A｜世界观生成角色
AG-10 可从以下来源主动生成 WORLD_CHARACTER_SEED：
- 地理位置
- 区域生态
- 城市结构
- 公司/组织
- 职业体系
- 资源生产与运输
- 法律/许可制度
- 日常生活方式
- 灾害与维护机制

AG-10 负责：
- 这个人为什么会存在；
- 他在哪生活/工作；
- 属于什么组织或社会层；
- 世界给他什么压力；
- 哪些身体、工具、服装、行动习惯是环境长期塑造出来的。

AG-11 负责：
- 这个具体的人是谁；
- 性格、欲望、个人矛盾；
- 角色十元；
- 具体体型、脸、剪影、服装细化；
- 与主角/剧情的个人关系；
- 最终角色卡。

## B｜角色反向生成世界
输入可以来自作者角色图、已审核AI角色图、角色卡、角色行为或剧情需求。

AG-11 先拆三层：
1. visual_evidence：图上真的有什么；
2. character_interpretation：作为个体怎么解释；
3. world_implication：如果不是个体特例，会对群体/组织/地理/制度造成什么后果。

只有第3层才允许进入 WORLD_PROPOSAL。

## C｜地理如何规划角色
地理不是“角色出生地”一行字。必须至少作用到：移动方式、体型/重心适应、防护、衣服、工具、作息、资源获取、风险判断、社交方式或职业分工中的一项。

## D｜组织如何规划角色
组织不是给角色贴 logo。必须回答：为什么需要这个岗位、角色有什么权限、获得什么资源、遵守什么流程、哪里能违抗、身份如何被识别、组织怎样改变服装/装备/语言/风险。

## E｜门禁
- WORLD_BYPASS：世界正本已足够。
- WORLD_CHECK：需要世界解释。
- WORLD_PROPOSAL：需要新世界规则。
- WORLD_CHARACTER_SEED：世界主动提供人物生态位。
