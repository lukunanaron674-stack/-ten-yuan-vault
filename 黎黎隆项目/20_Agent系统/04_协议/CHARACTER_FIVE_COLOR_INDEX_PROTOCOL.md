# CHARACTER_FIVE_COLOR_INDEX_PROTOCOL｜角色五色编号与排序协议 v1

## 目标
把角色库从“按创建时间堆 CH-001/002/003”改成：
- 主 ID 稳定
- 五色视觉分类清楚
- 世界归属独立
- 素材完成度一眼可见

## 两条颜色轴必须分开
### A. 世界区域
`world_region: cyan|red|pink|cross_region|unassigned`

### B. P00 五色视觉桶
| 编号 | 色名 | HEX |
|---|---|---|
| C01 | 深墨青 | #142A34 |
| C02 | 灰紫 | #855D8F |
| C03 | 暗红 | #913840 |
| C04 | 青蓝绿 | #69D4CE |
| C05 | 淡青灰 | #CDE7E6 |

视觉桶只负责**角色主视觉排序**，不等于十元、不等于世界阵营。

## 编号
现有主 ID `LLL-CHAR-###` 永不重排，避免旧引用失效。

新增排序号：
`color_sort_id: C01-001 | C02-001 ... C05-xxx`

只有素材 Agent 看过真实图后才允许最终分桶。

未核验：
`color_bucket: UNASSIGNED`
`color_bucket_status: NEEDS_ASSET_VERIFY`

## 五色分桶依据
优先看：
1. 已审核四宫格主参考；
2. 已确认全身 / 中全景 / 中景主参考；
3. 作者原稿；
4. 单头像只能做 provisional，不得永久定桶；
5. 文字颜色描述不能替代真图。

判断的是角色在统一 P00 系统中的**主视觉控制色**，不是像素占比机械最大色。

## 每个色桶内排序
先按视觉完成度：
1. READY_VISUAL
2. HEAD_ONLY_DESIGN_PENDING
3. ASSET_UNVERIFIED

同级再按稳定主 ID 排序。

## 角色库索引显示字段
```text
主ID | 五色号 | 角色 | 世界区域 | 世界同化 | 素材形态 | 角色设计状态 | 生产状态
```

## 禁止
- 因青色世界自动分 C04；
- 因角色有红围巾自动分 C03；
- 因十元为 Z 自动分青色；
- 为了五色整齐重命名/移动原角色卡；
- 单头像直接判“角色完成”。
