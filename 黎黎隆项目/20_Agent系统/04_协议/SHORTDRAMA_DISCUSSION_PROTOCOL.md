## 一、设计原则：十元不是贴标签，是制造剧情压力

十元端点在短剧里只有三种合法用法（每集至少落一种，且镜头可拍）：

| 用法 | 定义 | 实测样例（A线《合同上的日期比我早十一天》） |
|---|---|---|
| **武器** | 主角靠这个十元端点赢下本集 | （待验）H05 折层递送者用"递送"动线撕合同 |
| **枷锁** | 这个十元端点是主角本集受制的原因 | H06 接口复核员 `xn`=拆回/重接测试 ↔ S03「拆腕」：他最懂拆装，所以敢当众拆自己的腕 |
| **兑现** | 卡点帧里十元端点以动作/道具/身体特征/声音具象化 | 全城接口灯同秒闪出同一个名字（`zx` 主体资格的集体显形） |

- 十元端点必须从设定源读出（角色编号总表 / 图文审核页十元句），**禁止现编端点**。
- "名字、等级、色卡"不构成十元证据（铁边界 #8）；集纲里的十元兑现元素必须是行动证据：谁→对谁→机制→变量前后态。

## 二、三回合制

### R1｜SCRIPT_BEAT_PROPOSAL（AG-12 出）
- episode_entry 数组（集号/集名/事件/卡点/爽点/反应者）。
- 角色岗位表：**每格填已有角色池编号**（如 主角=H06），并注明换卡理由（十元对戏眼 / 资产已渲染 / 职能带对号）。
- 未定十元的格子留空，标 `CLAIM_NEEDED`。

### R2｜TENYUAN_CLAIM（AG-02 回）
对每个 `CLAIM_NEEDED` / 每个已填编号返回 `tenyuan_claim`：
- 主十元 / 次十元 / 动态链 / 体量
- 克 / 生 / 补关系（只调已复核关系，不自动推出）
- 用法判定：武器 / 枷锁 / 兑现（三选一，可多标，但每集主用法唯一）
- 具象化建议：动作 / 道具 / 身体特征 / 声音
- 已验证 / 待验证标记 + 禁止误读

### R3｜SCRIPT_TENYUAN_MERGE（AG-12 回填 + AG-02 校验）
- AG-12 把 tenyuan_claim 回填进 episode_entry 的"十元兑现元素"字段；每集卡点帧 ≥1 处。
- AG-02 做 SETTLE 校验：verdict = ACCEPT / MODIFY / REJECT。
- 校验通过的集由导演 AG-00 标 SETTLED，进入 AG-01 拆镜队列。

## 三、回合格式（沿用 DISCUSSION_PROTOCOL v1）
- verdict: ACCEPT | MODIFY | REJECT
- target_fields: []
- reason
- proposed_patch
- protected_fields: []

禁止：重写无关字段；用长篇自由讨论代替字段修改；越权改对方专业结论。

## 四、裁决规则
1. **AG-02 不得为映射方便改卡点**——十元是压力来源，不是装饰；映射不上说明选错了卡或选错了人，回 R1 换卡重提。
2. **AG-12 不得删十元元素凑节奏**——删元素等于删枷锁，枷锁没了爽点引擎就空转。
3. 双方僵持 → 提交导演 AG-00 MERGE / DECIDE，附各自 target_fields 与证据状态。
4. 十元代理发现集纲违反世界观正本（如黑金人格化）→ REJECT + 引用正本条目，AG-12 必须改。

### 7.2 协议修正案（依 R2 摩擦记录 #1-#7）
1. **需求分流（新增，最重要）**：R1 提出需求前先分域——十元域 / 世界观域（`WORLD_ASSET_NEEDED`→AG-10/AG-05）/ 角色视觉域（→AG-11/AG-05）/ 条例法理域（→AG-10 或作者）。**只有十元域需求才标 CLAIM_NEEDED**。本轮 8 处里 4 处错标，全靠这条堵住。
2. **S 卡字段降级**：S 卡无关系句时，"主十元"允许只填字母标记+「无关系句」；外貌因果句可作**兑现类具象化源**，不构成行动证据（铁边界 #8 不豁免）。
3. **提编流程**：从 60 池提编为组织职务走 `CLAIM_ORG` 声明（角色编号+目标职务+端点沿用角色源句+结构同构理由），经作者拍板后由 AG-11 认领。
4. **主用法唯一性定义**：主用法指**本集卡点帧那一拍**的唯一用法；角色全程可多标（枷锁/武器/兑现并存，如 H06）。
5. **已验证改标权**：待验证→已验证只能由作者或 AG-00 在"行动证据成片"后操作，Agent 无权改标。
6. **体量字段**：N 批允许"无源"。
7. **克/生/补字段**：允许整字段"无源"；另立待办——建《十元关系登记页》（STAGING）作唯一关系源，建好后本字段才必填。
8. **背景事实引用等级**：剧本任务包中的背景事实（如"十四岁被签"）标 `BACKDROP`（背景事实，非 Canon）——可用于具象化与用法判定，不得用于端点验证；正式存放 CTX-12（未建前随任务包走）。
