# 《黎黎隆》十元应用实验室｜A2 角色层｜锚序锁身

> 第二圈角色层实验。目标不是继续给巨尾加功能，而是让 G 层结构反事实审核器反查 A 层：十元是否已经进入黎黎隆的身体结构本身。只读使用 current canonical / Semantic IR / 生克补 / 动态链；不修改理论正本。

## 本轮应用层

A｜角色（第二圈）

## 当前真实问题

现有主树已经锁定“夺路尾 v0.1”：黎黎隆以 `zx8 + xn3` 先留下最小锚序，再把自己的方向压成队伍真实可走的新路；已布锚点又限制下一次临时转向。

但 G 层审核器暴露了一个新的真实缺口：如果角色设计图只画成“前段开路 + 后段锚定”的多功能机械尾，那么即使使用方式符合夺路尾，**身体本身仍可以被普通工程探索者几乎原样拥有**。

因此本轮只问：

> 能否让 `zx8 + xn3` 直接改变黎黎隆的身体自由度，使“开出一条别人能走的路”必然以“自己暂时失去一部分身体自由”为代价？

这不是追加一个副作用，而是要求身体结构把 `xn 克 zx` 的限制做成可观察、可反转、可审核的机械事实。

```yaml
  - 对应尾段关节实际锁止、展平或转成承力骨架
  - 后方挂索/人员/桥带开始依赖该锁止段
  - 拔锚后对应关节恢复活动，同时旧路线失去一部分稳定
```

## 十元只读依据

- `zx` 不是“力气大”或“画面中心”，而是主体公开显权并扩大现实决定范围，使他者与环境围绕其方向重新反应。
- current canonical `xn 克 zx`：既有结构先持续运行，随后 `zx` 的即时显权扩张范围、速度或持续性被限制；`xn` 克的不是力量本身，而是“绕过既有结构、立即扩大决定范围”的能力。
- 本项目只把这一关系做成角色身体层的项目应用，不把“关节锁止”反向升级为 canonical 定义。

## 三个候选

### 候选 A｜多模块换头尾

尾尖可换抓钩、钻头、探针、照明器、切割器；不同环境切换不同工具。

**nearest-neighbor：** 与普通模块化探索装备完全同类。

**removal：** 删除 `zx/xn` 后所有功能仍原样成立。

**G 审核预测：** `TENYUAN_DECORATIVE_ONLY`。

**结论：拒绝。**

---

### 候选 B｜路线记忆尾

尾部沿途记录压力、地形和坐标，必要时自动回放历史路线，帮助队伍返回。

**nearest-neighbor：** 等于轨迹记录 / 安全绳 / SLAM 路径记忆的生体版本。

**reverse：** 即使已布锚点完全不限制黎黎隆改向，这个设计仍然成立，说明 `xn 克 zx` 没有进入身体约束。

**counterexample：** 一个高 `xn` 测绘员比黎黎隆更自然拥有这套身体。

**结论：拒绝。**

---

### 候选 C｜锚序锁身：内部自由度换外部路线权

巨尾不是“前段负责开路、后段负责锚定”这么简单，而是存在**可从活动关节切换为承力锁骨的关节组**。

每当黎黎隆让一枚锚真正成为队伍可依赖的路线节点时，与该锚对应的一组尾部关节必须锁止：

1. 锚未成立：尾巴柔韧、自由度高，黎黎隆能迅速试探多个方向，但后方没人能稳定跟进；
2. 第 1 枚锚成立：一组关节锁成承力结构，外部获得第一个可靠通过点，巨尾侧向自由度下降；
3. 第 2 / 3 枚锚成立：更多身体自由被抵押给路线，桥带 / 挂索 / 人流开始围绕他选择的方向稳定重排；
4. 若黎黎隆突然想改方向，他不能“想转就转”，必须先拔锚、断开旧承力或把一段尾体留在旧路上；
5. 一旦拔锚，对应关节恢复自由，但原路线同步失去一部分可重复通过性。

这里的关键变量不是“尾巴变硬”，而是：

> **身体内部可自由决定的部分越少，环境中被他固定成公共路线的部分越多。**

这把 `zx8` 与低量 `xn3` 做成同一具身体里的可观察交换：黎黎隆可以强行把方向变成现实，但已经成立的最小结构会立即限制下一次即时扩张。

### 检查

**nearest-neighbor：**
- 不等于普通变形武器：变形武器可以在刚性 / 柔性之间切换而不改变外部路线的决策权与持续结构。
- 不等于安全绳：安全绳提供保护，但不会要求主体以自身关节自由度作为“路线稳定”的现实载体。
- 不等于普通负重代价：代价不是疲劳值，而是明确改变下一次 `decision_right` 可即时覆盖的方向范围。

**removal：**
若删掉十元结构，只保留“机械尾能变硬、能插锚”，最自然的设计会允许它一边锁住路线、一边仍任意转向；“内部自由度下降 ↔ 外部路线约束上升”的强耦合没有理由必须存在。因此不能原样保留。

**reverse：**
故意构造反例：三枚锚都在承力，但尾巴仍能像未锚定时一样自由甩向新方向。如果审核器仍判通过，则说明它只认道具，不认 `xn 克 zx`。正确结果必须是 `FAIL_REVERSE_INSENSITIVE` 或 `FAIL_CAUSAL_RESPONSE_MISSING`。

**counterexample：**
一个普通探索者可以有更强、更先进、更灵活的锚定尾，却没有必要让“每建立一段公共路线，就锁掉自己一部分自由度”。该耦合只在“个人方向扩大成现实路线 + 先行结构反过来限制即时扩张”同时成立时才自然。

**结论：通过。**

## 删掉十元测试

结果：**PASS**。

删除 `zx/xn` 后仍可保留“会锁止的尾巴”，但无法保留以下不可替代约束：

```text
黎黎隆选择方向
→ 锚点成立为别人真实使用的节点
→ 对应身体关节失去自由度
→ 外部路线稳定性上升
→ 下一次即时改向范围下降
→ 只有解除既有节点，身体自由与改向范围才恢复
```

因此十元改变了：身体分工、动作顺序、角色姿态、换路代价、后方人员如何依赖他，以及 AI 可审核的失败条件。

## 最终保留｜锚序锁身 v0.2

### 一句话

> 黎黎隆不是用一条“很强的尾巴”开路；他每把一段未知空间变成别人能走的现实路线，就必须把自己的一部分关节暂时锁进那条路里。

### 身体设计硬规则

1. 巨尾必须明确区分**自由关节组**与**可锁承力组**，但外形仍保持嵌合、包裹、节奏变化，不能退回均匀节节机械蛇。
2. 锚点不是外挂小工具；锚成立时必须有一条可见的力学链回到某组尾关节，并使其姿态/活动范围改变。
3. 最小锚序保持低量：通常只允许 1–3 个关键锁身节点，避免把黎黎隆写成高 xn 流程机器。
4. 角色静态设计也要留下“哪些段能自由摆、哪些段可锁成路线骨架”的读图证据。
5. H3 / 分镜里若出现“锚全落地但尾巴自由度不下降”，按 G 层直接 FAIL。

### G 层审核接口

```yaml
expected_ir:
  changed_variable:
    tail_internal_dof: down_when_anchor_becomes_public_route_node
    route_external_constraint: up_when_tail_joint_locks
  evidence_required:
    - anchor_becomes_load_bearing
    - corresponding_joint_group_locks
    - downstream_route_or_people_begin_to_depend_on_it
  removal_test: removing ten-yuan coupling must collapse the body-route exchange
  reverse_test: anchors_stable + no_dof_loss => FAIL
nearest_neighbor: "普通模块化锚定尾 / 安全绳 / 变形武器"
non_substitutable_constraint: "外部路线稳定性必须由主体内部自由度的真实下降换来"
```

### 它给《黎黎隆》新增的东西

- **角色轮廓会随行动阶段改变**：探索初期尾巴松、弯、试探；路线成立后尾巴局部变成明显的承力折线/骨架。
- **黎黎隆的姿态会被自己创造的路反向牵住**：他越把世界变成“大家能走的路”，身体越不像完全自由的个人。
- **换路可以成为真正动作戏**：不是按按钮切换模式，而是拔哪一锚、牺牲哪段旧路、先解锁哪组关节。
- **世界母题进入身体**：生命为了进入更远地方而改变身体；黎黎隆进一步表现为“把自己的一部分暂时变成道路”。
