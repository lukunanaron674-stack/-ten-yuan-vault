# 外发聊天系统｜使用说明

> 解决的问题：每个 AI 框都只记住自己那一段。本系统让**任何一个新框 10 秒进入状态**，聊完的内容**能回流进 vault**。

## 1｜四步循环

```
① 复制  →  打开对应聊天卡（A/B/C/D），整份复制，贴进任何新框
② 聊    →  在那个框里正常干活（它已经有全部上下文）
③ 粘贴  →  把框里的产出复制回来，贴进 06_外发聊天系统/收件框_粘贴与归位.md
           并在段首写上卡片给你的归位标记，如【世界观更新】【角色·红桶】
④ 归位  →  跟我说一声（或自动化扫到），我按标记把内容合并进对应正式文件
```

## 2｜四张聊天卡

| 卡 | 干什么用 | 归位标记 |
|---|---|---|
| **A 世界观底盘** | 聊设定、推力量体系、修生长链 | 【世界观更新】 |
| **B 角色五桶** | 跑角色卡、扩写、分桶调整 | 【角色·桶名】如【角色·红桶】 |
| **C 故事发散** | 一句话前提、章节、Bible | 【故事·前提】/【故事·正文】 |
| **D 场景出图** | 场景描述词、出图方案 | 【场景·出图】 |

## 3｜规矩（防止聊散了收不回来）

1. 卡片内容**只在 vault 改**，改完卡重新复制——外面的框永远只是临时工
2. 归位标记必须带，没标记的粘贴内容我按【未分类】处理，攒多了催你分
3. 每次归位我会在收件框对应段落下写 `✅ 已归位 → 文件路径`，然后删掉原文（原句太长就留摘要）
4. **分 Canvas ×3**（按聊的内容选对应那张发散）：
   - `世界观发散Canvas_v0.1.canvas` —— 配 卡A 世界观底盘：中央三色力量核 → G0-G8 生长链（右）/ O1-O6 势力（左）/ 地域·资源链·五色合成各枝
   - `角色发散Canvas_v0.1.canvas` —— 配 卡B 角色五桶：中央五桶核 → 红（ZY 卡+CH）/ 粉 / 青 / 黑 / 白 各桶枝 + 分桶纪律·统计
   - `场景发散Canvas_v0.1.canvas` —— 配 卡D 场景出图：中央「三色能量×R地域」核 → R1-R6 / 城外六带 / 视觉三定律 / 诡异渗出点词库
5. `黎黎隆_发散Canvas_v0.1.canvas` 是总览版：全内容一图。细聊用分 Canvas，回库归位时我同步更新总览版
