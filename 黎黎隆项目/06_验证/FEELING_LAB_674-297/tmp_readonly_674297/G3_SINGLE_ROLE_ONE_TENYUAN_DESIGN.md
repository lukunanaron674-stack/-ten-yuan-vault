# G3｜单角色 × 单十元：感受如何被表现出来

## 这份文件做什么

把 674-297 用户锁定的 G3 目标整理成可执行的纸面方案。现在没有选定合格角色、没有合格 A_READY 素材、没有体验者数据；本文不是实验方案已获最终批准的声明，也不是实验结果。

- 目标研究对象是 **NX 感受**，不把它翻译成“耐心”或其他情绪词。
- 用户举的“船 → 暴雨 → 末世 → 独居”说明逐层加入语境线索可能放大目标感受；这些层级同时混杂多个变量，只能作研究启发，不能直接证明因果。
- 要测的是观看者当下报告的感受强弱，不是把 NX 当作角色的客观属性，也不是“角色变得更 NX”。

## 研究问题

固定一名经 G1 确认的角色及其身份、能力、造型和一个明确动作后，只改变一个主要表达线索，观察盲评观看者是否更常报告 NX，以及 NX 的自评强度是否相对基线提高；同时检查其他十元感受是否一起提高、替代 NX，或造成相反解释。

## 表达通道：分别设计，不在首轮捆成一个“配方”

| 通道 | 一次只动的主变量示例 | 固定/记录项 |
|---|---|---|
| 表情与情绪反应 | 面部肌肉/反应时长的一项 | 不用情绪词提示目标；不同时改姿势 |
| 姿态与空间关系 | 身体张力、朝向、视线距离中的一项 | 角色身份、服装、动作目标固定 |
| 动作选择与顺序 | 同一动作中的一个选择或一个顺序节点 | 能力、目的、道具、时长尽量固定 |
| 时间节奏 | 停顿、延迟、重复或回收中的一项 | 动作内容、镜头、声音固定 |
| 构图与空间响应 | 景别/留白/空间响应中的一项 | 角色、动作、时长与光色固定 |
| 光色/声音 | 首轮只选光色或声音之一 | 不同时改光色和声音；保持其他线索不变 |

这些是操纵维度，不是“某种表现必然产生 NX”的规则。哪个通道先做，须由可用刺激和明确的单变量对照决定；没有有效版本对时只能记录非因果案例观察。

## 语境线索拆分：把用户示例拆成独立因素

“船、暴雨、末世、独居”分别做有/无线索的独立候选条件。不能把四者按顺序一次性全加，然后把差异归因给 NX。设计阶段先记录：

1. **基线**：同一角色、动作、构图、时长、声音与 seed；不加入这四类线索。
2. **单因素候选**：在基线上分别只加船线索、只加暴雨线索、只加末世线索、只加独居线索。
3. **消融/交互**：任何两因素组合都单独标成交互条件；具体交互组在看反馈前预先登记，不根据结果挑选。
4. **完整叠加**：若未来需要，可作为综合案例；不得代替单因素组，也不得单独作因果证据。

正式素材门未通过前，上表只用于文字脚本/分镜预研，不生成 H3 视频。视觉实现细节要等角色身份、能力和冻结项明确后再填写。

## 盲评记录顺序

1. 随机给观看者看不含十元标签、研究者假设或“NX”字样的刺激；隐藏条件名称，尽量打乱顺序。
2. **先自由描述**：逐字记录“画面是什么、我实际有什么感受、是什么画面线索让我这样感觉”；允许“没有感受/说不清/不愿回答”。
3. 分开记录三个概念：
   - 画面中角色表现出的情绪；
   - 观看者自己实际产生的感受；
   - 喜欢/不喜欢。
4. 自由报告锁定后，再让观看者对现行十元感受分别自评 0–10，并标主次；不把喜好分数当感受强度。
5. 研究者最后才编码 NX 候选，记录其他十元、歧义、反例和不同解释；参与者不同意时保留其更正。
