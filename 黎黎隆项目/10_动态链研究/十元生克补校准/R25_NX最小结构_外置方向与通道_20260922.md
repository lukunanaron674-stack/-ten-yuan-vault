# R25｜NX最小结构：外置方向与通道

## 本轮问题
“另一主体掌握不可替代条件，使黎黎隆行动必须经过对方才能闭合”是否足以判定 NX？

## 用户已确认/正本规则
现行 nx canonical：主体不占据最终方向决定权，沿别人、关系、流程、秩序或现状已经给出的方向与通道推进。一次求人、一次借力、单纯资源差或外部强迫均不能单判 nx。

## 本轮推论
“另一主体掌握不可替代条件”本身不足以判 nx。它只证明资源/权限依赖。要进入 nx 关系功能，至少还要满足：
1. 方向、权限或解决通道已由他者/关系/流程给出；
2. 主体实际沿该既有通道推进；
3. 主体在该段不占最终决定、否决或重设问题的位置。
因此：不可替代条件 + 必须经过对方 ≠ 自动 NX；只有当依赖同时造成方向/通道外置，并且主体沿此外置通道推进，才是 NX 关系功能强候选。

## 支持案例
XN 让黎黎隆过去的临时改道失效。某维护员掌握城市已经存在的检修通道和开启权限；黎黎隆无法重设该通道的规则，只能请求维护员按既有检修路线带她进入，并沿对方给出的节点推进。这里不是“对方有钥匙”就算 NX，而是方向/权限/解决通道均在外部，黎黎隆借用并沿其推进。

## 反例/边界
同样是维护员掌握钥匙，但黎黎隆只借来钥匙，随后自己重新选目标、改路线、决定何时进入并可随时否决原方案。此时只是一次借资源/权限，不能由“必须借钥匙”反推 NX。若她因暴力或生存威胁被迫照做，也不能据此判稳定 NX。

## 判定与置信边界
- “不可替代条件使行动必须经过他者”足以判 NX：否。
- “方向/权限/解决通道外置 + 主体沿既有通道推进 + 本段不占最终重设位置”：NX 关系功能高置信候选。
- 置信度：9.8/10，依据 canonical nx 准度卡。

## 《黎黎隆》应用
关系判据已足够，因此可转成一个人物行动转折零件：

XN克ZX → 黎黎隆原来的即兴改道失效 → 她仍先尝试自己重设路线 → 失败 → 维护员提出城市既有检修通道 → 黎黎隆暂时不再重设方向，而沿维护员掌握的权限与节点推进 → NX关系功能成立。

这个零件保留黎黎隆“ZX主”的人物本体，只让某一任务段进入 NX 关系功能，避免把一次借力误写成角色整体变成 NX。

## 仍待验证的假设
XN克ZX并不自动生NX。当前只确认：XN克ZX可以制造“自主路径闭合失败”的条件；若随后出现符合 canonical 的外置方向/通道，才出现 NX 关系功能。二者之间的生克补关系尚未确认。
