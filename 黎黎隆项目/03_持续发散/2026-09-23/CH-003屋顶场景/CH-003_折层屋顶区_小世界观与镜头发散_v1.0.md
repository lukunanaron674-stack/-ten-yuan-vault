# CH-003｜折层屋顶区小世界观与镜头发散

> 本页是角色场景探索，不是正式世界观冻结。地点暂名“折层屋顶区”；魔法塔缺位与城市设施的因果仍待确认。

## 小世界观种子

### 地点

一片沿高低屋脊生长的城区。住屋、公共桥廊和维修水道叠在不同高度，屋顶不是纯粹的建筑顶面，而是居民穿行、收集雨水、晾晒和临时停留的日常层。

### 空间层次

1. **屋脊生活层**：倾斜屋面、雨槽、窄踏板、小平台；居民可从屋顶间穿行。
2. **公共桥廊层**：登记过的魔法服务与公共通行路线沿高架桥连接塔楼，桥梁高度和方向并不统一。
3. **维修水道层**：屋檐内侧的覆盖水渠、检修口和接口，把雨水、维护和城市魔法服务接在一起。
4. **缺位远景层**：城区某处有不自然的空白，桥路在附近断续或绕行。它是否与失踪魔法塔有关，只是当前视觉假设。

### 日常规则候选

- 常规魔法服务从登记节点进入，使用成本由城市系统管理；具体收费方式不在本轮定稿。
- 维修通道服务于维护，不等同于公共入口。角色可能观察到未登记的边缘路径，但每次使用都可能留下痕迹、造成设施暂时失灵或引来维护者注意。
- 雨水沿屋顶水槽流进覆盖水道；细小的青绿接口信号表示设施有反应，不直接解释它是否认出帽子。
- 猫暂时作为陪伴角色与构图锚点。它是否能辨路、是否有特殊能力，待后续确认。

### 角色在此地的场景功能

CH-003不是站在城市前摆造型，而是观察城市没有覆盖到的使用路径：停在屋脊、寻找桥廊落点、试探维修口、记录失败路线，再决定要不要继续。活体帽子的动作可以参与观察，但它是否保存老师或魔法塔的信息仍未确认。

## 视觉吸收规则

- 以大块平涂建立屋顶、人物、猫和桥廊；叠加轻水彩晕染、纸感和少量干刷，不用密集细节填满画面。
- 近景保留深墨青剪影和少数清楚边线；中景减少结构线；远景以淡青灰水彩块、断续轮廓和雾气淡出。
- 通过屋面斜线、不同高度的桥、桥拱间隙和水道开口建立空间趣味；不要只堆一排尖塔。
- 人物和猫是小比例、可读的剪影；色彩与环境共享 P00 五色，避免用统一滤镜替代真正的接触、遮挡与空间关系。
- P00：`#142A34` 深墨青、`#855D8F` 灰紫、`#913840` 暗红、`#69D4CE` 青绿、`#CDE7E6` 淡青灰。色卡只作颜色集合与功能参考，不把颜色直接等同十元关系。

## 生长链候选

`屋顶雨槽与维修口 → 未登记的边缘通道 → 学徒观察并试探 → 设施留下短暂响应或故障痕迹 → 城市维护者发现异常 → 学徒必须在继续找线索与保护通道之间选择 → 从屋脊远景切入、桥下跟拍、最后落到帽羽与水流近景`
