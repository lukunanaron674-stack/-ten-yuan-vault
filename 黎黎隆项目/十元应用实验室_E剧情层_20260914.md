# 《黎黎隆》十元应用实验室｜E 剧情层增量

> 本文件为 2026-09-14 的项目应用增量记录。只验证十元是否真实改变剧情事件结构，不修改、不覆盖 L1/L2 canonical、十元信息卡、准度卡、生克补正本或动态链正本。

## 本轮应用层

E｜剧情

## 当前真实问题

当前主树已经连续形成四个项目级结构：

1. 黎黎隆的“夺路尾”：`zx8 + xn3` 使他先留下最小锚序，再把个人方向压成队伍真实可走的新路；
2. 黎黎隆 × 塔汀“回路锁”：黎黎隆决定往前，塔汀维护被放弃旧路的对象特异回返接口，并只在回返接口即将被永久切断时产生有效拒绝；
3. “归巢拟态奇美拉”：不先毁路，而是复制公共接口壳，使队伍把错误对象持续当成自己的后路；
4. “返身断点文明”：高风险身体改造必须把公共可调用性与对象特异返身资格拆开，越接近不可逆改造，越必须保留不能被公共标准替代的返身位。

但这些目前仍主要是角色、关系、怪物和文明结构；主树缺少一个**只能由这些结构共同推出、且真正改变人物选择与代价的剧情事件**。

本轮只处理一个问题：

> **当黎黎隆必须把“用于回来”的身体结构本身改造成“用于继续往前”的器官时，剧情怎样不退化成普通的“任务重要还是回家重要”二选一？**

## 必要 Semantic IR

```yaml
actors:
  - 黎黎隆: zx8 + xn3
  - 塔汀: nz8 + nx6 + x3
object: 黎黎隆当前身体中同时承担“返身断点”与“下一阶段通行器官基底”的同一组身体结构
object_layer: plot_event / body_rewrite / decision_right_vs_reentry_right
current_window: 队伍抵达一处现身体无法通过的边境，到黎黎隆完成跨越或放弃跨越
changed_variable:
  - 黎黎隆能否继续把新方向现实化
  - 原身体状态的对象特异返身资格是否仍存在
  - 前进决定权与回返权是否仍由同一主体同时持有
  - 塔汀能否在不夺取前进方向的前提下真实保存回返资格
relation_shape: 为获得新路，黎黎隆必须把自身一个真实返身断点改造成任务器官；因此“继续前进”和“保留原身回返资格”不能再由同一结构同时承载，必须发生权利与实体锚的拆分
path_set:
  - P0: 当前可返回的身体/路线状态
  - P1: 通过再次夺路后形成的新区域
  - B0: 黎黎隆原本的对象特异返身断点
  - B1: B0 被改写后形成的任务器官/通行结构
  - R_tatin: 塔汀接管并维护的对象特异回返接口
  - R_public: 门站、标准接口、常规维护系统可识别的公共返程壳
decision_right:
  lili: 保留是否进入 P1、如何现实化 P1 的最终方向决定权
  tatin: 不决定 P1，但在 B0 被直接消耗前可拒绝“无交接切断”，要求先完成对象特异返身权的转移或明确放弃
reentry_right:
  before_event: 黎黎隆自身通过 B0 同时持有
  during_event: 从黎黎隆身体中拆出，由塔汀维护在 R_tatin
  after_event: 黎黎隆不能凭公共接口单方面恢复；必须重新与 R_tatin 建立真实对象关系，或明确让原返身资格终止
reality_anchor:
  - 从黎黎隆身上实际拆下/留下的返身结构，而非抽象数据备份
  - 塔汀持续维护的活体/组织/感觉基线接口
  - B0 改写为 B1 后不可同时承担原回返功能的实体证据
  - 进入 P1 后门站仍能识别黎黎隆，但这不等于其原身体已可返身
```

### 十元只读依据

- `zx`：关键不是“冲动”，而是主体自己的方向与权能真实扩大为环境/他者必须重新反应的运行方向；
- `xn`：黎黎隆只有 xn3，所以只保留最小必要锚序，不能突然变成全程流程规划者；
- `nz`：塔汀维护的是对象特异、可验证的回返/修复位置，不是“温柔照顾”；
- `nx`：塔汀不能偷走最终方向，只能在真实外部接口上让某条推进/切断失效；
- `x并z` 与返身断点文明只作为现有项目结构输入：公共壳可以继续让文明识别和调用一个身体，但这不能替代对象特异返身关系。

动态链只采用“对象层—主体—阶段—端点—唯一核心变量—条件—失败边”的分析方式，不把本项目案例反写成理论定义。

## 三个候选

### 候选 A｜“前方有人等救，回去就来不及”

边境即将坍塌，黎黎隆必须决定继续前进救人，还是和塔汀撤退。

**nearest-neighbor：** 与任何冒险片中的“任务 vs 安全”时间压力完全相邻。

**removal：** 删掉 `zx/nz/nx` 与返身断点后，只要保留倒计时和被困者，剧情仍几乎原样成立。

**结论：`TENYUAN_DECORATIVE_ONLY`。拒绝。**

---

### 候选 B｜“身体强化后可能变不回来”

为了打赢强敌，黎黎隆接受一次高风险强化；塔汀担心他失去原来的身体。

**nearest-neighbor：** 与“变身有副作用 / 使用力量会失去人性 / 强化不可逆”高度重合。

**reverse：** 如果把塔汀和回返接口全部删除，只保留“强化不可逆”，剧情照样完整；说明冲突主要来自力量副作用，不来自十元结构。

**counterexample：** 任意魔法暴走、药物强化、机甲超载都能自然产生同样故事。

**结论：`TENYUAN_DECORATIVE_ONLY`。拒绝。**

---

### 候选 C｜“返身权转交”：为了继续夺路，黎黎隆必须先把“回来”从自己身上交出去

边境出现一种只有重新组织身体才能通过的环境。关键不在于“加一个新器官”，而在于：新任务器官 B1 必须占用黎黎隆当前的返身断点 B0。B0 一旦被改写，他的身体仍可能被文明标准接口识别、维护甚至继续装备，但**原来的对象特异返身资格不再由他本人身体直接持有**。

塔汀因此不是劝他“别去”。她的 `nx6` 只在 B0 将被直接切断的接口瞬间发生作用：她能让“直接把 B0 改成 B1”这一步失败，迫使黎黎隆先完成两种动作之一：

1. 明确放弃原返身资格；
2. 把 B0 中仍可维持的对象特异回返部分实际拆出并交接给塔汀，由她建立 R_tatin。

黎黎隆选择第二种。

于是事件第一次把两个权利彻底拆开：

- **黎黎隆仍保留前进决定权。** 他进入 P1 后，可以继续夺路，塔汀不能远程命令他回来；
- **塔汀持有的是回返接口，不是他的方向。** 她必须持续维护 R_tatin，使“原来的黎黎隆身体状态”仍有一个真实可回接位置；
- **黎黎隆失去单方面返回的能力。** 他即使找到文明门站、公共接口、标准维护床，也只能证明“这个身体仍能被文明调用”，不能证明“他已经回到自己”；
- **时间压力改变。** R_tatin 不是无限存档。随着塔汀维持的活体结构衰减，旧返身资格存在明确窗口；黎黎隆每继续夺出一段新路，都在消耗一个最终不能由他自己控制的回返期限。

事件因此形成一个可反复进入剧情的结构，而不是一次性的悲壮按钮：

```text
B0 仍在黎黎隆身上
→ 边境要求 B0 改写为 B1
→ 塔汀 nx 在“无交接切断”处阻断
→ 黎黎隆主动把返身部分交给塔汀，形成 R_tatin
→ B0 → B1，黎黎隆夺出 P1
→ 决定权仍在黎黎隆，回返权已不在他手里
→ 每推进一段，R_tatin 窗口继续衰减
→ 最终必须选择：在窗口关闭前返回并重新接回，或继续前进并让旧返身资格真实终止
```

这不是“塔汀拿着他的备份”。若只是数据、身份钥匙或标准化器官样本，归巢拟态奇美拉与 `x并z` 公共壳问题仍可污染它；R_tatin 必须保留只有黎黎隆这具身体与塔汀持续维护关系共同产生的对象特异证据。

### 检查

**nearest-neighbor：**
- 不是“同伴保管复活点”，因为公共复活/备份不够；
- 不是“人质”，因为塔汀不能以回返权替代黎黎隆的前进决定权；
- 不是“不可逆强化”，因为事件的核心变量不是力量代价，而是 decision_right 与 reentry_right 被迫拆开并由不同主体承载。

**removal：**
删掉十元结构后，最自然的剧情会退化成“危险变身，朋友替他保管旧身体样本”。它不再必然要求：
- 塔汀只能阻止无交接切断、不能阻止黎黎隆选择 P1；
- 黎黎隆能继续前进却不能单方面返回；
- 公共接口仍识别他，但不能替代对象特异返身；
- 回返资格具有独立于前进方向的现实期限。

因此删掉十元后事件不能原样成立。

**reverse：**
- 若 B0 不必被改写即可进入 P1，则返身权无需转交，整个事件应消失；
- 若塔汀同时获得 P1 最终方向决定权，则她从 nx/nz 滑成第二个 zx，结构判失败；
- 若黎黎隆可通过任意公共门站无条件恢复 B0，则“返身断点文明”失效，结构判失败；
- 若 R_tatin 被毁但黎黎隆仍能原样返回，则说明此前所谓对象特异返身锚只是装饰，结构判失败。

**counterexample：**
一个纯粹勇敢的队长、一个善良医生、一个普通存档系统或一个“强化会掉血”的世界，都不能自然推出“前进决定权保留在本人，但对象特异回返权被实体转交给另一个只拥有接口拒绝权的人”这条链。

**结论：通过。**

## 最终保留｜返身权转交事件 v0.1

### 一句话

> **黎黎隆为了把下一条路变成现实，必须先把“还能回到原来身体的权利”从自己身上拆下来交给塔汀；从此他决定往哪走，却不再独自决定自己还能不能回来。**

### 它给《黎黎隆》增加了什么原本没有的东西

1. **剧情选择从普通二选一变成“权利拆分”**：前进与回返不再是同一角色手里的两个按钮，而被拆成不同主体、不同实体锚、不同失效条件。
2. **身体改造第一次直接产生剧情权力关系**：身体不是换皮装备；改哪一段，会改变谁掌握哪种现实能力。
3. **塔汀的存在变成结构必要**：她不是劝阻者或奶妈，而是唯一维护对象特异返身窗口的人；但她仍无法替黎黎隆决定方向。
4. **返身断点文明获得剧情验证**：文明公共设施可以继续服务黎黎隆，却无法替他把旧身体关系恢复回来，从而把世界史变成当下事件的真实约束。
5. **归巢拟态奇美拉获得后续剧情入口**：怪物若攻击 R_tatin，不是在“偷备份”，而是在攻击黎黎隆唯一仍存在的旧返身资格。
6. **阶段转移明确**：事件前，黎黎隆同时持有前进与回返；事件后，他保留 zx 的方向权，却进入“回返权外置”的新人生阶段。后续任何继续深入都带着这一结构债务。

### 删掉十元测试

结果：**PASS**。

删掉 `zx/nx/nz/x并z` 的结构约束后，可以保留“高风险身体改造”这个题材，但不能保留本事件的核心：

`为了现实化新方向 → 必须占用返身断点 → nx 只阻止无交接切断 → reentry_right 从本人身体转交给塔汀 → decision_right 仍留在黎黎隆 → 文明公共壳仍能调用他但不能让他原样返身 → 继续推进会独立消耗回返窗口`。

十元因此改变了事件因果、选择权分布、身体代价、阶段转移和后续剧情债务，而不是事后给“牺牲”贴标签。
