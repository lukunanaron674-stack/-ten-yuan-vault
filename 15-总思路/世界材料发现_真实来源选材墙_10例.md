# 世界材料发现墙｜真实来源10例（先找材料，再选材构成）

**用户2026-11-17校准：主要任务不是预先给某个故事的组织打世界体量分，而是向外找大量真实材料并按可视化卡片陈列，让作者挑选、组合，再决定要构成何种世界、十元与故事。**

## 一｜正确顺序

```
开放发现：公共史料 / 文献 / 机构制度 / 建筑图册 / 工艺 / 职业 / 行为 / 影视 / 科学
  ↓
逐条核源：事实是什么？物证在哪？年份、地域、来源和版权什么状态？
  ↓
材料卡片化：缩略图 / 一句话事实 / 可拆机制 / 关键词 / 点击原资料
  ↓
可视化筛选：按内容类型 / 来源 / 机制 / 时空 / 用途选入“构成篮”
  ↓
作者选材与组合：保留材料 ID、出处及所选理由
  ↓
构成阶段：仅在选材后建立世界关系和G/W候选，再研究十元动态链
```

**禁止倒序**：不能先锁《时间信封》剧情再找十元材料证明；不能把“采集30条”充作“30个真实外部发现”；不能把外部世界全部当作故事已经展开的世界。此前《时间信封》R1的30卡与R2的G240/290均是**旧的项目中心样本**，不再作为通用素材发现的第一入口，也不删除历史记录。

## 三｜作者看到的可视化材料卡应该长什么样

每卡只呈现：**(A) 图片/视频/地图/文档预览（无许可用图标和来源链接代替）→ (B) 来源标题与类型 → (C) 一句客观事实 → (D) 可拆机制候选 → (E) 原始资料入口 → (F) “选入构成篮”**。作者最开始无需看十元判断、G/W评分或AI写成的故事剧情。

选择完成后，系统导出 `selected_material_ids` 与来源清单，后续才会接十元与世界图；拒绝强迫用户每找到一个原料就填写作品名、体量数或人物动机。卡片还应保存来源日期、地域、时代、版权状态、去重键、可追溯原始媒体。

**图片和可读卡片**适合 Obsidian Bases / Gallery；**世界关系Canvas**只承载选中后形成的子图，不适合对数千条原始来源做总览。
