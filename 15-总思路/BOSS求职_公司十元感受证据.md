### AI 负责先提出十元映射/感受预测，不把所有分析推回给人

分析对象固定为：**求职者在具体时间阅读某家公司具体岗位材料，可能产生的感受**。AI须按十元全面比较，给出有证据的主元／次元／最近邻替代解释及反例与信赖度；可以给出明确的**候选结论**，但不得说成已经测得员工感受。

每家公司按顺序输出：

```yaml
stimulus: 公司 + 具体招聘材料 + 阅读场景 + 日期
observed: 直接材料事实 / 原网页 / Canvas source_id
ai_prediction:
  main: 候选十元或 UNKNOWN
  secondary: [候选十元]
  alternatives: [最近邻及排除理由]
  mechanism: 哪些材料特征可能诱发何种人的感受
  confidence: 0-100（仅表示证据强弱，非感受强度）
  counterexample: 能推翻这项预测的实际团队材料
human_report:
  observer: null
  feeling_profile_1_10: null
  top1: null
  top2_top3: null
```

**特别防错**：`岗位KPI ≠ Z感受已成立`；`导师制 ≠ NZ真实存在`；`团队协作 ≠ ZN喜悦已成立`；`L2诱发机制 ≠ L1感受核`。十元符号 `TENYUAN_XN` 与执行规则 `PROBLEM_XN` 必须分开。原JSON中旧的 `legacy_workstyle_tag` 是历史候选，不允许作为独立证据。

**当前状态**：本轮已完成GitHub十元正本/AG-02的来源链接；44家公司下一步需要依据这些文件逐条做AI预测。真实人的十槽强度仍保留空值，不能把AI预测写到 `feeling_profile`。

## 十元及五轴

- 十元：X／Z／N／ZN／NZ／XN／NX／ZX／XZ／X并Z；每一元独立1—10，未由人评价时留空，**五对不是零和，允许两端同时高**。
- 五轴：**木 ZX↔NX；火 ZN↔X；土 N↔X并Z；金 XN↔Z；水 XZ↔NZ**。
- 当前招聘材料区分三个层次：①有文字/材料证明的岗位条件；②哪些五轴值得向真实员工验证；③人类感受结果（目前空缺）。
- 不能把「Z=绩效/规则」「ZN=多人一起工作」「NZ=有导师」当十元体验定义。规则分布与向外张开的对照属于候选感受诱发语法，不等于直接给企业贴标签。
