# 十元核心定义

> 本页是给 Codex、DeepSeek、Qwen 使用的统一召回页。它整理现行来源，不自行升级为新的 L2 正本；遇到来源冲突必须保留冲突并标明版本。

## 1｜十元集合

机器使用以下十个 token，大小写只做输入归一化；语义不能因大小写改变：

```text
x / z / n / zn / nz / xn / nx / zx / xz / x并z
```

## 2｜稳定定义总表

| 十元    | 同行相反端 | 当前稳定召回                         | 不得偷换为           |
| ----- | ----- | ------------------------------ | --------------- |
| `zx`  | `nx`  | 主体权能公开显现、扩大，并凌驾于他者之上；自身占据方向源   | 只是强势、中心人物或大动作   |
| `nx`  | `zx`  | 主体让出最终方向决定权，沿既有路线、关系、权限或通道续接   | 被动、弱势或单次服从      |
| `zn`  | `x`   | 保留自己与他者的独立意义、选择和成立资格           | 善良、理想或表达观点      |
| `x`   | `zn`  | 对象、资源、地盘、权限或关系进入“归我／我方掌握”的边界   | 反派、贪婪、黑暗或控制欲    |
| `n`   | `x并z` | 让对象真实进入内部并持续承担其负荷，承载而不吞并       | 房屋、厚重、容器或同框     |
| `x并z` | `n`   | 把内部对象映射成外部可识别、调用、代表或进入的公共壳     | 爆炸、扩散、漂亮外壳或文字标签 |
| `xn`  | `z`   | 把重心分布进顺序、规则、记录和流程，使其持续运行       | 任何秩序感、时间经过或截止日期 |
| `z`   | `xn`  | 把一个对象提升为最高中心，其他对象退出中心判断        | 构图中心、景深焦点或被看见   |
| `xz`  | `nz`  | 终点先在前方形成，过程不断逼近；选择、退路与可能路径持续收窄 | 普通危险、爆炸题材或追逐    |
| `nz`  | `xz`  | 为特定对象保存、恢复或重开可返回、可停靠、可继续连接的路径  | 泛亲密、温柔、拥抱或一般承载  |

对应现行总表：[[01-十元系统/十元体系密度卡总览]]。详细必要条件、最近邻、拿掉测试和反向测试必须回读对应信息卡与准度卡，不能只依赖本表。

## 3｜十元与五行的固定关系

```text
木＝zx ↔ nx
火＝zn ↔ x
土＝n ↔ x并z
金＝xn ↔ z
水＝xz ↔ nz
```

这是同行阴阳两端的对立统一，不是把两个十元临时相加，也不是一条已经发生的生克补关系。L1 正本：[[01-十元系统/05-十元语义空间/L1_十元即阴阳五行相反轴正本_v1.6]]。

## 4｜必须保留的版本差异

### 4.1 xz：主本体与危险显影口径不能偷合

当前 `xz` 信息卡 v2.2（2026-09-01）把以下结构列为主本体：

```text
终点前置
→ 未来规定当前方向
→ 路径 / 选择持续收窄
→ 多条路径向终点汇流
```

视觉审核与旧准度材料仍保留临界危险口径。本协议原样保留用户要求的约束句：

```text
XZ＝易燃易爆炸／高反应性／高危险性／低阈值
```

在结构字段中，它对应“整体危险蓄积、低阈值触发、远大于输入尺度的系统性反应”的危险显影候选；它不能仅由“火、爆炸、危险、黑红”等词或题材触发。

机器状态：

```yaml
xz:
  current_main_source: 01-十元系统/【xz信息量卡v2】.md
  current_main_shape: 终点前置与路径收窄
  retained_user_hazard_phrase: 易燃易爆炸／高反应性／高危险性／低阈值
  retained_hazard_role: danger_or_visual_manifestation_candidate
  semantic_resolution: unresolved_between_main_and_hazard_wording
```

在冲突未经用户或新 L2 正本解决前，输出必须写清 `xz_main` 或 `xz_hazard_manifestation`，不得把两者压成一个无条件等价定义。

### 4.2 x 的语义层与 Style Grammar 层分开

语义层的 `x` 是“归我掌握”。最新视觉 Style Grammar（2026-09-16）冻结的是静态造型边界：

```text
独立形体单元
+ 清晰边界
+ 单元自足
+ 彼此不融合
+ 留有间隔
```

该 X 风格边界状态为 `FROZEN`，后续只做低频跨题材回归。它不等于几何、机能、冷酷、黑白、尖角或科技题材，也不能反向重写语义层 `x`。视觉窄义卡中的 `x＝刀`只在其视觉子域内调用，不能替代语义层定义。

来源：[[01-十元系统/06-视觉化研发/十元角色设计StyleGrammar_研究总整理_20260916]]、[[01-十元系统/06-视觉化研发/RELEASE_视觉化体系_v0.8.1_20260916]]、[[01-十元系统/03-十元准度卡/x_视觉狭义卡_v0.1]]。

## 5｜层级纪律

```text
十元操作端
→ 五行对立统一体 / 五轴
→ 领域狭义显化 / 五维主题
→ 具体案例的对象、状态、行为、场域或视觉显影
```

- 具体对象的十元判定，必须回到主体、对象、权利、路径、边界和时间窗口。
- 五轴是结构层；五维是主题／叙事层；任何一层都不能直接替代十元证据。
- 配比度、本征映射准度、体量、纯度和证据置信度必须分字段保存。
