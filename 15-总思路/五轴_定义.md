# 五轴定义

> 五轴 V1.0 是五行在十元体系中的结构化表达。它已进入 `FROZEN_REGRESSION_ONLY`：后续主要做真实案例回归，不以五行名称重新发明十元。

## 1｜先分清五维与五轴

```text
五维＝主题／叙事层：因果、本体、空间、时间、命运
五轴＝十元 × 五行深化的结构层：五个同行阴阳十元对立统一体
```

五维可以视为五轴进入主题／叙事领域后的狭义显化，但两者不能互相覆盖：

- 不能用“因果、命运、时间”等主题词直接判十元；
- 不能用五轴名称替代 actor、object、changed_variable、权利与路径证据；
- 不能因传统五行存在相生相克，就宣布具体案例已经发生生克。

## 2｜五轴总表

| 五轴 | 十元两极 | 轴的核心变量 | 五维叙事显化 |
|---|---|---|---|
| 木轴 | `zx ↔ nx` | 最终方向与作用权来源：自身生成并占据方向 ↔ 不占最终方向、沿既有通道续接 | 因果 |
| 火轴 | `zn ↔ x` | 对象独立成立资格与归属方式：保留自身成立 ↔ 纳入掌握、调用与处分边界 | 本体 |
| 土轴 | `n ↔ x并z` | 对象跨越内外边界的方向：外→内纳入承载 ↔ 内→外映射外化 | 空间 |
| 金轴 | `xn ↔ z` | 运行权与裁定重心配置：分布到规则节点流程 ↔ 收束到单一最高裁定点 | 时间 |
| 水轴 | `xz ↔ nz` | 可逆性与对象特异回返空间：持续收窄 ↔ 保存、恢复或重建 | 命运 |

固定映射：

```text
木＝zx ↔ nx
火＝zn ↔ x
土＝n ↔ x并z
金＝xn ↔ z
水＝xz ↔ nz
```

十元是五轴内部的阴阳操作端；五轴不是第三个临时十元，也不是生克补关系。

## 3｜五轴相生

结构顺序固定为：

```text
木 → 火 → 土 → 金 → 水 → 木
```

已有结构桥：

| 相生 | 结构桥 |
|---|---|
| 木生火 | 方向／作用来源被确定，为对象成立资格与归属边界提供锚点 |
| 火生土 | 本体成立与归属边界生成“内／外”边界 |
| 土生金 | 内外跨越形成入口、出口、接口和承载等可执行节点 |
| 金生水 | 规则、流程与裁定写入路径和回返权，决定继续、终止或重开 |
| 水生木 | 可达／回返空间定义下一轮真实可用方向集合 |

五轴层的“生”是**结构条件生成**：A 轴的有效变化建立、激活或重写 B 轴成立所需的条件。它不等于每个 A 案例都会自动出现 B。

## 4｜五轴相克

结构顺序固定为：

```text
木克土
土克水
水克火
火克金
金克木
```

已有结构桥：

| 相克 | 结构桥 |
|---|---|
| 木克土 | 定向作用穿透、绕过或重写既有内外边界，压缩土轴可成立状态空间 |
| 土克水 | 内外边界、入口与出口限制 `return_path / reentry_right` |
| 水克火 | 可逆与回返空间限制对象身份、成立资格和归属状态的可恢复集合 |
| 火克金 | 成立资格与归属先限定哪些主体／节点有资格进入运行与裁定链 |
| 金克木 | 运行权与裁定权授权或否决行动方向，压缩方向与作用权来源的状态空间 |

五轴层的“克”是**合法状态空间约束**：A 轴直接压缩、否决或重写 B 轴可成立的状态／迁移空间。它不等于情绪冲突、谁赢谁输或题材对立。

## 5｜具体案例最低证据

判定某个案例显影某轴，至少保存：

```yaml
axis_case:
  actor:
  object:
  object_layer:
  current_window:
  changed_variable:
  relation_shape:
  decision_right:
  path_set: []
  reentry_right:
  future_endpoint:
  reality_anchor:
  ten_yuan_primary:
  ten_yuan_secondary:
```

若一句话含两条独立因果箭头、不同对象层或不同权利主体，标记 `SPLIT_IR`，不能用一个五轴标签掩盖分层。

## 6｜五轴的冻结与重开

当前状态：

```text
单轴核心定义        → 已收束
十元固定映射        → 已固定
跨轴相生            → 5/5 结构验证
跨轴相克            → 5/5 结构验证
维护模式            → regression-only
```

只有出现以下 failure 才重开对应轴：

- 现有核心变量无法解释的新机制；
- 现有 guard 无法区分的稳定新边界；
- 重复出现且不能归入已有错误族的新 failure family；
- 真实案例中跨轴生克出现系统性反例；
- 解释器与五轴判定发生无法消解的结构冲突。

否则使用 `CLOSED_BY_EXISTING_GUARD`，不新增定义、不新增理论卡、不修改 canonical。
