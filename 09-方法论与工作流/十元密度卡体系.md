# 十元密度卡体系 v1

> **十元不是标签，十元是信息密度。信息量越分层，AI越能理解；信息量越乱堆，AI越会误判。**

---

## 核心理念

给每个符号建立一套**从本体到视觉、空间、叙事、动态链、误判防线的信息量结构**，让 AI 从"背词典"升级成"懂语义力场"。

### 为什么有用

现在很多 AI 对十元理解浅，是因为它只看到词典级信息量：

```text
xz = 危险 / 漂流 / 临界
nz = 柔情 / 停靠 / 依恋
xn = 规则 / 时间 / 制度
```

但给它完整的信息量包后：

```text
xz：
本体：危险感知、临界行动、来不及
行为：快速反应、逃离、冒险、靠近风险
空间：边缘、断桥、渡口、雨夜街口、逃生路径
视觉：切线、逆光、冷色、硬边、闪断
叙事：遭遇、追逐、错过、命运推送
动态：xz容易切断n，也容易寻找nz停靠
误判：不要等同恐怖、废墟、怪物、黑暗
```

AI 立刻就不只是知道"xz是什么"，而是知道**xz怎么动、在哪里成立、长什么样、会把故事推向哪里、最容易被误判成什么**。

### 关键坑：信息要分层，不能乱堆

❌ 错误做法——所有信息塞成一团：

```text
xz = 危险、命运、漂流、雨、风、刀、猎人、逃跑、恐怖、黑暗、废墟、怪物、海、船、边境……
```

→ AI 会把 xz 理解成"啥都黑一点"，又开始乱判。

✅ 正确做法——**主骨约束**：

```text
xz主骨 = 临界行动 + 风险路径 + 来不及
```

所有信息围绕主骨长出来，像骨架长肌肉，不是菜市场装袋。

## 符号信息量等级（1-10 级）

### 1-3 级：词典层
适合快速召回。AI 能大概懂，但容易乱套。

```text
xz = 危险、漂流、临界、来不及
```

### 4-6 级：应用层
适合分析角色、场景、故事。AI 开始能稳定分析。

```text
xz：
人物：敏感、警觉、风险反应快
空间：危险边缘、逃离路径、临界通道
视觉：冷光、切线、速度感、突变
叙事：遭遇、逃离、错过、命运推动
```

### 7-8 级：创作层
适合生图、写故事、设计角色。AI 可以帮你生成更准的内容。

```text
xz角色：
不是单纯黑暗，而是"被风险推着行动的人"。
他身上要有路径感、逃离感、未抵达感、临界感。
衣服可以有切割边、斜向结构、轻装、风损、雨痕、局部破损。
武器不一定恐怖，而是快速、危险、短促、可撤离。
```

### 9-10 级：动态链层
适合高级分析和自动化 F12。AI 能跑动态链，不只是贴标签。

```text
xz：
常见链：
xz → nz：漂流寻找停靠
xz → n：危险进入承载结构
xz → x：危险被欲望污染，变成占有/猎杀
xz → xn：临界行动被规则捕获
xz + nz = 命运主题

误判防线：
1. 黑暗感不等于xz
2. 恐怖怪物不等于xz
3. 废墟不等于xz
4. 真正xz必须有"临界路径 / 风险行动 / 来不及"
```

## 密度卡标准格式

每个符号做成统一格式的信息量卡。以 xz 为例：

```text
【xz 信息量卡 v1】

1. 核心本体（主骨）
危险感知、临界行动、来不及、风险漂流。

2. 第一体感
不是恐怖，而是"再慢一步就错过 / 被吞掉 / 出不去"。

3. 人物层
敏感、警觉、反应快、靠近危险、无法稳定停留。

4. 行为层
逃离、追逐、冒险、横穿、抢先行动、临界选择。

5. 空间层
渡口、断桥、边境、逃生通道、雨夜街口、列车站台、临界门洞。

6. 视觉层
冷色、逆光、硬边、切线、速度感、风、雨、水汽、断裂边缘。

7. 叙事层
遭遇、错过、被迫继续、无法停靠、命运推送。

8. 常见互补
xz + nz = 命运，危险漂流 + 柔情停靠。

9. 常见污染
xz 被 x 污染 = 从危险漂流变成欲望猎杀。

10. 禁止误判
黑暗 ≠ xz
废墟 ≠ xz
怪物 ≠ xz
恐怖 ≠ xz
必须有"临界行动感"才是xz。
```

## 三版本体系

| 版本 | 用途 | 信息量级 |
|------|------|---------|
| 召回版 | 让 AI 快速记住 | 3 |
| 分析版 | 作品分析、角色判断 | 6 |
| 创作版 | 生图、故事、设定、动态链 | 9 |

### 召回版（3 级用）
一句话定义 + 主骨 + 第一体感

### 分析版（6 级用）
核心本体 + 人物层 + 行为层 + 空间层 + 视觉层 + 叙事层

### 创作版（9 级用）
全套 10 层信息量卡，包含动态链、误判防线、常见互补/污染
