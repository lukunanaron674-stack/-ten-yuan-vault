# 十元密度卡体系 v1.1

> **十元不是标签，十元是信息密度。骨架先定，血肉再长，动态链定生命，案例回填定成长。**

---

## 0. 文件定位

本文件用于封存「十元密度卡」的总体系。

核心用途：

- 给每个十元建立长期信息量仓。
- 区分主骨、血肉、动态链、误判反例。
- 让影视、动画、漫画、音乐、游戏、视觉案例的分析结果可以回填到具体十元卡。
- 防止 AI 只背词典，不会判断体量、语义场和动态功能。

一句话：

> 十元不是标签，十元是信息密度。信息量越分层，AI 越能理解；信息量越乱堆，AI 越会误判。

---

## 1. 核心理念

### 1.1 主骨不可乱改

每个十元必须先有一个「主骨」。

主骨回答：

```text
这个十元最底层到底是什么？
它不是什么？
它和相邻十元如何区分？
```

主骨不是词典词堆，而是判断方向。所有血肉都必须围绕主骨生长。

### 1.2 血肉可以疯狂生长

主骨锁定后，可以通过大量作品、角色、场景、音乐、图像去补血肉。

血肉包括：

- 人物血肉
- 行为血肉
- 空间血肉
- 视觉血肉
- 声音 / 音乐血肉
- 叙事血肉
- 动态链血肉
- 误判反例
- 创作模板

### 1.3 判断不按词，按体量、语义场、动态功能

同一个词可能带多个十元。

例如：

```text
黑暗：常主判 x，但可带 xz
废墟：常在 xn / n 崩后的语义场下，可生出 xz
怪物：通常就是 xz，当它是“危险显身 / 异质逼近”时
恐怖：通常就是 xz，当它不是纯氛围渗透，而是逼近的可感知危险时
```

不能写死成「A ≠ B」。要看主导体量、语义场和动态功能。

## 2. 符号信息量等级（1-10 级）

### 1-3 级：词典层

适合快速召回。AI 能大概懂，但容易乱套。

```text
xz = 危险 / 漂流 / 临界 / 来不及
nz = 柔情 / 停靠 / 依恋 / 不想结束
xn = 规则 / 时间 / 制度 / 秩序框架
```

### 4-6 级：应用层

适合分析角色、场景、故事。AI 开始能稳定分析。

```text
xz：
人物：敏感、警觉、反应快
行为：逃离、追逐、冒险、临界选择
空间：危险边缘、逃离路径、临界通道
视觉：冷光、切线、速度感、突变
叙事：遭遇、逃离、错过、命运推动
```

### 7-8 级：创作层

适合生图、写故事、设计角色、音乐和世界观。AI 可以从结构生成内容。

```text
xz角色：
不是单纯黑暗，而是“被风险推着行动的人”。
身上要有路径感、逃离感、未抵达感、临界感。
衣服可以有切割边、斜向结构、轻装、风损、雨痕、局部破损。
武器不一定恐怖，而是快速、危险、短促、可撤离。
```

### 9-10 级：动态链层

适合高级分析和自动化 F12。AI 能跑动态链，不只是贴标签。

```text
xz：
常见链：
xz → nz：漂流寻找停靠
xz → n：危险进入承载结构
xz → x：危险被欲望污染，变成占有/猎杀
xz → xn：临界行动被规则捕获
xz + nz = 命运主题

误判防线：
1. 黑暗感不自动等于 xz
2. 废墟不自动等于 xz
3. 怪物 / 恐怖通常可进入 xz，但必须满足“危险显身 / 异质逼近 / 临界行动”
4. 真正 xz 必须有“边界不确定性 / 风险路径 / 逼近感 / 来不及”
```

## 3. 十元密度卡的 10 层结构

每张密度卡建议固定包含以下 10 层。

```text
0. 主骨
1. 本体密度
2. 人物血肉
3. 行为血肉
4. 空间血肉
5. 视觉血肉
6. 声音 / 音乐血肉
7. 叙事血肉
8. 常见关系牙印 / 动态链
9. 误判反例 / 体量校验
10. 案例回填记录 / 可偷走模板
```

## 4. 密度卡标准格式

每个符号做成统一格式的信息量卡。

```text
【符号 信息量卡 v1】

0. 元数据
symbol / element / theme / version / status / source

1. 核心本体（主骨）
一句主骨公式 + 不是什么 + 和相邻符号的边界

2. 第一体感
这个十元最先打到身体上的感觉

3. 人物层
角色类型、灵魂问题、错误标签

4. 行为层
这个十元如何行动、如何停、如何转向

5. 空间层
它在哪里成立，哪些空间会天然生成它

6. 视觉层
颜色、光线、构图、材质、形状、运动感

6.5 声音 / 音乐层
音色、节奏、和声、落点、能量曲线

7. 叙事层
它在故事中推动什么、阻断什么、回收什么

8. 常见关系牙印 / 动态链
和其他十元组合后生成什么主题、冲突、转导

9. 误判反例 / 体量校验
哪些词看起来像它但不是它，如何用体量校验

10. 案例回填记录 / 可偷走模板
作品案例、补了哪层血肉、是否可复用
```

## 7. xz 修正封存

### 7.1 旧误区

把 xz 只写成：

```text
临界行动 + 风险路径 + 来不及
```

这个定义太窄，只覆盖了「人在危险中怎么动」，没有覆盖「危险本身显身」。

### 7.2 新主骨

```text
xz = 危险显身 + 异质逼近 + 恐怖遭遇 + 命运失稳
```

一句话：

> xz 是危险以可感知形态逼近。

### 7.3 行动型子骨

旧定义不删除，而是降级为 xz 的行动型子骨：

```text
xz_action = 临界行动 + 风险路径 + 来不及
```

用途：

- 分析逃亡、追逐、错过、站台、断桥、倒计时。
- 设计角色动态、场景路径、音乐不稳定节拍。
- 判断“被命运推到边界上行动”的状态。

### 7.4 x 与 xz 区分

```text
x  = 深处的吞没、欲望、占有、压迫源。
xz = 吞没显形后逼近你，成为怪物、恐怖、追杀、异质威胁。
```

### 7.5 误判修正

```text
黑暗不自动等于 xz，黑暗常主判 x。
废墟不自动等于 xz，废墟常是 xn / n 崩后的残留场。
怪物通常就是 xz，但前提是它承担“危险显身 / 异质逼近”。
恐怖通常就是 xz，但纯氛围渗透可偏 x。
```

## 8. 与血肉采矿方法论的关系

| 模块 | 关系 |
|---|---|
| 血肉采矿方法论 | 如何从作品中采肉 |
| 密度卡体系 | 采到的肉回填到哪里 |
| 三大产物库 | 最终积累成什么 |

**流程闭环：**

1. 血肉采矿：从作品提取素材。
2. 回填密度卡：素材进入对应符号的信息量包。
3. 密度卡反哺 F12：信息量越完整，分析越准。
