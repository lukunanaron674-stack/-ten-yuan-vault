# 十元密度卡体系

## 0. 文件定位

本文件用于封存「十元密度卡」的总体系。

核心用途：

- 给每个十元建立长期信息量仓。
- 区分主骨、血肉、动态链、误判反例。
- 让影视、动画、漫画、音乐、游戏、视觉案例的分析结果可以回填到具体十元卡。
- 防止 AI 只背词典，不会判断体量、语义场和动态功能。

一句话：

> 十元不是标签，十元是信息密度。骨架先定，血肉再长，最后回填成可复用的创作与分析能力。

---

## 1. 核心理念

### 1.1 主骨不可乱改

每个十元必须先有一个「主骨」。

主骨回答：

```text
这个十元最底层到底是什么？
它不是什么？
它和相邻十元如何区分？
```

例如：

```text
xz = 危险显身 + 异质逼近 + 恐怖遭遇 + 命运失稳
x = 深层欲望 / 吞没 / 占有 / 压迫源
n = 承载 / 安顿 / 持续 / 容器
```

### 1.2 血肉可以疯狂生长

主骨锁定后，可以通过大量作品、角色、场景、音乐、图像去补血肉。

血肉包括：

- 人物血肉
- 行为血肉
- 空间血肉
- 视觉血肉
- 声音 / 音乐血肉
- 叙事血肉
- 动态链血肉
- 误判反例
- 创作模板

### 1.3 判断不按词，按体量、语义场、动态功能

同一个词可能带多个十元。

例如：

```text
黑暗：常主判 x，但可带 xz
废墟：常在 xn / n崩后的语义场下，可生出 xz
怪物：通常就是 xz
恐怖：通常就是 xz
```

不能写死成「A ≠ B」，要看主导体量和动态功能。

## 2. 十元密度卡的 10 层结构

每张密度卡建议固定包含以下 10 层。

```text
0. 主骨
1. 本体密度
2. 人物血肉
3. 行为血肉
4. 空间血肉
5. 视觉血肉
6. 声音 / 音乐血肉
7. 叙事血肉
8. 常见关系牙印 / 动态链
9. 误判反例 / 体量校验
10. 案例回填记录 / 可偷走模板
```

## 5. xz 修正封存

### 5.1 旧误区

把 xz 写成：

```text
临界行动 + 风险路径 + 来不及
```

这个定义太窄，只覆盖了「人在危险中怎么动」，没有覆盖「危险本身显身」。

### 5.2 新主骨

```text
xz = 危险显身 + 异质逼近 + 恐怖遭遇 + 命运失稳
```

一句话：

> xz 是危险以可感知形态逼近。

### 5.3 x 与 xz 区分

```text
x  = 深处的吞没、欲望、占有、压迫源。
xz = 吞没显形后逼近你，成为怪物、恐怖、追杀、异质威胁。
```

### 5.4 误判修正

```text
黑暗不自动等于 xz，黑暗常主判 x。
废墟不自动等于 xz，废墟常是 xn / n 崩后的残留场。
怪物通常就是 xz。
恐怖通常就是 xz。
```


## 8. 封存句

> 主骨不是词典，血肉不是散词。主骨定方向，血肉定密度，动态链定生命，案例回填定成长。
