# 十元密度卡体系 v1

> **十元不是标签，十元是信息密度。信息量越分层，AI越能理解；信息量越乱堆，AI越会误判。**

---

## 核心理念

给每个符号建立一套**从本体到视觉、空间、叙事、动态链、误判防线的信息量结构**，让 AI 从"背词典"升级成"懂语义力场"。

### 为什么有用

现在很多 AI 对十元理解浅，是因为它只看到词典级信息量：

```text
xz = 危险 / 漂流 / 临界
nz = 柔情 / 停靠 / 依恋
xn = 规则 / 时间 / 制度
```

但给它完整的信息量包后：

```text
xz：
本体：危险感知、临界行动、来不及
行为：快速反应、逃离、冒险、靠近风险
空间：边缘、断桥、渡口、雨夜街口、逃生路径
视觉：切线、逆光、冷色、硬边、闪断
叙事：遭遇、追逐、错过、命运推送
动态：xz容易切断n，也容易寻找nz停靠
误判：不要等同恐怖、废墟、怪物、黑暗
```

AI 立刻就不只是知道"xz是什么"，而是知道**xz怎么动、在哪里成立、长什么样、会把故事推向哪里、最容易被误判成什么**。

### 关键坑：信息要分层，不能乱堆

❌ 错误做法——所有信息塞成一团：

```text
xz = 危险、命运、漂流、雨、风、刀、猎人、逃跑、恐怖、黑暗、废墟、怪物、海、船、边境……
```

→ AI 会把 xz 理解成"啥都黑一点"，又开始乱判。

✅ 正确做法——**主骨约束**：

```text
xz主骨 = 临界行动 + 风险路径 + 来不及
```

所有信息围绕主骨长出来，像骨架长肌肉，不是菜市场装袋。

## 符号信息量等级（1-10 级）

### 1-3 级：词典层
适合快速召回。AI 能大概懂，但容易乱套。

```text
xz = 危险、漂流、临界、来不及
```

### 4-6 级：应用层
适合分析角色、场景、故事。AI 开始能稳定分析。

```text
xz：
人物：敏感、警觉、风险反应快
空间：危险边缘、逃离路径、临界通道
视觉：冷光、切线、速度感、突变
叙事：遭遇、逃离、错过、命运推动
```

### 7-8 级：创作层
适合生图、写故事、设计角色。AI 可以帮你生成更准的内容。

```text
xz角色：
不是单纯黑暗，而是"被风险推着行动的人"。
他身上要有路径感、逃离感、未抵达感、临界感。
衣服可以有切割边、斜向结构、轻装、风损、雨痕、局部破损。
武器不一定恐怖，而是快速、危险、短促、可撤离。
```

### 9-10 级：动态链层
适合高级分析和自动化 F12。AI 能跑动态链，不只是贴标签。

```text
xz：
常见链：
xz → nz：漂流寻找停靠
xz → n：危险进入承载结构
xz → x：危险被欲望污染，变成占有/猎杀
xz → xn：临界行动被规则捕获
xz + nz = 命运主题

误判防线：
1. 黑暗感不等于xz
2. 恐怖怪物不等于xz
3. 废墟不等于xz
4. 真正xz必须有"临界路径 / 风险行动 / 来不及"

# 十元密度卡体系

## 0. 文件定位

本文件用于封存「十元密度卡」的总体系。

核心用途：

- 给每个十元建立长期信息量仓。
- 区分主骨、血肉、动态链、误判反例。
- 让影视、动画、漫画、音乐、游戏、视觉案例的分析结果可以回填到具体十元卡。
- 防止 AI 只背词典，不会判断体量、语义场和动态功能。

一句话：

> 十元不是标签，十元是信息密度。骨架先定，血肉再长，最后回填成可复用的创作与分析能力。

---

## 1. 核心理念

### 1.1 主骨不可乱改

每个十元必须先有一个「主骨」。

主骨回答：

```text
这个十元最底层到底是什么？
它不是什么？
它和相邻十元如何区分？
```

例如：

```text
xz = 危险显身 + 异质逼近 + 恐怖遭遇 + 命运失稳
x = 深层欲望 / 吞没 / 占有 / 压迫源
n = 承载 / 安顿 / 持续 / 容器
```

### 1.2 血肉可以疯狂生长

主骨锁定后，可以通过大量作品、角色、场景、音乐、图像去补血肉。

血肉包括：

- 人物血肉
- 行为血肉
- 空间血肉
- 视觉血肉
- 声音 / 音乐血肉
- 叙事血肉
- 动态链血肉
- 误判反例
- 创作模板

### 1.3 判断不按词，按体量、语义场、动态功能

同一个词可能带多个十元。

例如：

```text
黑暗：常主判 x，但可带 xz
废墟：常在 xn / n崩后的语义场下，可生出 xz
怪物：通常就是 xz
恐怖：通常就是 xz
```

不能写死成「A ≠ B」，要看主导体量和动态功能。

## 5. xz 修正封存

### 5.1 旧误区

把 xz 写成：

```text
临界行动 + 风险路径 + 来不及
```

这个定义太窄，只覆盖了「人在危险中怎么动」，没有覆盖「危险本身显身」。

### 5.2 新主骨

```text
xz = 危险显身 + 异质逼近 + 恐怖遭遇 + 命运失稳
```

一句话：

> xz 是危险以可感知形态逼近。

### 5.3 x 与 xz 区分

```text
x  = 深处的吞没、欲望、占有、压迫源。
xz = 吞没显形后逼近你，成为怪物、恐怖、追杀、异质威胁。
```

### 5.4 误判修正

```text
黑暗不自动等于 xz，黑暗常主判 x。
废墟不自动等于 xz，废墟常是 xn / n 崩后的残留场。
怪物通常就是 xz。
恐怖通常就是 xz。
```
