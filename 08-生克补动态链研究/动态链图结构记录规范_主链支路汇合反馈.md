# 动态链图结构记录规范｜主链、支路、汇合、反馈与搭桥

> 当前研究优先级：**以具体动态链的积累为主，母型归纳后置。**
>
> 不再默认把所有关系对子压成一条直线。每个案例先记录真实图结构；只有多条独立动态链在关系、链序、拓扑和变量上稳定同构，才进入母型比较。

## 1. 核心纪律

```text
先完成人物/团队行为与具体名词对子
→ 再按真实阶段连接动态链图
→ 标明主链、支路、汇合、反馈、延伸、搭桥和断裂
→ 最后才与已有母型比较
```

1. 动态链不是关系对子清单，也不是剧情梗概。
2. 相同的关系对子，顺序不同，原则上是不同动态链。
3. 相同的主链，后续延伸不同，先分别保留为不同具体展开。
4. 串联、并行、汇合和反馈是不同机制，不能互相改写。
5. 母型只能从多条完整动态链后验归纳，不能作为首遍分析模具。
6. 第一遍分析默认屏蔽母型编号和名称；完整链画完后才开放比对。

## 2. 图结构的最小单位

### 2.1 节点

每个节点必须写：

```text
具体名词
+ 十元位置
+ 所属人物/团队与阶段
+ 稳定本体/当前状态/体量
+ 当前可被改变变量
```

只写`x`、`z`、`xn`或角色名，不算完成节点。

### 2.2 边

每条边必须写：

```text
人物/团队实施了什么行为
+ 源具体名词及位置
+ 生/克/补方向
+ 目标具体名词及位置
+ 作用机制
+ 被改变变量
+ 拿掉测试
+ 反向测试
+ 证据等级
```

箭头表示已经审核的作用方向，不只表示时间先后。

## 3. 必须区分的图结构

### 3.1 串联主链

前一关系改变的变量，构成下一关系的启动条件。

```text
A生B → B生C → C补D
```

每一段都要证明：若前段不发生，后段是否仍以同一路径启动。

### 3.2 后续延伸

核心链已经完成，结果继续启动新的关系。

```text
核心链：A生B → B生C → C补D
延伸：D生E
```

延伸不自动属于核心母型，必须单独记录。

### 3.3 并行支路

两条关系从不同来源共同作用于同一节点，不能硬排成先后。

```text
A生C
B补C
```

必须写清A和B分别改变C的哪一个变量，防止把两种机制合并。

### 3.4 汇合节点

多个支路在同一节点汇合，但各自承担不同功能。

```text
A ─生─→ C
B ─补─→ C
```

C是汇合节点。记录时要分别进行拿掉测试：拿掉A后损失什么，拿掉B后又损失什么。

### 3.5 反馈环

后段节点通过新的行为反过来改变前段节点。

```text
A生B → B补C
      ↑     │
      └─补──┘
```

反馈必须区分：
- 是同一具体对象跨阶段回返；
- 还是两个都位于同一十元位置、但具体名词和体量不同的节点。

不能因为字母相同就把两个节点误当成同一个对象。

### 3.6 搭桥

搭桥是中间节点让两个原本不能直接顺畅连接、甚至存在直接克制的端点，改走可接收路径。

```text
1生2 → 2生3
背景：1克3
```

其中2是桥。成立必须证明：
1. `1生2`与`2生3`各自真实成立；
2. `1克3`是基础直接关系，不因搭桥而从位置表消失；
3. 2具体转换了什么变量，使3能够接收；
4. 拿掉2后，1无法以同一方式生3，直接克制或变量下降重新显现；
5. 若末尾再有补，必须另写谁补谁、原缺口和恢复变量。

搭桥可以发生在串联主链、并行支路或反馈环中，不等于任何“中间经过一个节点”的普通顺序。

### 3.7 反转、转位与断裂

```text
继续：A生B → A生B
反转：A生B → B克A
转位：A生B → A克C
断裂：A生B → 后段关系未启动
```

前一阶段关系不能自动继承到后一阶段。对象、十元位置、体量或关系位置变化后必须重新审核。

## 4. 青霉素案例的正确图结构

青霉素不能只写成四个关系的直线清单。应区分正式成果主链、验证证据支路和程序层级。

```text
纯化样品、提取方法、动物与临床数据掌握 x
                    │
                    生
                    ↓
1940动物实验论文、1941临床报告、可复核方法壳 x并z
                    │
                    生
                    ↓
治疗价值与规模化资格的跨机构确认 z
          ↑                         │
          │                         补
          │                         ↓
验证程序 xn_A ─────补─────      研发、生产与供应程序 xn_B
```

压缩写法：

```text
主链：x生x并z → x并z生z → z补xn_B
并行证据支路：xn_A补z
```

关键区分：

- `x并z生z`：论文、临床报告与方法壳给确认提供可识别、可归因、可复核和跨机构调用的正式接口。
- `xn_A补z`：纯化、动物对照和临床观察程序给确认补入跨时间证据、剂量边界与重复稳定度。
- `z补xn_B`：治疗与规模化资格确认给更大的菌株筛选、发酵优化、企业生产和供应程序补入对象、标准、参与者与节点。
- `xn_A`与`xn_B`都定位为`xn`，但具体名词、阶段和体量不同。默认先记为“并行支路汇合后推动另一程序”，不能仅凭字母相同直接画成同一对象的闭环。
- 只有证明确实是同一具体程序跨阶段扩大，并且后段结果回头补强原确认，才可额外登记反馈环。

## 5. 三个现有例子的顺序分类

### 5.1 《疾速追杀2》：串联主链加后续延伸

```text
x生x并z → x并z生z → z补xn
                              → xn生xz
```

前三段完成正式化、确认与程序聚焦；`xn生xz`是程序运行后的风险延伸。不得倒写为风险先生成程序。

### 5.2 《疾速追杀3》：连续换挡链

```text
z补xn → xn生xz → zx克n → n克xz
```

责任确认聚焦追责程序，程序扩大临界，公开权能撤销承载，残余承载再吸收部分风险。任意调换顺序都会改变机制。

### 5.3 青霉素：串联主链加并行证据支路

```text
主链：x生x并z → x并z生z → z补xn_B
支路：xn_A补z
```

它不是普通四步直线，而是支路汇合于`z`后，再推动另一体量的`xn_B`。

## 6. 每个案例必须提交的两种表示

### 6.1 文字链

```text
人物/团队行为
→ 具体源名词及位置
→ 关系对子
→ 具体目标名词及位置
→ 被改变变量
```

### 6.2 图结构

至少标明：

```text
主链：
支路：
汇合节点：
反馈环：
搭桥节点：
后续延伸：
反转/转位：
断裂节点：
阶段编号：
```

不存在的项目明确写“无”，不能为了图形完整强行制造。

## 7. 顺序与拓扑测试

每条链完成后必须测试：

1. **换序测试**：交换两段后，因果是否仍成立？若不成立，链序是核心结构。
2. **拿桥测试**：去掉中介节点，前后两端是否恢复直接克制、失去输入或无法启动？
3. **支路拿掉测试**：去掉并行支路，汇合节点具体损失哪项变量？
4. **汇合分账测试**：不同来源是否只是重复提供同一变量，还是提供不同必要变量？
5. **反馈方向测试**：后段是否真的回头改变前段，而不只是继续产生新证据？
6. **同字母异对象测试**：两个同十元节点是否其实是不同具体名词、不同阶段或不同体量？
7. **断裂测试**：哪一段不成立时，后续哪些关系仍可独立运行？
8. **反向解释测试**：是否是后段结果倒证前段，或由第三因素同时造成？

## 8. 动态链积累与母型后置

当前研究以“具体动态链图谱库”为主：

```text
案例事实
→ 人物/团队行为
→ 具体名词关系对子
→ 阶段图结构
→ 顺序与拓扑测试
→ 入库
```

母型只在后置比较阶段使用：

```text
多条独立动态链
+ 关系方向相同
+ 链序相同
+ 分支/汇合/反馈拓扑同构
+ 被改变变量同构
+ 失败版与断裂位置同构
→ 才进入母型候选
```

禁止：

- 先选母型，再把案例端点塞进去；
- 只因字母链相同就合并案例；
- 忽略主链外的支路、汇合和反馈；
- 把同一十元位置的不同具体对象压成一个节点；
- 把并行关系写成虚假的时间顺序；
- 用结局成功补齐中间缺失关系。

## 9. 归档定位

本文件是动态链研究的图结构记录规范。后续案例应以本文件为图示和链序标准；母型索引只承担后验比较，不承担首遍发现。
