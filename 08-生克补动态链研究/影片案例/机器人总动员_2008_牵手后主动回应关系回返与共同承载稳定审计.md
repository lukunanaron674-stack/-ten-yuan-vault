# 《机器人总动员》（2008）｜牵手后主动回应、关系回返与共同承载稳定动态链审计

## 1. 固定片段与对象层

只分析瓦力恢复对象识别后，主动握住伊芙的手，伊芙给予对象特异回应，双方并肩面向地球新生活的连续C级片段。此前维修、照护和记忆接口恢复仅作为已完成前提，不回溯扩写整部影片。

- 对象层：对象特异关系回返与现实共同承载层。
- 主体：瓦力、伊芙；地球环境、其他机器人与人类共同体为后续承载条件。
- 阶段：对象识别恢复 → 瓦力主动牵手 → 伊芙自由回应 → 双方共同面向现实生活。
- 唯一核心变量：**主动牵手与双方自由回应是否足以形成片段级`nz`关系回返，以及现实共同生活的`n`承载究竟是稳定条件，还是被浪漫结局误写为已经生成完整长期关系。**

## 2. 端点分账

- `z_specific_recognition_confirmed`：瓦力已经明确识别伊芙及其关系位置，不再是一般程序上线。
- `nz_mutual_return`：瓦力主动发起对象特异接触，伊芙可拒绝但实际回应，双方恢复可进入、可停靠、可共同选择的关系接口。
- `n_shared_life_bearing`：双方回到地球后拥有空间、身体、行动与群体生活的现实承载条件。
- `xn_program_available`：双方基础程序与行动接口可运行，只提供行动载体，不承担关系意义。
- `x并z_shared_history_shell`：共同经历、收藏物与既有叙事为关系识别提供材料，但不替代当前双方回应。

## 3. 直接边

```text
对象特异识别确认 z_specific_recognition_confirmed
        ──补──▶
双方关系回返 nz_mutual_return 所缺的主体确认
```

该边成立于：瓦力不是被动执行牵手程序，而是在恢复对伊芙的对象特异识别后主动握手；伊芙也不是单向投射，而是以可拒绝的主体身份回应。`z`补入的是“这是同一对象、同一关系位置”的确认缺口。

## 4. 条件性补边

```text
现实共同生活承载 n_shared_life_bearing
        ──补──▶
片段级关系回返 nz_mutual_return 的持续落地条件
```

必要条件：

1. `nz`已经由双方对象特异回应成立，`n`不能替代双方确认；
2. 现实承载包含共同空间、持续行动、风险与生活任务，而不只是结尾构图；
3. 双方仍保留拒绝、离开、重新协商和改变关系方式的资格；
4. 程序可运行`xn`只保证行动接口，不得偷换为关系稳定；
5. 共同经历材料`x并z`只提供历史连续性，不得替当前主体作答。

## 5. 正式失败边

### 失败边A

```text
✕ 一次主动牵手与回应
  ──生──▶ 完整长期稳定关系 nz
```

不成立原因：一次自由回应足以支持片段级关系回返，却不足以证明长期协商、冲突修复、持续承载与未来多次自由选择。

### 失败边B

```text
✕ 现实共同生活承载 n
  ──生──▶ 双方对象特异关系 nz
```

不成立原因：共同处于地球、共同劳动或共同生活只能提供关系载体。没有对象识别和双方回应，同处一地仍可能只是共事或并存。

### 失败边C

```text
✕ 程序可运行 xn
  ──生──▶ 关系回返 nz
```

不成立原因：上一片段已经证明“能运行但不认识”。程序状态是行动前提，不是关系生成源。

### 失败边D

```text
✕ 共同经历与浪漫结局壳 x并z
  ──生──▶ 当前自由回应 nz
```

不成立原因：历史材料和叙事构图可以强化解释，却不能替代当前主体的识别、发起与回应。

## 6. 拿掉测试

- 拿掉`z`对象特异识别：牵手可能退化为程序动作或一般接触，`nz`显著失去对象确认。
- 拿掉伊芙的自由回应：只剩瓦力单方发起，不能判定双方关系回返。
- 拿掉瓦力主动发起：若伊芙单方握手而瓦力仅被动运行，则仍可能是照护延续，不足以确认双向接口。
- 拿掉`n`现实共同承载：片段级`nz`仍可成立，但长期稳定解释显著变弱。
- 拿掉共同历史材料：当前双方识别与回应仍能支持片段级关系，但“回返”应降为新关系建立候选。
- 拿掉程序可运行：行动无法实现，但这只证明`xn`是必要载体，不证明它生成关系。

## 7. 反向测试

- 若瓦力恢复识别后拒绝牵手，`z`成立而`nz`回返不成立。
- 若伊芙不回应或主动离开，只能确认瓦力单方关系意向。
- 若双方回应后没有共同生活条件，片段级回返仍成立，但稳定承载不足。
- 若共同生活条件完整但双方无对象特异回应，只能确认`n`承载，不得判`nz`。
- 若未来冲突中双方仍可退出并重新协商，则支持`nz`；若关系只能靠程序、任务或环境强制维持，则更接近`xn`或`z`约束。

## 8. 最近邻与第三因素

- 最近邻：浪漫动作、程序性握手、条件反射、一般亲密、搭档协作、共同劳动、同处空间、叙事圆满壳、旧关系惯性。
- 第三因素：记忆恢复、维修完成、影片结尾剪辑、音乐强化、共同危机后的情绪高峰、地球重建任务、群体环境与观众对爱情结局的预设。

## 9. 竞争解释

1. **程序动作解释**：牵手只是系统恢复后的预设动作。对象特异识别、主动发起和伊芙自由回应削弱该解释，但无法完全排除动画表现的程序化简写。
2. **浪漫结局壳解释**：音乐、牵手和并肩构图让观众自动补成长期爱情。该解释能说明过度推断，因此必须限制为片段级回返。
3. **共同任务解释**：双方只是共同投入地球重建。共同任务可解释`n`承载，却解释不了对象特异牵手和双方回应。
4. **旧关系惯性解释**：双方只是恢复旧模式，没有重新选择。瓦力主动发起和伊芙可拒绝式回应提供当下选择证据，但长期自由协商仍未展示。

## 11. 动态类型

- 主类型：对象识别确认后的关系回返链。
- 次类型：片段级`nz`由双方自由回应成立，`n`补持续落地条件。
- 边界类型：结局圆满壳容易把片段级回返夸大为长期稳定关系。

## 12. 搭配效果

`xn`维持行动接口，`z`确认同一对象与关系位置，瓦力主动发起和伊芙自由回应共同形成片段级`nz`，`n`再提供地球生活、行动和共同任务的现实承载。组合效果是：**能运行让回应可发生，识别让回应指向正确对象，双方回应让关系回返成立，现实承载让关系有机会持续；四者必须分账。**

## 13. 链段顺序效果

```text
程序与行动接口可运行 xn
→ 对象特异识别恢复 z
→ 瓦力主动发起
→ 伊芙自由回应
→ 片段级关系回返 nz
→ 现实共同生活承载 n 补持续条件
```

若把`n`提前为关系生成源，会把共同生活误判成亲密关系；若把`nz`提前到瓦力单方牵手，会把意向误判成双方回返；若把`xn`写成关系恢复，会重犯“能运行等于能认识”的错误；若把结尾构图直接写成长久稳定，会让失败边消失。
