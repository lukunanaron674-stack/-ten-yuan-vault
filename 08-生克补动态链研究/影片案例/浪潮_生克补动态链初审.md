# 《浪潮》生克补动态链审计

> 核心问题：外来示范由启蒙转成群体服从时，`zx/xn` 是否直接生成 `nx`；临时共同体 `n` 何时转成制度自愿再生产。

## 1. 结论摘要

本片不宜写成“教师权威生出学生服从”。更准确的链是：

```text
教师 zx 打开自治实验（允许条件）
→ 学生因归属、互认与共同承担形成临时 n
→ n 生 xn：共同体负荷被提炼为称呼、纪律、手势、服装、分工与边界
→ x 生 x并z：成员实际控制空间、资格与行动后形成名称、标识、制服和公开壳
→ x并z 生 z：公开壳使成员被彼此确认、被外界识别
→ 多数成员进入局部 nx：不再认领最终方向，只沿群体流程推进
→ 新 xn 反过来克制原教师 zx，实验脱离其单次决定
→ 强制终止时共同体与身份壳崩坏，Tim 的极端依附进入灾难结局
```

核心贡献：`nx` 在本片不是一条“被 zx/xn 直接生出”的正式关系，而是 `n 生 xn`、`x 生 x并z`、`x并z 生 z` 连续成立后，成员在关系位置上逐步放弃最终方向资格的结果。

## 5. 主克

```text
后段：群体 xn 克教师 zx
```

- 关系双方：已跨课堂复制的群体结构，与 Wenger 的即时终止决定。
- 被改变变量：教师单次命令的有效性、结构复制率、成员自愿执行、跨场景延续。
- 拿掉测试：若敬礼、服装、传播和排斥只在教师课堂内出现，教师一句终止即可结束，主克不成立。
- 反向测试：若学生只是公开反抗教师而没有共同流程，源更接近学生 `zx`，不是 `xn`。
- 置信度：93%，审计层稳定但不回写核心关系表，因为 `xn 克 zx` 已锁定。

## 6. 主补

**未锁定。**

浪潮为 Tim 提供归属、身份、任务与可见位置，但混合了 `n` 承载、`x并z` 身份壳、`z` 认可和 `xn` 规则。无法证明单一补关系恢复单一缺失核心变量。

尤其不能写“群体补回 Tim 的爱”。

## 7. 主生

### 主生：`n 生 xn`

初期成员互认、协作、保护、球赛配合与共同任务形成真实承载负荷；为了让共同体继续，负荷被提炼为称呼、纪律、手势、分工、传播和边界规则。

拿掉共同承载，只保留 Wenger 的命令，结构会停留在课堂纪律，难以跨场景自愿复制。

置信度：91%。它与核心表已锁定的 `n 生 xn` 一致，本片作为动态链案例，不新增理论锁定。

### 支链：`x 生 x并z → x并z 生 z`

群体先实际掌握空间、成员资格与行动，再形成名称、制服、标志和网站；公开壳随后提升成员识别与认可归因。

## 8. `nx` 的判定

本片不新增“`zx/xn 生 nx`”。

```text
共同体提供承载
→ 结构提供默认路线
→ 身份壳提高成员确认与退出成本
→ 成员反复不使用否决与最终判断
→ 局部 nx 上升
```

这是多节点动态后果，不是单一几何生关系。判断 `nx` 必须观察：无教师监督仍执行、遇到冲突先按群体方向处理、对退出者排斥、个人否决权萎缩。

## 9. 正例

1. Wenger 不在场时，学生仍统一穿衣、使用敬礼、传播标志并扩大成员边界，证明 `xn` 已跨场景复制。
2. Wenger 决定终止后，成员并未立即恢复个人判断与旧关系，证明结构已反向压低其即时 `zx`。
3. 球队和同伴关系先承担协作、保护与归属负荷，之后才出现更细的规则、分工和边界，支持 `n 生 xn`。

## 10. 反例

1. 第一堂课学生按要求站立发言：可能只是教师权威与课堂服从，不证明新 `xn` 已自愿再生产。
2. 学生穿白衬衫合影：单次视觉同步只证明 `x并z` 显影，不证明稳定 `nx`。
3. 标志和网站出现：若没有实际空间、成员资格和行动掌握，只是品牌设计，不足以判 `x 生 x并z`。
4. 球赛热情和群体欢呼：状态感染，不等于共同体已形成跨压力承载。

## 11. 最近邻排除

- 领袖崇拜 `z`：认可 Wenger 不能解释无教师在场时规则为何继续复制。
- 教师 `zx` 主动接管：只能解释实验入口，不能解释后段结构反噬教师。
- 普通团队协作：保留成员否决与退出，不要求统一身份和外部排斥。
- `x并z` 身份壳：提高识别与归属，但不等于内部 `n` 或持续 `xn`。
- 情绪感染：解释同步速度，不能解释跨场景、跨时间、自我维护和处罚边界。

## 12. 整体拿掉与反向测试

1. 拿掉初期互认和协作，只留课堂命令，难形成跨场景 `xn`。
2. 拿掉名称、制服、标志和网站，群体仍可能有承载，但识别、传播和退出成本明显下降。
3. 拿掉教师监督后仍执行的证据，就不能判制度再生产。
4. 拿掉排斥、处罚与边界，只剩共同活动，不足以判成员方向资格下降。
5. 反向：若 Wenger 一宣布结束，全体立即停止并恢复个人判断，则始终只是 `zx` 课堂实验，没有 `xn 克 zx`。

## 13. 动态链与感觉走向

```text
教师 zx 打开启蒙试验
→ 归属与协作形成临时 n
→ n 生 xn，规则从工具变成共同体维持方式
→ x 生 x并z，群体形成可识别身份壳
→ x并z 生 z，成员确认和外界识别增强
→ 局部 nx 扩张，个人否决与退出成本恶化
→ xn 克 zx，结构反噬发起者
→ 强制回收导致共同体、身份与个体同时崩坏
```

感觉：游戏感 → 被接纳 → 整齐与力量 → 归属高潮 → 排他压迫 → 失控恐惧 → 灾难性清醒。

## 14. 母型 M-004

**共同体负荷—制度提炼—身份增幅—结构反噬**

```text
外来 zx 打开试验
→ 临时 n 承担归属与协作
→ n 生 xn
→ x 生 x并z → x并z 生 z
→ 成员局部 nx 扩张
→ xn 克原 zx
→ 强制回收时灾难崩坏
```

适合：校园实验、政治运动、宗教组织、饭圈、公司文化与封闭社群。

失败版：没有真实共同承载，只有领袖命令和视觉同步；此时不会稳定生成制度，只会短时从众。

第二部待验证：《斯坦福监狱实验》题材作品或《帝国的毁灭》中组织末期片段。
