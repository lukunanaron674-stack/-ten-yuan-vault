# 《肖申克的救赎》瑞德获释后超市工作｜制度路径持续与个人方向低占用审计

## A. 启动信息

- 分析范围：瑞德获释后进入假释生活，在超市承担被分配的装袋工作，并在上厕所前向主管请求许可的连续C级片段。
- 分析粒度：C级单片段。
- 动态类型：主次双符号维持链。
- 主十元：`nx`。
- 次十元：`xn`（外部制度结构层，不是瑞德主动组织层）。
- 排除端点：`n`未成立；超市、宿舍与物理容纳不能单独证明真实内部承载。
- 本轮核心问题：瑞德是否仍沿假释、雇佣与监狱遗留程序给定的方向行动；外部流程是否形成`xn`端点；该流程是否对`nx`构成正式生克补边。

## B. 对象层、主体、阶段与端点

| 项目 | 判断 |
|---|---|
| 对象层 | 方向权、工作流程、许可程序、长期制度惯性 |
| 主体 | 瑞德为行动主体；假释制度、超市管理流程与监狱遗留许可习惯提供外部运行结构 |
| 阶段1 | 获释后，瑞德按假释与就业安排进入超市工作 |
| 阶段2 | 他执行被分配的装袋任务，没有组织工作流程、改写岗位或提出替代运行方式 |
| 阶段3 | 上厕所前仍先向主管请求许可，显示外部许可程序继续占据行动入口 |
| 主端点 | 瑞德不占据工作与日常行动的最终方向决定位置，沿既有安排继续：`nx`状态/行为 |
| 次端点 | 假释、雇佣岗位、主管许可与监狱长期训练共同构成跨阶段规则/流程惯性：外部结构层`xn` |
| 失败端点 | 超市、宿舍或“被社会收留”不能单独成立`n`；片段未展示结构持续接收并承担瑞德现实负荷 |

## C. 唯一核心变量

**瑞德在获释后的日常行动中，是否取得自主决定与改写行动流程的位置。**

- 初始状态：长期监狱制度已把工作、行动、许可与时间节点组织成外部流程。
- 终态：瑞德进入超市后仍执行他人安排，并在基本生理行动前请求许可，没有取得流程改写或最终决定位置。
- 展开指标：岗位来源、流程组织权、许可入口、替代方案、否决权、主动排程与自主行动。

## D. 主次十元路由

### 主十元：`nx`

```text
工作岗位、假释方向与许可通道已经存在
──给定外部方向──▶
瑞德不占据最终决定位置
──沿既有安排行动──▶
装袋工作与许可请求持续
```

`nx`成立依据：方向、权限和通道由假释制度、雇佣安排与主管位置给出；瑞德没有主动组织运行方式，只沿既有路径推进。

### 次十元：外部结构层`xn`

```text
长期监狱规则 + 假释程序 + 超市岗位流程
──跨阶段排列时间、行为与许可节点──▶
外部制度流程 xn 成立
```

`xn`只成立在外部结构层：规则、流程、岗位与许可节点跨阶段持续发挥结构力量。瑞德本人没有主动排程、搭流程或组织资源，因此不能把瑞德判为主体层`xn`。

### `n`端点失败

```text
超市工作地点 + 中途宿舍 + 物理容纳
──X端点判定──▶
十元 n

失败：没有充分证据证明某结构允许瑞德获得可持续内部位置，并跨阶段接收、保护和承担其现实负荷。
```

## E. 直接生克补边

```text
direct_edge: none
```

理由：

- `nx`在进入超市前已经由假释与长期制度化生活建立，本片段主要显示其持续显影；
- 外部`xn`流程与瑞德`nx`同时成立，但本片段未证明`xn`首次生成`nx`、削弱一个已成立目标，或补入`nx`的真实缺口；
- 监狱长期制度化可能是`nx`形成的历史原因，但当前C级片段只可证明流程持续与状态维持，不能把长程背景压缩成新增直接关系边；
- 不制造`xn生nx`、`xn补nx`或`xn克nx`等现行正本外关系。

## F. 完整核心动态图

```text
【次十元：外部结构层 xn】
长期监狱规则 + 假释程序 + 超市岗位/主管许可流程
        ──跨阶段组织规则、时间与许可节点──▶
外部制度流程 xn 持续运行
        ──给定行动方向与许可通道（条件/维持，非生克补）──▶

【主十元：瑞德 nx】
瑞德不占据工作与日常行动的最终决定位置
        ──沿既有安排执行──▶
被分配的超市装袋工作
        ──许可惯性继续显影──▶
上厕所前向主管请求许可
        ──维持低占用──▶
自主决定、改写流程与否决位置仍未取得

【失败支线】
超市 + 宿舍 + 社会物理容纳
        ──X端点判定──▶
十元 n
（失败：缺少持续准入、真实内部位置、现实负荷承担与保护连续性）
```

### 字母、箭头方向与关系标签

```text
外部制度流程 xn ──给定方向/许可通道（条件）──▶ 瑞德 nx
瑞德 nx ──沿安排执行──▶ 超市装袋工作
瑞德 nx ──许可惯性显影──▶ 请求上厕所许可
瑞德 nx ──维持低占用──▶ 自主流程决定位置未取得
超市/宿舍物理容纳 ──X端点判定──▶ n
```

- 主导关系：`xn（外部条件）──给定──▶ nx（主体状态）`。
- 关系性质：条件与维持箭头，不登记为直接生克补边。
- 阶段变化：监狱内的强制许可程序退出现场，但其组织惯性在假释与工作场景继续显影。

## G. 成立条件

- 假释、岗位分配与主管许可仍真实限定瑞德的行动入口；
- 瑞德没有主动组织工作流程、改写岗位、设置替代路径或取得最终许可权；
- 请求许可必须被理解为长期制度惯性的连续显影，而不是一次普通礼貌；
- 外部`xn`端点只取规则、时间、岗位与许可节点的持续组织，不把“身处制度”单独当作充分证据；
- `n`若要成立，必须另有持续准入、内部位置、负荷承担、保护和跨阶段接收证据。

## H. 正式失败边

### F-01

```text
xn ──生──▶ nx
```

- 为什么看似成立：长期制度训练使瑞德习惯服从安排并请求许可。
- 违反测试：当前片段只证明既有`nx`继续显影，不能证明目标在本片段此前不存在或不足并被新生成。
- 最近邻：外部`xn`条件维持`nx`行为显影。
- 最终处理：失败边。

### F-02

```text
xn ──补──▶ nx
```

- 为什么看似成立：流程为瑞德提供岗位和行动通道。
- 违反测试：`nx`不是一个已有但缺少流程接口的目标；片段没有可指认的`nx`真实缺口被补入。
- 最近邻：既有安排提供执行条件。
- 最终处理：失败边。

### F-03

```text
瑞德 nx ──生──▶ 外部制度 xn
```

- 为什么看似成立：瑞德服从岗位与许可要求，使流程在现场继续运行。
- 违反测试：流程、岗位与许可节点在瑞德进入前已经存在；他的服从不生成该外部结构。
- 最近邻：主体进入并执行既有流程。
- 最终处理：失败边。

### F-04

```text
超市 / 中途宿舍 ──承载──▶ 瑞德 n
```

- 为什么看似成立：瑞德获得工作地点与居住空间。
- 违反测试：物理容纳、就业与暂住不能替代结构对对象的持续接收、保护、负荷承担和真实内部位置。
- 最近邻：场景条件与制度安排。
- 最终处理：端点失败边。

## I. 拿掉、反向与竞争解释

- 拿掉超市场景，只保留“瑞德按外部安排工作并在基本行动前请求许可”，`nx`仍成立，说明工作地点不是主端点。
- 拿掉主管许可与长期监狱惯性，只保留普通装袋劳动，`nx`证据显著下降，说明许可入口与既定方向是关键条件。
- 拿掉外部流程的时间、岗位、规则与许可节点，外部`xn`端点不再成立。
- 反向写成`nx生xn`无法解释制度、岗位和许可流程为何在瑞德进入前已经存在。
- 竞争解释1：瑞德请求许可只是礼貌。该解释不足，因为片段将其与长期监狱制度化经验连续呈现，且许可对象涉及基本生理行动。
- 竞争解释2：瑞德主动适应社会，属于主体层`xn`。片段没有显示他主动排程、搭流程、组织资源或维护运行结构。
- 竞争解释3：超市和中途宿舍接住瑞德，属于`n`。现有证据只有岗位与物理位置，缺少持续负荷承担和保护连续性。

## J. 搭配效果、顺序效果与母型累计

- 搭配效果：外部结构层`xn`持续提供规则、岗位与许可通道，主体层`nx`沿这些通道行动，形成“已离开监狱但方向权仍未回到主体”的制度余波。
- 顺序效果：先有长期外部`xn`组织，再有瑞德`nx`在获释后的场景继续显影；若把顺序反写，会误成瑞德的服从生成制度。
- 动态类型：主次双符号维持链。
- 母型累计：新增“外部制度结构持续运行 + 主体方向决定权低占用”的`xn→nx`条件维持具体案例1；新增正式失败边4；直接生克补关系计数不变；`n`支持计数不变。
