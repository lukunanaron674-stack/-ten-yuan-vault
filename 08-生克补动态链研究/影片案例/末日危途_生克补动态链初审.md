# 《末日危途》（2009）生克补动态链审计

> 本轮问题：父子原本已经是成员关系时，移动护送母型如何变化；区分父子既有承载、资源依赖、关系余温、保护原则与危险，并检验 UM-02 是否应拆成“任务对象成员化”和“既有成员保存”两个子型。

## 1. 结论摘要

```text
食物、推车、手枪、道路、地下室、地堡、海岸、衣物、药物与火种 = x
→ 父亲、儿子、母亲、路人、盗贼、食人者、陌生家庭 = x并z
→ 搜索、迁移、掠夺、囚禁、躲避、资源管理与路线选择 = xn
→ 父子互保、临时地堡、房屋避难、结尾陌生家庭接收 = 不同成熟度的 n
→ 饥饿、严寒、疾病、食人者、资源枯竭与父亲死亡窗口 = 高体量 xz
→ 父亲的路线与杀伤决定、儿子的求助与接收判断 = 局部 zx
→ “不吃人、不把弱者当资源、继续携带火种” = zn 候选
→ 父子关系原本已成立，不存在高价值任务对象成员化；本片检验的是既有成员 n 在资源与主体逐步耗尽时如何保存、转交和失效
```

核心贡献：

1. **既有亲属身份壳不等于当前承载仍有效**：父子称谓一直存在，但父亲疾病、资源枯竭和路线减少会持续降低保护、照护、判断和返回能力。
2. **既有成员保存型与任务对象成员化型必须分开**：本片没有“从接口变成员”的节点，而是从成熟父子 n 开始，审计它在移动危险中如何维持、受损与转交。
3. **资源补给只恢复承载能力，不生成亲情**：地堡食物、房屋、药物和衣物能局部补回父子的身体照护与停留能力，却不生成父子关系本身。
4. **父亲的保护与儿子的原则出现分叉**：父亲偏向风险最小化，儿子持续要求帮助弱者；这不是“爱与生存冲突”，而是同一移动 n 内两个 `zn/zx` 路线的分化。
5. **父亲死亡是源端点耗尽，不是成员关系自动消失**：结尾陌生家庭的接收承担了承载转交，但影片未展示其长期稳定，故只能判新 n 启动候选。

## 4. 开场稳定结构

- 父子关系在影片开始前已形成稳定成员 `n`：共同移动、资源共享、互保、睡眠与身体照护均已存在。
- 父亲拥有路线、手枪与资源决定 `x/zx`，儿子拥有关系内部的道德提醒与拒绝接口。
- 世界公共 `n/xn` 已大规模崩解；道路只是移动空间，不是承载。
- 核心缺口不是“儿子还不是成员”，而是既有父子 n 缺乏可持续外部资源、替代保护者与稳定返回位置。
- 不得由父亲保护直接反推所有行为都来自同一 `zn`；父亲的风险最小化与儿子的非工具化原则会发生分叉。

## 6. 主克

### 主克：生态崩解与掠夺结构形成的高体量 `xz/xn` 克制父子移动 `zx`

- **关系双方**：环境资源枯竭、食人者搜索与掠夺结构，对父子路线、停留和保护决定。
- **源端点**：持续减少的食物、温度、身体健康与安全路线构成 `xz`；食人者的搜捕、囚禁与资源化处理构成 `xn`。
- **目标端点**：父亲带路、停留、分食、保护和交接的局部 `zx`。
- **被改变变量**：可停留时间、路线选择、保护连续性、资源分配余地、父亲决定执行率。
- **成立阶段**：全片持续，父亲病重后达到高峰。
- **显影条件**：资源下降、威胁可达、路线无法复用、身体无法恢复。
- **拿掉测试**：拿掉食人者组织，危险仍在但路线压缩降低；拿掉生态资源枯竭，只保留个别恶人，主克体量显著下降。
- **反向测试**：父子 `n` 可局部克制 `xz`，但不能恢复世界承载。
- **为什么不是普通阻碍**：危险与掠夺跨地点、跨阶段持续处理父子的每次停留与资源决定。

## 7. 主补

### 主补：临时 `x+n` 补回既有父子承载的运行能力

- **缺口原先如何成立**：父子关系已存在，但食物、睡眠、药物、衣物与安全停留持续缺失，使 `n` 的保护和照护能力下降。
- **补的来源**：地下地堡、临时房屋、海船物资、衣物与药物。
- **被补核心变量**：身体恢复、分食能力、安全停留时间、照护连续性、继续移动能力。
- **是否只是帮助/资源**：资源本身属于 `x`；只有进入父子共同使用并恢复照护运行时，才形成对既有 `n` 的局部补位。
- **拿掉补源后的差异**：父亲和儿子更快进入饥饿、疾病与死亡窗口。
- **为什么与主克对应**：主克持续消耗成员保护与照护能力，补源恢复的是同一组运行变量。

注意：它补的是**父子承载能力**，不是补出父子关系，也不是补出抽象希望。

## 8. 主生

### 主生候选：父亲承载耗尽后，儿子的 `zn+z` 打开新接收 `n`

- **新生目标此前是否不存在**：陌生家庭在父亲死亡前并非儿子的现实内部。
- **源是否提供核心变量净增量**：儿子持续坚持“好人/不吃人/不把弱者当资源”，并在父亲死亡后对陌生家庭进行接收判断；家庭则提供邀请、保护与成员位置。
- **类型**：桥接生/允许条件，非纯直接生。
- **第三因素**：家庭可能已长期观察父子，并拥有资源、儿童与母性照护结构。
- **首次显影**：儿子询问对方是否“携带火种”并接受同行。
- **跨阶段保持**：影片未展示，故不锁。

更稳的写法是：

```text
儿子既有 zn 提供接收判断标准
+ 陌生家庭 z/n 提供现实接收接口
→ 新成员承载启动候选
```

不能写成“父亲的爱直接生出新家庭”。

## 9. 支链与换挡

- **支链1**：父子 `n 克 xz`，通过抱持、分食、警戒与互相唤醒，局部降低失温、恐惧和漂流。
- **支链2**：食人者 `xn 克 zx`，将人作为可搜捕、囚禁和食用资源，压缩父子的停留与解释接口。
- **中段换挡**：地堡阶段从连续漂流转为短时承载恢复；父亲选择迅速离开，显示资源安全与追踪风险的权衡。
- **高潮反向关系**：父亲越来越以 `xz` 逻辑主导资源和他者边界；儿子以 `zn` 反向限制父亲的惩罚与非成员排除。
- **主角何时从目标端转为源端**：父亲死亡后，儿子从被保护者转为接收判断与关系延续的源端之一。

## 10. 正例、反例与最近邻

### 正例节点

1. 父亲与儿子在地堡获得食物后共同恢复身体、睡眠与照护，证明 `x` 只有进入共同使用才局部补回 `n` 的运行能力。
2. 父亲惩罚盗贼后，儿子要求归还衣物，显示同一成员关系中可以出现不同 `zn/zx` 路线，而不是“父爱”包办全部决定。
3. 父亲死亡后儿子接受陌生家庭，说明既有成员保存型最终需要承载转交，不是任务对象成员化。

### 反例节点

1. 父子称谓始终存在，但父亲病重后保护和照护能力持续下降：身份壳保持不等于 `n` 核心变量保持。
2. 到达海岸只是位置与目标壳兑现，不是安全承载成立。
3. 地堡拥有大量食物，只能证明资源与临时安全，不证明世界共同体恢复。
4. 儿子对老人和盗贼的同情是原则显影，不自动生成他们成为成员。
5. 陌生家庭一句邀请不自动证明成熟新共同体。

### 最近邻排除

- 亲属称谓 `x并z` ≠ 当前有效承载 `n`。
- 资源依赖 `x` ≠ 关系余温 `nz`。
- 保护原则 `zn` ≠ 父亲每一次风险决策 `zx`。
- 同路与共同危险 ≠ 新成员生成。
- 父亲死亡 ≠ 父子关系意义自动消失。
- 新家庭接收启动 ≠ 长期共同体已验证。

## 11. 整体拿掉测试

1. 拿掉生态资源枯竭与食人者结构，父子 n 不再被持续耗损，主链失去。
2. 拿掉临时补给，父亲更早死亡，承载保存时间显著缩短。
3. 拿掉父子既有成员关系，影片退化为普通任务护送，母型根本改变。
4. 拿掉儿子的原则差分，只剩父亲单向保护，结尾接收判断与关系转交会变薄。
5. 拿掉视觉与“火种”台词，只看分食、惩罚、照护、死亡与接收，链仍成立。
6. 换成病弱照护者带既有家庭成员穿越灾区，母型仍可迁移。

## 12. 反向测试

若写：

```text
父子 n 克 世界 xz
```

只能成立局部：父子互保降低失温、恐惧与短时漂流，却无法恢复生态、食物系统或公共安全。

若写：

```text
xz 克 zn
```

影片并不支持。父亲的行为变得更严厉，但他保护儿子的原则并未失去指导资格；儿子的非食人与同情原则也在危险中持续。危险改变的是实践、排序和他者边界，不是原则正确性被撤销。

若写：

```text
亲属身份 x并z 生 n
```

称谓本身不足。真正维持父子 n 的是持续分食、抱持、警戒、照护、回返与承担。

## 13. 动态链

```text
公共承载崩解，父子既有 n 进入移动保存
→ 生态 xz 与掠夺 xn 持续克制父亲路线 zx，并耗损父子承载能力
→ 父子以分食、警戒、抱持和共同移动局部 n 克 xz
→ 地堡、房屋和物资 x+n 暂时补回照护与停留能力
→ 父亲风险最小化与儿子非工具化原则持续分叉
→ 海岸目标壳失效，父亲疾病使保护源端耗尽
→ 父亲死亡后，父子 n 无法继续以原结构运行，但成员意义并未消失
→ 儿子以既有 zn/z 评估陌生家庭
→ 新家庭提供现实接收 n 候选
→ 既有成员保存完成承载转交，长期稳定仍待验证
```

感觉走向：

> 既有亲属互保 → 移动耗损 → 临时丰足 → 原则分叉 → 海岸落空 → 保护源耗尽 → 哀悼停留 → 承载转交。

## 15. 母型提炼

### M-020｜既有成员移动保存—承载耗损—原则分叉—源端耗尽—外部转交

```text
既有成员 n 已成立
→ 公共承载崩解，成员进入移动保存
→ xz/xn 持续消耗资源、路线和照护能力
→ 临时 x+n 周期性补回运行变量
→ 成员内部不同 zn/zx 路线发生分叉
→ 核心保护者身体与决定接口耗尽
→ 被保护者转为接收判断主体
→ 外部家庭/共同体提供新 n 接口
→ 原成员意义保持，现实承载发生转交
```

- **适合题材**：灾难迁徙、病弱照护者、亲属逃亡、儿童转介、濒危小队。
- **主要观感**：持续互保、资源耗损、原则摩擦、保护者衰竭、苦涩交接。
- **失败版**：只有亲属称谓与共同移动，没有真实照护；或保护者死亡后对象被任意接管。
- **不适用边界**：任务对象原本不是成员、后期才成员化的影片，应使用 M-019 子型。
- **第二部待验证影片**：《釜山行》（2016）。

### UM-02 分叉建议


## 16. 结论门槛

- **主链置信度**：96%。
- **可锁定节点**：父子既有 `n`；临时 `x+n` 局部补回承载运行；生态 `xz` 与掠夺 `xn` 克制父亲移动 `zx`；父亲死亡属于源端耗尽；新家庭接收属于承载启动候选。
- **未判定节点**：陌生家庭是否形成跨阶段成熟 `n`；儿子 `zn` 是否直接生出新承载；UM-02A/B 是否应正式拆分。
- **是否更新母型**：新增 M-020；UM-02 提出 A/B 分叉。
- **是否需要用户确认**：否，材料足够形成候选母型与红线，不涉及核心定义分歧。
- **下一部影片/问题**：《釜山行》（2016）；检验既有父女关系、车厢固定承载、移动群体互保、感染身份壳与外部接收是否复现 M-020。
