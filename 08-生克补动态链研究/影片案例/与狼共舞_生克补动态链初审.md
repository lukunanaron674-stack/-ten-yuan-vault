# 《与狼共舞》（1990）生克补动态链审计

> 本轮问题：自愿边疆停留、语言与生活学习、爱情关系、苏族营地承载、成员身份与美国军方制度脱钩如何分层；检验 M-016 是否跨题材复现，以及 M-015/M-016 是否需要上位合并。

## 1. 结论摘要

```text
前哨、武器、马匹、补给、土地、军装与翻译接口 = x
→ 美国军官、孤立士兵、部落客人、翻译者、成员候选与“与狼共舞”身份 = x并z
→ 军事派驻、巡逻、补给、翻译、狩猎、迁营、准入与战争动员 = xn
→ 前哨只提供低关系密度工具性 n；苏族营地逐步提供住所、食物、语言关系、互保、家庭位置与反复返回的关系性 n
→ 美国军方 xn 通过派驻、身份、巡逻与后续清剿持续克制邓巴/苏族 zx
→ 邓巴主动停留、学习和协助首先是状态、x/xn 学习与允许条件，不等于成员身份或原则已生成
→ 在离开营地、可返回军队身份且面临惩罚时，邓巴仍拒绝向军方交出部落信息，并返回承担，新的 zn 跨场景显影
→ 苏族 n 为“部落客人/成员候选”壳补入真实内部；但爱情、取名和服装只作桥接，不能独立证明完整成员本体
→ 军方 zx 击穿前哨与成员安全，并迫使部落迁移；邓巴最终离开部落是为降低追捕对共同体的可达性，不等于成员关系被撤销
```

核心贡献：

1. **自愿停留不等于成员吸纳**：邓巴主动留在边疆，只证明旧路线暂时空置与新接触可能；成员身份需另证住所、互保、责任、准入与反复返回。
2. **语言和爱情不是承载替代品**：语言学习属于 `x/xn`，爱情属于关系支链；它们可提高识别与进入概率，却不能替代共同体对成员的真实接收和负荷承担。
3. **原则内化仍需离开承载环境复测**：邓巴被军方俘获后拒绝提供部落路线，并在获救后继续承担，才提高新 `zn` 的纯度。
4. **离开共同体可以是保护承载**：结尾离开并非退出成员身份，而是减少追捕对营地的可达性；需区分关系撤回、位置离开与 `n` 的风险隔离。
5. **M-016跨题材复现，但入口不同**：本片不是敌方俘虏进入，而是旧制度边缘主体主动停留后被地方共同体接收，形成 M-017。

## 4. 开场稳定结构

- 邓巴掌握军人身体、枪械、马匹和前哨接口 `x`，并拥有美国军官身份壳 `x并z`。
- 派驻与补给将其接入军方 `xn`；前哨仅提供低密度工具性 `n`，缺少稳定成员关系和共同生活。
- 核心缺口不是“不够勇敢”，而是旧身份、现实生活与内部意义分离。
- 苏族营地已有成熟家庭、狩猎、迁营、互保和成员准入 `n+xn`。
- 不得从孤独、自杀式冲锋或主动留驻直接反推其已有稳定地方原则或缺失抽象归属。

## 6. 主克

### 美国军方 `xn克zx`

- **源端点**：派驻、身份登记、补给、巡逻、拘捕、翻译要求和清剿结构。
- **目标端点**：邓巴与苏族成员的公开决定有效性、土地与路线自决、情报拒绝和安全迁移。
- **被改变变量**：路线独立性、身份解释权、拒绝有效性、成员安全、迁移时间窗。
- **成立阶段**：前哨派驻至军方清剿跨阶段持续。
- **显影条件**：即使个别军官死亡或前哨空置，身份、命令和追捕仍能被后续部队重新调用。
- **拿掉测试**：拿掉军方派驻、登记、补给和清剿，只保留邓巴与苏族相遇，核心压缩显著下降。
- **反向测试**：邓巴一次拒供或离开不能让军方身份、巡逻和清剿结构整体停止。
- **置信度**：98%。

### 复合主克：军方 `zx克n`

军方拘捕、射杀与追击真实降低前哨/苏族共同体的成员保护、返回能力、迁移安全和结构抗崩。目标是现实承载 `n`，不是抽象“文化”。

## 7. 主补

### 苏族营地 `n补x并z` 候选

邓巴原有军官/孤立士兵壳具备公开角色，却缺少与新生活相符的真实内部。苏族营地逐步提供：

- 家庭和住所位置；
- 食物、劳动与狩猎分工；
- 语言关系与翻译位置；
- 成员互保与营救；
- 婚姻家庭和反复返回；
- 为共同体降低风险的责任。

被补变量是成员壳的内部位置、互保、返回、关系连续性和抗崩能力，不是抽象“爱情”或“自由”。

限制：爱情、共同敌人和军方威胁提高了迁移速度；完整成员本体仍不能从名字、服装或婚姻一次锁定。

**置信度：94%，未达95%。**

## 8. 主生

### 局部 `zn生n` 候选

邓巴形成“不再把苏族成员、土地和路线交还军方调用”的原则后：

- 拒绝提供情报；
- 承担惩罚；
- 获救后继续返回共同体；
- 最终主动离开以降低追捕风险。

这为部落成员保护和迁移安全补入一个新的承担位置，但苏族 `n` 在他加入前已成熟存在，因此不能写成他生出整个共同体。

**置信度：89%。**

### 身份桥接支链

“与狼共舞”名字、婚姻和部落服装属于高显影 `x并z/nz` 接口，可提高成员识别、关系归因和准入稳定度；不能独立生成稳定成员本体或共同体制度。

## 9. 正例、反例与最近邻

### 正例

1. 邓巴被军方俘获后仍拒绝交出苏族路线，且拒绝发生在离开营地、失去保护与可恢复军人身份的条件下，支持原则跨场景保持。
2. 苏族不仅教语言和狩猎，还提供家庭位置、营救、返回和迁移中的成员保护，支持关系性承载而非文化学习本身。
3. 邓巴最后离开部落是为降低追捕对营地的可达性，说明位置离开不等于成员关系撤回。

### 反例

1. 学会苏族语言、穿部落服装或获得新名字，只提高技能与可识别性，不等于完整身份生成。
2. 与“站立舞拳”相爱和结婚是 `nz/n/x并z` 支链，不独立证明共同体吸纳或原则内化。
3. 主动留在前哨只是路线选择和允许条件，不等于已经脱离军方制度或加入苏族。
4. 苏族营救邓巴不等于军方制度被克，只恢复一个成员的安全和返回位置。
5. 草原、野牛和狼的视觉意象只作显影，不是命运、自由或本体端点。

### 最近邻

- `x/xn` 学习：语言、狩猎、翻译和迁营知识。
- `nz` 爱情与关系余温：提高家庭位置，不等于共同体整体承载。
- `x并z生z`：名字与成员壳提高确认接口。
- `n克xz`：营救和接回降低被俘危险。
- `zn克xn`：拒绝继续提供军方情报，降低自愿维护。
- 位置离开：可服务于保护承载，不等于退出身份。

## 14. 母型提炼

### M-017｜旧制度边缘—自愿停留—地方接收—原则复测—保护性离开

```text
旧制度 x并z/xn 将主体派往边缘位置
→ 工具性 n 与旧成员联系变薄
→ 主体自愿停留并打开地方接触
→ x/xn 学习提高互动但不生成成员
→ 地方 n 以家庭、劳动、互保和返回补入成员壳内部
→ 旧制度重新调用主体并要求其提供地方接口
→ 主体在离开地方承载后仍撤回旧维护资格
→ 地方共同体恢复成员保护
→ 主体为降低追捕可达性而离开位置
→ 成员关系保持，新制度与土地结果未完成
```

- **适合题材**：边疆、殖民驻地、跨文化接触、卧底转向、企业驻外。
- **主要观感**：孤独、谨慎接触、归属形成、旧制度反扑、苦涩保护。
- **失败版**：只靠爱情、名字、服装和自然美景完成“文化归化”。
- **不适用边界**：地方共同体只提供一次庇护，没有成员责任和反复返回；主体始终由旧制度命令留驻。
- **第二部待验证**：《烈日灼人》不合适；优先《最后的莫希干人》（1992）或《风中奇缘》作边界反例。

### 上位结构判断

M-015、M-016、M-017 共享：

```text
旧制度接口
→ 地方承载
→ 新成员位置
→ 旧维护撤回
```

但暂不合并：

- M-015 核心是身体借壳与身体/身份/承载对齐；
- M-016 核心是俘虏承载、文化原则内化与失败转交；
- M-017 核心是自愿停留、成员接收与保护性离开。

可新增上位候选 **UM-01：旧制度接口—地方承载—成员迁移—旧维护撤回**，只作索引，不取代三个子母型。
