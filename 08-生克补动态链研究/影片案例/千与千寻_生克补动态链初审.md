# 《千与千寻》生克补动态链审计

> 本轮先读取 `01-十元系统/001-概念的定义.md`，再读取十元生补克表。判断顺序为：先确定概念锚与端点，再判断生克补；不得先看剧情效果，再反向挑一个箭头。

## 1. 本轮结论摘要

此前口头母型：

```text
压缩 → 承载 → 回认 → 自生 → 反向夺回
```

经本轮重审后，修正为：

```text
规则限位 → 获得场内身份与承载接口 → 主体承载范围扩大 → 完成规则内通关与身份退出
```

暂定主链：

```text
xn 克 zx
→ n 补 x并z
→ zn 生 n
→ 规则通关／身份退出（不判正式克）
```

状态：`audit`。前三个节点可用于继续校准，但尚不能由单片锁定跨影片母型。

## 2. 十元概念预检

### 2.1 概念不是剧情标签

十元概念必须包含：

```text
z 的切分焦点
+ 被切分的 x 现象集合
+ 在位置关系网络中的十元锚
+ 生、克、补及体量
```

所以“规则”“帮助”“成长”“勇敢”“压迫”本身都不是充分端点。必须进一步判断它们在本片中落在哪个十元位置。

### 2.2 本片主要对象锚

| 对象 | 暂定十元锚 | 理由 | 不得混写 |
|---|---|---|---|
| 汤屋制度、工作流程、禁令、名字管理 | `xn` | 维护既有秩序、规定可做与不可做、压低越界决定 | 不等于抽象 `z`，也不等于汤婆婆个人全部权能 |
| 汤婆婆的最终决定接口 | `zx` 的占位者 | 她掌握录用、命名、处罚与放行的最终接口 | 她本人不是整套 `xn` 制度 |
| “千／小千”工作身份 | `x并z` | 可被组织识别、调用和安排的身份壳 | 不等于千寻完整本体 |
| 千寻的持续承诺与判断 | `zn` | 她对父母、白龙与自身名字的内部意义保持 | 不等于所有勇敢行为 |
| 对人、任务与关系的持续接纳和处理 | `n` | 不只一次帮助，而是让对象进入并被持续承担 | 不等于建筑、食物或普通资源 |
| 白龙、小玲、锅炉爷爷的帮助 | 多层支链 | 分别含信息、路径、保护、工作入口和关系确认 | 不能整体打包成一个“补” |

## 3. 九层对象分层

| 层级 | 影片表现 | 本轮判断 |
|---|---|---|
| 稳定本体 | 千寻并非无行动能力，而是进入陌生制度后没有合法接口 | 不把开场恐惧等同于 `x` 本体缺失 |
| 当前状态 | 害怕、迷路、父母异化、身体将消失 | 状态下降不自动判克 |
| 行为功能 | 求职、工作、救白龙、处理无脸男、识别父母 | 行为是端点显影，需要追查来源 |
| 光影 | 阴影、巨大汤屋、名字被抽走、列车空景 | 只作显影，不参与关系锁定 |
| 场景 | 汤屋、锅炉房、钱婆婆家、列车 | 场景变化不等于十元变化 |
| 时间关系 | 进入规则前、被纳入规则、掌握规则、离开规则 | 主链依赖阶段换挡 |
| 关系位置 | 无资格者→雇员→承担者→通过测试者 | 比“胆小变勇敢”更接近结构变化 |
| 显影 | 她从等待指令转为主动承担后果 | 支持 `zn 生 n`，但不自动支持 `zn 生 x` |
| 动态链 | 被限位、获得接口、扩大承载、完成退出 | 当前最稳的整体描述 |

## 4. 阶段节点

### 节点一：进入异世界后失去合法决定接口

- 阶段：进入汤屋之前至求职之前
- 源端点：汤屋既有制度、禁令、资格与工作流程 `xn`
- 目标端点：千寻作为新进入者的突破／最终决定接口 `zx`
- 候选关系：`xn 克 zx`
- 被改变变量：越界决定的有效性、公开决定资格、行动能否被制度承认
- 可观察结果：她不能凭个人意愿留下、取食、救父母或自由行动，必须先进入规则认可的职位
- 最近邻：陌生、害怕、信息不足
- 排除：即使拿掉恐惧，她仍缺少合法行动接口；规则不是单纯心理状态
- 证据等级：B+

**判定：主克候选成立。**

这里不是“规则克行动能力”。千寻仍会跑、问、拒绝和求助；真正被压低的是她的决定能否成为场内有效决定。

### 节点二：获得工作身份与最低承载接口

- 阶段：锅炉房、小玲引导、与汤婆婆签约
- 源端点：汤屋的实际承载结构、岗位、食宿与工作流程 `n`
- 目标端点：可被组织识别与调用的“千”之身份壳 `x并z`
- 候选关系：`n 补 x并z`
- 缺口：她此前没有场内可持续存在的身份接口，身体甚至开始消失
- 被补变量：被接纳、被调用、可留存、可持续参与规则的身份位置
- 可观察结果：她不再是随时会被清除的外来者，而成为能工作、被安排和累积经验的雇员
- 最近邻：普通求职成功、资源帮助、汤婆婆施加控制
- 限定：这个补只补“场内可存在的身份壳”，不补回真实名字，也不证明制度善意
- 证据等级：A-

**判定：主补成立，但它是带代价的补。**

这是本片重要结构：同一个制度一方面 `xn 克 zx`，另一方面其承载面 `n` 又补出 `x并z`。好搭配不要求对象全善或全恶，而允许同一系统在不同端点上同时限制与承载。

### 节点三：工作熟练与能力显影

- 阶段：腐烂神清洗、日常劳动
- 候选：`zn 生 x`
- 竞争解释：训练、信息、同伴协作、体力适应使既有能力显影
- 拿掉测试：拿掉明确原则表达，千寻仍可能因任务压力和协作完成工作
- 证据等级：C

**判定：不列为主生。**

她变得能干，不等于 `zn` 直接生成 `x`。此处主要是经验增长、熟练度和已有行动能力显影。

### 节点四：对无脸男、白龙和父母承担持续处理责任

- 阶段：中后段至高潮
- 源端点：千寻稳定保持的内部判断与承诺 `zn`
- 目标端点：允许对象进入、留存并持续处理其后果的承载 `n`
- 候选关系：`zn 生 n`
- 被改变变量：准入、留存、持续承担、对象不被一次性抛弃
- 可观察结果：她不是只做一次善举，而是连续处理白龙的伤、无脸男的失控、父母的解救与后续选择
- 最近邻：善良、冲动救人、剧情要求、同情
- 排除：她多次在没有即时奖励且会增加风险的情况下继续承担，并跨对象重复
- 限定：不表示她建立建筑、制度或成熟共同体，只表示承载边界被原则推出
- 证据等级：B+

**判定：主生成立，暂定为 `zn 生 n`，不是 `zn 生 x`。**

### 节点五：记回白龙名字

- 候选：关系确认、记忆恢复、`nz` 支链
- 最近邻：信息揭示、旧记忆回返、爱情／友情显影
- 判定：重要，但本轮不强行指定为主补

白龙、小玲、锅炉爷爷不是共同补一个变量：

- 锅炉爷爷主要提供求职入口和临时保护；
- 小玲主要提供路径、示范与日常协作；
- 白龙主要提供名字线索、关系确认与跨阶段回返。

它们构成不同支链，不能合并成“关系补回主角”。

### 节点六：识别父母并离开汤屋

- 候选旧判：`zn 克 z` 或主角反向克制汤屋
- 实际变化：完成测试、满足放行条件、退出“千”的身份壳并离开场域
- 汤屋制度是否失去核心功能：没有
- 汤婆婆决定接口是否被持续撤销：没有
- 规则是否在其他对象上继续有效：是
- 证据等级：A（支持规则通关／身份退出），X（不支持正式克）

**判定：结尾不是正式克。**

千寻赢得的是离开资格和真实身份回收，不是摧毁汤屋的规则、权能或成立资格。

## 5. 主克、主补、主生

### 主克

```text
xn 克 zx
```

汤屋秩序压低新进入者未经许可的决定有效性。

### 主补

```text
n 补 x并z
```

工作与承载结构补出千寻在场内可持续存在的身份接口，但同时带来名字被替换的代价。

### 主生

```text
zn 生 n
```

稳定承诺使千寻把多个对象纳入持续承担，而不是只完成一次性救助。

## 6. 两个反例节点

### 反例一：吃下白龙给的食物

它恢复身体可见性与状态，但更接近资源／状态恢复，不能自动判“白龙补千寻某一十元本体”。

### 反例二：腐烂神事件后获得认可和奖励

奖励与认可提高位置和信心，但不能由此判 `z 生 nz`、`zx 生 zn` 或任何核心生位；它可能只是结果反馈。

## 7. 整体拿掉测试

### 拿掉汤屋制度

若没有 `xn` 限位，求职、签约、工作身份与规则通关都失去必要性，影片主链大幅坍塌。主克为必要结构。

### 拿掉工作身份

千寻无法持续留在场内积累信息、关系与经验，后续承担链难以发生。主补提供真实中间接口。

### 拿掉千寻的持续承诺

即使保留熟练度和他人帮助，她也可能完成工作，却不会连续承担白龙、无脸男和父母的后果。主生不是普通能力成长。

## 8. 高潮反向测试

高潮没有出现：

```text
目标端核心变量持续下降
或
原规则成立资格被撤销
```

所以不得写“反向克制”。更准确的是：

```text
主体掌握规则
→ 通过规则测试
→ 取回真实身份
→ 退出场域
```

这是一种“通关—退出”，不是“反杀—摧毁”。

## 9. 搭配效果

| 标准 | 判断 |
|---|---|
| 因果清楚 | 较清楚：规则限位迫使她取得身份接口，身份接口提供持续行动阶段 |
| 缺口对应 | 主补精确补的是场内身份，不是笼统勇气 |
| 不跳步 | 有求职、工作、熟练、承担等多个中间阶段 |
| 有换挡 | 从被规则处理者，转为规则内工作者，再转为主动承担者 |
| 有代价 | 获得身份接口的同时失去真实名字 |
| 有反向 | 有主体性反转，但没有正式克制原制度 |
| 有余波 | 她离开场域，汤屋仍存在；主体变化与制度存续同时成立 |
| 可迁移 | 可与监狱、学校、军队、公司等“制度限位—身份接口—承担扩大”影片比较 |

## 10. 母型修正

原 M-001：

```text
压缩 → 承载 → 回认 → 自生 → 反向夺回
```

修正为两个候选母型：

### M-001A：制度限位—带代价纳入—内部承载扩大—通关退出

```text
xn 克 zx
→ n 补 x并z
→ zn 生 n
→ 条件满足／身份退出
```

### M-001B：回认支链

```text
名字被替换
→ 跨阶段关系保留真实称呼
→ 主体记忆与身份连续性增强
```

M-001B 暂不指定正式生克补，等待第二部影片比较。

## 11. 当前结论与置信度

- 主克 `xn 克 zx`：78%
- 主补 `n 补 x并z`：82%
- 主生 `zn 生 n`：74%
- 结尾不构成正式克：91%
- M-001A 仅为跨影片候选：65%

本片最重要的搭配发现不是“先被压迫、再变勇敢”，而是：

> 限制主体的制度，也可能提供主体继续存在所需的身份接口；成长发生在主体利用这个接口扩大自己的承担范围，而非直接摧毁制度。

## 12. 下一步

选取一部同样存在强制度场域、但结尾真正改变制度成立资格的影片，与本片做反差测试。优先候选：《飞越疯人院》。
