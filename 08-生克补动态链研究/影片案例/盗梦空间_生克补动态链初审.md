# 《盗梦空间》生克补动态链审计

## 1. 结论摘要

本片不能写成“团队友情生出规则，图腾确认现实，柯布靠爱走出梦境”。更稳定的链是：

```text
梦境设备、架构知识、镇静剂、对象记忆与层级接口被任务方实际掌握
→ x 生 x并z：各层梦境成为可进入、可调用、可维持的世界壳
→ 团队 n 承担分工、同步、保护与返回负荷
→ 为持续处理共同负荷提炼出时间比例、踢醒、音乐提示、角色分工与撤离流程，形成局部 n 生 xn
→ 各层 xn 同时维持任务，也会在投射、防御、重力变化与时间差中克制即时 zx
→ 柯布对梅尔投影的持续容纳，使私人记忆壳反复侵入公共任务
→ 临界中柯布撤回对该投影的继续承载与身份复制
→ 团队完成多层回收；主补未锁；结尾图腾只保留检测悬念，不自动证明现实或梦境
```

核心贡献：多人共同搭建世界时，`x 生 x并z` 与 `n 生 xn` 必须分工。前者解释“什么被实际掌握后形成可调用世界壳”；后者解释“共同体承担跨成员负荷后，为什么提炼出可重复运行的同步结构”。图腾是私人检测接口，只有落到明确认可主体与确认内容时才可能参与 `z`；它本身不是稳定 `z` 或公共 `x并z`。

## 3. 九层分层

| 层级 | 判断 |
|---|---|
| 稳定本体 | 柯布并非稳定 `nx`；他在任务上具有强 `zx/xn`，但在梅尔关系上持续把最终解释权让给过去 |
| 当前状态 | 怀念、恐惧、焦躁、希望与释然只作状态证据 |
| 行为功能 | 搭建、伪装、同步、隐瞒、投影侵入、坦白与撤回必须追踪端点和变量 |

| 场景 | 梦境层级不自动等于 `x并z`；需先证明实际掌握与可调用性 |
| 时间关系 | 招募→设计→进入→层级分裂→投影干扰→流程反噬→迷失域坦白→多层回收→结尾检测悬念 |
| 关系位置 | 柯布由把梅尔投影当作仍有指导资格的关系对象，转为承认其只是自己维持的壳 |
| 显影 | 团队撤场或流程失配时，各层世界迅速失去稳定，证明壳与结构依赖持续掌握和组织 |
| 动态链 | `x 生 x并z` 建世界；任务 `n 生 xn` 建同步流程；`xn 克 zx` 限制临场决定；私人余温/记忆壳侵入主链；高潮撤回旧壳并完成回收 |

## 5. 主生

### 主生一：`x 生 x并z`

设备、药剂、架构知识、目标信息与层级入口先被实际掌握，梦境才成为能被团队进入、修改和持续调用的世界壳。

- 直接生：是。
- 拿掉测试：拿掉共享设备、药剂、架构与对象信息，只保留想象，无法形成共同可调用世界。
- 置信度：97%。

### 主生二：局部 `n 生 xn`

团队真实承担跨层协作、保护、同步与回收负荷后，必须提炼音乐信号、踢醒、角色分工、时间节点和备用流程。

- 不是领袖单次命令。
- 只在共同负荷真实存在并跨层持续时成立。
- 置信度：92%。

两条主生并非竞争：`x 生 x并z` 解释世界壳，`n 生 xn` 解释团队如何让多层任务持续运行。

## 6. 主克

### 主克：多层 `xn 克 zx`

每层梦境都有时间比例、物理条件、投射防御、同步要求和退出窗口。临时显权必须进入既有层级结构，单次决定无法取消前置组织。

- 被改变变量：即时决定有效性、可用路径、回收窗口、跨层同步率。
- 拿掉测试：只保留敌人而无层级时间、重力、踢醒和投射规则，故事退化为普通追逐。
- 反向测试：团队 `zx` 可临时调整计划，但必须借既有 `xn` 才能跨层生效。
- 置信度：96%。

## 7. 主补

未锁定。

阿里阿德涅提供外部观察、追问、进入迷失域和协助回收，但同时混入：信息、专业能力、任务职责、关系承载和直接行动。她没有单独恢复一个已明确缺失的核心变量。

不写成“阿里阿德涅补回柯布面对过去的勇气”。拿掉她，柯布更可能继续隐瞒且任务更易崩坏；但这支持关键条件与结构纠错，不足以锁正式补。

## 8. 图腾判定

图腾首先是私人检测接口：

```text
主体掌握只有自己知道的物理细节
→ 通过异常反馈检查当前世界是否被他者构造
```

- 它邻近 `x`：私人掌握检测参数。
- 检测结果若落到明确“我确认当前世界状态”的主体与内容，才可能支持 `z`。
- 它不是公共身份壳，因此不默认是 `x并z`。
- 结尾检测未闭合，不能判“现实获得最终确认”。

## 9. 正例、反例与最近邻

### 正例

1. 亚瑟、阿里阿德涅、伊姆斯和优素福分别承担跨层任务，音乐与踢醒必须在不同时间比例中联动，支持任务 `n 生 xn`。
2. 柯布在迷失域承认投影只是自己保存的版本，并不再沿其要求留下，旧壳对其指导覆盖下降。
3. 设备、镇静剂与架构撤掉后，共享梦境无法维持，支持 `x 生 x并z`。

### 反例

1. 城市折叠：视觉显影，不单独证明 `x 生 x并z`。
2. 团队成员坐在一起：共现，不等于 `n` 已形成。
3. 陀螺旋转：检测动作，不自动等于 `z` 已确认现实。
4. 柯布说“放下”：台词不等于旧壳覆盖已下降，必须看其是否拒绝继续留在投影世界。
5. 任务成功：结果，不证明主补已经成立。

### 最近邻

- 单纯 `xn` 规划不足以解释梦境壳生成，壳需实际掌握 `x`。
- 单纯 `x` 掌握不足以解释多人同步，持续运行需任务 `n` 提炼 `xn`。
- 梅尔投影不是稳定 `nz` 本人，而是私人 `x并z` 壳承载关系余温。
- 图腾不是自动认可 `z`；检测接口与确认结果必须分开。
- 柯布退出迷失域不等于整个梦境技术或任务制度被克。

## 10. 整体拿掉测试

1. 拿掉设备、药剂与架构掌握，多层共同世界不成立。
2. 拿掉团队承载，只留柯布命令，跨层同步和高压回收率显著下降。
3. 拿掉时间比例、踢醒与层级规则，主克退化为普通敌对。
4. 拿掉阿里阿德涅，秘密更晚暴露，但不能由此反推正式补。
5. 拿掉梅尔投影，任务主线更顺，但柯布私人动态链和高潮撤回消失。
6. 拿掉陀螺画面，只看柯布是否离开投影并回到孩子身边，私人旧壳撤回仍成立；现实确认悬念则消失。

## 11. 动态链与感觉

```text
实际掌握梦境接口
→ 多层世界壳形成
→ 团队承担共同负荷
→ 同步结构被提炼
→ 多层规则持续限制即时决定
→ 私人记忆壳侵入公共任务
→ 隐瞒导致共同承载受损
→ 临界倒计时迫使最终决定公开
→ 主体撤回旧投影的指导资格
→ 团队完成多层回收
→ 检测悬置，家庭回返完成但现实确认未闭合
```

感觉：专业掌控→奇观游戏→层层加压→私人秘密污染→团队失衡→临界同步→告别旧壳→回返释然→现实悬置。

## 12. 母型 M-007

### 多人造界—共同负荷提炼同步—私人旧壳污染—临界回收

```text
x 生 x并z：实际掌握生成临时世界壳
→ n 生 xn：共同负荷生成同步与回收结构
→ xn 克 zx：多层结构限制临场决定
→ 私人关系余温寄居于旧 x并z 壳并污染公共任务
→ xz 生 zx：最后窗口迫使决定生效
→ 主体撤回旧壳指导资格
→ 团队回收，现实检测保持开放
```

- 适合：梦境、虚拟副本、复杂行动、多人潜入、灾难救援。
- 主要观感：专业快感、结构压迫、私人秘密反噬、同步高潮、余韵悬置。
- 失败版：把团队同框当 `n`，把计划当 `n 生 xn`，把图腾当现实真理。
- 第二部待验证：《信条》或多人副本型作品。
- 状态：candidate。

- 未锁：主补、图腾的固定十元本体、整体 `zn 克 xn`。
