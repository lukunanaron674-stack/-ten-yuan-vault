# 《最后的莫希干人》（1992）生克补动态链审计

> 本轮问题：爱情、战争同盟、临时护送、堡垒与移动亲族承载、身份迁移和保护性离开如何分层；检验 M-017 的失败版，并继续验证 UM-01 的跨入口稳定性。

## 1. 结论摘要

```text
堡垒、步枪、火药、独木舟、土地、补给、山路与瀑布通道 = x
→ 英军军官、殖民民兵、边民、莫希干亲族、被护送者、俘虏与战争同盟角色 = x并z
→ 征召、围城、守备、停战、护送、追捕、部落复仇与俘虏处置 = xn
→ 威廉亨利堡提供高体量工具性 n；钦加哥、恩卡斯与鹰眼的移动亲族提供低人数高互保 n
→ 英军 xn 以征召、守备与拒绝民兵回乡持续克制殖民者 zx
→ 法军围城和休伦追击通过 xn 生 xz，把补给、撤离和救援窗口持续压窄
→ 移动亲族 n 多次克制 xz，为科拉、爱丽丝与邓肯提供可移动保护和返回路线
→ 爱情与战争同盟提高关系重量和互救意愿，但没有生成完整地方成员迁移
→ 瀑布离开是战术性风险撤离：离开被保护者以保存救援能力，不是保护共同体 n 的成员离场
→ 结局只完成幸存关系与亲族残存；没有形成 M-017 式“地方承载吸纳—旧制度维护撤回—成员保持”
```

核心贡献：

1. **战争同盟不等于共同体吸纳**：共同作战、共同逃亡和互救可以形成高强度临时协作，却不自动提供住所、劳动位置、跨阶段成员责任和反复返回。
2. **爱情不能替代成员迁移**：鹰眼与科拉的关系能提高互救和回返重量，但不能证明科拉已经进入莫希干亲族的稳定成员壳。
3. **保护性离开需要明确保护对象和变量**：瀑布离开主要保存鹰眼等人的生存与后续救援能力；它不是通过主体离开来降低追捕对既有共同体的可达性，因此不同于《与狼共舞》结尾。
4. **移动亲族可以构成真实 n**：人数少、无固定营地不妨碍承载成立；关键是持续互保、救援、路线知识、成员责任与返回，而不是建筑规模。
5. **本片是 M-017 的失败/邻接版**：具备旧制度冲突、地方关系和离场复测，却缺少外来者被地方共同体跨阶段吸纳的完整过程。

## 4. 开场稳定结构

- 鹰眼、钦加哥和恩卡斯掌握山林路线、武器、狩猎与独木舟接口 `x`，并形成低人数但成熟的亲族 `n+x并z`。
- 英军以殖民战争征召、守备和堡垒体系 `xn` 调用殖民民兵与军官身份壳。
- 科拉与爱丽丝拥有军官家庭身份和堡垒准入，却缺少边地路线掌握与移动承载。
- 核心缺口不是“缺爱情”，而是帝国守备结构无法同时保护堡垒、边民家庭和撤离路线。
- 不得从鹰眼独立行动直接反推 `nx` 缺失，也不得从科拉被救直接反推成员吸纳。

## 6. 主克

### 6.1 英军 `xn 克 zx`

- 关系双方：英军征召、守备与军令结构 → 殖民民兵、鹰眼及平民的地方决定接口。
- 被改变变量：回乡有效性、家庭保护、离堡权限、公开拒绝、路线独立性。
- 成立阶段：民兵家庭受袭信息出现后，堡垒仍拒绝其离开；鹰眼帮助离堡后被拘押。
- 拿掉测试：拿掉征召与军令，只保留法军围城，民兵与鹰眼可自行组织家庭保护，主克显著下降。
- 反向测试：鹰眼帮助少数民兵离开只降低局部执行，不使征召和守备结构整体停止。
- 置信度：98%。

### 6.2 休伦/战争 `zx 克 n`

伏击、追击和俘虏处置真实降低堡垒撤离队伍与移动亲族的成员保护、返回和抗崩能力。目标是具体承载，不是抽象文明。

## 7. 主补

**不锁定成熟主补。**

最强候选是移动亲族 `n 补 x并z`：鹰眼、钦加哥与恩卡斯使科拉等人的“被护送者/战争同盟”角色获得真实路线、保护、营救与回返内部。

但该壳高度临时，科拉未被展示为承担亲族劳动、长期成员责任、稳定住所或跨阶段返回；爱情与共同敌人又强烈参与。因此只保留：

```text
移动亲族 n
→ 为临时护送/战争同盟壳补入真实保护内部
```

置信度：89%，不锁成员迁移。

## 8. 主生

### `xz 生 zx`：路线临界生成临时决定接口

瀑布洞穴中火药耗尽、退路减少、追兵逼近，原有护送结构无法继续。危险制造公开决定空位，鹰眼亲族作出“暂时离开—保存行动能力—回返营救”的临时决定。

- 新生目标此前不足：没有可执行的继续固守方案。
- 核心净增量：临时决策接口、救援路线和承担主体明确。
- 类型：正式关系的低体量状态/关系位置调用。
- 跨阶段保持：随后真实回返追击，排除纯口号。
- 不生成稳定领导本体，也不证明离开本身保护了一个成熟共同体。

置信度：96%。

## 9. 支链与换挡

- 支链1：移动亲族 `n 克 xz`，多次把被护送者从开放危险路径接入可移动保护。
- 支链2：鹰眼低体量 `zn 克 xn`，撤回对强制征召和以边民为可替换资源的维护。
- 中段换挡：堡垒工具性 `n` 从保护容器转为围城陷阱，主线从守备转为移动撤离。
- 高潮反向：鹰眼等由被追捕者转为追击营救的源端；危险不再只压缩他们，也生成临时救援权能。
- 结局余波：亲族 `n` 严重受损，爱情关系保留，但没有展示新共同体与新制度。

## 10. 正例、反例与最近邻

### 正例节点

1. 民兵有明确家庭保护路线，仍被堡垒军令拒绝离开，支持 `xn克zx`，不是普通意见冲突。
2. 鹰眼亲族在无合同、无军饷条件下反复护送、回返和营救，支持移动亲族 `n` 与 `n克xz`。
3. 瀑布离开后真实回返营救，支持 `xz生zx` 的临时决定接口，而非抛弃。

### 反例节点

1. 鹰眼与科拉相爱：关系 `nz/n` 增厚，不证明科拉已被亲族完整吸纳。
2. 共同逃亡：共现与同一路线，不自动生成共同体。
3. 邓肯替死：一次极端承担不自动生成成熟承载或爱情本体。
4. 鹰眼穿边地服装、会山林技能：`x/x并z` 显影，不是身份迁移过程。
5. 英军投降：战役节点，不等于帝国战争制度整体被克。
6. 钦加哥杀死马瓜：复仇权能完成，不等于休伦结构或殖民战争终止。

### 最近邻排除

- 爱情 `nz`：提高回返与救援重量，不替代共同体成员承载。
- 临时护送 `xn/n`：有明确任务和路线，未必形成稳定成员位置。
- 战争同盟 `x并z/xn`：共同敌人与协作身份，不等于亲族吸纳。
- `n克xz`：真实保护和路线提供，与 `n补x并z` 的成员内部补位分开。
- `xz生zx`：危险只生成临时决定接口，不生成稳定领导或道德正确性。

## 11. 整体拿掉测试

1. 拿掉英军征召与军令，民兵家庭路线可自行生效，主克显著下降。
2. 拿掉鹰眼亲族的路线知识、互保与回返，科拉等人的存活和逃离路径显著下降。
3. 拿掉爱情线，护送、军令冲突、围城、伏击与营救主链仍成立；只降低科拉与鹰眼的关系重量。
4. 拿掉瀑布离开后的真实回返，该节点会退化为逃生或抛弃，不能判 `xz生zx` 的承担接口。
5. 拿掉视觉与配乐，只看军令、路线、保护、回返和成员损失，主链仍成立。
6. 换成被围城市、撤离车队或灾难护送题材，母型仍可迁移。

## 12. 反向测试

若要写“科拉进入莫希干共同体”，必须看到住所、劳动、亲族责任、准入、跨阶段互保和反复返回。影片仅展示爱情、护送、共同危险与结局幸存，不足。

若要写“瀑布离开是 M-017 式保护性离开”，必须证明离开降低追捕对一个既有共同体 `n` 的可达性，并保持成员身份。本片离开主要是保存行动能力、避免全员被俘并准备回救，保护对象是被护送者与救援任务，而非通过离场隔离共同体风险。

若要写“鹰眼 `zx` 克英军 `xn`”，必须看到征召、守备和军令跨阶段停止。影片没有。

```text
→ 没有完成外来者成员迁移或新制度建立
```

感觉：边地自由 → 帝国征召 → 堡垒压迫 → 撤离失序 → 山林追逃 → 战术分离 → 极端互救 → 亲族断裂 → 苦涩幸存。

## 15. 母型提炼

### M-018｜堡垒失效—移动护送—战争同盟—战术离开—回返营救

```text
高体量工具承载 n 在围城 xn 中失效
→ 被保护者进入移动危险 xz
→ 小型亲族/队伍 n 以路线、互保和武器接管护送
→ 爱情与战争同盟提高关系重量，但不完成成员吸纳
→ 路线和资源临界使 xz 生出临时 zx
→ 战术离开保存行动能力
→ 回返营救复测承担
→ 队伍承载遭受不可逆成员损失
→ 幸存关系保持，新共同体未成立
```

- 适合题材：围城撤离、灾难护送、逃亡队伍、战争爱情。
- 主要观感：压迫、速度、互救、牺牲、苦涩幸存。
- 失败版：把共同逃亡、爱情和一次营救直接写成成员吸纳；把战术离开写成背叛或保护共同体。
- 不适用边界：外来者已被地方共同体跨阶段接收，或离开确实通过降低追踪保护成熟共同体时，应优先检查 M-017。
- 第二部待验证：《人类之子》（2006）。

### 对 UM-01 的判断

本片不构成 UM-01 的第四个稳定正例，而是邻接/失败版：旧制度冲突成立，地方移动亲族也真实承载，但科拉没有完成成员迁移，鹰眼也不是从旧制度成员转入新共同体；爱情和战争同盟承担了大部分关系显影。

因此 UM-01 继续保持 `upper-candidate`，并新增失败边界：

```text
共同逃亡 + 爱情 + 战争同盟
≠ 地方承载完成成员迁移
```

## 16. 结论门槛

- 主链置信度：95%。
- 可锁定节点：英军 `xn克zx`；移动亲族 `n克xz`；瀑布阶段低体量 `xz生zx`。
- 未判定节点：移动亲族是否构成 `n补x并z` 的成熟成员补位；科拉是否发生身份迁移；邓肯替代承担是否形成局部 `zn生n`。
- 母型：新增 M-018 candidate；UM-01 保留上位候选并补失败边界。
- 无需用户确认：当前是证据边界清楚，不存在定义分歧。
