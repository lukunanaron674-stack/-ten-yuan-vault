# 《火星救援》（2015）生克补动态链审计

> 本轮问题：孤立成员、基地资源与地球团队在没有单次爆裂核心的情况下，是否复现M-024；临时救援程序何时扩展为跨阶段持续承载。

## 1. 结论摘要

```text
Hab、食物、水、氧气设备、火星车、Pathfinder、MAV、补给火箭、轨道与通信设备 = x
→ Watney、Hermes机组、NASA管理者、JPL工程师、轨道与通信团队 = x并z
→ 农业生产、生命保障、通信恢复、补给规划、轨道计算、发射、救援与舱外协作 = xn
→ Hab独居承载、地球远程支持、Hermes移动共同体与最后回收接口 = 不同成熟度n
→ 修复、种植、制水、长途驾驶、抛载、轨道改线与舱外捕获 = 局部zx
→ 不放弃成员、成员失联后仍承担回收责任 = zn候选
→ 孤立、食物倒计时、Hab破裂、通信中断、火星距离、发射窗口与轨道错失 = 高体量xz
→ Watney是否存活、农业是否可持续、补给窗口与Rich Purnell轨道是否可行 = z
```

核心结论：

1. **主克是长期环境与距离 `xz` 克制孤立承载 `n/zx`**：火星环境、食物与水的消耗、通信延迟、Hab破裂和发射窗口持续压缩Watney的可停留时间、路线、照护连续性和现场决定有效性。
2. **主补是跨地证据组织 `xn补z`**：卫星影像、Pathfinder通信、农业数据、轨道计算、模拟、发射与Hermes反馈，使“Watney活着”“粮食能维持多久”“哪条救援轨道可行”获得可复核确认。
3. **主生是孤立成员的真实承载负荷 `n生xn`**：Watney长期真实依赖Hab，持续呼吸、饮水、进食、排泄、种植、维护和移动，负荷被提炼成农业、制水、配给、通信、长途迁移与回收程序。
4. **本片不是M-024简单复制**：它没有单一爆裂先击穿成熟系统；开场撤离和失联先造成成员孤立，随后多次局部失效不断迫使程序升级。
5. **临时救援程序只有在跨阶段接住同一成员时才靠近持续承载**：单次发射、一次通信或一个轨道方案只是接口；农业、通信、补给、迁移和回收连续衔接，才形成地球—火星—Hermes分布式技术承载。
6. **新增M-025**：任务撤离—孤立成员自维持—通信复连—跨地承载扩张—补给失败—原成员回返—动态捕获。
7. **UM-03获得第二部独立技术题材支持，但需拆分入口**：阿波罗13号是核心接口爆裂型；火星救援是成员失联与时间性耗损型。

## 6. 主克

### 长期环境与距离 `xz` 克制孤立承载 `n/zx`

- **关系双方**：火星环境、资源耗尽、距离与窗口，对Watney的Hab承载、现场路线和回收决定。
- **源端点**：高体量`xz`，表现为食物、水、氧气、密封、通信与发射窗口持续缩窄。
- **目标端点**：Hab条件性`n`、Watney现场`zx`与地球/机组回收接口。
- **被改变变量**：安全停留时间、资源余量、通信带宽、路线数量、现场决定执行率、成员可达性。
- **成立阶段**：撤离后直至最终捕获，且Hab破裂和补给失败造成二次加压。
- **显影条件**：资源账本、作物周期、通信中断、距离、窗口和轨道差值可观察。
- **拿掉测试**：若移除长期距离和资源倒计时，只留下单次受伤，Watney可等待普通回收，不需农业、Pathfinder、补给与Hermes回返链。
- **反向测试**：Hab、远程支持与Hermes只能局部`n克xz`，不能消除火星生态与星际距离。
- **为什么不是普通阻碍**：它跨全片持续改变承载和执行资格，并迫使每轮方案围绕同一组资源与窗口重写。

置信度：98%。

## 7. 主补

### 跨地证据组织 `xn补z`

- **缺口原先如何成立**：地球最初无法确认Watney存活；随后也无法仅凭愿望确认农业、补给、轨道和回收方案可行。
- **补的来源**：卫星影像比较、Pathfinder双向通信、日志与生存数据、工程模拟、轨道计算、发射测试和Hermes反馈。
- **被补核心变量**：存活归因、资源余量可信度、方案复现度、轨道可行性、成员回收概率。
- **是否只是帮助、资源或时间恢复**：不是。设备与人员只是允许条件；只有数据—计算—模拟—反馈闭环才补`z`。
- **拿掉补源后的差异**：没有证据闭环，地球不能确认Watney状态，Hermes也不能承担可计算回返。
- **为什么对应主克缺口**：主克使资源与窗口不可见、不可控；`xn补z`把不可见状态转成可判断、可传递方案。

置信度：97%。

## 8. 主生

### 孤立成员真实承载负荷 `n生xn`

- **新生目标此前是否不存在或不足**：Ares 3没有为单人多年滞留准备农业循环、长期制水、Pathfinder通信、长途火星车迁移和动态轨道回收程序。
- **源是否提供核心变量净增量**：Watney真实居住、呼吸、饮水、进食、排泄、受伤、种植和移动，跨阶段重复形成负荷。
- **类型**：直接生；NASA/Hermes专业能力与设备是允许条件。
- **第三因素**：植物学与工程训练、Hab库存、地球计算能力。
- **首次显影**：Watney计算剩余食物并把Hab改造成种植环境。
- **跨阶段保持**：农业、通信、补给、迁移和回收持续升级，不是一次临时动作。

置信度：96%。

## 9. 支链与换挡

- **支链1：Hab `n克xz`**：住所、氧气、水与初始食物降低立即死亡和漂流，但属于条件性承载。
- **支链2：局部破裂 `zx克n`**：气闸破裂直接击穿密封与农业承载，证明固定设施库存不等于持续承载。
- **中段换挡**：Watney由完全孤立执行者转为地球远程支持下的现场验证者；NASA由搜索主体转为持续承载的一部分。
- **高潮反向关系**：Hermes移动共同体`n`通过改线、减速和舱外捕获局部克制Watney的轨道漂流`xz`。
- **主角何时从目标端转为源端**：Watney在恢复通信后不只是危险目标，也持续提供现场数据、修正方案和执行反馈，成为`xn补z`闭环中的源。

## 10. 正例、反例与最近邻

### 正例节点

1. Watney根据人口、储粮、作物周期和水需求建立农业与配给流程；持续居住负荷生出程序，而不是抽象“求生欲”。
2. Pathfinder从旧设备`x`经修复、编码和双方反馈成为通信链，使存活与方案获得可复核确认。
3. Rich Purnell轨道计算只有经过NASA/Hermes讨论、资源约束和机组执行才进入现实，清楚区分计算`xn`、确认`z`与改线`zx`。
4. Hermes回返不是重新生成成员关系，而是既有成员共同体在任务目标失败后仍承担真实返回。

### 反例节点

1. 土豆发芽只是农业流程显影，不是“希望生承载”。
2. NASA媒体宣布Watney存活只形成公开壳与传播，不等于补给和回收承载已经成立。
3. 补给火箭发射是执行动作，爆炸证明未通过完整程序验证，不能把忙碌写成`xn补z`。
4. 中国推进器是资源`x`，不会自动生成轨道方案或国际共同体。
5. 最终捕获是局部回收结果，不等于火星任务制度永久无风险。

### 最近邻排除

- 设备与库存`x` ≠ 持续承载`n`。
- 存活身份壳`x并z` ≠ 存活确认`z`。
- 单次通信 ≠ 跨阶段远程承载。
- 现场修复`zx` ≠ 稳定专业本体新生。
- 时间紧迫`xz` ≠ 程序`xn`自动生成。
- 公众关注与媒体传播 ≠ 成员接收。
- Hermes同行与回返 ≠ 新成员吸纳；成员关系开场已成立。

## 11. 整体拿掉测试

1. 拿掉长期环境、距离和资源倒计时：故事退化为单次失联等待回收，农业和跨地程序不成立。
2. 拿掉Hab、库存和车辆：Watney失去最小`n/x`，无法形成跨阶段程序。
3. 拿掉Watney真实居住负荷：农业、配给、通信和迁移程序不再有持续源。
4. 拿掉卫星、Pathfinder、模拟和轨道计算：地球只剩愿望与猜测，无法形成确认。
5. 拿掉Hermes成员关系：最终回返只能由外部指令或新队伍解释，原成员共同体复测消失。
6. 拿掉视觉、音乐和媒体镜头：资源、通信、轨道和执行链仍成立。
7. 替换为极地站、深海基地、远洋孤岛或远程医疗，母型仍可迁移。
