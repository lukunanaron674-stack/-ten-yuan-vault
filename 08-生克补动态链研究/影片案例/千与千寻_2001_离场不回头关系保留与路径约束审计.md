# 《千与千寻》离场不回头｜关系保留与路径约束动态链审计

## A. 启动信息

- 影片：《千与千寻》（2001）
- 分析范围：千寻离开隧道前被告知不要回头，沿既定路径离场并回到现实的连续片段
- 分析粒度：C级单片段
- 动态类型：维持 + 转换
- 本轮问题：分清路径与规则`xn`、方向外置`nx`、对象关系保留`nz`与现实回返`n`，避免把服从禁令直接写成关系维系。

## B. 对象层、主体、阶段与端点

| 项目 | 判断 |
|---|---|
| 对象层 | 行为功能层、关系层、现实场景层 |
| 主体 | 千寻为行动主体；白龙提供离场指令；父母与现实环境构成回返承载 |
| 阶段1 | 异界出口前，离场规则被明确 |
| 阶段2 | 千寻背向异界沿通道前进，不回头 |
| 阶段3 | 穿过隧道，回到现实家庭与车辆环境 |
| 源端点1 | 明确的离场路径与“不回头”执行规则：`xn` |
| 源端点2 | 被白龙外置并由千寻承接的前进方向：`nx` |
| 目标端点1 | 与白龙及异界对象的关系记忆和对象特异位置保留：`nz` |
| 目标端点2 | 父母、车辆、现实道路重新成为行动承载：`n` |

## C. 唯一核心变量

**离场后，千寻是否仍能保持“继续向现实前进”的行动方向，同时不把与异界对象的关系保留误写成即时互动。**

初始状态：方向需要由白龙明确外置，现实承载尚未重新接通。

终态：千寻完成现实回返，行动方向已被执行；与异界的关系位置以记忆和对象特异性保留，但没有继续发生即时互动。

## D. 直接边与条件

### 直接补边 D-01

```text
明确离场路径与“不回头”规则 xn
补
千寻继续前进的外置方向 nx 所缺的可执行接口
```

- 关系性质：直接补边。
- 目标缺口：千寻知道要离开，但缺少“如何离开且不中断”的具体执行接口。
- 补入变量：路径、动作限制、连续执行条件。
- 条件：规则必须对应真实出口路径，并由千寻实际执行；单独一句禁令不构成补。
- 拿掉：拿掉路径与规则，方向仍可能存在，但缺乏可执行连续性。
- 反向：`nx补xn`不如本解释，方向并未生成规则结构。

### 条件边 D-02

```text
现实家庭与道路承载 n
作为
方向完成和现实回返稳定的落地条件
```

`n`使离场结果落到现实生活，但不生成与白龙的对象特异关系，也不证明关系持续互动。

### 关系保留判断 D-03

```text
对象特异记忆与关系位置 nz
在现实回返 n 后维持
```

这是跨场景维持，不登记为`n生nz`或`xn生nz`。片段只证明关系位置未被现实回返自动抹除，不证明关系继续运行。

## E. 正式失败边

### F-01

```text
✕ 遵守“不回头”规则 xn → 生成或维系对象关系 nz
```

看似成立：不回头与白龙的嘱托绑定。

失败原因：规则只改变离场执行方式；拿掉对象身份后，同类路径禁令仍可成立。最近邻应判为`xn补nx执行接口`。

### F-02

```text
✕ 现实回返 n → 克制或消除异界关系 nz
```

失败原因：回到现实改变承载场景，不等于对象特异关系被否认。关系由即时互动转为记忆与位置保留。

### F-03

```text
✕ 保留记忆 nz → 已保证未来重逢或持续互动
```

失败原因：片段没有未来互动证据。关系保留不等于关系接口持续开放。

## F. 拿掉、反向与竞争解释

- 拿掉“不回头”规则：千寻仍可能希望回到现实，但路径连续性与执行稳定显著下降，支持`xn补nx`。
- 拿掉现实家庭与道路：方向可以完成到出口附近，但不能形成现实回返落地，支持`n`为承载条件。
- 拿掉白龙的对象特异身份：路径规则仍成立，说明`xn`不是由`nz`生成。
- 反向测试：`nx生xn`不足，因为方向意愿不会自行产生具体通道规则。
- 竞争解释1：纯粹勇气成长。可解释情绪，却不能解释规则为何直接改善执行接口。
- 竞争解释2：单纯服从。描述行为表面，不解释方向、关系保留和现实回返如何分账。
- 竞争解释3：仪式禁忌。可作为文化外壳，但不是本轮核心变量的最短机制。

## G. 具体动态链

```text
白龙外置离场方向 nx
→ 明确路径与“不回头”规则 xn 补 方向执行接口 nx
→ 千寻持续前进并穿过隧道
→ 现实家庭与道路承载 n 接住回返结果
→ 与白龙及异界对象的关系位置 nz 以记忆形式维持，而非即时互动
```

字母链：

```text
xn补nx → n承载回返 → nz跨场景维持
```

- 直接关系边：`xn补nx`。
- 条件节点：现实承载`n`。
- 维持节点：对象特异关系位置`nz`。
- 失败边：`xn生nz`、`n克nz`、`nz保证未来互动`。
- 总体效果：方向被规则接口稳定执行，现实回返完成，关系由现场互动转换为记忆保留。

## H. 搭配效果与顺序效果

- 搭配效果：`xn + nx + n + nz`形成“规则接口稳定方向、现实承载接住结果、关系位置不被场景切换抹除”的组合。
- 顺序效果：必须先有方向外置，再由规则提供执行接口，随后现实承载落地；若先把`nz`写成规则结果，会把情感关系误当成服从奖励。
- 动态类型：维持中的承载转换。
- 母型累计：新增“路径规则补方向执行接口，现实回返不必消除对象关系”的具体C级候选1；不提升为锁定母型。
