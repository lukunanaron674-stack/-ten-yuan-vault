# 《最后的莫希干人》（1992）生克补动态链审计

> 本轮问题：爱情、战争同盟、临时护送、堡垒与地方承载、成员身份迁移如何分层；检验 M-017 的失败版，并继续验证 UM-01 是否能跨入口稳定。

## 1. 结论摘要

```text
武器、堡垒、独木舟、路线、补给、土地与俘虏通道 = x
→ 英军军官、殖民地民兵、边民、护送者、莫希干成员、休伦战士与恋人身份 = x并z
→ 征召、围城、防务、撤离、护送、俘虏分配与部落战争规则 = xn
→ 威廉亨利堡提供高体量工具性 n；鹰眼—钦加哥—恩卡斯的小型同行体提供低体量关系性 n；影片没有展示科拉被完整吸纳进莫希干共同体
→ 英法殖民战争 xn 克制边民、军官、护送者和原住民的 zx
→ 围城、撤离与休伦追击持续生出 xz
→ 鹰眼与科拉的爱情提高 nz 与局部互保，但不能替代成员接收、共同劳动、长期住所、准入和反复返回
→ 鹰眼多次护送、营救和追随首先是 zx/nz/n 行动，不等于科拉完成身份迁移
→ 恩卡斯追击爱丽丝并战死，爱丽丝跳崖，形成爱情/亲缘与 xz 的悲剧支链；不能写成共同体 n 成熟或保护性离开
→ 钦加哥最后击杀马瓜完成复仇与成员保护回收，但战争结构和族群承载并未重建
```

核心贡献：

1. **爱情护送不等于共同体吸纳**：科拉与鹰眼建立高强度关系，但影片没有提供她进入莫希干共同体所需的住所、劳动、准入、互保、责任和反复返回。
2. **战争同盟不等于成员身份迁移**：鹰眼、钦加哥、恩卡斯与英军/殖民者短时协作，主要由围城、撤离和共同敌人驱动。
3. **保护性离开需要保护共同体变量**：本片多数离开是撤离、追击、爱情逃亡或风险规避；没有像《与狼共舞》那样通过离开降低追踪对成熟共同体的可达性。
4. **M-017 的失败版成立**：有爱情、护送、共同危险和离场，却缺地方共同体对外来者的完整接收，也缺离场后的成员关系保持。
5. **UM-01 不能仅靠跨文化爱情扩张**：若没有真实地方承载与旧制度维护撤回，不能纳入“成员迁移”上位母型。

## 4. 开场稳定结构

- 鹰眼、钦加哥、恩卡斯掌握边疆路线、武器、狩猎和小队互保 `x+n`，并拥有莫希干家庭/成员壳 `x并z`。
- 科拉与爱丽丝属于英军家庭和殖民军保护体系 `x并z+n/xn`。
- 民兵征召、堡垒防务和英法战争形成高体量 `xn`，持续压缩边民和军官的自主路线。
- 核心缺口不是“科拉缺少爱情”，而是战争结构使任何私人决定都难以稳定生效。
- 不得从鹰眼救人、科拉被吸引或三人同行直接反推共同体吸纳。

## 6. 主克

### 殖民战争 `xn 克 zx`

- 关系双方：英法殖民战争、民兵征召、堡垒防务、投降撤离与休伦俘虏结构，对鹰眼、民兵、科拉姐妹和莫希干小队的具体决定。
- 被改变变量：拒绝征召有效性、家庭保护路线、撤离时间窗、俘虏解释权、私人关系决定能否进入现实。
- 成立阶段：征召争议、围城、投降撤离、俘虏议事。
- 显影条件：个体有明确替代路线，却被跨阶段规则、身份和军事组织压回既定通道。
- 拿掉测试：拿掉征召、堡垒、围城、投降和俘虏规则，只保留马瓜个人追杀，主链退化为私人复仇追逐。
- 反向测试：鹰眼多次救人和突破节点，没有使殖民战争、征召和俘虏结构跨阶段停止。
- 为什么是主克：它持续改变所有角色的路线和决定有效性，不只是一次敌人阻碍。

置信度：98%。

## 7. 主补

**未锁定。**

最强局部补位是莫希干小队的低体量关系性 `n` 对科拉姐妹的 `xz`：提供带路、互保、营救和回返承诺，降低危险可达性。

但它没有补出科拉的完整成员壳：

- 没有长期住所和劳动分工；
- 没有共同体准入程序；
- 没有跨阶段返回位置；
- 没有在战争结束后持续承担成员负荷；
- 关系主要围绕护送、爱情和共同危险。

因此只能判：

```text
低体量同行 n 克 xz / 支持关系停靠
```

不能判成熟 `n 补 x并z`。

## 8. 主生

**未锁定。**

### 爱情 `z/nz` 不生共同体成员 `n/x并z`

鹰眼和科拉形成明确互认与回返承诺，但源提供的是特定关系对象、情感重量和互保动机。它没有为科拉生成莫希干共同体的成员准入、住所、劳动、共同责任和公共身份。

### 局部 `zn 生 n` 候选

鹰眼、蒙卡姆和钦加哥在代价节点上为具体成员保护提供新增承担位置，但这些行为发生在已经存在的小队/亲缘/军人关系中，更像既有 `n` 的高强度显影与维护，不足以证明新 `n` 生成。

## 9. 支链与换挡

- 支链1：鹰眼—科拉 `z/nz` 形成明确回返对象，提高护送和营救的关系重量。
- 支链2：恩卡斯—爱丽丝的关系只有低信息量显影，最终被 `xz` 与马瓜 `zx` 截断，不能反推成熟爱情或成员承载。
- 中段换挡：堡垒围城由工具性安全 `n` 转为封闭风险容器，`xn生xz` 超过 `n克xz`。
- 高潮反向：小队从被制度追赶的目标端转为主动营救源端，但只能改变局部处置和追击结果。
- 主角何时从目标端转为源端：鹰眼拒绝服从堡垒路线并持续追踪科拉时。

## 10. 正例、反例与最近邻

### 正例节点

1. 鹰眼三人反复带路、营救、回返，真实降低科拉姐妹的危险可达性，支持低体量 `n克xz`。
2. 民兵家庭遭袭后仍被军方要求守堡，证明殖民 `xn` 持续压低私人家庭保护决定的有效性。
3. 休伦议事能够重新定义俘虏用途，说明身份壳与战争程序共同克制个体 `zx`。

### 反例节点

1. 鹰眼与科拉相爱：只证明 `z/nz` 和关系互保，不证明科拉被莫希干共同体吸纳。
2. 一路同行和共同战斗：共同危险与临时同盟，不证明成熟 `n`。
3. 瀑布分离：“待在这里，我会回来”是回返承诺，不是保护成熟共同体的离场。
4. 恩卡斯为爱丽丝战死：悲剧结果与亲缘/爱情显影，不证明新共同体或稳定成员本体生成。
5. 钦加哥击杀马瓜：复仇与局部保护回收，不等于族群承载、土地或制度恢复。

### 最近邻排除

- 爱情 `nz`：提高回返意愿，不等于共同体 `n`。
- 护送 `zx+n`：降低危险，不等于身份迁移。
- 战争同盟 `xn/n`：共同敌人驱动，不等于无任务条件下的成员接收。
- 俘虏身份 `x并z`：被某结构重新分类，不等于主动加入。
- 保护性离开：必须真实降低对成熟共同体的追踪可达性；本片多数离开只是撤离或分离。

## 11. 整体拿掉测试

1. 拿掉殖民征召、堡垒围城、投降和俘虏规则，主克大幅下降。
2. 拿掉鹰眼—科拉爱情，护送、殖民战争和莫希干亲缘主线仍成立；说明爱情不是共同体承载的必要源。
3. 拿掉莫希干小队的反复营救，只保留爱情台词，科拉无法获得同等安全路径，证明关系承载有现实变量。
4. 拿掉视觉、配乐、瀑布和悬崖，只看行为与关系位置，仍只能确认护送、爱情、俘虏和亲缘悲剧，不能确认成员迁移。
5. 换成战区记者、地方向导与被护送平民，母型仍可迁移。

## 12. 反向测试

若写“科拉加入莫希干共同体”，必须看到：

- 战争任务结束后仍有住所与返回；
- 无爱情条件下仍被成员接收；
- 承担共同劳动与成员责任；
- 通过地方准入并被第三方持续调用为成员。

影片没有这些证据。

若写“鹰眼 `zx` 克殖民 `xn`”，必须看到征召、堡垒、投降、俘虏与殖民战争结构跨阶段下降。影片只显示局部突破。

若写“保护性离开”，必须证明离开降低追踪对一个已成熟共同体 `n` 的可达性，同时成员关系保持。本片瀑布分离主要保护科拉个体，不是保护共同体。

## 13. 动态链

```text

→ 休伦俘虏结构重新定义人物用途
→ 亲缘、爱情和复仇在悬崖追击中发生悲剧回收
→ 钦加哥完成局部复仇，殖民战争、地方承载与成员迁移均未解决
```

感觉走向：

> 边疆自主 → 军事征召 → 临时安全 → 围城窒息 → 爱情互认 → 撤离崩解 → 俘虏再分类 → 亲缘追击 → 悲剧回收 → 空旷余生。

## 15. 母型提炼

### M-017F｜战争护送—爱情互认—共同危险—成员吸纳失败

```text
高体量战争 xn 压缩私人 zx
→ 地方向导/小队以低体量 n 降低个体 xz
→ 爱情 z/nz 提高回返与互保动机
→ 共同危险和同盟持续升级
→ 外来者未获得住所、劳动、准入、成员责任和跨阶段返回
→ 保护性离开退化为撤离/个体营救
→ 亲缘与爱情在高体量 xz 中悲剧回收
→ 共同体成员迁移未完成
```

- 适合题材：战争护送、战区爱情、地方向导、临时同盟。
- 主要观感：宏大、窒息、炽烈、悲壮、不可归属。
- 失败版：把爱情、共同敌人和同行误写成完整成员吸纳。
- 不适用边界：影片已展示长期住所、成员准入、劳动、互保和反复返回。
- 第二部待验证：《新世界》（2005）。

### 对 UM-01 的结论

本片不进入 UM-01 正向支持集，而作为**边界负例**：

```text
旧制度/战争接口
→ 地方护送与爱情
≠ 地方承载完成
≠ 成员迁移
≠ 旧维护撤回
```

因此 UM-01 的必要条件进一步收紧：必须有真实地方 `n` 接收和离场后的旧制度维护撤回，爱情与临时同盟均不足。

## 16. 结论门槛

- 主链置信度：95%。
- 可锁定节点：殖民战争 `xn克zx`；围城/撤离 `xn生xz`；小队低体量 `n克xz`。
- 未判定节点：科拉是否形成任何稳定地方成员身份；爱情是否有共同体之外的长期承载；恩卡斯—爱丽丝关系厚度。
- 更新母型：新增 M-017F 作为 M-017 的失败版/边界负例；UM-01 不升级为锁定。
- 是否需要用户确认：否。当前是证据边界，不是定义分歧。
- 下一影片：《新世界》（2005）；下一问题：爱情与殖民定居如何分层，真实地方承载能否在跨文化亲密关系之外成立。
