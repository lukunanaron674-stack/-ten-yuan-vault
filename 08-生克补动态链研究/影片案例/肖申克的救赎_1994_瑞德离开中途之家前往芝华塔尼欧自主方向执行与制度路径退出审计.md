# 《肖申克的救赎》｜瑞德离开中途之家前往芝华塔尼欧：自主方向执行与制度路径退出审计

## 1. 对象层、主体与阶段

- 对象层：主体方向执行与外部制度路径退出的交接层。
- 主体：瑞德。
- 阶段：安迪指引已补入方向缺口 → 瑞德离开中途之家并踏上前往芝华塔尼欧的路线 → 原有假释、岗位与许可路径不再主导当前行动。
- 源端点：`nx`，瑞德已经恢复并开始持续执行的自主未来方向。
- 次端点：`xn`，此前组织瑞德行动的假释、工作、许可与中途之家制度路径。
- 唯一核心变量：瑞德当前行动接口是否从“由制度路径组织”转为“由自己选择并持续执行的芝华塔尼欧方向组织”。

## 2. 主次十元

- 主十元：`nx`。真正发生阶段变化的是瑞德对未来方向的占用度，由恢复状态转为持续执行。
- 次十元：`xn`。制度路径此前持续组织工作、住宿和许可节点，本片段中退出当前行动的主导位，但并未被证明遭到削弱或消失。

## 4. 直接生克补边

```text
direct_edge: none
```

本片段证明的是既有`nx`从恢复转入执行，以及`xn`退出当前主导位。没有证据证明`nx`新生成`xn`、克制`xn`，或补足`xn`缺口；也没有证据证明`xn`在本片段中新生成、克制或补足`nx`。

## 5. 成立条件

1. `nx`必须在前一片段已经获得具体目的地、资源和行动入口。
2. 瑞德必须实际离开中途之家并进入前往芝华塔尼欧的连续行动，而非只产生愿望。
3. 当前目的地与行动顺序必须由瑞德接受并执行的自主方向组织，而非主管、假释官或岗位许可现场给定。
4. `xn`退出只表示不再主导当前行动接口，不等于制度结构被摧毁、削弱或不存在。
5. 交通工具和地理移动只能作为行动证据，不能直接判成新的十元端点。

## 6. 正式失败边


```text
xn ──克──▶ nx
失败：瑞德已经离开原有制度路径并持续执行自主方向，当前没有制度压力直接降低其方向占用度。

```

```text

失败：移动只是`nx`执行后的外显证据，不是方向端点的生成源。
```

## 7. 拿掉、反向与竞争解释

- 拿掉实际离开与持续前往行为，只剩“准备去”的意图，不能证明`nx`已从恢复转入执行。
- 拿掉前一片段补入的目的地和入口，本片段行动链失去可执行方向，无法单独成立。
- 反向写成`xn退出生nx`会把条件退出误作目标生成；`nx`在前片段已经恢复。
- 竞争解释“只是交通移动”无法解释为何瑞德主动离开既有制度生活并持续朝具体未来目的地推进。
- 竞争解释“nx克xn”过强，无法解释制度仍可能客观存在，只是不再组织此刻行动。
