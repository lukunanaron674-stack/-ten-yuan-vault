# 《活埋》（2010）｜棺木封闭空腔与锁闭耗氧多位置边界审计

## 1. 片段与事实范围

Paul Conroy在伊拉克遭袭后醒来，发现自己被绑架者锁在木棺中并埋入地下。棺内有手机、打火机、笔、药物等有限资源；手机被用于勒索与对外求救。随着电量、空气和结构稳定度下降，外部定位与营救未能及时抵达。

本轮只审计“醒来—联络—耗氧—外部营救失败”的封闭棺木片段。恐惧、希望、求生意志、死亡和最终未获救均不直接作为十元端点。

## 2. 对象分层

```text
总体环境：地下掩埋、无自主出口、空气与时间窗持续缩窄
局部对象：同一口木棺的内部空腔、板壁、棺盖与锁闭接口
资源对象：手机、电量、打火机、笔、药物、酒与有限空气
外部程序：绑架勒索程序、政府/救援联络与定位程序
主体程序：拨号、信息确认、节省资源、尝试破坏与等待
```

## 6. 核心边界：同一棺木的`n+xz`多位置分账

```text
同一口木棺
├─ n：提供内部身体位置，并暂时隔离周围泥土直接压入
└─ xz：锁闭、无自主出口、有限空气、结构破裂与救援时间窗持续缩窄
```

两者改变的变量不同：

- `n`只降低“泥土立即压入、身体无内部位置”的危险；
- `xz`主导“无法离开、空气耗尽、难以定位、结构最终失效”的总体处境。

因此本案既不能写成“棺木能躺，所以是纯承载”，也不能写成“棺木用于杀人，所以从未有任何承载变量”。同一对象可在不同切分焦点下同时落位；但总体动态图以高体量`xz`为主导。

## 8. 正例、反例与最近邻

### 正例

1. 棺板真实维持内部空腔并隔离直接土压，因此存在低体量`n克xz_A`。
2. 绑架者的持续程序直接制造锁闭、无出口、位置隐匿和耗氧时间窗，成立`xn生xz`。
3. 对电话号码、位置线索、空气、电量和救援进展的确认改变了拨号与资源分配程序，成立`z补xn`。

### 反例

- “人在盒子里面”不足以判`n`；若盒体不隔离任何危险，只固定身体，则优先判困陷状态。
- 手机和空气是`x`资源，不是棺木承载本身。
- 等待和求救不是天然`xn`，必须证明跨阶段对象、顺序和节点被组织。
- 最终死亡不能倒证棺木从未提供过短时土压隔离；同样也不能把短时隔离夸大成总体安全承载。

### 最近邻

- 对照《127小时》：峡谷脚点只让身体暂稳，未隔离核心危险，因此`n`排除；本案棺板确实隔离了直接土压，故存在最小`n`。
- 对照《隧道》：车厢与空腔还能承担碎石冲击并允许跨日停留，`n`体量更高；本案棺木同时是主动拘禁装置，`xz`更强且持续主导。
- 对照《阿波罗13号》：登月舱承载降低多组核心危险；本案棺木只降低一组直接土压危险，不能类比救生承载。

## 9. 拿掉、换序与反向测试

1. 拿掉棺板与内部空腔，只保留地下泥土，直接土压与立即压埋显著上升，证明低体量`n克xz_A`成立。
2. 拿掉锁闭与掩埋，只保留木棺空腔，总体无出口与耗氧临界显著下降，证明`xz`不是由“内部位置”自动生成。
3. 拿掉绑架者的持续程序，只保留一次袭击，无法解释棺木、电话、勒索、位置隐匿和时间窗为何被组织成同一困陷结构。
4. 拿掉阶段确认，只保留手机资源，拨号、节电和行动顺序会失去对象与阈值。
5. 反向写成`xz克n`不能完整解释本案：总体临界最终会使空腔失效，但前段低体量承载与后段耗氧临界在很长阶段并行，不是简单单边替代。
6. 最终未获救不能倒证外部救援程序从未启动，只能证明定位与到达链最终断裂。

## 10. 搭配效果与后验结构

搭配效果：**“最低限度被接住，同时被彻底困死”**。`n`与`xz`并行，使空间既保持生命短暂延续，又持续压缩所有离开可能，形成强烈的封闭悖论感。

新增后验边界候选：

```text
R-MIG-09｜强制封闭空间的最小承载—主导困陷并存
同一封闭对象真实提供内部位置并隔离一类直接危险 n
+ 同一对象/外部程序同时制造无出口、耗氧或时间窗缩窄 xz
+ n只降低局部变量，xz主导总体处境
= n+xz多位置并存
≠ 纯承载
≠ 纯困陷
≠ 严格位置迁移
```
