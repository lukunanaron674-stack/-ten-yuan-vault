# 《肖申克的救赎》｜瑞德抵达芝华塔尼欧与安迪重逢：关系承诺兑现与方向完成审计

## 1. 对象层、主体与核心变量

- 对象层：自主方向完成与对象特异关系现场兑现的阶段交接层。
- 主体：瑞德。
- 连续片段：瑞德抵达海岸，看见正在修船的安迪，双方确认彼此并奔向对方拥抱。
- 唯一核心变量：瑞德此前由安迪承诺与指引组织的未来方向，是否在抵达对象并现场重逢后完成搜索阶段；同时，跨缺席保留的关系承诺是否转为双方可见、可回应的现场关系。
- 场景排除：海滩、海水、船只、奔跑和拥抱都是事实证据或动作，不直接构成十元端点。

## 2. 阶段对子

### 阶段A｜抵达前仍在完成方向

- 主十元：`nx`，体量 `8`。
- 次十元：`nz`，体量 `6`。
- 对象层：具体目的地执行与跨缺席关系承诺保留。
- 对子内部关系：`none`。前片段存在`nz补nx`候选来源，但本片段起点只登记既有共同在场，不重复制造新补边。
- 体量依据：影响范围为个人未来方向与一段核心关系；持续时间跨阶段；抵达前仍可因未找到对象而失败，故不可逆程度为高成本但未完全闭合。

### 阶段B｜重逢后方向完成、关系兑现

- 主十元：`nz`，体量 `9`。
- 次十元：`nx`，体量 `3`。
- 对象层：对象特异关系由跨缺席保留转为现场双方关系；原方向只保留低占用的后续生活接口。
- 对子内部关系：`none`。现场兑现与搜索阶段结束是阶段迁移，不等于`nz生nx`、`nx生nz`或新的补关系。
- 体量依据：影响范围仍是关系与个人未来；持续时间由跨缺席保留转为可持续现场关系；重逢事实已发生，搜索阶段基本不可逆地结束。

## 4. 触发、被改变变量与成立条件

- 触发事件：瑞德实际抵达海岸并看见安迪；安迪也看见瑞德，双方奔向彼此并拥抱。
- 被改变变量：是否仍需继续搜索具体对象，以及关系是否仍只能靠缺席中的承诺和记忆维持。
- 成立条件：
  1. 前片段的具体目的地与行动链已经真实执行，而非幻想或旁白愿望；
  2. 瑞德实际找到安迪本人，不是只到达地理地点；
  3. 双方都有可观察的识别与回应，不能只有单方远望；
  4. 搜索阶段因对象抵达而结束，不能仅因交通停止或到海边而判定完成；
  5. `nz`必须保持对象特异性，不能把“美好结局”“自由”“希望”直接当成关系端点。

## 5. 拿掉、反向、最近邻与第三因素

- 拿掉安迪本人，只保留瑞德到达海滩和船只，`nx`只能证明抵达地点，不能证明具体对象方向完成，也不能证明`nz`现场兑现。
- 拿掉双方识别和回应，只保留瑞德单方看见安迪，关系仍未完成现场双向确认。
- 拿掉前片段的目的地、资源与行动入口，当前抵达会失去连续方向来源，不能单独倒推出此前`nx`如何成立。
- 反向检验：若双方重逢后再次分离，已发生的现场兑现事实不会被抹除，但`nz`后续持续度可下降；这说明本片段锁定的是阶段完成，不是永久关系保证。
- 最近邻：到达地理地点、交通终止、情绪释放、希望实现、自由显影、结局蒙太奇。
- 第三因素：剪辑省略途中过程、海岸景观、安迪修船、配乐、旁白、拥抱动作强度。它们增强可见性和情绪，但不能替代对象抵达与双方回应。
- 竞争解释A“只是地理到达”无法解释为何搜索变量在看见安迪并双方会合后才归零。
- 竞争解释B“只是情绪高潮”无法解释对象特异关系从缺席保留转为现场双方关系的位置变化。
- 竞争解释C“nz生成nx”失败，因为具体方向在更早片段已经形成并执行，本片段只让其完成并退出高占用。


```text

失败：场景物与动作只是关系兑现的证据，不能作为关系端点的生成源。
```
