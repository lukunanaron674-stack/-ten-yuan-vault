# 《釜山行》（2016）生克补动态链审计

> 本轮问题：父女关系在开场只有稳定亲属壳、但现实承载不足时，列车封闭空间、感染传播、乘客互保与群体排斥如何改变父女 `n`；石宇死亡后秀安如何完成保护源端换挡与外部接收，并复测 M-020 与 UM-02B。

## 1. 结论摘要

```text
列车、车厢、车门、玻璃门、武器、食物、手机、轨道、机车、隧道与安全站 = x
→ 父亲、女儿、孕妇、丈夫、乘客、感染者、军人、列车员 = x并z
→ 列车运行、车厢封锁、感染传播、检疫、乘客排斥、军方识别与通行处置 = xn
→ 父女关系、尚华夫妇、临时移动互保组、孕妇对秀安的接收 = 不同成熟度的 n
→ 感染逼近、车门失守、路线缩窄、车站陷落、机车时间窗与被咬倒计时 = 高体量 xz
→ 石宇、尚华等人的开门、断后、改线、营救与交接 = 局部 zx
→ 不把他人纯粹当风险或工具、保护成员、在失去收益后仍承担 = zn候选
→ 开场父女只有稳定亲属壳与关系意义，石宇的现实照护长期不足；危机中父女n由低效转为真实运行，随后发生源端耗尽与孕妇接收
```

核心贡献：

1. **亲属壳已成立，不等于成员承载已成熟**：石宇是秀安父亲，但开场缺席演出、以工作和物品替代陪伴，父女 `x并z` 稳定，现实 `n` 却低效。
2. **封闭工具承载可迅速反转为危险放大器**：列车能提供移动、门、座位和路线，但感染进入后，车厢封锁、乘客排斥与线路失控使工具性 `n` 变成 `xz/xn` 放大器。
3. **移动互保不是“大家一起逃”**：尚华、石宇、乞丐、成景与秀安跨车厢承担开路、断后、遮挡、照护和回返，形成短时高密度 `n`。
4. **排斥型群体不是共同体**：有秩序、有多数、有门禁的安全车厢，若通过牺牲外部成员维护自己，首先是排斥 `xn/x`，不是成熟 `n`。
5. **保护源端耗尽后发生双重转交**：石宇被咬后把路线、刹车和秀安交给成景；成景提供持续照护，军方因秀安歌声完成“非感染者”确认并停止射击，外部接收才开始。

## 4. 开场稳定结构

- 父女 `x并z` 与关系意义已经成立，但石宇长期缺席，父女 `n` 的陪伴、倾听、共同时间和情绪接收不足。
- 石宇拥有工作、资金、手机、车票与路线安排 `x/xn`，但这些资源不能替代成员承载。
- 秀安并非“任务对象”；她从开场就是成员，只是保护者的现实承担不充分。
- 列车在开场是高体量工具性 `n/xn`：提供座位、路线、门禁和驾驶；感染进入后才逐步反转。
- 不得把石宇最终牺牲写成一次性生成父女关系；更准确的是危机跨节点补实原本低效的成员承担。

## 6. 主克

### 6.1 感染传播与封闭列车 `xn/xz` 克制乘客 `zx/n`

- **源端点**：感染通过咬伤、车厢连接、人员流动持续复制；列车运行把成员锁在有限路线。
- **目标端点**：乘客的移动、停留、开门、营救与车厢保护能力。
- **被改变变量**：安全车厢数量、可用门、路线宽度、停留时间、成员保护、决定执行率。
- **成立阶段**：感染者进入列车后持续到机车逃生。
- **显影条件**：门被突破、车站失效、轨道受阻、隧道与时间窗缩窄。
- **拿掉测试**：拿掉封闭列车，只保留开放城市感染，车厢间路线与门禁主链消失；拿掉感染，只保留列车运行，工具承载仍可正常工作。
- **反向测试**：移动互保组的 `n/zx` 只能局部克制感染 `xz`，不能终止感染传播结构。
- **为什么不是普通阻碍**：感染与列车路线持续跨阶段重写所有人物可用空间和保护条件。

置信度：98%。

### 6.2 群体排斥 `xn/x` 克制移动互保 `n/zx`

安全车厢通过闭门、驱逐与“可能感染”的身份读取维持自身。它有多数、有秩序、有内部，却把外部成员当作可牺牲风险，因此属于排斥型 `xn/x`，并真实降低移动组的准入、互信与保护连续性。

置信度：97%。

## 7. 主补

### 父女成员承载由低效转为真实运行

- **原缺口**：石宇虽有父亲壳和资源，却缺席秀安的演出与日常情绪位置。
- **补源**：跨阶段路线承担、回返营救、听取秀安对他人的要求、将自己置于感染与女儿之间、最终交接。
- **被补变量**：共同时间、真实保护、情绪接收、成员优先级、可依赖的返回位置。
- **不是普通帮助**：石宇在工作收益、个人安全和路线便利下降后仍继续承担，且承担落到同一成员关系。
- **拿掉补源**：只保留车票、礼物和父亲称谓，父女关系仍可指认，但承载缺口不恢复。
- **与主克对应**：感染不断耗损路线与保护，石宇的连续承担补的是父女 `n` 的现实运行，不是抽象父爱。

这更接近“既有亲属壳下，低效成员承载被危机中的持续承担补实”，而不是资源或危险直接生成亲情。

置信度：96%。

## 8. 主生

### 高体量 `xz` 生出临时救援 `zx`

- 原来不存在稳定共同领导；石宇甚至倾向先自保。
- 感染、门失守和路线减少不断制造决定空位。
- 石宇、尚华和乞丐在不同阶段获得临时开路、断后与交接接口。
- 这是状态层/关系位置层 `xz生zx`，第三因素包括身体能力、门和路线知识。
- 首次显影：跨车厢营救。
- 跨阶段保持：只持续到各自源端耗尽，不形成稳定制度领导。

置信度：97%。

## 9. 支链与换挡

- **支链1**：移动互保 `n克xz`，通过开路、遮挡、断后与回返降低危险直接到达成员的比例。
- **支链2**：感染者/未感染者身份壳 `x并z` 经乘客或军方确认形成 `z`，进而改变开门或射击。
- **中段换挡**：安全车厢从工具承载候选转为排斥结构；移动互保组反而承担真实成员保护。
- **高潮反向**：石宇从掌握资源但缺席的父亲，转为主动撤掉自身位置以隔离感染风险。
- **主角换端**：秀安从被保护对象转为发出确认信号、参与外部接收判断的主体。

## 10. 正例、反例与最近邻

### 正例

1. 尚华在门口断后并把成景与未出生孩子交托给石宇，明确改变成员保护与交接变量。
2. 石宇被咬后传授刹车、把秀安交给成景并离开驾驶室，属于源端耗尽前的现实承载转交。
3. 成景持续抱持、带领秀安进入隧道，证明她从被保护孕妇换挡为新保护者。
4. 秀安歌唱使军方确认两人具有人类身份并停止射击，支持 `x并z生z` 与局部执行下降。

### 反例

1. 石宇买礼物和车票：资源与路线安排，不等于成员承载成熟。
2. 乘客集中在安全车厢：同处内部不等于共同体，排斥机制可使其成为伪 `n`。
3. 尚华、乞丐和石宇死亡：牺牲结果不自动生成 `zn/n`，必须观察交接与成员保护。
4. 到达釜山隧道：位置到达不等于安全共同体已经成立。
5. 秀安歌唱：确认接口，不是“希望克感染/战争”。
6. 感染者停止在黑暗中行动：生理机制与条件变化，不是 `n克xz`。

### 最近邻

- 亲属 `x并z` ≠ 有效成员承载 `n`；
- 同车、同敌、共同逃亡 ≠ 移动共同体；
- 多数内部与门禁 `xn/x` ≠ 共同体 `n`；
- 牺牲 `zx/zn` ≠ 自动生成承载；
- 歌声与身份确认 `z` ≠ 制度整体被克；
- 保护者死亡 ≠ 成员意义删除；
- 外部军方接引 ≠ 成熟新 `n`。

## 11. 整体拿掉测试

1. 拿掉感染传播，只保留父女旅行，父女缺口仍在，但不会形成移动互保、排斥与源端耗尽链。
2. 拿掉父女开场疏离，石宇的变化只剩既有承载保存，M-021 的“低效补实”段消失。
3. 拿掉尚华、成景和乞丐，石宇会退化为单一英雄护送，移动群体 `n` 无法成立。
4. 拿掉安全车厢排斥，移动互保组的成员边界与伪共同体反例明显变薄。
5. 拿掉石宇被咬后的交接，父女关系只得到牺牲结算，没有现实保护转移。
6. 拿掉秀安歌唱，只保留到达隧道，军方可能按感染者射击，外部确认接口消失。
7. 拿掉视觉、哭声和配乐，只看开门、断后、驱逐、回返、交接与停止射击，主链仍成立。
8. 将题材换成封闭船舶、灾难航班或撤离巴士，母型可迁移。

## 12. 反向测试

### 父女 `n 克感染 xz`

只能局部成立：父女与移动互保能降低危险直接落到成员的比例、延长路线与时间，却不能停止感染传播。

### 感染 `xz 克 zn`

不成立。危险没有使石宇持续认定保护秀安错误，也没有使秀安放弃对他者的成员判断；变化主要落在行动接口、风险排序与承载承担。

### 父亲壳 `x并z 生 n`

不成立。父亲称谓、车票和礼物必须由实际倾听、回返、保护与交接填充，才形成有效承载。

### 军方 `n` 接收秀安与成景

只到启动候选。军方停止射击并接引，证明确认与通行开始；影片未展示医疗、住所、长期保护与成员维持。

- **适合题材**：封闭交通灾难、撤离船舶、航班事故、家庭疏离与公共危机。

### UM-02B 修正
