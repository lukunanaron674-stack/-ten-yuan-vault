# 《千与千寻》现实出口后短暂停步｜关系记忆保留与现实承载接续动态链审计

## A. 启动信息

- 影片：《千与千寻》（2001）
- 分析范围：千寻穿出隧道，重新进入父母、车辆与现实道路环境，并在离开前短暂停步的连续片段
- 分析粒度：C级单片段
- 动态类型：承载转换后的维持
- 本轮问题：现实承载`n`如何接续已经完成的方向`nx`，以及对象特异关系记忆`nz`是否只被保留而没有重新开放即时互动接口。

## B. 对象层、主体、阶段与端点

| 项目 | 判断 |
|---|---|
| 对象层 | 现实场景层、行动完成层、关系记忆层 |
| 主体 | 千寻为感知与行动主体；父母、车辆和道路构成现实承载；白龙与异界对象只以关系记忆位置存在 |
| 阶段1 | 千寻已经完成穿越隧道与离场方向执行 |
| 阶段2 | 父母、车辆和现实道路重新成为当前行动环境 |
| 阶段3 | 千寻短暂停步，异界关系位置仍保留，但没有新互动发生 |
| 源端点1 | 已完成的离场方向与行动结果：`nx`完成态 |
| 源端点2 | 父母、车辆、道路及现实生活接口：`n` |
| 目标端点 | 白龙及异界对象的对象特异关系记忆位置：`nz`保留态 |

## C. 唯一核心变量

**现实承载重新接通后，已经完成的方向是否被稳定接续，同时关系记忆只作为对象特异位置保留，而不被误判为互动接口重新开放。**

初始状态：千寻已经完成离场动作，但现实生活接口尚需重新接住行动结果。

终态：父母、车辆和道路接管当前行动承载；千寻短暂停步显示异界关系位置没有被抹除，但没有对白、接触、共同任务或双向回应，不能判为关系重新运行。

## D. 直接边与条件

### 直接补边 D-01

```text
现实家庭、车辆与道路承载 n
补
已完成方向 nx 所缺的现实接续接口
```

- 关系性质：直接补边。
- 目标缺口：方向已经完成到达现实出口，但若没有现实生活对象、空间和后续行动接口，结果只能停在“离开异界”，不能转入现实生活。
- 补入变量：现实空间、家庭同行、车辆移动和后续生活路径。
- 条件：`nx`必须已经完成离场；`n`补的是结果承载与后续接续，不是生成原始方向。
- 拿掉：拿掉父母、车辆和道路，千寻仍可完成穿越，却缺乏现实生活落点。
- 反向：`nx补n`解释较弱，方向完成不会自行生成父母、车辆和现实环境。

### 关系维持判断 D-02

```text
对象特异关系记忆 nz
在现实承载 n 接管后继续保留
但即时互动接口仍关闭
```

短暂停步可以支持注意力仍被异界对象牵引，最多证明关系位置没有归零。片段没有白龙出现、双向识别、回应或共同任务，因此不登记为`n补nz`、`nx生nz`或`nz重新开放互动`。

### 条件 D-03

`n`接续`nx`完成态的前提，是现实承载对象确实能够继续组织行动。父母、车辆与道路共同提供这一条件；单一背景镜头不足以构成承载。

## E. 正式失败边

### F-01

```text
✕ 现实承载 n → 生成或恢复对象特异关系 nz
```

失败原因：现实环境只接住生活行动，不提供白龙与千寻之间的双向识别或回应。拿掉白龙身份，父母、车辆和道路仍能完成现实承载。

### F-02

```text
✕ 短暂停步或回望倾向 → 即时互动接口重新开放
```

失败原因：单方注意、犹疑或记忆残留不等于双方关系正在运行。缺少第二主体的当前回应。

### F-03

```text
✕ 已完成方向 nx → 持续生成后续现实路径 n
```

失败原因：方向只说明“去哪里”及其完成，不自动提供现实对象、空间和生活任务。现实承载必须独立存在。

### F-04

```text
✕ 关系记忆 nz → 保证未来重逢、持续互动或现实回返异界
```

失败原因：保留对象位置与未来事件发生是不同层级。片段没有未来接口证据。

## F. 拿掉、反向与竞争解释

- 拿掉现实家庭、车辆和道路：千寻仍完成离场，但结果无法顺利进入现实生活，支持`n补nx完成态接续接口`。
- 拿掉短暂停步：现实回返链仍成立，但关系记忆保留的可见证据减弱，说明短暂停步是`nz`保留证据，不是承载机制。
- 拿掉白龙的对象特异身份：现实承载完全不受影响，排除`nz生n`。
- 反向测试：`nx补n`不成立，因为离场方向不会创造现实家庭和道路结构。
- 竞争解释1：单纯成长后的沉思。可以解释停顿情绪，但不能解释现实承载如何接续方向完成态。
- 竞争解释2：想回头却忍住。可解释动作倾向，但不能证明关系接口重新开放。
- 竞争解释3：现实与异界的象征分界。能解释场景意义，但不如`n接续nx完成态、nz仅保留`直接对应本轮变量。

## G. 具体动态链

```text
离场方向 nx 已完成
→ 父母、车辆与现实道路承载 n 补结果所缺现实接续接口
→ 千寻重新进入现实生活行动链
→ 短暂停步显示对象特异关系记忆 nz 仍保留
→ 因缺少第二主体当前回应，即时互动接口保持关闭
```

字母链：

```text
n补nx完成态接续 → nz跨场景保留｜互动接口未开放
```

- 直接关系边：`n补nx完成态的现实接续接口`。
- 维持节点：对象特异关系记忆`nz`。
- 关闭条件：没有第二主体当前识别、回应与共同任务。
- 失败边：`n生nz`、单方停步生互动、`nx生n`、`nz保证未来互动`。
- 总体效果：方向结果被现实生活接住，关系记忆被保留，但关系从现场互动退到单方记忆位置。

## H. 搭配效果与顺序效果

- 搭配效果：`nx完成态 + n + nz`形成“方向完成后由现实承载接续，关系位置跨场景保留但不占用当前行动接口”的组合。
- 顺序效果：必须先完成离场方向，再由现实承载接住结果，最后才能判断关系记忆是保留还是重新运行；若先把停步写成`nz`重启，会把单方注意误作双向关系。
- 动态类型：承载转换后的关系位置维持。
- 母型累计：新增“现实承载补方向完成态的后续接续接口，关系记忆可保留而互动接口不开放”具体C级候选1；不提升为锁定母型。
