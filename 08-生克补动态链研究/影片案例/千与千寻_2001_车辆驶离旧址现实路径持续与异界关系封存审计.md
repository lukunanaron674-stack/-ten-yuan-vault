# 《千与千寻》车辆驶离旧址｜现实路径持续与异界关系封存动态链审计

## A. 启动信息

- 影片：《千与千寻》（2001）
- 分析范围：千寻随父母上车，车辆离开旧址并进入现实道路的连续片段
- 分析粒度：C级单片段
- 动态类型：现实承载持续下的关系接口封存
- 本轮问题：现实路径`n`如何持续承载已完成方向`nx`，以及异界关系记忆`nz`是否从可见停步转入不占用当前行动接口的封存状态，避免把离开现场直接写成关系消失。

## B. 对象层、主体、阶段与端点

| 项目 | 判断 |
|---|---|
| 对象层 | 现实场景层、行动持续层、关系记忆层 |
| 主体 | 千寻为感知主体；父母、车辆与道路共同构成现实行动承载；白龙与异界关系不再拥有当前互动入口 |
| 阶段1 | 离场方向`nx`已经完成，车辆开始承担后续移动 |
| 阶段2 | 现实道路、家庭同行与车辆运动持续组织当前行动 |
| 阶段3 | 异界入口退出当前场景，关系记忆`nz`不再显影，但也没有被反证或清除 |
| 源端点 | 家庭、车辆和道路组成的持续现实路径承载：`n` |
| 目标端点1 | 已完成方向之后的行动连续性：`nx`完成态的持续接口 |
| 目标端点2 | 白龙及异界对象的对象特异关系记忆：`nz`封存态 |

## C. 唯一核心变量

**现实路径接管行动后，已完成方向能否获得连续承载，同时对象特异关系记忆是否仅退出当前接口而非被判定消失。**

- 初始状态：千寻已完成离场，关系记忆仍通过短暂停步显影。
- 终态：车辆与现实道路持续承载行动；异界关系不再占用当前注意和互动接口，但没有出现撤销、遗忘或关系对象被替代的证据。
- 展开指标：现实移动连续性、当前互动可用性、对象特异关系位置是否被反证。

## D. 直接边与条件

### 直接补边 D-01

```text
家庭、车辆与现实道路的持续承载 n
补
已完成方向 nx 所缺的跨场景行动连续接口
```

- 关系性质：直接补边。
- 目标缺口：离场方向已经完成，但完成本身不提供离开旧址后的连续移动、同行关系与现实生活路径。
- 补入变量：车辆运动、道路延伸、父母同行及现实目的地。
- 条件：`nx`必须已完成；`n`补的是完成后的持续承载，不生成离场方向。
- 拿掉：拿掉车辆、道路与家庭同行，方向仍已完成，但现实行动链会停在旧址出口。
- 反向：`nx补n`不成立，方向完成不会创造车辆、道路或家庭组织。

### 封存判断 D-02

```text
对象特异关系记忆 nz
由可见显影转入不占用当前行动接口的封存态
```

车辆驶离只改变关系记忆的当前可访问性与显影状态，不提供关系消失所需的撤销、遗忘、对象替代或反证。因此这里不登记`n克nz`，只登记“现实行动接口持续占用，`nz`退出当前互动接口”的条件性状态转换。

### 条件 D-03

`nz`封存成立需要：对象特异位置此前已经建立；当前片段缺少双方互动入口；同时没有明确遗忘、否认、撤销或替代证据。单纯看不见异界入口，只能证明当前接口关闭，不能证明关系位置归零。

## E. 正式失败边

### F-01

```text
✕ 现实路径持续 n → 克制或消除对象特异关系 nz
```

失败原因：现实移动减少当前可访问性，但没有降低关系对象的既有位置、记忆成立资格或未来被重新调用的可能性。最近邻应改判为“接口封存”。

### F-02

```text
✕ 离开旧址 → 关系消失
```

失败原因：空间离开是场景与访问条件变化，不是关系端点被撤销。拿掉空间距离，关系是否成立仍取决于双方对象位置，而不是距离本身。

### F-03

```text
✕ 关系记忆 nz → 持续占用当前行动接口
```

失败原因：对象位置可以保留而不持续显影。车辆驶离时，当前行动由现实路径组织，关系记忆不必持续干预动作。

### F-04

```text
✕ 已完成方向 nx → 自动维持后续行动连续性
```

失败原因：方向完成只结束“离场”任务，后续连续性依赖独立的现实承载`n`。

## F. 拿掉、反向与竞争解释

- 拿掉车辆、道路与家庭同行：离场仍完成，但现实行动无法跨场景持续，支持`n补nx完成态连续接口`。
- 拿掉上一片段的短暂停步：本片仍可判断现实路径持续，却更难证明`nz`此前显影，说明停步是关系记忆证据，不是本片承载机制。
- 拿掉白龙与异界对象的特异身份：现实移动完全不受影响，排除`nz生n`或`nz补n`。
- 反向测试：`nx补n`与`nz克n`均不能解释车辆、道路和家庭同行为何独立存在。
- 竞争解释1：成长后回归日常。能说明主题，但没有区分承载、方向完成与关系接口。
- 竞争解释2：异界经历被彻底遗忘。片段缺乏明确遗忘或否认证据，解释过强。
- 竞争解释3：空间距离自然削弱关系。只能解释互动困难，不能证明对象特异关系位置下降。

## G. 具体动态链

```text
离场方向 nx 已完成
→ 家庭、车辆与现实道路承载 n 补完成态所缺跨场景行动连续接口
→ 现实行动链持续向前
→ 异界入口退出当前场景
→ 对象特异关系记忆 nz 从可见显影转入接口封存
→ 因无撤销、遗忘或替代证据，不判关系消失
```

字母链：

```text
n补nx完成态持续接口 → nz显影退出｜当前接口封存｜关系位置未被反证
```

- 直接关系边：`n补nx完成态的跨场景行动连续接口`。
- 条件节点：`nz`由显影态转为封存态。
- 失败边：`n克nz`、空间离开生关系消失、`nz`持续占用当前接口、`nx`自动维持后续连续性。
- 总体效果：现实生活获得连续行动承载，异界关系从前台互动位置退入不占用当前行动的记忆封存位置。

## H. 搭配效果、顺序效果与母型累计

- 搭配效果：`nx完成态 + n持续承载 + nz封存`形成“方向结束后现实路径接管行动，关系位置保留但退出当前接口”的组合。
- 顺序效果：必须先确认离场方向已经完成，再判断现实承载如何持续，最后才能区分`nz`是封存还是消失；若直接从车辆驶离跳到关系消失，会把空间变化误作关系变量下降。
- 动态类型：现实承载持续下的关系接口封存。
- 母型累计：新增“现实路径补方向完成态的跨场景连续接口，关系记忆由显影转入封存但未归零”具体C级候选1；不提升锁定关系或跨片母型计数。
