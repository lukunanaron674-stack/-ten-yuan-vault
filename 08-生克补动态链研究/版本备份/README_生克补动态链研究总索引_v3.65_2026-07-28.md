```text
对象、主体、阶段与对象层
→ 信息卡确认候选端点
→ 准度卡排除最近邻并完成拿掉、反向
→ 生卡 / 克卡 / 补卡确认关系类型
→ 核心表与专项索引确认机制状态
→ 确认分账与单一核心变量
→ 直接关系边
→ 条件、间接路径与失败边
→ 单案例归档
→ 跨案例后验比较
→ 母型候选或锁定
```

默认按C单场→B段落→A整片推进；具体动态图积累优先，母型后置。

## 4. 最新具体动态图｜《楚门的世界》广播串台

```text
直接边：
实时车辆跟踪与内部播报程序 xn
→ 补 楚门被监看事实确认 z

条件：无线电频率意外串入

失败边：
临时跟踪播报接口 x并z ─×→ 生 楚门确认 z
节目组信息环境控制 x ─×→ 克 客观现实 z
广播异常 ─×→ 生 楚门确认 z

链式后果：
海景镇正常世界壳可信度下降；楚门后续测试和调查意愿上升。均不登记为新的直接关系边。
```

边界：

- `xn`提供对象特异、连续、可即时复核的时序证据，补入个人确认的证据缺口。
- 串台只开放接触机会，不是十元端点。
- 一次意外播报缺少稳定公共接口的持续和调用，不足以登记`x并z生z`。
- 客观现实不是`x克z`目标，本场具体个人确认反而上升。
- 本轮只完成C级，不与电梯后台或整片退出提前合并。
