# 1｜动态链研究的新核心：合法 ≠ 优秀

旧问题主要是：

> 这个节点是什么十元？这条边是不是生 / 克 / 补？

今天进一步明确：

> **一条边即使“说得通”，如果没有改变结构变量、没有产生残余、没有制造下一阶段的可供性，它仍然不是高质量动态边。**

优秀动态链至少同时满足：

1. **节点纯度**：阶段主 / 次十元有明确证据，不靠题材印象。
2. **同对象层**：Pair Coherence 要求比较对象处于同一 object layer。
3. **同核心变量**：生克补 / 迁移必须作用在同一核心 changed variable，不能跨变量强拉因果。
4. **机制边**：A→B 之间必须能指出 mechanism。
5. **变量 Δ**：边发生后，至少一个关键结构变量真正改变。
6. **残余**：上一阶段不能凭空消失，必须留下 residue / constraint / trace。
7. **下一可供性**：上一阶段的变化必须制造下一阶段可以发生的条件。
8. **主次迁移**：动态链要能说明谁升主、谁降次、谁新出现、谁退出。
9. **不可替代性**：删掉该边或替换成普通事件，链的结构必须明显退化。
10. **收束 / 回收**：结尾应回收前面留下的变量、残余或关系债务，而不是突然停机。

一句话：

> **好链不是“事件连续”，而是“前一阶段制造了后一阶段”。**

# 3｜动态链的横向 × 纵向分析法

今天正式确认：动态链不能只竖着读。

## 3.1 横向：同一阶段内部结构

每一阶段横向记录：

```text
主十元
次十元
体量 / 强度
当前生克补边
依赖关系
谁约束谁
谁为谁提供条件
谁占主导权
```

示意：

```text
阶段 T1
NZ 9 ───── X并Z 0

阶段 T2
NZ 5 ──[X并Z 克 NZ]── X并Z 9

阶段 T3
NZ 4 ───── X并Z 8 ──[Z 转导 / 利用]── Z 8

阶段 T4
NZ 3 ───── X并Z 6 ───── Z 7 ──▶ XN 9
```

这里横向看的不是“谁排在左边”，而是**同阶段权力 / 条件 / 约束结构**。

## 3.2 纵向：阶段之间如何迁移

纵向必须记录：

```text
trigger
changed_variable
primary_up / primary_down
secondary_up / secondary_down
newly_appeared
removed
relation_changed
path_opened
path_blocked
residue
reversibility
next_affordance
```

因此真正的动态图不是：

```text
NZ → X并Z → Z → XN
```

而应接近：

```text
T1: NZ=9
│  trigger: 异常进入整体关系
│  Δ: 原本整体关系可自行维持 → 被拆离 / 错接 / 重定义
▼
T2: NZ=5 + X并Z=9
│  residue: 原NZ仍留下局部痕迹
│  affordance: 异常现在可被识别 / 捕捉 / 分类
▼
T3: X并Z=8 + Z=8
│  Δ: 异常从一次性破坏 → 可操作对象
│  affordance: 标准化 / 接口化成为可能
▼
T4: Z=7 + XN=9
    Δ: 可操作对象 → 稳定制度 / 系统规则
```

核心问题始终是：

> **时间中，主导权怎么变化？**

# 4｜链条质量的关键概念：状态变化边

今天确认最重要的边不是“关系名称漂亮”，而是 **State-changing Edge**。

最低结构：

```text
A_state
+ trigger
+ mechanism
→ changed_variable Δ
→ B_state
+ residue
+ next_affordance
```

### 合格例

```text
开放世界仍被当作可自由通行
↓ 撞上人工边界
“空间可通行”变量失效
↓
行动由直行改成检查边界 / 搜索出口
↓
产生“出口路径可被发现”的下一可供性
```

### 不合格例

```text
A很危险
↓
所以B变谨慎
```

除非能指出“危险”怎样改变了具体路径、合法状态空间、决策权或运行条件，否则只是语义联想。

# 5｜生 / 克 / 补：今天从关系标签升级为因果审核

视觉化体系 v0.8.1 中，Relation Visualization v0.1 已工程化。

## 5.1 不再接受的假关系

```text
同框 ≠ 关系
大压小 ≠ 克
黑红危险 ≠ 克
发芽 / 变大 ≠ 生
拼图 / 对称 ≠ 补
感情和谐 ≠ 补
A帮助B ≠ 自动等于生
```

## 5.2 生

最低反事实问题：

> **没有 source，target 是否仍会以同样方式成立？**

真正的“生”要求 source 的运行制造 target 的成立条件。

## 5.3 克

最低问题：

> **target 原本如何运行？source 具体删掉 / 限制 / 改写了哪个合法运行条件？**

“克”优先理解为合法状态空间被约束，而不是攻击动作。

## 5.4 补

最低问题：

> **target 原本缺什么？source 是否补足缺口，同时没有替代 target？**

补不是融合，不是同类化，也不是简单“关系变好”。

## 5.5 当前视觉回归协议

25 条关系，每条 T1 固定：

```text
POS
COEXIST_NEG
SHORTCUT_NEG
```

基础量：

```text
25 × 3 = 75 张
```

优先 8 条：

```text
SHENG-07  nx -> x
SHENG-05  xn -> xz
SHENG-09  x并z -> z
KE-01     xz -> zn
KE-03     xn -> zx
KE-08     z -> nx
KE-09     nx -> x并z
BU-05     xn <-> z
```

这些关系被优先，因为最难用“成长 / 攻击 / 拼图”等视觉陈词滥调作弊。

# 7｜静态 Style Grammar 是动态链视觉化的前置依赖

动态链不是漂浮在空中的动画箭头。

若起点和终点十元静态结构本身都无法区分，则动态链视觉化无法可靠判断“从什么变成什么”。

当前最短 Style Grammar：

```text
X       独立自足
Z       方向迁移
N       双向互为条件
ZN      关系规则改写
NZ      终端嵌合
XN      规则槽位化
NX      缺席组织位
ZX      非对称组织锚点
XZ      临界耦合
X并Z    上位包络双读
```

当前冻结状态：

```text
X       FROZEN
Z       FROZEN
XN      STRONG_FREEZE_CANDIDATE
XZ      STRONG_FREEZE_CANDIDATE
N       A/B REQUIRED
ZN      A/B REQUIRED
NZ      REVISED A/B REQUIRED
NX      REVISED PRIORITY A/B
ZX      REVISED PRIORITY A/B
X并Z    FREEZE CANDIDATE
```

因此当前最高信息收益的图像依赖仍然是：

```text
ZX 3 张：POS / NEAR / DELETE
NX 3 张：POS / NEAR / DELETE
```

这 6 张不是偏离动态链，而是在补“状态端点识别器”。

# 15｜本日最重要的收束句

> **动态链不是“十元按顺序排列”，而是主导权、合法状态空间、路径、关系与可供性在时间中的连续改写。**

> **好动态链的核心不是关系数量，而是每一条边是否真正生产了下一阶段。**

> **视觉化的职责不是重新证明动态链，而是把这种变化变得可见、可区分、可盲审、可冻结。**
