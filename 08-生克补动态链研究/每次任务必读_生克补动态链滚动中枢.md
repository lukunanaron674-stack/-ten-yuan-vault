## 1. 十元概念强制预检

任何生克补判断前，先完成：

```text
z 切分焦点
+ x 现象集合
+ 十元位置锚
+ 稳定本体／当前状态
+ 关系体量与阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、反抗、自由、牺牲、成功、失败、角色名、组织名、单个动作或镜头直接作为十元端点。

## 2. 动态链基本单位

每个节点必须写：阶段、关系双方、源/目标概念锚、生克补类型、被改变变量、可观察结果、最近邻、拿掉测试与证据等级。

禁止用“被压迫→被帮助→成长→胜利”这种剧情梗概冒充动态链。

## 3. 生、克、补口径

### 生
源为目标核心变量提供净增量。区分直接生、桥接生与允许条件。空位、机会、曝光、信息、熟练度和领袖示范不自动算生。

### 克
目标核心变量或成立资格持续下降。必须区分显影下降、条件化、排序下降、局部成员覆盖下降与整体结构下降。

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离 ≠ 制度整体被克
低体量成员撤回自愿执行、维护和身份再生产 = 可构成局部正式 zn 克 xn
```

制度整体被克，必须观察跨成员覆盖、自愿执行、内部修复或跨轮次复制是否持续下降。

### 补
补是恢复目标缺失的核心变量。必须证明缺口、变量对应与源必要性。临时领袖替大家做决定、提供娱乐、课堂机会或制造试验场，不自动等于补回稳定自主。

### 示范转内化新增红线

```text
示范者在场时跟随 ≠ 内部 zn
模仿姿势与口号 ≠ 稳定意义
示范者撤场后仍独立判断 + 逆安全外部方向 + 承担后果
= 才接近自己的 zn
```

群体一次同步行为只支持状态或局部覆盖下降；要判制度再生产下降，必须观察无示范者时仍持续、跨情境迁移、成员主动传递和结构复制率下降。

## 4. 每部影片强制拆分

1. 十元概念预检；
2. 开场稳定结构；
3. 触发事件；
4. 主克；
5. 主缺口；
6. 主补；
7. 主生；
8. 中段换挡；
9. 高潮反向；
10. 结局稳定结构；
11. 可复用母型。

同时标注：稳定本体、当前状态、行为功能、光影、场景、时间关系、关系位置、显影与动态链。

## 5. 判断搭配好的标准

1. 概念先行；
2. 因果清楚；
3. 缺口对应；
4. 不跳步；
5. 有换挡；
6. 有代价；
7. 有反向检验；
8. 有结局余波；
9. 可跨片迁移；
10. 能区分局部克制与整体克制；
11. 能区分示范、模仿、内化与再生产。

## 6. 证据等级

- A：影片直接呈现端点、机制与结果；
- B：强推断，仍有少量第三因素；
- C：跨片重复；
- D：理论构造测试；
- X：共现、先后、视觉相似或剧情总结。

主链至少一个关键节点达到 A，其他不得低于 B。

## 7. 已完成影片

### 《千与千寻》v1.0

```text
xn 克 zx
→ n 补 x并z
→ zn 生 n
→ 规则通关／身份退出
```

结尾不判正式克。制度仍完整运行。

### 《飞越疯人院》v1.0

```text
xn 克 zx
→ 外来 zx 制造反规则试验（允许条件）
→ 群体短时撤回服从
→ 制度以 zx 强制回收并破坏临时 n
→ Chief 形成低体量 zn 克 xn
→ 个体退出；制度整体仍在
```

主补、主生暂不锁定。

### 《死亡诗社》v1.0

```text
学校 xn 克 zx
→ 基廷 zx 打开非标准判断试验（允许条件）
→ 学生发生模仿、失败、内化分化
→ 学校 zx/xn 强制回收并移除示范者
→ 托德在示范者撤场后独立形成 zn
→ 低体量 zn 克 xn
→ 学校整体仍在
```

锁定到本片审计层：基廷示范是关键允许条件，不先判主补或主生；托德站桌因发生在基廷撤场、诺兰命令坐下且需承担处分风险，可判局部 `zn 克 xn`。全班长期内化和制度整体克均不锁定。

## 9. 当前核心缺口

1. 外来领袖示范何时只是允许条件，何时真正补回对象缺失变量；
2. 示范者撤场后的跨情境迁移，是区分模仿与内部 `zn` 的关键证据；
3. 群体同步行为与制度自愿再生产下降仍需长期余波区分；
4. `zn 克 xn` 从单成员覆盖下降累积为群体复制率下降，需要成员主动传递与跨轮次证据；
5. 临时共同体在高压撤场后能否留存，决定 `zn 生 n` 能否进入主链；
6. 需要反向研究：示范如何不再启蒙，而变成新的 `zx/xn` 并生成 `nx`。
