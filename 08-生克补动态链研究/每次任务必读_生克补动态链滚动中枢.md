## 1. 十元概念预检

每个端点必须先写：

```text
z切分焦点 + x现象集合 + 十元位置锚
+ 稳定本体/当前状态 + 体量/阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、自由、服从、真相、觉醒、时间、命运、角色名、组织名、单个动作或镜头直接作为端点。

## 2. 生克补通用口径

- **生**：源为目标核心变量提供净增量。区分直接生、桥接生和允许条件。
- **克**：目标核心变量或成立资格持续下降。区分状态下降、局部成员覆盖下降与整体结构下降。
- **补**：恢复此前真实缺失的核心变量；信息、资源、训练、临时代理、领袖示范和单次情绪变化不自动算补。

## 3. 当前强制红线

### 3.1 制度、个体与退出

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离或通关 ≠ 制度整体被克
成员撤回自愿执行、维护或身份再生产 = 才可能构成低体量 zn 克 xn
```

### 3.2 示范、共同体与制度

```text
示范者在场时跟随 ≠ 内部 zn
撤场后仍独立判断 + 逆安全方向 + 承担后果 = 才接近自己的 zn

领袖命令 + 团队同框 + 计划书 ≠ n 生 xn
共同体先承担跨成员负荷
→ 再提炼规则、分工、边界、信号和预案
→ 才支持 n 生 xn
```

### 3.3 接口、壳、确认与制度执行

```text
设备、样本、语料、影像、概率、检测器、数据库、资源和通道 = 首先是 x
稳定可识别、可调用的身份/语言/未来角色/阶级界面 = x并z
明确主体确认明确对象与内容 = z
授权、筛选、抓捕、门禁、日检、分流、配给、教育、镇压与司法 = xn
制度执行使安全路线与时间窗缩窄 = xn 生 xz
主体决定必须先通过既有结构 = xn 克 zx
```

接口和数据长得再像真理，也不会自动获得 `z/xz/zn` 资格。

### 3.4 时间、预知与原则

```text
提前知道结果或损失 = x/xn 信息条件变化
路线、退路和最后窗口真实缩窄 = 才可能形成 xz
行动改变 ≠ zn 改变
原则是否被克 = 看最终指导资格是否持续撤销
```

### 3.5 概率身份壳与机会制度

```text
样本、评分、读数和检测设备 = x
风险等级、职业适配、信用等级与可调用档案 = x并z
机构确认谁适合进入什么位置 = z
招聘、门禁、保险、教育分流与任务分配 = xn
能力尚未进入现实，资格已被身份流程过滤 = xn 克 zx
```

没有倒计时追捕，也可存在高体量 `xn克zx`。借用样本、证件和档案首先是掌握接口 `x` 与调用既有 `x并z` 壳，不等于本体替换。

### 3.6 封闭承载、资源掌握、阶级壳与运行制度

```text
车体、引擎、水、食物、武器、药物、门与身体接口 = x
尾厢/前厢、制服、位置、职责和接班人身份 = x并z
空气、温度、食物循环、内部位置和持续维持 = n
配给、门禁、人口平衡、教育、镇压和维护 = xn
```

红线：

1. 同一物理容器可同时承载 `x/n/x并z/xn`，必须按被改变变量拆开。
2. `n` 真实承载生命，不自动证明等级制度正当，也不自动生出当前 `xn`。
3. 资源差和车厢色差只是显影；必须观察资源、身份与规则如何被持续调用。
4. 反抗穿过执行节点不等于制度被克；系统可用人口平衡、接班和角色吸纳回收 `zx`。
5. 主角进入中心或获得接班位置，不等于身份自由；可能是把反抗者转成新维护节点。
6. `zn克xn` 只能记录自愿维护、接班和复制资格下降；爆炸、雪崩和设施毁灭必须另记为物理结果。
7. 炸开出口不等于外部生存已确认；证据组织、接口打开与确认结果必须拆开。
8. 旧容器毁灭不等于新共同体 `n` 已成立。

## 6. 当前核心缺口

1. 外来示范何时只是允许条件，何时补回真实缺口；
2. 临时共同体能否跨高压留存，决定 `zn生n` 或 `n生xn` 的稳定性；
3. `nx` 常是多节点后果，不得伪造单一直接生关系；
4. 身份壳 `x并z` 不等于内部承载 `n`；
5. 多人造界、概率身份与封闭容器都必须拆 `x/x并z/n/xn`；
6. 团队执行既有协议不等于团队生出协议；
7. 牺牲结果不能单独证明补、`zn生n` 或稳定人格本体；
8. 长期机会关闭可构成高体量 `xn克zx`，不必先出现追捕倒计时；
9. 个体穿透筛选节点不等于制度整体被克；
10. 封闭承载 `n` 可被 `x/x并z/xn` 不平等调用，承载真实不等于制度正当；
11. 系统吸纳反抗者时，必须区分权位继承、身份替换、维护资格与原则撤回；
12. 物理容器毁灭、制度维护停止和新承载生成必须分写。
