## 1. 三层结构，禁止混用

```text
第一层：关系对子
谁生谁、谁克谁、谁补谁，例如 n生xn、zx克n、xn补z。

第二层：动态链
多个真实成立的关系对子按阶段连接，例如：
zx克n → xn补z → x生x并z → x并z生z。

第三层：通用母型
同一抽象动态链在多个独立案例、不同题材中稳定复现，具体名词虽不同，但关系顺序和被改变变量同构。
```

影片名、角色名、场景名和剧情梗概只能作为具体案例证据，不能直接充当母型。M-001A至M-032暂降为历史案例链编号。

## 2. 具体名词对子积累

每轮每条关系必须记录：

```text
具体源名词
+ 关系对子
+ 具体目标名词
+ 为什么成立
+ 被改变变量
+ 阶段
+ 拿掉测试
+ 反向测试
```

例如不得只写`xz克zn`；必须写清“哪一种危险、失去窗口或临界名词`xz`，克哪一种原则、意义或精神判断名词`zn`，为何使其正确性、无条件性或最终指导资格下降”。

字母关系是骨架，具体名词是积累内容。只写字母不算具体积累；只写名词不做十元定位也不算关系研究。

## 3. 十元概念预检

每个端点必须先写：

```text
z切分焦点 + x现象集合 + 十元位置锚
+ 稳定本体/当前状态 + 体量/阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、自由、真相、希望、命运、预言、角色名、组织名、单个动作或镜头直接作为端点。

## 4. 生克补通用口径

- **生**：源为目标核心变量提供净增量；目标此前不存在或不足。
- **克**：目标核心变量、成立资格或实际运行能力下降；不是普通阻碍。
- **补**：恢复此前真实缺失的核心变量；不是帮助、陪伴、资源存在或时间自然恢复。
- **动态链**：只连接已通过具体名词、变量和测试的对子。条件化、排序、显影和普通执行必须单独标记。

## 5. 通用红线

1. 共现、帮助、阻碍、先后、成功、失败、通关、离场、获救、死亡和视觉相似不等于生克补。
2. 稳定本体、当前状态、行为、光影、场景、时间、关系位置、显影和动态链不得互相替代。
3. 设备、资源、通道、身体、武器、路线、证件、样本与赎金首先是`x`。
4. 身份、职责、职业英雄、人质、成员、谈判者与家属界面首先是`x并z`。
5. 接收、保护、补给、照护、互保、清点、返航与反复返回属于`n`。
6. 授权、训练、检查、调查、谈判、证明存活、报价、审批、情报核验和证据组织属于`xn`。
7. 确认与执行分开；程序不会自动现实生效，资源不会自动变成结果。
8. `xz生zx`只生成状态层或关系位置层的临时决定接口，不生专业、勇气、正确性或稳定领导本体。
9. `n生xn`必须来自持续真实负荷；既有专业、资源、制度、爱情和个人魅力只是允许条件或第三因素。
10. `xn补z`必须有跨时间证据、反馈和复核闭环；一次声音、录像、地图、称赞或直觉不足。
11. `n克xz`必须实际接收、保护、补给、处理与维持；停止攻击、放人和离开危险位置不足。
12. 危险、创伤、恐惧和妥协不得倒写为`xz克zn`。
13. 工具性容器`n`与关系性共同体`n`必须分开；设施仍在不等于承载有效。
14. 原成员回返不是新成员吸纳；身体回到安全地点不等于共同体、职业、创伤和技术系统全部复归。
15. 英雄壳、公众认可、获奖、媒体曝光不得倒证现场机制。

## 6. 人质、资源换向与公开悬赏红线

16. 武装控制与长期不确定性必须分写：前者改变成员接口，后者压缩健康、信息、释放窗口和回返概率。
17. 赎金`x`、谈判`xn`、交换确认`z`、支付/放人`zx`与接收`n`必须分账。
18. 支付不等于释放，释放不等于返航接收。
19. 家庭等待只证明回返对象和关系保持，不能替代谈判、支付、保护和现实接收。
20. 谈判达成价格不等于释放窗口仍开放。
21. 谈判失效后必须重新锚定确认对象，不能把旧程序改名为新程序。
22. 情报补足与武装执行分开。
23. 私人吸引不得吞并专业责任。
24. 组织责任撤场不等于成员价值消失。
25. 现金改为悬赏时，必须拆成：现金掌握`x`→公开奖励壳`x并z`→目标识别`z`→程序聚焦`xn`；“有钱”“上电视”“绑匪害怕”均不能吞并中间对子。
26. `x生x并z`只生公开可识别、可调用、可兑现的资源壳，不直接生身份确认、抓捕或获救。
27. `x并z生z`必须写清谁通过公开壳识别谁、识别什么；曝光量本身不足。
28. `z补xn`必须证明确认改变程序聚焦对象、材料筛选标准或阶段节点。
29. 公开悬赏造成工具联盟恐惧和内斗，不足以直接判`x并z克nz`；目标`nz`必须先稳定成立。
30. 错误英雄壳与真实救援必须分账；被公众感谢不等于真实身份和机制成立。

## 7. 案例链与母型状态

- M-001A至M-032：全部标记为`legacy-case-chain`，仅作为历史案例链编号，不再直接叫通用母型。
- C-001：`x生x并z → x并z生z → z补xn`，名称仅作“资源公开化—目标确认—程序聚焦”候选链；当前只有《赎金》（1996）1次支持，未达到母型门槛。
- UM编号只授予多次、跨题材、变量同构、失败版明确的通用母型。

母型锁定门槛：

```text
多次独立复现
+ 至少跨两个题材
+ 关键对子A级证据
+ 具体名词不同但被改变变量和链序同构
+ 排除题材符号、身份壳、单次动作和结果解释
+ 能指出失败版
```
