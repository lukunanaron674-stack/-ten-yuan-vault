## 1. 十元概念预检

每个端点必须先写：

```text
z切分焦点 + x现象集合 + 十元位置锚
+ 稳定本体/当前状态 + 体量/阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、自由、真相、命运、预言、角色名、组织名、单个动作或镜头直接作为端点。

## 2. 生克补通用口径

- **生**：源为目标核心变量提供净增量；区分直接生、桥接生和允许条件。
- **克**：目标核心变量或成立资格持续下降；区分状态、局部覆盖和整体结构。
- **补**：恢复此前真实缺失的核心变量；信息、资源、训练、示范和一次情绪变化不自动算补。

## 3. 当前强制红线

### 3.1 制度、个体与退出

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离或通关 ≠ 制度整体被克
成员撤回自愿执行、维护或身份再生产 = 才可能构成低体量 zn克xn
```

### 3.2 接口、壳、确认与制度执行

```text
设备、样本、语料、影像、概率、资源和通道 = 首先是 x
稳定可识别、可调用的身份/语言/未来角色/阶级界面 = x并z
明确主体确认明确对象与内容 = z
授权、筛选、抓捕、门禁、生产、分流、配给、教育、镇压与司法 = xn
制度执行使安全路线与时间窗缩窄 = xn生xz
主体决定必须先通过既有结构 = xn克zx
```

### 3.3 承载、资源、身份壳与制度必须拆开

同一场景可同时包含：

```text
资源、设备、通道和身体接口 = x
公开身份、职责、阶级、家族、预言角色 = x并z
成员接收、住所、水食、保护、知识和持续维持 = n
授权、生产、门禁、军力、传播、准入和维护 = xn
```

容器、家族、堡垒、沙漠或星球不能包办四个端点。

### 3.4 预知、概率与原则

```text
提前知道结果 = x/xn 信息条件变化
路线和最后窗口真实缩窄 = xz
行动改变 ≠ zn 改变
原则被克 = 最终指导资格持续撤销
```

### 3.5 位置脱离、资源迁移、身份脱钩、承载迁移与制度重写

五者必须分写：

```text
离开旧地 = 位置脱离
带走设备/资源 = 资源迁移
拒绝旧称谓/职责 = 身份壳脱钩
被新群体实际接收并持续维持 = 承载迁移
规则、接口和复制方式跨阶段改变 = 制度重写
```

### 3.6 帝国授壳、地方掌握与预言识别（《沙丘》新增）

```text
帝国授予封地/领主称号 = x并z 壳与 xn 义务
香料、水、设备、军力、路线和地方知识实际归属 = x
地方住所、供水、庇护、成员位置和生存知识 = n
封地移交、生产义务、军力部署、围剿和预言传播 = xn
预言称呼为对象提供可识别接口 = x并z
弗雷曼具体确认某人是否符合 = z
```

红线：

1. 合法授权不等于实际掌握已经移交。
2. 高位结构可利用公开身份壳与生产义务，把被授权者放进可诱捕位置。
3. 预言壳提高可识别与归因概率，不证明命运真实、稳定 `zn` 或领导资格。
4. 一次能力显影、正确穿戴或决斗胜利不等于完整身份再壳化。
5. 加入地方群体首先检查准入、成员接收和现实承载；不能仅凭称呼判定共同体成立。
6. 地方成熟规则已存在，不得反推本片展示了 `n生xn` 的生成过程。
7. 原家族承载崩解后，新承载是否成立必须观察住所、水、保护、负荷承担与跨阶段返回。
8. 2021电影结尾只证明最低准入与承载迁移开始，未证明保罗成为弗雷曼领袖或新制度源端。
