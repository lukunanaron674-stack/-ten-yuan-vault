## 1. 十元概念预检

每个端点先写：

```text
z切分焦点 + x现象集合 + 十元位置锚
+ 稳定本体/当前状态 + 体量/阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、自由、服从、角色名、组织名、单个动作或镜头直接作为端点。

## 2. 生克补口径

- **生**：源为目标核心变量提供净增量。区分直接生、桥接生和允许条件。
- **克**：目标核心变量或成立资格持续下降。区分状态下降、局部成员覆盖下降与整体结构下降。
- **补**：恢复此前真实缺失的核心变量；临时代理、资源、娱乐、课堂机会和领袖示范不自动算补。

### 制度与个体红线

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离 ≠ 制度整体被克
成员撤回自愿执行、维护或身份再生产 = 可构成低体量正式 zn 克 xn
```

### 示范、模仿、内化

```text
示范者在场时跟随 ≠ 内部 zn
模仿姿势、口号、制服 ≠ 稳定意义
撤场后仍独立判断 + 逆安全方向 + 承担后果
= 才接近自己的 zn
```

### 新增：共同体转制度

```text
领袖命令 + 视觉同步 ≠ n 生 xn
真实共同体先承担归属、协作、保护和任务负荷
→ 为持续处理负荷提炼规则、分工、边界和重复流程
→ 才支持 n 生 xn
```

### 新增：nx 生成红线

```text
zx/xn 在场 + 成员服从 ≠ zx/xn 直接生 nx
必须观察无领袖监督仍沿默认路线推进、否决权萎缩、退出成本上升和跨场景复制
nx 可以是多节点动态后果，不得为链条完整伪造单一生关系
```

## 4. 已完成影片

### 《千与千寻》v1.0

```text
xn 克 zx → n 补 x并z → zn 生 n → 规则通关/身份退出
```

结尾不判正式克。

### 《飞越疯人院》v1.0

```text
xn 克 zx → 外来 zx 试验 → 制度强制回收
→ Chief 低体量 zn 克 xn → 个体退出，制度仍在
```

主补、主生未锁。

### 《死亡诗社》v1.0

```text
学校 xn 克 zx → 基廷 zx 打开判断试验
→ 模仿/失败/内化分化 → 制度回收
→ 托德低体量 zn 克 xn → 学校仍在
```

### 《浪潮》v1.0

```text
教师 zx 打开实验
→ 临时 n 承担归属与协作
→ n 生 xn
→ x 生 x并z → x并z 生 z
→ 成员局部 nx 扩张（多节点后果）
→ 新 xn 克原教师 zx
→ 强制回收与灾难崩坏
```

本片不锁“zx/xn 直接生 nx”；主补未锁。

## 5. 当前母型

- M-001A：制度限位—带代价纳入—通关退出（《千与千寻》）
- M-002：制度回收—个体继承退出（《飞越疯人院》）
- M-003：示范撤场—分化内化—局部拒绝再生产（《死亡诗社》）
- M-004：共同体负荷—制度提炼—身份增幅—结构反噬（《浪潮》）

均为 candidate，单片不锁。

## 6. 当前核心缺口

1. 外来示范何时只是允许条件，何时补回真实缺口；
2. 临时共同体能否跨高压留存，决定 `zn 生 n` 或 `n 生 xn` 的稳定性；
3. 群体同步与制度自愿再生产必须靠无领袖监督、跨场景复制和成员主动传递区分；
4. `nx` 常是多节点后果，需防止把服从画成不存在的直接生关系；
5. 身份壳 `x并z` 能提高识别、认可与退出成本，但不等于内部承载 `n`；
6. 下一步需要研究长期封闭媒介结构如何维持主体局部 `nx`。
