- 节点：具体名词+十元位置。

- 母型：最后才后验归纳，首遍分析必须屏蔽。

## 3. 生克补红线

- 生：源为目标核心变量提供净增量，目标此前不存在或不足。
- 克：目标核心变量、成立资格或实际运行能力下降。
- 补：恢复目标此前真实缺失的核心变量。
- 共现、先后、帮助、阻碍、通关、离场、攻击、杀死、制造、训练、控制和失控不能直接判生克补。
- 勇敢、成长、压迫、规则、爱、自由、真相、希望、角色名、场景和单个动作不得直接当端点。
- 相同字母可对应不同对象、阶段和体量，不能自动合并。
- 同一物理载体可被不同z切分同时落在多个十元位置。
- 同一物类或同批产品连续，不等于同一具体对象连续。
- 目标变量下降不等于必有克关系；新增反证、事实更新与前提断裂必须与已锁定克机制分开。
- 对象物理属性、生命状态、材质或空间边界持续，不等于旧控制、调用、承载或归因关系持续。
- 灾难发生在承载空间内部，不等于空间已经从`n`迁移为`xz`；必须证明接收、保护、停留、通行等旧承载变量退出，新路线缩窄、时间窗和危险可到达性成为运行中心。
- 火灾、进水、坍塌、撞击等只能先记必要第三因素，不能单个动作直接充当迁移或关系边。

## 4. 顺序、拓扑与位置测试

1. 换序测试。
2. 支路拿掉与汇合分账。
3. 反馈方向测试。
4. 拿桥测试。
5. 同字母异对象测试。
6. 断裂与反向解释测试。
7. 反转资格：同一源、目标、对象、变量，两条边分别A级。
8. 控制断裂、物理攻击、新事实更新与反证进入排除。
9. 位置迁移：对象连续；迁移前后z切分、x集合、核心变量和体量分别锚定；前后边分别合法。
10. 位置叠加：新位置变量新增而旧位置核心变量继续运行，只记叠加。
11. 严格迁移：旧位置现实关系显著下降、退出或不再主导，新位置变量成为实际运行中心。
12. 物理本体持续不等于旧十元关系持续；检查控制主体、调用权、接收能力、通行结构和运行中心。
13. 新位置必须启动至少一条A级合法关系边；只成为象征、纪念物、灾难背景或剧情焦点不足。
14. 第三因素必须保留：扫描、扣押、认证、任务协议、火灾、进水或制度接口可参与迁移，但不能替代对象原有真实内容。
15. `n→xz`附加测试：迁移前必须有真实内部位置、稳定停留、接收或通行；迁移后必须出现危险可到达性上升、路线/时间窗下降、无法稳定停留，且旧承载不是仅受损而继续主导。
16. `xz生zx`只生成状态层或关系位置层的临时公开决定接口，不生成勇气、能力或稳定领导本体；既有原则、资源与受困对象须作为第三因素分账。

## 5. 已有结构仅作后验参考

### 高频链

```text
x生x并z → x并z生z → z补xn
```

当前后验支持9次；新案例不得自动套用。主链相同不代表完整图同构。

### 搭桥

```text
1生2 → 2生3
背景：1克3
```

必须通过拿桥测试。

### R-REV-01｜稳定位置真反转不可能引理

固定位置表不存在`A生B`同时`B克A`。表面反转至少涉及位置迁移、对象/变量替换、接口断裂、物理终止，或至少一边未达正式资格。

### R-MIG-01｜同载体多位置叠加不等于迁移

```text
对象连续 + 新位置变量新增 + 旧位置变量持续运行
= 多位置叠加，不是迁移
```

### R-MIG-02｜旧现实关系退出—新位置主导的严格迁移

```text
对象连续
+ 旧位置的控制、调用或承载关系真实退出
+ 新位置变量成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移候选
```

当前支持3次：
1. 《十二怒汉》涉案刀：被告可调用工具`x`→司法证据展品`x并z`。
2. 《机器人总动员》同一株植物：WALL-E私人样本`x`→Axiom返航证据壳`x并z`。
3. 《哈利·波特与死亡圣器（下）》同一间隐藏物品室：内部承载`n`→厉火临界空间`xz`。

状态：`supported-positive-3-cross-position`。第三例首次完成非`x→x并z`位置复现，但`n→xz`仍只有一次，需非魔法灾难片复测。

### R-MIG-03｜隐藏属性揭露只增加证据壳，不自动取消原功能

```text
对象/物类已有稳定功能位置A
+ 生产、来源或成分被揭露，新增x并z识别接口
+ 原功能核心变量继续运行
= 位置叠加/信息重估，不是严格迁移
```

当前负例1次：《雪国列车》蛋白块。

### R-MIG-04｜承载崩塌—临界主导迁移

```text
同一空间先稳定接收、容纳、保护或提供通行 n
+ 灾难第三因素持续改变其运行变量
+ 旧承载关系退出
+ 路线、时间窗、危险可到达性与无法停留成为中心 xz
+ 新xz启动合法关系边
= n→xz严格迁移候选
```

当前支持1次：《哈利·波特与死亡圣器（下）》有求必应屋厉火片段。状态：`specific-positive-case-1`。
