## 1. 知识点位置关系

```text
固定十元定义与关系盘
→ 具体名词节点定位（z切分焦点+x现象集合+十元位置）
→ 人物/团队行为与阶段（关系启动器）
→ 生克补关系对子（图的边）
→ 具体动态链图（链序+拓扑）
→ 单案例归档（失败版+断裂）
→ 跨案例后验比较
→ 母型候选/锁定
```

横向结构：

```text
人物/团队+阶段
      └─实施行为→【具体源名词+十元位置】─生/克/补→【具体目标名词+十元位置】
                                      └─机制+被改变变量+证据等级+测试
```

- 节点：具体名词与十元位置；角色名、组织名、场景名不是默认节点。
- 启动器：人物/团队行为与阶段，不等于端点。
- 边：生克补关系对子，必须有机制和目标变量。
- 图结构：主链、支路、汇合、反馈、搭桥、延伸、反转、转位、迁移、断裂。
- 搭桥：`1生2→2生3，背景1克3`，必须通过拿桥测试。
- 反转：稳定位置下要求同一源、目标、对象和变量形成反向A级边；固定位置表中不存在`A生B`且`B克A`的组合。
- 位置迁移：同一具体对象跨阶段改变十元位置后，才可能启动新的合法方向；必须与对象替换、变量替换分账。
- 母型：最后才后验归纳，不参与首遍选片和端点命名。

当前优先级：

```text
关系对子真实性
> 具体动态链图完整度
> 案例积累与失败版
> 跨案例比较
> 母型命名与锁定
```

第一遍分析默认屏蔽母型编号和名称。

## 3. 生克补口径与红线

- 生：源为目标核心变量提供净增量，目标此前不存在或不足。
- 克：目标核心变量、成立资格或实际运行能力下降，不是普通阻碍。
- 补：恢复目标此前真实缺失的核心变量，不是帮助、陪伴或资源共现。
- 箭头表示已审核作用方向，不只表示时间先后。
- 相同对子但顺序不同，原则上登记为不同动态链。
- 串联、并行、汇合、反馈、搭桥、反转、转位、迁移不能互相改写。
- 同一十元字母可能是不同具体对象、阶段和体量，不能自动合并。
- 错误确认仍可是真实`z`，但必须与正确确认按对象分账。
- 制造、创建、训练、赋能、控制、失控、反噬、攻击、杀死和摧毁不能仅凭动词直接判生克补。
- “A制造B，B后来攻击A”先记普通因果与位置转位；必须分别证明两条正式边才能叫反转。
- 勇敢、成长、帮助、压迫、规则、爱、自由、真相、希望、角色名、组织名、动作、场景与镜头不得直接当端点。
- 不要求机械凑齐主克、主补、主生；无A级关系明确写无。

## 4. 顺序、拓扑与位置测试

1. 换序测试。
2. 支路拿掉测试。
3. 汇合分账测试。
4. 反馈方向测试。
5. 拿桥测试。
6. 同字母异对象测试。
7. 断裂测试。
8. 反向解释测试。
9. 反转资格测试：源、目标、对象与变量是否同一；两条边是否分别A级。
10. 控制断裂排除：是否只是遥控器、权限、线路、设备或命令接口失效。
11. 物理攻击排除：是否只是损坏、受伤、死亡或敌我目标倒转。
12. 稳定位置几何测试：固定位置表是否允许`A生B且B克A`；当前枚举结果为无。
13. 位置迁移测试：对象是否连续；z切分焦点、x现象集合、核心变量和体量是否真实改变；迁移前后边分别审核。
14. 对象/变量替换排除：不能把不同人物、不同确认对象或不同目标变量伪装成同一端点迁移。

## 5. 已有链条仅作后验参考

### 5.1 高频链

```text
x生x并z → x并z生z → z补xn
```

新案例不得自动套用。科研、工程与通信案例须区分`x并z生z`和`xn补z`，并区分不同具体程序。

### 5.2 《疾速追杀3》具体候选链

```text
z补xn → xn生xz → zx克n → n克xz
```

只作后验比较，不作选片模具。

### 5.3 搭桥参考

```text
1生2 → 2生3
背景：1克3
```

必须证明2转换的变量和拿掉2后的直接克制或输入断裂。

### 5.4 归因转位

```text
《寻梦环游记》：x_E克z_H；x_E生x并z_E→x并z_E生z_E；x并z_R生z_H→z_H补xn_R；n_H克xz_H
```

`z_E`与`z_H`是不同确认对象，是对象转位，不是真正反转。

### 5.5 造物反噬伪反转负例

```text
《超人总动员》：xn_K生xz_C；遥控接口断裂；控制者变攻击对象；普通攻击
《机械姬》：xn_N生xz_A；安保接口改写；测试对象变逃脱中心；创造者被物理杀死
```

共同边界：控制角色互换、设备失效、造物杀死创造者都不等于同一十元端点的方向反转。

### 5.6 R-REV-01｜稳定位置真反转不可能引理

固定十元位置表逐项枚举：任一`A生B`的B都不以`克A`为固定方向。因此：

```text
稳定十元位置下，不存在 A生B → B克A 的合法组合。
```

表面真反转至少意味着：端点位置迁移、对象替换、变量替换、接口断裂/物理终止，或至少一边未达正式资格。该引理只约束动态图解释，不修改关系表。
