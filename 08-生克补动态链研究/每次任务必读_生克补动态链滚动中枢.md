## 1. 三层结构

```text
关系对子：谁生谁、谁克谁、谁补谁。
动态链：多个真实成立的关系对子按阶段连接。
通用母型：同一抽象动态链在多个独立、跨题材案例中稳定复现，且链序和被改变变量同构。
```

影片名、人物名、场景名和剧情梗概只能作为案例证据。M-001A至M-032均为`legacy-case-chain`。

## 2. 戏剧具体积累格式

```text
人物与阶段
+ 人物行为
+ 具体源名词及十元位置
+ 关系对子
+ 具体目标名词及十元位置
+ 为什么成立
+ 被改变变量
+ 拿掉测试
+ 反向测试
```

人物行为负责关系发生与显影；具体名词固定两端。每个端点先写`z切分焦点+x现象集合+十元位置锚+稳定本体/当前状态+体量/阶段`。

## 3. 生克补口径与红线

- 生：源为目标核心变量提供净增量，目标此前不存在或不足。
- 克：目标核心变量、成立资格或实际运行能力下降，不是普通阻碍。
- 补：恢复目标此前真实缺失的核心变量，不是帮助、陪伴或资源共现。
- 动态链只连接通过具体名词、人物行为、变量、拿掉与反向测试的对子。
- 勇敢、成长、帮助、压迫、规则、爱、自由、真相、希望、角色名、组织名、单个动作、场景与镜头不得直接当端点。
- 资源、设备、权限、通道、奖品、名额、数据、模型与专业结果首先检查`x`。
- 身份、资格、岗位、名单、许可证、合约、论文、专利、标准与公开准入界面首先检查`x并z`。
- `x生x并z`只生可识别、可调用、可核验的资源/资格/岗位壳，不直接生认可、获胜或任务成功。
- `x并z生z`必须证明壳使特定人物、结果或资格获得明确归因确认。
- `z补xn`必须证明确认给既有程序补入参与者、聚焦对象、材料标准、期限或阶段节点。
- 不要求每片机械凑齐主克、主补、主生；没有A级主克必须明确写无。

## 4. 案例链与候选母型状态

- C-001：`x生x并z → x并z生z → z补xn`，暂称“资源/能力正式化—目标/资格确认—程序聚焦”。
- C-001支持5次：《赎金》《疾速追杀2》《查理和巧克力工厂》《隐藏人物》《点球成金》。
- C-001状态：`provisionally-supported-5-with-film-failure-cases`，暂不授予UM编号。
- 同构变量：真实资源、能力、权限、模型或结果掌握→正式可识别、可调用、可核验的壳→特定主体/资格/结果获得明确确认→既有程序获得对象、材料标准和节点。
- 明确失败版：壳存在但关键确认不发生；知晓或口头认同存在但程序对象、标准和节点不改变；旧壳、旧确认、旧程序仅延续不重复累计。
- 剩余门槛：至少一个非影片现实/历史结构复测。
- C-002：`z补xn → xn生xz → zx克n → n克xz`，支持1次《疾速追杀3》，仍缺异题材复现。

母型锁定门槛：多次独立复现、跨题材、关键对子A级、具体名词不同但变量与链序同构、排除题材符号与结果解释、能够指出失败版。
