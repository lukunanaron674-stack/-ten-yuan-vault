## 1. 十元概念预检

每个端点先写：

```text
z切分焦点 + x现象集合 + 十元位置锚
+ 稳定本体/当前状态 + 体量/阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、自由、服从、真相、觉醒、角色名、组织名、单个动作或镜头直接作为端点。

## 2. 生克补口径

- **生**：源为目标核心变量提供净增量。区分直接生、桥接生和允许条件。
- **克**：目标核心变量或成立资格持续下降。区分状态下降、局部成员覆盖下降与整体结构下降。
- **补**：恢复此前真实缺失的核心变量；临时代理、资源、娱乐、课堂机会、领袖示范和单次真相信息不自动算补。

### 制度与个体红线

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离 ≠ 制度整体被克
成员撤回自愿执行、维护或身份再生产 = 可构成低体量正式 zn 克 xn
```

### 示范、模仿、内化

```text
示范者在场时跟随 ≠ 内部 zn
模仿姿势、口号、制服 ≠ 稳定意义
撤场后仍独立判断 + 逆安全方向 + 承担后果
= 才接近自己的 zn
```

### 共同体转制度

```text
领袖命令 + 视觉同步 ≠ n 生 xn
真实共同体先承担归属、协作、保护和任务负荷
→ 为持续处理负荷提炼规则、分工、边界和重复流程
→ 才支持 n 生 xn
```

### nx 生成红线

```text
zx/xn 在场 + 成员服从 ≠ zx/xn 直接生 nx
必须观察无领袖监督仍沿默认路线推进、否决权萎缩、退出成本上升和跨场景复制
nx 可以是多节点动态后果，不得为链条完整伪造单一生关系
```

### 全域掌握、身份壳与局部 nx

```text
高体量 x 掌握生活、媒体、关系与路径接口
→ x 生 x并z，形成可持续调用的身份与世界壳
→ x并z 生 z，使壳被所有关系持续确认
→ xn 不断吸收偏离并恢复默认路线
→ 可长期维持主体局部 nx
```

### 新增：身体与感知接口

```text
高体量 x 若直接掌握身体、生存、神经输入与感知接口
→ x 生出的 x并z 不再只是社会身份壳，而是“现实本身”的可调用壳
→ x并z 生 z 由视觉、触觉、疼痛与所有社会回应共同完成
→ xn 克 zx 的体量会高于普通封闭场景，因为偏离同时遭程序、身体和现实规则回收
```

红线：知道真相不等于已有现实承载；吃药、醒来或穿帮不自动等于补、成长或制度被克。

### 新增：真实世界迁移

```text
脱离伪世界后，主体若没有身体恢复、成员位置、食物、训练、操作接口和返回点
→ 只获得真相，不获得可持续现实
真实 n 可以补入现实身份与承载接口
```

但医疗、技术、教学和共同体常混在一起，必须拆变量；不得写成“朋友补回自由”。

### 退出的复合判定

```text
主体撤回自愿执行与身份复制 = 可构成局部 zn 克 xn
身份不再被本人接受和调用 = x并z 对该主体失效
主体走出场域/断开接口 = 退出结果
```

三者可以同时出现，但不得压成一条“自由克制度”。

- M-002：制度回收—个体继承退出。
- M-003：示范撤场—分化内化—局部拒绝再生产。

## 6. 当前核心缺口

1. 外来示范何时只是允许条件，何时补回真实缺口；
2. 临时共同体能否跨高压留存，决定 `zn 生 n` 或 `n 生 xn` 的稳定性；
3. `nx` 常是多节点后果，需防止把服从画成不存在的直接生关系；
4. 身份壳 `x并z` 能提高识别、认可与退出成本，但不等于内部承载 `n`；
5. 高体量 `x/x并z/xn/z` 可以共同维持局部 `nx`，但仍需区分外部封闭与主体稳定本体；
6. 世界壳直接规定身体与感知接口时，`x 生 x并z` 的体量提高，但关系几何不变；
7. 真相入口、技术训练、身体恢复、共同体承载与内部意义必须分开；
8. 下一步研究多人共同搭建多层世界时，`x 生 x并z` 与 `n 生 xn` 的源端点是否分离。
