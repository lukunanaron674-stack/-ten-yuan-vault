## 1. 十元概念强制预检

在判断任何生克补之前，必须先为源端点与目标端点完成概念锚定：

```text
概念对应的 z 切分焦点
+ 被切分的 x 现象集合
+ 十元位置锚
+ 稳定本体与当前状态的区别
+ 生克补关系与体量
```

禁止把下列剧情词直接当作十元端点：

- 勇敢、成长、帮助、压迫、规则、爱、牺牲、成功、失败；
- 某个角色、某件物品、某个组织的名称；
- 单个动作、镜头、台词或情绪。

这些只能作为待定位材料。必须先回答“它在这部影片中具体改变了哪个十元核心变量”。

## 2. 动态链基本单位

每一个节点必须写清：

```text
阶段
+ 关系双方
+ 源端点与概念锚
+ 目标端点与概念锚
+ 生／克／补类型
+ 被改变变量
+ 可观察结果
+ 最近邻解释
+ 拿掉测试
+ 证据等级
```

禁止只写：

```text
A 克 B
B 被补回
最后生成 C
```

这种箭头串只是剧情梗概，不是动态链。

## 3. 生、克、补口径

### 生

源为目标核心变量提供净增量。区分：直接生、桥接生、允许条件。空位、机会、曝光、信息与熟练度不自动算正式生。

### 克

默认只指目标核心变量或成立资格持续下降。必须区分：显影下降、条件化、排序下降与核心克制。通关、离场、击败一个执行者不自动等于克制整个制度。

### 补

补是恢复目标缺失的核心变量。必须证明缺口、对应变量、源必要性，并排除普通帮助、资源、时间恢复与目标自行生成。补可以带代价；同一结构可在一个端点上克、在另一端点上补。

## 4. 每部影片强制拆分

1. 十元概念预检；
2. 开场稳定结构；
3. 触发事件；
4. 主克；
5. 主缺口；
6. 主补；
7. 主生；
8. 中段关系换挡；
9. 高潮反向关系；
10. 结局稳定结构；
11. 可复用母型。

必须同时标注：稳定本体、当前状态、行为功能、光影、场景、时间关系、关系位置、显影、动态链。

## 5. 判断“搭配好”的标准

1. 概念先行：每个端点先完成十元锚定；
2. 因果清楚：前一关系真实改变后一阶段变量；
3. 缺口对应：补回的正是此前缺失或受损变量；
4. 不跳步：承载、确认、自主行动之间有中间机制；
5. 有换挡：同一关系不机械重复；
6. 有代价：补与生不等于免费升级；
7. 有反向检验：高潮检验主体是否从目标端转为源端；
8. 有余波：结局显示制度、身份与主体分别发生什么；
9. 可迁移：母型至少能解释另一部影片。

## 6. 证据等级

- A：文本内直接呈现端点、机制与结果；
- B：文本内强推断，存在少量未排除因素；
- C：跨文本结构重复；
- D：理论构造测试；
- X：只有共现、先后、视觉相似或剧情总结。

主链至少一个关键节点达到 A，其他不得低于 B。

## 7. 当前影片结论｜《千与千寻》v1.0

本轮修正后的主链：

```text
xn 克 zx
→ n 补 x并z
→ zn 生 n
→ 规则通关／身份退出
```

### 锁定到审计层的判断

- 主克：汤屋规则 `xn` 限制新进入者未经许可的最终决定接口 `zx`；
- 主补：汤屋承载结构 `n` 补出“千”这一场内可持续身份接口 `x并z`，但代价是真名被替换；
- 主生：千寻的稳定承诺 `zn` 推出对多个对象的持续承载 `n`；
- 结尾：不是正式克制汤屋，而是掌握规则、通过测试、取回身份并退出场域。

### 被撤回的旧说法

- 不再把开场写成笼统 `z 克 x / z 克 zn`；
- 不再把白龙、小玲、锅炉爷爷打包成同一个主补；
- 不再把熟练度增长直接写成 `zn 生 x`；
- 不再把结尾写成 `zn 克 z`。

## 8. 当前母型

### M-001A｜制度限位—带代价纳入—内部承载扩大—通关退出

```text
xn 克 zx
→ n 补 x并z
→ zn 生 n
→ 条件满足／身份退出
```

状态：`candidate`。只有《千与千寻》一部支持，不能锁定。

### M-001B｜真实称呼回认支链

名字被替换后，跨阶段关系保留真实称呼，使身份连续性增强。暂不指定正式生克补。

## 9. 当前核心缺口

1. 需要一部“结尾真正改变制度成立资格”的影片，与《千与千寻》的通关退出做对照；
2. 需要判断 `xn 克 zx` 在制度影片中何时只是许可摩擦，何时真正压低决定接口；
3. 需要比较“带代价的补”与纯恢复型补的观众效果；
4. 需要验证 `zn 生 n` 是否能跨题材稳定出现。
