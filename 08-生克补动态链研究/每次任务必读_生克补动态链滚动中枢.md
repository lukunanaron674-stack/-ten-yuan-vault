# 每次任务必读｜生克补动态链滚动中枢

> 本文件是《生克补动态链研究》的强制启动缓存与滚动推进中枢。每次必须从真实断点继续，并在结束前原位回写。不得只在聊天里分析电影。

## 0. 强制启动顺序

```text
读取当前 main SHA
→ 读取本文件
→ 读取十元关系防遗忘清单
→ 读取十元生补克表
→ 读取动态链总索引与分析模板
→ 读取上一部影片案例与唯一运行账本
→ 承接 next_priority_film / next_priority_question
→ 才能开始本轮分析
```

每轮必须记录：起始 main SHA、本文件版本、十元关系表版本、框架版本、上一轮影片、上一轮结论、本轮影片、本轮研究问题。

## 1. 当前研究目标

本阶段不再只问“某两元是否生、克、补”，而研究：

1. 一部影片中哪些关系是主关系，哪些只是辅助关系；
2. 生、克、补如何按阶段排列；
3. 哪种搭配能形成可信成长、悲剧、治愈、悬念或反转；
4. 哪些变化只是状态、场景、光影或共现；
5. 如何把跨影片重复结构沉淀成可复用叙事母型。

## 2. 动态链基本单位

每一个节点必须写清：

```text
阶段
+ 关系双方
+ 源端点
+ 目标端点
+ 生／克／补类型
+ 被改变变量
+ 可观察结果
+ 最近邻解释
+ 证据等级
```

禁止只写：

```text
A 克 B
B 被补回
最后生成 C
```

这种箭头串看起来很聪明，实际上只是把剧情梗概穿上实验服。

## 3. 生、克、补的动态链口径

### 生

源为目标核心变量提供净增量。必须区分：

- 直接生：源本身使目标核心变量增长；
- 桥接生：源只打开入口，另一个机制完成目标；
- 允许条件：源只制造空位、机会或显影环境，不算正式生。

### 克

默认只指目标核心变量或成立资格下降。必须区分：

- 显影下降：做不到、说不出、无法实践；
- 条件化：适用范围缩小；
- 排序下降：仍正确，但优先级下降；
- 核心克制：正确性、最终指导资格或核心功能持续下降。

### 补

补不是泛泛帮助，而是恢复目标缺失的核心变量。必须证明：

- 目标此前确实缺失或受损；
- 源提供的变量与缺口对应；
- 拿掉源后恢复显著下降；
- 不是由第三因素、时间自然恢复或目标自行生成。

## 4. 每部影片强制拆分

1. 开场稳定结构；
2. 触发事件；
3. 主克；
4. 主缺口；
5. 主补；
6. 主生；
7. 中段关系换挡；
8. 高潮反向关系；
9. 结局稳定结构；
10. 可复用母型。

必须同时标注：稳定本体、当前状态、行为功能、光影、场景、时间关系、关系位置、显影、动态链。

## 5. 判断“搭配好”的标准

一条搭配至少满足：

1. 因果清楚：前一关系真实改变后一阶段的变量；
2. 缺口对应：补回的正是此前被克或缺失的变量；
3. 不跳步：从承载、确认到自主行动之间有中间机制；
4. 有换挡：同一关系不会机械重复整部影片；
5. 有代价：新生关系必须通过选择、损失或冲突显影；
6. 有反向：高潮能检验主角是否从被作用者转成作用源；
7. 有余波：结局显示哪些变量稳定，哪些只是暂时状态；
8. 可迁移：母型能解释至少另一部影片，而不是影片专属复述。

## 6. 证据等级

- A：文本内直接呈现端点、机制与结果；
- B：文本内强推断，存在少量未排除因素；
- C：跨文本结构重复，可支持母型但不能单独锁定关系；
- D：理论构造测试，只用于排除和验证；
- X：只有共现、先后、视觉相似或剧情总结。

主链不得由 X 级证据构成。至少一个关键节点达到 A，其他节点不得低于 B。

## 7. 当前可调用的搭配母型

### 待验证母型 M-001：压缩 → 承载 → 回认 → 自生 → 反向夺回

```text
外部结构压缩行动与判断资格
→ 他者提供最低现实承载
→ 可信关系恢复主体自我确认
→ 内部判断生成自主行动
→ 主体在高潮反向克制原压迫结构
```

当前证据：仅有《千与千寻》初步口头分析，尚未完成仓库内规范审计，状态为 `candidate`。
