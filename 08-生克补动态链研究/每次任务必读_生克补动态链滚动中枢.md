
`001-概念的定义.md`已降为`legacy-evidence-only`，不得再作为动态链现行 source of truth。旧`z切分焦点+x现象集合`只能解释历史文档如何形成，不能生成、替代或证明现行十元端点。

## 1. 核心方法与红线

```text
对象、主体与阶段明确
→ 信息卡确认候选端点“是什么”
→ 准度卡完成对象分层、最近邻、拿掉与反向
→ 生卡 / 克卡 / 补卡确认关系类型的必要条件
→ 十元生补克表与专项索引确认关系是否已锁定
→ 人物/团队行为与阶段
→ 确认主体/内容/证据状态分账
→ 只登记直接生克补关系边
→ 间接路径、条件节点、失败边另记
→ 单一核心变量
→ 主链、支路、汇合、断裂、维持与替换
→ 单案例归档
→ 后验比较
```

- 信息卡回答“它是什么”；准度卡回答“为什么必须判成它”；生克补卡回答“两个已成立端点之间发生了什么”。三层不得互相代替。
- 生：目标核心变量此前不存在或不足，源提供净增量。
- 克：目标成立资格、核心变量或实际运行能力下降。
- 补：目标原有真实缺口被补入对应变量。
- 勇敢、成长、压迫、规则、爱、自由、真相、希望、角色名、场景和单个动作不得直接当端点。
- 共现、帮助、阻碍、先后、通关、离场、攻击、胜利、回家、获释和最终团聚不得直接判关系。
- 相同字母但不同对象、主体、阶段、确认内容、采用范围与体量必须分账。
- 资源不等于承载；空间不天然是`n`；锁闭、固定身体与最低口粮不等于被接住。
- `x并z生z`必须写确认主体、确认内容与证据状态；`z补xn`必须写程序原缺口。
- `xz生zx`只生成临时决定接口，不生成勇气、爱情或稳定人格。
- 确认不得使用z0—z4单轴等级；必须分别记录确认主体、确认内容、证据状态、采用范围与阶段。
- 个人正确判断不等于机构可执行确认；机构采用也不改变客观事实本身。
- `z_right/z_wrong`只是具体确认的正确性注记，不是新十元位置。
- 只登记直接关系边。若真实结构为`A生C→C克B`，不得再追加“A间接克B”进入关系表或累计次数。
- 链尾总体效果只能作为动态链效果，不得倒写成源端对链尾的直接生克补。
- 补关系不要求与被克对象同层；只要求目标原缺口与补入变量具体对应。
- 每片只设一个核心被改变变量；其他后果作为展开指标。
- 每片先标动态类型：改变、崩坏、维持、循环或替换；动态类型不是新的十元关系。
- 体量分别记录影响范围、持续时间与不可逆程度，不做固定权重平均。
- 关系置信度按端点稳定度、机制清晰度、独立证据强度、竞争解释排除度、拿掉/反向可逆性、跨案例复现度六项记录，最终取最弱项。
- 每片至少记录一个正式失败候选，写清违反测试与最近邻替代。
- 默认按C单场→B段落→A整片推进，禁止从剧情梗概直接跳到整片母型。
- 旧案例保留原貌作历史证据；其中`z切分焦点+x现象集合`、旧十元昵称或旧关系口径不得直接迁移到新案例，必须重新经过信息卡与准度卡。

### 1.1 `x克z`严格门槛

- 必须有明确主体主动控制必要确认入口。
- 必须限定确认主体、确认内容、采用范围和阶段。
- 拿掉入口控制后，目标确认能力不得仍以同样路径下降。
- 普通混乱、人数增加、监控偶然损坏、自然漏登、无人目击、搜查无果、证人自然遗忘、诱导询问、确认偏差、自然传播和程序惯性不等于`x克z`。
- 错误确认成立与正确确认下降必须分账；错误确认本身不是克源。
- 没有单一主体持续掌握必要确认入口时，允许责任壳和错误确认成立，但严格`x克z_right`应判失败边。
- 主体只控制自我呈现、口供或表演材料，而法院、机构仍有独立物证、专家反鉴别和审查入口时，优先判`x生x并z→x并z生z_wrong`，不得直接写“表演克真相”。

### 1.2 错误确认来源

```text
制造型：主动生成、替换或伪造确认材料
转译型：含混现象被解释框组织成确定责任/身份
缺证型：必要证据不足，错误候选未被排除
惯性型：已有错误确认持续补入旧程序
```

同一案例可同时存在多类，但必须按主体、阶段和变量分账。
