## 1. 知识点位置关系总图

```text
固定定义与关系盘
→ 具体名词节点定位（z切分焦点+x现象集合+十元位置）
→ 人物/团队行为与阶段（关系启动器）
→ 关系对子（图的边：机制+变量+证据+测试）
→ 具体动态链图（链序+拓扑）
→ 单案例归档（失败版+断裂）
→ 跨案例后验比较
→ 母型候选/锁定
```

横向结构：

```text
人物/团队+阶段
      └─实施行为→【具体源名词+十元位置】─生/克/补→【具体目标名词+十元位置】
                                      └─机制+被改变变量+证据等级+测试
```

- 节点：具体名词与十元位置；角色名、组织名、场景名不是默认节点。
- 启动器：人物/团队行为与阶段，不等于端点。
- 边：生克补关系对子，必须有机制和目标变量。
- 图结构：主链、支路、汇合、反馈、搭桥、延伸、反转、转位、断裂。
- 搭桥：`1生2→2生3，背景1克3`，必须通过拿桥测试；不是任何中间节点。
- 反转：要求同一具体端点和同一关系对象跨阶段改变方向；两个不同`z`对象互换确认位置只能记转位。
- 母型：最后才后验归纳，不参与首遍选片和端点命名。

当前优先级：

```text
关系对子真实性
> 具体动态链图完整度
> 案例积累与失败版
> 跨案例比较
> 母型命名与锁定
```

第一遍分析默认屏蔽母型编号和名称。

每个案例必须同时提交：

```text

```

不存在的项目明确写“无”。

## 3. 生克补口径与红线

- 生：源为目标核心变量提供净增量，目标此前不存在或不足。
- 克：目标核心变量、成立资格或实际运行能力下降，不是普通阻碍。
- 补：恢复目标此前真实缺失的核心变量，不是帮助、陪伴或资源共现。
- 箭头表示已审核作用方向，不只表示时间先后。
- 相同对子但顺序不同，原则上登记为不同动态链。
- 串联、并行、汇合、反馈、搭桥、反转与转位不能互相改写。
- 同一十元字母可能是不同具体对象、阶段和体量，不能自动合并。
- 错误确认仍可是真实`z`，但必须与正确确认按对象分账。
- 勇敢、成长、帮助、压迫、规则、爱、自由、真相、希望、角色名、组织名、动作、场景与镜头不得直接当端点。
- 不要求机械凑齐主克、主补、主生；无A级关系明确写无。

## 4. 顺序与拓扑测试

1. 换序测试。
2. 支路拿掉测试。
3. 汇合分账测试。
4. 反馈方向测试。
5. 拿桥测试。
6. 同字母异对象测试。
7. 断裂测试。
8. 反向解释测试。
9. 反转资格测试：源、目标与被改变变量是否确为同一具体对象跨阶段，而非两个对象换位。

## 5. 已有链条仅作后验参考

### 高频链

```text
x生x并z → x并z生z → z补xn
```

新案例不得自动套用。科研、工程与通信案例须区分`x并z生z`和`xn补z`，并区分不同具体程序。

### 《疾速追杀3》具体候选链

```text
z补xn → xn生xz → zx克n → n克xz
```

只作后验比较，不作选片模具。

### 搭桥参考

```text
1生2 → 2生3
背景：1克3
```

必须证明2转换的变量和拿掉2后的直接克制或输入断裂。

### 《寻梦环游记》归因转位具体链

```text
主克：x_E克z_H
冒署支路：x_E生x并z_E → x并z_E生z_E
揭露链：x并z_R生z_H → z_H补xn_R
承载延伸：n_H克xz_H
```

`z_E`与`z_H`是不同确认对象。本案是确认对象转位，不是同一`z`先被生后被克的真正方向反转。

## 6. 当前接续点

```text
最近完成：《寻梦环游记》（2017）作者归因夺取与公开揭露片段
主克：埃内斯托掌握作品、传播和署名入口x_E克赫克托正确作者确认z_H
冒署支路：x_E生埃内斯托公共名望壳x并z_E→x并z_E生错误作者确认z_E
揭露链：可核验证据壳x并z_R生赫克托正确确认z_H→z_H补家族讲述与作品归档程序xn_R
承载延伸：家族接纳与祭坛承载n_H克遗忘临界xz_H
汇合节点：z_H
反馈环：无
搭桥：无
反转/转位：确认对象由z_E转位到z_H；因对象不同，不登记真正反转
断裂：无揭露证据壳时，跨主体正确确认与后续程序改线断裂
方法结论：错误确认也可能由稳定公共壳真实生成；揭露必须经过可识别、可归因和可复核接口，不能写成“真相自动胜利”
```
