## 1. 三层结构与当前优先级

```text
关系对子：谁生谁、谁克谁、谁补谁。
动态链：多个真实成立的关系对子按阶段连接，并保留图结构。
通用母型：多条独立动态链在关系方向、链序、拓扑和被改变变量上稳定同构后，才后验归纳。
```

当前优先级：**具体动态链图谱积累第一，母型命名与锁定后置。**

第一遍分析默认屏蔽母型编号和名称。影片名、人物名、场景名和剧情梗概只能作为案例证据。M-001A至M-032均为`legacy-case-chain`。

## 2. 具体积累格式

```text
人物/团队与阶段
+ 人物/团队行为
+ 具体源名词及十元位置
+ 关系对子
+ 具体目标名词及十元位置
+ 为什么成立
+ 被改变变量
+ 拿掉测试
+ 反向测试
```

行为负责关系发生与显影；具体名词固定两端。端点先写`z切分焦点+x现象集合+十元位置锚+稳定本体/当前状态+体量/阶段`。

每个案例必须同时提交两种表示：

```text
文字链：完整写人物行为、具体端点、关系方向和被改变变量。
图结构：标明主链、并行支路、汇合节点、反馈环、搭桥节点、后续延伸、反转/转位、断裂节点和阶段编号。
```

不存在的图结构项目明确写“无”，不能为了图形完整强行制造。

## 3. 生克补口径与红线

- 生：源为目标核心变量提供净增量，目标此前不存在或不足。
- 克：目标核心变量、成立资格或实际运行能力下降，不是普通阻碍。
- 补：恢复目标此前真实缺失的核心变量，不是帮助、陪伴或资源共现。
- 动态链只连接通过人物行为、具体名词、变量、拿掉与反向测试的对子。
- 箭头表示已审核的作用方向，不只表示时间先后。
- 相同关系对子但顺序不同，原则上登记为不同动态链。
- 串联、并行、汇合、反馈和搭桥是不同机制，不能互相改写。
- 同一十元字母可能对应不同具体对象、阶段和体量，不能自动合并节点。
- 勇敢、成长、帮助、压迫、规则、爱、自由、真相、希望、角色名、组织名、单个动作、场景与镜头不得直接当端点。
- 资源、设备、权限、数据、模型、样品、器件、技术和专业结果首先检查`x`。
- 身份、资格、岗位、名单、许可证、合约、论文、专利、标准、正式报告、图纸和技术包首先检查`x并z`。
- `x生x并z`只生可识别、可调用、可核验的资源/资格/成果壳，不直接生确认或最终成功。
- `x并z生z`必须证明壳使特定人物、结果、资格或技术获得明确归因确认。
- `z补xn`必须证明确认给既有程序补入参与者、对象、材料标准、期限或节点。
- 科研工程案例必须分开`x并z生z`与`xn补z`：正式壳提供识别归因接口，验证程序提供跨时间证据。
- 专利壳存在不等于科学确认、工程可靠性确认或产业采用确认；三者必须分阶段记录。
- 确认存在不等于研发、采购、许可或制造程序已经改线。
- 不要求每个案例机械凑齐主克、主补、主生；没有A级主克必须明确写无。

## 4. 顺序与拓扑测试

每条具体动态链完成后至少测试：

1. 换序测试：交换两段后，因果是否仍成立？
2. 支路拿掉测试：去掉并行支路，汇合节点具体损失哪项变量？
3. 汇合分账测试：不同来源提供的是重复变量，还是不同必要变量？
4. 反馈方向测试：后段是否真的回头改变前段，而不只是继续产生新证据？
5. 拿桥测试：去掉中介节点，前后两端是否恢复直接克制、失去输入或无法启动？
6. 同字母异对象测试：相同十元节点是否其实属于不同具体名词、阶段或体量？
7. 断裂测试：某段不成立时，后续哪些关系仍可独立运行？
8. 反向解释测试：是否由后段结果倒证前段，或由第三因素同时造成？

## 5. 已有链条仅作后验比较参考

### 高频具体链

```text
x生x并z → x并z生z → z补xn
```

已有多个案例出现，但新案例不得因此自动套用。科研工程案例还要单独审计并行的`xn补z`及不同体量程序节点。

### 《疾速追杀3》具体候选链

```text
z补xn → xn生xz → zx克n → n克xz
```

目前只保留为具体链候选，不作为选片模具。

### 搭桥结构参考

```text
1生2 → 2生3
背景关系：1克3
```

中介2是否构成搭桥，必须通过拿桥测试和变量转换证明；末尾若有补，另写方向、缺口和恢复变量。不得因为几何上符合就主动寻找或套入案例。
