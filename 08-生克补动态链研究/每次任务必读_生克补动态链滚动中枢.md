## 1. 十元概念预检

每个端点先写：

```text
z切分焦点 + x现象集合 + 十元位置锚
+ 稳定本体/当前状态 + 体量/阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、自由、服从、真相、觉醒、时间、命运、角色名、组织名、单个动作或镜头直接作为端点。

## 2. 生克补通用口径

- **生**：源为目标核心变量提供净增量。区分直接生、桥接生和允许条件。
- **克**：目标核心变量或成立资格持续下降。区分状态下降、局部成员覆盖下降与整体结构下降。
- **补**：恢复此前真实缺失的核心变量；信息、资源、训练、临时代理、领袖示范和单次情绪变化不自动算补。

## 3. 当前强制红线

### 3.1 制度、个体与退出

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离或通关 ≠ 制度整体被克
成员撤回自愿执行、维护或身份再生产 = 才可能构成低体量 zn 克 xn
```

### 3.2 示范、模仿与内化

```text
示范者在场时跟随 ≠ 内部 zn
撤场后仍独立判断 + 逆安全方向 + 承担后果
= 才接近自己的 zn
```

### 3.3 共同体转制度

```text
领袖命令 + 团队同框 + 计划书 + 视觉同步 ≠ n 生 xn
共同体先承担跨成员协作、保护、同步和回收负荷
→ 为持续处理负荷提炼规则、分工、边界、信号和备用流程
→ 才支持 n 生 xn
```

### 3.4 接口、壳、确认与制度执行

```text
设备、样本、语料、影像、概率、检测器与数据库 = 首先是 x
稳定可识别、可调用的身份/语言/未来角色界面 = x并z
明确主体确认明确对象与内容 = z
授权、筛选、抓捕、门禁、日检、分流、冻结与司法 = xn
制度执行使安全路线与时间窗缩窄 = xn 生 xz
主体决定必须先通过既有结构 = xn 克 zx
```

红线：接口和数据长得再像真理，也不会自动获得 `z/xz/zn` 资格。

### 3.5 时间、预知与原则

```text
提前知道结果或损失 = x/xn 信息条件变化
路线、退路和最后窗口真实缩窄 = 才可能形成 xz
行动改变 ≠ zn 改变
原则是否被克 = 看最终指导资格是否持续撤销
```

### 3.6 概率身份壳与机会制度

```text
血液、尿液、毛发、基因读数、评分与检测设备 = x
“有效/无效”、风险等级、职业适配、信用等级与可调用档案 = x并z
机构确认“谁适合进入什么位置” = z
招聘、门禁、日检、保险、教育分流与任务分配 = xn
能力尚未进入现实，资格已被身份流程过滤 = xn 克 zx
```

红线：

1. 概率提示不等于制度克制；必须观察是否持续关闭申请、解释、申诉和进入接口。
2. 没有倒计时追捕，也可存在高体量 `xn 克 zx`；长期机会关闭不必表现为 `xz`。
3. 借用样本、证件和档案首先是掌握接口 `x` 与调用既有 `x并z` 壳，不等于本体替换。
4. 初期交易与一次资源供应不是 `n`；只有双方跨阶段承担秘密、身体、失败与生活负荷，才接近真实承载。
5. 个体穿过筛选节点不等于制度整体被克；必须观察规则、成员维护和机会分配是否持续下降。
6. 牺牲、自焚、成功登船和一次放行都不能自动证明补、`zn生n` 或制度崩塌。

## 6. 当前核心缺口

1. 外来示范何时只是允许条件，何时补回真实缺口；
2. 临时共同体能否跨高压留存，决定 `zn生n` 或 `n生xn` 的稳定性；
3. `nx` 常是多节点后果，不得伪造单一直接生关系；
4. 身份壳 `x并z` 不等于内部承载 `n`；
5. 真相、训练、身体恢复、共同体承载与内部意义必须分开；
6. 多人造界必须拆 `x生x并z` 与 `n生xn`；
7. 时间接口 `x`、时间组织 `xn`、临界风险 `xz` 必须分层；
8. 团队执行既有协议不等于团队生出协议；
9. 牺牲结果不能单独证明 `zn生n`、补或稳定人格本体；
10. 预测材料、概率身份壳、确认、制度执行与临界追捕必须分层；
11. 长期机会关闭可构成高体量 `xn克zx`，不必先出现追捕倒计时；
12. 借壳运行必须区分：掌握接口、调用既有身份壳、内部承载、身份认领和制度脱钩；
13. 下一步用《雪国列车》检验物理空间、阶级身份、资源掌握、内部承载和运行规则如何叠加。
