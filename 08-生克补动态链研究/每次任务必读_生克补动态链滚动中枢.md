## 1. 知识点位置关系总图

```text
固定定义与关系盘
→ 具体名词节点定位（z切分焦点+x现象集合+十元位置）
→ 人物/团队行为与阶段（关系启动器）
→ 关系对子（图的边：机制+变量+证据+测试）
→ 具体动态链图（链序+拓扑）
→ 单案例归档（失败版+断裂）
→ 跨案例后验比较
→ 母型候选/锁定
```

横向结构：

```text
人物/团队+阶段
      └─实施行为→【具体源名词+十元位置】─生/克/补→【具体目标名词+十元位置】
                                      └─机制+被改变变量+证据等级+测试
```

- 节点：具体名词与十元位置；角色名、组织名、场景名不是默认节点。
- 启动器：人物/团队行为与阶段，不等于端点。
- 边：生克补关系对子，必须有机制和目标变量。
- 图结构：主链、支路、汇合、反馈、搭桥、延伸、反转、转位、断裂。
- 搭桥：`1生2→2生3，背景1克3`，必须通过拿桥测试。
- 反转：要求同一具体源、目标、对象和变量跨阶段形成可审核反向边；控制者变成被攻击对象、设备失效和物理伤害都不自动构成反转。
- 母型：最后才后验归纳，不参与首遍选片和端点命名。

当前优先级：

```text
关系对子真实性
> 具体动态链图完整度
> 案例积累与失败版
> 跨案例比较
> 母型命名与锁定
```

第一遍分析默认屏蔽母型编号和名称。

```text

```

不存在的项目明确写“无”。

## 3. 生克补口径与红线

- 生：源为目标核心变量提供净增量，目标此前不存在或不足。
- 克：目标核心变量、成立资格或实际运行能力下降，不是普通阻碍。
- 补：恢复目标此前真实缺失的核心变量，不是帮助、陪伴或资源共现。
- 箭头表示已审核作用方向，不只表示时间先后。
- 相同对子但顺序不同，原则上登记为不同动态链。
- 串联、并行、汇合、反馈、搭桥、反转与转位不能互相改写。
- 同一十元字母可能是不同具体对象、阶段和体量，不能自动合并。
- 错误确认仍可是真实`z`，但必须与正确确认按对象分账。
- 制造、创建、训练、赋能、控制、失控、反噬、攻击和摧毁均不能仅凭动词直接判生克补。
- “A制造B，B后来攻击A”只能先记普通因果与关系位置转位；必须分别证明前段生边与后段反向克边，且两边端点和变量一致，才能叫反转。
- 勇敢、成长、帮助、压迫、规则、爱、自由、真相、希望、角色名、组织名、动作、场景与镜头不得直接当端点。
- 不要求机械凑齐主克、主补、主生；无A级关系明确写无。

## 4. 顺序与拓扑测试

1. 换序测试。
2. 支路拿掉测试。
3. 汇合分账测试。
4. 反馈方向测试。
5. 拿桥测试。
6. 同字母异对象测试。
7. 断裂测试。
8. 反向解释测试。
9. 反转资格测试：源、目标、对象与变量是否同一；前后两条边是否分别达到A级。
10. 控制断裂排除：是否只是遥控器、权限、线路、设备或命令接口失效。
11. 物理攻击排除：是否只是损坏、受伤、死亡或敌我目标倒转。

## 5. 已有链条仅作后验参考

### 高频链

```text
x生x并z → x并z生z → z补xn
```

新案例不得自动套用。科研、工程与通信案例须区分`x并z生z`和`xn补z`，并区分不同具体程序。

### 《疾速追杀3》具体候选链

```text
z补xn → xn生xz → zx克n → n克xz
```

只作后验比较，不作选片模具。

### 搭桥参考

```text
1生2 → 2生3
背景：1克3
```

必须证明2转换的变量和拿掉2后的直接克制或输入断裂。

### 《寻梦环游记》归因转位具体链

```text
主克：x_E克z_H
冒署支路：x_E生x并z_E → x并z_E生z_E
揭露链：x并z_R生z_H → z_H补xn_R
承载延伸：n_H克xz_H
```

`z_E`与`z_H`是不同确认对象。本案是确认对象转位，不是真正方向反转。

### 《超人总动员》造物反噬伪反转负例

```text
主链：克罗诺斯测试、升级与部署程序xn_K生城市攻击临界xz_C
普通因果：机器人识别遥控器→击落控制接口→辛德罗姆失去控制→机器人攻击辛德罗姆
反转：无
转位：辛德罗姆由控制者转为攻击目标
断裂：遥控器失效后，控制脚本和伪英雄确认路径断裂
```

关键边界：控制角色互换、机器反噬创作者和物理攻击方向倒转，不等于同一十元端点的关系方向反转。
