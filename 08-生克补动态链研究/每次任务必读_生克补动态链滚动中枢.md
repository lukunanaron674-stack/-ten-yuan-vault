```text

```

每轮必须记录：起始 main SHA、本文件版本、概念定义版本、十元关系表版本、框架版本、上一轮影片、上一轮结论、本轮影片、本轮研究问题。

## 1. 十元概念强制预检

任何生克补判断前，先完成：

```text
z 切分焦点
+ x 现象集合
+ 十元位置锚
+ 稳定本体／当前状态
+ 关系体量与阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、反抗、自由、牺牲、成功、失败、角色名、组织名、单个动作或镜头直接作为十元端点。

## 2. 动态链基本单位

每个节点必须写：阶段、关系双方、源/目标概念锚、生克补类型、被改变变量、可观察结果、最近邻、拿掉测试与证据等级。

禁止用“被压迫→被帮助→成长→胜利”这种剧情梗概冒充动态链。

## 3. 生、克、补口径

### 生
源为目标核心变量提供净增量。区分直接生、桥接生与允许条件。空位、机会、曝光、信息、熟练度和领袖示范不自动算生。

### 克
目标核心变量或成立资格持续下降。必须区分显影下降、条件化、排序下降、局部成员覆盖下降与整体结构下降。

**新增红线：**

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离 ≠ 制度整体被克
低体量成员撤回自愿执行、维护和身份再生产 = 可构成局部正式 zn 克 xn
```

制度整体被克，必须观察跨成员覆盖、自愿执行、内部修复或跨轮次复制是否持续下降。

### 补
补是恢复目标缺失的核心变量。必须证明缺口、变量对应与源必要性。临时领袖替大家做决定、提供娱乐或制造试验场，不自动等于补回稳定自主。

## 4. 每部影片强制拆分

1. 十元概念预检；
2. 开场稳定结构；
3. 触发事件；
4. 主克；
5. 主缺口；
6. 主补；
7. 主生；
8. 中段换挡；
9. 高潮反向；
10. 结局稳定结构；
11. 可复用母型。

同时标注：稳定本体、当前状态、行为功能、光影、场景、时间关系、关系位置、显影与动态链。

## 5. 判断搭配好的标准

1. 概念先行；
2. 因果清楚；
3. 缺口对应；
4. 不跳步；
5. 有换挡；
6. 有代价；
7. 有反向检验；
8. 有结局余波；
9. 可跨片迁移；
10. 能区分局部克制与整体克制。

## 6. 证据等级

- A：影片直接呈现端点、机制与结果；
- B：强推断，仍有少量第三因素；
- C：跨片重复；
- D：理论构造测试；
- X：共现、先后、视觉相似或剧情总结。

主链至少一个关键节点达到 A，其他不得低于 B。

## 7. 已完成影片

### 《千与千寻》v1.0

```text
xn 克 zx
→ n 补 x并z
→ zn 生 n
→ 规则通关／身份退出
```

结尾不判正式克。制度仍完整运行。

### 《飞越疯人院》v1.0

```text
xn 克 zx
→ 外来 zx 制造反规则试验（允许条件）
→ 群体短时撤回服从
→ 制度以 zx 强制回收并破坏临时 n
→ Chief 形成低体量 zn 克 xn
→ 个体退出；制度整体仍在
```

锁定到本片结尾性质：执行者受伤、设施破坏和个体逃离均不等于制度整体被克；Chief 停止替病房维持沉默身份与自愿覆盖，可判局部成员层正式克。

主补、主生暂不锁定，避免把麦克墨菲的代理行动和短时热闹写成稳定恢复或成熟承载。

```text
xn 克 zx
→ 外来 zx 制造反规则试验
→ 群体短时撤回服从
→ 制度以 zx 强制回收
→ 一名主体形成低体量 zn 克 xn
→ 个体退出，制度整体仍在
```

状态：candidate；支持片：《飞越疯人院》。

## 9. 当前核心缺口

1. 外来领袖示范何时只是允许条件，何时真正补回对象缺失变量；
2. 群体短时参与与成员稳定撤回制度正当性如何区分；
3. `zn 克 xn` 从低体量成员覆盖下降累积为群体再生产下降，需要哪些阶段证据；
4. 临时共同体在高压撤场后能否留存，决定 `zn 生 n` 能否进入主链；
5. 继续比较制度通关、个体退出、局部正式克和制度整体克四种结尾。
