## 1. 知识点位置关系

```text
固定十元定义与关系盘
→ 具体名词节点定位（z切分焦点+x现象集合+十元位置）
→ 人物/团队行为与阶段（关系启动器）
→ 生克补关系对子（图的边）
→ 具体动态链图（链序+拓扑+位置变化）
→ 单案例归档（失败版+断裂）
→ 跨案例后验比较
→ 母型候选/锁定
```

- 节点：具体名词+十元位置。
- 行为：关系启动器，不等于端点。
- 边：生克补对子，必须写机制、目标变量和证据等级。
- 图结构：主链、支路、汇合、反馈、搭桥、延伸、反转、转位、迁移、叠加、断裂。
- 母型：最后才后验归纳，首遍分析必须屏蔽。

当前优先级：

```text
关系对子真实性
> 具体动态图完整度
> 案例积累与失败版
> 跨案例比较
> 母型命名
```

## 2. 具体积累格式

```text
人物/团队与阶段

```

每个案例同时提交文字链与图结构。不存在的主克、主补、搭桥、反馈等明确写“无”。

## 3. 生克补红线

- 生：源为目标核心变量提供净增量，目标此前不存在或不足。
- 克：目标核心变量、成立资格或实际运行能力下降。
- 补：恢复目标此前真实缺失的核心变量。
- 共现、先后、帮助、阻碍、通关、离场、攻击、杀死、制造、训练、控制和失控不能直接判生克补。
- 勇敢、成长、压迫、规则、爱、自由、真相、希望、角色名、场景和单个动作不得直接当端点。
- 相同字母可对应不同对象、阶段和体量，不能自动合并。
- 同一物理载体可被不同z切分同时落在多个十元位置。
- 同一物类或同批产品连续，不等于同一具体对象连续。
- 目标变量下降不等于必有克关系；新增反证、事实更新与前提断裂必须与已锁定克机制分开。
- 隐藏配方、来源或属性被揭露，只能先证明新增识别/归因接口；不能自动宣布原承载、用途或资源位置退出。
- 对象物理属性、生命状态或材质持续，不等于旧控制、调用、承载或归因关系持续。

## 4. 顺序、拓扑与位置测试

1. 换序测试。
2. 支路拿掉与汇合分账。
3. 反馈方向测试。
4. 拿桥测试。
5. 同字母异对象测试。
6. 断裂与反向解释测试。
7. 反转资格：同一源、目标、对象、变量，两条边分别A级。
8. 控制断裂、物理攻击、新事实更新与反证进入排除。
9. 位置迁移：对象连续；迁移前后z切分、x集合、核心变量和体量分别锚定；前后边分别合法。
10. 位置叠加：新位置变量新增而旧位置核心变量继续运行，只记叠加。
11. 严格迁移：旧位置现实关系显著下降、退出或不再主导，新位置变量成为实际运行中心。
12. 对象物理属性持续，不等于旧十元关系持续；必须检查控制主体、调用权与运行中心。
13. 同一类别的不同样本不能替代单个对象连续性；类别层变化先记物类重分类或信息叠加。
14. 新位置必须启动至少一条A级合法关系边；只成为象征、纪念物或剧情焦点不足。
15. 第三因素必须保留：扫描、扣押、认证、任务协议或制度接口可参与迁移，但不能替代对象原有真实内容。

## 5. 已有结构仅作后验参考

### 高频链

```text
x生x并z → x并z生z → z补xn
```

当前后验支持9次；新案例不得自动套用。主链相同不代表完整图同构。

### 搭桥

```text
1生2 → 2生3
背景：1克3
```

必须通过拿桥测试。

### R-REV-01｜稳定位置真反转不可能引理

固定位置表不存在`A生B`同时`B克A`。表面反转至少涉及位置迁移、对象/变量替换、接口断裂、物理终止，或至少一边未达正式资格。

### R-MIG-01｜同载体多位置叠加不等于迁移

```text
对象连续 + 新位置变量新增 + 旧位置变量持续运行
= 多位置叠加，不是迁移
```

### R-MIG-02｜旧现实关系退出—新接口主导的严格迁移

```text
对象连续
+ 旧位置的控制、调用或承载关系真实退出
+ 新位置接口成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移候选
```

当前支持2次：
1. 《十二怒汉》涉案刀：被告可调用工具`x`→司法证据展品`x并z`。
2. 《机器人总动员》同一株植物：WALL-E私人样本`x`→Axiom返航证据壳`x并z`。

状态：`supported-positive-2-cross-domain`。第二例完成非司法复现，但两例都属于`x→x并z`，尚未证明其他位置迁移同构。

### R-MIG-03｜隐藏属性揭露只增加证据壳，不自动取消原功能

```text
对象/物类已有稳定功能位置A
+ 生产、来源或成分被揭露，新增x并z识别接口
+ 原功能核心变量继续运行
= 位置叠加/信息重估，不是严格迁移
```

当前负例1次：《雪国列车》蛋白块。配方揭露后，口粮仍可供能、仍被食用、生产配给仍运行；新增的是生产流程揭露壳与Curtis的配方确认。
