## 3. 生克补红线

- 生：源为目标核心变量提供净增量，目标此前不存在或不足。
- 克：目标核心变量、成立资格或实际运行能力下降。
- 补：恢复目标此前真实缺失的核心变量。
- 共现、先后、帮助、阻碍、通关、离场、攻击、杀死、制造、训练、控制和失控不能直接判生克补。
- 勇敢、成长、压迫、规则、爱、自由、真相、希望、角色名、场景和单个动作不得直接当端点。
- 相同字母可对应不同对象、阶段和体量，不能自动合并。
- 同一物理载体可被不同z切分同时落在多个十元位置。
- 同一物类或同批产品连续，不等于同一具体对象连续。
- 目标变量下降不等于必有克关系；新增反证、事实更新与前提断裂须与已锁定克机制分开。
- 对象物理属性、生命状态、材质或空间边界持续，不等于旧控制、调用、承载或归因关系持续。
- 灾难发生在承载空间内部，不等于空间已从`n`迁移为`xz`；必须证明旧接收、保护、停留、通行和运输关系退出。
- 火灾、进水、坍塌、撞击、失压、爆炸等只先记必要第三因素，不能单个动作直接充当迁移或关系边。
- 严重受损不自动等于严格迁移；若生命维持、内部位置、接收、返航或保护关系继续主导，应判`n+xz`叠加而非`n→xz`。
- 组合系统中某子模块停机，不等于整个组合承载退出；必须检查是否发生承载中心重构。
- 外部救生艇、车辆、支援船或避难所接手人员，不等于旧承载对象内部重构；必须重新划定对象边界。

## 4. 顺序、拓扑与位置测试

1. 换序测试。
2. 支路拿掉与汇合分账。
3. 反馈方向测试。
4. 拿桥测试。
5. 同字母异对象测试。
6. 断裂与反向解释测试。
7. 反转资格：同一源、目标、对象、变量，两条边分别A级。
8. 控制断裂、物理攻击、新事实更新与反证进入排除。
9. 位置迁移：对象连续；迁移前后z切分、x集合、核心变量和体量分别锚定；前后边分别合法。
10. 位置叠加：新位置变量新增而旧位置核心变量继续运行，只记叠加。
11. 严格迁移：旧位置现实关系显著下降、退出或不再主导，新位置变量成为实际运行中心。
12. 物理本体持续不等于旧十元关系持续；检查控制主体、调用权、接收能力、通行结构和运行中心。
13. 新位置必须启动至少一条A级合法关系边；只成为灾难背景或剧情焦点不足。
14. 第三因素必须保留：扫描、扣押、认证、任务协议、火灾、进水、撞击、爆炸或制度接口可参与迁移，但不能替代对象原有真实内容。
15. `n→xz`附加测试：迁移前有真实内部位置、稳定停留、接收、运输或通行；迁移后危险可到达性上升、路线/时间窗下降、无法稳定停留，且旧承载不是仅受损而继续主导。
16. `xz生zx`只生成状态层或关系位置层的临时公开决定接口，不生成勇气、能力、爱情或稳定领导本体。
17. 迁移启动与迁移完成分段：局部破损时可先记`n+xz`叠加；只有旧承载整体失去主导后才登记严格迁移。
18. 组合承载测试：某子模块失效后，若另一子模块继续提供接收、生命维持、保护、运输或返航，登记承载中心重构，不判整体迁移。
19. 外部承载接手测试：旧对象完成`n→xz`后，独立艇筏、车辆或支援设施另行形成`n克xz`，两者并行记录，不合并为同一对象重构。

## 5. 已有结构仅作后验参考

### 高频链

`x生x并z → x并z生z → z补xn`，当前后验支持9次；新案例不得自动套用。

### 搭桥

`1生2 → 2生3`，背景`1克3`；必须通过拿桥测试。

### R-REV-01

固定位置表不存在`A生B`同时`B克A`。表面反转至少涉及位置迁移、对象/变量替换、接口断裂、物理终止，或至少一边未达资格。

### R-MIG-01｜多位置叠加不等于迁移

`对象连续 + 新位置变量新增 + 旧位置变量持续运行 = 多位置叠加。`

### R-MIG-02｜旧现实关系退出—新位置主导的严格迁移

```text
对象连续
+ 旧位置的控制、调用或承载关系真实退出
+ 新位置变量成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移候选
```

当前支持5次：十二怒汉凶刀`x→x并z`；机器人总动员植物`x→x并z`；有求必应屋`n→xz`；Titanic船体`n→xz`；Deepwater Horizon平台`n→xz`。状态：`supported-positive-5-cross-position`。

### R-MIG-03｜隐藏属性揭露只增加证据壳

`原功能继续 + 新增x并z识别接口 = 位置叠加/信息重估，不是迁移。`

### R-MIG-04｜承载崩塌—临界主导迁移

```text
同一空间先稳定接收、容纳、保护、运输或提供通行 n
+ 灾难第三因素持续改变运行变量
+ 旧承载关系退出
+ 路线、时间窗、危险可到达性与无法停留成为中心 xz
+ 新xz启动合法关系边
= n→xz严格迁移候选
```

当前支持3次：有求必应屋厉火；Titanic沉没；Deepwater Horizon井喷爆炸与火灾。状态：`supported-positive-3-cross-domain`。

### R-MIG-05｜灾难临界叠加—承载中心重构负边界

```text
同一组合承载严重受损
+ 某子模块旧承载下降或停机
+ 另一子模块真实接收并继续生命维持/内部位置/保护/运输/返航
+ 危险xz仍持续高位
= n+xz叠加与承载中心重构，不是整体n→xz迁移
```

当前支持1次：《阿波罗13号》Odyssey停机、Aquarius接管救生与返航承载。状态：`negative-boundary-case-1`。

### R-MIG-06｜旧承载崩塌—外部新承载接手

```text
旧空间n严格迁移为xz
+ 独立艇筏/车辆/支援设施另行形成n
+ 新n真实接收并克制人员所处xz
= 旧对象迁移与外部对象接手并行
≠ 同一组合内部承载中心重构
```

当前支持1次：《深海浩劫》平台崩塌、艇筏与Damon Bankston接手。状态：`specific-graph-candidate-1`。
