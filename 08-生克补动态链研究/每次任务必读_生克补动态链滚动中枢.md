## 1. 十元概念预检

每个端点先写：

```text
z切分焦点 + x现象集合 + 十元位置锚
+ 稳定本体/当前状态 + 体量/阶段
```

不得把勇敢、成长、帮助、压迫、规则、爱、自由、服从、真相、觉醒、时间、命运、角色名、组织名、单个动作或镜头直接作为端点。

## 2. 生克补通用口径

- **生**：源为目标核心变量提供净增量。区分直接生、桥接生和允许条件。
- **克**：目标核心变量或成立资格持续下降。区分状态下降、局部成员覆盖下降与整体结构下降。
- **补**：恢复此前真实缺失的核心变量；信息、资源、训练、临时代理、领袖示范和单次情绪变化不自动算补。

## 3. 当前强制红线

### 3.1 制度与个体

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离 ≠ 制度整体被克
成员撤回自愿执行、维护或身份再生产 = 可构成低体量正式 zn 克 xn
```

### 3.2 示范、模仿、内化

```text
示范者在场时跟随 ≠ 内部 zn
撤场后仍独立判断 + 逆安全方向 + 承担后果
= 才接近自己的 zn
```

### 3.3 共同体转制度

```text
领袖命令 + 团队同框 + 计划书 + 视觉同步 ≠ n 生 xn
共同体先承担跨成员协作、保护、同步和回收负荷
→ 为持续处理负荷提炼规则、分工、边界、信号和备用流程
→ 才支持 n 生 xn
```

### 3.4 多人造界双源

```text
x 生 x并z：实际掌握设备、架构、对象信息与进入接口，形成可进入、可修改、可持续调用的世界壳
n 生 xn：共同体先承担跨成员负荷，再提炼持续运行结构
```

世界壳被设计出来不等于共同体承载成立。

### 3.5 时间接口、时间组织与临界风险

```text
回转门、逆熵物体、氧气、封闭舱、时间设备 = 首先是被掌握的 x 接口
正逆身份标识、装备和任务界面 = 只在可被多人稳定识别调用时局部邻近 x并z
时间戳、夹击、信息隔离、撤离、氧气和保密协议 = xn
安全路线、出口、氧气、最后窗口和跨方向误伤被这些结构持续缩窄 = xn 生 xz
即时决定必须进入另一方向已组织的结构 = xn 克 zx
```

红线：时间倒流、子弹倒飞、红蓝房和反向爆炸只是显影；不得直接判 `xz`。自然时间不是 `xn`，被主体组织的时间接口与协议才是 `xn`。

### 3.6 检测接口与确认结果

```text
图腾、仪表、密码、传感器或异常反馈 = 首先邻近 x
只有检测结果落到明确认可主体与确认内容时，才可能参与 z
未完成读数或镜头悬置 ≠ 确认完成
```

### 3.7 退出复合判定

```text
撤回自愿执行与身份复制 = 局部 zn 克 xn 候选
身份不再被本人接受调用 = x并z 对该主体失效
走出场域/断开接口 = 退出结果
```

三者不得压成“自由克制度”。

### 3.8 语言接口、语义壳、时间组织与确认

```text
声画、字形、设备、白板、词表与语料 = 首先是可掌握的 x 对象/接口
语义可被稳定识别、复述、书写和共享 = 局部 x并z 语言界面
语法、整体语义、翻译流程与信息顺序被持续组织 = xn
具体主体确认具体对象与内容 = z
```

红线：语言、圆形文字、未来画面和“理解”本身不等于 `z`、`xz` 或 `zn`；必须写清确认主体、被确认对象、被改变变量与跨阶段结果。

### 3.9 预知、危险与原则资格

```text
提前知道损失 = x/xn 信息条件变化
已知损失使时间窗、退路或安全路线真实缩窄 = 才可能形成 xz
原则是否被克 = 看其最终指导资格是否持续撤销
行动改变 ≠ zn 改变
```

判断 `zn` 是否改变，必须看代价可接受边界、不可越过底线和原则排序；不能只看人物最后做了不同动作。

## 6. 当前核心缺口

1. 外来示范何时只是允许条件，何时补回真实缺口；
2. 临时共同体能否跨高压留存，决定 `zn 生 n` 或 `n 生 xn` 的稳定性；
3. `nx` 常是多节点后果，不得伪造单一直接生关系；
4. 身份壳 `x并z` 不等于内部承载 `n`；
5. 真相、训练、身体恢复、共同体承载与内部意义必须分开；
6. 多人造界必须拆 `x 生 x并z` 与 `n 生 xn`；
7. 时间接口 `x`、时间组织 `xn`、临界风险 `xz` 必须分层；
8. 团队执行既有协议不等于团队生出协议；
9. 牺牲结果不能单独证明 `zn 生 n`、补或稳定人格本体；
10. 语言记录 `x`、共享语义壳 `x并z`、语言组织 `xn` 与具体确认 `z` 必须拆开；
11. 预知损失不自动构成 `xz`，行动改变不自动构成 `zn` 被克；
12. 下一步用《少数派报告》检验预测接口、预犯罪身份壳与未来可能性是否被制度压成现实追捕。
