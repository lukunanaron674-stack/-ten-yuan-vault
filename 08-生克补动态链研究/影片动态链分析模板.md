# 影片生克补动态链分析模板

> 一条关系对子只记录直接改变；多个直接关系对子按真实阶段组成动态链；间接路径不得重复登记成新的生克补边。影片名、人物名和剧情流程只能作为具体积累，不能直接命名母型。

## A. 启动信息

```text
运行ID：
北京时间：
起始 main SHA：
动态链中枢版本：
方法修正版：v2.1
十元关系表版本：

分析范围：
分析粒度：C单场 / B段落 / A整片
动态类型：改变 / 崩坏 / 维持 / 循环 / 替换
上一轮结论：
本轮核心问题：
```

默认先做C级，再汇总B级，最后才允许形成A级。跨越多个主体、确认内容或核心变量时，应缩小范围或拆支路。

## D. 确认三轴与错误来源

确认不得写成z0—z4单轴等级，必须分开：

```text
确认主体：个人 / 关系双方 / 小群体 / 机构 / 公众
确认内容：身份 / 责任 / 存在 / 资格 / 事实状态 / 关系位置
证据状态：初步 / 可执行 / 稳定 / 被反证 / 已撤销
采用范围：私人 / 档案 / 媒体 / 医疗 / 法律
成立阶段：
错误来源：制造型 / 转译型 / 缺证型 / 惯性型 / 不适用
```

个人猜对不等于机构确认恢复；机构采用也不改变客观事实本身。

### 对子记录要求

- 生：目标此前不存在或不足；源提供目标核心变量净增量。
- 克：目标核心变量、成立资格或实际运行能力下降；不是普通阻碍。
- 补：目标原先存在真实缺口；补源补入与缺口对应的具体变量；不是帮助或陪伴。
- 补关系可以跨十元位置，不要求与被克对象“同层”。
- 若真实结构是`A生C→C克B`，只登记两条直接边，不得再登记“A间接克B”。
- 链尾总体效果只能写动态图后果，不得倒写成源端对链尾的直接生克补。

## K. 拿掉与反向测试

1. 拿掉具体主克源，目标变量是否仍以同样机制下降？
2. 拿掉具体补源，缺口是否仍以同样路径恢复？
3. 拿掉具体生源，新目标是否仍以同样方式出现？
4. 拿掉视觉、台词和角色光环，只看对象、阶段与变量，关系是否仍成立？
5. 换掉人物身份和题材，具体对子能否迁移？
6. 反向关系是否更能解释因果？
7. 若存在中间节点，是否错误地把路径首尾压成了直接关系？
8. 是否把个人确认、机构采用与客观事实混成了一个z？

## L. 具体动态链

动态链必须由已登记的直接关系对子组成：

```text
具体名词A 关系对子 具体名词B
→ 具体名词C 关系对子 具体名词D
→ 具体名词E 关系对子 具体名词F
```

同时写字母链：

```text
A克B → C生D → E补F
```

并标记：

```text
直接关系边：
间接图路径：
条件节点：
失败边：
总体链式效果：
```

动态链不是剧情梗概。若某阶段只有条件化、排序、显影、维持或普通执行，应明确标记，不能硬塞生克补。
