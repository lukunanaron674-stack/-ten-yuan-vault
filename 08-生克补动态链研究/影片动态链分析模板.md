# 影片生克补动态链分析模板

> 一条关系对子只记录直接改变；多个直接关系对子按真实阶段组成动态链；间接路径不得重复登记成新的生克补边。影片名、人物名和剧情流程只能作为具体积累，不能直接命名母型。


默认先做C级，再汇总B级，最后才允许形成A级。跨越多个主体、确认内容或核心变量时，应缩小范围或拆支路。

## B. 十元端点卡路由

先用信息卡回答“它是什么”，再用准度卡回答“为什么必须判成它”，最后才进入生卡、克卡、补卡。旧字段`z切分焦点 + x现象集合`只作历史材料，不再是现行端点生成器。

| 具体名词 | 对象层 | 候选十元 | 信息卡主骨 | 准度卡必要条件 | 最近邻 | 端点状态 | 体量三项 |
|---|---|---|---|---|---|---|---|
|  | 稳定本体/状态/行为/关系/场景/视觉 |  |  |  |  | 已成立/候选/未判定 | 范围/时间/不可逆 |

端点进入关系前必须满足：

```text
对象与阶段明确
→ 对应信息卡主骨成立
→ 准度卡最近邻、拿掉与反向测试通过
→ 端点置信度达到本轮所需门槛
→ 才能进入生卡 / 克卡 / 补卡
```

不得把勇敢、成长、帮助、压迫、规则、爱、自由、真相、希望、角色名、组织名、单个动作或镜头直接作为十元端点。

体量必须分别写影响范围、持续时间和不可逆程度；不得用固定权重平均制造虚假精确度。

## D. 确认三轴与错误来源

确认不得写成z0—z4单轴等级，必须分开：

```text
确认主体：个人 / 关系双方 / 小群体 / 机构 / 公众
确认内容：身份 / 责任 / 存在 / 资格 / 事实状态 / 关系位置
证据状态：初步 / 可执行 / 稳定 / 被反证 / 已撤销
采用范围：私人 / 档案 / 媒体 / 医疗 / 法律
成立阶段：
错误来源：制造型 / 转译型 / 缺证型 / 惯性型 / 不适用
```

个人猜对不等于机构确认恢复；机构采用也不改变客观事实本身。

## F. 具体名词对子积累

每一条必须写“具体源名词 + 直接关系对子 + 具体目标名词 + 变量变化”。只写字母、角色名或事件名不算完成。

| 编号 | 具体源名词 | 关系对子 | 具体目标名词 | 关系性质 | 为什么成立 | 被改变变量 | 阶段 | 证据等级 | 最近邻 |
|---|---|---|---|---|---|---|---|---|---|
| N-001 |  |  |  | 直接边/条件/失败边 |  |  |  | A/B/C/D/X |  |

### 对子记录要求

- 生：目标此前不存在或不足；源提供目标核心变量净增量。
- 克：目标核心变量、成立资格或实际运行能力下降；不是普通阻碍。
- 补：目标原先存在真实缺口；补源补入与缺口对应的具体变量；不是帮助或陪伴。
- 补关系可以跨十元位置，不要求与被克对象“同层”。
- 若真实结构是`A生C→C克B`，只登记两条直接边，不得再登记“A间接克B”。
- 链尾总体效果只能写动态图后果，不得倒写成源端对链尾的直接生克补。
