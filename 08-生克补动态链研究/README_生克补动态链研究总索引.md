## 4. 最新具体动态图｜离场后观众欢呼与节目接口转移

```text
楚门离场成功的公众确认 z
└─×生→ 观众与楚门的双方关系停靠 nz

节目终止与播出槽释放程序 xn
└─克→ 以楚门为中心的观看接口 nx 的实际运行能力

下一节目可用入口 xn
└─补→ 观众观看依赖 nx 缺少的持续内容承载
```

条件：楚门真实离场、节目入口关闭、替代节目可用、观众与楚门缺少普遍双向关系。

失败边：`z生nz`；长期熟悉壳`x并z生nz`；欢呼`z克nx`；停播`xn生zn`。

边界：强烈欢呼和长期熟悉可以是真实情绪，却仍不等于双方自主关系；节目终止克的是原接口运行能力，下一节目补的是观看承载缺口，不是对楚门关系的修复。
