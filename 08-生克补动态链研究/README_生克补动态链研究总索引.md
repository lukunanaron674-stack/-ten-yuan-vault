## 4. 最新具体动态图｜《V字仇杀队》

```text
V行动/媒体/爆破掌握 x
        └─生→ V公共面具/反抗身份壳 x并z
                 ├─生→ 公众代表确认 z_public
                 ├─生→ Finch/警方调查确认 z_police
                 └─生→ 政权威胁确认 z_enemy
                              └─补→ 监控、封锁、搜捕与军队部署程序 xn_regime
                                           └─生→ 暴露、路线缩窄与最后窗口临界 xz_pursuit

Shadow Gallery承载 n_shadow
        ├─克→ 局部追捕直达/无稳定位置临界 xz_local
        └─生→ 治疗、资料整理与行动准备程序 xn_shadow

群众临时承载 n_crowd ─生→ 集体聚集/推进程序 xn_crowd
群众身份归因接口掌握 x_crowd ─克→ 军警唯一V/开火目标确认 z_field_unique
```

关键结论：
- 公共面具壳分别生成公众代表、警方调查和政权威胁确认；三类确认进入不同程序。
- 敌方确认补入监控、封锁、搜捕与部署程序的目标、路线、时间和兵力节点。
- 群众共同佩戴同款面具不是单纯象征扩散；其实际控制现场视觉、证言和身份归因入口，使唯一V与唯一开火目标确认下降。
- 主克只锁现场唯一归因窄机制，不扩大为Finch历史调查确认消失，也不把多人壳复制写成V本体复制。
- 议会爆炸与V死亡不自动生成稳定自由社会或长期群众承载。
