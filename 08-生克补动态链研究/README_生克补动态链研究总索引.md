## 4. 最新具体动态图｜好友桥上安慰

```text
外部台词输送程序 xn
→ 经马龙方向权外置的执行接口 nx候选落地
→ 条件性补入 好友角色壳 x并z 当前所需精准回应
→ 好友角色壳 x并z 生 楚门对“马龙仍自主真诚”的私人错误确认 z_wrong
```

条件：隐藏耳机、节目监控、共同经历与马龙既有表演能力。

失败边：`nx生z`；`xn克z`；精准安慰生真正关系修复`nz`；回忆台词生友情真实性。

边界：方向权外置不自动构成关系；程序只作为条件性补入；单方被安抚与受控表演不等于双方自主修复。
