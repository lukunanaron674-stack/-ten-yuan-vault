# 生克补动态链研究总索引

## 1. 目录职责

- `每次任务必读_生克补动态链滚动中枢.md`：强制启动、红线、累计与真实断点。
- `生克补动态链方法修正_v2.1_2026-07-28.md`：动态链方法的明确范围正本修正。
- `影片动态链分析模板.md`：统一案例格式，当前v1.2。
- `影片案例/`、`现实案例/`：具体动态链积累。
- `生克补动态链每小时运行记录.md`：唯一活动账本。

## 2. 研究层级

```text
固定定义与关系盘
→ 具体名词与十元概念锚
→ 确认主体/内容/证据状态分账
→ 单一核心变量与动态类型
→ 直接生克补关系边
→ 间接路径、条件与失败边
→ 主链/支路/汇合/断裂/维持/替换
→ 单案例归档
→ 跨案例后验比较
→ 母型候选或锁定
```

当前优先：具体动态图积累第一，母型后置；每轮首遍屏蔽候选编号。默认按C单场→B段落→A整片推进。

## 4. 方法修正后的最新具体动态图｜《赎罪》

```text
直接边：
Briony首次目击证言/身份归因入口掌握 x
→ 生 Robbie施害责任壳 x并z

Robbie施害责任壳 x并z
→ 生 家族错误责任确认 z_wrong_family
→ 生 警方/司法错误责任确认 z_wrong_justice

警方/司法错误责任确认 z_wrong_justice
→ 补 调查、逮捕、定罪、监禁与参战程序 xn

司法/监禁/参战程序 xn
→ 生 Robbie可执行刑事责任位置与合法社会身份临界 xz

窄阶段候选边：
Briony控制首次必要证言归因入口 x
→ 克 Marshall进入家族/警方首次正确责任确认 z_right

失败边：
成年Briony文学团聚壳 x并z
─×→ Robbie/Cecilia现实共同生活承载 n
```

v2.1复核要求：
- 确认分为主体、内容、证据状态、采用范围与阶段，不使用z0—z4单轴等级。
- 核心变量收束为“Robbie可执行刑事责任位置/合法社会身份”，自由、职业、亲密关系与安全为展开指标。
- 严格主克只覆盖首次必要证言入口；黑暗、误读、嫉妒和阶级偏见为第三因素。
- 若后续复核发现必要入口控制不足，保留前半链并把主克降为失败边，不影响`x并z生z_wrong→z_wrong补xn`。
