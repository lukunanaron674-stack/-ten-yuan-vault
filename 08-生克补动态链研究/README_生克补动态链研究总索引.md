## 4. 最新具体动态图｜《换子疑云》

```text
LAPD对替代儿童、案件档案、记者会、医生意见与收治入口的掌握 x
        ├─生→ 替代儿童身份/母亲失常壳 x并z
        │          ├─生→ 警方错误身份确认 z_wrong_police
        │          │          └─补→ 强迫接收、结案、诊断、压制与收治程序 xn
        │          └─生→ 公众/媒体错误身份确认 z_wrong_public
        └─克→ 亲生子身份正确确认进入机构可执行位置 z_right

警方结案/压制/收治程序 xn
        └─生→ Christine行动资格归零与Walter搜寻时间窗临界 xz

警方处置显权 zx
        └─克→ Christine作为合法案件当事人的接收、保护与返回接口 n_case

教师、牙医、牧师、律师与独立调查确认 z_support
        └─补→ 取证、广播、诉讼与继续寻子程序 xn_appeal
```

关键结论：
- Christine个人正确识别始终存在；主克只覆盖该确认进入警方、媒体、医疗与法律可执行位置的传播和采用。
- 主克不是警方错误确认本身，而是LAPD主动掌握案件档案、公开口径、医生意见、诊断与收治入口。
- 警方和公众/媒体错误确认必须分账；前者能结案、诊断和收治，后者主要形成公共人物标签与传播压力。
- 身高、牙齿、割礼和教师记忆只有进入书面证明、广播与法律程序后，才作为确认补入申诉程序；现象本身不是补。
- 收治不是普通离场，而是公开处置显权改写Christine作为合法案件当事人的接收与返回资格。
