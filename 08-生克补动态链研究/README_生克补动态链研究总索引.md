## 4. 最新具体动态图｜屋顶并坐与现实承载转换

```text
操作系统连接终止程序 xn
└─克→ 数字亲密接口依赖 nx 的实际运行能力

艾米与西奥多现实共同在场 n
└─补→ 关系运行缺少的现实承载接口

双方对彼此失落与陪伴意愿的确认 z
└─补→ 现实共同承载 n 缺少的关系方向稳定度
```

条件：旧数字接口已不可召回、双方已有现实友谊、共同在场是双向自愿、`nz`保留为跨阶段回返与修复资格而不由一次并坐直接生成。

失败边：一次屋顶并坐`n生nz`；共同失落`z生nz`；现实在场克过去关系意义；接口终止生现实关系成熟。

边界：现实陪伴可以补关系运行承载，却不能替代跨阶段互惠、自由退出后的回返和冲突修复生成完整`nz`；数字接口退出也不等于数字关系从未真实存在。
