## 4. 本轮跨片新增结论

### 4.1 《千钧一发》与《雪国列车》的身份制度差异

| 维度 | 千钧一发 | 雪国列车 |
|---|---|---|
| 物理接口 `x` | 基因样本、读数、档案、检测 | 引擎、车体、水、食物、门、武器、儿童身体 |
| 身份壳 `x并z` | 有效/无效、职业适配、杰罗姆身份 | 尾厢/前厢、制服、位置、职责、接班人 |
| 承载 `n` | 文森特—杰罗姆局部互担 | 列车生命支持+尾厢内部互助 |
| 制度 `xn` | 招聘、门禁、日检、保险、任务 | 配给、门禁、人口平衡、教育、镇压、维护 |
| 主克 | 长期机会过滤 `xn克zx` | 封闭位置与运行秩序 `xn克zx` |
| 结局 | 个体借壳穿透，制度仍在 | 维护撤回后容器物理崩毁 |
| 最强误判 | 登船=制度被克 | 进入引擎室=革命胜利；脱轨=`zn克xn` |

### 4.2 真实承载不等于制度正当

《雪国列车》的列车确实是高体量 `n`：它维持空气、温度、食物循环和内部位置。但这只能证明“有人被持续维持”，不能证明：

- 资源分配合理；
- 阶级身份正确；
- 人口平衡和儿童零件具有正当性；
- 当前 `xn` 是由共同体平等承担自然提炼出来的。

因此：

```text
n 真实存在
≠ 当前 xn 正当
≠ n 自动生出当前 xn
```

### 4.3 反抗可能被系统吸纳

柯蒂斯逐车厢推进，最终进入引擎室，却被威尔福德提供接班位置。这个节点说明：

```text
反抗 zx 穿透执行节点
→ 系统把反抗者包装成新的 x并z 维护身份
→ 邀请其进入 xn 的复制与维护位置
```

进入中心可能不是制度被克，而是系统完成一次高阶吸纳。

### 4.4 维护撤回、接口破坏与容器毁灭必须分写

- 柯蒂斯拒绝接班：局部 `zn克xn` 候选，改变自愿维护与接班资格；
- 南宫民秀炸门：使用 `x` 改变出口接口；
- 爆炸和雪崩：物理摧毁列车承载与运行；
- 幸存者走出：退出结果；
- 北极熊：外部生命可能的确认线索。

任何一项都不能独自包办“制度被克、自由生成、新共同体成立”。

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把真相、训练、觉醒、时间、命运、牺牲、预知、预测、概率、革命或视觉奇观直接写成生克补；
- 不把材料、资源、公开身份壳、承载与组织流程压成一个端点；
- 不把行动改变直接写成稳定本体或`zn`改变；
- 不把团队执行既有协议写成`n生xn`；
- 不把个体脱钩外推成总体制度消失；
- 不把容器物理毁灭写成单一十元关系的纯克制；
- 新案例必须反向修正中枢和母型。
