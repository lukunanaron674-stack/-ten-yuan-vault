## 4. 最新具体动态图｜《斯巴达克斯》

```text
Batiatus学校最低生活/训练承载 n_A
        └─生→ 重复格斗训练与体能维持程序 xn_A1

奴役训练/消耗程序 xn_A
        └─生→ 无退出、死亡、出售与关系分离临界 xz_A

起义奴隶群体承载 n_B
        ├─克→ 饥饿、暴露、无保护与持续漂流临界 xz_B
        └─生→ 招募、释放、训练、粮秣、行军与作战程序 xn_B

Spartacus战斗/组织掌握 x
        └─生→ 起义领袖公共身份壳 x并z
                 ├─生→ 奴隶群体领导确认 z_group
                 └─生→ 罗马威胁确认 z_enemy
                              └─补→ 征召、包围、封锁与俘虏处置程序 xn_C
                                           └─生→ 撤离路线归零、家属分离与死亡临界 xz_C

被俘奴隶证言/归因接口掌握 x_D
        └─克→ Crassus对唯一Spartacus身份的官方确认 z_unique

断裂：公共领袖壳 x并z ─×→ Varinia/孩子家庭共同生活自动恢复 n_C
```

关键结论：
- 角斗士学校存在低体量最低生活/训练承载，但它不克制奴役、出售和被迫死斗临界；承载与控制程序必须分账。
- 起义营地和群体跨季节接收奴隶、家属与伤员，构成真实流动承载并生成持续组织程序。
- 公共领袖壳分别生成奴隶群体的领导确认和罗马军政的威胁确认；Varinia的亲密确认主要来自直接共同生活，不归公共壳独占。
- 罗马威胁确认补入镇压程序的目标、兵力、路线和处置节点。
- “I am Spartacus”主要是集体掌握现场证言/归因入口并克制敌方唯一确认，不是批量生成稳定身份壳。
- 公共领袖壳不能提供战败后的共同离场、安全住所和Spartacus生存条件，因此不能自动恢复家庭承载。
