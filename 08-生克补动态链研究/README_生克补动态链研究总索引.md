## 4. 最新具体动态图｜Deepwater Horizon平台崩塌与外部接手

```text
事故前平台工作/居住/通行/保护承载 n平台
                    ║ 井喷、爆炸、火灾、断电与结构破坏（第三因素）
                    ║ S1-S2：n+xz叠加
                    ▼ S3：旧承载退出
同一平台的火灾可达、路线/时间窗缩窄与无法停留临界 xz平台
                    │ 生
                    ▼
放弃平台、登艇/登筏或最后跳海的临时撤离决定 zx

并行A：救生艇/救生筏承载n ─克→ 平台火灾、落海与无离开路径临界xz
并行B：Damon Bankston/救援小艇承载n ─克→ 溺水、燃烧海面、失温与无稳定位置临界xz
程序支路：事故与人员/艇筏状态确认z ─补→ 集合、放艇、搜救与后送程序xn
允许条件：救生衣、艇筏、无线电、释放设备与支援船资源x ──→ n/xn/zx现实执行
```

压缩：

```text
严格迁移：n平台→xz平台
主生：xz平台生zx临时撤离决定
主克：n外部救援承载克xz落水/火场临界
主补：z事故与撤离确认补xn撤离救援程序
位置叠加：S1-S2局部成立
承载中心重构：无；艇筏与支援船为独立对象
搭桥/反馈/反转：无
```

关键结论：平台旧承载已经整体退出，但人员随后被独立艇筏和外部支援船接住。旧对象的`n→xz`迁移与新对象的`n克xz`可以并行，不能为了图画得省事，就把所有能浮的东西塞进一个“组合承载”。

## 6. 位置变化边界

### R-MIG-01｜多位置叠加

`对象连续 + 新位置变量新增 + 旧位置变量持续运行 = 多位置叠加，不是迁移。`

### R-MIG-02｜严格位置迁移

```text
对象连续
+ 旧位置现实控制/调用/承载关系退出或失去主导
+ 新位置变量成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移
```

当前正例：十二怒汉凶刀`x→x并z`；机器人总动员植物`x→x并z`；有求必应屋`n→xz`；Titanic船体`n→xz`；Deepwater Horizon平台`n→xz`。

### R-MIG-03｜隐藏属性揭露

`原功能继续 + 新增x并z识别接口 = 位置叠加/信息重估，不是严格迁移。`

### R-MIG-04｜承载崩塌—临界主导迁移

```text
同一空间先稳定接收、容纳、保护、运输或提供通行 n
+ 灾难第三因素持续改变运行变量
+ 旧承载关系退出
+ 路线、时间窗、危险可到达性与无法停留成为中心 xz
+ 新xz启动合法关系边
= n→xz严格迁移候选
```

当前支持：有求必应屋厉火、Titanic沉没、Deepwater Horizon井喷爆炸与火灾。

### R-MIG-05｜灾难临界叠加—承载中心重构

```text
同一组合承载严重受损
+ 某子模块旧承载下降或停机
+ 另一子模块真实接收并继续生命维持/内部位置/保护/运输/返航
+ 危险xz仍持续高位
= n+xz叠加与承载中心重构，不是整体n→xz迁移
```

当前支持：《阿波罗13号》Aquarius救生艇片段。

### R-MIG-06｜旧承载崩塌—外部新承载接手

```text
旧空间n严格迁移为xz
+ 独立艇筏/车辆/支援设施另行形成n
+ 新n真实接收并克制人员所处xz
= 旧对象迁移与外部对象接手并行
≠ 同一组合内部承载中心重构
```

当前支持：《深海浩劫》平台撤离片段。下一步须用翻覆船舶、燃烧建筑或交通设施复测外部对象边界。
