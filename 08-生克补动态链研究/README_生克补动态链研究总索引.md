## 4. 最新具体动态图

### 《超人总动员》全能机器人城市部署与“造物反噬”伪反转

```text
克罗诺斯测试、记录、淘汰、升级与城市部署程序 xn_K
                         │ 生
                         ↓
        全能机器人造成的城市攻击与安全临界 xz_C

辛德罗姆遥控、停机与伪英雄演出脚本掌握 x_S
                         │ 允许条件
                         ↓
               预定英雄表演（未形成稳定关系边）
                         │
                         × 机器人识别并击落遥控器
                         ↓
               控制接口失效（普通因果节点）
                         │
                         ↓
               机器人攻击辛德罗姆（普通攻击节点）
```

压缩：

```text
主链：xn_K生xz_C
支路：遥控掌握x_S只提供演出允许条件，英雄壳与确认未稳定形成
汇合节点：无
反馈环：无
搭桥：无
反转：无；造物反噬只形成剧情反差
转位：辛德罗姆由控制者转为攻击目标
断裂：遥控器被击落后，控制脚本与伪英雄确认路径断裂
普通因果：目标识别→遥控失效→失去控制→遭到攻击
```

关键新增：

- `xn生xz`要求跨阶段测试、记录、升级、识别与部署程序持续缩窄安全路线，不等于“造出一个很强的机器人”；
- “A制造B，B后来攻击A”不能自动写成`A生B→B克A`；
- 真正反转需要前段生边与后段反向克边分别达到A级，并固定同一具体源、目标、对象和变量；
- 遥控器、权限、线路或设备失效属于控制接口断裂，不能冒充关系反转；
- 激光击中、设备损坏、受伤和死亡属于物理结果，不自动等于`zx克n`或其他十元克；
- 控制者变为攻击目标属于关系位置转位，和关系方向反转是两回事。

## 6. 高频链当前边界

```text
x生x并z → x并z生z → z补xn
```

只允许后验使用：

1. 新案例先独立锚定节点和关系；
2. 比较时除字母链外，还要比较链序、支路、汇合、反馈、承载背景与断裂位置；
3. 同字母若具体对象、阶段或体量不同，必须分为不同节点；
4. 最终成功不能倒证中间关系；
5. 《火星救援》只增加主链支持，不意味着其完整动态图与科研案例同构；
6. 《寻梦环游记》的冒署支路局部含高频链前两段，但主图以`x克z`和确认转位为核心，不计新支持；
7. 《超人总动员》只登记`xn生xz`与伪反转负例，不计入高频链。

## 7. 方法修正记录

1. 节点是具体名词+十元位置；行为是启动器；生克补是边。
2. 动态链必须保存真实顺序和图拓扑。
3. 串联、并行、汇合、反馈、搭桥、延伸、反转、转位与断裂必须分账。
4. 同一字母不自动代表同一对象。
5. 搭桥是图结构功能，不是凡有中介皆搭桥。
6. 首遍屏蔽母型；母型仅后验比较。
7. 错误确认与正确确认可同时属于`z`，但必须按确认对象和归因内容分节点。
8. 真正反转要求同一具体源、目标、对象和变量跨阶段形成两条A级反向边。
9. 制造、训练、授权、控制、失控、设备损坏和物理攻击不得仅凭剧情动词直接写成生克补。
10. 造物伤害造物主通常先检查：前段是否只是制造事实，后段是否只是控制接口断裂或普通攻击。
