# 生克补动态链研究总索引

## 1. 目录职责

- `每次任务必读_生克补动态链滚动中枢.md`：强制启动、红线与真实断点；
- `影片动态链分析模板.md`：人物行为、具体名词对子与动态链统一格式；
- `影片案例/`：每部影片的具体积累；
- `生克补动态链每小时运行记录.md`：唯一活动账本；
- 本文件：案例链登记、候选链累计和通用母型锁定状态。

每轮必须先读`01-十元系统/001-概念的定义.md`，完成`z切分焦点+x现象集合+十元位置+本体/状态+体量`锚定。

## 2. 研究层级

```text
关系对子：谁生谁、谁克谁、谁补谁。
戏剧具体积累：人物与阶段 + 人物行为 + 具体名词A + 关系对子 + 具体名词B + 为什么成立 + 被改变变量。
动态链：多个具体关系对子按真实阶段连续启动。
通用母型：同一抽象对子链在多个独立、跨题材案例中稳定复现。
```

人物行为是戏剧主体；具体名词挂在行为两端，固定源端和目标端。M-001A至M-032均为`legacy-case-chain`，不再直接视为通用母型。

## 4. 新模板案例摘要

### 4.1 《赎金》（1996）

```text
武装绑架zx克家庭现实承载n
→证据程序xn补存活/履约确认z
→现金处分权x生公开悬赏壳x并z
→悬赏壳x并z生绑匪目标识别z
→目标确认z补追查程序xn
→复核程序xn补主谋身份确认z
→家庭/警方保护n克即时临界xz
```

### 4.2 《疾速追杀2》（2017）

```text
Santino七百万美元处分权x生John暗杀合约壳x并z
→暗杀合约壳x并z生地下网络对John的目标确认z
→John目标确认z补接单、筛选、靠近与攻击程序xn
→违规识别、除名和服务关闭程序xn生一小时倒计时与全球追杀临界xz
```

血誓执行`xn克zx`因炸屋暴力和现实报复混入，暂不并入A级核心链。

### 4.3 《疾速追杀3》（2019）

```text
裁决者对帮助者、违规内容与责任位置的确认z
补High Table惩罚、整改与追责程序xn
→除名、赏金分发、帮助者处罚和服务关闭程序xn
生John安全路线、帮助者数量、停留资格与时间窗缩窄xz
→裁决者公开撤销大陆酒店圣域的权能zx
克酒店保护、接收、安全停留与反复返回能力n
→Winston与Charon组织实际接收、补给与防守的酒店承载n
克High Table武装进攻的直接临界xz
```

字母链：`z补xn → xn生xz → zx克n → n克xz`。

C-001不增加支持次数：本片没有重新完成资源掌握→新合约壳→新目标确认→新程序聚焦，只是上一部同一赏金、目标和程序继续运行。

### C-001当前变量同构

```text
实际资源掌握与处分
→资源获得公开可识别、可调用、可兑现的壳
→壳使特定主体获得明确目标确认
→确认给既有程序补入聚焦对象、筛选标准与行动节点
```

失败边界：资源壳已经存在、目标已经确认、程序只继续运行时，不得重新累计。

### C-002当前变量假设

```text
明确确认给追责程序补入对象、责任、期限与节点
→程序持续处理偏差并扩大临界
→公开权能撤销承载资格与保护边界
→残余承载通过实际接收、补给和冲击吸收，阶段性降低风险
```

## 7. 方法修正记录

1. 关系对子是“谁生谁、谁克谁、谁补谁”。
2. 戏剧具体积累以主要人物在具体阶段的行为为主体。
3. 具体名词位于行为两端，固定源端和目标端，并必须做十元定位。
4. 多个对子合成动态链，不要求机械套“主克→主补→主生”的固定顺序。
5. 稳定多次出现的抽象动态链才是母型。
6. 一次出现只能建立具体动态链或C候选链，不能直接建立UM母型。
7. 同一续作延续同一资源、合约、目标和程序，不算新的独立支持。
8. 续作可以贡献关系对子连续性和失败边界，但必须写明没有重新发生的链段。
