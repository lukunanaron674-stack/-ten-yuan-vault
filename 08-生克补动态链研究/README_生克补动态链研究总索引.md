## 4. 本轮跨片新增结论

### 4.1 《少数派报告》与《千钧一发》的制度压缩差异

| 维度 | 少数派报告 | 千钧一发 |
|---|---|---|
| 原始接口 | 未来影像、脑波、球体、数据库 `x` | 样本、基因读数、检测器、档案 `x` |
| 身份壳 | “未来凶手/受害者” | “有效/无效”、健康概率、职业适配 |
| 制度执行 | 倒计时、追捕、冻结、司法 | 招聘、门禁、日检、保险、任务分配 |
| 主克 | `xn克zx`提前取消否认与改线接口 | `xn克zx`在能力显现前先关闭机会接口 |
| `xz`体量 | 高，追捕与最后窗口贯穿后段 | 低至中，主要在命案调查与发射截止显形 |
| 最强误判 | 预测本身等于危险和犯罪完成 | 基因概率本身等于制度决定和人物本体 |

### 4.2 没有倒计时，也可存在高体量 `xn克zx`

《千钧一发》的限制常表现为安静、重复和日常化：

```text
身份壳被制度稳定调用
→ 申请、门禁、任务与职业入口被提前过滤
→ 能力尚未进入现实，决定已失去有效接口
```

因此不能把 `xn克zx` 只理解为“强制追捕或公开镇压”。长期机会分配同样可以持续降低主体决定的现实有效性。

### 4.3 借壳运行必须拆成四层

```text
样本、档案与证件被掌握 = x
杰罗姆身份被机构稳定读取 = x并z
招聘、日检和门禁持续调用身份 = xn
文森特与杰罗姆跨阶段承担秘密和生活负荷 = n候选
```

文森特没有在本体上“变成杰罗姆”。他掌握并调用一个既有公开壳。初期样本交易只是 `x`；后期双方真实互担才可能形成 `n补x并z` 候选。

### 4.4 个体穿透不等于制度被克

文森特登船和拉马放行只证明：

- 一个主体穿过筛选接口；
- 一个执行节点撤回检查；
- 制度分类无法穷尽能力与意义。

影片没有证明基因身份壳、机会规则和成员维护在整体上持续下降。

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把真相、训练、觉醒、时间、命运、牺牲、预知、预测、概率或视觉奇观直接写成生克补；
- 不把材料、公开身份壳、组织流程与确认结果压成一个端点；
- 不把行动改变直接写成稳定本体或`zn`改变；
- 不把结果吻合直接当作主体、动机和因果路径解释正确；
- 不把长期歧视只写成情绪压迫，必须追踪机会与决定接口；
- 不把借用身份写成本体替换；
- 不把个体脱钩外推成总体制度消失；
- 新案例必须反向修正中枢和母型。
