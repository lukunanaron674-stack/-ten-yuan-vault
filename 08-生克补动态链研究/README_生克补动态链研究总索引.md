## 4. 本轮跨片新增结论

### 4.1 固定住所可成为条件性承载

《寂静之地》的农场、粮食、地下室和监控仍在运行，但任何声音都可让怪物直接抵达成员。设施库存没有消失，保护、分娩、沟通与回返变量却受到持续压缩。因此“建筑仍在”不能反推 `n` 未被克制。

### 4.2 保护源端耗尽可在家庭内部换挡

《末日危途》《釜山行》都以外部家庭或军方接收结束；《寂静之地》不同：Lee死亡后，Evelyn、Regan与Marcus继续承担照护、确认、执行和救援。家庭 `n` 没有等待外部容器，而是在内部重组保护接口。

### 4.3 能力、规则、设备与承载不能打包继承

```text
Lee的助听器试验史 = xn
助听器/广播设备 = x
Regan确认反馈弱点 = z
Evelyn射击使杀伤生效 = zx
家庭持续接住成员 = n
```

“女儿拿到父亲遗物”不足以证明能力继承；必须追踪试验、确认、执行与成员承担。

### 4.4 `xn补z` 可成为灾难高潮的知识换挡

重复试验和现场反应让弱点确认从偶然感觉变成可执行判断。它补的是确认的证据链与归因稳定度，不是情绪、自信或抽象希望。

### 4.5 UM-02B 增加第三种边界

```text
B1 成熟既有n移动保存：末日危途
B2 亲属壳已定、低效承载补实：釜山行
B3 成熟家庭n固定承载受穿透、内部多源换挡：寂静之地
```

B3不依赖外部接收，但目前只有同一部影片支持，继续保持候选。
