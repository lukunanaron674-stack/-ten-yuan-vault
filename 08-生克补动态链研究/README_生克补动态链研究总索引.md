## 2. 研究顺序

```text
对象、主体、阶段与对象层
→ 信息卡确认端点是什么
→ 准度卡排除最近邻并完成拿掉、反向
→ 生卡 / 克卡 / 补卡确认关系类型
→ 核心表与专项索引确认机制状态
→ 确认分账与单一核心变量
→ 直接边、条件、间接路径和失败边
→ 单案例归档
→ 跨案例后验比较
→ 卡片增量候选与母型累计
```

默认按C单场→B段落→A整片推进。卡片增量优先登记为候选证据；单片不得擅自改锁定本体或关系正本。

## 4. 最新具体动态图｜《楚门的世界》电梯后台

```text
条件：电梯无后壁及门扇开放

摄影棚后台演员候场、换装、补给、排队复位与假电梯循环运行结构 xn
→ 补 楚门对公共空间人工制作性质的私人确认 z

失败边：
短暂后台窗口 x并z ─×→ 生 楚门确认 z
后台程序 xn ─×→ 克 海景镇正常世界壳 x并z
节目组控制 ─×→ 克 客观现实 z
电梯故障 ─×→ 生 楚门确认 z

链式后果：
海景镇正常世界壳在楚门个人位置上的可信度下降；主动测试意愿上升。均不登记为新的直接关系边。
```

边界：

- 电梯开口只提供接触机会，不是端点。
- 一次门框窗口缺持续公共识别与调用，不足以登记稳定`x并z生z`。
- 后台程序通过多项同场、相互独立、可归因的制作痕迹，补入已有确认的结构性证据缺口。
- 客观现实不是`x克z`目标，本场具体个人确认上升。
- 本轮只完成C级，不与广播或父亲重现提前合并。

## 6. 卡片增量候选

- `xn`信息卡候选血肉：影视后台通过候场、换装、补给、排队和复位，让虚构前台跨轮次持续运行。
- `z`准度卡候选：多项同场、相互独立且可归因的制作痕迹，可提高具体私人确认的稳定度，但必须限定主体、内容、采用范围与阶段。
- 补卡候选正例：已有确认仍存在，长期组织结构暴露后补入其缺少的连续性、结构性和可归因证据。
- `x并z`准度卡反例：一次门框、窗口或后台开口即使高度可读，也不自动达到稳定公共壳。

这些只作为后续卡片维护与跨作品复现证据，本轮不直接修改锁定卡。
