## 4. 本轮跨片新增结论

### 4.1 既有成员保存与任务对象成员化必须分开

```text
M-019：对象最初是政治/任务接口
→ 经降价、照护、回返与交接进入成员候选

M-020：父子成员关系开场已成立
→ 研究资源耗损、保护源端衰竭、关系内部原则分叉与外部转交
```

二者都含移动、危险与交接，但目标变量完全不同。

### 4.2 亲属壳持续不等于承载能力持续

父子称谓 `x并z` 在父亲病重和死亡后仍存在，但父子 `n` 的保护、照护、路线决定与抗崩能力持续下降。身份保持只能证明关系可被指认，不能证明现实内部仍能运行。

### 4.3 资源补给只补回承载运行

地堡、食物、药物、衣物和住所属于 `x` 或临时 `n`。它们进入父子共同使用后，可恢复身体、分食、睡眠和继续移动能力；它们不生成父子关系，也不生成抽象希望。

### 4.4 源端耗尽不等于关系消失

父亲死亡使原保护与决定接口耗尽，但儿子仍保留父子意义与原则，并将接收判断带入下一关系。死亡改变现实承载结构，不自动删除成员意义或 `nz/zn`。

### 4.5 UM-02 建议拆为 A/B

```text
UM-02A：任务对象成员化
固定承载失效 → 移动护送 → 路线临界 → 回返复测 → 对象由接口进入成员
支持：M-018/M-019

UM-02B：既有成员保存
既有n → 移动耗损 → 临时补位 → 保护源端耗尽/换挡 → 外部承载转交
支持：M-020；待《釜山行》复测
```

暂不正式拆锁。
