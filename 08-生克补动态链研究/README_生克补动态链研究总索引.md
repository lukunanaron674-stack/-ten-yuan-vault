
## 4. 最新具体动态图｜《楚门的世界》街头父亲重现

```text
父亲跨时间稳定面孔、身体特征与亲属身份映射 x并z
→ 生 楚门对“这是父亲且父亲仍活着”的私人确认 z

条件：当前流浪者装束；群众遮挡、分流与车辆带离程序

失败边：
节目组接触入口控制 x ─×→ 克 已形成的父亲存活确认 z
父亲出现 ─×→ 生“真相”
群众和车辆 ─×→ 克客观事实
一次相似面孔 ─×→ 自动等于稳定x并z
```

边界：

- 稳定亲属身份映射可穿透当前装束生成窄身份/存在确认。
- 父亲存活确认与“完整死亡叙事由谁怎样制作”必须分账。
- 确认形成后关闭继续接触，只阻断续证，不自动构成严格`x克z`。
- 本轮只完成C级，不与广播或电梯后台提前合成B级。
