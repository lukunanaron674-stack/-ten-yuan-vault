## 4. 本轮跨片新增结论

### 4.1 时间接口、时间组织和时间危险分层

```text
回转门、逆熵物体、氧气、封闭舱 = x接口
时间戳、夹击、信息隔离、撤离和保密 = xn
由这些结构造成的出口缩窄、缺氧、错位、误伤和最后窗口 = xn生xz
即时行动必须进入另一方向已组织结果 = xn克zx
```

时间倒流、子弹倒飞和红蓝房只是显影，不直接等于`xz`。

### 4.2 《信条》的n生xn纯度低于《盗梦空间》

《盗梦空间》的同步结构较明显从团队共同承担跨层负荷后提炼；《信条》的回转协议、时间夹击、保密和分割算法结构在局部团队形成前已存在。团队主要提高既有`xn`的执行连续性，并非生出整套制度。

### 4.3 牺牲必须拆结果与机制

Neil回返支持局部`zn生n`，因为导师/同伴不再现场指令、风险与结局已知、行为仍持续承担成员与任务缺口。但“牺牲”这个结果本身不能自动证明友情补、稳定本体或命运关系。

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把真相、训练、觉醒、时间、命运、牺牲或视觉逆行直接写成生克补；
- 不把团队执行既有协议写成`n生xn`；
- 不把个体脱钩外推成总体制度消失；
- 新案例必须反向修正中枢和母型。
