## 4. 本轮跨片新增结论

### 4.1 共同体不等于制度

```text
成员被接入、被保护、共同协作和反复返回 = n 候选
共同负荷被提炼为规则、分工、边界和重复流程 = n 生 xn
```

《浪潮》中，课堂命令只是入口；真正让结构跨场景复制的，是归属、协作和成员维护负荷被提炼成纪律与边界。

### 4.2 身份壳不等于内部承载

名称、白衬衫、标志、敬礼和网站属于 `x并z`；它们提高识别、调用、认可和退出成本，但不自动证明内部 `n` 成立。

### 4.3 `nx` 可以是多节点后果

```text
n 提供归属
→ xn 提供默认路线
→ x并z 提供可识别身份
→ z 提高成员确认
→ 个人否决和退出成本逐步恶化
→ 局部 nx 上升
```

这不等于存在一条 `zx 生 nx` 或 `xn 生 nx` 的正式关系。动态链研究不得为了箭头整齐，给几何表增生不存在的器官。

### 4.4 结构反噬发起者

当规则、身份、传播和成员自愿执行已跨场景运行，发起者的一次终止命令无法取消长期复制，可判既有 `xn 克 zx` 在新结构中反向启动。

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把示范、制服、口号和同步行为写成稳定内化；
- 不把 `nx` 的多节点后果伪造为单一直接生关系；
- 新案例必须反向修正中枢和母型。
