## 4. 最新具体动态图｜《飞越疯人院》治疗机构多程序分账

```text
病人身份档案、分类与病历壳 x并z
                │ 生（A-）
                ▼
行为风险、转送与处置资格确认 z
                │ 补（A-）
                ▼
门禁、转送、护工控制、ECT与手术程序 xn_B
                │ 生（A）
                ▼
不可离开、拒绝无效、强制治疗与身体完整性临界 xz_B

生活承载支路：
床位、餐食、洗浴、护理站、活动区与可返回床位 n病房
        ├─生→ 睡眠、饮食、服药、清洁、查房与活动程序 xn_A
        └─克→ 露宿、饥饿、无护理、无床位与立即身体崩塌临界 xz_A

群体承载支路：
病人共同活动、互相见证与可返回群体位置 n群体
        └─生→ 娱乐、协作、共同决策与互助日常程序 xn_C

纪律权能支路：
Ratched公开裁定、隐私揭露与惩罚条件 zx
        ─克→ 病人互信、安全表达与可返回群体位置 n群体
```

关键结论：
- 高体量病房生活承载`n`与高体量强制治疗/不可离开临界`xz`长期并存，改变不同变量，不是严格迁移。
- 治疗机构必须分开生活承载`n`、日常/治疗程序`xn_A`、纪律/强制治疗程序`xn_B`、治疗资源`x`、处置确认`z`与病人身份壳`x并z`。
- 病历身份壳提供识别和调用接口，不自动证明诊断或处置正确。
- 处置确认可能被权力偏置，但仍可给强制程序补入对象、阈值和节点；结构成立与价值正当性分开。
- 共同生活不自动形成群体承载；Ratched的纪律权能通过公开裁定、隐私揭露和惩罚条件击穿群体互信与安全返回。

## 6. 新增边界｜R-MIG-12

```text
治疗机构真实提供床位、饮食、卫生、基础护理和内部返回位置 n
+ 日常/治疗程序 xn_A 反复运行
+ 纪律/强制治疗程序 xn_B 另行识别偏离并关闭退出、拒绝或身体完整性接口
+ 病人身份壳 x并z 与处置确认 z 为程序提供识别对象、资格和节点
+ 治疗资源 x 只提供材料与设备
= 高体量生活承载与强制治疗临界并存，且多程序、多接口必须分账
≠ 医院整体天然为n
≠ 治疗名义天然为补
≠ 处置有害就可跳过身份壳/确认/程序直接写克
```

## 7. 方法更新

1. 每个案例先分总体对象、局部对象、资源、程序、主体和外部接手对象。
2. `n`必须真实接收、提供内部位置、隔离危险、允许停留/返回，或反复承担同组生活负荷。
3. `n克xz`必须限定具体危险；生活承载不自动克不可离开、惩罚、暴力或强制治疗临界。
4. `n生xn`必须证明承载结构使跨阶段程序可重复运行。
5. 相同字母的控制、生活、教育、治疗、纪律和逃脱程序必须分账。
6. “制度化”“治疗”“自由”必须拆成具体位置、角色、程序、接口和变量，不能直接当端点。
7. 身份壳与处置确认可在错误价值判断下结构成立；正确性另行审计。
8. 最终获救、死亡、假释、脑叶切除或离场不能倒证中间关系。
9. 母型仅后验比较。
