## 4. 最新具体动态图｜Apollo 13事故后救生艇承载

```text
事故前Odyssey/服务舱/Aquarius组合承载 n组合
          ║ 氧气罐爆炸、氧气/电力/水损失（第三因素）
          ╠════════════════════════════════════╗
          ▼                                    ▼
返航生存临界 xz                    Odyssey主承载下降/停机
          │ 生                                 │
          ▼                                    └─承载中心转交
关闭Odyssey、进入Aquarius并改线返航的临时决定 zx
                                               ▼
                              Aquarius氧气、内部位置、动力与导航承载 n救生艇
                                               │ 克
                                               └────────→ 返航生存临界 xz

并行支路：系统状态与返航要求确认z ─补→ 应急返航工程程序xn
允许条件：氧气/电池/发动机/过滤材料x ──→ n、xn、zx现实执行
```

压缩：

```text
总体：n组合受损+xz上升+n救生艇继续=n+xz叠加，不是n→xz迁移
主生：xz生zx
主克：n克xz
主补：z补xn
模块内转位：Odyssey主承载→Aquarius主承载
严格迁移：无
搭桥/反馈/反转：无
```

关键结论：某子模块停机不等于整个组合承载退出。Aquarius继续接收三名乘员并提供氧气、内部位置、动力、导航和返航通路，因此事故后的结构是高`xz`与高`n`并行，并发生承载中心重构。

## 6. 位置变化边界

### R-MIG-01｜多位置叠加

`对象连续 + 新位置变量新增 + 旧位置变量持续运行 = 多位置叠加，不是迁移。`

### R-MIG-02｜严格位置迁移

```text
对象连续
+ 旧位置现实控制/调用/承载关系退出或失去主导
+ 新位置变量成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移
```

当前正例：十二怒汉凶刀`x→x并z`；机器人总动员植物`x→x并z`；有求必应屋`n→xz`；Titanic船体`n→xz`。

### R-MIG-03｜隐藏属性揭露

`原功能继续 + 新增x并z识别接口 = 位置叠加/信息重估，不是严格迁移。`

### R-MIG-04｜承载崩塌—临界主导迁移

```text
同一空间先稳定接收、容纳、保护、运输或提供通行 n
+ 灾难第三因素持续改变运行变量
+ 旧承载关系退出
+ 路线、时间窗、危险可到达性与无法停留成为中心 xz
+ 新xz启动合法关系边
= n→xz严格迁移候选
```

当前支持：有求必应屋厉火、Titanic沉没。

### R-MIG-05｜灾难临界叠加—承载中心重构

```text
同一组合承载严重受损
+ 某子模块旧承载下降或停机
+ 另一子模块真实接收并继续生命维持/内部位置/保护/运输/返航
+ 危险xz仍持续高位
= n+xz叠加与承载中心重构，不是整体n→xz迁移
```

当前支持：《阿波罗13号》Aquarius救生艇片段。下一步须用工业/海上设施案例复测对象边界和退出阈值。
