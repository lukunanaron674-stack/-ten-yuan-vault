## 4. 最新具体动态图｜《勇敢的心》

```text
Wallace战斗/组织掌握 x
        └─生→ 反抗领袖公共身份壳 x并z
                 ├─生→ 苏格兰群体领导确认 z_group
                 ├─生→ 贵族政治确认 z_noble
                 └─生→ 英军威胁确认 z_enemy
                              └─补→ 收买、调军、追踪、诱捕、审判与处刑程序 xn_C
                                           └─生→ 援军撤离、路线归零、被捕与死亡临界 xz_C

反抗群体承载 n_B
        ├─克→ 饥饿、暴露、无保护与漂流临界 xz_B
        └─生→ 招募、编队、行军与战斗程序 xn_B

亲密断裂：英军处决程序 xn_A ─生→ Murron死亡及共同生活归零临界 xz_A
失败边：公共领袖壳 x并z ─×→ Murron亲密/家庭承载自动恢复 n_A
R-MIG-19失败：群体称颂/追随 ─×→ 英军唯一Wallace确认下降
```

关键结论：
- 公共领袖壳分别生成群体、贵族与敌方确认；三类确认进入不同程序。
- 英军威胁确认补入收买、调军、追踪、诱捕、审判与处刑程序的目标、路线、优先级和节点。
- 反抗群体承载真实降低成员饥饿、暴露与漂流临界，并生成持续组织程序。
- 公共领袖壳不能恢复Murron生命、共同住所、照护连续性和可返回关系。
- 群体称颂和追随没有控制英军完成唯一身份确认的证言/归因入口，因此不是R-MIG-19第二例。
