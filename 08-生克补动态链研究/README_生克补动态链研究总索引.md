## 4. 当前跨影片结论

### 4.1 同样是 `xn 克 zx`，后续至少有三条路径

- 《千与千寻》：进入结构、获得带代价身份、掌握规则后退出；
- 《飞越疯人院》：外来者反复制造试验，制度强制回收，继承者形成局部意义撤回后退出；
- 《死亡诗社》：教师打开判断试验，学生发生模仿、失败与内化分化，示范者撤场后托德形成局部拒绝再生产。

因此开场关系相同，不代表动态链效果相同。决定差异的是：主角是否被纳入、试验是否转成自己的意义、制度如何回收、结尾是退出还是继续留在结构中公开拒绝配合。

### 4.2 正式克的体量必须分开

```text
执行者受伤 ≠ 制度整体被克
设施破损 ≠ 制度整体被克
个体逃离 ≠ 制度整体被克
成员停止自愿执行、维护或身份再生产 = 可构成低体量正式 zn 克 xn
```

《死亡诗社》中，托德拒绝继续以沉默配合学校对基廷的唯一解释，支持局部覆盖下降；诺兰仍在、课程和纪律仍运行，反证学校整体未被克。

### 4.3 示范、模仿与内化必须分开

```text
示范者在场时跟随 = 最多支持允许条件或状态变化
示范者撤场后仍在新情境独立判断 = 支持内化
逆当前安全方向并承担后果 = 提高 zn 证据
成员主动传递并跨轮次延续 = 才接近制度再生产变化
```

### 4.4 补与生不得为了链条完整而硬填

《飞越疯人院》和《死亡诗社》都保留主补为空。麦克墨菲和基廷极其重要，但“重要”并不自动等于某条正式补关系，理论终于学会不把所有好老师都塞进同一根箭头。

## 7. 研究纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把领袖替大家行动写成全员成长；
- 不把示范、模仿姿势和口号写成稳定 `zn`；
- 不把执行者受伤、设施破坏、通关或逃离写成制度整体被克；
- 每片最多先锁一条主链，其余作为支链；
- 新案例必须反向修正中枢和母型。
