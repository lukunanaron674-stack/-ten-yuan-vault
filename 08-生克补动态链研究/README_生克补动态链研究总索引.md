## 4. 本轮跨片新增结论

### 4.1 生产程序与安全确认必须分层

《深海浩劫》中负压测试、泥浆置换和临时弃井安排属于`xn`；矛盾读数是否足以确认井完整属于`z`。流程继续推进不能倒写为确认完成。

### 4.2 事故前补位失败与事故后补位成功不是同一节点

事故前测试数据未完成可靠收束；事故后泥浆、气体、报警、火势与岗位回报强制补出撤离确认。后者不能倒填前者。

### 4.3 成员撤离复归不等于原系统复归

外部船只和医疗接住幸存者，说明成员进入新承载；平台持续燃烧并最终损失，说明技术系统没有复归。

### 4.4 UM-03跨出航天题材但增加结局分型

《深海浩劫》具备成熟技术承载受损、多源承担重分布、确认与执行分离、成员局部复归，支持UM-03工业C型。它以撤离收束，不要求原平台恢复。

### 4.5 事后调查不得倒填事故当下确认

官方调查可用于校核事件和第三因素，但事故角色当时的`z`只能由当时可获得的读数、报警、目视和回报证明。
