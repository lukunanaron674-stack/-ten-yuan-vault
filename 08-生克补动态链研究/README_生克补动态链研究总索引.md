## 1. 目录职责

- `每次任务必读_生克补动态链滚动中枢.md`：强制启动、红线与真实断点；
- `影片动态链分析模板.md`：人物行为、具体名词对子与动态链统一格式；

- `生克补动态链每小时运行记录.md`：唯一活动账本；
- 本文件：案例登记、候选链累计和通用母型状态。

## 2. 研究层级

```text
关系对子：谁生谁、谁克谁、谁补谁。
戏剧具体积累：人物与阶段 + 人物行为 + 两端具体名词与十元位置 + 为什么成立 + 被改变变量。
动态链：多个具体关系对子按真实阶段连续启动。
通用母型：同一抽象对子链在多个独立、跨题材案例中稳定复现。
```

人物行为是戏剧主体；具体名词挂在行为两端。M-001A至M-032均为`legacy-case-chain`。

### C-001变量同构

```text
实际资源、能力、权限、模型或结果掌握
→获得正式可识别、可调用、可核验的壳
→壳使特定主体、资格或结果获得明确归因确认
→确认给既有程序补入对象、材料标准、期限或阶段节点
```

明确失败边界：

```text
旧壳、旧确认、旧程序只继续运行，不重复累计
购买量、曝光、随机结果、称赞、能力强、创新和最终成功不能替代中间链段
岗位、名单、表格或报告壳存在，但关键主体不确认时，x并z生z失败
主体知晓、口头认同或局部称赞，但程序对象、标准和节点不变时，z补xn失败
```

### C-002变量假设

```text
明确确认给追责程序补入对象、责任、期限与节点
→程序持续处理偏差并扩大临界
→公开权能撤销承载资格与保护边界
→残余承载通过实际接收、补给和冲击吸收阶段性降低风险
```

## 6. 通用母型索引

当前没有新锁定的UM通用母型。

C-001已达到5次并跨犯罪、儿童奇幻、历史职场/航天与体育管理题材，关键对子均有A级案例，也获得影片内明确失败版。暂不授予UM编号，仅因仍缺非影片现实/历史结构复测。

母型锁定门槛：

```text
多次独立复现
+ 至少跨两个题材
+ 关键对子A级证据
+ 具体名词不同但被改变变量与链序一致
+ 排除视觉符号、身份专属、单次动作和结果解释
+ 指出失败版
```

## 7. 方法修正记录

1. 关系对子是“谁生谁、谁克谁、谁补谁”。
2. 戏剧具体积累以主要人物在具体阶段的行为为主体。
3. 具体名词位于行为两端，固定端点并做十元定位。
4. 多个对子合成动态链，不机械套主克、主补、主生顺序。
5. 稳定多次出现的抽象动态链才是母型。
6. 不为模板完整强行制造主克。
7. 能力、职位、名单、认可与程序必须分层；“能力强所以被重用”“模型正确所以赢球”都不是完整关系链。
8. 失败版同样是母型证据：必须指出具体在哪一段断裂。
