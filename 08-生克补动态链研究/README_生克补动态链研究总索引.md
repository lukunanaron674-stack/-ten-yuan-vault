## 4. 最新具体动态图｜牵手后主动回应、关系回返与共同承载稳定

```text
程序与行动接口可运行 xn
→ 对象特异识别恢复 z
→ 瓦力主动发起
→ 伊芙自由回应
→ 片段级关系回返 nz
→ 现实共同生活承载 n 补持续条件
```

直接边：对象特异识别`z`补双方关系回返`nz`所缺主体确认。

条件性补边：现实共同生活承载`n`补片段级`nz`的持续落地条件，但不得替代双方自由回应。

失败边：一次主动牵手与回应不生完整长期`nz`；共同生活`n`不生对象特异`nz`；程序运行`xn`不生关系回返`nz`；共同经历壳`x并z`不生当前自由回应`nz`。

边界：能运行不等于能识别，能识别不等于双方已回应，片段级回返不等于长期稳定；现实承载是持续条件，不是关系生成源。
