- `每次任务必读_生克补动态链滚动中枢.md`：每轮强制启动与断点回写；
- `影片动态链分析模板.md`：每部影片统一分析格式；

## 3. 搭配母型索引

| 编号 | 母型 | 当前状态 | 已支持影片 | 核心风险 |
|---|---|---|---|---|
| M-001A | 制度限位 → 带代价纳入 → 内部承载扩大 → 通关退出 | candidate | 千与千寻（audit） | 把身份接口当自由，把规则通关当制度克制 |
| M-001B | 名字被替换 → 真实称呼跨阶段保留 → 身份连续性增强 | pre-candidate | 千与千寻（支链） | 把记忆恢复、关系确认直接硬判为补 |

母型只有满足以下条件才能锁定：

1. 至少两部不同题材影片出现同构链；
2. 每部至少一个关键节点为 A 级证据；
3. 换掉角色身份、场景和视觉符号后仍成立；
4. 能指出失败版或反例；
5. 能说明母型适合产生的叙事效果与不适用边界。

## 4. 《千与千寻》本轮贡献

1. 证明同一制度可以在不同端点上同时“克”和“补”：规则面 `xn` 克制决定接口 `zx`，承载面 `n` 又补出场内身份 `x并z`；
2. “补”可以带代价，不等于善意或解放；
3. 熟练度、知识与勇敢显影不能自动判 `zn 生 x`；
4. 通过测试、取回名字和离开场域不等于正式克制制度；
5. 白龙、小玲、锅炉爷爷必须拆成不同支链，不得合并为笼统“关系补”。

## 5. 跨影片比较维度

后续每完成一部影片，必须补充：

- 十元概念锚是否稳定；
- 主克出现时间；
- 主补进入时间与代价；
- 主生首次显影时间；
- 关系换挡次数；
- 主角从目标端转为源端的时点；
- 结局是通关、退出、替换执行者，还是核心克制；
- 观众主要获得的效果；
- 最强最近邻解释；
- 母型贡献与反例贡献。

## 6. 当前研究纪律

- 必须先读十元概念定义，再读生补克表；
- 单部影片不能直接锁定搭配母型；
- 不把角色成长总结当动态链；
- 不把所有帮助写成补；
- 不把所有阻碍写成克；
- 不把先后顺序写成生；
- 不因关系数量多就判断搭配丰富；
- 每部影片最多先锁一条主链，其余作为支链；
- 新案例必须反过来修正中枢和母型，而不是只增加文件数量。
