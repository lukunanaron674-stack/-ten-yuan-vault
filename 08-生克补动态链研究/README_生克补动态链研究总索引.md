## 4. 最新具体动态图｜车辆驶离旧址

```text
离场方向 nx 已完成
→ 家庭、车辆与现实道路承载 n 补完成态所缺跨场景行动连续接口
→ 现实行动链持续向前
→ 异界入口退出当前场景
→ 对象特异关系记忆 nz 转入不占用当前行动接口的封存态
→ 无撤销、遗忘或替代证据，不判关系消失
```

直接边：现实承载`n`补已完成方向`nx`所缺跨场景行动连续接口。

条件：`nz`此前已建立；当前互动入口关闭；无明确撤销、遗忘、否认或替代证据。

失败边：`n克nz`；空间离开生关系消失；`nz`持续占用当前接口；`nx`自动维持后续行动连续性。
