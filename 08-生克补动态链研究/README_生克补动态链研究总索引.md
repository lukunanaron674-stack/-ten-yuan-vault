## 4. 最新具体动态图｜《机器人总动员》植物返航

```text
WALL-E可保管、藏放并决定转交的同一株植物 x私人样本
                     │ 生（EVE扫描与任务协议为必要第三因素）
                     ▼
EVE阳性收纳+Axiom识别+Holo-Detector调用的返航证据壳 x并z返航证据壳
                     │ 生
                     ▼
船长对地球仍有可持续生命、返航条件满足的确认 z宜居确认
                     │ 补
                     ▼
Axiom返航、导航与地球重建准备程序 xn返航程序

位置变化：
x私人样本 ═旧控制退出══▶ x并z返航证据壳

并行支路：
xn禁返程序 ──压制候选──▶ zx返航执行
植物被隐藏/销毁尝试 ──接口断裂──▶ 主链执行暂时停止
```

压缩：

```text
主链：x生x并z→x并z生z→z补xn
严格迁移：x私人样本→x并z返航证据壳
主克：无新增A级
搭桥/反馈/反转：无
后续执行：植物进入Holo-Detector后返航启动
```

关键结论：同一株植物的生物属性持续，但WALL-E的私人持有、藏放与单方处分关系在EVE收纳后退出；船上系统、船长与AUTO围绕正式返航样本资格调用它，新位置成为运行中心。物理本性持续不等于旧控制关系持续。

## 6. R-REV-01｜稳定位置真反转不可能引理

固定位置表不存在`A生B`且`B克A`。表面反转至少涉及位置迁移、对象替换、变量替换、接口断裂、物理终止或至少一边未达正式资格。

## 7. 位置变化边界

### R-MIG-01｜同载体多位置叠加不等于迁移

```text
对象连续 + 新位置变量新增 + 旧位置变量持续运行
= 多位置叠加，不是迁移
```

当前负例：《美国队长》盾牌。战斗资源`x`持续运行，同时身份壳`x并z`新增。

### R-MIG-02｜严格位置迁移正例候选

```text
对象连续
+ 旧位置的现实控制/调用/承载关系退出或失去主导
+ 新位置变量成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移
```

当前正例：
1. 《十二怒汉》原涉案刀：被告可调用工具`x`→司法证据壳`x并z`。
2. 《机器人总动员》同一株植物：WALL-E私人样本`x`→Axiom返航证据壳`x并z`。

共同结构：同一具体对象连续；旧现实控制关系退出；新正式接口成为运行中心；新位置继续生成确认并补入程序。

边界：第二例完成非司法复现，但两例都属于`x→x并z`。目前只能说明“资源掌握退出—正式证据接口主导”这一窄迁移结构获得两次支持，不能推广为全部十元位置迁移规律。

### R-MIG-03｜隐藏属性揭露只增加证据壳

```text
对象/物类已有稳定功能位置A
+ 生产、来源或成分被揭露，新增x并z识别接口
+ 原功能核心变量继续运行
= 位置叠加/信息重估，不是严格迁移
```

当前负例：《雪国列车》蛋白块。揭露后口粮仍可供能和继续配给；新增的是生产流程证据接口与Curtis个人确认。

严格位置迁移最低门槛：

1. 同一具体对象连续，不能只证明同类物、同批产品或替代样本连续；
2. 迁移前后z切分焦点和x现象集合分别成立；
3. 旧位置现实关系显著下降、退出或不再主导；
4. 新位置变量成为实际运行中心；
5. 新位置启动合法关系边并通过拿掉与反向测试；
6. 物理属性持续不等于旧关系持续；检查控制主体、调用权与运行中心；
7. 必须保留扫描、认证、扣押、任务协议等必要第三因素，不能把对象自然变化夸大成单因迁移。

## 8. 方法修正

1. 节点是具体名词+十元位置；行为是启动器；生克补是边。
2. 动态链必须保存真实链序与拓扑。
3. 串联、并行、汇合、反馈、搭桥、延伸、反转、转位、迁移、叠加与断裂分账。
4. 同一字母不自动代表同一对象；同一对象也可能同时落在多个十元位置。
5. 同一物类或生产批次不等于同一具体对象。
6. 对象连续和先后变化不足以证明迁移。
7. 首遍屏蔽母型；母型仅后验比较。
8. 新事实或反证导致确认下降，不能仅因目标下降就硬判克。
9. 隐藏属性揭露先记识别壳新增；原用途继续时不得判严格迁移。
10. 对象物理属性或生命状态持续，不等于原控制、调用、承载和归因关系持续。
11. 新位置必须启动A级合法关系边；成为象征或剧情焦点不足。
