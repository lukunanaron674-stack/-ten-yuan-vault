## 4. 本轮跨片新增结论

### 4.1 高体量世界壳可以长期维持局部 `nx`

```text
高体量 x 掌握生活、关系、媒体和路径接口
→ x 生 x并z，形成可调用的身份与世界壳
→ x并z 生 z，使所有关系持续确认该壳
→ xn 吸收偏离、封回路线并修复解释
→ 主体长期少用最终世界解释权
→ 局部 nx 被维持
```

这仍不是 `xn/x并z` 直接生 `nx`，而是多节点关系位置后果。

### 4.2 退出必须拆成至少三层

```text
撤回自愿执行与身份再生产 = 局部 zn 克 xn 候选
原身份不再被本人接受和调用 = x并z 对该主体失效
身体走出场域 = 行动离场
```

三者可同时发生，但不自动证明整体制度被摧毁。

### 4.3 穿帮不是正式克

摄影灯坠落、广告台词露馅、演员失误和布景裂缝只提高反证密度。只有身份壳的调用、可信度、认可归因或结构覆盖持续下降，才接近正式关系变化。

### 4.4 高潮可由 `xz 生 zx` 提供最后决定接口

《楚门的世界》中，风暴把退路和安全窗口压缩到最后选择，楚门仍继续航行，使制作系统必须围绕他的决定反应。这支持已锁定的低/中体量 `xz 生 zx`，但不生成稳定领导本体。

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把示范、制服、口号和同步行为写成稳定内化；
- 不把 `nx` 的多节点后果伪造为单一直接生关系；
- 不把穿帮、个体离场、设施破损或观众反应写成整体制度被克；
- 新案例必须反向修正中枢和母型。
