## 4. 最新具体动态图｜《宾虚》

```text
Messala军政裁定/流放显权 zx
        ─克→ Ben-Hur家族/耶路撒冷对Judah的法律保护、共同居住、申诉与返回接口 n_A

战船奴役/消耗程序 xn_A
        ─生→ Judah死亡、无退路、无法返家与持续消耗临界 xz

Arrius罗马家族承载 n_B
        ├─克→ 无稳定位置、无社会接口与漂流临界 xz
        └─生→ 罗马生活、训练、社交与返程准备程序 xn_B

Ilderim车队承载 n_C
        └─生→ 马匹适配、战车训练、参赛与团队程序 xn_D

Judah驾驶/竞技能力 x
        ─生→ Ilderim车手/战车冠军公共身份壳 x并z
        ─生→ 公众能力确认、Messala敌方确认、Pilate政治确认 z

家人存活/位置/疾病确认 z_family
        ─补→ 寻找、麻风谷接触、护送与重新接收程序 xn_C

断裂：冠军壳 x并z ─×→ 原家族承载自动恢复 n_A
```

关键结论：
- Messala关闭的是法律保护、共同居住、公开申诉和返回接口，不是亲缘事实、财产实体或Judah能力本体。
- 战船奴役程序主要生成死亡和无退路临界；固定座位、口粮和船舱不能把战船自动判成承载。
- Arrius家族与Ilderim车队是两个独立承载对象，分别承担生活/社会接收与训练/竞技负荷。
- 战车冠军壳向公众、敌方和罗马机构生成不同确认；不同`z`进入不同程序。
- 原家族重新接收依赖家人存活、位置、疾病和接触节点确认，不由竞技胜利直接恢复。
