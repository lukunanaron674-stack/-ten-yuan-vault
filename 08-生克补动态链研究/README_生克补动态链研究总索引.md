## 4. 最新具体动态图｜《活埋》棺木多位置边界

```text
绑架、装棺、锁闭、掩埋与位置隐匿程序 xn绑架
                         │ 生
                         ▼
无出口、耗氧、难定位与最后救援窗口 xz囚禁临界
                         │ 生
                         ▼
继续联络、录像或破棺的临时决定 zx

同一棺木的最小承载支路：
木棺内部空腔与板壁 n
                         ─克→ 泥土直接压入、立即压埋与无内部位置临界 xz_A

确认—程序支路：
位置、氧气、电量、绑架要求与救援进展确认 z
                         ─补→ 拨号、节电、录像、破棺与定位协同程序 xn_B

资源支路：
手机、电量、打火机、笔、药物与酒 x
                         ─允许/供给→ xn_B与剩余时间
```

关键结论：

- 同一棺木真实提供低体量内部位置与土压隔离`n`，同时以锁闭、无出口、耗氧和难定位形成高体量主导`xz`。
- `n`与`xz`改变不同变量，因此应分账并存；不是严格迁移，也不能压成纯承载或纯困陷。
- 绑架勒索程序成立`xn生xz`；手机等是`x`资源，不并入承载。
- 最终死亡不能倒证低体量承载从未存在，也不能把局部土压隔离夸大为总体安全。

## 6. 承载边界补充

### R-MIG-08｜暂稳姿态不是承载

```text
主体被固定或暂时不再移动
+ 有脚点、阴影、身体支撑或有限动作空间
+ 核心危险仍直接作用
+ 无真实接收、危险隔离、返回或退出能力
= 暂稳状态/xz内部条件
≠ n局部承载岛
```

### R-MIG-09｜强制封闭空间的最小承载—主导困陷并存

```text
同一封闭对象真实提供内部位置并隔离一类直接危险 n
+ 同一对象/外部程序同时制造无出口、耗氧或时间窗缩窄 xz
+ n只降低局部变量，xz主导总体处境
= n+xz多位置并存
≠ 纯承载
≠ 纯困陷
≠ 严格位置迁移
```

## 7. 方法更新

1. 每个案例必须先分总体对象、局部对象、资源、程序和外部接手对象。
2. `n`必须提供内部位置、接收、隔离危险、停留或返回；“里面有东西”不够。
3. 水、食物、电话、电量、工具、药品和有限空气优先判`x`。
4. 身体被卡住、锁住或姿态暂稳不等于被承载；但若结构确实隔离一类直接危险，可登记相应低体量`n`。
5. 同一对象的`n`与`xz`可以并存，但必须分别写被改变变量、体量和主导层级。
6. 最终获救、死亡或离场不能倒证中间关系边。
7. 母型仅后验比较，不参与首遍端点命名。
