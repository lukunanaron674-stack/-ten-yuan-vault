## 4. 最新具体动态图｜《雪国列车》蛋白块揭露

```text
尾舱长期配给并食用的蛋白块 n口粮
          ║ 旧承载继续：仍可供能、仍被食用、配给未停
          ╠════════════════════════════╗
          ║                            ║
          ▼                            ▼
持续口粮承载 n口粮          生产流程揭露壳 x并z揭露壳
                                         │ 生
                                         ▼
                              Curtis的配方与隐瞒确认 z配方确认
                                         │
                                         └─传播未启动：一次沉默，关系边未判
```

压缩：

```text
主链：x并z揭露壳生z配方确认
位置变化：n口粮 + x并z揭露壳（叠加）
严格迁移：否
主克/主补/搭桥/反馈/反转：无
```

关键结论：隐藏配方被揭露，只能证明新增识别与归因接口。蛋白块仍能供能、仍被同伴食用、生产配给程序仍运行，所以旧`n`承载没有退出；且影片展示的是同一物类/生产批次，不足以替代单个具体对象连续性。

## 6. R-REV-01｜稳定位置真反转不可能引理

固定位置表不存在`A生B`且`B克A`。表面反转至少涉及位置迁移、对象替换、变量替换、接口断裂、物理终止或至少一边未达正式资格。

## 7. 位置变化边界

### R-MIG-01｜同载体多位置叠加不等于迁移

```text
对象连续 + 新位置变量新增 + 旧位置变量持续运行
= 多位置叠加，不是迁移
```

### R-MIG-02｜严格位置迁移正例候选

```text
对象连续
+ 旧位置的现实控制/调用/承载关系退出或失去主导
+ 新位置变量成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移
```

当前正例：《十二怒汉》原涉案刀。

### R-MIG-03｜隐藏属性揭露只增加证据壳

```text
对象/物类已有稳定功能位置A
+ 生产、来源或成分被揭露，新增x并z识别接口
+ 原功能核心变量继续运行
= 位置叠加/信息重估，不是严格迁移
```

当前负例：《雪国列车》蛋白块。揭露后口粮仍可供能和继续配给；新增的是生产流程证据接口与Curtis个人确认。

严格位置迁移最低门槛：

1. 同一具体对象连续，不能只证明同类物、同批产品或替代样本连续；
2. 迁移前后z切分焦点和x现象集合分别成立；
3. 旧位置现实关系显著下降、退出或不再主导；
4. 新位置变量成为实际运行中心；
5. 新位置启动合法关系边并通过拿掉与反向测试；
6. 物理属性或旧功能仍持续时，优先判叠加。

## 8. 方法修正

1. 节点是具体名词+十元位置；行为是启动器；生克补是边。
2. 动态链必须保存真实链序与拓扑。
3. 串联、并行、汇合、反馈、搭桥、延伸、反转、转位、迁移、叠加与断裂分账。
4. 同一字母不自动代表同一对象；同一对象也可能同时落在多个十元位置。
5. 同一物类或生产批次不等于同一具体对象。
6. 对象连续和先后变化不足以证明迁移。
7. 首遍屏蔽母型；母型仅后验比较。
8. 新事实或反证导致确认下降，不能仅因目标下降就硬判克。
9. 隐藏属性揭露先记识别壳新增；原用途继续时不得判严格迁移。
