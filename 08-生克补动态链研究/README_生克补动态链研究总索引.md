## 本轮失败边

```text
信件 ──补──▶ nx
失败：媒介物不能替代完整关系源端。

钱 ──补──▶ nx
失败：只提供资源，不独立提供目的地与关系承诺。

nz ──生──▶ nx
失败：nx此前已存在但低占用，本轮填补的是既有缺口。

nx ──生──▶ nz
失败：后续行动不能反向生成此前已经保留的关系承诺。
```
