## 4. 本轮跨片新增结论

### 4.1 《雪国列车》与《狂暴之路》的承载方向相反

| 维度 | 雪国列车 | 疯狂的麦克斯：狂暴之路 |
|---|---|---|
| 空间结构 | 唯一封闭移动容器 | 开放荒漠+固定资源堡垒+移动战车 |
| 核心 `x` | 引擎、车体、水、食物、门、儿童身体 | 水源、燃料、车辆、武器、种子、身体、入口 |
| 身份壳 `x并z` | 尾厢/前厢、职责、接班人 | 妻子、战争男孩、母亲、统治者、车队成员 |
| 承载 `n` | 列车生命支持 | 堡垒水食住产+移动车队短时互担 |
| 制度 `xn` | 配给、门禁、人口平衡、教育、维护 | 配给、繁殖、献祭、交换、追捕、军团调度 |
| 中段变化 | 进入中心后发现系统吸纳 | 到达目的地后发现承载已消失 |
| 高潮方向 | 拒绝维护并摧毁旧容器 | 返回旧中心并回夺资源/入口 |
| 结尾 | 容器毁灭，新承载未知 | 旧承载仍在，资源可达性改变，新制度未知 |

### 4.2 离场、迁移、脱钩与回夺必须分写

```text
离开堡垒 = 位置脱离
带走战车/燃料 = 资源迁移
不再接受妻子/战争男孩身份 = 身份壳脱钩
移动中承担驾驶/医疗/保护 = 临时 n 候选
夺取水源/入口/配给 = 掌握边界改变
跨阶段建立新分配规则 = 制度重写（影片未展示）
```

其中任一步都不能替代其他步骤。

### 4.3 目的地身份不等于真实承载

“绿洲”在记忆和身份叙事中存在，但到达后已变成沼泽。只有能够提供水、食物、空间、保护与持续维持，才是真实 `n`。因此：

```text
被命名的归宿 x并z
≠ 当前可用承载 n
```

### 4.4 杀死统治者不等于制度完成变化

乔死亡只移除一个高权重决定中心。旧结构是否下降，还要观察：

- 水源和入口由谁掌握；
- 军团与守门者是否继续执行；
- 妻子与战争男孩身份是否继续被调用；
- 配给接口是否改变；
- 新分配是否跨阶段运行。

本片明确展示资源可达性变化，却没有展示成熟新制度。
