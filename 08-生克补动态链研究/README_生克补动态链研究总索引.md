## 4. 本轮跨片新增结论

### 4.1 火星救援不是M-024简单复制

《阿波罗13号》由单一高能爆裂击穿成熟承载，并转入备用救生艇；《火星救援》由撤离与失联切断成员现实接口，随后长期环境、资源和距离持续耗损。两片共享多源确认与执行分离，但入口不同。

### 4.2 成员失联不等于成员关系消失

Watney失去通信、补给与回收接口时，机组成员身份与回返责任并未自动清零。Pathfinder恢复的是现实可达性与确认接口，不是重新生成成员关系。

### 4.3 孤立承载负荷可以连续生程序

```text
Hab真实接住Watney
→ 单人长期呼吸、饮水、进食、种植、维护和迁移
→ 农业、制水、配给、通信与长途迁移程序xn
```

抽象孤独或求生欲不能替代真实负荷。

### 4.4 临时救援何时扩展为持续承载

```text
一次通信/一次补给/一次轨道方案 = 局部接口
农业+通信+补给+迁移+回收跨阶段衔接 = 分布式持续承载候选
```

必须持续接住同一成员，并承担状态更新、资源、路线、反馈和回收。

### 4.5 UM-03升级但暂不锁定

阿波罗13号与火星救援提供两部独立技术影片支持，UM-03升为`provisionally-supported`；因两片均为航天题材，仍需极地、深海、医疗或工业灾难案例。
