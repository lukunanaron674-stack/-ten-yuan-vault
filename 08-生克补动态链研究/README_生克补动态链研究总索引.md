## 4. 本轮跨片新增结论

### 4.1 自愿停留是允许条件，不是吸纳完成

```text
主动留在边缘位置
≠ 旧制度已脱钩
≠ 地方共同体已接收
```

必须继续观察家庭/住所、劳动分工、互保、营救、成员责任和反复返回。

### 4.2 爱情与共同体承载分开

```text
爱情/婚姻 nz+n支链
→ 可提高家庭位置与回返意愿
但不能替代
营地住所、成员保护、劳动分工、共同风险与迁移责任 n
```

### 4.3 保护性离开不是身份退出

邓巴结尾离开部落的可观察作用是降低军方追捕对营地的可达性。若成员关系、互保义务与返回资格仍保持，则应分写：

```text
位置离开
+
共同体风险隔离
```

不能直接写成身份脱钩或关系结束。

### 4.4 离场原则复测再次成立

《最后的武士》通过“回东京后拒绝旧镇压路线”复测；《与狼共舞》通过“被军方俘获、失去地方保护后仍拒绝提供部落路线”复测。二者共同提高“地方文化原则需离开承载环境验证”的跨片稳定性。

### 4.5 M-015 / M-016 / M-017 与 UM-01

| 维度 | M-015 阿凡达 | M-016 最后的武士 | M-017 与狼共舞 |
|---|---|---|---|
| 进入接口 | 身体借壳 | 敌方职位与俘虏位置 | 旧制度边缘的自愿停留 |
| 地方接收 | 训练、住所、仪式、互保 | 过冬照护、家庭、劳动、互保 | 家庭、翻译、狩猎、婚姻、营救与迁移 |
| 旧制度复测 | 情报背叛后回返承担 | 回东京后拒绝镇压维护 | 被军方俘获后拒绝提供地方情报 |
| 结局 | 身体/身份/承载对齐 | 共同体殉灭，原则转交 | 保护性离开，成员关系保持 |

三者支持上位候选 UM-01，但入口、断裂方式和结局变量差异足够大，暂不合并子母型。
