## 4. 本轮跨片新增结论

### 4.1 《沙丘》：合法壳、实际掌握和地方承载三分

```text
帝国封地/领主称号 = x并z 壳
香料、水、设备、军力、路线和地方知识 = x
生产义务、封臣关系、军力部署和袭击时机 = xn
弗雷曼住所、水纪律、保护和成员位置 = n
```

公开合法壳可以先成立，而实际掌握和地方承载仍缺失。授权甚至可成为诱捕接口。

### 4.2 预言传播不是命运实体化

姐妹会长期传播的救世主叙事属于：

```text
传播组织 xn
→ 稳定预言角色壳 x并z
→ 弗雷曼获得可识别与归因对象
→ 具体确认 z 的概率提高
```

但它不能直接证明：

- 保罗的稳定 `zn`；
- 预见必然真实；
- 弗雷曼已承认其领导；
- 新制度已围绕他建立。

### 4.3 最低准入不等于完整身份再生产

保罗击败贾米斯并选择进入沙漠，只能证明：

- 外来者未被杀；
- 获得最低成员位置；
- 接受地方路线与规则；
- 地方承载迁移开始。

尚不能证明：

- 已成为弗雷曼稳定成员本体；
- 旧贵族壳已完全消失；
- 救世主壳已转成稳定认可；
- 已成为共同体或制度源端。

### 4.4 与《狂暴之路》的承载方向比较

| 维度 | 狂暴之路 | 沙丘（2021） |
|---|---|---|
| 原承载 | 堡垒仍存在但被垄断 | 厄崔迪家族承载被军事摧毁 |
| 主体策略 | 外逃失败后返回回夺旧承载 | 失去原承载后进入地方共同体 |
| 资源关系 | 水源、入口与车辆被重新掌握 | 水、沙漠知识与穴地仍由弗雷曼掌握 |
| 身份变化 | 旧身份脱钩，资源中心被回夺 | 贵族壳悬置，地方准入开始 |
| 结尾 | 资源可达性变化，新制度待证 | 承载迁移开始，新身份/制度待证 |
