```text
【上一阶段残留】
离场方向 nx
    ──完成退出──▶ 不再占用当前主导位

【本片段主次对子】
主：定点现实承载 n_fixed
（新家门前 + 家庭同行 + 可进入入口）

n_fixed
    ──生：提供可观察、可进入、可共同指认的现实位置证据──▶

次：客观位置确认 z_position
（“这里”被确认成即将进入的新生活位置）

z_position
    ──维持：固定后续行动所围绕的客观位置──▶

进入新家前的现实行动接口
```

字母关系：

```text
n_fixed ──生──▶ z_position
z_position ──维持──▶ 进入新家前现实行动接口
```

条件：`n_fixed`形成可持续定点承载；存在可观察对象、入口与家庭共同目的地；主体形成最低位置确认。

失败边：`z_position生n_fixed`；`n_fixed生nx`；`n_fixed补z_position`；`z_position克nx`。
