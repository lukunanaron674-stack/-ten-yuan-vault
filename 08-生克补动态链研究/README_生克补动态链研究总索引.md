## 4. 本轮跨片新增结论

### 4.1 世界壳直接规定身体与感知时，关系几何不变，体量提高

```text
高体量 x 掌握身体、生存、神经输入与感知接口
→ x 生 x并z：世界壳直接代理现实与身体
→ x并z 生 z：视觉、触觉、疼痛与社会回应共同确认该壳
→ 高体量 xn 克 zx：偏离同时遭程序、身体与现实规则回收
```

### 4.2 真相入口不等于现实承载

脱离伪世界后，若没有身体恢复、成员位置、食物、训练、操作接口与返回点，主体只获得真相，不获得可持续现实。《黑客帝国》中尼布甲尼撒号及其成员支持 `n 补 x并z` 的动态候选，但医疗、技术、教学和共同体仍需拆分。

### 4.3 训练不等于 `zn 生 x`

功夫、程序规则和身体适应主要来自教学、熟练度、技术条件与操作员支持。只有导师撤场后主体仍独立判断、逆安全方向并承担后果，才接近自己的 `zn`。

### 4.4 击败代理人不等于总体制度被克

Smith 被击败，只说明执行代理与矩阵对尼奥个人的覆盖下降；机器总体、矩阵和人类能源结构仍然运行。

## 5. 跨影片比较

| 维度 | 楚门的世界 | 黑客帝国 |
|---|---|---|
| 世界壳入口 | 媒体、关系、场景与路径 | 身体、神经、感知与生存接口 |
| 主生 | `x 生 x并z` | `x 生 x并z`，体量更高 |
| 主克 | 高体量 `xn 克 zx` | 高体量 `xn 克 zx`，程序可复制接管 |
| 真实世界承载 | 影片未展示退出后的承载 | 飞船 `n` 接住身体、成员位置和训练 |
| 临界决定 | 海上风暴 `xz 生 zx` | 红药丸与返救临界 `xz 生 zx` |
| 最强误判 | 走门=节目整体被克 | 觉醒/训练=信念生能力；击败 Smith=矩阵崩溃 |
| 结尾 | 个体退出，整体余波未决 | 个人规则覆盖下降，战争开启 |

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把真相、训练、觉醒、吃药、复活和击败代理人直接写成生克补；
- 不把 `nx` 的多节点后果伪造为单一直接生关系；
- 不把个体脱钩外推成总体制度消失；
- 新案例必须反向修正中枢和母型。
