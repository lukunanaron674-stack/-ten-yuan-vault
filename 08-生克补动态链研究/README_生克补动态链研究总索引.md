## 4. 最新具体动态图｜妻子车内广告

```text
妻子既有公共伴侣角色壳 x并z
→ 生 楚门对“她正在服务外部节目与广告”的私人确认 z

广告展示程序 xn
→ 条件性补入 角色壳外部服务用途的结构证据

条件：隐藏镜头、产品罐、赞助结构
失败边：一次广告行为自动等于稳定x并z；广告程序克亲密关系；产品道具生真相；xn克确认
```

边界：单次广告行为只显影既有角色壳；程序提高具体确认而非压低确认；楚门的片段确认不自动等于完整世界节目因果叙事。
