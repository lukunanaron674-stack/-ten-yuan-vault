## 4. 本轮跨片新增结论

### 4.1 语言对象、共享语义界面、组织结构与确认必须拆开

```text
声画、字形、设备、词表与语料 = x
可稳定识别、书写、复述和共享的语义界面 = 局部 x并z
语法、整体语义、翻译流程与信息顺序 = xn
明确主体确认明确对象与内容 = z
```

语言长得完整、优美或非线性，不会自动获得 `z/xz/zn` 资格。

### 4.2 《降临》的时间组织不同于《信条》

《信条》的 `xn` 主要组织正逆行动、窗口、氧气、情报和夹击；《降临》的七肢桶语言首先重排主体可读取信息的顺序，而全球军事 `xn` 则把误译和断联转成临界风险。两片都不能把时间奇观直接判为 `xz`。

### 4.3 预知损失不等于 `xz 克 zn`

```text
提前知道失去
→ 信息条件与代价排序变化
→ 具体行动可能改变
```

只有旧原则的最终指导资格持续撤销，才可能判 `xz 克 zn`。露易丝仍判断有限关系值得进入，因此《降临》是“原则在已知代价下保持”，不是“危险摧毁意义”。

### 4.4 高潮确认的跨时间证据链

未来号码和私密话语首先是 `x` 信息；它们由非线性语言与时间信息结构跨阶段组织，最终补入尚将军的确认位置，形成局部 `xn 补 z` 候选。电话和停战只是接口与后续结果。

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把真相、训练、觉醒、时间、命运、牺牲、预知或视觉逆行直接写成生克补；
- 不把语言材料、语言壳、语言组织与确认结果压成一个端点；
- 不把行动改变直接写成稳定本体或`zn`改变；
- 不把团队执行既有协议写成`n生xn`；
- 不把个体脱钩外推成总体制度消失；
- 新案例必须反向修正中枢和母型。
