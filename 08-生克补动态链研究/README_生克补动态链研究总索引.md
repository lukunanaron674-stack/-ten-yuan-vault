## 4. 最新具体动态图｜《十二怒汉》凶刀证物

```text
被告购买、携带并可调用特殊弹簧刀 x刀_作案期
          ║ 司法扣押后旧掌握与处分变量退出
          ║ 严格位置迁移
          ▼
法庭编号、保全、证言对应的凶刀证据壳 x并z刀_审判期
          │ 生（与购买、朋友辨认、罕见性判断并因）
          ▼
“凶刀唯一对应被告所购之刀”的确认 z唯一归因
          ▲
          │ 唯一性前提被击穿
陪审员8掌握并公开并置的同款刀 x同款刀
          └──新增反证与接口断裂，不登记新克边
```

压缩：

```text
位置迁移：x刀_作案期 → x并z刀_审判期
主链：x生x并z → x并z生z
断裂支路：同款刀击穿z唯一归因的唯一性前提（关系未判）
主克/主补/搭桥/反馈：无
```

关键结论：涉案刀进入司法控制后，被告不再能现实调用或处分，旧`x`掌握关系退出；证物编号、保全、展示和归因接口成为运行中心，因此不同于盾牌案例的多位置叠加。刀仍锋利只说明物理属性持续，不说明旧掌握关系持续。

## 6. R-REV-01｜稳定位置真反转不可能引理

固定位置表不存在`A生B`且`B克A`。表面反转至少涉及位置迁移、对象替换、变量替换、接口断裂、物理终止或至少一边未达正式资格。

## 7. 位置变化边界

### R-MIG-01｜同载体多位置叠加不等于迁移

```text
对象连续
+ 新位置变量新增
+ 旧位置变量持续运行
= 多位置叠加，不是迁移
```

### R-MIG-02｜严格位置迁移正例候选

```text
对象连续
+ 旧位置的现实控制/调用/承载关系退出或失去主导
+ 新位置变量成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移
```

当前正例：《十二怒汉》原涉案刀。迁移前是被告可调用的物理工具掌握`x`；迁移后是司法系统保全和陪审团调用的证据展品`x并z`。刀的物理锋利持续，但被告的掌握关系退出。

严格位置迁移最低门槛：

1. 同一具体对象连续；
2. 迁移前后z切分焦点和x现象集合分别成立；
3. 旧位置现实关系显著下降、退出或不再主导；
4. 新位置变量成为实际运行中心；
5. 迁移前后关系边分别通过拿掉与反向测试；
6. 对象物理属性持续不自动等于旧十元关系持续。

## 8. 方法修正

1. 节点是具体名词+十元位置；行为是启动器；生克补是边。
2. 动态链必须保存真实链序与拓扑。
3. 串联、并行、汇合、反馈、搭桥、延伸、反转、转位、迁移、叠加与断裂分账。
4. 同一字母不自动代表同一对象；同一对象也可能同时落在多个十元位置。
5. 对象连续和先后变化不足以证明迁移。
6. 首遍屏蔽母型；母型仅后验比较。
7. 制造、训练、控制、失控、攻击和死亡不得直接写成关系。
8. 新事实或反证导致确认下降，必须先记事实更新与接口断裂；不能仅因目标下降就硬判克。
