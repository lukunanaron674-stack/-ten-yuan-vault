## 4. 最新具体动态图

### 《寻梦环游记》作者归因夺取与公开揭露

```text
埃内斯托掌握作品、传播与署名入口 x_E
       ├─克→ 赫克托正确作者确认 z_H（长期压低）
       └─生→ 埃内斯托公共名望壳 x并z_E
                     │ 生
                     ↓
           对埃内斯托的错误作者确认 z_E

揭露证据壳 x并z_R ─生→ 赫克托正确作者/祖先确认 z_H
                                      │ 补
                                      ↓
                          家族讲述与作品归档程序 xn_R
                                      │ 延伸
                                      ↓
                          家族接纳与祭坛承载 n_H ─克→ 遗忘临界 xz_H
```

压缩：

```text
主克：x_E克z_H
冒署支路：x_E生x并z_E → x并z_E生z_E
揭露链：x并z_R生z_H → z_H补xn_R
承载延伸：n_H克xz_H
汇合节点：z_H
反馈环：无
搭桥：无
反转/转位：确认对象由z_E转位为z_H；对象不同，不登记真正反转
断裂：无揭露壳时，跨主体正确确认与后续程序改线断裂
```

关键新增：
- `x克z`必须写清被掌握的作品、署名、传播或引见入口，以及认可落错对象的变量；
- 错误确认`z_E`仍是真实发生的确认，不能因为事实错误就取消其关系位置；
- `x并z_E`冒署公共壳与`x并z_R`揭露证据壳同属`x并z`，但对象、阶段和功能相反，必须分账；
- `z_E`与`z_H`是不同确认对象，本案属于归因转位，不是同一端点的方向反转；
- 公开揭露不能直接写成“真相克谎言”，必须经过可识别、可归因和可复核的证据壳。

## 6. UM-004当前边界

```text
x生x并z → x并z生z → z补xn
```

只允许后验使用：
1. 新案例先独立锚定节点和关系；
2. 比较时除字母链外，还要比较链序、支路、汇合、反馈、承载背景与断裂位置；
3. 同字母若具体对象、阶段或体量不同，必须分为不同节点；
4. 最终成功不能倒证中间关系；
5. 《火星救援》只增加主链支持，不意味着其完整动态图与科研案例同构；
6. 《寻梦环游记》的冒署支路局部含`x生x并z→x并z生z`，但主图以`x克z`和确认转位为核心，不计入UM-004新支持。

## 7. 方法修正记录

1. 节点是具体名词+十元位置；行为是启动器；生克补是边。
2. 动态链必须保存真实顺序和图拓扑。
3. 串联、并行、汇合、反馈、搭桥、延伸、反转、转位与断裂必须分账。
4. 同一字母不自动代表同一对象。
5. 搭桥是图结构功能，不是凡有中介皆搭桥。
6. 首遍屏蔽母型；母型仅后验比较。
7. 错误确认与正确确认可同时属于`z`，但必须按确认对象和归因内容分节点。
8. 真正反转要求同一具体端点、同一对象和同一变量跨阶段改变方向；对象换位只记转位。
