## 4. 最新具体动态图｜《狮子王》承载资格断裂、外部接手与回归

```text
资格断裂：
Scar公开王权/驱逐权能 zx
        ─克→ 荣耀石对Simba的成员接收、保护与返回能力 n_A
        ─结果→ Simba流亡、追杀与无稳定停留临界 xz

外部承载接手：
Timon/Pumbaa绿洲、食物、同伴与返回位置 n_B
        ├─克→ Simba脱水、漂流与无稳定停留临界 xz
        └─生→ 觅食、休息、共同活动与群体日常程序 xn_B

旧家园失效：
Scar长期统治/资源消耗程序 xn_A
        ─生→ 荣耀石缺食、成员受压与承载失效临界 xz_C

回归汇合：
家园危机确认 z_C
+ Simba连续身份/回归资格确认 z_identity
        ─补→ 返程、伙伴联合、公开对质与恢复程序 xn_C
        ─结构结果→ 旧家园接收边界重新开放，n_A恢复运行
```

关键结论：
- Scar不是仅让Simba“离家”，而是以公开王权改写成员资格、保护接口与返回边界，成立`zx克n`。
- Timon/Pumbaa提供的是独立外部承载`n_B`，不是荣耀石迁移后的新位置；其真实接收与跨年生活使`n克xz`、`n生xn`成立。
- 荣耀石实体和部分成员承载仍存在，但在Scar统治下对Simba接收资格被关闭、整体承载能力衰退；这是资格断裂，不是空间消失。
- Nala的家园状态确认与Rafiki/Mufasa记忆提供的身份/回归资格确认补入回归程序的不同缺口。
- Scar统治终止后旧家园重新开放只登记结构结果，不硬造“回归程序生/补家园”。

## 6. 新增边界｜R-MIG-15

```text
旧承载对象A仍真实存在
+ 公开权能zx改写成员资格、接收边界或保护接口
+ A对特定主体的承载能力被克制，但空间本体未消失
+ 独立外部承载对象B真实接手主体并承担生活/保护负荷
+ 后段资格障碍解除，A重新接收主体
= 资格断裂—外部承载接手—旧承载重新开放
≠ A迁移为B
≠ A严格n→xz
≠ 主体离开自动等于n消失
≠ 回归程序天然生/补n
```

## 7. 方法更新

1. 家园、组织或家庭仍存在时，必须分开物理/群体对象持续与特定成员接收资格断裂。
2. `zx克n`优先检查公开成员裁定、驱逐、除名、断亲、资格撤销与保护接口关闭。
3. 外部承载接手必须真实提供接收、供给、保护、返回位置和跨阶段生活负荷。
4. 身份确认、家园危机确认和回归行动程序必须分账；“责任”“勇气”“爱家园”不得直接当端点。
5. 旧承载重新开放先登记结构结果，不自动写`xn生n`、`z补n`或“胜利补家园”。
6. 最终登位、下雨、生态恢复或回家不能倒证中间关系。
7. 母型仅后验比较。
