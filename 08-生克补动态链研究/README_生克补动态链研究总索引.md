## 4. 最新具体动态图｜《一级恐惧》法庭人格爆发

```text
直接边：
Aaron人格呈现入口掌握 x
→ 生 分裂人格减责壳 x并z

分裂人格减责壳 x并z
→ 生 Vail个人错误确认 z_wrong_Vail
→ 生 法院精神失常减责确认 z_wrong_court

法院精神失常减责确认 z_wrong_court
→ 补 司法减责处置程序 xn

失败边：
Aaron人格呈现入口掌握 x
─×→ 法院完整刑责正确确认 z_right

总体链式效果：
完整故意责任候选被替换为精神失常减责与精神医疗收押位置。
```

关键边界：
- 人格呈现、人格壳、律师个人确认、法院可执行确认与客观事实分账。
- 错误来源为制造型、转译型与缺证型。
- 主体只控制自我呈现，不控制检方证据、专家反鉴别与法官审查等全部必要入口，因此严格`x克z_right`失败。
- “表演克真相”“聪明生胜诉”均为失败表达。
