## 4. 本轮跨片新增结论

### 4.1 M-028获得第二部同题材支持，但不锁定

《迫降航班》复现成熟航班、控制能力突失、现场最小确认、即时执行和外部成员接收；但与《萨利机长》同属民航迫降，不能替代异题材验证。

### 4.2 技术成功与事实清白互不推出

Whip的迫降技术事实可以成立，同时毒理、录音、残骸和证词可以补出另一条责任事实。调查不能倒写其技术无效，技术也不能抹除责任。

### 4.3 法律证据接口与事实变量必须分开

律师和工会可改变证据可调用性、裁决路径和公开归因，却不能凭程序成功把事实变量改成不存在。

### 4.4 英雄壳可以保护，也可以劫持责任归因

公众认可与职业名望形成`x并z/z`增值后，可能成为代理防御的资源；它解释的是谁被相信、谁被保护，不解释事故当时的设备与执行机制。

### 4.5 公开承认只锁行为节点，不锁稳定原则

Whip停止嫁祸并承担后果，支持责任归位；但是否形成稳定`zn`仍需排除辩护路线耗尽并跨阶段复测。
