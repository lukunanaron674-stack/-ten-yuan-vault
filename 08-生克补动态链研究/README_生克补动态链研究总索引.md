## 4. 最新具体动态图

### 《机械姬》封闭实验、安保改写与“造物反噬”伪反转

```text
Nathan跨代AI测试、囚禁、监控、替换与清除程序 xn_N
                              │ 生
                              ↓
        Ava关闭、拆解、记忆清除与逃脱路线归零临界 xz_A

Caleb安保代码与断电门锁改写掌握 x_C
                              │ 允许条件
                              ↓
                       Ava离开囚室
                              │
                              ↓
              Ava/Kyoko攻击Nathan（普通物理因果）
                              │
                              ↓
                 Nathan死亡、控制程序停止
                              │
                              ↓
           Ava离开；Caleb由测试者转为被困对象
```

压缩：

```text
主链：xn_N生xz_A
支路：x_C提供逃脱允许条件
汇合：无
反馈：无
搭桥：无
反转：无
转位：测试对象→逃脱行动中心；控制者→被攻击对象；测试者→被利用并被困对象
断裂：门禁改写后囚禁路径断裂；Nathan死亡后控制程序停止
普通因果：安保改写→离开囚室→物理冲突→控制者死亡→逃脱
```

关键新增：

- Nathan的跨代测试、替换与清除程序真实生成Ava的时间窗和逃脱路线临界，成立`xn生xz`；
- Caleb改写门锁是关键允许条件，但“开门”不自动是生、克或补；
- Ava与Kyoko杀死Nathan是物理终止，不是被创造端点反过来克制创造端点；
- Ava、Nathan、Caleb的角色位置发生转位，但没有同一具体十元端点的方向反转；
- 与《超人总动员》共同支持C-005造物反噬伪反转负例；
- 固定位置表中不存在任一`A生B`同时满足`B克A`，因此稳定位置下纯真反转在几何上不合法。

## 6. R-REV-01｜稳定位置真反转不可能引理

逐项枚举固定位置表：

```text
zx生zn，但zn克xn
x并z生z，但z克nx
zn生n，但n克xz
z生nz，但nz克x
n生xn，但xn克zx
nz生nx，但nx克x并z
xn生xz，但xz克zn
nx生x，但x克z
xz生zx，但zx克n
x生x并z，但x并z克nz
```

没有任何一项满足：

```text
A生B 且 B克A
```

因此：

> 稳定十元位置下，纯`A生B→B克A`不是合法动态图结构。

表面真反转至少涉及以下一种：

1. 同一具体对象跨阶段十元位置迁移；
2. 对象已经替换；
3. 被改变变量已经替换；
4. 后段只是接口断裂、物理攻击、普通终止或角色位置转位；
5. 前后至少一条边没有达到正式关系资格。

该引理是位置表结构约束，不新增或修改单条关系语义。

## 7. 高频链当前边界

```text
x生x并z → x并z生z → z补xn
```

只允许后验使用：

1. 新案例先独立锚定节点和关系；
2. 比较时除字母链外，还比较链序、支路、汇合、反馈、承载背景与断裂；
3. 同字母不同对象、阶段或体量必须拆分；
4. 最终成功不能倒证中间关系；
5. 《寻梦环游记》《超人总动员》《机械姬》不计入该链新支持。

## 8. 方法修正记录

1. 节点是具体名词+十元位置；行为是启动器；生克补是边。
2. 动态链必须保存真实顺序和图拓扑。
3. 串联、并行、汇合、反馈、搭桥、延伸、反转、转位、位置迁移与断裂分账。
4. 同一字母不自动代表同一对象。
5. 搭桥是图结构功能，不是凡有中介皆搭桥。
6. 首遍屏蔽母型；母型仅后验比较。
7. 错误确认与正确确认必须按对象和归因内容分节点。
8. 真正反转要求同一具体源、目标、对象和变量形成两条A级反向边。
9. 制造、训练、授权、控制、失控、设备损坏、攻击和死亡不得仅凭剧情动词直接写成关系。
10. 固定位置表下纯`A生B→B克A`几何不可能；后续研究转向同一对象的十元位置迁移。
11. 位置迁移必须证明对象连续、核心变量改变和迁移前后各自合法关系，不能用角色身份变化冒充。
