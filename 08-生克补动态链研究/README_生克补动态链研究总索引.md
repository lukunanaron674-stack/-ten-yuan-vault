- `每次任务必读_生克补动态链滚动中枢.md`：强制启动、红线与真实断点；
- `影片动态链分析模板.md`：人物行为、具体名词对子与动态链统一格式；

- `生克补动态链每小时运行记录.md`：唯一活动账本；
- 本文件：案例登记、候选链累计和通用母型状态。

每轮先读`01-十元系统/001-概念的定义.md`，完成`z切分焦点+x现象集合+十元位置+本体/状态+体量`锚定。

## 2. 研究层级

```text
关系对子：谁生谁、谁克谁、谁补谁。
戏剧具体积累：人物与阶段 + 人物行为 + 两端具体名词与十元位置 + 为什么成立 + 被改变变量。
动态链：多个具体关系对子按真实阶段连续启动。
通用母型：同一抽象对子链在多个独立、跨题材案例中稳定复现。
```

人物行为是戏剧主体；具体名词挂在行为两端。M-001A至M-032均为`legacy-case-chain`。

### C-001变量同构

```text
实际资源掌握与处分
→资源获得公开可识别、可调用、可兑现或可核验的壳
→壳使特定主体获得明确目标或资格确认
→确认给既有程序补入参与者、聚焦对象、筛选标准与阶段节点
```

失败边界：资源壳已经存在、目标已经确认、程序只继续运行时，不得重新累计；购买量、曝光、随机中奖与最终获胜也不能替代中间三段。

### C-002变量假设

```text
明确确认给追责程序补入对象、责任、期限与节点
→程序持续处理偏差并扩大临界
→公开权能撤销承载资格与保护边界
→残余承载通过实际接收、补给和冲击吸收阶段性降低风险
```

## 6. 通用母型索引

当前没有新锁定的UM通用母型。

历史UM-01至UM-03保留为待复核记录。母型锁定门槛：

```text
多次独立复现
+ 至少跨两个题材
+ 关键对子A级证据
+ 具体名词不同但被改变变量与链序一致
+ 排除视觉符号、身份专属、单次动作和结果解释
+ 指出失败版
```

C-001虽达到3次并跨题材，但暂不升级：仍需非奖励、非悬赏、非竞赛的制度准入案例，检验它是否只是“公开资格活动”题材模板。

## 7. 方法修正记录

1. 关系对子是“谁生谁、谁克谁、谁补谁”。
2. 戏剧具体积累以主要人物在具体阶段的行为为主体。
3. 具体名词位于行为两端，固定源端和目标端并做十元定位。
4. 多个对子合成动态链，不机械套主克、主补、主生顺序。
5. 稳定多次出现的抽象动态链才是母型。
6. 一次出现只能建立具体动态链或C候选链。
7. 同一续作延续同一资源、壳、目标和程序不算独立支持。
8. 不允许为了模板完整强行制造主克；无A级关系应明确记录为空。
9. 中奖、营销、曝光、淘汰与胜利是剧情节点，不自动等于生克补。
