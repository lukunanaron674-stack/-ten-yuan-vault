## 4. 最新具体动态图｜《美国队长》盾牌

```text
Howard Stark研发、原型展示与交付程序 xn研
                   │ 前置/允许条件
                   ↓
Steve对圆形振金盾牌战斗用途的实际掌握 x盾
                   │ 生
                   ↓
Captain America盾牌身份壳 x并z盾
                   │ 生（与制服、称谓、战绩并行）
                   ↓
跨主体对Steve公共作战身份的确认 z史

同一载体并行保留：
x盾 ═════持续存在═════╗
                      ╠═ 盾牌同时承担资源与身份壳
x并z盾 ══新增并增强══╝
```

压缩：

```text
主链：x盾生x并z盾 → x并z盾生z史
前置条件：xn研提供原型、选择与交付接口
支路：既有制服与称谓壳并行生z史
汇合：z史
位置迁移：无
位置叠加：x盾+x并z盾并存
主克/主补/搭桥/反馈/断裂：无
```

关键结论：同一物理载体出现新的十元功能，不等于旧位置迁移。盾牌成为身份壳后，防御、格挡、投掷和回收等`x`变量仍持续运行，因此本案只能判为多位置叠加。

## 6. R-REV-01｜稳定位置真反转不可能引理

固定位置表不存在`A生B`且`B克A`。表面反转至少涉及位置迁移、对象替换、变量替换、接口断裂、物理终止或至少一边未达正式资格。

## 7. R-MIG-01｜同载体多位置叠加不等于迁移

```text
对象连续
+ 新位置变量新增
+ 旧位置变量持续运行
= 多位置叠加，不是迁移
```

严格位置迁移最低门槛：

1. 同一具体对象连续；
2. 迁移前后z切分焦点和x现象集合分别成立；
3. 旧位置核心变量显著下降、退出或不再主导；
4. 新位置核心变量成为实际运行中心；
5. 迁移前后关系边分别通过拿掉与反向测试。

## 8. 方法修正

1. 节点是具体名词+十元位置；行为是启动器；生克补是边。
2. 动态链必须保存真实链序与拓扑。
3. 串联、并行、汇合、反馈、搭桥、延伸、反转、转位、迁移、叠加与断裂分账。
4. 同一字母不自动代表同一对象；同一对象也可能同时落在多个十元位置。
5. 对象连续和先后变化不足以证明迁移。
6. 首遍屏蔽母型；母型仅后验比较。
7. 制造、训练、控制、失控、攻击和死亡不得直接写成关系。

