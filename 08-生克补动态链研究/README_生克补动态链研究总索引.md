## 4. 最新具体动态图｜《房间》生活承载与囚禁临界

```text
Old Nick绑架、门锁、监控、供给控制与暴力程序 xn囚禁
                         │ 生
                         ▼
不可离开、外界不可达与逃脱失败临界 xz_B

Room生活承载支路：
床、卫生、厨房、供暖、遮蔽与稳定活动区 n生活
        ├─生→ 睡眠、卫生、进食、教学、锻炼与照顾程序 xn生活
        └─克→ 暴露、失温、无睡眠卫生位置与立即崩塌临界 xz_A

逃脱支路：
门锁、Old Nick习惯、外部存在、Jack执行能力与卡车窗口确认 z
                         ─补→ 装病、卷毯、上车、跳车、求助与警方回溯程序 xn逃脱

执行换挡：
卡车移动、被发现风险与唯一跳车窗口 xz_C
                         ─生→ Jack跳车求助的临时决定 zx
```

关键结论：
- 同一Room的生活承载`n`与囚禁临界`xz`长期并存，改变不同变量，不是严格迁移。
- 高体量`n`不仅克局部暴露/生理崩塌临界，还可`生xn`形成跨年生活维持程序。
- 囚禁控制程序`xn_A`、生活维持程序`xn_B`、逃脱程序`xn_C`必须分账。
- 食物、药品、电视、玩具等为`x`资源，不并入`n`或补关系。

## 6. 承载边界补充

### R-MIG-09

```text
同一封闭对象真实提供内部位置并隔离/承担一组生活负荷 n
+ 同一对象或外部程序制造无出口、监控、耗氧、暴力或时间窗缩窄 xz
+ 两者改变不同变量
= n+xz多位置并存
≠ 纯承载
≠ 纯困陷
≠ 严格位置迁移
```

### R-MIG-10

```text
强制封闭空间具有高体量床、卫生、饮食、遮蔽与日常返回能力 n
+ n跨阶段反复承担同组生活负荷并生出持续维持程序 xn
+ 囚禁控制程序另行生出不可离开临界 xz
= 高体量生活承载与主导囚禁长期并存
```

## 7. 方法更新

1. 每个案例先分总体对象、局部对象、资源、程序、主体和外部接手对象。
2. `n`必须真实接收、提供内部位置、隔离危险、允许停留/返回，或反复承担同组生活负荷。
3. `n克xz`必须限定具体危险；生活承载不自动克不可离开临界。
4. `n生xn`必须证明承载结构使跨阶段程序可重复运行。
5. 相同字母的囚禁、生活和逃脱程序必须分账。
6. 最终获救、死亡或离场不能倒证中间关系。
7. 母型仅后验比较。
