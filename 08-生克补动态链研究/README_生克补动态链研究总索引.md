## 4. 本轮跨片新增结论

### 4.1 工具性承载与关系性承载分开

```text
军营住所、军饷、医疗、职位位置 = 工具性 n
村落住所、家庭位置、无任务照护、互保、共同劳动与反复返回 = 关系性 n
```

两者都能维持身体和生活，但前者主要被合同、职位和命令 `xn/x并z` 调用；后者更能为新的成员身份壳补入真实内部。

### 4.2 被俘、被照顾、学会文化与成为成员四分

```text
被俘且无法离开 = x/xn/xz 约束
获得住所、食物和医疗 = n 接收
学习语言、剑术、礼仪 = x/xn 学习
承担互保、准入、责任与返回 = 成员 n/x并z 候选
```

这些阶段不能合写成“被俘后逐渐成为武士”。

### 4.3 原则内化必须离开承载环境复测

奥尔格伦在村落中适应和感动，只能证明状态与关系变化。回到东京后仍在可退出、可获报酬的条件下拒绝继续训练镇压军，并主动营救胜元、返回承担，才提高 `zn` 内化纯度。

### 4.4 遗物是确认接口，不是政策发动机

胜元遗剑属于高显影 `x并z` 桥接壳；奥尔格伦的亲历叙述与政治事实属于 `xn` 证据组织；天皇接剑并重新判断才是 `z/zn/zx` 节点。遗物本身不能机械改变制度。

### 4.5 M-015 与 M-016 比较

| 维度 | M-015 阿凡达 | M-016 最后的武士 |
|---|---|---|
| 进入接口 | 另一具身体与神经接口 | 敌方军官职位与俘虏位置 |
| 地方接收 | 训练、住所、仪式、互保 | 过冬照护、家庭位置、语言、劳动、互保 |
| 旧制度关系 | 情报接口背叛后撤回殖民维护 | 离村后拒绝帝国军训/镇压维护 |
| 新身份显影 | 纳美身体、成员、魅影骑士 | 村落客人、武士参与者、盔甲 |
| 关键纯度测试 | 身体可用≠成员 | 学会文化/穿盔甲≠武士本体 |
| 结局 | 身体/承载/身份较强对齐 | 地方共同体殉灭，原则通过幸存者转交 |

二者共享上位结构“旧制度调用→地方承载→旧维护撤回”，但 M-015 的核心是身体借壳与身份对齐，M-016 的核心是俘虏承载、文化内化与失败后的原则转交，暂不合并。
