## 4. 最新具体动态图｜《角斗士》继承资格篡夺、奴隶团体承载与竞技身份壳

```text
Commodus公开继位/处决显权 zx
        ─克→ 罗马军政结构对Maximus的将军接收、保护、军团调用与合法返城接口 n_A

Proximo角斗士团体生活/训练承载 n_B
        ├─克→ Maximus无稳定位置、饥饿暴露与立即死亡临界 xz
        └─生→ 训练、编队、竞技、赴罗马与团队协作程序 xn_B

Maximus军事实战/竞技能力资源 x
        ─生→ “Spaniard/冠军角斗士/Maximus将军”公共身份壳 x并z
        ─生→ 民众、Commodus与政治主体的存活/能力/政治象征确认 z

敌方确认 z_enemy
        ─补→ Commodus加码竞技、监视、袭营、抓捕与预伤决斗程序 xn_A
        ─生→ Maximus逃亡路线、政治结盟与生存时间窗缩窄临界 xz
```

关键结论：
- `zx克n`只关闭Maximus的将军、军团调用、政治保护和合法返城接口，不判一般罗马人身份或军事能力本体消失。
- Proximo团体具有奴役控制，但仍真实提供住所、食物、同伴、训练场和队伍返回位置，因此可同时成立`n克xz`与`n生xn`。
- Maximus的军事实战/竞技能力`x`经反复公开战绩生成竞技身份壳`x并z`；Proximo营销、竞技制度和观众是第三因素。
- 同一公共身份壳分别生成公众确认、敌方确认和政治主体确认；确认主体不同，下游程序不同。
- 敌方确认`z`补入Commodus追捕程序的目标、优先级与阶段节点，随后`xn生xz`。
- Marcus的私人继承/过渡意向未形成稳定公开资格壳；Maximus死亡使旧政治承载没有对他完成重新开放。

## 6. R-MIG-17首例边界

```text
同一公共身份壳x并z
+ 公众确认z_public
+ 敌方确认z_enemy
+ 政治/制度确认z_political
+ 各确认主体获得不同对象、内容和下游程序
= 多主体异向确认分账

不等于：
身份壳天然保护主体
身份壳天然暴露主体
公众认可自动恢复正式资格
敌方识别本身就是克
```

《角斗士》中，竞技身份壳使公众确认Maximus的能力和象征位置，也使Commodus确认其存活与具体位置；后者补入追捕程序。公众确认产生的临时政治约束只登记结构结果，尚不硬判新的生克补关系。

## 7. 方法更新

1. 资格断裂必须限定层级：将军职务、军团调用、政治接收、一般公民身份和能力本体不得打包。
2. 奴役/强制组织可以同时包含生活承载`n`与控制/竞技程序`xn`；承载成立不代表制度正当。
3. 能力资源`x`生成公共身份壳`x并z`时，营销、制度、观众和重复展示必须作为第三因素分账。
4. 同一公共壳对不同确认主体产生不同`z`，每个`z`必须单独记录对象、内容和下游程序。
5. 敌方确认可以补追捕程序的明确目标、优先级和阶段节点；它不提供军力、武器或控制通道。
6. 私人继承意向没有公开条件、稳定见证与制度调用接口时，不构成资格壳。
7. 旧承载重新开放要求主体能被真实再次接收；死后尊崇、遗言执行或政治象征化不足。
8. 母型仅后验比较。
