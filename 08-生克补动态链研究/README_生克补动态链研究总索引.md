```text
    ──维持──▶
后续行动接口由自主未来方向组织
```

字母与关系：

```text
瑞德 nx（方向恢复） ──持续执行 / 阶段接管──▶ 前往芝华塔尼欧的行动链
外部制度路径 xn ──退出当前主导位──▶ 不再组织当前目的地与行动顺序
瑞德 nx（持续执行） ──维持──▶ 自主方向继续组织后续行动接口
```

直接生克补边：`none`。

## 本轮失败边

```text
nx ──克──▶ xn
失败：只证明xn退出当前主导位，未证明制度能力、存在资格或效力被削弱。

xn ──克──▶ nx
失败：当前没有制度压力直接降低瑞德的方向占用度。

nx ──生──▶ xn
失败：自主行动不能生成此前已经存在的制度结构。

交通工具 / 地理移动 ──生──▶ nx
失败：移动只是nx执行后的外显证据，不是方向端点生成源。
```
