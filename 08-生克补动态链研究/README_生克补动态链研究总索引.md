## 4. 本轮跨片新增结论

### 4.1 多人造界必须拆双源

```text
x 生 x并z：实际掌握设备、架构、药剂、对象信息与进入接口，生成可调用世界壳
n 生 xn：成员先承担跨层协作、保护、同步与回收负荷，再提炼信号、分工、时间节点与备用流程
```

世界壳被设计出来不等于共同体承载成立；团队同框、领袖下令或计划书也不等于 `n 生 xn`。

### 4.2 图腾首先是检测接口

私人图腾依靠主体掌握的物理细节检测当前状态，首先邻近 `x`。检测结果只有落到明确认可主体与确认内容时才可能参与 `z`；私人检测器不默认属于公共 `x并z`。结尾读数未闭合，不判现实已获得最终确认。

### 4.3 私人关系余温可寄居旧壳并污染公共任务

梅尔投影不是稳定 `nz` 本人，而是私人 `x并z` 记忆壳承载关系余温。只有当柯布停止把该壳当作仍有指导资格的关系对象，并在行为上拒绝继续留在其中，才支持局部旧壳覆盖下降。

## 5. 跨影片比较

| 维度 | 黑客帝国 | 盗梦空间 |
|---|---|---|
| 世界壳入口 | 机器掌握身体、神经与感知 | 团队掌握设备、架构、药剂与对象信息 |
| 主生 | `x 生 x并z` | `x 生 x并z`，并行任务 `n 生 xn` |
| 主克 | 程序 `xn 克 zx` | 多层时间、物理、投射与同步 `xn 克 zx` |
| 共同体作用 | 接住脱离后的现实身体 | 承担跨层协作、保护和回收负荷 |
| 检测接口 | 规则训练与感知重建 | 私人图腾，不自动成为 `z` |
| 最强误判 | 真相/训练=成长 | 团队同框=`n`；陀螺=现实证明 |

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把真相、训练、觉醒、吃药、复活和击败代理人直接写成生克补；
- 不把 `nx` 的多节点后果伪造为单一直接生关系；
- 不把个体脱钩外推成总体制度消失；
- 不把团队同框、计划书或领袖命令直接写成 `n 生 xn`；
- 不把检测动作、未完成读数或视觉悬置写成确认结果；
- 新案例必须反向修正中枢和母型。
