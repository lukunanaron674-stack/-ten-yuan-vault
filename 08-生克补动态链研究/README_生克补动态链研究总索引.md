## 4. 当前跨影片结论

### 4.1 同样是 `xn 克 zx`，后续可走两条不同路径

- 《千与千寻》：进入结构、获得带代价身份、掌握规则后退出；
- 《飞越疯人院》：外来者反复制造试验，制度强制回收，继承者形成局部意义撤回后退出。

因此开场关系相同，不代表动态链效果相同。决定差异的是：主角是否被结构纳入、是否形成稳定承载、高潮是规则通关还是强制回收。

### 4.2 正式克的体量必须分开

```text
执行者受伤 ≠ 制度整体被克
设施破损 ≠ 制度整体被克
个体逃离 ≠ 制度整体被克
成员停止自愿执行、维护或身份再生产 = 可构成低体量正式 zn 克 xn
```

《飞越疯人院》中，Chief 的退出支持局部覆盖下降；拉契特回岗、病房恢复运行则反证制度整体未被克。

### 4.3 补与生不得为了链条完整而硬填

《飞越疯人院》本轮保留主补、主生为空：麦克墨菲替患者直接做成很多事情，更多是试验场和代理权能；患者短时热闹也不足以证明成熟承载生成。

## 7. 研究纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把领袖替大家行动写成全员成长；
- 不把执行者受伤、设施破坏、通关或逃离写成制度整体被克；
- 每片最多先锁一条主链，其余作为支链；
- 新案例必须反向修正中枢和母型。
