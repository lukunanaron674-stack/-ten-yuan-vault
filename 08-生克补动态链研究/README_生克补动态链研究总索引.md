## 4. 最新具体动态图｜《肖申克的救赎》制度化承载与囚禁临界

```text
监狱判决、登记、门锁、点名、看守调度、惩罚与追捕程序 xn_A
                              │ 生
                              ▼
不可自由离开、暴力可达、禁闭与逃离失败临界 xz_B

制度内生活承载支路：
牢房、食堂、医务、院落、图书馆与固定岗位 n
        ├─生→ 睡眠、进食、治疗、劳动、借阅、教学与群体日常程序 xn_B/C
        └─克→ 露宿、饥饿、无治疗、无内部位置与立即身体崩塌临界 xz_A

图书馆支路：
经费、馆藏、学习需求、参与者与考试节点确认 z
        ─补→ 写信、筹款、整理、借阅、识字教育与考试程序 xn_C

Brooks断裂支路：
狱内稳定作息、群体关系与图书馆角色 n_Brooks
        ║ 假释后原承载关系退出；外部新承载不足
        ▼
外部孤立、无熟悉返回位置与生活失配临界 xz_D
        （断裂/缺失结构，不登记“自由生xz”）
```

关键结论：
- Shawshank的高体量生活承载`n`与监狱程序形成的不可离开/惩罚临界`xz`长期并存，改变不同变量，不是严格迁移。
- `n`可生出跨年生活、劳动、借阅和教育程序`xn`，但不克不可离开、禁闭或看守暴力临界。
- 图书馆程序同时依赖`n`运行位置、`z`对象/节点确认和`x`材料，必须分账。
- Brooks假释支路说明原承载退出与外部新承载缺失，不等于“自由生危险”。

## 6. 承载边界补充

### R-MIG-09

```text
同一封闭对象/强制机构真实提供内部位置并隔离或承担一组生活负荷 n
+ 同一对象或制度程序制造无出口、监控、耗氧、暴力、惩罚或时间窗缩窄 xz
+ 两者改变不同变量
= n+xz多位置并存
≠ 纯承载
≠ 纯困陷
≠ 严格位置迁移
```

### R-MIG-10

```text
强制封闭空间或机构具有高体量床、卫生、饮食、医疗、学习与日常返回能力 n
+ n跨阶段反复承担同组生活负荷并生出持续维持/教育程序 xn
+ 囚禁/管理程序另行生出不可离开或惩罚临界 xz
= 高体量生活承载与主导囚禁长期并存
```

### R-MIG-11

```text
主体长期依赖制度内稳定位置、角色、作息与关系通道 n
+ 离场后原承载关系真实退出
+ 外部没有建立等量可返回位置、角色与关系承载
+ 漂流/失配临界上升
= 承载退出与新承载缺失的断裂结构
≠ 自由/假释直接生危险
```

## 7. 方法更新

1. 每个案例先分总体对象、局部对象、资源、程序、主体和外部接手对象。
2. `n`必须真实接收、提供内部位置、隔离危险、允许停留/返回，或反复承担同组生活负荷。
3. `n克xz`必须限定具体危险；生活承载不自动克不可离开、惩罚或暴力临界。
4. `n生xn`必须证明承载结构使跨阶段程序可重复运行。
5. 相同字母的控制、生活、教育和逃脱程序必须分账。
6. “制度化”必须拆为具体位置、角色、作息和关系通道，不能直接当端点。
7. 最终获救、死亡、假释或离场不能倒证中间关系。
8. 母型仅后验比较。
