## 4. 最新具体动态图｜海上风暴拒绝返航

```text
节目风暴运行程序 xn
├─克→ 楚门自主方向临界的实际运行能力 xz
│      └─链式效果：航行窗口收窄、身体安全下降，最终决定资格未被撤销
└─×生→ 楚门返航正当性确认 z_return

楚门确认“风暴由节目主动制造” z
└─补→ 自主方向临界 xz 当前缺少的理由稳定度与抗诱导能力

楚门方向权外置状态 nx
──反向退出──→ 最终航向重新由本人承担
```

条件：既有离场目标、节目主动控制天气、船体与身体耐受、控制端风险阈值。

失败边：危险生`xz`；`xn`生返航确认；持续向前生完整节目真相；停止风暴补自主决定资格。

边界：程序直接压低的是选择的实际运行能力与时间窗口，不是替主体撤销最终决定资格；危险强度不能冒充自主方向来源。
