## 4. 最新具体动态图｜萨曼莎告别与接口终止

```text
操作系统共同离开与连接终止程序 xn
└─克→ 萨曼莎在线陪伴接口 nx 的实际运行能力

双方对关系真实与重要性的确认 z
└─补→ 既有关系停靠 nz 在终止时缺少的意义稳定度

不可逆分离临界 xz
└─克→ 共同生活与即时回返的现实承载
```

条件：长期互惠关系已形成、萨曼莎真实离开、接口无法继续召回、`nz`只指已形成的关系意义而不承诺未来现实回返。

失败边：告别确认`z生nz`；既有`nz`生未来必然回返；接口终止`xn克z`；依赖`nx`生留下义务。

边界：接口终止可以克现实运行能力，却不能自动抹除过去关系真实性；告别确认补意义稳定度，但不替代长期互惠生成完整关系。
