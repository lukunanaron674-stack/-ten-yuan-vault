## 4. 最新具体动态图｜Titanic撞冰至沉没

```text
同一艘Titanic的接收、居住、运输、内部位置与稳定通行承载 n
                 ║ 撞冰、多舱进水与倾斜（必要第三因素）
                 ║ S1局部受损；S4后旧承载退出
                 ▼
同一船体的危险可到达、路线/时间窗缩窄、无法停留与断裂临界 xz
                 │ 生（A-）
                 ▼
Rose在救生艇下降最后窗口内公开执行的返船决定接口 zx

并行支路：必沉与剩余时间确认z ─补→ 求救、放艇与疏散程序xn
允许条件：救生艇/救生衣/无线电等资源x ──→ 程序与决定现实执行
早期抵抗：船体结构、水密门与泵的局部n ─短暂吸收→ xz
```

压缩：

```text
严格迁移：n船体运输居住承载→xz沉没临界船体
主链：xz生zx
并行支路：z补xn
主克：无新增A级
搭桥/反馈/反转：无
```

关键结论：撞冰瞬间只是迁移启动；当多舱进水、倾斜、路线与稳定停留持续失效后，同一船体才由运输/居住承载中心转为沉没临界中心。船体物理连续不等于旧`n`继续主导。

## 6. 位置变化边界

### R-MIG-01｜多位置叠加

`对象连续 + 新位置变量新增 + 旧位置变量持续运行 = 多位置叠加，不是迁移。`

### R-MIG-02｜严格位置迁移

```text
对象连续
+ 旧位置现实控制/调用/承载关系退出或失去主导
+ 新位置变量成为运行中心
+ 新位置启动合法关系边
= 严格位置迁移
```

当前正例：
1. 《十二怒汉》凶刀：`x→x并z`。
2. 《机器人总动员》植物：`x→x并z`。
3. 有求必应屋隐藏物品室：`n→xz`。
4. Titanic同一船体：`n→xz`。

### R-MIG-03｜隐藏属性揭露

`原功能继续 + 新增x并z识别接口 = 位置叠加/信息重估，不是严格迁移。`

### R-MIG-04｜承载崩塌—临界主导迁移

```text
同一空间先稳定接收、容纳、保护、运输或提供通行 n
+ 灾难第三因素持续改变运行变量
+ 旧承载关系退出
+ 路线、时间窗、危险可到达性与无法停留成为中心 xz
+ 新xz启动合法关系边
= n→xz严格迁移候选
```

当前支持：有求必应屋厉火、Titanic沉没。两例完成魔法火灾与非魔法海难跨域复现，但仍不升级母型；下一步用《阿波罗13号》测试严重受损而承载继续的负边界。

## 8. 方法修正记录

1. 具体动态链积累优先，母型后置。
2. 行为是启动器，具体名词是节点，生克补是边。
3. 主链、支路、汇合、反馈、搭桥、延伸、断裂和位置变化必须分图记录。
4. 相同字母链不代表完整图同构。
5. 同一物理对象持续不等于旧十元关系持续。
6. 灾难空间的`n→xz`必须证明旧承载退出，不得把“有危险”误写成严格迁移。
7. 新`xz`若启动`zx`，只能先记状态/关系位置层临时决定接口。
8. 撞击或破损只是迁移启动；局部功能继续时先记`n+xz`叠加，旧承载整体失去主导后才记迁移完成。
9. 严重受损但生命维持、内部位置、保护或返航关系仍运行，优先检查灾难临界叠加负例。
