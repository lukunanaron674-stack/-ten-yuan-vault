## 4. 最新具体动态图｜离场不回头、关系保留与路径约束

```text
白龙外置离场方向 nx
→ 明确路径与“不回头”规则 xn 补 方向执行接口 nx
→ 千寻持续前进并穿过隧道
→ 现实家庭与道路承载 n 接住回返结果
→ 与白龙及异界对象的关系位置 nz 以记忆形式维持，而非即时互动
```

直接边：明确离场路径与“不回头”规则`xn`补方向`nx`所缺可执行接口。

条件：现实家庭与道路承载`n`接住回返结果，但不生成或恢复对象关系。

失败边：遵守规则`xn`不生或维系对象关系`nz`；现实回返`n`不克对象关系`nz`；关系记忆`nz`不保证未来重逢或持续互动。

边界：规则改变执行方式，不等于关系奖励；现实承载改变场景，不等于关系被抹除；记忆保留不等于互动接口仍开放。
