# 生克补动态链研究总索引

## 1. 目录职责

- `每次任务必读_生克补动态链滚动中枢.md`：强制启动、红线与真实断点；
- `影片动态链分析模板.md`：人物/团队行为、具体名词对子与动态链统一格式；
- `影片案例/`：影片与明确片段的具体积累；
- `现实案例/`：现实或历史案例的具体积累；
- `生克补动态链每小时运行记录.md`：唯一活动账本；
- 本文件：案例登记、候选链累计和通用母型状态。

每轮先读`01-十元系统/001-概念的定义.md`，完成`z切分焦点+x现象集合+十元位置+本体/状态+体量`锚定。

## 2. 研究层级

```text
关系对子：谁生谁、谁克谁、谁补谁。
具体积累：人物/团队与阶段 + 行为 + 两端具体名词与十元位置 + 为什么成立 + 被改变变量。
动态链：多个具体关系对子按真实阶段连续启动。
通用母型：同一抽象对子链在多个独立、跨题材案例中稳定复现。
```

行为是案例主体；具体名词挂在行为两端。M-001A至M-032均为`legacy-case-chain`。

### 青霉素（1928—1944）

```text
纯化青霉素、提取方法、动物与临床数据掌握x
→生1940动物实验论文、1941临床报告和可复核方法壳x并z
→成果壳x并z生对治疗价值与规模化资格的跨机构确认z
→关键确认z补菌株筛选、发酵优化、企业生产、纯化、试验与供应程序xn
```

并行证据支路：`xn补z`。实验与临床验证程序提供跨时间证据；正式成果壳提供识别、归因和跨机构调用接口。

现实失败版：Fleming的1929论文壳真实存在，但稳定纯化、体内/临床证据和生产可行性不足，关键确认与规模化程序长期未启动。

## 6. 通用母型索引

### UM-004｜资源/能力/成果正式化—目标/资格确认—程序聚焦

```text
x生x并z → x并z生z → z补xn
```

状态：`locked-general-archetype`。

当前支持：6次，覆盖犯罪悬赏、儿童奇幻资格、历史航天职场、体育管理和现实医药科研工业。

变量同构：

```text
实际资源、能力、权限、模型、样品、技术或结果掌握
→获得正式可识别、可调用、可核验的壳
→壳使特定主体、资格、结果或技术获得明确归因确认
→确认给既有程序补入对象、材料标准、参与者、期限与阶段节点
```

严格成立条件：

1. `x`端必须是真实掌握，不是愿望、名声或结果标签。
2. `x并z`端必须形成可识别、可归因、可调用或可复核的正式壳，不能只是展示和曝光。
3. `z`必须写清确认主体、对象、内容与重要位置。
4. `z补xn`必须证明既有程序原有真实缺口，确认随后改变对象、标准、参与者或节点。
5. 科研领域中，`x并z生z`与`xn补z`必须分开；论文/报告提供正式接口，验证程序提供证据连续性。
6. 最终成功、获奖、销量、连胜、获救或产业规模不能倒证中间链段。

失败版：

```text
旧壳、旧确认、旧程序只继续运行，不重复累计
壳存在但关键确认不发生，x并z生z断裂
知晓、引用或口头认同存在，但程序对象、标准和节点不变，z补xn断裂
正式论文、专利或报告存在，但内部成果不足或无法复核，壳为空心
1929青霉素论文存在，但治疗确认与规模化程序长期未启动
```

锁定依据：多次独立复现、跨题材、关键对子A级、变量与链序同构、失败版明确，并完成非影片现实历史复测。

历史UM-01至UM-03仍按旧体系保留为待复核记录，不因UM-004锁定自动恢复。

## 7. 方法修正记录

1. 关系对子是“谁生谁、谁克谁、谁补谁”。
2. 具体积累以主要人物或团队在具体阶段的行为为主体。
3. 具体名词位于行为两端，固定端点并做十元定位。
4. 多个对子合成动态链，不机械套主克、主补、主生顺序。
5. 稳定多次出现的抽象动态链才是母型。
6. 不为模板完整强行制造主克。
7. 能力、职位、论文、专利、名单、认可与程序必须分层。
8. 失败版同样是母型证据，必须指出具体在哪一段断裂。
9. 通用母型锁定后，新案例仍须独立审计，不得自动套用。
