## 4. 本轮跨片新增结论

### 4.1 身体接口、身份壳与承载三分

```text
链接舱、阿凡达身体、神经接口 = x
阿凡达操作者、外来纳美身体、魅影骑士 = x并z
住所、成员关系、保护、互保、仪式与返回位置 = n
训练、采矿、情报、安保、准入与灵魂转移程序 = xn
```

身体能被操控，不等于对应共同体身份或成员内部已经成立。

### 4.2 学会文化不等于被接收

语言、骑乘、狩猎和知识属于能力与训练；只有跨阶段住所、关系、准入、互保、负荷承担与可返回位置出现，才提高地方承载迁移纯度。

### 4.3 身份桥接壳不等于领导完成

魅影骑士壳提高可识别、归因和号召速度，但必须与杰克承担背叛后果、重建准入和组织联盟分开；称号本身不生成稳定认可、`zn` 或新制度。

### 4.4 与《沙丘》的地方准入比较

| 维度 | 沙丘（2021） | 阿凡达（2009） |
|---|---|---|
| 进入接口 | 贵族外来者与预言角色壳 | 人造身体与操作者壳 |
| 地方承载 | 结尾仅最低准入 | 训练、住所、关系、仪式与互保较完整 |
| 旧制度关系 | 家族承载被摧毁后逃入地方共同体 | 企业雇员/情报接口主动撤回维护资格 |
| 身份结果 | 新身份与领导位置悬置 | 身体、成员承载与公开身份较强对齐 |
| 制度结果 | 尚未改变帝国制度 | 本地军事接口退出，殖民制度整体未证 |
