## 4. 本轮跨片新增结论

### 4.1 语言对象、预测材料、公开界面、组织结构与确认必须拆开

```text
声画、字形、脑波、影像、设备、词表、数据库 = x
可稳定识别调用的语义界面或未来角色标签 = x并z
翻译、时间戳、授权、抓捕、冻结、司法和信息顺序 = xn
明确主体确认明确对象与内容 = z
制度执行真实关闭路线和时间窗 = xn生xz
即时解释与决定必须进入既有结构 = xn克zx
```

语言、预测、概率和未来画面长得再像神谕，也不会自动获得 `z/xz/zn` 资格。宇宙没有义务替理论偷懒。

### 4.2 《降临》与《少数派报告》的未来信息差异

| 维度 | 降临 | 少数派报告 |
|---|---|---|
| 未来接口 | 语言内化后读取跨时间信息 | 预知者身体与设备输出犯罪画面 |
| x并z | 可共享语义界面 | 未来凶手/受害者身份壳 |
| xn作用 | 翻译、隔离、外交与攻击倒计时 | 检索、授权、追捕、冻结与司法 |
| 主克 | `xn克zx`限制解释与沟通 | `xn克zx`提前取消否认与选择接口 |
| 主生 | `xn生xz`使战争窗口缩窄 | `xn生xz`使追捕与安全路线缩窄 |
| 原则结果 | 已知损失下原则保持 | 已知杀人画面下拒绝按预期路径完成 |
| 最强误判 | 预知女儿死亡=`xz克zn` | 预测画面=犯罪已完成/选择资格消失 |

### 4.3 结果吻合不等于因果解释正确

《少数派报告》中克罗死亡画面可以表面实现，但行动主体、主动性、动机与因果路径并不等同于机构原解释：

```text
结果图像
≠ 行为主体
≠ 动机
≠ 选择路径
≠ 制度确认正当性
```

### 4.4 主补的复核接口边界

《降临》和《少数派报告》都出现局部 `xn补z` 候选：跨时间信息或少数派报告为确认恢复可核验材料。但信息出现不自动算补，必须证明此前确认确实缺少复核接口，且材料进入组织后改变归因、回应或重判能力。

## 7. 纪律

- 概念先行；
- 单片不锁母型；
- 不把帮助都写成补；
- 不把阻碍都写成克；
- 不把先后都写成生；
- 不把真相、训练、觉醒、时间、命运、牺牲、预知、预测或视觉奇观直接写成生克补；
- 不把语言材料、预测材料、公开身份壳、组织流程与确认结果压成一个端点；
- 不把行动改变直接写成稳定本体或`zn`改变；
- 不把结果吻合直接当作主体、动机和因果路径解释正确；
- 不把团队执行既有协议写成`n生xn`；
- 不把个体脱钩外推成总体制度消失；
- 新案例必须反向修正中枢和母型。
