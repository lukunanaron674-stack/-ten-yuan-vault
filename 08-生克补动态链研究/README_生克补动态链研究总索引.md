## 4. 本轮跨片新增结论

### 4.1 M-031只复现前半

《生命的证据》同样出现证明存活、反复报价和价格收束，但交易窗口因Peter掌握敏感地图而关闭。价格确认没有继续通向交换释放，因此本片不能作为M-031完整第二正例。

### 4.2 谈判失效后必须更换确认对象

```text
前半：存活、价格、履约确认 z
→ 交易窗口关闭
→ 后半：营地位置、守卫状态、突袭窗口确认 z
```

旧谈判程序不能因为剧情要打枪，就自动升格成突袭程序。确认对象变了，证据链也必须重建。

### 4.3 爱情与专业责任必须分源

Terry返回同时受职业原则、私人吸引、个人选择和既有专业影响。爱情支线可以提高承担意愿和关系重量，却不能替代证明存活、情报核验、战术组织与现实接收。

### 4.4 新增M-032

M-032描述交换路径关闭后的换挡：谈判留下的人质信息与关系责任继续存在，但后续必须由新情报补足位置和执行确认，再由武装行动解除控制，最后完成撤离与家庭重接。
