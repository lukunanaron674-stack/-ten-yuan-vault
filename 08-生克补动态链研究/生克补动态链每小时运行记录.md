## 主关系

### 主生：`n 生 xn`

初期互认、协作、保护和共同任务形成真实承载负荷；为了持续处理负荷，群体提炼出称呼、纪律、手势、分工、传播和边界规则。

置信度：91%。与核心表已锁定机制一致，本片只作为动态链案例。

### 支链：`x 生 x并z → x并z 生 z`

群体先掌握空间、成员资格和传播行动，再形成名称、制服、标志和网站；公开壳随后提高成员识别、认可归因和外界识别。

### 主克：后段 `xn 克 zx`

结构已由成员跨场景复制后，Wenger 的一次终止命令无法取消其长期运行。改变的是即时决定有效性、结构复制率与成员自愿执行。

置信度：93%。核心关系已锁定，不新增理论表修改。

### 主补

未锁定。浪潮为 Tim 提供归属、身份、任务和可见位置，但混合 `n/x并z/z/xn`，无法纯化为单一补关系。

## 两种候选机制

### A. 权威直接生成服从

```text
教师 zx/xn
→ 学生服从
→ nx
```

否决：只能解释课堂入口，无法解释无教师在场时结构自我复制，也不是正式几何生关系。

### B. 共同体负荷转制度，再形成局部 nx

```text
n 承担归属与协作
→ n 生 xn
→ x 生 x并z → x并z 生 z
→ 默认路线、身份确认和退出成本共同上升
→ 成员局部 nx 扩张
```

结论：B 更稳。`nx` 是多节点关系位置后果，不新增 `zx/xn 直接生 nx`。

## 正例

1. Wenger 不在场时，成员仍统一穿衣、敬礼、传播标志并扩大成员边界，证明 `xn` 跨场景复制。
2. Wenger 决定终止后，成员没有立即恢复个人判断，证明新结构反向压低其即时 `zx`。
3. 球队与同伴关系先承担协作、保护和归属负荷，之后才出现规则、分工和边界，支持 `n 生 xn`。

## 反例

1. 第一堂课站立发言：可能只是课堂权威，未证明制度再生产。
2. 白衬衫合影：视觉同步和 `x并z` 显影，不证明稳定 `nx`。
3. 标志与网站：若无实际掌握，只是品牌设计，不足以判 `x 生 x并z`。
4. 群体欢呼：情绪感染，不等于跨压力承载与结构复制。

## 最近邻

- 领袖崇拜 `z`：不能解释无教师在场的规则复制；
- 教师 `zx` 主动接管：只能解释入口，不能解释结构反噬；
- 普通团队协作：保留否决与退出，不必统一身份和排斥外人；
- `x并z` 身份壳：提高识别与退出成本，但不等于内部 `n`；
- 情绪感染：解释同步速度，不能解释跨时间自我维护。

## 拿掉测试

1. 拿掉互认与协作，只留课堂命令，难形成跨场景 `xn`；
2. 拿掉制服、名称和标志，承载可能仍在，但识别、传播和退出成本下降；
3. 拿掉无监督执行证据，不能判制度再生产；
4. 拿掉排斥、处罚和边界，只剩共同活动，不能判方向资格下降；
5. 若 Wenger 一宣布结束，全体立即停止，则始终只是 `zx` 实验，不成立 `xn 克 zx`。
