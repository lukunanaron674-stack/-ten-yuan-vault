## 十元概念锚

- 病房日程、服药、集体治疗、投票门槛、记录与惩戒：持续运行 `xn`；
- 拉契特的最终处置、羞耻控制和医疗决定：高权重 `zx` 占位；
- 患者沿既有方向推进：局部 `nx` 状态/关系位置，不反推人格；
- 麦克墨菲直接争夺公共局面：`zx`；
- Chief 最终拒绝继续作为沉默对象：`zn`；
- 患者临时互助群体：`n` 候选，跨高压稳定性不足。

## 阶段节点与关系

### 主克

```text
xn 克 zx
```

病房持续结构压低患者未经许可的公开决定有效性。改变的是议程、投票、出入、娱乐和拒绝治疗的现实接口，不是笼统“勇气”。

置信度：84%，审计层稳定。

### 主补

未锁定。`zx 补 nx` 仅为候选：麦克墨菲替患者直接做成很多事情，制造试验与临时代理，但多数患者仍依赖他给方向，未稳定保留决定资格。

置信度：55%。

### 主生

未锁定。`zn 生 n` 仅为支链：共同尊严一度推出游戏、钓鱼、保护Billy和宴会，但临时共同体在强制反扑后迅速崩解，跨阶段留存不足。

置信度：58%。

### 高潮与结尾

Chief 停止替病房维护聋哑、沉默、被动留置的身份安排，形成低体量 `zn 克 xn`：结构对他的覆盖和自愿再生产下降。

但病房整体未被克：拉契特回岗、流程恢复、其他患者仍留在结构中，且麦克墨菲被叶切术处置。

```text
执行者受伤 ≠ 制度被克
设施破损 ≠ 制度被克
个体逃离 ≠ 制度整体被克
成员撤回自愿执行/维护/身份再生产 = 可构成低体量正式克
```

Chief局部 `zn 克 xn`：88%。
结尾非制度整体克：96%。

## 正例

1. Chief 从长期沉默到开口、准备逃离并最终破窗，制度不再能完整定义和调用他。
2. Billy 与Candy相处后短时不再口吃并拒绝羞耻，说明规则覆盖短时下降；但母亲威胁后迅速崩解，只算局部状态证据。

## 反例

1. 麦克墨菲掐拉契特：暴力与 `zx` 冲突，不等于 `zn 克 xn`。
2. 举起水台、破坏玻璃：设施动作不等于制度运行变量下降。
3. 钓鱼成功：一次组织行动不证明患者稳定自主。
4. 宴会热闹：短时共同快乐不等于成熟 `n`。

## 最近邻

- `zx` 夺权：直接击败执行者，不等于撤回制度正当性；
- `x` 设施掌握/破坏：不等于跨时间运行下降；
- `xz` 逃离紧迫：可解释最后窗口，不能解释自愿维护为何下降；
- 技能显影：Chief 原有力量出现，不等于 `zn 生 x`。

## 拿掉测试

1. 拿掉病房持续流程，只剩讨厌护士，主克退化为人物冲突；
2. 拿掉麦克墨菲，Chief同阶段退出不确定，说明其是关键允许条件，但不自动是补；
3. 拿掉Chief内部判断，只保留体力和机会，逃跑不能证明 `zn 克 xn`；
4. 拿掉拉契特受伤，制度仍能处置麦克墨菲，执行者受损非必要条件；
5. 拿掉视觉爆发，只看自愿服从和身份延续，局部克仍成立。

## 反向测试

制度加码强制并不反证局部 `zn 克 xn`；当成员已撤回自愿维护，结构往往只能依赖外力。若Chief仅趁疏忽逃跑、仍接受病房定义自己，则只是机会性退出。

## 动态链与感觉走向

```text
xn制度限位
→ 外来zx制造反规则试验
→ 群体短时借到行动接口
→ 制度以zx强制回收并破坏临时n
→ Chief把示范转成自己的zn
→ 局部zn克xn并个体退出
→ 制度整体恢复，局部覆盖永久丢失
```

感觉：窒息 → 热闹与可能性 → 短暂共同体 → 残酷回收 → 个体继承 → 苦涩释放。

## 本轮理论贡献

1. 正式克不只分“成立/不成立”，还必须标体量；
2. 低体量 `zn 克 xn` 可发生在单一成员覆盖、自愿执行与身份再生产下降；
3. 制度整体克需要跨成员覆盖、内部修复或复制率持续下降；
4. 主补和主生允许留空，不为链条整齐硬填；
5. 新建母型 M-002：制度回收—个体继承退出。
