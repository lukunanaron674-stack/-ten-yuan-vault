## 4. 直接关系与失败边

```text
Aaron人格呈现入口掌握 x
→ 生 分裂人格减责壳 x并z

分裂人格减责壳 x并z
→ 生 Vail个人错误确认 z_wrong_Vail
→ 生 法院精神失常减责确认 z_wrong_court

法院精神失常减责确认 z_wrong_court
→ 补 司法减责处置程序 xn
```

严格失败边：

```text
Aaron人格呈现入口掌握 x
─×→ 法院完整刑责正确确认 z_right
```

失败理由：Aaron只控制自身呈现材料，没有控制检方证据、专家反鉴别、法官审查、作案证据与后续矛盾等全部必要确认入口。正确改判是：

```text
x生x并z → x并z生z_wrong → z_wrong补xn
```
