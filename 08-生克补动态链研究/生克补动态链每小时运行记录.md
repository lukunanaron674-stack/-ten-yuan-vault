## 主克：`xn 克 zx`

```text
基因身份被嵌入招聘、门禁、日检与任务分配
→ 主体实际能力必须先通过身份筛选
→ 尚未公开行动，申请、解释与决定已经被概率壳过滤
→ `zx`的现实有效性与可进入范围持续下降
```

- 被改变变量：申请有效性、能力被读取概率、进入资格、公开解释权、任务选择空间；
- 成立阶段：从出生分类到职业与日常检测的跨阶段持续运行；
- 拿掉测试：拿掉招聘、日检、门禁和档案调用，只保留基因知识，主体不会持续失去进入接口；
- 反向测试：文森特穿过局部接口，不能自动取消制度的长期机会分配；
- 不是普通阻碍：被改变的是决定是否有资格进入现实；
- 置信度：98%。

## 主补：局部 `n 补 x并z` 候选

```text
双方从样本交易进入真实共同承载
→ 跨阶段承担样本、身体、秘密、暴露、失败与生活负荷
→ 借来的公开壳获得可持续运行的内部
→ 局部 n 补 x并z
```

限制：初期样本交易只是`x`资源供应；自动样本库可以替代部分物质功能，因此关系`n`并非唯一来源。不能写成“友情补回勇气”。置信度87%，不锁。

## 主生：局部 `x 生 x并z`

```text
生物样本、姓名、档案和检测接口被持续掌握
→ 以稳定身份被机构识别调用
→ “杰罗姆·莫罗”壳被文森特长期借用
→ 身份壳可调用性上升
```

这是正式`x生x并z`的局部借壳调用变体，不是从零创造身份，也不是本体替换。置信度93%。

## 正例

1. 文森特能力尚未进入实际考察，基因身份已关闭大量职业入口，支持`xn克zx`。
2. 杰罗姆长期提供样本并承担秘密与暴露，较一次帮助更接近局部`n补x并z`。
3. 文森特掌握样本与档案后持续通过检测，支持局部`x生x并z`壳调用变体。

## 反例

1. 训练身体提高能力，不自动是生或补。
2. 安东游泳失败不证明身份壳被克。
3. 睫毛被发现只是接口暴露，不等于制度确认已经完成。
4. 文森特登船不等于基因制度整体被克。
5. 杰罗姆自焚不自动证明补、`zn生n`或关系成熟。
6. 拉马一次放行不等于制度整体停止维护。

## 最近邻

- 医疗风险提示保留选择与异议接口，不等于高体量`xn克zx`；
- `x并z`负责公开读取，不等于制度如何分配机会；
- `z`确认不等于确认正确；
- 一次样本资源属于`x`，不足以构成`n`；
- `xn生xz`只在命案调查后成为后段临界；
- 文森特借用身份，不等于在本体上成为杰罗姆。

## 整体拿掉测试

1. 拿掉招聘、日检、门禁和任务分配，保留偏见，主克体量显著下降。
2. 拿掉杰罗姆，只留一次伪造证件，身份壳无法跨长期检测维持。
3. 拿掉样本、档案和检测接口，只保留努力，公开壳无法成立。
4. 拿掉命案，主克仍完整存在，说明追捕不是全片核心。
5. 拿掉视觉和台词，只看招聘、门禁、任务与放行，链仍成立。
6. 换成算法信用、教育分流、保险评级或招聘筛选，母型仍可迁移。

## 反向测试

若主张文森特`zx`克制度`xn`，必须看到成员大规模撤回执行、机会规则改变、身份壳不再稳定调用和制度复制下降。影片没有提供这些结果。结局是个体穿透分类，而不是总体制度被克。

## 动态链

```text
生物材料与概率被掌握
→ x生x并z，基因等级和职业身份壳形成
→ x并z生z，家庭与机构提前确认谁适合什么
→ 高体量xn长期分配教育、职业、门禁和任务
→ xn克zx，能力尚未进入现实，决定资格已被身份过滤
→ 文森特借用并维护杰罗姆身份壳
→ 交易逐渐成为共同承载，局部n补x并z候选出现
→ 命案调查形成后段局部xn生xz
→ 拉马在最后执行节点撤回检查
→ 文森特进入任务，但制度没有被整体克制
```

感觉：出生先验→安静排除→精密伪装→冷感运行→关系增厚→暴露临界→单点放行→个体穿透。
