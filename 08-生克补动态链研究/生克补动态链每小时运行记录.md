## 阶段节点与主关系

### 主克

```text
xn 克 zx
```

学校持续结构压低学生未经许可的公开决定有效性。改变的是表达、社团、职业、演出和处分叙事中的最终决定接口，不是笼统“勇气”。

置信度：89%，审计层稳定。

### 主补

未锁定。基廷同时提供示范、知识、课堂安全、临场引导与关系支持，无法把单一缺口和单一补源分离。

本轮只判：

```text
基廷的 zx + 教学 xn/n
→ 打开非标准判断试验入口
```

它是关键允许条件，不直接判“补回自由、自信或灵魂”。

### 主生

全班层不锁定。托德个体 `zn 生 n` 仅支链候选：他先站桌，为其他学生建立可加入的公开共同位置，但群体跨阶段留存不足，只支持准入启动，不支持成熟 `n`。

候选置信度：78%。

### 高潮与结尾

托德在基廷被驱逐、没有收到指令、诺兰明确命令坐下且存在处分风险时先站桌，说明他不再以沉默替学校维护唯一解释，形成低体量 `zn 克 xn`。

但学校整体未被克：诺兰仍掌权，课程、纪律和处分结构继续运行；影片也没有提供学生跨轮次继续传递的长期证据。

## 两种候选机制

### 候选 A：示范只是允许条件

```text
基廷公开做出非标准判断
→ 学生看见另一种可能
→ 在其课堂与保护范围内暂时表达
```

后果：只改变可见性、机会与状态，不证明学生自己的 `zn`。

### 候选 B：示范经撤场检验转成内部意义

```text
示范者撤场
→ 外部安全方向要求回顺
→ 学生仍在新情境独立判断
→ 承担处分、孤立或损失
→ 局部 zn 成立并克制结构对其自愿再生产
```

后果：改变的是“我是否仍替结构复制唯一答案”，而不是机械生成勇气或能力。

## 正例

1. 托德课堂即兴说诗后，结尾在新情境中再次独立判断，形成跨场景迁移。
2. 基廷被带走后，托德面对诺兰命令和处分风险先站桌；结构对其沉默与自愿配合的覆盖下降。

## 反例

1. 学生在基廷课堂中模仿走路、站桌看教室：课堂练习和视觉显影，不证明稳定 `zn`。
2. 查理挑衅、恶作剧和公开冒险：更接近 `zx/xz`，不等于对制度正当性的稳定意义撤回。
3. 重建诗社：可能来自新鲜感、同伴感染与秘密刺激，不自动等于 `zn 生 n`。
4. 尼尔登台成功：能力与意义显影，不证明现实决定接口已取得。

## 最近邻排除

- `z` 认可：基廷肯定可能提高托德表达资格感，但无法拿掉教学与强引导，不能锁 `z 克 nx`；
- `zx 补 nx`：基廷打开行动接口，但是否稳定取回方向资格必须分人判断；
- `n` 承载：诗社提供临时停靠，却无法承受家庭和学校高压；
- `xz` 风险：处分与失去未来制造临界感，不能解释托德为何撤回沉默配合；
- 情绪感染：站桌同步不自动等于长期制度再生产下降。

## 拿掉测试

1. 拿掉学校 `xn`，只保留严父，影片退化为家庭冲突片；
2. 拿掉基廷，托德同阶段形成公开判断的概率显著下降，说明其是关键允许条件；
3. 拿掉基廷撤场后的独立选择，只保留课堂诗歌，无法证明内化；
4. 拿掉站桌视觉，只看拒绝沉默、承担处分并公开保留判断，局部 `zn 克 xn` 仍成立；
5. 拿掉其他学生跟随，托德个体克制仍成立，群体再生产下降体量则显著减弱。

## 反向测试

若托德只在基廷在场并期待时站桌，行为更接近认可追随或模仿；本片中基廷正被驱逐且没有发出指令，故支持独立内化。

若学生随后全部恢复沉默并继续复制学校唯一解释，则群体站桌只是短时状态。影片缺长期余波，因此不判学校整体 `xn` 被克。

## 动态链与感觉走向

```text
学校 xn 限位
→ 基廷 zx 打开非标准判断试验
→ 学生出现模仿、失败与内化分化
→ 尼尔因现实承载与最终接口不足而失败
→ 学校以 zx/xn 强制回收并统一叙事
→ 托德在示范者撤场后独立形成 zn
→ 低体量 zn 克 xn，局部自愿再生产下降
→ 学校整体仍在
```

感觉：庄严压抑 → 新鲜松动 → 青春共同体 → 路径分化 → 悲剧回收 → 局部继承 → 苦涩敬意。

## 本轮理论贡献

1. 新增“示范转内化”三项检验：示范者撤场、逆当前安全方向、承担现实后果；
2. 模仿姿势、口号和课堂同步不等于稳定 `zn`；
3. 群体一次同步行为只支持状态或局部覆盖下降，不证明制度整体再生产下降；
4. 尼尔的悲剧不是缺少 `zn`，而是现实承载和最终决定接口持续不足；
5. 新建 M-003：示范撤场—分化内化—局部拒绝再生产。
