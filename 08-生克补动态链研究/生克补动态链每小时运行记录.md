| 层级 | 判断 |
|---|---|
| 稳定本体 | 专业能力、船长职责和船员共同体早于劫持；危险不生成这些本体 |

| 行为功能 | 预警、隐藏、断电、抓捕、交涉、谈判、射击和医疗必须分账 |
| 光影 | 机舱黑暗、救生艇窄舱和医疗舱白光只作`xz/n`显影 |
| 场景 | 货轮→机舱→救生艇→军舰→医疗舱，容器与承载连续换挡 |
| 时间关系 | 内部反制先于人质分离；军方确认先于射击；接收晚于位置脱离 |
| 关系位置 | 船长承担成员接口，船员反制，海盗掌握人质，军方接管救援，医护接管身体 |
| 显影 | 抓捕、狙击、获救和哭泣不能互相替代 |
| 动态链 | 成熟共同体受袭→内部反制→保护性分离→人质容器→外部确认→医疗接收→状态卸载 |

## 4. 主克、主补、主生

### 主克：海盗武装与封闭路线 `zx/xz克n`

海盗实际掌握武器、通道、救生艇和人质，使成员可达性、通信、自由移动、补给、医疗、返回接口与保护连续性下降。拿掉武器和通道掌握，只保留谈判冲突，承载不会同强度崩解。置信度98%。

### 主补：军方监视、谈判与拖带 `xn补z`

持续观察、无线电、谈判、拖带和多岗位反馈补出人质位置、威胁状态与射击窗口。军舰和武器只是`x`；没有反馈闭环，射击接近不可复核赌博。置信度97%。

### 主生：船员真实负荷局部 `n生xn`

船员隐藏、维持机舱、断电、反制、抓捕、联系外部并恢复船体，持续真实负荷让既有防御程序被重组和强化。专业能力与货轮结构是允许条件。阶段性成立，置信度95%。

Phillips的成员责任`zn`在危险前已有基线，危险中主要显影和排序，不判新生。

## 6. 正例、反例、最近邻

正例：

1. 船员在机舱隐藏、断电并抓住Muse，证明成员共同体承担真实负荷并重组程序。
2. Bainbridge以监视、谈判和拖带补人质位置与执行窗口，随后狙击才现实生效。
3. Phillips获救后进入军舰和医疗舱，保护、检查、补给和情绪接收共同完成外部承载。

反例：

- 船长被带上救生艇不能单凭镜头写成“牺牲生共同体”；共同体此前已成立。
- 军舰出现不等于确认、执行和接收自动完成。
- 击毙三名海盗不等于全球海盗制度或海上安全制度被克。
- 哭泣和语言断裂不等于原则、身份或稳定人格崩解。
- 英雄壳与公众认可不能倒证船员反制、军方确认或成员责任来源。

最近邻：武器/军舰/救生艇`x`≠执行`zx`≠接收`n`；船长壳`x并z`≠成员原则`zn`≠航海能力；军方程序`xn`≠确认`z`≠射击`zx`；位置脱离≠医疗接收；创伤状态≠稳定本体变化。
