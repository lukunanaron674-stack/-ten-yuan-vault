## 主关系

### 主生：`x 生 x并z`

制作系统先实际掌握生活世界的对象、关系和接口，随后海景镇、婚姻、职业、邻里与商品世界才形成可跨时间调用的公开壳。

置信度：97%。与核心表已锁定机制一致，本片增加全域媒介世界案例。

### 支链：`x并z 生 z`

公开身份壳使所有演员持续确认楚门是丈夫、朋友、职员与普通居民，并把异常重新归因到壳内解释。

### 主克：高体量 `xn 克 zx`

日程、交通、新闻、天气、恐惧教育与演员调度持续吸收楚门的即时偏离，使单次决定无法直接变成现实路径。

置信度：96%。

### 高潮：`xz 生 zx`

风暴压缩安全路线和最后窗口后，楚门仍决定继续航行，制作系统必须围绕其最终决定作出反应。只判临时公开决定接口上升，不生成稳定领导本体。

### 结尾：局部 `zn 克 xn` + 身份壳失效 + 个体退出

楚门撤回自愿执行、默认路线与场内身份复制，使结构对他的覆盖下降；但影片未证明整个节目工业和媒介结构消失。

局部 `zn 克 xn` 置信度：88%。整体制度被克：不判。

### 主补

未锁定。Sylvia 同时提供真实信息、关系记忆、外部方向与身份壳反证；其他异常也能独立推动调查，无法纯化成单一补关系。

## 两种候选机制

### A. 真爱补回自由

```text
Sylvia/爱情
→ 楚门获得自由与勇气
→ 退出
```

否决：源端点、缺失变量与恢复机制均不清；混入信息更新、关系记忆、异常证据和楚门原有怀疑。

### B. 全域掌握与身份确认长期维持局部 nx，主体复合退出

```text
x 生 x并z → x并z 生 z
→ xn 反复吸收偏离
→ 局部 nx 被维持
→ 壳的反证与真实关系入口累积
→ 主体撤回自愿执行
→ xz 生 zx
→ 局部 zn 克 xn + 身份壳失效 + 个体退出
```

结论：B 更稳。退出不是一条“自由克制度”的单箭头。

## 最近邻

- Christof 的 `zx`：能解释最终权能，不能单独解释日常跨时间回收；
- 普通习惯：不能解释每次偏离为何都需多系统协同；
- `x 克 z`：节目控制认可接口，但主轴不是阻止某个重要认可者正确确认楚门，因此不列主链；
- 整体 `zn 克 xn`：只证明结构对楚门覆盖下降，不能外推节目工业整体；
- `n/nz` 补：真实关系有作用，但目标缺口与净恢复变量无法纯化。

## 拿掉与反向测试

1. 拿掉实际掌握 `x`，只留布景，身份壳无法跨时间稳定；
2. 拿掉所有关系的身份确认 `z`，楚门更早会把异常归为骗局；
3. 拿掉跨时间组织 `xn`，只留 Christof 的个人命令，无法吸收所有偏离；
4. 拿掉 Sylvia，其他异常仍可推动调查；拿掉异常，只留关系记忆，也不足以形成完整退出路径；
5. 若楚门出海后仍请求 Christof 给出新方向，`nx` 未下降；实际他拒绝最终解释并自行选择；
6. 若退出后节目对其他对象继续运行，则只是对象退出；本片未给出整体结构灭失证据。
