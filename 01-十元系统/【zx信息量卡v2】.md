# 【zx 信息量卡 v2.1】

> **zx 的本体是张扬醒目与权能扩大；目标执行是 zx 的标准行为。**

## 1. 核心本体

zx 不是“能执行任务的人”，而是主体的能力、位置、影响与权能不断显现并扩大。

```text
主体形成自己的方向
→ 主观能力作用于客观世界
→ 能力通过结果显现
→ 主体位置与权能扩大
→ 继续作用于更大的对象
```

### 最短定义

> **我不仅存在，我的力量还要在世界中显现、做成，并不断扩大。**

## 2. 本体、行为、结果分层

### 本体

```text
张扬醒目
+ 权能扩大
+ 主体位置与影响范围上升
```

### 行为

```text
目标执行
+ 路径推进
+ 换路不换方向
+ 把能力转化为实际结果
```

### 结果

```text
事情被做成
+ 能力被外部显现
+ 权能范围扩大
```

不得把行为层直接偷换为本体层：

- 有目标，不一定是 zx。
- 能执行，不一定是 zx。
- 只有当目标执行服务于主体权能的显现与扩大，才形成完整 zx。

## 3. zx 的完整回路

```text
张扬醒目与权能扩大（本体）
→ 目标执行与路径推进（行为）
→ 做成真实结果（结果）
→ 主体能力与位置显现（外显）
→ 权能继续扩大（本体回收）
```

## 4. 王权感

zx 的王权不是身份装饰，而是：

- 自己确定方向。
- 把意志转化成现实结果。
- 作用范围不断扩大。
- 自己成为越来越多事件的决定力量。

因此，权杖、王座、利剑、向上生长可以是 zx 的视觉血肉，但必须回到“主体权能是否扩大”。

## 5. 与 z 的区别

### z

```text
我的存在、能力、作品或发现
→ 是否被认可主体看见与确认
```

### zx

```text
我的能力能够做成什么
→ 这种能力如何显现
→ 我的实际作用范围如何扩大
```

最小差异：

> **z 关心认可是否成立；zx 关心权能是否做成并扩大。**

认可可以出现在 zx 中，但不是 zx 的唯一核心。

## 6. 与 x 的区别

### x

- 聚焦具体物象、物质、所有权与局部利益。
- 人物层容易自私、狭隘、冷静、逻辑清楚。

### zx

- 不只盯住一个具体物象，而是让主体力量不断进入世界并扩大作用范围。
- zx 会使用物质、规律和路径，但目的不是占有物本身，而是扩大主体权能。

## 7. 典型行为

- 目标执行。
- 建立路径。
- 遇阻换路。
- 将抽象意志转化为实际结果。
- 扩大控制范围、影响范围或决定能力。
- 用成果证明主体力量已经进入现实。

## 8. 典型人物锚

### 8.1 朱元璋：权能建构型 zx

> **朱元璋是用户确认的典型 zx 人物。**

```text
张扬醒目
+ 权能不断扩大
+ 目标执行作为标准行为
+ 把主体意志持续做成现实
= 权能建构型 zx
```

该锚点突出的是：主体位置从低处不断上升，实际决定范围不断扩大，最终成为更大范围中的决定力量。

### 8.2 孙悟空：极限意志型 zx

> **孙悟空也是用户确认的典型 zx 人物。**

用户锁定的核心体感：

```text
无限的
打不倒的
不倒翁
人类的极限意志
```

孙悟空的 zx 不只表现为“会战斗”或“永不服输”，而是：

```text
外界不断压制、击倒、封锁
→ 主体始终重新站起
→ 每次站起都重新把意志做成行动
→ 不接受外界对自己作最终定义
→ 主体权能持续显现
```

这里的“不倒翁”不是被动耐受，而是主动复起：

- 被打倒，不等于承认失败。
- 被压制，不等于接受外界定义。
- 路被封死，就再次行动、破局、显现。
- 意志必须重新进入现实，才算完成。

因此，孙悟空可以作为 zx 的另一条人物主轴：

```text
朱元璋：权能不断建构、扩大
孙悟空：权能不断复起、不可被最终击倒
```

两者共同证明：zx 的“权能扩大”不只表现为统治范围增加，也可以表现为主体意志在反复压制中仍无限复起。

具体版本、阶段与副元结构，后续另建人物血肉卡逐项验证，不凭印象把所有孙悟空版本混成一只猴子。人类改编已经够忙了，理论不必再添乱。

## 9. 误判防线

以下不能单独判 zx：

- 做事效率高。
- 有目标。
- 有计划。
- 很努力。
- 身份高。
- 穿王者服装。
- 站在画面中央。
- 喜欢指挥别人。
- 很能挨打。
- 单纯倔强或不认输。

必须检查：

```text
主体权能是否扩大或持续复起？
能力是否通过实际行动和结果显现？
目标执行是否在服务这种权能显现？
外界压制后，主体是否重新把意志做成现实？
```

## 10. 判断对象

- **人物本体 zx**：长期通过做成结果扩大自己的能力、位置与权能，或在反复压制中持续让主体意志复起。
- **人物状态 zx**：此刻处于权能上升、结果显现、强烈推进或重新站起的状态。
- **行为 zx**：目标执行、路径推进、换路、破局、复起、做成。
- **视觉 zx**：轴向、利剑、权杖、向上、中心显现、反弹复起，仅为辅助证据。
- **关系 zx**：主体通过结果成为更强的决定力量，或拒绝让外界拥有最终定义权。

## 11. 旧卡迁移

旧 v1 中“目标执行的结构力”不再作为 zx 的完整本体定义。

旧内容处理：

```text
目标执行 / 路径推进 / 换路不换目标
→ 保留为 zx 标准行为层

王权 / 向上生长 / 主体位置扩大 / 不可被最终击倒
→ 上移为 zx 本体层
```

旧人物案例全部需要检查：

- 是否只是能执行。
- 是否真正存在张扬醒目。
- 是否形成权能扩大或持续复起。
