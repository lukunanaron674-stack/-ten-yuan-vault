# 【z 信息量卡 v1】旧口径迁移入口

> 本文件原先把“执念、追光、被点燃、光爆点”作为 z 的核心主骨。
> 2026-07-16 起，该口径不再作为纯 z 的底层定义。

## 当前正式入口

- [[【z信息量卡v2】]]
- [[00-三元底层定义_醒耐z_v0.1]]

当前 z 主骨：

> **一个精神个体面对庞大的物质客观世界时，需要另一个精神个体看见、回应并认可自己的精神存在。**

## 旧材料如何处理

旧版中的以下材料不删除，但取消纯 z 锚点资格：

- 追光
- 执念
- 被点燃
- 光爆点
- 舞台中央
- 否定变体
- 停不下来
- 兑现感

它们统一降级为：

```text
z 外部血肉候选
+ 其他十元候选
+ 待人物本体 / 状态 / 行为 / 视觉 / 关系分层二审
```

## 二审必须追问

```text
1. 该案例需要谁的认可？
2. 这种认可是否来自另一个精神个体？
3. 被认可的是否是主体的精神存在？
4. 去掉见证关系后，案例是否仍完整成立？
5. 若仍成立，它是否其实来自目标、冲动、欲望、执行或视觉风格？
```

## 楚庄王弓迁移

“楚庄王弓 = z 有边界的执念”作废。

楚庄王弓正式用于解释：

- x 对具体弓与物质状态的关注。
- n 从楚国、人类、自然到空的区域扩大。

## 迁移原则

> **保留旧血肉，不保留旧主骨；保留案例，不继承未经复判的 z 标签。**
