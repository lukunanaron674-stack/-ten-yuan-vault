# 【z 信息量卡 v1】

---

## 1. 核心本体（主骨）

**主骨公式**
执念 + 被看见的冲动 + 光爆点——不是「目标坚定」，是「有一个东西在亮着，我必须追着它跑」。

**一句话解释**（不是「有毅力/有目标/坚持」，而是「被一个光点击中，停不下来」）
- ❌ 不是：有决心、不放弃、追逐梦想
- ✅ 是的：有一个东西在ta眼前亮着，ta被它吸住了——不是因为有终点，是因为光的吸引力比ta的意志力大

**确认过的关键表述**（2026-05-30 session yyy确认）：
> 「z不是追到那个东西，是被那个光推着走的过程——那道光本身就是全部。」

**两种形态（2026-06-06轴级补丁确认）**：
1. **标准z（追光）** — 正向执念：光点在前方，跑向它会带来能量
2. **否定变体z_neg（追暗）** — 逆向执念：光点在过去（一个不可逆的负面事实），回头追它不会抵达只会耗尽——z越强，能量累积越大，因为事实不可改变

**不要和以下混淆**：
- z ≠ 目标明确（那是zx——zx知道终点在哪，z不知道终点在哪，只知道光的方向）
- z ≠ 努力奋斗（努力是行为，不是灵魂——z是被点燃，不是选择努力）
- z ≠ 热情/激情（zn也有热情，但zn的热情是有意义的——z的热情不需要意义，只需要光）

## 2. 第一体感

> 不是「他很努力」，不是「他不放弃」。
> 而是「他被什么点亮了，整个人都在发光——他自己也控制不住」。

- ❌ 误：有热情、有理想、执着追求
- ✅ 正：有一个东西在他面前亮着，他整个人被吸过去。他不是在做选择，他是被电流击中了。

**体感关键词**：光、燃、爆点、冲、停不下来、被击中、聚光灯

## 3. 人物层

| 面向 | 描述 |
|:----|:-----|
| 核心性格 | 被点燃的人——有一个东西吸引着他全部的注意力，其他都不重要 |
| 角色类型 | 追光者 / 被选中者 / 燃系主角 / 舞台中央的人 / 不要命的那个人 |
| 灵魂问题 | 「那道光在那——我怎么可能不去追？」——不是「值不值得追」 |
| 标签陷阱 | ❌ 不是「热血主角」——热血是叙事风格，z是灵魂结构。许多热血主角不是z（如路飞是zx+n） |

**典型角色示意**：
- **樱木花道（灌篮高手）** — z纯净版+zn辅：「我是天才」——这句话不是自信（自信是性格），是樱木被篮球这个光点击中后的必然表达。他不是在说「我很厉害」，他是在说**「我被这个光点确认了存在」**。樱木的z纯净体现在：他对篮球的追逐不是「想赢」（那是zx），不是「想证明自己」（那是z被nz包裹），是「篮球的光在那里——我怎么可能不去追？」。他的每一次进步、每一次爆发——都是光在推动他，不是他在规划自己
- **藤野（蓦然回首）** — z主+n辅：藤野画漫画不是因为「漫画有意义」（zn），是因为「被认可」的光点在她面前亮着——同学夸她画得好、老师说她有天分，她就被照亮了。但当京本出现、京本画得比她好时——光点开始闪烁。藤野的z本质不是「喜欢画漫画」，是**「被需要的存在感」**——她的光点是「有人看我的漫画」、「有人需要我画的东西」。这是z的标准形态：光从外部来，被看到才有意义
- **阿甘（阿甘正传）** — z主+zn辅：阿甘一直在跑。不是因为想通了要跑步的意义，是因为珍妮这个光点击中了他。他跑进了橄榄球队、跑进了越战、跑遍了美国——每件事都是「被点亮后一直跑下去」的结果。珍妮是他的光，即使珍妮不在身边。最纯净的z。
- **竹本祐太（蜂蜜与四叶草）** — z主+xz辅：被花本叶久美的光芒击中后开始骑行穿越日本。他不知道终点在哪，只知道要往前跑——骑行本身的过程比结果重要。标准的追光z。
- **布鲁斯·韦恩（蝙蝠侠）** — z主+zn辅：父母在小巷被杀的那道光（黑暗中的枪火）击穿了他的童年。他不是选择成为蝙蝠侠的，是被那个「不能再有人被这样杀死」的光点击中后，再也停不下来。
- **碇真嗣（EVA）** — z_neg主+x辅：真嗣追的不是光，是「妈妈不该死/父亲不该这样对我」的否定事实。他的z是指向过去的——无法抵达，只能被不停消耗。z否定变体的代表性案例。

**反例·容易误标但实际不是z的**：
- 目标明确的执行者 → 不是z，是zx。zx知道终点在哪，z只知道方向。
- 热情乐观的人 → 热情可以是任何十元的情绪特征。z的核心是「被点燃后的不可停」，不是「开心/积极」。
- 坚持不放弃的人 → 坚持可以是n（承载）、zx（路径推进）、xn（规则遵守）。z的坚持是「被光吸过去的停不下来」，不是选择坚持。

## 4. 行为层

| 行为类型 | 具体表现 |
|:--------|:---------|
| 追逐 | 被光点吸引——向光的方向跑，不管路好不好走 |
| 爆发 | 能量集中释放——不是在积累，是在一瞬间全部烧掉 |
| 不甘心 | 停下时的状态不是「算了」，是「还没完」——眼睛还在看光的方向 |
| 被看见的渴望 | z需要观众——不是因为虚荣，是光需要被看到才有意义 |
| 锁定目标后的偏执 | z锁定目标后会无视其他一切——不是坚定，是别的都看不见了 |
| z的正反馈闭环 | z的驱动依赖于光点反馈。被认可→更有动力→更投入→被更多人认可→动力更强。这是樱木花道的能量循环——每次接球/扣篮/被观众欢呼，「我是天才」这个光点就再亮一次。正反馈闭环是标准z的引擎模式 |
| z的坍塌临界点 | 当光点消失（被否定/被打败/被更亮的光遮蔽），z的能量会瞬间坍塌。藤野在看到京本的画后——她的光点（我是画漫画的人）被遮蔽了。z不会渐进式消退，是瞬间暗掉。坍塌后的z有两种路径：找新光点（换一个赛道发光），或转入z_neg（光点变成不可逆的「我不够好」） |
| z的否定变体免疫机制（樱木版） | 樱木的z最特殊的一点：他的「我是天才」光点——无论外界如何否定（被甩50次、赤木骂他白痴、观众笑他门外汉），光点都不会熄灭。这不是zn（内部信念），这是z的一种特殊子型——**光点具有自发光属性**。不是外部否定进不来（那是zn），是被否定了但光还在。樱木说「天才是不需要解释的」——他不是在说信念，他是在说**「你们灭不掉我的光」**。这是标准z向z_neg转化的免疫机制——当z的光点具有自修复能力时，不会跌入否定变体 |

**行为特征对比**：vs 其他易混淆十元

| 场景 | z | zx |
|:----|:--|:---|
| 面对目标 | 朝着光跑——兴奋、燃烧、可能走弯路 | 沿着路径推进——冷静、结算、换路不换目标 |
| 遇到障碍 | 撞上去或绕过去——但光还在前面 | 换路不换终点——效率优先 |
| 完成后 | 看有没有被看到、被认可 | 结算，找下一件事 |

| 场景 | z | zn |
|:----|:--|:---|
| 为什么追 | 「因为那道光太亮了」 | 「因为这是对的事」 |
| 信念来源 | 被外界点燃 | 从内部生长 |

| 场景 | 标准z | 否定变体z_neg |
|:----|:-----|:--------------|
| 目标 | 未来的光——可以抵达 | 过去的暗——不可逆转 |
| 能量 | 追逐→获得能量→继续追 | 追逐→消耗能量→更用力追 |
| 结局 | 追到或改成别的 | 永远追不到，能量持续累积直到崩溃 |

## 5. 空间层

z成立的空间，都是**有光、有方向、有聚焦感**的：

| 空间类型 | 示例 |
|:--------|:-----|
| 舞台/聚光处 | 表演台、领奖台、战场中央——z站在光最亮的地方 |
| 追光通道 | 一条通向光的路——不是终点在那，是产生光的源头在那 |
| 爆点空间 | 烟花升起的地方、火焰燃烧的位置、光芒爆发的那一瞬 |
| 观看/被观看 | 窗、阳台、高台——不是高处（权力），是能看见光和被光看见的地方 |
| 竞赛空间 | 跑道、赛场、决赛现场——有终点的追逐（z的冲动被规则化） |

**关键规则**：z的空间必须有**方向性**——不是循环（xn），不是包裹（n），不是通过（xz）。z的空间是一个**光源和一条指向光源的线**——z站在线的起点看着光源。

- ✅ 甲板上的阳光（阿甘在船上被珍妮看到）
- ✅ 舞台上的追光（被看到的那一瞬）
- ✅ 小巷里父母的尸体（布鲁斯·韦恩的z被点燃的地方）
- ❌ 容纳多人的家庭空间（不是z的空间——那是n）
- ❌ 没有光源的迷宫（z会迷路——没有光就没有方向）

## 6. 视觉层

| 视觉要素 | 特征 |
|:--------|:-----|
| 色彩 | 亮/高饱和度——红/金/橙/白——不是冷色（xz），不是柔色（nz） |
| 光线 | 追光/聚光/光束/高光对比——z在光最亮的地方，背后常有光晕或阴影对比 |
| 构图 | 不对称但有力的三角形——z身体向光的方向倾斜，眼神聚焦在画外 |
| 形状 | 尖角/火焰状/爆发状的扩散——不是弧线（n），不是直线（zx） |
| 质感 | 光面/高反光/边缘发光——不是粗糙（n），不是锋利（xz） |
| 运动感 | 爆发/冲刺/起跑—z的运动是「启动——一股能量释放」的瞬间 |
| 天气 | 晴空/日出/霞光——不是雨（x），不是雾（xz），不是黄昏（nz） |
| 标志物 | 火/灯/光柱/奖杯/勋章/一个一直看向的方向 |

**视觉语言一句话**：z的视觉是「被点燃的爆发瞬间」——不是燃烧本身，是**刚被点燃、能量还没释放完**的那一秒。

**与zx的视觉差异**：zx是轴向构图——身体沿一条线推进，终点在前方。z是中心构图——z自己就在光芒的中心，光从他身上或面前发出。

**作品采肉·z视觉追加**：

**Merry-Go-Round（天气之子·RADWIMPS）——情感爆点视觉化**：

| 视觉素材 | z解释 |
|:--------|:------|
| 情感爆点视觉化 | Merry-Go-Round副歌段的音乐爆发可以转化为z的视觉语言：**一个瞬间被点燃的人——不是渐进燃烧，是一道光束从身体中央炸开的瞬间姿态。** z的视觉是爆发式的：画面中的角色在某一帧被光芒贯穿，身体在光中微微后仰（承受爆发的力），但不是倒下——是「被光击中后站得更直了」。这与Merry-Go-Round副歌中情感的累积释放形成了视觉-声音的跨通道对应：**前奏/主歌的积蓄（光的暗涌）→副歌的爆发（光在身体中炸开）→余韵的延续（光还在发亮但不再扩散）** |

## 7. 叙事层

z在故事中的常见叙事功能：

| 叙事功能 | 描述 |
|:--------|:-----|
| 引擎启动 | z角色最擅长的事——点燃故事的第一把火。「我要去找他！」是z的标准叙事启动 |
| 能量供给 | z角色的存在本身提供故事的能源——他们燃烧，读者也跟着燃烧 |
| 转折触发器 | z的冲动经常触发不可逆事件——不是因为z在策划，是因为z被光点燃后停不下来 |
| 情感高潮 | z角色达到巅峰状态的时刻就是故事的情感高潮——不是智商胜利（nx），不是规则胜利（xn），是「他做到了」 |
| 光的定位器 | z角色通过追逐行为定位了故事中最重要的东西——「他在追的那个东西」=故事的核心价值所在 |

**叙事节奏特征**：z的叙事是**脉冲式**——燃→爆→收→再燃→再爆→再收。每一个脉冲之间是积累能量的等待。z不能持久燃烧（那是zx），z是「亮一下→暗→再亮一下」。

## 8. 常见互补（对子关系）

| 互补对 | 含义 | 典型效果 |
|:-------|:-----|:---------|
| **z ↔ xn** | 执念 + 规则 | 时间型核心对子——xn的规则给z的冲动提供框架和截止日期。xn补z：规则压出精准爆点；z补xn：执念给规则赋予温度 |
| **z ↔ nz** | 执念 + 等待 | z的追逐方向由nz的等待决定——「我要回到等我的那个人身边」。z生nz：一个冲刺兑现一个停靠 |
| **z ↔ xz** | 执念 + 漂流 | xz生z：漂流到绝境的人会被光点击中。z的追逐让xz不再盲目漂流 |
| **z ↔ n** | 执念 + 承载 | n对z的回收机制——z的能量被n承载消化。但z否定变体时，n越强z能量累积越大（轴级制约规则） |
| **z ↔ x（克）** | 执念 + 吞噬 | x克z：追光者的光被深渊一口吞掉。z面对x几乎没有抵抗能力——小王子掉进玫瑰园的现代版本 |

**对应五大主题**：z是时间型（xn+z）的核心符号之一——冲动与规则的时间拉锯。

**特别·z否定变体的特殊关系**：
- z_neg ↔ n：n越强，z_neg能量累积越大——n成了否定事实的能量蓄水池
- z_neg ↔ x：z_neg比标准z更容易被x捕获——因为无法抵达目标的不甘和愤怒是x的天然养分
- z_neg ↔ zx：z_neg可能转化成zx——如果否定事实被重新定义为可执行的目标（「我要阻止下一个凤的死亡」）

## 9. 常见污染（被其他十元侵蚀变味）

| 污染形态 | 变成什么 | 判断方法 |
|:---------|:---------|:---------|
| **z被x污染** | 从追光变贪婪 | 追逐开始带有占有欲——「我要得到那个东西」变成「我要拥有它」 |
| **z被zx污染** | 从追光变路径执行 | 热情变成了计划——追逐不再是本能燃烧，变成有步骤的推进 |
| **z被z_neg锁定** | 正向追光变成逆向追暗 | 光点变成不可逆的负面事实——能见累积但不能抵达（轴级补丁核心定义） |
| **z被n污染** | 从追逐变承接 | 不再主动追光——变成等光落下来就接着 |
| **z被nz污染** | 从冲劲变柔情 | 追逐软化为等待——不是不想跑，是不舍得离开等的人 |

**反向污染**：其他十元被z侵蚀
- **zx被z污染** — 路径推进变成了表演式执行——开始在意被看见
- **xz被z污染** — 临界漂流变成了有方向的追逐——漂流者被光捕获，临界感消失
- **nz被z污染** — 等待变成焦虑的徘徊——不再安静等，开始主动找

## 10. 禁止误判（核心防线）

| ❌ 误判 | ❌ 误判原因 | ✅ 正确归属 |
|:-------|:-----------|:-----------|
| 「他有目标/方向」→ z | 有目标是zx的特征——zx知道终点在哪，z只知道光的来源 | 先问：他知道终点长什么样吗？zx看到终点，z看到光 |
| 「他很努力/很拼」→ z | 努力是行为描述，不是灵魂结构。努力可以是zx的路径推进，n的承载，xn的遵守 | 区分努力的结构：是「因为停不下来」还是「因为必须如此」 |
| 「他热情/开朗」→ z | 热情是情绪，不是十元。zn（意义驱动）和n（承载）也可以热情 | z的热情是「被点燃的亮」，不是性格上的开朗 |
| 「热血主角」→ z | 绝大多数热血主角是zx+n或zn+n的组合，不是纯z | 路飞是zx+n（目标执行→保护同伴），鸣人是zn+z（被认可的信念+被光击中） |
| 「坚持到底」→ z | z不一定坚持到底——z在目标变化时可能换成新的光。坚持更接近n或zx | n的坚持——「接了就不放」；zx的坚持——「路径不变终点不变」 |
| 「追光者就是z」→ 默认 | xz被光捕获也可以追光，但那是xz的临界行动被z引导，不是z本身 | 区分：是本来就在追，还是本来在漂被抓进了追的轨道？ |
| 「所有努力型主角都是z」→ F12高频误判 | F12最常把zx+n的路线执行误判为z的追光 | 灵魂核验案例库中95.6%的zx+n标签需要修正（zx+n双主陷阱） |

**一句话防误判**：
> 如果去掉「被光点击中后的不可控追逐」，角色还像z——那它一定不是z。z的灵魂不是目标达成，是**被点燃的状态**——不是他在追光，是光在拉着他跑。

## 附录B：创作版快捷入口（7-8级信息量）

```
[z]角色设计：
- 不是有计划的人——ta是被点燃的，不是自己设计的
- 核心动作：注视光源→被吸引→冲出去→燃烧
- 神态：眼睛发光——不是冷静的注视（nx），是瞳孔放大、整个人在亮的注视
- 手部：不要稳重地握着——z的手是向前的、张开的、去触碰光的
- 身体姿态：前倾——重心在前面，身体已经要冲出去了但脚还在原地
- 衣服：亮色/燃烧色系——哪怕开始暗，被点燃后会变亮
- 站位：永远在光的路径上——不是拥有光，是在光能照到的地方

[z]否定变体（z_neg）设计注意：
- 眼神不是燃烧——是**烧不尽的余烬**——眼睛在发红但不是因为兴奋，是因为没睡
- 动作是重复性的、消耗性的——追同一个东西追不到就换方式继续追
- 色彩从亮的燃烧色变成暗红/铁锈色——燃烧还在，但燃料不对了
- 参考卡缪·维丹和阿姆罗·雷的气质差异——卡缪是z_neg（追不可逆的否定事实），阿姆罗是标准z（朝未来追）

忌：
- ❌ 不要把z画成冷静执行——那是zx
- ❌ 不要把z画成「在坚持」——坚持的姿态属于n或zx，z是「在冲」
- ❌ 不要把z_neg和情绪崩溃混淆——z_neg的人能量大得惊人，不会「垮掉」，只会「炸掉」
- ❌ 不要把z当成「热血/主角」的默认标签——真正的z在故事里其实很少见
```

## 附录C：动态链（9-10级信息量）

```
常见链1：z → x（追光被吞噬）
  描述：z的光太亮，引来了更黑暗的东西——光被深渊吃掉。追光者的执念撞上了不受控的欲望
  作品例：亚瑟（小丑）——每次想被看见都被哥谭的恶意吞掉
  动画：z(我想被看见) → x(哥谭的恶意) → z(再试一次) → x(被吃的越来越深) → z_neg(光没了，只剩执念)

常见链2：z → nz（追逐→停靠）
  描述：z的冲动被nz的等待收束——跑累了，有人在那接着
  作品例：蜂蜜与四叶草——竹本骑行的终点是花本所在的校园
  动画：z(骑去找答案) → xz(在路上漂) → z(还在继续骑) → nz(花本在等) → z到nz(到了——不走了)

常见链3：z_neg特殊链——n越强z能量越大
  描述：当z锁定否定事实时，z的能量不会被n承载消化，反而在n的容器中持续累积
  作品例：卡缪·维丹——凤死了→他追这个不可逆的事实→身边越多人关怀（n）→他越愤怒为什么凤回不来
  动画：z_neg(锁定) → n(承载者的关怀) → n不能回收z_neg → z_neg在n中累积 → 爆炸

常见链4：z → zn（追光→意义沉淀）
  描述：跑着跑着，跑出了意义。z在前行中附着了zn的信念层
  作品例：阿甘——跑了三年后突然停下来的那个场景——跑本身变成了符号
  动画：z(被珍妮点亮开始跑) → z(一直跑) → zn(跑出了意义——被时代解释) → z(还在跑)

常见链5：xn → z（规则压出爆点）
  描述：截止日期/纪律框架把z的能量压成集中的爆点
  作品例：爆裂鼓手——弗莱彻的严苛规则压出安德鲁最终的完美一击
  动画：xn(规则/纪律/截止日期) → xn补z(压力变成专注) → z(爆点——精准释放)
  注意：xn补z只在「规则框架和z的方向一致」时成立——规则压错方向会熄灭z

全链示例（时间型经典链）：
  xn(规则建立框架) → z(冲动在框架中燃烧) → xn(规则压出截止日期) → z(在截止前爆发)
  ——爆裂鼓手的每个排练和演出周期

全链示例（标准z的生命周期）：
  nx(先探测到光在哪) → z(被光捕获→开始追) → zx(如果光可抵达→转化为路径推进) → nz(如果在终点有人等→停靠)
  ——竹本：被花本的光击中(z)→骑行穿越日本(xz+z)→回到花本所在的校园(nz)

常见链6：z的正反馈闭环与坍塌临界点（藤野/樱木型）
  描述：z的驱动依赖于光点反馈——被认可→更有动力→更投入→被更多人认可→动力更强。这是标准z的引擎模式。但当光点被遮蔽（更亮的光出现、被否定等），z不是渐进式消退而是瞬间坍塌。坍塌后有两种路径：找新光点或转入z_neg
  作品例：蓦然回首——藤野的光点是「被认可」(有人看我的漫画)。京本出现后——京本的画比她好——她的光点被遮蔽。不是「我画得不够好所以要多画」，是「我的光不见了所以我不知道为什么要画」。这是z的坍塌临界点(Critical Point of z Collapse)的完美一刻
  动画：z(被认可的光——藤野在画漫画) → 更亮的光出现(京本的画) → z的光点被遮蔽(藤野停画) → 坍塌临界点 → 找新光点(她回去画四格——不是同一道光但换了一个发光的路径)

常见链7：z的否定变体免疫机制——自发光型z（樱木型）
  描述：标准z的光点来自外部（被认可/被看见），当外部否定增多时容易转入z_neg。但存在一种特殊子型——z的光点具有自发光属性：即使外部否定持续攻击，光点不会熄灭。不是否定进不来（那是zn），是被否定了但光还在
  作品例：灌篮高手——樱木花道的「我是天才」在逻辑上和「被甩50次」形成矛盾但能量上自洽。他的z不受z_neg机制影响——因为他的光点是自生的("我宣布我是天才"不是基于「别人说我是天才」)
  动画：外部否定(被甩50次→赤木骂他→对手藐视他) → 自发光型z(但我是天才) → 否定变体免疫(光不灭) → 正反馈闭环仍运转(一次扣篮就重新启动整条能量链)
```
