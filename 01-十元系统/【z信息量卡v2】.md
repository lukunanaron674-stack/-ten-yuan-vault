# 【z 信息量卡 v2】

> **z = 一个精神个体面对庞大的物质客观世界时，需要另一个精神个体看见、回应并认可自己的精神存在。**

## 1. 核心本体

```text
物质客观世界庞大
→ 单个精神个体显得渺小
→ 物质本身无法确认精神价值
→ 需要另一个精神个体的见证与认可
→ z
```

### 最短封存句

> **你看见我，才证明我的精神存在对另一个精神个体成立。**

## 2. z 的核心关系

```text
精神个体 ↔ 另一个精神个体
```

z 的重点不是大众数量，而是认可是否来自另一个真正的精神主体。

- 一万人围观，不一定触及 z 的根。
- 一个重要的人真正看见、理解并承认自己，可能形成极强 z。
- 自己展示、宣言、登上舞台，是为了让精神存在进入另一个精神个体的视野。

## 3. 外部表现与本体的区别

以下内容可以是 z 的血肉，但不能替代核心定义：

- 舞台
- 聚光灯
- 被看见
- 荣耀
- 宣言
- 追光
- 表现欲
- 执念
- 爆点
- 完成后的兑现感

判断时必须追问：

> **他到底希望谁认可他？这种认可为什么能确认他的精神存在？**

若没有另一个精神个体的确认关系，只剩目标、冲动或视觉光点，不足以直接判纯 z。

## 4. 人物判定

人物本体偏 z 时，常出现：

- 非常在意某个重要对象如何看自己。
- 做成一件事后，需要有人真正理解其意义。
- 被忽视、否认或误解时，精神存在感会受到打击。
- 会通过展示、作品、行动、宣言或形象，把自己送进另一个人的精神视野。
- 得到关键对象的认可后，状态可能瞬间完成或释放。

### 必要问题

```text
1. 他需要谁看见？
2. 为什么这个人的认可不可替代？
3. 他要被认可的是能力、身份、作品，还是完整的精神存在？
4. 没有任何精神个体回应时，他的行动是否仍然成立？
```

## 5. 误判防线

| 表面现象 | 为什么不能直接判 z |
|:---------|:--------------------|
| 有明确目标 | 可能是路径与执行问题 |
| 很努力 | 努力只是行为 |
| 很有执念 | 执念可能来自多种结构 |
| 喜欢表演 | 可能只是职业、社交策略或表象经营 |
| 很显眼 | 显眼是视觉结果，不等于精神认可需求 |
| 追光 | 必须确认“光”是否代表另一个精神个体的认可 |
| 自信宣言 | 可能是自主、目标或角色姿态 |

一句话防误判：

> **去掉“另一个精神个体的看见与认可”以后，案例仍完整成立，就不能只凭舞台、追光或执念判纯 z。**

## 6. z 与 x、n 的底层区别

```text
x：看具体物象与物质关系
z：看另一个精神个体是否认可自己
n：看更大区域与整体关系
```

- x 解决“这个物是什么、归谁、如何运作”。
- z 解决“另一个精神个体是否承认我的精神存在”。
- n 解决“这件事放进多大的整体关系中理解”。

## 7. 判断对象

- **人物本体 z**：长期依赖精神主体之间的认可关系。
- **人物状态 z**：此刻强烈需要某人的回应与确认。
- **行为 z**：展示、宣言、创作、兑现给某人看。
- **视觉 z**：舞台、聚光、中心、爆点，仅为辅助证据。
- **关系 z**：一个人是否真正看见并承认另一个人的精神存在。

单张图可以视觉偏 z，但人物本体不一定是 z。

## 10. 三元接口

本卡本身就是 z 的三元底层卡，同时与十元位置 z 对照使用。

三元与十元并列：

- 十元 z 是独立位置。
- 三元 z 描述其精神认可质地。
- 不得把 z 当成由其他三元派生的下级类型。
