# 【z 信息量卡 v2.1】

> **z = 精神个体面对庞大的物质客观世界，通过学习、理解并有限地改变它，使自己的主观能力被某个认可主体确认，进而扩大自身权能。**

## 1. 核心本体

```text
物质客观世界庞大
→ 单个精神个体显得渺小
→ 主体学习并理解客观世界
→ 发现规律、形成作品或产生有效改变
→ 改变被认可主体看见与承认
→ 主体确认“我的精神与能力能够作用于世界”
→ 权能扩大
```

### 最短封存句

> **我理解了世界的一部分，也确实改变了它；这种改变被确认，于是我的主观权能变得更大。**

## 2. z 的权能循环

z 不是坐等夸奖，而是一条完整循环：

```text
学习客观世界
→ 理解客观规律
→ 形成主观认识
→ 对客观世界产生有效改变
→ 改变得到认可
→ 主体权能扩大
→ 再去理解与改变更大的部分
```

“能力越来越强、发现越来越大、影响越来越广”是 z 权能增长的重要表现。

## 3. 认可主体

认可不必只来自一个现实中的具体他人。以下都可以成为 z 的认可主体：

- 一个具体的人。
- 一个群体或公众。
- 已经去世、但仍被主体想象和内化的人。
- 神。
- 国家。
- 历史。
- 想象中的观众。
- 自己对自己的认可。

关键不在认可者是否物理在场，而在于主体是否把它当作一个能够确认精神价值与能力的见证位置。

### 自我认可

自我认可也可以构成 z：

```text
行动的我
↔
见证并确认行动意义的我
```

主体内部形成了行动者与认可者两个精神位置。

## 4. 被认可的内容

以下都可以进入 z，但需要说明它们如何确认主体的能力或精神存在：

- 外貌。
- 能力。
- 作品。
- 身份。
- 选择。
- 发现的客观规律。
- 对世界造成的改变。
- 完整的精神存在。

它们不是体量高低的简单排序，而是不同的 z 对象。准度判断必须写清：

```text
谁认可？
认可什么？
这种认可怎样扩大主体权能？
```

## 5. 纯 z 与脏醒边界

### 纯 z

纯 z 承认客观世界独立存在：

```text
客观世界不由我凭空决定
→ 我可以学习它
→ 理解它的规律
→ 利用规律改变其中一部分
→ 我的改变被确认
```

> **纯 z：我能够改变世界。**

### 向 x 过量的“脏醒”

当主体不再满足于影响客观世界，而试图让主观世界替代、吞没或完全定义客观世界时，就越过了纯 z 边界：

```text
我理解了规律
→ 我有了改变能力
→ 我认为客观世界必须服从我的主观世界
→ 人、物与规律都变成我的材料和所有物
```

> **脏醒：世界应该由我定义并服从我。**

关键差异：

```text
z：主观能够作用于客观
脏醒：主观试图替代客观
```

## 6. 外部表现与本体的区别

以下内容可以是 z 的血肉，但不能替代权能循环和认可结构：

- 舞台
- 聚光灯
- 被看见
- 荣耀
- 宣言
- 追光
- 表现欲
- 执念
- 爆点
- 完成后的兑现感

判断时必须追问：

```text
他理解或改变了什么？
谁在确认这种改变？
认可怎样扩大了他的主观权能？
```

## 7. 人物判定

人物本体偏 z 时，常出现：

- 强烈想证明自己的认识、能力、作品或改变是有效的。
- 发现规律或完成作品后，很激动地向认可主体表达。
- 得到确认以后，会把目标扩展到更大的世界范围。
- 被忽视、否认或误解时，权能感与精神存在感会受到打击。
- 会通过展示、作品、发现、行动、宣言或形象，让主观世界进入认可主体的视野。

### 必要问题

```text
1. 他面对的客观世界是什么？
2. 他学习或理解了什么？
3. 他实际改变了什么？
4. 认可主体是谁？
5. 被认可的内容是什么？
6. 认可是否让他的权能继续扩大？
7. 他是否仍承认客观世界独立存在？
```

## 8. 误判防线

| 表面现象 | 为什么不能直接判 z |
|:---------|:--------------------|
| 有明确目标 | 可能只是路径与执行 |
| 很努力 | 努力只是行为 |
| 很有执念 | 执念可能来自多种结构 |
| 喜欢表演 | 可能只是职业或表象经营 |
| 很显眼 | 显眼是视觉结果 |
| 追光 | 必须解释光与认可、权能的关系 |
| 自信宣言 | 可能只是自主姿态 |
| 很聪明 | 可能是 x 的局部分析能力 |
| 改变世界 | 必须确认是否有学习、规律、认可与权能循环 |

一句话防误判：

> **只有目标、冲动、聪明或表现，没有“理解客观世界 → 有效改变 → 认可 → 权能扩大”，不足以直接判纯 z。**

## 9. z 与 x、n 的底层区别

```text
x：看具体物象与物质关系，小而清
z：理解并改变客观世界，通过认可扩大主观权能
n：看更大区域与整体关系，大而空
```

- x 解决“这个物是什么、归谁、如何运作”。
- z 解决“我的主观能力能够对客观世界产生多大作用，并是否得到确认”。
- n 解决“这件事放进多大的整体关系中理解”。

## 10. 判断对象

- **人物本体 z**：长期通过认识、改变、认可与权能扩大来确认自己。
- **人物状态 z**：此刻因发现、创造、被认可或被否认而权能上升或受损。
- **行为 z**：发现、展示、创作、宣言、向认可主体呈现改变。
- **视觉 z**：舞台、聚光、中心、爆点，仅为辅助证据。
- **关系 z**：某个认可主体是否确认主体的发现、能力、作品或精神存在。

单张图可以视觉偏 z，但人物本体不一定是 z。

二审必须验证：

```text

是否存在认可主体？
认可是否扩大主体权能？
是否已经越界为主观替代客观的脏醒？
```

## 13. 三元接口

三元与十元并列：

- 十元 z 是独立位置。
- 三元 z 描述其认识、改变、认可与权能质地。
- 不得把 z 当成由其他三元派生的下级类型。
