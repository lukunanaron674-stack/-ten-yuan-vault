# xz信息量卡 v2.1

## 1｜一句话本体

> **xz 是火药桶式危险结构：危险能量已经蓄积在一个整体中，对局部触发高度敏感；一旦触发，变化会从一点扩展到全局，造成整体爆发、扩散、失控或不可逆转化。**

最短召回：

```text
xz＝火药桶
```

## 2｜本体主骨

纯xz至少包含：

1. **危险整体**：危险不是只存在于一个刀口，而是储存在整个对象、关系、系统或场域中；
2. **能量蓄积**：压力、矛盾、风险或破坏潜力已经形成规模；
3. **触发敏感**：一个小事件、节点、接触或越界可能使整体状态改变；
4. **局部牵动全局**：触发后的后果不是局部修补，而是系统级释放、扩散或崩解；
5. **爆发前可静止**：xz不必主动进攻，表面可以平静、克制或尚未行动；
6. **不可轻易回收**：一旦爆发，恢复原状的成本高，甚至不可逆。

```text
整体危险蓄积
＋
触发高度敏感
＋
局部可牵动全局
＝
xz强候选
```

## 3｜对象层

### 人物本体xz

一个人长期像火药桶：

- 内部积累高压情绪、力量、矛盾或风险；
- 平时未必主动攻击；
- 存在明确底线、伤口、关系节点或触发区；
- 一旦被触发，行为、关系或命运整体改写；
- 这种结构跨情境复现，而不是一次发火。

### 状态xz

某阶段进入高压临界：

- 冲突和能量已经积累；
- 系统对微小刺激变得敏感；
- 一个节点可能引发整体爆发。

### 场域xz

环境本身像火药桶：

- 多个风险相互耦合；
- 局部事故会产生连锁反应；
- 爆发前可能安静，但系统稳定性很低。

### 行为xz

行为不是必要条件。点燃、越界、揭露、触碰底线等可以是触发行为，但xz首先是触发前已经存在的整体危险结构。

### 视觉xz

视觉层详见[[03-十元准度卡/xz_视觉狭义卡_v0.2]]：

```text
本征形：长三角／长楔形
感觉：厚主体＋引信式尖端
核心：整体蓄积＋触发敏感
```

## 4｜与旧“危险逼近”定义的关系

危险逼近、包围扩张、退路和时间窗减少，仍然可以是xz的**动态显影**，但不再是唯一或最高本体定义。

它们只有在以下情况下支持xz：

```text
逼近或压缩
→ 使整体危险继续蓄积
→ 使系统对触发更加敏感
→ 使一次局部事件可能引发全局爆发
```

如果只有危险靠近，却没有整体蓄积、触发敏感和系统级释放，不能仅凭紧迫感高判纯xz。

## 5｜最近邻

### xz vs x

```text
x：刀。危险来自物品本身的锐利、切割和直接伤害边界。
xz：火药桶。危险储存在整体中，一个触发点可能使全局爆发。
```

### xz vs zx

```text
xz：爆发前高压蓄积，等待或遭遇触发。
zx：力量已经主动推出并占据现实方向。
```

最短区别：

```text
被点爆＝xz
主动推出＝zx
```

### xz vs z

```text
z：节点、截点、长度、单一裁定或发生点。
xz：一个节点能够点燃已经存在的整体危险结构。
```

### xz vs nx

```text
nx：让位、顺流、散开或沿既有通道推进。
xz：整体危险蓄积，对触发高度敏感，并可能产生系统级爆发。
```

被动卷入不能自动判xz。

### xz vs nz

```text
xz：爆发、扩散、失控与不可轻易回收。
nz：保存、停靠、回返、修复与重建空间。
```

两者构成水行对立统一轴：

```text
危险整体的临界爆发 ↔ 对象特异的保存与回返
```

### xz vs xn

```text
xn：规则分布、流程、节点网络和秩序运行。
xz：这些结构内部危险已蓄积，一个局部节点可能使全局失控。
```

## 6｜非充分条件

以下不能单判xz：

- 看起来危险、阴暗、疯狂；
- 一把刀、一根尖刺或锐利服装；
- 单纯愤怒、发脾气、黑化；
- 角色跑得快或正在打斗；
- 倒计时、追逐、退路减少；
- 被动卷入或无法选择；
- 碎、乱、羽化、多方向视觉；
- 一次局部事故但没有系统级连锁可能。

## 7｜拿掉测试

```text
拿掉整体蓄积，只剩锐利危险物品 → x。
拿掉触发敏感，系统仍稳定运行 → 不足以判xz。
拿掉局部牵动全局，只剩局部伤害 → x或其他类型。
让力量主动持续向外推进 → zx。
让系统恢复、停靠并重建回返空间 → nz上升。
只有危险逼近但没有火药桶结构 → 最多是xz动态材料，不是纯端点。
```

## 8｜反向测试

- 降低整体压力后，微小刺激不再引发全局变化：支持xz；
- 移除触发节点后，系统恢复稳定：支持xz；
- 触发后只产生局部划伤而非整体释放：更接近x；
- 不触发也主动持续外推：更接近zx；
- 爆发后仍能低成本恢复原状：xz纯度下降。

## 9｜视觉形状接口

```text
x：三角／刀。
xz：长三角／火药桶。
zx：菱形／挥出的刀。
```

形状只是视觉狭义显影，不能单独替代本体主骨。长三角如果没有整体蓄积与触发敏感，也不能高判xz。

## 10｜关系接口

本卡确认xz端点，不自行改写生克补机制：

```text
xn 生 xz
xz 生 zx
n 克 xz
xz 克 zn
xz ↔ nz（补）
```

这些关系需要按新本体定义重新审计旧机制说明，旧“危险逼近”解释只保留为可能子型。

x＝刀。
