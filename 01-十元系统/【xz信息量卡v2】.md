# xz信息量卡 v2.2

## 1｜一句话本体

> **xz 是“终点先存在，过程不断逼近它”的命运收束结构：事情尚未发生，但某个结局、临界点或不可回避的终点已经在前方形成；随着过程推进，选择空间、退路与可能路径持续收窄，当前的一步步行动被那个未来终点牵引。**

最短召回：

```text
xz＝结局先在前面等你
```

或：

```text
结局先存在，过程只是不断逼近它。
```

## 2｜本体主骨

纯xz至少包含以下主骨中的大部分：

1. **终点前置**：结局、临界点、死亡、审判、失去、兑现或某个不可忽略的未来节点，先于当前过程获得结构地位；
2. **方向被未来规定**：人物不是随意漂流，当前事件越来越明显地朝那个终点排列；
3. **路径收窄**：可选道路、退路、时间窗或可能性逐步减少；
4. **路径汇流**：不同选择看似分叉，最终却越来越容易回到同一终点或同一狭窄区间；
5. **临界逼近**：距离、时间、机会或状态不断接近某个无法忽视的点；
6. **未发生先有压力**：真正的结果还没兑现，但因为终点已经“在前面”，现在就产生命运感；
7. **可安静存在**：xz不要求打斗、爆炸、追逐。越安静地朝已知终点前进，往往越纯。

```text
终点前置
＋
方向被未来规定
＋
路径/选择持续收窄
＋
临界不断逼近
＝
xz强候选
```

## 3｜最核心的感觉

xz不是普通“危险”，而是：

- **注定感**；
- **迟早会到**；
- **逃不掉或越来越难逃**；
- **已经开始倒计时**；
- **前方存在明确终点**；
- **每一步都在靠近它**；
- **人仍然能行动，但自由度越来越小**。

最短感觉句：

> **路还在走，但墓碑已经立好了。**

## 4｜动态骨架

xz常见的动态不是“突然爆发”，而是收束：

```text
很多可能性
→ 终点出现影子
→ 终点越来越具体
→ 其他道路逐渐关闭
→ 多条路径开始汇流
→ 只剩少数出口 / 一个出口
→ 终点兑现
```

所以xz常呈现“前宽后窄”的结构：

```text
\         /
 \       /
  \     /
   \   /
    \ /
     ●
```

`●`不是普通目标点，而是**已经对当前过程产生牵引和限制的未来终点**。

## 5｜对象层

### 人物本体xz

人物长期活在某个前置终点的牵引下：

- 很早就知道、感到或不断遭遇某个未来结局；
- 行动看似自由，但长期选择不断把自己带向同一个终点；
- 越逃避，路径反而越窄；
- 人物的存在感来自“我正在走向什么”。

人物xz不等于“容易发火”或“很危险”。

### 状态xz

某一阶段开始明显收束：

- 一个结果逐渐成为主导未来；
- 时间窗、退路、机会持续减少；
- 多种可能性逐渐失效；
- 当前状态越来越接近临界兑现。

### 场域xz

环境本身把人往某个终点导流：

- 走廊、轨道、审判流程、包围圈、倒计时、不可逆程序等都可以形成xz；
- 关键不在“环境危险”，而在它是否让未来不断收束；
- 场域越让不同路径汇向同一点，xz越强。

### 行为xz

单个行为不是xz本体。行为只有在“它使人物更接近已经存在的终点”时，才成为xz显影。

例如：

```text
继续前进
→ 少一个退路
→ 更接近终点
```

比单纯“冲过去”“攻击”“爆炸”更典型。

### 视觉xz

视觉上优先抓：

```text
长廊 / 轨道 / 狭长透视
漏斗 / 长楔 / 前宽后窄
远处明确终点
重复逼近的门、钟、台阶、光点
退路逐步关闭
同一终点不断在远处出现
```

现有“长三角／长楔形”可以保留，但主解释改为：

```text
长楔＝路径向终点收束
```

而不是“厚主体＋引信”。

## 6｜xz与“未知恐怖”的区别

```text
未知恐怖：不知道会发生什么。
xz：知道、预感或结构上已经存在“会走到哪里”，并不断逼近。
```

所以：

- 黑暗里突然跳出怪物，不一定xz；
- 知道第七天会死，而今天已经是第六天，xz很强；
- 刑场已经搭好，人物仍在吃最后一顿饭，xz很强；
- 没人追赶，但人物自己沿长廊走向已经亮起的终点门，也可以很纯xz。

## 7｜与旧“火药桶”定义的关系

v2.1 的“整体危险蓄积＋触发敏感＋一点牵动全局”**不再作为xz最高本体定义**。

它降级为：

```text
xz_firepowder = xz 的一种危险显影子型
```

只有当火药桶结构同时具备下面这一层时，才强支持xz：

```text
某个爆发/崩解终点已经形成
→ 系统越来越难避开它
→ 触发窗口越来越近
→ 可恢复路径越来越少
→ 最终走向爆发或不可逆转化
```

如果只是：

```text
高压蓄积
＋
一点触发全局
```

但没有“终点前置、路径收窄、未来牵引”，则不能只凭火药桶高判纯xz。

旧材料保留为证据库与子型，不删除。

## 8｜与旧“危险逼近”定义的关系

“危险逼近、包围扩张、退路减少、时间窗减少”重新获得较高地位，但必须抓到真正主骨：

```text
不是因为危险靠近所以是xz，
而是因为危险靠近正在把未来压成越来越少的结局。
```

因此：

```text
逼近
→ 路径收窄
→ 选择减少
→ 临界点越来越确定
→ 终点兑现
```

是典型xz动态链。

## 9｜最近邻

### xz vs x

```text
x：危险/切割/边界就在当下，伤害来自对象本身或直接接触。
xz：真正重要的是未来终点已经形成，现在正不断向它收束。
```

最短区别：

```text
x＝刀口在这里。
xz＝终点在那里，而你正在过去。
```

### xz vs zx

```text
xz：未来终点先取得结构地位，过程被它不断收束。
zx：力量、决定或因果方向从当前被推出，使后续现实沿某方向发生。
```

最短区别：

```text
xz＝结局拉着现在走。
zx＝现在把后果推出去。
```

所以：

```text
“因为你做了这件事，所以后果来了” → 更偏zx因果推进。
“不管怎样绕，越来越走向那个已经存在的结局” → 更偏xz。
```

### xz vs z

```text
z：一个节点、截点、长度、裁定点或发生点。
xz：这个未来点提前支配了一段过程，并让路径不断向它汇流。
```

单独一个截止日期不自动等于xz；只有它持续收紧现在，才进入xz。

### xz vs nx

```text
nx：让位、顺流、沿既有安排继续，主体把自己交给现状或通道。
xz：无论主体主动还是被动，关键是未来路径正在向某个终点收束。
```

“随安排继续”本身是nx；“安排一步步把你送到唯一终点”才产生xz。

### xz vs nz

```text
xz：未来向一个终点收束，空间越来越少。
nz：保存、停靠、依恋、回返，让对象仍有可留下或可回来的位置。
```

两者放入“命运 xz+nz”时，可以形成：

```text
xz：终点在拉近
nz：仍在等待、保存或寻找可以停靠的归宿
```

### xz vs xn

```text
xn：规则、流程、节点网络、时间秩序怎样分布和运行。
xz：这些流程是否正在把不同可能性压向同一未来终点。
```

规则本身不是xz；规则开始成为不可回避的命运通道时，xz上升。

## 10｜非充分条件

以下都不能单独判xz：

- 看起来危险、阴暗、疯狂；
- 有刀、尖刺、枪、血或凶器；
- 单纯愤怒、黑化、攻击；
- 单纯火药桶、高压、容易被触发；
- 单纯爆炸或全局连锁；
- 角色跑得快、打斗激烈；
- 只有倒计时数字，但它没有改变选择空间；
- 只有追逐，但追逐没有形成未来收束；
- 单纯被动卷入、无法选择；
- 一次突然事故，没有前置终点与逼近过程。

## 11｜拿掉测试

```text
拿掉“前方终点”，只剩当下危险 → 更可能是x或其他。
拿掉“路径收窄”，仍有大量等价未来 → xz下降。
拿掉“逼近过程”，只剩突然结果 → 不足以判纯xz。
拿掉“未来对现在的牵引”，只剩主动外推 → 更偏zx。
让人物重新获得大量真实出口与可逆空间 → xz下降。
让终点从确定/强约束变成完全未知 → xz下降，未知感上升。
```

## 12｜反向测试

- 越接近某个未来点，真实可选项越少：支持xz；
- 改走另一条路，却仍逐渐汇回同一终点：强支持xz；
- 终点尚未发生，但现在已经因为它改变：强支持xz；
- 完全不知道未来会发生什么，且没有收束方向：xz不足；
- 结果主要由当前主动行为向外制造，而非未来收束当前：zx更高；
- 增加真实退路后，命运压力明显下降：支持xz判定。

## 13｜视觉形状接口

```text
x：三角／刀口／直接危险边界。
xz：长三角／长楔／漏斗／通向远端终点的收束路径。
zx：菱形／推出／碰撞／现实方向被主动改变。
```

形状只是视觉狭义显影，不能单独替代本体主骨。

长三角若只是“尖”，没有终点牵引和路径收束，不足以高判xz。

## 14｜关系接口

本卡只重定xz端点定义，不在此强行改写全部生克补机制：

```text
xn 生 xz
xz 生 zx
n 克 xz
xz 克 zn
xz ↔ nz（补）
```

但旧机制中凡把xz只解释为“火药桶／触发爆发”的部分，后续需要按v2.2重新审计。

审计优先级：

1. `xz_准度卡`
2. `xn生xz`
3. `xz生zx`
4. `n克xz`
5. `xz克zn`
6. `xz补nz`
7. 五大主题“命运 xz+nz”说明
