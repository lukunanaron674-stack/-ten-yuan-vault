# 领域狭义五行十元映射｜固定工作习惯 v1.1

## 0｜固定起手式

```text
每进入一个新领域，先写该领域的五行—十元狭义定义，
并为五个狭义名称分别保存一条 is-a狭义 继承边。
```

五行广义本体不变；变化的是进入领域后使用的对象、名称、动作、证据和具象词。

```text
五行广义本体
→ 进入具体领域
→ 保留同行阴阳十元轴
→ 形成领域狭义子项
→ 保存 子项 --is-a狭义[domain]→ 五行父项
→ 再建立案例库
```

## 1｜为什么必须保存继承边

只写“词语映射”会让后续系统误判为平行系统、类比或偶然同构。`is-a狭义`明确说明：

- 子项继承五行轴；
- 子项只覆盖该领域的狭义外延；
- 领域不同，狭义名称可以不同；
- 五行父项仍是广义本体。

示例：

```text
因果 --is-a狭义[叙事]→ 木
肝   --is-a狭义[生理]→ 木
发束主动外拨 --is-a狭义[发型行为]→ 阳木zx
```

## 2｜每个领域必须完成的五行映射

| 五行父项 | 阴阳端 | 必答问题 |
|---|---|---|
| 木 | `zx ↔ nx` | 该领域中最终方向与作用权来源是什么？ |
| 火 | `zn ↔ x` | 该领域中对象独立成立与归属方式是什么？ |
| 土 | `n ↔ x并z` | 该领域中什么跨越内外边界？ |
| 金 | `xn ↔ z` | 该领域中运行权和裁定重心怎样配置？ |
| 水 | `xz ↔ nz` | 该领域中什么发生可逆性收窄或回返保存？ |

## 4｜工作顺序

```text
写领域与尺度
→ 找五行在该领域的五个狭义名称
→ 保存五条 is-a狭义 边
→ 展开十个十元端的相反操作
→ 写可观察证据与反例
→ 再开始案例分类
```

不能先把案例硬塞进十元，再倒推领域定义。

## 5｜成功门

领域映射至少满足：

1. 五行广义本体未被改写；
2. 五个狭义子项均有父项与领域；
3. 十个十元端均有可观察定义；
4. 同行阴阳位于同一对象层和核心变量；
5. 子项继承轴，但不冒充父项全部外延；
6. 至少有正例、反例和最近邻；
7. 具体案例用 `instance-of`，不得替代 `is-a狭义`；
8. 未完成时标记 `draft-domain-map`。

## 6｜固定纪律

```text
做一个领域
＝先做该领域五行狭义地图
＝保存五条 is-a狭义 继承边
＝之后所有案例从该地图进入
```
