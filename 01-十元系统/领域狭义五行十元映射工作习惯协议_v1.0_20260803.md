# 领域狭义五行十元映射｜固定工作习惯 v1.0

## 0｜习惯本体

```text
每进入一个新领域，先重新思考并写出该领域的五行—十元狭义映射定义。
```

这不是可选补充，而是进入领域工作的固定起手式。

五行广义本体不变；变化的是它进入不同领域后，对象、变量、动作、证据和具象名词怎样显化。

```text
五行广义对立统一体
→ 进入具体领域
→ 找到该领域中的同一核心变量
→ 写出阴阳十元的相反操作
→ 再开始案例、角色、视觉、音乐、游戏或素材分类
```

## 1｜为什么必须每个领域重做一次

不能把主题领域、人物行为领域、生理领域或视觉领域的狭义词直接复制到另一个领域。

例如：

```text
木在主题领域＝因果
木在生理领域＝肝
木在人物行为领域＝方向源与续接方式的具体行动
木在发型领域＝发束方向由自身生成，或沿既有发流续接
```

它们继承同一个木轴，但领域对象、可观察变量和证据不同。

## 2｜每个领域必须完成的十项映射

对五行十元逐一回答：

| 五行 | 阳端 | 阴端 | 必答问题 |
|---|---|---|---|
| 木 | zx | nx | 该领域中“最终方向与作用权来源”具体是什么？自身生成与沿既有通道分别怎样显现？ |
| 火 | zn | x | 该领域中“对象独立成立资格与归属方式”具体是什么？保留自身与纳入掌握边界分别怎样显现？ |
| 土 | n | x并z | 该领域中什么在跨越内外边界？外→内承载与内→外映射分别怎样显现？ |
| 金 | xn | z | 该领域中运行权与裁定重心是什么？分布到节点流程与集中到最高点分别怎样显现？ |
| 水 | xz | nz | 该领域中什么具有可逆性与回返路径？收窄与保存／重建分别怎样显现？ |

## 4｜工作顺序

```text
先写领域对象和分析尺度
→ 为五行各找一个该领域中的核心变量
→ 在同一变量上写出阴阳两端的相反操作
→ 写可观察动作、形态、声音、机制或结果
→ 做反例、最近邻、拿掉与反向检查
→ 再建立案例库或素材分库
```

不能先把案例硬塞进十元，再倒推领域定义。

## 5｜领域映射成功门

一组领域映射至少满足：

1. 五行广义本体没有被改写；
2. 十个十元在该领域都有可执行或可观察的狭义定义；
3. 同行阴阳落在同一对象层、同一核心变量；
4. 两端能写出明确反向操作；
5. 不依赖情绪、颜色、职业、气质或传统对应直接判定；
6. 至少有正例、反例和最近邻误判；
7. 领域术语不能反向冒充广义正本；
8. 未完成时标记`draft-domain-map`，不得伪装成正本。

## 6｜固定纪律

```text
做一个领域
＝先做一次该领域的五行十元狭义映射
＝形成一张可复用的领域地图
＝之后所有案例都从该地图进入
```

这是长期习惯，不因领域熟悉、案例数量少或任务紧急而跳过。
