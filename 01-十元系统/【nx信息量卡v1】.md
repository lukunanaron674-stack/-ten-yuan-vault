
## 旧口径如何处理

旧材料不删除，统一降级为：

```text
历史血肉
+ xn 候选材料
+ 执行翻牌部分另查 zx
+ 待人物本体 / 行为 / 环境 / 结果分层二审
```

需要重新复核的旧词：

- 暗算
- 看牌
- 记账
- 等待
- 结算
- 清算
- 按节点翻牌
- 信息不对称
- 暗室 / 监控室 / 赌桌 / 档案柜
- 分析师 / 军师 / 检察官 / 幕后人

## 当前迁移假设

### 更像 xn 的部分

```text
记录
等待
按顺序累积
维持账目
时间到了再处理
依据流程或节点结算
```

### 可能带 zx 的部分

```text
到点主动翻牌
推进结果
切断关系
执行清算
```

这只是迁移候选，不是正式归类。最终仍需 xn 准度卡、三元构成表与生克补关系表校验。

## 禁止继续使用的旧推断

- 不能因为角色聪明、沉默、看穿全局，就判 nx。
- 不能因为场景有暗室、档案、监控或赌桌，就判 nx。
- 不能因为角色最后翻牌、复仇或清算，就判 nx。
- 不能直接沿用旧卡中的生克补链条。
- 不能把旧版“nx + zx”作为默认双主标签。
- 不能再把“把自己让没”写成 nx 主动压掉自己的目的。

## 迁移原则

> **保留旧血肉，不保留旧主骨；旧暗算结算先进入 xn 候选池，执行动作另查 zx；任何关系结论重新查表。**
