## 旧口径如何处理

旧材料**不删除**，但取消“纯 nx 锚点”资格，统一降级为：

```text
历史血肉
+ 复合 / 异化候选
+ 待人物本体、行为、环境、结果分层二审
```

需要重新复核的旧词：

- 暗算
- 看牌
- 记账
- 结算
- 清算
- 等待翻牌
- 信息不对称
- 暗室 / 监控室 / 赌桌 / 档案柜
- 分析师 / 军师 / 检察官 / 幕后人

## 旧案例池

这些案例下一轮必须逐个回答：

```text
1. 判断的是人物本体、状态、行为、环境还是结果？
2. 是否存在“把自己让没”的纯 nx 必要条件？
3. 若不存在，旧的暗算 / 结算来自哪个复合或异化结构？
4. 原有生克补与动态链是否仍能通过正式关系表？
```

## 禁止继续使用的旧推断

- 不能因为角色聪明、沉默、看穿全局，就判 nx。
- 不能因为场景有暗室、档案、监控或赌桌，就判 nx。
- 不能因为角色最后翻牌、复仇或清算，就判 nx。
- 不能直接沿用旧卡中的生克补链条。
- 不能把旧版“nx + zx”作为默认双主标签。

## 迁移原则

> **保留旧血肉，不保留旧主骨；保留案例，不保留未经复判的标签；保留关系假设，不把它当正式关系。**
