# 【xz 信息量卡 v1】

---

## 1. 核心本体（主骨）

**危险显身 + 异质逼近 + 恐怖遭遇 + 命运失稳**

xz 不是“危险/黑暗”的笼统概念。它的核心是：**危险以可感知形态逼近**。它让人进入边界不确定、退路变窄、必须行动的状态。

主骨公式：

```text
xz = 危险显形后逼近你，成为怪物、追杀、异质威胁、命运临界线。
```

### 行动型子骨

旧定义不删除，而是降级为 xz 的行动型子骨：

```text
xz_action = 临界行动 + 风险路径 + 来不及
```

它用于判断逃亡、追逐、错过、站台、断桥、倒计时、边界奔跑等“被命运推到风险路径上行动”的状态。

---

## 2. 第一体感

> 不是单纯恐怖，不是单纯黑暗，而是**“危险正在逼近，我必须在边界上行动”**。

- ❌ 误：xz = 暗色、废墟、惨、不幸、单纯黑暗氛围
- ✅ 正：xz = 危险显身、异质逼近、边界奔跑、来得及但差一点、命运临界线

**关键修正（2026-06-07）**：xz 不是“不是恐怖”，而是“恐怖的类型被精确定位”：不是氛围恐怖（那是 x 的渗透），是**边界上的恐惧**：危险以可感知形态逼近，你必须在边界上行动。怪物可以 = xz，当怪物是“逼近的危险显形”时。

- ❌ 废墟（不是 xz）：废墟可以是任何十元的场景，不具有临界行动性。

**反向污染**：其他十元被 xz 侵蚀。

- **nz 被 xz 污染**：停靠变成了不得已的临界站，等待变成煎熬。
- **z 被 xz 污染**：追光变成了逃命，舞台变成了断崖。

## 10. 禁止误判（核心防线）

**以下这些看起来像 xz，但实际不一定是 xz。必须看“危险显身 / 异质逼近 / 临界行动感”是否成立。**

| ❌ 误判 | ❌ 误判原因 | ✅ 正确归属 |
|:-------|:-----------|:-----------|
| 黑暗感 | 黑暗不自动等于 xz，黑暗更常是 x 的氛围/渗透 | x（氛围/渗透） |
| 废墟 | 废墟没有“边界行动通过性”，常是 xn / n 崩后的残留场 | xn（规则崩坏后）或 n（承载被压垮后） |
| 黑暗角色 | 黑暗是色彩，不是灵魂 | 视情况判断 |
| “很惨”/“不幸” | 承受苦难不是 xz 的职业 | n（承载）或故事设定 |
| 流浪汉 | 流浪 = nx + xz 混合态 | 纯 xz 必须有风险路径，不只是无家可归 |
| 死亡/毁灭 | 终点不是 xz | x（死亡作为终点）或 nx（死亡作为结算） |
| 孤独 | 孤独可以是许多十元的状态 | nz（等一个人）或 zn（无人理解的意义） |
| 怪物 | 怪物不是因为“丑/黑/恐怖”才是 xz，而是因为它承担“危险显身 / 异质逼近” | 多数可判 xz，若只是深处吞噬则偏 x |
| 恐怖 | 恐怖若只是氛围渗透可偏 x；若危险以形体、脚步、追杀、威慑逼近，则是 xz | x 或 xz，按逼近形态判断 |

**一句话防误判**：
> 如果去掉“危险显身 / 异质逼近 / 临界行动 / 来不及”这些要素，角色或场景还像 xz，那它一定不是纯 xz。

## 附录B：创作版快捷入口（7-8级信息量）

```text
xz角色设计：
- 不是单纯黑暗，而是“危险已经显形、正在逼近的人/物/场”
- 身上要有路径感、逃离感、未抵达感、临界感
- 衣服：切割边、斜向结构、轻装、风损、雨痕、局部破损
- 武器：快速、危险、短促、可撤离（匕首/弓箭/投掷物）
- 色彩：冷色 + 逆光切割
- 构图：倾斜 / 对角线 / 画面边缘留白

xz场景设计：
- 渡口 / 断桥 / 边境线 / 末班车站台 / 逃生通道
- 雨 / 风 / 雾 / 冷光
- 必须有“通过性”，不是封闭空间

忌：
- ❌ 暗色大全套：会变成 x
- ❌ 废墟破败：会变成 n 的受损状态或 xn 崩后残留
- ❌ 沉重滞涩：xz 是快的、逼近的、临界的，不是重的
```

## 附录C：动态链（9-10级信息量）

常见链1：xz → nz  
漂流者被迫继续 → 渴望停靠但不敢停  
作品例：《秒速5厘米》远野贵树

常见链2：xz → n  
危险漂流进入承载结构 → 临时庇护成为生命线  
作品例：《萤火虫之墓》节子的寄居状态

常见链3：xz → x  
临界行动被欲望污染 → 从逃生变成吞噬  
作品例：《蝙蝠侠》布鲁斯·韦恩的下坠边缘

常见链4：xz → xn  
临界行动被规则捕获 → 逃犯被法律追索  
作品例：《肖申克的救赎》安迪的越狱

常见链5：xz + nz = 命运主题  
核心动态对子：漂流与停靠的永恒拉扯

全链示例：

```text
xz(命运推力) → nz(想停靠) → x(被欲望拖住) → xz(继续漂流)
“快靠岸了，又被拉回海里”
```

**作品采肉：xz 动态链追加**

**葬送的芙莉莲**：
| 链 | 结构 | xz 解释 |
|:--|:-----|:-------|
| 时间尺度漂流链 | xz(精灵时间尺度→永远告别) → nz(想留住但留不住) → xz(继续在时间长河中漂流) | 芙莉莲不是不想停，是她的时间流速不允许她停在任何一个人类身边太久。这不是 nz 的等待（她不是在原地等），这是 xz 的时间漂流。 |
| 情感延迟风险链 | xz(爱来得太慢) → nz(对方还在等她的回应) → xz(但等到了她已经慢了) | 勇者辛美尔死后芙莉莲才意识到对他的感情。这是 xz 延迟风险的经典结构。 |

**棋魂**：
| 链 | 结构 | xz / nz 解释 |
|:--|:-----|:----------|
| nz→xz 力传导链 | nz(佐为千年等待的围棋渴望) → xz(进藤光被推入围棋世界) → nz(佐为通过阿光下了千年后的棋) → xz(阿光无法拒绝被推着走) | nz 的等待力转化为 xz 的行动力。佐为想继续下棋的柔情等待驱动了阿光的被迫漂流。 |
| 命运型时间对子链 | nz(佐为在千年前开始等待的坐标) + xz(进藤光在千年后被推入的坐标) = 两条时间线在 1998 年交汇 | 命运型对子的精确时间拓扑：等待的时间和漂流的时间在同一个点交汇。 |

**光逝去的夏天**：
| 链 | 结构 | xz 解释 |
|:--|:-----|:-------|
| 夏天作为 xz 的临界时间容器 | xz(夏天是临界时间容器：倒计时感) + nz(不想夏天结束) = 同一时间容器中同时承载漂流和等待 | 夏天不是田园，是临界时间容器。阳光从峰值走向耗尽，每一天都在倒计时。阳水耗尽 = 夏天结束 = 临界点。 |
| xz + nz 的夏天张力 | xz(阳水流向耗尽：漂流 + 倒计时的临界行动) + nz(不想结束：等待 + 柔情的依恋) = 夏天同时承载两种力量 | 同一段时间里，一个人在被时间推着走，一个人想让时间停下来。这是命运型对子在同一个容器中的张力。 |
