# 概念映射：欲望（2026-06-08 建立）

## 1. 一句话定义

**欲望 = 现象之流驱动的占有/吞噬本能，是底层生存指令的「要」——永不满足、永远在渴。不包装、不解释、先吃了再说。**

---

## 2. 三元粗拆（x/z/n）

| 三元面 | 对应内容 | 说明 |
|:-----:|:--------|:-----|
| **x** | 现象之流、不满足、永远在渴 | 欲望的核心本体——流动的、吞食的、没有边界的「要」 |
| **z** | 追光冲动、被看见、有边界的执念 | 欲望的z面表现为被点燃后追某样东西的冲动，但z有楚王弓边界 |
| **n** | 承载、稳定、容器、尊严 | 欲望的n面表现为承载欲望的容器——被压制的欲望、有底线的欲望 |

---

## 3. x/n/z 分别细化为十元候选

### x面细化
| 十元候选 | 理由 |
|:-------:|:-----|
| **x〔锚点〕** | 欲望就是x的本体定义——现象之流、不满足、永远在渴 |
| **xz** | 越界欲——想要突破边界、想要禁忌之物。欲望的临界面 |
| **nx** | 欲望被算计、被管理——为了满足欲望而进行精密筹划 |
| **zx** | 目标执行的欲望——「我要得到它，所以我做A、B、C」 |

### z面细化
| 十元候选 | 理由 |
|:-------:|:-----|
| **z** | 欲望的执念形态——「我一定要那个东西」的冲动，有边界但炽烈 |
| **zn** | 欲望被意义化——「我要这个不是因为想要，是因为它是对的」——意义包装的欲望 |
| **nz** | 欲望的依恋形态——不想失去、不愿放手、「等不及」的焦渴 |

### n面细化
| 十元候选 | 理由 |
|:-------:|:-----|
| **n** | 欲望被承载——被控制住的欲望、有底线的欲望、「够了就不拿了」 |
| **xn** | 欲望被制度化——道德、戒律、欲望的管理系统 |
| **x并z** | 欲望的伪装——「我其实不想要」、「欲拒还迎」 |

## 4. 体量 1-10

**体量 = 9.5**

欲望不是局部概念——它是整个十元体系中最底层、最基础的驱动力之一（与死亡并列为两大底层本能力量）。x是整个系统的基本操作单元。但欲望不完全等同于x（x还包括现象之流本身），因此体量给9.5而非10。

## 10. 跑动态链

### 主链（正向生成链）—— 欲望的生成与扩张

```
x(9.5) → z(8) → xz(7)
```

**释义**：流(x)生出冲动(z)→冲动推到边界(xz)。欲望从「永远不满足的渴」到「想要去追」到「想要突破边界」。这是欲望的完整生成路径：从底层涌动到具体追逐到临界突破。

### 克链（压制/反抗链）—— 欲望的克制与反噬

```
xz(7) → zn(6) → xn(5)
```

**释义**：越界欲(xz)消解欲望的意义化(zn)→被正当化的欲望(zn)打破道德规则(xn)。欲望的克链是向内自反的——欲望突破边界的冲动越大，它为自身找意义的能力越弱；而当欲望被赋予了意义，道德规则就难以约束它。

### 补链（互济链）—— 欲望的救赎

```
nx(7) ↔ n(6)
```

**释义**：欲望的清算(nx)与欲望的承载(n)构成互补。每一次欲望带来的代价都会被承载消化，而承载的容量又决定了下一次欲望的空间。清算与承载的循环是欲望系统的自稳机制。

## 11. 动态链总强度

| 链型 | 强度计算 | 总强度 |
|:----:|:--------:|:------:|
| **主链** | (9.5+8+7)/3 | **8.2** |
| **克链** | (7+6+5)/3 | **6.0** |
| **补链** | (7+6)/2 | **6.5** |

**总动态强度 = (8.2 + 6.0 + 6.5) / 3 = 6.9**

**解读**：欲望的动态强度6.9，属于系统中上。主链(8.2)显著强于克链(6.0)和补链(6.5)——欲望的核心特征不是被什么克制，而是它本身的生成力有多强。克链≈补链，说明欲望被克制的程度和它被承载/清算的强度大致相当。

**关键洞察**：欲望的克链（6.0）虽然低于主链（8.2），但克链中的每一环都是欲望的自我反噬——xz克zn（越界消解意义）、zn克xn（意义突破规则）。欲望的结构性自毁倾向不在于外部压制，而在于它内部每一步生成都同步消解自己的支撑条件。

## 14. 误判检查

### 检查1：是不是把行为当本质？
- ✅ 没有。欲望的行为（占有、追逐、越界）在步骤5中被映射到具体十元点位（z8/xz7/zx5），但步骤1的定义已经区分了本质（永不满足的「要」）与行为。
- **危险点**：不小心把「贪吃」「性欲」等具体行为等同于欲望本身。已纠正——这些是欲望的行为表达而非欲望的定义本身。

### 检查2：是不是把局部当整体？
- ✅ 欲望在步骤4被赋予体量9.5——承认它是底层力量但不等同于全部十元体系。
- **危险点**：可能把x（欲望之流）和z（追逐冲动）混淆。已区分——步骤5给x=9.5、z=8，明确一个是底层流一个是驱动力。

### 检查3：是不是把意象当结构？
- ✅ 「渴」「流」「燃烧」在步骤6-10中被用作说明意象，但映射强度基于十元星盘的几何位置关系（生/克/补），不是基于意象联想。
