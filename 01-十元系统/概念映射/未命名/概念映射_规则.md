# 概念映射：规则（2026-06-08 建立）

## 1. 一句话定义

**规则 = 秩序本身的客观化框架+时间规律的刻度化约束**——不是"什么是对的"（zn），不是"我想要什么"（z），不是"怎么算划算"（nx），而是"如果不这么执行，系统就会崩"的客观结构。规则是xn的核心本体——xn≈规则秩序+时间规律。规则在十元体系中是**本体化之前的真理**：真理是"被赋予本体地位的规则"(zn给xn盖章)，规则是"还没被赋予本体地位但已经在运行的秩序"(xn自身的客观存在)。

---

## 2. 三元粗拆（x/z/n）

| 轴 | 规则在该轴上的表达 | 说明 |
|:--|:----------------|:-----|
| **x** | 规则的执行表象、被遵守/被打破的行为场 | x提供规则被执行或被违反的场所——规则的"可见面"：谁在遵守、谁在破坏、规则在现场是什么样子 |
| **z** | 对规则的追逐/反抗冲动、被规则约束又想打破它的动力 | z是规则的最大张力源——规则的"被反抗面"：z既被规则约束（xn+z=时间主题），又想打破规则的束缚（z的冲动本质） |
| **n** | 规则的承载面、社会默认值、文化惯性 | n提供规则赖以存在的土壤——规则如果不被"默认接受"就只是写在纸上的文字，n让规则成为"大家默认这样"的社会惯习 |

**三元定位特征**：规则的核心矛盾在于——它既是xn的纯秩序（客观规则不以人的意志为转移），又被z的冲动不断挑战（被规则约束的冲动想打破它），同时被n的惯性承载（规则的社会化接受）。规则的三个面——"客观秩序"(xn)、"被反抗的冲动场"(z)、"被承载的惯习"(n)——构成了它的完整张力结构。这正是xn+z=时间主题的底层逻辑。

## 4. 体量1-10

**规则的体系体量：9**

规则不是某个十元的附属概念——它是整个十元体系的中层骨干概念。xn作为十元之一本身就是"规则秩序+时间规律"，但规则的概念比xn稍宽——它还包括规则被z挑战（z=8被规则约束又想打破它的冲动）和规则之外[nx]的暗账（nx=7.5在规则之外的暗账计算）。规则≈xn(9.5)+z(8)+nx(7.5)，即xn为核心但出xn边界到z和nx。

体量9的理由：规则触及十元体系的核心区域（xn为主轴→z为对子→nx为边界操作），但不是"哲学"(9.5)或"欲望"(9.5)级别的超级概念。规则的体量略低于真理(9)但接近——因为规则是"本体化之前的真理"(规则不需要被赋予意义就能运行，真理需要zn的认可)。

规则与真理的关键区分：
- 规则 = xn的纯秩序——"红灯停"不需要有人相信它是"对的"(zn)，只需要大家执行它(xn)
- 真理 = 被赋予本体地位的规则——"万有引力是真理"是因为它被科学界相信是客观规律(zn→xn)
- 规则可以没有zn支撑（恶法、空心制度），真理必须有zn支撑

## 10. 动态链

### 主链（正向生成链）—— n → xn → z → nx

```
n(6) → 生 → xn(10) → 补 → z(8) → 克 → nx(7.5)
  │               │               │               │
  │  社会惯习     │  规则为冲动   │  冲动烧穿     │
  │  长出规则     │  提供参照系   │  暗账计算     │
  │  "大家都这    │  "你要打破    │  "不管代价    │
  │   么做"→"规   │   什么？"     │   了，打破    │
  │   矩"         │               │   它！"       │
  └── 规则的起源 ─┴── 规则的张力 ─┴── 规则的边界 ┘
```

**规则的主链**：社会惯习(n)中自然长出规则(xn)→规则为冲动(z)提供了"可打破"的参照系→冲动(z)烧穿暗账(nx)完成规则的"被验证或被突破"闭环。这是规则从"社会默认"经过"正式制度化"到"被挑战/被突破"的完整生命周期。

补充说明：xn与z不是生克关系，是**补关系**（灵魂对子）。在动态链中，n→xn→z→nx的流向中，xn↔z之间的"补"是最核心的连接——规则为冲动提供参照系，冲动为规则提供生命力。

### 克链（压制/反抗链）—— xn 克 zx + xn 生 XZ

```
  │  执行突破     │           │  过度警觉     │
  │  "走流程，    │           │  "规矩太严    │
  │   别走捷径"   │           │   了，我必    │

  │               │           │   心"         │
```

**规则的克链**：规则(xn)压制突破(zx)——"走流程"扼杀了效率。同时，过度的规则(xn)会产生警觉(XZ)——"规矩太严了，每一步都要小心"。这是规则的"压制-副作用"链——规则的存在本身就是一种压制力量，而这个压制又会产生新的副作用（警觉/紧张）。

### 补链（互济链）—— xn ↔ z + xn ↔ nx

```
xn(10) ↔ z(8)              xn(10) ↔ nx(7.5)
  │       │                   │        │

  │ 冲动互济│                 │ 暗账互济│
  └── 时间主题 ┘             └── 规则的操作面 ┘
```

**规则的补链**：xn↔z是规则概念的灵魂补对子——规则给冲动方向感，冲动给规则生命力。xn↔nx是规则的操作层补对子——规则的明文(xn)与规则的可操作空间(nx)互相定义。
