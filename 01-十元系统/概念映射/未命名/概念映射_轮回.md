# 概念映射：轮回

## 1. 定义
轮回（Saṃsāra）——生命或意识在时间之流中不断转生、死亡、再转生的循环过程，受因缘果报驱动，直至解脱。它是一个闭环的生成—消亡—再生成系统。

## 2. 三元粗拆
- **x（形式/结构/问题面）** = 轮回的形态结构与界域划分（六道、三界、十二因缘链的形式骨架）
- **z（能量/流变/驱力面）** = 驱使轮回运转的驱动力（业力、无明、渴爱、行蕴流变）
- **n（质料/承载面）** = 承载轮回过程的转生主体与所依（神识、五蕴、业种、阿赖耶识）

## 10. 动态链3条

### 主链（生链）：无明→业力→神识→六道→生死
x并z → nz → z → zx → zn → n → nx → x → xz → xn
**路线：** 形式+驱力 → 无明渴爱 → 业力之轮 → 业力法则 → 行蕴业种 → 神识 → 六道结构 → 十二因缘链 → 生死循环 → 五蕴
**说明：** 从无明出发，经由业力驱动，生成神识与六道空间，在十二因缘链中展开生死交替，最终产生五蕴经验——这是轮回的完整生成通路。

### 克链（克链/解构链）：观十二因缘→破无明→断业力→超生死
x → x并z → nz → z → zx → nx → n → xz
**路线：** 十二因缘链 → 形式+驱力 → 无明渴爱 → 业力之轮 → 业力法则 → 六道结构 → 神识 → 生死循环
**说明：** 通过观照十二因缘的形式结构，揭示形式与驱力的一体性，直破无明，断业力惯性，超越六道与生死——这是解脱的逆向通路。

### 补链（互补链）：神识载业种⇄六道定业趣⇄生死生五蕴
n ↔ zn | nx ↔ zx | xz ↔ xn
**路线：** 神识 ↔ 行蕴业种 — 六道结构 ↔ 业力法则 — 生死循环 ↔ 五蕴
**说明：** 三组互补构成轮回的稳态结构——神识承载业种决定投生方向，六道与业力的互补框定趣向空间，生死与五蕴的互补维系经验连续性。

## 12. 归五大主题

### 时间 = xn + z （五蕴 + 业力之轮）
时间在轮回中体现为五蕴经验的相续流变，由业力之轮的惯性驱动。每一瞬间的经验（xn）都由过往的业力惯性（z）塑造。轮回的时间不是线性流逝，而是由业力编织的循环时间——过去业影响现在五蕴，现在造作又形成未来业种。

### 本体 = zn + x （行蕴业种 + 十二因缘链）
轮回的本体基础是行蕴业种的不断造作（zn）与十二因缘链的形式结构（x）。本体不是静态实体，而是缘起性空的动态过程。十二因缘链给出了轮回的本体论结构——一切存在皆因缘和合，无独立自性。

### 空间 = x并z + n （形式+驱力 + 神识）
轮回的空间是形式与驱力共同作用的心识场域。神识（n）是空间的感知中心，形式与驱力（x并z）界定了空间的性质。六道本质上是心识状态的投射——由神识的业力倾向所呈现的体验空间。

### 因果 = zx + nx （业力法则 + 六道结构）
轮回的因果机制由业力法则（zx）和六道结构（nx）共同构成。业力是因，六道趣向是果。每一行为都产生业力种子，在因缘成熟时决定六道中的投生。因果在轮回中是客观的法则性存在，非人格化的自然律。

### 命运 = xz + nz （生死循环 + 无明渴爱）
命运在轮回中体现为生死循环（xz）与无明渴爱（nz）的锁定关系。无明渴爱推动生死循环，生死循环又强化无明渴爱，形成自我强化的命运闭环。命运并非外在预定，而是内在无明驱动的惯性轨道——觉知可破。

## 15. 封存句

**轮回是缘起性空的十二因缘链在业力驱动下展开的生死相续——无主体而业种不断，无实体而五蕴相续，观照形式与驱力的一体性即见解脱之门。**
