# 概念映射：饥荒（Don't Starve）

---

## 1. 定义

**饥荒** 是一款以生存为核心的开放世界动作冒险游戏，玩家在荒野中管理饥饿、精神、生命三值，采集资源、建造基地、对抗怪物，探索永冬与黑暗的无尽循环。

**核心三元张力**：生存（秩序/延续） ↔ 荒野（混沌/熵增） ↔ 玩家（意志/干预）

---

## 10. 三条动态链

### 链A：生存链（基础循环）

```
n（营地）←→ x并z（饥饿）←→ nx（季节）←→ z（荒野）
```

**机制**：玩家在营地为生火烹饪→对抗饥饿→饥饿受季节影响→季节由荒野驱动→荒野限制营地扩张。

### 链B：战斗链（力量博弈）

```
xn（装备）←→ zx（怪物）←→ xz（洞穴）←→ nz（资源）
```

**机制**：造武器→杀怪物→下洞穴→挖资源→造更强武器→杀更强怪物。

### 链C：循环链（时间结构）

```
zn（循环）←→ x（需求）←→ x并z（饥饿）←→ nz（资源）
```

**机制**：每次循环（死亡/重生）重置需求→饥饿驱动搜资源→资源支撑营地→营地延长循环的可持续性。

## 15. 封存句

> **饥荒的十元结构揭示了一个冷酷真相：生存（x并z）不是玩家的目标，而是荒野（z）通过循环（zn）施加的拷问。营地（n）是人类对抗熵增的脆弱秩序，装备（xn）是变数中的短暂掌控，而洞穴（xz）和怪物（zx）则提醒你——这个世界从未被设计为可征服的。每一次重生都是循环（zn）对意志的嘲讽，但正是在这永恒的匮乏中，玩家找到了自己的持续存在（nz）。饥荒不是关于"活下去"，而是关于"在注定失败的游戏中，秩序如何一次次从混沌中诞生"。**
