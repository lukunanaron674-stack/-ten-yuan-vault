# 15步模板分析：「暴力」——完整映射强度分析

## 1. 一句话定义

暴力 = 以力量压服对方意志的行为——在不同十元层表现为不同形式的破坏与压制。

---

## 2. 三元粗拆（x/z/n）

| 三元 | 内容 |
|:----|:----|
| x = 形式面 | 暴力的表象、暴力的形式、暴力的工具 |
| z = 能量面 | 暴力的冲动、暴力的驱动力、暴力的效果 |
| n = 载体面 | 暴力的承载者、暴力的受害者、暴力的结构性基础 |

## 4. 体量 1-10

**体量：8.5**

暴力是人类经验的重要主题，但不是底层结构（低于欲望/死亡）。它是**底层力场的极端表达形式**——当欲望/恐惧/冲动超过阀值，暴力成为出口。

## 10. 跑动态链

### 主链（暴力的生成）
```
nx(8) → 生 → x(9) ↔ 补 → z(8.5) → 生 → zx(7.5)
```
- 暗账系统激发暴力情绪>暴力情绪与冲动互补>冲动生成工具性使用
- 链强度：(8+7+9+8.5+8.5+7+7.5)/7 = **8.0**

### 克链（暴力的压制）
```
nz(5) → 克 → x(9) → 被克 → xn(7) → 克 → xz(7.5)
```
- 柔情试图消解暴力>情绪被制度压制>制度压制临界行为
- 链强度：(5+6.5+9+5+7+7+7.5)/7 = **6.7**

### 补链（暴力的互补循环）
```
x(9) ↔ z(8.5) → xz(7.5) ↔ nx(8)
```
- 情绪与冲动互补>暴力推及临界>临界与暗账互补
- 链强度：(9+8.5+8.5+7.5+7.5+8)/6 = **8.2**

### 总动态强度
(8.0 + 6.7 + 8.2) / 3 = **7.6**

---

## 11. 动态链总强度

**7.6**——偏高。暴力的体系力量很强，补链尤其强（8.2），说明暴力最核心的特征不是单一方向的发生，而是多种破坏形式的循环放大。

## 14. 误判检查

1. ❌ **暴力 = z** — 错。z的冲动暴力只是暴力的一种形式，不是全部
2. ❌ **暴力 = x** — 不全是。x（情绪暴力）确实是最原始的，但暴力有nx（结构性）、xn（制度性）等不同层次
3. ❌ **暴力只有破坏** — 错。暴力也有结构性秩序（xn的制度暴力维持了另一种"秩序"）
4. ❌ **暴力是失控** — 不一定。zx的工具性暴力可以非常精准、可控
5. ❌ **暴力是xz** — 错。xz的临界暴力是被逼的反击，而暴力可以主动、预制、战略化
