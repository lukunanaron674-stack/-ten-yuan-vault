# 概念映射：权力（2026-06-08 重建）

## 1. 一句话定义

**权力 = 在边界上行动的能力——不是支配（那是结果），不是控制（那是工具），是决定「界内和界外」的临界行动。权力的本质不是「拥有什么」，而是「谁能划定那条线」。**

---

## 2. 三元粗拆（x/z/n）

| 三元面 | 对应内容 | 说明 |
|:-----:|:--------|:-----|
| **x** | 权力的现象流变——斗争、博弈、此消彼长 | 权力在现象层面的显现——权力的流动性和不稳定性。权力从来不是静止的 |
| **z** | 权力的驱力——「想要更多」、「不服」、「支配欲」 | 权力的核心动力——人为什么追求权力？不是因为它有用，是因为追求本身就是z的冲动 |
| **n** | 权力的承载——统治者、机构、社会结构 | 权力必须有实体才能运作——没有承载的权力只是冲动（z）或现象（x） |

## 3. x/n/z 分别细化为十元候选

### x面细化
| 十元候选 | 理由 |
|:-------:|:-----|
| **xz（锚点）** | 权力的本质——在边界上行动。划定边界、控制边界、决定谁在界内谁在界外。权力不是「我有什么」，是「我能决定谁能进这个门」 |
| **x** | 权力的现象流变——权力的斗争、博弈、此消彼长。权力在现象层面是流动的、不稳定的 |
| **x并z** | 权力的伪装——表面恭敬实际敌意、权术、表演性的权力姿态 |
| **zx** | 权力的执行——下达命令、执行统治、行使权力 |

### z面细化
| 十元候选 | 理由 |
|:-------:|:-----|
| **z** | 权力的冲动面——「想要更多」、「支配欲」、「我不服」。权力的驱动力不是理性的计算，是z的原始冲动 |
| **zn** | 权力的正当化/意义化——「为什么我该听你的」、「君权神授」。权力需要被赋予意义才能持久 |
| **nz** | 等待权力——「等待上位」、「待权」。但不是权力的核心 |

### n面细化
| 十元候选 | 理由 |
|:-------:|:-----|
| **n** | 权力的承载——统治者、机构、社会结构。权力需要被「承载」才有实体——没有机构的权力只是个人权威 |
| **xn** | 权力的制度化/规则化——法律、制度、官僚体系就是权力的规则化形态 |
| **nx** | 权力的清算——权力被推翻、革命、「清算旧势力」。权力的反面——权力可以被颠覆 |

## 4. 体量 1-10

**体量 = 9**

权力不是底层驱力（低于欲望9.5/死亡9.5），但它是人类社会的终极组织原则——谁来决定边界，谁就在行使权力。体量9的理由：
- 权力覆盖了从个人到社会到政治的所有层面——不是一个局部概念
- 但权力不独立于边界存在——它依赖「边界」作为前置条件，因此体量无法触及9+

## 5. 每个十元点位的映射强度

| 十元 | 映射强度 | 理由 |
|:----:|:-------:|:-----|
| **xz** | **9** | **锚点**。权力的本质——在边界上行动。xz的「临界行动」完美匹配权力：权力就是「在边界处做决定」的能力。谁划定那条线，谁就在行使权力。权力的核心不是「你听我的」，是「我来决定什么可以、什么不可以」 |
| **z** | **7** | **可用**。权力的冲动面——「想要更多」、「不服」、「支配欲」。权力如果只有制度没有冲动，就会变成空洞的规则；z给了权力「想扩张」的动力 |
| **n** | **7** | **可用**。权力的承载——统治者、机构、社会结构。权力需要实体才能运作——一个人有权力可能是因为他的职位/军队/财富，这些都是n的承载 |
| **zx** | **7** | **可用**。权力的执行——下达命令、执行统治。权力的「行使」面——但zx只是权力执行的方式，不是权力的定义本身 |
| **xn** | **6** | **可用**。权力的制度化——法律、制度、官僚体系。制度是权力的规则化形态，但制度≠权力——制度是权力的化石 |
| **nx** | **6** | **可用**。权力的清算——权力被推翻、革命。权力的反面定义了权力的脆弱性 |
| **x** | **5** | **中性**。权力的现象流变——权力的斗争、博弈。权力在现象层面是流动的，但这不是权力的本质 |
| **zn** | **5** | **中性**。权力的正当化——「为什么我该听你的」。权力需要意义包装，但正当化不是权力本身 |
| **x并z** | **5** | **中性**。权力的伪装——表面恭敬实际敌意、权术表演。权力需要外壳，但外壳不是核心 |
| **nz** | **3** | **弱**。等待权力——「等待上位」。权力的被动面，但远不如xz的主动面重要 |

### 映射强度排序

```
xz(9) > z(7) = n(7) = zx(7) > xn(6) = nx(6) > x(5) = zn(5) = x并z(5) > nz(3)
```

## 10. 跑动态链

### 主链（正向生成链）—— 权力的生成与扩张

```
xz(9) → z(7) → n(7) → xn(6) → nx(6) → xz(9)
```

**释义**：在边界上行动(xz)→边界上的行动激发了扩张的冲动(z)→冲动需要被承载才有实体(n)→承载稳定后制度化为规则(xn)→规则会被清算/挑战(nx)→新的边界行动(xz)重新划定。权力的核心循环：边界->冲动->承载->制度->清算->新的边界。权力不是静止的「拥有」，是永不停息的「划定→固化→被挑战→重新划定」。

### 克链（压制/反抗链）—— 权力的收敛与反噬

```
n(7) 克 xz(9) → xz(9) 克 zn(5) → nx(6) 克 x并z(5)
```

**释义**：承载结构(n)压制权力边界的流动性(xz)→纯权力消解了正当性(zn)→清算(nx)揭开权力的伪装(x并z)。权力的克链揭示了它的结构性自毁：制度让权力僵化→僵化的权力不再需要正当性→正当性的缺失让权力可以被清算。

### 补链（互济链）—— 权力的自持

```
xz(9) ↔ nz(3) → z(7) ↔ xn(6)
```

**释义**：权力边界与权力等待互补→权力的冲动需要制度框架来收束。权力的持久性来自边界行动(xz)与等待(nz)的节奏感——不能一直在边界上行动（会烧尽），也不能一直在等（会被推翻）。

## 11. 动态链总强度

| 链型 | 强度计算 | 总强度 |
|:----:|:--------:|:------:|
| **主链** | (9+7+7+6+6+9)/6 | **7.3** |
| **克链** | (7+9+5+6+5)/5 | **6.4** |

| 主题 | 公式 | 权力对应 |
|:----|:----|:--------|

## 13. 主题归仓强度

| 主题 | 强度 | 归仓理由 |
|:----:|:----:|:---------|
| **命运 xz+nz** | **9.5** | 权力就是命运型的核心——在边界上行动(xz9)+等待被权力覆盖(nz3)。权力的本质不是「支配」，是「在临界中」——谁在边界上，谁就在命运中 |
| **时间 xn+z** | **7.5** | 制度(xn6)与冲动(z7)的张力——权力的制度化需要时间沉淀，权力的冲动在时间中爆发 |
| **因果 zx+nx** | **7** | 执行(zx7)与清算(nx6)——权力的行使必有果，权力的滥用必有报 |
| **本体 zn+x** | **6.5** | 正当性(zn5)与流变(x5)——权力需要被赋予意义才能持久 |

### 主题排序

```
命运(9.5) > 时间(7.5) > 因果(7) > 本体(6.5) > 空间(5)
```

**主归主题：命运〔9.5〕**——权力的本质是命运式的：谁在边界上、谁在等、谁被排除，这就是权力的走向。权力不是因为你想拥有就有——它在你没选择的时候就已经在边界上等你了。

## 14. 误判检查

### 检查1：是不是把行为当本质？
- ❌ 权力的行为（命令、统治、支配）≠ 权力的本质
- ✅ 确认：xz(边界行动)是权力的本质——不是「我命令你做什么」，而是「我来决定你能做什么」

### 检查2：是不是把局部当整体？
- ❌ 只看到权力的「制度面」(xn)或「冲动面」(z)而忽略权力的「边界面」(xz)
- ✅ 确认：权力不是制度（xn≠权力）、不是冲动（z≠权力）、不是执行（zx≠权力）——权力是「决定边界的行动」，这是xz独有的

### 检查3：是不是把意象当结构？
- ❌ 「王座」「权杖」「皇冠」等意象 ≠ 权力的结构关系
- ✅ 确认：所有映射基于十元位置盘的几何关系

### 检查4：权力与「支配欲」(z)是否混淆？
- ⚠️ 危险——权力不等于「想要权力」。z的「支配欲」只是权力的驱力，不是权力本身
- ✅ 区分：z=权力冲动(7)，xz=权力本质(9)——冲动驱动权力的扩张，但权力的核心是边界行动

## 15. 封存句（带映射强度版）

**权力 = xz〔9〕锚点的边界行动（决定界内与界外）被z〔7〕的扩张冲动驱动，被n〔7〕的社会结构承载，借zx〔7〕的执行行使，制度化为xn〔6〕的规则，终被nx〔6〕的清算挑战——主归命运〔9.5〕主题，总动态强度6.7。权力不是「我命令你做什么」，是「我来决定谁能进这个门」。**
