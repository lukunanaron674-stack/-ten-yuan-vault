# 15步模板分析：「家」——完整映射强度分析

## 1. 一句话定义

家 = 归属的空间化——不是物理场所，是"可以回去"的关系性空间。

---

## 2. 三元粗拆（x/z/n）

| 三元 | 内容 |
|:----|:----|
| x = 形式面 | 家的物质形式——房子、家具、一顿饭的姿态 |
| z = 能量面 | 为什么想要家——归属的冲动、回家的欲望 |
| n = 载体面 | 家作为承载——安全、尊严、可以脆弱的地方 |

---

### x面

| x | 占有家的欲望——"这是我的家"的领地感 | 5 |
| xn | 家的制度——家长制、家规、家庭结构 | 5.5 |

### z面
| 十元 | 映射 | 强度 |

| n | 家的承载——日常、吃饭、睡觉、可以不说话的地方 | **9** |

| nx | 家的暗面——家庭暴力、家庭算计 | 4.5 |

---

## 4. 体量 1-10

**体量：8.5**

"家"是十元体系中最有趣的概念之一——它极度跨十元但极难归入单一十元。它涉及日常（n）、情感（nz）、外壳（x并z）、丧失（xz）多个维度。

## 10. 跑动态链

### 主链（家的形成）
```
x并z(7) → 补 → n(9) ↔ 补 → nz(9)
```
- 外壳成为家>家有了日常>日常生出了等待
- 链强度：(7+8+9+9.5+9)/5 = **8.5**

### 克链（家的瓦解）
```
xz(7.5) → 被克 → nz(9) 等不到→ x(5) → 克 → n(9) 被克 → 崩塌
```
- 回不去消解了等待>欲望吞没了日常
- 链强度：(7.5+8+9+5+5+9)/6 = **7.3**

### 补链（家的循环）
```
n(9) ↔ x并z(7) → z(5.5) → zx(5) → 生 → n(9)
```
- 家需要外壳>冲动生成行动>行动回归承载
- 链强度：(9+8+7+5.5+5+5+9)/7 = **6.9**

### 总动态强度
(8.5 + 7.3 + 6.9) / 3 = **7.6**

## 14. 误判检查

1. ❌ **家 = n** — 半对半错。n是家的承载面但不是全部。没有nz（有人等）的家只是房子
2. ❌ **家 = x并z** — 错。外壳不等于家——装修精美的房子如果没人等就不是家
3. ❌ **家 = 物理空间** — 错。物理空间是载体，家的本质是关系性
4. ❌ **所有房子/建筑 = 家** — 错。房子是n的空间类型之一但"家"有nz的等待属性
5. ❌ **家 = 故乡** — 家可以是故乡（物理性）也可以是关系性（父母所在的公寓）
