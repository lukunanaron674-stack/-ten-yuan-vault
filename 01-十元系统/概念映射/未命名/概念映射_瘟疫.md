# 概念映射：瘟疫

## 第一步：定义

**瘟疫** → 一种在群体中快速传播、造成大规模病患与死亡的恶性流行病。它突破了人体的防御边界（n），撕裂了社会结构（x），同时激发出强烈的生存驱力与集体情绪（z）。瘟疫的本质是**无序的扩张性消耗**——它以质料（人体/社会资源）为燃料，以空间传播为路径，以时间为衰减轴，最终指向系统的崩溃或免疫重构。

---

## 第二步：三元粗拆

| 元 | 对应 | 说明 |
|---|---|---|
| **x（形式结构）** | 传播网络、隔离制度、医疗体系、社会秩序、流行病学模型 | 瘟疫如何被组织、控制、建模的结构层面 |
| **z（能量驱力）** | 求生本能、恐慌、愤怒、集体动员、免疫反应的能量 | 瘟疫激发的驱动力量——人与社会的能动反应 |
| **n（质料承载）** | 病原体、受感染的身体、死亡人数、医疗物资、环境载体 | 瘟疫的物质基底——病毒、细胞、尸体、资源 |

## 第十步：3 条动态链

### 链1：感染爆发链（瘟疫的自发过程）

```
n₁(病原体) 
  生 → xn(传播拓扑x₁+受感染身体n₂) 
      生 → xz(医疗架构x₃+求生意志z₁) 
          克 ← n₁(病原体)同时克之 (拉锯)
              生 → n₃(死亡) via zn(免疫+病原体)
                  生 → z₂(群体恐慌)
                      生 → z₅(社会动员) via x并z(信息+恐慌)
```

**叙事**: 病原体出现→感染传播→医疗系统与求生意识启动→免疫战争产生死亡→死亡引发恐慌→恐慌催生社会动员。

### 链2：防御崩溃链（系统被击穿）

```
n₁(病原体) 
  克 → xz(医疗架构x₃+求生意志z₁) [击穿]
      → n₂(受感染身体)暴增
         → n₃(死亡)暴增 via zn
            nz(死亡+免疫) 克 → x₃(医疗架构) [二次击穿]
               nx(环境+拓扑) 克 → x并z(隔离+求生) [三次击穿]
                  系统溃败
```

**叙事**: 病原体击穿医疗系统→身体大量感染→死亡暴增→死亡冲垮医疗→环境传播穿透隔离→全面崩溃。

### 链3：免疫重构链（系统恢复与适应）

```
x₂(隔离制度) 
  克 → z₂(群体恐慌) [稳定情绪]
      生 → x并z(信息秩序+恐慌) [信息透明化]
          生 → z₅(社会动员) [集体行动]
              耦 x₂(隔离) + x₃(医疗) [制度强化]
                  克 → nx(环境+拓扑) [抑制传播]
                      克 → n₁(病原体) [最终压制]
                          生 → zn(免疫+病原体) [群体免疫/疫苗]
                              封存
```

**叙事**: 隔离稳定恐慌→信息透明催化社会动员→制度与医疗强化→抑制环境传播→压制病原体→免疫形成→系统获得新平衡。
