# 概念映射：进化

---

## 1. 定义

**进化**（Evolution）—— 系统在时间中通过变异、选择与遗传机制，从简单到复杂、从低适应到高适应、从无序到有序的不可逆变化过程。进化不是随机漂变，而是方向性适应与结构性创新的统一：既有随机变异（xn↔z / 自由试探）的探索，也有选择压力（zx克n / 结构淘汰）的收敛，更有遗传保存（zn生n / 质料传递）的积累。进化是十元系统中唯一同时调动全部五个时间过程（生成、克制、映射、组合、动态）的核心概念。

---

## 2. 三元粗拆

| 三元 | 角色 | 对应进化机制 |
|------|------|-------------|
| **x / 形式结构** | 秩序骨架 | 基因组结构、器官形态、行为程序、制度框架 |
| **z / 能量驱力** | 动力本源 | 生存冲动、繁殖欲望、竞争压力、资源追逐 |
| **n / 质料承载** | 物质基底 | DNA分子、生物质能、种群个体、环境资源 |

**粗拆解读**：进化是 z（能量驱力）驱动 x（形式结构）在 n（质料承载）中不断试错与沉淀的过程。没有 z 的驱动，结构停滞；没有 n 的承载，变异无处附着；没有 x 的编码，适应无法遗传。

## 6. 关系五对（25对）

### 补（共生互补）

| 关系 | 内容 |
|------|------|
| **zx ↔ nx** | 突变压 ⇋ 表型：变异倾向的变化通过表型显现表达 |
| **zn ↔ x** | 功能模块 ⇋ 基因型：模块由基因编码，基因通过模块发挥作用 |
| **n ↔ x并z** | 生物质料 ⇋ 适应度景观：质料状态约束/反映适应度势能分布 |
| **xn ↔ z** | 适应性变异 ⇋ 生存意志：变异的方向受生存驱力的引导 |
| **xz ↔ nz** | 选择压力 ⇋ 遗传物质：选择压力塑造遗传物质的构成，遗传物质记下选择历史 |

### 克（克制约束）

| 关系 | 内容 |
|------|------|
| **zx 克 n** | 突变压克制生物质料：变异过程不断改变/瓦解原有质料结构 |
| **n 克 xz** | 生物质料克制选择压力：物质限制（如物理化学极限）约束了选择可达到的范围 |
| **xz 克 zn** | 选择压力克制功能模块：选择淘汰不适应的功能模块，保留适应的 |
| **zn 克 xn** | 功能模块克制适应性变异：已固化的功能模块约束了可能的变异方向 |
| **xn 克 zx** | 适应性变异克制突变压：已适应的变异格局反过来抑制了后续盲目突变的效应 |
| **nx 克 x并z** | 表型克制适应度景观：实际表型决定了适应度的计算，而非抽象景观 |
| **x并z 克 nz** | 适应度景观克制遗传物质：景观上的位置决定了遗传物质是否被保留 |
| **nz 克 x** | 遗传物质克制基因型：遗传物质（DNA）的物理化学属性约束了基因编码的可能 |
| **x 克 z** | 基因型克制生存意志：基因决定了生物体行为的上限和表达模式 |
| **z 克 nx** | 生存意志克制表型：强烈的基本驱力压倒/遮蔽了精细的表型调控 |

### 生（生成催生）

| 关系 | 内容 |
|------|------|
| **zn 生 n** | 功能模块生成生物质料：功能模块通过代谢活动更新/补充生物质料 |
| **xz 生 xn** | 选择压力生成适应性变异：定向压力诱导/筛选出适应性变异 |
| **zx 生 zn** | 突变压生成功能模块：变异产生新的基因序列→新蛋白质→新功能模块 |
| **nx 生 x** | 表型生成基因型：表型的差异通过繁殖传递反作用于基因频率变化 |
| **n 生 xn** | 生物质料生成适应性变异：质料状态（如氧化应激）引发变异率变化 |
| **x并z 生 z** | 适应度景观生成生存意志：景观的高度差异激发生物体的生存冲劲 |
| **xn 生 xz** | 适应性变异生成选择压力：群体中出现的有利变异改变了选择梯度 |
| **z 生 nz** | 生存意志生成遗传物质：生存与繁殖的需求驱动DNA复制与传递 |
| **x 生 x并z** | 基因型生成适应度景观：基因型的分布决定了群体在适应度景观上的位置 |
| **nz 生 z** | 遗传物质生成生存意志：遗传信息编码了生物体的基本行为程序 |
