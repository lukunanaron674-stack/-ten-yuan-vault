# 【x 信息量卡 v2】

> **x 的本体是把对象、资源、地盘、权力或关系纳入“归我、我方、由我掌握”的边界。**

## 1. 核心本体

```text
对象被切定
→ 进入“我 / 我方”的归属范围
→ 主体取得占有、使用、调配或控制权
→ 即使不公开显现，控制关系仍然成立
```

### 最短定义

> **x = 归我掌握。**

x 关注的不是主体是否醒目，而是：

- 什么属于我或我方。
- 什么在我的控制范围内。
- 哪些资源、地盘、关系和权力由我调配。
- 内外边界怎样被切定。

## 2. x 不是什么

- x 不是黑暗、邪恶或反派气质。
- x 不是无方向的欲望流。
- x 不是“停不下来就会消失”的吞噬机器。
- x 不是公开显威、征服和骑到别人头上，那是 zx 的高显影。
- x 不是安排计划、流程和时间，那是 xn。
- x 不是顺着别人给出的方向继续，那是 nx。

欲望、吞噬、收藏、扩张等行为只有在明确指向“纳入我的范围、归我支配”时，才可作为 x 的血肉，不能再反过来充当 x 的主骨。

## 3. 两个标准锚点

### 3.1 《楚人之弓》

```text
楚人失弓，楚人得之。
```

该材料的核心不是炫耀、战斗或执行，而是归属范围：

```text
对象仍在“楚人 / 我方”的边界内
→ 归属没有离开我方
→ x 成立
```

因此《楚人之弓》是 x 的归属边界标准材料。

### 3.2 唐人街幕后 Boss

幕后 Boss 不必亲自出面，也不必让所有人看见自己：

```text
钱在他手里
地盘归他
手下听他调配
关系网由他控制
规则最终服务于他的范围
```

这正是 x：**权力与对象已经归其掌握，但权能未必公开显现。**

幕后控制不再归 nx。暗中安排流程与节点时可带 xn；公开显威、逼所有势力低头时才进入 zx 高显影。

## 4. x 与 zx

```text
x：有权、掌握、归我。
zx：显权、扩大、凌驾于他者之上。
```

| 场景 | x | zx |
|---|---|---|
| 幕后控制整片地盘 | 成立 | 未必成立 |
| 公开登场让所有势力低头 | 可作为底层控制权 | zx 高显影 |
| 收藏资源并锁入私人范围 | 成立 | 未必成立 |
| 把权能推到所有人头上 | 不足以单判 | zx 成立 |

判断切口：

> **是在强调“东西归谁”，还是在强调“谁的力量压过所有人”？**

## 5. x 与 xn

```text
x：哪些对象和权限归我掌握。
xn：我怎样把信息、时间、流程和资源组织起来持续运行。
```

一个老员工主动调配局部资源、维护自己负责的范围时，可带少量 x；主动排程、搭流程、预判节点的主体仍是 xn。不能因为“掌握工作”就把 xn 全部改判为 x。

## 6. x 与 nx

```text
x：占据归属、资源或控制位置。
nx：不占据方向决定权，沿别人或关系网络给出的方向继续。
```

唐人街幕后 Boss 是 x，不是 nx。老板安排什么就做什么的员工是 nx，不是 x。

## 7. 人物、行为、场景分层

### 人物本体 x

长期依靠掌握对象、资源、地盘、权限或关系范围成立；拿掉“归我控制”的结构，人物的存在方式明显崩塌。

### x 行为

- 占有。
- 收拢资源。
- 划定内外。
- 调配归属范围内的人与物。
- 保护或扩大自己的控制范围。

### x 场景

- 私人领地。
- 地盘与势力范围。
- 仓库、金库、收藏室。
- 被某个主体实际掌握的地下网络。

题材和道具不能单独证明 x，必须说明归属与控制关系。

## 8. 误判防线

以下不能单独判 x：

- 很贪婪。
- 很黑暗。
- 会吃东西或吞噬。
- 是资本家、地主、反派或 Boss。
- 藏在幕后。
- 有控制欲这一个形容词。

必须检查：

```text
对象是否进入“我 / 我方”的归属边界？
主体是否拥有实际占有、使用、调配或控制权？
拿掉这种掌握关系后，案例是否不再成立？
```

## 9. 召回版

```text
x = 归我掌握。
《楚人之弓》说明归属边界。
唐人街幕后 Boss 说明不必显眼也能控制整个范围。
x 是有权，zx 是显权并骑到他者之上。
```
