# 十元生克补卡总控 v2.0

> 信息卡确认端点是什么；准度卡确认为什么必须判成该端点；每条生、每条克、每组补分别进入独立关系卡。总控只导航，不承载完整关系正文。

## 1. 三个独立目录

- 生：[[生/README_十元生卡索引_v1.0]]，10张单条生卡。
- 克：[[克/README_十元克卡索引_v1.0]]，10张单条克卡。
- 补：[[补/README_十元补卡索引_v1.0]]，5张单组补卡；每卡内部拆两个补向。

## 2. 每轮写入目标

```text
本轮关系对应单卡（必写或明确无新记忆）
→ 源/目标信息卡（本体变化时写）
→ 源/目标准度卡（判定边界变化时写）
→ 核心表、词典、专项正本（达到95%并改变正式机制时写）
→ 滚动中枢
→ 唯一运行账本
```

## 3. 关系类型最小差异

- 生：目标此前不足或不存在；源使目标自身核心变量出现或持续上升。
- 克：目标关系前真实存在；源使其核心能力、资格、边界或调用下降。
- 补：两端独立存在；一端补入后改变另一端的真实结构缺口，拿掉后原端仍在但缺口重现。

## 4. 卡片双版本

每张单卡维护理论`version`和`memory_record_version`。理论结论没变时不涨理论版本；运行新增有效复核记忆时才涨记忆版本。提交自引用使用`last_memory_commit: SELF`，实际SHA写入Git历史与运行账本。

## 5. 七项置信度

分别记录源端点、目标端点、机制、独立证据、竞争解释排除、拿掉/反向可逆性、跨案例复现，最终取最弱项。七项均不低于95%才允许锁定。
