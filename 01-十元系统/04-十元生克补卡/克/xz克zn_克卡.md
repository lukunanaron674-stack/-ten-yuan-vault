# xz 克 zn｜单条克卡 v0.2

## 当前结论

**仍未锁定。** 新xz定义要求先证明火药桶式整体蓄积、触发敏感与系统级爆发；随后还要证明这场爆发持续撤销`zn`的自身成立资格，而不只是暂时压制、损伤或迫使策略调整。

## 当前候选机制

### 候选A｜整体爆发摧毁自身成立条件

```text
xz高压整体被触发
→ 爆发从局部扩展到全局
→ zn赖以自成体的内部连续性、材料条件或原则资格被破坏
→ 安全恢复后仍无法按原本方式独立成立
```

### 候选B｜仅造成状态压制

```text
xz爆发
→ zn暂时无法表达、实践或维持
→ 压力解除、材料补齐后zn恢复
```

候选B不构成稳定克，只能判状态压制、损伤或调用受阻。

## 达到95%还缺什么

1. xz源端点必须按新卡成立，不能只靠危险逼近或一次爆发；
2. 触发后确有系统级连锁，而非局部切割或单次损伤；
3. zn的自身成立资格下降，而非只换策略、暂停表达或缩窄条件；
4. 压力解除、能力恢复、资源补齐和安全场景恢复后，zn仍不恢复；
5. 冻结新事实、反证、道德反省、身份变化和关系破裂后，下降仍由xz解释；
6. 至少两类不同xz火药桶与zn模板复现同一持久撤销机制。

## 被改变变量候选

- zn内部连续性；
- 自成体资格；
- 原则未来调用权；
- 材料或结构自持能力；
- 跨情境复现资格；
- 安全恢复后的可逆性。

## 固定测试

- **最近邻**：普通损伤、创伤回避、策略调整、条件细化、x直接切割、zx主动压制；
- **拿掉**：拿掉整体蓄积与触发连锁，只保留局部伤害；若zn仍下降，则不由xz解释；
- **反向**：降低压力、隔离触发、恢复资源后，zn若恢复，只能判状态压制；
- **第三因素**：事实证伪、道德反省、身份变化、能力下降、关系破裂和新规则介入。

## 否定或降级条件

- 只有危险逼近与退路减少；
- 爆发后zn在安全环境中恢复；
- 下降主要由x式切割或zx式主动压制造成；
- 原原则仍被认为正确，只是暂时不敢调用；
- 没有跨对象、跨阶段复现。
