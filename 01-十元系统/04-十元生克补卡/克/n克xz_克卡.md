# n 克 xz｜单条克卡 v0.2

## 当前锁定机制

> **n以真实承载、容纳、隔离、泄压和持续处理，把原本耦合在一起的危险拆回可局部管理的部分，降低整体蓄积、触发敏感度与局部牵动全局的概率，从而克制xz火药桶。**

```text
真实承载与持续处理（n）
→ 隔离触发点、分散压力、吸收冲击
→ 切断局部到全局的连锁
→ 整体危险蓄积和触发敏感下降
→ xz被克制
```

## 被下降变量

- 整体压力与危险储量；
- 触发敏感度；
- 节点耦合度；
- 局部事故传播率；
- 系统级爆发概率；
- 爆发后的不可逆损失；
- 恢复原状的成本。

## n必须提供什么

- 可持续承载，而非一次获救；
- 对压力或危险的实际吸收与分配；
- 对触发节点的隔离、缓冲或降敏；
- 对连锁反应的切断；
- 可停留、补给、恢复或重新组织的内部空间。

## 红线

以下不等于n克xz：

- 封路、锁门、拘禁；
- 把危险暂时藏起来但压力继续累积；
- 单次救援；
- 仅让敌人无法到达；
- 只拖延爆发时间；
- 压制表达却提高系统内部压力。

这些操作甚至可能让火药桶更危险。

## 固定测试

- **最近邻**：xn防护流程、短暂隐藏、敌人撤退、资源补给、纯封锁；
- **拿掉**：拿掉承载、泄压和持续处理，只保留墙、门或停留位置；若xz仍下降，则不支持本关系；
- **反向**：承载退出、触发隔离解除或压力重新耦合后，整体敏感度与连锁风险应回升；
- **第三因素**：危险源消失、时间暂停、力量增强、信息隐藏、外部救援。

## 与旧机制的关系

危险可达性、退路和时间压力可以作为外部指标，但新主变量是：

```text
整体蓄积
触发敏感
局部到全局的连锁
```

只有真正降低这些变量，才是n克xz。
