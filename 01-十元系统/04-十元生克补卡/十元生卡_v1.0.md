# 十元生卡 v1.0

> **生 = 源端点通过明确机制，使目标端点原本不足或不存在的核心变量出现、持续上升，或获得新的稳定运行资格。**

## 1. 必要条件

```text
A在关系前真实成立
B的目标变量在关系前不足、空缺或较低
A通过可说明机制改变B
B出现的是自身核心端点，不只是一次行为、表情、结果或进入概率
拿掉A后，B的新生或上升明显减弱
反向恢复A的关键机制时，B变化可重复
```

以下不是生：

- A与B共现；
- A先发生、B后发生；
- A提供普通资源，B自己完成；
- A只是让B更显眼；
- B本来就稳定存在，只是在当前场景显影；
- 一个主题、五行位置或几何箭头直接推出案例。

## 2. 十条生位与当前状态

| 生位 | 状态 | 当前最短口径 |
|---|---|---|
| zx 生 zn | 未锁定 | 公开高成本权能行为能否使此前不存在的原则命题与最终指导资格新生，仍缺纯例 |
| x并z 生 z | 已锁定 | 稳定公开壳提供可识别对象与归因接口，使重要认可能够正确落到主体 |
| zn 生 n | 已锁定 | 不可抛下的意义撤回拒绝与推出资格；对象跨阶段留存并被持续处理，形成承载 |
| z 生 nz | 未锁定 | 认可是否生成双方可信停靠与回返，而非单方关注、评价或预测模型延续 |
| n 生 xn | 已锁定 | 反复承载负荷迫使主体把经验提炼为顺序、分工、记录、节点与预案 |
| nz 生 nx | 未锁定 | 可信停靠是否使最终方向资格不可达，而非认识性信任、委托或资格主动闲置 |
| xn 生 xz | 已锁定 | 结构识别并持续处理偏差，关闭安全路线与时间窗，使危险逼近 |
| nx 生 x | 未锁定 | 方向空位是否真正生成代理者独立处分资格，而非历史授权、知识瓶颈与关键人依赖 |
| xz 生 zx | 已锁定 | 危险使旧决定中心失效并形成决定空位；主体连续作出决定且被执行，形成临时公开决定接口 |
| x 生 x并z | 已锁定 | 已成立掌握边界为被识别、调用、代表或保护而形成稳定公共壳 |

## 3. 已锁定生位快速调用

### 3.1 x并z 生 z

```text
稳定身份壳、作品形式或公开界面形成
→ 认可主体获得可识别对象与归因接口
→ 存在、能力、作品、身份或选择被正确指认和确认
→ z成立或上升
```

目标变量：对象可识别性、归因稳定度、认可对象清晰度。曝光、点击、宣传和一次换装不足。

### 3.2 zn 生 n

```text
主体确认某对象不能被抛下
→ 撤回拒绝与推出资格
→ 对象跨阶段留在内部
→ 主体持续处理其现实负荷
→ n成立或上升
```

一次善举、收留、口号、建筑和捐助不足。`zn`不直接生成房屋、资金、流程或成熟共同体。

### 3.3 n 生 xn

```text
对象已被真实接住并持续产生负荷
→ 同类负荷重复、并发或增加
→ 临场处理不足
→ 主体主动提炼顺序、分工、记录、节点、资源与预案
→ xn成立或上升
```

外部制度早已存在、上级命令轮班、一次事故临时分工均不足。

### 3.4 xn 生 xz

```text
xn规定正常时间窗、路线与身份接口
→ 偏差被识别、记录并持续处理
→ 安全路径、退路和可用时间逐步减少
→ xz临界风险上升
```

必须证明危险真正可到达、时间窗或路线下降，不是普通守规则和紧张氛围。

### 3.5 xz 生 zx

```text
危险使旧决定中心失效
→ 出现公开决定空位
→ 主体连续作出至少两项不同层面的最终决定
→ 他者实际执行并停止等待旧中心
→ 临时公开决定接口成立
```

只允许生成状态层或关系位置层的临时`zx`接口，不得写成危险凭空生成能力、勇气、领导人格或稳定本体。

### 3.6 x 生 x并z

```text
实际掌握边界已经成立
→ 需要被世界识别、调用、代表或保护
→ 名称、职位、品牌、制服、法人身份、门面或前台角色形成
→ 掌握关系获得稳定公共壳
```

一次包装、视觉门面和无实际掌握的头衔不足。

## 4. 未锁定生位红线

### zx 生 zn

必须区分：行为样本、观察者释义、共享文化模板、原则命题、原则选择、可信度、权重、承诺和最终指导资格。多个观察者说出同一口号，若依赖共同话语模板，不等于行为生成原则。

### z 生 nz

必须分别证明：被认可者具有对象特异关系价值；认可者提供无请求、非评价性的关系投入；双方跨阶段维护；关系可自由退出、回返与修复。关注、验证判断、预测对方和维护自我形象不是完整`nz`。

### nz 生 nx

必须证明的不是“更愿意听对方”，而是低成本退出、第三判断者可用、原对象连续犯错时，否决、换人、私下分叉和重设标准的资格本身不可达。长期不用资格不等于资格消失。

### nx 生 x

必须排除历史授权、合同、密码、职位、隐性知识、关键人依赖、协调瓶颈和原主体接管能力下降。只有代理者在公开撤权、第三方知情、程序关闭、能力补回后仍以自身资格排除原主体并跨新对象处分，才接近真实生成。

## 5. 拿掉测试

```text
拿掉源端点，只保留资源、教学、职位、制度、危险或关系背景。
拿掉目标的既有本体，确认不是原有端点显影。
拿掉共同第三因素，检查B是否仍由A出现。
恢复关系前条件，检查B是否回落。
换人物、场景或文化模板，检查机制能否复现。
```

## 6. 反向测试

- B在A出现前已稳定存在：优先判显影、补位或共现。
- 去掉A后B仍由同一第三因素生成：生关系失败。
- A只提高B被看见、被调用或进入场景的概率：检查`x并z/z/xn`接口，不直接判生。
- B只出现一次状态，条件解除即消失：最多是状态层生成，不得升级稳定本体。
- 反向改变A的关键机制，B目标变量随之反向变化：支持生关系。

## 8. 召回版

```text
生不是先后，不是帮助，不是显影。
生必须证明：A通过机制，使B自身的核心变量从不足走向出现或持续上升。
```
