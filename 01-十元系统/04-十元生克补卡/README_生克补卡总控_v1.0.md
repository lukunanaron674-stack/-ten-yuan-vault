# 十元生克补卡总控 v1.0

> 信息卡先确认端点，准度卡再确认端点判得准不准；只有两个端点都真实成立，才允许进入生卡、克卡、补卡。

## 1. 三张关系卡

- [[十元生卡_v1.0]]：A通过明确机制，使B的核心端点新生或上升。
- [[十元克卡_v1.0]]：A通过明确机制，使B的核心变量下降、失效、退出资格或无法继续调用。
- [[十元补卡_v1.0]]：A与B各自独立成立，彼此补足真实结构缺口，但不互相生成或消灭。

## 2. 固定启动条件

任何关系必须写清：

```text
源端点
目标端点
作用机制
被改变的目标变量
成立阶段
体量T / 显影M / 关系作用量E
显影条件
至少两种候选机制
正例与反例
最近邻排除
拿掉测试
反向测试
动态链只改变哪一层感觉走向
```

缺任何关键项，只能保留为几何位置、候选关系或未判定。

## 3. 关系与共现的边界

```text
A和B同时出现 ≠ A补B
A先出现、B后出现 ≠ A生B
A伤害、反对或阻碍B ≠ A克B
A帮助B完成剧情 ≠ A补B
同一人物拥有A和B ≠ 关系已经启动
视觉对比、台词对照、主题并列 ≠ 生克补
```

必须说明：**A通过什么机制，改变了B的哪个核心变量。**

## 4. 正本优先级

```text
十元信息卡正本总览
→ 十元准度卡
→ 本目录三张总关系卡
→ 十元生补克表
→ 关系专项正本索引
→ 旧审计、案例与视觉卡只作证据
```

关系状态以`十元生补克表`和`关系专项/README_十元关系专项正本索引.md`为最终准绳。本目录负责快速判断与调用，不得把未锁定关系写成正式机制。

## 5. 三种关系最小差异

| 类型 | 核心问题 | 目标变量方向 | 端点前提 |
|---|---|---|---|
| 生 | A是否使B原本不存在的核心端点出现，或使其持续上升？ | 生成 / 上升 | B可在关系前不足或不存在 |
| 克 | A是否使B的核心能力、资格、边界或调用下降？ | 下降 / 失效 | B关系前必须真实存在 |
| 补 | A与B是否各自存在，并填补对方独立存在时的结构缺口？ | 缺口被补足 | 两端不能由彼此定义 |

## 6. 关系置信度

分别记录：

1. 源端点稳定度；
2. 目标端点稳定度；
3. 机制清晰度；
4. 独立证据强度；
5. 竞争解释排除度；
6. 拿掉 / 反向可逆性；
7. 跨案例复现度。

最终置信度取最弱项。只有全部不低于95%，才允许锁定正式机制。

## 7. 动态链纪律

关系卡只说明端点之间的作用。动态链只记录这种作用怎样改变：

- 本体调用；
- 状态；
- 行为选择；
- 关系位置；
- 安全感、归宿感、时间感、空间感或因果感走向。

不得把生、克、补写成机械生成勇气、成长、背叛、成功、爱情、人格崩坏或剧情结局的按钮。
