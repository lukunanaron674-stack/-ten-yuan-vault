# 十元补卡 v1.0

> **补 = 两个端点各自独立成立，其中一端补入后，改变另一端独立存在时的真实结构缺口；它们不互相生成、不互相消灭，也不要求固定先后。**

## 1. 必要条件

```text
A与B的定义互不依赖
至少一端在补位前已独立成立
该端存在可观察的结构缺口
另一端补入后，缺口变量真实改善
拿掉补入端，原端仍存在，但缺口重新出现
双向补位必须分别记录变量，不能用一句“互相帮助”带过
```

以下不是补：

- 两个十元同框或属于同一人物；
- A帮助B完成任务；
- A提供普通资源、情绪安慰或一次救援；
- 五大主题公式直接反推案例关系；
- 生与克同时出现后取平均；
- 角色性格互补、颜色互补、男女搭配或视觉平衡。

## 2. 五组现行补位

| 补位组 | 状态 | 核心缺口 |
|---|---|---|
| zx ↔ nx | 已锁定 | 直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补 |
| zn ↔ x | 已锁定 | 内部意义方向，与具体对象、资源、处分和现实掌握边界互补 |
| n ↔ x并z | 已锁定 | 真实承载内部，与可识别、可进入、可持续指认的公共界面互补 |
| xn ↔ z | 已锁定 | 跨时间可复核证据，与明确认可位置、材料筛选和阶段收束节点互补 |
| xz ↔ nz | 已锁定 | 真正失去与窗口关闭的风险，与可回返对象、关系终点和归宿方向互补 |

## 3. zx 补 nx / nx 补 zx

```text
zx：直接以主体自身权能做成，公开决定、推进、扩张和压过障碍。
nx：承认既有身份、关系、权限和通道，通过请求、借力、人情、旧交与他者力量办成。
```

方向变量必须分开：

```text
nx 补 zx：改变zx是否拥有间接路径、外部权限接口、救兵、关系通道与非正面解决方案。
zx 补 nx：改变nx借到的资源和通道能否被主体重新转成实际行动、公开决定与结果推进。
```

成立条件：一端单独运行时出现明确路径缺口；另一端补入后解决该缺口。领导与服从、强弱搭配、求人一次和普通协作不足。

标准锚：孙悟空直接战斗与显权为`zx`；找菩萨、土地、龙王、天庭、借法宝和请救兵为`nx`；借到力量后重新行动，形成双路径完整性。

## 4. zn 补 x / x 补 zn

```text
zn：为什么值得掌握、守护、限制、使用或放弃。
x：具体什么归我、由我调配、在哪条边界内落实。
```

方向变量：

```text
zn 补 x：改变掌握用途、守护与放弃标准、否决权服务的原则。
x 补 zn：改变意义的现实落点、可保护与持续投入的对象范围、明确的我方边界。
```

意义不会自动制造资源；拥有资源不会自动产生意义。必须证明一端存在而悬空，另一端补入后形成“知道为什么守，也确实掌握能被守住的对象与边界”。

## 5. n 补 x并z / x并z 补 n

```text
n：内部真能接住、容纳、处理并持续存在。
x并z：外部能够识别、进入、理解、调用和持续指认。
```

方向变量：

```text
n 补 x并z：改变壳内部是否有真实承接内容、公开承诺与内部实际是否连接。
x并z 补 n：改变外界能否识别和进入承载结构、进入边界是否可理解、内部能否被同一名称持续指认。
```

漂亮装修、建筑内外、制服、门牌、产权挂牌与品牌广告不足。关键是“外部可读，内部真能接住”。

## 6. xn 补 z / z 补 xn

```text
xn：跨时间组织、记录、复核和重复呈现。
z：谁认可、认可什么、在哪个重要精神位置完成确认。
```

方向变量：

```text
xn 补 z：改变认可材料的连续性、稳定度、可复核性，以及认可者区分运气和稳定能力的能力。
z 补 xn：改变长期组织的聚焦对象、材料筛选标准、阶段收束节点、最终呈现内容和下一周期修正依据。
```

准备久了不必然获奖；被表扬后也不必然开始努力。考试日期、一次称赞、广告曝光、播放量和绩效奖励不足。

## 7. xz 补 nz / nz 补 xz

```text
xz：关系可能真正失去、返回窗口可能关闭的危险与命运压力。
nz：明确的可回返对象、可信停靠、关系终点与归宿候选。
```

方向变量：

```text
xz 补 nz：改变关系失去的可能性、返回窗口有限性、继续等待是否经过风险检验、停靠是否成为主动选择。
nz 补 xz：改变风险路径的方向性、值得返回的对象、穿越风险的理由、漂流能否收束为关系终点。
```

危险与暖光同框、追兵逼近后突然告白、一次获救、普通依恋和避难所收留不足。`n克xz`负责安全承载；`xz↔nz`负责失去风险与关系归宿之间的缺口互补。

## 8. 拿掉测试

对每组补位分别做：

```text
拿掉A：B是否仍存在，但出现可明确命名的缺口？
恢复A：该缺口是否改善，而不是只增加资源或显影？
拿掉B：A是否也独立存在并出现另一方向缺口？
冻结共同第三因素：爱情、任务、危机、制度、职位、资源、视觉和主题公式。
换场景：同一缺口是否仍可被另一端补足？
```

若拿掉一端后另一端也完全不存在，可能是生关系、共同前因或定义重叠，不是补。

## 9. 反向测试

- 两端各自成立，但互不改变缺口：只是并列。
- A出现后B核心端点才从无到有：优先检查生。
- A出现后B核心变量下降：优先检查克。
- A只提供钱、房子、工具、安慰或一次帮助：先检查资源与行为层。
- 双向变量不能分开说明：补位判定不完整。
- 拿掉一端，另一端仍存在但明显残缺；恢复后缺口可重复改善：支持补位。


## 11. 召回版

```text
补不是同框、帮助和性格互补。
补必须证明：A、B各自存在；拿掉任一端，另一端仍在但有真实缺口；补回后缺口被改变。
```
