# xz 生 zx｜单条生卡 v0.2

## 当前锁定机制

> **xz火药桶被触发后，原本蓄积在整体中的力量、风险或冲突从临界静止转为主动释放；若主体或新中心把这股释放组织成明确方向并让他者实际执行，zx临时公开权能成立。**

```text
整体高压与触发敏感（xz）
→ 触发发生，旧稳定结构爆开或失效
→ 出现决定空位与必须外推的力量
→ 主体连续作出最终决定并被执行
→ zx成立
```

## 被改变变量

- 蓄积力量释放率；
- 决定空位；
- 最终决定范围；
- 他者执行率；
- 旧中心等待程度；
- 临时公开权能接口稳定度。

## 红线

- xz爆发不自动生成zx；
- 纯失控、混乱、崩坏或情绪爆炸仍可能只有xz；
- 必须出现明确主动方向、最终决定和外部执行；
- 不得写成危险凭空生成稳定领导人格或永久能力；
- 若主体只是被爆发推着走，优先检查nx或状态层。

## 固定测试

- **最近邻**：纯xz失控、既有能力显影、职业职责、xn流程授权、x资源掌握；
- **拿掉**：拿掉xz蓄积与触发后，若主体仍按既有职位主动指挥，则不支持本关系；
- **反向**：旧中心恢复或爆发压力解除后，临时zx接口应回落或重新受限；
- **第三因素**：正式任命、军衔、专业资格、预案、既有服从关系。

## 证据门槛

1. xz端点在触发前已成立；
2. 触发导致旧结构失效或决定空位；
3. 主体不是只爆发，而是主动推出至少两项不同层面的最终决定；
4. 他者实际执行并停止等待旧中心；
5. 危机解除后临时zx应回落，除非有独立机制将其稳定化。
