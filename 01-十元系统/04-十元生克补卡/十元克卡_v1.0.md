# 十元克卡 v1.0

> **克 = 源端点通过明确机制，使目标端点原本真实存在的核心能力、资格、边界、可达性或调用权下降、失效或退出。**

## 1. 必要条件

```text
目标B在关系前真实存在
源A在指定阶段真实运行
A通过可说明机制触碰B的核心变量
B下降的是自身能力、资格、边界或调用，而非只是不高兴、失败、受伤或暂时没显影
拿掉A的关键机制后，B下降应明显减弱或恢复
```

以下不是克：

- A与B立场相反；
- A伤害、打败、拒绝或批评B；
- B暂时不行动；
- 画面上一个压住另一个；
- 剧情先失败后成功；
- B的资源减少，但核心端点仍完整；
- A只使B换策略、换场景或降低显影。

## 3. 已锁定克位快速调用

### 3.1 zx 克 n

```text
zx主体公开显权并决定成员资格、接收边界或结构运行条件
→ n原有接收、保护、照顾、互信与反复返回能力被迫停止
→ n承载能力下降、断裂或失效
```

目标变量：成员资格、接收边界、照顾连续性、互信、反复返回与结构抗崩能力。

### 3.2 x并z 克 nz

```text
稳定身份壳持续替真实主体承接关系证据
→ 对方把回应、承诺、共同时间与回返意愿归因给壳或错误身份
→ 真实主体无法占据可信回返位置
→ nz下降
```

仅有秘密、伪装或一次误会不足；必须证明关系证据的归因接口被稳定污染。

### 3.3 zn 克 xn

```text
某项结构与不可让渡意义发生直接冲突
→ 主体撤回“这套结构值得被主动维护”的资格
→ 自愿执行、修复、覆盖与复制下降
→ xn被克制
```

违反一次规则、情绪反抗和结构效率下降不足；必须改变维护资格。

### 3.4 n 克 xz

```text
n已形成真实接收、保护、处理与持续维持能力
→ xz主体进入承载范围
→ 危险被隔开、吸收或持续处理
→ 可停留、补给、恢复和返回位置增加
→ 危险可到达性与行动紧迫度下降
```

封路、拘禁、锁门和剥夺出口只证明路径封锁；“不能移动”不等于“被接住”。

### 3.5 nz 克 x

```text
掌握者承认某段对象特异关系具有回返与共同位置
→ 主动收窄独占、替代决定、否决和调用边界
→ 对方重新获得退出、选择与自我处分空间
→ x掌握边界下降
```

被迫让权、法律撤权、资源不足和讨好关系不足；核心是关系端点使掌握者主动缩权。

### 3.6 xn 克 zx

```text
现实已被时间、规则、流程与前置行动组织
→ zx即时显权扩张必须进入既有结构
→ 单次爆发不能取消长期积累
→ zx当下决定范围和扩张效率下降
```

制度题材、守规则和慢节奏不足；必须证明长期结构真实限制即时权能。

### 3.7 x 克 z

```text
x主体掌握认可发生所必需的对象、署名、引见、发布、传播或回应接口
→ 扣留、垄断、改署、隔离或关闭
→ 认可主体看不到对象，或把对象归因给他人
→ z无法获得正确确认
```

自然低曝光、作品未完成、认可者不感兴趣和普通资源不足均不足。

## 4. 未锁定克位红线

### z 克 nx

必须证明认可不是只提供自信、表达许可、教学、资源、路线或一次行动启动，而是最终判断资格、标准修订权、临时标准生成权与失败责任跨阶段回到主体。人物若只是执行认可者内化的标准或“忠于自己”的元规则，`nx`未必下降。

### nx 克 x并z

必须分开：事实索引壳、制度资格壳、静态第三方调用、持续表演壳、单次互动令牌、构成性认证与证据性认证。拒绝一次自称、签署或表演，只能终止依赖该动作的即时壳；不得倒写成既存事实、制度资格和稳定公共壳整体下降。

### xz 克 zn

必须分开：原则正确性、未来调用授权、当前调用、行动策略、适用谓词、风险记忆、创伤回避、身份退出、多原则排序和元原则重写。危险后避开原场景，不等于原则在其他安全情境中的未来资格被撤销。

## 5. 拿掉测试

```text
拿掉源端点，只保留伤害、失败、资源减少或视觉压迫。
恢复目标的资源、能力、时间与显影机会，检查核心资格是否仍下降。
冻结第三因素：制度、职位、危险、教学、创伤、关系破裂与新事实。
将源端点反向撤回，检查目标变量能否恢复。
换场景但保留同一核心端点，检查克制是否跨情境成立。
```

## 6. 反向测试

- B只是换策略、暂时不调用或降低显影：克关系不足。
- 条件恢复后B立刻重新运行：优先判状态压制或通道关闭。
- A撤回后B核心资格恢复：支持克关系。
- B下降主要由第三因素解释：克关系失败。
- B从未真实存在：不能判被克，只能判未生成或缺失。

```text
克不是反对、伤害、失败或视觉压住。

```
