# n ↔ x并z｜单组补卡

## 两端独立成立

- `n`：内部真能接住、容纳、处理并持续承担负荷。
- `x并z`：外部能识别、进入、理解、调用并持续指认。

## n 补 x并z

补入壳内部的真实承接内容，使公开承诺与内部实际连接，改变`x并z`单独存在时空壳、假入口或只有外观的缺口。

## x并z 补 n

补入外界可识别和进入的界面、可理解的进入边界及稳定名称，改变`n`单独存在时内部能接住但外部无法找到、进入或持续指认的缺口。

## 红线与测试

漂亮装修、制服、门牌、产权挂牌和品牌广告不足。拿掉任一端，另一端必须仍成立，但重新出现“外部可读/内部真接住”的对应缺口。
