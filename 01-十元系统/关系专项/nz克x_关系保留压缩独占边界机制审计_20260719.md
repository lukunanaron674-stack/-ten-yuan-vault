# nz 克 x｜关系保留压缩独占边界机制审计

## 0. 审计结论

几何位置 `nz 克 x` 保留，但正式机制未达到95%门槛。

已高置信确认：

1. 旧“贤惠妻子管不住赌鬼丈夫”不是有效正例，且实际上写的是失败关系。
2. `nz克x` 不能写成“因为爱所以放弃财产”。
3. 若本关系成立，被改变变量必须是 x 的独占、否决、调用或关系掌握边界，而不是对象物理消失。
4. 关系必须排除 nx 让位、zn 道德牺牲、zx 强制剥夺、被迫失去和普通赠与。

未锁定原因：现有案例均难以排除 n、zn、nx、zx 或反向 `x克nz`；尚不能证明 nz 本身是直接启动源，而不是既有亲情、道德原则或剧情任务。

## 1. 对象分层

| 层级 | nz | x |
|---|---|---|
| 稳定本体 | 长期维持关系余温、不愿承认关系结束 | 长期依靠对象、资源、权限、地盘或关系“归我掌握”成立 |
| 当前状态 | 此阶段舍不得结束、保持靠近或保留关系位置 | 此阶段收紧、维持或放松掌握边界 |
| 行为功能 | 等待、保留、靠近、维持联系 | 占有、否决、调配、划定归属 |
| 光影 | 暖光、旧物、停靠空间 | 钥匙、边界、私人领地、所有权标记 |
| 场景 | 家庭、旧居、告别、重逢 | 财产、职位、权限、关系控制 |
| 时间关系 | 关系先有温度，随后出现掌握变化 | 先后本身不足以证明克制 |
| 关系位置 | 恋人、亲人、旧友、守望者 | 所有者、家长、上级、权限持有人 |
| 显影 | 不愿结束强度、关系保留需求 | 独占度、否决权、调用权、边界宽度 |
| 动态链 | 从“我要留住这段关系”转向“我不能继续只按归我掌握处理对象” | 不自动生成赠与、和解或永久共享 |

## 2. 端点、变量与成立条件

### 源端点 nz

必须已经存在一段有时间厚度、余温与不愿结束的关系。单纯善良、一次心软、家庭题材或被迫等待均不足。

### 目标端点 x

必须存在明确掌握关系：对象、资源、权限、地盘或关系由某主体占有、调用、否决或划界。

### 被改变变量

- 独占程度；
- 对他者的排除权；
- 否决与调用边界；
- “归我”是否被改写为“可共同使用、可让渡、可归还”；
- 关系是否仍被当作可控制对象。

### 成立阶段

1. x 的掌握边界已经成立；
2. nz 关系保留需求随后显影；
3. 主体发现继续坚持独占会令关系结束或失去余温；
4. 掌握边界因此主动缩小、开放或归还；
5. 变化不是外部强制、交易、道德命令或流程规定造成。

### 体量

- 低体量：允许一次共享或暂缓行使否决权；
- 中体量：持续开放资源、权限或关系位置；
- 高体量：主体重新定义“归我”的边界，使对象从私人掌握转成共同关系承载。

## 3. 候选机制

### 候选 A：关系保留压缩独占

```text
nz 不愿让关系结束
→ 主体意识到继续坚持“只能归我”会切断关系
→ 主动放松排除权、否决权或独占调用
→ x 的掌握边界缩小
```

理论后果：`nz克x` 改变的是独占强度，不必消灭所有权。

### 候选 B：对象重新归类为关系共有

```text
对象原本处于私人掌握边界
→ 长期关系使对象承载共同时间与双方位置
→ 主体不再把对象只当“我的东西”
→ 对象进入共同使用、共同记忆或可归还边界
→ x 下降
```

理论后果：目标变量是归属边界重写，而不是情绪感动。

### 候选 C：因爱牺牲或赠与

```text
人物爱对方
→ 把钱、房子或机会给对方
```

不接受为充分机制。可能是 zn 的“这样做是对的”、nx 的主动让位、z 的目标推进、交易行为或剧情任务。

## 4. 正例候选

### 4.1 《飞屋环游记》卡尔，营救罗素阶段

- x：房屋、家具与艾莉遗物长期处于卡尔的私人掌握边界。
- nz：他既不愿结束与艾莉的关系余温，也逐渐不愿失去与罗素形成的新关系。
- 行为变化：为了让房子重新升空并营救罗素，他主动抛弃家具，放松对物件的占有。
- 可观察结果：物件仍有意义，但不再必须以“全部归我并完整保留”的方式维持关系。
- 第三因素：营救任务含 z/zx；对艾莉承诺含 zn；因此只能作复合候选。

### 4.2 《老爷车》沃尔特，遗嘱阶段

- x：Gran Torino 是沃尔特明确拥有并严密守护的私人对象。
- nz：与涛的长期相处形成不愿让关系在自己死亡后彻底结束的余温。
- 行为变化：他将汽车留给涛，主动解除对象只归自己的边界。
- 可观察结果：对象从私人占有转成关系延续载体。
- 第三因素：道德判断、补偿、遗嘱安排与 zn/xn 很强，不能证明纯 nz 启动。

### 4.3 纯结构候选：共同记忆物的归还

一位老人长期独占两人共同创作的底片。旧友病重后，他为了不让关系只以争夺结束，主动允许对方家人复制并归还部分原件。

若拿掉“关系不愿以断裂收场”，开放边界不会发生，则支持候选 A/B；但仍需排除道德补偿与法律压力。

## 5. 反例

1. **因法院判决分割财产**：x 下降，但启动源是制度与权限，不是 nz。
2. **因为善良把钱送人**：若核心是“这样做是对的”，优先检查 zn。
3. **员工把决定权交给上级**：若不主动占位，优先检查 nx，不是 nz。
4. **恋人威胁分手迫使交出密码**：主要是 zx 强制或关系勒索，不是柔情停靠。
5. **人物破产后失去房产**：是被迫失去掌握，不构成克制机制。
6. **“贤惠妻子管不住赌鬼丈夫”**：只说明 nz 未能改变 x，且把 x 错写为泛欲望；不得继续作为本关系案例。

## 6. 最近邻排除

### 与 nx 让位

- nx：主体不占据方向决定权，顺着他者或关系安排推进。
- nz克x：主体原本拥有掌握边界，因不愿关系结束而主动压缩独占。

### 与 zn 牺牲

- zn：因为内部意义判断而放弃掌握，即使关系对象不存在也会这样做。
- nz：关键是“不这样做，这段关系会结束或余温会被切断”。

### 与 zx 剥夺

- zx：他者公开显权，强迫主体交出对象或权限。
- nz克x：掌握者主动缩小边界，不以外部压服为启动源。

### 与反向 x 克 nz

x 也可能通过占有、控制和排他要求压坏关系余温。若掌握先强化、nz 随后崩解，应写 `x克nz` 的候选动态，不得倒写。

## 7. 拿掉测试

1. 拿掉 nz 的关系保留需求，主体仍会因法律、利益、道德或任务放弃掌握，则案例不依赖本关系。
2. 拿掉 x 的独占、否决或调用边界，只剩普通情感和赠礼，则没有目标端点。
3. 拿掉外部强制后，主体仍主动开放边界，才可能支持 nz 克 x。
4. 拿掉关系将结束的风险后，主体仍照样让渡，可能是稳定 zn 或 nx。
5. 拿掉具体对象与权限变化，只剩“心变软了”，不能判克制成立。

## 8. 反向测试

交换为：

```text
x 克 nz
```

候选机制是：主体把人、关系或共同物严格纳入“归我掌握”，提高排他与控制，令柔情停靠失去自愿性和余温。

方向区别：

- `nz克x` 改变掌握边界；
- `x克nz` 改变关系余温、不愿结束与自愿停靠。

现有作品中反向关系往往更容易成立，因此正向案例必须严格证明启动源。

## 9. 动态链后果

```text
这些东西、权限或关系位置原本归我
→ 我发现继续只按“归我掌握”处理，会让这段关系真正结束
→ 我主动缩小独占边界
→ 对象不再只是我的东西，而成为关系仍能继续的接口
```

改变的感觉层是：从占有维持存在，转成通过开放边界维持关系。

不表示：

- 爱会自动消灭所有权；
- 柔情天然反资本或反财产；
- 放弃对象就一定是 nz；
- nz 必然能够压过高体量 x；
- 关系保留一定健康或正确。

## 10. 三元与十元并行

三元继续核验作品整体精神感受；十元只核验具体阶段、端点、变量与方向。不得由“为爱让出物品”反推人物稳定三元，也不把 nz 与 x 写成父子派生。

## 11. 95%门槛

### 已达到高置信

- 旧失败案例必须撤回；
- 目标变量必须是独占、否决、调用与归属边界；
- 必须排除 nx、zn、zx、制度强制和被迫失去；
- 物品转移本身不等于 `nz克x`。

### 未达到95%

- 候选 A 与 B 是同一机制的两个阶段，还是两种独立机制；
- 现有具体作品案例均含 zn、z、zx 或 xn；
- 仍无法排除“关系只是动机，真正改变 x 的是道德判断或任务行动”。

因此本轮状态：几何位置保留，正式机制未锁定，不修改生补克表与关系词典，不新增待用户确认问题；当前属于材料不足与纯度不足，不构成必须由用户裁决的明确二选一。
