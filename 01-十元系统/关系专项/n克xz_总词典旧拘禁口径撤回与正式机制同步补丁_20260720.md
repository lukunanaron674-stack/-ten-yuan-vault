# n 克 xz｜总词典旧拘禁口径撤回与正式机制同步补丁

## 1. 本轮裁定

正式沿用既有专项正本：

```text
n 已形成真实接收、保护、处理与持续维持能力
→ xz 主体进入有效承载范围
→ 危险被隔开、吸收或持续处理
→ 主体获得真实停留位置，不再必须沿风险路径继续移动
→ 危险可到达性、行动紧迫度与漂流强度下降
→ n 克 xz
```

最短表达：

> n 不是通过关住漂流者克 xz，而是通过接住漂流者、替其承担危险并让其可以停止赶路来降低 xz。

本补丁不改写 n 或 xz 的定义，只撤回总词典残留的拘禁口径，并把正式专项接入现行读取顺序。

## 2. 对象分层

| 层级 | n | xz | 本轮约束 |
|---|---|---|---|
| 稳定本体 | 长期接收、容纳、处理并抗崩 | 长期在危险边缘且难稳定停留 | 不从一次收留或逃亡反推 |
| 当前状态 | 此阶段正在接住、保护、补给 | 此阶段危险逼近、退路缩窄 | 本关系主要可在阶段层观察 |
| 行为功能 | 开门、救治、补给、掩护、值守 | 逃离、抢窗口、穿越风险路径 | 行为不能替代端点 |
| 光影 | 暖室、围墙、内部灯光 | 风雨、追踪光、倒计时 | 仅作显影 |
| 场景 | 家庭、社区、医院、避难所 | 公路、边境、追捕路线 | 场景名称不自动判十元 |
| 时间关系 | n 实际运行并接收主体 | xz 已先显形或正在显形 | 先后仍须有变量变化 |
| 关系位置 | 居民、医生、守门人、接收者 | 逃亡者、漂流者、临界行动者 | 身份称谓不代替功能 |
| 显影 | 接收范围、抗崩能力、安全时间 | 危险可达性、移动紧迫度、退路宽度 | 两端均须可观察 |
| 动态链 | 世界出现能承担压力的内部 | 所有地方不再只是下一段逃生路线 | 不自动生成依恋或永久安全 |

## 3. 源端点、目标端点与变量

### 3.1 源端点 n

至少具备一项稳定承载能力：

- 接收进入者而非推出；
- 提供内部位置；
- 承担保护、照护、补给或处理；
- 在外部压力下保持一定抗崩；
- 允许主体不必立即再次离开。

建筑、围墙、家庭、医院和收容所只是场景候选。只有实际接收并处理负荷时才构成 n。

### 3.2 目标端点 xz

至少出现一项临界变量：

- 危险可感知地逼近；
- 安全路线减少；
- 无法稳定停留；
- 不行动便会被追上、吞没或错过窗口；
- 主体被迫持续沿风险路径移动。

旅行、陌生感、身份焦虑或黑暗气氛不能替代 xz。

### 3.3 被改变变量

1. 危险对主体的可到达性；
2. 安全停留时间；
3. 必须继续移动的紧迫度；
4. 可用退路与安全路径数量；
5. 外部冲击直接落到主体身上的比例；
6. 主体能否从“通道上的人”变为“内部被接住的人”。

### 3.4 成立阶段、体量与显影

成立阶段：

```text
xz 已显形
→ n 已实际运行
→ 主体进入承载范围
→ 危险可到达性或继续移动紧迫度下降
```

体量：

- 低体量：短时急救、藏身、补给；
- 中体量：安全屋、家庭或社区持续接收；
- 高体量：稳定聚落、后方或保护网络长期吸收风险。

显影条件：危险更难直接抵达、主体得到治疗与休息、安全时间增加、无需立即寻找下一条路线，或可以反复返回而非只穿过。

## 4. 候选机制

### 候选 A：危险隔离与冲击吸收

```text
n 位于危险与主体之间
→ 墙体、成员、资源或照护能力承担外部冲击
→ 危险不能直接落到主体
→ xz 逼近强度下降
```

理论后果：n 的核心是承担本会压到主体身上的压力，不是限制主体自由。

### 候选 B：漂流落地与行动紧迫解除

```text
xz 主体原本必须不断移动
→ n 提供可停留、补给、恢复与返回的位置
→ 主体不再必须抢下一条路线或最后窗口
→ 风险路径的强制性下降
```

理论后果：外部危险可以仍存在，但只要主体能够停下并被接住，xz 已局部下降。

### 统一机制

> n 一方面替主体承受危险，另一方面提供内部位置，使主体不再必须靠继续移动来维持存在。

### 正式排除：拘禁与路径封锁

```text
制度、权限或强权把主体关住
→ 主体无法移动
```

无法移动不等于被承载。审核、封路、驱逐、命令、锁闭与剥夺出口应优先检查 xn、x、zx 或 xz 本身。

## 5. 正例

### 5.1 《最后生还者》乔尔与艾莉进入杰克逊聚落

- 关系双方：杰克逊聚落与乔尔、艾莉；
- 阶段：二人长期穿越感染区后进入已经运行的聚落；
- n：住房、供电、巡逻、食物、医疗、成员分工与接收关系；
- xz：危险持续可达、无法稳定停留、必须不断寻找路线；
- 结果：聚落承担防御、补给与居住，安全停留时间上升，继续赶路的紧迫度下降。

汤米的引见含 nx，聚落制度含 xn，但目标变量“能否停下并由结构承担危险”由 n 直接改变。

### 5.2 《行尸走肉》瑞克一行进入亚历山大安全区初期

- 关系双方：亚历山大安全区与瑞克一行；
- 阶段：长期在公路和临时据点移动之后；
- n：围墙、住房、水电、食物、医疗与成员位置；
- xz：外部危险随时可达、无法稳定休息；
- 结果：能够睡觉、洗澡、补给，不再每天寻找临时营地，外部风险先由围墙与社区防御承担。

后续安全区被攻击不否定该阶段的克制，关系不承诺永久安全。

### 5.3 运行中的灾后避难所

洪水与失温逼近，居民必须不断转移。已经运行的避难所接收居民，提供高地、床位、医疗、食物与值守。居民无需继续夜间寻找路线，危险可到达性和移动紧迫度下降。

## 6. 反例

1. **签证制度拦住流浪者**：规则、审核与权限限制移动，属于 xn/x；没有接收、保护或安全停留。
2. **收容所把流浪猫关进笼子**：若只有捕捉和锁闭，没有照护与风险缓冲，只是拘禁。
3. **恋人让逃亡者不想离开**：改变的是关系结束意愿，优先检查 nz；危险仍可直接到达。
4. **空房子供一次躲藏**：只有空间外观，没有持续承载与处理能力。
5. **监狱终止漂流**：通过强制关闭路径，可能反而使无退路和危险临界增强。
6. **暴风自行停止**：xz 自然结束，不依赖 n。

## 7. 最近邻排除

### 与 nz / xz↔nz

```text
nz：我想留下
n：这里接得住我，所以我可以留下
```

nz 改变关系结束意愿与回返对象；n 改变危险能否抵达及现实停留条件。

### 与 xn

门禁、巡逻表、登记和分工属于 xn 行为。只有它们最终形成真实接收、保护和抗崩能力时，才构成 n 端点。

### 与 x

“这里归我，别人不能进”属于地盘和权限掌握。若只排除外人、不承担内部成员，不是 n。

### 与 zx

英雄冲入危险把人带走是行动与显权。被救者进入持续承载结构后，才启动 n 克 xz。

## 8. 拿掉测试

1. 拿掉接收、保护和处理能力，只留建筑，xz 若仍下降，则不依赖 n。
2. 拿掉外部危险，主体本来即可停留，则没有 xz 目标端点。
3. 拿掉墙、成员、补给与照护后，主体又必须移动，支持本关系。
4. 拿掉情感依恋，主体仍因结构安全而停下，排除 nz 替代。
5. 拿掉规则和命令，只要承载仍能实际运行，说明不以 xn/zx 为必要源端点。

## 9. 反向测试

交换为 `xz 克 n`：

```text
持续危险、追杀或灾难
→ 超过承载结构接收与抗崩能力
→ 成员撤离，照护与保护中断
→ n 下降
```

方向不对称：

- n 克 xz 改变危险可到达性、行动紧迫度与漂流强度；
- xz 克 n 改变容器的接收、保护和持续运行能力。

同一故事可以形成反馈，但必须分阶段记录。

## 10. 动态链后果

```text
危险不断逼近
→ 主体只能不停向前，任何地方都只是通道
→ 一个结构真正接住主体，并替其承担外部压力
→ 主体第一次不需要靠继续逃跑维持存在
```

改变的感觉层是：

> 世界从“所有地方都只是下一段逃生路线”，转成“终于出现一个能够把危险留在外面的内部”。

不机械生成依恋、归属、永久安全、人物稳定本体变化或必然获救。

## 11. 三元与十元并行

三元继续独立核验作品整体精神运动。

十元只核验：

- n 是否形成真实承载；
- xz 是否处于危险逼近与风险路径；
- 危险可到达性与移动紧迫度是否下降；
- 关系方向是否正确。

不把 n 写成 xz 的父级，不从局部收留反推稳定三元或十元本体。

## 12. 95%门槛

### 通过：98%

理由：

- 正式专项已以 97% 锁定；
- 两端点与现行 n、xz 口径一致；
- 候选 A、B 可统一为“承担危险 + 提供内部停留位置”；
- 两个具体人物阶段与一个结构例可观察目标变量；
- 六个反例排除拘禁、制度阻拦、情感停靠、空间外观和自然结束；
- 最近邻、拿掉测试与反向测试通过；
- 本轮只同步正式机制，不新造理论定义。

本轮不新增待用户确认问题。
