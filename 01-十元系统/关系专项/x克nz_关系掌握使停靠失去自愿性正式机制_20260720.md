# x 克 nz：关系掌握使停靠失去自愿性正式机制

## 0. 结论

> **x 把关系对象纳入“归我决定、由我调用、不能自由退出”的掌握边界，使继续停留不再是自主选择，回返也不再能证明关系余温，由此克制 nz。**

该关系只锁定于关系层与阶段层，不表示所有 x 人物必然破坏所有关系，也不表示一次嫉妒、一次争吵或一次限制就足以克制 nz。

---

## 1. 关系对象分层

| 层级 | x | nz | 审计要求 |
|---|---|---|---|
| 稳定本体 | 长期依靠归属、占有和掌握边界成立 | 长期保留关系余温与回返姿态 | 不从一次控制或一次不舍反推本体 |
| 当前状态 | 此阶段收紧关系控制 | 此阶段停靠意愿下降 | 正式机制主要发生层 |
| 行为功能 | 替代决定、限制退出、控制交往与路线 | 等待、回返、继续靠近 | 必须出现自主停靠变量变化 |
| 光影 | 门锁、定位、密码、封闭空间 | 暖光、旧物、回望、旧居 | 只作显影，不代替端点 |
| 场景 | 亲子、伴侣、监护、家庭 | 旧爱、家、共同生活 | 题材不能直接判关系 |
| 时间关系 | 掌握边界先持续收紧 | 余温随后受损 | 先后不自动证明克制 |
| 关系位置 | 掌握者、家长、伴侣、管理者 | 被停靠者、返回者、旧关系对象 | 必须处于同一关系结构 |
| 显影 | 否决、独占、调用和退出控制上升 | 自愿停留、回返和不愿结束下降 | 两端变量均需可观察 |
| 动态链 | “你在我的范围内” | “我还愿不愿回来” | 不机械生成分手或仇恨 |

三元与十元并行核验。三元只处理作品整体精神运动，不从本关系反推人物固定三元，也不把本体主题与命运主题建立父子派生。

## 2. 源端点与目标端点

### 2.1 源端点 x

必须存在具体关系掌握：

- 替对方决定行动、交往、身体、身份或人生路线；
- 掌握进入、退出和返回的许可；
- 拥有并实际使用最终否决权；
- 把对方视作“归我管理、由我保护、由我调用”的关系对象；
- 即使不公开显权，控制关系仍然有效。

以下不足以单独判 x：

- 普通吃醋；
- 一次争吵；
- 一次建议；
- 一次临时保护；
- 只有控制欲形容词，没有实际权限变化。

### 2.2 目标端点 nz

在克制发生前必须已经存在：

- 真实共同时间；
- 关系余温；
- 不愿承认关系结束；
- 等待、回返或继续停靠的姿态；
- 对某个具体关系位置的温柔保留。

### 2.3 被改变变量

1. 停留是否仍为自主选择；
2. 离开与返回是否仍由关系主体自己决定；
3. 回返能否继续证明“我还想回来”；
4. 共同生活是否从柔情关系变成管理关系；
5. 对原关系位置的安全感与可信度；
6. 不愿结束是否转化为想要逃离、躲避或切断联系。

## 3. 成立阶段、体量与显影条件

### 3.1 成立阶段

```text
关系已经形成余温
→ 掌握者持续收紧决定、退出和回返边界
→ 被掌握者的停留不再能被视为自愿
→ 原关系位置从可返回处变成被管理范围
→ nz 下降
```

### 3.2 关系体量

- **低体量**：少量事项被代决，停靠意愿轻微下降，仍能协商修复。
- **中体量**：交往、时间与行动路线被持续控制，回返开始带有被迫意味。
- **高体量**：退出权、身份与人生路线被纳入掌握，关系形式仍在，但 nz 已被压成逃离欲或断裂。

### 3.3 显影条件

必须同时满足：

- 原本存在 nz；
- x 掌握边界真实增加；
- 对方的自主停留、退出或回返权真实下降；
- nz 的等待、回返与不愿结束实际下降；
- 排除 zx 暴力、xn 监控流程、法律强制和原本无余温等第三因素为唯一启动源。

## 4. 候选机制

### 候选 A：自愿性被抽空

```text
x 收紧关系掌握
→ 留下、离开与返回都受控制
→ “仍然留在这里”不再能证明主体愿意停靠
→ nz 失去最关键的自愿性证据
→ 余温下降
```

**理论后果：**

nz 的核心不是物理停留，而是仍愿意为关系保留位置。x 可以让人继续留在场景中，却同时使 nz 消失。

### 候选 B：关系位置被管理位置替代

```text
掌握者持续替对方决定
→ 对方在关系中不再作为独立主体出现
→ 共同生活从“我们之间”变成“你在我的范围内”
→ 原关系位置被管理关系替代
→ nz 无处停靠
```

**理论后果：**

被改变的不是距离，而是关系对象的资格。对方仍可能住在同一屋檐下，却不再觉得那里是可返回的“我们”。

### 候选 C：保护强度本身克制 nz

排除。保护若仍保留对方的自主路线，可能是 n，而不是 x 克 nz。

### 候选 D：公开威胁迫使留下

若主要依赖惩罚、威胁、暴力或公开权能，优先判 zx。x 可作为底层掌握，但不能吞掉显权机制。

### 正式统一机制

A 是直接作用过程，B 是结构结果：

> **x 先抽空停靠的自愿性，再把关系位置替换成管理位置；人仍可能被留在范围内，但 nz 已无法通过自主回返继续成立。**

## 5. 正例

### 5.1 《海底总动员》马林与尼莫，影片前段至离开珊瑚礁阶段

#### 关系双方

- **x**：马林替尼莫决定可去哪里、能做什么、能否探索，并持续使用最终否决权。
- **nz**：父子共同生活形成的亲密余温，以及尼莫原本对父亲和家的停靠。

#### 可观察变化

```text
父亲以保护为理由收紧行动边界
→ 尼莫的自主路线不断被否决
→ 家与父子关系逐渐被体验为管理范围
→ 尼莫不再愿意通过服从证明亲密
→ 冲突升级并主动离开父亲给定的安全边界
```

危险环境含 xz，父亲的照护含 n，但核心被改变变量仍是：马林的掌握使尼莫的自愿停靠下降。

#### 拿掉测试

拿掉马林的替代决定和否决边界，父子余温不需要通过逃离来争取自主，因此该变化依赖 x。

---

### 5.2 《青春变形记》明与美美，家庭仪式冲突前后

#### 关系双方

- **x**：明掌控美美的时间、朋友、身体解释权、公开形象与人生安排。
- **nz**：长期母女关系、家庭共同生活与美美原本对母亲的亲密停靠。

#### 可观察变化

```text
母亲不断扩大替代决定范围
→ 女儿的朋友、身体和身份都被纳入“由母亲决定”
→ 家庭停靠逐渐等同于放弃自己的路线
→ 美美选择离开母亲安排的仪式轨道
→ 母女余温仍在，但自愿停靠明显下降
```

本例含家庭 xn 和母亲公开压迫时的 zx 高显影，但在公开冲突之前，关系掌握本身已经持续侵蚀 nz。

#### 拿掉测试

拿掉身体、交往和身份的掌握，只保留母女关心，冲突不会以“必须离开家庭轨道才能成为自己”的方式成立。

---

### 5.3 《魔发奇缘》葛朵与乐佩，离塔前后

#### 关系双方

- **x**：葛朵掌握乐佩的空间、信息、身份解释、外界通道与离塔许可。
- **nz**：乐佩在长期共同生活中形成的母女式依恋、回返与不愿彻底失去关系的余温。

#### 可观察变化

```text
葛朵把乐佩完全纳入自己的掌握范围
→ 塔不再是可自主返回的家，而是不能自由退出的管理空间
→ 乐佩一旦获得外部路线，停靠意愿迅速转向离开
→ 原有余温无法维持原关系位置
```

身份欺骗含 x并z，威胁含 zx，但“不能自由离开”这一关系掌握变量独立成立。

## 6. 反例

1. **伴侣一次吃醋但未限制任何行动或退出权**：只有状态，没有 x 端点。
2. **家长提出安全建议，孩子保留最终决定权**：可能是 n 的保护或普通协商。
3. **暴力威胁对方不准离开**：主要是 zx 高显影，不能只写 x。
4. **安装监控系统但主体没有最终调用和否决权**：可能主要是 xn 流程或技术场景。
5. **关系原本已经没有余温**：离开只说明关系结束，不能判 nz 被克。
6. **双方自愿共享位置和账户，且均可随时撤回**：没有单向掌握边界。
7. **短期医疗监护限制行动**：若目的是接住风险且有明确退出条件，优先检查 n 与 xn。
8. **人物仍愿自主回家、保留联系并主动回返**：即使控制存在，也尚未证明 nz 下降。

## 7. 最近邻排除

### 7.1 与 zx 克 nz

- **x 克 nz**：掌握边界使停靠失去自愿性，可在低调、不公开显权时成立。
- **zx 克 nz**：公开权能、威胁或惩罚直接压迫关系主体。

最短区别：

> x 是“你归我决定”；zx 是“我公开逼你服从”。

### 7.2 与 xn 克 nz

- xn 通过流程、排程、监控和长期结构消耗关系余温；
- x 直接改变谁拥有决定、退出与调用权。

### 7.3 与 x并z 克 nz

- x并z 让主体不知道自己停靠的真实对象是谁；
- x 让主体即使知道对方是谁，也无法自由决定是否停靠。

### 7.4 与 n

n 可以接住、照护并保护对象。只有保护进入单向占有、否决和退出控制时，才越过 n 进入 x。

### 7.5 与反向 nz 克 x

- `x克nz`：掌握先加强，停靠自愿性下降。
- `nz克x`：关系余温先显影，掌握者为了保留关系主动放松控制。

二者可以构成反馈，但不能互相代证。

---

## 8. 拿掉测试

1. 拿掉 x 的实际掌握，只保留关心、建议或情绪，nz 是否仍下降？若是，不依赖本关系。
2. 拿掉 nz，关系原本没有余温，目标端点不存在。
3. 拿掉 zx 威胁和暴力，只保留低调的决定、否决和退出控制，nz 是否仍下降？若是，支持 x 直接作用。
4. 拿掉 xn 监控流程，只保留谁拥有最终权限，关系是否仍受损？若是，支持 x。
5. 恢复对方的退出、否决和自主回返权后，nz 是否回升？若是，说明自愿性是关键变量。
6. 物理上仍共同生活，但不再主动回返、不再愿意继续关系，说明“留在场景”不能代替 nz。

三个具体案例均通过核心拿掉测试。

## 9. 反向测试

交换为：

```text
nz 克 x
```

反向机制是：

```text
掌握者仍珍惜关系余温
→ 发现继续控制会让对方真正离开
→ 主动恢复对方的决定、退出和回返权
→ x 的关系掌握边界下降
```

方向切口：

- `x克nz` 的被改变变量是自愿停靠与回返意愿；
- `nz克x` 的被改变变量是独占、否决、替代决定和调用边界。

同一父子或母女关系可以先发生 `x克nz`，再发生 `nz克x`，形成反馈修复；这不是同一关系写了两遍。

## 10. 动态链后果

```text
我们原本有可以回去的关系
→ 你把我的路线、退出与返回都纳入掌握
→ 我仍留在这里，却不再是因为想留下
→ 关系从停靠变成管理
→ 我开始把离开视为恢复主体位置的必要行动
```

改变的感觉层是：

> **从“我还想回到这里”，转成“只有离开这里，我才能重新成为可以选择的人”。**

该关系不机械生成：

- 分手；
- 仇恨；
- 暴力反抗；
- 控制者必然邪恶；
- 被控制者必然彻底断情；
- 关系永远无法修复。

## 11. 三元与十元并行核验

三元只核验作品整体精神感受与大关系走向。

十元本轮只核验：

- x 是否存在具体掌握边界；
- nz 是否先有真实余温与停靠；
- 掌握是否抽空停靠自愿性；
- 对方的退出、回返和方向权是否下降；
- zx、xn、x并z、n 是否为第三因素。

不建立：

```text
x 是 nz 的父级
nz 是 x 的情感结果
本体主题自动生成命运主题
```

理由：

- x 与 nz 端点均符合现行信息量卡；
- 候选 A、B 可统一为“自愿性被抽空 → 关系位置被管理位置替代”；
- 三个具体人物案例均明确阶段、双方与可观察变量；

- 无须改写 x 或 nz 的核心定义。

正式结论：

> **x 把关系对象纳入单向掌握，使停留、离开和回返失去自主选择资格；关系因此从可自愿停靠的位置变成被管理范围，nz 的余温与不愿结束受到克制。**
