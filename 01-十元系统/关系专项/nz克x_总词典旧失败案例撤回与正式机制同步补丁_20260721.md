# nz 克 x｜总词典旧失败案例撤回与正式机制同步补丁

## 0. 补丁范围

本文件不发明新的关系定义，只同步现行正式专项到关系词典读取链。

正式读取顺序：

```text
十元生补克表中的几何位置
→ nz克x_关系余温压缩关系控制边界正式机制_20260719.md
→ 本同步补丁
→ 十元关系词典旧案例仅作历史材料
```

关系词典中的以下旧句撤回现行资格：

```text
贤惠妻子管不住赌鬼丈夫
柔情压不住欲望
nz 克 x 失败
```

撤回原因：现行 `x` 是对象、权限、资源或关系“归我掌握”的边界，不是赌瘾、欲望或失控冲动；“管不住”也不能证明 `nz` 曾作用于 `x` 的独占、否决、替代决定与调用边界。

## 1. 正式结论

> `nz` 通过“不愿让关系真正结束”的余温，使掌握者主动放松对关系对象的独占、替代决定、否决与调用边界，从而克制 `x`。

本机制首先锁定在关系掌握边界，不泛化为“因为爱所以放弃财产”。财产让渡只有在它真实改变关系控制边界时，才可作为次级显影。

## 2. 对象分层

| 层级 | nz | x | 本轮判定 |
|---|---|---|---|
| 稳定本体 | 长期保留关系余温、不愿结束 | 长期把对象、权限或关系纳入归我掌握 | 不从一次让步反推本体 |
| 当前状态 | 此阶段仍想维持停靠 | 此阶段收紧或放松控制 | 正式机制主要发生层 |
| 行为功能 | 等待、保留、回返、维持联系 | 代替决定、否决、调用、排除 | 必须改变实际边界 |
| 光影 | 暖光、旧物、回望 | 门锁、权限、监控、私人边界 | 只作显影 |
| 场景 | 亲子、伴侣、旧友、离别 | 抚养、行程、关系准入、资源控制 | 题材不能代替端点 |
| 时间关系 | 关系已有厚度 | 控制随后被主动放松 | 先后不自动证明克制 |
| 关系位置 | 不愿失去的一方 | 掌握者、家长、伴侣、权限持有人 | 必须是同一关系中的边界变化 |
| 显影 | 关系保留需求上升 | 独占、否决、替代决定下降 | 目标变量需可观察 |
| 动态链 | 为了关系仍能继续 | 不再把对方当作可完全掌握对象 | 不自动生成和解 |

## 3. 端点与变量

### 源端点 nz

必须先有真实共同时间、关系余温与“不想让这段关系结束”。一次心软、普通善良、责任感或害怕失去利益均不够。

### 目标端点 x

必须存在明确的关系掌握：

- 替对方决定；
- 控制其行动、交往或选择；
- 以“归我／属于我方”排除他者；
- 掌握最终否决与调用权；
- 把关系对象当成可被管理的对象。

### 被改变变量

- 独占程度；
- 替代决定强度；
- 最终否决权；
- 对他者自主路线的容忍度；
- 关系准入与退出边界；
- “属于我”是否改写为“仍与我相连，但不由我完全决定”。

## 4. 成立阶段、体量与显影

```text
x 的关系掌握已经成立
→ 关系对象因控制而准备离开或无法真实回返
→ nz 的“不愿关系结束”在掌握者一侧显影
→ 掌握者主动放松独占、替代决定、否决或调用
→ 对方自主离开与自主返回的空间增加
→ x 下降
```

体量：

- 低体量：取消一次非必要检查或局部否决；
- 中体量：恢复社交、行程、身份或生活选择权；
- 高体量：掌握者重写整段关系的准入、退出与自主回返边界。

显影条件：

1. 原先确有关系掌握；
2. 放松由掌握者主动完成；
3. 直接理由是“不放松，关系会真正结束”；
4. 对方的否决、退出或自主路线真实增加；
5. 排除法律强制、交易、疲惫、道德原则与外部压服。

## 5. 机制候选

### 候选 A：关系保留迫使控制退场

```text
nz：我不愿这段关系结束
→ 主体发现继续替对方决定会把对方推走
→ 主动放松独占、否决与替代决定
→ x 的关系掌握边界缩小
```

理论后果：克制的是控制关系的强度，不要求责任、保护或全部现实边界消失。

### 候选 B：停靠对象重新成为独立主体

```text
对方原本被纳入“归我掌握”
→ 关系余温使主体承认：只有对方仍能自主返回，停靠才真实
→ 对方从被管理对象重新成为独立关系主体
→ x 的对象化与调用边界下降
```

理论后果：关系被保留的条件，不是掌握更严，而是允许对方以自己的方向继续存在。

### 统一机制

候选 A 是行动过程，候选 B 是对象地位变化：

> 为了让关系仍有真实回返可能，掌握者把对方从“归我决定的对象”还原为“可以自主离开、也可以自主回来的人”。

## 6. 正例

### 6.1 《海底总动员》马林与尼莫，结尾返校阶段

- `x`：马林长期替尼莫判断风险、限制行动并控制探索范围；
- `nz`：失散与重逢后，马林明确不愿再次失去父子关系；
- 变化：他允许尼莫独自上学、参与行动并承担适度风险；
- 目标变量：替代决定、行动否决与关系控制下降。

拿掉外部危险后，结尾仍明确表现“为了让关系继续，不再完全掌握对方”。

### 6.2 《青春变形记》明与美美，演唱会冲突后的母女阶段

- `x`：明长期掌握美美的时间、交往、身体变化解释权与人生安排；
- `nz`：明真正害怕的是女儿从关系中离开；
- 变化：明允许美美保留熊猫、朋友与自己的选择；
- 目标变量：身份调用、交往否决与替代决定下降。

影片同时包含代际传统、照护与自我确认，但母亲端的直接变化仍落在“为了不失去女儿而放松归我决定”。

### 6.3 纯结构例：旧伴侣的关系准入放松

甲长期把乙的社交、行程与共同空间纳入自己最终决定。乙准备离开后，甲取消定位共享要求、放弃检查权限，并明确允许乙独立安排生活。甲的核心理由是“只有不再完全掌握你，我们才可能仍有关系”。

## 7. 反例

1. 法院判决削减监护权：启动源是制度；
2. 对方威胁分手后被迫交出密码：主要是 `zx` 或关系勒索；
3. 因道德原则放弃财产：优先检查 `zn`；
4. 因疲惫不再管理对方：只是状态下降；
5. 一次允许孩子外出：若最终否决未变，只是局部授权；
6. 正常分工与协商：双方原本均保留否决权，未必存在 `x`；
7. 财产赠与后仍严格控制受赠者：对象转移不等于关系掌握下降；
8. 关系已经结束，仅为补偿而让渡：可能是责任、交易或流程安排；
9. 赌瘾或冲动无法被伴侣劝住：源端点不是现行 `x`，也没有掌握边界下降。

## 8. 最近邻排除

### 与 zn 克 x

- `zn克x`：因为“继续掌握是不对的”而放弃，即使关系可能结束也会这样做；
- `nz克x`：因为“不放松掌握，这段关系会真正结束”而退让。

### 与 nx

- `nx`：主体不占方向位置，把决定交给别人；
- `nz克x`：原掌握者仍有行动能力，但主动缩小自己对他人的掌握边界。

### 与 zx 剥夺

- `zx`：外部主体以权能强迫交出控制；
- `nz克x`：掌握者主动退让，不依赖被压服。

### 与反向 x 克 nz

- `x克nz`：控制加强，使停靠失去自愿性；
- `nz克x`：关系余温先显影，使控制主动下降。

## 9. 拿掉测试

1. 拿掉 `nz` 后，若主体仍因法律、道德、利益或疲惫放松控制，则不依赖本关系；
2. 拿掉 `x` 后，只剩陪伴与和解，目标端点消失；
3. 拿掉外部强制后，掌握者仍主动退让，支持直接机制；
4. 拿掉关系将结束的风险后仍照样放权，可能是 `zn` 或正常授权；
5. 拿掉具体控制变化，只剩“心软了”，不能判克制；
6. 放松控制后，对方自主路线、否决权或退出权必须真实增加。

两个具体人物案例均通过核心拿掉测试。

## 10. 反向测试

交换为 `x 克 nz`：

```text
主体加强对关系对象的占有、替代决定与排他控制
→ 对方无法自愿停靠
→ 关系余温被管理关系取代
→ nz 下降
```

方向切口：

- `nz克x` 改变掌握边界；
- `x克nz` 改变自愿停靠与关系余温。

## 11. 动态链后果

```text
我害怕失去你
→ 我曾试图把你管得更紧
→ 但继续掌握只会让你真正离开
→ 我放下替你决定的权力
→ 关系仍可能继续，但不再以“你归我掌握”为条件
```

改变的是关系中自主停靠的可能性，不机械生成和解、永久共享、赠与或人格成长。

## 12. 三元与十元并行

三元继续核验作品整体精神运动。

十元只核验：

- `nz` 是否已有真实关系余温；
- `x` 是否已有关系掌握边界；
- 独占、否决、替代决定与调用是否主动下降；
- 是否实际由法律、交易、`zn`、`zx` 或疲惫启动。

本体与命运并行，不建立父子派生。
