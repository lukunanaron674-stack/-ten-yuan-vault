# z 克 nx：现行认可端点与旧占位口径冲突审计

## 审计结论

几何位置 `z 克 nx` 保留；旧机制“z 持续表达、决定和占位，压缩 nx 选择空间”与现行 z 本体冲突，撤回其正式机制资格。该旧过程的源端点更接近 `zx` 的显权、`x` 的权限掌握或外部方向主体，不应继续叫 z。

当前最窄候选是：

> 重要认可主体确认了主体自己的判断、能力或选择，使主体不再只能沿外部方向行动，并重新认领方向决定位置，从而降低 nx。

该候选目前只达到关系层／状态层，正式机制未锁定。

## 1. 关系对象分层

| 层级 | z | nx | 审计要求 |
|---|---|---|---|
| 稳定本体 | 长期需要重要认可位置确认自身 | 长期不占方向决定位置 | 不从一次鼓励反推人物本体 |
| 当前状态 | 此阶段被重要对象看见并确认 | 此阶段停止沿外部安排 | 最可能成立层 |
| 行为功能 | 呈现、被确认、回应 | 跟随、接受安排、沿关系通道推进 | 行为先后不等于克制 |
| 光影 | 目光、署名、回应、聚光 | 后退、侧位、队列 | 仅作显影 |
| 场景 | 师徒、家庭、治疗、舞台 | 学校、公司、家庭、组织 | 场景不能代替端点 |
| 时间关系 | 认可先发生 | 方向认领随后上升 | 只证明先后 |
| 关系位置 | 认可者与被认可者 | 外部方向提供者与跟随者 | 认可者未必等于方向提供者 |
| 显影 | “你的判断/能力成立” | “我不再只沿别人安排” | 必须观察方向权变化 |
| 动态链 | 被确认 | 取回方向位置 | 不机械生成独立人格 |

## 2. 端点、变量与成立条件

### 源端点 z

必须写清：

1. 谁认可；
2. 认可什么；
3. 为什么该认可位置重要；
4. 认可是否真正落到主体自己的能力、判断或选择。

普通命令、强势表达、职位占位、公众注意和完成结果都不能代替 z。

### 目标端点 nx

被改变变量是：

- 主体对方向决定位置的认领强度；
- 对外部安排的唯一依赖度；
- 是否开始提出替代方向；
- 是否保留否决权；
- 是否仍只能借他者权限和关系网络推进。

### 成立阶段与体量

- 低体量：在一个具体选择上不再只听安排；
- 中体量：在某段关系中持续提出并执行自己的方向；
- 高体量：稳定人物结构发生改变。当前无证据支持高体量。

显影条件：认可后必须出现真实方向权变化，而非只出现情绪振奋、表现更好或继续追逐认可。

## 3. 候选机制

### 候选 A：判断资格确认

```text
重要认可主体确认“你的判断可以成立”
→ 主体不再把外部方向视为唯一合法方向
→ 开始提出、选择并承担自己的路线
→ nx 下降
```

理论后果：z 克制的是 nx 的方向依赖，不是克制关系网络本身。

### 候选 B：能力资格确认

```text
主体此前因不确定自身能力而沿别人安排
→ 重要认可者确认其能力足以承担选择后果
→ 主体取回否决和决定位置
→ nx 下降
```

理论后果：若认可只让主体更卖力执行原安排，则只是 z 增强表现，不构成克制。

### 排除候选 C：认可者替主体决定

```text
重要人物持续决定和占位
→ 主体退后
```

这会使 nx 上升，不是 z 克 nx；源端点还可能是 zx、x 或 xn。

## 4. 正例候选

### 《死亡诗社》托德与基廷，课堂即兴诗阶段

- z：基廷确认托德具有自己的诗性声音，而非只是沉默、普通或只能照标准答案行动的学生。
- nx 候选：托德从不占表达与判断位置，转为说出自己的语言。

限制：基廷同时提供教学结构与强引导，混有 xn、n 和 zx；只能支持“认可使自我方向获得资格”。

### 《跳出我天地》比利与父亲，父亲支持舞蹈选择之后

- z：父亲由否定者转为确认比利的舞蹈能力与选择。
- nx 候选：比利不再只能沿矿工家庭与社区给定路线，自己的方向获得现实资格。

限制：比利在父亲认可前已有较强自主方向，故更像 z 为既有非 nx 提供现实支持，不足以证明生成式克制。

### 结构例

学生长期只按导师选题。导师明确确认：“你的判断足以独立决定研究方向。”此后导师不再给题，学生仍提出并承担自己的路线。若只得到表扬却继续等导师决定，则不成立。

## 5. 反例

1. 老板表扬员工后，员工更认真执行老板安排：z 上升，nx 未降。
2. 父母说“我相信你”，但仍替孩子决定学校和职业：认可与方向权分离。
3. 强势领导持续表达、决定和占位，使成员退后：更接近 zx/x 克制主体选择，不是现行 z。
4. 获奖后人物情绪高涨，却没有新增任何决定权：只是状态变化。
5. 群体看见人物，人物随后更依赖掌声：z 上升，可能加强认可依赖。
6. 主体本来就有稳定方向，认可只提供资源和机会：目标 nx 原本不存在。
7. 认可者命令主体“独立一点”：仍是外部方向，不证明主体取回方向。
8. 认可后主体只是换了一个更喜欢的跟随对象：nx 结构未变。

## 6. 最近邻排除

### 与 zx 克 nx

- zx：公开权能决定、压过并重排现实位置；
- z：重要认可主体确认主体的存在、能力或选择。

旧“持续表达、决定和占位”更像 zx，不是 z。

### 与 x 克 nx

若认可者掌握职位、资源、许可并通过放权让主体能决定，变化可能来自 x 的权限转移，而非 z。

### 与 zn 克 nx

若主体因为“这件事无论如何都是对的”而不再跟随，启动源是 zn；z 只可能是确认该判断获得关系资格。

## 7. 拿掉测试

1. 拿掉认可，只保留放权或资源，主体仍取回方向，则不依赖 z。
2. 拿掉权限转移，只有一句认可，主体仍持续决定，才支持 z 直接作用。
3. 拿掉主体原有自主判断，认可后若仍只能等对方给方向，则目标端点不存在。
4. 拿掉情绪振奋，只观察方向、否决与替代方案，关系仍成立才有效。
5. 认可停止后主体仍保持自己的方向，纯度高于继续追逐认可。

两个作品候选均未通过完全拿掉 n、xn、x 与既有自主性的测试。

## 8. 反向测试

交换为 `nx 克 z`：主体长期不表达、不呈现、不进入认可接口，可能使认可无法发生。但这是另一关系变量：改变的是认可接口，不是方向认领。

旧机制交换后也暴露方向错误：强势主体占位压缩他人选择，源端点本来就不是认可关系。

## 9. 动态链后果

```text
重要的人确认：你的判断和能力可以成立
→ 外部安排不再是唯一合法方向
→ 主体开始提出并承担自己的路线
```

改变的是“谁有资格决定”的关系感觉，不是认可自动制造成熟、勇气或稳定独立人格。

## 10. 三元与十元并行

三元继续核验作品整体精神运动；十元只核验认可端点、方向位置和可观察变量。z 与 nx 并行，不建立父子派生。

## 11. 95%门槛

高置信结论：

- 旧“z 持续表达、决定和占位”与 z v2.2 冲突：99%。
- 旧机制源端点更接近 zx/x：98%。
- 认可后只有方向认领真实上升，才可能构成 z 克 nx：98%。
- 当前最窄候选是“认可确认主体自己的判断资格”：96%。

未过门槛部分：

- 缺少两个能拿掉 n、xn、x 与既有自主性的纯人物案例；
- z 是直接克制 nx，还是只让原有自主方向获得显影资格；
- 关系能否超过状态层与局部关系层。

因此：几何位置保留；旧机制撤回；新候选未锁定；不得继续把“强势表达和占位”写成现行 z 克 nx。
