# nz 克 x｜关系余温压缩关系控制边界正式机制

## 0. 正式结论

> **nz 通过“不愿让关系真正结束”的余温，使掌握者主动放松对关系对象的独占、替代决定、否决与调用边界，从而克制 x。**

本机制首先锁定在**关系掌握边界**，不泛化为“因为爱所以放弃财产”。财产让渡只有在它明确改变关系控制边界时，才可作为次级显影。

## 1. 对象分层

| 层级 | nz | x | 本轮判定 |
|---|---|---|---|
| 稳定本体 | 长期保留关系余温、不愿结束 | 长期把对象、权限或关系纳入归我掌握 | 不从一次让步反推本体 |
| 当前状态 | 此阶段仍想维持停靠 | 此阶段收紧或放松控制 | 正式机制主要发生层 |
| 行为功能 | 等待、保留、回返、维持联系 | 代替决定、否决、调用、排除 | 必须改变实际边界 |
| 光影 | 暖光、旧物、回望 | 门锁、权限、监控、私人边界 | 只作显影证据 |
| 场景 | 亲子、伴侣、旧友、离别 | 抚养、行程、关系准入、资源控制 | 题材不能代替端点 |
| 时间关系 | 关系已有厚度 | 控制随后被主动放松 | 先后不自动证明克制 |
| 关系位置 | 不愿失去的一方 | 掌握者、家长、伴侣、权限持有人 | 必须是同一关系中的边界变化 |
| 显影 | 关系保留需求上升 | 独占、否决、替代决定下降 | 目标变量需可观察 |
| 动态链 | 为了关系仍能继续 | 不再把对方当作可完全掌握对象 | 不自动生成和解 |

## 2. 端点与被改变变量

### 源端点 nz

必须先有真实共同时间、关系余温与“不想让这段关系结束”。一次心软、普通善良、责任感或害怕失去利益均不够。

### 目标端点 x

必须存在明确的关系掌握：

- 替对方决定；
- 控制其行动、交往或选择；
- 以“归我／属于我方”排除他者；
- 掌握最终否决与调用权；
- 把关系对象当成可被管理的对象。

### 被改变变量

- 独占程度；
- 替代决定强度；
- 最终否决权；
- 对他者自主路线的容忍度；
- 关系准入与退出边界；
- “属于我”是否改写为“仍与我相连，但不由我完全决定”。

## 3. 候选机制

### 候选 A：关系保留迫使控制退场

```text
nz：我不愿这段关系结束
→ 主体发现继续替对方决定会把对方推走
→ 主动放松独占、否决与替代决定
→ x 的关系掌握边界缩小
```

理论后果：nz 克制的是**控制关系的强度**，不是消灭关系、责任或所有现实边界。

### 候选 B：停靠对象重新成为独立主体

```text
对方原本被纳入“归我掌握”
→ 关系余温使主体承认：只有对方仍能自主返回，停靠才真实
→ 对方从被管理对象重新成为独立关系主体
→ x 的对象化与调用边界下降
```

理论后果：关系被保留的条件，不是掌握更严，而是允许对方以自己的方向继续存在。

### 统一机制

候选 A 是行动过程，候选 B 是对象地位变化。统一为：

> **为了让关系仍有真实回返可能，掌握者必须把对方从“归我决定的对象”还原为“可以自主离开、也可以自主回来的人”。**

## 4. 正例

### 4.1 《海底总动员》马林与尼莫，结尾返校阶段

- **x**：马林长期替尼莫判断风险、限制行动并控制其探索范围。
- **nz**：父子关系经历失散与重逢后，马林明确不愿再失去这段关系。
- **变化**：他不再以“保护”为理由替尼莫决定全部路径，而允许尼莫独自上学、参与行动并承担适度风险。
- **目标变量**：替代决定、行动否决与关系控制下降。
- **机制**：马林意识到继续严密掌握会使尼莫在关系中无法真正靠近；为了让父子关系继续，他主动放松控制。

第三因素包括 n 的照护与 xz 的危险经历，但拿掉外部危险后，结尾仍明确表现“为了保留关系而不再完全掌握对方”。

### 4.2 《青春变形记》明与美美，演唱会冲突后的母女阶段

- **x**：明长期掌握美美的时间、交往、身体变化解释权与人生安排。
- **nz**：母女关系具有强时间厚度，明真正害怕的不是一次违抗，而是女儿离开自己。
- **变化**：冲突后明最终允许美美保留自己的熊猫、朋友与选择，不再要求她完全回到母亲设定的身份轨道。
- **目标变量**：身份调用、交往否决与替代决定下降。
- **机制**：若继续以完全控制维持亲密，关系只会真正断裂；关系余温反而迫使控制边界退让。

影片同时含代际传统、n 照护与 zn 自我确认，但母亲端的直接变化仍落在“为了不失去女儿而放松归我决定”。

### 4.3 纯结构例：旧伴侣的关系准入放松

甲长期把乙的社交、行程与共同空间纳入自己最终决定。乙准备离开后，甲不是以威胁换取留下，而是取消定位共享要求、放弃检查权限，并明确允许乙独立安排生活。若甲的核心理由是“只有不再完全掌握你，我们才可能仍有关系”，则构成本机制。

## 5. 反例

1. 法院判决削减监护权：启动源是制度，不是 nz。
2. 对方威胁分手后被迫交出密码：主要是 zx 或关系勒索。
3. 因道德原则放弃财产：优先检查 zn。
4. 因疲惫不再管理对方：只是状态下降。
5. 一次允许孩子外出：若最终否决与替代决定未变，只是局部授权。
6. 正常分工与协商：双方原本均保留否决权，未必存在 x 被克。
7. 财产赠与后仍严格控制受赠者：对象转移不等于关系掌握下降。
8. 关系已经结束，仅为补偿而让渡：可能是责任、交易或 xn 安排。

## 6. 最近邻排除

### 与 zn 克 x

- `zn克x`：因为“继续掌握是不对的”而放弃，即使关系可能结束也会这样做。
- `nz克x`：因为“不放松掌握，这段关系会真正结束”而退让。

### 与 nx

- nx：主体不占方向位置，把决定交给别人。
- nz克x：原掌握者仍有行动能力，但主动缩小自己对他人的掌握边界。

### 与 zx 剥夺

- zx：外部主体以权能强迫交出控制。
- nz克x：掌握者主动退让，不依赖被压服。

### 与反向 x 克 nz

- `x克nz`：控制加强，使停靠失去自愿性。
- `nz克x`：关系余温先显影，使控制主动下降。

## 7. 拿掉测试

1. 拿掉 nz 后，若主体仍因法律、道德、利益或疲惫放松控制，则不依赖本关系。
2. 拿掉 x 后，只剩陪伴与和解，没有目标端点。
3. 拿掉外部强制后，掌握者仍主动退让，支持直接机制。
4. 拿掉关系将结束的风险后，主体仍照样放权，可能是 zn 或正常授权。
5. 拿掉具体控制变化，只剩“心软了”，不能判克制。
6. 放松控制后，对方的自主路线、否决权或退出权必须真实增加。

两个具体人物案例均通过核心拿掉测试。

## 8. 反向测试

交换为 `x 克 nz`：

```text
主体加强对关系对象的占有、替代决定与排他控制
→ 对方无法自愿停靠
→ 关系余温被管理关系取代
→ nz 下降
```

方向切口：

- `nz克x` 改变掌握边界；
- `x克nz` 改变自愿停靠与关系余温。

## 9. 动态链后果

```text
我害怕失去你
→ 我曾试图把你管得更紧
→ 但继续掌握只会让你真正离开
→ 我放下替你决定的权力
→ 关系仍可能继续，但不再以“你归我掌握”为条件
```

改变的是**关系中自主停靠的可能性**。不机械生成和解、永久亲密、正确养育、财产转移或控制者人格重生。

## 10. 三元与十元并行

三元继续核验作品整体精神方向。十元只核验：

- nz 是否先有真实关系余温；
- x 是否存在具体关系掌握边界；
- 控制是否因关系保留需要主动下降；
- zn、nx、zx、制度与利益是否为真正启动源。

三元与十元并行，不建立父子派生。

## 11. 95%门槛

**通过：96%。**

理由：

1. 两端符合现行 `nz v1.1` 与 `x v2.0` 正本；
2. 正式机制缩窄到关系掌握边界，不再泛化财产赠与；
3. 两个具体人物案例均有明确阶段、关系双方和可观察控制变量；
4. 八个反例稳定排除制度、道德、疲惫、普通授权与被迫让渡；
5. 最近邻、拿掉测试与反向测试通过；
6. 不改写 nz 或 x 的本体定义。

正式锁定：

> **nz 为保留真实关系与回返可能，迫使掌握者主动缩小对关系对象的独占、否决、替代决定和调用边界，从而克制 x。**
