# xz 克 zn｜危险测试意义而非自动摧毁｜二次审计

## 本轮结论

几何位置 `xz克zn` 保留，正式直接机制仍未达到95%门槛。

本轮新增的高置信边界是：

> 危险、追杀、酷刑、灾难和退路缩窄，首先测试的是 zn 能否实践、能否显影，以及人物此前是否真的拥有稳定 zn；只有主体持续改判“这件事不再是对的”，而非仅仅恐惧、失败、妥协或公开屈服，才可能进入 `xz克zn`。

旧《黑暗骑士》“小丑以无规则嘲讽正义”继续撤回。小丑的主动设计、公开强迫与流程操控混有 zx、xn；“混乱感”也不是现行 xz。

## 1. 对象分层

| 层级 | 本轮判定 |
|---|---|
| 稳定本体 | xz 是危险显形、异质逼近、退路缩窄；zn 是不依赖奖励和认可的内部意义确定 |
| 当前状态 | 恐惧、疲惫、创伤、绝望、麻木、犹豫 |
| 行为功能 | 逃跑、妥协、否认、背叛、沉默、放弃行动 |
| 光影 | 刑场、警报、黑暗、倒计时、逼近镜头 |
| 场景 | 战场、监狱、灾难、追杀、酷刑 |
| 时间关系 | 危险先出现、人物后动摇，只是先后 |
| 关系位置 | 施害者、追捕者、制度执行者，需另查 zx/xn |
| 显影 | zn 是否仍被判断为正确，是否仍拥有指导选择的资格 |
| 动态链 | 危险压缩实践条件，不自动机械生成意义崩塌 |

## 2. 端点与变量

### 源端点 xz

必须满足：危险可感知地逼近；安全路径、时间窗口或退路真实减少；主体若不行动就会被吞没、捕获或失去最后机会。

### 目标端点 zn

必须是主体此前已经稳定认为：

> 即使没有奖励、认可和外部证明，这件事仍然是对的，因为不这样就不是我。

### 被改变变量

1. 意义的无条件性；
2. 意义是否仍被判断为正确；
3. 意义是否仍有资格指导现实选择；
4. 原则是否被改写为“安全时才成立”；
5. 危险解除后改判是否持续。

行动失败、公开认错、暂时逃跑和无法实践，不足以单独证明 zn 被克。

## 3. 候选机制

### 候选A：危险把无条件原则压成生存条件

```text
xz 持续逼近
→ 按原意义行动会直接扩大毁灭风险
→ 主体把“这是对的”改成“只有安全时才对”
→ zn 的无条件性与指导资格下降
```

理论后果：若成立，`xz克zn` 的感觉不是“人害怕了”，而是“正确被危险压成了奢侈品”。

### 候选B：危险只测试、遮蔽或阻断 zn 的实践

```text
xz 逼近
→ 主体恐惧、逃跑、妥协或无法行动
→ 但仍认为原意义正确
→ zn 未变，改变的是状态、行为能力和显影机会
```

理论后果：真正稳定的 zn 可能恰好以“危险无法进入意义判断通道”为特征。危险只暴露此前的价值是否只是口号、继承规范、角色身份或安全环境下的自我想象。

### 候选C：施害者的 zx/xn 冒充 xz

公开命令、惩罚、酷刑流程、制度性迫害和精密两难，通常含 zx 或 xn。危险场景不能把全部作用归给 xz。

## 4. 正例候选

### 4.1 《蝙蝠侠：黑暗骑士》哈维·丹特后期

- 阶段：瑞秋死亡、身体重创后至硬币裁决阶段。
- xz 候选：连续不可预测危险、损失逼近和退路收缩。
- zn 候选：依法实现正义的内部意义。
- 可观察变化：丹特不只是做不到，而是撤销正义原则的指导资格，转向随机裁决。
- 未通过纯例原因：小丑的 zx/xn 操纵、创伤、丧失与身份崩塌均为强第三因素。

### 4.2 《沉默》罗德里格斯踏绘阶段

- 阶段：他者持续受刑，罗德里格斯被要求踏像。
- xz 候选：他者死亡危险持续逼近，行动窗口缩窄。
- zn 候选：不可弃教、不否认基督的内部意义。
- 可观察变化：原无条件原则的适用范围被重新划定。
- 未通过纯例原因：幕府的公开强迫和制度流程混有 zx/xn；也可能是更高层 zn“救人”替换了“不可弃教”，不是 zn 被克。

### 4.3 《一九八四》温斯顿，101室

- 阶段：面对自己最恐惧的老鼠威胁时，温斯顿要求把酷刑转移给朱莉娅。
- 支持点：危险逼近使他撤销“绝不背叛朱莉娅”的原则指导资格。
- 未通过纯例原因：101室是高度设计的制度酷刑，源端点明显包含 xn 与 zx；更适合证明制度与权能如何利用 xz，而不是 xz 独立克 zn。

## 5. 反例

1. 《勇敢的心》华莱士在酷刑和处决逼近时仍喊出自由：xz 上升，zn 不降，甚至高显影。
2. 《末路浩劫》父亲在持续危险中仍保护孩子：行动条件恶化，但意义继续支配选择。
3. 人物因恐惧逃跑，危险解除后仍承认原原则正确：只是状态与行为失败。
4. 被迫写悔过书、公开否认信仰，但内心判断不变：改变的是行为或 x并z 的公开接口。
5. 危险暴露人物此前只是服从家庭、宗教或组织规范：是“原本没有稳定 zn”，不是 zn 被克。
6. 两个 zn 原则在危险中重新排序，例如“不可弃教”让位于“不可让无辜者继续受刑”：属于意义排序，不等于 zn 总量被克。

## 6. 最近邻排除

### 与 zx 克 zn

zx 通过主体公开权能、惩罚和强迫，压迫人物否认意义；xz 若独立成立，不依赖某个主体下命令，而是危险临界本身改变意义判断。

### 与 xn 克 zn

xn 通过规则、流程、长期奖惩和制度结构改变意义的形成、适用或实践；xz 是迫近危险与退路收缩。

### 与“状态遮蔽 zn”

恐惧、麻木、创伤和疲惫可让 zn 无法显影。只有主体持续改判“它不再正确”或“它不再有资格指导我”，才触及目标端点。

### 与 zn 内部排序

一个意义让位给另一个更高意义，不等于 zn 被摧毁。必须观察原意义是否失去正确性，而不仅是此次没有执行。

## 7. 拿掉测试

1. 拿掉危险，只保留命令、制度和酷刑流程，若改判仍发生，主要依赖 zx/xn。
2. 拿掉施害者和制度，只保留不可控危险，人物仍把无条件原则改成条件原则，才支持直接机制。
3. 拿掉行为失败，若人物仍认为原则不再正确，才可能落到 zn。
4. 拿掉原有稳定 zn，若人物此前只重复口号，则危险只是揭露空壳。
5. 拿掉危险解除后的持续改判，若原则随后恢复，说明只是遮蔽或暂时失去实践资格。

## 8. 反向测试

交换为 `zn克xz`：

```text
内部意义保持无条件有效
→ 主体不再让危险决定最终方向
→ xz 对选择路径的支配下降
```

华莱士受刑、末路中的父亲更接近这一方向。

方向区别：

- `xz克zn` 改变意义的无条件性和指导资格；
- `zn克xz` 改变危险对最终选择方向的支配力。

## 9. 动态链后果

若候选A成立：

```text
危险逼近、退路缩窄
→ 原则从“无论如何都对”降为“安全时才对”
→ 生存规则、现有安排或他者路径接管选择
```

若候选B成立：

```text
危险压缩行动与显影
→ 意义仍在内部保持
→ 危险解除或出现机会后，zn重新指导行动
```

关系改变的是“意义能否继续拥有最终裁决权”，不是把危险当成自动删信念按钮。理论已经够复杂，不需要再安装一键格式化灵魂的廉价功能。

## 10. 三元与十元并行

三元只核验作品整体精神走向；十元只核验具体阶段、端点、变量和方向。不从一次崩溃反推稳定三元，也不把 xz 与 zn 写成父子派生。

## 11. 95%门槛

### 已达到高置信

- 99%：旧《黑暗骑士》“无规则嘲讽意义”不是合格机制。
- 99%：恐惧、逃跑、公开妥协和无法实践，不等于 zn 被克。
- 98%：必须排除 zx/xn 的施害设计、原本没有 zn、以及两个 zn 的内部排序。
- 98%：目标变量必须是意义的无条件性、正确性与最终指导资格。

### 未达到95%

- 候选A是否为独立普遍机制；
- 真正稳定的 zn 是否按定义只能被测试、遮蔽，而不能被纯 xz 直接克制；
- 当前三个作品候选均有强第三因素，拿掉测试未完全通过。
