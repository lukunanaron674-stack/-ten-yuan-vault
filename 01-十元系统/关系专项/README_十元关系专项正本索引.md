## 读取规则

1. 先读 `十元生补克表.md` 判断几何位置。
2. 再读本索引判断该关系是否已有正式专项正本。
3. `正式机制`、`正式机制二次核验` 高于关系词典中的旧案例短句。
4. `审计`、`待二审`、`未锁定` 只提供证据和边界，不覆盖正式机制。
5. 关系词典负责总览；专项正本负责已锁定端点、机制、变量、反例与测试。
6. 同一关系同时存在审计与 `canonical-current` 时，审计自动降为 `covered-by / evidence-only`，除非正式正本明确把它列为当前补丁。

## 上下位与覆盖总则

```text
十元生补克表（几何位）
→ parent
关系专项正式机制
→ example-of / implements
案例验证与动态链调用
```

- 补位关系的正式正本实现的是双向缺口机制，不把两端写成互相生成。
- 正式正本出现后，同关系旧审计若仍含独有材料，保留为 `covered-by / evidence-only`，不得按旧 `locked`、`finalized` 或 `current` 字样越级读取。
- 正式关系摘要尚未同步到生补克表或关系词典时，以本索引路由到对应专项正本；总表短句不得覆盖专项正本。

## 本批次新增路由

### `xn 补 z`

正式正本锁定：xn 提供跨时间可复核证据，z 提供认可位置、材料筛选标准与阶段收束节点；两端互补，不互相生成。

### `xz 补 nz`

正式正本锁定：xz 让关系可能真正失去并迫使停靠被重新选择；nz 为危险漂流提供回返对象和归宿方向。

### `n 生 xn`

正式正本锁定：真实承载的负荷反复进入后，主体把接收经验提炼为顺序、分工、记录、节点与资源安排，使承载获得跨轮次运行方式。

### `x并z 克 nz`

正式正本锁定：身份壳污染关系证据归因，使真实主体退出可返回的关系位置，从而侵蚀余温与停靠。

### `nz 克 x`

正式正本锁定：为保留真实关系与回返可能，掌握者主动缩小独占、否决、替代决定与调用边界。

### `x 克 nz`

正式正本锁定：单向掌握抽空停靠的自主选择资格，使关系从可回返位置变成被管理范围。

### `zn 克 xn`

正式正本锁定：意义撤回既有结构“应当被维护”的资格，截断结构对主体的完整覆盖、自愿维护与跨轮次复制。
