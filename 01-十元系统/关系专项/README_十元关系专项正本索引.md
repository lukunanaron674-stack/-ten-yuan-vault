## 读取规则

1. 先读 `十元生补克表.md` 判断几何位置。
2. 再读本索引判断该关系是否已有正式专项正本。
3. `正式机制`、`正式机制二次核验` 高于关系词典中的旧案例短句。
4. `current-patch / canonical-amendment` 只同步或撤回指定范围，不取代其 parent 正式正本。
5. `审计`、`待二审`、`未锁定` 只提供证据和边界，不覆盖正式机制。
6. 关系词典负责总览；专项正本负责已锁定端点、机制、变量、反例与测试。
7. 同一关系同时存在审计与 `canonical-current` 时，审计自动降为 `covered-by / evidence-only`，除非正式正本明确把它列为当前补丁。
8. 正式同步补丁必须从本索引进入读取链；只写 `covers / supersedes` 而未进入索引的补丁视为路由断链。
9. 总入口第14层已显式路由到本索引；本索引中的 `parent / child` 只表示文件读取层级，不构成理论父子派生。
