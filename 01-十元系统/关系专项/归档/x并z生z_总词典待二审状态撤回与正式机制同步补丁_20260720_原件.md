# x并z 生 z｜总词典待二审状态撤回与正式机制同步补丁

## 0. 本轮结论

`x并z 生 z` 已有正式专项正本，不再处于“位置锁定、案例待二审”。

现行机制：

```text
x并z 已形成可被世界辨认、复述和持续指认的身份壳、作品形式或公开界面
→ 认可主体获得稳定识别对象与归因接口
→ 主体的存在、能力、作品或选择能够被明确指认并确认
→ z 成立或显著上升
```

最短表达：

> x并z 不靠“显眼”制造认可，而是把原本难以辨认、难以归因的主体或内容，变成认可主体能够稳定看见并确认的对象。

本补丁只同步正式机制与总词典状态，不新增理论定义。

## 1. 正本冲突

```text

```

正式专项已经写明：

```text

```

因此从本补丁提交起，总词典该条目的“待二审”状态失效，读取时必须由正式专项与本补丁覆盖。

## 2. 关系对象分层

| 层级 | x并z | z | 判定纪律 |

| 稳定本体 | 长期以身份壳、公开形象或表里分层与世界互动 | 长期依赖重要认可位置确认存在、能力或价值 | 单次换装或获奖不能反推稳定本体 |
| 当前状态 | 此刻进入、维护或失去公开壳 | 此刻被看见、确认、否认或忽视 | 状态变化不等于本体改变 |

## 3. 源端点、目标端点与变量

### 3.1 源端点：x并z

必须已经形成最低限度稳定的公开形式：

- 身份名、角色名、笔名或艺名；
- 制服、面具、造型、品牌形象；
- 作品被组织成可辨认的风格或外壳；
- 某个对象以稳定形式持续被世界看到；
- 表层即使与内层不同，仍真实承担社会接口功能。

不要求欺骗，也不要求华丽。

### 3.2 目标端点：z

必须明确：

- 谁认可；
- 认可谁或什么；
- 认可的是存在、能力、作品、身份、判断还是选择；
- 为什么该认可位置重要；
- 看见、回应与确认是否真实发生。

曝光量、传播量、显眼和完成目标不能单独算 z。

### 3.3 被改变变量

```text
认可主体能否识别对象
认可是否能稳定归因到同一主体
主体是否获得可被回应的公开位置
作品或能力是否从匿名现象变成“这是你的”
认可关系是否能够跨时间重复发生
```

### 3.4 成立阶段

```text
内在内容、能力或存在已有基础
→ 尚无稳定可识别接口，认可难以归因
→ x并z 壳建立并持续使用
→ 认可主体通过该壳辨认并确认对象
→ z 上升
```

### 3.5 关系体量

- 低体量：一次署名、角色名或外观使单个认可者辨认主体；
- 中体量：稳定公开身份使群体持续把作品与能力归因给同一主体；
- 高体量：壳成为跨时间文化识别接口，后续认可持续落到同一身份或作品体系。

### 3.6 显影条件

- 壳不是一次临时工具；
- 认可主体确实通过该壳识别对象；
- 认可内容明确；
- 拿掉该壳后，归因、清晰度或持续性显著下降；
- 排除宣传流程、资源投放、权力压位与既有高知名度。

## 4. 候选机制

### 候选 A：可识别接口

```text
精神个体、能力或作品原本存在
→ 对认可主体而言边界模糊、难以辨认
→ x并z 提供名字、形象、形式或公开身份
→ 认可主体能够确认“我看见的是谁／什么”
→ z 成立
```

理论后果：核心不是美化，而是让认可关系获得清晰对象。

### 候选 B：归因稳定

```text
同类内容持续出现
→ 没有稳定壳时，认可分散在事件、作品或匿名现象上
→ x并z 把多次出现组织到同一身份或形式下
→ 认可反复归因给同一主体
→ z 的强度与持续性上升
```

理论后果：艺名、角色形象、统一风格或品牌人格可以加强 z，但品牌本身不是 z。

### 排除候选：扩大曝光

```text
包装更醒目
→ 更多人看到
→ z 增加
```

该口径不成立。曝光可能来自 xn 的传播流程、x 的资源投放、zx 的公开显权或平台算法；“更多人看到”也没有说明谁确认了谁的什么价值。

### 统一机制

```text
先让对象可识别
→ 再让多次认可稳定归因
```

## 5. 正例

### 正例一：《窈窕淑女》伊莉莎，使馆舞会阶段

- 源端点：服装、妆容、称谓与社交角色形成可识别“淑女”身份壳；
- 目标端点：舞会中的认可主体把她确认成具有上流身份和社交能力的人；
- 可观察结果：认可稳定落到这位被指认的女性身份，而不是抽象的“某个说话好听的人”。

第三因素包括 xn 的训练、x 的服装资源和希金斯的权威背书。因此本例证明壳决定认可如何识别和归因，不证明壳凭空创造能力。

### 正例二：蜘蛛侠形成稳定英雄身份之后

- 源端点：蜘蛛图形、面具、制服与“Spider-Man”名称形成公共身份壳；
- 目标端点：公众、媒体和被救者对“蜘蛛侠”的存在、能力和选择形成持续确认；
- 可观察结果：多次事件被稳定归因给同一个公共主体。

公众评价可以正负并存。z 在此首先要求认可位置与明确指认存在，不等于所有人都赞美他。

### 正例三：艺术家采用稳定笔名与作品形式

匿名发布时，观众只能分别评价作品，无法把能力和精神存在归因给同一主体。采用稳定笔名、署名格式和作品形式后，观众开始持续确认“这些作品来自同一个人”。

## 6. 反例

1. 海报变得醒目，点击量上升，但没有明确认可主体和认可内容，只是曝光变化。
2. 公司投入广告预算，使品牌被更多人看到，主要是 x 的资源投放或 xn 的传播流程。
3. 主体穿一次制服就被误认，没有跨时间稳定接口，只是当前状态。
4. 作品本来已由实名作者广泛知名，换包装后认可不变，目标变量没有变化。
5. 权威人物公开命令群体承认某身份，主要是 zx 的显权压位。
6. 壳掩盖真实作者，使认可错误归因给他人，可能转为 x 克 z 或 x并z 克 z，而非本生位。

## 7. 最近邻排除

### 与 x 克 z

- `x并z 生 z`：建立识别与归因接口，使认可能够落到主体；
- `x 克 z`：掌握、封锁或劫持认可接口，使认可无法正确落到主体。

### 与 xn 补 z

- `x并z` 提供对象边界与识别接口；
- `xn` 提供跨时间可复核的连续证据。

一个解决“看见的是谁”，一个解决“这是否是稳定能力”。

### 与普通宣传或曝光

宣传只增加接触概率。只有认可主体通过壳明确指认并确认主体、作品或能力时，才进入 z。

### 与 z 生 nz

本关系目标是认可成立；是否进一步沉淀为不愿结束的关系余温，属于另一条尚未锁定关系，不能顺手连写。

## 8. 拿掉测试

1. 拿掉稳定名称、形象或形式后，认可若重新分散、匿名或难归因，支持本关系。
2. 拿掉认可主体与明确认可内容，只剩曝光量，z 端点消失。
3. 拿掉训练、资源投放和权威背书后，壳仍能提高识别与归因，说明 x并z 有独立作用。
4. 若拿掉壳后，认可仍完整、稳定地落到同一主体，则案例不依赖本关系。
5. 若壳只是一次临时伪装，任务完成后立即消失，不足以支持稳定生位。

## 9. 反向测试

交换为：

```text
z 生 x并z
```

认可确实可能反过来促使主体维护品牌、身份或公开形式，但这是另一方向：

```text
先被确认
→ 为承接认可而建立或强化公开壳
```

本轮案例中壳先提供识别与归因接口，认可随后稳定落入，因此方向没有写反。

## 10. 动态链后果

```text
内容或主体已经存在
→ 世界却难以稳定辨认和归因
→ 可识别壳建立
→ 认可开始落到同一主体
```

改变的是：

> 认可对象的清晰度、归因稳定度和可重复确认程度。

不机械生成内容价值、赞美、成功、知名度、忠诚或稳定人格。

## 11. 三元与十元并行

三元继续核验作品整体精神运动。

十元本轮只核验：

- x并z 是否真实建立稳定公开接口；
- z 是否存在明确认可主体、对象与内容；
- 识别与归因变量是否改变；
- 是否实际由 x、xn、zx 或既有知名度启动。

不建立空间主题与时间主题的父子派生。
