# x 生 x并z｜总词典待二审状态撤回与正式机制同步补丁

## 0. 本补丁结论

`x 生 x并z` 已由正式专项锁定，不再处于“位置保留、案例待二审”。

```text
x 已经取得或扩大对象、资源、地盘、权限或关系的实际掌握
→ 掌握范围需要被世界辨认、调用、代表或保护
→ 主体建立名称、职位、品牌、制服、门面、法人身份或前台角色
→ 实际控制关系获得稳定公开壳
→ x并z 成立或显影上升
```

最短表达：

> **已成立的掌握边界，为了被世界识别、调用、代表或保护，形成稳定公开壳。**

旧《寄生虫》“想活下去，所以伪造身份”不属于本方向。该结构通常是壳先帮助主体取得尚未拥有的资源，更接近 `x并z→x`、xn策略或z目标推进。

## 1. 对象分层

| 层级 | x | x并z |
|---|---|---|
| 稳定本体 | 长期依靠占有、调配与控制范围成立 | 长期以公开壳和表里分层同世界互动 |
| 当前状态 | 此阶段取得或扩大掌握 | 此阶段建立、维护或切换公开壳 |
| 行为功能 | 占有、划界、调配、保护控制范围 | 命名、挂牌、包装、设门面、维持身份 |
| 光影 | 金库、钥匙、地盘、幕后网络 | 制服、招牌、徽记、前台、面具 |
| 场景 | 企业、势力范围、私人领地 | 品牌门店、职位、合法公司、公众角色 |
| 时间关系 | 掌握先成立 | 壳随后出现，但必须由掌握需要启动 |
| 关系位置 | 所有者、控制者、权限持有人 | 身份持有者、品牌主体、公开代表 |
| 显影 | 实际调用、调配、否决范围上升 | 可识别性、界面稳定度、表里分层上升 |
| 动态链 | “这些已经归我掌握” | “世界开始通过这层壳接触我的范围” |

单次换装、撒谎、拥有奢侈品或显得富有，都不能反推稳定本体。

## 2. 源端点、目标端点与变量

### 源端点 x

必须已经存在明确掌握对象：

- 对象、财产或地盘；
- 组织、人员、资源或渠道；
- 权限、职位实权或否决权；
- 被纳入“我／我方”边界的关系。

只有欲望、生存压力、企图或想得到某物，不足以构成源端点。

### 目标端点 x并z

必须出现稳定公开形式：

- 名称、职位、头衔、制服、徽记；
- 品牌、门店、合法公司、组织名义；
- 社交角色、公众人格或前台代表；
- 既保护内层，又决定外界如何读取内层的壳。

临时骗一次、临时换装或单一工具性伪造，不自动形成 x并z。

### 被改变变量

- 掌握关系的对外可识别性；
- 掌握边界的可调用、可复述与可代表性；
- 内层控制与外部社会之间的接口稳定度；
- 内层控制暴露程度；
- 壳对掌握范围的保护、合法化与代表能力；
- 同一掌握关系能否持续归到同一公开主体。

## 3. 成立阶段、体量与显影条件

### 成立阶段

```text
x实际掌握先成立
→ 无壳状态出现调用、代表、合法性或暴露问题
→ 主体建立并认领公开界面
→ 世界开始通过该界面同掌握范围发生关系
```

### 关系体量

- 低体量：为一项资源设置名称、标记或公开身份；
- 中体量：职位、公司、门店或公众角色代表实际控制范围；
- 高体量：庞大幕后网络以完整合法组织、王权身份或公共品牌为壳。

### 显影条件

1. 壳明确服务于已成立的掌握关系；
2. 拿掉掌握关系，壳不会以同样形式出现；
3. 壳不是纯粹为求职、取悦认可者、完成任务或骗过一次检查；
4. 壳具有持续性，并改变外界读取和接触内层控制的方式。

## 4. 候选机制

### 候选 A：掌握边界可识别化

```text
x已经控制对象或范围
→ 外界无法稳定识别谁拥有、谁代表、谁有权调用
→ 主体建立名称、职位、徽记、品牌或正式身份
→ 掌握边界获得公开界面
→ x并z上升
```

理论后果：把“实际归我”变成“世界知道通过什么壳接触这一范围”。

### 候选 B：内层控制保护化

```text
x已经掌握资源、地盘或地下网络
→ 完整暴露会威胁控制关系
→ 主体建立合法门面、前台角色或社会身份
→ 外界只接触壳，内层继续被主体控制
→ x并z上升
```

理论后果：壳不仅展示，也隔离和保护内层控制。

### 统一机制

> **已成立的掌握边界通过公开壳被代表；壳既让边界可识别，也限制外界看见内层的程度。**

## 5. 正例

### 5.1 《绝命毒师》古斯·弗林，毒品帝国成熟阶段

- **x**：已掌握毒品生产、运输、人员、资金与地盘网络；
- **x并z**：Los Pollos Hermanos、慈善商人和社区领袖形象；
- **阶段**：不是刚想进入行业，而是地下网络已经形成，需要同合法社会持续接触；
- **结果**：企业身份成为物流、人员和资金接口，同时限制公众看见真实控制结构。

### 5.2 统治者取得领地后形成王冠、国号与宫廷身份

- **x**：土地、税收、军队与任免权限已经实际归其掌握；
- **x并z**：王冠、国号、王室徽记、宫廷礼仪与“国王”公开身份；
- **结果**：实际控制被组织成可辨认、可复述、可继承的公开壳。

### 5.3 黑帮控制地盘后经营合法公司

- **x**：现金流、地盘、人手与地下渠道已经掌握；
- **x并z**：运输公司、夜总会、建筑公司或基金会；
- **结果**：合法名义让资源可被调用、人员可被安置，同时保护真实控制结构。

## 6. 反例

1. 《寄生虫》金家伪造学历进入朴家：壳先帮助取得尚未掌握的工作与资源，方向更像 `x并z→x`。
2. 富人购买华丽衣服：只证明财富与外观共现。
3. 演员因角色换装：没有已成立的掌握范围。
4. 公司因市场流程统一视觉：启动源可能是 xn，未必是 x。
5. 冒充警察取得进入权限：目标是取得尚未拥有的权限，方向相反。
6. 一次撒谎保护隐私：缺少稳定公开壳与持续接口。

## 7. 最近邻排除

### 与反向 `x并z 生 x`

- `x 生 x并z`：实际掌握先成立，壳随后代表或保护它；
- `x并z 生 x`：身份、品牌、职位或伪装先成立，随后帮助取得资源或权限。

### 与 xn

xn 解决怎样排程、组织和重复运行；本关系解决实际掌握通过什么公开界面被读取。

### 与 z

z 关注认可主体是否确认主体；本关系不要求认可，只要求外界能够辨认、调用或被壳隔离。

### 与 zx

zx 是公开权能扩大并凌驾；本关系可以低调，甚至为了避免显权而造壳。

## 8. 拿掉测试

1. 拿掉实际掌握，壳仍因求职、表演或任务出现，则不依赖 x。
2. 拿掉公开壳，实际控制仍存在但难以合法调用、代表或隐藏，支持本关系。
3. 拿掉资源和地盘，只剩漂亮身份，缺少源端点。
4. 拿掉合法性与保护需求，主体仍只为获得认可而造形象，优先检查 z。
5. 古斯案例拿掉毒品网络，餐饮身份不会以同样强度承担掩护、物流与控制接口。

## 9. 反向测试

```text
先有实际掌握，后因掌握需要造壳
= x 生 x并z

先有壳，壳帮助取得掌握
= x并z 生 x
```

两者可形成反馈，但必须分阶段，不得因最终同时拥有资源与身份就混写。

## 10. 动态链后果

```text
这些对象、权限和关系已经归我掌握
→ 世界无法直接同这套掌握关系相处，或完整暴露会威胁它
→ 我建立名字、职位、品牌、门面或公众角色
→ 世界开始通过这层壳接触我的范围
```

改变的是：

> **掌握边界从幕后实际存在，进入可被世界识别、调用，同时保留内外层差异的存在方式。**

不机械生成资源增加、认可、公开权能、虚伪人格或稳定成功。

## 11. 三元与十元并行

三元只核验作品整体精神运动。

十元本轮只核验：

- 已成立的 x 掌握边界；
- 随后形成的 x并z 公开壳；
- 表里接口、代表与保护变量；
- 关系方向。

不把 x 写成 x并z 的父级，不从一次公司门面、制服或王冠反推稳定本体。

## 12. 95%门槛

**通过：98%。**

理由：

- 正式专项已以 96% 锁定；
- 两端点与现行 x、x并z 正本一致；
- 候选 A、B 可统一为“掌握边界生成对外接口”；
- 三个正例均明确掌握先成立、壳后出现及可观察结果；
- 六个反例能排除旧《寄生虫》口径、表面共现与方向倒置；
- 最近邻、拿掉测试、反向测试完整；
- 本补丁只撤回总词典过期状态，不改写本体定义。
