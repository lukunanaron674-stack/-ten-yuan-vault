# xz 生 zx｜核心表母行未锁定状态同步补丁

## 0. 本轮裁定

`xz 生 zx` 的几何位置继续保留，但正式机制尚未达到 95% 锁定门槛。

核心表中的母行应按下列状态读取：

```text
xz→zx（语义待验收）→nz
```

不得仅凭危险后人物反击、带队、抢先行动或成为画面中心，就把该箭头当作正式生位调用。

当前唯一保留的最窄候选是：

> 危险临界使旧秩序无法继续提供方向，形成现实决定空位，迫使原本未公开承担决定位置的主体以自身力量公开接管；但现有证据更容易证明潜在 `zx` 被迫显影，尚不能证明 `xz` 独立生成此前不存在的 `zx`。

## 1. 对象分层

| 层级 | xz | zx | 本轮要求 |
|---|---|---|---|
| 稳定本体 | 长期危险逼近、退路缩窄、无法停留 | 长期依靠显权、扩权与凌驾成立 | 不从一次危机接管反推人物本体 |
| 当前状态 | 此刻危险显形且不行动会被吞没 | 此刻公开接管、夺回或扩大决定位置 | 当前最可能成立层 |
| 行为功能 | 逃跑、冒险、抢窗口、临界反击 | 宣告、夺位、指挥、迫使环境重排 | 普通行动不能替代权能位置变化 |
| 光影 | 警报、倒计时、断路、逼近阴影 | 中心构图、高位、众人转向 | 只作显影证据 |
| 场景 | 灾难、追杀、战争、封锁 | 指挥中心、公开领路、夺取控制台 | 场景不能替代端点 |
| 时间关系 | 危险先出现 | 显权随后出现 | 先后不自动证明生成 |
| 关系位置 | 被局面规定者、逃亡者、受困者 | 新决定中心、领路者、公开权能主体 | 必须发生现实位置重排 |
| 显影 | 退路、时间窗和旧路径缩窄 | 决定范围、服从度与公开影响扩大 | 两端均须可观察 |
| 动态链 | 世界逼我行动 | 我开始规定世界如何行动 | 不机械生成胜利或稳定领导人格 |

## 2. 端点、变量与成立阶段

### 2.1 源端点 xz

必须同时满足：

1. 危险已经以可感知形态逼近；
2. 旧安全路径、时间窗口或退路真实缩窄；
3. 不行动会导致主体、关系或群体被吞没；
4. 危险直接改变可用选择，而非只是灾难背景。

### 2.2 目标端点 zx

必须出现：

1. 主体力量公开进入现实；
2. 主体从被局面规定转为规定局面；
3. 决定范围、影响范围或权能位置扩大；
4. 他者、环境或既有等级围绕其重新行动。

### 2.3 被改变变量

- 谁拥有现场最终方向决定权；
- 主体公开权能的可见范围；
- 他者是否转而服从、跟随或退位；
- 旧秩序是否失去决定资格；
- 主体是否成为新的现实运行中心。

### 2.4 成立阶段与体量

```text
xz 已真实压缩退路与时间窗
→ 原决定结构失效或不足
→ 主体公开接管
→ 现场决定范围与服从关系重排
```

- 低体量：局部关系中夺回决定权；
- 中体量：公开重定团队路线并让多人跟随；
- 高体量：危机使旧等级失效，主体成为新的权力中心。

若危机结束后权能位置立即归零，只能先判状态层或关系层显影。

## 3. 候选机制

### 候选 A：退路剥夺迫使潜在权能公开

```text
危险封死延后空间
→ 隐藏、等待或局部使用能力已经不够
→ 主体必须公开夺回方向
→ 决定范围与影响位置扩大
```

理论后果：解释显影时点为何提前，但可能只证明潜在 `zx` 被迫公开。

### 候选 B：旧秩序失效形成决定空位

```text
危险使原指挥、规则或等级无法继续反应
→ 现场出现无人能够决定方向的空位
→ 主体以自身力量占据空位
→ 他者围绕其行动
→ 新公开决定中心形成
```

理论后果：若成立，生成点不在恐惧本身，而在危险造成的关系位置空缺。

### 竞争解释 C：普通反击或逃生

```text
危险出现
→ 人物跑、打、躲、求救或执行预案
```

没有决定范围、服从关系与权能位置变化，不构成 `zx`。

### 竞争解释 D：既有端点借危机显影

- 因“必须救人”公开领导，优先检查 `zn 生 zx`；
- 因职位本来就负责指挥，优先检查既有 `x/zx`；
- 按应急预案组织行动，优先检查 `xn`；
- 通过他人权限与关系网络推进，优先检查 `nx`。

## 4. 正例候选

### 4.1 《异形2》里普利｜殖民地救援后段

- `xz`：指挥系统失效，异形逼近，撤离路线持续减少；
- `zx` 候选：里普利由顾问、幸存者转为公开决定救援与返回路线，士兵和幸存者围绕她行动；
- 第三因素：既有异形经验、判断信用、救人意义与行动能力。

结论：支持“危险造成决定空位并迫使潜在权能公开”，不足以证明此前不存在的 `zx` 被生成。

### 4.2 《疯狂的麦克斯：狂暴之路》弗瑞奥萨｜绿洲失效后反攻

- `xz`：绿洲已毁，继续漂流几乎必死；
- `zx` 候选：弗瑞奥萨公开重定全队路线、带领反攻，并改变城堡权力结构；
- 第三因素：既有战斗能力、团队信任、资源判断与潜在领导位置。

结论：强制显影候选，不足以证明独立生位。

### 4.3 《釜山行》尚华｜车厢突破阶段

- `xz`：感染者逼近，安全路径持续缩窄；
- `zx` 候选：尚华站到队伍前方，公开决定突破节奏并成为局部领路者；
- 第三因素：体能、保护家人的 `zn` 与临时现场性质。

结论：最多支持低体量状态层显影。

## 5. 反例

1. 火灾中跟随消防员逃生：主要是 `nx`；
2. 被追杀者击倒敌人后继续逃跑：只是临界反击；
3. 团队按既定预案撤离：主要是 `xn`；
4. 军官按职位下令：权能位置原本存在；
5. 因道德确信冒险救人：优先检查 `zn 生 zx`；
6. 群众因恐惧听从最强者：只证明服从结果；
7. 夺权后才遭追杀：方向更接近 `zx 生 xz`；
8. 危险中表现勇敢但无人跟随、环境未重排：没有 `zx` 端点；
9. 设备故障后某人临时代办：可能只是功能补位；
10. 人物本来就是正式负责人：危机只是显影场景。

## 6. 最近邻排除

### 与 xz 自身行动子骨

`xz` 本身已经包含临界行动、冒险与抢先选择。只有行动使主体成为更高决定力量，才进入 `zx`。

### 与 zn 生 zx

- `zn 生 zx`：意义先决定“必须这样做”，再推动权能公开；
- `xz 生 zx` 候选：危险先关闭延后与退路，使主体不得不公开接管。

### 与 xn

预案、排程、分工和资源组织属于 `xn`。执行成功不等于 `zx`。

### 与 x

掌握武器、职位和资源不等于力量已经公开扩张并令现实重排。

## 7. 拿掉测试

1. 拿掉危险后，主体是否仍会在同一阶段公开扩权？
2. 拿掉权能位置变化，只保留逃跑、反击与救人，故事是否仍完整？
3. 拿掉他者跟随和环境重排，只剩能力展示，是否仍能判 `zx`？
4. 拿掉既有能力、职位、计划和意义后，所谓 `zx` 是否消失？
5. 恢复旧秩序的有效指挥后，主体是否仍成为决定中心？
6. 危机结束后权能立即归零，是否只能判状态层？

现有具体候选均未通过“拿掉既有能力、意义或组织条件后，危险仍独立生成 `zx`”的纯度测试。

## 8. 反向测试

```text
xz 生 zx 候选：
危险先关闭退路
→ 主体随后公开接管

zx 生 xz 候选：
显权先改变秩序
→ 危险随后反扑
```

“反抗后遭追杀”不能倒写为 `xz 生 zx`。

## 9. 动态链后果

当前最窄候选链：

```text
旧秩序在危险中失灵
→ 决定位置出现空缺
→ 潜在权能被迫公开
→ 现实决定中心发生转移
```

改变的是：

> 现实决定中心的位置。

不机械生成勇气、胜利、领导人格或稳定 `zx`。

## 10. 三元与十元并行

三元继续核验作品整体精神感觉。

十元只核验：

- `xz` 是否先真实压缩退路；
- `zx` 是否随后扩大公开决定范围；
- 旧秩序是否失效；
- `zn/xn/x/nx` 和既有 `zx` 是否才是真正启动源。

两套系统并行，不建立父子派生。

## 11. 95%门槛

### 高置信通过

- 危险后的普通反击、逃生成功不能证明 `xz 生 zx`：99%；
- 目标变量必须落到公开决定范围与权能位置：99%；
- 必须排除既有职位、计划、意义与潜在 `zx`：98%；
- 核心母行必须标记“语义待验收”：99%。

### 未通过

- `xz` 是否能独立生成此前不存在的 `zx`；
- 候选 A、B 是前后阶段还是独立机制；
- 现有案例究竟是“生”还是潜在 `zx` 被迫公开；
- 母行 `xz→zx→nz` 能否作为正式机制直接调用。

## 12. 正式读取顺序

```text
十元生补克表：保留几何位置
→ 本补丁：母行按 xz→zx（语义待验收）→nz 读取
→ 二次审计：读取完整候选、反例与测试
```

本补丁不锁定新机制，只同步现行审计已经确定的真实状态。
