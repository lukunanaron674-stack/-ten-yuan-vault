# nx 克 x并z｜已锁定状态撤回与接口候选保留补丁

## 0. 当前裁定

```text
几何位置：保留
生补克表4.3“已锁定关系语义”资格：撤回
正式机制：未锁定
最窄候选：主体持续不认领、不复述、不履行壳要求的身份位置，使壳无法把该主体纳入共同说法
适用层：关系层 / 状态层
```

本补丁不改写 `nx` 或 `x并z` 的本体定义，也不把三元与十元写成父子派生。

## 1. 撤回理由

现行专项审计已经明确：

1. 两个具体作品候选均未通过全部拿掉测试；
2. 当前唯一较纯材料是“组织共同声明中的不背书成员”结构例，但缺少具体人物文本；
3. 仍未解决“壳尚未完成生成”与“已经成立后被克制”的时间差；
4. 候选A“认领接口缺失”与候选B“共同背书链中断”是否为同一机制的不同体量，尚未完成验收；
5. 审计结论明确写明“不修改生补克表，不建立正式专项正本”。

因此，生补克表把该三行短机制置于“已锁定关系语义”与专项审计直接冲突。位置可以保留，机制不得继续按正式结论调用。

## 2. 对象分层

| 层级 | nx | x并z | 当前裁定 |
|---|---|---|---|
| 稳定本体 | 长期不占方向决定位置 | 长期通过表里分层存在 | 不从一次拒签反推人物本体 |
| 当前状态 | 暂不表态、不认领 | 壳正在吸纳主体 | 候选最可能成立层 |

| 场景 | 公司、组织、家庭 | 宣传、职位、共同声明 | 题材不能代替端点 |

## 3. 源端点、目标端点与变量

### 源端点 nx

```text
方向、权限或解决通道已经由关系、他者、流程或现状给出
→ 主体不把自己放在最终决定位置
→ 同时不主动认领、复述或代表壳要求的立场
```

排除：看穿骗局、公开揭露、主动反抗、价值拒绝、能力不足、被禁止表态。

### 目标端点 x并z

必须是一层需要主体接口才能完成覆盖的稳定壳：身份、包装、共同说法、公开角色或表面秩序。

### 被改变变量

- 壳能否把主体纳入身份范围；
- 主体是否完成认领、复述和履行；
- “我们都这样认为”能否成立；
- 壳对主体行为的解释权；
- 壳的覆盖范围是否真实缩小。

## 4. 候选机制

### 候选A：认领接口缺失

```text
x并z 要把主体纳入身份、包装或共同说法
→ 壳需要主体复述、履行或默认承认
→ nx 不占认领与表达位置
→ 壳无法完成“这也是你的身份／立场”
→ x并z 对该主体的吸纳范围下降
```

理论后果：克制对象不是整个壳，而是壳把特定主体纳入自身的接口。

### 候选B：共同背书链中断

```text
共同壳依赖成员形成“大家都这样”的现实
→ nx成员不提出反壳，但也不完成复述与背书
→ 共同说法缺少关键一环
→ 壳对群体的覆盖范围下降
```

理论后果：被改变的是共同壳覆盖范围，不是壳内部真假。

## 5. 正例候选

1. **《千与千寻》千寻与“小千”身份阶段**：行动上进入油屋流程，却未完整认领“小千”为全部身份。支持“行动跟随不等于身份认领”，但混入白龙帮助、真名记忆、汤婆婆权能和千寻后期主动性，不能独立锁定。
2. **《黑客帝国》尼奥离开“托马斯·安德森”办公室壳阶段**：不再履行员工身份接口后，公司壳无法继续稳定覆盖他；但混入主动选择、追捕、现实离职与证据暴露。
3. **组织共同声明中的不背书成员**：成员不公开反对，只是不签字、不复述、不允许名字进入“全体一致”声明，使壳只能覆盖多数。结构纯度最高，但缺具体人物文本。

## 6. 反例

- 记者搜证揭露公司造假：启动源更接近 `xn/zn/z/zx`；
- 下属因恐惧签署虚假声明：nx可能上升，但x并z反而获得接口；
- 看穿伪装却继续完整扮演：认知变化没有改变壳接口；
- 撕下面具公开宣告真实身份：主要是主动占位；
- 卧底因证据泄露暴露：由外部证据击穿；
- 员工从未被要求背书：沉默不影响壳覆盖；
- 能力不足无法履行角色：只是状态失败；
- 少一个无关成员但包装仍完整成立：目标变量没有变化。

## 7. 最近邻排除

- 与 `zn 克 x并z`：因“这个身份不对”主动拒绝时，启动源优先判 `zn`；
- 与 `zx 克 x并z`：公开拆壳、强迫揭露与权能摧毁属于 `zx`；
- 与 `x 克 x并z`：撤销职位、资源、名称或合法接口属于 `x`；
- 与反向 `x并z 克 nx`：身份壳预设角色路径，使主体更沿既有方向行动，改变的是nx，而非壳覆盖。

## 8. 拿掉测试

1. 拿掉不认领后，完整复述和履行是否使壳恢复覆盖？
2. 拿掉主动揭露、公开拒绝和价值判断后，壳是否仍因接口缺失而受损？
3. 拿掉证据曝光与外部强制后，目标变化是否仍成立？
4. 拿掉壳对主体背书的需要后，沉默是否不再产生作用？
5. 拿掉主体原本可认领的位置后，是否只是没有资格？
6. 拿掉方向关系，只保留一次不签字，是否不足以构成稳定克制？

当前两个具体作品候选未通过全部测试，因此不得正式锁定。

## 9. 反向测试

```text
x并z 克 nx：
稳定身份壳预先规定主体怎样行动和被读取
→ 可用方向被角色要求限定
→ 主体更容易沿壳给出的安排推进
→ nx上升
```

正向改变壳的吸纳与覆盖，反向改变主体可用方向与角色路径。反向案例不能代替正向补证。

## 10. 动态链后果

```text
这个壳需要我说“这也是我”
→ 我没有另立旗帜，也没有主动拆壳
→ 但始终不完成认领
→ 壳只能停在我身外
```

改变的感觉层是：主体行动上可能跟随，但壳没有取得解释主体的资格。

不机械生成真相曝光、公开反抗、壳整体崩塌、恢复真实身份或群体全部退出。

## 11. 三元与十元并行

三元继续核验作品整体精神方向。十元只核验nx不认领、x并z接口依赖和壳覆盖变量。二者并行，不建立父子派生。

## 12. 95%门槛

### 已通过的修正结论

- 旧“看穿底牌就是nx克x并z”失效：99%；
- 公开揭露和主动拒绝不能直接归为nx：99%；
- 目标变量必须是吸纳、背书、覆盖与解释接口：98%；
- 生补克表4.3不应继续列为“已锁定关系语义”：99%。

### 未通过的机制结论

- 缺少两个第三因素足够弱的具体人物案例；
- 未完成生成与已经成立后被克制仍未区分；
- 候选A、B是否同一机制的不同体量尚未验收。

因此，本补丁只撤回错误锁定状态，不把候选机制抬为正式正本。
