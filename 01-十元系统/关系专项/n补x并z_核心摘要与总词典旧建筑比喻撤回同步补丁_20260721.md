# n 补 x并z｜同步补丁已并入现行入口

本文件不再作为 `canonical-amendment` 覆盖核心表或关系词典。

现行读取：

```text
n 为 x并z 提供真实可承载的内部；
x并z 为 n 提供可识别、可进入、可持续指认的公共界面；
两者互补，但不互相生成。
```

完整对象分层、双向变量、正反例、最近邻、拿掉测试和反向测试，继续以 parent 专项正本为准。

正式撤回“精装样板间 + 混凝土楼板”“漂亮门面 + 房间”“建筑内外并存即可证明互补”等旧建筑比喻。
