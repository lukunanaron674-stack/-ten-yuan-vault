# z 生 nz｜认可关系是否生成不愿结束机制二次审计

## 0. 审计结论

```text
几何位置：保留
旧“目标完成/获奖/录取后自然留恋”口径：撤回
当前可确认的窄机制：认可关系可能使“被认可位置本身”获得关系价值
独立 z生nz 普遍机制：未达到95%门槛
队列：继续沿用 UQ-20260718-005，不新增重复问题
```

本轮使用现行 `z v2.2`：z 不是普通完成、爆点或成功，而是某个认可主体看见、回应并确认主体的存在、能力、作品、身份或选择。

## 1. 关系对象分层

| 层级 | z | nz | 本轮纪律 |
|---|---|---|---|
| 稳定本体 | 长期依赖重要认可位置确认自身 | 长期保留关系余温，不愿承认结束 | 单次掌声或一次留恋不能反推本体 |
| 当前状态 | 被认可、否认、忽视后的释放或受挫 | 舍不得离开、延迟告别、维持余温 | 情绪先后不等于生位 |
| 行为功能 | 呈现、表达、让认可者看见 | 等待、回返、保留共同位置 | 行为不能替代端点 |
| 光影 | 聚光、观众、回应、署名 | 暖光、旧物、空位、余温 | 仅作显影证据 |
| 场景 | 展览、演出、答辩、公开确认 | 谢幕、撤展、毕业、告别 | 场景题材不自动成立 |
| 时间关系 | 认可发生在前 | 留恋出现在后 | 先后只提供候选 |
| 关系位置 | 认可者与被认可者 | 共同阶段、见证关系、可回返位置 | 必须说明对象是否相同 |
| 显影 | “这是你的能力/作品/选择”被确认 | “我不想让这段关系或阶段结束”增强 | 被改变变量必须落到后者 |
| 动态链 | 认可使某个精神位置成立 | 该位置是否沉淀为停靠关系 | 不把关系当机械生成器 |

## 2. 源端点与目标端点

### 源端点 z

必须同时明确：

```text
认可主体是谁
认可谁或什么
为什么该认可位置重要
该确认是否真实落到主体
```

### 目标端点 nz

必须已有或新形成：

```text
具有关系或共同阶段对象
存在时间厚度或可保留的共同位置
主体不愿让该关系/阶段真正结束
仍保留等待、回返或停靠姿态
```

### 被改变变量

- 对认可主体或共同见证关系的停靠意愿；
- 对被认可阶段结束的抗拒强度；
- 认可位置是否从一次判断变成可返回关系；
- 即使没有后续奖励，主体是否仍想保留这一共同位置；
- 拿掉原有友情、空间与长期共事后，留恋是否仍由认可新增。

## 3. 成立阶段、体量与显影条件

### 成立阶段

认可已经发生之后，主体开始把“认可者/被见证共同体/共同完成阶段”视为不愿失去的关系位置。

### 关系体量

- 低体量：认可后短暂不舍、赛后兴奋，不足以锁定。
- 中体量：认可后主动延长共同阶段、维护见证关系。
- 高体量：主体宁愿改变下一步选择，也要保留该认可关系或共同阶段。

### 显影条件

必须观察到至少一项：

- 主体延迟离开不是为了奖励，而是为了保留关系；
- 认可者从评价者变成可回返的关系对象；
- 共同完成被见证后，主体主动维护“我们仍在一起做这件事”的位置；
- 拿掉认可事件后，nz 强度明显下降。

## 4. 候选机制

### 候选 A：认可者转化为可停靠关系

```text
重要认可主体确认主体
→ 主体不再只把对方当评判位置
→ 认可关系获得情感与时间厚度
→ 主体希望该关系继续存在
→ nz 上升
```

理论后果：

> z 不是直接制造泛依恋，而是可能把一个重要认可位置转成不愿失去的关系位置。

风险：大量案例中，关系厚度早在认可前已经存在；此时只是既有 nz 被确认，并非 z 生 nz。

### 候选 B：共同被见证使阶段沉淀为余温

```text
多人共同完成某事
→ 作品或能力被重要主体共同见证
→ “这件事属于我们共同经历”被确认
→ 共同阶段获得不可替代性
→ 不愿结束增强
```

理论后果：

> 被改变的不是目标完成感，而是共同阶段在关系记忆中的唯一性。

风险：真正提供时间厚度的可能是 xn 长期共事、n 的共同容器或原有友谊。

### 候选 C：完成后自然空虚与留恋

```text
目标完成
→ 兴奋消退
→ 舍不得结束
```

排除。没有认可主体，也无法区分 nz、普通失落、惯性与转场困难。

### 候选 D：奖励与新身份制造停靠

```text
获奖/录取/签约
→ 进入新学校、团队或机构
→ 想留下
```

排除。可能是 x、n、xn 或 x并z 的变化，不是 z 直接生 nz。

## 5. 正例候选

### 5.1 固定剧团最终谢幕

具体阶段：固定剧团经过多年共同排演，在最后一场演出结束后获得重要观众与导演明确确认。

关系双方：

- z：观众与导演确认这群演员共同完成了不可替代的演出；
- nz 候选：演员不愿离开彼此及共同舞台位置，反复延长谢幕和告别。

支持点：认可明确落到“这群人共同完成的作品”，不是普通掌声。

限制：多年排练已形成强 xn 与既有 nz；拿掉最终认可，演员仍可能同样不舍。

### 5.2 毕业展小组撤展阶段

具体阶段：固定小组共同完成毕业展，观众明确确认其作品与合作方式，撤展时成员主动延迟离开并保留共同创作计划。

关系双方：

- z：观众和导师确认“这是你们共同完成的作品与能力”；
- nz 候选：成员希望被共同见证的关系和阶段继续存在。

支持点：如果没有公开确认，他们只把项目视为课程任务；确认后才开始把小组视为值得延续的共同位置。

限制：需要真实个案证明认可前后 nz 强度差异，目前仍是结构候选。

### 5.3 《爆裂鼓手》安德鲁与弗莱彻，结尾对视

具体阶段：安德鲁最终演奏中获得弗莱彻通过对视和协作给出的专业确认。

关系双方：

- z：安德鲁的鼓手能力被其最重要的专业认可主体确认；
- nz 候选：他是否因此希望保留与弗莱彻之间的音乐关系和舞台位置。

支持点：认可位置极其明确。

不通过原因：影片没有充分显示“不愿关系结束”或持续停靠，更多是当场 z 完成与高压关系闭环，不能作为正式正例。

## 6. 反例

1. 考生收到录取通知后进入学校：这是结果、新结构或 n/xn 变化，没有证明不愿结束旧阶段。
2. 运动员夺冠后立刻追逐下一目标：z 延续，没有 nz。
3. 获奖者舍不得奖杯：对象留存可能是 x 或记忆载体，不等于关系停靠。
4. 演员本来就舍不得剧团，即使演出失败也不想离开：nz 先于 z。
5. 观众鼓掌后演员短暂兴奋：当前状态，不是关系沉淀。
6. 导师长期照顾学生，最后给予认可：留恋可能来自 n 的承载和既有关系。
7. 公司表彰后员工愿意留下：可能是奖励、身份、待遇与组织归属，不足以证明 z生nz。

## 7. 最近邻排除

### 与 xn 补 z

`xn补z` 改变认可的证据连续性与阶段收束；`z生nz` 若成立，改变的是认可后对关系或共同阶段的不愿结束。

### 与 n

n 提供真实承载、成员位置和可返回容器。若留恋主要来自长期被接住，不能归给 z。

### 与 xz 补 nz

xz 通过可能永远失去和返回窗口缩窄，提高停靠选择重量。z 则必须通过“被确认”本身提高关系停靠强度。

### 与 nz 生 z

原有不舍可能推动主体完成最后一次作品、演出或表达，让对方看见自己。若依恋先于认可，方向是 `nz→z`，不能倒写。

### 与 x并z 生 z

公开身份壳使认可正确识别与归因；它不解释认可后为何不愿关系结束。

## 8. 拿掉测试

1. 拿掉公开认可后，人物是否仍同样舍不得共同阶段？若是，不依赖 z。
2. 拿掉既有友情、共同空间与长期共事后，认可是否仍产生持续停靠？当前无高纯案例稳定通过。
3. 拿掉奖品、录取、签约和新身份后，不愿结束是否仍增强？若否，只是外部结果。
4. 拿掉认可主体，只保留目标完成，若留恋仍出现，只能证明完成后状态变化。
5. 拿掉 nz 行为，只保留兴奋、感谢和释放，目标端点不存在。

## 9. 反向测试

交换为 `nz 生 z`：

```text
主体不愿共同阶段结束
→ 希望通过最后一次作品、演出或表达让对方看见
→ 认可关系被主动追求
```

这一方向在最终演出、告别作品和临别表达中更容易找到纯案例。

方向切口：

```text
z生nz：认可先改变关系停靠强度
nz生z：既有不舍先推动最后一次被看见
```

## 10. 动态链后果

若候选 A/B 成立：

```text
我终于在重要位置上被你/你们确认
→ 这个位置不再只是评判席
→ 它成为我不愿失去的共同关系或阶段
→ nz 上升
```

当前更稳妥的结论：

```text
z 可以使既有 nz 显影、被命名或获得共同见证
但是否能在缺少既有关系厚度时独立生成 nz，证据不足
```

改变的是关系层的停靠强度，不是自动生成友情、归属、依恋或永久留任。

## 11. 三元与十元并行

三元继续核验作品整体精神运动。

十元本轮只核验：

- z 的认可主体、认可内容与重要位置；
- nz 的关系余温与不愿结束；
- 认可前后停靠强度是否变化；
- 既有关系、n、xn、奖励与转场是否为第三因素。

不建立父子派生，也不从谢幕、毕业和获奖题材反推稳定本体。

## 12. 95%门槛

### 高置信修正

- 99%：旧“完成/获奖/录取后自然产生停靠”不是合格机制。
- 99%：z 必须使用认可主体结构，不能继续写成目标爆点。
- 98%：目标变量必须是关系或共同阶段的不愿结束，而非兴奋、空虚或结果留存。
- 97%：现有候选案例均需排除既有 nz、n、xn 与奖励因素。

### 未达到95%的部分

- 认可者是否能仅因一次重要确认，直接转化为具有时间厚度的停靠关系；
- “共同被见证”是否是独立机制，还是只命名并强化已经由长期共事产生的 nz；
- 当前没有至少两个通过拿掉测试的高纯具体人物案例。
