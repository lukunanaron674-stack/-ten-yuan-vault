# n 克 xz｜承载结构吸收临界风险正式机制

## 1. 审计结论

本轮正式锁定：

```text
n 已经形成可接收、保护、处理并持续维持的承载结构
→ xz 主体或对象进入该结构的有效承载范围
→ 逼近危险被结构隔开、吸收或持续处理
→ 主体获得可停留位置，不再必须沿风险路径继续移动
→ 危险可到达性、退路压缩与行动紧迫度下降
→ xz 被克制
```

最短表达：

> **n 不是通过关住漂流者克 xz，而是通过接住漂流者、隔开危险并让其可以停止赶路，降低 xz。**

## 2. 源端点与目标端点

### 2.1 源端点 n

n 必须已经具备至少一项稳定承载能力：

- 接收进入者，而非把对象推出去；
- 提供内部位置，使对象能够暂时或持续存在；
- 承担保护、照顾、补给或处理；
- 在外部压力下仍保持一定抗崩能力；
- 允许对象不必立即再次离开。

房屋、城墙、家庭、医院、收容所等名称只属于场景候选。只有它们实际接收、保护和处理对象时，才构成 n。

### 2.2 目标端点 xz

xz 必须已进入可观察临界：

- 危险以可感知形态逼近；
- 安全路线减少；
- 无法稳定停留；
- 不行动就会被吞没、追上或错过最后窗口；
- 主体被迫沿风险路径继续移动。

一般悲伤、身份焦虑、旅行、黑暗气氛或处于陌生场所，不足以构成 xz。

### 2.3 被改变变量

本关系改变：

1. 危险对主体的可到达性；
2. 安全停留时间；
3. 必须继续移动的紧迫度；
4. 可用退路和安全路径数量；
5. 外部冲击直接落到主体身上的比例；
6. 主体能否从“通道上的人”变成“内部被接住的人”。

## 3. 对象分层

| 层级 | 判定 |
|---|---|
| 稳定本体 | 不因一次收留判人物稳定 n；不因一次逃亡判人物稳定 xz |
| 当前状态 | n 此刻接住并处理；xz 此刻被危险逼近、不能停留 |
| 行为功能 | 开门、收留、救治、补给、掩护；逃离、抢时间、穿越风险路径 |
| 光影 | 暖室、围墙、逆光出口、暴雨只作视觉证据 |
| 场景 | 家庭、社区、医院、避难所、城镇不自动等于 n |
| 时间关系 | 先逃亡后进入某地，只能证明先后，不能自动证明克制 |
| 关系位置 | 主人、居民、医生、守门人只有实际承载时才属于源端点 |
| 显影 | 观察危险是否更难抵达、主体是否获得真实停留能力 |
| 动态链 | 改变临界与漂流强度，不自动生成依恋、归属或永久安全 |

## 4. 候选机制

### 候选 A：危险隔离与冲击吸收

```text
n 位于危险与主体之间
→ 由墙体、成员、资源或照护能力承担外部冲击
→ 危险不能直接落到主体
→ xz 的逼近强度下降
```

理论后果：

- n 的核心不是控制主体，而是承担原本会直接压到主体身上的东西；
- 高体量 n 可以把一次临时避难变成持续安全区。

### 候选 B：漂流落地与行动紧迫解除

```text
xz 主体原本必须不断移动
→ n 提供可停留、可补给、可返回的位置
→ 主体不再必须抢下一条路线或最后窗口
→ 风险路径的强制性下降
```

理论后果：

- 克制发生在“必须继续走”被解除；
- 即便外部危险仍存在，只要主体能够停下并被接住，xz 已发生局部下降。

### 候选 C：拘禁与路径封锁

```text
制度、权限或强权把主体关住
→ 主体无法继续移动
```

本轮正式排除为 `n 克 xz` 的充分机制。

无法移动不等于被承载。若主体被锁闭、驱逐、审核、命令或剥夺出口，应优先检查：

- xn 的规则与流程；
- x 的地盘、权限和出口掌握；
- zx 的公开强制；
- xz 危险本身的捕获。

### 统一机制

候选 A 与 B 是同一机制的两面：

> **n 一方面替主体承受危险，另一方面提供内部位置，使主体不再必须靠继续移动来活下去。**

## 5. 成立阶段、体量与显影条件

### 成立阶段

1. xz 已经显形，主体正处于风险路径；
2. n 已实际运行，而非只有容器外观；
3. 主体进入 n 的承载范围；
4. 危险可到达性或继续移动紧迫度发生下降。

### 关系体量

- **低体量**：短暂躲雨、急救、藏身，使危险延迟抵达；
- **中体量**：安全屋、家庭、社区持续接收并提供补给；
- **高体量**：稳定聚落、后方或保护网络长期吸收外部风险，使漂流生活结束。

### 显影条件

必须至少观察到一种变化：

- 追兵无法直接进入；
- 主体获得食物、治疗、休息和安全时间；
- 主体不必立即寻找下一条逃生路线；
- 危险被其他结构承担和处理；
- 主体可以反复返回，而不只是穿过。

## 6. 正例

### 正例一：《最后生还者》乔尔与艾莉进入杰克逊聚落阶段

**源端点 n：**

杰克逊不是一幅“有围墙的小镇”图片，而是实际运行的聚落：有住房、供电、巡逻、食物、医疗、成员分工和接收关系。

**目标端点 xz：**

乔尔与艾莉此前长期穿越感染区和敌对区域，危险持续逼近，无法稳定停留，生存依赖不断移动和抢路线。

**作用结果：**

```text
杰克逊接收二人
→ 聚落承担巡逻、防御、补给与居住
→ 二人不再每天沿感染与追杀路径迁移
→ 安全停留时间上升，必须继续赶路的紧迫度下降
→ xz 被中高体量克制
```

**第三因素：**

汤米的关系引见含 nx；聚落制度含 xn。但被改变的目标变量明确是“能否停下并由结构承担危险”，因此 n 是直接作用端点。

### 正例二：《行尸走肉》瑞克一行进入亚历山大安全区初期

**源端点 n：**

亚历山大提供围墙、住房、水电、食物、医疗与成员位置，并尝试接收外来幸存者。

**目标端点 xz：**

瑞克一行此前长期在公路、树林和临时据点间移动，外部危险随时可达，无法稳定休息。

**可观察结果：**

- 第一次能够在屋内睡觉、洗澡、补给；
- 不再需要每天寻找下一处临时营地；
- 外部尸群与敌人的风险先由围墙和社区防御承担；
- 漂流与行动紧迫度明显下降。

后续安全区被攻击，不否定前一阶段的克制成立。关系只需证明在明确阶段内目标变量下降，不承诺永久无风险。

### 正例三：运行中的灾后避难所

居民在洪水中被迫不断转移。一个已经运行的避难所接收居民，提供高地、床位、医疗、食物与持续值守。

```text
洪水和失温风险逼近 xz
→ 避难所实际接收并处理负荷 n
→ 居民不必继续在夜间寻找路线
→ 危险可到达性和移动紧迫度下降
```

这比“收容所把流浪猫关进笼子”纯得多，因为重点是接住与保护，不是剥夺移动权。

## 7. 反例

### 反例一：移民局签证制度拦住流浪者

规则、审核和权限限制移动，优先属于 xn 与 x。它没有证明主体被接收、保护或允许停留，甚至可能使其更接近危险临界。

### 反例二：收容所把流浪猫关进笼子

若只有捕捉、锁闭和无法离开，没有照护、接收和风险缓冲，则只是拘禁或路径封锁。不能拿“动不了”冒充“被接住”。

### 反例三：恋人使逃亡者不想离开

被改变的是关系结束意愿与依恋强度，优先检查 nz。若没有实际安全结构，危险仍可直接到达，n 未成立。

### 反例四：空房子让逃亡者暂时躲藏

房屋只有空间外观，没有持续接收、保护与处理能力。它最多是一次场景工具，不足以判稳定 n 作用。

### 反例五：监狱让逃亡者停止漂流

监狱通过规则、权限、看守与强制关闭路径，主体可能反而进入更强的危险逼近和无退路状态。停止移动不等于 xz 下降。

## 8. 最近邻排除

### 与 `nz 克 x` 或 `xz ↔ nz` 命运补位

- nz 改变“我是否愿意结束这段关系、是否想停靠在某人身边”；
- n 克 xz 改变“危险能否抵达、我是否有条件停下来”。

一句话区分：

```text
nz：我想留下
n：这里接得住我，所以我可以留下
```

### 与 xn 的规则保护

门禁、巡逻表、登记和分工属于 xn 行为。只有这些结构最终形成真实接收、保护和抗崩能力，才构成 n 端点；不能把规则本身直接写成 n。

### 与 x 的地盘控制

“这里归我，别人不能进”优先属于 x。若控制者只是排除外人，却不接收、照顾或承担内部成员，不能判 n。

### 与 zx 的救援行动

英雄冲入危险把人带走，是 zx 或行动功能。被救者进入能够持续承载的结构后，才启动 n 克 xz。

### 与 xz 自然结束

追兵自行离开、暴风自然停止、倒计时结束，不是 n 的作用。必须证明风险下降依赖承载结构。

## 9. 拿掉测试

1. 拿掉 n 的接收、保护和处理能力，只留下建筑，xz 是否仍同样下降？若是，则不依赖 n。
2. 拿掉外部危险，主体本来就可以停留，则没有 xz 目标端点。
3. 拿掉墙、成员、补给和照护后，主体又必须继续移动，支持本关系。
4. 拿掉情感依恋，主体仍因结构安全而能够停下，说明不是 nz 替代。
5. 拿掉规则和命令，只要承载仍能实际运行，关系仍可成立；说明不以 xn 或 zx 为必要源端点。

## 10. 反向测试

交换为：

```text
xz 克 n
```

其机制可能是：

```text
持续逼近的危险、追杀或灾难
→ 超过容器接收与抗崩能力
→ 成员被迫撤离，照护与保护中断
→ n 失去承载能力
```

方向不对称：

- `n 克 xz` 改变危险可到达性、行动紧迫度和漂流强度；
- `xz 克 n` 改变容器的接收、保护和持续运行能力。

同一故事可以形成反馈，但必须分阶段记录。

## 11. 动态链后果

```text
危险在身后不断逼近
→ 我只能不停向前，任何地方都只是通道
→ 一个结构真正接住我，并替我承担外部压力
→ 我第一次不需要靠继续逃跑来维持存在
```

改变的感觉层是：

> **世界从“所有地方都只是下一段逃生路线”，转成“终于出现一个能够把危险留在外面的内部”。**

本关系不表示：

- 承载结构永久安全；
- 主体必然产生依恋或归属；
- 所有房屋、城镇和家庭都是 n；
- 关押、审核、封路与限制自由都属于 n；
- xz 人物从此改变稳定本体。

## 12. 三元与十元并行核验

三元继续独立核验作品整体精神运动。

十元本轮只核验：

- n 是否已经形成真实承载；
- xz 是否处于危险逼近与风险路径；
- 危险可到达性与继续移动紧迫度是否下降；
- 关系方向是否正确。

不从局部收留反推稳定三元，也不把 n 写成 xz 的父级或派生来源。

## 13. 95%门槛

### 通过：97%

理由：

- 两端点与现行 n、xz 信息量卡一致；
- 候选 A、B 能统一为“承担危险 + 提供内部停留位置”；
- 两个具体作品阶段和一个纯结构例均能观察目标变量变化；
- 五个反例稳定排除拘禁、制度阻拦、情感停靠、空间外观与自然结束；
- 最近邻、拿掉测试和反向测试均通过；
- 不需要改写 n 或 xz 的本体定义。

本轮不新增待用户确认问题。

## 14. 对旧口径的处理

正式撤回：

```text
移民局的签证制度拦住流浪汉
收容所把流浪猫关进笼子
```

它们把 xn/x/zx 的路径限制与拘禁误写为 n 的承载。旧材料可保留作为反例，但不得继续作为 `n 克 xz` 的纯案例。
