# x 克 nz：总词典与核心摘要待同步补丁

## 0. 读取结论

> **x 把关系对象纳入“归我决定、由我调用、不能自由退出”的掌握边界，使继续停留不再是自主选择，回返也不再能证明关系余温，由此克制 nz。**

本补丁只覆盖总词典和核心摘要中未同步、过宽或题材化的旧解释；正式机制仍以 parent 专项正本为准。

正式状态：

```text
几何位置：已锁定
机制：已锁定
成立层：关系层／阶段层
置信度：98%
```

## 1. 关系对象分层

| 层级 | x | nz | 审计要求 |
|---|---|---|---|
| 稳定本体 | 长期依靠归属、占有与掌握边界成立 | 长期保留关系余温与回返姿态 | 不从一次控制或一次不舍反推本体 |
| 当前状态 | 此阶段收紧关系控制 | 此阶段停靠意愿下降 | 正式机制主要发生层 |
| 行为功能 | 替代决定、限制退出、控制交往与路线 | 等待、回返、继续靠近 | 必须观察自主停靠变量 |
| 光影 | 门锁、定位、密码、封闭空间 | 暖光、旧物、回望、旧居 | 只作显影 |
| 场景 | 亲子、伴侣、监护、家庭 | 家、旧爱、共同生活 | 题材不代替端点 |
| 时间关系 | 掌握边界先收紧 | 余温与回返随后受损 | 先后不自动证明克制 |
| 关系位置 | 掌握者与被掌握者 | 返回者与关系对象 | 必须位于同一关系结构 |
| 显影 | 否决、独占、调用、退出控制上升 | 自愿停留、回返、不愿结束下降 | 两端均须可观察 |
| 动态链 | “你在我的范围内” | “我还愿不愿回来” | 不机械生成分手或仇恨 |

三元与十元并行，不建立父子派生。

## 2. 源端点、目标端点与变量

### 2.1 源端点 x

必须存在具体关系掌握：

- 替对方决定行动、交往、身份或人生路线；
- 掌握进入、退出和返回许可；
- 实际使用最终否决权；
- 把对方视作“归我管理、由我保护、由我调用”的对象；
- 即使不公开显权，控制关系仍持续有效。

一次吃醋、一次争吵、一次建议、一次临时保护，或只有“控制欲”形容词，不足以成立。

### 2.2 目标端点 nz

克制前必须已有：

- 真实共同时间；
- 关系余温；
- 不愿承认关系结束；
- 等待、回返或继续停靠姿态；
- 对具体关系位置的温柔保留。

### 2.3 被改变变量

1. 停留是否仍为自主选择；
2. 离开与返回是否仍由关系主体决定；
3. 回返能否继续证明“我还想回来”；
4. 共同生活是否由柔情关系变成管理关系；
5. 原关系位置的安全感与可信度；
6. 不愿结束是否转成逃离、躲避或切断联系。

## 3. 成立阶段、体量与显影条件

```text
关系已经形成余温
→ 掌握者持续收紧决定、退出与回返边界
→ 被掌握者的停留不再能被视为自愿
→ 原关系位置从可返回处变成被管理范围
→ nz 下降
```

体量：

- 低体量：少量事项被代决，停靠意愿轻微下降；
- 中体量：交往、时间与行动路线持续受控；
- 高体量：退出权、身份与人生路线被纳入掌握，关系形式仍在但停靠已转为逃离欲。

显影必须同时满足：原有 nz、x 掌握真实增加、自主退出或回返权下降、停靠意愿实际下降，并排除 zx 暴力、xn 监控流程、法律强制和原本无余温为唯一启动源。

## 4. 候选机制

### A. 自愿性被抽空

```text
x 收紧关系掌握
→ 留下、离开与返回均受控制
→ “仍留在这里”不再证明主体愿意停靠
→ nz 失去自愿性证据
→ 余温下降
```

理论后果：x 可以让人继续留在场景中，却同时使 nz 消失。

### B. 关系位置被管理位置替代

```text
掌握者持续替对方决定
→ 对方不再作为独立关系主体出现
→ “我们之间”变成“你在我的范围内”
→ 原关系位置被管理关系替代
→ nz 无处停靠
```

理论后果：改变的不是物理距离，而是关系对象资格。

统一机制：

> **x 先抽空停靠的自愿性，再把关系位置替换成管理位置。**

## 5. 正例

### 5.1 《海底总动员》马林与尼莫

- x：马林替尼莫决定可去哪里、能做什么，并持续使用最终否决权；
- nz：父子共同生活形成的亲密余温，以及尼莫对父亲和家的停靠；
- 变化：保护名义下的掌握不断扩大，家被体验为管理范围，尼莫以离开争取自主。

拿掉马林的替代决定与否决边界，父子余温不需要通过逃离来争取自主，因此通过核心测试。

### 5.2 《青春变形记》明与美美

- x：母亲掌控美美的时间、朋友、身体解释权、公开形象与人生安排；
- nz：长期母女关系和家庭共同生活形成的停靠；
- 变化：家庭停靠逐渐等同于放弃自身路线，美美选择离开母亲设定的仪式轨道。

拿掉身体、交往与身份掌握，只保留关心，冲突不会以“必须离开家庭轨道才能成为自己”的方式成立。

### 5.3 《魔发奇缘》葛朵与乐佩

- x：葛朵掌握空间、信息、身份解释、外界通道与离塔许可；
- nz：长期共同生活形成的母女式依恋与回返余温；
- 变化：塔从可返回的家变成不能自由退出的管理空间，乐佩获得外部路线后停靠意愿迅速转向离开。

身份欺骗含 x并z、威胁含 zx，但“不能自由离开”的掌握变量独立成立。

## 6. 反例

1. 伴侣一次吃醋但没有限制行动与退出权；
2. 家长提出安全建议，孩子保留最终决定权；
3. 暴力威胁对方不准离开，主要是 zx；
4. 安装监控系统但主体没有最终调用和否决权，可能是 xn；
5. 关系原本已经没有余温，目标端点不存在；
6. 双方自愿共享位置和账户，并可随时撤回；
7. 短期医疗监护有明确退出条件，优先检查 n 与 xn；
8. 人物仍愿自主回家、主动联系和回返，尚未证明 nz 下降。

## 7. 最近邻排除

- 与 `zx 克 nz`：x 是“你归我决定”；zx 是“我公开逼你服从”。
- 与 `xn 克 nz`：xn 通过流程、排程与监控消耗关系；x 直接改变最终决定、退出与调用权。
- 与 `x并z 克 nz`：x并z 让主体不知道自己停靠的真实对象是谁；x 让主体知道对方是谁，却不能自由决定是否停靠。
- 与 `n`：保护保留自主路线时属于 n；保护进入单向否决与退出控制后才越过为 x。
- 与反向 `nz 克 x`：正向改变停靠自愿性，反向改变独占、否决与调用边界。

## 8. 拿掉测试

1. 拿掉 x 的实际掌握，只保留关心、建议或情绪，nz 是否仍下降？
2. 拿掉 nz，原关系没有余温，目标端点不存在。
3. 拿掉 zx 威胁，只保留低调决定、否决与退出控制，nz 是否仍下降？
4. 拿掉 xn 监控流程，只保留最终权限，关系是否仍受损？
5. 恢复退出、否决与自主回返权后，nz 是否回升？
6. 物理上仍共同生活，但不再主动回返，说明场景停留不能代替 nz。

三个具体案例均通过核心拿掉测试。

## 9. 反向测试

交换为 `nz 克 x`：

```text
掌握者仍珍惜关系余温
→ 发现继续控制会让对方真正离开
→ 主动恢复决定、退出与回返权
→ x 的关系掌握边界下降
```

方向切口：

- `x克nz` 改变自愿停靠与回返意愿；
- `nz克x` 改变独占、否决、替代决定与调用边界。

## 10. 动态链后果

```text
关系仍在，甚至共同生活仍在
→ 掌握边界持续收紧
→ 留下不再能证明愿意留下
→ 家或关系位置变成管理范围
→ nz 从温柔停靠转为逃离、躲避或断联
```

改变的是关系停靠的自愿性与可信度，不把关系当成自动制造分手、仇恨或永久断裂的机械生成器。
