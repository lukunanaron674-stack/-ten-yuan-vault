# xz 生 zx｜危险迫使潜在权能公开，还是仅提供显影机会（二次审计）

## 0. 本轮结论

`xz 生 zx` 的几何位置继续保留，但正式机制仍未达到 95% 锁定门槛。

本轮把旧审计中的两个候选进一步压缩为一个最窄候选：

> **危险临界使旧秩序无法继续提供方向，迫使原本未公开承担决定位置的主体，以自身力量公开接管局面；被改变变量必须是主体的公开决定范围、他者服从关系与现实权能位置，而不是勇气、战斗或逃生效率。**

仍未锁定的核心原因：现有高质量案例大多要求主体已经拥有能力、关系信用、职位、计划或稳定 zx 倾向。当前证据更容易证明“xz 迫使潜在 zx 显影”，尚不足以证明“xz 独立生成 zx”。

## 1. 关系对象分层

| 层级 | xz | zx | 本轮要求 |
|---|---|---|---|
| 稳定本体 | 长期处于危险逼近、退路缩窄与无法停留 | 长期依赖显权、扩权与凌驾成立 | 不从一次危机领导反推稳定本体 |
| 当前状态 | 此刻危险显形且不行动会被吞 | 此刻公开接管、夺回或扩大决定位置 | 本轮最可能成立层 |
| 行为功能 | 逃跑、冒险、抢先选择、穿越风险 | 宣告、夺位、指挥、迫使环境重排 | 行动必须改变权能位置 |
| 光影 | 警报、逼近阴影、倒计时、断路 | 中心构图、聚光、居高、众人转向 | 仅作显影证据 |
| 场景 | 灾难、追杀、战争、封锁、失控现场 | 指挥中心、公开领路、夺取控制台 | 场景不能替代端点 |
| 时间关系 | 危险先出现 | 显权随后出现 | 先后不自动证明生成 |
| 关系位置 | 被局面规定者、逃亡者、受困者 | 新决定中心、领路者、公开权能主体 | 必须发生位置重排 |
| 显影 | 退路和旧路径真实缩窄 | 决定范围、服从度与公开影响范围扩大 | 两端都须可观察 |
| 动态链 | 世界正在逼我行动 | 我开始规定世界如何行动 | 不机械生成胜利 |

## 2. 源端点、目标端点与变量

### 2.1 源端点 xz

必须同时满足：

1. 危险已经以可感知形态逼近；
2. 旧的安全路径、时间窗口或退路真实缩窄；
3. 不行动会导致主体或关系被吞没；
4. 危险不是只在背景中存在，而是直接改变可用选择。

### 2.2 目标端点 zx

必须出现：

1. 主体力量公开进入现实；
2. 主体从被局面规定转为规定局面；
3. 决定范围、影响范围或权能位置扩大；
4. 他者、环境或既有等级围绕其力量重新反应。

### 2.3 被改变变量

- 谁拥有现场最终方向决定权；
- 主体公开权能的可见范围；
- 他者是否转而服从、跟随或退位；
- 旧秩序是否失去决定资格；
- 主体是否成为新的现实运行中心。

### 2.4 成立阶段、体量与显影条件

- 低体量：主体在局部关系中夺回决定权；
- 中体量：主体公开重定团队路线并让多人跟随；
- 高体量：危机使旧等级失效，主体成为新的权力中心。

显影条件：拿掉危险后，该主体不会在该时间点公开扩权；拿掉权能位置变化后，案例不能只剩求生、勇敢或计划执行。

## 3. 候选机制

### 候选 A：退路剥夺迫使潜在权能公开

```text
危险逼近并封死延后空间
→ 原本可以隐藏、等待或只局部使用的能力不再够用
→ 主体必须公开夺回方向并压过障碍
→ 决定范围与影响位置扩大
→ zx 上升
```

理论后果：该机制最稳妥地说明“显影时点为何被提前”，但它可能只证明潜在 zx 被迫公开。

### 候选 B：旧秩序失效形成权力真空

```text
临界危险使原有指挥、规则或等级无法继续反应
→ 现场出现无人能够决定方向的空位
→ 主体以自身力量接管并让他者围绕其行动
→ 新的公开决定中心形成
→ zx 上升
```

理论后果：若成立，生成点不在恐惧本身，而在危险造成的关系位置空缺。

### 候选 C：危机只触发普通反击或逃生

```text
危险出现
→ 人物跑、打、躲、求救或执行预案
```

排除。目标变量没有落到显权、扩权和凌驾。

### 候选 D：意义、职位或计划借危机显影

- 因“必须救人”公开领导，优先检查 `zn 生 zx`；
- 因职位本来就负责指挥，优先检查既有 x / zx；
- 按应急预案组织行动，优先检查 xn；
- 通过他人权限和关系网络推进，优先检查 nx。

## 4. 正例候选

### 4.1 《疯狂的麦克斯：狂暴之路》弗瑞奥萨，绿洲失效后决定反攻

**xz：**绿洲已毁，继续向盐地漂流几乎必死，停靠位置与退路同时消失。

**zx 候选：**弗瑞奥萨从逃亡队伍中的驾驶者，转为公开重定全队方向、带领反攻，并在结尾改变城堡权力结构的决定中心。

**支持点：**危险不是只让她继续逃，而是使她公开规定所有人往哪里走，并最终让城堡秩序围绕其行动重排。

**第三因素：**既有战斗能力、团队信任、资源判断和潜在领导位置都很强。更稳妥的解释仍可能是 xz 迫使既有 zx 高显影。

### 4.2 《釜山行》尚华，列车感染扩散后的车厢突破阶段

**xz：**感染者逼近，车厢安全路径不断缩窄，不突破就会被吞没。

**zx 候选：**尚华公开站到队伍前方，以自身力量决定突破节奏、压过感染者，并使其他幸存者围绕其行动跟随。

**支持点：**他不只完成个人反击，而是在局部关系中成为公开领路和决定中心。

**第三因素：**其体能和保护家人的 zn 很强；权能扩大主要局限于临时现场，危机后是否持续并不明确。

### 4.3 《你的名字。》三叶，彗星坠落前推动全镇疏散

**xz：**彗星即将坠落，时间窗口与退路极度缩窄。

**zx 候选：**三叶从被父亲否定的位置，转向公开推动镇民改变行动方向。

**第三因素：**广播、破坏设备、计划分工属于 xn；镇长权限、同伴协作与记忆信息均为强中介。该案例更适合证明“危险要求权能进入现实”，不够纯地证明 xz 独立生成 zx。

## 5. 反例

1. 火灾中跟随消防员逃生：主体没有取得决定权，主要是 nx。
2. 被追杀者击倒一名敌人后继续逃跑：只是 xz 的局部反击。
3. 团队按既定预案撤离：主要是 xn 的结构运行。
4. 军官按职位下令：权能位置本来存在，危险只是显影机会。
5. 因道德确信冒险救人：优先检查 `zn 生 zx`。
6. 群众因恐惧听从最强者：可能只有服从结果，未证明主体权能真正扩大。
7. 夺权后才遭追杀：方向更接近 zx 引发 xz，不能倒写。
8. 个人在危险中表现勇敢但无人跟随、环境未重排：没有 zx 目标端点。

## 6. 最近邻排除

### 6.1 与 xz 行动型子骨

xz 自身已经包含临界行动、冒险与抢先选择。只有行动让主体成为更高决定力量，才进入 zx。

### 6.2 与 zn 生 zx

- `zn 生 zx`：意义先决定“必须这样做”，再推动权能公开进入现实；
- `xz 生 zx` 候选：危险先关闭延后与退路，使主体不得不公开接管。

### 6.3 与 xn

预案、排程、分工和资源组织属于 xn。计划执行成功不等于 zx；必须另证主体公开决定范围扩大。

### 6.4 与 z

被看见、获奖或成为焦点不足以构成 zx。zx 要求现实权能位置、影响范围和凌驾强度改变。

### 6.5 与 x

掌握武器、职位、资源和权限属于 x。只有这些力量公开显现、扩张并压到现实之上，才是 zx。

## 7. 拿掉测试

1. 拿掉危险临界后，主体是否仍会在同一阶段公开扩权？若会，xz 不是必要源端点。
2. 拿掉显权和权力位置变化，只保留逃跑、反击、救人或计划成功，案例是否仍完整？若是，zx 不成立。
3. 拿掉他者跟随、退位或环境重排，只剩个人能力展示，不能证明目标端点。
4. 拿掉既有能力、职位、计划和意义后，若所谓 zx 完全消失，说明危险可能只提供显影机会。
5. 恢复旧秩序的有效指挥后，若主体不再取得更高决定位置，支持“权力真空”是关键中介。
6. 危机结束后权能位置立即归零，只能判局部状态层，不可扩张为稳定人物本体。

三个候选均未通过“拿掉既有能力、意义或组织条件后仍能稳定生成 zx”的纯度测试。

## 8. 反向测试

交换为 `zx 生 xz`：主体公开扩权、夺位和凌驾后，可能制造追捕、封锁、敌意和新的危险路径。

方向切口：

```text
xz 生 zx 候选：危险先关闭退路，主体随后公开接管
zx 生 xz 候选：显权先改变秩序，危险随后反扑
```

“反抗后遭追杀”的案例不能反向用于证明本关系。

## 9. 动态链后果

若候选 A 成立：

```text
危险逼得我不能再隐藏力量
→ 我把权能推到现实台面
→ 从被局面规定，转为公开规定局面
```

若候选 B 成立：

```text
旧秩序在临界现场失灵
→ 决定位置出现空缺
→ 我以自身力量占据空位
→ 他者开始围绕我行动
```

改变的是**现实决定中心的位置**，不是普通勇气、胜利或行动速度。

## 10. 三元与十元并行核验

三元继续核验作品整体精神感觉。十元本轮只核验：

- xz 是否先真实压缩退路；
- zx 是否随后扩大公开决定范围；
- 旧秩序是否失效并发生关系位置重排；
- zn、xn、x、nx 与既有 zx 是否为真正启动源。

不建立命运主题与因果主题的父子派生。

## 11. 95% 门槛

### 高置信通过部分

- 99%：危险后的普通反击、逃生成功和一次战斗不能证明 `xz 生 zx`。
- 99%：目标变量必须是公开决定范围、他者服从关系与权能位置扩大。
- 98%：必须优先排除既有职位、计划、意义与潜在 zx。
- 97%：旧秩序失效和关系位置空缺，是比“危险使人勇敢”更准确的机制入口。
- 96%：本关系若成立，优先限定为状态层／关系层的强制显影机制。

### 未达到 95% 的部分

- xz 是否能够独立生成此前不存在的 zx；
- 候选 A 与 B 是单一机制的前后阶段，还是仅在不同案例中分别成立；
- 当前案例更像“危险迫使潜在 zx 公开”，还是严格意义上的生位；
- 母行 `xz→zx→nz` 是否可以作为正式动态链直接调用。

因此本轮状态：

```text
xz 生 zx 几何位置：保留
旧“危险后开始行动就是 zx”口径：撤回
最窄候选：危险造成决定空位，并迫使潜在权能公开接管
正式机制：未锁定
生补克表：不修改
关系词典：不修改
待用户确认队列：不新增，当前仍属案例纯度与生成／显影边界不足
```
