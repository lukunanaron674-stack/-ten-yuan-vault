# x 克 z｜对象门控机制审计

## 1. 本轮结论

`x克z` 的几何位置继续成立，正式机制锁定为：

```text
x 主体掌握 z 完成或被看见所必需的对象、资源、权限、关系入口、发布通道或署名界面
→ x 主体拒绝、扣留、收回、垄断或改写这些必要接口
→ z 的完成条件、公开显现条件或成果归属被压缩
→ z 无法完成，或虽然完成却不能以自己的名义被看见
```

最短公式：

> **x 通过掌握必要对象与显现入口，压制 z 的完成与被看见。**

被改变变量不是一般情绪，而是：

- 完成所需资源是否可用；
- 进入关键场景或关系的权限是否存在；
- 成果能否发布、署名、被共同体确认；
- z 主体能否把“我做成了”落实到公共现实。

## 2. 旧口径撤回

以下旧解释不得继续作为正式机制：

```text
x = 深渊、恶意、欲望或黑暗
→ 把 z 的光吞掉
```

“哥谭的恶意把亚瑟摁回黑暗”“赌红眼的人被高利贷吃掉”等说法，只能形成气氛隐喻，未明确：

- x 到底掌握了什么对象；
- 掌握者是谁；
- z 的哪个完成或显现接口被关闭；
- 结果为什么不是普通失败、贫困、羞辱或环境恶劣。

因此，《小丑》与“赌徒被高利贷吃掉”撤回纯案例资格。关系词典中的相关旧行应视为待同步旧口径，不得继续调用。

## 3. 对象分层

| 材料 | 层级 | 是否可直接证明 x克z |
|---|---|---|
| 主体长期掌握资金、场地、设备、职位、发布权、署名权或关键关系 | x 源端点 | 是，需说明具体掌握边界 |
| 主体想完成作品、任务、比赛或公开表达 | z 目标端点 | 是，需出现完成与被看见变量 |
| 扣设备、不给场地、撤权限、封发布口、夺署名 | 行为功能 | 可作为克制机制 |
| 阴影、黑暗城市、压迫色调 | 光影与视觉 | 不能单独证明 |
| 监狱、公司、学校、舞台、平台 | 场景 | 不能单独证明 |
| 上级、平台管理员、资源所有者、监狱管理者 | 关系位置 | 只有实际掌握必要接口才成立 |
| 先被拒绝、后失败 | 时间先后 | 不等于 x克z |
| 羞耻、焦虑、受挫 | 当前状态 | 是结果候选，不是关系本身 |
| 人物稳定为 x 或 z | 稳定本体 | 本轮不要求，也不由单次行为反推 |
| 资源被封后，整体从“即将显现”转向“无处完成/无人承认” | 动态链显影 | 是关系后果 |

## 4. 源端点、目标端点与成立条件

### 源端点 x

必须存在明确掌握关系：

```text
某个主体拥有或控制
对象 / 资源 / 地盘 / 权限 / 关系入口 / 发布与署名界面
```

“社会很坏”“环境压抑”“别人不喜欢他”均不足以构成 x。

### 目标端点 z

必须存在明确的集中目标：

```text
完成某事
并让完成结果进入可见、可确认、可署名的公共现实
```

只有一般努力、想成功、痛苦或被欺负，不足以构成 z。

### 成立阶段

本关系主要成立于两个阶段：

1. **完成前门控**：x 掌握完成所需的资源和权限，使 z 无法落地；
2. **完成后截断**：z 已做成结果，但 x 掌握发布、署名或确认界面，使“被看见”无法归于 z 主体。

### 关系体量

- 低体量：延迟一次提交、缩小一次曝光；
- 中体量：持续封锁关键资源或资格，使目标反复无法完成；
- 高体量：x 垄断完整的完成与显现环境，z 主体即使行动也无法在公共现实中留下“我做成了”的结果。

### 显影条件

至少出现一项可观察变化：

- 目标因缺少必要对象、场地、设备或许可而停摆；
- 完成品被扣留、删除或禁止发布；
- 成果被改署他人名下；
- z 主体被移出能够获得确认的关系或公共界面；
- 取回资源或权限后，z 立即恢复完成或显现能力。

## 5. 候选机制比较

### 机制 A：完成条件门控

```text
x 掌握必要资源或权限
→ 拒绝提供 / 收回 / 垄断
→ z 无法完成
```

理论后果：`x克z` 首先作用于“完成条件”。

### 机制 B：显现与归属截断

```text
z 已经完成
→ x 掌握发布、署名、评价或确认界面
→ 成果不能以 z 主体名义被看见
```

理论后果：`x克z` 也可只压住 z 的“被看见”，不必抹掉行为完成本身。

### 机制 C：普通敌意或失败

```text
环境恶劣 / 他人嘲笑 / 目标太难
→ z 失败或受挫
```

若不存在明确掌握者与必要接口，不能判 `x克z`。这只是状态变化、阻力或结果失败。

本轮锁定 A 与 B 为同一正式机制的两个阶段；C 排除。

## 6. 正例

### 正例一｜编辑甲与创作者乙，交稿阶段

- 乙已经完成画稿，目标是以自己的名字公开发表；
- 甲掌握出版社的发布权限、稿件终审与署名界面；
- 甲没有否定画稿是否完成，而是扣住发布权限，并要求把署名改给公司主理人；
- 结果是：作品完成成立，但乙的“完成后被看见”被截断。

对象链：

```text
甲的 x：掌握发布与署名入口
克
乙的 z：完成画稿并以本人名义被看见
```

拿掉甲的发布与署名控制，克制立即消失，案例通过。

### 正例二｜方志敏狱中文稿的剧本候选结构，文稿传出阶段

本例只作为对象链候选，不替代史实核验：

- 方的 z 不是“相信中国会更好”，而是把文章写完并送出监狱，让外部真正读到；
- 监狱管理系统掌握纸笔、搜查、通信、探视和文稿出口，构成具体 x；
- 若系统扣留纸笔、截断传递或没收文稿，压住的是文章完成与公开显现；
- 凌凤梧、胡逸民、高家骏若帮助纸笔与文稿绕过门控，他们不是用 zn 凭空保护抽象 n，而是在具体对象链上松开 x 对 z 的克制接口。

对象链：

```text
监狱系统的 x：掌握纸笔、通信、搜查与出口
克
方的 z：完成并送出文稿，使文字被外界看见
```

这一结构比“黑暗监狱吞掉方的光”具有完整对象逻辑，但人物实际行为仍须由史料单独验证。

## 7. 反例

### 反例一｜观众不喜欢作品

作品已经发布，观众评价很差。这里没有某个主体掌握并关闭必要接口，只是 z 显现后的负面反馈，不是 `x克z`。

### 反例二｜创作者拖延导致错过截止日

资源、场地、发布权都可用，创作者因自身拖延没有完成。主要检查 xn、z 体量或个人状态，不能判 x 克 z。

### 反例三｜上级公开威吓员工停止项目

若核心是上级以公开权能直接压人、命令停止，优先检查 `zx`。只有上级真正通过掌握预算、设备、权限或发布入口封死完成条件时，才同时出现 x 克 z。

### 反例四｜贫困人物无法实现梦想

若只写“没钱、社会恶意、命运悲惨”，没有明确谁掌握具体资源并如何门控，则只是环境阻力。贫困不会自动获得 x 户口本，人类理论最爱在这里偷渡。

## 8. 最近邻排除

### 与 xn 克 zx

| 关系 | 源端点 | 目标变量 |
|---|---|---|
| x克z | 掌握必要对象、权限、入口 | 完成条件或被看见条件被压缩 |
| xn克zx | 已运行的规则、流程、时间结构 | 直接权能的即时扩张被迫进入流程 |

审批流程要求补材料，重点是 xn；审批者私自扣住本来归其掌握的许可，并以许可所有权压住完成，才偏 x。

### 与 zx 克 n

`zx克n` 是公开权能击穿承载结构；`x克z` 是掌握者封锁完成或显现接口。前者改变容器稳定性，后者改变目标兑现与公开确认。

### 与普通失败

普通失败只说明结果没做成；`x克z` 必须证明没做成或没被看见，是因为某个主体掌握了不可替代的必要对象。

### 与 z 克 x

`z克x` 若成立，应表现为完成与公开显现打破原有私有控制、迫使资源或关系脱离某主体掌握。目标变量是 x 的掌握边界缩小，方向相反。

## 9. 拿掉测试

1. 拿掉 x 主体对必要对象、权限或界面的掌握，z 是否立即恢复完成或显现能力？若否，本关系可能不成立。
2. 保留敌意、贫困和压力，但提供独立资源与发布入口后，z 是否能够完成并被看见？若能，证明真正克制点是门控接口。
3. 拿掉 z 的明确完成与显现目标后，资源封锁是否仍只是一般控制？若是，则不能单独调用 x克z。
4. 只拿掉公开威吓，保留资源扣押后克制仍成立，说明关系核心是 x，不是 zx。

## 10. 反向测试

交换为 `z克x`：

```text
主体完成并公开显现成果
→ 原本被某人私有掌握的信息、资源或关系暴露
→ x 的控制边界被打破或迫使让出
```

反向关系在揭密、公开发布、成功突围等情境中可能成立，但它改变的是 x 的掌握范围。原关系改变的是 z 的完成与显现条件，二者不对称。

## 11. 动态链后果

### x克z → z生nz 候选链

不能自动成立。被压住的 z 不会因为失败自然生成 nz，后续停靠必须另有关系对象和机制。

### x克z → zn介入 → z恢复

可以成立为对象链：

```text
x 封锁完成/显现接口
→ z 无法做成或无法被看见
→ zn 提供“不因封锁而否定此事正确性”的意义稳定
→ 另一主体通过 nx 借关系、或 zx 直接突破、或 xn 重组流程
→ 取回具体接口
→ z 恢复
```

注意：zn 本身不直接生成纸、门、通信许可或发布渠道。它稳定“为什么仍要做”，真正松动 x 门控仍需具体行为与关系桥。

### 对方志敏剧本的直接后果

方的 zn 可以保护自己和狱友不因强权解释而自我否定；但若剧情目标是文章写完并传出，必须另写对象链：

```text
监狱系统 x 克 方的 z
→ 凌/胡/高通过各自真实权限、关系或行为松开纸笔与传递接口
→ 方完成并送出文稿
→ z 显现
→ 文稿内容再承担 zn
```

这样能避免把“意义”“文章”“狱友情”“传递渠道”揉成一个看似热血、实际找不到受力点的理论肉丸。

## 12. 三元与十元并行核验

- 本轮不从“掌握发布权”直接判人物稳定 x；稳定本体仍需跨阶段证据。
- 本轮不从“想完成作品”直接判人物稳定 z；这里可只用行为/状态层 z。
- 三元负责更基础的精神运动与大感受骨架；十元关系负责明确谁掌握什么、压住谁的哪一个变量。
- 不写成“三元生出十元”或“十元是三元下位”。

## 13. 95% 门槛

### 已通过

- 旧“深渊吞光”不是现行 x 的可观察机制；
- `x克z` 必须存在明确掌握者与必要接口；
- 正式目标变量是完成条件和被看见条件；
- 完成前资源门控与完成后发布/署名截断属于同一机制的两个阶段；
- 必须排除普通失败、环境敌意、xn 流程约束与 zx 公开强压。

### 未锁定内容

- 任何具体影视人物是否稳定为 x 或 z；
- 方志敏狱中文稿链中每个史实人物实际掌握的权限和具体行为；
- `z克x` 的正式通用机制。

以上均不影响本轮锁定 `x克z` 的对象门控机制。
