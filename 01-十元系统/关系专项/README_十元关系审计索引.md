# 十元关系审计索引

> 本页只路由“审计完成但机制未锁定”的关系文件。它们提供边界、反例和未判定理由，不覆盖《十元生补克表》几何位、现行定义正本或已锁定关系专项正本。

## 读取规则

1. 先读 `十元生补克表.md` 判断几何位置。
2. 再读 `README_十元关系专项正本索引.md`，确认是否已有正式机制。
3. 只有正式索引未列出正式机制时，才进入本审计索引补读证据边界。
4. `audit-only / 未锁定 / position-locked-mechanism-unresolved` 不得被动态链当作已锁定机制调用。
5. 审计文件与关系词典冲突时，只能撤回旧案例资格或标记冲突，不能自动把候选机制抬成正本。
