# z 生 nz｜认可位置能否转成可停靠关系三次审计

## 0. 本轮结论

```text
几何位置：保留
旧“完成/获奖/录取后自然留恋”口径：继续撤回
最窄候选：重要认可主体持续确认主体，并由评价位置转成可返回的共同关系位置
正式机制：未达到95%门槛
队列：继续沿用 UQ-20260718-005，不新增重复问题
```

本轮不再检查“完成后舍不得结束”，只检查：

> z 的认可关系本身，能否新增 nz 的时间厚度、回返位置与不愿结束。

## 1. 对象分层

| 层级 | z | nz | 本轮纪律 |
|---|---|---|---|
| 稳定本体 | 长期依赖重要认可位置确认精神存在 | 长期保留关系余温与回返姿态 | 不从一次认可或一次不舍反推本体 |
| 当前状态 | 被看见、回应与确认 | 舍不得离开、延迟告别 | 情绪先后不是生位 |
| 行为功能 | 展示、表达、让认可主体确认 | 等待、回返、维护共同位置 | 行为共现不代替端点 |
| 光影 | 聚光、目光、署名、回应 | 暖光、旧物、空位、余温 | 仅作显影 |
| 场景 | 课堂、舞台、治疗、师徒、创作 | 告别、毕业、离职、谢幕 | 题材不能自动成立 |
| 时间关系 | 认可先发生 | 不愿结束随后增强 | 先后只提供候选 |
| 关系位置 | 认可者与被认可者 | 可回返的共同关系双方 | 必须确认是否为同一对象 |
| 显影 | “你看见了真正的我” | “我不想失去这个看见我的人/位置” | 目标变量必须真实变化 |
| 动态链 | 精神存在在某位置成立 | 该位置是否沉淀为可停靠关系 | 不写成获奖自动生依恋 |

## 2. 源端点、目标端点与变量

### 2.1 源端点 z

必须明确：

```text
认可主体是谁
认可了主体的什么
为什么该认可位置不可替代
认可是否真实落到主体，而非泛泛称赞
```

### 2.2 目标端点 nz

必须新增或增强：

```text
对认可主体或共同位置的回返意愿
不愿让该关系真正结束
即使奖励、职位和任务消失仍希望保留联系
关系留下时间厚度与可停靠位置
```

### 2.3 被改变变量

- 认可者是否从评价者变成关系对象；
- 主体是否主动维持认可关系；
- 奖励和任务结束后是否仍想回去；
- 拿掉原有友情、照护和共同生活后，nz 是否仍由认可新增；
- 认可关系是否获得跨阶段持续性。

## 3. 成立阶段、体量与显影条件

### 成立阶段

认可已经发生，并且主体开始把“被这个人看见”本身视为不愿失去的关系位置。

### 关系体量

- 低体量：认可后短暂兴奋或感谢，不足以成立；
- 中体量：任务结束后仍主动联系、返回或延长共同关系；
- 高体量：主体改变下一阶段选择，只为保留该认可关系。

### 显影条件

至少满足两项：

1. 奖励、成绩、职位已经结束，关系仍被主动维护；
2. 认可主体不再提供现实利益，主体仍愿回返；
3. 若换成同等能力但不具认可意义的人，主体不会产生同样 nz；
4. 认可前后，主体对关系结束的态度有明确变化。

## 4. 候选机制

### 候选 A：认可者由评判位置转成可停靠关系

```text
重要认可主体看见并确认主体
→ 主体第一次在该关系中感到精神存在被完整接收
→ 认可者不再只是评判者
→ 该关系成为可返回的位置
→ nz 上升
```

理论后果：

> z 若生 nz，生成的不是泛依恋，而是“我不想失去这个真正看见我的人”。

风险：完整接收可能更接近 n；若认可者同时长期照护，不能把 n 偷换成 z。

### 候选 B：被确认的共同身份沉淀为阶段余温

```text
认可明确落到“我们共同完成/共同成为的东西”
→ 共同阶段获得不可替代性
→ 主体把认可关系与共同时间绑定
→ 阶段结束后仍维持回返姿态
→ nz 上升
```

理论后果：

> z 改变的是共同阶段被精神确认的重量，而不是完成本身。

风险：时间厚度可能主要来自 xn 长期共事、n 共同容器或既有 nz。

### 候选 C：认可依赖误判为 nz

```text
主体需要继续被认可
→ 不愿离开认可者
```

排除。

这是 z 的持续需求，不必包含柔情、余温或不愿关系结束。主体可能只是在追逐下一次确认。

### 候选 D：职位、资源和归属制造留下

```text
被认可
→ 获得团队位置、资源、身份和机会
→ 愿意留下
```

排除。更接近 x、n、xn 或 x并z。

## 5. 正例候选

### 5.1 《心灵捕手》威尔与肖恩，治疗结束阶段

关系双方：

- z：肖恩看见并确认威尔的聪明、创伤与真实选择，不把他只当问题学生或天才工具；
- nz 候选：威尔在治疗结束时对肖恩形成不愿轻易失去的关系余温，并把这段关系带入后续人生选择。

支持点：

```text
肖恩的确认不是成绩评价
→ 而是“真正的你被我看见”
→ 威尔不再只把肖恩当治疗者
→ 关系获得可回返与告别重量
```

限制：

- 肖恩持续接住威尔，n 很强；
- 治疗的重复过程含 xn；
- 影片对长期回返行为呈现有限。

本例支持候选 A，但不能证明 z 独立生成 nz。

### 5.2 《国王的演讲》伯蒂与莱昂内尔，演讲完成后的友谊阶段

关系双方：

- z：莱昂内尔确认伯蒂不是一个失败的王子，而是能够发声并完成职责的人；
- nz 候选：伯蒂不再只把莱昂内尔当技术治疗者，而把他保留为长期朋友与可回返关系。

支持点：认可内容与认可主体都明确，关系在任务成功后仍继续。

限制：

- 长期训练含 xn；
- 陪伴与接住含 n；
- 战争演讲成功本身带来 z 与 zx 结果。

### 5.3 具体结构例：导师确认学生独特创作语言

学生甲长期只把导师乙当评分者。毕业前，乙明确指出并确认甲独特的创作语言，而不是只给高分。毕业后乙不再提供课程、资源或推荐，甲仍主动回访、保留共同讨论位置，并拒绝把这段关系替换成任何“同等级导师”。

若拿掉乙对甲精神存在的独特确认，甲不会产生同样回返意愿，则支持候选 A。

本例结构纯度较高，但缺少正式人物文本，不能独自锁定。

## 6. 反例

1. 获奖者舍不得离开领奖台：是状态兴奋，不是 nz。
2. 学生因导师能提供推荐信而维持联系：主要是 x。
3. 员工因表彰后获得团队归属而留下：可能是 n、x并z 或待遇。
4. 演员本来就舍不得剧团，认可前已有强 nz：方向可能是 nz 生 z。
5. 被偶像点赞后持续追逐更多回应：z 延续，不是停靠。
6. 治疗者长期接住来访者而产生依恋：主要需检查 n。
7. 项目共同完成后成员不舍，但没有重要认可主体：只是共同时间或 xn。
8. 对认可者产生崇拜、模仿和服从：可能是 z、nx 或 x并z。
9. 认可消失后关系立即失去价值：说明只依赖 z，不是 nz。
10. 换一个同等评价者即可替代原关系：缺少不可替代的关系对象。

## 7. 最近邻排除

### 与 n 生 nz 式误读

n 提供接住、容纳和持续照护；z 提供看见与确认。

若主体不愿结束主要因为“这个人一直接住我”，不能归为 z 生 nz。

### 与 z 自身延续

```text
我还想被他认可
```

不等于：

```text
即使他不再评价我，我仍不想失去这段关系
```

### 与 nz 生 z

若主体先舍不得某段关系，于是完成最后一次表达让对方看见自己，方向是 nz→z。

### 与 xn 补 z

xn 补 z 改变认可的连续证据与阶段节点；z 生 nz 候选改变认可后关系是否获得余温和回返位置。

### 与 xz 补 nz

xz 通过可能失去提高停靠重量；z 必须仅凭“被看见与确认”本身改变关系价值。

## 8. 拿掉测试

1. 拿掉认可事件，原有照护与共同时间仍在，nz 是否同样成立？若是，不依赖 z。
2. 拿掉奖励、职位、资源和推荐，主体是否仍维护关系？
3. 拿掉长期照护，只保留关键确认，是否仍出现回返意愿？
4. 拿掉既有友谊，认可是否足以新增时间厚度？
5. 换成同等能力但不具精神认可意义的人，nz 是否明显下降？
6. 认可者停止评价后，主体若只追逐新认可者，说明是 z 延续。

两个作品候选均未通过“拿掉 n 与 xn 后仍稳定生成 nz”的完整测试。

## 9. 反向测试

交换为：

```text
nz 生 z
```

可能过程：

```text
主体不愿关系结束
→ 完成最后一次表达、作品或告别
→ 让重要对象看见自己
→ z 上升
```

方向区别：

- z 生 nz：认可先使评价位置转成可停靠关系；
- nz 生 z：不舍先推动最后一次被看见。

两者可反馈，但不能用同一案例互相代证。

## 10. 动态链后果

候选链：

```text
你真正看见了我
→ 我不再只把你当作评判者
→ 即使评价和任务结束
→ 我仍想保留这个能认出我的关系位置
```

改变的是：

> 认可位置是否沉淀为不可替代的关系停靠点。

不机械生成：

- 爱情；
- 依赖人格；
- 永久忠诚；
- 组织归属；
- 认可者与被认可者必然亲密。

## 11. 三元与十元并行

三元继续核验作品整体精神关系。

十元本轮只核验：

- z 是否真实由重要认可主体确认；
- nz 是否新增时间厚度、回返与不愿结束；
- n、xn、x、x并z 和既有 nz 是否为真正来源；
- 认可停止后关系是否仍被保留。

不建立 z 与 nz 的父子派生。

## 12. 95%门槛

### 高置信通过

- 完成、获奖、录取与掌声不能直接生 nz：99%。
- 持续追逐认可不等于关系停靠：99%。
- 认可者必须从评价位置转成不可替代的关系对象：98%。
- 必须排除 n、xn、x 与既有 nz：98%。
- 任务结束、认可停止后仍维护关系，是关键显影条件：97%。

### 未达到95%

- 两个具体作品均混有强 n 与 xn；
- 候选 A 是否是 z 的直接作用，还是“被接住并共同经历”的复合结果；
- 认可关系是否能够独立提供 nz 所需的时间厚度；
- 缺少两个拿掉照护、制度和原有友谊后仍成立的具体人物案例。
