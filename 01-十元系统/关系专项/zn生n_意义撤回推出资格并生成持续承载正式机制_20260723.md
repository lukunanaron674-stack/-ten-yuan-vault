# zn 生 n｜意义撤回推出资格并生成持续承载正式机制

## 0. 正式结论

`zn 生 n` 以窄机制正式成立，优先落在具体人物、关系或状态层，不自动升级为大型组织、建筑或稳定共同体。

> **主体先以内在意义确认某个对象不能被抛下，由此撤回拒绝与推出资格；对象随后真实进入内部、跨阶段停留，并使主体持续处理食物、照护、隐藏、风险或关系负荷时，`n` 成立或上升。**

必须拆成两段：

```text
A 准入启动：zn 使主体撤回拒绝与推出资格。
B 承载成立：对象跨阶段留在内部，负荷被持续处理，并保留再次进入或返回位置。
```

只有 A，没有 B，只能判 `zn` 的接纳行为；不能判完整 `n`。

## 1. 端点与变量

### 源端点 zn

即使没有奖励、认可、法律义务、亲属职责和结果保证，主体仍认为某人或某事不能被抛下。

### 目标端点 n

对象必须真实进入主体的生活、关系或可用空间，并跨阶段停留；主体没有立即推出或转交，而是持续处理对象带来的现实负荷。

### 被改变变量

- 拒绝权与推出资格；
- 可接收对象范围；
- 留存时间与再次进入资格；
- 外部议题转成内部负荷的程度；
- 食物、照护、隐藏、风险与关系负荷的持续处理度。

## 2. 作用机制

```text
zn：这件事不能被丢下
→ 主体撤回“可以拒绝或推出”的资格
→ 对象进入内部
→ 下一阶段仍留在内部
→ 主体持续承担对象产生的负荷
→ n 的准入与留存边界上升
```

`zn` 直接生成的是 `n` 的准入、留存和承担关系，不直接生成房屋、资金、流程、权限、领袖权能或无限扩容能力。后续 `x/xn/zx` 可以扩大、维护和保护承载，但不等于它们必然是最初承载入口的生成源。

## 3. 正例

### 3.1 《摩登时代之子／The Kid》流浪汉与弃婴

流浪汉最初试图把婴儿交出去，随后选择不再推出，并在贫困、没有正式监护权和成熟制度的条件下长期抚养孩子。对象从街头外部负荷进入其生活，食物、居住、照护与分离风险被跨年持续处理。

关键纯度：低资源、低制度、无职位命令；正式目标不是房屋或家庭称号，而是孩子持续留在其内部生活并被承担。

### 3.2 《何以为家／Capernaum》赞恩与约纳斯

拉希尔消失后，赞恩没有法律、亲属、资源或职位义务，却没有把幼儿推出；在极端贫困中继续寻找食物、移动、照护并承担风险。初始互惠条件失效后，承载仍跨阶段继续。

关键纯度：成熟制度、产权与资源均缺席，目标仍真实表现为幼儿持续落在赞恩承担范围内。

### 3.3 《小偷家族》治与信代接纳友里

二人发现友里遭受虐待后不再把她送回原环境，使她进入贫困家庭并跨阶段获得食物、睡眠、照护和关系位置。房屋与既有家庭结构属于实现条件，但“听见虐待后撤回推出资格”是准入边界变化的直接启动点。

## 4. 反例

- 一次捐款、送饭、藏匿或临时过夜：缺少跨阶段留存与负荷处理。
- 因法律、亲属、职位或合同义务接收：源端点不是纯 `zn`。
- 商业旅馆因利润接待：`n` 可成立，但不是由 `zn` 生成。
- 领袖命令成员收留：优先检查 `zx/nx`。
- 政府按预算、审批和工程计划建纪念馆：优先检查 `xn/x/zx`。
- 只有“应该帮助”的言论，未改变准入与留存边界：目标端点不存在。

## 5. 最近邻排除

- `zn 生 zx`：改变公开推进与现实权能；本关系改变对象是否进入并留在内部。
- `n 生 xn`：既有承载因重复负荷提炼分工、记录和预案；本关系发生在承载入口。
- `zn 补 x`：为已有掌握边界提供意义方向；本关系直接改变准入与留存。
- `n 生 zn`：长期共同承载反过来沉淀不能放弃的意义，方向相反。

## 6. 拿掉测试

1. 拿掉 `zn`，若主体仍因商业、法律、亲属或职位义务接收，不成立。
2. 拿掉第二阶段留存，只剩首次接纳，不足以判完整 `n`。
3. 拿掉成熟流程，若对象已经留存且负荷持续被处理，关系仍可成立。
4. 拿掉房产、资金与正式权限，若主体仍用生活与风险承担接住对象，纯度上升。
5. 拿掉领袖命令与公开推动，若主体仍撤回推出资格，支持直接机制。
6. 换掉建筑，只要准入、留存和处理关系保持，`n` 仍成立。

## 7. 反向测试

```text
zn 生 n：不能抛下的意义先成立 → 对象进入并被持续承担。
n 生 zn：对象先长期被接住 → 共同时间与负荷沉淀为不能放弃的意义。
```

两方向可形成反馈，但不能互相代证。

## 8. 动态链后果

```text
这件事不能被丢下
→ 它获得进入资格
→ 下一阶段仍留在内部
→ 我持续承担它带来的负荷
→ 承载从一次接纳变成可持续内部位置
```

改变的是意义如何打开承载入口，并把入口转成跨时间持续的内部位置。它不机械生成建筑、组织、制度、资源成功或永久稳定。

## 9. 调用红线

- 必须同时证明“准入启动”和“承载成立”。
- 一次善举、收留、捐助、藏匿、口号与建筑题材均不足。
- `zn` 只直接生成准入、留存与承担边界，不自动生成成熟承载能力或规模。
- 后续出现 `x/xn/zx` 不自动推翻本关系；必须判断它们是后续实现层，还是最初入口的真实启动源。
- 三元与十元并行，不从本体主题或空间主题反推本关系。
