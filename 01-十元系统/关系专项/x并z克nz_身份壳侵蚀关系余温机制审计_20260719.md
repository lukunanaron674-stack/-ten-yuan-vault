# x并z 克 nz｜身份壳侵蚀关系余温机制审计

## 0. 本轮结论

几何位置 `x并z 克 nz` 保留。

旧《色，戒》解释“麦太太假壳渗入太太团，使真正停靠者无法信任”不合格：太太社交圈只证明场景、身份和关系位置，没有证明已成立的 nz，也没有说明哪一段关系的余温、停靠意愿或不愿结束被实际削弱。

当前最有力的候选机制是：

```text
x并z 使关系只能通过一层稳定身份壳被读取
→ 同一温柔行为同时可能被解释为角色表演、任务动作或公共说法
→ 关系双方无法确认“此刻靠近的是你，还是你的壳”
→ 自愿回到原关系位置的可信度下降
→ nz 的余温、停靠与不愿结束被侵蚀
```

但现有作品案例仍普遍混入 xn 的长期骗局流程、zx 的强制、x 的占有和既有关系破裂，因此正式机制暂不锁定。

## 1. 关系对象分层

| 层级 | x并z | nz |
|---|---|---|
| 稳定本体 | 长期以公开身份壳、角色界面和表里分层与世界互动 | 长期保留一段关系或时光的余温，不愿承认已经结束 |
| 当前状态 | 此阶段进入、维持或暴露一层身份壳 | 此阶段仍愿等待、回望、停留或返回原关系位置 |
| 行为功能 | 扮演、命名、包装、维持共同说法、切换角色 | 等待、保留旧物、回到原处、延迟告别 |
| 光影 | 面具、舞台、制服、精致表面、双层空间 | 暖光、旧物、空座、黄昏、停驻构图 |
| 场景 | 婚姻表象、社交圈、卧底身份、公开家庭形象 | 旧居、婚姻余温、旧友关系、共同阶段结束前 |
| 时间关系 | 壳先存在，关系后破裂，只是先后证据 | 关系曾经真实存在，之后仍保留温度 |
| 关系位置 | 配偶角色、同事角色、卧底角色、公众形象 | 恋人、旧友、家人、共同生活者 |
| 显影 | 表里差异与公共可读壳的稳定度 | 自愿停靠、可信回返和不愿结束的强度 |
| 动态链 | 壳改变关系如何被读取 | 不机械生成分手、揭穿或仇恨 |

## 2. 源端点、目标端点与变量

### 2.1 源端点：x并z

必须有一层已经稳定运行、能被关系双方或外界持续读取的身份壳：

- 公开配偶、模范家庭、完美朋友；
- 卧底、假身份、任务角色；
- 共同维持的社会说法；
- 表面关系与内部真实关系存在结构差异。

一次撒谎、临时伪装或一句客套话不足以构成源端点。

### 2.2 目标端点：nz

必须先有一段真实经历过、具有时间厚度的关系或共同阶段：

- 双方曾经真正停靠；
- 至少一方仍愿保留原位置；
- 关系即将或已经结束，但余温尚未消失；
- 关键问题是“我还能不能相信并回到这段关系”。

普通信任、一般亲密、社交归属和团队合作不能替代 nz。

### 2.3 被改变变量

- 温柔行为的真实性可判定度；
- 双方能否确认正在面对真实主体；
- 原关系位置是否仍可安全返回；
- 对共同记忆的解释是否仍稳定；
- 继续等待或保留关系的意愿；
- 关系余温能否跨过壳暴露继续存在。

## 3. 成立阶段、体量与显影条件

### 成立阶段

```text
关系已经留下余温
→ 身份壳开始介入关系读取
→ 温柔行为出现双重解释
→ 回返位置变得不可信
→ nz 下降
```

壳从一开始就存在，不等于已经克制 nz。必须观察它何时开始改变关系余温和可信回返。

### 体量

- 低体量：一次靠近被怀疑为角色行为，短暂无法停靠；
- 中体量：共同记忆被重新解释，双方不再确定过去是否真实；
- 高体量：关系只能以公共壳继续，真实主体无法回到原位置，nz 断裂。

### 显影条件

至少满足两项：

1. 同一温柔行为出现“真实靠近 / 角色表演”双重解释；
2. 壳暴露后，过去共同记忆的真实性被重判；
3. 一方不再愿意回到原关系位置；
4. 关系虽未形式结束，但余温与自愿停靠明显下降。

## 4. 候选机制

### 候选 A：关系位置替代

```text
x并z 提供一个稳定公共角色
→ 双方逐渐只通过角色相处
→ 真实主体退出原关系位置
→ nz 找不到可返回的对象
```

理论后果：壳克制的是“关系还能否回到真实双方之间”，不只是揭穿秘密。

### 候选 B：温柔行为双读化

```text
身份壳与真实动机并存
→ 每次照顾、亲近和等待都可能是表演或任务
→ 关系中的温度失去可验证性
→ 继续停靠的意愿下降
```

理论后果：即使温柔中确有真实部分，只要无法判断它属于谁，nz 仍可能被侵蚀。

### 候选 C：壳暴露直接造成愤怒

```text
发现被骗
→ 生气、报复或离开
```

排除为充分机制。它可能只是当前状态变化，或由 zx 强制、x 占有、xn 骗局流程引发；没有证明此前存在 nz，也没有证明被改变的是关系余温与停靠意愿。

## 5. 正例候选

### 5.1 《革命之路》弗兰克与爱普莉，中后段“模范郊区家庭”壳反噬阶段

- 源端点：两人持续维持体面夫妻、房屋、工作与郊区生活的公开家庭壳；
- 目标端点：两人早期共同梦想与婚姻余温，仍含“不想让我们变成普通失败夫妻”的停靠愿望；
- 作用阶段：巴黎计划失败后，双方越来越只能通过丈夫、妻子、父亲、母亲的角色说话；
- 可观察结果：共同记忆不再提供返回位置，温柔行为被解释为维持表面，双方逐渐不再相信还能回到原来的“我们”。

限制：经济压力、性别制度和个人攻击混入很强，只能作为候选。

### 5.2 《楚门的世界》楚门、梅丽尔与西尔维娅关系线

- 源端点：梅丽尔的妻子身份、海景镇家庭生活和整个节目世界都是稳定公开壳；
- 目标端点：楚门对西尔维娅保留多年的关系余温与回返愿望；
- 作用阶段：节目不断用“正常婚姻”和公共生活壳覆盖这段未结束关系；
- 可观察结果：楚门无法在现有生活中确认任何亲密行为是否真实，最终必须离开壳才能寻找仍可信的关系位置。

限制：该案例也可能主要证明 x并z 压制真实身份、xn 系统控制和 x 资源掌握；nz 端点虽明确，直接克制仍需更纯证据。

### 5.3 《色，戒》王佳芝与易先生，关系后段

更可靠的写法不是“麦太太渗入太太团”，而是：

- 源端点：王佳芝持续以麦太太和任务角色进入关系；
- 目标端点：双方在多次相处后形成的真实柔情与不愿结束；
- 可观察结果：每次靠近同时属于真实情感和任务表演，双方都无法获得稳定、可返回的真实关系位置。

限制：王佳芝最终放走易先生说明 nz 也可能穿透壳，而非单向被克；因此该片更适合双向张力案例，不宜作为纯 `x并z克nz` 铁证。

## 6. 反例

1. 一次普通谎言被揭穿后对方生气：没有稳定身份壳，也未证明 nz。
2. 卧底身份暴露后被组织追杀：主要是 zx、x 或 xn 的行动后果，不是关系余温下降。
3. 夫妻在公共场合维持体面，私下仍能真实相处：x并z 与 nz 共存，没有克制发生。
4. 演员卸妆后恋人仍能确认其真实主体：壳未破坏回返位置。
5. 太太社交圈发现陌生人身份可疑：这只是社交信任与群体边界，不自动构成 nz。
6. 关系本来就没有余温，只因骗局暴露而结束合作：目标端点不存在。

## 7. 最近邻排除

### 与 x 克 nz

- x 克 nz：占有、排他、控制边界使停靠失去自愿性；
- x并z 克 nz：身份壳使双方无法确认正在与真实主体相处。

### 与 xn 克制关系

长期骗局的排程、信息隔离、角色脚本与监控属于 xn。只有当“壳本身改变关系如何被读取”时，才判 x并z。

### 与 zx 公开强制

威胁对方继续扮演夫妻、公开羞辱或强迫维持关系，优先判 zx。x并z 可以没有公开压位。

### 与普通信任破裂

信任下降只是结果。`x并z克nz` 必须进一步证明：失去的是一段具有时间厚度关系的自愿停靠和不愿结束。

## 8. 拿掉测试

1. 拿掉身份壳后，关系余温是否仍因其他原因同样崩解？若是，不依赖本关系。
2. 拿掉既有 nz，只剩骗局和愤怒，目标端点不存在。
3. 拿掉长期脚本与强制后，只保留壳的双重可读性，余温仍下降，才支持直接机制。
4. 拿掉壳暴露，仅因占有、背叛或暴力导致关系破裂，优先检查 x、zx 或 zn。
5. 若壳存在但双方仍能稳定确认真实主体并自愿返回，则克制不成立。

## 9. 反向测试

交换为：

```text
nz 克 x并z
```

候选机制是：

```text
真实关系余温持续存在
→ 主体越来越无法只按角色和公共说法相处
→ 壳在温柔停靠中被放下或撕开
→ x并z 的表里分层下降
```

《色，戒》王佳芝放走易先生反而更接近这一反向作用：真实柔情在关键时刻压过任务壳。

方向区别：

- `x并z克nz` 改变关系余温、可信回返与停靠意愿；
- `nz克x并z` 改变壳的维持能力与表里分层。

## 10. 动态链后果

```text
我们曾经真正靠近过
→ 后来只能通过丈夫、妻子、卧底、模范家庭或公共角色相处
→ 每一次温柔都同时像真实和表演
→ 我不再知道该回到你，还是回到你的角色
→ 关系没有立刻结束，但余温失去可停靠的位置
```

改变的是关系层的可返回性与真实性，不是机械生成揭穿、分手或报复。

## 11. 三元与十元并行核验

三元继续核验作品整体精神走向；十元仅核验具体阶段的壳、关系余温、作用变量和方向。不能因为作品讨论婚姻表象，就反推人物稳定 x并z，也不能因为角色留恋过去，就反推固定三元。

## 12. 95%门槛

### 已达到高置信的部分

- 99%：旧“麦太太渗入太太团”不是合格 `x并z克nz` 案例；
- 98%：目标变量必须是余温、可信回返、自愿停靠与不愿结束，而非一般社交信任；
- 98%：一次欺骗、身份暴露和愤怒不能单独证明本关系；
- 97%：必须排除 xn 的骗局流程、x 的占有、zx 的强制与普通关系破裂。

### 未达到95%的部分

- “关系位置替代”与“温柔行为双读化”是同一机制的两个阶段，还是两套机制；
- 当前三个作品候选均存在强第三因素；
- 《色，戒》在关键节点更能证明反向 `nz克x并z`，不宜作为正向纯案例。

因此本轮：

```text
保留 x并z 克 nz 几何位置
撤回旧《色，戒》太太团案例资格
正式机制未锁定
不修改生补克表与关系词典
不新增待用户确认问题
```

材料仍需补纯，不制造抽象问题塞入队列。
