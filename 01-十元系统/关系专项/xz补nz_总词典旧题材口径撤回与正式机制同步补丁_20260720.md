# xz 补 nz｜总词典旧题材口径撤回与正式机制同步补丁

## 0. 补丁结论

`xz 补 nz` 已由正式专项正本以 97% 置信度锁定。本补丁不新增理论，只处理 `十元关系词典.md` 仍输出旧题材共现与端点混淆的问题。

总词典以下旧口径撤回正式资格：

```text
流浪猫找到常来喂它的人
→ 漂流者需要停靠，停靠者需要被需要
```

```text
库珀在宇宙里飘，墨菲在卧室里等
→ 两份想念互补成跨维度联系方式
```

撤回原因：

1. 固定投喂、收留、房屋、食物与安全更优先构成 `n` 的现实承载，不足以证明 `nz`；
2. “漂流者需要停靠”只是题材对照，没有说明 `nz` 改变了 `xz` 的哪一个变量；
3. “停靠者需要被需要”既不是现行 `nz` 端点，也没有证明 `xz` 补入了关系失去风险和选择重量；
4. “两份想念”只说明关系情绪共现，没有完成双向端点、缺口变量与拿掉测试。

现行正式机制统一读取为：

> **xz 为 nz 提供“关系可能真正失去、停靠必须被再次选择”的命运压力，使余温从惯性维持变成有代价的归宿选择；nz 为 xz 提供明确的关系终点、可回返对象与“我为何穿过风险”的方向，使漂流不再只是继续逃离。两端互补，不互相生成。**

最短公式：

```text
xz 补 nz：失去风险与离散路径，使停靠获得选择重量
nz 补 xz：关系余温与可返回对象，使漂流获得方向和归宿
```

## 1. 关系对象分层

| 层级 | xz | nz | 正式判定 |
|---|---|---|---|
| 稳定本体 | 危险显形、异质逼近、无法稳定停留 | 关系余温、不愿结束、保持停靠姿态 | 单次逃跑、等待或想念不能反推 |
| 当前状态 | 退路缩窄、时间窗减少、被迫行动 | 回望、等待、舍不得离开 | 状态同框不等于互补 |
| 行为功能 | 穿越、撤离、冒险返回、抢时间窗 | 保留位置、维持旧接口、主动回返 | 必须回到缺口变量 |
| 光影 | 断桥、雨夜、列车、宇宙、边界 | 暖灯、旧房间、空位、未冷物件 | 只作显影 |
| 场景 | 漂流、撤离、失散、临界路径 | 旧居、渡口、共同记忆空间 | 题材不能替代端点 |
| 时间关系 | 补位不要求固定先后 | 补位不要求固定先后 | 不得压成单向生成 |
| 关系位置 | 漂流者、被追赶者、临界行动者 | 等待者、旧友、亲人、未结束关系方 | 身份称谓不是本体 |
| 显影 | 风险路径、退路、方向不确定性 | 回返对象、停靠意愿、结束承认度 | 两端变量必须分别可观察 |
| 动态链 | 让离开带有失去压力 | 让回来成为被选择的归宿 | 不机械生成获救或团圆 |

## 2. 双向端点、作用机制与被改变变量

### 2.1 `xz 补 nz`

已有端点：

```text
主体已经保留一段关系的余温
→ 不愿轻易承认它已经结束
→ 仍保留等待、回返或继续靠近的位置
```

候选机制 A，现已纳入正式统一机制：

```text
关系余温原本可能只是习惯或模糊等待
→ xz 使离散、错过或永久失去成为现实可能
→ 返回窗口与继续等待的成本变得有限
→ 主体必须明确是否返回、等待或承担风险
→ nz 从惯性余温获得命运选择重量
```

被改变变量：

- 关系真正失去的可能性；
- 返回窗口的有限性；
- 停靠是否经过风险检验；
- “以后再说”是否仍可成立；
- 关系余温的选择重量。

理论后果：`xz` 不创造柔情，也不自动生成 `nz`；它让已经存在的柔情面对“可能来不及”。

### 2.2 `nz 补 xz`

已有端点：

```text
主体不断被危险推着移动
→ 退路缩窄
→ 只能持续离开
→ 但尚未确定最终朝哪里去
```

候选机制 B，现已纳入正式统一机制：

```text
nz 提供仍有余温的关系对象与可回返位置
→ 风险路径从“只要离开这里”
→ 转成“我要回到那里／那个人”
→ 漂流获得方向、承担理由与收束候选
```

被改变变量：

- 风险路径的方向性；
- 哪个对象值得返回；
- 主体为什么承担穿越风险；
- 漂流是否拥有关系终点；
- 命运是否从无尽离散转成有归宿候选。

理论后果：`nz` 不消除危险，也不保证安全停下；它改变危险中的最终方向。

## 3. 成立阶段、体量与显影条件

### 低体量

一次临界告别使主体确认“我仍想回来”。只成立于当前状态或单一关系阶段。

### 中体量

危险路径反复围绕某个关系对象定向；关系余温也多次经受失去风险检验。

### 高体量

人物的长期漂流方向和归宿选择被同一关系持续组织，但仍不得从关系机制直接反推稳定人物本体。

### 必要显影条件

- xz 端必须有真实风险、退路缩窄、错过或永久离散可能；
- nz 端必须有既存关系余温和不愿结束，而非一次好感；
- `xz 补 nz` 必须观察停靠是否由惯性变为有代价的选择；
- `nz 补 xz` 必须观察风险路径是否新增明确回返对象与方向；
- 若改变的是安全可达性和现实停留能力，优先判 `n 克 xz`。

## 4. 正例

### 4.1 《最后生还者》乔尔与艾莉，盐湖城前后至最终选择

关系双方：

- `xz`：二人长期穿越感染区、猎人地带与不断缩窄的安全路径；
- `nz`：旅途中形成父女式余温，双方都不愿这段关系以任务完成而结束。

`xz 补 nz`：

```text
艾莉可能在手术中永久死亡
→ 任务完成与关系继续无法兼得
→ 乔尔无法再把余温留在模糊陪伴层
→ 必须明确是否承担风险把她带走
```

`nz 补 xz`：

```text
原本只是完成护送并继续赶路
→ 艾莉成为不可替代的关系对象
→ 风险路径获得“带她离开并继续共同生活”的方向
```

本例含 `zn`、`zx` 与 `n`，但双向缺口变量仍可独立观察。不得把乔尔的全部最终行为压缩为单一补位机械结果。

### 4.2 《星际穿越》库珀与墨菲，跨越虫洞至返航阶段

关系双方：

- `xz`：库珀进入不可预测的宇宙路径、时间错位和可能无法返回的命运临界；
- `nz`：父女关系余温，以及墨菲长期保留的回返位置。

`xz 补 nz`：

```text
时间离散与可能永别
→ 等父亲回来不再只是普通等待
→ 关系余温获得跨越一生仍不愿承认结束的重量
```

`nz 补 xz`：

```text
宇宙漂流本可只服务于离开地球和完成任务
→ 墨菲与父女承诺成为明确回返对象
→ 风险路径持续带有“回去”的方向
```

正确使用本例时必须写出上述变量。不得只写“一个漂流、一个等待，所以互补”。

### 4.3 纯结构例：战争撤离中的旧友归返

甲与乙共同生活多年，关系疏远但余温仍在。战争迫使甲转移；甲本可沿安全路线独自撤离，却得知乙困在旧城。

```text
xz：道路封锁、时间窗缩窄、返回风险上升
nz：甲不愿两人的关系以未告别结束
```

双向作用：

- xz 使“以后再联系”失效，迫使甲确认是否真正保留关系；
- nz 使甲的危险路径获得“回旧城找到乙”的方向。

若乙是任意陌生人，优先检查 `zn`；若旧城主要提供安全住宿，优先检查 `n`。

## 5. 反例

1. **流浪猫被固定投喂**：首先是食物、照护与安全承载，优先判 `n`；未证明既有关系余温，更未证明风险路径获得回返方向。
2. **流浪者进入避难所得到床位和医疗**：改变危险可达性与实际停留能力，属于 `n 克 xz`。
3. **两个人同时想念对方**：只证明情绪共现，没有说明失去风险和路径方向如何互补。
4. **恋人因没钱只能同居**：被迫停留，不是自愿停靠。
5. **追兵逼近使人物突然告白**：可能只是临界情绪；此前无关系余温时不能反推 nz。
6. **人物怀念故乡但从不改变路径**：nz 显影存在，但没有补入 xz 的方向变量。
7. **人物因道德责任返回救陌生人**：优先检查 `zn`，不是关系余温启动。
8. **安全后产生依赖**：可能是 `n` 的保护和承载带来的后续关系，不证明 xz↔nz 互补。

## 6. 最近邻排除

### 6.1 与 `n 克 xz`

| 关系 | 被改变变量 |
|---|---|
| `n 克 xz` | 危险可达性、安全停留时间、外部冲击比例 |
| `nz 补 xz` | 风险路径方向、回返对象、归宿候选 |

一句话：`n` 让主体真的停得下来；`nz` 让主体知道为什么、为了谁想停下或回来。

### 6.2 与 `z 生 nz`

`z 生 nz` 若成立，重点是认可主体如何使关系位置沉淀为不愿结束；本关系不要求认可，重点是危险与停靠如何在命运路径中补足缺口。

### 6.3 与 `zn`

因“这是对的”而冒险返回，优先判 `zn`。因“不愿这段关系就此结束、那里仍是我的回返方向”而返回，才偏 `nz`。

### 6.4 与普通爱情或依恋

爱情身份、亲属身份和依恋强度均不能代替端点。必须继续回答：

- 风险到底怎样改变余温的选择重量？
- 余温到底怎样改变风险路径的方向？

---

## 7. 拿掉测试

1. 拿掉 xz 的失去风险，如果主体仍以同样强度维持关系，说明 xz 没有补入选择重量。
2. 拿掉 nz 的回返对象，如果主体仍沿相同路线行动，说明 nz 没有补入路径方向。
3. 拿掉房屋、食物、医疗与保护后，关系变量仍成立，才可排除 `n`。
4. 拿掉道德责任后，主体仍因不愿关系结束而返回，才可排除 `zn`。
5. 拿掉恋爱或亲属标签，双方仍有具体共同时间与关系余温，才可排除题材替代。
6. 若危险解除后主体不再保留任何回返意愿，可能只是临界状态，不足以判中高体量互补。

《最后生还者》《星际穿越》与战争撤离结构例均能通过核心双向测试，但前两者仍须注明第三因素，不得宣传成“无其他十元干扰”的绝对纯案例。

## 8. 反向测试

补位关系不是单向箭头倒转：

```text
xz 补 nz
≠ xz 生 nz
```

`xz` 不创造关系余温，只使既有余温面对真实失去风险。

```text
nz 补 xz
≠ nz 生 xz
```

`nz` 不创造危险，只给既有风险路径提供回返对象与方向。

交换观察方向时，双方各自补足的变量必须保持不同，不能把补位写成父子派生或机械生成。

## 9. 动态链后果

```text
关系可能真正失去
→ 模糊余温必须接受选择检验
→ 主体决定是否为这段关系返回或等待
→ 回返对象反过来给危险路径定向
```

改变的是：

> **命运中的离开是否拥有可返回的关系终点，以及停靠是否经过真实失去风险检验。**

不机械生成：

- 获救；
- 团圆；
- 永久安全；
- 爱情；
- 依恋人格；
- 正确选择；
- 漂流者必然找到家。

## 10. 三元与十元并行核验

三元继续核验作品整体的命运运动、精神方向和关系结构。

十元只核验：

- xz 是否真实存在危险、退路缩窄与离散路径；
- nz 是否真实存在关系余温、不愿结束和回返姿态；
- 双方是否各自补足不同缺口变量；
- `n`、`zn`、`z` 与普通依恋是否才是真正启动源。

命运主题由 `xz + nz` 并行构成，不建立父子派生。
