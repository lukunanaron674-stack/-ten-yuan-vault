# xn 克 zx｜总词典旧交规短锚降级与正式机制同步补丁

## 一、同步裁定

`xn 克 zx` 已由正式专项以 97% 置信度锁定。总词典中的：

```text
交规（xn）拦住超速（zx）
→ 规则一出手行动就停了
```

只能保留为**低体量场景比喻**，不得继续承担完整关系机制。

正式机制为：

```text
zx 试图以主体权能直接扩大当下决定范围
→ xn 已把时间、程序、角色、许可、信息与资源接口组织成持续结构
→ 显权必须经过既有节点，不能把单次力量直接兑换成完整现实支配
→ zx 的即时扩张范围、速度或持续时间下降
```

`xn` 克制的不是力量本身，而是力量绕过既有结构、立即扩张现实决定范围的能力。

## 二、对象分层

| 层级 | xn | zx | 核验边界 |
|---|---|---|---|
| 稳定本体 | 长期主动组织持续运行 | 长期依靠公开显权扩权成立 | 不从一次守规或一次爆发反推 |
| 当前状态 | 审批、许可、程序正在运行 | 主体正在公开接管或越级决定 | 正式机制主要发生层 |
| 行为功能 | 登记、审核、交接、排程 | 宣告、命令、夺位、越级推进 | 行为必须改变目标变量 |
| 光影 | 网格、时间表、文书、关卡 | 中心、高位、众人转向 | 只作显影 |
| 场景 | 法庭、军队、组织、交通系统 | 指挥席、战场、公众现场 | 场景不代替端点 |
| 时间关系 | 结构先跨轮次运行 | 显权随后试图扩张 | 先后仍需机制证据 |
| 关系位置 | 审批节点、程序维护者 | 越级决定者、公开权能中心 | 职位名不能自动判定 |
| 显影 | 节点约束、许可门槛 | 即时决定范围、扩权速度 | 两端均须可观察 |
| 动态链 | 现实已被预先组织 | 单次权能不能直接改写全部现实 | 不机械生成失败 |

## 三、端点与被改变变量

### 源端点 xn

必须具备：

- 已经运行的规则、程序、排程、记录或角色结构；
- 结构在单一主体不配合时仍能继续发挥作用；
- 权限、资源、时间窗或信息接口分布在多个节点；
- 不是临时命令、单个强者阻拦或普通背景规则。

### 目标端点 zx

必须具备：

- 主体力量公开进入现实；
- 主体试图扩大决定范围、压过他者或越过原位置；
- 他者与环境原本可能围绕主体重新行动；
- 普通执行、战斗、反抗或能力展示不足。

### 被改变变量

- 即时决定范围；
- 越级通过率；
- 公开权能扩张速度；
- 单次命令覆盖的角色与资源范围；
- 权能离开结构后的持续时间；
- 他者是否必须立即围绕主体重排。

## 四、成立阶段、体量与显影条件

### 成立阶段

```text
xn 已经持续运行
→ zx 试图越级扩张
→ 结构要求其等待、备案、授权、复核或回到既定角色
→ 即时扩权范围、速度或持续性下降
```

### 关系体量

- 低体量：一次许可或节点延迟单次显权；
- 中体量：多个程序使主体只能局部行动；
- 高体量：结构长期吸收个人爆发，使其无法成为唯一现实中心。

### 显影条件

至少出现一项：

- 单次命令无法直接调用全部角色或资源；
- 越级决定必须经过多个独立节点；
- 权能峰值被等待、复核或交接摊薄；
- 主体只能在限定区域、时间或权限范围内显权；
- 结构在主体离场后仍继续运行。

## 五、候选机制

### 候选 A：节点门控

```text
现实被 xn 切分为多个许可与执行节点
→ zx 无法凭单次显权直接调用全部资源和角色
→ 每经过一个节点，扩张范围被重新限定
```

理论后果：主要改变覆盖范围与越级通过率。

### 候选 B：时间摊薄

```text
zx 依赖当下集中爆发
→ xn 把决定拆入等待、复核、交接和重复执行
→ 权能峰值被分散到多个时间段
→ 即时凌驾强度下降
```

理论后果：结构不必消灭力量，只需让力量不能在一个时刻完成全部扩张。

### 统一机制

> `xn` 把现实组织成不能被单次权能完整跳过的连续结构。

A 处理角色、权限与空间节点；B 处理时间持续。二者是同一机制的两个维度。

## 六、正例

### 1. 《超人总动员》鲍勃与超级英雄安置制度

- 阶段：超级英雄被法律禁止公开行动后，鲍勃仍试图恢复公开救援；
- xn：法律、身份保密、赔偿、职业安排与事故处理形成跨时间结构；
- zx：鲍勃凭超能力公开介入，希望重新成为现场决定中心；
- 结果：力量没有消失，但公开行动范围、持续时间与合法接口被长期压缩。

拿掉制度结构，鲍勃的力量足以迅速回到公共中心；拿掉公开扩权，只保留私人能力，目标端点消失。

### 2. 《美国队长3：内战》复仇者与索科维亚协议

- xn：国际协议、批准程序、成员登记和任务授权试图把复仇者纳入持续结构；
- zx：复仇者原本可以凭自身力量跨境公开决定介入；
- 结果：“我判断后立即行动”被改成“经过授权，或承担违法后果”。

政治立场与 zn 是第三因素，但目标变量仍明确落在即时公开行动范围。

### 3. 五行山式结构锚

孙悟空的力量仍在，但长期有效的结构使其不能把单次爆发直接兑换成现实行动范围。该锚只证明持续结构压住即时显权，不把石头重量本身写成 xn。

## 七、反例

1. 更强者一拳打倒强者：普通力量对抗或 zx 对 zx。
2. 资源所有者不给资金：优先检查 x。
3. 群众不认可领导者：优先检查 z。
4. 主体因良心拒绝扩权：优先检查 zn。
5. 临时命令要求停止行动：没有跨时间结构，只是一次 zx 压位。
6. 设备故障使行动失败：技术状态变化。
7. 主体按自身计划主动收敛：可能是自身 xn，不必然构成克制。
8. 结构只增加文书，却不改变范围、速度或持续时间：只有共现。
9. 交通规则存在，但超速者仍可完整支配现场：只有规则背景。
10. 行动最后失败，但失败由资源、能力或偶发事故造成：不能倒推 xn 克 zx。

## 八、最近邻排除

### 与 x 克 zx

`x` 通过资源、权限或对象归属限制权能可调用范围；`xn` 通过持续节点与时间结构限制即时扩张。

### 与 zn 克 xn

`zn 克 xn` 改变结构的正当性、自愿执行和再生产；本关系中结构仍有效运行，并限制显权。

### 与 zx 克 n

`zx 克 n` 击穿接收和承载；本关系是结构反过来要求显权进入既定程序。

### 与普通行动失败

失败不等于 `zx` 被克。必须观察即时决定范围、越级通过率、扩权速度或持续时间下降。

## 九、拿掉测试

1. 拿掉既有程序、节点与跨轮次结构后，zx 是否恢复即时扩张？
2. 拿掉公开扩权意图，只保留普通任务，目标端点是否消失？
3. 拿掉资源封锁后，程序门控是否仍有效？
4. 拿掉更强主体的直接压制后，结构是否仍能独立发挥作用？
5. 若只增加等待却最终完整扩权，应只判低体量成立。
6. 若主体可随时废除结构，结构尚未形成独立约束。
7. 拿掉交通、法庭或军队题材后，端点与变量是否仍完整成立？

## 十、反向测试

```text
xn 克 zx：
既有结构先运行
→ 即时显权扩张被限制

zx 克 xn：
公开权能先压过程序与节点
→ 结构运行范围下降
```

两个方向改变的变量不同，不能因“制度与强者冲突”这一画面互相代证。

## 十一、动态链后果

```text
一个主体足以在当下压过现场
→ 现实已被时间、角色与程序切成连续节点
→ 力量必须进入结构，不能一次完成全部支配
→ 感觉从“个人权能直接改写现实”转为“现实比个人爆发更长”
```

改变的是即时显权扩张的范围、速度与持续性。

不机械生成：

- 行动失败；
- 服从人格；
- 制度合法性；
- 结构永久胜利；
- 主体稳定本体变化。

## 十二、三元与十元并行

三元继续核验作品整体精神运动。

十元只核验：

- xn 是否形成独立持续结构；
- zx 是否试图公开扩张；
- 即时决定范围、速度或持续性是否下降；
- 是否实际由 x、z、zn、技术故障或更强 zx 启动。

时间主题与因果主题并行，不建立父子派生。
