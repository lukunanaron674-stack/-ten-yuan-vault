# zn 克 xn｜总词典旧“革命击穿制度”口径撤回与正式机制同步补丁

## 0. 本补丁处理范围

本补丁只覆盖 `十元关系词典.md` 中 `zn 克 xn` 的旧短句：

```text
V 以面具革命对抗极权政府
→ 意义击穿制度
```

该句把公开行动、爆炸、动员、夺权与制度倒塌压缩进 `zn克xn`，混入 `zx`、资源故障、领导更替和外部执行链，不能继续作为现行机制。

本补丁不取代 parent 正本，只把总词典的读取结果同步到已经锁定的正式机制。

## 1. 正式结论

> **zn 以不可让渡的内部意义拒绝把既有 xn 继续视为“应当维护的运行方式”，从而降低结构对主体的覆盖、自愿执行、内部修复与跨轮次再生产。zn 不直接摧毁制度设施，也不自动生成革命胜利。**

关系首先成立于成员层、关系层与运行层。高体量时可以累积为结构空心化，但不能把爆炸、财政崩溃、夺权和政权更替统统计入本关系。

## 2. 对象分层

| 层级 | zn | xn | 判定 |
|---|---|---|---|
| 稳定本体 | 无奖励、无认可仍成立的内部意义 | 长期主动组织并使结构持续运行 | 不从一次抗命或一条规则反推本体 |
| 当前状态 | 此阶段确认“继续这样做会背弃我” | 此阶段规则、训练或传统正在运行 | 正式机制主要发生层 |
| 行为功能 | 拒绝执行、拒绝维护、保留原则边界 | 排程、记录、训练、复制、修复 | 行为必须改变运行变量 |
| 光影 | 孤立站立、沉默拒绝、逆流 | 队列、表格、仪式、纪律 | 只作显影 |
| 场景 | 军队、法庭、学校、教会、公司 | 制度、流程、传统、训练体系 | 场景不代替端点 |
| 时间关系 | 意义先撤回认同 | 结构覆盖或再生产随后下降 | 先后本身不足 |
| 关系位置 | 内部成员、执行者、受规训者 | 组织者、流程、制度共同体 | 必须说明谁撤回维护 |
| 显影 | 无监督仍拒绝背叛原则 | 自愿执行、内部修复、复制下降 | 两端都需可观察 |
| 动态链 | “这套运行不能定义我” | “结构仍在，但不再被我主动续命” | 不机械生成制度倒塌 |

## 3. 源端点、目标端点与变量

### 3.1 源端点 zn

必须同时满足：

```text
主体形成内部意义确定
→ 不依赖奖励、认可、群体支持或胜利结果
→ 判断既有运行方式违背不可放弃之物
→ 即使无人看见，仍拒绝替它执行或维护
```

普通不满、利益受损、害怕处罚、冲动反抗和意见分歧均不够。

### 3.2 目标端点 xn

目标必须是已经跨时间运行的：

- 规则与程序；
- 训练与纪律；
- 记录、节点与交接；
- 传统与重复实践；
- 组织内部的维护、修复与复制方式。

一次命令或一个强势领导不自动构成 `xn`。

### 3.3 被改变变量

1. 结构对主体的覆盖率；
2. 无监督时的自愿执行率；
3. 成员主动修复结构的意愿；
4. 规则、传统或训练的跨轮次复制率；
5. 结构是否仍被成员理解为“应当继续”；
6. 结构是否只剩惯性和强制外壳。

### 3.4 成立阶段

必须发生在 `xn` 已经成立之后。若结构尚未运行，只是价值争论，目标端点不存在。

### 3.5 关系体量

- 低体量：一个成员拒绝让结构覆盖某项原则；
- 中体量：关键成员撤回维护，流程必须设置例外或重新设计；
- 高体量：群体撤回正当性，结构仍有强制外壳，却失去内部再生产。

### 3.6 显影条件

拿掉暴力、夺权、财政崩溃、领导更替与外部失败后，结构仍因成员“不再认为它值得被主动维护”而衰减。

## 4. 候选机制与统一

### 候选 A：正当性撤回

```text
zn 判断结构违背不可让渡意义
→ 规则不再被理解为“应当遵循”
→ 自愿执行与内部维护下降
→ xn 持续运行能力被削弱
```

理论后果：改变的是意义接口和自愿再生产，不是设施或流程知识本身。

### 候选 B：覆盖边界被原则截断

```text
xn 试图以统一程序覆盖主体
→ zn 保留不可让渡原则
→ 主体只在不违背原则的范围内执行
→ 结构对该主体的适用范围缩小
```

理论后果：制度可以继续存在，但不能完整定义或调用这个人。

### 候选 C：成员退出复制链

```text
结构依赖成员示范、训练、交接和传递
→ zn 使成员拒绝把该结构交给下一轮
→ 结构失去内部复制节点
→ xn 从持续运行退化为依靠强制维持
```

理论后果：克制可以表现为“不再替结构续命”，不要求公开反抗。

### 正式统一机制

A 是意义判断，B 是当下覆盖结果，C 是时间后果：

> **zn 撤回 xn 的“应当被维护”资格，使结构先失去对主体的完整覆盖，再失去成员自愿执行、修复与传递形成的跨轮次再生产。**

## 5. 正例

### 5.1 《血战钢锯岭》戴斯蒙德·多斯｜训练与军法阶段

- `zn`：多斯认定不能持枪杀人，但仍必须救人；该判断不以军队认可或个人利益为条件。
- `xn`：军队以统一训练、武器规范、纪律、考核和服役流程组织士兵。

```text
统一训练要求所有士兵进入持枪程序
→ 多斯拒绝让该程序覆盖“不杀人”的原则
→ 军队对他的覆盖范围被截断
→ 结构必须设置例外并重写服役接口
```

法律裁定与父亲介入帮助结果落地，但即使没有即时胜利，多斯仍拒绝持枪，说明启动源不是外部认可。

### 5.2 《安提戈涅》安提戈涅｜埋葬波吕涅刻斯阶段

- `zn`：她认定死者必须被埋葬，亲属义务不可被城邦命令取消。
- `xn`：禁葬令通过命令、守卫、处罚和服从程序持续运行。

```text
城邦要求所有人把禁葬令视作应当服从
→ 安提戈涅拒绝该规则定义她与兄长的关系
→ 她退出禁令的自愿服从链
→ 禁令仍有强制外壳，却无法获得完整内部认同
```

本关系锁定的是规则无法完整覆盖她，不是她靠一次行动摧毁整个城邦。

### 5.3 良心拒服兵役者结构例

主体已经进入征召、登记、训练与服役程序，却因不可让渡原则拒绝某项行为：

```text
制度可以处罚他
→ 却不能使他在无人监督时主动维护该规范
→ 也不能使他把该规范作为正确传统传给下一人
```

## 6. 反例

1. 《V字仇杀队》炸毁议会：爆炸、动员和夺取公共局面主要属于 `zx` 行动链。
2. 员工认为公司文化虚伪却照常执行：只有态度变化，`xn` 变量未变。
3. 制度因财政断裂停摆：启动源是资源故障。
4. 学生一时愤怒违反校规：可能只是状态或冲动。
5. 成员因待遇下降辞职：利益变化不等于不可让渡意义。
6. 法律裁定旧制度无效：若成员只是服从新法律，启动源更接近外部 `xn/x/zx`。
7. 领导被推翻后流程停止：领导更替不等于内部意义撤回。
8. 一次公开抗议后制度照常被成员维护：没有改变自愿执行和复制率。

## 7. 最近邻排除

### 与 `zx 克 xn` 或公开夺权

公开冲击、破坏、夺取公共空间和重排权力位置，优先检查 `zx`。`zn克xn` 可以极安静，只表现为拒绝替结构执行、修复和传递。

### 与 `nx 克 x并z`

`nx` 不认领共同说法，改变身份壳覆盖；`zn克xn` 由不可让渡意义主动截断结构的运行覆盖和复制链。

### 与制度内部修订

按既有程序提交议案、投票和改规，可能仍是 `xn` 自我修复。只有成员撤回“它应被维护”的资格，才进入本关系。

### 与资源或技术崩溃

钱、设备、人员或信息不足使流程停摆，改变的是运行条件，不是正当性和自愿再生产。

## 8. 拿掉测试

1. 拿掉公开行动和暴力，主体是否仍拒绝执行与传递？
2. 拿掉外部奖励、认可和胜利，意义是否仍成立？
3. 拿掉财政、技术和领导故障，结构是否仍因成员撤回维护而衰减？
4. 拿掉已运行的 `xn`，是否只剩价值争论？
5. 若成员仍在无人监督时主动执行、修复和教学，说明 `xn` 尚未被克制。
6. 若只是换用制度内部程序修订规则，不能自动判为克制。

两个具体人物案例均通过核心拿掉测试。

## 9. 反向测试

交换为 `xn 克 zn`：

```text
结构通过训练、奖惩、记录和重复实践
→ 压缩主体保留不可让渡意义的空间
→ zn 的无条件性或指导资格下降
```

方向区别：

- `zn克xn` 改变结构覆盖、自愿执行与再生产；
- `xn克zn` 改变内部意义的无条件性与指导资格。

两者不能用同一组“制度与信念冲突”画面互相代证。

## 10. 动态链后果

```text
结构仍然存在
→ 但成员不再认为它值得主动维护
→ 覆盖边界先出现例外
→ 自愿执行、修复与传递下降
→ 结构逐渐只剩强制外壳
```

改变的是结构的内部续命能力，而不是机械生成革命、胜利或制度物理消失。

## 11. 三元与十元并行

三元继续核验作品整体精神运动。

十元只核验：

- `zn` 是否为不依赖外部证明的内部意义；
- `xn` 是否已经跨时间运行；
- 覆盖、自愿执行、修复与传递是否下降；
- 是否实际由 `zx`、财政故障、法律替换或领导更替启动。

不建立父子派生。
