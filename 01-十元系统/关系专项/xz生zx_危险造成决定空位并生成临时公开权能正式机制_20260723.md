# xz 生 zx｜火药桶被触发后生成主动公开方向 v2.0

## 0｜正式结论

> **xz火药桶被触发后，原本蓄积在整体中的力量、冲突或风险从临界静止转为释放；当主体把这股释放组织成明确方向、连续最终决定与他者执行时，临时zx公开权能成立。**

```text
整体危险蓄积与触发敏感（xz）
→ 触发发生，旧稳定结构爆开或失效
→ 现场出现决定空位与必须外推的力量
→ 主体连续作出最终决定
→ 他者实际执行并停止等待旧中心
→ 临时zx成立
```

## 1｜源端点xz

必须在触发前已经成立：

1. 危险储存在一个整体结构中；
2. 压力、冲突或风险已经累积；
3. 一个局部节点可能牵动全局；
4. 爆发前结构可以表面安静或尚未主动释放。

普通灾难、追杀或倒计时不能自动替代xz端点。

## 2｜目标端点zx

必须在触发后新增：

1. 明确的主动方向；
2. 至少两项不同层面的最终决定；
3. 他者实际执行；
4. 他者停止等待旧中心确认；
5. 力量从内部进入外部现实。

只爆发、乱跑、反击或失控，不足以形成zx。

## 3｜被改变变量

```text
蓄积力量释放率
决定空位
最终方向清晰度
最终决定范围
他者执行率
旧中心等待程度
临时公开接口稳定度
```

## 4｜与旧机制的关系

旧版“危险使旧中心失效并产生决定空位”继续有效，但必须补上新前提：

```text
不是普通危险场景
而是已成立的xz火药桶被触发
```

危险逼近、退路关闭和时间压力只能是可能显影，不能替代整体蓄积与触发敏感。

## 5｜能力与位置分开

- xz不能凭空制造专业能力、勇气或领导人格；
- 主体可以提前拥有能力，但危险前没有公开最终决定位置；
- xz触发后生成的是状态层或关系位置层的zx接口；
- 危机结束后若位置回落，不影响本关系在阶段内成立。

## 6｜正例模板

### 模板A｜高压系统爆发后临时接管

组织内部矛盾和危险已累积成火药桶，一个节点触发全局失效；旧中心无法提供方向，原本无正式最终权的主体连续决策并被群体执行。

### 模板B｜关系火药桶爆开后公开定向

长期压抑的关系结构被一个事件点燃。主体不再只是情绪爆发，而是公开规定边界、行动路线与后续秩序，他者据此行动。

## 7｜反例

- xz爆发后纯失控，没有方向；
- 被追杀者临时反击；
- 军官按既有职位下令；
- 团队执行预案；
- 一次建议被采纳；
- 主体只逃跑或被局面推着走；
- x式刀口伤害后立刻攻击，没有整体蓄积。

## 8｜拿掉测试

1. 拿掉触发前的xz整体蓄积，zx是否仍由既有职位产生？
2. 拿掉决定空位，主体是否仍获得新公开接口？
3. 拿掉连续决定和他者执行，只剩一次爆发，zx是否消失？
4. 恢复旧中心后，临时zx是否回落？

若答案不符合预期，本关系不成立。

## 9｜反向测试

```text
xz 生 zx：火药桶先被触发 → 力量被组织成主动公开方向。
zx 生 xz：主动扩权或推出先发生 → 反作用累积成火药桶危险。
```

两方向不得因最后都出现危险与权力而互相代证。

## 10｜调用红线

- xz端点未成立，不得调用；
- 只有灾难题材或危险逼近，不得调用；
- 只有情绪爆发，不得调用；
- 只有一次决定，不得调用；
- 必须标明目标是状态层、关系位置层还是稳定本体；本机制默认只覆盖前两层。

## 11｜结论

关系边`xz 生 zx`继续锁定。正式机制升级为：

> **火药桶被触发后，蓄积力量经主体组织，转化为主动公开方向。**
