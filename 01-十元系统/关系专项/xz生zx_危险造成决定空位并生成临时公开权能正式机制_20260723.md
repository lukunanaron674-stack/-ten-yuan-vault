# xz 生 zx｜危险造成决定空位并生成临时公开权能

## 0. 正式结论

`xz 生 zx` 只按以下窄机制正式调用：

> 危险使原有指挥、规则或等级无法继续提供有效方向，形成现实决定空位；此前没有正式最终接口的主体连续作出至少两项不同层面的最终决定，他者实际执行并停止等待旧中心，于是主体在当前阶段或关系中获得新的公开决定位置。

该机制生成的是**状态层或关系位置层的公开最终接口**，不生成专业能力、勇气、领导人格、正义性或稳定 `zx` 本体。

## 1. 对象分层

| 层级 | xz 源端点 | zx 目标端点 | 正式边界 |
|---|---|---|---|
| 稳定本体 | 长期危险逼近与无法停留 | 长期公开显权与扩权 | 本机制不负责稳定本体生成 |
| 当前状态 | 危险关闭退路和延后空间 | 主体临时成为最终决定接口 | 主要成立层 |
| 行为功能 | 不行动会被吞没 | 连续决定、他者执行、旧中心退位 | 单次反击不足 |
| 光影 | 警报、倒计时、断路 | 中心构图、众人转向 | 只作显影 |
| 场景 | 灾难、坠毁、封锁、追杀 | 临时队伍、逃生路线 | 场景不替代端点 |
| 时间关系 | 旧中心先因危险失效 | 新接口随后形成 | 先后仍须作用链 |
| 关系位置 | 被局面规定者 | 新公开决定中心 | 核心变化 |
| 显影 | 安全路线与时间窗缩窄 | 决定无需反复确认 | 核心变量 |
| 动态链 | 世界逼迫主体行动 | 现场开始围绕主体决定运行 | 不机械生成胜利 |

## 2. 源端点与目标端点

### 2.1 xz 源端点

必须同时满足：

1. 危险已经真实、可感知地逼近；
2. 安全路线、退路或时间窗持续缩窄；
3. 原有指挥、规则或等级因危险失去反应资格；
4. 拿掉危险或恢复旧中心后，本阶段不会产生新的公开决定接口。

### 2.2 zx 目标端点

必须同时满足：

1. 主体此前没有正式最终决定职位或稳定追随关系；
2. 主体连续作出至少两项不同层面的最终决定；
3. 他者实际执行，而不是只听取建议；
4. 他者停止等待旧中心重新确认；
5. 危机结束后若位置立即归零，只判状态层或关系位置层。

### 2.3 被改变变量

- 谁拥有现场最终方向决定权；
- 谁的决定默认有效；
- 他者是否执行并停止等待旧中心；
- 原有指挥或规则是否失去决定资格；
- 主体是否成为新的公开现实接口。

## 3. 正式机制

```text
危险关闭退路并使旧决定中心失效
→ 现场出现无人承担的最终决定空位
→ 此前无正式接口的主体连续作出决定
→ 他者实际执行并停止等待旧中心
→ 主体获得临时公开最终接口
→ 状态层 / 关系位置层 zx 新增
```

### 能力与位置必须分开

人物可以在危险前已经拥有专业知识、体能或判断力。已有能力不等于已有 `zx` 位置；只要危险前无人把最终决定交给他，危险后其决定首次成为公共默认接口，关系位置仍可由 `xz` 生成。

反过来，危险不能凭空制造能力。若拿掉人物既有能力后所有决定都无法成立，只说明能力是必要条件，不自动否定公开位置的生成。

## 4. 正例

### 4.1 《海神号遇险记》弗兰克·斯科特牧师

巨浪使轮船倾覆，船长与上层指挥死亡，原有船舶秩序无法继续提供方向。斯科特此前没有船上正式指挥职位，却连续决定：

1. 不在宴会厅等待，而向翻转后位于上方的船底移动；
2. 选择通风井、机舱与螺旋桨轴方向；
3. 在路线争议、积水、爆炸与人员伤亡后继续重定行动。

一部分幸存者实际跟随并停止等待已失效的船方指挥。其宗教身份和强性格是第三因素，但不能提供船舶正式决定权；公开逃生接口是在灾难造成的空位中形成。

### 4.2 《人狼大战》约翰·奥特维

飞机坠毁与狼群威胁使原有机组、公司和日常等级失效。奥特维此前是猎狼人员，不是幸存者队伍的正式负责人，却连续决定：

1. 生火、处理尸体并安排守夜；
2. 离开暴露的坠机点，前往树林；
3. 制作武器、选择移动路线并处理后续风险。

迪亚兹曾公开质疑其领导，但幸存者仍围绕奥特维的连续判断行动。其野外专长是能力条件，不是既有公开职位；灾难使该能力第一次成为群体默认决定接口。

### 4.3 《海神号遇险记》罗戈的后续接管（辅助例）

斯科特死亡后，原决定中心再次消失。罗戈原本持续质疑斯科特，却在蒸汽阀阶段后接管剩余队伍，继续决定并带领幸存者抵达救援点。该段进一步证明：危险造成的决定空位可以生成临时接口，接口不必等同人物稳定本体。

## 5. 反例

1. 火灾中跟随消防员逃生：主体没有取得决定权，主要是 `nx`。
2. 被追杀者击倒敌人继续逃跑：只是 `xz` 临界反击。
3. 团队按既定预案撤离：主要是 `xn` 运行。
4. 军官按职位下令：最终接口此前已经存在。
5. 因“必须救人”公开领导：优先检查 `zn 生 zx`。
6. 一次建议被采纳：没有连续决定与默认接口。
7. 群众因恐惧暂时服从强者：只证明服从结果，未必形成稳定接口。
8. 夺权之后遭到追杀：方向更接近 `zx 生 xz`。

## 6. 最近邻排除

- 与潜在 `zx` 显影：能力前置不等于决定位置前置；本机制只锁定公开位置新增。
- 与 `zn 生 zx`：后者由意义先规定“必须做”；本机制由危险先使旧中心失效。
- 与 `xn`：预案、排程、分工不等于最终接口转移。
- 与 `x`：掌握武器、资源或职位不等于公开显权。
- 与普通 `xz` 行动：冒险、逃跑和反击必须另证他者执行与旧中心退位。

## 7. 拿掉测试

1. 拿掉危险，主体在同阶段是否仍获得公开最终接口？
2. 恢复旧中心有效指挥后，群体是否仍持续执行主体决定？
3. 拿掉第二项决定、他者执行和旧中心退位，只剩一次正确行动时，目标是否消失？
4. 拿掉正式职位、预案和上级授权后，决定位置是否仍形成？
5. 危机结束后位置若立即归零，是否明确只判状态层？
6. 已有专长只作能力条件，是否与公开决定资格分开记录？

《海神号遇险记》和《人狼大战》均通过“危险前无正式接口、旧中心失效、连续决定被执行”的窄门槛；两例均有既有能力，但没有既有公共最终决定位置。

## 8. 反向测试

```text
xz 生 zx：危险先使旧中心失效 → 主体获得新的公开决定位置。
zx 生 xz：主体先公开扩权或夺位 → 旧秩序反扑并制造危险。
```

两方向不能因为最后都出现“领导与危险”而互相代证。

## 9. 动态链后果

```text
旧中心仍有效，我只是其中一员
→ 危险使旧中心无法继续决定
→ 现场出现最终决定空位
→ 我连续作出决定
→ 他者开始执行并停止等待旧中心
→ 我成为当前阶段的公开最终接口
```

改变的是现实决定中心的位置与默认有效性，不生成能力、领导人格、胜利或永久权力。

## 10. 95%门槛

通过，96%。

理由：

- 能力生成与关系位置生成已经分开；
- 两个具体人物案例均在危险前没有正式最终接口；
- 危险都使原有指挥或制度失效；
- 主体均连续作出多项决定并被他者执行；
- 反例能够排除职位下令、预案执行、普通反击和意义推动；
- 机制被严格限制在状态层或关系位置层，不夸大为稳定本体生成；
- 三元与十元保持并行。

## 11. 调用红线

- 不得写成“危险让人变勇敢或变成天生领袖”。
- 不得用一次反击、救人、逃生或建议被采纳判定。
- 必须证明旧中心因危险失效。
- 必须证明至少两项不同层面的最终决定被执行。
- 必须标明是状态层、关系位置层还是稳定本体；本机制默认只覆盖前两层。
