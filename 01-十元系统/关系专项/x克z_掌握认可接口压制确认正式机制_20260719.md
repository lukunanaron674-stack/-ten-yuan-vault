# x 克 z｜掌握认可接口压制确认正式机制

## 1. 本轮结论

`x克z` 的几何位置继续成立，但 2026-07-18 旧专项把 z 目标端点写成“完成并公开显现”，仍残留旧版 z 口径。

现行 z v2.2 的核心是：

> 精神个体需要一个认可主体看见、回应并确认自己的存在、能力、作品、身份、选择或发现。

因此正式机制修正为：

```text
x 主体掌握 z 与重要认可主体发生确认关系所必需的对象、权限、关系入口、署名界面或传播通道
→ x 主体扣留、垄断、改署、隔离或关闭这些接口
→ 认可主体无法看见目标对象，或把对象错误归因给他人
→ z 主体无法在该认可位置上获得“这是你的存在、能力、作品或选择”的确认
→ z 被克制
```

最短公式：

> **x 通过掌握认可接口，使 z 无法被重要认可者正确看见和确认。**

## 2. 旧口径修正

### 2.1 撤回“完成条件门控就是 z 被克”

扣住资金、设备、场地，使作品无法完成，首先证明：

```text
x 掌握资源
→ 某项行动或生产无法继续
```

它不自动证明 z，因为 z 不是一般目标完成。

只有同时明确：

```text
主体要让什么被谁认可
资源门控怎样切断这一确认关系
```

才可进入 `x克z`。

### 2.2 撤回“深渊吞光”

“哥谭恶意把亚瑟摁回黑暗”“高利贷吞掉追光者”等旧解释，没有明确：

- 谁是 x 主体；
- 掌握了什么；
- 认可主体是谁；
- 认可对象是什么；
- 哪个确认接口被关闭。

因此继续撤回《小丑》旧纯案例资格。

## 3. 对象分层

| 层级 | 本轮判断 |
|---|---|
| 稳定本体 | 不因一次封稿判人物稳定 x；不因一次求认可判人物稳定 z |
| 当前状态 | 被忽视、被夺名、无法获得回应，可是结果状态，不是关系本身 |
| 行为功能 | 扣稿、封发布口、夺署名、隔离认可者、控制推荐与引见 |
| 光影 | 黑暗、聚光、后台、幕布只能作辅助证据 |
| 场景 | 出版社、画廊、学校、公司、平台、家庭不自动构成关系 |
| 时间关系 | 先封锁、后无人认可，只是先后证据 |
| 关系位置 | 老板、编辑、导师、经纪人、平台管理员只有实际掌握接口才成立 |
| 显影 | 认可主体能否看到、正确归因、回应和确认发生实际变化 |
| 动态链 | 从“我的存在或作品可被确认”转成“认可位置被别人控制” |

## 4. 源端点、目标端点与变量

### 4.1 源端点 x

必须存在明确掌握关系：

```text
某主体实际控制
对象 / 作品载体 / 署名权 / 推荐权 / 引见关系 / 发布通道 / 进入认可场景的权限
```

### 4.2 目标端点 z

必须写清：

```text
认可主体是谁？
被认可的内容是什么？
为什么这个认可位置重要？
```

### 4.3 被改变变量

- 认可主体接触目标对象的概率；
- 认可对象能否正确归因给 z 主体；
- z 主体能否进入重要认可位置；
- 回应与确认能否发生；
- 确认是否被他人冒领或替换。

### 4.4 成立阶段

1. **看见前门控**：控制引见、进入、传播或展示接口，使认可主体根本接触不到对象；
2. **看见后归因劫持**：对象已经出现，但控制署名、话语或身份界面，使认可落到别人身上；
3. **回应隔离**：认可主体已经有回应可能，但关系入口被切断，确认无法返回 z 主体。

### 4.5 关系体量

- 低体量：一次推荐被扣、一次署名缺失；
- 中体量：持续控制展示与归因，使能力长期无法被关键认可者确认；
- 高体量：完整垄断认可环境，使 z 主体的作品、身份与能力长期被抹除或冒领。

## 5. 候选机制

### 候选 A：认可入口门控

```text
x 掌握进入重要认可场景的权限或关系
→ 不引见、不推荐、不展示、不转交
→ 认可主体看不到 z 主体或其对象
→ 确认关系不能成立
```

理论后果：作用变量是“能否被认可主体接触”。

### 候选 B：归因与署名劫持

```text
z 主体的作品、能力或发现已经进入公共界面
→ x 掌握署名、所有权或解释权
→ 将对象归给自己或第三人
→ 认可发生，但不落到真正主体
→ z 被克制
```

理论后果：不必阻止对象出现，只需控制“这是谁的”。

### 候选 C：一般资源封锁

```text
不给钱 / 不给设备 / 不给场地
→ 项目没有完成
```

若没有明确认可主体与确认对象，只是 x 对行动或生产条件的控制，不足以判 `x克z`。

### 正式统一机制

A 与 B 是同一机制的两个阶段：

> **x 掌握认可关系所依赖的入口与归因界面，使看见、回应或正确确认无法落到 z 主体。**

C 排除为单独充分机制。

## 6. 正例

### 正例一｜《大眼睛》玛格丽特与沃尔特·基恩

#### 明确阶段

玛格丽特已经创作“大眼睛”画作；沃尔特控制销售、公开叙述、署名和公众身份接口。

#### 关系双方

- x 源端点：沃尔特掌握画作对外销售、署名与作者身份叙述；
- z 目标端点：玛格丽特希望自己的创作能力与作品被公众、买家和艺术界正确确认。

#### 可观察结果

```text
画作被看见并获得认可
→ 署名与作者身份却被沃尔特掌握
→ 认可错误归因给沃尔特
→ 玛格丽特作为创作者无法被确认
```

这是候选 B 的高纯度人物案例。

### 正例二｜《寻梦环游记》赫克托与埃内斯托

#### 明确阶段

赫克托创作歌曲；埃内斯托夺取歌曲与公共作者身份，长期垄断舞台、唱片和历史叙述。

#### 关系双方

- x 源端点：埃内斯托掌握歌曲的公开归属、传播与明星身份界面；
- z 目标端点：赫克托的创作应被家人、公众和历史确认属于他。

#### 可观察结果

公众确实认可歌曲，但认可被归给埃内斯托；赫克托的创作者存在被抹除。

本例混有暴力与 x并z 明星壳，但 `x克z` 的目标变量仍清楚：认可对象被错误归因。

### 正例三｜编辑扣住作者署名

创作者乙完成文章，希望导师与读者确认其研究能力。编辑甲掌握终审、发表与署名界面，并将乙改为“资料协助”，把主署名给负责人。

```text
甲的 x：掌握发表与署名
克
乙的 z：让重要认可者确认“这是我的研究能力与成果”
```

拿掉甲的署名控制，认可立即可正确归因，案例成立。

## 7. 反例

### 反例一｜设备被扣导致作品没画完

没有写明认可主体与确认内容，只能证明生产条件受控，不足以判 z。

### 反例二｜作品公开后观众不喜欢

看见与正确归因已经发生，只是评价为负面。负面回应仍是一种明确回应，不是 x 门控。

### 反例三｜平台算法自然降低曝光

若没有明确主体实际掌握并针对性关闭接口，可能只是 xn 的系统流程或环境条件。

### 反例四｜导师公开批评学生

若核心是公开压制与权威姿态，优先检查 zx；只有导师利用推荐权、署名权或引见权切断确认关系，才同时出现 x 克 z。

### 反例五｜本人拖延未投稿

认可接口可用，但主体没有进入，主要检查 xn、状态或行为，不是 x 克 z。

## 8. 最近邻排除

### 与 zx 公开压制

| 关系 | 源端点 | 目标变量 |
|---|---|---|
| `x克z` | 掌握认可入口、署名或归因界面 | 看见、回应与正确确认不能落到主体 |
| zx 相关压制 | 公开显权、命令、羞辱或逼退 | 主体位置与行动空间被直接压低 |

### 与 xn 流程延迟

正常审核、排期、队列和统一规则优先是 xn。某人把本归其掌握的推荐或署名入口私有化，用来控制谁能被谁确认，才偏 x。

### 与 x并z 生 z

- `x并z生z`：公开壳提供可识别与可归因接口，使认可成立；
- `x克z`：掌握者关闭或劫持该接口，使认可不能正确成立。

二者可能直接构成对向关系，但不能合并。

### 与普通忽视

认可主体自己没有兴趣，不等于第三方 x 克 z。必须存在明确掌握者控制必要接口。

## 9. 拿掉测试

1. 拿掉 x 主体对引见、发布、署名或归因界面的掌握，确认关系是否恢复？
2. 保留作品与能力，但给 z 主体独立接触认可者的通道，克制是否消失？
3. 拿掉认可主体与认可内容后，案例是否只剩资源纠纷？若是，不得判 z。
4. 只拿掉公开威吓，保留署名劫持后关系是否仍成立？若成立，核心是 x，不是 zx。
5. 拿掉署名与归因劫持后，公众是否会把认可正确落到创作者？若会，支持本关系。

## 10. 反向测试

交换为 `z克x`：

```text
z 主体使真相、作品或身份被重要认可者确认
→ 原有私有叙述、冒领关系或接口垄断失效
→ x 的掌握边界被迫缩小
```

例如真实作者公开证明身份后，冒领者失去对作品归属与公共叙述的控制。

反向关系改变的是 x 的掌握边界；原关系改变的是 z 的确认关系，方向不对称。

## 11. 动态链后果

### `x克z → z恢复` 的感觉走向

```text
我有能力、作品或真实身份
→ 但通往重要认可者的门、名字和解释权都在别人手里
→ 世界看见了对象，却没有看见我
→ 当接口被取回，认可第一次正确落回主体
```

改变的是：

> **主体能否在重要认可位置上被正确指认和确认。**

本关系不自动表示：

- 作品无法完成；
- 主体没有价值；
- 认可必然为赞美；
- x 主体一定公开强势；
- z 主体一定是稳定本体；
- 取回署名后所有现实问题自动解决。

## 12. 三元与十元并行核验

- 三元继续核验作品整体精神运动与大感受；
- 十元本轮只核验具体阶段的掌握边界、认可主体、认可对象与确认接口；
- 不从一次夺名反推人物稳定 x；
- 不从一次渴望署名反推人物稳定 z；
- 不建立“三元生十元”或父子派生。
