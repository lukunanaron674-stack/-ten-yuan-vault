# zx 克 n｜正式机制二次核验与旧案例撤回

## 1. 本轮结论

现行专项正本 `zx克n_公开权能击穿承载机制审计_20260718.md` 已完整通过对象分层、端点机制、正反例、最近邻、拿掉测试与反向测试。本轮以当前 `zx` 定义和现行关系表二次核验后，正式保留：

```text
zx 主体公开显权，直接决定成员资格、接收边界或结构运行条件
→ n 原有的接收、保护、照顾、互信与反复返回能力被迫停止
→ n 的承载能力下降、断裂或失效
```

被改变变量是：

- 谁仍被承认为“我们的人”；
- 谁仍有资格被接收、保护和照顾；
- 共同体能否继续维持互信与日常运行；
- 承载结构能否在公开强制后继续抗崩。

旧关系词典中的《盗梦空间》解释正式撤回。柯布通过梦境植入想法，主要涉及方案组织、心理操控、目标完成与资源权限，未清楚证明一个已经成立的 n 承载结构失去接收、保护、互信或持续运行能力；同时旧文把 zx 写成“突破执行者”，与现行“公开显权、扩权并凌驾”的定义冲突。

## 2. 对象分层

| 层级 | 判定 |
|---|---|
| 稳定本体 | 不由一次驱逐、处分或命令反推人物稳定 zx；不因家庭、学校、团队存在就自动判稳定 n |
| 当前状态 | 恐惧、羞耻、愤怒、麻木只是作用后的状态 |
| 行为功能 | 公开命令、处分、驱逐、隔离、强迫表态、强制改组是 zx 行为候选 |
| 光影 | 制服、审讯灯、铁门、中心高位构图只能辅助显影 |
| 场景 | 监狱、家庭、学校、组织不是端点本身 |
| 时间关系 | 先处罚后关系破裂，只证明先后，不自动证明克制 |
| 关系位置 | 上级、家长、校长、典狱长只有实际公开行使权能时才进入 zx |
| 显影 | 成员资格、接收能力、互信或连续运行实际下降 |
| 动态链 | zx 击穿 n 后，可由 zn 重新承认主体资格、由 xn 重建运行，或由新 n 接替承载；关系本身不机械生成修复 |

## 3. 源端点与目标端点

### 源端点 zx

必须同时出现：

1. 明确主体；
2. 权能公开进入现实；
3. 主体直接决定他者位置、资格或行动；
4. 该决定具有压过对象的现实效力。

### 目标端点 n

必须是已经成立的承载结构：

- 能接收成员；
- 能让成员反复返回；
- 能持续照顾、保护、互信或共同生活；
- 具有一定抗崩能力。

### 成立阶段、体量与显影

- 低体量：一次公开命令暂时打断接收或照顾；
- 中体量：互信下降、成员不敢互助、共同体运行受损；
- 高体量：成员资格被取消、共同体解体、承载结构无法继续存在。

显影至少满足一项：原本会接纳的人被拒绝；原本可持续的照顾被迫停止；稳定共同规则被单一权能取消；成员彼此怀疑、疏离或退出；结构无法继续保护弱者。

## 4. 候选机制

### 候选 A：资格取消

```text
zx 公开宣布某人不再属于共同体
→ n 失去继续接收、照顾和保护该成员的资格
→ 承载边界被直接撕开
```

理论后果：目标变量首先落在成员资格与接收边界。

### 候选 B：运行中断

```text
zx 以命令、惩罚或强制改组压过既有承载结构
→ 原本持续的照顾、互信、分工和返回机制停止
→ n 的连续运行能力下降
```

理论后果：成员名义上仍在，n 也可能因无法继续运行而被克制。

### 候选 C：资源封锁

```text
某主体掌握物资、通信、场地或出口
→ n 因资源不足受损
```

若没有公开显权和直接压位，优先检查 x；C 不作为 `zx克n` 正式机制。

结论：A 与 B 是同一正式机制的两个入口，一条针对成员位置，一条针对结构运行。

## 5. 正例

### 正例一：方志敏监狱剧本中的狱友共同体

阶段：狱友已经形成递水、照料病弱者、传递消息和互相承认的 n。

关系双方：管理者公开以处分、审讯和隔离权逼迫某名狱友辱骂、指认或否认同伴，再宣布其“已经背叛”，迫使其他狱友疏远他。

可观察结果：该人不再被承认为“我们的人”，递水、照顾和消息传递停止，狱友共同体的互信与接收能力下降。

这里克制的不是方志敏的个人坚定，而是狱友关系是否还能接住被逼迫者。

### 正例二：家庭首领公开逐出成员

阶段：家庭原本持续提供居住、照顾、保护与成员资格，构成稳定 n。

关系双方：家长当众宣布某人“不再是这个家的人”，并要求其他家庭成员停止联系、居住支持和经济帮助。

可观察结果：家庭 n 的接收边界、照顾连续性和成员资格被公开权能直接切断。

### 正例三：校长强制拆散学生互助小组

阶段：互助小组已长期向困难学生提供学习、食物和情绪支持。

关系双方：校长公开处分核心成员，禁止任何人继续接触，并以处罚威胁其他成员。

可观察结果：互助、接收和反复返回停止，困难学生失去可被接住的位置。

## 6. 反例

1. 上级当众辱骂成员，但团队仍继续接纳、保护与合作。只有 zx 行为共现，没有 n 变量变化。
2. 毕业、合同到期、迁居导致小组自然结束。属于时间关系，不是 zx 克制。
3. 监狱扣住纸笔、通信与文稿出口。若改变的是完成和被看见的条件，优先判 `x克z`。
4. 成员主动泄密后被共同体排除。若没有外部主体公开压位，只是关系后果，不自动判 `zx克n`。
5. 柯布设计多层梦境并成功植入想法。行动复杂且有效，但没有清楚呈现既有承载结构的接收、保护、互信或持续运行能力被取消，因此不能作为纯案例。

## 7. 最近邻排除

### 与 x 克 z

- `x克z`：掌握必要对象、资源、权限或显现入口，使完成或被看见受阻。
- `zx克n`：公开权能直接决定成员资格或压停结构运行，使接收、保护、互信与承载能力下降。

### 与 xn 克 zx

- `xn克zx`：既有规则、流程和时间结构限制单次权能扩张。
- `zx克n`：单一主体权能反过来压过并击穿承载结构。

### 与 n 克 xz

- `n克xz`：稳定容器限制漂流、离开和危险路径。
- `zx克n`：公开权能使容器不能继续接住成员。

### 与普通破坏

打坏房屋、摧毁设施、杀伤成员并不自动等于克 n。只有承载资格、接收能力、互信或连续运行被击穿，目标端点才成立。

## 8. 拿掉测试

1. 拿掉公开命令、惩罚或资格裁决后，n 是否恢复接收和运行？若是，支持本关系。
2. 保留恐惧和资源不足，但成员仍能互助，n 是否仍成立？若是，不能判克制。
3. 拿掉既有 n 后，只剩个人被处罚，则没有目标端点。
4. 拿掉成员资格与连续运行变化，只保留强势气势，则案例仍能完整成立，不需要 `zx克n`。
5. 拿掉《盗梦空间》的“承载结构”解释，故事仍可完整由 xn、x、z 与心理操控说明，因此旧案例未通过拿掉测试。

## 9. 反向测试

交换为 `n克zx`：

```text
稳定共同体通过成员保护、互助与反复接收
→ 吸收或限制单一主体的公开强制
→ zx 的决定范围不能继续扩大
```

该方向在某些案例可成立，但改变的是 zx 的权能范围；本关系改变的是 n 的承载能力。二者目标变量不同，方向不对称。

## 10. 动态链后果

加入链条后，感觉变化是：

```text
原本“这里还能接住我们”
→ 某个公开权能开始决定谁配留下、谁能被照顾
→ 共同体从容器变成筛除与服从的场所
→ 成员不再相信这里能接住自己
```

它不自动表示主体获胜，也不自动生成革命、背叛或共同体彻底消失。低体量可能只是局部照顾中断，高体量才发展为共同体解体。

可能的修复链：

```text
zx 克 n
→ zn 重新承认被逼迫者的主体资格
→ 具体照顾与关系位置恢复
→ n 重新运行
```

这里 zn 不是凭空消灭刑罚，而是修复“他是否仍是我们的人”的意义判断。

## 11. 三元与十元并行核验

三元只核验作品整体精神感受和大关系走向；十元本轮只核验具体阶段中 zx 源端点、n 目标端点和承载变量。不能因为管理者强制驱逐就反推其稳定三元，也不能因为共同体受损就把 n 写成三元或十元的父子派生。

## 12. 95%门槛

通过，置信度 98%。

理由：

- 现行 zx 正本明确要求公开显权、决定范围扩大与凌驾；
- 现有专项正本已把 n 目标变量锁定为接收、保护、互信、成员资格与连续运行；
- A/B 两机制可统一为“公开权能取消承载资格或连续运行条件”；
- 三个正例均能明确关系双方、阶段与可观察结果；
- 反例、最近邻、拿掉测试与反向测试均能稳定区分；
- 旧《盗梦空间》案例同时误写 zx 端点并缺少 n 目标变量，撤回把握超过95%。

## 13. 本轮处理

- 正式保留 `zx克n` 机制；
- 撤回《盗梦空间》作为纯案例；
- 不新增待用户确认问题；
- 下一轮优先审计 `n生xn`：区分承载结构自然提炼维持秩序，与管理者主动制定规则、既有 xn 反过来塑造 n，以及家庭/组织与规则仅仅共现。
