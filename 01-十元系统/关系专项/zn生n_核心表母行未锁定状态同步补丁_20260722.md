# zn 生 n｜核心表母行未锁定状态同步补丁

## 0. 同步裁定

本补丁不锁定 `zn 生 n` 的正式机制，也不改变几何位置。

当前正式读取状态为：

```text
几何位置：保留
旧“有了信仰就建教堂”口径：撤回
最窄候选：意义扩大承接边界
直接机制：未锁定
母行调用：语义待验收
待确认问题：沿用 UQ-20260718-004
```

在 `十元生补克表.md` 完成原位同步前，核心表中以下两处必须按本补丁读取：

```text
3.3 zn：生 n
```

只表示几何位置，不表示机制已经通过案例验收。

```text
zn → n → x
```

应读作：

```text
zn → n（语义待验收） → x
```

不得把该母行直接压缩为“相信某事正确，就会自动建成家园、教堂、组织或共同体”。

## 1. 关系对象分层

| 层级 | zn | n | 本轮裁定 |
|---|---|---|---|
| 稳定本体 | 无奖励、无认可时仍成立的内部意义确定 | 长期接住对象、允许停留并持续处理负荷 | 一次善举、收留或信仰表达不能反推稳定本体 |
| 当前状态 | 此阶段认为某对象不能被放弃 | 此阶段接手、容纳或承担 | 状态先后不能自动判生 |
| 行为功能 | 拒绝抛弃、承担代价、坚持 | 接收、照护、隐藏、处理 | 行为只作为端点证据 |
| 光影 | 圣性、誓言、纪念光 | 房间、床位、围墙、容器感 | 视觉容器不能替代 n |
| 场景 | 宗教、救援、纪念、革命 | 家庭、酒店、避难所、据点 | 教堂、纪念馆和家园只是场景候选 |
| 时间关系 | 意义先成立 | 承接随后持续化 | 先后不足以证明直接生成 |
| 关系位置 | 信念持有者 | 接收者、照护者、共同体 | 神父、家长、领袖等身份不能直接判定 |
| 显影 | “不能把它丢下”的确定度 | 接收范围、持续时间、处理闭环 | 被改变变量落在承接边界 |
| 动态链 | 决定什么必须进入我方承担范围 | 对象真正进入内部并被持续处理 | 不机械生成建筑、制度或成功 |

## 2. 源端点、目标端点与变量

### 2.1 源端点 zn

必须出现：

```text
即使没有奖励、认可、监督和结果保证
主体仍认为某个人、某件事或某段意义不能被抛下
```

排除：

- 普通善良；
- 社会职责；
- 宗教身份；
- 害怕评价；
- 法律义务；
- 为完成任务暂时承担。

### 2.2 目标端点 n

必须出现真实承载闭环：

```text
对象实际进入主体或结构内部
→ 被接住
→ 被允许停留
→ 负荷被持续处理
→ 不是立即推出、外包或一次象征动作
```

### 2.3 被改变变量

- 哪些对象被划入“不能推出去”的范围；
- 愿意接收的对象范围；
- 接入后的持续承担时间；
- 对象是否从外部议题变为内部负荷；
- 是否形成接收、停留与处理闭环；
- 拿掉 `zn` 后，承接边界是否明显缩小。

### 2.4 成立阶段

当前最窄候选要求：

```text
zn 已确定某对象不能被放弃
→ 主体因此把对象纳入自身承担范围
→ 接收与处理跨阶段反复成立
→ n 的承载边界或承载能力上升
```

### 2.5 关系体量与显影条件

- 低体量：一次明确接手，只能作弱证据；
- 中体量：持续照护、隐藏或承担后果；
- 高体量：形成可重复接收、跨时间维持并处理负荷的关系或共同体。

显影必须看到：

1. 对象真的进入承担范围；
2. 没有被立刻推出或转交；
3. 承载持续存在；
4. 拿掉意义判断后，接收范围会收缩。

## 3. 候选机制

### 候选 A：意义扩大承接边界

```text
zn：这件事不能被丢下
→ 主体重划“什么必须由我接住”
→ 原本可被拒绝或视作外部的对象进入自身承担范围
→ 持续接收与处理形成
→ n 上升
```

理论后果：

- 目标变量落在承接边界；
- 不要求先出现建筑；
- 不要求先有公开号召；
- 若成立，最多先锁关系层或结构启动层，不能直接推出成熟共同体。

### 候选 B：意义只提供理由，zx／xn／x 才形成 n

```text
zn 提供应当接住的理由
→ zx 公开推动并守住空间
→ xn 分工、记录与跨时间维持
→ x 提供资源、权限与准入边界
→ n 最终形成
```

理论后果：

- 母行只保留几何压缩；
- 具体链应写成 `zn→zx/xn/x→n`；
- 不允许把意义题材直接写成容器生成；
- “扩大承接边界”可能只是动机层，不足以成为独立生位。

### 排除候选：共同意义聚集自动形成共同体

```text
多人相信同一件事
→ 聚集
→ 共同体成立
```

该机制不足。聚集可能只是集会、号召、共同认可或情绪共振。没有接收、停留、持续处理和抗崩能力，就没有 `n`。

## 4. 正例候选

### 4.1 《卢旺达饭店》保罗与进入酒店的难民

- **阶段**：酒店从商业接待空间转为长期接收、隐藏和供给难民；
- **zn 候选**：保罗确认眼前的人不能被交出去等死；
- **n 候选**：难民进入内部，房间、食物、秩序与风险被持续承担；
- **可观察变化**：原本属于酒店外部的风险对象，被纳入酒店内部承接范围。

第三因素：

- 经理权限含 `x`；
- 谈判与公开推进含 `zx`；
- 物资、名单和秩序含 `xn`。

结论：支持候选 A 可辨认，但不能证明 A 独立于中介。

### 4.2 《偷书贼》汉斯、罗莎与马克斯

- **阶段**：家庭决定长期隐藏并照护马克斯；
- **zn 候选**：不能把马克斯交给迫害体系；
- **n 候选**：马克斯进入家庭内部，被长期隐藏、供给和照护；
- **可观察变化**：外部逃亡者转为家庭持续承担的内部负荷。

第三因素：

- 隐藏规则含 `xn`；
- 家庭空间、物资与准入含 `x`。

结论：同样支持承接边界变化，但未通过独立生成测试。

### 4.3 无统一领袖的长期遗属照护点

群体因“遗属不能被独自留下”，逐渐形成固定接收、资料保存、休息和陪伴位置。

该结构最接近低 `zx`、低制度起点，但缺少第二个可核验人物文本，不能独自越过95%门槛。

## 5. 反例

1. 政府按行政流程建设纪念馆，主要是 `xn/zx`；
2. 一次宗教集会，只证明意义与场景共现；
3. 因声誉压力开放避难所，优先检查 `z/x并z`；
4. 领袖命令成员收留难民，优先检查 `zx/nx`；
5. 商业旅馆因利润接待客人，可以有 `n`，但没有 `zn` 源端点；
6. 只发表“应该帮助”的言论，没有对象进入承担范围；
7. 法律义务监护，拿掉制度后不再接收，主要是 `xn`；
8. 一次性捐款或转交专业机构，没有形成主体自身的持续承载；
9. 有了信仰后筹款施工建教堂，只能证明复合行动链；
10. 建筑出现但内部没有接收、停留和处理能力，只是场景或空壳。

## 6. 最近邻排除

### 与 zn 生 zx

`zn 生 zx` 改变公开推进、号召和权能范围；本候选只观察承接边界。

### 与 n 生 xn

`n 生 xn` 是既有承载为了持续而提炼规则；本候选要求意义先改变谁必须被接住。

### 与 zn 补 x

`zn 补 x` 为已有掌握边界定向，或让意义获得资源落点；不要求对象进入内部承载。

### 与普通善良

一次心软或一次帮助没有无奖励意义，也没有跨时间处理闭环。

### 与 x／n 共现

拥有房屋、资源或准入权不等于真实承载；必须观察对象是否被持续接住。

## 7. 拿掉测试

1. 拿掉 `zn` 后，若仍因商业、行政或亲属义务接收，则不依赖本关系；
2. 拿掉 `n` 后只剩信念、捐款或号召，目标端点消失；
3. 拿掉 `zx` 后仍自发接住对象，才支持直接机制；
4. 拿掉成熟 `xn` 时，承接已经开始可支持候选 A，但长期稳定仍可能依赖 `xn`；
5. 拿掉 `x` 的资源和权限后，仍通过生活与风险承担接住对象，才不只是掌握；
6. 拿掉建筑后承接仍成立，说明建筑只是场景；
7. 对象只被转交给另一结构时，主体自身的 `n` 没有生成。

两个具体人物候选仍未通过全部测试。

## 8. 反向测试

```text
zn 生 n：
意义先改变承接边界
→ 对象进入内部并被持续处理

n 生 zn：
长期共同承载先发生
→ “不能放弃”逐渐沉淀为内部意义
```

两方向可能形成反馈，但不能因为最终同时出现意义和共同体就互相代证。

## 9. 动态链后果

候选 A：

```text
这件事不能被丢下
→ 它不再只是世界外部的问题
→ 它落到我这里
→ 我允许它停留，并持续处理它带来的负荷
```

候选 B：

```text
意义提出方向
→ 权能、组织与资源把方向变成现实结构
→ n 才形成
```

当前能够确定的是：

> **被讨论的感觉层变量是“什么必须进入我方承担范围”，而不是“意义自动制造建筑或组织”。**

不得把 `zn 生 n` 当作机械生成器。

## 10. 三元与十元并行

三元继续核验作品整体精神运动。

十元只核验：

- `zn` 是否为不依赖外部证明的意义端点；
- `n` 是否形成真实接收、停留与处理；
- 承接边界是否改变；
- `zx/xn/x` 是否为必要中介。

三元与十元并行，不建立父子派生。

## 11. 95%门槛

### 高置信通过

- 旧“有了信仰就建教堂”口径失效：99%；
- 建筑场景不能替代 `n`：99%；
- 目标变量应落在承接边界、允许停留和持续处理：98%；
- 必须排除 `zx/xn/x`、法律义务和普通善良：98%；
- “意义扩大承接边界”是目前最贴近双端点的窄候选：96%。

### 未达到95%的部分

- 候选 A 是否独立于 `zx/xn/x` 具有普遍因果效力；
- 低制度、低资源的持续承接是否已经足以判 `n` 生成；
- 两个具体人物案例无法同时拿掉权限、组织和资源中介；
- 直接锁定会改变母行 `zn→n→x` 的正式调用方式。

因此：

```text
正式机制：未锁定
理论定义：不改写
待确认队列：不新增，沿用 UQ-20260718-004
母行：标记语义待验收
```
