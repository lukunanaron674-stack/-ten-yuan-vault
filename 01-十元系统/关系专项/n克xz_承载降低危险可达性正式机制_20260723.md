# n 克 xz｜承载泄压并切断局部到全局连锁正式机制 v2.0

## 0｜正式机制

> **n以真实承载、容纳、隔离、缓冲、泄压和持续处理，把耦合在一起的整体危险拆回可局部管理的部分，降低触发敏感度并切断局部到全局的连锁，从而克制xz火药桶。**

```text
真实承载与持续处理（n）
→ 接收压力并提供内部空间
→ 隔离触发节点、分散危险、吸收冲击
→ 切断局部到全局的传播
→ 整体蓄积与触发敏感下降
→ xz被克制
```

## 1｜源端点n

必须具备：

- 对对象或压力的真实接收；
- 持续而非一次性的容纳能力；
- 能把外部危险纳入可处理空间；
- 能隔离、缓冲、分配或消化压力；
- 能维持恢复、补给或重新组织。

墙、门、封锁和拘禁本身不等于n。

## 2｜目标端点xz

克制前必须有：

- 整体危险蓄积；
- 触发高度敏感；
- 一个局部节点可能牵动全局；
- 爆发后有扩散、失控或不可逆损失可能。

只有外部危险靠近、退路减少或时间紧迫，不足以证明纯xz。

## 3｜被下降变量

```text
整体压力与危险储量
触发敏感度
节点耦合度
局部事故传播率
系统级爆发概率
不可逆损失规模
恢复原状成本
```

## 4｜成立机制分型

### A｜承载泄压

n接收高压对象，提供持续容纳与表达空间，使压力不再只在封闭结构内部累积。

### B｜触发隔离

n把高敏感节点与整体危险结构分隔，使一个小刺激无法直接点燃全局。

### C｜连锁切断

n把耦合系统拆成可局部处理的单元，阻止局部事故跨节点扩散。

### D｜冲击吸收

n承担爆发前后的冲击与后果，降低系统进一步扩散和不可逆损失。

四种分型可以组合，但至少要真实降低xz主变量。

## 5｜反例

- 锁门把压力关在内部；
- 让对象沉默但危险继续累积；
- 一次获救；
- 敌人暂时无法到达；
- 只拖延爆发时间；
- 纯xn防护流程，没有真实承载；
- 危险源自行消失；
- 把火药桶搬到别处但没有降压。

这些情况甚至可能增加xz纯度。

## 6｜拿掉测试

拿掉：

- 真实接收；
- 持续处理；
- 泄压；
- 触发隔离；
- 连锁切断。

只保留墙、门、位置或临时隐藏。若xz仍同样下降，则不支持n克xz。

## 7｜反向测试

承载退出、缓冲消失、触发隔离解除或节点重新耦合后：

- 整体压力应重新累积；
- 触发敏感度上升；
- 局部事故重新可能牵动全局；
- xz回升。

## 8｜最近邻

- `xn防护`：规则和流程降低风险，不一定承载对象；
- `nz修复`：提供回返与重建终点，不一定直接克制爆发前蓄积；
- `x阻断`：切割或破坏危险结构，机制不是承载；
- `敌人撤退`：危险源自行下降；
- `短暂隐藏`：只降低可见度，不一定降低整体压力。

## 9｜与xz补nz区别

```text
n克xz：直接泄压、隔离并切断连锁，使火药桶不易爆。
xz补nz：爆发风险与对象特异回返、修复方向互相补足。
```

## 10｜调用门槛

必须证明：

1. n端真实承载成立；
2. xz端火药桶结构成立；
3. n直接降低整体蓄积或触发敏感；
4. 局部到全局的连锁被切断；
5. 拿掉n后xz重新上升；
6. 变化不由危险源自行消失解释。

## 11｜结论

`n 克 xz`正式机制为：

> **承载把火药桶从整体高压、触发敏感的系统，拆回可容纳、可泄压、可局部处理的结构。**
