# zn 克 xn｜意义撤回制度正当性机制审计

## 0. 审计结论

几何位置 `zn克xn` 保留。本轮未达到95%锁定门槛。

关系词典旧句“意义可以击穿最坚硬的制度”不能继续作为正式机制，因为它把人物信念、公开革命行动、制度崩溃结果压成一条机械因果。`《V字仇杀队》V 对抗 Norsefire` 不是纯案例：V的爆炸、号召、组织与公开权能大量混入 zx；制度失效还依赖群众响应、统治危机和执行链断裂。

当前最有力候选是：**zn 不是直接摧毁 xn，而是撤回其被承认为应当遵循的意义基础，使 xn 的自愿服从、内部维护和持续再生产下降。** 但仍缺少两个排除 zx、外部失败和制度自毁的纯案例，因此不得锁定。

## 1. 对象分层

- 稳定本体：人物长期不依赖奖励、认可和结果而保持“这样做是对的”的内部意义确定，才可判 zn；擅长制度设计、流程维护的人物才可判 xn 本体。
- 当前状态：愤怒、失望、恐惧、幻灭、热血，不自动等于 zn。
- 行为功能：拒绝执行、辞职、抗命、公开演说、推翻机构，分别可能属于 nx中断、zx推进、z占位或一般行为。
- 光影：面具、火焰、旗帜、整齐队列、冷色办公室只是显影材料。
- 场景：政府、学校、教会、军队、公司、法律系统只是 xn 可能成立的环境。
- 时间关系：制度先存在、人物后反对，只能证明先后。
- 关系位置：统治者、执行者、内部成员、异议者必须分开。
- 显影：zn 是否使成员不再把该结构视为“应当维护”；xn 是否因此失去自愿服从、内部修复和持续复制。
- 动态链：关系只改变感觉走向与运行变量，不机械生成革命胜利。

## 2. 端点、变量、阶段、体量与显影条件

### 源端点 zn

人物或群体已经形成不依赖外部奖惩的意义确定，并明确判断某套规则、流程或长期结构不再值得遵循。

### 目标端点 xn

已经持续运行的计划、制度、流程、记录、节点、训练、传统或组织结构。

### 被改变变量候选

1. 结构的正当性与应当服从感；
2. 成员的自愿执行率；
3. 内部维护、修复和复制意愿；
4. 规则在无人监督时的持续有效性。

### 成立阶段

必须发生在 xn 已经真实运行之后；若结构尚未建立，只是价值分歧，不构成克制。

### 关系体量

- 低体量：个人拒绝内化或继续维护一条规则；
- 中体量：关键成员因意义判断撤回合作，使流程持续失灵；
- 高体量：群体共同撤回正当性，制度仍有强制外壳但失去内部再生产。

### 显影条件

拿掉公开暴力、资源崩溃和领导更替后，xn 仍因成员“不再认为它应当被维持”而出现执行与维护衰减。

## 3. 候选机制

### 候选A：正当性撤回

```text
zn 判断某结构违背不可放弃的意义
→ 成员不再把规则视为应当遵循
→ 自愿执行、内部维护和复制下降
→ xn 的持续运行能力被削弱
```

理论后果：`zn克xn` 改变的是结构的意义接口，不是物理设施、权力资源或流程知识。

### 候选B：内部原则拒绝被结构吸收

```text
xn 试图把人物纳入统一程序
→ zn 保持内部意义确定
→ 人物只在不违背意义的范围内执行
→ xn 对该主体的覆盖率下降
```

理论后果：这是局部克制。制度可能继续存在，只是无法完整占据人物。

### 候选C：zx革命冒充zn克xn

```text
人物公开号召、组织行动、破坏设施或夺取权力
→ 制度停止运行
```

该结果主要可能是 `zx` 直接压过结构，zn只提供行动理由。不能因行动者“有信念”就把全部结果归给 zn。

## 4. 正例候选

### 正例候选1：《十二怒汉》8号陪审员，中段至后段

- 关系双方：8号陪审员的“不能在合理怀疑未排除时判一个人死刑”的意义判断，对陪审团既有快速定罪流程与群体运行惯性。
- 具体阶段：其他人准备尽快投票结束时，他拒绝把程序当成自动结论，持续要求重新检查证据。
- 可观察结果：陪审程序没有被物理摧毁，而是其原有“按惯性迅速定罪”的运行方式失去正当性，成员逐步撤回原票。
- 支持点：较接近候选A/B。
- 混杂：8号也主动组织讨论、逐项验证，含明显 xn；他说服他人也含 z/zx 显影，因此仍非纯案例。

### 正例候选2：《血战钢锯岭》戴斯蒙德·多斯，训练与军法阶段

- 关系双方：多斯“不持枪杀人但仍救人”的内部意义，对军队训练、命令和纪律结构。
- 具体阶段：训练营要求统一持枪、周末训练和服从命令时，他拒绝让制度覆盖该原则。
- 可观察结果：军队结构没有崩溃，但对他的覆盖率下降，最终必须为其设置例外并重新解释服役方式。
- 支持点：较接近候选B，改变的是 xn 对主体的覆盖和适用范围。
- 混杂：制度调整依赖法律裁定、上级权限与父亲介入，含 xn内部修订和外部权限因素。

## 5. 反例

1. 《V字仇杀队》炸毁议会：爆炸、公开号召、群众动员和权力崩溃主要是 zx 行动链，不能证明 zn 自身直接克 xn。
2. 员工认为公司文化虚伪但仍照常执行：只有内部态度变化，xn 的执行、维护和复制变量未变，属于共现。
3. 制度因财政断裂或技术故障停摆：目标变量由资源与系统故障改变，不依赖 zn。
4. 学生一时愤怒违反校规：可能是状态、z占位或冲动行为；危险解除后继续认同规则，不构成稳定意义撤回。

## 6. 最近邻排除

### 与 zx克xn（剧情功能候选）

- zx改变：现实权力、设施、命令链、公开局面；
- zn克xn若成立：改变正当性、自愿服从、内部维护与复制。

### 与 xn内部自我修订

制度发现效率低或法律冲突后调整，启动源仍是 xn 的评估与重组；只有成员基于不可让渡意义拒绝继续维护，才可能是 zn 源端点。

### 与 nx停止跟随

nx只是主体不再沿既有方向继续；若没有明确内部意义判断，不能判 zn。`不照做`不是`因为不这样就不是我`。

## 7. 拿掉测试

1. 拿掉 zn 意义判断，只保留利益损失、恐惧或派系斗争，结构仍被抵制，则不依赖 zn。
2. 拿掉公开号召、暴力和夺权，若成员仍因意义撤回而不再自愿执行、维护和复制，才支持 zn克xn。
3. 拿掉 xn 已有持续运行，若只是两种观点争论，则没有目标端点。
4. 拿掉关键成员的维护与服从后，若制度依靠纯强制仍完整运行，只能判低体量局部克制，不能写“击穿制度”。

## 8. 反向测试

交换为 `xn克zn`：

```text
长期制度、训练、程序和奖惩持续组织人物
→ 人物把外部规范内化为“我认为这是对的”
→ 或压缩其表达和实践意义的机会
```

这与 `zn克xn` 不对称。前者改变意义形成、表达或实践条件；后者若成立，改变结构的正当性与维护变量。

## 9. 动态链后果

候选A进入链条后，感觉走向是：

```text
稳定制度仍在运行
→ 内部意义判断撤回认可
→ 人们从“照规矩做是正确的”转成“只是被迫照做”
→ 结构外壳尚在，内部自愿维护开始空心化
```

大感觉：**制度不是被一拳打碎，而是失去人们愿意继续替它活下去的理由。**

候选B进入链条后：

```text
xn要求统一覆盖
→ zn保留不可让渡原则
→ 结构被迫产生例外、边界或适用范围调整
```

大感觉：**规则仍在，但再也不能完整定义这个人。**

## 10. 三元与十元并行核验

本轮不因人物反抗制度就反推其稳定三元；也不把三元视为十元父级。三元只核验作品整体精神感受，十元关系独立核验具体阶段的源端点、目标端点、机制和变量。

## 11. 95%门槛

高置信通过：

- 旧“意义击穿制度”过度机械，必须撤回正式机制资格；
- 《V字仇杀队》不能作为纯 `zn克xn` 案例；
- 恰当目标变量应优先检查正当性、自愿服从、内部维护、复制与覆盖率，而非制度是否物理倒塌；
- 不应把 zx 革命行动、资源崩溃和 xn 自我修订冒充 zn克xn。

未通过：

- 候选A是否就是正式唯一机制；
- 候选B是同一机制的低体量阶段，还是独立机制；
- 当前两个人物案例都含 xn组织、法律权限或公开说服等第三因素。

因此本轮不修改生补克表和关系词典，不新增待用户确认问题，记录为未判定。
