本关系不表示有秘密就毁掉感情，也不表示一次谎言、礼仪身份、太太圈层或角色扮演自动克制 nz。

## 2. 源端点、目标端点与变量

### 2.1 源端点：x并z

至少满足三项：

1. 身份壳或公共角色持续运行，而非一次谎言；
2. 壳真实参与双方相处，不只对外展示；
3. 同一温柔、照顾或承诺可以被读取为角色履行，也可以被读取为真实靠近；
4. 壳决定内部主体如何被关系对象看见；
5. 拿掉壳会改变关系结构。

### 2.2 目标端点：nz

克制前必须已经存在：

- 真实共同生活或停靠；
- 时间厚度与余温；
- 至少一方仍不愿承认结束；
- 可等待、回返或继续保留的位置。

普通信任、社交好感、恋爱题材和合作默契不能代替 nz。

### 2.3 被改变变量

- 过去温柔行为的真实性可判定度；
- 当前靠近行为的归因稳定度；
- 共同记忆是否仍属于真实双方；
- 原关系位置是否仍安全可返回；
- 继续等待、停留和保留联系的意愿；
- 壳暴露后，余温能否跨过身份差异继续存在。

### 2.4 成立阶段、体量与显影

```text
真实关系先留下余温
→ 身份壳开始主导相处，或其存在被揭示
→ 关系证据出现真实主体/角色壳双重归因
→ 一方无法确认自己相处、等待或依恋的是谁
→ 回返位置失去可信度
→ nz下降
```

体量：

- 低体量：一次亲近被怀疑为角色动作，短暂不敢停靠；
- 中体量：共同记忆被重判，过去是否真实变得不确定；
- 高体量：壳覆盖整段关系，真实主体无法回到原位置。

显影至少满足三项：关系先有余温；证据出现双重归因；壳是实际相处接口；回返意愿下降；拿掉愤怒与道德谴责后，可信回返问题仍成立。

## 3. 机制候选与统一

### 候选 A：关系位置替代

```text
公共角色长期承担相处功能
→ 双方越来越只通过角色说话和行动
→ 真实主体退出原关系位置
→ nz找不到可返回的对象
```

理论后果：克制的是“真实双方还能否重新相遇”。

### 候选 B：关系证据污染

```text
身份壳与真实动机同时存在
→ 温柔、照顾、承诺和共同记忆具有双重来源
→ 关系对象无法判断它们属于谁
→ 过去与现在的余温失去可靠证据
→ 停靠意愿下降
```

理论后果：即使温柔有真实部分，只要无法稳定归因，nz 仍会受损。

### 正式统一

> **B 是直接过程，A 是结构结果：身份壳先污染关系证据的归因，随后使真实主体退出可返回的关系位置。**

### 排除候选：被骗后生气

发现秘密后愤怒、报复或离开，只是状态结果，也可能来自 zn 的价值判断、zx 的攻击、xn 的骗局流程或 x 的占有控制，不能单独证明本关系。

## 4. 正例

### 4.1 《广告狂人》唐·德雷柏与贝蒂

阶段：贝蒂发现唐的真实身份后。

- x并z：“唐·德雷柏”是持续多年的丈夫、父亲和广告人身份壳；
- nz：婚姻已经留下共同生活、家庭与仍可继续的余温；
- 机制：过去的照顾、承诺、战争经历与家庭叙述全部出现双重归因；贝蒂无法确认与自己生活的是唐，还是被长期扮演出来的唐；共同记忆不再稳定属于真实双方，原婚姻位置失去可信回返。

经济、婚外情和时代性别结构是第三因素，但拿掉这些因素，“整段关系证据因身份壳而被重判”仍独立成立。

### 4.2 《美国谍梦》克拉克与玛莎

阶段：克拉克的身份开始暴露前后。

- x并z：“克拉克”具有工作、婚姻和生活细节，是稳定相处接口；
- nz：玛莎已把婚姻、共同生活与未来当作不愿结束的停靠位置；
- 机制：过去每次照顾、求助、婚姻承诺与亲密都被重新解释，玛莎无法确认哪些属于真实主体、哪些属于任务角色。她仍可能有余温，却没有可信对象可返回。

间谍任务的 xn、国家权力的 zx 与安全危险的 xz 均存在，但不替代关系证据污染这一直接过程。

### 4.3 长期假名婚姻结构例

甲以稳定假名、职业与家庭经历同乙共同生活多年。乙后来发现：甲的照顾可能真诚，但婚姻身份原本为任务设置。乙的核心变化不是“秘密让我生气”，而是“不知道过去与我共同生活的是谁”，随后不再相信原关系位置可以返回。

## 5. 反例

1. 《色，戒》太太团礼仪与身份圈层，只能证明角色环境存在，未证明既有 nz 的关系证据被污染；
2. 一次隐瞒收入或临时说谎，壳不稳定，无法覆盖整段关系；
3. 伴侣发现秘密后仍能确认过去温柔属于真实主体，回返意愿不降；
4. 演员下台恢复私人身份，角色边界清楚，不污染真实关系；
5. 因背叛价值而离开，核心可能是 zn 判断，不是证据归因；
6. 因控制、限制退出和监控而离开，优先检查 x克nz；
7. 因公开威胁和暴力而断联，优先检查 zx；
8. 原关系从未存在余温，目标端点不存在。

## 6. 最近邻排除

### 与 x 克 nz

- x克nz：知道对方是谁，但无法自由决定留下、离开和返回；
- x并z克nz：能自由离开，却不知道自己还能回到哪个真实关系对象。

### 与 zn 克 x并z

- zn克x并z：主体因内部意义判断主动拒绝身份壳；
- x并z克nz：身份壳污染另一方对关系证据的读取。

### 与普通秘密暴露

秘密只是信息。只有稳定壳长期承担相处功能，并使关系证据无法归因，才进入本关系。

### 与 xn

精密伪装、任务流程和长期组织属于 xn；本关系只取这些流程产出的壳如何改变关系证据与可信回返。

## 7. 拿掉测试

1. 拿掉稳定身份壳，只留一次秘密，nz 是否仍同样下降？若是，不依赖本关系；
2. 拿掉原有关系余温，目标端点是否消失？
3. 拿掉愤怒、价值谴责和外部惩罚，只保留“我不知道你是谁”，回返是否仍下降？
4. 拿掉任务流程与国家权力，关系证据的双重归因是否仍成立？
5. 若壳暴露后，过去行为能够稳定归回真实主体，nz 是否恢复？
6. 若角色边界始终清楚，真实双方能够在角色外相遇，则不构成克制。

三个正例均通过核心测试。

## 8. 反向测试

交换为 `nz 克 x并z`：

```text
关系余温与可信回返仍然存在
→ 双方愿意越过或放下公共角色
→ 身份壳对真实关系的覆盖下降
```

- 正向改变关系证据归因与可信回返；
- 反向改变身份壳的覆盖与维持强度。

方向不对称，不能互相代证。

## 9. 动态链后果

```text
我们曾经真实共同生活
→ 身份壳介入并重新解释过去
→ 温柔、承诺和共同记忆失去稳定归因

```

改变的是关系证据的可信度与回返对象，不机械生成仇恨、报复、身份暴露或永久分离。
