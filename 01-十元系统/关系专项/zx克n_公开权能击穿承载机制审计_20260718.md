# zx 克 n｜公开权能击穿承载机制审计

## 一、正式结论

`zx克n` 的正式关系机制锁定为：

```text
zx 主体以公开权能直接命令、惩罚、驱逐、隔离、强制改组或取消资格
→ n 原有的接收、保护、容纳、维持和反复返回能力被迫停止
→ 成员不能继续被该结构接住，或结构不能按原方式持续运行
→ n 的承载能力下降、断裂或失效
```

被改变的目标变量不是抽象的“温暖程度”，而是：

- 谁仍有资格被接收；
- 成员能否继续留在共同体内；
- 照顾、互信、庇护和日常运行能否持续；
- 结构能否抵抗一次公开强制而不垮；
- 成员是否仍被承认为“我们的人”。

一句话：

> zx 不是靠气势压住 n，而是以公开权能直接取消 n 的承载资格、成员资格或连续运行条件。

## 二、关系对象分层

| 材料 | 层级 |
|---|---|
| 掌权者公开命令、惩罚、驱逐、强制表态、强制改组 | zx 源端点与行为功能 |
| 家庭、团队、狱友共同体、学校、组织的接收和维持能力 | n 目标端点 |
| 恐惧、羞耻、愤怒、麻木 | 当前状态，不等于关系本身 |
| 监狱、办公室、学校、家庭住宅 | 场景，不自动等于 n 或 zx |
| 铁门、制服、审讯灯、阴影 | 光影与视觉显影 |
| 典狱长、上级、家长、校长、首领 | 关系位置；只有实际公开行使权能时才进入 zx |
| 先被处罚、后关系破裂 | 时间关系；先后不自动证明克制 |
| 人物稳定本体 | 本轮不由单次行为反推 |
| 公开强制导致接收、保护、互信或连续运行失效 | 关系显影 |
| zx→n断裂→其他十元介入修复或替代 | 动态链 |

## 三、源端点、目标端点与成立条件

### 3.1 源端点 zx

必须同时满足：

1. 有明确主体；
2. 权能公开显现，而非仅在幕后掌握资源；
3. 主体直接决定他者位置、资格或行动；
4. 决定具有压过对象的现实效力。

典型动作：公开命令、惩罚、驱逐、隔离、强迫表态、宣布解散、撤销成员资格、当众羞辱后强制切断关系。

### 3.2 目标端点 n

必须是已经成立的承载结构，而不是单纯“有人在一起”：

- 能接收成员；
- 能让成员反复返回；
- 能维持照顾、互信、庇护或日常运行；
- 在时间中具有一定抗崩能力。

### 3.3 关系体量

- 低体量：一次公开命令暂时打断照顾或接收；
- 中体量：成员开始不敢互助、互信下降、结构运行受损；
- 高体量：成员被排除、共同体解体、承载结构失去继续存在的能力。

### 3.4 显影条件

至少出现一个可观察结果：

- 原本会接纳的人被拒绝；
- 原本能继续的照顾被迫停止；
- 原本稳定的共同规则被个人权能直接取消；
- 成员因公开强制开始彼此怀疑、疏离或退出；
- 结构无法继续保护弱者或承载共同生活。

## 四、候选机制

### 候选 A：资格取消

```text
zx 公开宣布某人不再属于共同体
→ n 失去继续接收、照顾或保护该成员的资格
→ 承载边界被权能直接撕开
```

理论后果：`zx克n` 首先改变成员资格和接收能力。

### 候选 B：运行中断

```text
zx 以命令、惩罚或强制改组压过既有承载结构
→ 原本持续的照顾、互信、分工和返回机制停止
→ n 的连续运行能力下降
```

理论后果：即使成员名义上仍在，n 也可能因无法运行而被克制。

### 候选 C：一般资源封锁

```text
某主体掌握物资、通信或场地
→ n 因缺少资源受损
```

若没有公开显权和直接压位，优先检查 x，不足以单独证明 zx克n。

### 锁定

A 与 B 是同一机制的两种入口：

- 对成员位置下手；
- 对结构运行下手。

C 排除为最近邻机制。

## 五、正例

### 正例一：方志敏监狱剧本中的狱友共同体

阶段：狱友之间已经形成递水、照料病弱者、传递消息与互相承认的 n。

关系双方：

```text
审讯或管理者的 zx
→ 当众强迫某名狱友辱骂、指认或否认同伴
→ 再宣布其“已经背叛”、逼其他人疏远他
→ 狱友共同体不再接纳该人，互信和照顾停止
→ n 被克制
```

这里真正被改变的不是方志敏个人是否坚定，而是：

> 被逼迫者是否仍被狱友承认为“我们的人”，以及狱友关系是否还能继续接住他。

方志敏的 zn 若介入，不能写成凭空挡住刑罚；更准确的修复链是：

```text
方的 zn 重新解释：被强迫说出的话不等于真实选择
→ 重新承认被逼迫者的主体资格
→ 再给他递水、照顾伤员或传递消息的具体关系位置
→ n 恢复运行
```

这说明 zn 可以帮助 n 再生或修复，但不等于 zn 直接消灭 zx。

### 正例二：校长公开驱逐互助小组成员

阶段：学生互助小组已长期为困难学生提供学习、食物与情绪支持，构成稳定 n。

```text
校长公开宣布核心成员违规并禁止任何人继续接触
→ 以处分威胁其他成员
→ 原本的互助、接收和反复返回停止
→ 困难学生失去可被接住的位置
```

拿掉校长公开处分权后，小组仍可继续运行，克制显著消失。

### 正例三：家庭首领强制逐出成员

家庭原本持续提供居住、照顾与成员资格。家长当众宣布某人“不再是这个家的人”，并要求所有家庭成员停止联系和帮助。

被改变变量是家庭 n 的接收边界、照顾连续性和成员资格，而非普通争吵情绪。

## 六、反例

### 反例一：掌握纸笔和通信出口

监狱系统扣住纸笔、通信、探视与文稿出口，主要改变的是目标完成和被看见的条件，更接近 `x克z`。除非管理者进一步公开强迫狱友断绝照顾与承认，否则不能直接判 `zx克n`。

### 反例二：一次公开辱骂

上级当众辱骂团队成员，但团队仍继续接纳、保护、合作和正常运行。这里有 zx 显权，却没有 n 的目标变量变化，只能判 zx 行为共现。

### 反例三：结构自然解散

毕业、合同到期、成员迁居导致小组结束，属于时间关系或结构自然变化，不是 zx 克制。

### 反例四：成员自身背叛

成员主动泄密后被共同体排除，若没有外部主体公开压位，主要是关系后果，不可自动写成 zx克n。

## 七、最近邻排除

### 7.1 与 x克z

| 关系 | 源端点 | 目标变量 |
|---|---|---|
| x克z | 掌握必要对象、资源、权限与显现入口 | 完成或被看见的条件 |
| zx克n | 公开权能直接决定成员资格或压停结构运行 | 接收、保护、互信与连续承载能力 |

监狱扣文稿出口：优先 `x克z`。

监狱公开逼迫狱友彼此否认、停止照顾：优先 `zx克n`。

### 7.2 与 xn克zx

- `xn克zx`：已运行的规则、流程和时间结构限制单次权能扩张；
- `zx克n`：单一主体权能直接压过并击穿承载结构。

### 7.3 与 n克xz

- `n克xz`：稳定容器限制漂流和离开；
- `zx克n`：公开权能使容器无法继续接住成员。

### 7.4 与普通关系冲突

争吵、误解、嫉妒和疏远只有在明确由公开权能压位，并改变承载能力时，才进入 `zx克n`。

## 八、拿掉测试

1. 拿掉 zx 主体的公开命令、惩罚或资格裁决后，n 是否恢复接收和运行？
2. 保留恐惧、资源不足和环境压力，但成员仍可互助，n 是否仍成立？
3. 拿掉既有 n 后，zx 行为是否只剩普通显权而没有明确克制对象？
4. 拿掉“停止承认、照顾、接收或持续运行”的结果后，是否仍只能说两者共现？

若分别表现为“恢复、仍成立、只剩显权、只是共现”，则机制边界成立。

## 九、反向测试

交换为 `n克zx`：

```text
稳定共同体通过成员互保、制度惯例和持续承载
→ 使单一权能无法随意驱逐、隔离或改组成员
→ zx 的公开扩张受限
```

该反向关系在现实中可能发生，但目标变量不同：

- `zx克n` 改变 n 的承载能力；
- `n克zx` 改变 zx 的扩张能力。

因此方向不对称，不能因双方对抗就混写。

## 十、动态链后果

### 10.1 破坏链

```text
zx 公开裁决成员资格或强制断绝关系
→ n 的承载、互信和照顾断裂
→ 成员失去可返回的位置
→ xz 漂流感或 nx 被迫顺从可能上升
```

整体感觉从“有地方接住”转成“权能一击，容器裂开，成员被抛出去”。

### 10.2 方志敏修复链候选

```text
审讯系统 zx 克狱友共同体 n
→ 被逼迫者被解释为背叛者
→ 方的 zn 重新确认真实选择与人格意义
→ 通过递水、照料、传递等行为重新给予关系位置
→ n 恢复
```

这条链中：

- zx 真正攻击的是狱友共同体的接收和互信；
- zn 改变的是共同体对行为意义的解释；
- 具体照顾行为让 n 重新运行；
- 凌、胡、高若介入，应分别按真实权限、关系位置和行为接口判断，不能统称为“暗zx”。

## 十一、三元与十元并行核验

- 不从典狱长、校长、家长身份直接判稳定 zx；
- 不从家庭、监狱、学校场景直接判 n；
- 本轮只锁定关系层机制；
- 三元负责整体精神大感受，十元负责明确源对象、目标对象、机制与变量；
- 三元与十元并行，不写成父子派生。

## 十二、调用纪律

调用 `zx克n` 必须写清：

```text
谁公开行使了什么权能
对哪一个已经成立的承载结构
取消了谁的资格或压停了哪种运行
n 的接收、保护、互信或连续性具体下降在哪里
拿掉公开权能后关系是否恢复
是否其实只是 x克z、资源不足、普通冲突或时间结束
```

仅有“强权压迫温暖”“监狱很黑”“反派很凶”不得调用本关系。
