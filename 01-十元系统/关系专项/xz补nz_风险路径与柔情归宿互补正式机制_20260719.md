# xz 补 nz｜风险路径与柔情归宿互补正式机制

## 0. 正式结论

> **xz 为 nz 提供“关系可能真正失去、停靠必须被再次选择”的命运压力，使余温从惯性维持变成有代价的归宿选择；nz 为 xz 提供明确的关系终点、可回返对象与“我为何穿过风险”的方向，使漂流不再只是继续逃离。两端互补，不互相生成。**

最短公式：

```text
xz 补 nz：失去风险与离散路径，使停靠获得选择重量
nz 补 xz：关系余温与可返回对象，使漂流获得方向和归宿
```

本关系不等于 `n 克 xz`。n 改变危险可达性、实际停留能力与外部冲击；nz 不必提供安全容器，它改变的是主体愿意朝哪里去、愿意为哪段关系停下或回来。

---

## 1. 关系对象分层

| 层级 | xz | nz | 本轮判断 |
|---|---|---|---|
| 稳定本体 | 危险显形、异质逼近、无法稳定停留 | 关系余温、不愿结束、保持停靠姿态 | 单次逃跑或留恋不能反推稳定本体 |
| 当前状态 | 退路缩窄、时间窗减少、被迫行动 | 等待、回望、舍不得离开 | 状态同框不等于互补 |
| 行为功能 | 逃亡、穿越、抢窗口、冒险返回 | 保留位置、等待、维持旧关系接口 | 行为需回到端点变量 |
| 光影 | 逆光通道、雨夜、列车、断桥 | 暖灯、旧房间、未冷咖啡、空位 | 只能作显影证据 |
| 场景 | 边界、站台、逃生路径、临时住所 | 旧居、渡口、窗边、共同记忆空间 | 场景题材不能替代关系 |
| 时间关系 | 可能先漂流后停靠，也可能因停靠而冒险 | 可能先有关系余温，也可能在危险中显影 | 补关系不要求固定先后 |
| 关系位置 | 漂流者、被追赶者、临界行动者 | 等待者、旧友、亲人、未结束的关系方 | 身份称谓不是十元本体 |
| 显影 | 风险路径、退路、移动紧迫度、方向不确定性 | 可信回返、停靠意愿、关系余温、结束承认度 | 必须分别观察变量 |
| 动态链 | 让“离开”带有命运压力 | 让“回来”成为被选择的归宿 | 不机械生成获救、团圆或永久安全 |

## 2. 双向端点与缺口变量

### 2.1 xz 补 nz

已有 nz：主体仍保留关系余温和停靠姿态，但这份“不想结束”可能只是惯性、习惯或没有真正面对失去。

xz 补入后改变：

- 关系真正失去的可能性；
- 返回窗口的有限性；
- “继续等”是否经过现实风险检验；
- 停靠是否成为主动选择，而不是默认状态；
- 关系余温的命运重量。

### 2.2 nz 补 xz

已有 xz：主体被危险推着穿越路径、不断离开，但可能只有“远离危险”，没有“去向哪里”。

nz 补入后改变：

- 风险路径的方向性；
- 哪个对象或关系值得返回；
- 主体为什么承担穿越风险；
- 漂流是否具有可收束的关系终点；
- 命运从无尽离散转成有归宿候选。

## 3. 候选机制

### 候选 A：失去压力使停靠成为选择

```text
nz 已保留关系余温
→ xz 使离散、错过或永久失去成为现实可能
→ 主体不能再无限期维持模糊停靠
→ 必须明确是否返回、等待或承担风险
→ nz 从惯性余温获得命运选择重量
```

理论后果：xz 不创造柔情，只让已有柔情面对“可能来不及”的现实。

### 候选 B：关系终点为漂流定向

```text
xz 主体不断被危险推着移动
→ nz 提供仍有余温的关系对象与可回返位置
→ 主体的路径从“只要离开这里”变成“我要回到那里/那个人”
→ 漂流获得方向与收束候选
```

理论后果：nz 不消除危险，只改变危险中的最终方向。

### 排除候选 C：收留、治疗与保护

```text
有人提供房屋、食物、医疗和防御
→ 漂流者可以停下
```

这是 `n 克 xz` 的直接机制。若目标变量主要是危险可达性下降和安全停留时间上升，不属于本补位。

### 排除候选 D：走投无路被迫留下

被迫停留没有自愿停靠与关系余温，不构成 nz。

## 4. 正例

### 4.1 《最后生还者》乔尔与艾莉，盐湖城前后至最终选择

关系双方：

- **xz**：二人长期穿越感染区、猎人地带与不断缩窄的安全路径；
- **nz**：旅途中形成的父女式余温，使双方都不愿这段关系以任务完成而结束。

`xz 补 nz`：

```text
关系可能在手术中永久终止
→ 乔尔必须面对“任务完成”与“关系结束”的不可兼得
→ 对艾莉的余温不再只是旅途中的陪伴惯性
→ 它成为乔尔愿意承担巨大风险的选择
```

`nz 补 xz`：

```text
乔尔原本只是护送并继续赶路
→ 艾莉成为明确的关系对象
→ 风险路径获得“带她离开并继续共同生活”的方向
```

第三因素：含 zn 的价值判断、zx 的暴力行动和 n 的照护阶段。本例只取“关系终点为风险路径定向”与“失去压力使余温成为选择”的互补变量。

### 4.2 《星际穿越》库珀与墨菲，跨越虫洞至返航阶段

- **xz**：库珀进入不可预测的宇宙路径、时间错位与可能无法返回的命运临界；
- **nz**：父女关系的余温与墨菲长期保留的回返位置。

`xz 补 nz`：离散时间和可能永别，使“等父亲回来”不再是普通等待，而成为跨越一生仍不愿承认关系结束的命运姿态。

`nz 补 xz`：墨菲及父女承诺为库珀的宇宙漂流提供持续回返方向。即使具体任务含 zn/z/xn，关系终点仍改变了漂流的感觉走向。

### 4.3 纯结构例：战争撤离中的旧友归返

甲与乙曾共同生活多年，关系已经疏远但余温仍在。战争迫使甲不断转移；甲本可沿安全路线独自撤离，却得知乙困在旧城。

```text
xz：道路封锁、时间窗缩窄、返回风险上升
nz：甲仍不愿两人的关系以未告别结束
```

- xz 使“以后再联系”失效，迫使甲确认是否真正保留这段关系；
- nz 使甲的危险路径获得“回旧城找到乙”的方向。

若乙只是任意陌生人，则更可能是 zn/善意；若旧城提供安全住宿，则另查 n。

## 5. 反例

1. **流浪者进入避难所得到床位和医疗**：主要是 `n 克 xz`，改变实际安全与停留能力。
2. **流浪猫被固定投喂**：可能是 n 的照护或普通善意，未证明既有关系余温。
3. **恋人因没钱只能同居**：被迫停留，不是自愿停靠。
4. **追兵逼近使人物突然告白**：可能只是临界情绪；若此前没有关系余温，不能反推 nz。
5. **人物怀念故乡但从不改变路径**：nz 显影存在，但没有补入 xz 的方向变量。
6. **人物为了道德责任返回救陌生人**：优先检查 zn，关系余温不是启动源。
7. **安全后产生依赖**：若核心是承载与保护产生依恋，属于 n/nz 的后续关系，不证明 xz↔nz 互补。

## 6. 最近邻排除

### 6.1 与 `n 克 xz`

| 关系 | 改变变量 |
|---|---|
| `n 克 xz` | 危险可达性、安全停留时间、外部冲击比例 |
| `nz 补 xz` | 风险路径方向、回返对象、归宿候选 |

一句话：n 让你真的停得下来；nz 让你知道为什么、为了谁想停下或回来。

### 6.2 与 `z 生 nz`

`z 生 nz` 若成立，重点是认可或阶段确认如何产生“不想结束”；本关系不要求认可主体，重点是危险与停靠在命运路径上互补。

### 6.3 与 `zn`

因“这是对的”而冒险返回，优先判 zn。因“不愿这段关系就此结束、那里仍是我的回返方向”而返回，才偏 nz。

### 6.4 与普通恋爱依恋

恋爱身份、喜欢和依赖不能替代“已有关系余温 + 不愿结束 + 保留回返位置”。

## 7. 拿掉测试

1. 拿掉 xz 后，nz 是否仍存在但失去“可能来不及、必须选择”的命运重量？
2. 拿掉 nz 后，xz 是否仍成立但只剩离开危险、没有明确回返对象？
3. 拿掉 n 的保护与资源后，关系方向仍否改变风险路径？若仍改变，支持 nz 补 xz。
4. 拿掉 zn 的道德理由后，主体是否仍因不愿关系结束而返回？
5. 拿掉既有共同时间后，人物只是临危产生好感，则 nz 端点不足。
6. 任一端拿掉后案例完全不变，只是共现，不是互补。

三个正例均通过至少一组双向缺口测试。

---

## 8. 反向测试

补位几何对称，但作用方向不同：

```text
xz 补 nz：危险与失去可能改变停靠的选择重量
nz 补 xz：关系余温与回返位置改变漂流的方向和收束
```

“先遇险、后恋爱”不是自动互补；“先有关系、后逃亡”也不是自动互补。必须证明另一端确实改变上述缺口变量。

## 9. 动态链后果

```text
只有 xz：
我必须继续走，但不知道最终要去哪里

只有 nz：
我仍留着关系余温，却可以无限期不面对它是否已经结束

xz ↔ nz：
失去风险迫使停靠被重新选择
关系余温让危险路径拥有回返方向
```

改变的感觉层是：

> **命运从无尽漂流与无期限等待，收束为“我愿意穿过风险回到哪里，以及我是否仍选择在那里停靠”。**

不机械生成团圆、获救、永久安全、健康关系或幸福结局。

---

## 10. 三元与十元并行

三元继续核验作品整体精神感受与大方向。

十元本轮只核验：

- xz 是否已形成危险逼近与风险路径；
- nz 是否已有关系余温与不愿结束；
- xz 是否改变停靠的选择重量；
- nz 是否改变漂流的方向和归宿候选。

不建立父子派生：xz 不是 nz 的来源，nz 也不是 xz 的终极结果。

## 11. 95%门槛

**通过：97%。**

理由：

- 两端符合现行信息量卡；
- 双向机制分别锁定“选择重量”和“路径方向”，没有误写成互生；
- 两个具体人物案例与一个纯结构例明确阶段、双方和可观察变量；
- 七个反例排除 n、zn、被迫停留、普通依恋和临界情绪；
- 最近邻、拿掉测试与反向测试通过；
- 无须改写 xz 或 nz 本体定义。

关系具体怎样改变了漂流方向？
拿掉 n 的保护后，互补是否仍成立？
拿掉 zn 的道德理由后，互补是否仍成立？
