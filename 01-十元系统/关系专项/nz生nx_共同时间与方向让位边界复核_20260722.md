# nz 生 nx｜共同时间与方向让位边界复核

## 0. 本轮结论

```text
几何位置：保留
关系层窄候选：保留
正式机制：未锁定
新增高置信排除：延长共同时间、提高建议接受度、共同协商，均不等于 nx
稳定人物本体生成：不成立
待确认队列：不新增；当前仍属于材料纯度不足
```

本轮没有找到两个能够排除年龄、任务、照护、资源、职位、危险和既有 `nx` 的具体人物案例，因此不把 `nz 生 nx` 升格为正式机制。

但可以确定一个此前摘要中未压清的边界：

> `nz` 可以让主体愿意多留一会、多走一段、重新协商路线或更愿意听取对方建议；只要主体仍保留最终否决与替代路线，就没有形成 `nx` 目标端点。

---

## 1. 关系对象分层

| 层级 | nz | nx | 本轮边界 |
|---|---|---|---|
| 稳定本体 | 长期保留关系余温与回返位置 | 长期不占方向决定位置 | 不从一次同行或接受建议反推人物本体 |
| 当前状态 | 此阶段不愿结束、愿意继续靠近 | 此阶段暂时沿外部方向推进 | 当前最可能成立层 |
| 行为功能 | 等待、回返、延长共同时间、恢复联系 | 跟随、借力、接受安排、不占最终方向 | 同行与协商本身不等于 nx |
| 光影 | 暖光、旧路、旧物、停靠构图 | 退后、侧位、跟随构图 | 只作显影证据 |
| 场景 | 重逢、告别、旅途、旧居 | 队伍、路线、任务、关系通道 | 场景不能替代端点 |
| 时间关系 | 余温先成立 | 方向位置随后下降 | 先后不等于生成 |
| 关系位置 | 旧友、伴侣、亲人、曾经共同生活者 | 跟随者、被安排者、借通道者 | 称谓不能直接判定 |
| 显影 | 不愿结束、愿意继续共同时间 | 否决、替代路线和最终决定位置下降 | 必须看到方向权变化 |
| 动态链 | 关系仍值得继续 | 因此是否让出方向 | 不把关系当人格生成器 |

## 2. 源端点、目标端点、变量、阶段与体量

### 2.1 源端点 `nz`

必须先有：

```text
关系已经真实存在过
→ 形成共同时间与情感余温
→ 主体不愿关系或共同阶段彻底结束
→ 仍保留等待、回返或继续靠近的位置
```

一次好感、一次照顾、怕孤独、现实依赖和恋爱题材均不足。

### 2.2 目标端点 `nx`

必须出现：

```text
主体原本拥有可行替代路线与否决位置
→ 关系对象提出或已经占据明确方向
→ 主体不再把自己放在最终决定位置
→ 沿该方向继续行动
```

以下三种结果均不足：

1. 只是愿意多相处一段时间；
2. 只是更愿意听取建议；
3. 双方重新协商并共同形成路线。

### 2.3 被改变变量

- 独自定向的必要感；
- 最终方向决定位置的认领强度；
- 替代路线是否仍被保留；
- 否决权是否仍可实际使用；
- 跟随是否只在这段关系中出现；
- 拿掉关系余温后，方向让位是否消失。

### 2.4 成立阶段与体量

- 低体量：一次接受路线，只能作弱证据；
- 中体量：在该段关系中反复把最终方向交给对方；
- 高体量：人生方向长期交由关系对象决定。高体量尤其要排除稳定 `nx` 本体、`x/zx` 控制和制度身份。

显影条件：主体有真实选择余地，没有年龄监护、职位命令、任务预设、资源依赖、照护安全与危险压迫。

## 3. 候选机制

### 候选 A：可信停靠降低独自定向负担

```text
关系仍有可信余温与回返位置
→ 主体不再认为每一步都必须独自决定
→ 暂时接受关系对象已经给出的路线
→ nx 在该段关系中上升
```

理论后果：

- 只能先成立于关系层或状态层；
- 改变的是独自定向负担，不是能力和意志；
- 必须证明最终方向位置真的下降，而非只增加协商意愿。

### 候选 B：为了维持关系主动减少方向竞争

```text
主体不愿关系结束
→ 判断继续争夺方向会使共同位置断裂
→ 主动减少否决与替代路线的使用
→ 沿对方方向继续
```

理论后果：

- `nx` 由保留关系这一目的触发；
- 若对方持续要求、威胁、表达和占位，则应转查 `z/zx/x`；
- 若双方共同生成新路线，则属于协商，不是单方让位。

### 竞争解释 C：共同时间延长

```text
关系余温存在
→ 双方愿意多相处一段
→ 行程延长或离开推迟
```

这里只改变共同时间，不改变谁拥有最终方向位置，不构成 `nx`。

### 竞争解释 D：建议接受度上升

```text
我信任你
→ 更愿意听取你的建议
→ 但仍保留否决和替代路线
```

这里只改变建议权重，不构成方向让位。

## 4. 正例候选

### 4.1 山姆与弗罗多｜进入末日火山阶段

- `nz` 候选：长期共同旅程形成不愿放弃彼此的关系余温；
- `nx` 候选：最终任务方向由弗罗多与魔戒使命给出，山姆不改写路线并背负弗罗多继续；
- 具体阶段：进入魔多、弗罗多体力与意志接近极限后；
- 关系双方：山姆与弗罗多。

支持点：山姆拥有强行动力，却没有把最终路线改成自己的路线。

未通过原因：守护朋友的 `zn`、既定任务的 `xn`、照护承载的 `n` 均过强；任务方向并非由关系余温单独生成。

### 4.2 《末路浩劫》男孩与父亲｜向南行进阶段

- `nz` 候选：父亲是男孩唯一可信的关系停靠；
- `nx` 候选：路线、风险判断和节奏由父亲决定，男孩沿其方向推进；
- 具体阶段：灾后长期向南移动；
- 关系双方：父亲与男孩。

支持点：可信关系确实降低男孩独自定向的必要。

未通过原因：年龄、监护、`n` 的保护、`xz` 生存压力和原本不平等的决定权无法拿掉。

### 4.3 纯结构候选：旧友重逢后的单方路线让位

甲乙曾共同生活多年，分离后重逢。甲有两条同等可行路线，乙提出返回旧居。乙没有资源优势、职位权限或专业优势；甲也不受威胁。甲只因不愿关系再次结束，停止坚持自己的路线，明确把最终选择交给乙。

该结构满足端点，但尚缺可核验具体人物文本，不能作为第二个正式正例。

## 5. 反例

1. **杰西与席琳重逢后继续散步和交谈**：共同时间延长、路线不断协商；双方仍共同决定，不是单方 `nx`。
2. **关系很好但各自坚持职业和城市路线**：`nz` 成立，`nx` 不上升。
3. **接受医生、导师或专业人员安排**：专业权限、`n` 或 `xn` 已给出方向。
4. **孩子跟随父母**：年龄与监护权决定路线。
5. **恋人以分手威胁服从**：`zx/x/z` 主动压力，不是关系余温直接生成。
6. **对方提供住房、钱和安全后留下**：优先检查 `n/x` 与现实依赖。
7. **双方共同商议形成第三条路线**：属于共同决策，双方均未退出最终方向位置。
8. **主体原本就是稳定 `nx`**：关系只是显影机会，不是生成源。

## 6. 最近邻排除

### 与 `n` 的承载

- `n` 改变能否被接住、保护和持续停留；
- `nz 生 nx` 候选改变最终方向位置是否让出。

有人接住我，不等于我把方向交给他。

### 与 `z 克 nx`

- `z 克 nx`：重要确认使主体重新认领自身判断与选择，外部安排不再是唯一合法方向；
- `nz 生 nx`：没有外部确认或压迫，主体因关系余温主动少占方向。

### 与 `x/zx` 控制

资源掌握、威胁、公开显权和关系入口控制导致服从，不属于本关系。

### 与共同协商

共同协商改变的是路线形成方式；`nx` 要求某一主体不占最终方向位置。两者不能混写。

## 7. 拿掉测试

1. 拿掉 `nz` 后，主体仍因任务、职位、年龄、资源、危险或照护同样跟随，则不依赖本关系。
2. 拿掉对方主动占位、命令和威胁后，主体仍因关系余温少占方向，才支持候选。
3. 拿掉现实照护与安全条件后，方向让位仍成立，纯度才上升。
4. 拿掉既有共同时间，只剩一次温柔，源端点消失。
5. 拿掉方向位置变化，只剩陪伴、延长时间和听取建议，目标端点消失。
6. 恢复替代路线和否决机会后，主体仍主动不使用，才支持关系层机制。
7. 若双方共同形成路线，拿掉任一方都无法得到同一路线，则属于协商，不是单方 `nx`。

现有两个具体作品候选仍未通过全部测试。

## 8. 反向测试

```text
nz 生 nx：
已有关系余温
→ 主体降低独自定向必要感
→ 暂时沿对方方向

nx 生 nz：
主体长期沿对方方向共同生活
→ 共同路径积累时间厚度
→ 形成不愿结束和回返余温
```

反向 `nx 生 nz` 在“长期同行后产生不舍”中更容易找到纯案例。两方向可能反馈，但不能互相代证。

## 9. 动态链后果

```text
我仍想让这段关系继续
→ 我愿意多留一段时间，并更认真听你的方向
→ 只有当我实际退出最终决定位置
→ 才进入 nz 生 nx 候选
```

改变层级依次是：

```text
共同时间延长
≠ 建议权重上升
≠ 共同协商
≠ 最终方向让位
```

只有最后一项属于 `nx` 目标变量。

本关系不机械生成永久服从、人格软弱、健康关系、正确选择或共同终局。

---

## 10. 三元与十元并行

三元只判断作品整体精神运动。

十元只核验：

- `nz` 是否已有真实关系余温；
- `nx` 是否出现最终方向位置的实际让出；
- 变化究竟是共同时间、建议权重、协商方式，还是方向认领；
- `n/z/x/zx/xn`、年龄、任务和身份是否才是真正作用源。

不得写成 `nz` 是 `nx` 的父级，也不得用命运主题自动生成因果主题。

## 11. 95%门槛

### 高置信通过

- 99%：延长共同时间不等于 `nx`；
- 99%：提高建议接受度不等于 `nx`；
- 99%：共同协商形成路线不等于单方方向让位；
- 99%：稳定人物本体生成不成立；
- 98%：必须排除年龄、任务、照护、资源、职位、危险、`x/zx/xn` 与既有 `nx`；
- 97%：若关系成立，只能先落在关系层或状态层，目标变量是最终方向认领下降。

### 未通过

- 尚无两个第三因素足够弱的具体人物案例；
- 候选 A 与 B 是否是同一机制的负担层和目的层，仍未确定；
- 现有案例无法证明 `nz` 是独立生成源，而不是 `nx` 的显影条件；
- 用户对是否保留正式关系层机制，仍有超过5%概率给出不同答案。
