# zx 生 zn｜跨主体见证内化是否成立二次审计

## 0. 本轮结论

```text
保留 zx 生 zn 的几何位置
同主体“行动自证”继续撤回
跨主体“见证内化”收窄为唯一主候选
现有案例仍无法排除 z、x并z、n、xn 与既有 zn
正式机制未锁定
```

本轮只审计：甲的 zx 是否能直接生成乙的 zn。

不再研究“一个人显权之后才发现自己的意义”，因为现行 zn 不依赖成功、胜利或外部证明；若必须先赢一次才相信自己，通常更接近 z 的确认、x并z 的身份认领或普通自我效能。

## 1. 关系对象分层

| 层级 | zx 源端点 | zn 目标端点 | 本轮要求 |
|---|---|---|---|
| 稳定本体 | 长期依靠公开显权、扩权与凌驾成立 | 长期依靠内部意义确定成立 | 不从一次演说、胜利或感动反推本体 |
| 当前状态 | 某阶段公开接管、压过旧秩序 | 某阶段开始认领原则 | 最可能成立层 |
| 行为功能 | 领导、夺位、公开推进、让现实重排 | 无奖励仍坚持、不背弃原则 | 跟随行为不能代替 zn |
| 光影 | 高位、中心、群众转向、权力显现 | 精神重量、孤独坚持、无人注视 | 视觉只作显影证据 |
| 场景 | 革命、战争、公开抗争、权力中心 | 纪念、信仰、传承、孤独选择 | 题材共现不构成关系 |
| 时间关系 | 甲先公开显权 | 乙后形成内部确信 | 先后不足以证明生成 |
| 关系位置 | 显权者、决定中心 | 见证者、追随者、后继者 | 必须明确源与目标不是同一主体 |
| 显影 | 决定范围、影响范围、旧秩序退位 | 无奖励坚持、脱离英雄仍坚持 | 崇拜与服从必须排除 |
| 动态链 | 原则被强力推入现实 | 见证者把原则变成自己的存在理由 | 不机械生成信仰共同体 |

## 2. 源端点、目标端点与变量

### 2.1 源端点 zx

必须同时出现：

1. 甲的力量公开进入现实；
2. 甲的决定范围、影响位置或等级位置扩大；
3. 他者或旧秩序被迫围绕甲重新反应；
4. 不是普通善举、演讲、坚持或完成任务。

### 2.2 目标端点 zn

乙必须在甲显权后新增或显著增强：

1. 对某一原则的内部意义认领；
2. 即使甲不在、没有奖励、没有群众和成功保证，仍坚持；
3. 坚持对象是原则本身，不是英雄本人、群体身份或胜利阵营；
4. 拿掉宣传、纪念和从众后仍成立。

### 2.3 被改变变量

- 乙对原则的内部确定度；
- 乙在无监督时仍按原则行动的持续度；
- 原则与英雄个人的可分离度；
- 拿掉胜利结果后，乙是否仍认领原则；
- 乙是否从“他很强”转成“这件事即使没人做，我也必须做”。

### 2.4 成立阶段、体量与显影条件

- **成立阶段**：zx 已经公开显现之后，且目标乙此前尚无稳定 zn。
- **低体量**：一个见证者由此形成阶段性内部意义。
- **中体量**：一组见证者在英雄离场后仍按原则行动。
- **高体量**：原则脱离英雄、胜利与制度奖励，成为共同体内部不可背弃的意义。
- **显影条件**：必须看到无人监督、逆风、失败或英雄缺席后的持续选择。

## 3. 候选机制

### 候选 A：原则可行性被显权证明

```text
甲以 zx 把原则公开推入现实
→ 乙看见原则不是空话，而能改变现实
→ 乙开始把原则认作值得坚持的内部意义
→ zn 上升
```

**理论后果**：zx 提供的不是奖励，而是“原则能够进入现实”的存在性证据。

**结构风险**：zn 本来不需要证明。若乙必须看到成功才愿意相信，仍可能是 z 的结果确认，而非 zn。

### 候选 B：公开承担代价使原则与个人分离

```text
甲显权并公开承担失去位置、利益或生命的代价
→ 乙看见甲不是借原则谋利
→ 英雄个人从原则前退开
→ 乙开始在甲缺席时仍坚持该原则
→ zn 上升
```

**理论后果**：关键不是胜利，而是显权者以真实代价取消“这只是表演或谋利”的解释。

**结构风险**：承担代价更可能直接显影甲既有 zn；乙的变化仍可能来自 n 的情感承载、nz 的关系余温或 z 的精神认可。

### 候选 C：决定空位被原则继承

```text
甲以 zx 压过旧秩序并随后离场
→ 现实出现新的决定空位
→ 乙不是继承甲的权位，而是继承其原则
→ 无奖励时仍按原则行动
```

**理论后果**：真正生成点发生在甲离场后，而不是群众围绕甲时。

**结构风险**：若乙只是接任职位、沿组织流程继续，分别更接近 x、xn 或 nx。

### 排除候选 D：英雄形象传播

```text
甲显权成功
→ 海报、纪念、口号、仪式扩散
→ 群体宣称认同原则
```

这主要涉及 x并z 的身份壳、z 的认可、n 的纪念承载与 xn 的传播结构，不足以直接证明 zn。

## 4. 正例候选

### 4.1 《饥饿游戏》凯特尼斯与第十一区民众｜露露死亡后的公开悼念阶段

- **源端点 zx 候选**：凯特尼斯在竞技场规则中公开作出无法被完全吸收的悼念动作，使都城权力必须重新处理她的影响。
- **目标主体**：第十一区民众及后续反抗者。
- **目标 zn 候选**：部分民众不再只因愤怒或利益反抗，而认领“人不应被当作竞技消费品”的原则。
- **支持候选**：B，公开承担风险使原则与表演区分。
- **第三因素**：地区长期压迫、露露的死亡、群体身份、传播符号和反抗组织均很强。
- **当前资格**：复合候选，不是纯案例。

### 4.2 《悲惨世界》主教宽恕冉阿让之后的长期变化

- **源端点问题**：主教公开以自身宗教与社会位置压过警察的定罪解释，并承担银器损失。
- **目标 zn 候选**：冉阿让后来把“人可以不被过去定义、应当救助他人”认作内部意义。
- **支持候选**：B，承担代价取消谋利解释。
- **关键限制**：主教行为更接近 zn、n 与 z 的精神确认，zx 是否达到公开扩权、凌驾与决定范围扩大存在疑问。
- **当前资格**：可作为目标 zn 变化清晰的反向校验，但源端点 zx 不够纯。

### 4.3 《黑暗骑士》渡轮阶段中的市民选择

- **源端点候选**：蝙蝠侠长期公开压过犯罪秩序并承担污名，使“不能按小丑规则互相毁灭”的原则进入现实。
- **目标主体**：两艘渡轮中的普通市民与囚犯。
- **目标 zn 候选**：即使没有奖励、无法保证获救，仍拒绝主动杀死另一船的人。
- **支持候选**：原则在英雄不直接指挥时被独立执行。
- **第三因素**：当场恐惧、法律道德、群体互相监督和剧情设置均很强；蝙蝠侠的 zx 与该具体选择之间并非直接链。
- **当前资格**：候选，不足以锁定。

### 4.4 纯结构候选

甲公开夺回被压迫群体的发言与决定位置，随后失败、离场并失去所有奖励。乙此前只因甲强大而围观；甲离场后，乙仍在无人看见、会受惩罚的情况下保护同一原则。

若这一变化可被具体作品完整呈现，才是高纯 `zx生zn` 候选。

## 5. 反例

1. **强者获胜后群众加入胜方**：利益与胜利预期，不是 zn。
2. **英雄被授勋后成为榜样**：z 的认可与 x并z 的英雄身份。
3. **群众因恐惧服从夺权者**：nx 或权力结果。
4. **追随者本来就相信同一原则**：既有 zn 被显影，不是新生。
5. **英雄牺牲后建立纪念馆**：n、xn 与 x并z 的纪念结构。
6. **学生被老师鼓舞后努力一个月**：状态激励，未证明无奖励持续。
7. **领袖命令成员坚持原则**：zx 或 xn 继续作用，目标仍是服从。
8. **宣传不断重复英雄故事后群体认同**：传播结构，不是 zx 直接生成。
9. **人物因为英雄认可自己而获得意义**：更接近 z 的重要认可。
10. **英雄成功证明某路线有效，群众照做**：可能只是工具理性或 nx。

## 6. 最近邻排除

### 6.1 与 `zn 生 zx`

```text
zn生zx：甲先有内部意义，再公开推进、夺位与显权。
zx生zn：甲先显权，乙随后独立形成内部意义。
```

若意义在行动前已成立，只能证明正向 `zn生zx` 或两者共现。

### 6.2 与 z

被英雄看见、认可、鼓励或确认，改变的是重要认可位置，优先检查 z。

本关系必须在英雄不再回应乙时仍成立。

### 6.3 与 x并z

英雄称号、旗帜、面具、纪念海报和共同身份属于公开壳。认领壳不等于认领原则。

### 6.4 与 n

共同体、纪念空间和长期照护可以承载意义，但承载不等于内部意义生成。

### 6.5 与 xn

教育、传播、训练、制度和重复实践能够使原则稳定运行，但那是组织化，不是 zx 的直接作用。

### 6.6 与 nx

跟随英雄、沿其路线行动可以是 nx。只有英雄离场后仍自主坚持原则，才可能是 zn。

## 7. 拿掉测试

1. 拿掉甲的公开显权与决定范围扩大，只保留善举或演讲，乙仍形成 zn，则不依赖 zx。
2. 拿掉胜利、奖励、英雄称号与传播，乙仍在逆风中坚持，才支持关系。
3. 拿掉乙原有信念，若变化完全消失，说明只是既有 zn 显影。
4. 拿掉甲本人，只保留原则，乙仍坚持，才能证明原则与英雄分离。
5. 拿掉组织、纪念、教育和群体监督，乙仍行动，纯度才提高。
6. 拿掉关系感动与个人恩情，乙仍坚持普遍原则，才排除 nz 与 n。
7. 若甲必须持续命令、监督或奖励乙，目标更接近 nx、xn 或 z。

三个具体候选均未通过全部拿掉测试。

## 8. 反向测试

交换为：

```text
zn 生 zx
```

在现有候选中，反向通常更稳：

- 凯特尼斯先有对露露与人的价值判断，才公开挑战竞技规则；
- 主教先有宽恕与人的意义，才压过警察解释；
- 蝙蝠侠先有不杀与守城原则，才持续显权。

所以源人物自身几乎都证明 `zn生zx`。本轮只能观察源人物的 zx 是否进一步使另一个目标主体形成 zn，不能把甲自己的两端点混写。

## 9. 动态链后果

若跨主体候选成立：

```text
他把原则以公开权能推入现实
→ 我先看见的是力量
→ 当他失败、离场或不再奖励我时
→ 我仍选择那个原则
→ 原则从“他的”变成“我的”
```

改变的感觉层是：

> **公开权能从支配现实的力量，转成见证者内部不可背弃的意义种子。**

它不机械生成：

- 英雄崇拜；
- 群体信仰；
- 正义性；
- 永久传承；
- 所有追随者的 zn；
- 成功后的精神升华。

## 10. 三元与十元并行核验

三元继续核验作品整体精神运动与关系大方向。

十元本轮只核验：

- 甲是否达到 zx 的公开显权、扩权与凌驾；
- 乙此前是否没有稳定 zn；
- 乙是否在甲离场、无奖励和逆风时仍认领原则；
- z、x并z、n、xn、nx 与既有 zn 是否是真正中介。

不建立：

```text
zx 是 zn 的父级
zn 是英雄行动的必然后果
因果主题自动生成本体主题
```

## 11. 95%门槛

### 高置信通过部分

- **99%**：同主体“行动自证”不能作为正式 `zx生zn` 机制。
- **99%**：英雄崇拜、胜方追随、纪念传播与服从不是 zn。
- **98%**：源与目标通常必须分属不同主体。
- **98%**：正式案例必须展示英雄离场、无奖励或逆风后的独立坚持。
- **97%**：跨主体“原则从他的变成我的”是当前唯一值得保留的窄候选。

### 未达到95%的部分

- 现有具体案例均无法同时弱化 z、x并z、n、xn 与既有 zn；
- “见证原则进入现实”是否与 zn 的自完备性冲突仍未完全解决；
- 甲承担代价的作用可能来自其 zn 显影，而非 zx 本身；
- 缺少两个源、目标清晰且拿掉测试通过的具体人物案例。

因此本轮状态：

```text
zx生zn 几何位置：保留
同主体生成：撤回
跨主体窄候选：保留
正式机制：未锁定
生补克表：不修改
关系词典：不修改
待确认队列：不新增
```

不新增待确认问题。当前不足仍是案例纯度与中介排除，不是已经形成用户必须裁决的成熟理论分叉。

## 12. 下一步检索标准

下一例必须同时满足：

1. 甲在前一阶段明确达到 zx；
2. 乙此前没有稳定 zn；
3. 甲离场、失败或失去奖励后，乙仍坚持原则；
4. 乙不是因为英雄认可、群体身份、纪念宣传或组织命令；
5. 原则能够与甲个人分离；
6. 反向 `zn生zx` 只能解释甲，不能解释乙的新增 zn。
