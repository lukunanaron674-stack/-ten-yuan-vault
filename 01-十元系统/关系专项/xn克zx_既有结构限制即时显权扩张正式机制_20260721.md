# xn 克 zx｜既有结构限制即时显权扩张正式机制

## 一、正式结论

```text
zx 试图以主体权能直接扩大当下决定范围
→ xn 已把时间、程序、角色、许可、信息与资源接口组织成持续结构
→ 显权必须先通过既有节点，不能把单次力量直接兑换成完整现实支配
→ zx 的即时扩张范围、速度或持续时间下降
```

`xn` 克制的不是力量本身，而是力量**绕过既有结构、立即扩张现实决定范围的能力**。

## 二、对象分层

| 层级 | xn | zx | 核验边界 |
|---|---|---|---|
| 稳定本体 | 长期主动组织持续运行 | 长期依靠公开显权扩权成立 | 不从一次守规矩或一次爆发反推 |
| 当前状态 | 审批、程序、轮班、许可正在运行 | 主体正在公开接管或越级决定 | 正式机制主要发生层 |
| 行为功能 | 登记、审核、分工、交接、排程 | 宣告、命令、夺位、越级推进 | 行为须回到目标变量 |
| 光影 | 网格、时间表、关卡、文书 | 中心构图、众人转向、强势动作 | 只作显影 |
| 场景 | 法庭、军队、组织、交通系统 | 指挥席、战场、公众现场 | 场景不代替端点 |
| 时间关系 | 结构先成立并跨轮次运行 | 显权随后试图扩张 | 先后仍需机制证据 |
| 关系位置 | 程序维护者、审批节点、制度共同体 | 越级决定者、公开权能中心 | 职位名不自动判定 |
| 显影 | 节点约束、许可门槛、持续运行 | 即时决定范围、扩权速度 | 两端均须可观察 |
| 动态链 | 现实已被预先组织 | 单次权能不能直接改写全部现实 | 不机械生成失败 |

## 三、端点、变量与成立条件

### 源端点 xn

必须具备：

- 已经运行的规则、程序、排程、记录或角色结构；
- 结构在单一主体不配合时仍能继续发挥作用；
- 权限、资源、时间窗或信息接口被分散到多个节点；
- 不是临时命令、单个强者阻拦或普通背景规则。

### 目标端点 zx

必须具备：

- 主体力量公开进入现实；
- 主体试图扩大决定范围、压过他者或越过原位置；
- 他者与环境原本可能围绕主体重新行动；
- 普通执行、战斗、反抗或能力展示不够。

### 被改变变量

- 即时决定范围；
- 越级通过率；
- 公开权能扩张速度；
- 单次命令可覆盖的角色与资源范围；
- 权能离开结构后能持续多久；
- 他者是否必须立即围绕主体重排。

### 成立阶段

```text
xn 已经持续运行
→ zx 试图越级扩张
→ 结构节点要求其等待、分散、备案、授权或回到既定角色
→ 即时扩权范围下降
```

### 关系体量

- 低体量：一次许可或节点延迟单次显权；
- 中体量：多个程序使主体只能局部行动；
- 高体量：结构长期吸收个人爆发，使其无法成为唯一现实中心。

## 四、候选机制

### 候选 A：节点门控

```text
现实被 xn 切分为多个许可与执行节点
→ zx 无法凭单次显权直接调用全部资源和角色
→ 每经过一个节点，扩张范围被重新限定
```

理论后果：克制变量主要是**覆盖范围和越级通过率**。

### 候选 B：时间摊薄

```text
zx 依赖当下集中爆发
→ xn 把决定拆入等待、复核、交接和重复执行
→ 权能峰值被分散到多个时间段
→ 即时凌驾强度下降
```

理论后果：结构不必否定权能，只需让它不能在一个时刻完成全部扩张。

### 统一机制

A 处理空间与角色节点，B 处理时间持续。二者共同说明：

> `xn` 把现实组织成不能被单次权能完整跳过的连续结构。

## 五、正例

### 1. 《超人总动员》鲍勃与超级英雄安置制度

- **阶段**：超级英雄被法律禁止公开行动以后，鲍勃仍试图恢复公开救援；
- **xn**：法律、身份保密、赔偿、职业安排与事故处理形成跨时间结构；
- **zx**：鲍勃凭超能力公开介入并希望重新成为决定现场的英雄中心；
- **结果**：个人力量没有消失，但公开行动范围、持续时间与合法接口被长期压缩。

拿掉制度结构，鲍勃的力量足以迅速重回公共中心；拿掉公开扩权，只保留私人能力，则目标端点消失。

### 2. 《美国队长3：内战》复仇者与索科维亚协议阶段

- **xn**：国际协议、批准程序、成员登记和任务授权试图把复仇者行动纳入持续结构；
- **zx**：复仇者原本可以凭自身力量跨境公开决定介入；
- **结果**：协议不能消灭力量，却把“我判断后立即行动”改为“必须经过授权或承担违法后果”。

该案例混有政治立场与 `zn`，但目标变量仍明确落在即时公开行动范围。

### 3. 五行山式结构锚

孙悟空的力量仍在，但长期有效的结构使其无法把单次爆发直接兑换成现实行动范围。该锚只证明“持续结构压住即时显权”，不把石头重量本身写成 `xn`。

## 六、反例

1. 强者被另一个更强者一拳打倒：主要是 `zx克zx` 或普通力量对抗。
2. 资源所有者不提供资金：优先检查 `x`。
3. 群众不认可领导者：优先检查 `z`。
4. 主体因良心拒绝扩权：优先检查 `zn`。
5. 临时命令要求停止行动：没有跨时间结构，只是一次 `zx` 压位。
6. 设备故障使行动失败：技术状态变化。
7. 按既定计划主动收敛行动：可能是主体自身 `xn`，但未必构成克制。
8. 结构只增加文书，却不改变决定范围、速度或持续时间：只有共现。

## 七、最近邻排除

### 与 x 克 zx

`x` 通过资源、权限或对象归属限制权能可调用范围；`xn` 通过持续运行的节点与时间结构限制即时扩张。

### 与 zn 克 xn

`zn克xn` 改变结构的正当性、自愿执行与再生产；本关系是结构仍有效运行，并限制显权。

### 与 zx 克 n

`zx克n` 击穿接收与承载；本关系是结构反过来要求显权进入既定程序。

### 与普通失败

行动失败不等于 `zx` 被克。必须观察公开决定范围、越级通过率或扩权持续时间下降。

## 八、拿掉测试

1. 拿掉既有程序、节点与跨轮次结构后，zx 是否恢复即时扩张？
2. 拿掉公开扩权意图，只保留普通任务，目标端点是否消失？
3. 拿掉资源封锁后，程序门控是否仍限制行动？
4. 拿掉更强主体的直接压制后，结构是否仍能独立发挥作用？
5. 若只增加等待却最终完整扩权，是否仅降低速度而未降低范围？应按低体量成立。
6. 若主体可随时废除结构，结构并未形成独立约束。

## 九、反向测试

```text
xn 克 zx：
既有结构先运行
→ 即时显权扩张被限制

zx 克 xn：
公开权能先压过程序与节点
→ 结构运行范围下降
```

两个方向改变的变量不同，不能因制度与强者冲突的同一画面互相代证。

## 十、动态链后果

```text
一个主体足以在当下压过现场
→ 但现实已被时间、角色与程序切成连续节点
→ 力量必须进入结构，而不能一次完成全部支配
→ 感觉从“个人权能直接改写现实”转为“现实比个人爆发更长”
```

改变的是**即时显权扩张的范围、速度与持续性**，不机械生成失败、服从、合法性或结构永远胜利。

## 十一、三元与十元并行

三元继续核验作品整体精神运动；十元只核验 `xn` 的持续结构、`zx` 的公开扩权，以及目标变量是否下降。二者并行，不建立父子派生。

## 十二、门槛结论

- 双端点与被改变变量清晰：99%；
- 候选 A/B 可统一为“连续结构限制即时扩张”：98%；
- 两个具体人物/阶段案例与五行山锚能够通过核心拿掉测试：97%；
- 最近邻与反向关系可以区分：98%。

因此将 `xn 克 zx` 锁定为正式机制；总词典中的“交规一出手行动就停了”只能保留为低体量比喻，不能代替正式端点机制。
