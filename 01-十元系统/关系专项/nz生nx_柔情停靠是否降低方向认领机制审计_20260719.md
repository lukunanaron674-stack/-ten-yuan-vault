# nz 生 nx：柔情停靠是否降低方向认领机制审计

## 0. 审计结论

```text
几何位置：保留
关系层／状态层窄机制：有成立可能
稳定人物本体生成：不成立
正式机制：未达到95%，暂不锁定
```

当前最窄候选是：

> 已有关系余温与可信回返位置，使主体在该段关系中暂时不必独自占据方向决定位置，因而愿意沿对方已给出的方向继续。

但现有案例无法稳定排除 `n` 的实际接住、`z` 的主动领路、既有 nx 本体、身份义务与权力结构。因此不能把“温柔的人身边有人跟随”写成正式生成规律。

---

## 1. 关系对象分层

| 层级 | nz | nx | 本轮纪律 |
|---|---|---|---|
| 稳定本体 | 长期保留关系余温、不愿结束 | 长期不占方向决定位置 | 不从一次依赖反推人物本体 |
| 当前状态 | 此阶段想继续停靠、保留回返 | 此阶段暂不决定、沿对方安排 | 本轮主要可能成立层 |
| 行为功能 | 等待、回望、维持联系、轻柔靠近 | 跟随、接受安排、求人、沿通道推进 | 行为共现不自动构成生位 |
| 光影 | 暖光、旧物、停靠空间 | 退后、侧位、跟随构图 | 只作显影证据 |
| 场景 | 家庭、旅途、重逢、告别 | 队伍、工作、关系网络 | 场景不能替代端点 |
| 时间关系 | 关系先有余温 | 随后出现方向让位 | 先后不等于生成 |
| 关系位置 | 旧友、伴侣、亲人、照护对象 | 跟随者、助手、被安排者 | 身份称谓不自动判十元 |
| 显影 | 不愿关系结束、保留回返位置 | 自主方向认领下降 | 必须观察前后变量 |
| 动态链 | 关系仍值得停靠 | 因此暂时沿关系继续 | 不写成人格制造器 |

## 2. 源端点与目标端点

### 2.1 源端点 nz

必须先有：

```text
一段关系已经真实存在过
→ 留有时间厚度与余温
→ 主体不愿承认它已经结束
→ 仍保留回返、等待或继续靠近的位置
```

以下不够：一次好感、一次照顾、恋爱题材、被迫同住、害怕孤独、现实依赖。

### 2.2 目标端点 nx

必须出现：

```text
方向、权限或解决通道由他者／关系给出
→ 主体不把自己放在最终决定位置
→ 沿该方向或通道继续行动
```

以下不够：听一次建议、礼貌配合、正常分工、被威胁服从、无权决定。

### 2.3 被改变变量

- 主体对方向决定位置的认领强度；
- 独自决定的必要感；
- 对关系给出方向的接受度；
- 是否保留替代方案与否决位置；
- 跟随是否只在该段关系中发生；
- 拿掉关系余温后，跟随是否仍然成立。

### 2.4 成立阶段、体量与显影条件

- **成立阶段**：nz 已先成立；关系对象随后给出明确方向或通道；主体原本具有一定可选择空间。
- **低体量**：一次共同移动或接受安排。
- **中体量**：一段关系中反复沿对方方向推进。
- **高体量**：主体长期把人生方向交给关系对象。高体量时尤其要排除稳定 nx 本体、x/zx 控制与制度身份。
- **显影条件**：主体不是因为无权、恐惧、利益、照护资源或任务规则才跟随。

## 3. 候选机制

### 候选A：可信停靠降低独自定向负担

```text
nz 提供仍可信的关系余温与回返位置
→ 主体不再把每一步都视为必须独自决定
→ 暂时接受关系对象给出的方向
→ nx 状态／关系功能上升
```

**理论后果**：

- 可成立于关系层和状态层；
- 不表示 nz 把非 nx 人物永久改造成 nx；
- 被改变的是“独自定向的必要感”，不是能力、智力或意志被删除。

### 候选B：为了维持关系而让出方向

```text
主体不愿关系结束
→ 判断持续争夺方向会破坏停靠
→ 主动少占决定位置
→ 沿对方方向继续
```

**理论后果**：

- nx 由“保留关系”这一目的触发；
- 但容易与 `z 克 nx` 混淆：若对方持续表达、决定和占位，可能是 z 压退 nx，而非 nz 生成 nx。

### 候选C：n 的现实接住冒充 nz

```text
对方提供住房、资源、照护和安全
→ 主体依赖该结构并接受安排
```

本轮排除为直接机制。这里改变主体方向的可能是现实承载与资源条件，不是“不愿关系结束”。

### 候选D：权力／身份服从冒充关系停靠

上级、家长、导师或伴侣原本拥有决定权，主体服从安排。此时优先检查 `x`、`zx`、`xn`、职位关系和既有 nx。

## 4. 正例候选

### 4.1 《指环王》山姆跟随弗罗多进入末日火山阶段

**关系双方**：

- nz 候选：山姆与弗罗多长期共同旅程形成不愿放弃彼此的关系余温；
- nx 候选：任务方向由弗罗多与魔戒使命给出，山姆沿其方向继续，甚至背负弗罗多前进。

**支持点**：

山姆并非缺乏行动力，而是在这段关系中不改写最终方向，选择沿弗罗多已经认领的路线推进。

**第三因素**：

- 强 zn：守护朋友与完成使命；
- 强 xn：既定任务和路线；
- n：照护与承载；
- 任务方向并非单纯由关系余温生成。

因此只能作为复合候选。

### 4.2 《末路浩劫》男孩跟随父亲向南行进阶段

**关系双方**：

- nz 候选：父子之间保留“我们还在一起”的关系停靠；
- nx 候选：路线、风险判断和行动节奏主要由父亲决定，男孩沿父亲方向推进。

**支持点**：

父亲是男孩在灾后世界唯一可信的关系位置，关系信任确实降低男孩独自定向的必要。

**第三因素**：

- 年龄与监护关系；
- n 的保护和资源承载；
- xz 的生存危险；
- 男孩本就缺少平等决定权。

拿掉这些因素后，无法确认 nz 是独立生成源。

### 4.3 纯结构候选：旧友重逢后的短程跟随

甲与乙曾共同生活多年，关系中断后重逢。甲原本有两条可行路线；乙提出沿旧路回到共同生活过的地方。甲并非认为乙更专业，也不依赖其资源，只因仍不愿这段关系结束，暂时不坚持自己的路线，沿乙方向前进。

此结构可支持候选A/B，但仍缺具体作品人物证据。

## 5. 反例

1. **被照护者接受医生安排**：主要是专业权限、n 承载或 xn 流程。
2. **员工因喜欢老板而服从工作安排**：职位关系已给出方向，不能证明 nz 生 nx。
3. **恋人威胁分手，迫使对方听从**：主要是 zx 强制或 z 克 nx。
4. **孩子跟随父母出行**：年龄与监护权决定方向。
5. **人物因走投无路接受陌生人带路**：主要是 xz 临界与现实通道，不存在既有 nz。
6. **朋友关系很好但各自坚持方向**：nz 成立而 nx 不上升，说明不愿结束不必然产生让位。
7. **主体原本就是稳定 nx 人物**：关系只提供显影机会，不是生成。
8. **对方提供住所、钱和安全后主体留下**：优先检查 n、x 与利益条件。

## 6. 最近邻排除

### 6.1 与 n 克 xz／n 提供承载

- n 改变的是能否被接住、保护和持续停留；
- nz 生 nx 候选改变的是主体是否认领方向决定位置。

有人接住我，不等于我把方向交给他。

### 6.2 与 z 克 nx

- z 克 nx：对方持续表达、决定和占位，压缩 nx 的选择空间；
- nz 生 nx：没有持续外压，主体因关系停靠而主动降低方向认领。

最关键测试：拿掉对方主动占位后，主体是否仍因关系余温而跟随？

### 6.3 与 x／zx 控制

掌握资源、威胁、公开显权或掌握关系入口，都可能使主体服从，但不是 nz。

### 6.4 与稳定 nx 本体

稳定 nx 人物在没有 nz 时也会沿外部方向行动。若拿掉关系余温，行为不变，则只是显影。

---

## 7. 拿掉测试

1. 拿掉 nz 后，主体仍因职位、年龄、资源、危险或任务同样跟随，则案例不依赖本关系。
2. 拿掉对方主动领路和占位后，若 nx 不再出现，可能更接近 `z 克 nx` 或普通指挥。
3. 拿掉现实照护与安全条件后，主体仍因不愿关系结束而沿对方方向，才支持 nz 直接作用。
4. 拿掉既有共同时间，只剩一次温柔与好感，源端点不存在。
5. 拿掉方向认领变化，只剩靠近、陪伴和不舍，目标端点不存在。
6. 恢复主体的替代路线与否决机会后，若其仍主动少占方向，候选机制纯度上升。

现有两个具体作品候选均未通过全部拿掉测试。

## 8. 反向测试

交换为：

```text
nx 生 nz
```

候选机制：

```text
主体长期沿对方方向共同生活
→ 共同路径积累时间厚度
→ 形成不愿结束与可回返余温
→ nz 上升
```

这一方向在“长期同行后产生不舍”中反而更容易成立。

方向区别：

- `nz 生 nx`：已有余温先降低方向认领；
- `nx 生 nz`：长期跟随与同行先沉淀关系余温。

两者可能形成反馈，但不能互相代证。

---

## 9. 动态链后果

候选A成立时：

```text
我还想让这段关系继续
→ 我不必在这一刻独自决定全部方向
→ 我愿意沿你已经给出的路继续一段
```

改变的是：

> 从“必须由我决定才能继续”，转成“因为这里仍可停靠，我可以暂时沿关系继续”。

不机械生成：永久服从、人格软弱、失去主见、健康关系、正确选择或共同终局。

---

## 10. 三元与十元并行核验

三元只核验作品整体精神运动。

十元本轮只核验：

- nz 是否先有真实关系余温；
- nx 是否出现方向决定位置的实际让出；
- 作用源是关系停靠，还是 n、z、x、zx、xn、年龄与身份；
- 变化发生在状态、关系功能还是稳定人物本体。

不得写成：

```text
nz 是 nx 的父级
nx 是 nz 的行为派生
命运主题自动生因果主题
```

## 11. 95%门槛

### 高置信通过

- 99%：一次温柔、照护或依赖不能证明 nz 生 nx。
- 99%：稳定人物本体生成口径不成立。
- 98%：必须排除 n、z 克 nx、x／zx、身份与年龄。
- 97%：若关系成立，只能先锁在关系层／状态层，目标变量是方向认领下降。

### 未通过部分

- 尚无两个第三因素足够弱的具体人物案例；
- 候选A与候选B是否是同一机制的两阶段仍不确定；
- 现有正例均无法完全排除 n、zn、任务结构、年龄与身份；
- `nz 生 nx` 是否应保留为正式关系层机制，还是只视作 nz 提供 nx 显影机会，用户存在超过5%给出不同判断的概率。

### 本轮状态

```text
几何位置：保留
关系表现有三行机制：降为待二审口径，不新增锁定
专项正式机制：未建立
待确认队列：不新增；当前只是案例纯度不足，尚未形成优于继续补证的具体理论二选一
```
