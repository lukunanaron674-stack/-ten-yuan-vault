# zx 生 zn｜显权到意义成立机制审计

## 0. 本轮结论

```text
保留 zx 生 zn 的几何位置
撤回“执行足够久了就成了意义”
撤回《肖申克的救赎》作为纯案例的资格
正式机制未锁定
```

现行 `zx` 是主体权能公开显现、扩大并形成凌驾，不是普通执行、坚持或长期做事；现行 `zn` 是不依赖外部奖励、认可与证明的内部意义确定，不是被他人看见后形成的名声、象征或公共评价。因此旧公式同时错置了源端点与目标端点。

## 1. 关系对象分层

| 层级 | zx | zn | 本轮防误判 |
|---|---|---|---|
| 稳定本体 | 长期依靠显权、扩权、凌驾成立 | 长期依靠内部意义确定成立 | 人物同时有 zx、zn 不等于生位启动 |
| 当前状态 | 某阶段夺位、复起、压过环境 | 某阶段意义被重新确认 | 状态先后不能替代作用机制 |
| 行为功能 | 战斗、宣告、领导、夺权、公开推进 | 坚持、不妥协、按内在原则行动 | 行为像不等于端点成立 |
| 光影 | 中心、高位、压顶、王权构图 | 圣性光、纪念性光、精神重量 | 视觉只作辅助证据 |
| 场景 | 战场、群众场面、权力中心、公开冲突 | 教堂、纪念地、孤独选择、精神场域 | 场景共现不构成生位 |
| 时间关系 | 权能先显现 | 意义后被确认或扩散 | 先后不等于生成 |
| 关系位置 | 领袖、挑战者、征服者、决定中心 | 见证者、追随者、确信者、意义共同体 | 必须说明关系双方是否为同一主体 |
| 显影 | 决定范围、影响范围、他者服从度上升 | 无奖励时仍坚持的内部确信上升 | 名声、崇拜、口号传播不能替代 zn |
| 动态链 | 让主体从被规定转为规定局面 | 让行动从有效变成“为什么必须如此” | 只能改变感觉走向，不自动生产信仰 |

## 2. 源端点、目标端点与变量

### 2.1 源端点 zx

必须至少出现：

- 主体权能公开进入现实；
- 主体位置、影响或决定范围扩大；
- 他者、环境或等级秩序被迫围绕主体重新反应；
- 形成凌驾、征服、夺位或无敌之姿。

普通执行、长期坚持、完成任务、成功逃脱都不足以单独成立 zx。

### 2.2 目标端点 zn

必须至少出现：

- 某主体或群体形成内部意义判断；
- 即使没有奖励、认可、观众或成功结果，仍认为“这样做是对的”；
- 意义成为其存在与选择的内部理由，而非宣传标签或他人评价。

### 2.3 被改变变量

本轮候选变量只有三类值得继续验证：

1. **内部意义确定度**：人物是否从“我能做到”进入“我必须这样做，因为这定义了我”。
2. **群体意义认领率**：见证者是否把公开显权背后的原则内化为自己的意义，而不只是崇拜强者。
3. **原则与行动的不可分离度**：某次权能显现是否让原则从口号变成不能背弃的存在理由。

被看见度、名声、象征传播、群众激动、胜利结果不等于以上变量。

### 2.4 成立阶段、体量与显影条件

- **成立阶段**：必须在 zx 已经公开显现之后，观察 zn 的内部确信是否新增或显著增强。
- **低体量候选**：一次公开行动使一个见证者开始认领某原则。
- **中体量候选**：持续显权使群体把原则转化为无奖励仍维持的共同意义。
- **高体量候选**：权能显现改变时代精神，使原则脱离人物个人仍被共同体内部坚持。
- **显影条件**：必须排除既有 zn、宣传包装、名声效应、从众、恐惧服从和胜利奖励。

## 3. 候选机制

### 候选 A：同一主体的“行动自证”

```text
zx 将主体力量公开推到现实
→ 主体在行动中体验到“这就是我”
→ 原本模糊的价值成为不可背弃的内部意义
→ zn 确定度上升
```

**理论后果**：`zx生zn` 可用于人物阶段成长，表示权能实践使意义从模糊偏好变成存在理由。

**主要风险**：现行 zn 明确“不需要被证明”。若人物必须靠成功、胜利或公开显权才相信意义，目标更可能是 z 的确认、x并z 的身份认领或普通自我效能，而非 zn。候选 A 与 zn 的自完备性存在结构性冲突。

### 候选 B：跨主体的“见证内化”

```text
人物甲以 zx 公开显权并让现实围绕其原则重新反应
→ 人物乙或群体不只看见力量，也看见原则能够进入现实
→ 乙在无奖励时仍认领该原则
→ 乙或群体形成 zn
```

**理论后果**：`zx生zn` 主要是关系层或群体层机制，源端点与目标端点通常不是同一主体。

**主要风险**：观众可能只是崇拜强者、追随赢家、接受宣传或被符号感染，分别更接近 z、nx、x并z 或利益判断。必须证明他们认领的是原则本身，而不是权力拥有者。

### 候选 C：公共显权把原则变成时代象征

```text
zx 公开压过旧秩序
→ 行动被传播、纪念和符号化
→ 原则成为共同体的精神核心
```

**理论后果**：可解释英雄行动如何成为历史意义。

**判定**：当前不接受为直接机制。传播、纪念与符号化主要涉及 `x并z`、`z`、`n` 与 `xn`；“成为象征”并不自动等于群体内部形成 zn。

## 4. 正例候选

### 4.1 《勇敢的心》华莱士｜斯特灵桥胜利至后续追随阶段

- **人物与阶段**：华莱士公开领导反抗、取得战场胜利并挑战贵族等级之后。
- **源端点 zx**：他的权能公开扩大，士兵与贵族必须围绕其行动重新选择位置。
- **目标端点候选 zn**：部分苏格兰人可能从“跟随一个能打赢的人”转为内部认领“自由本身值得坚持”。
- **支持候选**：B，跨主体见证内化。
- **第三因素**：华莱士自己的自由信念早已存在；群众还受到民族身份、战争利益、复仇、领袖魅力和胜利奖励影响。
- **当前资格**：候选，不是纯案例。

### 4.2 《肖申克的救赎》安迪｜越狱揭露监狱腐败之后

- **人物与阶段**：安迪成功越狱、揭露诺顿并使监狱权力结构崩塌之后；目标观察对象是瑞德，而不是“肖申克的公共名声”。
- **源端点候选 zx**：安迪从被监狱规定的人转成反过来改写监狱局面的人，权能高显影。
- **目标端点候选 zn**：瑞德最终不再只把希望视为危险幻想，而愿意在无制度保证的情况下选择希望。
- **支持候选**：B，甲的显权可能提高乙对“希望值得坚持”的内部认领。
- **第三因素**：二十年友谊、信件、具体逃生路线、出狱后的绝望与承诺都在起作用；瑞德的变化也可能是 nz、nx、xz 与 zn 混合链。
- **当前资格**：只能保留为复合候选，不能再写“执行足够久了就成了意义”。

### 4.3 孙悟空｜大闹天宫与“齐天大圣”阶段

- **源端点 zx**：公开显权、扩大、挑战最高等级，标准 zx 高显影。
- **目标端点候选 zn**：是否因此形成“众生不应被等级压住”的内部意义，或让他者认领这一原则。
- **结果**：证据不足。孙悟空的行动可由尊严、占位、权力与反压制解释；天庭和群妖对其反应也不等于形成 zn。
- **当前资格**：用于反证“标准 zx 也不自动生 zn”。

## 5. 反例

### 5.1 执行足够久后被称为英雄

一个人长期完成任务，后来获得勋章、名声和英雄称号：

- 长期执行可能是 xn；
- 完成与被看见可能是 z；
- 英雄身份与宣传形象可能是 x并z；
- 没有证据说明本人或观众形成无奖励仍坚持的内部意义。

因此不是 `zx生zn`。

### 5.2 强者公开夺权后群众追随

群众因为害怕、利益、胜利预期或从众而追随：

- zx 端点可能成立；
- 追随行为可能是 nx；
- 服从不等于内部意义认领。

因此只是权力变化与行为结果。

### 5.3 英雄牺牲后成为城市象征

纪念碑、口号、海报和仪式形成：

- 主要说明 n 的承载、x并z 的符号包装、xn 的纪念制度与 z 的显现；
- 象征存在不等于市民在无人监督、没有奖励时仍按其原则行动。

因此不能直接判 zn。

### 5.4 人物通过赢得比赛确认“我果然是对的”

其内部判断依赖胜利结果，拿掉胜利就可能动摇：

- 更接近 z 的结果确认或身份自信；
- 与 zn 的“不需要外部证明”冲突。

因此不是同主体 `zx生zn`。

## 6. 最近邻排除

### 6.1 与 `zx生z` 式误写

公开力量带来关注、认可、完成和焦点，目标变量是被看见度与结果显现，优先检查 z，不得写成 zn。

### 6.2 与 `zx→x并z`

显权后形成王者身份、英雄形象、旗帜和宣传壳，目标变量是公开身份与包装认领，优先检查 x并z。

### 6.3 与 `zn生zx`

```text
zn：因为这是对的，所以我要让它进入现实
→ zx：公开行动、显权、扩权
```

这条方向在许多革命者、英雄和信念型行动者中更自然。若人物的意义在行动前已经稳定存在，则案例证明的是 `zn生zx` 或 zn 驱动 zx，而不是反向。

### 6.4 与 `z生zn`

若重点是完成、被看见或被认可之后产生意义认领，首先会落入 `z生zn` 的候选边界；`zx生zn` 必须额外证明关键变量来自权能凌驾与决定范围扩大，而不是结果与关注。

## 7. 拿掉测试

1. **拿掉公开显权与决定范围扩大**：只保留长期坚持或成功结果，zn 仍形成，则不依赖 zx。
2. **拿掉胜利、认可、宣传和纪念**：人物或群体仍因见证原则进入现实而无奖励地坚持，才支持关系。
3. **拿掉目标主体原有意义**：若其 zn 消失，说明原本就是既有 zn 的显影或强化，不是新生。
4. **拿掉原则，只保留强者力量**：群众仍追随，则只是权力、利益或 nx，不是 zn。
5. **拿掉关系双方差异**：若源与目标混成“同一个英雄既强又有信念”，无法证明作用方向。

## 8. 反向测试

交换为：

```text
zn 生 zx
```

在大量案例中更容易成立：人物先确信“这件事是对的”，随后公开推进、夺位、领导或压过阻碍。华莱士、V、革命者和信念型英雄通常都能这样解释。

因此对任何 `zx生zn` 候选，必须证明：

- zn 在 zx 之前尚未成立或明显较弱；
- 关键变化由显权、扩权与凌驾带来；
- 不是 zn 先存在并驱动 zx；
- 不是两者同时显影。

当前两个作品候选均无法完全排除反向，因此正式机制不锁定。

## 9. 动态链后果

### 若候选 A 成立

```text
我把力量推入现实
→ 我在行动中发现这不是一次胜利，而是我存在的理由
```

感觉层从“能做到、压过去”转成“为什么必须这样活”。但它与 zn 不需证明的口径冲突，暂不采用。

### 若候选 B 成立

```text
他把原则以权能推到世界面前
→ 我看见这不是口号
→ 即使他离开、失败或不再奖励我，我仍愿意按这个原则活
```

感觉层从“强者改变局面”转成“见证者内部出现不可背弃的意义”。这是当前最有潜力的方向，但证据仍不足。

### 链条纪律

`zx生zn` 不表示：

- 战斗久了自动有意义；
- 成功自动高尚；
- 英雄出名自动成为 zn；
- 领导者自动让群众有信仰；
- 公共符号自动成为内部精神核心。

## 10. 三元与十元并行核验

- 三元用于核验作品整体精神感受和大关系走向；
- 十元用于核验具体阶段的 zx 源端点、zn 目标端点和变量变化；
- 不从 zx 或 zn 反推固定三元；
- 不把“意义型作品”写成所有行动都属于 zn；
- 不把“强势英雄”写成所有精神后果都由 zx 生成。

二者并行，不构成父子派生。

## 11. 95%门槛

### 已通过，可直接修正

1. `zx` 不能再解释为普通执行或长期做事。
2. `zn` 不能解释为被看见、被称赞或成为公共象征。
3. “执行足够久了就成了意义”与现行两端点同时冲突，应撤回。
4. 《肖申克的救赎》不能继续作为纯 `zx生zn` 案例；至多保留为安迪影响瑞德的跨主体复合候选。
5. 任何正式机制都必须区分同主体与跨主体，并排除 `zn生zx`、z、x并z、nx 和既有 zn。

### 未通过，不锁定

1. 同主体“行动自证”是否与 zn 自完备性根本冲突。
2. 跨主体“见证内化”是否就是 `zx生zn` 的正式机制。
3. 华莱士与安迪案例中的第三因素仍过多，缺少纯案例。

### 队列判断

本轮不新增待用户确认问题。当前不足主要是纯案例与跨阶段证据不足，并非已经形成必须由用户判断的清晰二选一理论分叉。先记录未判定，不拿材料贫困冒充哲学难题。

## 12. 后续检索标准

下一批案例必须同时满足：

1. zx 在前一阶段明确成立；
2. 目标主体在此前没有稳定 zn；
3. zx 后目标主体形成无奖励、无观众仍坚持的内部意义；
4. 拿掉胜利、名声、宣传与身份包装后仍成立；
5. 反向 `zn生zx` 无法解释；
6. 至少有一例源、目标为不同人物，关系双方清楚。
