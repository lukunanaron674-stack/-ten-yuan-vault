# 题材分析：爱情

## 题材定义

爱情 = 两个个体之间产生的强烈情感连接，核心结构是「相遇→连接→考验→（在一起或分离）」。

## 激活的主题及强度

| 主题 | 激活强度 | 说明 |
|:----|:-------:|:------|
| **命运型** xz+nz | **10** | 爱情是命运型最经典的题材化——「跑和等」的结构。一个人在追逐(xz)，一个人在等待(nz)。「我们能不能在一起」是命运问题不是选择问题。爱情中最动人的不是「爱了」，是「跑不动了还在跑，等不来还在等」 |
| **本体型** zn+x | **8** | 爱情触发本体追问——「我爱他是因为他是我想要的人」(x)还是「爱他就是意义」(zn)。爱情中的付出、牺牲、意义化都是zn的运作。但爱情的本质不是意义追问——「为什么爱」是爱之后的反思，不是爱本身 |
| **空间型** x并z+n | **7** | 爱情中的伪装与承载——初期恋爱往往有x并z的表演成分（「展现最好的一面」），长期关系需要n的日常承载。很多爱情故事的冲突来自「壳」与「真」的张力 |
| **时间型** xn+z | **5** | 时间是爱情的考验——「经过了时间还爱不爱」。但不是所有爱情故事都以时间为轴 |
| **因果型** zx+nx | **4** | 爱情不靠执行与清算。算计爱情(nx)是爱情的堕落形态——「我们合不合适」不是爱情的核心问题 |

## 人物配置

| 角色类型 | 十元 | 说明 |
|:--------|:----:|:------|
| 追逐者 | xz (主) | 主动靠近、不断行动——「我必须和你在一起」。爱情中最动感的一方 |
| 等待者 | nz (主) | 守望、坚持——「我等你」。爱情中最静止的一方。等待者的价值往往被低估——但其实nz的「不走」和xz的「来」同样重要 |
| 爱情双方的可互换性 | — | 爱情中追逐者和等待者的身份可以互换——一个故事中A追B，另一个故事中B等A。甚至同一个故事中角色在不同阶段切换角色 |
| 阻碍者 | xn/n/zn | xn(社会规则——门第/性别/制度)、n(家庭——「你不能和ta在一起」)、zn(信念冲突——「我们不合适是因为价值观不同」) |
| 诱惑者 | x/x并z | 第三者或欲望的诱惑。让角色面对「我要的是真爱还是欲望」(x)或「我要的是真爱还是面子」(x并z) |

## 冲突类型

- **外部冲突**：相爱的人 vs 阻碍他们在一起的力量（社会、家庭、命运）
- **内部冲突**：爱ta vs 放弃自我——「爱到失去自己还叫爱吗」
- **核心张力**：追逐(xz)与等待(nz)之间的时差——「我在追的时候你在等，我等到了你却不来了」

## 典型故事弧

```
相遇(xz触发) → 连接(nz/zn建立) → 考验(xz+nz持续) → 抉择(zn选择) → 结局(在一起或分离)
```
1. 相遇——命运式的临界接触(xz触发)
2. 关系建立——情感连接(nz建立)/意义赋予(zn——「这就是对的人」)
3. 关系受考验——外部阻碍(xn/n)或内部冲突(zn/x)
4. 关键抉择——「我要不要放弃/要不要坚持」
5. 结局——在一起（nz的等待得到回应）或分离（xz的追逐到达终点）

## 经典案例

| 作品 | 爱情类型 | 主题配置 | 独特点 |
|:----|:--------|:--------|:-------|
| **泰坦尼克号** | 跨越阶级 | 命运10·空间9·本体7 | Jack是xz(追逐自由+露丝)、Rose是nz(等待被爱)+空间型(从上层社会的壳中挣脱) |
| **星际穿越** | 跨时空 | 命运10·时间8·本体7 | Coop是xz(穿越临界点去拯救)、Murph是nz(等爸爸回来)。命运型的极致——跑的在天上，等的在地上 |
| **傲慢与偏见** | 误认与认识 | 命运8·空间9·本体8 | 达西和伊丽莎白之间的核心不是跑和等——是x并z(社会面具/傲慢与偏见)被拆穿后zn(真正的认识) |
| **你的名字** | 时空交错 | 命运10·时间9·本体6 | 泷和三叶既是xz(找对方)又是nz(等对方)。时间型的扭曲让命运型变成了跨时空的追逐与等待 |
| **爱在黎明破晓前** | 一夜情缘 | 命运9·空间7·本体7 | 纯粹的相遇——没有外部阻碍、没有身份冲突。「一夜」本身就是xz的临界状态——短暂所以浓烈 |

## 爱情故事的误判防线

- ⚠️ 爱情 ≠ 欲望(x)。x是占有和吞噬，爱情的核心是「不舍」(nz)和「奔赴」(xz)而不是「想要」
- ⚠️ 追求 ≠ xz。一个人追另一个人不一定是xz——如果追是因为「我觉得ta配得上我」(z/zn)而不是「我必须在边界上行动」
- ⚠️ 爱情故事的悲剧核心不在「没在一起」，而在「没在一起是因为命运(xz+nz结构被阻断)」还是「没在一起是因为选择(zn选择不在一起)」
- ⚠️ 出轨 ≠ 爱情故事的「反派」。出轨的本质是x并z(伪装)+x(欲望)混入nz(等待)——第三者的结构往往是空间型的（一个原本的nz等待者被x诱惑）
