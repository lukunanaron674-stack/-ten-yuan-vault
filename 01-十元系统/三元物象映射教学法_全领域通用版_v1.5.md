# 三元物象映射教学法｜全领域通用版 v2.0（原路径正文革新）

> **2026-07-16革新：三元不再作为十元的前置骨架，也不从x/n/z派生十元。先独立判断十元点位，再用三元比例解释该点位更关注具体物象、认可主体还是精神与整体关系。**

## 0. 总定义

**三元物象映射教学法｜全领域通用版**  
是一套先独立判断十元点位，再用x/n/z比例解释内部注意对象与质地，最后检查映射强度、关系位置、动态链和五大主题的通用教学方法。

一句话：

```text
先定分析对象与十元点位，再用三元比例解释质地；点位通过后查位置盘，最后才跑动态链与五大主题。
```

---

## 1. 最短口令版

```text
用「三元物象映射教学法｜全领域通用版」教我【概念/领域/作品/机制】：
先一句话定义；
先独立给十元Top-2并区分主、副、功能十元；
再用x/n/z说明已判点位内部更关注物、认可还是整体关系；
给物象比喻；
给点位映射强度 1-10；
给总体体量 1-10，并说明体量不是力量而是在场密度；
查位置盘生成生/被生/克/被克/补关系五对；
给每条边的映射强度；
组合关系对子；
跑动态链；
给动态链总强度；
最后归入五大主题，给归仓强度、误判检查和封存句。
```

## 2. 核心分层

| 层级 | 名称 | 回答什么 | 禁止混用 |
|---|---|---|---|
| 1 | 一句话定义 | 它是什么 | 不要先堆例子 |
| 2 | 十元点位 | 它以什么存在方式成立 | 不要用三元、视觉或结局反推 |
| 3 | 三元比例 | 已判点位更关注物、认可还是整体关系 | 只解释内部质地，不派生十元 |
| 4 | 物象比喻 | 它看起来像什么运动结构 | 不要只写抽象词 |
| 5 | 映射强度 | 这个映射有多硬 | 不要全写 9 分 |
| 6 | 体量 | 在场密度多大 | 体量不是力量 |
| 7 | 关系五对 | 按位置盘定边 | 不要凭感觉乱连 |
| 8 | 关系对子 | 多条关系五对的组合 | 不要把单边叫对子 |
| 9 | 动态链 | 力流如何跑 | 不要用结局倒推 |
| 10 | 五大主题 | 最后归入什么高阶结构 | 五大主题不是起手 |
| 11 | 误判检查 | 哪些地方容易错 | 不要省略 |
| 12 | 封存句 | 一句话压缩入库 | 不要散尾 |

## 3. 三元总骨架

| 三元 | 通用定义 | 通用问题 | 常见物象 |
|---|---|---|---|
| **x（醒）** | 具体物象、物质关系、归属、价值与局部因果 | 它具体是什么、归谁、值多少、怎样运作？ | 物件、账目、边界、门、刻度、工具 |
| **n（耐）** | 精神、整体与多方关系；理解、包容与协调 | 谁与谁处在什么关系中，整体如何相互作用？ | 关系网、群体、历史图景、多方会谈 |
| **z** | 精神个体需要认可主体看见、回应并确认自己 | 谁的认可使这个精神位置成立？ | 目光、回应、见证、舞台、署名、勋章 |

标准句式：

```text
x = 它具体关注什么物象、归属、价值和局部因果？
n = 它在理解、包容或协调哪些精神与整体关系？
z = 它需要哪个认可主体确认什么？
```

## 4. 物象化规则

物象不是装饰，而是帮助理解力流。

每个 x/n/z 都要尽量变成：

```text
能看见
能运动
能互相作用
能画出来
能转成角色、场景、机制或叙事
```

示例：

| 抽象词 | 物象化 |
|---|---|
| 压力 | 水压、铁门、坠石、深井 |
| 规则 | 铁轨、棋盘、网格、钟表 |
| 欲望 | 黑水、火苗、藤蔓、吞口 |
| 承载 | 桥、碗、房屋、骨架、仓库 |
| 显现 | 火光、旗帜、果实、回声、裂开的门 |

## 6. 映射强度

### 6.1 定义

**映射强度 = 某个内容映射到某个十元 / 关系 / 动态链 / 五大主题时，贴合得有多硬。**

它不是体量。

| 项目 | 回答什么 |
|---|---|
| **体量** | 这个东西在不在场、占不占空间、密度多大 |
| **映射强度** | 这个映射准不准、硬不硬、能不能入主链 |

一句话：

```text
体量看“存在密度”，映射强度看“对应准度”。
```

---

### 6.2 映射强度标尺

| 分数 | 含义 | 用法 |
|---:|---|---|
| **1-2** | 弱映射 | 只是擦边，不入主链 |
| **3-4** | 辅助映射 | 可作背景或旁证 |
| **5** | 中性映射 | 有关系，但不能定核心 |
| **6-7** | 可用映射 | 可进入分析，但要补证据 |
| **8-9** | 强映射 | 可作为主链节点 |
| **10** | 锚点映射 | 几乎就是标准样本 |

## 7. 体量

### 7.1 定义

**体量 = 在场密度 / 存在占位 / 场域压强。**

体量不是：

```text
力量
战斗力
能力强弱
道德高低
重要性绝对值
```

### 7.2 体量标尺

| 体量 | 含义 |
|---:|---|
| 1-2 | 几乎不可察，背景微弱存在 |
| 3-4 | 可感知，但不主导 |
| 5 | 标准存在值 |
| 6-7 | 明显存在，开始影响周围 |
| 8-9 | 场域级存在，能重塑环境 |
| 10 | 极限存在，本体即空间 / 系统围绕它运转 |

### 7.3 体量句式

```text
【概念】体量 = X / 10。
这不是力量，而是它在该领域中的在场密度、占位程度和重塑周围结构的能力。
```

## 8. 关系五对

### 8.1 定义

关系五对是十元位置盘中的基础边型。

```text
1. 生：A 生 B
2. 被生 / 承生：A 被 B 生
3. 克：A 克 B
4. 被克 / 受克：A 被 B 克
5. 补：A 补 B
```

简义：

```text
生 = 推出 / 生成 / 显影
被生 = 被推出 / 承生
克 = 压制 / 限制 / 截断 / 迫使转向
被克 = 被压制 / 被限制 / 受克
补 = 补厚 / 补全 / 结构加厚
```

---

### 8.2 标准位置盘 v0.1｜生对

```text
xz → zx → zn → n → xn → xz
nz → nx → x → x并z → z → nz
```

展开：

```text
xz 生 zx
zx 生 zn
zn 生 n
n 生 xn
xn 生 xz

nz 生 nx
nx 生 x
x 生 x并z
x并z 生 z
z 生 nz
```

---

### 8.3 标准位置盘 v0.1｜克对

```text
xz → zn → xn → zx → n → xz
nz → x → z → nx → x并z → nz
```

展开：

```text
xz 克 zn
zn 克 xn
xn 克 zx
zx 克 n
n 克 xz

nz 克 x
x 克 z
z 克 nx
nx 克 x并z
x并z 克 nz
```

---

### 8.4 标准位置盘 v0.1｜补对

当前可用补对：

```text
xz ↔ nz
zx ↔ nx
zn ↔ x
n ↔ x并z
```

待校准补对：

```text
xn ↔ z
```

处理规则：

```text
xn 补 z / z 补 xn 暂用待校准。
未再次确认前，不进入强动态链。
```

## 9. 边映射强度

每条关系边都必须给强度。

模板：

| 关系五对 | 标准位置 | 内容解释 | 映射强度 |
|---|---|---|---:|
| 生 | A 生 B |  |  |
| 克 | A 克 B |  |  |
| 补 | A 补 B |  |  |
| 被生 | A 被 B 生 |  |  |
| 被克 | A 被 B 克 |  |  |

判断原则：

```text
位置正确 ≠ 映射必强。
内容贴合度不足时，必须降强度。
```

## 10. 关系对子

### 10.1 定义

**关系对子 = 多个关系五对的组合方式。**

它不是单条边。

常见组合：

```text
生 + 生
生 + 克
克 + 克 + 生
补 + 生
生 + 生 + 克
```

## 11. 动态链

### 11.1 定义

**动态链 = 关系对子落到具体十元后跑出的力流结构。**

它回答：

```text
这个概念不是静态是什么，而是如何发生、如何转向、如何结算。
```

---

### 11.2 动态链模板

```text
起手十元：
第一被作用十元：
生成十元：
承载位：
承载位实际十元：
冲突位：
冲突位实际十元：
结算位：
结算位实际十元：
最终落点：
```

链条公式：

```text
起手 → 第一作用 → 生成 / 克制 / 补厚 → 承载 → 冲突 → 结算 → 落点
```

---

### 11.3 链条强度模板

| 段落 | 位置关系 | 内容解释 | 映射强度 |
|---|---|---|---:|
| A → B | 生 / 克 / 补 |  |  |
| B → C | 生 / 克 / 补 |  |  |
| C → D | 生 / 克 / 补 |  |  |

```text
动态链总强度 = 各段平均值 / 10
```

---

### 11.4 常见动态链结果

| 结果 | 含义 |
|---|---|
| 回收型 | 力量被承载后回到可持续结构 |
| 崩坏型 | 强度超过承载，链条断裂 |
| 扭曲型 | 原意义被改写，形成新稳定 |
| 循环型 | 问题不断回炉，持续生成 |
| 反噬型 | 结果倒打起手 |
| 停滞型 | 链条还能存在，但推进失灵 |
| 换芯型 | 外壳保留，核心更换 |
| 断链型 | 原有循环不再成立 |

## 12. 五大主题归仓

五大主题不是十元起手，而是高阶归仓。

| 五大主题 | 公式 | 核心问题 | 常见领域 |
|---|---|---|---|
| **时间** | xn + z | 变化、等待、阶段、错过、节拍、爆点 | 历史、成长、节奏、流程、学习 |
| **本体** | zn + x | 我是谁、靠什么活、核心如何被冲击 | 哲学、身份、心理、角色、AI主体 |
| **空间** | x并z + n | 能否进入、停留、承载、被组织 | 建筑、场景、组织、平台、社群 |
| **因果** | zx + nx | 选择如何触发，代价如何返回 | 叙事、游戏机制、策略、法律、商业 |
| **命运** | xz + nz | 相遇、错过、漂流、停靠、归宿 | 爱情、旅途、人生、关系、迁徙 |

## 15. 误判检查总表

| 误判 | 为什么错 | 修正 |
|---|---|---|
| 把五大主题当起手 | 五大主题是归仓，不是发动源 | 先定十元起手，再归仓 |
| 把体量当力量 | 体量是存在密度，不是战斗力 | 单独写体量定义 |
| 把映射强度当体量 | 映射强度是准度，不是占位 | 两栏分开 |
| 把语义边当位置边 | 内容感觉不等于位置盘关系 | 必须查表 |
| 把承载位默认写成 n | 承载位是功能位 | 实际十元另判 |
| 默认 zn 起手 | 意义可能是补位、被生、结算 | 看第一推动力 |
| 视觉强反推本体 | 外显不等于存在类型 | 视觉层和本体层分开 |
| 结局倒推动态链 | 结果不是起手证据 | 找第一状态改变 |
| 所有映射都写高分 | 会污染判断 | 必须区分 5、7、9 |
| 硬凑完整链 | 有些概念只适合半链 | 可标记“弱链 / 暂挂” |

## 16. 最终封存句

**三元物象映射教学法｜全领域通用版 = 用 x/n/z 定骨架，用物象让抽象可见，用十元定点，用映射强度校准硬度，用位置盘生成关系五对，用关系对子组合力流，用动态链观察变化，最后归入五大主题并封存。**
