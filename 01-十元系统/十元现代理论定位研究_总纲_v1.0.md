# 十元现代理论定位研究｜总纲 v1.0

> 研究主语：**十元**
>
> 论文不是研究对象，只是一个外部学术视角与验证入口。
>
> 本研究要回答的不是“论文怎么写”，而是：
>
> 1. 十元到底是什么？
> 2. 它与现代理论的关系是什么？
> 3. 在现代知识体系里，它最接近哪一类模型？
> 4. 应该用什么名字描述它最准确？
> 5. 它能否稳定完成跨对象映射？
> 6. 相比普通分类或通用语义表示，它有没有额外价值？

# 3｜现代位置｜当前最接近哪些理论

现阶段不能用一个现代术语硬套十元。

更准确分四层：

## A｜表示母类
### Conceptual Spaces
帮助理解：
> 对象如何进入一个结构化语义表示空间。

它和十元相似在：
- 不是简单单标签；
- 强调对象在结构中的位置；
- 可以讨论相似、边界、邻近。

但十元目前没有正式：
- metric；
- distance；
- 连续坐标；
- convex region。

所以不能直接说：
> 十元 = Conceptual Spaces。

---

## B｜映射形式邻居
### Semantic Differential

帮助理解：
> 同一个对象如何在若干固定相反端上形成一个多维 profile。

它和十元相似在：
- 固定端点；
- 多对象可共用同一套维度；
- 最后形成 profile。

但十元不是简单形容词量表。

当前更准确说：
> 十元有 **paired oppositional endpoints｜成对相反结构端点**，
> 但还不是严格意义上的连续双极量表。

---

## C｜可靠性方法
### Qualitative Coding / Codebook

帮助解决：
> 怎么证明映射不是我随便贴标签。

可借用：
- definition；
- inclusion / exclusion；
- nearest neighbor；
- positive / negative cases；
- intercoder agreement / reliability。

十元现有：
- 信息卡；
- 准度卡；
- 最近邻；
- 正反证；
- 拿掉 / 反向测试；

与这类方法非常接近。

---

## D｜机器形式化
### Ontology / OWL

以后可以帮助：
- 存储十元映射；
- 写成机器可读；
- 表达 class / property / relation；
- 交给 AI / Agent / rule engine。

但它主要负责：
> **保存与推理已经定义好的结构**

不负责证明：
> 某对象为什么应该映射成 ZX / NX / Z 等。

---

# 4｜当前最谨慎的现代名字

暂不叫：

- 完整 Conceptual Space；
- 严格 Bipolar Semantic Space；
- Ontology；
- Relation Graph；
- 普通 Taxonomy。

当前最安全：

> **Theory-defined Semantic Mapping Scheme with Paired Oppositional Endpoints**

中文：

> **一种由理论定义、包含成对相反结构端点的语义映射体系。**

再加它自己的后续结构：

> **+ Rule-governed Coding**
> **+ Post-mapping Relation System**

所以完整暂定描述：

> **十元是一套由理论定义的语义映射体系，使用成对相反的结构端点和规则化判定将不同对象映射到十元位置；端点成立以后，再进入生克补与动态链。**

这只是“当前现代定位”，不是最终定义。

---

# 5｜最核心的底层研究问题

## Q1｜Mapping Reliability

> **一套固定的十元结构映射，能否将不同创作对象稳定映射到可区分的语义位置？**

这里的“不同创作对象”可以包括：
- 人物；
- 场景；
- 关系；
- 组织；
- 概念；
- 音乐；
- 视觉结构。

“稳定”至少包含：
- 同一对象重复映射是否接近；
- 不同编码者是否接近；
- 最近邻端点是否可区分；
- 换对象域后核心定义是否保持。

这是当前最核心的底层问题。

---

# 6｜第二核心问题｜额外价值

> **十元映射，相比普通分类或通用语义表示，是否提供额外价值？**

这里必须说明：

## “通用语义 profile”是什么？

它**不是一个固定学术理论名字**。

它是实验里对“非十元、但已经结构化的普通语义表示”的简称。

大白话：

> 不用十元，也给同一个对象做一份结构化语义画像。

例如可以是：

```
对象 A

主动性：8
规则依赖：6
关系导向：4
开放性：3
可逆性：7
...
```

或者用某套固定双极维度：

```
主动 ↔ 被动
集中 ↔ 分散
开放 ↔ 封闭
稳定 ↔ 变化
...
```

最后得到一组数值 / 标签：

> 这就是一个 semantic profile｜语义画像 / 语义剖面。

它的作用只是当 **baseline｜对照组**：

```
普通分类
vs
普通结构化语义 profile
vs
十元映射
```

然后问：

> 十元到底多提供了什么？

---

# 7｜为什么“通用语义 profile”不能直接写进最终论文

因为它太泛。

未来真正做实验时必须操作化成一个具体 baseline，例如：

### Baseline A｜普通分类
- character trait categories
- scene categories
- intent categories

### Baseline B｜固定通用语义维度
例如明确冻结 5–10 个普通维度。

### Baseline C｜Semantic Differential-style profile
固定若干双极尺度。

然后才和：

### TEN｜十元
比较。

否则“通用语义 profile”只是研究阶段的占位词。

# 8｜当前保留的 4 个可实验问题

## A｜跨对象域结构不变性
Cross-domain Structural Invariance

同一个十元在：
- 人物；
- 场景；
- 关系；
- 音乐；

是否仍保持同一个核心结构。

---

## B｜相反端区分度
Pair-Core Discriminability

五组相反对子是否真的：
- 围绕同一个核心变量；
- 做相反方向操作；
- 能被稳定区分。

---

## C｜三元纠错增量
Three-Yuan Error-Detection Gain

比较：

```
只做十元映射
vs
十元映射 + 三元独立复核
```

看误判是否下降。

---

## D｜端点门控关系
Endpoint-Gated Relation Error Reduction

比较：

```
直接判关系
vs
先完成十元端点映射，再判生克补
```

看关系假阳性是否下降。

# 9｜验证顺序

十元最底层必须先按：

```
Gate 1
Mapping Reliability
映射稳不稳
↓
Gate 2
Discriminant Validity
十元之间分不分得开
↓
Gate 3
Mapping Utility
相比普通分类 / 普通 semantic profile 有没有增量
↓
Gate 4
Relation Utility

↓
Gate 5

最后测动态链
```

不能再倒着从动态链开始。

# 10｜研究和论文的关系

当前研究对象始终是：

> **十元。**

论文只提供三个好处：

1. 帮十元找到现代学术里的邻居；
2. 强迫十元把模糊概念变成可验证问题；
3. 借本科论文的小规模实验先打一个最核心的验证孔。

所以：

> **不是为了论文去改十元。**
>
> 而是借论文的方法，解决十元最核心的现代定位与有效性问题。

---

# 11｜当前最重要的两句话

### 现代位置
> 十元当前可暂时定位为：**一种由理论定义、具有成对相反结构端点、规则化编码与后置关系系统的语义映射体系。**

### 最核心问题
> **一套固定的十元结构映射，能否将不同创作对象稳定映射到可区分的语义位置？**

### 第二核心问题
> **这种映射相比普通分类或普通结构化语义 profile，是否具有稳定的额外信息或决策价值？**

这三句是当前十元现代理论定位研究的中心。
