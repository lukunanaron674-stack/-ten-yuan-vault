# R4｜感受模型研究路线重排

版本目标：TY-FEELING-1.4.0-R4

## 总研究问题
从“对象属于哪个十元”改为：

> 哪些可观察形式，在什么语境下，能较稳定地让人产生目标感受？这些感受之间如何组合、对立、转化，并能否被 AI 学会后用于创作控制？

## P0｜十种感受本体
优先补齐十元 L1 人类体验词。
- X / Z / N：已冻结为醒 / 张 / 耐。
- 其余七元：先做自由描述、相似感受聚类、反例和边界，不允许用旧结构变量直接命名。
- DONE：每元都有体验定义、近邻、反例、混淆边界。

## P1｜人类感受测量
研究“人能否稳定报告这些感受”。
- 自由描述优先，标签后置。
- 1–10 感受谱，而非单标签 Top1。
- 重复刺激检查个体内稳定性。
- 多观察者检查群体一致性。
- DONE：得到可靠性、混淆矩阵、不能稳定区分的感受对。

## P2｜诱发机制
旧五轴、视觉语法、角色/音乐/叙事训练全部转到这里。
- 控变量研究形状、边界、对比、节奏、关系、动作、声音、语境。
- 研究形式特征对感受谱的影响，而不是对象本体归类。
- DONE：得到可重复的“特征变化 → 感受变化”证据。

## P3｜审美关系
保留现有高价值研究，但全部以人的感受结果为终点：
- 同型统一：同类感受跨领域叠加是否提高 Unity / Fit。
- 关系对折：反端、生、克、补是否改变 Charm / Tension / Completeness。
- 动态链：克→生→再克→补等序列是否形成稳定节奏感。
- 强度谱：Top1 / Top3 / Full Profile 哪个更能预测人的评价。

## P4｜AI学习与生成
AI只做模型与执行层：
- 输入目标感受谱。
- 预测哪些形式可诱发该谱。
- 生成候选。
- 人复核。
- 用误差回训“形式—感受”关系。

成功标准不是“AI判断对了哪个十元”，而是“AI更稳定地产生目标人类感受”。

## P5｜来源与文化参照
五行、阴阳、传统理论和现代系统/关系理论保留为：
- 来源史
- 结构启发
- 比较框架

它们不得再承担“证明十元客观正确”的任务。

## 降级/暂停
- 五行本体 → 十元有效性的证明链：停止。
- is-a 狭义跨域同一：降为历史实验假设。
- 本征准度、对象配比：退出核心有效性指标。
- 自产自测高分：不得作为外部有效性。

## 新研究顺序
P0 十感受定义
→ P1 人类测量可靠性
→ P2 诱发机制
→ P3 审美关系
→ P4 AI创作控制
→ P5 来源/文化解释并行维护

R4 DONE 条件：研究优先级、成功标准、旧研究去向和新实验主线全部明确。
