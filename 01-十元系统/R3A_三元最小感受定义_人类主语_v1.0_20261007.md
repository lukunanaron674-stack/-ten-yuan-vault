# R3-A｜三元最小感受定义·人类主语 v1.0

## 0｜最高主语原则

> **感受的主语是人。**

AI、模型、脚本、分类器本身不被视为“正在感受”的主体。

因此十元/三元现行语言统一从：

```text
这个对象是 X / Z / N
```

改写为：

```text
这个对象 / 形式 / 关系 / 事件
→ 让人产生某种感受
→ 这份感受可被三元/十元描述
```

对象是刺激源；人是体验者；三元/十元是描述人的感受结构的语言。

## 1｜AI的角色

AI不承担“感受主体”角色。

AI能做的是：

1. 读取对象、形式、关系和语境；
2. 学习哪些可观察特征常与某类人的感受共同出现；
3. 把人的感受描述编码成可比较的结构；
4. 预测某种设计可能诱发怎样的感受；
5. 根据目标感受反向生成视觉、音乐、动作、镜头和叙事；
6. 比较“目标感受”与“真实人类反馈”之间的偏差并迭代。

所以：

> **AI负责理解、编码、预测和生成“人的感受条件”；人负责真正感受。**

禁止写：

> “AI感受到了ZX。”

应写：

> “AI根据已定义规则与人类反馈，预测该刺激可能激活较强ZX感受。”

## 2｜感受与生理机制的层级

人的感受可能伴随：

- 神经活动变化；
- 多巴胺等神经递质变化；
- 激素变化；
- 心率、唤醒、注意等身体反应。

这些可作为未来的生理证据层，但：

> **感受 ≠ 某一种神经递质 / 激素数值。**

现阶段三元/十元的核心对象仍是：

> **人能够直接报告、比较和区分的主观体验。**

如果未来接入生理数据，它的角色是帮助研究：

```text
刺激
→ 身体 / 神经反应
→ 主观体验
→ 三元 / 十元感受描述
```

而不是用单一生理指标取代人的感受本身。

## 3｜三元最早直接来源

三元最早来自视觉色彩关系中的直接人类感受：

```text
对比色 → 让人感到“醒目”
补色   → 让人感到“张扬”
临近色 → 让人感到“耐看”
```

因此三元的一级定义必须保持“让人如何感受”的句式。

暂冻结的最小感受核：

### X｜醒

> **X首先指一种让人“醒过来、被拉开差异、注意被抓住、边界变得清楚”的感受方向。**

“具体物象、切分、边界、明确因果、变量减少”等旧定义，降为常见诱发机制，不再作为X本体。

### Z｜张

> **Z首先指一种让人感到“张开、显出、凸显、向外释放、存在感被放大”的感受方向。**

“被看见、被认可、舞台、宣言、中心化”等旧定义，降为常见诱发情境与表现，不再作为Z本体。

### N｜耐

> **N首先指一种让人愿意停留、继续感受、关系之间能够相处、整体可以被持续容纳的感受方向。**

“精神、整体、多方关系、理解、包容、协调”等旧定义，降为常见诱发机制与表现，不再作为N本体。

## 4｜三层定义结构

从本版开始，每个三元/十元都必须拆成三层：

### L1｜感受核
人直接感受到什么。

### L2｜诱发机制
哪些结构、关系、形式、行为、声音或语境常容易诱发这种感受。

### L3｜领域表现
这种感受进入人物、发型、服装、音乐、镜头、剧情、场景后可能表现成什么。

任何L2/L3都不得反过来冒充L1。

例如：

```text
X感受核：醒、差异被拉开、注意被抓住、边界清楚
↓
诱发机制：高对比、切分、单一变量、明确边界
↓
领域表现：锐利轮廓、强节奏切分、明确所有权、清楚因果等
```

## 5｜人与AI的闭环

现行运行链冻结为：

```text
外部刺激 / 艺术形式
→ 人产生直接感受
→ 人给出语言/评分/选择反馈
→ 三元/十元描述感受结构
→ AI学习“形式—感受”关系
→ AI生成或调整形式
→ 再交给人感受
→ 反馈回流
```

这意味着：

> **AI不能成为十元正确性的最终裁判。**

最终校准源必须回到人的感受反馈。

## 6｜一句话冻结

> **三元/十元研究的不是“对象客观是什么”，而是“对象以何种形式作用于人，并让人产生什么感受”；AI不拥有这份感受，只负责学习、编码和操作“形式—人的感受”之间的可执行关系。**
