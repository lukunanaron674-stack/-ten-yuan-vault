# 三元十元语义融合总表

本页负责把 [[CODEX_三元知识语义理解表_v1]] 与 [[十元生补克表]] 融合成一个可执行的整理规则。

它不是新增理论，而是给 Codex / Obsidian 整理时使用的判读顺序：

```text
三元识别语义底座
→
十元判定结构类型
→
生补克检查关系运动
→
五大主题决定入仓位置
→
F12 / 银矿 / 归档轮次生成可复用结果
```

## 1. 两张表的分工

| 文件 | 负责什么 | 不负责什么 |
|---|---|---|
| [[CODEX_三元知识语义理解表_v1]] | 解释 x / z / n 的最小语义、十元字段、体量、顺序感、五大主题、银矿字段 | 不直接替作品下最终结论 |
| [[十元生补克表]] | 固定十元之间的生位、补位、克位、三母型路径 | 不从视觉、结局、名作光环倒推起手 |
| 本页 | 规定两者怎么一起使用 | 不新增作品、不重评作品、不改已有分数 |

## 2. 第一层：三元只做语义底座

三元只回答：文本里最小的语义母核是什么。

| 三元 | 整理时先看什么 | 禁止误用 |
|---|---|---|
| x | 欲望、压迫、吞没、占有、失控、恐惧、反噬源 | 不要见到危险就判 x 起手 |
| z | 显现、执念、光点、爆点、承诺、被看见 | 不要把 z 自动合并成 zn |
| n | 承载、稳定、容器、安顿、持续、关系容器 | 不要把所有承载位都写成 n |

结论：三元只提供底色，不直接决定银矿入仓。

## 3. 第二层：十元判结构

十元回答：作品、角色、关系、空间真正以什么结构运作。

| 十元 | 融合后的整理含义 | 常见整理用途 |
|---|---|---|
| zx | 主动行动、突破、开局、先动手 | 因果起局、主动推动 |
| x并z | 表象、包装、被观看、媒介化、伪装 | 空间外壳、身份接口、观看结构 |
| zn | 意义、信念、精神核心、价值归宿 | 本体意义层，不能默认起手 |
| z | 执念、光点、爆点、被看见 | 时间爆点、追索目标 |
| n | 稳定、承载、安顿、中心关系 | 空间承载，但不能默认所有容器都是 n |
| nz | 依恋、停靠、柔情、不想结束 | 命运里的停靠与关系余温 |
| xn | 规则、制度、时间秩序、流程 | 时间结构、规训结构 |
| nx | 隐性判断、暗流、结算、算计 | 因果暗线、解码、账本 |
| xz | 临界、漂流、危险边缘、命运不稳 | 命运起伏、风险轨道 |
| x | 欲望、占有、深层驱动、失控强度 | 本体欲望、反噬、崩坏源 |

结论：十元是结构标签，不能用五大主题或结局倒推。

## 4. 第三层：生补克判关系运动

当十元标签出现后，再进入 [[十元生补克表]] 检查关系：

| 检查项 | 要问的问题 |
|---|---|
| 生位 | 这个结构自然生出什么下一步？ |
| 补位 | 它缺什么才能完整？ |
| 克位 | 谁会压制、污染、反咬它？ |
| 桥接 | 没有直连时，是否存在中介关系？ |
| 污染 | 桥接是否改变了原来的结构性质？ |

整理时必须先判断：

```text
直连 / 桥接 / 污染桥
```

不能只因为两个词看起来相似，就强行连成动态链。

## 5. 第四层：五大主题只决定入仓

五大主题回答的是：这个结果最后进入哪个高阶仓。

| 五大主题 | 公式 | 入仓判断 |
|---|---|---|
| 时间 | xn+z | 规则、期限、等待、记忆、错过、爆点压缩 |
| 本体 | zn+x | 主体资格、身份、精神核心、欲望反噬 |
| 空间 | x并z+n | 容器、阶级、观看、包装空间、进入与停留 |
| 因果 | zx+nx | 行动、调查、旧账、暗线、结算失败 |
| 命运 | xz+nz | 漂流、相遇、停靠、失归、归属重判 |

注意：五大主题不是起手，不得反推十元。

## 6. 融合后的执行顺序

以后整理旧库、F12 轮次、银矿卡片时，按这个顺序走：

1. 先读原文已有字段，不新增作品。
2. 用三元识别最小语义底座。
3. 用十元判结构类型。
4. 查 [[十元生补克表]]，判断生位、补位、克位。
5. 判断动态链是否是推进、污染、反咬、克制、互补或桥接。
6. 再把结果放入五大主题仓。
7. 缺字段写“不确定”，放入待人工二审。

## 7. 银矿整理红线

- 不默认 zn 起手。
- 不默认 n 承载。
- 不用五大主题倒推十元。
- 不用结局倒推起手。
- 不用视觉风格反推本体。
- 不把体量理解成战斗力。
- 不把名作光环当入库理由。
- 不把“感觉很像”当十元关系证据。
- 85 分以下不得进入正式银矿。
- Codex 只管文件整理、字段提取、索引生成、缺失标记；理论判断交给人工二审。
