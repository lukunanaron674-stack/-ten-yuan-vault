# 三元十元语义融合总表

本页负责把 [[CODEX_三元知识语义理解表_v1]] 与 [[十元生补克表]] 融合成一个可执行的整理规则。

它不是新增理论，而是给 Codex / Obsidian 整理时使用的判读顺序：

```text
十元独立判定点位
→
三元比例解释内部质地
→
生补克检查关系运动
→
五大主题决定入仓位置
→
F12 / 银矿 / 归档轮次生成可复用结果
```

## 1. 两张表的分工

| 文件 | 负责什么 | 不负责什么 |
|---|---|---|
| [[CODEX_三元知识语义理解表_v1]] | 解释 x / z / n 的最小语义、十元字段、体量、顺序感、五大主题、银矿字段 | 不直接替作品下最终结论 |
| [[十元生补克表]] | 固定十元之间的生位、补位、克位、三母型路径 | 不从视觉、结局、名作光环倒推起手 |
| 本页 | 规定两者怎么一起使用 | 不新增作品、不重评作品、不改已有分数 |

## 2. 三元只做比例与质地解释

三元不再作为十元的前置底座，也不负责派生十元。先独立判断十元位置，再用三元说明该位置内部注意力落在物、认可还是整体关系。

| 三元 | 整理时先看什么 | 禁止误用 |
|---|---|---|
| x（醒） | 具体物象、物质关系、归属、价值、局部因果 | 人物x可显得自私狭隘，但不能把道德评价外推给场景与物件 |
| z | 精神个体是否被认可主体看见、回应与确认 | 舞台、追光、显现必须回到认可结构 |
| n（耐） | 精神、整体与多方关系；理解、包容、协调 | 不得把区域越大写成n越高级，也不得把n写成天然服从整体 |

结论：三元只解释已判十元的内部比例和质地，不缩小候选、不派生十元，也不直接决定银矿入仓。

## 3. 第二层：十元判结构

十元回答：作品、角色、关系、空间真正以什么结构运作。

| 十元 | 融合后的整理含义 | 常见整理用途 |
|---|---|---|
| zx | 主动行动、突破、开局、先动手 | 因果起局、主动推动 |
| x并z | 表象、包装、被观看、媒介化、伪装 | 空间外壳、身份接口、观看结构 |
| zn | 意义、信念、精神核心、价值归宿 | 本体意义层，不能默认起手 |
| z | 执念、光点、爆点、被看见 | 时间爆点、追索目标 |
| n | 稳定、承载、安顿、中心关系 | 空间承载，但不能默认所有容器都是 n |
| nz | 依恋、停靠、柔情、不想结束 | 命运里的停靠与关系余温 |
| xn | 暗中观察、隐蔽判断、算计、计划、记录、积累、等待节点与结算；可稳定为规则、阶级和制度高墙 | 判断结构、时间节点、账本、家族阶级、规训结构 |
| nx | 不主动占据选择、方向和位置，顺着已有关系、流程、群体或现状继续 | 被动延续、选择外包、既有方向中的跟随位置 |
| xz | 临界、漂流、危险边缘、命运不稳 | 命运起伏、风险轨道 |
| x | 欲望、占有、深层驱动、失控强度 | 本体欲望、反噬、崩坏源 |

结论：十元是结构标签，不能用五大主题或结局倒推。

## 4. 第三层：生补克判关系运动

当十元标签出现后，再进入 [[十元生补克表]] 检查关系：

| 检查项 | 要问的问题 |
|---|---|
| 生位 | 这个结构自然生出什么下一步？ |
| 补位 | 它缺什么才能完整？ |
| 克位 | 谁会压制、污染、反咬它？ |
| 桥接 | 没有直连时，是否存在中介关系？ |
| 污染 | 桥接是否改变了原来的结构性质？ |

整理时必须先判断：

```text
直连 / 桥接 / 污染桥
```

不能只因为两个词看起来相似，就强行连成动态链。

## 5. 第四层：五大主题只决定入仓

五大主题回答的是：这个结果最后进入哪个高阶仓。

| 五大主题 | 公式 | 入仓判断 |
|---|---|---|
| 时间 | xn+z | 规则、期限、等待、记忆、错过、爆点压缩 |
| 本体 | zn+x | 主体资格、身份、精神核心、欲望反噬 |
| 空间 | x并z+n | 容器、阶级、观看、包装空间、进入与停留 |
| 因果 | zx+nx | 公式暂保留；旧“nx=旧账、暗线、结算”解释作废，内容显影待二审 |
| 命运 | xz+nz | 漂流、相遇、停靠、失归、归属重判 |

注意：五大主题不是起手，不得反推十元。

## 6. 融合后的执行顺序

以后整理旧库、F12 轮次、银矿卡片时，按这个顺序走：

1. **先读原文已有字段**，不新增作品。
2. **第零层：灵魂像素预判** — 不急于套标签，先问灵魂问题：
   - **「他为什么做这个？」而不是「他做了什么？」**
   - 驱动ta活着的底层能量是什么？是光、是意义、是欲望、是规则、还是完成本身？
   - 这个角色去掉所有行为之后，还剩什么？
   - 判断方法见 [[十元灵魂判断法]]
3. **独立判断十元点位**，区分主十元、副十元与功能十元。
4. **用三元比例解释内部质地**，不得反推或派生十元。
5. **查 [[十元生补克表]]**，判断生位、补位、克位。
6. **判断动态链**是否是推进、污染、反咬、克制、互补或桥接。
7. **再把结果放入五大主题仓**。
8. **缺字段写"不确定"**，放入待人工二审。

## 7. 银矿整理红线

- 不默认 zn 起手。
- 不默认 n 承载。
- 不用五大主题倒推十元。
- 不用结局倒推起手。
- 不用视觉风格反推本体。
- 不把体量理解成战斗力。
- 不把名作光环当入库理由。
- 不把“感觉很像”当十元关系证据。
- 85 分以下不得进入正式银矿。
- Codex 只管文件整理、字段提取、索引生成、缺失标记；理论判断交给人工二审。
