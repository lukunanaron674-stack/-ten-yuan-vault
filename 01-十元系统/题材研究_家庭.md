# 题材分析：家庭

## 题材定义

家庭 = 空间型题材（x并z+n）—— 家庭既是 **n（承载/日常/归属）**，也是 **x并z（面具/角色扮演/「应该」的壳）**。家庭故事的本质不是「家和万事兴」，是 **「在同一个屋檐下，每个人都在承载别人也在被承载」**。

## 激活的主题及强度

| 主题 | 激活强度 | 说明 |
|:----|:-------:|:------|
| **空间型** x并z+n | **10** | 家庭是空间型最核心的题材化。家庭本身就是一个空间/外壳（x并z）——人在家庭里扮演角色（好儿子/好妻子/好父亲），同时家庭也是承载这些人的容器（n）。「回家过年」就是最典型的x并z（进入家庭角色）→n（被家庭承载）的切换。家庭冲突的本质就是「壳破了」或「装不下去了」 |
| **本体型** zn+x | **8** | 家庭是最激烈的本体追问场所——「我是谁」在家庭里被反复拷问。zn（意义追问）：我为什么是这家的人？我应该承担什么？x（欲望驱动）：我想逃离、我想要被爱、我想证明自己。伯德小姐的「我想去东海岸」就是x在对抗zn的「你是这个家庭的女儿」 |
| **命运型** xz+nz | **6** | 家庭是命运型的天然土壤——出身无法选择（xz），却要背负一生（nz）。「我成了我妈那样的人」是命运型在家庭中的典型回响。但命运型不是家庭的核心——家庭的故事更多是有选择的纠缠，而不是被命运支配 |
| **因果型** zx+nx | **4** | 家庭里也有因果——付出与回报、父母的错误在孩子身上重现。但家庭冲突不是「清算账目」的逻辑（那是复仇），而是「算不清的账」。因果型在家庭里是局部工具，不是整体框架 |
| **时间型** xn+z | **3** | 家庭与时间有关——成长、衰老、代际。但时间型更多是背景（孩子长大需要时间），不是家庭故事的驱动力 |

## 人物配置

| 角色类型 | 十元 | 说明 |
|:--------|:----:|:------|
| **故事主体（家庭本身）** | x并z+n | 家庭是空间——既是角色们扮演的家庭面具（x并z），也是承载他们的场所（n）。一个好的家庭题材故事，「家庭」本身是主角 |
| **承载者（母亲/父亲原型）** | n（主）+zn | 在家庭中承担承载功能的人——维持日常、照顾、包容。n是家庭的底色。加zn则变成「我该这样做但我快撑不住了」——承载者的尊严与崩溃 |
| **面具者（角色扮演）** | x并z | 在家庭中扮演「应该」的角色——好媳妇、孝顺儿子、成功人士。特征：在外人面前维持完美家庭，关起门来崩溃。x并z的张力在于「演不下去的时刻」 |
| **渴望者（孩子/逃离者）** | x（主）+zn | 想逃离、想突破、想做自己。x驱动：「我想要不一样的生活」。zn则变成「但他们是我的家人」的矛盾。伯德小姐就是x+zn的完美呈现 |
| **修复者（可选）** | zx | 试图修复家庭关系的人。zx的「执行」指向的是修补裂缝。但家庭不是机器——zx在家庭里常常失败，因为家庭不是可以被「修好」的系统 |
| **壳外人（闯入者）** | nz | 新成员（结婚、继父继母）或长期缺席者突然回归。nz等待/适应的张力——壳外人要找到在家庭空间中的位置 |

## 冲突类型

- **外部冲突**：家庭 vs 家庭（两个家庭的冲突）、家庭 vs 社会（经济压力/社会期待）、家庭 vs 空间本身（房子要塌了/要搬家）
- **内部冲突**：面具 vs 本心（x并z vs zn）、逃离 vs 愧疚（x vs n）、不同角色之间的期待错位
- **核心张力**：**n（承载/归属） vs x并z（面具/束缚）**——「我属于这个家（n），但我不想像这样活着（x并z）」

## 典型故事弧

```
日常(n) → 裂缝(壳破了) → 角色暴露(x并z崩塌) → 冲突/逃离(x) → 重新选择(zn) → 新的承载方式(n重构)
```

1. **日常呈现**（n建立——家庭如何运作、谁承担什么角色）
2. **裂缝出现**（壳出现裂痕——某个事件让面具戴不住了，或者外部压力打破日常）
3. **角色崩塌**（x并z瓦解——「好妻子」「好父亲」的身份被质疑或自我放弃）
4. **冲突或逃离**（x爆发——争吵、离家出走、断绝关系）
5. **重新选择**（zn追问——「我还要不要这个家？我能不回家吗？家对我意味着什么？」）
6. **新的承载**（n重构——家庭以新的方式重组，或者确认分离）

## 经典案例

| 作品 | 家庭类型 | 主题配置 | 独特点 |
|:----|:--------|:--------|:-------|
| **东京物语** | 传统家庭瓦解 | 空间10·本体8·命运6 | x并z+n的极致——父母去东京看望子女，子女的「孝」是面具（x并z），家散了但还要维持表面（n的脆弱）。尾声中母亲的沉默是全片最重的n——她承载了一切但不说话 |
| **小偷家族** | 非血缘家庭 | 空间10·本体9·命运5 | 揭示了家庭最本质的东西——n（承载）可以脱离血缘。这个家庭是先有n（互相承载），后有了x并z（假装是一家人去偷东西）。当法律说「这不是家」，观众会质疑「什么是家」 |
| **伯德小姐** | 母女角力 | 本体9·空间8·x7 | 女儿x（想逃离/想被认可）vs 母亲n（承载/控制/疲惫）。最终女儿发现「我想去的地方就是家」——这是zn对x的收束。母女在试衣间的争吵是x并z崩塌的经典场景 |
| **海街日记** | 姐妹日常 | n9·空间8·zn6 | 是枝裕和用日常(n)讲述家庭——吃饭、洗衣服、樱花、梅子酒。没有什么大事件，但每个人都在被姐妹们承载(n)。姐姐说「不要紧，我们家有的是姐妹」——这是n最温柔的显形 |
| **人生密密缝** | 跨性别家人 | 空间9·本体9·x8 | 当「家」的空间遇到「性别」的定义冲突——小友的舅舅凛子（跨性别女性）如何在这个家中找到自己的位置。织毛衣（108个毛线丁丁）是n的仪式化——通过重复的日常动作确认归属。最终三人一起吃饭就是新家庭的n重构 |
| **八月：奥色治郡** | 有毒家庭 | 空间10·x9·本体8 | 家庭的x并z被撕碎到最血腥的程度——母亲、三个女儿、各自的秘密在家庭聚餐中全部爆炸。每个人都在扮演「好家人」，但没有人真的想承载别人。台词「真相——真相就是一大家子人住在同一栋房子里互相看不顺眼，但还要吃同一顿饭」——这是x并z+n最残酷的注脚 |

## 家庭故事的误判防线

- ⚠️ 不是所有「有家人的故事」都是家庭题材——如果核心是个人冒险（比如主角离开家庭去闯荡），那是成长题材，家庭只是背景。家庭题材要求 **「家庭本身」是冲突的战场和意义的来源**
- ⚠️ 家庭题材不一定有亲情——小偷家族里是陌生人，人生密密缝里是舅舅和外甥女。关键是 **n（互相承载）是否成立**
- ⚠️ 「家庭美满」不是故事——家庭题材需要冲突、裂缝、或至少是「面具的疲劳」。完全和谐的家庭没有戏剧张力
- ⚠️ 家庭中的「离别」不是命运型（nz等待）而是空间型——离开家是退出x并z，不是被命运推开。区别在于：角色是否在主动选择「要不要这个家」
- ⚠️ 家庭题材中的「原谅」不是xn（规则/秩序修复）——家庭的裂痕不是规则能修复的，而是n（承载的重新建立）。原谅是「我选择继续承载你」
