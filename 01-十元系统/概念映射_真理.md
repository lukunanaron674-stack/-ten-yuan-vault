# 概念映射：真理（2026-06-08 建立）

## 1. 一句话定义

**真理 = 被赋予本体地位的规则**——不是规则本身（xn），不是信仰本身（zn），而是"这条规则之所以为规则，是因为它符合某种更高层次的真实"。真理介于zn（信仰/意义本体）和xn（规则/秩序）之间——它通过xn形成规范，通过zx被追寻，通过n被承载。

---

## 2. 三元粗拆（x/z/n）

| 轴 | 真理在该轴上的表达 | 说明 |
|:--|:----------------|:-----|
| **x** | 真理的表述形式、命题结构、被检验的表象 | 真理需要被说出来、写下来、验证——x提供检验场和命题外壳 |
| **z** | 对真理的追寻冲动、求真意志、为真理牺牲 | 真理是"追的东西"——z驱动人走向真理，甚至为之献身 |
| **n** | 真理的承载面、前提假设、被相信而不被质疑的基础 | 真理需要被"接住"才有效——n提供了承载真理的场域（如公理系统、文化土壤） |

**三元定位特征**：真理的本质矛盾在于——它既是zn（意义本体：这就是对的），又是xn（规则结构：这就是规则），同时通过zx被追寻执行。真理的三个面——"是什么"（zn→xn）、"怎么确认"（xn→zx→nx）、"在哪里"（n）——构成了它的完整结构。

## 4. 体量1-10

**真理的体系体量：9**

真理是一个超级概念——它触及十元体系的核心区域（zn→xn→zx→n），涵盖"意义本体+规则执行+承载"三大面。真理不是某个十元的专属概念，而是横跨多个十元的枢纽概念。其体量略低于"哲学"（9.5），因为真理是哲学的子系统（哲学 包含 真理 作为下辖概念），但真理性高于权力（7.5）/时间（8.2）的体量。

## 10. 动态链

### 主链（正向生成链）—— zn → xn → zx → nx

```
zn(10) → 生 → xn(9) → 生 → zx(8) → 克 → nx(6)
  │                     │                     │
  │  意义不需要验证     │  规则引导追寻       │  追寻被结算限制
  │  这就是对的         │  规则说去哪里找     │  验证确认或推翻
  └── 真理的源头 ──────┴── 真理的通道 ──────┴── 真理的闭环
```

**真理的主链**：意义本体(zn)外化为规则(xn)，规则引导追寻/执行(zx)，追寻的结果被结算(nx)确认——这是真理从"内在确信"到"被验证的公共知识"的完整生成路径。

### 克链（压制/反抗链）—— xn 克 zx + zx 克 n

```
xn(9) ─克→ zx(8) ─克→ n(7)
  │              │
  │  规则压制     │  追寻打破承载
  │  "真理已经    │  "新发现颠覆
  │   被定义了"   │   旧认知土壤"
```

**真理的克链**：规则(xn)压制过度追寻(zx)，确保真理不沦为疯狂的追逐；但同时，追寻(zx)会打破承载面(n)——新真理颠覆旧常识。这是真理的"范式革命"结构——从xn→zx→n的压制，到n被zx打破，再到新的xn建立。

### 补链（互济链）—— zx ↔ nx + zn ↔ x

```
zx(8) ↔ nx(6)        zn(10) ↔ x(2)
  │       │             │       │
  │ 追寻与  │           │ 意义与  │
  │ 结算互济│           │ 私占互济│
  └── 动态验证 ┘         └── 张力平衡 ┘
```

**真理的补链**：zx与nx的互济构成"追寻-验证"循环——没有结算的追寻是盲目的，没有追寻的结算是空洞的。zn与x的互济（但x极弱）——信仰偶尔需要被"私占"的冲动激活，但这种互补极弱。

## 12. 主题归入

| 主题 | 公式 | 真理的映射 | 归仓判断 |
|:----|:----|:----------|:--------|
| **时间** | xn+z | xn(9) + z(5) = 14 | **次归。** 真理有时间性——规则会变，真理的认知有时代性。xn引导z追逐真理，构成时间维度的真理动态 |
| **本体** | zn+x | zn(10) + x(2) = 12 | **主归。** 真理最核心的是本体问题——"什么是真/什么是存在的本质"。zn锚定真理的意义本体，x只提供私占的弱映射 |
| **空间** | x并z+n | x并z(2) + n(7) = 9 | 弱。真理有承载空间——文化土壤(n)是真理的家，但x并z边缘 |
| **因果** | zx+nx | zx(8) + nx(6) = 14 | **次归。** 真理有因果结构——追寻(zx)产生结果，结算(nx)确认因果。真理的操作层在因果主题 |
| **命运** | xz+nz | xz(4) + nz(3) = 7 | 弱。真理在压迫中显现(xz)、在坚守中固化(nz)——但只是边缘映射 |

**主归主题判定**：
- **本体(zn+x) = 12分**——但x只有2分，zn被极度拉低
- **时间(xn+z) = 14分**——xn(9)+z(5)=14，分布更均匀
- **因果(zx+nx) = 14分**——zx(8)+nx(6)=14，同样均匀

实际上真理最核心的领土在**zn(10) + xn(9)**——这两个十元不属于同一个主题公式（zn在本体、xn在时间）。这是真理的特殊性：它跨越两个主题。

**综合判定：真理 = 本体为主(zn锚定)，时间为辅(xn规则化)，因果为操作层(zx→nx验证)**

| **规则** (xn) | 真理的表述形式——但不是真理本身 | 规则可以纯工具性（\"红灯停\"是规则但不是真理），真理的规则有本体地位 |
| **正义** (xn+zx+nx) | 真理在伦理领域的应用 | 真理是"什么是真的"，正义是"什么是对的"——正义以真理为认知前提 |
| **哲学** (x+zn+xn) | 探索真理的学科 | 真理是哲学的认知论核心，但哲学还包含本体论、美学、伦理等 |
| **科学** (xn+nx+zx) | 探索真理的方法论 | 科学不宣称掌握了"终极真理"——科学是xn→nx→zx的验证循环，真理是zn→xn的本体化 |
