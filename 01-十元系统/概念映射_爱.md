# 15步模板分析：「爱」——完整映射强度分析

## 1. 一句话定义

爱 = 跨十元的情绪力场——在不同十元中表现为不同的"连接模式"。没有唯一的十元归属，但有一个分布规律：**爱的本质不是某种情绪，是人与人之间张力最大的连接方式**。

---

## 2. 三元粗拆（x/z/n）

| 三元 | 内容 |
|:----|:----|
| **x = 形式/压力面** | 爱的表达形式、爱的表演、爱的欲望面、爱的外壳 |
| **z = 能量/驱力面** | 爱的冲动、爱的追求、爱的不顾一切、爱的目标化 |
| **n = 载体/承载面** | 爱的日常承载、爱的不离开、爱的结构性支撑 |

---

---

## 4. 体量 1-10

**体量：9**

爱是人类经验的终极主题之一。但它不是底层情绪（欲望/恐惧/死亡才是底层），而是这些底层力场的**高阶组合形态**。因此体量给9（低于欲望的9.5和死亡的10，高于语言/真理的8）。

| **z** | **6** | 爱的冲动追逐——追求期的z心爆棚 |

## 10. 跑动态链

### 主链（爱的正向生成）
```
zn(8) → 生 → n(7.5) → 补 → nz(9)
```
- 意义生出承载，承载与柔情互补
- 链长：2条边
- 链强度：(8+7.5+9+7+8.5)/5 = **8.0**

### 克链（爱的压制/变形）
```
nz(9) → 克 → x(6.5) → 生 → x并z(7) → 生 → z(6)
```
- nz的柔情压倒欲望>欲望生出表演>表演生出冲动
- 链强度：(9+7.5+6.5+6+7+6)/6 = **7.0**

### 补链（爱的互补循环）
```
nz(9) ↔ xz(5) ↔ n(7.5)
```
- 柔情与临界互补，临界需要承载
- 链强度：(9+8.5+5+5+7.5)/5 = **7.0**

### 总动态强度
(8.0 + 7.0 + 7.0) / 3 = **7.3**

---

## 11. 动态链总强度

**7.3**——中上等。爱不是体系中最强的力（低于欲望7.9、死亡8.5），但它跨越的十元最多（8个十元有映射）。

---

## 14. 误判检查

1. ❌ **爱 = nz** — 错。nz是最强单点但爱覆盖8个十元，不能缩减到单点
2. ❌ **爱 = x** — 错。欲望占有是爱的一部分但不是全部，弄反了比例
3. ❌ **爱只有正面** — 错。爱有x（占有）、x并z（表演）、xz（逃离）等暗面
4. ❌ **爱是情绪** — 不全是。爱是跨十元的力场，情绪（x）只是其中一维
5. ❌ **亲情/母爱 = n** — 不完全。母爱可以有n的承载、nz的不舍、zn的意义灌注
