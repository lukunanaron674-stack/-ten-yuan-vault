# 十元信息卡正本总览 v1.0

> 信息卡回答“它是什么”；准度卡回答“为什么这个对象必须判成它”；生卡、克卡、补卡回答“两个已成立端点之间究竟发生了什么”。三层不得互相代替。

## 1. 固定读取顺序

```text
先分对象层：稳定本体 / 当前状态 / 行为功能 / 场景 / 光影 / 时间关系 / 关系位置 / 显影 / 动态链
→ 读对应十元信息卡，确认端点是什么
→ 读准度卡，排除最近邻与视觉皮肤
→ 只有两个端点都成立，才进入生卡 / 克卡 / 补卡
→ 关系机制是否可调用，以十元生补克表和关系专项正本索引为最终准绳
```

## 5. 版本与旧卡纪律

1. 文件名版本和正文版本不一致时，以本页“当前读取目标”与文件 frontmatter 为准。
2. `redirect-only`、`legacy-evidence`、`core-partial` 不得覆盖 `canonical-current`。
3. 旧卡中的人物、视觉、空间与关键词可作证据召回，但不得反向定义十元。
4. 信息卡不得自行锁定生克补；关系卡不得改写十元本体。
5. 几何位置锁定不等于机制锁定。关系是否正式可调用，必须再查 [[十元生补克表]] 与 [[关系专项/README_十元关系专项正本索引]]。

## 6. 最短召回

```text
信息卡：它是什么。
准度卡：为什么必须判成它。
生卡：A怎样使B出现或上升。
克卡：A怎样使B的核心变量下降。
补卡：A与B各自存在时，怎样补足彼此缺口。
动态链：这些变化在时间中把感觉推向哪里；不是机械生成器。
```
