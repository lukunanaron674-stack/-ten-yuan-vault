# 桌面端续跑清单｜视觉化研发

## 一句话任务

> 不再重讲五轴理论；继续把十元／五轴／动态链压成可画、可生成、可审核的视觉结构，并让每张图都有实验卡和审核结论。

## 启动后第一轮

优先跑：**图像审核器 R1.5 → NX 样本组**。

约束：

```text
同角色
同场景
同画风
3 张单图
只改结构
禁止颜色、武器、表情、UI、题材标签作弊
```

输出：

```text
1 张目标正样本
1 张最近邻对照样本
1 张非目标负样本
```

每张图都写：

```text
sample_id
prompt
只改了什么结构变量
为什么判中/判不中
是否依赖视觉捷径
最近邻误判对象
PASS / FAIL / AMBIGUOUS
下一步修正
```

## 第二轮

**ZN 跨对象测试**，不要继续只拿少女测试。

顺序：

1. 建筑
2. 机器
3. 植物群
4. 城市
5. 房间
6. 组织

每个对象至少做：

```text
ZN 正样本
最近邻十元对照
结构去除后的负样本
```

目的：判断 ZN 的规则是否跨对象成立，而不是依赖“自然、温柔、少女感”。

## 第三轮

**十元生克补最小对照集**。

每轮只做一种关系：

```text
生：A 的结构变化生成 B 成立条件
克：A 压缩/否决 B 的合法状态空间
补：A 补足 B 缺失但不替代 B 本体
```

必须有“仅共存但未发生关系”的负样本。

## 第四轮

**动态链视觉化**。

不要再证明链条理论，直接画：

```text
起始状态
触发条件
中段变化
路径关闭/打开
终点
```

优先验证：
- 单帧是否能读出当前阶段。
- 连续 3 帧是否能读出方向和端点变化。
- 去掉文字后是否仍成立。

## 第五轮

**十元风格语法跨题材回归**。

X 已冻结：

```text
独立形体单元
清晰边界
单元自足
彼此不融合
留有间隔
```

只验证，不重写。

后续十元也按“结构语法 → 跨题材 → 对照 → 冻结”的流程推进。

## 每轮固定产物

桌面端不要只留下提示词。每一轮至少有：

```text
01_prompt.md
02_sample_manifest.yaml
03_audit.md
04_failure_log.md
```

图片文件名与 sample_id 对齐。

建议目录：

```text
├─ 01-图像审核器/

```

## 停止条件

某个视觉规则达到以下条件即可暂时冻结：

```text
跨至少 3 种题材仍成立
最近邻十元可区分
去掉颜色/符号/表情捷径仍成立
审核器能稳定给出结构证据
出现失败时能归入明确 failure family
```

若只是“看起来像”，不算冻结。

## 当前禁止事项

- 不要继续无限加抽象定义。
- 不要把 10 个测试画成一张十宫格。
- 不要因为一张漂亮图就宣布十元规则成立。
- 不要用黑红、王冠、武器、科技感、少女感替代结构。
- 不要把五维主题反向当十元本体。
- 不要重新做已经封版的五轴 V1.0，除非出现真实 failure。
