# 桌面端续跑清单｜视觉化研发

## 默认模式｜低图耗 ON

先读取：`01-十元系统/06-视觉化研发/低图耗视觉化研发协议_v1.0_20260916.md`

桌面端默认不再“想到一个规则就直接大量正式生图”，统一改成：

```text
L0 Visual DSL / 结构推演
↓
L1 草图代理 / 本地低成本粗图
↓
L2 少量结构样本
↓
L3 关键三样本正式验证
```

正式高成本生图默认只做：

```text
A 正样本
B 最近邻对照
C 非目标负样本
```

只有三样本仍然 AMBIGUOUS 或出现真实 failure 才扩到 6 张。

## 一句话任务

> 不再重讲五轴理论；继续把十元／五轴／动态链压成可画、可生成、可审核的视觉结构，并让每张图都有实验卡和审核结论。

## 启动后第一轮

优先跑：**图像审核器 R1.5 → NX 样本组**。

先做 L0：

```text
写 NX Visual DSL
指定唯一 changed_variable
指定最近邻混淆对象
明确正证据 / 负证据
明确禁止捷径
```

L0 成立后，再跑：

```text
同角色
同场景
同画风
3 张单图
只改结构
禁止颜色、武器、表情、UI、题材标签作弊
```

输出：

```text
1 张目标正样本
1 张最近邻对照样本
1 张非目标负样本
```

每张图都写：

```text
sample_id
prompt
只改了什么结构变量
为什么判中/判不中
是否依赖视觉捷径
最近邻误判对象
PASS / FAIL / AMBIGUOUS
下一步修正
```

## 第二轮

**ZN 跨对象测试**，不要继续只拿少女测试。

顺序：

1. 建筑
2. 机器
3. 植物群
4. 城市
5. 房间
6. 组织

先一次性完成六类对象的 DSL，不急着六类都正式生图。

每类优先低成本验证：

```text
ZN 正结构
最近邻结构
```

只有进入 L3 后才生成正式对照样本。

目的：判断 ZN 的规则是否跨对象成立，而不是依赖“自然、温柔、少女感”。

## 第三轮

**十元生克补最小对照集**。

每轮只做一种关系：

```text
生：A 的结构变化生成 B 成立条件
克：A 压缩/否决 B 的合法状态空间
补：A 补足 B 缺失但不替代 B 本体
```

必须有“仅共存但未发生关系”的负样本。

优先在 L0/L1 证明关系结构真的可区分，再进入正式图像验证。

## 第四轮

**动态链视觉化**。

不要再证明链条理论，先用结构草图 / storyboard 表达：

```text
起始状态
触发条件
中段变化
路径关闭/打开
终点
```

低成本验证通过后，再生成关键阶段图。

优先验证：
- 单帧是否能读出当前阶段。
- 连续 3 帧是否能读出方向和端点变化。
- 去掉文字后是否仍成立。

## 第五轮

**十元风格语法跨题材回归**。

X 已冻结：

```text
独立形体单元
清晰边界
单元自足
彼此不融合
留有间隔
```

只验证，不重写。

冻结后的十元风格默认只做低频回归，不持续烧正式图额度。

后续十元也按：

```text
结构语法
→ 低成本跨题材
→ 最近邻对照
→ 关键三样本
→ 冻结
```

推进。

## 正式生图闸门

只有同时满足：

```yaml
dsl_complete: true
changed_variable_isolated: true
nearest_confusion_named: true
forbidden_shortcuts_defined: true
positive_evidence_defined: true
negative_evidence_defined: true
cheap_test_passed: true
```

才允许进入 L3 正式生图。

否则：

```text
BLOCK_L3
→ 继续结构推演 / 草图 / 本地粗图
```

## 停止条件

某个视觉规则达到以下条件即可暂时冻结：

```text
跨至少 3 种题材仍成立
最近邻十元可区分
去掉颜色/符号/表情捷径仍成立
审核器能稳定给出结构证据
出现失败时能归入明确 failure family
```

若只是“看起来像”，不算冻结。

## 当前禁止事项

- 不要继续无限加抽象定义。
- 不要把 10 个测试画成一张十宫格。
- 不要因为一张漂亮图就宣布十元规则成立。
- 不要用黑红、王冠、武器、科技感、少女感替代结构。
- 不要把五维主题反向当十元本体。
- 不要重新做已经封版的五轴 V1.0，除非出现真实 failure。
- 不要把正式生图当成第一步。
- 不要在 DSL 尚不完整时用额度碰运气。
