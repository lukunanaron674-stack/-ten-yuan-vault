# 视觉化总收束 R0

> 本轮不以“继续找新理论”为目标，而是把已经完成的大量深度研究、聊天实验、项目实战与图像审核经验压成一套可执行、可审核、可冻结的视觉规则库。

## 0｜阶段切换

旧模式：

```text
发现问题
→ 深度研究
→ 生图
→ 再研究
→ 再生图
```

R0 模式：

```text
已有深研材料
→ 归并
→ 去重
→ 冲突标记
→ 十元标准卡
→ 最近邻对照
→ 少量关键图验证
→ 冻结 / 定点重开
```

原则：

1. 默认不再新增无边界 Deep Research。
2. 新资料只能用于解决明确冲突、空缺或 failure family。
3. 生图不再负责“发现定义”，只负责验证已写清的规则。
4. 十元视觉卡不得覆盖十元/五轴 canonical；发现冲突只登记 failure。
5. 角色、建筑、机器、城市等对象只作为跨对象压力测试，不得反向定义十元。

## 2｜当前成熟度矩阵

> 这是“视觉规则收束成熟度”，不是十元本体成熟度。

| 十元 | 当前状态 | R0动作 |
|---|---|---|
| X | **frozen** | 只做低频跨题材回归；核心语法不再重写 |
| Z | consolidation | 汇总已有控制/裁定/中心化相关视觉研究，建立最近邻对照 |
| N | consolidation | 汇总承载、纳入、背景/容器相关研究，清除“厚重= N”的捷径 |
| ZN | **candidate_frozen** | 重点完成建筑/机器/植物群/城市/房间/组织跨对象回归 |
| NZ | consolidation | 与 XZ、ZN、N 做最近邻拆分，明确保存/恢复/对象特异回返的可见结构 |
| XN | consolidation | 把规则节点、流程、分布运行权转成可视结构，防止“秩序感= XN” |
| NX | consolidation-priority | 当前优先做严格三样本，建立稳定最近邻边界 |
| ZX | consolidation | 从“强势/中心人物”退回方向生成、作用权来源与结构占位 |
| XZ | **candidate_frozen** | 已清除黑手/恐怖/黑红等捷径，继续验证路径收窄、临界、不可逆结构 |
| X并Z | consolidation | 汇总内→外映射/外化结构，避免“爆炸/扩散= X并Z”的表面化 |

## 3｜X 已冻结基线

```text
独立形体单元
+ 清晰边界
+ 单元自足
+ 彼此不融合
+ 留有间隔
```

X 不等于：

```text
几何
机能
冷酷
黑白
尖角
科技感
```

R0 中 X 只作为“冻结样板”，用于规定其他九张卡该达到什么完成度。

## 4｜XZ 已知收束方向

已明确禁止：

```text
黑手
怪物
血
恐怖表情
黑红配色
单纯危险感
```

现阶段保留的核心验证方向：

```text
可用路径持续收窄
临界位置显性化
未来端点逐步唯一化
可逆性下降
对象处于边界/切线/阈值结构中
```

R0 任务：把这些方向与 Z / NZ 的最近邻差分写成标准卡，并只做关键对照图。

## 6｜审核器在 R0 的职责

图像审核器不是“评审好不好看”，而是回答：

```yaml
structure_visible: 目标结构是否直接可见
shortcut_dependency: 是否靠题材捷径
nearest_neighbor_separable: 与最近邻是否可区分
changed_variable_visible: 本轮唯一变量是否真正显影
relation_real: 若有生克补，关系是否真的发生
confidence: 0-1
failure_family: 失败归因
```

每张标准卡至少需要：

```text
1 正样本
1 最近邻
1 负样本
```

仅当三样本仍 AMBIGUOUS，才扩样本。

## 7｜深研材料处理规则

过去的深度研究不丢弃，统一分为四类：

```text
A 可直接进入 canonical visual card
B 有价值但属于对象/题材层例子
C 与其他结论冲突，进入 conflict log
D 已被后续实验否定，保留历史但不继续使用
```

禁止把“出现频率高”直接当成“底层语法”。

## 8｜R0 执行顺序

```text
R0.1 X：冻结样板复核
R0.2 XZ：候选冻结
R0.3 ZN：跨对象候选冻结
R0.4 NX：严格三样本
R0.5 ZX：去人格化/去强势化收束
R0.6 XN：流程节点可视化
R0.7 NZ：回返/保存/恢复可视化
R0.8 N：承载/纳入结构可视化
R0.9 Z：裁定/中心化结构可视化
R0.10 X并Z：内→外映射结构可视化
R0.11 十元最近邻矩阵
R0.12 总冻结审查
```

这 12 个步骤不是 12 轮大规模生图；多数工作是材料归并和规则写卡。

## 9｜停止继续深研的条件

某十元达到：

```yaml
core_variables_stable: true
nearest_neighbor_separable: true
shortcut_removed: true
cross_object_or_cross_topic_passed: true
audit_repeatable: true
```

则：

```text
FROZEN
→ 停止主动深研
→ 只接受 failure-driven reopen
```

---

## 10｜何时允许重新 Deep Research

只有：

1. 两份已有研究发生无法消解的核心冲突。
2. 最近邻三样本反复无法区分。
3. 跨对象测试系统性失败。
4. 审核器形成新的稳定 failure family。
5. 真实项目出现现有语法无法解释的视觉结构。

否则：

```text
NO_NEW_DEEP_RESEARCH
```

↓
