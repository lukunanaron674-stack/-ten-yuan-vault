# 十元角色设计 Style Grammar｜研究总整理｜2026-09-16

> 本文件收束当前聊天框关于“十元角色设计风格语法”的研究。目标不是性格、职业、颜色、题材或符号映射，而是寻找每个十元在角色设计中的底层造型语法，并把它压成可画、可删、可做单变量实验、可跨风格复现的结构规则。

## 0｜研究定位

研究主链：

```text
十元抽象定义
↓
角色造型关系
↓
最小可画结构
↓
排除视觉捷径
↓
A/B 单变量验证
↓
跨部位
↓
跨风格
↓
冻结 Style Grammar
↓
接入图像审核器
```

真正的 Style Grammar 必须通过四关：

```text
能画
↓
能删
↓
能单变量改变
↓
换风格仍成立
```

禁止把下列内容直接当十元本体：
- 性格、职业、情绪
- 颜色
- 王冠、武器、怪物、科技 UI 等题材符号
- 单纯不对称、斜线、重复、包围、中心构图、负空间
- “看起来危险 / 温柔 / 王者 / 高冷”之类气质判断

当前策略已经从“大量找图”切换为：

```text
20% 定向找图复核
+
80% 关键控变量验证 / 审核
```

找图只保留三个用途：
1. 找反例和假阳性；
2. 做跨风格 / 跨题材外部泛化复核；
3. 解决具体混淆边界。

原则：
> 找图 = 外部普适性验证；生图 = 关键因果验证。

## 2｜已正式冻结

### X｜FROZEN

冻结定义：

> 独立形体单元 + 清晰边界 + 单元自足 + 彼此不融合 + 留有间隔。

最短语法：

```text
独立自足
```

X 不等于：几何、机能、冷酷、黑白、尖角、科技题材。

### Z｜FROZEN

冻结定义：

> 一个已建立的主方向，在明确结构节点发生方向迁移，并由至少两个后续、彼此不同的结构层级继续继承新的方向。

最短语法：

```text
建立方向
→ 转向
→ 跨结构继承
```

Z 不等于：不对称、斜线、尖角、破碎、动态姿势、飘带、重复 V、方向杂乱。

删除测试：删除转向节点后，Z 可读性应显著下降。

## 4｜N｜双向互为条件

当前假设：

> 两个保持独立、可分离身份的形体，在邻接界面形成互为条件的结构响应；任意一方改变，另一方对应局部的结构理由也会失效。

最短结构：

```text
A ⇄ B
```

关键不是“有关系”，而是“互为成立条件”。

假阳性 / 捷径：
- 同形重复
- 同色
- 对称
- 共同朝向
- 连接线
- 共同外框
- motif 重复

与 X：
- X：A、B 各自完整，不互相需要。
- N：A、B 保持独立，但局部关系互相需要。

与 XN：
- N：规则来自双方。
- XN：双方共同服从第三套规则。

最小 A/B：

```text
A：单向接口 A → B
B：双向接口 A ⇄ B
```

删除测试：删除任意一方后，另一方应留下明显“无结构理由”的局部接口。

阶段结论：部分通过；当前对象应停在 N，先做 A/B，不因文字完整自动进入 ZN。

---

## 5｜ZN｜关系规则改写

当前假设：

> 一个已经成立的关系规则，在明确迁移节点后被另一种关系规则取代，并由后续结构继续采用新规则。

最短结构：

```text
α → β → β
```

与 N：
- N：α / α / α，同一关系反复成立。
- ZN：α / β / β，关系规则发生状态改写。

与 Z：
- Z 改方向规则。
- ZN 改形体之间的关系规则。

视觉捷径：
- 多层服装
- 斜裁
- 不对称
- 普通 rhythm
- “看起来有变化”

最小 A/B：

```text
A：α → α → α
B：α → β → β
```

---

## 6｜NZ｜终端嵌合

早期“关系停靠”过于宽泛，容易退化为普通包围 / closure / common region，因此修正为：

> 一个开放关系，通过具有余量的接纳接口，形成明确的终端嵌合，使关系在此处结束而不再继续传播。

最短结构：

```text
开放
↓
接纳
↓
终端
```

必要条件：
- 明确终端性
- 有余量
- 不是单纯外框包围

与 XZ：
- NZ：有余量，可以稳定落入。
- XZ：余量极低，处于临界越界。

A/B：

```text
A：关系保持开放
B：只增加终端接纳接口
```

删除测试：打开终端接口后，NZ 应显著下降。

---

## 7｜XN｜异质单元规则槽位化

当前假设：

> 多个彼此不同的独立单元，被同一套外部结构规则约束到共同槽位系统中。

最短结构：

```text
异质单元
↓
共同规则
↓
固定槽位
```

关键不是整齐或重复，而是异质单元共同服从不可见规则。

捷径：
- 网格背景
- 制服
- 同形复制
- 机械队列
- 冷脸 / 黑白 / 直线

A/B：

```text
A：异质单元自由排列
B：相同单元进入共同槽位规则
```

删除测试：任意单元偏离半个槽位，整体秩序应明显被破坏。

当前状态：强冻结候选，仍需 R5 图证。

---

## 8｜NX｜缺席组织位

早期“让位留痕”包含行为过程，单帧无法证明“让位”，因此修正为：

> 一个组织位本身缺席，但周围结构仍然被这个缺席位置约束。

最短结构：

```text
B [∅] C
```

关键：缺席本身仍然参与组织。

NX 不等于：
- 黑影
- 隐身
- 小人物
- 藏起来
- 低饱和
- 普通负空间

A/B：

```text
A：普通任意空隙
B：被周边轮廓共同塑造的必要缺席位
```

删除测试：改变一条周边边界后，缺席模块应无法再被稳定补全。

---

## 9｜ZX｜非对称组织锚点

早期“单源触发重排”暗含动态因果，静态图不易证明，因此修正为：

> 一个局部结构成为非对称组织锚点，使多个其他结构的合理组织依赖于它。

最短结构：

```text
    B
    ↑
C ← A → D
```

核心不是“视觉中心”，而是约束传播：

> 改掉 A 的接口、位置或朝向规则后，B/C/D 的合理组织也必须随之改变。

ZX 不等于：
- 王冠
- 王座
- 中央构图
- 大体量
- 红黑
- 武器
- 强势表情
- 普通视觉层级

A/B：

```text
A：A 显眼，但 B/C 不依赖 A
B：A 外观不变，只让 B/C 的组织真正依赖 A
```

删除测试：切断 B/C 对 A 的结构依赖后，ZX 应显著下降。

当前状态：优先验证对象之一。

---

## 10｜XZ｜低余量临界耦合

当前假设：

> 多个独立结构的关键接口处于低余量、低容错的临界耦合状态。

最短结构：

```text
A | | B
C | | D
```

关键不是接触，而是只需非常小的结构变化就会越界；最好至少两个接口同时进入临界。

XZ 不等于：
- 红黑
- 尖刺
- 血
- 黑手
- 怪物
- 爆炸
- 危险姿势
- 恐怖表情

A/B：

```text
A：接口有安全余量
B：只缩小 ≥2 个关键接口余量到临界
```

删除测试：恢复接口余量后，XZ 可读性应显著下降。

当前状态：强冻结候选，待 R5 图证。

---

## 11｜X并Z｜上位包络双重读取

当前假设：

> 一个上位包络建立第二层整体读取，同时内部独立单元仍保持自治与可辨认。

最短结构：

```text
[ A B C ]
  A B C
```

第一层读取：外层是一个整体。
第二层读取：内部仍然是多个独立单元。

X并Z 不等于：
- 透明玻璃
- 罩子
- 外套
- 科技 UI
- 包装盒
- 普通 layering
- 单纯 common region

与 X：
- X：只有内部多个独立单元。
- X并Z：内部独立 + 外部整体同时成立。

A/B：

```text
A：内部单元裸露独立
B：内部完全不动，只增加中性上位包络
```

删除测试：删除包络后，第二层整体读取应消失。

## 16｜当前研发主循环

当前不再把“继续大量找图研究”作为默认任务。

默认主循环：

```text
候选语法
↓
最小 A/B
↓
删除测试
↓
审核
↓
失败 → 修定义
通过 → 跨部位
↓
跨风格定向找图复核
↓
冻结
```

只有以下情况重新扩大找图：
- 出现新反例；
- 最近邻仍不可分；
- A/B 结果无法解释；
- 跨风格系统性失败；
- 真实项目出现现有语法无法解释的结构。

否则不要继续用更多参考图给错误理论“续命”。
