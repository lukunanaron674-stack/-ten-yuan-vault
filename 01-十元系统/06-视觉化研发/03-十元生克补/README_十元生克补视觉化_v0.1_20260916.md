# 十元生克补视觉化｜冻结工作台 v0.1

> 本目录只负责把已经确定的十元“生 / 克 / 补”关系转译成可见、可生成、可审核的视觉结构。关系表只读；视觉实验只能发现 failure，不能反写理论正本。

## 0｜唯一正本

关系定义与当前锁定机制以：

`01-十元系统/十元生补克表.md`

为唯一直接正本。

本目录中的所有“视觉机制句”均属于 `visual-working-hypothesis`，只有通过图像回归后才能冻结为视觉规则，不能升级为十元理论定义。

## 1｜冻结关系表

### 生

```text
xz → zx → zn → n → xn → xz
nz → nx → x → x并z → z → nz
```

### 克

```text
xz → zn → xn → zx → n → xz
nz → x → z → nx → x并z → nz
```

### 补

```text
xz ↔ nz
zx ↔ nx
zn ↔ x
n ↔ x并z
xn ↔ z
```

## 2｜三种关系的视觉硬判据

### 生

> A 按照自身结构运行，使 B 获得成立条件。

最低视觉证据：

```text
A 可识别
→ A 的运行可识别
→ 出现可追踪结构变化
→ B 获得新的成立条件
→ B 真正成立
```

审核追问：`没有 A，B 是否仍会以同样方式成立？`
若会，则“生”关系可疑。

### 克

> A 的介入使 B 不能继续按原方式运行。

最低视觉证据：

```text
B 原本运行趋势可识别
→ A 介入
→ B 的边界 / 路径 / 占位 / 连接 / 完整度 / 运行能力发生改变
→ B 原方式受限、失效或被迫改向
```

审核追问：`A 具体改变了 B 的哪个运行条件？`
说不出来，则多半只是强弱或气氛。

### 补

> B 存在明确缺口，A 进入后提高完整度、稳定度或运行能力，但不替代 B。

最低视觉证据：

```text
B 的不足可识别
→ A 对应缺口进入
→ A 不替代 B
→ AB 的完整度 / 稳定度 / 运行能力提高
```

审核追问：`A 进入以前，B 到底缺了什么？`
说不出来，则多半只是并置、对称或和谐。

## 3｜六个一级视觉变量

所有关系优先检查：

1. boundary｜边界
2. path｜路径
3. occupancy｜占位
4. connectivity｜连接
5. integrity｜完整度
6. operability｜运行能力

颜色、材质、冷热、尖圆、角色表情、职业和题材只能作为二级信息。

## 4｜去作弊规则

### 生不能只靠
- 发芽 / 生孩子 / 蛋孵化
- 一个球掉出另一个球
- 单纯变大
- 魔法粒子 / 光效

### 克不能只靠
- 大压小
- 黑色 / 红色
- 尖刺 / 武器 / 血 / 爆炸
- 恐怖或愤怒表情

### 补不能只靠
- 拼图形状
- 对称
- 和谐配色
- 金色裂缝
- 两个对象刚好贴合

统一原则：`气氛像 ≠ 关系成立`。

## 5｜本地实验层级

每条关系只按以下三层推进：

```text
T1 纯结构
↓
T2 中性物体（建筑件 / 机械件 / 几何空间）
↓
T3 项目载体（角色 / 服装 / 场景 / 镜头）
```

本地默认先跑 T1；T1 FAIL 不进入 T2/T3。

## 6｜视觉机制工作假说

> 以下仅用于生成第一批可证伪图，不是 canonical。

### 生 10 条

| 关系 | visual-working-hypothesis |
|---|---|
| xz→zx | 临界积累达到阈值后，作用方向从多可能收束为明确公开作用 |
| zx→zn | 明确作用持续留下可保持痕迹，逐渐沉淀成稳定结构 |
| zn→n | 已成立结构继续沉积，形成可接收、承载、维持其它对象的内部 |
| n→xn | 持续承载与反复运行形成可重复的时间、规则与组织结构 |
| xn→xz | 规则识别偏差并持续处理，使安全路线与时间窗收窄，临界风险上升 |
| nz→nx | 稳定依附关系内部产生沿既有关系/流程推进的让位与借力通道 |
| nx→x | 持续不占据决定权的推进最终在某一处形成明确掌握边界或独立占位 |
| x→x并z | 已成立掌握边界生成可被外部识别、调用或保护的公开壳 |
| x并z→z | 稳定公开壳提供明确识别与归因接口，使认可焦点成立 |
| z→nz | 明确认可节点反复稳定后形成可停靠、可回返的关系依附 |

### 克 10 条

| 关系 | visual-working-hypothesis |
|---|---|
| xz克zn | 临界风险/失稳迫使原有意义或稳定结构无法按原方式维持 |
| zn克xn | 内部意义方向对既有规则、时间组织与持续运行结构形成否决/改写压力 |
| xn克zx | 已运行的规则、流程和时间结构限制即时显权扩张 |
| zx克n | 公开权能直接改变接收边界或成员资格，使承载连续性下降 |
| n克xz | 有效承载吸收/隔离风险，使危险可到达性和继续移动紧迫度下降 |
| nz克x | 稳定依附与归宿关系限制纯掌握边界的独占或单向处分空间 |
| x克z | 掌握认可入口、署名或传播通道，使确认无法发生或被错误归因 |
| z克nx | 明确认可/指认使原本可沿关系暗流推进的借力路径失去隐蔽空间 |
| nx克x并z | 沿既有通道与关系的内部借力/让位使公开壳的统一边界被内部改写 |
| x并z克nz | 公开壳与空间边界重新划分，使原有依附、停靠或回返关系被切断 |

### 补 5 组

| 关系 | visual-working-hypothesis |
|---|---|
| xz↔nz | 风险路径补入真正失去/错过窗口；归宿关系补入回返对象与终点 |
| zx↔nx | 直接显权做成 ↔ 通过既有身份、关系、权限与通道借力做成 |
| zn↔x | 内部意义方向 ↔ 具体掌握对象、资源与边界落点 |
| n↔x并z | 真实可承载内部 ↔ 可识别、可进入、可持续指认的公共界面 |
| xn↔z | 跨时间可复核的组织证据 ↔ 明确认可位置、筛选标准与阶段收束节点 |

## 7｜失败族

统一记录：

```text
FP-COEXIST      仅共存，关系未发生
FP-TOPIC        靠题材常识命中
FP-COLOR        靠配色命中
FP-SCALE        靠大压小命中
FP-EMOTION      靠表情/情绪命中
FP-FX           靠爆炸/黑气/光效命中
FP-SYMMETRY     把对称误判为补
FP-GROWTH       把长大/分裂误判为生
FP-VIOLENCE     把攻击/危险误判为克
FN-RELATION     十元端点成立，但关系读不出
FN-SOURCE       source 十元未成立
FN-TARGET       target 十元未成立
```
