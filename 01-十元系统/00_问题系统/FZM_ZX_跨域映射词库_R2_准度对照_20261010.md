# 《方志敏》｜ZX第二轮映射再发散与准度复核

## 0. 这轮回答什么
- **恢复旧映射全品类**：职业、人物身份、抽象名词、实体名词、事件名词、动词、社会现象、关系位置、场景，而不只是“愤怒的近义词”或动词。
- **准度判断对象**：词/职业在给定故事时段、功能、对象尺度下与ZX结构是否贴切。不是“ZX让人感觉很愤怒吗”；不是AI给观众情绪打分。
- **数据主权**：作者校准优先；本次仅做竞争十元和反例检测，**未抽检4:17成片的真实逐镜证据，也没有产生0–100实测准度。**
- **原规则**：ZX=主体自身权能**公开显现并扩张**→他者/秩序被迫回应→自身决定范围/作用位置或凌驾程度**确实上升**；强烈战斗、命令、公开辱骂、本来就握有权限而照章执行，单独都不够。见[ZX准度卡](https://github.com/lukunanaron674-stack/-ten-yuan-vault/blob/main/01-%E5%8D%81%E5%85%83%E7%B3%BB%E7%BB%9F/03-%E5%8D%81%E5%85%83%E5%87%86%E5%BA%A6%E5%8D%A1/zx_%E5%87%86%E5%BA%A6%E5%8D%A1_v0.1.md)。
- **关系门**：ZX克N要额外证明ZX公开权能实际取消/压停N原有**接收、保护、互信、反复返回或运行**能力，而不只是背景压迫或内心悲伤。见[专项关系审计](https://github.com/lukunanaron674-stack/-ten-yuan-vault/blob/main/01-%E5%8D%81%E5%85%83%E7%B3%BB%E7%BB%9F/%E5%85%B3%E7%B3%BB%E4%B8%93%E9%A1%B9/zx%E5%85%8Bn_%E5%85%AC%E5%BC%80%E6%9D%83%E8%83%BD%E5%87%BB%E7%A9%BF%E6%89%BF%E8%BD%BD%E6%9C%BA%E5%88%B6%E5%AE%A1%E8%AE%A1_20260718.md)。

## 2. 《方志敏》里的结构关系：两套不同检验
**A｜ZX端点候选**：具体主体是谁？此前拥有什么权能？是否公开扩权？哪些对象因此改变行动？新的实际影响位置是否上升？
**B｜ZX克N关系候选**：N是否已具持续保护/照顾/接纳能力？谁的公开决定直接让N成员资格、互信、照顾或运行下降？除掉这项强制后N是否仍能运行？
**F｜感受轨**：观众/作者因此可能感到压迫、愤慨、揪心、悲壮或不屈；这些是**候选结果**，不证明S端点成立。

### 可执行《方志敏》提取样本（剧情/理论案例≠成片已核验）
- **山林围剿**：候选社会事件“围剿”。真实故事任务卡含“可算摆脱围剿了”和迷失战士情节；先核成片有没有这个镜头/台词。即便有围剿，也须确认“谁改写了现场决定位置”；不能凭战争镜头直接判ZX克N。
- **监狱狱友互助**：旧关系专题写过**剧本假设**：狱友已递水、互助，管理者公开逼其相互否认并迫使照料停止，若在成片确有此事件，才是高质量ZX克N CASE。若仅拍了“铁门/光影/审讯/囚禁”，要分别看X/XN/XZ及感受层，不锁ZX克N。
- **方志敏人物自身**：他的坚定或反抗可能触发ZX样态，但不能只凭英雄身份锁人物本体；如果关系事实是他维护狱友承载N，需另分析ZN/N/其他对象的作用，不要把所有英雄美德塞进ZX。

## 3. 比上一轮准度提高在哪里？
### 前版问题（来自本次聊天的误判）
1. **“攻击、强烈、做事”就归ZX**，职业错把外科医生/记者/审讯官等吸进。
2. **“职业变动词”**，审讯官=审讯、记者=曝光，偷换对象。
3. **“名词=作恶”**，镣铐/军令/监狱天然贴ZX。
4. **“恐惧/悲壮/愤慨=ZX本体”**，情绪直接代替结构。
5. **“战争破坏亲情=ZX克N”**，未检查N原有运行能力以及公开权能对其机制性压停。

### 本版改正（本轮可自检的方法改进，不是映射准确率数字）
1. 明确准度卡4个成立条件、排除普通战斗及既有权限。
2. 所有词按职业/角色/抽象名词/实物/事件/动词/现象/场景/关系分类。
3. 对竞争端明确列出 X/XN/XZ/Z/ZN/NX 等，不在ZX内部寻找支持例。
4. 将ZX端点与ZX克N关系分开，并用实际承载变量检验。
5. 情绪和创作目标交给感受轨，旧准度与感受强度不得互换。
6. 六职业校准样本不再被统一误贴ZX——这是**符合USER已给判断**，还不是外部准确率。

**本轮判断：规则一致性和可解释性较前版明显改善；客观准度是否提升，仍需USER逐词审定 + 同尺度正反例审核，当前不能计算或报告提升百分比。**

## 5. 给674-303和674-301的使用规则
- **674-303是来源与镜头索引工单，不作为主观情绪自评分中心**：基于真实逐镜资产回填候选词，不凭该表推断作品实际上表现了什么；JX原义仍待源材料检索，不擅自扩写。
- 将与镜头对应的映射候选另建**只读** `FZM_ZX_MAPPING_CASES.csv` 或 MD，关联`FZM_SHOT_LIST.csv`，优先记录至少1组ZX成立候选与1组ZX伪阳性；来源不足保留空格。
- **674-301只消费有原始来源的案例**，分别标当时意图、今日事后解释、创作者感受、观众实际反馈；不能因现有理论更细就说当时必然如此创作。
- 两套知识的作用按任务决定：查职业词→结构轨S主；决定目标感受→感受轨F主；复盘镜头→两轨并行。
