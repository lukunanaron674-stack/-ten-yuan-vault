## 1｜谁是主、谁是次？谁帮助谁？

**分清两种主次：**
- **创作目的/最终验收**：目标感受为**主**；结构映射和生克补关系是**服务目标的分析与创作工具**。不因结构映射分高就宣称感受达成。
- **十元知识判定/工作先后**：结构判据及跨领域映射为**先**，并作为解释名词、职业、角色与关系的基础；感受诱发和作品评价为**后续上层**，不得拿感受词直接覆盖结构判定。
- **反馈**：人实际感受到什么，可以回头调整“哪些结构更能诱发目标感受”的**应用策略**，但不凭一次艺术效果把十元定义任意改掉。
- **总式**：旧映射知识帮助新感受构成具象化；新感受目标给旧映射规定创作方向；人的体验帮助检验作品，不替代结构判据。

## 2｜不是单条直线，而是上下层 + 正反两个回路

```text
                   作者的自由感受意图  ← 创作目的（最高）
                             │
               轮盘提取目标十元/感受候选
                             │
                    选对象、领域、镜头任务
                             ↓
 ┌────────────────────────────────────────────┐
 │ 下层｜映射 / 关系知识基础  [必须恢复可调用] │
 │ 同尺度对象身份/具体行为/社会机制分别建模     │
 │ 全十元候选比较 → 本体判据 → 最近邻/反例      │
 │ 主次/配比/准度(候选)/体量，分字段记录         │
 │ A端点本身 ≠ B对象关系的整体表达              │
 └─────────────────────┬──────────────────────┘
                       ↓
            生克补 / 动态链 / 多单元约束
                       ↓
 ┌────────────────────────────────────────────┐
 │ 上层｜感受构成 / 创作表达 / 人的体验评价      │
 │ 角色·场景·构图·光影·镜头·声音·动作 → 成片     │
 │ 作者复盘 / 可得时人的报告 → 感受修正          │
 └─────────────────────┬──────────────────────┘
                       │
                   仅反馈应用策略
              （不得无证据改写十元本体）
```

**识别链**：对象/语境→结构映射→关系→可能感受。
**创作链**：目标感受→选映射与关系→给视听元素约束→作品→人复盘。
