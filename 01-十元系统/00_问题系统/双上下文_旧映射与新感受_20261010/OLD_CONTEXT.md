# A｜旧体系独立上下文｜结构 / 跨领域映射

> 独立读取包：用于恢复被降权的**知识与判定能力**，不是要求恢复所有旧本体断言。不得从新版感受定义倒推旧规则。

## 1. 起源与功能（原有上下文）
色彩关系体验（补色张扬、邻近色耐看、对比色醒目）→三元→引入五行的五类关系骨架→十元、生克补与关系结构→十类映射方向→跨领域人物/职业/角色/物件/名词/行为/社会现象/场景/叙事/音乐→五组相反对子→动态链/主次/体量/五维。
* 十元：X、Z、N、ZN、NZ、XN、NX、ZX、XZ、X并Z。
* 五轴：ZX↔NX；ZN↔X；N↔X并Z；XN↔Z；XZ↔NZ。
* 五维：因果 ZX+NX；本体 ZN+X；空间 X并Z+N；时间 XN+Z；命运 XZ+NZ；五维是叙事问题域，不自动当十元属性。
* 生/克/补各自具方向、作用变量、条件；五轴相反不等于克/补。

## 2. 原有判定知识与字段
1. **对象/尺度/语境**：明确当前分析的是职业身份、人物行为、事件关系、物件结构还是整体故事；不能动词偷换名词。
2. **十元本体结构判据**：比较的是结构机制，不是词面联想（“主动做事”不等于ZX）。
3. **全十元横向对照**：主/次/弱候选；邻近竞争元、反例、反向/删除检验；灰区允许不判。
4. **配比度** `ten_yuan_composition_ratio`：旧版规定十项合计100，代表对象内结构分量；**不是**感受强度。
5. **本征映射准度** `ten_yuan_archetype_accuracy`：旧版按某元原型相似度独立0–100，可与其他元对照；**不是**对象成分百分比、证据置信度或人类感受评分。旧种子分数可能未经复核，不得视为真值。
6. **类型、体量、纯度、证据置信度**分别存，不合并。
7. **对象端点 L1 与关系整体 L2**分别判断：材料不一定是ZX，但对象间的关系可能表达ZX；禁止从L2反推L1。
8. 旧 `is-a狭义`、五行父项100%继承、唯一五行分库**有历史记录**，但其普遍正确性尚未成立，须隔离为假设/旧协议，不可自动重启。

## 3. 用户提出的人工纠错锚点（2026-10-10）
- 拳击手：ZX优先候选；军官：ZX依情境而定。
- 改革推动者：更偏ZN；审讯官：更偏XZ；外科医生：更偏XN；调查记者：更偏Z。
- 六例是**用户判断/人工锚点**，待真实对象和时间窗口补证；不是给职业永久贴标签。
- 错误族：行动性万能ZX、负面压迫万能ZX、职业名词等于动词、先选ZX再凑例、没有竞争元、未校准的高分假准度。

## 4. 旧体系强项
- 让抽象符号可解释为跨领域的可感知对象与具体故事素材。
- 对职业、名词、角色、物件、机制、关系提供系统化检索与组合。
- 独立区分“配比、原型相似、体量、证据”；利于约束与创作复盘。
- 结构对照、关系动态链、反例检验能抑制表面情绪词堆砌。

## 5. 旧体系弱点与不得原样恢复的部分
- 领域内先强制找五行父项、全部100% is-a继承：易把结构类比误写为客观分类真理。
- 旧排行榜/旧纯度种子缺逐项重新复核，不能直接宣称客观准确。
- 结构映射得分不证明创作真的激发目标感受。
- 词汇/职业一旦脱离对象、尺度和语境，容易出现表面关键词映射。
- 原有批量映射脚本和独占父库工作流保持隔离，直到小样判定通过。

## 6. 可恢复项与保留项
- **RECOVER_INTO_ACTIVE_METHOD**：词与职业跨域映射、全十元竞争、对象/关系分层、正反例、映射准度和配比**作为明确定义的候选分析字段**。
- **KEEP_LEGACY_GATED**：is-a狭义100%继承、旧算法排行榜、自动父库归类；不得通过快照自动重启。
- **PRESERVE**：原材料、旧分析、版本时间线、视觉/音乐/故事案例，保留来源证据。
