# B｜新体系独立上下文｜主观感受与AI动画创作

> 独立读取包：保留2026-10-07迁移的真实有效成果，同时标明后续用户于10-10提出的层级纠正。不得假装新体系没有实际价值。

## 1. 迁移版本事实
- R1：从对象归类转为“人受到作品刺激产生什么感受”。
- R2：识别**至少166个不同文件**的影响面（扫描下限，不等于全库数量）。
- R3A/R3B：人是感受主体；X=醒、Z=张、N=耐的体验定义；L1感受核/L2诱发机制/L3领域表现；其余体验定义仍有候选/待定项。
- R4：十种感受定义→人的报告/可靠性→诱发机制→关系与动态链→AI生成控制。
- R5：在2026-10-07封板旧分类入口退居历史；保留旧素材与回滚锚点，锁定感受谱默认读取。
- 当前版本链记录 `TY-FEELING-1.5.0-R5`，尚**未**按最新用户要求实现“映射先、感受后”的双链整合。

## 2. 新体系的目标与有效价值
- **最高创作目标**：创作者自由描述目标感受 → 轮盘提取感受方向/主次/关系 → 通过角色、故事、分镜、光影、音乐、运动等约束实现 → 实际作品/人的感受复盘。
- 人的主观感受由人报告；AI只可理解、预测和执行，不以AI自评冒充人的反应。
- 区分词义/结构映射准确、AI对感受意图的理解、作品实际感受达成：三者不可偷换。
- 五行情绪用于十元感受候选锚点（如 ZX=怒火、ZN=喜悦、X=无望、N=思念等），**不覆盖**映射知识；NX“平淡”等未冻结。
- 用户目前的“轮盘”是统一列出/提取感受，不自动等于聚类，也不必把1–10强度计算作为所有讲解的唯一入口。
- 十元关系不只是情绪标签，还包括相生相克互补、不同感受的增强/压制/交替/收束。

## 3. 作品接口与重要限制
- 《方志敏》已完成4分17秒：用真实成片、镜头、当时记录/后期复盘说明映射、关系、约束及感受选择；禁止把回顾性解释说成当时已使用的决策。
- 《黎黎隆》后续多个个人风格AI动画短片继续研究镜头、光影、构图、节奏如何深化目标感受；未完成不能写为完成。
- 研究身份是实践引导型艺术研究；不强求将模型写成普适心理定律。
- 现有论文工单674-301，素材归集674-303。

## 4. 新体系强项
- 给创作提供清晰目标：不是“词像哪个符号”而是“观众/作者要得到什么体验”。
- 让AI服从创作者意图，以目标感受控制多个视听单元，并保留复盘依据。
- 人类感受评价主权清楚，避免生成器自评循环论证。
- 轮盘与动态感受关系能支持艺术论文和项目案例讲解。

## 5. 新体系现有弱点/误用
- R2-R5将旧名词、职业、物件映射整个移出默认链，导致知识检索和全十元比较被弱化。
- 把“感受”放在所有推理步骤最前时，容易无法解释“为何这个职业映射ZX而另一个映射XN”。
- 仅用怒火/愤慨等情绪词发散，丢失行业、名词、社会机制、对象与关系结构。
- 目标感受1–10谱**不能代替**旧结构配比度/本征映射准度；相同数字不意味着同一指标。
- 仅靠创作者回看自己作品，不能声称外部观众已稳定产生所述感受。

## 6. 新版值得保留的硬规则
- 人是感受主语；AI不是人的体验替代。
- 感受作为创作最终目标、评价和约束回路。
- 十元体验词未冻结者仍标 PENDING；五轴相反不自动等于生克补。
- 每次作品分析区分原始意图、真实执行、实际效果、回顾性归因。
- 只有人类反馈才能声称人的实际感受，而艺术创作可保留作者主观复盘。
