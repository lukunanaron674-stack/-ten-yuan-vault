# 十元双轨均衡调用协议｜结构映射 × 主观感受

> R1独立知识入口：先同时读取 [OLD_CONTEXT](双上下文_旧映射与新感受_20261010/OLD_CONTEXT.md) / [NEW_CONTEXT](双上下文_旧映射与新感受_20261010/NEW_CONTEXT.md)，再读 [优缺点桥接](双上下文_旧映射与新感受_20261010/COMPARE_AND_BRIDGE.md)。若两侧冲突，标记冲突，不假定任何一侧因「新旧」自然拥有最高真值。

## R2｜两种能力的权衡，不是固定上下等级
- 结构映射轨（S）：解决**职业/名词/人物/物件/现象/动作/场景在指定语境与尺度下，与哪一个或哪些十元结构相近**。证据是结构、功能、改变变量、最近邻反例；输出是「当前实例的候选十元结构」，不是人类感受事实。
- 感受构成轨（F）：解决**作者要什么体验、何种视听安排可能诱发、观众或作者最终报告什么体验**。证据是作者创作意图、成片和真实人的反馈；输出是目标/预测/报告，不能自证结构真值。
- **谁是主，按任务切换**：问「职业是什么十元」→ S主F参考；问「如何让观众感到某种情绪」→ F定目标，S帮挑适合的对象关系；问「作品怎样构成」→ S/F并行，明确因果和证据。
- **既能互助又不能吞并**：感受不代替本征准度，映射不代替观众报告；发现冲突则保存两轨，交作者复核。

## R3｜对象 / 关系 / 感受分成不同判定对象
1. `endpoint_mapping`：具体对象/人物/名词/职业/物件，在给定语境和时段的结构候选。
2. `relational_expression`：两个或多个已界定对象之间的**关系整体**呈现哪个十元；不得从整体关系反推每个端点的符号。
3. `feeling_target`：作者希望达到的感受，不等同预测也不等同实测。
4. `feeling_prediction`：AI提出的预期感受，只能标候选。
5. `feeling_report`：作者回顾/观众实测需分来源、时间、是否独立评价。

**问词类时，职业身份≠该职业的一次动作，名词≠动词，职业≠伦理立场，物品≠使用者的行动。**

## R3｜结构映射准度与感受强度不要相加
| 字段 | 含义 | 单位/范围 | 约束 |
|---|---|---|---|
| `structure_candidate` | 十元候选 | X/Z/N/ZN/NZ/XN/NX/ZX/XZ/X并Z | 至少考虑10元并列竞争；可GREY |
| `composition_ratio` | 模型中的结构成分比 | 旧版0–100%总和100；仅有依据才填写 | 数据不代表现实客观组成比例 |
| `archetype_similarity` | 对某个十元原型的结构相似评分 | 旧版0–100且每元独立；目前可null | 无统一校准与近邻证据不填数字 |
| `ten_yuan_volume` | 构成体量 | 1–10内部标注 | 绝不替代准度 |
| `feeling_profile` | 人自报或AI预测的感受强度 | 1–10/方向；明确来源 | 不能拿S的分数直接赋值 |
| `evidence_confidence` | 对判断的证据把握 | provisional/confirmed/ambiguous | 不能等于感受强度或准度 |

旧“is-a狭义100%五行父项继承”只有历史来源和候选语义，**不是必须执行的判定公理**；旧一键分库脚本继续停用。

## R4｜全十元竞争的最低判定流程
1. 写`noun_phrase`、`part_of_speech`、`domain`、`analysis_scale`、`context`、`time_window`、`observed_mechanism`。
2. 依次对 X/Z/N/ZN/NZ/XN/NX/ZX/XZ/X并Z 记录：候选吻合/冲突/证据缺口（至少一条判别性比较，不得简单画勾）。
3. 输出`primary_candidate`、`runner_up`、`alternate_candidates`、`nearest_neighbor_difference`、`counterexample`、`ambiguity_status`。
4. 如果物件/职业本身没有足够结构证据，输出「需要具体情境」而不是随手给一个百分比。
5. 特别禁止根据「主动、强烈、压迫、尖锐、外显」单个形容词直接判ZX。

### USER提供的六个反例锚点（均不是冻结职业本体）
| 职业名词 | 作者当前判断 | 禁止的捷径 | 需区分的结构 |
|---|---|---|---|
| 拳击手 | ZX更合适 | 「会攻击」=ZX | 竞技对抗机制、职业/比赛动作区分 |
| 军官 | 有点ZX、依情境 | 「发号施令」=ZX | 指挥权、强攻、职业职能分开 |
| 改革推动者 | 更偏ZN | 「推动」=ZX | 价值确认、组织成立及方向权 |
| 审讯官 | 更偏XZ | 「逼迫」=ZX | 试探、临界、条件变化及处置 |
| 外科医生 | 更偏XN | 「动手术」=ZX | 程序、约束、手术动作分别看 |
| 调查记者 | 更偏Z | 「揭露」=ZX | 公开呈现、使其被看见与冲击行为 |

这些是`user_preference_anchor`，不可假写为已经通过十维盲测的准度或永久职业归类。

## R5｜三条调用工作流

### A. 词汇/职业/名词映射
```text
提问 → 定词类/领域/尺度/时间 → S十元全量竞争 → 结构/关系分开
→ 正例+反例+最近邻 → 候选准度(可空) → F可能诱发何种感受(可空)
→ 作者校准
```

### B. AI动画创作（感受是创作目的）
```text
作者自由描述目标感受 → 轮盘列出十元与五轴候选
→ S词库挑人物/物件/故事事件及生克补/动态链
→ AI对故事/分镜/光影/运动/声音执行约束
→ 生成作品 → 作者复盘，条件允许时采集观众报告
→ 只回训应用选择/诱发假说，禁止自动覆写理论定义
```

### C. 既有作品复盘
```text
真实作品与原始材料 → 先标识哪些是当时的创作判断
→ S拆对象/事件/关系整体 → F标作者目标、事后理解、可得的人类报告
→ 比较原意/执行/观众实际 → 留证据索引与反例
```
