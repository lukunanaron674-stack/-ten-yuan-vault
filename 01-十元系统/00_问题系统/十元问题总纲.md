# 十元问题总纲 v1.0

## G0｜总目标
让十元成为一个**端点稳定、关系可证、动态链可解释、跨模型可执行、视觉与故事可生成、结果可审核**的结构系统。

## 八个分目标
- G1｜十元端点与正本一致
- G2｜五轴被正确调用与回归
- G3｜生克补关系可证明、不可串对
- G4｜动态链可解释、可盲测
- G5｜解释器 / DSL 跨模型稳定
- G6｜十元视觉化可生成、可审核
- G7｜十元能真正驱动故事 / H3 / 感受
- G8｜版本、自动化与研究治理不漂移

## 固定纪律
1. 五轴 V1.0 本体已冻结，默认 FROZEN_REGRESSION_ONLY；没有真实 failure 不重开五轴理论。
2. 阴阳相反轴 ↔ 只表示同核心变量上的反向操作，不自动等于生/克/补。
3. 正式 Q 必须有证据、父目标、因果和 DONE 条件；假设不直接占 Canvas。
4. D1/D2/D3 最多三级；能直接实验就停止继续拆。
5. volume 与 impact_weight 分开。
6. Canvas 管关系；Q Markdown 管 Problem State v1 与完整证据。
