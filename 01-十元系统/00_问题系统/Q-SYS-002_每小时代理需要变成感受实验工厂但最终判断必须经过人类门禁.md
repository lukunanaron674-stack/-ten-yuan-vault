# Q-SYS-002｜每小时代理需要变成感受实验工厂，但最终判断必须经过人类门禁

## 1｜问题一句话
长时间自动化最适合持续“生产实验”，不适合让 AI 自己给自己做最终感受验证。

## 2｜每小时允许自动做
1. 从旧知识中抽一个待感受化假设。
2. 找最有区分度的素材。
3. 写预注册预测。
4. 设计单变量 A/B。
5. 生成或准备实验素材。
6. 自动整理成盲审卡。
7. 放入 HUMAN_GATE 队列。
8. 人反馈后自动计算误差、更新证据等级、挑下一实验。

## 3｜禁止
- AI生成 → AI自评 → 直接升为已验证。
- 没有人类反馈就把 E0/E1 升成外部证据。
- 每小时无限制造重复样本。
- 先知道答案再改预测。

## 4｜证据等级
E0 旧假设
→ E1 单人重复
→ E2 多人趋势
→ E3 跨素材
→ E4 跨媒介
→ E5 AI反向生成有效

## 5｜DONE
- 自动队列、预注册预测、A/B素材、盲审卡、人类门禁、误差回写全部可运行。
- 每小时任务以“信息增益”排序，而非样本数量。
- 人不需要每小时参与，可按日/批次集中审核。

### 6.4｜自动循环（现有小时任务，决策优先于产量）
`读现行Z-C-E/已有卡索引与上次receipt → 选择最前置一条具体Q → 检查证据增益/去重 → 能补原始可核证据则自动做 → 锁AI预期与A/B/负控 → READY才编排一张实验卡并校验 → HUMANGATE必要时才集中送用户盲审 → 人反馈后计算误差及按门禁升级/降级 → 更新原Q与Linear、保留回滚 → STOP/NO_OP`。
**每小时上限一张新工作卡**，同源复述/重复生成/只写新文稿不算有效卡；连续2轮没有证据增益即停止同一机制/切换READY问题。**已有自动任务**「AI感受证据总控」只负责问题系统证据和READY最小Q，不复制「十元作品研究与H3吸收」的影片样本，不复制五轴独立实验，不复制目标提醒的通知职责。

**状态纪律**：E0旧假设→E1单人重复→E2多人→E3跨素材→E4跨媒介→E5目标生成；人的主观体验绝不能由AI代填；C5需人评；C9还需要真实反向生成、跨任务/媒介复验和长期治理回归。每次只报告真实receipt、已验证新增卡（或0）及下一个可解除的阻塞。无证据增量时NO_OP静默。
