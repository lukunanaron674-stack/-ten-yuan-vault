# 概念映射：牺牲（体系化重制版）

---

## 1. 定义

**牺牲** = 为了某个高于自身的目标（体系、群体、信仰、道义、他者），主动或被动地放弃自身所拥有的核心价值（生命、利益、尊严、享乐、时间），并承受由此带来的损耗与痛苦。

核心特征：**以失换得**——失去当下可感的"小我之利"，换取超验或远期之"大我之义"。

---

## 2. 三元粗拆

| 三元 | 对应位 | 指称 |
|:---:|:---:|:---|
| 阴爻 ⚋ | z | 被放弃之物（砧上之肉） |
| 中爻 ☰ | x | 牺牲者（主体） |
| 阳爻 ⚊ | n | 牺牲所为之目标（神／群体／理想） |

> **牺牲结构** = 牺牲者(x) 把 被放弃之物(z) 献给 目标(n)

**例**：战士(x) 将 生命(z) 献给 祖国(n) → 三元= (x:战士, z:生命, n:祖国)

## 10. 三条动态链

### 链A：英勇牺牲（经典模式）
```
x(战士) → xz(我无·我是祭品) → xn(我神·使命) → z(生命) → n(祖国)
```
**边组合**：x→xz(7) + xz→xn(生) + xn→z(补) + z→n(8)
**说明**：战士先把自己定位为祭品(x→xz)，使命内化(xz→xn)，然后以生命(z)献给祖国(n)。经典英雄叙事。

### 链B：无神献身（现代模式）
```
x(医生) → zx(无我) → zn(无神) → n(人类/生命尊严) → x并z(消逝)
```
**边组合**：x→zx(7) + zx→zn(生) + zn→n(生) + n→x并z(补)
**说明**：无宗教背景的凡人，放下自我(x→zx)走向纯粹为人的牺牲(zx→zn)，为人类尊严献身(zn→n)，最终在消逝中完成(x并z)。抗疫精神模型。

### 链C：孤独虚空（反思模式）
```
nz(神无·值吗) → n(目标) → x(牺牲者) → z(失去) → nz(再次追问)
```
**边组合**：nz→n(克·逆) + n→x(9) + x→z(9) + z→nz(生)
**说明**：从"值了吗"的虚空出发(nz)，回望目标(n)与牺牲者(x)，凝视失去之物(z)，再次回到"值了吗"的追问——这是牺牲的哲学闭环，痛苦但有深度。

## 14. 误判检查

| 检查项 | 结果 | 说明 |
|:---|:---:|:---|
| 定义是否前置于推理 | ✅ | 第1步已定义 |
| 三元拆解是否有逻辑依据 | ✅ | x=牺牲者, z=被舍之物, n=目标 |
| 十元是否与三元连贯 | ✅ | 十元是在三元框架内的细化 |
| 体量赋值是否有理由而非随意 | ✅ | 每项标注了理由 |
| 25对关系是否与十元定义一致 | ✅ | 补/克/生均基于十元含义推导 |
| 边强度是否与映射强度、关系一致 | ✅ | 高强度边对应高映射+(x,z,n) |
| 对子组合是否有冗余 | ✅ 无 | 15个对子覆盖所有高、中强边 |
| 三条链是否覆盖不同场景 | ✅ | 经典/现代/反思三个维度 |
| 主题归并是否完整 | ✅ | 五主题无遗漏，闭环包全十元 |
| "牺牲"的核心特征是否全程贯穿 | ✅ | 以失换得，小我→大我 |

**无重大误判。** 注意链C中nz→n使用了"克·逆"（逆克），但系统容许可逆性解释，在牺牲语境中"虚空追问目标"在哲学上是合理的。
