# 动态母型

本页是十元系统的核心文件之一，用于归档“动态链条”的高层定义、基础构架、复杂构架、某十元的动态链条，以及向量尺标计算法。

相关入口：[[总入口]]、[[十元生补克表]]、[[五大主题]]、[[银矿哥评分标准]]

---

## 0. 总定义：艺术作品、主感觉、意蕴

艺术作品可以先理解为：

```text
艺术作品 = 表达一种核心感觉
```

好作品不是只把这个感觉说出来，而是通过多个层次去反复强化它：

```text
人物 / 情景 / 事件 / 意象 / 节奏 / 视觉 / 声音 / 主题 / 结构
```

当这些层次都朝同一个核心感觉用力时，作品会得到更强的意蕴，也就是更高的作品分数。

```text
作品分数 ≈ 主感觉准确度 × 层次强化程度 × 意蕴沉淀强度
```

十元关系的动态链条，是强化主感觉的一种结构办法，但不是艺术作品的全部。

---

## 1. 动态链条的新定义

动态链条不是剧情梗概，也不只是十元符号连线。

```text
动态链条 = 作品构架 / 作品构成方式
```

它描述作品如何通过十元关系组织：

```text
人物如何安排
情景如何组织
事件如何推进
意象如何反复
冲突如何传导
主题如何浮现
意蕴如何形成
```

因此动态链条分析要分三层：

```text
1. 基础动态链条构架
2. 复杂动态链条构架
3. 个别特殊动态链条构架
```

---

## 2. 基础动态链条构架

基础动态链条构架不是只有“主十元→生位→补位”一种。它是研究十元生、克、补关系如何构成作品完整性的基础语法。

### 2.1 生补型

```text
主十元 → 生位 → 补位
```

用于观察某个主十元的自然展开与完整化。

### 2.2 克补型

```text
主十元 → 克位 / 被克位 → 补位
```

用于观察主感觉先遇到压力，再通过补位获得完整性的构架。

### 2.3 克制转顺型

克制转顺型与“克制泄流型”归为同一类。

公式：

```text
A 被 B 克制
→ B 生 C
→ C 生回 / 导回 A
```

例：

```text
zx 被 xn 克制
→ xn 生 xz
→ xz 生 zx
```

核心：

```text
克制没有导致停滞，而是被导入顺生循环。
```

艺术效果：

```text
冲突不是被解决，而是被转成运动。
```

### 2.4 生位反克型 / 克制回环型

公式：

```text
A 克 B
→ B 生 C
→ C 克 A
```

例：

```text
xz 克 zn
→ zn 生 n
→ n 克 xz
```

核心：

```text
被克者不直接反击，而是生出能反克对方的位置。
```

艺术效果：

```text
意义不能直接战胜命运，但意义能生出承载，让承载反制命运。
```

### 2.5 补位互学型

公式：

```text
主十元 ↔ 补位
```

双方互相学习、互相补全。例如时间主题中：

```text
xn ↔ z
```

可以形成“持续 / 秩序 / 时间感”与“瞬间 / 明亮 / 显现”的互补成长。

## 3. “某十元的动态链条”是什么意思

“xz 的动态链条”“nz 的动态链条”“zx 的动态链条”不是说作品主题必然等于这个十元，也不是改写生补克表。

它的意思是：

```text
以某个十元作为构架核心 / 动力中心 / 主感觉中心，
调用它自己的生、克、补关系，
让人物、情景、事件、意象与结果都围绕它强化。
```

一句话：

```text
某十元的动态链条 = 让这个十元更像自己的构架方式。
```

分析时要区分：

```text
1. 主角十元链
2. 主题五维链
3. 主意蕴落点链
```

三者可以重合，也可以不重合。

## 4. xz 的最佳动态链条架构

### 4.1 xz 的分量

```text
xz = x 为主，z 为辅
```

因此 xz 的最佳动态链条不应优先套外部顺生母型，而应优先使用 xz 自身关系。原因是：

```text
意蕴重叠
```

要表达 xz，就要让人物、情景、事件、意象、结果都反复落在 xz 的关系上。

### 4.2 xz 主链：克制关系为主

xz 的主链优先看克制关系：

```text
n 克 xz
```

含义：

```text
承载 / 家 / 稳定 / 容器
反制
漂流 / 临界 / 命运不稳
```

主感觉：

```text
本来要走，但被留下。
本来漂流，但被承载接住。
```

或者：

```text
xz 克 zn
```

含义：

```text
命运临界 / 漂流 / 遭遇
压迫
意义 / 信念 / 精神核心
```

主感觉：

```text
命运压迫意义，漂流让信念失稳。
```

### 4.3 xz 辅链：nz 补 xz

```text
nz 补 xz
```

含义：

```text
停靠 / 依恋 / 归宿 / 不想结束
补厚
命运临界 / 漂流 / 不稳
```

没有 nz，xz 容易变成普通危险、黑暗、逃亡、灾难。有 nz，xz 才会变成真正的命运感：

```text
想停，却停不稳。
想走，却舍不得。
被推走，却还回头看灯。
```

### 4.4 xz 归档句

```text
xz 的最好动态链条架构 = 以 xz 自身关系为主构架。
主链使用 xz 的克制关系：n 克 xz，或 xz 克 zn。
辅链使用 xz 的补位关系：nz 补 xz。
因为作品要表达 xz，就必须让人物、情景、事件、意象、结果都反复落在 xz 的关系上，形成意蕴重叠。
```

## 5. nz 的动态链条架构

### 5.1 nz 的分量

```text
nz = n 为主，z 为辅
```

因此 nz 的最佳动态链条不能照搬 xz 的“克制为主”逻辑，而应以：

```text
生关系为主，补位为辅
```

### 5.2 nz 的生链候选：nx 与 z 平等

在 nz 的动态链条里：

```text
nz → nx
nz → z
```

二者是平等候选关系，不应固定判断谁更高级。真正标准是：

```text
哪一条更能让作品更加 nz？
```

这是逻辑计算题，不是静态排名。

### 5.3 nz → nx 的力流动

```text
nz = n + z
nx = n + x
```

当 nz 选择 nx：

```text
x 出现
x 压 z
z 被压低
n 留下并变强
```

结果：

```text
nz → nx = n 分量增强，z 分量下降
```

艺术效果：

```text
停靠更稳
归宿更重
依恋变成辨认
不想走变成“确认为什么留下”
```

适合：

```text
这个归宿是真的吗？
这个人值得停留吗？
这份依恋能不能被信任？
我为什么不想离开？
```

### 5.4 nz → z 的力流动

```text
nz = n + z
z = z
```

当 nz 选择 z：

```text
z 被点亮
n 不消失
n 与 z 更接近平衡
```

结果：

```text
nz → z = 停靠被显影，n 与 z 旗鼓相当
```

艺术效果：

```text
一盏灯
一碗汤
一次回头
没关的门
临别前的小窗
```

### 5.5 xz 作为 nz 的辅助补位

```text
nz = n + z
xz = x + z
```

当 xz 加入 nz：

第一阶段：

```text
xz 里的 x 压住 xz 的 z
也压住 nz 的 z
z 被压
n 剩下
n 变强
```

第二阶段：

```text
xz + nz 的命运关系产生新的 z 力
z 回染 n
n 重新变成 nz
```

所以：

```text
nz + xz
→ x 压 z
→ n 变强
→ z 回流
→ n 被染成 nz
→ 回归 nz
```

### 5.6 在 xz 辅助回归 nz 后，主生位选谁？

前提：

```text
xz 已经作为辅助位加入，并且刚好回归 nz
```

此时主生位应优先选：

```text
z
```

原因：

```text
xz 已经负责了 x 的压制、命运压力、n 的凸显；
如果主生位再选 nx，会重复引入 x，导致 z 被二次压低，结果容易偏 n / nx；
如果主生位选 z，则能把已经被压实的 n 重新点亮，形成更完整的 nz。
```

公式：

```text
nz + xz = n 被压实后回归 nz
此时再加 z = nz 被点亮，更完整
此时再加 nx = nz 更重，但可能偏 n / nx
```

### 5.7 nz 归档句

```text
nz 的动态链条 = n 为主、z 为辅的停靠构架。
主链以生关系为主，nx 与 z 都可以作为 nz 的平等生链候选。
选择标准不是固定高低，而是哪一条更能让作品更加 nz。
当 xz 作为辅助补位并刚好回归 nz 时，主生位更适合选 z，因为 xz 已经压实 n，z 能把强 n 重新点亮并回染为更完整的 nz。
```

## 6. 向量尺标：动态链条的力学层

动态链条不能只看符号连接，还要计算分量流动。

```text
动态链条 = 构架
向量尺标 = 力学
```

最小向量可先用：

```text
V = (x, z, n)
```

初始估值只作分析尺标，不作绝对定义：

```text
x  ≈ (10, 0, 0)
z  ≈ (0, 10, 0)
n  ≈ (0, 0, 10)
xz ≈ (7, 3, 0)
nz ≈ (0, 3, 7)
nx ≈ (3, 0, 7)
```

分析时要问：

```text
哪个分量先变强？
哪个分量被压？
哪个分量剩下？
哪个分量回流？
最后主感觉是否回归？
```

向量尺标的用途：

```text
1. 判断哪条链更能强化主感觉
2. 判断哪条链会污染主感觉
3. 判断补位是否真正回归主感觉
4. 判断意蕴是否重叠
5. 判断作品分数为什么更高
```

## 7. 审稿红线

- 不把动态链条当剧情梗概。
- 不把十元符号连线当最终答案。
- 不默认 zn 起手。
- 不默认 n 承载。
- 不把五维主轴当十元起手。
- 不用结局倒推起手。
- 不用视觉强度反推本体。
- 不把 xz 的克制主链套到 nz 上。
- 不把 nz 的生链选择固定成 nx 或 z 的单一优劣。
- 不忽略向量分量中的压制、剩余、回流与回归。

## 8. 最小断点包

```text
动态链条 = 作品构架 / 作品构成方式。
艺术作品 = 表达一种核心感觉，并通过多个层次强化这种感觉。
十元动态链条 = 强化主感觉的一种结构办法。

某十元的动态链条 = 以该十元为构架核心，调用其生、克、补关系，让作品更像这个十元。

xz = x为主，z为辅。
xz 最好链条：克制关系为主，nz补位为辅。
主链：n克xz / xz克zn。
辅链：nz补xz。
目标：意蕴重叠，让所有层次压回xz。

nz = n为主，z为辅。
nz 最好链条：生关系为主，xz补位为辅。
nz→nx 与 nz→z 是平等生链候选。
选择标准：哪条更能让作品更加nz。
若 xz 已作为辅助位并回归 nz，则主生位选 z 更好，因为 xz 已压实 n，z 能点亮并回染为更完整的 nz。

动态链条不是路线题，而是分量计算题。
向量尺标用于计算 x / z / n 在生、克、补中的增强、压制、剩余、回流与最终回归。
```
