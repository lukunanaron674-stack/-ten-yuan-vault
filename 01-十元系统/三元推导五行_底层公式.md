# 三元底层符号推导五行

> 用 3 个对立符号 z、x、n 作为能量运行的动态矢量，完整推导出五行。
> z = 正向/显性/离心爆发 | x = 反向/隐性/向心收敛 | n = 零位/介质承载

---

## 一、三个符号的底层定义

| 符号 | 方向 | 性质 | 作用 |
|------|------|------|------|
| **z** | ⬆️ 向外 | 显性、扩张、释放 | 绝对的主动性与阳性矢量 |
| **x** | ⬇️ 向内 | 隐性、收缩、潜藏 | 绝对的被动性与阴性矢量 |
| **n** | ⏸️ 居中 | 静止、包容、缓冲转换 | z 与 x 碰撞的容器和场地 |

---

## 二、五行公式推导

| 五行 | 符号公式 | 物理意象 | 含义 |
|------|---------|---------|------|
| **火**🔥 | **z**（纯爆发） | 完全离心释放 | 流量爆发、高潮、情绪燃点 |
| **木**🌳 | **z + n**（在承载中突围） | 受约束的向上生长 | 破局、韧性、成长动机 |
| **土**🌏 | **n**（纯承载） | 居中承载与中和 | 平台基调、风控、现实主义 |
| **金**⚔️ | **x + n**（在承载中凝聚） | 对混沌的修剪凝固 | 精度、秩序、清算、肃杀 |
| **水**💧 | **x**（纯收敛） | 完全向心收敛 | 暗流、留白、深层潜藏 |

## 三、生克关系的数理化

| 关系 | 公式 | 解释 |
|------|------|------|
| **火克金** | z 克 (x+n) | 纯粹的释放冲散在介质中凝聚的秩序 |
| **金克木** | (x+n) 克 (z+n) | 凝固的秩序压制在承载中的生长 |
| **木克土** | (z+n) 克 n | 在承载中生长反过来改造承载本身 |
| **土克水** | n 克 x | 承载的稳定性吸纳纯粹的收敛 |
| **水生木** | x 滋养 (z+n) | 极度的潜藏积蓄破土的能量 |
| **木生火** | (z+n) → z | 生长到极致就是纯粹的释放 |
| **火生土** | z → n | 释放的余烬沉淀为承载 |
| **土生金** | n → (x+n) | 承载遭遇收敛凝固成秩序 |
| **金生水** | (x+n) → x | 秩序收敛到极致就是纯粹的潜藏 |
