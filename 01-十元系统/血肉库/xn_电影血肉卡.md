### XN｜固定循环规则如何改变行动

| 构成字段 | 增量拆解 |
|---|---|
| `material_ref` | 《明日边缘》旧卡：固定开局与反复经历（未核镜头/时间码） |
| `source_state` | `LEGACY_SUMMARY_UNVERIFIED`（人物形象母型中的创作推演为`CREATIVE_H`） |
| `observable_in_old_card` | 旧卡记录相同开局重复出现，以及人物逐步熟悉战斗流程。 |
| `conditions` | 存在可重复的起始条件与限制；角色保留某些经验。 |
| `trigger` | 角色在一次失败后重新经历同一阶段。 |
| `action_sequence_H` | 遇阻→尝试→失败→返回→调整（为旧卡机制概括，不代表逐镜核完）。 |
| `changed_variable_H` | 角色掌握的信息与对行动结果的预期。 |
| `result_or_limit` | 同一规则可从束缚转变为学习工具；不把循环题材本身定为 XN。 |
| `felt_response` | 可能有麻木、紧迫、熟练或哀默；场景与观众不同会改变强度。 |
| `competing_explanation` | 重复有可能是 N 日常规律，也可能是纯叙事手法，需检验规则是否改变选择。 |
| `negative_control` | 移除记忆保留，人物还能积累策略吗？若不能，关键机制在规则×记忆而非循环画面。 |
| `transfer_H` | 竞赛演练的多次失败到策略优化，作为原创候选而非影片事实。 |
| `evidence_gap` | 具体重置条件、失败-改动细节、感受测量。 |
