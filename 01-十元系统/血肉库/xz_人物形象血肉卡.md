# xz 人物形象血肉卡 v0.1

> **范围声明：本卡记录 xz 在“危险女性人物形象”中的血肉表达，不替代 xz 本体定义。**
>
> xz 本体仍以“危险显身、异质逼近、边界失稳、临界行动”为准；致命女人、危险御姐、疯批美人等，只是这一结构在人际关系和人物气氛中长出的形象。

## 1. 人物形象主骨

```text
危险已经显身
→ 她控制距离、暧昧和选择窗口
→ 对方的安全边界持续变窄
→ 对方被诱导着主动越界
```

最短句：

> **她不是追你，而是让你自己走进危险。**

因此，xz 危险女性不能只靠性感、红黑、疯笑或御姐感成立。她必须在关系中实际制造：

- 危险逼近。
- 安全距离缩短。
- 退出窗口变窄。
- 对方必须作出临界选择。

## 2. 控制方式差异

| 类型 | 控制方式 | 人物感觉 |
|:----|:---------|:---------|
| xn | 规则、纪律、制度、程序 | 我规定你怎么做 |
| zx | 行动、目标、压迫、推进 | 我直接带你冲过去 |
| **xz** | **诱导、危险、暧昧、距离、选择窗口** | **我让你自己走到边界** |

> **xz 的控制不是把人管住，而是控制“你还能退到哪里”。**

## 3. is-a 名词系统

### 3.1 可直接作为 is-a 的人物身份

```text
致命女人 / Femme Fatale

黑寡妇型女人
女间谍
赌场女荷官
审讯官

```

这些名词具有较明确的叙事位置、职业机制或捕食关系，能够自然生成服装、动作和关系结构。

### 3.2 has-a：人物气质

```text
危险御姐
支配系御姐
疯批美人
小恶魔姐姐
冷艳危险感
```

这些是气质，不宜单独充当人物本体。

### 3.3 behaves-as：关系行为

```text

关系猎手
心理逼近者
危险调情者
让对方主动越界的人
```

### 3.4 carries：意象系统

```text

黑寡妇
蜘蛛网
裂口笑
活体入口
噬口边界

```

## 7. 关系动力血肉

> 本节记录当前“危险女性母型”的关系倾向，不作为所有 xz 人物的普遍定律。

### 喜欢 zx

```text
zx 能立即行动、打穿出口、制造下一步。
```

她会被 zx 的决断和推进吸引，因为 zx 能让正在闭合的局面重新打开。

### 喜欢 xn

```text
xn 提供规则、禁区和边界线。
```

她喜欢围着 xn 的线犯规、试探和施压，因为明确边界能产生越界张力。

### 讨厌 zn

```text
zn 命名、解释、审判、净化、升华。
```

她讨厌 zn 把危险、欲望和裂口解释成某种意义或道德结论。

最短句：

> **别解释我。**

### 害怕 n

```text
n 承载、收容、安放、稳定、留下。
```

她害怕 n 不是因为 n 有攻击性，而是 n 真的可能接住她、让她停下，并把临界生活变成固定生活。

最短句：

> **别留下我。**

关系封存：

```text
喜欢 zx：出口被打穿。
喜欢 xn：边界可以被试探。
讨厌 zn：拒绝被解释和净化。
害怕 n：恐惧被承载和安放。
```

## 8. 服装生成原则

服装不能从“破不破、完整不完整”生成，应从 is-a 名词生成：

```text
女间谍 → 礼服、暗袋、假证件、监听器、手套
赌场荷官 → 牌桌制服、袖箍、筹码、领结、发牌工具
审讯官 → 制服、记录板、手套、冷光灯、权限证件
魅魔 → 契约物、捕食器官、欲望标记、非人结构
```

原则：

> **is-a 定身份，has-a 定气质，behaves-as 定关系，carries 定意象。**

## 9. 误判防线

以下单独出现时，不能直接判为 xz 人物形象：

- 红黑配色。
- 破损衣服。
- 御姐身材。
- 疯笑或挑衅眼神。
- 性感危险妆容。
- 女王、上司或高位身份。
- 单纯强控制欲。

最小差异：

```text
她只是制定规则、要求服从 → 更偏 xn。
她直接行动、击穿目标 → 更偏 zx。
她经营身份、面具和表象 → 检查 x并z。
她沉入欲望、吞噬与毁灭 → 检查 x。
她让对方主动靠近危险，且退出窗口正在缩小 → xz 强。
```
