# zx 孙悟空人物血肉卡 v0.1

> **孙悟空是典型 zx：无限的、打不倒的不倒翁，是人类极限意志的显形。**

## 1. 核心人物锚

```text
外界不断压制、击倒、封锁
→ 孙悟空重新站起
→ 再次把意志变成行动
→ 不接受外界对自己作最终定义
→ 主体权能重新显现
```

最短句：

> **你可以暂时压住他，但不能替他决定“他已经结束”。**

## 2. 为什么是 zx

孙悟空的关键不是单纯能打，也不是一般意义上的坚持。

### 本体

```text
张扬醒目
+ 主体权能持续显现
+ 不接受被外部最终定义
+ 每次被压制后仍能复起
```

### 行为

```text
战斗
+ 破局
+ 目标执行
+ 路径被封后重新行动
+ 把意志做成现实
```

### 结果

```text
没有被彻底取消主体性
+ 意志重新进入现实
+ 权能再次成立
```

所以：

> **打不倒不是结果描述，而是 zx 本体不断通过行动重新成立。**

## 3. “不倒翁”的准确含义

不倒翁不是 n 式承受，也不是 nx 式顺着环境继续。

```text
n：容纳压力
nx：不主动占位，顺着已有安排继续
zx孙悟空：压力把我按下去，我仍主动重新立起来
```

区别在于：

- 不是被动熬过去。
- 不是接受安排。
- 不是等待环境放松。
- 是主动让主体意志重新占据现实位置。

## 4. “无限”的含义

这里的无限不是体积、范围或抽象的“大”。

它指：

> **外界无法通过一次、十次或无数次打击，获得对主体的最终定义权。**

```text
被击倒
≠
被定义为失败
```

只要主体仍能重新行动，zx 就再次显现。

## 5. 人类极限意志

孙悟空作为 zx 锚点，代表的不是普通毅力，而是：

```text
身体可受限
环境可压制
路径可被切断
结果可暂时失败
但主体仍重新把意志推进现实
```

所以“人类极限意志”可暂时定义为：

> **主体在一切外部否定之后，仍保有再次行动、再次做成、再次显现自身权能的能力。**

## 6. 与朱元璋的双锚区别

| 人物锚 | zx 主轴 |
|:------|:--------|
| 朱元璋 | 权能建构、位置上升、决定范围不断扩大 |
| 孙悟空 | 无限复起、不可被最终击倒、极限意志不断重新显现 |

共同点：

```text
主体意志必须进入现实
→ 通过行动与结果成立
→ 外界不能替主体完成最终定义
```

差异：

- 朱元璋偏“把权能越做越大”。
- 孙悟空偏“无论被压到哪里，权能都再次站起来”。

## 7. 误判防线

以下不够单独判为孙悟空式 zx：

- 很耐打。
- 脾气倔。
- 不愿认输。
- 喜欢打架。
- 战斗力强。
- 台词很热血。

必须出现：

```text
外部压制
+ 主体主动复起
+ 意志重新转化为行动
+ 拒绝外界最终定义
+ 权能再次显现
```

## 8. 版本边界

不同文学、影视、动画、游戏版本的孙悟空可能存在不同副元、状态与关系结构。

当前只锁定跨版本人物母型：

```text
典型 zx
= 无限复起
+ 打不倒的不倒翁
+ 人类极限意志
```

具体版本不得未经材料直接混判。

## 9. 召回版

> **孙悟空式 zx：世界可以无数次把他按下去，但不能替他决定结束；他总会重新站起，把意志再次做成现实。**
