# 西游记·齐天大圣孙悟空人物血肉卡 v0.3

> 本卡只指《西游记》中的齐天大圣孙悟空，不泛指所有影视、动画、游戏改编版本。

## 1. 完整人物锚

```text
主十元：zx
副十元：nx
完整结构：zx+nx
结构性质：人物本身自始即有，不是五行山阶段后来生成
关键关系：xn 克 zx，nx 补 zx
```

孙悟空的 zx 是：

- 无限复起。
- 打不倒的不倒翁。
- 人类极限意志。
- 主体意志必须重新进入现实。

孙悟空的 nx 是：

- 在暂时不能掌握方向、行动权与位置时，能够沿着已有条件继续。
- 不主动牺牲自己，也不等于温顺服从。
- 在 zx 不能立即破局时，保存人物继续存在和等待条件变化的能力。

## 2. nx 从求学阶段已经存在

> **孙悟空不是被五行山压住以后才“增加 nx”。他在剧本开始的求学阶段就已经表现出 nx。**

正确理解：

```text
人物从起点就是 zx+nx
→ zx 负责主动出发、求取能力、扩大权能
→ nx 负责在尚未掌握路径与位置时，沿着已有条件继续求学和等待
```

这里先锁定用户确认的结构结论，不擅自把《西游记》具体段落扩写成未经核对的材料证明。后续人物事件卡再逐段补证。

## 3. 五行山不是生成 nx，而是让 nx 显影

五行山是 xn 的高体量结构显影：

```text
时间的庞大积累
+ 秩序、规则与既定安排
+ 已经形成、不能被单次行动取消的巨大结构
= 五行山式 xn
```

标准位置关系：

```text
xn 克 zx
```

齐天大圣再强的即时意志，面对已经积累成山的时间与结构，也只能被克制：

```text
zx 想行动、破局、再次显现
→ xn 取消当下路径与行动位置
→ zx 暂时无法向外执行
```

五行山没有给孙悟空安装一个新的 nx 零件。它只是把人物本来就有的 nx 从阴影里逼了出来。毕竟人物不是剧情走到一半才下载副人格补丁。

## 4. nx 如何补住 zx

```text
稳定人物：zx+nx
→ xn 强力克制 zx
→ zx 的直接行动暂时失效
→ 原有 nx 成为当前主要显影
→ 人物在既定时间和条件中继续存在
→ 条件改变后 zx 再次复起
```

因此：

> **nx 不是把孙悟空变软，而是让原有 zx 在长期不能行动时不被耗尽。**

标准补关系：

```text
zx ↔ nx
```

## 5. 剧本人物锚解释

孙悟空不是先成为 zx，后来变成 nx，也不是五行山以后才成为 zx+nx。

正确结构：

```text
稳定本体：始终是 zx+nx
求学阶段：zx 与 nx 已共同出现
大闹阶段：zx 高显影
五行山阶段：xn 克 zx，nx 高显影
条件解除：zx 再次高显影
```

这是同一个人物在不同压力下暴露完整本性，不是中途换芯。

## 6. 最短动态链

```text
齐天大圣本体 zx+nx
→ 五行山 xn 克制其中的 zx
→ 原有 nx 显影并补住 zx
→ 人物在长期结构中继续存在
→ 条件变化后 zx 再次复起
```

## 7. 防误判

- 不能把孙悟空只判成纯 zx。
- 不能说 nx 是五行山以后才生成。
- 不能把五行山只当成物理重量或普通压迫。
- 不能把 nx 理解成主动牺牲、软弱或服从。
- 不能把所有改编版孙悟空直接套入本卡。
- 本卡锚定的是《西游记》齐天大圣孙悟空。

## 8. 召回版

> **《西游记》的齐天大圣孙悟空从求学阶段起就是 zx+nx：zx 是无限复起的人类极限意志；nx 是在暂时没有方向与行动位置时仍能沿条件继续的副结构。五行山的 xn 没有创造 nx，只是克制 zx 并迫使原有 nx 显影，直到 zx 再次站起来。**
