# 西游记·齐天大圣孙悟空人物血肉卡 v0.2

> 本卡只指《西游记》中的齐天大圣孙悟空，不泛指所有影视、动画、游戏改编版本。

## 1. 完整人物锚

```text
主十元：zx
副十元：nx
完整结构：zx+nx
关键关系：xn 克 zx，nx 补 zx
```

孙悟空的 zx 是：

- 无限复起。
- 打不倒的不倒翁。
- 人类极限意志。
- 主体意志必须重新进入现实。

孙悟空的 nx 是：

- 在行动权、选择权和位置被长期锁住时，仍让主体继续存在。
- 不是主动牺牲，也不是温顺服从。
- 是在不能立即破局的阶段，不让 zx 消失。

## 2. 五行山关系

五行山不是普通重量，而是 xn 的结构性显影：

```text
时间的庞大积累
+ 制度与秩序的积累
+ 已经形成的巨大结构
= xn
```

标准位置关系：

```text
xn 克 zx
```

齐天大圣再强的即时意志，面对已经积累成山的时间与秩序，也只能被克制：

```text
zx 想行动、破局、再次显现
→ xn 取消路径与行动位置
→ zx 暂时无法向外执行
```

这不是 zx 不够强，而是 zx 的极限意志仍然有明确克制者。

## 3. 为什么会加 nx

```text
xn 克 zx
→ zx 无法立刻行动
→ nx 副元显影
→ 人物在既定时间与安排中继续存在
→ 等待条件变化
→ zx 再次复起
```

因此：

> **nx 不是把孙悟空变软，而是让 zx 在长期不能行动时仍能被保存。**

标准补关系：

```text
zx ↔ nx
```

## 4. 剧本人物锚解释

孙悟空不是先变成 zx、后来又变成 nx。

正确理解：

```text
稳定本体：zx+nx
平常主要显露：zx
遭遇五行山式 xn 压力：nx 显影
条件解除：zx 重新显影
```

这是同一个人物在不同压力下暴露完整本性，不是中途换芯。

## 5. 最短动态链

```text
齐天大圣 zx
→ 被五行山 xn 克制
→ nx 显影并补住 zx
→ 形成 zx+nx
→ zx 最终再次复起
```

## 6. 防误判

- 不能把孙悟空只判成纯 zx。
- 不能把五行山只当作物理压迫。
- 不能把 nx 理解成主动牺牲或软弱。
- 不能把所有改编版孙悟空直接套入本卡。
- 本卡锚定的是《西游记》齐天大圣孙悟空。

## 7. 召回版

> **《西游记》的齐天大圣孙悟空是 zx+nx：zx 是无限复起的人类极限意志；xn 的时间、制度与巨大积累可以把它压住；nx 则让这股意志在无法行动的阶段继续存在，直到 zx 再次显现。**
