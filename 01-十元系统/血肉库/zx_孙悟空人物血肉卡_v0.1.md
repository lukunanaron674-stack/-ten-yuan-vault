# 西游记·齐天大圣孙悟空人物血肉卡 v0.4

> 本卡只指《西游记》中的齐天大圣孙悟空，不泛指所有影视、动画和游戏改编版本。

## 1. 稳定结构

```text
主十元：zx
副十元：nx
完整结构：zx + nx
```

最短人物锚：

```text
zx：骑到所有人头上的齐天大圣、无敌之姿。
nx：后续进入既有神仙与人情网络，求人、借力、请救兵、借法宝办事。
```

## 2. zx 主轴：齐天大圣的无敌之姿

孙悟空的 zx 不以“执行力”或“耐打”作为首要证据，而以主体权能凌驾为核心：

- 与天齐名。
- 不接受既有等级把自己压在下面。
- 直接闯入最高秩序。
- 骑到所有人头上。
- 让天庭、神仙与规则围绕他的力量重新反应。
- 形成公开、张扬、醒目的无敌之姿。

```text
主体力量公开显现
→ 既有等级被冲破
→ 所有人必须正面回应他
→ 孙悟空成为更高的决定力量
= zx 高显影
```

“被压制后复起”仍可作为 zx 动态血肉，但不是孙悟空 zx 的唯一主骨。若只写“打不倒”，会把齐天大圣缩成耐受型角色，丢掉骑到世界之上的权能姿态。

## 3. nx 副轴：人际关系、人情世故与求人办事

取经过程中的大量问题，不是孙悟空靠单独武力直接压过去，而是通过已经存在的神仙、身份与权限网络解决：

- 找土地问情况。
- 找龙王、天庭和各路神仙。
- 请观音或其他更高权限者出面。
- 借法宝。
- 请救兵。
- 利用旧交、身份、职责和人情接口获得帮助。

```text
问题超出自己当前权限或直接武力范围
→ 进入既有关系网络
→ 求人、借力、借身份与权限
→ 得到解决资源
= nx 高显影
```

这不是说孙悟空整体没有主见。人物主轴仍是 zx。这里判断的是**关系功能与办事路径**：方向与权限掌握在别人和既有秩序手中，孙悟空需要沿关系通道推进。

## 4. zx 与 nx 的交替显影

孙悟空的 zx+nx 常见动态：

```text
直接战斗、压过对手：zx
→ 遇到单靠武力无法解决的身份、法宝或权限问题
→ 求人、借力、走神仙关系网：nx
→ 获得法宝、救兵或许可
→ 再次直接行动并压过对手：zx
```

因此 zx↔nx 的互补不是“强与弱”，也不是“领导与服从”，而是：

```text
zx：直接用自己的权能做成。
nx：通过已有关系与权限借力做成。
```

## 5. 五行山的正确位置

五行山仍可作为外部高体量 xn 场景：

```text
已经成立的规则、时间与结构
→ 克制孙悟空当下 zx 的直接显现
```

但五行山不再作为孙悟空 nx 的核心证据，也不能写成：

```text
纯 zx 孙悟空
→ 被五行山压住
→ 后天长出 nx
```

本卡锁定的 nx 证据主要来自后续反复出现的人情、求人、借力和权限网络。五行山只说明外部 xn 能克制 zx，不负责制造人物副元。

## 6. 求学阶段的处理

“求学阶段已经充分证明 nx”不再作为强锁定句。求师、拜师、接受传授可以提供 nx 候选，但需要逐段材料区分：

- 是沿既有师徒与传授关系推进，还是 nx。
- 是主动求取并扩大权能，还是 zx。
- 是长期学习、训练、节点积累，还是 xn。

在没有逐段原著事件卡前，不用求学阶段替后续关系结构抢证据。

## 7. 对象分层

### 人物稳定本体

```text
zx + nx
```

### 高显影 zx 状态

- 齐天大圣。
- 大闹天宫。
- 公开战斗与夺位。
- 以无敌姿态压过对手。

### 高显影 nx 行为 / 关系功能

- 求人。
- 请救兵。
- 借法宝。
- 找有权限者处理。
- 进入既有神仙关系网。

### 外部 xn 场景

- 五行山式长期结构。
- 天庭的制度、身份与权限层级。

## 8. 防误判

- 不能把孙悟空只判成纯 zx。
- 不能把 nx 解释成软弱、服从或没主见的整体人格。
- 不能把孙悟空的 nx 只归因于五行山压制。
- 不能把求人、借力和走关系自动判为 xn。
- 不能因为孙悟空会战斗，就把所有行为都归 zx。
- 不能把幕后掌控误判为 nx，幕后控制属于 x。

## 9. 召回版

> **《西游记》的齐天大圣孙悟空是 zx+nx：zx 是与天齐名、骑到所有人头上的无敌权能；nx 是取经途中进入既有神仙和人情网络，求人、借法宝、请救兵、借权限把事情办成。五行山是外部 xn 克 zx，不负责制造 nx。**
