# nx 暗算看牌 · 人物血肉库

> 纯nx = **把自己让没的人**
> 结算/清算/暗算是异化nx——分别带了zx/xz/x

---

## 1. 纯nx版（核心模板）

| 层 | 内容 |
|:--|:----|
| **is-a** | 龟男、老好人、受气包、小透明、工具人、窝囊人、不敢拒绝的人 |
| **has-a** | 旧外套、通勤包、别人塞给他的任务、未读消息、借来的东西、普通制服 |
| **behaves-as** | 忍、让、吞、躲、跟、装没事、先答应、不拒绝、把自己往后放 |
| **carries** | 表面和平、关系压力、别人的情绪、别人的需求、自我消失、不能说"不"的惯性 |

> **is-a：老好人；has-a：别人交给他的包；behaves-as：一直说"没事"；carries：自己被一点点让没。**

## 7. 纯nx最高频组合

### A. 龟男型
```
is-a：关系里的龟男
has-a：对方丢给他的情绪和任务
behaves-as：先低头、先道歉、先说算了
carries：维持和平直到自我消失
```

### B. 老好人型
```
is-a：老好人
has-a：所有人都能麻烦他的时间
behaves-as：不拒绝、不抱怨、笑着接下
carries：被需要感和自我空洞
```

### C. 小透明型
```
is-a：人群里的小透明
has-a：普通衣服、普通包、普通座位
behaves-as：跟着走、坐边上、不出声
carries：低存在感和被漏看的习惯
```

### D. 受气包型
```
is-a：受气包
has-a：别人的怒气、误会、烂摊子
behaves-as：吞下去、装没事、继续做事
carries：长期委屈和不敢爆开的怒
```

## 8. nx加料对照表

| 公式 | is-a | has-a | behaves-as | carries |
|:---|:----|:-----|:----------|:-------|
| **纯nx** | 龟男/老好人 | 普通物件 | 忍让吞躲 | 自我消失 |
| **nx + n** | 低阶守夜人/文员 | 工牌/记录册 | 值守/登记 | 职责压力 |
| **nx + z** | 沉默但有线的人 | 一个亮色物件 | 不说但会显现 | 尚未消失的自我 |
| **nx + x** | 忍到发黑的人 | 破损物/旧伤 | 表面忍，内里烂 | 怨气 |
| **nx + nz** | 讨好型照顾者 | 围巾/药/饭盒 | 照顾、补关系 | 怕关系断 |
| **nx + zn** | 苦行者 | 经卷/灯/旧符 | 忍耐、修行 | 把忍解释成意义 |
| **nx → zx** | 迟来反击者 | 藏起的刀 | 忍到最后出手 | 迟来的选择 |

## 9. 最好用的一组nx入口

```
is-a：把自己让没的人
has-a：别人留下的东西
behaves-as：顺着关系和日常继续走
carries：一个不属于自己的后果
```

## 10. 最狠封存句

> **nx的is-a不是英雄，而是关系里的缓冲垫；
> has-a不是神器，而是别人塞来的东西；
> behaves-as不是行动，而是忍让吞躲；
> carries不是伟大使命，而是自我被一点点让没。**
