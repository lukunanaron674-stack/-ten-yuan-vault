# nx 顺着走 · 人物血肉库

> **纯 nx = 不主动占据选择、方向和位置，别人怎么安排，就先怎么继续。**

> **“把自己让没”是 z 持续克制 nx 后的结果，不是纯 nx 的主动本体。**

## 0. 判定锁

### 纯 nx

```text
已有方向 / 安排 / 流程
→ 不主动改写
→ 不主动成为选择者
→ 让别人或现状决定下一步
→ 自己顺着继续
```

### z 克 nx

```text
z 持续显现、要求、决定、占位
→ nx 不主动抢回位置
→ nx 持续退位
→ 最后把自己让没
```

### 对象层锁

本卡描述的是人物血肉入口，但任何例子都必须先拆开：

```text
人物稳定本体
当前人物状态
关键行为功能
外部场景
时间关系 / 时间结构
视觉与光影
关系变化与动态链
```

- 一次跟随、服从或等待，只能证明当下行为候选，不能直接证明人物本体为 nx。
- 人物长期、反复把方向交给别人或现状，且拿掉这一点后存在方式会崩，才可提高人物本体 nx 的置信度。
- 军队、学校、监狱、公司、家族、流程、制服与排班表都只是场景或题材证据，不自动赋予 nx 或 xn。
- 光影中的弱位、边缘位、低对比与跟随构图，只能辅助视觉判断，不能代替人物判定。

### 排除

- 为等待反击时机而忍，不直接判纯 nx。
- 为完成明确目标而服从，不直接判纯 nx。
- 因规则、纪律和时间表行动，不能只凭“规则存在”判 xn；必须检查主体是否主动组织计划、记录、节点、流程或隐藏结构。
- 只是接受既有规则并继续执行，可保留为 nx 行为候选，但仍不能越级判人物本体。
- 主动照顾、主动承接别人，优先检查其他关系结构。
- 看牌、记账、清算、翻底牌，移入 xn 候选池，执行部分另查 zx。

## 1. 纯 nx 核心模板

| 层 | 内容 |
|:--|:----|
| **is-a** | 随安排的人、跟着走的人、没主意的人、习惯说“你们定”的人、被动参与者 |
| **has-a** | 别人分配的物件、既定路线、通知单、集体名单、轮到自己的任务 |
| **behaves-as** | 跟、等别人选、默认、照安排做、不主动改方向、事情落下就继续 |
| **carries** | 外包的选择权、现状惯性、低主动性、没有自己定下的下一步 |

> **is-a：随安排的人；has-a：别人给出的路线；behaves-as：说“我跟着就行”；carries：选择权始终没有回到自己手里。**

> 上述词只是召回入口。正式判定仍需通过拿掉测试、起手测试、最近邻排除与对象层拆分。

| **is-a** | 通勤者、排队的人、公司普通职员、集体宿舍成员、家庭里被安排的人 |

注意：通勤者、职员、排队者不是 nx 身份标签；只有反复“不建立方向、沿已有方向继续”的结构成立时，才进入 nx 检查。

|:--|:----|

最小边界：

```text
接受并沿既有流程继续，不主动改写方向 → nx 行为候选
主动设计流程、安排节点、记录信息并利用积累 → xn 行为或状态候选
```

## 7. z 克 nx 的高频社会形态

这些不是纯 nx 的全部，而是 nx 在 z 持续占位下的常见结果。

### A. 龟男型

```text
z：持续提出要求、占据关系方向
nx：不主动拒绝、不抢回选择权
结果：先低头、先道歉、不断退位，最后把自己让没
```

### B. 老好人型

```text
z / 群体：默认他会接下所有麻烦
nx：事情落下就继续做，不主动推出去
结果：所有人都有他的时间，只有他没有自己的时间
```

### C. 受气包型

```text
z：持续释放怒气、要求和判断
nx：不主动对抗，顺着让冲突过去
结果：别人把他的沉默当作可以继续越界
```

### D. 被默认懂事型

```text
家庭 / 群体中的 z：替他决定什么才是正确选择
nx：不主动建立自己的方向
结果：越懂事，越没有自己的位置
```

## 8. nx 加料对照表

| 结构 | 核心变化 | 人物表现 |
|:----|:---------|:---------|
| **纯 nx** | 不主动占位，顺着已有安排 | “你们定，我跟着” |
| **z 克 nx** | z 持续占位，nx 持续退位 | 把自己让没 |
| **nx + n** | 被动继续中带了承载重量 | 事情落下就接着扛 |
| **nx + z** | 低主动性中仍保留一条自我方向 | 平时随和，但有一件事不让 |
| **nx + x** | 被动延续被欲望或怨气污染 | 表面跟随，内部发黑 |
| **nx + nz** | 顺着关系继续，同时产生依恋承接 | 不主动选择，却舍不得离开 |
| **nx → zx** | 长期被动后终于主动选择路径 | 第一次说“不”，第一次自己决定 |

> 上表为血肉对照，不自动代表正式生克关系；除 `z 克 nx` 外，其他关系仍需查表并通过关系语义验收。

> `nx → zx` 只描述状态、行为或显影切换，不自动表示人物稳定本体被改写。

## 9. 图像怎么画才有用

### 纯 nx 单图

- 多条路前看向别人。
- 队伍已出发，他自然跟在最后。
- 会议中所有人举手，他最后跟着举。
- 手里拿着别人分配的东西，没有主动选择痕迹。

这些图只能表现视觉或行为候选。单张图不能单独证明人物主十元。

### z 克 nx 连续图

1. z 先决定。
2. nx 没有反对。
3. z 再向前占一格。
4. nx 再向后退一格。
5. 最终 nx 仍在画面里，却没有自己的位置。

连续图的价值在于显示关系过程，而不是用弱姿态、暗光或边缘构图替代关系证明。


## 11. 封存句

> **纯 nx 不是主动牺牲，而是主动性没有站出来；
> z 克 nx 不是一次退让，而是 z 一直占位、nx 一直不抢回，最后自己被让没。**
