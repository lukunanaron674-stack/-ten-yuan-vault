# nx 人物血肉卡 v1.4

> **nx 的人物血肉分成两层：纯 nx 人物本体，以及其他强主体使用的 nx 关系功能。**

## 1. 纯 nx 人物

核心：

```text
方向已经存在
→ 不主动改写
→ 让别人、群体或现状决定
→ 自己顺着继续
```

高频人物感：

- 没主见的人。
- 老板安排什么就做什么的员工。
- 总说“你们定”的人。
- 跟着家庭、群体或流程走的人。
- 不愿成为最终选择者的人。

这类人物不是一定善良、温柔或聪明。关键是方向决定位置长期不在自己这里。

## 2. z 克 nx 的人物结果

```text
z 持续表达、决定和占位
→ nx 不主动抢回位置
→ 选择与声音持续减少
→ 高体量时把自己让没
```

老好人、受气包、关系缓冲垫等，可以是这一关系结果，但不能替代 nx 主骨。

## 3. nx 关系功能人物

强主体也可以反复使用 nx 关系路径：

- 求人。
- 借力。
- 托关系。
- 找有权限的人。
- 借法宝、请救兵。
- 通过旧交、身份和既有秩序取得资源。

这类人物总体可以非常有主见，因为判断对象是某段关系功能，不是整体人格。

## 4. 孙悟空

```text
人物稳定结构：zx + nx
zx：齐天大圣、骑到所有人头上的无敌权能。
nx：取经途中进入神仙关系网，求人、借法宝、请救兵。
```

孙悟空不是纯 nx 人物。他是强 zx 主体稳定使用 nx 办事路径的标准案例。

## 5. 与 xn 的人物差异

```text
老板安排什么就做什么：nx。
接到目标后主动排程、搭流程、分资源、预判节点：xn。
```

成熟老员工常见 xn 主，可带少量 x 与 n 质地，不应因为职业服从表面判 nx。

## 6. 与 x 的人物差异

```text
沿关系网求人办事：nx。
控制整张关系网、地盘、钱和手下：x。
```

唐人街幕后 Boss 是 x，不是 nx。

## 7. 误判

- 沉默强者不自动是 nx。
- 幕后操盘者不自动是 nx。
- 聪明观察者、记账者与等待结算者优先检查 xn。
- 一次服从或求人只证明行为候选。
- 主体整体有主见，不排除其具备 nx 副元或关系功能。

## 8. 召回版

```text
纯 nx：没主见，顺着别人安排继续。
nx 关系功能：权限在别人手里，通过求人、借力和人情网络办事。
孙悟空是 zx+nx，不是纯 nx。
```
