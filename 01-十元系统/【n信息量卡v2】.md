# 【n 信息量卡 v2.0】

> **n = 对象真实进入主体或结构内部，被允许留下，并由该主体或结构跨阶段接收、处理、保护和承担其持续负荷。**

## 1. 核心本体

```text
对象进入内部
→ 没有被立刻拒绝、推出或转移
→ 获得真实位置
→ 其时间、空间、照护、风险或资源负荷被持续处理
→ 外部压力下仍保有一定接收与抗崩能力
→ n
```

最短定义：

> **n = 真正接住，并让它在内部继续存在。**

核心变量：准入、内部位置、持续处理、负荷承担、保护连续性、成员互信、反复返回、结构抗崩能力。

## 2. n 不是什么

- 不是被动、受气、忍耐或情绪稳定；
- 不是善良、圣母、母亲、家庭与房屋题材；
- 不是一次帮忙、收留、捐助、救援或接任务；
- 不是“不拒绝”这一个动作；
- 不是只把对象关在内部；拘禁、封锁和无法退出不等于承载；
- 不是主体沿别人安排做事，那是`nx`；
- 不是主动组织流程，那是`xn`。

## 3. 必要条件

稳定`n`至少满足：

1. 对象或成员真实进入内部；
2. 获得可持续位置，而非一次停留；
3. 主体承担对象产生的现实负荷；
4. 存在处理、保护、补给、照护或内部协调；
5. 外部压力下仍保持一定接收能力；
6. 对象不是被强制扣留。

## 4. 对象分层

- 人物本体：长期以接住、容纳和持续处理为存在方式。
- 状态：某阶段承担进入内部的对象或负荷。
- 行为：接收、照护、保护、内部处理、维持。
- 关系：成员能进入、留下、返回并被持续接住。
- 场景：家庭、医院、避难所、共同体只是候选载体。
- 视觉：容器、房间、土地、怀抱只作辅助证据。

## 5. 最近邻

```text
n vs nx：n接住对象并处理负荷；nx沿外部方向与通道推进。
n vs nz：n负责内部承载；nz负责自由离开后的可信回返与修复。
n vs xn：n承担负荷；xn主动把处理经验组织成可持续流程。
n vs zn：n回答“谁被接住并怎样留下”；zn回答“什么不可被抛下、为什么”。
n vs x：n允许对象在内部存在；x强调对象归我掌握、由我决定和调用。
n vs x并z：n是内部真能接住；x并z是外部可识别和可进入的公共壳。
```

## 6. 拿掉与反向

- 拿掉房屋、家庭称谓、暖色和照顾台词，检查是否仍有真实准入与持续负荷处理。
- 若对象只能进入不能退出，检查`x/xn/zx`控制结构。
- 若只是一次救援后立刻转交，最多是行为层。
- 若负荷重复后主体主动形成流程，目标`xn`可上升，但不能反写成`n=xn`。
- 取消内部位置与持续处理后，承载应明显下降。

## 7. 关系接口

```text
zn 生 n
n 生 xn
zx 克 n
n 克 xz
n ↔ x并z（补）
```

是否正式启动必须查关系正本。

## 8. 召回版

```text
n = 对象真实进入内部，被允许留下，并被跨阶段接收、处理、保护和承担负荷。
房屋、家庭、忍耐和一次帮助都不能单判。
```
