## 1. 核心本体（主骨）

**主骨公式**
欲望 + 吞噬 + 现象之流——不是「坏人/毁灭/黑暗」，是「它想拥有/吃掉/溶解一切，因为它没有自己的形状」。

**一句话解释**（不是「邪恶/反派/黑暗」，而是「它想要——而且它不会停下来，因为它停下来就不是它了」）
- ❌ 不是：反派、坏人、黑暗面、深渊、毁灭性
- ✅ 是的：一种向外扩张的力量——它在不断吞噬、吸收、溶解周围的东西，不是因为恨，是因为**停下就意味着不存在**

**确认过的关键表述**：
> x是十元中唯一一个「没有自己的形状」的符号。它通过吞掉别的东西来获得存在感。你看到x的时候，看到的是一个在吃的形状——不是它自己的形状。

**三种呈现形态（空间型钧分析确认）**：
1. **主动吞噬（物理）** — 来自深渊的上升诅咒：胃在消化探窟家。x有主动意志
2. **隐形渗透（心理）** — MOAN的山村诅咒：x在边界偷偷渗入。x没有主动意志但有渗透路径
3. **静默荒芜（空间）** — 少女终末旅行的废墟：空间停止提供服务，角色被存在的遗忘吞噬。x是「近于无」但在慢慢消化

**不要和以下混淆**：
- x ≠ 邪恶（邪恶是道德判断。x可以是中性的——欲望本身不是恶）
- x ≠ 反派（反派可以是任何十元。x的角色不一定坏，坏的角色不一定x）
- x ≠ 黑暗/深渊（黑暗是视觉语义，深渊是空间隐喻——真正的核心是「吞噬」的动作）
- x ≠ 毁灭（毁灭可以是zx的执行结果——炸掉一座城。x是吃掉一座城——不是为了毁灭，是为了拥有）

## 2. 第一体感

> 不是「他很坏」，不是「世界很黑暗」。
> 而是「有一个东西在不停地想要——而且它永远不满足」。

- ❌ 误：邪恶、黑暗、反派、恐怖
- ✅ 正：一张嘴——不是在咬人，是在不停地吞，因为它不吞就会消失

**体感关键词**：渴望、不满足、吞食、扩张、溶解、无底洞、永不饱

## 3. 人物层

| 面向 | 描述 |
|:----|:-----|
| 核心性格 | 欲望驱动——想拥有更多，想体验更多，想溶解更多。不是因为他需要，是因为他停不下来 |
| 角色类型 | 掠夺者 / 饕餮者 / 不满足者 / 永远的consuming machine / 没有内部核心的人 |
| 灵魂问题 | 「还能有更多吗？」——不是「还差多少」，是「还能吃」 |
| 标签陷阱 | ❌ 不是「贪婪」——贪婪是欲望的一个侧面。x比贪婪更原始：它不是在追求超额，它是天生就吃不饱 |

**典型角色示意**：
- **BLUE GIANT的爵士** — x的「更多即运动」形态：不是欲望对象驱动（我想要某样东西），是「更多」本身就是运动形式。爵士中即兴演奏的持续——不是想好了再吹下一句，是想吹下一句所以吹了。停在好听的地方不是目标，继续才是。这不是x主的人（那是汉尼拔），这是x作为物质底层的存在——音乐本身在流动、在吞噬、在扩张，演奏者只是通道
- **京本（蓦然回首）** — x的「不画就难受」形态：京本不是z（被光点击中才画），不是zn（画漫画是信念）。她是——「不画就难受」。画漫画不是她的选择，是她的存在方式——像呼吸一样，不呼吸就不舒服。这不是欲望驱动的「想要更多」（标准x），是存在层面的「不停下来」：她没有离开漫画的选择，因为停下她就不存在了。这是x的一个特殊子型——**存在性x**：不是主动吞噬，是如果不继续运动就会消失
- **汉尼拔·莱克特（沉默的羔羊）** — x主+zn辅：汉尼拔的x不是一般意义上的吃人——他在品尝人的本质。他的欲望是有品味的、有审美的、有认知的——但底层仍然是欲望：他想知道人是什么样的味道。x和zn的完美互补对子——汉尼拔的x需要克拉丽丝的zn来「配餐」。
- **白鲸（白鲸记）** — x的纯粹物化：亚哈船长追的是z，但白鲸是x。它在深海中游荡、吞掉水手、摧毁船只——不是因为它恨人类，是因为这就是它存在的状态：吃和毁灭是其本能。
- **鬼母（MOAN山村）** — x的隐形渗透形态：她没有出来咬人，但诅咒在慢慢渗入山村。山村的边界在变薄，空气在变质。x在MOAN中的存在方式是渗透不是突袭——这和汉尼拔的优雅吞噬形成了x光谱的两端。
- **小丑（黑暗骑士）** — x主+xz辅：小丑不是传统意义的反派——他不是为了钱、不是为了权力、不是为了复仇。他是为了**看世界燃烧**（watch the world burn）。毁灭不是手段，是目的——吃秩序让他获得存在感。

**反例·容易误标但实际不是x的**：
- 有欲望的坏蛋 → 大多数电影反派是zx（有目标）或z（执念）或nz（被背叛后的报复）。x的核心是「欲望本身没有方向」。
- 大反派/灭世者 → 灭霸是zx+n（目标执行+愿景）；萨诺斯的毁灭是为了意义不是欲望。x毁灭是为了毁灭本身。
- 黑暗风格主角 → 蝙蝠侠是z+zn（执念+信念），不是x——他想保护哥谭，不是在消费哥谭。
- 贪婪的资本家 → 贪婪是z（追逐更多）+ x（想拥有更多）的复合。纯x的资本家很少——纯x的角色往往没有规划能力。

## 5. 空间层

x成立的空间，都是**有吞噬感、不满足感、边界在消失**的：

|| 空间类型 | 映射强度 | 示例 |
||:--------|:-------:|:-----|
|| 吞噬空间 | **9** | 深渊、怪物的胃、大漩涡、燃烧的建筑——空间在被消耗 |
|| 消耗空间 | **8.5** | 赌场、欲望街、战场尸体堆——在空间里东西在消失 |
|| 无边界空间 | **9** | 海、宇宙、空洞——看不到边界的空间让人恐惧不是因为它大，是因为它一直在吞 |
|| 边界被侵蚀的空间 | **8.5** | 鬼母山村——空间在慢慢变质，边界变薄 |
|| 渗透空间 | **8** | 水下的世界、病毒传播的路径——入侵性的、不可见的 |
|| 没有容器的欲望 | **8** | 纯粹的欲念场域——不是物理空间，是欲望场景（权力的游戏中的铁王座之争） |

**关键规则**：x的空间必须有**不可满足性**——站在里面的人会感到「吃永远不够」。x的空间是**正在消失的空间**——不是已经没了（那是少女终末旅行），是在消失的过程中。

- ✅ 深渊（来自深渊）— 越往下越深，探窟家被消化得越彻底
- ✅ 燃烧的城市（黑暗骑士）— 秩序被火焰吞掉的过程
- ✅ 赌场（任何作品）— 永不满足的欲望空间
- ❌ 一个已经毁坏的废墟（不是x的空间）— 那是已经结束的空间，不是正在被吞噬的空间
- ❌ 一个规则井然的法庭（不是x的空间）— 这是xn——规则空间

## 8. 常见互补（对子关系）

| 互补对 | 含义 | 典型效果 |
|:-------|:-----|:---------|
| **x ↔ zn** | 欲望 + 意义 | 本体型核心对子——x的深渊需要zn的意义来证明自己。没有吞不下，欲望不知道自己在吞什么。zn补x：信仰靠近深渊，深渊需要被看见 |
| **x → x并z** | 欲望 → 包装 | x生x并z：欲望要满足先要套一个壳。金家伪装身份进入朴家（寄生虫）——x并z是x实现自己的工具 |
| **x ↔ n** | 吞噬 + 承载 | 核心对抗对子——x在吞噬，n在承接。x克n：欲望可以压垮承载者。但当n的承载质上超过x的吞噬量时，n可能中和x |
| **x ↔ z（克）** | 欲望 + 执念 | x克z：追光者的光被深渊吞掉。z在x面前几乎没有抵抗力 |
| **x克nz** | 欲望击穿等待 | 柔情在欲望面前没有还手之力 |

**对应五大主题**：x是本体型（zn+x）的核心符号。同时在空间型中作为次维/辅维大量出现（来自深渊、MOAN、少女终末旅行）。

|:---------|:---------|:---------|
| **x被zn污染** | 欲望被意义合理化 | «我吞噬是因为这是对的»——x的最危险形态，因为堕落有了正当性 |
| **x被z污染** | 从吞噬变执念 | 欲望开始聚焦在一个目标上——不再是万物皆想吃，是只要那一个 |
| **x被xn污染** | 从吞噬变成有计划的占有 | 吞噬开始切分对象、判断价值、安排顺序与等待节点——不再单纯「吃」，而是「算着吃」 |
| **x被n污染** | 从吞噬变承载 | 欲望开始被容器包裹——x的流动性被n的稳定性压住 |

**反向污染**：其他十元被x侵蚀
- **n被x污染** — 从承载变被吞噬——n角色开始被事情压垮、消化、耗尽。接住后没有处理的环节，只剩承受痛苦——来自深渊中n的抵抗态
- **z被x污染** — 追逐变成占有——从«我想被看见»变成«我必须拥有你»
- **zx被x污染** — 执行变成欲望——路径推进从«做成本身就是意义»变成«做完就能拥有»
- **xz被x污染** — 临界行动变成猎杀——漂流者变成捕食者

## 10. 禁止误判（核心防线）

| ❌ 误判 | ❌ 误判原因 | ✅ 正确归属 |
|:-------|:-----------|:-----------|
| 「反派/坏人」→ x | 绝大分反派是zx（目标执行）或z（执念）或nz（报复）。x反派反而少见 | 问角色核心：他使坏是因为有目标（zx），还是因为停不下来（x）？ |
| 「黑暗/黑暗系角色」→ x | 黑暗是视觉语义，不是十元结构。蝙蝠侠很黑暗但他是z+zn | 黑暗感在十元中可以是xz（临界/危险道路）或n（承载无力）或任何符号在特定环境中 |
| 深渊/地狱 → x | 深渊的空间感可能xz（向下边缘）或x并z（包裹外壳） | 深渊（来自深渊）是的x，因为它在消化、召唤、分层吞噬。但一般意义上的深渊可能是xz向下？ |
| 「恐惧/恐怖」→ x | 恐惧是情绪，不服务于x。MOAN的恐怖是x的渗透，但普通恐怖片可能是xz（临界感）或x并z（包装恐惧） | 核心不是恐怖的强度，是「恐怖的来源在不在吞噬」 |
| 「毁灭/毁灭性角色」→ x | 毁灭可能是zx的执行（炸掉楼），可能是z的冲动（打碎东西），可能是xn的效率（清理物种） | x的毁灭是有吞噬感的——它在吸收，不是简单搞破坏 |
| 「贪婪/贪得无厌」→ x | 最接近x的误判——但贪婪也可能是z的「被看见」×重复（要我更多认可） | 问：ta吃了是想要更多（→x），还是吃了要证明自己够资格（→z/zn）？ |

**一句话防误判**：
> 如果去掉「没有自己形状 + 不断想吃 + 永不满足」三个要素，角色还像x——那它一定不是x。x的灵魂不是黑暗/毁灭，是**存在即吞咽**——它不吞的时候，它不存在。

## 附录B：创作版快捷入口（7-8级信息量）

```
[x]角色设计：
- 不是规划者——ta凭欲望行事，没有长期策略
- 核心动作：靠近目标→打开→吞入→消化→找下一个
- 神态：不是愤怒——是**饥饿**。眼睛不是凶狠的，是空虚的——因为吞得再多也填不满
- 手部：抓、握、撕扯、捧起、送入口中——不是优雅地触碰（zn），是「我的」
- 身体姿态：微前倾、重心不稳定——随时可以扑出去
- 衣服：深色、但不一定破旧——可以是精致的，但精致感下面有种「会被消耗」的意味
- 站位：在边界上——不是在边缘（xz），是在边界线外——因为x不承认边界

[x]三种呈现形态：
1. **主动吞噬（来自深渊·上升诅咒）** — 物理的、强力的、不可逆的。x有吸引力场（召唤探窟家），渗透后潜伏在目标内部，离开时触发吞噬。x的强度按深度分层递进，每层不同形态诅咒——不是一次性吞噬，是循环往复的递进吞噬
2. **隐形渗透（MOAN·山村诅咒）** — 无声的、缓慢的、从边界渗入的。x从边界变薄处渗入，角色尚未察觉已被包裹
3. **静默荒芜（少女终末旅行·废墟）** — 近于无的、空间停止服务的、慢慢消化。x已吃完一切，只剩空间的空壳

[x]三形态关系图：
```
x_自然（现象本体·深渊基底） ← 基底
    ↓ 指向性激发
x_欲望（召唤·在个体中回响） ← 在目标中激发的欲望
    ↓ 与n接触
x_界面（诅咒·可观测后果） ← x与n交互时的「证据」
```

忌：
- ❌ 不要把x画成一直愤怒——x不愤怒，x是饿。愤怒是z的
- ❌ 不要把x画成一直破坏——破坏是zx的。x可以非常安静地吞
- ❌ 不要把x画成拥有很多——x拥有不了任何东西，x吞下去的东西最终不属于x
- ❌ 不要把x当成纯反派标签——x角色可以很迷人（汉尼拔）
```

## 附录C：动态链（9-10级信息量）

```
常见链1：x → x并z（欲望→包装）
  描述：欲望要满足需要先套一个壳。x不直接露出来，它通过包装去获得
  作品例：寄生虫——金家的生存欲（x）驱动了他们伪造身份（x并z）
  动画：x(想要活下去) → x并z(伪装进入朴家) → x并z被nx发现(伪装被戳破) → x(欲望失控)

常见链2：x 克 z（欲望吞噬执念）
  描述：追光者的光会被深渊一口吞掉——z面对x几乎没有抵抗力
  作品例：小丑——亚瑟每次想被看见（z）都被哥谭的恶意（x）摁回去
  动画：z(我想被看见) → x(城市在吞) → z(再试一次) → x(吞得更深)

常见链3：x 克 nz（欲望摧毁柔情）
  描述：x对nz的克制关系几乎总是成立——柔情在欲望面前没有还手之力
  作品例：苦月亮——咪咪管不住奥斯卡
  动画：nz(我还爱着你) → x(欲望在扩张) → nz 克 x失败 → x(吞噬一切)

常见链4：x → n（被承载——当x进入n的容器）
  描述：x需要被n承载才不会失控——但n承载x的过程也是消耗n的过程
  作品例：来自深渊——探窟家的n承载着深渊的x诅咒
  动画：n(承载者) → x(深渊的欲望/诅咒进入) → n(承载着消化) → n抵抗(在x中保持承载姿态不垮掉)

常见链5：zn ↔ x（本体型经典对子）
  描述：zn的意义需要x的深渊来证明自己——x需要zn的意义来品尝自己
  作品例：沉默的羔羊——汉尼拔(x)和克拉丽丝(zn)的对望
  动画：zn(我要救她) → x(深渊——汉尼拔) → zn(信念在黑暗中发亮) → x(深渊的欲望被信念吸引)

x的空间型全链（三种呈现）：
  MOAN：x(山村边界变薄) → x(诅咒渗透) → n(村民在承载痛苦) → x(渗透加深)
  来自深渊：x(深渊在下面) → x(上升诅咒——主动消化) → n(探窟家的承载极限) → x(吞噬)
  少女终末旅行：x(空间停止服务) → x(静默荒芜) → n(千户和尤莉在人) → x(空间在慢慢消失)

常见链6：x螺旋递进吞噬链（来自深渊型）
  描述：x的吞噬不是一次性捕获，而是循环往复的递进过程——每次下降-上升的循环不是逃离x，而是x的渗透加深一层。探窟家以为自己每次返回是赢了深渊，实际上每次返回都在为下一轮更深的吞噬做准备
  作品例：来自深渊——第一轮浅层→轻度诅咒→x_欲望被喂养→第二轮更深→中度诅咒→x_执念加强→第三轮深界→重度诅咒→不可逆改变→最终轮→成为深渊的一部分
  动画：x(召唤→渗透浅层) → n(返回→x被喂养) → x(更强的召唤) → n(再下降) → x(渗透加深) → 循环 → n(最终无法返回→x完成吞噬)

全链示例（x的人生观）：
  x(欲望出生——我想要) → x并z(包装——我该如何获得) → x(吞——我得到了) → x(厌倦——这不是我真正想要的) → x(欲望重新膨胀——下一个是什么？)
  ——x的永恒循环：没有终点，因为x停不下来。

常见链7：x的「更多即运动」形态（BLUE GIANT型）
  描述：x的原始形态不总是「欲望渴望得不到满足的对象」，也可以是「更多本身就是运动形式」——即兴演奏中的持续流动：不是想好下一句才吹下一句，是想吹下一句所以吹了。停在好地方不是目标，继续才是
  作品例：BLUE GIANT——宫本大的即兴演奏中那种「永远不够好，永远在下一秒追求更好的音」——这不是z的追求完美（那是目标导向），是x的「吹奏在运动中才存在」
  动画：x(音乐在流动) → x(演奏者在音乐中消失) → x(只有运动在继续) → x(「更多」不是渴望，是运动的自然延伸)

常见链8：x的「存在性x」——不继续就消失（京本型）
  描述：x的一个特殊子型——不是主动吞噬（想要更多），而是「如果不继续运动就会消失」。画漫画不是选择是存在方式，不画就难受。这不同于标准x的「欲望驱动」——京本的x没有「想要更多」，只有「不停下来」
  作品例：蓦然回首——京本画画不是为了被认可（那是z）、不是为了意义（那是zn）、不是为了规则（那是xn）。她是「不画就难受」——她的存在是通过画画的持续运动来维持的。停下就不是她了
  动画：存在性x(不画就难受) → 持续运动(画画中) → x(手在动，意识消失) → 不画？→ 存在性x(画——因为不画就没有我)
```
