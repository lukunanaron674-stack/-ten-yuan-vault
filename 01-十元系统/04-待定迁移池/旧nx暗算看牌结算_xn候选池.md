# 旧 nx 暗算看牌结算 · xn 候选迁移池

> 用户判断：旧 nx 的“暗算、看牌、结算”虽然带因果感，但整体更像 xn。

本池只保存迁移假设，不直接改写 xn 正式定义。

## 1. 当前拆分假设

### 更像 xn 的部分

```text
记录
等待
保存信息
按顺序累积
维持账目
延迟反应
到特定时间 / 节点再处理
依据规则、流程或既定结构结算
```

共同感觉：

> **不是现在出手，而是让信息与时间在结构里累积，等节点成立。**

### 可能带 zx 的部分

```text
主动翻牌
执行清算
推进结果
切断关系
利用已记录信息破局
将等待转化为明确行动
```

共同感觉：

> **xn 保存与等待，zx 在节点到来后推进。**

该公式仍是候选，不是正式对子结论。

## 2. 为什么不再归纯 nx

当前纯 nx 锁定为：

> **不主动占据选择、方向和位置，顺着已有安排继续。**

旧暗算者却往往具备：

- 主动收集信息
- 主动维持隐藏结构
- 主动等待时机
- 最终主动执行结算

这些行为的主动性和结构性，不能继续用纯 nx 的低主动、顺势延续来解释。

## 3. 待校验问题

### xn 侧

```text
1. 记录与等待是否属于 xn 本体，还是只是 xn 行为？
2. “到节点再处理”是否必须包含时间 / 规则 / 流程？
3. 没有正式规则，只有个人账本时，还能不能判 xn？
4. 信息累积与秩序维持的共同根是什么？
5. 暗算是否只是 xn 被其他十元污染后的形态？
```

### zx 侧

```text
1. 翻牌是否属于 zx，还是只是一个普通执行行为？
2. 执行清算必须达到什么主动性与路径推进强度？
3. xn 保存信息 → zx 推进结果，是否是稳定组合？
4. 旧“因果型 zx + nx”是否应重新审为 zx + xn，或其他结构？
```

### 三元侧

```text
1. 旧看牌与 xn 是否有相同三元构成？
2. 纯 nx 与 xn 在“不立即行动”上为何相似，发动机有何不同？
3. 一个是没有主动，一个是主动延迟，是否可作为最小差异？
```

## 4. 最小差异假设

| 现象 | nx 候选 | xn 候选 | zx 候选 |
|:----|:--------|:--------|:--------|
| 不立即行动 | 没主动定方向 | 主动按时间 / 结构延迟 | 等待推进窗口 |
| 跟随流程 | 顺着已有安排 | 以流程为行动依据 | 使用流程打通路径 |
| 保存信息 | 事情落下未推出 | 主动记录并维持结构 | 为下一步行动准备 |
| 到点处理 | 未必主动 | 节点成立后按结构处理 | 主动执行、推进、切断 |

> 最关键差异候选：**nx 是主动性没站出来；xn 是主动把行动放进时间、规则或结构里。**

## 5. 旧词迁移表

| 旧词 | 当前候选 | 备注 |
|:----|:---------|:-----|
| 记账 | xn | 若是主动长期记录 |
| 看牌 | xn / 其他 | 看信息结构，不等于人物本体 |
| 等待时机 | xn | 若有明确节点与延迟结构 |
| 清算日 | xn + zx 候选 | 节点属于 xn，执行另查 zx |
| 翻底牌 | zx 候选 | 若承担推进和切断功能 |
| 暗室 / 档案室 | xn 视觉候选 | 记录与制度空间，不判人物本体 |
| 军师 / 分析师 | 不直接判 | 职业不是十元 |
| 复仇者 | 不直接判 | 动机、时间结构、执行方式分开判 |

## 7. 使用限制

- 本池不能作为 xn 正式准度卡引用源。
- 不能从“像 xn”直接推出生克补关系。
- 不能自动把旧 `zx + nx` 批量改成 `zx + xn`。
- 每个案例必须重新区分本体、状态、行为、场域与结果。
- xn 准度卡完成后，再逐项迁移或退回。
