# zn / z / zx 对错关系轴·信息卡补充 v0.1

> 本卡只补充 `zn / z / zx` 在**人物立场、关系冲突与对错判断领域**中的狭义表现。
>
> 本卡不修正、不覆盖三张十元信息卡原有本体定义，也不得凭本卡单独改写生克补关系。

## 1. 三点总表

| 十元 | 对错关系轴原句 | 核心关系 |
|---|---|---|
| `zn` | **你们都对，我也是对的。** | 多方正确可以并存，自己的正确不以否定别人为条件 |
| `z` | **我是最对的，你们不关我事。** | 自我被放在最高确认位置，别人不进入自己的核心判断 |
| `zx` | **我是对的，你们都是错的。** | 通过否定、排除或压过别人的正确，确立自己的正确 |

最短召回：

```text
zn：并存正确。
z：自我最高，他者无关。
zx：排他正确，他者皆错。
```

## 2. zn 的狭义补充

### 原句

> **你们都对，我也是对的。**

### 狭义定义

在对错关系轴中，`zn` 允许多个主体、多个立场或多个局部答案同时成立。主体坚持自己的正确，但不需要把别人的正确取消，才能维持自身立场。

其结构是：

```text
我有自己的正确
+ 我承认别人也可能有其正确
+ 多个正确可以同时保留
→ zn 的并存式正确
```

### 关键特征

- 自己的意义、原则或选择仍然成立；
- 他者的立场不因与自己不同就自动失去正当性；
- 不要求自己成为唯一正确或最高正确；
- 冲突可以通过理解边界、适用条件或不同位置来并存；
- “我也是对的”不能被吞成“只有你们对，我放弃自己”。

### 不是

- 不是没有立场；
- 不是平均主义；
- 不是所有答案在所有条件下都一样正确；
- 不是为了讨好别人而放弃自身原则；
- 不是“你们都对，但我是最对的”。

## 3. z 的狭义补充

### 原句

> **我是最对的，你们不关我事。**

### 狭义定义

在对错关系轴中，`z` 把自身放在最重要、最高或最值得确认的位置。主体关心的是“我是否成立、我是否被确认、我是不是最对的”，而不是主动裁决所有他者是否错误。

其结构是：

```text
我的正确被推到最高位置
+ 他人的正确与否不进入我的核心任务
+ 我不需要处理、包含或驳倒所有人
→ z 的单点自我确认
```

### 关键特征

- 对自身正确性、价值或精神位置高度集中；
- “最对”表现为自我位置上升，而非必须证明别人全错；
- 他者可以被忽略、绕开或排除出关注范围；
- 重点是“我必须成立”，不是“你必须被判错”；
- 他者的反应只有在涉及自我确认位置时才重新变得重要。

### 不是

- 不是 `zn` 的多方并存；
- 不是 `zx` 的主动否定他者；
- 不是普通自信；
- 不是所有场景中的自我中心都自动判 `z`；
- 不是“别人错，所以我对”。

## 4. zx 的狭义补充

### 原句

> **我是对的，你们都是错的。**

### 狭义定义

在对错关系轴中，`zx` 通过排除、否定、压过或改写他者立场，确立自己的正确。自己的正确与他者的错误形成直接竞争，双方不能在同一判断范围内同时成立。

其结构是：

```text
我认定自己正确
+ 他者立场被判断为错误
+ 我的正确通过压过、排除或替代他者进入现实
→ zx 的排他式正确
```

### 关键特征

- 自身正确与他者错误被绑定；
- 不只是不关心别人，而是对别人作出否定判断；
- 常要求他者退位、改口、服从或失去决定资格；
- 可能以论战、命令、征服、显权、改写秩序等方式外显；
- 现有 `zx` 信息卡中的显权、扩权与凌驾，可作为这种排他正确进入现实后的外部表现之一。

### 不是

- 不是单纯行动力；
- 不是普通意见不同；
- 不是只坚持自己、不处理别人；
- 不是只因能力强、身份高或战斗胜利就自动成立；
- 不是“你们也可以对，但我仍坚持自己”。

## 5. 三者最近邻边界

### zn 与 z

```text
zn：我与别人可以同时正确。
z：我把自己放到最高位置，别人不进入核心判断。
```

判别问题：

> 主体是否需要处理并承认他者正确的成立空间？

- 是：优先检查 `zn`；
- 否，且只集中确认自己最高：优先检查 `z`。

### z 与 zx

```text
z：别人不关我事。
zx：别人必须是错的。
```

判别问题：

> 主体是忽略他者，还是必须否定他者？

- 忽略、绕开、无关：优先检查 `z`；
- 驳倒、排除、压过、取消资格：优先检查 `zx`。

### zn 与 zx

```text
zn：差异可以并存。
zx：差异必须决出唯一正确。
```

判别问题：

> 自己的正确是否必须以他者错误为条件？

- 否：优先检查 `zn`；
- 是：优先检查 `zx`。

## 6. 领域映射

| 领域 | zn | z | zx |
|---|---|---|---|
| 人物心理 | 承认多方立场并保留自身 | 把自身正确推到最高，他者无关 | 认定自身正确并否定他者 |
| 对话 | “我们位置不同，但都说得通” | “我知道我最对，别人的事我不管” | “我对，你们必须承认自己错” |
| 群体关系 | 多方共存、协商边界 | 单点自我确认、退出公共争论 | 排除异议、夺取唯一解释权 |
| 叙事冲突 | 多重答案并置 | 主体只完成自身证明 | 主体压倒竞争答案 |
| 视觉关系 | 多中心可并存 | 单中心自我聚焦，外围失去相关性 | 单中心压倒、切断或覆盖其他中心 |

## 7. 使用纪律

1. 本补充只在判断对象涉及**主体立场、正确性、他者资格与关系冲突**时调用；
2. 光影、色彩、服装、构图中心等只能作辅助证据；
3. 三句原话是教学锚，不要求角色逐字说出口；
4. 必须判断角色通过选择、关系处理和跨情境行为实际体现哪一种结构；
5. 本卡不能替代三张原信息卡，也不能把狭义表现升级为十元唯一广义定义；
6. 同一人物可在不同对象层、阶段或关系中出现不同点位，不得一次台词锁死人物本体。
