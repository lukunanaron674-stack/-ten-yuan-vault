# 【zx 信息量卡 v2.3】

> **zx 的本体是主体权能公开显现、张扬扩大，并形成骑到他者之上、压过环境的强势姿态。**

## 1. 核心本体

```text
主体拥有自己的力量与方向
→ 力量公开进入现实
→ 他者和环境被迫承认其强度
→ 主体位置、影响与决定范围扩大
→ 形成凌驾、征服或无敌之姿
```

### 最短定义

> **zx = 我的力量必须显出来，并压到世界之上。**

zx 的核心不是普通行动力，而是：

- 张扬醒目。
- 权能显现。
- 主体位置上升。
- 影响与决定范围扩大。
- 凌驾于他者之上。
- 被压制后重新把权能推回现实。

## 2. 本体、行为、结果

### 本体

```text
张扬醒目
+ 权能显现与扩大
+ 凌驾、征服、骑到他者之上
```

### 常见行为

```text
目标执行
路径推进
破局
战斗
重新站起
公开宣告与夺位
```

### 常见结果

```text
主体成为更强的决定力量
他者必须承认、服从或退位
世界的运行范围被主体改写
```

目标执行只是常见行为。一个人有效率、有计划、会做事，不能单独证明人物本体为 zx。

## 3. 齐天大圣孙悟空：标准 zx 锚点

孙悟空的 zx 核心首先是：

```text
齐天大圣
与天齐名
骑到所有人头上
不接受既有等级压住自己
以无敌之姿让天庭秩序围绕他重新反应
```

这比“会战斗”“有执行力”“打不倒”更接近 zx 主骨。

“被压制后复起”可以是 zx 的重要动态，但不能反过来把 zx 缩成单纯耐打、不服输或人类极限意志。孙悟空最强的 zx 体感，是**主体权能直接推到最高等级之上**。

## 4. x 与 zx

```text
x：对象、资源、地盘和权限归我掌握。
zx：我的权能公开显现、扩大，并凌驾于他者之上。
```

- 唐人街幕后 Boss 不露面却控制全部资源：x。
- 幕后 Boss 公开登场，让所有势力低头：zx 高显影。
- x 是有权；zx 是显权、扩权、压人。

## 5. zx 与 nx

```text
zx：直接用自己的力量决定方向、压过对象。
nx：不占据方向决定权，进入已有关系、秩序与权限网络，通过求人、借力和人情路径推进。
```

两者互补不是“领导与服从”，而是两条办事路径：

```text
直接凌驾、强行做成：zx
通过既有人际与权限网络借力办成：nx
```

孙悟空真正开打、压过妖怪时，zx 高显影；寻找菩萨、土地、龙王、天庭关系，借法宝、请救兵时，nx 功能高显影。

## 6. zx 与 xn

```text
zx：主体权能要在当下显现并扩大。
xn：主体主动把信息、行动和资源放进计划、时间、规则与结构，使其持续运行。
```

执行一个计划不自动等于 zx。若重点是排程、记录、节点和长期结构，优先检查 xn；若重点是主体通过行动公开扩大权能，才检查 zx。

## 7. 人物、状态、行为、视觉分层

- **人物本体 zx**：长期依靠权能公开显现、扩大和凌驾成立。
- **人物状态 zx**：某阶段权能上升、夺位、破局或重新压回现实。
- **行为 zx**：战斗、推进、宣告、执行、破局、复起。
- **关系 zx**：主体直接成为关系中的更高决定力量。
- **视觉 zx**：中心上升、轴向、王权、利剑、压顶、所有视线被其夺走，仅为辅助证据。

## 8. 误判防线

以下不能单独判 zx：

- 有目标。
- 会执行。
- 很努力。
- 很能打。
- 很能挨打。
- 身份高。
- 穿王者服装。
- 喜欢命令别人。
- 站在画面中央。

必须检查：

```text
主体权能是否公开显现？
是否形成张扬醒目与凌驾姿态？
是否让他者、环境或等级秩序围绕其力量重新反应？
是否扩大了主体的决定范围？
```

## 9. 高体量体感词（人物层 / 典型外显，非独立判据）

用户确认的高价值体感词正式记录如下：

```text
张扬醒目 · 王权 · 权能扩大 · 不可被最终击倒 · 极限意志
```

这些词描述的是**人物层的高体量体感或典型外显**：

- 张扬醒目、权能扩大：zx 本体与常见行为的核心外显（见第 1、2 节）。
- 王权：多为视觉层辅助外显（中心上升、王权、利剑、压顶），仅作辅助证据（见第 7 节）。
- 不可被最终击倒、极限意志：复起型 zx 的人物层体感外显，对应“被压制后复起”“重新站起”动态（见第 1、3 节）。

它们不是单独充分判据，也不能反向把 zx 缩成单纯耐打、不服输或人类极限意志（见第 3 节）。出现任一词语都不能直接判定 zx，必须回到第 8 节误判防线与 zx 准度卡 v0.1 检查：

```text
主体权能是否公开显现？
是否形成张扬醒目与凌驾姿态？
是否让他者、环境或等级秩序围绕其力量重新反应？
是否扩大了主体的决定范围？
```

禁止拿上述体感词做关键词直判（例如“王权”“不可被最终击倒”出现即判 zx）。
