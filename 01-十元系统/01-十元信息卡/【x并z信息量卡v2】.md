# 【x并z 信息量卡 v2.0】

> **x并z = 对象通过一层稳定公共壳被世界识别、调用、归因、代表、进入或保护。壳可以与内部一致，也可以不一致。**

## 1. 核心本体

```text
内部对象、关系、能力或掌握边界真实存在
→ 需要一个外部可识别形式
→ 名称、身份、职位、作品形式、品牌、界面、门面或保护性前台稳定形成
→ 第三方能够持续识别、调用、归因、代表或进入
→ x并z
```

最短定义：

> **x并z = 世界通过这层壳知道该怎样找到、称呼、调用或进入它。**

核心变量：

- 公共可识别性；
- 跨场景指认稳定度；
- 第三方调用资格；
- 归因接口；
- 代表性与保护性；
- 壳与内部对象的连接稳定度；
- 续期、继承与撤销方式。

## 2. 壳不等于伪装

以下都可以是`x并z`：

- 与内部高度一致的真实身份；
- 为复杂内部提供简洁入口的名称与界面；
- 保护内部不被直接暴露的前台；
- 允许第三方调用的职位、制服、法人、品牌或作品形式；
- 内外不一致、伪装或双重身份。

因此：

```text
内外不一 = x并z的一种高张力子型
稳定公共接口 = x并z的必要主骨
```

只要戴面具、撒谎、换装或表演一次，不能自动判`x并z`。

## 3. 必要条件

判断稳定`x并z`，以下五项至少满足四项，第1、2项不可缺：

1. **壳对象明确**：到底是哪一个身份、名称、作品形式、职位、品牌、前台或界面。
2. **公共识别成立**：至少一个第三方能够通过该壳稳定识别对象。
3. **持续性**：不是一次换装、一次发言或一次临时伪装。
4. **接口功能**：壳实际改变调用、归因、代表、进入或保护方式。
5. **连接关系**：壳与内部对象存在可说明的映射，不只是视觉相似。

## 4. 六类常见子型

### 4.1 身份壳

姓名、亲属称谓、职业、国籍、组织成员、艺名等，使人物可被持续指认。

### 4.2 权能壳

职位、制服、证件、印章、法人身份、官方账号等，使指令或代表行为获得公共入口。

### 4.3 作品壳

标题、署名、出版形式、角色形象、系列名与展示格式，使内部能力和作品可被识别与归因。

### 4.4 服务与空间壳

门牌、前台、品牌、界面、入口规则，使外界知道怎样进入、使用或求助。

### 4.5 保护壳

中性名称、匿名接口、代理前台、秘密身份，使内部真实对象能够存在而不被直接暴露。

### 4.6 伪装与双层壳

表面身份与内部真实位置不一致。此类张力高，但不是全部`x并z`。

## 5. 对象分层

- **人物本体 x并z**：长期依靠公共身份壳、代表接口或多层身份存在。
- **人物状态 x并z**：此刻进入某个公开角色或壳内。
- **行为 x并z**：命名、署名、穿戴、代表、包装、切换界面、维持身份。
- **关系 x并z**：第三方通过壳与内部对象发生调用、归因或进入。
- **场景 x并z**：前台、舞台、门面、账号、制服只是候选载体。
- **视觉 x并z**：面具、双层空间、包装和橱窗只作显影证据。

## 6. 最近邻

### x并z vs x

```text
x：对象、资源、权限或关系实际归我掌握。
x并z：这种对象或掌握边界怎样被外部识别、调用、代表或保护。
```

有门牌不等于拥有房子；拥有房子也不自动产生稳定公共入口。

### x并z vs z

```text
x并z：提供可识别对象与归因接口。
z：重要认可主体对该对象进行看见、回应与确认。
```

曝光、账号和舞台只建立接口，不自动等于认可成立。

### x并z vs n

```text
n：内部真能接住、容纳和持续处理。
x并z：外部知道它是什么、怎样进入和怎样持续指认。
```

漂亮前台可能空心；真实承载结构也可能没有可读入口。

### x并z vs xn

```text
xn：主动组织时间、流程、记录与节点。
x并z：让结构拥有稳定可识别和可调用的公共壳。
```

制度流程不是身份壳；名册、证件也需检查它们是在记录，还是在构成公共身份接口。

### x并z vs nx

```text
nx：主体不占最终方向，沿既有关系与权限通道推进。
x并z：通道、角色或身份本身作为公共接口存在。
```

使用职位不等于职位壳由`nx`生成。

## 7. 拿掉测试

依次拿掉：

1. 华丽视觉、面具和服装；
2. 欺骗与秘密；
3. 一次性宣传与曝光；
4. 内部实际掌握；
5. 主体第一人称自称。

检查第三方是否仍能通过稳定名称、身份、作品形式或接口识别、调用、归因、代表或进入。若只能靠一次表演维持，不是稳定`x并z`。

## 8. 反向测试

- 主体停止自称，但事实索引、制度资格和第三方调用仍在：稳定壳仍存在。
- 拒绝当次签署、回应或表演后，只让单次互动失败：是构成性令牌停摆，不等于整个壳消失。
- 撤销登记、职位、授权、名册和公共接口后，第三方无法继续调用：`x并z`下降。
- 只有视觉包装，没有稳定识别和调用：非`x并z`主判。
- 壳与内部完全一致但承担识别、代表与保护：仍可判`x并z`。

## 9. 关系接口

本卡只定义`x并z`端点，不自行证明关系启动。

现行几何位置：

```text
x 生 x并z
x并z 生 z
x并z 克 nz
nx 克 x并z
n ↔ x并z（补）
```

其中机制是否锁定，必须查`十元生补克表`与关系专项正本。
