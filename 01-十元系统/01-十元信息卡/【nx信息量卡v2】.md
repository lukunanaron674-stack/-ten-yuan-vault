# 【nx 信息量卡 v2.4】

> **nx 的本体是主体不占据方向决定权，沿别人、关系、流程、秩序或现状已经给出的方向继续行动。**

## 1. 核心本体

```text
方向、权限或解决通道已经存在
→ 主体不把自己放在最终决定位置
→ 顺着外部安排、关系网络或既有秩序推进
```

### 最短定义

> **nx = 方向不是我定，我沿着已有关系和安排把事情继续办。**

nx 不是没有行动。它可以很忙、很能办事，甚至主动求人；关键仍是：**方向、权限和解决通道不由主体自己建立。**

## 2. 纯 nx：没主见与随安排

纯 nx 常见为：

- 没什么主见。
- 老板安排什么就做什么。
- 让别人决定方向。
- 不主动提出替代方案。
- 顺着群体、家庭、流程或现状继续。

标准员工判例：

```text
老板定方向
→ 员工不改写、不组织新的运行方式
→ 安排什么就做什么
= nx 行为
```

有命令、有制度、有工作，不自动等于 xn。主体若没有主动组织计划、时间和流程，仍应优先判 nx。

## 3. nx 作为关系功能：求人办事与人情世故

nx 不只表现为被动服从。强主体也可以使用 nx 功能：

```text
自己的权能不能直接解决问题
→ 进入已经存在的人际、身份与权限网络
→ 求人、借力、请救兵、借法宝、托关系
→ 沿他者拥有的角色和通道把事情办成
```

这仍是 nx，因为：

- 解决通道属于既有关系网络。
- 权限在别人手里。
- 主体需要承认外部位置、开口请求或借用他者力量。
- 不是自己骑到所有人头上直接决定。

因此，**纯 nx 人物本体**与**nx 关系功能**必须分层：

```text
纯 nx 本体：长期没主见，方向常由别人决定。
强 zx 人物的 nx 功能：人物总体有主见，但某段办事必须进入既有关系网络求人借力。
```

## 4. 孙悟空的 nx

《西游记》齐天大圣孙悟空的 nx 主要表现在后续办事路径：

- 找菩萨。
- 找土地、龙王、天庭与各路神仙。
- 借法宝。
- 请救兵。
- 通过身份、旧交、权限和人情网络解决问题。

这不是说孙悟空整体没主见。人物主十元仍是 zx；nx 是稳定副元与高频关系功能。

```text
齐天大圣骑到所有人头上：zx。
进入神仙关系网求人、借力、人情世故：nx。
```

## 5. nx 与 xn

```text
nx：方向或通道由别人、关系和现状给出，我沿着继续。
xn：我主动组织时间、计划、流程、记录和节点，使事情持续运行。
```

老员工标准区别：

- 老板安排什么就做什么：nx。
- 接到目标后主动排程、搭流程、分配资源、预判节点：xn。

等待也要分层：

```text
因为不占方向，等别人或现状决定：nx。
为了计划和节点主动等待：xn。
```

## 6. nx 与 zx

```text
zx：直接以自己的权能决定方向，压过对象。
nx：借用既有关系、身份、权限和他者力量推进。
```

二者互补是两条办事路径：

```text
能直接压过去：zx。
不能或不宜直接压过去：nx 进入关系网络借力。
获得支持后重新行动：zx 再显影。
```

## 7. nx 与 x

```text
x：资源、地盘、对象和权限归我掌握。
nx：资源和权限在别人手里，我沿关系通道借用或配合。
```

唐人街幕后 Boss 控制整个网络，是 x，不是 nx。

## 8. 人物、状态、行为和关系分层

- **人物本体 nx**：长期不占据方向决定位置，反复让别人或现状决定。
- **人物状态 nx**：某阶段暂时进入既有安排或关系网络。
- **行为 nx**：跟随、接受安排、求人、借力、托关系、沿权限通道推进。
- **关系 nx**：主体承认他者已有位置和权限，通过人情接口取得帮助。
- **场景 nx**：不能只凭办公室、队伍、监狱或安静画面直接成立，必须看到方向权或权限位置。

## 9. z 克 nx：位置保留，机制重审

正式几何位置继续保留：

```text
z 克 nx
```

旧机制：

```text
z 持续表达、决定和占位
→ nx 不主动抢回方向
→ nx 的选择空间被压缩
```

已经撤回正式资格。原因是现行 z 的本体是重要认可主体看见、回应并确认主体的存在、能力或价值；持续决定、占位和压退他者更接近 zx、x、xn 或外部方向主体。该旧过程甚至更可能使 nx 上升，而不是证明 z 对 nx 的克制。

当前最窄候选：

```text
重要认可主体确认主体自己的判断、能力或选择
→ 外部安排不再是唯一合法方向
→ 主体开始提出、选择并承担自己的路线
→ nx 下降
```

该候选目前只保留在关系层 / 状态层，正式机制未锁定。必须观察：

- 认可主体是谁；
- 认可了什么；
- 主体是否真实取回决定与否决位置；
- 拿掉资源、权限转移、教学结构和既有自主性后是否仍成立。

专项审计见：`01-十元系统/关系专项/z克nx_现行认可端点与旧占位口径冲突审计_20260720.md`。

“把自己让没”仍可作为 nx 在其他压制关系中的高体量结果，但不能继续被固定写成现行 z 克 nx 的正式机制。

## 10. 旧暗算口径删除

以下不再作为 nx 主骨：

- 幕后操盘。
- 暗算。
- 看牌。
- 记账。
- 风控。
- 等待结算。
- 清算。

主动记录、排程、观察节点和延迟结算，优先检查 xn；幕后拥有和控制资源，优先检查 x。

## 11. 误判防线

以下不能单独判 nx：

- 沉默。
- 低调。
- 聪明。
- 忍耐。
- 愿意帮助别人。
- 身处制度。
- 求人一次。
- 普通礼貌。

必须检查：

```text
方向、权限或解决通道是谁的？
主体是否没有占据最终决定位置？
是否沿别人、关系或现状给出的路径推进？
这是人物长期本体，还是某段关系功能？
```

## 12. 召回版

```text
nx = 方向不是我定，我沿已有关系和安排把事继续办。
老板安排什么就做什么：纯 nx 标准行为。
孙悟空求人、借法宝、请救兵、走神仙人情网络：nx 关系功能。
幕后 Boss 控制网络：x，不是 nx。
z 克 nx 的几何位保留，但旧“z 强势占位压退 nx”机制已撤回，现行候选改为认可确认主体自己的判断资格。
```
