# 【z 信息量卡 v2.2】

> **z = 精神个体面对庞大的物质客观世界时，需要一个认可主体看见、回应并确认自己的存在、能力或价值。**

## 1. 核心本体

```text
物质客观世界庞大
→ 单个精神个体显得渺小
→ 主体需要一个认可位置
→ 自己的存在、能力、作品或发现被确认
→ z
```

> **你看见并认可我，我的精神存在或能力才在这个认可位置上成立。**

z 的根是认可关系，不是目标执行，不是改变世界的完整路径，也不是楚庄王弓。

## 2. 认可主体

认可主体可以是：

- 一个具体的人。
- 一个群体或公众。
- 已经去世、但仍被主体想象和内化的人。
- 神、国家、历史。
- 想象中的观众。
- 自己对自己的认可。

关键不在认可者是否物理在场，而在于主体是否把它当作能够确认存在、能力或价值的精神位置。

## 3. 被认可的内容

可以是：

- 外貌。
- 能力。
- 作品。
- 身份。
- 选择。
- 发现。
- 对世界造成的改变。
- 完整的精神存在。

它们是不同的 z 对象，不是简单高低排序。

判断时必须写清：

```text
谁认可？
认可什么？
为什么这个认可位置重要？
```

## 4. z 与 zx 的边界

此前把“学习客观规律、改变世界、能力越来越强、权能越来越大”写进 z 核心，是错误归类。

用户已明确：这属于 **zx，也就是张扬醒目**。

### z

```text
存在 / 能力 / 发现
→ 被认可主体看见与确认
```

### zx（张扬醒目）

```text
面对客观世界
→ 学习并理解规律
→ 对世界形成有效改变
→ 把发现或成果显现出来
→ 得到认可
→ 能力与权能继续扩大
```

这套“认识、改变、显现、扩张”的过程属于 zx 的确认表现，不是 z 的底层定义。

### 语音误识别纠正

- “脏醒”不是正式类型。
- 这是语音输入把“张扬醒目”识别错了。
- 正式符号是 zx。
- 不得由该错词创造新的复合、污染或异化类型。

### 客观世界边界

不能说主观世界替代客观世界。

正确表述是：

> **主体发现客观规律，并逐渐扩大自己改变客观世界的能力。**

## 5. 外部表现与本体

以下内容可以是 z 的血肉，但不能替代认可结构：

- 舞台、聚光灯、被看见。
- 荣耀、宣言、追光。
- 表现欲、执念、爆点。
- 完成后的兑现感。

必须追问：

```text
认可主体是谁？
被认可的内容是什么？
去掉认可关系后，案例是否仍完整成立？
```

## 6. 人物判定

人物本体偏 z 时，常出现：

- 非常在意某个认可主体如何看自己。
- 完成作品、表达、选择或发现后，需要一个确认位置。
- 被忽视、否认或误解时，精神存在感会受到打击。
- 会通过展示、作品、行动、宣言或形象，把自己送进认可主体的视野。
- 得到确认后，会出现明显完成感或释放感。

## 7. 误判防线

| 表面现象 | 为什么不能直接判 z |
|:---------|:--------------------|
| 有明确目标 | 可能是 zx 的目标与路径 |
| 很努力 | 努力只是行为 |
| 很有执念 | 执念可能来自多种结构 |
| 喜欢表演 | 可能只是职业或表象经营 |
| 很显眼 | 显眼是视觉结果 |
| 追光 | 必须解释光与认可的关系 |
| 改变世界 | 完整的认识与改变循环优先检查 zx |

> **没有认可主体与认可内容，只靠舞台、光点、目标或改变世界，不能判纯 z。**

## 8. z 与 x、n 的底层区别

```text
x：看具体物象与物质关系
z：看自己是否被认可主体确认
n：看精神、整体与多方关系
```

## 9. 判断对象

- 人物本体 z：长期依赖认可位置确认自己。
- 人物状态 z：此刻因被看见、认可、否认或忽视而变化。
- 行为 z：展示、表达、宣言、创作、向认可主体呈现。
- 视觉 z：舞台、聚光、中心、爆点，仅为辅助证据。
- 关系 z：认可主体是否确认主体的存在、能力、作品或选择。

单张图可以视觉偏 z，但人物本体不一定是 z。

## 10. 楚庄王弓迁移声明

- x 对具体弓与物质状态的关注。
- n 对精神、整体与关系框架的理解。

## 12. 具体分析中的确认分账边界

### 12.1 本体不变：确认必须落在认可位置

动态链研究中，z 可以显影为某个主体对身份、责任、存在、资格、事实状态或关系位置的具体确认；但只有当这个判断把对象放入一个可被认可、采用或否认的位置，并对主体关系或下游程序发生作用时，才可登记为具体 z 端点。

```text
确认结论 z
= 某个确认主体
+ 对某项具体内容的认可/归因
+ 在明确阶段与采用范围内成立
```

这只是 z 的具体应用，不把 z 改成“所有事实判断”。

### 12.2 确认必须分账，不使用 z0—z4 单轴等级

个人、群体、机构与公众不是从低到高的真实性等级。每个具体 z 至少分别记录：

```text
确认主体：个人 / 关系双方 / 小群体 / 机构 / 公众
确认内容：身份 / 责任 / 存在 / 资格 / 事实状态 / 关系位置
证据状态：初步 / 可执行 / 稳定 / 被反证 / 已撤销
采用范围：私人 / 档案 / 媒体 / 医疗 / 法律
成立阶段：首次判断 / 调查中 / 审判中 / 后段揭露 / 历史回看
```

同一确认内容由不同主体在不同阶段采用，必须拆成不同 z 对象，不得合并为一个“大 z”。

### 12.3 z 不等于客观事实

```text
某主体确认 A
≠
A 在客观上因此成立
```

个人猜对不等于机构可执行确认已经恢复；机构采用错误结论，也不改变客观事实本身。

`z_right` 与 `z_wrong` 只是对某个具体确认结论是否符合事实的注记，不是新的十元位置，也不是高低等级。

### 12.4 z 不等于规则、制度、程序或权力

以下对象不能因参与确认就直接判 z：

- 法律与规则；
- 制度和行政结构；
- 调查、诊断、审判与执行程序；
- 权力处置能力；
- 证据材料与客观现象本身。

它们必须分别重新完成十元锚定。规则与持续程序优先检查 `xn`，公开处置与显权接口优先检查 `zx`，具体证据与现象优先检查 `x`；不能把它们全部塞入 z。

机构只有在“作为认可主体，把某对象确认进身份、责任、资格、存在或关系位置”时，该具体确认结论才可作为机构层 z 端点。

### 12.5 `x克z`只克具体确认能力，不克现实本身

严格 `x克z` 必须同时证明：

1. 有明确主体主动控制目标确认所需的必要入口；
2. 被克对象是具体主体在具体阶段形成、采用或执行某项确认的能力；
3. 拿掉入口控制后，该确认不再以同样路径下降；
4. 确认主体、确认内容、采用范围和阶段均被限定；
5. 普通混乱、漏登、无人目击、搜查无果、诱导询问、确认偏差、自然传播和程序惯性不足以解释主要变化。

正确写法：

```text
证言/识别入口控制 x
克
警方在首次调查阶段形成正确责任确认的能力 z
```

错误写法：

```text
谎言 x
克
真相 z
```

“真相”没有写确认主体、内容、采用范围和阶段，也把客观事实与认可位置混成了一团。

### 12.6 错误确认与正确确认下降必须分账

```text
替代身份/责任壳 x并z
生
某主体的错误确认 z_wrong
```

解释错误对象为什么被认可或归因。

```text
必要确认入口控制 x
克
某主体形成正确确认的能力 z_right
```

解释正确对象为什么难以进入该认可位置。

错误确认本身不是克源。没有单一主体控制必要入口时，可以成立责任壳生错误确认，但严格 `x克z_right` 应判失败边。
