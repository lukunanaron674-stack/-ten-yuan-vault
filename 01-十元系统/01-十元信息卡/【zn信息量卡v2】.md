# 【zn 信息量卡 v2.0】

> **zn = 主体内部存在一项不可轻易让渡的意义或原则，它不仅被认为正确，还拥有进入未来判断、排序冲突对象并最终指导选择的资格。**

## 1. 核心本体

```text
某项意义或原则在主体内部成立
→ 不依赖外部奖励、认可或当前利益维持正确性
→ 在冲突中能够排序其他选项
→ 条件变化后仍可进入未来判断
→ 主体愿意承担坚持、修订或放弃它的责任
→ zn
```

最短定义：

> **zn = 这是我认定不能随便让出去的意义与最终指导标准。**

核心变量：原则正确性、未来调用授权、最终指导资格、不可让渡性、冲突排序权、反事实指导能力、修订边界。

## 2. zn 不是什么

- 不是善良、正义、宗教、理想主义或三观正确；
- 不是一句口号、一次牺牲、一次坚持或不听劝；
- 不是被看见和认可，那是`z`；
- 不是公开显权、扩权和凌驾，那是`zx`；
- 不是遵守规则与流程，那是`xn`；
- 不是对象进入内部后被持续处理，那是`n`；
- 不是“我拥有它”，那是`x`。

原则可以残酷、狭窄或错误；`zn`判断的是内部意义资格，不是道德评价。

## 3. 必要条件

稳定`zn`至少满足：

1. 原则命题或意义对象明确；
2. 主体认为它拥有正确性或不可抛弃性；
3. 无外部认可、奖励或观看时仍进入判断；
4. 在冲突中能影响排序与最终选择；
5. 跨阶段保留未来调用资格；
6. 主体能够说明边界、条件或为什么不让渡。

## 4. 对象分层

- 人物本体：长期依靠不可让渡意义决定自己是谁。
- 状态：当前阶段某项原则高调用或暂时被遮蔽。
- 行为：拒绝、坚持、牺牲、辩护只是显影。
- 关系：某对象被认定不可抛下、不可背叛或必须按某标准对待。
- 场景：教堂、纪念碑、旗帜与高处只是候选载体。
- 视觉：光、圣性、孤独站立只作辅助证据。

## 5. 最近邻

```text
zn vs z：zn的正确性和指导资格来自内部；z需要重要认可主体确认。
zn vs xn：zn决定什么值得维护；xn决定怎样组织并持续运行。
zn vs n：zn撤回抛弃资格；n让对象真实留在内部并处理负荷。
zn vs zx：zn提供原则与最终标准；zx把自身权能公开推入现实。
zn vs x：zn提供“为什么守”；x提供“具体什么归我掌握”。
zn vs nz：zn是原则归属；nz是对象特异关系的停靠、回返与修复。
```

## 6. 拿掉与反向

- 拿掉奖励、认可、观众、群体许可与制度要求，原则仍应进入判断。
- 换成安全情境，检查原则未来资格是否保留。
- 主体只因害怕惩罚而遵守：优先检查`xn/xz/x`。
- 主体只在被赞美时坚持：优先检查`z`。
- 只是换策略、细化适用条件或暂停当前调用，不等于`zn`消失。
- 不同情境中仍认为原则正确且应进入未来判断，支持稳定`zn`。

## 7. 关系接口

```text
zx 生 zn
zn 生 n
zn 克 xn
xz 克 zn
zn ↔ x（补）
```

几何位置不等于机制锁定，必须查关系正本。
