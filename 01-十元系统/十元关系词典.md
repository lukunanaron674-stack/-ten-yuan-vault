## 2. 已锁定关系

- `xn 克 zx`：既有时间、规则、流程与前置行动限制即时显权扩张。
- `zx 补 nx / nx 补 zx`：直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补。
- `zx 克 n`：公开权能裁决成员资格、接收边界或结构运行，使既有承载能力下降。
- `xn 生 xz`：持续组织识别并处理偏差，关闭安全路线和时间窗，使危险逼近。
- `x并z 生 z`：稳定公开壳为认可主体提供可识别对象与归因接口。
- `x 生 x并z`：已成立的掌握边界为被识别、调用、代表或保护而形成稳定公开壳。
- `x 克 z`：掌握引见、发布、署名、归因或回应接口，使确认无法正确落到主体。
- `n 克 xz`：真实承载结构接收临界中的主体，隔开、吸收或处理危险，使行动紧迫度下降。
- `zn 补 x / x 补 zn`：意义方向与现实掌握对象互补。
- `n 补 x并z / x并z 补 n`：真实承载内部与可识别公共界面互补。
- `xn 补 z / z 补 xn`：跨时间证据与认可收束节点互补。
- `xz 补 nz / nz 补 xz`：失去风险与关系归宿互补。
- `n 生 xn`：反复进入的承载负荷迫使主体把经验提炼为顺序、分工、记录、节点与预案。
- `zn 生 n`：不可抛下的意义撤回拒绝与推出资格；对象跨阶段留在内部并被持续处理，才形成完整承载。
- `xz 生 zx`：危险使旧决定中心失效并形成决定空位；主体连续作出至少两项决定且被执行，形成临时公开决定接口。
- `x并z 克 nz`：稳定身份壳污染关系证据归因，使真实主体退出可信回返位置。
- `nz 克 x`：关系余温使掌握者主动收窄独占、替代决定、否决与调用边界。
- `x 克 nz`：掌握收紧决定、退出与回返边界，使停靠失去自愿性。
- `zn 克 xn`：不可让渡意义撤回结构应被主动维护的资格，使覆盖、自愿执行、修复与复制下降。

## 3. 两条新锁定生位的调用红线

### `zn 生 n`

必须同时证明：

```text
准入启动：zn 撤回拒绝与推出资格
+
承载成立：对象跨阶段留存，现实负荷被持续处理
```

一次善举、收留、捐助、藏匿、口号与建筑题材均不足；`zn` 不直接生成房屋、资金、流程、权限或成熟共同体。

### `xz 生 zx`

必须同时证明：

```text
危险使旧决定中心失效
+
主体连续作出至少两项不同层面的最终决定
+
他者实际执行并停止等待旧中心
```

只允许生成状态层或关系位置层的临时公开决定接口，不得写成危险凭空生成能力、勇气、领导人格或稳定本体。

## 4. 暂不锁定关系

- `z 克 nx`
- `nx 生 x`
- `nz 生 nx`
- `nx 克 x并z`
- `zx 生 zn`
- `z 生 nz`
- `xz 克 zn`

## 5. 通用红线

```text
几何位置锁定 ≠ 机制锁定
共现、先后、对照、视觉相似 ≠ 生克补启动
人物有某十元 ≠ 关系已经启动
状态、行为、光影、场景、时间关系、关系位置、显影与动态链必须分层
三元与十元并行，不构成父子派生
```
