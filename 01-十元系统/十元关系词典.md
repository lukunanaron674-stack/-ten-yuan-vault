# 十元关系词典｜现行摘要

> 完整端点、机制、反例与测试以 `十元生补克表.md` 和专项正本索引为准。

## 1. 十元位置

| 十元 | 生 | 被生 | 克 | 被克 | 补 |
|---|---|---|---|---|---|
| zx | zn | xz | n | xn | nx |
| x并z | z | x | nz | nx | n |
| zn | n | zx | xn | xz | x |
| z | nz | x并z | nx | x | xn |
| n | xn | zn | xz | zx | x并z |
| nz | nx | z | x | x并z | xz |
| xn | xz | n | zx | zn | z |
| nx | x | nz | x并z | z | zx |
| xz | zx | xn | zn | n | nz |

## 2. 已锁定关系

- `xn 克 zx`：既有时间、规则、流程与前置行动限制即时显权扩张。
- `zx 补 nx / nx 补 zx`：直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补。
- `zx 克 n`：公开权能裁决成员资格、接收边界或结构运行，使既有承载能力下降。
- `xn 生 xz`：持续组织结构识别并处理偏差，关闭安全路线和时间窗，使危险逼近。
- `x并z 生 z`：稳定公开壳为认可主体提供可识别对象与归因接口。
- `x 生 x并z`：已成立的掌握边界为了被识别、调用、代表或保护而形成稳定公开壳。

### x 克 z

```text
掌握重要认可关系所依赖的引见、发布、署名、归因或回应接口
→ 扣留、垄断、改署、隔离或关闭接口
→ 认可主体看不到对象，或把对象错误归给他人
→ 认可无法正确落到真正主体
```

核心变量：接触概率、正确归因、进入重要认可位置的资格、回应与确认是否发生、确认是否被冒领。

正式锚点：

1. 《大眼睛》玛格丽特的画作被公众认可，但沃尔特掌握署名和作者叙述，使认可错误归因。
2. 《寻梦环游记》赫克托的歌曲被认可，但埃内斯托掌握公共作者身份和传播叙述，使赫克托被抹除。
3. 编辑掌握发表与署名，把真正作者改为“资料协助”，使导师和读者无法正确确认其研究能力。

红线：不给钱、设备、场地而导致项目没完成，不自动等于 `x 克 z`；作品公开后观众不喜欢，不是接口门控；自然低曝光、本人拖延、认可主体无兴趣，也不足。

## 3. 暂不锁定关系

- `z 克 nx`
- `nx 生 x`
- `nz 生 nx`
- `nx 克 x并z`
- `zx 生 zn`
- `zn 生 n`
- `xz 生 zx`
- `z 生 nz`
- `xz 克 zn`

## 4. 当前红线

```text
几何位置锁定 ≠ 机制锁定
包装显眼 ≠ z
曝光量上升 ≠ z
被强迫复述 ≠ 被认可
一般资源封锁 ≠ x 克 z
负面评价 ≠ z 被克
自然低曝光 ≠ 第三方 x 门控
```
