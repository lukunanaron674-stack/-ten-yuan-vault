# 十元关系词典｜金链 · 银链 · 灰链
> 归档：`01-十元系统/十元关系词典.md`

> **2026-07-16正文革新：本页保留位置关系，但旧“nx=暗算、暗账、追踪、结算”案例解释全部失效。当前nx是不主动占据选择、方向和位置、顺着已有安排继续；暗中观察、隐蔽判断、算计、记录与等待结算转入xn。涉及nx的旧案例必须逐案二审。**

## 前置：术语层级

```text
十元            = 点

关系对子          = 基础位置关系
                   生 / 克 / 补 / 被生 / 被克

动态链条          = 多个关系对子接在一起的力流结构
                   如 zn 克 xn → xn 克 zx → zx 生 zn
```

**一句话封存：**

> 关系对子是基础关系单位；动态链条是多个关系对子接在一起后的运行结构。

## 五组灵魂对子（星盘直径两端）

| 对子 | 阳面 | 阴面 | 维度 |
|:----:|:----:|:----:|:----:|
| **1** | **zx（阳木·突破）** | **nx（阴金·不主动占位）** | 因果（位置保留，内容待二审） |
| **2** | **zn（阳火·意义）** | **x（阴水·深欲）** | 本体 |
| **3** | **n（阳土·承载）** | **x并z（阴木·包装）** | 空间 |
| **4** | **xn（阳金·规则）** | **z（阴火·执念）** | 时间 |
| **5** | **xz（阳水·漂流）** | **nz（阴土·停靠）** | 命运 |

注意：对子内部不是生克补关系。对子是**星盘直径两端的灵魂配对**，它们之间的力流完全由具体动态链决定。

## 第一章：生对子（10对）

| 生对子 | 作品案例（一个场景钉死） |
|:------:|------------------------|
| **n 生 xn** | **《教父》** — 柯里昂家族（n）生出家族规矩（xn）——「永远别让外人知道你在想什么」，承载容器一旦形成就会提炼出维持它的秩序 |
| **xn 生 xz** | **《逃出绝命镇》** — 被规则系统排斥 → 身份漂流 |
| **xz 生 zx** | **《搏击俱乐部》** — 杰克（xz·漂流者）遇上泰勒（zx·目标执行）——临界者找到了可以执行的方向 |
| **zx 生 zn** | **《肖申克的救赎》** — 安迪（zx）用二十年挖隧道建图书馆 → 他的存在成了肖申克的希望符号（zn）——执行足够久了就成了意义 |
| **zn 生 zx** | **《勇敢的心》** — 华莱士（zn）喊出「Freedom」→ 苏格兰人开始起义（zx）——信仰一旦被点燃，会催生出一群执行者 |
| **zx 生 x** | **《华尔街之狼》** — 贝尔福特（zx）不断突破规则赚钱 → 赚到后欲望膨胀（x）——毒品、女人、FBI都不在乎——执行者的突破最终释放了底层欲望 |
| **x 生 x并z** | **《寄生虫》** — 金家全家人（x·生存欲/想活下去）→ 伪造学历、伪造身份、伪造经历（x并z）——欲望要满足，必须先给自己套一个外壳 |
| **x并z 生 nz** | **《楚门的世界》** — 桃源岛（x并z·精心设计的表演外壳）→ 楚门对这里产生了依恋（nz·对家的柔情）——但问题是这个壳是假的，nz也是假的 |
| **nz 生 nx** | **位置保留，内容待二审。** 《消失的爱人》旧“柔情破碎生暗账算计”解释作废；艾米的主动设计、判断与等待结算先查xn |
| **nx 生 n** | **位置保留，内容待二审。** 《纸牌屋》旧“一路算计后由nx生n”解释作废；主动谋划先查xn |

## 第二章：克对子（10对）

| 克对子 | 作品案例（一个场景钉死） |
|:------:|------------------------|
| **xn 克 zx** | **《让子弹飞》** — 黄四郎（xn）用「跪着赚钱」的秩序压住张牧之（zx）——鹅城的规则让枪也打不穿 |
| **n 克 xz** | **《海边的曼彻斯特》** — 小镇（n）把李·钱德勒（xz）困在失去孩子的记忆里——容器太厚重，漂流者走不出去 |
| **nx 克 x并z** | **位置保留，内容待二审。** 《无间道》旧“暗账系统看穿伪装”解释作废；主动观察、隐蔽判断和拆穿底牌先查xn |
| **nz 克 x 失败** | **《苦月亮》** — 咪咪（nz）管不住奥斯卡（x）——柔情在欲望面前没有任何还手之力 |
| **x 克 z** | **《小丑》** — 亚瑟（z）每次想被看见都被哥谭的恶意（x）摁回黑暗里——追光者的光被深渊一口吞掉 |
| **zx 克 n** | **《盗梦空间》** — 柯布（zx 突破执行者）用多重梦境植入想法，打破斋藤（n·商界帝国）的心理防线——行动者可以击穿容器的壁 |
| **xz 克 zn** | **《蝙蝠侠：黑暗骑士》** — 小丑（xz·混乱的漂流者）用「无规则」冲击哥谭市民（zn·对正义的信仰）——漂流者的存在本身就是对意义的嘲讽 |
| **zn 克 xn** | **《V字仇杀队》** — V（zn·信仰/意义）用面具革命对抗 Norsefire 极权政府（xn·铁律）——意义可以击穿最坚硬的制度 |
| **x并z 克 nz** | **《色，戒》** — 王佳芝（x并z·伪装身份/麦太太）接近易先生 → 易太太的社交圈（nz·柔情停靠的太太团）被这个假壳渗入——伪装者让真正的停靠者无法再信任 |
| **z 克 nx** | **当前确认公式** — z持续显现、决定和占位；nx不主动对抗，也不抢回选择权，位置逐步后退，最终形成“把自己让没”。旧《猫鼠游戏》暗账追踪解释作废。 |

## 第三章：补对子（5对）

| 补对子 | 作品案例（一个场景钉死） |
|:------:|------------------------|
| **zx ↔ nx** | **《七宗罪》** — 米尔斯（zx·冲动的年轻警探）在大雨中追捕 → 沙摩塞（nx·老练的暗线分析者）在图书馆查资料。一个在前面撞墙，一个在后面算墙有多厚。他们互补才能破案——拆开就崩 |
| **zn ↔ x** | **《沉默的羔羊》** — 克拉丽丝（zn·想救人的信念）靠近 汉尼拔（x·吃人但洞察一切的深渊）。她的zn需要他的x来获得线索，他的x需要她的zn来消遣——没有深渊信仰就证明不了自己 |
| **n ↔ x并z** | **《布达佩斯大饭店》** — 饭店建筑（n·百年承载容器）+ 门童泽罗（x并z·继承了饭店的包装身份）——一个在空间里生了根，一个在外壳里成了继承人。空间本身就是壳与核的互补 |
| **xn ↔ z** | **《爆裂鼓手》** — 弗莱彻（xn·极致严苛的规则）= 节拍器、准时、不差半拍 ＋ 安德鲁（z·我要成为伟大鼓手的执念）= 练到出血、不惜一切。规则压出爆点，爆点需要规则来丈量 |
| **xz ↔ nz** | **《星际穿越》** — 库珀（xz·离开地球寻找新家园的漂流者）↔ 墨菲（nz·在房间里等父亲回来的柔情停靠）——一个人在宇宙里飘，一个人在卧室里等。两份想念互补成跨维度的联系方式 |
