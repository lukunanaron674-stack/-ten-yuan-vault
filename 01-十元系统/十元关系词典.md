# 十元关系词典｜现行摘要

> 完整端点、机制、反例与测试以 `十元生补克表.md` 和专项正本索引为准。

## 1. 十元位置

| 十元 | 生 | 被生 | 克 | 被克 | 补 |
|---|---|---|---|---|---|
| zx | zn | xz | n | xn | nx |
| x并z | z | x | nz | nx | n |
| zn | n | zx | xn | xz | x |
| z | nz | x并z | nx | x | xn |
| n | xn | zn | xz | zx | x并z |
| nz | nx | z | x | x并z | xz |
| xn | xz | n | zx | zn | z |
| nx | x | nz | x并z | z | zx |
| xz | zx | xn | zn | n | nz |
| x | x并z | nx | z | nz | zn |

## 2. 已锁定关系

- `xn 克 zx`：既有时间、规则、流程与前置行动限制即时显权扩张。
- `zx 补 nx / nx 补 zx`：直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补。
- `zx 克 n`：公开权能裁决成员资格、接收边界或结构运行，使既有承载能力下降。
- `xn 生 xz`：持续组织结构识别并处理偏差，关闭安全路线和时间窗，使危险逼近。
- `x并z 生 z`：稳定公开壳为认可主体提供可识别对象与归因接口。
- `x 生 x并z`：已成立的掌握边界为了被识别、调用、代表或保护而形成稳定公开壳。
- `x 克 z`：掌握认可关系所需的引见、发布、署名、归因或回应接口，使确认无法正确落到主体。
- `n 克 xz`：真实承载结构接收临界中的主体，隔开、吸收或处理危险，使行动紧迫度与漂流强度下降。

### zn 补 x / x 补 zn

```text
zn 给 x 以内部意义方向：为什么值得掌握、守护、限制、使用或放弃。
x 给 zn 以具体现实落点：什么归我、由我调配、在哪条边界内持续落实。
```

核心变量：

- `zn 补 x`：掌握用途的方向、守护与放弃标准、否决权服务的原则；
- `x 补 zn`：意义的现实对象、资源、权限、保护范围和我方边界。

正式锚点：

1. 《辛德勒的名单》辛德勒以工厂、资金、名单和雇佣权落实救人意义；
2. 《V字仇杀队》V 以影子画廊、档案、广播和行动资源落实自由与反抗意义；
3. 掌握档案原件、访问权和备份密钥的家族证词守护者。

红线：互补不等于相互生成。信念不会自动制造钱、地盘与权限；拥有资源不会自动产生意义；危险、深渊、战乱和受苦不是 `x`。

### n 补 x并z / x并z 补 n

```text
n 给 x并z 以真实内部：壳里面确实能接住、容纳、处理并持续承载人、事和关系。
x并z 给 n 以公共界面：世界知道它是什么、怎样进入、由谁接洽，并能持续指认同一承载结构。
```

核心变量：

- `n 补 x并z`：壳内部真实性、承受真实负荷的能力、公开承诺与内部实际的连接；
- `x并z 补 n`：外界可识别性、进入方式与边界、同一名称与角色的持续指认能力。

正式锚点：

1. 《千与千寻》千寻进入并工作后的油屋；
2. 《布达佩斯大饭店》1932年古斯塔夫管理时期；
3. 真实运行的社区匿名互助站获得保护性公共入口。

红线：互补不等于相互生成。建筑内外、漂亮装修、样板间加楼板、姓氏门牌、统一制服、品牌广告和产权挂牌均不能自动证明本关系。

### xn 补 z / z 补 xn

```text
xn 给 z 以跨时间证据：认可者能复核并确认能力、作品或发现不是一次偶然。
z 给 xn 以精神节点：长期组织知道被谁确认、确认什么、何时收束、哪些材料值得进入最终呈现。
```

核心变量：

- `xn 补 z`：证据连续性、重复稳定度、可复核材料密度、认可归因的跨时间可信度；
- `z 补 xn`：组织聚焦对象、材料筛选标准、阶段收束节点、最终呈现内容和下一周期校准依据。

正式锚点：

1. 《爆裂鼓手》安德鲁在 JVC 音乐节前后的长期训练与专业确认；
2. 《国王的演讲》乔治六世战时广播前的训练结构与广播确认节点；
3. 科研人员的长期复现实验与同行答辩。

红线：互补不等于相互生成。考试日期、临时熬夜、普通排程、一次称赞、一次夺冠、广告投放、播放量、绩效奖励、宣传曝光和结果完成都不能自动证明本关系；五大主题“时间 = xn + z”也不能反推案例中双向补位已经启动。

## 3. 暂不锁定关系

- `z 克 nx`
- `nx 生 x`
- `nz 生 nx`
- `nx 克 x并z`
- `zx 生 zn`
- `zn 生 n`
- `xz 生 zx`
- `z 生 nz`
- `xz 克 zn`

## 4. 当前红线

```text
几何位置锁定 ≠ 机制锁定
包装显眼 ≠ z
曝光量上升 ≠ z
被强迫复述 ≠ 被认可
一般资源封锁 ≠ x 克 z
负面评价 ≠ z 被克
自然低曝光 ≠ 第三方 x 门控
停止移动 ≠ xz 被 n 克制
建筑或围墙存在 ≠ n 已形成承载
精神意义 ≠ 自动获得资源
实际掌握 ≠ 自动产生意义
危险深渊 ≠ x
建筑内外并存 ≠ n 补 x并z
漂亮门面 ≠ 内部真实承载
真实互助存在 ≠ 必须拥有公共入口
准备时间长 ≠ xn 补 z
被表扬一次 ≠ z 补 xn
```
