# 十元关系词典｜金链 · 银链 · 灰链
> 归档：`01-十元系统/十元关系词典.md`

> **2026-07-16正文革新：本页保留位置关系，但旧“nx=暗算、暗账、追踪、结算”案例解释全部失效。当前nx是不主动占据选择、方向和位置、顺着已有安排继续；暗中观察、隐蔽判断、算计、记录与等待结算转入xn。涉及nx的旧案例必须逐案二审。**

## 前置：术语层级

```text
十元            = 点

关系对子          = 基础位置关系
                    生 / 克 / 补 / 被生 / 被克

动态链条          = 多个关系对子接在一起后的力流结构
                    如 zn 克 xn → xn 克 zx → zx 生 zn
```

**一句话封存：**

> 关系对子是基础关系单位；动态链条是多个关系对子接在一起后的运行结构。

## 第一章：生对子（10对）

| 生对子 | 作品案例（一个场景钉死） |
|:------:|------------------------|
| **zx 生 zn** | **位置锁定，机制与案例待二审。** 旧《肖申克的救赎》“执行足够久了就成了意义”同时把 zx 错写为执行、把 zn 错写为公共象征，正式撤回 |
| **zn 生 n** | **位置锁定，案例待二审。** 旧《勇敢的心》“信仰催生起义”更像zn→zx叙述，不能证明本生位 |
| **n 生 xn** | **正式机制：n 已经真实接住并持续处理落到自身的对象或负荷；当同类负荷反复进入、并发增加或超出单次临场处理能力时，承载主体主动把经验提炼为顺序、分工、记录、节点和资源安排，使“这次接住”转成“下次仍能接住”，由此生成 xn。** 标准锚点：《阿波罗13号》事故后的任务控制中心；《十三条命》确认被困者位置后的持续洞穴救援。旧“有家庭所以自然有家规”口径撤回。 |
| **xn 生 xz** | **《逃出绝命镇》** — 被规则系统排斥 → 身份漂流 |
| **xz 生 zx** | **《搏击俱乐部》** — 杰克（xz·漂流者）遇上泰勒（zx·目标执行）——临界者找到了可以执行的方向 |
| **x并z 生 z** | **位置锁定，案例待二审。** 不再用“包装生依恋”代替本生位 |
| **z 生 nz** | **位置锁定，案例待二审。** 必须重新寻找显现/执念如何推出停靠与依恋的独立证据 |
| **nz 生 nx** | **位置保留，内容待二审。** 《消失的爱人》旧“柔情破碎生暗账算计”解释作废；艾米的主动设计、判断与等待结算先查xn |
| **nx 生 x** | **位置保留，内容待二审。** 旧“nx生n”箭头正式撤销；不得再用《纸牌屋》主动谋划作nx证据 |
| **x 生 x并z** | **位置保留，案例待二审。** 旧《寄生虫》“生存欲/想活下去→伪造身份”把 x 当作泛欲望，并把策略行为直接当作稳定 x并z，不能继续作为纯案例 |

> **2026-07-18 x生x并z审计：** 现行 x 是对象、资源、地盘、权限或关系“归我掌握”，不是生存欲、想活下去或一般获取动机。正式机制若存在，必须证明主体已经拥有或正在扩大明确的掌握边界，并且这一掌握关系实际提高了“制作、认领或维持一层被世界看到的壳”的必要性。为取得对象而临时伪造学历、身份或经历，可能只是 xn 的策略组织、z 的目标推进或 x并z 作为前置工具；不能因伪装最终帮助获得资源，就倒写成 x 生 x并z。还必须排除反向 `x并z→x`：身份、品牌、职位或包装本身帮助主体取得资源、权限与关系。

> **2026-07-19 zx生zn审计：** 现行 zx 是权能公开显现、扩大并凌驾，不是普通执行、坚持或长期做事；现行 zn 是不依赖奖励、认可与外部证明的内部意义确定，不是名声、英雄称号或公共象征。正式机制若存在，必须区分同主体“行动自证”与跨主体“见证内化”，并证明目标主体在 zx 显现后新增或显著增强无奖励仍坚持的意义认领；同时排除既有 zn、反向 `zn→zx`、z 的被看见、x并z 的符号包装和 nx 的追随。当前《勇敢的心》与《肖申克的救赎》只能作为复合候选，不能作为纯案例。

> **2026-07-20 n生xn同步：** 旧“家庭存在所以自然有家规”“承载容器一旦形成就自动提炼秩序”只证明题材共现，不能证明生成。正式机制要求 n 先实际接住并持续处理负荷，随后同类负荷反复、并发或跨轮次进入，使临场处理出现遗漏、冲突或崩溃风险；承载主体因此主动建立顺序、轮班、记录、交接、资源安排和复盘，且这些组织直接服务于继续承载。若流程由上级、法律、既有制度、利润或纯效率目标先行启动，优先检查外部 xn、zx、x 或 nx，不得倒写为 n 生 xn。正式专项：`关系专项/n生xn_承载负荷提炼持续运行结构正式机制_20260719.md`。

> **2026-07-22 xz克zn同步：** 自然危险能够强力压缩 zn 的实践通道、迫使多个意义重新排序，并暴露原则是否原本只是安全条件下的规范；但目前没有两个高纯案例证明 xz 本身会把稳定 zn 持续改写为“不再正确”。施害者命令、酷刑、制度化惩罚与精密两难优先检查 `zx/xn/x`。

| **xz ↔ nz** | **《星际穿越》** — 库珀（xz·离开地球寻找新家园的漂流者）↔ 墨菲（nz·在房间里等父亲回来的柔情停靠）——一个人在宇宙里飘，一个人在卧室里等。两份想念互补成跨维度的联系方式 |
