# 十元关系词典｜现行摘要

> 本页只做现行关系总览。完整端点、机制、反例与测试以 `十元生补克表.md` 和专项正本索引为准；旧案例与旧骨型保存在归档原件中，不再覆盖现行语义。

## 2. 已锁定关系

### xn 克 zx
既有时间、规则、流程与前置行动限制即时显权扩张。

### zx 补 nx / nx 补 zx
`zx` 直接以自身权能做成；`nx` 通过既有身份、关系、权限与通道借力做成。

### zx 克 n
公开权能裁决成员资格、接收边界或结构运行，使既有承载的接收、保护、互信、返回或抗崩能力下降。

### xn 生 xz
持续组织结构识别并处理偏差，持续关闭安全路线与时间窗，使危险由潜在变成可感知逼近。

### x并z 生 z

```text
稳定身份壳、作品形式或公开界面
→ 为认可主体提供可识别对象与归因接口
→ 主体的存在、能力、作品、身份或选择被明确指认和确认
→ z 成立或上升
```

核心变量是可识别性、归因稳定度和认可对象清晰度，不是曝光量、点击量、包装华丽度或普通宣传。

标准锚点：

- 《窈窕淑女》伊莉莎在使馆舞会阶段；
- 蜘蛛侠形成稳定英雄名称、面具和公共身份后；
- 匿名艺术家采用稳定笔名、署名与作品形式后。

## 3. 暂不锁定关系

- `z 克 nx`：重要认可是否使主体重新认领方向位置。
- `nx 生 x`：持续让位是否使他者既有掌握边界扩大。
- `nz 生 nx`：关系余温是否导致最终方向让位，而非只延长共同时间。
- `nx 克 x并z`：不认领接口是否削弱身份壳对主体的覆盖。
- `zx 生 zn`：跨主体见证内化是否成立。
- `zn 生 n`：意义是否直接扩大承接边界，或必须经过 `zx/xn/x` 中介。
- `xz 生 zx`：危险是生成权能，还是只迫使潜在权能显影。
- `z 生 nz`：认可是否独立生成关系停靠。
- `xz 克 zn`：危险是否持续撤销稳定原则的正确性与指导资格。

## 4. 当前红线

```text
几何位置锁定 ≠ 机制锁定
包装显眼 ≠ z
曝光量上升 ≠ z
被强迫复述 ≠ 被认可
一次换装 ≠ 稳定 x并z 接口
有壳但无人回应 ≠ x并z 生 z
```

`x并z生z` 与 `x克z` 必须区分：前者建立识别与归因接口，使认可能够正确落到主体；后者掌握、封锁或劫持认可接口，使认可无法正确落到主体。
