# 十元关系词典｜金链 · 银链 · 灰链
> 归档：`01-十元系统/十元关系词典.md`

> **2026-07-16正文革新：本页保留位置关系，但旧“nx=暗算、暗账、追踪、结算”案例解释全部失效。当前nx是不主动占据选择、方向和位置、顺着已有安排继续；暗中观察、隐蔽判断、算计、记录与等待结算转入xn。涉及nx的旧案例必须逐案二审。**

## 前置：术语层级

```text
十元            = 点

关系对子          = 基础位置关系
                   生 / 克 / 补 / 被生 / 被克

动态链条          = 多个关系对子接在一起的力流结构
                   如 zn 克 xn → xn 克 zx → zx 生 zn
```

**一句话封存：**

> 关系对子是基础关系单位；动态链条是多个关系对子接在一起后的运行结构。

## 第一章：生对子（10对）

| 生对子 | 作品案例（一个场景钉死） |
|:------:|------------------------|
| **zx 生 zn** | **《肖申克的救赎》** — 安迪（zx）用二十年挖隧道建图书馆 → 他的存在成了肖申克的希望符号（zn）——执行足够久了就成了意义 |
| **zn 生 n** | **位置锁定，案例待二审。** 旧《勇敢的心》“信仰催生起义”更像zn→zx叙述，不能证明本生位 |
| **n 生 xn** | **《教父》** — 柯里昂家族（n）生出家族规矩（xn）——「永远别让外人知道你在想什么」，承载容器一旦形成就会提炼出维持它的秩序 |
| **xn 生 xz** | **《逃出绝命镇》** — 被规则系统排斥 → 身份漂流 |
| **xz 生 zx** | **《搏击俱乐部》** — 杰克（xz·漂流者）遇上泰勒（zx·目标执行）——临界者找到了可以执行的方向 |
| **x并z 生 z** | **位置锁定，案例待二审。** 不再用“包装生依恋”代替本生位 |
| **z 生 nz** | **位置锁定，案例待二审。** 必须重新寻找显现/执念如何推出停靠与依恋的独立证据 |
| **nz 生 nx** | **位置保留，内容待二审。** 《消失的爱人》旧“柔情破碎生暗账算计”解释作废；艾米的主动设计、判断与等待结算先查xn |
| **nx 生 x** | **位置保留，内容待二审。** 旧“nx生n”箭头正式撤销；不得再用《纸牌屋》主动谋划作nx证据 |
| **x 生 x并z** | **位置保留，案例待二审。** 旧《寄生虫》“生存欲/想活下去→伪造身份”把 x 当作泛欲望，并把策略行为直接当作稳定 x并z，不能继续作为纯案例 |

> **2026-07-18 x生x并z审计：** 现行 x 是对象、资源、地盘、权限或关系“归我掌握”，不是生存欲、想活下去或一般获取动机。正式机制若存在，必须证明主体已经拥有或正在扩大明确的掌握边界，并且这一掌握关系实际提高了“制作、认领或维持一层被世界看到的壳”的必要性。为取得对象而临时伪造学历、身份或经历，可能只是 xn 的策略组织、z 的目标推进或 x并z 作为前置工具；不能因伪装最终帮助获得资源，就倒写成 x 生 x并z。还必须排除反向 `x并z→x`：身份、品牌、职位或包装本身帮助主体取得资源、权限与关系。

### 对子1：zx ↔ nx（因果位置保留，旧暗算解释作废）

| 动态链条 | 纯案例（无其他十元干扰） | 来源 |
|---------|----------------------|:----:|
| zx 补 nx | **位置保留，案例待二审。** 旧“检方暗线接收结算”不能证明nx | 旧骨型10不得继续作证 |
| zx 补 nx → nx 生 x | **旧案例作废。** 账房计算窟窿、记录与结算属于xn检查，不能用来补出nx | 旧骨型11待重判 |
| xn 克 zx | **交规（xn）拦住超速（zx）**，规则一出手行动就停了 | 骨型1擦除回吸链 |

### 对子2：zn ↔ x（本体）

| 动态链条 | 纯案例（无其他十元干扰） | 来源 |
|---------|----------------------|:----:|
| zn 补 x | **传教士（zn）靠近战乱地带（x）**——信仰需要危险的深渊来证明自己 | 十元生补克表 |
| zn 生 n | **有了信仰（zn）就要建教堂（n）**——意义出来后第一件事是给自己找容器 | 三母型 |
| x 克 z（跨对子）| **赌红眼的人（z）被高利贷（x）吃掉**——追光者撞上深渊就没了 | 小王子分析 |

### 对子3：n ↔ x并z（空间）

| 动态链条 | 纯案例（无其他十元干扰） | 来源 |
|---------|----------------------|:----:|
| n 补 x并z / x并z 补 n | **精装样板间（x并z）+ 混凝土楼板（n）**——包装靠承载立住，承载靠包装被看见 | 十元生补克表；骨型7/8/9 |
| n 生 xn | **家庭（n）生出家规（xn）**——承载久了就必须提炼出秩序 | 三母型 |
| n 克 xz（跨对子）| **移民局的签证制度（n）拦住流浪汉（xz）**——承载秩序天然压制漂流动能 | 骨型13 |

> **2026-07-17 边界确认：** 温和、无欺骗性的生活外壳、房屋和真实生活容器归 n，不因具有名称、边界或家的外观而判为 x并z。x并z 可作为包装或表里张力反衬 n；反衬不等于双方已经互补。只有两个独立端点分别成立，并能说明双方各自补足什么，才允许写 n 与 x并z 互补。

### 对子4：xn ↔ z（时间）

| 动态链条 | 纯案例（无其他十元干扰） | 来源 |
|---------|----------------------|:----:|
| xn 补 z | **考试日期（xn）把复习的动力（z）压成一个爆点**——没有截止日期就没有冲刺 | 骨型3 |
| z 生 nz | **旧案例作废，关系待二审。** “高考那天→录取通知书上的学校”只证明目标完成、结果出现或进入新结构；学校与录取外观不能单独证明 nz 的“不想结束”、依恋或关系停靠 | 旧骨型3待重判 |
| xn 克 zx（跨对子）| **公司流程（xn）拦住创业者的突击执行（zx）**——「先审批再动手」 | 骨型1 |

> **2026-07-18 z生nz审计：** 几何位置继续保留。正式机制必须证明 z 的“完成后被看见”实际提高了某段关系、某个共同阶段或某个被见证位置的“不想结束”强度，并排除外部奖励、既有 nz、n 的承载结构、目标自然结束及反向的 `nz→z`。在纯案例通过拿掉测试与反向测试前，不得把录取、抵达终点、获得奖品或进入新场所直接判为 nz。

### 对子5：xz ↔ nz（命运）

| 动态链条 | 纯案例（无其他十元干扰） | 来源 |
|---------|----------------------|:----:|
| xz 补 nz / nz 补 xz | **流浪猫（xz）找到一个常来喂它的人（nz）**——漂流者需要停靠，停靠着需要被需要 | 骨型13/14/15 |
| n 克 xz（跨对子）| **收容所（n）把流浪猫关进笼子（克xz）**——承载系统管束漂流动能 | 骨型13 |
| nz 克 x 失败 | **贤惠的妻子（nz）管不住赌鬼丈夫（x）**——柔情压不住欲望 | 骨型14 |

| **n 克 xz** | **《海边的曼彻斯特》** — 小镇（n）把李·钱德勒（xz）困在失去孩子的记忆里——容器太厚重，漂流者走不出去 |

| **nz 克 x 失败** | **《苦月亮》** — 咪咪（nz）管不住奥斯卡（x）——柔情在欲望面前没有任何还手之力 |
| **x 克 z** | **《小丑》** — 亚瑟（z）每次想被看见都被哥谭的恶意（x）摁回黑暗里——追光者的光被深渊一口吞掉 |
| **zx 克 n** | **《盗梦空间》** — 柯布（zx 突破执行者）用多重梦境植入想法，打破斋藤（n·商界帝国）的心理防线——行动者可以击穿容器的壁 |
| **xz 克 zn** | **《蝙蝠侠：黑暗骑士》** — 小丑（xz·混乱的漂流者）用「无规则」冲击哥谭市民（zn·对正义的信仰）——漂流者的存在本身就是对意义的嘲讽 |
| **zn 克 xn** | **《V字仇杀队》** — V（zn·信仰/意义）用面具革命对抗 Norsefire 极权政府（xn·铁律）——意义可以击穿最坚硬的制度 |
| **x并z 克 nz** | **《色，戒》** — 王佳芝（x并z·伪装身份/麦太太）接近易先生 → 易太太的社交圈（nz·柔情停靠的太太团）被这个假壳渗入——伪装者让真正的停靠者无法再信任 |
| **z 克 nx** | **当前确认公式** — z持续显现、决定和占位；nx不主动对抗，也不抢回选择权，位置逐步后退，最终形成“把自己让没”。旧《猫鼠游戏》暗账追踪解释作废。 |

## 第三章：补对子（5对）

| 补对子 | 作品案例（一个场景钉死） |
|:------:|------------------------|
| **zx ↔ nx** | **《七宗罪》** — 米尔斯（zx·冲动的年轻警探）在大雨中追捕 → 沙摩塞（nx·老练的暗线分析者）在图书馆查资料。一个在前面撞墙，一个在后面算墙有多厚。他们互补才能破案——拆开就崩 |
| **zn ↔ x** | **《沉默的羔羊》** — 克拉丽丝（zn·想救人的信念）靠近 汉尼拔（x·吃人但洞察一切的深渊）。她的zn需要他的x来获得线索，他的x需要她的zn来消遣——没有深渊信仰就证明不了自己 |
| **n ↔ x并z** | **《布达佩斯大饭店》** — 饭店建筑（n·百年承载容器）+ 门童泽罗（x并z·继承了饭店的包装身份）——一个在空间里生了根，一个在外壳里成了继承人。空间本身就是壳与核的互补 |
| **xn ↔ z** | **《爆裂鼓手》** — 弗莱彻（xn·极致严苛的规则）= 节拍器、准时、不差半拍 ＋ 安德鲁（z·我要成为伟大鼓手的执念）= 练到出血、不惜一切。规则压出爆点，爆点需要规则来丈量 |
| **xz ↔ nz** | **《星际穿越》** — 库珀（xz·离开地球寻找新家园的漂流者）↔ 墨菲（nz·在房间里等父亲回来的柔情停靠）——一个人在宇宙里飘，一个人在卧室里等。两份想念互补成跨维度的联系方式 |
