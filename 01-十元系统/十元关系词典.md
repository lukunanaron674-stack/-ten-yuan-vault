# 十元关系词典｜现行摘要

> 完整端点、机制、反例与测试以 `十元生补克表.md` 和专项正本索引为准。

| 十元 | 生 | 被生 | 克 | 被克 | 补 |

| zx | zn | xz | n | xn | nx |

## 2. 已锁定关系

- `xn 克 zx`：既有时间、规则、流程与前置行动限制即时显权扩张。
- `zx 补 nx / nx 补 zx`：直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补。
- `zx 克 n`：公开权能裁决成员资格、接收边界或结构运行，使既有承载能力下降。
- `xn 生 xz`：持续组织结构识别并处理偏差，关闭安全路线和时间窗，使危险逼近。
- `x并z 生 z`：稳定公开壳为认可主体提供可识别对象与归因接口。
- `x 生 x并z`：已成立的掌握边界为了被识别、调用、代表或保护而形成稳定公开壳。
- `x 克 z`：掌握认可关系所需的引见、发布、署名、归因或回应接口，使确认无法正确落到主体。
- `n 克 xz`：真实承载结构接收临界中的主体，隔开、吸收或处理危险，使行动紧迫度与漂流强度下降。
- `n 生 xn`：反复进入的真实承载负荷迫使主体把接收经验主动提炼为顺序、分工、记录、节点、资源安排与预案。
- `x并z 克 nz`：稳定身份壳污染关系证据归因，使真实主体退出可返回的关系位置。
- `nz 克 x`：关系余温与不愿结束，使掌握者主动收窄对关系对象的独占、替代决定、否决与调用边界。

### x并z 克 nz

```text
已有真实共同时间与 nz 余温
→ 稳定身份壳成为实际相处接口
→ 温柔、承诺与共同记忆出现“真实主体 / 角色壳”双重归因
→ 原关系位置不再可信、不可安全返回
→ nz 下降
```

核心变量：关系证据可归因度、共同记忆归属、可信回返、停靠意愿。一次谎言、临时乔装、普通秘密、制服、公开恋爱和被骗后生气均不足。

### n 生 xn

```text
n 已经接住并持续处理负荷
→ 同类负荷反复、并发或增加
→ 临场处理不足
→ 主体主动排列、分工、记录、设节点并保存经验
→ xn 上升
```

核心变量：处理顺序、负荷分配、信息跨轮次保存、资源可预判性、人员更替后的持续运行能力。家庭有家规、医院有制度、上级命令轮班和照章执行均不足。

### nz 克 x

```text
x 的关系掌握已经成立
→ 继续独占、替代决定、否决或调用会把关系对象推走
→ nz 的“不愿关系真正结束”在掌握者一侧显影
→ 掌握者主动放松关系控制边界
→ 对方自主离开、自主决定与自主返回空间增加
→ x 下降
```

核心变量：独占程度、替代决定强度、最终否决权、关系准入与退出边界、对自主路线的容忍度，以及“属于我”是否改写为“仍与我相连，但不由我完全决定”。

正式锚点：

1. 《海底总动员》马林与尼莫，结尾返校阶段：马林为了父子关系继续，放松对尼莫探索、行动与风险的替代决定。
2. 《青春变形记》明与美美，演唱会冲突后的母女阶段：明为了不让女儿真正离开，允许美美保留熊猫、朋友与自己的选择。
3. 旧伴侣关系中，掌握者取消定位共享、检查权限和行程否决，理由是“只有不再完全掌握你，我们才可能仍有关系”。

红线：一般温柔、一次让步、一次允许孩子外出、法院削减监护权、被迫交出密码、疲惫后不再管理、因道德原则放弃财产、赌瘾无法被伴侣劝住和财产赠与均不自动构成 `nz 克 x`。必须先有具体关系掌握，再证明掌握者为了保留真实关系而主动缩小控制边界，且对方的否决、退出或自主路线真实增加。

最近邻：

- `x 克 nz`：控制加强，使停靠失去自愿性；改变的是 nz。
- `nz 克 x`：关系余温先显影，使控制主动下降；改变的是 x。
- `zn 克 x`：因为继续掌握“不对”而放弃，即使关系结束也会这样做。
- `zx` 剥夺：外部权能强迫交出控制，不是掌握者主动退让。

### zn 补 x / x 补 zn

```text
zn 给 x 以内部意义方向：为什么值得掌握、守护、限制、使用或放弃。
x 给 zn 以具体现实落点：什么归我、由我调配、在哪条边界内持续落实。
```

### n 补 x并z / x并z 补 n

```text
n 给 x并z 以真实内部：壳里面确实能接住、处理并持续承载。
x并z 给 n 以公共界面：世界知道它是什么、怎样进入、由谁接洽。
```

### xn 补 z / z 补 xn

```text
xn 给 z 以跨时间证据：认可者能确认能力、作品或发现不是一次偶然。
z 给 xn 以精神节点：长期组织知道被谁确认、确认什么、何时收束。
```

### xz 补 nz / nz 补 xz

```text
xz 给 nz 以真正失去与错过窗口的风险。
nz 给 xz 以关系终点、回返对象和归宿方向。
```

## 3. 暂不锁定关系

- `z 克 nx`
- `nx 生 x`
- `nz 生 nx`
- `nx 克 x并z`
- `zx 生 zn`
- `zn 生 n`
- `xz 生 zx`
- `z 生 nz`
- `xz 克 zn`

## 4. 当前红线

```text
几何位置锁定 ≠ 机制锁定
共现、先后、视觉相似 ≠ 生克补启动
包装显眼 / 曝光量上升 ≠ z
一般资源封锁 ≠ x 克 z
停止移动 ≠ xz 被 n 克制
建筑或围墙存在 ≠ n 已形成承载
准备时间长 ≠ xn 补 z
危险与温情同框 ≠ xz 补 nz
家庭有家规 / 医院有制度 ≠ n 生 xn
有身份壳 / 有秘密 / 有制服 ≠ x并z 克 nz
害怕失去 / 心软 / 一次放权 ≠ nz 克 x
关系控制下降必须可观察，且由掌握者为保留真实关系主动完成
```
