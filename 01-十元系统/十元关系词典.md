# 十元关系词典｜现行摘要

> 完整端点、机制、反例与测试以 `十元生补克表.md` 和专项正本索引为准。

## 1. 十元位置

| 十元 | 生 | 被生 | 克 | 被克 | 补 |
|---|---|---|---|---|---|
| zx | zn | xz | n | xn | nx |
| x并z | z | x | nz | nx | n |
| zn | n | zx | xn | xz | x |
| z | nz | x并z | nx | x | xn |
| n | xn | zn | xz | zx | x并z |
| nz | nx | z | x | x并z | xz |
| xn | xz | n | zx | zn | z |
| nx | x | nz | x并z | z | zx |

## 2. 已锁定关系

- `xn 克 zx`：既有时间、规则、流程与前置行动限制即时显权扩张。
- `zx 补 nx / nx 补 zx`：直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补。
- `zx 克 n`：公开权能裁决成员资格、接收边界或结构运行，使既有承载能力下降。
- `xn 生 xz`：持续组织结构识别并处理偏差，关闭安全路线和时间窗，使危险逼近。
- `x并z 生 z`：稳定公开壳为认可主体提供可识别对象与归因接口。
- `x 生 x并z`：已成立的掌握边界为了被识别、调用、代表或保护而形成稳定公开壳。
- `x 克 z`：掌握认可关系所需的引见、发布、署名、归因或回应接口，使确认无法正确落到主体。

### n 克 xz

```text
真实承载结构已经运行
→ 接收临界中的主体并提供内部位置
→ 替主体隔开、吸收或持续处理外部危险
→ 主体获得停留、补给、恢复与返回条件
→ 不再必须沿风险路径继续移动
→ xz 的危险可到达性、行动紧迫度与漂流强度下降
```

核心变量：危险可到达性、安全停留时间、继续移动紧迫度、安全路径与退路数量、外部冲击直接落到主体的比例。

正式锚点：

1. 《最后生还者》乔尔与艾莉进入杰克逊聚落，巡逻、防御、住房、医疗与补给替二人承担外部风险，使长期赶路暂时停止。
2. 《行尸走肉》瑞克一行进入亚历山大安全区初期，围墙、住房、水电、食物和社区防御使外部危险先由结构承担。
3. 运行中的灾后避难所接收洪水与失温中的居民，使其不再必须夜间继续寻找路线。

红线：签证审核、封路、拘禁、监狱和锁闭只是规则、权限或强制关闭路径；“无法移动”不等于“被接住”。空房子、恋人挽留、自然灾害自行结束，也不能自动判 `n 克 xz`。

## 3. 暂不锁定关系

- `z 克 nx`
- `nx 生 x`
- `nz 生 nx`
- `nx 克 x并z`
- `zx 生 zn`
- `zn 生 n`
- `xz 生 zx`
- `z 生 nz`
- `xz 克 zn`

## 4. 当前红线

```text
几何位置锁定 ≠ 机制锁定
包装显眼 ≠ z
曝光量上升 ≠ z
被强迫复述 ≠ 被认可
一般资源封锁 ≠ x 克 z
负面评价 ≠ z 被克
自然低曝光 ≠ 第三方 x 门控
停止移动 ≠ xz 被 n 克制
建筑或围墙存在 ≠ n 已形成承载
```
