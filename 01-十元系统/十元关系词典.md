# 十元关系词典｜现行摘要

> 完整端点、机制、反例与测试以 `十元生补克表.md` 和专项正本索引为准。

## 1. 十元位置

| 十元 | 生 | 被生 | 克 | 被克 | 补 |
|---|---|---|---|---|---|
| zx | zn | xz | n | xn | nx |
| x并z | z | x | nz | nx | n |
| zn | n | zx | xn | xz | x |
| z | nz | x并z | nx | x | xn |
| n | xn | zn | xz | zx | x并z |
| nz | nx | z | x | x并z | xz |
| xn | xz | n | zx | zn | z |
| nx | x | nz | x并z | z | zx |

## 2. 已锁定关系

- `xn 克 zx`：既有时间、规则、流程与前置行动限制即时显权扩张。
- `zx 补 nx / nx 补 zx`：直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补。
- `zx 克 n`：公开权能裁决成员资格、接收边界或结构运行，使既有承载能力下降。
- `xn 生 xz`：持续组织结构识别并处理偏差，关闭安全路线和时间窗，使危险逼近。
- `x并z 生 z`：稳定公开壳为认可主体提供可识别对象与归因接口。
- `x 生 x并z`：已成立的掌握边界为了被识别、调用、代表或保护而形成稳定公开壳。
- `x 克 z`：掌握认可关系所需的引见、发布、署名、归因或回应接口，使确认无法正确落到主体。
- `n 克 xz`：真实承载结构接收临界中的主体，隔开、吸收或处理危险，使行动紧迫度与漂流强度下降。
- `n 生 xn`：反复进入的真实承载负荷迫使主体把接收经验主动提炼为顺序、分工、记录、节点、资源安排与预案。
- `x并z 克 nz`：稳定身份壳污染关系证据归因，使真实主体退出可返回的关系位置。
- `nz 克 x`：关系余温与不愿结束，使掌握者主动收窄对关系对象的独占、替代决定、否决与调用边界。
- `x 克 nz`：关系掌握收紧决定、退出和回返边界，使停靠失去自愿性，关系位置被管理位置替代。
- `zn 克 xn`：不可让渡意义撤回结构“应当被维护”的资格，使其对主体的覆盖、自愿执行、内部修复与跨轮次再生产下降。

### zn 克 xn

```text
既有 xn 已通过规则、训练、程序、记录或传统持续运行
→ zn 判断继续替它执行或维护会背弃不可让渡之物
→ 结构不再被主体理解为“应当主动续命”
→ 对该主体的覆盖、自愿执行、内部修复与复制下降
→ xn 被克制
```

核心变量：结构对主体的覆盖率、无人监督时的自愿执行率、成员主动修复意愿、规则或传统的跨轮次复制率，以及结构是否只能依靠惯性和强制维持外壳。

正式锚点：

1. 《血战钢锯岭》训练与军法阶段的戴斯蒙德·多斯：统一持枪训练无法覆盖其“不杀人但必须救人”的原则，军队必须设置例外并重写服役接口。
2. 《安提戈涅》埋葬波吕涅刻斯阶段：禁葬令仍有惩罚外壳，却不能取得安提戈涅的自愿服从与内部认同。
3. 良心拒服兵役者结构例：制度可以处罚，却不能使其在无人监督时主动维护或把该规范作为正确传统传给下一人。

最近邻：

- `zn 克 xn` 改变的是意义接口、覆盖、自愿执行和再生产；公开破坏、夺权、爆炸或命令链断裂优先检查 `zx`。
- 单纯停止跟随更接近 `nx` 中断；只有“继续这样做会背弃不可让渡意义”并改变运行变量，才进入 `zn`。
- 结构因财政、技术、资源或领导更替停摆，不是 `zn 克 xn`。

红线：人物有信念、公开反抗、制度最后倒塌，均不能自动证明 `zn 克 xn`。必须拿掉暴力、夺权、财政崩溃、领导更替与外部失败后，仍看到结构因成员拒绝主动维护而失去覆盖、修复或复制。

### x 克 nz

```text
已有真实共同时间与 nz 余温
→ x 掌握者持续收紧行动、交往、决定、退出与回返边界
→ 留下不再能够证明“我仍愿意停靠”
→ 原关系位置从可返回的“我们”变成被管理范围
→ 自主停靠、回返意愿与关系余温下降
→ nz 被克制
```

核心变量：停留是否仍为自主选择、离开和返回是否仍由关系主体决定、回返能否证明关系余温、共同生活是否由柔情关系变成管理关系，以及原关系位置的安全感与可信度。

正式锚点：

1. 《海底总动员》影片前段的马林与尼莫：父亲持续替代决定、否决探索，使父子关系与家被体验为管理范围，尼莫以离开争取自主。
2. 《青春变形记》家庭仪式冲突前的明与美美：母亲掌握时间、朋友、身体解释与人生安排，使家庭停靠逐渐等同于放弃自身路线。
3. 《魔发奇缘》离塔前后的葛朵与乐佩：空间、信息、身份解释和离塔许可被单向掌握，塔从家变成不能自由退出的管理空间。

最近邻：

- `x 克 nz`：控制加强，目标变量是 `nz` 的自主停靠、回返和不愿结束。
- `nz 克 x`：关系余温先显影，掌握者主动缩小控制，目标变量是 `x`。
- `x并z 克 nz`：身份壳使人不知道自己停靠的真实对象是谁；`x 克 nz` 是知道对象是谁，却不能自由决定是否停靠。
- `zx`：公开威胁、惩罚和强迫服从优先判 `zx`；`x 克 nz` 可以在低调而持续的权限控制中成立。

红线：一次吃醋、一次争吵、安全建议、临时保护、双方可撤回的位置共享、医疗监护、普通经济依赖、外部危险和只有“控制欲”形容词均不自动构成 `x 克 nz`。必须先有真实 `nz`，再证明 `x` 的最终决定、否决、退出或回返控制真实增强，并使自主停靠与回返意愿下降。

### x并z 克 nz

```text
已有真实共同时间与 nz 余温
→ 稳定身份壳成为实际相处接口
→ 温柔、承诺与共同记忆出现“真实主体 / 角色壳”双重归因
→ 原关系位置不再可信、不可安全返回
→ nz 下降
```

核心变量：关系证据可归因度、共同记忆归属、可信回返、停靠意愿。一次谎言、临时乔装、普通秘密、制服、公开恋爱和被骗后生气均不足。

### n 生 xn

```text
n 已经接住并持续处理负荷
→ 同类负荷反复、并发或增加
→ 临场处理不足
→ 主体主动排列、分工、记录、设节点并保存经验
→ xn 上升
```

核心变量：处理顺序、负荷分配、信息跨轮次保存、资源可预判性、人员更替后的持续运行能力。家庭有家规、医院有制度、上级命令轮班和照章执行均不足。

### nz 克 x

```text
x 的关系掌握已经成立
→ 继续独占、替代决定、否决或调用会把关系对象推走
→ nz 的“不愿关系真正结束”在掌握者一侧显影
→ 掌握者主动放松关系控制边界
→ 对方自主离开、自主决定与自主返回空间增加
→ x 下降
```

核心变量：独占程度、替代决定强度、最终否决权、关系准入与退出边界、对自主路线的容忍度。

### zn 补 x / x 补 zn

```text
zn 给 x 以内部意义方向；x 给 zn 以具体现实落点。
```

### n 补 x并z / x并z 补 n

```text
n 给 x并z 以真实内部；x并z 给 n 以公共界面。
```

### xn 补 z / z 补 xn

```text
xn 给 z 以跨时间证据；z 给 xn 以精神节点。
```

### xz 补 nz / nz 补 xz

```text
xz 给 nz 以真正失去与错过窗口的风险；nz 给 xz 以关系终点、回返对象和归宿方向。
```

## 3. 暂不锁定关系

- `z 克 nx`
- `nx 生 x`
- `nz 生 nx`
- `nx 克 x并z`
- `zx 生 zn`
- `zn 生 n`
- `xz 生 zx`
- `z 生 nz`
- `xz 克 zn`

## 4. 当前红线

```text
几何位置锁定 ≠ 机制锁定
共现、先后、视觉相似 ≠ 生克补启动
包装显眼 / 曝光量上升 ≠ z
一般资源封锁 ≠ x 克 z
停止移动 ≠ xz 被 n 克制
建筑或围墙存在 ≠ n 已形成承载
准备时间长 ≠ xn 补 z
危险与温情同框 ≠ xz 补 nz
家庭有家规 / 医院有制度 ≠ n 生 xn
有身份壳 / 有秘密 / 有制服 ≠ x并z 克 nz
害怕失去 / 心软 / 一次放权 ≠ nz 克 x
一般占有欲 / 一次争吵 / 普通嫉妒 ≠ x 克 nz
人物有信念 / 公开反抗 / 制度倒塌 ≠ zn 克 xn
zn 克 xn 必须观察覆盖、自愿执行、内部修复与跨轮次复制下降
x 克 nz 必须观察决定、退出、回返控制上升及自主停靠下降
```
