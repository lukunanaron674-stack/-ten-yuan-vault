# 十元关系词典｜金链 · 银链 · 灰链
> 归档：`01-十元系统/十元关系词典.md`

> **2026-07-16正文革新：本页保留位置关系，但旧“nx=暗算、暗账、追踪、结算”案例解释全部失效。当前nx是不主动占据选择、方向和位置、顺着已有安排继续；暗中观察、隐蔽判断、算计、记录与等待结算转入xn。涉及nx的旧案例必须逐案二审。**

---

## 前置：术语层级

```text
十元 = 点
关系对子 = 基础位置关系：生 / 克 / 补 / 被生 / 被克
动态链条 = 多个关系对子接在一起后的力流结构
```

> 关系对子是基础关系单位；动态链条是多个关系对子接在一起后的运行结构。

| 对子 | 阳面 | 阴面 | 维度 |
|:----:|:----:|:----:|:----:|
| **1** | **zx（阳木·突破）** | **nx（阴金·不主动占位）** | 因果（位置保留，内容待二审） |
| **2** | **zn（阳火·意义）** | **x（阴水·深欲）** | 本体 |

## 第一章：生对子（10对）

| 生对子 | 作品案例（一个场景钉死） |
|:------:|------------------------|
| **zx 生 zn** | **位置锁定，机制与案例待二审。** 旧《肖申克的救赎》“执行足够久了就成了意义”同时把 zx 错写为执行、把 zn 错写为公共象征，正式撤回 |
| **zn 生 n** | **位置锁定，案例待二审。** 旧《勇敢的心》“信仰催生起义”更像zn→zx叙述，不能证明本生位 |
| **n 生 xn** | **正式机制：n 已经真实接住并持续处理落到自身的对象或负荷；当同类负荷反复进入、并发增加或超出单次临场处理能力时，承载主体主动把经验提炼为顺序、分工、记录、节点和资源安排，使“这次接住”转成“下次仍能接住”，由此生成 xn。** 标准锚点：《阿波罗13号》事故后的任务控制中心；《十三条命》确认被困者位置后的持续洞穴救援。 |
| **xn 生 xz** | **正式机制见专项正本。** 结构把偏离转成临界风险，不再读取旧“身份漂流”短句 |
| **xz 生 zx** | **位置锁定，机制待二审。** 危险造成决定空位并迫使潜在权能公开只保留为窄候选，不得用《搏击俱乐部》“临界者找到方向”替代生位 |
| **x并z 生 z** | **正式机制见专项正本。** 可识别壳建立认可接口，不再用“包装生依恋” |
| **z 生 nz** | **位置锁定，机制待二审。** 认可可使既有 nz 显影或被命名，但是否独立生成停靠证据不足 |
| **nz 生 nx** | **位置保留，内容待二审。** 《消失的爱人》旧“柔情破碎生暗账算计”解释作废 |
| **nx 生 x** | **位置保留，内容待二审。** 不得再用《纸牌屋》主动谋划作nx证据 |
| **x 生 x并z** | **正式机制见专项正本。** 掌握边界提高制作、认领和维持公开壳的必要性 |

> **zx生zn审计：** zx 是权能公开显现、扩大并凌驾；zn 是不依赖奖励、认可与外部证明的内部意义确定。必须排除反向 `zn→zx`、z、x并z、nx 与既有 zn。

> **n生xn同步：** n 先持续接住真实负荷，随后同类负荷反复、并发或跨轮次进入，使主体为继续承载而建立顺序、轮班、记录、交接、资源安排和复盘。

## 第二章：克对子（10对）

| 克对子 | 当前关系摘要 |
|:------:|------------------------|
| **xn 克 zx** | **正式机制见专项正本。** 既有时间、规则、流程和前置行动限制即时显权 |
| **n 克 xz** | **正式机制见专项正本。** 承载结构吸收危险、漂流和临界行动的压力 |
| **nx 克 x并z** | **位置保留，机制待二审。** 主体持续不认领身份壳只保留为窄候选 |
| **nz 克 x** | **正式机制见专项正本。** 关系余温压缩关系控制边界；旧“柔情压不住欲望”失败案例撤回 |
| **x 克 z** | **正式机制见专项正本。** 掌握认可接口使对象无法被重要认可者正确看见与确认 |
| **zx 克 n** | **正式机制见专项正本。** 公开权能击穿承载结构的接收、维持或抗崩能力；旧《盗梦空间》心理容器短句撤回 |
| **xz 克 zn** | **位置锁定，机制未锁定。** 旧《黑暗骑士》“小丑是混乱漂流者、无规则本身嘲讽并摧毁意义”正式撤回。现行 xz 必须是危险显形、退路与资源缩窄；必须证明稳定 zn 的正确性与最终指导资格被持续撤销，且危险解除后仍不恢复。当前更可靠的是实践通道受压、多个 zn 排序或原则纯度被测试 |
| **zn 克 xn** | **正式机制见专项正本。** 意义撤回结构自愿再生产，不再使用“革命击穿制度”泛化口径 |
| **x并z 克 nz** | **正式机制见专项正本。** 身份壳污染关系证据，使停靠失去可信归因 |
| **z 克 nx** | **位置保留，机制未锁定。** 重要认可使主体重新认领方向位置只保留为窄候选 |

> **2026-07-22 xz克zn同步：** 自然危险能够强力压缩 zn 的实践通道、迫使多个意义重新排序，并暴露原则是否原本只是安全条件下的规范；但目前没有两个高纯案例证明 xz 本身会把稳定 zn 持续改写为“不再正确”。施害者命令、酷刑、制度化惩罚与精密两难优先检查 `zx/xn/x`，不得让危险场景替它们背锅。
