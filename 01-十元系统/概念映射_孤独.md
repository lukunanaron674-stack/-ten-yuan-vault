## 第四步：概念边界 (Concept Boundary)

| 相邻概念 | 区分点 |
|----------|--------|
| 寂寞 | 寂寞缺的是陪伴（j/r层面），孤独缺的是存在性联结（nz/n层面） |
| 孤单 | 孤单是物理状态（j），孤独是存在状态 |

**关键判准**: 孤独的本质不是"一个人"，而是"一个人而想要另一个人在"（nz判准）。

## 第五步：语义角色框架 (Semantic Role Frame)

```
框架名: 孤独_等不到

核心角色:
  [体验者]  — 正在等待的主体（主格）
  [期待者]  — 被等待的客体（宾格，但缺席）
  [场域]    — 等待发生的时空（临界、边界、边缘）

  ① 体验者处于开放状态（准备好接收）
  ② 期待者始终在场域之外（不可达）

示例:
  "他在人群中感到孤独" → 体验者=他，期待者="能理解的人"，场域=人群
  "深夜的孤独" → 体验者=我，期待者="另一个人"，场域=深夜
```

## 第十五步：精髓一句话 (The Essence)

### 体量：8.5

孤独不是底层驱动力（低于欲望9.5/死亡9.5），但它是人类存在的终极模态之一——从物理独处到存在性等待的完整层级覆盖了人类经验的深水区。体量8.5的理由：
- 孤独的覆盖面极广（从r=3到nz=9，横跨7个层级）
- 但孤独不独立于其他概念存在——它依赖nz（等待）和xz（临界）作为前置结构，因此体量无法触及9+

### 动态链

#### 主链（生成链）—— 孤独的深化
```
nz(9) → xz(8.5) → x(8) → n(7.5) → zn(7)
```
**释义**：等不到(nz)催生了临界中的无人同行(xz)→不被欲望/x的否定深化孤独(x)→承载着却无人来停(n)→意义不被理解的最后一层孤独(zn)。孤独不是从外向内侵入的，是从最深处（nz）向外逐层显化的。

#### 克链（消解链）—— 孤独的解药
```
zn(7) 克 xz(8.5) → n(7.5) 克 x(8)
```
**释义**：意义被理解(zn)消解临界无人同行的孤独(xz)→承载有人停(n)消解不被欲望的孤独(x)。孤独的克链是其对偶的镜像——相遇(nz反)、共鸣(zn反)、陪伴(r反)各自对应一个孤独层。

#### 补链（互济链）—— 孤独的自持
```
x(8) ↔ n(7.5)
```
**释义**：不被欲望(x)与承载无人停(n)形成互锁——越不被渴望就越无人来停，越无人来停就越确认不被渴望。这是孤独最残酷的自我循环。

#### 总动态强度：7.1
| 链型 | 强度 | 计算 |
|:----:|:----:|:-----|
| 主链 | 8.0 | (9+8.5+8+7.5+7)/5 |
| 克链 | 6.5 | (7+7.5)/2 |
| 补链 | 6.5 | (8+7.5)/2 |

**总强度 = (8.0+6.5+6.5)/3 = 7.0**

### 主题归仓

| 主题 | 强度 | 归仓理由 |
|:----:|:----:|:---------|
| **命运 xz+nz** | **9.5** | 孤独的核心就是xz(8.5)+nz(9)——在临界中等不到。命运主题公式与孤独的十元最高两个点位完全重合 |
| **本体 zn+x** | **7.5** | 孤独的本体追问——「我是谁，为什么我一个人」是存在的终极问题之一。zn(7)+x(8)构成意义与欲望的否定面 |
| **空间 x并z+n** | **5** | n(7.5)的承载面在孤独中重要，但x并z在孤独中几乎没有映射（r=3最低）——孤独是去伪装的 |
| **时间 xn+z** | **4** | 时间在孤独中主要是等候的时长感，但非孤独的本质结构 |
| **因果 zx+nx** | **3** | 孤独不具因果结构——不是「做了什么所以孤独」，是「在等本身」 |

**主归主题：命运〔9.5〕**——孤独的命运本质：在边界等着一个可能不来的结局
