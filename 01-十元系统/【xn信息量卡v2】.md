# 【xn 信息量卡 v2】

> **xn = 主动把信息、行动与资源放进计划、时间、规则或隐藏结构中，使其经过积累形成可持续运转、难以被即时意志推翻的结构。**

## 1. 核心本体

xn 不只是“遵守规则”，也不只是“制度”。

它的核心动作是：

```text
把分散的信息、行动与资源
→ 放进时间、计划、规则或隐藏结构
→ 记录、排列、等待、重复、积累
→ 形成比单次行动更稳定的结构力量
```

### 最短定义

> **xn 把事情放进时间与结构里，让积累替单次意志发挥力量。**

## 2. 两个层级

### 2.1 主体运行层

主体主动把信息和行动放进：

- 计划。
- 时间顺序。
- 规则。
- 流程。
- 记录。
- 隐藏结构。
- 节点与结算时机。

因此，暗中观察、隐蔽判断、算计、记账、等待时机、等待节点与结算，应优先归 xn 检查。

### 2.2 外部积累层

当 xn 长期积累并外化时，会形成：

- 法律与制度。
- 家族积累与祖业。
- 传统与谱系。
- 长期训练体系。
- 历史惯性。
- 已经固化的程序与组织。
- 像山一样难以被单次意志移动的客观结构。

> **“时间积累成庞大结构”是 xn 的高体量外显，不是唯一入口。**

## 3. 为什么 xn 克 zx

标准位置关系：

```text
xn 克 zx
```

zx 依靠主体意志、目标执行与权能显现，要求力量进入当下现实。

xn 则把现实预先组织在长期积累的时间、规则和结构中：

```text
zx：我要现在行动、破局、扩大权能
xn：你必须进入既有时间、流程、规则与积累
```

因此 xn 对 zx 的克制不是简单说“不许动”，而是：

> **即时主体意志撞上了已经由时间、规则与无数前置行动积累成形的结构。**

zx 可以很强，但无法只靠一次爆发取消漫长积累。

## 4. 五行山式 xn

五行山可作为 xn 的高体量场景锚：

```text
时间积累
+ 秩序与规则
+ 已经完成的巨大结构
+ 对行动路径的长期封锁
= 五行山式 xn
```

重点不是石头重，而是：

- 结构早已成立。
- 个体不能通过一次即时行动把它取消。
- 行动必须等待时间、条件、关系或结构发生变化。

## 5. 家族积累式 xn

家族积累不是因为“家人”而自动属于 xn。

它属于 xn 的条件是：

```text
多代人的资源、名望、规则、关系与知识
→ 经过时间沉淀
→ 形成后人出生前就已存在的结构优势或约束
```

因此：

- 家庭感情本身不等于 xn。
- 家族谱系、祖业、传统训练、代际资源与长期规则的累积，才接近 xn。

## 6. 与 nx 的最小边界

```text
xn：主动把信息和行动放进计划、时间、规则或隐藏结构中。
nx：不主动建立方向，把选择留给别人、流程、关系或现状。
```

### xn

- 主动组织。
- 主动记录。
- 主动等待节点。
- 主动建立隐藏结构。
- 时间是力量积累的工具。

### nx

- 不主动占位。
- 不抢回方向。
- 顺着既有安排继续。
- 在无法决定时保留主体或流程。

“等待”不能单独判定：

```text
为了计划与节点而等待 → xn
因为自己不占据选择而继续等 → nx
```

## 7. 与旧“法律”题材词的关系

“法律”仍可以作为 xn 的题材词和典型外显，但不再等于完整定义。

```text
xn 本体：时间、计划、规则与隐藏结构中的主动组织和积累
法律制度：xn 长期外化后形成的一种结构
```

同理，学校、军队、家族、传统、监狱也不能只凭题材直接判 xn，必须检查结构是否由时间、规则和积累维持。

## 8. 典型行为

- 制定计划。
- 收集并记录信息。
- 暗中观察。
- 隐蔽判断与算计。
- 安排顺序和节点。
- 等待时机。
- 延迟结算。
- 重复训练。
- 通过长期积累形成优势。
- 维护或利用已经形成的时间结构。

## 9. 误判防线

以下不能单独判 xn：

- 守规矩。
- 年纪大。
- 家族历史悠久。
- 站在监狱或学校里。
- 会思考。
- 很有耐心。
- 一次临时计划。
- 普通职业理性。

必须检查：

```text
主体是否主动组织信息和行动？
是否放入时间、规则、计划或隐藏结构？
是否通过记录、重复、等待和积累形成持续力量？
```

## 10. 判断对象

- **人物本体 xn**：长期依靠计划、时间、规则、记录或隐藏结构建立力量。
- **人物状态 xn**：当前进入观察、记录、等待节点或结构化思考状态。
- **行为 xn**：计划、算计、记录、排程、等待时机、结算。
- **环境 xn**：制度、传统、谱系、长期流程与积累形成的巨大结构。
- **视觉 xn**：时间层叠、重复序列、档案、刻度、山体压制等，仅为辅助证据。

## 11. 召回版

```text
xn 把信息和行动放进时间、规则、计划或隐藏结构。
小处表现为观察、记录、算计和等待节点；
大处表现为制度、家族、传统与时间积累成的庞大结构。
xn 克 zx，是长期积累的结构压住即时扩张的主体意志。
```
