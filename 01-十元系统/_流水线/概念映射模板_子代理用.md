# 概念映射模板（给子代理用）

## 输出要求
- 每个概念输出一个文件到 /home/yyy/概念映射_[概念名].md
- 严格按下面的格式，不要自己发明新结构
- 所有十元符号标准化：z zn n nz x xz xn zx nx x并z
- 不使用三元旧术语（信/勇/智/仁等）
- 25对合法关系是硬性约束

## 格式模板

```md
# [概念名] — 15步映射

## 1-3. 十元映射

| 十元 | 在[概念名]中的表现 | 映射强度 |
|:----|:--------------|:--------:|
| **x** | ... | N |
| **xz** | ... | N |
| **nz** | ... | N |
| **xn** | ... | N |
| **nx** | ... | N |
| **zx** | ... | N |
| **z** | ... | N |
| **zn** | ... | N |
| **n** | ... | N |
| **x并z** | ... | N |

（按强度降序排列，写清楚每个符号的具体表现）

## 4. 体量（1-10）

一句话理由。

## 5-6. 位置盘

### 合法生克补（只使用25对中的关系）

**生：**
- A 生 B = N（含义）

**克：**
- A 克 B = N（含义）

**补：**
- A ↔ B = N（含义）

（只写强度≥5的对子，不编造25对之外的关系）

## 7. 动态链（<=15字）

符号→符号→符号...

## 8. 五大主题归仓

| 主题 | 强度 | 解释（<=15字） |
|:----|:----:|:--------------|
| 因果 zx+nx | N | ... |
| 本体 zn+x | N | ... |
| 时间 xn+z | N | ... |
| 空间 x并z+n | N | ... |
| 命运 xz+nz | N | ... |

**归仓排序：** [最高] > [次高] > ...

## 9. 误判检查

- ✅/⚠️ 常见误判

## 10. 封存句（<=60字）

> ...
```

## 25对合法关系参考（生10/克10/补5）

**生（10种）：**
n→xn, xn→xz, xz→zx, zn→zx, zx→x, x→x并z, nx→x, nz→nx, x并z→nz, z→zn

**克（10种）：**
xn→zx, n→xz, nx→x并z, nz→x(总失败), x→z, zx→n, xz→zn, zn→xn, x并z→nz, z→nx

**补（5种）：**
zx↔nx, zn↔x, n↔x并z, xn↔z, xz↔nz

## 示例概念：死亡（供参考结构）

死亡概念映射结果：
- x=10（死亡的本质——吞噬）
- xz=9（逼近——临界恐惧）
- nz=8.5（等待——对逝者的记忆）
- zn=8.5（意义——向死而生）
- nz→nx（等待生出清算）等
- 归仓：本体9.5 > 命运9 > 时间8 > 因果7.5 > 空间6.5
