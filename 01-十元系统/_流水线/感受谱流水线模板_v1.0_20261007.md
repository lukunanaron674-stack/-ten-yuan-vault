# 感受谱流水线模板 v1.0

> **2026-10-10 修复分支候选入口**：此模板继续用于感受轨 F，不再被当成十元体系唯一默认入口。涉及职业、名词、物件、事件的十元映射必须先/并行执行结构轨 S；涉及创作目标时先保留作者感受目标，随后调用结构映射挑选载体。统一调用 [[01-十元系统/00_问题系统/十元双轨均衡调用协议_v0.1_20261010]]。
>
> **盲测例外**：研究纯粹的人类即时感受时，依然要在展示十元标签之前采集自由描述；不得先展示结构映射结果诱导参与者。对作品复盘则同时保留「原意、回顾、观众」三种不同证据来源。

**任务切换**：名词映射S主、F可空；创作感受F定目标后S挑故事与视听约束；既有作品S/F并列。**这不是规定固定的本体上下级**，而是根据问题选择判断链；绝不把同一个数字同时解释成结构准度和真实感受。

## 输入
- stimulus：对象 / 形式 / 事件
- context：呈现语境、时间点、媒介
- observer：人类观察者或明确的人群范围
- target_feeling（可选）：希望诱发的三元/十元感受

## 第1步｜人类直接感受
先记录自由描述，不先展示十元标签。

## 第2步｜感受谱
对十元分别给 1–10：
`X / Z / N / ZN / NZ / XN / NX / ZX / XZ / X并Z`

Top1 = 当前主导感受，不等于对象本体。

## 第3步｜诱发特征
记录哪些可观察特征可能诱发该感受：
- 形状
- 边界
- 对比
- 连续性
- 节奏
- 关系
- 动作
- 构图
- 声音
- 语境

## 第4步｜关系
在人类感受谱基础上，再检查：
- 五轴相反感受
- 生 / 克 / 补张
- 动态链

## 第5步｜AI执行
AI只负责：
- 编码人类感受
- 预测形式→感受
- 生成目标形式
- 比较目标感受与真实反馈差异

不得写“AI自己感受到某十元”。
