# 感受谱流水线模板 v1.0

## 输入
- stimulus：对象 / 形式 / 事件
- context：呈现语境、时间点、媒介
- observer：人类观察者或明确的人群范围
- target_feeling（可选）：希望诱发的三元/十元感受

## 第1步｜人类直接感受
先记录自由描述，不先展示十元标签。

## 第2步｜感受谱
对十元分别给 1–10：
`X / Z / N / ZN / NZ / XN / NX / ZX / XZ / X并Z`

Top1 = 当前主导感受，不等于对象本体。

## 第3步｜诱发特征
记录哪些可观察特征可能诱发该感受：
- 形状
- 边界
- 对比
- 连续性
- 节奏
- 关系
- 动作
- 构图
- 声音
- 语境

## 第4步｜关系
在人类感受谱基础上，再检查：
- 五轴相反感受
- 生 / 克 / 补张
- 动态链

## 第5步｜AI执行
AI只负责：
- 编码人类感受
- 预测形式→感受
- 生成目标形式
- 比较目标感受与真实反馈差异

不得写“AI自己感受到某十元”。
