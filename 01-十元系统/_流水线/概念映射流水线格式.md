# 概念映射流水线格式 v1
# 100轮次 × 每轮3个并行概念 = 300个概念
# 输出格式：每个概念一个独立文件
# 
# 分发模式：Hermes规划清单 → delegate_task(3子代理并行) → 审阅回填

## 概念输入文件格式

每个概念在输入清单中占一行：
```
概念名 | 题材/场景来源（可空）| 一句话定义参考（可空）
```

## 概念输出文件格式（子代理产出）

```md
# 概念名 — 15步映射

## 1-3. 十元映射
| 十元 | 表现 | 映射强度（1-10） |
|:----|:----|:--------------:|
| x | [这个十元在概念中如何表现] | N |
| ... | ... | ... |

## 4. 体量（1-10）

## 5-6. 位置盘（生/克/补 高强度对子，每个对子标注强度）
- [A]生[B] = N（含义）
- [A]克[B] = N（含义）
- [A]↔[B]补 = N（含义）

## 7. 动态链（<=20字）
[符号]→[符号]→[符号]→...

## 8. 五大主题归仓
| 主题 | 强度 | 解释（<=15字） |
|:----|:----:|:--------------|
| 因果 | N | ... |
| 本体 | N | ... |
| 时间 | N | ... |
| 空间 | N | ... |
| 命运 | N | ... |

**归仓排序：** [最高主题] > [次高] > ...

## 9. 误判检查（<=3条）
- ✅/⚠️ 常见误判检查

## 10. 封存句（<=50字）
> ...
```

## 审阅标准（我回填前检查）
1. ✅ 十元映射合不合法（是否与25对关系一致）
2. ✅ 动态链走得通吗（生克方向对）
3. ✅ 归仓合理吗（与概念定义一致）
4. ⚠️ 有误判标记吗
