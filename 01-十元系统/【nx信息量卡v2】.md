# 【nx 信息量卡 v2】

> **纯 nx = 不主动占据选择、方向和位置，顺着已有关系、群体、流程、安全结构或环境继续运行。**

> **“把自己让没”不是纯 nx 一开始的主动目的，而是 nx 被 z 持续克制后，因没有主动抢回位置而形成的结果。**

## 1. 核心本体（主骨）

```text
已有关系 / 安排 / 流程 / 环境正在运行
→ nx 不主动改写、不主动占位、不主动定方向
→ 别人怎么安排，就先怎么继续
→ 事情落到自己这里，也很少主动推出去
```

### 主骨公式

```text
nx = 不主动发起
   + 不主动占位
   + 顺着已有结构继续
   + 避免自己成为明确选择者
```

### 最短封存句

> **他不是决定退让，他只是从未主动决定。**

### 不是

- 不是主动奉献自己。
- 不是一定为了维持亲密关系。
- 不是主动照顾、主动承载。
- 不是策略性忍耐或等待反击。
- 不是规则本身，也不是纪律本身。
- 不是聪明、看牌、暗算、结算的同义词。

## 2. 纯 nx 与 z 克 nx

### 纯 nx

```text
不抢方向
不主动打断
不主动拒绝安排
顺着现有状态继续
让选择落到别人手里
```

纯 nx 未必已经很惨，也未必已经完全失去自我。它首先表现为：

> **主动性没有站到前面。**

### z 克 nx

```text
z 持续显现、要求、决定、占位
→ nx 不主动对抗、不抢回选择权
→ nx 的位置不断后退
→ 最终“把自己让没”
```

因此：

- 龟男
- 老好人
- 受气包
- 关系缓冲垫
- 被默认懂事的人

更适合看作 **nx 被 z 克制后的高频社会形态**，而不是纯 nx 的全部定义。

## 3. 第一体感

纯 nx 的第一体感不是：

> “我为了你牺牲自己。”

而是：

> **“既然已经这样安排了，那就先这样吧。”**

常见语言：

- 都行。
- 随便。
- 你们定吧。
- 我跟着就行。
- 那就这样。
- 既然轮到我了，我做吧。

## 4. 动机范围

nx 不只发生在亲密关系里，也包括：

- 顺着群体运转
- 顺着工作流程
- 顺着家庭安排
- 顺着安全需求
- 顺着社会习惯
- 避免自己承担明确选择
- 别人怎么安排就怎么继续

共同核心不是“爱关系”，而是：

> **不主动中断当前运行，也不主动建立自己的方向。**

## 5. 人物层

| 面向 | 描述 |
|:----|:-----|
| 核心人物 | 被安排着继续生活的人 |
| 高频 is-a | 随安排的人、跟着走的人、没主意的人、习惯说都行的人、被动参与者 |
| 常见位置 | 队伍后面、集体边缘、流程中的普通节点、别人决定后的执行余位 |
| 灵魂问题 | “如果没有人替我决定，我要往哪里走？” |
| 被 z 克制后 | 位置持续后退，最后把自己让没 |

## 6. 行为层

| 行为 | 强度 | 判定说明 |
|:----|:---:|:---------|
| 跟着安排走 | 9.5 | 已有方向由别人决定，自己不主动改写 |
| 不主动表态 | 8.5 | 不是藏牌，而是没有主动占据选择位 |
| 让别人决定 | 9 | 把方向权交给外部 |
| 事情落下就接着做 | 8 | 未必主动承载，只是没有推出去 |
| 避免明确选择 | 8.5 | 不愿成为决定后果的人 |
| 顺着流程继续 | 8 | 流程可以是工作、家庭、群体或生存环境 |
| 被要求后退 | 7.5 | 单次后退只是行为；长期后退才形成 z 克 nx |
| 自我消失 | 9 | 属于 z 克 nx 的结果，不是纯 nx 的初始动机 |

## 7. 关系与场域

nx 容易在以下场域显形：

- 大家都默认由别人作决定。
- 一个角色总说“你们定”。
- 环境已经形成惯性，角色只是顺着继续。
- 群体把任务自然推到最不反抗的人身上。
- 家庭安排了他的道路，他没有主动改写。
- 工作流程不断往前，他只是其中一个被动节点。
- 为了安全，他宁可不选择，也不冒险改变现状。

### 场域核心

```text
方向已经存在
选择权在别人手里
nx 没有主动把它拿回来
```

## 8. 视觉层

nx 单图可以表达“被动位置”，但要判 z 克 nx，仍需要连续过程。

### 纯 nx 可用视觉

- 队伍往前走，他自然跟在后面。
- 别人讨论方向，他站在旁边等待结果。
- 多条路摆在前面，他看向别人而不是自己选。
- 座位不是被抢走，而是他从未主动坐到中心。
- 手里拿着别人分配的物件，神态并非主动承担。

### z 克 nx 连续视觉

- z 角色不断决定、要求、占位。
- nx 每次都没有主动反对。
- nx 的座位、声音、物品和选择空间逐格减少。
- 最后一格仍在跟随，但画面中已经没有自己的位置。

## 9. 与相邻结构的防混淆

### nx vs nz

- nz：主动想接住、照料或维系某个人。
- nx：不一定想接住，只是事情落到这里，没有主动推出去。

封存区别：

> **nz 是“我来接住你”；nx 是“既然落到我这里，那就这样吧”。**

### nx vs xn

- xn：规则、时间、秩序或流程本身构成行动依据。
- nx：不一定认同规则，只是顺着已有安排继续。

规则取消以后：

- 仍等待别人安排，nx 可能成立。
- 会主动重新规划，需检查其他结构。

### nx vs zx

- zx：主动选择路径并推进。
- nx：把路径选择留给别人或现状。

### nx vs z

- z：主动显现、表达、定方向、占位置。
- nx：不主动占据这些位置。
- z 持续施压时，可形成 **z 克 nx → nx 把自己让没**。

## 10. 旧暗算 / 看牌 / 结算口径迁移

旧版中的以下内容不再作为 nx 主骨：

```text
暗算
看牌
记账
等待
结算
清算
按节点翻牌
信息不对称
```

当前迁移判断：

- **暗中观察、隐蔽判断、算计、记录、等待、按顺序累积、到节点处理与等待结算**：归 xn 检查。
- **到了节点主动翻牌、推进、切断、执行清算**：可能带 zx。
- 这些旧词具有很强的醒质地，但不再构成纯 nx 主骨。

## 11. 生克接口

当前锁定关系：

```text
z 克 nx
```

现象解释：

> z 主动显现、决定和占位；nx 没有主动抢回方向与位置，于是持续退位。

其他生、克、补关系仍必须查正式位置关系表，不由本卡自行扩写。

## 12. 三元比例接口

nx可以表现为n多x少：n使人物更关注既有关系、群体与整体安排，少量x保留具体边界和眼前判断。

这只是nx内部质地，不是由n与x派生出nx。无论比例如何，纯nx仍必须通过“不主动占据选择、方向和位置”的本体检查。

## 13. 召回版

```text
纯 nx = 不主动占选择和方向的位置，顺着已有安排继续。
z 克 nx = z 不断决定和占位，nx 不抢回位置，最后把自己让没。
```
