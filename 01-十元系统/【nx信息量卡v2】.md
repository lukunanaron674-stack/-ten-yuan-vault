# 【nx 信息量卡 v2】

> **纯 nx = 为了让关系、气氛或日常继续，反复压掉自己的需求与边界，最后把自己的位置让没。**

## 1. 核心本体（主骨）

```text
有自己的需求 / 意见 / 边界
→ 害怕冲突、失望、排斥或关系断裂
→ 先忍、先让、先吞、先说“算了”
→ 退让被别人当成默认规则
→ 自己在关系中的位置越来越小
```

### 主骨公式

```text
nx = 忍 + 让 + 吞 + 躲 + 维持表面运转 + 自我消失
```

### 不是

- 不是单纯沉默、内向、冷静。
- 不是单纯善良、温柔、愿意帮助。
- 不是单纯服从制度或纪律。
- 不是为了未来反击而暂时忍耐。
- 不是聪明、看牌、暗算、结算的同义词。

## 2. 第一体感

> **“我其实不愿意，但我一说出来，事情是不是就坏了？”**

于是他又一次说：

- 没事。
- 都行。
- 我来吧。
- 算了。
- 你先。

nx 的第一体感不是“他藏着一张牌”，而是：

> **他为了不让局面裂开，先把自己从局面里删掉。**

## 3. 人物层

| 面向 | 描述 |
|:----|:-----|
| 核心人物 | 把自己让没的人 |
| 高频 is-a | 龟男、老好人、受气包、工具人、小透明、不敢拒绝的人 |
| 关系位置 | 缓冲垫、收拾残局者、被默认懂事的人 |
| 灵魂问题 | “我什么时候才能说一次不？” |
| 极端结果 | 别人越来越习惯越界，自己越来越不知道想要什么 |

### 纯 nx 人物必须有过程证据

不能只凭一张安静、疲惫、冷灰色立绘判断。至少要看见：

1. 他原本不愿意。
2. 他担心拒绝带来的关系后果。
3. 他主动压掉自己。
4. 同类退让反复发生。
5. 他的边界和位置持续缩小。

## 4. 行为层

| 行为 | 强度 | 判定说明 |
|:----|:---:|:---------|
| 忍住不说 | 8 | 必须有“怕说出后关系变坏”的动机 |
| 先答应 | 9 | 明明不愿意，却先让事情继续 |
| 先道歉 | 8.5 | 不一定是自己错，只是想让冲突停止 |
| 替人收尾 | 8 | 别人的后果反复落到自己身上 |
| 装没事 | 9 | 压掉真实感受，维持表面和平 |
| 让别人先 | 7 | 单次礼貌不算，重复让位才构成结构 |
| 不解释 | 7.5 | 不是高冷，而是觉得解释会让事情更麻烦 |
| 自我缩小 | 9.5 | 从表达、座位、时间到人生选择逐渐后退 |

## 5. 关系场域

nx 最容易在以下场域显形：

- 一个人总被默认“最懂事”。
- 一个人承担所有人的情绪，但没人问他的感受。
- 群体把他的退让当成理所当然。
- 亲密关系中，他害怕提出需要会被抛下。
- 工作中，他总接别人不愿意做的事。
- 家庭里，他负责不让气氛变坏。

### 场域核心

```text
他不是没有边界，
而是每次边界出现时，
都先由他自己撤掉。
```

## 6. 视觉层

### 有效视觉

nx 更适合连续图，而非单张气质图：

- 第一格想拒绝。
- 第二格观察对方脸色。
- 第三格说“我来吧”。
- 第四格别人继续加码。
- 第五格自己的物品、座位或说话空间被挤掉。

可用意象：

- 别人塞来的包和任务越来越多。
- 自己的椅子逐渐退到画面边缘。
- 想开口的气泡一次次消失。
- 别人的东西占满他的桌面。
- 合照里他总站在最边上，最后被裁掉。

### 弱证据

冷灰色、旧外套、工牌、低头、雨伞、档案室、普通制服都只是血肉，不能单独定 nx。

## 7. 叙事层

nx 的故事动力不是“翻底牌”，而是：

```text
第一次退让
→ 对方认为可以继续
→ 第二次越界
→ 主体继续压低自己
→ 关系表面稳定，内部位置失衡
→ 主体消失或迟来地重新选择
```

### 常见叙事问题

- 他什么时候第一次意识到，自己已经没有位置？
- 他拒绝一次以后，关系真的会毁掉吗？
- 他是在保护关系，还是只是在延迟破裂？
- 当别人不再需要他的退让，他还剩下什么？

## 8. 混淆防线

| 表面现象 | 不能直接判 nx 的原因 |
|:--------|:---------------------|
| 沉默 | 可能是克制、规则、观察或不想说 |
| 帮助别人 | 可能是主动照料或承担 |
| 服从 | 可能是职责和制度 |
| 忍耐 | 可能是在等待目标窗口 |
| 低存在感 | 可能只是视觉和社会位置 |
| 聪明看穿 | 是功能，不是纯 nx 主骨 |
| 暗算结算 | 旧口径，必须重新判复合或异化 |

一句话防误判：

> **去掉“为了维持关系或运转而反复压掉自己”以后，如果案例仍然成立，它就不是纯 nx。**
