# 三元—十元感受模型｜核心正本 v1.2.0

## 0｜本次版本更迭

本版把三元/十元的核心研究对象从“对象属于哪一类、领域如何映射五行/十元”，切换为：

> **人在具体艺术语境中，被对象、形式、行为、音乐、叙事或关系激活了什么感受。**

因此：

- 三元首先是**感受母结构**；
- 十元首先是**十种感受基元/感受方向**；
- 五轴首先是**五组相反感受关系**；
- 五行首先是**理论来源、文化参照与母感受研究入口**；
- 跨领域研究首先比较**不同媒介是否触发相近感受**，不再要求先给领域建立十类名词映射。

## 1｜三元的新核心定位

三元不再以“物象类别 / 精神类别 / 认可类别”作为最终本体定义。

本版冻结：

> **三元 = 对艺术与经验中基本感受方向的一级归纳。**

旧版关于醒、耐、z的物象、精神关系、认可结构等内容保留为历史形成材料、案例特征和可能的诱发条件，但不得继续自动推导“对象本体就是某元”。

本轮只冻结“感受模型”这一层级；三元三种感受各自的最小体验定义，在后续迁移轮逐项复核，不在R1凭空重写。

## R3-A 人是感受主语

> 感受的主语是人。AI只负责学习、编码、预测和生成“形式与人的感受之间的关系”，不把AI自身当作三元/十元的体验者。

详见：[[R3A_三元最小感受定义_人类主语_v1.0_20261007]]。

## 2｜十元的新核心定位

十元集合保持：

~~~
X / Z / N / ZN / NZ / XN / NX / ZX / XZ / X并Z
~~~

本版冻结：

> **十元不是把世界分成十类对象，而是描述人在具体语境中可能被激活的十种关系性感受基元。**

对象、领域与刺激可以无限变化；十元感受槽位保持有限。

核心原则：

> **刺激无限，十元感受有限。**

因此禁止把“这个石头是ZX”“这段音乐客观上是N”作为本体结论。应写成：

> “在当前语境中，这个对象主要激活ZX感受，同时伴随其他十元感受。”

## 3｜十元强度谱

每个具体刺激都可以形成十项1–10的感受强度谱。

~~~
对象 / 场景 / 音乐 / 行为
→ 十种感受分别1–10
→ Top1 = 当前主导感受
→ Top2 / Top3 = 次级感受
→ 完整分布 = 感受结构轮廓
~~~

最高值只表示**当前最强感受**，不表示对象的客观本体类别。

同一对象在不同光线、构图、故事、关系或时间点中，可以得到不同十元感受谱。

## 4｜五轴的新核心定位

固定配对暂保留：

~~~
木轴：ZX ↔ NX
火轴：ZN ↔ X
土轴：N ↔ X并Z
金轴：XN ↔ Z
水轴：XZ ↔ NZ
~~~

但本版改变解释层级：

> **五轴 = 十种感受基元中的五组相反感受方向。**

旧版“最终方向与作用权来源 / 对象独立成立资格 / 内外边界 / 裁定重心 / 可逆性”等结构变量，降为历史操作化工具与可能的感受诱发机制，不再作为“世界客观上被五轴划分”的本体证明。

R1保留配对拓扑，不在本轮重定义十个端点的完整体验语义。

## 5｜五行的新位置

五行不再承担“十元必须被证明为五行客观显化”的本体责任。

本版冻结：

> **五行 = 三元/十元感受理论的重要来源参照、关系思想来源与母感受研究入口。**

艺术研究中，“行”优先理解为：

> **感受的运动方式、倾向与变化，而不是一类固定物质对象。**

传统“五志”等材料可以用于提出五种母感受及其阴阳分化的研究假设，但不得直接宣布“人类客观只有十种情绪”或“阴阳五行已经证明十元成立”。

例如“水—恐”可以作为母感受研究入口；阴水/阳水如何进一步分化，必须作为模型假设继续研究，不在R1强行锁死具体情绪词。

## 6｜跨领域定义改写

旧版：

> 领域 → 建立五行狭义名词 → 十元操作 → 对象归类。

新版：

> **刺激 / 对象 / 形式 / 事件**
> → **人的直接感受**
> → **十元感受强度谱**
> → **主次 / 对立 / 生克补张 / 动态链**
> → **艺术构成与AI可执行化**

因此“跨领域同构”重新定义为：

> **角色、发型、音乐、镜头、建筑、故事等不同媒介，是否能触发相近的十元感受结构。**

跨领域不是“相同名词类别”，而是“相似感受结构”。

## 7｜审美构成接口

本版允许直接研究：

1. **同型统一**：不同媒介共同激活相近主导感受，是否产生统一感。
2. **关系对折**：主导感受被相反、生成、克制、补张感受扰动时，是否产生魅力与张力。
3. **动态链**：感受关系按“克→生→大克→补”等顺序变化时，是否形成稳定的审美节奏。
4. **强度谱**：Top1之外，Top2/Top3与完整十维谱是否影响整体体验。

这些属于创作与感知研究，不等于证明宇宙或客观世界由十元构成。

## 8｜AI的角色

AI不是十元理论的裁判。

AI在本体系中的核心用途是：

> **把抽象感受关系转译成可执行的角色、造型、音乐、镜头、叙事与生成控制规则。**

禁止：

> 用户先定义ZX → AI再说这是ZX → 因此证明ZX客观成立。

允许：

> 给定目标感受谱 → AI生成不同媒介刺激 → 观察实际感受是否接近目标 → 迭代创作规则。

## 9｜旧内核废弃声明

以下旧默认逻辑自本版起不再拥有核心定义权：

- “先把一个领域分成五行/十元十类，再开始案例。”
- “对象本体属于某个十元。”
- “领域狭义名称越能覆盖更多名词，定义越正确。”
- “跨领域映射就是同一个五行/十元概念在不同领域的is-a继承。”
- “十元必须通过五行、物理、系统论或现代科学证明其客观本体。”
- “旧五轴结构变量本身足以证明五行/十元客观成立。”

旧文件全部保留，用于追溯理论形成史、旧实验和可能有效的操作规则；其内容需要在R2/R3按新感受内核逐项迁移，不静默删除。

## 10｜R1冻结与未冻结

### 已冻结

~~~
核心对象：感受，而非对象分类
三元：一级感受母结构
十元：十种感受基元 / 感受方向
五轴：五组相反感受方向
五行：来源参照 / 母感受研究入口
跨领域：跨媒介相似感受触发
1–10：感受强度，不是对象身份
Top1：主导感受，不是客观本体
AI：执行与转译工具，不是理论裁判
~~~

### 尚未冻结

- 三元三种感受的最小体验定义；
- 十个十元各自的最终体验定义；
- 五种母感受与十种阴阳感受的完整对应；
- 旧五轴结构变量中哪些保留为可靠诱发机制；
- 生/克/补张在感受层的严格操作定义；
- 旧领域映射、信息卡、准度卡、解释器的逐文件迁移。

这些进入R2“影响面盘点”和R3“全量定义迁移”。

## 11｜一句话正本

> **三元与十元首先研究“人感受到什么”，而不是“世界里的东西客观属于什么”；五行提供关系与母感受参照，五轴组织相反感受，十元强度谱描述具体艺术刺激所激活的十种感受及其动态构成。**
