# 概念映射：破坏

---

## 第1步：一句话定义

**破坏**：系统从有序/整合状态向无序/碎裂状态的不可逆或半可逆转化，伴随结构崩解、功能丧失、能量泄漏、承载面断裂的综合过程。

---

## 第2步：三元粗拆

| 元 | 对应 | 在破坏中的体现 |
|:--:|:----|:--------------|
| **x** (形式/结构/问题面) | 结构的断裂、形态畸变、边界瓦解、秩序坍塌 |
| **z** (能量/流变/驱力面) | 破坏能、冲击波、内应力、腐蚀性驱动 |
| **n** (质料/承载面) | 被破坏的实体材料、组织、系统载体 |

## 第6步：查位置盘生成关系五对

从25对关系中选择，每对两条边，共五对。强制补/克/生至少各一对。

### 第1对：补——zx ↔ nx

| 方向 | 关系 | 含义 |
|:---:|:----|:-----|
| zx → nx | 补 | 冲击能(zx)与内应力释放(nx)相互补足——冲击释放内应力，内应力集中召唤冲击突破口 |
| nx → zx | 补 | 内应力积累(nx)补足冲击能(zx)的破坏效率——预应力使冲击事半功倍 |

### 第2对：克——xz 克 zn

| 方向 | 关系 | 含义 |
|:---:|:----|:-----|
| xz → zn | 克 | 崩塌(xz)压制地质体承载(zn)——崩塌释放的能量摧毁其所依附的地质基座 |
| (zn → xz的反向不成立) | 克单向 | 地质体不能克制崩塌，反而被崩塌消解 |

### 第3对：克——nx 克 x并z

| 方向 | 关系 | 含义 |
|:---:|:----|:-----|
| nx → x并z | 克 | 内应力释放(nx)克制爆散(x并z)——预裂释放后爆散能量被提前消耗 |
| (x并z → nx不成立) | 克单向 | 爆散反而会诱发更多内应力 |

### 第4对：生——zn 生 n

| 方向 | 关系 | 含义 |
|:---:|:----|:-----|
| zn → n | 生 | 地质体承载(zn)生养固体(n)——地质体是固体的母体和基质 |
| (反向) | 不成立 | 固体不生成地质体，而是从属于地质体 |

### 第5对：生——xz 生 xn

| 方向 | 关系 | 含义 |
|:---:|:----|:-----|
| xz → xn | 生 | 崩塌(xz)生成断裂(xn)——大崩塌必然产生断裂面 |
| (反向) | 不成立 | 断裂是崩塌的子形态 |

**结构特征**：崩塌作为破坏的"核心算子"，同时生成子形态（断裂）和压制承载基础（地质体）。形成破坏的垂直链。

## 第10步：跑3条动态链

### 主链（正向生成）：冲击(zx) → 崩塌(xz) → 断裂(xn) → 碎裂(x)

```
zx ──生→ xz ──生→ xn ──生→ x
冲击    崩塌    断裂    碎裂
```

**每步说明**：
1. 冲击(zx) 施加破坏能 → 结构失稳
2. 崩塌(xz) 结构整体塌陷 → 产生断裂面
3. 断裂(xn) 主裂纹扩展 → 交叉裂纹生成
4. 碎裂(x) 碎片化 → 破坏最终态

**强度**：7 + 9 + 8 = **24/30**

### 克链（压制/反抗）：地质体(zn) ↔ 固体(n) 承载 → 被崩塌(xz) 克 → 断裂(xn) 反克

```
zn ──生→ n ──被克→ xz ──生→ xn
地质体  固体   崩塌   断裂
            ↑ 反克阻力
```

**说明**：地质体承载固体，崩塌克制这一承载，但断裂产生后释放应力，对崩塌的反向消耗（崩塌后的松弛）。

**强度**：7 + 8 + 9 = **24/30**

### 补链（互济）：冲击(zx) ↔ 内应力(nx) → 影响爆散(x并z)

```
zx ←→ nx ──克→ x并z
冲击↔内应力    爆散
```

**说明**：冲击与内应力互补增强，共同克制爆散的突发性——应力释放使爆散被消化为有序碎裂。

**强度**：7 + 6 + 5 = **18/30**

| 链 | 总强度 | 排名 |
