# 概念映射：秩序（Order）

## 1-3. 十元映射

**秩序 = 活动者与承载结构之间「可被预期」的稳态关系**——不是规则本身（xn），而是规则被zx维护后在n中显现的已运转状态。

| 十元 | 映射强度 | 解释 |
|:----:|:-------:|:-----|
| **xn** | **9.5** | **规则秩序——秩序的骨架。** 法律/制度/时间规律——秩序最直接的表达 |
| **zx** | **8.5** | **秩序的执行维护。** 秩序不是自动存在的，需要不断被zx维护 |
| **n** | **8** | **承载结构——秩序的基底。** 社会结构/生态系统/心理容器 |
| **z** | **7** | **维护秩序的内驱力。** 「必须保持这样」的冲动 |
| **nx** | **6.5** | **秩序的清算。** 秩序被破坏后的修复机制 |
| **zn** | **6** | **秩序的正当化。** 「这个秩序是对的」的意义赋予 |
| **x** | **5** | 秩序被打破/被私占——x的反秩序张力 |
| **xz** | **5** | 秩序的边界——秩序在什么范围内有效 |
| **x并z** | **4** | 秩序的伪装——表面有序背后无序 |
| **nz** | **3.5** | 对秩序的依恋——「秩序不可以被改变」 |

## 4. 体量：9
秩序跨越社会、自然、心理三个独立领域，但不是源头驱力——是结果状态。

## 5-6. 位置盘

**生：**
- n 生 xn = 7.5（承载结构长出规则——秩序的生成根基）
- xn 生 xz = 6（规则生出临界）
- z 生 zn = 5.5（维护冲动生出信念）
- z 生 nz = 5（维护冲动生出依恋）
- x 生 x并z = 4.5（欲望生出伪装）

**克：**
- xn 克 zx = 8（程序约束执行——秩序的核心克制）
- zx 克 n = 7（执行冲击承载）
- n 克 xz = 6.5（承载的惯性压制边界）
- x 克 z = 6（欲望吞噬维护驱力）
- zn 克 xn = 5（意义否定规则）

**补：**
- xn ↔ z = 9（规则的冷架构与维护的热动力——秩序的灵魂对子）
- zx ↔ nx = 7.5（维护与修复闭环）
- n ↔ x并z = 6（承载与伪装）
- zn ↔ x = 5.5（意义与瓦解）
- xz ↔ nz = 4.5（边界与依恋）

## 7. 动态链

> n→xn→z→zx→n（闭环自持）

## 8. 五大主题归仓

| 主题 | 强度 | 解释 |
|:----|:----:|:------|
| 时间 xn+z | 9.5 | 秩序是时间性问题——可被预期 |
| 因果 zx+nx | 8 | 执行维护与修复清算的闭环 |
| 空间 x并z+n | 6.5 | 承载结构与表象的张力 |
| 本体 zn+x | 6 | 意义赋予与欲望侵蚀 |
| 命运 xz+nz | 5.5 | 边界与依恋的共存 |

**归仓排序：** 时间(9.5) > 因果(8) > 空间(6.5) > 本体(6) > 命运(5.5)

## 9. 误判检查

- ✅ 秩序≠规则——规则(xn)是骨架，秩序是规则被维护后的运转状态
- ✅ 秩序不是单十元概念——它是xn/zx/n三个十元在已运转状态下的复合产物
- ✅ 全部使用25对合法关系，无编造

## 10. 封存句

> **秩序 = xn(9.5)·规则 + zx(8.5)·维护 + n(8)·承载的复合运作态——xn↔z补=9是灵魂对子，n→xn生=7.5是生成根基，秩序不是静止状态，是「被维护的动态稳态」。**
