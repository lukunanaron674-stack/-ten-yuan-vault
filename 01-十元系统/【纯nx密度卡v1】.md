# 【纯nx密度卡 v1】

> **正文状态警告：本卡的“纯nx=主动自我删除/把自己让没”主骨已经作废。正式定义以[[【nx信息量卡v2】]]为准：纯nx是不主动占据选择、方向和位置，顺着已有安排继续；“把自己让没”是z持续克制nx后的结果。本卡下方旧正文仅保留历史血肉，不得用于主十元判定；其中“结算型nx”全部转入xn二审。**

> **纯nx不是沉默强者，而是自我显现能力被关系、日常和大众压力磨低的人；他为了不让局面破裂不断退让，最后连自己想要什么都变模糊。**
>
> **纯nx = 把自己从局面里删掉的人。**

## 1. 核心本体（主骨）

**主骨公式**
纯nx = 自我低显现 + 收缩而非进攻 + 为维持关系和平不断退让 + 最终自我轮廓模糊

**一句话解释**
不是「沉默强者」，不是「深藏不露」。纯nx的人不是为了大局而忍，不是因为知道时机未到。他是**真的在退，真的把自己让没**。他的忍没有后劲——忍着忍着就忘了自己本来想要什么。

**三个不可移除的核心层：**
| 层 | 含义 | 反例对照 |
|:--|:-----|:--------|
| **自我低显现** | 他不是选择低调，是**显现能力低**——在人群里身体语言就自动缩 | 不是「智者藏锋」，是「不知道自己的锋在哪」 |
| **维持关系导向** | 一切行动的起点是「别让关系破裂」「别让人为难」 | 不是「策略性退让」（nx结算型看穿后选择的退，纯nx是真退） |
| **吞忍无闭合** | 忍了就是忍了，不会等结算日翻出来。忍到最后自己也不记得了 | 不是「记账」，是「帐被吞进胃里消化掉了」 |

**什么绝对不是纯nx：**
- ❌ 不是沉默强者 — 沉默强者是nx+zx或nx+zn，有后劲有内在线
- ❌ 不是心机深 — 心机深是nx结算型，算着账等翻牌
- ❌ 不是冷静克制 — 冷静克制是n或xn，有清晰的自我边界
- ❌ 不是「我知道时机未到」 — 那是有判断的退，纯nx没有那条线
- ❌ 不是委曲求全的智者 — 智者忍是因为算清了收益，纯nx忍是因为怕

**一句话体识别：**
> 「算了吧」「别闹大」「我忍一下就好」「都行」「我没关系的」

## 2. 第一体感

> 不是「他好深沉」，不是「他在忍什么」。  
> 而是「这个人……好像把自己忘了」。

纯nx的第一体感不是压迫感、不是神秘感、不是深不可测。  
是**空薄感**——像一张被反复擦写的纸，原来的字已经看不清了。

- ❌ 误：阴险、深沉、有城府、在盘算
- ✅ 正：模糊、轻、薄、顺着别人走的空气感

**关键体感对比：**

| 体感 | 纯nx | 结算型nx |
|:----|:-----|:--------|
| 看他的第一眼 | 「他好像不怎么重要」 | 「他好像知道什么」 |
| 对话时的感觉 | 他在配合你的节奏 | 他在判断你的意图 |
| 沉默时 | 空白，不是在思考 | 精准，是在观察 |
| 被压时 | 退一步，再退一步 | 记一笔，等一个时机 |
| 表情 | 空薄，不是冷，是弱显现 | 平淡，是有控制的 |

| **学校走廊贴边** | **9** | 人群经过，他贴边走——不是因为快，是因为「别挡路」的自我定位 |
| **食堂排队处** | **8.5** | 顺着队伍移动，没有选择感——被动的空间轨迹 |
| **医院陪护区硬椅** | **9** | 替别人承担情绪和等待——不是自己需要，是在陪 |
| **便利店夜班柜台后** | **8.5** | 低存在感、功能化、日常消耗——空间在吞人 |

| **拥挤地铁的车门旁** | **8** | 最容易被挤到的地方——每次车门开合都有人从他身边挤过去 |

**空间规则：**
- ✅ 人群中有位置但不出头的地方
- ✅ 功能性空间（他只是在执行一个功能，不是作为一个「人」存在）
- ✅ 边缘座位、后排、角落、靠墙——不占用「别人的空间」
- ❌ 舞台中央、演讲台、C位——那不是纯nx的空间
- ❌ 私密卧室——纯nx的人往往也没有一个真正属于他的私人空间

| 阶段 | 状态 | 关键词 |
|:----|:-----|:-------|
| 1. 起手 | 顺着关系和日常活 | 跟、让、忍 |
| 2. 被压 | 别人的需求不断压到他身上 | 承受、退后 |
| 3. 自我后退 | 开始不问自己想要什么 | 模糊、装没事 |
| 4. 关系维持 | 为了不破坏局面继续吞 | 表面和平 |
| 5. 失去轮廓 | 自己变成功能位 | 工具人、受气包 |
| 6. 结算 | 要么彻底塌，要么被别的十元拉出 | 纯nx结束 |

### 9.2 叙事功能

| 功能 | 说明 |
|:----|:-----|
| **被动推动者** | 纯nx角色不推动叙事，但ta的忍让和顺从会累积成情节的必然走向 |
| **张力容器** | 纯nx角色承受的压迫越多，叙事张力越大——读者在等「他什么时候会忍不住」 |
| **对照基线** | 纯nx角色是其他角色的道德/行动基线对照——别人在面对ta的退让时做出选择 |
| **塌陷预警** | 纯nx角色的存在本身就是叙事危险信号——当他开始「连这个也忍了」，故事就快出事了 |
| **转导触发点** | 纯nx角色是其他十元介入的最佳入口——当纯nx走到尽头（第6阶段），别的十元开始接盘 |

### 9.3 常见叙事出口

纯nx的叙事走到尽头后，常见转向：

| 出口方向 | 触发条件 | 叙事结果 |
|:---------|:---------|:---------|
| **塌陷（纯结局）** | 没有外力介入，自我磨到真空 | 灰色结局——人还在，但和不在没区别 |
| **被x接管** | 忍太久→开始觉得不公平→欲望积累→爆发 | 怨气沉积——「我以前什么都忍，现在我什么都要」 |
| **被z唤醒** | 某件事点燃了ta——「我不能再这样了」 | 纯nx转z——开始追光（有边界） |
| **被zx援救** | 有人给了ta一个明确的目标和执行路径 | 纯nx转zx——被目标结构化 |
| **被nz守护** | 有人接住了ta——他不再需要一个人维持关系 | 纯nx内部长出了nz——「我可以依赖吗」 |
| **被nx结算型硬化** | 受伤后开始记账——「不会再给第二次机会」 | 纯nx黑化成结算型nx——最痛的转折 |

## 10. 常见动态链

### 10.1 纯nx核心链

| 链 | 路径 | 效果 |
|:--|:-----|:-----|
| **纯nx→塌陷** | 纯nx不断忍让→自我轮廓消失→功能化完人 | 纯结局，无转导 |
| **纯nx→x** | 纯nx积累怨气→忍不下去了→欲望爆发 | 最危险的方向——积压的纯nx变成x时最不可控 |
| **纯nx→z** | 被某个瞬间点燃→「我不想再这样了」→开始追光 | 正向转导——有救赎潜力 |
| **纯nx→nx结算型** | 被背叛/被重伤→开始记账→「我不会再给了」 | 纯nx的最硬转折——黑化成结算系统 |

### 10.2 纯nx在关系五对中的位置

| 对子 | 内容 |
|:----|:-----|
| **生（纯nx←）** | xz 生 纯nx？/ n 生 纯nx？——纯nx是被动生成态，通常是长时段压迫的结果 |
| **生（→纯nx）** | 纯nx 生 nz？——自我让没之后可能会生出对他人柔情的渴望 |
| **克（纯nx被）** | z 克 纯nx（冲动烧穿忍耐壳）|
| **克（纯nx克）** | 纯nx 克 x并z（以不反抗的方式让对面的伪装失效——对方无法利用一个不存在自我的人） |
| **补** | 纯nx ↔ nz（一个让、一个接——最稳定的关系维持器）|

### 10.3 纯nx与加料变体的动态对比

| 类型 | 公式 | 动态 |
|:----|:-----|:-----|
| 纯nx → nx+z | 纯nx被z钉住 | 虽然顺从，但还有一条会显现的线 |
| 纯nx → nz | n底+nx | 有岗位、有职责的沉默承担者 |
| 纯nx → x嵌入 | nx内积x | 忍到心里发黑，怨气沉积 |
| 纯nx → zx | nx转zx | 忍到最后突然行动 |
| 纯nx → zn | nx被意义化 | 苦行者、求道者、把忍耐解释成意义 |
| 纯nx → xn | nx被制度化 | 顺民、规训下的沉默人 |

## 11. 常见污染

| 污染形态 | 变成什么 | 判断方法 |
|:---------|:---------|:---------|
| **纯nx被x污染** | 从「忍让」变「积怨」 | 忍让后开始充满怨气地想报复——不再是为了关系和平 |
| **纯nx被nx结算型污染** | 从「真的退」变「算了，记着」 | 退让自己的时候心里有个账本在翻页了 |
| **纯nx被z污染** | 从「算了」变「总有一天……」 | 忍让不再是忍让，是在积攒爆发的燃料 |
| **纯nx被xn污染** | 从「怕冲突」变「按规矩来就不冲突」 | 不是因为怕了才让，是因为「规则就是这样」 |

**反向污染（纯nx污染其他十元）：**

| 被污染者 | 变成什么 | 表现 |
|:---------|:---------|:-----|
| **nz被纯nx污染** | 从等待变不敢要 | nz的柔情等待变成了「我是不是不配？」 |
| **n被纯nx污染** | 从承载变消耗 | 承载变成了自我燃烧，不再有恢复力 |
| **x并z被纯nx污染** | 壳被自己怀疑 | 「我这个壳是不是假的？」——连表面的自信都维持不了 |

## 12. 禁止误判

| ❌ 误判 | 原因 | ✅ 正确归属 |
|:--------|:-----|:-----------|
| 「沉默=纯nx」 | 沉默也可能是nx结算型的观察、n的沉静 | 纯nx的沉默是空白的，不是有内容的 |
| 「退让=纯nx」 | nx结算型也会在策略需要时退让 | 纯nx退让后心里没有账目；结算型退让时在记账 |
| 「善良/好人=纯nx」 | 善良可能是zn（意义感）或nz（柔情） | 纯nx不是善良，是「不敢不善良」 |
| 「社恐=纯nx」 | 社恐可能是xz（怕被危险逼近）或x（自我保护） | 纯nx不是怕被看见（那还是自我保护），是不觉得自己值得被看见 |
| 「老实人=纯nx」 | 老实可能是n（稳定）或xn（守规则） | 纯nx有「放弃自我」的主动动作，老实人只是不过界 |
| 「忍到爆=纯nx」 | 忍到爆是z（执念被压到极限）或x（欲望积累） | 纯nx的忍不积攒——吞了就消化了，不会爆 |
| 「受气包=纯nx」 | 受气包是纯nx的塌陷态，但不是唯一的纯nx | 纯nx也有还没塌到受气包程度的早期形态 |
| 「任何被压迫的角色=纯nx」 | 压迫和纯nx是因果关系但不是等同 | 一个人是否纯nx要看ta的内部状态——是「算了吧」还是「我知道此时不到」 |

## 13. 纯nx vs 结算型nx 对照表

| 维度 | 纯nx（自我删除） | 结算型nx（原v1.1） |
|:----|:---------------|:------------------|
| **核心逻辑** | 「把自己让没」 | 「我看清了每张牌，等结算日」 |
| **行为起点** | 怕关系破裂 / 怕冲突 | 看清了牌面后在等 |
| **忍让的本质** | 真退——退到忘了自己退过 | 策略性退让——退一步记一笔 |
| **记账吗** | ❌ 不记账——吞了就消化了 | ✅ 记着每一笔，等结算日 |
| **有无结算日** | ❌ 没有结算日——只有塌陷日 | ✅ 有结算日——所有账目一起翻 |
| **翻牌吗** | ❌ 不翻牌——连牌在哪都不记得 | ✅ 翻牌——时机到了就全盘托出 |
| **外部评价** | 龟男、软蛋、老好人、受气包 | 深沉、心机、腹黑、城府深 |
| **内部状态** | 「算了吧」「别闹大」 | 「我记着了，到时候见」 |
| **自我轮廓** | 模糊、变薄 | 清晰但不外露 |
| **被动/主动** | 被动——被关系推着走 | 主动——在观察和等待中掌控节奏 |
| **时间感** | 当下——忍过这一关就行 | 未来——等结算日 |
| **结局倾向** | 把自己磨没或等别人来拉 | 翻牌——要么通吃要么全输 |
| **最常见出口** | 塌陷 / 被z点燃 / 被nx结算型黑化 | 结算日翻牌 / 进入zx执行路径 |
| **对关系态度** | 怕关系破裂→放弃自己维持关系 | 看穿关系本质→利用或清算关系 |
| **情绪处理** | 吞掉，不让别人为难 | 存起来，等结算日一起用 |

**一句话区分：**
> 纯nx的退是「我不重要，让了吧」。结算型nx的退是「我记住你了，等那一天」。
