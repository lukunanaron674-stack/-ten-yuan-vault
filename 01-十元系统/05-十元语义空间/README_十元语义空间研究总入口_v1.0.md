# 十元语义空间研究｜总入口 v1.6

## 最高口径

```text
十元是五行内部的阴阳两极。
五行是同行两个十元的对立统一体。
五大主题是五行进入主题／叙事领域后的狭义定义。
```

五行固定映射：

```text
木＝zx↔nx
火＝zn↔x
土＝n↔x并z
金＝xn↔z
水＝xz↔nz
```

主题领域固定显化：

```text
木→因果
火→本体
土→空间
金→时间
水→命运
```

这不是两套系统偶然调用同一组合，而是同一五行结构进入主题领域后的具体命名。类似：木火土金水进入生理领域，对应肝心脾肺肾。

## 层级

```text
十元操作端
→ 五行对立统一体
→ 领域狭义显化
→ 具体案例显影
```

具体作品中某一主题是否成立，仍须检查中心问题、阶段、转折、高潮和结局；不能因为出现一个十元端，就宣布整个主题完成显影。

## 五大主题生克

```text
五行相生：木→火→土→金→水→木
主题显化：因果→本体→空间→时间→命运→因果

五行相克：木克土、土克水、水克火、火克金、金克木
主题显化：因果克空间、空间克命运、命运克本体、本体克时间、时间克因果
```

主题生克方向来自五行生克的领域显化；具体作品中的生克是否启动，仍需证据。

## 使用顺序

```text
先定十元操作端
→ 合并读取同行阴阳所构成的五行对立统一
→ 确认当前分析领域
→ 调用该领域的狭义定义
→ 最后判断具体案例显影与关系
```
