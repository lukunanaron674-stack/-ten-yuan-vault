## L1 的硬边界

L1 可以回答：

- 十个符号在固定环上的位置；
- 哪些位置属于五个锚点位，哪些属于五个间位；
- 每个符号的两个直接邻居；
- 两个位置之间的最短环步数；
- 五个锚点位在来源图中的五行与情志标签。

L1 不回答：

- 相邻是否意味着生、克、补；
- 顺时针是否意味着时间、生成或叙事顺序；
- 图形大小是否意味着体量、价值、置信度或层级；
- 距离是否意味着更容易转化；
- 中央“五行关系层”的箭头方向与严格机制。

## 下游使用规则

- 组合规律研究可读取 L1 坐标，但不得由相邻位置推出对子功能。
- 趋势规律研究可把 L1 作为背景坐标，但迁移箭头必须另有事实与机制。
- 动态链研究不得把环线、顺时针次序或视觉距离当作生克补证据。
- 单条关系正本与 L1 冲突时，先区分“静态位置”和“作用关系”，不得互相覆盖。
