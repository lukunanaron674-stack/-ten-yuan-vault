# 十元语义空间研究｜总入口 v1.2

## 最高口径

```text
五行就是十元。
十元就是五行各分阴阳后的十个直接位置。
同一五行的阴阳十元首先是相反两极。
```

不得再写成“五行在上、十元在下”，也不得写成“两个十元必须交补后才构成完整五行”。`zx`本身就是阳木，`nx`本身就是阴木；其余四行同理。

## 十元—五行直接身份

| 五行轴 | 阳极 | 阴极 | 情志 |
|---|---|---|---|
| 木 | `zx`＝阳木 | `nx`＝阴木 | 怒 |
| 火 | `zn`＝阳火 | `x`＝阴火 | 喜 |
| 土 | `n`＝阳土 | `x并z`＝阴土 | 思 |
| 金 | `xn`＝阳金 | `z`＝阴金 | 哀 |
| 水 | `xz`＝阳水 | `nz`＝阴水 | 恐 |

固定相反轴：

```text
阳木zx ↔ 阴木nx
阳火zn ↔ 阴火x
阳土n  ↔ 阴土x并z
阳金xn ↔ 阴金z
阳水xz ↔ 阴水nz
```

`↔`只表示同一五行内部的静态阴阳相反轴，不表示时间、因果、生、克、补、自动转化或必然共现。

## L1 外环

```text
zx → z → zn → nz → n → nx → xn → x → xz → x并z → 回到zx
```

外环负责：

- 十个阴阳五行位置；
- 每点两个直接邻居；
- 最短环距离；
- 五组几何对径位。

大圆、小圆只表示原图位置类型，不表示阳完整、阴附属，也不表示体量、价值、等级或主次。

## 环距离

```text
d_L1(a,b) = min(|index(a)-index(b)|, 10-|index(a)-index(b)|)
```

五组距离为5的对径位与阴阳相反轴重合：

```text
zx ↔ nx
zn ↔ x
n  ↔ x并z
xn ↔ z
xz ↔ nz
```

几何对径不能单独证明案例中的对立、互补、转化或生克补机制。

## 五行关系

### 相生

```text
木 → 火 → 土 → 金 → 水 → 木
```

### 相克

```text
木克土
土克水
水克火
火克金
金克木
```

五行生克是母结构，不能自动拆成任意十元对十元细边；具体单条十元生、克、补仍须由信息卡、准度卡、关系卡、生补克表与专项正本独立裁决。

## 退役口径

以下内容从 v1.2 起停止作为正本：

- 五行与十元是两套系统；
- 五行是上位父类、十元只是下位标签；
- `nx`属于阴金、`x并z`属于阴木、`nz`属于阴土、`x`属于阴水；
- 单个十元只是不完整五行的锚点；
- 阴阳必须先交补后才能构成一行；
- `⨝`是五行构成的核心符号。

## 下游使用规则

1. 先确认直接五行身份，再读十元信息卡判具体变量。
2. 阴阳相反只提供同一行的本体轴，不替代最近邻、拿掉、反向与对象层测试。
3. 共存、平衡、互补、转化、接管均须案例证据。
4. 动态链不得把相反轴、圆环邻接、几何对径或五行生克直接当作阶段迁移证据。
5. 情志、颜色、季节、职业、身份、能力、情绪和作品气质不得直接倒推十元。
