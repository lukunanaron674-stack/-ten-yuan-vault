# 十元语义空间研究｜总入口 v1.3

## 最高口径

```text
五行就是十元。
每个十元本身就是一个阴阳五行位。
同行阴阳必须在同一对象层、同一核心变量上执行相反操作。
```

固定五轴：

```text
木：阳木zx ↔ 阴木nx｜占据方向源 ↔ 让出方向源并沿既有通道推进
火：阳火zn ↔ 阴火x｜保留独立成立资格 ↔ 纳入单一归属掌握边界
土：阳土n ↔ 阴土x并z｜内部真实承载 ↔ 外部公共壳接口
金：阳金xn ↔ 阴金z｜分布式时序组织 ↔ 单点最高化集中
水：阳水xz ↔ 阴水nz｜关闭可逆回返空间 ↔ 保存或重开回返修复路径
```

特别纠正：

```text
z 与 zn 不是同行阴阳。
z 的同行相反端是 xn。
zn 的同行相反端是 x。
```

## 使用顺序

```text
先定对象层与改变变量
→ 判断唯一十元
→ 读取其同行相反端做反向检查
→ 再查准度卡
→ 最后查单条生克补关系
```

阴阳相反轴不自动证明生、克、补、互补、转化、先后或必然共现。
