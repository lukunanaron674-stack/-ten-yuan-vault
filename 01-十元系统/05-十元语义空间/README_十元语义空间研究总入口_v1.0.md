## L1 双层结构

### 外层：十元等距圆环

```text
zx → z → zn → nz → n → nx → xn → x → xz → x并z → 回到zx
```

外层负责：

- 十个符号的固定位置；
- 五个大圆锚点与五个小圆间位；
- 每点两个直接邻居；
- 最短环距离；
- 五组几何对径位。

### 中央：五行阴阳对子

每组固定为“前阳、后阴”，使用 `⨝` 作为交补符：

```text
木 = 阳zx ⨝ 阴nx = 怒
火 = 阳zn ⨝ 阴x = 喜
土 = 阳n  ⨝ 阴x并z = 思
金 = 阳xn ⨝ 阴z = 哀
水 = 阳xz ⨝ 阴nz = 恐
```

`⨝` 表示两个十元从阴阳两侧交会互补，共同构成一个完整五行。它不是单条十元关系卡里的严格“补”箭头。

## 五行关系

### 相生

```text
木 → 火 → 土 → 金 → 水 → 木
```

### 相克

```text
木克土
土克水
水克火
火克金
金克木
```

五行生克以完整五行对子为作用单位，不自动拆成四条十元对十元关系。具体单条十元生、克、补仍须由关系正本独立裁决。

## L1 环距离

```text
d_L1(a,b) = min(|index(a)-index(b)|, 10-|index(a)-index(b)|)
```

五组环距离为 5 的对径位：

```text
zx ↔ nx
zn ↔ x
n  ↔ x并z
xn ↔ z
xz ↔ nz
```

它们同时对应五行的阴阳配对，但“空间对径”和“五行交补”仍是两个不同层级的陈述。

## L1 的硬边界

L1 可以回答：

- 十元在哪里、谁与谁相邻、相隔几步；
- 哪五个节点是五行阳位锚点，哪五个节点是对应阴位；
- 每一行由哪两个十元交补构成；
- 五行层怎样相生、相克。

L1 不直接回答：

- 任意一条具体十元生、克、补是否成立；
- 外环邻接是否意味着容易转化；
- 顺时针是否意味着时间、生成或叙事顺序；
- 圆的大小是否意味着体量、价值或等级；
- 五行关系怎样自动展开成十元关系。

## 下游使用规则

- 组合研究可以读取五行阴阳对子，但不得把 `⨝` 当成已经审计通过的补边。
- 趋势研究可以使用外圈坐标和五行母结构，但迁移箭头仍须有事实、条件与机制。
- 动态链不得把圆环邻接、几何对径或五行生克直接替代阶段对子证据。
- 单条关系审计负责十元细分后的具体作用关系；L1 负责五行母结构与空间坐标。
