# 十元语义空间研究｜总入口 v1.5

## 最高口径

```text
五行就是十元。
同行阴阳必须在同一对象层、同一核心变量上执行相反操作。
同行阴阳既对立又统一：操作方向相反，但共同成轴并相互规定对极位置。
```

这里的“统一”不等于严格补关系，也不自动证明具体案例中发生良性互补、转化、共现或生克补。

固定五轴：

```text
木 zx↔nx｜最终方向与作用权来源
火 zn↔x ｜对象独立成立资格与归属方式
土 n↔x并z｜对象跨越内外边界的方向
金 xn↔z｜运行权与裁定重心的配置
水 xz↔nz｜可逆性与对象特异回返空间
```

精确定义：

```text
木：zx生成并占据方向 ↔ nx不占最终方向、沿已有通道续接
火：zn保留对象独立成立 ↔ x将对象纳入掌握与处分边界
土：n外→内纳入承载 ↔ x并z内→外映射外化
金：xn把运行与裁定分布到节点流程 ↔ z收束到单一最高裁定点
水：xz收窄退路与可逆空间 ↔ nz保存或重建回返修复路径
```

特别纠正：`z`的同行相反端是`xn`；`zn`的同行相反端是`x`。

## 使用顺序

```text
先定对象层与改变变量
→ 判断唯一十元
→ 用同行相反端做反向检查
→ 区分结构统一与严格关系
→ 再查信息卡与准度卡
→ 最后查单条生克补关系
```

同行阴阳在结构上同时具备两项：

```text
对立：同变量上的反向操作
统一：共同构成一轴，并相互规定彼此位置
```

结构统一不自动生成补边；阴阳相反轴也不自动证明生克、转化、先后或必然共现。动态变化必须另写完整的 `对子P1 ──条件/机制──▶ 对子P2`。
