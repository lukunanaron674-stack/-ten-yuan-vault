# L1｜十元—五行对立统一与领域显化正本 v1.6

## 0｜最高原则

```text
十元是五行内部的阴阳两极。
五行是同行两个十元的对立统一体。
五大主题是五行进入主题／叙事领域后的狭义定义。
```

因此，五行不是十元之外的父级标签，也不是两个十元机械相加后的第三物；它是同一核心变量上两个反向十元操作共同构成的统一结构。

固定身份：

```text
木＝阳木zx ↔ 阴木nx
火＝阳火zn ↔ 阴火x
土＝阳土n  ↔ 阴土x并z
金＝阳金xn ↔ 阴金z
水＝阳水xz ↔ 阴水nz
```

## 1｜对立统一的严格含义

```text
对立：同一对象层、同一核心变量、相反方向的结构操作。
统一：两端共同覆盖该变量的两个方向，并相互规定彼此的五行位置。
五行：这组对立统一本身。
```

统一不等于具体案例里已经发生严格补关系，也不保证两端必然同时出现、互相帮助或互相转化。

## 2｜五行广义本体

| 五行 | 阳端 | 阴端 | 广义对立统一变量 |
|---|---|---|---|
| 木 | zx | nx | 最终方向与作用权来源：自身生成并占据方向 ↔ 不占最终方向、沿既有通道续接 |
| 火 | zn | x | 对象独立成立资格与归属方式：保留自身成立 ↔ 纳入掌握、调用与处分边界 |
| 土 | n | x并z | 对象跨越内外边界的方向：外→内纳入承载 ↔ 内→外映射外化 |
| 金 | xn | z | 运行权与裁定重心配置：分布到规则节点流程 ↔ 收束到单一最高裁定点 |
| 水 | xz | nz | 可逆性与对象特异回返空间：持续收窄 ↔ 保存、恢复或重建 |

## 3｜领域狭义显化

五行是广义结构；进入不同领域后，会获得该领域的狭义名称、对象和判据。

```text
广义五行本体
→ 进入某一领域
→ 保留同一组阴阳对立统一
→ 形成该领域的狭义定义
```

这不是类比贴标签，而是同一结构在不同对象域中的具体化。

### 3.1 主题／叙事领域

| 五行 | 十元对立统一 | 主题领域狭义定义 |
|---|---|---|
| 木 | zx↔nx | 因果：作用如何沿方向发生，并使结果有来源与责任 |
| 火 | zn↔x | 本体：对象如何在独立成立与归属边界中被确定为“它是什么” |
| 土 | n↔x并z | 空间：对象怎样跨越内外、被容纳、分隔、呈现与进入 |
| 金 | xn↔z | 时间：变化怎样分布到阶段流程，又怎样由关键节点完成裁定 |
| 水 | xz↔nz | 命运：可能性怎样收窄为去向，又怎样保留或失去回返路径 |

标准写法：

```text
木在主题领域＝因果
火在主题领域＝本体
土在主题领域＝空间
金在主题领域＝时间
水在主题领域＝命运
```

因而，五大主题不是五行之外的第二套系统；它们是五行在主题领域的五个狭义器官。

### 3.2 生理领域类比

```text
木→肝
火→心
土→脾
金→肺
水→肾
```

心、肝、脾、肺、肾不是五行本体的全部，也不是与五行无关的另一套系统；它们是五行进入生理领域后的具体归属。五大主题与五行的关系同理。

## 4｜主题公式的重新解释

```text
因果＝zx ↔ nx＝木的主题领域显化
本体＝zn ↔ x＝火的主题领域显化
空间＝n ↔ x并z＝土的主题领域显化
时间＝xn ↔ z＝金的主题领域显化
命运＝xz ↔ nz＝水的主题领域显化
```

公式中的两端不是案例里临时拼接，也不是由额外的“z补合”生成主题；它们表示一行内部阴阳十元的对立统一。

## 5｜五大主题生克盘的来源

主题生克不是另造一套方向，而是五行生克在主题领域的狭义表达。

### 相生

```text
木生火生土生金生水生木
＝
因果生本体生空间生时间生命运生因果
```

### 相克

```text
木克土、土克水、水克火、火克金、金克木
＝
因果克空间、空间克命运、命运克本体、本体克时间、时间克因果
```

静态映射固定；具体作品里某一主题是否真正生克另一个主题，仍须有明确对象、方向、结果和证据。

## 6｜层级纪律

```text
十元：五行内部的阴阳操作端。
五行：两个同行十元的对立统一体。
五大主题：五行在主题／叙事领域的狭义定义。
主题案例：某部作品中对该领域定义的具体显影。
```

禁止：

- 把五大主题与五行写成互不相关的两套系统；
- 把相同十元组合说成只是“公式外形碰巧相同”；
- 把主题构成解释为额外关系符号把两个十元临时补合；
- 仅凭出现一个十元端，就宣布整行主题已经完整显影；
- 用传统脏腑、颜色、情志或季节直接倒推具体人物十元。
