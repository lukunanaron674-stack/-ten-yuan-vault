# L1｜十元即阴阳五行相反轴正本 v1.3

## 0｜最高核心概念

```text
五行就是十元。
十元就是木、火、土、金、水各自分阴阳后形成的十个直接位置。
同一五行的阴、阳十元，必须在同一核心变量上表现为相反操作。
```

固定身份：

```text
zx = 阳木    nx = 阴木
zn = 阳火    x  = 阴火
n  = 阳土    x并z = 阴土
xn = 阳金    z  = 阴金
xz = 阳水    nz = 阴水
```

因此，`z/zn`不是阴阳两端：

```text
金轴：阳金xn ↔ 阴金z
火轴：阳火zn ↔ 阴火x
```

## 1｜“相反”的严格含义

阴阳相反不是两个词在字典里互为反义词，而是：

> **在同一个对象层、同一个核心变量上，一端使变量向一个方向变化，另一端使它向反方向变化。**

它不自动表示：

- 两端互相仇视或互相消灭；
- 一端善、一端恶；
- 一个人只能拥有一端；
- 两端必然互补、转化或同时出现；
- 外放必为阳、内收必为阴；
- 主动必为阳、被动必为阴。

人物可以在不同对象、阶段和功能上使用同行两端，但同一条行为只能按实际改变变量唯一归类。

## 2｜五条阴阳相反轴的广义变量

| 五行轴 | 阳极操作 | 阴极操作 | 同轴核心变量 |
|---|---|---|---|
| 木 `zx↔nx` | `zx`占据方向源，以自身权能向外施加并压退竞争方向 | `nx`不占最终方向，接入既有路线、关系、权限或通道继续推进 | 最终方向由谁产生、谁占据施力源 |
| 火 `zn↔x` | `zn`保留自己与他者作为独立意义主体的成立资格，彼此不必被吸收或取消 | `x`划定“归我/我方”的掌握边界，使对象进入可使用、调配、处分或排除的范围 | 对象保持独立主体资格，还是被纳入单一掌握范围 |
| 土 `n↔x并z` | `n`让对象真实进入内部、获得位置并承担持续负荷 | `x并z`把内部对象映射为外部可识别、调用、归因、代表或进入的公共壳 | 内部真实承载，还是外部公共接口 |
| 金 `xn↔z` | `xn`把对象分布进顺序、规则、记录和流程，使其跨阶段持续运行 | `z`把一个对象提升为最高中心，使注意、评价、资源或选择重心集中，其他对象退出中心判断 | 结构重心被分布组织，还是集中到单一最高点 |
| 水 `xz↔nz` | `xz`使路线、时间窗、退路和可逆空间持续收窄 | `nz`保留或恢复对象特异的回返、修复与重新连接路径 | 可逆与回返空间被关闭，还是被保存/重开 |

### 2.1 相反轴不等于严格关系

`↔`只表示同行阴阳的静态本体相反。它不等于生、克、补，也不自动证明两端在具体案例里发生作用。

## 3｜广义、领域与狭义必须同轴

```text
广义本体层：任何领域都不变的最小结构操作
→ 领域关系层：进入人际、叙事、构图、音乐、游戏、社会后的具体变量
→ 狭义人物层：人物在触发下对对象做出的可观察行为
```

三层必须满足：

1. 狭义行为能由广义操作生成；
2. 同行另一端能在同一变量上写出反向行为；
3. 广义定义不能靠人物心理、职业、情绪或作品主题成立；
4. 狭义人物定义不能把某一高频子型冒充整个十元。

## 4｜本轮广义—狭义审计结论

| 轴 | 广义层 | 旧狭义层 | 结论 |
|---|---|---|---|
| 木 `zx↔nx` | 已同轴 | 已同轴 | 保留 |
| 火 `zn↔x` | 已同轴 | 旧`zn=单项内部原则`过窄；旧x五行字段误写阴水 | 修正：zn回到“多主体独立成立”，x固定阴火 |
| 土 `n↔x并z` | 已同轴 | 已同轴 | 保留；明确“内实↔外壳”不是敌对 |
| 金 `xn↔z` | 已同轴 | 旧`z=必须被认可`过窄，无法与xn形成同变量反向 | 修正：z回到“单点最高化”，认可降为条件子型 |
| 水 `xz↔nz` | 已同轴 | 已同轴 | 保留 |

## 5｜狭义人物层最短句

```text
zx｜我来定方向，并把力量压到外部对象上。
nx｜方向不是我定，我沿既有路线与权限继续。

zn｜我成立，也实际保留你们各自成立与继续的资格。
x ｜对象、资源、权限或关系进入“归我/我方掌握”的边界。

n ｜我真正把对象接进内部，并持续承担它的负荷。
x并z｜我建立外部可识别、调用、代表或进入的稳定壳。

xn｜我把分散行动组织成可重复、可积累、可持续的结构。
z ｜我把自己或某一目标置为最高中心，其他对象不进入中心判断。

xz｜我使或面对的局势正在压缩退路、时间窗与可逆空间。
nz｜我保留或恢复针对特定对象的真实回返与修复路径。
```

已确认人际口径：

```text
ZN＝你们都对，我也是对的。
z ＝我是最对的，你们不关我事。
ZX＝我是对的，你们都是错的。
X 的人际对错句保持未定义。
```

## 6｜五行身份、圆环与距离

顺时针固定环序：

```text
zx → z → zn → nz → n → nx → xn → x → xz → x并z → 回到zx
```

最短环距离：

```text
d_L1(a,b) = min(|index(a)-index(b)|, 10-|index(a)-index(b)|)
```

五组距离为5的对径位与阴阳相反轴重合：

```text
zx↔nx｜zn↔x｜n↔x并z｜xn↔z｜xz↔nz
```

对径是几何事实；阴阳相反是本体解释；两者都不能自动生成动态关系。

## 7｜五行相生与相克

```text
相生：木 → 火 → 土 → 金 → 水 → 木
相克：木克土、土克水、水克火、火克金、金克木
```

五行生克作用单位是五行轴，不自动展开为十元细边。单条十元生、克、补仍以关系卡、关系表和专项正本为准；端点定义改变后，涉及该端点的旧关系必须重新审计。

## 8｜读取纪律

```text
先确认五行身份与同行相反端
→ 再读信息卡确认具体变量
→ 再读准度卡做最近邻、拿掉与反向
→ 最后查关系是否经当前端点重新审计
```

禁止：

- 把`z/zn`当成同行阴阳；
- 把“坚持自己的路”自动判`zn`；
- 把“需要别人认可”自动判纯`z`；
- 用情志、颜色、职业、善恶、战斗、温柔或作品气质倒推十元；
- 把相反轴偷换为已成立的互补关系。
