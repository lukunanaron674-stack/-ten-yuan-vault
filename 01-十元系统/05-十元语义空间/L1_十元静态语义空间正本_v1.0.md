# L1｜十元静态语义空间正本 v1.0

## 0. L1 要解决的问题

L1 只解决一个基础问题：

> 十个十元符号在同一张静态图上分别处于哪里，谁与谁直接相邻，这张图允许怎样读取，又禁止怎样过度解释。

L1 是坐标底图，不是关系图，也不是动态链图。环上两点挨着，只证明它们在这张拓扑上挨着。邻居并不会因此自动签署生克补协议，宇宙暂时还没这么省事。

## 1. 两类位置

来源图把十个符号分成五个大圆与五个小圆。L1 将它们规范为两种**空间角色**：

### 1.1 锚点位（大圆）

```text
zx｜zn｜n｜xn｜xz
```

### 1.2 间位（小圆）

```text
z｜nz｜nx｜x｜x并z
```

### 1.3 大小的唯一含义

大圆与小圆只表示 L1 的位置类型：

- 大圆 = 锚点位；
- 小圆 = 两个相邻锚点之间的间位。

它们**不表示**：

- 体量大小；
- 理论重要性；
- 高低层级；
- 使用频率；
- 置信度；
- 主十元或次十元资格。

## 2. 固定环序

以 `zx` 为顶部起点，按顺时针读取，唯一规范顺序为：

```text
zx → z → zn → nz → n → nx → xn → x → xz → x并z → 回到zx
```

反向读取为：

```text
zx → x并z → xz → x → xn → nx → n → nz → zn → z → 回到zx
```

顺时针与逆时针只是坐标索引方向，不携带时间、因果、生成、退化或价值判断。

## 3. 五组“锚点—间位—锚点”

```text
xz ─ x并z ─ zx
zx ─ z    ─ zn
zn ─ nz   ─ n
n  ─ nx   ─ xn
xn ─ x    ─ xz
```

这五组三点结构完整覆盖外环。每个间位只位于一对相邻锚点之间；每个锚点左右各接一个间位。

## 4. 直接邻接表

| 符号 | 位置类型 | 逆时针直接邻居 | 顺时针直接邻居 |
|---|---|---|---|
| `zx` | 锚点位 | `x并z` | `z` |
| `z` | 间位 | `zx` | `zn` |
| `zn` | 锚点位 | `z` | `nz` |
| `nz` | 间位 | `zn` | `n` |
| `n` | 锚点位 | `nz` | `nx` |
| `nx` | 间位 | `n` | `xn` |
| `xn` | 锚点位 | `nx` | `x` |
| `x` | 间位 | `xn` | `xz` |
| `xz` | 锚点位 | `x` | `x并z` |
| `x并z` | 间位 | `xz` | `zx` |

“直接邻接”仅指外环上共享一条无向线段，不等同于任何严格关系。

## 5. L1 环距离

给顺时针序列编号：

```text
0 zx
1 z
2 zn
3 nz
4 n
5 nx
6 xn
7 x
8 xz
9 x并z
```

两个符号 `a` 与 `b` 的 L1 环距离定义为：

```text
d_L1(a,b) = min(|index(a)-index(b)|, 10-|index(a)-index(b)|)
```

距离范围为 `0—5`：

- `0`：同一点；
- `1`：直接邻接；
- `2—4`：隔着相应数量的环步；
- `5`：几何对径位。

### 5.1 五组几何对径位

```text
zx  ↔ nx
z   ↔ xn
zn  ↔ x
nz  ↔ xz
n   ↔ x并z
```

“对径”只表示环距离为 5，不自动表示语义相反、互克、互补或命运对立。

## 6. 五行与情志标签

来源图只给五个锚点位标注五行与情志。L1 按原图规范如下：

| 锚点位 | 五行 | 情志 | 来源图显示 |
|---|---|---|---|
| `zx` | 木 | 怒 | `ZX 木怒` |
| `zn` | 火 | 喜 | `ZN 火喜` |
| `n` | 土 | 思 | `n 思土` |
| `xn` | 金 | 哀 | `xn 哀金` |
| `xz` | 水 | 恐 | `XZ 水恐` |

五个间位 `z / nz / nx / x / x并z` 在来源图中没有独立的五行或情志副标题，L1 不替它们补造标签。

这些五行与情志是**空间标注层**，不代替十元信息卡中的端点定义。不能因为 `zx` 标注“怒”就把一切愤怒都判成 `zx`；也不能因为 `n` 标注“土”就把一切土地、房间或容器判成 `n`。

## 7. 中央“五行关系层”的处理

来源图中央写有“五行符号关系”，并存在五边形路径形状。由于原图没有为每条中央线提供可独立核验的端点、方向、关系名称、条件与机制，L1 只保留它作为：

```text
五行关系层占位
```

L1 **不锁定**中央线的：

- 起点与终点；
- 顺逆方向；
- 生、克、补类型；
- 强弱关系；
- 动态阶段含义。

相关作用关系必须回到十元生补克表、单条关系卡与审计正本，不能从图形箭头外观倒推。

## 8. L1 视觉语法

| 图形元素 | L1 允许含义 | 禁止解释 |
|---|---|---|
| 大圆 | 锚点位 | 体量大、重要、高级 |
| 小圆 | 间位 | 体量小、次要、附属 |
| 外环线 | 直接邻接 | 生、克、补或容易转化 |
| 顺时针排列 | 坐标索引 | 时间顺序、生成顺序、叙事顺序 |
| 五行情志文字 | 来源图标签 | 端点完整定义 |
| 中央五边形 | 五行关系层占位 | 已审计的关系箭头 |

## 11. 下游接口

### 给组合规律研究

L1 提供符号位置与位置类型。组合卡仍须独立证明主次、对象层、体量、激活方式和整体功能。

### 给趋势规律研究

L1 只提供静态坐标。`P1 → P2` 的迁移类型、条件和机制必须来自趋势证据，不得由环距离生成。

### 给动态链研究

外环相邻不构成箭头。动态链仍须写清完整对子、方向、条件、失败边和阶段变化。

### 给关系审计

单条生克补关系可以跨越任意 L1 环距离。L1 距离不提高也不降低七项置信度。

```text
十元静态语义空间是一张固定的十节点无向环形拓扑。

不定义生克补、动态迁移、语义相似、体量或叙事顺序。
```
