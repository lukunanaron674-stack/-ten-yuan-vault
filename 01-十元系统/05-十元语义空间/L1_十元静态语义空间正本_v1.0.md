# L1｜十元静态语义空间正本 v1.0（已归档）

> 本版只完成了十节点圆环、锚点/间位、邻接、环距离和五个锚点的五行情志标注；它把中央五行关系暂时当作占位，因此已经被 v1.1 取代。

当前唯一正本：

- [[L1_十元空间与五行阴阳正本_v1.1|L1 十元空间与五行阴阳正本 v1.1]]

v1.1 在完整保留等距十节点圆环的基础上，新增并固定：

```text
前项 = 阳
后项 = 阴

木 = 阳zx ⨝ 阴nx = 怒
火 = 阳zn ⨝ 阴x = 喜
土 = 阳n  ⨝ 阴x并z = 思
金 = 阳xn ⨝ 阴z = 哀
水 = 阳xz ⨝ 阴nz = 恐
```

同时固定五行层的标准相生与相克：

```text
相生：木 → 火 → 土 → 金 → 水 → 木
相克：木克土、土克水、水克火、火克金、金克木
```

`⨝` 是五行层的交补符，表示阴阳两个十元交会互补成一行，不等于已经通过审计的单条十元“补”关系。
