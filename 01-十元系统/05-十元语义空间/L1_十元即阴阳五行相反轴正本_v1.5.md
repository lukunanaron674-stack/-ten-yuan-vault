# L1｜十元即阴阳五行相反轴正本 v1.5

## 0｜最高原则

```text
五行就是十元。
同一五行的阴、阳十元，必须在同一对象层、同一核心变量上执行相反方向的结构操作。
同行阴阳既对立又统一：操作方向相反，但共同构成同一五行轴，并相互规定彼此的对极位置。
```

这里的“统一”是**共同成轴、相互规定**，不是已经成立的单条十元“补”关系，也不保证具体案例中必然良性互补、共现或转化。

固定身份：

```text
zx＝阳木    nx＝阴木
zn＝阳火    x＝阴火
n＝阳土     x并z＝阴土
xn＝阳金    z＝阴金
xz＝阳水    nz＝阴水
```

`z/zn`不是阴阳轴：

```text
金轴：阳金xn ↔ 阴金z
火轴：阳火zn ↔ 阴火x
```

## 1｜五组相反轴最终结构

| 五行轴 | 阳端操作 | 阴端操作 | 真正相反的核心变量 |
|---|---|---|---|
| 木 `zx↔nx` | `zx`生成并占据最终方向，以自身权能直接作用于对象 | `nx`不占据最终方向，接入外部已有路线、关系、权限或通道续接 | 最终方向与作用权的来源 |
| 火 `zn↔x` | `zn`保留对象自身的意义、选择、发展与独立成立资格 | `x`划定归属边界，使对象进入某一范围的调用、调配、处分或排除资格 | 对象的独立成立资格与归属方式 |
| 土 `n↔x并z` | `n`使外部对象进入内部、获得真实位置，并由内部承担其持续负荷 | `x并z`使内部对象映射到外部、形成稳定公共形式，供外界识别、调用、归因、代表或进入 | 对象跨越内外边界的方向：外→内纳入承载 ↔ 内→外映射外化 |
| 金 `xn↔z` | `xn`把运行权分布到顺序、规则、记录、节点和跨阶段流程中 | `z`把判断权与结构重心收束到一个最高中心、最终标准或唯一优先点 | 运行权与裁定重心的配置：分布 ↔ 集中 |
| 水 `xz↔nz` | `xz`使退路、时间窗、可选路线和可逆空间持续收窄 | `nz`保存、恢复或重新建立针对特定对象的回返、修复和重新连接路径 | 可逆性与对象特异回返空间 |

## 2｜对立统一：同一轴的双层规定

```text
结构对立 = 同一对象层 + 同一核心变量 + 反向操作
结构统一 = 同属一个五行轴 + 相互规定对极位置 + 共同覆盖该变量的两个方向
```

二者同时成立，不是“先相反、再互补”的时间顺序：

- 没有阴端作为对极，阳端仍可单独出现，但不能在该五行轴上被完整定位；反之亦然。
- 两端共同成轴，不代表人物、场景或事件必须同时出现两端。
- 两端可在具体条件下共存、互相支撑、发生主导权切换，或由一端的功能转向另一端；这些都属于待审计的动态事实，不能由L1静态结构直接推出。
- “统一”包含共同成维与相互规定；“互补”只是某些具体关系中的一种可能表现，不能用来替代统一的全部含义。

## 3｜相反不等于互斥

同行阴阳相反只表示同变量上的反向操作，不自动表示：

- 互相消灭、善恶对立或高低等级；
- 一个人只能拥有一端；
- 主动必为阳、被动必为阴；
- 必然发生良性互补、转化、共现或形成生克补；
- 两端在不同对象层上也必然相反。

同一人物可以在不同对象、阶段和功能上使用同行两端；同一条行为仍须唯一归类。

## 4｜结构统一不等于严格补关系

```text
L1结构层：同行阴阳共同成轴、相互规定
关系层：具体十元之间是否构成生 / 克 / 补边
动态层：完整对子 P1 ──条件 / 机制──▶ 完整对子 P2
```

强制边界：

1. 不能因为两端同行，就直接写成“互补已成立”。
2. 不能因为两端相反，就直接写成“互克已成立”。
3. 不能因为一端之后出现另一端，就直接写成“发生转化”。
4. 若使用严格生、克、补箭头，必须引用已锁定的单条关系正本。
5. 若描述动态转移，必须写明对象层、起点对子、终点对子、方向箭头、触发条件、阶段边界及主导权或体量变化。

## 5｜人物层最短句

```text
zx：方向由我产生，我直接使对象改变。
nx：方向已经存在，我沿它继续。

zn：我成立，也让你作为你自己继续成立。
x：对象进入我方掌握、调用与处分边界。

n：我把外部对象真正接进内部，并持续承担它。
x并z：我把内部对象外化成世界可识别和调用的稳定壳。

xn：我把运行分布到多个步骤、规则和节点。
z：我把一个目标、自我或答案置为最高裁定中心。

xz：越来越回不去了。
nz：仍能回来，或重新建立回来的路。
```

已确认人际口径：

```text
ZN＝你们都对，我也是对的。
z＝我是最对的，你们不关我事。
ZX＝我是对的，你们都是错的。
X的人际对错句未定义。
```

## 6｜审核等级

| 轴 | 审核状态 |
|---|---|
| 木 `zx↔nx` | 强成立 |
| 火 `zn↔x` | 成立；广义层须使用“对象独立资格/归属方式”，不局限“多主体” |
| 土 `n↔x并z` | 成立；必须使用“边界穿越方向”，不能只写“内实/外壳” |
| 金 `xn↔z` | 成立；必须使用“运行权与裁定权配置”，不能只写视觉分散/集中 |
| 水 `xz↔nz` | 强成立 |

## 7｜圆环与距离

固定环序：

```text
zx → z → zn → nz → n → nx → xn → x → xz → x并z → zx
```

最短环距离：

```text
d_L1(a,b)=min(|index(a)-index(b)|,10-|index(a)-index(b)|)
```

距离为5的对径位与五行阴阳相反轴重合：

```text
zx↔nx｜zn↔x｜n↔x并z｜xn↔z｜xz↔nz
```

几何对径与本体相反均不能自动生成动态关系。

## 8｜五行母结构

```text
相生：木→火→土→金→水→木
相克：木克土、土克水、水克火、火克金、金克木
```

五行关系不自动展开为十元细边。单条生、克、补必须重新经过端点、对象层、改变变量、拿掉、反向、最近邻与第三因素审计。
