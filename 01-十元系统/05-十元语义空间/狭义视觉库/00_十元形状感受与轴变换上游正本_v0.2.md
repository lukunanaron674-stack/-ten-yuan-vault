## 3｜轴向规则

### 3.1 画面全局轴

```text
x轴：左右宽度、横向展开或横向压缩
y轴：上下长度、纵向拉长或纵向压缩
```

当前已给定：

- 散开的发束沿 x轴铺展，视觉更偏 `nx`；
- 中间保留集中刘海，压缩两侧可用 x轴，视觉更偏 `x`；
- 厚而平的刘海压缩 y轴，也会加强 `x` 的压迫和危险蓄积感；
- 两侧长刘海沿 y轴拉长，视觉更偏 `z`。

### 3.2 发束局部轴

发束可以旋转、斜置，因此还要保存局部轴：

```text
局部长轴 L：发束主要延伸方向
局部横轴 W：垂直于 L 的宽度
```

- `z`：L拉长，W大体稳定，形成长片／长方形；
- `x`：宽度被压缩并形成三角危险块，但不要求结构主动前冲；
- `xz`：x的危险蓄积体沿z的触发通道显影，形成带尖端／引信的长三角或长楔形。

## 4｜x 的视觉感觉

### 4.1 一句话

> **x 是具有攻击性和危险性的压缩体，但危险主要处于蓄积状态，本身不主动发动。**

它像：

```text
没有被点燃的火药
收紧的捕兽夹
还未落下的尖刃
内部压力很高的封闭三角
```

因此：

- x可以危险，却静止；
- x可以有攻击形，却没有主动方向；
- x的核心不是“已经冲出去”，而是“它本身就具备伤害可能”；
- 若结构主动把力量推出并占据方向，应优先检查 `zx`，不能因为尖锐就全部归 x。

## 5｜z 在 xz 中的作用

在 `xz` 组合里，z不是简单给三角增加长度，而是增加：

```text
触发点
点火点
引爆节点
把潜在危险变成发生事件的一点
```

z可以表现为：

- 一个明确尖端；
- 一个被碰到就改变全局的节点；
- 一条把危险体连接到触发点的长轴；
- 一个视觉上高度集中的点火口／引信端。

没有x时，z只是节点、长片或触发点；没有危险蓄积体，不构成xz。

## 6｜xz 发型视觉定义 v0.2

### 6.1 一句话

> **xz 是一个本身具有攻击性和危险性、但尚未主动发动的蓄积体，因为加入了明确的 z 触发点或引信节点，而成为“碰到一点就会整体爆开”的临界结构。**

最短公式：

```text
x：危险蓄积体，但不主动
＋
z：触发点／点火点
＝
xz：可被一点引爆的危险体
```

火药桶模型：

```text
火药桶本体＝x
火星、引信、点火口＝z
被点中后整体爆开的临界体＝xz
```

### 6.2 形状显影

xz常可显成：

```text
长三角
长楔形
矛形
宽危险体＋窄引信尖端
```

但“长三角”只是结果，不是唯一原因。正式判断必须同时存在：

1. **x危险体**：整体有压缩、攻击、伤害或高张力的蓄积感；
2. **不主动**：结构不是自己向外推进，不以主动扩张为本体；
3. **z触发点**：存在一个明确的尖端、节点、引信端或点火口；
4. **局部牵动整体**：该点一旦被触发，视觉上会使整个危险体释放或爆开；
5. **整体连续**：危险体与触发点属于同一个结构，不是随机两根碎发拼在一起；
6. **主轮廓承担**：xz必须由主要轮廓承担，不能只由内部小尖束冒充。

### 6.3 发型中的视觉翻译

发型里的xz不等于真的爆炸，而是表现：

- 一块被压住的危险轮廓；
- 危险没有主动外冲，但张力高度集中；
- 一个长尖端、细长前束或明确尖点像引信；
- 尖端与主体相连，使人感觉“碰到这里，整体就会释放”；
- 轮廓可概括成宽部蓄势、窄部触发的长三角。

可能的候选：

- 单片长楔形斜刘海，宽根压住、尖端像引信；
- 中央或侧面具有明确长尖端的危险块面；
- 矛形前发，主体厚实而尖端集中；
- 长三角前束，整体静止，但尖端具有临界触发感。

这些只是候选形态，尚未用于现有刘海库重判。

## 7｜最近邻区别

### xz vs x

```text
x：危险体已经成立，但没有明确的触发节点；像未接引信的火药。
xz：危险体保留，同时出现一个能点燃整体的z节点；像接上引信的火药桶。
```

形状上：

```text
x：三角、短压缩、攻击感集中。
xz：三角危险体被拉出明确触发尖端，常显成长三角／长楔形。
```

### xz vs z

```text
z：只有节点、长轴、截点或触发点。
xz：节点连接了真实危险蓄积体，触发后会牵动整体。
```

### xz vs zx

```text
zx：已经主动把力量推出去，主动占据方向。
xz：本身不主动，危险处于临界蓄积，等待某个点把它引爆。
```

这是本版最重要区别：

```text
主动推出＝zx
被点爆＝xz
```

### xz vs nx

```text
nx：方形、散碎、横向铺展，没有唯一触发尖端，也没有整体危险蓄积体。
xz：整体连续、危险集中，并有可牵动全局的触发点。
```

**散碎不能单判xz。** 羽化、乱边、多方向、颗粒化优先检查 `nx`，自然自成纹理再检查 `zn`。

### xz vs nz

```text
nz：扁椭圆、柔软停靠、低重心、圆钝回落。
xz：危险蓄积、临界触发、尖端集中，没有柔软停靠感。
```

### xz vs zn

```text
zn：长椭圆、自身生长、两端圆润，不依靠触发点成立。
xz：危险体与触发点共同成立，至少一端具有引信式尖点。
```

## 8｜拿掉测试

```text
拿掉危险性，只剩长尖发束 → 可能只是z或普通造型，不是xz。
拿掉触发点，只剩危险三角块 → x。
拿掉“被触发后牵动整体”，尖端只是装饰 → 不是完整xz。
让结构自己主动向外推出 → 优先zx。
打散成许多碎束，没有统一危险体与引信 → 优先nx／zn。
磨圆并压扁整体 → 优先nz。
```

## 9｜截图示例的当前判断

对整体蓬松、横向展开、低而圆钝的发型：

```text
整体外轮廓：扁椭圆 → nz候选
内部散碎纹理：方形／横向铺展 → nx候选
xz：不成立，因为没有统一危险蓄积体，也没有可牵动整体的z触发尖端
```

必须分开：

```text
整体轮廓主十元
内部纹理副十元
局部尖束功能十元
```

不得拿内部几根尖发替换整体形状判断。
