# 发型98种十元形状映射接口 v0.2

## 1｜目的

连接：

```text
狭义视觉形状正本
→ 发型图片观察
→ 整体/内部/局部分层
→ 十元候选
→ 十元配比度
→ 单十元本征映射准度
→ 五行重组与排名
```

本接口定义复审方法，不允许旧纯度直接冒充视觉终审。

## 3｜第一层：对象分层

每张图片先分：

```text
A. 整体外轮廓主形
B. 内部发束纹理
C. 局部尖束、束点或切口
D. 临时状态：风吹、湿发、动作、光影
```

D层不得替代发型本体判断。内部几根尖发不得覆盖整体扁椭圆、圆形、方形或长椭圆主轮廓。

## 4｜第二层：轴向观察

```yaml
x_axis:

  evidence:

  state: extend | compress | stable | mixed
  evidence:

```

已确认规则：

- X轴扩散、碎束横向铺开 → `nx`候选；
- 中央刘海压缩X轴 → `x`候选；
- 厚平刘海压缩Y轴 → `x`候选；
- 两侧长刘海拉长Y轴 → `z`候选。

## 5｜第三层：形状候选

| 十元 | 已确认几何 | 发型观察 |
|---|---|---|
| `x` | 三角 | 刀、尖刺、锐利切割、中心压缩 |
| `z` | 长方形 | 等宽长片、两侧长刘海、长度节点 |
| `n` | 圆形／梯形 | 包裹、承载、圆融或下宽容积 |
| `nx` | 方形 | 散开、横向铺展、碎束块面化 |
| `nz` | 扁椭圆 | 低重心、横向柔软停靠 |
| `zn` | 长椭圆 | 纵向生长、两端圆润、自成体 |
| `zx` | 菱形 | 中部展开、力量主动推出 |
| `xz` | 长三角 | 火药桶式整体蓄积、触发敏感 |
| `xn` | pending | 只用既有秩序语义，不声称几何本征已定 |
| `x并z` | pending | 只用既有内外界面语义，不声称几何本征已定 |

## 6｜xz专项重审门禁

旧判据全部作废：

```text
碎＝xz
乱＝xz
羽化＝xz
多方向漂移＝xz
逐渐变细＝自动xz
```

主判xz必须同时满足：

1. 一个连续危险整体；
2. 整体有蓄积、重量或高张力；
3. 有明确触发尖端／引信束／临界节点；
4. 局部触发可牵动全局；
5. 尚未主动向外释放；
6. 长三角承担主轮廓。

当前旧水库9个xz编号：

```text
02、19、23、40、44、57、61、86、97
```

这些条目的旧xz配比、本征准度与排名一律视为`legacy-pending-review`，不得当作现行视觉证据。

## 7｜第四层：配比度与准度

### 十元配比度

回答“由哪些十元共同构成”，十项总和100%。

### 单十元本征映射准度

回答“有多像某个十元本身”，各项0–100独立评分，不参与配比总和。

```text
配比度 ≠ 本征准度 ≠ 纯度 ≠ 体量 ≠ 证据置信度
```
