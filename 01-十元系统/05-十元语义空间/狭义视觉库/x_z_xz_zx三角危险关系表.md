# x / xz / zx 狭义视觉危险关系表 v0.2

## 一句话

```text
x＝刀。
xz＝火药桶。
zx＝挥出的刀。
```

| 符号 | 危险结构 | 本征形 | 是否主动 | 核心感觉 |
|---|---|---|---|---|
| `x` | 危险物品本身 | 三角 | 否 | 锐利、切割、尖刺、直接伤害 |
| `xz` | 危险蓄积在整体中，对触发高度敏感 | 长三角 | 否，爆发前可静止 | 火药桶、临界、被点爆、整体失控 |
| `zx` | 力量从内部主动进入外部 | 菱形 | 是 | 推出、占据方向、释放、行动 |

## 核心区别

### x｜危险物品

```text
刀放在那里仍然危险。
危险来自物品本身的刃、尖端和切割边界。
```

### xz｜火药桶

```text
危险不是局部刀口，而是储存在整体中。
一个小触发点可能使整个结构爆发、扩散或失控。
```

`xz`本身才是火药桶。不得再把`x`称为火药本体。

### zx｜主动释放

```text
力量已经挥出、推出或占据外部方向。
```

## 发型形状

| 符号 | 发型视觉 |
|---|---|
| `x` | V形、尖角、锐斜切面、中心压缩的三角刀口 |
| `xz` | 厚主体＋引信式尖端，整体呈长三角／长楔形并具触发张力 |
| `zx` | 根部主动起势、中段展开、向外推出的菱形方向体 |

## 拿掉测试

```text
xz拿掉整体蓄积，只剩切割尖角 → x。
xz主动向外释放 → zx。
x拿掉锐利切割，只剩长度节点 → z。
zx拿掉主动推出，只剩静止危险物品 → x。
```

## 硬门禁

```text
碎 ≠ xz
乱 ≠ xz
羽化 ≠ xz
多方向 ≠ xz
长三角 ≠ 自动xz
```

主判xz必须同时看到：

- 整体危险蓄积；
- 触发敏感；
- 局部可牵动全局；
- 爆发前尚未主动释放；
- 主轮廓为连续危险体，而非随机碎束。
