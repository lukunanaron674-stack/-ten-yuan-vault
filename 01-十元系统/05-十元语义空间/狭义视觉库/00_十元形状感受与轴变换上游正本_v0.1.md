# 十元形状感受与轴变换｜狭义视觉库最上游文件 v0.1

> 本文件只记录十元进入**狭义视觉／发型领域**后的形状感受、轴向变形和轮廓判据。
>
> 它不替代十元全局语义正本，也不得直接修改现有发型库。当前阶段先把形状定义弄清楚，再进行水库、排行和配比重审。

## 1｜层级关系

```text
十元全局语义
└─ is-a狭义[domain=视觉]
   └─ 形状感受与轴变换
      └─ is-a狭义[domain=发型]
         └─ 发型轮廓、发束形状与局部结构
```

全局语义与视觉狭义必须同时保存：

```text
xz全局语义：危险逼近、扩张或包围，使安全距离、退路、时间窗和可逆空间下降。
xz视觉狭义：长三角。长轴持续伸出，横向宽度沿路径逐渐压缩并收尖。
```

二者不是完全等号。视觉形状是十元在特定领域中的狭义显影。

## 3｜轴向变化的当前规则

### 3.1 正面全局轴

```text
x轴：左右宽度、横向展开或横向压缩
y轴：上下长度、纵向拉长或纵向压缩
```

当前给定观察：

- 散开的发束可沿 `x轴` 拉长，视觉更偏 `nx`；
- 中间保留集中的刘海，会压缩可用 `x轴`，视觉更偏 `x`；
- 厚而平的刘海压缩 `y轴`，也可强化 `x` 的压迫与三角攻击感；
- 两侧长刘海沿 `y轴` 拉长，视觉更偏 `z`。

### 3.2 局部轴

发束可能斜向、侧向或旋转，因此正式判断不能只依赖画面全局横竖轴。

```text
局部长轴 L：发束主要延伸方向
局部横轴 W：垂直于长轴的发束宽度
```

旋转之后仍按局部轴判断：

- `z`：L被拉长，W大体稳定，形成长方形／长片；
- `x`：W被压缩并形成尖点，整体较短或压缩感集中；
- `xz`：L明显拉长，同时W沿L逐渐缩小，形成长三角。

## 4｜xz 发型视觉定义 v0.1

### 4.1 一句话定义

> **xz 发型形状＝一个连续发束或刘海块面沿长轴伸出，并从较宽根部持续收窄到明确尖端，形成长三角／长楔形。**

### 4.2 双向生成公式

```text
x（三角、收尖、攻击）
＋ z（长轴拉伸、长方形）
＝ xz（长三角）
```

或：

```text
z长方形
＋ 横向宽度沿长轴单调压缩
＝ xz长三角
```

因此，xz可以理解为：

```text
尖锐性被拉长
方向被收束成一条长楔形路径
宽度越往末端越少
```

### 4.3 必要视觉条件

判断发型主形是否为 `xz`，当前至少检查：

1. **连续整体**：必须能看见一个相对连续的发束、刘海片或轮廓块面；
2. **长轴明确**：整体有明显延伸方向，不是短而集中；
3. **宽根窄端**：起始区域较宽，末端明显变窄；
4. **侧边汇聚**：两条主要边界沿长轴趋向同一尖端；
5. **尖端成立**：末端不是圆头、平头或随机碎掉，而是可读的尖点／楔端；
6. **主轮廓成立**：长三角必须承担主要形状，不能只存在于几根内部碎发中。

### 4.4 形状拿掉测试

```text
拿掉“长轴拉伸”后，只剩短三角攻击形 → 更接近 x。
拿掉“逐渐收尖”后，只剩等宽长片 → 更接近 z。
拿掉连续块面，只剩多根散碎发束 → 优先检查 nx／zn，不成立为主xz。
拿掉尖端，外轮廓变成扁圆横向停靠 → 优先检查 nz。
```

### 4.5 与最近邻区别

#### xz vs x

```text
x：三角攻击集中，压缩感强，但长轴不一定明显。
xz：保留三角收尖，同时把它沿长轴拉长，形成长楔形。
```

#### xz vs z

```text
z：长方形／长片，侧边大体平行，宽度较稳定。
xz：长三角，侧边持续汇聚，宽度沿路径下降。
```

#### xz vs nx

```text
nx：方形、散开、横向铺展或碎束块面化，没有唯一尖端。
xz：连续、单向、长轴明确，并收束到一个尖端。
```

**散碎不能单判xz。** 多方向、羽化、乱边和颗粒化优先检查 `nx`，再根据自然纹理检查 `zn`。

#### xz vs nz

```text
nz：扁椭圆，横向低重心，边缘柔软圆钝，具有停靠感。
xz：长三角，方向集中，末端尖锐，形状没有横向柔和停靠。
```

#### xz vs zn

```text
zn：长椭圆，长轴明显但两端圆润，依靠自身材质与生长状态成立。
xz：长轴同样明显，但至少一端必须持续压缩成尖点。
```

#### xz vs zx

```text
zx：菱形，中段向外展开，前后或两端再次收束，具有“先扩后收”的双向结构。
xz：长三角，从宽端向单一尖端持续收窄，是单向汇聚。
```

## 5｜发型中的候选形态

以下只表示形状候选，不是现有刘海库的正式重判：

- 从发根宽区向眼下或颧骨伸出的长尖侧刘海；
- 单片斜向长楔形刘海；
- 中央宽根、向下拉成长尖端的矛形发束；
- 一侧等宽开始、随后明显收尖的长三角前发；
- 轮廓主体可被简化成一个长三角，而不是一团碎线。

## 6｜当前截图的判定示例

对“整体蓬松、横向展开、外轮廓低而圆”的发型：

```text
整体主轮廓：扁椭圆 → nz候选
内部散碎发束：方块化／横向散开 → nx副显影候选
xz：不成立为主形，因为没有连续长三角、没有宽根到尖端的单向收束
```

判断时必须分开：

```text
整体外轮廓主十元
内部发束纹理副十元
局部尖束功能十元
```

不得用内部几根尖发覆盖整体扁椭圆主轮廓。
