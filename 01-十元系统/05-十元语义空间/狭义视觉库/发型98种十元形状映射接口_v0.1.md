# 发型98种十元形状映射接口 v0.1

## 目的

连接：

狭义视觉形状理论 → 发型图鉴 → 十元映射 → 准度评分

暂不修改已有98种刘海归属，仅提供新的上游判断接口。

---

# 判定流程

## 第一层：几何形状

观察：

- X轴扩散 / 压缩
- Y轴拉伸 / 压缩
- 是否存在尖端
- 是否存在中心压力
- 是否存在连续长轴

---

# 十元视觉初始映射

| 十元 | 几何 | 发型表现 |
|---|---|---|
| x | 三角、尖角、集中压缩 | 锐利切割、危险物品感 |
| nx | X轴扩散 | 散开、多束、横向展开 |
| z | 长方形、长条 | 两侧长刘海、垂直延伸 |
| nz | 扁椭圆 | 横向柔和、低重心 |
| zn | 长椭圆 | 纵向完整、圆润延伸 |
| zx | 菱形 | 中部力量外放 |
| xz | 长三角、长楔形 | 危险蓄积、触发结构 |

---

# xz专项规则

## 错误判据

禁止：

- 碎 = xz
- 乱 = xz
- 羽化 = xz
- 不规则 = xz

## 正确判据

xz需要：

1. x危险集中
2. z长轴延伸
3. 存在触发点
4. 整体具有蓄积爆发感

视觉比喻：

x = 刀
xz = 火药桶
zx = 挥出的刀
