# 十元形状感受与轴变换｜狭义视觉库最上游正本 v0.3

> 本文件记录十元进入狭义视觉／发型领域后的形状感受、轴向变化和轮廓判据。
>
> 视觉形状是领域狭义显影，不替代十元全局语义。下游发型卡必须同时保存形状证据、语义发动机与对象层。

## 1｜层级关系

```text
十元全局语义
└─ is-a狭义[domain=视觉]
   └─ 形状感受与轴变换
      └─ is-a狭义[domain=发型]
         └─ 整体轮廓、刘海块面、发束形状与局部结构
```

## 3｜全局轴与局部轴

### 3.1 画面全局轴

```text
X轴：左右宽度、横向展开或横向压缩。
Y轴：上下长度、纵向拉长或纵向压缩。
```

当前确认：

- 散开的发束沿`X轴`拉开，视觉更偏`nx`；
- 中间保留集中刘海，压缩可用`X轴`，视觉更偏`x`；
- 厚而平的刘海压缩`Y轴`，强化`x`的切断和压迫感；
- 两侧长刘海沿`Y轴`拉长，视觉更偏`z`。

### 3.2 发束局部轴

发束可以斜置、旋转，不能只看画面横竖：

```text
局部长轴 L：发束主要延伸方向。
局部横轴 W：垂直于L的宽度。
```

- `z`：L拉长，W大体稳定，形成长方形／等宽长片；
- `x`：边界汇聚成三角、刀刃或尖刺；
- `xz`：主体沿L延伸，整体呈长三角，并具火药桶式蓄积与触发敏感；
- `zn`：L拉长但两端圆润，形成长椭圆；
- `nz`：纵向压低、横向圆化，形成扁椭圆；
- `nx`：横向铺开或碎束块面化，形成方形／方块感；
- `zx`：中部展开并向外主动推出，形成菱形方向体。

## 4｜危险视觉三角

### x｜刀

```text
危险来自物品自身的锐利、切割和直接伤害边界。
可以静止，不要求主动释放。
本征形：三角。
```

### xz｜火药桶

```text
危险储存在整体中。
对一个触发点高度敏感。
触发后可能整体爆发、扩散或失控。
本征形：长三角。
```

### zx｜挥出的刀

```text
力量已经主动推出并占据方向。
危险或权能从内部进入外部现实。
本征形：菱形。
```

最短区别：

```text
x：危险物品。
xz：可被点爆的危险整体。
zx：主动释放的力量。
```

## 5｜xz发型视觉定义

> **xz发型不是“乱、碎、羽化”，而是一个火药桶式连续危险体：主体承担蓄积，尖端或节点承担触发敏感，整体常显成长三角／长楔形。**

必要检查：

1. 主体连续，不是一堆随机碎束；
2. 整体具有压缩、重量或高张力；
3. 有清楚的触发尖端、引信束或临界节点；
4. 局部触发在视觉上会牵动整体；
5. 尚未主动向外释放；
6. 长三角必须承担主轮廓，而不是藏在几根内部发丝里。

## 6｜最近邻拿掉测试

```text
xz拿掉整体蓄积，只剩锐利切口 → x。
xz拿掉触发敏感，只剩等宽长片 → z。
xz主动向外推出 → zx。
xz被打散为多束横向扩散 → nx。
xz被压扁磨圆并形成低重心停靠 → nz。
xz两端圆润、自成生长体 → zn。
```

## 7｜整体、内部与局部分层

每个发型至少分三层：

```text
整体外轮廓主十元
内部发束纹理副十元
局部尖束／束点功能十元
```

不得用内部几根尖发覆盖整体扁椭圆、圆形或方形主轮廓。

## 8｜下游状态

- 现有刘海98种旧xz归属必须重审；
- 旧“碎／乱／羽化＝xz”不得继续调用；
- 新增发型先按本文件观察轴与形状，再进入十元配比度和本征准度；
- `xn`、`x并z`几何本征仍为pending，不得伪装成已确认；
- 视觉形状证据不能替代动态、人物或场域层的全局十元准度卡。
