# 狭义视觉库总索引 v0.1

## 1｜定位

本目录保存十元进入视觉领域后的`is-a狭义`定义。它不替代全局十元信息卡与准度卡，只回答形状、轴向、轮廓和视觉感觉怎样显影。

```text
十元全局语义
→ is-a狭义[domain=视觉]
→ 视觉形状与轴变换
→ is-a狭义[domain=发型]
→ 发型轮廓与发束结构
```

## 3｜当前形状完成度

```text
已确认：x、z、n、nx、nz、zn、zx、xz（8/10）
待补：xn、x并z（2/10）
```

待补不等于该十元没有视觉意义，只表示尚未获得用户确认的几何本征形。下游可继续使用其全局语义与结构证据，但不得伪造形状结论。

## 4｜危险视觉正本

```text
x＝刀：危险物品、锐利切割。
xz＝火药桶：整体蓄积、触发敏感、可能整体爆发。
zx＝挥出的刀：力量主动推出并占据方向。
```

## 5｜发型轴向召回

```text
X轴扩散、碎束横向铺开 → nx候选。
中央刘海压缩X轴 → x候选。
厚平刘海压缩Y轴 → x候选。
两侧长刘海拉长Y轴 → z候选。
长三角＋整体蓄积＋触发敏感 → xz候选。
```

## 6｜硬门禁

- 散、碎、乱、羽化不能单判xz；
- 长三角也不能自动判xz；
- 视觉形状不能替代人物、状态、行为和场域层准度；
- 整体轮廓、内部纹理与局部尖束必须分开；
- 十元配比度与本征映射准度必须分字段保存；
- 旧水库9个xz条目在重审前标记`legacy-pending-review`。

## 7｜版本治理

- v0.1、v0.2旧路径仅作重定向；
- 下游文件必须链接现行版本，不得继续调用已废止正文；
- `xn`与`x并z`获得确认形状后，升级上游正本版本并重新生成总览Canvas；
- 刘海98种完成全量形状复审后，才可重新标记为视觉终审版。
