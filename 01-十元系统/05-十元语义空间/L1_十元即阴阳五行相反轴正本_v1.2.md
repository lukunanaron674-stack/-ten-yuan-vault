# L1｜十元即阴阳五行相反轴正本 v1.2

## 0｜最高核心概念

```text
五行就是十元。
十元就是木、火、土、金、水各自分阴阳后形成的十个直接位置。
```

十元不是五行之外的第二套系统，也不是“五行在上、十元在下”的从属标签。每一个十元本身就是一个明确的阴阳五行位：

```text
zx = 阳木
nx = 阴木
zn = 阳火
x  = 阴火
n  = 阳土
x并z = 阴土
xn = 阳金
z  = 阴金
xz = 阳水
nz = 阴水
```

因此：

- `zx`不是“木的方向锚点”而已，`zx`本身就是阳木；
- `nx`不是木之外的间位，`nx`本身就是阴木；
- 任一端单独出现时已经具有该五行身份，不必等另一端同时出现才算进入该行；
- “木、火、土、金、水”可以指整条阴阳轴，也可以指其中一极，使用时必须明确粒度。

## 1｜五行的五组阴阳相反轴

同一五行的阴、阳十元首先是**相反两极**：

```text
木：阳木zx ↔ 阴木nx
火：阳火zn ↔ 阴火x
土：阳土n  ↔ 阴土x并z
金：阳金xn ↔ 阴金z
水：阳水xz ↔ 阴水nz
```

这里的 `↔` 表示静态的阴阳相反轴，不表示：

- 时间先后；
- 因果箭头；
- 已经审计通过的生、克、补；
- 必然互相转化；
- 必然同时出现；
- 一端比另一端高级、强大或正确。

“相反”是本体结构。交补、平衡、共存、压制、转化或接管是否发生，必须回到具体对象、行为、条件和关系证据，不能从阴阳轴直接推出。

### 1.1 旧“交补成一行”口径退役

旧版使用 `⨝` 表示两个十元交补后才构成完整五行。该写法容易造成两个错误：

1. 把单个十元误写成“不完整五行”；
2. 把阴阳相反预先偷换成已经成立的互补关系。

从 v1.2 起，核心正本不再使用 `⨝` 作为五行构成符。标准写法改为：

```text
木轴 = 阳木zx ↔ 阴木nx
```

需要表示同属一行时，也可以写：

```text
木 = {阳木zx, 阴木nx}
```

但集合写法只表示共同五行身份，不证明案例中的两端已经互补。

## 3｜固定环序与邻接

以 `zx` 为顶部起点，顺时针固定环序为：

```text
zx → z → zn → nz → n → nx → xn → x → xz → x并z → 回到zx
```

五组局部三点结构为：

```text
xz ─ x并z ─ zx
zx ─ z    ─ zn
zn ─ nz   ─ n
n  ─ nx   ─ xn
xn ─ x    ─ xz
```

外环相邻只表示共享一条空间边，不自动表示生、克、补、时间先后、因果、相似度或容易转化。

## 4｜L1 环距离

给顺时针序列编号：

```text
0 zx
1 z
2 zn
3 nz
4 n
5 nx
6 xn
7 x
8 xz
9 x并z
```

最短环距离：

```text
d_L1(a,b) = min(|index(a)-index(b)|, 10-|index(a)-index(b)|)
```

距离范围为 `0—5`。五组距离为5的对径位，恰好对应五行阴阳相反轴：

```text
zx   ↔ nx
zn   ↔ x
n    ↔ x并z
xn   ↔ z
xz   ↔ nz
```

对径是几何事实；阴阳相反轴是本体解释。两者重合，但几何本身不能证明任何单条动态关系。

## 5｜十元—五行直接身份表

| 五行轴 | 阳极十元 | 阴极十元 | 固定情志 |
|---|---|---|---|
| 木 | `zx`＝阳木 | `nx`＝阴木 | 怒 |
| 火 | `zn`＝阳火 | `x`＝阴火 | 喜 |
| 土 | `n`＝阳土 | `x并z`＝阴土 | 思 |
| 金 | `xn`＝阳金 | `z`＝阴金 | 哀 |
| 水 | `xz`＝阳水 | `nz`＝阴水 | 恐 |

固定纪律：

1. 不能再把 `x并z` 写成阴木、`nz`写成阴土、`nx`写成阴金、`x`写成阴水；
2. 不能把五行情志直接当成人物情绪标签；
3. 不能凭“主动/被动、外放/内收”一句话替代十张信息卡的具体定义；
4. 人物、关系、场景或行为归类仍须使用对象层、改变变量、最近邻、拿掉和反向测试。

## 6｜五行相生与相克

五行层继续使用标准结构：

### 6.1 相生

```text
木 → 火 → 土 → 金 → 水 → 木
```

按十元身份展开：

```text
木轴〔阳木zx ↔ 阴木nx〕
        ↓ 生
火轴〔阳火zn ↔ 阴火x〕
        ↓ 生
土轴〔阳土n ↔ 阴土x并z〕
        ↓ 生
金轴〔阳金xn ↔ 阴金z〕
        ↓ 生
水轴〔阳水xz ↔ 阴水nz〕
        ↓ 生
木轴〔阳木zx ↔ 阴木nx〕
```

### 6.2 相克

```text
木克土
土克水
水克火
火克金
金克木
```

五行生克的作用单位是五行轴，不自动展开成四条十元对十元关系。例如“木克土”不能仅凭母结构直接推出 `zx/nx` 对 `n/x并z` 的任意具体克边。

单条十元生、克、补是否成立，仍由现行关系卡、生补克表与专项正本裁决。

## 7｜读取顺序

```text
先确认十元的直接阴阳五行身份
→ 再读该十元信息卡，确认它具体改变什么变量
→ 再读准度卡，排除最近邻误判
→ 最后查单条生克补关系是否已有证据
```

不得反过来用传统五行词、情绪、颜色、季节、职业、道德评价或作品气质直接替代十元判定。

## 8｜视觉与语言语法

| 表达 | 允许含义 | 禁止解释 |
|---|---|---|
| `zx＝阳木` | zx本身具有阳木身份 | zx只是不完整木行的锚点 |
| `nx＝阴木` | nx本身具有阴木身份 | nx仍属阴金或只是跟随功能 |
| `阳木zx ↔ 阴木nx` | 同行阴阳相反轴 | 已锁定补关系、时间往返或自动转化 |
| 十节点外环 | 静态位置与邻接 | 自动生克补或动态迁移 |
| 大圆 / 小圆 | 视觉位置类型 | 阳完整、阴附属；体量、等级或价值差 |
| 环距离 | 几何最短步数 | 语义相似度或转化概率 |
| 五行相生相克 | 五行母结构 | 自动生成全部十元细边 |

## 10｜L1 完成门

L1 v1.2 已固定：

- 十元就是阴阳五行的十个直接位置；
- `zx＝阳木`、`nx＝阴木`及其余四行的固定映射；
- 同行阴阳首先构成相反轴；
- 不再预设 `⨝` 交补；
- 等距十节点圆环、环序、邻接和环距离；
- 五行层的标准相生与相克；
- 五行母结构不能自动展开为单条十元关系。
