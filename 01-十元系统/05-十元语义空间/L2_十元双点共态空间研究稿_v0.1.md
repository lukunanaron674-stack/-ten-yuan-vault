# L2｜十元双点共态空间研究稿 v0.1

## 0. 本轮先解决的冲突

仓库中“对子”至少出现了两种用法：

1. `主十元 + 次十元`，表示同一对象、同一阶段中两个十元同时在场；
2. `克 + 克 + 生`，表示多个关系五对的组合方式。

现行《关系五对校验包》已经明确：

```text
十元 = 点
关系五对 = 基础位置边型
关系对子 = 多个关系五对的组合方式
动态链条 = 关系对子落到具体十元后跑出的力流结构
```

因此，L2 不再把“主十元 + 次十元”直接命名为“关系对子”。本稿将它规范为：

```text
双点共态节点 / stage co-state node
```

术语分层固定为：

| 层级 | 名称 | 最小结构 | 回答的问题 |
|---|---|---|---|
| L1 | 十元点 | `A` | 十元在哪里 |
| L2 | 双点共态节点 | `A主 + B次` | 同一阶段中哪两个点共同在场 |
| 关系层 | 关系五对 | `A生B / A克B / A补B` | 两点之间是否存在已确认作用边 |
| 关系组合层 | 关系对子 | `克 + 克 + 生` | 多条基础边怎样组合 |
| 动态层 | 动态链 | 关系对子落到具体十元与阶段 | 力流怎样跨阶段运行 |

这项区分是 L2 的第一条硬规则。否则“两个点同框”和“多条边组合”都会被叫作对子，后续统计会像把演员表和交通路线塞进同一列，表格倒是很热闹，理论已经失踪。

---

## 1. L2 要解决的问题

L2 只解决：

> 同一对象、同一对象层、同一阶段窗口内，两个十元点怎样共同构成一个可重复记录的静态状态节点。

L2 回答：

- 谁是主十元；
- 谁是次十元；
- 两者各自的体量；
- 两者各自的映射强度；
- 两者如何同时在场；
- 是否存在已确认内部关系边；
- 该节点位于 L1 环上的什么几何位置。

L2 不回答：

- 这个节点为什么转成另一个节点；
- 哪种顺序更舒服；
- 哪个组合必然产生某种故事效果；
- 相邻、对径或距离是否意味着生克补；
- 新的严格关系是否成立。

## 2. L2 最小单位

一个完整双点共态节点记为：

```text
S = <对象, 对象层, 阶段窗口,
     主十元, 次十元,
     主体量, 次体量,
     主映射强度, 次映射强度,
     激活方式,
     内部边状态,
     证据>
```

压缩写法：

```text
S[对象层｜主A Vp/Mp｜次B Vs/Ms｜激活方式｜内部边]
```

其中：

- `V` = volume，体量，范围 `1—10`；
- `M` = mapping strength，映射强度，范围 `1—10`；
- `p` = primary，主十元；
- `s` = secondary，次十元。

示意：

```text
S[人物行动层｜主zx V7/M9｜次nx V4/M8｜simultaneous｜内部边:待查正本]
```

该示意只展示格式，不宣称 `zx` 与 `nx` 在该对象中已经形成某条严格边。

## 3. 主次定义

### 3.1 主十元

主十元是：

> 在当前对象层与阶段窗口中，最能决定该状态如何被识别、如何组织其他成分、以及整体朝哪个结构方向成立的首要十元点。

### 3.2 次十元

次十元是：

> 不能被轻易拿掉，并具体改变主十元的实现方式、限制方式、承载方式或显影质地的第二十元点。

### 3.3 主次不等于体量大小

```text
主十元 ≠ 体量一定更大
次十元 ≠ 体量一定更小
```

例如：

```text
主A V4 + 次B V7
```

仍可能成立。主次描述结构主导权，体量描述在场密度。人类很爱把“声音大”误当“负责指挥”，会议室已经替我们证明这两者毫无必然关系。

### 3.4 主次交换是不同节点

```text
A主 + B次 ≠ B主 + A次
```

即使：

- 体量相同；
- 对象相同；
- 两个符号相同；
- 发生在同一场景；

只要主导权交换，就必须登记为另一个 L2 节点。

## 4. 体量与映射强度

### 4.1 体量 V

```text
体量 = 在场密度 / 存在占位 / 场域压强
```

体量不表示：

- 战斗力；
- 道德高低；
- 理论重要性；
- 映射是否准确；
- 主次资格。

### 4.2 映射强度 M

```text
映射强度 = 内容对应到该十元点的准确度与硬度
```

标尺沿用现行教学法：

| M | 含义 |
|---:|---|
| 1—2 | 擦边，不入节点 |
| 3—4 | 辅助映射，只作背景 |
| 5 | 中性映射，不能定核心 |
| 6—7 | 可用映射，需要补证据 |
| 8—9 | 强映射，可进入主次判断 |
| 10 | 锚点映射，接近标准样本 |

### 4.3 L2 准入建议

双点共态节点进入正式候选池时：

```text
主映射强度 M ≥ 8
次映射强度 M ≥ 6
```

这只是 L2 候选准入阈值，不等于关系置信度，也不等于理论锁定。

## 5. 激活方式

L2 暂定四种静态共态方式：

| activation_mode | 含义 |
|---|---|
| `simultaneous` | 两点在同一证据窗口同步在场 |
| `layered` | 一点作为表层显影，另一点作为底层结构 |
| `alternating` | 同一阶段内两点交替占据显影前台，但阶段未切换 |
| `conditional` | 次点只在特定条件下被调用，但条件属于当前阶段内部 |

禁止把跨阶段先后写成 `alternating`。一旦阶段边界真实发生，就进入 L3，不再属于 L2 静态节点。

---

## 6. 内部边状态

两个点共同在场，不自动意味着它们之间存在严格生、克、补。

`internal_edge_status` 只允许：

| 状态 | 含义 |
|---|---|
| `strict-cited` | 引用现行已锁定单条关系正本 |
| `strict-pending` | 有候选，但关系尚未锁定 |
| `neutral-coactive` | 两点共同在场，不声称直接关系 |
| `none-observed` | 当前证据没有显示两点直接作用 |
| `not-evaluated` | 本轮尚未进行内部边判断 |

若为 `strict-cited`，必须同时记录：

```yaml
internal_relation: A生B | A克B | A补B
relation_card_path: 仓库正本路径
relation_version: 版本
```

L1 的邻接、环距离、顺时针位置、对径位置不得充当严格边证据。

## 7. L2 从 L1 继承的几何量

每个双点共态节点继承两个 L1 坐标：

```text
primary_index
secondary_index
```

并可计算：

```text
pair_ring_distance = d_L1(primary, secondary)
```

同时记录两点的位置类型：

```text
anchor / interstitial
```

### 7.1 四类有向空间壳

| 壳类型 | 结构 | 数量 |
|---|---|---:|
| `AA` | 锚点主 → 锚点次 | 20 |
| `AI` | 锚点主 → 间位次 | 25 |
| `IA` | 间位主 → 锚点次 | 25 |
| `II` | 间位主 → 间位次 | 20 |
| 合计 | 主次不同的有向双点壳 | 90 |

计算：

```text
10个主点 × 9个不同次点 = 90个有向双点结构壳
```

这 90 个只是几何壳，不是 90 条已成立组合规律。

### 7.2 按环距离分布

在十节点环上，有向双点壳按最短环距离分布为：

| 距离 | 有向壳数量 |
|---:|---:|
| 1 | 20 |
| 2 | 20 |
| 3 | 20 |
| 4 | 20 |
| 5 | 10 |
| 合计 | 90 |

这些数量只描述结构可能性：

```text
距离 ≠ 语义相似度
距离 ≠ 转化难度
距离 ≠ 关系强度
距离 ≠ 出现概率
```

## 8. 状态同一性规则

以下任一字段发生变化，都不能直接视为同一个 L2 状态：

1. 对象改变；
2. 对象层改变；
3. 主次交换；
4. 任一体量跨过已定义等级区间；
5. 激活方式改变；
6. 内部边状态改变；
7. 阶段窗口改变。

### 8.1 允许视为同一状态的微小波动

同一连续阶段内，若：

- 主次不变；
- 对象层不变；
- 激活方式不变；
- 内部边状态不变；
- 体量仅有 `±1` 的瞬时波动；

可先登记为同一 L2 节点的体量范围，而不是立刻切阶段：

```text
主A V6—7 + 次B V3—4
```

是否真正进入 L3，由阶段边界证据决定。

## 9. 对象层冻结

每个节点只能属于一个主要对象层：

```yaml
object_layer:
  - character
  - relationship
  - institution
  - scene
  - shot
  - stage
  - whole_work
```

不得把：

- 人物本体的 `zx`；
- 关系结构的 `nz`；
- 镜头氛围的 `xz`；

拼成一个“主zx + 次nz + xz背景”的双点节点。那不是共态，是三个对象层趁管理员不在偷偷合租。

若跨层影响确实重要，应另建：

```text
跨层映射记录
```

但不并入 L2 最小节点。

---

## 10. 拿掉、替代与主次检验

一条 L2 双点候选至少检查：

### 10.1 拿掉主点

拿掉主点后，整体状态的识别核心是否改变？

### 10.2 拿掉次点

拿掉次点后，主点的实现方式、质地或边界是否显著改变？

若拿掉次点毫无变化，该次点应降为背景，不进入双点节点。

### 10.3 主次交换

```text
A主+B次
```

与：

```text
B主+A次
```

是否产生不同状态解释？若没有差异，主次判断可能只是措辞装饰。

### 10.4 最近邻替代

将主点或次点替换为 L1 直接邻居，只能用于检验端点边界，不能因为替代后“感觉也通”就宣布空间相邻等于语义相似。

### 11.1 单节点

```text

│ S01｜人物行动层                       │
│ 主：A｜V7｜M9                         │
│ 次：B｜V4｜M8                         │

│ 阶段窗口：t0—t1                       │
└──────────────────────────────────────┘
```

### 11.2 禁止写法

```text
A + B
```

问题：没有对象层、主次、体量、映射强度、激活方式和边状态。

```text
A → B
```

问题：把静态共态误写成动态迁移或严格关系。

```text
A/B
```

问题：无法判断是二选一、混合、主次还是端点不确定。

## 13. 与现有“组合规律研究”的接口

L2 提供的是：

```text
可记录的双点共态节点
```

组合规律研究负责进一步证明：

```text
该双点结构是否产生不可由单点解释的稳定整体功能
```

因此：

```text
L2节点成立 ≠ 组合规律成立
```

L2 可以确认“同一阶段中 A主+B次 的状态记录有效”，但不能直接确认“该组合必然产生悲壮、成长、温暖或压迫”。体验命名必须经过跨案例研究。

现有组合规律库中使用“对子”表示 `主十元+次十元` 的段落，后续应统一迁移为：

```text
双点共态 / 组合节点
```

“关系对子”一词保留给多个关系五对的组合方式。

## 14. 与趋势和动态链的接口

L3 的最小迁移应写成：

```text
L2节点 S1 ──关系 / 条件 / 中性过程──▶ L2节点 S2
```

而不是：

```text
A → B → C
```

L2只负责保证起点与终点完整。箭头的：

- 方向；
- 触发；
- 阶段边界；
- 拿掉；
- 反向；
- 第三因素；
- 严格关系或中性过程；

全部属于 L3 或动态链研究。
