# L1｜十元空间与五行阴阳正本 v1.1

## 0. 核心定位

十元理论的底层仍然是五行理论。十元不是在五行之外另造一套系统，而是把每一行进一步拆成阴、阳两个十元，使五行内部结构更明确、更容易分析和使用。

L1 同时固定两层：

```text
外层：十个十元符号组成等距十节点圆环
中央：五组阴阳十元交补成木、火、土、金、水，并按五行关系相生相克
```

外层回答“十元在哪里”；中央回答“十元怎样细化五行”。

### 1.1 锚点位


### 1.2 间位

```text
z｜nz｜nx｜x｜x并z
```

大圆与小圆只表示空间位置类型，不表示体量、重要性、等级、置信度或主次资格。

## 2. 固定环序与邻接

以 `zx` 为顶部起点，顺时针固定环序为：

```text
zx → z → zn → nz → n → nx → xn → x → xz → x并z → 回到zx
```

五组局部三点结构为：

```text
xz ─ x并z ─ zx
zx ─ z    ─ zn
zn ─ nz   ─ n
n  ─ nx   ─ xn
xn ─ x    ─ xz
```

外环相邻只表示共享一条空间边，不自动表示生、克、补、时间先后、因果或容易转化。

---

## 3. L1 环距离

给顺时针序列编号：

```text
0 zx
1 z
2 zn
3 nz
4 n
5 nx
6 xn
7 x
8 xz
9 x并z
```

两个符号 `a` 与 `b` 的最短环距离定义为：

```text
d_L1(a,b) = min(|index(a)-index(b)|, 10-|index(a)-index(b)|)
```

距离范围为 `0—5`：

```text
0 = 同一点
1 = 直接邻接
2—4 = 相应环步距离
5 = 几何对径位
```

五组几何对径位恰好也是五行阴阳对子：

```text
zx   ↔ nx
zn   ↔ x
n    ↔ x并z
xn   ↔ z
xz   ↔ nz
```

这里的“对径”是空间事实；“阴阳交补成一行”是五行解释。两层可以重合，但不能把几何对径直接偷换成任意单条十元关系。

## 4. 五行阴阳对子

### 4.1 阴阳顺序

每一组五行对子都按固定顺序书写：

```text
前项 = 阳
后项 = 阴
```

因此五行的十元细化为：

| 五行 | 阳十元 | 阴十元 | 情志 |
|---|---|---|---|
| 木 | `zx` | `nx` | 怒 |
| 火 | `zn` | `x` | 喜 |
| 土 | `n` | `x并z` | 思 |
| 金 | `xn` | `z` | 哀 |
| 水 | `xz` | `nz` | 恐 |

这五组是五行内部的阴阳拆分，不是临时组合，也不是由案例共现统计出来的对子。

### 4.2 交补符号

本正本使用：

```text
⨝
```

作为十元五行层的**交补符**。它表示：

> 两个十元从阴、阳两侧在中央交会并互补，共同构成一个完整五行。

标准写法：

```text
木 = 阳zx ⨝ 阴nx = 怒
火 = 阳zn ⨝ 阴x = 喜
土 = 阳n  ⨝ 阴x并z = 思
金 = 阳xn ⨝ 阴z = 哀
水 = 阳xz ⨝ 阴nz = 恐
```

`⨝` 不等于单条关系卡里的严格“补”箭头。它不自动声称 `zx补nx` 或 `nx补zx` 已经通过关系审计，而是专门表示五行内部的阴阳交补构成。

## 6. 五行相生与相克

中央五行关系沿用五行理论的标准生克结构，只是在每个五行节点内部增加十元阴阳解释。

### 6.1 相生

```text
木 → 火 → 土 → 金 → 水 → 木
```

展开为十元五行节点：

```text
木〔阳zx ⨝ 阴nx〕
        ↓ 生
火〔阳zn ⨝ 阴x〕
        ↓ 生
土〔阳n ⨝ 阴x并z〕
        ↓ 生
金〔阳xn ⨝ 阴z〕
        ↓ 生
水〔阳xz ⨝ 阴nz〕
        ↓ 生
木〔阳zx ⨝ 阴nx〕
```

### 6.2 相克

```text
木克土
土克水
水克火
火克金
金克木
```

闭环写法：

```text
木 →克→ 土 →克→ 水 →克→ 火 →克→ 金 →克→ 木
```

### 6.3 关系层级边界

五行层的“木生火”或“木克土”，作用单位是完整五行对子：

```text
木〔zx ⨝ nx〕
火〔zn ⨝ x〕
土〔n ⨝ x并z〕
金〔xn ⨝ z〕
水〔xz ⨝ nz〕
```

它不自动展开成四条十元对十元关系。例如：

```text
木克土
```

不能仅凭这一条直接推出：

```text
zx克n
zx克x并z
nx克n
nx克x并z
```

单条十元生克补是否成立，仍由单条关系卡和审计正本裁决。五行层提供母结构，十元关系层负责细分后的具体作用方式。

## 7. 两层合并后的读取方式

```text
十元等距圆环
├─ 固定十个位置
├─ 固定顺时针环序
├─ 固定直接邻接
└─ 固定最短环距离

中央五行层
├─ 每行由前阳、后阴两个十元交补构成
├─ ⨝ 表示五行内部阴阳交补
├─ 外圈大节点承担五行方向锚定
├─ 中央对子表说明完整五行并非只由大节点单独承担
└─ 五行之间按标准相生、相克运行
```

因此，外圈标注 `ZX 木怒` 的准确含义是：

> `zx` 是木·怒在十元圆环上的阳位与方向锚点；完整木行由 `阳zx ⨝ 阴nx` 构成。

其余四行同理。

## 8. 视觉语法

| 图形元素 | 允许含义 | 禁止解释 |
|---|---|---|
| 十节点外环 | 静态等距位置与邻接 | 自动生克补或动态迁移 |
| 大圆 | 五行阳位、方向锚点 | 单独等于完整五行、体量更大 |
| 小圆 | 五行阴位、锚点间位置 | 次要、附属、体量更小 |
| 顺时针排列 | 坐标索引 | 时间、生成、叙事顺序 |
| 环距离 | 几何最短步数 | 语义相似度或转化概率 |
| `⨝` | 阴阳交补构成一行 | 已审计的单条“补”关系 |
| 外圈五行情志标签 | 五行方向锚定 | 单个十元独立承担完整五行 |
| 中央相生外环 | 五行层相生 | 自动展开为所有十元生边 |
| 中央相克内星 | 五行层相克 | 自动展开为所有十元克边 |

## 11. 正式结论

```text
十元空间是一张等距十节点圆环。
五个大节点是五行的阳位与方向锚点，五个小节点是对应阴位。
每一行由“前阳 ⨝ 后阴”两个十元交补构成：
木=zx⨝nx，火=zn⨝x，土=n⨝x并z，金=xn⨝z，水=xz⨝nz。
五行之间沿用标准相生、相克结构；
十元负责把五行内部细化明确，单条十元关系仍须独立审计。
```
