# 十元灵魂判断法（正式版）
> 归档：`01-十元系统/十元灵魂判断法.md`

---

## 核心原则（一句话钉死）

> **人物主十元不是出现频率最高的符号，而是人物存在被抽掉后最先崩塌的核心感受。**

定义一个人物的主十元，不看他身上"最多"的东西，而看：**拿掉哪个十元，这个人物就不再成立。**

---

## 第一章：三个必须绕过的陷阱

### 陷阱1：不是视觉最强，而是本体最强

一个角色穿黑衣、拿刀、表情冷，不一定是 x。那可能只是视觉接口。

**判断原则：** 如果换掉这些视觉，他的人物核心还在不在？
- 如果还在 → 视觉不是主十元
- 如果一换就塌 → 视觉可能参与本体，但仍需灵魂判断验证

**例子：**
- 冷色调、破碎、风雪 → 可能是 xz 场景接口，不是主十元
- 沉默、稳定、照顾别人 → 可能是 n 行为接口，不是主十元
- 真正主十元要看：**他为什么必须这样活着**

### 陷阱2：不是行为最多，而是第一推动力最稳

一个角色可能经常行动（看着像zx），也可能经常思考（看着像nx），也可能经常照顾别人（看着像n）。
但主十元不是行为频率榜。

**判断原则：** 问「他最早、最深、最反复被什么东西驱动？」而不是「他做了多少种事？」

| 问题 | 对应判断 |
|------|---------|
| 他是被欲望顶着走？ | x |
| 他是被行动选择推出去？ | zx |
| 他是被秩序、时间、规则困住？ | xn |
| 他是被隐性判断、怀疑、审查驱动？ | nx |
| 他是被归宿、依恋、停靠感牵住？ | nz |
| 他是被危险边缘、漂流、命运压迫牵引？ | xz |
| 他是被意义、信念、价值证明支撑？ | zn |
| 他是为了维持、承载、让关系不散？ | n |
| 他是为了显现、被看见、点亮一瞬？ | z |
| 他是被包装、身份、表象、观看机制定义？ | x并z |

### 陷阱3：主十元不是"优点"，而是反复制造问题的根

主十元不是标签，是**问题发动机**。

- n 主人物的问题不是"很温柔"，而是：**他如何承载到失衡？**
- x 主人物的问题不是"有欲望"，而是：**欲望如何烧穿关系？**
- xz 主人物的问题不是"很惨"，而是：**他为什么总在不能停靠的边缘？**
- nx 主人物的问题不是"聪明"，而是：**他为什么总要判断、审查、怀疑、隐藏？**

**主十元测试句：** 这个角色最核心的痛苦，是否由这个十元制造？
- 是 → 它才可能是主十元
- 否 → 它最多是副十元或功能十元

## 第二章：四层区分

一个人物身上至少拆成四层，不能混为一谈：

| 层级 | 作用 | 能不能定义人物 |
|:----:|:----:|:------------:|
| **主十元** | 人物存在方式 | ✅ 可以 |
| **副十元** | 强化人物气质 | ✅ 可以辅助 |
| **功能十元** | 某段剧情中起作用 | ❌ 不能直接定义 |
| **视觉十元** | 外观、服装、氛围 | ❌ 不能直接定义 |

**例子：** 一个角色表面冷酷 x，行动推进 zx，内心想停靠 nz，真正被命运漂流 xz 定义。
→ 主十元不是 x，不是 zx，是 **xz**。冷酷和行动只是应对方式，漂流感才是人物成立的根。

**结算十元**（特殊补充）：人物最终落点的验证十元。不是主十元，但用来验证主十元判断是否正确。详见第四章第4问。

## 第三章：主十元五问法

判断人物主十元的固定五问：

### 第1问：拿掉什么，他就不是他？

最重要的问题。对每个候选十元试一次：

- 拿掉行动，他还成立吗？→ zx候选
- 拿掉欲望，他还成立吗？→ x候选
- 拿掉归宿渴望，他还成立吗？→ nz候选
- 拿掉身份遮蔽，他还成立吗？→ x并z候选
- 拿掉命运压迫，他还成立吗？→ xz候选
- 拿掉意义信念，他还成立吗？→ zn候选
- 拿掉承载能力，他还成立吗？→ n候选
- 拿掉被看见的执念，他还成立吗？→ z候选
- 拿掉规则秩序，他还成立吗？→ xn候选
- 拿掉判断审查，他还成立吗？→ nx候选

**谁被拿掉后人物崩，谁就是主十元候选。**

### 第2问：他最反复面对的不是事件，而是什么结构？

人物不是被单个剧情定义，而是被**反复结构**定义。

| 反复结构 | 主十元候选 |
|---------|-----------|
| 反复错过 | xz / nz |
| 反复证明自己是谁 | zn / x |
| 反复被身份包装替换 | x并z / zn |
| 反复被规则压住 | xn / z |
| 反复判断别人是否可信 | nx / nz |
| 反复选择并承担后果 | zx / nx |
| 反复维持关系不散 | n / nz |

### 第3问：他最怕失去什么？

恐惧比渴望更真实。

| 最怕失去 | 主十元候选 |
|---------|-----------|
| 失去归宿、被留下的位置 | nz |
| 失去意义、信念、自己相信的东西 | zn |
| 失去身份真实性 | zn / x并z |
| 失去控制、节奏、秩序 | xn |
| 失去判断力、看清真相的能力 | nx |
| 失去行动机会、选择权 | zx |
| 失去承载关系的能力 | n |
| 失去欲望燃烧本身 | x |
| 失去被看见的一瞬 | z |
| 失去停靠可能，只剩漂流 | xz |

### 第4问：他最终不是去了哪里，而是回到了哪个感觉？

结局不能倒推起手，但可以**验证**主十元。

比如一个人物最后回家，不代表他主十元一定是 nz。要看"回家"在角色链条里是什么：
- 是真正停靠？→ nz
- 是意义完成？→ zn
- 是被现实承载？→ n
- 是命运暂时放过？→ xz+nz
- 是身份重新成立？→ zn+x
- 是规则闭环完成？→ xn
- 是行动后果结算？→ zx+nx

**结局是验证器，不是起手本体。**

### 第5问：他的副十元是在服务谁？

如果角色有很多十元，问：**这些十元最后都在强化哪个核心感觉？**

**例A：** 角色有 x、zx、nx。如果 x 是欲望，zx 是行动，nx 是审查，最后都在强化"他越行动越被因果反咬"→ 主结构可能是 **zx+nx 因果型**。

**例B：** 角色有 xz、nz、n。如果 xz 是漂流，nz 是想停靠，n 是临时生活结构，最后都在强化"停靠了但停不稳"→ 主结构可能是 **xz+nz 命运型**。

**例C：** 角色有 x并z、zn、x。如果身份包装、被观看、表象替代不断夺走"我是谁"→ 主结构可能是 **x并z → zn/x 本体型**。

## 第四章：人物主十元锁定公式

```text
人物主十元 =
  最不可替换的存在问题
  + 最反复出现的内在驱动力
  + 最能解释其痛苦/选择/关系的十元
  + 被拿掉后人物崩塌的核心感受
```

更短：

```text
主十元   = 人物的存在发动机
副十元   = 人物的气质加厚层
功能十元 = 剧情里的工具位
视觉十元 = 外观接口
结算十元 = 最后落点（验证器，非定义器）
```

## 第五章：固定输出格式

以后所有人物分析的输出格式统一为：

```markdown
## 1. 主十元判断

主十元：？
理由：拿掉它，人物哪一部分会崩？

## 2. 副十元

副十元：？
作用：它如何加厚主十元？

## 3. 功能十元

功能十元：？
作用：它在剧情中负责行动、承载、冲突、结算中的哪一位？

## 4. 视觉十元

视觉十元：？
注意：是否只是外观接口，不能反推本体。

## 5. 动态链

主十元 → 被什么压迫/补强/转导 → 最后落到哪里

## 6. 一句话定型

这个人物不是"[...]的人"，而是"[...]仍然必须[...]的人"。
```

## 第六章：行为陷阱清单（持续增长）

| 陷阱 | 误判 | 纠正方法 |
|:----:|:----:|---------|
| 「他执行了行动」→ zx | 小王子回到B-612不是zx | 问：执行是因为「完成本身有意义」还是因为「回去能见到玫瑰」？前者zx，后者z |
| 「他制定了规则」→ xn | 狐狸教驯服不是制度 | 问：他在创造系统还是教授方法？ |
| 「他算计了别人」→ nx | 蛇是死亡本身不是暗算 | 问：他是算了一笔账还是直接兑现了欲望？ |
| 「他看起来冷酷」→ x | 冷可能是xz的场景接口 | 问：冷酷是底层驱动还是表层应对？ |
| 「他很稳定」→ n | 稳定可能是xn的制度化产物 | 问：他是以承载为存在方式，还是被秩序包裹？ |
