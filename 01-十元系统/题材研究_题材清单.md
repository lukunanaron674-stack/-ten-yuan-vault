# 题材与五大主题关系研究

## 研究目标
建立题材→五大主题的映射关系：一个题材激活哪些主题，主题在题材中如何显形。

## 研究步骤
1. 列出题材清单
2. 每个题材标注激活的主题及强度
3. 每个题材写分析：题材的核心结构、人物配置、冲突类型、典型故事弧
4. 用实际作品验证
5. 产出题材分析指南

## 题材候选清单

### 经典叙事题材
- [ ] 复仇题材 — 因果型为主轴，可混命运/本体
- [ ] 成长题材 — 本体型为主轴，可混空间/时间
- [ ] 爱情题材 — 命运型为主轴，可混空间/本体
- [ ] 悬疑/推理题材 — 因果型为主轴，可混时间
- [ ] 战争题材 — 因果+命运，可混本体
- [ ] 逃亡题材 — 命运型为主轴（xz跑），可混空间
- [ ] 囚笼/越狱题材 — 空间型为主轴（x并z+n壳vs真实）
- [ ] 时间循环题材 — 时间型为主轴（xn+z规则vs冲动）
- [ ] 革命/反抗题材 — 因果+本体，可混时间

### 类型文学题材
- [ ] 奇幻/异世界题材 — 空间型为主轴（两个世界的张力）
- [ ] 末世/生存题材 — 因果+命运，可混本体
- [ ] 侦探/犯罪题材 — 因果型为主轴
- [ ] 历史/史诗题材 — 时间型为主轴

### 情感/心理题材
- [ ] 家庭题材 — 空间型（n承载）为主轴，可混命运
- [ ] 孤独题材 — 命运型（nz等不到）为主轴
- [ ] 救赎题材 — 本体型为主轴（zn意义追问）
- [ ] 背叛题材 — 因果+命运
- [ ] 失去/哀悼题材 — 命运型（nz等待回不来的）
