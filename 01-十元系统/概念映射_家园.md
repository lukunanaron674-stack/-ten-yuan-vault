# 家园（Home）— 15步映射

## 1-3. 十元映射

**概念定性：空间型概念**——家园的本质是归属的空间化。不是物理场所（那是房子），不是情感关系（那是羁绊），而是**「可以回去」的空间性存在**。家园在三元结构中展开：n（承载·家人/居所/归属）+ x并z（壳·房子的外壳/家庭的表象）+ nz（等待·家的等待）+ zn（意义·家的意义）。

| 十元 | 在「家园」中的表现 | 映射强度 |
|:----|:------------------|:--------:|
| **n** | **承载·家人的居所与归属**——家园最基本的层：能住人的物理空间（房子/房间/村落）、能承载关系的情感容器（家人/亲人/族群的共居结构）、能提供安全的后盾系统。「家是避风港」——n是家园一切的承载基础：没有n就没有"可以回去"的地方 | **9.5** |
| **nz** | **等待·家的等待**——家园的等待面：有人在等你回去、你等待回家、等待团圆。家的温度不在于你在这里，而在于你离开后总想回来的牵绊。nz是家园中最柔软也最深刻的情绪层——「有人在等你」是家之所以为家的最高证明 | **9** |
| **x并z** | **壳·房子的外壳与家庭的表象**——家园的外壳层：墙、屋顶、门、院子——家的物理边界。「家」与「房子」的区分正在于此——房子的外壳（x并z）不等于家的本质（n），但没有壳的家也是不完整的。x并z是家园的界面——对内是保护，对外是界定 | **8.5** |
| **zn** | **意义·家的意义**——家园被赋予的精神意义：家不仅是住的地方，它是归属的象征、身份的锚点、生命意义的原点。「家是根」「家是来处」「家是心安处」——这些意义化的表达将家园从物理空间升华为精神信仰 | **8** |
| **xz** | **临界·回不去的家**——家园的丧失面：拆迁、离乡、家庭破裂、有家不能回、家已不再是家。xz是家园被压缩到临界状态时的张力——家的边界在恐惧中被模糊（怕失去家）、在被迫离开时的边缘体验 | **7.5** |
| **x** | **吞噬·离散与漂泊**——家园的被吞噬：物理的消失（房屋坍塌、家园毁灭）、关系的断裂（亲人离散、家庭破碎）、精神的无根（精神家园的丧失）。x是家园不可逆的丢失感 | **6.5** |
| **z** | **冲动·安家的本能**——建造家园、维护家园、保卫家园的原始驱动力。「为什么人要有个家」——z是安家筑巢的冲动：鸟筑巢、人买房、游子思归 | **6** |
| **nx** | **结算·家园的账**——维护家园的成本与回报：养家的付出、建家的投资、家的责任（房贷、家务、赡养）。家的温馨背后是nx的支撑——日子要过下去，账要算清楚 | **5.5** |
| **xn** | **规则·家庭制度**——家庭伦理、家规、家风、家族传统、孝道。家园不是无序的，它有内在的秩序和规则：谁当家、怎么分、家的仪式和节庆 | **5** |
| **zx** | **执行·建家持家**——建造/修缮房子、购置家具、安排生活、履行家庭责任的行动。zx是将"想要一个家"（z）固化为"拥有一个家"（n）的执行行为 | **4.5** |

### 映射强度排序

```
n(9.5) > nz(9) > x并z(8.5) > zn(8) > xz(7.5) > x(6.5) > z(6) > nx(5.5) > xn(5) > zx(4.5)
```

## 4. 体量（1-10）

**体量 = 8.5**

家园不是局部概念——它覆盖物理家园（房子、居所、环境）、情感家园（家人、关系、归属感）、精神家园（文化根脉、身份认同、精神归宿）。每一层面都有自己的家园体验。但家园不自成体系——它依附于归属感的存在（如果一个人不被任何人需要，就没有"家"），依附于物理空间的承载。故给8.5而非更高。

## 5-6. 位置盘

### 合法生克补（25对关系）

#### 补关系（直径灵魂对子）

| 对子 | 关系 | 说明 |
|:----:|:----|:-----|
| **n ↔ nz** | **补=9.5** | 承载与等待——家园的灵魂对子。有人等的地方才是家（nz），能回去的地方才是在等（n）。没有n（一处可归的居所），nz（等待）就成了空等——等不到人回去；没有nz（家人牵挂），n（房子）就只是空壳。n与nz的互补是家园区别于「房子」和「旅店」的根本 |
| **x并z ↔ zn** | **补=8** | 壳与意义——家园的外壳（房子的物理边界）与家园的意义化（精神归属的象征）互补。壳给意义以安放的空间，意义赋予壳以温度。没有壳的意义是飘的，没有意义的壳是空的 |
| **xz ↔ x** | **补=6.5** | 临界与吞噬——「回不去的家」的边界状态与「家园丧失」的不可逆性互补。二者共同构成家园的丧失序列：先被逼到边界（xz），然后被彻底吞噬（x） |
| **z ↔ zx** | **补=5** | 本能与执行——安家的冲动（z）与建家的行动（zx）互补。没有冲动就没有行动的开始，没有行动就没有家的建成 |
| **nx ↔ xn** | **补=4.5** | 代价与规则——持家的付出（nx）与家规的秩序（xn）互补。规矩让人愿意付出，付出让人维护规矩 |

#### 克关系

| 对子 | 方向 | 说明 |
|:----:|:----:|:-----|
| **x并z 克 n** | **克=7** | 外壳压抑承载——过度重视家的外在形式（x并z）——装修、面子、门面——会挤压家园的本质承载（n）。当房子变成炫耀品而非居住地，家的本质被异化 |
| **nz 克 x** | **克=6.5** | 等待对抗吞噬——有人在等你回家（nz）对抗家园的丧失（x）。「有牵挂就不会彻底破碎」——nz是x最有效的缓冲 |
| **x 克 z** | **克=6** | 吞噬消解本能——家园的丧失（拆了、散了、回不去了）消解了安家的冲动（z）。当你无家可归，你也不再想「建一个家」 |
| **nx 克 x并z** | **克=5.5** | 持家的付出戳穿外壳——生活的日子（nx的现实账单）会撕掉家的表面光鲜（x并z）。养家的辛苦让"外人的客厅"露出本质 |
| **xz 克 zn** | **克=5** | 临界消解意义——当家园被逼近临界（怕失去家、守不住家），家的精神意义（zn）被消解。「家都快没了还说那些虚的干什么」 |
| **zn 克 xn** | **克=4.5** | 意义超越规则——家的精神意义（"一家人整整齐齐"）有时越过家规（xn）。「你跟家人讲什么道理」——意义大于制度 |

#### 生关系

| 对子 | 方向 | 说明 |
|:----:|:----:|:-----|
| **n 生 nz** | **生=8** | 承载生出等待——家（n）的存在催生了等待（nz）——因为有一个可以回去的地方，才有「等你回来」。有了房子才有了归家的期待 |
| **nz 生 zn** | **生=7** | 等待生出意义——等待的牵挂（nz）被意义化为「家的精神」（zn）。「为什么你总想回家？因为有人在等你」——牵挂是意义的起点 |
| **z 生 xz** | **生=6** | 安家冲动生出临界——想建一个家的冲动（z）让家园敏感化，推向了害怕失去/守卫家园的临界状态（xz）。越在乎越怕失去 |
| **x并z 生 x** | **生=5.5** | 外壳生出吞噬——家的物理外壳（x并z）一旦被破坏（坍塌、出售、变成废墟），直接导致家园的不可逆丧失（x） |
| **zx 生 n** | **生=5** | 执行生成承载——建家持家的行动（zx）创造/维护了家园的承载（n）。不修屋子就漏水，不维护关系就散 |
| **n 生 xn** | **生=4.5** | 承载生出规则——家庭的存在（n）自然形成家规、家风、家族传统（xn） |
| **xn 生 zx** | **生=4** | 规则生出执行——家规（xn）指导持家的行动（zx）——「按规矩做事」让家庭有序运转 |
| **xz 生 nz** | **生=4** | 临界生出等待——当家园处于临界状态（怕失去），等待变得更强烈——越是怕失去，越是在等你回来 |
| **nx 生 x** | **生=3.5** | 持家付出生出吞噬——太累的持家（nx永无止境的付出）导致家园体验的丧失（x）——「撑不住了，这个家我不想回了」 |
| **zn 生 z** | **生=3** | 意义催生本能——精神家园的意义（zn）重新点燃安家的本能（z）——「为了这个家，我要再建一个」 |

## 7. 动态链（<=15字）

**家→壳→等→义→归**

### 三条链展开

**主链（正向生成链）：**
```
n(9.5) → nz(9) → zn(8)
```
承载（家）生出等待（人在等你）→等待生出意义（家的精神）。这是家园从物理到情感再到精神的正向生成路径：先有可归之处（n），然后在牵挂中（nz）体验到家的温度，最终将这种体验升华为归属的意义（zn）。

**强度计算：** (9.5 + 9 + 8) / 3 = **8.83**

**克链（压制/反抗链）：**
```
x并z(8.5) 克 n(9.5) → xz(7.5) 克 zn(8) → nx(5.5) 克 x并z(8.5)
```
外壳压抑承载（面子压过里子）→临界消解意义（怕失去让家失了魂）→持家支出戳穿外壳（日子的辛苦撕掉假面）。家园的自反性约束：表面的光鲜往往以牺牲实质为代价。

**强度计算：** (8.5 + 9.5 + 7.5 + 8 + 5.5 + 8.5) / 6 = **7.92**

**补链（互济链）：**
```
n(9.5) ↔ nz(9) → zn(8) ↔ x并z(8.5) → xz(7.5) ↔ x(6.5) → z(6) ↔ zx(4.5) → n(9.5)
```
承载与等待的互补（家园的灵魂对子）→意义与外壳的互补（精神与形式的统一）→临界与吞噬的互补（丧失序列）→冲动与执行的互补（安家-建家循环）→回到承载起点。

**强度计算：** (9.5 + 9 + 8 + 8.5 + 7.5 + 6.5 + 6 + 4.5 + 9.5) / 9 = **7.67**

### 动态链总强度

| 链型 | 强度计算 | 总强度 |
|:----:|:--------:|:------:|
| **主链** | (9.5+9+8)/3 | **8.83** |
| **克链** | (8.5+9.5+7.5+8+5.5+8.5)/6 | **7.92** |
| **补链** | (9.5+9+8+8.5+7.5+6.5+6+4.5+9.5)/9 | **7.67** |

**总动态强度 = (8.83 + 7.92 + 7.67) / 3 = 8.14**

**解读：** 家园的动态强度8.14，属于强概念。主链（8.83）显著强于克链（7.92）和补链（7.67）——家园的核心特征是它的正向生成力而非自反抑制力。主链从承载到等待到意义的递进极其自然、几乎没有阻力，说明家园的主要张力是**生成性的**——只要有一个安身之处（n），家的情感和精神就会自然生长出来。克链虽然低于主链但不低（7.92）——家园确实存在「外壳压本质」的异化风险，但它是可以被消化的异化而非结构性的内在矛盾。

## 8. 五大主题归仓

| 主题 | 强度 | 解释（<=15字） |
|:----:|:----:|:--------------|
| **空间 x并z+n** | **9.5** | 壳与承载——家园的本质主题 |
| **命运 xz+nz** | **9** | 家园的丧失与等待的牵绊 |
| **本体 zn+x** | **7.5** | 家园的意义化与被吞噬 |
| **时间 xn+z** | **5.5** | 家规秩序与安家本能 |
| **因果 zx+nx** | **5** | 建家持家与养家付出 |

**归仓排序：** 空间〔9.5〕> 命运〔9〕> 本体〔7.5〕> 时间〔5.5〕> 因果〔5〕

**主归主题：空间〔9.5〕**——家园最本质的归属是空间主题。家园不是一件"事情"（因果）、不是一段"时间"（时间），不是一种"信仰"（本体），而是一种**空间性的存在状态**：能回去的地方、有边界的容器、被壳包裹的归属。x并z（家的外壳）和n（家的承载）共同构成了家园的空间性基础——壳给定了界限以内/以外，承载给定了一个可以安放身心的处所。空间主题的强度（9.5）是唯一正确的归仓。

**辅归命运〔9〕**——家园的丧失维度和等待维度极其强烈（xz7.5 + nz9），命运主题中临界状态（回不去/守不住）与等待（等归/等团圆/等家好）共同构成家园的另一个核心张力：家园既是当下的栖居，也总是处在被失去的威胁中、被等待的牵挂里。家园的命运张力甚至比许多「命运型概念」更强。

## 9. 误判检查

**检查1：家园 vs 房子——是否混淆了本质与外壳？**
- ✅ 已区分。本映射将x并z（房子的外壳/家庭表象）设为8.5分，n（承载·归属）设为9.5分——家园的本质是"有人可以回去"的承载，不是"有墙有顶"的物理空间。x并z是家园的界面而非本质。
- ❌ **危险点**：把「装修好看」「房子大」当作家园的优质属性。已纠正——那些是x并z的伪装面，不构成家园的核心。家园的核心可以在一间破旧的老屋中完整存在。

**检查2：家园 vs 故乡——是否混淆了二者？**
- ✅ 用户已明确区分——家园是当下的栖居，故乡是回不去的来处。本映射中的xz（7.5·临界·回不去的家）是二者联系的桥梁：当家园变成了故乡，它就进入了"回不去"的临界状态。但家园本身是当下的（n的存在），故乡是过去的（xz的锁定）。家园可以被重建、搬迁、再造；故乡是唯一的。
- ❌ **危险点**：把乡愁（对故乡的思念）归入家园的概念。已纠正——乡愁属于记忆（nz+zn）而非家园。家园的nz是"等待回去"，乡愁的nz是"等待回不去的地方"——性质不同。

**检查3：物理/情感/精神三层面是否都覆盖了？**
- ✅ **物理家园**：x并z（外壳·房子）+ n（居所的承载）——可归的物理空间
- ✅ **情感家园**：n（家人的关系承载）+ nz（等待的牵挂）——可依的情感纽带
- ✅ **精神家园**：zn（家园的意义化）+ n（归属的精神寄托）——可安的信仰坐标
- ✅ 三层面共享同一个十元结构（n+nz+x并z+zn），只是在不同层面各有侧重：物理层更侧重x并z和n的实在载体，情感层更侧重nz的牵绊，精神层更侧重zn的意义升华。

**检查4：家园 vs 家庭——是否混淆了个体归属与社会结构？**
- ✅ 已区分。家庭（family）是xn主导的社会制度结构（家规、伦常、宗族），家园（home）是n+nz主导的空间性归属概念。家庭强调规则和责任，家园强调承载和牵挂。本映射中的xn（家庭制度）仅给5分，是家园的边缘位点而非核心。
- ❌ **危险点**：传统意义上的"成家"往往被理解为建立家庭（结婚生子），而非建立家园。已纠正——本映射定位的"家"是归属的空间化，不是婚姻制度的社会化。

**检查5：体量8.5——是否合理？会不会太低？**
- ✅ 合理。家园不是独立自存的概念——它需要"人"的存在（谁的家？）、"空间"的存在（哪里的家？）、"归属"的存在（被谁需要？）才能成立。家园是**关系的空间化**，依附于关系而存在。与其匹配的概念如"孤独"（体量待定）和"爱"（体量9）——家园需要它们作为前提。
- 但家园覆盖的尺度不小（从一间出租屋到整片乡土到文明的精神家园），且具有跨文化、跨时代的普遍性。8.5是一个合适的定位——不及因果（10）和时间（10）的元级别，但高于美（8）和信任（8）的局域级别。

**检查6：是否把「家」的意象（炊烟、灯光、饭菜香）当成了结构？**
- ✅ 已避免。本映射的所有强度基于十元几何位置（n↔nz补9.5、x并z克n克7等），而非基于意象联想。"炊烟"（家的信号/等待的证据）是nz的形象表达，"灯光"（温暖的指引）是x并z+ nz的界面表现——它们被用作说明语言而非映射依据。
