# R3-B｜旧定义三层迁移正本

现行统一结构：

```text
L1 感受核：人直接感受到什么
L2 诱发机制：哪些结构/关系/形式常诱发这种感受
L3 领域表现：进入角色/视觉/音乐/叙事后怎样表现
```

禁止 L2/L3 反向冒充 L1。

## X｜醒
- L1：人感到注意被拉醒、差异被拉开、边界更清楚、更容易分辨。
- L2：高对比、明确切分、变量减少、具体物象聚焦、边界/归属/因果明确。
- L3：锐利轮廓、强切分、明确判断、单一因果、明显节拍断点。
- 旧“X=具体物象/物质关系”降为L2。

## Z｜张
- L1：人感到某种东西被张开、凸显、外放，存在感被放大。
- L2：对比强化、中心化、外扩、被看见/确认、宣言、突出。
- L3：强中心构图、外扩形、强主旋律、聚光、存在感强的人物行为。
- 旧“Z=寻求认可”降为L2/L3高频情境。

## N｜耐
- L1：人愿意停留和继续感受；多个部分能共处，整体关系被持续容纳。
- L2：邻近、连续、多方并存、柔和过渡、理解/包容/协调。
- L3：连续过渡、协调组合、层叠和声、关系式构图、容纳多方的人物行为。
- 旧“N=精神/整体/关系”降为L2/L3。

## 十元与五轴迁移
- 十元L1＝独特的人类感受方向。
- 十元L2＝旧端点结构变量、五轴变量、行为机制。
- 十元L3＝各领域表现。
- 尚未冻结最终L1体验词的十元统一标记 `FEELING_CORE_PENDING`，不得用旧结构变量冒充感受核。
- 五轴配对拓扑暂保留；旧“方向权/归属/内外/裁定/可逆性”等变量降为L2诱发机制候选。

## 数据字段迁移
旧对象标签保留到 `legacy_labels`，现行至少记录：


## AI运行链
```text
刺激/形式/语境
→ 人的感受目标或真实反馈
→ AI提取诱发特征并预测感受谱
→ AI生成/调整
→ 再交给人评价
```

R3-B完成门：旧自动生产停止；核心入口换为感受链；X/Z/N三层化；十元/五轴旧定义降为诱发机制；旧素材保留。
