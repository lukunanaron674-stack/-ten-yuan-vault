# 【nz 信息量卡 v2.0】

> **nz = 某段对象特异关系形成了可信停靠：双方可以自由离开、经历分离或冲突，却仍存在可验证的回返、修复与重新接近位置。**

## 1. 核心本体

```text
双方曾真实建立共同关系
→ 彼此不是任意替代对象
→ 离开不自动毁灭关系，留下也不是被迫
→ 分离、冲突或时间经过后仍存在可信回返路径
→ 回来以后能够重新接近、修复或继续共同生活
→ nz
```

最短定义：

> **nz = 我知道这里仍是可以回来的关系位置。**

`nz`的核心变量是：

- 对象特异性；
- 回返可信度；
- 自愿退出与重新进入资格；
- 分歧后的修复能力；
- 共同时间与关系证据连续性；
- 停靠是否仍然属于双方，而非单方想象。

## 2. 等待与余温的正确位置

等待、守望、旧房间、余温、不想结束，是`nz`的重要血肉，但不是唯一主骨。

```text
等待型 nz：关系对象暂时离开，我保留可返回的位置。
修复型 nz：发生冲突后，双方仍能重建接近与信任。
归宿型 nz：漂流结束时，我知道要回到谁或哪里。
日常型 nz：不必戏剧化离别，关系本身长期可停靠、可返回。
```

只有单方怀念、无法确认对方是否愿意回返时，最多是`nz`候选状态，不能直接锁定稳定关系端点。

## 3. 必要条件

判断稳定`nz`，以下五项至少满足四项，第1、2项不可缺：

1. **对象特异**：不是“任何亲近者都行”，而是明确双方或明确共同体。
2. **关系证据**：双方曾有真实共同时间、共同处理或相互回应。
3. **自由性**：留下、离开和返回不是靠威胁、资源扣留、职位或照护强迫。
4. **回返性**：分离后仍存在真实可调用的返回路径，而非只剩回忆。
5. **修复性**：冲突、错误或距离出现后，双方有重新接近和修复的能力。

## 4. 对象分层

- **人物本体 nz**：长期把对象特异关系、回返与修复当作主要存在方式。
- **人物状态 nz**：此刻不愿结束、期待返回或重新靠近。
- **行为 nz**：等待、回去、保留位置、修复、重新建立联系。
- **关系 nz**：双方的退出、回返与修复资格真实存在。
- **场景 nz**：家、旧房间、车站、火炉只是显影候选，不能自行成立。
- **视觉 nz**：余温、留白、回望、旧物只作辅助证据。

## 5. 最近邻

### nz vs n

```text
n：对象进入内部后，被真实接住、处理并持续承载。
nz：对象离开或关系受损后，仍有可信返回与修复位置。
```

“照顾得很好”不能自动证明关系可自由退出和回返。

### nz vs z

```text
z：我是否被重要认可主体看见和确认。
nz：我们之间是否仍存在可信停靠与回返。
```

追求某人的认可，不等于双方具有关系归宿。

### nz vs xz

```text
xz：危险、失去风险与时间窗收窄。
nz：风险穿过以后值得返回的对象与关系终点。
```

危险会强化失去感，但不能凭空生成关系证据。

### nz vs x

```text
x：对象归我掌握，我拥有决定、调用或排除边界。
nz：对方可以自由离开，关系仍靠自愿回返维持。
```

禁止退出、替对方决定、扣留资源，更接近`x克nz`，不是高体量`nz`。

### nz vs nx

```text
nx：不占最终方向，沿他人或现状给出的路线推进。
nz：关系提供停靠，但不必撤销自己的否决、换人和重新判断资格。
```

## 6. 拿掉测试

依次拿掉：

1. 怀旧色调与旧物；
2. 同住、资金、照护和共同资产；
3. 危险与失去威胁；
4. 单方等待；
5. 公开承诺和角色称谓。

若仍能证明双方自由离开后可真实返回、冲突后可修复、对象不可任意替代，`nz`才稳定。

## 7. 反向测试

- 对方明确不愿回返，关系只剩单方回忆：稳定`nz`下降。
- 离开会遭惩罚或失去生存条件：优先检查`x/xn/zx/n`结构。
- 换成任何照护者都成立：对象特异性不足。
- 冲突后只能恢复表面角色，不能恢复可信接近：检查`x并z`壳，而非`nz`修复。
- 双方能各自选择、长期分离后仍主动回来并重建关系：`nz`强。

## 8. 视觉与创作显影

可用但不能反向定义：

- 留着空位，但对方真的可以回来；
- 门能够从两侧打开；
- 分开后重新坐回同一张桌子；
- 旧物不是遗物，而是双方仍能共同解释的关系证据；
- 冲突后第一次恢复自然称呼、触碰或共同节奏。

## 9. 关系接口

本卡只定义`nz`端点，不自行证明关系启动。

现行几何位置：

```text
z 生 nz
nz 生 nx
nz 克 x
x并z 克 nz
xz ↔ nz（补）
```

其中机制是否锁定，必须查`十元生补克表`与关系专项正本；不得由本卡反推。

## 10. 召回版

```text
nz = 对象特异的可信停靠、自由退出、冲突后修复与可回返。
等待和余温只是子型；单方怀念不是完整关系端点。
```
