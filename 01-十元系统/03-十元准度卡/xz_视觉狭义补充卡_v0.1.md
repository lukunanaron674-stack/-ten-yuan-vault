# xz视觉狭义补充卡

## 核心修正

xz不能等同于普通危险。

- x：危险物品本体，锐利、切割、直接伤害。
- xz：火药桶结构，危险能量已经蓄积，存在触发点，触发后整体爆发。

## x 与 xz

```text
x = 刀
xz = 火药桶
```

x关注：
- 锐利
- 切割
- 尖端
- 直接攻击面

xz关注：
- 内部压力
- 能量积累
- 临界状态
- 引爆点
- 整体爆发

## 视觉形态

xz常表现为：

- 长三角
- 长楔形
- 尖端引信结构
- 宽主体向尖端收束

形态逻辑：

```text
危险主体(x)
+
触发节点(z)
=
xz
```

## 发型映射

xz发型不是：

- 碎
- 乱
- 羽化
- 松散

这些更接近nx等扩散结构。

xz发型应寻找：

- 厚重主体
- 长轴延伸
- 明确尖端
- 压缩后的爆发方向

## 与zx区别

```text
zx = 主动释放力量
xz = 等待触发后爆发
```
