# nx 准度卡 v0.4

> **nx = 不占据方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。**

## 1. 必须先分对象

```text
人物本体 nx：长期没主见，方向常由别人或现状决定。
人物状态 nx：某阶段暂时不占方向位置。
行为 nx：接受安排、跟随、求人、借力、托关系、沿权限通道推进。
关系 nx：承认他者已有身份与权限，通过既有网络办事。
```

一次服从、一次求人、一次借法宝，不能单独证明人物本体是 nx。

## 2. 纯 nx 必要条件

判为纯 nx 人物本体，以下五项至少满足四项，第 1、2 项不可缺：

1. 方向已经由别人、群体、家庭、流程或现状给出。
2. 主体不主动改写方向，也不抢最终决定位置。
3. 更习惯让别人决定或让现状自动延续。
4. 这种方式跨场景反复发生。
5. 没有明显外部强迫时，仍倾向等别人安排。

最短公式：

```text
方向已经存在
+ 我不主动改写
+ 选择让给别人或现状
+ 反复成立
= 纯 nx 强候选
```

## 3. 员工金标准

### 正例：nx

```text
老板安排什么
→ 员工就做什么
→ 不改变方向
→ 不主动搭建新的运行结构
= nx 行为
```

### 反例：xn

```text
老板只给目标
→ 老员工自己排顺序、搭流程、分资源、预判节点
= xn 主
```

老员工可能带少量 x 和 n 质地，但不是“安排啥干啥”的 nx。

## 4. 求人办事与人情世故

nx 关系功能的必要条件：

1. 问题的权限、资源或解决通道在别人手里。
2. 主体需要进入既有人际、身份或制度网络。
3. 通过请求、借力、托关系、请救兵或借法宝推进。
4. 重点不是主体直接压过所有人，而是沿他者已有位置办成。

这类 nx 可以出现在强 zx 人物身上。不能因为人物总体有主见，就否定某段关系功能为 nx。

## 5. 孙悟空校准题

### zx 正例

```text
齐天大圣
与天齐名
骑到所有人头上
以无敌权能迫使天庭正面回应
```

### nx 正例

```text
找菩萨、土地、龙王、天庭
借法宝
请救兵
通过神仙身份、旧交与权限网络解决问题
```

### 错误判法

- “孙悟空整体没主见，所以是 nx。”错误。
- “孙悟空会求人，所以主十元是 nx。”错误。
- “五行山压住他，所以后来生成 nx。”错误。

正确分层：

```text
人物稳定结构：zx + nx
主轴：zx
关系功能与副轴：nx
外部五行山：xn 克 zx
```

## 6. 最近邻差异

### nx vs xn

| 检查项 | nx | xn |
|---|---|---|
| 方向 / 通道 | 来自别人、关系或现状 | 可接收外部目标，但主动组织运行方式 |
| 核心动作 | 跟随、配合、求人、借力 | 排程、记录、搭流程、设节点 |
| 等待 | 等别人或现状决定 | 为计划和节点主动等待 |
| 取消规则后 | 仍可能等别人给方向 | 会主动重新组织 |

### nx vs zx

| 检查项 | nx | zx |
|---|---|---|
| 办事路径 | 沿既有关系与权限借力 | 直接用自己的权能压入现实 |
| 方向位置 | 不占最终决定权 | 主动占据并扩大决定位置 |
| 孙悟空 | 求人、借法宝、请救兵 | 齐天大圣无敌之姿、直接战斗 |

### nx vs x

| 检查项 | nx | x |
|---|---|---|
| 权限 | 在别人手里，需要借用 | 归主体掌握 |
| 幕后网络 | 沿网络求人办事 | 控制整个网络 |
| 标准例 | 接受老板安排 | 唐人街幕后 Boss |

## 7. z 克 nx

```text
z 持续表达、决定和占位
→ nx 不主动抢回方向
→ 选择空间持续减少
→ 高体量时可能把自己让没
```

“把自己让没”是关系结果，不是 nx 的唯一主骨。

## 8. 非充分条件

以下不能单独判 nx：

- 沉默、内向、低调。
- 忍耐、礼貌、愿意帮助。
- 身处制度或接受一次命令。
- 暗中观察、看牌、记账、结算。
- 幕后控制。
- 求人一次。

## 9. 快速检查

```text
谁决定方向？
权限和资源在谁手里？
主体是在直接压过去，还是沿关系网络借力？
主体是否主动组织时间、流程和节点？
这是长期人物本体，还是一段行为 / 关系功能？
```
