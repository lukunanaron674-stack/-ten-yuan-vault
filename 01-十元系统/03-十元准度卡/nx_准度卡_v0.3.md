# nx 准度卡 v0.3

> **纯 nx = 不主动占据选择、方向和位置，顺着已有关系、群体、流程、安全结构或环境继续运行。**

> **“把自己让没”是 z 持续克制 nx 后的结果，不是 nx 一开始主动追求的状态。**

## 1. 判断对象

先区分：

- **nx 人物本体**：长期不主动定方向，让选择落到别人或现状手里。
- **nx 状态**：某阶段暂时顺从安排、避免作决定。
- **nx 行为**：跟随、默认、让别人选、事情落下就继续做。
- **nx 场域**：方向已被他人、群体、流程或环境决定。
- **z 克 nx 的结果**：nx 持续退位，最后把自己让没。

一次服从、一次礼貌让步、一次跟随，不能直接判人物本体为 nx。

## 2. 纯 nx 必要条件

判为纯 nx，以下五项至少满足四项，第 1、2 项不可缺：

1. **已有方向存在**：关系、群体、流程、家庭、安全或环境已经给出运行方向。
2. **主体不主动改写**：不抢决定权、不主动定方向、不主动中断。
3. **选择外包**：更习惯让别人决定，或让现状自动延续。
4. **重复性成立**：不是一次权宜，而是稳定惯性。
5. **无外部强迫时仍偏被动**：即使可以选择，也倾向等别人安排。

### 最短公式

```text
方向已经存在
+ 我不主动改写
+ 选择让给别人或现状
+ 这种方式反复发生
= 纯 nx 强候选
```

## 3. z 克 nx 必要条件

“把自己让没”必须另外判断：

1. z 持续表达、决定、要求或占位。
2. nx 没有主动对抗，也没有抢回选择权。
3. nx 的发言、空间、需求或身份位置不断缩小。
4. 结果不是一次退让，而是主体逐渐消失。

### 关系公式

```text
z 持续占位
→ nx 持续不抢回
→ nx 位置后退
→ 把自己让没
```

## 4. 非充分条件

以下特征不能单独判 nx：

- 沉默、内向、社恐
- 温柔、善良、愿意帮助
- 遵守制度、服从命令
- 忍耐、低头、坐边上
- 普通职员、小透明造型
- 一次说“都行”
- 聪明、看穿、暗算、结算
- 暗室、档案、监控、赌桌

尤其注意：

> **“主动压掉自己维持关系”不再是纯 nx 的唯一或首要定义。**

维持关系只是场景之一。维持群体、流程、安全和现状，或避免自己成为选择者，也可以进入 nx 检查。

## 5. 第一体感

> **“既然已经这样了，那就先这样吧。”**

nx 常见的不是悲壮牺牲，而是主动性没有出现：

- 你们定。
- 我跟着就好。
- 随便。
- 那就这样。
- 别人都这么做。
- 既然安排给我了，我就做。

## 6. 最小差异对子

### nx vs nz

| 检查项 | nx | 更偏 nz |
|:------|:---|:--------|
| 行动起点 | 已有事情落下来，顺着继续 | 主动想接住、照顾或维系 |
| 主动性 | 低 | 有明确关系主动性 |
| 封存句 | “既然落到我这里，那就这样吧” | “我来接住你” |

### nx vs xn

| 检查项 | nx | 更偏 xn |
|:------|:---|:--------|
| 核心动作 | 不主动建立或改写方向，沿已有安排继续 | 主动把信息、行动或资源放进计划、时间、规则、记录或隐藏结构 |
| 对规则与流程 | 可以不理解、不认同，也不主动组织；只是顺着走 | 主动使用、安排、维护或重组规则与流程，使积累发挥力量 |
| 等待 | 因自己不占选择位置而继续等 | 为计划、节点、记录、时机或结算而主动等待 |
| 规则取消后 | 仍可能等待别人或现状给出方向 | 会重新组织计划、顺序、记录或结构 |
| 最小切口 | “你们定，我继续。” | “我要把这件事放进结构里。” |

> **有规则存在，不等于 xn；服从规则，也不等于 xn。必须检查主体是否主动组织并利用时间与结构。**

### nx vs zx

| 检查项 | nx | 更偏 zx |
|:------|:---|:--------|
| 方向由谁定 | 别人、现状、环境 | 自己主动让权能进入现实并扩大 |
| 面对选择 | 外包、拖延、顺从 | 占据方向、破局、推进或复起 |
| 忍耐 | 没主动拿回位置 | 为再次显现或破局暂时压住 |

### nx vs z

| 检查项 | nx | z |
|:------|:---|:--|
| 位置 | 不主动占 | 主动显现、表达、占位 |
| 方向 | 顺已有方向 | 建立自己的方向 |
| 关系 | 可被 z 持续压退 | 可持续克制 nx |

## 7. 流行词入口

### 纯 nx 召回词

- 随安排的人
- 跟着走的人
- 没主意的人
- 总说“你们定”的人
- 被动参与者
- 习惯让别人选择的人

### z 克 nx 的社会形态

- 龟男
- 老好人
- 受气包
- 被默认懂事的人
- 关系缓冲垫
- 把自己让没的人

这些词只用于召回，最终仍检查结构。

## 8. 连续行为脚本

### 纯 nx

```text
别人提出方向
→ nx 不主动提出替代方案
→ 让别人完成决定
→ 自己跟着执行或继续
→ 下一次仍重复同样方式
```

### z 克 nx

```text
z 第一次要求并占位
→ nx 没有主动反对
→ z 将退让视为默认
→ z 第二次要求更多
→ nx 继续不抢回位置
→ nx 的位置逐渐消失
```

## 9. 人物准度检查

```text
谁在替他决定方向？
如果没人安排，他会不会主动选择？
他是在主动照顾，还是只是不把事情推出去？
他是否长期避免成为明确选择者？
他有没有一条会主动守住的线？
“把自己让没”是否由持续 z 压力造成？
```

## 10. 反例

### 反例 A：按军令行动

“军令、军队、纪律”只是题材与场景词，不能直接判 xn。

必须拆开：

```text
只是接受别人给出的命令并沿既定安排继续
→ 只能证明 nx 行为候选或服从行为

主动制定部署、安排时间节点、记录情报、组织流程并利用制度积累力量
→ 才优先检查 xn

为实现自身权能与目标而暂时服从命令，等待再次推进
→ 另查 zx 行为或状态
```

一次按军令行动不足以判人物本体为 nx、xn 或 zx。

### 反例 B：主动照顾朋友

若角色主动想接住对方，并能表达自己的边界，不是纯 nx。

### 反例 C：潜伏等待反击

若不表态是为了最后推进和出手，应检查 zx；若主体同时记录、排程、等待节点，则另查 xn。不能因为“等待”一词直接判 nx。

### 反例 D：聪明的观察者

看牌、记录、等待结算不再自动判 nx。更应检查 xn 候选，执行翻牌与权能显现部分另查 zx。

## 11. 旧口径迁移

| 旧材料 | 当前处理 |
|:------|:---------|
| 暗算、看牌、记账 | 移入 xn 候选迁移池 |
| 等待、累积、按节点处理 | 若为主动计划与节点组织，优先检查 xn；若只是不占方向而等，检查 nx |
| 到点翻牌、推进、切断 | 另查 zx 行为；若依靠预先安排，补查 xn |
| 暗室、档案、监控 | 仅作视觉 / 场景材料 |
| “把自己让没” | 改为 z 克 nx 的结果 |
| 军令、制度、学校、监狱 | 仅为题材入口，不直接判 xn |

## 12. 判定评分

### 纯 nx

| 项目 | 分数 |
|:----|:---:|
| 已有方向 / 安排存在 | 0-2 |
| 不主动改写 | 0-2 |
| 选择外包 | 0-2 |
| 重复形成惯性 | 0-2 |
| 相邻十元排除 | 0-2 |

### z 克 nx

另加检查：

- z 是否持续占位
- nx 是否持续退位
- 主体位置是否缩小

```text
8-10：纯 nx 强判
6-7：nx 主或 nx 状态，需补材料
4-5：只有一次跟随或外观皮肤
0-3：不应主判 nx
```

## 13. 三元与关系接口

当前确认：

```text
z 克 nx
```

三元构成、其他生克补关系仍待正式表校验，不从本卡自行扩写。

三元与十元只允许并行核对，不得写成父子派生关系。
