# xz视觉狭义卡 v0.2

## 1｜核心定义

> **xz 是火药桶式危险：危险能量已经蓄积在一个整体结构中，对一个触发点高度敏感；一旦被触发，变化不是局部切割，而是整体爆发、扩散或失控。**

最短召回：

```text
xz＝火药桶
```

重要修正：

```text
x不是火药桶本体。
x是刀、尖刺等锐利危险物品。
xz本身才是火药桶式危险结构。
```

## 2｜语义发动机

xz至少包含：

1. **整体蓄积**：危险不是只在一个尖角，而是储存在整个结构中；
2. **临界敏感**：一个小刺激、接触点或节点就可能改变全局；
3. **整体释放**：触发后不是只切开一点，而是整个系统爆开、扩散或失控；
4. **尚未主动发动**：爆发前可以平静、静止或被压住；
5. **不可局部化**：危险不能被解释为一把普通刀的单点切割。

## 3｜发型形状

发型视觉中的本征形：

```text
长三角
长楔形
宽厚主体＋细长触发端
火药桶主体＋引信式尖束
```

但长三角只是形状显影，不是充分条件。正式判断必须同时看到“蓄积整体”和“触发敏感”。

## 4｜轴向显影

```text
局部长轴 L：结构有明显延伸方向。
局部横轴 W：主体较宽，向触发端逐渐收窄。
```

常见结构：

- 宽厚根部或主体承担危险储量；
- 尖端、细束或节点像引信；
- 主体与触发端属于同一个连续轮廓；
- 轮廓未主动外冲，却有一碰就会整体释放的张力。

## 5｜发型成立条件

主判xz至少检查：

1. 整体不是散碎，而是一个连续危险体；
2. 主体具有厚度、压缩或高张力；
3. 存在清楚的触发尖端、引信束或临界节点；
4. 局部触发在视觉上能牵动整体；
5. 结构尚未主动向外释放；
6. 拿掉触发端或蓄积主体后，xz感明显下降。

## 6｜候选发型

- 宽根长尖的单片斜刘海；
- 厚主体连接一根引信式长尖束；
- 矛形前发，但主体必须有蓄积重量；
- 长楔形遮眼刘海，尖端承担触发焦点；
- 中央厚块向下收成一个长尖端的临界结构。

这些只是候选形，仍需逐图核验。

## 7｜最近邻

### xz vs x

```text
x：刀。危险来自锐利、切割和直接伤害边界。
xz：火药桶。危险储存在整体中，一个触发点可能使整体爆发。
```

### xz vs zx

```text
xz：尚未主动释放，但处于高敏感临界。
zx：力量已经主动推出并占据方向。
```

最短区别：

```text
被点爆＝xz
主动推出＝zx
```

### xz vs z

```text
z：长方形、长片、长度节点或单一裁定点。
xz：节点连接了真实的整体危险蓄积，触发后牵动全局。
```

### xz vs nx

```text
nx：方形、散开、横向铺展、碎束块面化。
xz：连续、集中、整体蓄积，并有唯一或高度集中的触发端。
```

**散、碎、乱、羽化不能单判xz。**

### xz vs nz

```text
nz：扁椭圆、低重心、柔软停靠和圆钝回落。
xz：高张力、触发敏感、尖端集中和整体爆发可能。
```

## 8｜拿掉测试

```text
拿掉整体蓄积，只剩尖锐切口 → x。
拿掉触发敏感，只剩等宽长片 → z。
让结构主动向外释放 → zx。
打散成许多横向碎束 → nx。
压扁并磨圆成低重心轮廓 → nz。
只有长三角，但没有火药桶张力 → 不能高判xz。
```

## 9｜发型库硬规则

- 旧“多方向漂移、羽化、散射、乱边＝xz”判据作废；
- 旧水库xz条目必须逐图重审，不得直接继承原排名；
- xz本征准度不能由旧纯度自动迁移为终审分数；
- 未完成视觉复审前，旧xz配比与排行只能标记为历史迁移数据。

## 10｜层级说明

本卡是`xz`进入视觉／发型领域后的狭义卡，不替代全局动态准度卡。全局卡回答危险怎样在人物、状态、场域中成立；本卡回答这种结构怎样在静态视觉中显影。两层必须分别记录，不得互相冒充。
