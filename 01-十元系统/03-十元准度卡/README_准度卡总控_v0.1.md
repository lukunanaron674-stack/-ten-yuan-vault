# 十元准度卡总控 v0.3

> 血肉卡回答“它能长成什么”；准度卡回答“为什么必须判成它”；关系卡回答“判定以后怎样生、克、补”。

## 1. 当前开发顺序

```text
判断对象
→ 十元初判
→ 三元比例与质地校验
→ 十元准度判定
→ 本体 / 状态 / 行为 / 环境 / 结果分层
→ 血肉扩展
→ 生克补判定
→ 动态链与故事
```

### 关键纠正

- 三元与十元并列，不是“三元派生十元”。
- 十元判位置，三元描述其内部比例、质地与当前观看方式。
- 例如 nx 可以表现为 n 多 x 少，但 nx 与 n 是同一层级的位置。
- 禁止因为故事链好看，就反推人物本体。

### 95% 自主推进阈值

- 至少 95% 确定用户会同意：直接完成。
- 存在超过 5% 的真实结构分叉：提问。
- 格式、同步、迁移入口与明显旧错误修正，不反复请示。

## 3. 五种基础对象必须分开

1. **本体**：人物长期稳定的发动结构。
2. **状态**：当前阶段或当下反应。
3. **行为**：这一次采取的方式。
4. **环境 / 场域**：外界形成的压力或容纳结构。
5. **结果**：事件最后落成的形态。

扩展视觉对象：

- 光影
- 色彩
- 构图
- 空间
- 时间关系

不同对象出现不同十元，不等于人物本体不断换标签。

## 4. 时间与剧本规则

现实分析中，一个人在不同时间点、不同对象上会切换主要观看方式。

故事和剧本中应优先保持稳定的 **人物本体锚**：

```text
稳定人物本体
→ 状态变化
→ 行为变化
→ 环境与关系作用
→ 本体被压制、补厚或显露新侧面
```

除非作品核心明确描写人格或主体结构重建，否则不得频繁改写人物本体。

## 5. 判定闸门

在以下项目没有完成前，不进入生克补：

```text
[ ] 判断对象已明确
[ ] 十元必要条件成立
[ ] 三元比例与质地已有证据
[ ] 相邻十元已排除
[ ] 本体 / 状态 / 行为 / 环境 / 视觉没有混淆
[ ] 人物锚与时间切片已经分开
[ ] 置信度达到 80%
```

低于 80% 时只输出候选，不生成关系链。

> 80% 是案例准度闸门；95% 是助手是否需要继续询问用户的执行阈值。两者不可混用。

## 9. 当前硬规则

### z

- z 不是楚庄王弓，也不是单纯追光、执念或舞台。
- z 通过学习、理解并有限改变客观世界，使改变得到认可，进而扩大主观权能。
- 认可主体可以是个人、公众、已故对象、神、国家、历史、想象观众或自己。
- 纯 z 承认客观世界独立存在，只改变其中一部分。
- 主观试图替代、吞没或完全定义客观世界时，进入脏醒边界。

### xz

- 不能只靠暗色、破损或怪物造型判断。
- xz 的核心是**危险感本身具有运动势能**。
- 人物不必行动，只要危险正在逼近、扩张或压缩安全距离，就可形成 xz。
- 临界行动是危险作用到主体后的常见结果，不再是 xz 必要条件。
- xz 是运动中的危险感；x 的生死感更像静止、干净、一瞬落点。
- 视觉 xz 不自动等于人物本体 xz。

### nx

- 纯 nx 不是“主动牺牲自己维持关系”。
- 纯 nx 是不主动占据选择、方向和位置，顺着已有安排继续。
- 维持关系只是表现之一，也可能顺着群体、流程、安全和环境运转。
- `z 克 nx` 已确认：z 持续决定和占位，nx 不抢回位置，最后把自己让没。
- “龟男、老好人、受气包、把自己让没”优先作为 `z 克 nx` 的社会形态，不等于纯 nx 全定义。

### 旧暗算 / 看牌 / 结算

- 不再作为纯 nx 主骨。
- 记录、等待、顺序累积、到节点处理，转入 xn 候选池。
- 主动翻牌、推进、切断和执行清算，另查 zx。
- 不能批量把旧 `zx + nx` 直接改成 `zx + xn`，必须逐案复判。

## 10. 流行词、图像与故事

- 流行词用于召回社会脚本，不直接代替判定。
- 单张图优先判断光影、颜色、构图、空间和视觉关系。
- 单张气质图只能提供视觉映射，不能直接确定人物本体。
- 漫画、电影优先看时间点变化与关系运动。
- 剧本人物本体保持稳定，状态与关系承担主要变化。
