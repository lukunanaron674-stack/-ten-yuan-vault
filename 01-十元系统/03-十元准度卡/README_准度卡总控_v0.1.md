# 十元准度卡总控 v0.2

> 血肉卡回答“它能长成什么”；准度卡回答“为什么必须判成它”；关系卡回答“判定以后怎样生、克、补”。

## 1. 开发顺序

```text
三元定义
→ 三元判定
→ 三元到十元的构成关系
→ 十元准度判定
→ 血肉扩展
→ 生克补判定
→ 动态链与故事
```

**禁止倒序：**不能因为一条故事链好看，就反推人物本体或十元类型。理论不是短视频标题，不能先抓人再补证据。

## 2. 五种对象必须分开

1. **本体**：人物长期稳定的发动结构。
2. **状态**：当前阶段或当下情绪。
3. **行为**：这一次采取了什么方式。
4. **环境 / 场域**：外界正在形成什么压力结构。
5. **结果**：事件最后落成什么形态。

不同层级出现不同十元，不等于人物本体不断换标签。

## 3. 判定闸门

在以下项目没有完成前，不进入生克补：

```text
[ ] 判断对象已明确
[ ] 三元主次已有证据
[ ] 十元必要条件成立
[ ] 相邻十元已排除
[ ] 本体 / 状态 / 行为 / 环境没有混淆
[ ] 置信度达到 80%
```

低于 80% 时只输出候选，不生成关系链。

## 7. 当前硬规则

### xz

- 不能只靠暗色、破损、怪物造型判断。
- 必须检查危险显身、异质逼近、边界失稳和临界行动。
- 视觉 xz 不自动等于人物本体 xz。

### nx

- 纯 nx 不是“主动牺牲自己维持关系”。
- 纯 nx 是不主动占据选择、方向和位置，顺着已有安排继续。
- 维持关系只是表现之一，也可能顺着群体、流程、安全和环境运转。
- `z 克 nx` 已确认：z 持续决定和占位，nx 不抢回位置，最后把自己让没。
- “龟男、老好人、受气包、把自己让没”优先作为 `z 克 nx` 的社会形态，不等于纯 nx 全定义。

### 旧暗算 / 看牌 / 结算

- 不再作为纯 nx 主骨。
- 记录、等待、顺序累积、到节点处理，转入 xn 候选池。
- 主动翻牌、推进、切断和执行清算，另查 zx。
- 不能批量把旧 `zx + nx` 直接改成 `zx + xn`，必须逐案复判。

## 8. 流行词与图像

- 流行词用于召回社会脚本，不直接代替判定。
- 图像适合外显原型；关系型和低主动型十元必须补连续行为过程。
- 单张气质图只能提供视觉映射，不能直接确定人物本体。

## 9. 三元接口

三元构成尚未正式锁定的部分，统一标注“待三元表校验”，不得根据字母排列或感觉词自行补理论。

下一阶段：

```text
x / z / n 三元判定卡
→ 三元到十元构成表
→ xn 准度卡
→ nx vs xn 最小差异盲测
```

## 10. 验收指标

```text
三元判断准确率 ≥ 90%
对象层级判断准确率 ≥ 90%
十元相邻类型准确率 ≥ 80%
主副与体量判断准确率 ≥ 75%
```

达到门槛后，再将准度卡接入生克补和动态链自动化。
