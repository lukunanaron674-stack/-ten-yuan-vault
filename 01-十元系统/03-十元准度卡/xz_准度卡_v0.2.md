# xz 准度卡 v0.2

> **xz = 危险已经以可感知方式显身，并具有逼近、扩张、包围或压缩安全距离的运动势能，使可逆空间、退路或时间窗持续下降。**

## 1. 先分对象

- **人物本体 xz**：长期以危险距离、退路、安全窗口和不可逆损失作为主要坐标。
- **当前状态 xz**：某阶段被推入危险逼近与安全边界收窄。
- **行为 xz**：逃离、追逐、抢窗口、临界选择，是高显影但不是必要条件。
- **场域 xz**：危险能到达主体，安全距离、路线或时间正在减少。
- **视觉 xz**：切线、逆光、边缘、速度、断桥、门缝只作辅助证据。

单个危险场景不等于人物本体是`xz`。

## 2. 必要条件

判断纯`xz`端点，以下三项不可缺：

1. **危险可感知**：威胁已经有可识别来源、事件、路径或不可逆损失对象。
2. **危险有运动势能**：正在接近、扩张、包围、追踪、传播或压缩安全距离；不是静止背景。
3. **安全边界下降**：可用路线、时间窗、退路、可逆性或稳定停留可能性正在减少。

可选高显影：

- 必须立刻移动；
- 抢最后窗口；
- 在两个坏选项中临界选择；
- 追逐、逃亡、越界、断后；
- 站着不动，但危险本身持续逼近并冻结行动。

```text
危险已显身
+ 具有运动势能
+ 安全距离或可逆空间持续下降
= xz 强候选
```

**临界行动不是必要条件。** 主体可以冷静、僵住、昏迷或尚未察觉；只要危险运动和边界压缩真实发生，场域或关系层`xz`仍可成立。

## 3. 非充分条件

以下不能单判`xz`：

- 暗色、雨夜、废墟、冷色和逆光；
- 怪物造型、疯笑、危险女性服装；
- 死亡、悲惨、不幸、孤独；
- 打斗激烈、角色跑得快；
- 被动卷入、不是自己选择；
- 时间流逝、寿命差、来得太晚；
- 站在悬崖、屋顶、轨道旁；
- 单纯不可逆结果已经发生。

它们必须真实承担“危险运动势能 + 安全边界下降”的功能。

## 4. 最近邻

### xz vs x

```text
xz：危险正在逼近，安全距离与可逆空间下降。
x：对象、资源、权限或关系进入某主体的掌握边界。
```

黑暗、吞噬、占有与生死题材不能替代端点。

### xz vs zx

```text
xz：行动被危险与最后窗口推动。
zx：主体主动把权能公开推入现实、扩大并压过对象。
```

拿掉危险后仍会为了扩权或目标冲过去，优先检查`zx`。

### xz vs xn

```text
xn：主动组织时间、路线、记录、规则与节点。
xz：这些结构或其他危险使安全路线与时间窗缩窄后的临界。
```

倒计时、制度和追踪系统是源或场景，不自动等于目标`xz`已成立。

### xz vs nx

```text
nx：方向不是我定，我沿既有安排推进。
xz：危险正在减少可选方向与安全窗口。
```

被推着走、被安排和被卷入不能直接判危险逼近。

### xz vs nz

```text
xz：可能失去、错过或无法返回的风险。
nz：值得返回、能够停靠并修复的对象特异关系。
```

温暖与危险同框不自动构成补位。

## 5. 拿掉测试

依次拿掉：

1. 冷色、破损、速度和惊恐表情；
2. 主体的逃跑或临界行动；
3. 怪物外形，只保留其实际到达路径；
4. 倒计时文字，只保留真实时间窗；
5. “命运”“来不及”等台词。

若仍能证明危险在运动，安全距离、退路或时间窗持续下降，`xz`成立。若拿掉行动后危险结构也消失，原判可能只是动作皮肤。

## 6. 反向测试

- 危险停止接近，路线与时间恢复，紧迫度下降：支持`xz`。
- 主体不行动，但追踪、传播、包围或崩塌仍推进：`xz`仍可成立。
- 只有静止死亡事实，没有新的逼近与窗口变化：不应主判动态`xz`。
- 只有被别人安排、无法自主选择：优先检查`nx/xn/zx/x`。
- 只有情感来得太晚，但没有可观察的失去窗口变化：最多是时间关系或`nz`材料。

## 7. 人物本体测试

人物本体不能靠一次追杀。必须检查：

```text
危险消失后，人物是否仍长期以出口、距离、退路和下一窗口组织生活？
这种结构是否跨对象、跨阶段复现？
是人物稳定选择方式，还是创伤状态、职业训练或场景要求？
```

若只在一次事件中成立，应标为`xz状态 / 场域 / 行为`。

## 8. 六项评分

```text
object_layer：人物、状态、行为和场域是否分开。
endpoint_fit：危险可感知、运动势能、安全边界下降三项是否成立。
neighbor_exclusion：x、zx、xn、nx、nz是否排除。
evidence_independence：危险来源、运动和边界变化是否为独立证据。
removal_reverse：拿掉行动与视觉后是否仍成立；危险解除后是否下降。
cross_context：人物本体是否跨场景复现，或场域结论是否只绑定当前阶段。
```

最终分数取六项最小值。

## 9. 关系接口

本卡只确认`xz`端点，不自行锁定：

```text
xn 生 xz
xz 生 zx
n 克 xz
xz 克 zn
xz ↔ nz（补）
```

正式机制必须查`十元生补克表`与关系专项索引。

## 10. 召回版

```text
xz不是“看起来危险”。
xz = 危险可感知 + 危险具有运动势能 + 安全距离、退路或时间窗持续下降。
临界行动是高显影，不是必要条件。
```
