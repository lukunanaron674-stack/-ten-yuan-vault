# xz视觉狭义定义

## 核心

xz = 火药桶。

不是已经挥出的刀，而是危险能量已经积累，存在明确触发点，一旦触发会导致整体爆发。

```text
危险蓄积(x)
+
触发节点(z)
=
xz
```

## 与x区别

x = 刀。

- 锐利
- 切割
- 直接伤害
- 危险物品本体

xz = 火药桶。

- 内部压力
- 临界状态
- 触发后整体释放
- 危险不是局部，而是系统性爆发

## 与zx区别

zx = 主动释放力量。
xz = 等待触发后爆发。

## 视觉形态

本征形：

- 长三角
- 长楔形
- 尖端结构

几何：

宽主体 + 长轴延伸 + 收尖触发点

## 发型视觉

成立条件：

- 厚重主体
- 长方向延伸
- 明确尖端
- 整体存在蓄力感

不成立：

- 碎发
- 乱发
- 羽化
- 普通层次

## 发型关键词

long pointed bangs
sharp long fringe
long wedge bangs
asymmetric pointed fringe

## 最近邻

x：短三角，刀刃
xz：长三角，火药桶
zx：主动外推，攻击释放
