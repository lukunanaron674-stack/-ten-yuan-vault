# nx 准度卡 v0.1

> **纯 nx = 为了维持关系、气氛或日常运转，持续压低自己的需求、意见和边界，最后把自己的位置让没。**

## 1. 判断对象

先区分：

- **nx 人物本体**：长期通过退让、吞咽和自我缩小维持关系或日常。
- **nx 状态**：某阶段因压力而暂时不敢表达。
- **nx 行为**：这一次先道歉、忍住、让步、装没事。
- **nx 场域**：一个人的边界被群体、关系或流程持续吃掉。
- **nx 结果**：主体位置变小、自我感变薄、别人的后果落到自己身上。

一次让步不能直接判人物本体是 nx。

## 2. 必要条件

判为纯 nx，以下五项至少满足四项，并且第 1、2、4 项不可缺：

1. **自己原本有东西可让**：需求、意见、不舒服、边界、选择或身份位置真实存在。
2. **主动压掉自己**：没有表达、没有拒绝、先吞下去、把自己排到后面。
3. **维持对象存在**：为了关系不破、气氛不坏、别人不失望、流程继续或避免被排斥。
4. **重复性成立**：不是一次策略，而是反复形成的惯性。
5. **主体位置缩小**：最后别人越来越习惯越界，而他越来越难说“不”。

### 最短公式

```text
我本来不愿意
+ 我怕关系 / 气氛 / 日常断掉
+ 所以我先把自己压掉
+ 这种事不断重复
= 纯 nx 强候选
```

## 3. 非充分条件

以下特征不能单独判 nx：

- 沉默、内向、社恐
- 冷静、克制、面无表情
- 善良、温柔、愿意帮忙
- 职员、普通人、小透明造型
- 忍耐、服从、排队、低头
- 聪明、看穿、会算计、记仇
- 暗室、档案、监控、赌桌

尤其注意：**“暗算 / 看牌 / 结算 / 翻底牌”不再是纯 nx 的主骨。**这些旧材料保留，但必须重新判为复合、异化或其他十元行为。

## 4. 第一体感

> **他不是没有意见。他先判断：说出来会不会把关系弄坏。然后又一次说了“算了”。**

nx 的痛点不是“没人理解我”，而是：

> **为了让一切继续，自己变成了最方便被删掉的那一项。**

## 5. 最小差异对子

### nx vs nz

| 检查项 | nx | 更偏 nz |
|:------|:---|:--------|
| 为什么帮助 | 怕拒绝后关系断裂或对方失望 | 主动想承接、照料或让对方停靠 |
| 自己的位置 | 越帮越薄 | 可以照顾别人，同时仍保留自己 |
| 核心动作 | 压掉自己 | 接住对方 |

**最小差异：**问一句“即使拒绝不会破坏关系，他还愿意做吗？”若仍主动愿意承接，需优先检查 nz；若主要是因为不敢拒绝，nx 上升。

### nx vs n

| 检查项 | nx | 更偏 n |
|:------|:---|:-------|
| 承担来源 | 不敢拒绝，别人不断塞过来 | 主动作为容器接住事情 |
| 边界变化 | 自己被磨薄 | 承载能力成为结构中心 |
| 压力结果 | 自我消失 | 负担加重但主体仍在 |

**最小差异：**承担很重不等于 nx。要看“接住”还是“没能拒绝”。

### nx vs xn

| 检查项 | nx | 更偏 xn |
|:------|:---|:--------|
| 为什么服从 | 怕冲突、怕失望、习惯退让 | 规则、时间、职责或秩序要求 |
| 是否有明确框架 | 常是人际与气氛压力 | 常有制度、流程和边界线 |
| 自己的位置 | 被关系吃掉 | 被规则安排，但不一定失去主体 |

**最小差异：**若规则取消后仍不敢拒绝具体的人，nx 仍成立；若规则取消后会自然停止服从，应优先检查 xn。

### nx vs z

| 检查项 | nx | 更偏 z |
|:------|:---|:-------|
| 自我方向 | 不断后撤 | 有想显现、坚持或追向的线 |
| 面对压制 | 先吞、先算了 | 即使受压仍会留下方向痕迹 |
| 结果 | 自己让没 | 自己仍想被看见或抵达 |

**最小差异：**只要人物还明确保留“一条不能让的线”，就不应轻易判纯 nx，需检查 nx + z 或其他结构。

### nx vs zx

| 检查项 | nx | 更偏 zx |
|:------|:---|:--------|
| 忍耐性质 | 真的把自己压掉 | 为后续破局、推进或出手暂时压住 |
| 是否等待时机 | 不一定有反击计划 | 常有明确下一步 |
| 最终方向 | 继续维持 | 打开路径、作出选择 |

**最小差异：**如果“忍”是为了最后出手，那不是纯 nx 的自我消失，而是策略性蓄力。

## 6. 流行词入口

这些词对召回有效，但仍需检查必要条件：

- 龟男
- 老好人
- 受气包
- 讨好型人格
- 工具人
- 班级小透明
- 永远说“都行”的人
- 被默认懂事的人
- 关系里的缓冲垫
- 总替别人收拾残局的人

流行词的价值在于它们带着完整社会脚本，不在于词本身等于 nx。

## 7. 连续行为脚本

nx 更适合用过程判，而不是靠一张立绘判。

```text
第一步：别人提出让他不舒服的要求
第二步：他意识到自己不愿意
第三步：他先判断拒绝会不会让对方不高兴
第四步：他说“没事”“都行”“我来吧”
第五步：对方把这次退让当成默认规则
第六步：下一次要求更过分
第七步：他越来越说不出自己的需要
```

若只有“低头、沉默、坐角落”而没有这条过程链，视觉证据不足。

## 8. 人物准度检查

判人物本体为 nx 时，至少回答：

```text
他在谁面前最容易失去边界？
他具体吞掉过什么需求？
他害怕什么后果，所以不敢拒绝？
这种退让发生过几次？
别人是否已经把他的退让当成默认？
没有外部压力时，他是否仍习惯把自己放最后？
```

答不出具体关系和重复过程，只能判“nx 候选”或“nx 状态”。

## 9. 视觉准度检查

### 可用视觉方式

- 同一人物的三至四格连续关系过程
- 别人手里的东西逐渐堆到他身上
- 座位、构图空间、说话位置逐渐被挤小
- 每次想开口又停住
- 对方越界后，他先替对方找理由
- 最后一格人物仍在做事，但自己的物品或位置已经消失

### 不足以定型的单图

- 冷灰色小职员
- 雨天转学生
- 低头通勤者
- 档案室助理
- 疲惫优等生

这些可以作为血肉，但必须补“为什么不拒绝”和“如何逐步让没”的过程。

## 10. 反例

### 反例 A：潜伏者忍辱负重

他暂时低头，是为了等待明确时机完成任务。主体方向和计划都在，不是纯 nx。

### 反例 B：照顾生病朋友

她主动愿意照料，也能表达疲惫并要求休息。关系没有吞掉她的边界，不应仅凭温柔判 nx。

### 反例 C：严格服从制度的工作人员

他按流程做事是因为职责与规则，不是害怕某个人失望。需优先检查规则结构。

### 反例 D：沉默的复仇者

他把每件事记下，等待最后翻牌。旧库可能标为 nx，但新口径下必须检查其目标、结算、欲望和行动成分，不再自动判纯 nx。

## 11. 边界例

### 边界 A：懂事的孩子

- 因为知道父母辛苦，主动少提要求：可能有承接成分。
- 因为一提要求就会被责怪，所以彻底不敢需要：nx 上升。

### 边界 B：职场老好人

- 偶尔帮同事一次：证据不足。
- 每次都接活，怕拒绝被排挤，自己的工作不断拖延：nx 强。

### 边界 C：忍到最后反击

反击发生不等于此前一定是纯 nx。要回看：此前是真的失去自己，还是一直在等待行动窗口。

## 12. 旧口径迁移

| 旧材料 | 新处理 |
|:------|:-------|
| 暗算、看牌、记账 | 保留为历史血肉，重新判复合或异化结构 |
| 结算、清算、翻底牌 | 不再作为纯 nx 必要条件 |
| 分析师、军师、检察官 | 不能只凭职业判 nx |
| 暗室、监控室、档案柜 | 只能作为视觉 / 场景辅助 |
| “聪明但不表态” | 必须追问他为什么不表态 |

**迁移原则：保留旧材料，不删除；取消其“纯 nx 锚点”资格。**

## 13. 判定评分

| 项目 | 分数 |
|:----|:---:|
| 有真实需求 / 边界可让 | 0-2 |
| 主动压掉自己 | 0-2 |
| 维持关系 / 气氛动机 | 0-2 |
| 重复形成惯性 | 0-2 |
| 主体位置持续缩小 | 0-1 |
| 相邻十元排除完成 | 0-1 |

```text
8-10：纯 nx 强判
6-7：nx 主或 nx 状态，需补关系材料
4-5：只有外观或单次行为
0-3：不应主判 nx
```
