# zx视觉狭义卡 v0.1

## 1｜核心定义

> **zx 是力量已经主动推出并占据方向的视觉结构。**

最短召回：

```text
zx＝挥出的刀
```

它不是“看起来锋利”就够了，而是轮廓自身产生方向，把视线、发束或力量推向外部结果。

## 2｜发型形状

发型领域中的本征形：

```text
菱形
中部展开、两端收束
由根部主动起势并向外推出的方向结构
```

典型显影：

- 根部主动抬起、上挑或后冲；
- 发束向一侧强斜扫；
- 中段展开并形成推进体量；
- 末端仍有明确方向；
- 轮廓不是被风偶然吹动，而是造型本身就在行动。

## 3｜必要视觉证据

1. 有清楚的起势点；
2. 力量从内部向外推出；
3. 发束占据一个最终方向；
4. 中部展开或形成可读的推进体量；
5. 拿掉主动方向后，zx感明显下降。

## 4｜发型候选

- 强斜扫刘海；
- 外翻层次；
- 上挑前发；
- 明显后梳；
- 莫霍克脊线；
- 高马尾中由束点主动推出的轮廓。

## 5｜最近邻

### zx vs x

```text
x：危险物品本身，像静止的刀。
zx：力量已经主动推出，像挥出的刀。
```

尖锐不等于主动。只有方向由结构自身生成并进入外部，才支持zx。

### zx vs xz

```text
zx：力量正在主动释放和占据方向。
xz：火药桶式危险蓄积，对触发点敏感，但尚未主动释放。
```

### zx vs nx

```text
zx：自己决定并占据最终方向。
nx：散开或沿已有通道让位，不争夺最终方向。
```

### zx vs xn

```text
zx：单向推出和行动性。
xn：规则分布到多个节点，以重复与秩序维持整体。
```

## 6｜拿掉测试

```text
拿掉主动起势，只剩尖锐形状 → 检查x。
拿掉向外推出，只剩内部高压和触发敏感 → 检查xz。
把方向拆散成横向多束、没有主导结果 → 检查nx。
把力量改成均匀重复和对称运行 → 检查xn。
```

## 7｜禁止误判

以下不能单判zx：

- 风把头发吹向一边；
- 人物正在跑；
- 发型只是斜；
- 有一根尖发；
- 轮廓看起来很酷。

必须证明发型结构自身生成并占据方向。
