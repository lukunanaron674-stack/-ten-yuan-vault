# 十元准度卡总控 v0.5

> 信息卡回答“它是什么”；准度卡回答“为什么这个对象必须判成它”；生克补卡回答“两个端点之间怎样发生关系”。

## 1. 固定流程

```text
明确判断对象
→ 分稳定本体 / 状态 / 行为 / 场景 / 光影 / 时间关系 / 关系位置 / 显影 / 动态链
→ 读取现行信息卡
→ 列出至少两个最近邻
→ 做必要条件、拿掉测试与反向测试
→ 输出候选与六项置信度
→ 端点稳定后才允许进入生克补
```

三元与十元并行核验，不写成父子派生。三元负责比例、质地和观看方式；十元负责对象在关系网络中的位置。

## 3. 六项置信度

每次判定分别记录：

1. `object_layer`：判断对象与层级是否清楚；
2. `endpoint_fit`：必要条件与核心变量是否成立；
3. `neighbor_exclusion`：最近邻是否真正排除；
4. `evidence_independence`：证据是否独立，是否只是同一事实换词；
5. `removal_reverse`：拿掉与反向测试是否通过；
6. `cross_context`：是否跨阶段、跨场景或跨对象复现。

最终置信度取六项最小值，不取平均数。

统一刻度：

```text
95–100：对象层明确；必要条件完整；至少两组独立证据；最近邻无存活解释；拿掉与反向通过；跨情境复现。
90–94：主判稳定，但仍缺一个关键控制或边界。
80–89：强候选；仍混有第三因素、状态层或相邻类型。
60–79：主要是共现、先后、行为、视觉或场景相似。
0–59：端点或方向不稳定，不应主判。
```

强制封顶：

- 层级混淆：`object_layer ≤ 79`；
- 只有视觉或题材证据：`endpoint_fit ≤ 59`；
- 最近邻仍能解释主要变化：`neighbor_exclusion ≤ 79`；
- 只有一个事实反复换词：`evidence_independence ≤ 69`；
- 拿掉核心条件后仍成立或反向不恢复：`removal_reverse ≤ 79`；
- 只在单一阶段成立却判人物本体：`cross_context ≤ 79`。

## 4. 三个不同门槛

```text
80%：允许进入十元强候选，但不得自动生成关系链。
90%：允许作为当前对象层的稳定工作判定，仍必须保留最近邻边界。
95%：才允许作为正式端点进入关系锁定或正本修正。
```

“95%助手可自主执行”是工程门槛；“95%端点或关系锁定”是理论门槛，两者不得混成一个数字。

## 6. 禁止事项

- 不得用角色名、职业、服装、光色或题材直接替代十元。
- 不得用人物成长解释主副十元被替换；优先检查显影、策略、关系和能力变化。
- 不得把一次行为升级为稳定人物本体。
- 不得把旧关系机制写进准度卡当作十元定义。
- `z 克 nx`当前仍是几何位置保留、机制未锁定；旧“z持续决定和占位，把nx让没”不得继续调用。
- `xz`的临界行动是高显影，不是必要条件；危险运动势能与安全边界收窄才是核心。
