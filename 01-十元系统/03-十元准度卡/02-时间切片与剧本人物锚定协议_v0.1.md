# 时间切片与剧本人物锚定协议 v0.2

## 1. 总原则

> **现实判断中，一个人在不同时间点的定义感和第一体感会变化；故事和剧本中，为了角色清晰，人物本体组合应保持稳定。**

时间变化首先解释为：

- 状态变化。
- 行为变化。
- 关系变化。
- 环境作用。
- 当前观察方式变化。
- 主元与副元在当前场景中的显隐变化。

不得一看到变化，就重写人物本体。

## 2. 现实时间切片

现实人物在一个具体时间点，通常只有一种观察方式占主导：

```text
x：聚焦具体物象与局部因果
z：关注认可与精神确认
n：观察精神、整体与多方关系
```

同一个人可以在不同时间、不同对象上切换，但每个时间切片仍应判断当前主导方式。

跨时间、跨对象的切换，不代表人物每次都变成另一个固定类型。

## 3. 剧本人物锚

每个主要人物在一部作品中，应设置一个稳定的 **人物本体锚**：

```text
主十元
+ 副十元
+ 稳定核心对象
+ 稳定选择方式
+ 稳定关系方式
```

例如：

```text
人物锚：xz + nz
```

无论经历什么压力，人物仍是 `xz+nz`，不会因为某场戏只显出 xz，就被改判成纯 xz。

人物锚回答：

```text
不管事件怎么变，他最终会以哪一种固定组合重新面对世界？
```

## 4. 主元与副元都保持稳定

标准剧本中：

- 主元不因成长而更换。
- 副元不因成长而消失。
- 主副顺序不因一场戏而颠倒。
- 不同压力只会让组合中的某一面更显眼。

```text
xz+nz
→ 在危险压力下更显 xz
→ 在停留、守望或关系压力下更显 nz
→ 仍然是同一个 xz+nz 人物
```

副元不是装饰。即使第一体感相同，少量副元也可能彻底改变人物的性格、喜好与关系方式。

## 5. 人物成长：暴露本性，而不是更换本性

人物成长通常是：

```text
稳定人物锚
→ 进入不同环境和关系
→ 本来就存在的侧面逐渐显露
→ 局限被看见
→ 行为、关系、能力与自我认识改变
→ 更完整地暴露并使用原本本性
```

因此，人物成长可以改变：

- 行为策略。
- 与他人的关系。
- 能力和经验。
- 对自己的认识。
- 同一主副组合的成熟程度。
- 主元与副元在不同场景中的显影强弱。

人物成长默认不改变：

- 主十元。
- 副十元。
- 核心组合。
- 最底层选择方式。

> **角色弧光不是换人格，而是让原来的人被看得更完整。**

## 6. 环境与关系承担变化

好的角色弧光通常是：

```text
稳定本体组合
→ 被环境与关系克制 / 激活 / 补全
→ 原本结构暴露局限
→ 学会新的行为或关系方式
→ 仍以原本组合完成更成熟的选择
```

例如：

```text
zn 人物
→ 进入 xz 环境
→ 出现 nx 状态
→ 采取 zx 行为
→ 最终仍以 zn 本体完成选择
```

这不等于人物依次变成 xz、nx、zx。

## 7. 特殊的人格重构

只有用户或作品明确把“成为另一个人”作为核心命题时，才讨论人物锚更换。

此时不能把它当作普通成长，应另立：

```text
前期人物锚
→ 人格断裂 / 重构事件
→ 后期人物锚
```

没有明确证据时，禁止自动使用这条例外。

## 8. 场景级输出

```text
【稳定人物锚】
主十元：
副十元：

【当前时间切片】
【当前对象】
【当前状态】
【当前行为】
【环境 / 关系作用】
【本轮显影】主元 / 副元 / 两者关系
【人物成长】暴露了哪一部分本性
【本体是否改变】通常为否
```

## 9. 编剧规则

- 主角的主副组合尽量稳定。
- 场景变化用于展示同一本体在不同压力下的侧面。
- 副元可以分阶段显影，但不能无故消失或被替换。
- 视觉、动作和情绪可以变化很大，核心选择方式仍应可识别。
- 人物成长优先写成暴露本性、学会新的关系与行为，而不是作者突然换一套人格说明书。

## 10. 最短封存句

> **现实里，人会随时间和对象切换主导方式；剧本里，主副人物锚保持稳定，成长负责暴露本性。**
