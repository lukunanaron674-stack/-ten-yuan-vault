# 时间切片与剧本人物锚定协议 v0.1

## 1. 总原则

> **现实判断中，一个人在不同时间点的定义与第一体感会变化；故事和剧本中，为了角色清晰，人物本体最好保持稳定。**

时间变化首先解释为：

- 状态变化
- 行为变化
- 关系变化
- 环境作用
- 三元镜头切换
- 主副比例在当前场景中的显隐变化

不得一看到变化，就重写人物本体。

## 2. 现实时间切片

现实人物在一个具体时间点，主要只能使用一种占主导的观察方式：

```text
x 镜头：聚焦具体物象与局部因果
z 镜头：确认主观能力、改变与认可
n 镜头：观察更大区域与整体关系
```

同一个人可以：

- 在技术问题上使用 x 镜头。
- 在获得认可与权能扩张时使用 z 镜头。
- 在家国、历史或人际整体上使用 n 镜头。

跨时间、跨对象的切换，不代表人物每次都变成另一个固定类型。

## 3. 剧本人物锚

每个主要人物在一部作品中，应设置一个稳定的 **人物本体锚**：

```text
人物本体十元
+ 主三元质地
+ 稳定核心对象
+ 稳定选择方式
+ 稳定关系方式
```

人物锚回答：

```text
不管事件怎么变，他最终总会用哪种方式重新面对世界？
```

## 4. 角色弧光不是频繁换本体

好的角色弧光通常是：

```text
稳定本体
→ 被环境与关系克制 / 激活 / 补全
→ 原本结构暴露出局限
→ 学会调用新的能力或关系
→ 仍以原本本体完成更成熟的选择
```

例如：

```text
zn 人物
→ 进入 xz 环境
→ 出现 nx 状态
→ 采取 zx 行为
→ 最终以被补厚的 zn 完成选择
```

这不等于人物依次“变成”x​z、nx、zx。

## 5. 允许人物本体改变的特殊情况

只有作品核心明确描写人格、信念或主体结构重建时，才允许本体锚变化。

必须同时满足：

1. 改变是作品核心，而不是一场戏的情绪波动。
2. 有清晰的转折事件或长期累积过程。
3. 改变前后的人物选择方式发生稳定变化。
4. 后续多个场景证明新结构能够持续。
5. 输出中明确标记“前锚 / 转化桥 / 后锚”。

格式：

```text
前期人物锚：
转化压力：
关键选择：
转化桥：
后期人物锚：
验证场景：
```

## 6. 场景级输出

分析单场戏时，应写：

```text
【稳定人物锚】
【当前时间切片】
【当前对象】
【当前状态】
【当前行为】
【环境 / 关系作用】
【本体是否改变】通常为否
```

## 7. 编剧规则

- 主角本体锚尽量稳定。
- 场景变化用于展示本体在不同压力下的侧面。
- 副元可以在不同段落显影，但不能没有结构原因地抢走主锚。
- 视觉、动作和情绪可以变化很大，核心选择方式仍应可识别。
- 人物最终变化应表现为“同一个人学会新的关系”，而不是作者突然换了一套人格说明书。

## 8. 最短封存句

> **现实里，人随时间和对象切换镜头；剧本里，角色最好守住本体锚，让状态和关系去变化。**
