# xz 准度卡 v0.3

> **xz＝火药桶式危险结构：整体危险已经蓄积，对局部触发高度敏感；一点可能牵动全局，引发整体爆发、扩散、失控或不可逆转化。**

## 1｜先分对象

- **人物本体xz**：跨情境长期维持“高压蓄积＋触发敏感＋整体爆发”的稳定结构；
- **当前状态xz**：某阶段进入火药桶临界，但不代表人物本体恒定如此；
- **场域xz**：系统中风险耦合，一个局部事件可能引发全局连锁；
- **行为xz**：点燃、越界、揭露、触碰底线等只是触发行为，不是xz本体；
- **视觉xz**：长三角、长楔形、厚主体＋引信式尖端，必须回到视觉狭义卡核验。

## 2｜必要条件

判断纯xz端点，以下三项不可缺：

1. **整体危险蓄积**：危险储存在对象、关系、系统或场域整体中，而非只有一个局部刀口；
2. **触发高度敏感**：一个小事件、节点或接触可能改变全局状态；
3. **局部牵动全局**：触发后出现系统级爆发、扩散、失控、崩解或不可逆转化。

辅助条件：

- 爆发前可以平静、静止、克制；
- 压力或风险具有累积历史；
- 一旦释放，低成本恢复原状困难。

```text
整体危险蓄积
＋触发高度敏感
＋一点牵动全局
＝xz强候选
```

## 3｜旧动态定义的降级

以下仍可作为xz动态显影，但不再是必要本体：

- 危险逼近、扩张、包围；
- 安全距离、退路、时间窗减少；
- 追逐、逃亡、抢最后窗口；
- 危险传播和空间压缩。

只有当这些变化使系统成为“一个点就能引发全局爆发”的火药桶结构时，才支持高准度xz。

## 4｜非充分条件

- 看起来危险、阴暗、疯癫；
- 一把刀或单一尖刺；
- 单纯愤怒和一次爆发；
- 倒计时、追逐、来不及；
- 被动卷入、不是自己选择；
- 退路减少但系统没有整体蓄积；
- 碎、乱、羽化、多方向视觉；
- 局部事故但无全局连锁。

## 5｜最近邻

### xz vs x

```text
x：刀。危险来自锐利、切割和直接伤害边界。
xz：火药桶。危险储存在整体中，一点可能引爆全局。
```

### xz vs zx

```text
xz：爆发前临界蓄积，等待或遭遇触发。
zx：力量已经主动推出并占据现实方向。
```

### xz vs z

```text
z：节点、截点、长度或单一裁定点。
xz：该节点能点燃已经存在的整体危险结构。
```

### xz vs nx

```text
nx：让位、顺流、散开或沿既有通道推进。
xz：整体危险蓄积，对触发高度敏感，可能系统级爆发。
```

### xz vs nz

```text
xz：临界爆发、扩散、失控、难以回收。
nz：保存、停靠、修复、重建回返空间。
```

### xz vs xn

```text
xn：规则和节点网络维持运行。
xz：节点网络内部已蓄积危险，一个局部节点可能使全局失控。
```

## 6｜拿掉测试

依次拿掉：

1. 危险题材、冷色、破损与表情；
2. 单次爆发行为；
3. 追逐、倒计时与退路减少；
4. 局部尖刺或刀口；
5. 触发点；
6. 整体压力与连锁机制。

若拿掉表面后仍能证明“整体蓄积＋触发敏感＋一点牵动全局”，xz成立。

## 7｜反向测试

- 降低整体压力后，微小刺激不再引发全局变化：支持xz；
- 移除触发节点后，系统恢复稳定：支持xz；
- 触发后只产生局部伤害：更接近x；
- 不需触发就主动持续外推：更接近zx；
- 爆发后可低成本完整恢复：xz纯度下降；
- 只有危险逼近，没有火药桶结构：不能高判纯xz。

## 8｜人物本体测试

```text
危险消失后，人物是否仍长期积累高压并围绕触发底线组织生活？
微小事件是否反复牵动其整体关系、身份或行为结构？
爆发是否具有系统级后果，而非普通发火？
这种结构是否跨对象、跨阶段复现？
```

只在一次事件中成立，应标为`xz状态／场域`。

## 9｜视觉层接口

视觉判断必须读取[[xz_视觉狭义卡_v0.2]]：

```text
x＝三角／刀。
xz＝长三角／火药桶。
zx＝菱形／挥出的刀。
```

长三角只是形状候选。没有整体蓄积与触发敏感，不得高判xz。

## 10｜六项评分

```text
object_layer：人物、状态、行为、场域、视觉是否分开。
endpoint_fit：蓄积、触发敏感、局部牵动全局是否成立。
neighbor_exclusion：x、zx、z、nx、nz、xn是否排除。
evidence_independence：整体压力、触发点、全局后果是否为独立证据。
removal_reverse：拿掉题材和行为后是否仍成立；减压或移除触发后是否下降。
cross_context：人物本体是否跨情境复现，或场域判断是否只绑定当前阶段。
```

最终分数取六项最小值。

强制封顶：

- 只有危险题材或视觉：≤59；
- 只有一次发火或爆发：≤69；
- 只有危险逼近和退路减少：≤79；
- 没有局部牵动全局机制：≤79；
- x、zx仍能解释主要变化：≤79；
- 单阶段却判人物本体：≤79。

## 11｜关系接口

```text
xn 生 xz
xz 生 zx
n 克 xz
xz 克 zn
xz ↔ nz（补）
```

旧关系卡中若以“危险逼近、退路收窄”作为唯一机制，必须重新审计；这些描述只能保留为xz子型或动态显影。

```text
x＝刀。
zx＝挥出的刀。
```
