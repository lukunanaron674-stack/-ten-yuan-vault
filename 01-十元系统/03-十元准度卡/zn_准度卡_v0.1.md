# zn 准度卡 v0.1

> **zn = 主体内部一项不可轻易让渡的意义或原则，拥有未来调用、冲突排序与最终指导选择的资格。**

## 必要条件

1. 原则命题或意义对象明确；
2. 主体认为它具有正确性或不可抛弃性；
3. 无奖励、认可与观看时仍进入判断；
4. 在冲突中影响排序与最终选择；
5. 跨阶段保留未来调用资格；
6. 主体能够说明边界、条件或让渡代价。

## 对象分层

- 人物本体：长期依靠不可让渡意义决定自己是谁。
- 状态：某原则当前高调用、暂停或被遮蔽。
- 行为：坚持、拒绝、牺牲与辩护只是显影。
- 关系：某对象被认定不可抛下或必须按某标准对待。
- 场景与视觉：教堂、旗帜、光、纪念碑只作辅助。

## 最近邻

```text
zn vs z：zn的指导资格来自内部；z需要重要认可主体确认。
zn vs xn：zn决定什么值得维护；xn组织怎样持续维护。
zn vs n：zn撤回抛弃资格；n让对象真实留在内部并持续处理。
zn vs zx：zn是原则与最终标准；zx是权能公开显现与扩大。
zn vs x：zn提供为什么守；x提供具体什么归我掌握。
zn vs nz：zn是原则归属；nz是关系停靠、回返与修复。
```

## 非充分条件

善良、正义、宗教、口号、固执、牺牲、孤独、发光、英雄行为、遵守规则，均不能单判`zn`。

## 拿掉测试

拿掉认可、奖励、群体许可、制度要求与当前利益，原则仍应进入判断。换到安全情境，检查未来调用资格是否保留。

## 反向测试

- 只因惩罚而遵守：检查`xn/xz/x`。
- 只在被赞美时坚持：检查`z`。
- 换策略、细化条件或暂停当前调用：不等于`zn`消失。
- 不同安全情境中仍认为原则正确且应进入判断：支持稳定`zn`。
- 会重复口号但不能在冲突中排序选择：证据不足。

## 六项评分

`object_layer / endpoint_fit / neighbor_exclusion / evidence_independence / removal_reverse / cross_context`分别评分，最终取最小值。
