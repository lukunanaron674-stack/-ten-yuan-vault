> 血肉卡回答“它能长成什么”；准度卡回答“为什么必须判成它”；关系卡回答“判定以后怎样生、克、补”。

## 1. 当前开发顺序

```text
判断对象
→ 十元初判
→ 三元比例与质地校验
→ 十元准度判定
→ 本体 / 状态 / 行为 / 环境 / 结果分层
```

三元与十元并列，不是“三元派生十元”。十元判位置，三元描述内部比例、质地与当前观看方式。

## 3. 对象分层

必须区分：

1. 人物本体。
2. 状态。
3. 行为。
4. 环境 / 场域。
5. 结果。
6. 光影、色彩、构图、空间、时间关系。

不同对象出现不同十元，不等于人物本体不断换标签。

## 4. 时间与剧本规则

现实分析中，一个人在不同时间点、不同对象上会切换主导方式。

故事和剧本中应保持稳定的人物锚：

```text
主十元
+ 副十元
+ 核心对象
+ 选择方式
+ 关系方式
```

例如 `xz+nz` 人物，在不同压力下可以分别显出 xz 或 nz 的一面，但始终是同一个组合。

人物成长默认改变：

- 行为策略。
- 与他人的关系。
- 能力、经验与自我认识。
- 主元和副元在不同场景中的显影强弱。

人物成长默认不改变：

- 主十元。
- 副十元。
- 核心组合。
- 最底层选择方式。

> **角色弧光优先解释为暴露本性，而不是替换本性。**

## 5. 判定闸门

```text
[ ] 判断对象已明确
[ ] 十元必要条件成立
[ ] 三元比例与质地已有证据
[ ] 相邻十元已排除
[ ] 本体 / 状态 / 行为 / 环境 / 视觉没有混淆
[ ] 人物主副锚与时间切片已经分开
[ ] 置信度达到 80%
```

低于 80% 时只输出候选，不生成关系链。

80% 是案例准度闸门；95% 是助手是否需要继续询问用户的执行阈值。

## 9. 当前硬规则

### z

- z 的核心是认可主体对精神个体的存在、能力、作品、选择或发现进行确认。
- 认可主体可以是个人、公众、已故对象、神、国家、历史、想象观众或自己。
- 学习规律、改变世界、成果显现和权能扩大的一整套过程，不再归 z 主骨。

### zx

- 对话中的“脏醒”是“张扬醒目”的语音误识别，正式符号是 zx。
- zx 可以表现为：学习客观规律 → 有效改变世界 → 成果显现与认可 → 能力与权能扩大。
- 不能说主观世界替代客观世界，只能说主体扩大改变客观世界的能力。
- 该补丁需与旧 zx 的目标、路径、执行、结果确认主骨进一步整合。

### x

- x 关注具体物象、物质关系、所有权、功能和局部因果。
- x 落到人物本体时，自私是稳定人物层结果。
- 自私不外推给 x 光影、场景或物件。

### n

- n 的核心是精神、整体与关系，并常表现为理解、包容和协调。
- 小 / 大只作为辅助体感，不是正式定义或等级。
- n 不天然要求小整体服从大整体。
- 此类取舍不是 n 的核心问题。

### xz

- xz 的核心是危险感本身具有运动势能。
- 人物不必行动，只要危险正在逼近、扩张或压缩安全距离，就可形成 xz。
- 临界行动不是必要条件。
- xz 是运动中的危险感；x 的生死感更像静止、干净、一瞬落点。

### nx

- 纯 nx 不是主动牺牲自己维持关系。
- 纯 nx 是不主动占据选择、方向和位置，顺着已有安排继续。
- `z 克 nx` 已确认：z 持续决定和占位，nx 不抢回位置，最后把自己让没。
