# zx 张扬醒目与权能扩张补丁 v0.2

## 1. 语音纠正

对话中出现的“脏醒”不是正式类型。

```text
脏醒（语音误识别）
=
张扬醒目
=
zx
```

不得根据“脏醒”另造 `z+x`、`z被x污染` 或其他异化概念。

## 2. zx 的层级锁定

### 本体核心

> **zx 的核心是张扬醒目与权能扩大。**

zx 关心的不只是把事情做完，而是主体的力量、能力、位置与影响在客观世界中不断显现、扩大并成立。

```text
主体形成自己的方向
→ 主观能力作用于客观世界
→ 结果被做出来、显现出来
→ 主体位置、能力与权能扩大
→ 能够继续作用于更大的对象
```

### 行为层

> **目标执行是 zx 的行为本身，不是 zx 的底层定义。**

```text
zx 本体：张扬醒目 / 权能扩大
zx 行为：目标执行 / 路径推进 / 做成结果
```

因此不能用“有目标、能执行”直接定义 zx，但 zx 在行动时，最典型的行为方式就是目标执行。

“目标执行只是常见行为”这一表述不够准确，应改为：

> **目标执行是 zx 的标准行为表达。**

## 3. zx 的运行过程

用户给出的具体过程：

```text
精神个体面对庞大的物质客观世界
→ 学习客观世界
→ 不断理解客观规律
→ 利用规律形成有效改变
→ 把发现、成果或改变显现出来
→ 自身能力、位置与权能扩大
→ 能够继续改变更大的部分
```

这里：

- 学习、理解规律，是主体获取可作用于世界的能力。
- 目标执行，是主体把能力变成实际结果的行为。
- 成果显现，是张扬醒目的外化。
- 权能扩大，是 zx 本体得到完成和继续生长。

## 4. 与 z 的区别

### z

```text
我的存在、能力、作品或发现
→ 是否被认可主体看见与确认
```

z 负责认可关系。

### zx

```text
我能够做成什么
→ 我的能力怎样在客观世界中显现
→ 我的实际作用范围怎样扩大
```

zx 不只是“有人认可我”，而是主体通过行动、结果和显现，使自己的权能真正扩大。

## 5. 客观世界边界

zx 不能被写成“主观世界替代客观世界”。

正确表述：

> **主体发现并利用客观规律，逐渐扩大自己改变客观世界的能力。**

- 客观世界仍然独立存在。
- 主体必须通过行动和结果使能力成立。
- 权能扩大表现为能改变更多、更复杂或更大的对象。
- 张扬醒目不是空喊，而是能力与结果已经显现。

## 6. 与旧 zx 卡的接口

旧 zx 卡中的以下内容继续保留，但重新分层：

### 保留为行为层

- 自定方向。
- 路径推进。
- 目标执行。
- 换路不换目标。
- 做成与结果确认。

### 上移为本体层

- 张扬醒目。
- 王权。

- 向上生长。

```text
张扬醒目与权能扩大（本体）
→ 通过目标执行与路径推进（行为）
→ 形成真实结果与外部显现（结果）
→ 权能继续扩大（本体回收）
```

## 7. 典型人物锚

> **朱元璋是用户确认的典型 zx 人物。**

该案例目前用于锁定 zx 的人物第一体感与本体方向：

```text
张扬醒目
+ 权能不断扩大
+ 通过目标执行把权能做成现实
= 典型 zx 人物锚
```

历史材料与具体事件另建人物血肉卡逐项验证，不在本补丁中凭印象补写。

## 8. 判定问题

```text
1. 主体的能力、位置或影响是否在扩大？
2. 这种扩大是否通过实际结果显现，而不是只靠宣言？
3. 主体采取的标准行为是否是目标执行与路径推进？
4. 去掉目标执行后，人物是否仍有明确的张扬醒目与权能扩张本体？
5. 只有执行功能、没有主体权能扩大时，是否只是行为像 zx？
6. 只有被认可、没有实际权能扩张时，是否更接近 z？
```

## 9. 最短封存句

> **zx 的本体是张扬醒目、权能扩大；目标执行是它把本体做成现实的标准行为。**
