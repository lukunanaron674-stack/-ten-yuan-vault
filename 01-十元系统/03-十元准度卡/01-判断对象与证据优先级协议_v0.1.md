# 判断对象与证据优先级协议 v0.1

## 1. 总原则

> **十元判定没有一套对所有对象都固定不变的证据优先级。先确定对象，再决定什么证据最重要。**

同一作品中，不同对象可以同时落在不同十元：

```text
人物本体：zn
人物状态：nx
光影场：xz
环境：xn
行为：zx
结果：n
```

这不是矛盾，而是对象层级不同。

## 2. 对象与优先证据

| 判断对象 | 第一优先 | 第二优先 | 低权重辅助 |
|:---------|:---------|:---------|:-----------|
| 人物本体 | 动机、长期选择、反复返回的发动结构 | 压力反应、牺牲对象、关系方式 | 外貌、单次动作、颜色 |
| 人物状态 | 当下注意对象、当下压力反应 | 情绪与临时选择 | 长期标签 |
| 行为 | 这次行为的直接功能与方向 | 谁先动、作用到谁 | 人物平时性格 |
| 单张插画 | 光影、颜色、氛围、构图、空间运动 | 姿态、视线、物件关系 | 无叙事证据的人物动机猜测 |
| 角色设计 | 第一体感、造型重心、身份与关系姿态 | 表情、动作、材质、色彩 | 编造出来的背景故事 |
| 场景 | 空间尺度、容纳方式、压迫或开放方向 | 光线、路径、物件分布 | 场景中某个小角色的性格 |
| 漫画 / 电影 | 时间点变化、镜头关系、事件转折 | 人物动机与关系运动 | 单帧孤立气质 |
| 音乐 | 能量方向、节奏、结构落点与段落变化 | 音色、旋律、和声关系 | 单个乐器或单句歌词 |
| 文字概念 | 概念实际指向的对象与关系 | 使用语境、边界与反例 | 字面关键词 |

## 3. 人物本体判定

人物本体必须优先回答：

```text
他真正想保住什么？
他反复把选择权放在哪里？
压力来临时，他最先牺牲什么？
哪一种方式在不同事件中不断回来？
```

一次行为不能直接覆盖人物本体。

## 4. 单张插画判定

单张插画没有完整时间过程，因此不得强行推断人物长期动机。

应优先判断：

```text
视觉映射十元
光影十元
构图十元
空间十元
人物姿态十元
画面中的关系方向
```

例如：

```text
人物本体可能是 zn
但使用 xz 光影、危险空间和逼近构图
→ 画面表达的是 xz 正在作用于 zn
```

## 5. 漫画与电影判定

漫画、电影的关键是时间点变化：

```text
前一时间点的稳定状态
→ 外力或关系进入
→ 人物如何回应
→ 新状态与结果
```

但不得因为每个镜头状态不同，就不断改写人物本体。

## 6. 视觉与本体分离输出

视觉作品至少输出：

```text
【人物本体】
【人物当下状态】
【光影 / 色彩】
【空间 / 环境】
【关系表达】
【综合第一体感】
```

## 7. 关键词限制

- 冷静不自动等于 x。
- 温柔不自动等于 n。
- 显眼不自动等于 z。
- 危险造型不自动等于人物本体 xz。
- 规则服装不自动等于人物本体 xn。
- 单次退让不自动等于人物本体 nx。

## 8. 最短执行句

> **人看动机，画看视觉关系，电影看时间运动，概念看实际对象。**
