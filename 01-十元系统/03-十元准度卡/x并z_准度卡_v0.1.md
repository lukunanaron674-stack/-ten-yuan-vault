# x并z 准度卡 v0.2

> **x并z = 对象通过稳定公共壳被世界识别、调用、归因、代表、进入或保护。壳可以与内部一致，也可以不一致。**

## 必要条件

1. 壳对象明确：身份、名称、职位、作品形式、品牌、前台、界面或保护壳；
2. 至少一个第三方能通过它稳定识别对象；
3. 壳跨场景或跨时间持续，不是一次换装和一次表演；
4. 壳真实改变调用、归因、代表、进入或保护方式；
5. 壳与内部对象存在可说明映射；
6. 拿掉视觉包装后，接口功能仍可验证。

## 对象分层

- 人物本体：长期依靠公共身份壳、代表接口或多层身份存在。
- 状态：当前进入某个公开角色或壳内。
- 行为：命名、署名、穿戴、代表、包装、切换界面。
- 关系：第三方通过壳与内部对象发生调用、归因或进入。
- 场景与视觉：前台、舞台、门面、面具、橱窗只作辅助。

## 壳的依赖类型预注册

关系审计前必须在观察结果前预注册壳类型，禁止看到结果后再把一次令牌改名为稳定壳。

| 类型 | 维持来源 | 主体停止自称/签署/表演后 | 审计意义 |
|---|---|---|---|
| 事实索引壳 | 档案、历史事实、既有署名、第三方索引 | 通常保持 | 本人拒认不是整体下降 |
| 独立制度壳 | 登记、职位、法人、授权或组织规则 | 制度未撤销时保持 | 必须排除制度撤销 |
| 构成性认证壳 | 本人持续认领、签署、续期或占位是成立必要条件 | 核心调用可能下降 | 可进入`nx克x并z`主检验 |
| 持续表演壳 | 第三方调用依赖主体反复表演该角色 | 跨时间调用可能下降 | 须排除即时表演中断 |
| 单次互动令牌 | 一次回应、口令、签署或现场动作 | 只影响当次程序 | 不足以证明稳定`x并z`下降 |

预注册至少写明：壳对象、第三方、跨时间窗口、核心调用指标、维持来源、撤销主体和恢复条件。

## 最近邻

```text
x并z vs x：x是实际掌握边界；x并z是其公共识别、调用、代表或保护接口。
x并z vs z：x并z提供可识别对象与归因接口；z是重要认可主体实际完成确认。
x并z vs n：x并z外部可读；n内部真能接住。
x并z vs xn：x并z是公共壳；xn是时间、流程、记录和持续组织。
x并z vs nx：x并z是角色与通道本身；nx是主体沿既有角色和通道推进。
稳定壳 vs 单次令牌：稳定壳可跨时间/场景被第三方调用；单次令牌只决定当次程序是否完成。
```

## 非充分条件

面具、伪装、撒谎、演员、制服、品牌、门牌、账号、华丽包装、内外不一、双层空间，均不能单判`x并z`。

以下也不能单独证明`x并z`下降：

- 主体停止自称；
- 拒绝一次签署、回应或口令；
- 当次表演中断；
- 新壳停止生产；
- 第三方暂时不知情；
- 法律、职位、组织或授权已经被外部撤销。

## 拿掉测试

拿掉欺骗、秘密、服装、视觉和一次曝光，检查第三方是否仍能稳定识别、调用、归因、代表或进入。若只有一次现场动作才成立，可能只是互动令牌。

关系审计还要依次拿掉：

1. 法律撤销、组织解散和授权终止；
2. 身份揭露、证据公开和第三方拒认；
3. 程序中断和一次互动失败；
4. 新壳生产停止；
5. 主体第一人称自称。

只有在外部结构冻结后，既存壳的核心调用仍随被检验变量下降，才支持关系启动。

## 反向测试

- 主体停止自称，但事实索引、制度资格和第三方调用仍在：稳定壳仍存在。
- 拒绝一次签署或回应，只让当次程序失败：构成性令牌停摆，不等于整体壳下降。
- 撤销登记、职位、授权、名册和公共接口后无法继续调用：`x并z`下降，但变化优先归于制度撤销。
- 构成性认证壳在主体重新认证后恢复，而事实索引壳不随之改变：支持依赖类型区分。
- 内外完全一致但承担识别、代表与保护：仍可判`x并z`。
- 只有视觉包装，无稳定接口：非主判。

## 六项评分

`object_layer / endpoint_fit / neighbor_exclusion / evidence_independence / removal_reverse / cross_context`分别评分，最终取最小值。

新增硬门：未完成壳依赖类型预注册时，`endpoint_fit`与`neighbor_exclusion`均不得超过89；未排除单次互动令牌和外部制度撤销时，`removal_reverse`不得超过79。

## 召回版

```text
这层壳让谁能够怎样找到、称呼、调用、归因、代表或进入对象？
它靠事实索引、制度、主体持续认证，还是只靠一次互动令牌维持？
只会伪装，不等于稳定x并z；一次签署失败，也不等于稳定壳整体下降。
```
