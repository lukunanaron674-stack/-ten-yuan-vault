# x视觉狭义卡 v0.1

## 1｜核心定义

> **x 是危险物品本身：锐利、切割、尖刺、直接伤害边界明确。**

最短召回：

```text
x＝刀
```

x不需要主动进攻。刀放在那里也仍是危险物品；它的危险来自自身锋利结构，而不是已经向外释放力量。

## 2｜发型形状

发型领域中的本征形：

```text
三角
V形
尖角
锐斜切面
短而集中的危险块面
```

轴向显影：

- 中间保留集中刘海，压缩可用 `X轴`，强化中心危险感；
- 厚而平的刘海压缩 `Y轴`，形成压迫、切断与硬面；
- 两条边界汇聚成尖端，形成刀刃／尖刺感；
- 轮廓可以静止，不要求主动外推。

## 3｜必要视觉证据

主判 `x` 至少检查：

1. 轮廓有清楚尖角、切口或硬边；
2. 危险来自形状本身，而不是风吹、动作或表情；
3. 压缩与集中强于扩散和包裹；
4. 主轮廓可概括为三角、刃面或短尖块；
5. 拿掉尖角与硬切后，x感明显下降。

## 4｜发型候选

- V形尖角刘海；
- 中央尖刘海；
- 短锐斜切刘海；
- 几何刀口刘海；
- 厚平刘海中形成明确切割边界的变体。

候选不是自动定论，仍需看整体主轮廓。

## 5｜最近邻

### x vs xz

```text
x：危险物品，像刀；危险由锐利结构直接成立。
xz：火药桶；危险蓄积在整体中，对一个触发点高度敏感，可能整体爆发。
```

长三角不自动等于xz。若只是把刀刃拉长，仍可能是x或z；必须出现火药桶式蓄积与触发结构才是xz。

### x vs zx

```text
x：刀存在，但没有主动挥出。
zx：刀已经挥出，力量主动推出并占据方向。
```

### x vs z

```text
x：尖角、刃面与直接切割。
z：长方形、长轴、长度节点或单一裁定点。
```

### x vs nx

```text
x：集中、压缩、尖锐。
nx：散开、横向铺展、方形／碎束块面化。
```

## 6｜拿掉测试

```text
拿掉尖角、切口和硬边后仍成立 → 可能不是x。
让形状主动向外推出 → 优先检查zx。
加入整体蓄积、触发敏感和爆发可能 → 检查xz。
打散成多束横向扩散 → 检查nx。
拉成长而等宽的片状结构 → 检查z。
```

## 7｜禁止误判

以下不能单判x：

- 只是短；
- 只是厚；
- 只是黑色或冷色；
- 角色看起来凶；
- 发丝数量少；
- 任意不对称。

必须有真实的锐利、切割或危险物品形状证据。
