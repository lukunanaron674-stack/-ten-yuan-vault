# 十元准度卡总控 v0.6

> 信息卡回答“它是什么”；准度卡回答“为什么这个对象必须判成它”；视觉狭义卡回答“它进入视觉领域后怎样显影”。三层不能互相冒充。

## 1｜固定流程

```text
明确判断对象与阶段
→ 分人物本体／状态／行为／场域／视觉／时间关系
→ 读取现行信息卡
→ 读取现行准度卡
→ 若涉及视觉，再读取对应视觉狭义卡
→ 列出至少两个最近邻
→ 做必要条件、拿掉与反向测试
→ 输出六项端点置信度
→ 端点稳定后进入对应关系卡
```

## 4｜六项端点置信度

1. `object_layer`：对象层是否分开；
2. `endpoint_fit`：必要条件是否完整；
3. `neighbor_exclusion`：最近邻是否排除；
4. `evidence_independence`：证据是否独立；
5. `removal_reverse`：拿掉与反向测试是否通过；
6. `cross_context`：本体判断是否跨情境复现。

最终取六项最小值。

```text
95–100：对象层明确、必要条件完整、两组独立证据、最近邻排除、拿掉反向通过、跨情境复现。
90–94：主判稳定，但仍缺一个关键控制。
80–89：强候选，仍混有第三因素、状态层或相邻类型。
60–79：主要是共现、行为、视觉或场景相似。
0–59：端点或方向不稳定。
```

## 5｜三个门槛

- 80%：强候选，不自动生成关系链；
- 90%：当前对象层稳定工作判定；
- 95%：正式端点进入关系锁定或正本修正。

工程执行95%与理论判定95%不得混用。

## 6｜视觉层强制规则

- 整体外轮廓、内部纹理、局部功能必须分层；
- 风吹、动作、湿发、光影不能替代发型本体；
- `x＝刀`、`xz＝火药桶`、`zx＝挥出的刀`；
- 散、碎、乱、羽化不能单判xz；
- `xn`与`x并z`的几何本征尚未确认，不得擅自补全；
- 十元配比度与本征映射准度必须分字段保存。

## 8｜禁止事项

- 不得用角色名、职业、服装、光色或题材替代十元；
- 不得把一次行为升级为稳定人物本体；
- 不得把关系机制写成十元本体定义；
- 不得把视觉形状直接升级为全局本体；
- 不得继续调用“危险逼近就是xz”的旧简式；
- 不得继续调用“碎乱羽化就是xz”的旧视觉判据。
