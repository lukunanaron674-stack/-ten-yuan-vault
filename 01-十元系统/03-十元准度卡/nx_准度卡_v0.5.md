# nx 准度卡 v0.5

> **nx = 主体不占据最终方向决定权，沿别人、关系、流程、秩序或现状已经给出的方向与通道推进。**

## 1. 先分对象

```text
人物本体：跨场景反复不占最终方向。
当前状态：某阶段暂时把方向交给别人或现状。
行为功能：跟随、接受安排、求人、借力、托关系、沿权限通道推进。
关系位置：方向、权限或解决通道在他者手里，主体承认并借用该位置。
场景与视觉：办公室、队伍、沉默、低调均不能自行成立。
```

一次服从、一次求人或一次借法宝，只能证明行为候选。

## 2. 纯 nx 必要条件

稳定人物本体至少满足五项中的四项，第1、2项不可缺：

1. 方向、权限或解决通道已经由别人、关系、流程或现状给出。
2. 主体不主动改写方向，也不抢最终决定、否决与重设问题的位置。
3. 没有明确外部强迫时，仍倾向等待安排、默认延续或寻找他者通道。
4. 这种方式跨阶段、跨场景反复出现。
5. 提供低成本自主窗口后，主体仍不主动形成替代路线。

```text
方向已存在
+ 我不占最终决定
+ 我沿既有关系或安排推进
+ 跨场景复现
= nx 强候选
```

## 3. 两种 nx 必须分开

### 3.1 纯 nx 本体

长期让别人、群体、家庭、流程或现状决定方向。

### 3.2 nx 关系功能

人物总体很有主见，但某件事的权限和资源在别人手里，于是通过请求、旧交、身份、职位、通道或人情网络办成。

孙悟空“齐天大圣、直接压过对象”偏`zx`；找菩萨、土地、龙王、天庭、借法宝和请救兵，是`nx`关系功能。不能由一段求人行为反推人物本体没主见。

## 4. 最近邻

### nx vs xn

| 检查项 | nx | xn |
|---|---|---|
| 最终方向 | 由别人、关系或现状给出 | 可接外部目标，但主体主动组织运行方式 |
| 核心动作 | 跟随、配合、求人、借力 | 排程、记录、搭流程、设节点、分资源 |
| 取消旧安排 | 倾向等待新方向 | 主动重组结构 |

### nx vs x

```text
nx：权限和资源在别人手里，我沿通道借用。
x：对象、资源、权限和调用边界归我掌握。
```

幕后控制网络是`x`，不是`nx`。

### nx vs zx

```text
nx：沿他者已有位置和关系网络推进。
zx：以自身权能公开显现、扩大并压过对象。
```

### nx vs nz

```text
nx：不占方向。
nz：关系可停靠、可退出、可回返，但不必交出判断资格。
```

信任伴侣、默认采用建议，不等于最终方向资格不可达。

### nx vs n

```text
n：对象进入内部后被真实接住并持续处理。
nx：沿已有方向和通道推进。
```

愿意承接任务不等于没有方向；照安排做也不等于形成承载结构。

## 5. 非充分条件

以下不能单判`nx`：

- 沉默、内向、低调；
- 礼貌、忍耐、愿意帮助；
- 身处制度或接受一次命令；
- 一次求人、一次借力；
- 暗中观察、看牌、记账、等待节点；
- 创伤后犹豫；
- 因专业信息差听从专家；
- 因经济、监护、职位或暴力无法反抗。

暗算、记录、排程与延迟结算优先检查`xn`；幕后掌握优先检查`x`；主动压制优先检查`zx`。

## 6. 拿掉测试

依次拿掉：

1. 外部强迫、惩罚和生存威胁；
2. 信息、能力、资源与专业差；
3. 职位、监护、合同和权限结构；
4. 一次危机和临时分工；
5. 关系破裂威胁；
6. 既有流程，提供可自行重设问题的窗口。

若主体仍不提出替代路线、不占否决与重设位置，并继续寻找他者安排，才支持稳定`nx`。

## 7. 反向测试

- 获得安全窗口后主动重设目标、标准、流程并承担失败：`nx`下降。
- 只是会执行别人给出的目标：仍可为`nx`行为。
- 接到目标后主动搭流程：`xn`上升。
- 撤销外部权限后仍能独立处分对象：检查`x`。
- 关系安全且允许退出时仍能否决、换人、私下形成替代方案：说明只是信任或委托，不是稳定方向让位。

## 8. `z 克 nx`纠错

现行状态：

```text
几何位置保留
机制未锁定
```

旧口径：

```text
z持续表达、决定和占位
→ nx不抢回方向
→ 把自己让没
```

已经撤回。现行`z`是重要认可主体对存在、能力、作品或选择的确认；强势占位更可能属于`zx/x/xn`或外部方向主体。

当前仅保留候选：重要认可主体确认人物自己的判断资格，是否会使最终方向资格真正回归。必须排除教学、资源、权限、治疗、既有自主与一次行动启动。不得在本卡写成已确认关系。

## 9. 六项评分

```text
object_layer：人物本体、状态、行为与关系功能是否分开。
endpoint_fit：方向与通道是否外置，主体是否不占最终决定。
neighbor_exclusion：xn、x、zx、nz、n是否排除。
evidence_independence：是否有跨场景独立证据，而非同一服从行为换词。
removal_reverse：拿掉强迫、信息差、职位后是否仍成立；自主窗口出现时是否恢复。
cross_context：是否跨阶段、跨对象复现。
```

最终分数取六项最小值。

## 10. 召回版

```text
老板安排什么就做什么：nx行为。
老板给目标，员工主动排程搭流程：xn。
权限在别人手里，通过关系网络借力：nx关系功能。
对象与网络归自己掌握：x。
z克nx旧占位机制已撤回，当前不得写成已锁定。
```
