# zn / z / zx 对错关系轴·准度补充 v0.1

> 本卡只用于 `zn / z / zx` 在**人物立场、关系冲突与对错判断领域**中的狭义判定。
>
> 本卡不替换三张现行准度卡，不改变原信息卡本体，也不凭一句台词直接升级人物本体。

## 1. 启动门槛

只有同时满足以下条件，才调用本补充：

1. 判断对象是人物本体、人物状态、关系位置、对话立场或冲突中的选择方式；
2. 场景中真实存在“我是否正确、他者是否正确、多个立场能否共存”的问题；
3. 有行为、选择、关系处理或跨情境证据，不只是一句口号；
4. 能明确区分主体如何处理他者：承认、忽略，还是否定。

以下情况不启动：

- 只有光色、构图中心、服装或题材；
- 只有胜负，没有对他者正确资格的处理；
- 只有自信、固执、愤怒或战斗；
- 只是事实判断正确或错误；
- 只出现一次情绪化台词，后续行为不支持。

## 2. 三点最短判定

```text
zn：你们都对，我也是对的。
z：我是最对的，你们不关我事。
zx：我是对的，你们都是错的。
```

判定顺序：

```text
是否承认他者也可成立？
├─ 是，并保留自身正确 → zn
└─ 否
   ├─ 他者只是无关，不必判错 → z
   └─ 他者必须被判错、排除或压过 → zx
```

## 3. zn 准度补充

### 必要条件

狭义 `zn` 至少满足：

1. 主体有明确的自身立场，不是无原则附和；
2. 主体承认至少一个不同立场具有成立空间；
3. 自身正确不以取消他者正确为条件；
4. 冲突时会寻找边界、位置、条件或并存方式；
5. 拿掉“他者也可成立”后，当前关系处理方式明显改变。

### 强证据

- 主体在坚持自己时，仍保护对方表达、选择或存在的资格；
- 能说清双方分别在哪个位置、条件或尺度上成立；
- 面对冲突，不要求对方先承认错误，自己才允许关系继续；
- 跨不同对象仍反复采用并存式处理，而非只对亲近者宽容。

### 最近邻排除

```text
zn vs z：zn主动保留他者成立空间；z不处理他者，只把自己推到最高。
zn vs zx：zn的自身正确不依赖他者错误；zx必须排除竞争正确。
```

### 拿掉测试

拿掉他者立场的成立资格，只保留“我坚持自己”。若结构仍完整，优先检查 `z` 或其他十元，不足以判本轴 `zn`。

### 反向测试

- 表面说“都对”，实际要求所有人服从自己的最终解释：不得直接判本轴 `zn`；
- 为避免冲突而敷衍附和，没有自身立场：不是本轴 `zn`；
- 只允许自己人正确、外人全部错误：检查 `zx`；
- 承认他者正确后把自己完全让没：需检查 `nx/nz` 等结构，不能只凭包容判 `zn`。

### 召回问句

```text
我是否保留自己的正确？
我是否真实承认别人也能成立？
我的正确是否不依赖别人被判错？
```

## 4. z 准度补充

### 必要条件

狭义 `z` 至少满足：

1. 主体把自身正确、价值或精神位置推到最高；
2. 核心任务是确认“我最对 / 我必须成立”；
3. 他者不进入主体的主要判断范围，表现为无关、绕开或不处理；
4. 主体不需要系统证明“所有人都错”才能维持自身位置；
5. 拿掉自我最高位置后，当前行为或精神动力明显下降。

### 强证据

- 主体只寻找能确认自身最高位置的舞台、对象或结果；
- 面对异议时不辩论其内容，而是认为对方与自己无关；
- 他者不是被驳倒，而是被降为背景、噪音或局外人；
- 跨情境持续回到“我是否成立、我是否最值得确认”。

### 最近邻排除

```text
z vs zn：z不承担多方正确的并存；zn主动承认并处理他者成立空间。
z vs zx：z让他者无关；zx让他者错误。
```

### 拿掉测试

拿掉他者的反对、赞同和存在，只保留主体面对自己的目标或认可位置。若“我必须最成立”的动力仍在，支持狭义 `z`。

若必须持续攻击、驳倒或取消他者资格才能成立，优先检查 `zx`。

### 反向测试

- 只是专注做自己的事，没有“自我最高 / 最对”结构：证据不足；
- 明确承认他者与自己同时正确：检查 `zn`；
- 明确要求他者承认错误、退位或失去资格：检查 `zx`；
- 只因外部赞美而短暂兴奋：仍需按现行 `z` 准度卡核验认可结构，不能只凭本补充锁定。

### 召回问句

```text
主体是否把自己推到最高正确位置？
他者是无关，还是必须被判错？
没有他者可反驳时，自我最高结构还成立吗？
```

## 5. zx 准度补充

### 必要条件

狭义 `zx` 至少满足：

1. 主体明确认定自身立场正确；
2. 至少一个竞争立场被明确判断为错误、无效或应被取消；
3. 自身正确与他者错误形成排他关系，不能在同一判断范围内并存；
4. 主体试图让这种排他判断进入现实，改变他者资格、位置、话语权或行动范围；
5. 拿掉对他者的否定后，当前 `zx` 结构明显下降。

### 强证据

- 主体要求异议者改口、退位、服从或被排除；
- 通过显权、扩权、征服、命令或改写规则，使自己的答案成为唯一答案；
- 不只认为自己更强，而是认为竞争立场没有成立资格；
- 他者的错误被用来证明或扩大主体的正确位置。

### 最近邻排除

```text
zx vs z：zx必须处理并否定他者；z可以直接认为他者无关。
zx vs zn：zx要求唯一正确；zn允许不同正确并存。
zx vs x：x可只掌握对象、资源或权限；zx在本轴上还要取消竞争立场的正确资格。
```

### 拿掉测试

拿掉对手、异议者及其立场，只保留主体自己的力量和目标：

- 若排他正确结构消失，只剩显权、扩权或行动，应回到现行 `zx` 信息卡判断其他层面；
- 若人物本体仍必须制造一个“错误者”来确认自己，支持本轴 `zx`。

### 反向测试

- 只是赢了战斗，没有否定对方正确资格：不能单判本轴 `zx`；
- 只是对别人不感兴趣：检查 `z`；
- 承认双方各有道理：检查 `zn`；
- 只是事实证明对方判断错误，不等于人物具有稳定排他正确结构；
- 临时反驳一次，不足以升级人物本体。

### 召回问句

```text
主体是否必须把别人判错，才能确立自己对？
他者是否被取消表达、选择或决定资格？
这种排他判断是否真实进入关系与现实？
```

## 6. 六项准度评分的补充要求

沿用准度卡总控六项评分：

```text
object_layer
aendpoint_fit
neighbor_exclusion
evidence_independence
removal_reverse
cross_context
```

其中 `aendpoint_fit` 为本补充中的书写误差时，应统一按正式字段 `endpoint_fit` 记录，不另造字段。

本轴的额外封顶：

- 只有一句原话或近义台词：≤69；
- 只有视觉中心、强势姿态或表情：≤59；
- 无法区分“他者无关”与“他者错误”：≤79；
- 无法区分“承认他者成立”与“敷衍附和”：≤79；
- 单次争论升级人物本体：≤79；
- 三者最近邻未完成排除：≤79。

## 8. 禁止事项

1. 不得把三句教学锚直接改写成三张十元信息卡的唯一广义定义；
2. 不得因为人物说“我对”就判 `z` 或 `zx`；
3. 不得把事实上的正确与十元意义上的正确关系混为一谈；
4. 不得把 `z` 的“他者无关”误写为“他者皆错”；
5. 不得把 `zn` 的并存理解成没有判断标准；
6. 不得把 `zx` 缩成普通行动力、战斗力或高权力；
7. 不得凭本补充单独生成或修订生克补关系。

## 9. 召回版

```text
本卡只判人物与关系领域的对错处理方式，不覆盖十元本体。

zn：你们都对，我也是对的。
判点：多方正确并存，自身不靠否定别人而成立。

z：我是最对的，你们不关我事。
判点：自我最高，他者被置为无关，不必被判错。

zx：我是对的，你们都是错的。
判点：排他正确，必须否定或取消竞争立场。

最重要边界：
z 是“无关”；zx 是“错误”。
```
