# n 准度卡 v0.1

> **n = 对象真实进入主体或结构内部，被允许留下，并被跨阶段接收、处理、保护和承担持续负荷。**

## 必要条件

1. 进入内部的对象或成员明确；
2. 获得真实位置而非一次停留；
3. 主体承担对象产生的时间、空间、照护、风险或资源负荷；
4. 存在持续处理与保护；
5. 对象不是被强制扣留；
6. 外部压力下仍有一定接收与抗崩能力。

## 对象分层

- 人物本体：跨场景以接住和持续处理为存在方式。
- 状态：当前阶段承担内部对象或负荷。
- 行为：接收、照护、保护、处理、维持。
- 关系：成员能进入、留下、返回并被接住。
- 场景与视觉：家庭、房屋、土地、怀抱只是候选。

## 最近邻

```text
n vs nx：n承载内部对象；nx沿外部方向和通道推进。
n vs nz：n负责内部接住；nz负责自由离开后的可信回返与修复。
n vs xn：n承担负荷；xn主动组织处理方式持续运行。
n vs zn：zn确认什么不可抛下；n让对象真实留下并处理负荷。
n vs x：n允许内部存在；x强调归我掌握、处分和排除。
n vs x并z：n是内部真能接住；x并z是外部可识别与可进入。
```

## 非充分条件

善良、忍耐、情绪稳定、母亲、家庭、房屋、医院、一次收留、一次帮助、被迫承受，均不能单判`n`。

## 拿掉测试

拿掉暖色、家庭称谓、容器意象和照顾台词，检查是否仍有真实准入、持续内部位置和负荷处理。若对象无法退出，优先检查控制结构。

## 反向测试

- 只被动承受却不处理：不是完整`n`。
- 一次救援后立刻转交：行为层。
- 进入后被拘禁：不等于被承载。
- 负荷重复后主动形成流程：可出现`n生xn`，但两端需分开。
- 取消内部位置与处理后，成员无法停留与返回：支持`n`端点曾成立。

## 六项评分

`object_layer / endpoint_fit / neighbor_exclusion / evidence_independence / removal_reverse / cross_context`分别评分，最终取最小值。

## 召回版

```text
谁进入了内部？
是否被允许留下？
谁在跨阶段处理其真实负荷？
```
