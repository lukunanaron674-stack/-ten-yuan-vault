# xn 准度卡 v0.1

> **xn = 主体主动组织时间、计划、规则、信息、记录、流程、资源与节点，使分散行动经过排列、重复和积累形成可持续运行的结构力量。**

## 必要条件

1. 主体主动组织，而不是被动遵守；
2. 被组织对象明确；
3. 至少涉及时间、顺序、流程、记录、节点、分工或资源中的两项；
4. 组织跨阶段保存并影响下一轮；
5. 单次临时安排不足。

## 对象分层

- 人物本体：长期主动把世界放进结构持续运行。
- 状态：当前阶段组织、维护或重组流程。
- 行为：排程、记录、分工、复盘、预案、等待节点。
- 外部结构：程序、训练、传统、制度与历史惯性，是长期`xn`外化。
- 场景：学校、军队、公司、监狱不能单判。
- 视觉：网格、表格、钟表、队列只作辅助。

## 最近邻

```text
xn vs nx：xn主动决定怎样持续运行；nx沿别人或现状给出的方向继续。
xn vs x：xn组织对象；x掌握对象与处分边界。
xn vs zx：xn靠时间结构和积累；zx靠当下公开显权与扩张。
xn vs n：n承载负荷；xn把处理经验提炼成可重复结构。
xn vs z：xn提供跨时间证据；z提供认可主体与确认节点。
```

## 非充分条件

有规则、守纪律、接受命令、身处制度、年纪大、经验多、一次计划、安静等待、会记账，均不能单判`xn`。

## 拿掉测试

拿掉上级命令、既有制度和职位，检查主体是否仍主动重组时间、流程和记录。拿掉记录与跨轮次保存后，若结构无法持续，支持`xn`。

## 反向测试

- 老板安排什么就做什么：`nx`。
- 老板只给目标，主体主动排程搭流程：`xn`。
- 只拥有部门但不组织运行：偏`x`。
- 一次爆发改变现实但无持续结构：偏`zx`。
- 规则早于主体且其只被动执行：外部`xn`场景，不等于人物本体`xn`。

## 六项评分

`object_layer / endpoint_fit / neighbor_exclusion / evidence_independence / removal_reverse / cross_context`分别评分，最终取最小值。

## 召回版

```text
谁主动安排它怎样持续运行？
是否跨时间保存、重复和积累？
有规则不等于xn，主动组织才是。
```
