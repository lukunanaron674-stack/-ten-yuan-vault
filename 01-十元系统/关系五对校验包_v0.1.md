## 0. 四层规则

```text
内容显影 ≠ 标准位置关系

十元 = 点
关系五对 = 基础位置边型
关系对子 = 多个关系五对的组合方式
动态链条 = 关系对子落到具体十元后跑出的力流结构
```

一句话封存：

> 内容负责显影，位置盘负责定边，关系五对负责基础边型，关系对子负责组合，动态链条负责跑流。

## 1. 关系五对定义

关系五对是十元位置盘里的基础边型，共五类：

```text
1. 生：A 生 B
2. 被生 / 承生：A 被 B 生
3. 克：A 克 B
4. 被克 / 受克：A 被 B 克
5. 补：A 补 B
```

简义：

```text
生 = 推出 / 生成 / 显影
被生 = 被推出 / 承生
克 = 压制 / 限制 / 截断 / 迫使转向
被克 = 被压制 / 被限制 / 受克
补 = 补厚 / 补全 / 结构加厚
```

注意：被生、被克不是新边，而是从受力方视角看同一条边。

## 2. 标准位置盘 v0.1｜生对

### 生环 1

```text
xz → zx → zn → n → xn → xz
```

展开：

```text
xz 生 zx
zx 生 zn
zn 生 n
n 生 xn
xn 生 xz
```

### 生环 2

```text
nz → nx → x → x并z → z → nz
```

展开：

```text
nz 生 nx
nx 生 x
x 生 x并z
x并z 生 z
z 生 nz
```

关键防错：

```text
z 生 nz ✅
nz 生 z ❌
zx 生 zn ✅
```

## 3. 标准位置盘 v0.1｜克对

### 克环 1

```text
xz → zn → xn → zx → n → xz
```

展开：

```text
xz 克 zn
zn 克 xn
xn 克 zx
zx 克 n
n 克 xz
```

### 克环 2

```text
nz → x → z → nx → x并z → nz
```

展开：

```text
nz 克 x
x 克 z
z 克 nx
nx 克 x并z
x并z 克 nz
```

关键防错：

```text
x并z 克 nz ✅
xz 克 nz ❌
n 克 x ❌
xn 克 zx ✅
zn 克 xn ✅
```

## 4. 标准位置盘 v0.1｜补对

当前可用补对：

```text
xz ↔ nz
zx ↔ nx
zn ↔ x
n ↔ x并z
```

展开：

```text
xz 补 nz / nz 补 xz
zx 补 nx / nx 补 zx
zn 补 x / x 补 zn
n 补 x并z / x并z 补 n
```

待校准补对：

```text
xn ↔ z
```

处理规则：

```text
xn 补 z / z 补 xn 暂用待校准。
未再次确认前，不进入强动态链。
```

## 7. 关系对子定义

关系对子不是单个具体边，而是多个关系五对的组合方式。

```text
关系五对 = 生 / 被生 / 克 / 被克 / 补
关系对子 = 多个关系五对的组合方式
动态链条 = 关系对子落到具体十元后跑出的力流结构
```

示例：

```text
克 + 克 + 生 = 关系对子
zn 克 xn → xn 克 zx → zx 生 zn = 动态链条
```

## 8. 已确认动态链示例

### 示例 1：克 + 克 + 生

```text
zn 克 xn
→ xn 克 zx
→ zx 生 zn
```

位置校验：

```text
zn 克 xn ✅
xn 克 zx ✅
zx 生 zn ✅
```

关系对子：

```text
克 + 克 + 生
```

内容显影：

```text
意义责任压住长期路径；
长期路径继续压住行动选择；
行动选择最终生出新的意义归属。
```

命名建议：

```text
克制接力回生链 / 压制传递回流链
```

---

### 示例 2：生 + 补 + 被克

```text
z 生 nz
→ xz 补 nz
→ nz 被 x并z 克
```

位置校验：

```text
z 生 nz ✅
xz 补 nz ✅
x并z 克 nz ✅
```

关系对子：

```text
生 + 补 + 被克
```

内容显影：

```text
一个显影点生出停靠 / 依恋感；
命运漂流 / 临界感补厚停靠；
表象外壳又克制停靠，使关系变得不可信、不稳定、难以确认。
```

关键防错：

```text
nz 生 z ❌
n 补 nz ❌
xz 克 nz ❌
```

## 9. AI 防错铁律

### 铁律 1：不许从内容动词直接推关系五对

不能因为内容里有“压住”“生出”“补上”，就直接写成克、生、补。

```text
内容：漂流压住停靠
错误位置：xz 克 nz ❌
标准位置：xz 补 nz ✅
```

### 铁律 2：先查位置盘，再写关系五对

每条边必须经过：

```text
候选十元 A
候选十元 B
查生 / 克 / 补
确认关系
再进入动态链
```

### 铁律 3：未确认关系不入强动态链

```text
xn ↔ z 补对 = 暂用待校准
不作为强关系自动入链
```

### 铁律 4：内容显影和标准位置关系分栏写

固定三栏：

```text
内容显影：故事里看起来发生了什么
标准位置：位置盘真实关系是什么
动态链条：校验后的关系五对如何组合跑流
```
