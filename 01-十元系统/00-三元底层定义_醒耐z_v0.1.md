# 三元底层定义·醒耐z v0.1

> 本文件是当前三元底层口径。旧文件中“z=楚王弓、n=精神个体、x=现象之流”的对应关系作废。

## 1. z：精神个体需要另一个精神个体的认可

z 的起点不是楚王弓，也不只是执念或舞台表现。

```text
一个精神个体
面对庞大的物质客观世界
→ 感到自身非常渺小
→ 单靠客观物质无法确认自己的精神存在
→ 需要另一个精神个体看见、回应、认可自己
→ z
```

### z 的核心关系

```text
精神个体 ↔ 另一个精神个体
```

### 最短定义

> **z = 一个精神个体需要另一个精神个体确认：我看见你，你的精神存在对我成立。**

因此，“被看见、被认可、舞台、展示、荣耀、宣言”可以是 z 的外部形态，但不是最底层定义。

---

## 2. x（醒）：关注具体物象，小而清

x 的注意力落在具体、有限、可以切清楚的物象和物质关系上。

```text
关注区域小
→ 变量少
→ 边界清楚
→ 因果容易切开
→ 思考冷静、聪明、逻辑清晰
```

### x 常关注的问题

- 这个东西是什么。
- 它归谁。
- 它值多少。
- 它如何运作。
- 它与另一个具体事物有什么因果关系。
- 我能否得到、控制、处理或保存它。

### x 的优势

- 具体。
- 清晰。
- 冷静。
- 逻辑强。
- 对物质、功能、局部因果判断准确。
- 更接近理科式的切分与分析。

### x 的局限

x 容易显得自私，不一定是道德意义上的坏，而是结构上过于在意物象、物质、所有权和眼前利益。

```text
区域小
→ 自己与眼前对象最清晰
→ 区域之外的人、精神与大关系被弱化
→ 狭隘、自我、物质性增强
```

### 最短定义

> **醒看物，所以窄而清。**

---

## 3. n（耐）：关注大区域与大关系，大而空

n 不把注意力锁死在一件具体物品上，而是把对象放进越来越大的区域与关系中理解。

```text
单个物品
→ 人与物的关系
→ 群体关系
→ 国家与国家的关系
→ 人类关系
→ 自然
→ 空
```

### n 常关注的问题

- 这件事放进更大的整体中意味着什么。
- 谁与谁处在什么关系中。
- 一个群体、国家、历史或精神整体如何相互作用。
- 哪个更大的区域能够容纳当前的得失与矛盾。

### n 的优势

- 视野大。
- 能看整体关系。
- 更理解人与人、群体与群体、国家与国家之间的关系。
- 容纳矛盾与多重答案。
- 人际、社会、历史和宏观理解更强。
- 更接近文科式的整体与关系思考。

### n 的局限

区域越大，变量越多，边界越模糊，所以 n 的思考容易显得空、散、乱，具体物质逻辑较弱。

```text
区域大
→ 变量多
→ 多重关系同时在场
→ 很难切成唯一、干净的因果线
→ 宏观关系强，局部逻辑弱
```

### 最短定义

> **耐看关系，所以大而乱。**

“大而乱”不是愚笨，而是以局部清晰换取整体容纳。

## 4. 楚庄王弓：n 与 x 的核心教学案例

楚庄王弓不是 z 的定义，而是用来说明 x 的具体物象与 n 的区域尺度。

### x：具体的弓

```text
这把弓离开了原主人
位置改变
所有权改变
所以弓丢了
```

x 盯住的是具体物品及其物质状态。

### 楚庄王：区域扩大到楚国

```text
楚人丢弓
楚人得弓
弓仍在楚国区域中
所以没有丢
```

### 孔子：区域扩大到人类

```text
何必只说楚人
人丢弓，人得弓
弓仍在人类区域中
所以没有丢
```

### 孟子：区域扩大到自然

```text
弓来自自然
最终也会腐化并回到自然
它始终没有离开自然
```

### 高僧：空

```text
空
```

拥有、失去、弓、人、自然等区分都被更大的区域容纳并消解。

### 区域梯度

```text
具体的弓（x）
→ 楚国
→ 人类
→ 自然
→ 空（最高 n）
```

> **高僧最 n，因为他的区域最大，大到没有一个对象还落在区域之外。**

## 5. x 与 n 的交换关系

| 维度 | x（醒） | n（耐） |
|:-----|:--------|:--------|
| 视野 | 小、窄 | 大、广 |
| 注意对象 | 具体物象、物质、局部 | 精神、整体、大关系 |
| 思维方式 | 切分、分析、局部因果 | 容纳、联系、宏观关系 |
| 优势 | 清晰、冷静、精准、逻辑强 | 宏观、人际、社会、关系理解强 |
| 局限 | 狭隘、自私、忽略区域外 | 空散、混乱、具体物质逻辑弱 |
| 学科类比 | 理科 | 文科 |
| 核心交换 | 牺牲广度换清晰 | 牺牲清晰换广度 |

### 封存句

> **醒牺牲广度，换取清晰；耐牺牲清晰，换取广度。**

## 6. 三元的最小关系式

```text
x：精神个体 ↔ 具体物象与物质关系
z：精神个体 ↔ 另一个精神个体的看见与认可
n：精神个体 ↔ 更大区域与整体关系
```

最短召回：

> **醒看物，所以窄而清；耐看关系，所以大而乱；z 看另一个精神个体是否认可自己。**

## 7. 三元与十元的地位

三元与十元不是父子派生关系。

- 十个十元是平等的位置。
- 三元用于描述十元内部的比例、质地与侧重。
- 例如 `nx` 可以表现为 n 多、x 少，但 nx 与 n 在十元判定上仍是同一层级的位置。
- 少量副元不是装饰，可能彻底改变性格、喜好和关系方式。

```text
错误：n + 少量x → 派生出nx
正确：十元位置是nx；其内部三元比例表现为n多x少
```

## 8. 判定对象决定证据优先级

不能给所有对象使用同一套优先级。

| 判断对象 | 优先证据 |
|:---------|:---------|
| 人物本体 | 动机、选择方式、长期稳定结构 |
| 人物状态 | 当下反应与压力方式 |
| 单张插画 | 光影、颜色、氛围、构图、空间关系 |
| 漫画 / 电影 | 时间点变化、事件转折、关系运动 |
| 场景 | 空间尺度、方向、容纳与压迫关系 |

同一张图可以同时成立：

```text
人物本体：zn
光影 / 场域：xz
画面关系：xz 正在作用于 zn
```

这不是判定冲突，而是对象层级不同。

## 9. 禁止误读

- 不得再写 `z = 楚王弓`。
- 不得再写 `n = 精神个体`。
- 不得再写 `x = 现象之流` 作为完整定义。
- 楚庄王弓用于解释 x 的具体物象与 n 的区域扩大。
- x 的自私与 n 的混乱都是结构代价，不直接等于道德好坏或智力高低。
- “舞台、追光、被看见”必须回到“另一个精神个体的认可”才能触及 z 的根。
