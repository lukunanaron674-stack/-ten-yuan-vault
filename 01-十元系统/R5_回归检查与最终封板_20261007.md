本轮只处理**可执行入口、核心读取链与 Skill 门禁**；历史论文、旧实验记录、旧数据字段和旧 Canvas 不删除。

## 3. 允许继续存在的“旧痕迹”

以下内容**不视为回归失败**：
- 历史文件中的 is-a狭义文字；
- 已生成的配比度 / 本征准度数据；
- 旧五行分库、Canvas、排行榜；
- 旧研究结论与 changelog；
- 旧字段名在数据卡中继续存在。

条件是：它们不能位于现行默认读取链的最高权重位置，也不能覆盖感受模型正本。

## 4. 现行不可违背的执行规则

```text
感受主语 = 人

对象 / 画面 / 音乐 / 角色 / 服装 / 发型 / 事件
+ 具体语境
→ 人的自由感受描述
→ 十元感受1–10谱
→ 主导 / 次级感受
→ 诱发特征
→ AI预测 / 生成
→ 人复核
```

AI 可以学习、预测、生成“什么形式更可能让人产生什么感受”，但 AI 的分类输出不能代替人的真实感受数据。
