# 题材分析：复仇

## 题材定义

复仇 = 因受伤害而采取行动，使伤害者承受对等或更重的代价。

## 激活的主题及强度

| 主题 | 激活强度 | 说明 |
|:----|:-------:|:------|
| **因果型** zx+nx | **10** | 复仇是因果型最纯粹的题材化——执行(zx)与清算(nx)的闭环。复仇者做计划(zx)，然后算账(nx)。「血债血偿」就是最朴素的因果公式 |
| **命运型** xz+nz | **7** | 复仇者往往不是主动选择复仇，是被命运推上这条路（xz）。复仇过程中对目标的等待（nz）也是常见结构。但命运型不是复仇的核心——复仇是「我要算这笔账」，不是「命运让我算这笔账」 |
| **本体型** zn+x | **6.5** | 复仇到深处会触发本体追问——「我复仇完了我是谁」(zn)。以及复仇本身的欲望驱动(x)。基督山伯爵复仇后的空虚就是本体型的显形 |
| **时间型** xn+z | **5** | 复仇需要时间——计划多久、等多久。有些复仇故事的核心是「等到了合适的时机」(z突破xn)。但时间型是复仇的工具而非本质 |
| **空间型** x并z+n | **3** | 复仇与空间/外壳无直接关联。除非复仇者需要伪装身份潜入对方领地（x并z），但这是手段不是题材核心 |

## 人物配置

| 角色类型 | 十元 | 说明 |
|:--------|:----:|:------|
| 复仇者 | zx+nx (主) | 执行计划+清算账目。zx给行动力，nx给策略和结算的「够不够」判断 |
| 复仇者变体A | zx+zn | 为了正义复仇——复仇不只是清算，还有意义支撑。但zn也可能让复仇者变成「我不得不做」的悲剧角色 |
| 复仇者变体B | zx+x | 复仇变成欲望——不是为了清算，是「想看他痛苦」。这是复仇的堕落形态 |
| 复仇对象 | n (被清算者) | 复仇对象在复仇结构中是被动的——ta是目标、等待被清算 |
| 催化剂 | xz | 触发复仇的事件（伤害行为把受害者推到临界） |
| 阻碍者 (可选) | n/zn | 劝复仇者放下的人——n的承载（「别毁了我们的生活」）或zn的宽恕（「复仇没有意义」） |

## 冲突类型

- **外部冲突**：复仇者 vs 复仇对象 + 复仇对象的社会保护系统
- **内部冲突**：复仇者 vs 自己的道德底线（「我到什么程度就够了」）
- **核心张力**：清算的欲望(zx+x) vs 放下的可能(zn+n)

## 典型故事弧

```
触发(xz) → 规划(zx) → 执行(zx) → 推进(zx+nx) → 清算(nx) → 后果(zn空间)
```
1. 伤害发生（xz触发——被推到边界）
2. 复仇者决定复仇（zn意义支撑+zx行动开启）
3. 计划与执行（zx核心阶段）
4. 清算（nx高潮——「够了」「还不够」的抉择）
5. 复仇完成后的意义追问（zn——「然后呢」）

## 经典案例

| 作品 | 复仇类型 | 主题配置 | 独特点 |
|:----|:--------|:--------|:-------|
| **基督山伯爵** | 纯粹复仇 | 因果10·命运7·本体6 | zx+nx最完整的呈现——每一步都是执行+清算的完美闭环 |
| **哈姆雷特** | 犹豫复仇 | 因果8·本体9·命运7 | zn的「意义追问」压倒了zx的执行力——复仇者的犹疑推动整个故事 |
| **风骚律师(吉米)** | 身份复仇 | 因果9·空间8·本体7 | 复仇不是清算——是「成为那个能清算的人」(x并z→nx的转变) |
| **杀死比尔** | 血路复仇 | 因果10·x9·命运8 | zx+x的复仇——执行中是纯粹的欲望驱动，暴力之美 |
| **蝙蝠侠(黑暗骑士)** | 正义复仇 | 因果8·本体8·时间7 | zn的正义感约束了nx的清算——「我不杀你」就是zn克nx |

## 复仇故事的误判防线

- ⚠️ 不是所有「报仇故事」都是因果型——如果核心是「我等了二十年终于等到这一天」(nz等待)，那是命运型披着复仇的外壳
- ⚠️ 复仇者不一定是zx——被仇恨吞噬的人可能是x（从复仇变成欲望），放不下的人可能是nz（永远在等一个清算不了的账）
- ⚠️ 复仇题材中的「宽恕」不是xn（规则）而是zn（意义超越）
