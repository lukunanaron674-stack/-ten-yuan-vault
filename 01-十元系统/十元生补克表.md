# 十元生补克表

> 本页是十元生、克、补关系的直接正本。几何位置与关系语义分开读取：位置写入表格不等于机制已经通过案例验收。

## 1. 当前四元召回

```text
x：对象、资源、地盘、权限或关系归我掌握。
zx：主体权能公开显现、扩大，并凌驾于他者之上。
xn：主体主动组织计划、时间、规则、信息和资源，使结构持续运行。
nx：主体不占据方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。
```

## 2. 五组补位

| 几何组 | 主题 | 当前语义 |
|---|---|---|
| **zx ↔ nx** | 因果 | 直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补 |
| **zn ↔ x** | 本体 | 精神意义与具体归属、控制边界形成内外本体张力 |
| **n ↔ x并z** | 空间 | 承载内部与公开形式互相提供容器和界面 |
| **xn ↔ z** | 时间 | 时间组织提供可累计证据，认可节点提供阶段确认 |
| **xz ↔ nz** | 命运 | 危险补入失去风险，停靠补入回返对象和归宿方向 |

补位只表示几何位置；具体调用仍须检查专项正本。

## 4. 已锁定关系语义

### 4.1 xn 克 zx

```text
现实已经被时间、规则、流程和前置行动组织
→ zx 的即时显权扩张必须进入既有结构
→ 单次爆发不能直接取消长期积累
```

### 4.2 zx 补 nx / nx 补 zx

```text
zx：直接以主体自己的权能做成。
nx：通过既有身份、关系、权限与通道借力做成。
```

### 4.3 zx 克 n

```text
zx 主体公开显权，直接决定成员资格、接收边界或结构运行条件
→ n 原有的接收、保护、照顾、互信与反复返回能力被迫停止
→ n 的承载能力下降、断裂或失效
```

被改变变量：成员资格、接收边界、保护与照顾连续性、成员互信、反复返回能力、结构抗崩能力。

### 4.4 xn 生 xz

```text
xn 规定正常运行的时间窗、路线和身份接口
→ 主体偏离后，偏差被识别、记录并持续处理
→ 可用安全路径与退路逐步缩窄
→ xz 的临界风险和命运失稳上升
```

被改变变量：偏差识别率、暴露与追踪概率、安全路线数量、可用时间窗、退路宽度、稳定停留可能性。

### 4.5 x并z 生 z

```text
x并z 已形成可被世界辨认、复述和持续指认的身份壳、作品形式或公开界面
→ 认可主体获得稳定的识别对象与归因接口
→ 主体的存在、能力、作品、身份或选择能够被明确指认并确认
→ z 成立或显著上升
```

源端点要求：`x并z` 不是一次换装或醒目包装，而是最低限度稳定的名称、形象、身份、署名、角色、作品形式或公开界面。

目标端点要求：必须说明谁认可、认可谁或什么、认可内容是什么、为何该认可位置重要；曝光、点击、传播、显眼和任务完成不能单独算 `z`。

被改变变量：对象可识别性、认可归因稳定度、认可对象清晰度、主体是否获得可被回应的公开位置、认可关系能否跨时间重复落到同一主体。

两个连续入口：

```text
A 可识别接口：原本边界模糊、难以辨认
→ 名称、形象、形式或公开身份使认可者知道“我看见的是谁／什么”

B 归因稳定：多次内容原本分散在事件或匿名现象上
→ 稳定壳把多次出现组织到同一主体
→ 认可反复归因给同一主体
```

成立阶段：内容、能力或存在已有基础，但认可无法稳定归因；壳先建立并持续使用，认可主体随后通过该壳辨认并确认对象。

排除：广告预算、宣发排期、平台流量、权力强迫、一次华丽换装、无人回应、既有高知名度下的纯美术更新，均不能单独证明本关系。

标准正例：《窈窕淑女》伊莉莎在使馆舞会阶段；蜘蛛侠形成稳定名称、面具与公共身份后；匿名艺术家采用稳定笔名、署名与作品形式后。

### 4.6 x 生 x并z

```text
x 已经取得或扩大对象、资源、地盘、权限或关系的实际掌握
→ 掌握范围需要被世界辨认、调用、代表或保护
→ 主体建立名称、职位、品牌、制服、门面、法人身份或前台角色
→ 实际控制关系获得稳定公开壳
→ x并z 成立或显影上升
```

源端点要求：必须先有具体掌握对象、地盘、权限、资源、人员或关系边界；只有欲望、企图、生存压力或“想得到”不构成 `x`。

目标端点要求：必须形成具有持续性的公开名称、职位、品牌、门面、法人身份、前台角色或其他表里接口；一次换装、临时撒谎和工具性伪造不构成稳定 `x并z`。

被改变变量：掌握关系的对外可识别性、可调用性、可复述性、接口稳定度、内层暴露程度，以及壳能否代表、合法化或保护掌握范围。

两个连续入口：

```text
A 可识别化：实际掌握已有，但外界不知道谁拥有、谁代表、谁有权调用
→ 名称、职位、徽记、品牌或正式身份建立公开界面

B 保护化：实际掌握已有，但完整暴露会威胁控制关系
→ 合法门面、前台角色或社会身份隔离外界与内层控制
```

成立阶段：先有实际掌握；随后出现调用、代表、合法性或暴露问题；主体再建立并认领公开壳，世界开始通过该壳接触掌握范围。

排除：为取得尚未拥有的资源而临时伪造身份、普通换装、演员扮演、纯市场视觉统一、冒充职位获取权限，均不能单独证明本关系；这些更接近 `x并z→x`、`xn` 策略或 `z` 目标推进。

标准正例：《绝命毒师》古斯·弗林在毒品网络成熟后使用餐饮企业与社区领袖形象；统治者取得领地、军队与税权后建立国号、王冠和宫廷身份；黑帮已控制地盘和现金流后经营合法公司作为门面。

## 5. 暂不锁定的关系语义

### 5.1 z 克 nx
几何位置保留。只保留“重要认可使主体重新认领方向位置”的关系层候选，正式机制未锁定。

### 5.2 nx 生 x
旧欲望积累口径撤回。只保留“持续空位被既有掌握边界吸纳”与“默认授权累积为事实控制”两个候选，正式机制未锁定，沿用 `UQ-20260718-003`。

### 5.3 nz 生 nx
关系余温降低独自定向必要感，只是候选；共同时间延长、建议权重上升、共同协商均不等于最终方向让位。正式机制未锁定。

### 5.4 nx 克 x并z
只保留“主体跨阶段不完成认领、复述或背书接口，使身份壳对该主体的吸纳、代表和解释范围下降”的候选。正式机制未锁定。

### 5.5 zx 生 zn
同主体行动自证撤回。只保留跨主体见证内化候选，正式机制未锁定。

### 5.6 zn 生 n
只保留“意义扩大什么必须由我方接住的承接边界”候选，仍不能排除 `zx/xn/x` 中介，沿用 `UQ-20260718-004`。

### 5.7 xz 生 zx
只保留“危险造成决定空位并迫使潜在权能公开”的候选，现有证据更支持显影而非独立生成。

### 5.8 z 生 nz
只保留“认可关系获得时间厚度”与“共同阶段被见证后获得不可替代性”候选，沿用 `UQ-20260718-005`。

### 5.9 xz 克 zn
只保留“无条件原则被压成生存条件”与“原则长期失去最终指导资格”候选；必须排除意义排序、实践通道受压及 `zx/xn/x` 中介。

### 5.10 其他未单独解释关系
未在本页写出机制的关系，只表示几何位置候选。专项索引明确列为 `canonical-current` 时，按专项正本读取；否则不得凭箭头自动生成心理故事。

## 6. 旧语义删除

```text
x = 无形欲望 / 吞噬流
nx 生 x = 压抑欲望后欲望越来越大
幕后操盘 = nx
包装显眼 = z
曝光量上升 = z
想得到资源所以伪造身份 = x 生 x并z
```

正式替换：`x` 是具体掌握边界；`xn` 负责主动组织；`nx` 沿外部方向与关系通道推进；`z` 必须有明确认可主体、认可对象和确认内容；`x 生 x并z` 必须先有实际掌握，再由掌握需要生成公开壳。

## 7. 五大主题

| 五大主题 | 十元构成 | 核心问题 |
|---|---|---|
| 时间 | xn + z | 事物怎样从之前走到之后，什么被积累、点燃或改变？ |
| 本体 | zn + x | 它的精神核心是什么，什么被划入其具体归属与掌握范围？ |
| 空间 | x并z + n | 什么能在哪里存在，形式与承载如何成立？ |
| 因果 | zx + nx | 事情通过直接权能还是既有关系通道被做成，二者如何交替？ |
| 命运 | xz + nz | 漂流、危险与停靠如何收束为最终归宿？ |

主题构成不能反向证明人物十元点位。
