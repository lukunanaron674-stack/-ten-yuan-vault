# 十元生补克表

> 本页是十元生、克、补关系直接正本。几何位置锁定不等于机制锁定；只有本页“已锁定关系语义”或专项索引列为 `canonical-current` 的关系才能正式调用。

## 1. 当前四元召回

```text
x：对象、资源、地盘、权限或关系归我掌握。
zx：主体权能公开显现、扩大，并凌驾于他者之上。
xn：主体主动组织计划、时间、规则、信息和资源，使结构持续运行。
nx：主体不占据方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。
```

## 2. 五组补位

| 几何组 | 当前语义 |
|---|---|
| zx ↔ nx | 直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补 |
| zn ↔ x | zn 为掌握边界提供内部意义方向；x 为意义核心提供具体对象、资源和现实掌握落点 |
| n ↔ x并z | n 为公开壳提供真实可承载的内部；x并z 为承载结构提供可识别、可进入、可持续指认的公共界面 |
| xn ↔ z | xn 为认可提供跨时间、可复核、可重复呈现的证据；z 为长期组织提供明确认可位置、材料筛选标准与阶段收束节点 |
| xz ↔ nz | xz 为关系停靠补入真正失去与错过窗口的风险；nz 为危险路径补入明确回返对象、关系终点与归宿方向 |

## 4. 已锁定关系语义

### 4.1 xn 克 zx

```text
现实已经被时间、规则、流程和前置行动组织
→ zx 的即时显权扩张必须进入既有结构
→ 单次爆发不能直接取消长期积累
```

### 4.2 zx 补 nx / nx 补 zx

```text
zx：直接以主体自己的权能做成。
nx：通过既有身份、关系、权限与通道借力做成。
```

### 4.3 zx 克 n

```text
zx 主体公开显权，直接决定成员资格、接收边界或结构运行条件
→ n 原有的接收、保护、照顾、互信与反复返回能力被迫停止
→ n 的承载能力下降、断裂或失效
```

被改变变量：成员资格、接收边界、保护与照顾连续性、成员互信、反复返回能力、结构抗崩能力。

### 4.4 xn 生 xz

```text
xn 规定正常运行的时间窗、路线和身份接口
→ 主体偏离后，偏差被识别、记录并持续处理
→ 可用安全路径与退路逐步缩窄
→ xz 的临界风险和命运失稳上升
```

被改变变量：偏差识别率、暴露与追踪概率、安全路线数量、可用时间窗、退路宽度、稳定停留可能性。

### 4.5 x并z 生 z

```text
稳定身份壳、作品形式或公开界面形成
→ 认可主体获得可识别对象与归因接口
→ 主体的存在、能力、作品、身份或选择被明确指认和确认
→ z 成立或上升
```

核心变量：对象可识别性、认可归因稳定度、认可对象清晰度。曝光、点击、宣传和一次换装均不足。

### 4.6 x 生 x并z

```text
实际掌握边界已经成立
→ 需要被世界识别、调用、代表或保护
→ 名称、职位、品牌、制服、门面、法人身份或前台角色形成
→ 掌握关系获得稳定公开壳
```

核心变量：掌握边界的对外可识别性、可调用性、接口稳定度、内层暴露程度，以及壳能否代表或保护实际控制范围。

### 4.7 x 克 z

```text
x 主体掌握 z 与重要认可主体发生确认关系所必需的对象、权限、关系入口、署名界面或传播通道
→ x 主体扣留、垄断、改署、隔离或关闭这些接口
→ 认可主体无法看见目标对象，或把对象错误归因给他人
→ z 主体无法在该认可位置获得正确确认
→ z 被克制
```

源端点要求：必须有明确主体实际掌握作品载体、署名权、推荐权、引见关系、发布通道或进入认可场景的权限。

目标端点要求：必须写清认可主体、认可对象、确认内容及该认可位置的重要性。

被改变变量：认可主体接触目标对象的概率、对象能否正确归因、主体能否进入重要认可位置、回应与确认能否发生、确认是否被他人冒领或替换。

两个连续入口：

```text
A 认可入口门控：不引见、不推荐、不展示、不转交，使认可主体看不到对象。
B 归因与署名劫持：对象已被看见，但掌握署名、所有权或解释权，使认可落到别人身上。
```

成立阶段：看见前门控、看见后归因劫持、回应隔离。一般资源不足、作品没完成、自然低曝光、认可主体自己不感兴趣，均不足以证明本关系。

标准正例：《大眼睛》玛格丽特与沃尔特·基恩；《寻梦环游记》赫克托与埃内斯托；编辑掌握发表与署名并把作者降为资料协助。

### 4.8 n 克 xz

```text
n 已形成真实接收、保护、处理与持续维持能力
→ xz 主体进入有效承载范围
→ 危险被结构隔开、吸收或持续处理
→ 主体获得可停留、可补给、可恢复和可返回的位置
→ 不再必须沿风险路径继续移动
→ 危险可到达性、行动紧迫度与漂流强度下降
→ xz 被克制
```

源端点要求：`n` 必须实际接收进入者、提供内部位置、承担保护或补给，并在外部压力下保持一定抗崩能力。房屋、城墙、家庭、医院和避难所只是场景候选。

目标端点要求：`xz` 已出现危险逼近、安全路线减少、无法稳定停留或必须抢最后窗口等可观察临界。

被改变变量：危险可到达性、安全停留时间、继续移动紧迫度、可用退路与安全路径数量、外部冲击直接落到主体的比例，以及主体能否从“通道上的人”变为“内部被接住的人”。

两个连续入口：

```text
A 危险隔离与冲击吸收：承载结构位于危险与主体之间，替主体承担原本会直接落下的冲击。
B 漂流落地与紧迫解除：承载结构提供停留、补给、恢复与返回位置，使主体不再必须抢下一条路线。
```

成立阶段：`xz` 已显形，`n` 已实际运行，主体进入承载范围，危险可到达性或继续移动紧迫度随后下降。

正式排除：签证审核、封路、拘禁、监狱、锁闭与剥夺出口只证明 `xn/x/zx` 或路径封锁；“无法移动”不等于“被接住”。空房子、恋人挽留、暴风自行停止也不足。

标准正例：《最后生还者》乔尔与艾莉进入杰克逊聚落；《行尸走肉》瑞克一行进入亚历山大安全区初期；运行中的灾后避难所接收洪水与失温中的居民。

### 4.9 zn 补 x / x 补 zn

`zn ↔ x` 是本体维度的双向互补，不是生、克，也不是父子派生。

```text
zn 提供“为什么值得掌握、守护、限制或使用”的内部意义方向
+
x 提供“具体什么归我、由我调配、在哪条边界内落实”的现实掌握对象
→ 意义不再悬空，掌握不再只剩占有
→ 形成“我知道为什么守，也确实掌握能够被守住的对象与边界”的本体完整感
```

双向变量必须分开：

```text
zn 补 x：改变掌握用途的方向、守护与放弃标准、否决权服务的原则。
x 补 zn：改变意义的现实落点、可保护与持续投入的对象范围、明确的我方边界。
```

成立条件：`zn` 与 `x` 两端分别真实成立；拿掉任一端，另一端仍存在但出现明确缺口。补位不要求固定先后。

正式排除：信念不会自动制造资源；拥有资源不会自动产生意义；危险、深渊、战乱和受苦不是 `x`；建设完成、获胜、被认可和组织稳定也不是本关系的机械结果。

标准正例：《辛德勒的名单》中辛德勒以工厂、资金、名单和雇佣权落实救人意义；《V字仇杀队》中 V 以影子画廊、档案、广播和行动资源落实自由与反抗意义；掌握档案原件、访问权和备份密钥的家族证词守护者。

### 4.10 n 补 x并z / x并z 补 n

`n ↔ x并z` 是空间维度的双向互补，不是生、克，也不是建筑内外的视觉比喻。

```text
n 为 x并z 提供能够真实接住、容纳、处理并持续存在的内部内容与承载能力
+
x并z 为 n 提供可被世界识别、进入、理解和持续指认的公开界面
→ 公开壳不再空心，真实内部不再不可读
→ 形成“外部可识别、内部真能接住”的完整空间存在
```

双向变量必须分开：

```text
n 补 x并z：改变壳内部是否有真实可承接内容、能否承受人事关系进入、公开承诺与内部实际是否连接。
x并z 补 n：改变外界能否识别和进入承载结构、进入边界是否可理解、内部能否被同一名称和角色持续指认。
```

成立条件：两端至少一端先独立成立；另一端补入后必须改变已有端点的真实缺口。补位不要求固定先后。

正式排除：精装样板间与混凝土楼板、漂亮装修、建筑内外层、姓氏门牌、统一制服、品牌广告和产权挂牌只证明视觉、场景、`xn`、`x` 或 `z` 共现，不自动构成本关系。

标准正例：《千与千寻》千寻进入并工作后的油屋；《布达佩斯大饭店》1932年古斯塔夫管理时期；真实运行的社区匿名互助站获得中性名称、固定标识和保护性前台入口。

### 4.11 xn 补 z / z 补 xn

`xn ↔ z` 是时间维度的双向互补，不是生、克，也不是“准备久了必然获奖”或“被表扬后开始努力”的机械链。

```text
xn 为 z 提供跨时间、可复核、可重复呈现的证据
→ 认可不再只落在一次偶然表现上
+
z 为 xn 提供明确认可主体、认可内容与阶段确认节点
→ 长期组织获得聚焦、材料筛选标准与阶段收束
→ 形成“一次确认具有时间重量，长期积累拥有精神节点”的时间完整感
```

双向变量必须分开：

```text
xn 补 z：改变被认可内容的证据连续性、重复稳定度、可复核材料密度，以及认可者区分运气与稳定能力的能力。
z 补 xn：改变长期组织的聚焦对象、材料筛选标准、阶段收束节点、最终呈现内容与下一周期保留或修正的依据。
```

成立条件：至少一端先独立成立，另一端补入后，原端点的缺口变量发生可观察变化。`xn` 必须是主体主动组织，不是被动遵守课程、制度或截止日期；`z` 必须写清认可主体、认可对象、确认内容及该认可位置的重要性。

正式排除：考试日期、临时熬夜、普通排程、一次称赞、一次夺冠、广告投放、播放量上涨、绩效奖励、宣传曝光和结果完成均不能自动证明本关系。补位不互相生成，也不能由五大主题“时间 = xn + z”反推。

标准正例：《爆裂鼓手》安德鲁在 JVC 音乐节演出前后的长期训练与专业确认；《国王的演讲》乔治六世战时广播前的训练结构与全国广播确认节点；科研人员的长期复现实验与同行答辩。

### 4.12 xz 补 nz / nz 补 xz

`xz ↔ nz` 是命运维度的双向互补，不是相互生成，也不是危险与温情同框后自动成立。

```text
xz 为 nz 提供关系可能真正失去、回返窗口可能关闭的命运压力
→ 已有关系余温不能再无限期停留在模糊惯性
→ 等待、返回或继续保留关系必须被重新选择
+
nz 为 xz 提供明确的关系终点、可回返对象与归宿候选
→ 风险路径从“只要离开危险”变成“我要穿过风险回到那里/那个人”
→ 形成“失去风险使停靠获得选择重量，关系余温使漂流获得方向”的命运完整感
```

双向变量必须分开：

```text
xz 补 nz：改变关系真正失去的可能性、返回窗口有限性、继续等待是否经过风险检验、停靠是否成为主动选择，以及关系余温的命运重量。
nz 补 xz：改变风险路径的方向性、值得返回的关系对象、主体承担穿越风险的理由、漂流能否收束为明确关系终点与归宿候选。
```

成立条件：两端必须分别成立。`nz` 必须已有共同时间、关系余温、不愿结束与可信回返位置；`xz` 必须已有危险逼近、退路或时间窗缩窄和被迫移动。另一端补入后，必须改变已有端点的真实缺口。补位不要求固定先后。

正式排除：避难所收留、治疗、防御和安全停留属于 `n 克 xz`；为了道德原则返回陌生人优先检查 `zn`；追兵逼近后突然告白、普通恋爱依恋、被迫同居、怀念故乡但路径不变、一次获救和危险与暖光同框均不能自动证明本关系。五大主题“命运 = xz + nz”不能反推案例中双向补位已经启动。

标准正例：《最后生还者》乔尔与艾莉在盐湖城前后至最终选择；《星际穿越》库珀与墨菲跨越虫洞至返航阶段；战争撤离中仍为未结束的旧友关系冒险返回旧城的结构例。

### 4.13 n 生 xn

```text
n 已经真实接住并持续处理落到自身的对象或负荷
→ 同类负荷反复进入、并发或持续增加
→ 单次临场处理不足以维持承载
→ 承载主体主动把经验提炼为顺序、分工、记录、节点、资源安排与预案
→ “这次接住了”转成“下次仍能接住”
→ xn 成立或上升
```

源端点要求：对象或问题已经进入主体或结构内部；主体没有立刻推出、转移或拒绝；允许其停留并持续承担其产生的时间、空间、照护、风险或资源负荷。

目标端点要求：主体主动组织处理顺序、时间、分工、信息、记录、资源、节点、复盘或预案。规则存在、照章执行和一次临时协调均不足。

被改变变量：承载事项的处理顺序、负荷分配方式、信息跨轮次保存能力、资源消耗可预判性、再次进入时对临场救火的依赖、人员更替后的持续运行能力，以及单次接住能否转成可重复承载。

两个连续入口：

```text
A 负荷密度组织化：持续接收超过直觉处理能力，迫使主体建立顺序、轮班、资源分配和节点。
B 承载记忆跨轮次保存：反复处理的经验被记录、交接、复盘、训练和预案化，使下一轮不必重新付出同样代价。
```

成立阶段：`n` 先真实运行；负荷重复、并发或持续；临场处理出现遗漏、冲突、浪费或崩溃风险；承载主体主动提炼组织方式；组织跨轮次直接服务于继续承载。

正式排除：家庭自然有家规、医院执行外部规范、公司为利润建立流程、上级命令轮班、仓库有货架编号、一次事故临时分工、被动遵守课程或制度，均不能自动证明 `n 生 xn`。若制度早于承载对象，或启动源是效率、权限、命令与既有组织，优先检查既有 `xn`、`x`、`zx` 或 `nx`。

标准正例：《阿波罗13号》事故后 Gene Kranz 与任务控制中心为持续接住三名宇航员而重组模拟、耗电记录、问题分工与返回节点；《十三条命》确认被困者后，救援共同体因持续承担生存负荷而建立潜水路线、氧气布点、人员轮换与撤离顺序；灾后互助站从临时接收转为登记、床位、药品库存、值班、交接和转介的稳定运行。

## 5. 暂不锁定的关系语义

- `z 克 nx`：只保留“重要认可使主体重新认领方向位置”的关系层候选。
- `nx 生 x`：只保留“持续空位被既有掌握边界吸纳”与“默认授权累积为事实控制”候选，沿用 `UQ-20260718-003`。
- `nz 生 nx`：共同时间延长、建议权重上升、共同协商均不等于最终方向让位。
- `nx 克 x并z`：只保留不完成认领、复述或背书接口，使壳覆盖范围下降的候选。
- `zx 生 zn`：同主体行动自证撤回，只保留跨主体见证内化候选。
- `zn 生 n`：只保留意义扩大承接边界候选，仍不能排除 `zx/xn/x` 中介，沿用 `UQ-20260718-004`。
- `xz 生 zx`：只保留危险造成决定空位并迫使潜在权能公开候选。
- `z 生 nz`：只保留认可关系获得时间厚度、共同阶段被见证候选，沿用 `UQ-20260718-005`。
- `xz 克 zn`：只保留无条件原则被压成生存条件、原则长期失去最终指导资格候选。
