# 十元生补克表

> 本页是十元生、克、补关系的直接正本。几何位置与关系语义分开读取：位置写入表格不等于机制已经通过案例验收。已并入本页的状态补丁不再作为更高优先级覆盖层。

## 1. 当前四元召回

```text
x：对象、资源、地盘、权限或关系归我掌握。
zx：主体权能公开显现、扩大，并凌驾于他者之上。
xn：主体主动组织计划、时间、规则、信息和资源，使结构持续运行。
nx：主体不占据方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。
```

## 2. 五组补位

| 几何组 | 主题 | 当前语义 |
|---|---|---|
| **zx ↔ nx** | 因果 | 直接以主体权能做成，与通过既有关系、身份和权限网络借力做成，构成两条互补办事路径 |
| **zn ↔ x** | 本体 | 精神意义与具体归属、控制边界形成内外本体张力 |
| **n ↔ x并z** | 空间 | 承载结构与可见包装互相提供容器和形式 |
| **xn ↔ z** | 时间 | xn 为 z 提供可累计、可复核、可重复呈现的时间证据；z 为 xn 提供明确认可主体、认可内容与阶段确认节点 |
| **xz ↔ nz** | 命运 | xz 为 nz 补入真正失去的风险；nz 为 xz 补入明确回返对象、归宿候选与风险路径方向 |

补位只表示几何候选。具体案例必须说明双方分别补足什么，不能因人物同时带两个十元就自动宣布互补成立。

## 4. 已锁定关系语义

### 4.1 xn 克 zx

```text
zx 要以主体权能直接进入当下现实
→ xn 已经通过时间、规则、流程和前置行动组织现实
→ zx 的即时扩张必须先进入既有结构
→ 单次爆发不能直接取消长期积累
```

典型场景锚：五行山式长期结构。重点是已经成立且持续运作的规则与时间结构，不是石头重量本身。

### 4.2 zx ↔ nx

```text
zx：直接以自己的权能决定方向、压过对象并做成。
nx：承认外部已有的身份、关系与权限，通过求人、借力、托关系和既有通道做成。
```

互补动态：

```text
直接力量足够
→ zx 直接推进

直接力量不足，或问题属于他者权限
→ nx 进入关系网络求人借力
→ 获得法宝、救兵、许可或信息
→ zx 再次直接行动
```

孙悟空标准案例：齐天大圣公开压过他者是 `zx`；取经途中找菩萨、土地、龙王、天庭借法宝、请救兵是 `nx`。该关系不是“领导与服从”。

## 5. 暂不锁定的关系语义

### 5.1 z 克 nx

几何位置保留。旧“z 持续表达、决定和占位，压缩 nx 选择空间”的解释撤回；持续决定与占位更接近 `zx`、`x` 或外部方向主体。

当前最窄候选：重要认可主体确认主体自己的判断、能力或选择，使外部安排不再是唯一合法方向，主体重新认领方向决定位置。该候选仅限关系层或状态层，正式机制未锁定。

### 5.2 nx 生 x

几何位置保留。旧“压抑欲望后欲望积累成 x”删除，因为现行 `x` 是归属、占有和控制边界。具体人物机制待独立案例重新验收。

### 5.3 nz 生 nx

几何位置保留。当前最窄候选是：已有关系余温与可信回返位置，使主体在该段关系中降低独自定向的必要感，暂时沿关系对象给出的方向继续。稳定人物本体生成不成立，正式机制未锁定。

### 5.4 nx 克 x并z

几何位置保留。最窄候选仅限已经成立、且需要主体持续认领或背书的身份壳；主体持续不认领、不复述、不履行壳要求的位置，使壳对该主体的吸纳、代表与解释接口下降。正式机制未锁定。

### 5.5 zx 生 zn

几何位置保留。同主体“行动自证”撤回。唯一保留的窄候选是跨主体见证内化：甲以 `zx` 把原则推入现实，乙此前没有稳定 `zn`，甲失败、离场或不再奖励乙后，乙仍在逆风与无人监督时坚持同一原则。正式机制未锁定。

### 5.6 zn 生 n

几何位置保留。旧“有了信仰就建教堂”式建筑生成口径撤回。

当前最窄候选：

```text
zn 确认某个人、某件事或某段意义不能被抛下
→ 主体重划什么必须由自己接住
→ 外部对象进入自身承担范围
→ 接收、停留与处理跨时间持续
→ n 的承接边界或承载能力上升
```

当前证据仍不能排除 `zx` 的公开推动、`xn` 的组织维持和 `x` 的资源与准入权限。正式机制未锁定；在具体动态链中必须标为“语义待验收”。

### 5.7 xz 生 zx

几何位置保留。当前最窄候选是：危险使原指挥、规则或等级无法继续提供方向，形成现实决定空位，迫使原本未公开承担决定位置的主体以自身力量公开接管。

现有证据更容易证明潜在 `zx` 被迫显影，尚不能证明 `xz` 独立生成此前不存在的 `zx`。正式机制未锁定；在具体动态链中必须标为“语义待验收”。

### 5.8 z 生 nz

几何位置保留。旧“目标完成、获奖或录取后自然产生留恋”的口径撤回；现行 `z` 必须有明确认可主体、认可对象与确认内容，不能再写成普通完成爆点。

当前保留两种窄候选：

```text
候选A：重要认可主体确认主体
→ 认可者不再只是评判位置
→ 该认可关系获得情感与时间厚度
→ 主体希望关系继续存在
→ nz 的停靠强度上升

候选B：共同作品或能力被重要主体见证
→ “这件事属于我们共同经历”被确认
→ 共同阶段获得不可替代性
→ 主体不愿该阶段结束
```

现有案例均无法排除认可前已经存在的 `nz`、`n` 的长期承载、`xn` 的共同时间与组织、奖励、新身份及转场困难。当前更可靠的结论只是：`z` 可以使既有 `nz` 显影、被命名或获得共同见证；是否能在缺少关系厚度时独立生成 `nz`，证据不足。正式机制未锁定；在具体动态链中必须标为“语义待验收”。

### 5.9 其他未单独解释关系

未在本页写出机制的生、克、补关系，只表示位置候选。使用时必须回到具体案例证明，不得根据几何图自动生成心理故事。

## 6. x 相关旧语义删除

以下旧说法不再进入正式关系解释：

```text
x = 无形欲望 / 吞噬流 / 停下来就不存在
nx 生 x = 压抑欲望后欲望越来越大
zn ↔ x = 精神表达与深层欲望
幕后操盘 = nx
```

正式替换为：

```text
x = 归我掌握的对象、资源、地盘、权限与关系边界。
幕后掌控优先检查 x。
公开显权并凌驾他者优先检查 zx。
主动组织流程和时间优先检查 xn。
沿外部方向与关系通道推进优先检查 nx。
```

## 7. 五大主题

| 五大主题 | 十元构成 | 核心问题 |
|---|---|---|
| 时间 | xn + z | 事物怎样从之前走到之后，什么被积累、点燃或改变？ |
| 本体 | zn + x | 它的精神核心是什么，什么被划入其具体归属与掌握范围？ |
| 空间 | x并z + n | 什么能在哪里存在，形式与承载如何成立？ |
| 因果 | zx + nx | 事情通过直接权能还是既有关系通道被做成，二者如何交替？ |
| 命运 | xz + nz | 漂流、危险与停靠如何收束为最终归宿？ |

主题构成属于高级分析层，不能用来反向证明人物点位。
