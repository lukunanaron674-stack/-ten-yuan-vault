## Ⅲ. 极简星盘应用定理

1. **“克”可以成为故事动力候选，但必须由独立端点和具体机制验证。** `nx克x并z` 已重新确认，但机制不是看穿、清算或反操控，而是拒绝认领包装、拒绝按要求表态，使包装失去共同背书接口。
2. **互补必须双向说明。** `zx↔nx` 的互补不是单向领导：zx提供方向、开路与第一行动；nx提供人际维护、照顾、日常承接和社会支持。
3. **阴阳链与母行先记录几何位置。** 几何生位不自动等于语义上的生成；`nx→x` 是当前明确反例。
4. **人物本体、状态、行为与关系必须分层。** 被照顾后暂时不用决定，不等于人物稳定本体被改造成nx。

## 5. 三母型格式

每条十元线都可按几何位置记录：

```text
主十元 → 所生位 → 所补位
```

展开为：

```text
回收型 = 主十元 → 所生位 → 所补位 → 所生位 → 主十元
崩坏型 = 主十元 → 所生位 → 所补位 → 停
扭曲型 = 主十元 → 所生位 → 所补位 → 新主十元′
```

但运行具体故事前，必须重新审核每条边的语义资格。若某边只有几何位置，没有生成机制，则不得把箭头直接写成动态链中的“生”。
