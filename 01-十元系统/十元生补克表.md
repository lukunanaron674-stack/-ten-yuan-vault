# 十元生补克表

> 本页是十元生、克、补关系的直接正本。几何位置与关系语义分开读取：位置写入表格不等于机制已经通过案例验收。

## 1. 当前四元召回

```text
x：对象、资源、地盘、权限或关系归我掌握。
zx：主体权能公开显现、扩大，并凌驾于他者之上。
xn：主体主动组织计划、时间、规则、信息和资源，使结构持续运行。
nx：主体不占据方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。
```

## 2. 五组补位

| 几何组 | 主题 | 当前语义 |
|---|---|---|
| **zx ↔ nx** | 因果 | 直接以自身权能做成，与通过既有身份、关系、权限和通道借力做成互补 |
| **zn ↔ x** | 本体 | 精神意义与具体归属、控制边界形成内外本体张力 |
| **n ↔ x并z** | 空间 | 承载内部与公开形式互相提供容器和界面 |
| **xn ↔ z** | 时间 | 时间组织提供可累计证据，认可节点提供阶段确认 |
| **xz ↔ nz** | 命运 | 危险补入失去风险，停靠补入回返对象和归宿方向 |

补位只表示几何位置；具体调用仍须检查专项正本。

## 4. 已锁定关系语义

### 4.1 xn 克 zx

```text
现实已经被时间、规则、流程和前置行动组织
→ zx 的即时显权扩张必须进入既有结构
→ 单次爆发不能直接取消长期积累
```

### 4.2 zx 补 nx / nx 补 zx

```text
zx：直接以主体自己的权能做成。
nx：通过既有身份、关系、权限与通道借力做成。
```

### 4.3 zx 克 n

```text
zx 主体公开显权，直接决定成员资格、接收边界或结构运行条件
→ n 原有的接收、保护、照顾、互信与反复返回能力被迫停止
→ n 的承载能力下降、断裂或失效
```

源端点要求：权能公开进入现实，主体直接决定他者位置、资格或行动，且决定具有压过对象的现实效力。

目标端点要求：`n` 已经形成真实接收、保护、照顾、互信、反复返回或持续共同生活的承载结构。

被改变变量：成员资格、接收边界、保护与照顾连续性、成员互信、反复返回能力、结构抗崩能力。

两个正式入口：

```text
A 资格取消：公开宣布某人不再属于共同体
→ n 失去继续接收、保护与照顾该成员的资格

B 运行中断：以命令、惩罚或强制改组压过既有承载结构
→ 原有照顾、互信、分工与返回机制停止
```

排除：只有资源被掌握而没有公开显权时优先检查 `x`；普通暴力、打坏设施、成员自然离开、毕业或合同到期均不能自动判 `zx克n`。

标准正例：管理者公开裁决狱友“已经背叛”并迫使共同体停止接收照顾；家庭首领公开逐出成员并要求其他人停止支持；校长以处分威胁强制拆散已持续运行的互助小组。

## 5. 暂不锁定的关系语义

### 5.1 z 克 nx

几何位置保留。旧“持续表达和占位压缩 nx”的口径撤回；当前只保留“重要认可使主体重新认领方向位置”的关系层候选，正式机制未锁定。

### 5.2 nx 生 x

旧欲望积累口径撤回。当前保留“持续空位被既有掌握边界吸纳”与“默认授权累积为事实控制”两个关系层候选；必须排除职位、制度赋权、正常分工、强迫与主动压位。正式机制未锁定，沿用 `UQ-20260718-003`。

### 5.3 nz 生 nx

当前候选是关系余温降低独自定向必要感，使主体在该段关系中暂时沿对方方向继续。共同时间延长、建议权重上升、共同协商均不等于最终方向让位。正式机制未锁定。

### 5.4 nx 克 x并z

只保留“主体跨阶段不完成认领、复述或背书接口，使身份壳对该主体的吸纳、代表和解释范围下降”的候选。看穿、公开揭露、身份自然失效或资格被剥夺均不能代替本关系。正式机制未锁定。

### 5.5 zx 生 zn

同主体“行动自证”撤回。唯一窄候选是跨主体见证内化：甲以 `zx` 把原则推入现实，乙此前无稳定 `zn`，甲失败、离场或不再奖励后，乙仍在逆风与无人监督时坚持同一原则。正式机制未锁定。

### 5.6 zn 生 n

旧“有了信仰就建教堂”口径撤回。当前候选是意义扩大“什么必须由我方接住”的承接边界，但仍不能排除 `zx/xn/x` 中介。正式机制未锁定，沿用 `UQ-20260718-004`。

### 5.7 xz 生 zx

当前候选是危险使原指挥、规则或等级失效，形成决定空位并迫使潜在权能公开。现有证据更支持显影而非独立生成。正式机制未锁定。

### 5.8 z 生 nz

旧完成、获奖或录取后自然留恋口径撤回。当前只保留“重要认可关系获得时间厚度”与“共同阶段被见证后获得不可替代性”两个候选；现有案例无法排除既有 `nz/n/xn`。正式机制未锁定，沿用 `UQ-20260718-005`。

### 5.9 xz 克 zn

旧混乱或嘲讽摧毁意义口径撤回。当前只保留“无条件原则被压成生存条件”与“原则长期失去最终指导资格”两个候选；必须排除意义排序、实践通道受压及 `zx/xn/x` 中介。正式机制未锁定。

### 5.10 其他未单独解释关系

未在本页写出机制的关系，只表示几何位置候选。若专项正本索引明确列为 `canonical-current`，则按专项正本读取；否则不得凭箭头自动生成心理故事。

## 6. x 相关旧语义删除

```text
x = 无形欲望 / 吞噬流 / 停下来就不存在
nx 生 x = 压抑欲望后欲望越来越大
zn ↔ x = 精神表达与深层欲望
幕后操盘 = nx
```

正式替换为：

```text
x = 归我掌握的对象、资源、地盘、权限与关系边界。
幕后掌控优先检查 x。
公开显权并凌驾他者优先检查 zx。
主动组织流程和时间优先检查 xn。
沿外部方向与关系通道推进优先检查 nx。
```

## 7. 五大主题

| 五大主题 | 十元构成 | 核心问题 |
|---|---|---|
| 时间 | xn + z | 事物怎样从之前走到之后，什么被积累、点燃或改变？ |
| 本体 | zn + x | 它的精神核心是什么，什么被划入其具体归属与掌握范围？ |
| 空间 | x并z + n | 什么能在哪里存在，形式与承载如何成立？ |
| 因果 | zx + nx | 事情通过直接权能还是既有关系通道被做成，二者如何交替？ |
| 命运 | xz + nz | 漂流、危险与停靠如何收束为最终归宿？ |

主题构成不能反向证明人物十元点位。

## 9. 调用纪律

每次关系调用必须标明：分析对象、对象层、具体阶段、源端点、目标端点、机制、被改变变量、第三因素、拿掉测试、反向测试、证据与反例。

固定位置不等于同框成立；专项索引列为 `canonical-current` 的关系高于旧词典和旧案例短句。
