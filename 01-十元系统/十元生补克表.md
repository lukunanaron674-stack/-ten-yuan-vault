# 十元生补克表

> 本页只保留现行十元点位、几何关系与已经通过案例验收的关系语义。旧解释若与当前信息量卡冲突，直接删除，不再用“覆盖补丁”并存。

## 1. 当前四元召回

```text
x：对象、资源、地盘、权限或关系归我掌握。
zx：主体权能公开显现、扩大，并凌驾于他者之上。
xn：主体主动组织计划、时间、规则、信息和资源，使结构持续运行。
nx：主体不占据方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进。
```

## 2. 五组补位

| 几何组 | 主题 | 当前语义 |
|---|---|---|
| **zx ↔ nx** | 因果 | 直接以主体权能做成，与通过既有关系、身份和权限网络借力做成，构成两条互补办事路径 |
| **zn ↔ x** | 本体 | 精神意义与具体归属、控制边界形成内外本体张力 |
| **n ↔ x并z** | 空间 | 承载结构与可见包装互相提供容器和形式 |
| **xn ↔ z** | 时间 | xn 为 z 提供可累计、可复核、可重复呈现的时间证据；z 为 xn 提供明确认可主体、认可内容与阶段确认节点，使长期组织能够聚焦、收束并进入下一轮 |
| **xz ↔ nz** | 命运 | xz 为 nz 补入关系真正失去的风险与停靠必须再次选择的重量；nz 为 xz 补入明确回返对象、归宿候选与风险路径方向，使漂流不再只是继续逃离 |

补位只表示几何候选。具体案例必须说明双方分别补足什么，不能因人物同时带两个十元就自动宣布互补成立。

## 4. 已锁定关系语义

### 4.1 xn 克 zx

```text
zx 要以主体权能直接进入当下现实
→ xn 已经通过时间、规则、流程和前置行动组织现实
→ zx 的即时扩张必须先进入既有结构
→ 单次爆发不能直接取消长期积累
```

典型场景锚：五行山式长期结构。重点是已经成立且持续运作的规则与时间结构，不是石头重量本身。

### 4.2 zx ↔ nx

当前正式解释：

```text
zx：直接以自己的权能决定方向、压过对象并做成。
nx：承认外部已有的身份、关系与权限，通过求人、借力、托关系和既有通道做成。
```

互补动态：

```text
直接力量足够
→ zx 直接推进

直接力量不足，或问题属于他者权限
→ nx 进入关系网络求人借力
→ 获得法宝、救兵、许可或信息
→ zx 再次直接行动
```

孙悟空标准案例：

```text
齐天大圣骑到所有人头上的无敌之姿：zx。
取经途中找菩萨、土地、龙王、天庭，借法宝、请救兵：nx。
```

该关系不是“领导与服从”，也不是“zx负责开口、nx负责长期照顾”这一种固定剧本。

## 5. 暂不锁定的关系语义

### 5.1 z 克 nx

几何位置继续保留：

```text
z 克 nx
```

旧解释“z 持续表达、决定和占位，压缩 nx 的选择空间”已经撤回，因为现行 z 的本体是认可主体看见、回应并确认主体的存在、能力或价值；持续决定、占位和压退他者更接近 zx、x 或外部方向主体。

当前最窄候选：

```text
重要认可主体确认主体自己的判断、能力或选择
→ 外部安排不再是唯一合法方向
→ 主体重新认领方向决定位置
→ nx 下降
```

当前状态：

```text
几何位置保留
旧占位机制撤回正式资格
新候选仅限关系层 / 状态层
正式机制未锁定
```

在取得两个能够排除 n、xn、x 与既有自主性的纯人物案例前，不得把该候选写成正式机制。专项审计见：`01-十元系统/关系专项/z克nx_现行认可端点与旧占位口径冲突审计_20260720.md`。

### 5.2 nx 生 x

几何位置继续保留：

```text
nx 生 x
```

旧解释“nx 压抑欲望，使未满足欲望积累成 x”已经删除，因为 x 的当前本体不是无方向欲望，而是归属、占有和控制边界。

当前状态：

```text
几何位置保留
具体人物机制待独立案例重新验收
不得继续引用“欲望积累”作为正式答案
```

在新机制通过正例、反例、拿掉测试和最近邻排除前，不擅自补写。

### 5.3 nz 生 nx

几何位置继续保留：

```text
nz 生 nx
```

旧表述“nz 以温柔、靠近、照顾和可停靠位置进入关系，使 nx 暂时不必决定”不再列入已锁定关系语义。该表述混合了 `n` 的现实接住、关系对象主动领路、身份义务和既有 nx，现有案例不足以证明 nz 是独立生成源。

当前最窄候选：

```text
已有关系余温与可信回返位置
→ 主体在该段关系中降低独自定向的必要感
→ 暂时沿关系对象已经给出的方向继续
→ nx 的状态 / 关系功能上升
```

当前状态：

```text
几何位置保留
稳定人物本体生成不成立
窄候选仅限关系层 / 状态层
正式机制未锁定
```

必须排除 `n` 的照护承载、`z/zx` 的主动领路、`x/xn` 的身份与权限结构、年龄监护关系和主体原有 nx。专项审计见：`01-十元系统/关系专项/nz生nx_柔情停靠是否降低方向认领机制审计_20260719.md`。

### 5.4 nx 克 x并z

几何位置继续保留：

```text
nx 克 x并z
```

生补克表 v2.4 曾把三行短机制列入“已锁定关系语义”，但现行专项审计与 current-patch 已确认：两个具体人物候选均未通过全部拿掉测试，正式机制未锁定。旧锁定资格现正式撤回。

当前最窄候选：

```text
已经成立、且需要主体持续认领或背书的身份壳
→ nx 主体行动上仍可沿既有方向推进
→ 但持续不认领、不复述、不履行壳要求的身份位置
→ 壳无法把该主体稳定纳入共同说法
→ x并z 对该主体的吸纳、代表与解释接口下降
```

当前状态：

```text
几何位置保留
最窄候选仅限关系层 / 状态层
必须区分“壳尚未生成”与“已成立后被克制”
候选A与候选B是否只是不同体量仍未验收
正式机制未锁定
```

在取得两个能够排除主动揭露、价值拒绝、外部证据、强迫与主动拆壳的具体人物案例前，不得按正式机制调用。专项 current-patch 见：`01-十元系统/关系专项/nx克x并z_已锁定状态撤回与接口候选保留补丁_20260720.md`。

### 5.5 zx 生 zn

几何位置继续保留：

```text
zx 生 zn
```

旧同主体口径“主体先公开显权、做成或获胜，再由行动证明自己的意义”正式撤回。现行 `zn` 不依赖胜利、成功或外部证明；若人物必须先赢一次才相信自己，优先检查 `z` 的结果确认、`x并z` 的身份认领或普通自我效能。

当前唯一保留的窄候选是跨主体见证内化：

```text
甲先以 zx 把原则公开推入现实
→ 乙此前没有稳定 zn
→ 甲失败、离场或不再奖励乙
→ 乙仍在逆风与无人监督时坚持同一原则
→ 原则从“他的”变成“我的”
```

当前状态：

```text
几何位置保留
同主体“行动自证”撤回正式资格
跨主体“原则从他的变成我的”保留为唯一窄候选
源与目标通常必须分属不同主体
正式机制未锁定
```

必须排除英雄崇拜、胜方追随、`z` 的认可、`x并z` 的英雄身份、`n` 的纪念承载、`xn` 的教育传播、`nx` 的跟随，以及乙原本已经存在的 `zn`。在取得两个满足“英雄离场、无奖励、逆风坚持、原则与英雄个人分离”的具体人物案例前，不得把该箭头作为正式动态链机制调用。专项审计见：`01-十元系统/关系专项/zx生zn_跨主体见证内化是否成立二次审计_20260720.md`。

### 5.6 其他未单独解释关系

未在本页写出机制的生、克、补关系，只表示位置候选。使用时必须回到具体案例证明，不得根据几何图自动生成心理故事。

## 6. x 相关旧语义删除

以下旧说法不再出现在正式关系解释中：

```text
x = 无形欲望 / 吞噬流 / 停下来就不存在
nx 生 x = 压抑欲望后欲望越来越大
zn ↔ x = 精神表达与深层欲望
幕后操盘 = nx
```

正式替换为：

```text
x = 归我掌握的对象、资源、地盘、权限与关系边界。
幕后掌控优先检查 x。
公开显权并凌驾他者优先检查 zx。
主动组织流程和时间优先检查 xn。
沿外部方向与关系通道推进优先检查 nx。
```

## 7. 五大主题

| 五大主题 | 十元构成 | 核心问题 |
|---|---|---|
| 时间 | xn + z | 事物怎样从之前走到之后，什么被积累、点燃或改变？ |
| 本体 | zn + x | 它的精神核心是什么，什么被划入其具体归属与掌握范围？ |
| 空间 | x并z + n | 什么能在哪里存在，形式与承载如何成立？ |
| 因果 | zx + nx | 事情通过直接权能还是既有关系通道被做成，二者如何交替？ |
| 命运 | xz + nz | 漂流、危险与停靠如何收束为最终归宿？ |

主题构成属于高级分析层，不能用来反向证明人物点位。

## 9. 调用纪律

每次使用关系必须标明：

```text

源端点与目标端点
```

固定位置不等于同框即成立。没有可观察作用机制时，只能写候选关系。
