# 十元生补克表

本页用于锁定十元之间的生位、补位、克位。后续动态链分析必须先检查：

```text
直连 / 桥接 / 污染桥
```

不能默认 zn 起手，不能默认 n 承载，不能用五维反推十元本体。

## 1. 五大主题

| 五大主题 | 十元组合 | 核心问题 |
|---|---|---|
| 时间 | xn+z | 变化、等待、回望、阶段、错过 |
| 本体 | zn+x | 我是谁、靠什么活着、核心如何被冲击 |
| 空间 | x并z+n | 能否进入、停留、承载、被组织 |
| 因果 | zx+nx | 选择如何触发，代价如何返回 |
| 命运 | xz+nz | 相遇、错过、漂流、停靠、归宿 |

## 2. 补位关系

补位按五维互补固定：

| 十元 | 补位 |
|---|---|
| zx | nx |
| nx | zx |
| zn | x |
| x | zn |
| n | x并z |
| x并z | n |
| xn | z |
| z | xn |
| xz | nz |
| nz | xz |

## 3. 克位关系

| 十元 | 克制 |
|---|---|
| zx | n |
| n | xz |
| xz | zn |
| zn | xn |
| xn | zx |
| nx | x并z |
| x并z | nz |
| nz | x |
| x | z |
| z | nx |

## 4. 当前母行生位口径

> 注意：此处“生位”按当前母行取边口径归档，不等同于传统五行顺生闭环。若位置盘后续修正，以最新版本为准。

| 主十元 | 生位 | 补位 | 三点母行 |
|---|---|---|---|
| zn | n | x | zn→n→x |
| xz | xn | nz | xz→xn→nz |
| zx | zn | nx | zx→zn→nx |
| nx | x | zx | nx→x→zx |
| n | xn | x并z | n→xn→x并z |
| x并z | z | n | x并z→z→n |
| xn | xz | z | xn→xz→z |
| z | nz | xn | z→nz→xn |
| x | x并z | zn | x→x并z→zn |
| nz | z | xz | nz→z→xz |

## 5. 三母型格式

每条十元线都按：

```text
主十元 → 所生位 → 所补位
```

展开为：

```text
回收型 = 主十元 → 所生位 → 所补位 → 所生位 → 主十元
崩坏型 = 主十元 → 所生位 → 所补位 → 停
扭曲型 = 主十元 → 所生位 → 所补位 → 新主十元′
```

## 6. 已确认例子

### zn 线

```text
zn回收型：zn→n→x→n→zn
zn崩坏型：zn→n→x→停
zn扭曲型：zn→n→x→新zn′
```

### xz 线

```text
xz回收型：xz→xn→nz→xn→xz
xz崩坏型：xz→xn→nz→停
xz扭曲型：xz→xn→nz→新xz′
```

## 7. 审稿红线

- 不默认 zn 起手。
- 不默认 n 承载。
- 不把五维主轴当十元起手。
- 不用视觉强度反推本体。
- 不用结局倒推动态链起手。
- 无直连关系先判断桥接是否污染。
