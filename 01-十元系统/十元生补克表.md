# 十元生补克表

> **2026-07-16 nx关系校准：** 当前 nx 是不主动占据选择、方向和位置，并顺着已有安排继续。“把自己让没”是 z 长期克 nx 后的极端结果。已确认：`nx生x`、`nz生nx`、`nx克x并z`、`z克nx`、`zx↔nx互补`。其中 `nx生x` 不表示从无到有地创造 x，而表示促使原本存在的 x 积累、扩大和增长。所有暗算、账本、风控、幕后操盘、结算者与阴险设计解释继续作废。

本页记录十元之间的几何生位、补位、克位以及已经校准的关系语义。具体案例调用前必须检查：


| 星盘几何组 | 对应主题 | 当前叙事语义 |
|---|---|---|
| **zx ↔ nx** | 因果 | zx 提供方向、开路与第一次行动；nx 提供人际维护、日常照顾、社会资源与关系缓冲。不是单向领导—服从 |

```text
生：z
```

`nx 克 x并z` 已确认：

```text
x并z 要求对方认领包装、身份、立场或公开说法
→ nx 不接、不认领、不替对方复述，也不按要求表态
→ x并z 失去共同背书和把 nx 纳入包装叙事的接口
```

nx 可能在行动上暂时被带着走，但不等于认可包装或完成立场表演。

2026-07-17 用户确认的案例边界：

```text
温和、无欺骗性的生活外壳与真实生活容器，判为 n，不判为 x并z。
x并z 可以通过包装、公开说法或表里张力，反衬 n 的真实承载。
反衬关系不等于案例内 n 与 x并z 已启动互补。
不能因为对象有名称、边界、审美或“家”的外观，就把 n 升格或改判为 x并z。
```


#### nx 生 x：促长既有 x，而非从无到有

```text
人物原本已有 x
→ nx 不主动为自身欲望占据选择、表达和行动位置
→ 欲望长期得不到实现、处理或公开承认
→ 未满足的欲望持续积累
→ x 的体量、压力或占位规模增长
```

因此：

```text
nx 不创造原本不存在的 x；
nx 会促使原本存在的 x 增长。
```

T / M 必须分开：

```text
x 的 T 可以持续增长；
由于 nx 不主动表达，x 的 M 仍可能长期偏低；
条件变化后，x 的 M 才可能突然升高。
```

```text
此前没有表现 ≠ x 不存在；
后期强烈显影 ≠ 后期才生成；
nx 生 x = 促长既有 x。
```

#### nx 克 x并z

```text
拒绝认领包装；
拒绝按要求表态；
不给包装提供共同背书接口。
```

#### nx 被 z 克

```text
z 持续决定和占位，nx 不主动夺回位置；
长期高作用量下可能发展为“把自己让没”。
```

#### nx 与 zx 互补

```text
zx 提供共同事项的方向和开路；
nx 提供人际照顾、关系维持、日常承接和社会支持。
```

共同事项由 zx 带方向，不等于 nx 只会服从，也不等于 nx 没有自己的事情。

## Ⅲ. 五大主题

| 五大主题 | 十元构成 | 核心问题 |

| 时间 | xn + z | 事物怎样从之前走到之后，什么被改变或保留？ |

主题构成属于高级主题生成系统，不得把人物同时具有两个十元直接写成主题生成事件。

## Ⅴ. 动态链调用纪律

每条关系在具体案例中仍需冻结：

```text
源端点；
目标端点；
人物本体、状态或行为层；
具体阶段；

被改变的目标变量；
```

固定关系语义不等于同框就自动启动。

尤其：

```text

```
