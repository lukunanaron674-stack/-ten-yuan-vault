# 001 — 概念的定义（内涵与外延）

> **元问题**：当我们说一个"概念"时，到底在说什么？它是认知单元？是知识骨架？还是纯粹的语言游戏？

---

## 一、十元定位

| 字段 | 内容 |
|------|------|
| **十元位置** | **zx（阳木·突破者）** |
| **定位理由** | 概念的本质不是静态容器，而是 **z（执念焦点）切分 x（现象集合）** 的突破行为——心灵先有执着，再拿这个执着去切割世界、定义边界。这正好是 zx（因果主题·突破开局）的核心动作：先动手，先切分，开第一条线 |
| **见前身** | 概念在成为符号之前是 **z 执念**（某种不得不切的冲动），落稳之后才进入 zn（精神表达）和 n（承载结构） |

### 十元位置图解

```text
    z（执念）—— 概念的源动力：不可还原的切割冲动
     │
   zx（突破）← 概念的核心动作位置
     │
     ↓
    x（现象）—— 概念的对象：被切分的世界质料
```

### 第二落脚域

| 次要落脚 | 理由 |
|----------|------|
| **zn**（阳火·精神表达） | 概念成型后成为精神个体的认知工具，参与"我是谁"的本体构建 |
| **xn**（阳金·秩序维护） | 概念沉淀为术语后，又反过来约束新的切割行为（规训机制） |

## 二、生克补关系（只写实际存在的）

### 生（顺生）—— 概念向谁生长

| 链向 | 方向 |
|------|------|
| **→ zn（阳火）** | 概念切分成功后，滋养精神个体，成为认知框架——"我懂了" |

**解释**：概念的定义动作完成（zx 突破）后，自然顺位于 zn 阳火位，为精神表达提供燃料。先切割才有语言，有语言才有表达。

### 克（逆克）—— 概念克制谁

| 链向 | 方向 |
|------|------|
| **→ n（阳土）** | 概念突破既有结构，颠覆旧的稳定秩序——"新概念推翻旧范式" |

**解释**：zx 天生克 n。新概念的定义就是对旧分类体系（n 的承载结构）的一次推倒重建。

### 被克（谁克制概念）

| 链向 | 方向 |
|------|------|
| **xn（阳金）→** | 旧制度、已有术语体系会反向约束概念的产生——"这不符合规范" |

**解释**：xn 阳金（规则/制度）克制 zx 阳木（突破）。概念定义不能无限自由，必须在已有语言结构中展开。

### 补（灵魂对子）

| 链向 | 解释 |
|------|------|
| **↔ nx（阴金·算计者）** | 概念的定义（zx 突破）需要 **逻辑自洽的自我结算**（nx 暗算检验）来确认边界不矛盾 |

**解释**：zx 的补位是 nx。一个概念有没有"内爆"——它的内涵和外延是否自洽——需要 nx 的结算检验。没有 nx 清算的概念是伪概念。

### 不存在的生克补

- **概念不被 XZ 生**（XZ 的危险感知是衍生的，不是概念之源）
- **概念不直接克 x**（zx 切的是 x 但"克"在十元体系中特指顺天克地的网格位置，不是切分行为本身）
- **概念与 xz/nz 无关**（命运主题不是概念定义的必要维度）

## 四、经典概念定义（原版核心）

### 4.1 逻辑学传统（亚里士多德—康德）

- **内涵（Intension）**：概念的核心属性总和，即"什么是 X"的充要条件。例如"人"的内涵 = 理性动物。
- **外延（Extension）**：概念覆盖的全体对象，即"哪些是 X"的边界。例如"人"的外延 = 苏格拉底、孔子、我、你……
- **概念** = 内涵 + 外延 的不可分割对偶体。

### 4.2 十元对经典的不满

| 经典断言 | 隐含问题 | 十元再诊断 |
|----------|---------|-----------|
| 概念有明确边界 | 现实事物边界模糊（好/坏、喜欢/中立/讨厌） | 真概念是 **z（执念焦点）** 切分 **x（现象集合）**，不是归纳 |
| 概念是静态的"容器" | 大部分真实概念随语境变化含义 | 概念在 **位置关系网络** 中更新，而非在字典中固定 |
| 存在"原子概念"作为基础 | 如"存在"其实是 z（不能被 x 事物穷尽） | 最小单元是 **关系** 而非 **实体** |

### 4.3 现代语言学转向

- **索绪尔**：符号的意义来自它在系统中的位置（差异而非实指）
- **维特根斯坦**：概念是"家族相似"，而非共享本质
- **十元截断**：家族相似说对了"无单一本质"，但放弃了"结构约束"——十元用 **位置关系网络** 代替本质，但仍保持结构刚性

### 4.4 经典例子的十元再表达

| 经典例子 | 经典理解 | 十元再表达 |
|----------|---------|-----------|
| **"人"** | 内涵=理性动物，外延=孔子/苏格拉底/你/我 | **zx 突破**：z（"必须区分人与非人"的执念）切分 x（高智能生物集合），锁在 zn 精神表达中<br>**生**：→ zn（认知框架）<br>**克**：→ n（颠覆动物分类体系）<br>**被克**：xn（已有术语体系的约束） |
| **"爱"** | 内涵=依恋+利他，外延=所有亲密关系 | **zx 突破**：z（"这不同于单纯的合作/欲望"的切割冲动）切分 x（可观察的亲密行为）<br>但"爱"在十元中更准确的定位是 **nz（柔情）**而非概念本身 |
| **"游戏"** | 维特根斯坦认为无法给出单一共同本质 | 十元定位：**zn 克 xn** 这一位置关系投射到活动领域的产物<br>游戏 = 精神个体（zn）对规则（xn）的戏弄与超越<br>概念定义卡只负责捕捉这个结构，具体展开见后续卡 |
| **"正义"** | 柏拉图：给每个人应得的——但什么是"应得"？ | **zx 突破**：z（"不公平！"的执念嘶喊）切分 x（社会资源分配现象）<br>真正的发力点在 **zn（精神个体的愤怒）**→ zx（切割动作）|

## 五、概念定义的十元定理

**定理 1**：真概念不是归纳结果，是 **z 切分 x** 的产物。概念清晰度 = 执念纯度 × 现象覆盖的匹配度。

**定理 2**：概念定义三阶递补——
1. 穷极 x 边界不够，必须找到 z 执念；
2. 找到 z 还不够，必须定位它在位置关系网络中的锚；
3. 定位锚还不够，还要看它生谁、被谁生、克谁、被谁克。

**定理 3**：概念争议的本质不是 x 层面的归类精度问题，而是 **不同 z 在争夺同一组 x 的解释权**。两个定义者各自的起手十元不同，永远无法单纯通过扩展现象覆盖来达成共识。

## 六、💡 亮点（概念层面的核心洞见）

1. **概念 = zx（突破）**：不是内涵+外延的平面对偶，而是 z 切分 x 的裂行为
2. **伪概念生成机制**：跳过位置关系直接定义（只给 x 层描述，找不到 z 执念，也不定位十元锚）= 制造伪概念
3. **十元诊断**：维特根斯坦的"家族相似"说对了"没有单一本质"，但十元补充了"有结构约束"——位置关系网络就是那个约束
4. **反直觉结论**：概念争议是好事——说明多个 z 在同一个 x 域上竞争，这是理论活的标志
5. **元工具属性**：本卡定义的定义方法——[十元定位] + [生克补] + [体量]——是后续所有原子卡的检查清单

## 七、🏷️ 五大主题定位

| 主题 | 与本概念的关系 | 理由 |
|------|---------------|------|
| **因果（zx + nx）** | **主要居所** | 概念是"切割→分类→因果推理"的开端，zx 是突破者，属于因果主题的核心 |
| **本体（zn + x）** | **次居所** | 概念成型后成为精神个体的认知工具（zn），但这不是定义动作本身的位置 |
| **时间（xn + z）** | **关联** | 概念随语境漂移的本质是时间要素——同一概念在不同文明中的 z 执念层面会偏转 |
| **空间（x并z + n）** | **弱关联** | 概念在不同系统（行业、文化、学科）中的位置不同，属于次生效应 |
| **命运（xz + nz）** | **极弱关联** | 概念本身不与命运相关，除非被定义的概念就是"命运"本身 |

## 八、概念定义检查清单（元工具）

写任何新概念定义时，用此清单检查：

- [x] **十元定位** —— 该概念落在哪个十元位置？起手是什么？
- [x] **生克补** —— 只写实际存在的生/克/补，不编造全链
- [x] **体量** —— 范围/强度/寿命/空间覆盖四维评定
- [x] **z 执念** —— 找到了吗？谁的什么执着在切分这个 x 域？
- [x] **x 边界** —— 现象层覆盖够吗？典型例子有了吗？
- [x] **不回避** —— 经典理论在此概念上的遗留张力有没有被触及？
