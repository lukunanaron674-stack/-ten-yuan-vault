# 【xz 信息量卡 v1】

---

## 1. 核心本体（主骨）

**临界行动 + 风险路径 + 来不及**

xz不是"危险/黑暗"的笼统概念。它的核心是**临界感**——处于边缘、被风险推着行动、总在"再慢一步就错过/被吞掉/出不去"的时态里。

主骨公式：
```
xz = 被命运推到临界点的人，必须在风险路径上行动，没有后退选项
```

---

## 2. 第一体感

> 不是恐怖，不是黑暗，不是惨。
> 而是**"再慢一步就来不及了"**。

- ❌ 误：xz = 恐怖片、黑暗感、废墟、怪物
- ✅ 正：xz = 边缘奔跑感、来得及但差一点、命运临界线

---

## 3. 人物层

| 面向 | 描述 |
|:----|:-----|
| 核心性格 | 警觉、敏感、反应快、无法稳定停留 |
| 角色类型 | 逃亡者 / 猎手 / 失位少年 / 被时代推着走的人 / 站台边缘的人 |
| 灵魂问题 | "为什么总在不能停靠的边缘？" |
| 错误标签 | ❌ 不是"惨的人"——xz人物的核心不是承受苦难，而是**被风险推动不能停** |

**典型角色示意**：
- 车站月台上等候却一直上不去车的人
- 在边界线上奔跑、回头就是追兵的人
- 必须在规定时间内完成某事、否则一切崩塌的人

---

## 4. 行为层

| 行为类型 | 具体表现 |
|:--------|:---------|
| 逃离 | 逃避追踪、逃离危险场景、离开无法停留的地方 |
| 追逐 | 赶末班车、追赶机会、追赶最后窗口 |
| 冒险 | 横穿危险地带、抄近路、以风险换时间 |
| 临界选择 | 必须在短时间内在两个坏选项之间选一个 |
| 抢先行动 | 不等、不犹豫、先跑再说 |

**行为特征对比**：
- xz的行动 ≠ zx（执行即意义）—— xz行动是因为**不行动就会被吞**
- xz的逃离 ≠ x（求生本能）—— xz逃离是因为**命运齿轮在转，不停就会被碾**
- xz的冒险 ≠ z（想被看见）—— xz冒险没有观众，是**独自临界**

---

## 5. 空间层

xz成立的场所，都是**边缘性的、有路径感、有时间压迫感的空间**：

| 空间类型 | 示例 |
|:--------|:-----|
| 临界边界 | 国境线、悬崖边、屋顶边缘、铁轨旁 |
| 过渡空间 | 渡口、站台、候车室、检票口、走廊、隧道 |
| 逃生路径 | 逃生通道、下水道、天桥、秘密通道 |
| 危险场所 | 雨夜街口、暴风中心、战争前线的暂时安全区 |
| 漂流空间 | 列车、渡船、临时住所、旅馆 |
| 时间边缘 | 末班车、最后几分钟、截止时间、倒计时场景 |

**关键规则**：xz空间必须有**路径的通过性**——不是封闭的空间（那不是xz），而是有出口有入口、正在穿行的地方。

- ✅ 渡口（xz） — 从一边到另一边，不上岸就还在漂流
- ❌ 废墟（不是xz） — 废墟可以是任何十元的场景，不具有临界行动性

## 6. 视觉层

| 视觉要素 | 特征 |
|:--------|:-----|
| 色彩 | 冷色为主（蓝灰/青/冷白），局部暖色只出现在关键瞬间 |
| 光线 | 逆光 / 切线光 / 闪断光 / 路灯下的分割光 |
| 构图 | 倾斜构图 / 对角线分割 / 画面边缘留白（路径感） |
| 形状 | 硬边 / 切割线 / 尖角 / 不完整形状 |
| 质感 | 风损 / 雨痕 / 磨损边缘 / 半湿状态 |
| 运动感 | 速度线 / 残影 / 模糊边缘 / 断裂的笔画 |
| 天气 | 雨 / 风 / 雾（能见度降低+边界模糊） |
| 标志物 | 列车轨道 / 分岔路 / 断桥 / 打开的伞 / 飞扬的衣角 |

**视觉语言一句话**：xz的视觉是"**试图抓住但抓不住**"的形态。

---

## 7. 叙事层

xz在故事中的常见叙事功能：

| 叙事功能 | 描述 |
|:--------|:-----|
| 遭遇 | 让角色与其他力量在临界点相遇 |
| 追逐 | 推动叙事动力的核心——倒计时感 |
| 错过 | xz+nz的常见结果：停靠失败，继续漂流 |
| 被迫继续 | xz角色的叙事终点不是胜利，而是**被迫进入下一段旅程** |
| 命运推送 | 事件不是角色主动选择的，是被命运的临界力量推入的 |

**叙事节奏特征**：xz的叙事是**短促 + 急迫 + 不停歇**的——
- 没有回头路
- 没有喘息窗口
- 每个场景结尾都是"必须走，现在"

---

## 8. 常见互补（对子关系）

| 互补对 | 含义 | 典型效果 |
|:-------|:-----|:---------|
| **xz + nz** | 命运型·漂流+停靠 | 命运主题核心对子——漂流者寻找停靠，停靠着等待 |
| **xz + n** | 漂流+承载 | 危险进入承载结构——临时小屋成了最后一站 |
| **xz + x** | 漂流+欲望 | 危险被欲望污染——从临界逃亡变成猎杀 |
| **xz + xn** | 漂流+规则 | 临界行动被规则捕获——逃犯被法律追到 |
| **xz + z** | 漂流+执念 | 被迫逃跑的人突然有了想追的光 |

**对应五大主题**：xz+nz = **命运型**（主）

---

## 9. 常见污染（被其他十元侵蚀变味）

| 污染形态 | 变成什么 | 判断方法 |
|:---------|:---------|:---------|
| **xz被x污染** | 从危险漂流变成欲望猎杀 | 角色开始享受危险，追逐不是为了逃而是为了吞 |
| **xz被nx污染** | 从临界行动变成暗账结算 | 角色的临界行动不是被迫而是算好的棋 |
| **xz被nz污染** | 从漂流变成软柔情 | 临界感消失，变成"舍不得走"而不是"不得不走" |
| **xz被z污染** | 从临界变成表演 | 危险变成了秀，不再是被迫而成为主动追逐追光 |

**反向污染**：其他十元被xz侵蚀
- **nz被xz污染** — 停靠变成了不得已的临界站，等待变成煎熬
- **z被xz污染** — 追光变成了逃命，舞台变成了断崖

---

## 10. 禁止误判（核心防线）

**以下这些看起来像xz，但实际不是xz——必须有"临界行动感"才是xz。**

| ❌ 误判 | ❌ 误判原因 | ✅ 正确归属 |
|:-------|:-----------|:-----------|
| 恐怖/黑暗感 | 恐怖不等于临界行动 | 不一定是十元，或是x的场景接口 |
| 废墟 | 废墟没有"行动通过性" | 空间接口，任何十元都可能出现 |
| 怪物 | 怪物是实体不是"临界路径" | x（欲望实体）或功能角色 |
| 黑暗角色 | 黑暗是色彩，不是灵魂 | 视情况判断 |
| "很惨"/"不幸" | 承受苦难不是xz的职业 | n（承载）或 故事设定 |
| 流浪汉 | 流浪= nx+xz 混合态 | 纯xz必须有风险路径，不只是无家可归 |
| 死亡/毁灭 | 终点不是xz | x（死亡作为终点）或 nx（死亡作为结算） |
| 孤独 | 孤独可以是许多十元的状态 | nz（等一个人）或 zn（无人理解的意义） |

**一句话防误判**：
> 如果去掉"临界行动/危险路径/来不及"这三个要素，角色或场景还像xz——那它一定不是xz。

## 附录B：创作版快捷入口（7-8级信息量）

```
xz角色设计：
- 不是单纯黑暗，而是"被风险推着行动的人"
- 身上要有路径感、逃离感、未抵达感、临界感
- 衣服：切割边、斜向结构、轻装、风损、雨痕、局部破损
- 武器：快速、危险、短促、可撤离（匕首/弓箭/投掷物）
- 色彩：冷色+逆光切割
- 构图：倾斜/对角线/画面边缘留白

xz场景设计：
- 渡口/断桥/边境线/末班车站台/逃生通道
- 雨/风/雾/冷光
- 必须有"通过性"——不是封闭空间

忌：
- ❌ 暗色大全套 → 会变成x
- ❌ 废墟破败 → 会变成n的受损状态
- ❌ 沉重滞涩 → xz是快的，不是重的
```

## 附录C：动态链（9-10级信息量）

```
常见链1：xz → nz
  漂流者被迫继续 → 渴望停靠但不敢停
  作品例：《秒速5厘米》远野贵树

常见链2：xz → n
  危险漂流进入承载结构 → 临时庇护成为生命线
  作品例：《萤火虫之墓》节子的寄居状态

常见链3：xz → x
  临界行动被欲望污染 → 从逃生变成吞噬
  作品例：《蝙蝠侠》布鲁斯·韦恩的下坠边缘

常见链4：xz → xn
  临界行动被规则捕获 → 逃犯被法律追索
  作品例：《肖申克的救赎》安迪的越狱

常见链5：xz + nz = 命运主题
  核心动态对子——漂流与停靠的永恒拉扯

全链示例：
  xz(命运推力) → nz(想停靠) → x(被欲望拖住) → xz(继续漂流)
  "快靠岸了，又被拉回海里"
```
