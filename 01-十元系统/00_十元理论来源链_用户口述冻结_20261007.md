>
> 本文件记录十元理论“怎么产生”的历史来源链。
>
> 它与现行分析时的判定流程不同：
> - 来源链回答：理论从哪里长出来；
> - 判定链回答：今天拿一个对象来分析时按什么顺序判断。

# 1｜理论来源总链

用户确认的理论来源：

```
印象派 / 色彩关系经验
↓
三种颜色关系
- 补色 → 张扬
- 临近色 → 耐看
- 对比色 → 醒目
↓
抽象成三元关系
↓
接入五行结构
↓
产生十元关系结构
↓
形成 n / x / z 三关系与生 / 克 / 补
↓
形成十类映射方向
“不是这个，就是那个”的结构分向
↓
各领域预映射
人物 / 场景 / 关系 / 叙事 / 音乐 / 视觉……
↓
形成五个相反对子
↓
后续发展出动态链、主次、体量、五维等扩展
```

# 2｜第一源头：色彩关系

理论最早不是从知识图谱、ontology 或五行学术研究开始。

最初来自视觉/色彩经验中的三类关系感受：

## 补色
用户原始感受：
> 张扬

## 临近色
用户原始感受：
> 耐看

## 对比色
用户原始感受：
> 醒目

这里的关键不是现代色彩学术语能否严格一一对应，
而是：

> 用户从视觉关系中先观察到“三种不同的作用关系/感受方向”。

这是三元理论的最初经验来源。

# 3｜第二层：三元抽象

三种颜色关系进一步被抽象成三元。

因此三元在“理论生成史”上具有祖先位置。

注意：

> 这不等于现行判定时可以用三元比例机械计算出十元。

要区分：

## Genealogy｜来源
三元先出现，十元后发展。

## Runtime / Judgment｜现行判定
三元与十元可以独立判定，不能用三元比例直接替代十元证据。

所以：

```
历史生成：
颜色关系 → 三元 → 十元

现行判定：
十元独立判定
↕
三元独立判定 / 复核
```

两句话不冲突。

# 4｜第三层：三元接五行

三元之后接入五行。

这一步不是简单：
> “传统五行里本来就有十元。”

而是：

> 用户已有三元关系结构
> +
> 五行五类 / 生克关系骨架
> →
> 十元关系结构开始形成。

因此五行对十元的作用更接近：
- 提供五类结构骨架；
- 提供生/克关系来源；
- 提供五组展开框架；
- 与三元关系结构发生重新组合。

# 5｜第四层：十元关系结构

十元不是先作为“10个孤立类别”被发明，再事后加关系。

来源链上更准确是：

> **关系结构先参与十元的生成。**

即：

```
三元关系结构
+
五行结构
↓
十元关系结构
```

因此今天研究十元时，不应该把：
- 十元分类
- 生克补关系

完全拆成两个互不相关的模块。

分类端点本身就是在这套关系结构历史中形成的。

# 6｜第五层：n / x / z 三关系与生克补

用户确认：

> 十元关系结构进一步做成了生 / 克 / 补，以及 n / x / z 三关系。

这里应记录为：
**理论生成层**

而不是当前外部论文里的 generic relation labels。

它们是十元体系内部从三元 + 五行组合后形成的关系语法来源。

# 7｜第六层：十类映射方向

随后形成：

> **十类映射方向**

核心直觉：

> “不是这个，就是那个。”

即十元开始承担：
- 分向；
- 定位；
- 映射；
- 区别邻近结构

的功能。

这一步才是后来的“十元映射模型”来源。

所以：

> 十元不是一开始就为了做 semantic mapping 发明的。

更准确是：

```
颜色关系经验
→ 三元
→ 三元 × 五行关系结构
→ 十元
→ 十元关系
→ 十类映射方向
→ 跨领域预映射
```

“映射模型”是理论演化到后段形成的功能，不是最初源头。

# 8｜第七层：各领域预映射

十类映射方向形成后，开始把同一套结构预映射到多个领域：

- 人物
- 性格
- 行为
- 关系
- 场景
- 视觉
- 叙事
- 音乐
- 组织
- 概念
- 其他对象域

这里形成十元的一个关键主张：

> 同一套十元方向能够跨对象域显化。

这才产生后来需要验证的：
**cross-domain structural invariance｜跨领域结构不变性**

# 9｜第八层：五个相反对子

后续形成五组相反对子：

```
ZX ↔ NX
ZN ↔ X
N ↔ X并Z
XN ↔ Z
XZ ↔ NZ
```

这些对子不是理论最初第一步，
而是理论发展后进一步收束出的五组相反结构。

它们与五行五类发生固定对应。

因此来源顺序应记录为：

> 三元 → 接五行 → 十元关系结构 → 十类映射方向 → 跨领域预映射 → 五个相反对子

而不是倒过来用“五个对子”解释三元的来源。

# 10｜对当前论文研究的重大修正

之前方向3 v2 把十元直接定位为：
> semantic mapping scheme

这只描述了十元当前功能的一部分，
没有描述它真正的理论生成史。

更准确应拆两层：

## A｜Theory Genealogy
```
色彩关系
→ 三元
→ 五行接入
→ 十元关系结构
→ 生克补 / n-x-z
→ 十类映射方向
→ 跨领域预映射
→ 五个相反对子
```

## B｜Current Functional Model
今天十元可以被用于：
```
对象
→ 十元映射
→ 端点
→ 关系
→ 动态链
```

论文不能把 B 当成 A。

# 11｜后续社会比较也要拆成两种问题

## 问题 1｜来源上像什么？
这要研究：
- 色彩关系抽象；
- 三元关系；
- 五行结构重组；
- 关系生成分类系统。

## 问题 2｜今天功能上像什么？
这才比较：
- Conceptual Spaces
- Semantic Differential
- Coding Scheme
- Ontology

因此：

> Conceptual Spaces 等只是在“当前功能”上和十元可比，
> 不是十元理论的历史来源。

# 12｜冻结句

> **十元理论最初由视觉色彩关系经验出发：补色的张扬、临近色的耐看、对比色的醒目先被抽象为三元；三元再与五行结构结合，形成十元关系结构，并发展出生克补与 n/x/z 三关系、十类映射方向、跨领域预映射，随后进一步收束出五组相反对子。今天所说的“十元映射模型”是这条理论演化链后段形成的功能，而不是理论最初来源。**
