# ten-yuan-vault

这是刘啟师的 Obsidian + GitHub 知识仓库，用于承载：

- [[十元生补克表]]
- [[雾中渡口总蓝图]]
- [[F12总控载体蓝图]]
- [[银矿哥评分标准]]
- [[总入口]]

## 仓库定位

```text
GitHub = 版本骨架 / 远程仓库
Obsidian = 可视星图 / 双链知识图谱
ChatGPT = 整理、分析、归档、生成文档
Codex = 修改代码、维护项目结构
F12总控载体 = 自动化任务投料与回流
```

## 当前核心区域

- `00-中枢索引/`：总入口、索引、导航
- `01-十元系统/`：十元、五维、动态链、母型、关系盘
- `03-雾中渡口/`：大型网页游戏项目与设计归档
- `04-F12总控载体/`：F12 自动化、payload、工单、断点续跑

## Obsidian 使用方式

在 Obsidian 中打开本仓库对应的本地文件夹。所有 `[[双链]]` 会进入图谱视图。

## 同步方式

```text
Obsidian 写文档
↓
GitHub Desktop commit
↓
Push origin
↓
GitHub 远程仓库
↓
ChatGPT / Codex 可读取与修改
```
