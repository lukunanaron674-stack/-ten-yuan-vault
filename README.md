这是一个 Obsidian + GitHub 知识库，用来承载“十元系统”“雾中渡口”和“F12总控载体”的长期整理、演化与回流。

## 仓库定位

```text
Obsidian：双链知识库与星图视图
GitHub：版本管理与远程备份
README：仓库说明与入口导航
F12总控载体：自动化任务、工单、断点与回流载体
```

## 当前目录

- `00-中枢索引/`：总入口、导航、索引与跨系统连接。
- `01-十元系统/`：十元关系、生补克、结构表与理论骨架。
- `03-雾中渡口/`：项目总蓝图、交互设计、场景与版本推进。
- `04-F12总控载体/`：F12 自动化蓝图、投针、货架、工单断点。

## 使用方式

先从 [[总入口]] 进入，再根据当前任务跳转到 [[十元生补克表]]、[[雾中渡口总蓝图]] 或 [[F12总控载体蓝图]]。

日常编辑在 Obsidian 内完成；版本提交和同步由 GitHub Desktop 手动执行。
