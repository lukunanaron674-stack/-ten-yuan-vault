# CET 课程包结构与 DONE / STOP

## 本地数据结构

| 字段 | 作用 |
|---|---|
| `lessons[].id` | 唯一课号，例如 L01、L02、L03 |
| `level` | 课程目标：4 或 6（不能代替官方词目核验） |
| `story[]` | 原创英文阅读段落 |
| `target` | 本课目标词数量，目前每课 12 |
| `image` | 相对 `word-companion/` 根目录的本地插画路径 |
| `exercise` | 一道带解析的选择题 |
| `event` | 角色互动 ID、条件和二选一分支 |
| `sourceState` | `candidate_unverified`，词级已校验才允许升级 |

**实际 JSON：** `word-companion/课程单元包/lesson_packs.json`；**词库：** `demo_words.json`。两者编译为 `data.js`，浏览器读取。不要把 MD 排版完成当作游戏已经验收。

## 三样例审核标准

1. 阅读：故事有开始—变化—结果，至少承载本课 12 个候选词。
2. 考试：至少一项可答题的语法选择、一项阅读理解、一项开放迁移题。
3. 感受：L01 初遇、L02 误会、L03 雨天约定，三种区分明显的关系变化。
4. 画面：成年角色统一感、场景区别、图片与 `event.id` 对应。
5. 软件：导入、主动回忆、剧情解锁、存档与刷新，必须分别实测；静态检查不等于浏览器 PASS。

**DONE：** 用户明确确认三个样例可用 + 脚本真实浏览器回执 + 逐词来源核验（课程正式版）。  
**STOP：** 不在审核前无限扩写、不开新工单、不把未来计划说成完成。
