## 最高层级

```text
三元＝一级感受母结构
十元＝十种关系性感受基元
五轴＝五组相反感受方向
五行＝来源参照 / 关系思想 / 母感受研究入口
跨领域＝不同媒介是否激活相近的十元感受结构
```

五轴配对拓扑暂保留：

```text
木 ZX↔NX
火 ZN↔X
土 N↔X并Z
金 XN↔Z
水 XZ↔NZ
```

但旧“领域狭义 is-a 五行父项”不再是核心本体路线。

## 十元感受强度谱

```text
十个十元分别按1–10记录当前感受强度。
Top1＝当前主导感受，不等于对象客观本体。
Top2 / Top3＝次级感受。
完整十维分布＝当前感受结构轮廓。
```

旧“配比度 / 本征映射准度”保留为历史研究工具，是否迁移为感受层指标进入R2/R3再审计。

## 固定感受工作习惯

```text
每遇到一个对象 / 角色 / 发型 / 音乐 / 镜头 / 事件
→ 固定具体语境与时间点
→ 先记录“它让我产生什么感受”
→ 给十种十元感受分别1–10
→ 判断主导与次级感受
→ 再研究五轴对立、生克补张、动态链
→ 跨领域时比较感受结构，不比较名词归类
```

禁止再默认执行：

```text
新领域
→ 先找五个五行狭义名称
→ 再把对象塞进十元
```

旧领域映射协议与 is-a 关系只保留为历史证据；R3 已完成默认执行权迁移，禁止旧协议重新取得核心定义权。
