## 十元双指标

```text
十元配比度：回答“对象由哪些十元共同构成”，十项总和100%。
单十元本征映射准度：回答“对象有多像某个十元本身”，0–100独立评分，不参与配比总和。
```

十元内排名只使用本征映射准度。配比度、本征准度、类型继承度、体量、纯度和证据置信度必须分别保存。

## 固定领域工作习惯

```text
每做一个新领域
→ 确定领域对象与尺度
→ 为五行寻找该领域狭义名称
→ 保存五条 子项 --is-a狭义[domain]→ 五行父项
→ 保存每条关系的两端十元继承映射度
→ 写十个十元在该领域的相反操作
→ 为具体实例保存总和100%的十元配比度
→ 为目标十元保存0–100本征映射准度
→ 在同领域同尺度内生成十元独立排行榜
→ 做正例、反例、最近邻与反向检查
```

具体案例使用 `instance-of`，不得替代领域子项与五行父项之间的 `is-a狭义`。
