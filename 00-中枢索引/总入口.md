## 最高层级

```text
十元＝五行内部阴阳两极
五行＝同行十元的对立统一体
领域狭义定义＝同一五行进入具体对象域后的名称、变量与判据
五大主题＝五行在主题／叙事领域的狭义定义
```

```text
木 zx↔nx → 因果
火 zn↔x → 本体
土 n↔x并z → 空间
金 xn↔z → 时间
水 xz↔nz → 命运
```

类似五行进入生理领域对应肝心脾肺肾；五大主题不是五行之外的另一套系统。

五大主题生克盘是五行生克在主题领域的显化。静态方向固定，具体作品中是否启动关系仍须证据。

## 固定领域工作习惯

```text
每做一个新领域
→ 先确定领域对象与分析尺度
→ 为五行分别寻找该领域中的核心变量
→ 写出十个十元在该领域中的狭义相反操作
→ 做正例、反例、最近邻、拿掉与反向检查
→ 再开始案例库、素材库或项目分类
```

不得把主题、人物、生理、视觉、音乐、游戏等一个领域的狭义词直接搬到另一个领域。领域映射未完成时只标`draft-domain-map`。
