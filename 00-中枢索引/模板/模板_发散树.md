- **主画布**：[[{{主题}}发散树.canvas]]

- **节点解释目录**：[[{{主题}}发散树_说明/{{节点}}|{{主题}}发散树_说明/]]（每个节点一份解释 md）

## 主画布怎么搭

| 节点 | 类型 | 放什么 |
|---|---|---|
| `root` | text | `# {{主题}}｜发散树` + 📂/├─/└─ 总览 + 规则行 |
| `grp{{N}}` | group | {{区块N}}，色号 {{颜色N}} |
| `{{节点id}}` | text | 一句话要点 + `📄 解释：[[{{主题}}发散树_说明/{{节点}}|详解]]` |
| `{{子分支}}` | file | 嵌套子画布：`[[{{主题}}发散树_{{子分支}}.canvas]]`（type=file 指向子 canvas） |

## 规则清单

1. 发散结构只在 **canvas**；父子级 → **canvas 节点装 canvas**（type=file）
2. **md 只做节点内解释**，不承载发散结构，不许在 md 里画树
3. 命名统一：节点 id / 解释 md 文件名 / 链接别名 一致
4. 区块用 group + 色号区分；边表示明确父子/归属关系
5. 模板里的 `[[{{...}}]]` 是链接占位：替换占位符后即可点击打开
