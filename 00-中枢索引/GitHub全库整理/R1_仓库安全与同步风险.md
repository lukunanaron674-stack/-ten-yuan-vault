# R1 仓库安全与同步风险

> [!danger] 当前结论
> 当前不具备安全进入 R2 的条件。原因是实时远端与本地分叉、工作树有未提交状态、存在敏感信息候选、大文件/嵌套仓库风险，以及 Canvas 缺失引用尚未分级。
