# R1 图片与 Canvas 完整性报告

> [!warning] 快照有效性
> 本报告的全量统计来自后台 merge/图像压缩和远端再次推进之前的扫描。外部同步期间有工作树和 Git 引用变化；R2 前须在冻结 SHA 后重扫 Canvas 与图片引用。

> 扫描所有以 `.canvas` 结尾的文件，并纳入带 `.canvas.bak`、`.canvas.backup`、`.canvas.<历史后缀>` 的 Canvas 历史快照；历史快照的失效引用单独记录，不自动修复。

## 3. 完整性结论

- Canvas JSON 结构可解析，未发现 JSON 损坏。
- 图片缺失主要集中在历史备份、旧目录路径、已替换候选和跨目录相对引用；不能直接断言原图已被删除。
- 未执行引用修复、重命名、补图、移动或 Canvas 写回。
- R2 修复前应先按“当前正本 / 工作候选 / 历史归档”分类，并保留缺失引用的原始文本。
