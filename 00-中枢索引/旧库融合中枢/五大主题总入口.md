## 一、五大主题的十元构成区

- 时间：xn+z
- 本体：zn+x
- 空间：x并z+n
- 因果：zx+nx
- 命运：xz+nz

这些公式中的符号全部是十元点位。

例如：

```text
时间 = xn + z
```

这里的 `z` 是十元点位 z，是时间主题的构成成员。

公式中的 `+` 表示理论系统预设的十元构成双方，不表示现实案例里两个十元碰巧同时出现。

## 二、两套“补”必须分开

### 十元层互补

```text
两个十元同时出现
→ 在十元层发生互补、生、克或并列
→ 不自动生成五大主题
```

### 五大主题生成系统

```text
主题生成系统统一 z 补合
+ 预设十元构成双方
→ 形成高级主题符号
```

五大主题的诞生来自另一套专门解决主题的系统，不是案例里两个十元一同出现后的临时合成。

## 三、五大主题关系区

```text
z = 补 / 补合
n = 生 / 生发
x = 克 / 克制
```

```text
z：统一补合指定十元构成双方，生成五大主题
n：五大主题之间的生发
x：五大主题之间的克制
```

## 四、正式生环

```text
空间 生 时间
时间 生 命运
命运 生 因果
因果 生 本体
本体 生 空间
```

闭环：

```text
空间 → 时间 → 命运 → 因果 → 本体 → 空间
```

## 五、正式克环

```text
空间 克 命运
命运 克 本体
本体 克 时间
时间 克 因果
因果 克 空间
```

闭环：

```text
空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

## 六、旧表达迁移

```text
Legacy：n 补克 nx
Current：因果克制空间
```

旧表达停止作为现行十元关系或动态链结论使用。

## 七、旧关系盘覆盖

五个主题单页中标题为“生补克关系”的旧图，不再拥有现行定义权。

凡与正式生克盘方向不一致的旧关系，一律以现行盘为准。

尤其覆盖：

```text
旧：空间克因果
现：因果克空间
```

## 八、使用规则

- 五大主题负责高级归类、主题生成与主题级生克。
- 十元负责人物、状态、行为、场景、时间结构等对象的具体化。
- 动态链负责具体对象之间的阶段性生、克、补。
- 十元层互补不得冒充五大主题生成。
- 主题级生克不得直接还原成唯一十元关系。
- 人物稳定本体优先保持不变，变化主要落在状态、关系和动态链。
- 表面关键词、场景外观、职业、服装与光影不能越级证明人物本体。
- 三元与十元并行判断，不得写成父子派生关系。
