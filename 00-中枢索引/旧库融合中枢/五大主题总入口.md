## 五大主题

- 时间：xn+z
- 本体：zn+x
- 空间：x并z+n
- 因果：zx+nx
- 命运：xz+nz

上述公式当前用于标记被补合的双方与主题位置，不得理解为普通加法或从十元到主题的机械派生。

## 形成顺序

```text
双方分别成立
↓
z 先补合双方
↓
形成五大主题的高级符号
↓
主题之间再观察 n 生与 x 克
```

关系功能：

```text
z = 补 / 补合
n = 生 / 生发
x = 克 / 克制
```

“五大主题像五行一样只有生克”，指主题形成后的主题间关系主要看生克，不表示 z 或补合被排除出体系。

## 当前正式关系

```text
因果 x 空间
即：因果克制空间
```

```text
Legacy：n 补克 nx
Current：因果克制空间
```

旧表达停止作为现行十元关系或动态链结论使用。

## 旧关系盘冻结

五个主题单页中标题为“生补克关系”的旧关系图，目前全部降级为历史候选，不再拥有现行定义权。

原因：

1. 主题层形成后主要观察生与克，不应把主题级关系与十元级生克补混在同一标题下；
2. 旧空间页仍写“空间克因果”，与当前正式关系“因果克制空间”方向相反；
3. 旧关系盘尚未按照 z 先补合、主题后生克的顺序重新验收；
4. 旧公式中的部分十元语义已经更新，不能沿用旧案例自动证明主题关系。

在完整复验前，只允许调用已经单独锁定的主题关系，不得从旧图补齐整套五主题生克盘。

## 使用规则

- 五大主题负责高级归类与主题级生克。
- 十元负责人物、状态、行为、场景、时间结构等对象的具体化。
- 动态链负责具体对象之间的阶段性生、克、补。
- 人物稳定本体优先保持不变，变化主要落在状态、关系和动态链。
- 表面关键词、场景外观、职业、服装与光影不能越级证明人物本体。
- 三元与十元并行判断，不得写成父子派生关系。
