## 二、五大主题的十元构成区

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

这些公式中的符号全部是十元点位。

公式中的 `+` 表示理论系统预设的十元构成双方，不表示现实案例里两个十元碰巧同时出现。

当前研究状态：

```text
五组公式是现行基准构成；
尚未证明它们是唯一构成；
也尚未证明存在合法的非标准构成变体。
```

任何新组合只能先进入“候选变体”研究，不得直接改写正本。完整门槛以 [[02-五大主题/五大主题基准构成与候选变体研究协议_v0.1_2026-07-16]] 为准。

## 三、两套“补”必须分开

### 十元层互补

```text
两个十元同时出现
→ 在十元层发生互补、生、克或并列
→ 不自动生成五大主题
```

### 五大主题生成系统

```text
理论系统预设十元构成双方
↓
主题生成系统以统一关系层 z 补合
↓
形成高级主题符号
```

五大主题的诞生来自另一套专门解决主题的系统，不是案例里两个十元一同出现后的临时合成。

## 四、五大主题关系区

```text
z = 补 / 补合
n = 生 / 生发
x = 克 / 克制
```

```text
z：统一补合指定十元构成双方，生成五大主题
n：五大主题之间的生发
x：五大主题之间的克制
```

## 五、主题最小定义

```text
空间：什么能够在哪里存在，彼此如何共处或受限。
时间：事物怎样从之前走到之后，什么被改变或保留。
命运：多种可能最终收束到哪里。
因果：什么导致了什么。
本体：它究竟是什么。
```

这些是高级主题问题，不是十元关键词的同义替换。

## 六、正式生环

```text
空间 生 时间
时间 生 命运
命运 生 因果
因果 生 本体
本体 生 空间
```

闭环：

```text
空间 → 时间 → 命运 → 因果 → 本体 → 空间
```

## 七、正式克环

```text
空间 克 命运
命运 克 本体
本体 克 时间
时间 克 因果
因果 克 空间
```

闭环：

```text
空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

## 八、旧表达迁移

```text
Legacy：n 补克 nx
Current：因果克制空间
```

旧表达停止作为现行十元关系、动态链或人物判定使用。

## 九、显影等级

```text
0级：背景存在
1级：局部主题
2级：次主题
3级：主主题
```

不得使用关键词命中数量判定主次。

两个主题同时出现，不等于主题生克启动。必须出现明确方向，并真实改变目标主题的能力、边界、路径或答案。

## 十、使用规则

- 五大主题负责高级归类、主题生成与主题级生克。
- 十元负责人物、状态、行为、场景、时间结构等对象的具体化。
- 动态链负责具体对象之间的阶段性生、克、补。
- 十元层互补不得冒充五大主题生成。
- 主题级生克不得直接还原成唯一十元关系。
- 五组公式作为现行基准构成使用，但唯一性与变体均保持未判定。
- 候选变体不得反向改写人物稳定本体。
- 人物稳定本体优先保持不变，变化主要落在状态、关系和动态链。
- 表面关键词、场景外观、职业、服装与光影不能越级证明人物本体。
- 三元与十元并行判断，不得写成父子派生关系。
