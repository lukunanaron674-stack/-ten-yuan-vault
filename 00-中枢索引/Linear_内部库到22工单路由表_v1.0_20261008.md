## 0｜硬规则

```text
内部文件/Canvas/素材被发现
→ 先判 source_authority（L0–L6）
→ 查本路由表
→ 查 674-294 工单注册表
→ 进入已有 canonical issue
→ 只有没有现有职责承接时才允许 294 preflight CREATE
```

- Canvas = 结构/知识来源；**工单适应 Canvas，不反向重构 Canvas**。
- GitHub / Obsidian = 长期知识、规则、状态、索引正本。
- Linear = 任务、状态、执行回执、阻塞与 USER 审核入口；不成为第二套理论正本。
- 搜到旧号、旧 Canvas、旧 MD 不代表恢复其主权。
- 同一知识同时出现在多个库时，按 `L0→L1→L2→L3→L4→L5→L6` 和 explicit supersedes/canonical-current 决定权力。
