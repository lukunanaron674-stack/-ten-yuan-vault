## 二、五大主题结构

### 主题1：xn + z = 时间（规则 × 执念）
**维度解释**：节拍、时机、临界点、倒计时——剧情节奏如何组织

| 审阅项 | 分析内容 | 纠正内容 |
|--------|----------|----------|
| 外部节奏 | 外部世界的压力节奏如何（快/慢/周期） | |
| 内部节奏 | 内部情绪/关系的节奏变化 | |
| 关键节点 | 最重要的"时机/爆点"在哪里 | |
| 节奏感评价 | 分析是否准确 | |

### 主题2：zn + x = 本体（精神 × 欲望）
**维度解释**：精神驱动与内在欲望如何耦合，形成角色/世界的驱动核心

| 审阅项 | 分析内容 | 纠正内容 |
|--------|----------|----------|
| 核心驱动 | 主角的核心驱动是什么 | |
| 能量来源 | 这个驱动靠什么维持 | |
| 驱动力评价 | 分析是否准确 | |

### 主题3：x并z + n = 空间（包装 × 稳定）
**维度解释**：场域、容器、可被组织进入的环境——关系场域如何构建

| 审阅项 | 分析内容 | 纠正内容 |
|--------|----------|----------|
| 核心空间 | 最重要的"容器/场域"是什么 | |
| 空间构建 | 这个空间如何被建立和维持 | |
| 空间功能 | 这个空间对角色/叙事的作用 | |
| 空间评价 | 分析是否准确 | |

### 主题4：zx + nx = 因果（突破 × 暗流）
**维度解释**：起因与后果、起局与收局、事件如何推进

| 审阅项 | 分析内容 | 纠正内容 |
|--------|----------|----------|
| 突破者 | 谁是"先动手/打破局面"的人 | |
| 暗流者 | 谁在暗中操控/算计 | |
| 因果链 | 事件如何一个接一个发生 | |
| 因果评价 | 分析是否准确 | |

### 主题5：xz + nz = 命运（危险 × 柔情）
**维度解释**：漂流、遭遇、缘分、归宿——角色为什么继续走、最后停在哪里

| 审阅项 | 分析内容 | 纠正内容 |
|--------|----------|----------|
| 命运感 | 整体命运的走向和质感 | |
| 遭遇结构 | 角色之间如何相遇/离散 | |
| 最终归宿 | 故事的终点感是否准确 | |
| 命运评价 | 分析是否准确 | |
