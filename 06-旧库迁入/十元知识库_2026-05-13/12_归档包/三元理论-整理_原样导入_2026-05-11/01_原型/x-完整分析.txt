x（阴水）完整分析

核心定义

x = 无法满足的深层渴求，在欲海中沉沦的存在。

更精确的表达：
不说，只做。
占有欲极强，不分享。
沉溺于某事无法自拔。
是所有类型中最"向内"的一类——只有欲望，没有包装，没有出口。

本质结构

x = 强 X（欲望/占有）+ 弱 Z（不需要显现）+ 弱 N（不在乎稳定）

深层动因：

- 强 X：欲望，占有，渴求
- 弱 Z：不需要被看见，被看见了反而危险
- 弱 N：没有规则，没有道德，没有边界

核心矛盾

x 的欲望是"得到"，但得到之后是"空虚"，空虚之后是"更想要"。
这是一个永远填不满的深渊。
越得越渴，越渴越要。

典型行为

- 不说，只做
- 占有欲极强
- 沉溺于某事无法自拔
- 越得到越空虚
- 可以为了"那一个"放弃一切

一句话精准描述：
"我也不知道我要什么，我只知道我还要。"

与 nz 的关系

x 生 nz。
欲望生出沉溺。
x 对 nz 有天然的吸引力——那种深不可测的感觉。
nz 会在 x 面前失去抵抗力，越陷越深。

与 nx 的关系

nx 克 x。
稳定压制深渊。
nx 的理性能在 x 失控之前拉缰绳。
nx 是少数能在 x 面前保持清醒的人。

与 ZN 的关系

x 与 ZN 是互补对（x ↔ ZN）。
深渊欲望与外在光热，是最完整的"人"的结构。
x 需要 ZN 的光照进来；ZN 需要 x 的深度来沉下去。

体量展开

x1：隐匿的贪
x4：有所求，有所在乎
x7：强烈的占有欲，难以自拔
x10：毁灭级欲望，吞噬一切

创作提示

x 适合：
- 反英雄的内心黑暗面
- 悲剧性的沉溺者
- 让人同情的"坏人"
- 深渊般的存在

x 的经典弧光：
开局：有所渴求 → 中段：得到了，但空虚 → 高潮：越要越多，开始失控 → 结局：被欲望吞噬，或者找到超越欲望的意义

x 的最大悲剧：永远不知道自己要什么，因为要的是"更多"。
