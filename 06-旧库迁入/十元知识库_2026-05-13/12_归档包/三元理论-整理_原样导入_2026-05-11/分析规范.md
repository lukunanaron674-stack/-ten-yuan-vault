## 一、五大主题的标准定义

### 1. xz + nz = 命运（相遇与分离的命定性）

**定义：** 两个角色/存在，因为某种"缘分"相遇，但这种相遇本身带有命定性——相遇不是偶然，也不是选择，而是被某种更大的结构所决定。

**核心问题：** "他们为什么相遇/为什么分离？"

**判断标准：**
- 相遇是由某种超出双方控制的力量促成的
- 分离不是因为谁做错了，而是命运本身的要求
- 结局指向"各自的漂流/各自的继续"

**典型意象：** 错过、缘分、命运的铁轨、偶然中的必然

---

### 2. xn + z = 时间（规则与执念的对抗）

**定义：** 某种"规则"（倒计时、制度、代价）压在角色身上，但角色的"执念"拒绝屈服于这种规则。

**核心问题：** "规则说你应该放弃，你偏不——这个执念是什么？"

**判断标准：**
- 有明确的"代价"或"倒计时"
- 角色有一个明确的"执念"作为回应
- 结局指向执念对规则的回应/挑战/和解

**典型意象：** 倒计时、契约、承诺、一日限定、八千年等待

---

### 3. zx + nx = 因果（突破与暗流的博弈）

**定义：** 谁先动手，谁在暗中操控——事件不是自然发生的，而是由特定主体的意志和计算所推动。

**核心问题：** "谁先动的手？背后的暗流是什么？"

**判断标准：**
- 有明确的"行动者"和"被行动者"
- 有某种"布局"或"算计"的质感
- 结局指向因果的完成或打破

**典型意象：** 刺客、谋士、阴谋、朝堂博弈、因果链条

---

### 4. zn + x = 本体（精神与欲望的撕裂）

**定义：** 角色的内心存在两个层面——"我以为我是这样的人"（zn/精神）和"我实际上被什么驱动"（x/欲望），两者之间存在撕裂或耦合。

**核心问题：** "这个人真正被什么驱动？他自己知道吗？"

**判断标准：**
- 有明显的内心冲突
- 角色对自己的认知和实际驱动之间存在落差
- 结局指向自我认知的确认、颠覆或和解

**典型意象：** 得道与欲望、爱国与情欲、内心挣扎、自我发现

---

### 5. x并z + n = 空间（场域与容器的构建）

**定义：** 故事的核心不是"谁做了什么"，而是"一个特定的空间/容器如何承载了某种功能"。

**核心问题：** "这个空间/容器的功能是什么？它如何影响角色？"

**判断标准：**
- 有明确的核心空间（如食堂、家、虚拟空间）
- 空间本身有明确的"承载"或"过滤"功能
- 结局指向空间的打破、维持或创造

**典型意象：** 食堂、家庭、虚拟空间、城市、一个封闭的场域

---

## 二、分析SOP（五步流程）

### 第一步：找最大体量

拿到一部电影，先问：

> "这部作品里，**体量最大的那个主题**是什么？"

判断方法：
- 哪个主题的内容占电影篇幅最多？
- 哪个主题的变化最核心、最决定结局？
- 哪个主题让观众记住这部电影？

**最大体量 = 这部电影的主主题**

---

### 第二步：找角色原型

找到主要角色，判断他们的原型：

| 符号 | 原型 | 核心问题 |
|------|------|----------|
| z | 突破者/执念者 | "我就是要" |
| x | 压制者/代价 | "规则/代价" |
| n | 承载者/稳定 | "我在" |
| nz | 依恋者/柔情 | "我需要你" |
| xn | 制度者/规则 | "应该有秩序" |
| xz | 危险者/感知 | "有危险" |
| nx | 暗流者/算计 | "我在暗处" |
| zn | 精神者/表达 | "我有精神追求" |

---

### 第三步：找关系结构

> "主主题里，角色之间的关系是什么？"

用"×"表示连接：

- z × nz = 执念者与依恋者的共振
- xn × z = 规则与执念的对抗
- z × zn = 执念与精神的耦合
- N × nz = 容器与依恋的承接

---

### 第四步：找结局的意义

> "结局是什么？它对这个主题说了什么？"

| 结局类型 | 对主题的意义 |
|----------|--------------|
| 主题要素获胜 | 主题被确认 |
| 主题要素失败 | 主题被质疑 |
| 主题要素转化 | 主题被深化 |
| 主题要素共存 | 主题被复杂化 |

---

### 第五步：写核心公式

用一句话概括这部电影：

> **[主角/关系] + [主题] + [结局的意义]**

格式：
> **[符号结构]** —— **[一句话核心内容]**

---

## 三、判断决策树

```
这部电影的核心是什么？
│
├─ 是"相遇/分离的命定性"？
│   └─ → 命运型（xz+nz）
│
├─ 是"规则与执念的对抗"？
│   └─ → 时间型（xn+z）
│
├─ 是"谁先动手/暗流操控"？
│   └─ → 因果型（zx+nx）
│
├─ 是"精神与欲望的撕裂"？
│   └─ → 本体型（zn+x）
│
└─ 是"一个空间的承载功能"？
    └─ → 空间型（x并z+n）
```

## 五、常见误区

### 误区1：一部电影只能有一个主题
**正：** 五大主题经常共存，但有一个是主主题。

### 误区2：类型是固定的
**正：** 同一个角色可以同时具有多个类型的特征。

### 误区3：结局决定主题
**正：** 主题由整体结构决定，结局是主题的完成形式。

### 误区4：类型有高下之分
**正：** 五种类型是平等的分析维度，没有优劣。

## 六、跨类型互动（进阶）

### 常见组合

| 组合 | 互动关系 |
|------|----------|
| xz+nz × xn+z | 命运型里常有时间的压力（如秒速5厘米） |
| zn+x × xz+nz | 本体型角色常在命运框架里（如日瓦格医生） |
| x并z+n × xz+nz | 空间常作为命运的容器（如深夜食堂） |
| zx+nx × zn+x | 因果型角色的内心常是zn+x的结构 |

### 分析方法

当一部作品有多个主题时：
1. 找出主主题（体量最大）
2. 找出副主题（服务于或对抗主主题）
3. 分析副主题对主主题的影响
