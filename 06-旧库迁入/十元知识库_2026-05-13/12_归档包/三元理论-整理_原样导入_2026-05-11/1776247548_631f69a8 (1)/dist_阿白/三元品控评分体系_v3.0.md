## 核心理念

**一幅画的完整身份 = 叙事身份 + 感知身份**

| 身份 | 回答的问题 | 维度工具 |
|------|----------|---------|
| **叙事身份** | 这个角色/场景「怎么动」 | 三元理论 × 十元原型 |
| **感知身份** | 观者「怎么看」 | 十元视觉体系 × 顺序感谱 |

## 第一维：五维类型（叙事身份）

**执行者：霜**

### 五维类型

| 类型 | 结构公式 |
|------|---------|
| 命运型 | xz + nz |
| 时间型 | xn + z |
| 空间型 | x并z + n |
| 本体型 | zn + x |
| 因果型 | zx + nx |

### 输出格式

```
第一维：五维类型
- 类型判定：□ 命运 □ 时间 □ 空间 □ 本体 □ 因果
- 主要结构：□ xz+nz □ xn+z □ x并z+n □ zn+x □ zx+nx
结论：（类型名称）
```

## 第三维：顺序感谱（Z轴 · 行为序列）

**执行者：霜**

### 核心本质

顺序谱衡量**体量压迫强度的感知层级**。

- **1** = 最大压迫（最大体量/最强对比）
- **2** = 次强压迫
- **3** = 最小但最精准的定锚

### 十元 × 顺序谱

| 十元 | 顺序 | 压迫结构 |
|------|------|---------|
| N | 123 | 先扫全场框架，再进主体，最后细节 |
| zx | 312 | 先抓住冲突点，再退回框架 |
| z | 231 | 先压住，再忍，最后那道光 |
| nz | 慢123 | 缓慢沉入，像被吸进去 |
| xn | 213 | 先结构，再结果，细节最后才显 |
| nx | 213 | 表面平静，深层才显现刀锋 |
| XZ | 231 | 从边缘压缩，压迫感先来 |
| x | 321 | 被虚无扩散拉进去 |
| x并z | 213 | 两个焦点拉扯视线 |

### 尺度三阶层

| 层级 | 压迫强度 | 例子 |
|------|---------|------|
| **尺度1** | 最大压迫 | 大块面/强对比区域 |
| **尺度2** | 次强压迫 | 引导层、中间调 |
| **尺度3** | 精准定锚 | 高饱和小色块、极小高光 |

### 输出格式

```
第三维：顺序感谱
- 顺序谱判定：□ 123 □ 312 □ 231 □ 慢123 □ 213 □ 321
- 尺度1（最强压迫）：（描述）
- 尺度2（次强压迫）：（描述）
- 尺度3（精准定锚）：（描述）
结论：顺序感谱 □ 对 □ 错
```

## 斟终审

**执行者：斟**

### 斟输出格式

```
【斟终审】
三维坐标：X=____维 / Y=____元+____质感+____光+____色温 / Z=____序
叙事身份：□ 成立 □ 断裂
感知身份：□ 统一 □ 混乱
综合评分：____（0-100）
最终判定：□ 归档 □ 退回 □ 待定
斟备注：
```

### 归档标准

| 综合评分 | 判定 |
|----------|------|
| 60以下 | 退回 |
| 60-75 | 常规归档 |
| 76-90 | 值得归档 |
| 91以上 | 精品，重点积累 |
