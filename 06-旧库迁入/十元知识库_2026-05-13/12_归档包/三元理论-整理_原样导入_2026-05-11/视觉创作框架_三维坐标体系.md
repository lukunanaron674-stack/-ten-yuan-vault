# 视觉创作框架：三维坐标体系

> 基于三元理论 × 十元视觉 × 顺序感谱的统一创作体系
> 2026-04-10 · 共创版

---

## 核心理念

一幅画的完整身份 = **叙事身份** + **感知身份**

| 维度 | 回答的问题 | 工具 |
|------|----------|------|
| **叙事身份** | 这个角色/场景「怎么动」 | 三元理论 × 十元原型 |
| **感知身份** | 观者「怎么看」 | 十元视觉体系 × 顺序感谱 |

两者统一，画面才不会「演的`和「看的」打架。

## 第二维：十元视觉体系

> 十元不仅决定角色行为，也决定画面的**视觉语法**。

### 1. 质感类型 × 十元

| 十元 | 质感类型 | 核心特征 | 代表作品 |
|------|---------|---------|---------|
| **xn** | 结构精确型 | 精确勾线+色块概括+滤色光效 | 赛璐珞平涂、v2少女 |
| **zn** | 有机厚重型 | 揉擦感+厚涂笔触+油彩质感 | 城生原作 |
| **zx** | 爆发冲击型 | 笔触张扬+对比强烈+动势感 | 动作张力画面 |
| **xz** | 锐利冷峻型 | 干燥笔触+硬边+无彩色系 | 极简主义插画 |
| **nz** | 柔和沉溺型 | 模糊边缘+水汽感+透明叠色 | 梦幻氛围 |
| **nx** | 暗流涌动型 | 细腻层次+隐藏肌理+压迫感 | 暗部细节丰富 |
| **z** | 执拗堆叠型 | 反复叠加+密集笔触+厚重量 | 古典写实厚涂 |
| **N** | 稳定包裹型 | 完整结构+哑光质感+沉重感 | 纪念碑感、场域感 |
| **x** | 虚无扩散型 | 无边界+透明流动+渐变消失 | 虚无感、迷雾、融解 |
| **x并z** | 矛盾并置型 | 两种质感强行共存+对抗感 | 铠甲崩裂、面具群像 |

> **x并z的本质**：不是某一种质感，而是**两种质感在同一画面被迫共存**——这是它真正的视觉特征。

### 4. 配色比例 × 十元

> 配色比例本质是「色域的势力范围分配」，不是装饰搭配。

| 十元角色 | 比例 | 功能 |
|---------|------|------|
| **n** 主色调（场域） | 50-70% | 容器最大，稳定底色 |
| **z** 焦点色（内核） | 10-20% | 不靠量大，靠对比强度抓眼球 |
| **x** 侵蚀色（欲望） | 5-15% | 从边缘/裂缝渗透，不占领但无处不在 |
| **nz** 底氛围色（沉溺） | 5-10% | 渐变/弥散，铺垫情绪底色 |
| **zx** 突破色（冲突爆发） | 3-8% | 爆发点，点睛用，量少但极高饱和 |

**核心原则：**
- x不是点缀色，是**侵蚀色**——比例虽小，但在结构薄弱处出现，暗示整体正在被渗透
- 配色是势力分布，不是装饰搭配

**构图比例公式：**
```
n大面（容器） + z小面（焦点） + x细线（侵蚀） + 背景消隐（nz）
```

## 第三维：顺序感谱（Order-Response Mapping）

### 核心本质

**123是一种衡量体量比例顺序的感受提炼法。**

不是时间顺序，不是视线轨迹，而是「体量压迫强度的感知层级」：

> 哪个给我的压迫感最大、哪个次之、哪个最小但最精准

---

### 基础定义

| 数字 | 本质 | 不是 | 是 |
|------|------|------|------|
| **1** | 最大体量/最强压迫 | 「先看到」的时间 | 压迫强度最高 |
| **2** | 中等体量/次强压迫 | 「再看到」的顺序 | 压迫强度次之 |
| **3** | 最小体量/精准定锚 | 「最后才看」 | 压迫最弱但最精准 |

---

### 123的四个维度展开

#### A. 尺度维度（体量大小）

| 层级 | 压迫强度 | 例子 |
|------|---------|------|
| **1** | 最大尺度（大块面/强对比） | 白色铠甲主体 |
| **2** | 中等尺度（引导层） | 胸腔红裂纹 |
| **3** | 最小尺度（精准定锚） | 裂缝发光点 |

#### B. 颜色对比维度

| 层级 | 本质 | 例子 |
|------|------|------|
| **1** | 最抓住眼球的色块 | 明度/饱和度最高区域 |
| **2** | 次级对比区域 | 次要色彩关系 |
| **3** | 点睛细节色 | 高饱和小色块 |

#### C. 形状大小维度

| 层级 | 本质 | 例子 |
|------|------|------|
| **1** | 最大形状框架 | 轮廓/剪影 |
| **2** | 结构引导形状 | 引导线/构图结构 |
| **3** | 收尾细节形状 | 焦点细节 |

#### D. 明暗维度

| 层级 | 本质 | 例子 |
|------|------|------|
| **1** | 最亮或最暗的块面 | 主光区/最深阴影 |
| **2** | 明暗过渡层 | 中间调 |
| **3** | 极小高光/极暗 | 精准定锚点 |

---

### 十元 × 123尺度序列

| 十元 | 顺序 | 压迫结构 |
|------|------|---------|
| **N 123** | 大→中→小 | 先扫全场框架，再进主体，最后细节 |
| **zx 312** | 中→小→大 | 先抓住冲突点，再退回框架 |
| **z 231** | 中→小→小 | 先压住，再忍，最后那道光 |
| **nz 慢123** | 大慢慢收小 | 缓慢沉入，像被吸进去 |
| **xn 213** | 中→小→小 | 先结构，再结果，细节最后才显 |
| **nx 213** | 中→小→小 | 表面平静，深层才显现刀锋 |
| **XZ 231** | 中→小→小 | 从边缘压缩，压迫感先来 |
| **x 321** | 小→中→大 | 被虚无扩散拉进去 |
| **x并z 213** | 中→小→小 | 两个焦点拉扯视线 |

---

### 城生v2完整尺度分析

```
尺度1（最大压迫）：白色铠甲大块面 → 建立「壳」的重量感
尺度2（次强压迫）：胸腔红裂纹 → 视线被「不一样」拽住
尺度3（精准定锚）：裂缝发光点 → 最后定在能量核心

= 大统一压住 → 中拽进来 → 小精准点死
```

## 第四维：氛围词归属（十元，不归五维）

**五维定「能不能」，十元定「怎么感」。**

| 十元 | 氛围词 | 理由 |
|------|--------|------|
| **zn** | 燃烧感、热烈感、光芒感 | 精神内核向外传播 |
| **z** | 执念感、聚焦感、被看见感 | 偏执的聚光 |
| **zx** | 撕裂感、爆发感、突破感 | 内外撕裂的瞬间 |
| **N** | 沉重感、纪念碑感、包裹感 | 大地承载 |
| **nz** | 沉溺感、迷雾感、渐消失感 | 沉进去出不来 |
| **xn** | 规则感、压迫感、框架感 | 制度从上压下来 |
| **nx** | 暗流感、危险感、深渊凝视感 | 表面平静下有刀 |
| **xz** | 刀锋感、来不及感、刀刃行走感 | 极致的临界感 |
| **x** | 虚无感、无边界感、融化感 | 欲望无边没有坐标 |
| **x并z** | 矛盾拉扯感、两个自我争夺感 | 共存但对抗 |

**核心原则：同一五维度结构，不同十元感出来完全不同**
（例：同一空间型结构，z偏执者感出来是「我必须撑住」，nz沉溺者感出来是「慢慢沉进去」）

## 三维坐标体系

每幅画都可以用三个坐标完全定义：

```
X轴：五大维度（命运/时间/因果/本体/空间）
Y轴：十元质感类型（10种质感）
Z轴：顺序感谱（行为顺序+尺度顺序）

三维坐标一定 = 画面的叙事身份 + 感知身份 完全确定
```

xn：精确勾线 + 大面积色块 + 滤色光效

```
123：先环境 → 再主体 → 最后细节（稳定承接）

231：先压抑 → 再忍 → 最后决断（偏执积累型）
321：被拖进去，无终点（虚无扩散型）
```
