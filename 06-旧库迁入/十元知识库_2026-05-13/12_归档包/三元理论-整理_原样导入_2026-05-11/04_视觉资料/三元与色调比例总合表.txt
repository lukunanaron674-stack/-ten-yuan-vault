十种色调体系（Ten-Tone System）
——基于能量比例 × 能量方向 × 顺序感的综合色调模型

0｜使用说明（强烈建议保留）
本体系用于快速判断画面、影像、设计中的色调本质，
适用于：绘画 / 电影 / 游戏 / 灯光 / 视觉世界观 / AI 审美判断。
本体系不讨论「好坏」，只讨论状态。

1｜核心前提（压缩版）
色调 ≠ 颜色名称 ≠ 风格标签
色调 = 能量比例 + 能量方向 + 顺序感

2｜三项比例定义（并排压缩写法）
白 White（1–9）
空间 / 空气 / 留白 / 扩散权重
纯 Pure（1–9）
颜色能量 / 饱和度 / 存在感 / 生命力
黑 Black（1–9）
重量 / 代价 / 压迫 / 风险 / 不可逆性
数值越高，占比越大
比例顺序固定为：白 – 纯 – 黑

3｜能量方向（合并为一栏，避免散页）
内循环：包裹 / 留人
外放：展示 / 攻击
扩散：消散 / 呼吸
下沉：压制 / 迟滞
劫持：伪装 / 表演（仅 x并z）

① 淡色调 · n
比例：8-5-1（典型 851）
十元：N
顺序感：123（世界在运转）
方向：扩散
能量状态：低密度，被白稀释
视觉感受：明亮、轻、通透
判定句：
颜色慢慢散开，不强留人

② 绵调 · nz
比例：5-8-3（典型 583）
十元：N → Z
顺序感：慢 123（不想结束）
方向：爆出 → 包裹 → 内循环
能量状态：高能量被兜住
视觉感受：厚、稳、温暖
判定句：
能量爆出后，被画面包裹住

③ 浓色调 · zn
比例：5-7-5（典型 575）
十元：Z → N
顺序感：132（先看我，再跟我）
方向：稳定外放
能量状态：高但受控
视觉感受：饱满、有分量
判定句：
能量稳定地向外释放

④ 锐色调 · z
比例：2-9-2 / 3-9-3
十元：Z
顺序感：231（我忍不住了）
方向：刺出
能量状态：极端集中
视觉感受：尖锐、紧张
判定句：
能量集中成一点，直接刺出

⑤ 明色调 · zx
比例：9-7-1（典型 971）
十元：Z → X
顺序感：312（被拖进去）
方向：攻击
能量状态：极高
视觉感受：强光、命令感
判定句：
我出现，你被卷入

⑥ 涩色调 · xz
比例：2-7-8（典型 278）
十元：X → Z
顺序感：231 / 312（拉扯）
方向：对抗
能量状态：冲突
视觉感受：不适、摩擦
判定句：
想发生，但不断受阻

⑦ 暗色调 · x
比例：1-3-9（典型 139）
十元：X
顺序感：321（被拖入深处）
方向：下沉
能量状态：低能量 + 高代价
视觉感受：危险、不可逆
判定句：
结果先于理解出现

⑧ 钝色调 · nx
比例：5-6-3（典型 563）
十元：N → X
顺序感：213（结果说了算）
方向：被压住
能量状态：有重量，无爆发
视觉感受：迟滞、拖慢
判定句：
世界在，但行动被压制

⑨ 弱色调 · xn
比例：3-3-1（典型 331）
十元：X → N
顺序感：213 / 123
方向：耗散
能量状态：极低
视觉感受：虚弱、被动
判定句：
只剩最低限度的存在
