## 核心体系速查

```
三元：Z=张扬(显现) X=醒目(欲望) N=耐看(包裹)
十元：ZX x并z ZN z N nz xn nx XZ x
规律：顺时针相生 / 逆时针相克 / 直径互补

五维：
  时间 = xn+z（制度+张扬）
  空间 = x并z+n（适配+承载）
  因果 = zx+nx（突破+暗流）
  命运 = xz+nz（猎手+沉溺）
  本体 = zn+x（感染+醒目）
```
