# 自然之灵 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

## v0 空间母体层

### 神木森林
is-a 有灵古森林
整个森林的树木像是有意识般排列——树干上长着像眼睛一样的天然节疤、树冠在头顶形成活的天蓬、风吹过时树叶发出低语般的沙沙声
可用于场景：初次踏入灵界 / 自然意志 / 万物有灵

### 灵泉山谷
is-a 灵性泉水峡谷
从山壁裂缝中涌出的泉水散发着淡蓝色的微光、泉水流经的岩石上长着发光苔藓、山谷中水声如铃
可用于场景：精灵饮水 / 治愈场景 / 灵泉沐浴

### 兽径圣地
is-a 动物迁徙通道
由无数动物踩出的蜿蜒小径穿越密林、路径两侧的树枝上挂着脱落的鹿角与兽毛、地面有深深的动物足印
可用于场景：动物集体迁徙 / 追踪兽踪 / 原始野性

### 巨根洞穴
is-a 树根自然洞穴
上古神木的根系在地面以下形成了天然的拱形隧道网、根如巨柱般支撑着土层的穹顶、根缝中渗出发光的树汁
可用于场景：地下穿越 / 树根通道 / 自然殿宇

### 风语草原
is-a 有灵草原
起伏的丘陵草地上、风在草尖上滑过时发出细碎的哨音——像无数看不见的东西在低语、草浪的节奏仿佛有心跳
可用于场景：草原奔跑 / 风的声音 / 追逐灵体

### 灵鹿湖畔
is-a 灵鹿饮水湖
被古老林木包围的静谧湖泊、湖面上终年薄雾、湖边有被踩实的光滑兽径通往水面、湖水清澈得能见到底部的白石
可用于场景：动物聚集 / 灵鹿现身 / 宁静场景

### 花冠丘陵
is-a 野花覆盖丘陵
连绵的丘陵在特定季节被一层层野花覆盖——从低处的白色到高处的紫色渐变、风来时花海涌动如彩浪
可用于场景：远景观花 / 浪漫场景 / 季节感

### 蘑菇环庭
is-a 虚幻菌类庭院
林间空地中出现的巨大蘑菇群围成的完美圆形——蘑菇的颜色从荧光蓝到艳红不等、孢子粉末在空气中发光飘浮
可用于场景：精灵/仙女聚集 / 超自然场景 / 童话感

### 溪流神龛
is-a 溪边自然神龛
自然巨石在溪流拐弯处形成的天然神龛状凹陷、石面上长满苔藓与蕨类、常年有流水从石面淌下、当地动物在此饮水
可用于场景：敬拜自然 / 小憩冥想 / 动物饮水

### 生命根系迷宫
is-a 树根迷宫地貌
无数古树根在地表蜿蜒隆起形成一人高的根墙、根与根之间形成天然的迷径、地面铺满了落叶、迷径中时闻水声但不见水源
可用于场景：迷宫追逐 / 根阵探索 / 植物秘密

## v1 典型空间层（以神木森林为上位）

### 神木森林废墟
is-a 废弃有灵森林遗迹（上位：神木森林）
森林中残存着某种古老祭仪的痕迹——半埋的石板排列成发光的同心圆、中央竖着一根刻满符文的柱石、树根从石板缝隙中穿出
可用于场景：古代祭仪遗迹 / 自然与过去的对话 / 能量节点

### 神木森林圣所
is-a 废弃自然圣所（上位：神木森林）
由一棵巨树的天然树洞扩展而成的空间、树皮内壁被磨得光滑如镜、地面上排列着鹿角与兽骨——曾用于某种通灵仪式
可用于场景：萨满仪式 / 灵界入口 / 树心冥想

### 神木森林大厅
is-a 废弃林地集会厅（上位：神木森林）
一圈天然石台围合出圆形空地、地面被踩得坚实光滑、周围树桩上残留着炭化的火痕——过去部落在此集会
可用于场景：部落集会遗迹 / 篝火记忆 / 旧时歌声

### 神木森林回廊
is-a 废弃林地通道（上位：神木森林）
两排古树自然形成的拱形隧道、树冠在头顶交错成天然的拱顶、阳光在树冠间形成斑斓的光柱
可用于场景：穿越灵界 / 光之隧道 / 神圣通道

### 神木森林祭坛
is-a 废弃自然祭坛（上位：神木森林）
自然形成的圆形石台微微高于周围地面、石面中央有一个天然的碗状凹陷收集着雨水、祭坛周围的树枝上挂着褪色的布条与兽骨
可用于场景：自然献祭 / 灵魂祈祷 / 许愿之地

### 神木森林庭院
is-a 废弃林地庭落（上位：神木森林）
古树倒伏后形成的林间空地——横倒的树干成为天然的围栏与座椅、空地上长满了野花与蘑菇、像被遗忘的花园
可用于场景：短暂歇脚 / 发现惊喜 / 林间小憩

### 神木森林钟楼
is-a 废弃林地高台（上位：神木森林）
一棵极高耸的古树树冠突破林冠线、树梢上挂着风化严重的大铃铛（不知是谁挂上去的）——风来时铃铛发出低沉的一声
可用于场景：林冠俯瞰 / 风铃之声 / 守望高塔

### 神木森林地下层
is-a 废弃林地地下（上位：神木森林）
树根之下更深层的洞穴——根须像血管一样密布在洞壁上、地面是潮湿的黑土混着碎石、能感受到来自更深处的气流
可用于场景：通向地下灵界 / 根之深渊 / 大地之息

### 神木森林入口
is-a 废弃林地入口（上位：神木森林）
两株古树的枝干在头顶交叉形成天然的拱门、拱门下有一块被踏平的草地、入口处的树干上钉着生锈的铁质圣徽——人类留下的痕迹
可用于场景：踏入灵域 / 人类与自然的边界 / 入口仪式

### 神木森林核心区
is-a 废弃林地中心（上位：神木森林）
整个森林能量最浓郁的地方——地面上的苔藓自发地发出幽绿色的光、树根在地表编织成规则的几何图案、中央有一口发光的树汁泉眼
可用于场景：世界树之心 / 灵脉节点 / 能量爆发点

## v2 状态侵蚀层（以神木森林废墟为上位）

注意：自然之灵的"花蔓侵蚀"与其他子类的语义不同——因为自然之灵本身就是自然，所以这里的"侵蚀"不是外来的破坏，而是自然灵力被污染或异化的状态。

### 神木森林废墟被花蔓侵蚀
is-a 灵花覆盖废墟（上位：神木森林废墟）
与龙与魔法/精灵森林的粉白色花蔓不同——这里的花是深紫色与血红色的、花瓣厚实如肉质、花朵大得不正常（能包住人的拳头）
可用于场景：异样繁茂 / 灵力过剩 / 非自然之花

### 神木森林废墟被荆棘缠绕
is-a 恶棘封锁废墟（上位：神木森林废墟）
荆棘的刺上长了倒钩、藤蔓粗如成人手臂、它们缠绕的方式是有方向的——像是故意封锁了通往某个方向的道路
可用于场景：自然有意志地封锁 / 不容通过 / 恶意藤蔓

### 神木森林废墟被树根穿刺
is-a 根系撕裂废墟（上位：神木森林废墟）
树根不再是安静地生长——而是狂暴地钻出地面、像触手一样扭曲上升、将石板卷起撕碎、根尖扎穿了树干
可用于场景：自然暴走 / 根之怒 / 大地失控

### 神木森林废墟被苔藓覆盖
is-a 荧光苔藓废墟（上位：神木森林废墟）
苔藓不是普通的绿色——而是发出幽蓝色与琥珀色交织的荧光、在黑暗中整个废墟像星空、苔藓摸上去温热（活的）
可用于场景：发光林地 / 灵界夜色 / 活的苔原

### 神木森林废墟被菌丝寄生
is-a 灵菌废墟（上位：神木森林废墟）
菌丝在废墟中组成了规则的同心圆——像是某种有意识的书写、蘑菇的颜色是不自然的亮橙色与蓝色、孢子有致幻效果
可用于场景：萨满迷幻境 / 菌丝意识 / 精灵之毒

### 神木森林废墟被黑雾吞没
is-a 阴郁灵雾废墟（上位：神木森林废墟）
雾不是普通的雾——它是青黑色的、贴着地面和树干流动、雾中隐约可见非实体的轮廓在移动、雾的核心有低沉的大地嗡鸣
可用于场景：灵雾笼罩 / 阴界入口 / 不可见之物

### 神木森林废墟被冰晶封存
is-a 反常冰封废墟（上位：神木森林废墟）
冰晶从树汁内部生长——树枝被自己的汁液冻裂、石面上的水滴被冻成尖锐的冰针、冰不是透明的而是乳白色的
可用于场景：自然被自身冻住 / 反常气候 / 冰封灵脉

### 神木森林废墟被血迹污染
is-a 献祭血迹废墟（上位：神木森林废墟）
血迹呈环状洒落——像是被某种动物拖行形成的圆圈、血迹早已干透变黑但颜色异常黑（不像普通动物的血）
可用于场景：祭祀遗迹 / 动物牺牲 / 灵界契约

### 神木森林废墟被月光空壳化
is-a 月光漂白废墟（上位：神木森林废墟）
月光下的森林灵体会显出"外壳"——树皮呈现出骨质的白色、叶脉在月光下透明如血管、林中浮现出淡蓝色的轮廓（灵体的影子）
可用于场景：月下灵显 / 灵界与凡间重叠 / 可见的魂

### 神木森林废墟被星尘异化
is-a 星灵降临废墟（上位：神木森林废墟）
银色的星尘像粉末般覆盖着树叶与苔藓、树皮上出现了不自然的晶状凸起、空气中有臭氧的气味——灵界与星界在此交汇
可用于场景：星界降临 / 灵力突变 / 灵的进化

## v3 内部功能空间层（以神木森林废墟被花蔓侵蚀为上位）

### 神木森林废墟被花蔓侵蚀中央空间
is-a 灵花废墟中心（上位：神木森林废墟被花蔓侵蚀）
最大的空地被深紫色巨花占据——花的直径可达两米、花蕊向上挺立指向天空、地面上铺满了肥厚的肉质花瓣
可用于场景：花之领域 / 灵花丛中 / 异花围困

### 神木森林废墟被花蔓侵蚀祭坛空间
is-a 灵花废墟祭坛（上位：神木森林废墟被花蔓侵蚀）
在灵花最密集的正中央有一块青色石台——只有这块石台寸花不生、石面上流动着暗红色的光纹、周围的灵花全部朝向石台
可用于场景：灵力汇聚点 / 被标记的祭台 / 不要站上去

### 神木森林废墟被花蔓侵蚀回廊空间
is-a 灵花废墟走廊（上位：神木森林废墟被花蔓侵蚀）
灵花的茎秆长到成人腰部高度形成天然的回廊墙壁、花瓣在头顶交错成拱、行走时花瓣拂过身体
可用于场景：花中穿行 / 香气眩晕 / 遮挡视线

### 神木森林废墟被花蔓侵蚀洗礼池
is-a 灵花废墟泉池（上位：神木森林废墟被花蔓侵蚀）
灵花根部汇聚的泉水变成了深紫色、水面漂浮着脱落的肉质花瓣——水闻起来有浓郁的草药味、用手触碰会留下淡紫色的印记
可用于场景：灵泉染色 / 花汁之池 / 异化之水

### 神木森林废墟被花蔓侵蚀祈祷室
is-a 灵花废墟小室（上位：神木森林废墟被花蔓侵蚀）
数根粗壮的花茎在地面与头顶之间交织成封闭的笼状空间、内部仅容一人蹲坐、光线被花瓣过滤成紫色
可用于场景：困在花中 / 被自然隔绝 / 独处冥思

### 神木森林废墟被花蔓侵蚀花窗大厅
is-a 灵花废墟光厅（上位：神木森林废墟被花蔓侵蚀）
阳光穿过深紫色半透明的花瓣投下全紫色的光——整个空间浸泡在紫光中、所有物体的颜色都被染成紫调
可用于场景：单色光空间 / 紫光浸染 / 超现实色调

### 神木森林废墟被花蔓侵蚀地下墓穴
is-a 灵花废墟根墓（上位：神木森林废墟被花蔓侵蚀）
深紫色巨花的根扎入了地下土层中、根部缠绕着不知年代的动物骨骸——根从骨骸中汲取养分、骨殖呈现紫色
可用于场景：养分循环 / 根缠白骨 / 自然回收

### 神木森林废墟被花蔓侵蚀钟楼
is-a 灵花废墟高塔（上位：神木森林废墟被花蔓侵蚀）
一棵枯死的巨树顶部被灵花的花冠取代——巨大的紫色花朵在树梢怒放、像一座花朵的灯塔/钟楼
可用于场景：花冠灯塔 / 自然信号 / 奇异地标

### 神木森林废墟被花蔓侵蚀圣像墙
is-a 灵花废墟浮雕墙（上位：神木森林废墟被花蔓侵蚀）
一面天然岩壁上、灵花的根沿着岩缝生长出类似浮雕的图案——不是人造的但看起来像是有意识的图像、像是森林在讲述什么
可用于场景：自然壁画 / 灵界消息 / 解读根迹

### 神木森林废墟被花蔓侵蚀忏悔室
is-a 灵花废墟封闭室（上位：神木森林废墟被花蔓侵蚀）
由紧密交织的花茎与藤蔓形成的密闭球状空间、内部空气潮湿而温热、只有微弱的紫光照亮——像是被自然囚禁
可用于场景：被灵花吞噬 / 窒息感 / 自然囚笼

## v4 最终复合场景层（中央空间10种变体）

### 神木森林废墟被花蔓侵蚀中央空间复合场景
is-a 灵花中心标准版（上位：中央空间）
最大的紫色灵花在中央盛开到最大尺寸、花的雄蕊向上伸张如手臂、周围的小花朝向外围辐射排列——像一张由花构成的王座
可用于场景：花的王座 / 自然之灵现身 / 标准大全景

### 神木森林废墟被花蔓侵蚀中央空间镜面版
is-a 灵花中心倒影版（上位：中央空间）
中央地面的浅水洼倒映着巨型紫花——花和倒影形成上下对称结构、花瓣的颜色在水面反射中变成紫色与粉色交织的幻影
可用于场景：花与倒影 / 上下镜像 / 自然对称

### 神木森林废墟被花蔓侵蚀中央空间沉水版
is-a 灵花中心水淹版（上位：中央空间）
地下水位上升没过地面、灵花根部泡在水中、紫色的花汁在水中扩散形成淡紫色的渐变——水也被染色了
可用于场景：涉水而行 / 紫色水域 / 染色水景

### 神木森林废墟被花蔓侵蚀中央空间月光版
is-a 灵花中心月夜版（上位：中央空间）
满月之夜灵花的花瓣关闭合拢成紫色花苞、只有雄蕊从闭合的花瓣中露出、在月光下呈现银白色——像一座闭合的巨大手掌
可用于场景：花闭月夜 / 等待天明 / 夜的宁静

### 神木森林废墟被花蔓侵蚀中央空间黑水版
is-a 灵花中心污染版（上位：中央空间）
灵花开始枯萎——花瓣边缘卷曲发黑、深色的腐液从花茎上滴落汇成黑色的水洼、空气中有腐败的甜臭味
可用于场景：腐败之花 / 花之死 / 异化终结

### 神木森林废墟被花蔓侵蚀中央空间环形祭坛版
