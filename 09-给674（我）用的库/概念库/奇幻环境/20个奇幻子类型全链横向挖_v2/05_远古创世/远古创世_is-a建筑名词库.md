# 远古创世 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

---

## v0 空间母体层

### 原初大陆
is-a 未成型大陆
混沌初始的陆地——地面是黑灰色的玄武岩与红土混杂、没有植被、天空中翻滚着紫色的云层、远处的山脉轮廓还未定形
可用于场景：世界初生 / 未命名之地 / 创世之始

### 巨神遗迹
is-a 神级巨构遗迹
比人类尺度大十倍的巨石建筑残骸——门框高30米、台阶宽如广场、散落的砌块上刻着无法解读的凹槽纹理
可用于场景：人类在巨神面前 / 比文明更早的造物 / 遗迹探索

### 创世裂谷
is-a 大地裂口
大地被撕开的巨型裂缝——裂谷深不见底、从深处涌出暗红色的光与蒸汽、裂谷边缘的岩石被高温熔化成玻璃状
可用于场景：接近创世之核 / 大地喉咙 / 不可靠近

### 世界树根部
is-a 宇宙树基座
比山脉还粗的树根从地下隆起、根的表皮像岩石一样灰硬、根与根之间有巨大的空洞可以走人、树汁是金色的
可用于场景：树根峡谷 / 世界之基 / 缓慢的生命

### 方舟坟场
is-a 废弃方舟遗迹
多艘巨大古代方舟的残骸搁浅在干涸的平原上——船体是黑木与金属的混合结构、肋骨般裸露的船架指向天空
可用于场景：末日后 / 不知名的迁移 / 船之墓地

### 星核祭坛
is-a 陨石核心祭坛
一颗坠落的星核嵌在大地上——星核表面是深蓝色的晶体半透明、内部可以看到缓慢流动的光、周围的土地被晶体化
可用于场景：星核能量 / 异界物质 / 触摸星星

### 太初海岸
is-a 原始海洋边界
世界的第一片海滩——沙是黑色的火山沙混着白色碎骨、海浪拍打的是形状奇怪的岩石（不像普通海蚀）、空气中硫磺味重
可用于场景：原始之海 / 生命起源 / 边界之地

### 巨石阵原野
is-a 史前巨石阵
比任何已知文明更早的巨石排列——每块巨石高20米以上、排列成多层同心圆、石面上有螺旋状凹槽（非文字）
可用于场景：比文明古老 / 天文标记 / 不可知的目的

### 初火山脉
is-a 原始火山链
世界上第一批火山——呈链状排列、部分还在喷发、岩浆呈蓝白色（极高温）、火山灰是浅灰色的覆盖了周围一切
可用于场景：烈火世界 / 地貌锻造 / 不可靠近

### 未命名荒原
is-a 未被定义地貌
一片什么都没有的平原——没有植物、没有动物、没有风、地面是均匀的灰色沙砾、天空中也没有云——纯粹的空白
可用于场景：虚无之地 / 创世前的寂静 / 等待被定义

## v1 典型空间层（以原初大陆为上位）

### 原初大陆废墟
is-a 远古荒原残迹（上位：原初大陆）
不知名建筑的黑石残骸散落在荒原上——石块上无任何装饰雕刻、纯粹的功能性结构、但建造技术明显不属人类
可用于场景：非人遗迹 / 远古残墙 / 历史真空

### 原初大陆圣所
is-a 远古荒原圣殿（上位：原初大陆）
一块独石（monolith）竖立在荒原上——表面光滑到不自然、顶部呈完美的平面、像被激光切割过、周围没有任何其他结构
可用于场景：独石之谜 / 呼唤谁 / 走向不可知

### 原初大陆大厅
is-a 远古荒原巨厅（上位：原初大陆）
天然岩洞与人工切割的界限模糊的巨厅——巨石从洞顶悬挂、地面被磨平、大厅中央有一根由黑石雕成的圆柱（用途不明）
可用于场景：巨柱之厅 / 远古集会 / 不可知功能

### 原初大陆回廊
is-a 远古荒原廊道（上位：原初大陆）
两排巨石的间隙形成通道——巨石不是建筑的柱子、它们像是原地生长出来的、排列方向精确指向正北
可用于场景：列石通道 / 指向未知 / 荒原路径

### 原初大陆祭坛
is-a 远古荒原献祭台（上位：原初大陆）
一块深色的倾斜巨石——台面中央有凹陷的槽道通向边缘、槽道内是暗红色的沉淀物（可能是血、也可能是铁矿石被水冲蚀的痕迹）
可用于场景：史前祭祀 / 血槽石台 / 第一个牺牲

### 原初大陆庭院
is-a 远古荒原围场（上位：原初大陆）
巨石围合出的矩形空地——地面均匀地覆盖着一层白色的细沙、没有脚印、没有生物痕迹、沙子像被刻意铺平的
可用于场景：白沙围场 / 等待什么降临 / 干净的场地

### 原初大陆钟楼
is-a 远古荒原高塔（上位：原初大陆）
天然石柱在荒原上拔地而起——形状像一座扁平的塔、顶部有天然形成的孔洞、风穿过孔洞时发出低沉的嗡鸣
可用于场景：风鸣之塔 / 自然形成的乐器 / 孤塔

### 原初大陆地下层
is-a 远古荒原地下（上位：原初大陆）
地面的裂缝通向地下的空洞网络——洞壁上覆盖着发光的黑色晶体、空气温热而干燥、能听到来自深处的低频震动（不是水）
可用于场景：地下晶洞 / 大地脉动 / 深入未命名

### 原初大陆入口
is-a 远古荒原入口（上位：原初大陆）
荒原地面突然下陷的坑洞——像一个漏斗状入口、边缘的岩石呈螺旋形排列（像是被水或风或某种力量螺旋切割出来的）
可用于场景：通向地下世界入口 / 螺旋下潜 / 踏入未知

### 原初大陆核心区
is-a 远古荒原中心（上位：原初大陆）
荒原最中心的区域——不是建筑而是一个精确的圆形区域、圆形边界线清晰（像是被激光画出来的）、圆内的气流不流动、完全静止
可用于场景：绝对静止 / 能量零点 / 圆心

## v2 状态侵蚀层（以原初大陆废墟为上位）

注意：远古创世的"被侵蚀"有特殊含义——原始物质被后来的生命/时间/世界改造。这里的废墟本就不是人类的，所以入侵者也是另一种"第一次"。

### 原初大陆废墟被花蔓侵蚀
is-a 第一次花开废墟（上位：原初大陆废墟）
灰黑色巨石上长出了世界上的第一批花——花很小、颜色偏白偏淡、花瓣薄到半透明、像不确定自己是否应该存在
可用于场景：生命的试探 / 第一个颜色 / 温柔入侵

### 原初大陆废墟被荆棘缠绕
is-a 第一道荆棘（上位：原初大陆废墟）
荆棘是深紫色的——不是植物该有的颜色——尖端锋利如刺、缠在灰石上像活着的铁丝网
可用于场景：异色荆棘 / 第一道防御 / 不友善的生命

### 原初大陆废墟被树根穿刺
is-a 第一棵树入侵（上位：原初大陆废墟）
灰白色的树根像骨骼一样贯穿了黑石——树根不是褐色而是骨白色、从碎石中伸出如巨大的手指
可用于场景：骨白之根 / 新旧争夺 / 永恒与新生

### 原初大陆废墟被苔藓覆盖
is-a 第一层苔藓（上位：原初大陆废墟）
橙色与黑色的地衣苔藓在灰石上成片长开——像铁锈一样附着、摸上去像硬的痂——苔藓不像在"覆盖"而像在"侵蚀"
可用于场景：岩上锈色 / 缓慢吞噬 / 第一层生命

### 原初大陆废墟被菌丝寄生
is-a 第一片菌群（上位：原初大陆废墟）
灰白色的巨大蘑菇从巨石缝隙中挤出——蘑菇的伞盖上有像眼睛一样的同心圆纹路、菌丝在石面上爬出星状图案
可用于场景：巨菇之眼 / 大地长菌 / 寂静繁衍

### 原初大陆废墟被黑雾吞没
is-a 原初黑雾（上位：原初大陆废墟）
这里的黑雾不是外来的——它从原初大陆本身的地缝中涌出、颜色黑到吞噬光线、雾中有微弱的磷光闪烁
可用于场景：大地自生的夜 / 不可见深渊 / 雾就来自脚下

### 原初大陆废墟被冰晶封存
is-a 远古冻结（上位：原初大陆废墟）
冰晶不是水冻结的——是岩石缝隙中长出的矿物晶体、呈冰蓝色半透明、像冰但密度更大、包裹着巨石仿佛镀了一层玻璃壳
可用于场景：矿物之冰 / 晶体封存 / 大地凝固

### 原初大陆废墟被血迹污染
is-a 第一次流血（上位：原初大陆废墟）
黑石上的暗红血迹——已经干涸到发黑——但在这个没有生物的原初大陆上血迹本不该存在——它从哪里来的？
可用于场景：第一笔罪 / 不该存在的红 / 未解之痕

### 原初大陆废墟被月光空壳化
is-a 月下原初（上位：原初大陆废墟）
月光下的原初大陆废墟显露出白天看不见的纹路——巨石表面的凹槽在月光下呈现银白色、像是某种地图或星图
可用于场景：月光显形 / 暗纹夜现 / 被月照亮的秘密

### 原初大陆废墟被星尘异化
is-a 星尘降临（上位：原初大陆废墟）
银蓝色的星尘如雪般覆盖在巨石上——星尘发出微弱的冷光、风来时星尘从石面上扬起像雾一样飘散
可用于场景：星尘覆盖 / 天外来客的礼物 / 发光的尘埃

## v3 内部功能空间层（以原初大陆废墟被花蔓侵蚀为上位）

### 原初大陆废墟被花蔓侵蚀中央空间
is-a 第一花中央（上位：原初大陆废墟被花蔓侵蚀）
黑色巨石围合的圆形空地——中心处有一片白色小花簇拥着一个低矮的天然石台、石台表面光滑到反射天空
可用于场景：花与石台 / 原始舞台 / 第一个中心

### 原初大陆废墟被花蔓侵蚀祭坛空间
is-a 第一花祭坛（上位：原初大陆废墟被花蔓侵蚀）
倾斜的黑石台面上白色小花呈螺旋状排列生长——像是花自己知道该怎么摆、螺旋的中心指向天空
可用于场景：花之螺旋 / 祭坛的自发仪式 / 自然指向

### 原初大陆废墟被花蔓侵蚀回廊空间
is-a 第一花走廊（上位：原初大陆废墟被花蔓侵蚀）
两排巨石之间的缝隙被白色小花沿两侧排开——像仪仗队的白花行列、中间留出的通道笔直通向远方
可用于场景：白花仪仗 / 自然铺开的走廊 / 走入

### 原初大陆废墟被花蔓侵蚀洗礼池
is-a 第一花水池（上位：原初大陆废墟被花蔓侵蚀）
天然石碗状的凹陷积累着雨水——水面平静、白花的倒影在水中、水底有白色小花振动水流不成的样子
可用于场景：石碗浅水 / 花影相映 / 第一次倒影

### 原初大陆废墟被花蔓侵蚀祈祷室
is-a 第一花小间（上位：原初大陆废墟被花蔓侵蚀）
三面黑色巨石围出的凹室、开口朝向东方——白色小花在这里长得最密、花丛中露出一块手掌大的扁平白石（像祭器）
可用于场景：天然祈祷室 / 花丛白石 / 朝拜方向

### 原初大陆废墟被花蔓侵蚀花窗大厅
is-a 第一花光厅（上位：原初大陆废墟被花蔓侵蚀）
黑色巨石搭成的半开放空间——顶部有天然裂缝、光穿过白色的花丛投下斑驳的阴影在地面上、花影随日光移动
可用于场景：光与花影 / 时间标记 / 原始日晷

### 原初大陆废墟被花蔓侵蚀地下墓穴
is-a 第一花地下（上位：原初大陆废墟被花蔓侵蚀）
向下的裂缝两侧长着白色的花——花只在裂缝口有、再往下就没了——像它们是边界线、下面是无花的纯黑
可用于场景：入地之口花标记 / 花与暗的分界 / 地下入口

### 原初大陆废墟被花蔓侵蚀钟楼
is-a 第一花石塔（上位：原初大陆废墟被花蔓侵蚀）
一块孤立高耸的黑色巨岩——岩顶的裂缝中长出一丛白花、像给石头戴了一顶花冠——远看像是荒原上的白色信标
可用于场景：花冠石柱 / 荒原路标 / 石头开花

### 原初大陆废墟被花蔓侵蚀圣像墙
is-a 第一花石壁（上位：原初大陆废墟被花蔓侵蚀）
一面巨大的黑色石壁——白色小花沿着石面上的自然裂纹生长、裂纹像是花的根引导出来的——花在画什么
可用于场景：花随脉走 / 岩石被花重新划界 / 活着的壁画

### 原初大陆废墟被花蔓侵蚀忏悔室
is-a 第一花夹缝（上位：原初大陆废墟被花蔓侵蚀）
两块巨石之间的狭窄夹缝——宽仅容一人侧身通过、夹缝底部有一丛白色的花在微风中动（是这个夹缝里唯一等光线）
可用于场景：侧身而过 / 夹缝中的花 / 唯一的亮色

## v4 最终复合场景层（中央空间10种变体）

### 原初大陆废墟被花蔓侵蚀中央空间复合场景
is-a 第一花中心标准版（上位：中央空间）
黑色的石台浮在白色的花海中央——不是真的浮、而是石台被白花围在中央形成视觉的"升腾"感、石台上方有一束天光打下来
可用于场景：花海石台 / 天命降临 / 标准大全景

### 原初大陆废墟被花蔓侵蚀中央空间镜面版
is-a 第一花中心倒影版（上位：中央空间）
地面的浅水洼映出天空和小白花——倒影中的花数量比现实多一倍、天空在水中的颜色比现实更蓝——水在欺骗
可用于场景：水骗人 / 倒影美化现实 / 真假边界

### 原初大陆废墟被花蔓侵蚀中央空间沉水版
is-a 第一花中心水淹版（上位：中央空间）
积水没过小腿——白花泡在水中的根看得一清二楚、水面上的花瓣被水浸湿呈半透明、走路时搅动水花能闻到淡淡的草味
可用于场景：涉花而行 / 水中花根 / 第一次雨水

### 原初大陆废墟被花蔓侵蚀中央空间月光版
is-a 第一花中心月夜版（上位：中央空间）
月光下白色的小花合拢成花苞、黑色的石台在月光下泛出青灰色的光泽——白天温暖的黑石在夜里是冰冷的
可用于场景：花闭夜 / 温差之景 / 冷漠的月下

### 原初大陆废墟被花蔓侵蚀中央空间黑水版
is-a 第一花中心污染版（上位：中央空间）
不知从何而来的黑色液体渗入了花丛——花开始枯萎变黄、黑色的液体在石台上留下油亮的痕迹
可用于场景：不祥的液体 / 第一朵花的死亡 / 入侵

### 原初大陆废墟被花蔓侵蚀中央空间环形祭坛版
is-a 第一花中心仪式版（上位：中央空间）
有人在黑石台上摆了一圈黑色卵石——像是人类的干涉、卵石围成一个圆形将白花圈在其中——文明与自然的第一次接触
可用于场景：第一次标记 / 圈地为界 / 文明雏形

### 原初大陆废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 第一花中心泉水版（上位：中央空间）
黑石台边缘裂开涌出清澈的泉水——泉水沿着石面流下浸入花丛、白花在泉水的滋养下格外白亮
可用于场景：清泉润花 / 水的新生 / 第一次灌溉

### 原初大陆废墟被花蔓侵蚀中央空间白花漂浮版
is-a 第一花中心白花版（上位：中央空间）
小白花的花瓣脱离花茎、在空中漂浮不落——这里的气流特殊、花瓣像雪一样悬浮在整个空间中、永不着陆
可用于场景：永不落地的花瓣 / 浮花空间 / 风与花

### 原初大陆废墟被花蔓侵蚀中央空间枯井版
is-a 第一花中心深坑版（上位：中央空间）
黑石台中央有一个直径不到半米的圆洞——洞口边缘生着一圈白花像是花环、朝里看黑洞洞的深不见底
