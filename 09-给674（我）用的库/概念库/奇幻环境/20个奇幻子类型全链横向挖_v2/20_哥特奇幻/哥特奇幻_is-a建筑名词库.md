# 哥特奇幻 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：神圣废墟、黑暗宗教、雨与雾、玫瑰与死亡。

## v0 空间母体层

### 废弃宗教建筑
is-a 哥特式宗教废墟
尖拱与飞扶壁的轮廓穿透雾气——彩色玻璃已碎裂大半——屋顶塌陷——建筑内部被蔓草占领——但整体结构依然壮丽
可用于场景：哥特全景 / 宗教遗迹 / 中心的荒芜

### 黑蔷薇庭院
is-a 哥特庭院场景
盛开的黑色月季爬满了铸铁凉亭——残破的维纳斯雕像斜倒在花丛中——大理石长椅被风雨侵蚀得光滑
可用于场景：角色登场 / 唯美中景 / 暗色花园

### 地下墓穴
is-a 哥特地下葬所
拱形砖砌的地下长廊——两侧是层层叠叠的壁龛式墓穴——烛台已空——空气中有陈腐的石灰与骨的混合气味
可用于场景：地下探索 / 尸体安放处 / 危机四伏

### 月光钟楼
is-a 哥特高处场景
巨大的圆月作为钟楼的背景——哥特尖塔与齿轮的剪影在月光下锋利——钟楼的钟摆静止
可用于场景：标志性远景 / 终帧 / 刺客登场

### 贵族古堡
is-a 哥特城堡建筑
建在悬崖上的古老城堡——深色粗石砌成——塔楼是圆形而非方形——城堡内部有悬挂祖先画像的长廊
可用于场景：吸血鬼巢穴 / 主舞台 / 贵族之家

### 尖塔城市
is-a 哥特城市天际线
密集的尖塔刺向天空——窄巷在塔楼之间蜿蜒——阴天的灰色背景衬托出无数塔尖的轮廓
可用于场景：远景城市 / 追逃 / 城市剪影

### 雾中修道院
is-a 哥特修道院
被浓雾半裹的灰石修道院——连续拱廊围合着中央回廊庭院——修士的袍子已经空了
可用于场景：探索修道院 / 秘密集会 / 信仰之地

### 彩窗审判厅
is-a 哥特审判空间
高耸的大厅——巨大的彩色玻璃窗描绘最后的审判——窗下的审判席已空——阳光透过彩窗投下彩色图案
可用于场景：审判场景 / 信仰裁决 / 彩色光斑

### 黑铁大门
is-a 哥特入口建筑
用黑铁锻造的宏伟大门——门上的铁艺花纹是荆棘与藤蔓的样式——门环是狮头
可用于场景：进入古堡或教堂 / 门禁 / 引路

### 诅咒王城
is-a 哥特王国首都
灰黑色的建筑群在山坡上层层叠叠——王宫在最高处——全城笼罩在永久的阴天中——街道是湿漉漉的
可用于场景：王城全景 / 诅咒蔓延 / 压迫的氛围

## v1 典型空间层（以废弃宗教建筑为上位）

### 圣堂废墟
is-a 废弃哥特教堂（上位：废弃宗教建筑）
一座哥特式教堂的残骸——中殿的屋顶已塌、但圣坛区的拱顶奇迹般地保留着——地面上堆积着碎石与彩色玻璃碎片
可用于场景：教堂核心废墟 / 神已不在 / 残存的圣坛

### 礼拜堂废墟
is-a 废弃小教堂（上位：废弃宗教建筑）
小型家庭礼拜堂——木质长椅已腐朽坍塌——圣坛上的十字架歪斜——墙壁上有渗水的黄斑
可用于场景：家族礼拜堂 / 个人祈祷的遗迹 / 小空间的废墟

### 修道院废墟
is-a 废弃修道院（上位：废弃宗教建筑）
修道院的宿舍区已半毁——单间的小窗还保留着——小礼拜堂的壁画已模糊不清——回廊庭院中的井已干
可用于场景：修士生活遗迹 / 独处空间 / 信仰生活结束

### 神殿废墟
is-a 废弃神殿（上位：废弃宗教建筑）
比教堂更古老的宗教建筑——石柱的柱头是科林斯式——但柱身布满了裂痕——祭台上有未熄灭的蜡烛痕迹
可用于场景：古老信仰 / 柱痕与烛迹

### 钟楼废墟
is-a 废弃钟塔（上位：废弃宗教建筑）
脱离了主体建筑的独立钟楼塔——钟已掉落在内部地面上——塔身开裂——但仍可以是高的观察点
可用于场景：独立的塔 / 掉落的钟 / 高处俯瞰

### 洗礼堂废墟
is-a 废弃洗礼空间（上位：废弃宗教建筑）
圆形独立的洗礼堂——中央的洗礼池已干——池底的马赛克图案（受洗者的灵魂升天）已被灰尘覆盖
可用于场景：洗礼池已干 / 灵魂的图案被尘盖

### 祭坛厅废墟
is-a 废弃祭坛室（上位：废弃宗教建筑）
教堂最深处的祭坛室——墙面原贴有金箔——现在金箔已大片脱落露出了下面的石膏底层——残存的金色斑驳
可用于场景：金箔剥落 / 残金祭坛 / 奢华已褪

### 地下墓穴
is-a 废弃地下墓（上位：废弃宗教建筑）
——注意这个与v0的地下墓穴重复。更准确说是教堂地下的小型墓穴——石棺紧贴墙壁排列——墙上有手写的名字
可用于场景：教堂下的小墓 / 手写名字 / 紧凑的葬

### 圣骨堂/遗骨堂
is-a 骨殖装饰空间（上位：废弃宗教建筑）
墙壁和柱子由真正的人类骨骼拼嵌而成——头骨排列成拱形装饰线——股骨构成柱子的垂直条纹
可用于场景：骨堂 / 死亡装饰 / 震撼空间

### 回廊废墟
is-a 废弃回廊（上位：废弃宗教建筑）
连接教堂与修道院的有顶走廊——拱廊的柱子还在但拱顶部分坍塌——地面铺着被踩踏了数百年的石砖
可用于场景：连续拱廊 / 有顶走廊 / 漫步废墟

## v2 状态侵蚀层（以圣堂废墟为上位）

哥特的v2侵蚀名称与前面19个都不同——用的是"XX圣堂"而不是"XX被XX侵蚀"的句式。名称本身就包含了状态。

### 花蔓侵蚀圣堂
is-a 花蔓覆盖的教堂（上位：圣堂废墟）
教堂内部被绿色藤蔓覆盖——藤蔓沿着柱身与拱顶攀爬——叶子的绿色被彩窗的彩色光照亮——自然在教堂内部重建了穹顶
可用于场景：绿藤圣堂 / 植物占领教堂 / 自然的彩窗

### 荆棘缠绕圣堂
is-a 荆棘封锁的教堂（上位：圣堂废墟）
野生的黑荆棘将大门口完全封锁——荆棘上挂着褪色的丝带（曾有人试图穿越留下的）

可用于场景：入口被棘封 / 无法进入的教堂

### 树根穿刺圣堂
is-a 树根穿入的教堂（上位：圣堂废墟）
教堂外大树的根穿过了墙壁——根部如巨蛇般在教堂内部蜿蜒——沿着地面爬向圣坛
可用于场景：根穿墙入 / 根系在教堂内延伸

### 苔藓覆盖圣堂
is-a 绿色苔衣教堂（上位：圣堂废墟）
所有表面覆盖了一层暗绿色的干燥苔藓——圣坛、长椅、雕像都被苔藓包裹成软绿色的形状
可用于场景：全苔教堂 / 每件东西都被苔穿上了衣服

### 菌丝寄生圣堂
is-a 菌丝遍布的教堂（上位：圣堂废墟）
淡蓝色发光菌丝在彩窗旁编织出新图案——菌丝在黑暗中发光——勾勒出了拱肋与尖顶的轮廓
可用于场景：蓝光菌堂 / 发光的轮廓线

### 黑藤污染圣堂
is-a 黑藤覆盖的教堂（上位：圣堂废墟）
深黑色的藤蔓——不是植物而是异化的霉菌集合体——覆盖了半个教堂——藤蔓触及之处的石头变黑
可用于场景：黑藤蔓延 / 石头被染黑

### 白花占据圣堂
is-a 白花满堂的教堂（上位：圣堂废墟）
纯白色的野花从祭坛到大门密集开放——教堂的地面变成了白色花毯——圣坛的位置被花衬得格外白
可用于场景：白花教堂 / 圣坛在花中 / 纯色的覆盖

### 红蔷薇圣堂
is-a 红蔷薇缠绕的教堂（上位：圣堂废墟）
深红色的野蔷薇攀上教堂外墙——红色与黑色石墙形成刺眼对比——教堂像披了一件深红色的袍子
可用于场景：红蔷薇教堂 / 刺眼的红色 / 血色之花

### 枯藤干裂圣堂
is-a 枯藤教堂（上位：圣堂废墟）
藤蔓已干枯成为褐色——像干燥的血管一样贴在墙上——一碰就碎、露出下面墙上的裂缝
可用于场景：枯藤教堂 / 一触即碎的年代

### 水草沉没圣堂
is-a 水下教堂（上位：圣堂废墟）
被淹没的教堂——水至腰部——绿色水草在柱间飘荡——彩窗在水下透过的光是斑驳的绿色
可用于场景：被淹没的教堂 / 水中彩光 / 半水下

## v3 内部功能空间层（以花蔓侵蚀圣堂为上位）

### 中央圣池_祭坛水庭
is-a 祭坛水池庭院（上位：花蔓侵蚀圣堂）
圣坛位置被改造成了一个浅水池——水中倒映着上方的藤蔓与天空——水是清澈的——可以看到池底的马赛克图案
可用于场景：圣坛变水池 / 倒影中庭 / 水与光的结合

### 花蔓祭坛厅
is-a 藤蔓缠绕的祭坛室（上位：花蔓侵蚀圣堂）
圣坛本身已被花蔓包裹成绿色的小丘——原本的祭坛形状已经不可辨认——只有祭坛的台面高度还隐约可见
可用于场景：祭坛成绿丘 / 圣坛被花吞

### 藤蔓回廊
is-a 绿色拱廊（上位：花蔓侵蚀圣堂）
回廊的拱顶上垂满了藤蔓——像绿色的钟乳石——光透过叶子的间隙投下跳跃的圆点
可用于场景：藤蔓拱廊 / 绿色光点 / 穿行

### 白花洗礼池
is-a 开花的洗礼池（上位：花蔓侵蚀圣堂）
洗礼池中积着雨水——水面上漂满了白色花瓣——池底积着厚厚的白色花瓣沉淀物
可用于场景：洗礼池花瓣满 / 水上白瓣 / 圣洁的覆盖

### 黑蔷薇祈祷室
is-a 黑玫瑰祈祷间（上位：花蔓侵蚀圣堂）
祈祷室的窗外长着黑蔷薇——透过碎裂的窗格可以看到黑色花朵与黄昏的暗红天空
可用于场景：黑蔷薇窗外 / 祈祷与死亡的结合

### 花窗藤影大厅
is-a 彩窗藤影厅（上位：花蔓侵蚀圣堂）
彩窗的光穿过藤蔓——在地面和墙壁上投下藤蔓的复杂影子与彩色光斑交叠——影子在光中跳舞
可用于场景：彩色光影交叠 / 藤影与彩窗重合

### 根须地下墓穴
is-a 根系穿过地下墓（上位：花蔓侵蚀圣堂）
地下墓穴的顶部被根须穿透——根须垂下如帘、在烛光中摇摆——根须触摸着石棺
可用于场景：根须地下墓 / 根如帘 / 根触棺

### 藤蔓钟楼
is-a 绿色钟塔（上位：花蔓侵蚀圣堂）
钟楼内部的楼梯被藤蔓覆盖成了绿色阶梯——攀爬时手扶着藤蔓而不再是石墙——藤蔓代替了扶手
可用于场景：藤楼梯 / 爬钟楼花蔓代扶

### 花藤圣像墙
is-a 花蔓覆盖圣像墙（上位：花蔓侵蚀圣堂）
墙上的圣像浮雕——花蔓沿着圣像的轮廓生长——像是给圣人穿上了绿色的法衣
可用于场景：圣像穿绿衣 / 浮雕与藤合体

### 水镜忏悔室
is-a 水面倒影的忏悔间（上位：花蔓侵蚀圣堂）
木质忏悔室已腐朽倒下——倒下的位置形成了一个浅水洼——水洼倒映着空无一人的隔间——忏悔间只剩倒影
可用于场景：倒下的忏悔室 / 水中倒影 / 只剩镜像

## v4 最终复合场景层（以中央圣池_祭坛水庭为上位）

### 花蔓祭坛水庭
is-a 标准花蔓水庭（上位：中央圣池_祭坛水庭）
圣坛水池——花蔓从水池边缘垂下接触水面——水面倒映着花蔓与天空——水池中央的十字架底座露出水面
可用于场景：标准全景 / 花蔓垂水 / 水映十字

### 镜面花蔓圣池
is-a 镜面水池版（上位：中央圣池_祭坛水庭）
水面完全静止如镜——倒影中的花蔓与实物形成对称——水面上没有一丝涟漪——像一面深色的玻璃
可用于场景：如同镜面的水 / 对称倒影 / 静到不真实

### 沉水花蔓祭坛
is-a 淹没祭坛版（上位：中央圣池_祭坛水庭）
水位上升至淹没祭坛——花蔓泡在水中——水面下的藤蔓在水底摇摆——祭坛的顶端刚好露出水面
可用于场景：半没祭坛 / 水下藤摇 / 祭坛冒头

### 月光花蔓水庭
is-a 月夜水庭版（上位：中央圣池_祭坛水庭）
月光洒在水池上——水中的倒影与月光融合——花蔓在月光下呈现银灰色——整个水池像一面银镜
可用于场景：月下水庭 / 银色的池 / 月与藤的银光

### 黑水花蔓圣池
is-a 黑水版（上位：中央圣池_祭坛水庭）
水变成了不透明的黑色——花蔓的倒影消失了——水面只能映出最亮的光点——像墨水一样吞没反射
可用于场景：黑水吞噬 / 光点浮于黑 / 池变成了无底洞

### 环形花渠祭坛
is-a 环形水道版（上位：中央圣池_祭坛水庭）
水被引导成环绕祭坛的环形浅渠——水在环中流动（不止是静止）——花蔓沿着渠边生长
可用于场景：环形流动的水渠 / 活水环绕祭坛

### 裂缝花泉
is-a 泉水喷涌版（上位：中央圣池_祭坛水庭）
水池中央的地面裂开涌出泉水——水流推动花蔓摆动——水声在教堂中回荡——打破了几百年的寂静
可用于场景：泉水活涌 / 水流声响 / 新生命

### 白花漂浮圣池
is-a 白花满池版（上位：中央圣池_祭坛水庭）
水面上覆盖了一层纯白的花瓣——看不到水面——整个水池看起来是白色的固态平面——花瓣沉下去后会浮起新的
可用于场景：白色花毯水面 / 看不到水 / 纯白覆盖

### 枯井花蔓圣池
is-a 枯井版（上位：中央圣池_祭坛水庭）
水池中央发现了一个隐藏的排水口——拉开铁栅是一个向下的枯井——井口边缘一圈花蔓向井下观望
可用于场景：池下有井 / 花围井口 / 隐藏入口

### 终帧花房水庭
is-a 爆发版（上位：中央圣池_祭坛水庭）
花蔓上的花同时全部绽放——花的重量压低了藤蔓触及水面——水面上漾开了层层涟漪——花瓣入水的瞬间被定格
可用于场景：百花同时开 / 花触水波 / 瞬间的极致
