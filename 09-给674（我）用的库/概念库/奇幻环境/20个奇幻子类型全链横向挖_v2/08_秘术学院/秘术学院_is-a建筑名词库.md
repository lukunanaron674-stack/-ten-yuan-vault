# 秘术学院 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：知识即力量、规则决定结果、学习场所也有危险。

## v0 空间母体层

### 魔法学院
is-a 魔法教育机构
石砌的哥特式学院建筑群——尖拱窗、爬山虎覆盖的墙面、庭院中央有喷泉、拱廊下的壁龛里放着历代院长的半身像
可用于场景：入学/上课之间 / 学院全景 / 魔法学习生活

### 图书塔
is-a 魔法图书馆
圆形的高塔内部完全中空——从地面到天花板的环形书架、书脊朝外形成彩色的螺旋条纹、中央有螺旋楼梯沿书架上旋
可用于场景：找书 / 高处取书 / 静读空间

### 禁书馆
is-a 封印知识库
地下封闭书库——铁链锁着书架、每本书的封面有封印符文、书架之间的过道窄到只能侧身行走、空气中纸与灰尘的味道很重
可用于场景：禁忌知识 / 偷看书库 / 危险发现

### 法阵教室
is-a 魔法教学空间
圆形阶梯教室——地面刻着巨大的法阵图案（粉笔痕迹）天花板有画好的星象图、黑板位置是一整块打磨过的黑曜石板
可用于场景：上课场景 / 法阵教学 / 老师示范

### 星象观测台
is-a 魔法天文台
学院最高塔的顶端——半球形空间、天窗可开启、地面刻着十二星座标示、中央有一架黄铜与水晶制成的望远镜
可用于场景：夜观星象 / 预言推算 / 高处对话

### 炼金实验室
is-a 魔法化学室
长排石桌上摆满了蒸馏瓶与坩埚、墙角是草药柜与矿物标本、空气中混杂着硫磺/薄荷/铁锈的复杂气味
可用于场景：调药场景 / 爆炸实验 / 炼金术的日常

### 导师议会厅
is-a 魔法教授会议厅
圆桌会议室——桌子是整块橡木、桌面嵌着七大学派的徽章、椅子扶手上有刻名字的铜牌、墙壁挂着历任院长的肖像画
可用于场景：教授开会 / 争议决策 / 学院政治

### 宿舍回廊
is-a 学生宿舍走廊
漫长的一楼走廊——两侧是学生宿舍门（门上贴着姓名与课程表）、壁灯昏黄、走廊尽头是公共休息室有壁炉
可用于场景：课后日常 / 夜晚串门 / 熄灯后的秘密

### 考试竞技场
is-a 魔法考试场地
露天圆形竞技场——铺设红色地砖、地面有可激活的魔法阵网格、四周的看台是石阶、上方有防护魔法屏障
可用于场景：实战考试 / 对决场景 / 测试魔法

### 地下档案室
is-a 魔法档案馆
地下深处恒温恒湿的档案库——排放着无数抽屉式的文件柜、每个抽屉上贴着年份与字母编号、空气中纸的酸味重
可用于场景：查档案 / 寻找历史 / 发现秘密记录

## v1 典型空间层（以魔法学院为上位）

### 魔法学院废墟
is-a 废弃魔法学院（上位：魔法学院）
学院的某翼楼已坍塌——墙上挂着霉变的地毯残片、教室的门半开——能看到里面翻倒的桌椅、墙壁的粉笔法阵图案还依稀可见
可用于场景：学院衰落 / 一课室遗骸 / 被时间侵蚀的教育

### 魔法学院圣所
is-a 废弃魔法圣殿（上位：魔法学院）
学院的旧礼堂——讲台上的魔法水晶已碎裂成粉末、彩窗破碎、阳光从破洞射入在斑驳的地面上形成彩色光斑
可用于场景：破旧大礼堂 / 彩窗光影 / 残破的讲台

### 魔法学院大厅
is-a 废弃学院大厅（上位：魔法学院）
主厅的水晶吊灯坠落在地面上碎成千万片水晶、地面有散落的羊皮纸与羽毛笔、壁炉中的灰烬早已冷透
可用于场景：大厅废弛 / 水晶满地 / 时间停止的房间

### 魔法学院回廊
is-a 废弃学院走廊（上位：魔法学院）
走廊两侧的画像被刀划破（画像中人物的脸被划去了）、壁灯歪斜、地毯被踩出一层灰——曾有很多人从这里匆忙跑过
可用于场景：被破坏的画廊 / 逃难的痕迹 / 走廊尽头

### 魔法学院祭坛
is-a 废弃学院祭台（上位：魔法学院）
学院内的小教堂——原本供奉的不是神而是"求知"的概念——祭台是空的、只有一盏熄灭的永恒之灯（灯油已干）
可用于场景：空祭台 / 求知之火熄灭 / 无人献花

### 魔法学院庭院
is-a 废弃学院中庭（上位：魔法学院）
方形中庭——中央的喷泉雕塑（一只展翅的铜鹰）已经发绿生锈、喷泉池中的水是静止的、水面上漂着枯叶
可用于场景：喷泉铜绿 / 静止的水 / 记忆中的庭院

### 魔法学院钟楼
is-a 废弃学院钟塔（上位：魔法学院）
钟楼的四面钟已经停摆——但奇怪的是它停在午夜十二点（而不是一个随机时间）、像是被刻意定为这个时刻
可用于场景：午夜钟停 / 时间定格在十二点 / 不祥的时刻

### 魔法学院地下层
is-a 废弃学院地下室（上位：魔法学院）
通向下层的阶梯潮湿而阴暗、墙上有水渍形成的"图案"（像字但又不是）、地下室的铁门锈得无法打开
可用于场景：封死的地下室 / 墙上的假字 / 想进进不去

### 魔法学院入口
is-a 废弃学院大门（上位：魔法学院）
学院大门——原本是铁艺双开的精美大门、现已歪斜、门上的院徽被喷漆涂抹（不是自然脱落而是人为破坏）
可用于场景：被亵渎的院徽 / 大门歪斜 / 再无新生

### 魔法学院核心区
is-a 废弃学院核心（上位：魔法学院）
学院中央的魔法枢纽（曾用于给全院供能）——核心水晶碎裂、底座上有烧灼的黑色痕迹、周围散落着碎裂的魔杖
可用于场景：力量枢纽毁坏 / 水晶碎 / 断裂的魔杖堆

## v2 状态侵蚀层（以魔法学院废墟为上位）

注意：秘术学院的侵蚀——知识场所被遗忘/破坏后，知识与魔法残留物与环境发生反应。

### 魔法学院废墟被花蔓侵蚀
is-a 墨水花蔓（上位：魔法学院废墟）
从羊皮纸碎片中长出的花——花瓣上有墨水渗透的蓝色纹路、像文字从纸转移到花上、花蔓沿着书架的轮廓生长
可用于场景：花继承文字 / 知识长成花 / 花与纸同源

### 魔法学院废墟被荆棘缠绕
is-a 书脊荆棘（上位：魔法学院废墟）
荆棘从书籍的脊背中长出——书页被根须撑开、荆棘的刺上挂着小块的羊皮纸碎片、像书在流血
可用于场景：荆棘从书中出 / 知识长刺 / 暴力阅读

### 魔法学院废墟被树根穿刺
is-a 根穿图书馆（上位：魔法学院废墟）
树根从天花板裂缝中垂下、直接穿透了书架——根须缠绕着书籍、像在翻页、有些书被根卷着悬在半空
可用于场景：树根代替手翻书 / 被自然翻阅的图书馆

### 魔法学院废墟被苔藓覆盖
is-a 霉变书架（上位：魔法学院废墟）
灰绿色的霉丝在书脊上蔓延——书脊上的标题被霉斑覆盖、翻开书页内侧也长了霉——知识被生物降解
可用于场景：书发霉 / 被微生物消化 / 知识腐烂

### 魔法学院废墟被菌丝寄生
is-a 发光菌书（上位：魔法学院废墟）
荧光菌丝沿着书脊与书架绘制出"新的文字"——菌丝组成的图案看起来像某种没人见过的字母系统
可用于场景：菌丝书写 / 微生物的图书馆 / 另一种文字

### 魔法学院废墟被黑雾吞没
is-a 墨水雾（上位：魔法学院废墟）
黑色的细雾从干涸的墨水瓶中升腾而出——不是真正的雾而是被蒸发的墨水、带有纸张燃烧的气味
可用于场景：墨水雾 / 知识的烟 / 黑雾来自瓶子

### 魔法学院废墟被冰晶封存
is-a 水晶封卷（上位：魔法学院废墟）
水晶从蜡烛融化的蜡中结晶生长——将摊开的书籍与羊皮纸封存在晶体中、像琥珀保存的古代遗物
可用于场景：水晶封书 / 知识琥珀 / 冻住的一页

### 魔法学院废墟被血迹污染
is-a 墨血混合（上位：魔法学院废墟）
桌面上墨水与血迹混在一起——黑与红交融难以分辨哪些是血哪些是墨——在此处学习的人付出了什么代价
可用于场景：血与墨 / 代价的痕迹 / 学习有伤亡

### 魔法学院废墟被月光空壳化
is-a 月光翻页（上位：魔法学院废墟）
月光从破损的天窗射入在桌面形成光斑——光斑恰好照亮了摊开的书页、像是月想要阅读最后一页
可用于场景：月光读书 / 最后的读者是月 / 光在书上

### 魔法学院废墟被星尘异化
is-a 星尘笔记（上位：魔法学院废墟）
银蓝色星尘落在了残存的羊皮纸上——文字被星尘的微光覆盖、原本的内容不可读、但星尘"写"出了新的闪光页码
可用于场景：星尘改写 / 新的文字 / 被天外信息覆盖

## v3 内部功能空间层（以魔法学院废墟被花蔓侵蚀为上位）

### 魔法学院废墟被花蔓侵蚀中央空间
is-a 花蔓教室中央（上位：魔法学院废墟被花蔓侵蚀）
教室中央的讲台——蓝色墨纹的白花从木质讲台裂缝中涌出、花在地面围成半圆形像一群听课的学生
可用于场景：花围讲台 / 自然的学生 / 无人的课堂

### 魔法学院废墟被花蔓侵蚀祭坛空间
is-a 花蔓祭台（上位：魔法学院废墟被花蔓侵蚀）
学院小教堂的祭台被花覆盖——花蔓沿着祭台边缘编织了一个花圈、花圈的中央放着一本被翻开的残破书籍
可用于场景：花与书共祭 / 知识为信仰 / 祭坛上的读物

### 魔法学院废墟被花蔓侵蚀回廊空间
is-a 花蔓廊道（上位：魔法学院废墟被花蔓侵蚀）
走廊两侧的壁龛中长出了花——壁龛原本放的是石膏胸像、如今花从胸像断裂的脖颈中长出、像给智者戴上了花冠
可用于场景：花冠智者 / 胸像生花 / 知识者的自然冠冕

### 魔法学院废墟被花蔓侵蚀洗礼池
is-a 花蔓墨池（上位：魔法学院废墟被花蔓侵蚀）
本应是洗手池的角落——积存的雨水被染成了蓝黑色（墨水与水的混合）、水面漂着写有残字的纸片和蓝纹花瓣
可用于场景：墨池花漂 / 水与墨与花的混合 / 洗笔池变花池

### 魔法学院废墟被花蔓侵蚀祈祷室
is-a 花蔓自习室（上位：魔法学院废墟被花蔓侵蚀）
小隔间曾经是学生自习室——桌面上积了灰但花蔓沿着桌角的刻字（"我要毕业"）长出了花——那个学生的愿望以花的形式实现了
可用于场景：花从刻字长 / 愿望成花 / 自习室的最后一课

### 魔法学院废墟被花蔓侵蚀花窗大厅
is-a 花蔓彩窗厅（上位：魔法学院废墟被花蔓侵蚀）
花窗的彩色玻璃碎裂大半——但花蔓填补了空白、透过花的阳光是浅紫色与粉色的——比原来的彩色玻璃更柔和
可用于场景：自然彩窗 / 花代替玻璃 / 更温柔的光

### 魔法学院废墟被花蔓侵蚀地下墓穴
is-a 花蔓墓室（上位：魔法学院废墟被花蔓侵蚀）
学院地下埋葬着历届导师的墓穴——每个墓前石板上都长出了一丛花——花的颜色因墓主人的学派而异
可用于场景：导师之墓花各异 / 学派色的花 / 墓地花园

### 魔法学院废墟被花蔓侵蚀钟楼
is-a 花蔓钟塔（上位：魔法学院废墟被花蔓侵蚀）
钟塔内部的齿轮组被花蔓缠住停转了、但花蔓的生长方向恰好像新的"指针"——指向下午三点的方向
可用于场景：花代替齿轮 / 自然的报时 / 生物钟

### 魔法学院废墟被花蔓侵蚀圣像墙
is-a 花蔓院徽墙（上位：魔法学院废墟被花蔓侵蚀）
墙上的学院浮雕徽章——一只鹰与一本打开的书——花蔓沿着鹰的翅膀与书的轮廓生长、突出了这两个元素
可用于场景：花描徽章 / 自然赞扬 / 浮雕上长花

### 魔法学院废墟被花蔓侵蚀忏悔室
is-a 花蔓角亭（上位：魔法学院废墟被花蔓侵蚀）
走廊拐角的壁凹——本来是放邮箱的——现在被花蔓填满成了一个小花亭、花蔓自然围出了一个可容一人蹲坐的空间
可用于场景：角落花亭 / 躲进去 / 花中之人的影像

## v4 最终复合场景层（中央空间10种变体）

### 魔法学院废墟被花蔓侵蚀中央空间复合场景
is-a 花蔓教室标准版（上位：中央空间）
讲台上花蔓编织出一个花冠落在原本放课本的位置、教室桌椅已被搬空、地面只有中央的花环和二十把空椅子留下的灰尘印记
可用于场景：空课室花冠 / 花接替教师 / 标准大全景

### 魔法学院废墟被花蔓侵蚀中央空间镜面版
is-a 花蔓教室倒影版（上位：中央空间）
地面积水——倒影中的花蔓比实物更多——像水下还有一个更繁茂的教室、水中映出破碎的天花板和曾经的彩窗
可用于场景：水下教室 / 镜中另一个学院 / 倒影更繁荣

### 魔法学院废墟被花蔓侵蚀中央空间沉水版
is-a 花蔓教室水淹版（上位：中央空间）
水从地砖缝隙中涌出淹到脚踝——书架底层的书籍全部泡在水里、墨水从书中散开在水中形成蓝黑色的烟雾
可用于场景：泡水的知识 / 墨烟在水 / 书在水中开

### 魔法学院废墟被花蔓侵蚀中央空间月光版
is-a 花蔓教室月夜版（上位：中央空间）
月光从破损的天花板射入、在花蔓之间形成了交错的光影网——像教室中有一张由光织成的蜘蛛网
可用于场景：月光织网 / 光网覆盖花丛 / 夜的教室

### 魔法学院废墟被花蔓侵蚀中央空间黑水版
is-a 花蔓教室黑液版（上位：中央空间）
不知从何处渗出的黑色粘稠液体覆盖了花蔓——花被黑色包裹、花萎靡不振、液体有刺鼻的化学墨水味
可用于场景：黑液污染 / 花被墨水窒息 / 化学入侵

### 魔法学院废墟被花蔓侵蚀中央空间环形祭坛版
is-a 花蔓教室仪式版（上位：中央空间）
有人在教室地面上用粉笔画了一个完整的法阵——将花丛圈在法阵中央、法阵的线条是新鲜的——有人来过不久
可用于场景：新画法阵 / 还有人在用教室 / 秘密仪式

### 魔法学院废墟被花蔓侵蚀中央空间裂缝圣泉版
