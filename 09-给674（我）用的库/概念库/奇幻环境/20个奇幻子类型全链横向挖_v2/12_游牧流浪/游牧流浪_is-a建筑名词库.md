# 游牧流浪 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：不生根、在路上、临时但温暖、风才是主人。

---

## v0 空间母体层

### 风帐营地
is-a 游牧临时居所
由十几个深色羊毛帐篷组成的圆形营地——帐篷之间用粗绳连接固定在地面、中央的空地有篝火余烬、拴马桩上系着几匹马
可用于场景：游牧日常 / 草原夜晚 / 迁徙休息

### 星夜草原
is-a 草原夜空
没有人工光源的纯自然草原夜空——银河像烟带横跨天空、草在夜风中形成波浪状的暗影、地面与天空间没有任何其他物体
可用于场景：星空下 / 独自旅行 / 辽阔感

### 迁徙古道
is-a 游牧迁徙路径
被无数代游牧的畜群踩出的宽阔土路——路面被踩实下凹、两侧的草更高、沿途有拴马用的石桩和倒下的界碑
可用于场景：迁徙途中 / 长途旅行 / 古道的痕迹

### 驼队集市
is-a 游牧交易市场
流动的集市——由几十头骆驼排成行、每头骆驼旁边堆着待售的货物（毛毯/盐/铁器/香料）、布棚相连遮阳
可用于场景：沙漠/草原交易 / 异域风情 / 商品交换

### 移动村落
is-a 车队组合聚落
由数十辆兽力篷车围成环形组成的临时村落——车的尾部相对形成一个封闭的圆形内部空间、外部是各种绳子和晾晒的衣物
可用于场景：车队宿营 / 村落移动前 / 生活感

### 荒原水井
is-a 水源地
荒原上唯一的浅水井——石砌的井口被绳索磨出深深的凹槽、井边围绕着密集的脚印与蹄印、不远处有一棵孤零零的老树
可用于场景：取水场景 / 人际交汇 / 荒原的焦点

### 边境驿站
is-a 游牧补给站
土坯墙围合的小驿站——有马厩、一口井、一间供过客歇脚的土房、门板上画着褪色的地图
可用于场景：歇脚 / 获取信息 / 边境交易

### 篝火圆场
is-a 牧民营火场地
草地上被踩出的圆形空地——中央有篝火石圈、周围放着一圈可供坐卧的干草捆或毛毯、火光照亮人脸的傍晚
可用于场景：夜间集会 / 讲故事 / 围火而谈

### 风旗山坡
is-a 风神祭坡
山丘顶上插着数十根木杆——每根木杆上系着褪色的布条或旗幡——风来时旗猎猎作响——游牧人祈求风向的圣地
可用于场景：风祭仪式 / 瞭望远方 / 风中的颜色

### 临时圣地
is-a 移动神坛
游牧人用石头垒成的圆形祭台——祭台中央插着一根系着马鬃的木棍——不是固定的宗教场所而是每次迁徙后重建
可用于场景：祈祷出发 / 感谢旅途 / 精神依托

## v1 典型空间层（以风帐营地为上位）

### 风帐营地废墟
is-a 废弃游牧营地（上位：风帐营地）
帐篷已被撤走——只剩地上插帐篷桩的孔洞、篝火石圈里的黑灰、几根断绳被风缠绕在残桩上
可用于场景：人去营空 / 迁徙后留下的痕迹 / 风打扫了一切

### 风帐营地圣所
is-a 废弃游牧圣坛（上位：风帐营地）
一个用白石头在地面摆出的圆形符号——牧人的祈祷标记——已部分被牲畜踩乱了但仍可辨识、旁边的地面插着褪色的旗帜
可用于场景：被踩乱的圣符 / 信仰褪色 / 游牧的祭坛

### 风帐营地大厅
is-a 废弃大帐遗址（上位：风帐营地）
最大的那顶帐篷撤走后——留下的圆形帐篷印痕比其他帐篷更深——草被压扁后颜色比其他区域浅
可用于场景：帐篷印痕 / 草的记忆 / 大帐的位置

### 风帐营地回廊
is-a 废弃连接通道（上位：风帐营地）
帐篷与帐篷之间被踩出的通道——草已被踩秃形成一条带状的土路、通道两侧的草更高——像绿色走廊的底面
可用于场景：草中路 / 被脚踩出的走廊 / 通行的痕迹

### 风帐营地祭坛
is-a 废弃祭火台（上位：风帐营地）
篝火石圈中的黑灰已被风吹散大半——但石圈的石头被火烧黑、几块石头裂开——火的力量留下了
可用于场景：冷灰石圈 / 火的遗迹 / 曾经的温暖

### 风帐营地庭院
is-a 废弃营地空场（上位：风帐营地）
营地的中央空场——草已被踩光露出沙土——空场上散落着一些废弃的绳头、牛骨和碎陶片
可用于场景：踩实的空地 / 生活残片 / 营地的心脏

### 风帐营地钟楼
is-a 废弃旗杆（上位：风帐营地）
营地最高处插着一根斜的木杆——杆顶的旗帜已经风化到只剩几根纤维——但杆子还在、还插在那里
可用于场景：旗杆仍在旗已无 / 风化的标志 / 游牧的灯塔

### 风帐营地地下层
is-a 废弃地窖（上位：风帐营地）
——游牧人不挖地下室。这里是一个半地穴式的冬季食物储存坑——坑内还有干涸的奶渍痕迹、坑壁被熏黑过
可用于场景：游牧的储存坑 / 半地下的记忆 / 冬季的痕迹

### 风帐营地入口
is-a 营地入口标桩（上位：风帐营地）
营地的入口处两根绑着牦牛尾毛的木桩——毛已经掉光了只剩光秃的桩——但入口这个位置被记住了
可用于场景：光桩 / 入口的记忆 / 游牧的门的遗迹

### 风帐营地核心区
is-a 营地中央（上位：风帐营地）
营地的绝对中心——一根木桩钉在地上（曾是拴马桩/拴帐篷的锚点）——木桩周围有一圈被人和动物反复踩出的同心圆
可用于场景：中心木桩 / 同心足迹 / 奔跑与绕行

## v2 状态侵蚀层（以风帐营地废墟为上位）

注意：游牧流浪的侵蚀——草原/荒原本身对临时居所的分解，风吹雨打重新画平地。

### 风帐营地废墟被花蔓侵蚀
is-a 野花覆营（上位：风帐营地废墟）
营地废弃后的春天——野花从篝火灰烬中、从帐篷桩的孔洞中、从每一个被扰动过的土坑中长出——花在填补人的空洞
可用于场景：花填土坑 / 人的痕迹被花取代 / 草原自愈

### 风帐营地废墟被荆棘缠绕
is-a 旱地荆棘（上位：风帐营地废墟）
灰褐色干燥的荆棘从——不是碧绿的而是干枯的、在营地周围的土地上成片蔓延、像荒草中的铁丝网
可用于场景：枯棘封锁 / 硬而脆 / 干旱荒漠化

### 风帐营地废墟被树根穿刺
is-a 树根寻水（上位：风帐营地废墟）
——草原上没树。唯一的那棵孤树的根延展过来钻入了营地下面——根露在地表的几处在寻找水坑的位置
可用于场景：孤树根寻水 / 根的探索 / 草原中唯一的树

### 风帐营地废墟被苔藓覆盖
is-a 地衣结皮（上位：风帐营地废墟）
干旱气候下——不是苔藓而是地衣在裸露的沙土表面结成灰绿色的薄壳——人走后土地结了一层"痂"
可用于场景：土地结壳 / 地衣如痂 / 干旱的覆盖

### 风帐营地废墟被菌丝寄生
is-a 草原蘑菇圈（上位：风帐营地废墟）
营地废弃后——地面上长出了蘑菇圈——蘑菇在篝火灰烬的营养上形成了完美的环形、游牧人说这是精灵的脚印
可用于场景：蘑菇圈 / 灰烬的营养 / 草原上的环形

### 风帐营地废墟被黑雾吞没
is-a 沙尘暴（上位：风帐营地废墟）
强烈的沙尘暴将整个营地废墟笼罩在灰褐色的尘雾中——能见度不足五米、风中的沙粒打在皮肤上刺疼
可用于场景：沙暴笼罩 / 天地浑浊 / 极限天气

### 风帐营地废墟被冰晶封存
is-a 霜冻（上位：风帐营地废墟）
冬夜——地面结了一层白色的霜——帐篷桩上、旗杆上、每一根草上都挂着白霜——草原一夜白头
可用于场景：草原结霜 / 一夜白头的土地 / 冷之极

### 风帐营地废墟被血迹污染
is-a 捕猎血迹（上位：风帐营地废墟）
营地附近的草地上有大片暗褐色的污渍——不是人的血——是游牧人屠宰牲畜留下的——生活的一部分
可用于场景：宰杀痕迹 / 生存的必然 / 血的渗透

### 风帐营地废墟被月光空壳化
is-a 月下荒原（上位：风帐营地废墟）
满月下的草原——草在月光下呈银灰色——地面的每一个起伏都被月光的斜射放大——营地废墟的痕迹在月光下格外清晰
可用于场景：月照荒原 / 银色的草海 / 过去的影子

### 风帐营地废墟被星尘异化
is-a 星沙落地（上位：风帐营地废墟）
——但在游牧民族的传说中，星尘是祖先的火种。星尘落在地面上后发出微弱的暖黄色光——像是草原上也有一片微缩星空
可用于场景：星尘暖光 / 大地之星 / 祖先的火在草原上

## v3 内部功能空间层（以风帐营地废墟被花蔓侵蚀为上位）

### 风帐营地废墟被花蔓侵蚀中央空间
is-a 野花围绕的篝火痕（上位：风帐营地废墟被花蔓侵蚀）
中央的篝火石圈——花从石头的缝隙中长出围成一圈——像是火灭了之后长出的新"火"（花像火焰一样围成圈）
可用于场景：花围石圈 / 花代替火 / 但温暖不再

### 风帐营地废墟被花蔓侵蚀祭坛空间
is-a 野花圣石（上位：风帐营地废墟被花蔓侵蚀）
祭坛用的白石堆——花沿着石堆的缝隙向上爬——覆盖了石头的一半、花与石各占一半
可用于场景：花半覆石 / 信仰一半自然一半 / 祭石的春天

### 风帐营地废墟被花蔓侵蚀回廊空间
is-a 野花通道（上位：风帐营地废墟被花蔓侵蚀）
帐篷与帐篷之间的通道——现在两侧长出了比人高的野草与花——形成了一条狭窄的植物走廊
可用于场景：草高过人 / 穿过野花的通道 / 自然的走廊

### 风帐营地废墟被花蔓侵蚀洗礼池
is-a 野花水坑（上位：风帐营地废墟被花蔓侵蚀）
营地唯一的水坑——雨后坑中积水——水面上漂着落入的花瓣——水是浑浊但仍有花的倒影
可用于场景：积水中的花 / 浑浊与美丽的并存

### 风帐营地废墟被花蔓侵蚀祈祷室
is-a 野花祈祷处（上位：风帐营地废墟被花蔓侵蚀）
营地的祈祷处——地面那个白石围成的圆形——野花在圆内长得特别茂盛——像是在保佑那个位置
可用于场景：白石圈中花最盛 / 祝福的位置 / 草都更绿

### 风帐营地废墟被花蔓侵蚀花窗大厅
is-a 野花天窗（上位：风帐营地废墟被花蔓侵蚀）
——不可能有花窗。这里的"花窗"是帐篷的布顶布腐朽后只剩下布料纤维如网一样盘绕在高处——花从这些网上垂下
可用于场景：帐篷布料化网 / 花从网上垂 / 布做的花架

### 风帐营地废墟被花蔓侵蚀地下墓穴
is-a 野花地窖（上位：风帐营地废墟被花蔓侵蚀）
储存坑——坑壁上长满了蕨类和白花、坑底积着一些雨水、花从坑口向坑底垂成一条花瀑
可用于场景：坑中花瀑 / 从地面垂入地下 / 储存坑变花坑

### 风帐营地废墟被花蔓侵蚀钟楼
is-a 野花旗杆（上位：风帐营地废墟被花蔓侵蚀）
旗杆上——花蔓沿着旗杆旋转爬上杆顶——在杆顶开出了一簇花——旗走了、花来了
可用于场景：花旗杆 / 旗帜换成了花簇 / 杆顶的新标志

### 风帐营地废墟被花蔓侵蚀圣像墙
is-a 野花图腾（上位：风帐营地废墟被花蔓侵蚀）
营地入口的木桩——牦牛尾毛掉光后花蔓爬上木桩——桩上开出了花像木桩长了头发
可用于场景：开花木桩 / 入口的新装饰 / 植物图腾

### 风帐营地废墟被花蔓侵蚀忏悔室
is-a 野花歇脚石（上位：风帐营地废墟被花蔓侵蚀）
营地边缘一块曾被用作凳子的扁平石头——石头上长满了青苔与小花——坐着可以看见草原
可用于场景：长花的坐石 / 歇脚也坐在花上 / 自然的座位

## v4 最终复合场景层（中央空间10种变体）

### 风帐营地废墟被花蔓侵蚀中央空间复合场景
is-a 野花营心标准版（上位：中央空间）
篝火石圈已被花完全覆盖——花圈与石圈重叠——从上方看是白色的花圈内包围着黑色的灰痕
可用于场景：花圈与灰 / 过去的火现在的花 / 标准大全景

### 风帐营地废墟被花蔓侵蚀中央空间镜面版
is-a 野花营心倒影版（上位：中央空间）
水坑中的倒影——天空在积水中、花圈的倒影与实物形成一个闭合的花环
可用于场景：水中的花环 / 天地之间的花 / 完整的圆环倒影

### 风帐营地废墟被花蔓侵蚀中央空间沉水版
is-a 野花营心水漫版（上位：中央空间）
雨水淹没整个中央空地——水浅到脚踝——花从水面上露出、水面下花的根系可见、水中有草茎形成的绿色水下森林
可用于场景：草原湿地 / 水中的花茎 / 脚下是绿色

### 风帐营地废墟被花蔓侵蚀中央空间月光版
is-a 野花营心月夜版（上位：中央空间）
月光下花圈的白花发出幽幽的白光——篝火灰痕的黑色在月光下更黑——黑白对比如同草原的阴阳
可用于场景：月下花圈 / 黑灰与白花 / 草原的阴阳

### 风帐营地废墟被花蔓侵蚀中央空间黑水版
is-a 野花营心污染版（上位：中央空间）
暴雨后——水坑中的水因腐殖质变成了深褐色——花漂在水中颜色显得暗淡——美丽被稀释
可用于场景：褐水泡花 / 祭奠变浑浊 / 自然的另一面

### 风帐营地废墟被花蔓侵蚀中央空间环形祭坛版
is-a 野花营心仪式版（上位：中央空间）
有人在花圈外又用白色石子摆了一圈——两圈同心圆——外圈是新加的人类石头、内圈是自然的植物
可用于场景：人与自然的双环 / 新的纪念 / 双重印记

### 风帐营地废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 野花营心清泉版（上位：中央空间）
篝火石圈正中央的地面裂开涌出地下水——清泉从黑灰中涌出、冲刷出一个干净的圆形水面
可用于场景：灰中清泉 / 火底涌水 / 冲突的新生

### 风帐营地废墟被花蔓侵蚀中央空间白花漂浮版
