# 魂系 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：破败但宏伟、循环与枯萎、孤寂的英雄、一切都会熄灭。

---

## v0 空间母体层

### 灰烬王座
is-a 终结之王的位子
高耸的王座由灰烬色的石头构成——座椅上覆盖着一层灰色的细灰——椅背刻着已经不可读的王冠图案——周围没有其他家具
可用于场景：最终王座 / 王已化成灰 / 尽头

### 破败王城
is-a 亡国的首都
城墙大面积倒塌——塔楼倾斜但未倒——街道上空无一人——建筑的门窗全部大开或缺失——风吹过时发出空洞的呼啸
可用于场景：空城一瞥 / 王国已死 / 无人之城

### 火祭场
is-a 传火仪式地
圆形露天祭场——中央有一个巨大的石质火盆——火盆中是黑色的灰烬与碎裂的龙骨——四周有五个石质坐席
可用于场景：传火现场 / 余烬已冷 / 最后的朝圣者

### 巨型城墙
is-a 不可逾越的墙
高耸的石墙延伸至视野尽头——墙面覆盖着青灰色的苔壳与风化的痕迹——墙顶似乎有人在走动（但仔细看只是风中的旗）
可用于场景：墙之大 / 越墙 / 墙作为背景

### 废弃要塞
is-a 被遗弃的堡垒
在多条道路交汇处的庞大石堡——门洞大开、内部已经空无一物——但堡垒的结构保存完好——像是驻军刚刚撤离
可用于场景：空堡穿过 / 被遗弃的防守点 / 没有人但仍有防御

### 深井升降机
is-a 垂直交通井
一个巨大的垂直竖井——中央有一台用铁链悬挂的木制升降平台——平台踩上去咯吱作响——井壁的涂层反射着微弱的光
可用于场景：下降 / 前往下层 / 升降中的危险

### 王墓长廊
is-a 王者陵墓群
在山体内开凿的长廊——两侧是逐个排列的石棺——每个石棺前有一个熄灭的石灯——长廊尽头是一扇紧闭的巨型石门
可用于场景：死者走廊 / 石棺两侧排列 / 尽头的门

### 毒沼边境
is-a 有毒湿地
广阔的灰色泥沼——水面覆盖着灰白色的浮膜——水泡间歇性升起破裂释放出淡绿色的毒气——沼泽中有露出水面的树桩与石碑
可用于场景：穿越毒沼 / 危险地形 / 环境伤害

### 古龙桥
is-a 飞龙栖息桥
连接两座山峰的巨大石拱桥——桥面宽可容六人并行、两侧没有栏杆、桥身多处开裂——桥下是深渊、桥上空偶尔有龙的影子掠过
可用于场景：过桥 / 龙在头上 / 险峻跨行

### 断剑广场
is-a 战败者的纪念碑
广袤的灰石广场地面上插满了断裂的剑——剑柄或剑身从地面露出——有些已被锈蚀成碎片——像是战斗结束后没有人来收拾
可用于场景：插剑的地面 / 战场遗迹 / 收剑

## v1 典型空间层（以灰烬王座为上位）

### 灰烬王座废墟
is-a 废弃灰烬王座（上位：灰烬王座）
王座所在的殿堂已经坍塌了大半——穹顶碎裂——灰烬从裂口飘入——落在王座上堆积成更厚的灰色——王座像正在被自己同化
可用于场景：灰烬堆积 / 王座在消失 / 时间真正的王

### 灰烬王座圣所
is-a 废弃圣殿（上位：灰烬王座）
王座旁的祈祷室——墙上的壁画已经模糊到只剩一片灰色——只有圣者的翅膀轮廓还能隐约辨认——像画也变成了灰烬
可用于场景：灰画 / 轮廓在消失 / 记忆成灰

### 灰烬王座大厅
is-a 废弃大厅（上位：灰烬王座）
王座前的等候大厅——长椅排列整齐但上面落满了灰——地上有数个圆形的灰圈（曾有什么立在那里现在只剩底座痕迹）
可用于场景：整齐的灰椅 / 圆形的空痕 / 等待者已不在

### 灰烬王座回廊
is-a 废弃走廊（上位：灰烬王座）
走廊两侧的半身像——头像已全部滚落在地——但没有碎——只是整齐地掉在底座旁边——像是被轻轻地放下去的
可用于场景：头像落地 / 整齐的掉落 / 温和的毁灭

### 灰烬王座祭坛
is-a 废弃献祭台（上位：灰烬王座）
祭坛——台面上有一个环形的凹槽——槽底还有黑色的灼烧痕迹——祭坛周围的地面没有灰（像是被清扫过的）——有人还在使用？
可用于场景：环槽已黑 / 没人用的祭坛被清理过 / 谁来过

### 灰烬王座庭院
is-a 废弃庭院（上位：灰烬王座）
被高墙围合的露天空间——地面覆盖着均匀的灰色灰烬——灰面上没有脚印——像从未有人踏足——中央有一棵枯树（已石化）
可用于场景：灰毯地面 / 无脚印 / 岁月本身

### 灰烬王座钟楼
is-a 废弃钟楼（上位：灰烬王座）
钟楼依然高耸——钟的摇锤已经锈断——钟口朝上接满了灰烬——像在接一场下了几百年的灰雨
可用于场景：钟口接灰 / 灰代替了声音 / 沉默的钟

### 灰烬王座地下层
is-a 废弃地窖（上位：灰烬王座）
王座基座下方的隐藏空间——低矮的拱顶——墙上有炭笔写的名字——每个名字后面跟着一个日期——最后一笔潦草
可用于场景：名字与日期 / 谁留下的 / 最后一笔

### 灰烬王座入口
is-a 废弃大门（上位：灰烬王座）
巨大的铁门——铁门已经锈蚀到布满孔洞——透过门上的孔洞可以看到王座的方向——像一个让视线穿透的筛子
可用于场景：锈透了的门 / 透过门看王座 / 门已不是障

### 灰烬王座核心区
is-a 灰烬之源（上位：灰烬王座）
王座的正下方——建筑的心脏——一个巨大的空洞——灰从这里向上飘升——被气流带出覆盖整个王城——这里在持续地产灰
可用于场景：灰之源 / 飘灰的起点 / 王座之下

## v2 状态侵蚀层（以灰烬王座废墟为上位）

注意：魂系的侵蚀——不是生物性的入侵而是"灰化"与"风化"——物体逐渐失去形态回归尘埃。

### 灰烬王座废墟被花蔓侵蚀
is-a 灰花（上位：灰烬王座废墟）
从灰烬中开出的花——花瓣是灰白色的——花蕊也是灰色的——花像用灰捏出来的——没有生机的颜色
可用于场景：灰之花 / 死灰中的花 / 没有颜色

### 灰烬王座废墟被荆棘缠绕
is-a 石化棘（上位：灰烬王座废墟）
荆棘变成化石了——是灰色的、硬的、风一吹就碎成粉末——不是缠绕而是灰化的荆棘保持了缠绕的姿势
可用于场景：灰化的棘 / 化石姿势 / 一触即碎

### 灰烬王座废墟被树根穿刺
is-a 化石根（上位：灰烬王座废墟）
树根穿墙而入——但根已石化——灰色的树根保持入侵的姿态但不再生长——像石雕
可用于场景：石根穿墙 / 入侵被时间定格 / 根变成了石

### 灰烬王座废墟被苔藓覆盖
is-a 灰苔（上位：灰烬王座废墟）
一种特殊的灰色苔藓——长在灰烬覆盖的表面——看起来像是灰本身长了绒毛——苔藓与灰不分
可用于场景：灰长了毛 / 苔与灰同色 / 边界的模糊

### 灰烬王座废墟被菌丝寄生
is-a 白丝菌（上位：灰烬王座废墟）
纯白色的菌丝在灰烬下蔓延——掀开灰层能看到白色的菌丝网——像灰下面是另一个世界
可用于场景：掀灰见白 / 灰下的另一个世界 / 菌丝织网

### 灰烬王座废墟被黑雾吞没
is-a 影灰（上位：灰烬王座废墟）
不是雾——是被风扬起的灰色灰烬形成的灰尘——在空中弥漫形成灰色的"雾"——吸入会呛
可用于场景：灰尘如雾 / 呼吸困难 / 灰色弥漫

### 灰烬王座废墟被冰晶封存
is-a 灰冰（上位：灰烬王座废墟）
冰晶包裹住了灰烬——冰是灰色的（灰烬被封在冰中）——冰与灰的混合物像灰色的树脂
可用于场景：灰冰 / 灰封在冰中 / 灰色的冰

### 灰烬王座废墟被血迹污染
is-a 暗痕（上位：灰烬王座废墟）
在灰色的地面上——有几处深色的痕迹——不是红色只是比灰更深的灰黑色——曾有什么液体渗入灰中
可用于场景：深色灰痕 / 曾经有液体 / 过去事件的证据

### 灰烬王座废墟被月光空壳化
is-a 月下灰影（上位：灰烬王座废墟）
月光下的灰色废墟与白天没有区别——因为灰本身就是灰色——月光与日光下一样灰——颜色已经褪无可褪
可用于场景：没有再可褪的颜色 / 灰到极致 / 月光也照不亮

### 灰烬王座废墟被星尘异化
is-a 星灰（上位：灰烬王座废墟）
银色的星尘混入了灰色的灰烬——灰烬中出现银色的闪光颗粒——灰不再只是灰——是带有星光的灰
可用于场景：星光灰烬 / 灰中有光 / 死灰中有星

## v3 内部功能空间层（以灰烬王座废墟被花蔓侵蚀为上位——"花蔓"=灰花）

### 灰烬王座废墟被花蔓侵蚀中央空间
is-a 灰花中央（上位：灰烬王座废墟被花蔓侵蚀）
王座大厅——灰色的花沿着地面的裂缝开出无数朵——花是灰色的、地面的灰是灰色的——灰花与灰地融为一体
可用于场景：灰花灰地一色 / 花与灰不分 / 灰色花开

### 灰烬王座废墟被花蔓侵蚀祭坛空间
is-a 灰花祭台（上位：灰烬王座废墟被花蔓侵蚀）
祭坛——灰色的花从环形的灼烧槽中长出——花沿着槽的弧形排列——像用花重新画出了环
可用于场景：灰花画环 / 花代替了灰痕 / 祭坛的花边

### 灰烬王座废墟被花蔓侵蚀回廊空间
is-a 灰花走廊（上位：灰烬王座废墟被花蔓侵蚀）
走廊的两侧——灰花从底座下的灰中长出——花的高度正好及腰——像是有人在走廊两侧摆满了灰色花束
可用于场景：腰高的灰花列队 / 走廊两侧的花兵 / 灰花的仪仗

### 灰烬王座废墟被花蔓侵蚀洗礼池
is-a 灰花水（上位：灰烬王座废墟被花蔓侵蚀）
水盆中的积水表面漂浮着一层灰色的薄膜——盆底的灰花在水中半沉半浮——水是透明的但看起来是灰的
可用于场景：灰水灰花 / 透明但看起来灰 / 水被花染

### 灰烬王座废墟被花蔓侵蚀祈祷室
is-a 灰花室（上位：灰烬王座废墟被花蔓侵蚀）
祈祷室——跪垫的位置被灰花取代——花组成了一个跪着的人的形态——像是花模拟了祈祷者
可用于场景：花的人形 / 灰花模拟祈祷 / 花代替了人

### 灰烬王座废墟被花蔓侵蚀花窗大厅
is-a 灰花光厅（上位：灰烬王座废墟被花蔓侵蚀）
花窗碎裂后——灰花从窗框间长出——透过花的光变成了灰色的——灰色的光照亮灰色的空间
可用于场景：灰色的光 / 灰花滤光 / 整个厅是灰色的

### 灰烬王座废墟被花蔓侵蚀地下墓穴
is-a 灰花墓（上位：灰烬王座废墟被花蔓侵蚀）
墓穴——石棺被灰花覆盖——花在棺盖上长出一个十字形的图案——像是用花给死者做了标记
可用于场景：灰花十字棺 / 花的标记 / 每一棺一个十字

### 灰烬王座废墟被花蔓侵蚀钟楼
is-a 灰花钟（上位：灰烬王座废墟被花蔓侵蚀）
钟楼——灰花从钟口溢出——花像水一样从钟口倾泻下来——灰花的瀑布
可用于场景：花从钟口倾泻 / 灰花瀑布 / 钟倒出了花

### 灰烬王座废墟被花蔓侵蚀圣像墙
is-a 灰花浮雕（上位：灰烬王座废墟被花蔓侵蚀）
墙上的壁画——灰花沿着残存的翅膀轮廓生长——翅膀的线条被花重新勾勒出来——花的灰色与画的灰色同色
可用于场景：花描羽翼 / 花的线条勾勒 / 花接续了画

### 灰烬王座废墟被花蔓侵蚀忏悔室
is-a 灰花角（上位：灰烬王座废墟被花蔓侵蚀）
角落里的灰花长得特别厚——像一个用灰色花做成的靠垫——坐上去会挤压出灰色的花粉
可用于场景：厚花如垫 / 一坐就散出灰粉 / 角落的花堆

## v4 最终复合场景层（中央空间10种变体）

### 灰烬王座废墟被花蔓侵蚀中央空间复合场景
is-a 灰花心标准版（上位：中央空间）
王座——灰花从王座基座一直蔓延到座椅——王座像是被花慢慢"吃"掉了——只剩一个花形的王座轮廓
可用于场景：花吃王座 / 王座变成花座 / 标准大全景

### 灰烬王座废墟被花蔓侵蚀中央空间镜面版
is-a 灰花心倒影版（上位：中央空间）
地面的灰色积水——倒影中的花比地面上的花更多——倒影中的花是深灰色的（比实物的灰更深）
可用于场景：倒影更深 / 水把花变深了 / 水下更丰富

### 灰烬王座废墟被花蔓侵蚀中央空间沉水版
is-a 灰花心水漫版（上位：中央空间）
灰色的积水漫过了地面——灰花泡在水中——花在水中散开成灰色的丝状——花的形态在水中解体
可用于场景：花在水中散 / 灰色丝状 / 花溶解

### 灰烬王座废墟被花蔓侵蚀中央空间月光版
is-a 灰花心月夜版（上位：中央空间）
月光下的灰色花变成了银灰色——在月光中花的轮廓发光——银灰色的光
可用于场景：银灰发光 / 花在月下有了亮度 / 月让花微亮

### 灰烬王座废墟被花蔓侵蚀中央空间黑水版
is-a 灰花心黑液版（上位：中央空间）
从王座下方渗出的黑色液体——花被黑色液体覆盖后变成了黑色——黑花与黑液混成一团
可用于场景：黑液黑花 / 花被液吞噬 / 黑色

### 灰烬王座废墟被花蔓侵蚀中央空间环形祭坛版
is-a 灰花心仪式版（上位：中央空间）
有人在王座前用灰色的石子摆了一个环——环内用灰烬画了一个符号——还有人在此祈祷
可用于场景：行人还在祈祷 / 灰石环 / 王座前的仪式

### 灰烬王座废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 灰花心清泉版（上位：中央空间）
王座下的地面裂开涌出一股清澈的泉水——泉水冲开了灰烬露出下面原始的黑色岩石——灰色中出现了黑色
可用于场景：清泉洗灰 / 黑色岩石露出 / 新的颜色出现

### 灰烬王座废墟被花蔓侵蚀中央空间白花漂浮版
is-a 灰花心飞灰版（上位：中央空间）
灰花的花瓣化为灰色的尘埃——被气流卷起在空中盘旋——不是花瓣是灰——花在分解
可用于场景：花化灰飞天 / 花的消失 / 灰在空中

### 灰烬王座废墟被花蔓侵蚀中央空间枯井版
