# 龙与魔法 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

---

## v0 空间母体层（题材落到空间）

### 龙巢山脉
is-a 自然山脉要塞
绵延的山脊凿满大小不等的龙穴，碎石与骨殖覆盖山坡，终年云雾缭绕，地热蒸汽在岩缝间升腾
可用于场景：巨龙登场 / 远征远景 / 发现入口

### 王国城堡
is-a 人类王权建筑
白色巨石砌成的多层堡垒、高耸的方塔与雉堞城垛、主堡前有宽阔的列兵广场与旗帜阵列
可用于场景：人类阵营主城 / 国王召见 / 大军集结

### 魔法高塔
is-a 法师塔建筑
独立于险峻山岩或湖畔的细长尖塔、通体由深色石材与琉璃构成、塔顶有持续发光的水晶
可用于场景：法师登场 / 魔法实验 / 奥术远景

### 古龙峡谷
is-a 天然峡谷地貌
两侧数千米高的峭壁如刀劈般陡立、谷底幽暗深不见底、峭壁上有巨大的爪痕化石与龙骨化石裸露
可用于场景：穿越险道 / 龙族遗迹 / 俯视深渊

### 王城广场
is-a 城市公共广场
圆形或方形的宽阔石砌广场、中央有喷泉或英雄雕塑、四周围合着拱廊与市政建筑
可用于场景：民众聚集 / 宣告事件 / 战斗开幕

### 浮空岛
is-a 悬空自然地形
底部岩石被地脉能量切割后悬浮于半空、岛屿之间以藤蔓桥或魔法石板连接、下方是无尽深渊
可用于场景：空中旅行 / 圣域入口 / 坠落危机

### 龙骨荒原
is-a 荒芜平原地貌
绵延数百里的灰白色砾石平原、地表遍布巨大的半埋龙骨化石、寸草不生、风沙中回响着低沉的呜咽
可用于场景：穿越废土 / 龙族坟场 / 战斗舞台

### 王家祭坛
is-a 皇室祭祀建筑
建在山顶或悬崖边缘的露天石造祭坛、圆形平台中央有石质祭台、四角立有龙纹图腾柱
可用于场景：加冕仪式 / 献祭召唤 / 剧情转折点

### 火山龙穴
is-a 活火山内部空间
巨龙的真正巢穴——位于活火山内部空腔、岩浆湖的红光照亮整个洞窟、洞壁镶嵌着被高温融化的金币与宝石
可用于场景：最终决战 / 巨龙苏醒 / 宝藏洞窟

### 边境要塞
is-a 军事防御建筑
建在山隘间的黑石要塞、厚实的梯形城墙、密集的箭塔与垛口、城门是厚重的铁包木结构
可用于场景：防守战 / 边界检查 / 行军驻扎

## v1 典型空间层（母体 → 废墟类型，以龙巢山脉为上位）

### 龙巢山脉废墟
is-a 废弃山脉要塞（上位：龙巢山脉）
昔日龙族聚居的山脉通道已塌陷过半、石阶碎裂、石柱倾颓、藤蔓与苔藓覆盖了所有人工痕迹
可用于场景：初次进入遗迹 / 探索废墟 / 历史沧桑感

### 龙巢山脉圣所
is-a 废弃宗教空间（上位：龙巢山脉）
山脉内部凿出的穹顶大厅、中央有碎裂的龙形雕像、墙上的壁画已模糊不清、从穹顶裂缝漏下光束
可用于场景：发现秘密 / 神圣遭遇 / 光源中心构图

### 龙巢山脉大厅
is-a 废弃集会空间（上位：龙巢山脉）
最大的内部空腔、可容纳数百人、地面有碎裂的石板拼花、四周有壁龛与火炬架遗迹
可用于场景：战斗舞台 / 群体场景 / 回声效果

### 龙巢山脉回廊
is-a 废弃通道空间（上位：龙巢山脉）
两侧排列着石柱的狭长走廊、柱间透进零星光斑、路面因常年踩踏磨得光滑、尽头是黑暗
可用于场景：潜行探索 / 追逐戏 / 光影交错

### 龙巢山脉祭坛
is-a 废弃祭祀空间（上位：龙巢山脉）
高台上的祭坛区、石台上刻有凹陷的纹路（曾用于引导龙血或魔力）、周围散落着祭器碎片
可用于场景：仪式现场 / 关键道具放置处 / 触发事件

### 龙巢山脉庭院
is-a 废弃露天空间（上位：龙巢山脉）
被高墙围合的露天区域、地面曾有花园但现在只剩野草与碎石、中央的枯井是唯一结构
可用于场景：短暂喘息 / 发现隐藏入口 / 天光场景

### 龙巢山脉钟楼
is-a 废弃高耸构筑物（上位：龙巢山脉）
崎岖山壁上向外挑出的石造塔楼、内部有断裂的青铜钟（钟面刻有龙纹）、可俯瞰整个山脉
可用于场景：高地狙击 / 观察全貌 / 呼唤信号

### 龙巢山脉地下层
is-a 废弃地下空间（上位：龙巢山脉）
空气潮湿、滴水声不断、石壁上渗出水珠与矿物质的结晶、部分区域被地下水淹没
可用于场景：深入地下 / 遭遇未知生物 / 黑暗探索

### 龙巢山脉入口
is-a 废弃大门空间（上位：龙巢山脉）
巨大的石门半开半闭、门上的浮雕已被风化到几乎不可辨认、门槛处有深深的爪痕凹槽
可用于场景：第一次进入 / 团队集结 / 宏伟远景

### 龙巢山脉核心区
is-a 废弃中枢空间（上位：龙巢山脉）
整个龙巢最中心的巨大空腔、穹顶最高处达百米、底部有复杂的石质结构与能量传导遗迹
可用于场景：Boss房 / 核心机关 / 剧情高潮地点

## v2 状态侵蚀层（废墟 → 被自然/超自然力量改造，以龙巢山脉废墟为上位）

### 龙巢山脉废墟被花蔓侵蚀
is-a 植物侵蚀废墟（上位：龙巢山脉废墟）
粉白色与淡紫色的野花从每一道石缝中长出、花蔓像瀑布一样从断壁垂下、石面被根系撑裂——自然的温柔征服
可用于场景：唯美废墟 / 时光流逝 / 静谧氛围

### 龙巢山脉废墟被荆棘缠绕
is-a 植物侵占废墟（上位：龙巢山脉废墟）
黑色的粗壮荆棘如同活物般缠绕每一根石柱、尖刺密布、通道被荆棘完全封锁、空气中弥漫着腐烂的甜味
可用于场景：被封锁的通道 / 危险气息 / 无法通过

### 龙巢山脉废墟被树根穿刺
is-a 植物破坏废墟（上位：龙巢山脉废墟）
数十米高的古树的根系直接穿透了石质地板与墙壁、树木从废墟内部生长出来、石构被彻底肢解
可用于场景：自然反噬 / 新旧更替 / 巨大的空间感

### 龙巢山脉废墟被苔藓覆盖
is-a 微生物覆盖废墟（上位：龙巢山脉废墟）
所有表面被厚厚的深绿色苔藓包裹、踩上去柔软而滑腻、空气中弥漫着湿润的土腥味、光线被苔藓吸收得暗淡
可用于场景：地下湿地 / 滑倒危机 / 绿色调场景

### 龙巢山脉废墟被菌丝寄生
is-a 真菌覆盖废墟（上位：龙巢山脉废墟）
白色或荧光蓝色的菌丝网络覆盖了石壁与地面、蘑菇从裂缝中成簇长出、空气中飘浮着发光的孢子粉尘
可用于场景：超现实场景 / 发光氛围 / 异界感

### 龙巢山脉废墟被黑雾吞没
is-a 魔法污染废墟（上位：龙巢山脉废墟）
浓稠的黑色雾气从地底涌出、弥漫在废墟的底层空间中、可见度极低、雾中隐约有影子移动
可用于场景：迷雾探索 / 压迫感 / 隐藏怪物

### 龙巢山脉废墟被冰晶封存
is-a 冰封废墟（上位：龙巢山脉废墟）
所有表面覆盖着半透明的冰晶层、被冻结的藤蔓像玻璃雕塑一样挂在墙上、冷空气凝结成白雾
可用于场景：寒冰场景 / 时间停滞 / 透明质感

### 龙巢山脉废墟被血迹污染
is-a 血迹污染废墟（上位：龙巢山脉废墟）
石面上有大片暗红色的陈旧血迹飞溅与拖拽痕迹、空气中若有若无的铁锈味、部分血迹是最近留下的
可用于场景：屠杀现场 / 悬疑场景 / 暗示事件

### 龙巢山脉废墟被月光空壳化
is-a 月光异化废墟（上位：龙巢山脉废墟）
满月的光照让石质仿佛变得半透明、如同褪去了色彩只留下白色轮廓、整个废墟呈现一种梦境般的空洞感
可用于场景：月夜仪式 / 幻象场景 / 灵异氛围

### 龙巢山脉废墟被星尘异化
is-a 陨星改造废墟（上位：龙巢山脉废墟）
银色的星尘颗粒嵌入石面发出微光、原本的结构被陨击揉碎重组成不规则的几何形态、重力似乎被扭曲
可用于场景：天外来物 / 修改现实 / 超自然领域

## v3 内部功能空间层（状态空间 → 具体功能区，以龙巢山脉废墟被花蔓侵蚀为上位）

### 龙巢山脉废墟被花蔓侵蚀中央空间
is-a 花蔓侵蚀废墟中心大厅（上位：龙巢山脉废墟被花蔓侵蚀）
废墟最高大的穹顶空间、天花板的裂缝垂下的花蔓像是自然的帷幔、地面中央的花蔓最密——似乎有什么在滋养它们
可用于场景：中心舞台 / 关键事件发生地 / 俯瞰全场

### 龙巢山脉废墟被花蔓侵蚀祭坛空间
is-a 花蔓侵蚀废墟祭坛区（上位：龙巢山脉废墟被花蔓侵蚀）
高台上的祭坛已被花蔓完全包裹成绿色小山包、看不清原本的形状、只有朝上的裂口处漏出内部的金色微光
可用于场景：献祭场所 / 隐藏圣物 / 光从祭坛发出

### 龙巢山脉废墟被花蔓侵蚀回廊空间
is-a 花蔓侵蚀废墟走廊（上位：龙巢山脉废墟被花蔓侵蚀）
两侧石柱被花蔓缠绕成绿色柱廊、花从高处垂下形成天然帘幕、走在其中要拨开花的幕帘、明亮斑驳
可用于场景：浪漫步行 / 穿越大自然 / 半遮挡对话

### 龙巢山脉废墟被花蔓侵蚀洗礼池
is-a 花蔓侵蚀废墟水池（上位：龙巢山脉废墟被花蔓侵蚀）
浅圆形石池内积满了清澈的雨水、水面漂浮着白色与粉色的花瓣、池底的石纹清晰可见、宁静得像一面镜子
可用于场景：水面镜反射 / 角色情感瞬间 / 神圣净化

### 龙巢山脉废墟被花蔓侵蚀祈祷室
is-a 花蔓侵蚀废墟小室（上位：龙巢山脉废墟被花蔓侵蚀）
狭小的半圆形石室、正面的花蔓间露出一尊残缺的圣女石像、一束单纯的阳光从天花裂缝直射在石像的面部
可用于场景：内心独白 / 安静时刻 / 圣光降临

### 龙巢山脉废墟被花蔓侵蚀花窗大厅
is-a 花蔓侵蚀废墟彩窗空间（上位：龙巢山脉废墟被花蔓侵蚀）
侧墙的哥特式窗洞虽有彩窗但已碎裂大半、花蔓从破洞中涌入、阳光穿过彩色碎片在花蔓上投下斑驳的彩色光影
可用于场景：彩色斑驳 / 光与花蔓交织 / 情景氛围

### 龙巢山脉废墟被花蔓侵蚀地下墓穴
is-a 花蔓侵蚀废墟地下空间（上位：龙巢山脉废墟被花蔓侵蚀）
地下层的石棺被花蔓根系缠绕、从棺盖的裂缝中探出白色的根须、空气潮湿、光线昏暗、只有发光的苔藓照明
可用于场景：地下探索 / 尸变暗示 / 幽闭恐惧

### 龙巢山脉废墟被花蔓侵蚀钟楼
is-a 花蔓侵蚀废墟塔楼（上位：龙巢山脉废墟被花蔓侵蚀）
塔楼内部的木制楼梯已经腐朽坍塌、花蔓从窗口涌入在楼梯井中盘旋如绿色螺旋、顶层的铜钟被藤蔓固定悬在半空
可用于场景：攀爬塔楼 / 高空俯瞰 / 摇摇欲坠

### 龙巢山脉废墟被花蔓侵蚀圣像墙
is-a 花蔓侵蚀废墟浮雕墙（上位：龙巢山脉废墟被花蔓侵蚀）
一整面墙的浮雕被花蔓半覆盖、浮雕人物的手和脸从花间露出、花蔓沿着雕纹生长像是给浮雕添加了新的纹身
可用于场景：文化探秘 / 浮雕细节 / 自然与艺术的融合

### 龙巢山脉废墟被花蔓侵蚀忏悔室
is-a 花蔓侵蚀废墟隔间（上位：龙巢山脉废墟被花蔓侵蚀）
狭小的双人木质隔间结构已大半腐朽、中间隔板的花纹窗格被花蔓塞满、两侧只余昏暗的空间
可用于场景：秘密对话 / 偷听 / 压抑亲密

## v4 最终复合场景层（同一功能空间的多种版本变体，以中央空间为上位）

### 龙巢山脉废墟被花蔓侵蚀中央空间复合场景
is-a 花蔓侵蚀中心大厅标准版（上位：中央空间）
花蔓从穹顶裂缝垂下形成绿色巨型帷幕、地面中央塌陷成一汪浅水池、池中有碎裂的龙骨雕塑从水中升起——光从上方射下照亮水池中央
可用于场景：标准场景大全景 / 角色登场 / 环境概念确立

### 龙巢山脉废墟被花蔓侵蚀中央空间镜面版
is-a 花蔓侵蚀中心大厅镜面倒影版（上位：中央空间）
地面的浅水池完全静止如镜面、倒映出穹顶垂下的花蔓与裂缝光、上下对称的构图充满仪式感——仿佛天空与大地在此对称
可用于场景：对称构图 / 倒影意境 / 静谧极端

### 龙巢山脉废墟被花蔓侵蚀中央空间沉水版
is-a 花蔓侵蚀中心大厅半淹没版（上位：中央空间）
水位上涨至半膝深、花蔓的根部浸泡在水中、水面上飘浮着残花与落叶、走路时泛起破碎的涟漪——入口已被淹没一半
可用于场景：涉水前进 / 淹没危机 / 水中光线折射

### 龙巢山脉废墟被花蔓侵蚀中央空间月光版
is-a 花蔓侵蚀中心大厅月光照明版（上位：中央空间）
穹顶的裂缝在月夜中透入银白色月光、花蔓在月光下呈现银色/冷蓝的色泽、水池反射出波动的月影——一切色彩被漂白只剩蓝与银
可用于场景：月夜主题 / 冷色调 / 幽灵般氛围

### 龙巢山脉废墟被花蔓侵蚀中央空间黑水版
is-a 花蔓侵蚀中心大厅黑化版（上位：中央空间）
池水变成漆黑的、不反射任何光——花蔓也已枯萎变黑干掉、空气中悬浮着黑色颗粒、只有从穹顶射下的光束在不透明的黑水表面形成刺眼对比
可用于场景：污染恶化 / 黑化版本 / 高对比光影
