# 洛夫克拉夫特 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：不可知、海、疯狂的遗迹、知道得越多越危险。

---

## v0 空间母体层

### 海岸神庙
is-a 海滨邪教场所
建在海蚀崖上的黑色石质神庙——屋顶不是人类常见的尖顶而是扭曲的章鱼触手状的雕塑——正门对着大海、常年被海浪拍打
可用于场景：邪教圣地 / 海边的黑石 / 入口面对深渊

### 渔村港口
is-a 诡异渔港
新英格兰风格的灰木码头——但渔船上晾的不是渔网而是某种生物的皮——港口的水不是蓝色的而是灰绿色的
可用于场景：不对劲的渔村 / 港口的异样 / 居民不看海

### 禁忌图书馆
is-a 禁书收藏馆
古老石质建筑、窗户极小——内部书架高到需要梯子——收藏的书籍用铁链锁在书架上——多数书没有标题写在封面
可用于场景：找禁书 / 秘密知识 / 知道太多的地方

### 星海祭坛
is-a 星海交汇祭场
在海岸突出的岩石平台上——用黑色石头摆出的几何图案祭坛——图案对应某个星座的排列——祭坛中心有一个碗状凹陷（装有海水？）
可用于场景：星祭 / 指向天上的图案 / 海与星之间

### 旧日石门
is-a 不可开的门
一扇嵌在岩壁中的黑色石门——门上刻着非欧几何的线条——没有把手没有铰链——它应该不是用来打开的
可用于场景：不可理解的门 / 触摸即疯 / 存在即威胁

### 沉没城市
is-a 水下的异界城市
退潮时露出水面的古城废墟——建筑的风格不属于任何已知文明——窗和门的形状是三角形和椭圆形的混合物——街道的走向不是直线
可用于场景：退潮露出 / 非人建筑 / 潮汐城市

### 观测灯塔
is-a 疯狂灯塔
孤悬在礁石上的白色灯塔——光线旋转扫过海面——但塔内的守灯人的日记写满了"它们在看我们"——光线不仅仅照亮也在引诱
可用于场景：灯塔内部 / 守灯人的疯狂 / 光线通向何处

### 地下仪式井
is-a 深渊之井
在废弃庄园的地下室中的一口井——井水不是水而是某种黑暗的流体——井的直径不规则——从井中传出低沉的声音（像地底在呼吸）
可用于场景：地下室井口 / 不要朝里看 / 声音从深处来

### 怪异研究所
is-a 禁忌科学场所
维多利亚式的旧宅被改成实验室——桌上放着装有异样生物标本的玻璃罐（标本的形态不符合任何已知生物分类）、墙上有画满的公式与符号
可用于场景：疯狂学者的实验室 / 不符合生物学的标本 / 发现真相

### 黑潮洞穴
is-a 海底洞穴
潮间带的潮汐洞穴——入口低矮需弯腰进入——内部逐渐变大——洞穴的墙壁上有荧光矿物画出的不知名图腾——洞中有水声但看不见水
可用于场景：洞穴探险 / 荧光图腾 / 水声不见水

## v1 典型空间层（以海岸神庙为上位）

### 海岸神庙废墟
is-a 废弃邪教神庙（上位：海岸神庙）
神庙的屋顶已经塌了——章鱼触手雕塑碎在地上——但庙内的祭坛仍完好——祭坛上的黑色蜡烛残骸表明不久前还有人在用
可用于场景：废墟还有人在用 / 邪教未散 / 仍然活跃的废墟

### 海岸神庙圣所
is-a 废弃内殿（上位：海岸神庙）
神庙最深处的房间——墙上的壁画是用贝壳与骨骼拼成的——拼出的是一个不可名状的轮廓——壁画的中间部分被刮去了
可用于场景：贝壳骨画 / 轮廓被刮去 / 不完整但更可怕

### 海岸神庙大厅
is-a 废弃仪式厅（上位：海岸神庙）
主厅——地面铺着黑白交错的石砖——石砖的排列不是棋盘格而是螺旋形——从入口到祭坛的路没有直线
可用于场景：螺旋地砖 / 不直线 / 走向祭坛的路在转

### 海岸神庙回廊
is-a 废弃侧廊（上位：海岸神庙）
两侧的墙上嵌着壁龛——壁龛中放着的是人的头骨——但头骨的额头部位有被人工加宽过的痕迹（改造过头颅）
可用于场景：改过的头骨 / 额头被扩 / 祭祀的痕迹

### 海岸神庙祭坛
is-a 废弃主祭台（上位：海岸神庙）
黑色石头祭坛——坛面上有明显的液体流动痕迹——液体是深绿色的（不是血是海水？还是别的）——有腥味
可用于场景：有液体痕迹的祭坛 / 绿液 / 祭祀还在进行

### 海岸神庙庭院
is-a 废弃祭院（上位：海岸神庙）
被黑墙围合的露天区域——地面是碎石混合着贝壳——中央有一个枯井——井口的边缘雕刻着波浪纹
可用于场景：枯井中庭 / 贝壳地面 / 井口有波浪纹

### 海岸神庙钟楼
is-a 废弃钟塔（上位：海岸神庙）
钟楼——钟的表面刻着与石门相同的非欧图案——站在钟下仰头看那些图案会感到眩晕——钟不敲自响？——不、钟从未响过
可用于场景：非欧图案钟 / 看图案会晕 / 不响的钟

### 海岸神庙地下层
is-a 神庙地窖（上位：海岸神庙）
地下潮湿的储藏室——墙上的盐霜在灯光下闪光——地面上有拖拽的痕迹——从入口通向黑暗的深处
可用于场景：地下拖痕 / 盐霜闪光 / 通向深处

### 海岸神庙入口
is-a 神庙大门（上位：海岸神庙）
门口两侧的柱子上刻着一对眼睛状的图案——但不是眼睛——是闭不上的器官——柱顶的火盆已熄灭多年
可用于场景：永远睁着的眼柱 / 熄灭的火盆 / 进入邪祠

### 海岸神庙核心区
is-a 神庙地底裂缝（上位：海岸神庙）
祭坛正下方——一条通向地下的裂缝——裂缝中涌出温暖湿润的风——带着深海的气味——裂缝深度未知
可用于场景：裂缝有海风 / 深海气味从地下来 / 通向非人之处

## v2 状态侵蚀层（以海岸神庙废墟为上位）

注意：洛夫克拉夫特的侵蚀——不是自然分解而是"来自异界的渗透"——物体被异质取代。

### 海岸神庙废墟被花蔓侵蚀
is-a 海花（上位：海岸神庙废墟）
从岩石裂缝中长出的不是陆地花——是海葵般的触手状生物——颜色是荧光粉与深紫色的混合——在黑暗中发光
可用于场景：海花如触手 / 发光 / 不属地

### 海岸神庙废墟被荆棘缠绕
is-a 骨刺（上位：海岸神庙废墟）
从石头中伸出的白色骨状尖刺——不是生物的骨头——是某种矿物以骨骼形态结晶——像石头在长骨头
可用于场景：骨刺从石出 / 矿物变成骨 / 石在钙化

### 海岸神庙废墟被树根穿刺
is-a 海树根（上位：海岸神庙废墟）
黑色滑腻的根部组织——不是树根——更像是巨型章鱼的腕足部分——穿过石缝伸出——表面有吸盘状的凹痕
可用于场景：非树之根 / 腕足状的根 / 黑滑触手

### 海岸神庙废墟被苔藓覆盖
is-a 活苔（上位：海岸神庙废墟）
暗绿色的苔藓——在黑暗中仍能看出明显的缓慢生长——它在"动"——苔藓的边界在不断变化
可用于场景：活的苔藓 / 边界在移动 / 覆盖物是有生命的

### 海岸神庙废墟被菌丝寄生
is-a 星丝（上位：海岸神庙废墟）
发着淡蓝色光的菌丝——菌丝的走向不是随机的——它们按照某个复杂的几何图案生长——像在用丝画出一个高维图形
可用于场景：蓝色光丝画高维图 / 菌丝的非随机图案 / 丝在画什么

### 海岸神庙废墟被黑雾吞没
is-a 虚空雾（上位：海岸神庙废墟）
从海面蔓延而来的黑色雾——雾中没有任何概念——没有温度没有气味没有方向——步入其中会失去所有感官几分钟
可用于场景：感官剥夺之雾 / 黑雾无感 / 走入即失去

### 海岸神庙废墟被冰晶封存
is-a 异冰（上位：海岸神庙废墟）
淡蓝色半透明的冰晶体——冰中封存着不是生物的东西——是图案——冰中长出了像文字的条纹
可用于场景：冰中有字 / 封着图案 / 冰不仅仅是冰

### 海岸神庙废墟被血迹污染
is-a 绿液（上位：海岸神庙废墟）
不是红色——是荧光绿色的液体——洒在石头表面发出微光、液体的粘度像胶——沾到石头上无法擦除
可用于场景：荧光绿液 / 不可擦除 / 不是血

### 海岸神庙废墟被月光空壳化
is-a 月下显现（上位：海岸神庙废墟）
月光下神庙的墙面上浮现出白天看不到的文字——荧光绿色的文字像海藻的磷光一样浮现——月是真言灯
可用于场景：月下文字浮现 / 被月照亮的秘密

### 海岸神庙废墟被星尘异化
is-a 星之种（上位：海岸神庙废墟）
银蓝色的星尘落在了神庙上——星尘在石头上生根——长出了细小的透明晶体——像是星尘在这里繁殖了
可用于场景：星尘结晶体 / 尘在石上生 / 天外来物扎根

## v3 内部功能空间层（以海岸神庙废墟被花蔓侵蚀为上位——"花蔓"=海花）

### 海岸神庙废墟被花蔓侵蚀中央空间
is-a 海花中央（上位：海岸神庙废墟被花蔓侵蚀）
神庙主厅——地面的砖缝中长满了荧光粉色的海花——花像一圈圈涟漪从中心向外扩散——中心的花最密集
可用于场景：荧光粉花如涟漪 / 光晕中央 / 发光的满地

### 海岸神庙废墟被花蔓侵蚀祭坛空间
is-a 海花祭台（上位：海岸神庙废墟被花蔓侵蚀）
黑色祭坛——海花从液体流动的痕迹中长出——花沿着液体的流向排列——像用花标注了祭品的路径
可用于场景：花沿着液流 / 祭品的路径被花标出

### 海岸神庙废墟被花蔓侵蚀回廊空间
is-a 海花侧廊（上位：海岸神庙废墟被花蔓侵蚀）
侧廊——海花从壁龛的头骨中长出——花的茎穿过头骨的眼孔与鼻孔——像花把头骨当成了花盆
可用于场景：花从头骨中出 / 眼孔中长花 / 骨为花盆

### 海岸神庙废墟被花蔓侵蚀洗礼池
is-a 海花池（上位：海岸神庙废墟被花蔓侵蚀）
洗礼池——水中长满了海花——水不是绿色而是被花染成了荧光粉色——水面上一层荧光粉的薄膜
可用于场景：粉水 / 花染水 / 荧光水池

### 海岸神庙废墟被花蔓侵蚀祈祷室
is-a 海花小室（上位：海岸神庙废墟被花蔓侵蚀）
祈祷室——墙上贝壳与骨骼拼成的壁画——海花沿着拼图的缝隙生长——花变成了壁画的一部分
可用于场景：花融入壁画 / 花成为拼图的一部分

### 海岸神庙废墟被花蔓侵蚀花窗大厅
is-a 海花窗（上位：海岸神庙废墟被花蔓侵蚀）
窗——没有玻璃——海花的触手从窗口探入室内——在窗口形成了粉色的帘幕——光穿过花帘变成粉紫色
可用于场景：触手花窗帘 / 粉色光 / 花从窗口涌入

### 海岸神庙废墟被花蔓侵蚀地下墓穴
is-a 海花地窖（上位：海岸神庙废墟被花蔓侵蚀）
地窖——海花从墙壁上向下生长——像荧光粉色的瀑布从墙上倾泻——地面厚厚的花丛覆盖了原本的地面
可用于场景：粉花瀑布墙 / 花从墙泻地 / 地上的厚花毯

### 海岸神庙废墟被花蔓侵蚀钟楼
is-a 海花钟（上位：海岸神庙废墟被花蔓侵蚀）
钟楼——非欧图案的钟面被海花覆盖了大半——露出的图案部分在花的衬托下更加扭曲
可用于场景：花半遮非欧纹 / 图案在花中更诡异

### 海岸神庙废墟被花蔓侵蚀圣像墙
is-a 海花壁（上位：海岸神庙废墟被花蔓侵蚀）
墙上的眼状刻痕——海花从"瞳孔"位置长出——像花代替了眼睛的眼球——花的中心是深紫色的像瞳孔
可用于场景：花为眼珠 / 花的位置在瞳孔 / 刻痕中的花

### 海岸神庙废墟被花蔓侵蚀忏悔室
is-a 海花角室（上位：海岸神庙废墟被花蔓侵蚀）
角落——海花在这里形成了一个茧状的厚团——花的内部是空心的——人可以蜷缩进去
可用于场景：花茧 / 花的避难所 / 蜷入花中

## v4 最终复合场景层（中央空间10种变体）

### 海岸神庙废墟被花蔓侵蚀中央空间复合场景
is-a 海花心标准版（上位：中央空间）
荧光粉色的花海从大门一直铺到祭坛——祭坛上方的屋顶已塌—月光洒入照亮了祭坛中央的花最密处——花在发光
可用于场景：粉花月照 / 最密的花在祭坛 / 标准大全景

### 海岸神庙废墟被花蔓侵蚀中央空间镜面版
is-a 海花心倒影版（上位：中央空间）
地面的积水倒映着荧光粉的花和月光——水中的荧光粉色比实物更亮——像水下还有第二个发光源
可用于场景：水中更亮 / 粉光水影 / 水下有光源

### 海岸神庙废墟被花蔓侵蚀中央空间沉水版
is-a 海花心水漫版（上位：中央空间）
海水倒灌入神庙——荧光粉的花漂在水面上——海水本身是深绿色的——粉色花朵在深绿海水上形成对比
可用于场景：粉花漂绿海 / 海水淹教堂 / 粉绿对比

### 海岸神庙废墟被花蔓侵蚀中央空间月光版
is-a 海花心月夜版（上位：中央空间）
月光下荧光粉的花变成银紫色——花的荧光在月光中减弱——但月光的白色与花的粉色混合成柔和的淡紫
可用于场景：银紫花 / 月淡了花的荧光 / 月染花色

### 海岸神庙废墟被花蔓侵蚀中央空间黑水版
is-a 海花心黑液版（上位：中央空间）
从祭坛下的裂缝中涌出黑色粘稠液体——荧光粉的花被黑色液体覆盖后——荧光消失——花变成暗灰色
可用于场景：黑液熄荧光 / 粉色被黑吞 / 光被灭

### 海岸神庙废墟被花蔓侵蚀中央空间环形祭坛版
is-a 海花心仪式版（上位：中央空间）
祭坛周围——有人用海花的茎秆在祭坛周围编了一环形——花环是新鲜的不是干枯的——有人最近来过
可用于场景：新鲜花环 / 还有人祭祀 / 花环在祭坛外

### 海岸神庙废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 海花心泉涌版（上位：中央空间）
祭坛正下方的裂缝扩大——涌出的水不是黑色——是清澈的——水流冲开了海花露出下面的黑色祭坛——第一次见到祭坛全貌
可用于场景：清水洗出祭坛 / 第一次看到完整 / 水流后的揭示

### 海岸神庙废墟被花蔓侵蚀中央空间白花漂浮版
is-a 海花心飞瓣版（上位：中央空间）
荧光粉的花瓣大量脱离——在空气中缓慢飘浮（比正常飘落慢得多）——像在水中一样——空气密度异常
可用于场景：浮瓣慢飘 / 慢动作的花散 / 空气似水

### 海岸神庙废墟被花蔓侵蚀中央空间枯井版

可用于场景：花避开的地方 / 裂缝无花 / 下方有东西

可用于场景：粉色光雾 / 花爆满厅 / 一切淹没在粉色中
