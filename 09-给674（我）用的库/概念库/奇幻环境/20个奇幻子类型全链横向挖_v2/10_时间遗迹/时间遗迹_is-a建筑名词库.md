# 时间遗迹 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：时间本身是这里的主导者——被遗忘、等待、流逝感。

---

## v0 空间母体层

### 断钟遗迹
is-a 时停古迹
巨大的石造钟表机构残骸——齿轮直径达数米半埋在砂砾中、指针断裂、钟面碎裂、钟体上刻着几种不同文明的文字
可用于场景：时间遗迹入口 / 巨大的齿轮 / 不同文明的痕迹

### 环形神殿
is-a 圆形时间圣殿
完美圆形的露天石殿——柱子排列的阴影在一天中构成一个完整的日晷、神殿中央有一个向下凹陷的圆形深坑
可用于场景：日晷神殿 / 影随日转 / 圆形朝圣

### 时沙庭院
is-a 沙漏庭院
透明的玻璃穹顶覆盖的庭院——地面铺着数层细沙、庭院中央有一个高耸的古代沙漏（已经停摆多年）、沙子堆积在底部
可用于场景：沙漏庭院 / 漏尽的沙 / 时间静止

### 古代机关城
is-a 机械城市遗迹
由纯机械组成的建筑群——齿轮、杠杆、滑轮的组合、比任何人类建筑更精密、但现在大部分已锈死卡住、发出断续的咯吱声
可用于场景：机械遗迹 / 停止的精密 / 再上发条

### 停摆钟楼
is-a 静止钟塔
一座内部全是齿轮的塔——齿轮从地面堆叠到天花板、占据了所有空间、人需要从齿轮缝隙中侧身穿行
可用于场景：齿轮迷宫 / 爬上钟塔 / 时间的内部

### 逆流河道
is-a 时间倒流河流
一条河流——但水在从低处向高处流、逆着重力方向流动、河面上漂浮着枯叶逆流而上
可用于场景：反常河流 / 视觉错乱 / 时间方向乱

### 日晷广场
is-a 广场巨型日晷
巨大的圆形广场——地面铺着精确的刻度线纹路、中央竖立着一根高耸的晷针、晷针的影子在这个地方永远固定在正午位置
可用于场景：静止的日晷 / 时间不再流转 / 被钉住的影

### 时间裂缝大厅
is-a 时间裂痕空间
一个大厅中存在着多个"时间窗口"——某些区域光线更亮（过去）、某些区域光线更暗（未来）、不同区域温度不同
可用于场景：踏进不同时间 / 时间碎裂 / 一脚过去一脚未来

### 遗忘车站
is-a 废弃传送车站
神秘文明的交通枢纽——拱形大厅中有多个封闭的拱门门洞、每个门洞上方写着不同的地名（已不可读）、地板有自动扶梯的凹槽
可用于场景：废弃车站 / 无法出发的站台 / 通向哪里的门

### 年代断层街
is-a 时间拼贴街道
一条街道上同时存在三种建筑风格：最左边是远古石柱中间是哥特尖拱最右边是工业铁架——三个时代的建筑被拼接在一起
可用于场景：时代杂糅 / 时间错位 / 视觉混乱

## v1 典型空间层（以断钟遗迹为上位）

### 断钟遗迹废墟
is-a 废弃时计遗迹（上位：断钟遗迹）
巨大的齿轮已经停止转动多年——齿轮缝隙中卡着碎石与枯枝、爬满铁锈、断钟的半截指针指向十点十五分（永远）
可用于场景：齿轮卡死 / 时间永远停在十点十五 / 静谧的机械废墟

### 断钟遗迹圣所
is-a 废弃时间圣殿（上位：断钟遗迹）
用一个巨大的齿轮框架作为圣殿的门——穿过齿轮门内是一个圆形石室、中央有一个干涸的喷泉（喷泉的出水口是一个小日晷造型）
可用于场景：齿轮门 / 日晷喷泉已干 / 时间不再涌出

### 断钟遗迹大厅
is-a 废弃齿轮厅（上位：断钟遗迹）
巨大厅堂中平放着一个直径超20米的钟面——人可以走在钟面上、钟面的刻度已经模糊、数字是某种古老文字
可用于场景：巨型钟面 / 行走在时间之上 / 刻度之大

### 断钟遗迹回廊
is-a 废弃摆锤廊（上位：断钟遗迹）
走廊上方悬挂着一排停止的摆锤——不同长度、不同高度、全部静止不动、像一排被冻结的钟摆
可用于场景：摆锤之廊 / 冻结的摆动 / 安静得令人不安

### 断钟遗迹祭坛
is-a 废弃时计祭坛（上位：断钟遗迹）
用齿轮堆砌成的台阶状祭坛——最高处嵌着一块发光的石英石（曾是能量核心）、现在已暗淡、但石英内部仍有细微的裂纹发光
可用于场景：齿轮祭台 / 能量已尽但仍有残光

### 断钟遗迹庭院
is-a 废弃时间庭院（上位：断钟遗迹）
被高墙围合的天井——地面上用黑色与白色石子拼出了一个巨大的沙漏图案、墙上有一排熄灭的油灯、油灯的数量对应月份的数目
可用于场景：沙漏地画 / 月份灯全灭 / 庭院的象征

### 断钟遗迹钟楼
is-a 废弃遗迹钟塔（上位：断钟遗迹）
——但断钟遗迹本身就是钟楼。这里的"钟楼"指的是遗迹入口的柱塔——一根高耸的柱状岩石上面刻着螺旋纹路的刻度
可用于场景：时间之柱 / 螺旋刻度 / 无可读性

### 断钟遗迹地下层
is-a 遗迹地下（上位：断钟遗迹）
地面以下层层叠叠的机械层——每一层是不同时代的机械结构——最下层的齿轮是青铜的最上层是铁的——文明演替的纵切面
可用于场景：科技地层 / 文明堆叠 / 向下即是向后

### 断钟遗迹入口
is-a 遗迹大门（上位：断钟遗迹）
由两个垂直放置的巨大齿轮组成的拱门——齿轮的齿相互咬合形成一个"门"的造型、穿过它即算进入时间领域
可用于场景：齿轮门拱 / 跨入时间的入口 / 机械的拱

### 断钟遗迹核心区
is-a 遗迹能量核心（上位：断钟遗迹）
遗迹的最中心——一个由多圈齿轮嵌套的球形结构（像钟表机芯被放大到一间屋子大小）、中央嵌着一块碎裂的时间水晶
可用于场景：机芯球 / 核心水晶已碎 / 心脏停跳

## v2 状态侵蚀层（以断钟遗迹废墟为上位）

注意：时间遗迹的侵蚀——被时间本身侵蚀，而不是被自然。

### 断钟遗迹废墟被花蔓侵蚀
is-a 铁锈花（上位：断钟遗迹废墟）
齿轮上长出的不是植物花——是铁锈在金属表面结晶出的花状氧化层——像橙红色的花长在铁上
可用于场景：铁锈之花 / 金属生花 / 氧化的美

### 断钟遗迹废墟被荆棘缠绕
is-a 锈棘（上位：断钟遗迹废墟）
断裂的金属丝与锐利碎片的组合——不是植物但形似荆棘、缠绕在齿轮与柱子上、锋利到能割破皮肤
可用于场景：金属荆棘 / 工业的刺 / 进不去

### 断钟遗迹废墟被树根穿刺
is-a 时间树根（上位：断钟遗迹废墟）
树根穿入机械结构——根须卡在齿轮的齿间、使齿轮无法转动一根须成了新的"润滑剂/阻滞剂"
可用于场景：根卡齿轮 / 自然锁死时间 / 机械被根驯服

### 断钟遗迹废墟被苔藓覆盖
is-a 铜绿苔（上位：断钟遗迹废墟）
青铜齿轮上长出了绿锈——与苔藓混合后形成一种介于绿锈和绿苔之间的物质、覆盖了机械表面的所有细节
可用于场景：青绿之壳 / 细节被时间覆盖 / 铜绿色的覆盖

### 断钟遗迹废墟被菌丝寄生
is-a 菌丝时间网（上位：断钟遗迹废墟）
白色菌丝从齿轮的轴孔中蔓延出来——菌丝沿着齿轮的齿根扩散、像为齿轮画出了新的"时间线"
可用于场景：菌丝盘齿轮 / 微生物画出新时间 / 白色网络

### 断钟遗迹废墟被黑雾吞没
is-a 时间雾（上位：断钟遗迹废墟）
从遗迹裂缝中涌出的灰黑色雾气——雾中能看见时快时慢飘动的尘埃（像时间的流速在雾中不均匀）
可用于场景：时间不均匀的雾 / 尘的速度不一 / 时间错乱

### 断钟遗迹废墟被冰晶封存
is-a 石英晶封（上位：断钟遗迹废墟）
石英晶体在齿轮的缝隙中生长——透明的晶体将断裂的金属包裹、像自然用玻璃将时间遗迹打了补丁
可用于场景：石英封缺口 / 晶体修补 / 自然在修复

### 断钟遗迹废墟被血迹污染
is-a 油血（上位：断钟遗迹废墟）
机器的润滑油与血液混合的痕迹——在齿轮上形成一种暗红色的油膜——分不清是维护机器的工人受伤还是别的
可用于场景：油与血的混合 / 机械的伤痛 / 暗红色油痕

### 断钟遗迹废墟被月光空壳化
is-a 月下机影（上位：断钟遗迹废墟）
月光将机械的轮廓镀成银色、齿轮的影子上映着月光的反光——白天看起来锈蚀的铁在月下显得神圣
可用于场景：月下齿轮 / 锈变银 / 夜的洗白

### 断钟遗迹废墟被星尘异化
is-a 星尘润机（上位：断钟遗迹废墟）
银蓝色星尘落在齿轮的轴和咬合面上——被星尘接触的齿轮开始缓慢转动——时间遗迹的一部分开始重新运转了
可用于场景：星尘重启时间 / 齿轮缓慢转动 / 复活

## v3 内部功能空间层（以断钟遗迹废墟被花蔓侵蚀为上位——这里的"花蔓"=铁锈花）

### 断钟遗迹废墟被花蔓侵蚀中央空间
is-a 锈花中央（上位：断钟遗迹废墟被花蔓侵蚀）
最大的齿轮厅——中央放着一个直径10米的水平齿轮——齿轮平面上覆盖着橙红色的铁锈花、像给齿轮铺了一层花毯
可用于场景：锈花齿轮 / 铁花地毯 / 机械与花的共生

### 断钟遗迹废墟被花蔓侵蚀祭坛空间
is-a 锈花祭台（上位：断钟遗迹废墟被花蔓侵蚀）
齿轮台阶的顶端——铁锈花长得最密的地方、花包围着一块嵌在齿轮轴心的石英石、石英内部有微弱的光
可用于场景：锈花中的残光 / 被花簇拥的核心

### 断钟遗迹废墟被花蔓侵蚀回廊空间
is-a 锈花廊（上位：断钟遗迹废墟被花蔓侵蚀）
走廊上方的摆锤全部覆盖了一层橙红色的铁锈花——摆锤不再只是金属而是变成了橙色结晶的"雕塑"
可用于场景：锈花摆锤 / 铁花坠 / 腐蚀的装饰

### 断钟遗迹废墟被花蔓侵蚀洗礼池
is-a 锈花水池（上位：断钟遗迹废墟被花蔓侵蚀）
齿轮凹槽中积存的雨水——水已被铁锈染成橙红色透明、水底沉积着细碎的红色铁锈粉末
可用于场景：锈水之池 / 橙红透明 / 铁色之水

### 断钟遗迹废墟被花蔓侵蚀祈祷室
is-a 锈花小室（上位：断钟遗迹废墟被花蔓侵蚀）
狭窄的操作台被铁锈花覆盖——但操作台面上的金属部分被磨得发亮（曾有人长时间使用）——亮面与锈花形成了对比
可用于场景：亮面与锈 / 曾经人手触及之处不锈

### 断钟遗迹废墟被花蔓侵蚀花窗大厅
is-a 锈花光厅（上位：断钟遗迹废墟被花蔓侵蚀）
光线穿过齿轮的孔洞在室内投下光斑——光斑的形状不是圆的而是齿轮形的、地面上布满了齿轮形状的光影
可用于场景：齿轮光斑 / 机械的影子 / 光与齿

### 断钟遗迹废墟被花蔓侵蚀地下墓穴
is-a 锈花底层（上位：断钟遗迹废墟被花蔓侵蚀）
最下层的机械层——空气更潮湿——铁锈花在这里长得更大但颜色偏深（暗红色）、空气中弥漫着金属与水的气味
可用于场景：低层锈花更红更湿 / 金属与水味 / 深层腐蚀

### 断钟遗迹废墟被花蔓侵蚀钟楼
is-a 锈花指针（上位：断钟遗迹废墟被花蔓侵蚀）
钟面已经被铁锈花覆盖——只剩指针尖端露在外面——露出的部分却是不锈的锃亮的——像时间还在试图指示
可用于场景：锈花盖面 / 最尖端的坚持 / 指着却没人看

### 断钟遗迹废墟被花蔓侵蚀圣像墙
is-a 锈花浮雕（上位：断钟遗迹废墟被花蔓侵蚀）
墙上的机械浮雕——齿轮与连杆的图案——铁锈花沿着浮雕的轮廓线生长、强化了浮雕的立体感
可用于场景：锈花描边 / 腐蚀加深了轮廓

### 断钟遗迹废墟被花蔓侵蚀忏悔室
is-a 锈花夹层（上位：断钟遗迹废墟被花蔓侵蚀）
两个大齿轮之间的狭窄通道——通道墙面左右两侧的铁锈花在头顶交错、形成橙红色花顶的天然隧道
可用于场景：锈花隧道 / 侧身通过的橙红

## v4 最终复合场景层（中央空间10种变体）

### 断钟遗迹废墟被花蔓侵蚀中央空间复合场景
is-a 锈花中心标准版（上位：中央空间）
水平齿轮上的铁锈花呈同心圆放射状分布——从齿轮中心到边缘密度递减、中心的花最密最红
可用于场景：同心圆锈花 / 中心最盛 / 标准大全景

### 断钟遗迹废墟被花蔓侵蚀中央空间镜面版
is-a 锈花中心倒影版（上位：中央空间）
齿轮凹槽积满雨水——水平如镜——倒映着橙红色的锈花和灰白色的天空、齿轮的倒影在水中显得更精密
可用于场景：锈花倒影 / 水映齿轮 / 镜像机械

### 断钟遗迹废墟被花蔓侵蚀中央空间沉水版
is-a 锈花中心水淹版（上位：中央空间）
水位上升到齿轮平面以下半米——齿轮像是沉在水中的圆盘、透过锈水能看到水下齿轮上铁锈花的橙色轮廓
可用于场景：水下齿轮 / 橙色轮廓在水中 / 锈花池

### 断钟遗迹废墟被花蔓侵蚀中央空间月光版
is-a 锈花中心月夜版（上位：中央空间）
月光将橙红色的铁锈花变成深紫色——月光的光谱中红色被吸收——锈花呈现月下独有的冷紫与暖橙的交界色
可用于场景：冷月暖锈 / 紫与橙的交界 / 温度对比

### 断钟遗迹废墟被花蔓侵蚀中央空间黑水版
is-a 锈花中心油污版（上位：中央空间）
从某个管道的泄漏使黑色油脂覆盖了齿轮表面——铁锈花被黑油覆盖变成黑色、机械表面变成油亮的黑
可用于场景：油没锈花 / 黑亮的机械 / 油毯覆盖

### 断钟遗迹废墟被花蔓侵蚀中央空间环形祭坛版
is-a 锈花中心仪式版（上位：中央空间）
有人在齿轮上围绕着石英核心用白石头摆了一个锚形或罗盘形——某个未知文明的朝圣者留下的
可用于场景：石摆锚形 / 朝圣者的痕迹 / 新仪式旧地

### 断钟遗迹废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 锈花中心泉涌版（上位：中央空间）
齿轮中央的轴孔中涌出了清澈的地下水——水从锈花中穿过带走了一些铁锈色——在齿轮表面形成橙→粉→透明的渐变色带
