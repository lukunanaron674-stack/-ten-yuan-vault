# 巨人山脉 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：巨物尺度、沉默、人类渺小、一切建筑都是为比人大得多的存在建造的。

---

## v0 空间母体层

### 巨人山脉
is-a 巨人栖息山地
整座山脉都是巨人雕刻过的——巨大的台阶凿入山体、岩壁上有手掌大小的抓握凹槽、山巅被削平为平台、所有尺度都是人类的五倍以上
可用于场景：巨人之地 / 渺小的人类 / 巨构远景

### 巨人石门
is-a 巨人之门
两块高达三十米的直立巨石形成的门——巨石之间宽可容四辆马车并行并行、门梁也是一块横跨的巨石——不知什么力量放置的
可用于场景：进入巨人领地 / 门之大 / 惊叹

### 沉睡王座
is-a 巨人王座遗迹
山体侧面凿出的巨大椅形——像一个座位但坐垫的尺寸足以让一个山丘大小的存在坐下——座椅上覆盖着冰雪与苔藓
可用于场景：空王座 / 巨人已不在 / 沉默的权力

### 山体神殿
is-a 山体内部圣殿
整座山从内部被挖空——内部是一个高百米的大厅、光线从山顶的裂缝射入、地面是天然岩石磨平的、没有任何家具（不需要）
可用于场景：巨大的空厅 / 山内圣殿 / 回声

### 云雾峡谷
is-a 巨人级的峡谷
峡谷两侧的垂直岩壁间距有五十米以上——风在峡谷中形成持续的呼啸、峡谷底部终年云雾弥漫看不到底
可用于场景：云雾深渊 / 穿越大峡谷 / 风之走廊

### 断裂石桥
is-a 碎裂巨桥
连接两座山峰的石桥——宽可供二十人并行但已经从中断裂、断裂面像被巨力拧断的、桥体大部分仍悬在空中
可用于场景：断桥冒险 / 越过裂缝 / 巨力留下的伤痕

### 巨骨山谷
is-a 巨兽葬谷
遍布巨大骨化石的山谷——肋骨如同拱门般跨越路径、头骨像房屋一样大的化石半埋在碎石中、脊椎骨排成山脊的形状
可用于场景：巨兽墓地 / 化石拱门 / 远古的死亡

### 冰峰平台
is-a 冰川之巅
山脉最高处的冰盖平台——极其平整（不像自然形成）、冰面厚达数米、可以照见人影、周围是翻涌的云海
可用于场景：冰镜平台 / 云海之上 / 极寒之顶

### 悬崖城寨
is-a 悬崖上的聚落
嵌在垂直悬崖面上的石造城寨——用凿出的台阶与栈道连接每个房间、下方是万丈深渊、房间的石门都异常高大（为巨人建造）
可用于场景：悬崖上的巨人住所 / 栈道行走 / 垂直都市

### 山腹回廊
is-a 山体内廊道
贯穿山体的水平通道——通道的截面是半圆形高八米宽六米、两侧有间隔相等的壁龛（放的是火把还是照明水晶？已灭）
可用于场景：山内长廊 / 巨人走廊 / 步行的深层隧道

## v1 典型空间层（以巨人山脉为上位）

### 巨人山脉废墟
is-a 巨人文明遗迹（上位：巨人山脉）
巨人的石屋坍塌后——每块碎石都有半人高——废墟的碎块堆中散落着巨人用的陶器碎片（陶片比人的脸还大）
可用于场景：巨人废屋 / 碎片之大 / 巨物残骸

### 巨人山脉圣所
is-a 巨人神殿（上位：巨人山脉）
巨人朝拜的地方——但这里没有任何神像——只有一个巨大的空壁龛、壁龛的形状是人的轮廓——巨人向人形祈祷（还是人向巨人祈祷？）
可用于场景：巨人跪拜人形 / 谁拜谁 / 模糊的信仰

### 巨人山脉大厅
is-a 巨人大厅（上位：巨人山脉）
足够容纳数十个巨人的巨大空间——柱子粗到三个人合抱不住——桌子的位置只剩两条腿高到人胸口、桌板已倒在地上盖住半间屋
可用于场景：巨桌倒地 / 柱子的粗度 / 大厅的剩余

### 巨人山脉回廊
is-a 巨人走廊（上位：巨人山脉）
高八米的走廊——两侧的壁灯位置在人的头顶两米以上——人走过时头顶上方是有光的但不属于人的高度
可用于场景：光在头上 / 人的尺度在巨人走廊中 / 走错时代

### 巨人山脉祭坛
is-a 巨人祭台（上位：巨人山脉）
一个由整块巨石雕成的祭坛——高四米、人可以爬上去但爬上后看不到祭坛的台面（因为太高了）、台面上有干涸的黑色痕迹
可用于场景：爬上的祭坛 / 看不到顶的台面 / 巨大的献祭

### 巨人山脉庭院
is-a 巨人大庭院（上位：巨人山脉）
围墙高六米围合出的露天空间——面积有一个足球场大——但没有任何布置——对于巨人来说这就是后院空地
可用于场景：巨大的空地 / 空空如也 / 无事发生的远处

### 巨人山脉钟楼
is-a 巨人之塔（上位：巨人山脉）
一整块高耸的岩柱——表面刻着盘旋上升的台阶——台阶是为巨人设计的（每级高半米）——人爬上去等于攀岩
可用于场景：巨阶攀岩 / 爬巨人走的楼梯 / 每一步都是跨越

### 巨人山脉地下层
is-a 巨人地宫（上位：巨人山脉）
山脉底部的地下大厅——比地面建筑还要宏伟——巨柱林立如地下森林——地面上有巨人走过的巨大足迹（凹陷的石面）
可用于场景：地下的巨人足迹 / 柱林 / 更深层的巨物

### 巨人山脉入口
is-a 巨人入口（上位：巨人山脉）
山体的入口——一个被劈开的三角形缺口——像是用斧头之类的巨器一刀斩开的——缺口边缘平整到不自然
可用于场景：一刀斩开的山体入口 / 暴力的门 / 力量的证明

### 巨人山脉核心区
is-a 巨人之心（上位：巨人山脉）
巨人的能源核心——一个由透明水晶构成的巨大球形——球体直径约五米、已无光、但球体表面还有余温
可用于场景：水晶球核 / 巨大的能量壳 / 巨人力量已散但热度还在

## v2 状态侵蚀层（以巨人山脉废墟为上位）

注意：巨人山脉的侵蚀——山体自身的风化与巨物被时间缩小（相对人类的视角则在扩大时间的痕迹）。

### 巨人山脉废墟被花蔓侵蚀
is-a 巨岩生花（上位：巨人山脉废墟）
巨人石屋的裂缝中长出了野花——花在巨大的背景中显得极其微小——但是人类尺度下它们正常大小——巨与小的双重感知
可用于场景：巨石下的小花 / 尺寸的相对性 / 微小的生命力

### 巨人山脉废墟被荆棘缠绕
is-a 山棘（上位：巨人山脉废墟）
耐寒的高山荆棘沿着碎石堆蔓延——刺硬而粗、在碎石之间的空隙形成天然的障碍——荆棘也长得比别处大（因为养分来自巨人废墟）
可用于场景：高山硬棘 / 养分充足所以长得大 / 废墟上的刺

### 巨人山脉废墟被树根穿刺
is-a 高山松根（上位：巨人山脉废墟）
高山松树的根从巨石的缝隙中钻入——松根为生存而扭曲、顺着石缝如蛇一般蔓延——根系比树干更长更粗
可用于场景：松根寻缝 / 高山生命的韧性 / 根的路径

### 巨人山脉废墟被苔藓覆盖
is-a 高山苔壳（上位：巨人山脉废墟）
灰色与深绿色的片状苔藓在巨人碎石上形成一层厚壳——苔藓壳的厚度超过五厘米——手指按下去像按在湿海绵上
可用于场景：苔壳厚厚 / 石头穿绿衣 / 冰凉的软

### 巨人山脉废墟被菌丝寄生
is-a 雪白菌丝（上位：巨人山脉废墟）
白色的菌丝在巨人碎石的阴面蔓延——菌丝如同白色的网将石头联结在一起——不是分解而是像在缝合废墟
可用于场景：白丝缝石 / 菌丝联结巨岩 / 缝合者

### 巨人山脉废墟被黑雾吞没
is-a 山腰云（上位：巨人山脉废墟）
——在高山上这不是雾——是云。云将废墟的半山腰包裹——从下方看废墟在云中若隐若现、从上方看废墟像飘在云海之上
可用于场景：云中废墟 / 云海掩映 / 天空上的残骸

### 巨人山脉废墟被冰晶封存
is-a 冰山（上位：巨人山脉废墟）
冰在巨石的裂缝中反复溶解与冻结——形成了冰楔将巨石进一步撑裂——冻在冰中的碎石像琥珀中的包含物
可用于场景：冰楔裂石 / 冰中的石头 / 冷冻的分解

### 巨人山脉废墟被血迹污染
is-a 铁色苔（上位：巨人山脉废墟）
——与血无关。这里的红色来自岩石中的铁氧化物——含铁高的石面呈铁锈色——像是石头在流血
可用于场景：石头流锈 / 铁色的血痕 / 山体在出血

### 巨人山脉废墟被月光空壳化
is-a 月下巨影（上位：巨人山脉废墟）
巨大的山体在月光下的阴影覆盖了大半个山谷——阴影中的废墟轮廓像一只趴着的巨兽——阴影本身比废墟更有存在感
可用于场景：巨影压境 / 阴影覆盖一切 / 白天是废墟晚上是巨兽

### 巨人山脉废墟被星尘异化
is-a 星光结晶（上位：巨人山脉废墟）
银蓝色的星尘落在高山冰晶上——冰晶折射星光的颜色——夜晚的废墟像撒了一层碎钻
可用于场景：冰晶闪星光 / 高山上的钻石 / 夜间的闪烁

## v3 内部功能空间层（以巨人山脉废墟被花蔓侵蚀为上位）

### 巨人山脉废墟被花蔓侵蚀中央空间
is-a 巨厅开花（上位：巨人山脉废墟被花蔓侵蚀）
巨人大厅的地面——花从地砖的缝隙中长出来——在巨大的柱子和巨大的空间中这些花像点缀——但在人类尺度下它们就是正常的花丛
可用于场景：巨厅中的小花丛 / 尺度对比 / 花在巨构中

### 巨人山脉废墟被花蔓侵蚀祭坛空间
is-a 巨坛生芽（上位：巨人山脉废墟被花蔓侵蚀）
巨人的祭坛——四米高的石台上方——悬垂的花蔓从台顶边缘垂落下来——像祭坛的流苏
可用于场景：花蔓如帘坠巨坛 / 装饰过大的祭台 / 垂下的颜色

### 巨人山脉废墟被花蔓侵蚀回廊空间
is-a 巨廊花径（上位：巨人山脉废墟被花蔓侵蚀）
巨人走廊——路中央的巨石缝隙中长出了一条花的线条——花沿着裂缝延伸、像画在地面上的一条虚线
可用于场景：裂缝中的花线 / 画在地上的虚线 / 被花标记的路

### 巨人山脉废墟被花蔓侵蚀洗礼池
is-a 巨池（上位：巨人山脉废墟被花蔓侵蚀）
巨人用的水池——一个直径四米的浅圆石盆——盆中积满了雨水——水面倒映着天空——花的影子在水面上
可用于场景：巨大的石盆水镜 / 花影落巨池 / 水的尺度对比

### 巨人山脉废墟被花蔓侵蚀祈祷室
is-a 巨人壁龛（上位：巨人山脉废墟被花蔓侵蚀）
壁龛的高度在头顶两米处——花从壁龛的边缘垂下来——人抬头看花时像是在仰望
可用于场景：仰望的花 / 在高处的花 / 需要抬头才能看到的美丽

### 巨人山脉废墟被花蔓侵蚀花窗大厅
is-a 巨窗花帘（上位：巨人山脉废墟被花蔓侵蚀）
巨人建筑的窗户——高四米宽两米——窗框早已无玻璃——花蔓从窗沿垂下来像窗帘、透过花帘看外面的山景
可用于场景：花帘巨窗 / 透过花看山 / 窗户成了相框

### 巨人山脉废墟被花蔓侵蚀地下墓穴
is-a 巨人墓室（上位：巨人山脉废墟被花蔓侵蚀）
巨人的墓穴——石棺长四米宽两米——棺盖已掀开但棺内空无一物——只有一小丛花从石棺的一角长出
可用于场景：巨棺中的小花 / 巨人不在只有花 / 空棺与花

### 巨人山脉废墟被花蔓侵蚀钟楼
is-a 巨岩花塔（上位：巨人山脉废墟被花蔓侵蚀）
巨人用作钟楼的岩柱——花蔓从柱脚爬到柱顶——塔的原始功能被花重新定义了——变成了花塔
可用于场景：花爬岩柱 / 功能被花模糊 / 花做的装饰塔

### 巨人山脉废墟被花蔓侵蚀圣像墙
is-a 巨壁花绘（上位：巨人山脉废墟被花蔓侵蚀）
巨人留在岩壁上的刻痕——刻痕是螺旋形的（可能是他们的文字）——花蔓沿着螺旋刻痕生长、勾勒出完整的螺旋形状
可用于场景：花描螺旋 / 刻痕成花路 / 被花强调的远古图案

### 巨人山脉废墟被花蔓侵蚀忏悔室
is-a 巨人角落（上位：巨人山脉废墟被花蔓侵蚀）
两根巨柱之间的夹角——形成一个三角形的角落空间——花在这个角落中长得特别厚——像有人种过
可用于场景：角落花丛 / 隐蔽的植物 / 花的聚集地

## v4 最终复合场景层（中央空间10种变体）

### 巨人山脉废墟被花蔓侵蚀中央空间复合场景
is-a 巨厅花心标准版（上位：中央空间）
巨人大厅中央——地面有一个巨大的圆形裂缝——裂缝中长出了密实的白花——花圈直径三米——像大地开了花眼
可用于场景：地面花眼 / 圆形花裂 / 标准大全景

### 巨人山脉废墟被花蔓侵蚀中央空间镜面版
is-a 巨厅花心倒影版（上位：中央空间）
破碎的地面积水——倒映的穹顶和花的轮廓——因穹顶破碎倒影中的天空像一面不规则的拼图
可用于场景：破碎水面 / 天空拼图在脚下 / 不规则倒影

### 巨人山脉废墟被花蔓侵蚀中央空间沉水版
is-a 巨厅花心水漫版（上位：中央空间）
融雪水淹没巨厅地面至脚踝——花从水下探出头来——水面以下的根部清晰可见——花像漂在水面上的岛屿
可用于场景：水下花根 / 花浮水面 / 雪水淹没

### 巨人山脉废墟被花蔓侵蚀中央空间月光版
is-a 巨厅花心月夜版（上位：中央空间）
月光从破损的穹顶射入——光柱在黑暗的巨厅中形成圆锥形的可见通路——花在光柱边缘、一半被照亮一半在暗处
可用于场景：光柱中的花 / 半明半暗 / 月光锥

### 巨人山脉废墟被花蔓侵蚀中央空间黑水版
is-a 巨厅花心融雪版（上位：中央空间）
融雪水夹带着泥沙变成了灰黑色的水——花漂浮在灰水上——花被污染但依然白——对比强烈
可用于场景：灰水白花 / 污浊与纯洁共存

### 巨人山脉废墟被花蔓侵蚀中央空间环形祭坛版
is-a 巨厅花心祭坛版（上位：中央空间）
有人在花圈周围摆了一圈小石子——与巨人尺度相比这些小石子是人类的手笔——人类在这个巨人之地留下了自己的印记
可用于场景：小人小石 / 人类在巨人之地的痕迹 / 微小的仪式

### 巨人山脉废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 巨厅花心泉涌版（上位：中央空间）
中央裂缝中涌出了山泉水——清澈的泉水从花丛根部涌出——花在泉水的动态中轻轻摇曳
可用于场景：泉涌花摇 / 活水中的花 / 花与水共舞

### 巨人山脉废墟被花蔓侵蚀中央空间白花漂浮版
