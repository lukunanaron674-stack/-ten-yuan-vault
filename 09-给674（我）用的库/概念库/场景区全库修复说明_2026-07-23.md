# 概念库场景区全库修复

## 问题确认

`09-给674（我）用的库/概念库/` 下的多份 `*_is-a名词素材库.canvas`，其“场景”区域错误复用了建筑全链的 v2 状态侵蚀、v3 内部功能、v4 复合场景模板。

这些节点描述的是单一建筑母体的演化链，不是所属世界观可直接检索、绘制和配图的场景名词，因此整区需要重写。

## 修复边界

- 保留服装、建筑、构件、元素区域。
- 保留 Canvas 中既有 file 节点、参考图节点和有效连线。
- 重写每份 Canvas 的场景分类标题、场景叶子概念、is-a 描述和镜头用途。
- 场景概念必须属于该世界观，能独立形成画面，并与服装、建筑、构件、元素互相调用。
- 不再使用统一的“花蔓侵蚀 / 荆棘缠绕 / 中央空间 / 镜面版”等占位模板。
- 修改后保持 JSON Canvas 合法，节点位置尽量原位复用。

## 执行顺序

按 `*_is-a名词素材库.canvas` 文件路径字典序逐份校正，并记录每份文件的旧场景节点、新场景节点、提交 SHA 与远端读回。
