### 作者255《高人指點》｜行175–275
- **宵禁信号**：全城长鸣钟敲满三十六声，行人称「三十六聲長鳴鍾，今夜開始宵禁，禁酒」「固原已經六年沒有宵禁過了」，整条街行人驻足等待钟停 → 记为**已宣布且全城响应的管制信号**；不推为常设制度，也未证执行罚则。
- **领粥规则执行**：排队老大爷转述「軍爺們說了，領粥要自己帶碗的，不帶碗不給粥」 → 与 254 已证「边军实际施粥」衔接，补一条现场配给规则；仍是人物转述，不推为正式章程。
- **杨记皮货**：陈迹回忆小五曾说「羅什坊多渾街楊記皮貨的掌櫃…都是景朝諜探」（既有转述）；本正文直接写出老吴在柜台前与掌柜低声交谈、似在争执，掌柜随即从柜台下抽短刀跃出刺向陈迹 → **现场实证该铺掌柜与老吴有接触且具备武装敌对行为**；「景朝谍探」身份仍属转述，不登记为已证组织隶属。
- **老吴否认（重大矛盾，登记不裁决）**：陈迹问「你們是爲了給靖王報仇才做這些事」，老吴答「爲靖王報仇？我都沒見過靖王」；陈迹问「你爲何要毒殺陳家三十四口」，老吴答「我沒有！…我去驿站交代驿卒，給你準備紅螺炭啊！」 → 与 227／228 章「陈府随行仆役与驿卒遇害」及 227 小吏「周将军从都司府调拨炭、点名只给陈迹用」形成**跨章呼应兼反转**。本轮只登记人物否认与自述动机，**不推翻既有章结论、不确认真凶**。
- **现象（不推组织）**：老吴背后凭空白焰焚身、陈迹割开衣服见朱砂黄纸符咒烧剩边角、最终「連骨頭都燒成灰燼」；老吴称「那人說了，這火熄不了」 → 「那人」身份、符咒来源、加害组织全未证。
- 排除：老吴自述粮政「一石糧食從豫州、江南收歸朝廷時就隻剩九成…官商勾結…換成積年的穀子」、「邊軍有高人指點，将這邊陲軍鎮經營成商賈往來之地」、「靖王也回天乏術」、「邊軍不是晉黨的人嗎」等均为**人物自述与议论**，是重要的社会结构线索候选，但不登记为已证制度事实；陈迹「你們勾連景朝圍困固原城」是提问，不是事实。

### 作者256《黃面窩頭》｜行90–177
- **黄纸符咒使用范围（陈迹推断）**：「使用黃紙符咒的行官不止白龍一人，夢雞用，道庭也用，從道庭分支、流散出來的行官門徑，都要用到黃紙符咒」；「冥冥之中便覺得…一定是白龍」 → 人物推断，符咒主人未证。
- **密谍司存在与撤离说法**：陈迹回想驿卒曾说「密諜司的人因為這裡太艱苦，所以撤走了」，并质疑「一個魚龍混雜的諜探之城，怎麽可能少了密諜司」 → 既有机构的存在性与「撤离」说法（转述）+ 主角质疑，**不新增组织、不改既有隶属**。又及「當初司禮監為了讓劉家放下戒備心，故意由著皎兔、雲羊被流放」为陈迹回忆。
- **现场处置**：老头领一队边军甲士到胡同，只见一地灰烬；甲士捻土判「是骨灰」 → 边军到场查验的实证。
- **元草堂（商户，非新组织）**：人参经掮客商贾运至元草堂供挑选；胡三爷与掌柜议价，称「固原已被天策軍圍困，破城就在近日」「如今糧倉被燒，家家缺糧」；掌柜称「我這元草堂是怎麽來的您也清楚，即便景朝殺進來，我也有熟人可以說情」「你元草堂養著上百號人，一家老小三十余口都得吃飯」 → 铺号、人员规模、关系网自述；「有熟人可说情」是掌柜自夸，不新增组织也不证保护关系。价格（野山参八两一斤、五十年老参十两一支）为议价内容。
- **龙门客栈规矩再证**：掌柜对求离城的中年人说「我龍門客棧送人離開的規矩，你們都知道吧？」 → 补强 237／241–243 已记的规则化离城服务，不新增节点。
- 排除：陈迹推断「胡三爺要這麽多人參做什麽」、天策军围城说法均为人物陈述。

### 作者257《奪嫡》｜行90–166
- **粮食分配冲突**：王贵称「好不容易買來點糧食，嫡公子都不一定能吃飽，哪輪得著他？」；齐斟酌与一名羽林军着常服，拎轻飘布袋，直接从王贵处拿窝头，称「大家現在同舟共濟，有糧食就拿出來大家一起吃」，并说「各家糧鋪被邊軍搜得乾乾淨淨，隻能從百姓家的邊邊角角搜羅一些糧食來，還得花天價買」 → 与 251–254 征粮／粮铺被搜／买粮无粮形成连续现场证据。
- **配给与军纪担忧（人物判断）**：陈礼钦称「若再買不到糧食，羽林軍今晚就要餓肚子」「羽林軍是有軍紀，可人到餓急眼的時候…我就怕他們去搶百姓的糧食，被邊軍抓了軍法處置」「羽林軍是殿下帶出來的…太子之位能不能保住都成問題」 → 担忧与因果推测，非已证抢粮事件。
- **夺嫡背景（人物陈述）**：「胡鈞羨乃是福王的舅舅」；陈礼钦怀疑「都司府、糧倉、軍械庫向來守備森嚴，景朝賊子如何縱火？必然是邊軍監守自盜！…我甚至懷疑一切都是邊軍捏造出來的，隻為了讓羽林軍犯錯，為了奪嫡！」 → **推测，登记为动机候选，不作事实**。
- 数量口径待核：「五百羽林軍都找不來糧食」（陈问孝语）；260 章记「四百余人出門」、262 章记「四十斤糧食分到五百人碗裡」 → 三处口径不一，登记待核，不取单一数字入树。
- 张夏跟踪至桃槐坊「一戶姓李的員外家」 → 观察，与 261 章陈迹报「桃槐坊、渠黎街、李員外家」呼应。

### 作者258《鍾粹宮，景陽宮》｜行90–167
- **指令关系实证**：白龙对陈迹「本座先前隻叮囑你潛伏在陳家，可沒交代你接近太子」「盯好太子，他見了什麽人、去了哪裡，都要每日稟告本座」「辦完固原的事情，全都送回無念山再練幾年」 → **明确的上下级汇报指令**；「无念山」为训练场所的人物陈述，登记为候选场所，不新增独立组织。

### 作者259《假戲真做》｜行90–152
- **粮食去向关键实证**：白龙答「昨夜燒了一大半，剩下的都在邊軍的中軍大營裡藏著」 → 直接补上 250《大火》／251《征粮》之后「余粮在哪里」的缺口；本条为白龙自述，但属当事方对自身安排的说明，登记为**高可信陈述**，仍不冒充全城粮账。
- **机构关联实证**：白龙「問問她願不願入我密諜司」「文官容不得她參加科舉，在我司禮監卻能青雲直上，本座保她在十二生肖有一席之地」 → **白龙自述属司礼监、十二生肖为其可安置的序列、密谍司为其可招人的机构**；三者关系由本人陈述，不擅自画成行政隶属边。钦天监副监正徐术（既有官署职位）、「行官門徑」为既有类别。
- **部分确认的做局（不扩推）**：陈迹推断「以靖王之死做局，令邊軍之中有嘩變舊案的周遊，用『為靖王報仇』的名義假意降景，引景朝天策軍前來送死」，白龙「倒是猜對了幾分」；「汙井水、燒糧倉，便是投名狀」为陈迹推断 → 只记「部分被认可」，不把全部细节升为事实。
- 白龙「莫再查景朝諜探了，本座留著他們還有用處」 → 对景朝谍探的处置意图实证。
- **现场**：百姓聚街「去找邊軍要回自家糧食」；羽林军三人提鼓囊布袋；边军连片营帐起火、甲士拎木桶救火 → 群体行动与火灾现场，火灾原因未证（陈迹疑「邊軍之中有人想假戲真做」属推测）。

### 作者260《尋糧》｜行90–180
- **粉尘爆炸**：边军大营轰鸣、火焰吞没营帐，陈迹判「這是粉塵爆炸的模樣，邊軍大營裡的麵粉炸開了」「燒得確實是邊軍存糧！」 → 现场现象 + 主角判断；与 259「余粮藏中军大营」呼应。「邊軍征走我們的糧，又被景朝細作燒了」是民众归因，不作事实。
- **羽林军寻粮组织化执行与量化结果（本批最硬的制度实证）**：客栈正堂李玄「面前擺著一本帳簿，提筆問面前的羽林軍：『你今日買到多少糧食？』」，将士逐一上前禀报；「今天四百余人出門，竟隻買回來十二斤小米，二十八斤黃面」 → **有帐簿、有逐人禀报、有汇总数字的配给执行流程**。
- **命令**：李玄「現在都給我出去繼續尋糧食，尋不到今夜便不睡覺了，不管你們用什麽手段，若是空著手，就不用回來了！」 → 已下达的强制命令。陈礼钦「尋糧也要注意手段…連累殿下也一並被史官記上一筆」为约束性劝告，非已证约束制度。
- 排除：齐斟酌「若能活著回京城，定要讓祖父參那胡鈞羨一本」为气话；两方争执（羽林军军纪／陈家藏粮）为冲突，不新增组织。
