# ② 题材/世界观风格

## 核心公式

xz（边缘/不可能）+ zn（意义体系）——每一个题材都定义了一个不同的世界规则

## 问法

这个环境属于哪个世界？

## 子节点

| 节点 | 十元 | 一句话 | 接入 |
|:----|:----:|:-------|:----:|
| [[现实环境.canvas\|🗺️ 现实环境]] | n+xn | 我们熟悉的日常世界 | |
| [[历史环境.canvas\|🏺 历史环境]] | xn+zx | 过去世界的规则与执行 | |
| **🧙 奇幻环境** | xz+zn | 不可能的体系 | → [[奇幻子类型谱系.canvas]]（20子类型） |
| [[科幻环境.canvas\|🚀 科幻环境]] | xn+x | 规则被技术重新定义的世界 | |
| [[后末日环境.canvas\|☢️ 后末日环境]] | xn→x | 规则崩塌后的欲望世界 | |
| [[超现实环境.canvas\|🧠 超现实环境]] | nx+xz | 规则不存在的精神空间 | |
| [[恐怖怪谈环境.canvas\|👻 恐怖/怪谈]] | xz+x | 边缘被恐惧吞噬的世界 | |

## 奇幻环境接入说明

奇幻环境（xz+zn）已有完整的20子类型谱系，放置于：

```text
画画理论/🧙 奇幻环境设计 xz+zn 不可能的体系/
```

每个子类型都有 canvas + md 成对卡。本轴直接引用 [[奇幻子类型谱系.canvas]] 作为奇幻环境的展开入口。

## 封存句

题材不是「这个世界有什么」，是「这个世界用的是什么规则」。
