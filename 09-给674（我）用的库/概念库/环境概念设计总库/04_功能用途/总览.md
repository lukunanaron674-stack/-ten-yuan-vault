# ④ 功能/场景用途

## 核心公式

zx（目标）+ zn（意义）——空间的用途决定了它承载什么样的行为和情感

## 问法

这个环境用来干什么？

## 子节点

| 节点 | 十元 | 一句话 |
|:----|:----:|:-------|
| [[祭坛仪式.canvas\|🕯️ 祭坛/仪式]] | zn+zx | 执行意义的场所 |
| [[居住空间.canvas\|🔸 居住空间]] | n | 睡觉/吃饭/活着——最基本的容器 |
| [[战斗场.canvas\|🔸 战斗场]] | xz+zx | 冲突发生的空间 |
| [[交易场.canvas\|🔸 交易场]] | nx+x | 利益交换的地方 |
| [[逃亡路径.canvas\|🔸 逃亡路径]] | xz+zx | 离开的通道 |
| [[角色登场.canvas\|🔸 角色登场]] | z+x并z | 被看见的第一眼 |
| [[Boss房地标.canvas\|🔸 Boss房/地标]] | zx+zn | 叙事的终点节点 |
| [[隐藏空间.canvas\|🔸 隐藏空间]] | x并z+n | 需要被发现才知道存在的空间 |
| [[秘境圣所.canvas\|🕯️ 秘境/圣所]] | zn+n | 被意义包裹的封闭空间 |

## 封存句

功能不是「这个空间有什么用」，是「角色在这个空间里要做什么」。
