# ⑤ 氛围/情绪场

## 核心公式

十元组合——氛围不是环境自带的，是「空间xn + 十元组合」在观者心中产生的情绪

## 问法

这个环境让人感觉到什么？

## 子节点

| 节点 | 十元组合 | 一句话 |
|:----|:--------:|:-------|
| [[神圣.canvas\|🔸 神圣]] | zn+n | 意义被容器包裹，空间有超越感 |
| [[湿冷.canvas\|🔸 湿冷]] | xz+n | 边缘+容器，身体感受到的不适 |
| [[危险.canvas\|🔸 危险]] | x+xz | 欲望+边缘，威胁正在逼近 |
| [[孤独.canvas\|🔸 孤独]] | nz+xz | 等待+边缘，只有自己 |
| [[荒凉.canvas\|🔸 荒凉]] | xz+n | 边缘+容器，世界空了 |
| [[诡异.canvas\|🔸 诡异]] | x并z+xz | 表面不对+边缘，哪里不对但说不出来 |
| [[宁静.canvas\|🔸 宁静]] | n+nz | 容器+等待，时间变慢 |
| [[压迫.canvas\|🔸 压迫]] | xn+x | 规则+欲望，喘不过气 |
| [[命定.canvas\|🔸 命定]] | nz+zn | 等待+意义，这件事注定了 |
| [[温柔停靠.canvas\|🔸 温柔停靠]] | nz+n | 等待+容器，可以休息了 |

## 规则

- 氛围不能凭空产生——必须来自前四个轴的选择组合
- 同一空间可以叠加多种氛围（主氛围+副氛围）
- 氛围是最直接的观众感受，也是最容易被忽略的设计维度

## 封存句

氛围不是「这个空间有什么感觉」，是「前四个轴的选择合在一起，让观众感觉到了什么」。
