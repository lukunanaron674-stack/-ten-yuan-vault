# 三元物象教学法总文档 v1.4

## 0. 总定位

这是一套用来学习任何新知识的教学法。它不是普通分类器，而是一套让知识从抽象变成可视、可动、可推演、可归档的教学操作系统。

核心目标：

```text
把陌生知识拆成三元骨架，细化成十元质地，判断体量与顺序，再用位置盘校验生克补关系，组合成关系对子，跑出动态链，最后归入五大主题。
```

总公式：

```text
三元定粗骨架
十元细化定真实质地
体量判断定在场密度
顺序感谱定第一反应
位置盘定生克补
关系五对定基础边型
关系对子定小链组合
动态链定运行结果
五大主题定最终归仓
```

封存句：

> 先拆三元，再细十元；先判体量，再查关系；最后跑链归仓。

## 1. 三元粗拆

三元负责让知识先站起来。

| 三元 | 教学含义 | 提问 |
|---|---|---|
| x | 压力 / 问题 / 扰动 / 欲望源 | 它面对什么问题？是什么让系统不安？ |
| n | 承载 / 结构 / 系统 / 容器 | 它靠什么维持、组织、承接？ |
| z | 显现 / 反应 / 输出 / 结果 | 它最后表现成什么行动、结果、现象？ |

三元输出模板：

```text
x = 它面对的压力、扰动、危险或欲望
n = 它依靠的承载、结构、规则或系统
z = 它显现出的行动、输出、爆点或结果
```

注意：三元是粗骨架，不是最终判断。三元之后必须进入十元细化。

---

## 2. 物象映射

物象映射负责把抽象概念变成能看见、能运动、能记住的图像。

标准要求：

```text
物象必须能对应 x / n / z。
物象必须能运动。
物象必须能解释动态变化。
物象不能只漂亮，必须能跑链。
```

物象模板：

```text
这个概念像：________

x 像：________，它制造压力。
n 像：________，它负责承载。
z 像：________，它显现结果。

动态画面：
________ 进入 ________，经过 ________，最后变成 ________。
```

例：学习 AI。

```text
AI 像一座会学习的磨坊。

x = 混乱谷物，代表大量任务与信息压力
n = 齿轮、水车、筛网，代表模型、数据、参数和推理结构
z = 磨出的面粉，代表回答、图像、代码和预测结果
```

## 3. 十元细化

十元细化负责让 x / n / z 长出真实质地。不要只写“这是 x”，而要继续问：它是哪一种 x？哪一种 n？哪一种 z？

### 3.1 十元总表

| 十元 | 基础语义 | 常见教学感 |
|---|---|---|
| zx | 突破 / 开局 / 先动 | 我先打出去 |
| x并z | 表象 / 包装 / 媒介化 | 被包装、被观看、被表演 |
| zn | 意义 / 精神 / 本体价值 | 为什么要做，凭什么坚持 |
| z | 显现 / 爆点 / 执念 | 我忍不住了，我要被看见 |
| n | 稳定 / 承载 / 中心结构 | 我在，我能接住 |
| nz | 停靠 / 依恋 / 柔性归宿 | 不想结束，想靠近 |
| xn | 规则 / 路线 / 制度 / 节拍 | 结果说了算，流程说了算 |
| nx | 暗流 / 判断 / 结算 / 计算 | 刀在最后，账在暗处 |
| xz | 危险 / 临界 / 漂流 / 风险 | 来不及，必须反应 |
| x | 欲望 / 深层压力 / 吞没 | 被拖进去，想占有 |

### 3.2 标准输出格式

```text
【十元细化】

x 更像：
- 主十元：
- 副十元：
- 说明：
所以这里的 x 不是单纯____，而是____。

n 更像：
- 主十元：
- 副十元：
- 说明：
所以这里的 n 不是单纯____，而是____。

z 更像：
- 主十元：
- 副十元：
- 说明：
所以这里的 z 不是单纯____，而是____。
```

### 3.3 《毛选》示例

三元粗拆：

```text
x = 革命面对的围剿、战争、敌我矛盾和生存压力
n = 路线、纪律、组织、根据地、群众基础和方法论
z = 破局行动、组织动员、战略胜利和意义生成
```

十元细化：

```text
x 更像：xz + nx
xz = 被追击、被围剿、战争压力、危险局势
nx = 暗线判断、利益结构、敌我分析、阶级分析、局势计算

所以它的 x 不是单纯欲望，而是：危险局势里的判断压力。
```

```text
n 更像：xn + n + nz
xn = 路线、纪律、组织原则、方法论
n = 根据地、组织、群众基础、承载结构
nz = 群众连接、依附、信任、情感动员

所以它的 n 不是单纯容器，而是：纪律化组织 + 根据地承载 + 群众信任网络。
```

```text
z 更像：zx + zn
zx = 破局行动，打出去，发动起来
zn = 意义动员，为什么要做，凭什么坚持

所以它的 z 不是单纯结果，而是：行动破局 + 意义动员。
```

## 4. 体量判断

体量不是力量，不是战斗力，不是能力强弱。体量是：在不在场、强不强、占不占空间、影响范围有多大、是否持续改写后续判断。

| 体量 | 含义 |
|---:|---|
| 1-2 | 微弱概念，只是局部现象 |
| 3-4 | 可识别，但影响有限 |
| 5 | 标准概念，能解释一类问题 |
| 6-7 | 强概念，能组织一套分析 |
| 8 | 系统级概念，能改写多个领域 |
| 9 | 时代级行动系统，持续高密度在场 |
| 10 | 世界观级 / 文明级结构，几乎能重写整套秩序 |

体量判断五问：

```text
1. 它影响的是局部、系统，还是时代？
2. 它只是一个观点，还是一套行动系统？
3. 它能不能组织大量对象？
4. 它有没有持续在场能力？
5. 它是否能改写后续判断和行动？
```

《毛选》体量示例：

```text
体量：9

原因：它不是一篇文章的观点，而是一个时代级行动系统。
它不是力量大，而是在场密度极高。
它能同时组织战争判断、阶级分析、群众动员、路线纪律、组织建设、战略行动和意义生产。
```

封存句：

> 《毛选》的体量不是“观点很强”，而是“它像一套时代级行动操作系统，持续占据判断、组织、动员和行动的位置”。

## 5. 顺序感谱

顺序感谱回答：第一反应先发生什么？它不等于善恶，不等于本体，不等于力量。

| 顺序 | 含义 | 典型十元 |
|---|---|---|
| 123 | 先安顿，再行动，再推进 | n |
| 慢123 | 缓慢抵达，不想结束 | nz |
| 132 | 先看我，再跟我 | zn |
| 213 | 先反应，再评估，后定价 | xn / nx / x并z |
| 231 | 先忍耐，再爆发，再结算 | z / xz |
| 312 | 先动手，再思考，再改写 | zx |
| 321 | 被拖进去 | x |

教学问法：

```text
这个概念第一反应是什么？
先判断？先行动？先承载？先爆发？先被拖入？还是慢慢抵达？
```

## 6. 位置关系：生克补必须查表

这是最新版最重要修正。

```text
内容显影 ≠ 标准位置关系
```

不能因为内容里有“压住”“生出”“补上”，就直接写成克、生、补。必须先查位置盘。

### 6.1 四层规则

```text
十元 = 点
关系五对 = 基础位置边型
关系对子 = 多个关系五对的组合方式
动态链条 = 关系对子落到具体十元后跑出的力流结构
```

### 6.2 关系五对

```text
1. 生：A 生 B
2. 被生 / 承生：A 被 B 生
3. 克：A 克 B
4. 被克 / 受克：A 被 B 克
5. 补：A 补 B
```

简义：

```text
生 = 推出 / 生成 / 显影
被生 = 被推出 / 承生
克 = 压制 / 限制 / 截断 / 迫使转向
被克 = 被压制 / 被限制 / 受克
补 = 补厚 / 补全 / 结构加厚
```

## 7. 标准位置盘

### 7.1 生盘

```text
生环 1：
xz → zx → zn → n → xn → xz

展开：
xz 生 zx
zx 生 zn
zn 生 n
n 生 xn
xn 生 xz
```

```text
生环 2：
nz → nx → x → x并z → z → nz

展开：
nz 生 nx
nx 生 x
x 生 x并z
x并z 生 z
z 生 nz
```

关键防错：

```text
z 生 nz ✅
nz 生 z ❌
zx 生 zn ✅
```

### 7.2 克盘

```text
克环 1：
xz → zn → xn → zx → n → xz

展开：
xz 克 zn
zn 克 xn
xn 克 zx
zx 克 n
n 克 xz
```

```text
克环 2：
nz → x → z → nx → x并z → nz

展开：
nz 克 x
x 克 z
z 克 nx
nx 克 x并z
x并z 克 nz
```

关键防错：

```text
x并z 克 nz ✅
xz 克 nz ❌
n 克 x ❌
xn 克 zx ✅
zn 克 xn ✅
```

### 7.3 补盘

当前可用补对：

```text
xz ↔ nz
zx ↔ nx
zn ↔ x
n ↔ x并z
```

展开：

```text
xz 补 nz / nz 补 xz
zx 补 nx / nx 补 zx
zn 补 x / x 补 zn
n 补 x并z / x并z 补 n
```

待校准补对：

```text
xn ↔ z
```

处理规则：

```text
xn 补 z / z 补 xn 暂用待校准。
未再次确认前，不进入强动态链。
```

## 9. 关系对子

关系对子不是单条边，而是多个关系五对组合成的小链。

```text
关系五对 = 生 / 被生 / 克 / 被克 / 补
关系对子 = 多个关系五对的组合方式
动态链条 = 关系对子落到具体十元后跑出的力流结构
```

例：

```text
克 + 克 + 生 = 关系对子

zn 克 xn
→ xn 克 zx
→ zx 生 zn
= 动态链条
```

可用组合：

```text
生 + 生
生 + 克
克 + 生
克 + 克 + 生
生 + 补 + 被克
克 + 补
补 + 被克
生 + 克 + 补
```

## 10. 动态链

动态链负责回答：点和边跑起来之后，力流如何变化？

标准格式：

```text
起手十元 → 第一被作用十元 → 生成十元 → 承载位 → 冲突位 → 结算位 → 最终落点
```

注意：承载位是功能位，不一定等于 n。必须判断实际十元。

动态链输出模板：

```text
【动态链】
起手：
第一被作用：
标准关系：
生成：
承载位：
冲突位：
结算位：
最终落点：
链条类型：回收 / 崩坏 / 扭曲 / 循环 / 停滞 / 反噬 / 换芯 / 断链
```

动态母型：

| 母型 | 链条感觉 | 判断 |
|---|---|---|
| 回收型 | 力量能回到承载，意义再生 | 稳定成长 |
| 崩坏型 | x 超过承载上限，结构断裂 | 承载破裂 |
| 扭曲型 | 旧意义被改写，新意义稳定 | 变质稳定 |
| 灰区型 | 关系不闭合，结果未定 | 需要二审 |

## 11. 五大主题归仓

五大主题不是起手，不是前置分类。它是动态链跑完之后的高阶归仓。

| 五大主题 | 公式 | 核心问题 |
|---|---|---|
| 时间 | xn + z | 规则、节奏、倒计时、爆点如何组织？ |
| 本体 | zn + x | 这个存在真正被什么驱动？ |
| 空间 | x并z + n | 它靠什么场域、容器、空间来成立？ |
| 因果 | zx + nx | 谁先动手？暗线如何结算？ |
| 命运 | xz + nz | 为什么相遇、漂流、停靠、分离？ |

归仓规则：

```text
五大主题只能做最终结算。
不能用五大主题倒推十元起手。
不能因为作品像时间，就默认起手是 xn。
不能因为作品像本体，就默认起手是 zn。
```

## 12. 标准教学输出模板

```text
请用《三元 × 物象 × 十元 × 体量 × 关系五对 × 动态链教学法 v1.4》教我【概念】。

0. 一句话定义
先说这个概念是什么。

1. 层级判断
判断它主要属于：本体 / 结构 / 行为 / 结果 / 应用 哪一层。

2. 三元粗拆
x = 它面对什么压力、问题、扰动？
n = 它靠什么承载、组织、稳定？
z = 它显现成什么结果、行动、输出？

3. 物象映射
用一个能看见、能运动的物象解释这个概念，并分别对应 x / n / z。

4. 十元细化
分别回答：x 更像什么十元？n 更像什么十元？z 更像什么十元？
允许复合，但必须说明主次和理由。

5. 体量判断
给出 1-10 体量，并说明它不是力量，而是在场密度、影响范围、组织能力、持续程度和改写能力。

6. 顺序感谱
判断它第一反应是什么：先安顿、先判断、先行动、先爆发、先被拖入，还是慢慢抵达？

7. 位置关系查表
不要按内容感觉直接写生克补。
必须查标准位置盘：A 生谁？A 克谁？A 补谁？A 被谁生？A 被谁克？

8. 关系五对
输出标准边：生 / 被生 / 克 / 被克 / 补。

9. 关系对子
把多个关系五对组合成：生+生 / 生+克 / 克+克+生 / 生+补+被克 等。

10. 动态链
写出：起手十元 → 第一被作用十元 → 生成十元 → 承载位 → 冲突位 → 结算位 → 最终落点。

11. 五大主题归仓
判断最终落入：时间 / 本体 / 空间 / 因果 / 命运。

12. 误判检查
检查：五维有没有回填起手？承载位有没有默认写成 n？体量有没有误写成力量？内容动词有没有冒充位置关系？视觉/情绪有没有污染本体？

13. 现实例子
用一个具体例子跑完整流程。

14. 反推练习
给我一个小练习，让我自己拆。

15. 封存句
最后压成一句能记住的话。
```

## 13. 误判检查表

| 误判 | 错在哪里 | 正确做法 |
|---|---|---|
| 把内容里的“压住”直接写成克 | 内容显影冒充位置关系 | 先查克盘 |
| 写 xz 克 nz | 标准盘不支持 | xz 补 nz，x并z 克 nz |
| 写 n 补 nz | 标准盘不支持 | n 补 x并z，nz 补 xz |
| 把五大主题当起手 | 层级错乱 | 五大主题只能归仓 |
| 把体量当力量 | 概念偷换 | 体量是在场密度 |
| 把承载位默认写成 n | 功能位冒充十元 | 承载位需另判实际十元 |
| 视觉强就判本体强 | 视觉污染本体 | 先分层再映射 |
| 默认 zn 起手 | 旧误区 | 必须找第一推动力证据 |

## 14. 超短口令版

```text
教我【概念】：
先一句话定义，再三元粗拆；
用物象映射解释 x/n/z；
然后细化 x/n/z 分别更像哪些十元；
给体量 1-10，并说明不是力量而是在场密度；
判断顺序感谱；
再查位置盘生成生克补关系五对；
组合关系对子，跑动态链；
最后归入五大主题，并给误判检查、例子、练习和封存句。
```

## 15. 最终封存句

> 三元让知识立骨架，物象让知识能被看见，十元细化让它长出真实质地，体量判断让它有重量和占位，位置关系让点开始咬合，动态链让它跑起来，五大主题把它归进大矿仓。
