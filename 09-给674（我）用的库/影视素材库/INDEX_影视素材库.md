# 影视感受素材库｜INDEX

**定位**：用户主动挑选的影视/动画作品；目标不是普通影评，而是用「作品事实 → 感受提取 → 十元候选与对象分层 → 镜头/光影/声音/故事构成 → 动态关系 → 可复用创作实验」采集可用的感受构成经验。

## 基本规则

1. 一部作品一张卡；记录年份、导演、原片链接、媒介、核心感受、动态链、可控视听变量、证据等级和待审核项。
2. 严格区分**已见实证**、**来源二手描述**、**创作解释候选**、**迁移实验方案**，不能把后两者宣称为原片事实。
3. 主十元与次十元是本次分析的假设，不是强制套标签；五轴与生克补必须核对最新正本。对同一作品的世界、角色、关系分别建对象层。
4. 体量与主观感受强度不能代替艺术性评分；未实际逐镜观影，不填虚构时间码，不把拟议镜头写成已出现的镜头。
5. 素材库与音乐库并列；研究后可把高质量构成零件**候选**提送十元血肉/动态链研究正本，未经验证不覆盖。
6. 保留来源链接作为创作研究引用；不擅自将原作者画面、模型或音频直接投入H3生成。

## 入库回访的问题

- 哪一处让人**最害怕**？请指认具体时间、景别与声画因素。
- 哪一处让人**最愿意靠近/同情**？是什么具体行为触发改变？
- 同一时刻两种感受是否**仍同时成立**，还是恐怖被温情替换？
- 仅改变镜头、光影、动作或声音中的一个变量，感受强度能否稳定上升？
