# FILM-001｜《战壕犬》：恐惧的形体里保留温柔的关系

> **一句话构成：** 以不正常的身体制造“靠近会害怕”，再以正常而具体的照顾行为制造“即使害怕也想靠近”。情感没有消除怪异，怪异也没有抹除关系。
>

## 1. 核心采矿结论

这里的主要感受构成不是“先恐怖后温馨”的简单替换，而是**同一形体里保留两个观看入口**：
1. **形态入口**：融合、错位、生理边界被破坏、战壕的窒息与脏污，唤起拒斥、警觉、惊惧。
2. **关系入口**：照料、安抚、依赖、习惯的改变、对伙伴的持续承认，唤起亲近与不忍。
3. **叠加入口**：情感行为并不改变角色的畸异外形，观众不得不同时持有冲突判断，由此提升记忆度与复杂感受。

**核心变量不是怪物画得多恶心，而是观众从哪一个可观察行为开始改变对这副身体的判断。**

## 2. 十元候选定位：主客体分开

**对象一｜世界/制度：**
- 长期消耗、复活机制、持续作战，可候选高XN或高Z的外部系统；不能只凭“军队”两个字把制度关系锁定，须确认运作规则与授权。
- 重组后的身体成为制度处理结果；但“形态异常”本身不自动等于X并Z——是否形成可被他人识别、命名、归档的公共身份接口，需要证据。

**对象二｜Charlie/Cathy关系：**
- **XZ候选主感受：** 死亡、无法按原样复原、身体与选择路径的不可逆损害带来的临界感；单纯恶心/怪异不直接等于XZ。
- **NZ候选次感受：** 身体受损后依然认定彼此是可返回、可停靠的对象；必须靠反复、具体的相处行为显影，而非“狗很可爱”的外观标签。
- **N候选：** 明确的持续照料负荷（如日常行为因Cathy而改变），不因“温馨”一词直接推定成立。
- **X并Z候选（待证）：** 个体被重组并被作为某类对象公开识别的身份界面；不能把肢体拼接本身直接当作成立证据。

**候选感受量顺序（资料初审，无数值刻度）：** XZ≈NZ为主要对位；X并Z与N为可能中介；Z/XN偏向世界系统；ZX/NX等需具体行动片段，不为凑十元而填满。

**目前不做1—10精确打分：** 未逐镜播放、缺用户感受评定；量尺不可伪装成已测量。

## 4. 血肉拆解

| 层级 | 提取对象 | 可供未来创作直接使用的构成零件 |
|---|---|---|
| 人物血肉 | 吓人的身体与温柔人格不同步 | 不要用“善良=漂亮”或“恐怖=邪恶”的外貌捷径 |
| 行为血肉 | 小动作、照料行为与习惯变化 | 用具体的代价和照顾，而不是独白，令关系可信 |
| 空间血肉 | 狭窄战壕、残破军装、持续危险 | 让环境不能接纳完整身体，使依恋成为局部安全岛 |
| 视觉血肉 | 生物异化、军装/泥土/肉体边界相互渗透 | **形态对照**：外形的拒斥线索 × 动作的亲近线索 |
| 声音血肉 | 对话、角色反应及战场氛围的潜在对位 | 声场设计需要原片核查；尚不能断言具体配乐、声音静默和剪辑点 |
| 叙事血肉 | 观众对同一人物的初判被关系信息修正 | “先看见结果，再理解他为何仍有人性”这一信息释放策略 |
| 关系血肉 | 不因身体融合就自动失去主体—伙伴关系 | 由日常承担证明NZ/N；身体接合与情感依赖不是同一概念 |

## 6. 动态构成：应区分故事因果、叙事揭示和观众感受

**故事因果（公开资料支持的粗线，非播放顺序）：**
```text
长期战壕环境 / 复活机制（外部结构）
        │
     炮击伤害
        ↓
 Charlie 与 Cathy 被错误合成一体
        │
    肉体无法原样复原
        │
    伙伴关系仍持续
        └── 生活行为因互相关照而改变
```

**候选观众感受层（待 USER 看片修订）：**
```text
外观 → 惊惧/拒斥（XZ候选）
                    │
      发现习惯与具体照顾行为
                    ↓
               NZ/N增长
                    │
   XZ并未消失：身体依然异常
                    ↓
    恐惧与依恋在同一主体并存
```

**注意：** 箭头只表示假设的信息释放或感受变化，不表示十元正本的“生/克/补”箭头。

## 7. 固定关系“牙印”：仅作为候选

- **XZ ↔ NZ（五轴水轴，正本补位关系）**：在本片中假设存在“真正失去/错过的风险”与“明确回返的对象/归宿”彼此定义的互补。**验证必要条件：** 如果没有死亡与不可恢复的代价，关怀是否仍具有同等感受分量？如果没有Cathy作为关系对象，恐怖是否只剩外形刺激？资料目前能启发该机制，不足以标本片已证实。
- **N 克 XZ（正本关系；本片不应先宣布）**：持续照料能否实质吸收风险、使回归路径不再临界？这里Charlie/Cathy的照料可能**无法逆转畸变**，故不能因为观众“觉得暖”就写成N已克XZ。
- **X并Z + N（正本互补）**：身体/身份接口与照料结构能否相互支撑，需要证明外部识别界面如何改变支持条件。没有证据时只保留研究问题。

## 8. 误判与反例

1. “造型恶心” ≠ 必然XZ成立（需要具体的风险、退路与不可逆条件）。
2. “亲密可爱” ≠ N已成立（需要有可观察的持续接收与承担）。
3. “肉体融合” ≠ 自然证明两者有爱情、同一意识、共同身份或新的X并Z；人格改变的猜测不能当设定正本。
4. 世界观里的“无限战争”并不等于这7分钟里的每条制度机制都被演出。
5. 观众评论的评价具有主观性；可作验片线索，不能替代创作者意图和镜头原证据。
6. 视听制作中的低饱和、低照度可以强化压迫，但不能单凭颜色推出角色本体十元。

## 9. 最小构成研究方案（给H3/原创短片，非照搬原作资产）

**核心测试：同一角色、同一场景、同一造型，感受如何由一个行为改变？**
- A版：角色保留异样形体，保持中性行为；记录恐惧/排斥/同情。
- B版：其他条件不变，仅加入“为弱小伙伴改变原本动作或习惯”这一可观察行为；记录感受变化。
- C版：仅增加恐怖光影/音效，不增加照顾行为；排除“刺激量更大=关系更强”的误判。
- 控制：镜头景别、时长、角度、环境、角色模型、配乐音量应尽量一致，一轮只改一组变量。
- 指标：XZ、NZ的观众自评强度分别记录；**艺术性评价与感受量分账**，不预设跨媒介强弱排序。
- **创作迁移**：《方志敏》的监狱压力与战友/家庭依恋可以研究风险—归宿对位；《黎黎隆》可研究外形异常的角色如何靠真实行动而非解释性台词获得观众认同。只借构成原理，**不直接拿原作角色/场景资产投入H3**。
