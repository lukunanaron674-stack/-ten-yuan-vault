# R6｜实战复盘、20局小实验与上分手册

**Z：怎么区分“这场赢了”和“我的决策能力进步了”？**

## 20局建议协议（自愿、非连续任务）
G01–05：观察基线，只记录最常见可控失误。
G06–10：只练兵线与回城窗口。
G11–15：只练目标前准备和换资源。
G16–20：只练中后期胜利条件与优势兑现。
每5局复核一次，不因一场输赢颠覆规则。

## 不只看胜率
- 无收益死亡：当时可预见的风险造成阵亡，且没有可兑现收益。
- 资源决策质量：凭当时线权、人数、视野、技能，打/放/换是否合理。
- 错过线权次数：本可抢先回城/游走/布视野却无行动。
- 优势兑现：优势最终转成塔、地图区域、兵营或结束比赛的次数。
20局不保证统计显著，换位置或英雄也会混淆结论。

## 五类常见问题
K机制知识；I信息错误；T时间节奏；E执行操作；C队友配合。区分“好决策执行失败”和“坏决策碰巧打赢”。

## 固定输出
若【局面与可观察条件】，优先【动作】，因为【预期收益与风险】，除非【例外条件】。每次只保留一个下局可练的动作。

复盘记录见 [[实战复盘模板]]。

**DONE**：基于真实录像形成3–5条可执行个人规则；至少一条错误的旧规则被修订。**STOP**：用户没有比赛记录不得宣称已经上分或真实验证。

## R6｜桌面研究与可执行测量协议（2026-10-26）

### 1. 先明确本轮可以完成什么
**可以完成：** 游戏技能测量指标、20局分组练习设计、审核模板、案例评分规则与停止条件。
**不能完成：** 没有 USER 比赛录像、段位、位置/英雄数据时，不可声称20局已打、胜率上升、上分策略已经针对USER生效。

### 2. 一局三层复盘：必须避免结果论
**事实层（录屏可见）**：时间点、兵线、人数、血蓝/装备、召唤师技能、自己那时能看到的视野信息。
**判断层（当时预期）**：目标收益、对手可能反制、可替代动作，必须保留当时的不确定性。
**结果层（事后回看）**：结果是否吻合预期、哪里信息判断错、是操作还是决策错误。**先写前两层，再揭示结果**。

### 3. 5局为1小批：建议20局四批（非连续、用户不必强行刷局数）
|批次|唯一训练行为|主要可观察量|提前停止/调整条件|
|---|---|---|---|
|G01–G05 基线|仅记录一局最关键错误决策|死亡前是否有可用地图信息；回城是否亏线；是否到错资源|重播无法还原事实时标UNKNOWN|
|G06–G10 节奏|推线后只做有收益的回城/支援|每局“错误离线损失”次数、节奏获得后是否兑现|如果角色位置改动太大，不能与前5局直比|
|G11–G15 目标|目标刷新前处理兵线/视野/状态|无准备硬接目标次数、低风险交换是否出现|版本/阵容变化显著时分层观察|
|G16–G20 终结|领先时优先把优势推进成塔/兵营|团后空转、死亡送节奏、关键兵线没人接次数|如长期劣势则观测止损而非强造“优势”|

### 4. 不用一个虚假的“宏观操作分数”掩盖不同失误
**主KPI建议**
1. **避免得了的阵亡**：需要同时满足「风险当时可见或可合理推断」和「没有相称可兑现收益」，并保留时间码。仅看死亡次数会错判牺牲型辅助或分推者。
2. **关键资源决策可解释率**：每次重要开/放/换能否给出当时三条证据（人数、线权、视野/技能）和一个替代方案。记录分母，而非只选漂亮局面。
3. **时间/线权空转**：推线后没有与回城、视野、抓人或目标兑现衔接；惩罚不是“游走少”，而是“免费失去可用窗口”。
4. **目标前90秒准备**：在能提前行动的场景中，至少进行回城/兵线/视野之一；不能没机会也强记失败。
5. **中后期净兑现**：团赢后是否能推进成塔/水晶/大龙/局部控制；也记不可能兑现时及时回城的合理动作。

### 5. 反事实审核的简单格式
`某个时间码 → 现实A → 替代B → 当时可靠信息 → A/B可能收益与风险 → 结果 → 下一局规则`。

分类错误：
- **K** 不知道当前机制，例如拿2025 Atakhan做计划。
- **I** 把3个敌人失踪当成“都在远处”。
- **T** 有线权但回城错时，队友争龙时还在商店。
- **E** 决策正确但技能放空/走位错误。
- **C** 单排队友不响应，导致高配合战略不可执行；应改低配合方案，而不是一味归咎别人。
- **UNK** 录像不支持归因，不能强行定性。

### 6. 课程测验（基于假想战局）
|编号|问题|应该出现的关键决策要素|
|---|---|---|
|V1|领先中路想游走，却没推完线|对方控线可能性、下路配合、返回经济损失|
|V2|对面打野露头上路，我方想秒龙|小地图其他四人、怪物耐久、线权、时间窗|
|V3|优势局团赢后继续追残血|死亡时间、最近兵线、塔/基地能否更稳兑现|
|V4|敌方三人在龙区，我方上单可拿二塔分段|龙魂临界点、TP/视野、边线对塔的确定收益|
|V5|自己分带吸引两人，队友4v3却输|分推是否创造机会、四人决策/操作错误、自己离撤退是否够近|

**评判协议**：能点名至少2个与结论相关的现场变量、1个替代行为、1个反例条件记为“决策证据完备”；不是确认用户一定打赢。
