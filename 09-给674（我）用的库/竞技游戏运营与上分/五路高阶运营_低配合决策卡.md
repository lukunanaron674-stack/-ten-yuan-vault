# 五路高阶运营｜单排低配合决策速查

[[LOL_研究总纲|总纲]] · [[R1_胜利条件与基线|胜利条件]] · [[R2_兵线回城与节奏|兵线节奏]] · [[R3_地图信息与野区联动|地图信息]] · [[R4_目标控制与资源交换|资源交换]] · [[R5_中后期分推与终结|终结]] · [[R6_实战复盘与上分验证|复盘]]

> 这不是“每个位置固定唯一玩法”，是五个位置在单排信息不完备、沟通有限时的**可执行判断树**。角色任务、兵线节奏和视野机制按照2026赛季核对，但具体英雄强弱与装备配装不在此卡内。

## 上单 TOP｜一波兵线逼出几个人，比一换一击杀更关键
**你优先控制的是侧线压力、TP/到场成本、对方回应人数。**
- 如果你能安全一对一、队友正在争另半区目标、敌方关键抓边者刚露头在远端 → 先将侧线推进至对方必须回应的位置，确认队友能利用人数/目标窗口。
- 如果你能逼来两人，但己方四人技能/血量不足、在中路守不住开团 → 不要为了“证明我分推正确”强带；发信号、撤退、等待同步。
- 如果大目标必须5v5且你方没有TP或传送距离太远 → 提前完成兵线处理与会合；不要等目标刷新才开始清线。

**错误案例**：已赢线就一直越过河道推，关键敌人消失后仍不退，变成无收益死亡。
**一局练习**：带边前问“对面哪2人会来抓？我的退路在哪？队友因此能拿到什么？”
**量化**：有效迫使回防次数/被多人抓时是否安全退出/压力转换资源数；不是单一补刀数。

## 打野 JUNGLE｜路径是选择题，不是背诵标准路线
- 如果敌方打野确定出现在上路、己方中下两路有线权与健康状态 → 考察下半区野怪、塔或龙是否真可获得；若都不能，保持刷野和地图位置，不强行凑“对称交换”。
- 如果关键龙即将刷新，但中下都被兵线压在塔下 → 别孤身去黑暗河道争视野；先帮中路线处理并集合。
- 如果你方有前期能先到的阵容 → 用线权提前建立视野，反过来限制敌打野的安全入口；不等于看见机会就秒龙。
- 资源窗口中优先评估惩戒、队友爆发伤害、对方可抢夺位置、己方进退路线。

**错误案例**：我方三路无权且打野在对方野区反野，导致撤离必经河道被包。
**一局练习**：每次重大资源前60秒写出“谁先到、有没有先动线权、我方惩戒与打龙伤害、另一半地图有无替代”。
**量化**：无准备强开目标次数；成功兑现对面打野露头信息的次数。

## 中单 MID｜真正的中路线权=能先动且仍保有状态
- 如果你先清完一波但血蓝已空、对面野辅失踪 → 不把“我清线快”自动翻译为“我能游走”。
- 如果中单先推、我打野要打河道 → 先快速核我是否可安全走到河道、对面中单会不会丢线跟过来；能合作再移动。
- 如果边线长期无人接、我方中路压不动 → 与边线者协调路线（缺少沟通时用信号），清出两处同时压力，而非五人挤中吃一条兵线。

**错误案例**：为了支援下路没把线推进塔，失败后返回中路损失两波。
**一局练习**：记录3次“我最先清线后做了什么”，标注兑现收益或空转。
**量化**：先推后有效转线次数、错误离线导致丢失波次。

## 下路射手 ADC｜活着输出与持续发育是地图控制能力
- 如果团战前你没有关键装备、血量不好且一大波兵正到塔 → 先与队友判断是否有安全的补给/接线窗口，别抢着第一个进河道。
- 如果团胜后仅你一人有持续拆塔伤害 → 撤离与跟进优先听“能不能活着点塔/兵营”，不必跟着队友长距离追残血。
- 如果对方强开手段仍在、己方没有保护 → 优先找可退的输出角度，允许牺牲一点位置/伤害以避免终结比赛能力瞬间归零。

**错误案例**：人头优势巨大，却为野区一人追击死亡，己方男爵加成期间失去推塔核心。
**一局练习**：每次团后记录“我方可拆目标与我的站位/血量，为什么选择追人、拆塔或回城？”
**量化**：胜势中关键阵亡、团胜后参与推进/回城成功率；不要只看KDA。

## 辅助 SUPPORT｜视野必须围绕下一项行动，而不是为了分数
- 如果己方中路推线且打野有空档 → 两人联动插眼/排眼；只有你单独进敌野黑区不等于运营。
- 如果对面两名关键开团英雄失踪 → 别一个人从同一入口探草，先借兵线/技能/安全守卫/队友位置排除风险。
- 如果己方要争龙但ADC还在回城/补线 → 不是越早孤身占坑越好；等到能够由己方人数支持的视野进攻窗口。
- 2026赛季有新增视野点Faelights等机制，但**额外视野持续时间有限**，不能因此永远带线无风险。

**错误案例**：单独探视野阵亡，使己方丢失关键目标控制权。
**一局练习**：记录“这个眼确认了谁、排除了什么路线、允许我们执行哪个动作、何时过期”。
**量化**：有效改变团队路线的关键眼位、为做眼的无收益死亡；绝不只追求视野分。

## 共同的单排“低配合”规则
1. **先看队友实际动作，再选择战略**：队友没有动，不要只因自己的推导逻辑正确就单人冲阵地。
2. **不依赖高难度语音同步**：用两次可读的信号表达“下一目标”“撤退/回防”，选择容易执行的兵线/塔交换。
3. **一局只练一个点**：初次测不混英雄、不跨位置换一堆变量。
4. **失败边显式写明**：对手人数未知、关键TP/终极技能不可用、阵容没有清线能力都能直接推翻计划。
5. **输赢与决策质量分开**：成功的低概率冒险不是好决策，正确的撤退也可能输局。

## 实战练习母题（同一情景五视角）
**局面设定，仅供教学推演：** 小龙前约60秒，我方上单在远端有边线推进能力，中单有先动，打野有惩戒，ADC需回城，辅助可做眼，敌方打野位置未知。

|位置|优先动作|若条件突变则改变|
|---|---|---|
|上单|安全送线、确认回防人数及TP/会合距离|对方中野消失、队友不能兑现→提前撤|
|打野|不孤身开龙；配合中单建立入口并等ADC到|中线失权→暂停目标转安全刷野|
|中单|推完后与野辅一起进河道|血蓝状态差或敌方多人失踪→先补给|
|ADC|完成有条件的安全回城并发到场信号|来不及、队友无权→告知别硬接|
|辅助|与打野配合争目标入口视野|对面先占危险入口→绕路/暂时放弃|

**DONE-知识卡**：五个位置均有条件化原则、失败边、练习与度量；**STOP-验证**：未看到USER常玩位置及对局，不能声称这套已经个性化或提升了真实胜率。

主要机制来源：[Riot 26.1官方说明](https://www.leagueoflegends.com/en-us/news/game-updates/patch-26-1-notes/)；方法论假设仍需位置与段位层面的实战验证。
