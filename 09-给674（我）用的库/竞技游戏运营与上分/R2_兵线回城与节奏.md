# R2｜兵线 × 回城 × 节奏

**Z：推完兵线后，拿到了什么行动权？**

|选择|核心收益|反例|
|---|---|---|
|Freeze控线|让敌方暴露在较危险区域、自己安全发育|马上要争地图资源却无法先走|
|Slow push慢推|积累兵量创造越塔、回城、转线窗口|打野失踪时无保护推进过深|
|Crash完整推塔|让对手先处理兵线，腾出支援和回城时间|只推到半路，反被控线|
|Fast push速推|急需抢支援先手、回防或出装备|因缺视野抢推送掉性命|

## 实战推演
目标临近时，先问自己：我是否需要回城补给？另一条线是否该先处理？队友谁能先到？在兵线仍需处理时强行先到目标，可能是虚假的“到场快”。

【反例A】推线立即游走，下路根本没配合条件，中路亏两波。
【反例B】优势上单死守冻结兵线，导致对手先到上河道关键团。

**练习**：每场回放3次，逐条记“兵线位置→可行动时间→最终换得的资源”，不以游走次数代替收益。

**DONE**：4种方法各有条件与失败条件，2局能追踪线权实际收益。**STOP**：旧版兵线具体数值需先复核。

## R2｜桌面研究实跑（2026-10-26）

### 1. 重新定义“兵线管理”= 一种制造对手必须行动的工具
不是“兵多就推、兵少就控”；高级运营首先判断：**这条兵线到达对方塔下的时间，能否与自己下一项行动同步？**

|手段|对方被迫付出的成本|自己获得的窗口|失败边界|
|---|---|---|---|
|冻结控线 Freeze|敌方要么冒风险前来补刀，要么损失资源|不必离塔很远即可吃线，易配合打野施压|自己丢先动权；敌方游走到别路获得更高价值|
|慢推 Slow push|对方随后要消耗较长时间清掉一大波兵|配合换血越塔、回城或另一地图目标|没视野形成大兵线前被抓；推太慢错过目标|
|推进塔 Crash|对方先花时间清线，经验/经济被塔压制或迫使交技能|回城买装、补视野、走河道短窗|未推进塔导致敌方冻结；推完自己无血无法动|
|反弹线 Bounce|防守塔清兵后，后续兵线方向可朝自己一侧移动|回线更安全、有接线窗口|须根据双方兵量和到塔时机实测，不是每次推线都能反弹|
|快速处理 Fast push|抢到短时先动并拒绝对手慢推|立刻支援、换目标、回防|敌方能清线和反推，自己盲走反亏|

### 2. “回城回合”决策树
- **血量蓝量低/有重要金币待花** → 必须先确认是否有安全回城窗口，不要为了凑成大波硬推被抓死。
- **能把线完整推进塔** → 先推进，再回城；记录对方会损失几只兵（未有录像不填虚数）。
- **推不完且兵线朝我方来** → 如果能安全回城，薄化过大敌方兵线，使其慢慢进入我方可接区域；不要硬把半波推进去。
- **敌方有先动权/位置未知** → 优先保线与补给，避免为了看似漂亮的推线牺牲位置。

“Cheater recall（提前回城）”本质是通过早期波次控制制造装备/补给领先后的再对线窗口，不是固定第几波就一定能够回。2026前期兵线/野怪节奏已变，教学只保留机制，不强制套老视频的秒表。

### 3. 双时钟模型：兵线和目标同时看
设想目标出现前，你有约一段回城与支援时间：
- **Wave Clock**：兵线几秒后抵达对方可安全清线的区域？
- **Objective Clock**：本方补给/走位/视野建立后，还剩多少时间？
- 只有两者窗口重叠，才可能用一条边线迫使对手清线而让你方先开目标。

重要2026变动：Riot 26.1将**14分钟后兵线刷新间隔改为25秒、30分钟后20秒**；因此旧赛季“14分钟后依然30秒一波”的长期边线经验可能失准。实战以当前补丁为准。

### 4. 情境与反例（均为模拟）
**R2-A**：下路击杀敌方二人，对面中野位置未知。残血ADC想贪第三波塔皮。只要“敌方中野到场时间可能早于我方回城/撤退时间”，就需比较一个分段金币和失去人头/兵线/大龙准备权的风险；通常不该单凭一片塔奖励留人。

**R2-B**：中路已经有推进优势，打野喊3秒后来河道。中单若清完整波却把己方状态打空，实际能不能去争？真正线权=**兵线有压力 + 人能动且愿意动**，不是单一“先清完”。

### 5. 练习题与答案
- **题①**：你推到敌方塔前差一点未入塔，现在直接回城。回线有可能发生什么？  
  **答案**：敌方可能控住兵线、使其停在对自己有利的位置；完成Crash才常能压出安全补给窗口。
- **题②**：龙即将刷新，己方边线慢推很大、但没有人能安全陪兵线深入。还能否坚持推进？  
  **答案**：兵线本身不是胜利条件；要评估敌方回防人数与队友能否用时间差兑现龙。若不能，强带可能同时亏人和龙。
