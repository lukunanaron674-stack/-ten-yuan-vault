# R3｜地图信息、野区与跨线联动

**Z：我确定了什么信息，从而敢做什么决定？**

## 四层情报
- 已确认：敌方关键人物刚露头、回城或阵亡。
- 高概率推断：根据露头时间、营地、波次推测位置，必须标为推断。
- 未知：关键敌人消失且无视野，不允许把未知自动算安全。
- 反证：敌人未按猜测路线出现，立即更新假设。

## 连锁因果
线权→先一步走进河道→布/排视野→对方被迫绕路→我方先到可争区域。没有中路线权时贸然入侵则可能变成被夹击。

## 例题
己方打野下半区，敌方打野上半区露头：不意味着立即开龙。还需要下中两路能否到场、健康状态、敌方传送/快速支援、目标是否能及时安全打完。

## 信息行动卡
敌方谁确认不在？→谁仍未知？→眼位排除了哪条路线？→行动要多久？→撤退路线？

2026新视野机制（如 Faelights）需依当前补丁核实，不能机械复用2025年眼位教程。

**练习**：对2次被抓或成功抓单情境，重建当时玩家视角信息，而不是事后全图视野。

**DONE**：2个有时间码的地图推断与替代决策。**STOP**：推断不能伪装已确认位置。

## R3｜桌面研究实跑（2026-10-26）

### 1. 高阶信息链：信息只要能消除关键的不确定性，就有价值
**关键是“让我敢做什么/不再敢做什么”。**

|信息类别|示例|操作意义|
|---|---|---|
|Confirmed已确认|敌方打野2秒前在上路出现；敌方中单可见于中线|下半区短期存在可利用的时间窗（仍需看对方传送和其他位置）|
|Inferred推断|敌方某侧野怪已消失，按清野路线推测下一步|提高某方向的危险权重，不得称其位置已知|
|Unknown未知|中单、打野、辅助同时消失；己方边路无视野|不可强行把3名失踪者都默认在远端|
|Invalidated反证|预测对方在下野，对方却从上河道出现|马上更新路线而非归咎“对方反常不讲道理”|

### 2. 地图上实战的三个闭环
**A. 中路线权→视野推进**：推线 → 与队友同步去河道/敌方野区入口布视野 → 获得先到大目标的权利 → 必须确保自己在被包抄前有回撤路线。

**B. 反野→跨图交换**：确认敌打野上半区且上路敌人压深 → 下半区拥有线权和足够人数 → 才考虑下半区野怪/龙/塔；不满足则直接清线或回城，避免“看到对面打野就必须做事”。

**C. 反抓→反向兑现**：对面多人抓上 → 我方下路线权可兑现 → 把对方在上半区投入的时间换成塔/目标/营地；我方下路状态不好则不强开。

### 3. 2026视野机制必须纳入
官方26.1引入 **Faelight（萤辉点位）**：在特定发光圈放置守卫，可在一段时间内扩大视野并显示额外区域。初始设定为守卫视野半径**+25%**、额外区域**45秒**，并有侧边推进用点位；这能减小边路视野部署成本，但无法永久保证安全。上述具体数据应随当期补丁复核。

据此，高阶分推判断要问：
1. 我方是否真正照亮了对方最可能来抓的路线？
2. 额外区域什么时候消失？
3. 即使看见对手，我有没有**提前撤退的时间**？
4. 视野是否被扫掉，导致过去的安全推断已经失效？

### 4. 两个反常识案例（模拟）
**R3-A：对方打野在上出现，是否可以强开下龙？**  
不必然。要比较对方下路是否可立即围过来、我方中路线是否先推、关键技能是否可用、击杀龙需要多久。2026官方增强中立怪物有效耐久，使“看到敌打野远就迅速偷掉”更需要精算时间。

**R3-B：自己视野分数很高，仍被侧翼开死。**  
可能是守卫全插在不决定本次行动的地方。一次“插眼能否改变决策”比绝对视野分数更有价值。

### 5. 标准化录像练习
对三次危险决策，录像停止在角色准备前进的瞬间，建立 `Confirmed / Inferred / Unknown / Action / Exit` 五栏。然后才播放结果，判断当时是否有另一条低风险路线。
