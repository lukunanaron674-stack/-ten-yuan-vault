## 二、核心理论依据（十元生补克表 v0.1）

### n 的补位对象：x并z（阴木），不是 x（阴水）

| 十元 | 补位对子 | 所属维度 | 生母 |
|------|---------|---------|------|
| **n（阳土）** | **x并z（阴木·包装）** | **空间** | zn 生 n |
| zn（阳火） | **x（阴水·深欲）** | **本体** | zn 补 x |
| xn（阳金） | **z（阳火）** | 时间 | n 生 xn |
| zx（阳木） | **nx（阴金·算计）** | 因果 | — |
| xz（阴木） | **nz（阴土）** | 命运 | — |

**关键发现：n的补位对子是 x并z（阴木/包装），不是 x（阴水/深欲）。**

### 母行链路追踪

- **n 的母行**：`zn → n → xn → x并z`
  - zn 生 n → n 生 xn → n 补 x并z
  - **n→x 不是这条链上的任何一步**
- **zn 的母行**：`zn → n → x ...`
  - zn 补 x（本体线）
  - 这里涉及 n，但 n 是 zn 生的**中间产物**，不是补位方

**也就是说：n→x 之间没有直接的补位或生位关系。** n→x 若要成立，必须经过 zn 这个中介——那是「zn补x」的本体线机制，和 n 无关。

## 四、误读的源头分析

所谓的「n→x 补生转化」最可能是以下两种误读的混淆：

### 误读1：把「n 补 x并z」看作「n 补 x」

x并z（阴木/包装）与x（阴水/深欲）在字面上接近，但本质完全不同：
- **x并z** = 表象、伪装、包装——依附于表面的东西
- **x** = 深欲、占有、吞噬——底层驱动的本能

空间公式：**空间 = x并z（包装）+ n（承载）**。x并z补n/被n补是空间维度的核心机制。如果换成x（深欲），空间就变成了「欲望+容器=烂泥」，与逻辑完全矛盾（此点已在x并z阴木论证中确认）。

### 误读2：把「zn 补 x」看作「n→x」

母行链路：
```
zn →（生）→ n →（生）→ xn →（补）→ x并z  （空间线）
zn →（补）→ x                              （本体线）
```

因为 n 出现在 zn 的母行中（zn生n），容易误以为「n → x」是一步，但实际上 n 在这条链中是**zn的产物**，不是向x输送补位的主动方。「zn补x」的正确解释是：精神之火需要原始深欲为燃料，经由n（容器）这个中间态。

## 五、最终结论

| 维度 | 结论 |
|------|------|
| **n→x 补生转化** | **❌ 证伪 — 不存在的机制** |
| 实际存在的机制 | **n 补 x并z**（空间容器补包装载体） + **zn 补 x**（精神补欲望） |
| 误读性质 | 字面混淆（x并z vs x）+ 母行链路误认（把zn的补位安到n身上） |
| 是否影响n补克nx | **不影响**。n补克nx是n与nx之间的跨维压制，与n→x无生克链冲突 |

| 角色 | 立场 | 结果 |
|------|------|:----:|

### 路标修正

从「空间（n补x并z）」到「本体（zn补x）」确实是跨主题跳跃，但不是n→x的直接转化。正确的表达是：
> **空间容器中的包装（x并z）被承载（n），与本体维度的深欲（x）被精神（zn）补充，是两个完全不同的机制。** n→x 的幻觉来自于这两个维度的字面混淆。
