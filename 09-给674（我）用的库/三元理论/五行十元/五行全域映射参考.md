# 五行全域映射

五行是「5 个不可替代的名词覆盖任意领域」的终极参照系。  
任何领域填入这 5 个格子，每个格子精确、不重叠、可推导。

---

## 核心定义

| 行 | 核心意象 | 不可替代性 |
|----|---------|-----------|
| **木**🌳 | 生长、生发、条达 | 任何"向上向外舒展"的东西只能放这里 |
| **火**🔥 | 炎热、上升、发光 | 任何"能量释放、转化"的东西只能放这里 |
| **土**🌏 | 承载、化生、中和 | 任何"居中、过渡、储存"的东西只能放这里 |
| **金**⚔️ | 肃杀、收敛、变革 | 任何"切割、收束、决断"的东西只能放这里 |
| **水**💧 | 寒凉、润下、藏匿 | 任何"向下、流动、潜藏"的东西只能放这里 |

## 五行推导规则

五行能映射所有领域，靠的不是死记硬背，而是三条推导规则：

### 规则 1：类象推导
如果已知「心脏 = 火」，则心跳（搏动、泵血、输送能量）相关的东西归火类。  
→ 同理：血液循环 = 火，体温调节 = 火，情绪激动 = 火

### 规则 2：生克推导
木生火 → 树木生火 → 所以燃料、能源类归木  
水生木 → 水滋养树木 → 所以营养、滋养类归水  
金克木 → 刀砍树 → 所以规则、约束类归金

### 规则 3：时空定位
春天 = 木（生长）→ 所有在「初始阶段」的东西归木  
北方 = 水（寒凉、向下）→ 所有「下沉、潜藏」的东西归水

## 对十元五大主题的启示

| 五行成功的要素 | 对应问题 |
|----------------|---------|
| 每个行有**不可替代的核心意象**（生长/升发/承载/收敛/润下） | 你的五个主题各自的核心意象是什么？能用一句话概括吗？ |
| 任意领域都能**填入这5格**，不留空位 | 你的五个主题在所有领域都有对应吗？哪个领域有盲区？ |
| 有**推导规则**（类象/生克/时空），不靠死记 | 你的五大主题之间有推导关系吗？ |
| 任何人对同一事物的五行归类**基本一致** | 两个人看同一个东西，会分进同一个主题吗？ |
