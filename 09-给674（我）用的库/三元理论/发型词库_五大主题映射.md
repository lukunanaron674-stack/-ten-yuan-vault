# 发型词库｜五大主题 × 视觉名词映射

> 归档：`09-给74用的可视化库/三元理论/`  
> 性质：视觉语言映射 → 十元理论五大主题  
> 关联：图象库（`图象库/`）的配套视觉词库  
> 评分标准：关联精密度 0-100（灵魂像素匹配度） · 向量强度 1-10（设计用力程度）

---

## 核心映射总表

| 主题 | 十元组合 | 灵魂像素关键词 | 核心发式 |
|:----|:--------|:-------------|:--------|
| **时间** | xn + z | 秩序、节拍、规整、统一、刻度 | 盘发/编发/背头/马尾 |
| **本体** | zn + x | 本质、裸露、贴近、无需修饰 | 短发/素发/碎发/披散 |
| **空间** | x并z + n | 包裹、层叠、掩盖、边界 | 长发/长发过腰/刘海遮眼/包头 |
| **因果** | zx + nx | 行动、操作、便捷、节点 | 高马尾/丸子头/短发干练/绑带发 |
| **命运** | xz + nz | 飘动、散落、路途、风迹 | 散发/微卷/碎辫/发丝飘动 |

## 词库详解（含精密度+强度评分）

### ① 时间系（xn + z）

**灵魂像素**：规则(xn)对头发进行秩序化处理——每一根头发都被规矩(z的瞬间每一缕都要就位)

**核心发式**：盘发 / 编发 / 背头 / 马尾

|:----|:-----:|:---:|:----|

## 强度分布规律总结

**高强度（8-10）** 特征：
- 发型直接表达主题的核心灵魂像素——不需要搭配/场景/情节辅助
- 例：后梳背头→时间97/10、刘海遮眼→空间97/10、高马尾→因果98/10、风中散发→命运99/10

**中强度（4-7）** 特征：
- 体现了部分场意，但受其他因素影响（发质/长度/造型手段的混合）
- 或跨主题属性稀释了单一纯度
- 例：大波浪卷→时间68/4（规律性的节奏但不强）、狼尾发→本体72/4（反叛但偏x）

**低强度（1-3）** 特征：
- 发型在主题中的表达是附属/间接的——需要额外条件激活
- 例：发胶定型→时间60/3（作用是固定而非发型本身）

## 跨主题发型处理

同一发型在不同语境中可能切到不同主题——关键在"场意"：

- **马尾**：高束运动型 = **因果**（98）| 低位松束 = **命运**（78→半途）| 配合制服 = **时间**（88→规则系住的）
- **丸子头**：紧束干练 = **因果**（93）| 松散随手一扎 = **本体**（58→"我就是这样"）
- **披肩发**：丝滑整齐 = **空间**（85→包裹）| 未经打理 = **本体**（96→原始）| 风中飘动 = **命运**（99→飘）
