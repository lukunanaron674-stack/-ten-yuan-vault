# 图象库｜三元理论·空间主题组

> 归档：`09-给74用的可视化库/三元理论/图象库/`
>
> 本页保存历史视觉案例、旧评分和旧标签。它只负责召回与追溯，**不拥有当前三元、十元或生克补语义的定义权**。

## 当前使用边界

1. 三元、十元、五大主题、生克补和动态链是并行协作层，不得写成父子派生关系。
2. `空间 = x并z + n`、`时间 = xn + z` 等旧公式，只保留为历史映射口径，不作为“十元生成三元”或“三元生成十元”的证明。
3. 图片中的服装、表情、红色、蛇、账本、监狱、学校、规则等，只能作为视觉召回入口，不得凭表面关键词直接判定人物本体或关系。
4. 必须区分：人物稳定本体、当前状态、行为功能、外部场景、时间关系、视觉与光影、关系与动态链。
5. 本页所有依靠“算计、暗账、记账、清算、幕后操控”证明 `nx` 的旧内容，统一标记为 **legacy-nx**；按现行口径应优先重新检查 `xn` 行为/状态，不能直接改判人物本体。
6. 旧分数和文件名暂不改写，避免伪造历史；需要调用时必须先复验。

## 当前最小边界

```text
nx：不主动建立或改写方向，把选择留给别人、流程、关系或现状，沿既有条件继续。
xn：主动把信息、行动或资源放进计划、时间、规则、记录或隐藏结构，使积累发挥力量。
```

因此：

```text
算计、记账、审计、等待结算、幕后布局
→ 优先检查 xn 行为 / xn 状态
→ 不再直接作为 nx 本体证据
```

### 旧语义隔离

以下旧句不再拥有当前定义权：

```text

nx = 精巧账本、暗流操控者、利益结算机

```

这些内容统一标记为 `legacy-nx`。其中“记录、计算、安排、等待结算、幕后组织”应优先检查 `xn` 行为或状态；但不能因为行为像 `xn`，就自动把历史角色锚改判成 `xn` 本体。

旧映射人物与系统：

- L（《死亡笔记》）
- 韩琛（《无间道》）
- Seele 议事堂（EVA）

### 当前允许保留的候选问题


这与旧“容器封住暗账结算”不是同一语义。由于目前证据不足，`n补克nx` 不在本页恢复为正式关系。
