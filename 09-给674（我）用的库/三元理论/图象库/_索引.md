## 001｜x并z+xz5+n3 — 血液蛇惊恐木脸

### 视觉要素

| 要素 | 十元映射 | 解释 |
|------|---------|------|
| 木勒脸 / 惊恐僵硬的木质面容 | **x并z（阴木·8）** | 包装者的表情——僵硬的、虚假的、带着恐惧却仍在维持表面的「木」 |
| 蛇（缠绕/潜伏的意象） | **x（阴水·深渊欲望）** | 藏在包装下面的贪婪、渗透性、阴冷的本能 |
| 血液 / 红色蔓延 | **z（冲动·渴望被看见）** | 血液的「红色」是z的视觉映射——奔腾、需要被认可的生命力 |
| 诡异的纹样服装 | **n（承载·容器）** | 承载这些符号的场域/外壳——空间的外层界面 |
| **整体强度** | x并z(8) + xz(5) + n(3) = 93分 | 阴木包装为主调，附有命运执行的魄力（xz5）和空间承载的稳定基座（n3） |

### 空间克制命运——核心关系（来自 15条银矿骨型 第13条）

**表达式**：
- **空间** = x并z（阴木·包装）+ N（阳土·承载）→ 稳定的容器 + 光鲜的表象
- **命运** = xz（阴木·漂流）+ nz（阴土·柔情停靠）→ 寻求归宿的执行线

**克制机制**：**n（阳土·空间承载秩序）克 xz（阴木·命运漂流执行）**

> 骨型13「临时家庭生成链」的核心：临界漂流者 xz 试图与柔性停靠 nz 互补成临时家庭，但外部空间 n（血缘制度/稳定秩序/社会容器）行使先天资格审判，直接压制漂流动能。
>
> **空间越完整、表面越光鲜，命运就越难突破**——因为包装（x并z）用漂亮的壳把一切可能撕裂命运的边缘都打磨圆润了，而承载（n）用秩序锁死了所有的出口。

**这张图的视觉呈现**：惊恐的木勒脸，僵硬的木性面具维持着表面的完整（x并z的空间包装在运行），但血液（z/命运的执行冲动）和蛇（x/深渊欲望）正在从诡异纹样服装（n/空间承载层）底下渗透出来——命运正试图从空间的包裹中破壳而出。

## 002｜时间生空间 — 命运感1比10 空间包裹

### 核心数据

| 维度 | 值 |
|------|-----|
| 十元构成 | nz(3) + nx(5) + n(9) + xn(7) |
| 分数 | **99** |
| 主题配比 | 空间 : 命运 = **10 : 1** (命运被空间完全压制) |
| 脸 / 出口 | **10比** — 面部是命运感唯一的出口 |
| 主题生克 | **时间生空间** → 空间克制命运 |

**解读**：

这张图展示的是**时间（xn+z）生出空间（x并z+n）**之后，**空间全面压制命运**的状态。

- **nz(3) + nx(5) + n(9)** —— 三个n面（柔情/算计/承载）叠满，空间容器极度厚重
- **xn(7)** —— 时间规则是空间的母体，xn的规则力量在生空间后隐退
- **命运只占1** —— 被10分的空间死死包裹，命运的出口仅仅剩下一张脸（10比的脸）
- **99分** —— 几乎满分，因为空间主题的完成度极高，命运的断裂感也极致

**视觉呈现**：厚重的空间容器（n的层层叠压）× 压抑的规则秩序（xn的余韵）× 命运只能从面孔的缝隙中勉强透出。

## 003｜空间容器9克因果3 — n补克nx

### 核心数据

| 维度 | 值 |
|------|-----|
| 十元构成 | n(9) + nx(13) + x并z(少量) |
| 分数 | **93** |
| 核心生克 | **空间克因果** — n(9)克nx(13) |
| 特殊机制 | **n补克nx** — n对nx的补位同时带有压制性，不是纯粹的生 |

**解读**：

这张图展示的是**空间容器以n补位的形式压制因果结算**的状态。

- **n(9)** —— 空间承载极强，容器本身极度厚重
- **nx(13)** —— 因果暗账的体量巨大，但全部被困在空间容器内部，无法结算
- **x并z(少量)** —— 包装层很少，说明这不是「用漂亮壳去骗」的型态，而是「空间本身即牢笼」——不是假装的，是真实的结构性压制
- **n补克nx** —— 关键机制：n对nx的「补」变成了「克」。容器本该承接暗账、让因果完结（补），但这张图里的容器锁死了nx——暗账被压在容器底层，永远算不清
- **93分** —— 空间的强度n(9)+nx(13)但x并z层缺失导致结构完成度略逊

**与002对比**：
- 002：空间(10)压命运(1)，命运还有脸作为出口
- 003：空间(9)压因果(3·nx13)，因果被彻底关在容器内部，连出口都没有——因为nx本身就是暗账/看不见的结算，被n封死后连「被看见」都不可能

### nx13的本体系外映射

nx（阴金·算计）= 精巧的小账本、暗流操控者、利益结算机。
13 = 体量巨大，不是记账本的级别，是一个完整的**账房系统**。
