# 74 载体方案流（候选 v0.1）

## 1. 方案流原文序列（74 的实际推进顺序）

```text
① 插画        → 解决【本体】+【命运】
                  但：需要空间跟时间
② （推演）     → 命运越来越大 / 空间越来越小 / 本体没法达成
③ 动画        → 表达【本体】
                  问题：本体太小，扛不住命运
④ 角色建模    → 扛住【命运】
                  问题：扛到一半被命运带偏
⑤ AI动画      → 顺着被带偏的命运去做【因果】
                  结果：最接近本体的一次 / 本体也最大的一次
                        "似乎扛得住命运，只是不清楚什么扛"
```

## 2. 载体 ↔ 目标十元 对照表

| 载体 | 目标 | 附带需求 | 遇到的问题 |
|---|---|---|---|
| 插画 | 本体 + 命运 | 空间、时间 | 需要时空才能成立 |
| 动画 | 本体 | —— | 本体太小，扛不住命运 |
| 角色建模 | 命运 | —— | 扛到一半被命运带偏 |
| AI动画 | 因果（顺着被带偏的命运） | —— | 最接近本体、本体最大，"不清楚什么扛" |

## 3. 方案流的结构判读（674 初步）

**3.1 这是一条"载体升级链"**
插画 → 动画 → 角色建模 → AI动画，每一级都在**换更强的承载器**，目标从"本体+命运"逐步聚焦到单个十元（本体 → 命运 → 因果）。

**3.2 每级都是"目标 + 失败点"成对出现**
- 插画：要时空 → 命运大/空间小 → 本体达不成
- 动画：装本体 → 本体太小扛不住命运
- 角色建模：扛命运 → 被命运带偏
- AI动画：做因果 → 反而最接近本体、本体最大

**3.3 关键转折：AI动画是"顺着被带偏的命运"**
前面各级都是"硬扛命运"，只有 AI动画 改成**顺着命运的偏向走因果**——结果反而最大。这是方案流里唯一一次"不扛而顺"，值得单独标注（是否可映射为 命运/因果 的对子关系，待二审）。

**3.4 "不清楚什么扛"**
AI动画那级虽最接近本体，但74自己标了**归因不明**——"似乎扛得住命运只是不清楚什么扛"。此处留 T未判定 / E未判定，不代填。
