## 1｜一句话结构

> **主体不是通过“得到对方”完成恋爱，而是对方的颜色、头发、动作、气味不断侵入自己的感知系统；喜欢一个人最终表现成“世界里越来越多东西都开始带上她的颜色”。**

结构：

```text
看见她的颜色
→ 注意力被吸住
→ 镜子 / 头发 / 晨光 / 气味都开始围绕她被解释
→ 她的颜色进入我的感知
→ 喜欢的重复越来越密
→ 世界主观上被恋爱染色
```

核心变量：

```text
other_color_salience ↑
self_perceptual_absorption ↑
romantic_attribution_bias ↑
affection_intensity ↑
formal_relationship_evidence ≈ low
```

## 2｜最大的十元价值：高情绪 ≠ 高端点

这首“喜欢”的强度极高：Kiss反复出现，“好き”高密度重复，注意力高度集中到“君”。

但按仓库 current canonical，不能因此机械判高 N / NZ / X / Z。

关系事实层没有充分证明：
- 双方形成持续承载（N）；
- 分离后仍有真实回返 / 修复（NZ）；
- 对方进入“归我掌握”的处分边界（X）；
- “君”成为能排退竞争中心的最终裁定点（current Z）。

> **恋爱感可以很强，但十元端点要求的是结构变量真的发生改变。**

## 4｜K37-A｜他者染色型

为避免与仓库既有音乐动态链 H29-H35 编号冲突，本卡新增素材使用 K37 子编号，不新增全局H号。

定义：

```text
主体先看见对象的强可见特征
→ 该特征成为注意力锚
→ 越来越多普通感官线索被重新解释为与对象有关
→ 对象不需要真的改变环境
→ 主体自己的感知系统主动把环境染上对象的色彩
```

> **不是她把世界染色，而是我已经开始用她的颜色看世界。**

关键变量：

```text
object_salience ↑
sensory_association_density ↑
neutral_cue_count ↓
romantic_attribution ↑
world_subjective_colorfulness ↑
```

## 5｜中性线索不断失去中性

歌词里的镜子、晨光、湿发、毛巾气味，本来都可以是普通环境信息。

但主体不断把它们吸进同一个恋爱解释场。

> **关系还没被证明成立，解释已经先开始恋爱。**

尤其“湿掉的发梢说不定是为了我”这类结构，体现的是：

```text
neutral cue
→ romantic interpretation
→ self-relevance ↑
```

这属于恋爱感知偏置，不应倒推出正式关系事实。

## 6｜颜色三联组

### K33｜Persona Q2《colorful world》
> 别人先看见我，我才相信自己也是一种颜色。

机制：**被见着色。**

### K34｜仮谷せいら《Colorful World》
> 我开始自己决定眼泪、软弱、阴天可以是什么颜色。

机制：**自主配色。**

### K37｜AKASAKI《Kiss Kiss Kiss》
> 我看见你的颜色以后，我周围的世界开始被你染色。

机制：**他者染色。**

三首组成：

```text
K33：他者 → 我有颜色
K34：我 → 给自己重新配色
K37：他者的颜色 → 改写我的感知世界
```

这对“色彩如何进入感受，再进入结构”的跨域研究很有价值。

## 7｜K37-B｜陈词自觉不减真

歌词主动承认自己可能只是“二番煎じの恋”——这种恋爱和说法并不新鲜。

但喜欢的强度没有因此下降。

所以可以抽成：

```text
知道表达很俗 / 很老套
→ 不否认陈词性
→ 仍保留真实感受
→ 用具体感官细节重新获得个人性
```

> **原创性不足，不自动等于感受不真。**

## 8｜老套情绪如何重新变具体

这首真正让恋爱变具体的不是“喜欢”“接吻”这些大词，而是：
- 镜子里的颜色；
- 湿掉的发梢；
- 笨拙动作；
- 毛巾残留的气味；
- 清晨光线。

公式：

```text
generic emotion
+ specific sensory anchor
= personally believable emotion
```

这对写青春 / 恋爱特别好用：

> **大情绪可以很普通，但承载它的小感官必须足够具体。**

## 10｜与《トリコ》的对照

《トリコ》：
> 强占有语言很高，但实际X控制边界低。

核心：
> **affection intensity ≠ control intensity**

《Kiss Kiss Kiss》：
> 喜欢强度很高，但连稳定关系端点本身都还没有充分成立。

核心：
> **affection intensity ≠ relationship establishment**

所以：
- トリコ：强恋爱表达 vs 控制机制分账；
- Kiss Kiss Kiss：强恋爱感受 vs 关系事实分账。

## 11｜与《Puppet》的对照

《Puppet》里，对方已经开始成为主体的方向启动条件。

《Kiss Kiss Kiss》里，对方主要成为主体的**感知过滤器**。

所以：
- Puppet：**她影响我怎么走。**
- Kiss Kiss Kiss：**她影响我怎么看。**

## 13｜重复为什么不是XN

Kiss Kiss Kiss、好き好き好き好き都高度重复。

但 current XN 要求主体把重心分布进顺序、规则、记录和流程，使其持续运行。

这里重复只是 hook、情绪密度与音乐形式。

> **重复很多 ≠ XN。**

## 14｜可迁移到视觉

不要一开始就把整个世界直接变成彩虹。

更适合：

```text
喜欢对象身上先出现固定色A
→ 背景维持普通
→ 主角开始注意到环境中的A色小物
→ A色元素逐镜增加
→ 最终不是世界真的换色
→ 而是镜头选择越来越只看A相关元素
```

这更接近恋爱感知，而不是简单滤镜。

## 15｜色彩理论A/B实验

可以直接做三组：

### A｜对象色扩散
- 喜欢对象有固定色A；
- 后续镜头逐渐增加同色 / 邻近色元素。

### B｜随机色扩散
- 颜色数量、饱和度、出现频率与A相同；
- 但颜色与喜欢对象无对应关系。

### C｜纯叙事控制
- 对象与场景色关系不变；
- 只保留恋爱行为。

盲测：
- 被某个人占据注意力的感觉；
- 恋爱感；
- 世界被该对象影响的程度；
- 无台词时能否识别“对象中心”。

如果A显著高于B/C，才说明：

> **同色关系本身可能承担了“对象 → 感知场扩散”的结构作用。**
