# nz-z-xz-an-evening-calm-fripSide-nao

## 0｜身份确认与版本边界

本卡按 **2005 年 nao 主唱原版** 分析，不与 2017 年南條愛乃主唱的 `-crossroads version-` 混写。

- 曲名：an evening calm
- Artist：fripSide（第1期）
- Vocal：nao
- 收录：`3rd reflection of fripSide`
- 初出：2005-06-23
- 作词 / 作曲 / 编曲：八木沼悟志
- 原版时长约 5:51
- 可核验编制资料：electric guitar = maya；wind synthesizer = masa；arrange = 八木沼悟志
- 第2期 2017 年《crossroads》另收录南條愛乃演唱的重制 / cover 版本，属于独立版本对照，不作为本卡主证据

第三方分析数据库给原曲约 108 BPM；本卡不把该数值作为核心结构结论。

## 1｜一句话结构

> **主体回到多年未走的旧街，仍然寻找已经失去的人；到最后甚至接受“你不再认出我也没关系”，但关系指向并没有因此消失。**

这不是普通的：
`想念 → 希望重逢`

更准确是：
`失去 → 回到旧地点 → 寻找 → 发现无法恢复 → 撤回“必须被你认出”的要求 → 仍然保留想见你的方向`

核心变量不是“悲伤强度”，而是：

> **recognition_required ↓，relationship_direction 仍保持。**

## 2｜声音 / 形式构成

### 2.1 中速电子骨架托住长时间回望

可核验资料显示：
- 原曲约 5:51；
- 第三方节拍分析约 108 BPM；
- 编制包含电子合成器体系、吉他与 wind synth。

因此它不是极慢、停滞式哀歌。

形式上更适合承载：
> **“一边继续走，一边不断回头。”**

也就是：
- 身体仍在移动；
- 记忆却不断把注意力拉回过去。

这与纯 NZ 的“停在原地等”略有不同。

### 2.2 固定地点反复返回

歌词结构反复回到：
- 久别的街道
- 坡道
- 秋风
- 夕阳 / 暮色
- 落叶
- 同一个寻找动作

因此场景并不是“背景换来换去”。

它更像一个固定坐标：

> **时间已经过去很多年，但地点仍在替过去保存位置。**

这里的空间不是 N 承载结构，因为它没有真正接住主体。

它只是：
> **记忆坐标。**

### 2.3 “记忆褪色”与“声音仍响”并行

很重要的一组反向变量：

```text
memory_visual_clarity ↓
relationship_echo ≈ persistent
```

也就是：
- 画面越来越模糊；
- 关系却没有同步归零。

这意味着：
> **记忆的精确度下降，不等于关系意义下降。**

## 4｜核心动态：Z下降，NZ不跟着下降

这是本曲最值得保留的部分。

通常很容易假设：

> “如果对方不再认我，那关系应该结束。”

但本曲并不这样。

### 前段

`NZ8 + Z6`

主体重新来到旧地，仍在寻找对方。

这里：
- 想见到对方；
- 想重新建立联系；
- 仍含有“再次被彼此确认”的愿望。

### 中段

`NZ9 + XZ6.5`

几年过去：
- 记忆在褪色；
- 真相无法抵达；
- 旧关系无法直接恢复。

XZ的不可逆性上升。

### 后段

`NZ8.5 + Z2`

最关键的转折：

> **即使对方不再注意 / 认出自己，也接受。**

这意味着主体撤回了：
`“你必须重新确认我”`

但没有撤回：
`“我还是想再见你”`

因此本曲出现一个很漂亮的分离：

> **Z需求下降 ≠ NZ关系方向下降。**

## 5｜动态链初版

```text
NZ7 + Z6

      ↓ 时间推进
XZ6

      ↓

```

简写：

> **回去 → 寻找 → 回不去 → 放弃被认出 → 仍然想见**

## 6｜关系边审计

### 6.1 XZ ↔ NZ｜强候选

现行 v2.22 已锁命运互补：

- XZ 为 NZ 提供真正失去 / 返回窗口关闭的重量；
- NZ 为 XZ 提供明确的回返对象与关系终点。

本曲高度贴合：
- 多年流逝与无法回到原关系，使“再见一次”的愿望具有有限性；
- 主体的回返方向始终明确指向同一个人，而不是抽象怀旧。

作品级候选强度：**8.5/10**。

### 6.2 Z 生 NZ｜不锁

现行仓库中 `Z 生 NZ` 仍属于**未锁定关系**。

本曲确实存在：
- 过去彼此有关系 / 交谈；
- 被对方注意、记住的愿望与关系停靠相连。

但后段最关键的结构恰恰是：

> **Z需求下降后，NZ仍然维持。**

所以这首反而不适合用 `Z生NZ` 做主解释。

它更适合拿来证明：

> **Z与NZ可以相关，但不是同一件事，也不是必须同步升降。**

## 7｜新增素材母型

# H13｜撤回确认型 / 单向保留

定义：

```text
关系仍然重要
→ 现实重逢概率下降
→ 主体原本希望被对方重新确认
→ 逐渐撤回“必须被确认”的条件
→ 对方是否回应不再决定关系是否存在
→ 关系从“等待恢复”变成“单向保存”
```

核心变量：

```text
recognition_required ↓
reciprocity_required ↓
relationship_target = constant
relationship_persistence ≈ high
```

这不是“终于放下”。

也不是“执着升级”。

而是：

> **关系的存在方式改变了。**

## 8｜一个非常重要的边界：NZ不等于无条件单恋

现行 NZ 准度卡要求警惕：

> 若对方明确不愿回来，关系只剩单方回忆，稳定 NZ 可能下降。

本曲没有足够证据证明“对方明确拒绝返回”。

歌曲只证明：
- 已失去；
- 已多年无回应；
- 主体无法重新抵达真相；
- 主体愿意接受对方不再注意自己。

因此本卡把它判为：

> **高 NZ，但同时登记为“单向化边界样本”。**

这正好可以拿去测试：
> **NZ在互惠性降低后，最低需要保留什么，才不会坍缩成纯回忆 / 纯Z缺失 / 纯XZ失去。**

## 9｜与最近三首缺席关系样本对照

### 《砕月～イノチ～》

```text
旧关系
→ 新现实关系 N 进入
→ 世界重新打开
```

关键词：
**有人重新陪我看世界。**

### 《月の雫》

```text
现实回应 = 0
→ 环境代理回应 ↑
→ NZ继续
```

关键词：
**世界替你回答。**

### 《an evening calm》

```text
现实回应 = 0
环境代理回应 ≈ 0
Z确认要求 ↓
→ NZ仍继续
```

关键词：
**你不用回答。**

这三首已经形成一个非常干净的小型控制组：

> **失去以后，关系靠什么继续？**

1. 新的人进入；
2. 环境代答；
3. 不再要求回答。

## 10｜可迁移到视觉 / 剧情

### 视觉

不要画幽灵，也不要让风突然像对方摸脸。

可以更狠：

- 多年后回到同一个坡道；
- 镜头位置和过去完全一样；
- 对方的位置始终空着；
- 主体看了一会儿；
- 最后没有任何超自然回应；
- 转身继续走。

核心：

> **场景什么都没有回答，但角色已经不再要求它回答。**

### 剧情

传统写法：

> “我要让他重新记起我。”

H13写法：

> “我只是想再看你一次。你是否记得我，已经不是条件。”

于是关系从：
**恢复关系**

变成：
**保存关系。**

## 11｜关键变量

- **时间距离**：↑
- **记忆画面清晰度**：↓
- **真相可达性**：↓
- **被确认需求 Z**：明显 ↓
- **关系指向 NZ**：保持高位
- **新现实承载 N**：低
- **环境代理回应**：低

最关键的实验变量：

```text
Z ↓
NZ ≈ high
```

这张卡未来可以直接拿去测试：

> **Z下降到什么程度，NZ还能成立？**

> **我不是一定要你认出我；我只是还想再看见你。**
