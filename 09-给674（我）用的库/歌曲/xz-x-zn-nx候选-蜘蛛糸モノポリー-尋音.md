## 1｜一句话结构

> **当整个世界只剩一根随时会断的救命线，主体先把它当成救赎，随后又把“能抓住它”误写成“它应该只属于我”，最终占有动作反而毁掉唯一出口。**

不是：
`绝望 → 得救`

而是：

```text
绝境
→ 唯一出口出现
→ 把全部意义压到这根线上
→ 沿它往上爬
→ 发现别人也在抓
→ “救命通道”被解释成“我的东西”
→ 排他占有
→ 线断
→ 唯一出口彻底关闭
```

核心不是“希望破灭”。

而是：

> **稀缺把希望变成占有，占有又亲手摧毁希望。**

## 2｜原作母题与歌曲改写

芥川《蜘蛛の糸》的基本结构是：
- 地狱中的罪人得到一根通向上方的蜘蛛丝；
- 其他罪人也开始攀爬；
- 主体试图把这根丝声明为自己的、驱赶别人；
- 丝线最终断裂，主体重新坠落。

sasakure.UK 的歌词在这个母题上继续加入：
- `糸 / 意図`
- `愛 / 賽`
- `赤い糸`
- 救赎者 / 神 / 爱的暧昧重叠

于是“蜘蛛丝”不只是一条物理逃生路线。

它同时成为：

> **生路 + 爱 + 意义 + 他者给予的救赎接口。**

## 4｜最核心的动态：XZ把通道压成“一根”，X再把“一根”变成“我的”

### 起：XZ9

主体一开始就处在：
- 地狱
- 无稳定出口
- 唯一可攀附的细线
- 随时可能断裂

这是真正高体量的 XZ。

### 承：NX-like6.5 + ZN7

主体并不能自由设计逃生路径。

能做的只有：
> **沿这根已经被放下来的线向上。**

与此同时，这条线开始从“通道”升级成：
> **救赎 / 爱 / 神意 / 唯一意义。**

### 转：X4 → 8.5

关键不是别人出现。

关键是：

> **别人也抓住同一根线以后，主体突然把“我正在使用它”改写成“它属于我”。**

这一步把：
`access`

偷换成：
`ownership`

也就是：

> **使用权 → 所有权幻觉。**

### 合：XZ9.5 → 10

排他动作没有让主体更安全。

反而导致唯一通路崩解。

最终：

```text
可用路径数量：1 → 0
安全窗口：open → closed
掌握幻觉：↑
真实可控性：↓
```

所以它的结局不是普通失败。

而是：

> **为了独占出口，把出口本身弄没了。**


简写：

> **绝境 → 单线 → 赋义 → 争线 → 独占 → 断线**

## 6｜关系边审计

### 6.1 XZ ↔ NZ｜不作为本曲主关系

本曲有很强“爱 / 救赎”语言，但稳定 NZ 需要：
- 共同时间
- 关系余温
- 不愿结束
- 可信回返位置

当前歌词更强的是“对唯一救赎对象的依附”，而不是稳定的关系停靠。

所以不因为“爱”字面就机械锁 `XZ ↔ NZ`。

### 6.2 NX：单一路径不等于纯NX

虽然主体只能沿外部给出的蜘蛛丝向上，形式上非常像：
`方向由外部给定 → 主体沿路推进`

但现行NX准度要求排除：
- 生存威胁
- 强迫
- 没有选择的紧急条件

本曲这些污染都非常强。

因此：

> **只判NX-like路径依赖，不锁正式NX纯例。**

### 6.3 X：这里是真正值得高判的

后段不是抽象“自私”。

而是：
- 对象明确：蜘蛛丝 / 唯一出口；
- 边界明确：只许自己占用；
- 排他明确：别人必须退出；
- 掌握意图明确：把共享通道改写成私有资源。

所以 X 高位比“自私”这个性格词更精确。

## 7｜新增母型

# H20｜独线垄断型 / 救赎资源占有化

定义：

```text
系统只剩一个脆弱出口
→ 多个主体都依赖同一出口
→ 单个主体把“我需要它”误写成“它属于我”
→ 尝试排除其他使用者
→ 为了提高个人安全而破坏共享条件
→ 唯一出口整体失效
→ 所有人（包括垄断者自己）失去路径
```

核心不是：
> “坏人自私所以受惩罚。”

而是：

> **在极度稀缺里，局部自保策略可能直接摧毁全局生存结构。**

## 8｜H20关键变量

```text
path_count = 1
path_fragility = high
user_count ↑
scarcity_pressure ↑
ownership_claim ↑
shared_path_integrity ↓
final_path_count: 1 → 0
```

这个母型非常适合：
- 唯一撤离通道
- 唯一水源
- 唯一药物
- 唯一服务器 / 算力接口
- 唯一能进入城市的证件
- 唯一能联系某人的通信口
- 一段所有人都依赖的信任关系

## 9｜第二个素材：使用权偷换成所有权

# H20-A｜Access → Ownership 错写

定义：

```text
我暂时得到使用资格
↓
因为这个资源对我极重要
↓
心理上把“我正在用”
偷换成“它本来就该属于我”
↓
开始排除其他人
```

这是一个非常好的 X 生成前置候选机制。

但注意：

> **本卡只把作品内 X 的上升锁定，不把“XZ必然生X”写成正式十元关系。**

## 10｜第三个素材：希望被压成单点以后，会变脆

一开始：

```text
hope = one possible way out
```

后来：

```text
hope = the only way out
```

再后来：

```text
self-worth / love / salvation / survival
全部绑定在同一个接口
```

于是只要这根线出问题：

> **不是损失一个选项，而是整个意义系统一起坍塌。**

这个可以独立用于角色设计：

> **真正危险的不是“很在乎一个东西”，而是所有价值都只有一个承载点。**

## 12｜与《Puppet》的对照

### Puppet｜H16

> **我知道你在牵我，但我仍主动把方向交给你。**

结构：
`确认需求 → 方向让渡 → 依赖`

### 蜘蛛糸モノポリー｜H20

> **我知道这根线很危险，但它是唯一出口，于是我最终想把它变成只属于我的。**

结构：
`单线依赖 → 稀缺恐惧 → 占有 → 通道崩塌`

所以：
- Puppet：**把自己交给关系**
- 蜘蛛糸：**把关系 / 通道据为己有**

一个向外让权。

一个向内收权。

## 13｜与《ベノム》的对照

### ベノム｜H17

> 缺口填不满 → 索取加量 → 索取本身变毒。

### 蜘蛛糸モノポリー｜H20

> 出口只有一个 → 占有加剧 → 占有本身毁掉出口。

两者共同点：

> **补救动作开始扩大原问题。**

区别：
- ベノム：问题在需求回路。
- 蜘蛛糸：问题在稀缺共享资源。

## 14｜与《はいよろこんで》的对照

### はいよろこんで

> 系统里还保留“把正常接口反编码成SOS”的出口。

### 蜘蛛糸モノポリー

> 系统几乎只有一条出口；当主体把它私有化，系统就直接失去最后路径。

一个是：
**接口改写打开出口。**

一个是：
**接口垄断关闭出口。**

## 15｜可迁移到剧情

例如一个城市只剩一座桥可以撤离。

普通写法：
> 大家争先恐后过桥。

H20写法：

> 主角最初只是想先让家人过。
> 后来发现桥承载有限。
> 再后来开始封锁桥头，不让别人进入。
> 为了防止别人抢，他提前破坏部分结构。
> 最后桥因为负载 / 破坏彻底断裂。

这时他的失败不是：
> “没抢到。”

而是：

> **他为了确保自己拥有出口，亲手消灭了出口。**

## 16｜可迁移到视觉

非常适合做“线越来越少”的构图：

第一幕：
- 黑暗空间里有很多模糊路径。

第二幕：
- 所有路径熄灭，只剩一根亮线。

第三幕：
- 很多人都抓住这根线。

第四幕：
- 主体开始把别人的手掰开。

第五幕：
- 近景只拍他的手握得越来越紧。

第六幕：
- 线不是被别人抢断。
- 是在他最用力宣称“我的”时断掉。

这就是：

> **占有强度↑，真实可控性↓。**

## 17｜声音 / 语言可迁移

这首最值得抽走的语言技术之一是：

> **让一组相近声音 / 字形持续互相污染与改写。**

例如：
- 糸（线）
- 意図（意图）
- 愛（爱）
- 賽（骰 / 命运选择）

它们不断把“物理通道、主观意图、关系意义、命运偶然”缠在一起。

最终观众很难再把那根线只看成线。

它已经同时是：
> **出口、爱、意图和命运。**
