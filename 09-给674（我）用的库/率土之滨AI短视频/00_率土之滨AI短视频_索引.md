# 率土之滨 AI 短视频

![[率土之滨AI短视频_项目状态.base]]

## 当前边界

- 暂时只做独立短视频，不做长期连载。
- 每条视频只保留一个核心笑点和一个结尾爆点。
- 率土素材库只作为角色卡面与视觉参考来源。
- 历史人物关系可以架空和恶搞，但不包装成史实。

## 工单系统规则

- 任务卡负责内容：角色、参考图、画幅、动作、分镜和提示词。
- 工单负责执行：执行器、提交、生成、验证、功耗与回写；工单建立不等于允许提交。
- 管理卡负责结果：实际耗时、结果文件、交付路径和完成证据。
- 锁定只表示内容是否锁定，不单独授予生成权限；只有 可执行: true 才能进入提交闸门。

### 统一状态机

审批状态：待确认 → 已确认

可执行：false → true

提交状态：未提交 → 已提交

生成状态：未生成 → 生成中 → 已生成 / 生成失败

交付状态：未交付 → 已复制 → 已交付

失败、缺素材或用户撤回时，保留原始证据并回到对应的待确认/阻塞状态，不用“已完成”覆盖问题。

## 评分口径

- 笑点评分：设定反差、角色错位、台词是否真正好笑。
- 爆点评分：开场抓力、结尾画面或台词是否足够突然。
- 16 分以上才进入优先打磨区；低于 16 分先不做生成。
