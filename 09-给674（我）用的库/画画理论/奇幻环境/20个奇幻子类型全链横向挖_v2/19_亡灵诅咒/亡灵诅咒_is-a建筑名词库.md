# 亡灵诅咒 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：死者未安息、被诅咒的延续、亡灵的空间。

---

## v0 空间母体层

### 地下墓殿
is-a 死者地下宫殿
由无数层地下墓穴组成的庞大陵墓——拱顶的支撑柱是用白骨加固的——石棺排列成街区的样式——像一座地下城市
可用于场景：地下陵墓 / 亡灵都市 / 死者之国

### 黑墓回廊
is-a 漆黑墓道
没有照明的地下长廊——两侧墙壁是砌成人字形的暗色墓砖——每隔几米有一个空壁龛（曾放油灯或遗骨）
可用于场景：漆黑走廊 / 墓道前行 / 壁龛中的空洞

### 亡灵王座
is-a 死者的王位
一座由骨与黑石构成的王座——坐垫是暗红色的（曾是什么织物已不可辨）——椅背顶端的装饰是一个闭合的眼睑轮廓
可用于场景：死者之王 / 被诅咒的皇权 / 亡者之地的心脏

### 墓园钟楼
is-a 墓园中的塔
建在古老墓园中的钟楼——钟的鸣响不按小时而是按死者的人数——钟绳穿过一系列的滑轮延伸到墓园各处
可用于场景：墓园钟声 / 死亡的报时 / 钟与葬礼

### 骨墙要塞
is-a 骨墙筑成的堡垒
用千年的遗骨砌成的防御工事——骨墙中嵌着头骨——骨头的排列形成几何图案——要塞的城门是用大腿骨束成的
可用于场景：骨垒成的墙 / 防御与死亡的结合 / 白骨阵

### 灵魂井
is-a 聚魂井
一口直径巨大的圆井——井壁有台阶螺旋向下——井底不是水而是淡蓝色的冷光（灵魂的浓度呈现为光）
可用于场景：灵魂之井 / 向下走近光 / 灵体聚集处

### 旧城墓区
is-a 被死亡占据的城市
曾经是活人居住的城市——在瘟疫之后整个城区变成了墓区——房屋被改造成墓室——每栋房子里都住着死人
可用于场景：死亡之城 / 房中有棺 / 生人勿入

### 诅咒礼拜堂
is-a 被诅咒的教堂
教堂内所有圣像被倒置安装——墙面用血字写满了诅咒——圣坛上不是十字架而是一个倒吊的骨架
可用于场景：渎神圣堂 / 诅咒仪式 / 不敢久留

### 尸骨桥
is-a 白骨桥梁
横跨峡谷的桥——桥体本身是用数以万计的股骨与肋骨编织而成的——走在桥面上能透过骨缝看到下面的深渊
可用于场景：骨桥过峡 / 每一步都踩在骨上 / 摇摇欲坠

### 夜雾墓道
is-a 夜间墓地通道
墓园中连接各处的小径——终年被一种淡蓝色的薄雾笼罩——雾很冷——小径两侧的墓碑像是站立的人影
可用于场景：夜墓穿行 / 蓝雾笼罩 / 墓碑如人

## v1 典型空间层（以地下墓殿为上位）

### 地下墓殿废墟
is-a 废弃地下陵墓（上位：地下墓殿）
墓殿的某些区域发生了坍塌——石棺被砸碎——骨架散落在碎石中——墙上的骨雕断落
可用于场景：陵墓崩坏 / 死者被打扰 / 古代的坍塌

### 地下墓殿圣所
is-a 废弃死者圣堂（上位：地下墓殿）
墓殿最深处的小圣堂——祭台上放的不是神像而是一个空王冠——王冠是用黑色的细枝编成的
可用于场景：死者朝拜 / 空王冠 / 谁曾统治这里

### 地下墓殿大厅
is-a 废弃墓厅（上位：地下墓殿）
存放最多石棺的大厅——棺盖大部分已被撬开——棺内空无一物——骨都去哪了
可用于场景：空棺成列 / 棺材开着 / 死者出走

### 地下墓殿回廊
is-a 废弃墓廊（上位：地下墓殿）
壁龛中的头骨被移走了——只剩下头骨底部的圆形凹陷——凹陷中有黑色的油脂沉淀
可用于场景：空头骨位 / 像眼睛的空洞 / 油脂痕迹

### 地下墓殿祭坛
is-a 废弃墓祭台（上位：地下墓殿）
祭祀用的石台——台面上有干涸的黑色流体痕迹——台面四角有插蜡烛的凹孔——但蜡烛只剩下黑色烛泪
可用于场景：停祭的祭台 / 黑色烛泪 / 仪式中断

### 地下墓殿庭院
is-a 废弃地下庭院（上位：地下墓殿）
地下墓殿中少有的露天空间——阳光从上方洞口射入——阳光照到的石面上长出了青苔——唯一有生机的地方
可用于场景：阳光入地 / 墓中的生机 / 唯一的光

### 地下墓殿钟楼
is-a 废弃墓钟（上位：地下墓殿）
墓地的钟——钟已停——但钟绳还在——有人拉动钟绳时发出的不是钟声而是摩擦的吱嘎声
可用于场景：不再响的钟 / 只有绳子摩擦声

### 地下墓殿地下层
is-a 墓下之墓（上位：地下墓殿）
墓殿下方还有一层——更古老的墓葬——这一层的风格更原始——石棺是直接凿在岩床上的
可用于场景：更古老的地下 / 原始葬法 / 双层的死者

### 地下墓殿入口
is-a 墓殿大门（上位：地下墓殿）
巨大的石门——门上用浮雕刻着警告语（已不可读）——门轴已经锈蚀导致门只能开到半人宽的缝隙
可用于场景：半开的巨门 / 只有侧身能进 / 警告已不可读

### 地下墓殿核心区
is-a 墓殿心脏（上位：地下墓殿）
墓殿最中心的位置——一个由骨粉画成的巨型圆环——环内没有石棺、没有任何东西——只有地面上一个凹陷（像膝盖跪出的痕迹）
可用于场景：骨粉环 / 中心的跪痕 / 核心的空

## v2 状态侵蚀层（以地下墓殿废墟为上位）

注意：亡灵诅咒的侵蚀——死人世界在腐烂过程中释放物质。这里的"侵蚀"不是外来而是内在的死亡物质的转变。

### 地下墓殿废墟被花蔓侵蚀
is-a 骨花（上位：地下墓殿废墟）
从骨骸缝隙中开出的花——花瓣是半透明的白色——像骨头磨成的薄片做成的花
可用于场景：白骨之花 / 半透明白 / 从骨中出

### 地下墓殿废墟被荆棘缠绕
is-a 亡灵棘（上位：地下墓殿废墟）
从地底伸出的干枯根状结构——不是植物——是被法力扭曲过的骨骼变成了荆棘的形状
可用于场景：骨棘 / 骨骼化棘 / 缠绕的骨头

### 地下墓殿废墟被树根穿刺
is-a 根缠骨（上位：地下墓殿废墟）
树根穿入墓穴——缠住了骨骸——根与骨缠绕在一起再也分不开——植物在吸取骨质中的养分
可用于场景：根与骨缠绕 / 植物在消化死者

### 地下墓殿废墟被苔藓覆盖
is-a 骨苔（上位：地下墓殿废墟）
浅灰色苔藓——与骨头的颜色一致——苔藓在骨头上生长后苔与骨同色难以区分——像骨头自己长了绒毛
可用于场景：骨与苔同色 / 骨长毛了 / 边界的消失

### 地下墓殿废墟被菌丝寄生
is-a 暗光菌（上位：地下墓殿废墟）
发出暗紫色光的菌丝从石棺的缝隙中溢出——菌丝在黑暗中勾勒出骨架的轮廓——像光在画骨
可用于场景：紫光描绘骨架 / 菌丝画出死者的形状

### 地下墓殿废墟被黑雾吞没
is-a 死雾（上位：地下墓殿废墟）
从地下墓穴深处升起的浅灰色雾气——雾气发冷——吸入喉咙有轻微的刺痛感——雾中有微弱的呜咽声
可用于场景：死者之雾 / 冷雾 / 雾中有声音

### 地下墓殿废墟被冰晶封存
is-a 霜骨（上位：地下墓殿废墟）
冬季水汽在半露的骨骸上结霜——骨头被白霜包裹——骨与霜形成白色的复合结构
可用于场景：骨上结霜 / 白色叠加白色 / 霜的装饰

### 地下墓殿废墟被血迹污染
is-a 暗液（上位：地下墓殿废墟）
从石棺缝隙中渗出的暗红色液体——不是鲜血——是尸体分解过程中组织液与棺内的色素混合的结果
可用于场景：棺缝渗液 / 尸体的流出物 / 分解的信号

### 地下墓殿废墟被月光空壳化
is-a 月下墓（上位：地下墓殿废墟）
月光照亮了部分墓穴——光在白色的骨头和灰色的石头上形成明亮的反差——月光下的墓地像一座银色雕塑园
可用于场景：月照白骨 / 银色的死亡 / 月下的寂静

### 地下墓殿废墟被星尘异化
is-a 星辰入墓（上位：地下墓殿废墟）
星尘落在了墓穴的开口处——在漆黑的地下墓穴入口处形成了微弱的银光点——像天界的尘埃降临了死者之国
可用于场景：星光入墓 / 墓口的银色 / 天上与地下的交汇

## v3 内部功能空间层（以地下墓殿废墟被花蔓侵蚀为上位——"花蔓"=骨花）

### 地下墓殿废墟被花蔓侵蚀中央空间
is-a 骨花中央（上位：地下墓殿废墟被花蔓侵蚀）
墓殿主厅——骨花从每一具石棺的缝隙中长出——每个石棺顶部都有几朵半透明的白花——死者戴着花
可用于场景：每棺有花 / 亡灵的装饰 / 白花点点棺上

### 地下墓殿废墟被花蔓侵蚀祭坛空间
is-a 骨花祭台（上位：地下墓殿废墟被花蔓侵蚀）
祭台——骨花从祭台台面的黑色流体痕迹中长出——花沿着流痕的方向排列——像用花写出了祭祀的过程
可用于场景：花沿痕长 / 流痕变花道 / 祭台开花

### 地下墓殿废墟被花蔓侵蚀回廊空间
is-a 骨花廊（上位：地下墓殿废墟被花蔓侵蚀）
壁龛——原来放头骨的位置——现在每个壁龛中长出了一朵骨花——花取代了头骨的位置
可用于场景：花在放头的位置 / 骨花代替了骨头

### 地下墓殿废墟被花蔓侵蚀洗礼池
is-a 骨花池（上位：地下墓殿废墟被花蔓侵蚀）
祭台上的石盆——盆中积水——骨花从盆底长出水面——花在水面上开放——根在水中
可用于场景：水中骨花 / 花从水底出 / 透明水中的白花

### 地下墓殿废墟被花蔓侵蚀祈祷室
is-a 骨花室（上位：地下墓殿废墟被花蔓侵蚀）
小圣堂——空王冠上长出了一朵最大的骨花——花从王冠的环中生出一—像是王冠孵化了花
可用于场景：王冠生花 / 花取代了冠 / 空冠上的花

### 地下墓殿废墟被花蔓侵蚀花窗大厅
is-a 骨花窗（上位：地下墓殿废墟被花蔓侵蚀）
——墓殿没有窗。通过天井的开口可以看到灰白的天空——骨花在开口的边缘密集生长——像给天窗镶了一圈白边
可用于场景：天窗花边 / 天光被花镶边 / 白花围住天空

### 地下墓殿废墟被花蔓侵蚀地下墓穴
is-a 骨花墓下层（上位：地下墓殿废墟被花蔓侵蚀）
更古老的墓葬层——骨花从凿在岩床上的石棺中长出——花在极暗的环境中开得更大更白（因为没有竞争）
可用于场景：更下层花更大 / 暗中的白花 / 古老的花

### 地下墓殿废墟被花蔓侵蚀钟楼
is-a 骨花钟（上位：地下墓殿废墟被花蔓侵蚀）
墓钟——骨花从钟的裂缝中开出——花包围了钟的表面——敲钟时花会震动但不会脱落
可用于场景：钟上生花 / 花与钟共响

### 地下墓殿废墟被花蔓侵蚀圣像墙
is-a 骨花墙（上位：地下墓殿废墟被花蔓侵蚀）
骨粉画的圆环——骨花沿着圆环的线条生长——花重新勾勒了圆环的轮廓——线条由花保存
可用于场景：花沿着骨粉画 / 花保存了消失的画

### 地下墓殿废墟被花蔓侵蚀忏悔室
is-a 骨花角（上位：地下墓殿废墟被花蔓侵蚀）
角落——骨花在这里形成了一个半圆形的小窝——花从地面向墙角蔓延堆积——像一个白色的花坐垫
可用于场景：角落花窝 / 白色花垫 / 可以坐在花中

## v4 最终复合场景层（中央空间10种变体）

### 地下墓殿废墟被花蔓侵蚀中央空间复合场景
is-a 骨花心标准版（上位：中央空间）
骨花从每一个石棺、每一个裂缝中长出——整个大厅像被白色的花海淹没——花沿着石棺的排列形成白色的行
可用于场景：白花覆棺 / 花海墓厅 / 标准大全景

### 地下墓殿废墟被花蔓侵蚀中央空间镜面版
is-a 骨花心倒影版（上位：中央空间）
地面积水——倒影中的骨花变成了浅蓝色（因为天空的颜色反射）——水上花白水下花蓝
可用于场景：水上白水下蓝 / 花的双重色彩

### 地下墓殿废墟被花蔓侵蚀中央空间沉水版
is-a 骨花心水漫版（上位：中央空间）
地下水渗出——骨花泡在水中变得半透明——花瓣在水中像薄冰——花在水中的姿态像白色的水母
可用于场景：花在水中如冰 / 半透明花 / 白色水母般的花

### 地下墓殿废墟被花蔓侵蚀中央空间月光版
is-a 骨花心月夜版（上位：中央空间）
月光从上方天井射入——花在月光中发光——骨花像一盏盏小灯——白花变成了光源
可用于场景：花在月中自发光 / 花作灯 / 月光激活了花

### 地下墓殿废墟被花蔓侵蚀中央空间黑水版
is-a 骨花心黑液版（上位：中央空间）
从棺中渗出的暗色液体——白花被液体从根部开始染黑——花瓣的根部变成灰色尖端还是白色
可用于场景：花从根开始黑 / 渐变的灰 / 死亡在染花

### 地下墓殿废墟被花蔓侵蚀中央空间环形祭坛版
is-a 骨花心仪式版（上位：中央空间）
有人在中央用石子摆了一个环——环内放着一小束新鲜的骨花（而不是采来的）——是有人把自己花放在了那里
可用于场景：新花环 / 有人献花给已故者 / 还有人记得

### 地下墓殿废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 骨花心泉涌版（上位：中央空间）
大厅地面裂开——涌出清澈的地下水——水冲开了骨花的底层——露出下面被花覆盖的原始石棺——原来石棺一直在这里
可用于场景：清泉洗出棺 / 花下的真实 / 水揭示埋葬

### 地下墓殿废墟被花蔓侵蚀中央空间白花漂浮版
is-a 骨花心飞瓣版（上位：中央空间）
骨花的花瓣大面积脱落——在空中缓慢飘浮下落——经过月光时花瓣半透明得像魂体
可用于场景：花瓣如魂 / 慢飘的花瓣 / 半透明的白

### 地下墓殿废墟被花蔓侵蚀中央空间枯井版
is-a 骨花心井口版（上位：中央空间）
中央的地面有一个掩盖的圆形——掀开石板——下面是一个垂直的井口——井口边缘没有花（花避开了这里）
可用于场景：石板下的井 / 花避开 / 下面有别的

### 地下墓殿废墟被花蔓侵蚀中央空间终帧版
is-a 骨花心爆发版（上位：中央空间）
所有的骨花同时从花茎上脱落——花瓣如雪一般覆盖了整个空间——在黑暗的墓殿中漫天的白——死亡的最后一场雪
可用于场景：花雪满天 / 墓中的白色风暴 / 最后的绽放
