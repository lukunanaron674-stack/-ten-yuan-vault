# 血源诅咒 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：维多利亚+血+病态医学+长夜猎杀。

---

## v0 空间母体层

### 血月教堂
is-a 血月下的宗教建筑
哥特式石砌教堂——但月光是血红色的——教堂的尖塔在血月下呈暗红色剪影、彩色玻璃透出的光不是彩色而是红的
可用于场景：血月下的教堂 / 不洁的礼拜 / 入口

### 疫病街区
is-a 瘟疫蔓延的街巷
砖石房屋拥挤的狭窄巷道——门窗被封死（用木板从内部钉上）、墙脚堆着焚烧过的衣物、空气中有草药与腐败混合的气味
可用于场景：疫区穿行 / 封锁的窗口 / 无人但有人声

### 教会医院
is-a 医学与宗教混合机构
原本是教堂后被改造成医院——长排的病床代替了长椅——圣坛位置现在是手术台——墙上同时挂着十字架与医疗器械
可用于场景：医疗场景 / 实验性治疗 / 信仰与科学的边界

### 狩猎广场
is-a 猎人聚集地
圆形石砌广场——地面有黑色的焚烧痕迹、四周的铁制路灯上挂着熄灭的火盆、广场中央有一座持枪猎人的铜像（已发绿生锈）
可用于场景：猎人集会 / 出发前 / 战前广场

### 血瓶工坊
is-a 血液加工场所
闷热的地下室——成排的玻璃瓶架、桌上放着采血与注血的工具、墙角有冷却池（里面是红色的液体）、空气中弥漫着铁味
可用于场景：血制作场景 / 不道德的医疗 / 流程展示

### 地下诊所
is-a 非法医疗场所
隐藏在墓地下面的秘密诊所——用烛光照明、手术台周围环绕着排水槽、墙上的病历记录着"治疗"前后的对比——
可用于场景：地下手术 / 禁忌研究 / 回不了头的病人

### 钟楼病房
is-a 钟楼里的隔离病房
教堂钟楼的每一层都被改成了病房——床沿墙摆放、钟的位置被移除挂上了输液瓶——钟声再也不会在这座楼里响起
可用于场景：垂直病区 / 每一层都有人躺着 / 钟楼不再鸣

### 尸车长街
is-a 运送尸体的街道
从医院后门到墓地的固定路线——路面上有黑色的推车辙印、路边堆着待烧的衣物与杂物、夜晚这条街无人敢走
可用于场景：死亡路线 / 夜的禁忌 / 覆盖的辙印

### 红雾桥
is-a 血雾笼罩的桥
连接两个街区的石桥——从桥下的水面上升腾起淡红色的雾气——桥的栏杆上挂着褪色的祭品（干枯的花环与布条）
可用于场景：雾桥穿行 / 不可见的水面 / 祭物挂栏

### 猎人墓园
is-a 猎人长眠处
被铸铁围栏圈起的小墓园——墓碑上刻的不是名字而是被猎杀的怪物名字——墓园中央有一把插在石头中的残剑
可用于场景：猎人终局 / 墓志铭是怪物名 / 武器成墓碑

## v1 典型空间层（以血月教堂为上位）

### 血月教堂废墟
is-a 废弃血教堂（上位：血月教堂）
尖塔已倒塌了一半——砸穿了教堂的屋顶——彩色玻璃全部碎裂、地面上有碎片和灰尘——讲道坛被倒下的横梁压碎
可用于场景：教堂已塌 / 圣坛被梁压碎 / 神的房子破了

### 血月教堂圣所
is-a 废弃教堂圣坛（上位：血月教堂）
圣坛——神像已面目全非——不是风化的、是被人为敲掉了脸——神像的手也被折断——只剩一个无脸无手的存在
可用于场景：无面神像 / 信仰被砸 / 谁做的

### 血月教堂大厅
is-a 废弃教堂主厅（上位：血月教堂）
长椅散架堆在一侧——地面上有干涸的暗红色大斑——天花板上垂下的不是吊灯而是生锈的铁链——被用来挂过什么东西
可用于场景：长椅堆叠 / 地面血斑 / 挂过什么

### 血月教堂回廊
is-a 废弃教堂侧廊（上位：血月教堂）
侧廊的壁龛中——圣徒的雕像全部被搬走了——只剩壁龛空的凹痕——但每个壁龛底部都有一小堆灰烬（烧过什么）
可用于场景：空龛有灰 / 圣像被取代 / 焚烧的遗迹

### 血月教堂祭坛
is-a 废弃教堂主祭台（上位：血月教堂）
大理石祭台——台面上有数道深深的抓痕（指甲的）、祭台的白石已被染成浅红色（渗透的）、祭台下方的地面有黑色的圆环痕迹
可用于场景：被破坏的祭台 / 台上的抓痕 / 祭台下有圈

### 血月教堂庭院
is-a 废弃教堂中庭（上位：血月教堂）
封闭的方形中庭——地面上的石板松动、石板缝隙中长出的不是草而是一种红色的茎状植物（像血管）、中央的井已干但井壁上有红色锈迹
可用于场景：红茎植物 / 血管草 / 中庭病了

### 血月教堂钟楼
is-a 废弃钟楼（上位：血月教堂）
钟楼已斜、钟体还在但被藤蔓固定住——钟的金属表面有暗红色的斑块（不是锈是血迹氧化后的颜色）
可用于场景：血斑钟 / 斜塔 / 钟还在但已不会响

### 血月教堂地下层
is-a 教堂地下墓穴（上位：血月教堂）
地下墓穴——石棺排列不整齐（被人移动过）、有些棺盖被推开、棺内是空的——空的、壁上有手印（黑色的手印）
可用于场景：开棺空 / 黑手印壁 / 地下被翻过

### 血月教堂入口
is-a 教堂大门（上位：血月教堂）
教堂的橡木大门——门上刻着圣防护符——但防护符被人用刀划出叉——门板有被撞击的凸起（从内部被撞击过）
可用于场景：符咒被毁 / 门被撞凸 / 防不住了

### 血月教堂核心区
is-a 教堂地下试验室（上位：血月教堂）
教堂正下方的隐藏空间——曾经是一个医学实验室——有手术台、解剖工具、浸泡着不明器官的玻璃罐
可用于场景：教堂下的人 / 医学禁忌 / 神的房子下面是人做的事

## v2 状态侵蚀层（以血月教堂废墟为上位）

注意：血源诅咒的侵蚀——血与病本身就是侵蚀源。这些状态不是后来施加的——它们是这里本来就有的。

### 血月教堂废墟被花蔓侵蚀
is-a 血花（上位：血月教堂废墟）
在教堂废墟裂缝中开出的花——花瓣是暗红色的——花在月光下看起来像是凝固的血滴
可用于场景：血之花 / 红瓣散落 / 花如血滴

### 血月教堂废墟被荆棘缠绕
is-a 血棘（上位：血月教堂废墟）
红色的棘刺从墙缝中长出——刺尖是深色的——像有血在刺的尖端凝结
可用于场景：红棘 / 尖端的暗色 / 比普通荆棘更危险的颜色

### 血月教堂废墟被树根穿刺
is-a 血管根（上位：血月教堂废墟）
从地下伸出的根——根是暗红色的、表面有纵向的沟壑、像血管一样蜿蜒在墙面——根与血管难以区分
可用于场景：红根如管 / 根在墙上爬 / 地下的血脉

### 血月教堂废墟被苔藓覆盖
is-a 血苔（上位：血月教堂废墟）
暗红褐色的苔藓覆盖了教堂的北墙——在潮湿的环境中苔藓像一层干涸的血壳
可用于场景：暗红苔壳 / 墙像糊了血 / 北墙的颜色

### 血月教堂废墟被菌丝寄生
is-a 红丝菌（上位：血月教堂废墟）
暗红色的菌丝在手术室的墙上蔓延——菌丝的末端像毛细血管一样分叉——看起来像是墙在重新生长血管系统
可用于场景：菌丝如血管 / 墙上的循环系统 / 建筑在长"肉"

### 血月教堂废墟被黑雾吞没
is-a 红雾（上位：血月教堂废墟）
教堂周围的雾呈现出淡红色——像是血被雾化在了空气中——雾吸入时有淡淡的铁味
可用于场景：红色雾 / 闻铁味 / 雾有颜色

### 血月教堂废墟被冰晶封存
is-a 血晶（上位：血月教堂废墟）
红色的晶体（不是冰是矿物与血反应形成的结晶）从地面长出——晶体内部有深红色的竖纹——像冻在晶中的血丝
可用于场景：血晶从地生 / 红色晶体柱 / 血丝冻在里面

### 血月教堂废墟被血迹污染
is-a 层层血迹（上位：血月教堂废墟）
地面上多层的干涸血迹堆叠——旧血迹被新血迹覆盖——新的在上面、旧的渗入石面——地面的颜色从灰变成暗褐
可用于场景：血叠血 / 地面成了褐色 / 痕迹的厚度

### 血月教堂废墟被月光空壳化
is-a 血月空壳（上位：血月教堂废墟）
血月的光照在教堂上——一切都被染成红色——红色的废墟在红色的月光下轮廓变得模糊——像建筑在融化在月光里
可用于场景：红光照红墙 / 血色融化 / 红中更红

### 血月教堂废墟被星尘异化
is-a 苍白星尘（上位：血月教堂废墟）
银白色的星尘落在了血色的废墟上——星尘的白与血色的红形成刺眼的对比——像是想要净化但净化不了
可用于场景：白尘落血红 / 对照强烈 / 无法覆盖的白

## v3 内部功能空间层（以血月教堂废墟被花蔓侵蚀为上位——"花蔓"=血花）

### 血月教堂废墟被花蔓侵蚀中央空间
is-a 血花中央（上位：血月教堂废墟被花蔓侵蚀）
教堂的中殿——暗红色的花从讲道坛的台阶上成片长出——花沿着中央过道的方向排成两列（像婚礼的花瓣队列但颜色是红的）
可用于场景：红花开如流血 / 中央过道的红花列 / 血色通道

### 血月教堂废墟被花蔓侵蚀祭坛空间
is-a 血花祭台（上位：血月教堂废墟被花蔓侵蚀）
祭台上——暗红色的花从抓痕中长出——每一条抓痕对应一朵花——像祭台在用自己的伤痕开花
可用于场景：抓痕中开花 / 伤口中开出的花 / 伤痕变花茎

### 血月教堂废墟被花蔓侵蚀回廊空间
is-a 血花侧廊（上位：血月教堂废墟被花蔓侵蚀）
侧廊——暗红色的花从壁龛的灰烬中长出——每个壁龛中开出一朵——像每个被搬走的圣徒的位置被花取代
可用于场景：空龛红花 / 取代圣徒的花 / 每一龛一朵

### 血月教堂废墟被花蔓侵蚀洗礼池
is-a 血花洗礼池（上位：血月教堂废墟被花蔓侵蚀）
洗礼用的石盆——盆中积着雨水——雨水被盆底的花瓣染成淡红色——水是半透明的红
可用于场景：淡红洗礼水 / 花瓣染色 / 水中有花的魂

### 血月教堂废墟被花蔓侵蚀祈祷室
is-a 血花小室（上位：血月教堂废墟被花蔓侵蚀）
小祈祷室——祷告用的跪垫已腐烂——花从跪垫的位置长出——像是在代替祈祷者长跪
可用于场景：跪垫长花 / 花的代替祷告 / 无人但花在跪

### 血月教堂废墟被花蔓侵蚀花窗大厅
is-a 血花彩窗（上位：血月教堂废墟被花蔓侵蚀）
花窗的彩色玻璃碎裂后——血花的花蔓填补了窗上的空隙——透过花蔓的光是暗红色的——花窗的新颜色是自然的红色
可用于场景：花蔓填窗 / 自然红彩窗 / 新的彩色

### 血月教堂废墟被花蔓侵蚀地下墓穴
is-a 血花墓室（上位：血月教堂废墟被花蔓侵蚀）
地下墓穴——石棺的棺盖上开出了暗红色的花——每一朵花都长在石棺的腹部位置（对应死者的胸腔位置）
可用于场景：花从棺长 / 花在胸腔位置 / 死者的呼吸

### 血月教堂废墟被花蔓侵蚀钟楼
is-a 血花钟塔（上位：血月教堂废墟被花蔓侵蚀）
斜钟楼上——血花从钟的血斑中开出——花的颜色与钟上的血斑同色——花与钟锈融为一体
可用于场景：花从钟锈出 / 钟的血斑生花 / 花钟同色

### 血月教堂废墟被花蔓侵蚀圣像墙
is-a 血花圣像（上位：血月教堂废墟被花蔓侵蚀）
无面神像——血花从神像的断颈处长出——像是神像重新长出了"头"——一个花的头
可用于场景：无面神长了花头 / 断口的花 / 神像戴上花冠

### 血月教堂废墟被花蔓侵蚀忏悔室
is-a 血花忏悔（上位：血月教堂废墟被花蔓侵蚀）
木制忏悔室已开始腐烂——花从隔板的缝隙中长出、两侧都有花——像是忏悔者与神父之间开出了花
可用于场景：隔板生花 / 忏悔者与倾听者之间的花 / 花的见证

## v4 最终复合场景层（中央空间10种变体）

### 血月教堂废墟被花蔓侵蚀中央空间复合场景
is-a 血花心标准版（上位：中央空间）
中殿的暗红色花从讲道坛一直铺到大门——地面像铺了一条红色的花毯——花毯的尽头讲道坛上是空的
可用于场景：红花毯空讲坛 / 花的指引 / 标准大全景

### 血月教堂废墟被花蔓侵蚀中央空间镜面版
is-a 血花心倒影版（上位：中央空间）
地面的积水映出暗红色的花和破碎的穹顶——水中的红色更深——像是水下才是真正的血源
可用于场景：水中更红 / 花的水下颜色更深 / 倒影的血

### 血月教堂废墟被花蔓侵蚀中央空间沉水版
is-a 血花心水淹版（上位：中央空间）
地下水从祭台下涌出——暗红色的花泡在水中——水被染成淡淡的粉红色——花在水中的姿态像漂流的血细胞
可用于场景：粉水红花 / 花在水中如血细胞 / 水与花的混合物

### 血月教堂废墟被花蔓侵蚀中央空间月光版
is-a 血花心月夜版（上位：中央空间）
血月的光从破碎屋顶射入——暗红色的花在红月光下变成了深紫色——花与月光变成了同色系的不同深浅
可用于场景：紫花红月 / 深浅不同但同色 / 花月一色

### 血月教堂废墟被花蔓侵蚀中央空间黑水版
is-a 血花心黑液版（上位：中央空间）
从地下涌出的不是水而是黑色粘稠液体——花被液体覆盖变成黑红色——花的颜色接近消失——红花变暗花
可用于场景：黑液淹没红花 / 颜色消失 / 暗色的吞噬

### 血月教堂废墟被花蔓侵蚀中央空间环形祭坛版
is-a 血花心仪式版（上位：中央空间）
有人在祭台上用暗红色的花瓣摆了一个圆形——花瓣已干枯卷曲——但摆成的圆环形清晰可见——仪式痕迹
可用于场景：干花环形 / 花瓣的仪式 / 有人来过

### 血月教堂废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 血花心泉涌版（上位：中央空间）
祭台正下方的地面裂开——涌出的水是红色的（不是血是含铁量极高的地下水）——水在花丛中冲出一条红色水道
可用于场景：红水流过花 / 铁水与花 / 自然的红与花的红

### 血月教堂废墟被花蔓侵蚀中央空间白花漂浮版
is-a 血花心白瓣版（上位：中央空间）
——不是白花。暗红的花瓣脱落后从上方飘下来——在血月的光线下看起来是黑色的——黑红色的花雨
可用于场景：暗瓣如雨 / 黑色花瓣从天降 / 花雨的暗色

### 血月教堂废墟被花蔓侵蚀中央空间枯井版
is-a 血花心井口版（上位：中央空间）
