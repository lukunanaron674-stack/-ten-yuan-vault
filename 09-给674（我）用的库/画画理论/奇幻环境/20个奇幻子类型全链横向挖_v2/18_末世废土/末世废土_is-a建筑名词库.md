# 末世废土 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：资源匮乏、旧世界遗迹、生存第一、一切都在锈蚀。

---

## v0 空间母体层

### 铁皮避难城
is-a 废土聚居地
用废弃的金属板、集装箱与预制板拼凑成的城墙——城内是帐篷与铁皮屋的丛林——中央有一座用钢筋焊成的瞭望塔
可用于场景：废土主城 / 聚集地 / 幸存者的家

### 沙暴交易站
is-a 废土贸易市场
在公路交叉口的临时市集——用支起的布棚与木板搭建的摊位——交易水、弹药、零件和药品——周围停着改装车辆
可用于场景：交易 / 易货 / 三教九流

### 废弃高速路
is-a 裂开的公路
曾经的高速公路——路面布满龟裂——裂缝中长出耐旱植物——车辆残骸横七竖八地堵塞了道路
可用于场景：在路上 / 穿越 / 车队行进

### 残骸都市
is-a 殉难的大城市
曾经是摩天楼林立的都市——现在建筑只剩下钢筋混凝土的骨架——玻璃已全部碎裂——街道被倒塌的建筑堵塞
可用于场景：大城废墟 / 空无一人的摩天楼 / 残壳

### 污染水厂
is-a 废弃净水设施
巨大的锈蚀水塔与管道——净化池已干涸、池底覆盖着黑色的沉积物——偶尔滴落的水有刺鼻的化学味
可用于场景：寻找水源 / 危险区域 / 旧文明的遗迹

### 废土市场
is-a 废品交易中心
被高墙围合的堆满废品的空地——废品按类别堆成山（金属/塑料/橡胶/电子垃圾）——工人在拆解有用的零件
可用于场景：垃圾山 / 回收 / 交易零件

### 加油站堡垒
is-a 改装加油站
废弃的加油站被改造成防御据点——用沙袋和铁板加固了外墙——加油机已损坏、但地下储油罐可能还有余油
可用于场景：防御点 / 检查站 / 补给点

### 车队营地
is-a 移动车队宿营地
由十几辆改装车辆围成的环形营地——车头朝外、车厢相连形成围墙——营地中央有火坑
可用于场景：车队停靠 / 野外过夜 / 壁垒

### 地下避难所
is-a 末日地下室
冷战时期的地下掩体——厚重铁门、狭窄通道、简陋的居住隔间、空气过滤系统还在运转（发出嗡嗡声）
可用于场景：避难所内部 / 幸存者的长期居所 / 资源有限

### 风蚀广播塔
is-a 废弃信号塔
一座孤立在荒原上的铁塔——塔上挂着断裂的天线与电缆——塔基有被撬开的设备箱（内部的电子元件已被拆走）
可用于场景：地标 / 高处 / 可能的信号

## v1 典型空间层（以铁皮避难城为上位）

### 铁皮避难城废墟
is-a 废弃避难城（上位：铁皮避难城）
避难城被攻破或遗弃后——铁皮墙倒塌了部分——城内帐篷被吹散——空地上散落着被翻过的物资箱
可用于场景：避难城毁了 / 幸存者撤离 / 被搜刮过

### 铁皮避难城圣所
is-a 废弃祈祷处（上位：铁皮避难城）
废墟中用回收材料搭建的小教堂——用焊接的铁片做的十字架——长椅是废弃的汽车座椅——讲台是用堆叠的轮胎做的
可用于场景：废土信仰 / 祈祷还在继续 / 幸存者的精神寄托

### 铁皮避难城大厅
is-a 废弃议会厅（上位：铁皮避难城）
最大的铁皮屋——曾作为避难城的议事厅——现在桌翻椅倒——地上的文件被踩烂——墙上钉着褪色的规则告示
可用于场景：集会的残骸 / 秩序散了 / 废土的议会

### 铁皮避难城回廊
is-a 废弃金属廊（上位：铁皮避难城）
由金属板搭成的通道——两侧的板面被撞击出凹陷——通道中散落着弹壳与空罐头
可用于场景：战后的通道 / 有人守过 / 交战痕迹

### 铁皮避难城祭坛
is-a 废弃分配站（上位：铁皮避难城）
曾是物资分配点——柜台被砸——残余的罐头与水瓶被踩扁——墙上写着"没有水了"
可用于场景：分配站的末日 / 物资耗尽 / 墙上的最后消息

### 铁皮避难城庭院
is-a 废弃空场（上位：铁皮避难城）
城内的公共空地——地面被踩实——中央有一个用油桶改成的火盆——盆中还有未燃尽的衣物（曾用来取暖？还是焚烧什么）
可用于场景：火盆余烬 / 公共空地 / 无人的聚集点

### 铁皮避难城钟楼
is-a 废弃瞭望塔（上位：铁皮避难城）
焊接金属塔——塔顶已变形弯曲——塔上挂着一口用氧气瓶改成的钟——敲钟用的铁棒还系在旁边
可用于场景：危塔 / 还能敲的警钟 / 瞭望台

### 铁皮避难城地下层
is-a 废弃储藏室（上位：铁皮避难城）
半地下的储藏室——铁门已扭曲变形——货架倒了一地——地面上散落着罐头和干粮的碎片——被老鼠啃过
可用于场景：储粮被毁 / 地下被鼠侵入 / 最后的储备没了

### 铁皮避难城入口
is-a 避难城大门（上位：铁皮避难城）
由铁皮焊接的大门——门上用红漆写着"禁止入内"——但现在门已歪斜——门下有一堆被丢弃的废弃物
可用于场景：被突破的大门 / 禁止的牌子已失效

### 铁皮避难城核心区
is-a 避难城水井（上位：铁皮避难城）
避难城的命脉——手动水泵——井口周围的地面是湿的（说明还能出水）——但井口旁边的铁桶里只有很少的水
可用于场景：水还在 / 但不够 / 命脉衰弱

## v2 状态侵蚀层（以铁皮避难城废墟为上位）

注意：末世废土的侵蚀——不是生物再生而是"风化"与"锈蚀"——旧物在衰败中呈现新的用途。

### 铁皮避难城废墟被花蔓侵蚀
is-a 锈花（上位：铁皮避难城废墟）
金属板表面锈蚀出的橙色花纹——像花一样在铁皮上绽放——锈花是铁的另一种形态
可用于场景：铁锈成花 / 金属在败中成画

### 铁皮避难城废墟被荆棘缠绕
is-a 金属丝棘（上位：铁皮避难城废墟）
从破碎的金属板上翘起的铁皮边缘——撕裂的铁片像荆棘一样锋利——不是植物是工业品变成的荆棘
可用于场景：铁皮棘 / 工业品的自残 / 边缘锋利

### 铁皮避难城废墟被树根穿刺
is-a 旱根（上位：铁皮避难城废墟）
在裂缝中生长的耐旱灌木的根——根细而坚韧——从铁皮板与混凝土的缝隙中钻出——根缠住了铁板
可用于场景：旱根缠铁 / 自然与工业的纠缠

### 铁皮避难城废墟被苔藓覆盖
is-a 沙苔（上位：铁皮避难城废墟）
灰绿色的地衣苔藓在铁皮表面形成一层薄壳——像绿色的锈——苔藓在铁上生长比在石上更好
可用于场景：绿壳覆铁 / 工业表面被自然覆盖

### 铁皮避难城废墟被菌丝寄生
is-a 霉菌蔓延（上位：铁皮避难城废墟）
暗色霉斑在潮湿的角落扩散——霉斑呈放射状从中心向外延伸——像废弃的秩序在生物层面崩溃
可用于场景：霉斑扩散 / 角落的生物分解

### 铁皮避难城废墟被黑雾吞没
is-a 沙尘雾（上位：铁皮避难城废墟）
干热的气候使细沙尘在风的吹动下形成褐色的尘雾——遮蔽了大部分光线、让人咳嗽
可用于场景：沙尘弥漫 / 废土天气 / 能见度低

### 铁皮避难城废墟被冰晶封存
is-a 霜铁（上位：铁皮避难城废墟）
冬季寒夜——水汽在铁皮上结成白霜——铁皮上原本的锈色被白霜一层层遮盖——铁在霜下继续锈
可用于场景：霜盖锈铁 / 铁在霜下继续腐

### 铁皮避难城废墟被血迹污染
is-a 锈血（上位：铁皮避难城废墟）
——锈与血的颜色在废土上难以区分。锈就是红色的——血也是红色的——墙上的深红色斑点分不清是锈还是血迹
可用于场景：血色与锈色不分 / 废土的痕迹

### 铁皮避难城废墟被月光空壳化
is-a 月下铁影（上位：铁皮避难城废墟）
月光下铁皮避难城反射着冷光——金属碎片在月光下像碎银——阴暗的铁锈色被月掩盖——只剩银色与黑色
可用于场景：月下铁城银白 / 锈色被月光清洗

### 铁皮避难城废墟被星尘异化
is-a 星尘镀铁（上位：铁皮避难城废墟）
星尘落在废铁上——铁皮表面泛起一层银蓝色的光泽——废铁看起来像被重新镀了金属——旧物焕发了不属于它的光亮
可用于场景：星光中的废铁如新 / 被天外之光镀亮的废品

## v3 内部功能空间层（以铁皮避难城废墟被花蔓侵蚀为上位——"花蔓"=锈花）

### 铁皮避难城废墟被花蔓侵蚀中央空间
is-a 锈花中央（上位：铁皮避难城废墟被花蔓侵蚀）
中央空地——地面的铁皮上全部生出了橙色的锈花——锈花像地毯一样覆盖了整个空场——踩上去铁锈碎裂的声音
可用于场景：锈花地面 / 踩碎的声音 / 锈色覆盖

### 铁皮避难城废墟被花蔓侵蚀祭坛空间
is-a 锈花祭坛（上位：铁皮避难城废墟被花蔓侵蚀）
轮胎和铁板搭成的简陋祭坛——锈花沿着焊接的焊缝生长——像燃料沿着缝隙蔓延
可用于场景：焊缝生锈花 / 铁皮祭坛的花边

### 铁皮避难城废墟被花蔓侵蚀回廊空间
is-a 锈花走廊（上位：铁皮避难城废墟被花蔓侵蚀）
金属板通道——两面的铁皮墙上锈花从底向上生长——像墙被一种橙色爬藤植物占领了但其实是铁自己开的花
可用于场景：铁墙生花 / 铁在自焚为橙色

### 铁皮避难城废墟被花蔓侵蚀洗礼池
is-a 锈花水桶（上位：铁皮避难城废墟）
一个大铁桶盛满了雨水——铁桶的内壁已经生锈——水被铁锈染成了浅橙色——水面漂着脱落的锈片
可用于场景：锈水桶 / 橙水 / 铁味

### 铁皮避难城废墟被花蔓侵蚀祈祷室
is-a 锈花小室（上位：铁皮避难城废墟被花蔓侵蚀）
一个小铁皮屋——内部地面长满了锈花——只有门口进来的脚印位置没有锈——说明还有人进来过
可用于场景：有人来过 / 脚印在锈花中 / 铁皮屋里还有人

### 铁皮避难城废墟被花蔓侵蚀花窗大厅
is-a 锈花天窗（上位：铁皮避难城废墟被花蔓侵蚀）
屋顶的铁皮已部分锈穿——光从锈穿的小孔中漏下——在地面形成无数橙色光斑（因为锈孔边缘的颜色过滤了光线）
可用于场景：锈孔漏光 / 橙色光斑 / 锈做的满天星

### 铁皮避难城废墟被花蔓侵蚀地下墓穴
is-a 锈花地窖（上位：铁皮避难城废墟被花蔓侵蚀）
半地下的储藏室——锈花从墙面到地面处处斑点——墙角的架子被锈腐蚀到快要垮塌
可用于场景：到处锈点 / 架子快塌 / 锈的控制

### 铁皮避难城废墟被花蔓侵蚀钟楼
is-a 锈花铁塔（上位：铁皮避难城废墟被花蔓侵蚀）
瞭望塔——塔身的铁架布满橙色锈花——塔顶的氧气瓶钟也被锈覆盖——但钟声还能敲响（橙色的锈片随钟声抖落）
可用于场景：锈塔锈钟 / 敲一敲落锈如雨

### 铁皮避难城废墟被花蔓侵蚀圣像墙
is-a 锈花墙（上位：铁皮避难城废墟被花蔓侵蚀）
铁皮墙上用红漆写的"禁止入内"——现在锈花沿着漆字的笔画生长——像花的根在"读"那些字
可用于场景：锈花读字 / 字在锈中 / 警告被锈覆盖

### 铁皮避难城废墟被花蔓侵蚀忏悔室
is-a 锈花角（上位：铁皮避难城废墟被花蔓侵蚀）
铁皮屋的角落——锈花堆成一个橙色的小丘——像废弃的铁在这个角落自我堆叠
可用于场景：锈堆成丘 / 铁的自我堆积

## v4 最终复合场景层（中央空间10种变体）

### 铁皮避难城废墟被花蔓侵蚀中央空间复合场景
is-a 锈花心标准版（上位：中央空间）
锈花覆盖了整个空场——从边缘到中心密度递增——中央的锈花最厚——踩上去会发出持续的碎裂声
可用于场景：锈花毯中央最厚 / 标准大全景 / 铁锈的同心圆

### 铁皮避难城废墟被花蔓侵蚀中央空间镜面版
is-a 锈花心倒影版（上位：中央空间）
积水中的倒影——铁锈的橙色在水中显得更深——水中倒影的颜色比实物更接近深棕
可用于场景：水中锈色更深 / 橙色变棕 / 水下的锈

### 铁皮避难城废墟被花蔓侵蚀中央空间沉水版
is-a 锈花心积水版（上位：中央空间）
雨水淹没空地——锈花泡在浅水中——水的表面浮着锈色的油膜——花在水下呈现模糊的橙色轮廓
可用于场景：锈花泡水 / 油膜浮在表 / 水下的橙色

### 铁皮避难城废墟被花蔓侵蚀中央空间月光版
is-a 锈花心月夜版（上位：中央空间）
月光下橙色锈花变成灰色——锈的橙色在月光中几乎不可见——只剩下灰色花朵的轮廓
可用于场景：月下锈色消失 / 灰色花影 / 夜抹去了颜色

### 铁皮避难城废墟被花蔓侵蚀中央空间黑水版
is-a 锈花心油污版（上位：中央空间）
不知从何处泄漏的黑色油污覆盖了锈花——橙色被黑色覆盖——花在油中变成黑色——失去最后一点颜色
可用于场景：油盖锈花 / 橙色消失 / 黑色统治

### 铁皮避难城废墟被花蔓侵蚀中央空间环形祭坛版
is-a 锈花心仪式版（上位：中央空间）
有人在锈花中用白色碎石摆了一个圈——圈内锈花被清理干净露出了地面——像清出一块圣区
可用于场景：白圈清地 / 人为的圣区 / 在锈中清出净土

### 铁皮避难城废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 锈花心泉涌版（上位：中央空间）
中央地面裂开涌出水流——水流经锈花——锈花的橙色溶解在水中——水变成了橙色——像橙汁一样流走
可用于场景：锈溶于水 / 橙色水流 / 铁锈泉

### 铁皮避难城废墟被花蔓侵蚀中央空间白花漂浮版
is-a 锈花心飞锈版（上位：中央空间）
干燥的天气使锈花粉末化——风一吹锈花的桔色粉末在空中飞散——整个空间弥漫着铁锈色的粉尘
可用于场景：铁锈粉飘散 / 橙色尘 / 吸进去会呛

### 铁皮避难城废墟被花蔓侵蚀中央空间枯井版
is-a 锈花心井口版（上位：中央空间）
