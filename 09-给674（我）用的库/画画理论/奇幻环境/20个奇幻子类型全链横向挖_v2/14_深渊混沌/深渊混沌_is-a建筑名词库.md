# 深渊混沌 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：向下、吞噬、不成形、不可知、物体在崩溃溶解。

---

## v0 空间母体层

### 深渊井
is-a 无尽竖向洞穴
一个直径约十米的圆形垂直洞穴——边缘的岩石呈螺旋形磨损（像有东西不断从井口缠绕进出）、向下看只有完全的黑暗——没有底
可用于场景：凝视深渊 / 入口 / 深度的诱惑

### 黑雾裂谷
is-a 黑暗峡谷
谷底有黑色的浓雾涌动的峡谷——雾不是自然雾而是从岩壁裂缝中渗出的、雾中有微弱的声音（不是风声）
可用于场景：雾谷穿行 / 不可见的危险 / 黑色雾海

### 无底洞厅
is-a 无底地洞
洞穴中有一个向下的巨大洞孔——洞孔边缘有倒刺状的岩石（像牙齿）、周围的岩壁上有划痕（像是有什么东西在进出）
可用于场景：洞中洞 / 齿状洞口 / 通往更深

### 混沌海沟
is-a 地下混沌海洋
地下的巨大液态空间——液体不是水而是某种暗色的稠密流体（缓慢涌动但不蒸发）、表面的波动非常缓慢像地球的心跳
可用于场景：混沌之海 / 不祥的液体 / 不可触碰

### 坠落阶梯
is-a 向下无尽台阶
一排向下延伸的石头台阶——每一级都比下一级宽一点（像透视被拉伸了）、台阶消失在黑暗中——走上去感觉越走越宽越走越深
可用于场景：无尽头下行 / 步向深渊 / 层级感失常

### 污染巢穴
is-a 混沌生物巢穴
由某种有机物质构成的巢穴——壁面像内脏一样光滑湿润、地面覆盖着半透明的粘液、空气中有甜腥的气味
可用于场景：非人巢穴 / 生物的居住痕迹 / 异质环境

### 异形石林
is-a 非逻辑石柱群
岩石的生长方向不符合重力——有横向/斜向/甚至向上弯曲的、石柱表面有像眼球般的瘤状凸起、地面不平整像被融过
可用于场景：石柱反常 / 多瘤的石头 / 逻辑崩溃的景观

### 熔黑河道
is-a 黑色熔岩流
已经冷却的黑色熔岩形成的河流——河面是波状的凝固形态、在微光下呈黑色玻璃质感、有些缝隙下还隐约透出暗红色的光
可用于场景：凝固的熔岩 / 黑玻璃地面 / 地下仍有热

### 禁区边界
is-a 禁止进入标记
——不是人类设立的边界。地面有一条清晰的分界线——一侧岩石是正常的灰色另一侧变成了深黑色——所有生物本能地停在线外
可用于场景：颜色分界 / 跨越即踏入 / 不可见的警告

### 反重力空洞
is-a 重力异常区域
球形的空间——内部重力方向混乱、地面上的小石子浮在空中、空气中有一种让人眩晕的旋转感、墙壁上有螺旋形的纹路
可用于场景：失重区 / 混乱的物理学 / 东西在天上

## v1 典型空间层（以深渊井为上位）

### 深渊井废墟
is-a 深渊入口遗迹（上位：深渊井）
深渊井口周围——曾有人类的建筑遗迹（围绕井口建的安全围栏）——现在围栏已倾斜断裂、石制的铭牌上文字被磨去、像是被故意的
可用于场景：围栏已毁 / 深渊边缘 / 门口无防

### 深渊井圣所
is-a 深渊祭拜地（上位：深渊井）
开凿在井口边缘岩壁上的壁龛——里面放着早已干枯的黑色祭花——曾有人向深渊献祭以求保佑？还是求它别出来？
可用于场景：祭龛已枯 / 向黑暗祈祷 / 供奉者已不在

### 深渊井大厅
is-a 深渊边缘大厅（上位：深渊井）
紧邻井壁凿出的半圆形大厅——地面向井口微微倾斜、椅子全部朝向井口而不是朝向彼此——都是在看深渊
可用于场景：面朝深渊的座位 / 都想看井 / 集体的凝视

### 深渊井回廊
is-a 深渊环绕廊道（上位：深渊井）
沿着井壁螺旋下行的狭窄廊道——宽度仅容一人通过——外侧是井口深渊、内侧是潮湿的岩壁——每一步都危险
可用于场景：螺旋下行的窄廊 / 一边是深渊一边是墙 / 不回头

### 深渊井祭坛
is-a 深渊祭台（上位：深渊井）
深渊底部（？）的一块突起的岩石平台——不，是从井壁伸向井心的一个石舌——站在上面脚下一半是悬空的下面是可能的无限
可用于场景：悬空祭台 / 站在深渊之上 / 极限位置

### 深渊井庭院
is-a 深渊井口露天区（上位：深渊井）
井口周围被削平的空地——地面上有一圈深黑色的石砖拼成的圆环、圆环的直径正好与井口一样——像呼应
可用于场景：井口呼应圆环 / 与深渊对齐 / 人造环形

### 深渊井钟楼
is-a 深渊警示塔（上位：深渊井）
井口旁边竖立的一根柱子——柱顶有一个早就锈蚀的钟——曾有人用它来预警深渊的变化（发出异响时敲钟）
可用于场景：生锈的警钟 / 不再有人敲 / 无声的预警

### 深渊井地下层
is-a 深渊之下的更深层（上位：深渊井）
——深渊井本身就已经在地下了。这里的"更下层"是井壁上一个横向开口通向另一个洞穴——像深渊的侧室
可用于场景：井壁开口 / 深渊的分支 / 侧向拓展

### 深渊井入口
is-a 深渊的进口（上位：深渊井）
地面上的入口——一座用黑色石头建成的拱门——拱门的形状不是半圆而是被向下拉伸的椭圆形（像被重力拉长了）
可用于场景：椭圆入口 / 被拉长的拱形 / 踏入即下坠

### 深渊井核心区
is-a 深渊中心（上位：深渊井）
井底——如果它有底的话——是井底一个非常狭窄的尖点——像漏斗的底部——那里的黑暗浓稠到像实体
可用于场景：漏斗底 / 黑暗凝结 / 再也下不去

## v2 状态侵蚀层（以深渊井废墟为上位）

注意：深渊混沌的侵蚀——不是被外来物侵蚀而是被深渊本身的本质"感染"。

### 深渊井废墟被花蔓侵蚀
is-a 暗花（上位：深渊井废墟）
在深渊边缘开出的花——花瓣是近乎黑色的深紫色、花蕊是暗红色的——像用深渊的颜色开的花
可用于场景：暗色花开在深渊边缘 / 黑的美丽 / 被深渊同化的植物

### 深渊井废墟被荆棘缠绕
is-a 影棘（上位：深渊井废墟）
从深渊的黑色岩石中长出的黑色棘刺——不是植物是矿物——碳的结晶呈荆棘状从石缝中刺出
可用于场景：黑晶棘 / 矿物的刺 / 岩石自己长刺

### 深渊井废墟被树根穿刺
is-a 深渊根（上位：深渊井废墟）
黑色的根从深渊井底延伸到井口外——根的颜色像烧焦的木头、表面有液态的黑色光泽——不是植物的根
可用于场景：黑根蔓延 / 根从深渊来 / 不可名状

### 深渊井废墟被苔藓覆盖
is-a 暗藓（上位：深渊井废墟）
深绿色的几乎黑色的苔藓——不是覆盖在表面而是从石头内部渗出来、像石头在"出汗"——触摸后手会留下黑色的印迹
可用于场景：黑苔如汗 / 石头渗黑 / 触及留印

### 深渊井废墟被菌丝寄生
is-a 荧光腐丝（上位：深渊井废墟）
发着鬼火般淡绿色光的菌丝——菌丝在黑暗中画出图案——图案看起来像某种语言——用光在写没人能读的东西
可用于场景：绿光菌语 / 菌丝在写什么 / 冷光之字

### 深渊井废墟被黑雾吞没
is-a 浓缩黑暗（上位：深渊井废墟）
这里的雾不是雾——是黑暗的浓度超过了正常空气——像空气被染成了纯黑——进入其中感觉被实体包裹
可用于场景：黑暗成实体 / 被黑色包裹 / 视觉为零

### 深渊井废墟被冰晶封存
is-a 黑曜晶（上位：深渊井废墟）
黑色的半透明晶体从岩壁上长出——包裹住了一些碎石和废弃物——像用黑琥珀封存了深渊的记忆
可用于场景：黑晶包裹 / 黑色琥珀 / 封在黑暗中的物

### 深渊井废墟被血迹污染
is-a 暗色液痕（上位：深渊井废墟）
——不一定是血。井口边缘有黑色的干涸的液体痕迹——从井中涌出过的、在岩石表面留下蜿蜒的流痕
可用于场景：黑液流痕 / 来自深渊的分泌物 / 液体记忆

### 深渊井废墟被月光空壳化
is-a 月照深渊（上位：深渊井废墟）
月光永远照不到井底——月光刚好照亮井口边缘的一圈、井口以内的黑暗与井口以外的月光形成圆的切割——月与暗的边界
可用于场景：月切暗 / 圆圈的光与圆圈的黑 / 边界分明

### 深渊井废墟被星尘异化
is-a 深渊星光（上位：深渊井废墟）
银色的星尘落在了深渊井的入口——但星尘被黑暗吸入——吸入的瞬间星尘的颜色从银变成了黑——光被深渊吸收的过程可见
可用于场景：光被吸入变黑 / 星尘坠入深渊 / 颜色消失

## v3 内部功能空间层（以深渊井废墟被花蔓侵蚀为上位——这里的"花蔓"=暗花）

### 深渊井废墟被花蔓侵蚀中央空间
is-a 暗花中心（上位：深渊井废墟被花蔓侵蚀）
深渊井口边缘——暗花沿着井口生长了一圈——像给深渊戴了一个黑色的花环——花面向井心开放
可用于场景：暗花环井 / 面向黑暗盛开的花 / 深渊戴花

### 深渊井废墟被花蔓侵蚀祭坛空间
is-a 暗坛（上位：深渊井废墟被花蔓侵蚀）
悬空石舌上—暗花从石头的缝隙中钻出—花的根垂向深渊—像吊兰但根是黑的朝向无尽的深处
可用于场景：根垂深渊 / 花在祭坛根去深 / 向下的根

### 深渊井废墟被花蔓侵蚀回廊空间
is-a 暗廊（上位：深渊井废墟被花蔓侵蚀）
井壁螺旋廊道——暗花从外侧的岩壁中探出——花开向深渊——走在廊道中看到的是暗花与无尽的黑暗交织
可用于场景：花朝暗开 / 侧壁的花与外侧的暗 / 花伴行

### 深渊井废墟被花蔓侵蚀洗礼池
is-a 暗池（上位：深渊井废墟被花蔓侵蚀）
井壁上的浅坑中积着黑色的液体——暗花的花瓣漂浮在上面——黑液反射着天空的最后一缕光（但只能反射没有光泽）
可用于场景：黑液漂暗瓣 / 只有漂浮的花能证明这不是纯黑

### 深渊井废墟被花蔓侵蚀祈祷室
is-a 暗龛（上位：深渊井废墟被花蔓侵蚀）
壁龛中——干枯的黑花摆放在本来放祭品的位置——花已枯但形状仍在——曾有人在此祈祷不要发生什么
可用于场景：枯花龛 / 祷告已干 / 曾经的恐惧

### 深渊井废墟被花蔓侵蚀花窗大厅
is-a 暗窗（上位：深渊井废墟被花蔓侵蚀）
——没有窗户因为在地下。井口上方的一个开口——透过暗花的枝干形成的缝隙看出去——外面的天空是紫黑色的（花的颜色过滤了光）
可用于场景：紫黑天窗 / 花滤的光 / 暗色滤镜

### 深渊井废墟被花蔓侵蚀地下墓穴
is-a 深渊葬（上位：深渊井废墟被花蔓侵蚀）
沿着井壁开凿的壁穴——每个壁穴中放着一具蜷缩的人体骨架——骨架的颜色是黑色的——是被深渊染色了
可用于场景：黑骨葬壁 / 骨被深渊染 / 墓葬也属于暗

### 深渊井废墟被花蔓侵蚀钟楼
is-a 暗钟（上位：深渊井废墟被花蔓侵蚀）
锈钟——暗花从钟的裂缝中长出、花包裹了半个钟体——敲响时花的震动让花蕊散出黑色花粉
可用于场景：钟生花 / 敲钟散黑粉 / 报警的花

### 深渊井废墟被花蔓侵蚀圣像墙
is-a 暗浮雕（上位：深渊井废墟被花蔓侵蚀）
岩壁上的天然纹路被暗花沿着轮廓勾勒——像花的根在"读"岩壁上的纹路并"描"了出来
可用于场景：花读岩纹 / 描出的天然图案 / 花的临摹

### 深渊井废墟被花蔓侵蚀忏悔室
is-a 暗角（上位：深渊井废墟被花蔓侵蚀）
井壁上一个凹陷——大小刚好容一个人蜷缩坐进去——凹陷的底部有一朵暗花开着——像是深渊留给人坐的位置也放了花
可用于场景：角落有花 / 蜷缩的位置有陪伴 / 黑暗中的一点暗美

## v4 最终复合场景层（中央空间10种变体）

### 深渊井废墟被花蔓侵蚀中央空间复合场景
is-a 暗花心标准版（上位：中央空间）
深渊井口被暗花包围——天空从井口看进去是一个圆形的亮斑——暗花的花蕊指向井心——像所有花都在引导视线下坠
可用于场景：花指深渊 / 目光随花入井 / 标准大全景

### 深渊井废墟被花蔓侵蚀中央空间镜面版
is-a 暗花心倒影版（上位：中央空间）
——但深渊的黑暗不反射光。水面倒影中只照出天空——没有花的倒影、没有井壁的倒影—像水只反射了不属于深渊的那部分
可用于场景：水只映天不映暗 / 非选择性反射 / 深渊不照镜子

### 深渊井废墟被花蔓侵蚀中央空间沉水版
is-a 暗花心水漫版（上位：中央空间）
地下水淹没了部分井壁——暗花最下面一层泡在了暗色的水中——但花没有变色它本来就是暗的——水与花混为一体
可用于场景：花与水同色 / 暗花暗水 / 界限消失

### 深渊井废墟被花蔓侵蚀中央空间月光版
is-a 暗花心月夜版（上位：中央空间）
月光照到井口——浅层岩石被照成淡灰色——但暗花不反射月光、花在月光下几乎隐形——只剩花茎的影子
可用于场景：花隐形只剩茎影 / 月光下的消失 / 暗色的花不被照亮

### 深渊井废墟被花蔓侵蚀中央空间黑水版
is-a 暗花心深渊液（上位：中央空间）
井中的黑色液体上涨——液面上泛着暗紫色的油膜——暗花浸在液体中的部分开始脱落——花消亡于液
可用于场景：黑液上涨 / 花被液体消化 / 深渊在吃花

### 深渊井废墟被花蔓侵蚀中央空间环形祭坛版
is-a 暗花心仪式版（上位：中央空间）
有人在井口外圈用黑色的卵石摆了一个圆——圆内放着一根熄灭的黑蜡烛——有人来过、向深渊献了什么
可用于场景：黑石圈黑烛 / 还有人献祭 / 仪式仍在继续

### 深渊井废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 暗花心裂液版（上位：中央空间）
井壁的一条新裂缝中涌出了黑色的液体——液体像浓稠的糖浆——沿着井壁缓慢流下流经的暗花全部变黑（更深了）
可用于场景：黑液流壁 / 液体从新裂缝来 / 深渊在渗漏

### 深渊井废墟被花蔓侵蚀中央空间白花漂浮版
is-a 暗花心飞白版（上位：中央空间）
——不是白花、是暗花的花瓣脱落时在空中折射了天空的最后一缕蓝——看起来是白色的（其实是天空的颜色穿过了花）
可用于场景：花借天光成白 / 假白花 / 颜色是骗人的

### 深渊井废墟被花蔓侵蚀中央空间枯井版
is-a 暗花心双重井（上位：中央空间）
在深渊井的井口中心出现了第二个更小的井口——小井直径仅一臂——大井中有小井——深渊在深渊内部
可用于场景：井中井 / 嵌套的黑暗 / 更深

### 深渊井废墟被花蔓侵蚀中央空间终帧版
is-a 暗花心爆发版（上位：中央空间）
深渊井中突然涌出一股气流——暗花被气浪掀飞——花在井口上方炸开变成黑色的烟尘——黑色的烟在天空散开
可用于场景：花爆成黑烟 / 深渊的呼吸 / 黑暗喷涌
