# 矮人地底 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：厚重、规则、功能性优先、矿物与铁器、没有多余的美。

---

## v0 空间母体层

### 地下矿城
is-a 地下矮人城市
掏空山体建成的多层地下城市——粗凿的石壁上嵌着矿物灯照明、街道宽得能并行四辆矿车、到处是金属管道与齿轮传动结构
可用于场景：地下主城 / 矮人文明核心 / 功能性城市

### 地底锻炉
is-a 地下锻造厂
巨大的熔炉嵌在岩壁中——炉口正对着一个石质锻造平台、液压锤由水力齿轮驱动、空气中弥漫着金属与煤烟的气味
可用于场景：铸剑场景 / 工匠登场 / 工业化手作

### 矮人王座厅
is-a 矮人王权大厅
在一整块黑曜石中凿出的王座——王座背后刻着整部矮人历史浮雕、大厅的柱子是方形的没有装饰、柱顶直接支撑岩顶
可用于场景：矮人王接见 / 权力中心 / 岩石中的王权

### 矿脉隧道
is-a 地下采矿隧道
沿着天然矿脉挖掘的隧道——一侧岩壁上裸露着石英与铁矿的混合脉纹、在火把光下闪光、路径随矿脉走向蜿蜒
可用于场景：挖矿之路 / 矿工日常 / 追随矿脉

### 齿轮升降井
is-a 地下垂直运输井
巨大的垂直竖井——中央悬挂着由铁链和齿轮驱动的升降平台、井壁上有规律排列的煤油灯、升降时齿轮声回荡
可用于场景：垂直交通 / 进入深层 / 工业感升降

### 岩浆铸造池
is-a 岩浆铸造车间
直接引岩浆入池的铸造工坊——岩浆从岩缝中流入石槽再分流至多个铸造模具、池边排着冷却中的铸件
可用于场景：熔铸现场 / 热浪场景 / 矮人利用自然力

### 石门要塞
is-a 地下防御要塞
厚达数米的石门——表面包铁、门后有横闩与多重锁链系统、门框是整块花岗岩切割而成、一夫当关
可用于场景：城门守卫 / 防御工事 / 最后防线

### 地下集市
is-a 地下矮人市场
隧道扩大形成的拱形大厅——两侧有石砌的摊位与货架、交易的多是铁器与矿石、火把与炉火照明而不是天光
可用于场景：矮人商业 / 物资交易 / 地下烟火味

### 宝库大厅
is-a 矮人藏宝室
层层下降的石阶通往地下最安全的宝库——每层有巨大石门与锁具、最后到达一个高穹顶大厅、中央堆着金山
可用于场景：财宝山 / 龙的兴趣 / 矮人积累

### 深井机房
is-a 地下机械核心
整个地下城的水泵、通风扇和传动轴集中在这里——巨大的齿轮墙从地面延伸到天花板、机器声轰鸣震耳
可用于场景：机器心脏 / 机械之美 / 轰鸣的宁静

## v1 典型空间层（以地下矿城为上位）

### 地下矿城废墟
is-a 废弃矮人城（上位：地下矿城）
矿城的某些区域已经废弃——铁轨锈蚀、矿车翻倒、煤油灯油耗干、岩壁上剥落下碎屑堆积成小坡
可用于场景：矮人衰退 / 废弃的工业 / 铁锈与静默

### 地下矿城圣所
is-a 废弃矮人圣堂（上位：地下矿城）
矮人的祈祷室——但矮人不拜神他们拜锻炉——圣所中央有一座铸铁的锻炉雕塑已经生锈、炉膛已冷
可用于场景：冷炉 / 信仰冷却 / 铁铸的祭物

### 地下矿城大厅
is-a 废弃矮人大厅（上位：地下矿城）
集会的石厅——长石桌还在、木椅已朽坏坍塌、墙上的金属浮雕被撬走只剩固定钉孔
可用于场景：举杯不再 / 空桌残椅 / 矮人离散

### 地下矿城回廊
is-a 废弃矮人走廊（上位：地下矿城）
连接各区域的走廊——顶上每隔几米有一盏熄灭的油灯、走廊两侧墙上挂着锈蚀的工具（镐/锤/矿灯）
可用于场景：工具比人久 / 静立空廊 / 锈蚀的悬挂

### 地下矿城祭坛
is-a 废弃矮人祭台（上位：地下矿城）
锻炉祭坛——铁质锻炉台面上积了一层灰、炉灰中残留着几块未熔的矿石、像是最后一次锻造没做完
可用于场景：未完成的锻造 / 凝固的最后一锤

### 地下矿城庭院
is-a 废弃矮人天井（上位：地下矿城）
——但地下没有庭院这种概念。这里是通向地面的人造竖井底部——从井口射下一束光在地面形成一个光斑、周围是黑暗
可用于场景：地下的唯一自然光 / 光柱落底 / 来自地面的记忆

### 地下矿城钟楼
is-a 废弃矮人报时塔（上位：地下矿城）
巨大的铜钟嵌在岩壁上——不是用来听而是用来敲响震动整座山的、钟的表面布满敲击凹痕、钟绳已断
可用于场景：震山之钟 / 哑了的钟 / 沉默的警示

### 地下矿城地下层
is-a 废弃矮人更深层（上位：地下矿城）
矿城之下的更深处——温度明显升高、岩壁滚烫、远处有岩浆的暗红色反光——这里已经接近地心了
可用于场景：地底深处 / 熔岩层 / 不能再往下

### 地下矿城入口
is-a 废弃矮人大门（上位：地下矿城）
通往地面的石门——石门大敞、门轴被强行破坏的痕迹明显（不是关闭的状态而是被轰开的）、门槛上有碎骨
可用于场景：被攻破的城门 / 最后之战遗迹 / 尸骨门槛

### 地下矿城核心区
is-a 废弃矮人核心（上位：地下矿城）
矿城最中心的控制室——这里曾经有一整套控制全城机械的主齿轮、现在齿轮已拆走、只剩一个巨大的空洞和底座
可用于场景：心脏被掏走 / 中心只有空洞 / 机芯缺失

## v2 状态侵蚀层（以地下矿城废墟为上位）

注意：矮人地底的侵蚀——自然力对工业的反噬，矿物与金属被时间改造。

### 地下矿城废墟被花蔓侵蚀
is-a 地下花开（上位：地下矿城废墟）
在铁轨缝隙和石缝中长出了地底的白色小花——花没有叶子、只有细长的茎和白色的花冠、靠热能而不是阳光生存
可用于场景：地底生命 / 暗处开花 / 铁轨旁的绿

### 地下矿城废墟被荆棘缠绕
is-a 铁锈棘（上位：地下矿城废墟）
不是植物荆棘——是被锈蚀的铁丝与管线氧化后形成的尖刺状结构、坚硬的、像荆棘一样缠住通道
可用于场景：铁荆棘 / 金属自生的刺 / 锈蚀封锁

### 地下矿城废墟被树根穿刺
is-a 地表根入侵（上位：地下矿城废墟）
从地面伸下来的树木根系穿透了矮人城堡的岩顶——树根从裂隙中垂下、像巨大的绳缆一样摇摆
可用于场景：地表植物的报复 / 根从上方来 / 上下夹击

### 地下矿城废墟被苔藓覆盖
is-a 矿苔（上位：地下矿城废墟）
深绿色的苔藓覆盖了所有铁质表面——苔藓在铁上生长得比在石上更好、像铁在长毛
可用于场景：铁上长苔 / 工业化覆盖 / 绿锈

### 地下矿城废墟被菌丝寄生
is-a 地底荧光菌（上位：地下矿城废墟）
发着暗橙色光的菌丝在岩壁上像血管一样分布、菌丝沿着矿脉生长、照亮了废弃的轨道路径
可用于场景：荧光菌引路 / 橙色光丝 / 暗处的路标

### 地下矿城废墟被黑雾吞没
is-a 矿尘雾（上位：地下矿城废墟）
最深的矿道里充满了黑色的矿尘悬浮物——不是雾而是微小的碎矿颗粒浮在空气中、呼吸会觉得割喉咙
可用于场景：矿尘弥漫 / 看不见的毒 / 黑障

### 地下矿城废墟被冰晶封存
is-a 矿物结晶（上位：地下矿城废墟）
不是真正的冰——是白色与透明水晶从岩壁上生长出来、将废弃的矿车与工具包裹在水晶中、像自然形成的博物馆
可用于场景：水晶包裹工业 / 时间胶囊 / 冻结的劳作

### 地下矿城废墟被血迹污染
is-a 矿工伤痕（上位：地下矿城废墟）
铁轨与工具上残留的暗褐色血迹——不是战斗的溅射而是日常劳作的擦伤累积、长年累月渗入金属的缝隙
可用于场景：劳作的代价 / 血沃铁 / 日常的黑暗面

### 地下矿城废墟被月光空壳化
is-a 月光渗入（上位：地下矿城废墟）
——但月光下不到地下。这里的"月光空壳化"指的是月光从地面裂缝中漏入地下形成的苍白光柱——像一根白色的光柱插在地底
可用于场景：地下的月光柱 / 来自地面的信 / 苍白的光

### 地下矿城废墟被星尘异化
is-a 星矿化（上位：地下矿城废墟）
陨石碎片嵌入了矿城的岩层中——银蓝色的星尘与矿石混合、使废旧的矿脉重新发光——矿死了这么多年第一次又亮了
可用于场景：旧矿新光 / 星尘激活 / 第二次发光

## v3 内部功能空间层（以地下矿城废墟被花蔓侵蚀为上位）

### 地下矿城废墟被花蔓侵蚀中央空间
is-a 地底花厅（上位：地下矿城废墟被花蔓侵蚀）
废弃矿城的主厅——地面碎石间长满了白色地底花、花的排列沿着曾经放桌子的轮廓线——花代替了家具
可用于场景：花代椅 / 植物重新摆放居所 / 中央大厅的白点

### 地下矿城废墟被花蔓侵蚀祭坛空间
is-a 地底花坛（上位：地下矿城废墟被花蔓侵蚀）
曾经是锻炉祭坛的地方——白花从冷炉的烟道中长出、从锻炉口向外溢出一片白花、像炉火变成花
可用于场景：炉中花 / 冷炉成花盆 / 火变生命的残余

### 地下矿城废墟被花蔓侵蚀回廊空间
is-a 地底花廊（上位：地下矿城废墟被花蔓侵蚀）
走廊两侧的油灯凹槽里积了土长出了白花、花沿着油灯的排列一路盛开、像一排新的灯
可用于场景：花换灯 / 黑暗中的白点 / 自然点灯

### 地下矿城废墟被花蔓侵蚀洗礼池
is-a 地底花池（上位：地下矿城废墟被花蔓侵蚀）
原本用来冷却铸件的水池——水仍在、但池底长满了白色的水生根花、花的根系在水中漂荡如白色丝线
可用于场景：冷却池变花池 / 白根水中漂 / 工业变园艺

### 地下矿城废墟被花蔓侵蚀祈祷室
is-a 地底花室（上位：地下矿城废墟被花蔓侵蚀）
废弃的工具间——白花从工具的木柄上发芽长出、废弃的锤头变成花盆、休息的矮人工匠的化石不见了——花替他坐在那里
可用于场景：花坐空位 / 工具成花盆 / 无人但花满

### 地下矿城废墟被花蔓侵蚀花窗大厅
is-a 地底光厅（上位：地下矿城废墟被花蔓侵蚀）
——但地下没有花窗。这里的"花窗"是指岩壁上矿脉透过白色花的缝隙透出的微光——花丛中透出矿灯的余晖
可用于场景：岩壁透光 / 矿灯与花 / 地底彩窗

### 地下矿城废墟被花蔓侵蚀地下墓穴
is-a 地底花墓（上位：地下矿城废墟被花蔓侵蚀）
矿城最深的墓穴——矮人石棺排列整齐、每个棺盖上长出一丛白花——像死者在呼吸
可用于场景：花棺 / 矮人之墓 / 死者也有花陪伴

### 地下矿城废墟被花蔓侵蚀钟楼
is-a 地底花钟（上位：地下矿城废墟被花蔓侵蚀）
大钟的钟槌上结了一个花巢——白花从铁槌的缝隙中长出、敲钟的时候花会抖动——钟最后一次被敲响是为了震落花
可用于场景：钟槌上长花 / 摇花的钟 / 自然接管传信

### 地下矿城废墟被花蔓侵蚀圣像墙
is-a 地底花浮雕（上位：地下矿城废墟被花蔓侵蚀）
墙上的矮人浮雕——刻的是矮人锻造的图景——白花沿着雕刻的线条生长、勾勒出"火焰"和"铁锤"的轮廓
可用于场景：花勾勒的浮雕 / 自然描边 / 花画历史

### 地下矿城废墟被花蔓侵蚀忏悔室
is-a 地底花夹缝（上位：地下矿城废墟被花蔓侵蚀）
狭窄的维修通道——白花从两侧的管线缝隙中挤出、走进通道的人脸上会拂过冰凉的花瓣
可用于场景：花拂面 / 管线中开花 / 工业缝隙的温柔

## v4 最终复合场景层（中央空间10种变体）

### 地下矿城废墟被花蔓侵蚀中央空间复合场景
is-a 地底花心标准版（上位：中央空间）
废弃主厅中白花从各个方向汇聚到中央形成一个自然的白色花环、花环中央是空的（原本放王座的位置）
可用于场景：空王座花环 / 中央空缺 / 标准大全景

### 地下矿城废墟被花蔓侵蚀中央空间镜面版
is-a 地底花心倒影版（上位：中央空间）
地面的积水（冷却池的水渗过来了）形成了镜面——倒映着岩顶的白花、水有微微的铁锈色但映出的花格外白亮
可用于场景：锈水映花 / 铁色水镜 / 工业感的倒影

### 地下矿城废墟被花蔓侵蚀中央空间沉水版
is-a 地底花心水淹版（上位：中央空间）
地下水位上升——水淹没到膝盖、白花泡在水中但依然盛开、水面上的花飘动在水流中
可用于场景：涉水花丛 / 地下水位上升 / 花被水养

### 地下矿城废墟被花蔓侵蚀中央空间月光版
is-a 地底花心月夜版（上位：中央空间）
——但地下没有月光。这里是说月光从通往地面的裂缝中射下照亮了中央的花丛——银白色的光束斜插在花海中
可用于场景：月照地底 / 银色光柱入花海 / 天上的信

### 地下矿城废墟被花蔓侵蚀中央空间黑水版
is-a 地底花心油污版（上位：中央空间）
不知从哪个管道泄露的黑色机油渗入了花丛——白花被染成了黑色、机油表面的彩虹反光在火光下流动
可用于场景：黑花 / 机油染花 / 工业毒害自然

### 地下矿城废墟被花蔓侵蚀中央空间环形祭坛版
is-a 地底花心仪式版（上位：中央空间）
有人在花丛中搬来了几块新的黑色石块围成圈——石块上有新刻的粗糙符文——还有人在用这个旧址
可用于场景：新祭坛旧地 / 矮人的后代 / 传承

### 地下矿城废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 地底花心温泉版（上位：中央空间）
地热使地下水的温度升高——中央花丛中出现了一汪冒着热气的水池、花的热带变种在温水中开得更大更白
可用于场景：地热温泉 / 热气中的白花 / 花在蒸汽中

### 地下矿城废墟被花蔓侵蚀中央空间白花漂浮版
is-a 地底花心飘花版（上位：中央空间）
地底有气流上升——白花脱离花茎被气流托着在整个空间漂浮、像白色蝴蝶群、花碰壁后缓缓滑落
可用于场景：花在空中 / 盛大的飘散 / 花之旋舞

### 地下矿城废墟被花蔓侵蚀中央空间枯井版
is-a 地底花心竖井版（上位：中央空间）
