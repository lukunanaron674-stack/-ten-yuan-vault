# 骑士王国 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：秩序、荣耀、执行力、等级分明。

---

## v0 空间母体层

### 白石王城
is-a 王国首都城堡
白色石灰岩建成的多层城堡——城墙厚实方正、塔楼是方形的而不是尖的、城门前有宽阔的吊桥与护城河
可用于场景：王国全景 / 王城光景 / 国家首都

### 骑士誓约厅
is-a 骑士册封厅
长条形大厅——两侧排列着历代骑士的盔甲与盾牌、地面铺设蓝色与金色的马赛克拼花、尽头是国王座位前的一个宣誓台阶
可用于场景：册封仪式 / 骑士宣誓 / 立下誓言

### 王座大厅
is-a 君主正式接见厅
正中是正对大门的高台王座——王座背后是一面巨大的挂毯（描绘建国战争）、大厅两侧有供贵族站立的低台
可用于场景：接见群臣 / 审判 / 王权之座

### 训练校场
is-a 骑士训练场
开阔的土地——一端有木制假人（练习枪术用的）、另一端是弓箭靶场、场边有武器架与饮水槽
可用于场景：日常训练 / 新兵较量 / 备战状态

### 护城桥
is-a 城堡入口桥
跨越护城河的石拱桥——两端有门楼、桥面铺设石板、桥两侧有低矮的胸墙、吊起时桥板垂直紧贴城门
可用于场景：入城场景 / 迎接队伍 / 屏障升起

### 边境堡垒
is-a 前线防御工事
建在边境山丘上的粗石堡垒——比王城的建筑粗糙得多、纯粹功能导向、有观察哨和烽火台
可用于场景：前线 / 防守 / 信号

### 纹章广场
is-a 王国仪式广场
城堡前的方形广场——地面用不同颜色的石块嵌出王国的纹章图案、广场四面有旗杆、顶部挂着各国盟旗
可用于场景：出征集结 / 庆典仪式 / 阅兵

### 马厩长廊
is-a 战马饲养区
长条形低矮石建筑——内部是连续的木质马厩隔间、地面铺着干草、气味强烈、有挂在墙上的马具与鞍
可用于场景：战马准备 / 骑士与马 / 出发前

### 圣剑祭坛
is-a 圣剑封印地
城堡内部的一间封闭石室——中央有一座石台上插着一把古剑（象征王国正统）、剑身发出微弱的蓝光
可用于场景：拔出圣剑 / 继承王位 / 英雄的起点

### 战前营地
is-a 临时军事营地
骑士们出征前在城墙外搭起的帐篷群——旗帜在风中猎猎、篝火旁盔甲反光、帐篷之间有木质栅栏通道
可用于场景：全军集结 / 临战之夜 / 黎明前

## v1 典型空间层（以白石王城为上位）

### 白石王城废墟
is-a 废弃白石城（上位：白石王城）
墙壁断裂坍塌、白石灰石表面覆盖着黑色的火烧痕迹、铺地石的缝隙中长出了野草、护城河水已干涸见底
可用于场景：城堡陷落后的样子 / 火烧残壁 / 王国落幕

### 白石王城圣所
is-a 废弃王城圣堂（上位：白石王城）
城堡内的小圣堂——彩色玻璃窗碎裂、神龛中的圣像被移走只留底座、长条木椅翻倒发霉
可用于场景：荒废的圣堂 / 彩窗碎落 / 信仰离席

### 白石王城大厅
is-a 废弃王城大厅（上位：白石王城）
挂毯被撕碎散落在地面、大厅的长桌已被劈成柴火、王座被推倒——王座背后的墙壁上有涂鸦
可用于场景：被洗劫的大厅 / 王座倾覆 / 败亡的景象

### 白石王城回廊
is-a 废弃王城走廊（上位：白石王城）
走廊两侧的盔甲雕像被推倒——盔甲散落一地、像战场上阵亡的士兵被整齐陈列在这里
可用于场景：盔甲散落 / 走廊如战场 / 无人收殓

### 白石王城祭坛
is-a 废弃王城祭台（上位：白石王城）
祭坛的石台上放着被折断的国王权杖——权杖断成三截横放在台上、像是某种有意的仪式
可用于场景：断权杖 / 政权的终结 / 象征性的破坏

### 白石王城庭院
is-a 废弃王城庭院（上位：白石王城）
中庭的玫瑰园已经荒废——玫瑰枯死、花架坍塌、地面覆盖着枯枝与杂草、中央的喷泉池中积着绿色脏水
可用于场景：玫瑰枯园 / 庭院荒废 / 曾经的美景已逝

### 白石王城钟楼
is-a 废弃王城钟塔（上位：白石王城）
钟楼的敲钟绳已断、钟体上有一个弹洞（被攻城武器击中过）、钟裂了所以声音变得沉闷刺耳
可用于场景：被击中的钟 / 破钟沙哑 / 城破的标志

### 白石王城地下层
is-a 废弃王城地牢（上位：白石王城）
城堡下层的地牢——铁栏锈蚀、墙壁上有刻字（囚犯的名字与绝望的话）、地面上散落着破碎的陶碗
可用于场景：地牢遗迹 / 囚徒刻字 / 窒息的过去

### 白石王城入口
is-a 废弃王城大门（上位：白石王城）
城门的木制门板已被烧毁只剩框架——门洞大开像一个黑洞、门洞上方的城徽被凿去
可用于场景：城门洞开 / 徽章被毁 / 入口无防

### 白石王城核心区
is-a 废弃王城核心（上位：白石王城）
王座厅的遗址——王座原本的位置现在只剩一个四方的凹陷痕迹（王座被整个搬走）、周围的地砖被撬起
可用于场景：王座被搬走 / 空凹 / 中心被取

## v2 状态侵蚀层（以白石王城废墟为上位）

注意：骑士王国的侵蚀——战争/火烧/掠夺后的二次覆盖，时间与自然对军事权力的分解。

### 白石王城废墟被花蔓侵蚀
is-a 白花上城（上位：白石王城废墟）
白色的小野花从城墙裂缝中成片长出——在白色的石灰岩上白色的花几乎与石同色——像石头自己开出了花
可用于场景：白花白石 / 石头开花 / 温柔收复

### 白石王城废墟被荆棘缠绕
is-a 黑色荆棘缠城（上位：白石王城废墟）
黑色的粗荆棘从城墙上垂下来——像军队的旗帜一样挂在城垛上——但不是旗帜而是植物的占领
可用于场景：荆棘如旗 / 植物占领城堡 / 自然的城旗

### 白石王城废墟被树根穿刺
is-a 树根破墙（上位：白石王城废墟）
大树的根从城墙根部的石缝中挤入、然后沿着墙面的垂直裂缝一路向上——根如巨蛇般贴在墙面上
可用于场景：根系爬墙 / 根部如蛇 / 墙被撑裂

### 白石王城废墟被苔藓覆盖
is-a 绿苔覆城（上位：白石王城废墟）
绿色的苔藓覆盖了所有向北的墙面——北面墙壁在苔藓下变成了深绿色的山体般的质感
可用于场景：北墙全绿 / 城堡像山 / 归回自然

### 白石王城废墟被菌丝寄生
is-a 光菌墙绘（上位：白石王城废墟）
淡蓝色的发光菌丝沿着城墙的表面画出不规则的新纹路——在夜晚从远方看、废墟像被涂上了发光的地图
可用于场景：发光菌绘 / 夜中的蓝色纹路 / 自然的壁画

### 白石王城废墟被黑雾吞没
is-a 落日烟尘（上位：白石王城废墟）
不是真正的雾——是干燥季节被风扬起的石灰岩粉尘形成的白色微尘——笼罩在废墟周围像淡白色的烟
可用于场景：石灰粉尘 / 白色烟幕 / 废墟在吐息

### 白石王城废墟被冰晶封存
is-a 霜封城（上位：白石王城废墟）
初冬时节——水汽在城墙的石面上凝成白霜——整座废墟像撒了一层糖霜、墙上的苔藓在霜下呈现半透明的绿色
可用于场景：结霜的城堡 / 初冬的白 / 冷季景象

### 白石王城废墟被血迹污染
is-a 城墙上的血渍（上位：白石王城废墟）
城门附近的白石面上有灰黑色的陈旧血渍——血已深深渗入石头的毛细孔中再也洗不掉——像石头记着
可用于场景：血渗入石 / 战争记忆 / 无法洗去的记录

### 白石王城废墟被月光空壳化
is-a 月下白石（上位：白石王城废墟）
月光下白色石灰岩反射出清冷的银白色——废墟的轮廓在月光里格外清晰——像一把白色的骨头架子
可用于场景：白骨般的废墟 / 银色之城 / 死去的王都在月下

### 白石王城废墟被星尘异化
is-a 星尘授勋（上位：白石王城废墟）
银色星尘落在废墟的最高处——塔楼的尖顶被星尘照亮——像给废城的最高点戴上了一顶隐形的王冠
可用于场景：星尘冠顶 / 废城的加冕 / 天界的认可

## v3 内部功能空间层（以白石王城废墟被花蔓侵蚀为上位）

### 白石王城废墟被花蔓侵蚀中央空间
is-a 白花王座厅（上位：白石王城废墟被花蔓侵蚀）
王座厅的遗址——白花沿着王座原本位置的四方形轮廓长了一圈——像用花画出了王座的替代品
可用于场景：花画王座 / 白色的王座轮廓 / 空位的花框

### 白石王城废墟被花蔓侵蚀祭坛空间
is-a 白花祭台（上位：白石王城废墟被花蔓侵蚀）
圣堂祭坛上——碎裂的彩色玻璃中长出了白花——花的根穿过玻璃碎片、像是彩窗变成了花盆
可用于场景：碎彩窗长出白花 / 玻璃成花盆 / 光穿过花与玻璃

### 白石王城废墟被花蔓侵蚀回廊空间
is-a 白花盔甲廊（上位：白石王城废墟被花蔓侵蚀）
走廊上倒地的盔甲中长出了白花——花从盔甲的领口与头盔的眼部开出——像是盔甲里长出了花做的骑士
可用于场景：花从盔甲眼中出 / 盔甲开花 / 死亡的美丽

### 白石王城废墟被花蔓侵蚀洗礼池
is-a 白花洗剑池（上位：白石王城废墟被花蔓侵蚀）
庭院中的水池——水已干——池底积了一层土土上长满了白花——像是池中放了花而不是水
可用于场景：干池花满 / 池中无只有花 / 植物代替了水

### 白石王城废墟被花蔓侵蚀祈祷室
is-a 白花小堂（上位：白石王城废墟被花蔓侵蚀）
小祈祷室的石长椅已被白花覆盖——花沿着椅面的边缘密集生长、像是坐垫变成了花的
可用于场景：花垫长椅 / 花的座位 / 空位待坐

### 白石王城废墟被花蔓侵蚀花窗大厅
is-a 白花彩窗（上位：白石王城废墟被花蔓侵蚀）
彩色玻璃碎裂后——白花从窗框的缝隙中交错生长——在窗口形成了新的"花窗"——花的白色与透过来的彩色光混合
可用于场景：花+彩光 / 白花玻璃 / 新的彩窗

### 白石王城废墟被花蔓侵蚀地下墓穴
is-a 白花墓室（上位：白石王城废墟被花蔓侵蚀）
地牢中——被囚禁者的刻字旁长出了花——花从刻痕中发出、像是那些绝望的刻字终于开花了
可用于场景：刻字生根 / 绝望开出的花 / 囚徒的遗赠

### 白石王城废墟被花蔓侵蚀钟楼
is-a 白花钟巢（上位：白石王城废墟被花蔓侵蚀）
——不，钟楼里筑了一个鸟巢——鸟巢用花蔓编制而成、鸟飞走了之后花蔓继续生长、变成了一个花窝
可用于场景：花巢钟楼 / 鸟走了花继续 / 空巢盛花

### 白石王城废墟被花蔓侵蚀圣像墙
is-a 白花盾墙（上位：白石王城废墟被花蔓侵蚀）
墙上的盾牌浮雕——盾牌的正中被一丛白花覆盖——像是被花击中了盾牌的中心
可用于场景：花击盾心 / 植物打赢了武器 / 和平占领

### 白石王城废墟被花蔓侵蚀忏悔室
is-a 白花骑士室（上位：白石王城废墟被花蔓侵蚀）
一个窄小的石室——曾经骑士在出征前独自在此整理盔甲和祈祷——现在石室中长满了花、盔甲架已经锈在花中
可用于场景：骑士室成花室 / 盔甲锈花中 / 战前的最后一站

## v4 最终复合场景层（中央空间10种变体）

### 白石王城废墟被花蔓侵蚀中央空间复合场景
is-a 白花王座标准版（上位：中央空间）
王座厅废墟——白花沿着王座的方形轮廓形成白色边框、光从破损的屋顶射下照亮花框的中央——空位的圣光
可用于场景：空位花光 / 王座的继承者不在 / 标准大全景

### 白石王城废墟被花蔓侵蚀中央空间镜面版
is-a 白花王座倒影版（上位：中央空间）
地面积水——倒映出上方的破碎穹顶和从穹顶裂缝中垂下的白花——水中的花比实物多一倍
可用于场景：水下另一座王座厅 / 镜中的加倍繁花

### 白石王城废墟被花蔓侵蚀中央空间沉水版
is-a 白花王座水淹版（上位：中央空间）
地下水渗出形成了没过脚踝的浅水——白花从水下伸出水面、水面上的花顶和水中花的倒影相连形成一个完整的圆形
可用于场景：花从水中出 / 水花相连 / 王座泡在水中

### 白石王城废墟被花蔓侵蚀中央空间月光版
is-a 白花王座月夜版（上位：中央空间）
月光从穹顶裂缝中射下——白花在月光中发出比白天更亮的光泽——花与月光同色难分彼此
可用于场景：花与月同色 / 月下的白色王国 / 银白交融

### 白石王城废墟被花蔓侵蚀中央空间黑水版
is-a 白花王座火焚版（上位：中央空间）
焦黑的地面——王座厅曾被大火烧过——但白花从焦土中再次长出——黑地面白花形成了刺眼的对比
可用于场景：黑土白花 / 火烧后重生 / 黑与白

### 白石王城废墟被花蔓侵蚀中央空间环形祭坛版
is-a 白花王座仪式版（上位：中央空间）
有人搬来新的白色石块在王座空位周围摆了一个环——环内插着几根新蜡烛、蜡泪滴在白花上——仍有人纪念
可用于场景：还有人记得 / 新祭旧王座 / 蜡与花

### 白石王城废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 白花王座泉水版（上位：中央空间）
王座正下方的地面裂开涌出泉水——水沿着花框的轮廓流成了一个方形——水框与花框重叠
可用于场景：水框花框重叠 / 清泉涌出 / 新的生命力

### 白石王城废墟被花蔓侵蚀中央空间白花漂浮版
is-a 白花王座飘雪版（上位：中央空间）
白花的花瓣大量脱落——被风吹起在整个王座厅中飞舞——像一场白色的雪、花瓣附着在裂墙上、在墙上形成新的花
