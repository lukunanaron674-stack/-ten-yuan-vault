# 乌托邦仙境 · is-a 建筑名词库

格式：名词 `is-a` 上位概念 `|` 视觉特征描述 `|` 可适用场景/镜头

核心气质：完美的表象之下——过于完美本身就是一种诡异。

---

## v0 空间母体层

### 永昼花园
is-a 永恒白昼花园
永远是下午四点的金色光线——花永远盛开但从不凋谢、草永远碧绿但从不生长、空气中的花香浓郁到有些让人头晕
可用于场景：完美表象 / 过于完美的公园 / 凝固的时间

### 玻璃宫殿
is-a 全透明宫殿
完全由透明玻璃构成的宫殿——所有房间一览无余、没有隐私、阳光穿过所有玻璃将空间融化成明亮的暖白色
可用于场景：透明生活 / 无可隐藏 / 明亮到不安

### 花园城市
is-a 理想化城市
从空中俯瞰呈完美同心圆的城市——每条街道的宽度与建筑的层高严格一致、街角的树木修剪成球形、所有屋顶的颜色统一
可用于场景：规划到病态 / 过于整齐 / 空洞的完美

### 云糖街区
is-a 糖果色居住区
建筑的外墙是粉彩色（粉红/薄荷绿/淡紫/浅黄）、每个窗台上都摆放着相同的花盆、街道干净到反光
可用于场景：虚假温馨 / 糖果色世界 / 过甜到发腻

### 镜湖乐园
is-a 人工理想乐园
圆形的人工湖——湖底铺着白色瓷砖、湖水清澈见底、湖心有一个白色大理石喷泉雕塑（演奏竖琴的天使）
可用于场景：人工完美自然 / 静止的水 / 过于精美的丑

### 白塔社区
is-a 白色高层社区
一排排纯白色的塔形住宅楼——窗户的排列规则到像网格纸、每层阳台上有相同的白色椅子、没有人使用阳台
可用于场景：集体主义美学 / 统一的孤独 / 无人之城

### 无痛疗养院
is-a 理想化医疗设施
白色建筑群被花园环绕——没有围墙、所有门都是自动滑门、每一位"病人"的房间都朝南且窗户大如画框
可用于场景：自愿的囚禁 / 太完美的治疗 / 没有痛苦但也没有自由

### 完美广场
is-a 理想城市广场
椭圆形广场、地面铺着严丝合缝的彩色马赛克拼出巨幅天象图、广场四面完全对称、中央的纪念碑是抽象的白色螺旋
可用于场景：城市核心 / 集体活动 / 对称强迫

### 花冠剧场
is-a 露天理想剧场
半圆形露天剧场——座位由白色石阶组成、舞台背靠一片树篱、听众席的设计使每一个座位的视角都完美
可用于场景：上演理想 / 无人观看的演出 / 声音特好但无人

### 彩虹桥庭
is-a 彩色拱桥庭院
由七座不同颜色的拱桥连接的小型庭院群——每座桥通向一个不同颜色的独立庭院（红院/橙院/蓝院……）、太有设计感了
可用于场景：色彩分区 / 过于设计感 / 形式大于功能

## v1 典型空间层（以永昼花园为上位）

### 永昼花园废墟
is-a 废弃理想花园（上位：永昼花园）
花园的草开始枯黄、花开始凋谢——不是自然的衰老而是像同时被抽走了生命力、所有花在同一时间垂下了头
可用于场景：完美开始崩塌 / 表象褪色 / 第一次裂痕

### 永昼花园圣所
is-a 废弃理想圣殿（上位：永昼花园）
花园中心的白色小山丘——顶部有一个白色凉亭、凉亭的柱子开始出现发丝般的裂纹、地上散落着干枯的花瓣
可用于场景：圣所风化 / 修复不了的裂缝 / 安静地坏

### 永昼花园大厅
is-a 废弃花园大厅（上位：永昼花园）
花园中最大的亭台式建筑——白色大理石地面已经蒙了一层灰、座椅的白色坐垫开始发黄、空气中仍有花香但不再是活的
可用于场景：废墟化的花园家具 / 空椅 / 无人的音乐

### 永昼花园回廊
is-a 废弃花廊（上位：永昼花园）
藤架上的藤蔓已经干枯成褐色——垂下的不是绿叶而是干燥的枯藤、风一吹就折断、脚下的石板开始松动
可用于场景：枯藤走廊 / 脆化的结构 / 曾经的荫蔽

### 永昼花园祭坛
is-a 废弃花园祭台（上位：永昼花园）
花园中央的白色石台上——本来放着一个陶瓷花瓶但现在花瓶碎裂了、碎片在地上围成一个圈、土壤皲裂成龟壳纹
可用于场景：破碎的供品 / 祭台干裂 / 无人上供

### 永昼花园庭院
is-a 废弃花园围院（上位：永昼花园）
被修剪的树篱围合的矩形草坪——草坪中间出现了一块圆形的枯死斑（直径两米）、像是什么东西曾经在那里待过
可用于场景：圆斑枯地 / 无法解释的死亡 / 曾经有东西

### 永昼花园钟楼
is-a 废弃花园钟塔（上位：永昼花园）
白色钟塔的四面钟——指针全部停在十点零五分、但每个钟面的时间都是十点零五分（不是故障而是被同时停止的）
可用于场景：时间停止 / 共同的停摆 / 指向同一时刻

### 永昼花园地下层
is-a 废弃花园地下（上位：永昼花园）
花园下面有地下室——这本身就不正常——白色石阶通向地下、地下室的墙壁上有管道（不像是花园该有的基础设施）
可用于场景：理想花园之下的机械 / 隐藏的支撑系统

### 永昼花园入口
is-a 废弃花园大门（上位：永昼花园）
白色铁艺拱门上原本爬满的蔷薇已经干枯——门是开着的、但门轴已经锈死——永远保持在这个角度了
可用于场景：永远半开的门 / 锈住的时间 / 无法关闭

### 永昼花园核心区
is-a 废弃花园中心（上位：永昼花园）
花园正中央——本来应该有一个花瓶或雕像的位置如今只有一个圆形的空洞、从边缘的印记看原来的物体是被垂直拔走的
可用于场景：被取走的核心 / 空洞的中心 / 空缺

## v2 状态侵蚀层（以永昼花园废墟为上位）

注意：乌托邦仙境的侵蚀不是自然力量，而是**真相暴露**——完美表象被现实入侵。

### 永昼花园废墟被花蔓侵蚀
is-a 伪装为侵入的修复（上位：永昼花园废墟）
枯死的藤蔓上重新长出了叶子——但叶片是纸质的、枝是塑料的——不是真的复活、是人造的花蔓被安装上去伪装"修复"
可用于场景：虚假复活 / 粉饰崩塌 / 假花假藤

### 永昼花园废墟被荆棘缠绕
is-a 叛逃的装饰（上位：永昼花园废墟）
原本装饰性的人造荆棘真的开始生长了——塑料藤蔓变硬变锋利、从装饰变成了真正的刺——它"活"了
可用于场景：装饰品起义 / 假物成真 / 人造失控

### 永昼花园废墟被树根穿刺
is-a 真实自然的入侵（上位：永昼花园废墟）
真正的树根从地底刺穿了白色石砖——这里的根粗壮、褐色、含有泥土——与周围一切人造的、干净的、完美的东西形成对比
可用于场景：真实闯入完美 / 地被撕开 / 自然的暴力

### 永昼花园废墟被苔藓覆盖
is-a 霉变入侵（上位：永昼花园废墟）
不是漂亮的绿色苔藓——是黑色的霉斑在白色表面上蔓延、像墨水一样渗开、霉味代替了花香
可用于场景：霉斑扩散 / 干净的表面开始腐烂 / 黑斑

### 永昼花园废墟被菌丝寄生
is-a 腐败真菌（上位：永昼花园废墟）
白色走廊里长出深灰色的菌丝——菌丝不是在地上而是在墙上爬出具象的图案、像是什么东西想要通过霉菌写字
可用于场景：菌丝书写 / 霉菌作画 / 腐败之美

### 永昼花园废墟被黑雾吞没
is-a 真相雾（上位：永昼花园废墟）
黑雾从花园各处同时涌出——不是靠风而是从地面自体渗出、雾中没有任何方向感——像走进了照片的背面
可用于场景：表象之下的颜色 / 雾从内部来 / 失向

### 永昼花园废墟被冰晶封存
is-a 人工冷冻（上位：永昼花园废墟）
冰晶覆盖了枯黄的花园——但这里的冰是透明的、无气泡、完美得像玻璃——像是人为冷冻以阻止进一步腐败
可用于场景：完美的保存 / 冻住崩坏 / 封存为标本

### 永昼花园废墟被血迹污染
is-a 第一滴不完美（上位：永昼花园废墟）
白色台阶上出现了一小滴红色的血迹——来源不明——在这个一切过于干净的世界里红色的血像是最高级别的犯罪
可用于场景：一滴血 / 完美的瑕疵 / 颜色入侵

### 永昼花园废墟被月光空壳化
is-a 美丽的真相（上位：永昼花园废墟）
月光下洁白的花园褪去颜色后显露出它本来的面貌——粉彩色的建筑在月光下变成了统一的灰色、假花变回了塑料
可用于场景：月光揭露 / 褪去伪装 / 真实面目

### 永昼花园废墟被星尘异化
is-a 外来的修正（上位：永昼花园废墟）
银色的星尘落在枯萎的花园上——被星尘接触的地方恢复了颜色——但恢复后的颜色是错的（蓝色的花变成了紫色）
可用于场景：错误的修复 / 星尘的误操作 / 被篡改的表象

## v3 内部功能空间层（以永昼花园废墟被花蔓侵蚀为上位——注意这里的"花蔓"是_按上去的假花蔓_）

### 永昼花园废墟被花蔓侵蚀中央空间
is-a 假花中央（上位：永昼花园废墟被花蔓侵蚀）
被塑料花蔓装饰成凉亭状的中央空间——假花蔓的绿叶上有明显的接缝和卡扣、玫瑰是丝绸做的、但远看确实好看
可用于场景：近看露馅 / 远看完美 / 中间地带

### 永昼花园废墟被花蔓侵蚀祭坛空间
is-a 假花祭坛（上位：永昼花园废墟被花蔓侵蚀）
中央石台上用假花蔓摆出一个心形图案——太刻意了——像是有谁想用塑料花重新为这个空间赋予意义
可用于场景：刻意的意义 / 人造的爱 / 塑料仪式

### 永昼花园废墟被花蔓侵蚀回廊空间
is-a 假花回廊（上位：永昼花园废墟被花蔓侵蚀）
塑料花蔓从藤架上垂下、间距均匀——但翻转叶片会看到背面的价格标签编号还没有撕掉
可用于场景：标签还没撕 / 商品化的伪装 / 细节让人出戏

### 永昼花园废墟被花蔓侵蚀洗礼池
is-a 假花水池（上位：永昼花园废墟被花蔓侵蚀）
水池的水是清澈的——但假花蔓的根部浸在水中已经褪色、绿色的染料在水中扩散成一缕缕绿色烟雾
可用于场景：染料入水 / 人造物在水中现形 / 绿色烟雾

### 永昼花园废墟被花蔓侵蚀祈祷室
is-a 假花祈祷室（上位：永昼花园废墟被花蔓侵蚀）
被假花蔓围合成的小隔间——里面放着一张白色椅子、座椅朝东、前方有一个假花编成的十字架——谁做的
可用于场景：无名者的祈祷 / 塑料信仰 / 还有人相信

### 永昼花园废墟被花蔓侵蚀花窗大厅
is-a 假花光厅（上位：永昼花园废墟被花蔓侵蚀）
阳光透过塑料花蔓投下的影子不是花的形状——是塑料花瓣模具的轮廓、圆角矩形的影子暴露出它们是批量生产的
可用于场景：塑料阴影 / 模具形状的揭露 / 光影暴露一切

### 永昼花园废墟被花蔓侵蚀地下墓穴
is-a 假花地宫（上位：永昼花园废墟被花蔓侵蚀）
通往地下的台阶两侧插着假花——像是刻意用假物来掩盖地下有什么东西——越往下空气中化学品的味道越重
可用于场景：掩盖的入口 / 假花遮羞 / 通往真相

### 永昼花园废墟被花蔓侵蚀钟楼
is-a 假花钟塔（上位：永昼花园废墟被花蔓侵蚀）
钟塔的钟面指针被假花蔓装饰性地缠绕着——像是为了挡住什么——扒开花蔓看到钟面是空的（根本没有指针）
可用于场景：花蔓遮空 / 隐藏的缺失 / 装饰即谎言

### 永昼花园废墟被花蔓侵蚀圣像墙
is-a 假花圣像墙（上位：永昼花园废墟被花蔓侵蚀）
墙上的浮雕本是一些人物——但现在被假花蔓贴满、只露出人物的眼睛、像是给每个人戴上了花的面具
可用于场景：被贴花的脸 / 假花面具 / 身份被覆盖

### 永昼花园废墟被花蔓侵蚀忏悔室
is-a 假花隔间（上位：永昼花园废墟被花蔓侵蚀）
隔间的墙壁上贴满了假花——像贴壁纸一样密不透风——在这个满墙假花的小空间里任何忏悔都显得可疑
可用于场景：假花封墙 / 密室假花 / 被塑料包裹

## v4 最终复合场景层（中央空间10种变体）

### 永昼花园废墟被花蔓侵蚀中央空间复合场景
is-a 假花中心标准版（上位：中央空间）
塑料花蔓从各个方向汇聚到中央搭成一个不自然的华盖——这个华盖的对称是人工的、结构是靠鱼线固定的、一眼就能看出是搭建的
可用于场景：人工华盖 / 搭出来的完美 / 标准大全景

### 永昼花园废墟被花蔓侵蚀中央空间镜面版
is-a 假花中心倒影版（上位：中央空间）
地面的浅水洼倒映着假花——倒影中的颜色比实物还要鲜艳（水中的染料饱和度更高）、倒影看起来比真的更真
可用于场景：假花的倒影比花真 / 水美化一切 / 二次欺骗

### 永昼花园废墟被花蔓侵蚀中央空间沉水版
is-a 假花中心水淹版（上位：中央空间）
水淹过假花的根部——塑料花浮在水面上不沉、水面上遍布各种颜色的塑料花、像浴缸里的玩具
可用于场景：塑料花浮在水面 / 浴缸之景 / 本应浪漫但实则廉价

### 永昼花园废墟被花蔓侵蚀中央空间月光版
is-a 假花中心月夜版（上位：中央空间）
在月光下假花蔓和真花蔓再无区别——因为它们都是塑料的/干的——月光把所有颜色统一为银灰色、真假不再重要
可用于场景：月色消除差异 / 真假无别 / 月下的平等

### 永昼花园废墟被花蔓侵蚀中央空间黑水版
is-a 假花中心污染版（上位：中央空间）
不知何处涌出的深灰色液体淹没了地面——假花漂浮在其中、染料在深色液体中不再可见——塑料花变成了灰蒙蒙的漂浮物
可用于场景：灰水漂花 / 所有颜色被吞噬 / 报废

### 永昼花园废墟被花蔓侵蚀中央空间环形祭坛版
is-a 假花中心仪式版（上位：中央空间）
有人用假花蔓在中央地上摆了一个直径5米的同心圆——圆圈内用假花拼出了问候语——像是在开一场无人参加的派对
可用于场景：无人派对 / 自娱自乐 / 孤独的装饰

### 永昼花园废墟被花蔓侵蚀中央空间裂缝圣泉版
is-a 假花中心泉水版（上位：中央空间）
