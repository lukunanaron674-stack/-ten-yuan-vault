# 剪辑三档时长 · xn三角克制的视听映射

## 核心映射公式

| 时间档位 | 视觉类型 | 十元映射 | 克制位置 |
|:-------:|:--------|:--------:|:--------|
| **1-3秒** | 高频刺激 / 快剪 | **zx（目标/执行/冲动）** | 被xn克 |
| **4-6秒** | 标准叙事 / 中镜头 | **xn（规则/节拍/秩序）** | 主位·夹在中间 |
| **6-10秒** | 情绪沉淀 / 长镜头 | **zn（意义/超越性）** | 克xn |

## 三角结构

```
        6-10秒（zn · 意义/超越）
            ↓ 克（意义悬浮，规则不能切）
        4-6秒（xn · 规则/节拍）   ← 剪辑的基底
            ↓ 克（规则说「这里不能加速」，冲动被压住）
        1-3秒（zx · 执行/冲动）
```

---

## ⏱️ 1-3秒（快剪）→ zx（目标/执行）

**映射强度：9/10**

| 维度 | 对应 |
|:----|:-----|
| 核心感觉 | 完成一个动作本身即是意义 |
| 时间感 | 子弹时间式的压缩——zx的推进力 |
| 克制关系 | 被xn克——规则说「不能延长」，必须在3秒内切 |
| 导演思维 | 一个镜头只交代一件事（拔刀/惊恐/闪光），然后立刻切机位 |
| 什么时候用 | 高燃打斗 / 极度震惊 / 危险信号 / 快速反应 |

---

## ⏱️ 4-6秒（标准叙事）→ xn（规则/节拍/秩序）

**映射强度：9/10**

| 维度 | 对应 |
|:----|:-----|
| 核心感觉 | 规则提供了可预测的框架——观众能认出空间关系 |
| 时间感 | 4-6秒是人脑理解场景的最小时间窗口——感知的"节拍" |
| 克制关系 | 对zn：接住意义不让它飘走； 对zx：给快剪归零的呼吸 |
| 导演思维 | 这是剪辑的中流砥柱——观众需要4-6秒来认清「这个场景有谁、在干什么」 |
| 什么时候用 | 完整动作（进门/坐下/变身）/ 文戏对白 / 建立空间感 |

**核心地位：xn（4-6秒）是剪辑的节拍器。** 短片节奏散了，本质是xn的基底松了。

---

## ⏱️ 6-10秒（长镜头）→ zn（意义/超越性）

**映射强度：8.5/10**

| 维度 | 对应 |
|:----|:-----|
| 核心感觉 | 意义不急于被验证——它就是在那里 |
| 时间感 | 6秒后观众从「接收信息」切换到「感受氛围」 |
| 克制关系 | 克xn——意义瓦解规则：「这不是信息，它有独立的重力」 |
| 导演思维 | 敢用一个8秒不切的镜头，说明你对美术资产和镜头语言有绝对自信——定海神针 |
| 什么时候用 | 片头意境渲染 / 大远景夕阳 / 极度沉重内心戏 / 空旷孤独感 |

## 30秒短片结构 · 三角动力学展开

```
   zn（6-10秒）开场蓄势 ——「在这个世界里」
     ↓ 被xn接住
   xn（4-6秒）建立规则 ——「这里发生着什么」
     ↓ 节拍稳定后
   zx（1-3秒×6）执行爆发 ——「它发生了！下一个！它发生了！」
     ↑ zn在背后支撑——每一次快切的间隙，观众知道为什么在打
     ↑ xn在下面垫着——节奏再快也保持在可读范围内
   xn（4-6秒）收束 ——节拍重新校准
   zn（4秒定格）收刀——意义在最后一刻落下
```

**加起来 ≈ 30秒**

---

## 关键发现

1. **xn（4-6秒）是剪辑节奏的基底**——纯zx（快切到底）→ 观众迷失空间；纯zn（全是长镜）→ 观众不知道该看什么
2. **xn夹在中间**：压着zx不让节奏失控（规则说「这里不能走」），又被zn赋予超越信息传递的意义
3. **映射强度差异**：zx→1-3秒（9/10）、xn→4-6秒（9/10）纯度高；zn→6-10秒（8.5/10）——氛围型zn成立，宣言型zn需更强叙事支持
