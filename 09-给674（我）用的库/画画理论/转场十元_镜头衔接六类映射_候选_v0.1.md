# 转场十元 · 镜头衔接六类映射 候选 v0.1

> **本卡是候选。** 镜头衔接的**分类**来自体系（`k_cut` 六类），
> 但**每一类归哪个十元，是本卡自推**，未经作者验收。

## 1｜体系已有的分类（直接依据）

`分镜知识_五行十元分析.canvas` 的 `k_cut` 节点原文：

```text
⑥ 镜头衔接
动作｜视线｜形状｜声音先行｜情绪｜对比
下一镜必须被上一镜触发或补足。
```

配套 `k_sound` 节点（含跨镜延续）：

```text
⑦ 声音分镜
台词、环境音、动作音、音乐进入点、静默、跨镜延续
声音能替代昂贵画面。
```

**两条硬门禁（原文）**：
1. **下一镜必须被上一镜触发或补足**——不能只是"接着放"；
2. **声音能替代昂贵画面**——转场可以不靠画面完成。

## 2｜转场技法清单（影视工业既有，非十元材料）

| 转场 | 机制 |
|:-----|:-----|
| 硬切（cut） | 直接切换，无过渡 |
| 叠化（dissolve） | 两镜画面重叠渐变 |
| 淡入/淡出（fade） | 经黑/白过渡 |
| 划像（wipe） | 边界扫过替换画面 |
| 动作匹配切 | 前后镜动作轨迹连续 |
| 形状匹配切 | 前后镜图形相似 |
| 视线匹配切 | 前镜看向→后镜被看对象 |
| 声音先行 | 下一镜声音先入 |
| 跳切（jump cut） | 同机位时间跳跃 |

## 3｜六类衔接 → 十元（本卡自推 · 待验收）

推法：走**因果维 `zx+nx`**——"下一镜被上一镜触发或补足"本质是谁触发、谁承接。
另参考 `k_sound` 的"跨镜延续"。

| 衔接类 | 常用技法 | 十元 | 推法 | 状态 |
|:-------|:---------|:----:|:-----|:----:|
| **动作** | 动作匹配切 | `zx` | 前一镜的动作**主动推出**并占据下一镜的方向 | `pending` |
| **视线** | 视线匹配切 | `x` | 前镜的视线把对象**纳入掌握边界**（被看者被确立） | `pending` |
| **形状** | 形状匹配切 | `nx` | 沿既有图形通道**续接**，不夺方向 | `pending` |
| **声音先行** | 声音先入 | `xz` | 终点（下一镜）**先在听觉上形成**，过程随后逼近 | `pending` |
| **情绪** | 叠化／慢过渡 | `nz` | 保存并**重开可返回路径**，允许情绪停靠 | `pending` |
| **对比** | 硬切／跳切 | `z` | 把对象**提升为最高中心**，其余退出（对比即强制重新中心化） | `pending` |

## 4｜跨镜延续（声音替代画面）

`k_sound` 指出"声音能替代昂贵画面"。按体系，**跨镜延续**对应：

- 一段声音跨两镜不断 → 该段落在时间维 `xn`（节奏连续性）
- 声音先于画面出现 → `xz`（终点前置）
- 静默本身作转场 → 需回本义表判定，**本卡暂不推**（静默的十元归属尚不明确）

## 5｜抽帧节奏（体系已有，供衔接参考）

见 [[帧数节奏_十元克制映射.canvas]]：

```text
三档时长不是十元本体，是入口云：
1-3秒 ≠ zx，4-6秒 ≠ xn，6-10秒 ≠ zn
```

⚠️ 因此**不得**用"这个转场很短所以是 zx"来判——时长只是入口，必须落到实际的触发/承接关系。

## 6｜误判检查

- ❌ 不得因"转场很快"就判 `zx` 或 `z`（时长不是十元本体）；
- ❌ 不得因"画面很好看"就判 `zn`——美观不构成意义源；
- ❌ 不得把"接着放"当作已经构成衔接——门禁要求"下一镜被上一镜触发或补足"；
- ❌ 不得因两镜同时有某物就判为关系；
- ❌ 六类推法全为自推，任何引用必须同时标注来源。

## 7｜复审入口

1. 六类衔接的十元归属是否成立？
2. 是否该走因果维 `zx+nx`？还是**转场本身需要独立维度**（因为它跨镜，不属单镜内的五维）？
3. 硬切/叠化/淡入淡出/划像这四种**技法**是否需要单独映射（与"衔接类"并列）？
4. 静默作为转场时的归属？
5. 声音跨镜延续是否该独立成项？

## 8｜封存句

```text
转场不是两镜之间的缝，是上一镜对下一镜的一次委托。
六类委托方式里，卡给出的是候选——它们等着被验证，而不是被引用。
```
