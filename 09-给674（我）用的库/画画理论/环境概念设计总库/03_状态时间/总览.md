# ③ 状态/时间痕迹

## 核心公式

xz（边缘）+ n（容器）——时间对空间的侵蚀和改变

## 问法

这个环境经历了什么？

## 子节点

| 节点 | 十元 | 一句话 |
|:----|:----:|:-------|
| [[运转中.canvas\|🔸 运转中]] | xn | 空间正在被使用，规则在运行 |
| [[废墟遗迹.canvas\|🏘️ 废墟/遗迹]] | xz+n | 被时间侵蚀后，边缘化的容器 |
| [[荒废.canvas\|🔸 荒废]] | xz | 被遗弃但还没开始崩塌 |
| [[战损.canvas\|🔸 战损]] | nx+x | 暴力留下的痕迹，有人在结算 |
| [[植物侵蚀.canvas\|🔸 植物侵蚀]] | x+nz | 自然在收回空间 |
| [[沉没淹没.canvas\|🔸 沉没/淹没]] | x+n | 被水吞噬的沉默 |
| [[冰封.canvas\|🔸 冰封]] | nz | 时间被暂停 |
| [[燃烧后.canvas\|🔸 燃烧后]] | x→xz | 欲望烧完了，只剩边缘 |
| [[崩塌中.canvas\|🔸 崩塌中]] | xz→n | 正在变成废墟 |
| [[新建未完成.canvas\|🔸 新建/未完成]] | zx | 还没开始使用的空间 |

## 封存句

状态不是「这个空间现在什么样」，是「这个空间经历过什么才变成这样」。
