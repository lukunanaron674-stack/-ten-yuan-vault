# 视觉描述词库｜总索引

## 0. 定位

这是给实际画图、AI 生图、角色设定、分镜与动画关键帧调用的**可复用视觉描述词库**。

它不是：
- 十元 canonical 定义库；
- 项目逐镜头描述词目录；
- 单一作品的风格锁定文件；
- 直接替代 `五行轴角色生成器/数据/trigger_registry_v0.1.json` 的机器触发器表。

建议链路：

```text
05-银矿库/十元血肉库/视觉家族（研究/证据/视觉家族）
        ↓
09-给674（我）用的库/画画理论/描述词库（可调用词条）
        ↓
具体项目描述词/角色卡/分镜卡（方、黎黎隆等）
        ↓
AI 生图/动画测试
        ↓
有效结果回填词条的“已验证组合/边界/反词”
```

## 1. 标注格式

最简显示格式：

```text
二次元角色设定稿（zx3）
90年代国产动画人设风（zn8）
```

其中：
- `zx / zn / ...` = **十元候选标记**；
- `1–10` = 该词条在当前视觉用途中的**体量/主导程度**；
- 这里的标记只用于应用层检索与组合，**不得反向定义十元**；
- 没有通过比较测试的映射写 `待校准`，不要为了整齐硬填。

复杂词条可以写主/次：

```text
词条（主 zn8 / 次 zx3）
```

## 2. 每个词条至少记录

- 词条名
- 所属组
- 十元候选 + 体量
- 作用变量（它到底改变线、色、比例、镜头还是材质）
- 正向视觉结果
- 适用场景
- 反词 / 禁止项
- 可组合词
- 来源
- 状态：`seed-user / candidate / verified / deprecated`
- 有条件时附参考图或项目实测链接

## 4. 与现有仓库的分工

### `方/02_描述词/`
保存**逐镜头成品描述词**。它是下游项目文件，不适合作为全局词库。

### `05-银矿库/十元血肉库/视觉家族/`
保存**视觉家族研究与十元结构分析**。可以给本词库提供来源和边界，但不要把项目 prompt 直接塞回研究库。

### `09-给674（我）用的库/09-方法论与工作流/五行轴角色生成器/`
保存**编译器、registry、mapping 与运行测试**。描述词库稳定后，可以再导出机器 registry；当前不要把自然语言风格词直接混进符号触发器。

## 5. 当前建设顺序

先做：

```text
01 画风
→ 06 角色比例与脸型
→ 02 线稿
→ 03 色彩
→ 04 光影
→ 05 材质
→ 07 构图镜头
→ 08 动作表演
→ 09 场景气氛
→ 10 输出形式
→ 11 负面限制
→ 12 组合配方
```

原因：先锁“长什么样”，再锁“怎么画”，最后锁“怎么拍/怎么动”。否则词条很多，但一组合就互相打架，人类又会重新发明一次关键词垃圾场。
