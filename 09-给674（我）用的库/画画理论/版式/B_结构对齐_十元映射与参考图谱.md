# B. 结构对齐：十元映射与参考图谱

> 目标：把你给的“结构对齐”表，变成能找图、能拆图、能接到绘画构图/线稿判断里的知识节点。  
> 找图风格：按你现在找图的习惯，优先找**参考图 + 结构线 + 标注 + 拆解感**，不要只收藏最终美图。

## 总表

| 类型 | 最高强度 | 十元映射 | 感觉 |
|---|---:|---|---|
| 网格对齐 | 9.5 | xn 9.5 / n 9 / nx 4 | 系统、杂志、展板、UI |
| 边缘对齐 | 8.5 | n 8 / x并z 7 / xn 5 | 被边框、建筑、画面边界控制 |
| 透视对齐 | 8.5 | n 8.5 / zx 7 / xn 5 | 空间可信、视线推进 |
| 建筑线对齐 | 8.5 | n 9 / xn 6.5 / zn 4 | 稳定、结构感、场景压住画面 |
| 模块对齐 | 8 | xn 8.5 / n 8 | 信息块、栏目、卡片式排版 |

## 找图总原则

你要找的不是“漂亮”，而是“能让我看见结构怎么工作”。

优先找这些关键词：

- `grid overlay`
- `layout breakdown`
- `composition guide`
- `poster grid system`
- `architectural composition lines`
- `perspective grid illustration`
- `vanishing point street`
- `modular card layout`
- `dashboard card grid`
- `magazine layout grid`

图片最好有这些特征：

- 能画出 3-5 条主线。
- 能看出文字/角色/建筑/模块服从同一个框架。
- 有明显版心、边框、柱线、消失点、卡片组。
- 可以拿来做“描结构线”，而不是只能看氛围。

## 1. 网格对齐

### 十元理解

- `xn 9.5`：规则、网格、栏目最强。
- `n 9`：版心和整体承载也很强。
- `nx 4`：冷静、克制、系统感作为副作用。

### 画面感觉

系统、杂志、展板、UI、信息整理、课程页、作品集页。

### 适合找什么图

- 瑞士网格海报。
- 杂志版式网格。
- 作品集页面网格。
- UI Dashboard 栅格。
- 带 12 栏、基线、版心标注的设计图。

### 搜图关键词

- `Swiss grid poster layout`
- `editorial grid system magazine layout`
- `12 column grid poster`
- `portfolio grid layout design`
- `UI dashboard grid system`

### 拆图方法

1. 先画画面外框和版心。
2. 找所有文字左边缘/图片边缘是否共线。
3. 标出列宽、栏距、上下边距。
4. 看有没有一个元素故意破格。

## 2. 边缘对齐

### 十元理解

- `n 8`：画面边界先托住。
- `x并z 7`：边框、装饰线、建筑边缘参与控制。
- `xn 5`：规则存在，但不像网格那么系统。

### 画面感觉

被边框、门框、窗框、建筑边缘、画面边界控制；角色像被框住、压住、展示出来。

### 适合找什么图

- 建筑海报。
- 有门框/窗框/柱子压住人物的电影画面。
- 人物贴边或被边缘切割的插画。
- 边框强烈的展板、封面、游戏 UI。

### 搜图关键词

- `edge aligned typography poster`
- `architecture poster border typography`
- `framed composition character illustration`
- `window frame composition illustration`
- `poster edge alignment layout`

### 拆图方法

1. 先画四周边界和所有门窗/柱子边线。
2. 看人物有没有贴在某条边缘线上。
3. 看文字是不是像刻在结构上，而不是贴纸。
4. 找一处“贴边”带来的压迫或秩序感。

## 3. 透视对齐

### 十元理解

- `n 8.5`：空间承载必须强。
- `zx 7`：斜线动势、视线推进。
- `xn 5`：透视规则让空间可信。

### 画面感觉

空间可信、视线推进、地面/建筑/人物都向同一个深度服从。

### 适合找什么图

- 一点透视街道。
- 车站、走廊、楼梯、桥、隧道。
- 动漫背景的街景透视。
- 有消失点标注的教学图。

### 搜图关键词

- `one point perspective street illustration`
- `anime background perspective street`
- `vanishing point composition`
- `perspective grid environment design`
- `corridor one point perspective drawing`

### 拆图方法

1. 先找地平线。
2. 找主消失点。
3. 把建筑边、地砖边、栏杆线都延长。
4. 检查人物脚底、地面、建筑是否服从同一空间。

## 4. 建筑线对齐

### 十元理解

- `n 9`：建筑本身是画面的承重骨架。
- `xn 6.5`：建筑立面、窗格、梁柱带来规则。
- `zn 4`：中轴/仪式感可能出现，但不是主导。

### 画面感觉

稳定、结构感、场景压住画面；特别适合哥特、废墟、城市、教堂、宫殿。

### 适合找什么图

- 建筑摄影里的立面线。
- 哥特教堂/柱廊/拱门。
- 城市环境概念图。
- 人物被建筑结构压住的概念插画。

### 搜图关键词

- `architectural line composition poster`
- `building facade grid composition`
- `gothic cathedral composition lines`
- `concept art architecture composition`
- `urban environment composition lines`

### 拆图方法

1. 先不看人物，只画建筑主线。
2. 标出柱子、窗格、梁、墙面的纵横骨架。
3. 看人物是否落在建筑线的节点上。
4. 如果人物和建筑没关系，就是贴图；如果被建筑线托住，就是结构对齐。

## 5. 模块对齐

### 十元理解

- `xn 8.5`：模块、栏目、卡片、规则最明显。
- `n 8`：整体画面仍要托住所有信息块。

### 画面感觉

信息块、栏目、卡片式排版、UI、作品集、角色设定页、训练打卡页。

### 适合找什么图

- Dashboard 卡片布局。
- 角色设定页。
- Moodboard。
- 作品集案例页。
- 课程/训练打卡模板。

### 搜图关键词

- `modular card layout UI design`
- `dashboard card grid design`
- `character sheet layout grid`
- `moodboard modular layout`
- `portfolio case study card layout`

### 拆图方法

1. 把每个信息块画成矩形。
2. 看卡片大小是否分级。
3. 看卡片之间是否有统一间距。
4. 看主模块、次模块、注释模块是否清楚。

## 给你自己的图怎么用

你当前画画的流程可以这样接：

1. **小比例定大构图**：先定整体 n。
2. **剪影强化结构认知**：用角色/建筑/大色块确认承载。
3. **结构对齐选择一种主系统**：
   - 角色设定页：网格对齐 + 模块对齐。
   - 叙事插画：透视对齐 + 建筑线对齐。
   - 哥特/城市/废墟：建筑线对齐 + 边缘对齐。
   - 训练笔记/打卡：模块对齐 + 网格对齐。
4. **线稿决策**：只把服从主系统的线提高权重。
5. **厚涂塑造**：用明暗块面强化结构，不让细节抢主骨架。
