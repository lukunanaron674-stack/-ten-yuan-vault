# 对齐的 n+xn 骨架系统

> 对齐不是"摆整齐"。
> 对齐是让画面里所有东西都承认同一个秩序：
> **谁和谁是一组，谁服从谁，谁可以破格。**

对齐是版式里的**骨架线、军令、引力场**。

---

## 1. 对齐的十元本体（强度表）

| 十元 | 对齐里的作用 | 强度 | 说明 |
|------|------------|:----:|------|
| **n** | 承载、版心、整体结构 | 9 | 负责"托住"——画面整体的空间承载 |
| **xn** | 规则、网格、栏目、信息秩序 | 8.5 | 负责"规训"——对齐的规则体系 |
| **nx** | 克制、隐藏、弱显现、低声排列 | 6.5 | 冷感、距离感、审判记录的小字区 |
| **z** | 被对齐后显现得更明确 | 6 | 对齐让主体/焦点更清晰，而不是对齐本身 |
| **zn** | 中轴、碑文、神圣仪式感 | 5 | 中轴对称带来的庄严与仪式 |
| **xz** | 故意错位、临界、不安 | 4 | 破格设计——强对齐后的偏移 |
| **x并z** | 装饰线、边框、纹理辅助对齐 | 4 | 沿建筑线贴边，刻在结构上 |
| **zx** | 斜线动势、方向推进 | 3.5 | 动势线/方向性引导 |
| **x** | 破坏、压迫、冲突偏移 | 3 | 破坏性偏移——很少用 |
| **nz** | 柔和停靠、亲密排布 | 2.5 | 软性对齐，亲密接近 |

**核心公式：** `n + xn`

- **n** 负责"托住"
- **xn** 负责"规训"

## 2. 对齐的七种类型

### ① 中轴对齐 `n + zn`

```
       标题
        |
       主图
        |
       小字
```

- 感觉：庄重、仪式、审判、纪念碑、教堂感
- 危险：太正变死，太 zn 变"神圣模板"
- 用法：中轴稳住，局部轻微偏移

### ② 左对齐 `xn + n`

```
标题
副标题
说明文字
日期信息
```

- 感觉：清晰、理性、现代、阅读顺
- 适合信息多的海报
- 危险：全左对齐 → 设计展板 / 课程宣传 / 系统说明书（xn 过量）

### ③ 右对齐 `xn + nx`

```
        标题
      副标题
    说明文字
```

- 感觉：冷、克制、距离感、隐藏感
- 比左对齐更不日常→"偏、压、低声"
- 适合做 **nx + z** 的小字区：档案 / 审判记录 / 冷静注释

### ④ 顶部对齐 `xn + z`

- 所有元素上边缘在一条线上
- 感觉：宣布、展示、开场
- 危险：顶部太强画面会浮，下面没承载

### ⑤ 底部对齐 `n + nx`

- 所有元素压在底部
- 感觉：沉、稳、坠落、压舱
- 适合教堂感：上方暗空 → 中间彩窗光 → 底部标题/小字压住

### ⑥ 边缘对齐 `n + x并z`

- 元素贴着边框、窗框、柱子、建筑线走
- 感觉：画面被建筑结构控制
- 文字要像刻在结构上，不是贴纸
- 特别适合哥特建筑海报

### ⑦ 破格对齐 `xz + z`

- 大部分有秩序，只有一个偏出去
- 感觉：临界、不安、危险、要发生事
- **破格必须建立在强对齐之后**。全破=无 n

## 3. nx + z 方向的对齐结构（推荐）

你想要的：**强结构里有一点被压住的显现**

```
主结构：中轴对齐 n + zn
文字系统：右对齐 xn + nx
光源/彩窗：中心对齐 z
装饰边缘：沿建筑线 x并z
破格点：一个小偏移 xz
```

### 布局示意

```
        小标题
          |
      彩窗 / 主视觉
          |
        主标题

                         右侧小字
                         日期
                         信息
```

### 各部分十元归属

| 部分 | 十元 |
|------|------|
| 中轴 | n |
| 彩窗光 | z |
| 暗部留白 | nx |
| 右侧小字 | xn + nx |
| 轻微偏移 | xz |
| 建筑边框 | x并z + n |

## 4. 对齐强度控制

### 太弱（n 崩）

- 文字到处飘
- 主视觉没有轴
- 边缘距离不统一
- 小字没有共同起点
- 画面像素材堆

### 太强（xn 过量）

- 所有东西都居中
- 所有距离都一样
- 所有文字都规整
- 画面像模板、告示牌、学校展板

### 刚好

- 大结构严格
- 小结构克制
- 一个地方破格
- 亮点只显一次

> **90% 对齐，10% 逃跑。** 🪡

---

## 5. 对齐检查方法

看一张海报时，画六条线：

1. 有没有主中轴？
2. 标题和主视觉有没有关系？
3. 小字是不是共用一条边？
4. 元素和画面边缘距离是否统一？
5. 有没有一个故意不对齐的地方？
6. 不对齐的位置是不是有意义？

**如果"不对齐"没有意义，它就是错误。**
**如果"不对齐"能制造视线，它就是设计。**

---

## 6. 对齐封存句

> **对齐是 n 建骨、xn 立规矩；高级感来自强对齐后的少量偏移。全乱是塌，全齐是死，九成入骨，一成出逃。** 📐

## 7. B. 结构对齐：从版式骨架接到画面结构

> 入口：[[B_结构对齐_十元映射与参考图谱.canvas]] / [[B_结构对齐_十元映射与参考图谱]]

这一组不是普通排版对齐，而是把“版式的对齐”接到“绘画里的结构认知”：

**先让画面承认一套结构，再决定角色、文字、建筑、模块怎么服从它。**

| 类型 | 最高强度 | 十元映射 | 感觉 |
|---|---:|---|---|
| 网格对齐 | 9.5 | xn 9.5 / n 9 / nx 4 | 系统、杂志、展板、UI |
| 边缘对齐 | 8.5 | n 8 / x并z 7 / xn 5 | 被边框、建筑、画面边界控制 |
| 透视对齐 | 8.5 | n 8.5 / zx 7 / xn 5 | 空间可信、视线推进 |
| 建筑线对齐 | 8.5 | n 9 / xn 6.5 / zn 4 | 稳定、结构感、场景压住画面 |
| 模块对齐 | 8 | xn 8.5 / n 8 | 信息块、栏目、卡片式排版 |

### 这组知识怎么找图

不要只找“好看的图”，要找能看出结构的图：

- 带网格、版心、栏目、卡片、蓝图、辅助线的图。
- 建筑边界明显、人物被框在门窗/柱子/边框里的图。
- 透视线清楚、能一眼找到消失点的图。
- 画面被建筑立面、街道、墙线压住的图。
- 信息块像 UI/展板/杂志一样归组的图。

### 和绘画线稿的连接

- 网格对齐：帮你先定比例和位置，避免局部画爽但整体漂。
- 边缘对齐：帮你把角色贴到画面结构里，不像素材浮在上面。
- 透视对齐：帮你确定“空间推进线”，让地面、建筑、人物朝同一个空间服从。
- 建筑线对齐：适合你画场景压住人物的氛围图，尤其哥特、废墟、城市、展板式构图。
- 模块对齐：适合做参考板、角色设定页、训练打卡页，把知识变成栏目。
