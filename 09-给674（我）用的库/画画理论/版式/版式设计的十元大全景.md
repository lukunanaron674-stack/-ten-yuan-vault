# 版式设计的十元大全景

> 版式不是"摆放元素"。
> 版式是**用 n 建空间体、用 xn 立秩序线、用 z 控视线焦点、用 nx 给呼吸**的一场平衡术。

框架结构：

```
┌─────────────┐
│  版式的十元本体  │  六大要素 × 十元映射 + 强度谱
├─────────────┤
│  要素的交互关系  │  生克补链：要素之间怎么配合/冲突
├─────────────┤
│  版式风格谱系   │  不同版式风格=不同十元组合
├─────────────┤
│  实用分析模板   │  看任何版式时的检查清单
└─────────────┘
```

## 一、版式六大要素的十元本体

### 1.1 要素 × 十元 × 强度 总表

| 版式要素 | 十元核心 | 强度 | 一句话 |
|---------|---------|:----:|--------|
| **对齐** Alignment | n + xn | 9+8.5 | n 托空间，xn 规训秩序 |
| **留白** White Space | nx + n | 8+7 | nx 给呼吸，n 定空间边界 |
| **对比** Contrast | z + x | 7.5+5 | z 让焦点跳出来，x 制造张力 |
| **层级** Hierarchy | xn + zn | 8+5 | xn 建信息权重，zn 定阅读轴线 |
| **重复/韵律** Repetition | xn + nz | 6.5+3.5 | xn 建立复现规则，nz 制造柔和节奏 |
| **平衡** Balance | n + nz | 7.5+4 | n 承重分布，nz 保持柔和稳定 |

### 1.2 每个要素的深入拆解

#### ① 对齐 Alignment — n + xn（←已有独立篇）

- **n（9）**：对齐的"地心引力"——画面空间怎么承载元素
- **xn（8.5）**：对齐的"法律条文"——网格、栏目、边距规则
- **调用：** 锚点确定版面重心，网格系统控制秩序

详见 [[对齐的n+xn骨架系统]]

---

#### ② 留白 White Space — nx + n

| 十元 | 留白里的作用 | 强度 |
|------|------------|:----:|
| **nx** | 呼吸、隐藏、沉默、克制表现 | 8 |
| **n** | 空间体量、载体边界 | 7 |
| **nz** | 柔和过渡、排布间的软间隙 | 5 |
| **xn** | 等距留白、数学化的节奏间隙 | 4 |

**nx 是留白的灵魂。** 留白不是"空的地方"——而是**故意不填东西的克制**。

留白三层次：

| 层次 | 对应 | 十元 | 例子 |
|------|------|------|------|
| 外白 | 画面边缘到内容区 | n | 宽边距让版面像被托着 |
| 内白 | 元素之间的间距 | nx + nz | 段间距、行距、图边距 |
| 呼吸白 | 核心焦点周围的空 | nx + z | 标题周围的空，让z显现 |

**留白的危险：**
- **太弱（nx 不足）**：版面闷、挤、喘不过气 → 像传单
- **太强（nx 过量）**：版面空、散、信息联系断裂 → 像没人管的大厅

**刚好：** 外白稳得住画面，内白区分信息组，呼吸白保护焦点。

**补充——x 在留白里的变异：**
当留白不是为了呼吸而是为了**制造不安**（大片空白+小字靠边），留白变成 x 的工具。此时 nx 被 x 绑架。

---

#### ③ 对比 Contrast — z + x

| 十元 | 对比里的作用 | 强度 |
|------|------------|:----:|
| **z** | 焦点显现、主要/次要分化 | 7.5 |
| **x** | 张力、压迫、硬冲突 | 5 |
| **xz** | 意外对比、临界对比 | 4 |
| **xn** | 规则化的对比比例（如字号阶梯） | 3.5 |

**对比是版式的"戏剧性"。**

大小对比 → 主次关系（z）
颜色对比 → 情绪爆发（x）
粗细对比 → 结构区分（xn + z）
方向对比 → 动势冲突（xz + z）

**对比三法则：**

1. **够狠才有效**（z 需要足够差异才能显现）
2. **对比点不超过两个**（多个对比点 = 没有对比）
3. **对比必须有理由**（不是为了好看，是为了信息分级）

**x 的边界用法：**
当对比不是为了凸显焦点，而是为了**制造压力**（超大黑字怼脸 + 极小信息缩角落），x 成为主力。典型：重金属海报、恐怖电影海报。

---

#### ④ 层级 Hierarchy — xn + zn

| 十元 | 层级里的作用 | 强度 |
|------|------------|:----:|
| **xn** | 信息权重规则、字号/位置阶梯 | 8 |
| **zn** | 中轴阅读线、从上到下的仪式顺序 | 5 |
| **n** | 层级之间的空间承载 | 4 |
| **z** | 第一眼看到的层级顶点 | 4 |
| **zx** | 斜线/z字形阅读路径 | 3 |

**层级是版式的"阅读说明书"。**

| 层级构件 | 作用 | 十元 |
|----------|------|------|
| 主标题 | 第一眼看到 | z（显现） |
| 副标题 | 补充主标题 | xn（规则分支） |
| 正文 | 主要信息 | n（承载） |
| 标注/注释 | 次级信息 | nx（弱显现） |
| 装饰元素 | 不做阅读用 | x并z（伪装） |

**阅读路径（zx 的体现）：**
- Z字形阅读（zx → n 左到右 → n 下一行）
- F形热区（zx → xn 左到右上角）
- 中心放射（zn 中心 → xz 周边）

**层级的危险：**
- **太弱（xn 不足）**：分不清哪是重点 → 像密密麻麻的合同
- **太强（xn 过量）**：所有层级都一样清楚 → 没有主次，像Excel表

---

#### ⑤ 重复/韵律 Repetition — xn + nz

| 十元 | 重复里的作用 | 强度 |
|------|------------|:----:|
| **xn** | 统一的重复规则（同字体、同色块、同间距） | 6.5 |
| **nz** | 柔和节奏、渐变、脉动 | 3.5 |
| **x并z** | 纹理/图案的装饰性重复 | 3 |
| **xn + nz** | 规律性重复 + 节奏变化 = 韵律 | 6.5+3.5 |

**重复 ≠ 单调。**
重复是建立**视觉语言的一致性**，韵律是在重复里加入**可感知的变化**。

| 类型 | 例子 | 十元 |
|------|------|------|
| 规律重复 | 等距的图标行 | xn |
| 渐变节奏 | 字号从小到大、间距从密到疏 | nz |
| 交错节奏 | 黑条/白条交替 | x并z + xn |
| 自由节奏 | 元素大小变化但保持同一规则 | xn + nz |

**韵律的危险：**
- **太强（xn 过量）**：太规律=死板，像瓷砖
- **太弱（nz 不足）**：重复没变化=平淡，没呼吸

---

#### ⑥ 平衡 Balance — n + nz

| 十元 | 平衡里的作用 | 强度 |
|------|------------|:----:|
| **n** | 视觉重量的空间承载 | 7.5 |
| **nz** | 柔和稳定、不夹生不压迫 | 4 |
| **nx** | 轻量元素、弱化区域的使平衡 | 3.5 |
| **x** | 不平衡、有意识的不安 | 3 |

**平衡不是"对称"。**
平衡是**视觉重量分布使画面不倾倒**。

| 平衡类型 | 十元 | 感觉 |
|----------|------|------|
| 对称平衡 | n + zn | 稳定、仪式、庄严 |
| 不对称平衡 | n + nz | 现代、动感、呼吸感 |
| 径向平衡 | zn + z | 聚焦、向外或向内 |
| 有意不平衡 | x + xz | 紧张、不安、要动起来 |

**不对称平衡的秘密（n + nz 的精髓）：**
```
小面积高重量物体  ≈  大面积低重量物体
    红色方块           大片灰色区域
```

这是 n（空间感知）和 nz（柔和分布）的配合。

## 二、要素之间的生克补链

### 生（A催生/放大B）

| 生 | 原因 |
|----|------|
| 对齐 → 层级 | 对齐结构让层级更有阅读秩序 |
| 对齐 → 平衡 | 有轴之后，平衡才有基准 |
| 留白 → 对比 | 留白让对比元素更突出 |
| 重复 → 平衡 | 重复的节奏感让画面稳定 |
| 层级 → 对比 | 层级需要对比来凸显 |

### 克（A压制/约束B）

| 克 | 原因 |
|----|------|
| 对齐 克 留白 | 太严格的对齐会吃掉呼吸空间 |
| 对比 克 重复 | 强对比会打断重复的节奏感 |
| 层级 克 留白 | 层级太多会吃掉留白 |
| 平衡 克 对比 | 太追求平衡会削弱对比的冲击 |

### 补（A弥补/救B）

| 补 | 原因 |
|----|------|
| 留白 补 层级 | 层级太密时留白救场 |
| 重复 补 对比 | 对比太强时重复元素做锚点 |
| 重复 补 对齐 | 重复的节奏可以补足对齐的僵硬 |

## 三、版式风格谱系（十元组合）

| 版式风格 | 十元组合 | 感觉 |
|----------|---------|------|
| 现代极简 | n + nx + xn | 留白多、对齐严、层级清 |
| 哥特教堂 | zn + n + z | 中轴、沉重、神圣光 |
| 瑞士风格 | xn + n + nz | 网格严格、不对称平衡 |
| 朋克/噪点 | x + xz + z | 破格、冲突、强对比 |
| 档案/审判 | nx + xn + n | 克制、右对齐、低显现 |
| 波普/pop | z + x并z + nz | 高对比、装饰图案、活泼 |
| 日式侘寂 | nx + n + nz | 大量留白、不对称、自然 |
| 赛博/故障 | xz + x + z | 错位、破坏、电子感 |
| 古典/书籍 | n + zn + xn | 中轴、版心规整、字体严谨 |
| 海报/戏剧 | z + xn + xz | 大对比、网格+破格 |

## 四、版式分析检查清单

看任何一张版式设计时（海报/网页/封面/页面），按这个顺序查：

### 第一层：空间感（n）

- [ ] 画面的空间体量是紧的还是松的？
- [ ] 元素与画面边缘的距离是否统一？
- [ ] 版心/内容区是否清晰可辨？

### 第二层：规则（xn）

- [ ] 有没有明显的对齐轴？
- [ ] 字距/行距/段距是否有一致的规则？
- [ ] 网格/栏目系统是否存在？几栏？

### 第三层：呼吸（nx）

- [ ] 留白够不够？内白/外白/呼吸白各如何？
- [ ] 有没有被信息挤死的地方？
- [ ] 呼吸白的分布是否有意识？

### 第四层：焦点（z）

- [ ] 第一眼看到什么？
- [ ] 焦点和次焦点之间差多少倍？
- [ ] 对比力度是否足够？

### 第五层：路径（zx + zn）

- [ ] 阅读路径是Z字？F型？中心放射？
- [ ] 视线有没有被引导到重要信息？
- [ ] 有没有视线死角？

### 第六层：破格（xz）

- [ ] 有没有故意不对齐/不重复的地方？
- [ ] 破格的位置有意义吗？
- [ ] 破格能制造视线还是制造混乱？

> **版式是 n 建体量、xn 立规矩、z 显焦点、nx 给呼吸、nz 调暖意、xz 留一句反话——六要素各自为政则画面散，按生克补链调出各自位份，方成一张不费力但有力的版面。** 📐
