# 留白的 n+nx 呼吸系统

> 留白不是"空"。
> 留白是版式里最贵的空气，是让主视觉变重、让文字变清、让情绪沉下去的地方。🕯️

**留白 = 用空的位置控制视线、重量、呼吸和高级感。**

---

## 1. 留白的十元本体

| 十元 | 在留白里的作用 | 强度 | 说明 |
|------|--------------|:----:|------|
| **n** | 承载、空间、稳定、版心 | 9 | 空间体量的基底 |
| **nx** | 克制、沉默、压低、隐藏 | 8.5 | 留白的灵魂——故意不画的克制 |
| **z** | 因为空白而被显现 | 7 | 空白让主体更突出 |
| **zn** | 神圣、纪念碑、仪式感 | 6 | 大面积空白带来的庄严 |
| **xn** | 规整边距、版面秩序 | 6 | 等距留白的秩序感 |
| **xz** | 空白带来的不安、边缘感 | 4.5 | 偏移的空白制造临界 |
| **nz** | 柔软、停靠、温情空气 | 4 | 软性留白、温润间隙 |
| **x** | 压迫性空白、黑场压力 | 4 | 大面积黑暗吞没 |
| **x并z** | 装饰少时衬托空白，多时污染空白 | 3 | 装饰与空白的张力 |
| **zx** | 留白制造方向推进 | 3 | 留白引导视线动势 |

**核心公式：** `n 托住画面 + nx 压低声音 + z 被迫显现`

---

## 2. 留白的七种类型

### ① 上方留白 `zn + x`

```
上方大空
中间主视觉
下方信息
```

- 感觉：天命、压迫、神圣、不可抵达
- 适合：教堂海报、彩窗海报、审判感、角色被上方力量压住
- 对 nx + z 场景：**上面不是空，是有东西没降下来**

### ② 左右留白 `nx + n`

```
左空          主视觉          右空
```

- 感觉：孤独、安静、克制、距离感
- 适合：人物孤立、忏悔室、冷感角色、"不说话"的画面
- 人物像被框住——不是热闹，是被困在空气里

### ③ 底部留白 `n + nx`

```
主视觉在上
下方空出一片沉重空间
```

- 感觉：坠落、压舱、等待、祭坛、墓碑感
- 彩窗光在中上→人物在中间→标题压到底部→底部暗留白托住
- 让画面更稳，更像"仪式完成前的静止"

### ④ 中央留白 `z 未显现`

```
四周有结构
中央空出来
```

- 感觉：召唤、等待、缺席、洞口、门、即将显现
- 适合：黑圆虚空、教堂门洞、忏悔室洞口、角色尚未出现的场景
- 中央留白不是普通空白——它是一个**被保留的显现位**

### ⑤ 黑场留白 `x + nx`

```
大面积黑
小面积光
```

- 感觉：压迫、吞没、沉默、危险
- `nx 里超出 nx 的 z`：黑暗面积大，亮点面积小，亮点必须被黑暗压住
- 亮点太多→变 zn 梦幻；碎光太多→变 x并z 噪音

### ⑥ 白场留白 `n + zn / nz`

```
大面积白
少量文字/图形
```

- 感觉：干净、纯净、展览感、文学感、轻盈
- 不太适合教堂彩窗方向（白场偏轻，不够 nx）
- 除非做：圣洁、纪念、画册、轻艺术展

### ⑦ 边缘留白 `xn + n`

```
元素不贴边
四周边距统一
```

- 感觉：规整、高级、稳定
- 边距是版式里的基本礼貌
- 安全值：边缘留白 = 画面宽度的 5%~12%；标题周围 = 标题高度的 0.5~1 倍；主视觉周围至少有一侧能呼吸

## 3. 高级留白的三个特征

### ① 空白面积比细节大

```
大块面 > 小细节
暗部 > 碎光
空气 > 装饰
```

细节是宝石，留白是黑丝绒盒子。没有盒子，宝石就像撒在桌上的玻璃渣。

### ② 空白有方向

- ❌ 坏留白：哪里没东西，哪里就是空
- ✅ 好留白：空白把眼睛推向主视觉 → 空白让标题更清楚 → 空白制造压迫或等待

**空白必须参与动线。**

### ③ 空白和主体有关系

| 场景 | 留白的意义 |
|------|----------|
| 人物低头，上方留白 | 被压住 |
| 人物向左看，左侧留白 | 视线空间 |
| 人物背对光，背后留白 | 命运空间 |
| 中央空洞，四周留白 | 召唤空间 |

留白不是剩下的地方——**留白是主体的第二身体。**

---

## 4. nx + z 方向的留白配置

你要的不是梦幻童话，不是 zn 糖光——是**沉默的大面积 nx，被一小块 z 刺破。**

### 推荐比例

| 区域 | 占比 | 十元 |
|------|:----:|------|
| 暗部留白 | 55%~70% | nx + n |
| 主视觉结构 | 20%~30% | n + z |
| 彩窗/光点 | 5%~10% | z |
| 装饰碎片 | 3%~8% | x并z |
| 小字信息 | 2%~5% | xn |

### 最稳公式

```text
70% 暗部空气
20% 建筑结构
8% 彩窗显现
2% 极亮金光
```

## 5. 留白过少的问题

```
细节满 / 碎光满 / 藤蔓满 / 文字满 / 边缘满
```

| 问题 | 十元污染 |
|------|---------|
| 画面脏 | x并z 过量 |
| 主体不突出 | z 被稀释 |
| 没有高级感 | n 不够 |
| 情绪太吵 | nx 被冲掉 |
| 像素材拼贴 | xn/n 骨架不足 |

**解法：删掉 30% 装饰，画面可能立刻高级。**

---

## 6. 留白过多的问题

| 问题 | 表现 |
|------|------|
| 空 | 没有主题压力 |
| 装 | 像故意高级 |
| 冷 | 情绪没有落点 |
| 散 | 主体和空白没关系 |
| 弱 | z 不够显现 |

**解法：** 增加一个明确 z 点 → 加强主视觉边缘 → 让空白方向指向主体 → 用小字或光点钉住版面

留白不是越多越好——是**空白要有重量。**

---

## 7. 留白检查法

看任何版面时，问 6 个问题：

1. 最大的空白在哪里？
2. 它是托住主体，还是只是没画？
3. 空白有没有把视线推向主视觉？
4. 主标题周围有没有足够呼吸？
5. 边缘距离是否统一？
6. 有没有一块空白能制造情绪？

如果答案都没有，那只是空。
如果答案明确，那就是留白。

## 8. 教堂彩窗 nx + z 留白版式模板

```
┌────────────────────┐
│                    │
│      大暗部留白      │
│        nx          │
│                    │
│        彩窗光        │
│         z          │
│                    │
│      主视觉/人物      │
│       n + z        │
│                    │
│        主标题        │
│        xn          │
│   小字 小字 小字      │
└────────────────────┘
```

关键：

- 上方空 → 压迫
- 中间亮 → 显现
- 底部稳 → 承载
- 边缘暗 → 收束

## 9. 留白封存句

> **留白不是少画，而是让 n 托住、nx 压住、z 被迫显现。空白要有方向、有重量、有情绪；没有目的的空只是空，有目的的空才是版式里的命。** 🕯️
