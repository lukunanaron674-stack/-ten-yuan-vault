## 4. 信息量卡结构

每张正本卡至少包含：

```text
核心本体
不是什么
最近邻边界
人物 / 状态 / 行为 / 关系 / 场景分层
正例与反例
关系接口
召回版
版本记录
```

## 5. 对象分层

每次判断必须区分：

```text
人物稳定本体
当前人物状态
关键行为功能
关系位置与权限通道
外部场景
时间结构
视觉辅助
动态链
```

强 zx 人物可以使用 nx 关系功能。一次求人不能直接证明人物主十元为 nx；人物总体有主见，也不能否定某段行为属于 nx。

```text

→ 直接修改正本
```
