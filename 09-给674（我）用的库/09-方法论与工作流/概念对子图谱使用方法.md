# 概念对子图谱使用方法

> 如何用概念之间的生克补关系做题材/作品分析
> 归档位置：09-方法论与工作流/

---

## 1. 为什么需要概念对子

概念映射告诉你「这个概念是什么」，概念对子告诉你「这个概念在系统中和什么有关」。

例如：只知道「欲望是x9.5归本体9」是不够的。知道「欲望被爱/记忆/孤独/希望/家5个nz型概念克制(nz→x)」——这才能解释为什么欲望故事中「被感情软化」是最经典的转折。

## 2. 基本用法三步

### 第一步：找核心概念
选一个作品中的核心概念（欲望/自由/正义/死亡等），查它在22篇概念映射中的位置和强度。

### 第二步：展开对子关系
查这个概念的对子图谱——克它的、被它克的、补它的、生它的。这四个方向构成了这个概念在故事中的「力场」。

| 关系 | 含义 | 故事功能 |
|:----|:-----|:---------|
| 克（克制） | A压制B | 故事中的对抗关系、反面力量 |
| 生（生成） | A产生B | 故事的因果推进、转变逻辑 |
| 补（互补） | A和B互相需要 | 故事中的灵魂对子、核心张力 |

### 第三步：映射到人物配置
把对子关系转化为角色配置。如果欲望被爱克制，那故事中的「欲望角色」和「爱角色」就是天然的对抗关系。

## 3. 实战案例：复仇题材

```
复仇的核心概念：nx(清算)9 + zx(执行)9
  ↓
展开对子关系：
  补：zx↔nx(执行与清算互补) — 复仇者同时需要行动力和算账能力
  克：nx→x并z(清算拆穿伪装) — 复仇故事中假面具总是被揭穿
  生：nx→x(算计生出欲望) — 复仇到深处可能变成欲望
  ↓
映射到故事：
  复仇者 = zx(执行)+nx(清算)
  复仇动力的变质 = nx→x(清算变成欲望)
  反转时刻 = nx克x并z(清算揭穿伪装)
```

## 4. 精炼公式

```
作品分析 = 核心概念 × (克 + 生 + 补) 展开 → 人物配置 + 冲突类型 + 故事弧
```

不用读22篇映射全文，只需要：
1. 定位核心概念的十元点位（知道它在哪个十元上最强）
2. 查该十元点位在十元体系中的生克补关系
3. 展开为故事的结构要素

## 5. 已知的对子强度参考

| 对子类型 | 最经典例子 | 强度 | 故事价值 |
|:--------|:---------|:---:|:---------|
| **补→zn↔x** | 意义与欲望 | 9.5 | 本体型故事的核心张力 |
| **补→xz↔nz** | 临界与等待 | 9.5 | 命运型故事的灵魂对子 |
| **补→xn↔z** | 规则与冲动 | 9.5 | 时间型故事的双核驱动 |
| **克→n克xz** | 承载压制边界 | 7.5 | 稳定vs流动的冲突 |
| **克→nz克x** | 柔情克制欲望 | 9 | 情感vs欲望的对抗 |
| **生→z生zn** | 冲动生意义 | 8 | 从追求到信仰的转变 |
