# nx × 世界观｜应用映射 v0.1

> 本文件只把 current `nx` 的理论变量翻译成世界观生成语法。员工、下属、乞求者、弱者、被管理者、服从者、关系户、职位与制度都只是载体，不能反向定义 `nx`。

## 0｜canonical 锚点

木轴广义变量是“最终方向与作用权来源”：`zx` 自身生成并占据方向，`nx` 不占最终方向、沿既有通道续接。

current `nx` 的最低结构不是“被动”，而是：方向、权限或解决通道先由外部主体、关系、流程、秩序或现状建立；当前主体不占最终重设、否决与改题位置，并沿这些既有通道推进。主体可以很忙、很主动求人、很能执行；只要其关键解决接口仍来自外部，仍可能是 `nx` 行为或关系功能。

本轮只抽取五种世界观结构：既有方向承接、他者权限借用、可替换角色续接、关系网络多节点借力、方向更新权与执行权分离。

稳定人物本体与世界制度不是同一个判断对象。本文件生成的是“角色在世界中可进入的 nx 型方向/权限接口”，不把处于这种世界中的所有人自动判成稳定 `nx` 人物。

## 6｜反例与误映射

### R1｜等级森严、命令很多，所以这个世界是 nx

**rejected。**

职位、合同、监护、惩罚、生存威胁和暴力都属于 nx 准度卡必须先拿掉的第三因素。若人物只是因为无法反抗而服从，不能用强迫替代“在可选择时仍不占最终方向并沿既有通道续接”。一个高压帝国可以主要是 `x/zx/xn` 控制结构，而不是 `nx` 世界观。

### R2｜上级给目标，员工自己把整个流程搭出来，所以是 nx

**rejected。**

“目标来自外部”只说明最终目的未必由主体生成；若主体接到目标后主动排程、建流程、设节点、分资源并持续维护运行结构，current 卡明确要求优先检查 `xn`。外部给目标不是 nx 的充分条件。

### R3｜幕后人物有庞大关系网，所以是 nx

**rejected。**

如果关系节点、资源、账号、权限和调用边界都归幕后主体掌握，核心是 `x`；如果主体公开压过各节点并扩大决定范围，则检查 `zx`。`nx` 的关系网络要求关键通道真实在别人手里，主体通过承认并借用外部位置推进。

### R4｜关系很好、总听伴侣建议，所以是 nx

**rejected。**

安全关系中的信任、委托和默认采纳建议，不等于最终方向资格不可达。若主体始终可否决、换人、形成替代方案并保有退出/回返，则应检查 `nz` 或普通信任关系，而不能直接判 nx。

## 7｜最近邻排除总表

| 最近邻 | nx 世界观必须保留的区别 |
|---|---|
| `zx` | nx 不以自身权能生成、夺取或扩大最终方向；一旦直接改题并迫使外部响应，zx 上升。 |
| `xn` | 外部目标可存在，但若主体主动搭计划、流程、节点和资源结构，xn 上升；nx 只要求沿既有方向/通道续接。 |
| `x` | nx 借用他者资源与权限，所有权和调用边界仍在他者；若全部归主体掌握则 x。 |
| `nz` | nz 的核心是对象特异的自由退出与真实回返；信任关系可保留判断资格。nx 冻结的是最终方向/权限通道外置。 |
| `n` | n 是对象进入内部后被真实接住并持续处理负荷；nx 是行动者进入已有方向或权限通道。 |
| `z` | z 关注重要主体对明确对象的看见、回应、确认；nx 关注行动所需方向、权限和解决通道是否在外部并被借用。 |

## 8｜生成模式门禁

### 单符号

只允许使用本文件中已经通过 current `nx` 门禁的 worldbuilding 结构。不得为了“丰富”偷用 `zx` 的夺位、`xn` 的流程组织或 `x` 的权限所有权。

### 多符号

同一世界观模块必须写清主副职责，例如：

```text
primary nx responsibility：决定角色通过哪些既有外部通道推进
secondary xn responsibility：只负责角色接入后如何组织局部运行流程
relation_source：current nx/xn 信息卡与各自应用映射的显式边界
```

不得写 `70% nx + 30% xn`。

### 无向量尺标

只保留：节点、关系、路径、模块职责。例如：

```text
外部方向节点 -> 角色接入节点 -> 权限借用节点 -> 结果节点
```

不生成强弱分数、百分比或 weight。

## 9｜structure_id 检查

本轮五条语义身份只由：

```text
symbol + module + changed_variable + relation_shape + module_grammar
```

组成。

`NX-W-001 ~ NX-W-005` 的 changed_variable / relation_shape / module_grammar 均不同，故本轮：

```text
structure_id 新增：5
structure_id 重复：0
```
