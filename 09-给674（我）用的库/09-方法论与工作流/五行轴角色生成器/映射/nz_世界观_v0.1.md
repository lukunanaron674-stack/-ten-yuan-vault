# nz × 世界观｜应用映射 v0.1

> 本文件只把 current `nz` 的理论变量翻译成世界观生成语法。家、火炉、车站、旧房间、婚姻、朋友、恋爱、怀旧、等待都只是载体，不能反向定义 `nz`。

## 0｜canonical 锚点

水轴广义变量：可逆性与对象特异回返空间；`xz` 持续收窄，`nz` 保存、恢复或重建。

current `nz`：对象特异关系形成可信停靠，双方可自由离开，经历分离或冲突后仍存在真实回返、修复和重新接近位置。

本轮只抽取：对象特异、自由退出、真实可回返、冲突后修复、共同关系证据连续性。禁止偷换成“温暖、怀旧、有人等我、住在一起、关系名称”。

## 1｜NZ-W-001 双向可退出的停靠共同体

```yaml
id: NZ-W-001
symbol: nz
module: 世界观
sub_semantic: 自由退出后的可信回返
changed_variable: 成员离开共同体后是否仍保有面向原对象组合的真实重新进入资格
relation_shape: 已建立共同关系 -> 成员自愿离开 -> 原关系位置不被强制占有 -> 返回时可由双方恢复共同参与
module_grammar: 建立允许成员自由退出且不会因退出自动抹除原对象特异回返接口的共同体规则
concrete_candidate: [可退会又可回返的旅团, 允许离港后回归的船队, 成员可暂离并重新加入的魔法工坊]
genre_context: [中古奇幻, 公路冒险, 科幻舰队, 校园社团]
positive_reason: 关键不是组织包容，而是原成员与原对象组合之间的回返接口在自由退出后仍真实存在
nearest_neighbor: n / xn
why_not_neighbor: n 是进入后被接住和承载；xn 是流程节点是否允许再入；本候选必须保留对象特异关系与双方重新接近资格，而不只是通用入会流程
removal_test: 去掉徽章、会籍和场所，只要原对象组合仍允许该成员自由离开后回来并恢复共同参与，结构仍成立
reverse_test: 若退出即永久除名，或只有重新走一套面向所有人的通用报名程序而原关系不再有效，则 nz 下降
counterexample: 任何人都能凭票反复进入的公共旅馆，没有对象特异关系
source_evidence: nz 信息卡 v2.0；nz 准度卡 v0.1；行为库原对象组合/继续接口门禁
confidence: 96
status: candidate
```

# 6｜明确拒绝的误映射

### REJECT-NZ-W-001｜“温暖的家就是 nz”
- status: rejected
- 原因：场景、同住和被承载优先可能是 `n`；没有自由退出、对象特异回返与修复不能判 nz。

### REJECT-NZ-W-002｜“永远不能离开的关系最稳定，所以是高 nz”
- status: rejected
- 原因：禁止退出、资源扣留、自动召回与惩罚离开直接破坏 nz 的自由性，优先检查 `x/xn`。

### REJECT-NZ-W-003｜“末日前最后一个安全港就是 nz”
- status: rejected
- 原因：若核心是时间窗关闭、退路减少、未来汇向唯一终点，主结构是 `xz`；只有安全港与特定对象关系本身具有可回返/修复资格时才另有 nz。

# 7｜structure_id 检查

五个候选的 `changed_variable + relation_shape + module_grammar` 均不同，故形成 5 个新的结构身份；具象名词和题材不参与 structure_id。三条 rejected 不进入运行池。

# 8｜本轮结论

`nz × 世界观` 可进入应用层 candidate 机器投影。它不是“温暖世界观生成器”，而是“世界是否允许特定关系在自由退出、分离和冲突之后仍保存真实回返与修复空间”的生成语法。
