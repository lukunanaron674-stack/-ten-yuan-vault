# zx × 世界观｜应用映射 v0.1

## 0｜这一层不定义 zx

本文件只问：**如果一个世界观模块需要承载 zx 的 current-canonical 结构，哪些世界机制可以作为生成候选？**

当前理论锚：

```text
木轴广义变量：最终方向与作用权来源
zx 端：自身生成并占据方向
人物/状态召回：主体自己的权能公开进入现实，迫使他者、环境或秩序回应，并扩大主体的决定范围或凌驾位置
```

因此世界观模块不能靠“王冠、红金色、王宫、强者、战斗民族”等表面词成立。世界规则至少要让以下变量可观察：

1. 谁在生成方向；
2. 主体的决定接口是否公开进入现实；
3. 其他人/制度是否被迫响应；
4. 主体的决定范围、位置或辖域是否因此上升。

## 1｜世界观模块语法

当前候选语法：

```text
既有方向/边界存在
→ 主体以自己的决定接口公开介入
→ 既有参与者或制度必须正面响应
→ 局部方向、排序、辖域或决定范围被重新分配
```

这是应用规则候选，不是新的理论定义。

## 2｜可检验候选

### ZX-W-001｜公开挑战可转移决定席

- `symbol`: zx
- `module`: 世界观
- `sub_semantic`: 公开显权 / 夺取方向源
- `changed_variable`: 当前局部方向的最终决定席由谁占据
- `relation_shape`: 既有决定席 → 主体公开挑战 → 持席者必须回应 → 挑战成功则决定席转移/扩大
- `concrete_candidate`: 夺位台 / 挑战席 / 决定者高座
- `genre_context`: 中古奇幻、武侠、学院、竞技都市
- `positive_reason`: 重点不是“有擂台”，而是主体用自身力量公开迫使当前决定者回应，并真实改变谁能定方向。
- `nearest_neighbor`: nx / x / z
- `why_not_neighbor`: nx 沿既有通道续接而不占最终方向；x 可以静态拥有席位而无需公开扩权；z 需要重要认可主体确认而不是靠自身权能迫使秩序重排。
- `removal_test`: 若拿掉“挑战可改变决定席”，只剩普通竞技场或展示舞台，则 zx 映射消失。
- `reverse_test`: 若挑战者只能按既有裁判流程争取奖励、不能改变决定位置，优先转向 xn/nx 或普通竞技机制。
- `counterexample`: 王国有豪华竞技场，但所有权与治理权永远不随挑战结果变化。
- `source_evidence`: zx 信息卡 v2.3；zx 准度卡 v0.1；探春案例的“外部权力压入→公开反推→执行者改行为→局部决定位置恢复/上升”结构。
- `confidence`: 94
- `status`: candidate

### ZX-W-002｜辖域随公开压服而扩张

- `counterexample`: 王女出生即拥有最大领地，但从未以自身权能让任何边界重新反应。

## 4｜本轮最近邻压缩

```text
zx vs nx
zx：自身生成/占据方向，并把权能公开压进现实；
nx：不占最终方向，沿已有关系、权限、流程或安排续接。

zx vs x
zx：公开显权/扩权，必须看到他者或秩序重新响应；
x：可以只是已有掌握、归属与处分边界。

zx vs xn
zx：当前决定位置公开上升；
xn：把行动放进计划、时间、流程、记录与节点持续运行。

zx vs z
zx：靠自身权能使现实重新反应；
z：需要重要认可主体看见、回应或确认，或单点最高化的现行金轴结构。

zx vs xz
zx：主体主动扩大决定范围；
xz：危险逼近使路线、退路、安全窗口与可逆性收窄。
```

## 5｜给生成器的最低实现要求

世界观生成时，禁止只抽一个名词。至少输出：

```yaml
symbol: zx
module: 世界观
changed_variable: <谁拥有最终方向/当前决定范围>
world_rule: <主体怎样公开介入>
response_rule: <其他人或制度被迫怎样响应>
position_change: <主体决定位置怎样上升/扩张>
concrete_candidate: <题材化名词>
neighbor_guard: <最容易误成哪个十元>
```

只有 `world_rule + response_rule + position_change` 成立时，具象名词才允许进入最终描述词。
