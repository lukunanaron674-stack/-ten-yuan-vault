# 五行轴角色生成器｜nz × 世界观压力测试 R4

> 只验证应用映射层与生成逻辑；不修改 L1/L2 canonical、十元信息卡、准度卡、正式关系卡或 behavior evidence。

## 1｜测试目标

本轮选择 `nz × 世界观`。原因：当前机器映射已覆盖 `nz` 与最近高风险邻居 `nx`，且最新研究正在校准 nx/nz 边界；同时 `nz` 五条机器映射的 `genre_translation` 仍全部为空，适合检查“温暖/等待/回返”等表面词是否替代结构，以及题材翻译链是否真正可运行。

结构化中间链固定为：

`symbol → sub_semantic/changed_variable → relation_shape → module_grammar → concrete_candidate → genre_translation`

## 2｜样本与模式

总样本：60。

- single：20，primary=`nz`
- multi：20，primary=`nz`，secondary=`nx`，secondary 只承担“外部路线/权限续接压力参照”，禁止权重/百分比
- graph：20，无向量尺标

题材四类：`中古奇幻 / 太空歌剧 / 赛博都市 / 军事科幻`。

Node：`v22.16.0`。

## 3｜固定检查结果

1. 模式不是只改标签：PASS。single/multi/graph 输出结构不同；multi 有 primary/secondary/responsibility/relation_source；graph 有 node-edge path。
2. single 邻居十元偷渡：0/20。
3. multi 主从职责不清/百分比炖汤：0/20；未出现 weight/percent/ratio。
4. graph 偷引强弱分数：0/20。
5. 具象名词过度绑定：当前 15 个 distinct concrete noun，最高单名词 6/60=10.00%；未发现一个名词反向定义 nz，但结构池仍很窄。
6. 颜色/职业/身份/题材/情绪当十元判据：未观察到；生成器按 mapping.symbol 取池，题材不进入 structure_id。
7. 世界/服装/发型/道具/人生同义重复：NOT_IMPLEMENTED，当前机器 projection 只覆盖世界观。
8. 人生事件时间顺序：NOT_IMPLEMENTED，当前无“人生”排序 runtime。
9. 最近邻和同轴对端：`nz ↔ nx` 可做应用压力参照且本轮未混淆；`nz ↔ xz` 同轴对端不在当前机器 projection，DATA_BLOCKED。
10. 题材翻译保持核心语义：DATA_GAP。`NZ-W-001..005` 的 `genre_translation` 全为空；60/60 返回 null，不能标 PASS。
11. 相同 seed 可复现：20/20 PASS。
12. 模块锁定后重抽：10/10 PARTIAL_ONLY。当前只验证“世界观”单模块锁定后该模块不漂移；跨模块 selective lock NOT_IMPLEMENTED。
13. 重复率/集中度/模板化：primary structure excess duplicate 55/60=91.67%，明显偏高；根因是当前只有 5 个 nz primary structure，不得通过篡改 canonical 强行扩结构。

## 5｜5 个代表失败样本 / 失败链

### F01｜single / 中古奇幻 / NZ-W-002

`nz → 冲突后的修复资格 → 关系受损后是否仍有恢复可信接近路径 → 原关系→断裂→双方保留退出权→修复→重新接近 → 双向修复接口 → 破裂后可共同修复的关系印记 → genre_translation=null`

失败：`GENRE_TRANSLATION_DATA_GAP`。结构存在，但题材翻译链没有实际数据。

### F02｜multi / 中古奇幻 / NZ-W-005 + nx secondary

`nz(primary) → 双方可调用的重新接近路径 → ... → 双向归返桥 → genre_translation=null`

secondary nx 仅负责外部路线/权限压力参照，没有夺走 primary；失败仍是 `GENRE_TRANSLATION_DATA_GAP`。

### F03｜graph / 中古奇幻 / NZ-W-003

`nz → 长期分离中的回返坐标保存 → ... → 跨星年回航坐标 → genre_translation=null`

graph 路径真实生成且无权重，但最后一个题材翻译节点没有可用值。

### F04｜single / 太空歌剧 / NZ-W-005

`nz → 双方可调用的重新接近路径 → ... → 不强制召回的伙伴信道 → genre_translation=null`

题材高度适配，但机器 projection 仍没有太空歌剧翻译文本，因此不能验证翻译是否语义守恒。

### F05｜multi / 太空歌剧 / NZ-W-003 + nx secondary

`nz(primary) → 长期分离回返坐标 → ... → 跨星年回航坐标 → genre_translation=null`

同时暴露结构模板复用：不同 seed/模式/题材仍频繁回到同 5 个 primary structure。

## 6｜实际修复 / 状态变化

本轮不修改 canonical，也不凭空替 `nz` 编写题材翻译。实际状态修正是：

- 新增本回归测试资产；
- 明确把 `nz genre_translation` 从“未检查”提升为可追踪的 `DATA_GAP`；
- 把 5 个失败链固定为后续回归集；
- 明确重复率高是应用 projection 池窄，不得倒逼 canonical 扩理论结构。

未对 `generator_core_v0.2.js` 做无证据改写。

## 7｜下一轮最高风险

最高风险不是模式逻辑，而是两个应用层问题：

1. `nz` 题材翻译覆盖为 0，导致题材语义守恒检查无法真正执行；
2. 只有 5 个 primary structure，造成 60 样本下 91.67% excess duplicate。

下一轮优先应先补“有证据的 genre_translation 校准/回归门”，而不是为了降重复率制造新的 nz 理论结构。随后再评估 structure-aware recent-exclusion 是否值得进入 generator runtime。
