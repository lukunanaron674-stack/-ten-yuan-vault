## 本轮发现并修复的运行时问题

### GRAPH_CHAIN_TRUNCATED

修复前 `composeGraph()` 的 node-edge path 只到 `concrete_candidate`：

`symbol → sub_semantic → changed_variable → relation_shape → module_grammar → concrete_candidate`

但 materialized module 已经存在 `genre_translation`。因此 graph 模式无法显式表达/审计最后一段题材翻译链，造成“single/multi 有字段、graph 图链丢字段”的模式不一致。

修复：
- 新增 graph node：`genre_translation`
- 新增 edge：`concrete_candidate → genre_translation`
- 即使当前映射对应翻译为 null，也必须显式保留 null node，不能把“未知/缺数据”静默吞掉。

修复前：20/20 graph 样本都缺最后节点/边；按 60 样本口径为 33.33% mode-chain failure。
修复后：0/20 graph 样本缺链；post-fix mode_failure_rate=0%。
