## 5｜代表失败样本 / 回归失败链

### F01｜GLOBAL_STRUCTURE_DUPLICATION
`60 samples → N-W-001..005 仅 5 个 structure_id → seed/genre 改变 → primary structure 重复`

### F02｜GENRE_TRANSLATION_GAP
`requested genre → 抽中 N mapping → 该 mapping 无该 genre 的 exact genre_translation → genre_translation=null`

代表：`中古奇幻 → N-W-002 → concrete=地下城邦类候选 → genre_translation=null`。不能把题材名本身当翻译成功。

### F03｜CROSS_MODULE_DEDUP_NOT_IMPLEMENTED
`世界观 → 服装/发型/道具/人生 → 无同级 machine projection → 无法执行跨模块同义去重`

### F04｜LIFE_ORDER_NOT_IMPLEMENTED
`出生 → 成长 → 反噬 → 结局 → 当前无 life timeline runtime → NOT_IMPLEMENTED`

### F05｜OPPOSITE_POLE_MACHINE_AUDIT_DATA_BLOCKED
`n 世界观 → 需要同轴对端世界观机器映射 → registry 当前未覆盖该完整对照 → DATA_BLOCKED`

## 6｜实际修复 / 状态变化

本轮不修改 generator core，也不自由补写 mapping。真实变化是新增可执行 60-sample R11 测试资产，并首次把 N 的题材翻译覆盖率固定为 23.33%，将“非 null 翻译语义守恒”和“翻译缺失”分开记录。

测试资产要求未来映射或 generator 改动时继续验证：same seed reproducibility、single symbol isolation、multi responsibilities、graph 7-node/6-edge chain、pseudo-vector rejection、translation coverage 与 5 个 known failure chain。

## 7｜运行边界

Node `v22.16.0` 可用。当前容器无法 DNS 访问 github.com，因此无法完整 checkout current-main 后执行仓库全 suite。本轮 ACTUAL_RUNTIME 为依据写前远端回读的 `generator_core_v0.2.js` 与当前 N/NX mapping blobs 重建的 focused 60-sample harness；不能冒充完整 repo suite pass。

## 8｜下一轮最高风险

最高风险不是 N 的翻译漂移，而是 `genre_translation` 覆盖稀疏：本轮只有 14/60 非 null。下一步应先做 application-level `genre_translation coverage / unsupported-genre explicit status`，让“没有翻译”成为可机读状态，而不是继续只返回 null；不要为了把覆盖率数字刷高而现场发明理论映射。
