# 五行轴角色生成器｜nx × 世界观压力测试 R2

> 只验证应用映射层与 `generator_core_v0.2.js` 的生成逻辑，不修改 L1/L2 canonical、十元信息卡、准度卡、正式关系卡或 behavior evidence。

## 1｜测试目标

本轮选择 `nx × 世界观`。原因：当前 nx 世界观已有 5 条机器映射，且最容易被“职位、服从、求人、关系网、弱势”等表面词诱导；同轴 `zx` 与近邻 `xn/x` 也最容易在生成阶段发生职责偷渡。

固定编译链：

`symbol → sub_semantic / changed_variable → relation_shape → module_grammar → concrete_candidate → genre_translation`

## 2｜样本设计

总样本 60：

- single：20；
- multi：20，`nx` primary + `zx` same-axis secondary audit；
- graph（无向量尺标）：20。

题材固定覆盖 4 类：`中古奇幻 / 太空歌剧 / 赛博都市 / 军事科幻`。

当前机器层只有“世界观”模块，因此真正跨模块 lock/reroll 与“一生/生命周期”顺序测试不能伪造：分别记为 `PARTIAL_ONLY` 与 `NOT_IMPLEMENTED`。

## 3｜运行说明

Node 实际可用。由于本执行环境无法直接 clone GitHub，实际运行采用：

- 远端回读 `generator_core_v0.2.js`；
- 远端回读当前 `nx × 世界观` 5 条映射与同轴对端 `zx × 世界观` 5 条映射；
- 按当前 generator 算法建立 targeted extracted runtime；
- 生成 60 条并执行 seed、lock、模式、去重与字段审计。

因此本文件的 ACTUAL_RUNTIME 仅代表本轮 target subset，不代表完整 current-main repository suite 已通过。

## 4｜指标

| metric | result | note |
|---|---:|---|
| semantic_drift_rate | `0/60 = 0%` | `sub_semantic / changed_variable / relation_shape / module_grammar` 均直接来自选中的 mapping，题材没有改写这些结构字段；但存在 genre_translation 字段串位，见失败 F01-F05 |
| neighbor_leak_rate | `0/20 = 0%` | single 模式只从 `symbol === nx` 的 pool 取值；未见 zx/xn/x 偷渡到 single 主链 |

| concrete_noun_concentration | `8/60 = 13.33%` | top concrete output 出现 8 次；尚未形成单一名词垄断，但 5 个结构骨架导致模板重复仍高 |

附加审计：

- pseudo-vector：`0`；multi 未出现 weight/ratio/percent；graph 未出现强弱分数。
- single 邻居十元偷渡：`0`。
- 当前 60/60 输出的 `genre_translation` 字段都只是 genre 标签，而不是翻译结果。
- 其中至少 14/60 样本把完整题材翻译句错误放进 `concrete_candidate`，说明当前 `chooseConcrete()` 把 `genre_translation[genre]` 与 concrete candidate 混用了。

## 5｜固定检查结论

1. **三模式算法**：PASS。multi 与 graph 都有真实结构差异，不是只改标签。
2. **single 邻居偷渡**：PASS，本轮 0/20。
3. **multi 主从职责**：PASS，primary/secondary 均有 responsibility；secondary 有 relation_source；未出现百分比炖汤。
4. **graph 伪向量**：PASS，未出现强弱/百分比/ratio。
5. **具象名词反定义十元**：本轮未发现；但 concrete output 池偏窄。
6. **颜色/职业/身份/题材/情绪当判据**：本轮未发现 generator 反推 symbol；symbol 仍由调用配置决定。
7. **模块同义词重复**：当前只有世界观模块，无法做世界/服装/发型/道具/人生跨模块同义词审计，`NOT_IMPLEMENTED_DATA_COVERAGE`。
8. **人生时间顺序**：`NOT_IMPLEMENTED`。
9. **最近邻/同轴对端**：single 可分；multi 能显式把 zx 放在 secondary 并保留职责来源，但 xn/x 当前无世界观 machine mapping，完整 nearest-neighbor 横向审计仍不完整。
10. **题材翻译守语义**：结构字段 0 drift，但输出字段串位，FAIL。
11. **相同 seed**：PASS，20/20。
12. **模块锁定**：当前世界观模块 PASS 10/10；跨模块只标 PARTIAL。
13. **重复率/集中度/模板化**：FAIL，primary structure duplicate 91.67%，当前只有 5 个 nx 世界观结构骨架。

## 6｜5 个代表失败样本（保留为回归集）

### F01｜single / S0 / 中古奇幻 / NX-W-001

`nx → 既有方向承接与角色接口接入 → 外部任务接口先成立 → 方向接口先于角色 → [完整翻译句] → genre_translation="中古奇幻"`

失败：`concrete_candidate` 被写成“角色通过既有誓约席加入已设终点的长期远征……”完整题材翻译句，而 `genre_translation` 只有标签 `中古奇幻`。

分类：`APPLICATION_RUNTIME_FIELD_MISPLACEMENT`。

### F02｜single / S2 / 赛博都市 / NX-W-002

`nx → 他者权限通道借用 → 持权节点许可 → 借用权限接口 → [完整翻译句] → genre_translation="赛博都市"`

失败：`concrete_candidate` 被写成“角色调用他人账户或授权令牌……”；题材翻译句与具象候选槽位混用。

分类：`APPLICATION_RUNTIME_FIELD_MISPLACEMENT`。

### F03｜single / S7 / 军事科幻 / NX-W-003

`nx → 既有位置就位 → 换人不换方向 → 可替换执行席 → [完整翻译句] → genre_translation="军事科幻"`

失败：`concrete_candidate` 变成“接班导航员进入已有任务席……”整句；不再是 concrete noun/candidate。

分类：`APPLICATION_RUNTIME_FIELD_MISPLACEMENT`。

### F04｜single / S12 / 中古奇幻 / NX-W-001

结构链与 F01 在不同 seed 下再次命中同一个 `structure_id` 与同一题材翻译句。

失败：不是 seed 不可复现，而是当前 5 个结构池在 60 样本压力下模板重复过高。

分类：`HIGH_TEMPLATE_REUSE`。

### F05｜graph / nx / unsupported-translation fallback

`nx → 任一 mapping → graph nodes/edges → concrete_candidate fallback → genre_translation=<genre label>`

失败：当某 mapping 没有对应 `genre_translation[genre]` 时，系统回退到 generic concrete candidate，但输出仍把 `genre_translation` 写成 genre 标签，调用方无法区分“真实已翻译”与“仅使用 generic fallback”。

分类：`GENRE_TRANSLATION_PROVENANCE_AMBIGUOUS`。

## 7｜实际修复 / 状态变化

本轮没有修改 generator 源码，原因不是理论不确定，而是当前执行环境不能直接 checkout current-main 后跑完整 regression suite。直接在线改 `generator_core_v0.2.js` 会在无法执行仓库全 suite 的情况下提高破坏风险。

已确认的最小应用层修复方向：

1. `chooseConcrete()` 只从 `concrete_candidate` 选择 concrete；
2. 新增独立 `chooseGenreTranslation()`；
3. `materialize()` 返回真实 `genre_translation` 文本或明确 `null/fallback` 状态，而不是 genre label；
4. genre 标签单独放 `genre_context`（或等价字段）；
5. 加回归门：translated sentence 不得进入 concrete slot。

该问题登记为应用 runtime 修复，不反馈 canonical。
