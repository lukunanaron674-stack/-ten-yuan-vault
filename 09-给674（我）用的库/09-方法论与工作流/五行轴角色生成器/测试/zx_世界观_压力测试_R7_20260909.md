# zx × 世界观｜生成器压力测试 R7｜2026-09-09

> 只验证应用映射层与 current-main `generator_core_v0.2.js` 的生成逻辑；不修改 L1/L2 canonical、十元信息卡、准度卡、正式关系卡或 behavior evidence。

## 1｜测试目标

本轮选择 `zx × 世界观`。原因：前序已分别压过 nx / nz / n / zn，而 zx 尚未做独立 60 条压力审计；当前 ZX-W-001..005 同时包含 candidate 与 evidence-supported，可检查状态混合池是否造成模式漂移、邻居偷渡、模板集中或题材翻译断点。

测试结构链固定为：

`symbol → sub_semantic/changed_variable → relation_shape → module_grammar → concrete_candidate → genre_translation`

## 2｜样本与模式

总样本：60。

- single：20；primary=`zx`
- multi：20；primary=`zx`，secondary=`zn`

## 5｜固定检查结论

1. 模式确实改变算法：single 走单 pool；multi 生成 primary/secondary/responsibility/relation_source；graph 生成完整 node-edge semantic→genre 链。
2. single 20 条未发现 zn 或其他邻居 symbol 偷渡。
3. multi 没有主从职责缺失，也没有百分比、权重、ratio 炖汤。
4. graph 未出现隐式强弱分数。
5. 未发现某一个 concrete noun 被写回 structure_id 作为 zx 定义；但本批最高单一名词占 25%，具象集中度偏高。
6. 颜色、职业、身份、题材、情绪没有进入 symbol/structure 判据。
7. 当前机器运行仍只有世界观模块；世界/服装/发型/道具/人生跨模块同义重复审计为 NOT_IMPLEMENTED。
8. 人生事件时间顺序 runtime 为 NOT_IMPLEMENTED。
9. zx ↔ zn 可做当前应用层跨轴压力对照；完整最近邻/同轴对端机器覆盖仍受现有 mapping coverage 限制。
10. zx 的 genre_translation 全为空，因此“题材翻译是否改变核心语义”本轮为 DATA_GAP，不能伪造 PASS。
11. 同 seed 重跑：20/20 一致。
12. lock：10/10 保留当前世界观完整模块；仅单模块 PARTIAL_ONLY，不能冒充跨模块 selective lock。
13. primary structure excess duplicate 55/60，模板化风险高；具象层也出现 25% 峰值集中。

## 9｜下一轮最高风险

最高风险仍是结构池窄导致的模板重复，但不应通过伪造新理论结构解决。

下一步优先验证 deterministic `recent_structure_exclusion` / `exclude_structure_ids` 一类应用层采样策略：

- 只减少短窗口连续撞同 structure；

- lock 模块不能参与重抽；
- secondary 变化不能掩盖 primary 重复；
- pool 耗尽必须显式 fallback / DATA_BLOCKED，不得静默换 symbol。

第二风险是 ZX-W-001..005 的 genre_translation 全空，需要单独做有证据的应用层题材翻译校准，再回来审计 semantic drift。
