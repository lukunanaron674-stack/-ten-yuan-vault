## 为什么要加这一门

现有 `semantic_ir_ai_extraction_adapter_v0.1` 已经能做到：

- 只接受带 evidence_span 的 observation；
- 低置信度保持 unknown；
- 缺证据或 span 不匹配保持 unknown；
- 禁止 provider 直接注入 symbol；
- 最终仍通过安全 extractor 形成固定 12-field Semantic IR。

但它本身不判断“同一个结构换一种说法后，provider 是否把 object_layer / current_window / relation_source / decision_right / path_set 改漂”。因此需要独立的 paraphrase/minimal-pair evaluator。

## 新增 fixture

`实现/semantic_ir_paraphrase_stability_v0.1.test.js` 内嵌 `semantic-ir-paraphrase-stability-fixture-v0.1`。

固定 24 条测试样本：

- 18 条同结构改写：6 组 × 每组 3 种说法；
- 6 条最小差异样本：3 对 × 每对只允许一个目标字段发生变化。

覆盖重点：

- 外部既有审批接口的不同说法；
- 同词“退出”但锁定任务参与层，不漂到成员关系层；
- current_window 与 future_endpoint unknown 分离；
- chosen route blocked 与 complete path-set 仍有替代路径；
- complete path-set exhausted；
- same changed_variable / formal relation_source；
- personal-consent-layer vs organization-approval-layer；
- same changed_variable / different relation_source；
- one-hour current_window vs lifecycle-stage current_window。

fixture 中的 normalized values 只作为应用层回归标签，不拥有 canonical 权限。

## 新增 evaluator

`实现/semantic_ir_paraphrase_stability_v0.1.js`

新增固定指标：

- `ir_field_guess_rate`
- `expected_value_mismatch_rate`
- `paraphrase_field_drift_rate`
- `minimal_pair_overmutation_rate`
- `minimal_pair_underreaction_rate`
- `unknown_preservation_rate`
- `unknown_silent_swallow`

判定原则：

1. 同结构 paraphrase 的指定 invariant fields 必须保持一致；
2. minimal pair 只允许 `expected_delta_fields` 发生变化；
3. fixture 未允许的字段被 provider 填入，计入 `ir_field_guess_rate`；
4. 明确要求 unknown 的字段被填入，计入 `unknown_silent_swallow`；
5. unknown/null 本身不是失败，没有证据却猜字段才是失败。

## 反向证伪

测试器额外注入四种故意错误 provider 输出：

1. 同结构改写中把 `object_layer` 改成错误值；
2. minimal pair 除目标字段外再错误改变 `changed_variable`；
3. fixture 未允许时凭空新增 `relation_source`；
4. 明确要求 unknown 的 `future_endpoint` 被强行猜成 known。

四种错误均被 evaluator 捕获。说明本轮 PASS 不是只会接受正确 fixture 的“自我庆祝式测试”。

## 下一最高风险

下一步不再增加 fixture 数量。优先把一个真实 provider 接到 `evaluateParaphraseStability()`：本地 Qwen / 现有可调用模型任选其一，但必须保留 provider_id / provider_version / evidence_span / confidence provenance。

真实 provider 首轮只跑这 24 条；若失败，按字段归因回流：

- object_layer / current_window / relation_source / decision_right / path_set 漂移 → “十元语义解释器｜轮转校准”；
- provider 为了给出答案而补全无证据字段 → interpreter extraction policy；
- 不在本轮修改 canonical，也不把失败倒逼成理论定义变化。
