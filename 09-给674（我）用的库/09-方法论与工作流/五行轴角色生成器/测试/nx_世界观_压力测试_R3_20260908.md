## 1. 测试目标

本轮继续选择 `nx × 世界观`，原因是 R2 已发现 `genre_translation / concrete_candidate` 分槽错误，且 R3 开始时最新 main 的 generator_core_v0.2.js 仍存在该缺陷。本轮先做最小修复，再执行 60 样本修复后压力回归。

结构链固定观察：

`symbol → sub_semantic/changed_variable → relation_shape → module_grammar → concrete_candidate → genre_translation`

## 2. 当前数据与模式

- primary symbol：`nx`
- multi secondary：`zx`，只作为同轴对端压力参照，职责显式分离
- module：世界观
- 当前 nx 世界观映射：NX-W-001 ～ NX-W-005，共 5 个 primary structure
- 模式：single 20 / multi 20 / graph 20
- 总样本：60
- 题材：中古奇幻 / 太空歌剧 / 赛博都市 / 军事科幻

## 3. 本轮真实修复

R2 缺陷：旧 `chooseConcrete(mapping, genre, rng)` 会优先读取 `mapping.genre_translation[genre]`，导致完整题材翻译句进入 `concrete_candidate`；同时 `materialize()` 把 `genre_translation` 写成题材标签本身。

R3 修复：

- `concrete_candidate` 只从 `mapping.concrete_candidate` 抽样；
- 新增独立 `chooseGenreTranslation(mapping, genre, rng)`；
- `genre_translation` 从 `mapping.genre_translation[genre]` 抽样；
- 没有对应题材翻译时返回 `null`，不伪装成已翻译；
- 未修改 structure_id、mapping 判定、模式逻辑、seed 算法、lock 算法。

新增回归门：

1. 已支持题材时，concrete 必须属于 concrete_candidate 池，translation 必须属于对应 genre_translation 池；
2. 未支持题材时 concrete 仍正常生成，genre_translation 必须为 null。

## 6. 13 项固定审计结论

1. 模式不是只换标签：PASS。single 为单 pool；multi 真实 primary+secondary+responsibility+relation_source；graph 生成 node-edge path。
2. single 邻居十元偷渡：0/20。
3. multi 主从职责不清 / 百分比炖汤：本轮未发现；weight/percent/ratio 仍由 runtime hard reject。
4. graph 偷引强弱分数：未发现；assertNoPseudoVector 通过。
5. 具象名词过度绑定：未发现单名词反向作为 symbol 判据，但 5 个结构池导致重复显著。
6. 颜色/职业/身份/题材/情绪误作十元判据：本轮未发现；题材只作用于 translation 输出。
7. 世界/服装/发型/道具/人生同义词重复：跨模块机器覆盖不足，NOT_IMPLEMENTED。
8. 人生事件时间顺序：NOT_IMPLEMENTED。
9. 最近邻/同轴对端：single 无 zx 泄漏；multi 中 zx 以显式 secondary 职责存在，可区分。完整 nx↔xn 横测仍受映射覆盖限制。
10. 题材翻译换掉核心语义：修复后 translation 与 structure 分槽；结构字段不受 translation 改写。
11. 相同 seed 可复现：20/20。
12. 模块锁定后重抽：世界观锁 10/10；跨模块 selective lock 未实现。
13. 重复率/名词集中度/模板化：primary duplicate_structure_rate 91.67%，仍为本轮最大失败。

## 7. 五个代表失败样本与失败链

以下保留为后续回归集，失败类型均为 `DUPLICATE_STRUCTURE`，不是 semantic drift：

### F01｜single｜S12｜NX-W-001
`nx → 既有方向承接与角色接口接入 → 最终方向由外部接口给出 → 外部任务先成立→主体接入→不争最终重设权→沿既定方向推进 → 世界结构先于角色存在 → concrete/translation`

失败：与同批其他 NX-W-001 样本 primary structure_id 重复。

### F02｜single｜S18｜NX-W-001
失败链同 F01；seed 不同但 primary structure 仍相同。说明 seed 只能在有限映射池内重抽，不能创造新结构。

### F03｜multi｜M0｜NX-W-001 + zx secondary
primary 仍为 NX-W-001；secondary zx 职责明确，但按 primary structure 审计仍重复。

### F04｜multi｜M6｜NX-W-001 + zx secondary
同一 primary structure 再次出现。multi 增加组合层，不等于 primary 结构去重。

### F05｜multi｜M7｜NX-W-001 + zx secondary
再次重复。失败指向 mapping coverage / structure selection 策略，而不是理论 canonical。

这些失败不应通过随手制造新的 nx 定义来解决；若需要扩展，只能新增有证据的应用映射或改进 runtime 的 structure-aware sampling/dedupe 策略。

## 9. 本轮结论

R2 的 `genre_translation / concrete_candidate` 槽位串线已得到真实应用层修复，并通过修复后 60 样本压力回归：`genre_slot_error_rate` 与 `concrete_sentence_leak_rate` 均降到 0。

当前最高风险已从“题材翻译污染 concrete 槽”转移为“5 个 primary structure 对大量 seed 的模板复用”。本轮不修改 canonical，也不为降低统计重复率制造未经证据支持的新十元结构。

## 10. 下一轮断点

优先设计应用层 `structure-aware sampling / recent-structure exclusion` 的最小方案，在不改变 deterministic seed 和 lock integrity 的前提下，验证：
