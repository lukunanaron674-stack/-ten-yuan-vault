- `zn少女`

- `x+z少女`
- `x＋z少女`

规则：
- longest-match；`x并z` 永远作为单一 canonical symbol；
- 只有 `+ / ＋` 显式表示多 symbol；
- `zxzn少女` 这类相邻 canonical token 无连接符时返回 `ERROR_AMBIGUOUS_TOKEN`；
- unknown token 返回 `ERROR_UNKNOWN_TOKEN`；
- 空主体返回 `ERROR_EMPTY_SUBJECT`；
- 单 symbol 自动 `single`；多 symbol 自动 `multi`，但缺显式职责结构时返回 `BLOCKED_MULTI_RESPONSIBILITY_REQUIRED`；
- graph 只通过现有 runtime 的 nodes/relations/path 表达，不增加权重。
