## 触发器成熟度

当前：**P0-alpha / parser hard-gate established**。

已支持并归一化：
- `zn少女`
- `zn 少女`
- `ZN少女`
- `zn的少女`
- `xz少女`
- `x并z少女`
- `x+z少女`
- `x＋z少女`

规则：
- longest-match；`x并z` 永远作为单一 canonical symbol；
- 只有 `+ / ＋` 显式表示多 symbol；
- `zxzn少女` 这类相邻 canonical token 无连接符时返回 `ERROR_AMBIGUOUS_TOKEN`；
- unknown token 返回 `ERROR_UNKNOWN_TOKEN`；
- 空主体返回 `ERROR_EMPTY_SUBJECT`；
- 单 symbol 自动 `single`；多 symbol 自动 `multi`，但缺显式职责结构时返回 `BLOCKED_MULTI_RESPONSIBILITY_REQUIRED`；
- graph 只通过现有 runtime 的 nodes/relations/path 表达，不增加权重。

## 当前真实数据边界

当前 machine-readable mapping 只有世界观模块：
- `zx × 世界观`
- `z × 世界观`：pending-review，默认生产池排除
- `zn × 世界观`

因此：
- `zx少女`、`zn少女` 已接入现有 `generator_core_v0.2.js` 的世界观 composer；
- `z少女` 默认 `DATA_BLOCKED`，除非显式允许 pending；
- `nz/n/nx/xn/x/xz/x并z` 可正确解析，但世界观 runtime 数据仍为 `DATA_BLOCKED_MAPPING_MISSING`；
- 服装、发型、身体/脸、道具、身份/行为、关系、一生、构图、具象名词等模块仍返回 `NOT_IMPLEMENTED`，不得伪造完整角色。
