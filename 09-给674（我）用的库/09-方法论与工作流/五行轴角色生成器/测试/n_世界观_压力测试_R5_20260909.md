## 1｜测试目标

选择 `n × 世界观`。原因：current-main 已有 5 条 n 世界观结构且部分条目已有 genre_translation，适合同时检查结构守恒、n↔nz 邻居边界、题材翻译覆盖、seed/lock 和重复率。

执行环境：Node v22.16.0。

本轮按 current-main `generator_core_v0.2.js` 的 deterministic seed / single / multi / graph / lock / pseudo-vector guard 逻辑，以及 current-main `世界观_机器映射_v0.1.json` 中 N-W-001..005、NZ-W-001..005 构造目标 stress harness。不是完整仓库 runtime suite。

- single：20；主符号 n
- multi：20；primary=n，secondary=nz；职责显式分离，不使用 weight/percent/ratio

结构链统一记录：

`symbol → sub_semantic/changed_variable → relation_shape → module_grammar → concrete_candidate → genre_translation`

## 3｜固定检查结果

1. 三模式真实走不同执行路径：PASS。
2. single 邻居十元偷渡：0/20。
3. multi 主从职责存在且无百分比权重：PASS。
4. graph 伪向量/强弱分数：0。
5. 具象名词未反向写入 structure_id；但结构池仅 5 条，模板重复高。
6. 颜色/职业/身份/题材/情绪未成为 symbol 判据。
7. 世界/服装/发型/道具/人生跨模块同义重复：NOT_IMPLEMENTED，本轮仅世界观机器映射。
8. 人生事件时间顺序：NOT_IMPLEMENTED。
9. n↔nz 可做邻居压力对照；n↔x并z 同轴对端机器横测：DATA_BLOCKED（x并z 尚无世界观机器映射）。
10. genre_translation 不改写结构字段，但覆盖不足；本轮仅 15/60 非空。
11. 相同 seed 可复现：20/20。
12. 世界观模块 lock 后 reroll 不漂：10/10 PARTIAL_ONLY；跨模块 selective lock 未实现。
13. primary structure 重复率高：55/60 excess duplicates。

- 首次将 `n × 世界观` 的 genre translation 稀疏问题量化：75% null（基于本轮四题材压力集）。
- 固定 5 个失败链进入回归资产。

## 7｜下一轮最高风险

优先处理 `structure-aware recent exclusion` 与 genre translation coverage 的相互作用：

1. recent-structure exclusion 必须保持 `same input + mapping_version + seed + policy` 可复现；
2. 不得用不同 concrete noun 冒充结构多样性；
3. multi secondary 组合不能掩盖 primary 结构重复；
4. 若补 genre_translation，只补已有结构的题材转译，不新增无证据十元结构；
5. 补完后重跑本 60 样本并检查 semantic_drift_rate 仍为 0。
