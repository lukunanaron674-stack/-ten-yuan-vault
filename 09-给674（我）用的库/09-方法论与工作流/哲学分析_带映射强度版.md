# 加入「映射强度」后的哲学分析版

## 0. 先钉规则

**映射强度 ≠ 体量。**

| 项目 | 回答什么 |
|---|---|
| **体量** | 这个东西在不在场、占不占空间、密度多大 |
| **映射强度** | 这个内容映射到某个十元 / 关系 / 动态链时，贴合得有多硬 |

一句话：

```text
体量看“存在密度”，映射强度看“对应准度”。
```

比如哲学的总体体量可以是 **9**，但哲学映射到不同十元时强度不同：

```text
x = 9.5
zn = 9
xn = 8
nx = 8
z = 6.5
n = 7
```

不是所有点都一样亮。要像调音台一样拉推子。🎛️

---

## 1. 映射强度标尺

| 分数 | 含义 | 判断 |
|---:|---|---|
| **1-2** | 弱映射 | 只是擦边，不建议入链 |
| **3-4** | 辅助映射 | 可作背景，不作主判断 |
| **5** | 中性映射 | 有关系，但不够定核心 |
| **6-7** | 可用映射 | 能进入分析，但要看证据 |
| **8-9** | 强映射 | 可作为主链节点 |
| **10** | 锚点映射 | 几乎就是这个十元的标准样本 |

---

## 2. 哲学的十元点映射强度

### 2.1 点位总表

| 十元 | 哲学映射内容 | 映射强度 | 说明 |
|---|---|---:|---|
| **x** | 死亡、痛苦、虚无、欲望、根本不安 | **9.5** | 哲学最常从“活着为什么痛 / 为什么会死 / 为什么不满足”起火 |
| **zn** | 意义、价值、精神追问、存在理由 | **9** | 哲学最终一定会追到“意义如何成立” |
| **xn** | 逻辑、定义、论证规则、方法 | **8.5** | 没有方法就变空想，哲学必须被规则切开 |
| **nx** | 怀疑、辨析、反驳、概念审查 | **8** | 哲学不是接受答案，而是审查答案 |
| **z** | 命题、判断、观点显现 | **6.5** | 重要，但它是结果，不是最深发动机 |
| **n** | 文本、学派、传统、课堂、承载系统 | **7** | 负责保存和传递思想，但不等于哲学本体 |
| **zx** | 突破性提问、破旧前提 | **7.5** | 哲学常靠一个“反问”破局 |
| **xz** | 临界、荒诞、危险真相、存在焦虑 | **7.5** | 存在主义、悲剧哲学、死亡问题很强 |
| **x并z** | 概念包装、理论表述、语言外壳 | **6.5** | 哲学必须通过语言显影，但语言也会遮蔽 |
| **nz** | 安慰、归宿、依恋、温柔停靠 | **4.5** | 哲学可能触及，但不是主发动机 |

---

### 2.2 最硬前三点

```text
x 9.5：根本不安
zn 9：意义追问
xn 8.5：概念方法
```

哲学最核心不是“观点很多”，而是：

```text
不安足够深
意义追问足够硬
方法承载足够稳
```

## 3. 按 GitHub 位置盘加「关系映射强度」

GitHub 位置盘锁定了生、被生、克、被克、补五类关系，且强调关系五对是基础位置边型，不是内容感觉边。

十元查表中，x 的位置是：

```text
x 生 x并z
x 被 nx 生
x 克 z
x 被 nz 克
x 补 zn
```

---

### 3.1 x 作为哲学起手的关系强度

| 位置关系 | 标准位置 | 哲学映射 | 映射强度 |
|---|---|---|---:|
| **补** | x 补 zn | 根本不安补厚意义问题 | **9.5** |
| **生** | x 生 x并z | 不安生成概念语言和理论外壳 | **7.5** |
| **克** | x 克 z | 深层问题压制浅层口号答案 | **8.5** |
| **被生** | x 被 nx 生 | 怀疑越拆，越挖出更深不安 | **8** |
| **被克** | x 被 nz 克 | 归宿感 / 安慰暂时压住不安 | **5.5** |

结论：

```text
哲学的 x 不是单独乱冲，而是最强地补 zn，其次克 z，再被 nx 挖深。
```

---

### 3.2 zn 作为核心补位的关系强度

GitHub 表中，zn 的位置是：

```text
zn 生 n
zn 被 zx 生
zn 克 xn
zn 被 xz 克
zn 补 x
```

| 位置关系 | 标准位置 | 哲学映射 | 映射强度 |
|---|---|---|---:|
| **补** | zn 补 x | 意义必须面对痛苦、欲望、死亡才变厚 | **9.5** |
| **生** | zn 生 n | 意义沉淀成文本、学派、生活方式 | **8** |
| **克** | zn 克 xn | 意义追问挑战僵硬规则和旧定义 | **8.5** |
| **被生** | zn 被 zx 生 | 突破性提问生成新意义 | **8** |
| **被克** | zn 被 xz 克 | 荒诞、危险、临界压垮旧意义 | **7.5** |

结论：

```text
zn 在哲学里不是默认起手，而是被 x 补厚、被 zx 生出、再反过来挑战 xn。
```

## 4. 关系对子强度

关系对子是多个关系五对的组合，不是单边。  
关系对子是多个关系五对组合，动态链条是组合落到具体十元后的力流。

---

### 关系对子 A：补 + 生

```text
x 补 zn
→ zn 生 n
```

| 环节 | 映射强度 |
|---|---:|
| x 补 zn | **9.5** |
| zn 生 n | **8** |
| 平均强度 | **8.75** |

解释：

```text
根本不安补厚意义
→ 意义沉淀成文本、学派、传统、生活方式
```

这是哲学最稳的“意义落地链”。

---

### 关系对子 B：克 + 克 + 生

GitHub 已确认示例：

```text
zn 克 xn
→ xn 克 zx
→ zx 生 zn
```

| 环节 | 哲学解释 | 映射强度 |
|---|---|---:|
| zn 克 xn | 意义追问挑战旧规则 | **8.5** |
| xn 克 zx | 方法压住乱冲式突破 | **8** |
| zx 生 zn | 真正的反问生成新意义 | **8.5** |
| 平均强度 |  | **8.33** |

解释：

```text
意义不服旧规则
→ 方法约束乱冲
→ 合格突破生成新意义
```

这是哲学的“概念炼刀链”。

---

### 关系对子 C：生 + 生 + 克

```text
x 生 x并z
→ x并z 生 z
→ x 克 z
```

| 环节 | 哲学解释 | 映射强度 |
|---|---|---:|
| x 生 x并z | 不安生成概念外壳 | **7.5** |
| x并z 生 z | 概念外壳生成观点表达 | **7** |
| x 克 z | 深层问题压制浅答案 | **8.5** |
| 平均强度 |  | **7.67** |

解释：

```text
问题生成语言
→ 语言生成观点
→ 深层问题反过来审判观点
```

这是哲学为什么会不断推翻第一版答案。

## 5. 动态链加映射强度

### 哲学主动态链

```text
x
→ 补 zn
→ zn 克 xn
→ xn 克 zx
→ zx 生 zn
→ zn 生 n
→ n 生 xn
→ xn 生 xz
```

### 链条逐段强度

| 段落 | 位置关系 | 哲学含义 | 强度 |
|---|---|---|---:|
| x → zn | 补 | 根本不安补厚意义 | **9.5** |
| zn → xn | 克 | 意义追问挑战规则 | **8.5** |
| xn → zx | 克 | 方法限制乱冲突破 | **8** |
| zx → zn | 生 | 破局提问生成新意义 | **8.5** |
| zn → n | 生 | 意义沉淀成传统 / 文本 | **8** |
| n → xn | 生 | 传统生成规则和方法 | **7.5** |
| xn → xz | 生 | 方法逼出边界 / 临界问题 | **7** |

### 链条平均映射强度

```text
总强度 = 8.14 / 10
```

### 强度判断

| 项目 | 评分 |
|---|---:|
| 点位强度 | 8.2 |
| 关系强度 | 8.3 |
| 动态链强度 | 8.14 |
| 五大主题归仓强度 | 9 |

结论：

```text
哲学映射到“本体 zn+x”的主仓强度最高；
映射到动态链时，是强链，但不是满分锚点，因为哲学内部流派差异太大。
```

## 6. 五大主题归仓强度

GitHub 五大主题表锁定：本体是 **zn+x**，核心问题是“我是谁、靠什么活着、核心如何被冲击”。

| 五大主题 | 哲学关系 | 映射强度 |
|---|---|---:|
| **本体 zn+x** | 我是谁、我靠什么活、意义如何面对欲望与死亡 | **9.5** |
| **因果 zx+nx** | 理由链、责任链、论证链、选择后果 | **8** |
| **时间 xn+z** | 概念史、时代问题、变化、阶段、等待 | **7.5** |
| **空间 x并z+n** | 学派、学院、文本传统、思想场域 | **7** |
| **命运 xz+nz** | 存在漂流、荒诞、归宿、死亡 | **7.5** |

最终归仓：

```text
主仓：本体 zn+x，强度 9.5
副仓：因果 8，时间 7.5，命运 7.5，空间 7
```

## 7. 新模板：以后教任何概念都加这一栏

