# 十元血肉采矿方法论

## 0. 文件定位

本文件是 `07-Codex大脑库/十元血肉采矿方法论.md` 的方法论归档版，方便在 09 方法论区统一查阅。

07 版负责执行，09 版负责方法论封存。

一句话：

> 分析作品不是为了写影评，而是为了给十元长血肉。

---

## 1. 采矿目标

每次分析必须回答：

```text
这个案例给哪个十元增加了什么血肉？
这个血肉属于人物、行为、空间、视觉、声音、叙事、动态链，还是误判反例？
能不能回填到信息量卡？
能不能变成创作模板？
```

---

## 2. 媒介价值

| 媒介 | 最适合补什么 |
|---|---|
| 影视 | 关系血肉 / 五大主题血肉 / 叙事动态链 |
| 动画 / 漫画 | 视觉血肉 / 姿态血肉 / 角色体量 |
| 音乐 | 顺序感谱 / 力的变化 / 时间血肉 |
| 游戏 | 交互血肉 / 资源血肉 / 反馈反噬 |
| 图像 / 视觉案例 | 视觉接口 / 材质 / 色温 / 信息量 |

---

## 3. 标准流程

```text
1. 先定主骨
2. 拆人物 / 行为 / 空间 / 视觉 / 声音 / 叙事血肉
3. 找关系牙印
4. 跑动态链
5. 回填密度卡
6. 提炼创作模板
```

---

## 4. 三大产物库

### A. 十元血肉库

每个十元下挂人物、行为、空间、视觉、声音、叙事、误判反例与案例回填。

### B. 十元关系牙印库

记录十元之间真实作用痕迹。

### C. 创作模板库

把分析转成未来可复用故事、角色、场景、音乐、游戏模板。

## 6. 触发指令

```text
用十元血肉采矿方法论分析【作品/角色/场景/音乐】：
目标不是影评，而是提取可回填到十元密度卡的血肉。
必须输出：主骨校验、人物/行为/空间/视觉/声音/叙事血肉、关系牙印、动态链、误判反例、回填位置、可偷走模板。
```

---

## 7. 禁止项

```text
禁止只写剧情总结。
禁止只夸作品。
禁止只给评分。
禁止没有回填位置。
禁止把五大主题倒推成十元起手。
禁止把视觉层直接反推本体。
禁止把承载位默认写成 n。
禁止把怪物 / 恐怖从 xz 核心血肉里排除。
```

---

## 8. 封存句

> 作品是矿，十元是仓，动态链是矿脉，血肉是可复用的创作组织。
