# Judge Rules

## Critical gate

Reject immediately if:
- J4 structure cannot be described without theory labels
- J6 structure did not actually change
- J7 eventization contains no real event

## Full checklist

J1 Remove color: still works?
J2 Remove genre: still works?
J3 Remove identity: still works?
J4 Remove theory words: can the relation still be described?
J5 At least two concrete evidence points?
J6 Structural change, not reskin?
J7 Event, not state rename?
J8 Cross-domain transfer keeps the same relation?

## Duplicate rule

If two accepted candidates differ only in nouns/adjectives, keep the stronger one.
