# Five-Axis Interface

This file defines HOW Inspiration Wall uses Five-Axis, not WHAT the axes mean.

## Rule

Five-Axis must be loaded from the project's canonical Five-Axis definition cards.

Each axis must expose an operation-oriented interface:

- structural operation
- directionality
- boundary behavior
- aggregation/separation behavior
- path behavior
- stability/instability behavior
- positive examples
- counterexamples

## Required generation modes

For every axis:

### Direct
Keep the domain. Change the structural operation only.

### Transfer
Keep the operation. Change the domain.

### Inversion
Keep the underlying axis logic. Reverse the initial visual/narrative presentation.

## Forbidden shortcut

Never map an axis directly to:
- color
- element icon
- costume
- material
- profession
- genre
without structural evidence.
