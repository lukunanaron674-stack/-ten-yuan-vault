# Ten-Yuan Eventization Interface

This skill does not duplicate Ten-Yuan semantics.

Canonical Ten-Yuan cards are authoritative.

## Purpose

Convert a static structural variation into an event.

## Intermediate representation

Use as many of these fields as the canonical interpreter supports:

- actor
- object
- current_window
- changed_variable
- relation_shape
- direction
- path_set
- decision_right
- reentry_right
- condition
- stage
- primary
- secondary

## Event validity

A valid Ten-Yuan event must show:

1. Before-state
2. Trigger or pressure
3. Changed relation
4. Observable consequence
5. New state / endpoint / unresolved condition

## Anti-cheat

Reject outputs where Ten-Yuan is expressed only by:
- mood
- facial expression
- color
- character archetype
- costume
- decorative symbol

The relation must change.
