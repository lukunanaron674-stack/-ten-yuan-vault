# Benchmark Acceptance Thresholds

Run all cases in `benchmark.json`.

## Pass thresholds

- surface-reskin failure rate <= 30%
- accepted duplicate rate < 20%
- parent-traceability = 100%
- cross-domain structural preservation >= 80%
- concrete/drawable output >= 80%
- every accepted event passes J7

## Failure handling

Do not add more examples first.
Identify which rule caused the collapse:
- extraction
- Five-Axis operation
- Ten-Yuan eventization
- Judge
and revise that layer only.
