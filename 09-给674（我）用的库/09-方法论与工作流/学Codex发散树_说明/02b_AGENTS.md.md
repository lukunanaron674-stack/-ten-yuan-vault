# 📄 AGENTS.md 项目家规

> 项目级的"给 Codex 看的 README"，自动载入上下文。

## 是什么

`AGENTS.md` 是一种开放式说明文件，Codex 进到项目目录会自动读取。适合把"你希望 Codex 在这个仓库怎么干活"写死。

## 放什么

- 目录结构、重要路径
- 怎么运行项目
- 构建 / 测试 / lint 命令
- 工程约定、PR 要求
- 约束和"别做"清单
- **"完成 = 什么"以及怎么验证**

## 分层（越具体越优先）

- 全局：`~/.codex/AGENTS.md`（个人默认）
- 项目根：`<仓库>/AGENTS.md`（团队共享）
- 子目录：`<仓库>/xxx/AGENTS.md`（局部规则，优先级最高）

## 使用建议

- **短而准 > 长而泛**。先写基础，发现重复错误再加
- **同一个错犯两次** → 让它做次复盘，并更新 AGENTS.md
- 内容多了 → 主文件精简，引用外部 md（如 planning.md、review.md）

## 你项目里的例子

你工作区已有 AGENTS.md（"确保和我没有歧义再行动……"），这就是项目家规。可以继续往里面沉淀你的工作习惯。
