# 🥇 第一优先级｜治卡 + 每天用

> 这三个习惯直接解决你的"加载卡"，也是每天都会用到的。

## 包含

- [[01a_单线程单任务|🧵 单线程单任务]] —— 一个 chat 只干一件事
- [[01b_Prompt四要素|📝 Prompt 四要素]] —— Goal / Context / Constraints / Done when
- [[01c_config.toml|⚙️ 认识 config.toml]] —— 个人默认配置

## 为什么是"第一优先级"

**单线程单任务**治本：你卡是上下文太大，而上下文大是"一个 chat 装太多活"导致的。

**Prompt 四要素**让你每次下指令更省事：写齐了，Codex 少瞎猜、少乱跑、少返工，整体更快。

**认识 config.toml**让你能自己调速度和安全，不用每次都来问。

## 建议

- 新任务 → 新线程；线程变长 → `/compact` 或 `/fork`
- 指令尽量写全四要素
- 想改默认行为 → 改 `~/.codex/config.toml`（改动前先备份）
