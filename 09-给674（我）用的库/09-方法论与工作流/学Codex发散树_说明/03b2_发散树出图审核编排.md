# 🌳 发散树 → 出图 → 审核（主子代理编排）

> 承接 [[03b1_子代理实操|子代理怎么用]]，用你的真实流程举例：发散树里有**未锁定的图描述词** → 要**生成图** → 要**审核图**。

## 核心分工

- **主代理（你）= 导演**：盯全流程、**拍板**、对接你
- **子代理 = 执行**：锁定 / 出图 / 审核，各管一摊，上下文隔离、可并行

## 整体流程

```
主代理（你）
├─ ① 扫发散树 → 列出所有"未锁定"描述词的卡，排优先级
├─ 子代理A「锁定描述词」
│     └─ 逐张对照任务卡/角色设定，把描述词补全润色成"可出图定稿"
│     └─ 产出锁定描述词清单 → 回主代理
├─ ② 主代理：把 A 的锁定稿给你【抽查确认】  ← 关键拍板
├─ 子代理B「出图」：按锁定稿批量生成图（imagegen / ComfyUI）
├─ 子代理C「审核」：逐张质检 → 通过 / 打回+原因
│     └─ 标准：比例 / 动作 / 画面风格一致性 / 描述词忠实 / 清晰度 / 灰图彩点；不合格标小叉 ✕
└─ ③ 主代理：汇总
      ├─ 通过 → 锁卡、更新发散树（补 🖼 图链接）
      └─ 打回 → 退回 A/B 改 → 重新出图 → 再审
```

## 三个子代理各管一摊（都不占主线）

| 子代理 | 干什么 | 可并行 |
|---|---|---|
| **A 锁定描述词** | 未锁定 → 对照设定补全成定稿 | ✅ 每卡独立 |
| **B 出图** | 锁定稿 → 生成图 | ✅ 可批量 |
| **C 审核** | 出图 → 质检打分 | ✅ 可批量 |

## 审核代理（子代理C）查什么

按顺序逐张查，**不合格就标小叉 ✕ + 一句原因**：

1. **比例**：头身比、构图比例、透视是否合理（有没有被拉长/压扁/比例崩）
2. **动作**：姿势/动态是否符合描述词、是否自然（手、肢体有没有别扭）
3. **画面风格一致性**：是否和已验收图一致（角色长相、画风、描边、色调）
4. 其它：描述词忠实度、清晰度、灰图/彩点/多余人

全部汇总给主代理，**由你拍板**通过 / 打回。

## 你（主代理）在哪两步必须拍板

1. **锁定稿抽查**：子代理A 锁定的描述词，你扫一眼确认（这是"没锁定的图"的核心，别让子代理替你定）
2. **打回 vs 通过**：C 说打回的，你决定是"改描述词"还是"换出图方式"

## 触发指令（直接对 Codex 说）

> "扫我的发散树，列出所有未锁定的图描述词。派子代理A 把每张锁定成可出图的定稿，给我抽查确认；确认后派子代理B 出图，派子代理C 逐张审核（**比例、动作、画面风格一致性**、描述词忠实、清晰度、灰图彩点），不合格标小叉 ✕ + 原因，通过的锁卡更新发散树，打回的报原因。"

## 要点

- 出图可并行，但**锁定和审核的主意由你拿**——这是"主子"的分界
- 子代理只回"结果 + 原因"，别让它们替你下最终决定
- 审核标准提前写进指令，C 才不会瞎判
