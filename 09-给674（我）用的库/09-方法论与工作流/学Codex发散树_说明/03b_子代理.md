# 🤝 子代理 subagent

> 大任务拆给子代理，主线程保持轻快。

## 为什么

把探索、测试、杂活塞进主线程，上下文会膨胀、主任务会被拖慢。拆给子代理能并行、隔离上下文。

## 谁适合丢给子代理

- 🧩 代码库探索
- 🧪 测试 / 冒烟
- 🗂 信息收集 / 分诊
- 🔍 独立可并行的子问题

## 主代理该干嘛

- 🎯 盯住核心问题、编排调度
- 🤝 汇总子代理结果、继续主线

## 对应到你的工作流

就像你把"生图""跑 H3""剧本"分开成不同 skill 一样——**一个任务，主线程只做主线，边角活拆出去**，别让一个线程又当编辑又当渲染又当搬运。
