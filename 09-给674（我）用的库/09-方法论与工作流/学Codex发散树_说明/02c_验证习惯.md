# ✅ 让 Codex 改完自己验证

> 别只让它"改"，让它"改完证明改对了"。

## 为什么

Codex 改完不自己检查，容易留下 bug、回归、格式问题。你要在指令或 `AGENTS.md` 里告诉它"什么叫好"。

## 让它做这些

- ✅ 写完 **跑测试 / 构建**
- ✅ 检查 **lint / 格式 / 类型**
- ✅ **自查 diff** 有无 bug 或回归
- ✅ 确认最终行为符合要求

## 配套工具

- **diff 面板**：桌面 App 里直接看改动，点某行给反馈（会作为下一轮的上下文）
- **`/review`** 命令：
  - 对照 base 分支做 PR 式评审
  - 评审未提交的改动
  - 评审某个 commit
- **`code_review.md`**：在 AGENTS.md 里引用它，让评审行为一致

## 一句话

> 让它"生成代码"只是第一步；用对了，它还能**帮你测试、检查、评审**。
