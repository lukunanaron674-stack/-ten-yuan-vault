# 🤖 主子代理怎么用出来（实操 + 我方项目举例）

> 承接 [[03b_子代理|子代理]] 节点。这里讲**具体怎么触发、让它们干什么**，并用你的真实项目举例。

## 1. 先分清"主代理"和"子代理"

- **主代理（main agent）**：你现在这个对话里的 agent。负责**编排、决策、对接你**，守住核心目标。
- **子代理（subagent）**：主代理临时派出的**独立小 agent**。有**自己隔离的上下文**，干完把结果交回主代理，不污染主线。

官方一句话：*offload bounded work from the main thread* —— 把有边界的活卸给子代理。

## 2. 怎么"用出来"（触发方式）

不用特殊开关，直接**用指令让主代理派**，例如：

- "**用子代理去探索** `xx` 文件夹，找出所有 `yy`"
- "**派个子代理**跑一下测试确认 `zz` 能过"
- "**并行用两个子代理**，一个查素材重复，一个检查任务卡格式"
- 任务复杂时主代理也会自己拆，但显式指定更可控

关键收益：**子代理的上下文不占你主线程**，主线程保持轻快 → 不卡。

## 3. 具体该把什么任务丢给子代理

✅ 适合：
- **探索/调研**：读一堆文件，提炼结论
- **测试/验证**：跑测试、构建、确认结果
- **分诊**：定位 bug、找根因
- **独立可并行的子任务**：各卡互不影响时批量处理

❌ 不适合：
- 需要**连续决策、上下文连贯**的活（留主代理）
- 结果会影响主线大方向、需要你拍板的活（先回主代理）

## 4. 用我方项目举例（方志敏三幕）

### 例 A：跑一张卡（卡3-3）
```
主代理（你）：编排"第三幕3-3卡"整体流程、对接你
├─ 子代理①：读 3-3 描述词+分镜 → 提炼成 H3 提示词
├─ 子代理②：用 Animagine 出首帧 + 质检（灰图/彩点先拦下）
└─ 主代理汇总：把合格首帧交给 H3 图生视频 → 盯运行/时长/可播放
```

### 例 B：素材去重（发散树）
```
子代理：去 `方/07_素材图/第三幕/` 用 SHA256 比对，找有没有重复图
主代理：根据结果决定"补链接"还是"跳过"，并汇报给你
```

### 例 C：批量卡（第三幕 9 卡）
```
子代理①：逐卡生成首帧
子代理②：逐卡提炼 H3 提示词
主代理：只盯整体队列、显存、错卡重试
```

## 5. 原则

- **主代理盯核心和决策，子代理干边角/独立活**
- 一个子代理只干一件事，别贪多
- 需要连续上下文的活别拆给多个子代理
- 子代理结果回来，主代理负责"审查 + 交给下一步"，别直接丢给模型

## 6. 对应到你

你已经有天然的子代理场景：
- **H3 批量**：出首帧 / 提炼提示词 / 盯采样，可分给子代理，主线程只编排
- **发散树/任务卡**：格式检查、素材去重、链接补齐，都是独立活
- **Linear / 素材整理**：纯搬移、比对，交给子代理不占主线
