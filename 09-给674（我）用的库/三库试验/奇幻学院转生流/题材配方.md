# 奇幻学院转生流｜题材配方

## 1. 组合语法

```text
W-FAN 奇幻世界
+ D-ACA 学院/训练机构
+ M-REI 转生机制
+ E-GCS 成长/竞争/生存（可选剧情引擎）
= TOPIC-FAN-ACA-REI-001
```

本配方只决定题材模块怎样组合，不决定人物十元。任何十元结论必须来自独立的行为证据。

## 2. 模块职责

| 模块 | 类型 | 可复用范围 | 负责供给 | 不负责 |
|---|---|---|---|---|
| `W-FAN` | 世界基底 | 所有奇幻题材 | 魔法规律、种族、魔力资源、奇幻生物、魔法器物 | 学院制度、转生者行为 |
| `D-ACA` | 机构/生活域 | 现实或幻想学院题材 | 学生与教职、院系组织、课程、宿舍、考试、社团、校规 | 魔法规律、前世记忆 |
| `M-REI` | 剧情机制 | 所有转生题材 | 前世身份、新身体、记忆残留、身份错位、复苏节点 | 完整社会与职业体系 |
| `E-GCS` | 可选引擎 | 多题材复用 | 成长目标、排名竞争、生存压力、试炼结果 | 世界与制度本体 |

## 3. Bridge 专有对象

只有两个或更多模块相交后才成立的对象，进入 Bridge，不塞回任一基础模块。

| Bridge | 组合 | 典型对象 |
|---|---|---|
| `BR-WD` | `W-FAN × D-ACA` | 魔法课程、元素学派、魔药实验室、魔法制服部件 |
| `BR-DM` | `D-ACA × M-REI` | 转生新生、身份矛盾档案、转生身份审查 |
| `BR-WM` | `W-FAN × M-REI` | 记忆封印器、灵魂残影、前世旧物改造物 |
| `BR-WDM` | `W-FAN × D-ACA × M-REI` | 灵魂鉴定室、转生异常调查室、灵魂鉴定镜 |

Bridge 对象在表中明确标注“Bridge 专有”，不可作为单一模块的通用对象。

## 4. 1号名词对象库范围

本轮覆盖八类：人物、职业组织、地点、服装外观、道具资源、文件信息、生物、事件状态。每张对象卡必须具备：

```text
ID
标准名
is-a
可见特征
模块来源
故事动作钩子
```

“故事动作钩子”只是中性的可供行为，例如读取、穿戴、争夺、消耗、修复；它不是十元判定。

## 5. 通用行为槽

这些槽用于试拼可画内容，不属于十元行为库，也不预设动机。

| 槽ID | 中性动作 | 要改变的普通变量 |
|---|---|---|
| `ACT-OBSERVE` | 观察/读取 | 信息是否被主体获得 |
| `ACT-TEST` | 检测/试验 | 对象隐藏状态是否显露 |
| `ACT-RECORD` | 记录 | 经验是否变成可复查信息 |
| `ACT-ALLOCATE` | 分配 | 资源在对象间的分布 |
| `ACT-CONCEAL` | 隐藏 | 信息或对象的可见性 |
| `ACT-REVEAL` | 揭示 | 信息或身份的公开程度 |
| `ACT-EXCHANGE` | 交换 | 所有者、使用权或信息持有者 |
| `ACT-PROTECT` | 保护 | 对象的安全状态 |
| `ACT-REPAIR` | 修复 | 对象从损坏到可用 |
| `ACT-ESCAPE` | 脱离 | 主体与限制空间的关系 |
| `ACT-NEGOTIATE` | 协商 | 权限、条件或任务归属 |
| `ACT-COMPETE` | 竞争 | 排名、资格或稀缺名额 |
| `ACT-TRANSPORT` | 搬运/护送 | 对象所在位置 |
| `ACT-REORGANIZE` | 重排 | 顺序、计划或资源结构 |

## 6. 合流边界

```text
题材配方 → 提供可选名词范围
名词对象库 → 提供主体、外观、地点、目标物与事件
通用行为槽 → 仅用于验证“名词 + 动词”能否形成可画瞬间
十元行为库 → 后续依据具体角色行为独立建设
```

禁止从“奇幻”“学院”“转生”“考试”“制服”等题材词反推人物十元。
