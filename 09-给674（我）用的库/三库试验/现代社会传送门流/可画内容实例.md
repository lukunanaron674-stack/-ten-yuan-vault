# 现代社会传送门流｜可画内容实例

## 使用规则

- 本页只合流[[名词对象库]]中的对象 ID 与[[题材配方]]列出的通用行为槽 ID。
- 每条必须说明“谁做了什么、作用于什么、前后变量怎样改变”。
- `OBJ-EVT-003` 强制传送是遭遇，不是主动行为；若没有后续主体动作，必须使用 `ACT-NONE-000`，不得判人物十元。
- 十元只依据当前动作与变量变化进行候选判断，不能从“现代社会传送门流”题材名反推。
- 生克补本轮默认不登记；两点共现不等于关系启动。

## 实例 01｜按市政路线撤离

- 实例 ID：`DRAW-001`
- 主体：`OBJ-PER-001`
- 外观：`OBJ-APP-004`
- 地点：`OBJ-LOC-001`
- 处境：`OBJ-EVT-005` + `OBJ-EVT-001`
- 使用对象：`OBJ-DOC-001` + `OBJ-PROP-010`
- 行为槽：`ACT-GEN-001`
- 可画内容：夜班办公职员在停运的地铁换乘大厅对照紧急疏散路线图，沿市政标出的封闭区外路线带着电脑包离开。
- 前后变量：位置从“停运大厅内”变为“外部指定安全路线中”；路线方向由市政文件给定。
- 十元检查：`nx`行为候选。依据是方向权在外部；不是因为穿职员装，也不是因为题材有传送门。
