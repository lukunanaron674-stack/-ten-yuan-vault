# 2号库｜十元人物行动试验接口

> 本文件建立接口和首批候选行为，不替代漫画原页分析。正式入库必须补作品、章节、页码和角色阶段。

## 行为记录字段

| 字段 | 要求 |
|---|---|
| 行为ID | 全库唯一 |
| 角色@阶段 | 禁止把全作揉成一个人格 |
| 主十元 | 正式 / 候选 / 未知 |
| 触发处境 | 行动前发生了什么 |
| 主动动词 | 必须由主体执行 |
| 作用对象 | 连接1号名词ID |
| 前→后状态 | 明确可观察变化 |
| 改变变量 | 资源、权限、关系、方向、秩序、信息等 |
| 漫画依据 | 作品、章节、页码、画面/台词 |
| 生克补 | 正式机制 / 候选 / 未映射；写源端、目标端、第三因素 |

## 首批跨题材动作接口

### BP-XN-001｜主动组织流程与资源（xn候选）

- 触发：现有流程失序、信息零散或资源无法持续运行。
- 动词链：清点 → 排序 → 分配 → 记录 → 复核。
- 目标类型：人员、课程、时间表、物资、记录、任务。
- 必要结果：零散行动变为可持续、可追踪的结构。
- 排除：只是照既有指令执行，不能据此判xn。
- 题材复用：学院训练安排；传送门撤离编组。
- 正式状态：候选；必须由漫画原页验证人物是否稳定重复。

### BP-NX-001｜沿已有路线和安排继续（nx候选）

- 触发：已有规则、命令、路线或角色位置可供承接。
- 动词链：接受 → 跟随 → 执行 → 继续。
- 必要结果：主体没有主动占据新的方向与位置。
- 排除：若主体重建流程、重新分配资源，转查xn；若公开扩张决定权，转查zx。
- 题材复用：按学院规定完成考核；按疏散标识穿过门站。
- 正式状态：候选；必须由漫画原页验证。

### BP-ZX-001｜公开扩张决定范围（zx候选）

- 触发：既有权力或管理链阻挡主体目标。
- 动词链：公开挑战 → 夺取节点 → 重定规则/命令 → 扩大决定范围。
- 必要结果：原权力者、权限边界或集体方向发生可观察退让/转移。
- 排除：仅展示能力、赢一次比赛或被人关注，不足以判zx。
- 题材复用：夺取学院决斗规则解释权；夺取传送门站控制权。
- 正式状态：候选；必须由漫画原页验证。

### BP-X-001｜收拢并控制关键对象（x候选）

- 触发：关键资源、许可、秘密或对象可以被占有和排他控制。
- 动词链：识别 → 收拢 → 隔离 → 掌握使用边界。
- 必要结果：对象的使用、进入或转移由主体实际控制。
- 排除：只是临时拿在手上、保管公物或服从岗位职责，不足以判x。
- 题材复用：控制唯一灵魂档案；控制唯一跨界通行许可。
- 正式状态：候选；需与最新x信息卡和漫画证据复核。

## 暂不虚构的部分

其余点位与生克补行为不从题材演绎。它们必须从漫画的双通道场景卡中逐条积累，再进入本库。
