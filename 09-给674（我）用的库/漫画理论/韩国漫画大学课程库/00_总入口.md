# 韩国漫画大学课程库·总入口

> 目标：把韩国大学的漫画、Webtoon、动画课程拆成可检索、可练习、可继续扩建的知识系统，而不是堆一张长到让人失去生存欲望的课程表。

## 一、范围

本库收录：

1. 韩国大学公开发布的漫画、Webtoon、动画专业课程；
2. 课程背后的完整知识模块；
3. 故事写作、角色心理、世界观、分镜、场景演出、作画、数字生产、产业经营知识；
4. 能公开核实的教材、教师著作与公开课资料；
5. 根据课程目标重建的练习、作业和四年自学路线；
6. 各学校资料的来源、年份与核验状态。

## 四、韩国漫画教育的统一底层链

```text
现实与题材调查
→ 建立人物、职业、场景、道具等对象
→ 分析欲望、恐惧、关系和行为动机
→ 设计冲突、事件、类型承诺和情绪变化
→ 组织短篇、长篇、单元与连载结构
→ 转换成漫画分镜、页面或竖屏滚动演出
→ 完成线稿、背景、色彩、字体和数字生产
→ 接受教师、编辑、企业与读者反馈
→ 修改、连载、出版、授权或改编
```

## 五、对应用户的对象库与行为库

| 本库模块 | 对象库对应 | 行为库对应 |
|---|---|---|
| 资料调查 | 职业、时代、地点、制度、器物 | 现实中的工作流程与生活动作 |
| 角色心理 | 身份、性格、欲望、关系 | 选择、回避、攻击、保护、依附、欺骗 |
| 世界观 | 社会结构、规则、资源、阵营 | 规则允许和禁止的行动 |
| 类型故事 | 爱情、动作、悬疑、恐怖、SF等对象 | 各类型固定行为与事件模式 |
| 场景演出 | 空间、人物位置、道具 | 进入、离开、对峙、接近、隐藏、发现 |
| 分镜 | 画格、镜头、页面、滚动空间 | 看、说、停顿、反应、转场、揭示 |
| 产业生产 | 平台、编辑、合同、IP | 投稿、修改、交稿、连载、授权、协作 |

## 六、资料可信度标签

- `A｜官方课程表`：大学官网或官方课程手册直接公开。
- `B｜官方课程说明`：大学官网的专业介绍、能力地图、教师负责课程。
- `C｜公开课资料`：KOCW、K-MOOC等官方教育平台。
- `D｜教师著作`：由学校官方教师介绍确认作者与课程关系。
- `R｜补充参考`：内容适配课程，但不能冒充该校指定教材。
- `T｜待核实`：课程存在，但教材、周计划或作业没有公开。

## 七、版权边界

本库只保存：

- 课程名称与公开课程说明；
- 自行整理的知识摘要；
- 书目信息、用途和阅读路线；
- 自行设计的练习模板；
- 合法公开资源链接。

不保存受版权保护书籍的全文、盗版扫描件或未公开的校内讲义。书可以买，知识可以拆，版权不能靠装死消失。
