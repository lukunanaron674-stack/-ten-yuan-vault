# 韩国漫画大学课程库·总入口

> 目标：把韩国大学的漫画、Webtoon、动画课程拆成可检索、可验证、可练习、可继续扩建的知识系统。

## 一、先看这四份

1. [[01_课程总纲/韩国漫画大学课程总纲]]：多校归纳出的课程骨架；
2. [[01_课程总纲/十元化_内容人物行为索引]]：把课程转换成内容库、人物行为库和动态链；
3. [[06_矩阵/课程知识作业矩阵]]：每门课应学什么、做什么；
4. [[90_采集与核验/韩国院校覆盖清单]]：哪些已核、哪些没核，防止资料库自我膨胀。

## 二、范围与边界

本库收录：

1. 韩国大学公开发布的漫画、Webtoon、动画专业课程；
2. 课程背后的重建知识模块；
3. 故事、心理、世界观、类型、分镜、作画、动画、声音、平台和产业知识；
4. 能公开核实的教材、教师著作与公开课线索；
5. 根据课程目标重建的练习、作业和自学路线；
6. 各学校资料的来源、年份、链接健康和覆盖等级；
7. 面向创作的对象库、行为库、回应库、代价库与关系状态机。

必须区分：

- `学校档案`回答学校公开教什么；
- `知识模块`是本库根据多校课程重建的学习内容；
- `补充书目`不等于学校指定教材；
- `十元接口`属于用户个人理论，不属于韩国学校官方课程；
- `深知识采矿`必须通过对象、行为、回应、代价、关系变化和训练门槛，不能只列术语。

## 八、韩国漫画教育的统一底层链

```text
现实与题材调查
→ 建立人物、职业、场景、道具等对象
→ 标注对象状态、控制权、可操作性和关系绑定
→ 分析欲望、恐惧、关系和稳定行为策略
→ 用具体触发器启动人物行为
→ 让对方作出独立回应
→ 结算即时、延迟和转移代价
→ 更新对象、信息和关系状态
→ 设计冲突、事件、类型承诺和情绪变化
→ 组织短篇、长篇、单元与连载结构
→ 转换成漫画分镜、页面或竖屏滚动演出
→ 完成人体、背景、色彩、字体、声音和数字生产
→ 接受教师、编辑、企业与读者反馈
→ 修改、连载、出版、授权、改编或本地化
```

## 九、对象库与行为库深度标准

对象库必须至少包含：

- 类别、状态、所有权、控制权；
- 稀缺度、可见性、可替代性；
- 允许行为、禁止行为、使用代价；
- 与人物、制度、空间和关系的绑定；
- 至少两次功能变化。

人物行为库必须至少包含：

- 行动者、目标对象、目的和触发器；
- 表层动作与真实功能；
- 对方预期回应与实际回应；
- 行为升级、修正或撤回；
- 即时、延迟和转移代价；
- 信任、权力、距离、依赖、债务、信息差与关系定义权变化。

完整标准见[[01_课程总纲/十元化_内容人物行为索引#9. 深度门槛]]。

## 十、证据等级

统一等级：

- `A`：官方课程表；
- `B`：官方课程说明；
- `C`：官方公开课；
- `D`：教师著作与研究；
- `R`：补充参考；
- `T`：待核实。

完整规则见[[91_规范/证据等级与文件规范]]。

## 十一、版权边界

本库保存：

- 课程名称与公开说明；
- 自行整理的知识摘要；
- 书目信息、用途和证据；
- 自行设计的练习；
- 合法公开资源链接。

本库不保存受版权保护书籍全文、盗版扫描件或未公开校内讲义。知识要整理，别顺便把版权埋了。
