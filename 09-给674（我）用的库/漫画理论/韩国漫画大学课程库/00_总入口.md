## 三、四层必须分开

| 层 | 负责什么 | 不负责什么 |
|---|---|---|
| 专业课程 | 事实、方法、训练、表现与生产证据 | 不直接判十元 |
| 十元 | 人物、状态、行为、关系、对象、场景与时间结构的具体语义和生克补 | 不替代课程知识 |
| 动态链 | 端点怎样启动、转位、退隐、结算并进入下一阶段 | 不负责高级主题归类 |
| 五大主题 | 时间、本体、空间、因果、命运的显影、主次与主题级生克 | 不反向证明人物十元 |

禁止写法：

```text
动作课＝zx
背景课＝n
分镜课＝z
出现xz+nz＝命运主主题
两个十元共现＝主题自动生成
```

## 四、ABC三模式

### A｜分析模式

```text
已有作品／场景
→ 专业课程拆解对象、行为、表现与生产
→ 十元正本复核端点、生克补、体量与顺序
→ 动态链完成后判断五大主题显影
→ 修改与校准
```

### B｜设计模式

```text
对象与状态
→ 关系条件
→ 对不同人物的意义
→ 十元候选端点
→ 行为、回应与代价验证
→ 进入C模式运行
```

### C｜动态运行模式（默认）

```text
对象状态
→ 关系位置
→ 当前十元端点／已锁定关系
→ 行为
→ 对方独立回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与新关系
→ 端点重新分配
→ 下一轮
```

五大主题不要求每轮强判。场景通常只能提供0—1级显影证据，序列可支持2级，3级主主题必须由中心问题、关键转折、高潮与结局共同支持。

## 八、深度融合最低标准

每个课程知识点进入创作时，至少记录：

1. 分析对象层：人物／状态／行为／关系／对象／场景／时间结构；
2. 对象状态、控制权、可见性、稀缺度和权限；
3. 欲望、触发、行为、独立回应、收益和代价；
4. 关系七变量的前后变化；
5. 十元源端点、目标端点、机制、被改变变量；
6. 体量、顺序、成立阶段、显影条件和第三因素；
7. 拿掉测试、反向测试、正例、误判与反例；
8. 五大主题0—3级显影及高层证据；
9. 主题生克的源主题、目标主题、方向和决定性改变；
10. 课程来源和证据等级。

## 九、五大主题接口

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

这里的`+`是主题系统预设构成，不是案例中两个十元相遇，也不表示十元共现会自动生成主题。

显影等级：

```text
0级：背景存在
1级：局部主题
2级：次主题
3级：主主题
```

主题层生克必须另外写明端点和目标主题被改变的能力、边界、路径或答案。不得把主题关系还原成唯一十元关系。
