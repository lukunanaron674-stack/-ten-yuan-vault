## 三、五层必须分开

| 层 | 负责什么 | 不负责什么 |
|---|---|---|
| 专业课程章 | 事实、方法、训练、表现与生产证据 | 不直接判十元 |
| 同名十元规整章 | A/B/C入口、候选端点、关系证据与误判红线 | 不冒充十元正本 |
| 十元正本 | 人物、状态、行为、关系、对象、场景与时间结构的具体语义和生克补 | 不替代课程知识 |
| 动态链 | 端点怎样启动、转位、退隐、结算并进入下一阶段 | 不负责高级主题归类 |
| 五大主题 | 时间、本体、空间、因果、命运的显影、主次与主题级生克 | 不反向证明人物十元 |

禁止写法：

```text
动作课＝zx
背景课＝n
分镜课＝z
某章列了十元词＝该章完成深度融合
出现xz+nz＝命运主主题
两个十元共现＝主题自动生成
```

## 四、ABC三模式

### A｜分析模式

```text
已有作品／场景
→ 专业课程章拆解对象、行为、表现与生产
→ 同名规整章选择证据入口与误判红线
→ 十元正本复核端点、生克补、体量与顺序
→ 动态链完成后判断五大主题显影
→ 修改与校准
```

### B｜设计模式

```text
选择专业知识章
→ 对象与状态
→ 关系条件
→ 对不同人物的意义
→ 同名规整章提出十元候选端点
→ 行为、回应与代价验证
→ 进入C模式运行
```

### C｜动态运行模式（默认）

```text
本轮专业章＋同名规整章
→ 对象状态
→ 关系位置
→ 当前十元端点／已锁定关系
→ 行为
→ 对方独立回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与新关系
→ 端点重新分配
→ 下一轮重新选章
```

五大主题不要求每轮强判。场景通常只能提供0—1级显影证据，序列可支持2级，3级主主题必须由中心问题、关键转折、高潮与结局共同支持。

## 六、逐章融合完成标准

一章必须同时具备：

1. 专业正文；
2. 同名十元规整章；
3. A／B／C入口；
4. 本章可提供的对象、行为、表现或生产证据；
5. 候选端点，但不把课程名、对象名、动词或气氛直接映射成十元；
6. 可调用的已锁定关系与正本状态；
7. 源端点、目标端点、启动机制和被改变变量；
8. 体量、顺序、成立阶段、显影条件和第三因素；
9. 拿掉测试、反向测试、正例、误判和反例；
10. Canvas中的专业章／规整章双卡连接。

17章已经全部建立配套规整文件。后续案例证据继续填充，但“没有逐章入口”的结构缺口已经关闭。

## 九、五大主题接口

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

这里的`+`是主题系统预设构成，不是案例中两个十元相遇，也不表示十元共现会自动生成主题。

显影等级：

```text
0级：背景存在
1级：局部主题
2级：次主题
3级：主主题
```

主题层生克必须另外写明端点和目标主题被改变的能力、边界、路径或答案。不得把主题关系还原成唯一十元关系。
