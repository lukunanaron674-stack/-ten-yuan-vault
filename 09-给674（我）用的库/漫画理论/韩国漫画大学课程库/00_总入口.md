## 三、课程与十元的边界

本库必须区分：

- `学校档案`：回答学校公开教什么；
- `知识模块`：根据多校课程重建的专业知识；
- `补充书目`：不自动等于学校指定教材；
- `十元正本`：用户个人理论，不属于韩国大学官方课程；
- `ABC协议`：课程知识进入十元分析、设计和动态运行的接口。

课程名不直接对应十元。“动作课＝zx”“背景课＝n”“分镜课＝z”均为禁止写法。课程提供证据，十元判断对象进入关系后的作用。

## 四、ABC三模式

### A｜分析模式

```text
已有作品／已有场景
→ 专业课程拆解
→ 十元正本复核
→ 修改与校准
```

用于课程学习、韩漫拆解和作品复盘。

### B｜设计模式

```text
对象与状态
→ 关系条件
→ 对象对人物的意义
→ 十元候选端点
→ 行为、回应与代价验证
```

对象不天然等于十元，候选必须被关系和结果证明。

### C｜动态运行模式（默认）

```text
对象状态
→ 关系位置
→ 当前十元端点／已锁定关系
→ 行为
→ 对方回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与新关系
→ 下一轮
```

## 八、知识深度标准

对象、行为或课程知识进入创作前，至少说明：

- 对象状态、控制权、可见性、稀缺度和权限；
- 人物欲望、恐惧、触发器、实际行为和对方回应；
- 即时、延迟和转移代价；
- 关系七变量变化；
- 十元源端点、目标端点、机制和被改变变量；
- 体量、顺序、成立阶段、第三因素；
- 拿掉测试、反向测试、正例、误判和反例；
- 课程来源和证据等级。
