# 青江文化产业大学·Webtoon漫画内容课程

## 1. 培养模型

青江的路线最接近“独立漫画作者＋产业项目负责人”。课程不是把编剧、分镜、作画分给不同人，而是训练学生完成：

```text
调查 → 企划 → 人物 → 世界 → 故事 → 分镜 → 作画 → 项目 → 出版／连载
```

公开课程表以三年制为主，并配置毕业评价、Capstone、作品集、就业创业和产业课程。

## 5. 本库对故事教育的解释

> 本节是根据课程名称和公开说明重建的知识目标，不是学校逐周官方讲义。

### 角色心理学

- 行为由需求、恐惧和信念驱动；
- 性格标签转化成可观察选择；
- 人物在压力、诱惑、羞耻和损失下变化；
- 人物关系改变行动优先级。

### 历史人物角色

- 区分史料、推断和虚构；
- 提取时代位置、社会身份与关键事件；
- 保留历史约束并重建戏剧目标；
- 写人物梗概与事件选择说明。

### 资料调查与采访

- 设计问题；
- 记录职业术语、空间、动作和冲突；
- 建立事实卡与对象表；
- 避免把单个采访对象当成整个职业。

### 漫画故事叙述Ⅰ、Ⅱ

- 短篇和中长篇结构；
- 场景、序列、章和话的层级；
- 人物目标、冲突、转折与后果；
- 情节线、关系线和主题线；
- 从梗概到漫画分镜。

### 序列设计

- 将长篇拆成连续事件群；
- 每个序列具备局部目标、升级和结果；
- 序列通过信息、情绪和因果接续；
- 控制主线推进与角色日常比例。

### 类型故事创作

- 类型承诺；
- 类型对象库与行为库；
- 读者期待与变奏；
- 爱情的关系变化、动作的目标阻力、悬疑的信息控制、恐怖的安全崩坏、SF的规则推演。

## 6. 推荐作业重建

1. 采访真实职业者，制作20张对象卡与30条行为记录；
2. 将历史人物重写为8页短篇，附史实与虚构对照；
3. 为同一人物写三种压力场景；
4. 制作16页无旁白短篇；
5. 完成一话60至80格Webtoon，至少三轮分镜修改；
6. 写12话连载大纲；
7. 将短篇小说改编为漫画并写删改理由；
8. 制作商业企划书、样话、角色表和排期。
