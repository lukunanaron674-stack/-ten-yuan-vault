# ABC三模式与C动态运行协议

> 专业课程负责提供可核验的现实知识、表现方法和训练证据；十元负责具体对象进入关系后怎样产生作用；动态链负责阶段变化；五大主题负责高级归类与主题级生克。四层不能揉成同一套关键词。

## 1. 最终结构

```text
A｜分析已有作品
B｜设计对象与关系条件
C｜持续运行对象、关系、行为和十元
D｜动态链完成后判断五大主题显影
```

默认主模式为C。A用于学习与复盘，B用于起案，C用于场景、单话、序列和连载推进；主题层不是第四种创作模式，而是A／C产出达到足够范围后进行的高级判断。

## 2. A｜分析模式

```text
已有作品／场景
→ 专业课程拆出对象、制度、行为、回应、代价、分镜与生产条件
→ 十元正本检查端点、生克补、体量、顺序
→ 重建动态链阶段
→ 判断五大主题0—3级显影与主题关系
→ 找出误判、缺失与可调整处
```

A模式允许剧情先发生再分析，但不得把分析结果倒写成作品原本的真实机制。

## 3. B｜设计模式

```text
选择对象
→ 设定对象状态、控制权、可见性、稀缺度和关系绑定
→ 判断对象对不同人物意味着什么
→ 提出十元候选端点与候选关系
→ 设计行为、回应和代价验证
→ 进入C模式
```

B模式不是：

```text
门＝x
枪＝zx
家＝n
```

而是：

```text
对象＋当前关系位置＋实际作用
→ 十元候选
→ 行为与结果验证
```

## 4. C｜动态运行模式

```text
对象状态
→ 关系位置
→ 当前十元端点／已锁定关系
→ 行为
→ 对方独立回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与新关系
→ 十元端点重新分配
→ 下一轮
```

每轮完成后重新检查对象状态、关系位置和端点是否改变。十元不是剧情写完后的标签。

## 5. 专业课程怎样进入ABC

专业课程提供三类东西：

1. **事实材料**：职业、制度、空间、身体、技术、平台、合同和生产流程；
2. **表现方法**：故事、分镜、表演、色彩、字体、声音、滚动节奏与编辑；
3. **验证机制**：作业、教师讲评、编辑反馈、读者数据、来源等级与案例反证。

课程名不直接对应十元。课程帮助看见证据，不能替十元下结论。

主题构成区：

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

注意：

- 构成式中的`+`是系统预设，不是案例内一次十元关系；
- 十元共现不自动生成主题；
- 主题关系不能还原成唯一十元关系；
- 单场通常只能支持0—1级显影；
- 2级需要序列证据；
- 3级需要中心问题、关键转折、高潮与结局共同支持。

主题记录：

```yaml
目标主题:

```

## 9. 防遗忘示例：zx克n

```text
zx主体公开显权，直接决定成员资格、接收边界或结构运行条件
→ n原有的接收、保护、照顾、互信与反复返回能力被迫停止
→ n承载能力下降、断裂或失效
```

普通攻击、一次命令、声音更大或场面激烈，都不能自动证明zx克n。

## 10. 十元关系证据标准

每条关系必须写清：

- 源端点；
- 目标端点；
- 启动机制；
- 被改变变量；
- 成立阶段；
- 体量与顺序；
- 显影条件；
- 第三因素；
- 拿掉测试；
- 反向测试。

共现、先后、视觉相似、课程关键词和作者主观意图都不等于关系已经启动。

## 12. 当前正式口径

> A理解作品，B设计条件，C推动变化，五大主题在动态链形成后负责高级归类。

> 专业课程提供真实材料与表现方法；十元负责具体化；动态链负责过程；五大主题负责主题重心与主题级生克。
