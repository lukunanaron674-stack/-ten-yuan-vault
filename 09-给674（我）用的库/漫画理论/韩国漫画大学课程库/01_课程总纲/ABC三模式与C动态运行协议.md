# ABC三模式与C动态运行协议

> 专业课程负责提供可核验的现实知识、表现方法和训练证据；十元负责判断对象进入关系后怎样产生作用。二者不是混成一锅，而是通过不同工作模式协作。

## 1. 最终结论

A、B、C都成立，但适用阶段不同：

```text
A｜分析已有作品
B｜设计对象与关系
C｜让对象、关系、行为与十元持续循环运行
```

默认主模式为C。A用于学习和复盘，B用于创作起案，C用于场景、单话、序列和连载推进。

## 2. A｜分析模式

适用：韩国大学课程学习、韩漫拆解、作品复盘、理论校准。

```text
已有作品／已有场景
→ 用专业课程拆出对象、制度、行为、回应、代价、分镜与生产条件
→ 用十元正本检查端点、生克补、体量、顺序和五维结果
→ 找出误判、缺失与可调整处
```

定位：十元是后置分析器。

A模式允许剧情先跑完再分析，但不得把分析结果倒写成作品原本的真实机制。

## 3. B｜设计模式

适用：人物设计、场景设计、剧情起案、对象库和行为库调用。

```text
选择对象
→ 设定对象状态、控制权、可见性、稀缺度和关系绑定
→ 判断对象对不同人物意味着什么
→ 提出十元候选端点与候选关系
→ 设计行为、回应和代价进行验证
```

定位：十元参与生成假设。

B模式不是：

```text
门＝x
枪＝zx
家＝n
```

而是：

```text
对象＋当前关系位置＋实际作用
→ 才能提出十元候选
```

候选若不能被行为、回应和被改变变量证明，应撤回。

## 4. C｜动态运行模式

适用：实际写场景、连续推进、动态链、长篇和连载。

```text
对象状态
→ 关系位置
→ 当前十元端点／已锁定关系
→ 行为
→ 对方独立回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与新关系
→ 十元端点重新分配
→ 下一轮
```

定位：十元是关系持续变化时的动态运行规则。

C模式不是等剧情结束再贴标签。每次行为与回应完成后，都必须重新检查对象状态、关系位置和端点是否改变。

## 5. 专业课程怎样进入ABC

专业课程只提供三类东西：

1. **事实材料**：职业、制度、空间、身体、技术、平台、合同和生产流程；
2. **表现方法**：故事、分镜、表演、色彩、字体、声音、滚动节奏和编辑方法；
3. **验证机制**：作业、教师讲评、编辑反馈、读者数据、来源等级和案例反证。

课程名不直接对应十元。例如“动作课”不等于zx，“分镜课”不等于z，“背景课”不等于n。课程只能帮助看见证据，不能替十元下结论。

## 8. 防遗忘示例：zx克n

```text
zx主体公开显权，直接决定成员资格、接收边界或结构运行条件
→ n原有的接收、保护、照顾、互信与反复返回能力被迫停止
→ n的承载能力下降、断裂或失效
```

所以zx克n。普通攻击、一次命令、声音更大或场面更激烈，都不能自动证明zx克n。

## 9. 十元关系证据标准

每条关系必须写清：

- 源端点；
- 目标端点；
- 启动机制；
- 被改变变量；
- 成立阶段；
- 体量与顺序；
- 显影条件；
- 第三因素；
- 拿掉测试；
- 反向测试。

共现、先后、视觉相似、课程关键词和作者主观意图都不等于关系已经启动。

## 11. 当前正式口径

> A理解作品，B设计条件，C推动变化。

> 专业课程提供真实材料和表现方法；十元不替代课程，也不被课程关键词定义。C模式下，十元持续参与对象、关系、行为、回应和下一轮条件的演化。
