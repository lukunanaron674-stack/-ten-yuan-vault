# R6全量十元知识化规范

> R6不再把十元作为章节末尾的接口、旁注或标签。专业课程中的每个知识点都必须被重新理解为对象、状态、关系、行为、动态链与五维结果。

## 1. 什么才叫“完全十元知识化”

每个知识点必须同时完成：

```text
原专业含义
→ 作用对象
→ 对象当前状态
→ 主十元
→ 条件十元
→ 结果十元
→ 已锁定关系／待确认关系
→ 体量与顺序
→ C动态链位置
→ 五维归纳
→ 误判与反证
→ 创作训练
```

只写“可对应x、n、zx”不算完成；只在章节末尾列十元词也不算完成。

## 2. 三类十元位置

### 主十元

本知识点当前直接改变的核心变量。例如“掌握资源和否决权”优先检查`x`，而不是因为动作强硬就判`zx`。

### 条件十元

使主十元能够显影的前置结构。例如长期流程、规则、记录和持续维护可作为`xn`条件，但不能因出现流程就自动判`xn`关系启动。

### 结果十元

行为结算后新出现或增强的端点。结果必须通过对象状态、关系变量或行动权限的变化证明。

## 3. 十元关系调用门槛

任何生、克、补必须写清：

```yaml
源端点:
目标端点:
关系:
正本状态: 已锁定 / 待确认
启动机制:
被改变变量:
成立阶段:
体量:
顺序:
显影条件:
第三因素:
拿掉测试:
反向测试:
```

共现、先后、动词、色调、课程名称、作者意图和视觉相似均不等于关系成立。

## 4. 当前防遗忘关系

课程库只能直接调用正本已锁定关系，包括：

- `xn 克 zx`；
- `zx 补 nx / nx 补 zx`；
- `zx 克 n`；
- `xn 生 xz`；
- `x并z 生 z`；
- `x 生 x并z`；
- `x 克 z`；
- `n 克 xz`；
- `zn 补 x / x 补 zn`；
- `n 补 x并z / x并z 补 n`；
- `xn 补 z / z 补 xn`；
- `xz 补 nz / nz 补 xz`；
- `n 生 xn`；
- `x并z 克 nz`；
- `nz 克 x`；
- `x 克 nz`；
- `zn 克 xn`。

特别固定：`zx 克 n`，`zx 被 xn 克`。攻击、追逐、命令和公开动作不自动等于`zx`关系成立。

## 5. C动态运行

知识点进入创作时按以下循环运行：

```text
对象状态
→ 关系位置
→ 当前主十元与条件十元
→ 行为／表现／操作
→ 对方或系统回应
→ 收益与代价
→ 被改变变量
→ 结果十元
→ 新对象状态与新关系
→ 下一轮
```

专业知识不再停留在“应该怎么画、怎么写”，而要说明它怎样改变动态链。

## 6. 五维归纳

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

五维是十元动态链完成后的高层归纳，不是起手标签。单个知识点通常只提供显影证据，不能独自证明整部作品的主主题。

## 7. R6章节结构

每章必须包含：

1. 本章十元总判断；
2. 原知识点全量十元归整表；
3. 每个原章节的十元化理解；
4. 已锁定关系与待确认关系区分；
5. C模式动态链；
6. 五维结果；
7. 误判红线；
8. 全量十元化模板；
9. 十元化课程作业。
