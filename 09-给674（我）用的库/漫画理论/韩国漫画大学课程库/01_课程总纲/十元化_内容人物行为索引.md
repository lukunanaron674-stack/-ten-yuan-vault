# 十元化·内容向与人物行为向索引

> 本文件不是韩国大学官方课程，而是把专业课程转换成对象、行为、回应、代价、十元动态与五大主题接口。十元定义、生克补和主题生克不在这里自行发明，必须调用正本。

## 1. 当前总结构

```text
专业课程知识
→ 对象与状态
→ 关系位置
→ 行为、回应与代价
→ ABC模式
→ 十元正本端点与关系
→ 动态链
→ 五大主题显影
→ 场景、单话、序列与案例反证
```

当前执行协议：[[ABC三模式与C动态运行协议]]。

## 2. 两条专业知识主轴

### 内容生成轴

```text
对象 → 关系 → 事件 → 场景 → 类型 → 单话／序列／连载
```

回答作品中有哪些人物、职业、制度、场所、资源、信息和道具；对象处于什么状态；谁拥有、控制、看见或无法获得；对象怎样改变事件、场景、类型承诺和连载条件。

### 人物行为轴

```text
欲望／恐惧
→ 触发器
→ 行动策略
→ 对方回应
→ 升级／修正／撤回
→ 选择与代价
→ 关系状态变化
```

回答人物为什么在此刻行动、实际做了什么、对方怎样独立回应、谁承担何种代价，以及关系七变量怎样变化。

## 5. 人物行为七层

| 层级 | 要问的问题 | 可观察内容 |
|---|---|---|
| 欲望与缺失 | 想得到什么，怕失去什么 | 寻找、保存、争夺、回避 |
| 触发器 | 什么变化使旧状态不能继续 | 威胁、秘密、时限、越界、评价 |
| 行动策略 | 人物怎样解决问题 | 接近、控制、保护、攻击、交换、欺骗 |
| 对方回应 | 对方怎样独立反应 | 接受、协商、拒绝、回避、反制、撤离 |
| 表演 | 行为怎样被读者看见 | 姿势、视线、停顿、台词、声音、镜头 |
| 选择与代价 | 哪两项不能同时保住 | 放弃、承担、牺牲、越线、转移代价 |
| 关系变化 | 行为后什么真实改变 | 信任、权力、距离、依赖、债务、信息、定义权 |

## 6. ABC三模式

### A｜分析已有作品

课程拆解事实与表现，十元复核端点与关系，动态链复原阶段，五大主题判断高级重心。

### B｜设计对象与条件

对象、状态与关系条件提出十元候选，再用行为、回应和代价验证。禁止“对象＝十元”。

### C｜动态运行

```text
对象状态
→ 关系位置
→ 十元端点／已锁定关系
→ 行为
→ 独立回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与关系
→ 下一轮
```

## 7. 十元接口的正确含义

课程库中的对象词、行为词和视觉词只能帮助检索证据，不能充当十元定义。

错误：

```text
攻击＝zx
等待＝xn
保护＝zn
房屋＝n
门＝x
```

正确：

```text
对象状态＋关系位置＋行为目的＋对方回应＋被改变变量
→ 提出端点与关系
→ 用正本验证
```

同一个“保护”可能保存主体、维持承载、公开显权、掌握边界、吸收代价或剥夺选择。必须看它实际改变了什么。

## 9. 五大主题分层接口

调用：[[../../../../../07-Codex大脑库/五大主题与十元分层接口协议_v0.4_2026-07-16]]。

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

这些公式属于主题构成区。`+`不表示案例内现实对象相遇，不表示一次十元关系，也不表示两个十元共现就自动生成主题。

显影等级：

```text
0级：背景存在
1级：局部主题
2级：次主题
3级：主主题
```

3级必须由中心问题、关键转折、高潮与结局共同支持。两个主题共现不等于主题生克启动，必须写明源主题、目标主题、方向，以及目标主题的能力、边界、路径或答案怎样被改变。

## 11. 深度门槛

任何知识模块至少包括：

1. 概念与边界；
2. 分类树；
3. 状态与变化；
4. 可观察行为；
5. 对方回应；
6. 代价；
7. 关系状态；
8. 正例、反例和误判；
9. 模板；
10. 训练与评分；
11. 跨模块连接；
12. 案例或证据待办；
13. 十元源端点与目标端点；
14. 启动机制与被改变变量；
15. 拿掉测试、反向测试和第三因素排除；
16. 五大主题显影范围、等级与高层证据；
17. 主题生克端点与决定性改变。
