# 十元化·内容向与人物行为向索引

> 本文件不是韩国大学官方课程，而是把课程库转换成用户可用于创作的“内容库＋人物行为库”。十元定义本身不在这里重写，本文件只负责建立接口。

## 1. 两条主轴

### 内容生成轴

```text
对象
→ 关系
→ 事件
→ 场景
→ 类型
→ 单话／序列／连载
```

内容向回答：

- 作品里有哪些人、物、制度、场所和规则；
- 对象处于什么状态，谁拥有、控制或无法获得；
- 对象允许、禁止和诱发哪些行为；
- 对象之间形成什么关系；
- 什么事件值得发生；
- 事件应该落在哪种场景；
- 场景属于什么类型承诺；
- 怎样扩展成一话、一个序列或一部长篇。

### 人物行为轴

```text
欲望／恐惧
→ 触发器
→ 行动策略
→ 对方回应
→ 行为升级或修正
→ 选择
→ 代价
→ 关系与身份变化
```

人物行为向回答：

- 人物想得到什么；
- 什么具体瞬间会逼他行动；
- 他习惯用什么方式处理问题；
- 行为如何被看见，而不是只停留在心理标签；
- 对方怎样依据自己的目标作出回应；
- 哪两件事不能同时保住；
- 谁立即承担代价，谁延迟承担；
- 行为最后改变了什么对象和关系状态。

## 5. 总动态链

```text
对象进入场景
→ 对象产生价值或威胁
→ 人物形成当前欲望
→ 具体触发器出现
→ 人物采用行为策略
→ 对方作出有效回应
→ 行为升级、修正或撤回
→ 收益和代价结算
→ 对象、信息与关系状态改变
→ 形成新事件
→ 下一场获得必要性
```

## 7. 十元接口

> 下表只说明课程内容怎样进入十元分析，不替代十元核心定义。十元必须在对象、行为、回应和代价成立后再判断。

| 十元 | 内容向接口 | 人物行为向接口 |
|---|---|---|
| xn | 过程、训练、连载推进、长期积累 | 持续、反复尝试、推进、养成 |
| z | 节点、限制、规则、转折、截断 | 禁止、决定、停止、切断 |
| zn | 主体、成长、角色核心、生成 | 表达、确认、保护、生成 |
| x | 边界、身份、结构、形式稳定 | 定义、拒绝、维持、排除 |
| x并z | 世界系统、规则空间、组织结构 | 配置、分类、管理、约束 |
| n | 关系、承载、位置与连接 | 靠近、共享、协调、依赖 |
| zx | 外部冲突、显性行动与结果 | 追逐、攻击、控制、执行 |
| nx | 代价、补偿、隐性回收 | 让步、吸收、承担、补偿 |
| xz | 临界、不可逆、命运压力 | 逼迫、跨线、剥夺、推向极限 |
| nz | 归属、停靠、余波、回归 | 等待、陪伴、保存、修复、返回 |

## 9. 深度门槛

任何模块不能因“写了定义和十个词”就标记深入完成。至少必须包括：

1. 概念与边界；
2. 分类树；
3. 状态与变化；
4. 可观察行为；
5. 对方回应；
6. 代价；
7. 关系状态；
8. 正例、反例和误判；
9. 模板；
10. 训练与评分；
11. 跨模块连接；
12. 案例或证据待办。

评分标准见[[04_知识模块/内容行为动态链与训练#12. 评分表]]。

## 10. 使用顺序

1. 从对象库选择人物、场所、制度、资源、信息或道具；
2. 明确对象状态、控制权和可操作性；
3. 为人物建立欲望、恐惧和稳定策略；
4. 设计一个具体触发器；
5. 写人物实际做什么；
6. 写对方依据自身目标怎样回应；
7. 判断行为怎样升级、修正或撤回；
8. 结算即时、延迟和转移代价；
9. 更新关系七变量；
10. 把变化组织成场景、单话和序列；
11. 最后标注十元、生克补、体量、顺序和五维；
12. 用学校档案和证据等级追溯课程来源。
