## 2. 两条专业知识主轴

### 内容生成轴

```text
对象
→ 关系
→ 事件
→ 场景
→ 类型
→ 单话／序列／连载
```

内容向回答：

- 作品中有哪些人物、职业、制度、场所、资源、信息和道具；
- 对象处于什么状态，谁拥有、控制、看见或无法获得；
- 对象允许、禁止和诱发哪些行为；
- 对象怎样改变事件、场景、类型承诺和连载条件。

### 人物行为轴

```text
欲望／恐惧
→ 触发器
→ 行动策略
→ 对方回应
→ 升级／修正／撤回
→ 选择与代价
→ 关系状态变化
```

人物行为向回答：

- 人物为什么在此刻行动；
- 他实际对谁做了什么；
- 对方依据自己的目标怎样回应；
- 谁获得收益，谁立即、延迟或替别人承担代价；
- 信任、权力、距离、依赖、债务、信息差和关系定义权怎样改变。

## 4. 内容库六层

| 层级 | 核心对象 | 典型操作 | 主要模块 |
|---|---|---|---|
| 对象库 | 人物、职业、制度、场所、道具、资源、信息 | 使用、占有、进入、交换、隐藏 | 对象库深层结构 |
| 关系库 | 亲密、权力、债务、竞争、依赖、承载 | 靠近、控制、保护、拒绝、修复 | 回应代价与关系状态机 |

| 场景库 | 对话、追逐、等待、对峙、揭示 | 进入、停顿、反应、升级、转场 | 漫画分镜与Webtoon演出 |

## 5. 人物行为七层

| 层级 | 要问的问题 | 可观察内容 |
|---|---|---|
| 欲望与缺失 | 想得到什么，怕失去什么 | 寻找、保存、争夺、回避 |
| 触发器 | 什么变化使旧状态不能继续 | 威胁、秘密、时限、越界、评价 |
| 行动策略 | 人物习惯怎样解决问题 | 接近、控制、保护、攻击、交换、欺骗 |
| 对方回应 | 对方怎样独立反应 | 接受、协商、拒绝、回避、反制、撤离 |
| 表演 | 行为怎样被读者看见 | 姿势、视线、停顿、台词、声音、镜头 |
| 选择与代价 | 哪两项不能同时保住 | 放弃、承担、牺牲、越线、转移代价 |
| 关系变化 | 行为后什么真实改变 | 信任、权力、距离、依赖、债务、信息、定义权 |

## 6. ABC三模式

### A｜分析模式

```text
已有作品
→ 专业课程拆解对象、行为、分镜与生产
→ 十元正本复核
→ 调整与校准
```

适合学习课程、拆韩漫和复盘作品。

### B｜设计模式

```text
对象与状态
→ 关系条件
→ 对不同人物的意义
→ 十元候选端点
→ 用行为、回应和代价验证
```

禁止“对象＝十元”的静态匹配。

### C｜动态运行模式（默认）

```text
对象状态
→ 关系位置
→ 当前十元端点／已锁定关系
→ 行为
→ 对方回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与新关系
→ 下一轮
```

C模式下，十元持续参与每一轮，不在剧情写完后才补填。

## 7. 十元接口的正确含义

课程库中的对象词、行为词和视觉词只能帮助检索证据，不能充当十元定义。

错误：

```text
攻击＝zx
等待＝xn
保护＝zn
房屋＝n
门＝x
```

正确：

```text
对象状态＋关系位置＋行为目的＋对方回应＋被改变变量
→ 提出端点与关系
→ 用正本验证
```

同一个“保护”可能保存主体、维持承载、公开显权、掌握边界、吸收代价或剥夺选择。必须看它实际改变了什么。

| 十元 | 生 | 克 | 被克 | 补 |
|---|---|---|---|---|
| zx | zn | n | xn | nx |
| x并z | z | nz | nx | n |
| zn | n | xn | xz | x |
| z | nz | nx | x | xn |
| n | xn | xz | zx | x并z |
| nz | nx | x | x并z | xz |
| xn | xz | zx | zn | z |
| nx | x | x并z | z | zx |
| xz | zx | zn | n | nz |
| x | x并z | z | nz | zn |

防遗忘：`zx 克 n`。其成立要求zx公开显权并改变成员资格、接收边界或结构运行条件，使n的接收、保护、照顾、互信或反复返回能力下降。普通攻击和一次命令不够。

## 10. 深度门槛

任何知识模块不能因写了定义和一串词就标记“深度完成”。至少包括：

1. 概念与边界；
2. 分类树；
3. 状态与变化；
4. 可观察行为；
5. 对方回应；
6. 代价；
7. 关系状态；
8. 正例、反例和误判；
9. 模板；
10. 训练与评分；
11. 跨模块连接；
12. 案例或证据待办；
13. 十元源端点与目标端点；
14. 启动机制与被改变变量；
15. 拿掉测试、反向测试和第三因素排除。
