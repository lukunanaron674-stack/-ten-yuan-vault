# 十元化·内容向与人物行为向索引

> 本文件不是韩国大学官方课程，而是把课程库转换成用户可用于创作的“内容库＋人物行为库”。十元定义本身不在这里重写，本文件只负责建立接口。

## 1. 两条主轴

### 内容生成轴

```text
对象
→ 关系
→ 事件
→ 场景
→ 类型
→ 单话／序列／连载
```

内容向回答：

- 作品里有哪些人、物、制度、场所和规则；
- 它们之间形成什么关系；
- 什么事件值得发生；
- 事件应该落在哪种场景；
- 场景属于什么类型承诺；
- 怎样扩展成一话、一个序列或一部长篇。

### 人物行为轴

```text
欲望／恐惧
→ 触发器
→ 行动策略
→ 身体与语言反应
→ 选择
→ 代价
→ 关系与身份变化
```

人物行为向回答：

- 人物想得到什么；
- 什么东西会逼他行动；
- 他习惯用什么方式处理问题；
- 行为如何被看见，而不是只停留在心理标签；
- 哪两件事不能同时保住；
- 谁承担代价；
- 行为最后改变了什么关系。

## 6. 使用顺序

1. 先从对象库选人物、场所、制度或道具；
2. 为人物建立欲望、恐惧和稳定行为倾向；
3. 设计一个真正能触发行动的压力；
4. 写人物做什么，不先写“他很痛苦”；
5. 判断行动怎样改变关系；
6. 把关系变化放入十元动态链；
7. 转成场景、分镜和单话结构；
8. 用课程矩阵检查缺失知识；
9. 用学校档案追溯该知识来自哪些课程；
10. 用证据等级区分官方事实与个人理论。
