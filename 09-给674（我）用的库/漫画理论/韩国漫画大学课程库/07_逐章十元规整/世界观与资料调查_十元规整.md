# 世界观与资料调查｜十元规整

## 本章专业任务

提供时代、职业、制度、空间、资源、技术和日常流程等可核实事实，回答世界怎样真实运行。

## A／B／C入口

- **A分析**：检查作品中的制度、空间和职业行为是否可信，以及哪些规则实际产生了剧情；
- **B设计**：先建立规则制定者、执行者、例外者、受益者和承担成本者，再提出十元候选；
- **C运行**：当制度、空间或资源变化时，重新计算人物权限、可用路线和关系位置。

## 十元候选端点

- `x`：实际掌握对象、资源、地盘或权限；
- `x并z`：掌握关系形成可识别、可调用的公开壳或制度接口；
- `xn`：时间、流程、记录和规则持续组织现实；
- `n`：结构真实接收、承载、保护和维持进入者；
- `xz`：安全路线、时间窗和退路被持续压窄。

对象或制度名称本身不是端点。必须说明谁在运行它、改变了什么变量。

## 可调用的已锁定关系

- `x生x并z`：实际掌握形成稳定公开接口；
- `x并z生z`：公开壳让对象获得明确识别与确认；
- `n补x并z`：内部承载与公开界面互补；
- `xn生xz`：规则和时间组织使偏离者风险持续上升；
- `n克xz`：真实承载降低危险可到达性和继续移动紧迫度。

## 禁止直接映射

- 有法律不等于`xn`；
- 有城墙不等于`n`；
- 有制服或机构名称不等于`x并z`；
- 有战争或危险不等于`xz`；
- 有资源不等于`x`，必须证明掌握和否决权。

## C模式最小记录

```yaml
制度或空间对象:
制定者与执行者:
掌握者与例外者:
准入与退出条件:
时间窗与路线:
人物当前权限:
候选端点:
启动机制:
被改变变量:
下一轮可用行为:
```

## 输出与反证

输出一张“规则压力场卡”：同一规则分别如何保护、排除、承载或制造临界。至少写一个规则存在却未实际运行的反例。
