# README知识模块说明｜十元规整

## 本章专业任务

规定“学校公开课程、重建知识模块、个人理论接口、训练与证据”之间的边界。

## A／B／C入口

- **A分析**：确认某条知识来自学校、公开资料还是本库重建，防止来源混写；
- **B设计**：选择要调用的专业章，再选择对应逐章规整，不从总词表盲配十元；
- **C运行**：每轮创作只调用与当前对象、关系和表现问题有关的章节。

## 十元规整原则

```text
专业知识章＝事实与方法
十元规整章＝候选端点与验证方式
十元正本＝关系最终裁决
```

候选端点不是正式结论。任何章节都必须经过对象状态、关系位置、行为／表现结果和被改变变量，才能进入十元判断。

## 禁止直接映射

- “故事课＝zn”；
- “动作课＝zx”；
- “背景课＝n”；
- “分镜课＝z”；
- “色彩课＝x并z”。

这些只能是检索联想，不是理论判断。

## C模式最小检查

```yaml
当前调用章节:
章节提供的事实或方法:
对象与关系问题:
候选端点:
调用的正本关系:
被改变变量:
输出证据:
误判排除:
```

## 完成判定

一个知识模块只有在“正文＋同名十元规整章＋Canvas双卡连接＋至少一个正例和一个误判”同时存在时，才标记为逐章融合完成。
