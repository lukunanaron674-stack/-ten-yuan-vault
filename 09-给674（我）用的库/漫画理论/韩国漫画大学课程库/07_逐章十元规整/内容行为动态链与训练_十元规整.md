# 内容行为动态链与训练｜十元规整

## 本章专业任务

把对象、欲望、触发、行为、回应、代价、关系变化和下一场连接成可持续运行的场景、单话、序列与长篇动态链。

## 本章采用ABC总协议

- **A分析**：让现成作品先跑完，再用十元检查真实机制和可调整处；
- **B设计**：从对象与关系条件提出候选端点和关系；
- **C运行（默认）**：十元持续参与每轮对象、关系、行为和回应的重分配。

## C模式正式链

```text
对象状态
→ 关系位置
→ 当前十元源端点／目标端点
→ 已锁定关系或待确认假设
→ 行为
→ 对方独立回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与新关系
→ 端点重分配
→ 下一轮
```

## 十元关系调用门槛

每条关系必须记录：源端点、目标端点、启动机制、被改变变量、成立阶段、体量、顺序、显影条件、第三因素、拿掉测试和反向测试。

若只写“这里是zx克n”而没有说明接收、保护、互信或返回能力怎样下降，关系视为未证明。

## 当前防遗忘关系

- `zx克n`；
- `xn克zx`；
- `zx补nx`；
- `x生x并z`；
- `x并z生z`；
- `x克z`；
- `n克xz`；
- `zn补x`；
- `n补x并z`；
- `xn补z`；
- `xz补nz`；
- `n生xn`；
- `x并z克nz`；
- `nz克x`；
- `x克nz`；
- `zn克xn`。

其他位置关系只能标记“待确认”，不得因位置表存在就冒充机制锁定。

## 禁止直接映射

- 动态链长不等于`xn`；
- 行动激烈不等于`zx`；
- 代价沉重不等于`nx`；
- 结局温暖不等于`nz`；
- 危险逼近不自动证明`xz`端点或关系；
- 五维不能倒推起手节点。

## 输出与反证

每条完整动态链至少包含一轮成功关系、一轮关系撤回和一个近邻误判。训练评分必须把“机制与变量证据”单独计分，不再把填了节点名称当完成。
