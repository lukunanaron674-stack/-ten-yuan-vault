# 角色心理与行为库｜十元调用接口

> 本文件只负责把角色心理与行为证据送入十元分析，不再与`04_知识模块/角色心理与行为库.md`竞争知识正本。

## 1. 固定入口

1. 先读[[../04_知识模块/角色心理与行为库]]；
2. 需要视觉导航时打开[[../04_知识模块/角色心理与行为库_R7运行总览.canvas]]；
3. 十元端点查`01-十元系统/十元体系密度卡总览.md`及对应准度卡；
4. 关系边查对应生卡、克卡、补卡与`01-十元系统/十元生补克表.md`；
5. 动态链按`08-生克补动态链研究/生克补动态链方法修正_v2.1_2026-07-28.md`执行。

## 2. A／B／C运行顺序

### A｜心理基线

只记录：

```text
特质证据
核心需要假设
价值与信念
自我叙事
关系预期
防御与应对
决策规则
资源、权限与限制
```

A层不判“稳定主十元”，也不要求把十元填满。

### B｜单场行为事件

```text
触发器
→ 情境解释
→ 本场目标
→ 可选路线
→ 实际行为
→ 具体对象
→ 权限与资源
→ 对方/系统独立回应
→ 收益与代价
→ 唯一核心变量：初态→终态
```

心理词、意图和表层行为只能提出候选，不能直接证明端点或关系。

### C｜十元路由与动态图

```text
对象、主体、阶段明确
→ 核心变量明确
→ 读取源/目标信息卡与准度卡
→ 两端分别标记已成立/候选/未判定
→ 两端成立后读取对应关系卡
→ 查v2.22关系正本
→ 只登记直接改变目标核心变量的关系边
→ 多条直接边组成具体动态图
```

动态图必须区分主链、支路、汇合、反馈、搭桥、断裂和转位。

## 4. 角色弧接口

角色弧至少比较三次同类压力事件，并分开记录：

- 理解是否改变；
- 选择是否改变；
- 新行为能力是否形成；
- 他人和系统是否允许新策略运行；
- 是否出现复发、局部改变或跨对象迁移。

禁止把角色弧写成“旧十元→新十元”。十元只描述具体场景中的关系位置与变量变化。

## 5. 禁止快捷映射

- 恐惧、欲望、创伤、依恋和诊断名不是十元；
- 温柔、控制、保护、攻击和顺从不是固定端点；
- 角色名、组织名、场景、镜头和台词不是默认节点；
- 关系在正本中锁定，不等于本场自动成立；
- 几何位置存在，不等于机制锁定；
- 间接路径不能补写成首端对链尾的直接关系；
- Canvas连线不能替代行为、变量和测试。

## 6. 输出标准

完成一次调用至少产出：

```text
一张人物基线卡（心理层）
＋一张单场行为事件卡（证据层）
＋一个核心变量初态/终态
＋经卡片路由确认的端点状态
＋直接关系边或失败边
＋具体动态图位置
```

端点或关系证据不足时，保留候选或未判定，不为表格完整强行定性。
