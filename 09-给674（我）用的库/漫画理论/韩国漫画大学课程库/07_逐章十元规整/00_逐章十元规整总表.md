# 专业课程逐章十元规整总表

> 每个专业知识章节保留课程事实与方法，同时配一份独立十元规整。规整文件不是给课程贴标签，而是说明本章怎样提供端点、关系、变量、反证和C模式运行条件。

## 使用顺序

```text
打开专业知识章
→ 打开同名十元规整章
→ 选择A分析／B设计／C运行
→ 调用十元正本
→ 写源端点、目标端点、机制与被改变变量
→ 输出作品并做反证
```

## 统一红线

- 对象不天然等于十元；
- 动词不天然等于十元；
- 课程名不等于十元；
- 视觉气氛不等于十元；
- 共现、先后与作者意图不等于生克补；
- 关系判断以`十元生补克表`和防遗忘清单为准；
- `zx克n`，`zx被xn克`；
- 五维是动态链结果，不是课程章节的起手标签。
