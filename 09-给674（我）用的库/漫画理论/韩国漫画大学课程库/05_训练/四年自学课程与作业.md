# 四年自学课程与作业

> 这不是某一所大学的原样课表，而是根据韩国多所大学公开课程重建的完整训练路线。目的是让课程能真正执行，而不是让课程名称在文件夹里安详退休。

## 总体毕业目标

四年结束时，应能独立完成：

- 题材调查与资料核验；
- 角色心理、关系和行为设计；
- 世界观与场景对象库；
- 短篇、中篇和连载结构；
- 页面漫画与竖屏Webtoon分镜；
- 人物、背景、色彩、字体和数字原稿；
- 一套可投稿或展示的连载企划包；
- 制作排期、版权资产表和作品集。

## 评价结构

| 项目 | 比例 |
|---|---:|
| 故事与人物 | 25% |
| 视觉叙事与分镜 | 25% |
| 造型与完成度 | 20% |
| 调查与世界可信度 | 10% |
| 修改能力 | 10% |
| 制作管理与交付 | 10% |

# 第一学年：观察、造型与短篇

## 第一学期｜看见对象

### 课程

1. 漫画与Webtoon概论
2. 素描、速写与人体动态
3. 透视与场景基础
4. 漫画造型与角色设计
5. 数字绘画与文件规范
6. 故事叙述基础
7. 现实观察与行为记录

### 每周训练

- 30个人体动态；
- 10个表情与手势；
- 2个真实空间速写；
- 5条只记录动作、不猜心理的行为观察；
- 1个4至8格无台词事件。

### 中期作业

**《普通人的一天》**

- 选择一个真实职业或身份；
- 做一次观察或访谈；
- 建立20张对象卡；
- 画8页无台词短篇；
- 重点考察动作、空间和阅读清楚度。

### 期末作业

**12至16页短篇漫画**

必须包含：

- 一个明确主角；
- 一个外部目标；
- 一个关系对象；
- 两次阻碍升级；
- 一个不可逆选择；
- 不超过800字台词和旁白。

## 第二学期｜人物为什么行动

### 课程

1. 人体解剖与动作
2. 角色心理学
3. 历史人物与资料调查
4. 漫画分镜基础
5. 色彩与光影
6. 字体、气泡与拟声词
7. 世界观基础

### 每周训练

- 同一人物在三种压力下的反应；
- 两人关系距离变化的12格练习；
- 一页对话删减为无台词版本；
- 一处真实场景的平面图、透视图和动作路线；
- 每两周拆解一部短篇。

### 中期作业

**历史人物再设计**

- 史实／推断／虚构三栏；
- 人物欲望、恐惧、资源和时代限制；
- 8页事件改编；
- 附来源清单。

### 期末作业

**第一话Webtoon，40至60格**

必须完成：

- 角色表；
- 世界规则一页；
- 节拍表；
- 缩略分镜三版；
- 完整原稿；
- 手机端阅读测试；
- 修改复盘。

# 第二学年：世界、分镜与完整作品

## 第三学期｜世界观与场景导演

### 课程

1. 漫画角色设定
2. 世界观设定
3. 神话与叙事
4. 场景设计与导演
5. 漫画分镜工作坊
6. SketchUp／3D背景基础
7. 出版漫画创作

### 每周训练

- 一条世界规则的社会后果；
- 一个场景的权力位置图；
- 4页翻页揭示；
- 40格竖屏空间演出；
- 同一场景用爱情、恐怖、动作三种方式导演。

### 中期作业

**世界压力测试包**

- 世界六层；
- 10条规则；
- 30个对象；
- 30条日常行为；
- 3个阶层视角；
- 一段规则失效后的短篇分镜。

### 期末作业

**24至32页出版漫画或80格Webtoon**

要求：

- 场景空间清楚；
- 至少一场两人关系转折；
- 至少一场动作或复杂调度；
- 画面承担主要信息；
- 完成两轮外部讲评修改。

## 第四学期｜中长篇与连载

### 课程

1. 漫画故事叙述Ⅰ
2. 漫画故事叙述Ⅱ
3. Webtoon创作Ⅰ
4. Webtoon创作Ⅱ
5. 动态漫画／Animatic
6. 内容批评
7. 企划与参考资料

### 每周训练

- 一话节拍表；
- 3至8场景序列；
- 话尾钩子五种方案；
- 主线、关系线、主题线同步检查；
- 将一话压缩20%和扩展20%。

### 中期作业

**12话连载企划**

包括：

- 一句话前提；
- 目标读者和类型承诺；
- 角色关系图；
- 世界设定；
- 第一季结构；
- 每话目标、转折、结果、钩子；
- 前三话详细节拍。

### 期末作业

**连续两话完整Webtoon**

考核：

- 第一话能否建立作品；
- 第二话能否证明故事可以继续；
- 两话之间是否存在因果与关系推进；
- 生产流程是否可持续。

# 第三学年：类型、改编与产业项目

## 第五学期｜爱情、剧情、喜剧与SF

### 课程

1. 类型故事：爱情／剧情／SF
2. 情景喜剧故事叙述
3. 序列设计
4. 漫画改编
5. 高级作画与背景
6. 视觉开发
7. 内容批评研讨Ⅰ

### 每周训练

- 每种类型拆解5部作品；
- 建立类型对象库与行为库；
- 同一人物关系写四种类型场景；
- 重新设计一部失败作品的中段；
- 小说段落转4页漫画。

### 中期作业

**类型变奏实验**

同一前提分别制作：

- 8格爱情版；
- 8格喜剧版；
- 8格SF版；
- 说明对象、行为、节奏和结局承诺如何变化。

### 期末作业

**三话类型连载包**

- 完整第一话；
- 第二、三话精分镜；
- 12话大纲；
- 类型规则表；
- 读者测试与修改报告。

## 第六学期｜悬疑、恐怖、动作与商业制作

### 课程

1. 类型故事：悬疑／恐怖／动作
2. 高级分镜与导演
3. 外包漫画制作
4. 内容项目Ⅰ
5. 漫画商业模式
6. 编辑与出版
7. 内容批评研讨Ⅱ

### 每周训练

- 悬疑四张信息表；
- 恐怖空间规则；
- 动作场景地图；
- 每周一次完整短场景交付；
- 模拟编辑修改。

### 中期作业

**类型短篇三选一**

- 40至80格；
- 悬疑必须公平布置线索；
- 恐怖必须建立并破坏安全规则；
- 动作必须改变空间、资源或关系。

### 期末作业

**模拟商业项目**

团队完成：

- 客户Brief；
- 企划；
- 分工；
- 两周或四周排期；
- 完整样稿；
- 三次修改；
- 资产授权表；
- 成本和复盘。

# 第四学年：毕业作品与作者系统

## 第七学期｜毕业企划与生产

### 课程

1. 毕业项目Ⅰ
2. Capstone DesignⅠ
3. 作品集批评Ⅰ
4. 产业与合同
5. 作者品牌与平台
6. 研究方法／作品分析

### 第1至4周

- 题材调查；
- 前提与主题；
- 角色、关系和世界；
- 受众与平台；
- 风险评估。

### 第5至8周

- 第一季大纲；
- 前三话脚本；
- 视觉开发；
- 生产测试；
- Pitch。

### 第9至16周

- 完成第一话；
- 第二话分镜；
- 调整制作流程；
- 建立作品集页面。

## 第八学期｜毕业交付与公开评审

### 课程

1. 毕业项目Ⅱ
2. Capstone DesignⅡ
3. 作品集批评Ⅱ
4. 就业／投稿／创业
5. 版权与改编提案

### 毕业作品三种规格

#### A. Webtoon连载型

- 20至60话第一季大纲；
- 前三话完整分镜；
- 至少一至三话完整原稿；
- 角色、世界、场景资产；
- 排期、预算和版权表。

#### B. 完整短篇型

- 40至100页出版漫画；
- 或150至300格竖屏作品；
- 完整修改记录；
- 印刷／线上双版本。

#### C. 研究与实验型

- 明确研究问题；
- 漫画史、媒介或读者研究；
- 实验作品；
- 方法、过程和结论；
- 不得拿“实验”当没讲清楚的免死金牌。

## 毕业评审表

| 维度 | 核心问题 |
|---|---|
| 前提 | 是否清晰、有冲突、有代价 |
| 人物 | 行动是否由欲望、恐惧和关系驱动 |
| 结构 | 每话与整体是否持续变化 |
| 类型 | 是否兑现读者承诺并形成变奏 |
| 分镜 | 信息、空间、节奏和情绪是否清楚 |
| 画面 | 造型和风格是否服务叙事 |
| 世界 | 规则是否进入日常行为和冲突 |
| 修改 | 是否能吸收证据而非只接受夸奖 |
| 生产 | 是否可完成、可交付、可继续 |
| 权利 | 素材、字体、合同和署名是否清楚 |

## 每学期归档格式

```text
├─ 期末作品
├─ 外部反馈
├─ 修改版本
└─ 学期复盘
```

## 与现有漫画库连接

每完成一门类型或分镜课程，应从 `05-银矿库/漫画库/` 选择作品作为案例，并把分析结果反向链接到本课程库：

- 课程知识说明“应学什么”；
- 漫画案例说明“作品实际上怎么做”；
- 十元动态链说明“关系感觉如何变化”；
- 个人项目说明“如何转化成自己的作品”。
