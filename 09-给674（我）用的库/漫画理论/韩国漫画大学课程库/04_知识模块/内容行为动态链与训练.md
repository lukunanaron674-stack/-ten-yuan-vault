# 内容行为动态链与训练｜R6

## 1. 本章总判断

内容、行为和动态链不是三份互不相干的清单：

```text
内容对象提供可争夺、可使用、可隐藏、可损坏和可转义的现实条件
→ 对象进入人物关系后形成当前意义
→ 人物以稳定十元策略行动
→ 他人、制度、空间与时间结构独立回应
→ 生克补候选改变具体端点和变量
→ 代价重写对象状态与关系位置
→ 十元重新分配
→ 下一轮获得必要性
```

所谓“剧情推进”，不是发生了更多事件，而是主十元、条件十元、结果十元的体量、顺序、位置或可用性真实变化。

## 2. 动态链的七个知识单位

### 2.1 对象

对象必须记录当前状态、控制者、权限、可见性、稀缺度、替代品和关系绑定。对象名称不决定十元；钥匙、家、戒指、枪、文章都只能提出候选。

### 2.2 当前意义

同一对象对不同人物可以分别是：

- `x`候选：现实掌握、使用权、退出权或最终否决权；
- `z`候选：认可、证据、身份确认或阶段节点；
- `n/nz`候选：承载、接收、回返和关系余温；
- `xn`候选：流程、训练、记录、长期组织；
- `zx`候选：公开决定位置与显权执行；
- `xz`候选：最后窗口、路径收窄与危险临界；
- `nx`候选：沿既有方向借力、让位或承担；
- `zn`候选：主体认为值得坚持、保护或生成的内部意义；
- `x并z`候选：身份壳、公开界面、制度入口和可识别结构。

候选只有在行为、回应和变量变化后才能成立。

### 2.3 触发器

触发器不是“忽然想起过去”，而是使旧端点分配无法继续的具体变化：资源被夺、权限关闭、认可出现、成员资格改变、时间窗启动、关系对象准备离开、危险进入或秘密暴露。

### 2.4 行为

行为必须写清：行动者、目标对象、行为目的、使用资源、公开程度、可撤回性和希望改变的变量。攻击、保护、等待、离开、道歉都不是十元本身。

### 2.5 独立回应

回应者依据自己的主十元、对象状态、信息和权力作出接受、协商、回避、反制、升级、重解释、撤离或牺牲。回应不是给主角递弧光的自动售货机，人类已经发明够多这种机器了。

### 2.6 代价

代价必须改变后续可用性：

- 资源、权限与控制权；
- 认可位置与归因；
- 接收、照顾和返回能力；
- 长期流程的覆盖；
- 危险可到达性与剩余路径；
- 信任、权力差、距离、依赖、债务、信息差和关系定义权。

### 2.7 下一轮

下一轮不是作者另想一个事件，而是上一轮代价自然生成的新对象状态、关系位置、端点分配和可用行为。

## 3. ABC三模式完全十元化

### A｜分析模式

```text
已有作品
→ 按对象、状态、关系、行为、回应、代价拆开
→ 识别主十元、条件十元、结果十元
→ 检查关系是否来自正本
→ 做第三因素、拿掉和反向测试
→ 判断动态链与五维结果
```

### B｜设计模式

```text
选择对象与当前状态
→ 配置人物关系位置
→ 提出端点缺失、威胁或过量
→ 设计人物稳定十元策略
→ 设计独立回应与代价
→ 只保留能改变变量的候选关系
```

### C｜动态运行模式（默认）

```text
对象状态
→ 关系位置
→ 主十元／条件十元
→ 触发器
→ 行为
→ 独立回应
→ 候选生克补
→ 收益与代价
→ 被改变变量
→ 结果十元
→ 对象与关系重分配
→ 下一轮
```

## 4. 八种基础链的十元重建

> 下列不是固定公式，而是八种常见端点变化结构。

### 4.1 获取链

```text
对象可见但不可得
→ 人物确认对象价值
→ 以x、z、xn、nx或zx候选策略接近
→ 控制者、流程或危险回应
→ 获取成功／失败
→ 所有权、认可、债务或权限变化
→ 下一轮围绕“谁真正掌握、谁付费”展开
```

十元检查：

- `x`：是否获得实际使用、排他或否决权；
- `z`：是否只是被确认有资格，尚未掌握对象；
- `xn`：是否必须完成长期流程；
- `nx`：是否借既有身份、关系和通道做成；
- `zx`：是否获得公开最终决定位置；
- `xz`：获取窗口是否正在关闭。

### 4.2 试探链

```text
信息差存在
→ 主体不愿直接暴露
→ 通过可撤回动作测试
→ 对方按自身恐惧重解释
→ 双方调整距离、信息和定义权
→ 微动作或证据使端点显形
→ 信任、控制或关系停靠重新分配
```

主要候选：信息对象的`x`、认可归因`z`、关系承载`n`、停靠`nz`、边界`x`、借他人方向的`nx`。试探不天然等于任何节点。

### 4.3 隐藏—揭示链

```text
信息对象被某人掌握
→ 隐藏保护一个端点并伤害另一个端点
→ 维护成本跨轮次累积
→ 第三者获得碎片
→ 伪造、转交、公开或销毁
→ 认可归因、身份壳与关系信任改变
→ 旧场景被重新解释
```

重点区分：

- `x`掌握信息；
- `x并z`提供公开身份与传播界面；
- `z`完成确认和归因；
- `zx`决定公开处置；
- `n/nz`承受信任与回返后果。

### 4.4 控制—反抗链

```text
一方掌握资源、规则、身份入口或最终决定权
→ 他人选择权、替代路线或退出权下降
→ 受控者表面服从或沿既有方向nx推进
→ 建立替代对象、关系或流程
→ 控制者升级x／xn／zx覆盖
→ 受控者公开反抗、撤离、夺回x或建立新n
→ 重新缔约或破裂
```

红线：普通争吵和强硬语气不足。必须写清谁的选择权、准入、资源、路径或关系位置下降。

### 4.5 保护—债务链

```text
xz危险或损失进入
→ A提供n承载、x资源、xn组织或zx处置
→ B的危险下降，但自主、债务和依赖可能变化
→ A归还选择权／期待回报／扩大控制
→ B接受、偿还、拒绝或反制
→ 保护转成n、nz、nx、x或zx不同结果
```

重点判断：

- `n克xz`只有在真实接收、保护、补给和持续维持使危险可到达性下降时成立；
- 限制行动、锁门和拘禁不等于被接住；
- 替人承担不自动等于`nx`，必须看最终方向位置与代价归属。

### 4.6 交换—背叛链

```text
双方掌握不同稀缺对象
→ 建立条件与履约流程
→ 信息、风险或代价分配不对称
→ 一方改筹码、绕流程或借第三方
→ 短期合作完成
→ 债务、认可、掌握或承载失衡
→ 重谈、共同承担或背叛
```

十元读取：`x`掌握筹码，`xn`组织履约，`nx`借通道做成，`z`确认信用，`n`承载长期合作，`zx`执行最终处置，`xz`表示违约后的临界路径。

### 4.7 牺牲—转移链

```text
两个端点或价值不能同时维持
→ 人物选择保留其一
→ 表面危机解除
→ 代价落到自己、第三人或未来
→ 被转移者获得新的行动理由
→ 原牺牲被重新解释
→ 承担、否认、补偿或再次牺牲
```

必须区分：

- `nx`方向让位或承担；
- `zn`内部意义选择；
- `zx`主动执行；
- `n`承载他人；
- `x`决定保留什么；
- `xz`不可逆窗口。

“牺牲很感人”不构成关系证明，宇宙没有被配乐收买。

### 4.8 离开—返回链

```text
原关系或空间失去可承载性
→ 人物用x退出权、zx行动或nx顺势离开
→ 留下者回应并建立新秩序
→ 距离、资源、身份和回返证据变化
→ 外部压力或新理解出现
→ 自愿返回、被迫返回、拒绝返回或建立新关系
```

重点区分：

- `nz`必须有共同时间、关系余温与自愿回返；
- `x`可能保护退出权，也可能强制维持停靠；
- `xz`表示错过窗口、无稳定停留与路线收窄；
- `n`表示真实接收，而非只让人物无法移动。

### 防遗忘

```text
zx克n：公开显权直接决定成员资格、接收边界或结构运行条件

```

`zx`被`xn`克。不要再临场发明关系，理论不是即兴脱口秀。

## 6. 场景、单话、序列与长篇

### 6.1 场景

一场至少完成：对象状态改变、一次独立回应、一个变量变化、一次端点重分配和下一场条件。

### 6.2 单话

```text
恢复上轮代价
→ 提出本话对象和端点目标
→ 第一次策略
→ 回应造成偏差
→ 第二策略或升级
→ 不可同时保住的两项
→ 局部结算
→ 端点重分配
→ 后果型话尾
```

### 6.3 序列

| 位置 | 十元任务 |
|---|---|
| 进入 | 建立对象状态、关系位置和候选端点 |
| 试行 | 人物使用稳定主十元策略 |
| 回应 | 目标端点或条件十元反作用 |
| 升级 | 体量、顺序、第三者或未来选项损失增加 |
| 新解释 | 对象意义和候选关系改变 |
| 选择 | 两项端点不能同时维持 |
| 结算 | 结果十元与变量真实变化 |
| 余波 | 新条件进入下一序列 |

### 6.4 长篇三线

- 对象线：对象状态、控制权和功能怎样变化；
- 关系线：七变量、端点和生克补怎样变化；
- 策略线：人物惯用十元策略怎样被强化、扭曲、击穿或替换。

## 7. 类型动态链的十元理解

### 爱情

核心不是“接近—告白”，而是`n/nz`关系是否能在`x`边界、`nx`方向让位、`z`认可和`xz`错过窗口之间形成可持续结构。

### 动作

核心不是打得大，而是`x`目标物、`zx`公开行动、`xn`路线和预案、`nx`协作借力、`xz`危险窗口怎样重分配。

### 悬疑

核心是信息对象`x`、确认与归因`z`、公开界面`x并z`、调查流程`xn`和处置权`zx`的变化。

### 恐怖

核心是正常承载`n`与规则`xn`如何失效，安全路径怎样进入`xz`临界，以及主体`zn/x`边界是否被侵入。

### 职场／校园

核心是资格`z`、身份壳`x并z`、流程`xn`、资源掌握`x`、公开权能`zx`与群体承载`n`的组合与冲突。

## 8. 表现层如何进入动态链

分镜、人体、背景、色彩、字体和声音必须显影：

- 对象的可见与不可见；
- 谁占据观看、空间和话语中心；
- 谁能进入、退出、靠近、返回或封锁；
- 行为与回应的先后；
- 体量、顺序、停顿和不可逆性；
- 关系变量变化前后的画面差异。

表现层不能凭气氛证明十元，但可以让已经成立的机制被读者看见。

## 9. 五维归纳

动态链运行后再判断：

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

单场通常只能提供0—1级显影；序列可形成2级；3级主主题需要中心问题、关键转折、高潮与结局共同支持。

## 11. 训练

1. 同一对象在三种关系中分别运行一轮；
2. 同一表层动作跨三个十元候选比较；
3. 为一场写三种独立回应；
4. 把成功改写成延迟代价；
5. 把保护分别写成保留选择和剥夺选择；
6. 对一条候选关系做拿掉、反向和第三因素测试；
7. 用四页分镜显影一次变量变化；
8. 用60格Webtoon完成一轮C模式；
9. 从韩漫分别找正例、近邻误判和反例；
10. 把一条链分别改写成时间、本体、空间、因果、命运五种高层结果。
