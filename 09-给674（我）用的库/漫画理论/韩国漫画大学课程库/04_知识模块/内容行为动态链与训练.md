# 内容行为动态链与训练

> 内容库提供可被争夺、使用、隐藏和改变的对象；人物行为库让对象进入关系和事件；十元正本判断关系端点怎样生、克、补。三者协作，但不能互相冒充。

## 1. ABC三种使用方式

### A｜分析模式

```text
已有作品／已有场景
→ 拆对象、欲望、触发、行为、回应、代价与表现
→ 用十元正本复核端点、关系、体量和顺序
→ 找到误判与修改方向
```

### B｜设计模式

```text
选择对象与关系条件
→ 判断对象对人物的当前意义
→ 提出十元候选端点
→ 设计行为、回应和代价验证
```

对象不天然等于十元，动词也不天然等于十元。

### C｜动态运行模式（默认）

```text
对象状态
→ 关系位置
→ 当前十元端点／已锁定关系
→ 行为
→ 对方回应
→ 收益与代价
→ 被改变变量
→ 新对象状态与新关系
→ 十元端点重分配
→ 下一轮
```

C模式下，十元不是最后填写的标签，而是每轮关系变化的运行检查。

## 2. C模式总动态链

```text
对象进入场景
→ 对象对人物形成价值、威胁或义务
→ 场景前关系位置限制可选行为
→ 触发器使旧状态不能继续
→ 当前十元端点与候选关系显形
→ 人物采取实际行为
→ 对方依据自身目标独立回应
→ 行为升级、修正或撤回
→ 收益与代价结算
→ 对象、信息和关系变量改变
→ 端点与关系重新分配
→ 新事件形成
→ 下一场获得必要性
```

## 3. 三个不能省略的连接

### 3.1 对象→当前意义

必须回答“这个对象为什么在此时对这个人物重要”。

同一枚戒指可以是承诺、身份证据、家族控制、犯罪证物或可变卖资源。对象名称本身不能决定十元。

### 3.2 行为→独立回应

人物行动后，对方必须依据自己的欲望、信息、资源和权力回应。配角不能成为主角弧光的自动售货机。

### 3.3 代价→下一轮条件

代价必须真实改变后续可用对象、关系位置或行动路线。例如：

- 失去资源，必须向敌人借；
- 信任下降，只能改用隐瞒；
- 秘密暴露，第三者开始调查；
- 身份被剥夺，合法手段失效；
- 承载结构断裂，原有返回路线消失。

## 4. 八种基础内容行为链

> 下列是专业叙事结构，不是固定十元链。每次使用都要重新判断端点和正本关系。

### 4.1 获取链

```text
发现目标对象
→ 判断价值
→ 尝试获取
→ 权限或资源阻碍
→ 交换／偷取／证明资格
→ 得到但形成债务
→ 债务成为下一冲突
```

### 4.2 试探链

```text
怀疑对方
→ 不敢直接暴露
→ 设计可撤回试探
→ 对方误读或反试探
→ 双方增加隐藏动作
→ 微动作暴露真实目标
→ 信任上升或关系断裂
```

### 4.3 隐藏—揭示链

```text
秘密形成
→ 隐藏带来短期收益
→ 维护成本增加
→ 第三者获得碎片信息
→ 伪造、转移或承认
→ 真相公开
→ 旧场景被重新解释
```

### 4.4 控制—反抗链

```text
一方掌握关键对象、权限或关系入口
→ 减少他人选择
→ 受控者表面服从
→ 建立替代路线
→ 控制者升级
→ 受控者反抗、离开或重新谈判
→ 关系重新缔约／破裂
```

### 4.5 保护—债务链

```text
危险出现
→ A替B承担风险
→ B获救但部分选择权改变
→ 债务和依赖形成
→ A期待回报或归还选择权
→ B接受、偿还、拒绝或反制
→ 保护转为亲密、控制或反噬
```

### 4.6 交换—背叛链

```text
双方各有稀缺对象
→ 建立条件交换
→ 信息不对称出现
→ 一方改变筹码
→ 短期合作成功
→ 代价分配不均
→ 背叛、重谈或共同承担
```

### 4.7 牺牲—转移链

```text
两项价值不能同时保住
→ 人物牺牲一项
→ 表面解决危机
→ 代价转移给第三人或未来
→ 第三人开始行动
→ 原牺牲被重新评价
→ 承担、否认或再次牺牲
```

### 4.8 离开—返回链

```text
关系或空间无法继续承受
→ 人物提出或实施离开
→ 他人阻止、放行或误解
→ 离开改变资源、身份和关系位置
→ 留下者形成新秩序
→ 外部压力或新理解出现
→ 返回、拒绝返回或建立新关系
```

## 5. 十元关系进入动态链的门槛

只有满足以下条件，才能写生、克、补：

1. 源端点明确；
2. 目标端点明确；
3. 关系语义来自正本；
4. 启动机制可描述；
5. 被改变变量可观察；
6. 成立阶段、体量和顺序明确；
7. 第三因素被检查；
8. 拿掉测试和反向测试通过。

共现、先后、动作激烈、画面相似、课程关键词和作者意图都不等于关系启动。

## 6. 防遗忘：zx克n

```text
zx主体公开显权，直接决定成员资格、接收边界或结构运行条件
→ n原有的接收、保护、照顾、互信与反复返回能力被迫停止
→ n的承载能力下降、断裂或失效
```

普通攻击、追逐、公开讲话或一次命令不自动证明zx克n。

## 8. 单话动态链

```text
恢复上轮代价
→ 提出本话对象和目标
→ 第一次行动
→ 回应造成偏差
→ 第二策略或升级
→ 选择与局部结算
→ 端点与关系重分配
→ 产生更危险的新条件
```

单话至少完成：

- 一个可执行目标；
- 一次有效回应；
- 一项对象状态变化；
- 一项关系变量变化；
- 一次端点或体量重分配；
- 一个来自前面行为后果的话尾条件。

## 9. 序列与长篇

一个序列通常由3至8场组成：

| 位置 | 作用 |
|---|---|
| 进入 | 目标、对象与前置关系出现 |
| 试行 | 人物使用惯常策略 |
| 回应 | 对方或制度有效回应 |
| 升级 | 旧策略成本增加 |
| 新解释 | 对对象和关系产生新意义 |
| 选择 | 两项价值不能同时保住 |
| 结算 | 代价、变量和端点变化 |
| 余波 | 新条件进入下一序列 |

长篇同步三线：

- 情节线：对象和外部目标怎样变化；
- 关系线：七变量和十元端点怎样变化；
- 行为模式线：稳定策略怎样被强化、扭曲、击穿或替换。

## 10. 表现层接口

分镜、人体、背景、色彩、字体和声音负责让关系变化可见，不负责定义十元。

表现层至少回答：

- 哪个对象被突出或隐藏；
- 谁获得观看中心；
- 谁能进入、退出、靠近或占据空间；
- 哪个动作与回应是场景转折；
- 停顿、留白、翻页或滚动怎样显影体量与顺序；
- 画面改变是否来自真实关系变化，而不是仅靠气氛冒充。

## 11. 十项训练

1. 同一对象在三种关系中分别运行一轮C模式；
2. 同一表层动作跨三个候选十元端点比较；
3. 为一个场景写出对方三种独立回应；
4. 把一次成功改成延迟代价；
5. 把一次保护分别写成保留选择与剥夺选择；
6. 为一条候选关系做拿掉测试；
7. 为一条候选关系找第三因素；
8. 用四页分镜显影一次关系变量变化；
9. 用60格Webtoon完成一轮C模式；
10. 从韩漫找一个正例、一个近邻误判和一个反例。
