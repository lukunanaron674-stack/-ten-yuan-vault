# 内容行为动态链与训练

> 内容库负责提供可被争夺、使用、隐藏和改变的对象；人物行为库负责让这些对象进入关系和事件。两者不连接，内容只是设定，人物只是心理标签。

## 1. 总动态链

```text
对象进入场景
→ 对象对人物产生价值或威胁
→ 人物形成当前欲望
→ 触发器迫使人物行动
→ 人物选择行为策略
→ 对方回应
→ 行为升级、修正或撤回
→ 收益与代价结算
→ 关系状态改变
→ 新事件形成
→ 下一场景获得必要性
```

## 2. 三个不能省略的连接

### 2.1 内容→欲望

必须回答“这个对象为什么对这个人物重要”。

同一枚戒指对不同人物可能分别是：

- 恋爱承诺；
- 身份证据；
- 家族控制；
- 犯罪证物；
- 可以变卖的资源。

对象不自动产生同一种剧情。

### 2.2 行为→回应

人物行动后，对方必须依据自己的欲望、信息和权力作出回应。不能让所有配角自动配合主角完成弧光。

### 2.3 代价→下一场

代价不是场景末尾写一句“他很难过”。代价必须形成新的行动条件，例如：

- 失去资源，必须向敌人借；
- 信任下降，必须改用隐瞒；
- 秘密暴露，第三者开始调查；
- 身份被剥夺，原有合法手段失效。

## 3. 八种基础动态链

### 3.1 获取链

```text
发现目标对象
→ 判断价值
→ 尝试获取
→ 权利或资源阻碍
→ 交换／偷取／证明资格
→ 得到但形成债务
→ 债务成为下一冲突
```

适合：成长、冒险、职场、升级、权力题材。

### 3.2 试探链

```text
怀疑对方
→ 不敢直接暴露
→ 设计可撤回试探
→ 对方误读或反试探
→ 双方增加隐藏动作
→ 一个微动作暴露真实目标
→ 信任上升或关系断裂
```

适合：爱情、悬疑、权力关系、师生、敌友转换。

### 3.3 隐藏—揭示链

```text
秘密形成
→ 隐藏带来短期收益
→ 维护秘密的行为成本增加
→ 第三者获得碎片信息
→ 人物伪造、转移或承认
→ 真相公开
→ 旧场景被重新解释
```

适合：悬疑、家庭、身份、复仇、历史秘密。

### 3.4 控制—反抗链

```text
一方掌握关键资源
→ 用规则或帮助限制他人
→ 受控者表面服从
→ 建立隐蔽替代路线
→ 控制者升级监视和惩罚
→ 受控者公开反抗或离开
→ 关系重新缔约／彻底破裂
```

适合：职场、家庭、宫廷、黑帮、校园权力。

### 3.5 保护—债务链

```text
危险出现
→ A替B承担风险
→ B获救但失去部分选择权
→ 债务和依赖形成
→ A开始期待回报或服从
→ B接受、偿还或拒绝债务
→ 保护转为亲密／控制／反噬
```

适合：爱情、战友、救赎、英雄、监护关系。

### 3.6 交换—背叛链

```text
双方各有稀缺资源
→ 建立条件交换
→ 一方发现信息不对称
→ 暗中改变筹码
→ 短期合作成功
→ 代价分配不均
→ 背叛、重新谈判或共同承担
```

适合：犯罪、政治、商业、冒险、谍战。

### 3.7 牺牲—转移链

```text
两项价值不能同时保住
→ 人物选择牺牲一项
→ 表面解决危机
→ 代价被转移给第三人或未来
→ 第三人开始行动
→ 原牺牲被重新评价
→ 人物承担、否认或再次牺牲
```

适合：战争、家庭、英雄、伦理困境、悲剧。

### 3.8 离开—返回链

```text
关系或空间无法继续承受
→ 人物提出或实施离开
→ 其他人阻止、放行或误解
→ 离开改变资源和身份
→ 留下者形成新秩序
→ 外部压力或新理解出现
→ 返回、拒绝返回或建立新关系
```

适合：成长、爱情、家庭、流亡、归乡、命运题材。

## 5. 单话动态链

一话不必完成整个人物弧，但要完成一个局部行为闭环。

```text
恢复上话代价
→ 提出本话对象和目标
→ 第一次行动
→ 回应造成偏差
→ 第二策略或升级
→ 选择与局部结算
→ 产生更危险的新条件
```

### 单话检查

- 是否有本话可执行目标；
- 是否至少出现一次对方有效回应；
- 是否有一项对象状态变化；
- 是否有一项关系变量变化；
- 话尾钩子是否来自前面行为的后果，而不是凭空出现新怪物。

## 6. 序列动态链

一个序列通常由3至8个场景组成，围绕一个阶段目标。

| 场景位置 | 作用 |
|---|---|
| 进入 | 目标与对象出现 |
| 试行 | 人物使用惯常策略 |
| 反应 | 对方或制度有效回应 |
| 升级 | 旧策略成本增加 |
| 新信息 | 对对象和关系产生新解释 |
| 选择 | 两项价值不能同时保住 |
| 结算 | 目标、代价和关系变化 |
| 余波 | 新条件进入下一序列 |

## 7. 长篇三线同步

### 情节线

对象和外部目标怎样变化。

### 关系线

信任、权力、距离、债务、依赖和定义权怎样变化。

### 行为模式线

人物的稳定策略怎样被强化、升级、击穿或替换。

三条线不能互相代替。打赢敌人不自动等于人物成长，恋爱成功也不自动解决制度冲突。宇宙对此没有提供套餐服务。

## 8. 类型行为链

### 爱情

核心对象：时间、秘密、身体边界、旧关系、家庭与身份差。

```text
注意／吸引
→ 可撤回接近
→ 试探边界
→ 误读或拒绝
→ 用照顾、交换或共同秘密增加绑定
→ 亲密要求与自我保护冲突
→ 公开选择关系形式
→ 承担亲密代价
```

### 动作

核心对象：目标物、空间路径、能力、时间、队友和伤害成本。

```text
目标确认
→ 路径受阻
→ 使用能力
→ 对手适应
→ 空间和资源被压缩
→ 牺牲速度、安全或同伴
→ 达成／失败
→ 身体与关系余波
```

### 悬疑

核心对象：证据、证词、时间线、秘密和解释权。

```text
异常
→ 假设
→ 调查行为
→ 对象或人物反制
→ 新证据支持多种解释
→ 主角公开或隐瞒判断
→ 揭示重写旧关系
```

### 恐怖

核心对象：安全规则、身体边界、空间和可信信息。

```text
异常迹象
→ 否认或合理化
→ 试验安全规则
→ 规则部分成立
→ 应对行为失败
→ 身份／身体／空间被侵入
→ 逃离、牺牲或接受新规则
```

### 职场／校园

核心对象：资格、评价、机会、导师、同辈和制度资源。

```text
进入评价系统
→ 尝试证明资格
→ 规则与非正式权力冲突
→ 交换、竞争或结盟
→ 成果被认可／夺取／误读
→ 选择服从、改革、退出或夺权
```

## 9. 十元接口的使用限制

十元用于判断内容和行为之间的关系，不用于替代行为依据。

顺序：

1. 先确认对象、欲望、信息、资源和行为；
2. 再确认回应、代价和关系变化；
3. 最后判断十元节点、生克补、体量、顺序和五维主轴。

禁止：

- 先决定“这是zx”，再硬造攻击行为；
- 先决定结局是nz，再让人物无理由回归；
- 把心理、题材、色调或视觉气氛直接当十元行为；
- 用十元标签掩盖行为动机缺失。

## 10. 十元内容—行为检查

| 十元 | 内容检查 | 行为检查 |
|---|---|---|
| xn | 是否存在过程、训练、长期推进 | 行为是否持续积累并改变能力 |
| z | 是否存在节点、限制、截断 | 谁实施决定、禁止或停止 |
| zn | 主体资格或生成发生什么变化 | 人物怎样确认、表达、保护主体 |
| x | 边界、身份、结构如何稳定 | 谁定义、维持、拒绝或排除 |
| x并z | 系统、规则、空间如何组织 | 谁配置、分类、管理和约束 |
| n | 什么关系和承载物连接人物 | 谁靠近、共享、协调和依赖 |
| zx | 外部冲突如何显性推进 | 谁执行、攻击、控制、追逐 |
| nx | 代价和补偿怎样被吸收 | 谁让步、承担、补偿、退让 |
| xz | 哪项压力不可逆或逼近临界 | 谁逼迫、剥夺、跨线、封死选项 |
| nz | 什么被保存、停靠或重新归属 | 谁等待、陪伴、修复、返回 |

## 11. 十项训练

1. **对象启动**：随机抽一个普通物件，写出三种所有权冲突和三条行为链；
2. **行为多义**：同一“送礼”动作写亲密、控制、补偿三种功能；
3. **回应扩散**：给一次告白写12类回应，每类产生不同下一场；
4. **代价复利**：让一次成功在五场后产生更大代价；
5. **关系状态机**：用七变量记录两人6个场景的变化；
6. **制度入场**：让学校、公司或家庭规则真正阻止人物行动；
7. **无心理旁白**：删除心理说明，只保留动作、空间、道具与回应；
8. **反策略**：让对手根据主角旧策略进行有效适应；
9. **类型转换**：同一对象和人物关系分别写成爱情、悬疑、恐怖；
10. **十元后置**：先完整写行为链，再标十元并检查是否倒推。

## 12. 评分表

总分100：

| 项目 | 分值 | 通过标准 |
|---|---:|---|
| 对象具体性 | 10 | 有状态、控制权和可操作性 |
| 欲望与触发 | 10 | 行为由当前压力启动 |
| 行为逻辑 | 15 | 符合信息、资源、身份和习惯策略 |
| 对方回应 | 15 | 对方不是机关人，有独立目标 |
| 代价 | 15 | 至少包含即时或延迟真实损失 |
| 关系变化 | 15 | 至少一项变量发生可说明变化 |
| 场景必要性 | 10 | 下一场由本场后果产生 |
| 视觉化 | 5 | 可转成动作、空间、道具和镜头 |
| 十元后置准确性 | 5 | 标签不替代行为依据 |

低于70：仍是概念草稿；
70至84：能写成场景，但链条有松动；
85至94：可进入分镜与单话；
95以上：对象、行为、回应、代价与动态链均能互相证明。

## 13. 深度门槛

任何“深入完成”的模块至少包含：

- 概念边界；
- 分类树；
- 状态与变化；
- 可观察行为；
- 对方回应；
- 代价；
- 关系状态；
- 正例与反例；
- 模板；
- 训练和评分；
- 与其他模块的链接；
- 证据或案例待办。
