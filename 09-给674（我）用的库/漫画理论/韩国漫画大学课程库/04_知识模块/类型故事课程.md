# 类型故事课程

## 1. 类型不是皮肤

类型是一组对读者的承诺：

- 会出现哪些核心对象；
- 人物会执行哪些核心行为；
- 冲突如何升级；
- 读者主要期待什么情绪；
- 结局至少需要回应什么问题。

给校园恋爱故事加一把剑，不会自动变成奇幻史诗。那只是一把非常困惑的剑。

## 2. 类型分析模板

```yaml
类型:

```

## 3. 爱情／浪漫

### 核心问题

两人能否建立一种双方都愿意承担代价的关系？

### 对象库

- 身份差；
- 前任、婚约、家庭；
- 工作与社会评价；
- 共同秘密；
- 距离、时间、疾病；
- 竞争者；
- 权力不对等。

### 行为库

- 注意、靠近、照顾；
- 试探、误解、隐瞒；
- 嫉妒、拒绝、退缩；
- 告白、承诺、越界；
- 分离、等待、修复；
- 重新定义关系。

### 结构

```text
产生注意
→ 建立特殊互动
→ 风险显现
→ 关系升级
→ 核心矛盾暴露
→ 分离或背叛
→ 选择关系形式
```

## 4. 剧情／现实题材

### 核心

人物在制度、家庭、阶层或生活压力下作出有代价的选择。

### 对象库

职业、家庭、社区、学校、债务、疾病、住房、法律、舆论。

### 行为库

忍耐、协商、隐瞒、举报、离职、照顾、借贷、搬迁、妥协、反抗。

### 风险

- 把苦难堆积误认为深刻；
- 角色只承担议题，没有个人欲望；
- 反派被写成制度说明牌。

## 5. 喜剧／情景喜剧

### 喜剧来源

- 目标与能力不匹配；
- 身份与行为矛盾；
- 信息差；
- 规则被过度认真执行；
- 重复中的升级；
- 关系中的熟悉模式；
- 期待被精准打破。

### 情景喜剧结构

```text
日常目标
→ 小谎言或错误策略
→ 更多人物卷入
→ 维持谎言的成本升级
→ 公开崩坏
→ 关系恢复但留下新后果
```

## 6. 动作

### 核心

人物必须在清晰空间中，以有限能力完成目标。

### 对象库

地形、武器、载具、目标物、出口、队友、人质、时间限制。

### 行为库

侦察、潜入、追逐、伏击、防守、营救、夺取、反制、撤退、牺牲。

### 每轮升级至少改变

- 空间位置；
- 人数；
- 武器；
- 伤势；
- 信息；
- 目标；
- 关系。

## 7. 悬疑／推理

### 四张信息表

- 真实发生了什么；
- 犯人知道什么；
- 主角知道什么；
- 读者知道什么。

### 线索要求

- 可见；
- 可被误读；
- 回看时成立；
- 与人物行为相连；
- 不靠最后突然出现的秘密双胞胎救场。

### 结构

```text
异常／案件
→ 初步解释
→ 新证据破坏解释
→ 怀疑对象变化
→ 主角自身关系卷入
→ 真相重新解释旧信息
→ 揭露与后果
```

## 8. 恐怖

### 核心

安全、身份或现实规则逐步失效。

### 恐怖对象

- 空间；
- 身体；
- 家庭；
- 记忆；
- 技术；
- 群体；
- 不可理解存在。

### 行为链

注意异常、否认、验证、躲避、制定规则、规则失败、隔离、面对真相。

### 常见错误

- 怪物一开始全身出场，后面只剩造型展示；
- 人物为了剧情主动变笨；
- 惊吓没有后果；
- 所有恐怖都靠黑眼睛和长头发轮班。

## 9. SF

### 核心问题

一个技术或规则差异如何改变人的选择、制度和关系？

### 推演表

```text
差异规则
→ 直接用途
→ 产业变化
→ 法律变化
→ 家庭变化
→ 黑市与滥用
→ 最大受益者
→ 最大受害者
→ 主角私人困境
```

### SF类型

硬科幻、社会科幻、赛博朋克、时间旅行、人工智能、太空歌剧、灾变、第一接触。

## 10. 奇幻／武侠

### 核心

超常规则必须与价值、身份和代价相连。

### 对象库

血统、门派、魔法、契约、神器、种族、领地、宗教、异界。

### 行为库

修炼、试炼、继承、召唤、契约、封印、背叛、献祭、远征、夺权。

### 规则检查

- 能力成本是否真实影响选择；
- 强者为何不直接解决问题；
- 权力怎样进入政治和经济；
- 普通人怎样生活。

## 11. 历史

### 核心

真实时代约束下的具体人物选择。

必须研究：

- 制度；
- 交通与通信；
- 服装与器物；
- 阶层和语言；
- 当时可知的信息；
- 现代人不会自然拥有的观念。

## 12. 类型混合

先确定：

- 主类型负责什么核心问题；
- 副类型提供什么情绪和机制；
- 高潮按哪一种类型兑现。

例：爱情＋悬疑，可以让关系建立依赖秘密，但最终必须同时回应“真相是什么”和“知道真相后是否还能相爱”。

## 13. 类型课程作业

1. 每种类型分析10部作品；
2. 提取50个对象和50个行为；
3. 找出重复公式与有效变奏；
4. 同一前提分别写成爱情、恐怖、悬疑、喜剧；
5. 完成两种类型各一话分镜；
6. 为混合类型写“主承诺／副承诺／高潮兑现”说明。
