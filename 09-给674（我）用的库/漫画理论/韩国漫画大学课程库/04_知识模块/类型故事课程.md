# 类型故事课程｜R6

## 1. 本章十元总判断

类型不是视觉皮肤，而是对读者承诺：哪些对象会反复出现、哪些十元端点会成为主战场、冲突怎样升级、哪些代价必须结算、结局要回答哪一个五维问题。

类型的最低结构：

```text
核心对象族
＋常见关系位置
＋主十元候选
＋高频条件十元
＋典型动态链
＋体量与顺序
＋五维兑现
＋类型误判红线
```

给校园恋爱故事加一把剑不会自动变成奇幻。除非这把剑真正改变了身份、资源、关系、制度和结局，否则它只是带刃的美术附件。

## 3. 爱情／浪漫的十元化

### 3.1 核心问题

不是“能否相爱”，而是：

> 两人能否建立真实`n`承载和`nz`回返，同时保留各自`x`边界与`zn`主体资格，而不是把亲密变成`nx`方向让位或`x/zx`控制？

### 3.2 核心对象

- 身份差、婚约和社会评价：`x并z/z/xn`；
- 家庭与旧关系：`n/nz/x`；
- 工作、住房、距离和疾病：`x/xn/xz/n`；
- 共同秘密：信息`x`、关系`n/nz`；
- 权力不等：`x/zx/xn/nx`。

对象不自动等于端点。婚约可能只是身份壳，也可能真实掌握退出权。

### 3.3 行为库的十元重读

| 行为 | 可能主十元 | 必须验证 |
|---|---|---|
| 靠近、照顾 | n/nz/x | 是否真实接收、是否形成回返、是否控制 |
| 试探、误读 | x/z/n | 信息掌握、认可和信任变化 |
| 嫉妒、拒绝 | z/x/xz | 认可门控、边界、关系窗口 |
| 告白、承诺 | z/x并z/nz | 谁确认什么、公开关系壳、共同时间 |
| 分离、等待 | x/xz/nz/nx | 退出权、最后窗口、自愿停靠、方向让位 |
| 修复 | n/nz/zn/x | 恢复哪种能力，而不是只说和好 |

### 3.4 典型动态链

```text
注意对象进入z候选
→ 可撤回接近测试n/x边界
→ 共同时间形成nz候选
→ 身份、资源或旧关系x/x并z介入
→ 一方试图用x缩小对方退出权
→ 自愿停靠证据下降
→ 可检查x克nz
→ 分离后仍保留回返可能
→ 可检查nz克x条件
→ 高潮选择关系形式与边界
```

`x克nz`与`nz克x`都必须满足正本红线，不得用一次吃醋、一次挽留或一次争吵代替。

### 3.5 五维兑现

爱情常以命运`xz+nz`显影，但也可能主打本体`zn+x`或空间`x并z+n`。不能因为有情侣就自动判命运主题。

## 4. 剧情／现实题材的十元化

### 4.1 核心问题

人物在制度、家庭、阶层和生活压力下，怎样分配掌握`x`、承载`n`、流程`xn`、借力`nx`、公开权能`zx`和主体意义`zn`。

### 4.2 对象与端点

- 职业、学校、法律、舆论：`x并z/xn/z/zx`；
- 债务、住房、医疗：`x/n/nx/xz`；
- 家庭、社区：`n/nz/x/x并z`；
- 阶层：长期`xn`、资源`x`、身份壳`x并z`和认可`z`组合。

### 4.3 典型链

```text
人物沿既有nx方向生活
→ 制度xn持续分配资源与资格
→ 掌握者x关闭替代入口
→ 生活安全路线缩窄xz
→ 人物选择服从、借力、公开反抗zx或撤回意义zn
→ 代价由谁承担成为因果主问题
```

现实题材不能把苦难堆积当深度。必须写清谁制造、谁承担、谁受益、谁能退出。

### 4.4 可调用关系

- `xn克zx`：长期制度限制单次显权；
- `xn生xz`：流程识别偏差并压缩安全路径；
- `zx克n`：公开处置破坏原承载；
- `zn克xn`：主体意义撤回对结构的维护资格；
- `x克z`：资源与入口掌握阻断认可。

## 5. 喜剧／情景喜剧的十元化

### 5.1 喜剧来源

喜剧不是“轻松色调”，而是十元端点的预期与实际作用错位：

- 想展示`zx`权能，实际被`xn`流程压回去；
- 想维持`x并z`体面壳，内部`n`已经崩坏；
- 想获得`z`认可，却因`x`掌握错误接口而被误认；
- 想表现`zn`主体，实际只是沿`nx`群体方向；
- 想控制`x`，结果`nz`关系让其主动放权。

### 5.2 情景喜剧链

```text
日常xn秩序
→ 小目标触发
→ 人物用错误主十元策略
→ 为维护x并z身份壳不断追加行为
→ 代价复利、更多人物卷入
→ 公开崩坏形成z节点
→ 关系n/nz恢复但留下新对象状态
```

喜剧回归日常不等于变量归零。至少一个债务、秘密、身份或关系位置必须保留。

## 6. 动作类型的十元化

### 6.1 核心问题

人物在清晰空间和有限资源中，如何通过对象掌握、计划、借力、公开行动与临界风险完成目标。

动作不等于`zx`。动作场景常同时涉及：

- `x`：武器、目标物、出口和地形掌握；
- `xn`：侦察、计划、时间窗和规则；
- `nx`：队友、身份、路线和系统借力；
- `zx`：公开决定与权能显现；
- `xz`：退路、伤势、倒计时和最后窗口；
- `n`：队伍承载、营救和保护；
- `z`：任务节点和确认结果。

### 6.2 每轮升级

每轮至少改变一项对象状态和一个端点：

- 空间位置：`x/xz/n`；
- 人数与同盟：`n/x并z/nx`；
- 武器：`x/zx`候选；
- 伤势：能力和安全路线`xz`；
- 信息：`x/z/xn`；
- 目标：`z/zn`；
- 关系：七变量与端点重分配。

### 6.3 典型关系

- `xn克zx`：计划和流程限制蛮力；
- `n克xz`：队伍或安全结构真实吸收危险；
- `zx克n`：敌方公开显权击穿队伍承载；
- `zx补nx`：直接权能与借通道行动互补；
- `xn生xz`：规则和追踪让偏离者退路越来越少。

## 7. 悬疑／推理的十元化

### 7.1 四张信息表

- 真实发生：对象真实状态；
- 犯人知道：信息掌握`x`；
- 主角知道：调查`xn`和确认`z`；
- 读者知道：表现层信息接口`x并z`。

### 7.2 线索十元结构

```yaml
线索对象:
首次功能:
当前控制者x:
公开接口x并z:
可支持的解释:
确认主体z:
调查流程xn:
误读者:
揭示后改变的关系变量:
回收节点:
```

### 7.3 典型链

```text
异常对象出现
→ 初步z确认
→ xn调查积累证据
→ x掌握者隐藏、改署或关闭接口
→ 可检查x克z
→ 新证据x并z提供可识别对象
→ 可检查x并z生z
→ 真相重写旧关系
→ 公开处置zx与代价nx结算
```

最后突然出现的信息不属于有效`z`确认，因为缺少前置对象和流程。

## 8. 恐怖类型的十元化

### 8.1 核心问题

安全承载`n`、持续规则`xn`、主体意义`zn`和现实掌握`x`怎样在临界风险`xz`中失效或重组。

### 8.2 恐怖对象

- 空间：是否能接收和保护`n`，还是只有封闭`x/xn`；
- 身体：主体资格`zn`、身体掌握`x`和身份壳`x并z`；
- 家庭：真实承载`n`、关系停靠`nz`或控制`x`；
- 记忆：确认`z`、过程`xn`和主体`zn`；
- 技术：掌握`x`、系统`xn`、公共界面`x并z`；
- 群体：成员资格`n/x并z`和公开处置`zx`；
- 不可理解存在：只有当安全路线真实缩窄才是`xz`端点。

### 8.3 行为链

```text
正常n/xn规则建立
→ 微小异常
→ 人物否认或验证
→ 规则部分成立
→ xn持续识别偏离并压缩路线
→ 可检查xn生xz
→ 安全承载n尝试吸收风险
→ 成功则n克xz，失败则承载断裂
→ 主体被迫选择意义、身体或关系
```

黑眼睛、长头发、低明度和噪点不是`xz`。

## 9. SF的十元化

### 9.1 差异规则

一个技术差异必须逐层改变：

```text
实际掌握x
→ 公共身份壳x并z
→ 认可节点z
→ 长期流程xn
→ 内部承载n
→ 借力方向nx
→ 公开权能zx
→ 临界风险xz
→ 关系回返nz
→ 主体意义zn
```

### 9.2 推演表R6

```yaml
差异规则:
掌握者x:
公共接口x并z:
认证节点z:
产业流程xn:
家庭承载n:
借力通道nx:
公开执行zx:
最大风险xz:
关系停靠nz:
主体意义zn:
最大受益者:
最大受害者:
主角私人困境:
可调用关系:
```

科幻名词没有进入制度和日常，就还没有十元化。

## 10. 奇幻／武侠的十元化

### 10.1 超常规则

血统、门派、魔法、契约、神器、领地和宗教必须拆为对象、状态、权限、成本和关系。

- 血统：`x并z`身份壳、`z`认可和`x`继承掌握；
- 门派：`n`内部承载、`x并z`公开壳、`xn`训练；
- 魔法：`x`资源、`xn`规则、`xz`失败风险；
- 契约：`x/xn/nx`方向与代价；
- 神器：对象状态变化，不天然`zx`；
- 领地：实际掌握`x`与公共代表`x并z`；
- 宗教：`zn`意义、`xn`传统、`z`认可和`n`共同体。

### 10.2 典型链

```text
主体获得或被赋予身份壳x并z
→ 通过xn训练与z节点确认
→ 获得对象掌握x
→ 公开显权zx
→ 结构、关系与代价回应
→ 主体意义zn决定继续维护或撤回
```

强者为什么不直接解决问题，通常要由`xn`规则、`x`资源限制、`n`责任或`zn`意义约束解释。

## 11. 历史类型的十元化

历史题材必须以时代可用端点为边界：

- 当时谁能掌握资源`x`；
- 哪些身份壳`x并z`有效；
- 哪些认可主体`z`存在；
- 流程`xn`受交通与通信限制；
- 共同体`n`能承担什么；
- 借力`nx`依赖哪些关系和身份；
- 公开权能`zx`受何制度约束；
- 临界风险`xz`有哪些真实窗口；
- 停靠`nz`受时代关系形式限制；
- 主体意义`zn`不能被现代价值代写。

## 12. 类型混合的十元化

主类型决定主要动态链和高潮五维回答，副类型提供对象、条件十元或表现方式。

### 混合模板

```yaml
主类型:
主类型主端点:
主类型核心动态链:
副类型:
副类型提供的对象:
副类型提供的条件十元:
两类共享关系变量:
高潮按哪个类型结算:
另一个类型如何获得余波回答:
```

爱情＋悬疑不仅要同时回答真相和关系，还要说明信息`x/z/xn`变化怎样改变`n/nz/x`关系。

## 13. 类型与五维

| 类型 | 常见五维显影 | 不能自动判定的原因 |
|---|---|---|
| 爱情 | 命运、本体、空间 | 有情侣不代表有临界与回返链 |
| 现实剧情 | 因果、空间、本体 | 有社会议题不代表主题已运行 |
| 喜剧 | 因果、空间、时间 | 笑点只是表现，需端点错位链 |
| 动作 | 因果、命运、时间 | 动作不等于zx，倒计时不等于命运 |
| 悬疑 | 时间、因果、本体 | 信息差不自动形成主题 |
| 恐怖 | 命运、空间、本体 | 黑暗气氛不等于xz+nz |
| SF | 空间、时间、本体 | 设定名词不等于制度和主体变化 |
| 奇幻武侠 | 本体、空间、因果 | 能力和信仰需关系机制 |
| 历史 | 时间、空间、因果 | 年代背景不自动产生时间主题 |

## 14. 误判红线

- 恋爱行为不等于`n/nz`；
- 动作行为不等于`zx`；
- 悬疑线索不等于`z`；
- 恐怖气氛不等于`xz`；
- 制度题材不等于`xn/x并z`；
- 奇幻能力不等于`zn`；
- 历史年代不等于时间主题；
- 主类型和副类型不能只按视觉元素判断；
- 类型套路共现不能证明生克补；
- 高潮必须结算前置端点，不能临时换主题。

## 15. 全量十元化课程作业

1. 每种类型分析10部作品，提取对象、主端点、条件端点和结果端点；
2. 每种类型建立50个对象和50个行为，但禁止给动作永久贴十元；
3. 同一前提分别写成爱情、恐怖、悬疑、喜剧，比较端点和五维变化；
4. 写一个`xn克zx`动作场景；
5. 写一个`x克z`悬疑场景；
6. 写一个`n克xz`恐怖场景和一个失败反例；
7. 写一条爱情中的`x克nz`候选链，并做红线检查；
8. 为一项科幻技术完成十元全域推演；
9. 为一个奇幻门派区分`n/x并z/xn/x`；
10. 为混合类型写主承诺、副承诺、高潮端点和五维兑现说明。
