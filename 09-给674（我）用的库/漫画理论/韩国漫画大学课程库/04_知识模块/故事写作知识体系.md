# 故事写作知识体系｜R6

## 1. 本章十元总判断

故事不是事件清单，而是十元端点在对象、关系和时间中不断转位的动态链。

最低故事结构升级为：

```text
人物处于某个对象与关系状态
→ 一个端点缺失、受威胁或过度膨胀
→ 人物用稳定十元策略行动
→ 他人、制度或空间独立回应
→ 生克补候选启动[]()
→ 收益和代价改变对象及关系变量
→ 主十元、条件十元和结果十元重新分配
→ 人物被迫选择
→ 形成不可逆变化与下一轮
```

事件只有在改变端点、体量、顺序或关系变量时才成为剧情。

## 2. 前提的十元化

原前提“谁、想要什么、被什么阻碍、失败失去什么”改写为：

```yaml
主角:
场景前主十元:
目标对象:
目标对象状态:
想增强或恢复的端点:
主要阻碍端点:
条件十元:
失败会下降的能力或关系变量:
临界窗口xz:
不可同时保住的两项:
候选动态链:
```

### 十元化前提模板

> 当【对象状态或关系位置变化】发生后，【人物】必须通过【主十元策略】改变【目标端点】，否则【某项能力、关系或路径】将下降；但【阻碍端点与条件结构】迫使其在【两项不能同时保住的价值】之间选择。

## 3. 主题与故事问题的十元化

主题不是口号，也不是先写五维标签。主题来自整条十元动态链反复检验的中心问题。

### 主题问题转换

- “爱是否必须牺牲自我”：检查`n/nz`承载与停靠是否持续要求主体进入`nx`方向让位，或`x`自主边界是否被压缩；
- “身份来自什么”：检查`zn`主体意义、`x`现实掌握、`x并z`公开壳和`z`认可位置如何冲突；
- “为了安全放弃自由”：检查`n`保护是否真实克制`xz`，还是`x/xn/zx`以安全名义缩小选择权。

### 故事问题

“两人能否在一起”“能否逃离”“真相公开会怎样”必须写成可结算问题：

```text
哪个对象状态必须改变
哪个端点必须增强或退隐
谁会失去什么能力或关系位置
高潮用哪次不可逆选择回答
```

## 4. 人物设计的十元化

### 4.1 外部目标

赢比赛、找到人、复仇、告白、逃走和保住职位只是动作目标。需继续问：

- 目标对象由谁掌握`x`；
- 成功需要哪个认可位置`z`；
- 哪个流程`xn`必须完成；
- 能否借既有通道`nx`；
- 是否需要公开决定`zx`；
- 失败是否进入`xz`临界；
- 目标与`zn/n/nz`关系是否冲突。

### 4.2 内在需求

接受失去、建立边界、停止控制、允许依赖和承担责任，需要改写为端点变化：

- 建立边界：`x`自主掌握真实增加；
- 停止控制：`x/zx/xn`对他人选择的覆盖下降；
- 允许依赖：进入真实`n`承载，但不把方向外包为`nx`；
- 接受失去：`nz`不再被`x`强制维持，或承认`xz`窗口已关闭；
- 承担责任：代价不再转移，`zx`行动与`nx`承担重新补位。

### 4.3 恐惧

恐惧只说明人物会优先保护哪个端点，不能直接成为节点。

### 4.4 错误信念

错误信念是人物对十元关系的错误解释：

- “只有有用才值得被爱”：把`z/xn`成就误当`n/nz`接收；
- “任何依赖都会背叛”：把所有`n`承载误判为`nx`方向让位或`x`控制；
- “强者不能示弱”：把`zx/x`公开权能误当`zn`主体资格；
- “知道真相就会恢复”：把`z`确认误当`n/nz/zn`自动修复。

角色弧要让现实逐轮证明这种等同关系错误。

### 4.5 秘密

秘密是信息对象：

- 谁实际掌握`x`；
- 谁拥有公开接口`x并z`；
- 谁能确认`z`；
- 隐瞒怎样改变`n`信任和`nz`回返；
- 公开是否触发`zx`处置或`xz`临界。

### 4.6 矛盾

“想被看见又怕暴露”等矛盾必须拆成两个端点不能同时维持：

- 想获得`z`认可，但怕失去`x`边界；
- 想建立`n/nz`关系，但怕进入`nx`让位；
- 想维护`zn`意义，却依赖`xn/x并z`不正义结构；
- 想公开显权`zx`，却受长期结构`xn`克制。

## 5. 心理转行为的十元化

原“害怕被抛弃→确认、控制”等表必须继续结算：

| 心理 | 表层行为 | 主十元候选 | 结果需验证 |
|---|---|---|---|
| 害怕被抛弃 | 确认、测试、控制 | nz/x/nx | 回返证据、退出权和方向位置 |
| 羞耻 | 隐藏、攻击揭露者 | x/z/zx | 信息掌握、认可归因和公开权能 |
| 嫉妒 | 比较、争夺注意 | z/x | 认可主体是否被门控或转移 |
| 内疚 | 赔偿、保护、自罚 | nx/n/zn | 代价承担、真实接收和意义修复 |
| 权力欲 | 规则、资源、依赖 | x/xn/zx | 掌握、流程覆盖和选择权下降 |
| 依恋 | 靠近、等待、仪式 | nz/n/x | 共同时间、自愿回返和边界 |

同一心理产生相反行为，说明心理不是十元定义。必须由身份、资源、关系和回应判定结果。

## 6. 人物关系的十元化

原五变量扩展为七变量，并与端点连接：

```yaml
信任:
权力差:
情感距离:
依赖度:
债务:
信息差:
关系定义权:
```

### 变量与十元

- 权力差：检查`x/zx/xn/x并z`由谁占据；
- 情感距离：检查`n/nz/x`边界；
- 依赖度：区分`n`互相承载和`nx`方向外包；
- 债务：检查`nx/x/zx`承担与控制；
- 信息差：检查信息对象`x`及认可`z`；
- 关系定义权：检查`x/x并z/z`；
- 信任：不是独立十元，但决定`n/nz`能否运行。

每场至少改变一个变量，并重新判断端点。

## 7. 冲突的十元化

冲突不是吵架，而是两个端点、对象状态或行动结果不能同时成立。

### 7.1 外部冲突

- 人物对人物：两个主体争夺`x/z/zx/n/nz`等关系位置；
- 人物对制度：`zn`主体意义、`x`自主边界与`xn/x并z`结构冲突；
- 人物对自然：`n`承载能否克制`xz`危险；
- 人物对资源：谁掌握`x`，谁通过`nx`借力；
- 人物对时间：`xn`过程和`z`节点是否形成最后窗口。

### 7.2 内部冲突

人物内部的两个价值不能同时保住，例如`zn`意义与`z`认可、`x`自主与`nz`停靠、`n`保护与`zx`显权。

### 7.3 关系冲突

双方都想维持关系，但要求的关系机制不同：一方要`n`互相承载，另一方要`x`控制；一方要`nz`停靠，另一方仍要保留`x`退出权。

### 7.4 冲突升级

```text
对象轻微受限
→ 主十元策略试行
→ 对方回应造成偏差
→ 代价使条件十元增强
→ 关系候选启动
→ 两项价值不能同时保住
→ 不可逆选择
→ 结果十元重分配
```

升级不是声音更大，而是体量、顺序、第三方卷入或未来选项损失增加。

## 8. 场景结构的C模式

```yaml
场景前对象状态:
场景前关系七变量:
人物A主十元:
人物B主十元:
场景目标:
触发器:
条件十元:
A第一策略:
B独立回应:
候选关系:
正本状态:
启动机制:
被改变变量:
A升级/修正/撤回:
不可同时保住的两项:
最终选择:
即时收益:
即时/延迟/转移代价:
结果十元:
对象状态变化:
关系变量变化:
下一场必要性:
五维显影:
```

### 四类场景结果的十元理解

- 得到目标但付代价：目标端点上升，另一端点或关系变量下降；
- 没得到目标但获信息：`x/z`信息状态改变，下一轮策略重分配；
- 得到错误目标：表面`z/x`成功，但`n/nz/zn`或安全路径恶化；
- 彻底失败：旧主十元策略失效，被迫换端点或进入更高`xz`体量。

## 9. 序列、单话与长篇的十元化

### 9.1 序列

3至8场围绕一个阶段端点：

```text
端点提出
→ 旧策略试行
→ 对方回应
→ 关系候选启动
→ 代价复利
→ 端点转位
→ 阶段结算
```

### 9.2 单话

1. 恢复上话代价；
2. 提出本话对象与目标端点；
3. 第一次策略；
4. 回应造成偏差；
5. 第二策略或升级；
6. 选择与局部结算；
7. 端点重分配；
8. 话尾钩子来自新条件。

### 9.3 长篇三线

- 情节线：对象状态和外部目标；
- 关系线：七变量和十元端点；
- 主题线：五维中心问题如何被每次选择检验。

长篇不能用一条线替代另一条。打赢敌人不自动完成人物本体变化。

## 10. 短篇结构的十元化

短篇围绕一个不可逆端点变化：

```text
常态端点平衡
→ 裂缝暴露
→ 触发器
→ 主角使用惯常十元策略
→ 现实回应证明真正问题
→ 关键生克补或端点转位
→ 一次选择
→ 五维余波
```

### 短篇错误

- 世界观说明过多：对象尚未进入关系；
- 突然死亡：只有`xz`气氛，没有机制和前置体量；
- 角色无选择：人物只是`nx`被动推进，却未被有意识设计；
- 结尾解释主题：动态链没有自行显影五维。

## 11. 类型故事的十元入口

### 爱情

核心不是相遇，而是`n/nz/x/nx`之间的承载、停靠、边界和方向问题。

### 动作

核心是`x/zx/xn/xz/nx`如何通过目标物、空间、流程、风险和代价运行。动作不等于`zx`。

### 悬疑

核心是信息对象的`x`掌握、`z`确认、`xn`调查流程和`x并z`证据接口。

### 恐怖

核心是`n`安全承载是否失效、`xn`规则是否持续制造`xz`风险，以及主体`zn`是否被临界压力改写。

### SF

差异规则必须改变`x/xn/x并z/n/nx/zx`等社会端点，而不是只换名词。

## 12. 信息、悬念与伏笔的十元化

### 信息差

- 读者多于角色：读者掌握信息对象，角色进入`xz`候选；
- 读者少于角色：角色或作者控制信息`x`；
- 同步：认知流程`xn`与确认节点`z`同行；
- 不同角色掌握不同信息：争夺解释权、认可和行动权限。

### 伏笔

伏笔必须：

1. 首次出现有当前对象功能；
2. 被某主体看见、忽略或控制；
3. 经过时间结构`xn`保存；
4. 回收形成`z`确认或对象转义；
5. 改变后续关系和端点。

“之前出现过”不自动等于有效`xn/z`。

## 13. 改编的十元化

改编保留的不是句子，而是：

- 核心对象；
- 主要端点；
- 关键关系机制；
- 体量与顺序；
- 不可逆选择；
- 五维中心问题。

媒介变化后，可用分镜、动作、空间和声音重新显影，但不能用表现替代机制。

## 14. 修改流程的十元化

### 第一轮：对象与结构

检查对象状态、目标端点、阻碍端点和每轮结算。

### 第二轮：人物

检查行为是否来自主十元、恐惧、信息和权限。

### 第三轮：关系

检查七变量是否真实变化，生克补是否有机制。

### 第四轮：视觉

检查十元作用是否被动作、空间、镜头和声音显影，而不是靠说明。

### 第五轮：节奏

检查体量、顺序、停顿、重复和节点是否支持动态链。

### 第六轮：五维

只在整条链后判断时间、本体、空间、因果、命运显影等级。

## 16. 五维归纳

- 时间：过程、重复、等待和确认节点；
- 本体：内部意义和现实掌握的冲突与互补；
- 空间：身份壳和真实承载是否一致；
- 因果：公开行动与代价归属怎样循环；
- 命运：临界路径与关系回返如何决定结局。

## 17. 误判红线

- 事件多不等于动态链；
- 主角主动不等于`zx`；
- 目标明确不等于`z`；
- 长期训练不自动证明`xn`关系；
- 家庭、团队和恋爱不自动是`n`；
- 悲伤结局不自动是`xz`；
- 回家不自动是`nz`；
- 角色成长不自动是`zn`；
- 主题词出现不等于五维主主题；
- 生克补不能由结局倒推。

## 18. 全量十元化课程作业

1. 把一个普通前提改写为十元化前提；
2. 为四个错误信念写“错误十元等同关系”；
3. 写8个场景，每场改变一个端点和一个关系变量；
4. 为同一冲突分别设计`xn克zx`、`zx克n`和`x克z`结构；
5. 写一个`n克xz`短篇和一个假保护反例；
6. 为爱情、动作、悬疑、恐怖各写一条十元动态链；
7. 将一个伏笔写成对象状态—保存流程—确认节点—关系变化；
8. 对一篇旧剧本做六轮R6修改；
9. 完成一话Webtoon并提交十元场景结算表；
10. 用五维总结整部作品，但注明每个主题的链条证据。
