# 故事写作知识体系

## 1. 故事不是事件清单

故事的最低结构是：

```text
某个具体人物
因为某种缺失或欲望
采取行动
遭遇阻力和代价
被迫作出选择
使人物、关系或世界发生不可逆变化
```

只发生很多事，不等于故事。新闻联播每天事件很多，也不会自动变成角色连载。

## 2. 前提、主题与故事问题

### 前提

一句话说明：谁、想要什么、被什么阻碍、失败会失去什么。

模板：

> 当【触发事件】发生后，【主角】必须【目标】，否则【代价】；但【主要阻力】迫使他／她面对【内在矛盾】。

### 主题

主题不是口号，而是作品持续检验的问题。

例如：

- 爱是否必须以牺牲自我为代价？
- 身份来自记忆、身体还是他人的承认？
- 为了安全放弃自由是否值得？

### 故事问题

读者持续追问的具体问题：

- 两人能否在一起？
- 凶手是谁？
- 主角能否逃离？
- 真相公开后关系会怎样？

## 3. 人物设计

### 外部目标

人物能够明确执行的事情：赢得比赛、找到人、复仇、告白、逃走、保住职位。

### 内在需求

人物真正需要学习或承认的东西：接受失去、建立边界、停止控制、允许依赖、承担责任。

### 恐惧

人物最不愿面对的损失。恐惧决定其回避行为和防御方式。

### 错误信念

人物对自己、他人或世界持有的错误判断，例如：

- 只有有用才值得被爱；
- 任何依赖都会导致背叛；
- 强者不能示弱；
- 只要知道真相，一切就会恢复。

### 秘密

秘密制造信息差，并改变人物的行动成本。

### 矛盾

人物应同时具有相互拉扯的倾向：

- 想被看见，又害怕暴露；
- 想保护他人，又需要控制他人；
- 崇尚正义，却依赖不正义制度获利。

## 4. 角色心理转成行为

禁止只写“她很孤独”“他很自卑”。必须转成可观察行为。

| 心理 | 可能行为 |
|---|---|
| 害怕被抛弃 | 反复确认、提前离开、测试忠诚、控制联络频率 |
| 羞耻 | 隐藏、攻击揭露者、转移话题、过度补偿 |
| 嫉妒 | 比较、贬低、模仿、争夺注意力 |
| 内疚 | 赔偿、回避、过度保护、自我惩罚 |
| 权力欲 | 决定规则、控制资源、制造依赖、惩罚越界 |
| 依恋 | 靠近、等待、保存物品、重复共同仪式 |

同一种心理可以产生相反行为，具体由身份、能力、关系和情境决定。

## 5. 人物关系

关系不是“朋友／恋人／敌人”的静态标签，而是五个变量：

1. 谁需要谁；
2. 谁掌握资源；
3. 谁知道更多；
4. 谁更害怕失去；
5. 谁有权定义关系。

### 关系变化单位

每个重要场景至少改变一项：

- 信任增加或下降；
- 权力转移；
- 距离接近或疏远；
- 共同秘密形成或暴露；
- 债务产生或偿还；
- 身份认知被重写。

## 6. 冲突

冲突不是吵架，而是两个行动不能同时成功。

### 外部冲突

人物对人物、制度、自然、资源、时间。

### 内部冲突

人物的两种价值或欲望不能同时满足。

### 关系冲突

双方都想维持关系，却对关系的形式、边界和未来要求不同。

### 冲突升级

```text
轻微阻碍
→ 计划受挫
→ 代价出现
→ 新信息改变判断
→ 必须牺牲某物
→ 不可逆选择
```

## 7. 场景结构

每个场景填写：

- 进入场景前，人物想得到什么；
- 谁或什么阻止他；
- 人物采用什么策略；
- 策略如何升级；
- 出现什么新信息；
- 场景结果是什么；
- 人物关系或价值如何改变；
- 下一场为什么必须发生。

### 场景四类结果

- 得到目标，但付出意外代价；
- 没得到目标，却发现更重要信息；
- 得到错误目标，局势变坏；
- 彻底失败，被迫更换行动方向。

纯粹顺利完成任务通常缺少戏剧价值，除非顺利本身隐藏陷阱。

## 8. 序列、话与长篇

### 序列

由3至8个场景组成，围绕一个阶段目标。结尾必须改变局势。

### 单话

Webtoon单话通常包含：

1. 快速恢复上下文；
2. 本话目标或问题；
3. 2至4次升级；
4. 局部结果；
5. 新问题或话尾钩子。

### 长篇

至少管理三条线：

- 情节线：外部目标如何推进；
- 关系线：人物之间如何改变；
- 主题线：每次选择如何检验核心问题。

## 9. 短篇结构

短篇容量有限，应围绕一个不可逆变化。

建议结构：

```text
常态中的裂缝
→ 触发事件
→ 主角采取行动
→ 行动暴露真正问题
→ 一次关键选择
→ 结果与余波
```

短篇常见错误：

- 世界观讲了六页，人物还没开始做事；
- 结尾靠突然死亡制造重量；
- 角色没有选择，只被情节拖走；
- 最后一页解释主题，仿佛读者是被临时抓来的陪审员。

## 10. 类型故事

### 爱情

核心不是“相遇”，而是关系边界和亲密风险。

对象库：身份差、旧关系、家庭、工作、秘密、竞争者。

行为库：靠近、试探、误读、照顾、拒绝、隐瞒、嫉妒、告白、分离、修复。

### 动作

核心是明确目标、空间阻碍、能力差和代价。

行为库：追逐、潜入、防守、营救、夺取、撤退、牺牲、反制。

### 悬疑

核心是信息分配。

- 读者知道多少；
- 主角知道多少；
- 犯人知道多少；
- 每条线索能支持几种解释；
- 揭示是否重新解释旧场景。

### 恐怖

核心是安全规则逐步失效。

```text
异常迹象
→ 否认
→ 规则被确认
→ 逃避策略失败
→ 身份或空间被侵入
→ 必须面对无法承受的真相
```

### SF

核心不是科技名词，而是规则改变后的社会和人物后果。

步骤：

1. 设置一个差异规则；
2. 推演它改变哪些制度和日常行为；
3. 找到最大受益者和最大受害者；
4. 让人物关系承担规则冲突。

## 11. 信息、悬念与伏笔

### 信息差

- 读者多于角色：产生担忧；
- 读者少于角色：产生好奇；
- 读者与角色同步：产生沉浸；
- 不同角色掌握不同信息：产生关系冲突。

### 伏笔

有效伏笔必须：

- 首次出现有当前场景功能；
- 回收时产生新理解；
- 不应只靠作者事后宣称“你看这里有个杯子”。

## 12. 改编

改编不是逐句搬运，而是保留核心关系与变化，重建媒介表达。

检查：

- 原作最重要的体验是什么；
- 哪些内容只能靠文字内心完成；
- 漫画能用表情、动作、空间和画格替代什么；
- 哪些人物或事件应合并；
- 一话的视觉高潮在哪里。

## 13. 修改流程

### 第一轮：结构

检查目标、冲突、转折、高潮、结局。

### 第二轮：人物

检查每个行动是否符合欲望、恐惧和信息。

### 第三轮：关系

检查场景是否改变关系，而不是循环原地聊天。

### 第四轮：视觉化

删除能由画面表达的说明文字。

### 第五轮：节奏

压缩重复信息，扩大关键反应和选择。

## 15. 与十元动态链的连接

每个场景可记录：

```text
起始关系
→ 触发行为
→ 生/克/补变化
→ 体量变化
→ 新关系状态
```

十元用于比较“感觉关系和主题变化”，本文件用于保证人物、事件、行为与视觉叙事能够实际成立。两者互补，别让任何一种理论独自当皇帝，理论一当皇帝就开始制造冗官。
