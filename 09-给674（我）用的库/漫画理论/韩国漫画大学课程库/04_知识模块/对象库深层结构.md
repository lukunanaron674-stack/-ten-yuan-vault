# 对象库深层结构｜R6

## 1. 本章十元总判断

对象不是十元节点，十元也不是给对象贴永久标签。

对象只有在进入特定人物、关系和时间条件后，才显现某种十元作用：

```text
对象本体
＋当前状态
＋谁掌握
＋谁能使用
＋谁被排除
＋谁赋予意义
＋谁承担代价
＋对象如何变化
→ 主十元／条件十元／结果十元
```

同一把钥匙可以是`x`掌握、`x并z`身份接口、`xz`逃生窗口、`n`救援条件或`z`证据节点。对象名称不决定节点。

## 3. 八类对象的十元归整

### 3.1 人物对象

人物对象包括身份、身体、能力、资源、秘密、关系位置和当前状态。

十元检查：

- 身体和能力由谁掌握，检查`x`；
- 公开身份是否代表真实主体，检查`x并z/zn`；
- 谁能确认其资格，检查`z`；
- 谁接收其需要与负荷，检查`n`；
- 哪段共同时间形成回返，检查`nz`；
- 其长期策略如何运行，检查`xn`；
- 是否沿他人、制度或现状方向推进，检查`nx`；
- 是否公开决定他人条件，检查`zx`；
- 是否进入不可稳定停留的路线，检查`xz`。

人物不是“主角对象=zn”。主角资格也不能代替主体端点证据。

### 3.2 身份与角色对象

学生、继承人、军官、偶像、犯人、家长、导师和编辑主要提供：

- `x并z`：可识别的公开壳；
- `z`：资格被谁确认；
- `xn`：权利义务如何持续运行；
- `x`：身份附带哪些实际掌握；
- `nx`：人物可借身份和通道完成什么；
- `n`：身份是否伴随真实接收和内部位置；
- `zx`：身份是否允许公开改变他人条件。

同一人物的身份冲突必须写成两个对象权限不能同时履行，而不是只写“内心矛盾”。

**可调用关系：**

- `x生x并z`：实际掌握需要公共身份壳；
- `x并z生z`：身份壳使认可对象清晰；
- `n补x并z`：真实内部与公开壳互补；
- `x并z克nz`：身份壳污染关系证据并降低可信回返。

### 3.3 制度对象

学校、公司、军队、平台、家庭、宗教、法律和帮派不是单一对象，而是复合系统：

```text
规则与持续流程xn
＋内部承载n
＋公开界面x并z
＋资源和否决x
＋认可位置z
＋执行权能zx
＋借力通道nx
＋风险路线xz
＋意义核心zn
＋关系回返nz
```

制度卡必须分别记录谁制定、谁执行、谁能例外、谁获益、谁承担隐性成本、谁被接收和谁被推出。

### 3.4 空间对象

空间是行为权限分配器，而不是背景图。

```yaml
进入权:
退出权:
中心位置:
高低位置:
可见范围:
遮挡:
声音传播:
出入口:
安全路线:
危险路线:
内部承载n:
实际控制x:
公开规则壳x并z:
持续运行xn:
可返回证据nz:
```

房屋不天然是`n`，监狱不天然是`xz`，门不天然是`x`。必须看空间实际改变什么。

### 3.5 资源对象

钱、食物、时间、住房、医疗、机会、声誉、注意力、情报和情感劳动，重点检查：

- `x`：谁掌握和否决；
- `xn`：资源怎样积累、生产、分配和结算；
- `nx`：谁通过既有关系、信用或身份借力；
- `z`：声誉和资格由谁确认；
- `n`：资源是否用于真实接收和保护；
- `xz`：资源断裂是否压缩生存路线；
- `zx`：谁公开分配或剥夺。

资源少不自动是`xz`；资源多不自动是`x`。必须有明确控制和路线变化。

### 3.6 工具与道具对象

工具和道具可扩大能力、限制行动、证明身份、保存秘密、建立债务、触发记忆、转移权力或成为追逐目标。

功能与十元候选：

| 功能 | 十元候选 | 验证重点 |
|---|---|---|
| 扩大能力 | x/zx | 谁掌握，是否公开决定他人条件 |
| 限制行动 | x/xn/xz | 否决、流程覆盖或路线收窄 |
| 证明身份 | x并z/z | 公开对象和认可主体 |
| 保存秘密 | x/xn | 信息控制和跨时间保存 |
| 建立债务 | nx/x | 谁承担、谁获得控制 |
| 触发记忆 | z/nz/zn | 确认节点、共同时间、主体意义 |
| 转移权力 | x/zx/nx | 掌握、公开决定和借力位置 |

重要道具至少经历两次端点转义，不只是换象征意义。

### 3.7 信息对象

秘密、证据、误解、传闻、身份真相和规则说明必须记录：

- 谁知道；
- 谁以为知道；
- 谁能证明；
- 谁掌握传播和署名；
- 谁能让认可主体看见；
- 公开和隐瞒怎样改变关系；
- 哪个流程保存或查证；
- 被不同人物解释后产生什么行为。

重点关系：`x克z`、`x并z生z`、`xn补z`。

### 3.8 象征与身体对象

身体、服装、伤疤、称呼、徽章、照片和遗物同时具有物质、身份、关系和意义功能。

必须分开：

- 角色自己怎样理解：`zn/x`候选；
- 他人怎样理解：`z/x并z`；
- 社会怎样定义：`x并z/xn`；
- 关系怎样保存：`n/nz`；
- 场景变化后对象是否转义。

象征功能不能代替真实端点。例如遗物有情感不等于`nz`，除非它承载了共同时间和回返方向。

## 4. 对象六种状态的十元化

### 4.1 不可见

对象被隐藏、尚未出现或无公共接口。重点检查信息`x`和`x并z`缺失。

### 4.2 可见但不可得

对象有识别接口，但进入权被掌握者关闭。可能是`x`门控、`x克z`或`xz`路线问题。

### 4.3 可得但不可用

拥有与使用权分离。区分名义`x并z`和实际`x`，以及`xn`程序限制。

### 4.4 可用但有代价

使用会损伤资源、身份、关系或未来选项。记录代价落在`nx/n/xz/zn`的哪一端。

### 4.5 被争夺或共享

所有权、控制权、使用权和收益权分离。争夺不自动等于`zx`，共享也不自动等于`n`。

### 4.6 失效、损坏或转义

原端点退隐，新端点出现。例如武器失效后成为证据，`x/zx`功能下降，`x并z/z`功能上升。

## 5. 对象操作的十元化

| 对象操作 | 主问题 |
|---|---|
| 获取 | 获得的是实际`x`、身份`x并z`、认可`z`还是借用`nx` |
| 使用 | 谁保留最终否决，代价落给谁 |
| 隐藏 | 控制信息`x`怎样改变认可和关系 |
| 公开 | 形成`x并z/z`还是触发`zx`处置 |
| 赠送 | 转移实际掌握、制造债务还是建立关系 |
| 夺取 | `x/zx`是否真实增强 |
| 修复 | 恢复对象功能、承载、认可还是主体意义 |
| 销毁 | 哪个端点被克制，是否有替代对象 |
| 进入 | 获得的是身份壳还是内部位置 |
| 退出 | 自主`x`增强还是进入`xz`漂流 |

## 6. 对象关系词的十元语义

- owns：名义拥有，不一定等于`x`；
- controls：实际掌握与否决，优先检查`x`；
- grants_access：授予进入权，涉及`x/n/x并z`；
- blocks：阻止可能是`x/xn/zx/xz`，需看机制；
- depends_on：区分`n`互承载和`nx`方向让位；
- represents：公共代表，检查`x并z`；
- hides：信息控制`x`；
- proves：认可接口`x并z/z`；
- threatens：只有缩窄路线才形成`xz`；
- transforms_into：对象端点转义；
- costs：代价归属与`nx`；
- binds：关系绑定可能是`n/nz/x`；
- replaces：替代对象是否恢复端点功能；
- inherits：身份壳、掌握、流程和认可分别转移。

## 8. 从对象生成C动态链

```text
对象进入场景
→ 当前状态与控制权明确
→ 不同人物赋予不同意义
→ 主十元与条件十元显形
→ 人物尝试获取、使用、隐藏、公开或销毁
→ 他人依据自身欲望和权限回应
→ 所有权、使用权、信息权或进入权改变
→ 收益和代价结算
→ 对象转义为结果十元
→ 关系和局势进入下一轮
```

## 9. 示例：一封信的全量十元化

```yaml
对象: 一封未拆封的信
状态: 可见但仅特定人可读
名义拥有者: 收信人
实际控制者x: 截获信件的人
公开接口x并z: 信封、署名、邮戳
认可节点z: 真伪和作者身份被确认
持续流程xn: 邮递、保管、查证
内部关系n: 信中内容是否允许某人进入真实关系
回返证据nz: 旧共同时间是否因此重新成立
借力nx: 通过邮差、档案或第三人转交
公开权能zx: 谁决定公开、惩罚或处置
临界xz: 信被烧毁前最后阅读窗口
主体意义zn: 内容是否重新定义人物选择
```

可能关系：

- 截获者关闭信件进入认可主体的通道，可检查`x克z`；
- 信封和署名提供清晰归因接口，可检查`x并z生z`；
- 信件被送入保护范围并免于销毁，若真实降低临界风险，可检查`n克xz`。

## 10. 对象库深度检查R6

一个对象入库前必须回答：

1. 谁需要；
2. 谁名义拥有；
3. 谁实际控制和否决；
4. 谁能使用；
5. 谁被排除；
6. 谁赋予主体意义；
7. 谁能确认其身份或价值；
8. 哪个流程维持对象；
9. 哪个关系承载对象；
10. 哪条路线因对象改变；
11. 对象至少两次端点转义；
12. 哪个已锁定关系可调用；
13. 哪些第三因素可能伪装关系；
14. 拿掉对象后动态链是否仍成立；
15. 反向改变对象状态后结果是否反转。

## 11. 五维归纳

- 时间：对象怎样被保存、积累、等待和确认；
- 本体：对象如何承载主体意义与现实掌握；
- 空间：对象的公共界面和内部承载；
- 因果：对象怎样触发行动和代价转移；
- 命运：对象怎样改变临界路线与回返方向。

## 12. 误判红线

- 钥匙不天然是`x`；
- 门不天然是`x`；
- 家不天然是`n/nz`；
- 武器不天然是`zx`；
- 证据不天然是`z`；
- 制服不天然是`x并z`已成立；
- 规则书不天然是`xn`；
- 遗物不天然是`nz`；
- 危险道具不天然是`xz`；
- 信仰物不天然是`zn`；
- 对象的第一功能不能固定它后续所有十元属性。

## 13. 全量十元化训练

1. 为一个职业建立30个R6对象卡；
2. 同一道具分别写成`x/x并z/z/n/nz/xn/nx/zx/xz/zn`十种候选功能；
3. 为一个空间写安全、权力、秘密、逃生四种状态，说明端点变化；
4. 为一条制度规则建立复合十元对象图；
5. 写5个从对象状态变化出发的场景；
6. 做一个`x克z`信息对象案例；
7. 做一个`n克xz`空间对象案例和反例；
8. 写一个道具三次端点转义链；
9. 做对象拿掉测试和替代品测试；
10. 用五维归纳对象在整部作品中的最终功能。
