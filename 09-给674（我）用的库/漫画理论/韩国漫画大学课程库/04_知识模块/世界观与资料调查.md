# 世界观与资料调查

## 1. 世界观不是设定百科

世界观的作用是限制和推动人物行为。

一个有效规则必须回答：

- 谁从中获益；
- 谁为它付出代价；
- 谁能绕过规则；
- 规则如何进入日常生活；
- 违反规则会发生什么；
- 它怎样改变人物关系。

如果一条设定既不影响行为，也不影响画面，它目前只是作者私人收藏品。

## 2. 世界观六层

### 自然层

地理、气候、资源、生物、灾害、昼夜和季节。

### 技术／魔法层

能力来源、使用条件、成本、上限、失败方式、垄断者。

### 制度层

法律、阶级、学校、军队、宗教、企业、平台和家庭制度。

### 经济层

谁生产、谁分配、什么稀缺、什么能交换、贫富如何形成。

### 文化层

礼仪、禁忌、服装、饮食、节庆、语言、审美和死亡观。

### 日常层

人物怎样上班、吃饭、恋爱、出行、治病、获得信息和处理垃圾。宏大世界最终都得落到谁洗碗，文明不会因为设定宏伟就免除家务。

## 3. 资料调查流程

```text
提出创作问题
→ 建立关键词与来源清单
→ 找一手资料
→ 记录事实与出处
→ 访谈或观察
→ 建立对象卡和行为流程
→ 标注未知与争议
→ 只选与故事有关的材料
→ 转成场景和动作
```

## 4. 来源等级

### 一级

- 法律法规；
- 官方档案；
- 技术标准；
- 当事人记录；
- 原始历史材料；
- 现场观察。

### 二级

- 学术论文；
- 专业教材；
- 权威调查报告；
- 专业媒体采访。

### 三级

- 新闻综述；
- 通俗书；
- 纪录片；
- 从业者博客。

### 表现参考

- 电影、电视剧、漫画、游戏。

表现参考可以教你“别人怎么画”，不能自动证明现实就是这样。

## 5. 职业调查

记录：

- 工作目标；
- 日常流程；
- 常用工具；
- 行业术语；
- 空间布局；
- 权力关系；
- 新手最常犯的错；
- 外行最常误解的事；
- 风险、压力和伦理；
- 典型冲突；
- 身体动作和声音。

## 6. 访谈提纲

### 开放问题

- 一天通常从什么开始？
- 哪一步最费时间？
- 哪些事情外行看不见？
- 什么时候必须违反常规？
- 哪类同事最难合作？
- 出错后谁承担责任？
- 这个职业怎样改变你的身体和关系？

### 追问

- 能举一个具体例子吗？
- 当时你先做了什么？
- 谁在场？
- 空间是什么样？
- 你为什么没有选择另一种做法？

## 7. 历史人物改编

分成三栏：

| 史料确认 | 合理推断 | 创作虚构 |
|---|---|---|
| 日期、地点、公开事件 | 可能的情绪和动机 | 对话、合并角色、具体场景 |

改编应保留：

- 时代约束；
- 身份与资源；
- 已知关键事件；
- 真实选择的代价。

不得让现代价值观像穿越客服一样替历史人物解释一切。

## 8. 世界规则表

```yaml
规则名:

```

## 9. 场景对象库

每个重要场景记录：

- 空间用途；
- 出入口；
- 光源；
- 声音；
- 可藏匿区域；
- 权力位置；
- 常见人物；
- 常见行为；
- 道具；
- 时间变化；
- 情绪与主题功能。

## 10. 道具对象库

道具可承担：

- 工具；
- 身份标志；
- 关系纪念；
- 秘密载体；
- 权力资源；
- 伏笔；
- 行动障碍；
- 主题象征。

有效道具至少在两个场景中有不同功能。

## 11. 世界观压力测试

1. 普通人如何生活？
2. 穷人如何绕过规则？
3. 权贵如何利用规则？
4. 儿童如何理解规则？
5. 黑市和地下组织为何存在？
6. 医疗、教育、交通如何运作？
7. 规则突然失效一天会怎样？
8. 主角的欲望为什么必须在这个世界发生？

## 12. 从资料到故事

资料不直接等于剧情，应转成：

```text
事实
→ 对人物意味着什么
→ 人物想做什么
→ 制度或空间如何阻止
→ 产生什么选择和关系变化
```

## 13. 课程作业

- 一个职业的30张对象卡；
- 一次真实采访与动作流程图；
- 一个历史人物的史实／推断／虚构对照；
- 一座城市的交通、住房、食物与阶级图；
- 一条魔法规则的经济和家庭后果；
- 用同一场景写白天、夜晚、灾难后三种版本；
- 将资料包压缩成8页短篇，正文不得直接引用资料说明。
