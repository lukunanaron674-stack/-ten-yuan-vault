# 知识模块说明

## 1. 性质

本文件夹中的知识模块是根据多所韩国院校公开课程、公开教材线索和通用创作理论重建的学习体系。

它们是：

- 对课程目标的知识展开；
- 用于自学、训练、创作和案例拆解的工具；
- 对象库、行为库与十元动态链的接口。

它们不是：

- 某一所韩国大学的官方讲义；
- 某位教师的逐周课程内容；
- 未公开校内材料的转录；
- 能替代版权教材全文的“万能摘要”。

## 3. 每个模块的最低结构

1. 学习目标；
2. 核心知识；
3. 对象库；
4. 行为或操作库；
5. 常见错误；
6. 练习；
7. 与学校课程的对应；
8. 与十元系统的接口；
9. 证据与参考等级。

## 4. 使用顺序

```text
学校档案确认“学校教什么”
→ 知识模块解释“这门课需要懂什么”
→ 教材书目决定“从哪里深入学”
→ 训练文件规定“怎样练”
→ 漫画案例验证“作品里怎样发生”
→ 审计记录检查“有没有乱说或漏掉”
```

## 5. 更新边界

新增知识时必须区分：

- `课程事实`：必须有A/B级来源；
- `教师与教材事实`：使用C/D级来源；
- `本库重建`：明确标记为重建知识；
- `个人理论接口`：说明来自十元体系，不归因于韩国学校。
