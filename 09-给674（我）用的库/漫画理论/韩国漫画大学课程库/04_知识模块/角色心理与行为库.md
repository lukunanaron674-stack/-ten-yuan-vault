# 角色心理与行为库

## 1. 基本原则

角色不是“高冷御姐”“温柔男主”这样的商品标签。角色必须拥有：

```text
身份位置
＋欲望
＋恐惧
＋错误信念
＋能力与资源
＋关系需求
＋稳定行为倾向
＋在压力下的变化
```

课程目标是把抽象心理转成读者能看到的行动。

## 3. 欲望类型

- 生存：活下去、获得食物、住所、安全；
- 归属：被接纳、拥有家庭、进入群体；
- 亲密：被理解、被选择、维持陪伴；
- 权力：控制资源、规则与他人的选择；
- 成就：胜利、认可、作品、地位；
- 自由：摆脱控制、身份或环境；
- 真相：找到原因、记忆、凶手、历史；
- 修复：偿还、道歉、复仇、恢复秩序；
- 超越：创造、信仰、牺牲、自我实现。

同一人物通常同时有多个欲望，但场景中只能有一个主要行动目标。

## 4. 恐惧到行为

| 恐惧 | 防御行为 | 极端行为 |
|---|---|---|
| 被抛弃 | 讨好、确认、测试关系 | 控制、威胁、自我伤害式牺牲 |
| 被羞辱 | 隐藏、回避、装作不在意 | 报复、贬低他人、否认事实 |
| 失去控制 | 计划、检查、制定规则 | 监视、封锁资源、惩罚越界 |
| 无能 | 过度准备、拒绝帮助 | 造假、抢功、攻击竞争者 |
| 亲密 | 保持距离、玩笑化 | 突然断联、先背叛、物化关系 |
| 死亡 | 保守、求医、储备 | 不择手段生存、迷信、控制后代 |
| 真相 | 转移话题、合理化 | 销毁证据、伤害知情者 |

注意：这是行为可能性，不是心理诊断表。

## 5. 关系中的行为维度

### 接近

- 主动寻找；
- 增加共同时间；
- 分享秘密；
- 模仿对方；
- 允许进入私人空间。

### 回避

- 缩短对话；
- 推迟见面；
- 转移视线；
- 通过工作或他人建立缓冲；
- 提前离开。

### 控制

- 决定规则；
- 掌握钱、信息、空间或机会；
- 将帮助变成债务；
- 通过奖惩塑造行为；
- 定义对方身份。

### 保护

- 承担风险；
- 隐瞒危险；
- 替对方说话；
- 提供资源；
- 尊重或越过对方边界。

保护可能生出亲密，也可能变成控制。区别在于是否保留对方选择权。

### 交换

- 利益交换；
- 情绪劳动；
- 信息交换；
- 身份背书；
- 承诺与债务。

### 攻击

- 身体伤害；
- 羞辱；
- 排斥；
- 剥夺资源；
- 暴露秘密；
- 破坏关系网络。

## 6. 压力测试

把同一角色放进以下场景：

1. 得到渴望已久的机会，但必须背叛朋友；
2. 被最看不起的人救下；
3. 秘密被误解，而解释会伤害第三人；
4. 对手提出完全合理的条件；
5. 失去身份、财富或能力；
6. 被迫照顾自己讨厌的人；
7. 发现自己的成功来自他人的牺牲；
8. 被允许离开，但有人真诚等待。

记录：第一反应、公开行为、隐藏行为、后悔点、关系结果。

## 7. 角色弧

### 正向弧

错误信念被现实反复击穿，人物最终作出新的选择。

### 负向弧

人物坚持错误信念，并用越来越极端的手段维护它。

### 平直弧

人物自身核心信念相对稳定，但改变周围人或世界。

### 关系弧

两人从：

- 利用到信任；
- 崇拜到看见真实；
- 依赖到独立；
- 对抗到合作；
- 亲密到疏离；
- 误解到重新定义。

## 8. 群像功能

每个主要配角至少承担两种功能：

- 推动情节；
- 暴露主角不同侧面；
- 代表一种价值；
- 提供资源或阻碍；
- 形成关系压力；
- 承担类型功能；
- 见证变化。

只承担“负责搞笑”或“负责夸主角”的角色很容易变成有头像的家具。

## 9. 对话行为

对话的真实动作可能是：

- 请求；
- 拒绝；
- 试探；
- 诱导；
- 威胁；
- 安慰；
- 隐瞒；
- 交换；
- 定义关系；
- 争夺解释权。

写对话时先写动作，再写台词。

例：

```text
动作：试探对方是否知道秘密
台词：你昨天……是不是去过仓库？
```

## 10. 观察练习

- 每天记录5个真实动作，不猜心理；
- 为每个动作写3种可能动机；
- 观察同一人在上级、朋友、陌生人面前的行为差异；
- 记录谈话中的打断、停顿、距离和道具动作；
- 把一段现实对话改成无台词漫画。

## 12. 伦理边界

- 不随意给角色或真人贴医学诊断；
- 不把创伤当作自动增加深度的装饰；
- 不将控制、跟踪、强迫自动浪漫化；
- 反派也需要行动逻辑，但理解不等于美化；
- 真实采访要保护隐私并获得必要同意。
