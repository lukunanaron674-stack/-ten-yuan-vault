# 角色心理与行为库｜R6

## 1. 本章十元总判断

角色不是性格词集合，而是一个在不同对象、关系和压力下不断重新分配十元端点的运行系统。

角色最低结构升级为：

```text
身份位置与公开壳x并z
＋实际掌握与边界x
＋内部意义与主体资格zn
＋接收和依赖结构n
＋共同时间与回返证据nz
＋长期计划、规则与积累xn
＋认可位置z
＋沿既有方向借力nx
＋公开显权和决定zx
＋临界风险与退路xz
＋稳定行为策略
＋压力下端点转位
```

性格只说明“常见倾向”，十元化必须说明：人物在当前场景中究竟改变了什么对象和关系变量。

## 3. 欲望类型的十元化理解

### 3.1 生存

食物、住所、安全和身体完整首先是对象状态。

- 想掌握资源：`x`候选；
- 想进入真实保护范围：`n`候选；
- 安全路线正在缩窄：`xz`候选；
- 通过既有制度或他人关系获救：`nx`候选；
- 公开夺取或决定他人生存条件：`zx`候选。

生存欲不自动等于`xz`。必须先有临界路线、窗口或退路缩窄。

### 3.2 归属

被接纳、进入家庭和群体涉及：

- `n`：真实接收、内部位置、保护和持续承担；
- `x并z`：成员身份、制服、称呼和公开接口；
- `nz`：共同时间是否形成自愿回返；
- `z`：重要主体是否明确承认其成员资格。

“加入组织”可能只有`x并z`身份壳，没有`n`内部承载。

### 3.3 亲密

被理解、被选择、维持陪伴需要区分：

- `n`：双方是否真实接收对方的需要和负荷；
- `nz`：是否有共同时间、不愿结束和可返回证据；
- `x`：谁决定边界、靠近和退出；
- `nx`：谁把最终方向让给关系或对方；
- `xz`：分离是否进入最后窗口。

亲密动作不自动等于`n/nz`。一次拥抱、告白和陪伴都可能只是策略。

### 3.4 权力

控制资源、规则和他人选择必须拆开：

- `x`：实际掌握对象、资源、地盘和否决权；
- `zx`：主体权能公开显现并凌驾于他者；
- `xn`：通过规则、计划和流程持续组织；
- `x并z`：职位、名称和制度界面代表权力；
- `z`：获得重要认可位置。

大声、攻击和命令不自动等于`zx`；职位也不自动等于实际`x`。

### 3.5 成就

胜利、认可、作品和地位主要检查：

- `z`：谁认可谁、认可什么；
- `xn`：跨时间训练、作品和证据积累；
- `x并z`：作品、头衔、身份壳是否提供可识别接口；
- `x`：是否掌握作品、署名、发布和进入认可场景的通道。

可直接检查：`x并z生z`、`x克z`、`xn补z`。

### 3.6 自由

摆脱控制、身份或环境必须说明：

- 从谁的`x`掌握边界退出；
- 从哪个`x并z`身份壳脱离；
- 是否拒绝继续沿`nx`既有方向；
- 是否撤回对`xn`结构的维护资格；
- 退出是否导致`xz`风险上升。

“离开”不是固定十元。可能是`x`决断、`zn`撤回、`z`截断、`xz`逃离或`nx`顺从。

### 3.7 真相

找原因、记忆、凶手和历史涉及：

- 信息对象的控制权`x`；
- 公开界面和证据身份`x并z`；
- 确认节点`z`；
- 调查流程`xn`；
- 借线人、制度与关系推进`nx`；
- 揭示后的公开处置`zx`；
- 真相是否重写主体意义`zn`。

### 3.8 修复

偿还、道歉、复仇和恢复秩序要分清修复对象：

- 恢复内部承载：`n`；
- 恢复共同时间与回返：`nz`；
- 恢复主体资格和意义：`zn`；
- 恢复掌握边界和自主权：`x`；
- 恢复流程与秩序：`xn`；
- 恢复认可与归因：`z`。

“道歉”只是动作，不能自动证明修复。

### 3.9 超越

创造、信仰、牺牲和自我实现优先检查：

- `zn`是否形成不依赖外部奖惩的内部意义；
- `x`是否为该意义提供现实掌握落点；
- `zn补x`是否成立；
- 主体是否因此撤回对某个`xn`结构的维护资格，可检查`zn克xn`；
- 公开行动是否只是一时显权，不能反向自动证明`zx生zn`。

## 4. 恐惧到行为的十元化

恐惧不是节点，防御行为也不是节点。要观察恐惧怎样改变端点。

| 恐惧 | 常见策略 | 十元候选 | 必须验证的变量 |
|---|---|---|---|
| 被抛弃 | 讨好、测试、控制联络 | nz/n/x/nx | 回返证据、接收能力、退出权、方向让位 |
| 被羞辱 | 隐藏、攻击、否认 | z/x/zx/x并z | 认可位置、信息接口、公开权能 |
| 失控 | 计划、检查、封锁 | xn/x/zx | 流程覆盖、实际否决、他人选择权 |
| 无能 | 过度准备、抢功、造假 | xn/z/x/x并z | 证据积累、认可归因、署名与接口 |
| 亲密 | 保持距离、先背叛 | x/xz/nz | 边界、最后窗口、回返证据 |
| 死亡 | 储备、控制、求医 | x/n/xz/xn | 资源掌握、真实承载、路线收窄、持续维护 |
| 真相 | 销毁证据、伤害知情者 | x/zx/x并z | 信息掌握、公开处置、证据接口 |

### 例：害怕被抛弃

```text
关系中已有nz共同时间
→ 人物害怕失去回返位置
→ 通过x缩小对方退出权
→ 若控制边界增强并使自愿停靠失效
→ 可检查已锁定的x克nz
```

不能因为人物吃醋就写`x克nz`。

## 5. 关系行为六类的十元归整

### 5.1 接近

主动寻找、共享秘密、增加共同时间和允许进入私人空间，可能服务于：

- 建立`n`承载；
- 累积`nz`回返证据；
- 获取`x`掌握；
- 试图获得`z`认可；
- 通过`nx`借关系通道。

接近本身不是`n`。

### 5.2 回避

缩短对话、推迟见面、工作缓冲和提前离开可能：

- 保持`x`边界；
- 沿`nx`旧方向逃避选择；
- 进入`xz`危险路径；
- 保护`zn`主体意义；
- 暂停`n/nz`关系。

必须看回避后的选择权与关系变量。

### 5.3 控制

决定规则、掌握钱和信息、制造债务、奖惩和定义身份，需分层：

- 实际掌握：`x`；
- 公开显权：`zx`；
- 持续流程：`xn`；
- 身份壳：`x并z`；
- 认可门控：`x克z`候选；
- 接收断裂：`zx克n`候选；
- 停靠失效：`x克nz`候选。

“控制欲”形容词不足以证明任何关系。

### 5.4 保护

承担风险、隐瞒危险、提供资源和限制行动必须区分：

- 真实接收和保护：`n`；
- 替他人承担冲击：可能显现`n`或`nx`；
- 通过掌握资源保护：`x`；
- 公开处置威胁：`zx`；
- 剥夺被保护者选择：可能转为`x/zx`；
- 使危险可到达性下降：可检查`n克xz`。

保护与控制的十元分界是：对方是否仍有知情、选择、退出和回返空间。

### 5.5 交换

利益、信息、身份背书和承诺交换涉及：

- `x`对象和资源；
- `nx`既有通道与借力；
- `z`认可与背书；
- `x并z`身份接口；
- `n`关系内部承担；
- `xn`重复结算和信用结构。

交换不是固定`nx`。必须看谁保留最终方向。

### 5.6 攻击

身体伤害、羞辱、排斥、剥夺资源和破坏关系网络只是表层动作。

- 攻击资源掌握：检查`x`；
- 攻击认可归因：检查`x克z`；
- 公开决定成员资格：检查`zx克n`；
- 破坏关系回返：检查`x并z克nz`或`x克nz`条件；
- 压缩安全路线：检查`xz`端点；
- 迫使主体放弃意义：可观察`xz克zn`候选，但未锁定不得直接使用。

## 6. 压力测试的十元运行法

每个压力场景填写：

```yaml
场景前稳定主十元:
被威胁对象:
恐惧解释:
第一反应:
主十元是否维持:
条件十元:
实际行为:
对方独立回应:
收益与代价:
被改变变量:
结果十元:
端点是否转位:
候选关系:
正本状态:
五维显影:
```

原八个压力场景的十元任务：

1. 机会与背叛：`z/xn`成就和`n/nz`关系谁被牺牲；
2. 被轻视者救下：原`x/z`位置怎样被`n/nx`改写；
3. 解释会伤第三人：信息`x`、主体`zn`和承载`n`冲突；
4. 对手合理条件：`zx`冲突是否被`xn`结构克制；
5. 失去身份财富能力：`x并z/x`退隐后`zn`是否仍成立；
6. 照顾讨厌者：`n`是否真实运行，还是`nx`被迫延续；
7. 成功来自他人牺牲：`z`认可和`nx`代价如何重新归因；
8. 被允许离开但有人等待：`x`退出权与`nz`停靠是否形成`nz克x`条件。

## 7. 角色弧的十元化

### 7.1 正向弧

不是“变好”，而是旧端点和旧关系机制被现实反复证明失效，人物重新分配主十元。

```text
旧稳定策略
→ 多轮C运行
→ 同一代价复利
→ 旧关系被克制或失去补位
→ 人物作出新选择
→ 新主十元稳定
```

### 7.2 负向弧

人物通过更高体量维护旧端点：

```text
旧信念受威胁
→ 增强x/xn/zx等控制结构
→ 代价转移给他人
→ n/nz/zn等关系能力下降
→ 角色获得短期成功、长期崩坏
```

### 7.3 平直弧

人物自身`zn/x`核心相对稳定，通过行动改变他人的端点或世界结构。平直不代表无变化，变化发生在关系和环境。

### 7.4 关系弧

“利用到信任”“依赖到独立”等必须转换为七变量和十元端点：

- 利用→信任：资源`x`是否转化为真实`n`承载；
- 崇拜→真实：`z/x并z`公开形象是否退隐，`zn`主体是否被看见；
- 依赖→独立：`nx`方向让位是否减少，`x`自主边界是否恢复；
- 对抗→合作：`zx`公开冲突是否受到共同`xn/n`结构限制；
- 亲密→疏离：`nz/n`证据是否下降，退出`x`是否增强；
- 误解→重定义：信息和认可接口怎样重分配。

## 8. 群像功能的十元化

每个配角至少承担两个不同端点功能：

- 提供或控制对象`x`；
- 代表身份壳`x并z`；
- 提供认可`z`；
- 维持流程`xn`；
- 作为借力路径`nx`；
- 提供真实承载`n`；
- 保存回返证据`nz`；
- 迫使临界选择`xz`；
- 公开改变规则`zx`；
- 质问或保护主体意义`zn`。

配角不能只做主角的证人。必须有自己的欲望、端点和回应。

## 9. 对话行为的十元化

对话先写作用，不写节点：

| 对话动作 | 可能的十元作用 |
|---|---|
| 请求 | 争取`x`对象、`n`接收、`z`认可或`nx`通道 |
| 拒绝 | `x`边界、`z`截断、`zn`意义撤回 |
| 试探 | 信息掌握`x`、认可`z`和关系`n/nz`检测 |
| 诱导 | 让对方进入`nx`方向或接受某`xn`结构 |
| 威胁 | 压缩`xz`路线、展示`zx`权能或`x`否决 |
| 安慰 | 提供`n`承载或维护`nz`回返 |
| 隐瞒 | 控制信息`x`，也可能削弱`n`信任 |
| 交换 | `x/nx/z/x并z`多端点协商 |
| 定义关系 | 争夺`x`边界、`x并z`身份壳和`z`确认 |
| 解释权 | 掌握对象归因，检查`x克z` |

一句台词必须在回应后才能判断实际十元结果。

## 11. 伦理边界的十元理解

- 医学诊断不是十元节点；
- 创伤不能自动生成`xz/zn`；
- 控制、跟踪和强迫若减少选择权，应如实分析`x/zx/xn`作用，不因浪漫类型洗白；
- 理解反派机制不等于认可其`zn`；
- 采访隐私涉及信息`x`、身份壳`x并z`和主体资格`zn`；
- 角色牺牲若剥夺其方向决定，需检查`nx`而非自动赞美。

## 12. 五维归纳

- 时间：稳定策略怎样跨场景重复，何时被节点截断；
- 本体：人物内部意义与现实掌握是否互补；
- 空间：身份壳与真实承载是否一致；
- 因果：公开行动和代价承担如何相互补位；
- 命运：危险临界与回返关系怎样拉扯。

## 13. 误判红线

- 温柔不等于`n`；
- 依恋不等于`nz`；
- 强势不等于`zx`；
- 自律不等于`xn`；
- 高冷不等于`x`；
- 信念坚定不等于`zn`；
- 被关注不等于`z`；
- 顺从不必然是`nx`；
- 危险女性不等于`xz`；
- 制服身份不等于`x并z`已经代表真实内部；
- 心理词和人格母型不能替代端点、机制与变量。

## 14. 全量十元化课程作业

1. 为一个角色建立十元对象卡，区分稳定主十元与场景端点；
2. 为九类欲望各写一个同动机、不同十元结果的场景；
3. 同一“保护”行为分别写成`n`、`x`、`zx`和`nx`候选；
4. 为“害怕被抛弃”写`x克nz`成立例与不成立例；
5. 对一个角色做八场压力测试，记录端点转位；
6. 写一个`zn克xn`正向弧和一个控制升级负向弧；
7. 建立四人群像，每人至少承担两种独立十元功能；
8. 把一段对话拆成表层台词、真实行为、回应和结果十元；
9. 找一个“看似温柔但不是n”的误判案例；
10. 用五维总结整条角色弧，但不得从单场倒推主主题。
