# 角色心理与行为库｜R7 分层运行版

> 本章先建立角色心理与行为知识，再把经证据确认的场景结果送入十元分析。十元不是人格分类、心理诊断或角色器官清单。

## 0. 本章解决什么

角色设计与分析至少要回答四个不同问题：

1. **人物为什么这样理解局面？**——需要、价值、信念、自我叙事和关系预期。
2. **人物在这个场景具体做了什么？**——触发、判断、目标、权限、行为、对象。
3. **行为真实改变了什么？**——对方回应、收益、代价和唯一核心变量。
4. **多轮以后人物怎样改变？**——策略强化、反馈、断裂、转位、复发和角色弧。

十元只进入第三、第四问的后段，用于判断具体对象在具体阶段的关系位置和动态链。

## 1. 知识点位置总图

```text
心理基线
特质 / 需要 / 价值 / 信念 / 自我叙事 / 关系预期
        ↓ 提出行为预测，不直接生成十元
情境判断
触发器 / 风险 / 可选路线 / 人物如何解释局面
        ↓
行为事件
行动者 / 行为 / 对象 / 意图 / 权限 / 强度 / 可撤回性
        ↓
独立回应与代价
对方回应 / 系统回应 / 即时收益 / 延迟代价
        ↓
核心变量变化
初始状态 → 终态
        ↓ 可选路由
十元端点与直接关系边
        ↓
具体动态链图
主链 / 支路 / 汇合 / 反馈 / 搭桥 / 断裂 / 转位
        ↓ 多轮后验归纳
角色弧
```

### 1.1 三条硬规则

- 心理词只能提出假设，不能直接作为十元端点。
- 行为动作只能提供证据，不能直接等于生、克、补。
- 角色弧必须来自多轮行为事件和变量变化，不能写成“旧十元变成新十元”。

## 2. 角色心理层：必须分开的概念

| 层 | 含义 | 证据来源 | 常见误判 |
|---|---|---|---|
| 人格特质 | 跨多种情境相对稳定的倾向 | 多场景重复选择 | 一次勇敢就判勇敢型 |
| 当前情绪 | 短时状态，如恐惧、愤怒、羞耻 | 表情、身体、台词、行为变化 | 把情绪当稳定人格 |
| 核心需要 | 人物反复试图维持的基本状态 | 长期选择与代价 | 把故事任务当需要 |
| 价值 | 人物认为值得维护的原则和排序 | 无奖励时仍作出的选择 | 把口号当价值 |
| 信念 | 人物对自己、他人和世界的判断 | 预测、归因和选择 | 作者说明替代行为证据 |
| 自我叙事 | 人物怎样解释“我是谁、我为何如此” | 记忆选择、身份解释、羞耻与荣耀 | 等同客观事实 |
| 关系预期 | 人物预期别人会接纳、背叛、控制或离开 | 亲密场景中的测试与撤退 | 直接贴依恋标签 |
| 防御机制 | 人物避免承受某种心理内容的方式 | 否认、投射、合理化等反复模式 | 把任何隐瞒都叫防御 |
| 应对策略 | 面对压力时实际采用的方法 | 可观察行为与结果 | 把策略当人格本体 |
| 当前目标 | 本场想获得或阻止的具体结果 | 行为对象和终止条件 | 与深层需要混写 |
| 决策规则 | 人物在冲突中怎样排序选择 | 多次两难选择 | 用一句台词判定 |
| 习惯与冲动 | 自动重复或短时强烈趋向 | 时间、身体和重复性 | 等同价值或信念 |

### 2.1 不做临床诊断

本库用于角色创作和叙事分析，不凭少量情节给人物下医学诊断。需要使用临床概念时，应明确：作品证据、叙事功能、未知信息和替代解释。

## 3. 动机必须拆成四层

旧版把“生存、归属、亲密、权力、成就、自由、真相、修复、超越”并列为欲望类型，抽象层不一致。R7改为：

```text
需要层：人物为什么不能长期失去它
目标状态层：人物此刻具体想让什么成立
故事任务层：人物正在完成什么外部任务
手段层：人物用什么方式推进
```

### 3.1 需要层

可从以下方向提出假设，但必须由多场选择证明：

- 安全与生存；
- 接纳、归属与亲密；
- 自主、边界与退出权；
- 能力、效能与尊严；
- 秩序、可预测性与控制感；
- 意义、原则与自我一致；
- 探索、理解与真实感。

### 3.2 目标状态层

必须写成可观察结果，例如：

- 获得某份工作；
- 让某人留下；
- 拿回账户控制权；
- 被某位导师确认能力；
- 查明某份证据的来源；
- 保住一个人的安全路线。

“想要自由”“想被爱”太宽，必须继续落到对象和可观察终态。

### 3.3 故事任务层

寻找真相、逃离、复仇、修复、夺权、救援、竞赛和创作，是任务，不自动等于深层需要。

### 3.4 手段层

接近、回避、控制、保护、交换、攻击、证明、隐瞒、求助和服从，是推进方式，不自动等于人物真正想要的东西。

## 4. 角色基线卡：不再填十元全家桶

旧版“角色最低结构”要求为人物填满十个十元位置，容易制造空洞标签。R7只记录有证据的心理基线和当前活跃对象。

```yaml
姓名:
时代与社会环境:
公开身份与社会位置:
当前主要关系:
稳定特质证据:
核心需要假设:
核心价值与排序:
自我叙事:
关于他人的主要信念:
关系预期:
常用防御:
常用应对策略:
决策规则:
不可承受代价:
可用资源与真实权限:
缺失资源与受限路线:
当前长期目标:
当前活跃对象:
证据不足项:
禁止误判:
```

### 4.1 取消“稳定主十元”

不再写：

```text
这个角色本质是x
这个角色的主十元是zn
压力下变成zx
```

改写为：

```text
稳定心理策略：人物长期怎样保护价值、避免痛苦、处理关系。
当前主导关系位置：在这个对象、主体和阶段中，哪一个经审核的十元端点正在运行。
```

稳定的是策略倾向；十元端点必须逐场、逐对象重判。

## 5. 行为事件是最小分析单位

接近、回避、控制、保护、交换和攻击只保留为**表层检索标签**。真正分析必须落到一个完整事件。

```text
触发器
→ 人物如何解释局面
→ 本场目标
→ 可选路线
→ 实际行为
→ 行为作用的具体对象
→ 人物真实拥有的权限/资源
→ 对方或系统独立回应
→ 即时收益
→ 直接与延迟代价
→ 核心变量变化
```

### 5.1 行为事件卡

```yaml
场景与阶段:
行动者:
目标对象:
触发器:
人物对局面的解释:
本场目标:
深层需要假设:
可选路线:
可拒绝路线:
实际行为:
表层行为标签:
人物拥有的权限与资源:
行为强度:
公开程度:
可撤回性:
对方独立回应:
系统回应:
即时收益:
直接代价:
延迟代价:
唯一核心变量:
初始状态:
终态:
替代解释:
证据等级:
```

### 5.2 意图、功能和结果必须分开

例如“禁止对方出门”：

- 行动者意图可能是保护；
- 行为功能可能是控制通道；
- 对方体验可能是被剥夺选择；
- 实际结果可能降低危险，也可能破坏信任；
- 十元判断必须根据具体对象和变量另行审核。

所以“自称保护”不等于保护成功，“看似攻击”也不等于目标变量真的下降。

## 6. 单场只设一个核心被改变变量

每个场景先写：

```yaml
分析对象:
唯一核心变量:
初始状态:
终态:
展开指标:
```

常见变量包括：

- 对象掌握和否决权；
- 选择权与退出权；
- 信息可见性和归因；
- 进入资格与身份接口；
- 认可主体能否确认；
- 接收、保护与承担能力；
- 信任、停靠、退出后回返；
- 程序是否持续运行；
- 安全距离、退路和时间窗；
- 内部意义是否仍具有最终指导资格。

一个片段无法压成一个核心变量时，缩小片段或拆成主链与支路，不能把身份、亲密、名誉、安全和自由并列成五个主变量。

## 7. 恐惧、错误信念和防御的正确用法

### 7.1 恐惧不是端点

恐惧只说明人物预期某种损失。必须继续问：

1. 害怕失去什么具体对象或状态？
2. 人物怎样解释风险来源？
3. 人物用什么行为减少风险？
4. 行为改变了谁的哪项变量？
5. 短期有效是否造成长期代价？

### 7.2 错误信念不是“作者说人物错了”

错误信念至少要有：

```text
人物预测
→ 人物按预测行动
→ 现实提供反证
→ 人物仍如何解释反证
→ 信念是否修改
```

人物的信念可以事实错误但策略有效，也可以事实正确但使用方式伤害关系。

### 7.3 防御和应对分开

- 防御关注人物怎样避免体验某种心理内容；
- 应对关注人物实际怎样解决或回避问题；
- 同一行为可同时承担两种功能，但需要分别证明。

## 8. 压力测试：从填表改成三轮可比实验

每个角色至少做低压、中压、不可逆压力三轮。三轮尽量保持同一核心冲突，观察策略是否稳定、升级或转位。

```yaml
本轮压力等级: 低压 / 中压 / 不可逆
固定核心冲突:
本轮新增限制:
人物预测:
可选路线:
实际选择:
短期收益:
长期代价:
对方回应:
唯一核心变量:
初始状态:
终态:
旧策略是否维持:
策略升级/缩小/转位:
与上一轮差异:
替代解释:
```

### 8.1 压力测试要证明什么

- 心理词不变时，行为位置是否变化；
- 表面行为相同，真实功能是否变化；
- 短期奖励是否强化有害策略；
- 人物是否只在某个对象面前改变；
- 人物是否理解了问题，却仍没有新行为能力。

## 9. 关系行为的六个表层入口

六类入口仍可用于检索，但必须回到行为事件卡。

### 9.1 接近

可能为了获得信息、认可、接收、共同时间、控制或交换。接近不等于亲密成立。

### 9.2 回避

可能为了保持边界、避免羞耻、延迟冲突、保护他人、维持权力或逃离危险。回避不等于冷漠。

### 9.3 控制

必须写清控制什么对象、通过什么权限、减少了谁的哪些选择。控制欲只是心理描述。

### 9.4 保护

必须区分：承担冲击、提供资源、隔离危险、替人决定和剥夺知情权。保护可能与控制同时存在。

### 9.5 交换

必须写清交换对象、定价权、拒绝权、违约成本和谁保留最终方向。交换不自动等于公平。

### 9.6 攻击

必须写清攻击对象是身体、资源、身份、信息、认可、关系停靠还是安全路线。攻击动作不自动证明目标核心变量下降。

## 10. 对话分析：台词是行为，不是心理真相

```yaml
说话者:
听者:
公开话语:
隐藏意图假设:
话语动作: 请求 / 拒绝 / 试探 / 诱导 / 威胁 / 安慰 / 隐瞒 / 定义关系
所需权限或信息:
听者回应:
回应后的实际结果:
核心变量变化:
未说出口但可观察的代价:
```

一句台词必须经过回应和结果，才能判断其真实功能。自我描述只记录为人物叙事，不直接当事实。

## 11. 群像：配角先是独立行动者

取消“每个配角至少承担两个十元功能”的机械要求。每个重要配角先建立：

```yaml
自己的主要对象:
自己的目标:
自己的不可承受代价:
自己的权限与限制:
自己的决策规则:
自己的行为事件链:
与主角的利益重合:
与主角的利益冲突:
在没有主角时仍会做什么:
```

完成独立人物后，再分析其与主角关系中的十元位置。不能先分配“一个人负责n、一个人负责z”，再制造人物。

## 12. 角色弧必须画成动态图

角色弧不是“变好/变坏”，也不是十元属性替换。至少区分四类变化：

- **理解变化**：人物对自己、他人或世界的解释改变；
- **选择变化**：人物在同类冲突中作出不同决定；
- **能力变化**：人物知道新选择，却是否具备执行能力；
- **关系/位置变化**：他人和系统是否允许新策略运行。

### 12.1 角色弧基本图

```text
旧策略
  ├─短期收益→ 强化旧策略
  ├─延迟代价→ 关系或现实恶化
  ├─他人反证→ 人物解释/否认/修正
  └─不可逆事件→ 旧策略断裂
                    ↓
                新选择尝试
                  ├─失败与复发
                  ├─局部成功
                  └─跨对象迁移
```

### 12.2 五种弧形

- **改变弧**：决策规则和行为策略发生稳定变化；
- **崩坏弧**：旧策略体量升级，短期收益扩大，长期运行能力下降；
- **维持弧**：人物核心策略稳定，但外部世界或他人位置改变；
- **循环弧**：人物理解变化却反复回到旧策略；
- **分域弧**：人物只在某段关系或某类对象上改变。

### 12.3 角色弧归档卡

```yaml
旧策略:
旧策略保护的需要:
短期收益:
复利代价:
关键反证:
断裂节点:
新选择:
新选择所需能力:
首次失败:
支持支路:
阻断支路:
复发条件:
跨对象迁移证据:
最终稳定到哪一层: 理解 / 选择 / 能力 / 关系位置
```

## 13. 十元接口：必须在心理和行为分析之后

### 13.1 路由顺序

```text
对象、主体、阶段明确
→ 唯一核心变量明确
→ 行为与独立回应成立
→ 读取源/目标十元信息卡
→ 读取准度卡，排除最近邻
→ 两端标记：已成立 / 候选 / 未判定
→ 两端均成立后读取对应生卡、克卡或补卡
→ 查十元生补克表v2.22与专项正本
→ 只登记直接改变目标变量的关系边
→ 多条直接边组成具体动态链图
```

### 13.2 十元不是角色字段

不要求每个角色拥有十个十元端点。只登记当前场景有证据的节点：

- `x`：具体对象、资源、权限或关系边界归主体掌握；
- `x并z`：稳定公共壳使对象可识别、调用、归因或进入；
- `z`：重要认可主体对具体存在、能力、作品、选择或发现作出确认；
- `xn`：主体主动组织时间、流程、记录、资源和节点，使结构持续运行；
- `nx`：主体不占最终方向，沿既有安排、关系、权限或通道推进；
- `n`：对象真实进入内部，被持续接收、处理和承担负荷；
- `nz`：对象特异的可信停靠、自由退出、冲突后修复和可回返；
- `zn`：不可轻易让渡的内部意义及未来指导资格；
- `xz`：危险持续压缩安全距离、退路、时间窗或可逆空间；
- `zx`：主体权能公开显现、扩大并凌驾，使环境围绕其力量重新反应。

### 13.3 直接边和间接路径分开

若实际结构是：

```text
A生C → C克B
```

只登记两条直接边，不能追加“A克B”。链尾结果不能倒写成首端对链尾的直接关系。

### 13.4 关系状态纪律

- 几何位置不等于机制锁定；
- 关系在正本中锁定，也不等于本场自动成立；
- 每个具体端点仍要通过人物行为、变量、拿掉、反向和第三因素测试；
- 未锁定关系只写候选或未判定；
- 心理词、情绪、场景、镜头和单个动作不得直接当端点。

## 14. 动态链与角色心理怎样连接

十元关系边描述的是场景中具体变量怎样改变；心理模型解释人物为何反复选择某些边。二者不能互相替代。

```text
心理策略
→ 提高某类行为被选择的概率
→ 行为在具体对象上启动直接关系边
→ 关系边形成动态图
→ 图的收益和代价反过来强化或削弱心理策略
```

这是一条反馈路径，不是“恐惧自动生控制”“信念自动生成zn”。

## 15. 完整运行模板

### 15.1 A｜人物基线

使用第4节角色基线卡，只形成心理假设和长期证据，不判场景关系。

### 15.2 B｜单场行为事件

使用第5节行为事件卡，锁定一个核心变量，完成回应和代价。

### 15.3 C｜十元与动态图

### 15.4 D｜多轮角色弧

至少汇总三次同类压力事件，比较策略、收益、代价和变量，不从单场直接宣布角色完成成长。

## 16. 误判红线

- 温柔不等于真实接收；
- 陪伴不等于可信回返；
- 强势不等于公开权能成立；
- 自律不等于持续结构已经运行；
- 高冷不等于掌握边界；
- 坚定不等于内部意义具有最终指导资格；
- 被关注不等于重要认可主体已确认；
- 顺从不必然是沿既有方向推进；
- 危险气质不等于安全路线正在缩窄；
- 制服和称号不等于公共壳具有真实内部；
- 创伤、诊断名和人格母型不能替代行为证据；
- 结局成功不能倒补中间缺失关系；
- Canvas连线不能替代关系证明。

## 17. 伦理边界

- 不用医学诊断制造角色捷径；
- 不因浪漫类型洗白跟踪、强迫、隔离和剥夺选择；
- 解释行为机制不等于认可行为；
- 受害者的应对策略不能被写成其应为伤害负责；
- 创伤只能作为经历和条件，不能自动推出人格、命运或十元；
- 涉及自伤、成瘾、暴力和精神疾病时，区分叙事功能与现实健康信息。

## 18. 课程作业

1. 为同一角色分别填写心理基线卡和单场行为事件卡，禁止把两张卡合并；
2. 写一个“意图是保护、功能是控制、结果降低危险但破坏信任”的场景；
3. 用同一核心冲突完成低压、中压、不可逆三轮压力测试；
4. 找出一个表面行为相同、实际功能不同的双场景；
5. 为一个配角建立脱离主角仍能运行的独立事件链；
6. 把一段对话拆成话语动作、回应、代价和核心变量；
7. 为一个角色弧画出短期收益反馈、延迟代价支路、断裂和复发；
8. 在完成心理与行为分析后，只选择一场做十元路由；
9. 写一个端点成立但关系边失败的反例；
10. 写一个心理理解已经改变、行为能力尚未改变的角色阶段。
