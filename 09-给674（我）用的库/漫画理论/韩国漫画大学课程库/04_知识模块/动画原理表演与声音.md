# 动画原理表演与声音

## 1. 学习目标

- 理解动作的时间、空间、重量与意图；
- 把角色心理转成可见表演；
- 从Storyboard进入Animatic和镜头生产；
- 使用对白、环境声、音效、音乐和静默构成叙事；
- 将动画知识反向用于漫画动作和节奏。

## 2. 动画原理

核心原则：

- 挤压与拉伸；
- 预备动作；
- 演出重点；
- 连贯动作与跟随；
- 缓入缓出；
- 弧线运动；
- 次要动作；
- 时间控制；
- 夸张；
- 体积与结构稳定；
- 吸引力和清晰度。

原则不是装饰清单。每一个原则都必须服务动作目的和角色状态。

## 3. Timing与Spacing

### Timing

动作占用多少帧或多少时间，决定速度、重量和情绪。

### Spacing

每帧位置之间的距离，决定加速、减速和冲击感。

同样一秒钟的动作，可以通过Spacing表现：

- 突然启动；
- 犹豫后行动；
- 沉重拖动；
- 轻快弹跳；
- 失去控制。

## 4. Body Mechanics

分析链：

```text
目标
→ 支撑点
→ 发力点
→ 重心移动
→ 关节传递
→ 惯性
→ 结果与恢复
```

训练动作：

- 行走、跑步、跳跃；
- 推、拉、举、抛；
- 坐下、起身、跌倒；
- 搬运不同重量；
- 双人拉扯、搀扶、拥抱和搏斗。

## 5. 角色表演

表演先写动作目标：

```text
角色不是“悲伤地说话”
而是“试图让对方留下，同时不暴露自己需要他”
```

表演层级：

1. 场景目标；
2. 当前策略；
3. 策略失败后的调整；
4. 身体与语言是否一致；
5. 关键想法变化；
6. 反应与余波。

## 6. 关键姿势

关键姿势应表达：

- 人物在做什么；
- 力量方向；
- 情绪；
- 与他人的关系；
- 前后动作的连续性。

轮廓测试：把角色涂黑后，动作和态度仍应可读。

## 7. Storyboard与Animatic

### Storyboard

记录：

- 镜号；
- 景别与机位；
- 人物动作；
- 镜头运动；
- 台词与声音；
- 时长；
- 转场。

### Animatic

将Storyboard按时间排列，加入临时声音，用于检查：

- 节奏；
- 镜头长度；
- 动作清晰度；
- 情绪停顿；
- 制作规模；
- 是否需要删镜头。

## 8. 摄影与布局

- 先建立空间和人物位置；
- 镜头运动必须有观看动机；
- 焦段影响空间关系和人物距离感；
- 角色移动与摄影机移动同时发生时要控制信息；
- 布局需要为动画动作留下可执行空间。

## 9. 声音五层

### 对白

人物说什么、怎样说、是否与身体一致。

### 环境声

维持空间、时间和现实连续性。

### 动作音效

强化接触、重量、材质和方向。

### 音乐

组织情绪、节奏和主题，但不能替人物表演哭完所有情绪。

### 静默

删除预期声音可以制造注意、孤独、恐惧、尴尬和决定性时刻。

## 10. 声音脚本

```yaml
镜号:
对白:
环境声:
动作音效:
音乐:
静默区:
声音视点:
转场方式:
叙事功能:
```

## 11. 漫画中的动画知识

动画原理可转化为漫画：

- 预备动作决定下一格期待；
- Timing转化为画格数量和留白；
- Spacing转化为动作阶段和位置差；
- 关键姿势决定动作格清晰度；
- 跟随动作决定衣服、头发和道具的延迟；
- 声音通过拟声词、气泡和画格边缘表现。

## 12. 常见错误

- 动作只移动肢体，没有重心；
- 情绪只靠脸，身体完全中立；
- 每个镜头长度相同；
- 摄影机无原因地不停运动；
- 音乐从头铺到尾；
- 对白解释画面已经看见的内容；
- 动画镜头复杂度超过项目资源。

## 13. 课程作业

1. 5秒不同重量搬运动画；
2. 无对白角色犹豫表演；
3. 两人权力变化的关键姿势组；
4. 30秒Storyboard与Animatic；
5. 同一Animatic做三种声音设计；
6. 删除音乐后重新判断表演；
7. 把动画动作转成12格漫画；
8. 完成2至3分钟角色短片或动态漫画。
