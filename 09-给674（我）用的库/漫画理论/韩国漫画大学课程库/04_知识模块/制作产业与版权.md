# 制作产业与版权

## 1. 漫画生产不是“画完就行”

职业Webtoon与出版漫画必须同时管理：

```text
企划
→ 分镜
→ 作画
→ 背景
→ 色彩
→ 字体与气泡
→ 校对
→ 平台规格
→ 交稿
→ 修改
→ 宣发
→ 权利与收益
```

任何一环没有负责人，最后都会神秘地变成主笔本人负责。产业分工的古老魔法，大致如此。

最低字段：


## 3. Webtoon周更生产管线

### 前期储备

- 完成世界观、角色、地点和主要道具设定；
- 至少准备第一季大纲；
- 提前完成若干话库存；
- 建立背景、3D、笔刷、字体和色彩资产；
- 明确审核、修改与交稿节点。

### 单话流程

```text
本话节拍表
→ 文字分镜
→ 缩略分镜
→ 编辑反馈
→ 精分镜
→ 线稿
→ 背景
→ 底色
→ 光影与特效
→ 气泡与字体
→ 手机端检查
→ 校对
→ 交稿
→ 修改与归档
```

### 文件状态

- `00_brief`
- `01_beat`
- `02_thumbnail`

- `04_line`
- `05_bg`
- `06_color`

## 4. 团队角色

| 职位 | 核心责任 |
|---|---|
| 原作／编剧 | 前提、人物、世界、结构、单话脚本 |
| 主笔 | 视觉统一、人物作画、最终质量 |
| 分镜 | 页面或滚动节奏、镜头与演出 |
| 线稿助手 | 清线、局部人物与道具 |
| 背景 | 场景建模、透视、气氛与连续性 |
| 上色 | 色彩规范、底色、光影与特效 |
| 字效 | 气泡、字体、拟声词、阅读顺序 |
| 编辑 | 受众、结构、进度、平台与修改沟通 |
| 制作管理 | 排期、文件、交付、预算和成员负荷 |

同一个人可以兼任多职，但职责仍应分开记录，否则问题只会混成一团，然后被命名为“状态不好”。

## 5. 质量检查

### 故事

- 本话是否有目标、阻力、转折和结果；
- 主线、关系线或主题线至少推进一项；
- 话尾钩子是否来自本话因果；
- 新信息是否改变判断。

### 画面

- 人物比例与服装连续；
- 场景方向、光源和时间连续；
- 重要动作清楚；
- 手机缩小后表情、文字仍可读；
- 3D背景与人物透视一致；
- 特效没有覆盖叙事重点。

### 交付

- 文件名、尺寸、格式、色彩模式正确；
- 字体具有商业使用许可；
- 素材、照片、3D与笔刷来源可追溯；
- 分层文件和最终文件均归档；
- 修改意见与版本对应。

## 6. 编辑反馈

将意见分为：

1. 必须修改：事实错误、阅读障碍、平台规范、合同要求；
2. 高价值建议：人物动机、结构、节奏、类型承诺；
3. 口味建议：可讨论，不应自动服从；
4. 相互冲突意见：要求明确优先级和最终决策人。

修改记录：

```yaml
版本:
提出者:
问题:
证据/读者反应:
修改方案:
影响范围:
是否采纳:
理由:
结果:
```

## 7. 平台与读者

需要研究：

- 主要阅读设备；
- 单话长度和更新节奏；
- 免费、付费、等待免费等商业模式；
- 首页缩略图与作品简介；
- 年龄分级和内容规范；
- 评论、收藏、留存和付费转化；
- 海外翻译与本地化。

平台规则会变化，所有记录必须附年份与官方来源。

## 8. 出版与品牌

- 纸书分页与Webtoon滚动需要重新编排；
- 封面、书脊、目录、印刷色和出血；
- 单行本增补内容；
- 作者品牌与社交媒体；
- 展会、签售、众筹和周边；
- 宣传素材不能泄露关键剧情或使用无授权音乐图片。

## 9. 权利清单

签约前至少区分：

- 著作权归属；
- 独家或非独家连载权；
- 地区与语言；
- 纸书出版权；
- 海外发行权；
- 影视、动画、游戏和音频改编权；
- 商品化权；
- 宣传使用权；
- 合同期限；
- 自动续约；
- 终止条件；
- 数据与结算查阅；
- 作者署名；
- 修改与完整权；
- 争议解决。

## 10. 收益结构

可能包括：

- 稿费／制作费；
- 保底；
- 付费阅读分成；
- 广告；
- 单行本版税；
- 海外授权；
- 改编授权；
- 商品分成；
- 奖金、基金与政府支持项目。

必须确认收入定义、扣除项目、结算周期、税务和审计权。百分比很漂亮，但分母若由别人自由发挥，它就只是一幅抽象画。

## 11. 素材与版权

每项外部资产记录：

```yaml
资产名:
来源:
作者/权利人:
许可证:
商业使用:
可否修改:
可否再分发:
署名要求:
购买凭证:
使用位置:
```

特别检查：

- 字体；
- 照片；
- 3D模型；
- 笔刷和纹理；
- 音乐和音效；
- 商标、制服、建筑和人物肖像；
- 公版作品的具体版本与翻译。

## 12. AI辅助的最低规则

- 不把未经授权的他人作品直接当作可发布资产；
- 记录AI使用环节、模型、日期和人工修改；
- 检查平台、比赛和客户对AI的申报要求；
- 检查生成内容中的商标、角色、签名和相似性；
- 重要角色、分镜、最终画面保留人工决策和可追踪过程；
- 不上传受保密协议保护的脚本、角色或客户素材到未经批准的服务。

## 13. 健康与排期

周更排期应记录：

- 每工序平均用时；
- 返工比例；
- 个人每日可持续工时；
- 休息日；
- 生病和设备故障缓冲；
- 连载库存。

长期依靠熬夜不是制作体系，只是把未来的身体当作无息贷款机构。

## 14. 毕业／商业项目交付包

- 企划书；
- 角色、世界和场景设定；
- 第一季大纲；
- 前三话脚本与分镜；
- 至少一话完整样稿；
- 制作流程和成员分工；
- 预算排期；
- 资产与版权清单；
- 平台和受众分析；
- 作品集页面；
- 修改记录与复盘。
