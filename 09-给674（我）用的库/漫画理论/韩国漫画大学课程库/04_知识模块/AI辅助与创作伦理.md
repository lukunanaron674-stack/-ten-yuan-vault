# AI辅助与创作伦理

## 1. 学习目标

- 区分AI在企划、参考、生产和发布中的不同风险；
- 保留作者决策、来源记录和可修改流程；
- 检查学校、比赛、平台、客户和合同对AI的要求；
- 不把生成速度误认为故事、导演和审美质量。

## 2. 可用环节

### 资料与企划

- 关键词扩展；
- 研究问题整理；
- 资料分类；
- 多方案比较；
- 不能把模型回答直接当史实来源。

### 故事

- 压力测试；
- 反方意见；
- 场景变体；
- 连续性检查；
- 不能替代人物动机和作者最终判断。

### 视觉前期

- 构图发散；
- 色彩方案；
- 道具与场景参考；
- 临时预演；
- 需检查训练来源、风格挪用和相似性风险。

### 制作

- 背景辅助；
- 颜色与分层实验；
- 重复资产；
- 修补与放大；
- 必须保留人工校正、风格统一和版权记录。

## 3. 风险分类

| 风险 | 典型问题 | 控制方式 |
|---|---|---|
| 事实风险 | 虚构课程、书目、历史和法律 | 回到官方或一手来源 |
| 版权风险 | 近似现有角色、画风、商标、签名 | 相似性审查、来源记录、重绘 |
| 合同风险 | 客户或平台禁止未申报AI | 签约前书面确认 |
| 隐私风险 | 上传未公开脚本、客户素材和个人数据 | 使用批准环境、去除敏感信息 |
| 风格风险 | 画面不统一、细节漂移 | 建立角色与场景规范、人工修正 |
| 劳动风险 | 不透明替代助手、署名和报酬争议 | 明确分工、工具使用和署名 |
| 教育风险 | 用生成结果跳过基础训练 | 评估过程文件和独立能力 |

## 4. AI使用记录

```yaml
项目:
环节:
工具/模型:
日期与版本:
输入素材:
素材权利:
输出用途:
人工修改:
相似性检查:
平台/客户许可:
是否申报:
最终责任人:
```

## 5. 不应上传的内容

- 保密协议覆盖的脚本和设定；
- 未公开客户素材；
- 未经同意的私人照片和采访；
- 可识别学生、同事或读者的信息；
- 付费教材全文；
- 尚未取得授权的角色、商标和资产。

## 6. 学校作业中的AI

作业要求至少说明：

- 哪些步骤允许AI；
- 哪些能力必须独立完成；
- 是否提交提示、草稿和修改过程；
- 是否允许风格模拟；
- 如何处理版权与隐私；
- 评价重点是成品还是过程。

禁止规则不明后再临时惩罚，也禁止学生把“AI做的”当成不解释过程的万能烟雾弹。

## 7. 漫画项目最低流程

```text
人工确定前提与角色
→ AI仅参与规定环节
→ 保存原始输出
→ 检查事实与相似性
→ 人工重构分镜、造型和细节
→ 统一角色、空间、光线和文字
→ 记录资产与权利
→ 按平台要求申报
```

## 8. 生成图像审查

检查：

- 是否出现现有IP特征；
- 是否出现签名、水印或乱码商标；
- 人体、服装、道具和空间是否连续；
- 角色年龄、身份和情绪是否漂移；
- 画面是否只靠颗粒、光晕和复杂细节假装完成度；
- 是否能被分层、修改和重复生产。

## 9. 生成故事审查

检查：

- 前提是否只是常见类型拼接；
- 人物行动是否有具体动机；
- 冲突是否由误会拖延；
- 设定是否前后矛盾；
- 台词是否同质；
- 是否存在无来源事实；
- 作者实际保留了哪些独立判断。

## 10. 课程作业

1. 同一场景人工版与AI辅助版对照；
2. 对生成故事做事实、结构、角色和伦理四层审计；
3. 建立可追踪的AI资产表；
4. 将生成背景重绘到统一透视和风格；
5. 分析一项平台或比赛的AI规则；
6. 为团队项目写AI使用协议；
7. 完成一份AI参与作品的公开说明。

## 11. 对应韩国课程

- AI Artwork；
- AI数字绘画；
- AI Webtoon制作；
- 生成式媒体与影像制作；
- AI图像设计；

- 数字工具；
- 著作权与内容商业。

## 12. 更新规则

AI工具、平台政策和法律变化快。本页只保存原则与审计框架；具体规则必须按使用当天的官方条款重新核验，并记录日期。
