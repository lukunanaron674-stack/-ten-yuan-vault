# 漫画史美学与批评｜R6

## 1. 本章总判断

漫画史研究的是生产、媒介、平台、法律、读者和形式怎样改变作品可用的对象、权限、时间结构和关系位置；批评则检验这些条件怎样进入具体作品的十元动态链。

```text
历史与产业事实
→ 形成创作对象、媒介界面、生产流程和读者位置
→ 作品在这些限制中组织十元端点
→ 形式让端点、体量和顺序可见
→ 批评用证据检验机制、代价和五维结果
```

十元不能替代史料。某时期“像`xn`”并不等于历史本身是`xn`，不然理论会把整个世界吞成一张配色不错的表格。

## 2. 漫画史十个研究维度的十元化

| 研究维度 | 十元知识任务 |
|---|---|
| 生产技术 | 谁掌握工具`x`，流程怎样形成`xn`，形式界面怎样稳定为`x并z` |
| 发行渠道 | 谁控制准入、推荐、可见性和传播路径 |
| 读者群 | 谁被定义为成员、谁被排除、谁提供`z`认可和`n`持续承载 |
| 作者劳动 | 谁决定方向、谁沿流程`nx`、谁承担代价、谁获得署名与收益 |
| 审查与法律 | 规则、权限、公开处置和认可入口怎样改变作品 |
| 常见类型 | 某时期反复运行哪些对象、关系和动态链 |
| 页面/屏幕 | 媒介如何组织时间、空间、信息和观看界面 |
| 商业模式 | 对象控制、付费节点、平台承载和风险转移 |
| 海外交流 | 作品怎样跨语言、平台和身份壳重新归因 |
| 代表作与争议 | 哪个端点变化成为历史转折，争议由谁定义 |

## 3. 韩国漫画史主线的十元理解

```text
报刊与讽刺画
→ 战后出版
→ 租书店与漫画房
→ 类型杂志与单行本
→ PC通信与网络漫画
→ 门户网站Webtoon
→ 手机竖屏、平台付费与全球发行
→ 工作室化、IP改编与AI争议
```

这条主线要逐阶段检查：

- `x`：作品、工具、版权、发行口和数据由谁掌握；
- `x并z`：作品以什么公开壳被识别和传播；
- `z`：谁给予认可、排名、签约和历史地位；
- `xn`：生产、连载、审核和推荐流程如何持续；
- `nx`：作者、助手、读者如何沿既有系统行动；
- `zx`：平台、国家、编辑或作者何时公开决定；
- `n`：租书店、杂志、平台和社群如何承载作品与读者；
- `nz`：长期读者关系、怀旧和回返怎样形成；
- `xz`：审查、市场、停刊、窗口与职业风险；
- `zn`：作者和群体为何坚持某种表达。

具体年代和因果必须由史料证明，十元只组织理解。

## 4. 漫画形式分析的十元知识

### 4.1 图像

造型、线条、材质、明暗、色彩、构图和人物背景关系要回答：

- 哪个对象被识别为中心；
- 谁拥有观看和解释位置；
- 人物边界、身份壳和空间权限如何显影；
- 风格是否支持行为、回应与代价。

### 4.2 顺序

画格数量、格间省略、页面翻页、竖屏滚动、视点转换对应`xn/z/xz`时间与节点组织。顺序能改变读者何时知道，却不能反向篡改事件实际机制。

### 4.3 文字

台词、旁白、标题、字体、气泡和拟声词是信息与声音界面：

- 谁说、谁听、谁无法回应；
- 谁掌握信息`x`；
- 哪个身份壳`x并z`发声；
- 何时完成`z`确认；
- 文字与图像是重复、补充、矛盾还是互相揭穿。

### 4.4 读者行为

阅读方向、停留、滚动、评论、分享、付费和连载等待形成读者端的`xn/z/n/nz`结构，但读者数据不自动等于作品质量。

## 5. 漫画美学问题的十元重写

### 漫画时间在哪里

检查`xn`持续组织、`z`节点和读者实际阅读时间怎样配合。时间既不只在格子，也不只在读者脑内，而在媒介和行为共同运行中形成。

### 页面整体与单格竞争

页面作为`x并z`整体界面，单格作为局部对象和节点。两者争夺观看中心、顺序和体量。

### 竖屏是否无限

竖屏受屏幕、平台、加载、读者手势和生产成本限制。所谓无限画布依然拥有非常有限的人类拇指。

### 风格化人物为何可传达心理

因为读者读取的是姿势、视线、节奏、关系和回应，不只读取解剖相似度。

### 素材、3D与作者性

检查谁决定选择、删改、组合、署名和最终方向。工具参与不自动取消`zn/x`作者性，作者也不能用“我点了生成”跳过责任。

### 商业类型与个人表达

检查`xn/x并z`生产结构是否克制或承载`zn/x`主体表达，以及作者能否利用类型通道`nx`实现自己的方向。

### 数据是否成为作品一部分

数据改变编辑和作者下一轮选择时，已经进入动态链；但数据仍是读者行为的代理指标，不是读者灵魂扫描仪。

## 6. 批评四层的十元化

### 描述

只记录作品实际对象、行为、镜头、文字、平台和版本，不先贴节点。

### 分析

判断对象状态、主十元、条件十元、回应、体量、顺序和被改变变量。

### 解释

把作品机制与历史、产业、作者选择和媒介条件连接，检查第三因素。

### 评价

评价作品是否兑现自身目标：

- 目标端点是否真实变化；
- 关系机制是否成立；
- 表现是否让机制可读；
- 代价是否进入后续；
- 五维结果是否由整部作品支持。

## 8. 比较研究

比较必须统一对象和维度：

- 同题材纸漫与Webtoon：比较界面、顺序、观看和生产；
- 原作与改编：比较对象功能、端点、体量和五维重排；
- 不同国家：比较具体媒介、制度、读者和产业，不拿国籍当万能原因；
- 同平台不同时期：比较推荐、付费、首话和生产流程；
- 独立与商业：比较掌握、资源、认可、承载和风险。

## 9. 内容批评工作坊

```text
陈述作品目标
→ 选定具体页面或屏幕
→ 描述对象和形式
→ 拆十元端点、行为与回应
→ 检查正本关系、变量和第三因素
→ 分析读者体验
→ 区分作者选择与生产限制
→ 提出修改
→ 在自己的作品中C模式复演
```

## 10. 实验漫画的十元知识

改变阅读方向、画格边界、实体材料、声音、滚动、互动、顺序选择、档案和聊天记录形式时，必须说明：

- 实验改变了哪个媒介`x并z`界面；
- 谁掌握阅读方向`x`；
- 读者是否进入`nx`既定路径或获得新的选择权；
- `xn/z`时间节点怎样变化；
- 形式变化是否改变对象、关系和五维结果；
- 评价标准是什么。

看不懂不是自动高级，只是信息传输也拥有失败的自由。

## 11. 史料与十元边界

- 课程、年代、政策、作品和平台事实必须有来源；
- 十元只用于组织机制，不得把推断冒充史实；
- 未锁定关系只能写候选；
- 历史共现不等于生克补；
- 销量、热度和奖项属于`z`候选，不等于质量；
- 后世认可不能倒写成作品当时已经拥有同样位置。

## 12. 常见错误

- 剧情复述代替分析；
- 只评价画面好看；
- 销量等于质量；
- 个人不适等于作品失败；
- 只找支持自己观点的场景；
- 忽略版本、年代、平台和生产；
- 把所有韩国Webtoon看成同一工业模板；
- 用十元术语替代史料和形式证据。

## 13. 五维归纳

- 时间：媒介演化、连载、流程、节点与阅读等待；
- 本体：作者性、身份、主体表达和作品边界；
- 空间：发行界面、平台、页面、屏幕和社群承载；
- 因果：生产决定、制度处置、劳动承担和形式后果；
- 命运：停刊、迁移、读者回返、历史遗忘与再发现。

## 14. 训练

1. 一部作品的纯形式分析，不复述剧情；
2. 同章节纸版与竖屏版，比较端点显影与顺序；
3. 一位韩国漫画家的阶段研究，区分史实与十元解释；
4. 一种类型20年对象、平台、读者和动态链演变表；
5. 平台规则如何改变首话的案例研究；
6. 对自己作品写反方十元批评；
7. 完成带页面证据的3000字评论；
8. 制作一部有明确研究问题的实验短漫；
9. 找一个“高销量但目标端点未兑现”和一个“低数据但机制成立”的对照；
10. 对一条历史解释做拿掉测试：移除平台、政策或技术后，因果是否仍成立。
