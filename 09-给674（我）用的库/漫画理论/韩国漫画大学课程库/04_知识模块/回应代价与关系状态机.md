# 回应、代价与关系状态机

> 行为没有回应，就只是人物单方面表演；行为没有代价，就很难形成剧情；行为没有改变关系状态，就只是场面热闹。

## 1. 回应不是“同意／不同意”

人物面对他人行为时，至少有十二类回应。

### 1.1 接受

直接满足对方要求，但接受也可能带条件、保留或误解。

### 1.2 有条件接受

提出交换条件、期限、保证人、抵押物或边界。

### 1.3 协商

承认对方部分目标，修改手段、范围或成本分配。

### 1.4 拒绝

明确不执行、不承认或不进入关系。

### 1.5 回避

不正面回答，通过拖延、转移、离场、装作没看见来降低压力。

### 1.6 表面服从

公开接受，私下保留、破坏、泄密或寻找替代路线。

### 1.7 反制

使用对方的规则、资源、秘密或关系网络反过来限制对方。

### 1.8 升级

把冲突从私人层面扩大到身体、制度、公众或第三方。

### 1.9 重解释

改变行为的意义，例如把“保护”解释成“控制”，把“离开”解释成“背叛”。

### 1.10 转移

把压力、责任或代价推给第三人、制度或未来的自己。

### 1.11 撤离

切断互动、关系、资源或身份，拒绝继续参加同一游戏。

### 1.12 牺牲

主动承担损失以保住另一项价值，但牺牲也可能制造债务和控制。

## 2. 回应选择的依据

回应不是为了让场景“有反转”才突然出现。它由以下因素决定：

- 回应者的欲望和恐惧；
- 对行动者的信任；
- 权力差；
- 可用资源；
- 掌握的信息；
- 公开环境与旁观者；
- 过去债务；
- 退出成本；
- 对行为意义的解释。

## 4. 九类代价

### 4.1 资源代价

钱、物资、机会、住房、工作、工具和支持者减少。

### 4.2 时间代价

错过窗口、延迟目标、消耗耐心、让对手获得准备时间。

### 4.3 身体代价

受伤、疲劳、疾病、能力下降、留下可见痕迹。

### 4.4 身份代价

失去职位、资格、名誉、归属、合法性或自我认同。

### 4.5 关系代价

信任下降、距离增加、债务形成、依赖加深、共同秘密破裂。

### 4.6 信息代价

暴露秘密、让对方了解弱点、丢失解释权、制造错误认知。

### 4.7 道德代价

违反自己的价值、伤害无辜者、合理化下一次越界。

### 4.8 未来选项代价

一旦选择，某些道路永久关闭，例如公开身份后无法回到普通生活。

### 4.9 他人转移代价

人物自己获得收益，却把风险转移给家人、部下、陌生人或未来群体。

## 5. 代价的四种时间形态

- 即时代价：行为结束时立刻发生；
- 延迟代价：暂时看似成功，后续回收；
- 隐性代价：人物尚未意识到；
- 复利代价：每次重复行为都会扩大损失。

真正有效的长期剧情，往往不是每次都制造新灾难，而是让旧代价不断积累和变形。

## 6. 代价归属

每个重要行为都要问：

1. 谁获得收益；
2. 谁立即付费；
3. 谁以后付费；
4. 谁根本不知道自己在付费；
5. 谁有权决定代价是否值得；
6. 代价是否可以转移、补偿或追回。

## 7. 关系状态向量

关系不只用“敌人、恋人、朋友”表示。推荐记录七个变量：

```yaml
信任: -5..+5
权力差: -5..+5
情感距离: 0..10
依赖度: 0..10
债务: -5..+5
信息差: -5..+5
关系定义权: -5..+5
```

说明：

- 信任：相信对方会不会伤害、欺骗或抛弃自己；
- 权力差：谁能决定资源、规则和退出成本；
- 情感距离：允许对方进入多少私人区域；
- 依赖度：离开对方后损失多大；
- 债务：谁认为谁欠谁；
- 信息差：谁知道更多关键事实；
- 关系定义权：谁有权说“我们是什么关系”。

## 8. 关系变化单位

每个场景不必让人物从陌生人变爱人，但至少应改变一个变量。

### 微变化

- 多说出一个真实信息；
- 允许一次靠近；
- 接受一次帮助；
- 拒绝一次旧仪式；
- 让对方看见弱点。

### 中变化

- 权力资源转移；
- 共同秘密形成；
- 债务被承认；
- 某人获得定义关系的权利；
- 依赖被公开或否认。

### 大变化

- 背叛；
- 公开站队；
- 身份揭露；
- 不可逆牺牲；
- 退出、断绝或重新缔约。

## 9. 六种关系状态机

### 9.1 利用→债务→信任／反噬

```text
一方提供资源
→ 另一方接受
→ 债务形成
→ 债务被尊重：信任增加
／债务被利用：控制增加
→ 合作或反噬
```

### 9.2 试探→误读→修正／断裂

```text
一方隐晦试探
→ 对方按自身恐惧解释
→ 回应偏离预期
→ 继续试探或公开说明
→ 理解修正／关系断裂
```

### 9.3 保护→依赖→控制／独立

```text
提供保护
→ 被保护者减少自主行动
→ 保护者掌握更多资源
→ 边界争议
→ 控制固化／重新归还选择权
```

### 9.4 对抗→能力承认→合作

```text
目标冲突
→ 多次交锋
→ 看见对方能力和底线
→ 出现共同威胁
→ 临时合作
→ 新信任或更危险的竞争
```

### 9.5 崇拜→去魅→真实关系

```text
一方理想化另一方
→ 真实缺陷暴露
→ 否认或失望
→ 接受复杂性／转为仇恨
→ 建立真实关系或彻底离开
```

### 9.6 共同秘密→绑定→暴露危机

```text
秘密共享
→ 形成特殊联盟
→ 信息成为权力
→ 第三者接近真相
→ 互保、甩锅或背叛
→ 关系被重新定义
```

## 10. 行为、回应、代价的组合

### 示例：保护性隐瞒

- 行为：A隐瞒危险；
- A的目的：保护B；
- B的回应：发现后重解释为不信任；
- 即时收益：B暂时安全；
- 延迟代价：B失去知情权，信任下降；
- 关系变化：A权力增加，B依赖增加但情感距离扩大；
- 下一行为：B秘密调查或公开反抗。

### 示例：公开道歉

- 行为：A公开道歉；
- 可能功能：修复、止损、抢回解释权；
- B的回应：有条件接受，要求赔偿；
- 即时代价：A失去部分声誉；
- 延迟收益：关系可以重新谈判；
- 风险：若道歉只为结束追责，信任继续下降。

## 12. 常见失败

- 回应者像机关门，只负责挡主角；
- 代价由无关配角承担，主角毫无损失；
- 每次冲突后关系变量归零，下一场重复同样争吵；
- 道歉自动修复一切；
- 牺牲自动证明爱；
- 控制行为没有被受控者重新解释；
- 背叛只靠突然揭露，不经过债务、恐惧和机会条件。

## 13. 训练

1. 给同一行为写12种回应；
2. 给一次成功设计即时收益和三种延迟代价；
3. 用七变量记录一段关系在5个场景中的变化；
4. 写一个“保护→控制→归还选择权”的完整链；
5. 写一个道歉失败的场景，失败原因不能只是对方固执；
6. 让第三者承担代价，并在后续反过来改变主角关系；
7. 删除“他们关系更好了”，改成可测量的状态变化。
