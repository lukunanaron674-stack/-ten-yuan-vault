# 回应、代价与关系状态机｜R6

## 1. 本章十元总判断

十元关系不能靠行动者单方面宣布。只有在对方回应、代价归属和关系变量变化之后，才能证明某个端点真实增强、减弱、转位或退隐。

```text
A行为
→ B按自身端点独立回应
→ A修正／升级／撤回
→ 收益与代价结算
→ 对象状态和关系七变量变化
→ 结果十元出现
→ 生克补成立或被否定
→ 下一轮
```

没有回应，行为只是意图；没有代价，行为缺少因果；没有变量变化，生克补只是文字装饰。

## 2. 十二类回应的十元归整

### 2.1 接受

接受可能：

- 进入真实`n`承载；
- 承认`z`位置；
- 接受`x并z`身份壳；
- 沿对方方向进入`nx`；
- 允许对方获得`x`控制。

必须看接受后谁保留最终决定权。

### 2.2 有条件接受

条件、期限、抵押和边界涉及`x/xn/z/nx`：谁定义条件、谁控制对象、哪个节点确认、谁承担未履约代价。

### 2.3 协商

协商不是天然`n`，而是双方尝试重分配：

- `x`掌握；
- `nx`承担；
- `xn`流程；
- `z`确认；
- `n`内部位置。

只有双方选择权真实保留，才不是伪协商。

### 2.4 拒绝

拒绝可能是：

- `x`守边界；
- `z`停止确认；
- `zn`撤回意义资格；
- `n`拒绝接收；
- `x并z`拒绝身份接口；
- `xz`因窗口关闭而出现。

拒绝动作本身不固定节点。

### 2.5 回避

拖延、转移和离场可能维持`x`边界、沿`nx`旧方向继续、延长`xn`过程或使`xz`风险累积。

### 2.6 表面服从

公开接受但私下破坏，常见结构：

```text
x并z身份壳仍覆盖
→ 表面沿nx方向执行
→ 私下保留x边界或建立替代路线
→ 若持续停止背书使公开壳失去代表性
→ 可观察nx克x并z候选，但未锁定不得直接判定
```

### 2.7 反制

利用对方规则、资源和秘密反过来限制对方，可能调用`nx`借力、`x`掌握、`xn`流程和`z`确认。

### 2.8 升级

从私人扩大到身体、制度、公众或第三方，使体量增加，并可能把`x`转成公开`zx`、把关系冲突转成`x并z/z`公开确认或增强`xz`风险。

### 2.9 重解释

把保护解释成控制、离开解释成背叛，改变的是对象意义、关系定义权和认可归因：检查`x/z/x并z/zn`。

### 2.10 转移

把责任和代价推给第三人、制度或未来自己，是因果层核心：

- 谁执行`zx`；
- 谁承担`nx`；
- 谁掌握分配`x`；
- 哪个流程`xn`让转移持续。

### 2.11 撤离

切断互动、资源或身份，可能恢复`x`自主，也可能失去`n/nz`并进入`xz`漂流。

### 2.12 牺牲

主动承担损失以保住另一价值，必须区分：

- 自主选择的`zn/x`；
- 沿关系或制度方向的`nx`；
- 真实保护`n`；
- 通过牺牲制造债务和控制`x`；
- 最后窗口`xz`中的被迫选择。

牺牲不自动高尚，也不自动是`nx`。

## 3. 回应选择依据的十元化

回应由以下端点条件共同决定：

- 欲望和恐惧：人物想保护哪个端点；
- 信任：`n/nz`能否运行；
- 权力差：`x/zx/xn/x并z`由谁占据；
- 资源：谁有实际`x`；
- 信息：谁掌握`x`、谁能确认`z`；
- 公开环境：是否进入`x并z/zx/z`；
- 过去债务：`nx/x`方向；
- 退出成本：`x/xz`；
- 行为解释：`zn`意义与关系定义权。

## 5. 九类代价的十元归整

### 5.1 资源代价

钱、物资、机会和工具减少，改变`x`掌握、`nx`借力能力和`xz`安全路线。

### 5.2 时间代价

错过窗口、延迟目标和让对手准备，改变`xn`过程、`z`节点和`xz`临界。

### 5.3 身体代价

伤病和疲劳改变身体`x`、行动`zx`能力、承载`n`需求和风险`xz`。

### 5.4 身份代价

失去职位、资格、名誉和归属，分别影响`x并z/z/n/zn`，不得统称“身份受损”。

### 5.5 关系代价

信任、距离、债务和依赖变化，影响`n/nz/x/nx`。

### 5.6 信息代价

秘密暴露、弱点被掌握、解释权丢失，影响信息`x`、认可`z`和主体`zn`。

### 5.7 道德代价

违反自身价值，检查`zn`主体意义是否下降、扭曲或迫使其撤回对`xn`结构的维护。

### 5.8 未来选项代价

道路永久关闭，使`x`选择空间下降、`xz`临界增强、`z`节点不可逆。

### 5.9 他人转移代价

行动者获益，家人、部下或未来群体承担，重点分析`zx补nx`是否被扭曲为“一个人显权、另一个人消失”。

## 6. 代价的时间形态

- 即时：本轮立刻改变端点；
- 延迟：暂时潜伏，后续在`z`节点回收；
- 隐性：承担者尚未获得信息；
- 复利：`xn`重复结构使损失体量上升。

延迟和复利代价是长篇`xn`组织的重要证据，但不能只因“过了很久”就判`xn`关系。

## 7. 代价归属的十元问题

1. 谁获得对象`x`；
2. 谁公开获得功劳或权能`z/zx`；
3. 谁立即承担`nx`；
4. 谁以后承担；
5. 谁不知道自己承担；
6. 谁有权决定代价是否值得`x`；
7. 哪个`xn`流程让代价持续转移；
8. 代价是否破坏`n/nz`；
9. 是否使某人进入`xz`；
10. 是否改变主体`zn`。

## 8. 关系七变量与十元端点

```yaml
信任: -5..+5
权力差: -5..+5
情感距离: 0..10
依赖度: 0..10
债务: -5..+5
信息差: -5..+5
关系定义权: -5..+5
```

### 对应关系

- 信任：`n/nz`运行条件；
- 权力差：`x/zx/xn/x并z`分布；
- 距离：`n/nz/x`边界；
- 依赖：区分`n`互承载与`nx`方向外包；
- 债务：`nx/x/zx`；
- 信息差：信息`x`和确认`z`；
- 定义权：`x/x并z/z`。

变量是证据，不与十元一一等同。

## 9. 关系变化体量

### 微变化

透露信息、允许靠近、接受帮助、拒绝旧仪式和暴露弱点，通常只能证明端点轻微显影。

### 中变化

资源转移、秘密形成、债务承认、定义权变化和依赖公开，可支持生克补候选。

### 大变化

背叛、公开站队、身份揭露、不可逆牺牲和退出，改变体量和顺序，但仍需机制验证。

## 10. 六种关系状态机的十元重建

### 10.1 利用→债务→信任／反噬

```text
A以x资源帮助B
→ B通过nx接受并形成债务
→ A归还选择权，资源进入真实n承载
／A利用债务扩大x控制
→ 信任上升或反噬
```

### 10.2 试探→误读→修正／断裂

```text
A控制部分信息x
→ 试探B的z/n/nz回应
→ B按自身恐惧重解释
→ 信息差和关系变量改变
→ 公开说明形成z确认
／继续隐藏使n断裂
```

### 10.3 保护→依赖→控制／独立

```text
A提供真实n保护
→ B风险xz下降但资源依赖上升
→ A掌握更多x
→ 若A缩小B退出权，保护转控制
→ B恢复x自主或进入nx方向让位
```

重点检查`n克xz`是否先成立，以及后来是否转为`x克nz`等结构。

### 10.4 对抗→能力承认→合作

```text
双方zx候选冲突
→ xn规则和多次交锋提供证据
→ z确认对方能力
→ 共同危险xz出现
→ 建立临时n承载或nx借力
→ 合作、竞争或新的控制
```

### 10.5 崇拜→去魅→真实关系

```text
A把B的x并z公开壳当作真实主体
→ 缺陷暴露
→ z认可对象被重写
→ A接受B的zn主体和现实x边界
／关系断裂
```

### 10.6 共同秘密→绑定→暴露危机

```text
信息对象由双方共同掌握x
→ 形成n/nz特殊关系
→ 秘密成为控制资源
→ 第三者接近z确认
→ 双方互保、甩锅或背叛
→ x、n、nz和x并z重新分配
```

## 11. 两个组合案例

### 11.1 保护性隐瞒

```yaml
行为: A隐藏危险信息
表面目的: 保护B
信息控制: A的x上升
B选择权: 下降
即时结果: B暂时远离xz
真实承载: 若A实际承担并提供安全，可有n
延迟代价: 信任下降、B秘密调查
可能转位: n保护 → x控制
候选关系: n克xz / x克nz，需分别验证
```

### 11.2 公开道歉

```yaml
行为: A公开道歉
可能目的: 修复n / 承担nx / 抢回x解释权 / 获得z确认
B回应: 有条件接受
即时损失: A的公开地位或资源
延迟结果: 是否恢复接收、信任和选择权
判断: 只有变量恢复才算修复
```

## 13. 已锁定关系在回应层的证明

### zx克n

必须观察公开显权是否改变成员资格、接收边界或运行条件，并使接收、保护、互信和返回能力下降。

### xn克zx

必须观察规则、流程和前置行动是否让即时权能无法取消长期结构。

### n克xz

必须观察真实接收和保护是否降低危险可到达性和继续移动紧迫度。

### x克z

必须观察掌握者是否关闭对象到达认可主体的接口，或劫持署名与归因。

### x克nz／nz克x

必须观察退出权和自愿停靠证据的真实变化，不能用吃醋、争吵和挽留代替。

## 14. 五维归纳

- 时间：代价如何延迟、复利并在节点回收；
- 本体：回应是否维护主体意义和自主边界；
- 空间：身份壳与内部承载怎样变化；
- 因果：谁行动、谁承担、代价是否被转移；
- 命运：回应是否关闭路线或保留回返。

## 15. 误判红线

- 接受不等于`n`；
- 拒绝不等于`x/z`；
- 牺牲不等于`nx`；
- 道歉不等于修复；
- 保护不等于`n`；
- 反抗不等于`zx`；
- 关系变差不等于生克启动；
- 情绪强烈不等于体量高；
- 一次代价不等于长期`xn`；
- 七变量变化不能替代端点机制。

## 16. 全量十元化训练

1. 为十二类回应各写两个不同十元结果；
2. 同一“接受”写成`n/nx/x并z/z`四版；
3. 写保护性隐瞒从`n克xz`转为`x`控制的完整链；
4. 写一场`zx克n`并明确成员资格变化；
5. 写一场`xn克zx`，禁止只靠上级命令；
6. 为九类代价建立端点影响表；
7. 设计一个延迟代价和复利代价长篇链；
8. 为六种关系状态机各做正例、误判和反例；
9. 用场景结算模板检查一话作品；
10. 从五维归纳一条关系弧，不从单场倒推主主题。
