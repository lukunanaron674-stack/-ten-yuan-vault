# 绘画人体与背景

## 1. 学习目标

- 用结构而不是轮廓猜测绘制人物；
- 让姿势表达行动、重量、情绪和身份；
- 建立可重复使用且叙事清楚的场景；
- 统一人物与背景的透视、光线和尺度；
- 将速写、解剖、动作与漫画分镜连接。

## 2. 观察与速写

观察顺序：

```text
动作方向
→ 重心与支撑
→ 大体块
→ 关节与比例
→ 衣服受力
→ 手、脸和道具
→ 细节
```

训练重点：

- 30秒抓动作线；
- 2分钟抓体块与重心；
- 5至10分钟补关节、衣褶和空间；
- 同一动作从正、侧、背三角度重建。

## 3. 人体结构

### 骨架

- 头、脊柱、胸廓、骨盆；
- 肩带与髋部；
- 肘、膝、腕、踝；
- 关节活动范围；
- 身体比例随年龄、体型和风格变化。

### 肌肉

优先学习影响轮廓和动作的肌群：

- 颈肩；
- 胸背；
- 上臂和前臂；
- 腹部与腰侧；
- 臀腿；
- 小腿。

目的不是背出拉丁文，而是解释体块为什么在这个姿势下压缩、拉伸或突出。

## 4. 动作与重量

一个动作至少判断：

- 谁在施力；
- 力从哪里进入身体；
- 哪只脚或哪个部位承担重量；
- 身体怎样保持平衡；
- 动作前的预备；
- 动作后的惯性与恢复。

动作表达心理：

| 心理或身份 | 身体倾向 |
|---|---|
| 防备 | 收紧核心、缩短步幅、保护躯干 |
| 支配 | 占据空间、动作直接、减少试探 |
| 犹豫 | 重心反复、动作未完成、手部停顿 |
| 疲惫 | 支撑点增加、脊柱下沉、动作延迟 |
| 亲密 | 距离缩短、方向同步、允许触碰 |

## 5. 面部、手与表演

### 面部

- 先确定头部朝向和透视；
- 眉、眼、口不是三个独立表情按钮；
- 情绪通过面部、头部、肩颈和视线共同完成；
- 强烈情绪后保留恢复与残余表情。

### 手

手可承担：

- 目标动作；
- 紧张泄露；
- 权力和距离；
- 道具操作；
- 关系接触或拒绝。

## 6. 服装与道具

服装需要同时解释：

- 身份、职业、时代和阶层；
- 面料重量与活动范围；
- 穿着方式和损耗；
- 动作中的拉伸、压缩和摆动；
- 角色轮廓识别。

道具必须有尺寸、重量、握法、使用流程和放置位置。

## 7. 透视基础

- 视平线决定观看高度；
- 灭点决定平行方向；
- 人物尺度应共享同一空间逻辑；
- 圆柱、楼梯、门窗和重复结构要检查缩短；
- 镜头焦段效果与几何透视分开理解。

常用训练：

1. 一点透视室内；
2. 两点透视街角；
3. 高低机位人物与建筑；
4. 同一房间五个镜位；
5. 根据平面图重建镜头。

## 8. 背景与叙事

背景不是空缺填充。它可以：

- 提供行动障碍和路线；
- 表示身份、经济和生活习惯；
- 暴露人物关系；
- 隐藏或揭示信息；
- 控制压迫、孤独、拥挤和安全感；
- 保存事件痕迹。

## 9. 3D与SketchUp辅助

3D适合：

- 保持复杂场景连续；
- 测试机位、焦距和人物高度；
- 重复使用建筑与道具；
- 降低周更背景成本。

3D不能替代：

- 构图选择；
- 气氛；
- 叙事重点；
- 与人物画风统一；
- 对真实建筑逻辑的理解。

## 10. 常见错误

- 解剖准确但动作僵硬；
- 每个角色共用同一身材和站姿；
- 背景透视正确，却没有叙事重点；
- 人物像贴纸一样浮在3D场景上；
- 重要道具忽大忽小；
- 场景只在第一格出现，之后人物漂进虚空。

## 11. 课程作业

1. 100个30秒动态；
2. 20个职业动作流程；
3. 同一角色的8种重心状态；
4. 一间房的平面图、五机位和昼夜版本；
5. 12格无台词搬运重物；
6. 24格两人在复杂空间追逐；
7. 用3D搭景后重新手绘风格化；
8. 完成一话人物与背景连续性检查表。

- 漫画背景；
- SketchUp基础与进阶；
- 3D背景制作；
- 角色表现与动画表演。
