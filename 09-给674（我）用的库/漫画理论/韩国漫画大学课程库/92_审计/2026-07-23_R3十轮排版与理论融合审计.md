# R3十轮排版与理论融合审计

## 总结

旧版优点是文件清楚、链条明确；缺点是十元主要停留在末端标注，Canvas更像目录，不像关系推演工作台。本轮把结构改为三层：

```text
现实知识层
→ 关系生成层
→ 十元动态层
→ 五维主题层
→ 场景／单话／序列输出
```

## 第1轮｜Canvas排版

**问题**：旧版纵向链条干净，但理论节点缺少并列比较，内容层、行为层、十元层没有视觉分区。

**修复**：
- 采用左中右三栏；
- 左栏为对象、制度、课程知识；
- 中栏为关系生成器与行为闭环；
- 右栏为十元、生克补、体量、顺序和五维；
- 底部集中输出场景、单话、序列、案例和审计。

## 第2轮｜阅读顺序

**问题**：旧版从审计文件进入，读者容易先看结论后看知识。

**修复**：固定入口顺序：

```text
对象状态
→ 关系约束
→ 欲望与恐惧
→ 触发器
→ 行为策略
→ 回应
→ 代价
→ 关系变化
→ 十元判断
→ 动态链输出
```

## 第3轮｜十元解释准确度

**问题**：旧版把十元写成内容词和行为词的对照，容易退化为关键词匹配。

**修复原则**：
- 十元不是题材标签；
- 十元判断对象在关系中的作用方式；
- 同一行为可因对象、顺序、体量和关系不同而属于不同节点；
- 必须先证明对象、行为、回应和代价，再判断十元。

## 第4轮｜十元与对象层融合

新增中间判断：对象不直接等于十元，对象进入关系后才产生十元功能。

```text
对象属性
＋控制权
＋稀缺性
＋可见性
＋关系绑定
＝对象在当前场景中的十元作用
```

例如“门”可成为：
- x：边界被定义；
- z：通路被截断；
- x并z：空间规则与通行制度；
- xz：跨越即不可逆；
- nz：返回与停靠的入口。

## 第5轮｜十元与行为层融合

行为不按表面动词判断，而按其关系功能判断：

```text
表面动作
→ 行为目的
→ 对方选择权变化
→ 资源／信息／边界变化
→ 十元功能
```

“保护”可分别是：
- zn：保存对方主体生成；
- n：维持连接和承载；
- zx：执行性阻挡威胁；
- x：建立边界；
- nx：替对方承担代价；
- xz：以保护之名剥夺选择。

## 第6轮｜生克补融合

**旧问题**：生克补仅在模板末尾填写。

**修复**：生克补必须解释行为为何成功、失败或转向。

- 生：A的作用扩大B，使B获得新的行动能力；
- 克：A限制、截断或压缩B的作用空间；
- 补：A不直接扩大B，而是补足B缺少的条件；
- 互补不是和谐标签，必须写清双方交换了什么缺口。

## 第7轮｜体量与顺序融合

新增硬规则：
- 同一十元节点体量不同，会形成日常行为、场景主导或命运级压力；
- 顺序改变关系意义；
- 禁止只列节点不写先后。

```text
节点A(体量)
→ 节点B(体量)
→ 节点C(体量)
```

必须说明每一步带来的对象、行为、回应与代价变化。

## 第8轮｜五维融合

五维不作为分类文件夹，而作为动态链的主题结果：

- 时间：过程如何积累、截断、回收；
- 本体：主体如何生成、被定义、被保护或被抹除；
- 空间：位置、规则、承载和通路如何组织行动；
- 因果：外部执行与代价承担如何形成结果；
- 命运：不可逆压力与归属回归如何改变选择。

每条链最多一个主维度、一个副维度，避免五维全勾的理论自助餐。

## 第9轮｜课程知识融合

韩国大学课程知识分为三种作用：

1. **事实材料**：职业、制度、空间、制作流程；
2. **表现方法**：分镜、表演、对白、色彩、声音；
3. **验证机制**：作业、编辑反馈、读者数据、审计。

课程不直接对应某个十元，而是提供：

```text
可验证对象
＋可观察行为
＋可执行表现
＋可重复训练
```

再由关系结构进入十元判断。

## 结论

本轮没有改写十元核心定义，而是修复“课程知识与十元之间缺少关系生成层”的问题。以后所有课程材料必须经过对象状态、关系约束、行为闭环和代价结算后，才能进入十元、五维与动态链。
