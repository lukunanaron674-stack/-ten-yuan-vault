# 专业课程 Canvas 与十元正本统一清理

## 一、清理前问题

1. 根目录同时存在两张十元相关 Canvas，入口职责重叠。
2. 旧 Canvas 使用旧口径：把 `z` 写成规则截断、把 `x并z` 写成世界规则、把 `nx` 写成代价补偿。
3. 专业课程、深知识采矿、十元分析、五大主题与生克补没有形成同一工作流。
4. 课程证据层和用户个人理论层没有在 Canvas 中清楚分隔。
5. 旧版没有统一标记主入口、辅助材料和历史记录。

## 二、处理方式

- 新建唯一主入口：[[韩国漫画大学专业课程_十元融合总览.canvas]]。
- 删除两张重复旧 Canvas：
  - `韩国漫画大学课程库_十元化_内容人物行为向.canvas`
  - `内容人物行为_10轮深知识采矿.canvas`
- 保留两份双角色审计 Markdown，作为历史证据与采矿记录。
- 重写[[01_课程总纲/十元化_内容人物行为索引]]，同步现行十元主骨。
- 在新 Canvas 中把专业课程拆成五层：课程证据、知识学习、对象行为、十元动态、主题与作品回填。

## 三、现行十元接口

| 十元 | 课程知识进入分析时的现行接口 |
|---|---|
| x | 对象、资源、身份、场域与关系的掌握、准入、退出和归属边界 |
| zx | 主体权能在公共界面显现、扩大并重新分配他者位置 |
| xn | 主动组织计划、时间、流程、规则、信息与节点，使结构持续运行 |
| nx | 沿既有身份、关系、权限、安排或流程通道推进，方向权不完全在主体 |
| x并z | 表层壳、公共身份与内部真实的结构性分层，壳承担保护、展示或准入 |
| zn | 即使没有奖励和认可，主体仍因不可背弃的意义与自我定义而行动 |
| z | 重要认可主体对人物存在、能力、作品、选择或价值作出确认 |
| n | 事情落到主体身上后被接住、承载、消化和处理，而非简单忍耐 |
| nz | 维持已发生的温度、停靠与等待，不愿一段关系或时光结束 |
| xz | 危险显身、异质逼近、退路与时间窗缩窄，主体在临界边界行动 |

## 四、融合门槛

课程知识点只有同时满足以下条件，才算完成十元深度融合：

1. 指明分析对象层：人物、状态、行为、关系、对象、场景或时间结构。
2. 记录对象状态前后变化。
3. 记录行为触发、回应、代价和关系变量变化。
4. 标主十元、辅十元、体量与显影顺序。
5. 生克补写清双方端点、被改变变量和结算阶段。
6. 五大主题只在动态链完成后判断，并标0—3级显影。
7. 保留最近邻反证，禁止从职业、视觉、题材名或结局倒推。
8. 学校官方课程证据与用户个人理论判断分栏保存。

## 五、清理结果

- 根目录只保留一张专业课程主 Canvas。
- 旧十元口径不再作为可点击入口存在。
- 历史审计记录保留，但不参与现行导航。
- 新增课程或知识模块时，必须同步总入口、十元索引和主 Canvas；否则标记 `integration_missing`。
