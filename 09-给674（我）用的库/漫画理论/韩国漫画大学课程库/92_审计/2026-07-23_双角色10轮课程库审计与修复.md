# 双角色10轮·韩国漫画大学课程库审计与修复

## 0. 审计设定

### 角色A｜怀疑论审计员

职责：

- 默认不相信“完整”“全部”“官方教材”等大词；
- 检查证据、来源、链接、目录、排版、遗漏和过度推断；
- 专门寻找那些读起来很像真的、但实际上没人能证明的句子。

### 角色B｜课程库修复者

职责：

- 不靠辩解保住旧结构；
- 将问题落实到具体文件；
- 能修的立即修；
- 不能从公开资料解决的，建立待核实项和升级路径；
- 修复后再次接受A的追问。

### 审计对象

```text
09-给674（我）用的库/漫画理论/韩国漫画大学课程库/
```

### 审计标准

1. 事实是否有对应证据等级；
2. 学校课程与本库重建知识是否分开；
3. 是否夸大覆盖范围；
4. Obsidian链接是否稳定；
5. 课程、教材、作业和知识是否能互相导航；
6. 是否遗漏韩国漫画教育的重要模块；
7. 文件元数据和排版是否统一；
8. 无法解决的缺口是否显式登记。

# 第1轮｜“全部韩国课程”是不是虚假完成

**A：** 总入口写着要把韩国漫画大学课程全部放进去，但目前只有7所学校。你是不是建了一个很大的标题，再把未完成藏在标题下面？

**B：** 是。第一版虽然在正文中承认持续采集，但仍使用“完整学校档案”等容易误导的措辞。7所学校也没有一所拿到全部逐周大纲、作业和指定教材。

**A：** 那么必须区分“建了学校文件”和“完整覆盖学校课程”。

**B：** 同意。建立学校覆盖等级：

- L0：只确认学校／专业；
- L1：官方入口和课程表；
- L2：课程说明、培养目标、学制；
- L3：教师、研究、教材线索和毕业要求；
- L4：逐周大纲、作业、评价和明确教材。

**实际修复：**

1. `00_总入口.md`中的“完整学校档案”改为“首轮学校档案”；
2. `韩国院校覆盖清单.md`明确当前7所只到L1-L2；
3. 写明当前没有学校达到L4；
4. 6所待采集学校保留为L0→L1队列；
5. “全部”改为持续维护目标，不再作为当前完成状态。

**结果：** 已解决措辞夸大；全国穷尽式采集仍是公开任务。

# 第2轮｜证据标签前后打架

**A：** 第一版总入口说D是教师著作，书目却把教师著作写成B。覆盖表又把教师著作写成B。一个库连自己的字母都不能达成共识，怎么审教材？

**B：** 属实。旧版同时存在两套证据含义。

**A：** 统一，不要让每个文件拥有自己的私人法律。

**B：** 统一为：

| 标签 | 统一含义 |
|---|---|
| A | 官方课程表 |
| B | 官方课程说明 |
| C | 官方公开课 |
| D | 教师著作与研究 |
| R | 补充参考 |
| T | 待核实 |

**实际修复：**

1. 新建[[91_规范/证据等级与文件规范]]；
2. 教材书目中的教师著作全部改为D；
3. 覆盖表中的教材状态改用统一标签；
4. 学校文件使用`source_grade: A/B/D`组合；
5. 明确D不能证明“指定教材”，R不能证明“学校采用”。

**结果：** 已解决证据标签冲突。

# 第3轮｜Obsidian链接会不会断

**A：** 启明文化大学和覆盖表里出现`[[../04_知识模块/...]]`。Obsidian对相对Wikilink的处理会受设置、文件移动和链接格式影响。为什么不用库内唯一路径？

**B：** 第一版混用了文件系统相对路径和Obsidian库内路径，确实不稳定。

**A：** 修，不要把导航可靠性寄托在用户配置恰好与你相同。

**实际修复：**

1. 启明文化大学文件中的`[[../04_知识模块/...]]`改为`[[04_知识模块/...]]`；
2. 覆盖表中的`[[../02_学校课程/...]]`改为`[[02_学校课程/...]]`；
3. 新规范明确禁止`[[../...]]`形式；
4. 总入口重新链接全部新增文件；
5. 残留字符串检查未发现本课程库中旧链接目标。

**结果：** 已解决本库已发现的相对Wikilink问题。

# 第4轮｜来源链接是否只是装饰

**A：** 文件底部列了一堆URL，但没有检查日期和链接状态。若链接失效，库仍会把它当证据。URL只是长，不代表可靠。

**B：** 正确。第一版没有来源注册表，也没有链接健康字段。

**A：** 实际检查，而不是新增一段“应定期检查”的漂亮废话。

**B：** 本轮检查了已建学校和待建学校的官方入口。

**检查结果：**

- 青江、世宗、公州、顺天、祥明、清州、启明文化的主要官方入口可访问；
- 东洋、世翰、灵山、极东、湖南、世宗Cyber的入口可访问；
- 两条KOCW旧深链当前返回错误。

**实际修复：**

1. 新建[[90_采集与核验/来源索引与链接健康]]；
2. 为来源建立ID、等级、状态和最后检查日期；
3. KOCW旧深链降级为`BROKEN`／`C-T`；
4. 书目不再把失效深链当稳定入口；
5. 建立季度检查流程。

**结果：** 已解决来源无状态问题；失效KOCW课程仍需重新定位。

# 第5轮｜中文课程名是否可追溯

**A：** 学校文件大量只有中文课程名。这个中文是学校官方翻译，还是你自己翻的？读者无法知道，也无法回韩国页面搜索。

**B：** 多数是本库中文概译。第一版没有明确标记，确实容易让人误以为是官方中文名。

**A：** 课程库不能切断原语言。特别是`콘티`、`연출`、`서사`这些词，翻译不同会改变知识分类。

**实际修复：**

1. 新建[[91_规范/中韩英术语表]]；
2. 所有7所学校档案增加`translation_status`；
3. 规定课程首次出现推荐写成“中文概译（韩文原名｜英文辅助名）”；
4. 覆盖表新增韩文课程原名字段；
5. 青江因官方页面可直接读取韩文课程表，被列为优先补录对象。

**结果：** 已解决翻译身份不明；逐门课程韩文原名仍需继续补齐。

# 第6轮｜官方课程与本库知识有没有混在一起

**A：** 学校文件先列官方课程，后面直接写“应掌握什么”。读者可能认为这些详细知识是学校公开教学大纲，其实很多是你根据课名重建的。

**B：** 这是第一版最危险的结构问题之一。内容本身可能合理，但证据身份不清。

**A：** 合理不等于官方。把两者分开。

**实际修复：**

1. 新建[[04_知识模块/README_知识模块说明]]；
2. 总入口明确：学校档案回答“公开教什么”，知识模块回答“本库重建应学什么”；
3. 学校档案的分析段统一增加“本库解释／不是逐周官方讲义”提示；
4. 新增知识文件统一使用`document_type: reconstructed_knowledge`和`not_official_syllabus: true`；
5. 十元接口明确标为用户个人理论，不归因于韩国学校。

**结果：** 已解决官方事实与重建知识的身份混淆。

# 第7轮｜原库知识模块严重偏科

**A：** 原库有故事、角色、世界观、类型、分镜和产业，但学校明明还教人体、色彩、字体、动画表演、声音、漫画史、批评、AI和平台。为什么故事客厅装修得很漂亮，其他房间还只有水泥地？

**B：** 原库确实偏重叙事，造型、动画和研究模块只散落在学校文件里，没有独立知识入口。

**A：** 补齐，不要只写“待拆分”。

**实际修复：** 新建6个知识模块：

1. [[04_知识模块/绘画人体与背景]]；
2. [[04_知识模块/色彩字体与拟声词]]；
3. [[04_知识模块/动画原理表演与声音]]；
4. [[04_知识模块/漫画史美学与批评]]；
5. [[04_知识模块/AI辅助与创作伦理]]；
6. [[04_知识模块/Webtoon编辑平台与读者数据]]。

每个模块包含学习目标、核心知识、常见错误、作业和韩国课程对应。

**结果：** 已解决第一层知识模块遗漏。教师论文、真实课堂案例和创作者健康仍可继续深化。

# 第8轮｜教材书目是不是“西方编剧书大礼包”

**A：** 用户要求韩国漫画大学用到的书，第一版却大量列McKee、Truby、McCloud、Eisner。它们可以参考，但不能假装是韩国学校教材。还有“田野调查教材”“依恋理论读物”这种根本不是具体书的条目。

**B：** 对。第一版虽然标了R，但正式书目和模糊研究方向仍混在一起，韩国语本土资料也明显不足。

**A：** 让书目承认自己知道什么、不知道什么。

**实际修复：**

1. `教材书目总表.md`升级到v0.2；
2. 西方书全部明确标为R级补充参考；
3. 青江教师著作改为D级线索，不称指定教材；
4. 模糊条目移为T级研究方向；
5. KOCW教材线索因链接失效标为`C/T`；
6. 新建[[03_教材与书目/待核实教材队列]]；
7. 明确韩国漫画史、Webtoon叙事、平台劳动、PD、著作权、拟声词、本地化等本土书目缺口；
8. 建立书名、作者、出版社、版次、课程关系和证据模板。

**结果：** 已解决书目身份混乱；韩国各校真实指定教材仍需持续采集。

# 第9轮｜课程、知识、作业是不是三张皮

**A：** 读者看到“角色心理学”，还要自己猜应该打开哪个知识文件、做什么作业。课程表是课程表，知识是知识，训练是训练，它们之间没有桥。

**B：** 属实。原总入口只有并列链接，缺少交叉关系。

**A：** 建矩阵。不要让读者在18个文件里玩寻宝。

**实际修复：**

1. 新建[[06_矩阵/课程知识作业矩阵]]；
2. 每个课程族对应核心知识、对象库、行为库、最低作业和知识模块；
3. 新建[[06_矩阵/学校比较矩阵]]；
4. 比较7所学校的培养路线、优势资产和适合目标；
5. 比较表明确不等于大学排名；
6. 总入口增加“三份先看”导航。

**结果：** 已解决课程到训练的断层。

# 第10轮｜文件格式和最终可维护性

**A：** 学校文件的Frontmatter不统一。有的写`updated`，有的写`verified`；有的没有学制、适用年份、翻译状态和覆盖等级。以后加学校会继续长成七种形状。

**B：** 是。第一版只保证内容存在，没有建立统一档案模式。

**A：** 规范必须落实到旧文件，不能只写一本没人遵守的宪法。

**实际修复：**

1. 7所学校档案统一增加：
   - `school_zh`；
   - `school_ko`；
   - `program_zh`；
   - `program_ko`；
   - `school_type`；
   - `program_length`；
   - `applicable_year`；
   - `coverage_level`；
   - `source_grade`；
   - `translation_status`；
   - `verified`；
   - `document_type`。
2. 每校增加“证据边界”；
3. 暴露世宗缺一年级、公州未按学期重排、祥明未完整抽取二至四年级等具体缺口；
4. 总入口升级为v0.3；
5. 课程总纲升级为v0.2并明确是多校归纳版；
6. 建立本审计文件作为变更记录。

**A：** 是否可以宣布“所有问题都解决”？

**B：** 不可以。结构、证据、导航和主要知识遗漏已修复；无法从公开页面取得的校内大纲、真实作业、指定教材和全国穷尽名单仍然存在。

**A：** 这种回答比“全部完成”可信。首轮结构审计通过。

**结果：** 当前库通过首轮结构审计，进入持续资料采集阶段。

# 当前仍然存在的真实缺口

## P0｜资料缺口

- 全国全部相关院校名录；
- 每校现行完整课程表与适用年份；
- 逐周教学大纲；
- 真实作业和评分标准；
- 各课明确指定教材；
- 校内LMS和未公开讲义。

## P1｜翻译缺口

- 7所学校所有课程的韩文原名逐项并列；
- 韩国教育和产业术语的上下文差异；
- 书名作者出版社的韩文规范记录。

## P2｜研究缺口

- 韩国漫画史详细年代与史料；
- 韩国学术论文、教师论文和研究室项目；
- Webtoon劳动、健康、工作室管理；
- 不同平台实际数据与合同版本；
- 毕业作品、学生案例和就业路径。

# 最终结论

这次审计没有证明课程库“已经包含韩国大学的所有知识”。它做成了更重要、也更不讨喜的事情：

- 把已知和未知分开；
- 把官方和重建分开；
- 把教材和参考书分开；
- 把课程、知识和作业接起来；
- 把遗漏变成明确任务；
- 把容易断的导航和格式修好。

当前版本适合继续扩建，不适合被当成已经封顶的百科全书。封顶通常只是项目停止呼吸的礼貌说法。
