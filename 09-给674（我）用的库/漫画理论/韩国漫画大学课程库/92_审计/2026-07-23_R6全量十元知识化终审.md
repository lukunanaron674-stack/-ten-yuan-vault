# R6全量十元知识化终审

## 一、用户要求

本轮目标不是：

- 在每章结尾提到十元；
- 为每章外挂一张十元规整卡；
- 把课程名、对象名、动词、镜头或色调匹配成节点；
- 用Canvas总览冒充正文已经融合。

本轮目标是：

> 先完整备份原版，再把所有专业知识点直接按照十元体系重新整理、归整、归纳和理解，使R6正文成为实际学习与创作主版本。

## 三、R6知识点统一结构

每个知识点按以下结构重建：

```text
原专业含义
→ 作用对象
→ 对象当前状态
→ 主十元
→ 条件十元
→ 结果十元
→ 已锁定／待确认关系
→ 源端点、目标端点、机制和被改变变量
→ 体量、顺序、阶段、显影条件和第三因素
→ C动态链
→ 五维归纳
→ 误判、拿掉和反向测试
→ 创作训练
```

只写“可以对应x、n、zx”不计入完成。

## 八、理论红线

- 对象不天然等于十元；
- 动词不天然等于十元；
- 课程名不等于十元；
- 镜头、姿势、色调、声音和气氛只显影机制；
- 共现、先后和作者意图不等于生克补；
- 五维只能在动态链后归纳；
- 未锁定关系只写候选；
- 固定防遗忘：`zx克n`，`zx被xn克`。
