# 证据等级与文件规范

## 1. 统一证据等级

本库所有事实、课程、教材和推导统一使用以下标签：

| 标签 | 名称 | 可证明的内容 | 不可证明的内容 |
|---|---|---|---|
| `A` | 官方课程表 | 某校某年公开设置了某门课程 | 该课每周具体教法、指定教材和作业 |
| `B` | 官方课程说明 | 学校公开说明了课程目标、能力或产出 | 教师实际每次授课内容完全一致 |
| `C` | 官方公开课 | KOCW、K-MOOC或学校公开课程的讲次、教材 | 该公开课等同于目标学校内部课程 |
| `D` | 教师著作与研究 | 教师身份、公开著作和研究方向 | 著作必然是其课程指定教材 |
| `R` | 补充参考 | 与课程目标高度相关的外部教材和方法 | 韩国院校正式采用该资料 |
| `T` | 待核实 | 已发现线索，但证据不足、链接失效或信息冲突 | 任何确定性结论 |

禁止把 `D` 写成 `B`，也禁止把 `R` 包装成 `A`。字母不多，人类仍然能把它们用乱，所以单独立规矩。

## 2. 学校档案覆盖等级

| 等级 | 完成条件 |
|---|---|
| `L0` | 仅确认学校或专业名称 |
| `L1` | 已核实当前官方专业入口与课程表 |
| `L2` | 已补主要课程说明、培养目标和学制 |
| `L3` | 已补教师、研究方向、教材线索、毕业要求 |
| `L4` | 已取得逐周教学大纲、作业、评价与明确教材 |

当前公开资料通常只能达到 `L1-L3`。只有达到 `L4` 才可称“完整课程档案”。

## 3. 学校文件标准前言

```yaml
---
title:
school_zh:
school_ko:
program_zh:
program_ko:
school_type:
program_length:
applicable_year:
coverage_level:
source_grade:
translation_status:
verified:
document_type: school_profile
---
```

### 必填说明

- `applicable_year`：课程表适用年份；不知道时写 `T-待核实`。
- `coverage_level`：使用L0-L4。
- `translation_status`：`已核对韩文原名`、`中文概译`或`待逐项补原名`。
- `verified`：最后核验官方入口的日期。

## 4. 知识模块标准前言

```yaml
---
title:
status:
created:
updated:
document_type: reconstructed_knowledge
basis:
  - 韩国院校公开课程
  - 公开教材与创作理论
not_official_syllabus: true
---
```

知识模块是根据多校课程重建的学习系统，不是任何一所韩国大学的官方讲义。

## 5. 教材记录标准

```yaml
书名_原文:
书名_中文:
作者:
出版社:
版次:
年份:
语言:
证据等级:
关联学校:
关联课程:
是否明确指定:
官方证据:
合法获取:
链接状态:
最后核验:
备注:
```

没有作者、出版社、版次和证据的条目，不称为“教材”，只能放入待核实队列。

## 6. 来源记录标准

每个来源记录：

```yaml
source_id:
title:
organization:
url:
source_grade:
applicable_year:
access_status:
last_checked:
used_in:
notes:
```

### 链接状态

- `OK`：本轮可访问且内容相关；
- `REDIRECT`：可访问但发生跳转；
- `PARTIAL`：页面存在，但课程内容以图片、附件或脚本加载；
- `BROKEN`：当前无法访问；
- `ARCHIVE`：只用于历史课程；
- `T`：尚未检查。

## 7. Obsidian链接规范

统一使用库内路径：

```text
[[04_知识模块/故事写作知识体系]]
```

不使用：

```text
[[../04_知识模块/故事写作知识体系]]
```

理由：相对Wikilink在不同Obsidian设置、移动文件和同步环境下解析不稳定。

## 8. 课程名翻译规范

学校课程首次出现时推荐写法：

```text
角色心理学（캐릭터심리학，Character Psychology）
```

若没有核到原文：

```text
角色心理学〔中文概译，韩文原名待核〕
```

不得把中文概译伪装成学校官方中文名称。

## 9. 排版规范

- 每个文件只保留一个一级标题；
- 一级结构从 `## 0.` 或 `## 1.` 开始，保持文件内部一致；
- 课程表优先使用表格，长解释使用分节；
- 原始课程与分析分开，分别标为“官方可确认”和“本库解释”；
- 原始URL集中在来源段，正文使用来源ID或脚注；
- 单文件超过300行时拆分；
- 所有新文件必须被总入口或局部README链接。

## 10. 版本规则

- 修正文案、链接和元数据：补丁版本；
- 新增学校或知识模块：次版本；
- 改变证据制度或目录结构：主版本；
- 每次审计建立独立审计记录，不覆盖旧记录。
