# 中韩英术语表

> 用于课程原名追踪、检索和翻译统一。不同学校可能使用不同名称，表中不是唯一标准答案。

## 1. 故事与企划

| 中文 | 韩文常见写法 | 英文 | 说明 |
|---|---|---|---|
| 故事叙述 | 스토리텔링 | Storytelling | 从人物、事件、信息到叙事结构 |
| 叙事 | 내러티브 / 서사 | Narrative | `서사`更偏叙事结构与意义，`내러티브`常作外来语使用 |
| 梗概 | 시놉시스 | Synopsis | 故事全貌的压缩说明 |
| 剧本 | 시나리오 | Scenario / Screenplay | 韩国课程中常用`시나리오` |
| 情节 | 플롯 | Plot | 因果组织后的事件结构 |
| 企划 | 기획 | Planning / Development | 包括受众、形式、卖点与生产方案 |
| 世界观设定 | 세계관 설정 | Worldbuilding | 世界规则、制度与生活方式 |
| 角色设定 | 캐릭터 설정 | Character Development | 身份、心理、功能和视觉设定 |
| 角色心理学 | 캐릭터심리학 | Character Psychology | 将心理与行为转为创作工具 |
| 类型研究 | 장르연구 | Genre Studies | 类型承诺、对象、行为与变奏 |
| 改编 | 각색 | Adaptation | 将小说、影视等重组为漫画形式 |
| 序列设计 | 시퀀스디자인 | Sequence Design | 多场景构成的阶段性叙事单元 |

## 2. 漫画与Webtoon演出

| 中文 | 韩文常见写法 | 英文 | 说明 |
|---|---|---|---|
| 漫画分镜 | 콘티 | Conte / Storyboard | 韩国漫画与影像行业常用`콘티` |
| 分镜工作坊 | 콘티제작워크숍 | Conte Workshop | 从脚本到画格、镜头和节奏 |
| 场景设计与导演 | 장면설계와 연출 | Scene Design & Direction | 人物、道具、空间和镜头组织 |
| 漫画导演 | 만화연출 | Comics Direction | 页面、格子、视线与节奏 |
| Webtoon导演 | 웹툰연출 | Webtoon Direction | 竖屏、滚动、屏幕单位和话尾钩子 |
| Storyboard | 스토리보드 | Storyboard | 动画或影像的镜头规划 |
| 动态漫画 | 모션코믹스 | Motion Comics | 漫画画面、运动、声音与剪辑结合 |
| 拟声词 | 의성어 | Onomatopoeia | 模拟声音的文字 |
| 拟态词 | 의태어 | Mimetic Word | 模拟状态、动作或感觉 |
| 书法／艺术字 | 캘리그라피 | Calligraphy | 标题、拟声和画面文字设计 |

## 3. 绘画、动画与技术

| 中文 | 韩文常见写法 | 英文 | 说明 |
|---|---|---|---|
| 人体绘画 | 인체드로잉 | Figure Drawing | 比例、动态、体块和观察 |
| 人体解剖 | 인체해부학 | Anatomy | 骨骼、肌肉与动作结构 |
| 动作绘画 | 액션드로잉 | Action Drawing | 力量、方向、关键姿势和连续性 |
| 作画 | 작화 | Drawing / Animation Drawing | 根据上下文可指漫画或动画绘制 |
| 背景 | 배경 | Background | 场景空间、透视和气氛 |
| 数字原稿 | 디지털원고 | Digital Manuscript | 数字线稿、上色、文字与输出 |
| 动画原理 | 애니메이션원리 | Principles of Animation | Timing、Spacing、重量和运动 |
| 角色表演 | 캐릭터연기 | Character Acting | 用动作、节奏和姿势表达心理 |
| 预演 | 프리비주얼라이제이션 | Previsualization | 制作前的镜头与空间测试 |
| 动态分镜 | 애니매틱 | Animatic | 带时间和声音的Storyboard |
| 三维图形 | 3D 그래픽 | 3D Graphics | 建模、布局、灯光与渲染 |
| 生成式媒体 | 생성형 미디어 | Generative Media | 生成模型参与图像、影像或资产生产 |

## 4. 批评、研究与产业

| 中文 | 韩文常见写法 | 英文 | 说明 |
|---|---|---|---|
| 内容批评 | 콘텐츠비평 | Content Criticism | 对作品形式、意义和产业的分析 |
| 漫画美学 | 만화미학 | Comics Aesthetics | 漫画媒介的形式与审美问题 |
| 漫画史 | 만화사 | Comics History | 地区、时期、媒介与产业演变 |
| 作品集 | 포트폴리오 | Portfolio | 求职、投稿或升学材料 |
| 毕业评价 | 졸업평가 | Graduation Assessment | 毕业项目的阶段或终期评审 |
| 产学合作 | 산학협력 | Industry–Academia Cooperation | 企业、学校与学生共同项目 |
| 现场实习 | 현장실습 | Field Practicum | 企业或真实生产环境实习 |
| 著作权 | 저작권 | Copyright | 作者权利、授权和利用 |
| 商业模式 | 비즈니스모델 | Business Model | 收费、分成、授权与IP开发 |
| 出版编辑 | 출판편집 | Publishing & Editing | 出版流程、校对、规格与发行 |

## 6. 待逐项补原名规则

当前学校档案中大量课程使用中文概译。后续补录时采用：

```text
中文概译（韩文原名｜英文辅助译名）
```

若韩文原名存在特殊拼写、空格或罗马数字，保留学校页面原样，不自行“顺手优化”。课程名不是排版错误收容所。
