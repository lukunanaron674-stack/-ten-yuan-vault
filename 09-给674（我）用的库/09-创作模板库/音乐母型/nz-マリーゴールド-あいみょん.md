# nz —克→ x，n —生→ nz — マリーゴールド / あいみょん

核心关系对子：**nz 克 x**（柔情压住欲望——"不想破坏这份美好"）

## 关系对子拆解

### 对子1：nz —克→ x（强度：弱）
**表现形式：** "想要更多"的占有冲动被nz轻轻盖住——不是不能要，是不舍得要。
**歌曲对应：** 副歌"このままでいい"（就这样就好）——欲望没有完全消失，但nz说"就这样就可以了"。
**强度判据：** 弱——x几乎不显形，但底层存在（夏末的酸涩感就是x的痕迹）。不是强克（激烈压制），是弱克（温柔包裹）。

### 对子2：n —生→ nz（强度：中）
**表现形式：** 日常的可爱（花/风/夏天的气味）唤醒了"不想结束"的守望感——不是凭空不舍，是日常太美了才不舍。
**歌曲对应：** 主歌铺日常（n）→ 副歌转不舍（nz）。n绽放，nz看着它绽放。
**强度判据：** 中——n生nz有力但不极端（不是残酷日常生出撕裂的守望）。

### 关系结构图

```
n（日常可爱）——生（中）——→ nz（不舍）
                                   ∣
                                   ∣ 克（弱）
                                   ↓
                                  x（想要）
```

## 模仿路径

想做nz温柔不舍型的歌：

1. **n先于nz入场** — 先铺日常（n）再转不舍（nz），让n生出nz
2. **欲望（x）不出声** — x只留下"尽头"的意象作为背景，不被歌词直接喊出来
3. **副歌末句做沉降** — 旋律从高往下滑，不要激烈抵抗，慢慢放手
