# 11｜平台标签与元数据层

> 生产母型回答“故事怎样运行”；平台标签回答“作品被放在哪个货架、卖给谁、以什么尺度发布”。两者不能混成同一层，否则“BL”“科幻”“喜剧”会和“契约婚姻”“回归复仇”争夺同一个分类位置，数据库很快就会长成一团礼貌的海带。

## 一、四层分类模型

| 层级 | 回答的问题 | 示例 |
|---|---|---|
| 生产母型 | 冲突怎样持续生成 | 契约婚姻、回归改命、证据追查 |
| 平台主标签 | 读者从什么类型入口发现作品 | 恋爱、动作、奇幻、悬疑、喜剧 |
| 世界观外壳 | 故事发生在什么时代和规则环境 | 现代都市、宫廷、西幻、武侠、末日 |
| 市场元数据 | 面向谁、什么分级、什么连载形式 | BL、GL、15+、18+、竖屏周更 |

## 二、平台主标签词表

```yaml
platform_genres:
  - romance       # 恋爱
  - drama         # 剧情
  - fantasy       # 奇幻
  - action        # 动作
  - comedy        # 喜剧
  - slice_of_life # 日常
  - healing       # 治愈
  - thriller      # 惊悚
  - horror        # 恐怖
  - mystery       # 悬疑
  - crime         # 犯罪
  - supernatural  # 超自然
  - sci_fi        # 科幻
  - historical    # 历史
  - sports        # 体育
  - martial_arts  # 武侠
  - workplace     # 职业
  - family        # 家庭
```

### 标签使用规则

1. 主标签最多三个，按“主入口、次入口、调味入口”排序。
2. 平台标签不代替生产母型。例如“奇幻”不能说明角色每话做什么。
3. 喜剧必须继续标明笑点发动机：误认、身份差、重复失败、规则反转、语言错位或关系尴尬。
4. 历史题材必须标明史实约束程度：史实改编、历史架空、时代借壳。
5. 科幻题材必须标明核心技术对象及其社会后果，不能只给现代办公室换一张霓虹背景。

## 三、关系取向与受众元数据

```yaml
relationship_orientation:
  - BG            # 男女关系主线
  - BL            # 男男关系主线
  - GL            # 女女关系主线
  - queer_mixed   # 多元性别或多种关系取向
  - non_romance   # 无恋爱主线
  - ensemble      # 群像、多关系并列
```

### 使用原则

- BL、GL是市场与关系取向标签，不自动等于某一种性格、攻受位置或权力结构。
- 同一“契约关系”“宿敌关系”“救命债”母型可以用于BG、BL、GL，具体差异来自社会环境、身体经验、公开风险与人物选择。
- 禁止用性别取向代替人物设计，例如把一方固定写成“女方功能”或把控制欲误写成天然浪漫。

## 四、世界观与时代外壳

```yaml
setting_shells:
  - contemporary_korea      # 韩国当代都市
  - contemporary_global     # 全球化现代都市
  - school                   # 校园
  - workplace                # 职场
  - entertainment_industry  # 娱乐产业
  - chaebol_family           # 财阀家族
  - korean_historical        # 韩国历史时代
  - chinese_martial_arts     # 武侠/门派
  - western_fantasy          # 西式奇幻
  - royal_court              # 皇室宫廷
  - dungeon_hunter           # 地下城猎人
  - apocalypse               # 末日
  - science_fiction          # 科幻社会
  - urban_supernatural       # 都市超自然
  - rural_healing            # 乡村疗愈
  - closed_facility          # 监狱、医院、研究所等封闭空间
```

每个外壳必须额外填写：

```yaml
setting_rules:
  authority_source:
  scarce_resource:
  entry_requirement:
  exit_cost:
  public_punishment:
  everyday_visual_objects:
```

## 五、内容分级

| 分级 | 可包含内容 | 必填说明 |
|---|---|---|
| all | 轻度冲突、无明显恐怖和性内容 | 无需额外说明 |
| 12_plus | 轻度暴力、校园冲突、暧昧 | 标记暴力或欺凌类型 |
| 15_plus | 中度暴力、犯罪、强烈关系压力、非露骨性暗示 | 标记胁迫、囚禁、跟踪等风险 |
| 18_plus | 成人性内容、严重暴力、性暴力、极端控制关系 | 必须使用[[013_AI用素材库/06B_韩漫题材对象行为库_十元分析版/14_伦理风险与内容分级]]审计 |

```yaml
content_rating: all / 12_plus / 15_plus / 18_plus
content_warnings:
  -
```

## 八、校验清单

```text
[ ] 平台标签与生产母型分开记录
[ ] BL/GL等取向标签没有被当作人物性格
[ ] 喜剧、历史、科幻均注明具体发动机或规则对象
[ ] 内容分级与警告完整
[ ] 世界观外壳具备权威、资源、准入和惩罚规则
[ ] 连载形式和预期篇幅可被检索
```
