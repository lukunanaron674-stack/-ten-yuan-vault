# 27｜韩漫Canvas逐节点十元覆盖审计

## 一、问题确认

上一版完成的是：

```text
生产输入
→ 十元分析
→ 主题与关系验证
→ 采矿回填
```

但这只是总流程接入十元。题材库、主体库、关系库、对象库、行为库等节点旁边没有自己的十元分析卡，工具节点也没有说明“库功能”和“作品内容”的边界，因此不能称为逐节点融合。

## 二、本轮处理

1. 重建 `韩漫题材对象行为库_十元分析总览.canvas`；
2. 27个唯一文件节点全部增加一对一十元分析卡；
3. 根节点、验证门槛、同步维护三个文字节点直接写入自身十元功能；
4. 四个Group标题写明系统功能与“不继承给内容”的限制；
5. 删除5个重复镜像节点：`ethics2`、`generator2`、`length2`、`deep2`、`fusion2`；
6. 新增 [[26_Canvas逐节点十元分析矩阵]] 作为文字正本；

## 四、关键修正

### 题材节点

```text
题材母型
→ 提出机制候选
→ 经人物、对象、行为和状态变化复验
→ 才能进入端点与生克补
```

### 行为节点

```text
攻击 ≠ zx
等待 ≠ nz
保护 ≠ zn
服从 ≠ nx
```

行为必须真实改变权限、认可、承载、流程、危险窗口等变量。

### 工具节点

索引、模板、审计、状态机、生成器等标记的是库功能，例如：

- 总控索引：`xn + x并z`；
- 模板：`x并z + xn`；
- 验证门槛：`x + z + xn`；
- 同步维护：`xn + x + x并z`。

这些功能禁止继承给作品人物。

### 主题节点

五大主题节点明确标为“主题层，不是一个十元对象”。十元共现不自动生成主题，主题生克另写主题端点。

## 五、新增维护规则

新增Canvas节点时必须同步增加十元分析卡。没有分析卡的节点标记：

```text
node_analysis_missing
```

同一文件若只是为了在不同区域展示，不再复制文件节点；使用连线回到唯一节点，避免同一文件出现多套分析。
