# 17｜十元分类总纲与判定规则

## 一、分类对象必须先分层

同一个韩漫条目至少拆成八层，禁止把它们揉成“这个题材是某十元”。

| 层 | 要回答的问题 | 例：契约婚姻 |
|---|---|---|
| 人物稳定本体 | 这个人物长期靠什么成立 | 男主可能是x，也可能是xn、zx或zn，不能由财阀身份决定 |
| 当前人物状态 | 此刻什么机制被抬高 | 害怕失去关系时可能出现nz状态 |
| 关键行为 | 这次动作在改变什么 | 签约偏xn；扣留证件偏x；公开承认偏z接口 |
| 关系位置 | 谁掌握退出、公开、资源与解释权 | 出资方常占x位置，被雇者可能掌握最终拒绝权 |
| 对象状态 | 合同、身份、秘密怎样变化 | 未建立→建立→受争议→解除→重新确认 |
| 场景 | 空间怎样容纳、分隔或展示主体 | 宴会是公开壳接口，家是承载空间 |
| 时间结构 | 期限、重复、等待、错过怎样运行 | 一年期限偏xn，临近到期产生xz风险 |
| 动态链 | 大感觉如何显影、转位与回收 | x并z壳建立→x控制升级→nz依恋显影→解除后重新选择 |

## 二、十元分类字段

```yaml
ten_yuan:
  target_layer: 人物 / 状态 / 行为 / 关系 / 对象 / 场景 / 时间
  primary: x
  secondary: [xn, x并z]
  unresolved: [nz]
  volume:
    x: 8
    xn: 6
    x并z: 5
  order: [xn, x并z, x, nz]
  evidence:
    - 具体行为
    - 对象变化
    - 关系权限变化
  counter_evidence:
    - 最近邻反例
  confidence: 结构候选 / 场景支持 / 作品复验 / 正本锁定
```

## 三、十元主骨的韩漫叙事接口

### `x`｜掌握边界

常见对象：股份、婚约、地盘、证件、账号、署名、武器、关系入口、监护权。

成立条件：必须写清谁实际掌握什么，以及该掌握如何限制他人使用、进入、退出或归因。

不成立：只是喜欢、想要、嫉妒、富有或身份高。

### `zx`｜公开权能显现与扩大

常见对象：排名、战力、职位、舞台成果、公开胜负、制度决定权。

成立条件：主体能力真实改变客观世界，并在公共界面上扩大、压过或重新分配他者的位置。

不成立：单纯显眼、穿得张扬、说话霸气。

### `xn`｜主动组织运行

常见对象：计划、合同、课程、赛程、规则、时间节点、资源流程、证据链。

成立条件：主体主动确定方向与结构，使多个行动跨时间持续运行。

不成立：只是遵守规则；那可能是nx关系功能。

### `nx`｜沿既有通道推进

常见对象：家族安排、系统任务、组织许可、人情网络、上级流程、既定身份。

成立条件：方向决定权不在主体，主体借用或沿着已有关系、权限与流程做成事情。

不成立：软弱、没主见、被动受害。强者也可以使用nx功能。

### `x并z`｜壳、表里分层与公共接口

常见对象：假婚身份、艺人人设、卧底身份、贵族礼法、品牌、制服、账号人格、身体交换。

成立条件：表层壳与内部真实存在结构性间隙，而且壳本身承担保护、代表、展示或准入功能。

不成立：一次撒谎、单纯换装、普通秘密。

### `zn`｜意义与精神主体

常见对象：正义、创作意义、职业伦理、革命信念、不可背弃的自我定义。

成立条件：即使没有奖励、认可或好结果，主体仍因“不这样就不是我”而行动。

不成立：善良、热血、正确价值观、宏大台词。

### `z`｜认可主体的确认

常见对象：作品、能力、身份、选择、发现、外貌与完整精神存在。

成立条件：必须写清谁认可、认可什么、为什么这个认可位置重要。

不成立：舞台、聚光灯、执念、努力、目标本身。

### `n`｜接住与承载

常见对象：家庭成员、任务、病人、灾民、团队负荷、住所、共同生活。

成立条件：事情落下→主体接住→内部消化处理→不转嫁。

不成立：单纯挨打、忍耐、善良、稳定。

### `nz`｜柔情停靠与不想结束

常见对象：旧爱、临时家庭、旧房、共同生活、等待位置、余温与归宿。

成立条件：核心不是得到对方，而是维持一段已经发生过的温度，不想承认它结束。

不成立：追逐目标、强占关系、纯粹被动等待。

### `xz`｜危险显身与命运临界

常见对象：追杀、怪物、倒计时、末班车、逃生路径、身份暴露、处刑结局、错过窗口。

成立条件：危险可感知地逼近，退路与时间窗缩窄，主体必须在边界上行动。

不成立：暗色、惨、废墟、悲伤或普通风险。

## 四、主辅十元判定

```text
主十元：删除它，当前结构的发动机失效。
辅十元：删除它，结构仍运行，但质感、方向或落点显著改变。
状态十元：只在某个阶段抬高，不等于人物稳定本体。
落点十元：结算时成为最终感觉，但不能倒推起手。
```

例：恶役千金改命

```text
起手：xz（处刑结局逼近）
方法：xn（提前组织资源与节点）
界面：x并z（恶役身份壳与真实行为冲突）
核心候选：zn（不再按原剧本道德评价活）
关系落点：z或nz，取决于结局是获得确认还是保留关系
```

## 五、体量与顺序

### 体量

| 体量 | 含义 |
|---:|---|
| 1—2 | 背景痕迹，不驱动行为 |
| 3—4 | 局部状态或辅助功能 |
| 5—6 | 稳定副机制 |
| 7—8 | 主驱动或关键阶段 |
| 9—10 | 压倒性主骨，决定全局选择 |

### 顺序

顺序记录“谁先显影、谁接管、谁结算”，不记录普通事件流水账。

```text
错误：签合同→吃饭→宴会→吵架→分手
正确：xn组织绑定→x并z建立公共壳→x越界掌握→nz关系余温上升→zn/x重新定义关系边界
```

## 六、十元分析的最低证据

至少具备以下三项中的两项：

1. 可观察行为功能。
2. 对象状态前后变化。
3. 权限、关系或认可位置变化。

人物稳定本体还需要：

- 跨多个阶段重复出现；
- 在重大代价下仍保持；
- 与最近邻十元有反证比较；
- 不能只靠职业、视觉或一句台词。

## 七、题材分类的正确用法

本库的题材分类只用于：

- 为创作选择可用机制；
- 预测容易出现的对象与行为；
- 建立作品采矿假设；
- 检查某个十元是否缺少题材血肉。

不得用于：

- 看到“财阀”就判x人物；
- 看到“恶役”就判x并z人物；
- 看到“疗愈”就判n或nz；
- 看到“复仇”就判zx；
- 看到“系统”就判xn；
- 从结局的温暖反推开头一定是nz。
