# 64题材完全节点化十元重构协议

## 一、什么才算“节点化十元重构”

不是：

```text
题材节点
→ 旁边写一句主十元
```

而是每个题材必须拆成一条可运行、可反证、可回填的节点链：

```text
题材入口
→ 对象
→ 主体位置
→ 关系与权限
→ 触发行为
→ 对象前后状态
→ 十元端点
→ 生克补机制
→ 动态链
→ 五大主题显影
→ 反证
→ 输出
```

64个题材全部使用这一结构。缺少任一节点，标记 `topic_node_incomplete`。

## 二、节点判定规则

1. **题材名不继承十元。** 题材只提供机制假设。
2. **主体、对象、关系分层。** 人物稳定本体、阶段状态和关系功能不得混写。
3. **动词不继承十元。** 攻击、等待、照料、服从等必须通过被改变变量判定。
4. **状态先于关系结论。** 没有对象前后状态，不写生克补成立。
5. **生克补必须有方向。** 写源端点、目标端点、启动机制、被改变变量、阶段、体量、顺序和第三因素。
6. **动态链逐段重判。** 辅助十元可以接管主驱动；禁止题材标签从头固定到尾。
7. **主题层后置。** 十元共现不自动生成时间、本体、空间、因果、命运。
8. **反证为必填节点。** 拿掉测试、最近邻误判和主辅重分配必须保留。

## 三、完整节点字段

| 节点 | 必填字段 |
|---|---|
| 题材入口 | ID、题材名、主辅候选、结论等级 |
| 对象 | 核心对象、控制者、准入、可见性、替代性 |
| 主体 | 稳定本体、阶段状态、关系功能 |
| 关系权限 | 定义权、退出权、资源权、解释权、承载与认可 |
| 触发行为 | 行动者、对象、目的、回应、收益、代价 |
| 状态转换 | 前态、触发、后态、不可逆变量 |
| 十元端点 | 源端点、目标端点、主辅、体量、顺序 |
| 生克补 | 方向、机制、变量、阶段、第三因素 |
| 动态链 | 起手、接管、冲突、结算、稳定锚点 |
| 主题显影 | 构成对、0—3级、中心问题与结局证据 |
| 反证 | 误判、拿掉测试、反向测试、替代解释 |
| 输出 | 场景、人物、关系、行为链、证据卡 |

## 四、验收

- 64题材全部拥有12节点。
- 每个分类Canvas拥有8个题材Group。
- 总Canvas只负责导航，不替代分类Canvas中的实际节点。
- 原R3通过备份分支完整保留。
