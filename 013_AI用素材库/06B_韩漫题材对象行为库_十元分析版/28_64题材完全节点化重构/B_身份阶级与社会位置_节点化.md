# B｜身份阶级与社会位置

> 这页不是“豪门、贵族、娱乐圈题材清单”。
>
> 它真正研究的是：**一个人被叫作谁、能进入哪里、能控制什么、由谁承认，以及这些社会位置怎样发生变化。**
>
> 本页是题材运行骨架，不是十元理论正本。题材名不能直接继承十元，具体案例仍需回填人物、阶段、体量、顺序、第三因素与反证。

---

# 一｜先看懂本页常用名词

| 名词 | 白话解释 | 判断时要问什么 |
|---|---|---|
| **题材** | 一类常见故事外壳，例如“财阀继承”或“底层逆袭” | 这个外壳里真正被改变的东西是什么？ |
| **主对象** | 本题材当前最核心、能够记录前后变化的对象 | 到底是哪一项资格、资源、权限或关系位置发生了变化？ |
| **关联对象** | 与主对象有关，但不能混成同一个变量的其他对象 | 股份、职位、称号、证据、名誉分别发生了什么？ |
| **主体** | 在这条关系中行动、控制、确认、承载或被影响的人／机构 | 谁在做事？谁在决定？谁在承认？ |
| **稳定本体** | 人物跨阶段较稳定的内在倾向，不是一次行为 | 这是长期成立，还是这一刻临时如此？ |
| **阶段状态** | 人物在某一阶段暂时处于的状态 | 他现在失势、服从、被误认，不代表永远如此。 |
| **关系功能** | 人物在当前关系里承担的作用 | 他是控制者、认可者、承载者、保护者还是被采用者？ |
| **权限** | 谁可以定义、退出、调用、调配、否决或解释 | 谁拥有最后决定权？谁能拒绝？谁能把别人挡在外面？ |
| **准入** | 谁被允许进入某个圈子、资源、职位或关系位置 | 谁能进董事会、舞会、皇位继承序列或公众视野？ |
| **公共壳** | 世界可以识别、调用和持续指认的名称、职位、身份或界面 | 这个称号是否真的承担识别、代表、准入或保护功能？ |
| **认可主体** | 能够确认某人存在、能力、作品、身份或选择的重要位置 | 谁认可？认可什么？为什么这个人的认可重要？ |
| **控制入口** | 进入资源、传播、署名、证据、职位或关系所必经的接口 | 谁掌握发布权、推荐权、表决权、证据或诏令？ |
| **十元端点** | 某一阶段真正成立的十元位置 | 这一阶段究竟是掌握、认可、组织、显权还是公共壳在主导？ |
| **主十元** | 当前阶段最主要的驱动力 | 哪个十元最直接改变了核心变量？ |
| **辅十元** | 同时存在、但尚未主导的辅助位置 | 它是否会在下一阶段接管？ |
| **接管** | 故事进入下一阶段后，主导十元发生变化 | 什么时候从“身份争议”转成“控制权争夺”？ |
| **被改变变量** | 能观察到的真实变化，不是抽象感觉 | 表决权、署名、准入、确认范围、控制范围到底变了多少？ |
| **第三因素** | 可能真正造成变化的其他原因 | 是十元关系导致的，还是法律、职位、暴力、运气、制度本来就如此？ |
| **稳定锚点** | 一轮变化结束后，暂时维持局面的核心位置 | 最终靠什么稳定：真实控制、公共名位、关系认可还是持续组织？ |
| **反证** | 用来证明“不能这样判”的失败条件 | 拿掉这个十元后，结果还会不会发生？ |

# 二｜十元便读词典

> 下表中的中文名是本页为了阅读方便使用的“便读名”，不是重新发明十元定义。正式判断仍以十元信息卡、准度卡与关系卡为准。

| 十元 | 本页便读名 | 核心解释 | 在B区常见表现 |
|---|---|---|---|
| **x** | **掌握边界** | 对象、资源、地盘、权限或关系真正归某主体掌握，能够调用、调配、否决或限制别人 | 股份、军权、表决权、发布权、署名权、婚约资源 |
| **z** | **认可确认** | 重要认可主体看见、回应并确认某人的存在、能力、作品、身份或选择 | 董事会确认继承资格、公众确认艺人作品、家族承认身份 |
| **zx** | **公开显权** | 主体的权能公开显现、扩大并凌驾于他者之上，使环境围绕其力量重新反应 | 公开罢免、强势裁决、政变后发号施令、当众夺权 |
| **xn** | **持续组织** | 主体主动组织时间、流程、规则、信息、资源和节点，使结构能够持续运行 | 董事会流程、长期复仇计划、行政体系、创业运营结构 |
| **nx** | **方向让位／沿既有通道** | 主体不占据本可拥有的最终方向位置，沿别人、关系、流程、秩序或现状给出的方向推进 | 被动按投资人方向行动、长期把决定权交给家族或伴侣 |
| **n** | **内部承载** | 对象真实进入内部，被允许留下，并被跨阶段接收、处理和承担负荷 | 团队长期接住成员与任务、家族内部持续安置某人 |
| **zn** | **内部意义／原则** | 不可轻易让渡的内部意义、原则正确性与未来最终指导资格 | “什么不能被牺牲”“我为何必须守住这个身份或对象” |
| **nz** | **关系停靠／回返** | 对象特异的可信停靠、自由退出、冲突后修复与可回返位置 | 即使身份变化，仍存在可以回去的关系与归属 |
| **xz** | **临界风险** | 危险持续逼近，压缩安全距离、退路、时间窗或可逆空间 | 政变倒计时、身份暴露、逃亡窗口关闭、退路越来越少 |
| **x并z** | **公共身份壳／公开界面** | 稳定公共壳使对象可识别、调用、归因、代表、进入或被保护 | “继承人”“皇帝”“贵族小姐”“艺人品牌”“法人职位” |

## 本区最常用的六个十元

```text
x（掌握边界）
z（认可确认）
zx（公开显权）
xn（持续组织）
x并z（公共身份壳）
zn（内部意义／原则）
```

其中最容易混淆的是：

- **有钱不等于 x（掌握边界）**：必须能真实调用、调配、否决或限制。
- **出名不等于 z（认可确认）**：必须写清谁认可、认可什么、为什么重要。
- **打脸不等于 zx（公开显权）**：必须有公开权能扩大，而不只是别人惊讶。
- **忙碌不等于 xn（持续组织）**：必须是主体主动建立可持续结构。
- **称号不等于 x并z（公共身份壳）**：称号必须承担识别、准入、代表或保护功能。
- **坚持自我不等于 zn（内部意义）**：必须出现不可轻易让渡的原则和最终指导资格。

# 三｜生、克、补怎么读

| 关系 | 白话解释 | 不能误解成什么 |
|---|---|---|
| **A 生 B** | A 的运行使 B 出现或上升 | 不是只要A先发生，B后来出现就算“生” |
| **A 克 B** | A 使 B 的核心变量下降、失效或无法运行 | 不是两个人吵架、对立或胜负就算“克” |
| **A 补 B** | A和B都各自成立，A补足B原本缺失的一部分 | 不是A自动生成B，也不是两者同时出现就算“补” |

本页常用关系的白话读法：

- **x（掌握边界）生 x并z（公共身份壳）**：真实控制已经成立，为了让世界能够识别、调用和代表它，形成职位、名称、品牌或正式身份。
- **x并z（公共身份壳）生 z（认可确认）**：稳定可识别的身份或作品界面，让认可主体终于能够看见并正确归因。
- **x（掌握边界）克 z（认可确认）**：有人控制了发布、署名、证据、引见或传播入口，使正确认可无法发生。
- **xn（持续组织）克 zx（公开显权）**：长期规则、程序和前置组织限制一次性的强势显权，单次爆发不能取消长期结构。
- **xn（持续组织）补 z（认可确认）**：长期组织提供可复核、可重复的证据，让认可不只落在偶然表现上。
- **z（认可确认）补 xn（持续组织）**：明确的认可对象和确认节点，为长期组织提供聚焦、筛选标准和阶段收束。
- **n（内部承载）生 xn（持续组织）**：内部已真实接住反复负荷，临场处理不够，主体才把经验整理为流程和长期结构。

# 四｜12节点到底在问什么

| 节点 | 白话问题 |
|---|---|
| **0 入口** | 这个题材一开始最可能由哪个十元主导？只是候选，不是结论。 |
| **1 对象** | 故事里真正被争夺、确认或改变的核心东西是什么？ |
| **2 主体** | 谁行动、谁控制、谁确认、谁承载、谁被影响？ |
| **3 关系** | 谁拥有什么权限？谁在关系里承担什么功能？ |
| **4 触发** | 哪个具体行动使局面开始变化？ |
| **5 状态** | 变化前是什么，变化后是什么，哪项变量无法轻易恢复？ |
| **6 端点** | 每个阶段实际成立的是哪个十元？谁主谁辅？ |
| **7 生克补** | 两个已成立端点之间，究竟发生了生成、压制还是补位？ |
| **8 动态链** | 哪个对子在什么条件下推动、改写或接管另一个对子？ |
| **9 主题** | 这是否真的成为时间、本体、空间、因果或命运的中心问题？ |
| **10 反证** | 哪些表面现象不能证明这个判断？ |
| **11 输出** | 最后能沉淀成哪些可复用卡片？ |

# 五｜八个题材

## T-B01｜财阀继承

### 一句话看懂

财阀继承不是“谁更有钱”，而是：**谁真正拥有表决、否决、调配资源和代表企业的权力。**

### 本题材十元速查

- **x（掌握边界）**：股份背后的实际表决权、否决权、资金调用权和人事控制权。
- **x并z（公共身份壳）**：“继承人”“董事长”“法人代表”等可被社会和机构调用的正式身份。
- **z（认可确认）**：董事会、家族、员工或公众是否确认其继承资格与代表身份。
- **xn（持续组织）**：章程、董事会程序、继承安排和长期经营结构。
- **zx（公开显权）**：公开罢免、夺权、命令全体服从等凌驾性显权行为。

### 12节点

- **0 入口｜初始候选**：主 `x（掌握边界）`；辅 `zx（公开显权）`、`xn（持续组织）`、`x并z（公共身份壳）`。只是初始候选，需逐阶段重判。
- **1 对象｜真正争什么**：
  - 主对象：企业表决权与实际控制范围。
  - 关联对象：股份、职位、继承资格、婚约接口与处置权限。它们彼此相关，但不能混成一个“权力”。
- **2 主体｜谁在什么位置**：继承候选人、现掌权者、董事会、家族确认机构、员工与公众。要分清谁控制、谁确认、谁只是旁观。
- **3 关系｜谁有何权**：谁定义继承资格，谁能否决方案，谁调配资源，谁解释章程，谁承担企业持续运行，谁确认公共身份。
- **4 触发｜什么时候开始变**：继承资格被争夺、掌权者失能、董事会倒戈或出现权力真空。
- **5 状态｜前后发生什么**：名义继承资格存在 → 实际表决和调用权被争夺 → 控制范围与正式职位重新分配。重点观察表决权、否决权、资金调用权和对外代表权。
- **6 端点｜阶段重判**：
  - 阶段A：资格被讨论，`x并z（公共身份壳）` 与 `z（认可确认）` 显影。
  - 阶段B：资源、表决和否决权进入争夺，`x（掌握边界）` 接管。
  - 阶段C：真实控制需要对外被识别，重新形成 `x并z（公共身份壳）`。
- **7 生克补｜关系怎么读**：
  - `x（掌握边界）生 x并z（公共身份壳）`：真实控制先成立，随后生成董事长、法人或继承人等正式接口。
  - `xn（持续组织）克 zx（公开显权）`：章程和长期程序限制某人一次性强势夺权。
  - 两者虽有现行关系语义，本题材仍须用具体案例证明。
- **8 动态链**：
  - **白话链**：名义资格被质疑 → 权力争夺启动 → 一方取得真实控制 → 为了对外调用和代表，建立正式职位与身份。
  - **十元链**：`x并z（资格壳）/z（资格确认）` → **控制权争夺** → `x（掌握边界）接管` → **对外调用需要** → `x生x并z`。
  - **被改变变量**：表决、否决、资金调用、任免和代表范围。
  - **稳定锚点**：真实控制与正式职位是否重新统一。
- **9 主题**：只有长期组织与最终确认节点成为整部故事的中心问题时，才可登记时间主题候选。
- **10 反证**：有钱、持股、被称为继承人都不自动是 `x（掌握边界）`。没有调用、调配、否决或限制边界，主x不成立。
- **11 输出**：控制边界卡｜继承资格卡｜董事会权限卡｜公共职位壳卡｜动态链卡｜反证卡。

## T-B02｜真假继承人

### 一句话看懂

真假继承人不是单纯“谁的DNA是真的”，而是：**哪个身份壳被家族和制度采用，谁因此获得准入、资源与关系位置。**

### 本题材十元速查

- **x并z（公共身份壳）**：姓名、家族身份、继承人称号等可识别和可调用的身份界面。
- **z（认可确认）**：家族、机构或重要人物确认“你是谁”。
- **x（掌握边界）**：谁控制证据、财产入口、档案、检测报告和资源准入。
- **zn（内部意义／原则）**：主体对“真正的我是谁、什么不能被替换”的内部意义判断。

### 12节点

- **0 入口**：主 `x并z（公共身份壳）`；辅 `x（掌握边界）`、`z（认可确认）`、`zn（内部意义）`。
- **1 对象**：
  - 主对象：承担公共识别和准入功能的身份壳。
  - 关联对象：姓名、血统凭证、财产入口、家族称谓与真实自我。
- **2 主体**：真假继承人、家族确认者、证据持有者、资源控制者。必须把“客观上是谁”和“被家族采用成谁”分开。
- **3 关系**：谁定义身份，谁控制证据，谁决定财产准入，谁确认亲属关系，谁维持当前公共壳。
- **4 触发**：凭证出现、身份被质疑、检测结果公开、确认主体改口或证据入口被控制。
- **5 状态**：错误身份壳稳定运行 → 证据使公共壳与内部真实分裂 → 不同确认主体分别改判或拒绝改判 → 资源和关系位置重新归因。
- **6 端点**：
  - 阶段A：`x并z（公共身份壳）` 主导识别与准入。
  - 阶段B：`x（证据和入口控制）` 与 `z（确认结论）` 分账。
  - 阶段C：是否形成新的公共身份壳，再检查 `x生x并z` 与 `x并z生z`。
- **7 生克补**：
  - `x并z（公共身份壳）生 z（认可确认）`：稳定身份界面让认可主体获得可指认对象。
  - `x（掌握边界）生 x并z（公共身份壳）`：资源和资格的实际掌握生成正式身份接口。
  - `x（掌握边界）克 z（认可确认）`：控制证据或确认入口，使正确身份无法被承认。
  - `x补zn` 仅作候选，不能因为出现“真实自我”四个字就自动调用。
- **8 动态链**：
  - **白话链**：旧身份被采用 → 新证据出现 → 证据控制和身份确认分裂 → 旧壳维持或失效 → 新壳重建，或多个主体长期持有不同确认。
  - **十元链**：`x并z（旧公共壳）` → **证据冲突** → `x（证据入口） + z（确认结论）` 分账 → 新 `x并z` 或确认分裂。
  - **被改变变量**：姓名采用、财产准入、家族角色、公开档案与关系称谓。
  - **稳定锚点**：哪一个身份最终被制度、家族和资源接口持续采用。
- **9 主题**：只有“真实自我、现实掌握与公共身份壳”持续成为中心问题，才可登记本体主题候选。
- **10 反证**：秘密、DNA、换名、真假反转不自动是 `x并z（公共身份壳）`。身份必须真实承担识别、准入或关系角色。
- **11 输出**：身份壳卡｜确认主体分账卡｜证据入口卡｜资源准入卡｜多重确认卡｜反证卡。

## T-B03｜豪门复仇

### 一句话看懂

豪门复仇不是“主角终于打脸”，而是：**曾被夺走的资源、署名、证据和控制边界，如何经过长期组织被重新夺回。**

### 本题材十元速查

- **x（掌握边界）**：被夺走或准备夺回的股份、证据、渠道、署名与继承权。
- **xn（持续组织）**：长期调查、资源安排、盟友组织与行动节点。
- **zx（公开显权）**：在公开场合直接夺权、裁决或让对手失去支配位置。
- **z（认可确认）**：公众、机构或重要人物重新确认真相、署名、责任与身份。

### 12节点

- **0 入口**：主 `x（掌握边界）`；辅 `xn（持续组织）`、`zx（公开显权）`、`z（认可确认）`。
- **1 对象**：
  - 主对象：被夺取且能够重新掌握的具体边界。
  - 关联对象：股份、证据、渠道、署名和继承权。每个案例必须选一个主对象。
- **2 主体**：被夺者、豪门控制者、盟友、公众与机构确认者。夺回者、控制入口者和认可主体必须分开。
- **3 关系**：谁控制证据和渠道，谁拥有退出与否决权，谁解释旧案，谁确认署名、责任与身份。
- **4 触发**：旧案证据重现、被害者回归、内部盟友出现或现掌权者暴露漏洞。
- **5 状态**：掌握边界丧失 → 证据和资源被组织 → 控制权或署名入口被夺回 → 公众和机构是否改判另作z分账。
- **6 端点**：
  - 失去阶段：`x（掌握边界）` 下降。
  - 组织阶段：若主体主动建立持续计划，`xn（持续组织）` 接管。
  - 公开反击阶段：若直接公开扩大权能，`zx（公开显权）` 可短暂接管。
  - 结算阶段：分别检查 `x（掌握恢复）` 和 `z（认可恢复）`。
- **7 生克补**：
  - `x克z`、`xn克zx`、`xn补z`、`z补xn` 都必须逐段证明，不能因为复仇成功就整套套上。
  - `xn补z` 指长期组织为最终确认提供可复核证据；`z补xn` 指最终认可节点为长期行动提供聚焦和收束。
- **8 动态链**：
  - **白话链**：控制被夺 → 主体长期组织证据与盟友 → 公开行动窗口出现 → 夺回具体入口 → 机构或公众重新确认。
  - **十元链**：`x↓` → **长期组织启动** → `xn接管` → **公开窗口** → `zx可接管` → `x恢复` → `z确认或拒绝`。
  - **被改变变量**：股份、署名、证据可见性、渠道控制、机构采用与公众归因。
  - **稳定锚点**：夺回的控制是否真实持续，以及确认是否落在正确主体上。
- **9 主题**：长期组织与最终确认共同构成中心问题时，可登记时间主题候选。
- **10 反证**：复仇情绪、对手失败、观众爽感和一句狠话都不自动是 `zx（公开显权）`。
- **11 输出**：被夺对象卡｜计划结构卡｜公开显权卡｜控制恢复卡｜认可分账卡｜反证卡。

## T-B04｜娱乐圈上位

### 一句话看懂

娱乐圈上位不是“流量变高”，而是：**作品、能力或身份是否进入了真正重要的认可位置，并被正确看见和归因。**

### 本题材十元速查

- **z（认可确认）**：导演、编辑、观众、奖项机构或某个重要人物确认作品和能力。
- **x并z（公共身份壳）**：作品形式、艺人人设、署名、品牌和可识别的公开界面。
- **x（掌握边界）**：发布、推荐、引见、署名和传播入口。
- **zx（公开显权）**：主体通过公开行动扩大行业权能，而不只是被看见。

### 12节点

- **0 入口**：主 `z（认可确认）`；辅 `x并z（公共身份壳）`、`zx（公开显权）`、`x（掌握边界）`。
- **1 对象**：
  - 主对象：被具体认可主体确认的作品、能力、身份或选择。
  - 关联对象：人设壳、曝光渠道、署名、评价和商业资源。流量不能吞掉全部对象。
- **2 主体**：艺人或创作者、个人认可者、专业群体、公众、机构、资本平台与渠道控制者。不同认可主体必须分账。
- **3 关系**：谁控制发布、署名、推荐、引见与解释入口；谁认可什么；该认可位置为什么重要；采用范围和阶段是什么。
- **4 触发**：作品发布、试镜、奖项评选、舆论危机、竞争舞台或关键人物看见作品。
- **5 状态**：作品未进入目标认可位置 → 获得可识别形式和正确归因接口 → 认可主体确认、误认或拒绝 → 渠道控制与认可结果分别结算。
- **6 端点**：
  - 作品、人设或品牌形成可识别界面：`x并z（公共身份壳）`。
  - 特定主体确认作品、能力或身份：`z（认可确认）`。
  - 掌握署名、推荐和发布入口：`x（掌握边界）`。
  - 主体公开扩张权能：另查 `zx（公开显权）`。
- **7 生克补**：
  - `x并z生z`：作品和身份界面让目标认可主体能够看见并正确归因。
  - `x生x并z`：掌握作品和渠道后形成可持续的品牌、职位或公开身份。
  - `x克z`：控制发布、署名或引见入口，使正确认可被阻断或冒领。
- **8 动态链**：
  - **白话链**：作品形成明确界面 → 进入特定认可位置 → 被正确确认；若渠道或署名被控制，则认可被阻断；若主体公开扩权，另开显权分支。
  - **十元链**：`x并z（作品/身份壳）` → **进入目标认可位置** → `z（具体确认）`；旁支：`x克z` 或 `zx分支`。
  - **被改变变量**：作品可识别性、署名归因、目标认可者接触概率、机构采用和公众确认范围。
  - **稳定锚点**：认可是否落在正确主体和正确作品上，而不是只剩流量。
- **9 主题**：长期训练与专业确认共同成为中心问题时，可登记时间主题候选。
- **10 反证**：热搜、播放量、粉丝尖叫、广告投放和大众看见都不自动是 `z（认可确认）`。
- **11 输出**：认可主体分账卡｜作品壳卡｜渠道控制卡｜署名归因卡｜显权分支卡｜反证卡。

## T-B05｜商战创业

### 一句话看懂

商战创业不是“努力赚钱”，而是：**谁主动把产品、团队、资金和流程组织成可以持续运行的结构。**

### 本题材十元速查

- **xn（持续组织）**：主动安排时间、流程、信息、资源和节点，使公司能够继续运行。
- **x（掌握边界）**：股权、资金、产权、渠道、否决权和市场入口。
- **zx（公开显权）**：公开处置、强势并购、压制竞争者或扩大行业支配力。
- **n（内部承载）**：团队真实接住成员、客户、任务和反复负荷。
- **nx（方向让位）**：创业者或团队长期不占方向决定位置，只沿投资人、平台或现状推进。

### 12节点

- **0 入口**：主 `xn（持续组织）`；辅 `zx（公开显权）`、`x（掌握边界）`、`n（内部承载）`。职业经营机制还需H区复核。
- **1 对象**：
  - 主对象：主体主动组织并持续运行的产品、流程或市场结构。
  - 关联对象：资金、团队承载、产权、渠道和市场入口。
- **2 主体**：创业者、团队、投资人、竞争者、客户或市场采用主体。组织者、承载者、控制者和显权者必须分开。
- **3 关系**：谁组织时间与流程，谁掌握资金和产权，谁承担内部负荷，谁能公开处置，谁确认产品被采用。
- **4 触发**：机会窗口、资金危机、产品失败、团队扩张或市场规则改变。
- **5 状态**：零散行动 → 主体主动组织时间、规则、信息与资源 → 产品或团队持续运行／失败 → 市场采用、产权掌握和公开权能分别结算。
- **6 端点**：
  - 主动建立持续结构：`xn（持续组织）`。
  - 掌握资金、股权、渠道或否决权：`x（掌握边界）`。
  - 公开处置并扩大支配：`zx（公开显权）`。
  - 团队真实接住反复负荷：`n（内部承载）`。
  - 主体把方向持续让给投资人或平台：检查 `nx（方向让位）`。
- **7 生克补**：
  - `xn克zx`：长期流程和制度限制一次性的强势显权。
  - `zx克n`：公开权能改变接收、保护或成员资格，使团队承载能力下降。
  - `n生xn` 不能默认调用。只有团队先真实承载反复负荷，随后为继续承载而主动流程化，才成立。
- **8 动态链**：
  - **白话链**：零散尝试 → 主动建立持续组织 → 分别形成产权控制、团队承载或公开显权 → 若承载负荷反复出现，再形成承载推动组织化的回路。
  - **十元链**：`零散行动` → `xn（持续组织）` → `x / n / zx` 分支；仅在条件成立时 `n生xn`。
  - **被改变变量**：流程稳定度、资金调用、产权边界、团队负荷、市场采用和方向决定权。
  - **稳定锚点**：公司靠主动组织持续，还是靠一时融资、个人强压或外部指令维持。
- **9 主题**：若中心问题是职业现实和行业经营，转H区；若是长期组织与认可节点，可登记时间候选。
- **10 反证**：忙碌、加班、融资、营收增长和执行已有制度都不自动是 `xn（持续组织）`。被动按投资人方向行动可能是 `nx（方向让位）`。
- **11 输出**：主动组织卡｜产权卡｜团队承载卡｜显权卡｜市场采用卡｜方向决定权卡。

## T-B06｜贵族社交

### 一句话看懂

贵族社交不是“穿华服参加舞会”，而是：**礼法身份如何决定谁被看见、谁能进入圈层、谁有资格结婚和代表家族。**

### 本题材十元速查

- **x并z（公共身份壳）**：爵位、称呼、礼法、家族名号和舞会社交身份。
- **z（认可确认）**：社交圈、家族或重要人物确认某人的名誉、身份和选择。
- **x（掌握边界）**：家族掌握婚约、资源、邀请、名誉解释和准入入口。
- **xn（持续组织）**：主动组织并持续维护的礼法、仪式、社交流程和家族秩序。

### 12节点

- **0 入口**：主 `x并z（公共身份壳）`；辅 `z（认可确认）`、`x（掌握边界）`、`xn（持续组织）`。
- **1 对象**：
  - 主对象：承担公共识别和社交准入功能的礼法身份壳。
  - 关联对象：爵位、称呼、婚约、名誉、邀请入口与家族资源。
- **2 主体**：贵族主体、社交圈认可者、礼法与家族机构、资源控制者。被识别者、确认者和入口控制者必须分开。
- **3 关系**：谁定义称谓和资格，谁决定准入与退出，谁控制婚约和资源，谁认可名誉，谁主动维护礼法结构。
- **4 触发**：舞会、婚约宣布、丑闻、称谓争议、家族除名或重新接纳。
- **5 状态**：公共壳决定识别和准入 → 内部意图、关系事实或资源边界与壳冲突 → 认可主体和控制者分别重排。
- **6 端点**：
  - 礼法壳承担识别和准入：`x并z（公共身份壳）`。
  - 某主体确认名誉、身份或选择：`z（认可确认）`。
  - 家族掌握婚约、资源和邀请入口：`x（掌握边界）`。
  - 主体主动维护长期礼法结构：`xn（持续组织）`，被动守礼不算。
- **7 生克补**：
  - `x并z生z`：礼法身份壳使认可主体获得明确的识别对象。
  - `x生x并z`：家族真实掌握资源与关系后，形成爵位、名号与正式社交接口。
  - `x克z`：控制邀请、名誉解释和婚约入口，使正确认可无法发生。
  - `z补xn` 必须证明认可节点确实改变长期礼法组织的聚焦和收束。
- **8 动态链**：
  - **白话链**：礼法壳决定谁能进入 → 名誉或准入发生争议 → 资源控制和身份认可分开变化 → 礼法壳被维持、撕裂或重建。
  - **十元链**：`x并z（礼法壳）` → **准入/名誉争议** → `x（入口控制） + z（认可确认）` 分账 → `xn` 另判 → 壳维持或重建。
  - **被改变变量**：邀请资格、婚约资格、称谓、名誉采用、家族资源和对外代表权。
  - **稳定锚点**：新的礼法壳是否仍被圈层持续采用。
- **9 主题**：礼法结构与认可节点共同成为中心问题时，可登记时间主题候选。
- **10 反证**：华服、舞会、礼貌、称呼和古典视觉都不自动是 `x并z（公共身份壳）`。
- **11 输出**：礼法壳卡｜准入卡｜名誉确认卡｜婚约控制卡｜组织结构卡｜反证卡。

## T-B07｜宫廷继承

### 一句话看懂

宫廷继承不是“谁坐上皇位”，而是：**名位、军权、任免权、诏令执行权和官僚接口是否真正统一。**

### 本题材十元速查

- **x（掌握边界）**：军权、任免、诏令执行、财政和最终处置边界。
- **x并z（公共身份壳）**：皇位名号、血统身份、正式继承人和君主名位。
- **zx（公开显权）**：公开裁决、政变夺权、当众处置反对者和直接发号施令。
- **xn（持续组织）**：行政程序、官僚体系、继承安排和长期治理结构。
- **z（认可确认）**：宗法、官僚、军队或公众是否确认某人具有君主资格。

### 12节点

- **0 入口**：主 `x（掌握边界）`；辅 `zx（公开显权）`、`xn（持续组织）`、`x并z（公共身份壳）`。
- **1 对象**：
  - 主对象：军权、任免权、诏令执行权或最终处置边界，案例必须选择其一。
  - 关联对象：皇位名号、血统壳、诏书、派系和官僚接口。
- **2 主体**：继承者、现君主、竞争者、军队、官僚与宗法确认机构。实际控制者与名位确认者必须分开。
- **3 关系**：谁掌握军队和任免，谁解释诏书，谁确认名位，谁组织行政流程，谁能公开处置他者。
- **4 触发**：君主病危、诏书争议、政变、军权转移、官僚倒戈或继承仪式中断。
- **5 状态**：资格和名位争议 → 派系、军权与官僚接口重新组织 → 实际控制和公共名位可能统一，也可能长期分裂。
- **6 端点**：
  - 皇位与血统名位：`x并z（公共身份壳）`。
  - 军权、任免和处置范围：`x（掌握边界）`。
  - 公开夺权与凌驾裁决：`zx（公开显权）`。
  - 行政、程序和长期治理：`xn（持续组织）`。
  - 宗法和官僚确认：`z（认可确认）`。
- **7 生克补**：
  - `x生x并z`：真实军政控制形成可被世界调用的君主名位。
  - `xn克zx`：长期制度、行政和前置程序限制一次性的公开夺权。
  - 两者都必须用具体军权、诏令和官僚变量证明，不能直接复制财阀继承链。
- **8 动态链**：
  - **白话链**：公共资格发生争议 → 军权或官僚接口转移 → 真实控制和长期组织分别接管 → 公开裁决窗口出现 → 名位与控制统一或长期分裂。
  - **十元链**：`x并z/z（名位与确认）` → **军权/官僚转移** → `x / xn接管` → **公开裁决** → `zx可接管` → 统一或分裂。
  - **被改变变量**：军队服从、任免权、诏令执行、财政调用、官僚采用和对外名位。
  - **稳定锚点**：军权、制度和公共名位是否落在同一主体上。
- **9 主题**：长期制度与认可节点共同构成中心问题时，可登记时间主题候选。
- **10 反证**：权谋、计策、宫廷场景和皇位称号不自动是 `xn（持续组织）` 或 `x（掌握边界）`。
- **11 输出**：军权卡｜诏令接口卡｜名位确认卡｜行政组织卡｜公开显权卡｜分裂结算卡。

## T-B08｜底层改造／逆袭

### 一句话看懂

底层逆袭不是“变漂亮、变强、大家震惊”，而是：**原本被忽视或错误定义的人，是否借由可识别证据进入重要认可位置，并被正确确认。**

### 本题材十元速查

- **z（认可确认）**：明确的人、群体或机构确认其能力、作品、身份、选择或完整精神存在。
- **x并z（公共身份壳）**：能够稳定展示和归因的作品、形象、身份、成绩或公开界面。
- **zx（公开显权）**：主体主动公开扩大权能并改变环境，不是单纯打脸。
- **zn（内部意义／原则）**：主体不可轻易放弃的原则、身份意义和未来指导资格。
- **x（掌握边界）**：舞台、资源、传播、职位和社会准入入口。

### 12节点

- **0 入口**：主 `z（认可确认）`；辅 `x并z（公共身份壳）`、`zx（公开显权）`、`zn（内部意义）`。能力成长部分须由D区复核。
- **1 对象**：
  - 主对象：由明确认可主体确认的能力、作品、身份、选择或精神存在。
  - 关联对象：形象壳、公开舞台、能力证据、资源入口和社会评价。
- **2 主体**：被低估者、不同认可主体、帮助者、压制者和舞台入口控制者。自我认可与外部认可必须分开。
- **3 关系**：谁定义“底层”，谁控制舞台和资源，谁认可什么内容，谁只是围观，谁改变了主体的方向决定权。
- **4 触发**：进入新舞台、能力证据出现、作品公开、旧评价被挑战或关键认可者开始关注。
- **5 状态**：被错误定义或忽视 → 能力、作品或身份获得可识别证据 → 不同认可主体确认、误认或拒绝 → 社会位置是否改变另查x、x并z与xn。
- **6 端点**：
  - 可识别形象、作品或成绩界面：`x并z（公共身份壳）`。
  - 具体认可关系成立：`z（认可确认）`。
  - 主体公开扩大权能并改变环境：`zx（公开显权）`。
  - 内部原则与“什么不能被放弃”：另查 `zn（内部意义）`。
  - 舞台、传播和职位入口：`x（掌握边界）`。
- **7 生克补**：
  - `x并z生z`：可识别证据使目标认可主体获得正确归因接口。
  - `zx生zn` 当前仍是研究中、未锁定关系，禁止写成正式机制；只能标记为 `research-active candidate`。
- **8 动态链**：
  - **白话链**：旧评价阻断认可 → 形成可识别证据 → 进入特定认可位置 → 被确认、误认或拒绝；若主体主动扩权，另开显权分支；若出现原则形成，只能保留研究问号。
  - **十元链**：`z受阻` → **证据形成** → `x并z（可识别壳）` → `z（具体确认/拒绝）`；旁支：`zx`；研究支：`zx→zn?`。
  - **被改变变量**：谁看见、看见什么、归因给谁、采用范围、舞台准入、资源入口和社会位置。
  - **稳定锚点**：重要认可是否稳定落到正确主体，而不是只获得一次围观惊叹。
- **9 主题**：若中心问题是能力成长、胜负和排名，转D区；若是身份准入与认可位置，本区继续处理。
- **10 反证**：换装、变美、变强、排名提升、打脸和围观惊叹都不自动是 `z / x并z / zx`。
- **11 输出**：认可主体分账卡｜证据壳卡｜舞台入口卡｜显权分支卡｜社会位置变化卡｜研究关系警示卡。
