# B｜身份阶级与社会位置

> Canvas 是运行主体。本页保存 8 个题材的 12 节点运行骨架与候选机制，不是已经验证完成的题材理论正本。
>
> **使用纪律**：题材名不继承十元；入口主辅只表示初始机制候选。具体案例必须逐阶段回填对象状态、主体位置、关系权限、十元端点、体量、顺序、第三因素与反证后，才允许登记生克补和动态链结论。

## 本区边界

本区只研究：**身份、资格、社会准入、公共名位与控制边界如何变化。**

- 职业流程、行业生产与商业经营，转交 H 区复核。
- 能力升级、战斗与竞争胜负，转交 D 区复核。
- 本区可以保留跨区题材，但不得用题材名替代机制判定。

## 12节点状态说明

| 节点 | 当前用途 | 完成条件 |
|---|---|---|
| 0入口 | 初始主辅候选 | 必须标明结论等级，不得当成固定主导 |
| 1对象 | 主对象与关联对象 | 主对象必须可记录前后状态，不得把多个异质对象混成一项 |
| 2主体 | 稳定本体、阶段状态、关系功能 | 至少区分两方主体及确认/控制接口 |
| 3关系 | 权限分配 + 关系功能 | 分开记录定义、退出、资源、解释、承载、认可 |
| 4触发 | 行动者、对象、目的、回应、收益、代价 | 不得只写事件名称 |
| 5状态 | 前态、触发、后态、不可逆变量 | 至少有一个可观察变量改变 |
| 6端点 | 源、目标、主辅、体量、顺序 | 逐阶段重判，允许辅十元接管 |
| 7生克补 | 候选或已锁定关系 | 标明关系状态、机制、变量、阶段、第三因素 |
| 8动态链 | 对子与对子之间的变化 | 标明主次符号、箭头、接管条件、结算与稳定锚点 |
| 9主题 | 主题候选 | 不得由十元共现反推主题成立 |
| 10反证 | 拿掉、反向、最近邻、替代解释 | 至少填写一项具体失败条件 |
| 11输出 | 可复用分析卡 | 只输出已回填字段，缺项标记 `topic_node_incomplete` |

## T-B01｜财阀继承

- **0入口**：初始候选主 `x`；辅 `zx` / `xn` / `x并z`；结论等级：骨架候选，需逐阶段重判。
- **1对象**：
  - 主对象：表决权及企业实际控制范围。
  - 关联对象：股份、职位、继承资格、婚约接口与处置权限；不得合并成同一状态变量。
- **2主体**：继承候选人／现掌权者／董事会与家族确认机构；分别记录稳定本体、阶段状态与关系功能。
- **3关系**：
  - 权限：谁定义继承资格、谁能退出、谁调配资源、谁解释章程与血统。
  - 功能：谁承载企业运行、谁确认公共身份与职位合法性。
- **4触发**：继承资格被争夺或出现权力真空。案例回填：行动者／争夺对象／目的／对方回应／短期收益／长期代价。
- **5状态**：名义资格存在 → 实际表决与调用权被争夺 → 控制范围、公共职位壳与组织接口重新分配。不可逆变量优先检查表决权、否决权和对外代表权。
- **6端点**：
  - 阶段A：资格争议，`x并z` / `z` 候选显影。
  - 阶段B：资源、表决和否决权争夺，`x` 候选接管。
  - 阶段C：职位与法人接口重建，`x生x并z` 候选。
  - 体量、顺序与主体归属须由案例回填。
- **7生克补**：
  - `x生x并z`：已锁定关系，可作为候选，但须证明实际掌握边界先成立，再生成公开职位或法人接口。
  - `xn克zx`：已锁定关系，仅在章程、流程与长期组织限制即时显权扩张时成立。
  - 不得仅因“继承”“豪门”“有钱”直接登记任何关系。
- **8动态链**：
  - 候选链：`资格壳争议(x并z/z)` → **控制权争夺条件启动** → `实际掌握边界(x)接管` → **对外调用需要形成** → `x生x并z` → 新职位壳成为下一轮争夺入口。
  - 结算必须写明：谁取得何种控制、谁失去哪项接口、哪一符号成为稳定锚点。
- **9主题**：暂不升格主题；若中心问题持续围绕长期组织与认可节点，可登记时间候选，仍需转折、高潮与结局证据。
- **10反证**：有钱、持股或被称作继承人都不自动是 `x`；若没有实际调用、调配、否决或限制他人的边界，主 `x` 不成立。
- **11输出**：对象状态卡｜双主体权限卡｜阶段端点卡｜关系机制卡｜逐段动态链｜反证卡。

## T-B02｜真假继承人

- **0入口**：初始候选主 `x并z`；辅 `x` / `z` / `zn`；结论等级：骨架候选。
- **1对象**：
  - 主对象：承担公共识别和准入功能的身份壳。
  - 关联对象：姓名、血统凭证、财产入口、家族称谓与主体真实自我；分别记录。
- **2主体**：真假继承人／家族确认者／证据持有者／资源控制者；不得把“谁是真的”和“谁被采用”为同一主体位置。
- **3关系**：
  - 权限：谁定义身份、谁控制证据、谁决定财产准入、谁解释血统。
  - 功能：谁认可身份、谁承载关系角色、谁维护公共壳。
- **4触发**：凭证出现、身份被质疑或确认主体改口。回填行动者、对象、目的、回应、收益与代价。
- **5状态**：错误身份壳稳定运行 → 证据使壳与内部真实分裂 → 不同确认主体分别改判或拒绝改判 → 准入、资源和关系角色重新归因。
- **6端点**：
  - 阶段A：公共壳 `x并z` 主导识别与准入。
  - 阶段B：证据控制 `x` 与确认关系 `z` 分账重判。
  - 阶段C：新壳是否建立，重新检查 `x生x并z` / `x并z生z`。
- **7生克补**：
  - `x并z生z`、`x生x并z`、`x克z`：均为已锁定关系，但必须分别证明可识别壳、实际控制入口与具体认可主体。
  - `x补zn`：仅作候选，必须另查关系正本及案例中的意义落点，不得因“真实自我”自动调用。
- **8动态链**：`既有公共壳(x并z)` → **证据或确认冲突出现** → `证据入口控制(x)` 与 `确认结论(z)` 分账 → **旧壳失效或维持** → 新壳重建／多主体确认分裂。不得把“真相揭露”直接写成十元转化。
- **9主题**：本体候选；必须证明中心问题持续围绕真实自我、掌握边界和公共身份壳，而非仅有身份秘密。
- **10反证**：秘密、DNA、换名和真假反转不自动是 `x并z`；必须证明身份壳实际承担识别、准入、关系角色或资源接口。
- **11输出**：身份壳状态卡｜确认主体分账卡｜证据控制卡｜准入变化卡｜逐段动态链｜反证卡。

## T-B03｜豪门复仇

- **0入口**：初始候选主 `x`；辅 `xn` / `zx` / `z`；结论等级：骨架候选。
- **1对象**：
  - 主对象：被夺取且可重新掌握的具体边界。
  - 关联对象：股份、证据、渠道、署名、继承权；必须选定主对象，不能全部混写。
- **2主体**：被夺者／豪门控制者／盟友／公众或机构确认者；区分夺回者、控制入口者和认可主体。
- **3关系**：谁控制证据与渠道、谁拥有退出与否决权、谁解释旧案、谁认可署名或责任。
- **4触发**：旧案证据重现、被害者回归或现控制者出现漏洞。回填具体行动链及收益代价。
- **5状态**：具体掌握边界丧失 → 证据与资源被组织 → 控制权或署名入口被夺回／替换 → 公众评价是否变化另行作为 `z` 分账。
- **6端点**：
  - 失去阶段：目标 `x` 下降，但不据此推定源符号。
  - 组织阶段：若主动建立持续计划，`xn` 候选显影。
  - 公开反击阶段：若主体直接公开显权并凌驾他者，`zx` 候选。
  - 结算阶段：检查 `x` 是否真实恢复，`z` 是否由具体认可主体确认。
- **7生克补**：
  - `x克z`、`xn克zx`、`xn补z`、`z补xn` 均须逐段证明，不得因为“复仇成功”成套调用。
  - `xn补z / z补xn` 只表示时间组织与认可节点互补，不是准备久了必然被认可。
- **8动态链**：`掌握边界丧失(x↓)` → **主体建立长期组织时** `xn` 接管 → **公开行动窗口出现时** `zx` 可短暂接管 → `控制入口重新归属(x)` → `具体认可主体形成或拒绝确认(z)`。每段必须写明主次与接管条件。
- **9主题**：时间候选，仅在长期组织与最终确认节点共同构成中心问题时成立。
- **10反证**：复仇情绪、打脸快感和对手失败不自动是 `zx`；必须看主体是否公开扩大权能，以及究竟夺回了什么边界。
- **11输出**：被夺对象卡｜计划结构卡｜显权阶段卡｜控制恢复卡｜认可分账卡｜反证卡。

## T-B04｜娱乐圈上位

- **0入口**：初始候选主 `z`；辅 `x并z` / `zx` / `x`；结论等级：骨架候选。
- **1对象**：
  - 主对象：被具体认可主体确认的作品、能力、身份或选择。
  - 关联对象：艺人人设壳、曝光渠道、署名与评价；流量不得作为统一对象。
- **2主体**：艺人或创作者／不同层级认可主体／资本平台与渠道控制者；认可主体必须分账。
- **3关系**：
  - 权限：谁控制发布、署名、推荐、引见与解释入口。
  - 认可：谁认可什么、该认可位置为何重要、采用范围和成立阶段是什么。
  - 自我认可、专业认可、公众认可和机构采用不得合并成一个“大 z”。
- **4触发**：作品发布、舆论危机或竞争舞台。回填行动者、呈现对象、目标认可主体、回应、收益与代价。
- **5状态**：作品或能力未进入目标认可位置 → 获得可识别形式与归因接口 → 目标认可主体看见并确认／误认／拒绝确认 → 渠道控制与认可结果分别结算。
- **6端点**：
  - 作品或人设形成可识别壳：`x并z` 候选。
  - 特定主体确认作品、能力或身份：`z` 成立。
  - 主体公开扩大权能：另查 `zx`，不能用“上位”名称代替。
  - 渠道、署名和推荐入口被掌握：`x` 候选。
- **7生克补**：
  - `x并z生z`、`x生x并z`、`x克z` 为已锁定关系，可按具体入口调用。
  - 不能把曝光、播放量、热搜或广告投放直接登记为 `z`。
- **8动态链**：`作品/身份壳形成(x并z)` → **进入特定认可位置** → `具体确认(z)`；若发布、署名或引见入口被控制，则 `x克z` 分支启动；若主体主动公开显权，另开 `zx` 分支，不与认可结果合并。
- **9主题**：暂不升格；若长期训练结构与专业确认节点共同构成中心问题，可转时间主题候选。
- **10反证**：流量不是纯 `z`；大众看见也不等于正确归因。拿掉目标认可主体后仍完整成立的“事业成功”，可能主要是 `x`、`xn` 或 `zx`。
- **11输出**：认可主体分账卡｜作品壳卡｜渠道控制卡｜署名归因卡｜分支动态链｜反证卡。

## T-B05｜商战创业

- **0入口**：初始候选主 `xn`；辅 `zx` / `x` / `n`；结论等级：跨区骨架候选，必须由 H 区复核职业经营机制。
- **1对象**：
  - 主对象：主体主动组织并持续运行的产品、流程或市场结构。
  - 关联对象：资金、团队承载、产权、渠道和市场入口；分别记录。
- **2主体**：创业者／团队／投资人与竞争者／客户或市场采用主体；区分组织者、承载者、控制者和显权者。
- **3关系**：谁组织时间流程、谁掌握资金和产权、谁承担内部负荷、谁能公开处置、谁确认产品被采用。
- **4触发**：机会窗口、资金危机或产品失败。回填行动者、对象、目标、回应、收益、代价和替代路径。
- **5状态**：零散行动 → 主体主动组织时间、规则、信息与资源 → 产品或团队结构持续运行／失败 → 市场采用、产权掌握和公开权能分别结算。
- **6端点**：
  - 主体主动建立持续结构：`xn` 候选。
  - 掌握资金、股权、渠道或否决权：`x` 候选。
  - 公开处置与凌驾性扩权：`zx` 候选。
  - 团队真实接住反复负荷：`n` 候选；不得由“团队存在”自动判定。
- **7生克补**：
  - `xn克zx`、`zx克n`：仅在对应变量真实变化时调用。
  - `n生xn`：不得作为创业题材默认关系。只有 `n` 已真实承载反复负荷，随后为继续承载而主动提炼流程，才可登记。
- **8动态链**：`零散行动` → **主动组织启动** `xn` → 根据产权、承载和显权分别分支为 `x / n / zx` → **若 n 的重复负荷迫使流程化**，才建立 `n生xn` 回路 → 结构持续或崩解。不得把忙碌和增长曲线写成动态链。
- **9主题**：暂不升格；若中心问题是长期组织与认可节点，可作时间候选；若主要是职业现实，应转 H 区。
- **10反证**：忙碌、加班、融资、营收和执行制度不自动是 `xn`；被动遵守投资人要求可能是 `nx` 或外部 `xn`，必须检查谁占据方向决定权。
- **11输出**：主动组织卡｜产权控制卡｜承载负荷卡｜显权卡｜市场采用卡｜跨区复核卡。

## T-B06｜贵族社交

- **0入口**：初始候选主 `x并z`；辅 `z` / `x` / `xn`；结论等级：骨架候选。
- **1对象**：
  - 主对象：承担公共识别与社交准入功能的礼法身份壳。
  - 关联对象：爵位、称呼、婚约、名誉、舞会入口与家族资源；分别记录。
- **2主体**：贵族主体／社交圈认可者／礼法与家族机构／资源控制者；区分被识别者、确认者和控制入口者。
- **3关系**：谁定义称谓与资格、谁决定准入与退出、谁控制婚约和资源、谁认可名誉、谁维持礼法结构。
- **4触发**：舞会、婚约宣布、丑闻或称谓争议。回填行动者、目标对象、回应、收益与代价。
- **5状态**：公共壳决定识别与准入 → 内部意图、关系事实或资源边界与壳发生冲突 → 不同认可主体和控制者分别重排。
- **6端点**：
  - 礼法壳承担准入：`x并z` 候选。
  - 某主体确认名誉、身份或选择：`z` 分账。
  - 家族掌握婚约、资源和入口：`x` 候选。
  - 长期礼法组织：`xn` 候选，不等于被动守礼。
- **7生克补**：`x并z生z`、`x生x并z`、`x克z` 可作已锁定候选；`z补xn` 必须证明认可节点改变长期组织的聚焦与阶段收束，不能因礼仪获得称赞就调用。
- **8动态链**：`礼法公共壳(x并z)` → **准入或名誉争议** → `控制入口(x)` 与 `具体认可(z)` 分账 → **长期礼法是否主动组织** 另判 `xn` → 壳被维持、撕裂或重建。
- **9主题**：时间候选仅在礼法结构与认可节点共同成为中心问题时成立；华服、舞会和古典视觉不构成主题证据。
- **10反证**：华服、礼貌、称呼和贵族场景只是视觉候选；若没有公共识别、准入或关系角色功能，`x并z` 不成立。
- **11输出**：礼法壳卡｜准入卡｜名誉确认卡｜婚约控制卡｜组织结构卡｜反证卡。

## T-B07｜宫廷继承

- **0入口**：初始候选主 `x`；辅 `zx` / `xn` / `x并z`；结论等级：骨架候选。
- **1对象**：
  - 主对象：军权、任免权、诏令执行权或最终处置边界，案例必须选定其一。
  - 关联对象：皇位名号、血统壳、诏书、派系与官僚接口。
- **2主体**：继承者／现君主与对手／军队、官僚和宗法确认机构；区分实际控制者与名位确认者。
- **3关系**：谁掌握军队与任免、谁解释诏书、谁确认名位、谁组织长期行政流程、谁能公开处置他者。
- **4触发**：君主病危、诏书争议、政变或军权转移。回填行动者、对象、回应、收益、代价和第三因素。
- **5状态**：资格与名位争议 → 派系、军权与官僚接口重新组织 → 实际控制和公共名位可能统一，也可能长期分裂。
- **6端点**：
  - 名位与血统壳：`x并z` 候选。
  - 军权、任免和处置边界：`x` 候选。
  - 公开显权与凌驾性裁决：`zx` 候选。
  - 行政、程序和时间组织：`xn` 候选。
- **7生克补**：`x生x并z` 与 `xn克zx` 可作已锁定候选；必须证明真实控制先于公共名位，或长期制度确实限制即时显权。
- **8动态链**：`公共资格争议(x并z/z)` → **军权或官僚接口发生转移** → `x / xn` 分支接管 → **公开裁决窗口** 可触发 `zx` → `实际控制与公共名位统一或分裂`。不得复用财阀继承链而省略军权、诏令和官僚接口。
- **9主题**：暂不升格；若长期制度与认可节点构成中心问题，可作时间候选。
- **10反证**：权谋、宫廷和计策不必然是 `xn`；若核心变量是军权、任免和处置边界，应主查 `x`。皇位称号本身也不证明实际掌握。
- **11输出**：军权卡｜诏令接口卡｜名位确认卡｜行政组织卡｜公开显权卡｜分裂结算卡。

## T-B08｜底层改造／逆袭

- **0入口**：初始候选主 `z`；辅 `x并z` / `zx` / `zn`；结论等级：跨区骨架候选，能力成长部分须由 D 区复核。
- **1对象**：
  - 主对象：由明确认可主体确认的能力、作品、身份、选择或完整精神存在。
  - 关联对象：形象壳、公开舞台、能力证据和社会评价；必须分账。
- **2主体**：被低估者／不同认可主体／帮助者、压制者与舞台入口控制者；自我认可和外部认可分开记录。
- **3关系**：谁定义“底层”、谁控制公开舞台和资源、谁认可什么内容、谁只是在围观、谁改变了主体的方向决定权。
- **4触发**：进入新舞台、能力证据出现或旧评价被挑战。回填行动者、呈现对象、目标认可主体、回应、收益与代价。
- **5状态**：被某主体错误定义或忽视 → 能力、作品或身份获得可识别证据 → 不同认可主体分别确认、误认或拒绝 → 主体社会位置是否改变另查 `x / x并z / xn`。
- **6端点**：
  - 可识别形象或作品壳：`x并z` 候选。
  - 具体认可关系成立：`z`。
  - 主体主动公开显权并改变世界：`zx` 候选，不能由“打脸”自动判定。
  - 内部原则与“不能放弃什么”：另查 `zn`，不能由逆袭结果反推。
- **7生克补**：
  - `x并z生z`：已锁定关系，可在可识别壳使目标认可主体获得归因接口时调用。
  - `zx生zn`：当前研究中、未锁定，禁止作为正式机制；只能标记 `research-active candidate`，并附证据缺口。
- **8动态链**：`错误/缺失确认(z受阻)` → **可识别证据形成** `x并z` → `特定认可主体确认或拒绝(z)`；若主体公开扩大权能，另开 `zx` 分支；若出现原则形成，只能标记 `zx→zn?` 研究候选，不得写成正式箭头。
- **9主题**：暂不升格；若中心问题是能力成长与竞争，转 D 区；若是社会身份准入和认可位置，本区继续处理。
- **10反证**：换装、变美、变强、打脸、排名上升和围观惊叹都不自动是 `z / x并z / zx`。必须写清谁认可、认可什么、为什么重要，以及社会位置究竟哪项变量改变。
- **11输出**：认可主体分账卡｜证据壳卡｜舞台入口卡｜显权分支卡｜社会位置变化卡｜研究关系警示卡。
