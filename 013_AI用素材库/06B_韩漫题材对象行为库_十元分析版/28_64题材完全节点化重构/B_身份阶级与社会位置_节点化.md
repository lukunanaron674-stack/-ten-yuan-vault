# B｜身份阶级与社会位置

> **五行在上，十元在下。每一行分成阴、阳两个相反十元。**
>
> 阴阳不是两个平行功能，也不是随手拼在一起的标签，而是同一五行内部的相反两极。应用教学必须先找到这条相反轴，再用它拆解具体知识对象。

## 五行与阴阳十元

| 五行 | 阳 | 阴 | 本页应用时观察的相反轴 |
|---|---|---|---|
| 木 | `zx` | `nx` | 自己占据方向、向外改变环境 ↔ 让出方向、沿他人通道推进 |
| 火 | `zn` | `x` | 守住内部意义与身份核心 ↔ 取得并控制外部对象 |
| 土 | `n` | `x并z` | 内部真实承载与接纳 ↔ 外部可识别的身份壳与公共接口 |
| 金 | `xn` | `z` | 规则、流程与长期秩序 ↔ 个人最高焦点、执念与自我判断 |
| 水 | `xz` | `nz` | 临界、断裂与不可逆压力 ↔ 回返、归属与关系修复 |

> 上表只用于本页知识教学，不替代十元理论正本。重点是：每组先看相反，再看具体对象怎样落在两端、怎样偏移、怎样冲突。

# 一｜应用教学方法

面对一个题材，按以下顺序学习：

```text
具体对象是什么
→ 它包含哪些权利、资格、关系和机构
→ 五行中哪条相反轴最能拆开它
→ 阳端出现哪些具体名词
→ 阴端出现哪些具体名词
→ 人物从一端滑向另一端时发生什么
→ 这条变化如何生成剧情
```

## 禁止写法

```text
股份 = x
继承人 = x并z
制度 = xn
```

这只是贴标签，没有学到对象。

## 正确写法

```text
股份包括收益权、表决权、转让权和剩余财产请求权；
股份多不必然取得控制权；
控制权还取决于表决联盟、董事席位、章程和实际经营接口。

火轴：
阳火 zn 看继承人守住什么家族意义与经营原则；
阴火 x 看谁真正掌握股份、投票、账户、印章和任免。
```

# 二｜B区基础对象

## 1. 身份

身份是人物被持续识别成谁，以及这个“谁”能否被家庭、法律、组织或公众调用。

```text
身份
├─ 自我身份：真正的我、秘密身份、身份核心
├─ 关系身份：子女、配偶、师徒、主仆
├─ 法律身份：户籍、收养、婚姻登记、继承人
├─ 组织身份：员工、股东、董事、会员、军官
├─ 公共身份：艺名、人设、爵位、皇位、公众形象
└─ 身份凭证：证件、档案、族谱、合同、任命书
```

最常用的是土轴：

```text
阳土 n：内部是否真的接纳、培养、保护这个人
↕
阴土 x并z：外部是否给他正式姓名、职位、称号和公共接口
```

一个人可以有正式身份壳，却没有内部归属；也可以被内部接纳，却没有法律和公共身份。

## 2. 阶级

阶级不是财富排名，而是人物在资源、教育、人脉、制度保护、信息和决策能力上的长期位置。

```text
经济资本：现金、房产、股份、信托、债务
文化资本：学历、口音、礼仪、审美、资格证书
社会资本：家族、人脉、推荐人、校友圈
制度保护：律师、公关、媒体、职位、家族兜底
权力接口：任免、审批、表决、否决、资源分配
```

## 3. 社会位置

社会位置必须指明具体结构。同一个人可以同时是：

- 家族中的私生子；
- 公司里的大股东；
- 董事会里的少数派；
- 公众眼里的明星；
- 婚姻里的被安排者。

所以位置变化必须写成：

```text
在哪个结构中
从什么位置
变成什么位置
新增或失去什么资格、权限、资源、确认和退路
```

# 三｜八个题材应用教学

## T-B01｜财阀继承

### 核心名词

| 名词 | 解释 | 不等于 |
|---|---|---|
| 继承资格 | 进入继承候选范围 | 已经取得公司与资产 |
| 股份 | 对公司的所有权份额 | 实际控制公司 |
| 表决权 | 对重大事项投票 | 所有提案都能通过 |
| 否决权 | 阻止某项决定成立 | 主动决定全部方向 |
| 董事席位 | 进入治理层的位置 | 最大股东 |
| 控制权 | 持续决定方向、人事和资源 | 职位、财富或名声 |
| 法人代表 | 对外代表公司的正式接口 | 所有者或幕后控制者 |

### 五组相反轴

| 五行 | 阳端 | 阴端 | 本题材要看什么 |
|---|---|---|---|
| 木 | `zx`：公开罢免、逼宫、强制换董事、夺印 | `nx`：傀儡继承人、代持股东、名义董事长 | 谁自己占据方向，谁只是沿长辈或董事会方向行动 |
| 火 | `zn`：祖业、创始人理念、家族使命 | `x`：股份、表决权、账户、印章、任免权 | 守住家族意义，还是只取得可控制对象 |
| 土 | `n`：老臣班底、管理团队、家族内部培养 | `x并z`：继承人、董事长、法人代表 | 内部是否接住，与公开身份是否成立可能分离 |
| 金 | `xn`：章程、遗嘱执行、股东大会、审计 | `z`：家族承认、董事会确认、市场信任 | 程序有效与个人执念、确认焦点怎样冲突 |
| 水 | `xz`：股权冻结、收购期限、表决倒计时 | `nz`：旧部、家族庇护、被罢免后的归处 | 权力断裂时人物还有没有回返关系 |

### 对象链

```text
继承资格 → 股份或董事席位 → 表决联盟 → 任免和资金调用 → 实际控制权 → 公开职位
```

### 剧情联想

- 主角持股最多，却没有董事会多数票；
- 董事长公开掌权，实际只是祖母的代理人；
- 主角夺回公司，却背叛了原本要守住的祖业原则。

## T-B02｜真假继承人

### 核心名词

生物血缘、法律亲属、身份凭证、家族承认、公共身份、资源准入、关系归属。

### 五组相反轴

| 五行 | 阳端 | 阴端 | 本题材要看什么 |
|---|---|---|---|
| 木 | `zx`：当众揭露、强制改名、废除资格 | `nx`：被迫扮演别人、替他人占位 | 谁主动改写身份局面，谁被安排成身份工具 |
| 火 | `zn`：真正的我、姓氏意义、养育之恩 | `x`：DNA、户籍、遗嘱、族谱、财产入口 | 身份核心与证据、资源控制是否冲突 |
| 土 | `n`：养育、共同生活、家庭接纳 | `x并z`：正式子女、姓氏、户籍、继承人 | 家里真正把谁当家人，社会又把谁叫作家人 |
| 金 | `xn`：DNA复核、法院程序、档案更正 | `z`：父母确认、家族改口、自我坚持 | 程序结论与人物最高认定是否一致 |
| 水 | `xz`：证据销毁、遗产期限、被逐出 | `nz`：养父母、旧家庭、仍可回去的家 | 身份崩塌后还有没有归属 |

### 四层分账

```text
客观层：血缘是谁
法律层：文件登记是谁
社会层：大家持续把谁当成谁
关系层：谁真正养育、接纳并允许回返
```

## T-B03｜豪门复仇

### 核心名词

报复、追责、赔偿、返还、控制回收、名誉恢复、生活重建。

### 五组相反轴

| 五行 | 阳端 | 阴端 | 本题材要看什么 |
|---|---|---|---|
| 木 | `zx`：公开揭露、罢免、强制清算 | `nx`：内应、代理执行、替幕后者行动 | 复仇者自己主导，还是成为另一人的刀 |
| 火 | `zn`：清白、作者身份、复仇底线 | `x`：证据入口、股份、署名权、发布权 | 守住什么意义，实际夺回什么对象 |
| 土 | `n`：盟友团队、证人保护、长期支持 | `x并z`：合法继承人、真实作者、受害者身份 | 支持系统与公开身份恢复是否同步 |
| 金 | `xn`：调查计划、诉讼、证据备份 | `z`：法院改判、公众澄清、自我执念 | 长期追责程序会不会被私人执念吞掉 |
| 水 | `xz`：诉讼时效、证据销毁、生命威胁 | `nz`：旧友、家庭、复仇后的生活 | 能不能结束，而不是永远活在复仇里 |

### 目标区别

```text
让对手痛苦 = 报复
让责任成立 = 追责
拿回损失 = 赔偿或返还
拿回决定权 = 控制回收
让别人重新认识我 = 名誉恢复
结束后还能生活 = 重建
```


### 真逆袭与假逆袭

```text

职位和资源入口改变：获得准入
拥有新的决定权：获得控制
变化可持续：形成新的社会位置
```

# 四｜教学验收标准

本文件合格必须满足：

1. 五行处于上位，十元作为每一行的阴阳展开；
2. 每组阴阳先说明相反关系，不能只并排罗列功能；
3. 每个题材至少解释五个具体专业名词；
4. 每条五行轴都必须落到具体名词、机构、权限、关系或场景；
5. 必须说明对象怎样从阳端滑向阴端，或从阴端夺回阳端；
6. 必须区分最容易混淆的相邻概念；
7. 必须能转成对象链、人物冲突和剧情场景；
8. 十二节点、体量、顺序、生克补与动态链验证留在详细 Canvas。
