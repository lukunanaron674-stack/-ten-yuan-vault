# B｜身份阶级与社会位置

> **十元就是五行，是同一套理论本体。**
>
> 本页属于十元的**应用教学层**：用十元拆解外部知识，帮助学习身份、阶级、股份、军权、继承资格、社会准入、署名权等具体对象。
>
> 本页不研究十元定义，也不把十二节点审计当成教学正文。端点、体量、顺序、生克补与动态链验证放在详细 Canvas 中。

## 三种工作层

```text
底层理论
十元定义、对子、五维、生克补与动态规律

应用教学 ← 本页
用十元扩散具体名词、区分相邻概念、理解对象关系并转成创作知识

分析验证
把具体案例放入12节点，检查主体、体量、顺序、关系、反证与动态链
```

## 本页固定学习顺序

```text
题材
→ 核心名词
→ 名词区别
→ 十元具体名词联想
→ 对象之间怎样连接
→ 可以写成什么剧情
```

# 一｜十元应用教学怎么用

看到一个陌生题材时，不是先问“它属于哪个十元”，而是用十元把知识向十个方向扩散。

| 十元入口 | 应用时寻找的具体知识 | 常见名词联想 |
|---|---|---|
| `x` | 谁真正掌握、调用、调配、否决、任免或处置 | 所有权、控制权、表决权、否决权、任免权、发布权、署名入口、资金调用权 |
| `z` | 谁确认谁，确认什么，哪一种确认真正改变位置 | 家族承认、董事会确认、法院裁定、专业认可、公众认可、市场信任、身份确认 |
| `zx` | 哪些公开行动使权能直接显现并迫使环境重排 | 罢免、夺权、逼宫、公开裁决、强制驱逐、威慑、政变、当众改判 |
| `xn` | 对象怎样被长期建立、登记、审核、组织和维持 | 章程、流程、制度、审计、继承程序、治理结构、运营系统、官僚链、长期计划 |
| `nx` | 谁没有占据本可拥有的方向位置，而沿别人给出的方向推进 | 傀儡继承人、代理人、代持人、被安排婚姻、执行者、附庸、职业受控、投资人主导 |
| `n` | 谁真正进入内部，被持续接纳、承担、训练或安置 | 家族内部成员、管理团队、共同体、幕僚、长期照料、组织培养、团队承载、内部归属 |
| `zn` | 什么内部意义、身份核心或原则不能轻易让渡 | 家族使命、祖业、血统认同、职业尊严、作者身份、个人底线、国家原则、真正的我 |
| `nz` | 失势、冲突或退出后，人物还能回到哪里 | 庇护人、旧家、养父母、老部下、关系归属、和解、回归、避风港、可回返位置 |
| `xz` | 什么危险正在逼近并压缩时间、退路和可逆空间 | 继承截止、股权冻结、身份暴露、敌意收购、破产、政变倒计时、丑闻爆发、被驱逐 |
| `x并z` | 什么名称、职位或身份让世界可以持续识别、准入和调用人物 | 继承人、董事长、法人代表、皇帝、贵族、明星艺名、家族姓氏、会员、正式配偶 |

这张表不是十元释义表，而是**知识搜索与联想表**。例如看到“股份”，不能停在 `x`，还要继续联想到股东身份、投票程序、董事会确认、代持、冻结和继承期限。

# 二｜B区基础名词

## 1. 身份

身份是一个人被持续识别成谁，以及这个“谁”能否被家庭、组织、法律、市场或公众使用。

### 具体名词联想

```text
身份
├─ 自我：自我认同、真正的我、身份核心、秘密身份
├─ 关系：子女、配偶、师徒、主仆、监护人与被监护人
├─ 法律：户籍、出生证明、收养、婚姻登记、继承人、法人代表
├─ 组织：员工、股东、董事、会员、军官、官员
├─ 公共：艺名、人设、爵位、皇位、品牌身份、公众形象
└─ 凭证：证件、档案、族谱、合同、任命书、资格证书
```

### 十元应用

- 用 `x并z` 找身份的正式名称、职位和公共接口；
- 用 `z` 找身份由谁确认；
- 用 `x` 找身份附带什么真实权利；
- 用 `n` 找内部是否真的接纳这个人；
- 用 `zn` 找人物自己认定的身份核心；
- 用 `xz+nz` 找身份崩塌后还有没有退路和归属。

## 2. 阶级

阶级不是财富排行榜，而是一个人在资源、教育、人脉、制度保护、信息接近和决策能力上的长期位置。

### 具体名词联想

```text
阶级
├─ 经济资本：现金、房产、股份、企业、信托、债务
├─ 文化资本：学历、学校、口音、礼仪、审美、资格证书
├─ 社会资本：家族、人脉、推荐人、校友圈、政商关系
├─ 制度保护：律师、公关、媒体、职位、豁免、家族兜底
├─ 权力接口：任免、审批、表决、否决、资源分配
└─ 阶级符号：住宅、服装、座驾、社交场所、称谓、生活方式
```

## 3. 社会位置

社会位置是人物在某个具体结构中相对于他人的位置。

同一个人可以同时是：

- 家族里的私生子；
- 公司里的大股东；
- 董事会里的少数派；
- 公众眼里的明星；
- 婚姻里的被安排者；
- 团队里的实际决策者。

所以“逆袭”不能只写成底层变上层，必须写清：

```text
在哪个结构中
从什么位置
变成什么位置
新增或失去了哪些资格、权限、资源、认可和退路
```

# 三｜八个题材应用教学

## T-B01｜财阀继承

### 学习目标

区分：**继承资格、股份、表决权、董事席位、控制权、董事长和法人代表不是同一件事。**

### 核心名词

| 名词 | 具体解释 | 不等于什么 |
|---|---|---|
| 继承资格 | 被允许进入继承候选范围 | 不等于已经取得资产与公司 |
| 股份 | 对公司的所有权份额 | 不等于实际控制公司 |
| 表决权 | 对重大事项投票的权利 | 不等于所有方案都能通过 |
| 否决权 | 阻止某项决定成立 | 不等于主动决定全部方向 |
| 董事席位 | 进入公司治理层的位置 | 不等于最大股东 |
| 控制权 | 持续决定方向、人事和资源配置 | 不等于职位、财富或名声 |
| 法人代表 | 公司对外的正式代表接口 | 不等于所有者或幕后控制者 |

### 十元具体名词联想

| 十元 | 本题材应联想到的名词 |
|---|---|
| `x` | 股份、表决权、否决权、任免权、资金调用权、账户、印章、代理投票、议程设置权 |
| `z` | 家族承认、董事会确认、法院确认、员工服从、市场信任、继承公告 |
| `zx` | 公开罢免、逼宫、强制换董事、当众夺印、冻结对手权限 |
| `xn` | 公司章程、遗嘱执行、股东大会、董事会程序、审计、任期、继承流程 |
| `nx` | 傀儡继承人、代持股东、家族代理人、只按长辈方向经营、名义董事长 |
| `n` | 管理团队接纳、老臣班底、家族内部培养、员工组织承载 |
| `zn` | 祖业、家族使命、创始人理念、不能出售的核心产业、继承人的身份原则 |
| `nz` | 家族庇护、旧部支持、被罢免后仍可回家的关系、保留姓氏与归属 |
| `xz` | 遗嘱公开期限、股权冻结、敌意收购、董事会表决倒计时、掌权者病危 |
| `x并z` | 继承人、董事长、法人代表、家族发言人、正式股东、企业品牌代表 |

### 关键区别

```text
持股最多 ≠ 控制公司
董事长 ≠ 实际控制人
继承人称号 ≠ 已经继承
法人代表 ≠ 所有者
能否决 ≠ 能主动推动所有决定
```

### 对象连接链

```text
继承资格
→ 股份或董事席位
→ 表决联盟
→ 任免与资金调用
→ 实际控制权
→ 董事长／法人代表等公开身份
```

### 剧情联想

- 主角持股最多，却没有董事会多数票；
- 公开董事长只是祖母的代理人；
- 没有血缘的人因遗嘱与长期经营获得继承资格；
- 主角夺回职位，却失去家族归属与旧部支持。

## T-B02｜真假继承人

### 学习目标

区分：**血缘真实、法律身份、家族承认、公共身份和资源准入可以彼此分离。**

### 核心名词

| 名词 | 具体解释 |
|---|---|
| 生物血缘 | 基于出生关系的亲缘事实 |
| 法律亲属 | 经登记、收养、婚姻或裁决确认的关系 |
| 身份凭证 | 出生证明、户籍、族谱、DNA报告、档案 |
| 家族承认 | 家族是否把人物当作真正成员 |
| 公共身份 | 姓名、姓氏、称号被外界持续采用 |
| 资源准入 | 能否进入遗产、教育、住宅、社交和继承资源 |
| 关系归属 | 谁真正养育、保护、接纳并允许人物回返 |

### 十元具体名词联想

| 十元 | 本题材应联想到的名词 |
|---|---|
| `x` | DNA报告控制、户籍档案、遗嘱、族谱、财产入口、教育基金、证据销毁与公开权 |
| `z` | 父母承认、家族会议、法院确认、兄弟姐妹改口、社会改判 |
| `zx` | 当众揭露、强制改名、公开驱逐、宣布废除继承资格 |
| `xn` | 身份登记、DNA复核、法院程序、遗产审查、档案更正、家族会议流程 |
| `nx` | 被迫扮演别人、沿家族安排生活、替真继承人占位、听从证据控制者 |
| `n` | 养育关系、家族内部接纳、共同生活、家庭仪式、长期照料 |
| `zn` | 真正的我、姓氏意义、血统认同、养育之恩、不可替代的身份核心 |
| `nz` | 养父母之家、旧家庭、兄弟姐妹关系、失去身份后仍能回去的地方 |
| `xz` | 身份暴露、遗产截止、成年期限、被赶出家门、证据即将销毁 |
| `x并z` | 家族姓氏、正式子女、继承人、户籍身份、学校档案、公开称谓 |

### 四层身份分账

```text
客观层：血缘到底是谁
法律层：文件登记是谁
社会层：大家持续把谁当成谁
资源层：谁能进入遗产与家族资源
关系层：谁真正拥有家庭归属
```

### 剧情联想

- 真继承人取得法律身份，却没有家庭归属；
- 假继承人失去遗产，却仍被部分家人承认；
- DNA证据真实，但被掌权者控制，无法改变公共身份；
- 两人最终分别获得不同的身份、资源和关系，而不是简单换座位。

## T-B03｜豪门复仇

### 学习目标

区分：**报复、追责、赔偿、夺回控制、恢复名誉和重建生活是不同目标。**

### 核心名词

| 名词 | 具体解释 |
|---|---|
| 被夺对象 | 股份、职位、署名、继承权、证据或渠道中的具体一项 |
| 证据链 | 多项证据怎样互相支持并指向事实 |
| 责任主体 | 谁决定、执行、掩盖或获利 |
| 受益人 | 谁从侵害和资源转移中获利 |
| 追责 | 使责任被确认并承担后果 |
| 赔偿 | 补偿损失，不自动恢复身份与关系 |
| 控制回收 | 夺回对象的使用、决定、署名或处置范围 |
| 名誉恢复 | 让机构、行业或公众重新正确归因 |

### 十元具体名词联想

| 十元 | 本题材应联想到的名词 |
|---|---|
| `x` | 股份回收、证据入口、发布权、署名权、董事会控制、财产冻结、处置权 |
| `z` | 法院改判、家族道歉、公众澄清、行业恢复署名、受害者身份确认 |
| `zx` | 当众揭露、公开罢免、夺回印章、强制清算、公开处置加害者 |
| `xn` | 长期调查、证据备份、资金安排、盟友部署、法律程序、复仇阶段计划 |
| `nx` | 内应、代理执行者、被胁迫证人、替幕后主使行动的人 |
| `n` | 盟友团队、证人保护、受害者支持系统、长期接住主角的人 |
| `zn` | 清白、作者身份、家族原则、不能被牺牲的人、复仇底线 |
| `nz` | 旧友、原生家庭、幸存者共同体、完成复仇后可返回的生活 |
| `xz` | 诉讼时效、证据销毁、对手察觉、资金断裂、身份暴露、生命威胁 |
| `x并z` | 合法继承人、真实作者、受害者身份、公司负责人、公开清白身份 |

### 目标分账

```text
让对手痛苦：报复
让事实成立：追责
拿回损失：赔偿／返还
拿回决定权：控制回收
让别人重新认识我：名誉恢复
结束后还能活下去：生活重建
```

### 剧情联想

- 主角成功扳倒仇人，却仍没拿回作品署名；
- 证据足以恢复名誉，却不足以追回公司；
- 盟友帮助复仇，但逐渐占据主角的方向决定权；
- 真正结局不是敌人倒下，而是主角重新拥有生活和回返位置。

## T-B04｜娱乐圈上位

### 学习目标

区分：**作品、版权、署名、发布、渠道、流量、专业认可和公众认可。**

### 核心名词

| 名词 | 具体解释 |
|---|---|
| 作品 | 被创作、表演或制作的具体成果 |
| 版权 | 作品复制、传播、改编和收益等权利集合 |
| 署名权 | 公开说明作品归属于谁 |
| 发布权 | 决定作品能否以及如何公开 |
| 渠道 | 平台、媒体、经纪、推荐、排期和引见入口 |
| 人设 | 公众能够持续识别的艺人形象 |
| 流量 | 可见度和注意力，不等于认可 |
| 专业认可 | 导演、评审、同行和奖项机构的确认 |
| 公众认可 | 观众对作品、能力或形象的确认 |

### 十元具体名词联想

| 十元 | 本题材应联想到的名词 |
|---|---|
| `x` | 版权、署名入口、发布权、选角权、排期、推荐位、合同解除权、账号与素材控制 |
| `z` | 导演认可、同行评价、奖项、观众认同、品牌采用、核心粉丝确认 |
| `zx` | 公开解约、拒绝潜规则、夺回话筒、当众揭露、强势改组团队 |
| `xn` | 训练计划、作品路线、经纪运营、发行周期、宣传节奏、长期职业规划 |
| `nx` | 被公司安排人设、只按资本方向接戏、代言傀儡、替别人背锅 |
| `n` | 经纪团队、长期合作班底、粉丝共同体、剧组接纳、创作团队承载 |
| `zn` | 作者性、表演原则、作品底线、真实身份、不能被市场牺牲的表达 |
| `nz` | 老搭档、家人、独立工作室、退圈后可回去的生活、稳定关系 |
| `xz` | 舆论爆发、合同到期、封杀、作品泄露、丑闻倒计时、角色被替换 |
| `x并z` | 艺名、明星身份、演员标签、歌手品牌、作品署名、奖项头衔、人设 |

### 关键区别

```text
被看见 ≠ 被认可
流量高 ≠ 作品好
有署名 ≠ 有版权
有粉丝 ≠ 有专业认可
有名气 ≠ 有发布和选角控制
```

### 剧情联想

- 主角爆红，但作品版权和账号仍在公司手中；
- 大众喜欢人设，却不承认真实作品；
- 奖项确认专业能力，但市场渠道仍封锁主角；
- 主角夺回署名，却必须在商业路线和作者原则之间选择。

## T-B05｜商战创业

### 学习目标

区分：**股权、融资、估值、稀释、控制权、治理、运营、现金流和市场采用。**

### 核心名词

| 名词 | 具体解释 |
|---|---|
| 股权 | 企业所有权及附带的收益和决策权 |
| 融资 | 用股权、债务或条件换取资金 |
| 估值 | 市场或交易对企业价值的判断 |
| 稀释 | 新股份进入后，原股东比例下降 |
| 控制权 | 决定方向、人事和资源调用的能力 |
| 治理结构 | 股东、董事会和管理层如何分工制约 |
| 运营结构 | 产品、流程、团队和资源怎样持续运行 |

### 核心名词

| 文化资本 | 学历、礼仪、语言、审美和专业知识 |

| 象征资本 | 名誉、头衔、奖项和社会信任 |

|---|---|
| `x` | 舞台入口、奖学金、职位、资源、账号、推荐位、投资、决定权、控制渠道 |
| `z` | 导师认可、机构录取、同行改判、公众确认、家族承认、自我确认 |
| `zx` | 当众反击、公开夺回资格、拒绝羞辱、强势谈判、推翻旧评价权威 |

| `nx` | 只按贵人安排改造、替别人活、依附上位者、被包装成工具人 |

| `x并z` | 优等生、专业人士、明星、继承人、正式员工、获奖者、社会精英标签 |

### 真逆袭与假逆袭

```text
换装、变美、变强：只改变表象或能力
获得证明：能力变得可观察
获得认可：重要主体改判
获得准入：职位、学校、圈子或资源入口改变
获得控制：人物拥有新的决定权
形成持续位置：变化不再依赖一次表演
```

只有后几层真实发生，才构成社会位置意义上的逆袭。

### 剧情联想

- 女主变美后仍没有教育和职业准入；
- 主角能力被看见，却被别人夺走署名；
- 贵人帮助主角上位，同时逐渐替主角决定人生；
- 主角获得社会位置后，仍保留原来的关系归属和身份核心。
