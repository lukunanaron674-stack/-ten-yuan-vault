# G｜执念控制与危险关系

> Canvas是运行主体。本页保存每个题材12节点的文字索引与关键证据。

## T-G01｜占有型关系
- **0入口**：主`x`；辅`xz`/`nz`/`x并z`；结构候选。
- **1对象**：通讯、住所、社交、身体与选择权；证据：通讯｜社交｜住所与选择权被掌握｜危险边界缩窄。
- **2主体**：控制者／被控制者／外部关系网；区分稳定本体、阶段状态、关系功能。
- **3关系权限**：定义权｜退出权｜资源权｜解释权｜承载｜认可。
- **4触发行为**：限制升级、逃离尝试或关系暴露；补行动者、对象、目的、回应、收益、代价。
- **5状态转换**：亲密名义→权限被垄断→退路缩窄并逼出反抗或崩坏。
- **6十元端点**：主`x`；辅`xz`/`nz`/`x并z`；逐阶段记录体量与顺序。
- **7生克补**：x生x并z；xz补nz；nz克x；nz补xz；只作可检验方向。
- **8动态链**：被争夺对象出现 → 主体取得/失去控制边界 → x改变准入、使用或归属 → 生成公共壳或压制认可 → 权限进入下一轮
- **9主题**：命运候选；仍需中心问题、转折、高潮与结局共同显影。
- **10反证**：爱得深不等于x；必须实际剥夺或垄断权限；执行拿掉测试与替代解释。
- **11输出**：对象状态卡｜双主体关系卡｜行为卡｜机制证据卡｜动态链｜主题卡。

## T-G02｜救命恩情/债务爱
- **0入口**：主`nx`；辅`x`/`nz`/`zn`；结构候选。
- **1对象**：恩情、债务、行动通道、道德解释权与依恋；证据：被救者沿债务关系通道行动｜恩人掌握道德入口。
- **2主体**：被救者／恩人／社会道德与共同对象；区分稳定本体、阶段状态、关系功能。
- **3关系权限**：定义权｜退出权｜资源权｜解释权｜承载｜认可。
- **4触发行为**：恩人提出要求或债务被重新解释；补行动者、对象、目的、回应、收益、代价。
- **5状态转换**：沿恩情通道行动→资源或选择被掌握→意义与依恋接受反证。
- **6十元端点**：主`nx`；辅`x`/`nz`/`zn`；逐阶段记录体量与顺序。
- **7生克补**：nx生x；x补zn；nz生nx；nz克x；只作可检验方向。
- **8动态链**：既有身份、债务、关系或制度通道存在 → 主体沿通道推进但不占方向决定权 → 获得对象或冲击公共壳 → 决定是否夺回方向权
- **9主题**：本体候选；仍需中心问题、转折、高潮与结局共同显影。
- **10反证**：服从不等于nx本体；可能只是关系位置；执行拿掉测试与替代解释。
- **11输出**：对象状态卡｜双主体关系卡｜行为卡｜机制证据卡｜动态链｜主题卡。

## T-G08｜病态依赖修复或崩坏
- **0入口**：主`nz`；辅`x`/`n`/`xz`；结构候选。
- **1对象**：唯一依赖、照料、控制、分离窗口与自我边界；证据：不愿关系结束｜唯一依赖｜控制升级与分离危险。
- **2主体**：依赖双方／治疗或外部支持者／替代关系；区分稳定本体、阶段状态、关系功能。
- **3关系权限**：定义权｜退出权｜资源权｜解释权｜承载｜认可。
- **4触发行为**：分离尝试、第三者进入或危机复发；补行动者、对象、目的、回应、收益、代价。
- **5状态转换**：停靠变唯一→承载转控制→危险窗口决定修复还是崩坏。
- **6十元端点**：主`nz`；辅`x`/`n`/`xz`；逐阶段记录体量与顺序。
- **7生克补**：nz克x；nz补xz；n克xz；xz补nz；只作可检验方向。
- **8动态链**：关系已有时间厚度与返回位置 → 主体不愿其结束 → nz推动借路维持或抵抗控制 → 错过/告别窗口完成结算
- **9主题**：命运候选；仍需中心问题、转折、高潮与结局共同显影。
- **10反证**：依赖不是天然nz；若核心是占有需主x；执行拿掉测试与替代解释。
- **11输出**：对象状态卡｜双主体关系卡｜行为卡｜机制证据卡｜动态链｜主题卡。
