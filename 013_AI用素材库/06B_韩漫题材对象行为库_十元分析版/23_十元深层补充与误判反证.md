# 23｜十元深层补充与误判反证

> “深层补充”不是新增一层十元理论，而是把题材、人物、关系、行为、场景和动态链中可复用的体感、功能、边界、反例与创作模板，回填为十元血肉。

## 一、深层补充的六种产物

| 补充层 | 要提取什么 | 例子 |
|---|---|---|
| 人物血肉 | 某十元长期怎样做人、选择和付代价 | `x`人物不仅占有，还会维护署名、通道和退出边界 |
| 行为血肉 | 某行为在什么条件下显影十元 | “公开承认”只有明确认可主体与认可对象时才偏`z` |
| 关系血肉 | 两个位置怎样分配资源、方向、公开权和退出权 | 上司`xn`组织方向，下属用`nx`通道推进 |
| 空间血肉 | 空间怎样容纳、展示、封锁或逼近 | 家庭容器偏`n`，公共门面偏`x并z`，追逐通道偏`xz` |
| 时间血肉 | 十元何时升高、退隐、回收或转位 | 合同到期使`xn`退场，关系余温`nz`才可能显影 |
| 误判血肉 | 什么看起来像但实际不是 | 黑暗场景不等于`xz`，温柔不等于`n/nz` |

## 二、十元最近邻边界与韩漫误判

### 1. `x`｜掌握边界

**深层血肉**

- 不是“想得到”，而是已经拥有或正在争夺对象的使用、分配、进入、退出、署名与解释权限。
- 韩漫里最稳定的`x`对象不是金钱本身，而是金钱能关闭或开放什么接口。
- 爱情中的`x`不等于吃醋。只有角色实际控制通讯、住所、社交、身体决定、婚姻解释或退出条件，才形成掌握边界。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `zx` | `x`重在“归谁掌握”；`zx`重在主体权能公开显现、扩大并压过他者 |
| `xn` | `x`决定谁能用；`xn`组织怎样持续运行 |
| `nz` | `x`不让你走因为关系归我；`nz`不想结束但不应剥夺退出权 |
| `n` | `x`把对象纳入我方边界；`n`把落下的负荷接住并处理 |

**反证**：富豪、黑帮、嫉妒、霸道台词、送昂贵礼物都不能单独证明`x`。

### 2. `zx`｜公开权能显现与扩大

**深层血肉**

- 竞技、猎人、战斗、料理和电竞的爽点，只有在能力真实改变客观结果、排名与他者位置时才进入`zx`。
- `zx`不等于“很强”。隐藏实力未调用时可以只是潜能；公开显现并扩张才形成完整功能。
- 权力者公开任命、驱逐、废黜或重排成员资格，是`zx`对关系结构的显权。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `z` | `z`需要认可主体确认；`zx`即使无人赞美，也已客观改变世界与位置 |
| `x` | `x`拥有对象；`zx`把权能做出来、扩大并压过 |
| `zn` | `zn`回答为何必须做；`zx`回答能否做成并显现 |

**反证**：聚光灯、盛装登场、狂妄表情、打斗场面、主角光环不等于`zx`。

### 3. `xn`｜主动组织持续运行

**深层血肉**

- 韩漫的合同、系统、赛程、证据链、训练、项目和回归布局，都是`xn`高频容器。
- 关键不在“有规则”，而在主体是否主动配置时间、节点、信息和资源，使多个行动持续协同。
- 一次聪明判断不是完整`xn`。跨阶段复用、修正和结算才形成结构。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `nx` | `xn`拥有方向和组织权；`nx`沿别人或现成流程提供的方向推进 |
| `x` | `xn`设计系统怎样运行；`x`掌握谁能进入、使用与退出 |
| `zx` | `xn`依赖长期组织；`zx`依赖主体权能的公开有效显现 |

**反证**：冷静、制服、守规矩、按时上班、会算计、系统存在都不自动证明人物`xn`。

### 4. `nx`｜沿既有通道推进

**深层血肉**

- `nx`不是弱、被动、没主见，而是当前方向权与最终许可不在主体这里。
- 韩漫里的秘书、侍从、宿主、下属、欠债者、卧底和公会成员常使用`nx`关系功能。
- 强`zx`人物求人、借法宝、调用关系网络时，也可以使用`nx`功能。
- `nx`最重要的分析问题是：“谁给了方向和接口？主体借了哪条关系或权限通道？”

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `n` | `nx`沿通道推进；`n`把负荷接到自己内部处理 |
| `xn` | `nx`不掌握最终方向；`xn`主动搭建和调整方向结构 |
| `xz` | `nx`受通道约束；`xz`受危险与时间窗口逼迫 |

**反证**：沉默、服从一次、性格温顺、被欺负、没有资源均不足以证明人物主`nx`。

### 5. `x并z`｜壳与表里分层

**深层血肉**

- 韩漫最常见的`x并z`不是撒谎，而是假婚、恶役名声、艺人人设、卧底身份、贵族礼法、账号人格、替身与附身身体。
- 壳必须真实改变别人怎样识别、调用、信任和允许主体进入某个位置。
- 好的壳可以保护内部，坏的壳可以污染关系证据；道德评价不能代替结构判断。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `x` | `x`掌握边界；`x并z`把边界包装成世界可读取的接口 |
| `z` | `x并z`提供可识别对象；`z`发生认可与确认 |
| `nx` | `x并z`是身份壳；`nx`是沿关系/流程通道行动 |

**反证**：一句谎言、换装、秘密、演员职业、两面三刀不能单独证明`x并z`。

### 6. `zn`｜意义与精神主体

**深层血肉**

- 韩漫里`zn`常不作为题材发动机，而作为人物在中后段拒绝系统、家族、复仇和角色安排的稳定核心。
- `zn`最有价值的时刻不是宣言，而是在没有奖励、可能失去爱、职位或生命时仍不背弃某条意义。
- 正义、爱情、创作、医德和传承都只是容器。必须回答“不这样做为什么就不再是我”。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `z` | `zn`不依赖外部确认；`z`需要重要认可位置 |
| `n` | `zn`因意义主动承担；`n`因事情落到自己身上而接住 |
| `zx` | `zn`提供方向；`zx`提供公开有效的改变能力 |

**反证**：善良、热血、三观正、宗教、英雄台词、牺牲结果都不能直接证明`zn`。

### 7. `z`｜认可主体的确认

**深层血肉**

- 娱乐圈、艺术、校园、职场逆袭和受害者叙述题材，为`z`提供大量“谁认可、认可什么、为何重要”的对象血肉。
- `z`不只是大众喝彩。恋人、导师、家人、对手、历史、想象观众甚至自我认可都可能成为认可主体。
- 作品、能力、身份、选择、发现和完整精神存在，是不同的认可对象，不能混成“被看见”。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `zx` | `z`关注确认关系；`zx`关注权能实际改变与扩大 |
| `x并z` | `x并z`提供公共壳；`z`通过壳完成正确归因与确认 |
| `nz` | `z`问“你是否确认我”；`nz`问“这段关系是否还不想结束” |

**反证**：目标、努力、舞台、流量、曝光、追光、执念、耀眼视觉都不能脱离认可关系判`z`。

### 8. `n`｜接住、承载、消化

**深层血肉**

- 临时家庭、医疗、救援、末日共同体、同居、美食店和育儿，是`n`最丰富的韩漫血肉区。
- `n`不是“承担很多”，而是负荷真实落入主体内部，主体继续处理、消化并维持承载。
- `n`可以崩溃，但即使崩溃也仍在处理；如果只挨打而没有内部处理，不是完整`n`。
- 保护行为若剥夺选择和退出权，会从`n`滑向`x`。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `nz` | `n`接住后可以放下；`nz`接住后还不想结束 |
| `zn` | `n`因为落到了我这里；`zn`因为这是不可背弃的意义 |
| `nx` | `n`在内部消化负荷；`nx`沿外部通道推进 |

**反证**：温柔、母亲、善良、可靠、隐忍、受害和房屋场景都不自动证明`n`。

### 9. `nz`｜柔情停靠与不想结束

**深层血肉**

- 旧爱、临时家庭、宠物、旧屋、共同创伤和长期假婚，可为`nz`提供“时间厚度、余温、回返位置”的血肉。
- `nz`的对象不是人本身，而是已经共同生活过、停靠过的关系位置和温度。
- `nz`不应被拿来美化控制。无法自由离开、被扣留证件和被债务绑定，核心更可能是`x/nx/xz`。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `z` | `z`追求被确认；`nz`维持已经存在过的温度 |
| `n` | `n`接住并处理；`nz`不愿让接住过的关系结束 |
| `x` | `nz`希望对方留下但保留其主体权；`x`通过权限不让对方走 |
| `xz` | `nz`提供归宿；`xz`提供真正错过与失去的窗口 |

**反证**：单恋、痴情、等人、恋爱题材、柔光、旧照片、哭着挽留均不足。

### 10. `xz`｜危险逼近与命运临界

**深层血肉**

- 囚禁、怪谈、恶役处刑、敌对阵营、逃亡、倒计时、末日与身份暴露，是`xz`高密度题材区。
- `xz`必须有可感知危险、缩窄的退路或时间窗，以及被迫发生的临界行动。
- “危险女性”不能从红黑服装、疯笑和性感姿态判断；必须分析她怎样改变他人的安全边界和行动可能。

**最近邻**

| 易混淆 | 区别 |
|---|---|
| `x` | `x`掌握对象和出口；`xz`是危险正在逼近、出口正在减少 |
| `zx` | `zx`主动显权；`xz`因为不行动就会被危险吞没 |
| `nz` | `xz`必须离开或抢窗口；`nz`想返回或多停一会儿 |

**反证**：黑暗、惨、疯、废墟、雨夜、悬崖、怪物外观、普通风险都不自动证明`xz`。

## 三、显影、退隐、污染与复位

### 1. 显影

某十元从背景升为主导，必须出现：

- 对象或权限被改变；
- 行为选择因此改变；
- 其他机制的路径被压缩或重排；
- 在关键转折中可观察。

### 2. 退隐

十元退隐不等于消失。契约解除后`xn`可能退到背景，人物的`zn`稳定核心仍可保留；危险解除后`xz`下降，关系中的`nz`才可能成为落点。

### 3. 污染

“污染”只描述某十元的血肉被另一机制扭曲，除非关系正本已经锁定，不自动写成正式生克。

常见候选：

```text
n保护被x污染 → 接住变成替人决定和剥夺出口
nz停靠被x污染 → 不想结束变成不允许离开
z认可被x并z污染 → 被确认的是人设壳而非真实主体
zn信念被zx污染 → 意义变成必须压过他者的权能证明
xn组织被x污染 → 流程只服务于门控和占有
nx借力被xz污染 → 沿通道推进变成无退路逃亡
```

这些是分析候选，不是未经专项验收的正式十元关系。

### 4. 复位

- `n`完成承载后清空负荷，恢复可再次接住的容器状态。
- `xn`完成阶段结算后重设节点和流程。
- `z`获得确认后释放当前认可压力，但新的认可对象可能出现。
- `xz`进入安全承载范围后，危险紧迫度下降。
- `nz`完成真正告别后，余温可保留，但等待姿态结束。

## 四、体量、顺序与稳定锚点

### 体量不是戏份多少

```text
体量 = 该十元对对象、关系、选择和结局的决定程度
```

一个只出现两分钟的证据公开，可能以体量8改变整季关系；一个陪伴几十话的日常习惯，也可能只是体量3背景血肉。

### 顺序不是剧情列表

分析顺序应写：

```text
起手机制
→ 第一被作用机制
→ 承载位
→ 冲突位
→ 结算位
→ 最终落点
```

### 稳定锚点

每条人物动态链都必须注明什么没有变：

```yaml
stable_anchor:
  character_core:
  still_true_after_change:
  evidence_under_cost:
```

例：契约婚姻里的继承人从`x`控制转为交还选择权，不代表人物完全变成`n`。他的稳定锚点可能仍是“必须掌握现实资源才能保护对象”，只是掌握方式受到`zn`重新定向。

## 五、五类对象分别怎样回填十元血肉

| 原库对象 | 最有价值的十元补充 |
|---|---|
| 主体对象 | 人物本体、状态转位、稳定锚点与最近邻反例 |
| 关系对象 | 资源权、方向权、公开解释权、退出权与关系位置 |
| 资源对象 | `x`掌握边界、`xn`流程节点、`z`认可对象和`zx`显权结果 |
| 秘密对象 | `x并z`壳、`x`公开权、`xz`暴露风险和`z`归因问题 |
| 场域对象 | `n`承载、`x并z`公共界面、`xn`规则、`xz`路径和主题空间显影 |
| 行为对象 | 当前功能十元、意图改判条件、代价和被改变变量 |
| 行为链 | 十元顺序、阶段接管、关系牙印、结算与落点 |

## 六、五个完整分析示例

### 示例1｜契约婚姻

```yaml
object_layer:
  relationship_shell: x并z
  contract_operation: xn
  resource_control: x
  recognition_position: z
  attachment_state: nz候选
sequence:
  - xn建立期限与条款
  - x并z形成公共配偶壳
  - x通过资金和身份越界掌握
  - x并z克nz候选在“真心/履约无法归因”时成立
  - 解除合同，x与xn退隐
  - 无绑定状态下重新选择，z或zn成为结算
primary_theme: 本体
center_question: 去掉合同与角色壳后，这段关系究竟是什么
```

### 示例2｜恶役千金改命

```yaml
start: xz处刑结局逼近
method: xn提前重排节点和资源
shell: x并z恶役身份壳
core_candidate: zn拒绝继续按原剧本道德角色活
resource_boundary: x建立独立领地、资金或退出权
theme:
  primary: 命运
  secondary: 本体 / 因果
misjudgment: 恶役服装和傲慢表情不能证明x并z人物本体
```

### 示例3｜猎人升级

```yaml
start: nx沿公会、系统或队伍通道进入副本
method: xn理解关卡规则与训练结构
manifestation: zx能力公开显现并扩大
resource: x获得装备、技能和队伍资格
risk: xz在副本崩坏与时间窗缩窄时显影
theme:
  primary: 因果或时间，需看结局回答训练结果还是选择责任
misjudgment: 战斗场面不能直接证明zx；外挂获得也不等于主体权能真正扩大
```

### 示例4｜临时家庭

```yaml
start: n接住临时成员
progress: n生xn，形成接送、家务、医疗与分工
interface: n补x并z，获得“家人”、住址、姓氏或店铺的公共壳
attachment: nz在成员准备离开时显影
risk: 外部xz逼近
counter: n克xz，前提是家庭真正提供停留、补给和返回位置
primary_theme: 空间
center_question: 无血缘者能否共同建立一个可存在和返回的位置
```

### 示例5｜连环案件

```yaml
method: xn组织时间线、证据与排除过程
control: x决定谁掌握档案、发布与调查权限
shell: x并z伪证、假身份和公共形象
risk: xz在真凶逼近或证人受威胁时显影
recognition: z在真相被正确归因和公共指认时完成
theme:
  primary: 因果
  evidence: 多起事件被追溯到同一来源、责任和作用链
misjudgment: 有谜底不自动形成因果主主题；高潮必须真正追责而非只揭脸
```

## 八、分析版的剩余缺口

1. 64题材分类目前是结构候选，尚未逐条通过真实韩漫关键转折、高潮与结局复验。
2. 120行为是默认功能接口，同一行为在不同意图和关系位置下必须改判。
3. 除已锁定关系外，不能因为几何位置存在就补写统一机制。
4. 本版尚未统计不同平台、性别取向、篇幅和分级下的十元分布差异。
5. 视觉与演出血肉仍需从真实分镜、竖屏节奏和角色姿态逐项采矿。
6. 人物稳定本体不能从题材库自动生成，必须在完整作品中跨阶段验证。

## 九、冻结防线

```text
不默认zn起手。
不默认n承载所有温柔。
不从视觉反推人物本体。
不从结局倒推动态链起手。
不把旧z“追光/执念”口径带回当前分析。
不把题材发动机当人物永久十元。
不把两个十元并存写成五大主题生成。
不把未锁定关系包装成正式生克机制。
```

> 本版真正的价值不是给每一项贴上十元标签，而是让每个标签都能回答：**谁在什么层次上，通过什么行为改变了哪个对象的什么变量，并把统一大感觉推向哪里。**
