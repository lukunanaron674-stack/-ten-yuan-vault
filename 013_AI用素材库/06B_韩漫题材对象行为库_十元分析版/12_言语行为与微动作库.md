# 12｜言语行为与微动作库

> 原行为库擅长“做什么”，但对“怎么说”和“身体怎样泄漏真实立场”覆盖不足。漫画尤其依赖对白气泡、停顿、视线和手部动作。把这些全归为“聊天”，等于把作画全归为“拿笔乱划”，多少有点侮辱劳动。

## 一、言语行为库

| 规范ID | 言语行为 | 直接对象 | 主要功能 | 常见反制 |
|---|---|---|---|---|
| VB-S01 | 直接询问 | 信息 | 要求对方明确回答 | 回避、反问、沉默 |
| VB-S02 | 追问细节 | 叙述漏洞 | 加压并验证真实性 | 修改口径、发怒 |
| VB-S03 | 反问 | 对方立场 | 拒绝接受问题预设 | 被要求正面回答 |
| VB-S04 | 打断 | 发言权 | 阻止羞辱、暴露或失控 | 对方提高音量或转向公开场合 |
| VB-S05 | 改称呼 | 关系身份 | 把关系拉近、疏远或正式化 | 对方拒绝该称呼 |
| VB-S06 | 给出承诺 | 未来行为 | 建立可检验期待 | 被追问期限与条件 |
| VB-S07 | 撤回承诺 | 未来行为 | 宣告关系或条件改变 | 信誉损失 |
| VB-S08 | 告白 | 私人欲望 | 终止暧昧解释空间 | 拒绝、延迟、要求行动证明 |
| VB-S09 | 否认感情 | 关系认知 | 保护身份或逃避风险 | 身体行为与语言矛盾 |
| VB-S10 | 正式道歉 | 责任 | 承认造成的具体后果 | 对方接受道歉但拒绝复合 |
| VB-S11 | 辩解 | 责任解释权 | 降低自身责任 | 被证据或受害体验反驳 |
| VB-S12 | 指控 | 责任对象 | 把隐性冲突公开化 | 反指控、要求证据 |
| VB-S13 | 威胁 | 安全/资源 | 用未来损失迫使服从 | 对方亮出更大把柄 |
| VB-S14 | 要挟报价 | 秘密/资源 | 将威胁转成交易 | 对方拒绝交易并公开秘密 |
| VB-S15 | 撒谎 | 事实认知 | 保护秘密或操纵行动 | 细节矛盾、第三方证词 |
| VB-S16 | 半真半假 | 事实认知 | 提供可验证部分以掩护核心 | 对方只相信被隐去部分 |
| VB-S17 | 公开声明 | 群体叙述 | 改变名誉、身份或阵营 | 舆论追查证据 |
| VB-S18 | 私下坦白 | 亲密信任 | 给予单独知情权 | 对方要求同步公开 |
| VB-S19 | 请求许可 | 边界/行动 | 承认对方拥有决定权 | 被拒绝或附加条件 |
| VB-S20 | 代替回答 | 他人主体权 | 保护、控制或抢夺解释权 | 被代答者当场纠正 |
| VB-S21 | 给出评价 | 能力/人格 | 配置认可或羞辱 | 对方拒绝评价体系 |
| VB-S22 | 公开感谢 | 劳动/帮助 | 让隐形付出被看见 | 被感谢者拒绝被包装成恩人 |
| VB-S23 | 发布命令 | 他人行动 | 建立强制上下关系 | 拒命、拖延、曲解执行 |
| VB-S24 | 宣布退出 | 关系/组织 | 收回继续参与的许可 | 对方提出新条件或阻拦 |

## 二、微动作库

| 规范ID | 微动作 | 暴露的信息 | 可承载的行为功能 | 误读风险 |
|---|---|---|---|---|
| VB-M01 | 视线停留后移开 | 在意但不愿被发现 | 试探、压抑、观察 | 也可能只是警觉 |
| VB-M02 | 避开眼神 | 羞愧、撒谎、害怕或拒绝亲密 | 隐瞒、撤退 | 不能直接等同心虚 |
| VB-M03 | 主动对视 | 挑战、确认或请求被看见 | 反抗、告白、审问 | 需结合距离和表情 |
| VB-M04 | 手指收紧 | 压抑冲动或恐惧 | 克制、忍耐、准备攻击 | 单格难区分情绪类型 |
| VB-M05 | 松开抓握 | 放弃控制或允许离开 | 放手、认错、失去力量 | 也可能是体力耗尽 |
| VB-M06 | 收回伸出的手 | 请求被拒或自我阻止 | 撤回接近、尊重边界 | 需保留前置动作 |
| VB-M07 | 把物品推回 | 拒绝债务、礼物或身份 | 设限、退还、反抗 | 物品意义必须提前建立 |
| VB-M08 | 把钥匙放下 | 归还空间控制权 | 放权、离开、信任 | 钥匙归属需明确 |
| VB-M09 | 替对方整理衣物 | 低风险照料或身份表演 | 亲密、控制、演戏 | 动作可甜也可压迫 |
| VB-M10 | 挡在前面 | 公开优先保护某人 | 保护、宣示、阻断 | 可能同时剥夺被保护者发言 |
| VB-M11 | 退后半步 | 让出空间或产生戒备 | 尊重、拒绝、恐惧 | 配合视线判断 |
| VB-M12 | 站到同一侧 | 公开选边 | 支持、结盟、共同承担 | 必须让旁观者看见 |
| VB-M13 | 改变座位 | 关系位置变化 | 接近、疏远、夺权 | 场景座次规则需建立 |
| VB-M14 | 保留空位 | 等待与归属许可 | 邀请返回、纪念 | 不能只靠旁白解释 |
| VB-M15 | 删除消息又恢复 | 犹豫是否建立联系 | 接近、撤回、坦白 | 过度使用会拖沓 |
| VB-M16 | 静音而不拉黑 | 暂停接触但保留关系 | 设限、等待 | 与彻底退出区分 |
| VB-M17 | 把伤口藏起来 | 拒绝依赖或保护他人 | 隐瞒、逞强 | 需产生后续代价 |
| VB-M18 | 主动露出伤口 | 请求照料或提供证据 | 求助、坦白、指控 | 可能被利用 |
| VB-M19 | 吃下对方留下的食物 | 接受低风险照料 | 和解、依赖、停靠 | 需建立食物关系意义 |
| VB-M20 | 停在门口不进入 | 想靠近但尚未获得许可 | 等待、试探、告别 | 门内外空间关系要清晰 |
| VB-M21 | 主动关门 | 建立私密谈判或隔绝外界 | 坦白、威胁、保护 | 容易转成压迫画面 |
| VB-M22 | 把门保持敞开 | 保留退出权 | 尊重、信任、邀请 | 与警戒不足区分 |
| VB-M23 | 撕毁象征物 | 终止旧身份或关系规则 | 反抗、清算、告别 | 需承担不可逆后果 |
| VB-M24 | 修复象征物但保留裂痕 | 关系修复但不抹除历史 | 和解、记忆保留 | 不应等于恢复原状 |

## 三、组合公式

```text
言语行为 + 微动作 + 对象状态变化 = 可画出的关系推进
```

例：

```yaml
言语行为: VB-S20 代替回答
微动作: VB-M10 挡在前面
直接对象: 契约配偶的公开身份
表层功能: 保护
隐藏功能: 控制解释权
对象反制:
  言语: 当场纠正他的说法
  微动作: 从他身后走到同一侧
结果: “被保护者”改为“共同发言者”
```

## 四、使用约束

1. 微动作不能脱离前后格独立定性。
2. 同一动作至少保留两种可能解释，让后续行为完成确认。
3. 对白必须改变信息权、关系权、行动权或公共评价中的至少一项。
4. 沉默只有在“本来应当回答”时才构成行为。
5. 频繁使用误会和欲言又止，却不产生对象变化，属于拖延而非细腻。
