# 偶像身份推进与粉丝推位对照｜卷册补证

## 一、本轮边界

本轮把“偶像题材”进一步拆成两条路线：

- **推位型**：粉丝进入偶像的新竞争场，替偶像组织曝光和上位。
- **自我偶像型**：角色以自己的偶像身份进入准备、团体和舞台流程。

比较作品：《我推的孩子》《偶像崇拜》《如果推的偶像能登上武道馆我就死而无憾》。第三部本轮仍只作题材对照，不产生动作记录。

## 三、原始行为清单与后置归类

### A. 《偶像崇拜》／陽見循菜

- 行为1：ふわ里所属的偶像团体解散，且循菜得知ふわ里参加百人选秀 → 循菜亲自出场参加选秀 → 作用于自己的参赛资格、ふわ里的新路线和两人的同赛程关系 → 循菜进入选秀。【IDOLATRY-EP1】
  - 归类：`nx`（来源已闭合候选）。官方简介确认“亲自出场”，但原卷中具体进入动作和结果还未定位。
- 行为2：循菜要把推带到百人选秀顶点 → 循菜决定在选秀中暗中行动 → 作用于选秀竞争过程和推位目标 → 官方简介确认“暗中行动”，但没有策略节点和结果细节。【IDOLATRY-EP1】【IDOLATRY-EP3】
  - 归类：`xn`（来源已闭合候选）。必须看到多个流程节点被她主动组织后，才可升级锁定。

### B. 《我推的孩子》／星野露比及团体层

- 行为1：进入有艺能科的高中后，露比看到同学已经在芸能界活动并产生焦虑 → 露比开始准备偶像活动 → 作用于自己的偶像活动准备与未来舞台资格 → 官方第3卷简介明确写出“开始准备”，但没有训练内容、时间节点或结果。【OSHI-V3-OFFICIAL】
  - 归类：暂不归类（证据不足）。这是可观察动词，但对象粒度仍太粗，不能直接判 `xn` 或 `z`。
- 行为2：露比所属的新生 B 小町面向第一次舞台正式开始活动 → 作用于团体活动与首演安排 → 这是团体层叙述，简介没有把动作归给露比个人。【OSHI-V4-OFFICIAL】
  - 归类：暂不归类（对象层不合）。不能把团体行为直接转写为露比个人行为。
- 行为3：阿库亚受网络剧制作人邀请出演恋爱真人秀 → 作用于节目出演与芸能界关系 → 官方第3卷简介确认出演，但阿库亚不是本轮偶像主角，保留为芸能界邻接证据，不进入偶像行为库。【OSHI-V3-OFFICIAL】
  - 归类：暂不归类（题材边界）。演员/综艺出演不自动等于偶像行为。

## 四、母型细化

### 1. 推位型：外部方向进入并组织

```text
偶像失去原舞台
→ 粉丝沿偶像的新路线进入竞争场
→ 粉丝把自身参赛转成暗中推位
→ 目标变量是偶像的排名、曝光与上位路径
```

当前由 Idolatry 的官方简介直接支持，状态仍为 `draft-theme-pattern`。

### 2. 自我偶像型：准备进入但证据尚浅

```text
进入芸能教育环境
→ 看到同龄偶像并产生位置压力
→ 开始准备自己的偶像活动
→ 团体首演与公开身份形成后续观察窗口
```

《我推的孩子》第3、4卷只支持到“开始准备/团体正式活动”的简介层，尚不能判定具体十元或与推位型发生关系。
