# 偶像资格压力与路线回返：AKB49第2卷对照

## 本轮边界

本轮从“伪装身份进入偶像组织”继续收窄，观察资格已经取得之后，主体如何面对训练/中心位置压力，以及是否主动回到原有路线。只记录主体的可观察动作，不把“被选为中心”“团体首演”等被动结果或团体动作直接算成个人行为。

## 行为先行穷举

### 《AKB49～恋爱禁止条例～》｜浦山实/浦川みのり

身份：男高中生浦山实，以“浦川みのり”化名女装进入AKB48研究生体系。范围：第1卷官方简介＋第2卷正版商品简介，非全作逐页实读。

- 行为1：得知同级生要参加AKB48选秀 → 采用“浦川みのり”化名并女装潜入选秀 → 选秀身份识别与入场接口 → 以伪装身份进入并与同级生一同合格。【SRC-1】【SRC-2】
  - 归类：`x并z`（候选，不锁定）。对象端点：选秀入口、性别/姓名识别和临时资格接口。理由：公开简介明确身份壳改变了进入结果；但尚未看到组织现场规则，不能升级为`x`控制。
- 行为2：取得研究生资格后被安排参加研究生公演 → 接受中心位置并面对自身实力不足 → 研究生公演的中心位置与训练关系 → 公开简介只确认“被选为中心”，未说明这是其主动争取。【SRC-3】
  - 归类：暂不归类（证据不足）。理由：被选为中心是外部结果，不能冒充主体的控制或持续经营动作。
- 行为3：担任中心且担心实力不足会给同伴添麻烦 → 在训练中逃出 → 训练路线、同伴协作和即将到来的舞台 → 暂时退出训练现场，舞台路线被中断。【SRC-3】
  - 归类：`xz`（候选，不锁定）。对象端点：训练现场与即将到来的演出资格。理由：主体主动关闭当下训练路径，符合“危险/收窄选择”方向；但需原卷确认逃出持续多久、是否真正失去资格。
- 行为4：看到吉永仍相信并等待自己 → 重新下定决心返回剧场 → 原有同伴关系与研究生舞台路线 → 返回剧场，公开简介将其连接到研究生舞台初日。【SRC-3】
  - 归类：`nx`（候选，不锁定）。对象端点：既有研究生路线、同伴关系和剧场入口。理由：动作是回到已经建立的路线/关系渠道；“舞台初日”是结果，不能进一步推断表现质量。
- 行为5：研究生公演初日开始 → 研究生们登台 → 团体首演对象 → 公开简介确认首演幕开，但未给浦山个人舞台动作。【SRC-3】
  - 归类：暂不归类（证据不足）。理由：团体结果不能直接归给单一主角。

## 母型卡：资格压力下的路线回返

- 核心对象：已取得的偶像资格、训练现场、同伴协作关系和首演入口。
- 主体位置：刚获得资格但能力/身份不稳的新人；外部期待突然高于其可用能力。
- 关系/权限：主体拥有研究生/团体入口，但中心位置和正式舞台仍受组织安排、训练能力与同伴关系约束。
- 可观察行为：
  1. 以身份壳取得选秀入口（AKB49-A1）。
  2. 在新资格中被安排到高可见度位置（AKB49-A2，结果级，暂不归类）。
  3. 因能力压力主动离开训练现场（AKB49-A3，`xz`候选）。
  4. 因同伴仍等待而返回既有路线（AKB49-A4，`nx`候选）。
- 对象前后状态：无资格 → 临时资格 → 高曝光/能力不匹配 → 训练路线中断 → 关系触发回返 → 首演入口重新打开。
- 行为链候选：`身份壳进入 → 资格获得 → 位置压力 → 退出路径 → 关系召回 → 既有路线回返`。
- 情绪回报：先是“终于能同行”的满足，随后是害怕拖累同伴，最后通过回返恢复承诺与共同目标；情绪不是十元证据。
- 反证：若主体只是被迫留下、被他人拉回而没有主动返回，A4不能判`nx`；若逃出是短暂喜剧桥段且没有训练/资格变量变化，A3不能判`xz`。
- 相邻题材区别：不同于AKB49第1卷的“伪装入团”（入口机制）；不同于Idolatry的“推位经营”（目标是他人排名）；不同于《神渣☆偶像》的“低投入外部重启”（资格已存在但不是新人压力）；不同于《我推的孩子》当前公开资料中的“偶像准备状态”（动作粒度不足）。
- 适用作品：有公开的训练、资格、中心/首演安排与回返行为的偶像作品。不适用：只写舞台光环、粉丝情绪或团体结果而没有主体动作的作品。

## 十元与关系结论

- 当前L1下仅保留候选：AKB49-A1=`x并z`、A3=`xz`、A4=`nx`；Idolatry各1条`nx/xn`候选。
- 不能由“先退出后返回”直接登记生克补。若原卷确认同伴关系是触发回返的第三因素，仍需补齐源端、目标端、机制、被改变变量、阶段与反向检查。
- 作品主维只记录“偶像资格/训练/团内位置竞争”，不把`x并z`、`xz`、`nx`候选写入正式正本或JSONL。
