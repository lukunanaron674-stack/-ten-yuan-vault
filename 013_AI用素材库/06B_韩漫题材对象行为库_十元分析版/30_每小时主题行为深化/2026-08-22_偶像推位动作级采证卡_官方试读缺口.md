# 偶像推位动作级采证卡｜官方试读缺口

## 一、本轮问题

检查 Idolatry 官方第1、3话是否提供可读取的动作级试读内容，判断前轮两条 `nx/xn` 候选能否升级。

## 二、现场检查结果

### 官方第1话与第3话

- [第1话](https://pocket.shonenmagazine.com/title/02901/episode/420905)：HTTP 200。
- [第3话](https://pocket.shonenmagazine.com/title/02901/episode/421671)：HTTP 200。

服务器端 HTML 能确认：标题、日期、作品简介、缩略图、总话数/免费话数元数据，以及正規版配信站标识；阅读器主体只有空的 `c-viewer__content` 容器，实际漫画页由前端动态加载，HTML 没有可直接核对的页面图像、对白、动作或结果。

这意味着本轮只能确认“作品官方简介说了什么”，不能声称已经读到第1—3话具体场景。没有绕过登录、付费或阅读器权限。

### 《我推的孩子》与《推武道》

前轮已验证官方原作/卷册页 HTTP 200；本轮没有发现比卷册简介更细的公开动作层材料，因此不重复生成旧18条，也不把粉丝关系词转成行为。

## 三、动作清单与分类门槛

- 行为1：偶像团体解散且ふわ里参加百人选秀 → 循菜亲自出场 → 参赛资格、偶像新路线、同赛程关系 → 官方简介明确写出进入选秀，但没有场景页码和结果细节。【IDOLATRY-EP1】
  - 归类：`nx`（来源已闭合、动作级未闭合候选）。继续等待合法原卷/试读场景；不升级 locked。
- 行为2：循菜要把推带到百人选秀顶点 → 循菜决定在选秀中暗中行动 → 选秀竞争过程、推位目标和上位路径 → 官方简介明确写出“暗中行动”，没有具体策略节点和可观察结果。【IDOLATRY-EP1】【IDOLATRY-EP3】
  - 归类：`xn`（来源已闭合、动作级未闭合候选）。不能用“暗中行动”四字代替多个组织动作。
- 行为3：露比开始准备偶像活动 → 具体准备对象、节点、训练动作和结果未公开 → 目前无法闭合对象端点。【OSHI-V3-OFFICIAL】
  - 归类：暂不归类（证据不足）。
- 行为4：新生 B 小町正式面向首演开始活动 → 行动主体是团体，非露比个人动作 → 团体层结果不能越级转写人物层。【OSHI-V4-OFFICIAL】
  - 归类：暂不归类（对象层不合）。
