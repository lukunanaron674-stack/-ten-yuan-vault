# 主角十元行为穷举 · 偶像反转后公开旧关系

## 本轮边界

本轮只处理“身份反转/偶像竞争状态中，主体是否主动把旧同学、旧关系或原有称呼带入当前公开场景”。重点为《Audition in Disguise》第4话前段；其余三部作品作机制对照。只记录主角实际说出、呼叫或执行的动作，不把旁观者的惊讶、笑声或主持人的节目流程归给主角。

## 《Audition in Disguise》｜Lee Chohee

身份：原女性偶像，在第1话舞台中突发男性外观；第4话前段以男性参赛者外观与旧同学Wi Inwoo重逢。本轮不外推她是否会借旧关系经营节目镜头。

- 行为1：在身份反转后的男性参赛者集合中认出旧同学Wi Inwoo → 主动喊出对方姓名并说“我们是同学” → 当前参赛者之间的旧关系与公共身份说明 → 画面随后让房间内其他人知道两人是同学，但未改变排名、资格或节目资源。【SRC-2】
  - 归类：`z`（候选，不锁定）。理由：主体主动把旧关系带入当前场景，首先改变的是“谁被确认、关系如何被看见”；若后续借此获得资格/镜头，才考虑`nx`或`zx`功能。

## 《AKB49～恋爱禁止条例～》｜浦山实/浦川みのり

身份：男高中生，为支持同级生主动采用女性化名和外观进入女性选秀。范围限于官方第1卷简介。

- 行为2：想支持参加选秀的同级生 → 主动采用“浦川みのり”这一女性化名并女装潜入 → 旧同学关系与选秀身份接口 → 与同级生一同合格为研究生，双重身份风险启动。【SRC-3】
  - 归类：`x并z`（既有候选，不锁定）。这是用公共身份壳保护并承载旧关系，不是公开确认本身的`z`。

## 《偶像狂热》｜Junna

身份：解散团体成员、推的偶像的支持者。范围限于官方作品介绍与第1话入口。

- 行为3：得知旧团体成员Fuwari参加百人选秀 → Junna本人报名并暗中推动推的偶像登顶 → 旧团体关系、选秀渠道与他人排名 → 报名和推位目标成立，但旧关系是否被公开确认及排名结果未公开。【SRC-4】
  - 归类：`nx`（既有候选，不锁定）。她沿既有关系和选秀通道推进，不因“旧团体”或“登顶”字样直接判`z`/`zx`。

## 《我推的孩子》｜星野露比

- 行为4：面对母亲留下的舞台目标与同龄偶像环境 → 开始准备偶像活动 → 自身偶像身份与团体路线 → 公开资料没有她主动呼叫旧关系、公开确认身份或因此改变资格的动作级结果。【SRC-5】

## 母型卡：旧关系公开确认—当前身份重叠

- 核心对象：旧同学/旧团体关系、姓名、当前偶像身份与节目内公共叙述。
- 主体位置：身份反转或角色转换后，仍保留旧关系记忆的参赛者；有发言权，但不掌握他人是否承认或节目如何使用该关系。
- 关系/权限：主体能主动呼叫并声明关系；同场参赛者获得知情，但节目资格和资源仍由组织/评审控制。
- 可观察行为：①喊出旧同学姓名；②公开说两人是同学；③对照：用化名承载旧同学关系进入选秀；④对照：沿旧团体关系通道为推的偶像报名。
- 对象前后状态：陌生/隐藏旧关系 → 主体识别 → 公开呼叫与声明 → 同场群体知道关系 → 是否形成合作、镜头、资格或风险变化待后续。
- 行为链候选：`身份反转 → 旧关系重逢 → 主体公开确认 → 群体关系重排 → 资源/资格后果待观察`。
- 情绪回报：重逢带来短暂亲近和身份连续感，也暴露“旧我/新我”是否冲突；情绪不替代十元判定。
- 反证：若Chohee后续否认旧关系、利用关系操纵镜头或改变排名，需拆成`x并z`、`nx`或`zx`功能；若只是偶遇问候且对后续关系无影响，保留`z`场景候选即可。
- 相邻题材区别：不同于第1话公开舞台扩展可见性的`zx`候选；不同于AKB49主动伪装入团的`x并z`；不同于偶像狂热粉丝沿既有渠道推位的`nx`；也不同于《我推的孩子》目前仅有的准备状态。
- 适用：旧关系声明会改变同场主体的认识、合作或资格讨论的偶像作品。不适用：只有回忆旁白、观众单方面认出、或他人替主角宣布关系的场景。

## 主十元

本轮主十元暂记`z`候选：Chohee主动确认旧同学关系，使关系对象被当前群体看见；因尚未改变资格、排名或资源，不能判`zx`。
