# 主角十元行为穷举 · 偶像身份反转的被动显影

## 本轮边界

本轮复核上一轮对《Audition in Disguise》的身份条件疑问。通过WEBTOON官方第1话的公开图像序列，确认“成为男性”不是Lee Chohee主动选择的伪装，而是在女性偶像演出中突然显影的身体/身份反转；她随后公开自称女性，但现场承认结果仍不明。该机制与《AKB49》主动化名女装潜入不同。

## 《Audition in Disguise》｜Lee Chohee

身份：女性偶像练习/演出者，公开图像显示在舞台演出中突然出现男性外观。范围：WEBTOON官方第1话图像序列，非全作实读。

- 行为1：站上偶像舞台并面对现场观众 → 持麦克风完成女性形象的歌唱/舞台表演 → 观众与演出现场 → 图像显示观众挥灯、呼喊和持续关注。【SRC-2】【SRC-3】
  - 归类：`zx`（候选，不锁定）。对象端点：公开舞台、观众注意与表演接口。理由：主体的公开表演确实扩展了可见性；不把观众情绪直接算成主体十元。
- 行为2：舞台演出持续中，身体/外观突然转为男性 → Chohee当场发现并试图理解变化 → 自身身体身份与舞台识别 → 图像把转变表现为突发事件，未显示她事前选择或控制。【SRC-3】
  - 归类：暂不归类（证据不足）。理由：这是主体遭遇的状态转换，不是她主动采取的身份伪装行为。
- 行为3：被周围人以“oppa/哥哥”称呼并被男性成员扶住 → Chohee反复喊“我是女性/我是女人” → 现场成员与公众对其性别/艺人身份的识别 → 现场出现短暂争执与混乱，尚未确认组织承认结果。【SRC-3】
  - 归类：`zn`（候选，不锁定）。对象端点：性别身份意义与舞台角色资格。理由：她主动用语言维护自身身份定义；但尚未看到这句话是否改变他人资格判断。
- 行为4：公司成员离开/出道准备中断的场景出现 → Chohee追问“为什么他们停止/离开？理由是什么？” → 公司合作关系与即将到来的出道路线 → 公开图像显示她提出质问，但未给回答和后续行动。【SRC-3】
  - 归类：暂不归类（证据不足）。理由：质问动作存在，但作用对象结果尚未闭合，不能强判信息处理或权限控制。

## 母型卡：偶像身份反转的被动显影

- 核心对象：公开舞台、观众识别、性别/身体身份与出道组织承认。
- 主体位置：已有表演能力和舞台入口，但身份状态在公开演出中突然变化的主体。
- 关系/权限：主体能控制表演动作和公开发言，却不能预先控制身体反转或组织对其新身份的解释。
- 可观察行为：
  1. 以原有身份完成公开舞台表演（`zx`候选）。
  2. 在突发身份反转后发现并承受状态变化（状态，不归类）。
  3. 公开喊出“我是女性”以维护身份定义（`zn`候选）。
  4. 追问公司/团队为何停止出道准备（待结果闭合）。
- 对象前后状态：女性艺人舞台 → 身体/外观突发为男性 → 公众识别混乱 → 主体口头自证 → 组织承认与出道路线悬置。
- 行为链候选：`公开表演 → 被动身份显影 → 公众误认 → 主体自证 → 组织资格复核`。
- 情绪回报：原本是舞台可见性，反转后转为身份危机与被承认需求；情绪不能替代行为分类。
- 反证：若后续证明反转是Chohee主动施术、变装或节目策略，母型应改为主动身份壳；若组织从未把新身份纳入资格判断，则只是身体奇观，不构成偶像身份题材行为。
- 相邻题材区别：与AKB49“主动化名女装”区别在主观控制与触发方向；与偶像狂热“粉丝进入并推位”区别在主体自身身份；与我推的孩子“偶像准备状态”区别在已有舞台动作与公开身份冲突；与神渣偶像“已有身份低投入重启”区别在危机来自身份显影而非投入不足。
- 适用：身份反转发生在公开演出并引起可观察的公众/组织识别变化的作品。不适用：仅有日常变装、艺名或无资格结果的性别玩笑。
