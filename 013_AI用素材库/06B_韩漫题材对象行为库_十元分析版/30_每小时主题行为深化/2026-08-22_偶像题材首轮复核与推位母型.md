# 偶像题材首轮复核：推位型推し活与偶像选秀

## 一、本轮边界

本轮只处理“确实以偶像、偶像团体、选秀或推し活为核心”的两部作品：

- 《我推的孩子》：偶像行业、艺人身份、粉丝凝视和身份反转；使用库内第九十七批既有报告作审计对象。
- 《偶像崇拜》（Idolatry／アイドラトリィ）：粉丝为了支持自己的偶像进入一百人选秀；使用库内公开简介和第八十四批行为报告。

本轮不把舞台艺术、普通音乐成长、演员行业或网红题材混入“偶像题材”。没有新增作品，也没有把旧记录直接升级为 locked。

### 2.1 口径冲突

旧报告 frontmatter 写的是“2026-08-12 天干总框”，并把 `z/nx/x/nz/x并z` 绑定到另一套五行称呼；当前 L1 v1.6 和行为库门禁仍以 `xn↔z、zn↔x、n↔x并z、zx↔nx、xz↔nz` 为正本。旧称呼不能覆盖当前正本，本轮不沿用旧元素名称。

### 2.2 行为证据审计结果

旧报告的 18 条（星野爱 6、有马佳奈 6、星野露比 6）全部采用高度模板化的“按规则、按时段完成 → 被公司接收”句式。现有 `OSHI-V01`、`OSHI-V16`、`OSHI-OFFICIAL` 只给出卷次/资料范围，没有在报告内提供可直接打开的出版社 URL、章节定位、原始场景或逐条可核验动作。

因此本轮对 18 条统一保留为：

`pending-source-and-action-audit`（待来源与动作复核）。

它们暂时不能证明：

- 主角确实做了报告所写的具体动作；
- “被公司接收”是剧情可观察结果，而不是分析者补写的结果；
- 某条行为的对象端点足以支持对应十元；
- 三主题公式可以直接替代人物行为证据。

本轮不删除旧 JSONL、不改正式索引、不把 18 条升格或降格为最终结论。

## 三、Idolatry：推位型推し活的原始行为清单

分析对象：陽見循菜；偶像宅高中生，因推月城ふわり参加选秀而进入同一百人选秀。范围为讲谈社第1—4卷公开简介/专题范围，非全作逐页。

- 行为1：偶像团体解散且ふわり决定参加新选秀 → 循菜决定亲自进入同一场一百人选秀 → 作用于自己的参赛位置、ふわり既定路线和两人的同赛程关系 → 两人进入同一赛程。【ID-FEATURE】
  - 归类：`nx`（候选，待官方页面 URL 与原卷页码复核）。方向先由ふわり的参赛路线给出，循菜沿该方向进入；不能因为“粉丝很狂热”直接判人物本体。
- 行为2：进入选秀后，循菜把自己的参赛改造成支持ふわ里的任务 → 循菜在节目流程与排名目标中安排推位步骤 → 作用于节目流程、排名节点和ふわ里曝光 → 现有记录称单纯参赛被改造成持续推位任务，但具体场景尚未回到原卷核对。【ID-FEATURE】
  - 归类：`xn`（候选，证据范围不足）。只有确认她实际配置了多个节点、时间或资源后，才可保留 `xn`；“想让推赢”本身不够。
- 行为3：第一阶段启动 → 循菜把ふわ里引导到预定排名并争取舞台注意 → 作用于排名顺序、曝光位置和阶段节点 → 现有记录称预设结果兑现，但缺少可直接访问的 ID-V2 来源和场景定位。【ID-V2】
  - 归类：`xn`（候选，待来源复核）。若原卷只显示结果而没有循菜的组织动作，则退回“暂不归类”。
- 行为4：第三阶段分队且队内必有一人淘汰 → 循菜在正式舞台连续采用奇策以维持自身留存和ふわ里推位方向 → 作用于淘汰规则、舞台节点和两人的留存条件 → 现有记录称她继续存活并维持推位方向，但尚未完成原卷页码核对。【ID-V4】
  - 归类：`xn`（候选，待原卷复核）。连续策略与规则节点若能被定位，才可区别于单次运气或普通晋级。

### 3.1 暂定母型

`解散/失去舞台 → 粉丝沿偶像既定路线进入选秀 → 把自身参赛转成推位任务 → 用赛程节点换取偶像曝光 → 粉丝与偶像的身份边界被重新安排`
