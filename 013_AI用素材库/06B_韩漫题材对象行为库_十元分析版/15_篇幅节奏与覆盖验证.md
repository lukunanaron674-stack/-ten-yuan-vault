# 15｜篇幅节奏与覆盖验证

> 同一条行为链放进8话短篇、40话一季和120话长篇，节奏必须完全不同。原库给了24—40话季结构，但没有覆盖短篇、超长连载、喜剧单元剧和实证验证标准。

## 一、篇幅模型

| 规范ID | 形式 | 参考篇幅 | 核心要求 | 常见失效 |
|---|---|---:|---|---|
| LEN-S08 | 极短篇 | 4—8话 | 只保留一个关系反转与一个永久变化 | 世界观解释挤占角色行动 |
| LEN-S12 | 短篇 | 9—12话 | 绑定、越界、反制、选择各有位置 | 中段没有空间，突然表白收尾 |
| LEN-S24 | 标准短季 | 20—24话 | 一次权力反转、一次外部规则升级 | 每话只加误会不付回报 |
| LEN-S40 | 标准长季 | 30—40话 | 两次局部回报、一次大代价兑现 | 支线角色只负责拖延 |
| LEN-L60 | 中长篇 | 41—60话 | 至少两个阶段目标和一次题材重心转换 | 同一行为链重复换皮 |
| LEN-L120 | 长篇 | 61—120话 | 多季对象状态持续积累、旧代价跨季回收 | 季末恢复原状 |
| LEN-UNIT | 单元剧 | 每话/每3话闭环 | 固定人物关系 + 每单元新对象 | 单元互不积累，主角永不变化 |
| LEN-GAG | 喜剧短单元 | 1—4话闭环 | 设置、升级、反转、余波 | 只有吐槽，没有行为后果 |

## 二、竖屏单话节奏

```text
入口：承接上一话未完成对象
目标：本话谁想改变什么
第一次动作：低成本尝试
对象回应：接受、拒绝、误读或反制
升级动作：支付更大代价
局部结果：至少一个对象状态改变
余波：显示关系或权力变化
钩子：让下一话目标发生变化
```

### 单话最低推进标准

每话至少完成两项：

- 新增一个可靠信息
- 改变一个对象持有者
- 改变一个知情者名单
- 改变一次关系许可
- 产生一个不可撤回代价
- 支付一次情绪回报
- 改变下一话目标

## 三、不同类型的节奏差异

### 1. 恋爱关系

```text
许可建立 → 小越界 → 反制 → 短回报 → 更高风险的许可
```

禁止连续三话只靠脸红、误会、擦肩而过维持推进。

### 2. 战斗成长

```text
规则展示 → 训练/准备 → 实战检验 → 新限制 → 能力重组
```

升级必须改变策略或代价，不能只让数值更大。

### 3. 悬疑犯罪

```text
提出问题 → 初始解释 → 证据支持 → 来源可疑 → 新问题
```

新线索必须减少或重新组织可能性，不能只增加更多神秘名词。

### 4. 喜剧

```text
正常规则 → 角色误判 → 行为升级 → 结果反转 → 后果留下
```

笑点可以复用，但角色必须记得上一次失败，否则那不是人物，是自动重置的家电。

### 5. 疗愈日常

```text
微小生活阻碍 → 具体照料/劳动 → 关系许可变化 → 安静余波
```

低冲突不等于无对象变化，座位、饭桌、钥匙、作息和称呼都能承担推进。

## 四、季结构校准

| 阶段 | 24话版 | 40话版 | 必须完成 |
|---|---:|---:|---|
| 入口与绑定 | 1—3 | 1—5 | 缺口、关系对象、退出代价 |
| 试运行 | 4—7 | 6—12 | 高频行为与第一次小回报 |
| 越界 | 8—11 | 13—18 | 优势方滥用权力或秘密 |
| 中段反转 | 12—15 | 19—25 | 弱势方获得拒绝权/公开权 |
| 外部升级 | 16—19 | 26—32 | 场域实施惩罚 |
| 代价与选择 | 20—24 | 33—40 | 旧行为后果兑现并永久改变对象 |

## 五、实证覆盖要求

v1.1仍是“生产结构基线”，不能直接声称已经覆盖全部韩漫。要升级为经过验证的完整库，最低采矿样本为：

| 采矿组 | 最低作品数 | 必须覆盖 |
|---|---:|---|
| 恋爱与关系 | 20 | BG、BL、GL、都市、古装 |
| 身份与阶级 | 15 | 财阀、娱乐圈、宫廷、职场 |
| 命运改写 | 15 | 回归、穿书、附身、循环、系统 |
| 战斗成长 | 20 | 猎人、塔、武侠、体育、末日 |
| 悬疑危险 | 15 | 犯罪、怪谈、心理、校园暴力 |
| 日常疗愈 | 15 | 家庭、美食、乡村、职场群像 |
| 科幻历史喜剧补样 | 20 | 科幻、历史、纯喜剧、实验短篇 |
| 合计 | 120 | 至少来自3个平台与多个年份 |

## 七、验证状态

| 状态 | 含义 | 使用权限 |
|---|---|---|
| draft | 来自单次观察或原创假设 | 不进入生成器默认池 |
| reviewed | 两次人工审查通过 | 可作候选组合 |
| validated | 至少3部作品或10个独立场景支持 | 可进入默认生成池 |
| deprecated | 被更准确条目替代或证据不足 | 保留记录，不再调用 |

## 八、覆盖率计算

```text
题材覆盖率 = 已验证题材母型 / 全部题材母型
行为覆盖率 = 有真实场景证据的行为 / 全部行为
链条覆盖率 = 被至少3部作品支持的行为链 / 全部行为链
平台覆盖率 = 已采样平台数 / 目标平台数
时间覆盖率 = 已覆盖年份区间 / 目标年份区间
```

任何“完整”声明必须同时给出：

- 当前样本总数
- 平台分布
- 年份分布
- BL/GL/BG与非恋爱分布
- 连载状态分布
- 未覆盖区
