# 24｜原库与十元分析融合矩阵

> 本文件解决“原库负责生产、十元层负责分析，但两者只并排放置”的问题。每一种原始条目都必须有明确的十元入口、五大主题入口、风险入口和回填出口。

## 一、完整闭环

```text
题材母型
→ 主体 / 关系 / 资源 / 秘密 / 场域对象
→ 行为与言语行为
→ 对象状态变化
→ 行为链与篇幅节奏
→ 十元分层、体量与顺序
→ 生克补与动态链
→ 五大主题显影
→ 伦理、分级与反证审计
→ 作品证据与模板回填
```

任何分析若跳过“对象状态变化”直接进入十元，容易把标签当机制；若跳过伦理与反证，容易把危险关系包装成回报；若没有作品证据，只能停在结构候选。

## 三、五条横向融合线路

### 1. 题材线

```text
01题材 → 18十元分类 → 21五大主题 → 15篇幅验证
```

### 2. 人物关系线

```text
02主体 + 03关系 → 19主体关系分析 → 22生克补 → 14伦理审计
```

### 3. 对象行为线

```text
04对象 + 05行为 + 12言语微动作 → 13状态机 → 20动态分析
```

### 4. 连载生成线

```text
06行为链 + 07回报钩子 + 08组合生成器 → 15篇幅节奏
```

### 5. 采矿回填线

```text
17判定规则 → 23误判反证 → 10/10A模板 → 作品证据 → 正本或候选库
```

## 四、新增条目的同步规则

新增一个题材母型时，至少同步：

```text
01_题材总库
18_64题材十元分类总表（后续更名时可保留兼容路径）
21_五大主题分类与显影分析
24_原库与十元分析融合矩阵（若引入新类型）
10A_条目模板v1.1补充字段中的证据状态
```

新增主体、关系、行为或行为链时，必须同步对应分析文件和对象状态机。只新增原始条目而不补分析，状态标记为 `analysis_missing`；只新增十元结论而无原始条目与证据，标记为 `orphan_analysis`。

## 五、融合完成标准

一条结构只有同时满足以下条件，才算进入融合库：

- 原始条目有唯一ID。
- 十元分析明确对象层级。
- 至少记录一个对象状态变化。
- 生克补关系写清端点和被改变变量。
- 五大主题有显影等级而非关键词命中。
- 危险关系经过同意与权力差审计。
- 至少保留一个反证。
- 有明确回填模板与证据等级。
