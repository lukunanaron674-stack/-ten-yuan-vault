# 07｜情绪回报与钩子库

> 回报不是结局专属。商业连载需要把大欲望拆成小额、持续、递增的支付。一直欠读者情绪债，作者迟早会被弃坑，互联网在耐心方面一向像饥饿的猫。

# 三、回报节奏建议

| 连载尺度 | 应支付的回报 | 不应只做什么 |
|---|---|---|
| 每话 | 新信息、小选择、小关系变化 | 只在最后一格吓人却不改变对象 |
| 3—5话 | 一次局部胜利、身份许可或明确失败 | 永久误会拖延 |
| 8—12话 | 权力位置第一次反转 | 单纯增加新角色 |
| 20—30话 | 主题材中回报：公开选择、阶段复仇、能力突破 | 用吻戏替代结构进展 |
| 季终 | 身份、关系或世界规则的大改变 | 恢复原状继续循环 |

# 四、回报审计

1. 回报是否回应了角色最初缺口？
2. 回报是否可见，而不是只靠旁白说“大家认可了他”？
3. 回报前是否支付过对应代价？
4. 小回报是否推进大回报，而非消耗读者耐心的糖果纸？
5. 钩子是否改变下一话的目标、对象或权力关系？
