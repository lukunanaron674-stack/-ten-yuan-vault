# 阴阳五行全域映射

> 五行分阴阳为十天干。这是中国哲学最古老的「5×2=10」分类系统。  
> 任何领域填入这10格，每格精确、不重叠、可推导。

## 五、阴阳五行的核心规律

### 生克关系（与你的十元生补克表一致）

```
阳链相生：甲(ZX) → 丙(ZN) → 戊(N) → 庚(xn) → 壬(XZ) → 甲(ZX)
阴链相生：乙(x并z) → 丁(z) → 己(nz) → 辛(nx) → 癸(x) → 乙(x并z)
```

### 阳克阳 / 阴克阴

```
水克火：壬(XZ) 克 丙(ZN)，癸(x) 克 丁(z)
火克金：丙(ZN) 克 庚(xn)，丁(z) 克 辛(nx)
金克木：庚(xn) 克 甲(ZX)，辛(nx) 克 乙(x并z)
木克土：甲(ZX) 克 戊(N)，乙(x并z) 克 己(nz)
土克水：戊(N) 克 壬(XZ)，己(nz) 克 癸(x)
```

### 类象推理原则

已知「甲=木=肝」，则所有与肝相关的功能（藏血、疏泄、主筋、开窍于目）均带甲木属性。
同理，已知「ZX=甲木=突破」，则所有与「开局、先动手、主动行动」相关的场景均带 ZX 属性。
