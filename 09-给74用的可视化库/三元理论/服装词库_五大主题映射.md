## 强度分布规律总结

**高强度（8-10）** 特征：
- 单品本身直接承载了该主题的核心灵魂像素
- 不需要特殊穿着方式或场景配合就能触发
- 例：制服→时间97/10、斗篷→空间95/10、多口袋战术背心→因果98/10、长裙→命运95/10

**中强度（4-7）** 特征：
- 单品体现了主题的部分场意，但受材质/剪裁/搭配影响较大
- 或该单品在另一主题中更有主导权
- 例：直筒裤→时间65/4（有线但不够强）；机车夹克→因果73/5（行动感的日常版）

**低强度（1-3）** 特征：
- 单品是主题的"附属配件"或"边缘表达"
- 依赖于主服装才有意义
- 例：领带夹→时间55/2（没有领带就没有意义）；居家鞋→命运50/2（更偏向本体）

## 核心原则

### 不是穿在哪层，而是场意投射

```
错误理解❌：
时间=最外层（制服）= xn
本体=最内层（内衣）= zn
空间=中间层（外套）= x并z+n

正确理解✅：
时间=xn+z — 规则(xn)处理瞬间(z)
本体=zn+x — 意义(zn)与欲望(x)贴身交织
空间=x并z+n — 包装(x并z)与承载(n)构建外壳
因果=zx+nx — 行动(zx)需暗线(nx)补完
命运=xz+nz — 漂流(xz)需停靠(nz)
```

### 跨主题服装的处理

同一件服装可能同时承载多个主题的场意——此时**看它在具体角色/场景中的主导场意**，而非机械对应：

- **风衣**：侦探 = **因果**（zx行动工具，精密度78→改因果方向）| 旅人 = **命运**（xz旅途外套，精密度86→提升）| 神秘角色 = **空间**（x并z遮蔽，精密度82→提升）
- **马甲**：职场 = **时间**（xn制服组件）| 户外 = **因果**（zx功能口袋）

### 与图象库联动

每个角色视觉卡服装要素标注格式：
```
服装要素：长款风衣（空间·n·92/9） + 衬衫（时间·xn·80/7） + 飘带（命运·xz·83/7）
总强度加权：时间(7) + 空间(9) + 命运(7) → 命运主导(命运裹在时空外面)
```
