# 本体类创作规则

> 本文件固化“本体类创作框｜19条一句话故事｜三幕式+直接生图循环”的全局规则。

## 全局规则

- 模式：本体类创作 / 三幕式扩写 / 直接生图 / 故事讲解图。
- 总目标：逐条处理19条本体类一句话故事；每条执行“三幕式生成”和“故事解释图生成”两个步骤。
- 本体核心必须围绕：我是谁、我如何成立、什么正在夺走我、什么正在替换我、什么正在证明我、什么正在改写我。
- 每条故事必须保留原始核心机制，不随意换题。
- 未经聊天记录或用户明确内容支持的部分，必须标为“待展开”，不得杜撰。

## 三幕式规则

### 第一幕｜本体被定义 / 本体缺口

写清主角是谁、被世界怎样定义、缺什么。

公式：主角因为____被世界承认为____，但他的本体缺口是____。

### 第二幕｜机制反咬 / 本体被夺走或替换

写清原本让主角成立的机制如何开始夺走他，以及什么逐渐替他拥有真正的本体。

公式：____机制开始反咬，____逐渐替他拥有真正的____。

### 第三幕｜危险动作 / 本体证明 / 崩坏 / 新本体生成

写清主角必须做的危险动作、证明代价和结局生成的新本体。

公式：他选择____，失去____，但因此生成____。

## 核心机制字段

每张故事卡必须检查：本体对象、本体缺口、外部定义、夺走者、被夺走的本体、替代者、触发动作、危险证明、最终风险。

## 生图规则

- 生图不是普通插画，而是“故事解释图 / 三幕设定讲解图”。
- 横版16:9，左中右三栏，对应第一幕、第二幕、第三幕。
- 必须有主角、核心机制符号和三幕编号1/2/3。
- 风格偏中古奇幻 / 黑童话 / 本体污染 / 设定图感。
- 少文字、强符号，让人一眼看出故事结构。
- 每张图至少明确：主角符号、夺走符号、替代符号。
- 当前环境不能生图时，写“【待生图：当前环境未执行图片生成】”。

## 故事评估

可按四项复验：本体强度、机制清晰度、视觉符号度、结局穿透力。高分倾向于“缺口明确 + 替代者具体 + 证明动作危险 + 结局不完全复原”。

## 执行边界

- 发散树负责导航，故事卡负责正文，解释图另存。
- 不把长正文塞进 Canvas。
- 用户手改内容优先保留。
- 理论正本只作引用，不在本库覆盖或改写。
