# 白椿30秒场景分镜经验归档

日期：2026-06-10  
项目：鸣潮白椿 / 椿 30秒3D动画场景实验  
归档类型：场景视觉经验卡 / 分镜资产经验 / 提示词复用卡

---

## 0. 本轮结论

这次生成成立的核心，不是单纯“花房好看”，而是把白椿的十元气质翻译成了可执行场景链：

> 白花诱入 → 红黑藤蔓寻找 → 花影现身 → 缠绕追逐 → 花房闭合 → 镜头被捕获。

它不是普通废墟，也不是普通花海，而是：

> **黑海岸冷废墟 + 红白黑花藤领域 + 被命运盯上的空间。**

这个方向值得积累，后面可以作为“角色PV场景分镜参考模板”。

---

## 1. 为什么这张图成立

### 1.1 场景统一

成功点：

- 场景从头到尾都在同一个空间体系里：冷色废墟长廊 / 残破花房 / 潮湿石面。
- 镜头之间不是散图，而是同一空间逐步被藤蔓吞没。
- 前期冷白、灰蓝，后期红黑花藤增加，形成清晰阶段变化。

关键经验：

> 30秒动画场景不要每镜都换地点，要让同一个空间“变形”。

这比做很多场景更高级，也更适合3D制作。

---

### 1.2 颜色逻辑清楚

本轮最稳定的色彩结构：

| 层级 | 颜色 | 功能 |
|---|---|---|
| 空间底色 | 冷蓝黑 / 灰白 | 黑海岸、废墟、静 |
| 角色/花视觉 | 白 / 淡粉 | 诱惑、花、命定感 |
| 危险层 | 深红 / 暗红 / 黑藤 | 缠绕、危险、占有感 |
| 高光 | 冷白边缘光 | 保持鸣潮式清冷科幻感 |

经验封存：

> **白不是纯洁，红不是热血，黑不是恐怖。三者组合后是“美丽陷阱”。**

---

### 1.3 镜头链条有因果，不是拼贴

12格分镜的实际节奏成立：

1. 白花落下，观众被引入。
2. 长廊出现，空间建立。
3. 第一根藤蔓试探。
4. 更多藤蔓寻找目标。
5. 花影后出现人物/出场位。
6. 环绕移动，建立猎手主导。
7. 突然近身，打破安全距离。
8. 缠绕攻击，动作进入高潮。
9. 前景藤蔓遮挡，目标被困。
10. 花房闭合，领域成型。
11. 她靠近，捕获确认。
12. 极近景定格，留下记忆点。

经验封存：

> **镜头不是“展示画面”，而是每一镜都让空间更像她的领域。**

## 2. 白椿十元翻译成场景的方法

### 2.1 十元判断

白椿在这条动画里的结构：

```text
主归仓：命运 = xz + nz
副驱动：x 欲望 / 追逐 / 兴奋
视觉包装：x并z = 花、藤、漂亮表象、危险装饰
动作触发：少量 zx = 突然近身、切入、缠绕攻击
```

### 2.2 场景翻译

| 十元 | 场景语言 |
|---|---|
| nz | 被牵引、靠近、寻找、停在某个人身上 |
| xz | 危险临界、逃不掉、空间逐渐收紧 |
| x | 兴奋、占有、战斗欲、靠近欲 |
| x并z | 花、藤蔓、漂亮陷阱、视觉包装 |
| zx | 突然近身、舞步式切入、领域闭合 |

一句话：

> **白椿不是“打人”，是把目标慢慢变成她的花房。**

## 5. 制作优先级

### 优先级 1：空间变形

场景要从“废墟长廊”逐步变成“花藤领域”。

关键不是堆花，而是：

> 藤蔓越来越像空间骨架。

### 优先级 2：前景遮挡

本轮图最有效的画面之一，是前景藤蔓把画面切碎。

这能直接制造：

- 被困
- 被窥视
- 被捕获
- 她在花影后看你

### 优先级 3：潮湿反光地面

湿地面非常适合这个方向：

- 可以反射白光和红花
- 让黑海岸感更强
- 增加高级冷感
- 3D里容易出效果

### 优先级 4：红色只做危险层

红不能大面积铺满，否则会变廉价血色。

正确用法：

> 冷黑废墟占70%，白花占15%，红黑藤蔓占15%。

## 6. 本次避坑记录

### 6.1 台词暂不使用

不要把公开台词直接当“免费可用台词”。

规则：

> 除非找到明确免费授权 / 可商用授权，否则这支动画先做无对白版。

用表演代替台词：

- 靠近
- 停顿
- 眼神
- 微笑
- 花房闭合

### 6.2 不要做普通花房

普通花房 = zn / 温柔 / 美术装饰。  
白椿花房 = x并z + xz + nz，漂亮但会收紧。

判断标准：

> 如果画面只是“美”，不够；必须让美变成陷阱。

### 6.3 不要做普通恐怖藤蔓

普通恐怖藤蔓会偏 x 或 xz 灾难感。  
白椿藤蔓应该像在“寻找气味”，带命定牵引。

动作关键词：

```text
探、闻、绕、贴、缠、收
```

不要：

```text
炸、冲、爆、乱刺、怪物化
```

## 7. 可复用公式

### 公式 A：角色领域化场景

```text
角色十元气质
→ 找到对应空间材料
→ 让空间随时间变化
→ 最后空间变成角色的外化身体
```

白椿案例：

```text
nz+xz 命运牵引
→ 白花、红黑藤蔓、冷废墟
→ 藤蔓从试探到包围
→ 花房闭合成为她的领域
```

### 公式 B：30秒角色PV场景链

```text
0-5s：诱入
5-10s：异样
10-16s：现身
16-23s：动作关系
23-28s：领域成型
28-30s：记忆点
```

## 8. 下一步建议

如果继续推进，建议分三轮：

1. **无角色场景版**：只生成12格空场景，严格 no character。
2. **角色走位版**：在空场景上画白椿动线，不追求精修。
3. **3D blocking版**：按镜头 2、6、8、10、12 五个关键镜头先搭粗模。

最小可执行资产：

```text
A. 废墟长廊主场景
B. 红黑藤蔓模块 3种
C. 白花瓣粒子
D. 花房闭合大形态
E. 终帧近景背景
```

## 9. 封存句

> 白椿这支30秒的场景核心，不是“花藤好看”，而是“空间被她一点点变成命运陷阱”。前10秒诱入，中10秒缠绕，后10秒闭合。冷废墟是底，红黑花藤是手，白花是饵。
