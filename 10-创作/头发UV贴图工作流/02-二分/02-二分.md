# 02 二分

## 目标

在已经对齐的真实 UV 上只划分亮面和暗面。前发、侧发、后发和辫子都在同一张图里，但各部件独立判断；不让一个部件的形状误染到另一个部件。

## 纯二分阶段的边界

纯二分只负责：

```text
亮区
暗区
```

此阶段不加入：

```text
渐变
高光
发丝线
描边
材质反光
```

这些内容可以在二分遮罩稳定后作为独立风格层叠加。`粉色头发_BaseColor.png` 是应用示例，不改变纯二分遮罩的定义。

## 前发三瓣规则

前面中、左、右三瓣刘海必须当成一个整体处理，不能每瓣单独切。

```text
三瓣合并判断
      ↓
使用同一条世界空间 Y 水平线
      ↓
上部亮、下部暗
```

当前统一切线：

```text
cut_y = y_min + (y_max - y_min) × 0.52
cut_y = 126.6152
```

这样三瓣贴回模型后会形成一条连续的横向亮暗关系，不会三块各自出现不同高度的弧形。

## 全头分区

语义分区如下，但输出仍回到同一张 0–1 UV 图：

| 主分区 | 子分区 |
|---|---|
| 前发 | 中间、画面左、画面右三瓣 |
| 侧发 | 左右上层、左右脸侧短发、贴脸下层、小尖发 |
| 后发 | 头顶、左后、右后、后脑中央、后脑下层 |
| 辫子 | 左右辫的上段、中段、下段和发尾 |

贴脸下层属于遮挡区域，当前有 4 个面强制为暗面，避免贴回后脸下出现突兀亮块。

## 灰度值

纯二分图使用固定值：

| 区域 | RGB |
|---|---|
| 暗面 | 76, 76, 76 |
| 亮面 | 214, 214, 214 |
| 原灰度转二分阈值 | 142 |

## 分层使用

1. `粉色头发_二分遮罩.png`：只控制亮暗区。
2. `粉色头发_发丝线遮罩.png`：控制发丝线，不应改动二分边界。
3. `粉色头发_BaseColor.png`：把基础粉、暗面、亮部、发丝和轮廓合成后的示例。
4. Maya 模型通过 BaseColor 贴回，用正、背、左、右四视图检查错岛和接缝。

## 贴回检查

![[预览/粉色版_四视图.png]]

验收时依次看：

1. 正面：三瓣前发的亮暗切线是否连续。
2. 左右侧：侧发上部是否漏空，亮暗是否沿同一空间逻辑。
3. 背面：后发是否误用前发形状。
4. 辫子：每节是否沿自己的发根到发梢方向，不出现横向拉伸。
5. UV：岛内无黑洞，边缘有 20 px 外扩。

## 不再采用的做法

- 不按每个 UV 岛各自画一条前发二分线。
- 不把前发和侧发合并成同一语义分区。
- 不用生成图直接覆盖完整 UV。
- 不通过外接框硬拉图形；必须使用真实岛轮廓和发流坐标。
- 不在“只做分区”阶段混入渐变、高光、发丝和描边。
