头发 UV 对齐数据包
====================

这一份是当前已对齐结果的独立归档，不需要再靠截图猜 UV 位置。

核心数据
--------
- 贴图尺寸：2048 x 2048
- UV 岛数：111
- 可见网格数：7
- 逐面记录数：3698
- 未对应到 UV 岛的面：0
- 边缘外扩：20 px

目录说明
--------
01_源文件：原始 Maya ASCII 模型和原生成图。
02_UV参考：精确 UV 线框、遮罩、岛编号和发根到发梢方向。
03_对齐贴图：灰度二分、纯二分和粉色风格版。
04_Maya文件：已经把贴图路径指向对齐结果的 .ma 文件。
05_预览：对齐对比和模型四视图。
06_数据：UV 岛和每个模型面的 JSON/CSV 对应。
07_复现工具：生成和检查这份资料用的工具。

坐标规则
--------
- UV 坐标原点在左下。
- PNG 像素坐标原点在左上。
- root_to_tip_axis 始终表示“发根 -> 发梢”。
- 绘制时必须保持 0-1 UV 和 2048 尺寸，不移动、不重排 UV 岛。
- 最终贴图请保留 20 px 边缘外扩。

快速查找
--------
- 想看某个岛在哪：02_UV参考/UV岛编号图.png
- 想看发流：02_UV参考/发根到发梢方向图.png
- 想查精确数据：06_数据/UV岛_对齐与发流.json
- 想查 Maya 哪个面：06_数据/逐面UV对应.csv

manifest.json 记录了每个文件的 SHA-256，用来确认后续文件没有意外变化。
