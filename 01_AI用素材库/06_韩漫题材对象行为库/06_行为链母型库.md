# 06｜行为链母型库

> 行为链不是桥段顺序表，而是对象状态连续变化。每一步必须继承上一步产生的债务、误解、损失或新权限。

## A. 恋爱与亲密关系链

### C01｜假关系变真关系

```text
现实危机 → 提出假关系 → 约定边界 → 被迫公开表演 → 一方越界保护
→ 另一方质问动机 → 契约即将结束 → 主动解除工具关系 → 无合同状态下重新选择
```

对象变化：合同工具 → 共同秘密 → 公共身份 → 私人承诺。

### C02｜敌对者成为唯一理解者

```text
公开竞争 → 互相拆台 → 被迫合作 → 看见对方隐藏代价 → 关键救场
→ 拒绝欠人情 → 再次竞争 → 在更大敌人前承认对方资格
```

对象变化：胜负对象 → 能力镜像 → 可信赖同伴。

### C03｜保护转控制再转平等

```text
强者救援 → 被保护者依赖 → 强者代替决定 → 被保护者秘密违抗
→ 危险升级 → 强者承认控制 → 归还钥匙/证件/决定权 → 并肩处理后果
```

对象变化：安全 → 依赖 → 控制物 → 自主合作。

### C04｜重逢旧爱复盘链

```text
意外重逢 → 礼貌回避 → 旧物触发 → 误会版本冲突 → 第三者提供缺失信息
→ 一方补偿 → 另一方拒绝用补偿替代选择 → 重新认识现在的彼此
```

对象变化：旧记忆 → 争议事实 → 现在的选择。

### C05｜救命债转自由关系

```text
救命事件 → 被救者主动服从 → 恩人不断调用债务 → 被救者失去自主
→ 恩人发现依赖不是爱 → 主动免债 → 被救者离开 → 自由状态下返回或告别
```

对象变化：生命债 → 道德控制 → 被取消的债权 → 真选择。

### C06｜利用目标却产生感情

```text
带任务接近 → 精准迎合 → 获得信任 → 发现目标并非旧认知 → 暗中保护
→ 任务方催促收网 → 身份暴露 → 目标夺回解释权 → 行动者承担背叛代价
```

对象变化：任务目标 → 关系对象 → 被伤害的主体。

## B. 身份、阶级与夺权链

### C07｜被逐者夺回资格

```text
公开除名 → 失去资源 → 保留关键知识 → 在外部建立新能力/盟友
→ 家族遭遇危机 → 被要求无条件回归 → 提出新规则 → 公开表决或继承对决
```

### C08｜真假继承人身份反转

```text
身份疑点 → 亲子证据出现 → 原继承人排斥新人 → 家族资源重新分配
→ 证据被质疑 → 养育关系暴露 → 两人发现共同操纵者 → 子女共同拒绝家族竞赛
```

### C09｜豪门潜入复仇

```text
旧案损失 → 改名进入豪门 → 利用成员矛盾 → 获得内部证据 → 对目标产生复杂理解
→ 复仇计划伤及无辜 → 调整清算对象 → 公开证据 → 拒绝成为新掌权暴君
```

### C10｜职场新人反转评价

```text
被低估入职 → 被分配烂任务 → 发现流程漏洞 → 私下补救 → 功劳被夺
→ 留下证据链 → 重大事故爆发 → 新人公开救场 → 争取制度而非个人奖励
```

### C11｜政治联姻到共同执政

```text
被安排婚约 → 双方互相戒备 → 明确利益边界 → 联手应付外部派系
→ 一方家族要求背叛配偶 → 拒绝旧阵营 → 重新分配军权/领地 → 共同制定联盟规则
```

### C12｜顶流身份崩塌与重建

```text
高位营业 → 私人秘密泄露 → 公司切割 → 粉丝与公众审判 → 旧伙伴提供真实记录
→ 主角停止伪装 → 自主发布作品/声明 → 失去部分流量 → 获得新的作者身份
```

## C. 命运改写与信息差链

### C13｜回归抢先布局

```text
失败结局 → 回到关键节点 → 抢走旧敌资源 → 避开旧错误 → 旧因果以新形式出现
→ 未来知识开始失效 → 必须信任当下伙伴 → 不靠记忆完成最终选择
```

### C14｜恶役改命

```text
得知处刑结局 → 退出原争夺 → 建立独立资源 → 原剧情人物主动接近
→ 所有善意仍被解释为阴谋 → 用代价证明立场 → 审判反转 → 拒绝只靠洗白获得价值
```

### C15｜时间循环找隐藏变量

```text
重复死亡 → 记录固定节点 → 尝试改变表面事件 → 失败方式变化 → 发现他人也保留碎片记忆
→ 两人共享信息 → 必须牺牲一项旧目标 → 打破循环 → 只有一方记得全部
```

### C16｜穿书人物脱离原剧情

```text
利用剧情知识 → 抢先干预名场面 → 被干预人物做出意外反应 → 原剧情失真
→ 主角失去全知优势 → 把人物当主体重新协商 → 新冲突不再有剧透答案
```

### C17｜宿主反制系统

```text
接受任务 → 获得奖励 → 任务侵犯私人底线 → 尝试钻规则漏洞 → 系统升级惩罚
→ 发现系统依赖宿主行为 → 故意拒绝关键任务 → 迫使系统谈判或暴露目的
```

### C18｜身份交换互相修复

```text
身体/身份交换 → 模仿对方生活 → 发现对方被误解的压力 → 替对方处理旧关系
→ 造成新的越界 → 坦白交换事实 → 回到原位 → 各自执行对方未敢做的选择
```

## D. 成长、战斗与团队链

### C19｜弱者越级成长

```text
被评级为弱者 → 获得特殊但有限能力 → 用规则理解弥补数值不足 → 第一次越级成功
→ 被强组织招募 → 拒绝工具化 → 建立自己的队伍 → 用团队完成无法单刷的战斗
```

### C20｜天才失能再成长

```text
顶级身份 → 突然失去能力 → 隐瞒并勉强上场 → 导致团队事故 → 被迫退出
→ 从新人视角重学基础 → 找到不同技术路线 → 不恢复旧状态也能重返核心位置
```

### C21｜宿敌共同升级

```text
争夺第一 → 互相针对训练 → 一方先遭遇更强敌人 → 另一方救场但拒绝施舍
→ 交换技术 → 双方都改变打法 → 决赛真正对决 → 胜负不再否定对方资格
```

### C22｜临时队伍变共同体

```text
利益组队 → 隐瞒能力与目的 → 首次分配冲突 → 小成员救场 → 共同秘密形成
→ 背叛诱惑出现 → 队长交出部分指挥权 → 成员主动返回 → 建立长期组织
```

### C23｜机构工具反叛

```text
特殊能力登记 → 接受任务与药物控制 → 发现任务对象并非敌人 → 私下放走
→ 机构要求忠诚证明 → 同伴被清除 → 主角叛逃 → 揭露机构并建立替代规则
```

### C24｜末日资源伦理链

```text
建立避难所 → 按贡献分配资源 → 弱者被排除 → 主角私下救助 → 资源危机暴露
→ 群体要求驱逐主角 → 外部灾难迫使再合作 → 制定新的配给与风险承担规则
```

## E. 悬疑、犯罪与危险链

### C25｜证据逐层翻转

```text
发现异常 → 锁定嫌疑人 → 关键证据确认 → 证据来源可疑 → 第一嫌疑人成为受害者
→ 追查谁能制造证据 → 找到利益链 → 真凶利用主角公开行动反杀 → 二次取证完成指认
```

### C26｜追踪者与被追踪者换位

```text
单向监视 → 被观察者察觉 → 故意提供假日常 → 追踪者被诱入错误现场
→ 被观察者开始调查追踪者 → 双方发现第三方监控 → 临时合作 → 最后互相保留一项秘密
```

### C27｜囚禁中的反控制

```text
被夺走空间与通讯 → 表面服从 → 记录控制者习惯 → 藏匿小资源 → 制造情绪依赖假象
→ 获取钥匙/权限 → 第一次逃跑失败 → 利用失败改变监控规则 → 第二次让控制者主动打开出口
```

### C28｜校园暴力结构曝光

```text
个体受害 → 求助被压下 → 收集同类经历 → 潜入加害者社交圈 → 获得影像证据
→ 校方反向处分受害者 → 公开渠道发布 → 旁观者被迫站队 → 加害结构而非单人被清算
```

### C29｜共犯信任崩坏

```text
共同犯罪 → 分工与掩护 → 一方私藏资源 → 双方互相要挟 → 外部调查逼近
→ 一方准备出卖 → 发现另一方早已留下自毁证据 → 最终选择共同承担或彻底互毁
```

### C30｜怪谈规则破解

```text
触犯禁忌 → 第一次异常 → 寻找旧传说 → 按错误规则自救 → 付出更大代价
→ 发现规则由旧事件产生 → 找到被遗忘对象 → 完成补偿/承认 → 异常消退或转移
```

## F. 疗愈、家庭与日常链

### C31｜临时家庭形成

```text
意外收留 → 明确短期期限 → 生活分工冲突 → 第一次共同应对外部问题
→ 某成员准备离开 → 其他人装作不在意 → 公共空间留下位置 → 主动邀请回来并重订规则
```

### C32｜乡村停靠再出发

```text
高压生活崩溃 → 临时回乡 → 不适应慢节奏 → 参与具体劳作 → 被邻里记住
→ 旧城市机会召回 → 主角发现停留也可能变成逃避 → 完成告别 → 带着新节奏返回或留下
```

### C33｜家庭偏爱终止竞争

```text
长期比较 → 被忽视者加倍讨好 → 资源再次偏向宠儿 → 兄弟姐妹正面冲突
→ 发现宠儿也被角色化 → 两人拒绝继续争夺父母认可 → 建立独立生活与新的亲缘方式
```

### C34｜美食修复记忆

```text
失去味道/菜谱 → 重开小店 → 常客带来旧记忆 → 模仿失败 → 找到缺失的人际背景
→ 与旧关系对质 → 改造而非复制旧味道 → 新菜成为新的家庭记忆
```

### C35｜职场群像互助

```text
烂项目降临 → 成员互相甩锅 → 发现每人都被不同制度卡住 → 重新分工
→ 管理层抢功 → 团队保留共同证据 → 公开争取成果 → 有人留下、有人离职但关系延续
```

### C36｜宠物陪伴与告别

```text
被迫收养 → 生活节奏改变 → 主角第一次稳定承担照料 → 宠物走失/生病
→ 主角调动过去不愿接触的人际关系寻找 → 找回或面对失去 → 将照料能力转向新的生活关系
```

# 行为链设计公式

```text
1. 建立绑定：为什么不能分开
2. 首次获利：关系为何值得继续
3. 权力滥用：优势方如何越界
4. 对象反制：弱势方夺回什么
5. 外部升级：场域规则加入惩罚
6. 代价显形：旧行为造成不可撤回后果
7. 重新选择：去掉债务/合同/误会后是否仍选择
```

# 链条审计

- 每一步是否改变了对象状态，而非只是换场景聊天？
- 上一步的代价是否进入下一步？
- 弱势角色是否至少有一次有效反制？
- 中段是否发生权力位置变化？
- 结尾解决的是关系规则，还是只靠一段表白糊墙？
