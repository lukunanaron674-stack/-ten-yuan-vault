# 韩漫题材对象行为库｜总控索引

> 目标：把“韩漫题材”从模糊标签拆成可调用、可组合、可采矿的生产系统。

## 一、核心公式

```text
题材 = 欲望场域 + 主体身份 + 目标对象 + 阻碍对象 + 高频行为 + 情绪回报

剧情单元 = 主体 → 对对象采取行为 → 对象反制 → 权力/关系改变 → 回报或新钩子

单话闭环 = 承接钩子 → 目标显形 → 行动升级 → 局部结果 → 更大钩子
```

题材库回答“故事在哪一种欲望里发生”；对象库回答“谁、什么东西值得争夺”；行为库回答“角色如何作用于对象”；回报库回答“读者为什么继续翻下一话”。

## 三、对象的四种等级

| 等级 | 定义 | 示例 |
|---|---|---|
| 人物对象 | 能主动回应的行动者 | 财阀继承人、回归猎人、恶役千金 |
| 关系对象 | 把两人绑定起来的结构 | 契约婚姻、师徒、债务、共犯 |
| 资源对象 | 能交换或改变权力的东西 | 遗产、证据、技能、名额、药物 |
| 规则对象 | 决定行为代价的场域 | 皇宫继承法、公司晋升制、猎人等级制 |

## 四、条目最小标准

每个题材至少必须标注：

- 主体缺口
- 主目标对象
- 阻碍对象
- 权力来源
- 高频行为
- 典型反制
- 核心回报
- 可视化场景
- 失效风险

每个行为至少必须标注：

- 行动者
- 承受者
- 显性目标
- 隐性目标
- 触发条件
- 动作形式
- 代价
- 对方回应
- 关系变化
- 后续钩子

## 五、组合约束

1. 不把动作姿势当行为。接吻、拥抱、壁咚只是动作外壳，必须注明其功能是试探、宣示、安抚、欺骗还是控制。
2. 不把身份名词当题材。财阀、公爵、猎人只是主体或场域；题材必须包含欲望与冲突。
3. 不只写主角想要什么，还要写谁有资格拒绝他。
4. 每个强行为必须留下代价，否则只剩无重量爽点。
5. 每条链至少产生一次对象反制，避免角色像家具一样被剧情拖行。
6. 题材混合最多采用“1个主题材 + 1个驱动题材 + 1个调味题材”。标签堆得再多，也不会自动长出故事。

## 六、推荐使用流程

```text
选择主题材
→ 抽取主体对象
→ 抽取关系对象
→ 配置资源/秘密/场域
→ 选择3个高频行为族
→ 选择1条行为链母型
→ 配置每3—5话一次中回报
→ 配置季终身份或权力大回报
→ 用十元接口检查感觉走向
```

## 七、版本边界
