# 14｜伦理风险与内容分级

> 危险关系可以写，控制、囚禁、跟踪、债务与暴力也都可以成为题材。问题不在“能不能出现”，而在作品是否看见了对象的主体权、后果和退出代价。把伤害画得漂亮，不等于剧情就自动获得了伦理豁免证。

## 一、风险条目表

| 规范ID | 风险 | 常见行为 | 必须检查 |
|---|---|---|---|
| RISK-01 | 权力不对等 | 上司恋爱、师生、雇主保镖、监护关系 | 弱势方是否拥有真实拒绝权与退出路径 |
| RISK-02 | 强迫与胁迫 | 威胁、强制契约、逼迫亲密行为 | 同意是否自由、具体、可撤回 |
| RISK-03 | 经济控制 | 扣钱、断供、债务绑定、扣留证件 | 生存资源是否被用来替代感情许可 |
| RISK-04 | 跟踪与监视 | 查手机、定位、尾随、监听 | 叙事是否将其误标为单纯关心 |
| RISK-05 | 隔离与囚禁 | 限制社交、锁门、阻止离开 | 被控制者是否有视角、反制与后果 |
| RISK-06 | 身体与医疗控制 | 隐瞒诊断、强迫用药、替人决定治疗 | 知情权和身体决定权归谁 |
| RISK-07 | 生育控制 | 隐瞒避孕、强迫怀孕、争夺生育决定 | 禁止将其包装为爱或家族责任 |
| RISK-08 | 性暴力与性胁迫 | 无同意接触、醉酒、权力换取性关系 | 必须明确责任、创伤与分级 |
| RISK-09 | 未成年与成人关系 | 教师、监护者、成年权力者介入 | 禁止浪漫化成人利用未成年人 |
| RISK-10 | 家庭暴力 | 身体、语言、经济、情绪暴力 | 不能用一次道歉跳过长期后果 |
| RISK-11 | 校园欺凌 | 排挤、偷拍视频、集体羞辱 | 处理群体结构，不只安排个人报复 |
| RISK-12 | 精神疾病污名 | 把疾病等同危险、邪恶或不可控 | 行为责任与诊断必须分开 |
| RISK-13 | 自伤与自杀 | 威胁自伤、用自伤绑定关系 | 不作为浪漫证明，避免操作性细节 |
| RISK-14 | 成瘾与药物 | 酒精、药物、赌博等依赖 | 展示长期代价，避免万能意志治愈 |
| RISK-15 | 仇恨与歧视 | 性别、取向、阶级、残障歧视 | 区分角色偏见与作品立场 |
| RISK-16 | 复仇失控 | 连坐、无差别毁灭、替代性伤害 | 清算对象是否准确，受害者是否被再次工具化 |

## 二、同意模型

有效同意至少包括：

```text
自由：没有生存、职位、债务或暴力压力
具体：同意某项行为，不等于同意全部行为
知情：知道对象、风险和真实身份
可撤回：先前同意可以停止
可表达：沉默、僵住和无法反抗不等于同意
```

## 三、危险关系的五项叙事审计

### 1. 视角

被控制者是否拥有自己的欲望、判断和叙述，而不只是用来证明控制者“爱得太深”？

### 2. 命名

作品是否准确命名行为是监视、威胁、囚禁或经济控制，而不是全部塞进“占有欲”这个柔光滤镜？

### 3. 后果

伤害是否改变信任、身体、安全、社会关系或退出成本？不能亲一下就恢复出厂设置。

### 4. 修复

修复至少包含：停止行为、归还控制物、承认责任、补偿损失、接受对方可能离开。

### 5. 选择

去掉债务、职位、监护、药物和暴力优势后，弱势方是否仍有自由选择关系的机会？

## 五、分级建议矩阵

| 内容 | 最低建议分级 | 必填内容警告 |
|---|---|---|
| 轻度恋爱误会、非暴力竞争 | all / 12_plus | 通常无需 |
| 校园欺凌、跟踪暗示、中度打斗 | 12_plus / 15_plus | bullying、stalking、violence |
| 囚禁、家庭暴力、严重犯罪、创伤回忆 | 15_plus | confinement、domestic_violence、trauma |
| 露骨性内容、性暴力、严重虐待 | 18_plus | sexual_content、sexual_violence、abuse |
| 自伤、自杀、成瘾 | 15_plus / 18_plus | self_harm、suicide、addiction |

## 六、危险关系与恋爱回报的分离

以下内容不能直接作为“甜点回报”：

- 偷看手机成功
- 强行接吻后对方停止反抗
- 扣留证件迫使同居
- 用工作或治疗资格交换亲密关系
- 威胁自伤阻止分手
- 成年权力者让未成年人“自愿选择”

这些可以作为冲突、反派行为、崩坏链或修复前提，但回报必须来自主体权恢复、真实选择或责任清算。

## 八、红线检查

```text
[ ] 未把沉默或恐惧当作同意
[ ] 未把控制物当作爱的证明
[ ] 未用一次道歉抹除重复伤害
[ ] 未把未成年人置于成人权力关系中浪漫化
[ ] 未把精神疾病直接等同暴力或邪恶
[ ] 被伤害者拥有反制、退出和继续生活的路径
[ ] 内容分级和警告与实际演出一致
```
