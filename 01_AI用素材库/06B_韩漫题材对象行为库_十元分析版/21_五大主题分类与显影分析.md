# 21｜五大主题分类与显影分析

> 五大主题负责高级归类，十元负责具体对象，动态链负责阶段过程。主题不是由案例中两个十元临时相加生成，也不能从题材关键词直接判定。

## 一、五大主题最小定义

| 主题 | 核心问题 | 正式十元构成区 |
|---|---|---|
| 空间 | 什么能够在哪里存在，彼此怎样共处、分隔、容纳或受限 | `x并z + n` |
| 时间 | 事物怎样从之前走到之后，什么被改变、积累、循环或保留 | `xn + z` |
| 命运 | 多种可能怎样收束为某个去向、归宿或不可逆结果 | `xz + nz` |
| 因果 | 什么导致了什么，结果怎样具有来源、责任与可追溯性 | `zx + nx` |
| 本体 | 对象在变化、关系和表现中究竟是什么，凭什么仍是自身 | `zn + x` |

构成公式中的`+`是理论系统预设双方，不代表案例里两个人或两个十元相遇。

## 二、主题显影等级

| 等级 | 含义 | 判定标准 |
|---:|---|---|
| 0 | 背景存在 | 场景或设定带到，但不改变关键选择 |
| 1 | 局部主题 | 一个支线或单元集中处理 |
| 2 | 次主题 | 多次转折受其影响，但高潮/结局不主要回答它 |
| 3 | 主主题 | 中心问题、关键转折、高潮与结局共同回答 |

## 五、主题关系的正式方向

### 生环

```text
空间 生 时间
时间 生 命运
命运 生 因果
因果 生 本体
本体 生 空间
```

### 克环

```text
空间 克 命运
命运 克 本体
本体 克 时间
时间 克 因果
因果 克 空间
```

## 六、在韩漫中的主题级生克示例

> 以下只是可检验模板。两个主题并存不等于生克启动，必须写出源主题怎样真实改变目标主题的能力、边界、路径或答案。

### 空间生时间

共同住所、队伍、公会或店铺形成稳定容器后，人物才可能积累日常、关系历史与成长阶段。

```text
临时家庭获得稳定住所
→ 可重复共同生活
→ 关系从一次救助变成长期历史
```

### 时间生命运

多次选择、训练、等待或循环积累后，多种可能逐步收束成某个不可逆结局。

```text
旧爱多次错过沟通节点
→ 可修复窗口持续减少
→ 最终只能告别或重新开始
```

### 命运生因果

不可逆结果显形后，角色被迫追问它由哪些选择、制度和责任造成。

```text
恶役处刑结局已知
→ 反查哪条原剧情因果链把她推到这里
→ 改写关键原因而非只躲最后一刀
```

### 因果生本体

行为后果和责任结算迫使角色回答“我究竟是谁”。

```text
复仇伤及无辜
→ 主角必须决定是否继续无差别清算
→ 选择定义其主体核心
```

### 本体生空间

主体确认自己和边界后，才可能建立适合自身存在的关系和生活位置。

```text
替身拒绝继续复制原型
→ 夺回名字和作品
→ 建立自己的工作室与关系位置
```

### 空间克命运

稳定承载空间提供新路径，降低被危险和既定结局继续驱赶的程度。

```text
逃亡者进入真正运行的避难所
→ 获得停留、补给和返回位置
→ 不再只能抢下一条逃生路线
```

### 命运克本体

预言、原剧情、家族安排或不可逆结局把主体压缩成一个功能角色。

```text
“恶役必死”的命运
→ 所有行为都被解释为恶意
→ 主体无法以自身选择被识别
```

### 本体克时间

稳定核心拒绝被阶段、期限或成长叙事改写，可能停止时间变化或让旧模式长期固化。

```text
角色坚持“我只能是家族继承人”
→ 无法进入新的成长阶段
→ 时间变化被核心身份锁住
```

### 时间克因果

时间流逝、循环或证据老化使来源和责任难以追溯，也可能让旧因果失去继续作用的条件。

```text
旧案证人死亡、记录损坏、记忆变化
→ 责任链无法被完整还原
```

### 因果克空间

规则、债务、犯罪后果或身份记录限制主体进入、停留或返回某些位置。

```text
违约与犯罪记录成立
→ 工作、家庭或领地入口被关闭
→ 可存在空间被因果链压缩
```
