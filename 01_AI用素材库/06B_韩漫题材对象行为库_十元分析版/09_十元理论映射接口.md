# 09｜十元理论映射接口

> 本文件只负责“接口”，不重新定义十元，也不把题材标签硬塞进某个十元。叙事对象与行为先成立，再检查感觉走向。否则就会出现先判气质、再倒着编剧情的老毛病，理论被拿来当占卜盘。

# 一、五大主题固定入口

| 五大主题 | 十元构成 | 在叙事库中优先检查的对象 |
|---|---|---|
| 时间 | `xn + z` | 期限、等待、重复、错过、不可逆节点、成长阶段 |
| 本体 | `zn + x` | 主体资格、身份连续性、身体、署名、自我边界 |
| 空间 | `x并z + n` | 住所、领地、场域许可、归属、距离、共同体位置 |
| 因果 | `zx + nx` | 行为后果、债务、证据、规则、责任、交换链 |
| 命运 | `xz + nz` | 预定结局、无法回避的关系、停靠与离开、选择代价 |

上述只是五大主题入口。具体作品的主十元、辅十元、体量、顺序和生克补关系，必须按照十元核心库判断，不能由“韩漫题材名”自动推断。

# 二、两层工作顺序

```text
第一层：叙事可运行性
题材 → 主体 → 对象 → 行为 → 反制 → 代价 → 回报

第二层：感觉与动态链
主十元/辅十元 → 体量 → 顺序 → 生克补 → 五大主题 → 动态链
```

禁止反过来用第二层代替第一层。比如“这是命运类”并不能回答角色下一场戏要对谁做什么。

# 三、题材卡增加的十元字段

```yaml
十元接口:
  主十元: 待判
  辅十元: 待判
  体量: 待判
  顺序: 待判
  关系: 待判
  五大主题: 待判
  动态链:
    起点: 待判
    中段变化: 待判
    结尾回收: 待判
  判断证据:
    - 具体场景
    - 具体行为
    - 对象变化
  反证:
    - 可能被误判成什么
```

# 四、五大主题提问接口

## 1. 时间接口｜`xn + z`

- 哪个期限迫使角色行动？
- 哪一次等待、错过或重复改变了关系？
- 角色是在回收过去，还是被过去继续规定？
- 结尾是否让时间状态改变：继续、终止、重启、错过、完成？

适合调用的对象：合同期限、回归节点、倒计时、赛季、治疗窗口、成长阶段。

## 2. 本体接口｜`zn + x`

- 角色的主体资格被谁定义？
- 身份、身体、署名和记忆中，哪一个被夺走或替换？
- 角色最关键的行为，是证明“我是谁”，还是拒绝继续成为某种工具？
- 去掉职位、血统、能力后，这个主体还剩什么？

适合调用的对象：附身身体、真实血统、作者署名、能力者登记、替身身份。

## 3. 空间接口｜`x并z + n`

- 谁允许角色进入、停留或离开某个空间？
- 空间是保护、监禁、归属还是评价场？
- 角色是否拥有钥匙、席位、房间、领地或公共位置？
- 结尾空间关系是否发生改变：被驱逐、返回、共居、自建空间？

适合调用的对象：合租屋、皇宫席位、公会、领地、避难所、小店、临时家庭。

## 4. 因果接口｜`zx + nx`

- 哪个行为制造了后续必须偿还的结果？
- 谁掌握证据、规则与责任解释权？
- 保护行为是否同时产生控制后果？
- 角色是否把自己的责任让没，或被迫替别人承担？
- 结尾是清算个人，还是改变造成问题的因果结构？

适合调用的对象：债务、证据、契约、共同犯罪、组织规则、复仇名单。

## 5. 命运接口｜`xz + nz`

- 哪个结局被认为不可避免？
- 哪段关系既不能久留，又无法轻易离开？
- 停靠、依恋、压迫、错过和选择中，哪个是主导感觉？
- 角色改变的是结局本身，还是面对结局的方式？

适合调用的对象：预言、处刑结局、循环、旧爱重逢、逃亡路线、最后停靠点。

# 五、动态链接口

叙事行为链与十元动态链分开记录，但使用同一场景证据。

```yaml
叙事链:
  - 主体A提出契约
  - 主体B接受并添加条件
  - A越界控制
  - B解除契约
  - A失去资源优势后重新请求关系

十元动态链:
  起手: 待从第一场行为判断
  推进: 待从权力/感觉变化判断
  中段反转: 待从对象反制判断
  结尾: 待从最终选择判断
  五大主题主轴: 待判
```

关键原则：动态链描述统一大感觉的走向与层次，不等同于剧情事件列表。

# 六、映射流程

```text
1. 先抽取三场最关键的“主体—行为—对象”
2. 为每场记录显性目标、隐藏目标、代价和关系变化
3. 判断每场的感觉主次，不看服装与画面先入为主
4. 标注体量和顺序
5. 检查直接生/克/补，必要时再用近邻或桥
6. 形成动态链
7. 用五大主题检查主轴，不反向回填起手
8. 保存反证与误判风险
```

# 七、禁止项

- 禁止默认 `zn` 起手。
- 禁止默认由 `n` 承载全部情感或关系。
- 禁止先定五大主题再回填角色行为。
- 禁止用服装、色调、构图直接反推人物十元。
- 禁止从结局倒推整条动态链。
- 禁止把一个角色所有场景都标成同一十元，忽略关系中的层次变化。
- 禁止把题材高频套路当作十元结论。

# 八、示例：契约婚姻的接口记录

```yaml
题材: 契约婚姻 + 财阀继承
叙事核心:
  主体A: 继承人
  主体B: 负债设计师
  关系对象: 一年期婚姻合同
  权力对象: 资金、股份、公开身份
关键行为:
  - A提出合同，B添加署名归还条款
  - A在家族宴会上公开维护B，但替B发言
  - B解除合同并公开自己的作者证据
  - A失去继承优势后重新请求关系
五大主题候选:
  本体: B的作者资格与“不是替代配偶”的主体边界
  因果: 合同、署名债务、保护造成的控制后果
  时间: 一年期限与提前解除
十元结论: 必须回到具体场景另行判断，不由题材自动填写
```

# 九、与采矿库连接

真实作品采矿时，每个结论至少保留：

```yaml
作品名:
话数范围:
场景证据:
主体:
行为:
对象:
对象变化:
读者回报:
十元判断:
体量与顺序:
关系依据:
反证:
质量评分:
```

这样韩漫库提供叙事骨架，十元库负责感觉关系，两边互相提供证据，但谁也不冒充对方。
