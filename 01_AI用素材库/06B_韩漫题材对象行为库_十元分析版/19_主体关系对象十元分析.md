# 19｜主体与关系对象十元分析

> 主体原型只提供“常见十元入口”，不能替代人物本体判定。关系对象分析的是权力和功能位置，尤其要防止把`nx`关系功能误判成人物软弱本体。

## 三、关系分析的四个权限轴

任何关系都应分别标注：

```yaml
permissions:
  resource_control: 谁掌握资源
  direction_control: 谁决定目标与路径
  public_interpretation: 谁定义这段关系是什么
  exit_right: 谁能退出，退出代价是什么
```

对应十元常见入口：

- 资源与关系入口控制：`x`
- 公开压过、任命、剥夺与显权：`zx`
- 主动搭建规则与时间结构：`xn`
- 沿已有权限和关系通道行动：`nx`
- 公共身份与私下真实的分层：`x并z`
- 不可背弃的关系意义：`zn`
- 被看见与被承认：`z`
- 接住并处理他者负荷：`n`
- 不想让关系结束：`nz`
- 暴露、追捕与退出窗口收窄：`xz`

## 四、关系动态链模板

```text
关系壳建立
→ 权限分配
→ 优势方调用权限
→ 弱势方反制或沿通道推进
→ 代价使隐藏十元显影
→ 权限重新分配
→ 去掉旧绑定后重新选择
```

分析时不能只写“A爱上B”。必须写清：谁掌握什么、谁沿什么通道、谁被谁确认、谁承载谁、谁不愿结束，以及危险从哪里逼近。
