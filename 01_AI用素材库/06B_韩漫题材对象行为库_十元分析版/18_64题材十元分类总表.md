## 二、每个题材的12节点

```text
题材入口
→ 核心对象
→ 主体位置
→ 关系与权限
→ 触发行为
→ 对象状态转换
→ 十元端点
→ 生克补机制
→ 动态链
→ 五大主题显影
→ 反证
→ 输出
```

64个题材共形成：

```text
64 × 12 = 768个题材内部节点
```

## 五、维护规则

新增题材时禁止只添加一行主辅十元。必须建立完整12节点；缺少任一节点，标记：

```text
topic_node_incomplete
```

题材主十元仍是结构候选，必须经具体作品的对象变化、行为代价、阶段转位与反证复验后，才能升级为作品结论。
