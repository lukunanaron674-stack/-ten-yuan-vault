# C｜命运改写与信息优势

## T-C01｜回归重生
- **0入口**：主`xn`；辅`xz`/`x`/`zn`；结构候选。
- **1对象**：未来知识、资源配置、失败路径与关键窗口；证据：重排时间节点｜提前配置资源｜旧失败危险逼近。
- **2主体**：回归者／旧敌与旧盟友／时间节点；区分稳定本体、阶段状态、关系功能。
- **3关系权限**：定义权｜退出权｜资源权｜解释权｜承载｜认可。
- **4触发行为**：回到过去或灾难节点重启；补行动者、对象、目的、回应、收益、代价。
- **5状态转换**：知道失败→重排节点与资源→危险路径被改写或再次收束。
- **6十元端点**：主`xn`；辅`xz`/`x`/`zn`；逐阶段记录体量与顺序。
- **7生克补**：xn生xz；xz克zn；x补zn；zn克xn；只作可检验方向。
- **8动态链**：碎片行动与时间节点出现 → xn组织规则、流程、证据或计划 → 即时权能被限制或危险窗口被制造 → 结构持续运行
- **9主题**：本体候选；仍需中心问题、转折、高潮与结局共同显影。
- **10反证**：有未来知识不等于xn，必须主动组织新结构；执行拿掉测试与替代解释。
- **11输出**：对象状态卡｜双主体关系卡｜行为卡｜机制证据卡｜动态链｜主题卡。
