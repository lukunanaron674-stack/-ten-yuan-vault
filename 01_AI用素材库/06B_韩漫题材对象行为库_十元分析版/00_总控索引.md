## 二、逐节点十元规则

每个知识节点必须写明：

```text
分析对象层
主十元候选
辅十元／系统功能
可进入的生克补
最低证据
最近邻误判
```

必须区分：

```text
节点的库功能 ≠ 作品人物的十元
题材名 ≠ 固定十元
角色身份 ≠ 人物稳定本体
单个动词 ≠ 行为十元
连线先后 ≠ 生克补启动
十元共现 ≠ 自动生成五大主题
```

## 四、现行十元主骨速查

| 十元 | 当前主骨 |
|---|---|
| `x` | 对象、资源、地盘、权限与关系进入“归我 / 我方掌握”的边界 |
| `zx` | 主体权能公开显现、扩大，并凌驾于他者之上 |
| `xn` | 主体主动组织计划、时间、规则、流程、信息与节点，使结构持续运行 |
| `nx` | 主体不占方向决定权，沿已有安排、关系、身份、权限或流程通道推进 |
| `x并z` | 表层壳与内部真实形成结构性分层；壳本身也是存在与公共接口 |
| `zn` | 意义、信念与精神主体从内部成立；不靠外部奖励证明 |
| `z` | 精神个体需要认可主体看见、回应并确认其存在、能力、作品或价值 |
| `n` | 事情落到主体身上后被接住、承载、消化与处理 |
| `nz` | 柔情停靠、等待与不想让一段关系或时光结束 |
| `xz` | 危险显身、异质逼近、退路缩窄与命运临界行动 |

## 八、结论等级

| 等级 | 含义 | 使用方式 |
|---|---|---|
| `结构候选` | 从题材定义推得的常见机制 | 可用于生成，不能替代作品分析 |
| `场景支持` | 已有具体行为、对象变化或场景证据 | 可进入案例卡 |
| `作品复验` | 至少经过一部完整作品的关键转折、高潮和结局验证 | 可进入默认采矿池 |
| `正本锁定` | 与十元核心正本及关系专项一致并通过95%确认 | 可回填理论库 |

## 九、维护协议

新增条目后必须同步对应分析层：

```text
新增题材 → 18、21、篇幅验证
新增主体/关系 → 19、22、伦理风险
新增行为/言语行为 → 状态机、20
新增行为链/回报 → 20、21、22、篇幅验证
新增理论结论 → 17、23，并附正本来源与反证
新增Canvas节点 → 必须新增独立十元分析卡
```

状态约定：

- `node_analysis_missing`：Canvas存在唯一知识节点，但缺少独立十元分析卡。
- `analysis_missing`：原库已有条目，但分析层尚未同步。
- `orphan_analysis`：分析层有结论，但找不到原始条目或作品证据。
- `needs_revalidation`：十元正本或关系表更新后需要复验。

同一文件不再为了不同区域展示而复制多个Canvas文件节点；统一使用唯一节点与多条连线。

## 十、冻结原则

- 不默认 `zn` 起手。
- 不默认 `n` 承载所有温柔关系。
- 不从结局倒推整条动态链。
- 不用服装、色调、职业或平台标签证明人物本体。
- 不把动词直接映射成十元。
- 不把五大主题构成公式还原成唯一十元事件关系。
- 未锁定的生克机制只保留“位置候选”，不编造解释。
