# 青山团 · 怎么跑

> 92 个人物、94 个势力、297 条关系。一桌人在宁朝京城查一桩不该查的案子。

## 一、你先要知道的三件事

**1. 这是宁朝 vs 景朝的世界。** 南北对峙，景朝的细作已经扎进京城两年。

**2. 城里七股势力在互相咬：** 司礼监（皇权）、六部文官、京营军方、世家宗族、商帮盐引、书院清议、佛道诸宗。每一股都有人坐在跑团人物表里。

**3. 主角是沈砚。** 五城兵马司巡捕，28 岁，查案不问出身只问时辰。腰上那枚旧腰牌，编号不是他自己的 —— 这是你的第一条暗线。

## 二、三种跑法

## 三、本地 AI 跑团（推荐先试这个）

**最省事：双击 `C:\work\trpg\启动跑团.cmd`**，浏览器会自动打开 `http://127.0.0.1:8848`，
点右上角「开局」就开始。左边是剧情，右边是你的角色卡、关系最近的 8 个人、暗线进度；
GM 给的 A/B/C 选项可以直接点，点了等于替你输入；右下角有掷骰和抽签按钮。

右上角那个「主角」输入框可以填 92 个人里的任何一个（有下拉候选），换人就有新的一局。
当前默认主角是沈砚。

现在能跑的模型：`qwen3-4b-gm`（4B，一轮 3~5 秒）。14B 还在后台下，下完会自动切过去。

如果更喜欢终端：

```
cd C:\work\trpg
python trpg_local_gm.py --roll
```

- 开场会自动抽签（人名 + 地点 + 组织），然后生成第一个画面。
- 输入你的行动，回车。想看暗线进度输 `看`，想临时抽签输 `抽`，结束输 `退出`。
- **每轮它都会自动往 `冒险日志.md` 写一条带情节线标签的事件**，所以跑完自然沉淀成剧情。

换主角：

```
python trpg_local_gm.py --pc 柳青娘
python trpg_local_gm.py --pc 韩千岁
```

换模型（网页端会自动挑可用的最好的那个）：

```
python trpg_local_gm.py --model qwen25-14b-gm     # 14B，稳
python trpg_local_gm.py --model qwen3-4b-gm       # 4B，快但记性差
```

## 四、掷骰规则（跟 AI 跑也用它）

| 情况 | 判定 |
|---|---|
| 普通动作 | d20 ≥ 12 成功 |
| 你的本职（沈砚：查案、追踪、问话、近身） | d20 ≥ 9 成功 |
| 对上高一档的对手 | d20 ≥ 15 |
| 掷出 1 | 大失败，多付一个代价 |
| 掷出 20 | 大成功，多拿一条线索 |

## 六、抽签池怎么用

`抽签池.md` 里有 **姓名 92 / 地点 50 / 组织 94**，共 236 项。

临场需要路人时，三样各抽一个，画面立刻就有了：

> 抽到「鹿三七 · 盐引交易所 · 朝仓一 背后是 松浦氏海上武装」
> → 百鹿阁的东家在盐引交易所撞上赌坊老板，两人都在替南边的人做事。
