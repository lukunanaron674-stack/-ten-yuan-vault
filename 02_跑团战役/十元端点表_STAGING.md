# 青山团 · 十元端点表（STAGING）

> 用途：给跑团 GM 一层「NPC 第一反应先做什么」的发动机，避免所有 NPC 都长一个样。
> 纪律：AI 不当裁判。本表为候选，须你拍板才升为正史。每条都带原文证据与反事实检查，缺一不可。

## 固定映射（正本 v1.4）

```text
木：阳木zx ↔ 阴木nx
火：阳火zn ↔ 阴火x
土：阳土n  ↔ 阴土x并z
金：阳金xn ↔ 阴金z
水：阳水xz ↔ 阴水nz
```

## 十元核心操作

| 十元 | 五行 | 相反端 | 核心操作 |
|---|---|---|---|
| zx | 阳木 | nx | 占据方向源，以自身权能向外施加并压退竞争方向 |
| nx | 阴木 | zx | 让出最终方向源，沿既有路线、关系、权限或通道续接 |
| zn | 阳火 | x | 保留自己与他者的独立意义、选择和成立资格 |
| x | 阴火 | zn | 把对象纳入「归我/我方」的掌握与处分边界 |
| n | 阳土 | x并z | 让对象真实进入内部并持续承担其负荷 |
| x并z | 阴土 | n | 把内部对象映射成外部可识别、调用、代表或进入的公共壳 |
| xn | 阳金 | z | 把重心分布进顺序、规则、记录和流程，使其持续运行 |
| z | 阴金 | xn | 把一个对象提升为最高中心，其他对象退出中心判断 |
| xz | 阳水 | nz | 收窄路线、时间窗、退路和可逆空间 |
| nz | 阴水 | xz | 保存或重开对象特异的回返、修复和连接路径 |

## 这一层在跑团里怎么用

GM 不念符号。端点只决定两件事：NPC 的第一反应、被顶住之后的第二反应。
每一轮必须满足三条硬约束：

1. 有一个具体变量被改变：退路 / 凭据归谁 / 时间窗 / 谁欠谁 / 谁在场
2. 这个改变落在一件能看见、能摸到的实物上（钥匙、印章、账页、伤口、门槛、灯芯）
3. `<<LOG>>` 行末尾追加 `| 变量:变量名 从A到B`

## 边界与待办

- 92 人里只有 10 人手工标端，其余走势力兜底。这是故意的不完整：**没有证据的端点不该硬写**。
- 「人物索引」的备注是唯一证据来源。想让某个 NPC 有独立端点，先给备注补一句可核验的行为。
- 含 `z` / `zn` 的三张卡（温静之、韩千岁、铁骅次）只能标人，不能拿去跑生克 strict 推断。
- 沈砚 × 铁骅这一对：`xn` ↔ `xz`，一个先要凭据、一个先扣退路，天然对撞，适合作为开场冲突。
