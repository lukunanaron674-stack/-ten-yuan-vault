# 本体类神作库候选｜《第七次救人》记忆灵魂冲突 v0.1

## 0. 本轮核心校准

当前最强方向不是“少女救人七次”的能力爽点，而是：

```text
她本身是 x + zx 的灵魂。
她不是天生圣女，不是纯 zn 人格。
她是冲动、直接、讨厌被定义、靠行动硬闯的人。
但每救一次人，她都会失去一段自己的真实记忆。
城市与被救者为了保存她，反而把一堆 zn 英雄记忆强塞给她。
最后她的记忆越来越像英雄，灵魂却仍然是 x+zx。
冲突点：我记得自己是英雄，但我的魂不是英雄。
```

一句话封存：

```text
一个 x+zx 灵魂的少女靠牺牲记忆七次救人；被救者为了保存她，把“她像英雄”的 zn 记忆不断输入给她，最终她拥有了所有英雄记忆，却失去了那个真正愿意冲出去救人的自己。
```

---

## 1. 为什么第一版本值得冲 99

### 1.1 真正的神作点

不是“救人会失忆”。

而是：

```text
记忆被他人保存成 zn，灵魂本体却是 x+zx。
```

这会产生三层冲突：

| 层 | 冲突 | 说明 |
|---|---|---|
| 能力层 | zx救人行动 vs x自我耗损 | 每次行动救人，都会削掉自己的一段真实记忆。 |
| 记忆层 | 他人保存的zn记忆 vs 她真实的x+zx性格 | 人们只保存“她为何伟大”，却保存不了“她为何会冲出去”。 |
| 本体层 | 我记得我是英雄 vs 我的魂不认这个英雄身份 | 她被记忆塑造成英雄，但内核不是英雄雕像，而是活的冲动。 |

### 1.2 本体类力度

这正好落入本体类的核心公式：

```text
本体类 = 谁有资格占据 zn+x。
```

《第七次救人》的问题是：

```text
如果所有人都把我的记忆修成英雄版本，
那我还是原来的我，还是被大家共同写出来的英雄外壳？
```

---

## 2. 主角灵魂定型：x + zx

### 2.1 她不是圣女

她本身性格应该是：

```text
急、冲、嘴硬、讨厌仪式、讨厌被感谢、讨厌意义包装。
```

她救人不是因为“我有伟大信念”。

而是：

```text
我看见人要被命运吃掉，我身体已经先冲出去了。
```

### 2.2 她的魂核

```text
x：不受控的生命冲量，不肯看着人被吞掉。
zx：直接行动，不等待理由，不等待制度许可。
```

她最重要的一句话不应该是“我要拯救大家”。

而应该是：

```text
“少废话，我先把你拽出来。”
```

或者：

```text
“理由等活下来再编。”
```

这句话能把 x+zx 和后面的 zn 记忆包装区分开。

---

## 3. 被救者为什么会强塞 zn 记忆给她

### 3.1 不是恶意，而是保存失败

被救者不是坏人。

他们想保存她。

但他们只能保存自己理解到的她：

```text
她救了我，所以她一定是善良的。
她牺牲记忆，所以她一定是伟大的。
她救了很多人，所以她一定是英雄。
```

问题是：

```text
这些都是 zn 解释，不是她的 x+zx 灵魂。
```

### 3.2 记忆输入机制

每次她失忆后，被救者都会把一段“关于她的记忆”还给她。

但这些记忆是二手的、解释过的、感恩滤镜过的。

```text
原始她：冲出去、骂人、摔倒、害怕、临时起意。
被保存版本：坚定、温柔、伟大、命中注定、像英雄。
```

于是每救一次，她都少一点真实，多一点被解释出来的 zn。

## 4. 七次救人结构推敲 v0.1

七次不能只是重复救人。七次应该是“她的真实性格一点点被替换成英雄记忆”的七个阶段。

| 次数 | 她真实付出的记忆 | 被救者还给她的zn记忆 | 真实损失 | 结构功能 |
|---:|---|---|---|---|
| 1 | 她第一次冲出去前其实很害怕 | “你当时毫不犹豫” | 失去害怕 | 英雄化开始 |
| 2 | 她救人时骂了对方很难听的话 | “你当时温柔地鼓励我” | 失去嘴硬和粗粝 | 温柔圣女化 |
| 3 | 她其实想逃，但脚自己冲了出去 | “你说命运不能赢” | 失去逃跑冲动 | 信念化 |
| 4 | 她救人是因为那人像她讨厌的自己 | “你平等地爱着每个人” | 失去私人厌恶 | 公共爱化 |
| 5 | 她曾后悔救了某个人 | “你从不后悔” | 失去后悔能力 | 道德无瑕化 |
| 6 | 她差点为了保住自己记忆而放弃救人 | “你选择牺牲自己” | 失去自私 | 英雄壳完成 |
| 7 | 她最后要救的是“没有英雄记忆的自己” | 城市要求她成为永恒英雄 | 选择本体 | 神作结算 |

关键：

```text
第七次不是再救一个外人。
第七次她必须救回那个曾经会害怕、会骂人、会后悔、会想逃、会自私的自己。
```

## 5. 版本01｜99分候选：记忆与灵魂冲突版

### 一句话故事核

一个 x+zx 灵魂的少女每救一次人就会失去一段真实记忆；被救者为了让她“不忘记自己”，把感恩滤镜中的 zn 英雄记忆输入给她，最终她记得自己是伟大的英雄，却再也记不起那个曾经害怕、嘴硬、冲动、自私但仍会冲出去救人的自己。

### 三幕式

#### 第一幕：救人行动与第一次错存

少女第一次救人时，并不伟大。

她害怕、嘴硬、边跑边骂，甚至冲出去前还想过“关我什么事”。

但她还是冲了出去。

救完后，她失去这段真实记忆。

被救的人把记忆还给她：

```text
“你当时一点都没有犹豫。”
```

于是她记住了一个更漂亮的自己。

#### 第二幕：六次救人，英雄记忆逐层覆盖灵魂

每一次救人，她都失去一块 x+zx 的真实性格。

被救者每一次都把她修成更 zn 的英雄：

```text
害怕被改成勇敢。
嘴毒被改成温柔。
后悔被改成无私。
自私被改成牺牲。
冲动被改成使命。
```

城市开始包装她。

她的雕像、纪念歌、新闻影像、虚拟人格，全都在重复：

```text
她生来就是为了拯救别人。
```

但她灵魂深处越来越烦躁。

她不知道为什么。

因为她的记忆说：我是英雄。

但她的魂说：不对，我不是这样的人。

#### 第三幕：第七次救人，救回不配当英雄的自己

第七次灾难来临。

城市要求她上传最后一段灵魂，成为永恒救援AI/公共英雄人格。

这可以救下所有人。

代价是：她会彻底只剩下城市输入的英雄记忆。

最后她拒绝成为完整英雄。

她把前六个被救者叫来，要求他们说出真相：

```text
“别再说我伟大。告诉我，我当时到底是什么样的人。”
```

他们终于承认：

```text
你当时害怕。
你当时骂人。
你当时想逃。
你当时后悔。
你当时也想先救自己。
```

她听完后笑了。

因为那个不配当英雄的人，才是真正会冲出去救人的她。

第七次，她不是牺牲自己成为英雄。

她带着恐惧、自私、后悔和愤怒冲出去。

这一回，她救的是：

```text
人们从她身上删掉的那个真实自己。
```

### 构成链

```text
x+zx真实灵魂
→ zx救人行动
→ x自我记忆耗损
→ 被救者n+zn保存她
→ zn英雄记忆被强塞回她
→ x并z公共英雄外壳包装
→ xz命运临界持续克zn
→ zn+x主体被公共叙事夺走
→ 第七次拒绝纯英雄化
→ 带着不完美主体重新行动
```

### 评分

| 项目 | 分数 | 理由 |
|---|---:|---|
| 起手准度 | 25/25 | x+zx 灵魂与 zx 救人行动极清晰。 |
| 十元关系 | 25/25 | x自我耗损、zn记忆强塞、x并z包装、xz克zn全部可见。 |
| 动态链质量 | 30/30 | 七次结构每次推进一层主体替换，不是重复桥段。 |
| 入库价值 | 19/20 | 可上神作库，仍需写出第七次灾难具体形式。 |
| 总分 | 99/100 | 神作库候选。 |

## 6. 版本10｜95分候选：信任交互 / 自私取代版

### 核心想法

第十版本的强点不在“信念转交”，而在：

```text
信任的交互最后被自私取代。
```

她原本救人靠信任：

```text
我给你一段我的信念，你替我把它活下去。
```

但命运让她成为英雄后，她开始发现：

```text
所有人都在拿她的信念活，没人问她还剩不剩。
```

于是自私出现。

不是低级黑化，而是本体自救：

```text
我想把一块信念留给自己。
```

### 一句话故事核

一个靠把信念交给别人来救人的少女，被命运塑造成人人信赖的英雄；当她发现所有人都理所当然地索取她的信念时，她第一次产生自私，想把最后一块“活下去的理由”留给自己。

### 构成链

```text
zn信念交互
→ zx救人行动
→ n+zn被救者保存信念
→ xz命运反复逼她牺牲
→ x自私萌生
→ zn英雄人格被动摇
→ zn+x主体从公共英雄转向私人自救
```

### 可上95的原因

它不是“英雄堕落成自私”。

而是：

```text
自私第一次证明她还有主体。
```

如果一个人完全没有自私，那她只是公共工具。

所以这里的自私不是污点，而是本体回魂。

### 评分

95/100。

神作方向成立，但要注意：自私必须写成主体自救，不要写成普通黑化。

## 7. 版本03+10｜98分候选：xn城市 / 虚拟歌姬 / 记忆上传版

### 核心想法

这个版本可以独立成另一部高分作品。

结构不是单纯末日，也不是单纯偶像，而是：

```text
xn城市系统 + x并z虚拟歌姬外壳 + zn记忆上传 + x+zx魂核冲突。
```

空间气质可以是：

```text
末日城市外壳 + 虚拟偶像系统 + 救援AI信仰网络。
```

### 一句话故事核

末日城市把一个 x+zx 灵魂的救援少女制作成虚拟歌姬，并不断上传被救者对她的 zn 记忆来维持全民信仰；可歌姬人格越完美，越与她原本冲动、嘴硬、自私、会害怕的魂核冲突，最终她必须在拯救城市信仰与夺回真实自我之间选择。

### 结构定位

| 元素 | 十元 | 功能 |
|---|---|---|
| 末日城市 | xz + xn | 命运临界被制度化管理。 |
| 虚拟歌姬 | x并z | 公共观看外壳、包装、可传播的英雄皮肤。 |
| 记忆上传 | zn / nx | 人们把理解过的她输入系统，形成二手人格。 |
| 原始魂核 | x + zx | 冲动、行动、反命运、不等理由。 |
| 城市秩序 | xn | 需要她稳定人心，压制末日恐慌。 |
| 本体冲突 | zn+x | 被输入的人设是否有资格替代她。 |

### 三幕式

#### 第一幕：救援少女被上传成城市歌姬

城市濒临崩溃。

她七次救人后记忆残缺。

官方把她做成虚拟歌姬，让她每天唱“活下去”的歌，稳定城市秩序。

#### 第二幕：人们输入设定，歌姬越来越不像她

每个被救者都上传一段关于她的记忆。

但上传的不是她本人，而是被救者心中的她：

```text
温柔、坚定、圣洁、无私、永远愿意牺牲。
```

系统用这些 zn 记忆训练歌姬人格。

歌姬越来越完美。

但深层魂核不断产生噪声：

```text
“我不是这样说话的。”
“我没这么温柔。”
“我当时明明怕得要死。”
```

#### 第三幕：虚拟歌姬选择唱出不配被崇拜的真相

末日潮再次来临。

城市要求她唱最后一首歌，让所有人进入安定幻觉。

她却切断伴奏，公开播放七次救人的真实记忆：

```text
害怕、骂人、逃跑、后悔、自私、崩溃。
```

城市信仰瞬间破裂。

但人们第一次看见：

```text
救他们的不是神像，而是一个不完美的人。
```

最后她不再作为虚拟歌姬唱“希望”。

她用破音说：

```text
“别信我。自己站起来。”
```

### 构成链

```text
xz末日临界
→ xn城市秩序需要稳定信仰
→ x+zx少女救人行动
→ zn记忆上传
→ x并z虚拟歌姬包装
→ nx系统筛选并净化人格
→ zn英雄设定强塞魂核
→ x真实冲量反噬
→ zx公开真实记忆
→ zn+x从偶像外壳回到真人主体
```

98/100。
