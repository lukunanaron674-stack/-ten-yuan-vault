# 1. 本体类总定义

## 1.1 中枢总规则

```text
本体类 = 主体资格被追问。
不是身份题材，不是精神痛苦，不是艺术 / 战争 / 运动题材。
```

本体类追问：

- 谁才算我？
- 我靠什么活？
- 什么正在夺走我？
- 什么正在替换我？
- 什么正在切割我？
- 什么正在燃烧我？
- 什么正在证明我？
- 什么正在剥夺我？
- 什么正在空心化我？
- 什么正在碎片化我的存在？

一句话：

```text
本体类 = 谁有资格占据 zn+x。
```

# 3. 入库分层规则

## 3.1 主仓本体

必须出现主体资格被直接：

- 夺取
- 替换
- 切割
- 燃烧
- 证明
- 剥夺
- 空心化
- 碎片化
- 批量化
- 生成

## 3.2 跨仓回捞

```text
其他五维主链运行 → 主体资格被推上审判台 → zn+x 被重判
```

如果只是时间重释、空间压迫、因果失败、命运错过、精神痛苦、强情绪、身份题材，不能回捞。

## 3.3 灰银规则

灰银必须标污染来源：

- 时间污染
- 空间污染
- 因果污染
- 命运污染
- 媒介依恋污染
- 梦境谜题污染
- 情绪强度污染

## 3.4 铜矿规则

铜矿不是废物，是边界钉子。  
它用于提醒后续审稿：某类作品结构强，但不是本体强。
