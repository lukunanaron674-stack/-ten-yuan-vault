# 本体类音乐银矿挖矿归档 R1-R15

> 唯一矿区：**本体类音乐 zn+x**  
> 本体类音乐不是“歌词写我是谁”，而是：  
> 一个声音主体原本靠什么成立，被什么 x 撕开、燃烧、压迫、吞噬、证明、替换，最后声音里的“我”是回收、崩坏、空心化，还是变成新本体。

## 1. 银矿哥总原则

> 我不收“听起来很有感觉”的歌。  
> 我只收真正让声音主体发生存在变化的歌。

### 1.1 硬门槛

| 分数 | 入库判断 |
|---:|---|
| 95+ | 金矿 |
| 90-94 | 高银矿 |
| 85-89 | 银矿 |
| 85 以下 | 铜矿 / 待听池 / 转仓 |

### 1.2 四项评分

| 维度 | 分值 |
|---|---:|
| 听感起手准度 | 25 |
| zn+x 命中度 | 25 |
| 动态链质量 | 30 |
| 入库复用价值 | 20 |
| 总分 | 100 |

### 1.3 严查污染源

| 污染源 | 风险 |
|---|---|
| 歌词深刻 | 不能代替声音结构 |
| 现实议题强 | 不能代替 zn+x 动态链 |
| 角色语境强 | 不能倒灌进音乐本体 |
| 情绪强 | 不等于 x 击穿 zn |
| 名曲光环 | 不等于入库价值 |
| 怪物 / 机器 / AI 题材 | 不自动等于本体类 |
