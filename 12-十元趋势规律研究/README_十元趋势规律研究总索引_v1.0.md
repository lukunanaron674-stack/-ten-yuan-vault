# 十元趋势规律研究｜总索引 v1.0

> 本库研究的核心不是“某个十元接着另一个十元出现”，而是：**一个完整对子怎样转化为另一个完整对子**，这种顺序、主导权变化与体量迁移为何产生稳定的叙事或体验效果。

## 一、最小研究单位

趋势的最小单位必须写成：

```text
对子 P1 ──关系 / 条件 / 阶段机制──▶ 对子 P2
```

其中每个对子都必须完整：

```text
P1 = 主十元 + 次十元 + 对象层 + 体量 + 阶段功能
P2 = 主十元 + 次十元 + 对象层 + 体量 + 阶段功能
```

禁止退化成：

```text
zx → nx → xz
```

除非这三个符号分别只是已定义完整对子的简称，并且正文已明确每个阶段的主次、对象、条件和箭头标签。动态链研究的是对子与对子的关系，不是让单个符号排队制造一种看起来很深奥的交通拥堵。

## 二、趋势图强制格式

标准写法：

```text
[P1：主zx7 + 次nx4｜人物行动层｜承担并持续执行]
        ──失败责任累积 / 外部路径关闭 / 阶段切换──▶
[P2：主xz8 + 次nx3｜人物行动层｜压迫成为主导，顺流能力退居次位]
```

箭头必须写明：

1. 方向；
2. 起点对子；
3. 终点对子；
4. 关系或中性过程标签；
5. 触发条件；
6. 阶段边界；
7. 主导权或体量发生了什么变化。

只写“维持”“变化”“进入下一阶段”属于半条链，不得入库。

## 三、趋势与严格生克补的区别

趋势箭头不自动等于生、克、补：

```text
时间先后 ≠ 生
强度下降 ≠ 克
缺口被填 ≠ 补，除非缺口和补位机制均通过关系门槛
剪辑接续 ≠ 十元关系
位置迁移 ≠ 十元关系
主导权切换 ≠ 必然存在直接边
```

箭头标签分为四类：

| 类型 | 写法 | 使用条件 |
|---|---|---|
| 严格关系 | `A生B / A克B / A补B` | 只能引用已锁定关系正本 |
| 条件弱关系 | `conditional_relation` | 已通过弱关系门禁 |
| 概率或入口 | `probability_relation / entry_relation` | 已有跨领域弱机制复现 |
| 中性过程 | 阶段切换、主导权转移、体量升降、退出、替代、回返 | 不声称生克补机制 |

未通过审计的关系不得为了画面完整而伪装成严格箭头。

## 四、趋势类型候选

以下是研究分类，不是已锁定母型：

### 1. 主导权切换

```text
A主+B次  →  B主+A次
```

研究同一对子内部主次交换后，阶段功能怎样变化。

### 2. 配比迁移

```text
A8+B2  →  A4+B7
```

研究符号不变但体量结构改变时，体验是否出现稳定转折。

### 3. 次元替换

```text
A主+B次  →  A主+C次
```

研究主元稳定、次元替换对行动方式或主题质地的影响。

### 4. 主元替换

```text
A主+B次  →  C主+B次
```

研究承载环境或关系仍在，但主导变量发生更换。

### 5. 对子整体替换

```text
A+B  →  C+D
```

要求证明不是对象层偷换、剪辑跳跃或新事件直接覆盖。

### 6. 回返与循环

```text
P1 → P2 → P1'
```

`P1'`必须记录与初始 `P1` 的差异，禁止把成长后的回返写成原地转圈。

### 7. 分叉

```text
P1 → P2a
   → P2b
```

必须说明分叉条件和反事实路径，不能事后看见两个结局就补画树枝。

## 五、趋势证据门禁

一条趋势候选至少完成：

1. **原始事实核验**：片段、事件或阶段真实存在，不用常识补完未展示内容；
2. **对象连续性**：起点与终点研究同一对象或明确记录对象切换；
3. **起点对子完整**：主次、体量、对象层与阶段功能明确；
4. **终点对子完整**：主次、体量、对象层与阶段功能明确；
5. **阶段边界明确**：何时开始、何时完成、是否只是瞬时波动；
6. **箭头机制明确**：严格关系或中性过程不得混写；
7. **拿掉测试**：拿掉候选触发因素后，迁移是否仍发生；
8. **反向测试**：条件撤回后是否回返、停滞或继续；
9. **第三因素冻结**：排除新资源、职位、能力、剪辑跳跃与外部强制；
10. **跨作品复验**：同一趋势至少三部独立作品；
11. **顺序对照**：比较 `P1→P2` 与 `P2→P1` 是否产生不同功能。

## 六、八项置信度

```yaml
source_pair_accuracy: 0-100
target_pair_accuracy: 0-100
stage_boundary_accuracy: 0-100
transition_mechanism: 0-100
removal_test: 0-100
reverse_test: 0-100
rival_exclusion: 0-100
cross_case_replication: 0-100
final_confidence: 取最低项
```

状态门槛：

| 状态 | 条件 |
|---|---|
| `candidate` | 一条完整对子迁移假设 |
| `observed` | 两部独立作品出现同方向迁移 |
| `controlled` | 拿掉、反向、第三因素与顺序对照完成 |
| `stable` | 八项均≥90，至少三部作品复验 |
| `canonical` | 八项均≥95，跨领域成立，且不与关系正本冲突 |
| `rejected` | 主要由剪辑、题材惯例、对象切换或单次事件解释 |

## 八、与动态链研究的分工

### 动态链研究负责

- 核验具体作品的连续片段；
- 画出该片段中真实的对子与对子关系；
- 记录箭头、条件、端点、失败边和阶段变化；
- 向审计提交端点或关系问题。

### 趋势规律研究负责

- 从多个已核验案例中抽取共同迁移模式；
- 比较不同作品中的顺序、配比与主导权变化；
- 建立跨案例趋势卡和反例；
- 不回头篡改具体影片案例，不增加动态链母型计数。

### 组合规律研究负责

- 定义每个阶段内部的对子；
- 研究主次、体量、激活方式和整体功能；
- 为趋势起点与终点提供完整组合口径。

## 九、首批研究池

本库暂不预设“成长型、救赎型、黑化型”等名称已经成立。首批只做结构抽取：

1. 同对子主次交换；
2. 同对子体量迁移；
3. 主元稳定、次元替换；
4. 次元稳定、主元替换；
5. 对子整体替换；
6. 回返但不复原；
7. 无直接边的阶段接续。

每类先从已核验动态链案例中提取不少于三条候选，再决定是否值得命名。名字长得很快，证据通常还在穿鞋，所以先别给空气办户口。
