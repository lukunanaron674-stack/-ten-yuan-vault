## 1. 风格（Include / Exclude + 光色调）

- **Include**：老上影二维平涂线稿动画；受控深墨线、硬边纯色块、低饱和冷灰蓝主调、轻微纸张纤维、极少赛璐珞阴影、无写实高光。
- **Exclude**：3D、写实厚涂、渐变、水彩晕染、字幕、风格漂移、暖橙色调、背景音乐。
- **光色调**：冷灰蓝牢房、硬侧光、稳定墨线；胡左 / 方右的左右轴线全程锁定。

## 2. 时间轴（一镜到底，3.5s 处干净切镜）

| 时间 | 画面与动作 | 台词／声音 |
|---|---|---|
| 0–0.7s | 反打起幅：胡逸民在左半幅合焦、闭口看向方；方为右前景肩+局部侧脸，嘴在可读区外。 | 牢房底噪、对白尾音与呼吸连续。 |
| 0.7–2.5s | 胡眼与下巴极小幅度下沉，视线落向画外半块饼；表情从注意转克制思索；不点头不说话。 | 对白尾音延续，轻微衣料声。 |
| 2.5–3.5s | 胡保持低头，仅向方做极小幅度回望；不笑不接受不换位；方不新增手势。 | 呼吸、衣料、对白尾音收束。 |
| 3.5s | **干净切入**同凳双人中近景（由 @图片2 锁定的切点帧定义）。 | 滴水声渐隐。 |
| 3.5–4.3s | 方双手捧完整烧饼，胡看饼。 | 牢房底噪。 |
| 4.3–5.4s | 方低头，双手把饼**只掰一次**成两稳定半块。 | 一声轻干掰饼声。 |
| 5.4–7.7s | 方留一半、将另一半递向胡；胡闭口接住。 | 方：**「先吃，凉了就不好吃了。」** |
| 7.7–8.5s | 两人各持一半停顿。 | 轻微衣料声。 |
| 8.5–10.3s | 两块饼**只轻碰一次**（不握手不碰杯不庆祝）。 | 方：**「自有人间真情在，干一个。」** + 一声轻碰。 |
| 10.3–11.5s | 胡先低头看半块饼，再抬眼看方；方停话保持稳定。 | 留白，牢房底噪。 |

> **音频说明（关键）**：最终音轨按原 brief 要求，将参考视频（`ref5_motion.mp4`）的 11.5s 音频 **1:1 回灌（后期）**。导演台只出画面；取用方生成后用同源音频替换最终音轨即可。

## 3. 角色参考

- **R1 胡逸民（S1）**：灰白发、八字胡、左边长凳、完整深蓝灰囚服；**全程闭口、唯一不说话者**。
- **R2 方志敏（S2）**：黑发带伤、右侧、撕裂深蓝灰囚衣、脚镣；**唯一可见嘴型角色**，两段对白均属他。

## 4. 场景设定（C1 牢房）

- 冷灰蓝牢房：左侧铁栏窗、灰墙、编席板凳、硬侧光、受控墨线、平涂色块、纸纹。
- 胡左 / 方右的同凳双人关系由 @图片2（3.5s 切点帧）锁定，跨切镜不漂移。

## 5. 道具参考（P1 烧饼）

- **P1 烧饼**：一只完整圆烧饼，**只掰一次**成两稳定半块；不复制、不融合、不变馅、不变尺寸。
