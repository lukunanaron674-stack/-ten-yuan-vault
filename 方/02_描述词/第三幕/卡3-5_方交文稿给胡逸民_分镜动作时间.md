# 卡3-5｜方交文稿给胡逸民｜2:05—2:15｜10s

> 一句话：搜查逼近中，方志敏从衣内/草席夹层取折好文稿递给胡逸民，胡接稿藏衣内，无对白，共10s。

## ⏱ 动画+时间卡
| 时间 | 画面 | 动作 | 台词 | 声音 |
|---|---|---|---|---|
| 0—2.5s | 牢房中近景，铁栏外远处有人巡查 | 方志敏先向铁栏外看一眼，确认无人注意 | 无 | 搜查声渐近、脚步逼近 |
| 2.5—5s | 同上 | 从衣内或草席夹层取出折好的文稿，先看纸，再看胡逸民 | 无 | 纸张展开声 |
| 5—7.5s | 同上 | 把文稿递到两人之间，低声交付 | 无 | 衣料摩擦 |
| 7.5—10s | 同上 | 胡逸民停半拍，双手接过，迅速折好藏进衣内；两人只短暂对视；镜头最后停在胡压住文稿的手 | 无 | 牢房紧迫、脚步逼近 |


## ✅ 锁定
- 不握手、不拥抱、不激动点头；交接清楚；文稿必须是明确的折叠纸稿。
- 两人只短暂对视；无对白，仅眼神与动作。
