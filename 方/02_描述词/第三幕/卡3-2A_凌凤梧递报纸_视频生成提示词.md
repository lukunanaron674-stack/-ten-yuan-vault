## 1. 风格

- 整体：8K 电影感、低饱和、慢动作、压抑节奏、沉重呼吸构图
- 颗粒 / 特效：空气灰尘、纸屑微粒、火光余烬（极少）
- 光源（全局）：牢房头顶油灯为主光，左上高窗微弱冷月光为侧光
- 色调（全局）：暖灰主调 + 阴影冷青；不饱和；胶片颗粒感
- 氛围：1930s 民国监狱写实质感，无任何现代物件

**【Include】** cinematic, 8K, slow-motion, oppressive pacing, breathing composition, 1930s Republic of China prison realism, dim oil lamp light, low-saturation warm-grey palette, subtle film grain, dust motes, paper rustle micro-particles, dramatic shadow contrast
**【Exclude】** cartoon, plastic, low-poly, flat light, camera shake, lens flare, modern objects, English text, subtitles, anime style, 3D render, deformed hands, extra fingers, mutated faces, watercolor style, smartphone, surveillance camera, electric light bulb, modern clothing

## 2. 时间轴（每段含：机位 / 运镜 / 画面 / 台词·画外音 / 光源 / 色调 / 音效）

### 2.1 ［0.0—1.5s］ 接续 3-1B 尾帧 → 摇镜到递报位置
- **机位**：中景，镜头高度 / 方位继承 3-1B 已批准视频尾帧；牢门框中央
- **运镜**：固定机位基础上的慢速横摇（very slow dolly + pan），镜头从围坐众人摇向凌凤梧左侧递报位置
- **画面**：3-1B 收尾画面——狱友仍围坐原位；凌凤梧在牢门左外侧，双手托报纸于栏缝前；方志敏在栏内右侧；高家骏维持 3-1B 尾帧位置不动
- **台词 / 画外音**：无台词；远处牢房底噪淡入
- **光源**：头顶油灯为主光；左侧高窗微弱冷光补阴影；蜡烛烟气弥漫
- **色调**：低饱和暖灰主调；阴影偏冷青
- **音效**：远处铁栏轻响、囚犯低语余音、石墙回声

### 2.2 ［1.5—3.0s］ 凌凤梧递报 → 低声一句
- **机位**：中近景（栏缝与报纸边缘）；凌凤梧在画面左外侧、方志敏在栏内右侧
- **运镜**：缓慢推进（very slow dolly in），收束于手部递接动作
- **画面**：凌凤梧双手经栏缝向栏内递入报纸；方志敏从众人中前出半步、右手伸出栏缝接报；高家骏维持原姿态不动；凌凤梧倾身向前低声传话
- **台词 / 画外音**：凌凤梧低声说 **"小方，出事了。"**（压低音量，不响亮，被油灯烟气和石墙吸音）
- **光源**：油灯主光 + 报纸纸张对油灯火的微弱反射
- **色调**：递报瞬间略偏暖；栏内栏外亮度差形成空间对比
- **音效**：纸页摩擦声；台词被压低；铁栏轻微震响

### 2.3 ［3.0—4.5s］ 报纸特写 → 方志敏低头看折叠报纸 / 收尾
- **机位**：先报纸特写（报头与"攘外必先安内"大字占画面主体，方志敏手在下沿入画），再切方志敏半身与报纸同框的中近景
- **运镜**：特写固定；切中近景后极慢推进，定格于"看报"瞬间；本帧可挂尾帧
- **画面**：报纸外形以用户指定折叠图为准（折叠 / 层叠 / 斜向透视），标题区域保留并突出 **"攘外必先安内"** 大字，方志敏的手从画面下沿握紧报纸边缘、纸面轻微褶皱；随后切回方志敏半身，低头看报后抬眼，闭口克制；凌凤梧松手收手回左外侧
- **台词 / 画外音**：无台词；环境声降至最低
- **光源**：油灯主光从画面左上照入报纸表面，制造立体褶皱阴影；报纸标题区被照亮
- **色调**：暖灰留白、不煽情、克制低饱
- **音效**：纸张绷紧声、纸页轻微松弛声、环境声留白（成为后续卡可衔接的尾帧）

- 方志敏方向反向 / 与 3-1B 尾帧朝向不一致

- 报纸文字被改写 / 加字幕 / 加边框 / 加水印 / 出现英文
- 报纸版式被改、字形被换、加新文字
- 不出现胖子偷看 / 栏外窥视人物（2.3 段已删，画面里不得凭空出现）
- 变脸、3D、塑料感、额外手指、畸形手部
- 现代物件：手机、手电筒、电灯、监控摄像头、塑料椅、铁丝网（民国时期用）
- 现代服饰 / 现代化妆 / 高饱和配色
- 镜头剧烈抖动 / 强镜头光晕 / 模糊过度
- 多人台词叠加 / 多人同时说话
- 与 3-1B 尾帧场景不一致的空间元素（多了窗、多了门、家具风格突变）
- 出现卡通 / 二次元 / 水彩风元素
