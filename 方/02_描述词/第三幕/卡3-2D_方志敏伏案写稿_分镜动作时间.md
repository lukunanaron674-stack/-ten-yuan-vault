# 卡3-2D｜方志敏伏案写稿｜分镜动作时间

> 📌 版本：v1.0｜2026-08-15｜Codex（新建卡）

> 一句话：烛火下伏案写稿→胖士兵栏外窥见→离开，共约5s。
> ⏱ 帧率：12fps 主体（伏案/烛火摇曳）；H3 原生24fps渲染，成片转12fps，音频不变。

## ⏱ 动画+时间卡
| 时间 | 画面 | 动作 | 台词 | 声音 |
|---|---|---|---|---|
| 0—1.5s | 牢房内，方志敏伏案中景，烛火在桌角 | 方志敏执笔在纸页上缓慢书写，笔尖移动一两笔；烛火轻微摇曳 | 无 | 笔尖纸面沙沙声、烛芯轻响、夜环境声低 |
| 1.5—3.5s | 同上，栏缝方向矮胖士兵入画 | 矮胖士兵身影从栏缝外经过，停住，探头从栏缝窥见写稿动作，目光锁定纸面，不发一言 | 无 | 脚步停住一声、衣料摩擦、环境声压更低 |
| 3.5—5s | 同上 | 士兵缩回身、慢慢退离画面，方志敏继续书写不抬头 | 无 | 脚步远去、笔尖沙沙声继续 |

## ✅ 锁定
- 方志敏全程不抬头、不说话；烛火在桌边（旁边有蜡烛），不手持烛火。
- 胖士兵只做一次"经过→停住→窥见→离开"，不闯入、不对话、不夸张。
- 尾帧接卡3-3A矮胖士兵眼睛右看（同一士兵转身）。无字幕、无3D、无镜头晃动。
