# 卡3-2C｜凛递报后·胖子偷看｜分镜动作时间

> 📌 版本：v1.1｜2026-08-16｜Codex（按导演节奏重排为6s）

> 一句话：镜头先在左侧停住，再缓慢转向右侧；烛光从左向右移动，投影在第4秒左右照到胖子脸上；第5秒胖子像想到什么，露出爽朗又阴坏的笑，共6s。
> ⏱ 帧率：12fps 主体；H3 原生24fps渲染，成片转12fps，音频不变。

## ⏱ 动画+时间卡
| 时间 | 画面 | 动作 | 台词 | 声音 |
|---|---|---|---|---|
| 0—2s | 左侧牢门与递报余韵 | 镜头停在左侧，保持3-2A递报后的空间关系；凌凤梧收手，胖子暂不露全，只在左侧栏影后窥视。画面保持克制停顿。 | 无 | 牢房底噪、远处脚步、极轻呼吸；不加音乐重拍 |
| 2—3s | 从左向右的过渡 | 镜头在第2秒后才开始缓慢向右移动，栏柱前景连续掠过；胖子轮廓逐渐进入画面。烛光也同步从左向右移动，光影沿墙面和栏柱滑行。 | 无 | 轻微衣料摩擦、脚步停住、烛火轻响 |
| 3—4s | 右侧胖子近景 | 镜头继续缓慢转到右侧；烛光从左向右投影，约第4秒照到胖子脸上，先照到眼睛和半边脸，不突然变亮。胖子仍盯着牢内。 | 无 | 烛火声、远处牢门回响、呼吸略清晰 |
| 4—5s | 胖子脸部与栏柱 | 光线稳定在胖子脸上；胖子眼神先停住，再微微收紧，像突然想到什么。嘴角开始向上牵动，但笑还没有完全展开。 | 无 | 一次短促吸气，衣领轻响，环境声压低 |
| 5—6s | 胖子右侧近景定格 | 胖子露出爽朗、阴坏、带算计意味的笑；笑容不能夸张变形，保持人物体量和二维线稿表演。最后停在笑脸与栏柱构图上。 | 无 | 短促低笑，随后留一点牢房空响；不配对白 |

## ✅ 锁定
- 总时长固定6s。
- 0—2s左侧停顿；第2秒后才转；第3秒进入右移过程；第4秒左右烛光投到胖子脸上。
- 第5秒开始“想到什么”的表情变化，第5—6s完成爽朗但阴坏的笑。
- 镜头只做一次左→右缓慢移动，不甩镜、不回转；无对话、无字幕、无3D。
- 栏内方志敏/凌凤梧只作为连续性背景，不新增动作；胖子只完成偷看→想到什么→坏笑。
