# 卡1-1｜山河铺陈｜0:00—0:16｜16s

> 一句话：峨眉云海→西湖水面→雁荡远山→桂林山水四景山河铺陈，大远景无人物，共16s。

## ⏱ 动画+时间卡
| 时间 | 画面 | 动作 | 台词 | 声音 |
|---|---|---|---|---|
| 0—4s | 峨眉云海大远景晨光 | 云雾、山体缓慢自然运动，固定机位 | 无 | 高山风、远松涛（环境音高于音乐） |
| 4—8s | 硬切西湖水面倒影 | 水面微波、山影随波微动，缓慢横移固定机位 | 无 | 微波、极远鸟鸣；旁白沉稳报景名（可选） |
| 8—12s | 切雁荡远山淡雾 | 远山淡雾缓慢流动，固定机位 | 无 | 风声为主 |
| 12—16s | 切桂林山水 | 水面、山影缓慢变化，缓慢横移 | 无 | 水流声；无旁白或极轻 |


## ✅ 锁定
- 四景不简化成一景；云雾水面只做缓慢自然运动。
- 延续同一青绿色系与长卷感，同一画师风格。
- 无现代建筑、无夸张运镜、无3D质感、无文字、无人群突然出现、无镜头乱晃；不拍成旅游宣传片。
