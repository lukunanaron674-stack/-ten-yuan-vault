# 卡2-4R｜换画风重画｜分镜动作时间

> 总长 11.5s ＝ [Shot 1] 2-3 反打 3.5s ＋ [Shot 2] 2-4 掰饼 8s。机位固定同一光轴，不切镜、不越轴。
> 对白与呼吸时序严格对齐参考视频原音轨。

## [Shot 1] 过肩反打（固定机位，平视）

| 时间 | 动作 |
|---|---|
| 00:00.000–00:00.700 | 胡逸民看向方志敏，嘴唇紧闭 |
| 00:00.700–00:02.500 | 胡低头垂目一次，幅度极小，进入静思 |
| 00:02.500–00:03.500 | 保持低头，仅最后轻微眼动看向方 |
| 全程 | 方保持静止，无新手势，嘴在可读唇区外 |

> 此段去除原参考视频开头的重影／鬼脸／双重曝光／模糊，线稿稳定。

## [Shot 2] 双人中近景（首帧定义，00:03.500 干净切入）

| 时间 | 动作 |
|---|---|
| 00:03.500–00:04.300 | 方双手捧一整圆烧饼，胡注视 |
| 00:04.300–00:05.400 | 方低头，五指自然将烧饼只掰开一次成两稳定半块 |
| 00:05.400–00:07.700 | 方留一半，向胡递出另一半一次；方（S1）说：「先吃，凉了就不好吃了。」胡不语 |
| 00:07.700–00:08.500 | 两人各持半块停顿 |
| 00:08.500–00:10.300 | 两半饼轻触一次（无握手／碰杯／拥抱／庆祝）；方（S1）说：「自有人间真情在，干一个。」胡静默 |
| 00:10.300–00:11.500 | 胡低头看半块，缓抬眼向方安定；方停说保持静止 |

## 声音

- 复用参考视频原音轨 1:1：牢房低频环境、对白尾、克制呼吸、衣料轻响、一次干饼断裂、一次轻碰。
- 不加水声／撞击／呼啸／额外人声／音乐。
