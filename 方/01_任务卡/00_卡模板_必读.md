# 00｜卡模板｜核心不变框架（必读）

> 发散树里**每一张卡**（02_描述词 下每个 md 文件）都必须长成这个结构。字段顺序、标题层级、命名不许改；改内容前先读本页。

## 〇、两条底层规则（一切之上的规则，永不改变）

### 规则一：一句话卡号
- 每个画布节点框 = **卡号 + 一句话**：`卡X-X｜一句话`。
- 一句话来源 = 卡 md 标题正下方的 `> 一句话：`。
- 目的：统一理解、方便管理。框里第一行必须是这句话卡号，不允许裸卡号。

### 规则二：框内全链接化（索引化）
- 与这张卡有关的**一切内容**，在画布节点框里**只允许放 `[[链接]]`**，绝不直接展示内容本体。
- 必须链接的三类内容：
  1. **文字内容** → 链接本卡汇总 md（`卡X-X_….md`）
  2. **描述词 md** → 每个生成卡两个 md：`卡X-Y_….md`（画面描述词）、`卡X-Y_….md`（分镜动作时间）
  3. **图** → 链接分镜图/首帧图（`[[…png]]`，**不带 `!`，不嵌入**）
- 框内禁止：整段描述词、台词正文、图片嵌入、长文本。

## 一、卡文件固定结构（从上到下，一条不落）

```
# 卡X-X｜短名｜N条生成卡

> 一句话：<这一卡在讲什么、几条、总时长、关键看点>（= 画布节点框第一行「一句话卡号」）

## 📎 文件连接
- 分镜图/首帧：![[方/07_素材图/<幕>/<文件名>.png]]（md 内可嵌入，方便一键复制给 chat 跑）
- 角色卡：[[03_角色卡/方志敏|方志敏]]、[[03_角色卡/胡逸民|胡逸民]]…
- 声音：[[04_声音设计/声音设计总表|声音设计总表]]

## 🎬 画面描述词（一键复制给chat）
> 16:9，……（整段可以整体选中复制，丢进 AI 视频生成框）

## ⏱ 动画+时间卡
| 时间 | 画面 | 动作 | 台词 | 声音 |
|---|---|---|---|---|
| 0—Xs | … | … | … | … |

## ✅ 锁定
- （生成后对照检查项）
```

## 二、三条核心不变铁律

1. **一句话先行**：卡标题正下方必须有一行 `> 一句话：……`；画布节点第一行 = `卡X-X｜` + 这句话。
2. **画面描述词用 MD 引用块**：只允许 `> ` 引用块，16:9 开头；禁止普通段落直接当描述词。
3. **三件套齐全**：`📎 文件连接`（含生成图）＋`🎬 画面描述词`＋`⏱ 动画+时间卡` 缺一不可；时间卡用 Markdown 表格。

## 三、文件名与画布引用

- 发散树画布节点 = `02_描述词/<幕>/卡X-X_<短名>.md`；改文件名必须同步改画布节点链接。
- 每张卡内部，一条生成视频 = 一个 `##` 小节（如 `## 2-1A｜劝降开场｜124帧≈5.2s`）。
- 每个生成卡拆两个叶子 md：`卡X-Y_<名>_画面描述词.md`、`卡X-Y_<名>_分镜动作时间.md`。
- 素材图统一放 `方/07_素材图/<幕>/`；角色三视图统一放 `方/07_素材图/角色/`。

## 四、画布节点框格式（对应两条底层规则）

```
卡2-1｜一句话……

📄 文字：[[方/02_描述词/第二幕/卡2-1_….md|卡2-1]]
🎬 画面：[[方/02_描述词/第二幕/卡2-1A_….md|2-1A]] [[…2-1B…|2-1B]] [[…2-1C…|2-1C]]
⏱ 分镜：[[方/02_描述词/第二幕/卡2-1A_….md|2-1A]] [[…2-1B…|2-1B]] [[…2-1C…|2-1C]]
🖼 图：[[方/07_素材图/第二幕/牢房双人图.png|牢房双人图]]
```

- 第一行固定为 `卡X-X｜一句话`（一句话卡号）。
- 四行链接：文字 / 画面描述词 / 分镜动作时间 / 图，每行一类。
- 图片一律 `[[…png]]`（不带 `!`），框内不显示图片本体。

## 五、检查清单（写完一张卡过一遍）

- [ ] 画布节点第一行是 `卡X-X｜一句话`
- [ ] 节点框内只有链接（文字/画面/分镜/图），无内容本体
- [ ] 有 📎 文件连接，生成图/分镜图已嵌入
- [ ] 🎬 画面描述词是 `>` 引用块
- [ ] ⏱ 动画+时间卡是表格且时间轴完整覆盖
- [ ] 台词与统一台词表逐字一致
