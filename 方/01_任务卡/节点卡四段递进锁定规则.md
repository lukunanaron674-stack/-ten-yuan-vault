# 节点卡四段递进锁定规则

## 适用范围

适用于“方”项目第二至第五部分的所有节点卡。每张节点卡及其内容拆成四段，必须按顺序逐段锁定：

1. 内容概括锁
2. 画面描述与画面锁
3. 分镜头时间锁
4. 音效与视频锁

后一段不得反向改动前一段。确需修改前段时，必须在卡上标记“解锁”，说明修改原因，重新审核；被修改段之后的全部锁定自动失效，必须从该段起重新审核、重新锁定。

## 四段锁定规则

### 第一段：内容概括锁

- 内容：一句话事件、人物关系、前后接续、不可改变的剧情功能。
- 负责人：4号规则维护；1号内容审核。
- 输入：上游剧情/部分结构、上一节点尾部信息、下一节点衔接要求。
- 输出：节点卡的一句话内容概括及四项连续性约束。
- 通过标准：事件只有一个核心动作；人物关系明确；前后接续可追溯；剧情功能不可被画面或分镜改写。
- 打回条件：事件含糊或多中心；人物关系缺失；与前后节点冲突；没有写明剧情功能。
- 锁定方式：通过1号内容审核后，标记 `内容概括锁：已锁`。

### 第二段：画面描述与画面锁

- 内容：构图、人物位置、风格、比例、参考图/首帧。
- 负责人：2号描述词与结构；1号内容/画面审核。
- 输入：已锁的内容概括、角色/场景设定、上一节点尾帧或指定首帧。
- 输出：可执行的静态画面描述、构图关系、人物站位、风格比例、参考图/首帧清单。
- 通过标准：画面准确承载第一段剧情功能；人物位置和空间关系明确；风格、比例、参考资产可核对；首帧能与上节点接续。
- 打回条件：画面改变事件或关系；构图/站位不清；风格比例漂移；参考图或首帧缺失、冲突。
- 锁定方式：通过1号画面审核后，标记 `画面锁：已锁`。

### 第三段：分镜头时间锁

- 内容：景别、机位、运镜、动作时间线、对白嘴型。
- 负责人：2号描述词与结构；导演审核（含2号复核）。
- 输入：已锁的内容概括和画面描述；对白、动作、节奏要求。
- 输出：按时间顺序排列的镜头执行表，包含景别、机位、运镜、动作节点、对白及嘴型要求。
- 通过标准：镜头顺序可拍；景别/机位/运镜服务于已锁画面；动作时间线无跳变；嘴型只对应已写对白；首尾帧连续。
- 打回条件：镜头反向改写剧情或构图；动作过多、时间不可执行；机位/轴线不明；嘴型与对白不一致；首尾接续断裂。
- 锁定方式：通过2号/导演审核后，标记 `分镜头时间锁：已锁`。

### 第四段：音效与视频锁

- 内容：环境声、动作声、对白、音乐、视频时长/帧率/输出参数。
- 负责人：3号视频/图像执行；当前暂停执行；4号规则维护记录状态。
- 输入：前三段均已锁定的节点卡、镜头时间线、对白与声音设计要求。
- 输出：声音层级表和视频输出参数，包括环境声、动作声、对白、音乐、时长、帧率及其他项目规定参数。
- 通过标准：声音与动作时间线对齐；对白、嘴型、音乐不冲突；时长、帧率、输出参数齐全；成片检查无越界、缺声或接续问题。
- 打回条件：前三段仍有未锁内容；声音与动作/对白不同步；时长或帧率缺失；输出参数不符合项目要求；视频检查发现画面、接续或声音问题。
- 锁定方式：通过3号视频检查后，标记 `音效与视频锁：已锁`；当前阶段仅建立规则和待执行状态，不启动图像/视频执行。

## 节点卡状态标签

- `四段锁定状态：未开始`
- `内容概括锁：待审` / `已锁` / `解锁`
- `画面锁：待审` / `已锁` / `解锁`
- `分镜头时间锁：待审` / `已锁` / `解锁`
- `音效与视频锁：待审` / `已锁` / `解锁` / `暂停`
- `后续锁失效：是`：前段被解锁或修改后必须添加，并从修改段起重审。
- `重审原因：<一句话>`：每次解锁必填。

## 解锁与失效流程

1. 在被修改段写 `状态：解锁`、`重审原因`、修改人和日期。
2. 在该段之后的每个区块写 `状态：失效待重审`，并添加 `后续锁失效：是`。
3. 由对应负责人修改；前段重新通过原审核人后，才能按顺序恢复后续锁。
4. 4号更新锁定状态和变更记录；未完成重审前，不得进入下一段或执行生成。

## 执行边界

本规则只管理节点卡的内容、画面、分镜时间、声音与视频参数锁定。不得因维护本规则修改发散树 canvas或现有镜头内容；不得在规则生效/更新过程中自动启动图像或视频生成。
## 发散树工作台优先规则（新增）

- 发散树 Canvas 是本项目唯一的导演工作台和审批入口；Canvas 上的最新文字、颜色、位置、链接、锁定/解锁标记，以用户最后一次修改为准。
- 用户在 Canvas 上做出的批准、删除、替换、移动、改名、改内容或锁定标记，优先级高于旧 MD、旧探索卡、旧代理任务和旧备份；代理不得用旧文件覆盖 Canvas 的最新决定。
- 任何需要用户审核的未锁卡，必须在对应 Canvas 节点直接显示候选图/首帧、画面描述链接和审核状态；不能只把图片放在磁盘文件夹里，也不能只回报路径。
- 未锁卡的候选图必须标注“候选（待审核）”，不得写成“定稿”“已锁”；审核通过后才可改为“画面锁：已锁”。
- 已锁卡不得生成新图、替换首帧、改画面描述或改分镜；确需修改时，必须先在 Canvas 标记“解锁”和重审原因。
- 代理执行前必须重新读取 Canvas，按最新颜色/文字/锁定标记筛选任务；Canvas 未明确批准的删除、替换、改名和剧情改写一律不执行。
- 代理完成后必须把结果回写对应 Canvas 节点，并列出“已处理/待审核/跳过（已锁）”三类清单。
