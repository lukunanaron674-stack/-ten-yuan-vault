# 第二幕｜AI动画任务卡

> 📌 版本：v1.0｜2026-08-13｜Codex 初始化

> 总时长：0:45—1:27。主线：直接聊天 → 劝降 → 《清贫》两镜 → 人情反照 → 文稿伏笔。

## 本幕统一AI画面规则

- 不拍方志敏进入监狱，开场直接是方志敏与胡逸民已经坐在草席床上聊天。
- 牢房冷灰蓝、正铁栏、窄草席床；人物二维老动画平涂、微Q约5头身。
- 胡逸民穿干净囚服，是囚犯；递烧饼必须使用左手。
- 《清贫》插叙转火红、深暗色，但仍保持同一画师语言。
- 动作克制，嘴型只配合台词，禁止多动症、无意义手势与过度煽情。

> 更详细的全局规则见 [[01_任务卡/00_统一规则_必读]]；逐镜头描述词见 [[02_描述词/第二幕]]。

### 卡2-1｜已坐着聊天／左手递饼／劝降｜0:45—0:59｜14s｜✅

**画面区域**：双人中景。方志敏与胡逸民已经坐在草席床上。胡逸民左手把烧饼递给方志敏，说：“他们让我告诉你，只要肯写一份声明，家人、性命、高官、后路，都可以谈。”方接住，短停：“高官厚禄吗？胡兄可知当晚我被捕之事？”

**动作与镜头**：固定双人中景；胡逸民用左手缓慢递出烧饼 → 方志敏接住，先看饼再看胡。

**台词**：胡逸民：“他们让我告诉你，只要肯写一份声明，家人、性命、高官、后路，都可以谈。”方志敏：“高官厚禄吗？胡兄可知当晚我被捕之事？”

**声音**：牢房滴水声起；冷灰蓝牢房底噪、铁栏轻响。

**首尾帧**：首帧：双人中景，两人并坐在窄草席床上。尾帧：方接过饼，手短暂停顿，抬眼。

**锁定**：不起身、不走动、不挥手；嘴型准确配合对白；胡逸民必须左手递饼；胡穿完整干净囚服。

**AI描述词（直接复制丢进AI视频框）**：

### 卡2-2｜《清贫》搜身两镜｜0:59—1:07｜8s｜✅

**画面区域**：0:59—1:03：两名国民党士兵贪婪大脸从画框两侧挤入：“这个份量的‘大官’，身上一定有钱！”1:03—1:07：切中近景，方志敏双手被束在身后，一人压肩，一人翻衣襟、口袋与腰带，最后空手，恼怒：“怎么什么也没有？”

**动作与镜头**：第一镜夸张近景，两名士兵一瘦一壮从左右挤进画面 → 硬切第二镜，搜身动作粗暴但清楚 → 最后双手空空。

**台词**：士兵：“这个份量的‘大官’，身上一定有钱！”士兵：“怎么什么也没有？”

**声音**：急促短笑声；翻衣、掏口袋的摩擦声；环境音收起，气氛压低、隐约急促呼吸。

**首尾帧**：首帧：两名士兵头部从画框左右挤入。尾帧：搜身落空，士兵双手摊开，一无所获。

**锁定**：不做卡通鬼脸；动作粗暴但清楚；不增加第三镜；无3D质感；火红夜色插叙、深暗色。

**AI描述词（直接复制丢进AI视频框）**：

> 16:9 二维老动画火红夜色插叙。第一镜夸张近景，两名1930年代国民党士兵一瘦一壮，从左右挤进画面，贼眉鼠眼但不做卡通鬼脸，嘴型配合一句贪婪台词。硬切第二镜，方志敏双手被绑在身后，一人压肩一人搜衣襟口袋，动作粗暴但清楚，最后双手空空。平涂线稿，无3D质感，不增加第三镜。

### 卡2-3｜反问胡逸民｜1:07—1:20｜13s｜✅

  **画面区域**：滴水声切回牢房。方志敏平静反问：“你我真的想争夺这高官厚禄吗？”随后把问题照回胡逸民为兄弟舍弃一切、自己进入监狱的经历：“胡兄，你不也为了兄弟，舍弃一切进了监狱吗？”胡逸民不立即回应，目光从方志敏脸上缓慢移向烧饼，神情从自然转为沉默。

**动作与镜头**：固定双人中景，回到原坐姿和原空间；方志敏手里仍有烧饼，只在说话时轻微转头看胡逸民；胡逸民开始还能直视，随后目光慢慢下移，表情收住。

  **台词**：方志敏：“你我真的想争夺这高官厚禄吗？”“胡兄，你不也为了兄弟，舍弃一切进了监狱吗？”

**声音**：滴水声渐隐，氛围转静；靠停顿表现动摇，不配温暖钢琴。

**首尾帧**：首帧：滴水声切回双人中景。尾帧：胡逸民目光下移、沉默。

**锁定**：人物不站起、不激动争辩、不拍肩；嘴型只配合对话；镜头固定。

  **AI描述词（直接复制丢进AI视频框）**：
  
  > 16:9 冷灰蓝牢房双人中景，回到原坐姿和原空间。方志敏手里仍有烧饼，语气平静，只在说话时轻微转头看胡逸民，第一句“你我真的想争夺这高官厚禄吗？”；随后继续说第二句“胡兄，你不也为了兄弟，舍弃一切进了监狱吗？”，不挥手、不拍肩、不激动争辩。胡逸民开始还能直视，随后目光从方志敏脸上缓慢移向烧饼，表情收住、沉默动摇。镜头固定，人物不站起、不换位，嘴型只配合对话，靠停顿表现动摇，不配温暖钢琴。

### 卡2-4｜掰饼／人情／文稿伏笔｜1:20—1:27｜7s｜✅

**画面区域**：方志敏把烧饼掰开，将一半递回胡逸民：“先吃，凉了就不好吃了。自有人间真情在，干一个。”两块饼轻轻碰一下。胡逸民目光从饼移向方正在写的文稿，为第三幕埋钩子。

**动作与镜头**：中近景；方志敏缓慢把烧饼掰成两半 → 将一半递给胡逸民 → 两人只用饼轻碰一下，不握手、不拥抱 → 胡逸民接过后先看手里的饼，再自然把目光移到旁边纸张与文稿。

**台词**：方志敏：“先吃，凉了就不好吃了。自有人间真情在，干一个。”

**声音**：掰饼轻响、两块饼相互轻碰；滴水声渐隐，氛围转暖。

**首尾帧**：首帧：方志敏掰饼。尾帧：胡逸民目光落到文稿上，定住。

**锁定**：不握手、不拥抱；情绪温和但克制，动作少；结尾停在胡的视线与纸面。
