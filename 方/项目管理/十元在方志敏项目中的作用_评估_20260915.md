# 十元在方志敏项目中的作用｜收尾评估

> [!question] 名称核对
> 活库和本项目中没有检出“石元”的精确匹配；本评估按“十元”相关文件、角色卡和探索记录整理。如果“石元”不是“十元”的笔误，再单独补充对象，不改动本结论。

## 结论

十元在方志敏项目中不是一个生成器、排队器或验收状态，而是一个**把抽象关系翻译成可观察动作、构图和角色分工的创作筛选器**。它真正改变了第三幕后半段的镜头语法和第五幕的角色/动作约束；它没有证据证明已经完整支配六幕，也不能替代首尾帧、音轨、人工观看和卡级状态。

## 已被证据确认的四种作用

### 1. 探索筛选器：把发散候选排成可判断的视觉方案

`[[方/08_探索/方发散树_编排协议_v0.1]]` 明确规定：十元探索和主生产树分开；流程是“结构拆解 → 发散候选 → 编排 → 可见主树/折叠候选”。

第三幕探索文件不是只贴标签，而是为每组方案写出配比、画面、动作和评分。例如：

- `zx` 方向把“公开权能、压顶、裁决”转成文件、钥匙、坐姿高差、剪影先声；推荐方案为 `zx7 xn4 n3 xz2`。
- `zn` 方向把“托付、承载、不可让渡的意义”转成取稿、递稿、接稿、压住文稿；推荐方案为 `zn7 nx4 n3 xz2`。
- `zx克n` 方向把恶魔举刀、压顶、切开母亲的节奏排成镜头动作，并用评分筛出主方向。

这说明十元最先发挥的是“选方向”的作用，而不是“直接生成”。探索结果保留为候选，进入正式描述词后仍要经过实际素材和人工验收。

### 2. 镜头结构语言：把关系写成动作顺序

第三幕的正式描述词和分镜表已经把关系落实为可观察序列：

`纸卷染红 → 两鬼交错逼近 → 抓住/压迫 → 举刀直刺 → 母亲护胸与受压 → 红潮吞没 → 素描闪帧 → 黑色护胸轮廓收束`。

这里的重点不是“画面上有红黑色”，而是：谁公开施力、谁承载、承载如何被击穿、动作在哪一拍改变。十元因此参与了景别、站位、支撑脚的透视线、动作数量和声音/台词落点。

### 3. 角色动作分工：让同一关系由不同角色承担

`[[方/03_角色卡/日本鬼_胖瘦双鬼]]` 与 `[[方/03_角色卡/中国母亲_n角色]]` 提供了明确限制：

- 胖鬼：`zx` 的沉重版本，负责踩、压、抓取，体型矮壮、动作钝重。
- 瘦鬼：`zx` 的锋利版本，负责举刀、指向、裁决和切开，动作短促利落。
- 中国母亲：承载/接收/护住共同体，核心动作是双臂护胸如抱孩子；受压可以踉跄，但护持关系不能无故消失。
- 6/5/4 头身与体量规则服务于构图中的权力和承载关系，不是装饰性的角色标签。

这样，十元把“侵略/受难”变成了胖鬼压住、瘦鬼切开、母亲仍护住的角色动作系统。

### 4. 制作审核标准：检查结果有没有表达关系

在第五幕候选审查中，十元已经成为复核问题的一部分：

- 构图上是否仍能看出谁压住谁、谁承载谁；
- 动作数量是否符合卡级分镜，是否凭空增加拉扯、挥刀或人物；
- 胖鬼/瘦鬼的体型、职责是否互换；
- 母亲的护胸与抱持关系是否被视频运动破坏；
- 红黑是否服务于“击穿/承载”，而不是只变成泛红滤镜。

所以它影响的是“如何判断一个候选是否表达了镜头意图”，而不是把候选自动升级为正式片。

## 按幕判断作用强度

| 幕 | 证据强度 | 判断 |
|---|---|---|
| 第一幕 | 低 | 有中国母亲角色参考，也出现 n 相关入口，但没有足够正式记录证明十元完整决定三卡的镜头结构。收尾时不补写 retroactive 标签。 |
| 第二幕 | 低 | 主要创作依据是清贫、劝降、人情和连续性；当前正式卡中没有同等强度的十元结构映射证据。 |
| 第三幕 | 高 | `zx/zn/zn克n` 探索、评分、双鬼/母亲角色卡、3-7动作与时序均有直接证据，是十元真正改变成片设计的核心区域。 |
| 第四幕 | 中低 | “四手传稿”和文稿接力与承载/托付相容，但现有记录不能证明每一张第四幕卡都由十元推导。只能说提供了结构解释，不能说是完整生成依据。 |
| 第五幕 | 中高 | 双鬼、母亲、红黑抽象段和 5-2/5-3/5-5 的审查约束明显承接第三幕十元语法；但 A/B方向仍未完全收敛，最终候选尚未全部人工通过。 |
| 第六幕 | 低 | 终局主要由劝降、端茶、黑屏和走廊收束；当前没有足够正式证据把六幕整体归结为十元映射。 |

## 十元的边界

1. 十元探索文件不是生成授权；“推荐方案”不是“已提交任务”。
2. 十元标签不是素材；没有真实首帧、运动参考、音轨和 ffprobe，仍不能进入交付。
3. 十元关系不能覆盖用户最新确认、卡级状态和实际视频；冲突时保留冲突。
4. 收尾阶段不应为了理论完整而给第一、二、四、六幕补造映射；没有证据就写“未证明”。
5. 第五幕的 A/B方向和第六幕 6-3仍需人工决策，十元只能辅助看候选是否表达关系，不能代替决策。

## 收尾时如何保留它

- 把本文件作为方法论与证据索引保留，不把十元字段强行复制进每张卡。
- 在最终验收表中增加一列“关系是否被画面动作表达”，只对明确引用十元的第三幕/第五幕卡使用。
- 其余幕次只记录实际镜头、声音和审核结论；不因项目收尾而扩大理论范围。
