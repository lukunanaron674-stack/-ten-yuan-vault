# 方发散树｜编排协议 v0.1

> 作用：把十元映射发散结果变成“能看、能判断、能继续展开”的树。这里不重新解释十元，也不做题材/世界观仓库抽卡。

## 当前工作流

```text
问题
→ 十元结构拆解
→ 发散候选 RAW TREE
→ 方发散树信息编排 Skill
→ 可见主树 + 折叠候选 + 下一步展开
→ Canvas
→ 人工裁决
```

Skill：`07-Codex大脑库/skills/方发散树信息编排/SKILL.md`

## 发散结果进入 Canvas 前必须先过四关

### 1. 聚类
先按 `changed_variable → relation_shape → module_grammar` 判断哪些候选属于同一组。

### 2. 主次
同屏一级视觉中心最多 3 个；必须有且只有 1 个当前 focus。

### 3. 压缩
同构候选合并显示；低优先候选折叠，但数据保留且可恢复。

### 4. 路径
最多指出 3 条下一步展开方向，每条必须给结构理由。
