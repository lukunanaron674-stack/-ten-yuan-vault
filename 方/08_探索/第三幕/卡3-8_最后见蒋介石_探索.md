# 卡3-8｜最后见蒋介石｜10个分镜探索

> 📌 版本：v2.0｜2026-08-14

## 统一锁定

场景是南昌行营最高级军政办公室。蒋介石坐主位、只露背影或侧后方、正在喝茶；方志敏在桌对面正脸；顾祝同采用指定三视图，站在蒋侧后方沉默压场。三人保持二维老上影平涂、细腻线条、灰橄榄与冷灰蓝色块。蒋不推文件，方不喝茶，顾不抢动作。

| 9.7 | A｜背影三角压场 | 低机位中远景，蒋背影和茶杯占前景，顾祝同站右后方，方志敏正脸在桌对面；镜头2秒缓慢推向方 | 三个人的身份和动作一眼读懂，最稳 |

| 9.1 | C｜顾祝同夹压 | 方志敏正脸居中，前景左右分别是蒋背影和顾半身，形成两道夹压 | 威压最强，但要防止顾抢主位 |
| 8.9 | D｜桌面权力线 | 俯低角度拍长桌，蒋茶杯、顾的皮带与方的正脸处在一条压迫线 | 让办公室和权力秩序更明确 |
| 8.7 | E｜蒋喝茶不看人 | 蒋背对镜头连续两口茶，完全不看方；方正脸说完台词后保持静止 | 表现蒋的冷漠和轻蔑 |
| 8.5 | F｜顾的微转头 | 方正脸回应时，顾祝同只微微转头看他，蒋仍喝茶 | 用最小动作制造“被审视” |
| 8.2 | G｜窗口逆向构图 | 窗光落在方正脸上，蒋背影处在暗部，顾站在窗边暗处 | 方的精神成为画面唯一亮点 |
| 7.9 | H｜茶盖静音 | 方说完后，蒋慢慢盖上茶杯，顾保持站立；茶盖声后落“娘希匹” | 声音节奏强，适合接走廊落黑 |
| 7.6 | I｜声明书只作道具 | 声明书只在桌角出现，不被任何人推动；蒋喝茶，方看一眼后抬头 | 保留性命交易信息，避免动作混乱 |
| 7.2 | J｜远景冷处理 | 大办公室远景，三人都小，蒋背影喝茶、顾侍立、方正脸 | 历史距离感强，但人物情绪较弱 |

## 推荐

优先跑 **A**，其次跑 **B、C、H**。A最适合先验证人物关系；B验证蒋背影喝茶；C验证顾祝同增加威压但不抢戏；H验证“娘希匹”前的声音停顿。
