# 方志敏｜LoRA 五轴风格库

> [!info] 位置说明
> 根级真源在 `风格库/方志敏/`，与 `方/` 同级。本文件留在旧路径，仅作为历史兼容入口；新增候选不再写入此目录。

## 目标

用同一基准场景做可比较的 LoRA 风格探索。每小时只改变一个视觉轴，生成结果进入候选区；本库不自动修改正式风格词、任务卡、Canvas 活动卡或锁定资产。

## 固定基准

- 基准主体：单个中国历史人物，站在带铁栏的窗前，三分之二侧面，深色工作服，表情克制。
- 基准输出：`novaAnimeXL_ilV190.safetensors`、1024×1024、28 steps、CFG 6.5、DPM++ 2M、Karras。
- 固定负面：文字、字母、logo、水印、界面、拼贴、重复物件、畸形、模糊、低细节、过饱和。
- 当前可执行设备：本机 RTX 3070 / ComfyUI `127.0.0.1:8188`。

## 五轴定义

| 轴 | 变量 | 每小时实验内容 |
|---|---|---|
| 1 | 线条/边缘 | 墨线平涂、木刻断边、细霓虹边 |
| 2 | 媒介/材质 | 纸纤维、哑光剪纸层、织物表面 |
| 3 | 色彩/光线 | 冷灰蓝、黑红平面、炉火青影 |
| 4 | 构图/镜头 | 正面轴对称、侧面水平、低机位汇聚 |
| 5 | 场景信息密度 | 稀疏舞台、中等叙事、深层空间 |

## 轮换算法

`线条/边缘 → 媒介/材质 → 色彩/光线 → 构图/镜头 → 场景信息密度` 为一个 LoRA 的五小时小轮换；完成五轴后切换注册表中的下一个 LoRA。全部 LoRA 完成后进入下一组轴值。每次只保留一个本库排队/运行任务，便于比较和回滚。

## 安全闸门

1. ComfyUI 已有运行或排队任务：本轮只记录 `COMFY_BUSY` 并跳过，不抢队列。
2. GPU 温度达到 85°C：本轮只记录 `HOT` 并跳过。
3. 没有实际输出：不得写“已生成”；只保留失败证据。
4. 输出状态固定为“候选/待人工比较”，不自动锁定、交付或写入正式风格资产。
5. 不覆盖旧图；候选副本和运行证据按任务 ID 保存。
