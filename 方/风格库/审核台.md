# 方志敏｜LoRA 风格审核台

这是根级 `风格库/` 的本地审核入口，与 `方/` 同级。它读取已完成的 LoRA 候选，不改正式任务卡，也不自动锁定资产。

## 打开

运行：

`C:\Users\19308\Documents\New project 2\lora_style_library\review_platform\打开审核台.bat`

也可以运行同目录下的 `打开审核台.ps1`。脚本会先把最新候选、证据和 SHA-256 写入审核台数据，再打开页面。

## 审核时能看到什么

- 五轴、LoRA、轴值轮次、生成时间和候选图。
- 底模、LoRA 文件、model/clip 强度、seed、尺寸、Steps、CFG、采样器和 scheduler。
- 完整 Positive / Negative 描述词。
- 描述词拆解：基础场景、实验控制、本轮轴值、LoRA 前缀。
- LoRA 的作用解释、观察重点、来源/许可备注。
- `prompt_id`、`execution_id`、证据文件和候选图 SHA-256。

## 复现办法

打开一张候选，点击“复制复现参数”或“下载复现 JSON”，在当前 ComfyUI 工作流中逐项恢复：

1. 使用相同底模和 LoRA 文件。
2. 输入相同 LoRA model/clip 强度。
3. 粘贴相同 Positive / Negative。
4. 恢复尺寸、Steps、CFG、采样器、scheduler。
5. 使用相同 seed。

复现结果仍是候选。审核台里的“保留候选/淘汰候选”只保存在当前浏览器本地，不等于正式锁定或交付。

如果要直接重跑，使用审核台显示的“一键复现命令”，对应脚本为 `review_platform/复现候选.ps1`。脚本会先检查 ComfyUI 队列和 GPU 温度，再按原任务参数提交，不改正式项目状态。
