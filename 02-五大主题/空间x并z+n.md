# 空间（x并z + n）

## 一、主题层最小定义

空间是对象被放置、容纳、分隔、并存并建立边界的位置结构。

核心问题：

```text
什么能够在哪里存在？
哪些对象可以共处，哪些必须分隔？
边界、位置与容纳条件怎样改变关系和选择？
```

空间主题不等于故事有场景、建筑、房间、城市、迷宫、家或远景构图。

只有当位置、边界、容纳、并存或隔离真正组织人物选择、关系、转折、高潮或结局时，空间才结构性显影。

## 二、十元构成位置

```text
空间：x并z + n
```

这里的 `x并z` 与 `n` 都是十元点位。

该公式是主题生成系统预设的构成位置，不表示具体故事中出现一个包装对象和一个承载对象就自动生成空间主题，也不要求某个角色同时拥有两者。

正式生成机制：

```text
主题系统预设 x并z 与 n
↓
主题生成系统以统一的关系层 z 补合
↓
形成“空间”这一高级主题符号
```

具体案例中的 `x并z` 与 `n` 若同时显影，只在十元层发生互补、生克或并列，不能冒充主题生成过程。

## 三、主题显影证据

### 背景存在

```text
故事发生在特定地点
存在房屋、迷宫、城市、故乡或封闭场所
画面有框架、镜面、门窗或远近层次
角色搬家、旅行或进入新场景
```

这些都不能单独证明空间主题。

### 局部或次主题

空间在某个场景、支线或阶段改变人物可见范围、行动路径、关系距离或局部选择，但不组织整部作品。

### 主主题

至少需要结构性满足：

```text
中心问题围绕位置、边界、容纳、并存或隔离；
关键转折反复改变人物能够进入、停留、离开或共处的条件；
高潮或结局重新决定空间边界、归属或容纳关系；
替换空间结构后，作品核心冲突与关系会根本变化。
```

不得用“有封闭空间”“有家”“有漂亮场景”等关键词计数判定。

## 四、与其他主题的边界

```text
空间：什么能够在哪里存在并如何共处。
时间：这些对象怎样随阶段发生变化。
命运：这些可能最终走向哪里。
因果：什么导致边界或位置发生变化。
本体：进入不同空间后，对象究竟仍是什么。
```

“回家”可能是空间，也可能是命运；“迷宫”可能是空间，也可能只是因果机制或视觉外壳。必须看它是否组织中心结构。

## 五、正式生克位置

### 生

```text
本体 生 空间
空间 生 时间
```

解释层级：

- 对象的根本性质决定它能够建立、进入或承受怎样的空间，因此本体生空间；
- 位置、边界与容纳条件为变化提供展开场域，因此空间生时间。

### 克

```text
因果 克 空间
空间 克 命运
```

解释层级：

- 已形成的后果、责任链或必然代价会压缩、封闭或改写可继续展开的空间，因此因果克空间；
- 固定边界、位置与容纳条件会压缩可能性，使命运难以继续漂移和收束，因此空间克命运。

这些属于主题级关系，不自动等于固定十元对子。

## 六、场景与人物分层红线

空间主题尤其容易被场景外观冒充。

必须拆开：

```text
人物稳定本体
当前状态
关键行为
外部场景
真实空间结构
时间关系 / 时间结构
视觉与光影
十元层生克补
主题级空间关系
```

场景是监狱、教堂、城市、房间或故乡，不代表人物本体就是空间主题，也不代表场景自动属于某个十元。

视觉框架、冷暖光、建筑风格与构图只能提供辅助证据。

## 七、旧内容处理

旧版以下内容全部降级为历史材料：

```text
用“外壳 + 基底”直接定义空间主题；
看到房间、迷宫、家园、城市或构图框架就判空间型；
用 x并z 与 n 的关键词命中数决定主次主题；
把十元互补当作空间主题的案例内生成过程；
旧主题关系图中“空间克因果”等与正式生克盘相反的方向；
未经复验的空间子类型与案例高置信度标定。
```

旧案例与旧子类型可作为素材候选保留，但必须按 [[五大主题显影与判定协议_v1.0_2026-07-16]] 重新验收，不能继续拥有定义权。

## 八、调用模板

```text
主题层：
- 空间是背景、局部、次主题还是主主题？
- 哪些位置、边界或容纳条件真正改变了人物选择？
- 高潮或结局如何重写空间关系？
- 空间是否正在生出时间，或克制命运？

十元层：
- 人物、状态、行为、场景分别是什么十元？
- 十元层发生了什么生、克、补？

稳定锚点：
- 场景变化是否只是外部条件变化？
- 人物核心本体是否仍保持稳定？
```
