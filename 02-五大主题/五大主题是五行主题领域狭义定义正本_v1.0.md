# 五大主题是五行在主题领域的狭义定义｜正本 v1.0

## 0｜本体关系

```text
十元＝五行内部的阴阳两极
五行＝同行十元的对立统一体
五大主题＝五行在主题／叙事领域的狭义定义
```

五大主题不是五行之外的第二套系统，也不是把两个十元临时拼起来以后额外生成的高级符号。

## 1｜固定映射

| 五行广义本体 | 阴阳十元 | 主题领域狭义定义 | 主题核心问题 |
|---|---|---|---|
| 木 | zx↔nx | 因果 | 什么作用导致什么结果，结果从何而来、由谁承担 |
| 火 | zn↔x | 本体 | 对象如何保持自身成立，又如何被归属边界确定为“它是什么” |
| 土 | n↔x并z | 空间 | 对象如何跨越内外边界，被容纳、分隔、呈现与进入 |
| 金 | xn↔z | 时间 | 变化如何分布为阶段流程，又如何由关键节点完成裁定 |
| 水 | xz↔nz | 命运 | 可能性如何收窄为去向，回返、修复或改写是否仍可能 |

因此应直接写：

```text
因果是木的主题领域狭义定义。
本体是火的主题领域狭义定义。
空间是土的主题领域狭义定义。
时间是金的主题领域狭义定义。
命运是水的主题领域狭义定义。
```

## 2｜与五脏类比

```text
生理领域：木肝、火心、土脾、金肺、水肾
主题领域：木因果、火本体、土空间、金时间、水命运
```

肝心脾肺肾不等于五行的全部广义本体，但它们属于五行在生理领域的具体归属。五大主题同理。

## 3｜主题公式

```text
因果＝zx↔nx＝木
本体＝zn↔x＝火
空间＝n↔x并z＝土
时间＝xn↔z＝金
命运＝xz↔nz＝水
```

符号`↔`表示同行阴阳的对立统一。旧`+`若继续出现在历史文件中，只能按“同行两端共同构成一行”读取，不表示案例内共现、补边或额外主题生成关系。

## 4｜生克盘

五大主题生克盘就是五行生克盘在主题领域的狭义显化。

```text
相生：因果→本体→空间→时间→命运→因果
相克：因果克空间、空间克命运、命运克本体、本体克时间、时间克因果
```

静态方向固定。作品中是否真正发生主题生克，仍需明确源主题、目标主题、作用方向、被改变变量、高潮与结局证据。

## 5｜主题显影纪律

五大主题与五行有本体继承关系，但不能因此把任何单个十元动作直接升级为完整主题。

```text
十元端出现
≠ 五行两端已完整显影
≠ 主题已经成为作品主主题
≠ 主题生克已经启动
```

主题显影仍按：

```text
中心问题
+ 跨阶段重复
+ 关键转折
+ 高潮选择
+ 结局答案
```

## 6｜废止口径

停止调用：

- “五大主题≠五行，二者只是碰巧使用相同十元组合”；
- “五大主题由另一套主题生成系统用额外z补合生成”；
- “五组主题公式只是可替换的基准构成，尚不能确认固定映射”。

允许研究的是同一主题内部的分型、体量、显影方式和动态变化，不再研究把其他五行组合替换为该主题的本体身份。
