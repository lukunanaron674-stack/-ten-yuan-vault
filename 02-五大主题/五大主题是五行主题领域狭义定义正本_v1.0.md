# 五大主题是五行在叙事领域的 `is-a狭义`｜正本 v1.1

## 0｜本体层级

```text
十元＝五行内部阴阳操作端
五行＝广义对立统一体
五大主题＝五行进入叙事／主题领域后的狭义子项
```

正式关系：

```text
五大主题 --is-a狭义[domain=叙事]→ 五行
```

五大主题不是与五行互不相关的第二套系统，也不是五行全部广义本体的同义词。它们继承五行，但只覆盖叙事领域中的狭义外延。

## 1｜固定 `is-a狭义` 映射

| 叙事主题子项 | 五行广义父项 | 十元轴 | 核心问题 |
|---|---|---|---|
| 因果 | 木 | `zx ↔ nx` | 什么作用导致什么结果，方向和责任从何而来 |
| 本体 | 火 | `zn ↔ x` | 对象怎样保持自身，又怎样被归属边界确定 |
| 空间 | 土 | `n ↔ x并z` | 对象怎样跨越内外、被容纳、分隔和呈现 |
| 时间 | 金 | `xn ↔ z` | 变化怎样分布为阶段，并由节点完成裁定 |
| 命运 | 水 | `xz ↔ nz` | 可能性怎样收窄为去向，回返是否仍可能 |

标准边：

```text
因果 --is-a狭义[叙事]→ 木
本体 --is-a狭义[叙事]→ 火
空间 --is-a狭义[叙事]→ 土
时间 --is-a狭义[叙事]→ 金
命运 --is-a狭义[叙事]→ 水
```

## 2｜与五脏的同构关系

```text
叙事领域：因果→木，本体→火，空间→土，时间→金，命运→水
生理领域：肝→木，心→火，脾→土，肺→金，肾→水
```

因果与肝不是彼此同义；它们分别是木在不同领域中的狭义子项。

## 3｜继承内容

五大主题从五行继承：

- 对应阴阳十元轴；
- 广义核心变量；
- 五行相生相克位置；
- 对立统一方向。

五大主题另外增加：

- 叙事中心问题；
- 跨阶段显影；
- 转折、高潮和结局证据；
- 主题分型、体量和主次。

## 4｜主题生克

主题生克是五行生克在叙事领域的狭义表达：

```text
相生：因果→本体→空间→时间→命运→因果
相克：因果克空间、空间克命运、命运克本体、本体克时间、时间克因果
```

具体作品中是否启动生克，仍需明确源主题、目标主题、方向、被改变变量和结局证据。

## 5｜主题显影纪律

```text
出现一个十元端
≠ 五行轴完整显影
≠ 叙事主题成为主主题
≠ 主题生克已经发生
```

作品中的具体主题结构属于 `instance-of`：

```text
某作品中的因果结构 --instance-of→ 因果
因果 --is-a狭义[叙事]→ 木
```

两种边不得混写。

```yaml
  命运: {parent: 水, poles: [xz, nz]}
```

## 7｜废止口径

- 废止“五大主题与五行是互不相关的两套系统”；
- 废止“相同十元点位只是碰巧对照”；
- 废止“因果完全等于木的全部广义外延”；
- 废止不记录领域与父项的模糊映射。
