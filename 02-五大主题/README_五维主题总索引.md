### 固定分工
- 五维：这个故事究竟研究什么主题问题。
- 十元：问题内部有哪些力量、它们是什么性质。
- 动态链：这些力量如何连续作用、反作用、收敛、回写。

推荐顺序：
`五维问题 → 主题实验 → 人物困境 → 十元力量映射 → 动态链运行 → 事件/意义/可能性/机会四链审核`

禁止：
- 不直接拿十元符号硬生成主题。
- 不因某个电影有“时间旅行 / 监狱 / 预言 / 失忆”就直接判定主题。
- 不用研究层结论覆盖 canonical。

## P2｜电影主题研究
- [[电影主题研究/README|电影主题研究入口]]
- [[电影主题研究/五维主题研究总纲_v1.1|五维主题研究总纲 v1.1]]

电影研究用于回答：
1. 影片真正提出了什么主题问题；
2. 角色如何被该维度推动；
3. 冲突通过什么机制发生；
4. 结局如何回答 / 保留问题；
5. 哪些结构可复用于创作；
6. 哪些结论只是研究候选，尚不能升级正本。

## Agent 调用门禁
- 主题 Agent 默认先读本索引，再按任务读取具体文件。
- P0 与 P2 冲突时，以 P0 为准；P2 标记为 `RESEARCH_CONFLICT`。
- 项目创作时，主题 Agent 只输出“主题问题 / 主题实验 / 维度压力 / 结局回答方式”，不替剧本 Agent 写完整剧情。
- 主题 Agent 若要调用十元，只能提出接口需求，交十元 Agent 复核。
- 新电影研究先进入研究层，不自动写回 canonical。
