# 时间 (xn + z)

## 一、定義深化

時間是 **序列與流動的統一**——探討「什麼時候」。

它不問「為什麼」（因果）、不問「是什麼」（本體）。時間只問一件事：**過去-現在-未來如何連接？**

時間的底層張力來自兩股力量的交響：
- **xn（陽金·秩序）**：規則、制度、時間秩序、流程——線性的過去-現在-未來序列
- **z（陰火·執念）**：執念、光點、爆點、被看見——層疊的節奏與週期中的爆點

xn 是「時鐘的指針」，z 是「時鐘上的刻度」。時間既是不可逆的箭頭，也是循環的節拍。

---

## 二、雙元互動機制

### xn（陽金）→ 秩序力
```
核心屬性：規則、制度、時間秩序、流程、線性
動能方向：單向推進，建立時間框架
表現：年齡增長、歷史進程、制度週期、命運的時鐘
```
xn 像一條直線——從過去延伸到未來，不可逆轉。它提供時間的「骨架」。

### z（陰火）→ 爆點力
```
核心屬性：執念、光點、爆點、被看見
動能方向：在時間線上創造結點和高潮
表現：關鍵時刻、無法忘記的瞬間、執念的爆發
```
z 像直線上的結——某些時刻比其他時刻更重要。它提供時間的「血肉」。

### 互動張力
```
xn ──序列──→ ──時間線── ←──爆點── z
   │                      │
   結構性時間            事件性時間
   │                      │
   └─── 時間體驗 ────────┘
```

時間敘事的三種模式：
1. **xn 主導**：線性時間敘事，按時間順序展開（如《星際穿越》的任務時間線）
2. **z 主導**：時間被爆點打碎，執念定義時間（如《記憶碎片》的碎片時間）
3. **xn+z 平衡**：時間既有結構又有爆點（如《超時空輝夜姬》的時代跳躍）

## 三、領域映射

### 電影領域

| 層次 | xn 表現 | z 表現 | 經典案例 |
|------|---------|---------|---------|
| 劇情結構 | 線性敘事、年表結構、時間跳躍 | 非線性剪輯、倒敘、關鍵瞬間重複 | 《星際穿越》《恐怖郵輪》 |
| 角色弧線 | 角色隨時間成長/衰老 | 角色被困在某個瞬間 | 《少年時代》12年拍攝 |
| 視聽語言 | 長鏡頭、時間標記（字幕/時鐘） | 閃回、時間凍結、慢動作高潮 | 《時間的風景》延時攝影 |
| 情感基調 | 流逝感、滄桑、成長 | 遺憾、執念、來不及 | 《超時空輝夜姬》 |

### 角色原型

| 角色類型 | xn 驅動 | z 驅動 | 範例 |
|---------|---------|---------|------|
| 時間旅行者 | 穿越時間線、改變過去/未來 | 對某個瞬間的執念驅使穿越 | 《明日邊緣》比爾·凱奇 |
| 等待者 | 在時間中等待 | 等待的那個瞬間就是一切 | 《霍爾的移動城堡》索菲 |
| 被困者 | 時間循環、無法前進 | 試圖逃離循環的執念 | 《恐怖郵輪》《一日囚》 |
| 老者/智者 | 經歷了足夠的時間 | 對某個遺憾念念不忘 | 《大魚》愛德華·布魯姆 |

### 現實領域映射

| 現實場景 | xn 感 | z 感 |
|---------|-------|------|
| 年齡 | 按年紀長大、衰老、世代更替 | 永遠記得的某個生日/畢業典禮 |
| 職業 | 職業生涯規劃、工齡、晉升週期 | 某個項目的deadline、決定性瞬間 |
| 社會 | 歷史進程、朝代更替、制度變遷 | 歷史轉折點、革命瞬間 |
| 心理 | 時間焦慮、衰老恐懼 | 創傷記憶、美好回憶的定格 |

### 時間特徵判別清單

☐ 時間是故事的核心結構而非背景
☐ 存在明確的時間規則或限制（xn）
☐ 角色被某個瞬間/執念驅動（z）
☐ 非線性敘事或時間跳躍
☐ 時間有「流逝感」或「循環感」
☐ 結局與時間直接相關（時間到了/時間不夠了）

> 命中 4 項以上 → 時間型為主
> 命中 2-3 項 → 時間為輔助主題
> 命中 1 項以下 → 非時間型

## 五、判定指南

### 與其他主題的區分

| 易混淆主題 | 時間 vs 該主題 | 關鍵問句 |
|-----------|---------------|---------|
| 因果 (zx+nx) | 時間關心「先後」，因果關心「為什麼先後」。時間是框架，因果是邏輯。 | 時間是用來建立框架還是用來推導因果？ |
| 命運 (xz+nz) | 時間關心進程，命運關心歸宿。時間可以沒有命運感。 | 時間感重要還是歸宿感重要？ |
| 本體 (zn+x) | 時間是動態的，本體是靜態的。時間改變事物，本體揭示事物。 | 角色是在時間中變化還是在揭示不變的本質？ |

### 常見誤判

- ❌ 把有時序的作品全判為時間型 → 所有故事都有時間，關鍵是時間是否為結構核心
- ❌ 把時間旅行全判為時間型 → 時間旅行也可以是因果故事（如《蝴蝶效應》是因果型）
- ❌ 把回憶殺當時間主題 → 回憶可以是本體揭示而非時間結構
- ❌ 忽略 xn+z 中 z(執念)的作用 → 沒有 z 的時間只是時鐘，不是故事

## 六、生補克關係

### 時間在五大主題中的位置

```
           命運 (xz+nz)
              │
              │ 生 (時間推導出命運感)
              ▼
   因果 ◄─── 時間 ────► 空間
   (zx+nx)   │    (x並z+n)
              │ 克 (時間消解空間的靜止)
              ▼
            本體 (zn+x)
```

- **被生於**：命運 (xz+nz) → 命運的歸宿感需要時間展開
- **生向**：因果 (zx+nx) → 時間讓因果鏈得以展開
- **克**：空間 (x並z+n) → 時間的流逝打破空間的恆定
- **被克**：本體 (zn+x) → 本體的永恆性否定時間的變化

### 生補克細節（十元層）
- xn → 生 → xz（規則限制催生危機感）
- z → 生 → nz（執念最終轉為柔情）
- xn → 靈魂對子 ← z（規則需要執念來定義臨界點）
- xn → 克 → zx（制度限制突破行動）
- z → 克 → nx（偏執燒毀暗算）
