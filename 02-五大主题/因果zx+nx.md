# 因果 (zx + nx)

> **2026-07-16正文革新：zx+nx的主题公式暂保留，但旧“nx=隐性判断、暗流、算计、账本、结算”正文全部作废。暗中观察、判断、计划、记录与等待结算属于xn检查；当前nx只表示不主动占据选择、方向和位置，顺着已有安排继续。本页涉及nx的主题血肉正在二审，不能再用旧案例反推nx。**

## 一、定義深化

因果是 **動力與邏輯的鏈條**——探討「為什麼」。

它不問「走向何方」（命運）、不問「是什麼」（本體）。因果只問一件事：**什麼導致了什麼？**

因果主题的位置公式暂时仍是zx+nx，但两者必须独立判定：
- **zx（阳木·破局）**：主动行动、突破、开局、先动手——推动一条路径从原因走向结果。
- **nx（阴金·不主动占位）**：不主动改写选择、方向和位置，顺着已经落到自己身上的关系、流程或环境继续。

目前只确认zx的路径推进内容。nx在因果主题中究竟怎样形成独立贡献，必须重新从案例里显影；不能再用“看不见的因果链、隐藏逻辑或结算”直接补上。

## 二、雙元互動機制

### zx（陽木）→ 破局力
```
核心屬性：主動行動、突破、開局、先動手
動能方向：由因到果的顯性推導
表現：角色的主動選擇引發連鎖反應
```
zx 像多米諾的第一塊骨牌——一旦倒下，後續的因果鏈就不可逆轉。

### nx（阴金）→ 顺势延续（主题贡献待二审）
```
核心属性：不主动占据选择、方向和位置
动作姿态：已有关系、流程或环境落到这里，于是继续
禁止误判：隐藏动机、逆向解码、算计、账本和结算均不能证明nx
```
nx不是“水下冰山”或“精密计算的暗流”。这些都带主动判断，优先检查xn。当前只能确认nx的非主动占位与既有路径延续，其因果主题功能待案例二审。

### 互動張力
旧“zx显性行动 + nx隐性解码 = 因果闭环”图已经撤销。

当前二审顺序：
1. 先独立判断是否存在zx的主动路径推进。
2. 再检查人物是否在不主动重选方向的情况下，沿既有关系、流程或环境继续；只有这一点可能支持nx。
3. 若证据是布局、隐情、计算、伏笔回收或结算，改查xn，不得补成nx。
4. zx与nx均有独立证据后，才讨论因果主题是否成立。

## 三、领域映射（二审状态）

旧电影、角色和现实领域表把非线性剪辑、隐藏动机、办公室政治、取证、布局和利益计算统一归给nx，已经整体失效。这些项目大多涉及主动判断与结构安排，应先检查xn；只有“并未主动选择新方向，只沿已经形成的关系或流程继续”才可作为nx候选。

## 五、判定指南

### 與其他主題的區分

| 易混淆主題 | 因果 vs 該主題 | 關鍵問句 |
|-----------|---------------|---------|
| 命運 (xz+nz) | 因果有明確鏈條，命運接受隨機巧合。因果可追溯，命運不可逃。 | 你能追溯每一步的因果嗎？還是只能接受「就是這樣」？ |
| 時間 (xn+z) | 因果關心邏輯鏈，時間關心先後序。因果可以倒敘，時間不可逆。 | 核心是「因果邏輯」還是「時間流逝」？ |
| 本體 (zn+x) | 因果關心「為什麼這樣」，本體關心「這是什麼」。因果是動態，本體是靜態。 | 故事在解釋「為什麼」還是在揭示「本質」？ |

### 常見誤判

- ❌ 把有因果關係的作品都判為因果型 → 所有故事都有因果，關鍵是因果是否為核心結構
- ❌ 把反转、隐藏动机或结算当作nx → 这些先查xn；不能用它们凑出因果公式
- ❌ 把懸疑片全判為因果 → 懸疑也可以來自時間（如《記憶碎片》）或空間（如《心慌方》）

## 六、生補克關係

### 因果在五大主題中的位置

```
           時間 (xn+z)
              │
              │ 生 (時間積累因果)
              ▼
   命運 ◄─── 因果 ────► 空間
   (xz+nz)   │    (x並z+n)
              │ 克 (因果穿透空間的偽裝)
              ▼
            本體 (zn+x)
```

- **被生於**：時間 (xn+z) → 時間的流動讓因果得以展開
- **生向**：命運 (xz+nz) → 因果鏈條累積成命運感
- **克**：本體 (zn+x) → 因果邏輯消解本體的永恆性
- **被克**：空間 (x並z+n) → 空間的靜止打破因果的鏈條

### 生補克細節（十元層）
- zx → 生 → zn（行動創造意義）
- nx → 生 → x（位置保留，旧“暗流积累为深欲”解释作废，待二审）
- zx ↔ 灵魂对子 ↔ nx（位置保留，旧“破局需要风控结算”解释作废，待二审）
- zx → 被克 ← xn（制度限制突破）
- nx → 被克 ← z（当前确认：z持续显现、决定并占位；nx不主动抢回选择权，位置逐步后退，极端结果是“把自己让没”）
