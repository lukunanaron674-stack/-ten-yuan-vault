# 因果 (zx + nx)

## 一、定義深化

因果是 **動力與邏輯的鏈條**——探討「為什麼」。

它不問「走向何方」（命運）、不問「是什麼」（本體）。因果只問一件事：**什麼導致了什麼？**

因果的底層張力來自兩股力量的交織：
- **zx（陽木·破局）**：主動行動、突破、開局、先動手——原因→結果的推導方向
- **nx（陰金·暗流）**：隱性判斷、暗流、結算、算計——結果的多樣性與隱藏邏輯

zx 是「看得見的因果鏈」，nx 是「看不見的因果鏈」。因果故事永遠是表層行動與深層邏輯的雙線博弈。

---

## 二、雙元互動機制

### zx（陽木）→ 破局力
```
核心屬性：主動行動、突破、開局、先動手
動能方向：由因到果的顯性推導
表現：角色的主動選擇引發連鎖反應
```
zx 像多米諾的第一塊骨牌——一旦倒下，後續的因果鏈就不可逆轉。

### nx（陰金）→ 暗流力
```
核心屬性：隱性判斷、暗流、結算、算計
動能方向：由果溯因的逆向解碼
表現：隱藏的動機、未說出口的算計、命運的賬本
```
nx 像水下的冰山——看不見但決定一切。它不是 xz（臨界漂流）那種隨機感，而是**精密計算的暗流**。

### 互動張力
```
zx ──行動──→ ──因果鏈── ←──解碼── nx
   │                      │
   顯性因果              隱性邏輯
   │                      │
   └─── 因果閉環 ────────┘
```

經典因果敘事結構：
1. **zx 起手**：一個行動打破平衡（如《低俗小說》的開場搶劫）
2. **nx 介入**：背後另有隱情（如《低俗小說》的多線暗流交匯）
3. **因果閉環**：表層因果與深層因果交匯，形成震撼的「結算時刻」

## 三、領域映射

### 電影領域

| 層次 | zx 表現 | nx 表現 | 經典案例 |
|------|---------|---------|---------|
| 劇情結構 | 因果鏈敘事、線性因果、蝴蝶效應 | 非線性剪輯、隱藏動機、反轉 | 《蝴蝶效應》《低俗小說》|
| 角色弧線 | 角色的主動選擇引發後果 | 角色的秘密動機逐漸浮現 | 《無間道》梁朝偉的臥底 |
| 視聽語言 | 連貫剪輯、因果蒙太奇 | 跳剪、碎剪、暗示性的鏡頭並置 | 《教父》受洗+刺殺穿插 |
| 情感基調 | 緊張、預期、懸念 | 恍然大悟、震撼、悔恨 | 《老男孩》的終極真相 |

### 角色原型

| 角色類型 | zx 驅動 | nx 驅動 | 範例 |
|---------|---------|---------|------|
| 復仇者 | 主動行動、追兇 | 背後另有陰謀 | 《老男孩》吳大秀 |
| 偵探/解碼者 | (被動)接收案件 | 解密隱藏因果鏈 | 《降臨》露易絲 |
| 棋手/操盤手 | 布局、設局 | 計算每一步的隱藏後果 | 《紙牌屋》法蘭克·安德伍德 |
| 宿命反抗者 | 試圖打破因果 | 發現因果不可逃 | 《星際穿越》庫珀 |

|---------|-------|-------|

## 四、案例庫

### 庫內已標定案例

**因果型（高置信度）：**
- [[低俗小說-結構分析]] — zx(多個角色的因果行動) + nx(暗線交匯的結算)
- [[蝴蝶效應-結構分析]] — zx(每一次回到過去改變) + nx(不可逃的因果反噬)
- [[落水狗-結構分析]] — zx(搶劫行動) + nx(誰是臥底的暗流)
- [[老男孩-結構分析]] — zx(復仇行動) + nx(終極真相的隱藏因果)
- [[無間道-結構分析]] — zx(臥底行動) + nx(雙方暗線)
- [[降臨-鈞入庫]] — zx(語言學習的因果) + nx(非線性因果認知)
- [[萬湖會議-結構分析]] — zx(會議的決策) + nx(官僚系統的暗流)

**待確認：**
- [[刺客聶隱娘-結構分析]] — 因果為輔，本體為主
- [[布達佩斯大飯店-結構分析]] — 因果嵌套在空間中

### 因果特徵判別清單

☐ 故事的核心驅動是「為什麼」和「然後呢」
☐ 存在明確的因果鏈（zx）
☐ 有隱藏的動機或秘密在逐步揭示（nx）
☐ 角色的行動有明確的後果
☐ 結局帶有「結算感」——所有伏筆在此收束
☐ 通過反轉/揭曉推動高潮

> 命中 4 項以上 → 因果型為主
> 命中 2-3 項 → 因果為輔助主題
> 命中 1 項以下 → 非因果型

## 五、判定指南

### 與其他主題的區分

| 易混淆主題 | 因果 vs 該主題 | 關鍵問句 |
|-----------|---------------|---------|
| 命運 (xz+nz) | 因果有明確鏈條，命運接受隨機巧合。因果可追溯，命運不可逃。 | 你能追溯每一步的因果嗎？還是只能接受「就是這樣」？ |
| 時間 (xn+z) | 因果關心邏輯鏈，時間關心先後序。因果可以倒敘，時間不可逆。 | 核心是「因果邏輯」還是「時間流逝」？ |
| 本體 (zn+x) | 因果關心「為什麼這樣」，本體關心「這是什麼」。因果是動態，本體是靜態。 | 故事在解釋「為什麼」還是在揭示「本質」？ |

### 常見誤判

- ❌ 把有因果關係的作品都判為因果型 → 所有故事都有因果，關鍵是因果是否為核心結構
- ❌ 把反轉當因果的全部 → 反轉只是 nx 的一種表現
- ❌ 把懸疑片全判為因果 → 懸疑也可以來自時間（如《記憶碎片》）或空間（如《心慌方》）

## 六、生補克關係

### 因果在五大主題中的位置

```
           時間 (xn+z)
              │
              │ 生 (時間積累因果)
              ▼
   命運 ◄─── 因果 ────► 空間
   (xz+nz)   │    (x並z+n)
              │ 克 (因果穿透空間的偽裝)
              ▼
            本體 (zn+x)
```

- **被生於**：時間 (xn+z) → 時間的流動讓因果得以展開
- **生向**：命運 (xz+nz) → 因果鏈條累積成命運感
- **克**：本體 (zn+x) → 因果邏輯消解本體的永恆性
- **被克**：空間 (x並z+n) → 空間的靜止打破因果的鏈條

### 生補克細節（十元層）
- zx → 生 → zn（行動創造意義）
- nx → 生 → x（暗流積累為深慾）
- zx → 靈魂對子 ← nx（破局需要風控結算）
- zx → 被克 ← xn（制度限制突破）
- nx → 被克 ← z（偏執燒毀暗算）
