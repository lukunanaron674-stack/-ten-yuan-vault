# 因果（zx + nx）

## 一、主题层最小定义

因果是前因经过作用链产生后果，并使结果具有来源、责任与可追溯性的联系结构。

核心问题：

```text
什么导致了什么？
结果从哪里来？
谁或什么必须承担这个结果？
```

因果主题不等于故事里存在事件先后，也不等于有反转、伏笔、调查、真相、报应、算计或结算。

所有故事都存在某种因果，但只有当“原因怎样转化为结果”真正组织中心冲突、关键选择、转折、高潮或结局时，因果才结构性显影。

## 二、十元构成位置

```text
因果：zx + nx
```

这里的 `zx` 与 `nx` 都是十元点位。

该公式是主题生成系统预设的构成位置，不要求具体案例先证明一个 `zx` 人物与一个 `nx` 人物共同出现，也不要求解释“当前 nx 怎样贡献因果”，才能允许因果主题成立。

正式生成机制：

```text
主题系统预设 zx 与 nx
↓
主题生成系统以统一的关系层 z 补合
↓
形成“因果”这一高级主题符号
```

具体案例中的 `zx` 与 `nx` 若同时显影，只在十元层发生互补、生克或并列，不能冒充主题生成过程。

当前 `nx` 仍按现行十元定义独立判断：不主动占据选择、方向和位置，沿已有安排、关系、流程或环境继续。隐藏动机、暗线、算计、账本、调查和等待结算不能证明 `nx`。

## 三、主题显影证据

### 背景存在

```text
角色做事产生结果
剧情有前后逻辑
故事出现调查、反转、真相或报应
结局回收伏笔
```

这些只能证明因果媒介存在，不能单独证明因果是主题。

### 局部或次主题

某段剧情集中追溯原因、责任或后果，或因果链持续推动主主题，但作品最终问题不在因果本身。

### 主主题

至少需要结构性满足：

```text
中心问题围绕原因、后果、责任或可追溯性；
关键转折反复重写“什么导致了什么”；
人物重大选择持续制造或承担后果；
高潮或结局揭示、确认、反转或封闭核心因果链；
替换这条因果结构后，作品核心冲突会根本变化。
```

不得用反转数量、伏笔数量或十元关键词命中数量判定。

## 四、与其他主题的边界

```text
因果：什么导致了什么。
时间：这些作用怎样经过阶段和积累展开。
命运：多种结果最终收束到哪里。
本体：因果揭示对象究竟是什么。
空间：后果如何压缩或改写对象可存在的边界。
```

“发生在之前”不等于原因；“最后如此”不等于命运；“查出真相”也可能主要属于本体或时间。

## 五、正式生克位置

### 生

```text
命运 生 因果
因果 生 本体
```

解释层级：

- 命运的收束使原本分散的可能性形成必须追问的来源、责任与结果链，因此命运生因果；
- 因果链揭示对象如何形成、为何如此及其必须承担什么，从而使本质可见，因此因果生本体。

### 克

```text
时间 克 因果
因果 克 空间
```

解释层级：

- 时间的流逝、累积、断裂或阶段变化能够冲淡、截断或改写原有因果链，因此时间克因果；
- 已形成的结果、责任与必然后果会压缩、封闭或改写可继续容纳和展开的空间，因此因果克空间。

```text
Legacy：n 补克 nx
Current：因果克制空间
```

旧表达停止作为现行十元关系或动态链结论使用。

## 六、对象分层红线

分析因果主题时必须拆开：

```text
人物稳定本体
当前状态
关键行为
行为造成的具体后果
外部场景
时间关系 / 时间结构
视觉与光影
十元层生克补
主题级因果关系
```

人物执行某个计划，不足以证明人物本体是 `xn`；人物顺着安排继续，也不能单独证明作品是因果主题。

主题级“因果克空间”不能倒推出某个固定十元克制另一个固定十元。

## 七、旧内容处理

旧版以下内容全部降级为历史材料：

```text
用“显性行动 + 隐性算计”定义因果主题；
把暗线、调查、反转、真相、账本或结算归给 nx；
要求 zx 与 nx 在案例内同时成立后才允许判因果主题；
用十元关键词命中数量判断因果型；
旧主题关系图中与正式生克盘不一致的方向；
把旧高置信案例继续当作 nx 或因果公式的证明。
```

旧案例可作为待复验素材保留，但必须分别重新判断主题显影与十元对象层，不能用旧解释反推 `nx`。

## 八、调用模板

```text
主题层：
- 因果是背景、局部、次主题还是主主题？
- 核心原因、结果与责任链是什么？
- 高潮或结局怎样封闭或改写这条链？
- 因果是否正在生出本体，或克制空间？

十元层：
- 哪个具体人物、状态、行为、场景或时间结构承载了什么十元？
- 十元之间发生了什么生、克、补？

稳定锚点：
- 人物核心本体是否稳定？
- 变化是否主要落在状态、后果、关系和动态链？
```
