# 五维电影研究 R40｜制度如何把概率变成个人命运？

> 状态：研究层增量，不覆盖 canonical 正本。
> 承接 R39：R39 已拆出 Access / Permission / Possession，并证明空间可经 Resource Gradient 直接改变 Actionability 与 P_reachable。本轮不再研究“位置不同所以结果不同”，而研究更窄的问题：当制度根据预测、统计或分类提前分配机会时，概率如何被制造成命运。

## ①《千钧一发》 Gattaca (1997)

**核心五维：命运 × 本体 × 因果**

### 剧情设定
社会依据基因检测预测疾病、寿命和能力，并据此分配工作与社会位置。Vincent 的基因被判定为“劣等”，于是借用 Jerome 的基因身份进入 Gattaca。

### 真正的主题问题
预测一个人更可能成为什么，是否有权提前决定他可以尝试成为什么？当概率被制度当作事实使用时，命运究竟来自身体，还是来自对身体的解释？

### 具体剧情机制
基因并没有直接物理阻止 Vincent 成为宇航员。真正关闭路径的是机构把统计预测转化为筛选规则：Prediction → Classification → Permission → Opportunity。于是“未来风险”被提前兑换成“当前禁止”。

### 可复用结构【概率固化】
```text
Predictive Evidence
→ Risk Score
→ Category
→ Permission差异
→ Opportunity差异
→ Experience差异
→ Outcome逐渐接近预测
```

这里出现自我实现：预测并非单纯发现命运，而会参与制造它。

## ②《少数派报告》 Minority Report (2002)

**核心五维：因果 × 命运 × 时间**

### 剧情设定
PreCrime 根据先知对未来谋杀的预见，在犯罪发生前逮捕未来凶手；Anderton 自己也被预测将杀人。

### 真正的主题问题
一个尚未发生的结果，能不能倒过来成为现在惩罚你的原因？如果制度根据未来行动先采取行动，它是否反而参与制造那个未来？

### 具体剧情机制
通常因果顺序是 Action → Responsibility → Punishment；PreCrime 把顺序倒置成 Prediction(Action) → Punishment。于是“未来可能发生什么”获得了和“已经做过什么”类似的制度权重。

### 可复用结构【未来证据化】
```text
Future Prediction F
→ F 被制度当作 Evidence
→ 当前 Permission / Freedom下降
→ 人物为逃避 F 被迫行动
→ 新行动反过来提高 F 的可实现性
```

这不是普通时间旅行悖论，而是“预测本身进入因果链”。

## 维度关系提炼

### 命运 → 因果：预测可成为新原因
命运信息一旦被 Carrier（机构、算法、法律、宗教）执行，就不再只是描述未来：

```text
Prediction
→ Institutional Action
→ Environment Change
→ Character Action
→ Outcome
```

因此需要区分：
- Descriptive Prediction：只描述概率；
- Performative Prediction：预测被执行后改变世界，使结果概率发生变化。

### 本体 → 命运：分类是重要中介
```text
Evidence
→ Category
→ Identity Recognition
→ Permission
→ P_reachable
```

“你是什么人”一旦成为制度分类，就能直接控制“你可以去哪里”。这不是本体天然决定命运，而是 Category 被制度接入 Permission。

### 时间 → 因果：未来信息可以前置进入当前因果
R34 已拆 Foreknowledge ≠ Fate。本轮补充：Foreknowledge 本身不是 Fate，但 Foreknowledge 被 Authority 执行后，可以成为 Fate-producing Cause。

# 可复用故事母题

## 1｜概率固化
系统预测人物失败，于是提前剥夺训练、资源与机会，最后人物真的失败；问题变成预测究竟是准确，还是成功制造了自己的准确。

## 2｜未来罪
人物因为尚未发生的行为被处罚，而逃避处罚的行动反而逐步生成那个行为。

## 3｜分类越狱
人物不直接改变能力，而是攻击“能力→分类→许可”的转换规则，让同一事实不再自动产生同一种命运。

# ⑤ 三条一句话故事种子

1. 一座城市给每个孩子出生时计算“犯罪概率”，一个被判定为92%的女孩终生被警察跟随，直到她发现城市全部重罪都来自那批被重点监控的人。
2. 王国的神谕只公布“谁会成为暴君”，从不公布原因；一个温和王子被预言后遭到所有人背叛，而每一次背叛都让他更接近预言中的那个人。
3. 一家公司能预测员工十年后的最高职位，一个清洁工得到“董事长”的结果，却发现公司为了维持预测准确率，开始秘密替他清除所有竞争者。

# ⑥ 本轮新增 / 修正结论

## A｜新增：Prediction ≠ Fate，但 Prediction + Enforcement 可以制造 Fate
```text
Prediction
≠ Fate

Prediction
+ Authority
+ Enforcement
→ P_reachable改变
→ Fate-producing mechanism
```

## B｜新增：命运可以由“概率→许可”的转换产生
角色未必被物理墙壁困住。只要某个概率判断能够改变 Permission，它就已经开始改变命运结构。

## C｜新增候选机制：Performative Prediction｜施行性预测
定义：预测结果被某个 Carrier 执行后，反过来改变被预测对象的环境与行动，使预测本身成为结果的原因之一。

暂不升一级字段，优先作为 `Prediction + Carrier + Permission + Feedback` 的组合链。

## D｜修正“自我实现预言”
不能只写成心理效应。至少拆两型：
- Internal Self-Fulfillment：人物相信预测后改变自身行动；
- Institutional Self-Fulfillment：制度相信预测后改变资源、许可、监控和空间分配。

后者即使人物完全不相信预测，也能生效。

## E｜对动态链的吸收
遇到预言、算法评分、血统、阶级标签、天赋检测时，不直接标“命运”。先检查：
```text
谁预测？
→ 谁相信？
→ 谁拥有执行权？
→ 改变了哪个 Permission / Resource / Actionability？
→ P_reachable 是否真的收窄？
→ 结果是被发现，还是被部分制造？
```

这使“命运”从抽象不可抗力进一步变成可定位的执行链。
