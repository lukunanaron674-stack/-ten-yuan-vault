# 五维电影研究 R47｜如果未来只剩一个位置，现在的选择还算自由吗？

> 状态：研究层增量，不覆盖 canonical 正本。
> 去重：承接 R39 的 `Access / Permission / Possession`、R40 的 `Prediction + Enforcement`，本轮不再研究“能不能进入”或“预测如何制造命运”，而研究更窄的一条：**制度先固定终局位置，再允许人物在过程里自由行动时，这种自由还剩多少？**

## ①《龙虾》 The Lobster (2015)

**核心五维：命运 × 本体 × 时间**

### 主题问题
当制度只承认少数合法身份终点时，人物在终点之间的选择还是自由，还是被迫选择一种可被承认的本体？

### 具体剧情机制
人物拥有局部行动自由，但时间期限与身份制度共同把未来压成少数合法出口。真正推动角色的不是“奇怪规则”这一设定，而是：每拖延一天，保持未分类状态的成本都提高；为了获得继续存在的许可，人物开始主动把自己压进可识别身份。

### 可复用结构【终局槽位】
```text
多个现实中的自我可能
→ 制度只承认有限 Role Slots
→ Time.horizon 持续下降
→ 未归类成本上升
→ 人物主动寻找可被承认的匹配特征
→ Internal Identity 向合法槽位变形
→ 选择仍存在，但选择集合已被预先设计
```

## ②《楚门的世界》 The Truman Show (1998)

**核心五维：空间 × 命运 × 本体**

### 主题问题
如果一个人可以在世界内部自由选择，但世界本身替他删掉了所有真正不同的未来，那么“自由选择”是否成立？

### 具体剧情机制
控制并不需要每一步命令 Truman。系统只要控制空间边界、信息入口、恐惧与社会反馈，就能让大量局部选择最终重新汇入同一个生活轨道。角色的自由不是被直接删除，而是被“可想象未来”和“可抵达未来”双重收窄。

### 可复用结构【自由回流】
```text
局部选择很多
→ Space / Information 控制 P_visible
→ Fear / Recognition 控制 P_conceivable
→ Boundary 控制 P_reachable
→ 不同选择反复回流到同一终局
→ 人物第一次真正自由的动作不是选A/B，而是攻击边界本身
```

## ③《别让我走》 Never Let Me Go (2010)

**核心五维：命运 × 时间 × 本体**

### 主题问题
当终局从出生起就被制度固定，知道自己拥有感情、关系和个体性，是否足以生成另一种命运？

### 具体剧情机制
人物拥有丰富的内部生活，但制度没有为这些差异提供可转译成命运变化的接口。爱、艺术、自我理解都能改变本体经验，却不自动改变 Permission 与终局。冲突因此不是“他们有没有灵魂”，而是“本体差异能否获得改变去向的制度效力”。

### 可复用结构【无效本体】
```text
人物形成独特 Identity
→ 关系 / 记忆 / 创作证明差异
→ 期待差异应换来 Fate Difference
→ 制度拒绝 Identity → Permission 的转换
→ 个体差异真实存在
→ 终局仍保持同构
```

# ④ 可复用结构总提炼

## A｜Role-Slot Fate｜槽位型命运
命运不一定是“只剩一条路”。还可以是：世界预先规定有限终局类别，人物只能争夺、匹配或被分配到这些槽位。

```text
Future Roles fixed
→ Classification pressure
→ Identity adaptation
→ Permission allocation
→ Fate convergence
```

## B｜Local Freedom / Global Closure｜局部自由—全局封闭
```text
Action options ↑
但 System Exit = 0
且 Outcome Classes 不变
→ 局部自由很高
→ 全局命运仍封闭
```

这进一步修正“Option Quantity ≠ Freedom”：需要同时检查 **选项数量、终局类别数量、系统退出可能**。

## C｜Identity Efficacy｜本体效力
本体主题与命运主题连接时，不能只问“人物是否形成了真实自我”，还要问：

```text
Identity Difference
→ 是否能改变 Recognition？
→ 是否能改变 Permission？
→ 是否能改变 P_reachable / Outcome Class？
```

若全部不能，本体可以非常强烈地显影，但对命运的结构效力接近零。

# ⑤ 三条一句话故事种子

1. 一座城市允许每个人自由选择职业，但所有职业最终只通向三种法定身份；一个少女不断换工作后发现，她真正想成为的第四种人从法律里根本不存在。
2. 一个村庄的孩子可以自由选择任何道路离家，却不知道所有道路都会在夜里移动，第二天把他们送回同一座广场；第一个发现真相的孩子决定不再选路，而是挖穿地图边界。
3. 王国承认人的灵魂会改变颜色，却规定无论变成什么颜色都必须继承出生时分配的职位；一个守门人第一次不是证明自己“是谁”，而是逼制度回答“为什么身份不能产生新的去向”。

# ⑥ 本轮新增 / 修正结论

## A｜命运新增 instance 型：槽位型命运
这不是修改 canonical，而是补充命运的电影 instance：

```text
命运收敛
≠ 必须只有一个具体未来
也可能是 Outcome Classes 被预先限定
```

因此以后检查命运至少看：
- `Option Count`：当下可选动作数；
- `Outcome Class Count`：真正不同的终局类别数；
- `System Exit`：能否退出分类系统；
- `Role Assignment Power`：谁拥有把人放进终局槽位的权力。

## B｜自由至少分两层
```text
Local Freedom：系统内部能做多少不同动作
Global Freedom：能否改变终局类别 / 规则 / 系统边界
```

局部自由高，不推出全局自由高。

## C｜本体 → 命运不能只看“自我觉醒”
本体差异要真正改变命运，必须找到转换接口：

```text
Identity
→ Recognition / Rule
→ Permission
→ P_reachable / Outcome Class
```

若接口被制度切断，则出现“本体强显影、命运不变化”。

## D｜空间克命运的反抗动作可以从“换位置”升级为“攻击边界”
当所有内部路径都回流同一终局时，继续增加路径没有意义。真正的命运变化来自：

```text
改变 Boundary
或退出 Carrier
或新增 Outcome Class
```

## E｜对十元 / 动态链的吸收
本轮不直接给十元定性，只增加动态链检查项：

```text
局部动作变化
→ 是否改变终局类别？
→ 若否，检查 Carrier / Boundary / Role Slot
→ 若角色只在槽位之间移动，判“系统内位移”
→ 若角色新增槽位、废除槽位或退出分类系统，才判结构级命运变化候选
```

这可避免把“人物做了很多事”误判成“命运发生了很多变化”。

本轮不修改 canonical 五维定义与正式生克方向。
