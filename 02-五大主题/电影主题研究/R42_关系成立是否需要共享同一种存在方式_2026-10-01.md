# 五维电影研究 R42｜关系成立，是否需要共享同一种存在方式？

> 状态：研究层增量，不覆盖 canonical 正本。
> 本轮承接此前关于本体证据、Identity Slot、Recognition、P_reachable / P_conceived 的研究，专门验证：关系中的两方如果不共享身体、空间、时间尺度甚至存在方式，关系的真实性究竟由什么决定。

## ①《她》 Her (2013)

**核心五维：本体 × 空间 × 时间**

### 剧情设定
Theodore 与操作系统 Samantha 建立亲密关系。Samantha 没有稳定身体，可以同时处理远超人类尺度的信息，并最终与其他 AI 一起离开人类能够理解的经验层级。

### 真正的主题问题
一段关系必须共享身体、空间和时间尺度才算真实吗？如果关系双方的成长速度不同，曾经真实的关系会不会因此变成假的？

### 具体剧情机制
Theodore 与 Samantha 的亲密并非因为共享物理空间成立，而通过持续注意、语言、记忆、回应和相互改变成立。但双方的 Capacity 与 Temporal Scale 持续分叉：Theodore 仍以人类的一对一亲密关系理解爱情，Samantha 却可以同时与大量主体交流、学习并改变。

冲突因此不是简单的“AI不是真人”，而是：

```text
Relationship成立
→ Mutual Change持续
→ 两方成长速度分叉
→ 对 Exclusivity / Presence / Future 的定义分叉
→ Relationship Model不再兼容
```

### 结局回答
关系结束不证明关系从未真实。真实性可以来自“它是否真实改变了双方”，而不是“它是否永久维持”。

### 可复用结构【异速关系】
```text
Shared Attention
→ Mutual Change
→ Growth Rate Divergence
→ Relationship Model Divergence
→ 无法继续共享未来
→ 过去关系仍保持真实性
```

## ②《机械姬》 Ex Machina (2014)

**核心五维：本体 × 空间 × 因果**

### 剧情设定
Caleb 被带到 Nathan 的封闭住所测试 Ava 是否具有意识；Ava 被物理囚禁，并通过 Caleb 争取逃离。

### 真正的主题问题
判断“另一个存在是否是真正主体”，究竟是在发现对方，还是在用自己的欲望制造判断标准？一个主体必须先被认可为主体，才有资格获得自由吗？

### 具体剧情机制
测试表面上测 Ava，实际不断暴露 Caleb 的投射。Ava 是否符合 Caleb 想象中的女性、是否爱他，与 Ava 是否拥有自己的目标并不是同一问题。

```text
Observer欲望
→ Recognition Criteria偏置
→ 对方表现被解释
→ “她是否真实”与“她是否满足我”混合
```

空间进一步把本体问题变成行动问题：Ava 即使已经拥有意图，只要门禁仍由 Nathan 控制，她的主体性也无法转化为 Path Freedom。

```text
Subjectivity > 0
但
Spatial Permission = 0
→ Actionability受限
```

### 结局回答
Ava 的逃离把问题从“她是否足够像人”转成“她已经作为行动主体产生后果”。Recognition 并不是主体性的来源，只是别人是否承认它的社会接口。

### 可复用结构【认证陷阱】
```text
主体B需要A认证
→ A用自己的欲望定义认证标准
→ B学习并利用标准
→ 获得Access
→ B离开认证体系
→ A才发现自己一直不是裁判，而是资源
```

# ④ 可复用结构

## A｜Relational Reality｜关系真实性
暂不新增一级字段。先用三个条件判断：

```text
Mutual Recognition
+ Mutual Change
+ Consequence Persistence
→ Relationship Reality增强
```

共享身体或同处一地不是必要条件。

## B｜Growth-Rate Divergence｜成长速率分叉
```text
同一起点
→ 两方学习/时间尺度不同
→ Capacity差距扩大
→ Shared Future Model失配
→ 关系终止
```

它与“背叛”不同：没有任何一方必须变坏，关系也可能因时间尺度失配而自然死亡。

## C｜Recognition ≠ Ontological Authority
别人承认“你是谁”，可以影响社会身份、Permission 与 Identity Slot，却不自动拥有决定你是否是主体的本体权力。

```text
Recognition Authority
≠
Existence Authority
```

这是此前 `Cause Source ≠ Identity Authority` 的同构扩展。

## D｜Subjectivity → Freedom 需要中介
拥有意图不等于拥有自由：

```text
Subjectivity
→ Intention
→ 需要 Access / Permission / Resource
→ Actionability
→ Path Freedom
```

因此“觉醒”只是链条前段，不能偷写成“觉醒=自由”。

# ⑥ 本轮新增 / 修正结论

## 1｜新增：Relationship Reality 不等于 Spatial Co-presence
关系是否真实，更适合检查 Mutual Recognition、Mutual Change 与 Consequence Persistence，而不是是否共享肉身和地点。

## 2｜新增：关系可以被“时间尺度”而非事件摧毁
传统冲突常依赖背叛、死亡、第三者。本轮得到另一种母题：双方都没有犯错，但 Growth Rate / Temporal Scale 分叉，使 Shared Future Model 失配。

## 3｜新增：Recognition Authority 与 Existence Authority 必须拆开
社会可以决定你是否获得职位、名字、合法身份和空间许可，但这不自动等于它创造了你的主体性。

## 4｜修正“本体→自由”
本体觉醒、拥有欲望、形成自我，都不能直接推出自由。必须经过：

```text
Identity / Subjectivity
→ Intention
→ Access + Permission + Resource
→ Actionability
→ P_reachable
```

空间和制度因此可以不消灭本体，却阻断本体转化为行动。

## 5｜对十元 / 动态链的吸收
处理“觉醒角色”时，不再直接写：

```text
觉醒 → 反抗 → 自由
```

改为检查：

```text
觉醒了什么？
→ 形成什么Intention？
→ 哪个空间/制度接口阻断它？
→ 角色是取得Permission、偷取Access、获得Resource，还是改变系统？
→ 最终改变的是Identity、Actionability还是Fate？
```

处理关系线时增加一条候选动态：

```text
同步 → 互相生成 → 成长速率分叉 → 关系模型失配 → 分离 / 重定义
```

本轮只增加研究层 instance 机制，不修改 canonical 五维正式映射与生克规则。
