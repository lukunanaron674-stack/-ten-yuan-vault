# 五维电影研究 R36｜记忆断裂后，因果如何劫持本体？

> 状态：研究层增量，不覆盖 canonical 正本。
> 承接 R31–R35：R31 已拆 Cause Truth / Cause Model；R32 已拆 Event State / Event Meaning；R33 提出 Anchor Network；R35 已说明 Origin Authenticity 不是本体最高裁决权。本轮不再重复“记忆=身份”，而专门研究：当记忆连续性失效时，人物靠什么制造因果连续性，以及这个替代机制怎样反过来塑造本体。

## ①《记忆碎片》 Memento (2000)

**核心五维：时间 × 因果 × 本体**

### 剧情设定
Leonard 无法形成新的长期记忆，依靠拍立得、笔记和纹身维持调查，并追杀他认定杀害妻子的人。

### 真正的主题问题
如果一个人不能连续记住自己的行动，他还能不能对自己制造的因果链负责？当内部记忆失效，外部记录究竟是在保存真相，还是成为可以被当前自我操纵的“未来命令”？

### 具体剧情机制
Leonard 把照片、文字、纹身当成稳定事实，试图用外部记录替代记忆。但记录没有自动携带完整语境；它们只保存被选择写下的结论。影片最终让 Leonard 主动制造一条未来的错误线索，使“现在的自己”能够操纵“之后失忆的自己”。因此真正发动行动的不是过去事实，而是被压缩后的记录系统。

### 可复用结构【外置因果】
```text
Internal Memory断裂
→ External Record成为 Anchor
→ Context 被压缩
→ Record 获得高 Authority
→ 当前 Self 写入/篡改 Record
→ Future Self 将 Record 当作 Cause Truth
→ Action重复
```

关键点：记录不是记忆的中性容器，而是一个可以跨时间传递行动指令的 Carrier。

## ②《镜子》 Mirror (1975)

**核心五维：时间 × 本体 × 因果**

### 剧情设定
成年 Alexei 的意识在童年、战争、家庭、梦境和当下之间非线性流动，人物和时代经验互相叠映。

### 真正的主题问题
本体是否必须依靠一条完整、按顺序排列的自传才能成立？如果记忆不是档案，而是不断被当下重新召回的感受与关系，本体怎样跨时间保持连续？

### 具体剧情机制
影片没有通过“解谜”恢复唯一正确时间线，而让不同年代、人物面孔、私人记忆与公共历史彼此产生联想。这里时间不是把事件排序的容器，而是不断让远隔事件在当前意识中重新邻接。

### 可复用结构【联想连续性】
```text
Chronology断裂
→ Sensory / Emotional Cue出现
→ 远隔事件被重新邻接
→ Meaning发生迁移
→ 当前 Self 获得非线性连续性
```

这提供了 Memento 的反例：连续本体不一定要求可靠 chronology；它也可以由重复的情绪、关系、图像和感官 Anchor 维持。

# 维度关系提炼

## 时间克因果：不仅是“来不及知道原因”
R31 已得到：Time.horizon 下降会迫使人物在 Cause Model 未完成前行动。本轮增加第二型：

```text
Temporal Continuity断裂
→ Cause Context 无法持续保留
→ 因果被压缩成局部标签/记录
→ 局部标签获得过高 Authority
```

即：时间连续性受损，可以通过“语境丢失”克制因果模型质量。

## 因果生本体：叙事自我可以由因果任务维持
Leonard 不能记住连续生活，却可以持续保有“我是一个为妻复仇的人”。因此：

```text
Stable Mission
→ Stable Cause Model
→ 重复 Action
→ Identity Continuity
```

因果任务可以替代记忆连续性，暂时成为本体支架。

## 本体克时间：身份也会筛选过去
如果人物先锁定“我是谁”，他会优先保存与该身份一致的记录，并删除/忽略不一致语境。因此本体不是被动接受过去；它还能反向编辑可被未来访问的过去。

# 可复用故事母题

### 1｜未来自己的操纵者
人物无法记住现在，于是现在的自己通过记录控制未来的自己；最大的反派可能是昨天的自己。

### 2｜任务替代人格
人物失去生活连续性后，只剩一个长期目标，于是目标从“我要做什么”逐渐变成“我是谁”。

### 3｜联想式本体
人物没有完整人生档案，却通过反复出现的气味、地点、关系和动作维持自我连续。

# ⑤ 三条一句话故事种子

1. 一个每天醒来都会失去前一天记忆的女孩，只相信手臂上自己写下的七条规则，直到某天发现第八条正在皮肤下面慢慢浮出来，而字迹也是她自己的。
2. 一个失忆士兵靠“找到杀死妹妹的人”维持人格，完成复仇后却第一次彻底不知道自己是谁，于是开始偷偷制造新的仇人。
3. 一座城市禁止保存个人档案，居民只能靠每年重复一次的气味、歌曲和路线确认自己还是同一个人；某年节日被取消后，整座城开始出现身份错位。

# ⑥ 本轮新增 / 修正结论

## A｜Memory Continuity ≠ Identity Continuity
记忆连续性是本体 Anchor 之一，不是必要充分条件。它失效后，Mission、Relation、Recognition、Sensory Pattern 等仍可能维持本体连续。

## B｜新增机制：Externalized Causality（外置因果）
当内部记忆不足以保存 Cause Model 时，记录、纹身、档案、仪式、AI助手等 Carrier 可以承担因果连续性。

但：
```text
External Record Reliability
≠
Cause Truth Reliability
```
因为记录仍受选择、压缩、篡改和语境丢失影响。

## C｜新增：Context Loss 是独立于 False Evidence 的危险
证据本身可以是真的，但失去上下文后仍制造错误 Cause Model。

```text
True Evidence + Missing Context
→ False / Overconfident Cause Model
```

这比单纯“有人伪造证据”更适合复杂故事。

## D｜新增：Mission 可以充当 Identity Prosthesis（身份义肢）
暂不升一级字段。

当人物无法依靠记忆、关系或空间维持本体时，一个稳定任务可以临时替代本体连续性；任务完成反而可能制造 Identity Collapse。

## E｜对动态链的吸收
以后涉及失忆、档案、历史记录、AI记忆、轮回时，至少检查：
1. 哪部分 Event State 被保存？
2. 哪部分 Context 被丢失？
3. 谁拥有 Record Write Authority？
4. Record 是 Evidence、Anchor，还是 Action Instruction？
5. 人物的 Identity Continuity 最终由 Memory、Mission、Relation、Recognition 还是 Pattern 承担？

本轮不修改 canonical 五维映射和正式生克，只补充电影 instance 中“时间连续性→因果语境→本体连续”的中介机制。
