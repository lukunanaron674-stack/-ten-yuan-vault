# 电影主题研究｜入口

本目录用于研究“五大主题”在电影叙事中的**实际主题机制**。

## 权限层级

本目录属于**研究层**，不是五大主题 canonical 正本。

正本优先级始终高于本目录：

1. [[../五大主题是五行主题领域狭义定义正本_v1.0]]
2. [[../五大主题生克盘_v1.0_2026-07-16]]
3. [[../五大主题显影与判定协议_v1.0_2026-07-16]]

若研究结论与正本冲突：

- 不自动覆盖正本；
- 在研究总纲标记【修正候选 / 冲突】；
- 只有用户明确确认后，才进入 canonical 更新流程。

## 三层分工

- **五维 / 五大主题**：故事研究什么主题问题。
- **十元**：主题内部的力量性质。
- **动态链**：力量如何连续变化、传导、反馈、收敛、回写与断链。

## 主文件

- [[五维主题研究总纲_v1.1]]

当前总纲已经吸收电影研究 R1–R29，并对 R17–R29 做了结构化收束。

## 每小时研究的写回规则

每轮优先选1–3部电影，至少产出：

1. 电影与核心五维；
2. 主题问题；
3. 具体剧情机制；
4. 可复用结构；
5. 3条一句话故事种子；
6. 本轮新增 / 修正 / 否定结论；
7. 对十元 / 动态链可吸收结构。

写回时：

- 不创建 R30、R31 式独立“总纲”文件；
- 成熟结论直接合并进 [[五维主题研究总纲_v1.1]] 对应章节；
- 被后续反例推翻的口径必须降级或删除，不允许旧结论和新结论并排假装都对；
- 新字段优先尝试作为现有字段的子属性，防止字段无限增殖；
- 正式主题生克方向仍以 canonical 生克盘为准；
- 电影案例中的中介机制可以丰富“某条正式关系怎样具体发生”，不能改写正式关系方向。

## 当前重点

继续验证：

- 命运的多种具体机制，而非把命运压成单一 `P_reachable↓`；
- 本体许可、可见可能、可想象可能之间的边界；
- Carrier、阈值、锚点、残留、因果债如何共同形成故事动力；
- 动态链如何终止：克制、补合、退出Carrier、删节点、改写规则、接受不可逆；
- 哪些结构最适合30秒 / 1分钟 / 3分钟 / 8分钟动画。
