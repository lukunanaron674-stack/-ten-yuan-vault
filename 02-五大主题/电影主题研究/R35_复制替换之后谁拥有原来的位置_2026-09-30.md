# 五维电影研究 R35｜复制、替换之后，谁拥有原来的位置？

> 状态：研究层增量，不覆盖 canonical 正本。
> 承接 R32–R34：R32 已提出 Cause Source ≠ Identity Authority；R33 将地点/关系等视为 Identity Anchor；R34 拆开 Responsibility 与 Identity。本轮专门研究：当两个对象同时拥有同一身份的部分证据时，本体冲突怎样真正发生。

## ①《致命魔术》 The Prestige (2006)

**核心五维：本体 × 因果 × 空间**

### 剧情设定
Angier 使用复制装置完成“传送人”魔术，每次表演都会产生两个连续性都可追溯到表演前 Angier 的个体，其中一个必须死亡，另一个出现在舞台另一端。

### 真正的主题问题
当复制不是“假货模仿真货”，而是两个个体都拥有同一过去的因果连续性时，谁才有资格继续占据“原来的我”的位置？身份是否必须唯一？

### 具体剧情机制
装置没有提供一个可观察的“原件标记”。复制发生后，两个 Angier 都能从第一人称连续地声称自己就是进入机器的人。冲突因此不是 Source Truth 不清，而是 Source Truth 对两个对象同时成立。Angier 用空间机制强制解决本体歧义：舞台上只允许一个“Angier”继续被社会 Recognition，另一个被物理消除。

### 可复用结构【身份竞争】
```text
Identity I
→ Copy Event
→ A、B 同时继承 I 的历史证据
→ Identity Evidence 不再唯一指向单对象
→ 社会位置 / 关系 / 财产仍要求唯一 Carrier
→ A 与 B 发生 Legitimacy Conflict
→ 空间或制度强制选择唯一占位者
```

**关键结论：** 本体冲突不一定来自“我不知道我是谁”，也可以来自“有两个对象都足够像我”。

## ②《月球》 Moon (2009)

**核心五维：本体 × 因果 × 命运**

### 剧情设定
Sam Bell 发现自己并非唯一的长期雇员，而是公司批量制造、植入相同记忆并按周期替换的克隆体。

### 真正的主题问题
如果记忆、姓名和人生叙事都是复制来的，一个个体是否仍能获得自己的本体？来源是伪造的，是否意味着当下经验也是假的？

### 具体剧情机制
两个 Sam 相遇后，最初的身份危机来自“谁是真的 Sam”。但剧情逐渐把问题从 Origin Authenticity 移向 Current Experience：两个克隆拥有共同的过去叙事，却开始积累不同的当前经验、关系和选择。分叉发生后，本体证据开始从复制记忆转移到独立经历。

### 可复用结构【共享过去 / 分叉现在】
```text
Shared Memory M
→ A、B 都以 M 建立 Internal Identity
→ A 与 B 进入不同 Experience Path
→ Evidence 持续分叉
→ “谁是原件”解释力下降
→ “谁正在成为谁”解释力上升
```

**修正 R32：** `Cause Source ≠ Identity Authority` 进一步加强：不仅来源无永久裁定权，Shared Origin 也无法阻止后续身份分叉。

## 维度关系提炼

### 因果 → 本体：共同来源可以生成多个本体
此前容易默认：一个 Cause Source 对应一个 Identity。复制叙事证明这个假设并不稳定。

```text
Source S
→ A
→ Copy
→ A + B
```

如果 A、B 都继承 S 的有效证据，则 Source 只能回答“从哪里来”，不能单独回答“现在是谁”。

### 空间 → 本体：位置本身可以成为身份资源
舞台、家庭、职位、房间、身体位置等并非中性容器。当一个身份只能被一个 Carrier 占据时，空间具有 `Identity Slot` 功能。

```text
Identity Slot Q capacity = 1
A claims Q
B claims Q
→ 本体冲突被空间容量转译为排他冲突
```

暂不新增一级字段，`Identity Slot` 作为空间机制候选。

### 命运 → 本体：批量替换把个体降为可替换实例
当系统预先规定“每个 Sam 只能工作固定周期，然后由下一个 Sam 接替”，命运压制的不只是 Outcome，而是个体对身份连续性的独占权。

# 可复用故事母题

### 1｜双重合法者
不是“真假二选一”，而是两个对象都拥有充分合法性，但世界的某个位置只能容纳一个。

### 2｜共享过去，分叉现在
角色争夺共同历史没有答案，真正的本体变化发生在复制之后积累的不同经历。

### 3｜身份槽位
冲突不是双方本体天然互斥，而是制度、关系或空间只允许一个人占据某个身份位置。

# ⑥ 本轮新增 / 修正结论

## A｜新增：Identity Evidence 可以非唯一映射
```text
Evidence Set E
→ 不一定只支持一个 Carrier
```

因此“证据充分”与“身份唯一”必须拆开。

## B｜新增：Identity Conflict 可能来自 Slot Scarcity
```text
两个合法 Carrier
+ 一个容量为1的 Identity Slot
= 排他冲突
```

这给“空间克本体/空间约束本体”提供了非常具体的剧情机制：空间或制度位置的容量限制，迫使原本可共存的本体竞争。

## C｜修正“原件优先”假设
Origin Authenticity 只是 Identity Evidence 的一种，不能自动压过 Current Experience、Relationship、Recognition、Embodied Continuity 等其他证据。

## D｜新增：Identity Divergence
共享过去只能保证起点相似，不能保证持续同一。

```text
Shared Past
→ Different Experience
→ Different Action
→ Different Recognition
→ Identity Divergence
```

## E｜对十元 / 动态链的吸收
处理复制、替身、继承、职位争夺时，动态链至少检查：
1. 哪些 Identity Evidence 被复制？
2. 哪些证据在复制后开始分叉？
3. 冲突来自“真假判断”，还是来自 Identity Slot 容量不足？
4. 谁拥有 Recognition Authority？
5. 删除竞争者是在解决本体问题，还是只是在消除空间上的第二 Carrier？

本轮不修改 canonical 五维映射与正式生克，只补充本体、空间、因果、命运在电影 instance 中的可操作机制。
