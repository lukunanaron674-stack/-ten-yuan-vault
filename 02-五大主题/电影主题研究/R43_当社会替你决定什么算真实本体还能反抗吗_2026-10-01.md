# 五维电影研究 R43｜当社会替你决定什么算真实，本体还能反抗吗？

> 状态：研究层增量，不覆盖 canonical 正本。
> 承接 R35–R42：已有研究已拆出 Identity Slot、Recognition Authority、Normality Lock、P_reachable / P_conceived，以及 R42 的 Recognition Authority ≠ Existence Authority。本轮不再讨论“主体是否存在”，而验证更窄的问题：当制度、家庭或共同体垄断“什么版本的现实可被公开承认”时，人物的本体如何被压制，以及私人真实怎样转化为可行动的社会真实。

## ①《燃烧女子的肖像》 Portrait of a Lady on Fire (2019)

**核心五维：本体 × 时间 × 命运**

### 剧情设定
Marianne 被雇来秘密绘制 Héloïse 的婚姻肖像，肖像将寄给未来丈夫并促成婚姻。两人在有限时间内建立关系，但婚姻制度与阶级结构并未因此消失。

### 真正的主题问题
如果一段关系无法改变最终制度结果，它是否仍能改变人物是谁？短暂经验的价值是否必须由“持续占有”证明？

### 具体剧情机制
肖像首先是制度接口：它把 Héloïse 的身体和社会身份压缩成可供远方丈夫判断的 Representation。Marianne 从秘密观察到公开作画，关系也从单向凝视变成 Mutual Recognition。期限不断缩短，Outcome Freedom 很低，但共同创作、记忆与互相看见仍改变两人的 Internal Identity。

结局没有让爱情击败婚姻制度，而是让过去经验继续以音乐、图像和记忆形式存在。于是“关系是否成功”与“关系是否产生永久本体变化”被拆开。

### 可复用结构【短时高塑形】
```text
Time.horizon↓
→ Outcome Freedom↓
→ Attention Density↑
→ Mutual Recognition↑
→ Identity Update↑
→ 关系结束
→ Consequence Persistence仍存在
```

关键修正：时间短不推出本体影响小。Duration 与 Identity Weight 不是同一变量。

## ②《狩猎》 The Hunt / Jagten (2012)

**核心五维：因果 × 本体 × 空间**

### 剧情设定
Lucas 被儿童的一句话误指为性侵者，怀疑通过幼儿园、家庭和小镇共同体扩散。即使缺乏可靠证据，社会关系与公共空间迅速把他重新分类。

### 真正的主题问题
当共同体已经决定“你是什么人”，事实澄清为什么仍不足以恢复原来的你？

### 具体剧情机制
最初只是一个 Cause Claim，但它迅速获得高社会 Authority。共同体的重复询问、传言、排斥与暴力把一个未经证实的事件模型转化成 Public Identity。Lucas 知道自己的 Cause Truth，却无法单靠私人知识恢复 Recognition。

即使公开关系后来部分恢复，结尾仍保留威胁：社会判断可以被撤回，但被制造出的可能性不会完全消失。

### 可复用结构【指控本体化】
```text
Ambiguous Claim
→ Authority放大
→ Recognition Network同步
→ Public Identity重写
→ Permission / Access下降
→ 私人本体与公共本体分叉
→ Truth Clarification
→ Recognition恢复不完全
```

这里尤其重要：Truth Repair ≠ Identity Repair。

# 维度关系提炼

## 1｜因果 → 本体：需要 Authority 中介
此前已经有 Cause → Identity Pressure，本轮补充更严格的社会型链条：

```text
Cause Claim
→ Authority / Repetition
→ Recognition Network
→ Public Identity
```

因此“一个事件改变身份”不是自动发生的。必须问：谁有权解释事件、谁重复解释、多少 Carrier 接受解释。

## 2｜本体必须拆出 Private / Public 两个状态层
这不是新增五维，而是本体在剧情 instance 中的两个可观测状态：

```text
Private Identity = 人物对“我是谁”的内部模型
Public Identity = Recognition Network 当前允许人物以什么身份存在
```

两者可以一致，也可以剧烈分叉。

当：
```text
Private Identity稳定
Public Identity崩塌
```
人物会产生社会行动障碍，但不必立即产生自我怀疑。

当：
```text
Public Identity长期高压重复
→ Private Identity开始吸收外部判断
```
才形成更深的本体压制。

## 3｜时间 → 本体：不是只有侵蚀，也能浓缩
R37–R38 已研究 Repetition / Access Persistence。本轮加入反方向：

```text
Duration↓
+ Attention Density↑
+ Salience↑
+ Mutual Recognition↑
→ Identity Weight仍可极高
```

所以 Representative Weight 不能由时长直接推出。

## 4｜命运压制关系，不等于抹除关系的本体后果
```text
Fate限制共同未来
≠
Fate删除已经发生的Mutual Change
```

这是 R34 “Outcome Freedom = 0 不推出 Meaning Freedom = 0” 在关系主题上的具体化。

# 可复用故事母题

### A｜被社会重写的人
人物知道自己是谁，但所有社会接口都只接受另一个版本的他。冲突不是寻找内心，而是如何让 Private Truth 重新获得 Public Recognition。

### B｜短时高塑形关系
两个人注定无法共同生活，故事不再问“能不能在一起”，而问“这段有限关系最终把双方变成了谁”。

### C｜事实胜利、身份未恢复
人物证明了指控是假的，却发现工作、亲密关系、空间许可和他人的直觉判断没有同步恢复。

# ⑤ 三条一句话故事种子

1. 一个少女被全城误认为能带来瘟疫，她证明疾病来自水源后，城门重新向她开放，却发现所有孩子见到她仍会本能地捂住口鼻。
2. 两个敌国的地图师只有七天共同测绘边境，战争结束后他们永远不能再见，但双方国家此后使用的每一张地图都偷偷保留着他们共同发明的地名。
3. 一座城市每天公布每个人的“社会身份标签”，一个男人的标签因系统错误从“医生”变成“杀人犯”，他明明拥有全部记忆和证据，却发现连自己家的门锁都只承认公共标签。

# ⑥ 本轮新增 / 修正结论

## A｜新增：Truth Repair ≠ Identity Repair
```text
Cause Truth被纠正
≠
Recognition Network同步纠正
≠
Permission / Access自动恢复
≠
Identity Consequence消失
```

因此因果线结束后，本体线可以继续运行。

## B｜新增：Public Identity 是 Recognition Network 的涌现结果
不把 Public Identity 升成新五维字段，它是本体维的社会实例层。它由多个 Carrier 的 Recognition 共同稳定，而不是由单一人物宣布。

## C｜修正 Representative Weight
R37–R38 已提出 Salience × Recognition × Repetition × Access Persistence。本轮证明 Repetition 不是必要条件。极短事件如果 Attention Density、Salience、Mutual Recognition 极高，也能获得巨大 Identity Weight。

更稳妥的写法暂改为：
```text
Identity Weight
← Salience / Recognition / Access Persistence / Attention Density / Repetition 等机制共同贡献
```
不再写成近似乘法，避免把研究模型误装成数学公式。

## D｜新增：命运可以压制 Future Relation，但不能反向取消 Past Mutual Change
这提供一种非胜负式结局：制度赢了共同未来，人物仍保留已经发生的本体改变。

## E｜对动态链的吸收
遇到“污名 / 误解 / 社会标签 / 禁忌关系”时增加检查：
1. Cause Truth 是什么？
2. 谁拥有 Interpretation Authority？
3. Recognition Network 如何同步？
4. Private Identity 与 Public Identity 是否分叉？
5. Public Identity 改变了哪些 Permission / Access？
6. 真相揭露后，哪些层恢复，哪些层仍滞后？

推荐链：
```text
Claim
→ Authority
→ Recognition Repetition
→ Public Identity
→ Permission / Access
→ Actionability
→ Fate Pressure
```

反向修复链则不能偷懒写成“真相大白→恢复正常”，而应逐层检查：
```text
Truth Repair
→ Recognition Repair?
→ Access Repair?
→ Relationship Repair?
→ Private Identity Integration?
```

本轮不修改 canonical 五维定义与正式生克，仅把成熟 instance 机制写入电影主题研究层。
