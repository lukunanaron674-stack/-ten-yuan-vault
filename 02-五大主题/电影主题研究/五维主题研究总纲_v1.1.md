# 五维主题研究总纲 v1.1

> 本文件是**研究层总纲**，不覆盖五大主题 canonical 正本。  
> 正本仍决定五维定义、五行狭义继承与正式生克方向；本文件研究的是：电影如何把五维主题变成角色必须回答的问题，以及这些主题如何通过具体机制进入故事。

## 0｜三层分工

- **五维 / 五大主题**：故事研究什么主题问题。
- **十元**：主题内部的力量性质、对象属性与具体作用端。
- **动态链**：力量怎样连续变化、传导、反馈、收敛、回写、断链。

禁止反向混写：
- 不能因为某个十元显影就直接判主主题；
- 不能因为主题层发生生克，就反推人物固定十元；
- 不能因为“保护、攻击、离开、进入”等动作名，就直接给动作贴“生 / 克 / 补”。

# 1｜主题不是设定，而是被持续施压的问题

电影中的主题不是一句观点，也不是“出现了时间旅行 / 监狱 / 失忆 / 预言”就算主题。

推荐工作链：

```text
主题问题
→ 正常答案 / 初始信念
→ 反例或极端条件
→ 五维变量发生变化
→ 角色被迫行动
→ 选择产生代价
→ 意义被回写
→ 本体 / 因果 / 命运形成新状态
```

强主题常见结构：

```text
A有价值
B也有价值
但A+B无法同时保存
→ 角色必须选择
→ 代价让主题成立
```

即：**互斥正确性**。

# 2｜五维的可操作主题问题

## 2.1 时间

时间研究的不只是先后，而是：
- 剩余时间是否有限；
- 行动窗口还剩多少；
- 过去是否仍能回写现在；
- 理解是否总晚于行动机会；
- 外部事件与人物经验是否以同样速度持续；
- 时间是否让选择、锚点、关系、债务变得不可逆。

高价值问题：
- 如果知道结局，选择还有没有意义？
- 如果未来无限延后，“现在做”为什么有价值？
- 如果终于理解过去时已经无法修改，理解还有什么用？
- 外部事件被重置，但人物经验持续，人物还会不会改变？

新增操作变量：
- `Time.horizon`：剩余行动窗口；
- `Persistence(event/agent/relationship/institution)`：不同对象的持续时间；
- Event Persistence 与 Agent Persistence 可不同步。

## 2.2 本体

本体研究：
- “我为什么还是我？”
- 我是谁，与世界把我当成谁是否一致？
- 一个为了生存形成的稳定状态，是不是“真正的我”？
- 当外部锚点被逐步删除，本体还能靠什么持续？
- 过去版本的我做出的承诺，是否继续约束现在版本的我？

关键字段：
- `Anchor`：地点、关系、记忆、身体、职业、他者确认等本体支撑；
- `Internal Identity`：自我认定；
- `Recognition`：外界如何确认 / 固化身份；
- `Identity-Admissibility`（候选关系量）：角色是否把某个客观可达选项视为“我这种人可以做 / 可以成为”。

本体主题三问：
1. 我是谁？
2. 世界允许我成为什么？
3. 世界持续把我当成什么以后，我会不会最终真的变成它？

## 2.3 空间

空间研究：
- 什么能在哪里存在；
- 谁能进入，谁能保留位置；
- 空间如何改变同一事件的代价；
- 空间如何控制人物获得哪些关于自己 / 他人的反馈；
- 空间是否让后果“知道但不必回应”。

新增区分：
- **Reach ≠ Retain**：能进入不等于能稳定保有；
- `P_reachable.retainability`：可达可能的稳定性；
- 空间可作为 `Cost Transformer`：同一个 Cause 进入不同空间，会生成不同强度 / 类型的 Cost；
- 邻接不等于反馈：物理接近可以与伦理 / 行动反馈分离。

## 2.4 因果

因果研究不只“什么导致什么”，还包括：
- 原因、责任与归罪是否一致；
- 人是否必须知道原因才能行动；
- 解释是否被制度强迫收敛；
- 过去是否能被现在重新组织；
- 因果是否跨人物、跨代、跨制度持续。

必须拆开：
- `Cause Source`：谁 / 什么实际制造结果；
- `Responsibility`：结构上应承担责任者；
- `Cost Bearer`：谁实际承担代价；
- `Blame Target`：谁被归罪；
- `Carrier`：力量 / 因果通过什么从A传到B。

核心修正：

```text
代价落在哪里 ≠ 原因从哪里产生
```

## 2.5 命运

命运不能再定义成“未来不可改变”，也不能定义成单一的 `P_reachable↓`。

R27 的“命运 = 可选择空间被历史不断压缩”已被 R28–R29 修正为：**这只是命运的一种机制**。

当前至少区分：

### A. Convergent Fate｜选择收敛型命运
```text
多可能
→ 行动 / 时间 / 因果不断关闭路径
→ P_reachable收缩
→ 去向逐渐单一
```

### B. Identity-Filtered Fate｜本体许可收敛
客观路径仍存在，但人物长期认为“那不是我会做的事”，直到时间把客观机会也关掉。

```text
客观可达
→ Internal Identity过滤
→ 行动未发生
→ Time.horizon变化
→ 原选项最终真实消失
```

### C. Categorical Fate｜分类锁定型命运
选项很多，但全部被同一套元规则解释。

```text
多路径
→ 同一Meta-rule分类
→ 不同选择生成同构身份 / 代价
→ 命运感仍然成立
```

所以：

> **Option Quantity ≠ Freedom。**

有十个服从同一规则的选项，不一定比两个真正异质的选项更自由。

# 3｜四条并行故事轨道

## 3.1 事件链
发生了什么。

## 3.2 意义链
上一件事现在意味着什么。

```text
A发生
→ 被解释为X
→ 新经验出现
→ A被重新解释为Y
→ 本体 / 关系变化
```

## 3.3 可能性链
人物认为世界还有哪些可能。

`P_visible` 与 `P_conceivable` 必须区分：
- 看见一种生活，不等于能想象“那种生活属于我”；
- 没见过，也可能想象它存在。

## 3.4 机会链
人物实际上能不能抵达与保有某个选项。

```text
可能存在
→ 看得见 / 想得到
→ 能否进入
→ 能否承担行动成本
→ 能否保留结果
→ 真正执行
```

# 4｜行动进入剧情前的链

R23–R25把“知道”拆开后，当前推荐：

```text
Access
→ Salience
→ Actionability
→ Action
→ Consequence
→ Feedback
→ 回写本体 / 因果 / 命运
```

说明：
- Access：能否接触信息，优先并入 `P_visible`；
- Salience：信息是否足够显著，能否持续进入反馈；
- Actionability：知道以后能不能据此行动，优先由 `Threshold + P_reachable + Capacity` 表达，不单建一级字段；
- Consequence：行动产生什么真实后果。

修正：
- `Knowledge` 不建一级字段；
- `Allocation Power` 降为 `Carrier.allocation_power`；
- `Feedback Storage` 保留，但至少拆成 `Persistence × Reliability`；
- 保存得久，不代表保存得真。

# 5｜关键主题实验法

以下优先作为“故事操作”，不是电影类型。

### 改变条件
极端条件、冻结世界、变量分叉、权力换位、时间定价、阈值漂移。

### 改变认知
信息缺失、认知污染、因果黑箱、拒绝解释、确定性剥离、规则揭露、标签回写。

### 改变现实
观点执行、世界答案、空间显影、愿望异化、强制分类、分类失效。

### 改变时间关系
结局前置、迟到理解、追溯重写、未实现人生回返、可能性保留、不可逆收敛。

### 改变本体
本体反证、身份代偿、双身份互斥、同源分化、本体失稳、命运内化、本体社会化。

### 改变责任与代价
分布式责任、有限恢复、自我更新债务、代价转移、责任断裂、双正确互克、责任替代、责任真空。

# 6｜R17–R29稳定母题

## 6.1 自我保护叙事
本体为了维持当前版本，主动重组过去因果。

## 6.2 强制解释
复杂现实进入需要唯一答案的制度空间后，被压缩成可裁决因果。

## 6.3 锚点剥离 / 锚点腐蚀
不直接攻击本体，而是逐步删除维持它的外部依据。

## 6.4 版本债务
本体V1做出承诺，时间过去后本体变成V2，但后果仍存在。

## 6.5 自造命运
```text
自由选择
→ 不可逆因果
→ 时间延迟
→ 未来选择权下降
→ 命运形成
```

自由可以生命运。

## 6.6 责任替代 / 归罪漂移
真正原因不可达时，痛苦会寻找可达责任对象。

## 6.7 解决方案遗传
上一代为解决A制造B，下一代出生时A已消失，但B仍作为制度 / 命运继续存在。

## 6.8 脱源因果
```text
A产生B
→ B生成C
→ C开始维持B
→ A消失
→ B仍存在
```

## 6.9 携伤继续
无法Undo，也无法完全Repair，只能扩大人物承载能力继续存在。

## 6.10 悬空债务
受害者 / 补偿对象消失后，因果债仍存在。

## 6.11 解释放弃
人物成长不是找到唯一答案，而是放弃“必须完全解释”的要求。

## 6.12 环境校准 / 生存壳
空间长期控制人物获得的经验与反馈，使适应行为逐渐被确认成本体。

## 6.13 预知同意
未来代价提前进入现在；人物有机会避免，却为了保留价值V选择接受代价。

## 6.14 经验删除悖论
Erase降低当前痛苦，同时删除用于校准行为的反馈记录。

`Erase ≠ Undo ≠ Repair ≠ Adapt`。

## 6.15 预测制度化 / 提前裁决
Prediction本身不是命运；只有经Carrier获得资源 / 准入 / 惩罚分配权后，才真正进入命运链。

## 6.16 邻接隔离
灾难与日常物理相邻，但边界降低反馈显著性，使角色“知道却无需回应”。

## 6.17 责任拥塞
多个真实责任同时成立，人物保护其中一个责任时不得不伤害另一个。

## 6.18 载体倒戈
Carrier不变，但Routing改变，原本用于“克”的渠道可开始产生“补”。

## 6.19 借用空间
角色能进入高价值位置，却没有Retain权，最终临时身份被撤销。

## 6.20 代价锁定
```text
目标
→ 已付Cost
→ 为保护Cost的意义继续投入
→ 更多Cost
```

过去Cost可以回写为新的Cause。

## 6.21 预防生成
为了阻止坏未来而采取的行动，反而制造坏未来成立的条件。

## 6.22 选择锁定
一次选择改变下一次的选项结构，重复后“选择”逐渐看起来像“命运”。

## 6.23 保护性破坏
“保护”短期可能是补，长期可能翻转成克。

## 6.24 非对称解放
同一个Operation可同时：
- 生A；
- 克B；
- 补C。

## 6.25 固定世界 / 可变人物
外部事件反复重置，但人物的Feedback / Capacity / 本体继续累计。

## 6.26 本体先删选项，时间再封死
不是“没得选”，而是长期拒绝选择，最后时间把原本存在的选项真正关掉。

## 6.27 反制度同构
从制度A逃进反制度B，表面规则相反，但两边共享同一元规则；真正破局必须退出二元分类。

## 6.28 规则内化迁移
外部制度Carrier消失后，规则仍作为Internal Identity / Recognition习惯继续运行。

# 7｜动态链必须记录的中介

五维研究的最大修正之一：

> 禁止只写“时间生本体 / 命运克本体 / 空间克命运”然后结束。

研究层推荐写：

```text
A发生什么变化
→ 通过什么Carrier / 中介
→ 改变目标的哪个变量
→ 目标为什么发生变化
→ 代价由谁承担
→ 下一步可行动性如何改变
```

核心字段池：

- State
- Anchor
- P_visible
- P_conceivable
- P_reachable
- Threshold
- Persistence(object)
- Debt
- Cause Source
- Carrier
- Cost Bearer
- Blame Target
- Recognition
- Irreversibility
- Feedback Storage.persistence
- Feedback Storage.reliability

子属性优先，不继续无上限增加一级字段：
- `Carrier.routing`
- `Carrier.allocation_power`
- `P_reachable.retainability`
- `Debt.source = past_cost`
- `Time.horizon`

# 8｜生 / 克 / 补的研究层修正

## 8.1 生克补不是动作属性

禁止：

```text
保护 = 补
攻击 = 克
离开 = 克
进入 = 生
```

正确判断单位：

```text
Operation O
→ 目标变量 V
→ 经过时间 Δt
→ V 的状态发生什么变化
```

因此“保护”完全可能：
- 短期补；
- 长期克。

## 8.2 同一操作允许多目标异号

```text
O → A（生）
O → B（克）
O → C（补）
```

## 8.3 补 ≠ 复原

当前研究层工作定义：

> **补 = 提高受损系统继续运行 / 承载的能力。**

所以：
```text
X被克
→ 原状态不可恢复
→ 补进入
→ 形成可运行的X'
```

不要求回到X。

# 9｜链如何停下来

动态链不只研究力量怎样继续，还必须研究怎样结束。

当前保留：

### remove / exit Carrier
关键载体退出后，闭环失去成立条件。

### rewrite rule
不是离开系统，而是改写“什么关系才算合法”的元规则。

### Loop Break
```text
A→B→C→A
```
不一定靠更大的“克”解决，也可删除一个必要节点。

这对故事结局很重要：破局不必永远是“再搬一个更强十元进来打赢”。

---

# 10｜Undo / Repair / Adapt

必须严格区分：

### Undo
让事件等于没发生：
`S1 → A → S2 → S1`

### Repair
事件仍发生过，但恢复部分功能：
`S1 → A → S2 → S3`，且 `S3 ≠ S1`

### Adapt
损伤不能修复，只提高人物与结果共存的能力。

R28修正：
Adapt可只是**有限承载态**，不要求完整新稳定。

`Irreversibility`越高，Undo空间越小，故事越依赖Repair / Adapt。

---

# 11｜主题结局不只“问题→答案”

至少允许：

- 问题 → 明确答案；
- 问题 → 选择并承担代价；
- 问题 → 有限修复；
- 问题 → 适应 / 有限承载；
- 问题 → 接受不可知；
- 问题 → 容纳永久矛盾；
- 问题 → 精确承认不可恢复；
- 问题 → 改写规则；
- 问题 → 退出Carrier / 断环。

好的主题结局不一定降低复杂性。

本体成长有时不是“知道更多”，而是：

> **能够承载更多无法彻底解决的东西。**

---

# 12｜当前命运定义的修正状态

【否定旧总定义】

以下句子不能再当命运总定义：

> “命运 = 可选择空间被历史不断压缩后的结构。”

它只对应 **Convergent Fate**。

当前更稳妥的研究口径：

> 命运主题研究的是：**可能性如何被打开、过滤、分类、收敛、继承、内化或被人物自己的选择反向制造，最终形成某种去向结构。**

其中至少需要分别检查：
- 外部可达性；
- 本体许可；
- 元规则分类；
- 时间窗口；
- 历史残留；
- Carrier / 制度是否自我维持。

---

# 13｜当前最值得继续验证的问题

1. `P_conceivable / P_visible / Identity-Admissibility` 是否能进一步合并，还是必须保持三类。
2. Feedback Salience 能否完全由 Threshold / Carrier 表达。
3. Rule Diversity 是否真的值得长期保留，还是只是 Categorical Fate 的描述属性。
4. 哪些“命运”不改变外部结构，只改变人物对结构的意义，从而产生真实自由。
5. 五大主题正式生克盘中的固定方向，如何通过不同Carrier产生完全不同的具体叙事机制。
6. 动态链的终止机制能否形成有限集合：克制、补合、退出Carrier、删节点、改写规则、接受不可逆。
7. 同一主题问题更换实验法后，是否能稳定生成显著不同的故事。
8. 对短动画最有价值的是哪些结构，尤其是30秒 / 1分钟 / 3分钟 / 8分钟体量。

# 14｜一句话生成公式

```text
一个角色原本相信【正常答案A】，
直到【五维变量变化】制造出A无法解释的反例；
他必须在【两个都成立但无法同时保存的答案】之间选择，
而这个选择会改变【未来可能 / 本体 / 因果债 / 空间准入】，
并让【某个明确对象】承担代价。
```

审核时继续追问：

> 这个变化是谁付的钱？  
> 这个力通过什么Carrier传过去？  
> 人物知道以后真的能行动吗？  
> 这次行动让下一次更自由，还是更难退出？  
> 最后是解决了问题，还是学会承载问题？
