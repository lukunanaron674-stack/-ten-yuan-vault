# 五维电影研究 R39｜空间如何把阶级差异变成命运结构？

> 状态：研究层增量，不覆盖 canonical 正本。
> 承接 R38：空间可控制高频 Recognition，进而使本体与行动范围收敛。本轮进一步验证另一条路径：空间不经过“你是谁”的解释，也能否直接通过通行权、资源梯度与移动成本制造命运。

## ①《寄生虫》 Parasite (2019)

**核心五维：空间 × 命运 × 因果**

### 剧情设定
金家住在低洼半地下室，朴家住在山坡上的现代豪宅；金家逐步进入朴家的生活与劳动空间。

### 真正的主题问题
如果社会允许一个人暂时进入上层空间，却不改变他长期占有空间与资源的资格，这种“进入”究竟是上升，还是借用？

### 具体剧情机制
电影不断让人物上下移动：半地下室、山坡豪宅、豪宅地下密室、暴雨后的低洼社区。金家能进入朴家，却依赖伪造身份、劳动角色和雇主许可；暴雨则让同一天的天气在两个高度产生完全不同的 Cost。空间因此不是阶级的装饰符号，而是资源、风险与通行权的分配器。

### 可复用结构【Access ≠ Possession】
```text
低位 Space A
→ 获得临时 Access to Space B
→ B 的资源提高短期 Actionability
→ 但 Possession / Permission 未改变
→ 外部冲击发生
→ 临时 Access 被撤销
→ 人物迅速回落到原空间风险结构
```

**关键结论：** 能进入一个空间，不等于拥有那个空间所代表的命运可能性。

## ②《雪国列车》 Snowpiercer (2013)

**核心五维：空间 × 命运 × 因果**

### 剧情设定
末世幸存者生活在永久运行的列车中，车厢按阶级分层；尾部居民发动起义向车头推进。

### 真正的主题问题
如果反抗只能沿统治者预先设计的空间路径前进，那么“成功抵达中心”是否真的等于改变系统？

### 具体剧情机制
尾部到车头的线性推进，把革命写成空间移动。每通过一个车厢，人物似乎扩大了可达空间；但最终发现列车整体的秩序、人口控制和周期性暴力早已把反抗吸收为系统维持机制的一部分。因此 Path Expansion 可以发生，而 System Exit 仍然为零。

### 可复用结构【被允许的突破】
```text
封闭系统 S
→ 人物从低位沿唯一通路突破
→ P_reachable 局部扩大
→ 接近中心 Authority
→ 发现突破路径本身属于 S 的控制模型
→ “抵达中心”不再等于“离开规则”
→ 真正破局必须改变系统边界或退出 Carrier
```

**关键结论：** Path Freedom 增加，不自动推出 Fate Freedom 增加。

# 维度关系提炼

## 空间 → 命运：两条不同链

R38 已有：
```text
Space
→ Recognition Repetition
→ Identity 收敛
→ Action Range缩小
→ Fate收敛
```

R39 新增一条不经过本体的直接链：
```text
Space
→ Access / Permission / Resource Gradient
→ Actionability差异
→ P_reachable差异
→ Fate收敛
```

所以“空间克命运”不能只看是否有墙，而要看空间是否改变了可达路径、资源和许可。

## 因果 → 空间：后果可以重新暴露真实位置

《寄生虫》的暴雨不是单纯灾难事件：同一个 Cause 在不同空间产生不同 Cost，反向显影人物真实所处的阶级位置。

```text
Same Cause
+ Different Spatial Position
→ Different Cost
→ Hidden Hierarchy显影
```

可称 **Differential Consequence｜差异后果**，暂作机制，不建字段。

# 可复用故事母题

### 1. 借来的上层空间
人物可以进入高资源区域，但进入权依赖别人随时可撤销的 Permission。

### 2. 被允许的革命
人物不断突破关卡，却最终发现整个突破路线本身就是系统设计的一部分。

### 3. 同灾不同命
同一个外部事件同时作用于所有人，但空间位置把相同 Cause 转译成完全不同的 Cost。

# ⑥ 本轮新增 / 修正结论

## A｜Access、Permission、Possession 必须拆开
```text
Access：此刻能否进入
Permission：进入权由谁授权、能否撤销
Possession：是否稳定控制该空间/资源
```

剧情中人物“进入新空间”时，不应自动判定空间自由提高。

## B｜新增：Spatial Mobility ≠ Fate Mobility
人物移动得很远，命运结构可能几乎没动。

判断命运变化，应看：
- P_reachable 是否真正增加；
- 新路径是否依赖可撤销 Permission；
- 是否改变资源梯度；
- 是否存在 System Exit。

## C｜修正 R38
R38 强调空间通过 Recognition→Identity 间接制造命运。本轮证明还有一条更直接的链：

```text
空间分配资源/许可
→ Actionability
→ 命运
```

因此空间→命运至少有 **Identity-mediated** 与 **Resource-mediated** 两型。

## D｜新增：同一 Cause 的主题强度可由空间差异显影
空间不必自己制造事件。只要让同一事件在不同位置产生巨大 Cost 差，就能把隐藏结构突然显影。这特别适合短片：一个事件即可同时承担剧情转折与主题证明。

## E｜对动态链的吸收
以后遇到“进入新区域 / 晋升 / 越狱 / 革命推进”时增加检查：
1. 是 Access 变化，还是 Possession 变化？
2. Permission 的 Carrier 是谁？
3. Permission 能否撤销？
4. 新空间是否真的增加 P_reachable？
5. 人物是在系统内移动，还是改变/退出系统边界？

本轮不修改 canonical 五维映射和正式生克，只补充空间→命运在电影 instance 中的具体中介机制。
