# 五维电影研究 R31｜不确定因果如何制造行动

> 状态：研究层增量，不覆盖五大主题 canonical 正本。
> 本轮目的：验证一个此前研究里相对薄弱的问题：故事是否必须先获得可靠 Cause，角色才能行动？

## 1｜《燃烧》 Burning (2018)

**核心五维：因果 × 空间 × 命运**

### 剧情设定
海美失踪，钟秀怀疑富裕而神秘的 Ben 与她的消失有关，却始终没有得到完整证据链。

### 真正的主题问题
当一个人承受了真实的失去，却无法获得足以裁决的原因时，他是在寻找真相，还是在制造一个能够承载愤怒的原因？

### 具体剧情机制
海美的失踪制造 Cost，但 Cause Source 始终不可稳定确认。Ben 的阶级位置、行为和若干可疑痕迹不断提高钟秀的怀疑显著性，却没有把“怀疑”升级成可靠因果。于是故事动力并非 `Cause → Action`，而是：

```text
Cost 已发生
→ Cause Source 不可达
→ 多个弱证据持续累积
→ Salience 上升，但 Reliability 不同步上升
→ 人物无法忍受责任真空
→ 选择一个可达对象作为 Blame Target
→ Action 反过来关闭继续求证的可能
```

### 可复用结构【责任真空 → 归罪收敛】
真正原因不可达时，人物并不会停止行动；相反，痛苦会推动因果解释向“最可达、最能承载意义的对象”收敛。

**修正：** `Actionability` 不要求 Cause 已被证明。角色只需要“当前解释足以越过行动阈值”。

## 2｜《严肃的男人》 A Serious Man (2009)

**核心五维：因果 × 命运 × 本体**

### 剧情设定
Larry 接连遭遇婚姻、工作、家庭、健康等危机，并不断寻找一个能解释“为什么这些事发生在我身上”的答案。

### 真正的主题问题
如果世界没有向人物提供可读的因果解释，人是否仍必须行动？“得到解释”究竟是解决问题的必要条件，还是人为了获得控制感提出的额外要求？

### 具体剧情机制
Larry 不断寻找解释 Carrier：宗教权威、伦理规则、职业制度、个人道德。但每个 Carrier 都只能提供局部或含混答案。外部事件仍继续发生，意味着：

```text
事件继续
→ 人物要求 Cause Explanation
→ Carrier 无法提供确定答案
→ Interpretation Pressure 上升
→ 行动窗口却继续缩短
→ 人物最终必须在解释不足时行动
```

### 可复用结构【解释迟于行动】

```text
Need-to-know
→ 求解
→ 无确定答案
→ Time.horizon 继续下降
→ “等理解以后再做”失效
→ 人物被迫以不完整模型行动
```

**新增：** 时间可以“克”因果解释：不是消灭 Cause，而是让人物失去继续等待完整 Cause Model 的时间。

# 三条一句话故事种子

1. **因果×命运**：一座城每天随机失踪一个人，所有证据都指向同一个从不说话的孩子；侦探越接近证明他无罪，市民越需要他有罪，因为只有这样失踪才像一件可以阻止的事。
2. **时间×因果**：一艘飞船将在十二小时后撞星，船员发现事故原因有七种互相冲突的解释，而每验证一种就要耗掉两小时，他们必须决定什么时候停止求真、开始下注。
3. **本体×因果**：一个女孩坚信父亲抛弃自己是因为不爱她，二十年后获得一百个互相矛盾的真相版本；她发现真正难改的不是过去，而是“被抛弃的人”这个身份已经替她活了二十年。

# 本轮新增 / 修正结论

## A｜因果主题必须区分 Cause Truth 与 Cause Model

```text
Cause Truth：实际发生了什么
Cause Model：人物当前相信什么导致了结果
```

剧情行动通常由 Cause Model 直接驱动，而不是由不可见的 Cause Truth 直接驱动。

因此动态链建议写：

```text
Observed Evidence
→ Cause Model
→ Threshold
→ Action
→ Feedback
→ Cause Model 更新 / 固化
```

而不是偷懒写成 `Cause → Action`。

## B｜新增机制：责任真空会主动吸引 Blame

当同时满足：
- Cost 强；
- Cause Source 不可达；
- Time / Emotion 不允许无限悬置；

系统会产生“归罪收敛”。这不是新一级字段，而是 `Cost + Cause Uncertainty + Blame Target + Threshold` 的组合机制。

## C｜时间克因果的新具体机制：解释窗口关闭

canonical 的“时间克因果”可以出现为：

```text
Cause Model 尚未完成
→ Time.horizon 下降
→ 继续求证的机会成本上升
→ 行动阈值先于真相阈值被越过
→ 人物在不完整因果下行动
```

这里“克”的不是客观因果存在，而是**人物建立完整因果模型的能力/机会**。

## D｜R24–R25 的 Actionability 再修正

旧链：
`Access → Salience → Actionability → Action`

本轮补充：

```text
Access
→ Salience
→ Cause Model（可能低可靠）
→ Actionability / Threshold
→ Action
```

**Reliability 影响“行动是否正确”，不必决定“行动是否发生”。**

## E｜新增可复用母题：解释迟于行动

人物最想先知道“为什么”，世界却要求他先决定“怎么办”。

这类故事天然制造：
- 因果与时间冲突；
- 责任误投；
- 事后意义回写；
- 本体因错误行动而改变。

# 对十元 / 动态链的吸收

1. 动态链增加 `Cause Truth / Cause Model` 双层，避免把角色认知当客观因果。
2. 生克补关系的判定仍落在目标变量：时间可以克“因果模型完成度”，而不是笼统写“时间把因果消灭”。
3. 对群像故事，可让多个角色共享同一个 Cost，却持有不同 Cause Model；冲突不必来自目标不同，也可以来自“解释不同”。
4. 结局不一定揭露 Cause Truth。也可以只显示：人物选择了哪个 Cause Model，以及这个选择制造了什么新因果。

# 与 canonical 的关系

本轮不修改固定映射与正式生克方向。正本仍为：
- 因果→本体→空间→时间→命运→因果；
- 因果克空间、空间克命运、命运克本体、本体克时间、时间克因果。

本轮只补充“时间克因果”在电影 instance 中的一种可观察机制：**解释窗口关闭**。
