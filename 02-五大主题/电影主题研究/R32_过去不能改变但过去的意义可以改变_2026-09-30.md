# 五维电影研究 R32｜过去不能改变，但过去的意义可以改变

> 状态：研究层增量，不覆盖五大主题 canonical 正本。
> 本轮目的：承接 R31 的 `Cause Truth / Cause Model`，继续验证一个更窄的问题：事件已经不可逆时，后来的信息是否还能真正改变故事？

## 1｜《晒后假日》 Aftersun (2022)

**核心五维：时间 × 因果 × 本体**

### 剧情设定
成年 Sophie 重新观看童年与父亲 Calum 度假的影像，并以成年后的经验重新理解那段共同生活。

### 真正的主题问题
当一个人终于拥有理解过去所需的经验时，过去已经无法挽回；那么迟到的理解还有没有真实作用？

### 具体剧情机制
童年 Sophie 拥有事件，却缺少解释能力；成年 Sophie 获得新的经验和信息，却失去修改事件的行动窗口。录像保存的是局部 Evidence，不是完整 Cause Truth。

```text
Event E 已发生
→ 当时 Cause Model 不完整
→ Time.horizon 对 E 归零
→ 新经验 / 新证据进入
→ Cause Model(E) 改写
→ E 本身不变
→ E 对当前 Internal Identity / Relationship Meaning 的作用改变
```

### 可复用结构【迟到理解】
角色不是回到过去修复事件，而是在无法 Undo 的条件下，重新理解自己曾经经历了什么。

这说明：

```text
Past State 不变
≠ Past Meaning 不变
```

时间关闭“改事件”的窗口，却可以打开“改解释”的窗口。

## 2｜《飞向太空》 Solaris (1972)

**核心五维：本体 × 因果 × 时间**

### 剧情设定
Solaris 海洋把 Kelvin 记忆中的亡妻 Hari 以实体形式重新制造出来；这个“访客”并不是原来的 Hari，却逐渐表现出自己的痛苦、欲望和连续经验。

### 真正的主题问题
如果一个存在由我的记忆和愧疚制造，但现在已经能够感受痛苦，我对她的责任来自她的“来源”，还是来自她当前真实存在的感受？

### 具体剧情机制
Kelvin 起初用 Origin 判定 Hari：她是复制物，因此“不是真的”。但随着新 Hari 持续形成自己的经验，原有身份判断开始失效。

```text
Memory / Guilt
→ Solaris 生成 Visitor
→ Origin Classification：她不是原 Hari
→ Visitor 产生新的 Persistence / Experience
→ 当前痛苦形成新的伦理 Cost
→ Responsibility 不再只由 Cause Source 决定
→ 本体判断从“从哪里来”转向“现在能否作为主体存在”
```

### 可复用结构【来源失效】
一个对象的来源决定它最初被如何分类，但持续经验可能产生新的本体证据，使“来源”不再足以决定“现在是什么”。

**新增修正：** `Cause Source ≠ Identity Authority`。制造某物的原因，不自动拥有定义它最终是什么的永久权力。

## 3｜《楚门的世界》 The Truman Show (1998)

**核心五维：空间 × 本体 × 命运**

### 剧情设定
Truman 一生生活在被制造、监视和控制的 Seahaven；他的关系、环境、恐惧和可达路径都被节目系统设计。

### 真正的主题问题
如果一个人的过去全部发生在人工世界里，那么知道“它是假的”之后，过去的感情和人生也会一起变假吗？

### 具体剧情机制
真相揭露没有把 Truman 的过去 Undo。它改变的是过去事件的解释权：原本被理解为自然生活的事件，被重新解释为控制、表演和操纵。随后新的 Cause Model 改变了他的 P_reachable 与 Identity-Admissibility，他开始把“离开”视为自己可以做的事。

```text
Constructed Space
→ 长期制造 Cause Model / Fear / Recognition
→ Glitch 提供反证
→ 旧解释失效
→ Past Meaning 被重写
→ Internal Identity 与 P_conceivable 改变
→ Escape 变得可行动
```

### 可复用结构【真相不是增加信息，而是重写旧人生】
真正强的 Reveal 不只是告诉人物一个新事实，而是让过去一百件旧事同时改变意义。

这类揭露的强度可近似理解为：

```text
Reveal Power
≈ 被新解释同时重写的旧事件数量 × 这些事件对本体的重要度
```

不是正式数学量，只作为故事设计启发。

# 三条一句话故事种子

1. **时间×本体**：一个女人在母亲死后二十年收到她每天写给自己的日记，才发现童年里所有“被冷落”的记忆其实都是母亲偷偷替她承担某种危险；她无法重新拥有母亲，却必须决定自己还要不要继续做那个“从未被爱过的人”。
2. **本体×因果**：一个魔法师用死去女儿的记忆造出替身，替身活了十年后要求继承女儿的名字；魔法师必须决定，创造原因究竟给了自己所有权，还是只制造了一个新的责任对象。
3. **空间×命运**：一个少年发现自己的村庄其实是为研究他而搭建的实验场，但村里唯一真正爱过他的女孩也是实验员；逃出去很容易，困难的是决定那段爱情究竟属于骗局，还是属于他真实活过的人生。

# 本轮新增 / 修正结论

## A｜正式区分 Event State 与 Event Meaning

```text
Event State：过去实际发生了什么
Event Meaning：这个事件在当前 Cause Model / Identity 中意味着什么
```

时间可以让 Event State 进入高 Irreversibility，但后续 Evidence 仍可以改变 Event Meaning。

因此“过去不可改变”只能推出：

```text
Undo(Event State) ≈ 0
```

不能推出：

```text
Rewrite(Event Meaning) = 0
```

## B｜R31 的 Cause Model 不只决定下一步行动，也会回写旧事件

R31：

```text
Evidence → Cause Model → Action
```

R32 补充：

```text
New Evidence
→ Cause Model 更新
→ Past Event Meaning 更新
→ Internal Identity / Relationship Meaning 更新
→ Future Action 改变
```

这形成一条“向后解释、向前行动”的链。

## C｜新增机制：Retrospective Causality｜回溯意义因果

不是未来真的改变过去，而是后来的信息改变过去事件在当前系统中的作用。

```text
E1 已发生
→ E2 提供新解释
→ Meaning(E1) 改变
→ E1 对当前状态的因果作用改变
```

先作为机制，不升一级字段。

## D｜Cause Source ≠ Identity Authority

对象由谁制造、从哪里产生，不等于制造者永久拥有本体解释权。

当对象形成自己的：
- Persistence；
- Feedback；
- Experience；
- Relationship；

它可能产生新的 Identity Evidence，使 Origin Classification 失效。

这对“本体”主题非常有用：**来源可以生本体，但不能保证永远裁定本体。**

## E｜新增可复用母题：高密度揭露

好的 Reveal 不只是增加一条新信息，而是：

```text
一个新事实
→ 同时重写多个旧事件
→ 多条 Cause Model 改写
→ Internal Identity 改写
→ P_conceivable / P_reachable 改写
```

所以“反转强度”更应该看它能回写多少旧结构，而不是看信息本身有多惊讶。

# 对十元 / 动态链的吸收

1. 动态链增加 `Event State / Event Meaning` 双层标注候选，防止把“事件没变”误判成“系统没变”。
2. `Cause Model` 允许双向作用：向前决定 Action，向后重写 Past Meaning。
3. 本体链增加 `Origin Classification → Current Identity Evidence` 的冲突结构；来源不是最终判词。
4. 对短故事特别有用的结构：先展示 2–4 个普通事件，后给一个 Reveal，让这些事件同时改义，比继续增加新事件更省体量。
5. 五维关系可出现：时间压制 Undo，但生成 Retrospective Meaning；因果模型更新生本体变化；空间制造的解释环境可通过 Reveal 被击穿。
