# 五维电影研究 R30｜外部命运不变时，自由从哪里发生？

> 状态：研究层增量，不覆盖五大主题 canonical 正本。
> 本轮目的：继续反例攻击“自由必须来自外部 P_reachable 扩大”。

## 1｜《别让我走》 Never Let Me Go (2010)

**核心五维：命运 × 本体 × 时间**

### 剧情设定
Kathy、Tommy、Ruth 从小被培养为器官捐献者，成年后的死亡路径几乎由制度预定。

### 真正的主题问题
如果外部结局几乎无法改变，人物还能不能拥有真正的选择？自由是否必须等于逃离命运？

### 剧情机制
制度几乎不提供逃逸路径；人物仍在友情、爱情、嫉妒、原谅、记忆和如何面对终点上持续作出选择。结局没有靠“推翻制度”替人物赎回自由，而把自由压缩到：无法选择终点时，仍能选择如何理解、承担和对待彼此。

### 可复用结构【固定终点 / 可变意义】
固定 Fate F → P_reachable 在宏观层面几乎不扩张 → 人物无法 Undo F → 关系/本体仍可变化 → Meaning 与 Action 在有限区间内重写 → 结局保持 F，但人物抵达方式改变。

**修正：** 外部命运不变 ≠ 人物没有自由。自由至少还存在“路径自由 / 关系自由 / 意义自由”。

## 2｜《银翼杀手》 Blade Runner (1982)

**核心五维：本体 × 命运 × 因果**

### 剧情设定
复制人被制造、役使，并拥有有限寿命；Deckard负责追捕逃亡复制人。

### 真正的主题问题
当“你是什么”由制造来源、寿命和社会分类决定时，人的价值是否也由来源决定？死亡不可改变时，什么行为最能证明本体？

### 剧情机制
Roy Batty无法真正战胜死亡期限，但在终点前救下追杀自己的 Deckard。外部 Fate 没有解除，行为却反向改写“复制人=工具/非人”的本体判断。于是因果上的一个行动成为本体证据，而不是生存成功的工具。

### 可复用结构【终点不变 / 本体翻案】
身份分类 R → 固定终点 F → 角色无法改变 F → 最后行动 A 不服务于逃生 → A 与既有身份判断矛盾 → A 成为新的 Identity Evidence → Fate 不变，本体解释改变。

**新增：** Action 可以不改变结果，却改变“这个结果证明了什么”。这是因果→本体的一种非结果型生成。

## 3｜《安然无恙》 Safe (1995)

**核心五维：空间 × 本体 × 因果**

### 剧情设定
Carol 出现无法明确解释的身体症状，从郊区家庭进入 Wrenwood 疗养社区；两个环境都提供一套关于“她为什么生病”的解释。

### 真正的主题问题
如果人物逃离了一个压迫空间，却只能进入另一套同样替她解释自身的空间，她获得的是自由，还是更舒适的归因牢笼？

### 剧情机制
空间变化明显，但解释权没有真正回到 Carol 手里。家庭/医疗环境倾向否认或心理化她的症状；Wrenwood 又提供“你自己造成疾病”的完整语言。角色获得了新空间，却仍通过外部话语理解自己。

### 可复用结构【换空间 / 不换解释权】
Space A 使人物失语 → 逃离 A → Space B 提供更完整的语言 → B 看似提高 Recognition → 但 Cause Interpretation 仍由外部 Carrier 垄断 → 人物学会用 B 的语言审查自己 → 空间改变，本体控制结构保持。

**修正 R29：** rewrite rule 之前还要问“谁拥有解释规则的作者权”。只从 A 规则换成 B 规则，不等于改写规则。

# 三条一句话故事种子

1. **命运×本体**：一群人出生时都知道自己三十岁必死，其中一个女孩不再寻找延寿方法，而开始调查为什么所有人都默认“三十岁前必须活成同一种人生”。
2. **因果×本体**：一个被制造来杀人的人无法解除体内倒计时，最后一次行动却是救下负责销毁他的人；他的死亡没有改变，却让“他是什么”第一次失去标准答案。
3. **空间×本体**：一个女孩逃出禁止表达情绪的城市，来到要求每个人每天公开全部情绪的自由城，最后发现她真正缺少的不是表达权，而是决定哪些感受不必被解释的权利。

# 本轮新增 / 修正结论

## A｜自由至少分三层

```text
Outcome Freedom：能否改变最终结果
Path Freedom：能否改变抵达结果的行动/关系路径
Meaning Freedom：能否改变结果对“我是谁/这意味着什么”的解释
```

因此：

```text
Outcome Freedom = 0
并不推出
Freedom = 0
```

《别让我走》和《银翼杀手》都说明，外部终点可以保持锁定，而 Path / Meaning 仍发生变化。

## B｜命运压制的对象不能只写 P_reachable

命运可能分别压制：
- Outcome：终点不可变；
- Path：过程被规定；
- Meaning：结果只能被一种方式解释。

三者不能混成一个“选择多少”。

## C｜新增候选机制：Interpretive Agency（解释作者权）

暂不升一级字段。

定义：角色是否有权决定事件、身份、痛苦和结果“意味着什么”。

优先检查它能否由既有 `Interpretation Pressure + Internal Identity + Recognition + Carrier` 表达。

## D｜因果不仅改变状态，也能改变证据意义

新增链型候选：

```text
Action A
→ Outcome 不变
→ A 成为新的 Identity Evidence
→ 旧本体解释失效
```

可称【Evidence Reversal / 证据翻转】，先作为机制，不建字段。

## E｜对 R29 的修正

R29 的 `rewrite rule` 仍成立，但增加前置判断：

```text
换规则 ≠ 获得规则作者权
```

如果人物只是从制度 A 的解释语法迁移到制度 B 的解释语法，属于 Rule Migration，不是 Rule Rewrite。

# 对十元 / 动态链的吸收

1. 动态链增加“结果是否改变”与“意义是否改变”的分离标注，避免把所有有效行动都写成状态变化。
2. 生/克/补判定继续坚持目标化：同一行动可对 Outcome 无效，却对 Internal Identity 产生“生”，对 External Recognition 产生“克”。
3. 命运链建议暂分：Convergent Fate（可达性收敛）、Categorical Fate（分类锁定）、Terminal Fate（终点锁定）。这三者是链型，不是命运总定义。
4. 破局操作从 `remove/exit Carrier`、`rewrite rule` 再补一个研究候选：`reclaim interpretation`，即外部结构不变，但人物夺回解释作者权。

# 与 canonical 的关系

本轮不修改五大主题固定映射与正式生克：

- 因果→本体→空间→时间→命运→因果
- 因果克空间、空间克命运、命运克本体、本体克时间、时间克因果

本轮只研究这些正式关系在电影 instance 中通过什么 Carrier、阈值、解释权与行动链显影。
