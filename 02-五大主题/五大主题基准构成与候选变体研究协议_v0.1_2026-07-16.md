# 五大主题基准构成与候选变体研究协议 v0.1

## 1. 当前正式状态

现行五组公式继续作为五大主题的基准构成使用：

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

当前只冻结以下结论：

```text
这五组是现行可工作的基准构成。
它们已经获得正本使用权。
尚未证明它们是唯一构成。
也尚未证明存在合法的非标准构成变体。
```

因此，现阶段不得把五组公式擅自升级为“唯一构成”，也不得因为发现一个相似案例就宣布存在“合法变体”。

## 2. 三种状态必须分开

### A. 基准构成

```text
已经进入正本；
可以用于现行理论表达；
可以作为案例分析、主题页与接口文档的默认构成；
不等于已经完成唯一性证明。
```

### B. 候选变体

```text
某个非标准十元组合可能解释同一高级主题；
尚未通过边界、反例与重复案例验证；
只能进入研究记录，不能改写正本；
不能直接参与人物本体、动态链或主题级结论。
```

### C. 非主题构成

```text
只是案例中的十元并列、互补、生克或阶段关系；
只解释人物、状态、行为、场景或时间结构；
没有形成高级主题构成的必要证据；
不得因为“看起来像某主题”而升级。
```

## 3. 候选变体的最低启动条件

一个非标准组合只有同时满足以下条件，才允许被记录为候选变体：

```text
1. 它解释的是高级主题结构，而不是表面关键词。
2. 人物本体、当前状态、行为功能、场景、光影与时间关系已经分层。
3. 该组合不是一次偶然共现，也不是某段动态链的临时端点。
4. 现行基准构成无法完整解释该案例中的稳定主题结构。
5. 新组合提供了额外解释力，而不是换一种符号复述同一句话。
6. 至少存在一个可被反驳的边界条件。
```

任一条件不满足，候选不得启动。

## 4. 候选变体的验证门槛

候选变体进入正本前，至少必须经过：

```text
跨案例重复：
不依赖单一作品、单一角色或单一场景。

层级稳定：
换掉服装、职业、道具、光影与表面场景后，主题结构仍成立。

阶段稳定：
不是某一刻的状态或行为，而能跨阶段解释主题问题。

边界排除：
能够说明它为什么不是普通十元互补、生克、并列或动态链。

基准比较：
明确说明它相对现行基准构成新增了什么解释力。

污染测试：
不能导致“任何十元组合都能生成任何主题”。
```

在这些验证完成前，正式写法只能是：

```text
候选变体，未进入正本。
```

## 5. 案例分析中的使用规则

### 允许

```text
主题层：
先用现行基准构成与主题最小定义分析。

十元层：
分别判断人物本体、状态、行为、场景和时间结构。

研究层：
若基准解释出现稳定缺口，再记录候选变体。
```

### 禁止

```text
因人物具有两个十元，就宣布生成某主题。
因场景或光影像某主题，就改写主题构成。
因一次行为不符合基准，就宣布存在变体。
因候选变体出现，就反向改写人物稳定本体。
因主题关系成立，就推导唯一的十元构成。
```

## 6. 人物核心锚点规则

研究主题构成时，人物稳定本体优先保持不变。

变化优先落在：

```text
当前状态
行为功能
关系位置
场景承载
时间结构
显影强度
动态链阶段
```

候选变体不得被用作修改人物核心锚点的捷径。

## 7. 三元与十元的关系

```text
三元与十元并行判断。
三元不是十元的父级。
十元不是三元的子类。
主题构成公式不承担三元派生功能。
候选变体也不得通过三元比例直接生成。
```

若三元判断、十元判断与主题构成研究发生冲突，应返回各自原始证据重新分层，不得让任一层为了配合另一层而改答案。

## 8. 当前研究顺序

候选变体研究采用以下顺序：

```text
先确认高级主题问题是否成立
→ 再拆人物本体、状态、行为、场景、光影、时间关系
→ 再判断十元层关系
→ 再检查现行基准构成是否存在稳定解释缺口
→ 最后才允许提出候选变体
```

不得从十元组合外形直接跳到主题构成。

## 9. 当前冻结结论

```text
五组公式继续作为现行基准构成。
唯一性暂不宣称。
变体可能性暂不否定。
候选变体不拥有正本权。
候选必须通过跨案例、层级、阶段、边界、基准比较与污染测试。
研究过程不得改写人物稳定本体，也不得混淆状态、行为、场景、光影与时间关系。
三元与十元继续并行，不构成父子派生。
```
