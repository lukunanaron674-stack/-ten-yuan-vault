# 本体 (zn + x)

## 一、定義深化

本體是 **存在與屬性的根基**——探討「是什麼」。

它不問「為什麼」（因果）、不問「走向何方」（命運）。本體只問一件事：**這個東西的本質是什麼？**

本體的底層張力來自兩股力量的辯證：
- **zn（陽火·精神）**：意義、信念、精神核心、價值歸宿——實體本身的存在性
- **x（陰水·深慾）**：慾望、佔有、深層驅動、失控強度——可被感知的屬性系統

zn 是「本質的內核」，x 是「本質的陰影」。本體不是靜態的標籤，而是 zn 追求純粹與 x 吞噬純粹之間的動態平衡。

---

## 二、雙元互動機制

### zn（陽火）→ 精神力
```
核心屬性：意義、信念、精神核心、價值歸宿
動能方向：向上昇華，追求純粹的存在
表現：角色的信仰、作品的中心思想、不變的本質
```
zn 像燈塔——提供方向和意義。但它也是一個「不能默認起手」的位——不是所有角色都需要有精神核心。

### x（陰水）→ 深慾力
```
核心屬性：慾望、佔有、深層驅動、失控強度
動能方向：向下潛藏，吞噬一切純粹
表現：隱藏的私慾、無法控制的佔有、崩壞的根源
```
x 像深渊——看似平静的水面下是吞噬一切的暗流。它不是 xn（主动判断、计划与计算）形成的结构，而是**原始的本能驱动**。

### 互動張力
```
zn ──昇華──→ ──本質── ←──吞噬── x
   │                      │
   精神核心              深層驅動
   │                      │
   └─── 本體辯證 ────────┘
```

本體敘事的三種模式：
1. **zn 主導**：角色/作品在追求或維護某種精神核心（如《斷背山》的愛的本質）
2. **x 吞噬 zn**：精神被慾望吞噬，走向崩壞（如《色戒》的情感與任務的衝突）
3. **zn 與 x 共存**：本體是矛盾體，同時容納高尚與卑劣（如《教父》邁克的命運）
4. **x 反噬自身**：慾望擴張到極致後自我毀滅（如《2046》的周慕雲）

## 三、領域映射

### 電影領域

| 層次 | zn 表現 | x 表現 | 經典案例 |
|------|---------|---------|---------|
| 劇情結構 | 角色尋找/確認自我、身份危機 | 慾望驅動的衝突、失控的連鎖 | 《臥虎藏龍》玉嬌龍的矛盾 |
| 角色弧線 | 角色揭示本質而非改變 | 角色墮落或被慾望吞噬 | 《All of Us Strangers》身份的重新確認 |
| 視聽語言 | 象徵性的視覺母題、重複出現的圖騰 | 壓抑的色調、慾望的暗示性畫面 | 《燃燒》的塑料棚 |
| 情感基調 | 存在主義的寧靜、本真感 | 窒息感、失控感、墮落的快感 | 《日瓦戈醫生》的詩意與壓抑 |

### 角色原型

| 角色類型 | zn 驅動 | x 驅動 | 範例 |
|---------|---------|---------|------|
| 聖徒/殉道者 | 堅守信念、為意義獻身 | (被壓抑的)潛在慾望 | 《黑暗騎士》蝙蝠俠 |
| 墮落者 | 曾經有信念，後來失去 | 被深慾吞噬 | 《教父2》年輕邁克 |
| 探索者 | 追問「我是誰」 | 發現自己內心的陰暗 | 《臥虎藏龍》李慕白 |
| 反英雄 | 有自己的(扭曲的)信念 | 被慾望驅動但保持自我 | 《小丑》亞瑟 |

### 現實領域映射

| 現實場景 | zn 感 | x 感 |
|---------|-------|------|
| 身份 | 自我認同、價值觀、信仰 | 私慾、佔有慾、控制慾 |
| 關係 | 無條件的愛、犧牲 | 嫉妒、佔有、利用 |
| 職業 | 使命感、匠人精神 | 權力慾、金錢慾 |
| 心理 | 尋找人生意義 | 慾望與道德的衝突 |

### 本體特徵判別清單

☐ 故事的核心是「這是什麼」或「我是誰」
☐ 角色有明確的精神核心或信念（zn）
☐ 存在深層慾望或原始驅動（x）
☐ zn 與 x 之間存在衝突或張力
☐ 結局帶有本質揭示感——不是事情結束了，而是本質被看見了
☐ 故事的核心問題在本質層面得到回答

> 命中 4 項以上 → 本體型為主
> 命中 2-3 項 → 本體為輔助主題
> 命中 1 項以下 → 非本體型

## 五、判定指南

### 與其他主題的區分

| 易混淆主題 | 本體 vs 該主題 | 關鍵問句 |
|-----------|---------------|---------|
| 命運 (xz+nz) | 本體是靜態的本質，命運是動態的過程。本體不變化。 | 角色是在揭示本質還是在走向命運？ |
| 因果 (zx+nx) | 本體不問為什麼，只問是什麼。因果需要邏輯鏈。 | 故事的核心問題是「為什麼」還是「是什麼」？ |
| 空間 (x並z+n) | 本體是內在的，空間是外在的。本體在角色內部。 | 問題在角色內部還是外部環境？ |

### 常見誤判

- ❌ 把角色的「成長」全判為本體 → 成長可能是時間的變化而非本質的揭示
- ❌ 把有信念的角色全判為本體 → 信念(zn)只是本體的一半，還需要 x(深慾)的對抗
- ❌ 忽略 x(深慾) 的作用 → 沒有 x 的本體只是口號，不是故事
- ❌ 把悲劇當本體 → 悲劇可以是因果或命運的結果

## 六、生補克關係

### 本體在五大主題中的位置

```
           空間 (x並z+n)
              │
              │ 生 (空間容納本體)
              ▼
   時間 ◄─── 本體 ────► 命運
   (xn+z)    │    (xz+nz)
              │ 克 (本體否定命運的變化)
              ▼
            因果 (zx+nx)
```

- **被生於**：空間 (x並z+n) → 空間提供本體存在的場域
- **生向**：時間 (xn+z) → 本體在時間中展開
- **克**：命運 (xz+nz) → 本體的永恆否定命運的變化
- **被克**：因果 (zx+nx) → 因果鏈條消解本體的超越性

### 生補克細節（十元層）
- zn → 生 → n（精神落地為承載）
- x → 生 → x並z（深慾需要包裝）
- zn → 靈魂對子 ← x（精神之火需要原始深慾為燃料）
- zn → 克 → xn（熱情擊碎規則）
- x → 克 → z（深層利己淹沒單純執念）
