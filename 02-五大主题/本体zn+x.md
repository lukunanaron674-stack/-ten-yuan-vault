# 本体（zn + x）

## 一、主题层最小定义

本体是对象在变化、关系和表现之中仍被识别为其自身的存在核心与根本性质。

核心问题：

```text
它究竟是什么？
哪些变化只是表现变化？
哪些变化已经触及存在核心？
```

本体主题不等于角色有性格、有信念、有欲望或说出“我是谁”。这些只能成为具体证据候选。

只有当作品不断逼近、揭示、维护、否定或重构某个对象的存在核心，并在关键转折、高潮或结局中回答“它到底是什么”时，本体才结构性显影。

## 二、十元构成位置

```text
本体：zn + x
```

这里的 `zn` 与 `x` 都是十元点位。

该公式属于主题生成系统预设的构成位置，不表示每个本体主题案例都必须找到一个 `zn` 人物与一个 `x` 人物，也不表示两个十元同时出现就自动生成本体主题。

正式生成机制：

```text
主题系统预设 zn 与 x
↓
主题生成系统以统一的关系层 z 补合
↓
形成“本体”这一高级主题符号
```

具体案例中的 `zn` 与 `x` 若同时显影，只在十元层发生互补、生克或并列，不能冒充主题生成过程。

## 三、主题显影证据

### 背景存在

```text
角色有个性
角色有信念或欲望
剧情涉及身份、姓名、职业或过去
台词出现“我是谁”
```

这些都不能单独证明本体主题。

### 局部或次主题

某个场景、支线或人物关系短暂逼近对象本质，或为主主题提供本质对照，但不组织整部作品。

### 主主题

至少需要结构性满足：

```text
中心问题围绕对象的存在核心或根本性质；
关键转折不断揭示、动摇、遮蔽或重构这个核心；
高潮或结局给出本质性回答，而不只是事件结束；
替换这个本体问题后，作品核心结构会根本变化。
```

不得用“信念 + 欲望”是否同时出现来机械判定。

## 四、与其他主题的边界

```text
本体：它究竟是什么。
时间：它怎样从之前走到之后。
命运：它最终走向哪里。
因果：什么导致它成为现在这样。
空间：它能够在哪里存在并如何与其他对象共处。
```

人物成长不必然是本体，成长可能主要属于时间；人物归宿不必然是本体，归宿可能主要属于命运。

## 五、正式生克位置

### 生

```text
因果 生 本体
本体 生 空间
```

解释层级：

- 因果链让对象的来源、责任与形成过程可被追溯，从而使本质被揭示，因此因果生本体；
- 对象的根本性质决定它能够进入、建立或承受怎样的空间，因此本体生空间。

### 克

```text
命运 克 本体
本体 克 时间
```

解释层级：

- 不可逆的去向与归宿可能覆盖、扭曲或迫使对象改变原有本质，因此命运克本体；
- 稳定的本质判断会压缩变化、阶段和流动的解释权，因此本体克时间。

这些属于主题级关系，不自动对应固定十元对子。

## 六、人物核心锚点规则

本体主题尤其不能把人物的状态变化当作人物本体变化。

必须拆开：

```text
人物稳定本体
当前状态
关键行为
关系位置
外部场景
时间结构
视觉与光影
主题层本体问题
十元层生克补
```

除非作品明确完成存在方式的整体重构，否则人物一次服从、爆发、堕落、牺牲、算计或视觉变化，都不能直接改写人物核心锚点。

## 七、旧内容处理

旧版以下内容全部降级为历史材料：

```text
用“精神 + 深欲”直接定义本体主题；
用角色有信念、有欲望来累计命中数；
把身份台词、象征物、暗色光影直接判成本体；
把具体人物十元冲突当作本体主题生成机制；
旧主题关系图中与正式生克盘不一致的方向。
```

旧案例可继续作为待复验材料，但必须按 [[五大主题显影与判定协议_v1.0_2026-07-16]] 重新判断。

## 八、调用模板

```text
主题层：
- 本体是背景、局部、次主题还是主主题？
- 作品究竟在追问谁或什么的本质？
- 高潮或结局给出了什么本质答案？
- 本体是否正在生出空间，或克制时间？

十元层：
- 人物本体、状态、行为、场景分别是什么十元？
- 十元层发生了什么生、克、补？

稳定锚点：
- 哪些只是状态变化？
- 哪些证据足以说明存在核心真的被重构？
```
