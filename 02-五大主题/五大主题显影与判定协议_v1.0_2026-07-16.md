# 五大主题显影与判定协议 v1.0

## 1. 判定对象

五大主题是由专门的主题生成系统统一补合后形成的高级符号：

```text
空间
时间
命运
因果
本体
```

具体故事不是重新生成主题，而是在人物、状态、行为、场景、时间结构和动态链中承载、显影和实现这些既有主题。

主题判定不得用单一关键词、道具、职业、场景外观、光影或某个十元标签直接完成。

## 2. 五大主题最小定义

```text
空间：
对象如何被放置、容纳、分隔、并存并建立边界的位置结构。
核心问题：什么能够在哪里存在，彼此如何共处或受限？

时间：
变化如何按先后、持续、积累、循环或阶段展开的进程结构。
核心问题：事物怎样从之前走到之后，什么被时间改变或保留？

命运：
多种可能在推进中逐步收束为某种去向、归宿或不可逆结果的方向结构。
核心问题：这一切最终走向哪里？

因果：
前因经过作用链产生后果，并使结果具有来源、责任与可追溯性的联系结构。
核心问题：什么导致了什么？

本体：
对象在变化、关系与表现之中仍被识别为其自身的存在核心与根本性质。
核心问题：它究竟是什么？
```

这些定义属于主题层，不是十元定义的改写，也不能反向证明具体人物本体。

## 3. 显影等级

### 0级：背景存在

主题只是故事必然具有的媒介或条件。

```text
有场景，不等于空间主题。
有先后，不等于时间主题。
有结果，不等于命运主题。
有因果，不等于因果主题。
有角色性格，不等于本体主题。
```

移除或替换该主题的具体表现，不会改变中心冲突、关键选择、高潮与结局结构。

### 1级：局部主题

主题支配一个场景、段落、支线或阶段，并改变局部选择或局部结果，但不组织整部作品。

局部主题可以很强，却不自动升级为整部作品的主主题。

### 2级：次主题

主题反复参与关键选择、转折或人物关系，并持续影响主主题的发展，但不是作品最终要回答的最高问题。

次主题通常承担：

```text
支撑主主题
限制主主题
把主主题推向下一阶段
提供对照或反证
```

### 3级：主主题

主主题必须同时满足结构性证据：

```text
作品的中心问题主要由该主题提出；
关键转折反复改变该主题的状态；
高潮或结局对该主题给出决定性回答；
替换该主题后，整部作品的核心结构会发生根本变化。
```

不得用“命中几个关键词”的计数法判主主题。

## 4. 主题显影的证据优先级

从高到低：

```text
高潮与结局回答了什么
关键转折改变了什么
人物重大选择在处理什么
关系与动态链长期压向哪里
场景和时间结构怎样承载主题
视觉、光影、道具和台词提供什么辅助提示
```

低层证据只能辅助高层证据，不能反向统治判定。

## 5. 主题级生克启动标准

两个主题同时存在，不等于主题生克已经启动。

主题级关系成立，必须出现方向性的结构作用：

```text
生：
源主题为目标主题提供成立、展开、积累或进入下一阶段的条件。

克：
源主题压缩、限制、改写或破坏目标主题能够继续成立和展开的条件。
```

至少需要满足：

```text
源主题与目标主题均有结构性显影；
方向明确，不能正反两种说法都成立；
源主题确实改变了目标主题的能力、边界、路径或答案；
这种改变出现在一个决定性转折，或通过多个阶段持续累积；
能够指出具体承载它的人物、状态、行为、场景或时间结构。
```

## 6. 正式生克盘

### 生环

```text
空间 生 时间
时间 生 命运
命运 生 因果
因果 生 本体
本体 生 空间
```

### 克环

```text
空间 克 命运
命运 克 本体
本体 克 时间
时间 克 因果
因果 克 空间
```

方向以 [[五大主题生克盘_v1.0_2026-07-16]] 为准。

## 7. 十元互补与主题承载并列书写

同一案例可以同时存在：

```text
主题层：
作品承载某个五大主题，并发生主题级生克。

十元层：
具体人物、状态、行为、场景或时间结构发生十元生、克、补。
```

两层必须分别写清端点。

示例格式：

```text
主题层：
因果 x 空间。

十元层：
人物A的某项行为（十元）克制场景B的某项结构（十元）。
```

禁止写成：

```text
因果克空间
所以人物A必然是某个固定十元。
```

也禁止写成：

```text
两个十元互补
所以五大主题自动生成。
```

## 8. 剧本与人物稳定规则

人物稳定本体优先保持不变。

主题显影变化优先落在：

```text
当前状态
行为功能
关系位置
场景承载
时间结构
体量与显影强度
动态链顺序
```

场景、光影、服装、职业、道具、一次服从或一次爆发不能越级改写人物核心锚点。
