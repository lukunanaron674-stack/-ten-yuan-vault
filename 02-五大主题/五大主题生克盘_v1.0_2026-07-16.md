# 五大主题生克盘 v1.0

## 一、正式生环

```text
空间 生 时间
时间 生 命运
命运 生 因果
因果 生 本体
本体 生 空间
```

闭环写法：

```text
空间 → 时间 → 命运 → 因果 → 本体 → 空间
```

关系符号：

```text
空间 n 时间
时间 n 命运
命运 n 因果
因果 n 本体
本体 n 空间
```

## 二、正式克环

```text
空间 克 命运
命运 克 本体
本体 克 时间
时间 克 因果
因果 克 空间
```

闭环写法：

```text
空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

关系符号：

```text
空间 x 命运
命运 x 本体
本体 x 时间
时间 x 因果
因果 x 空间
```

## 三、关系区说明

五大主题是高级符号系统。主题成立后，主题与主题之间只按关系层的：

```text
n = 生
x = 克
```

进行观察。

关系层的 `z = 补 / 补合` 不属于主题间生克盘，而属于五大主题生成系统。

## 四、旧盘覆盖

凡旧主题单页、旧图、旧案例出现与本盘方向不一致的关系，一律以本盘为准。

尤其覆盖：

```text
旧：空间克因果
现：因果克空间
```

以及其他未按本盘排列的旧生克方向。

## 五、调用限制

本盘只确定五大主题之间的正式生克方向，不自动证明具体人物、状态、行为、场景或时间结构的十元关系。

具体案例仍需区分：

```text
人物稳定本体
当前状态
关键行为
外部场景
时间关系 / 时间结构
视觉与光影
十元动态链
```

不得由主题级生克直接改写人物核心锚点。
