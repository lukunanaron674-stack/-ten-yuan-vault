# 运行记录｜凯撒越卢比孔：P1 已关闭，不得冒充“可用许可路线被主动绕过”的第三正例

## 0｜本轮研究问题

现有高成本内部绕行已经有两份高纯正向控制：

1. 关羽五关：正常文凭/关卡许可路线与高成本武力通行路线形成对照；
2. 甘地丹迪取盐：殖民垄断购买路线与海边自行取盐形成对照。

二者共同支持：

> 主体若真实采用高成本 P2，P2 不依赖等价外部许可/关系/关键资源持有人，并实现同一结果对象，则当前 P1 的 nx 可以退出。

凯撒越卢比孔表面极像第三份：不等元老院批准，直接率自己的军团进入意大利。

本轮专门检查：它能否无条件并入同一“可用 P1 被主动绕过”模板。

结论：**不能直接并入。**

## 1｜事实、触发、对象、动作、结果

### 1.1 旧军权与调用资源

凯撒此前经共和国政治法律机制获得高卢等行省军权。授权完成以后，军团和行省军事事务已进入其稳定调用边界，属于局部 `x`。

因此在前49年的窄窗口中，第十三军团不是一个必须重新向独立外部节点借来的关键资源。

### 1.2 当前触发：外部许可不是“仍开放但未使用”

前49年政治危机中，元老院要求凯撒解除军权、交出军团并以私人身份返回。

所以当前合法方向是：

```text
解除军权
→ 不再以现有统帅身份带军进入意大利
```

而不是：

```text
存在一个当前开放的正常申请接口
→ 凯撒可以申请携军入意大利
→ 但他嫌麻烦而选择不用
```

这一区别是本轮核心。

### 1.3 明确动作与结果

凯撒没有沿“解除军权”方向推进，而是率第十三军团越过卢比孔进入意大利，并继续推进。此举触发共和国政治军事体系的公开重排和内战。

窄结果对象可以写为：

> R = 凯撒带着现有军团进入意大利。

R 确实由主体依靠既有可直接调用军团完成，没有通过新的元老院许可。

## 2｜zx 判断

本阶段 `zx` 沿用既有 99/98 锁定，不因本轮重做而降级。

证据不是“凯撒野心大”或“他敢违法”，而是：

1. 主体拒绝外部要求的解除军权方向；
2. 自身既有军事实力公开压入原授权外的意大利对象域；
3. 原政治军事节点被迫响应、撤离、重排；
4. 主体影响与决定范围从行省军权推进到意大利核心政治空间。

符合 zx 准度卡：自身权能公开进入现实、外部秩序真实响应、决定范围上升。

## 3｜nx 判断

### 3.1 历史授权入口：曾经存在 nx

高卢军权最初来自共和国制度授权，这一入口可以锁 `nx`。

### 3.2 当前越卢比孔执行窗口：nx 排除为主判

当前行动并未沿元老院给出的“解除军权”方向推进，也没有重新请求并获得携军入意大利的外部许可。

因此：

`nx_current_execution: rejected_as_primary`

但必须注意：

> **排除当前 nx，不等于本例自动满足“可用 P1 主动绕过”的实验模板。**

因为本窗口中的旧许可已经被撤回/反转。

## 4｜关键压力

关键压力不是战争危险本身，而是：

```text
旧 x 仍可被主体调用
+
上位制度明确要求终止这块权力
+
主体想实现的新结果需要越过旧授权边界
+
当前不存在一个已经开放、可正常沿用的“携军入意大利”许可 P1
```

这和甘地“合法购买盐渠道仍存在但不用”、以及关羽“许可/关卡体系作为正常通行接口存在但主体不走”的结构并不完全同型。

## 5｜拿掉测试

### 拿掉新的元老院许可

原事实链仍成立。凯撒没有依赖新的外部批准完成越界。

→ 支持当前执行层 `nx` 排除。

### 拿掉凯撒既有军团调用能力

如果凯撒无法直接调用第十三军团，又不获得新的外部军力/许可，则“带军进入意大利”无法按原链完成。

→ 当前结果真正依赖的是已经内化为局部 `x` 的军团调用资源。

### 拿掉“元老院已关闭旧授权”这一事实

如果改写成元老院仍提供一个正常、当前可用的携军入意大利许可接口，那么才可以把本例直接拿去和关羽/甘地做“可用 P1 vs 自有 P2”的同型实验。

→ **P1 当前可用性是第三正例资格的一道必要控制变量。**

## 6｜反向测试

### 6.1 真正的“可用 P1 主动绕过”版本

若出现：

```text
元老院存在当前可用的正常携军入意大利批准流程
→ 凯撒可以现实使用
→ 但主动不使用
→ 直接凭已有军团完成同一进入结果
```

才与关羽 / 甘地的实验问题高度同型。

### 6.2 当前原事实

```text
旧授权被要求终止
→ P1 当前关闭/反转
→ 凯撒仍以既有 x 军团资源完成 R
```

只能证明：

> **许可接口被关闭后，只要主体已有稳定内部资源可实现同一结果，当前 nx 不必继续成立。**

但它不能单独证明：

> **一个仍开放、可用的外部接口，即使存在，也因为主体有高成本 P2 就必然退出。**

## 7｜最近邻排除

### nx vs x

第十三军团在该窄阶段已经是凯撒稳定可直接调用的局部军事资源，优先 `x`；不能因为军团由许多人组成就重复计 `nx`。

### nx vs xn

越界、行军、占领路线有明显 `xn` 组织邻近，但“如何组织行军”不能替代“关键军力是否仍须从外部接口获得”的检查。

### nx vs zx

当前 nx 排除不会自动产生 zx。凯撒之所以另有 zx，是因为军力公开进入新对象域、外部体系被迫重排、决定范围真实上升。

### 违法/违令 vs zx

违法本身仍不是 zx。若主体越界后立刻被压回、没有新对象域现实生效，只能说明违法尝试。

## 8｜第三因素冻结

冻结：

- 凯撒人格、野心与后世评价；
- 庞培个人能力；
- 内战最终胜负；
- 罗马共和国是否“应当”支持哪一方；
- “越过卢比孔”后世象征意义。

只保留：

1. 旧军团是否已进入凯撒稳定调用边界；
2. 元老院是否要求终止旧军权；
3. 当前是否存在开放可用的正常携军许可 P1；
4. 凯撒是否实际依赖新的外部许可；
5. 同一“携军进入意大利”结果是否由既有内部资源实现。

结论仍稳定。

## 9｜与关羽、甘地的最小差异

| 检查项 | 关羽五关 | 甘地丹迪取盐 | 凯撒卢比孔 |
|---|---|---|---|
| 正常外部接口类型 | 文凭/关卡许可 | 殖民盐购买/垄断资源 | 共和国军权/进入意大利的合法许可结构 |
| P1 当前是否作为正常路线开放 | 是/可作为正常关卡路线 | 是，合法购买仍存在 | **否，旧军权已被要求终止** |
| 主体是否使用 P1 | 否 | 否 | 否 |
| P2 是否依赖等价外部关键接口 | 否 | 否 | 否，依靠既有可调用军团 |
| 同一窄结果是否实现 | 是 | 是 | 是 |
| 可直接计入“可用P1主动绕行”正例 | 是 | 是 | **否** |

## 10｜本轮新增护栏

正式锁定以下案例级纪律：

> **高成本内部绕行压力测试必须区分“P1 当前开放可用但主体主动不走”与“P1 已被撤回、关闭或反转”。后者可以证明当前 nx 不再运行，也可以证明主体依靠内部 x/xn/zx 继续实现结果；但不能直接拿来充当‘可用 P1 主动绕过’的第三正例。**

最短检查：

```text
先问 P1 现在还能不能正常走。

能走但我不用
→ 才测试主动绕行。

已经被关掉/撤回
→ 测的是通道失效后的内部续行，属于另一机制。
```
