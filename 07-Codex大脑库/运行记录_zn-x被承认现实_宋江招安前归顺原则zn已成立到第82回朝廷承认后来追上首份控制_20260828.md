# 运行记录｜宋江招安前 zn 已成立，到第82回外部承认才追上：首份“被承认 vs 真正成立”控制

## 1｜本轮问题

本轮不重新判宋江整个人物，也不把“忠义”“招安派”“朝廷官员”这些标签直接当作火轴结论，只测试一个窄变量：

> **宋江“最终仍要保留合法回返 / 归顺朝廷的未来资格”这一 `zn`，究竟是在第82回朝廷正式招安、公开承认以后才成立，还是在没有官方承认、甚至仍是罪犯 / 梁山首领时就已经独立成立？**

如果后者成立，则可锁：

> **外部承认可以追上一个已经成立的 `zn`，但不能被倒写成该 `zn` 的时间起点或充分条件。**

本轮不把第82回“受招安”自动判为新的 `x`；名位、诏书与认可是否进一步形成现实官方处分 `x`，必须另看后续真实职事、调用和处分证据。

## 2｜剧情事实链

### 阶段 A｜官方承认缺席，zn 已进入高代价排序

《水浒传》第36回：宋江旧郓城公务 `x` 已失，处于杀惜后逃亡 / 刺配链。梁山方面试图强留他入伙时，他拒绝杀防送公人、拒绝擅自开枷，坚持赴江州接受官府处分，并以“国家法度”“不忠不孝”等理由说明自己的边界。

此时：

```text
朝廷正式承认 / 招安：无
官位奖励：无
现实成本：有（刺配、受刑、失去自由）
归顺 / 合法回返原则：已进入排序
```

### 阶段 B｜仍未受招安，原则再次公开高调用

第71回梁山排定座次以后，宋江已经掌握完全不同的新梁山组织 / 军事 `x`，但仍公开祈求朝廷赦罪招安，并提出受招安后“尽忠报国”。菊花会中，他又明确主张“早招安”，即使武松、李逵、鲁智深等人反对，仍不撤回最高方向。

这一步非常重要：

```text
没有官方承认
+
主体已经拥有可替代现实权力（梁山 x）
+
内部还存在同伴反对成本
→ 同一归顺原则仍继续指导未来方向
```

因此该 `zn` 不能由后来的朝廷承认倒推生成。

### 阶段 C｜第82回外部承认终于到位

第82回，宋徽宗正式命宿太尉赍御笔丹诏前往梁山招安。诏书本身还明确概括宋江等“归顺之心已久”；宋江接到确切消息后大喜，组织迎诏，随后正式受诏谢恩。

此时发生的是：

```text
此前内部未来方向 / 原则 zn 已存在
→ 外部最高权威终于承认并允许该方向现实兑现
```

不是：

```text
第82回被承认
→ 才第一次生成 zn
```

## 3｜zn 证据

本轮沿用 current canonical，把 `zn` 限定为：

> **即使现实上被逐出原秩序、暂居梁山甚至掌握强大武力，也不把“永久草寇化”视为最终政治 / 法理归属；保留并追求未来合法回返、归顺与报国资格。**

该原则通过当前硬门：

1. **对象明确**：最终政治 / 法理归属与未来回返资格。
2. **无奖励 / 承认时仍进入判断**：第36回没有官位奖励，反而承担刺配代价。
3. **冲突排序**：梁山强留、现实安全、同伴反对都没有直接替换最高方向。
4. **跨阶段未来调用**：第36回 → 第71回 → 第82回持续出现。
5. **让渡边界可说明**：可以暂时逃亡、上梁山、使用梁山武力，但不接受“永久把草寇身份当最终归属”。
6. **外部承认到来以前已过门**：第82回不能作为 `zn` 起点。

因此本窄原则对象层：`zn = true`。

## 4｜x 检查

本轮不把“受招安”“金银牌面”“丹诏”“忠臣称号”直接判 `x`。

current `x` 仍要求：

```text
明确现实对象
+
主体可以稳定占有 / 调用 / 处分 / 否决 / 排除
+
不是纯名义或一次接触
```

所以：

- 第71回梁山军事 / 组织 `x` 可沿既有生命周期记录成立；
- 第82回朝廷正式承认只证明外部认可与身份关系发生变化；
- 是否形成新的“官方军政 `x`”，需要另看第83回以后是否真实取得并持续行使官方职事与处分权限，本轮不提前锁。

这能避免把“被承认”与“现实掌握”混为一谈。

## 5｜关键本体变量

本轮真正检查的不是“宋江身份叫什么”，而是：

```text
内部原则是否已经独立成立？
↓
外部权威什么时候开始承认它？
↓
承认到来以前，原则有没有在无奖励 / 高代价条件下真实指导选择？
```

若有，则：

> **被承认的时间 ≠ 本体原则真正成立的时间。**

## 6｜拿掉测试

### 拿掉第82回朝廷承认

只保留第36回和第71回：

- 宋江仍在没有官方承认时按合法回返 / 归顺方向排序；
- 该 `zn` 仍可独立成立。

因此官方承认不是该 `zn` 的必要条件。

### 拿掉此前 zn，只保留第82回承认

如果一个人物此前从未在无奖励 / 高代价冲突里保留该原则，只是在正式受诏、得到赦罪与新身份后才表态“忠于朝廷”，则不能仅凭第82回式外部认可倒推内部 `zn` 已成立；应继续检查 `z / x / nx / xn` 等邻近结构。

因此官方承认也不是 `zn` 的充分条件。

## 7｜反向测试

若剧情改成：

```text
受招安前：
主体完全不追求合法回返，甚至稳定以永久草寇化作为最终原则

受招安后：
仅因为赦罪、官位、奖励与皇帝认可
才第一次改口忠于朝廷
```

则应优先判“外部认可 / 奖励引发状态变化”，不能把受承认后的表态直接回填成此前已存在的 `zn`。

原著宋江不符合这个反向结构。

## 8｜最近邻排除

- `zn vs z`：第82回诏书、皇帝肯定与正式赦免属于外部认可 / 位置变化；但 `zn` 最硬证据早于这些认可。
- `zn vs x`：梁山现实权力、新官位 / 牌面是否形成处分边界，都与“最终政治归属应走向哪里”分开判断。
- `zn vs xn`：走李师师、燕青、宿太尉路线属于“怎么争取招安”的流程，不解释“为什么最终仍要招安”。
- `zn vs zx`：梁山首领公开推进招安可以有显权行为，但权力公开显现不能替内部原则定义。
- 稳定人物本体：本轮不锁，只锁这项原则跨承认窗口的成立时序。

## 9｜第三因素冻结

冻结：

- 对宋江“忠臣 / 投降派”的价值评价；
- 宋徽宗是否明君；
- 高俅、童贯的奸臣因素；
- 招安最终是否成功；
- 后续征辽、征方腊的胜负。

只保留：

```text
官方承认前原则是否独立过门？
承认到来后是否只是现实兑现？
拿掉承认后原则是否仍能解释此前选择？
```

结论不变。
