# 运行记录｜玄奘禁边令下秘密西行：绕过官方许可，但没有绕过整个外部接口层

## 研究问题

仓库已有《三国演义》关羽“五关无文凭”99/97 控制：正常低成本许可路线存在，但关羽没有使用，而是以自身武力连续通过五关，实际实现同一“物理通行”结果，因此当前执行层不能继续把曹方通关许可判为 nx 必经门。

本轮原本寻找第二个“高成本内部绕行同结果”正例。玄奘秘密西行表面非常相似：

```text
正常路线：
官方过所 / 合法出境许可

实际路线：
禁边令下秘密西行
→ 昼伏夜行
→ 绕玉门关 / 五烽
→ 穿沙漠
```

但压力测试后发现关键差异：玄奘实际路线并非纯主体自给，而是连续使用了地方僧人、州吏、向导等外部帮助。因此它不能作为第二个关羽型“内部自给绕行”正例，反而构成更有价值的反向控制：

> 绕过一种官方许可接口，不等于绕过整个外部接口层。

## 史料事实

主要依据《大唐大慈恩寺三藏法师传》卷一及相关整理：

1. 唐初边境有“禁约百姓不许出蕃”的禁令；凉州都督李大亮得知玄奘欲向西求法后，要求其返回。
2. 河西慧威法师赞同玄奘求法志愿，密遣弟子惠琳、道整护送，玄奘自此“昼伏夜行”前往瓜州。
3. 玄奘尚未出发时，凉州追捕文牒又到瓜州，要求州县严候捉拿；州吏李昌确认其身份和意图后，表示愿意为其设法，并毁去追捕文书。
4. 玄奘随后取得马匹与胡人向导；夜间抵达瓠芦河附近，由胡人砍木搭桥、铺草填沙，实际帮助其渡河、越过玉门关一线。
5. 胡人后来因前途危险与王法风险退出，玄奘才在后续五烽与莫贺延碛路段继续独行。

## 对象与路径切分

```text
结果对象 R：
实际离开唐朝西北边境并继续向西求法

正常官方路径 P1：
获得朝廷 / 官府正式出境许可、过所
→ 合法经过关防

玄奘实际路径 P2：
无中央许可
→ 秘密西行
→ 地方僧人密送
→ 州吏毁追捕文书
→ 胡人向导搭桥、指路
→ 后续独行
→ 实际越出边境继续西行
```

P1 与 P2 在“物理离境并继续西行”这个窄结果对象上可直接比较；不能把“是否合法出境”另行偷换成同一结果。

## nx 判断

### 1｜中央官方许可层：当前执行中排除

玄奘没有取得朝廷允许，没有使用正式过所，也没有在李大亮阻止后返回等待批准。

因此：

`central_official_permission_nx_in_actual_execution: rejected`

这与关羽案例相同的一点是：

> 低成本、正常、合法的外部许可路线存在，不等于主体当前实际就在沿它续接。

### 2｜但整个外部接口层并未消失

玄奘的实际绕行不是纯“主体自身能力足以完成全链”。

他实际使用了：
- 慧威法师及弟子的秘密护送关系；
- 李昌对追捕文书的现实处置；
- 地方供给、马匹等资源；
- 胡人向导的路线与搭桥能力。

这些条件都不属于玄奘本人稳定可自给的 x。

因此本轮锁：

`informal_local_relation_resource_nx: evidence-locked`

最窄结论不是“玄奘仍沿官方许可 nx”，而是：

> 他把外部依赖从“中央正式许可接口”切换成了“地方关系 / 放行 / 资源 / 向导接口”。

也就是：

`interface_class_changed_not_eliminated: true`

## 为什么不能算第二个关羽型内部绕行

关羽五关案的关键门是：

```text
无通关文凭
→ 不回去补办
→ 不转另一个等价许可节点
→ 直接以自身武力连续突破
→ 同一物理通行结果实现
```

关羽的绕行核心能力在主体自身，因而可以检验“高成本自有路线是否足以让许可 nx 退出”。

玄奘则不同：

```text
无中央许可
→ 仍需要外部护送 / 文书处置 / 向导 / 桥渡帮助
→ 才完成关键边境段
```

所以：

`self_sufficient_internal_bypass_exists: false`

不能因为“没有中央批文”就把 P2 误写成纯内部路线。

## zx 判断

玄奘西行的求法方向显然由自己保持，而且在禁令和阻拦下没有撤回。

但本轮不把“违法出境成功”直接锁成 zx。现行 zx 仍要求检查主体是否通过自身权能形成新的现实决定范围 / 稳定权限边界。

玄奘最终成功离境，不等于他获得了“以后由玄奘决定谁可出境”的新公共接口。

因此：

`zx_from_bypass_itself: deferred`

## xn 最近邻

玄奘选择路线、昼伏夜行、安排补给、决定何时绕关，存在 xn 邻近。

但这些组织行为不能抹掉：实际边境段仍使用多个独立外部资源与关系节点。

所以本轮不以 xn 替代局部 nx。

## 拿掉测试

### 拿掉中央官方许可 P1

原史料证明玄奘仍实际出境，因此中央正式许可不是当前执行链的必要条件。

### 拿掉所有地方外部帮助

如果同时拿掉：
- 慧威弟子密送；
- 李昌毁文书 / 放行；
- 马匹与补给；
- 胡人搭桥与向导；

现有史料不能支持“玄奘仍能按同一链稳定完成边境段”。

因此不能锁“自给内部绕行”。

### 只拿掉一个具体帮助者

某一具体人未必唯一不可替代，但仍需重新检查是否存在其他同类外部帮助节点。

这与仓库现有“具体节点可替代 ≠ 外部接口层可绕过”纪律一致。

## 反向测试

### 真正关羽型内部绕行

```text
官方许可被拒
→ 主体不接入任何等价外部放行 / 资源 / 关系节点
→ 仅凭稳定自有能力走高成本路线
→ 同一结果重复 / 稳定实现
= 当前许可 nx 显著下降
```

### 玄奘型接口切换

```text
中央许可被拒
→ 不走中央许可
→ 但转用地方僧人 / 州吏 / 向导等外部节点
→ 同一结果实现
= 中央许可 nx 退出
但局部外部关系 / 资源 nx 仍存在
```

## 最近邻排除

### nx vs x

地方官员、护送者、向导的资源与现实处置权并未进入玄奘稳定 x 边界。

### nx vs xn

主体主动策划秘密路线可有 xn；但“自己策划如何求助”不等于这些外部条件由自己生成。

### 绕过一个接口 vs 绕过整个接口层

这是本轮主边界：

> 绕过中央官方许可，只能证明“中央许可不是当前必经门”。
>
> 不能据此推出“主体已经不依赖任何外部接口”。

必须继续逐层检查实际链上是否仍有外部权限、关系、资源或专业能力。

## 本轮结论

最窄可靠纪律：

> “绕过一种正式许可”不能直接等同于“主体拥有内部自给绕行”。
>
> 判定高成本内部绕行是否足以削弱 nx，必须继续检查实际路线中是否仍依赖其他外部权限、关系、资源或专业接口。
>
> 如果只是从 P1 官方接口切换到 P2 非正式外部接口，则应按对象层分别判定：P1 的 nx 可退出，但 P2 的局部 nx 仍可能成立。

这使关羽案例的硬门进一步清晰：

> 真正用于测试“内部绕行削弱 nx”的路线，不能只是不走原许可；它还必须在关键结果链上不再依赖等价外部接口。
