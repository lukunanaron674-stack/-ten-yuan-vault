# F12 补脑蓝图

## 新定位

F12 不是简单自动续跑器。

它是 Codex 大脑的多框补脑系统。

目标：

```text
用多个 ChatGPT 页面并行采矿
-> 各框负责不同缺口
-> 只回传关键轮次
-> Codex 吸收成规则 / 蓝图 / 案例库
-> Obsidian 沉淀
```

## 多框分工

### A 框：十元关系采矿

任务：

- 找生、克、补、压、激活、包装、桥接、污染桥。
- 优先补缺少案例的关系。
- 输出关系公式和最小证据。

回传：

- 关系表。
- 可入库案例。
- 最大误判。

### B 框：动态链母型采矿

任务：

- 找回收、崩坏、扭曲、断链、停滞、反噬、换芯、循环、转承载、伪闭环。
- 重点看力的阶段变化。

回传：

- 动态链公式。
- 分叉点。
- 母型暂判。

### C 框：五大主题归仓审稿

任务：

- 审查时间、本体、空间、因果、命运归类。
- 专门抓五维倒推十元的错误。

回传：

- 归仓修正表。
- 主题缺口。
- 高风险误判。

### D 框：视觉 / 插画 / 场景采样

任务：

- 把十元转成可画的姿态、构图、光线、材质、角色关系。
- 找“没有 AI 味”的视觉方案。

回传：

- 风格词。
- 构图母题。
- 场景种子。
- 反 AI 味红线。

### E 框：故事种子与一句话

任务：

- 把动态链变成一句话故事。
- 把银矿母型转成可写的短故事钩子。

回传：

- 一句话故事。
- 角色冲突。
- 场景触发。
- 可扩写等级。

### F 框：反例与误判清理

任务：

- 专门找不该入库的伪矿。
- 找旧规则污染。
- 找重复、弱证据、名作光环。

回传：

- 待删减清单。
- 降权原因。
- 反例库。

## 回传策略

不是所有轮次都给 Codex 看。

默认：

- 普通研究轮：只记录状态。
- 审稿轮：回传摘要。
- 归档轮：完整回传。
- 承载轮：完整回传。
- 反例轮：完整回传。
- 下一轮代码 / 任务生成轮：完整回传。

## 任务字段

每个 F12 task 应增加：

```text
id
title
type: research / review / archive / carry / visual / story / anti / final
targetBrainSlot
payload
returnPolicy: none / summary / full
```

## Codex 需要的素材槽

```text
brain.tenYuan.rules

brain.fiveThemes.warehouse
brain.visual.styleSeeds
brain.story.oneSentenceSeeds
brain.errors.antiExamples
brain.f12.nextTasks
```

## 最小可实现版本

先不做复杂 UI。

只需要：

1. task 增加 `type`。
2. side panel 增加过滤：全部 / 只看归档 / 只看反例 / 只看视觉 / 只看故事。
3. bridge 回传时按 `returnPolicy` 控制正文。
4. 归档轮自动写入 Obsidian handoff。

## 一句话

F12 的未来不是更能跑，而是更知道该把什么材料带回来喂给 Codex。
