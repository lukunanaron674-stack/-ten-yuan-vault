# 候选记录｜王熙凤协理宁国府：授权 x 与 zx 扩权边界

## 0｜本轮为什么降级为 candidate/deferred

仓库已有正式案例把王熙凤第十三至十四回协理宁国府锁为非战斗管理域 `zx` 当前状态高显影，并同时锁 `xn` 组织功能；后续运行记录又已确认，当规矩建立以后，她对迟到媳妇的具体处分属于既有局部 `x` 正常调用，而不是每次处分都重新产生 `zx`。

本轮按最新分层授权纪律重跑连续时间链后，发现旧 `zx` 锚与“受托后获得真实局部权限优先可解释为 x”的规则之间存在一个不可忽略的中间灰区：

> 贾珍并非只给王熙凤一个模糊任务，而是实际交出宁国府对牌，并明确给予相当宽的内务调用空间；王夫人也真实批准她承接。王熙凤随后重设岗位、时刻、赔补与处分规则，究竟是“在已经交付的宽授权 x 内高强度行使 + xn 重组”，还是“把决定边界继续推出原授权范围，从而构成 zx”，文本存在真实双解。

因此本轮不推翻旧正式案例，也不把旧 `zx` 结论机械复制。事实置信锁 99；分类只给 93，保留为 deferred。

## 1｜剧情事实、触发、对象、动作、结果

### A｜授权入口

秦可卿死后，宁国府内务繁重，尤氏不能料理。贾珍请求王夫人允许王熙凤过去协理。

王夫人最初并非自动同意，而是担心凤姐没有办过婚丧大事；凤姐本人主动表示可以承接，王夫人才放行。

因此对王熙凤主体而言，进入宁国府承担这项跨府管理职责并非她单方面即可生效：

```text
贾珍提出外部任务
+
王夫人真实批准
+
王熙凤本人承接
→ 协理职责入口成立
```

本层锁：

`nx_delegation_entry_relation: evidence-locked`

这里只锁任务/授权入口，不推稳定人物本体。

### B｜局部处分 x 形成

贾珍随后交出宁国府对牌，并明确表示内部取用所需可凭对牌办理，不必逐项问他。王夫人同时提醒重要事项仍需问贾珍、尤氏，说明授权既真实又有边界。

到第十四回，王熙凤对迟到媳妇的具体处罚无需再回贾珍/王夫人逐项请示：她直接决定二十板、革一月银米，执行人员立即实施，之后才回来回覆。

因此在“宁府日常内务处分”这一局部对象层，本轮可高置信锁：

`x_delegated_local_disposition_boundary_after_token: evidence-locked`

这与既有 20260819 运行记录一致。

### C｜运行骨架由王熙凤主动重建

王熙凤到任后要求不再以“你们这府里原是这样”为理由，重新分岗位、班次、责任、赔补、点卯、领牌、巡查与钥匙交接等节点。

因此：

`xn_rule_and_process_rebuild: evidence-locked`

但 `xn` 不能替代木轴的 x/zx 判断。

## 2｜真正分歧：这一步到底是 x 还是 zx

### 支持“仍主要是 x + xn”的证据

1. 贾珍主动请她协理，并交出宁府对牌。
2. 贾珍明确给予非常宽的内务裁量：“爱怎样就怎样”“要什么只管拿这个取去，也不必问我”。
3. 王夫人明确批准她进入该职责。
4. 后续迟到处罚显示，她确实已经拥有无需逐项回报批准的局部处分接口。
5. 她建立岗位、时刻、赔补、点卯等制度，可以解释为在已交付管理域内进行 `xn` 重组，并正常调用已获得的 `x`。

若这一解释成立，则：

```text
外部nx授权入口
→ 局部管理x正式交付
→ 王熙凤在x范围内用xn重建运行结构
→ 非自动zx
```

### 支持“zx 当前状态仍成立”的证据

1. 宁国府此前存在自己的旧例与运行惯性。
2. 王熙凤公开宣布旧例不能继续作为最高理由，要求全体“如今可要依着我行”。
3. 她把此前不围绕自己运行的另一府内事秩序重新集中到自己的决定接口。
4. 宁府成员的行为与处分标准确实围绕她的新规则发生可观察重排。
5. 仓库既有正式案例据此认为：她不仅获得授权，还公开使现实组织围绕她新建立的决定中心响应，因此支持 `zx` 状态高显影。

若这一解释成立，则：

```text
nx授权入口
→ 得到管理接口
→ 不只调用接口，而是公开重写另一府的决定结构
→ 组织围绕新增中心重排
→ zx上升
```

## 3｜当前最小分歧点

本轮不再争论“她强不强、会不会管理”。真正只剩一个问题：

> **zx 的“决定范围上升”应以进入宁国府之前的王熙凤个人基线比较，还是必须以贾珍/王夫人已经明确授予的宽管理边界作为当前基线比较？**

若基线取“进入宁府前”：从荣府管理者变成宁府实际决定中心，位置明显上升，支持 zx。

若基线取“授权完成后”：贾珍已经把该内务管理接口交给她，她后续立规、处分主要是使用授权后的 x，并以 xn 组织运行；若没有越过“内务协理”边界，则新的 zx 增量不足。

这是真分叉，当前无法压到 ≥95%。

## 4｜zx 检查

### 本轮明确不接受的伪 zx 证据

- 王熙凤性格强势；
- 她敢罚人；
- 她把丧事办得好；
- 宁府众人怕她；
- 她设计了很多制度。

这些只能分别支持压力、结果、x/xn 邻近，不能单独证明“超过当前授权基线”。

### 当前状态

`zx_beyond_delegated_boundary: deferred`

需要新增材料证明至少一项：

- 她公开处分了原授权明确排除的对象；
- 她在必须回贾珍/尤氏的重要事项上跳过原授权者并让结果独立生效；
- 原授权者明确反对后，她仍让新边界成立；
- 宁府认可她拥有超过“暂代内务协理”本身的新增长期权限。

当前第十三至十四回材料尚不足把上述任一项锁到 95%。

## 5｜nx 检查

### 授权入口：成立

王熙凤不能凭自己意志单方面让“跨府协理宁国府”制度性生效；文本实际经过贾珍请求、王夫人放行、凤姐本人承接。

所以：

`nx_delegation_entry_relation: evidence-locked`

### 授权后的日常处分：不应继续全包成 nx

一旦对牌交付且局部日常处分可以直接生效，具体迟到处罚不需要再次经过上级批准。

因此：

```text
上位职责入口nx
≠
后续每个局部决定都nx
```

## 6｜最近邻排除

### nx vs x

- “能不能进入宁府承担协理职责” → 外部授权门存在，偏 nx。
- “取得对牌以后能否直接处分日常内务” → 可以独立生效，偏 x。

### x vs zx

- 在授权边界内正常调用 → x。
- 把决定范围公开推出授权边界，并让组织承认新增接口 → zx。

本轮真正卡在“她的新规是否已经超出贾珍主动授予的宽内务边界”。

### x/xn vs zx

排班、定时、分工、赔补、点卯、钥匙属于 xn 高显影；这些流程设计即使非常彻底，也不能自动证明权限扩大。

## 7｜拿掉测试

### 拿掉贾珍交对牌与宽授权

如果只剩“请凤姐帮忙”而没有真实局部处分接口转交，那么她后续直接处分、改制更容易支持 zx。

说明：**对牌与宽授权是降低 zx 置信、提高 x 解释力的关键事实。**

### 拿掉王熙凤后续改旧例

如果她取得对牌后完全照宁府旧例运行，则：

```text
nx授权入口
→ x局部调用
```

明显不需要 zx。

### 拿掉公开组织响应

如果她只是私下排表，但宁府成员并不围绕她的新接口行动，则旧正式案例的 zx 支柱显著下降。

## 8｜反向测试

### 纯分层授权版本

```text
外部正式委派
→ 主体接受
= nx入口

交付真实局部处分接口
→ 主体可独立让日常决定生效
= x

在授权范围内排班/定时/分工
= xn

没有越界扩权
= 非zx
```

### 真正 nx→x→zx 版本

```text
外部正式委派
→ nx入口

交付局部处分接口
→ x

主体随后公开把决定边界推出原授权范围
→ 原授权者/组织被迫承认新增接口
→ 决定范围继续上升
= zx
```

当前文本前两段高置信，第三段仍有解释分叉。

## 9｜第三因素冻结

冻结：

- 王熙凤“脂粉队里的英雄”评价；
- 性格泼辣、心硬；
- 秦可卿丧事规模；
- 贾珍是否欣赏她；
- 宁府此前是否混乱；
- 管理成效；
- 后续铁槛寺弄权。

只看：

1. 谁让跨府协理职责正式生效？
2. 对牌交付后哪些对象能由凤姐独立处分？
3. 她的新规是否越过授权边界？
4. 若越过，原授权者是否被迫承认新增边界？
