# 运行记录｜曹操衣带诏后弑董贵妃：献帝名义最高但无现实否决｜2026-08-25

## 1｜本轮目的

补测木轴 P4“名义权限 vs 现实否决权”。本轮不重新证明曹操稳定本体，也不把“皇帝在场”机械写成 nx；只检查第24回董贵妃处分这个窄对象层：**结果生效前，献帝是否拥有曹操必须承认并沿用的真实否决接口。**

本例与仓库已有《后汉书》曹操许都实际裁决反向证据属于“文学版本复验”，不计新的独立作品数量，不用于虚增 cross_work_count。

## 2｜剧情事实

《三国演义》第24回：

1. 衣带诏败露后，曹操处斩董承等人及其家属。
2. 曹操随后带剑入宫，要杀董贵妃。
3. 献帝明确以董贵妃已有五月身孕为由请求曹操保全。
4. 伏皇后进一步提出至少先贬入冷宫、待分娩后再处置。
5. 曹操明确拒绝两种请求，命武士将董贵妃牵出并勒死于宫门之外。
6. 结果按曹操决定落地，献帝的名义最高身份与现场请求均未形成能够阻止或修改结果的现实否决。

## 3｜对象、触发、动作、结果

```text
对象：董贵妃当前生死处分
触发：衣带诏败露、董承被诛
名义最高节点：汉献帝
主体：曹操
明确动作：曹操入宫要求处死；献帝求情；伏后提出替代处分；曹操全部拒绝并命令执行
结果：董贵妃被勒死，献帝未能阻止或修改结果
```

## 4｜zx / nx / 伪对子判断

### 4.1 nx：本窄对象层排除

若把“献帝是皇帝、曹操名义为臣”直接写成 nx，会违反当前 nx 准度纪律。

本阶段没有看到：

```text
曹操提出处分
→ 献帝拥有事前真实否决
→ 献帝批准后处分才能生效
```

实际相反：

```text
献帝明确反对/求情
→ 曹操拒绝
→ 曹操决定仍直接执行
```

所以“皇帝名义上级”不能自动成为曹操当前处分的 nx 权限来源。

### 4.2 zx：高显影候选，但本轮不锁 zx vs x

曹操带剑入宫、压过皇帝与皇后请求、让贵妃处分按自身决定落地，具备明显公开显权与秩序响应。

但本轮不把该段单独锁成纯 zx，因为仍有一个真实最近邻分叉：

- 若把许都阶段宫廷/朝政高位处分看作曹操此前已经稳定拥有的现实裁决边界，则本次更接近 `x` 的强势调用；
- 若把“直接处置皇帝宠妃并压过皇帝现场请求”视为把决定范围进一步推进皇帝内廷处分域，则可形成 `zx` 状态高显影。

该分叉超过5%，因此只锁“当前非 nx / 名义上级无现实否决”这一主结论，`zx vs x` 子分类保留 deferred。

### 4.3 zx+nx / 严格补：排除

当前 nx 权限端本身没有独立过门，因此不进入 `zx+nx` 共现，更不进入严格补测试。

## 5｜拿掉测试

### 拿掉名义身份

拿掉“献帝是皇帝、曹操名义是臣”这两个身份标签，只保留现场事实：献帝请求保全，曹操可以拒绝且结果仍直接执行。

结论不变：当前结果的现实否决不在献帝。

### 拿掉献帝的批准

原著本来就没有“献帝批准后才能杀”的必要步骤。删除假设中的批准节点，原事实链仍完整成立。

因此当前曹操处分结果不依赖这一外部许可接口，不能据此锁 nx。

### 拿掉曹操的现实执行接口

若曹操不能调武士执行、也不能让自己的处分命令直接落地，则原结果链无法按同样结构完成。

这说明当前现实作用接口至少主要在曹操一侧。

## 6｜反向测试

若情节改为：

```text
曹操请求处置董贵妃
→ 献帝可明确拒绝
→ 拒绝后曹操必须停止、重配或另寻通道
→ 只有献帝批准后结果才能生效
```

则该对象层会显著转向 `nx` 权限关系。

原著恰恰通过“献帝真实求情仍无效”给出了反方向证据。

## 7｜最近邻排除

### nx vs x

- `nx`：外部节点在结果生效前可以真实否决或修改，主体必须沿其通道推进。
- `x`：决定已经进入主体可直接执行的稳定处分边界。

本轮至少能高置信排除“献帝名义身份自动 = nx”。是否进一步锁曹操稳定 `x`，需与更长阶段的实际权力边界合看。

### nx vs zx

当前“直接压过献帝请求”具有 zx 邻近，但 zx 仍需独立证明**决定范围新增**，不能因为对方是皇帝就自动判扩权。

### nx vs xn

调武士、安排执行步骤只是运行组织邻近；本轮核心问题不是流程由谁排，而是结果生效前谁能真正否决。

## 8｜第三因素冻结

冻结：

- 曹操忠奸评价；
- 献帝是否软弱；
- 董贵妃是否无辜；
- 衣带诏的政治正当性；
- 后续魏代汉结局；
- 曹操个人性格、军事强弱。

只保留六个结构事实：

1. 谁名义最高；
2. 谁提出最终处分；
3. 谁明确表示反对；
4. 反对发生在结果生效前还是后；
5. 反对能不能阻止/修改结果；
6. 谁能让结果直接执行。

冻结后主结论不变。

## 9｜人物本体 / 当前状态 / 行为功能 / 关系位置

- 稳定人物本体：本轮不判。
- 当前状态：曹操处于现实裁决高位；zx vs x 子分类 deferred。
- 行为功能：公开拒绝皇帝求情并让处分直接落地。
- 关系位置：献帝名义在上，但在本处分微窗口不占现实可否决接口。
- 外部压力：衣带诏败露与宫廷冲突只作为触发，不直接充当十元证据。

## 10｜结论

本轮锁定：

> **名义最高上级存在，甚至在结果生效前明确表达反对，也不自动形成 nx。若该反对不能阻止、修改或迫使主体重配，而主体决定仍可直接落地，则这个名义上级在当前对象层不足以充当 nx 权限来源。**

进一步压缩为 P4 可迁移问法：

```text
不要先问“谁职位最高？”
先问“结果生效前，谁真的能让它停下来？”
```
