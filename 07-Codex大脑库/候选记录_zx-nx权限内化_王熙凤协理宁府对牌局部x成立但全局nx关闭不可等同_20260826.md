# 候选记录｜王熙凤协理宁府：局部 x 已成立，不等于整个任务层 nx 已关闭

## 0｜本轮目的

测试当前 strict temporal closure 的高价值反例槽：

> **外部权限/对象看似已经“交到主体手里”，是否就足以宣布 `nx→x` 内化、旧 `nx` 接口关闭？**

本轮不重做“王熙凤协理宁国府”人物判断，只切两段最小事实：

1. 第13回：贾珍交出宁国府对牌，授权凤姐协理；
2. 第14回：迟到媳妇处分由凤姐直接决定并立即执行。

## 1｜剧情事实、触发、对象、动作、结果

### 触发

秦可卿去世、尤氏病倒，宁国府内部缺少主理者。贾珍请求王熙凤暂代协理，王夫人放行后，贾珍交出宁国府对牌。

### 明确授权

贾珍对凤姐给出很宽的日常资源调用口径，大意为：要什么可凭对牌取用，不必逐项问他。

但同一场景中，王夫人同时提醒：不要凡事自作主意；有重要事情，要派人问贾珍、尤氏。

因此初始授权文本同时存在：

```text
宽日常调用
+
上位重要事项回问保留
```

### 后续局部实效

第14回，一名媳妇迟到。凤姐不先找贾珍、尤氏、王夫人批准，直接决定：打二十板、革一月银米；执行者立即执行，事后才回覆。

这条微窗口已经由仓库旧记录 99/98 锁定为：

```text
局部处分 x 成立
事前批准 nx 排除
执行后回覆 ≠ 事前批准
```

## 2｜zx 检查

本轮不新增 `zx` 结论。

较大“跨府协理、公开立规”阶段可有既有 zx 候选/旧锚；但当前问题是**授权是否已经内化为稳定 x、旧 nx 是否关闭**，不能拿“凤姐强势”“敢处罚”“宁府怕她”代替权限边界证据。

当前迟到处分本身优先解释为：

```text
既有局部处分边界已经建立
→ 现在调用
= x
```

而不是每处罚一次都重复收一次 `zx`。

## 3｜nx 检查

### 已能锁定的部分

不能因为“对牌在手”就自动写：

```text
宁府全部权限已内化为 x
→ 所有上位 nx 均关闭
```

因为初始授权文本明确保留了“有重要事情问哥哥嫂子”的上位回问口径。

### 不能锁定的部分

目前仍缺一条最关键事实：

```text
凤姐在某一上位重要事项上作出决定
→ 贾珍/尤氏事前说“不”或修改
→ 同一结果因此停住/改道
```

没有这个因果拨动，就不能以 ≥95% 把“上位回问口径”直接升级成：

```text
现实有效的持续 nx 最终否决接口
```

因此：

```yaml
whole-task-x-internalization: deferred
whole-task-nx-closure: deferred
```

## 4｜最近邻排除

### `x` vs `nx`

- 迟到处分对象层：凤姐能直接决定并生效，局部 `x` 已锁；
- 宁府所有重要事项层：不能只凭一块对牌推成全局稳定 `x`；上位是否仍有现实否决，需要实际事件继续验。

### `nx` vs `xn`

凤姐自行分班、点卯、设责任、定时序属于局部 `xn`；但“谁最终能否决重要事项”仍是权限问题，不能由流程组织能力替代。

### `x` vs `zx`

能直接处罚说明局部有权；是否越过授权边界形成新扩权，需要另证，不能把“处罚成功”直接当 `zx`。

## 5｜拿掉测试

### 拿掉对牌这件物件

如果事实仍然保留：

```text
凤姐能独立让局部处分生效
```

则局部 `x` 仍可成立。

说明：**持有象征物不是 x 的充分证据，现实独立生效能力才是。**

### 拿掉王夫人的“有事问哥哥嫂子”提醒

第14回迟到处分的局部 `x` 仍成立。

但“整个宁国府所有重要事项都已完全内化”会失去一个重要反向线索。

### 拿掉实际局部独立生效

若只剩“对牌交到手”，却没有任何直接处分、调用、拒绝或覆盖事件，则 `x` 的证据明显下降。

## 6｜反向测试

### 真正证明全局 `nx→x` 内化

需要看到：

```text
原上位节点不再保留逐次批准/撤回/覆盖权
+
主体可在同类重要事项上稳定独立决定
+
决定可直接生效
```

### 真正证明上位 `nx` 仍活跃

需要看到：

```text
凤姐提出/决定重要事项
→ 贾珍/尤氏事前否决或修改
→ 凤姐必须等待、重配或换通道
```

当前文本没有给出足够干净的同层实例。

## 7｜第三因素冻结

冻结：凤姐强势性格、贾珍信任、丧礼规模、迟到者身份、贾府权谋评价、后续铁槛寺。

只保留：

```text
授权范围是什么？
局部决定能否独立生效？
上位节点是否仍保留现实事前否决？
对象层是否相同？
```

结论不变。

## 8｜与杨志黄泥冈护栏的最小差异

### 杨志

有名义提调与实物押运，但谢都管在冲突发生时能实际压回其决定，因此“原节点现实否决仍活跃”有直接因果证据。

### 王熙凤

对牌交付后，迟到处分这一局部对象层反而证明了真实 `x`；但上位重要事项又存在保留回问条款。当前缺的是“上位节点实际否决并卡住同一结果”的硬事件。

所以本例**不能作为第二份与杨志完全同型的 95%+ 假内化正例**。

它只支持更窄、但可靠的方法纪律：

> **局部 x 已成立，不等于整个任务层所有 nx 都关闭；权限内化必须按对象层逐项验，不能从对牌、职位或一次局部独立处分向全局倒灌。**

## 9｜结论

```text
事实置信：99%
整体分类置信：93%
状态：deferred

已锁：
- 迟到处分微窗口局部 x 成立；
- 执行后回覆 ≠ 事前批准；
- 对牌/名义授权不能单独证明整个任务层全部内化。

未锁：
- 宁府重要事项层上位 nx 是否现实持续活跃；
- 整个协理任务是否已经完成全局 nx→x 内化；
- 能否计入 strict temporal closure 的第二份“假内化”跨作品负控制。
```

## 10｜最小分歧点

唯一需要继续补的硬证据是：

> **在“重要事项”同一对象层，贾珍/尤氏的事前意见究竟只是礼法咨询，还是能现实卡住凤姐决定的有效否决。**

在找到“否决→结果停住/改道”之前，不升级为 `evidence-locked` 假内化控制，不增加 cross-work 数，不修改任何 canonical。
