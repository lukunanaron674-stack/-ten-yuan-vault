# 百部电影十元位置关系压力测试

> 目的：不用题材或结局倒推十元，而是先判点位，再查标准位置盘，用 100 部唯一电影检验“生、克、补”在作品分析中分别负责什么。
>
> 本报告是结构映射实验，不改动正式理论、评分或银矿结论。

> [!warning] 2026-07-14 二审退回
> 首版完成了“关系边是否合法”的机械校验，但没有先独立证明每部电影的三元和十元点位判定正确。点位一旦错，后续生克补即使全部合法，仍然是在合法地连错。
>
> 因此本报告当前只保留为**关系层压力测试**，不能作为百片最终判定。正式二审顺序改为：分析单位 → 三元判定 → 三元与十元推导 → 十元判定 → 起手 → 生克补 → 动态链 → 五大主题。

## 0. 本轮锁定口径

只采用 [[01-十元系统/关系五对校验包_v0.1|关系五对校验包 v0.1]] 的合法边：

```text
生环一：xz → zx → zn → n → xn → xz
生环二：nz → nx → x → x并z → z → nz

克环一：xz → zn → xn → zx → n → xz
克环二：nz → x → z → nx → x并z → nz

补对：xz ↔ nz；zx ↔ nx；zn ↔ x；n ↔ x并z
待校准补对：xn ↔ z（本轮不作为强边使用）
```

本轮特别排除两条旧错误：

```text
nx 生 n ❌    正确：nx 生 x ✅
xz 生 nz ❌   正确：xz 补 nz ✅
```

### 字段说明

- **起手**：作品最先启动结构运动的十元，不等于主角性格，也不等于最终主题。
- **合法位置链**：只写标准盘存在的生、克、补边；多条边可以解释不同层面。
- **内容显影**：剧情里看起来发生了什么。它负责解释，不负责发明位置关系。
- **主仓**：动态链最终最集中回答的高阶问题。

## 7. 十元生克补到底怎么用

### 7.1 点位和关系分工

```text
十元点位：回答“这股力是什么”。
生：回答“下一股力从哪里被推出”。
克：回答“为什么不能直走，在哪里被压制或迫使转向”。
补：回答“缺失的另一极是什么，为什么两者合起来才成为完整主题轴”。
```

最短版：

```text
生 = 推出下一股力。
克 = 制造结构转向。
补 = 把两极咬成完整张力。
```

### 7.2 “生”不是剧情先后

只有当 A 的结构确实生成了 B，才能写 `A 生 B`。不能因为 A 事件先发生、B 事件后发生，就叫生。

百片中最清楚的四种生：

```text
xn 生 xz：规则制造危机。
xz 生 zx：危机逼出行动。
x 生 x并z：欲望为了实现自己而造壳。
z 生 nz：光点持续后变成不想结束的停靠。
```

判断句：

> 去掉 A，B 还会以同样方式出现吗？如果会，A 多半没有“生”出 B，只是和 B 同时存在。

### 7.3 “克”不是谁打赢谁

克表示一种结构压制、限制、截断或迫使转向。它可以成功，也可以失败；它不等于战斗胜负和道德胜负。

例如：

```text
xn 克 zx：规则让行动不能直接推进。
nx 克 x并z：证据与结算让身份壳无法继续成立。
n 克 xz：容器让漂流停下，也可能把漂流者困住。
xz 克 zn：持续危险让人的意义与信念失稳。
```

判断句：

> A 出现后，B 是否失去原来的运行方式，被迫停止、绕路、变形或污染？如果是，才考虑克。

### 7.4 “补”不是治愈，也不是好结局

补是结构缺口被另一极补厚。它经常让悲剧更痛，而不是让矛盾消失。

最典型的是：

```text
xz 补 nz
```

漂流、危险和来不及并不“生出”停靠；它们让停靠变得更必要、更疼、更有命运重量。反过来，正因为存在想停下的 `nz`，`xz` 才不只是普通危险，而成为命运漂流。

同理：

```text
zx 补 nx：行动和结算互相补全为因果。
zn 补 x：意义和欲望互相照出本体。
n 补 x并z：容器与外壳互相补全为空间。
```

判断句：

> A 和 B 单独都不完整，放在一起后主题张力是否突然成立？如果成立，才考虑补。

## 8. 标准操作流程

### 第一步：先锁分析单位

先说清楚分析的是：

```text
整部作品 / 某个角色 / 一段关系 / 一个场景 / 一条叙事线
```

不同单位可以有不同起手，不能把全片主题、主角灵魂和单场戏功能塞进同一条链。

### 第二步：先判点，不急着连线

每个候选十元都要回答：

```text
它在片中由哪个人物、物象、规则、空间或反复动作显影？
拿掉它，当前分析单位是否会崩？
它是主十元、副十元，还是仅仅是功能位/视觉位？
```

### 第三步：找起手

起手不是第一场戏，也不是结局最高点，而是最早让结构不可逆地开始运动的力。

例如《寄生虫》不是从豪宅 `n` 起手，而是金家的生存欲 `x` 起手：

```text
x 生 x并z
```

欲望先生成伪造身份的壳，之后豪宅才作为容器介入。

### 第四步：机械查位置盘

把候选 A、B 放进标准表，只能得到五种视角：

```text
A 生 B / A 被 B 生
A 克 B / A 被 B 克
A 补 B
```

没有合法边就不要硬写；寻找中间点，或者承认它们只是共现。

### 第五步：内容显影与标准位置分栏

固定写法：

```text
内容显影：故事里看起来发生了什么。
标准位置：查表后到底是生、克还是补。
动态链：合法边落到影片后怎样运行。
```

最重要的防错例：

```text
内容显影：距离和危险“切断”了爱情。
错误位置：xz 克 nz ❌
标准位置：xz 补 nz ✅
```

“切断停靠”的合法克位要另找证据。例如成人身份、礼法和表演壳成立时，可以写 `x并z 克 nz`；不能拿剧情动词改写位置盘。

### 第六步：先跑显链和暗链，再合主题

一部电影通常不需要“一条链吃到底”。更稳的是：

```text
显链：解释外部事件怎样推进。
暗链：解释人物内部怎样变形。
主题链：两条链在什么生、克、补关系上汇合。
```

百片中 89 部只需要 3—4 条合法边。超过 4—5 条仍解释不清，通常不是作品太复杂，而是分析单位没拆开或开始过拟合。

### 第七步：最后才归五大主题

主题是动态链跑完后的高阶结算，不是起手证据：

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

主题公式只说明高阶轴，不自动宣布两个点之间存在某条生克边。尤其 `xn + z` 当前仍不能自动写成强补关系。

## 9. 完整示例：《寄生虫》

### 入口云

```text
金家的生存与上升欲：x
伪造家教、司机、管家身份：x并z
朴家豪宅与地下室：n
隐藏住户、证据和秘密账目：nx
最后的暴力行动：zx
```

### 机械查表

```text
x 生 x并z ✅
n 补 x并z ✅
nx 克 x并z ✅
zx 克 n ✅
```

### 动态链

```text
x 生 x并z
→ 生存欲造出体面身份壳

n 补 x并z
→ 豪宅让身份壳有了可以站稳和表演的容器

nx 克 x并z
→ 地下室秘密和旧管家的账目撕开寄生身份

zx 克 n
→ 暴力行动最终击穿豪宅作为稳定阶级容器的功能
```

### 主题结算

它不是因为“故事发生在房子里”才归空间，而是因为整条链都在回答：

> 谁能进入这个容器，靠什么壳停留，秘密如何撕壳，行动又怎样击穿容器。

## 10. 假链与审稿红线

1. **见到“然后”就写生**：时间先后不是结构生成。
2. **见到冲突就写克**：争吵、战斗、反对不自动构成合法克位。
3. **见到爱情或搭档就写补**：共现和互助不等于位置补对。
4. **用内容动词改位置盘**：故事说“切断”也不能把 `xz 补 nz` 改成 `xz 克 nz`。
5. **跳过中间点**：`nx 生 x并z` 错；必须写 `nx 生 x → x 生 x并z`。
6. **用主题倒推起手**：命运片不一定从 xz 起手，空间片也不一定从 n 起手。
7. **把结局当起手证据**：结局只能验证，不能倒推第一推动力。
8. **把克写成必胜**：克是压制方向，不保证克制成功。
9. **把补写成治愈**：补可能让悲剧更完整、更难逃。
10. **把 `xn ↔ z` 自动当强补**：该补对仍待校准。
11. **把 `nz 克 x` 写成“爱必胜欲望”**：百片没有出现足够纯的高置信主链，必须专项二审。
12. **链越长越高级**：百片显示 3—4 条边通常已经足够；长链应拆分分析单位。
