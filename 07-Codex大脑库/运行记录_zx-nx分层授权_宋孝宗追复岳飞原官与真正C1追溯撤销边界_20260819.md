# 运行记录｜宋孝宗追复岳飞原官与真正 C1 追溯撤销边界

## 0｜本轮目的

当前待审议已经区分：

```text
A｜事后报告/备案
B｜事后追责主体
C1｜真正追溯撤销旧决定本身
C2｜重新授权/重新接纳/新任命
```

此前关羽华容道证明“事后追责 ≠ C1”；孙悟空被逐后回归、诸葛亮自贬后复丞相证明“后来恢复/重新接纳 ≠ C1”。本轮专门寻找真正 C1。

## 1｜剧情/史料事实

### 1.1 旧处分已经真实生效

岳飞在绍兴十一年末的冤狱中被处死，原有官爵、政治名誉与家属处境均受到实质处分。该旧状态并非未执行、未生效或仅停留在口头层。

### 1.2 绍兴三十二年出现新的最高权限决定

宋孝宗即位后，于绍兴三十二年七月下诏，核心动作包括：

```text
追复岳飞元官
+ 以礼改葬
+ 访求其后
+ 特与录用
```

追复告词又明确出现“尽洗于丹书”的表述，并恢复少保、武胜定国军节度使、武昌郡开国公等原有政治/官爵状态。

### 1.3 与 C2 的决定性差别

岳飞已经死亡，不可能在二十年后新增功绩、重新申请职位或重新承担职务；孝宗此举直接针对旧政治记录、旧官爵处分和由旧案造成的官方状态进行纠正。

因此，本轮不能写成：

```text
旧处分有效
→ 岳飞后来又立新功
→ 朝廷重新任命
= C2
```

而更接近：

```text
旧处分已经真实生效
→ 后来更高/最终权限重新评价旧案
→ 直接追复“元官”并清洗旧官方记录
→ 政治/官爵法律状态发生追溯性纠正
= C1（仅锁法律/名位对象层）
```

## 2｜zx 判断

### 结论

`zx_new_expansion_in_revocation_stage: rejected_as_primary`

宋孝宗的动作非常强，但不能因为皇帝一句诏令改变旧案就判 zx。

现行 zx 要求主体自身决定范围相对原边界继续公开扩大。本轮宋孝宗是在既有最高皇权范围内行使追复、改葬与褒录权，没有证据显示他通过此案取得此前不存在的更高处分层。

所以：

> 决定影响巨大 ≠ zx；已有最高权限的正常调用优先检查 x。

## 3｜nx 判断

### 结论

`nx_in_revocation_decision_layer: rejected_as_primary`

在“是否追复岳飞旧政治/官爵状态”这一窄对象层，诏令本身来自宋孝宗最高决定接口，不需要再沿另一个外部批准通道才能生效。

因此这里不是：

```text
宋孝宗提出恢复
→ 必须等待另一权限主体批准
→ 才可追复
```

而是既有最终撤销/追复权限的直接调用。

## 4｜最近邻排除

### 4.1 x

本轮最强最近邻：`x_existing_final_revocation_authority_neighbor: evidence-locked`。

被测试的是皇帝既有的最高政治/官爵处分与追复接口。该接口本轮直接生效，因此优先 x，不重复收 zx。

### 4.2 xn

诏令执行当然包含礼制、改葬、寻访后人等流程，但这些只是如何落实追复，不是本轮核心权限来源。

### 4.3 C2

诸葛亮“右将军 → 后因新战功复丞相”属于旧处分真实有效后，在新功条件下建立新状态；岳飞死后无新行为，且诏令直接写“追复元官”，故本轮明显更靠近 C1。

## 5｜关键压力

关键历史压力是新旧政治评价发生改变，但政治环境变化本身不能直接判 zx/nx。

真正有判别力的是：

```text
旧处分已经生效
+ 新最高权限明确针对旧状态作追复
+ 恢复对象是“元官/旧官方身份”
+ 不依赖被处分者后续新行为
```

## 6｜拿掉测试

### 拿掉“平反昭雪”现代概括词

只保留原始动作：

```text
追复元官
+ 以礼改葬
+ 访求其后录用
+ 尽洗丹书
```

仍足以证明这不是普通重新任命。

### 拿掉后世追谥、追封

只保留绍兴三十二年七月追复决定，C1 法律/名位层判断仍成立；后世武穆、鄂王等荣誉不是分类支柱。

### 拿掉岳飞冤屈的道德评价

即使完全冻结“忠奸、冤不冤”的价值判断，只看旧处分与新诏令的时间/权限结构，仍是旧官方状态被后续最高权力直接纠正。

## 7｜反向测试

### 反向成 C2

若结构是：

```text
岳飞旧处分有效
→ 后来本人重新立功/重新申请
→ 朝廷依据新功重新授予类似职位
```

则应判 C2，而非 C1。

### 反向成“事后荣誉但不撤销旧状态”

若朝廷只追加谥号、祭祀或纪念，却不追复原官、不处理旧官方记录，也不恢复旧案牵连状态，则 C1 明显下降。

### 反向成 nx

若孝宗只能建议追复，必须经另一个真实最终节点批准后才生效，则当前决定层 nx 上升。史料不支持这种结构。

## 8｜对象层限制

本轮只锁：

> **政治/官爵/官方记录对象层存在真正追溯纠正。**

绝不锁：

> “岳飞被杀这一物理历史结果被撤销。”

死亡事实无法回滚；C1 的“回滚”必须按被测试对象层理解。这里回滚的是旧政治处分、官爵状态与官方记录，而不是时间线本身。

## 9｜结论

本轮达到正式入库门槛：

```text
事实置信：99
分类置信：96
```

最窄结论：

> **岳飞绍兴三十二年追复原官，是当前待审议中首个足够接近并可高置信锁定的 C1 正向控制，但仅限“法律/政治名位与官方记录”对象层。**

由此进一步压实：

```text
C1 不要求物理历史倒带；
它要求被测试的“决定对象层”中，旧处分本身后来被最终权限直接纠正/撤回，而不是依赖新条件另建一个新状态。
```
