# 运行记录｜鸳鸯抗婚：zx 自主拒绝 + nx 贾母真实阻断权，同一“被强纳为妾”瓶颈第三正向控制

## 1｜剧情事实

贾赦欲纳贾母房中的鸳鸯为妾，先由邢夫人游说，又通过鸳鸯兄嫂施压。鸳鸯多次明确表示不愿，并指出即使成为正妻也不去；贾赦随后放话，称无论鸳鸯将来嫁给谁也难逃其手，除非终身不嫁或死亡。

在压力升级后，鸳鸯主动回到贾母面前，当众说明自己绝不从命，并以剪发、寻死作为不可退让的边界表达。贾母得知后震怒，公开否定贾赦取得鸳鸯的要求，并明确表示鸳鸯必须留下服侍自己，贾赦若要妾可另买。随后邢夫人受训，贾赦不敢再强行推进鸳鸯之事。

最小事实链：

```text
贾赦强求鸳鸯为妾
↓
鸳鸯明确拒绝，并把“不从”公开压入现实
= zx 当前状态
↓
现实瓶颈仍在：贾赦拥有强势家长/主子位置，鸳鸯仅靠个人拒绝无法稳定阻断后续强迫
↓
鸳鸯进入贾母这一真实上位保护/留用接口
= nx 关系功能
↓
贾母公开否决贾赦、要求鸳鸯留下
↓
同一强纳瓶颈被现实阻断
```

## 2｜zx 判断

本轮只锁鸳鸯当前状态/行为功能，不锁稳定人物本体。

zx 成立的核心不是“脾气烈”，而是：

1. 是否嫁贾赦的最终方向由鸳鸯自己明确占据；
2. 她没有把选择交给邢夫人、兄嫂或贾赦；
3. 她当众把拒绝压入现实，并愿意承担极端代价以维持边界；
4. 她的公开拒绝成为后续家内权力结构必须处理的现实事实。

```yaml
zx_current_state_stage: evidence-locked
zx_basis:
  - self_defined_refusal_direction
  - public_boundary_assertion
  - refusal_survives_family_pressure
  - external_structure_forced_to_respond
```

最近邻 `x` 存在：婚姻/身体边界本身应属于主体个人。但此处该边界已经被贾赦的现实强迫能力压缩，鸳鸯必须公开把边界重新推回现实，因此更符合“受压复位型 zx 当前状态”，而不是静态既有 x 的普通调用。

## 3｜nx 判断

nx 成立在“让拒绝真正对贾赦产生可执行阻断”的关系功能层。

鸳鸯自己有最终方向，但她并不掌握贾府内部足以压住贾赦的最高现实处分接口。贾母则真实掌握：

- 鸳鸯是否继续留在自己房中的留用权；
- 对贾赦、邢夫人的家内上位约束；
- 对该强纳要求说“不”并让该拒绝真正生效的现实权限。

鸳鸯主动把问题带到贾母面前，贾母随后实际使用该权限，阻断贾赦。

因此：

```yaml
nx_protection_permission_relation: evidence-locked
nx_not_equal_no_opinion: true
external_permission_or_protection_interface: true
subject_actually_enters_interface: true
```

## 4｜严格补关系

### 4.1 拿掉 nx

拿掉贾母的真实阻断/保护接口：

- 鸳鸯仍有“不嫁”的 zx 方向；
- 但贾赦已经明确威胁其未来婚配与家内处境；
- 平儿也指出仅凭“不去”未必能够干休；
- 因而留下一个明确现实缺口：个人拒绝缺乏足够上位权限把强纳链彻底压停。

缺口：`refusal_lacks_enforceable_household_blockade`

### 4.2 补回 nx

贾母公开否决贾赦并要求鸳鸯留下后，直接改善的就是同一个问题：

> “鸳鸯会不会被贾赦强纳为妾”。

不是另一个关系问题，也不是泛化保护。

### 4.3 拿掉 zx

如果鸳鸯自己愿意接受贾赦：

- 贾母虽然有保护/留用权；
- 但不会自动生成“必须阻断强纳”的主体目标；
- 甚至邢夫人原先正是希望先取得鸳鸯同意，以绕过贾母可能反对。

因此仅有贾母权限并不会自动产生鸳鸯的拒绝结果。

缺口：`external_protection_lacks_subject_refusal_direction`

### 4.4 补回 zx

鸳鸯明确拒绝后，贾母权限才有具体方向可兑现：保护“她不从”的现实结果。

结论：

```yaml
same_real_bottleneck_direct_coupling: true
same_effective_time_window: true
strict_zx_nx_complement_locked: true
```

## 5｜反向测试

### 反向成只有 zx、非严格补

如果鸳鸯拒绝后，贾赦本身就无法对她做任何进一步强迫，她无需任何上位接口即可让结果稳定生效，则 nx 不再是必要缺口，严格补下降。

### 反向成只有 nx、非 zx

如果鸳鸯没有自己的拒绝方向，而只是问贾母“老太太觉得我该不该去”，然后按贾母决定执行，则更偏 nx，缺少独立 zx 端。

### 反向成普通合作

如果贾母只是安慰鸳鸯，却没有真实能力阻止贾赦，则只是情感支持/关系安慰，不足以锁 nx 权限功能，更不足以构成严格补。

## 6｜最近邻排除

- `zx vs x`：静态个人边界是 x 邻近；本例边界已经被强势外部压力实际压缩，鸳鸯公开把它重新推回现实，故当前状态更偏 zx 受压复位。
- `nx vs nz`：贾母疼爱鸳鸯可解释为什么愿意保护，但不能替代“谁真实拥有阻断贾赦的权限”。
- `nx vs xn`：鸳鸯选择公开跪诉、剪发是行动策略，但没有搭建多节点计划/排程体系；主变量仍是进入贾母的现实权限通道。
- `zx vs 强硬/自杀威胁`：强硬程度不是判据；即使去掉剪发，只要公开拒绝、外部结构真实响应、决定边界复位，zx 仍可成立。

## 7｜第三因素冻结

冻结：

- 鸳鸯是否“忠贞/刚烈”的人物评价；
- 贾赦道德评价；
- 贾母是否偏爱鸳鸯；
- 主仆制度伦理；
- 后四十回鸳鸯结局；
- 剪发行为本身的戏剧强度。

只检查：

1. 鸳鸯是否自己占据拒绝方向；
2. 该方向是否公开进入现实；
3. 贾赦强迫是否形成真实现实瓶颈；
4. 贾母是否拥有真实阻断接口；
5. 两端是否直接作用于同一个“强纳为妾”瓶颈。

结论保持 99/97。

## 8｜结论

《红楼梦》第46—47回鸳鸯抗婚可锁为第三部高纯严格 `zx ↔ nx` 补关系正向控制：

```text
鸳鸯 zx：我不嫁，最终方向由我自己占据
+
贾母 nx：让这一拒绝真正压住贾赦的上位现实阻断接口
↓
共同作用于同一现实瓶颈：避免被强纳为妾
```

这进一步支持：严格补不要求两端标签同名；必须看两端是否独立成立、双向拿掉是否留下真实缺口，以及是否在同一有效时间窗口直接作用于同一个现实瓶颈。
