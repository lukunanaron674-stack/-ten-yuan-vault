# x-scope 动态名义授权污染反测｜邓布利多第25号教育令 contraction 旧控制保留

## 1｜本轮为什么测它

近期火轴已经连续锁出三类污染：

```text
capability / performance delta ≠ x-boundary delta automatically
task-source / direction-source delta ≠ x-boundary delta automatically
nominal conferral / title / authorization ≠ realized current x automatically
```

因此必须反向攻击旧 `x-scope dynamic` 资产中最容易被第三条击中的类型：

> 一个上位制度文件把“最高处罚权”写给新节点，是否只是 source/formal authority 改名，而没有真实证明原 actor 的 current `x` 收窄？

被测人物固定为 Albus Dumbledore，被测对象固定为 Hogwarts 校内 rule/punishment final-override layer，不从校长身份、阵营、声望、能力或善恶倒推。

## 2｜事实链

### 阶段 A｜Educational Decree No.25 前

HarryPotter.com / Wizarding World 官方回顾给出一个直接 reality-test：Umbridge 不愿允许 Gryffindor Quidditch team 重新组建，McGonagall 将争议带到 Dumbledore，Dumbledore 坚持球队可以继续比赛；Umbridge 自己把这次被覆盖当成之后推动 No.25 的原因。

因此 pre 阶段不是：

```text
Dumbledore title = Headmaster
→ 猜他有 final override
```

而是：

```text
Umbridge refusal
→ appeal to Dumbledore
→ Dumbledore override changes the current result
```

即被测窄 permission 在迁移前已有 observable current effect。

### 迁移节点｜Educational Decree No.25

同一官方材料明确说明该教育令使 High Inquisitor 获得对 punishments 的最高权限，并可以改变其他 staff 已施加的处罚。

这里形式授权本身仍不够；真正关键是它与 pre reality-test 指向同一 final-override permission family：

```text
pre: Dumbledore can override Umbridge on tested school-rule/discipline dispute
post: High Inquisitor is assigned supreme punishment authority and alteration power
```

这不是只更换 source label，而是同对象层 final-authority node 被明确重分配。

## 4｜对象层 / 当前窗口

只测：

> Hogwarts 当前 disciplinary / punishment final-override permission。

明确不外推：

- Dumbledore 对课程、教师任命、城堡空间、凤凰社、Wizengamot 的其他权限；
- Umbridge 后来成为 Headmistress 后的更宽 lifecycle；
- Ministry 的 ultimate sovereignty；
- 角色阵营、威望或剧情胜负。

因此本轮结论不是 `Dumbledore x overall off`，而是一个窄 permission family 的 current contraction。

## 5｜关键压力：formal/source authority 到底什么时候能证明 x 迁移

本轮锁出动态版校准：

```text
formal/source authority change alone
≠ x-boundary transition
```

但如果同时满足：

```text
1. pre 阶段同一 permission 已有 subject-specific reality effect
2. post 文件/节点明确重分配同一 object-layer final authority
3. 原 actor 在该 narrow permission 上不再是 final override
4. 变化不是 capability、任务来源或 title-only
```

则 source/formal change 可以作为**迁移节点证据的一部分**，而不是被一律排除。

更短：

> **名义授权不能创造 x；但“pre reality-tested x + post same-layer final-authority reassignment”可以证明 x contraction。**

这与刘备领徐州 calibration 是镜像：刘备是 `conferral → acceptance → same-object reality effect` 后才锁 activation；本轮是 `pre reality effect → explicit same-layer authority reassignment` 后才锁 contraction。

## 6｜最近邻排除

### 6.1 vs 宋江招安 contraction（已 superseded）

宋江旧案只证明 task/direction source 上移，没有独立证明某项 subject-specific permission `true→false`，所以应撤回。

本轮则有：

```text
pre permission reality-tested
+
post same permission family final node explicitly reassigned
```

两者不是同一种“上级出现”。

### 6.2 vs 刘备名义授权 calibration

刘备案说明 accepted conferral 仍不能自动等于 x，必须继续看现实持有/调用/转移效果。

本轮进一步说明：formal authority change 也不能自动等于 contraction；必须先知道原 actor 真有被测 permission，再证明新制度确实改写同一 final node。

### 6.3 vs capability contamination

Dumbledore 不是“还能不能做到”发生变化，而是被测 final authority 的制度归属节点发生变化；不以能力强弱、执行技术或成功率作为 x 证据。

## 7｜拿掉 / 反向

### 拿掉 post authority reassignment

如果 No.25 只给 Umbridge 一个更响亮的 title，却没有 supreme punishment authority / alteration power，则 pre reality-tested Dumbledore override 不会因此自动消失，不能判 contraction。

### 拿掉 pre reality effect

如果我们只知道 Dumbledore 是 Headmaster，却没有前置 override reality-test，那么 post decree 最多证明 Umbridge 获得一项 formal authority；不足以高纯推出“Dumbledore 原有 current x 被收窄”。

### 反向门

未来若出现证据证明 No.25 后 Dumbledore 仍能在同一 punishment layer 无需 Umbridge/Ministry同层批准而直接覆盖并让结果生效，则旧 contraction control 必须降级或撤回。

当前官方材料与旧证据链支持相反结构。
