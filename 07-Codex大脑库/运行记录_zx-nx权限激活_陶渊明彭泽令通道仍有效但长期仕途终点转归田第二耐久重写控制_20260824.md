# 运行记录｜陶渊明彭泽令在任至归田：通道仍有效，但持续生涯终点发生耐久重写/恢复

## 1｜本轮问题

现有 zx↔nx 研究已经锁定：旧 nx 通道即使仍有效、开放、可用，只要主体当前最高行动目标改变并实际停止续接，旧 nx 当前窗口也可以结束。

进一步的问题是：

> “只是临时把另一件事提到最高优先级”与“长期停止旧路线、把持续生涯终点转到另一条路”是否需要分层？

徐庶离刘备救母是当前优先级覆盖；李俊拒绝朝京为官、转向出海则是长期终点重写。本轮用陶渊明彭泽令至归田，测试第二种耐久终点变化能否在高质量历史材料中复现。

## 2｜事实

陶渊明在《归去来兮辞并序》中自述：家贫、耕植不足自给，亲故劝其出仕，后来因家贫获得小邑任用；彭泽距家较近，因此求为彭泽令。他已经真实进入官职通道，并在任八十余日。

但在任不久，他即产生强烈归意，并明确写出“饥冻虽切，违己交病”“深愧平生之志”，说明继续仕宦虽可解决口腹，却与自身长期志向发生持续冲突。他原本还打算至少再等一个收成再离开，随后因程氏妹丧而提前自免去职。

《归去来兮辞》又把离职后的持续终点写得很清楚：归田、耕作、亲友、琴书，并明确否定继续追逐富贵。后世传记还记载其后征著作郎不就，后续征命亦不应，说明这不是一次短暂请假后返回原仕途的窗口，而是长期离开该持续路线。

资料锚：
- 陶渊明《归去来兮辞并序》：自述因贫求彭泽令、在任八十余日、在任即有归意并自免去职。
- 《南史·隐逸传·陶潜》/昭明太子《陶渊明传》：彭泽令解印绶去职，后征著作郎不就，并有后续不应征命记载。

## 3｜对象、触发、动作、结果

```text
旧现实路线：
正式官职 / 彭泽令履职
→ 已经真实接入外部官僚任用与职责体系
= nx 已激活

通道状态：
职位仍在
没有被罢免
没有被制度拒绝
仍可继续履职

主体侧变化：
持续仕宦与主体长期志向冲突
→ 在任即形成归意
→ 自免去职
→ 归田耕作
→ 后续征召不就

结果：
旧 nx 官职执行窗口结束
+ 持续生涯路线转向归田
```

## 4｜nx 判断

前段 nx 成立在“官职进入与履职关系”层。

陶渊明不是自己凭空生成彭泽令这一公共职位，也不是自己决定国家官职体系的职责边界。他通过既有任用关系取得职位，并实际履职，所以：

> `nx_prior_official_service_route: evidence-locked`

关键在退出时：旧通道并未失效。

没有证据显示：
- 上级撤回任命；
- 陶渊明失去任职资格；
- 彭泽令职责已经无法继续；
- 官僚路线拒绝他继续留任。

相反，他是自己“自免去职”。因此：

> 通道仍有效、开放、可用，但主体不再续接，旧 nx 当前执行窗口仍然可以结束。

## 5｜本轮最重要的深度区分

陶渊明不能被粗暴写成：

> “原来稳定想当官，后来人格突然变成隐士。”

其自序已经表明，仕宦很大程度上是为口腹和家贫进入的现实路线，而归田更接近其“平生之志”。

因此本轮锁的是：

> **durable endpoint rewrite or restoration**

即：

> 当前持续生涯执行终点从“继续官职路线”切换为“归田生活”，而且此后长期维持。

但不锁：

> **stable value system newly rewritten**

更准确地说，这是旧现实路线的长期退出，同时也是更早个人价值方向的重新显影/恢复。

这对目标改变深度很重要：

> 长期终点重写，不要求稳定人格价值观一定同步“换芯”。

## 6｜zx 检查

辞官本身不锁 zx。

陶渊明自免去职确实是主动决定，但没有看到他因此：
- 取得新的公共最高处分权；
- 改写官僚任用制度；
- 迫使原官僚系统围绕新的陶渊明公共决定接口运行；
- 扩大现实公共决定范围。

所以：

> **长期否定旧路线 ≠ zx。**

退出 nx 仍必须与 zx 独立判定。

`zx_from_resignation_itself: rejected_as_primary`

## 7｜xn 最近邻排除

归田以后当然出现耕作、生活安排等持续结构，但“辞去彭泽令”这一窄窗口没有以复杂的人员、资源、节点和流程重建作为主变量。

因此：

> 旧路线退出 = nx 当前性问题；
> 新生活具体怎样组织 = 若另切对象层，再检查 xn。

不能从“长期换生活方式”自动推出 xn。

## 8｜关键压力

关键压力不是督邮这一单一事件本身，而是：

> **现实仕宦路线与主体长期志向持续冲突。**

程氏妹丧是实际提前离职的触发条件之一，但陶渊明在此之前已经明确写出在任不久即产生归意，并原计划日后离开。

因此不能把整个耐久终点变化缩成：

> “妹妹去世，所以临时请假离职。”

后续长期不仕进一步排除了这一解释。

## 9｜拿掉测试

### 拿掉主体长期归意

如果陶渊明只是因妹丧暂时离任，并明确准备服丧后返回仕途，则最多接近徐庶型“当前优先级覆盖”，不能锁耐久终点重写/恢复。

### 拿掉后续不仕证据

只看一次辞彭泽令，仍能锁旧 nx 当期退出，但“耐久”置信会下降。

### 拿掉官职通道仍有效

如果他是被罢免、失去资格或职位被撤回，则会转成“外部节点撤回/通道失效型 nx 退出”，不能承担本轮主体侧长期终点变化控制。

## 10｜反向测试

临时优先级覆盖版本：

```text
彭泽令通道仍有效
→ 因家事暂时离职
→ 仍明确把返回仕途作为长期终点
→ 之后重新入仕
= 当前 nx 可暂时退出，但不是耐久终点重写
```

本例：

```text
彭泽令通道仍有效
→ 在任已持续产生归意
→ 自免去职
→ 明确否定继续追逐富贵
→ 归田
→ 后续征召不就
= 旧 nx 退出 + 持续生涯终点耐久重写/恢复
```

真正 zx 版本还必须另外增加：

```text
退出旧官职路线
→ 新增公共决定范围
→ 外部秩序围绕新的主体权力接口重排
= 才重新查 zx
```

原材料不支持。

## 11｜第三因素冻结

冻结：
- “不为五斗米折腰”的道德评价；
- 督邮个人形象；
- 程氏妹丧的戏剧性；
- 陶渊明后世“隐逸诗人”声望；
- 东晋政治环境的价值评价。

只保留：
1. 旧 nx 官职路线是否真实激活？是。
2. 离职时通道是否仍有效？是。
3. 是否由主体主动停止续接？是。
4. 是否只有临时更急任务？否，离职前已经形成长期归意。
5. 后续是否恢复旧路线？没有，且有征召不就证据。
6. 是否独立出现 zx 扩权？没有。

结论仍稳定。

## 12｜最近邻排除

### nx vs zx

主动辞官只是停止续接旧外部路线，不等于扩张公共决定权。

### nx vs xn

改变长期生活终点，不等于已经主动搭建复杂运行系统。

### 当前终点 vs 稳定本体

持续生涯终点发生耐久变化，也不自动代表稳定人格本体刚刚被重写。本例反而更像更早价值方向重新占据当前执行位。

### 临时覆盖 vs 耐久重写/恢复

- 徐庶：旧长期方向仍明确保留，只是救母临时压过旧任务。
- 李俊：明确否定朝京为官，转入持续出海路线。
- 陶渊明：官职通道仍有效，但自免去职、归田并后续不应征召，属于耐久退出；同时其长期个人价值并非新生，而是恢复/重申。

## 13｜结论

本轮可靠新增：

> **nx 当前退出的“目标改变深度”至少需要再拆一层：长期执行终点的耐久重写/恢复，不等于稳定人物价值观换芯。**

并继续支持：

> **通道仍有效，也不能推出当前 nx 仍然存在；主体是否继续把该外部方向作为自己的当前持续终点并真实续接，才是当前性判据。**

本轮只形成第二份高纯“耐久终点变化”材料（李俊 + 陶渊明），尚未达到跨三独立作品/材料的纪律升级门槛。

因此：
- 不修改 L1；
- 不修改 zx/nx 信息卡；
- 不修改准度卡；
- 不修改 `zx补nx_补卡`；
- 不新建同义 pending-review。

下一轮优先寻找第三份：旧 nx 通道仍有效，主体明确长期否定旧终点并实际执行新持续方向，同时再独立检查新方向究竟只是 x、形成 xn，还是进一步出现 zx。
