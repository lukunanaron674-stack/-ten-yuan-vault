# 李逵扯诏｜外部组织修复链不等于主体 xn 结构传播

## 1｜本轮问题

上一部独立作品《三国演义》关羽拒婚已经显示：主体只做一次拒绝，外部对手随后发生多层战略反应，不能把这些外部反应倒算成主体的 xn 结构重设。

本轮用《水浒传》李逵扯诏检验同一边界：主体只做一次强烈否决，但梁山与朝廷使团随后出现多层现场修复与路线反应，这些变化是否能反推李逵发生了 xn？

结论：不能。

## 2｜剧情事实、触发、对象、动作、结果

- 朝廷第一次派陈宗善到梁山宣读招安诏，要求梁山交出钱粮、军器、马匹、船只，拆毁巢穴并赴京接受招安。
- 萧让读罢，梁山众人已有怒色。
- 李逵从梁上跳下，夺诏扯碎，欲殴陈宗善，又殴打李虞候，公开辱骂皇帝与招安。
- 宋江、卢俊义当场抱住李逵，众人将其推下堂。
- 随后由宋江继续安抚陈太尉、处理御酒与使团现场；梁山其他头领也因御酒问题进一步发作。
- 李逵本人没有设计一套替代招安制度、外交流程或新的梁山国家路线。

最小结构：

```text
外部招安方向进入梁山
↓
李逵强烈否决、扯诏
↓
当前招安接口被打断
↓
宋江 / 卢俊义 / 梁山核心层制止李逵、修复现场
↓
使团与梁山组织继续产生后续反应
```

后半段传播是真实的，但主要由外部组织节点完成。

## 3｜nx 判断

### 当前招安执行层：rejected

李逵没有沿朝廷招安诏继续，也没有接受宋江当前推进的招安路径。他公开否决并破坏该接口。

因此：

- `nx_in_amnesty_execution_layer: rejected`

注意：这里只判李逵当前招安执行层，不把“梁山整体是否最终招安”倒灌成李逵个人当前 nx。

## 4｜xn 判断

### rejected as primary

李逵造成的后果很大：宣诏现场被打断、宋江卢俊义介入、钦差受惊、梁山众头领继续发作。

但这些连锁变化不能自动证明李逵发生 xn，因为李逵没有主动：

- 建立替代外交流程；
- 重设梁山与朝廷的谈判节点；
- 分配新的人员与资源；
- 设计新的招安或反招安成功条件；
- 建立持续运行的反招安组织骨架。

他做的是一次强烈的拒绝 / 破坏。

随后怎样制止他、怎样安抚钦差、怎样继续处理招安现场，主要是宋江、卢俊义及梁山组织的外部反应。

锁定：

- `xn_subject_structural_rewrite_in_amnesty_layer: rejected_as_primary`
- `external_organization_reaction_propagation: evidence-locked`

候选纪律：

> 主体动作导致外部系统连续调整，不等于主体主动重新组织了自己的运行结构。

## 5｜zx 判断

### rejected as primary

李逵公开、强烈地破坏诏书，也短暂改变了现场结果，但没有获得梁山“招不招安”的最终路线权；宋江、卢俊义等核心节点没有把路线决定位置交给李逵，后续梁山也没有围绕一个新增的李逵最高接口持续运行。

因此：

- `zx_in_narrow_stage: rejected_as_primary`

强烈、公开、造成巨大骚乱，只证明行为强度与现场结果变化，不能替代“主体决定范围上升”。

## 6｜关键压力

- 朝廷正式招安诏进入梁山；
- 诏书带有强制性与贬抑性要求；
- 宋江长期倾向招安；
- 梁山头领内部对招安存在情绪张力。

这些压力使李逵的反招安立场高显影，但不直接产生 zx 或 xn。

## 7｜拿掉测试

### 拿掉宋江等人的后续修复反应

只保留：

```text
招安诏进入
→ 李逵拒绝并扯毁
→ 不沿外部招安接口推进
```

则当前 nx 退出、xn 不成立的判断仍然成立。

所以后续多层组织反应不是李逵 xn 的分类支柱。

### 拿掉李逵的暴力动作，只保留明确拒绝

如果李逵只是明确拒绝招安而没有扯诏打人，当前招安执行层 nx 仍下降；只是外部组织反应强度会降低。

说明暴力主要改变反应强度，不改变“主体是否重设运行结构”的核心判断。

### 拿掉外部招安接口

如果根本没有朝廷招安方案进入梁山，就不能把本轮写成“nx 当前接口退出”，只能重新判断一次独立反抗行为。

## 8｜反向测试

### 反向成持续 nx

```text
朝廷提出招安
→ 李逵虽不满但接受宋江 / 朝廷方向
→ 实际按招安流程推进
= nx上升
```

### 反向成 xn

```text
李逵否决招安
→ 主动提出并组织另一套持续路线
→ 重配人员 / 资源 / 外交节点
→ 建立替代性的反招安运行结构
→ 原招安方案无法按旧骨架继续
= xn显著上升
```

### 反向成 zx

李逵的公开否决若迫使梁山核心层把最高路线决定权转给他，并让组织持续围绕其新增决定接口运行，才检查 zx。

## 9｜最近邻排除

### nx vs xn

不沿旧接口，只能证明 nx 在当前窗口退出；若没有主体主动建立替代结构，不能自动升级 xn。

### xn vs 外部反应传播

本轮核心：

```text
李逵扯诏
→ 宋江卢俊义制止
→ 梁山核心层修复现场
→ 使团与众头领继续反应
```

这些后半段变化不是李逵主动组织的结构传播。

### zx vs 强烈行为

现场破坏强度、声音大小、暴力程度都不能替代决定范围扩大。

### x

李逵没有稳定掌握梁山招安路线处分权。

## 10｜第三因素冻结

冻结：李逵莽撞性格、武力、宋江忠君倾向、诏书是否侮辱、御酒真假、第一次招安是否成功、后续梁山最终招安。

只保留：

```text
当前外部招安接口是否被李逵续接？
李逵是否主动建立替代运行结构？
后续多层变化是谁组织出来的？
李逵决定范围是否真实上升？
```

## 11｜跨作品位置

同型高纯控制目前为 2 部：

1. 《三国演义》关羽拒婚辱吴：主体拒绝联姻接口，孙权 / 东吴随后发生多层战略反应，但关羽本人没有建立替代外交结构。
2. 《水浒传》李逵扯诏：主体破坏招安接口，梁山核心层与朝廷使团随后发生多层修复 / 反应，但李逵本人没有建立替代招安结构。

共同候选边界：

> **外部反应传播 ≠ 主体 xn 结构传播。**

当前仅 2 部独立作品，未达到 3 作品门槛：

- 不新建 pending-review；
- 不修改 L1；
- 不修改 zx / nx 信息卡；
- 不修改 zx / nx 准度卡；
- 不修改 `zx补nx_补卡`。

## 12｜结论

本轮锁定：

> 李逵在当前招安接口上明确退出 nx；他的拒绝造成了很深的外部组织反应，但这些反应主要由宋江、卢俊义、梁山组织与朝廷使团完成，不能倒算成李逵的 xn 方案重设。李逵也没有获得更高路线决定权，因此不锁 zx。

本例是《三国演义》关羽拒婚控制之后的第二部独立作品复验。
