# 运行记录｜鸳鸯抗婚｜按 current canonical 恢复严格 `zx↔nx` 补

## 0｜本轮目的

本轮不重新贴人物标签，只复核此前因更严 candidate 门而被降级的“鸳鸯抗婚严格补”子结论。

当前仓库层级明确：

```text
canonical-current 正本 / 补卡
>
pending-review / 方法卡 / 运行记录
```

因此本轮必须服从 `zx补nx_补卡 v0.1` 的现行口径：

```text
nx 补 zx
= 补入外部权限接口、关系通道、救援与非正面解决方案

zx 补 nx
= 把借到的资源、关系与通道转成实际行动、公开决定和结果推进
= 补 nx 单独运行时“有路径却缺落地权能”的缺口
```

此前“拿掉 zx 后必须损伤 nx 自身保护/许可能力本体”的更严门，只能保留为 candidate，不得覆盖正本。

## 1｜剧情事实链

### 触发

贾赦欲强纳鸳鸯为妾，先由邢夫人试探，再通过鸳鸯兄嫂施压。

### 对象

当前对象层严格限定为：

> **“鸳鸯是否会被贾赦强纳为妾，以及她的个人拒绝能否获得现实阻断力。”**

不把“鸳鸯长期人生”“贾母整体家权”“贾赦全部婚姻行为”混入。

### 明确动作

1. 鸳鸯持续明确拒绝，先私下拒绝邢夫人与兄嫂；
2. 贾赦继续以家内权力与未来报复威胁，明确表示即使她另嫁也难逃其手；
3. 鸳鸯转到贾母面前，当众公开陈述拒绝，甚至剪发明志；
4. 贾母公开发怒，明确阻断贾赦取得鸳鸯；
5. 到第四十七回，贾赦“无法，又且含愧”，不敢见贾母，转而另买嫣红，鸳鸯没有被纳。

### 结果

```text
个人拒绝方向
+
外部上位保护 / 否决权限
→
“拒绝”从个人意志变成现实可执行结果
→
贾赦原强纳路径被迫退出
```

## 2｜zx 端

### 判定：成立

本阶段的 `zx` 不来自“性格烈”“敢剪头发”或“很强硬”。

真正证据：

```text
不嫁贾赦的最终个人方向由鸳鸯自己占据
→ 面对邢夫人、兄嫂与贾赦压力不交出方向
→ 将原本私下拒绝公开压入贾母面前的现实关系场
→ 迫使贾府上位秩序围绕她的拒绝作出实际响应
```

这是受压复位型的当前 `zx` 显影：个人方向在外部强制压入后，被主体公开重新推回现实。

### 最近邻排除

- 不是“强硬=zx”：若只有激烈语言但现实系统完全不响应，不足锁 `zx`；
- 不是普通 `x`：私人意愿本身可以有 `x` 邻近，但本轮有外部强制现实压入，鸳鸯必须公开把拒绝重新推回并触发秩序回应；
- 不是 `xn`：她选择何时公开、如何表达有局部组织性，但本轮主变量不是排程流程，而是拒绝方向是否公开获得现实位置。

## 3｜nx 端

### 判定：成立

鸳鸯并不占据“能否稳定阻断贾赦强纳”的最高家内否决位置。

```text
贾赦仍能通过家内身份、兄嫂、邢夫人继续推进强纳
→ 鸳鸯个人拒绝不足以稳定封死该路径
→ 贾母拥有真实上位留用 / 保护 / 否决权限
→ 鸳鸯实际进入该接口并公开陈情
→ 贾母真实使用权限阻断
```

因此这里的 `nx` 是**保护 / 否决权限型关系功能**，不是“鸳鸯没主见”。

### 最近邻排除

- 不是 `x`：贾母的家内上位否决权没有稳定进入鸳鸯自己的直接处分边界；
- 不是 `xn`：鸳鸯可以组织表达，但真正让贾赦路径停下来的关键权力仍在贾母；
- 不是一次求人自动 nx：关键是外部接口具有真实否决能力，且主体实际沿它推进。

## 4｜关键压力

关键压力不是“贾赦人品坏”或“封建社会”。

本轮只保留：

```text
贾赦具现实推进强纳的能力
+
鸳鸯个人拒绝不足以稳定阻断
```

这个现实瓶颈不能在第三因素冻结时直接删除，否则测试对象本身消失。

## 5｜拿掉测试

### 5.1 拿掉 nx

去掉贾母或等价的真实上位保护/否决接口，又不给鸳鸯新的等价权限：

```text
鸳鸯“不嫁”的 zx 方向仍成立
→ 但贾赦继续掌握现实强纳、报复与家内施压能力
→ 个人拒绝缺稳定现实阻断力
```

因此：

```yaml
nx_to_zx_gap_filling: true
```

`nx` 补的是 `zx` 的**现实阻断路径 / 权限缺口**。

### 5.2 拿掉 zx

保留贾母的家内保护/留用/否决路径，但拿掉鸳鸯自己明确、公开、坚持的拒绝方向：

```text
贾母仍有一般上位权限
→ 但只剩一条可用的保护/否决路径
→ 缺少把该路径具体兑换成“鸳鸯不嫁贾赦”这一公开结果的主体方向与落地输入
```

原文内部也给出强反事实提示：邢夫人的思路正是“老太太虽不依，搁不住鸳鸯自己愿意”；也就是说，若鸳鸯本人接受，贾母的留用/保护路径并不会自动等价生成同一“拒婚”结果。

按 current canonical `zx补nx_补卡`：

> `zx` 可以补 `nx` 单独运行时“有路径却缺落地权能”的缺口。

本例中，鸳鸯的公开拒绝把贾母已有的上位保护路径具体化、触发并兑现为同一对象层的现实阻断结果。

因此：

```yaml
zx_to_nx_landing_power_gap_filling: true
```

注意：这**不等于**声称鸳鸯拿掉以后贾母的家权本体会损坏。那是此前更严 candidate 门，不是 current canonical 的要求。

## 6｜反向测试

### 6.1 若只有鸳鸯拒绝，但贾母不能阻止

```text
贾母只是口头同情
→ 贾赦仍可强纳成功
```

则 `nx` 不足，严格补失败。

### 6.2 若只有贾母反对，但鸳鸯本人愿意

若鸳鸯接受强纳，贾母的留用偏好即使存在，也不能直接等同于“替鸳鸯生成拒婚方向”。

这说明主体方向输入不能被外部保护接口完全替代。

### 6.3 若鸳鸯自己取得稳定家内否决权

若她无需贾母就能合法、稳定阻断贾赦，则本轮 `nx` 显著下降，转查 `x/zx`。

## 7｜第三因素冻结

可以冻结：

- 贾赦善恶评价；
- 鸳鸯“烈性”人物评价；
- 阶级/性别宏大主题；
- 贾母是否偏爱鸳鸯；
- 后续鸳鸯结局。

必须保留：

```text
鸳鸯明确拒绝
+
贾赦仍能现实推进强纳
+
个人拒绝缺稳定阻断力
+
贾母拥有并实际使用真实否决权限
```

“贾母离不开鸳鸯”可以解释她为什么愿意使用保护接口，但不能替代：

- 鸳鸯自己的拒绝方向；
- 贾母真实否决能力；
- 两端把同一强纳瓶颈从不同方向补齐。

因此不足以打破 current canonical 的严格补。

## 8｜稳定本体 / 当前状态 / 行为功能 / 关系位置 / 外部压力

```text
稳定人物本体：本轮不锁
当前状态：鸳鸯 zx 高显影
行为功能：公开拒绝、剪发明志为 zx 行为显影，不单独等于本体
关系位置：贾母保护/否决接口属于鸳鸯当前 nx 关系功能
外部压力：贾赦强纳与家内施压使“个人拒绝如何现实生效”成为当前瓶颈
```

不得写成“鸳鸯整体变 nx”或“人物换芯”。

## 9｜strict complement 结论

两端先分别独立成立：通过。

同一当前现实瓶颈：通过。

```text
nx → zx
= 贾母真实保护/否决接口
→ 补鸳鸯个人拒绝缺现实阻断力

zx → nx
= 鸳鸯公开占据并坚持拒绝方向
→ 把贾母已有保护路径具体兑换成“拒婚成功”的公开现实结果
→ 补 nx 单独运行时“有路径却缺落地权能”
```

因此按 current canonical：
