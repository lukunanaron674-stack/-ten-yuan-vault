# 运行记录｜吕布认董卓义父：强外部承认与封赏不等于内部 zn 真正成立

## 1｜本轮问题

本轮不判吕布整个人物，也不把“三姓家奴”“反复无常”等后世标签直接当作火轴结论，只测试一个窄变量：

> **当一段关系已经被双方公开命名、被职位与封赏强化，而且外部体系持续把主体当作该关系成员时，能不能仅凭这种强外部承认，倒推出一项内部不可轻易让渡的 `zn` 已经真正成立？**

本轮结论：**不能。**

这条记录作为“被承认 vs 真正成立”研究槽的首份反向护栏，与既有宋江“zn 先成立、官方承认后来追上”正向控制互补。

## 2｜剧情事实链

### 阶段 A｜第3回：关系命名、封赏与外部承认全部到位

李肃以赤兔马、黄金、明珠、玉带和高位前景说动吕布。吕布在接受这些现实利益后，主动杀丁原，携首级投董卓。

随后：

```text
董卓公开接纳吕布
+
吕布主动提出拜董卓为义父
+
董卓进一步赐金甲锦袍
+
吕布获骑都尉、中郎将、都亭侯等职位/封赏
+
此后作为董卓心腹猛将进入其权力体系
```

也就是说，这不是“别人随口叫他一声儿子”，而是**关系命名 + 双方承认 + 现实奖励 + 组织位置**同时出现。

### 阶段 B｜第8—9回：关系遇到新的高压冲突

凤仪亭与貂蝉冲突后，董卓甚至掷戟追杀吕布。到第9回，王允再次激发吕布的受辱、情感与名声冲突。

吕布自己仍提到“父子之情”，说明这层外部关系命名确实存在于当前认知中；但王允以“各姓不同”“掷戟之时岂有父子情”拆掉这层外在关系理由后，吕布很快改判，并最终以诛董卓行动结束旧关系。

因此可观察到：

```text
外部关系承认很强
≠
内部原则拥有不可轻易让渡性

关系名分存在
≠
一项原则能在利益、羞辱、情感与危险冲突中稳定排序
```

## 3｜zn 检查

current `zn` 要求：

1. 原则命题或意义对象明确；
2. 主体认为它具有不可轻易抛弃性；
3. 无奖励、认可与观看时仍进入判断；
4. 在冲突中影响最终排序；
5. 跨阶段保留未来调用资格；
6. 边界、条件或让渡代价可说明。

本例如果把候选 `zn` 写成：

> “董卓既为义父，我应把父子关系作为不可轻易让渡的内部最终原则。”

则证据不足：

- 初始关系成立高度伴随赤兔马、金珠、官位与现实上升通道；
- 关系命名虽然公开存在，但其成立过程本身缺少“无奖励/认可仍成立”的独立证据；
- 遇到新的情感、羞辱、生命威胁和权力冲突后，这一所谓原则没有表现出稳定的未来指导资格；
- 第9回吕布虽短暂顾虑“父子之情”，但该顾虑很快被另一套外部说辞与当前利益/情感结构替换，最终没有保留为不可让渡原则。

因此本窄对象层：

```yaml
external_recognition_of_father_son_relation: true
zn_from_that_recognition: false
stable_zn_essence_locked: false
```

注意：这不等于“吕布绝对没有任何 zn”。本轮只排除：**不能从这段被公开承认的义父关系本身，倒推出内部 zn 已真正成立。**

## 4｜x 检查

本轮不把“认义父”本身判为 `x`。

但第3回中赤兔马、金甲锦袍等具体物件在交付后可形成物品占有 `x`；职位与组织权限是否形成稳定 `x`，则必须继续依据真实调用/处分边界逐项检查。

所以：

```text
关系称谓 / 封号 / 外部认可
≠
自动 x

具体完成交付的资源
→ 可另查 x
```

本轮不增加 pure-x 或 zn+x 共现统计。

## 5｜关键本体变量

真正检查的是：

```text
别人是否明确承认你“是什么”
↓
你是否也公开接受这个关系/身份
↓
该关系背后的内部原则，是否在拿掉奖励、认可和当前利益后仍独立成立
↓
遇到冲突时，是否仍有最终排序与未来调用资格
```

所以本轮锁出的边界是：

> **被承认得很正式，不等于内部本体原则已经真正成立。**

## 6｜拿掉测试

### 拿掉外部承认与封赏

如果去掉赤兔马、金珠、官位、董卓公开接纳，只保留“义父关系”这个词，目前没有足够证据证明吕布仍会把它作为不可轻易让渡原则长期排序。

因此，外部承认并不能证明内部 `zn` 的独立成立。

### 拿掉所谓内部原则，只保留外部承认

这基本接近原著最强证据面：关系称谓、封赏、组织位置都很强，但一旦冲突结构改变，关系可以被重新定义并终止。

所以：

> **外部承认不是 `zn` 的充分条件。**

## 7｜反向测试

若剧情改成：

```text
没有赤兔马 / 金珠 / 官位奖励
+
董卓失势或关系给吕布带来现实损失
+
第三方反复诱导其背弃
+
吕布仍明确认为“既认父子，此义不可弃”
+
并在多个未来冲突里继续按同一原则排序
```

那么该“父子义”才会明显向 `zn` 上升。

原著并没有提供这种稳定结构。

## 8｜最近邻排除

- `zn vs z`：义父称谓、都亭侯等外部承认/位置很强，但强 `z` 不等于内部 `zn`。
- `zn vs x`：赤兔马等具体资源可以真实进入占有边界，但资源进入不产生内部原则。
- `zn vs xn`：王允如何组织连环计属于流程，不解释关系原则是否真的成立。
- `zn vs zx`：吕布最终参与诛董卓的公开行动不能反向证明此前父子关系具有内部原则性。
- 情绪/受辱/欲望：只能解释当前驱动，不能替代 `zn` 的未来调用资格。

## 9｜第三因素冻结

冻结：

- “三姓家奴”后世评价；
- 吕布武力强弱；
- 董卓善恶；
- 貂蝉是否真心；
- 王允计谋是否正义；
- 后续吕布最终结局。

只保留：

```text
外部关系承认有多强？
候选原则在无奖励/认可时能否独立成立？
冲突时是否保留最终排序资格？
跨阶段是否仍可调用？
```

结论不变。

## 12｜本轮边界锁定

### 已锁

1. 强外部承认、关系命名、封赏与职位 **不是 `zn` 的充分条件**；
2. 关系被双方公开承认，也必须另过 `zn` 的无奖励、冲突排序与未来调用门；
3. 外部身份/关系认同可以很强，但内部原则仍可能未真正成立；
4. “被承认”与“真正成立”必须分开记录时间和证据来源。

### 未锁

1. 吕布稳定人物本体；
2. 所有义父/结义关系是否天然非 `zn`；
3. 任何 L2 canonical 修改；
4. 该边界的跨作品 pending-review。
