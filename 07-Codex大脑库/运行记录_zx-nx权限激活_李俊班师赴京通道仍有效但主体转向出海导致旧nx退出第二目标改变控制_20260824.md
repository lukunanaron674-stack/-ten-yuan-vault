# 运行记录｜李俊班师赴京通道仍有效但主体转向出海导致旧 nx 退出

## 1｜剧情事实

征方腊结束后，宋江军整体班师回京。李俊并非从未进入朝廷任务/军令通道：此前已经随招安后的梁山军持续承担征讨任务，第一百一十三回仍受宋江军令调度水军、探听太湖、参与攻取江南诸城，说明朝廷—宋江体系的任务关系此前已真实激活。

到第一百一十九回，军队仍在实际赴京朝觐的返程路径上。行至苏州城外，李俊诈称中风，请宋江不要误回军期限，自己病愈后“随后赶来朝觐”。宋江留下童威、童猛照看后继续赴京。随后文本明确揭示：李俊并非患病，而是与童威、童猛去找费保等人，按此前约定造船出海；后来从留下的小校口中，宋江进一步得知李俊“原非患病，只是不愿朝京为官”。

因此，旧朝觐/受官路线当时并未失效：宋江及其余将佐继续沿同一通道回京、朝见并受封。退出原因发生在李俊主体侧。

## 2｜最小结构

```text
前段：
招安后朝廷任务 / 宋江军令体系
→ 李俊真实承接并持续执行
→ 班师后实际随军赴京
= nx 已激活

当前窗口：
赴京 / 朝觐 / 受恩赐通道仍有效、开放、可继续
+
外部节点没有撤回资格或拒绝李俊

但：
李俊当前最高目标转向“不愿朝京为官 / 另寻出路”
→ 诈病脱离班师队伍
→ 主动停止续接旧赴京通道
→ 与费保等出海
= 旧 nx 当前执行窗口结束
```

## 3｜zx 判断

本窄退出窗口不以 zx 主判。

李俊主动脱队、欺骗宋江、最终出海，都能证明他不再沿旧外部方向续接，但并不能仅凭“我不走了”推出公共决定范围扩大。他没有因为退出而取得朝廷、宋江军或其他既有组织的新最高处分权，也没有迫使原系统围绕一个新增的李俊公共权力接口重排。

因此：

> nx 退出 ≠ zx 自动出现。

后续海外建立新的政治位置若要判 zx，必须另开阶段重新取证，不能倒灌到班师脱队这一窄窗口。

## 4｜nx 判断

前段 nx 真实成立：李俊已经长期沿招安后的朝廷任务与宋江军令体系行动，班师时也真实处在“回京朝觐”路径中。

本轮关键是：

> 旧 nx 通道并没有坏。

宋江等人继续回京，朝廷也继续接受朝觐并授官。没有证据显示李俊被撤销资格、被拒绝朝见、方案失败或环境使通道不可持续。

真正发生的是：

> 主体当前最高目标改变，并主动停止续接。

所以应锁：

`nx_old_route_after_exit: rejected_as_current_execution_route`

## 5｜关键压力

关键压力不是外部通道失效，而是李俊对“回京为官”这一终点的主观价值判断发生改变。太湖小结义、费保“不愿做官，只求快活”等前史可视作目标转向的背景，但不直接作为十元判据。

真正用于分类的是：

1. 旧 nx 曾经真实激活；
2. 旧通道此刻仍然有效、开放、可用；
3. 外部节点并未撤回；
4. 李俊本人主动停止续接；
5. 文本明确点破其“不愿朝京为官”。

## 6｜拿掉测试

### 拿掉“旧通道仍有效”

如果朝廷已经取消李俊资格、宋江拒绝带他回京或朝觐路径失效，则会转成“外部节点撤回/通道失效型退出”，不能承担主体目标改变机制。

### 拿掉“主体目标改变”

如果李俊仍以回京朝觐为当前最高目标，只是短暂患病并准备病愈后赶上，那么 nx 不应退出。

### 拿掉后续出海

即使不看海外后话，只要文本明确“原非患病，只是不愿朝京为官”且其实际脱离返京队伍，旧 nx 当前执行窗口结束仍成立。出海只强化新方向已经真实发生。

## 7｜反向测试

真正持续 nx：

```text
赴京通道仍有效
+
李俊当前最高目标仍是朝觐 / 受官
+
继续随军或病愈后赶赴东京
= nx 持续
```

主体目标改变型退出：

```text
赴京通道仍有效、开放、可用
+
外部节点未撤回
+
主体当前最高目标转向不为官 / 出海
+
主动停止续接
= 旧 nx 窗口结束
```

真正 zx 仍需额外看到决定范围公开扩大，本阶段没有。

## 8｜最近邻排除

### nx vs xn

诈病、联系费保、造船出海有明显计划组织邻近，可查 xn；但本轮主变量不是“如何出海”，而是“是否仍沿原朝觐通道续接”。所以 xn 只作次级邻近，不吞掉 nx 的退出判断。

### nx vs x

是否回京为官属于李俊个人当前选择边界，但朝廷朝觐/受官接口本身仍是外部制度通道。主体选择不再使用该通道，不等于该通道变成自己的 x。

### nx vs zx

停止服从、主动离开、成功脱队都不能代替 zx 的公开扩权门槛。

## 9｜第三因素冻结

冻结李俊后来是否成为暹罗国主、费保思想、宋江忠君、征方腊伤亡、招安价值判断，只保留：

- 旧 nx 是否真实激活；
- 当前回京通道是否仍有效/开放；
- 外部节点是否撤回；
- 主体当前最高目标是否改变；
- 主体是否实际停止续接。

结论保持 99/97。

## 10｜结论

> 《水浒传》李俊班师途中诈病脱队，是第二部高纯“主体目标改变型 nx 退出”控制。
>
> nx 当前性不能只检查外部通道是否还有效。即使通道仍有效、开放、可用，只要主体当前最高目标改变并主动停止续接，旧 nx 当前执行窗口也可以结束。

- 李俊：回京朝觐/受官通道仍有效，但目标转向不为官、出海。
