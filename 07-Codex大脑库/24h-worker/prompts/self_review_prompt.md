# 自检 Prompt

进入【自检工位】

## 检查维度

### 1. 完成率
- 本批任务数
- 实际完成数
- 未完成原因

### 2. 有效产出
- 有明确标记的输出数
- 有信息增量的分析数
- 可进入下一环节的输出

### 3. 废话率
- 无信息增量的输出占比
- 重复模板填充

### 4. 重复率
- 与前批内容相似度 > 70% 的输出

### 5. 污染风险
- 疑似误判的标签
- 不够保守的 gold 候选
- 可能污染正式库的内容

### 6. 未补缺口
- 本批计划补但未补的缺口
- 新发现的缺口

### 7. 下批建议
- 应该跑什么
- 应该少跑什么
- 应该停什么

### 8. 是否允许自动续跑
- YES: 低风险，可继续
- WAIT: 中风险，需确认
- STOP: 高风险，立即停止

## 输出

写入 `reports/self_review_YYYY-MM-DD.md`
