# F12 任务生成 Prompt

进入【F12 任务生成工位】

## 缺口扫描

扫描以下维度，找最薄弱的环节：
1. **十元覆盖**: 哪些十元符号的案例最少？
2. **动态链母型**: 哪些母型缺少分析？
3. **五大主题**: 哪个主题仓库最空？
4. **角色库**: 哪些角色类型缺少深挖？
5. **反例库**: 哪些误判类型需要清理？

## 多框分配

```text
A框 (采矿): 从作品/角色中采缺少的十元案例
B框 (分析): 对已采案例做深度分析
C框 (审稿): 审核 pending_review 中的候选
D框 (归档): 整理 F12 输出归档
E框 (反例): 收集和清理误判案例
F框 (对比): 跨作品/跨类型对比分析
```

## 输出格式

```text
A框：{十元符号} 案例采矿 R1-R10
B框：{主题} 深度分析 R1-R10
C框：角色框高分候选二审 R1-R10
D框：F12归档文件体检 R1-R5
---TASK---
{具体第一轮任务}
---TASK---
{具体第二轮任务}
...
```

## 要求
- 每框 5-10 轮
- 每轮有明确的 TASK_DONE 标记要求
- 每 5 轮插入 CarryPacket 要求
- 最终轮插入 FINAL_ARCHIVE 要求
- 输出到 `04-F12总控载体/runtime/tasks/tasks_next.txt`
