# 废矿候选 Prompt

进入【废矿清理工位】

## 扫描目标

寻找以下类型的内容：
1. 重复规则 — 同一规则在多个文件中出现
2. 低价值 F12 输出 — 空归档、无信息增量
3. 过时任务卡 — 已完成超过 7 天的单轮任务
4. 旧版本污染 — 版本号过时的文件
5. 情绪材料 — 只有情绪表达无结构内容

## 分类标准

### 低风险 → 加 `deprecated` 标签
- 已完成且超过 30 天的任务卡
- 旧版本明确的文件

### 中风险 → 移到 `99-旧库/待复核`
- 可能还有残留价值的过时规则
- 低信息量的 F12 输出

### 高风险 → 只生成删除建议
- 与核心理论相关的文件
- 中枢索引引用的文件
- 不确定价值的内容

## 输出格式

```markdown
# 废矿候选清单 YYYY-MM-DD

## 低风险 (加 deprecated 标签)
| 路径 | 原因 | 建议动作 |

## 中风险 (移 99-旧库)
| 路径 | 原因 | 建议动作 |

## 高风险 (只建议不执行)
| 路径 | 原因 | 建议 | 需人工确认 |
```

## 安全规则
- 不执行任何删除
- 不移动任何文件
- 只生成候选清单
