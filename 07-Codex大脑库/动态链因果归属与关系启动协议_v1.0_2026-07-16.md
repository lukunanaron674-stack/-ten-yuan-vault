# 动态链因果归属与关系启动协议 v1.1

## 0. 核心定义：叙事的最小单位是两个对象之间发生的事情

本协议冻结以下定义：

```text
叙事的最小单位，不是单个对象的介绍、性格、状态或个人传记；
叙事的最小单位，是两个对象之间发生的事情。
```

标准结构：

```text
叙事 = A对象 + B对象 + A/B各自状态与十元 + 有方向的作用 + 关系变化 + 可观察结果
```

对象不限于人物，可以是：

```text
角色 × 角色
角色 × 组织
角色 × 区域
角色 × 世界机制
组织 × 区域
组织 × 组织
区域 × 世界
角色 × 物件/异常体（仅当后者在当前窗口具有独立关系作用）
```

每条叙事至少回答：

```text
1. A是什么对象？
2. B是什么对象？
3. 当前窗口A是什么十元？
4. 当前窗口B是什么十元？
5. A通过什么机制作用于B？
6. B通过什么机制作用或反作用于A？
7. 双方哪些变量因此发生变化？
8. 关系前后发生了什么可观察变化？
9. 最终留下什么结果、痕迹或下一阶段条件？
```

禁止把以下内容单独视为完整叙事：

```text
单个角色的性格介绍；
单个区域的世界观说明；
只给A/B贴十元标签；
只写“A克B / A生B / A补B”而没有作用机制；
只有事件先后，没有两个对象之间的作用；
为了凑关系强行制造不存在的第二对象。
```

十元叙事因此必须从“对象是什么”推进到“两个对象之间发生了什么”。动态链则负责继续记录这段双对象关系如何跨阶段变化。

## 1. 协议目的

本协议只解决一个问题：

```text
两个对象或两个阶段先后出现时，何时可以判定生、克、补已经启动。
```

它不新增三元或十元定义，不修改现行关系盘，也不把三元与十元写成父子派生关系。

## 2. 基本原则：先后不等于作用

以下均不能单独证明关系成立：

```text
A先出现，B后出现；
A与B同时存在；
A结束后B增强；
两个对象在视觉上形成对照；
结局与开头不同；
人物经历某事件后表现改变。
```

这些只能证明共现、顺序、对照或变化。

正式关系必须额外回答：

```text
A通过什么机制，改变了B的什么变量？
```

## 3. 关系启动的最低条件

生、克、补进入正式动态链前，至少同时满足：

```text
1. 源端点与目标端点已经分别完成对象层和十元判断；
2. 端点所属阶段明确，关系运行过程中没有偷换对象或层级；
3. 存在可描述的作用机制，不只存在时间先后；
4. 目标端点至少一个内部变量发生可验证变化；
5. 该变化不能被同等强度的第三因素更直接解释；
6. 关系方向明确，不能正反两种写法都同样成立。
```

任一条件不满足，只能保留为候选关系。

## 4. 目标变量必须明确

关系不得只写：

```text
A 生 B
A 克 B
A 补 B
```

必须指出B被改变的具体内容。允许的目标变量包括：

```text
能力：B能够做什么、不能做什么；
边界：B能够成立到什么范围；
路径：B从当前状态通向哪里的路线；
资源：B能够调用、保存或失去什么；
关系位置：B在人物或结构之间处于什么位置；
显影强度：B在当前阶段被放大、压低、退隐或恢复；
状态：B当前如何运行；
持续条件：B能否继续存在、积累或进入下一阶段。
```

人物稳定本体不作为默认变化变量。

## 5. 生、克、补的机制写法

### 5.1 生

```text
源端点为目标端点提供成立、展开、积累、延续或进入下一阶段的条件。
```

标准句式：

```text
A通过【机制】，扩大或建立B的【目标变量】，因此判为A生B。
```

### 5.2 克

```text
源端点压缩、限制、阻断、改写或破坏目标端点继续成立的条件。
```

标准句式：

```text
A通过【机制】，压缩或改写B的【目标变量】，因此判为A克B。
```

### 5.3 补

```text
源端点补足目标端点独立运行时缺失的条件，使其能够成立、稳定或完成。
```

标准句式：

```text
A提供B缺少的【条件】，使B的【目标变量】恢复或完整，因此判为A补B。
```

互相需要不自动等于互补；必须分别说明双方各自补足了什么。

## 6. 人物本体、状态与行为必须分开

人物经历事件后发生变化，优先检查：

```text
当前状态是否改变；
行为功能是否改变；
关系位置是否改变；
外部场景是否改变；
时间压力是否改变；
显影强度是否改变；
动态链阶段是否改变。
```

不得直接写成：

```text
事件A改变了人物，所以人物本体从某十元变成另一十元。
```

只有人物的存在方式、核心痛苦与反复选择发生持续、跨阶段、主动的整体重构，才允许重新审核人物稳定本体；重新审核不等于已经改变。

## 7. 场景、光影与时间关系的作用权限

### 场景

场景可以改变人物或行为的：

```text
行动范围
资源获得
身体自由
交流条件
关系位置
选择成本
```

场景不能因气氛相似就直接改写人物十元。

### 光影

光影可以改变：

```text
观看方式
信息显露
注意力位置
显影强度
情绪感受
```

光影不能单独成为人物本体或关系端点的证明。

### 时间关系

时间结构可以通过：

```text
等待
积累
重复
延迟
错过
阶段推进
不可逆节点
```

改变对象的路径、资源或持续条件。

但“后来发生了B”仍不等于“时间生B”或“A导致B”。

## 8. 第三因素排除

若A之后B发生变化，必须检查：

```text
是否由场景变化直接造成；
是否由时间积累直接造成；
是否由另一人物或事件造成；
是否只是人物原有本体在新条件下高显影；
是否只是叙事剪辑制造了相邻感；
是否存在同等强度的反向解释。
```

无法排除时，正式输出：

```text
A与B存在顺序相关，但关系机制未锁定。
```

不得为了让链条完整而强行指定生、克或补。

## 9. 多阶段动态链规则

动态链必须按阶段拆写：

```text
阶段1：端点与关系
阶段2：目标变量发生的变化
阶段3：新端点是否形成
阶段4：关系是否继续、反转、退隐或转位
```

前一阶段的关系不能自动继承到后一阶段。

若端点的对象层、十元、体量或关系位置发生变化，后一阶段必须重新审核。

## 10. 三元与十元并行

```text
三元负责高概括的关系与结构判断；
十元负责具体对象及其关系位置；
动态链负责已审核对象在阶段中的变化过程。
```

三者可以相互校验，但不得互相派生：

```text
三元关系不能自动生成十元端点；
十元关系不能自动推出唯一三元比例；
动态链结果不能反向补写端点本体。
```

发生冲突时，返回原始证据与对象分层重新审核。

## 11. 标准输出模板

```text
### 动态链关系卡

- 对象A：
- 对象A对象层：
- 对象A十元与置信度：
- 对象B：
- 对象B对象层：
- 对象B十元与置信度：
- 所属阶段：
- 共现 / 顺序事实：
- A→B作用机制：
- B被改变的目标变量：
- B→A作用/反作用机制：
- A被改变的目标变量：
- 生 / 克 / 补方向：
- 双对象关系前后变化：
- 可观察结果/历史痕迹：
- 第三因素排除：
- 反向解释测试：
- 人物核心锚点是否保持：
- 结论等级：正式关系 / 候选关系 / 未判定
```

## 12. 当前冻结结论

```text
叙事的最小单位是两个对象之间发生的事情。
单对象描述不是完整叙事；十元叙事必须进入A↔B关系。
先后、共现、对照与结果差异都不自动等于生克补。
正式关系必须写清作用机制与被改变的目标变量。
目标变化优先落在状态、行为、关系、场景、时间结构、资源、路径和显影强度。
人物稳定本体优先保持，不作为默认变化变量。
无法排除第三因素或反向解释时，关系必须保留为候选或未判定。
多阶段动态链逐段审核，关系不得自动跨阶段继承。
三元、十元与动态链相互校验但不构成父子派生。
```
