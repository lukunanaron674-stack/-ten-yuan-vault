# R3｜五轴 × 传统五行生克结构验证

## 0｜目的

本轮不再询问“当前五轴能自由推导出什么关系”，而是按项目约束执行：

```text
传统五行生克 = 上位验收约束
当前五轴核心变量 = 被验对象
若结构推演不能得到传统关系 = 回推检查并最小修正对应轴
```

传统目标盘：

```text
相生：木→火→土→金→水→木
相克：木克土、土克水、水克火、火克金、金克木
```

本轮只使用五轴现有核心变量证明，不允许把“传统上就是如此”本身当作证明。

## 1｜五轴被验定义

| 五行轴 | 十元两极 | 当前核心变量 |
|---|---|---|
| 木 | zx ↔ nx | 最终方向与作用权来源：自身生成并占据方向 ↔ 不占最终方向、沿既有通道续接 |
| 火 | zn ↔ x | 对象独立成立资格与归属方式：保留自身成立 ↔ 纳入掌握、调用与处分边界 |
| 土 | n ↔ x并z | 对象跨越内外边界的方向：外→内纳入承载 ↔ 内→外映射外化 |
| 金 | xn ↔ z | 运行权与裁定重心配置：分布到规则节点流程 ↔ 收束到单一最高裁定点 |
| 水 | xz ↔ nz | 可逆性与对象特异回返空间：持续收窄 ↔ 保存、恢复或重建 |

## 2｜R3 判定规则

### 生

`A 生 B` 不定义为“所有 A 案例都会自动出现 B”。严格定义为：

> A 的核心变量发生有效结构变化时，可以直接建立、激活或重写 B 核心变量成立所需的结构条件；移除 A 的该结构贡献后，B 的可判定条件明显减弱或消失。

因此“生”是跨轴的**结构条件生成**，不是词义联想，也不是必然共现。

### 克

`A 克 B` 严格定义为：

> A 的核心变量能够直接压缩、否决或重写 B 的合法状态空间／迁移空间，使 B 原本可成立的某些方向失效。

因此“克”是跨轴的**状态空间约束**，不是情绪冲突，也不是谁赢谁输。

## 3｜相生五条验证

### R3-G1｜木生火｜PASS

```text
木：确定“谁从哪里发出作用、作用沿什么最终方向成立”
↓
形成 actor / object / responsibility 的有效分界
↓
火：对象才能进一步被判定为“独立成立”还是“被纳入掌握与处分边界”
```

结构桥：**作用来源与方向的确定，为对象成立资格与归属边界提供可判定对象。**

反事实删除：若完全取消作用来源与方向，只剩无来源变化，则“谁是独立对象／谁对其有归属与处分边界”缺乏稳定锚点。

结论：`木 → 火` 成立。

### R3-G2｜火生土｜PASS

```text
火：先确定“对象自身成立到哪里、归属边界到哪里”
↓
产生对象边界
↓
土：才可严格判定什么是内、什么是外，以及对象发生外→内还是内→外
```

结构桥：**本体成立／归属边界生成内外边界。**

反事实删除：若对象没有可确定的成立与归属边界，则“进入谁的内部／从谁的内部外化”失去对象锚点。

结论：`火 → 土` 成立。

### R3-G3｜土生金｜PASS

```text
土：对象跨越内外边界
↓
形成入口、出口、接口、承载点、外化点等可操作节点
↓
金：运行权可分布到这些节点／流程，或在关键节点收束为最高裁定
```

结构桥：**内外跨越把连续关系离散成可执行接口与节点，为运行权／裁定重心配置提供结构载体。**

反事实删除：若不存在任何内外边界与跨越节点，流程节点的配置失去一类核心结构来源，裁定也少了“在哪个边界点发生”的可定位性。

结论：`土 → 金` 成立。

### R3-G4｜金生水｜PASS

```text
金：规则节点、流程与最高裁定点决定哪些步骤可继续、终止、重开
↓
决定 path_set / reentry_right 的实际配置
↓
水：回返空间被保存、恢复、重建或持续收窄
```

结构桥：**运行与裁定结构直接写入路径是否继续以及能否重新进入。**

反事实删除：移除流程／裁定条件后，许多“还能不能回去、什么时候彻底关死”的制度性来源消失。

结论：`金 → 水` 成立。

### R3-G5｜水生木｜PASS

```text
水：决定仍有哪些路径、哪些回返口、哪些未来方向真实可达
↓
形成下一步 action path 的可用集合
↓
木：主体从可达集合中生成／占据方向，或沿既有通道续接
```

结构桥：**可逆性与回返空间定义下一轮可用方向集合，方向集合成为因果作用的起点条件。**

反事实删除：若不区分可达／不可达、可返／不可返，下一步“自身生成方向还是只能续接既有方向”的判定缺少真实路径约束。

结论：`水 → 木` 成立。

## 4｜相克五条验证

### R3-K1｜木克土｜PASS

```text
木：确定并占据一个作用方向
↓
作用方向可以强制对象跨越、穿透、绕过或重写既有内外边界
↓
土：原有“在哪里被承载／从哪里被外化”的状态空间被压缩
```

关键不是“行动发生在空间里”，而是：**方向性作用能够使某些原有边界状态不再可保持。**

结论：`木克土` 成立。

### R3-K2｜土克水｜PASS

```text
土：设置真实内外边界、入口、出口与承载位置
↓
直接决定某条返回路径能否穿越边界
↓
水：reentry_right / return_path 被开启、限制或切断
```

结构桥：**边界是回返路径的物理／制度门。**

结论：`土克水` 成立。

### R3-K3｜水克火｜PASS

```text
水：路径持续收窄，或保留／恢复对象特异回返空间
↓
限制对象还能否维持、恢复或重新获得原有成立资格与归属位置
↓
火：独立成立／掌握处分边界的可行状态被压缩或恢复
```

这里的“克”不是“命运毁灭本体”，而是：**可逆性约束对象身份／归属状态的可恢复集合。**

若某对象在路径上已经不存在任何能返回原资格状态的真实通道，则火轴对应状态中的一部分被水轴排除。

结论：`水克火` 成立。

### R3-K4｜火克金｜PASS

```text
火：对象是否独立成立、属于谁、谁拥有调用／处分边界
↓
决定哪些规则／流程对它有管辖资格，以及谁有资格进入裁定链
↓
金：运行权分布与最高裁定点的合法候选集合被限制
```

结构桥：**资格与归属先限定“谁／什么可以进入这套运行与裁定结构”。**

没有资格的节点即使技术上能执行，也不能自动获得合法裁定权。

结论：`火克金` 成立。

### R3-K5｜金克木｜PASS

```text
金：规则节点／流程／最终裁定点分配可执行权与终局决定权
↓
限制谁可以生成方向、哪些方向有效、哪些行动只能沿既有通道续接
↓
木：最终方向与作用权来源的状态空间被压缩
```

结构桥：**运行权与裁定权能直接否决或授权因果行动方向。**

结论：`金克木` 成立。

## 6｜是否需要回推修轴

本轮未出现：

- 与传统五行方向相反的结构关系；
- 必须修改某轴核心变量才能建立传统关系的情况；
- 为通过验收而交换五行身份或十元两极的情况。

因此：

```yaml
axis_revision_required: false
l1_revision_required: false
mapping_swap_required: false
```

需要新增的不是新轴定义，而是本文件明确的**跨轴桥接语义**：

```text
生 = 结构条件生成
克 = 合法状态空间约束
```

它们不得倒灌成“出现A就必然出现B”的案例级自动判定。

## 7｜防止循环论证的 hard guards

1. 不得用“传统五行说木生火”作为木生火的结构证据。
2. 不得因为两个主题在同一故事连续出现，就判定发生了生。
3. 不得因为两个主题冲突，就判定发生了克。
4. 相生必须指出：源轴的哪个变量生成了目标轴的哪个成立条件。
5. 相克必须指出：源轴压缩了目标轴的哪一部分合法状态空间。
6. 单个案例若无对象、方向、结果证据，只继承静态五行盘，不宣称发生了动态生克。
7. 若未来真实案例长期只能通过反向桥接解释传统关系，必须重开对应轴，而不是修改传统目标盘。

```text

+
```
