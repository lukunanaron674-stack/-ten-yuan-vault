# 五大主题与十元分层接口协议 v0.6

## 1｜正式层级

```text
十元：五行内部阴阳操作端
↓
五行：广义对立统一体
↓ is-a狭义[domain=叙事]
五大主题：五行在叙事／主题领域的狭义子项
↓ instance-of
作品中的具体主题结构
```

固定继承边：

```text
因果 --is-a狭义[叙事]→ 木 zx↔nx
本体 --is-a狭义[叙事]→ 火 zn↔x
空间 --is-a狭义[叙事]→ 土 n↔x并z
时间 --is-a狭义[叙事]→ 金 xn↔z
命运 --is-a狭义[叙事]→ 水 xz↔nz
```

## 2｜广义与狭义

五大主题继承五行的轴、阴阳端和生克位置，但不等于五行的全部广义外延。

```text
因果 is-a狭义 木
≠ 因果与木毫无关系
≠ 因果完全等于木全部含义
```

五脏同理：肝、心、脾、肺、肾分别是五行在生理领域的狭义子项。

## 3｜主题生克来源

```text
五行相生：木→火→土→金→水→木
叙事狭义：因果→本体→空间→时间→命运→因果

五行相克：木克土、土克水、水克火、火克金、金克木
叙事狭义：因果克空间、空间克命运、命运克本体、本体克时间、时间克因果
```

具体作品中是否启动关系，仍须有方向、对象、转折、高潮和结局证据。

## 4｜接口字段

标准输出必须保存：

```yaml
十元端:
五行父项:
领域: 叙事
叙事狭义主题:
is_a_narrow:
  child:
  parent:
  domain: 叙事
主题显影等级:
主题关系: none | 生 | 克 | 其他弱关系
动态链:
```

## 5｜层级纪律

```text
出现单个十元行为
≠ 五行轴完整显影
≠ 叙事主题成为主主题
≠ 主题生克已经发生
```

具体作品主题使用 `instance-of`；领域主题继承五行使用 `is-a狭义`，不得混写。

## 6｜动态链接口

动态链处理人物阶段、行为对子与关系迁移；`is-a狭义`只声明本体继承，不替代动态证据。

## 7｜废止项

- 废止“五大主题与五行是互不相关的两套系统”；
- 废止“相同十元组合只是偶然对照”；
- 废止不保存父项和领域的裸主题标签；
- 废止把具体案例直接写成五行广义本体。
