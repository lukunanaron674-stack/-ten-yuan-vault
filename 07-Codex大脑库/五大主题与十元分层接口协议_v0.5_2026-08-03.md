# 五大主题与十元分层接口协议 v0.5

## 1｜正式层级

```text
十元：五行内部的阴阳操作端
↓
五行：同行两个十元的对立统一体
↓
领域狭义定义：同一五行进入不同对象域后的具体名称与判据
↓
五大主题：五行在主题／叙事领域的五个狭义定义
```

固定映射：

```text
木 zx↔nx → 因果
火 zn↔x → 本体
土 n↔x并z → 空间
金 xn↔z → 时间
水 xz↔nz → 命运
```

## 2｜不再是“两套系统”

旧口径“主题系统与五行系统彼此独立，只是调用相同十元组合”停止使用。

正确口径：

> 五大主题不等于五行的全部广义本体，但它们是五行在主题领域的直接狭义显化。

类似五行进入生理领域对应肝心脾肺肾；领域名称不同，本体轴未改变。

## 3｜主题公式含义

```text
因果＝zx↔nx
本体＝zn↔x
空间＝n↔x并z
时间＝xn↔z
命运＝xz↔nz
```

`↔`表示一行内部阴阳两端的对立统一。历史文件中的`+`按同义旧写法读取，不再解释为一次案例内组合，也不再由额外关系层`z`补合生成主题。

## 4｜主题生克来源

```text
五行相生：木→火→土→金→水→木
主题显化：因果→本体→空间→时间→命运→因果

五行相克：木克土、土克水、水克火、火克金、金克木
主题显化：因果克空间、空间克命运、命运克本体、本体克时间、时间克因果
```

方向继承自五行；具体作品里关系是否启动，仍须按主题证据审计。

## 5｜层级不能倒推

```text
出现单个十元行为
≠ 整个五行对立统一已经完整显影
≠ 五大主题已经成为作品主主题
≠ 主题生克已经发生
```

人物、行为、状态、场景先在十元层判断；作品中心问题、转折、高潮与结局在主题层判断。

## 6｜动态链接口

动态链仍处理具体人物阶段、行为对子和关系迁移。五行—主题映射只提供领域身份，不替代动态证据。

标准输出必须分开：

```text
十元端：
五行轴：
主题领域狭义定义：
主题显影等级：
主题关系：none / 生 / 克 / 其他弱关系
动态链：
```

## 7｜废止项

- 废止“主题生成系统使用统一z补合十元双方”。
- 废止“主题组合只是基准构成、可能被其他五行组合替换”的本体级研究。
- 保留主题内部的分型、显影强度、主次、体量和动态研究。
