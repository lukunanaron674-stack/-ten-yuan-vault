# 运行记录｜关羽旧义 zn 先成立，曹操后续公开称许才追上：第三份“被承认 vs 真正成立”控制

## 1｜本轮问题

本轮不重新判“关羽整个人是什么”，也不把“忠义关公”“汉寿亭侯”等后世或外部标签直接当作火轴结论，只测试一个窄变量：

> **关羽对刘备旧盟 / 旧义的 `zn`，究竟是在曹操公开赞许、承认其“不忘故主”以后才成立，还是在曹操给出这类承认之前就已经独立成立？**

若后者成立，则支持：

> **外部承认可以识别、追上一个已经成立的 `zn`，但不能被倒写成该 `zn` 的生成时点、必要条件或充分条件。**

## 2｜剧情事实链

### 阶段 A｜外部高评价尚未到位，原则已经进入关系条件

《三国演义》第25回土山约三事，关羽在曹军包围和下邳失守压力下，不是无条件把最高关系归向交给曹操，而是明确提出“降汉不降曹”、奉养二嫂、得知刘备去向即可离开的条件。

本轮不把“约三事”本身等同稳定人物本体，只取其中与后续第26回一致的可观察变量：

```text
刘备旧盟 / 旧义
→ 在曹操公开称许之前
→ 已经进入关系成立条件与未来退出条件
```

### 阶段 B｜曹操厚待、爵禄持续增加，原则仍独立排序

第25–26回，曹操以礼遇、金银、府第、赤兔马、封侯等持续提高留曹收益。关羽得知刘备消息后，仍明确离开，封存金银、悬回侯印、不带曹拨人役，旧义直接进入高代价冲突排序。

这一步是 current `zn` 的核心证据：

```text
外部奖励 / 地位 / 留用利益 = 高
外部赞许是否存在 = 不重要
旧义仍决定最终去留
→ zn 已独立过门
```

### 阶段 C｜曹操的明确承认后来追上

关羽离开后，《三国演义》第27回写曹操制止蔡阳追赶，并公开评价关羽“不忘故主，来去明白，真丈夫也”，又说其“财贿不以动其心，爵禄不以移其志，此等人吾深敬之”。

此时发生的是：

```text
此前已经在利益冲突中成立的旧义 zn
→ 被曹操公开识别、赞许和承认
```

而不是：

```text
曹操赞许
→ 才生成旧义 zn
```

## 3｜zn 证据

本轮沿用 current canonical，将被测 `zn` 限定为：

> **对刘备旧盟 / 旧义不可因曹方的现实厚待、爵禄与留用条件而作废；一旦刘备去向明确，旧义仍拥有决定离曹归刘的未来指导资格。**

逐门检查：

1. **原则对象明确**：旧盟 / 旧义及其未来归向。
2. **无外部赞许仍成立**：在曹操公开评价“不忘故主”以前，关羽已将旧义写入约三事并在得知刘备消息后执行。
3. **冲突排序成立**：曹操现实待遇越高，旧义仍压过留曹收益。
4. **最终选择受其指导**：辞曹、挂印封金、离开。
5. **未来调用资格明确**：土山阶段已经预先规定“知刘备去向即离开”；第26回兑现。
6. **让渡边界明确**：可以暂居曹营、报答曹恩，但不允许曹恩替换旧义的最终归向。

因此本窄原则对象层：`zn = true`。

## 4｜外部承认检查

本轮把“承认”严格限制为：曹操对关羽“不忘故主、财贿不动心、爵禄不移志”的公开赞许与价值确认。

它对本案有三点作用：

- 能证明外部高位主体后来识别到了同一原则；
- 能改善关羽离开后的现实追击风险（曹操制止追赶）；
- 不能倒写成原则本身的来源。

因此：

```yaml
zn_before_explicit_recognition: true
explicit_recognition_arrives_later: true
recognition_is_necessary_for_zn: false
recognition_is_sufficient_for_zn: false
recognition_can_lag_established_zn: true
```

## 5｜x 检查

本轮不增加 `x`、`zn+x` 或 strict 统计。

已有火轴记录已分别验证：

- 曹赐金银、赤兔马等具体资源可有现实 `x`；
- “汉寿亭侯”名位本身不能只凭称号、印信和外部承认倒推完整现实 `x`。

因此本轮只研究“原则成立时序 vs 承认时序”，不让同一个关羽案例同时在多个统计槽重复领工资。

## 6｜拿掉测试

### 拿掉曹操后续赞许

删除第27回曹操“不忘故主”“财贿不动其心、爵禄不移其志”的公开评价：

- 第25回旧义已进入关系条件；
- 第26回得知刘备消息后仍离曹；
- 反奖励选择仍完整。

→ `zn` 仍成立。

因此外部承认不是必要条件。

### 拿掉此前 zn，只保留外部承认

若一个人物此前并未在无奖励 / 高代价冲突中按某原则排序，只是后来被上位者称赞“忠义”“有原则”，则不能仅凭评价倒推其内部 `zn` 真正成立。

→ 外部承认也不是充分条件。

## 7｜反向测试

若剧情改成：

```text
曹操未赞许时
→ 关羽愿意因爵禄长期留曹、旧盟可作废

曹操后来公开称其忠义后
→ 才开始表现“不忘故主”
```

则应优先检查 `z / 身份收益 / 外部认可驱动`，不能把后来的评价回填成此前已经存在的 `zn`。

原著不符合这个反向结构。

## 8｜最近邻排除

- `zn vs z`：本轮最关键的 `zn` 证据先于曹操公开赞许，而且在爵禄奖励存在时仍发生反奖励选择。
- `zn vs x`：曹赐资源、爵位名义、赤兔马等现实对象另按 `x` 硬门审计，不参与本轮 `zn` 成立时序。
- `zn vs xn`：安排车马、护送二嫂、离开路线回答“怎么离开”，不解释“为什么必须离开”。
- `zn vs zx`：离曹造成公开现实响应，不等于旧义本身是 `zx`。
- 稳定人物本体：不锁，只锁当前原则在承认之前已经成立。

## 9｜第三因素冻结

冻结：

- 后世关公神化与“武圣”评价；
- 刘曹阵营正邪；
- 关羽武力；
- 后续过五关斩六将的戏剧强度；
- 曹操是否真心欣赏或有政治考虑。

只保留：

```text
曹操明确承认以前，旧义是否已经进入判断？
现实厚待与爵禄是否足以替换它？
后来承认到来后，是生成原则还是识别既有原则？
```

结论不变。
