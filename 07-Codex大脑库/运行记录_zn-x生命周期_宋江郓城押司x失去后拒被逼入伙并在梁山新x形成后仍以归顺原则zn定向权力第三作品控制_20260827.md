# 宋江｜旧押司 x 失去、后续梁山新 x 形成，而归顺/合法回返 zn 跨载体持续｜火轴第三作品生命周期控制

## 1｜本轮只测试什么

本轮不把“押司”“忠义”“招安派”这些身份或标签直接当作火轴结论，只测试一个跨阶段问题：

> **宋江原郓城押司的现实职事 `x` 因杀惜逃亡而失去以后，是否仍保留一项可跨阶段调用的内部原则 `zn`；当后来完全不同的梁山军事/组织 `x` 形成时，该原则是否继续约束新 `x` 的使用方向？**

对象层：

```text
旧 x：郓城县押司值日、公文处理与县衙事务中的现实职事权限
zn：即使个人已经犯罪、逃亡或被迫进入江湖，也不愿把“永久草寇化”当作最终政治/法理归属；宁可接受官府处分并保留日后合法回返的可能，也不愿被强行逼入伙；后来取得梁山现实权力后，仍把归顺朝廷作为可持续未来方向
新 x：后期梁山主帅对山寨人马、军事行动与俘虏处置的现实调用/处分边界
```

不锁宋江整体稳定人物本体。

## 2｜剧情事实链

### 阶段 A｜郓城押司：旧 x 真实成立

《水浒传》第18、21回：

- 宋江作为值日押司，实际承接、持有并呈递济州府实封公文，带何涛进入县衙，向知县说明公务并提出夜间捕拿的执行建议；
- 第21回又明确说自己有“县里事务”“公事”需要分拨。

因此这里不是单凭“押司”称号判 `x`，而是看到明确公务对象、公文接入与职事节点围绕其现实职务运行。

### 阶段 B｜杀惜后：旧 x 真实失去

第22回后，宋江成为杀人案在逃者，离开县衙体系投奔柴进等处；原郓城押司值日、公文处理与县衙事务权限不再由其运行。

这不是名义降权，而是原职事现实窗口断开。

### 阶段 C｜旧 x 已失时：zn 仍直接进入高代价排序

第36回，宋江回乡后面对官差，不选择继续躲在江湖或由梁山人马庇护，而主动决定“挺身出官”。他明确比较两条路：

```text
继续躲在江湖
→ 可能被一班杀人放火的弟兄卷入
→ 难以日后回家侍父

接受官府处分
→ 即使断配他州外府
→ 仍有程限
→ 日后仍有合法归来并侍父的可能
```

随后梁山刘唐、吴用、花荣等试图把他截上山。宋江反而坚持：

- 不准杀防送公人；
- 不准擅自开枷，理由是“国家法度”；
- 若强迫他入伙，会陷他于“不忠不孝”，宁可自刎；
- 只愿先按法赴江州听候限满，之后再谈相会。

说明原押司 `x` 已失后，该原则并未因职位消失而退出；反而在“自由/安全 vs 官府处分/合法回返”冲突中继续排序。

### 阶段 D｜后期梁山新 x 已形成：同一原则继续定向新的现实掌握

到梁山后期，宋江已拥有完全不同的现实 `x`：山寨主帅可以调动军马、处分俘虏、决定军事追击与停止。

第71回以后，他公开提出招安愿望；第77回两赢童贯后，即使梁山处于军事优势，他仍因“素怀归顺之心”下令不尽情追杀、收军，并对被俘朝廷将领说明梁山“本无异心，只要归顺朝廷，与国家出力”。

因此观察到：

```text
旧郓城公务 x = on
→ 杀惜逃亡：旧 x = lost
→ 无旧 x 条件下：zn 仍高调用，拒绝被强逼永久入伙
→ 后期梁山新 x = on
→ 同一 zn 继续限制新 x 的用途与最终方向：不以军事优势永久固化草寇身份，而持续寻求归顺/合法回返
```

## 3｜zn 证据

本轮原则不能粗写成“宋江永远服从官府”，因为他私放晁盖、杀惜、后来领导梁山，都说明他并非机械服从。

更精确的原则是：

> **即使现实上被逼出原秩序，也不愿把永久草寇化视为最终合法归属；可以承担官府处分、暂时处于江湖甚至后来掌握梁山武力，但未来仍应保留并追求回到合法政治/法理秩序的资格。**

该原则通过当前 `zn` 门：

1. 原则命题明确：最终不愿永久把自己定义为草寇，保留合法回返/归顺方向。
2. 非一次口号：第36回旧 x 已失时拒绝被逼入伙；第71/77回新 x 已形成后继续追求招安。
3. 冲突排序：第36回宁受刺配、宁冒风险也拒绝强行入伙；第77回军事优势下仍限制追击与杀戮以服务归顺方向。
4. 跨阶段未来调用：从旧公务身份丢失，到刺配，再到梁山高位，新载体变化后仍重复调用。
5. 边界可说明：不是“凡官府命令都对”，而是“最终政治/法理归属不愿被永久切断；合法回返资格值得保存”。
6. 外部奖励不是唯一解释：第36回最硬证据发生在没有官职奖励、反而要接受官府处分的窗口。

因此当前窄原则对象层 `zn` 成立。

## 4｜x 证据与生命周期

### 4.1 旧 x

旧 `x` 只锁郓城县押司的现实公务处理/接入边界，不锁“整个县政归宋江掌握”。

证据：值日、公文接入、呈递、县衙事务现实运行。

### 4.2 旧 x lost

杀惜逃亡后，这套具体公务权限现实断开。

### 4.3 新 x

后期梁山主帅 `x` 属于另一对象层：山寨军马、军事行动与俘虏处置可由宋江直接调动/决定。第77回“停止追击、收军、释放/礼待俘虏并传达归顺意愿”给出直接现实处分证据。

所以不是“同一个 x 一直偷偷存在”，而是：

```text
旧 x lost
→ 一段时间无该 x
→ 后来形成完全不同的新 x
```

而 `zn` 跨这个替换链继续拥有未来调用资格。

## 5｜本轮真正锁出的生命周期结论

本轮与前两份 lifecycle 不同：

- 严颜：领地/军政 `x` 真实失去后，`zn` 在同一高压窗口继续排序；
- 唐僧：关系处分 `x` 当前窗口关闭并后来恢复，同一 `zn` 后续再次调用；
- 宋江：**旧 `x` 失去，后来换成不同类型的新 `x`，同一 `zn` 跨载体持续，并继续定向新 `x` 的使用。**

因此第三份控制支持：

> **`zn` 的未来调用资格不绑定某一个固定 `x` 载体；旧掌握边界可以失去、替换或重建，而同一原则仍可能跨载体持续。**

更短：

```text
old x lost
+
new x later formed
≠
zn must be replaced
```

## 6｜拿掉测试

### 拿掉旧 x

原著已经真实发生：押司职事丢失。

结果：第36回 `zn` 仍进入最终排序。

### 拿掉新 x

第36回时宋江还没有后期梁山主帅 `x`，原则已经成立并决定他宁赴江州也不被逼入伙。

因此新 `x` 也不是该 `zn` 成立的前提。

### 拿掉 zn

若没有“最终仍应保留合法回返/不愿永久草寇化”的原则：

- 第36回最省事的路径应是直接接受梁山截取与保护；
- 后期梁山军事优势形成后，也缺少稳定理由反复把现有武力重新定向到招安/归顺。

原著不是这种结构。

## 7｜反向测试

如果剧情是：

```text
押司 x 一失
→ 宋江从此完全接受永久草寇身份
→ 后来梁山新 x 形成后，原“合法回返”标准彻底不再出现
```

则支持旧 `zn` 已退出/被替代。

本例恰好相反：第36回与第71/77回跨大阶段复现同一方向。

## 8｜最近邻排除

- `zn vs z`：第36回最硬证据发生在无官位奖励、反而接受刑罚/刺配时，不能只解释为求认可。
- `zn vs xn`：绕路、赴江州、招安操作回答“怎么实现”，不解释“为什么最终仍要保留合法回返方向”。
- `x vs 名义职位`：旧 `x` 不靠“押司”二字，而靠值日、公文处理与现实公务节点；新 `x` 不靠“寨主”称号，而靠直接调兵、停战、俘虏处分。
- `x vs zx`：本轮只锁已经形成后的稳定调用/处分范围，不重复把每次公开号令都记作扩权。
- lifecycle vs strict complement：本轮只增加 lifecycle，不增加 strict positive/negative 统计。

## 9｜第三因素冻结

冻结：

- 宋江“忠义”“投降派”等后世标签；
- 朝廷是否值得归顺的价值评价；
- 高俅等奸臣因素；
- 梁山最终招安成败；
- 宋江个人名声收益。

只保留：

1. 旧公务 `x` 是否真实成立并失去；
2. 失去后第36回是否仍出现高代价的合法回返原则排序；
3. 后来是否形成不同的新现实 `x`；
4. 新 `x` 形成后同一原则是否再次决定权力用途与最终方向。

结论不变。
