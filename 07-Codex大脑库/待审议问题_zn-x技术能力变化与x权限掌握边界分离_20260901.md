# 待审议｜zn-x：技术能力变化 ≠ x 权限掌握边界变化

> L4 `cross-work-control`，不是 L2 正本。current canonical 高于本文件；当前只有 2 controls / 2 independent works，不得自动升格 `pending-review`。

## 1｜当前候选边界

当前两部独立作品的纠偏共同支持：

> **technical capability / performance / discoverability / bandwidth / successful reversal probability 的变化，可以在 current `x` 的归属、权限类型、对象子集、处分/否决边界、mandatory decision node 与 execution entitlement 均未变化时独立发生。能力变强不自动等于 `x-scope` 扩张；能力变弱不自动等于 `x-scope` 收缩。**

因此固定反误判：

```text
capability delta
≠
permission-boundary delta automatically
```

只有出现可观察的 permission / object-scope / decision-node / credential / veto / entitlement 变化，才允许进入 `x-scope` dynamic transition 统计。

原研究曾把：

```text
→ rover 软件改造

```

分类成 `channel-capacity / expressive-resolution x-scope expansion`。

锁：

```text
communication capability / expressive capacity ↑
≠
x-scope ↑ automatically
```

原 x-scope dynamic increment 已 superseded，不进入 current `dynamic_transition_controls`。

### B｜Ray Arnold｜Jurassic Park (1993)｜99/99 classification correction

原研究曾把 Nedry sabotage 后 Arnold 无法直接发现并逆转隐藏 command、只能转向 whole-system shutdown/reboot，分类成 `permission-path-specific x-scope contraction`。

审计后撤回。现有事实高纯证明技术可发现性、可逆转性与成功恢复路径恶化，但没有 ≥95 证据证明 Arnold 的 credential、授权对象子集、处分/否决边界、mandatory veto node 或 execution entitlement 被撤销、转移或缩小。

锁：

```text
technical operability / discoverability / reversal capability ↓
≠
x-scope ↓ automatically
```

原 x-scope dynamic increment 已 superseded，不进入 current `dynamic_transition_controls`。

## 3｜双向最小差异

```text
能力扩张但权限不变：The Martian
能力收缩但权限不变：Jurassic Park
```

两条方向相反，但都说明同一件事：

> **能力层与权限掌握层必须分账。**

## 4｜什么情况下才算真实 x-scope 变化

至少需要出现以下一种可观察结构：

- 原不可调用对象子集真实进入主体可调用范围，或原可调用子集被排除；
- 某 permission 从 `false→true` 或 `true→false`；
- credential / ACL / authorization entitlement 被授予、撤销、转移或集中；
- 新 mandatory veto / co-approval node 插入，或原节点退出；
- current execution entitlement 真实转移到另一主体；
- same-layer pre-effect veto 结构变化；
- 可分割资产的 quantitative scope 真实改变；
- permission 的期限、revocability、return obligation、ultimate title 或 object scope 发生真实迁移。

只有“更快、更慢、更聪明、更难、更高带宽、更低成功率、更难发现、更容易执行”而没有上述结构时，默认先判 capability delta，不计 `x-scope` dynamic。

## 5｜与现有有效 dynamic controls 的最近邻排除

- Ripley / Alien：明确 `revoke=true→deadline→false`，是真 permission persistence 改变。
- Eduardo / The Social Network：明确 equity share `34.4%→0.03%`，是真 quantitative object scope 改变。
- Ramius / The Hunt for Red October：mandatory credential distribution 从双节点分散转为单 actor 集中，是真 decision gate 改变。
- Otto Octavius / Spider-Man 2：对象内部新增 independent execution node，使 exclusivity/final control 真实收窄。

The Martian 与 Jurassic Park 的现有证据都没有达到这些 permission/node/scope 级变化。
