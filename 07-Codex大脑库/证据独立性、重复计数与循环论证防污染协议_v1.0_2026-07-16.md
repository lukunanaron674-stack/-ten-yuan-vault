# 证据独立性、重复计数与循环论证防污染协议 v1.0

## 1. 协议目的

本协议解决三个容易被混淆的问题：

```text
同一事实被换几种说法，算不算多条证据；
同一事件在多个对象层被分别分析，能否互相补高置信度；
结论能否反过来证明产生它的前提。
```

本协议不新增三元或十元定义，不修改既有生克补位置，也不把三元与十元写成父子派生关系。

## 2. 基本原则：证据条目数量不等于证据来源数量

同一原始事实即使被拆成多个描述，仍然只有一个原始证据来源。

例如：

```text
人物在审讯中没有屈服；
人物面对威胁仍坚持原判断；
人物在高压下保持立场。
```

若三句话都来自同一场审讯、同一动作或同一段台词，它们不是三次独立证明，只是同一事实的三个解释角度。

因此禁止：

```text
同一镜头拆成多条；
同一句台词改写成多个关键词；
同一结局分别命名为选择、结果和命运；
同一行为同时充当本体证据、关系证据和主题证据后，再把三层相加提高置信度。
```

## 3. 证据必须记录来源簇

每条证据除对象与层级外，还必须标记来源簇：

```text
同一事件；
同一镜头；
同一段台词；
同一叙述信息；
同一结果；
同一外部材料。
```

属于同一来源簇的证据可以承担不同层级的分析功能，但不能在置信度计算中伪装成多个独立来源。

标准写法：

```text
来源簇 S1：监狱中持续写作
- 本体层解释：是否延续跨阶段信念
- 状态层解释：高压下的集中或孤立
- 行为层解释：保存、传递或反抗
- 场景层解释：行动与交流受限
- 时间层解释：长期累积与临近结局
```

S1 可以被多层使用，但仍然只是一组原始事实。

## 4. 独立支持与重复支持必须分开

### 4.1 重复支持

以下属于重复支持：

```text
同一事件的不同措辞；
同一行为的连续近景与特写；
同一人物在同一压力条件下的重复反应；
旁白复述画面已经表达的内容；
结局对前面同一事实的再次总结。
```

重复支持可以提高显影清晰度 M，但不会自动提高结构判断的证据独立性 C。

### 4.2 独立支持

独立支持通常至少改变以下一项：

```text
阶段；
情境；
关系对象；
代价结构；
可选路径；
证据来源。
```

例如，人物在不同阶段、不同关系和不同代价下仍作出相同核心选择，才构成更强的本体层独立支持。

因此：

```text
重复十次同一种反应
不等于
跨阶段、跨情境的稳定锚点。
```

## 5. 人物稳定本体必须依赖跨条件证据

人物稳定本体不能只靠同一场景、同一关系或同一种压力反复证明。

本体层高置信至少应检查：

```text
不同阶段是否成立；
外部条件变化后是否成立；
关系对象变化后是否成立；
有替代路径时是否仍选择同一核心方向；
拿掉单一关键事件后是否仍可识别。
```

若所有证据都依赖同一个监狱、同一个敌人、同一次创伤或同一段恋爱关系，则最多证明该条件下的状态、行为功能或关系位置，不能仅凭数量升级为稳定本体。

## 6. 同一证据多层使用，不允许跨层互证成闭环

允许：

```text
同一事实分别分析人物状态、行为功能、场景、时间结构和光影。
```

禁止：

```text
因为行为像 zx，所以人物本体是 zx；
因为人物本体是 zx，所以该行为证明 zx；
最后把两条互相引用写成双重证据。
```

同样禁止：

```text
场景被判为 xn
→ 用来证明人物状态 xn
→ 再用人物状态反证场景 xn。
```

每个对象层必须拥有自己的直接证据或明确的跨层作用机制，不能用结论互相抬高。

## 7. 结论不得反向证明前提

正式禁止以下循环：

```text
人物是 zn，所以他的选择是 zn；
他的选择是 zn，所以人物是 zn。

A 克 B，所以 A 必然是 x；
A 是 x，所以 A 克 B。

作品主主题是命运，所以结局属于命运；
结局属于命运，所以作品主主题是命运。
```

判断顺序必须保持：

```text
原始事实
→ 对象归属与层级
→ 候选解释
→ 排除最近邻与反向解释
→ 形成结论
```

形成的结论只能用于预测、复核或发现新材料，不能回头充当生成它时缺失的原始证据。

## 8. 预测证据与回填证据分开

一个已经形成的候选可以提出预测：

```text
若人物稳定本体为 zn，后续在不同条件下应继续出现何种存在方式、核心痛苦或反复选择？
```

后续新材料若独立出现，可作为新增支持。

但禁止：

```text
先按候选解释旧材料；
再把解释后的旧材料当作新证据回填；
最后宣布候选获得重复验证。
```

只有候选形成之后、来自不同来源簇的新事实，才能真正增加独立验证。

## 9. 三元与十元相容不等于双重独立证据

三元与十元必须并行判断，但若二者使用的是同一批原始事实，则它们的相容只能说明解释没有明显冲突，不能被计算为两套独立证据。

因此：

```text
三元判断与十元判断相容
≠ 证据数量翻倍；

三元 C-A
≠ 十元自动 C-A；

十元 C-A
≠ 三元自动 C-A。
```

只有两层各自获得额外、符合本层权限的独立证据时，才可分别提高置信度。

## 10. 动态链不得重复计算同一变化

一项目标变化不能同时被写成多个阶段、多个箭头或多个关系效果，除非能够证明它们改变的是不同变量或发生在不同阶段。

例如：

```text
人物失去行动自由
```

不能仅通过改写为：

```text
路径被压缩；
边界被限制；
状态被压迫；
关系位置下降；
```

就自动算作四次独立克制。

必须说明：

```text
这些是否为同一变化的不同描述；
还是具有不同机制、不同目标变量和不同时间节点的真实多重作用。
```

关系作用量 E 也不得因重复命名同一结果而叠加。

## 11. 主题显影不得用同一结局多次加权

同一高潮或结局可以回答多个主题问题，但必须分别说明它对每个主题的独立结构贡献。

禁止：

```text
因为结局不可逆，所以命运高显影；
因为结局有前因，所以因果高显影；
因为结局改变身份，所以本体高显影；
然后把三项简单相加，宣布三者都是主主题。
```

同一结局只能作为一个来源簇。主题主次仍须结合中心问题、关键转折、人物重大选择、高潮和结局的整体结构判断。

## 12. 标准证据独立性卡

```text
### 证据独立性卡

- 原始事实：
- 来源簇编号：
- 所属对象：
- 所属层级：
- 所属阶段：
- 直接证明权限：
- 是否与既有证据同源：
- 若同源，重复的是事实还是解释：
- 是否改变情境 / 阶段 / 关系对象 / 代价结构：
- 是否为候选形成后的新材料：
- 是否存在循环论证：
- 是否重复计算同一目标变化：
- 可提高：C / M / E 中的哪一项：
- 不可提高：
```

## 13. 当前冻结结论

```text
证据条目数量不等于独立证据来源数量。
同一来源簇可以多层分析，但不能跨层重复计数或互相补高置信度。
重复支持主要提高显影清晰度，不自动提高结构判断置信度。
人物稳定本体需要跨阶段、跨情境、跨关系或跨代价的独立支持。
结论不得反向证明产生它的前提，预测后的旧材料不得回填成新证据。
三元与十元相容不等于证据翻倍，两层仍分别独立审核。
同一目标变化不得被多个箭头、阶段或关系效果重复计量。
人物核心锚点优先稳定，变化继续优先落在状态、行为、关系位置、场景、时间结构与动态链。
```
