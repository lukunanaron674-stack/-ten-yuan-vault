# xz ↔ nz 水轴待审议问题｜形式关系断裂与现实回返资格分离边界

## 0｜current canonical

本文件只服从 current canonical，不由旧任务或旧映射倒推：

```text
水＝阳水 xz ↔ 阴水 nz
主题领域＝命运
广义变量＝可逆性与对象特异回返空间
xz：持续收窄
nz：保存、恢复或重建
```

本轮只迁移木轴/火轴的验证方法，不迁移理论结论。

## 1｜研究问题

> 同人物、同关系对象层里，形式师徒关系被明确解除、共同执行接口关闭，是否就等于 `nz` 的现实回返资格已经归零？

本研究不把“被逐→回来”直接粗判为 `nz OFF→ON`，而是拆分：

```text
formal_relationship_status
current_joint_execution
direct_reentry_consent
mediated_reentry_path
reentry_eligibility
return_path_credibility
bilaterality
repair_capacity
```

目标是判断：**共同执行接口关闭**、**名义关系撤销**、**直接重入被拒绝**、**双方现实回返资格关闭**是否必须同步发生。

## 2｜控制一：第二十七—三十二回｜形式关系 OFF 但回返路径非零

### 阶段 A｜第二十七回逐出前

- actor：唐僧 / 孙悟空；
- object：唐僧↔孙悟空对象特异师徒关系；
- object_layer：师徒关系中的共同取经、保护、退出与重新进入资格；
- current_joint_execution：ON；
- relationship_evidence：长期共同取经、保护、相互回应均已现实成立。

### 阶段 B｜第二十七回正式逐出

trigger：三打白骨精后，唐僧认定悟空滥杀。

observable facts：

1. 唐僧明确要求孙悟空回去；
2. 唐僧写下贬书，明确“不再要你做徒弟”，并以“再相见则堕阿鼻地狱”加强形式断裂；
3. 孙悟空接受贬书并离开，回花果山；
4. 但离开前孙悟空仍要求拜别，叮嘱沙僧若师父遭妖难可报“老孙是他大徒弟”；
5. 离开途中及回花果山后仍持续想起唐僧。

阶段 B 不是简单的“关系继续正常”：

```text
formal_relationship_status = OFF / repudiated by Tang
current_joint_execution = OFF
physical_co-presence = OFF
```

但同一时刻也不是所有回返结构都归零：

```text
Wukong-side object-specific attachment = retained
team-mediated contact path = retained
future rescue interface = retained by Wukong
bilateral reentry consent = NOT retained / currently failed on Tang side
```

因此阶段 B 最重要的事实不是 `nz=true` 或 `nz=false` 的二值答案，而是：**关系状态与回返路径发生分层。**

### 阶段 C｜第三十—三十一回危机触发重新接触

- trigger：唐僧被黄袍怪变虎，八戒按白龙马建议回花果山请孙悟空；
- action：八戒现实进入花果山请求；孙悟空追问唐僧是否有难，并明确说“身回水帘洞，心逐取经僧”；
- 八戒说明危机后，孙悟空重新进入救援；
- 孙悟空对群猴明确表示自己仍把“保唐僧”视为未完之事，并预期取经完成后再回花果山。

这里出现了**现实可调用的回返路径**：不是单方回忆，而是团队成员能够实际联系、请求，孙悟空能够实际重新进入同一对象特异关系网络。

### 阶段 D｜第三十二回重新共同运行

第三十二回开头明确写唐僧“复得了孙行者”，随后师徒“一心同体，共诣西方”。

```text
formal_relationship_status = restored in practice
current_joint_execution = ON
reentry_realized = YES
repair/common rhythm = restored
```

## 3｜控制一的 current nz 独立判断

### 阶段 A

stable `nz`：强候选/通过。

- 对象特异：通过；
- 真实共同关系：通过；
- 退出/分离在结构上并非任意替换对象：通过；
- 回返性尚未受压力测试，但基础关系证据完整。

### 阶段 B

**不得粗判 stable nz=ON。**

原因：唐僧一侧明确撤销师徒关系并拒绝再相见，current bilaterality 失败。按 `nz v2.0`，“停靠是否仍属于双方，而非单方想象”是核心门。

但也**不得粗判 return-space=0**：

- 孙悟空明确保留针对唐僧的对象特异救援接口；
- 他向沙僧留下可现实调用的名字/救援通道；
- 后续八戒确实沿这一团队通道找到他；
- 孙悟空仍能现实重入，并最终恢复共同取经。

因此阶段 B 更准确写成：

```text
stable_bilateral_nz = failed / suspended
return_path = narrow but non-zero
reentry_eligibility = asymmetric / contested
relationship_shell = formally broken
joint_execution = off
```

### 阶段 C→D

`nz` 重新上升并完成 reality-test：

- 有现实联系人；
- 有现实返回路径；
- 原对象本人仍可回应；
- 孙悟空实际重新进入；
- 之后恢复共同节奏。

## 4｜控制一的 current xz 独立判断

本控制不把“唐僧有难”“孙悟空被逐”倒推为 `xz`。

- 没有前置未来终点持续压缩多个真实未来路径；
- 没有不同替代路线反复汇流到同一命运终点；
- 黄袍怪危机是重新接触 trigger，不是本轮 trajectory-level `xz` 证据。

```text
current_xz = false / not-supported-in-tested-object-layer
```

因此本控制不是 `xz+nz` 共现，也不是 strict `xz↔nz`。

## 5｜控制一 same object layer / current window

对象层固定为：

> **唐僧↔孙悟空这段对象特异师徒关系的现实共同运行、退出、回返与修复资格。**

不混入：花果山统治权、取经任务整体成败、黄袍怪战斗胜负、紧箍咒控制、孙悟空身份标签、忠义/感人等主题词。

current window：

```text
A 共同运行
→ B 贬书逐出：formal OFF + joint execution OFF
→ B' 悟空侧救援/回返接口仍存，但 bilateral consent 失败
→ C 团队危机触发现实再联系
→ D 现实重入 + 共同节奏恢复
```

## 6｜控制一 nearest-neighbor

- 名义关系撤销 / `x并z` 壳变化：称谓与形式身份被撤销，不自动证明现实回返路径归零。
- `nx`：八戒按白龙马建议去请悟空，是沿已有路线推进的候选行为；不能把“八戒去请”本身算成 nz。
- `n`：孙悟空回来后重新承担保护功能，不等于仅因“重新照顾唐僧”就判 nz。
- 单方怀念：如果没有可调用救援接口与后续真实重入，只能是单方 candidate。

## 7｜控制一 removal / reverse / third-factor

### removal

拿掉“一日为师终身为父”、悲伤流泪、黄袍怪战斗刺激、英雄身份和八戒激将，只保留：

```text
对象特异共同关系已成立
→ 一方正式撤销关系、共同运行停止
→ 另一方仍保留现实可调用的对象特异救援/回返接口
→ 团队成员以后实际调用该接口
→ 原对象双方重新接触
→ 共同节奏恢复
```

仍能证明：**formal/joint-execution OFF 不等于 return-path 归零。**

### reverse

若逐出后同时出现：双方都撤销未来接触资格、团队无法现实联系悟空、没有可调用救援/中介通道、后续只能靠强制拘回或名义恢复，才更接近真正 `return-space close`。

### third-factor freeze

紧箍咒、观音授命、黄袍怪危机、八戒激将、团队功能依赖均只解释控制/任务/触发/即时行动，不单独生成对象特异 bilateral returnability。

## 9｜控制二：第五十六—五十八回｜直接重入被拒绝，但既有中介回返路径仍存

### 9.1 研究问题

> **同一人物、同一对象层里，孙悟空已经现实请求重入，而唐僧明确拒绝并以紧箍咒驱离时，是否可以把 `return-space` 判成真正 close？**

这比控制一更强，因为这里不是“未来也许可以回来”的抽象保留，而是：

```text
direct reentry request = actually attempted
direct reentry consent = explicitly denied
```

要测试的是：**direct path 被拒绝，是否等于 complete relevant return-path set = 0。**

### 9.2 剧情事实

#### 阶段 E｜第五十六回再次逐出

- trigger：孙悟空打死拦路强盗后，唐僧再次强烈反对其杀生；
- actor：唐僧 / 孙悟空；
- action：唐僧念紧箍咒并再次驱逐悟空；
- object：唐僧↔孙悟空对象特异师徒关系；
- object_layer：同一师徒关系中的现实重入资格与可调用回返路径；
- changed_variable：共同运行 ON → 直接共同运行被强制切断；
- observable_result：孙悟空离开团队。

#### 阶段 F｜第五十七回 direct reentry reality-test

原著给出比第一次逐出更强的现实测试：孙悟空没有只在远处想念，而是**实际回到唐僧面前请求重新加入**，表示以后愿受教诲，希望继续保护取经；唐僧明确不答应，再念紧箍咒，并要求其离开。citeturn757072search5

因此：

```text
direct_reentry_path = tested
direct_reentry_consent_by_Tang = NO
current_joint_execution = OFF
bilateral_current_consent = failed
```

如果只看 direct path，这一窗口比第二十七回更接近 `nz close`。

但孙悟空随后没有进入“所有回返路径归零”状态。他明确转向南海观音处申诉；观音不是临时凭空出现的陌生第三方，而是这段取经关系既有、制度化、现实可调用的关系中介与资格确认节点。第五十八回真假悟空争议进一步调用观音、天庭、唐僧、地府、如来等辨认/裁定接口，最终由如来辨明真假，公开梗概与章节资料均记录观音送真悟空回到唐僧处，师徒继续西行。citeturn393914search3

### 9.3 current nz 独立判断

阶段 F 必须分两层：

```text
direct bilateral reentry = failed
complete relevant returnability = not zero
```

理由：

1. **对象特异性：通过。** 悟空请求的不是加入任意取经团队，而是重新回到唐僧这一对象特异师徒关系。
2. **直接重入：现实失败。** 唐僧明确拒绝，这是比“单方怀念”更强的负证据。
3. **中介路径：现实存在。** 悟空立即转向观音；这不是事后发明的 deus ex machina 路线，而是自收徒以来一直存在的既有外部关系节点。
4. **资格可审理性：仍存在。** 观音、如来等节点能处理真假、归队与取经资格；说明“是否还能回到关系”仍有现实 adjudication/mediation path。
5. **现实重入：随后兑现。** 真伪被辨后，真悟空重新回到唐僧团队，共同西行恢复。

因此不能写：

```text
Tang direct rejection
→ nz return-space = 0
```

更准确是：

```text
direct_reentry_channel = CLOSED at this window
mediated_reentry_channel = OPEN / callable
stable_bilateral_nz = failed / suspended
complete_return_space = narrow but non-zero
```

### 9.4 current xz 独立判断

本控制仍不支持 `xz`：

- 没有多个真实未来路径逐步汇回同一前置终点；
- 唐僧拒绝是一个关系裁定节点，不是 trajectory-level 命运收束；
- 孙悟空反而存在 direct path 失败后转 mediated path 的现实替代接口。

```text
current_xz = false / not-supported-in-tested-object-layer
```

这尤其重要：**direct path 被拒绝后还有有效替代回返路径，本身就是 against path-exhaustion 的证据。**

### 9.5 same current window / same object layer

对象层不变：

> 唐僧↔孙悟空师徒关系中的现实退出、重新进入与修复资格。

窗口：

```text
E 共同运行
→ 再次逐出
→ F 悟空直接请求重入
→ 唐僧明确拒绝 direct reentry
→ 悟空调用既有观音 mediation path
→ 真伪/资格经外部节点处理
→ G 真悟空现实归队、共同运行恢复
```

### 9.6 nearest-neighbor

- **直接拒绝 / `z` 裁定节点**：明确说“不许回来”是强节点，但单节点不能证明所有 relevant return paths 都关闭。
- **紧箍咒 / `x` 控制**：能强制悟空离开当下共同运行，不等于掌握全部未来关系回返资格。
- **观音/如来 authority**：不能直接倒贴成 `nz`；它们只是现实存在的 mediation/adjudication path。`nz` 计的是这条对象特异关系仍可通过现实路径重入并最终恢复。
- **任务依赖**：唐僧需要悟空战斗力不能单独证明关系 nz；真正证据是明确被拒后仍存在可调用中介路径，并最终让同一对象双方恢复共同运行。

### 9.7 removal test

拿掉真假猴王的奇观、六耳猕猴身份、战斗力需求、悟空委屈情绪、取经“大义”，只保留：

```text
对象特异共同关系已成立
→ 一方再次逐出
→ 被逐者现实请求直接重入
→ 对方明确拒绝
→ 被逐者仍有既有、现实可调用的中介资格路径
→ 中介路径实际被调用
→ 同一关系最终现实重入并恢复共同运行
```

仍能证明：

> **direct reentry denied ≠ complete return-space closed。**

### 9.8 reverse test

若第五十七回同时满足以下条件，才更接近真正 lifecycle close：

1. 唐僧拒绝直接重入；
2. 悟空也撤销回返意愿；
3. 观音/如来/团队成员等既有 mediation path 明确无权、拒绝或无法介入；
4. 不存在其他现实可调用的对象特异 reentry interface；
5. 后续若重逢，也只能建立一个新关系，而不是恢复原关系。

原著不满足 3—5；因此不能锁 `ON→OFF→ON` 真 positive。

### 9.9 third-factor freeze

- 六耳猕猴：制造真假争议与恢复触发，不创造此前已有的观音中介路径；
- 观音/如来权威：解释为什么 mediated path 能裁定，不等于它们自己就是 nz；
- 唐僧安全需求：解释为什么团队后来需要悟空，不足以单独解释对象特异归队资格；
- 紧箍咒：解释 direct rejection 的执行力度，不证明全路径耗尽；
- 沙僧：参与真假辨认/联络，但不是 stable nz 的独立来源。

## 10｜当前锁定边界

现在 lifecycle 的“close”至少必须同时检查：

```text
formal_relationship_status
current_joint_execution
direct_reentry_consent
mediated_reentry_path
return_path_credibility
reentry_eligibility
bilaterality
repair_capacity
```

因此：

> **形式关系 OFF ≠ return-space OFF。**

> **共同执行 OFF ≠ return-space OFF。**

> **direct reentry 被明确拒绝 ≠ complete return-space OFF。**

> **只有 relevant return-path set 接近穷尽，且现实重入资格/修复能力也同时关闭，才更接近真正 nz close。**

这与火轴 x-scope 的 path-set completeness 只迁移“验证方法”，不迁移理论结论：这里不是把 x-scope 理论搬进水轴，而是采用同样的审计纪律，区分“枚举到的一个接口关闭”与“完整相关路径集合耗尽”。

## 12｜下一最高价值缺口

P0 继续在四大名著中找真正的同人物/同对象层：

```text

→ direct path CLOSED
→ mediated / alternate relevant path set 也接近 0

→ 后来由新的现实机制重新 OPEN
```
