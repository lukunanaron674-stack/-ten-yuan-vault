# xz ↔ nz 水轴待审议问题｜形式关系断裂与现实回返资格分离边界

## 0｜current canonical

本文件只服从 current canonical，不由旧任务或旧映射倒推：

```text
水＝阳水 xz ↔ 阴水 nz
主题领域＝命运
广义变量＝可逆性与对象特异回返空间
xz：持续收窄
nz：保存、恢复或重建
```

本轮只迁移木轴/火轴的验证方法，不迁移理论结论。

## 1｜研究问题

> 同人物、同关系对象层里，形式师徒关系被明确解除、共同执行接口关闭，是否就等于 `nz` 的现实回返资格已经归零？

本轮不把“被逐→回来”直接粗判为 `nz OFF→ON`，而是拆分：

```text
formal_relationship_status
current_joint_execution
reentry_eligibility
return_path_credibility
bilaterality
repair_capacity
```

目标是判断：**共同执行接口关闭**、**名义关系撤销**、**双方现实回返资格关闭**是否必须同步发生。

## 2｜事实骨架

### 阶段 A｜第二十七回逐出前

- actor：唐僧 / 孙悟空；
- object：唐僧↔孙悟空对象特异师徒关系；
- object_layer：师徒关系中的共同取经、保护、退出与重新进入资格；
- current_joint_execution：ON；
- relationship_evidence：长期共同取经、保护、相互回应均已现实成立。

### 阶段 B｜第二十七回正式逐出

trigger：三打白骨精后，唐僧认定悟空滥杀。

observable facts：

1. 唐僧明确要求孙悟空回去；
2. 唐僧写下贬书，明确“不再要你做徒弟”，并以“再相见则堕阿鼻地狱”加强形式断裂；
3. 孙悟空接受贬书并离开，回花果山；
4. 但离开前孙悟空仍要求拜别，叮嘱沙僧若师父遭妖难可报“老孙是他大徒弟”；
5. 离开途中及回花果山后仍持续想起唐僧。

阶段 B 不是简单的“关系继续正常”：

```text
formal_relationship_status = OFF / repudiated by Tang
current_joint_execution = OFF
physical_co-presence = OFF
```

但同一时刻也不是所有回返结构都归零：

```text
Wukong-side object-specific attachment = retained
team-mediated contact path = retained
future rescue interface = retained by Wukong
bilateral reentry consent = NOT retained / currently failed on Tang side
```

因此阶段 B 最重要的事实不是 `nz=true` 或 `nz=false` 的二值答案，而是：**关系状态与回返路径发生分层。**

### 阶段 C｜第三十—三十一回危机触发重新接触

- trigger：唐僧被黄袍怪变虎，八戒按白龙马建议回花果山请孙悟空；
- action：八戒现实进入花果山请求；孙悟空追问唐僧是否有难，并明确说“身回水帘洞，心逐取经僧”；
- 八戒说明危机后，孙悟空重新进入救援；
- 孙悟空对群猴明确表示自己仍把“保唐僧”视为未完之事，并预期取经完成后再回花果山。

这里出现了**现实可调用的回返路径**：不是单方回忆，而是团队成员能够实际联系、请求，孙悟空能够实际重新进入同一对象特异关系网络。

### 阶段 D｜第三十二回重新共同运行

第三十二回开头明确写唐僧“复得了孙行者”，随后师徒“一心同体，共诣西方”。

```text
formal_relationship_status = restored in practice
current_joint_execution = ON
reentry_realized = YES
repair/common rhythm = restored
```

## 3｜current nz 独立判断

### 阶段 A

stable `nz`：强候选/通过。

- 对象特异：通过；
- 真实共同关系：通过；
- 退出/分离在结构上并非任意替换对象：通过；
- 回返性尚未受压力测试，但基础关系证据完整。

### 阶段 B

**不得粗判 stable nz=ON。**

原因：唐僧一侧明确撤销师徒关系并拒绝再相见，current bilaterality 失败。按 `nz v2.0`，“停靠是否仍属于双方，而非单方想象”是核心门。

但也**不得粗判 return-space=0**：

- 孙悟空明确保留针对唐僧的对象特异救援接口；
- 他向沙僧留下可现实调用的名字/救援通道；
- 后续八戒确实沿这一团队通道找到他；
- 孙悟空仍能现实重入，并最终恢复共同取经。

因此阶段 B 更准确写成：

```text
stable_bilateral_nz = failed / suspended
return_path = narrow but non-zero
reentry_eligibility = asymmetric / contested
relationship_shell = formally broken
joint_execution = off
```

### 阶段 C→D

`nz` 重新上升并完成 reality-test：

- 有现实联系人；
- 有现实返回路径；
- 原对象本人仍可回应；
- 孙悟空实际重新进入；
- 之后恢复共同节奏。

## 4｜current xz 独立判断

本轮不把“唐僧有难”“孙悟空被逐”倒推为 `xz`。

- 没有前置未来终点持续压缩多个真实未来路径；
- 没有不同替代路线反复汇流到同一命运终点；
- 黄袍怪危机是重新接触 trigger，不是本轮 trajectory-level `xz` 证据。

```text
current_xz = false / not-supported-in-tested-object-layer
```

因此本轮不是 `xz+nz` 共现，也不是 strict `xz↔nz`。

## 5｜same object layer / current window

对象层固定为：

> **唐僧↔孙悟空这段对象特异师徒关系的现实共同运行、退出、回返与修复资格。**

不混入：

- 花果山统治权；
- 取经任务的整体成败；
- 黄袍怪战斗胜负；
- 紧箍咒控制；
- 孙悟空的职业/身份标签；
- “忠义”“感人”等主题词。

current window：

```text
A 共同运行
→ B 贬书逐出：formal OFF + joint execution OFF
→ B' 悟空侧救援/回返接口仍存，但 bilateral consent 失败
→ C 团队危机触发现实再联系
→ D 现实重入 + 共同节奏恢复
```

## 6｜nearest-neighbor

### 6.1 名义关系撤销 / `x并z` 壳变化

“徒弟”称谓与形式身份被撤销，可以造成关系壳变化，但不自动证明现实回返路径归零。

### 6.2 `nx`

八戒按白龙马建议去请悟空，是沿已有路线/他人建议推进的候选行为；不能把“八戒去请”本身算成 nz。`nz` 证据来自对象特异关系的现实重入资格与实际恢复。

### 6.3 `n`

孙悟空回来后重新承担保护功能，不等于仅因“重新照顾唐僧”就判 nz；核心是分离后的对象特异重入与修复。

### 6.4 单方怀念

若只有孙悟空想念唐僧，而没有八戒可现实找到他、没有可调用救援接口、没有后续真实重入，则最多是单方 nz candidate，不足以证明关系端点恢复。

## 7｜removal test

依次拿掉：

- “一日为师终身为父”等关系口号；
- 悲伤流泪；
- 黄袍怪的战斗刺激；
- 孙悟空英雄身份；
- 八戒的激将语言。

只保留：

```text
对象特异共同关系已成立
→ 一方正式撤销关系、共同运行停止
→ 另一方仍保留现实可调用的对象特异救援/回返接口
→ 团队成员以后实际调用该接口
→ 原对象双方重新接触
→ 共同节奏恢复
```

仍能证明：**formal/joint-execution OFF 不等于 return-path 归零。**

## 8｜reverse test

若第二十七回后出现以下任一结构：

1. 唐僧明确拒绝任何未来重新接触，且团队无法再联系悟空；
2. 悟空明确撤销对唐僧的对象特异救援接口；
3. 八戒无法现实找到或调用悟空；
4. 后续只能靠强制拘回、职位命令或资源扣留恢复表面师徒身份；
5. 重逢后只能恢复名义称谓，不能恢复可信共同运行；

则 `return_path_credibility` 与 `nz` 应明显下降，甚至真正 close。

原著事实不满足这些反向条件。

## 9｜third-factor freeze

- 紧箍咒：可造成控制/惩罚背景，但不能解释悟空主动保留救援接口；
- 观音授命：解释取经任务来源，不足以单独解释对象特异回返与修复；
- 黄袍怪危机：提供再次接触 trigger，不生成之前已存在的 return path；
- 八戒激将：解释孙悟空即时行动的一部分表面理由，但在激将前悟空已主动追问师父是否有难，并明示“身回水帘洞，心逐取经僧”；
- 团队功能依赖：能解释为什么需要悟空，却不能单独解释悟空为何仍认可自己与唐僧关系的未来共同运行。

## 11｜本轮锁定边界

> **形式关系被撤销 ≠ 现实回返路径必然归零。**

> **共同执行接口 OFF ≠ nz return-space OFF。**

> **但单方仍想回来 ≠ stable bilateral nz 仍为 ON。**

因此水轴 lifecycle 不应只有一个二值 `nz on/off`，至少需要同时记录：

```text
formal_relationship_status
current_joint_execution
return_path_credibility
reentry_eligibility
bilaterality
repair_capacity
```

只有当双方现实重入资格、可调用 return path 与修复能力同时关闭，才更接近真正 `nz close`；仅名义撤销、物理分离或共同执行停止不足以证明。

## 12｜统计与下一缺口

本控制不增加 pure nz positive / negative，不增加 `xz+nz` co-occurrence，不增加 strict，也不伪造 `ON→OFF→ON` lifecycle positive。

新增：

```text
lifecycle false-transition guard: 1 control / 1 independent work
actual lifecycle ON→OFF→ON verified: 0 / 0
```

下一最高价值缺口：继续在四大名著中找**真正的同人物/同对象层 return-space close→reopen**。要求 B 阶段不仅形式关系或共同执行关闭，而且双方现实回返路径、reentry eligibility 与 repair capacity 都可证实接近 0；随后同一关系对象层再出现真实重新开放。若四大名著内找不到这种强关闭，再转 P1 `xz+nz co-occurrence non-strict guard`。
