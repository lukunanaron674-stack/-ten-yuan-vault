# 待审议｜zn-x 压力显影中原则未来调用资格与现实表达窗口分离边界

## 1｜候选命题

当前 3 部独立文学作品支持：

> **一个已经独立成立的 `zn`，可以在外部压力下失去最直接、最强的现实表达窗口，而不等于其未来指导资格已经被删除。若压力解除后，同一可命名原则按原边界、原冲突排序硬门重新进入现实行动，则优先判 pressure-display，而不是人物本体换芯或 `zn` lifecycle 退出。**

反过来：

> **如果原则只在压力之后才形成、收紧或改写，则不得把后来原则倒填为压力前已经存在、只是被遮蔽的同一 `zn`。**

## 5｜候选判据

### 5.1 压力前同一性门

必须能在压力前独立写出可命名原则 P，并证明它已经通过 current `zn`：

- 非身份/称号/主题倒推；
- 无奖励/认可仍进入判断；
- 在真实冲突中排序；
- 具备未来调用资格。

### 5.2 压力窗口门

必须指出压力具体封住什么：

```text
直接行动
公开表达
现实许可
路径/信息
政治/关系位置
```

不能只写“他很痛苦”“环境很压抑”。

### 5.3 保留门

压力中不要求行为完全静止，但必须有证据证明 P 的未来指导资格没有被新原则替换。

### 5.4 解压复位门

压力解除后，必须是：

```text
same principle
same boundary
same conflict-order criterion
```

重新进入现实选择。

若只是出现相似口号、相似身份或新的利益条件，不足。

## 6｜与 lifecycle 分界

```text
pressure-display：
P before pressure = true
P during pressure future-guidance = retained
P after release = same P resumes

lifecycle exit/replacement：
P before = true
later same-class conflict = P no longer ranks
new stable ordering takes over / P does not return
```

因此：

> **表达暂时受阻，与原则真实退出必须分开审计。**

## 7｜与 x 的关系

本命题不是 `zn+x` 或 strict complement 命题。

压力窗口可能同时涉及现实 `x`、`nx`、`xn`、`z` 等邻近结构，但：

- 不能因为某项 `x` 仍在就宣布 `zn` 永久存在；
- 不能因为某项 `x` 暂失就宣布 `zn` 已删除；
- pressure-display 只审计同一 `zn` 的成立时点、受压窗口与复位时点。
