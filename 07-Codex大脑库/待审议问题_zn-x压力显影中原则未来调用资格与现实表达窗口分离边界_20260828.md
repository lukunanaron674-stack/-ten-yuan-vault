# 待审议｜zn-x 压力显影中原则未来调用资格与现实表达窗口分离边界

## 1｜候选命题

3 部独立文学作品支持：

> **一个已经独立成立的 `zn`，可以在外部压力下失去最直接、最强的现实表达窗口，而不等于其未来指导资格已经被删除。若压力解除后，同一可命名原则按原边界、原冲突排序硬门重新进入现实行动，则优先判 pressure-display，而不是人物换芯或 `zn` lifecycle 退出。**

反向必须同时防两种假阳性：

1. **temporal backfill**：原则其实在压力后才形成/收紧，却被倒填成压力前已存在；
2. **false restoration**：压力后只出现相似口号/主题词，但真实同类冲突排序已经由新原则或新权力结构接管。

本文件只到 L4 `pending-review`。

## 2｜正向控制｜3 works

### 《三国演义》关羽｜99/97
土山阶段旧盟/旧义已预先规定“知刘备去向即离曹”；刘备去向未知时，立即归刘的最强行动窗口受阻；去向明确后辞曹、挂印封金并归刘。

机制：**信息 / 路径条件封住行动窗口。**

### 《西游记》唐僧｜99/97
女儿国婚配压力前，西行修持/不可因婚配改变法门归向已成立；关文、放行与安全条件迫使表面应承；出城后恢复西行，第55回同类诱婚再复验。

机制：**许可 / 安全条件迫使策略性表面妥协。**

### 《水浒传》宋江｜99/97
第36回“不愿永久草寇化、保留合法回返资格”已成立；江州劫法场后直接合法回返窗口关闭；第71回梁山高位仍主张招安；第82回受招安后同一方向进入直接政治行动。

机制：**现实政治 / 身份位置封住直接回返窗口。**

共同结构：

```text
P before pressure = independently true
→ pressure blocks key expression / realization window
→ future-guidance retained
→ pressure releases
→ same P resumes by same boundary and conflict-order criterion
```

普通正向已经达到 3 部作品，停止继续堆第四个普通正例。

## 3｜反向护栏｜2 works

### Guard A｜徐庶｜99/98｜temporal backfill
伪书召母使徐庶入曹；“终身不为曹设谋”的明确原则边界是在受骗、徐母死亡等后续事件后才清晰形成/收紧。

因此：

> **压力后的稳定原则 ≠ 压力前已经存在的同一原则。**

压力前若无法独立命名 P 并通过 current `zn`，不能以后来的 P2 倒写“P1 只是被压住”。

### Guard B｜迈克尔·柯里昂｜99/97｜false restoration
压力前旧 P：属于家庭，但不把家族犯罪权力与暴力秩序作为自己的现实行动归属。

父亲遇刺后 Michael 进入并最终接管家族犯罪业务。回美后“未来让家族合法化”的语言与旧 P 共享合法/非犯罪主题词，但现实排序已经改变：他持续取得并主动使用组织、人事、交易与暴力处分 `x`，旧“保持现实距离”边界没有恢复。

因此：

> **相似口号 / 相似主题词 ≠ 同一 `zn` 复位。**

pressure-display 解压门必须比较：

```text
same principle
+
same boundary
+
same conflict-order criterion
```

若只是语言相似、身份相似或未来目标相似，但同类现实冲突中的最终排序已被新结构接管，应优先判 lifecycle replacement / false restoration。

## 4｜历史正向对照｜Mandela｜99/97

1964 年民主、平等、反种族支配原则已明确；长期监禁压缩公开政治行动窗口；拒绝有条件释放说明原则未被个人自由交换；1990 获释后同一方向重新进入公开政治行动。

只作历史对照，不计文学作品门槛。

## 5｜候选判据

### 压力前同一性门
压力前必须独立写出可命名原则 P，并证明已通过 current `zn`：无奖励/认可仍进入判断、真实冲突排序、未来调用资格明确。

### 压力窗口门
必须指出压力具体封住什么：直接行动、公开表达、现实许可、路径/信息、政治/关系位置。不能只写“很痛苦”“环境压抑”。

### 保留门
压力中不要求行为完全静止，但必须有证据说明 P 的未来指导资格没有被新原则替换。

### 解压复位门
解压后必须是 same principle + same boundary + same conflict-order criterion 重新进入现实选择。

### 反向换芯门
如果压力后只是主题词相似，而真实排序结构改变，优先 lifecycle replacement，不得判 pressure-display。

## 6｜与 lifecycle 分界

```text
pressure-display:
P before = true
P future-guidance during pressure = retained
P after release = same P resumes

lifecycle exit/replacement:
P before = true
later same-class conflict = P no longer ranks
new stable ordering takes over / P does not return
```

表达受阻与原则真实退出必须分开审计。

## 7｜与 x 的关系

本命题不是 `zn+x` 或 strict 命题。

- `x` 仍在，不证明 `zn` 永久存在；
- `x` 暂失，不证明 `zn` 删除；
- pressure-display 只审计同一 `zn` 的成立时点、受压窗口与复位时点。

## 8｜固定拿掉 / 反向 / 第三因素协议

每个候选必须回答：

1. 拿掉压力，原原则是否可以直接表达？
2. 拿掉原则，仅靠利益/命令/策略能否解释后续“复位”？
3. 解压后若原则不复位，是否应改判 lifecycle？
4. 后来原则是否由新事件形成，构成 temporal backfill？
5. 后来只是出现相似语言，真实排序是否已经换芯？
6. 身份、称号、认可、情绪、胜负与后世评价冻结后，结论是否仍成立？
