# xz ↔ nz 水轴待审议问题｜关羽麦城：观察到的选择路径走到 0，不等于 complete relevant path set 已经耗尽

## 0｜current canonical 与权限

本文件只服从 latest current canonical：

```text
水＝阳水 xz ↔ 阴水 nz
主题领域＝命运
广义变量＝可逆性与对象特异回返空间
xz：持续收窄
nz：保存、恢复或重建
```

current `xz信息量卡 v2.2` 的主门仍是：终点前置、方向被未来规定、路径/选择持续收窄、路径汇流、临界逼近。

本文件是 L4 研究层，只修正此前对“complete relevant path set exhaustion”可以从麦城样本中推出的强度；不修改 L1/L2、xz/nz 信息卡、准度卡、正式关系卡，也不取消既有麦城样本作为 current xz 候选/正控所提供的其他证据。

木轴与火轴仅迁移验证方法：complete relevant path set、enumerated interfaces、same actor、same object layer、same current window、subject-specific attribution、removal、reverse、third-factor freeze；不迁移理论结论。

## 1｜研究问题

上一轮水轴最高价值缺口被压缩到：

> 能否在四大名著里找到同一 changed variable 上真实的 `n>1 → 1 → 0` relevant path-set exhaustion，并证明 alternate paths 仍汇向同一前置终点？

《三国演义》第七十七回关羽麦城此前已经作为 high-purity current xz 控制使用，因此本轮优先复验同一人物、同一窗口，而不是另找静态人物。

本轮只问：

> **麦城文本是否已经足够证明 complete relevant escape-path set 从多条现实路径耗尽到 0？**

结论：**不足。**

## 2｜剧情事实

### trigger

关羽退守麦城后，兵只剩三百余人，粮草已尽，士卒继续离散，上庸救兵又不到；吴军同时设计各门攻打、只空北门，并在北面与临沮方向布置连续伏兵。

### actor

关羽。

### object

关羽在麦城阶段“能否脱离吴军封锁并向西川撤回”的现实逃脱路径集合。

### object_layer

战役 current window 中的现实 escape/recovery path set。

### changed_variable

```text
complete relevant escape-path set 的可调用路径数量与拓扑
```

### observable_result

原文明确出现一个此前需要单独冻结的事实：

```text
关羽看到北门敌军不多，准备走北面山僻小路；
王甫明确提出：小路有埋伏，可走大路；
关羽回答“虽有埋伏，吾何惧哉”，仍主动选择小路。
```

也就是说，在“出城路线选择”这个具体节点，文本至少**枚举了大路与小路两条替代接口**，但只实测了小路。

随后：

```text
小路 / 北门路径
→ 朱然伏兵
→ 转临沮小路
→ 潘璋伏兵
→ 随行只剩十余人
→ 决石伏兵
→ 被擒
```

这一条实际选择路径确实走到现实终止，但“大路”没有在同一文本窗口被实证为也会被同一伏兵结构关闭或汇回同一捕获终点。

## 3｜same current window / same object / same changed variable

```text
same actor = 关羽
same current window = 麦城粮尽兵少、援绝 → 出城路线选择 → 连续伏兵 → 决石被擒
same object = 脱离吴军封锁并向西川撤回的现实逃脱路径
same object layer = 战役层 escape/recovery path set
same changed variable = complete relevant path set 的数量/拓扑
```

所以本轮不是跨层问题，也不是自然语言同义问题；它专门审计 path-set completeness。

## 4｜xz 独立判断

### 4.1 仍然支持 xz 的部分

麦城窗口仍然存在强 xz 证据：

1. 吴军在关羽出城前已布置“只空北门 → 北路追杀 → 临沮再伏”的捕获结构，终点具有前置性；
2. 粮尽、兵少、援军不到、士卒离散使留守/等待空间持续下降；
3. 实际选择的小路撤离路径在连续伏兵中持续变窄；
4. 兵力从二百余人不断减少到十余人，最终在决石被擒，临界逼近真实存在。

因此，本轮**不把既有麦城 current xz 判断直接推翻**。

### 4.2 需要修正的过强表述

但以下更强命题不能由现有文本锁定：

```text
complete relevant escape-path set
n>1 → 1 → 0
```

原因是王甫明确枚举了“大路”作为替代方案，而文本没有给出：

- 大路已被现实封死；
- 大路也被另一层伏兵覆盖；
- 大路会稳定汇回同一临沮/决石捕获链；
- 关羽尝试大路后失败；
- 或第三方事实足以证明大路只是名义路径而非现实路径。

因此：

```text
observed chosen path exhausted = TRUE
complete relevant path set exhausted = NOT PROVEN
```

## 5｜subject-specific attribution

这一点尤其重要。

关羽没有走大路，并不是文本明确说明“大路已经不可走”，而是：

```text
王甫：小路有埋伏，可走大路
关羽：虽有埋伏，吾何惧哉
```

所以“大路未被采用”至少部分来自**主体决策/勇武偏好**，不能全部归因于外部命运结构把路径客观关闭。

这意味着：

> **chosen-path narrowing 与 environment-level complete-path narrowing 必须分账。**

如果不做 subject-specific attribution，就会把“人物没选另一条路”误写成“另一条路不存在”。

## 6｜nearest-neighbor

### `zx`

关羽主动决定走小路，属于强行动方向推出因素。它能解释为什么实际轨迹进入伏兵链，不能反向证明大路被客观关闭。

### `z`

路线选择节点本身是裁定点；一次选择使一条路径成为实际路径，不等于其他 relevant interfaces 已经失效。

### `xn`

吴军连续伏兵部署可解释既有围捕流程，但要把“大路”纳入完整 path-set exhaustion，仍须证实该流程也覆盖大路或其等价替代。

### `x`

决石擒拿、长钩套索等能锁当前局部控制结果，但不能补写此前未被验证的大路状态。

## 7｜removal test

拿掉：

- 关羽忠义；
- 卦象“今夜必擒”；
- 最终死亡；
- 英雄气质；
- 战斗描写；

只保留：

```text
A、B 两条出城路线被文本明确枚举
→ actor 主动选 A
→ A 连续受阻并最终失败
→ B 未被实测、未被明确关闭
```

仍然只能锁：

> **A 路径耗尽，不等于 complete {A,B,...} path set 耗尽。**

## 8｜reverse test

若要把该样本升级成真正的 complete-path-exhaustion positive，需要补到至少一种证据：

```text
大路也被明确封锁
或
改走大路仍进入同一捕获区间
或
大路只在名义上存在，现实条件已使其不可调用
或
所有 relevant routes 被逐一枚举并实证关闭
```

此时才可把：

```text
observed trajectory → 0
```

升级为：

```text
complete relevant path set → 0
```

## 9｜third-factor freeze

- 关羽骄傲/勇武：解释为什么选择小路，不生成 complete exhaustion；
- 吕蒙军事能力：解释围捕设计，不自动证明所有 relevant routes 均被覆盖；
- 王甫判断是否最终正确：不是关键；关键是“大路”被文本作为现实替代接口明确提出；
- 卦象：不能作为现实 path-set completeness 证据；
- 关羽最终被擒：只证明 actual path 失败，不能事后倒推所有未走路径也必然失败。

## 11｜本轮锁定的新边界

> **actual chosen path 走到 0 ≠ complete relevant path set 走到 0。**

> **一个未被主体采用的替代路线，不能仅因最终结局已经发生，就被事后回填成“当时现实上已关闭”。**

> **做 xz path-exhaustion 审计时必须区分：enumerated interfaces、actually chosen path、externally closed paths、nominal-only paths、untested paths。**

> **因此，真正的 `n>1 → 1 → 0` positive 仍是未解决缺口；麦城样本不能承担这份更强证明。**

## 12｜与既有麦城 pure-xz 控制的关系

本轮不删除、不降格既有麦城文件，也不修改 L2。

保留：

```text
终点前置
＋ 留守/等援空间下降
＋ chosen-path 连续受压
＋ 临界逼近
```

修正：

```text
“出城后大路/小路均已被证明受同一伏兵结构限制”
→ 证据不足

“complete relevant escape-path set 已趋近 0”
→ 不得由最终被擒事后倒推
```

因此，后续水轴研究应把“麦城是 xz 正控”和“麦城证明完整 path exhaustion”分成两个命题，不再捆绑。
