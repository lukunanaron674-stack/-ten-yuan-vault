# 待审议｜nx 激活与当前通道持续有效性边界

## 0｜为什么建立

现行 nx 正本强调：方向、权限或解决通道在外部，主体真实沿其推进。此前材料已充分区分“外部接口存在”与“主体实际激活接口”。本轮进一步发现：

> **接口一旦真实激活，也不能永久覆盖后续阶段。**

当前至少三部独立作品、三种不同机制都表明：判 nx 必须继续追踪“当前这一刻，旧通道是否仍有效、可用，而且主体是否仍沿其续接”。

## 1｜三部独立控制

### A｜《西游记》孙悟空·四海龙王施雨

```text
主动求援
→ 接受方案
→ 真实执行
= nx激活

但：
雨法对三昧真火无效
→ 主体停止沿旧方案推进
→ 转接观音
= 旧nx窗口结束
```

失效机制：**方案本身对当前瓶颈无效。**

### B｜《水浒传》林冲·柴进庄

```text
柴进真实收留
→ 庇护一度有效
= nx激活

但：
官府搜捕升级
→ 柴进庄继续庇护的现实风险改变
→ 林冲停止续接
→ 转接梁山准入网络
= 旧nx窗口结束
```

失效机制：**环境约束改变，使原有效通道不可持续。**

### C｜《三国演义》刘备·入川援刘璋

```text
刘璋邀请入川、提供外援/防务接口
→ 刘备真实承接
= nx激活

但：
刘璋后来限制供给、严守关隘、禁止荆州军继续进入
→ 原权限节点从开放者转为阻止者
→ 刘备不再沿旧授权通道推进
= 旧nx窗口结束
```

失效机制：**外部许可节点本人撤回/反转。**

## 2｜候选纪律

当前仅形成待审议，不升级核心定义：

> **nx 应按当前执行窗口判定，而不是按历史关系永久继承。**

最小检查：

```text
1. 旧通道是否曾真实激活？
2. 当前通道是否仍有效？
3. 当前通道是否仍可被主体使用？
4. 主体是否仍真实沿其续接？
5. 若已停止，主体现在转向的是新nx、x、xn还是zx？
```

## 3｜三种目前已锁失效机制

### 3.1 方案失效

外部通道真实执行，但无法解除目标瓶颈。

### 3.2 环境可持续性失效

方案/庇护本身有效，但外部压力变化使其不再能持续承担原功能。

### 3.3 许可节点撤回/反转

通道原先开放，但掌握权限的外部节点后来明确撤回、拒绝、封锁或转成阻止者。

这三者都可以结束旧 nx 当前执行窗口。

## 4｜防误判

### 4.1 曾经 nx ≠ 永久 nx

“以前求过他”“以前接受过这个安排”“最初是通过他进入的”，只能证明历史上曾有 nx。

### 4.2 关系仍在 ≠ 当前通道仍在

人物仍认识、仍有亲缘/旧交，不等于当前正在沿同一接口推进。

### 4.3 通道退出 ≠ zx 自动出现

退出旧 nx 后必须重新检查：

- 只是回到已有局部权限：`x`
- 自己重搭流程：`xn`
- 转接另一个外部通道：新 `nx`
- 自身权能公开扩大决定范围：才查 `zx`

### 4.4 方案失败与主体没激活要分开

- 从未请求/承接/续接：不能说 nx 已激活。
- 已请求、接受并实际执行，但后来失败：属于“nx 真激活后退出”。

## 5｜拿掉测试

### 拿掉“当前持续有效性”检查

会出现永久污染：

```text
人物曾经通过A获得帮助
→ 后面无论A是否失效、撤回、被换掉
→ 仍永久判A为当前nx
```

这与三部高纯材料冲突。

### 补回持续有效性检查

则可以明确区分：

```text
历史nx
vs
当前nx
```

## 6｜第三因素冻结

冻结人物强弱、成败、性格、作品主题，只保留：

- 外部通道最初是否真实开放；
- 主体是否真实承接；
- 通道后来是否仍有效/可用；
- 主体是否仍沿其推进。

三例边界仍稳定。

## 7｜当前状态

- 跨作品数量：3
- 三种机制均 ≥95%
- 允许形成待审议问题
- 不允许直接修改 L1 / 信息卡 / 准度卡 / 补卡

下一步最值得找的是**第四种失效机制**，尤其：外部节点仍愿意、方案也有效，但主体自身目标改变，主动放弃原通道。需要区分“nx退出”与“人物最高方向已改变”的因果先后。
