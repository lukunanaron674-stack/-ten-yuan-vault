# 待审议｜nx 激活与当前通道持续有效性边界

## 0｜为什么建立

现行 nx 正本强调：方向、权限或解决通道在外部，主体真实沿其推进。此前材料已充分区分“外部接口存在”与“主体实际激活接口”。本轮进一步发现：

> **接口一旦真实激活，也不能永久覆盖后续阶段。**

当前至少三部独立作品、四种不同机制都表明：判 nx 必须继续追踪“当前这一刻，旧通道是否仍有效、可用，而且主体是否仍沿其续接”。

## 1｜跨作品与机制控制

### A｜《西游记》孙悟空·四海龙王施雨

```text
主动求援
→ 接受方案
→ 真实执行
= nx激活

但：
雨法对三昧真火无效
→ 主体停止沿旧方案推进
→ 转接观音
= 旧nx窗口结束
```

失效机制：**方案本身对当前瓶颈无效。**

### B｜《水浒传》林冲·柴进庄

```text
柴进真实收留
→ 庇护一度有效
= nx激活

但：
官府搜捕升级
→ 柴进庄继续庇护的现实风险改变
→ 林冲停止续接
→ 转接梁山准入网络
= 旧nx窗口结束
```

失效机制：**环境约束改变，使原有效通道不可持续。**

### C｜《三国演义》刘备·入川援刘璋

```text
刘璋邀请入川、提供外援/防务接口
→ 刘备真实承接
= nx激活

但：
刘璋后来限制供给、严守关隘、禁止荆州军继续进入
→ 原权限节点从开放者转为阻止者
→ 刘备不再沿旧授权通道推进
= 旧nx窗口结束
```

失效机制：**外部许可节点本人撤回/反转。**

### D｜《西游记》猪八戒·四圣试禅心

```text
观音劝化 / 唐僧收徒 / 既有取经队伍
→ 猪八戒此前真实承接西行方向
= nx激活

此后：
取经通道仍有效
唐僧仍维持西行
队伍没有撤回猪八戒身份
现实路线也仍可继续

但：
富贵婚姻诱惑出现
→ 猪八戒当前最高目标转向留下招赘
→ 主动私下推进婚配
→ 不再续接当前西行终点
= 旧nx窗口结束
```

失效机制：**主体自身当前最高目标改变，主动放弃仍然有效、开放且可用的旧通道。**

这一例与前三种不同：不是方案失效，不是环境恶化，也不是外部节点撤回。旧通道本身仍然存在，退出原因发生在主体端。

### E｜《水浒传》李俊·班师赴京途中诈病脱队

```text
招安后朝廷任务 / 宋江军令体系
→ 李俊此前真实承接并持续执行
→ 班师时实际随军赴京
= nx激活

此后：
回京朝觐 / 受官通道仍有效
宋江和其余将佐继续赴京
朝廷没有撤回李俊资格
方案也没有失败

但：
李俊当前最高目标转向“不愿朝京为官 / 另行出海”
→ 诈病脱离班师队伍
→ 与童威、童猛转寻费保等人
→ 不再续接赴京终点
= 旧nx窗口结束
```

失效机制：**主体自身当前最高目标改变，主动放弃仍有效、开放且可用的旧通道。**

这一例把第四机制从《西游记》单例扩展到《水浒传》第二部独立作品。

## 2｜候选纪律

当前仅形成待审议，不升级核心定义：

> **nx 应按当前执行窗口判定，而不是按历史关系永久继承。**

最小检查：

```text
1. 旧通道是否曾真实激活？
2. 当前通道是否仍有效？
3. 当前通道是否仍可被主体使用？
4. 主体当前最高目标是否仍与旧通道一致？
5. 主体是否仍真实沿其续接？
6. 若已停止，主体现在转向的是x、xn、新nx还是zx？
```

## 3｜四种目前已锁退出机制

### 3.1 方案失效

外部通道真实执行，但无法解除目标瓶颈。

### 3.2 环境可持续性失效

方案/庇护本身有效，但外部压力变化使其不再能持续承担原功能。

### 3.3 许可节点撤回/反转

通道原先开放，但掌握权限的外部节点后来明确撤回、拒绝、封锁或转成阻止者。

### 3.4 主体最高目标改变

通道本身仍有效、开放、可用，外部节点也未撤回；但主体当前最高目标已经改变，因此主动停止续接旧方向。

目前已由《西游记》猪八戒与《水浒传》李俊两部独立作品复现。

四者都可以结束旧 nx 当前执行窗口，但因果来源不同：前三种主要发生在通道/环境侧，第四种发生在主体当前方向侧。

## 4｜防误判

### 4.1 曾经 nx ≠ 永久 nx

“以前求过他”“以前接受过这个安排”“最初是通过他进入的”，只能证明历史上曾有 nx。

### 4.2 关系仍在 ≠ 当前通道仍在

人物仍认识、仍有亲缘/旧交，不等于当前正在沿同一接口推进。

### 4.3 通道仍有效 ≠ 主体仍在 nx

即使旧通道仍开放、有效、可用，如果主体当前最高目标已经改变并主动停止续接，旧 nx 也可以退出。

### 4.4 通道退出 ≠ zx 自动出现

退出旧 nx 后必须重新检查：

- 只是回到已有局部权限：`x`
- 自己重搭流程：`xn`
- 转接另一个外部通道：新 `nx`
- 自身权能公开扩大决定范围：才查 `zx`

猪八戒四圣试禅心与李俊班师诈病脱队都直接控制：当前 nx 退出，但退出本身不足以证明新增 zx。

### 4.5 方案失败与主体没激活要分开

- 从未请求/承接/续接：不能说 nx 已激活。
- 已请求、接受并实际执行，但后来失败：属于“nx 真激活后退出”。

## 5｜拿掉测试

### 拿掉“当前持续有效性”检查

会出现永久污染：

```text
人物曾经通过A获得帮助
→ 后面无论A是否失效、撤回、被换掉
→ 仍永久判A为当前nx
```

这与前三部高纯材料冲突。

### 拿掉“主体当前目标是否仍一致”检查

又会出现另一类永久污染：

```text
旧通道仍有效
→ 就假定主体仍在nx

即使：
主体已经明确改变当前最高目标
并且主动停止续接旧方向
```

这与猪八戒四圣试禅心 99/98 及李俊班师诈病脱队 99/97 两份正式记录冲突。

### 补回两类检查

则可以明确区分：

```text
历史nx
vs
当前nx

以及：
通道侧退出
vs
主体侧退出
```

## 6｜反向测试

### 真正持续 nx

```text
旧通道仍有效、可用、开放
+
主体当前最高目标仍与旧方向一致
+
主体仍真实沿其续接
= nx持续
```

### 主体目标改变型退出

```text
旧通道仍有效、可用、开放
+
主体当前最高目标改变
+
主体主动停止沿旧方向推进
= 旧nx窗口结束
```

但该退出本身不能推出 zx，必须另验决定范围是否扩大。

## 7｜第三因素冻结

冻结人物强弱、成败、性格、作品主题，只保留：

- 外部通道最初是否真实开放；
- 主体是否真实承接；
- 通道后来是否仍有效/可用；
- 外部节点是否仍愿意/允许；
- 主体当前最高目标是否改变；
- 主体是否仍沿旧通道推进。

四种机制边界仍稳定。
