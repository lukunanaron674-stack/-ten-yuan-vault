# 《水浒传》林冲投梁山 → 火并王伦｜zx↔nx 严格补关系对象层错位控制

## 0｜结论先行

本轮不重判两个已有正式案例，只复审二者能否因为同一人物、同一梁山组织、前后相邻而被拼成严格 `zx ↔ nx` 补关系。

结论：**不能。**

两端都独立成立：

- 第十一回，林冲为获得安身与梁山成员资格，必须通过柴进荐书、朱贵引入，并接受王伦掌握的准入决定与投名状条件，`nx` 关系功能已正式锁定。
- 第十九回，王伦再次拒绝晁盖等人后，林冲不再承认王伦作为最终准入/首领接口，公开杀王伦并参与重排梁山首领结构，`zx` 当前状态已正式锁定。

但二者处理的不是同一个缺口：

```text
第十一回 nx 的对象：
“林冲本人能不能进入梁山、获得成员与安身资格”

第十九回 zx 的对象：
“梁山谁拥有最高首领位置，以及谁能决定晁盖等新来者是否被接纳”
```

因此，前一段 nx 只是让林冲历史上进入梁山，成为后一事件能够发生的一个**时间/因果前提**；它没有直接补第十九回 zx 在“组织最高治理接口”上的缺口。

反过来，第十九回 zx 清除王伦、重排首领，也没有回到第十一回去补“林冲本人如何取得第一次入寨许可”的旧缺口。

所以本例正式锁为：

> **两端都真 + 前后有因果连续 ≠ 严格补关系。严格补关系还要求两端针对同一对象层或可直接因果对接的同一现实缺口发生双向补位。**

---

## 1｜剧情事实与阶段切分

### 阶段 A｜第十一回：林冲投梁山

已有正式案例锁定：

- 林冲自己的方向是寻找长期安身处；
- 柴进提供盘缠、关系介绍与荐书；
- 朱贵负责把林冲引入梁山内部；
- 王伦掌握梁山最终准入；
- 王伦先拒绝，后设置三日投名状；
- 林冲没有夺取准入权，而是继续接受外部条件推进。

因此：

```text
自己的安身目标存在
→ 梁山成员准入权外置
→ 沿荐书 / 引入 / 王伦条件推进
= nx 关系功能
```

### 阶段 B｜第十九回：火并王伦

已有正式案例锁定：

- 晁盖等人来投梁山；
- 王伦再次以粮少房稀等理由拒绝；
- 林冲公开否定王伦首领资格；
- 林冲杀王伦；
- 原梁山头领结构无法继续；
- 林冲拒绝自己坐第一位，并参与把晁盖推上新首领位置。

因此：

```text
原最高首领 / 准入接口在王伦
→ 林冲公开否定并清除该接口
→ 梁山首领与准入结构被迫重排
→ 林冲取得此前没有的关键结构性决定位置
= zx 当前状态
```

---

## 2｜两端独立成立：第一门通过

### nx 端

第十一回的 `nx` 不依赖第十九回 zx 才成立。

即使完全删掉后续火并王伦，只保留：

```text
林冲想安身
→ 梁山准入权在王伦
→ 通过柴进 / 朱贵进入
→ 接受王伦附加条件
```

`nx` 仍然成立。

### zx 端

第十九回的 `zx` 也不是从第十一回 nx 反推出来的。

即使不强调林冲当年怎样入寨，只保留：

```text
王伦当前掌握最高首领 / 准入接口
→ 林冲公开否定并清除王伦
→ 组织首领结构重新排列
```

`zx` 当前状态仍然成立。

所以本例不是“贾芸型第一门失败”。两个端点都是真的。

---

## 3｜第三道下限：缺口对象层必须对接

### 3.1 nx 端实际处理的缺口

第十一回问题是：

> **林冲本人如何获得梁山的第一次成员准入与安身资格。**

缺口拥有者是“申请加入的林冲”。

外部接口是“柴进荐书 / 朱贵引入 / 王伦准入权”。

### 3.2 zx 端实际处理的缺口

第十九回问题已经变成：

> **梁山谁有资格做最高首领，以及晁盖等新来者是否继续受王伦狭窄准入结构支配。**

缺口对象已从“林冲自己的成员资格”切换到：

- 梁山组织最高治理结构；
- 王伦的首领资格；
- 晁盖集团的当前准入；
- 新首领排序与组织重排。

所以：

```text
A 的 nx 缺口 = 我怎么进去
B 的 zx 缺口 = 进去以后，谁有权决定整个组织怎么接纳别人、谁做最高首领
```

二者处于同一个梁山背景，却不是同一个被改变变量。

---

## 4｜为什么“历史前提”不能冒充“补关系”

确实存在一个普通因果：

```text
如果林冲从未通过 nx 进入梁山
→ 他大概率不会处在第十九回现场
→ 后续 zx 桥段可能不会以同样方式发生
```

但这只能证明：

> **早期 nx 是后期 zx 事件的历史/位置前提之一。**

不能证明：

> **早期 nx 正在补后期 zx 的同对象现实缺口。**

严格补机制要求的是：

```text
zx 当前有一个自身权能无法越过的明确缺口
→ nx 直接改变这个缺口变量

nx 当前获得了入口 / 条件
→ zx 再把这一条件兑换成同一现实目标的完成
```

林冲两阶段不存在这样的直接闭环。

把“先加入组织，几年后在组织内发动权力变化”写成严格补，就等于把所有人生履历都可以强行串成互补。理论会迅速变成传记连线游戏。

---

## 5｜双向拿掉测试

### 5.1 拿掉第十一回 nx

如果抽象地删掉“林冲本人当年通过王伦准入进入梁山”这一具体 nx 桥段，但假设林冲仍以其他方式已经身处梁山，第十九回面对王伦拒绝晁盖时：

- 林冲仍可形成公开反对；
- 仍可清除王伦；
- 仍可推动首领结构重排；
- `zx` 本身不会留下一个“缺少早期荐书/投名状接口，所以无法处理当前首领治理问题”的同对象缺口。

因此：

```yaml
nx_repairs_later_zx_same_object_gap: rejected
```

### 5.2 拿掉第十九回 zx

保留第十一回完整投梁山过程：

- 柴进荐书仍有效；
- 朱贵引入仍有效；
- 王伦的准入条件仍是当时必须面对的外部接口；
- 林冲仍可以通过该 nx 路径取得当时的成员位置。

后来的火并 zx 不会反向补足早期准入过程中的任何缺口。

因此：

```yaml
zx_repairs_prior_nx_same_object_gap: rejected
```

双向都没有形成严格补卡要求的“针对同一缺口的改善”。

## 6｜最近邻排除

### 6.1 与普通因果链

本例最接近的是：

> **前一事件改变人物位置 → 后一事件因此有机会发生。**

这属于时间 / 因果前提，不是严格补关系。

### 6.2 与压力显影

同一人物从“申请者 nx”变成“公开推翻接口 zx”，属于跨阶段压力与位置变化，可以作为动态链材料；但动态转换本身不自动等于互补。

### 6.3 与 xn

吴用在火并王伦桥段中有明显预判、暗号和语言推动，属于 `xn` 邻近污染；但冻结吴用策略后，林冲的 zx 仍独立成立，所以不影响本轮对象层错位判断。

### 6.4 与 x

林冲在第十一回没有梁山准入权；第十九回也没有因为杀王伦就长期把最高寨主位置据为己有。因此不能用 `x` 替代两个端点。

---

## 7｜关键压力

阶段 A 的压力：

- 官府追捕；
- 林冲需要长期安身；
- 王伦控制准入并设置条件。

阶段 B 的压力：

- 王伦再次拒绝晁盖等人；
- 梁山首领结构与准入结构发生公开冲突。

两组压力不是同一缺口持续升级，而是**问题对象已经切换**。

这是本轮不锁严格补关系的关键。

---

## 8｜反向测试：怎样才会变成真正严格补

要形成严格 `zx ↔ nx`，应当是同一事件目标中：

```text
林冲已有一个公开推进方向 zx
→ 但当前梁山治理目标卡在一个不属于自己的外部专属权限 / 资源接口
→ nx 直接取得这个接口
→ 林冲再把得到的条件兑换成同一治理目标的公开推进
```

或者反向：

```text
林冲已通过 nx 取得某一当前治理入口
→ 但外部接口本身不能完成同一目标
→ 必须由林冲 zx 再公开承担并收束
```

而现有“投梁山 → 八回后火并王伦”不满足这种同对象闭环。

## 9｜第三因素冻结

冻结：

- 林冲是否悲情英雄；
- 武艺强弱；
- 王伦是否嫉贤妒能；
- 吴用是否故意激林冲；
- 晁盖声望；
- 两个桥段相隔多少回；
- 最终梁山政治走向。

只检查：

```text
nx 当时补的是哪个对象的哪个缺口？
zx 后来处理的是哪个对象的哪个缺口？
两者是否直接改变同一变量？
还是只有历史前后关系？
```

结论不变。

## 10｜与前两类伪补下限的区分

### 第一类｜贾芸谋差

```text
nx 真成立
所谓 zx 只是主动性 / xn
→ 第一门失败：一端不存在
```

### 第二类｜鲁达五台山 / 鸳鸯拒婚

```text
zx、nx 两端都成立
但只有一个方向出现不可替代补位
→ 第二门失败：双向补缺不成立
```

### 第三类｜本轮林冲

```text
zx、nx 两端都成立
前后还有明显因果连续
但两端处理的是不同对象层 / 不同现实缺口
→ 第三门失败：缺口没有直接对接
```

因此严格补关系的最低筛选可进一步压成：

```text
第一门：zx、nx 是否分别独立成立？
↓
第二门：是否存在双向可命名缺口与双向改善？
↓
第三门：两边被补的缺口是否属于同一对象层，或至少存在可直接证明的同一现实变量因果对接？
↓
三门全部通过
才继续锁严格 zx ↔ nx 补关系
```

本轮只锁案例级限制，不修改 L1、信息卡、准度卡或 `zx补nx_补卡`。

**本轮最重要的案例级纪律：**

> **两个端点都真实、前后也存在因果，并不足以构成严格补关系。必须继续核对“缺口对象层”：A 端提供的条件，是否真的改变 B 端正在面对的那个现实变量；若只是让人物先进入另一个位置、后来才发生不同问题，则只是历史前提，不是严格补位。**

目前这是“对象层错位”第一部作品控制，不形成跨三作品待审议问题，不修改理论正本。
