# 运行记录｜关羽挂印封金：旧义 zn 成立，但汉寿亭侯名位不等于现实 x

## 1｜测试目标

给 `zn+x 当前共现` 补第一份**反方向伪共现**护栏：

> `zn` 真成立，但所谓 `x` 只是名位、称号或外部认可，缺少实际掌握/处分证据，因此不能计 `zn+x`。

本轮被测 `x` 对象不是曹赐金银、赤兔马等真实资源，而是**“汉寿亭侯”这一爵位/名位本身**。必须严格区分对象层。

## 2｜剧情事实

第26回关羽得知刘备消息后，明确以昔日盟誓与“旧义”压过曹操“新恩”，决定离曹归刘；临行将累次所受金银封置库中，将汉寿亭侯印悬于堂上，不带曹操所拨人役，只带原跟从人和随身行李离开。

可核原文来源：
- Chinese Text Project《三国演义》第26回：关羽书中明确“新恩虽厚，旧义难忘”，随后封金、挂印离曹。
- 东里书斋《三国演义》第26回同段。

## 3｜zn 证据

被测原则：**对刘备旧盟/旧义不能因新恩、爵位与现实奖励而替换；一旦确认刘备所在，旧义继续拥有未来行动的最终指导资格。**

- 原则对象明确：昔日盟誓/旧义；
- 无新增奖励时仍进入判断；
- 与曹操厚恩、爵位、金银发生现实冲突；
- 最终排序明确压过新恩；
- 直接指导离曹、归刘、护送二夫人的后续行动。

因此本窄原则对象层 `zn = true`。

## 4｜所谓 x 为什么不过门

本轮专测“汉寿亭侯名位”是否可直接算 `x`。

current `x_准度卡_v0.1` 要求：被测对象必须真实进入主体占有、使用、调配、调用、处分、否决或排除边界，而且权限不能只是纯名义、职位或一次接触。

对“汉寿亭侯”这一名位，当前桥段能直接证明的是：

- 曹操/汉廷授予的外部爵位与认可存在；
- 有一枚侯印作为名位凭证；
- 关羽可以把印悬回。

但当前没有足够证据证明：

- 该爵位对应一块可由关羽实际处分的封地；
- 有明确人口、财政、资源或公共事务进入关羽稳定直接调用边界；
- 关羽能凭这一名位独立决定某一现实对象的使用、退出、处分或排除。

因此：

```text
汉寿亭侯名位 / 外部承认
≠
现实掌握 x
```

侯印这一**物理物件**本身可另作为物品占有对象讨论，但不能把“持有一枚印”倒灌成“爵位所代表的现实权限已经形成 x”。

## 5｜关键本体变量

本轮真正分离的是：

```text
zn：什么内部原则仍拥有最终指导资格？

vs

```

所以“原则 + 高名位同框”不是 `zn+x` 的充分条件。

## 6｜拿掉测试

拿掉“汉寿亭侯”爵位与称号，只保留旧盟/旧义：

- 关羽旧义仍能进入冲突排序；
- 仍能指导离曹归刘；
- `zn` 不受影响。

拿掉曹赐金银、赤兔马等真实资源也不影响本轮对“爵位名位不是 x”的判断，因为本轮对象层只测试名位。

## 8｜最近邻排除

- `x vs z`：爵位、称号、授予首先是外部认可/位置，不等于现实掌握。
- `x vs zx`：名声和公开高位也不能替代稳定处分权。
- `zn vs z`：关羽旧义的指导资格不靠曹操认可成立。
- `zn vs x`：本轮旧义 `zn` 成立，但被测名位 `x` 不成立，所以不能计 co-occurrence。

- 旧义是否进入冲突排序；
