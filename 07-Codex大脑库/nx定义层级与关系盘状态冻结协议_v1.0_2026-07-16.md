# nx 定义层级与关系盘状态冻结协议 v1.3

## 1. 协议目的

本协议冻结 nx 当前已经确认的定义层级，并校准：

```text
nx 生 x；
nz 生 nx；
nx 克 x并z；
z 克 nx；
zx 与 nx 互补。
```

必须区分：

```text
从无到有的生成；
对既有十元的促长；
体量增长；
显影增强；
人物本体改变；
状态、行为和关系变化。
```

## 2. nx 核心定义

```text
nx：不主动占据选择、方向和位置，
把决定权留给已有关系、流程、群体、他人或既成安排，
并顺着已经形成的方向继续。
```

nx 不等于：

```text
暗算；
幕后操盘；
账本；
风控；
阴险设计；
结算者；
主动控制别人；
主动制造隐藏计划。
```

上述旧语义不得继续作为 nx 的本体、状态、行为或关系机制。

## 3. “把自己让没”的正式层级

```text
把自己让没
≠ nx 核心定义
```

正式写法为：

```text
nx 在 z 长期克制下的极端结果：
z 持续决定、占位、追索并压缩其他方向，
nx 又不主动夺回选择、方向和位置，
最终可能把自身位置持续让渡到接近消失。
```

因此必须区分：

```text
人物本体层：是否稳定以 nx 的方式处理选择和位置；
当前状态层：是否暂时不愿决定或依赖既有安排；
行为层：某次跟随、退让、服从或继续；
关系层：谁持续占位，谁没有取回位置；
结果层：是否已经发展为“把自己让没”。
```

单次退让、被迫服从、资源不足或权力悬殊，不能直接判人物本体 nx。

## 4. 当前关系状态

以下关系均已确认其基础语义：

```text
nx 生 x；
nz 生 nx；
nx 克 x并z；
z 克 nx；
zx 与 nx 互补。
```

其中 `nx 生 x` 必须使用限定口径：

```text
不从无到有地制造 x；
而是促使原本存在的 x 增长、积累和扩大。
```

## 5. 各关系的正式机制

### 5.1 nx 生 x：既有深欲因长期未被选择而增长

```text
人物原本已有 x
→ nx 不主动为自身欲望占据选择、表达和行动位置
→ 欲望长期得不到实现、处理或公开承认
→ 未满足的欲望在内部持续积累
→ x 的体量、压力或占位规模增长
```

这里的“生”不是：

```text
nx 创造了原本不存在的 x。
```

而是：

```text
nx 为既有 x 的增长提供了条件；
nx 使 x 更容易积压、扩大和变强。
```

必须同时区分 T 与 M：

```text
x 的 T 可以持续增长，
但因为 nx 不主动表达和选择，x 的 M 仍可能长期偏低；
当外部条件改变、压抑失效或选择窗口出现时，x 的 M 才可能突然升高。
```

因此：

```text
此前没有明显表现 ≠ x 不存在；
后期强烈显影 ≠ 后期才生成；
nx 生 x = 促长既有 x，而非从无到有。
```

### 5.2 nz 生 nx：主动靠近使 nx 暂时卸下决定痛苦

```text
nz 以可爱、温柔、主动靠近和照顾进入关系
→ 两位心灵发生触碰与交流
→ nx 被接住，并获得一个可以不用立即做决定的位置
→ nx 暂时摆脱持续做决定的痛苦
→ nx 的被动承接方式获得成立条件
```

这里的“生”是关系与状态层的条件建立，不表示：

```text
nz 把一个非 nx 人物改造成稳定本体 nx；
人物永久习惯把全部方向交给别人；
人物失去独立行动能力；
人物核心锚点被改写。
```

人物离开该关系后可以重新主动决定。

### 5.3 nx 克 x并z：拒绝进入包装要求的表态

```text
x并z 通过包装、价值说法、真假并置或“为你好”式叙事
要求对方认领某个身份、立场或公开表态
→ nx 天生抗拒被迫进入这套包装
→ nx 不接、不认领、不替对方复述，也不按要求表态
→ x并z 失去把 nx 纳入包装叙事并取得共同背书的接口
```

该关系克制的目标变量是：

```text
x并z 获得对方表态、认领与共同背书的能力。
```

nx 可能在行动上暂时被既有安排带着走，但：

```text
行为路径短暂被带动
≠ 包装获得认同
≠ nx 顺着 x并z 完成立场表演。
```

该机制不依赖看穿阴谋、暗中清算或主动反操控。

### 5.4 z 克 nx：长期占位使 nx 的自主位置减少

```text
z 持续决定和占位
→ 压缩 nx 可保留的选择、方向和位置
→ nx 不主动抢回位置
→ nx 的自主位置继续减少
```

“把自己让没”属于高作用量、长期持续条件下的极端结果，不是每次 `z 克 nx` 都必然出现。

### 5.5 zx 与 nx 互补：关系接口启动与互惠承接延续

这组关系属于关系机制，不是人物稳定本体的能力拼盘，也不是简单的领导者与跟随者。

#### zx 补 nx

```text
nx 本来愿意帮助别人，
但没有明确请求、具体事务或名正言顺的关系入口时，
通常不会主动伸手建立人情接口。

zx 通过主动开口、明确请求或把 nx 拉入第一次互助事件，
为 nx 提供关系进入许可、具体角色和合理行动理由。
```

zx 改变的是：

```text
关系能否开始；
第一次互助是否获得明确入口；
nx 是否拥有正当、具体、可执行的行动位置。
```

zx 没有从无到有创造 nx 的善意，也没有替 nx 决定全部人生方向。

#### nx 补 zx

```text
接口成立以后，
nx 通过可靠承接、回帮、照顾和后续执行，
让一次性接触发展为可持续的互惠关系。
```

nx 改变的是：

```text
事务能否被稳妥完成；
第一次互助是否形成后续回流；
关系能否从一次性接触延续为长期互惠。
```

nx 的承接与照顾属于已经成立关系中的行为功能，不得直接写成：

```text
nx 天生擅长社交；
nx 主动经营人脉；
nx 独立制造社会资源；
nx 负责所有人情世故。
```

最短冻结句：

```text
zx 启动人情接口；
nx 延续人情循环。
```

#### 拿掉测试

```text
拿掉 zx：nx 仍可能愿意帮，但因缺少明确请求、具体角色或合理入口，互助关系难以启动。
拿掉 nx：zx 即使完成第一次开口，关系也可能停在一次性接触，缺少可靠承接、回帮和后续延续。
```

双方同框或分别具有 zx、nx 特征，不等于互补自动启动。具体案例必须同时观察到第一次接口启动与后续互惠承接。

## 6. 人物本体、状态、行为、关系与结果必须分层

```text
人物本体层：人物是否长期稳定地以 nx 方式处理选择与位置；
当前状态层：人物是否因疲惫、信任、安全感、压力或被照顾而暂时不想决定；
行为层：某次跟随、拒绝表态、接受照顾、回帮或继续既有安排；
关系层：谁启动关系接口，谁延续互惠，谁施加表态压力、增长条件或位置压缩；
结果层：人物是否在长期作用下失去自身位置。
```

`nx 生 x` 默认改变的是既有 x 的增长条件、T 或内部压力，不自动改变人物稳定本体。

`zx ↔ nx` 默认改变的是关系启动与互惠延续条件，不自动证明 zx 或 nx 的人物稳定本体。

## 7. 动态链调用纪律

具体案例调用上述关系时，仍需冻结：

```text
源端点；
目标端点；
对象层；
具体阶段；
作用机制；
被改变的目标变量；
第三因素；
反向解释。
```

固定关系语义不等于每个共现案例都自动启动关系。

尤其：

```text
出现 nx 与 x
≠ nx 生 x 已经启动；
必须出现“既有 x 因 nx 式不选择、不表达、不处理而持续增长”的实际过程。

出现 zx 与 nx
≠ zx—nx 互补已经启动；
必须出现“第一次接口启动 + 后续互惠承接”的实际过程。
```

## 8. 三元与十元

```text
三元与十元并行判断；
三元不是十元的父级；
十元不是三元的子类；
上述 nx 关系不能由三元比例直接推出。
```

## 9. 当前冻结结论

```text
nx 核心是不主动占据选择、方向和位置，并顺着已有安排继续。
“把自己让没”是 z 长期克 nx 后可能出现的极端结果，不是 nx 本身。
nx 生 x：x 原本存在，nx 不从无到有地生成 x，但会促使既有 x 积累、扩大和增长。
nz 生 nx：nz 主动靠近和照顾，使 nx 可以暂时不用决定并摆脱决定痛苦。
nx 克 x并z：nx 拒绝认领包装、拒绝按要求表态，使包装失去共同背书接口。
z 克 nx：z 长期决定和占位，压缩 nx 的自主位置。
zx 与 nx 互补：zx 启动人情接口，nx 延续人情循环；该关系属于关系过程，不表示 nx 天生擅长社交，也不表示 zx 单向领导 nx。
人物本体、状态、行为、关系和结果必须分层记录。
三元与十元继续并行，不构成父子派生。
```
