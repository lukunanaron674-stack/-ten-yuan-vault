# nx 定义层级与关系盘状态冻结协议 v1.0

## 1. 协议目的

本协议冻结 nx 当前已经确认的定义层级，并阻止“把自己让没”被再次误写为 nx 的核心定义。

同时明确：几何位置保留，不等于关系语义已经成立。

## 2. nx 核心定义

```text
nx：不主动占据选择、方向和位置，
把决定权留给已有关系、流程、群体、他人或既成安排，
并顺着已经形成的方向继续。
```

核心负责回答：

```text
谁来决定方向；
人物是否主动争取位置；
人物是否重新取回选择权；
已有安排形成后，人物如何继续。
```

nx 不等于：

```text
暗算；
幕后操盘；
账本；
风控；
阴险设计；
结算者；
主动控制别人；
主动制造隐藏计划。
```

上述旧语义不得继续作为 nx 的本体、状态、行为或关系机制。

## 3. “把自己让没”的正式层级

```text
把自己让没
≠ nx 核心定义
```

正式写法为：

```text
nx 在 z 长期克制下的极端结果：
z 持续决定、占位、追索并压缩其他方向，
nx 又不主动夺回选择、方向和位置，
最终可能把自身位置持续让渡到接近消失。
```

因此必须区分：

```text
人物本体层：是否稳定以 nx 的方式处理选择和位置；
当前状态层：是否暂时不愿决定或依赖既有安排；
行为层：某次跟随、退让、服从或继续；
关系层：谁持续占位，谁没有取回位置；
结果层：是否已经发展为“把自己让没”。
```

单次退让、被迫服从、资源不足或权力悬殊，不能直接判人物本体 nx。

## 4. 已确认关系

当前与 nx 相关、可以正式调用的关系只有：

```text
z 克 nx
```

已确认机制：

```text
z 持续决定和占位
→ 压缩 nx 可保留的选择、方向和位置
→ nx 不主动抢回位置
→ nx 的自主位置继续减少
```

“把自己让没”属于该关系在高作用量、长期持续条件下的极端结果，不是每次 z 克 nx 都必然出现的结果。

## 5. 仅保留几何位置、语义待审的关系

以下关系目前不得作为正式生克补调用：

```text
nx 生 x；
nz 生 nx；
nx 克 x并z；
zx 与 nx 互补。
```

统一状态为：

```text
几何位置保留；
关系语义未确认；
不得自动进入动态链；
不得用旧 nx 故事补义；
不得反向修改人物稳定本体。
```

## 6. 关系候选的审核方式

每条待审关系必须分别通过：

```text
P1：源端点对象、对象层与阶段明确；
P2：目标端点对象、对象层与阶段明确；
P3：源端点十元判断达到 C-A；
P4：目标端点十元判断达到 C-A；
P5：具体作用机制达到 C-A；
P6：目标内部变量变化达到 C-A；
P7：生、克或补方向达到 C-A；
P8：第三因素不足以替代解释；
P9：反向关系不与当前方向同等成立。
```

任一必要命题未判定或为 C-C，关系不得进入正式动态链。

## 7. 生、显影、放大与放行必须分开

研究 nx 关系时，必须区分：

```text
生：源端点使目标结构真正生成或建立；
显影：目标原本存在，只是在当前阶段更明显；
放大：目标原本存在，体量或作用被扩大；
放行：源端点没有阻止目标运行；
状态诱发：只在特定关系或场景下暂时出现；
共现：两者同时存在，但没有作用机制。
```

不得把“nx 没有阻止 x”自动写成“nx 生 x”。
不得把“nz 关系中人物更依赖”自动写成“nz 生 nx”。
不得把“不接招”自动写成“nx 克 x并z”。
不得把“zx 带着 nx 行动”自动写成双向互补。

## 8. 人物核心锚点规则

涉及 nx 的剧情变化时，优先记录：

```text
人物是否仍以原有核心处理选择；
当前是否因压力、关系、场景或信息不足而暂时让位；
行为载体是否改变；
谁在关系中持续占位；
nx 的 M 是否变化；
z 克 nx 的 E 是否变化。
```

不得因为人物最终服从、失败、被捕、沉默或死亡，就倒推人物稳定本体为 nx，或倒推原有核心消失。

## 9. 当前冻结结论

```text
nx 核心是不主动占据选择、方向和位置，并顺着已有安排继续。
“把自己让没”是 z 长期克 nx 后可能出现的极端结果，不是 nx 本身。
当前只有 z 克 nx 获得正式调用资格。
nx 生 x、nz 生 nx、nx 克 x并z、zx 补 nx 均只保留几何位置，语义待审。
旧暗算、账本、风控、幕后操盘与阴险设计语义全部作废。
人物本体、状态、行为、关系和结果必须分层记录。
```
