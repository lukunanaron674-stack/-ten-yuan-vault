# nx 定义层级与关系盘状态冻结协议 v1.1

## 1. 协议目的

本协议冻结 nx 当前已经确认的定义层级，并阻止“把自己让没”被再次误写为 nx 的核心定义。

同时校准以下关系：

```text
nx 生 x；
nz 生 nx；
nx 克 x并z；
z 克 nx；
zx 与 nx 互补。
```

必须区分几何位置、正式关系语义、人物本体、当前状态、行为表现和关系结果。

## 2. nx 核心定义

```text
nx：不主动占据选择、方向和位置，
把决定权留给已有关系、流程、群体、他人或既成安排，
并顺着已经形成的方向继续。
```

核心负责回答：

```text
谁来决定方向；
人物是否主动争取位置；
人物是否重新取回选择权；
已有安排形成后，人物如何继续。
```

nx 不等于：

```text
暗算；
幕后操盘；
账本；
风控；
阴险设计；
结算者；
主动控制别人；
主动制造隐藏计划。
```

上述旧语义不得继续作为 nx 的本体、状态、行为或关系机制。

## 3. “把自己让没”的正式层级

```text
把自己让没
≠ nx 核心定义
```

正式写法为：

```text
nx 在 z 长期克制下的极端结果：
z 持续决定、占位、追索并压缩其他方向，
nx 又不主动夺回选择、方向和位置，
最终可能把自身位置持续让渡到接近消失。
```

因此必须区分：

```text
人物本体层：是否稳定以 nx 的方式处理选择和位置；
当前状态层：是否暂时不愿决定或依赖既有安排；
行为层：某次跟随、退让、服从或继续；
关系层：谁持续占位，谁没有取回位置；
结果层：是否已经发展为“把自己让没”。
```

单次退让、被迫服从、资源不足或权力悬殊，不能直接判人物本体 nx。

## 4. 当前关系状态总览

### 4.1 已确认

```text
z 克 nx；
nz 生 nx；
nx 克 x并z；
zx 与 nx 互补。
```

### 4.2 几何位置保留，但“生”的语义否定

```text
nx 生 x
```

当前正式结论为：

```text
x 本来就存在，只是此前没有表现；
nx 不生成 x；
nx 可能使既有 x 延迟显影、低显影或未被公开表达。
```

因此 `nx → x` 可以保留为旧几何生位记录，但不得作为正式“生成关系”进入动态链。

## 5. 各关系的正式机制

### 5.1 nx 不生 x：既有深欲的延迟显影

```text
人物原本已有 x
→ nx 不主动为自身欲望占据选择与表达位置
→ x 长期没有进入公开决定和明确表态
→ 后续条件变化时，x 才明显显影
```

这里发生的是：

```text
延迟显影；
低显影；
未表达；
后续暴露。
```

不是：

```text
nx 生成了原本不存在的 x。
```

不得把人物后来的强烈欲望倒推为“长期让位制造了深欲”。

### 5.2 nz 生 nx：主动靠近使被动者暂时卸下决定痛苦

正式机制：

```text
nz 以可爱、温柔、主动靠近和照顾进入关系
→ 两位心灵发生触碰与交流
→ nx 被接住，并获得一个可以不用立即做决定的位置
→ nx 暂时摆脱持续做决定的痛苦
→ nx 的被动承接方式得到成立条件
```

这里的“生”是关系与状态层的条件建立：

```text
nz 为 nx 提供可以被照顾、被靠近、暂时不决定的安全关系条件。
```

它不表示：

```text
nz 把一个非 nx 人物改造成稳定本体 nx；
人物从此习惯把全部方向交给别人；
人物失去独立行动能力；
人物核心锚点被改写。
```

人物离开该关系后可以重新主动决定。`nz 生 nx` 的重点是让 nx 摆脱当下决定负担，而不是培养永久的选择外包。

### 5.3 nx 克 x并z：拒绝进入包装要求的表态

正式机制：

```text
x并z 通过包装、价值说法、真假并置或“为你好”式叙事
要求对方认领某个身份、立场或公开表态
→ nx 天生抗拒被迫进入这套包装
→ nx 不接、不认领、不替对方复述，也不按要求表态
→ x并z 失去把 nx 纳入包装叙事并取得共同背书的接口
```

该关系克制的目标变量是：

```text
x并z 获得对方表态、认领与共同背书的能力。
```

必须保留一个重要区别：

```text
nx 可能在行动上暂时被既有安排带着走一下，
但内在会抗拒，表达上不会顺着包装说，
也不会主动进入对方要求的立场表演。
```

所以：

```text
行为路径短暂被带动
≠ 包装获得认同
≠ nx 顺着 x并z 完成表态
```

`nx 克 x并z` 不依赖“看穿阴谋”“暗中清算”或主动反操控。其核心是拒绝认领包装、拒绝提供表态接口。

### 5.4 z 克 nx：长期占位使 nx 的自主位置减少

```text
z 持续决定和占位
→ 压缩 nx 可保留的选择、方向和位置
→ nx 不主动抢回位置
→ nx 的自主位置继续减少
```

“把自己让没”属于该关系在高作用量、长期持续条件下的极端结果，不是每次 `z 克 nx` 都必然出现的结果。

### 5.5 zx 与 nx 互补：方向开路与人际照顾双向补足

这组关系不是简单的领导者与跟随者，也不是 nx 把全部人生交给 zx。

#### zx 补 nx

```text
zx 主动开路、确定共同事项的方向并承担第一次行动
→ nx 不必独自承受“现在必须由我决定”的痛苦
→ nx 获得可以承接和继续的明确路径
```

#### nx 补 zx

```text
nx 处理人际关系、日常照顾、人情往来与关系维持
→ 为 zx 提供人际支持、生活承接、社会资源和关系缓冲
→ zx 的开路行动不至于因缺乏照顾、协作或人情网络而中断
```

人需要相互照顾。zx 即使能够主动开路，也不能只靠一次突破长期生存；在重压落下、资源受限或需要他人协作时，nx 所维持的人际与日常支持会成为 zx 缺少的成立条件。

因此：

```text
zx 负责定方向
≠ nx 只会服从；

nx 承接共同方向
≠ nx 没有自己的事情；

nx 仍会独立完成自己负责的人际、照顾与日常工作。
```

双方都补足了对方独立运行时缺少的条件，因此拥有正式互补资格。

## 6. 人物本体、状态、行为与关系必须分层

### 人物本体层

判断人物是否长期稳定地不主动占据选择、方向和位置。

### 当前状态层

判断人物是否因疲惫、信任、安全感、压力或被照顾，暂时不想决定。

### 行为层

判断某一次跟随、拒绝表态、接受照顾、维持人际或继续既有安排的具体功能。

### 关系层

判断：

```text
谁提供方向；
谁提供照顾；
谁要求表态；
谁拒绝进入包装；
谁使对方暂时卸下决定负担。
```

### 结果层

判断人物是否被长期克制到失去自身位置，不得把结果倒推成 nx 核心。

## 7. 动态链调用纪律

任何具体案例调用上述关系时，仍需分别冻结：

```text
源端点；
目标端点；
人物本体或状态层；
具体阶段；
作用机制；
被改变的目标变量；
第三因素；
反向解释。
```

固定关系语义不等于每个共现案例都自动启动关系。

例如：

```text
出现 nz 与 nx
≠ nz 生 nx 已在该场景启动；

人物拒绝一句话
≠ nx 克 x并z 已成立；

zx 与 nx 同行
≠ 双向互补已经实际发生。
```

## 8. 三元与十元

```text
三元与十元并行判断；
三元不是十元的父级；
十元不是三元的子类；
上述 nx 关系不能由三元比例直接推出。
```

## 9. 当前冻结结论

```text
nx 核心是不主动占据选择、方向和位置，并顺着已有安排继续。
“把自己让没”是 z 长期克 nx 后可能出现的极端结果，不是 nx 本身。
nx 不生成 x；x 本来存在，只是此前没有显影或没有被表达。
nz 生 nx：nz 主动靠近和照顾，使 nx 可以暂时不用决定并摆脱决定痛苦。
nx 克 x并z：nx 拒绝认领包装、拒绝按要求表态，使包装失去共同背书接口。
z 克 nx：z 长期决定和占位，压缩 nx 的自主位置。
zx 与 nx 互补：zx 提供方向和开路，nx 提供人际、照顾、日常承接与社会支持。
互补不等于单向领导，nx 在共同方向之外仍会完成自己的关系与照顾工作。
人物本体、状态、行为、关系和结果必须分层记录。
三元与十元继续并行，不构成父子派生。
```
