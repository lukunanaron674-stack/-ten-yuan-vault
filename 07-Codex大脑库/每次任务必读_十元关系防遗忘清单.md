## 2. 当前可直接调用的已锁定关系

- `xn 克 zx`
- `zx 补 nx / nx 补 zx`
- `zx 克 n`
- `xn 生 xz`
- `x并z 生 z`
- `x 生 x并z`
- `x 克 z`
- `n 克 xz`
- `zn 补 x / x 补 zn`
- `n 补 x并z / x并z 补 n`
- `xn 补 z / z 补 xn`
- `xz 补 nz / nz 补 xz`
- `n 生 xn`
- `zn 生 n`
- `xz 生 zx`
- `x并z 克 nz`
- `nz 克 x`
- `x 克 nz`
- `zn 克 xn`

`zn 生 n` 只允许按窄机制调用：`zn` 撤回拒绝与推出资格，对象随后跨阶段留存并被持续处理，才构成 `n`。它不直接生成建筑、制度、资金或成熟共同体。

`xz 生 zx` 只允许按窄机制调用：危险使旧决定中心失效并形成决定空位；此前无正式最终接口的主体连续作出至少两项决定，他者实际执行并停止等待旧中心，于是状态层或关系位置层的公开决定接口新增。它不生成能力、勇气、领导人格或稳定 `zx` 本体。

## 3. 当前不得擅自锁定

| 关系 | 当前核心缺口 | 下一步必须寻找的证据 |
|---|---|---|
| `z 克 nx` | 纯认可最多可能克制判断资格自我取消型 `nx`；仍可能只是换一个跟随对象 | 认可者撤回支持甚至反对后，主体仍提出替代路线、使用否决并承担代价 |
| `nx 生 x` | `nx` 能空出方向位置，却不能单独解释掌握为何能抵抗原权利主体取回 | 撤掉职位、账户、合同、授权、信息控制和第三方制度化后，乙仍能实际拒绝、排除或持续代表 |
| `nz 生 nx` | 首次为了关系选择对方路线仍是自主决定；持续不恢复路线可能来自惯性或共同结构 | 关系已安全、可恢复自主且不会分离后，主体仍跨阶段不提出路线、不使用否决，并排除原有稳定 `nx` |
| `nx 克 x并z` | 行政壳不依赖认领，职责壳会被完整履行维持；共识背书壳的拒签动作又可能退出纯 `nx` | 主体继续基线流程、不公开反对、不另立路线，仅持续不进入可选背书位置，第三方自行降低代表资格 |
| `zx 生 zn` | 去来源、原则泛化和英雄背弃测试仍未通过 | 删除英雄姓名、形象、遗命、阵营和监督后，乙仍在新情境中按原则行动；英雄背弃时拒绝英雄 |
| `z 生 nz` | `z` 最多生成单方关系提议，完整 `nz` 仍需要另一方独立完成 | 评价、奖励与利益停止后，双方分别主动维护并兑现再次进入接口 |
| `xz 克 zn` | 现有案例多为实践能力、适用范围或原则排序变化，未证实规范资格被撤销 | 危险解除、事实纠正、创伤缓解、行动恢复且无竞争原则后，仍在新情境中否认旧原则正确性 |

## 4. 通用红线

1. 几何位置锁定不等于机制锁定。
2. 共现、先后、对照和视觉相似不等于关系启动。
3. 必须写源端点、目标端点、机制、变量、阶段、体量、显影条件与第三因素。
4. 必须做拿掉测试和反向测试。
5. 稳定本体、状态、行为、光影、场景、时间关系、关系位置、显影与动态链必须分层。
6. 三元与十元并行，不构成父子派生。
7. 无新证据时不得重复扩写完整专项。
8. `zn 生 n` 必须同时证明“准入启动”与“承载成立”。
9. 一次善举、收留、捐助、藏匿、口号和建筑题材均不足以证明 `zn 生 n`。
10. `zn` 只直接改变 `n` 的准入、留存与承担边界，不自动生成成熟容量、建筑或制度。
11. `xz 生 zx` 只能生成状态层或关系位置层的公开决定接口。
12. `xz 生 zx` 必须证明旧中心因危险失效，且至少两项不同层面的最终决定被执行。
13. `zx 生 zn` 必须跨主体；执行遗命不等于原则内化。
14. `zx 生 zn` 必须通过去来源、原则泛化与英雄背弃测试。
15. `z 生 nz` 必须拆开单方回返意愿与双方可信可回返关系。
16. `xz 克 zn` 必须拆开原则正确性、适用范围、优先级与实践能力。
17. `z 克 nx` 必须通过反认可测试。
18. `nx 生 x` 必须通过实际取回抵抗测试，并追查抵抗的第二入口。
19. `nz 生 nx` 必须通过关系安全保证测试，并排除惯性、路径依赖、共同结构与原有稳定 `nx`。
20. `nx 克 x并z` 必须分开行政归类壳、职责履行壳与共识背书壳。
