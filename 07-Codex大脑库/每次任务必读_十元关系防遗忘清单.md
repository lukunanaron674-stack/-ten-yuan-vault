`zn 克 xn` 红线：必须先有持续运行的规则、训练、程序、记录或传统；随后主体以不依赖奖惩和认可的内部意义撤回“应当维护”资格，使结构对该主体的覆盖、自愿执行、内部修复或跨轮次复制真实下降。人物有信念、一次抗命、公开反抗、制度最后倒塌、财政断裂或领导更替均不足。

`x 克 nz` 红线：必须先有真实共同时间、关系余温和自愿停靠；随后 `x` 的最终决定、否决、退出或回返控制真实增强，使留下不再能够证明“我还愿意停靠”。一次吃醋、一次争吵、安全建议、临时保护、普通嫉妒、外部危险、经济依赖、监护责任和只有控制欲形容词均不足。

`nz 克 x` 红线：关系余温必须使掌握者主动缩小控制边界，且对方的自主路线、退出权或回返空间真实增加。

`x并z 克 nz` 红线：身份壳必须污染关系证据归因并降低可信回返。

其他关系只有在核心表“已锁定关系语义”或专项正本索引明确列为 `canonical-current` 时才能直接调用。

## 3. 当前不得擅自锁定

| 关系 | 当前核心缺口 | 下一步必须寻找的证据 |
|---|---|---|
| `z 克 nx` | 旧“持续表达和占位”口径已撤回；现有案例混入教学、照护、放权或人物原有自主性 | 认可停止后主体仍提出替代路线、使用否决权并承担后果，外部方向从唯一合法降为可拒绝 |
| `nx 生 x` | 同主体生成缺乏机制；跨主体默认决定累积仍混入授权、资源、职位和主动占位 | 甲可拒绝却长期让位；乙原无稳定 x；随后新增事实否决、排他使用或关系控制，拿掉授权和夺取仍成立 |
| `nz 生 nx` | 本轮再次确认：共同时间延长、建议权重上升、共同协商都不等于 `nx`；真正目标必须是主体退出最终方向位置。现有山姆/弗罗多、男孩/父亲均混入任务、zn、年龄、照护、危险与既有方向不平等，无法证明 `nz` 独立生成 `nx` | 找到至少两个具体人物阶段：双方平等可选、无职位与资源依赖、可自由拒绝；已有共同时间和可信回返；主体原有可行替代路线与否决权，却只因不愿关系结束而明确把某段最终方向交给对方；拿掉关系余温后让位消失 |
| `nx 克 x并z` | 不认领身份壳与失去资源、权力压制混杂 | 壳依赖主体持续背书；拿掉 `x/zx` 后，拒绝认领仍使壳解释接口下降 |
| `zx 生 zn` | 英雄显权与原有意义、宣传、胜方追随混杂 | 甲离场、失败、无奖励后，乙仍把原则从“他的”变成“我的” |
| `zn 生 n` | 意义动机与 `zx/xn/x` 中介无法分开 | 低权能、低制度、低资源条件下，意义直接扩大持续承接边界 |
| `xz 生 zx` | 更像潜在 `zx` 被迫显影 | 危险前目标端点不存在，决定空位出现后才新增公开权能位置 |
| `z 生 nz` | 认可前已有关系厚度、共同时间与奖励 | 无既有 `nz/n/xn` 时，明确认可本身使关系获得不愿结束的时间厚度 |
| `xz 克 zn` | 行为妥协、意义排序与原则正确性改判混杂 | 危险解除后仍持续认为原原则不再正确，而非仅无法实践或优先级下降 |

## 4. 通用红线

1. 几何位置锁定不等于机制锁定。
2. 共现、先后、对照和视觉相似不等于关系启动。
3. 每条关系必须写源端点、目标端点、机制、被改变变量、阶段、体量、显影条件与第三因素。
4. 必须做拿掉测试和反向测试。
5. 稳定本体、状态、行为、光影、场景、时间关系、关系位置、显影与动态链分层。
6. 三元与十元并行，不构成父子派生。
7. 禁止依赖记忆重画关系表。
8. `nz 生 nx` 不能用“多陪一会、愿意听建议、共同商量、一起旅行”代替最终方向让位。
9. `nz 生 nx` 必须在主体拥有替代路线和否决权时，观察其是否主动退出最终决定位置；年龄、照护、任务、职位、资源、安全与能力差必须拿掉。
10. `nx 生 x` 若成立，优先检查跨主体方向，不能把乙原有 `x`、正式授权、资源交付、职位权力或主动夺取倒写成由甲的 `nx` 生成。
11. 无新证据时不得重复扩写整份审计，只更新最新缺口和下一证据目标。
12. 旧电影卡、视觉卡与案例卡只作证据，不得冒充本轮理论推进。
