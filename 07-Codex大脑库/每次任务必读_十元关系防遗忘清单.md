# 每次任务必读｜十元关系防遗忘中枢 v9.24

## 固定启动

```text
最新main SHA
→ AGENTS与文件权力总览
→ L1 v1.6
→ 判断任务是否进入或扩展一个领域
→ 若是：先读领域狭义五行十元映射习惯协议，并读取或建立该领域映射
→ 再读信息卡、准度卡与相关专项正本
→ 若涉及关系，先查端点冻结
→ 再读单条关系卡、核心表与专项索引
```

## 领域工作习惯

```text
做一个领域
＝先思考一次该领域的五行狭义定义
＝再写十个十元在该领域中的具体操作、对象与证据
＝之后才开始案例、素材、角色、场景、音乐、游戏或视觉分类
```

不得把主题领域、人物行为领域、生理领域或其他旧领域的狭义词机械复制到新领域。

每个领域至少先回答：

- 该领域的对象与分析尺度是什么；
- 五行各自对应哪一个领域核心变量；
- 同行阴阳如何在同一变量上反向操作；
- 十个十元分别有什么可观察动作、形态、声音、机制或结果；
- 正例、反例、最近邻和未解决问题是什么。

映射未完成时标记`draft-domain-map`，不得冒充稳定正本。

## 最高层级

```text
十元＝五行内部的阴阳操作端
五行＝同行十元的对立统一体
领域狭义定义＝五行进入具体对象域后的名称、变量与判据
五大主题＝五行在主题／叙事领域的狭义定义
```

## 最高五轴

```text
木：zx↔nx
火：zn↔x
土：n↔x并z
金：xn↔z
水：xz↔nz
```

禁止继续写`z↔zn`。

## z/zn/ZX

```text
ZN＝你们都对，我也是对的。
z＝我是最对的，你们不关我事。
ZX＝我是对的，你们都是错的。
```

- z：阴金单点最高化；认可不是纯z必要条件。
- zn：阳火并存赋义；自己成立并主动保存他者成立资格。
- 羽生式“你们退出，我继续唯一路线”优先检查z，不再作为稳定zn锚点。
- 方志敏、炼狱杏寿郎式“自己承担，同时让他人继续成立”作为zn采矿方向，仍须逐行为证据。

## 关系红线

所有含z或zn的旧生克补机制统一`endpoint-redefinition-freeze`。几何位保留，机制不得调用，直到逐条重新审计。

## 行为红线

人物十元必须由明确行为、对象层和改变变量判断。不得用职业、情绪、战斗、善良、牺牲、结局、作品气质或五行情志倒推。
