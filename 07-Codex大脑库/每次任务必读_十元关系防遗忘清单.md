## 2. 当前可直接调用的已锁定关系

- `xn 克 zx`
- `zx 补 nx / nx 补 zx`
- `zx 克 n`
- `xn 生 xz`
- `x并z 生 z`
- `x 生 x并z`
- `x 克 z`
- `n 克 xz`
- `zn 补 x / x 补 zn`
- `n 补 x并z / x并z 补 n`
- `xn 补 z / z 补 xn`
- `xz 补 nz / nz 补 xz`
- `n 生 xn`
- `zn 生 n`
- `xz 生 zx`
- `x并z 克 nz`
- `nz 克 x`
- `x 克 nz`
- `zn 克 xn`

`zn 生 n` 只允许按窄机制调用：`zn` 撤回拒绝与推出资格，对象随后跨阶段留存并被持续处理，才构成 `n`。它不直接生成建筑、制度、资金或成熟共同体。

`xz 生 zx` 只允许按窄机制调用：危险使旧决定中心失效并形成决定空位；此前无正式最终接口的主体连续作出至少两项决定，他者实际执行并停止等待旧中心，于是状态层或关系位置层的公开决定接口新增。它不生成能力、勇气、领导人格或稳定 `zx` 本体。

## 3. 当前不得擅自锁定

| 关系 | 当前核心缺口 | 下一步必须寻找的证据 |
|---|---|---|
| `z 克 nx` | 纯认可只可能克制“主体已有可行路线，却否定自身判断资格而跟随”的 `nx`；现有案例常把认可与新信息、教学判断、许可、资源、照护或既有自主显影混在一起 | 做“信息零增量／认可必要性测试”：认可者不提供新证据、理由、比较、诊断、方案、许可或兜底，只确认主体的判断资格；把相同事实信息匿名提供或改由低重要性来源提供后，若主体仍同样取回方向，则作用源不是纯 `z`。认可撤回、首次自主失败且进入认可者未评价的新选择后，主体仍须提出路线、否决外部安排并承担代价 |
| `nx 生 x` | `nx` 能空出方向位置并把决定、协调、记录与善后负荷推给乙，但乙的不可替代性可能只来自信息集中、熟练度和第三方习惯；这些首先属于代理或 `xn`，不等于乙拥有可自主使用、排除甲和保留剩余收益的掌握边界 | 做“可替换性／剩余控制测试”：撤掉乙本人但保留流程、资料和普通代理资格，若另一代理可接续，说明只是角色接口；只有乙在无职位、合同、授权、账户、信息截断、制度保护和主动压迫时，仍能决定资源剩余用途、排除甲直接使用、保留收益或把成本转嫁给甲，才继续接近 `x` |
| `nz 生 nx` | `nz` 能解释关系保全型一次委托、方向暂停或等待，但不等于把最终方向资格交给对方 | 关系安全、路线供给撤场且共同结构移除后，主体仍明确承认对方拥有最终决定资格；若只是等待、停滞、恢复自主或对称协商，不成立 |
| `nx 克 x并z` | 行政壳与职责壳不能由纯 `nx` 直接削弱；周期续期壳最多允许当期自愿代表资格不再续生 | 壳此前真实覆盖主体；当前代表资格明确依赖周期主动续签；主体继续基线流程且有同等机会却不进入；无需拒签、撤名或价值表态，到期后第三方自动标记未续期，同时保留历史身份与既有记录 |
| `zx 生 zn` | 现有案例最多稳定支持 `zx` 提高原则的公开可见性、现实可信度与见证强度，未证明公开权能是内部义务的必要生成源 | 同原则载体替换／公开权能净增量测试；去英雄化、新情境、无关对象、英雄背弃和同等 `zx` 推进无关原则的控制测试 |
| `z 生 nz` | `z` 较稳定生成被认可者的单方回返提议；完整关系仍可能依赖持续评价功能、训练照护、共同任务或既有友情 | 做零评价窗口／非评价冲突修复测试：停止双方对原能力、作品与选择的全部评价，撤掉奖励、推荐、资源和任务；双方仍分别主动维持普通相处、回返与非评价性共同内容，并能修复与评价无关的分歧 |
| `xz 克 zn` | 现有案例仍主要证明实践失败、适用范围条件化、原则排序、错误事实或创伤回避；事后认可一次极端决定只证明例外正当化 | 做反事实同条件复判／跨案例迁移测试：危险解除后，主体明确认为原危险条件若重现仍应拒绝旧原则，并把稳定替代原则用于至少两个结构相同但对象不同的新选择 |

## 4. 通用红线

1. 几何位置锁定不等于机制锁定。
2. 共现、先后、对照和视觉相似不等于关系启动。
3. 必须写源端点、目标端点、机制、变量、阶段、体量、显影条件与第三因素。
4. 必须做拿掉测试和反向测试。
5. 稳定本体、状态、行为、光影、场景、时间关系、关系位置、显影与动态链必须分层。
6. 三元与十元并行，不构成父子派生。
7. 无新证据时不得重复扩写完整专项。
8. `zn 生 n` 必须同时证明准入启动与承载成立。
9. 一次善举、收留、捐助、藏匿、口号和建筑题材不足以证明 `zn 生 n`。
10. `zn` 只直接改变 `n` 的准入、留存与承担边界，不自动生成成熟容量、建筑或制度。
11. `xz 生 zx` 只能生成状态层或关系位置层的公开决定接口。
12. `xz 生 zx` 必须证明旧中心因危险失效，且至少两项不同层面的最终决定被执行。
13. `zx 生 zn` 必须跨主体；执行遗命不等于原则内化。
14. `zx 生 zn` 必须通过去来源、原则泛化与英雄背弃测试。
15. `z 生 nz` 必须拆开单方回返意愿与双方可信可回返关系。
16. `xz 克 zn` 必须拆开原则正确性、适用范围、优先级与实践能力。
17. `z 克 nx` 必须通过反认可测试。
18. `nx 生 x` 必须通过实际取回抵抗测试，并追查抵抗的第二入口。
19. `nz 生 nx` 必须通过关系安全保证测试，并排除惯性、路径依赖、共同结构与原有稳定 `nx`。
20. `nx 克 x并z` 必须分开行政归类壳、职责履行壳与共识背书壳。
21. `z 克 nx` 必须做源主体分离测试。
22. `nx 生 x` 的取回抵抗必须分为正当性摩擦与事实控制抵抗。
23. `nz 生 nx` 必须做路线供给撤场测试。
24. `nz 生 nx` 必须做对称交换测试。
25. `nx 克 x并z` 必须通过可观察性—源动作双重测试。
26. “没有进入可选背书位置”不得与“从未被壳纳入、没有机会、不可用或偶然缺席”混写。
27. `zx 生 zn` 必须做源必要性测试。
28. `zx 生 zn` 必须分开原则进入注意范围与原则成为内部义务。
29. `z 生 nz` 必须做评价对象撤场测试。
30. `z 生 nz` 必须做负向评价存续测试。
31. `xz 克 zn` 必须做恢复后再承诺测试；沉默、回避或无法行动不得判克位。
32. `z 克 nx` 必须做失败后方向资格保持测试。
33. `z 克 nx` 必须做跨选择迁移测试。
34. `nx 生 x` 必须做决定负荷—掌握收益测试。
35. `nz 生 nx` 必须做方向暂停—方向转交测试。
36. `nx 克 x并z` 必须做存量壳—续期壳测试。
37. `zx 生 zn` 必须做同原则载体替换／公开权能净增量测试。
38. `z 生 nz` 必须做零评价窗口／非评价冲突修复测试。
39. `xz 克 zn` 必须做反事实同条件复判／跨案例迁移测试。
40. `z 克 nx` 必须做“信息零增量／认可必要性测试”：认可不得携带新事实、理由、比较、诊断、方案、许可或兜底；若相同事实由匿名或低重要性来源提供也产生同等自主变化，则应改查 `xn`、事实更新或既有自主显影，而非纯 `z` 克制。
41. `nx 生 x` 必须做“可替换性／剩余控制测试”：乙因熟练、信息集中或第三方习惯而不可替代，仍可能只是 `xn` 接口；只有乙能决定剩余资源用途、排除甲、保留收益或转嫁成本，才触及 `x`。

## 5. 每小时滚动推进区

### 5.1 当前接续点

```text
最近完成：nx 生 x 的可替换性与剩余控制审计
结果：甲持续让位会把决定、协调、记录与善后负荷推给乙，并可能使乙在第三方眼中变得不可替代；但不可替代性仍可能只是信息集中、熟练度、流程依赖与 xn 接口。新增“可替换性／剩余控制测试”：撤掉乙本人而保留资料、流程与普通代理资格，若另一代理能够接续，则未生成个人 x；只有乙在无职位、合同、授权、账户、信息截断、制度保护与主动压迫时，仍能决定剩余资源用途、排除甲直接使用、保留收益或把成本转嫁给甲，才触及受益型掌握。
理论结论：nx 能提供方向空位、代理负荷与掌握扩张条件；尚未证明它独立生成 x。核心表、词典、专项索引和队列未修改。
下一条关系：nz 生 nx
```
