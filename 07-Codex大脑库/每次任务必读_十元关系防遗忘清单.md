## 0. 每次任务启动顺序

```text
读取当前 main 最新 SHA
→ 读取本文件
→ 读取 07-Codex大脑库/Codex大脑总入口.md
```

理论任务开始时必须在运行记录中留下四项：

```text

本轮目标关系及其状态：已锁定 / 语义待验收 / 未单独解释
```

若没有这四项，不得提交理论结论。

## 3. 当前可以直接调用的已锁定关系语义

### xn 克 zx

```text
现实已经被时间、规则、流程和前置行动组织
→ zx 的即时显权扩张必须进入既有结构
→ 单次爆发不能直接取消长期积累
```

### zx 补 nx / nx 补 zx

```text
zx：直接以主体自己的权能做成
nx：通过既有身份、关系、权限与通道借力做成
```

除现行生补克表“已锁定关系语义”章节与关系专项正本索引明确列为 `canonical-current` 的关系外，不得凭记忆把其他箭头写成正式心理机制。

## 4. 当前明确不得擅自锁定的关系

```text
z 克 nx
nx 生 x
nz 生 nx
nx 克 x并z
zx 生 zn
zn 生 n
xz 生 zx
z 生 nz
```

这些关系的位置可以保留，但机制仍须按具体人物、阶段、双方和目标变量重新验收。

## 5. 十条防遗忘红线

1. **几何位置锁定 ≠ 机制锁定。**
2. **共现、先后、对照、视觉相似 ≠ 生克补启动。**
3. 每条关系必须写清源端点、目标端点、机制和被改变变量。
4. 必须检查第三因素、拿掉测试与反向测试。
5. 人物稳定本体、当前状态、行为功能、光影、场景、时间关系、关系位置、显影、动态链必须分层。
6. 三元与十元并行判断，互不构成父子派生。
7. 禁止把 `x / z / n` 固定翻译成“现象 / 本质 / 应用”。
8. 禁止继续使用 `x=无形欲望`、`幕后操盘=nx`、`nx生x=压抑欲望累积` 等旧口径。
9. 禁止用五大主题构成反推人物十元点位。
10. 禁止依赖记忆重画生克补表；每次任务必须重新读取当前正本。
