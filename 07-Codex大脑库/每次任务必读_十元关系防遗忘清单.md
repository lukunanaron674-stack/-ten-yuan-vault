# 每次任务必读｜十元关系防遗忘与滚动推进中枢

> 账本证明运行，卡片保存知识。无新证据时只做轻量复核，不拿重复检查冒充理论升级。未锁定关系的采矿必须由卡内“达到95%还缺什么证据”驱动。

## 0. 固定启动顺序

```text
当前main SHA
→ 问题单、本文件、执行门禁、卡片记忆协议
→ 信息卡总览与两端信息卡
→ 准度卡总控与两端准度卡
→ 生克补卡总控与本轮单卡

```

## 1. 执行红线

- 问题单有`pending`时优先处理。
- 无新证据只跑轻量轮，不改理论卡、不涨理论或记忆版本。
- 七项取最低值，未全部达到95不得锁定。
- 审计不写动态链案例、总索引或母型计数。
- 所有未锁定关系卡必须维护`evidence_gap_schema_version: v1.0`与`达到95%还缺什么证据`固定区块。
- 新案例只有命中某项明确证据缺口并通过对应控制，才算有效新增独立证据；普通相似案例不计。
- 不得只写“继续找案例”；必须写最弱项、已有证据、尚缺控制证据、三类采矿目标、锁定条件与否定/降级条件。
- `x并z`关系审计必须在观察结果前预注册壳依赖类型：事实索引、独立制度、构成性认证、持续表演或单次互动令牌。
- 未预注册壳类型时，`x并z`端点与最近邻排除不得高于89；未排除单次令牌和外部制度撤销时，可逆性不得高于79。
