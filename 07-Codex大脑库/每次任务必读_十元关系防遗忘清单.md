
## 2. 当前可直接调用的已锁定关系

- `xn 克 zx`
- `zx 补 nx / nx 补 zx`
- `zx 克 n`
- `xn 生 xz`
- `x并z 生 z`
- `x 生 x并z`
- `x 克 z`
- `n 克 xz`
- `zn 补 x / x 补 zn`
- `n 补 x并z / x并z 补 n`
- `xn 补 z / z 补 xn`
- `xz 补 nz / nz 补 xz`
- `n 生 xn`
- `zn 生 n`
- `xz 生 zx`
- `x并z 克 nz`
- `nz 克 x`
- `x 克 nz`
- `zn 克 xn`

`zn 生 n` 当前只允许按窄机制调用：`zn` 撤回拒绝与推出资格，对象随后跨阶段留存并被持续处理，才构成 `n`。它不直接生成建筑、制度、资金或成熟共同体。

`xz 生 zx` 当前只允许按窄机制调用：危险使旧决定中心失效并形成决定空位；此前无正式最终接口的主体连续作出至少两项决定，他者实际执行并停止等待旧中心，于是状态层或关系位置层的公开决定接口新增。它不生成能力、勇气、领导人格或稳定 `zx` 本体。

## 3. 当前不得擅自锁定

| 关系 | 当前核心缺口 | 下一步必须寻找的证据 |
|---|---|---|
| `z 克 nx` | 纯认可最多可能克制“主体因否定自身判断资格而形成的 nx”；认可后独立一次仍可能只是服从认可者的新方向 | 认可者停止支持、撤回认可甚至反对主体路线后，主体仍提出替代路线、使用否决并承担代价；若只是改听认可者安排，则 nx 未下降 |
| `nx 生 x` | 默认代管不足；必须通过取回抵抗，且抵抗不能来自既有 `x/xn` 或正式授权 | 甲取回时乙仍能实际拒绝、排除或维持代表接口 |
| `nz 生 nx` | 一次主动选择对方路线仍可能是自主决定 | 关系稳定后主体仍跨阶段不恢复自己的最终路线 |
| `nx 克 x并z` | 仅共识背书壳可能因撤回可选签署、复述或署名而缩小覆盖 | 主体继续基线流程，第三方随后把“全体／本人立场”降为“多数／外部标签” |
| `zx 生 zn` | 公开见证、崇拜、执行遗命与原则内化不是同一变量 | 甲撤场后乙在新情境中自行从原则推出行动，并能拒绝冲突的英雄遗命 |
| `z 生 nz` | `z` 最多可生成单方关系提议；完整 `nz` 还需要认可者在评价结束后主动保留并实际兑现回返入口 | 奖励、任务、利益和继续评价均停止后，双方分别主动维护再次相见或共同创作接口；任一方撤回时关系不能只靠被认可者追逐维持 |
| `xz 克 zn` | 现有案例主要改变实践能力、当下适用范围或多个原则的优先级，尚不能证明自然危险持续撤销稳定原则的规范资格 | 危险解除、事实纠正、创伤缓解、行动能力恢复且无竞争原则顶替后，主体仍在新情境中主动否认旧原则正确性，并拒绝其恢复最终指导权 |

## 4. 通用红线

1. 几何位置锁定不等于机制锁定。
2. 共现、先后、对照和视觉相似不等于关系启动。
3. 必须写源端点、目标端点、机制、变量、阶段、体量、显影条件与第三因素。
4. 必须做拿掉测试和反向测试。
5. 稳定本体、状态、行为、光影、场景、时间关系、关系位置、显影与动态链分层。
6. 三元与十元并行，不构成父子派生。
7. 禁止依赖记忆重画关系表。
8. `zn 生 n` 必须同时证明“准入启动”与“承载成立”。
9. 一次善举、收留、捐助、藏匿、口号和建筑题材均不足以证明 `zn 生 n`。
10. `zn` 只直接改变 `n` 的准入、留存与承担边界，不自动生成成熟容量、建筑或制度。
11. `zx 生 zn` 必须跨主体；执行遗命不等于原则内化。
12. `nz 生 nx` 的目标不是陪伴、协商或一次主动让路，而是跨阶段不占最终方向位置。
13. `nx 克 x并z` 不得混淆行政归类壳、职责履行壳和共识背书壳。
14. `xz 生 zx` 只能生成状态层或关系位置层的公开决定接口，不得写成危险凭空生成能力或稳定本体。
15. `xz 生 zx` 必须证明旧中心因危险失效，且至少两项不同层面的最终决定被执行。
16. `z 生 nz` 必须拆开单方回返意愿与双方可信可回返关系。
17. `xz 克 zn` 的目标变量是规范判断，不是事实判断、创伤回避或实践失败。
18. `nx 生 x` 必须通过实际取回抵抗测试。
19. 无新证据时不得重复扩写整份审计。
20. `z 生 nz` 的完整目标必须通过“双向完成测试”：被认可者想回返只构成关系提议；认可者停止评价后仍主动保留并兑现入口，才触及完整 `nz`。
21. 联系方式、礼貌邀请、关注账号和“以后再合作”口头承诺不等于可信回返接口；必须出现评价结束后的主动行动与实际进入资格。
22. `xz 克 zn` 必须拆开四个变量：原则正确性、原则适用范围、多个原则的优先级、现实实践能力；只有正确性或最终指导资格持续下降才触及克位。
23. 原则仍被认为正确，只因当下无能力实践、适用条件暂时不满足，或另一条 `zn` 优先级更高，均不得判 `xz 克 zn`。
24. `z 克 nx` 必须通过“反认可测试”：认可者撤回支持甚至反对后，主体仍保留自己的路线，才证明方向权回到主体，而不是转交给认可者。
25. `z 克 nx` 只适用于判断资格自我取消型 `nx`；资源、职位、许可、能力与现实路线缺失形成的结构性 `nx` 不能靠纯认可解除。

## 5. 每小时滚动推进区

### 5.1 当前接续点

```text
最近完成：z 克 nx
结果：正式机制未锁定。高置信收窄为“判断资格自我取消型 nx”：主体原本有真实路线、否决能力和承担资格，只因认为自己的判断不合法而跟随。新增反认可测试：认可者撤回支持、改为反对或提出相反路线后，主体仍维持自己的路线，才说明方向权真正回到主体；若主体随认可者改变方向，只是换了跟随对象。
理论提交：仅更新本必读中枢的证据缺口、红线与下一断点；核心表、关系词典和旧审计不修改。
下一条关系：nx 生 x
```

### 5.2 下一轮目标

优先核验 `nx 生 x`：

```text
甲原本拥有真实拒绝与取回方向的能力
→ 跨轮次持续不使用方向权
→ 乙此前没有稳定掌握边界
→ 甲明确取回时，乙或第三方接口仍能实际拒绝、排除或持续代表
→ 该抵抗又不能来自职位、账户、合同、正式授权、信息截断或乙既有 x/xn
```

重点区分：`nx` 是否真正生成掌握，还是只提供空位，随后由乙的主动接管、第三方制度化或既有权限完成 `x`。
