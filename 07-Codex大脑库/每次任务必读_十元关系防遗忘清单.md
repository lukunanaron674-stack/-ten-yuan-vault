## 2. 当前可直接调用的已锁定关系

- `xn 克 zx`
- `zx 补 nx / nx 补 zx`
- `zx 克 n`
- `xn 生 xz`
- `x并z 生 z`
- `x 生 x并z`
- `x 克 z`
- `n 克 xz`
- `zn 补 x / x 补 zn`

`zn 补 x / x 补 zn` 红线：必须分别证明 `zn` 的无奖励内部意义与 `x` 的实际掌握边界；`zn` 改变掌握用途与守护标准，`x` 提供意义的对象、资源、权限和我方边界。信念不会自动制造资源，拥有资源不会自动产生意义，危险、深渊、战乱和受苦不是 `x`。

其他关系只有在核心表“已锁定关系语义”或专项正本索引明确列为 `canonical-current` 时才能直接调用。

```text
z 克 nx

z 生 nz

```

## 4. 通用红线

1. 几何位置锁定不等于机制锁定。
2. 共现、先后、对照和视觉相似不等于关系启动。
3. 每条关系必须写源端点、目标端点、机制、被改变变量、阶段与第三因素。
4. 必须做拿掉测试和反向测试。
5. 稳定本体、状态、行为、光影、场景、时间关系、关系位置、显影与动态链分层。
6. 三元与十元并行，不构成父子派生。
7. 禁止依赖记忆重画关系表。
