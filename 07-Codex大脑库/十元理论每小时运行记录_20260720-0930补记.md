## 5. 源端点、目标端点与变量

### 源端点 nx

- 主体原本拥有可认领的方向、权限或否决位置；
- 并非法律、职位或能力上根本无权；
- 跨多个阶段持续不提出方向、不取回决定位置；
- 没有被持续威胁、强迫或公开压退；
- 即使无人命令，也默认等待外部主体安排。

### 目标端点 x

- 某一主体原本只拥有局部掌握边界；
- 随后新增对象、资源、时间、关系或权限进入其实际控制范围；
- 新增掌握表现为使用、调配、否决、对外接口或退出控制；
- 不是“看起来更强势”，而是事实边界发生变化。

### 被改变变量

- 谁决定顺序和方向；
- 谁持有账户、信息与资源接口；
- 谁拥有最终否决权；
- 原本共同或模糊的范围是否变成单方控制；
- nx 主体是否仍可随时取回位置；
- x 的扩大是否在拿掉主动施压后仍发生。

## 6. 候选机制

### 候选 A：稳定空位被既有掌握边界吸纳

```text
nx 主体持续空出本可认领的决定位置
→ 为维持关系和行动，既有 x 主体反复代决
→ 外部成员逐渐只向 x 主体请求决定
→ 临时代管沉淀为事实控制
→ x 边界扩大
```

理论后果：若成立，只能先锁定关系层；`nx` 不是主动赠予 x，而是提供持续许可条件。

### 候选 B：默认授权的累积改变事实权限

```text
每次事项都默认交由对方处理
→ 信息流、资源入口和外部联系集中
→ 即使没有正式授权，事实权限逐步固化
→ x 上升
```

理论后果：必须证明授权不再只是可随时撤回的普通委托，而已经改变现实掌握边界。

### 候选 C：x 自行扩张，nx 只是未阻止

```text
x 主体主动接管、要求或收拢
→ nx 主体没有抵抗
→ x 扩张完成
```

理论后果：若所有可靠案例都属于此类，`nx` 只是缺少阻力，不构成独立“生”机制。

### 候选 D：xn 或职位结构集中权限

流程、职位、法律或组织规则把信息和决定集中到某人，随后另一方沿其安排行动。此时 x 的来源是制度、职位或 xn 结构，不是 nx。

## 7. 正例核验

### 正例候选一：《穿普拉达的女王》安迪与米兰达，中段工作关系

- nx：安迪持续放弃对私人时间、任务优先级和拒绝边界的认领；
- x：米兰达对其全天时间、通讯、私人关系和资源使用的控制范围扩大。

未通过原因：米兰达持续主动要求和施压，职位 x、zx 压迫与 xn 工作结构均为强第三因素；拿掉米兰达主动扩张后，控制是否仍自然增长不清楚。

### 正例候选二：《长日将尽》史蒂文斯与达林顿勋爵，管家生涯阶段

- nx：史蒂文斯长期不把私人判断、情感和人生方向放在最终决定位置；
- x：主人意志进入其时间、劳动、公开表达和私人生活范围。

未通过原因：管家职位、阶级秩序和职业 xn 已经提供广泛掌握结构；难以证明超出职位边界的 x 主要由史蒂文斯的 nx 生成。

### 纯结构候选：成年子女长期让父母代决

成年子女法律上拥有账户、居住、职业和材料决定权，却持续不查看、不决定、不联系机构；父母起初仅建议，后逐渐掌握账户、日程、租房和对外沟通。

支持点：可以拿掉威胁与职位，直接观察“空位是否被事实掌握吸纳”。

不足：仍缺少可核验的具体人物文本与明确跨阶段材料，不能独自承担正式锁定。

## 8. 反例

1. 一次临时委托，对方处理完即归还权限：只有授权状态。
2. 老板凭职位扩大管理范围：x 来源是职位。
3. 家长以断供或威胁强迫接管：更接近 x、zx 或 xz 压力。
4. 流程把审批集中到负责人：主要是 xn。
5. 主体法律上本来无权决定：不存在“本可认领却空出”的 nx 源端点。
6. 对方掌握更多只是因为能力更强、效率更高：工具性分工，不等于生位。
7. nx 主体仍保留并频繁使用最终否决权：x 未真正扩大。
8. 对方只是替忙，没有获得信息、资源或外部接口：目标端点不足。

## 9. 最近邻排除

### 与 x 克 nx

若既有掌握者先收紧资源、权限和退出边界，迫使另一方沿其安排推进，方向是 `x 克 nx` 或 x 对 nx 的压制，不是 `nx 生 x`。

### 与 zx 对 nx 的压退

公开命令、威胁、强势决定和现实位置重排，源端点属于 zx；nx 的退后是结果。

### 与 xn

信息、流程、审批和排程集中若由组织设计产生，改变的是运行结构；只有集中最终落到“归谁掌握”，且由 nx 持续空位触发，才可能进入本关系。

### 与普通授权

可随时撤回、边界清楚、没有跨阶段事实固化的代办，不是 x 增长。

## 10. 拿掉测试

1. 拿掉 nx 主体持续不认领方向后，x 是否仍凭职位、威胁、流程或个人欲望扩张？若是，则不依赖 nx。
2. 拿掉 x 主体主动施压后，控制边界是否仍因持续空位而增长？当前具体案例不能稳定证明。
3. 拿掉职位和法律赋权后，事实权限是否仍集中？当前只有结构候选支持。
4. 恢复 nx 主体的否决和方向认领后，x 扩张是否停止或回退？作品候选缺少清晰对照。
5. 若只是对方承担更多工作而无控制边界变化，则目标端点不存在。

## 11. 反向测试

交换为 `x 生 nx`：

```text
x 主体掌握资源、权限和出口
→ 另一方必须沿其通道推进
→ nx 上升
```

反向在许多控制关系中更容易成立。必须防止把“x 先掌握、nx 后服从”的案例倒写成 `nx 生 x`。

## 12. 动态链后果

若候选 A 成立，感觉走向是：

```text
我一次次不决定
→ 你一次次替我决定
→ 别人也开始只找你决定
→ 原本属于我们共同或属于我的范围
→ 逐渐成为你实际掌握的范围
```

改变的是**决定空位怎样沉淀为事实掌握边界**。

它不机械生成：控制欲、反派人格、法定所有权、公开压迫、永久依赖或必然的 zx 扩权。

## 13. 三元与十元并行

三元只核验作品整体精神运动。

十元本轮只核验：

- nx 是否真实持续不占本可认领的方向位置；
- x 是否真实新增掌握对象和权限；
- x 的增长是否来自 nx 空位，而非职位、流程、威胁或主动扩张；
- 改变发生在关系层、状态层还是稳定人物本体。

不建立 nx 与 x 的父子派生，也不从因果主题自动推出本体主题。
