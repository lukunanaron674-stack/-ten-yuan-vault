# 刘姥姥一进荣国府｜首份纯 x 控制

## 1｜本轮问题

只测试一个窄对象层：

> 王熙凤交付的二十两银子与一吊钱，是否真实进入刘姥姥“归我掌握”的处分边界？在这一对象层，是否需要额外假设 zn 才能解释？

不判刘姥姥稳定人物本体，不从贫穷、亲戚身份、感恩、善恶或后续报恩倒推十元。

## 2｜剧情事实

《红楼梦》第6回中，刘姥姥为解决家中冬事不足进入荣国府求助。王熙凤明确让平儿把二十两银子与一吊钱交到刘姥姥跟前，说明二十两可给孩子做冬衣，一吊钱可雇车。刘姥姥随后“拿了银子钱”离开。

更关键的处分证据是：离开凤姐处后，刘姥姥主动提出要留一块银子给周瑞家的孩子买果子；周瑞家的拒绝接受。这个动作表明交付后的银钱已经不是刘姥姥只能代持、只能原样转交、必须逐次请示的对象，她实际尝试自行处分其中一部分。

公开文本来源：
- https://zh.wikisource.org/zh/紅樓夢/第006回
- https://ctext.org/hongloumeng/ch6/zhs

## 3｜x 证据

被测对象：王熙凤交付的二十两银子与一吊钱。

掌握主体：刘姥姥。

实际权限：

```text
王熙凤/平儿完成交付
→ 刘姥姥实际拿走
→ 可用于家中冬衣/交通
→ 又主动尝试处分其中一块给周瑞家孩子
→ 不需要回凤姐处逐次批准
→ 当前银钱进入刘姥姥实际占有、使用与处分边界
= x
```

这符合 current x canonical：对象明确、主体明确、实际占有/使用/处分能力明确，不是只有头衔、一次接触或视觉持有。

### x 六项检查

- object_layer：99｜对象是已完成交付的银钱。
- endpoint_fit：99｜占有与处分直接命中“归我掌握”。
- neighbor_exclusion：98｜已排除 nx/代理持有/临时接触。
- evidence_independence：99｜文本有“拿走 + 尝试再处分”双证据。
- removal_reverse：98｜拿掉实际处分权，只剩代持或受限用途，案例核心会改变。
- cross_context：98｜赠与完成后即使不依赖荣府身份展示，掌握关系仍可成立。

最小值：98。

## 4｜zn 证据

本窄银钱对象层不锁 zn。

文本当然存在“帮女儿女婿过冬”“为家里想办法”等动机，但这不足以通过 zn 六道门：

- 没有清楚锁定一项不可轻易让渡的内部原则命题；
- 没有看到该原则在与现实利益冲突时拥有最终排序资格；
- 没有证明无外部认可/亲属关系/当前经济压力时仍保留未来指导资格；
- “把钱用于家庭”在本桥段主要是现实用途，不足以自动升级成精神核心。

所以本轮只记：

```text
x：成立
zn：证据不足，不成立为当前主判
```

这里的“纯 x”只指当前火轴被测对象层：x 独立过门，而 zn 没有独立过门；不等于刘姥姥整个人物在所有阶段都是纯 x。

## 5｜最近邻排除

### x vs nx

受赠以前，银钱确实在凤姐一侧；但完成交付后，当前对象已经进入刘姥姥直接占有/处分边界。不能因为资源“历史上来自别人”就永久追挂 nx。

### x vs xn

怎样进荣府、找周瑞家的、如何开口求助有 xn 邻近，但不回答交付后的银钱归谁掌握。

### x vs zx

刘姥姥没有因为拿到银钱而公开扩张决定范围或凌驾他人。取得与处分资源已经足够解释本对象层，不需要 zx。

### x vs z

凤姐的接济与亲戚关系有外部认可/关系意味，但“钱已经归谁实际掌握”仍是独立的 x 问题。

### x vs x并z

没有必要依靠公共身份壳、牌照或制度识别来维持该银钱的当前处分权；本轮优先 x。

## 6｜拿掉测试

拿掉“实际掌握/处分”这一 x：

```text
若刘姥姥只能替凤姐代持
或每一笔用途都必须重新请示
或不能把任何部分转给第三人
```

则本例不再符合当前文本中“拿走并尝试自行处分一块银子”的事实，案例核心明显改变。

因此 x 是必要解释。

## 7｜反向测试

若剧情改成：

```text
凤姐把银子暂交刘姥姥保管
→ 规定不得改用途
→ 随时可撤回
→ 刘姥姥不能自行给第三人
```

则应重新检查 nx / 代理授权 / 临时持有，而不能锁稳定 x。

原著没有这些限制性证据。

## 8｜第三因素冻结

冻结：

- 刘姥姥贫穷形象；
- 凤姐慷慨与否；
- 贾府富贵程度；
- 亲戚关系真假；
- 后续刘姥姥报恩；
- 道德评价。

只保留：

```text
对象是否完成交付？
主体是否实际拿走？
能否使用/处分？
是否需要原节点逐次批准？
```

x 结论不变。

## 9｜本轮火轴价值

这是当前火轴第一份“纯 x”高纯控制：

> **资源一旦完成真实交付，并进入主体可直接占有、使用、处分的边界，即使资源来源于外部，也可以在当前对象层锁 x。历史来源不能永久覆盖当前归属。**

同时形成一条防误判纪律：

> **现实用途/家庭需求 ≠ 自动 zn。**

必须另证不可让渡原则、冲突排序与未来指导资格。
