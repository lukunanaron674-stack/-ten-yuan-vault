# 关羽华容道｜只改一个关键终局节点，是否已经等于 xn 方案重设？

## 1｜本轮问题

现有待审议已经形成两端控制：

```text
执行层微调
→ 不足以锁 xn

替换关键节点 / 资源 / 协同接口 / 成功条件 / 最终处置路径
→ xn 证据上升
```

但仍有一个危险灰区：

> 如果主体只改了一个非常关键的节点，尤其是最终处置节点，而其余资源、路线、组织与协同结构都没有重建，是否已经足以判 xn？

本轮用关羽华容道做最小压力测试。

## 2｜剧情事实

诸葛亮已给关羽明确任务：率军埋伏华容道，曹操到来后不得容情，并以军令状约束执行。

关羽实际到达指定位置、带指定兵力等待曹操，说明前段部署骨架并未被他重写。

曹操到来后，关羽仍清楚自己奉军令在此；但在真正最终执行点，他因旧恩与张辽故旧之情，没有完成截杀/擒拿，而是让军士四散摆开并实际放曹操通过。

关羽随后回营承认结果并请死。

因此最小事实结构是：

```text
外部任务与部署骨架存在
+ 主体前段进入并执行该部署
+ 到最终处置节点时使用自身否决
+ 把“截杀/擒拿”改成“放行”
+ 其余路线、兵力、协同、埋伏节点没有被重新设计
```

## 3｜nx 判断

在“曹操最终放不放”这个对象层，nx 排除。

原因不是关羽有没有主动动作，而是：

```text
外部最终要求：不得容情
↓
真实执行窗口出现
↓
主体没有沿该终点完成
↓
主体实际使用否决并承担后果
```

所以：

`nx_in_final_execution_decision_layer: rejected`

但这不能倒推出整个前段部署从头到尾都不是 nx。关羽在到达华容道、按指定位置和兵力设伏等环节仍在执行外部方案。

本轮只锁：**最终处置节点退出 nx。**

## 4｜xn 判断

本轮最关键结论：

> **“改了一个关键节点”本身还不足以自动锁 xn。**

关羽确实改变了一个高度决定性的节点：曹操最终处置结果。

但他没有：

- 重设埋伏位置；
- 重配兵力；
- 新建协同接口；
- 改造前段诱导路径；
- 新建替代流程；
- 重新组织后续持续运行结构。

他的核心动作更接近：

> **在既有流程的终局裁定点使用一次否决。**

这和“主动搭流程、设节点、分资源、重组运行方式”的 xn 不同。

因此：

`xn_key_scheme_rewrite: rejected_as_primary`

## 5｜zx 判断

强烈违令、改变曹操生死结果、造成巨大后果，都不等于 zx。

关羽没有因为放曹操而：

- 获得更高军令权；
- 取得以后可以稳定改写诸葛亮部署的权限；
- 让刘备集团围绕新增关羽裁决接口运行；
- 扩大常态决定范围。

事后他仍回到军法追责结构中。

因此：

`zx_in_narrow_stage: rejected_as_primary`

## 6｜关键压力

压力来自：

```text
明确军令
+ 军令状
+ 曹操旧恩
+ 最终处置窗口只能当场作出
```

压力使关羽的否决资格显影，但不能把否决本身偷换成 xn 或 zx。

## 7｜拿掉测试

### 拿掉关羽的旧恩动机

只保留“主体在最终执行点否定外部处置要求”，nx 最终执行层仍下降。

### 拿掉最终处置节点的否决

如果关羽按军令完成截杀/擒拿，则前段方案继续按原骨架运行，当前行为更接近 nx 执行。

### 拿掉前段外部部署

如果关羽从位置、兵力、路线、协同到最终处置全部自行设计，则才应重新检查更强 xn。

### 拿掉军令状

只要外部最终要求仍明确、关羽仍实际否决，当前 nx 最终执行层仍排除；军令状只提高违令成本。

## 8｜反向测试

### 反向为真正 xn 单节点重设

如果主体改变的虽然只有一个节点，但该节点同时迫使：

```text
后续资源重配
+ 协同关系改变
+ 成功条件改变
+ 原流程无法继续按旧结构运行
```

则一个节点也可能足以触发 xn 上升。

因此判断重点不是“改了几个节点”，而是：

> **这个节点改动是否造成运行结构重组。**

### 反向为 nx

如果关羽即使私人判断不同，仍按军令完成最终截杀/擒拿，且不重设流程，则 nx 当前行为明显上升。

### 反向为 zx

只有关羽通过此事取得此前没有的、更高且可持续调用的军令裁决范围，才检查 zx。

## 9｜最近邻排除

### nx vs xn

```text
nx：沿外部既有运行骨架继续。
xn：主动重组运行结构。
```

关羽本轮不是重组结构，而是在终局节点否决。

### xn vs x / z

一次最终裁定或否决，不自动等于 xn。若主体是在已有裁定权限内直接拍板，更应检查 x / z 等对象，而不是因为“节点很关键”就判 xn。

### xn vs nz

关羽放曹的动机与旧恩、故旧明显相关，nz 是强邻近动机；但关系动机不回答运行结构有没有被重设。

## 10｜第三因素冻结

冻结：

- 关羽忠义评价；
- 曹操历史命运；
- 赤壁胜负；
- 诸葛亮是否预料关羽会放曹；
- 军令状最后是否真执行死刑；
- 关羽武力。

只保留：

```text
原方案骨架是什么？
主体改了哪个节点？
这个改动有没有迫使运行结构重组？
主体是否取得更高权限？
```

结论不变。

## 11｜本轮新增边界

本轮支持把“xn最低强化证据”进一步细化为：

```text
替换一个关键节点
≠ 自动 xn

关键节点被替换
+ 该改动迫使资源 / 协同 / 成功条件 / 后续流程发生结构性重组
→ xn 才显著上升
```

尤其：

> **终局否决 / 一次最终处置改判，本身可能只是裁定或否决，不等于流程重构。**

所以现有待审议中的“替换关键节点”不能脱离“让旧方案在关键结构上无法原样运行”这一后半句单独使用。
