# 刘备携民渡江｜第三因素替代假 x 的伪共现压力测试

## 1｜本轮只测什么

本轮不重复证明刘备 pure `zn`。已有同阶段 99/96 记录已经锁定：追兵逼近、撤退速度明显下降、诸将与简雍多次建议弃民时，刘备仍坚持不能为了自身脱险主动抛弃已经自愿相随、把现实安危托付给自己的百姓。

本轮只测试一个更窄的问题：

> 百姓大量跟随刘备、接受其组织渡河与保护，看起来很像“百姓进入刘备掌握边界”；这个表面 `x` 是否真的需要 `x` 才能解释，还是存在一个不含 `x` 的第三因素已经足够解释同一结果？

## 2｜剧情事实

《三国演义》第41回中：

- 刘备面对曹军逼近准备撤离；
- 孔明提出遍告百姓，愿随者同去，不愿者留下；
- 大量百姓自行选择随刘备撤离；
- 刘备与部属组织船只、渡河、路线与保护；
- 大量百姓因此与刘备军共同移动，且撤退速度被显著拖慢；
- 诸将和简雍先后建议先弃百姓，刘备连续拒绝；
- 长坂追击最终真实发生，说明责任原则承受了现实成本。

这些事实足以证明“自愿跟随 + 战时共同路线/保护协同”真实存在。

## 3｜zn 端沿用既有锁定

被测原则仍是：

> 已经自愿相随并形成现实托付关系的百姓，不能在主体为了提高自身脱险概率时被主动抛弃。

该原则在更快撤退、更高生存概率与现实追兵压力下仍进入冲突排序，且不依赖封赏、称号或后世评价，因此本轮沿用既有 `zn=true`，不重复增加 pure-zn positive 统计。

## 4｜表面 x 为什么容易误判

如果只看结果，很容易写成：

```text
百姓大量随刘备移动
+ 刘备安排渡河与保护
+ 百姓听从整体撤退路线
→ 百姓归刘备掌握
→ x
```

这一步不成立。

current `x` 要求被测对象真实进入主体稳定的占有、调用、调配、处分、否决或排除边界。原著反而给出一个关键反证：百姓是否同行由其自己选择，刘备明确允许“愿随者同去，不愿者留下”。

因此，刘备能组织共同路线与保护，并不能自动推出他拥有这些百姓本人的稳定去留、归属或处分权。

## 5｜第三因素替代测试

本轮第三因素是：

> **百姓自己的自愿选择 + 战时共同路线/保护协同。**

把“百姓归刘备掌握”的 `x` 假设拿掉，只保留：

```text
百姓自主选择跟随
+
刘备军提供共同撤离路线、船只和保护
+
双方在同一危险环境中协同行动
```

就已经足以解释：

- 为什么百姓会跟随刘备移动；
- 为什么刘备可以安排渡河和保护；
- 为什么双方表现出强关系与共同路线；
- 为什么刘备会承担“不弃民”的责任原则。

因此，表面上像 `x` 的“跟随 / 协同 / 保护”结果，并不需要假设百姓进入刘备的现实掌握边界。

这满足 P5 的高信息增益条件：第三因素能够替代伪 `x` 对观察结果的解释。

## 6｜反向测试

如果百姓真的进入稳定 `x`，至少应看到同一对象层出现更强证据，例如：

- 刘备可以不顾百姓意愿稳定决定其去留；
- 可以把百姓转交、调配、分配或排除；
- 百姓退出与归属主要由刘备处分决定，而不是其自主选择；
- 同类决定无需重新取得百姓自己的同意或自愿响应。

原著当前桥段没有这些证据，反而明确保留百姓自己的选择权。

所以本轮不是“`x` 证据比较弱”，而是：

> **同一可观察结果已经有一个不含 `x` 的第三因素解释，且文本还给出与稳定掌握相冲突的自主选择证据。**

## 7｜最近邻排除

- `zn vs z`：刘备原则的硬证据发生在军事不利和现实危险中，不依赖百姓赞誉。
- `zn vs xn`：船只、路线、断后与保护回答“怎么撤”，不能替代“不为自身脱险弃民”的原则。
- `x vs 组织协同`：能安排共同路线，不等于能处分参与者本人。
- `x vs 责任关系`：对他人承担责任，不等于他人归主体掌握。
- `x vs 自愿跟随`：他人自主选择持续跟随，不能倒写成主体对其拥有稳定处分权。

## 8｜第三因素冻结的严格版本

为了防止把“第三因素”变成万能逃生口，本轮只冻结一个变量：

```text
假设没有“百姓归刘备 x”
但保留百姓自主选择 + 战时共同路线/保护协同
```

若主要观察结果仍然成立，则被测 `x` 不是解释该结果的必要条件。

反过来，如果拿掉百姓自愿选择与共同协同，只靠“刘备有责任原则”就无法解释十余万百姓为何实际同行；所以第三因素不是随意添加，而是原著明确存在的独立因果来源。

```text

```

本轮新增的不是第四个换皮“zn 真 + 假 x”，而是第一次把**第三因素替代测试**明确写成伪共现护栏。
