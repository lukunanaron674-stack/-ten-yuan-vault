# 待审议问题

现行 nx 核心口径强调：方向、权限或解决通道已经存在，主体不占最终决定位置，并沿外部安排、关系网络或既有秩序推进。

连续三部独立作品暴露出同一个未压实边界：

> 如果外部主体只提供一个关键事实、情报或条件，而主体仍自行形成方案、节点与行动，是否应将该信息节点计入 nx 的“外部解决通道”？

# 三个独立作品

## 1. 三国演义｜曹操官渡接许攸情报
- 许攸提供乌巢粮草等关键敌情。
- 曹操已有进攻意向，最终判断、军令和执行权仍在曹操。
- 状态：candidate/deferred。
- 最小分歧：关键信息输入是否足以成立有限 nx 关系功能。

## 2. 西游记｜孙悟空狮驼岭听长庚示警
- 长庚提供妖魔危险事实。
- 孙悟空自行决定侦察、变化、接近和盘问。
- 状态：candidate/deferred。
- 最小分歧：事实信息源是否属于 nx 外部解决通道。

## 3. 水浒传｜吴用智取生辰纲
- 公孙胜提供生辰纲路线，晁盖提供白胜这一可用条件。
- 吴用自行组织圈套、地点、角色和取纲方式。
- 状态：candidate/deferred。
- 最小分歧：外部条件源是否足以成立 nx，还是应优先视为 xn 的输入材料。

# 反向高纯控制

## 1. 三国演义｜关羽刮骨疗毒
- 关羽中毒箭后毒已入骨，右臂青肿不能运动。
- 华佗不仅提供“这是乌头毒”这一事实判断，还掌握并实际执行割开、刮毒、敷药、缝合这一专业处理能力。
- 关羽真实接入该专业解决接口，且同一个右臂毒伤瓶颈被直接修复。
- 状态：evidence-locked，事实99 / 分类98。
- 结论：`external_professional_solution_interface: evidence-locked`；`external_information_only: false`。

## 2. 红楼梦｜晴雯病补雀金裘
- 雀金裘烧破后，当前问题是让同一件衣裘恢复到可穿状态。
- 晴雯不仅判断“可用孔雀金线按界线法补”，而且在场人物明确指出当前只有她会该织补技法。
- 晴雯亲自拆里、固定破口、分经纬、依原纹织补并整理绒毛，最终把同一件雀金裘补到基本看不出破绽。
- 状态：evidence-locked，事实99 / 分类98。
- 结论：`external_professional_solution_interface: evidence-locked`；`same_problem_directly_repaired_by_external_interface: true`。

## 3. 西游记｜孙悟空黄眉怪遇弥勒
- 孙悟空此前已连续调用多个外援，但黄眉的人种袋仍使解决链无法闭环。
- 弥勒不仅告诉孙悟空“黄眉是谁”，还掌握黄眉与人种袋、敲磬槌的真实主仆/权属处分接口。
- 弥勒直接给出完整诱敌方案，并用掌上“禁”字处理人种袋这一执行障碍。
- 黄眉受制后向弥勒称主人公求饶，弥勒亲自取回宝物并最终带走黄眉。
- 状态：evidence-locked，事实99 / 分类98。
- 结论：`nx_relation_function_stage: evidence-locked`；本例不是仅信息输入，而是完整方案 + 关键法术/资源处分 + 最终主仆处置接口共同外置。

三个高纯反向控制共同说明：

```text
外部事实 / 情报输入
≠ 自动 nx 解决通道

但若外部节点掌握主体当前缺失的真实解决接口，
且主体实际接入，
并且该接口直接改变当前同一个现实瓶颈，
→ nx 关系功能显著增强并可高纯成立。
```

这里的“真实解决接口”目前已经跨三种形态得到高纯控制：

```text
专业治疗能力（华佗）
专业修复能力（晴雯）
完整方案 + 关键法术/资源处分 + 最终主仆处置权（弥勒）
```

# 纯许可接口高纯控制

## 1. 西游记｜唐僧女儿国倒换关文
- 唐僧师徒已经持有西行方向与行动结构，孙悟空甚至另有取得关文的策略。
- 女王几乎不负责设计“怎样西行”或“怎样离境”的完整方案。
- 真正不可替代的外部节点是西梁女国对通关文牒的国家确认权：女王亲自添注三徒姓名、盖御印并画花押。
- 唐僧实际请求倒换关文，官方文书结果由女王这一许可节点直接使之生效。
- 状态：evidence-locked，事实99 / 分类98。
- 结论：`nx_permission_relation_function: evidence-locked`；`external_complete_solution_scheme: false`；`same_problem_directly_unlocked_by_permission: true`。

## 2. 红楼梦｜贾芸谋差事
- 贾芸自己的目标很明确：在荣府谋得一个园内工程差事，并不存在“最终目标由凤姐替他形成”的问题。
- 贾芸先求贾琏未能办成，随后转向真正掌握园内派差权限的凤姐；他没有自行取得或夺取派差权。
- 凤姐并非形式盖章：她先表现出暂缓/拒绝当前种花木工程的真实选择，提出以后再派别项差事；贾芸继续请求后，凤姐才明确批准当前种花木差事。
- 批准随后通过领票、对牌、银库领银与进园监工流程真正落地；没有凤姐这一派差接口，贾芸不能单方面使“我得到这项荣府工程”成立。
- 凤姐并没有替贾芸设计具体种花木工程的全部执行方案；本轮关键是她拥有真实可拒绝、可拖延、可批准的派差/资源启用权限。
- 状态：evidence-locked，事实99 / 分类98（复用既有正式案例，不重复造文件）。
- 结论：`nx_relation_function_stage: evidence-locked`；本轮作为第二部纯许可/派差权限控制纳入。

两个许可控制共同支持：

> **纯许可型 nx 不要求许可方提供完整方案。真正检查的是：许可节点是否真实拥有可拒绝/附条件/拖延的否决能力，主体是否实际沿该接口取得许可，以及许可是否直接使当前制度/组织结果生效。**

本轮贾芸还提供了一个比女儿国更强的“真否决权”证据：凤姐在同一对话中先不立即批准当前工程，后经贾芸继续请求才放行，因此派差权不是形式盖章。

但必须保留限制：

> **“对方理论上有最终许可权”并不自动等于 nx；主体仍须在当前对象层实际接入并续接该许可接口。**

因此当前边界不应被误缩成“只有医生/手艺人式专业技能才算 nx”。真正变量更接近：

> **关键解决能力 / 许可 / 否决 / 处分接口是否真实外置，主体是否实际沿它推进，以及它是否直接处理当前同一现实问题。**

同时必须保持主体切面：专业提供者或权限提供者本人可以在其操作层出现 `x/xn`；这不否定需求方或当前问题侧存在 `nx` 外部解决接口。

# 当前最窄候选纪律

仅作为待审议候选，不进入 L1：

```text
外部事实/情报输入
≠ 自动等于 nx 解决通道

若外部主体只提供“我不知道的事实”，
而最终方向、方案组织、节点设计和行动接口仍由主体自己掌握，
则优先检查：信息输入 + xn/x 等最近邻，
不要仅凭“信息来自别人”锁 nx。

若外部主体提供的是：
- 必须沿用的完整解决方案；
- 关键许可或否决权；
- 必要资源处分权；
- 主体无法自行建立的专业解决接口；
- 对当前对象拥有不可替代的最终处分/权属接口；
并且主体实际沿该接口推进、同一现实问题被直接处理，
则 nx 关系功能证据显著增强。

其中，纯许可型接口不要求外部节点同时提供完整方案：
只要许可真实不可替代、主体实际接入、许可直接使同一制度/关系结果生效，
即可独立构成高强 nx 证据。

判断“真许可”时优先寻找：
- 许可方曾真实拒绝、拖延、附条件或改变批准结果；
- 主体不能绕过该节点自行让同一制度/组织结果生效；
- 批准后出现票据、印信、资源启用、正式职位/任务等可观察落地结果。
```

# 必须继续验证的问题

1. 信息是否只是事实输入，还是已经内含关键方案结构？
2. 拿掉信息提供者后，主体是否仍能自行建立解决方案，只是成本/不确定性上升？
3. 外部主体是否掌握许可、资源、否决权、权属处分或不可替代专业接口？
4. 主体取得信息后，是自行组织流程与节点，还是主要沿外部方案执行？
5. “信息缺口被补足”与“解决通道外置”是否应作为两个不同层级记录？
6. 专业接口是否必须由外部节点亲自执行决定性操作，还是提供不可替代方案并由主体执行也足够？
7. 同一专业接口中，需求方 `nx` 与提供者 `x/xn` 是否应固定采用双主体切面记录？
8. 纯许可型 nx 是否能在第三部独立作品复现，而不依赖完整方案、专业技能或资源转交？
9. 许可仅为形式性盖章、实际上从不具备真实否决能力时，是否应降级为弱 nx 或排除？
10. 完整方案、关键资源处分、最终权属/主仆处置三者中，哪些是可替代条件，哪些是高纯 nx 的独立充分证据？
11. 贾芸型“许可同时启用预算/票据资源”与女儿国型“国家印信确认”是否需要进一步拆成纯许可与许可+资源启动两个子型？

# 当前治理结论

- 触发三作品阈值，因此保持 pending-review。
- 三个原支持材料仍均不足95%分类把握，不能倒推为正式理论修改依据。
- 已有3个跨作品高纯反向控制：关羽刮骨疗毒（99/98）、晴雯病补雀金裘（99/98）、孙悟空黄眉怪遇弥勒（99/98）。
- 纯许可/派差权限型高纯控制现为2部：唐僧女儿国倒换关文（99/98）、贾芸谋差事（99/98）。
- 当前证据支持：真实许可/否决接口本身可以成为高纯 nx，不要求外部节点同时提供完整方案；贾芸案进一步证明许可方的真实拖延/拒绝能力可作为“非形式盖章”的强证据。
- 但纯许可型目前只有《西游记》《红楼梦》两部独立作品，尚不足以把这一子结论升级为准度层规则。
- 仍不修改 L1、zx/nx 信息卡、准度卡、zx补nx_补卡。
- 下一步优先寻找第三部“纯许可/否决接口”高纯控制，最好来自《三国演义》或《水浒传》，并优先要求许可节点曾真实拒绝、附条件或拖延，以证明否决权不是装饰。
