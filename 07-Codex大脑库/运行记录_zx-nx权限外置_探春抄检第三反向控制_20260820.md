# zx↔nx｜探春抄检第三反向控制｜权限外置不等于 nx 已激活

## 1｜本轮目的

复用仓库已有《红楼梦》第七十四回探春抄检大观园正式案例，不重复制造角色案例。专项检查当前已经在《三国演义》关羽过五关、《水浒传》武松飞云浦后形成的边界：

> 外部权限、命令或解决接口客观存在，是否足以自动判 nx？

结论：不足。现行 nx 还需要主体在被测试对象层实际承认并沿外部方向、关系、权限或流程推进。

## 2｜剧情事实

- 王夫人已经批准夜间抄检大观园，凤姐、王善保家的等人携真实上位授权进入秋爽斋。
- 探春没有否认“搜检任务存在”这一上位事实，反而主动开门、开箱，并要求把检查结果说清。
- 但她没有把本院局部边界完全交给搜检队：谁可以碰她本人、奴仆能否越界搜身、自己是否保留解释与否决资格，这些局部判断没有沿外部执行者既定方式续接。
- 王善保家的越界拉扯探春衣襟后，探春当场反击；凤姐、平儿等随即收束、解释并改变执行行为。

结果：外部授权真实存在，但探春在当前局部对象层没有形成“只沿外部安排推进”的 nx；相反，外部压力下 zx 当前状态重新高显影。

## 3｜zx 判断

zx 当前状态成立，但只锁当前状态、行为功能与关系位置。

证据链：

```text
外部权力进入本院
→ 探春局部位置被压成受查对象
→ 探春公开提出并承担自己的边界
→ 越界时直接否决
→ 搜检队实际改变行为
→ 主体局部决定位置恢复/上升
```

这符合 zx v2.3 / zx 准度卡 v0.1：自身权能公开进入现实、他者被迫回应、决定位置发生上升。不能简化为“打人所以 zx”。

## 4｜nx 判断

本轮最关键的是区分：

```text
外部授权存在
≠
主体沿外部授权方向推进
```

王夫人授权证明搜检队拥有真实外部权限，但 nx v2.5 还要求主体“不占最终方向，并沿别人、关系、流程或秩序给出的方向与通道推进”。

探春没有在“本院怎样查、奴仆能否搜身、自己是否保留否决资格”这一局部对象层把判断权交出去，因此：

`nx_in_local_search_boundary: rejected`

这不是说外部权力不存在，而是说该权力没有在这一对象层自动转化为探春的 nx 行为功能。

## 5｜关键压力

压力由四部分构成：王夫人批准、凤姐带队、王善保家的借陪房身份越界、夜间突击程序。

压力只负责压缩探春原局部位置，不直接判 nx。真正决定分类的是：探春面对外部方向以后，是否实际沿它交出局部决定资格。

## 6｜拿掉测试

### 拿掉“王夫人授权”

若没有真实上位授权，只剩普通人员私自搜检，案例仍可能有 zx 冲突，但不再适合作为“外部权限存在但 nx 未激活”的边界控制。

因此，外部权限存在是本控制的必要背景。

### 拿掉探春的局部否决与边界重设

若探春面对搜检：不设边界、不保留否决、对方怎样搜就怎样搜，即使她心里不愿意，当前 nx 会明显上升。

### 拿掉“一巴掌”

保留主动开箱、要求说明、拒绝奴仆搜身、迫使凤姐等调整方式，zx / 非 nx 的核心结构仍在；所以暴力动作不是支柱。

## 7｜反向测试

真 nx 版本：

```text
王夫人授权搜检
→ 探春接受执行者决定全部局部方式
→ 不保留否决与重设资格
→ 对方怎样查就怎样查
= nx 当前状态/行为上升
```

更纯 x 版本：

若搜检队从一开始就完全承认探春既有院内与身体处分边界，探春只正常调用已有权限，没有“受压后公开推回”的位置变化，则应优先检查 x，而不是 zx。

xn 版本：

若核心变成探春主动设计搜检名单、时间、流程、记录和节点，再以流程重组处理问题，才应提高 xn。

## 8｜最近邻排除

- `zx vs x`：不是单纯已有小姐身份，而是外部权力先压入，随后探春公开让对方重新围绕自己边界行动。
- `zx vs xn`：有预判，但没有持续流程组织成为主变量。
- `nx vs xn`：本轮不是“怎样组织搜检”，而是“是否沿外部方向交出局部判断资格”。
- `nx vs xz`：夜间突击和家内危险只是压力，不能替代方向权判断。
- `nx vs nz`：关系亲疏不能替代当前权限/通道是否被主体实际沿用。

## 9｜跨作品最小差异

### 《三国演义》关羽过五关

外部通关许可真实存在，并被明确告知；关羽拒绝等待审批并直接突破。结论：权限外置，但 nx 未激活。

### 《水浒传》武松飞云浦后

司法纠正节点仍存在；武松脱险后不进入申诉通道，改走直接复仇。结论：权限外置，但 nx 未激活。

### 《红楼梦》探春抄检

王夫人授权真实存在；探春承认上位搜检事实，却不把局部搜身/院内边界完全沿外部执行者交出。结论：权限外置，但当前局部 nx 未激活。

三部作品共同支持：

> **外部权限存在只能证明权限位置或压力来源；nx 行为/关系功能还必须看到主体在被测试对象层实际承认并沿该外部方向、权限、关系或流程推进。**

## 10｜第三因素冻结

冻结：人物身份高低、善恶、强弱、武力、是否合理、是否最终胜利、作品主题、传统人物评价。

只看：外部权限是否真实存在；主体是否实际沿该通道/方向推进；若不沿，当前结果由谁的作用权让其生效。

## 11｜结论

本轮达到第三部独立作品门槛。可靠边界为：

```text
外部权限存在
≠ nx 自动成立

外部权限存在
+ 主体实际承认并沿该权限/关系/流程推进
→ 才能进一步锁 nx 关系功能
```

建议形成待审议问题，但不得直接修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡。
