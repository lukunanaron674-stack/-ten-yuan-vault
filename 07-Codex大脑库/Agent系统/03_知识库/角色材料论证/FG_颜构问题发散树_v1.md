# 颜构｜键盘三排字母问题树 v3.0

> 74指定：**第一排 QWERTYUIOP=主问题；第二排 asdfghjkl=子问题；第三排 zxcvbnm=子子问题。** 使用键盘横向顺序，不使用 ABC 字母顺序。旧 QWE→Qq→QqwN 是误解后的历史版本，不再使用。

## 一｜唯一编号规则

| 问题层 | 键盘顺序（严格） | 编码方式 | 例子 |
|---|---|---|---|
| 主问题 | `Q W E R T Y U I O P` | 取第一排一个大写字母 | `Q`、`W`、`E`、`R` |
| 子问题 | `a s d f g h j k l` | 父级主问题+第二排一个小写字母 | `Qa`、`Qs`、`Qd`、`Qf` |
| 子子问题 | `z x c v b n m` | 完整子问题+第三排一个小写字母 | `Qaz`、`Qax`、`Qac` |

- 同父节点的兄弟问题按所属键盘排从左至右使用下一个字母；进入新父节点后从该排第一个字母重新开始，**不跨父节点累计**。
- 前缀必须是实际的父节点：`Qaz`的父节点是`Qa`，`Qa`的父节点是`Q`；`Waz`的父节点是`Wa`。
- 本分支目前占用 Q、W、E、R 四个主问题，剩下 T/Y/U/I/O/P 保留给将来新增主问题（不得为了填满键位造新问题）。
- 同一子问题允许继续追加三级兄弟：`Qaz → Qax → Qac → Qav → Qab → Qan → Qam`（这些互为兄弟，箭头仅表示编号顺序，不是因果关系）。
- 超出一排容量后需另行设计扩展编号协议，不擅自复用已占用 ID。编号是研究树显示口径，不自动构成正式缺陷 Q。
- 人物五官与十元关系仅是造型实验假说，非现实相貌推断人格的规律。所有叶问题目前状态 `H/TEST_PENDING`。
