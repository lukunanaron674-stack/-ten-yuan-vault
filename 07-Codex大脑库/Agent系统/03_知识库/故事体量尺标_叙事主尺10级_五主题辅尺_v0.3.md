# 故事体量尺标 v0.3｜叙事层级1–10【主】＋五大主题体量【辅】

## 0. USER修正与优先级

USER指出：「1-10」「之前那个权重大，这个其次」，指**原先“个人到世界”的叙事层级分类是主尺**，五大主题（时间、本体、空间、因果、命运）单独作为第二层的体量描述/评分；不再用五维分数替代叙事对象层级，也不以艺术质量或百分制排序。

此前V0.1的0–100合成评分以及V0.2「五主题×五级」均不满足当前要求，保留作为历史失败版本，**不再用于当前分级**。曾有十元在场强度1–10与五维评分历史资料，但目前尚未检索到个人→宇宙的十级旧正本逐条原文。以下是沿用用户已确认的八级主要对象分类方向，把顶层世界/宇宙细分为10级的**临时提案**，不是声称旧正本完全恢复。

原则：主尺判定优先于次尺评分；在无USER确认数字配比前，不擅自使用70:30等公式把序数层级混加。五主题逐轴等级是**各主题影响/涉及对象的范围**，不是该主题在电影中的强弱得分；对未结构性显影或只有背景者写「—」或标注「背景」。

## 1. 一级主尺 L1–L10：电影到底在讲什么层级

| 主尺 | 叙事级别 | 核心冲突/结算对象 |
|---|---|---|
| L1 | 个人 | 单人的存在、人生选择与去向 |
| L2 | 人际 | 两个人或少数几个人的关系/命运 |
| L3 | 家庭/代际 | 家庭、血缘、数代的延续 |
| L4 | 组织/群体 | 机构、集体、阶层、组织规则 |
| L5 | 城镇/地区 | 一座城市/地区及其居民 |
| L6 | 国家/历史 | 国家社会秩序、战争/历史进程 |
| L7 | 人类文明 | 人类生存、文明连续性与重建 |
| L8 | 星球/世界 | 世界整体存续或行星级秩序 |
| L9 | 多世界/星际 | 多个世界、星系及跨文明作用 |
| L10 | 宇宙/根本法则 | 宇宙存在本身，时间/因果/命运规律被改写 |

**主尺填写**：`CORE_LEVEL`＝电影真正讲述的主冲突对象；`BACKDROP_LEVEL`＝宏大的背景/舞台；`CONSEQUENCE_LEVEL`＝结局确实改变的对象范围。双核结构记`L3+L7`，扩张记`L2→L5`，而不是强迫只取最高数。

## 2. 二级辅尺：五维故事体量 1–10

五主题符号：T时间（XN+Z）；O本体（ZN+X）；S空间（X并Z+N）；C因果（ZX+NX）；F命运（XZ+NZ）。五个轴**不是五大主题的艺术评分，也不自动决定影片的主主题**。

- **T时间体量**：T1瞬间、T2一天/数天、T3数月/约一年、T4数年或数十年、T5一生、T6跨代、T7百年、T8千年、T9地质/宇宙纪元、T10世界时间规律或多时间线整体运行被重构。备注：时长与“闭环/重置/倒流”机制需**并列标注**，不把一日循环错算成跨千年。
- **O本体体量**：按被追问存在核心的对象分级，个人→两人关系→家庭→组织→城市→国家→文明→世界→多世界→存在根本。
- **S空间体量**：按有实际容纳/隔绝/跨越作用的场域分级，个人空间→人际共享场域→家庭→机构→城市→国家→文明生存场域→星球→星际/多世界→宇宙全域；仅作布景者标`(背景)`，不得冒充主作用。
- **C因果体量**：按事件造成并需叙事结算的责任/后果波及层级，从个人到宇宙。
- **F命运体量**：按被开启、关闭、收束的未来对象层级，从个人到宇宙。

重要：T时间有时间自身的单位，不能等同O/S/C/F的受影响人数。各轴只分别报告，不跨轴数学平均。

### 对标校验
1. 《前目的地》L1，时间T5：复杂闭环是时间机制而非叙事主尺L10；其身份与宿命仍主要指向一个人。
2. 《超时空辉耀姬！》主尺L2、T8：八千年不会把双人情感自动变成文明命运。
3. 《钢琴家》主尺L1、S6(背景)：二战的国家级历史背景不能抬升主人公行动改变结果的规模。
4. 《你的名字。》L2→L5，T4：3年错时使两个人直接改变城镇的生存结局。
5. 《星际穿越》L3+L7、S9(舞台)：人类迁移是实际文明结果，不是只看见宇宙镜头。

上述T时间数值并不等于时间主题强度；例如T2循环型可能是全片的时间主主题，而T8跨千年也可能只是两人关系的压力。要判断五维主次，另读原电影卡。
