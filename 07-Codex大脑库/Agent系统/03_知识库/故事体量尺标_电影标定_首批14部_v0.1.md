# 电影故事体量尺标｜首批14部交叉标定（V0.1）

> 此文评的是**时间×命运双主题合成尺标**，不是电影好坏、叙事质量、美学成就、钧评分、十元本体体量或USER确认评级。所有数字均为本轮助手依据既有电影F1故事事件的【AI-H】工作假设，F2逐镜与F3观众评估皆未补，不冒充实证。旧USER主题判读一字不改。

## 计算方式
T时间0–20；F命运0–20；R人物选择影响范围0–15；I不可逆代价0–15；A人物能动性0–20；C双主题耦合0–10。

V0.1门槛：T<10/F<10/A<10/C<5 → 总成绩封顶59；T<15或F<15 → 封顶79；S5须总分≥80且T≥15/F≥15/A≥15/I≥10/C≥8，缺项时至多79；S6另外需改变时间/命运规则，不只是利用它。

**关键口径**：R只统计“主角行动确实改变的外部去向”，不是战争背景/宇宙布景有多大。年代跨度主要记T；人类规模的实际后果才记R。

## 校准问题与V0.2候选纠错（不自动更改V0.1）

**主要发现：V0.1把“时间×命运在叙事中的强度”和“对多少人/文明产生后果”合成了一个0–100总分，但R仅占15分；因此《前目的地》（个人身份闭环，82）、《千年女优》（一生，80）会与《星际穿越》（文明生存，93）同被标成S5。这是标尺设计缺陷，不意味着它们同样宏大。**

建议拆出**两张正交尺标**：
1. **内部双主题深度 D**（T、F、I、A、C；范围0–85，转换为百分比或只用原值，先标研究）；回答“时间与命运对人物选择有多大决定性”。
2. **外部改变范围 E**（R及其可观察作用对象，独立记“个人/群体城镇/国家历史/文明/宇宙规则”）；回答“人物选择实际改变多少人的哪条可能未来”，不能只凭布景级别。

新增**宏大S5的候选上限门禁**：在旧≥80、T/F/A/C条件之外，建议加入`R≥12`并有独立文明级变化事件；则本批仅《星际穿越》具备相对明确的文明后果（仍属候选分数），而《你的名字》为高双主题强度／城镇影响，不降低其电影价值。今后需要先由USER审尺，再考虑是否正式改V0.1。

**跨样本的创作启示**：
- 《你的名字》提供双人物双轴关系＋错时救援，F/T强而R为城镇级。
- 《前目的地》提供个人时间闭环的极深结构，不提供大规模文明结局。
- 《千年女优》提供一生精神强度，不提供文明改写。
- 《星际穿越》把时间不可逆代价、亲子选择与人类未来联结，最接近74要求的双大主题＋大故事影响范围。
- 《钢琴家》说明“历史背景巨大”≠“主角能改写历史”；本片R不能按二战的全世界规模直接给15。
- 《罗生门》《楚门的世界》《千与千寻》在本尺上低分主要因为本尺只检验时间×命运，不能推断其它主题叙事弱。
