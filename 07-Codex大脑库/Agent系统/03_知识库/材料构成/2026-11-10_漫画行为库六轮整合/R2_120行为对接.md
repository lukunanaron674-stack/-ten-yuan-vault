# R2｜120条行为接入材料构成

**机器正本**：[[R2_120行为接口索引.jsonl]]；120条，每条保留B码（`B-A01`～`B-L10`）、原动作、对象、叙事功能、可能代价、旧来源。

| 来源字段 | 输出字段 | 解释 |
|---|---|---|
| A01 | B-A01 | 跨库唯一引用码；不同于C01行为链 |
| 行为名 | behavior | 仅是动作或叙事意图，不等于十元本体 |
| 直接对象 | direct_object | 等待真实人物和对象状态具体化 |
| 叙事功能 | narrative_function | 作者设定的用途，不是现实证明 |
| 常见代价 | possible_cost | 可选代价，不能自动写为实际后果 |
| 十元与主观感受 | tenyuan=null | 没有真人反馈时禁止填成已证实 |

**AG-16接口**：用户指定具体疑问后先查B码和现存SBR卡，补外部来源、人物、时点、制度、上下文，出`RAW_MATERIAL_PACKET_V1`；没有真实事例就标创作模板。

**AG-17接口**：`主体→对象状态→触发→动作→对方独立回应→改变变量→代价→反例→十元感受候选H`。任何一步缺证据必须null或H，不能靠模板名字补全。

**结果**：字段映射120/120 PASS；真实案例补证0；未部署本地代理，不宣称生产引擎自动运行。
