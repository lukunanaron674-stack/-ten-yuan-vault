# 宋江｜梁山身份封住直接合法回返窗口，但归顺/合法回返 zn 未退场，招安后按原方向复位｜第三文学作品 pressure-display 控制

## 1｜本轮只测试什么

P0 strict `zn↔x` 第一正例继续执行强门检查；当前仍没有候选能同时通过 `zn→x` 与 `x→zn` 的不可替代双向缺口，因此本轮不降低 strict 标准。

本轮只测试：

> **一项在压力前已经独立成立的 `zn`，当现实身份与政治位置使其最直接的行动路径暂时不可用时，是原则真的退出，还是只有最强现实行动窗口被封住；当该窗口重新打开后，同一原则是否按原内容复位？**

对象层限定：

```text
zn：不愿把“永久草寇化”视为最终政治/法理归属；即使现实被逐出旧秩序，也保留并追求合法回返、归顺与报国的未来资格
压力：江州劫法场后现实上进入梁山、成为被朝廷视为反叛集团的一员；无法靠普通个人回乡/服刑路径直接回到合法政治位置
解压：朝廷正式招安，合法回返/官方服务路径重新开放
```

本轮不锁宋江整体稳定人物本体。

## 2｜压力前：同一 zn 已经成立

《水浒传》120回本第36回，宋江面对官差时选择“挺身出官”，明确比较：继续躲在江湖，容易被卷入杀人放火的江湖网络；即使接受断配，也仍有期限，未来还能合法归来侍父。

随后梁山人马试图截取他上山，宋江拒绝被强行入伙，并以国家法度、忠孝和未来合法归返为理由，宁可按法赴江州。

因此在后来真正上梁山之前，已经存在可命名原则：

> **现实处境可以暂时恶化，但不能把永久草寇身份当成最终归属；合法回返资格应被保存。**

该原则不是第71回“想招安”后才倒填出来。

## 3｜压力进入：梁山位置封住的是直接行动窗口

江州劫法场以后，宋江被梁山等人救出，现实处境发生质变：

```text
个人受刑 / 服役 / 等限满
→ 原本仍存在“直接按官府路径回归”的个人窗口

劫法场后进入梁山
→ 被朝廷视为反叛集团成员
→ 普通个人合法回返路径现实关闭
```

关键是：

> **“现在不能直接以合法身份回去” ≠ “以后不再把合法回返/归顺作为最终方向”。**

若旧 `zn` 已经退出，那么后期梁山新权力形成后，最自然的结构应是永久固化山寨归属；原著却持续出现相反证据。

## 4｜压力中：未来指导资格仍保留

第71回，宋江已经是梁山现实领导者，拥有完全不同的新组织/军事 `x`，却公开祈求朝廷赦免，并在武松、李逵、鲁智深等人反对时继续主张招安、改邪归正、为国家臣子、同心报国。

这说明梁山身份并未把旧原则删除，而是出现：

```text
直接合法回返行动窗口 = blocked
zn future-guidance = retained
替代实现路径 = 争取招安
```

注意：本轮不把“争取招安”的具体联络与操作当作 `zn` 本身；那些更接近“怎么实现”的流程/关系手段。`zn` 只锁“最终政治/法理归属不永久停在草寇位置”。

## 5｜解压：第82回受招安后按原方向复位

第82回正式招安以后，原先被梁山反叛身份封住的合法政治行动窗口重新打开。

宋江等受诏后不再只是在梁山内部口头追求归顺，而是进入朝廷承认的官方行动链；后续征辽等阶段继续以国家军务身份行动。

所以时间链为：

```text
第36回：同一 zn 已成立
→ 江州劫法场 / 入梁山：直接合法回返窗口关闭
→ 第71回：压力中仍公开保留归顺/报国方向
→ 第82回：正式招安，合法行动窗口重新打开
→ 同一原则从“争取合法回返”转入“以合法身份实际服务”的现实表达
```

这里不是压力后新形成原则，而是原先已经存在的原则终于获得更直接的现实表达资格。

## 6｜zn 证据

本轮原则不写成“宋江凡官府命令都服从”，因为私放晁盖、杀惜、领导梁山都反对这种粗糙定义。

更精确为：

> **即使暂时犯罪、逃亡、受刑或进入梁山，也不愿把永久草寇化作为最终法理归属；未来应保留并争取合法回返、归顺与报国资格。**

该原则通过 current `zn` 门：

1. 压力前已可命名：第36回拒绝被强逼入伙。
2. 非奖励驱动：第36回最硬证据发生在需要接受处分、刺配的条件下。
3. 冲突排序：安全/自由与合法回返资格冲突时，后者仍进入选择。
4. 跨阶段调用：第36回、第71回、第82回连续出现。
5. 边界明确：允许暂时处于江湖/梁山，但不接受永久草寇化为最终归属。

因此本窄对象层 `zn` 成立。

## 7｜pressure-display 判定

满足同一 criterion：

```text
压力前：
同一可命名 zn 已独立成立

压力中：
最直接行动表达“以合法身份回到旧秩序”被现实梁山/反叛位置封住
但未来指导资格仍保留
并转为“争取招安”的受限实现路径

解压：
正式招安
→ 合法政治行动窗口重新开放
→ 同一归顺/报国方向进入直接现实执行
```

因此：

> **action window blocked ≠ `zn` erased。**

本例还补充：pressure-display 不要求压力中完全沉默；只要**关键现实实现窗口**被真实封住，而同一原则仍保留未来指导资格，解压后按同一内容恢复更直接现实表达，就可以成立。

## 8｜拿掉测试

### 拿掉压力

若没有江州劫法场后进入梁山、被置于反叛政治位置，宋江不需要通过“招安”才能恢复合法归属；原本个人服刑/限满的直接回返路径仍可能存在。

因此压力确实改变的是现实实现窗口。

### 拿掉 zn

如果删除“最终不愿永久草寇化、仍追求合法回返”的内部标准：

- 第36回拒绝被强逼入伙失去稳定解释；
- 第71回在已经拥有梁山现实权力时仍坚持招安也失去跨阶段解释；
- 第82回受招安只会成为一次外部机会，而不是此前方向的兑现。

## 9｜反向测试

若出现：

```text
第36回原则成立
→ 入梁山后彻底接受永久草寇归属
→ 后续同类冲突里不再出现合法回返/归顺方向
→ 朝廷招安到来才第一次临时改口
```

则应判 lifecycle / 新原则形成，而不是 pressure-display。

原著不符合。

## 10｜最近邻排除

- `zn vs z`：第36回最硬证据发生在没有官方赞誉、反而要受处分时；后来的受诏/赦免不能倒填原则起点。
- `zn vs xn`：争取招安的联络、路线与操作回答“怎么回去”，不回答“为什么最终不接受永久草寇化”。
- `zn vs nx`：招安需要外部朝廷接口，但外部接口不等于内部原则；第36回在该接口尚未激活时 `zn` 已成立。
- pressure-display vs lifecycle：本轮不重复增加 lifecycle。宋江已有独立 lifecycle 用途；这里仅审计“关键现实表达窗口受压/解压”。
- `x`：梁山军事/组织 `x` 属于既有其他研究用途，本轮不增加 `x` 或 `zn+x` 统计。
