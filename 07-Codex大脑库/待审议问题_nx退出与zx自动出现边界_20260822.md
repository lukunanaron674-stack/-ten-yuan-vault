# 待审议｜nx 退出与 zx 自动出现边界

## 0｜触发原因

连续三部独立作品出现同一边界：

> 主体此前已经真实承接外部给定方向 / 任务，后来在当前对象层主动不再续接；但退出 nx 以后，并没有因此自动取得新的公共决定范围，也没有让外部系统围绕主体新增权力接口重组。

因此形成待审议问题：

> **`nx ↓` 是否能被理解成 `zx ↑`？**

当前三部作品共同给出的答案是否定的：**不能自动这样理解。**

## 1｜三部独立控制

### 1.1《西游记》猪八戒四圣试禅心

此前真实承接取经方向；面对招赘诱惑后主动尝试退出西行、留下婚配。

- 当前 nx：退出
- x 私人选择邻近：有
- xn 新方案重建：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

### 1.2《水浒传》武松六和寺拒赴京

此前真实承接招安后的朝廷征讨体系；征方腊结束后拒绝继续班师赴京、朝觐受封，实际留在六和寺。

- 当前 nx：退出
- x 私人去留邻近：有
- xn 新政治/军事方案：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

### 1.3《三国演义》关羽挂印封金辞曹

土山三约后暂时进入曹操体系并实际执行任务；一旦得知刘备下落，按此前约定的退出条件挂印封金、写信告辞并实际离开。

- 当前 nx：退出
- x 既有退出边界：较强
- xn 新结构重建：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

## 2｜当前候选纪律

### 候选纪律 A｜nx 与 zx 不是自动跷跷板

```text
不再续接外部方向
= nx下降 / 退出

但只有进一步满足：
主体自身权能公开进入现实
+ 外部主体/环境围绕其新增权能重新响应
+ 主体决定范围、位置或作用边界真实上升

才继续检查zx
```

因此：

> **拒绝、退出、辞职、离队、反悔、停止服从，本身都不能直接判 zx。**

### 候选纪律 B｜退出后优先重查 x / xn / zx

主体退出 nx 后，应重新分层检查：

1. 是否只是调用本来已有的个人 / 局部 `x` 边界；
2. 是否主动建立一套新的持续运行结构，进入 `xn`；
3. 是否真正把决定范围公开推过原边界，进入 `zx`。

不能只因为“不听了”就跳过这些门。

### 候选纪律 C｜退出条件来源要单独检查

若主体的退出资格此前已经约定、授权或稳定存在，则当前行为更可能是：

> **停止 nx 续接 + 调用已有 x**

而非 zx。

只有主体原本没有该决定边界，并在冲突中公开取得新的、更大决定范围，才进一步检查 zx。

## 3｜防止矫枉过正

本待审议不意味着：

> 退出 nx 永远不会出现 zx。

可能存在真正的动态：

```text
原先沿外部方向
→ 主体退出
→ 进一步公开夺取更高决定位置
→ 外部系统被迫承认新增权能
= nx退出后zx高显影
```

因此真正要避免的是**自动推导**，不是禁止动态转化。

## 4｜与 x / xn 的最近邻

### x

主体只是在自己已有范围内决定“不继续”，优先检查 x，而非 zx。

### xn

主体退出以后若重新搭建流程、资源、人员、节点和持续成功条件，应检查 xn。

### zx

必须看到新增决定位置或范围被现实承认 / 被迫响应，而不是只看到拒绝动作。

## 5｜下一步需要的材料

最值得找的是反向正例：

> 主体先真实承接 nx → 后来退出 → 随后明确夺取新增公共决定范围 → 外部系统围绕新接口重排。

若能找到跨作品高纯正例，则可进一步压：

> **nx退出什么时候只是 x / xn，什么时候真正转化为 zx。**
