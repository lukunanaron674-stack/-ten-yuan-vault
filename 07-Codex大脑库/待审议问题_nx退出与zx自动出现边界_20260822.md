# 待审议｜nx 退出与 zx 自动出现边界

## 0｜当前问题

三部负控制已经稳定证明：

> **`nx ↓ / 退出` 不能自动推出 `zx ↑`。**

现在又有三部独立反向正例证明：

> **nx 退出以后确实可能出现 zx，但 zx 必须重新独立通过自己的硬门。**

因此本待审议研究的不是“nx 与 zx 能不能转化”，而是：

> **什么时候只是停止续接外部方向，什么时候又进一步形成新的公开权能与决定位置。**

---

## 1｜三部负控制：退出 nx，但非 zx

### 1.1《西游记》猪八戒四圣试禅心

此前真实承接取经方向；面对招赘诱惑后主动尝试退出西行、留下婚配。

- 当前 nx：退出
- x 私人选择邻近：有
- xn 新方案重建：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

### 1.2《水浒传》武松六和寺拒赴京

此前真实承接招安后的朝廷征讨体系；征方腊结束后拒绝继续班师赴京、朝觐受封，实际留在六和寺。

- 当前 nx：退出
- x 私人去留邻近：有
- xn 新政治/军事方案：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

### 1.3《三国演义》关羽挂印封金辞曹

土山三约后暂时进入曹操体系并实际执行任务；得知刘备下落后按此前约定的退出条件挂印封金、写信告辞并离开。

- 当前 nx：退出
- x 既有退出边界：较强
- xn 新结构重建：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

三例共同说明：

```text
停止服从 / 辞职 / 离队 / 反悔 / 拒绝继续
→ 只能先确认 nx下降或退出
→ 不能自动锁 zx
```

## 2｜反向正例1：《西游记》孙悟空弼马温 → 反天宫

前段：

```text
天庭给定弼马温职务
→ 孙悟空接受并实际到任
= nx 上位职责关系
```

得知弼马温“未入流”以后：

```text
停止续接天庭低位职务
= nx退出
```

但 zx 不是由此自动得到。真正的 zx 独立证据是：

```text
自定“齐天大圣”身份
→ 公开立旗、迎战天兵
→ 天庭围绕其公开权能重新响应
→ 主体等级 / 凌驾位置上升
= zx
```

拿掉自号、立旗、迎战和天庭响应，只剩“辞掉弼马温”，则不能锁 zx。

---

## 3｜反向正例2：《水浒传》林冲投梁山 → 火并王伦

前段：

```text
林冲需要安身
→ 梁山准入权在王伦
→ 请求收录并接受投名状条件
= nx
```

第十九回王伦再次拒绝晁盖等人时：

```text
林冲不再沿王伦最终接口推进
→ 公开否定并清除王伦
= nx退出
```

真正支持 zx 的额外证据是：

- 原最高首领 / 准入接口被实际清除；
- 杜迁、宋万、朱贵等旧头领屈服；
- 原组织无法继续按旧中心运行；
- 林冲参与重定新寨主结构；
- 梁山围绕新事实重新排列。

因此：

```text
nx退出
+ 公开推翻原最高接口
+ 组织结构真实重排
+ 主体取得此前没有的关键结构决定位置
= zx独立成立
```

拿掉清除王伦与组织重排，只保留“不再听王伦”，则仍只有 nx 退出。

已有专项复审同时锁定：前段 nx 处理“林冲本人如何获得梁山成员资格”，后段 zx 处理“谁拥有梁山最高治理 / 新成员准入接口”，所以这是动态转化材料，不是严格 zx↔nx 补关系。

## 4｜反向正例3：《红楼梦》探春抄检：上位续接 → 局部退出 → zx复位

### 4.1 前段 nx 真实续接

王夫人批准夜间搜检，凤姐等进入秋爽斋。探春没有否定“查明物品、洗清嫌疑”这一上位任务，而是提前开门，并主动命人打开自己的箱柜、妆盒、衣包请凤姐查阅。

因此在“上位查物任务”对象层：

`nx_upper_search_task_continuation: evidence-locked`

### 4.2 局部 nx 退出

当执行继续压入到“搜丫鬟 / 奴仆翻探春身体”这一层时，探春明确拒绝把局部最终判断资格继续交给执行组。

她允许查自己的东西，却拒绝王善保家的越界搜身；王善保家的拉扯衣襟以后，探春当场反击。

因此：

`nx_in_local_body_and_household_boundary: rejected`

### 4.3 后段 zx 为什么独立成立

真正 zx 证据不是“一巴掌”，而是：

```text
外部局部方向继续压入
→ 探春公开设定边界
→ 越界时直接否决
→ 凤姐、平儿等制止王善保家的并调整执行
→ 搜检队不再沿原越界方式继续
→ 探春局部决定位置恢复/上升
= zx受压复位
```

所以本例同样满足：

> **nx退出后重新独立取得 zx 证据，而不是由 nx 下降自动推出 zx。**

### 4.4 对象层警告

本例必须保留分层：

- 前段 nx：上位“查物”任务；
- 后段 nx 退出 / zx：身体、丫鬟与院内执行边界。

因此它是**嵌套对象层中的动态切换控制**，不能写成同一个权限对象瞬间由 nx 翻成 zx，更不能升级成严格补关系。

## 5｜3个负控制 + 3个反向正例后的共同结构

### 负控制共同结构

```text
前段nx真实成立
→ 当前停止续接外部方向
→ nx退出
→ 只发生私人选择 / 已有x / 单纯反抗
→ 没有新增公共决定位置
= 非zx
```

### 反向正例共同结构

```text
前段nx真实成立
→ 当前明确停止续接外部方向 / 权限接口
→ nx退出
→ 主体又公开生成并占据新的方向 / 边界
→ 外部系统围绕主体新增权能真实响应或重排
→ 主体决定位置、作用边界或凌驾位置上升
= zx独立成立
```

具体对象不同：

- 孙悟空：天庭职务 / 等级秩序；
- 林冲：梁山首领 / 准入治理结构；
- 探春：上位搜检任务 / 局部身体与院内边界。

共同分叉点不是“反抗有多猛烈”，而是：

> **退出以后有没有新增的公开权能证据，以及现实是否围绕它重新响应。**

## 6｜当前候选纪律

### A｜nx 与 zx 不是自动跷跷板

```text
不再续接外部方向
= nx下降 / 退出

只有进一步满足：
主体自身权能公开进入现实
+ 外部主体/环境围绕其新增权能重新响应
+ 主体决定范围、位置或作用边界真实上升

才继续锁zx
```

因此：

> **拒绝、退出、辞职、离队、反悔、停止服从，本身都不能直接判 zx。**

### B｜退出后重新检查 x / xn / zx

1. 只是调用已有个人 / 局部边界 → 优先 `x`；
2. 主动建立新的持续运行结构 → 检查 `xn`；
3. 把自身决定范围公开推过原边界并让现实响应 → 检查 `zx`。

### C｜已有退出资格不等于 zx

若退出资格此前已经约定、授权或稳定存在，则更可能是：

> **停止 nx 续接 + 调用已有 x。**

只有原本没有该决定边界，并在冲突中公开取得更大决定位置，才进一步检查 zx。

### D｜真正的 nx → zx 必须重新独立取证

至少检查：

1. 退出的是哪个对象层；
2. 退出后主体是否公开生成并占据自己的新方向；
3. 是否只做私人选择，还是把权能压到公共现实；
4. 外部系统是否围绕新增权能真实响应 / 重排；
5. 主体决定范围 / 作用边界 / 凌驾位置是否高于退出前的既有个人边界。

### E｜对象层可切换，但不得糊成一键翻转

探春案例补出：同一事件内部可能出现上位 nx 与下位 zx 的嵌套切换。

因此动态分析必须记录：

> **哪个外部方向被承接，哪个局部方向被退出，zx 又在哪个对象层独立成立。**

对象层不同，不妨碍做动态转化压力测试；但禁止把它们写成严格同对象补关系或人格“换芯”。

## 7｜与 x / xn 的最近邻

### x

主体只是在自己已有范围内决定“不继续”，优先检查 x，而非 zx。

### xn

主体退出以后若重新搭建流程、资源、人员、节点和持续成功条件，应检查 xn。

### zx

必须看到新增决定位置或作用边界被现实承认 / 被迫响应，而不是只看到拒绝动作。

---

## 8｜拿掉、反向与第三因素冻结

### 拿掉

- 拿掉孙悟空自号、立旗、迎战与天庭响应，只剩辞职 → 非 zx。
- 拿掉林冲清除王伦与首领结构重排，只剩不再听王伦 → 非 zx。
- 拿掉探春公开设界、阻断越界与搜检队调整，只剩停止配合 → 非 zx。

所以三例都证明：zx 有独立证据链。

### 反向

如果退出 nx 后只发生：

```text
个人离开 / 拒绝 / 不再服从
```

而没有公开权能扩张和现实重排，则回到负控制一侧。

### 第三因素冻结

冻结战斗力、暴力强度、英雄/小姐身份、人物好恶、吴用智谋、神仙身份、作品后续结果；只保留：

> **是否停止续接外部方向 + 是否又形成独立的公开权能扩张证据。**

三类结论不变。
