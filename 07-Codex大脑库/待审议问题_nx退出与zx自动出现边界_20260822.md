# 待审议｜nx 退出与 zx 自动出现边界

## 0｜触发原因

连续三部独立作品出现同一边界：

> 主体此前已经真实承接外部给定方向 / 任务，后来在当前对象层主动不再续接；但退出 nx 以后，并没有因此自动取得新的公共决定范围，也没有让外部系统围绕主体新增权力接口重组。

因此形成待审议问题：

> **`nx ↓` 是否能被理解成 `zx ↑`？**

当前三部负控制共同给出的答案是否定的：**不能自动这样理解。**

同时已补入两部独立反向正例：

- 《西游记》孙悟空“弼马温 → 反天宫”；
- 《水浒传》林冲“投梁山 → 火并王伦”。

二者共同证明：**nx 退出以后确实可能继续出现真正 zx，但 zx 必须重新独立通过自身门槛，不能由 nx 的下降自动推出。**

## 1｜三部独立负控制

### 1.1《西游记》猪八戒四圣试禅心

此前真实承接取经方向；面对招赘诱惑后主动尝试退出西行、留下婚配。

- 当前 nx：退出
- x 私人选择邻近：有
- xn 新方案重建：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

### 1.2《水浒传》武松六和寺拒赴京

此前真实承接招安后的朝廷征讨体系；征方腊结束后拒绝继续班师赴京、朝觐受封，实际留在六和寺。

- 当前 nx：退出
- x 私人去留邻近：有
- xn 新政治/军事方案：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

### 1.3《三国演义》关羽挂印封金辞曹

土山三约后暂时进入曹操体系并实际执行任务；一旦得知刘备下落，按此前约定的退出条件挂印封金、写信告辞并实际离开。

- 当前 nx：退出
- x 既有退出边界：较强
- xn 新结构重建：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

## 2｜反向正例 1｜《西游记》孙悟空弼马温 → 反下天宫

### 2.1 前段 nx 已独立成立

玉帝任孙悟空为弼马温，孙悟空真实到任御马监，并承接天庭给定的上位职务与任务。

```text
天庭给定职务与上位任务
→ 孙悟空接受并实际到任
= nx 上位职责关系位置
```

### 2.2 nx 退出发生在明确执行窗口

孙悟空得知弼马温“未入流”后，拒绝继续承接这个天庭给定的低位职务，打出御马监并反下天宫。

```text
原外部职务方向
→ 主体停止续接
= nx 退出
```

但到此为止仍不能直接写 zx。

### 2.3 后段 zx 为什么独立成立

退出以后又出现新的独立证据：

```text
主体拒绝天庭低位等级
→ 自定“齐天大圣”身份
→ 公开立旗、迎战天兵
→ 天庭不得不围绕其公开权能重新响应
→ 主体在等级 / 凌驾位置上的现实影响上升
= zx 高显影
```

因此：

```text
nx退出
↓
重新检查zx硬门
↓
公开显权成立
+ 天庭真实响应
+ 决定 / 凌驾位置上升
↓
zx独立成立
```

## 3｜反向正例 2｜《水浒传》林冲投梁山 → 火并王伦

### 3.1 前段 nx 已独立成立

第十一回，林冲需要安身，但梁山成员准入权在王伦一侧。林冲通过柴进荐书、朱贵引入进入梁山准入流程；王伦先推拒，后提出“三日投名状”条件，林冲接受并下山执行。

```text
林冲自有“寻找安身处”目标
→ 梁山准入权属于王伦
→ 林冲请求收录并接受投名状条件
→ 沿王伦既有准入接口推进
= nx 关系功能
```

该前段端点已有正式案例锁定：事实 99 / 分类 98。

### 3.2 当前 nx 退出发生在原接口被公开否定时

第十九回，晁盖等人来投梁山，王伦再次以粮少房稀等理由拒绝。此时林冲不再继续劝王伦、等待批准或接受新的准入条件，而是公开否定王伦的首领资格，并亲自清除这个原最高决定节点。

```text
王伦继续掌握首领 / 准入接口并拒绝晁盖
→ 林冲不再沿该接口续接
→ 公开否定并清除王伦
= 当前 nx 退出
```

这里首先只能证明 nx 退出；杀人、愤怒、武力强都不能自动推出 zx。

### 3.3 后段 zx 为什么独立成立

真正支持 zx 的是清除王伦以后出现了额外结构证据：

- 原梁山最高首领 / 准入接口被实际移除；
- 杜迁、宋万、朱贵等旧头领屈服，原组织结构无法继续；
- 林冲被推坐第一位时拒绝长期占据，但仍明确参与决定新的寨主结构；
- 林冲推晁盖为山寨之主，并以王伦为例要求组织接受新的排序；
- 组织现实围绕林冲造成的新事实重新排列。

因此：

```text
nx退出
↓
公开推翻原最高接口
↓
组织首领 / 准入结构被迫重排
↓
林冲取得此前没有的关键结构性决定位置
= zx 当前状态独立成立
```

该后段端点已有正式案例锁定：事实 99 / 分类 97。

### 3.4 拿掉测试

拿掉“林冲以前通过王伦准入”的前史，只保留第十九回“公开推翻原最高首领 / 准入接口 → 组织重排”，后段 zx 仍可独立成立。

拿掉第十九回的“清除王伦、旧头领屈服、重定新寨主”等结构证据，只保留“林冲不再听王伦”，则最多证明 nx 退出，不足以锁 zx。

因此：

> **zx 不是 nx 退出自动生成；它有自己的独立证据链。**

### 3.5 与严格补关系的排除

已有专项复审已锁定：第十一回 nx 处理的是“林冲本人如何获得第一次梁山成员资格”；第十九回 zx 处理的是“梁山最高首领 / 新成员准入治理接口由谁占据”。两个对象层不同。

因此本例可以作为 `nx退出 → zx高显影` 的动态转化材料，但不能因此升级为严格 `zx↔nx` 补关系。

## 4｜两部反向正例的共同结构

孙悟空与林冲共同满足：

```text
前段nx真实成立
→ 当前明确停止续接外部方向 / 权限接口
→ nx退出
→ 再出现新的公开权能证据
→ 外部系统围绕新增事实重新响应 / 重排
→ 主体决定位置或凌驾位置真实上升
→ zx独立成立
```

两例的具体对象不同：

- 孙悟空：天庭职务 / 等级秩序；
- 林冲：梁山首领 / 准入治理结构。

共同分叉点不是“反抗有多猛烈”，而是：**退出以后有没有新增的公开决定位置与现实重排。**

## 5｜当前候选纪律

### 候选纪律 A｜nx 与 zx 不是自动跷跷板

```text
不再续接外部方向
= nx下降 / 退出

但只有进一步满足：
主体自身权能公开进入现实
+ 外部主体/环境围绕其新增权能重新响应
+ 主体决定范围、位置或作用边界真实上升

才继续锁zx
```

因此：

> **拒绝、退出、辞职、离队、反悔、停止服从，本身都不能直接判 zx。**

### 候选纪律 B｜退出后优先重查 x / xn / zx

主体退出 nx 后，应重新分层检查：

1. 是否只是调用本来已有的个人 / 局部 `x` 边界；
2. 是否主动建立一套新的持续运行结构，进入 `xn`；
3. 是否真正把决定范围公开推过原边界，进入 `zx`。

### 候选纪律 C｜退出条件来源要单独检查

若主体的退出资格此前已经约定、授权或稳定存在，则当前行为更可能是：

> **停止 nx 续接 + 调用已有 x**

而非 zx。

只有主体原本没有该决定边界，并在冲突中公开取得新的、更大决定范围，才进一步检查 zx。

### 候选纪律 D｜真正的 nx → zx 转化必须重新取证

两部反向正例共同支持：

> **nx退出后可以出现 zx，但 zx 必须重新独立取证。**

至少检查：

1. 退出的是哪个外部方向 / 对象层；
2. 退出后主体是否公开生成并占据自己的新方向；
3. 是否只做私人选择，还是把权能压到公共现实；
4. 外部系统是否围绕该新增权能真实重排；
5. 主体决定范围 / 凌驾位置是否超过退出前的既有个人边界。

## 6｜防止矫枉过正

本待审议不意味着：

> 退出 nx 永远不会出现 zx。

当前已有两部高纯反向正例：

```text
孙悟空任弼马温
→ nx上位任务承接
→ 退出
→ 自号齐天大圣并公开让天庭响应
= zx

林冲投梁山
→ nx准入接口承接
→ 不再承认王伦最终接口
→ 清除王伦并使梁山首领结构重排
= zx
```

真正要避免的是自动推导，不是禁止动态转化。

## 7｜与 x / xn 的最近邻

### x

主体只是在自己已有范围内决定“不继续”，优先检查 x，而非 zx。

### xn

主体退出以后若重新搭建流程、资源、人员、节点和持续成功条件，应检查 xn。

### zx

必须看到新增决定位置或范围被现实承认 / 被迫响应，而不是只看到拒绝动作。

林冲案例还额外提醒：有吴用等人参与策略推动，不等于林冲 zx 不成立；必须冻结他人方案，检查林冲自己的公开清除与结构重排是否仍独立成立。

## 8｜拿掉、反向与第三因素冻结

### 拿掉测试

拿掉孙悟空退出弼马温后的自号、立旗、迎战与天庭响应，只剩“辞掉低位官职”，则不能锁 zx。

拿掉林冲火并后的首领结构重排，只剩“不再听王伦”，同样只能锁 nx 退出，不能锁 zx。

### 反向测试

若孙悟空辞掉弼马温以后只是回花果山过自己的生活，或林冲只是退出王伦安排、另找去处，不形成新的公共决定位置，则都应落到负控制一侧：nx 退出，但非 zx。

### 第三因素冻结

冻结战斗力、暴力强度、英雄评价、吴用智谋、孙悟空神仙身份和作品后续结果；只保留“是否停止外部方向 + 是否形成新的公开权能扩张”，两例结论仍稳定。

若第三部仍达到 ≥95%，再讨论是否把：
