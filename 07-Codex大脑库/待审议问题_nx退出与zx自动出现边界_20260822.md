# 待审议｜nx 退出与 zx 自动出现边界

## 0｜触发原因

连续三部独立作品出现同一边界：

> 主体此前已经真实承接外部给定方向 / 任务，后来在当前对象层主动不再续接；但退出 nx 以后，并没有因此自动取得新的公共决定范围，也没有让外部系统围绕主体新增权力接口重组。

因此形成待审议问题：

> **`nx ↓` 是否能被理解成 `zx ↑`？**

当前三部作品共同给出的答案是否定的：**不能自动这样理解。**

同时，本轮补入首个反向正例《西游记》孙悟空“弼马温 → 反天宫”：该例证明 **nx 退出以后确实可能继续出现真正 zx，但 zx 必须重新独立通过自身门槛，不能由 nx 的下降自动推出。**

## 1｜三部独立边界控制

### 1.1《西游记》猪八戒四圣试禅心

此前真实承接取经方向；面对招赘诱惑后主动尝试退出西行、留下婚配。

- 当前 nx：退出
- x 私人选择邻近：有
- xn 新方案重建：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

### 1.2《水浒传》武松六和寺拒赴京

此前真实承接招安后的朝廷征讨体系；征方腊结束后拒绝继续班师赴京、朝觐受封，实际留在六和寺。

- 当前 nx：退出
- x 私人去留邻近：有
- xn 新政治/军事方案：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

### 1.3《三国演义》关羽挂印封金辞曹

土山三约后暂时进入曹操体系并实际执行任务；一旦得知刘备下落，按此前约定的退出条件挂印封金、写信告辞并实际离开。

- 当前 nx：退出
- x 既有退出边界：较强
- xn 新结构重建：无
- zx 公共扩权：无

结论：**退出 nx，但非 zx。**

## 2｜首个反向正例｜《西游记》孙悟空弼马温 → 反下天宫

### 2.1 前段 nx 已独立成立

玉帝任孙悟空为弼马温，孙悟空真实到任御马监，并承接天庭给定的上位职务与任务。

因此前段不是“孙悟空一开始就完全自己定天庭岗位”，而是：

```text
天庭给定职务与上位任务
→ 孙悟空接受并实际到任
= nx 上位职责关系位置
```

该端点已在既有正式材料中锁定。

### 2.2 nx 退出发生在明确执行窗口

孙悟空得知弼马温“未入流”后，拒绝继续承接这个天庭给定的低位职务，打出御马监并反下天宫。

这里首先发生的是：

```text
原外部职务方向
→ 主体停止续接
= nx 退出
```

但到此为止仍然不能直接写 zx。

### 2.3 后段 zx 为什么可以独立成立

真正让本例跨入 zx 的，是退出以后又出现了一组新的、独立证据：

```text
主体拒绝天庭低位等级
→ 自定“齐天大圣”身份
→ 公开立旗、迎战天兵
→ 天庭不得不围绕其公开权能重新响应
→ 主体在等级 / 凌驾位置上的现实影响上升
= zx 高显影
```

因此本例不是：

```text
nx减少
→ zx自动增加
```

而是：

```text
nx退出
↓
重新检查zx硬门
↓
公开显权成立
+ 天庭真实响应
+ 决定 / 凌驾位置上升
↓
zx独立成立
```

### 2.4 与三部负控制的最小差异

猪八戒、武松、关羽同样都能做到“不再沿原外部方向走”，但退出后主要落到私人选择、既有退出资格或单纯停止续接，没有形成新的公共决定范围。

孙悟空不同：他在退出后继续把自身要求的等级位置公开压进现实，并让天庭以军事、招抚、重新安排等方式围绕其新位置作出响应。

因此：

> **nx退出是共同前件；真正分叉点是退出以后有没有新增 zx 所要求的公开权能扩张证据。**

## 3｜当前候选纪律

### 候选纪律 A｜nx 与 zx 不是自动跷跷板

```text
不再续接外部方向
= nx下降 / 退出

但只有进一步满足：
主体自身权能公开进入现实
+ 外部主体/环境围绕其新增权能重新响应
+ 主体决定范围、位置或作用边界真实上升

才继续检查zx
```

因此：

> **拒绝、退出、辞职、离队、反悔、停止服从，本身都不能直接判 zx。**

### 候选纪律 B｜退出后优先重查 x / xn / zx

主体退出 nx 后，应重新分层检查：

1. 是否只是调用本来已有的个人 / 局部 `x` 边界；
2. 是否主动建立一套新的持续运行结构，进入 `xn`；
3. 是否真正把决定范围公开推过原边界，进入 `zx`。

不能只因为“不听了”就跳过这些门。

### 候选纪律 C｜退出条件来源要单独检查

若主体的退出资格此前已经约定、授权或稳定存在，则当前行为更可能是：

> **停止 nx 续接 + 调用已有 x**

而非 zx。

只有主体原本没有该决定边界，并在冲突中公开取得新的、更大决定范围，才进一步检查 zx。

### 候选纪律 D｜真正的 nx → zx 转化必须重新取证

本轮反向正例支持：

> **nx退出后可以出现 zx，但 zx 必须重新独立取证。**

至少检查：

1. 退出的是哪个外部方向 / 对象层；
2. 退出后主体是否公开生成并占据自己的新方向；
3. 是否只做私人选择，还是把权能压到公共现实；
4. 外部系统是否围绕该新增权能真实重排；
5. 主体决定范围 / 凌驾位置是否超过退出前的既有个人边界。

## 4｜防止矫枉过正

本待审议不意味着：

> 退出 nx 永远不会出现 zx。

已经存在首个高纯反向正例：

```text
孙悟空任弼马温
→ nx上位任务承接
→ 得知低官阶后退出
→ 自号齐天大圣
→ 公开对抗并迫使天庭重新响应
= nx退出后zx高显影
```

因此真正要避免的是**自动推导**，不是禁止动态转化。

## 5｜与 x / xn 的最近邻

### x

主体只是在自己已有范围内决定“不继续”，优先检查 x，而非 zx。

### xn

主体退出以后若重新搭建流程、资源、人员、节点和持续成功条件，应检查 xn。

### zx

必须看到新增决定位置或范围被现实承认 / 被迫响应，而不是只看到拒绝动作。

## 6｜拿掉、反向与第三因素冻结

### 拿掉测试

拿掉孙悟空“退出弼马温”之后的自号、立旗、迎战与天庭响应，只剩“辞掉低位官职”，则不能锁 zx。

拿掉前段弼马温 nx，只保留后段“拒绝低位等级 → 自号齐天大圣 → 公开对抗天庭”，后段 zx 仍可独立成立。这说明 zx 不是 nx 下降自动生成，而是有自己的独立证据链。

### 反向测试

若孙悟空辞掉弼马温以后只是回花果山过自己的生活，不形成新的公共等级要求、不迫使天庭围绕其新位置响应，则应与猪八戒 / 武松 / 关羽同侧：nx退出，但非zx。

### 第三因素冻结

冻结孙悟空战斗力、神仙身份、独角鬼王建议、后来是否正式受封空衔、蟠桃园与后续大闹天宫；只保留“是否停止外部方向 + 是否形成新的公开权能扩张”，结论仍稳定。
