# 待审议问题｜zx 与 x 的“已有权限成功行使 ≠ 扩权”判定纪律

## 0｜为什么触发

当前已经跨三部独立作品稳定出现同一类误判风险：

1. 《西游记》唐僧逐悟空：唐僧调用已有师徒处分接口，命令成功，但没有因此取得新增决定范围。
2. 《红楼梦》贾母阻鸳鸯婚事：贾母调用原本已经存在的家内许可/否决接口，贾赦退让，但不是临时夺得新权限。
3. 《三国演义》诸葛亮斩马谡：诸葛亮调用原有北伐统帅/军法处分接口，马谡被处置；随后诸葛亮反而自请贬三等，进一步排除本轮正式扩权。

三例共同最小结构：

```text
主体在冲突发生前已经拥有某项处分/否决接口
→ 本轮公开调用该接口
→ 对象或组织真实服从/改变
→ 权力有效性得到证明

但
→ 主体没有取得此前不存在的更大决定范围
→ 权限边界没有新增
→ 不能仅凭“公开成功用权”判 zx
→ 优先检查 x
```

因此达到“跨至少3个独立作品同类边界问题”的待审议触发门槛。

## 1｜待审议命题

是否需要在 zx 准度层或 x↔zx 最近邻纪律中进一步显式写入：

> **权力有效 ≠ 权力扩大。**
> **已有权限被公开成功行使，优先检查 x；只有主体决定边界、影响位置或凌驾程度发生可证明的新增/上升，才进一步锁 zx。**

候选最短式：

```text
x：我本来就有这个权，我把它用出来。
zx：我原本没有这么大的权/位置，现在公开把决定范围推大了。
```

这不是要把所有“公开显权”都降成 x，而是要求 zx 的“显权”必须和“扩权/位置上升”同时核验，防止只看动作强度、服从结果或身份威慑。

## 2｜为什么暂时不能改 L1 或 zx 信息卡

现行 zx v2.3 与 zx 准度卡 v0.1 已经明确写有：

- 主体位置、影响与决定范围扩大；
- 决定范围、影响位置或凌驾程度上升；
- 权限早已由职位授予、主体只照章执行时，应检查 x/xn/nx。

所以当前三例更可能说明：

```text
定义本身未必有缺口
而是案例判定时需要更强的 zx↔x 最近邻纪律
```

因此当前只建立 pending-review 问题，不修改：

- L1；
- zx/nx 信息卡；
- zx/nx 准度卡；
- zx补nx_补卡。

## 3｜三例的最小差异

### 《西游记》唐僧逐悟空

```text
已有师徒处分接口
→ 执行逐出
→ 悟空离队
→ 没有新增处分边界
= x 最近邻优先
```

### 《红楼梦》贾母阻鸳鸯婚事

```text
已有家内许可/否决接口
→ 明确不给
→ 贾赦退让
→ 没有新增决定边界
= x 最近邻优先
```

### 《三国演义》诸葛亮斩马谡

```text
已有统帅/军法处分接口
→ 依法处置马谡
→ 军令执行
→ 没有新增军法边界
→ 后续本人正式官位反而下降
= x 最近邻优先
```

三例的对象域不同：师徒关系、家内处分、军事军法；但“权限是否在冲突前已属于主体”这一变量保持一致，因此具有跨情境价值。

## 4｜下一步验证要求

不要继续无脑堆第四、第五个“领导下令成功”的同型样本。优先找反向最小差异。

### A｜已有权限，但真 zx 上升

要求出现：

```text
主体原本已有局部权限
→ 本轮公开调用
→ 同时借冲突把权限边界推到原本不属于自己的范围
→ 外部秩序承认新增范围
```

用来检查“x 与 zx 可以同场，但必须拆出新增部分”。

### B｜名义权限存在，但实际接口不归主体

要求出现：

```text
主体看似有职位/名义
→ 实际关键否决权、资源或调用接口在别人手中
→ 需要借外部节点推进
```

用来防止把名义上的 x 错当实际 x，并继续检验 nx。

### C｜同人物跨阶段

优先找：

```text
阶段1：只是行使已有权限 = x
阶段2：决定范围真实扩大 = zx
```

这样最能证明差别不是人物性格标签，而是权限边界的结构变化。

## 5｜当前案例判定纪律（研究层临时执行）

```text
1. 看到主体公开下令、处分、否决成功时，先不要判 zx。
2. 先问：这个权限在冲突发生前是否已经属于主体？
3. 若是，只证明权限有效，优先检查 x。
4. 再问：本轮之后主体决定范围是否新增、位置是否上升、别人是否承认新边界？
5. 只有第4项成立，才进一步锁 zx。
6. 执行者替主体完成动作，不等于主体在借执行者权限，因此不能据此判 nx。
7. 本纪律暂只用于研究/案例判定，不上升为 L1 修改。
```
