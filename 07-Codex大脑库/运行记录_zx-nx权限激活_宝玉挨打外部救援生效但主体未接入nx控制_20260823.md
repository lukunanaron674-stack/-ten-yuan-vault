# 运行记录｜宝玉挨打：外部救援生效，但主体未接入 nx 通道

## 1｜剧情事实

《红楼梦》第三十三回中，贾政因多重事件震怒，对宝玉施以重责。宝玉在受打过程中由最初哭喊逐渐变得气弱，后续已处于明显被动受罚状态。

众门客先行劝阻但未成功，随后有人向内传信。王夫人进入书房后直接抱住板子并以夫妻、母子与贾母身体等理由阻止贾政继续下手。贾政一度仍欲继续处分，王夫人继续阻拦。之后贾母赶到并公开责备贾政，贾政最终停止并退出，宝玉被抬走。

本轮被测试的当前对象不是“王夫人是否使用上位关系保护儿子”，而是：

> **宝玉本人在这一窄阶段是否形成 nx 当前行为 / 关系功能。**

## 2｜最小结构

```text
宝玉遭贾政现实笞打
↓
宝玉自身当前无法停止处分
↓
王夫人 / 贾母的家内保护与上位关系接口真实进入
↓
外部接口直接改变结果：笞打停止、宝玉被移走

但同时：
宝玉没有请求该接口
没有等待其许可
没有沿该关系通道推进
没有接受一个外部任务并执行
没有把当前解决过程接到该通道上继续
```

因此必须区分：

```text
外部权限 / 保护接口客观存在并发生作用
≠
主体本人当前 nx 行为功能已经激活
```

## 3｜zx 检查

本窄阶段 `zx` 排除为主判。

宝玉没有：

- 自己生成并公开推进新的处分方向；
- 用自身权能迫使贾政调整；
- 让家内秩序围绕宝玉新增的决定接口重新运行；
- 扩大自己的决定范围。

笞打停止主要来自王夫人、贾母等外部节点介入，不应倒算为宝玉自身 `zx`。

正式锁：

`zx_in_narrow_stage: rejected_as_primary`

## 4｜nx 检查

现行 nx 要求的不是“别人帮了我”这一结果，而是：

> 方向、权限或解决通道在外部，且主体当前真实沿该关系、权限或流程推进。

宝玉本段不满足后半部分。

没有看到他：

- 主动向王夫人或贾母求救；
- 等待某个外部批准后再行动；
- 承接一个外部安排并持续执行；
- 沿家内关系链主动推进“停止笞打”；
- 借用身份、旧交、许可或流程让结果生效。

所以只能锁：

```text
external_protection_interface_exists = true
external_protection_interface_changes_result = true
```

但不能顺手写成：

```text
nx_behavior_function = true
```

正式锁：

`nx_behavior_function: rejected`

`nx_relation_position_by_subject: not_locked`

## 5｜与“被动承接也可 nx”正例的区别

本案不能反过来误伤现有正向控制。

周瑞家的送宫花、赵云博望坡诱敌、孙悟空任弼马温，都没有主动求人，但三者共同满足：

```text
外部给方向 / 任务
→ 主体真实承接
→ 在执行窗口持续沿该方向推进
```

宝玉挨打则是：

```text
外部节点自行介入
→ 直接改变主体遭遇的现实结果
→ 主体没有把自己的当前行为接到该通道上续接
```

所以：

> **“没有主动求人”不妨碍 nx；但“主体根本未发生承接 / 续接”不能只因外部救援成功就判 nx。**

## 6｜最近邻排除

### nx vs 外部状态改变

别人替主体改变现实，不等于主体自己形成 nx 行为。

必须继续追踪：

> 主体有没有请求、承认、接受、等待、借用、服从或沿该接口继续。

### nx vs x

王夫人、贾母拥有的是她们自己的家内关系 / 上位作用接口，不是宝玉已经稳定掌握的 `x`。

### nx vs xn

宝玉没有搭救援流程、节点、人员与时序，因此不以 `xn` 主判。

### zx vs 被救成功

结果对主体有利，不等于结果来自主体自己的公开权能。

## 7｜拿掉测试

### 拿掉王夫人 / 贾母外部介入

宝玉受到的笞打很可能继续，说明外部保护接口对现实结果确实重要。

但这只能证明：

> **外部接口有效。**

不能证明：

> **主体本人激活了 nx。**

### 拿掉宝玉任何主动请求

原文事实链基本不受影响：王夫人和贾母仍可以因自己的判断、关系与权力主动介入。

这说明“主体主动接入”并不是本段现实救援发生的必要条件。

因此不能把外部救援成功反推为主体 nx。

## 8｜反向测试

真正的 nx 版本应更接近：

```text
宝玉意识到自己无法停止笞打
→ 主动请求丫鬟 / 门客向王夫人或贾母求援
→ 等待并沿该家内上位保护通道推进
→ 外部权限介入后停止处分
= nx 行为功能可显著上升
```

或者：

```text
王夫人明确给出下一步外部安排
→ 宝玉接受并持续沿该安排执行
= 被动承接型 nx
```

本段都没有。

## 9｜第三因素冻结

冻结：

- 王夫人与宝玉的母子感情强度；
- 贾母对宝玉的偏爱；
- 贾政是否下手过重；
- 忠顺王府、蒋玉菡、金钏等前史；
- 宝玉人物总体是否反封建、敏感或叛逆。

只保留：

1. 外部保护权限是否真实存在；
2. 外部节点是否真的改变结果；
3. 宝玉本人是否实际接入该通道。

结论仍稳定：

```text
外部接口 = true
结果改变 = true
主体通道激活 = false
```

## 10｜结论

本轮最窄可靠纪律：

> **外部权限 / 保护 / 救援接口真实存在，而且真的替主体改变了结果，仍不足以单独锁主体当前 nx 行为功能。**
>
> **nx 还需要主体在被测试对象层真实发生“承接 / 请求 / 等待 / 借用 / 服从 / 沿流程续接”等通道激活。**

因此本例是：

> **伪 nx 反例：外部救援真实生效，但主体未实际接入。**

本轮不锁人物稳定本体，不锁严格 `zx↔nx` 补关系，也不修改 L1、zx/nx 信息卡、准度卡或补卡。
