# strict zn↔x 复审｜探春理家：修正 x→zn 门后仍不足恢复 95

## 1｜本轮结论

本轮不是新增人物材料，而是用两个 L2 canonical 正例反测后形成的 `current-layer-specific-anchor-gap-v2`，重新复审探春理家。

上一轮把本例从 `99/95 evidence-locked` 降为 `99/93 deferred`，其中一部分理由依赖后来已被确认过严的门：

> 被测 x 必须是 zn 在整个现实中没有任何其他理论上可能替代的唯一载体。

这条门已被《辛德勒的名单》《V字仇杀队》两个 L2 正例连续打穿，所以本轮撤销它。

但撤销过严门以后，本例仍有一个独立、未被修正的关键问题：

> **当前文本还不足 95% 证明第55回“按旧例拒绝私情”、第56回“削减重复支出并重构园务”的最终排序来自同一个窄 `zn`，而不是旧例、受托职责、公开治理信誉、节用与效率等第三因素分别在起作用。**

因此本轮当前判断为：

```text
事实 99
分类 94
L4 deferred
strict zn↔x = 未恢复
```

这不是继续沿用旧 93 的原理由，也不是自动恢复 95；而是：

```text
旧的 x→zn 过严门 → 撤销
x→zn current-layer anchor gap → 重新变得可支持
zn 独立性 / 原则同一性 → 仍不足 95
```

## 2｜对象层继续锁定

被测 `x` 仍只锁：

> **王夫人授权理家窗口中，探春对荣府日常公账、赵国基丧银与部分园务开支的现实增减 / 停支 / 改制处分边界。**

不锁：

- 整个荣国府最终家政权；
- 王夫人的上位最终权限；
- 探春永久人物本体；
- 所有公共资源。

第55回事实继续支持局部 `x=true`：

1. 李纨先拟赵国基丧银四十两；
2. 探春把对牌叫回，要求先查旧账；

5. 平儿转达凤姐“再添些也使得”，探春仍拒绝借当前公账处分做人情；
6. 第56回她又能直接推动蠲免重复学费、脂粉买办，并重组园务管理。

## 3｜第55回：zn 候选很强，但旧例 / 职责仍是现实第三因素

为了避免把被测 `x` 偷写进原则，本轮先用不引用当前公账权限的语言定义候选 `zn`：

> **公共 / 共同资源的分配，不应因为私亲、人情或自身便利而被任意扭曲；判断应能对共同规则和共同利益公开解释。**

这个定义比旧版“当我受托处分公账时……”更干净，不再把被测 `x` 直接嵌入 `zn`。

第55回确实有支持：

- 赵姨娘的私亲压力真实存在；
- 凤姐方面给出“再添些也使得”的宽松口径；
- 多给并非现实不能做，而是探春主动拒绝；
- 探春把自己与赵国基的关系重新放回可核验旧例，而不是按私亲单独加码。

这些说明当前行为不只是“没有能力偏私”。

但文本同时给出强第三因素：

```text
查旧账
→ 按家里 / 外头旧例
→ 强调不按理会被下人笑话、以后难见凤姐
```

所以第55回的当前结果仍能被以下结构部分解释：

```text
旧例
+
受托理家职责
+
公开治理信誉 / 下属观察
→ 拒绝破例加码
```

这不足以否定内部 `zn`，但仍削弱“纯内部原则独立完成最终排序”的 95% 锁定。

## 4｜第56回：真正加强 zn 独立性的地方

第56回比第55回更重要，因为探春不是机械沿用旧例，而是在主动检查并取消已经存在的重复支出：

- 发现姑娘们已有月银，又另有头油脂粉买办开支，认为两头花钱且东西不好，主张取消重复买办；
- 这些便利直接涉及探春自己和姐妹们，并不是只削减别人利益；
- 她进一步提出园务承包 / 专人负责，让园子同时减少浪费、增加维护，并使老妈妈获得额外收益。

这说明：

> 探春不是只在“旧规说二十两”时才会保持边界；她也会主动检查现行制度中对共同资源不合理、重复、低效的部分，甚至削减自己所属群体的既有便利。

因此本轮撤回旧审计中的一个过度悲观判断：

```text

```

更准确应写：

```text

```

## 5｜为什么仍然不是 95：原则同一性还没压死

第56回虽然增强内部原则，但它最直接支持的可能是：

- 节用；
- 避免重复支出；
- 提高治理效率；
- 让公共资源发挥作用；
- 受托管理责任；
- 兼顾园中老妈妈利益的治理设计。

第55回的主冲突则是：

- 私亲 / 人情；
- 旧例 / 可核验规则；
- 管理者公开信誉。

两段可以被统一解释为较宽的：

> **公共资源治理应压过私情和低效，并能够公开解释。**

但若把它压窄成：

> **公私分账 / 不徇私**

第56回就不再是完全同型；若把它压宽成：

> **公共资源治理原则簇**

又需要进一步证明这一宽原则在不同场景中稳定完成同一种最终排序，而不是多个治理目标并列。

所以目前最小分歧仍是：

```yaml
criterion_identity_across_contexts: contested
zn_independence: strong_but_below_95
```

但是 strict 仍然必须先要求 `zn` 独立达到 ≥95；当前这一前置端点还没过，所以不能仅凭 `x→zn` 改善就恢复 strict。

## 8｜第三因素冻结结果

本轮逐项冻结：

### 旧例

不能完全冻结掉。

第55回仍高度依赖查旧账与按例裁处。

### 王夫人授权 / 受托职责

不能完全冻结掉。

它解释了为什么探春必须处理这些事务，但不足解释为什么她主动削减涉及自己与姐妹便利的重复支出。

### 凤姐评价 / 下属观察

能解释第55回“管理信誉”压力的一部分，但不能充分解释第56回主动兴利除弊。

### 治理效率

第56回的强第三因素，不能直接视为“公私分账”同义词。

所以综合判断：

```text
没有单一第三因素能解释全部场景
但多个不同第三因素仍可以分别解释不同场景
→ 同一窄 zn 仍未压到 95
```

## 11｜恢复探春到 ≥95 需要什么

最值钱的不是再找更多“探春很会理家”的场景，而是找一个最小差异：


或者找到另一场景：

> 探春在没有当前公账处分权、没有制度强制和声望收益时，仍把同一“公共资源不可徇私”原则用于现实判断。
