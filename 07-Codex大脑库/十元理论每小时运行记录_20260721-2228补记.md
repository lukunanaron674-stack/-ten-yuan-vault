## 端点、变量、阶段与体量

### 源端点 nz

必须先有真实共同时间、关系余温、不愿承认关系已经结束，以及可等待、回返或继续靠近的位置。一次好感、孤独、被照护、被迫同住和现实依赖不够。

### 目标端点 nx

主体原本必须拥有真实可选路线与否决位置；方向或行动通道由关系对象给出；主体随后不占最终决定位置并沿该方向推进。无权决定、年龄监护、职位服从和被威胁服从不够。

### 被改变变量

- 独自定向的必要感；
- 方向决定位置的认领强度；
- 替代路线与否决位置；
- 对关系对象所给路线的接受度；
- 跟随是否只发生在该段关系中；
- 拿掉关系余温后，方向让位是否消失。

### 成立阶段与体量

```text
nz 已真实成立
→ 关系对象给出明确方向或通道
→ 主体原本有平等选择空间
→ 主体因不愿关系结束而暂时降低方向认领
→ nx 在状态层／关系层上升
```

低体量为一次短程同行；中体量为在一段关系中反复沿对方方向；高体量接近人生方向让渡，必须优先排除稳定 nx、x/zx 控制与制度身份。

## 候选机制

### 候选A：可信停靠降低独自定向负担

```text
关系仍有可信余温与回返位置
→ 主体不再认为每一步都必须独自决定
→ 暂时接受关系对象给出的路线
→ nx 状态上升
```

理论后果：只改变“独自定向的必要感”，不改造能力、意志或稳定人物本体。

### 候选B：为了保留关系主动让出方向

```text
主体不愿关系结束
→ 判断继续争夺方向会使共同位置断裂
→ 主动减少决定与否决
→ 沿对方方向继续
```

理论后果：若成立，作用源是关系保留，不是对方压位。必须拿掉威胁、命令、职位与资源依赖。

### 竞争解释C：现实承载冒充关系余温

住房、安全、照护、金钱与资源使主体接受安排时，优先检查 `n/x/xn`，不是纯 `nz 生 nx`。

### 竞争解释D：共同方向本就存在

任务、使命、职业、监护或既定路线先规定方向时，关系余温最多强化同行，不能证明生成 `nx`。

## 正例候选

### 1. 《指环王》山姆与弗罗多进入末日火山阶段

- nz：长期同行后不愿放弃彼此；
- nx候选：山姆不改写最终路线，沿弗罗多与魔戒使命继续；
- 限制：强 `zn` 守护意义、强 `xn` 任务路线、强 `n` 照护承载。

拿掉使命与照护后，无法证明关系余温独立生成方向让位，只能作复合候选。

### 2. 《末路浩劫》男孩跟随父亲向南

- nz：父子关系是灾后唯一可信停靠；
- nx候选：路线与风险判断由父亲决定；
- 限制：年龄、监护、`n` 保护和 `xz` 生存压力过强。

男孩原本没有平等方向位置，不能作为纯案例。

### 3. 《爱在日落黄昏时》杰西与席琳重逢后的同行候选

- nz：旧关系在多年后仍有余温，双方不愿会面立即结束；
- nx候选：杰西延后既有离开安排，沿席琳的城市路线继续交谈；
- 支持点：关系余温确实延长共同方向；
- 限制：双方共同协商、相互提出路线，缺少一方明确不占方向位置。

该案例更像 `nz` 延长共同时间，而非 `nz` 生成 `nx`，因此不通过。

## 反例

1. 被照护者接受医生安排：专业权限、`n` 或 `xn`。
2. 员工因喜欢老板而执行任务：职位已给出方向。
3. 恋人以分手威胁服从：`zx/x` 强制。
4. 孩子跟随父母：年龄与监护关系。
5. 走投无路接受陌生人带路：`xz` 临界与现实通道。
6. 朋友关系深厚但各自坚持路线：`nz` 成立而 `nx` 不升。
7. 主体原本就是稳定 `nx`：关系只提供显影。
8. 因住所、金钱、安全留下：优先检查 `n/x`。
9. 双方共同协商形成新路线：共同决定，不是方向让位。
10. 为完成共同使命跟随：方向来自 `zn/xn`，不是关系余温。

## 最近邻排除

- 与 `n`：`n` 改变现实能否被接住；本候选改变谁占方向决定位置。
- 与 `x/zx`：对方要求、威胁、占位或控制时，是主动压位，不是主体因余温让位。
- 与 `xn`：既定任务、规则和身份义务已给方向时，不由 `nz` 生成。
- 与反向 `nx 生 nz`：长期跟随可能形成共同时间与不愿结束；改变的是关系余温，不是方向认领。

## 动态链后果

若候选成立：

```text
我仍不愿这段关系结束
→ 因此不再坚持每一步都由我决定
→ 在这段关系中暂时沿你的方向继续
```

改变的是“独自定向的必要感”，不机械生成依赖、服从、无能、稳定 nx 或永久关系。

本轮新增的关键排除是：`nz` 延长共同时间、让双方继续同行，并不等于其中一方失去或让出方向决定位置。共同路线必须与 `nx` 的单方方向让位分开。
