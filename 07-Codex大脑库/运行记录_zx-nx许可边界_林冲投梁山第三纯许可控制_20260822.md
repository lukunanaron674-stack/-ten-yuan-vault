# 林冲投梁山｜第三个纯许可/准入权限型 nx 控制

## 1｜剧情事实

林冲遭官府追捕后，希望寻找长期安身处，并持柴进荐书投梁山。这个“我要安身、我要入梁山”的目标并不是王伦替他形成的。

真正外置的是梁山准入权：王伦先明确推拒林冲；在朱贵、杜迁、宋万等劝说后，王伦仍没有直接放行，而是设置“投名状”条件，限定三日。原文明确规定：三日内取得投名状则容其入伙；三日内没有则不收。林冲接受这个条件，随后连续下山执行。

因此当前结构是：

```text
主体已有目标：加入梁山安身
↓
准入权不在主体
↓
王伦真实拒绝
↓
王伦附加三日投名状条件
↓
林冲实际承接并执行
↓
是否入伙仍由该准入接口决定
= nx 许可/准入关系功能
```

## 2｜nx 判断

`nx_permission_relation_function: evidence-locked`

关键不是“林冲求人一次”，而是：

1. 梁山成员准入权真实属于王伦这一外部节点；
2. 王伦表现出真实否决能力，而不是形式盖章；
3. 王伦还能附加高成本准入条件并限定期限；
4. 林冲不能绕过该节点单方面使“我成为梁山成员”生效；
5. 林冲没有夺取准入权，而是实际沿条件继续推进。

这完全符合 nx v2.5 的关系功能：主体有自己的方向，但关键许可/权限在别人手里，主体承认并沿外部接口推进。

只锁当前行为功能与关系位置，不锁林冲稳定人物本体为纯 nx。

## 3｜zx 判断

`zx_in_narrow_stage: rejected_as_primary`

王伦拒绝后，林冲没有公开夺取梁山准入处分权，也没有迫使梁山组织围绕新增的林冲决定接口重排。武力、英雄身份、被追捕压力、愿意杀人取投名状都不能替代 zx 的“公开显权 + 外部响应 + 决定范围扩大”硬门。

后续火并王伦属于另一个阶段、另一个对象层，不能倒灌回来。

## 4｜nx vs xn 最近邻

投名状确实包含“三日”“下山寻找目标”等流程与节点，但这些决定性节点由王伦设置，不是林冲主动搭建。

```text
别人设准入条件、期限，我照条件推进
→ nx

别人只给“想办法证明资格”，我自己设计期限、对象、路径与验证流程
→ xn 上升
```

因此本阶段不以 xn 主判。

## 5｜拿掉测试

### 拿掉柴进荐书
只要仍保留“林冲申请加入 + 王伦掌握真实准入权 + 王伦可拒绝/附条件 + 林冲实际承接”，纯许可型 nx 仍成立。荐书只是进入接口的关系路径。

### 拿掉投名状具体内容
只要王伦仍拥有真实的准/不准权，林冲仍必须经过该节点，许可型 nx 仍成立；投名状只是把真实否决与附条件能力显得更硬。

### 拿掉王伦真实否决权
如果王伦无论说什么都不能阻止林冲入伙，或批准与否完全不影响成员状态，则许可型 nx 的核心证据显著下降。

## 6｜反向测试

### 形式审批假样本
```text
王伦名义签字
→ 实际无权拒绝、附条件或改变结果
→ 林冲不经过他也会自动成为成员
= 不足以锁高纯许可型 nx
```

### 转 zx
若王伦拒绝后，林冲当场夺取山寨准入权、改写规则，并迫使梁山围绕其新增决定接口运行，才检查 zx。

### 转 x
若林冲本来就稳定拥有梁山成员准入处分权，只是在正常调用已有权限，则优先检查 x。

## 7｜第三因素冻结

冻结以下因素后结论不变：
- 高俅追捕与悲情主题；
- 林冲武艺；
- 王伦人格好坏；
- 柴进与林冲情义；
- 投名状最终是否完成；
- 后续火并王伦。

只问：谁掌握准入、该节点能否真实拒绝/附条件、主体是否实际沿该接口推进。

## 8｜跨作品最小差异

现有纯许可高纯控制形成三部独立作品：

1. 《西游记》唐僧女儿国倒换关文：女王掌握国家御印确认权；主体已有西行目标/办法，但必须取得正式许可。
2. 《红楼梦》贾芸谋差事：凤姐掌握派差/资源启用权，且真实表现出拖延、拒绝当前差事、后再批准的能力。
3. 《水浒传》林冲投梁山：王伦掌握成员准入权，先拒收，再附“三日投名状”条件；林冲实际承接。

三例共同支持：

> **纯许可型 nx 不要求许可方同时提供完整方案。只要外部节点真实拥有可拒绝、拖延或附条件的准/不准权，主体无法绕过该节点使同一制度/组织结果生效，并且主体实际接入续接，许可本身即可形成高强 nx 关系功能。**

同时继续保留：

> 权限理论上在外 ≠ nx 自动激活；主体必须在当前对象层真实接入并沿该接口推进。
