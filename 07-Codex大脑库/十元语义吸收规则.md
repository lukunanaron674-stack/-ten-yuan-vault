# 十元语义吸收规则

## 吸收目标

Codex 学十元，不是背词表，而是学会判断：

```text
谁先动
作用到谁
中间有没有桥
桥是否污染
力落到哪里
最后进入哪个主题仓
```

## 判断顺序

1. 先明确判断对象：人物本体 / 状态 / 行为 / 光影 / 场景 / 时间关系。
2. 判断十元位置：zx / x并z / zn / z / n / nz / xn / nx / xz / x。
3. 判断三元比例与质地：x / z / n 在该十元中各占多少。
4. 判断关系运动：生 / 克 / 补 / 压 / 激活 / 包装 / 结算 / 桥接 / 污染桥。
5. 判断动态链结果：回收 / 崩坏 / 扭曲 / 断链 / 反噬 / 换芯 / 循环。
6. 五大主题归仓：时间 / 本体 / 空间 / 因果 / 命运。

> 三元与十元是并列校验，不是“三元派生十元”的父子关系。

## 三条硬规则

1. 起手只看第一推动力，不看结局。
2. 承载位是功能位，不能默认等于 n。
3. 五大主题是入仓结果，不是起手证据。

## F12 采样时必须问

```text
这条关系为什么成立？
有没有更少污染的桥？
如果换一个链条结果，会变成什么母型？
这个案例能不能复用到创作？
它补了哪个空缺？
```

## 最小材料

每个案例最少要有：

- 作品 / 场景 / 角色关系。
- 判断对象。
- 稳定人物锚（人物分析时）。
- 初始力。
- 第一被作用十元。
- 三元比例与质地。
- 关系类型。
- 动态链公式。
- 分叉点。
- 五大主题落点。
- 误判风险。

## 一句话

十元语义的核心不是分类，而是力在结构里的转向。

# 三元底色·正式校正版（2026-07-16）

正式入口：[[../01-十元系统/00-三元底层定义_醒耐z_v0.2]]

## z：精神个体寻求认可

```text
精神个体面对庞大的物质客观世界
→ 感到自身渺小
→ 需要认可主体看见、回应、确认自己
→ z
```

认可主体可以是个人、公众、已故对象、神、国家、历史、想象观众或自己。

> **z = 我是否被一个认可位置看见并确认。**

舞台、荣耀、宣言、追光和被看见是外部形态，不是底层定义。

## x（醒）：具体物象与物质关系

- x 关注具体物品、物质、所有权、功能、局部因果和眼前利益。
- 聚焦对象使变量和边界更清楚，因此人物常聪明、冷静、逻辑清晰。
- 当 x 落到人物本体时，自私是稳定人物层结果。
- 自私不外推给 x 光影、场景和物件。

> **人物 x：看物，因此清楚，也因此自私。**

## n（耐）：精神、整体与关系

- n 关注人与人、群体与群体、国家与国家、历史、精神与整体结构。
- n 常包含理解、包容和协调三种能力。
- n 不等于温柔或善良，冷酷人物也可能以整体关系为核心。
- 同时处理多方关系时，具体物质逻辑可能较弱，思维显得空、散、乱。

> **耐看精神与关系，整体理解强，但物质逻辑不如醒清楚。**

## 小 / 大只能作辅助体感

- x 常显得范围窄、边界清楚。
- n 常显得范围广、变量更多。
- 这只是辅助理解，不是正式定义或等级。
- 不得建立“小整体必须服从大整体”的 n 规则。
- 此类取舍不是 n 的核心问题。

## 楚庄王弓

楚庄王弓不归 z。

- x 关注具体弓的物质状态、位置和所有权。
- n 改变弓所在的精神与关系框架：楚人、人类、自然、空。

> **x 盯住物本身，n 改变物所在的关系框架。**

区域变化只用于帮助理解，不作为 n 的正式计分器。

## 三元最小关系式

```text
x：精神个体 ↔ 具体物象与物质关系
z：精神个体 ↔ 认可主体的看见与确认
n：精神个体 ↔ 精神、整体与多方关系
```

# z 与 zx 最新纠正

正式入口：

- [[【z信息量卡v2.2】]]
- [[../01-十元系统/03-十元准度卡/zx_张扬醒目与权能扩张补丁_v0.1]]

## z

```text
存在 / 能力 / 作品 / 发现
→ 被认可主体看见与确认
```

## zx（张扬醒目）

```text
学习客观规律
→ 形成有效改变
→ 成果显现与认可
→ 能力和权能扩大
```

- 对话中的“脏醒”是“张扬醒目”的语音误识别。
- “脏醒”不是新类型。
- 不得由错词创造 z+x、污染或异化分支。
- 主观世界不能替代客观世界，只能扩大改变客观世界的能力。

# 时间切片与剧本人物锚

正式入口：[[../01-十元系统/03-十元准度卡/02-时间切片与剧本人物锚定协议_v0.1]]，正文版本 v0.2。

## 现实

现实人物会随时间和对象切换主导观察方式，但一个具体时间点通常只有一种方式占主导。

## 剧本

剧本人物应锁定：

```text
主十元
+ 副十元
+ 核心对象
+ 选择方式
+ 关系方式
```

例如 `xz+nz` 在不同压力下可以分别显出 xz 或 nz 的一面，但仍是同一个组合。

人物成长默认改变状态、行为、关系、能力和自我认识；默认不改变主十元、副十元和核心组合。

> **角色弧光优先解释为暴露本性，不是替换本性。**

# 判断对象决定证据优先级

- 人物本体优先看动机、选择和长期结构。
- 单张插画优先看光影、颜色、氛围、构图与空间关系。
- 漫画电影优先看时间点变化与关系运动。
- 同一画面可以是“人物 zn + 光影 xz”，属于不同对象层级，不是冲突。

## 禁止继续吸收的旧定义

- z = 楚王弓。
- n = 精神个体。
- x = 现象之流。
- 大范围自动等于更纯 n。
- n 天然服从更大整体。
- 人物成长等于更换主副十元。
- “脏醒”是正式类型。

上述内容均已被用户正式推翻。
