# 十元语义吸收规则

## 吸收目标

Codex 学十元，不是背词表，而是学会判断：

```text
谁先动
作用到谁
中间有没有桥
桥是否污染
力落到哪里
最后进入哪个主题仓
```

## 判断顺序

1. 先明确判断对象：人物本体 / 状态 / 行为 / 光影 / 场景 / 时间关系。
2. 判断十元位置：zx / x并z / zn / z / n / nz / xn / nx / xz / x。
3. 判断三元比例与质地：x / z / n 在该十元中各占多少。
4. 判断关系运动：生 / 克 / 补 / 压 / 激活 / 包装 / 结算 / 桥接 / 污染桥。
5. 判断动态链结果：回收 / 崩坏 / 扭曲 / 断链 / 反噬 / 换芯 / 循环。
6. 五大主题归仓：时间 / 本体 / 空间 / 因果 / 命运。

> 三元与十元是并列校验，不是“三元派生十元”的父子关系。

## 三条硬规则

1. 起手只看第一推动力，不看结局。
2. 承载位是功能位，不能默认等于 n。
3. 五大主题是入仓结果，不是起手证据。

## F12 采样时必须问

```text
这条关系为什么成立？
有没有更少污染的桥？
如果换一个链条结果，会变成什么母型？
这个案例能不能复用到创作？
它补了哪个空缺？
```

## 对 Codex 有用的最小材料

每个案例最少要有：

- 作品 / 场景 / 角色关系。
- 判断对象。
- 初始力。
- 第一被作用十元。
- 三元比例与质地。
- 关系类型。
- 动态链公式。
- 分叉点。
- 五大主题落点。
- 误判风险。

## 一句话

十元语义的核心不是分类，而是力在结构里的转向。

# 三元底色·正式校正版（2026-07-16）

正式入口：[[../01-十元系统/00-三元底层定义_醒耐z_v0.1]]

## z：精神个体需要另一个精神个体的认可

```text
精神个体面对庞大的物质客观世界
→ 感到自身渺小
→ 需要另一个精神个体看见、回应、认可自己
→ z
```

- z 的根不是楚王弓。
- z 不是单纯追光、执念或表演欲。
- 舞台、荣耀、宣言、被看见，是 z 的外部形态。
- z 的核心关系是“一个精神个体是否被另一个精神个体确认”。

> z = 你是否看见并承认我的精神存在。

## x（醒）：具体物象，小而清

- x 关注具体物品、物质、所有权、功能、局部因果和眼前利益。
- 视野区域小，变量少，边界清楚，因此思考常表现为聪明、冷静、逻辑清晰。
- x 容易显得自私和狭隘，因为区域之外的人、精神与大关系会被弱化。
- x 更接近理科式切分和分析。

```text
范围小
→ 变量少
→ 边界清楚
→ 逻辑强
```

> 醒看物，所以窄而清。

## n（耐）：大区域与大关系，大而空

- n 不锁死在单个物品上，更关注人与人、群体与群体、国家与国家、历史与精神整体的关系。
- 区域大，变量多，边界模糊，因此思考容易显得空、散、乱，具体物质逻辑较弱。
- n 的优势是宏观、人际、社会关系与整体理解。
- n 更接近文科式整体与关系思考。

```text
范围大
→ 变量多
→ 多重关系同时在场
→ 局部逻辑变弱，整体容纳变强
```

> 耐看关系，所以大而乱。

## n 与 x 的核心交换

```text
x：牺牲广度，换取清晰
n：牺牲清晰，换取广度
```

这不是善恶差别，也不是聪明与愚笨的差别，而是认知区域大小带来的结构代价。

## 楚庄王弓：n 与 x 的教学案例

楚庄王弓不再归 z。

```text
具体的弓：x
楚国区域：n扩大一层
全人类区域：n继续扩大
自然区域：n继续扩大
空：最高n，区域最大
```

- x 看具体弓是否离开原主人。
- 楚庄王把区域扩大到楚国。
- 孔子把区域扩大到全人类。
- 孟子把区域扩大到自然与腐化循环。
- 高僧以“空”容纳并消解得失、归属和对象区分，是最高 n。

## 三元最小关系式

```text
x：精神个体 ↔ 具体物象与物质关系
z：精神个体 ↔ 另一个精神个体的看见与认可
n：精神个体 ↔ 更大区域与整体关系
```

## 判断对象决定证据优先级

- 人物本体优先看动机、选择和长期结构。
- 单张插画优先看光影、颜色、氛围、构图与空间关系。
- 漫画电影优先看时间点变化与关系运动。
- 同一画面可以是“人物 zn + 光影 xz”，这属于不同对象层级，不是冲突。

## 禁止继续吸收的旧定义

- z = 楚王弓。
- n = 精神个体。
- x = 现象之流。
- 楚王弓用于证明 z 有边界。

上述对应关系已被用户正式推翻。
