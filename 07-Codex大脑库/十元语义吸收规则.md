# 十元语义吸收规则

## 吸收目标

Codex 学十元，不是背词表，而是学会判断：

```text
谁先动
作用到谁
中间有没有桥
桥是否污染
力落到哪里
最后进入哪个主题仓
```

## 判断顺序

1. 三元底色：x / z / n 的最低语义。
2. 十元结构：zx / x并z / zn / z / n / nz / xn / nx / xz / x。
3. 关系运动：生 / 克 / 补 / 压 / 激活 / 包装 / 结算 / 桥接 / 污染桥。
4. 动态链结果：回收 / 崩坏 / 扭曲 / 断链 / 反噬 / 换芯 / 循环。
5. 五大主题归仓：时间 / 本体 / 空间 / 因果 / 命运。

## 三条硬规则

1. 起手只看第一推动力，不看结局。
2. 承载位是功能位，不能默认等于 n。
3. 五大主题是入仓结果，不是起手证据。

## F12 采样时必须问

```text
这条关系为什么成立？
有没有更少污染的桥？
如果换一个链条结果，会变成什么母型？
这个案例能不能复用到创作？
它补了哪个空缺？
```

## 对 Codex 有用的最小材料

每个案例最少要有：

- 作品 / 场景 / 角色关系。
- 初始力。
- 第一被作用十元。
- 关系类型。
- 动态链公式。
- 分叉点。
- 五大主题落点。
- 误判风险。

## 一句话

十元语义的核心不是分类，而是力在结构里的转向。
