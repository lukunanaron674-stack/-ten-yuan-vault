## 源端点、目标端点与变量

### zx 源端点

1. 甲的力量公开进入现实；
2. 甲的决定范围、影响位置或等级位置扩大；
3. 他者或旧秩序被迫围绕甲重新反应；
4. 不是普通善举、演讲、坚持或完成任务。

### zn 目标端点

乙必须在甲显权后新增或显著增强：

1. 对某一原则的内部意义认领；
2. 即使甲不在、没有奖励、没有群众和成功保证，仍坚持；
3. 坚持对象是原则本身，不是英雄本人、群体身份或胜利阵营；
4. 拿掉宣传、纪念与从众后仍成立。

### 被改变变量

- 乙对原则的内部确定度；
- 无监督时仍按原则行动的持续度；
- 原则与英雄个人的可分离度；
- 拿掉胜利结果后是否仍认领原则；
- 是否从“他很强”变成“这件事即使没人做，我也必须做”。

### 成立阶段、体量与显影条件

- 成立阶段：甲已公开显权，乙此前无稳定 zn；
- 低体量：单一见证者形成阶段性内部意义；
- 中体量：一组见证者在英雄离场后仍按原则行动；
- 高体量：原则脱离英雄、胜利与制度奖励，成为共同体内部不可背弃的意义；
- 显影条件：必须观察英雄缺席、无奖励、逆风或失败后的持续选择。

## 候选机制

### 候选A：原则可行性被显权证明

```text
甲以 zx 把原则公开推入现实
→ 乙看见原则并非空话
→ 乙开始把原则认作值得坚持的内部意义
→ zn上升
```

理论后果：zx 提供“原则能够进入现实”的存在性证据。

问题：zn 原则上不依赖成功证明；若乙必须先看到成功才相信，更接近 z 的结果确认或工具理性。

### 候选B：公开承担代价使原则与个人分离

```text
甲显权并公开承担位置、利益或生命代价
→ 乙看见甲并非借原则谋利
→ 英雄个人从原则前退开
→ 乙在甲缺席时仍坚持原则
→ zn上升
```

理论后果：真正作用点不是胜利，而是代价取消“表演或谋利”的解释。

问题：承担代价首先显影甲既有 zn；乙的变化仍可能来自 z、n、nz 或关系感动。

### 候选C：决定空位被原则继承

```text
甲以 zx 压过旧秩序并离场
→ 现实留下决定空位
→ 乙不继承甲的权位，而继承其原则
→ 无奖励时仍按原则行动
```

理论后果：生成点发生在甲离场之后，而不是群众围绕甲时。

问题：若乙只是接任职位或沿组织流程继续，更接近 x、xn 或 nx。

## 最近邻排除

- `zn生zx`：甲先有内部意义，再公开显权；源人物自身通常更符合这一方向；
- `z`：被英雄看见、认可或鼓励，改变的是重要认可位置；
- `x并z`：英雄称号、旗帜、纪念海报和共同身份是公开壳；
- `n`：共同体和长期照护可承载意义，但不等于生成内部意义；
- `xn`：教育、传播、训练和制度使原则稳定运行，不是 zx 直接生成；
- `nx`：沿英雄路线行动不等于无奖励仍坚持原则。

3. 拿掉乙原有信念，若变化消失，说明只是既有 zn 显影；
4. 拿掉甲本人，只保留原则，乙仍坚持，才能证明原则与英雄分离；
5. 拿掉组织、纪念、教育与群体监督，乙仍行动，纯度才提高；
6. 拿掉关系感动与个人恩情，乙仍坚持普遍原则，才排除 nz 与 n；
7. 若甲必须持续命令、监督或奖励乙，目标更接近 nx、xn 或 z。
