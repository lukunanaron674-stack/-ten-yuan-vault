# 十元质量审计 v1.0

## 审计方法

交叉检查同一十元在不同角色中的定义是否一致、是否模糊。

## x（欲望/求生/暴力）

| 角色 | 判断 | 一致性 |
|------|------|--------|
| 凌敏 | x：求生欲 | ✅ 清晰 |
| 刘建明 | x：欲望（想做好人/活命） | ✅ 一致 |
| 玉娇龙 | x：被压抑的野性欲望 | ✅ 一致 |
| 聂隐娘 | x：刺客本能 | ✅ 一致 |
| 杰克/泰勒 | x：暴力欲望分裂 | ✅ 一致 |
| 安东·齐格 | x：纯粹暴力 | ✅ 一致 |
| 威尔 | x：童年创伤保护壳 | ⚠️ 与其他x不同——更像是 xn/xz 的混合 |

## nz（归属/停靠/温柔接住）

| 角色 | 判断 | 一致性 |
|------|------|--------|
| 艾米丽 | nz：给予型温柔 | ✅ |
| 陈永仁 | nz：想做好人的归属 | ✅ |
| 杰克·特威斯特 | nz：想要共同生活 | ✅ |

## n（承载/日常/稳定）

| 角色 | 判断 | 一致性 |
|------|------|--------|
| 山音麦 | n：用现实承载关系 | ✅ |
| 帆高 | n：为阳菜撑出世界 | ✅ |
| 恩尼斯 | n：承载关系但残缺 | ✅ |
| 千寻 | n：劳动承载 | ✅ |
| 福贵 | n：承载一切失去 | ✅ |
| 苏菲 | n：日常承载所有人 | ✅ |
| 吕途 | nz（存疑→应改为n） | ⚠️ |

## 建议修正

1. **吕途**：当前 nz+xz，建议改为 n+xz。他的核心是承载母亲和凌敏，不是归属感。"托付"是 n 的一种形态。
2. **威尔**：当前 zn+x，x 的定义略有偏离——他的创伤壳更像是 xz（内在漂流）而非 x（向外欲望）。可考虑 zn+xz。
3. **玉娇龙+聂隐娘**：两人都判为 x+辅助，但一个外向反叛一个内向克制——建议在动态链中更好区分 x 的不同形态。

## 总体评价

- 48张卡中的十元核心判断基本一致
- x/nz/n/xn 四个最常用十元定义清晰
- zn（意义追问）使用偏少，可能被低估——建议在更多角色中考虑 zn 的可能性
- x并z 在不同角色中定义统一（环境/外壳/美学容器）
