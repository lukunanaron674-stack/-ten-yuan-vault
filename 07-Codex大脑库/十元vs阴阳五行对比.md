# 十元 vs 阴阳五行｜旧比较框架已退役

旧版把十元与阴阳五行当成两套系统进行横向比较，并使用了已失效映射：

```text
x并z = 阴木
nz = 阴土
nx = 阴金
x = 阴水
```

这些内容从 2026-08-02 起停止调用。

## 当前唯一口径

```text
五行就是十元。
十元就是木、火、土、金、水各分阴阳后的十个直接位置。
同一五行的阴阳十元首先是相反两极。
```

固定映射：

```text
木：阳木zx ↔ 阴木nx
火：阳火zn ↔ 阴火x
土：阳土n  ↔ 阴土x并z
金：阳金xn ↔ 阴金z
水：阳水xz ↔ 阴水nz
```

## 使用边界

- 不再讨论“传统五行与十元是否相似”，因为十元本身就是阴阳五行十位；
- 传统颜色、季节、脏腑、五味等映射不能直接覆盖十元信息卡；
- 情志不能直接当人物情绪标签；
- 阴阳相反轴不自动等于互补、转化、生、克或补；
