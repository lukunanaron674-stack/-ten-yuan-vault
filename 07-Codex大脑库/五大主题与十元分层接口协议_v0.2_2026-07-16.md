# 五大主题与十元分层接口协议 v0.2

## 1. 本轮正式修正

```text
Legacy（旧十元表达）

n 补克 nx

↓

Current（正式主题表达）

因果克制空间
```

旧表达停止作为现行十元关系、人物判定或动态链结论使用，仅允许在迁移说明中出现。

“因果克制空间”属于五大主题形成后的主题级克制关系，不自动等于某一条固定十元关系。

## 2. z、n、x 的关系功能

```text
z = 补 / 补合
n = 生 / 生发
x = 克 / 克制
```

这里描述的是关系功能与观察顺序，不是在建立三元与十元的父子派生关系。

三元与十元仍然并行判断：

- 三元提供高概括的关系与结构判断；
- 十元提供具体对象、状态、行为、场景、时间结构与实现机制的细粒度判断；
- 不得由三元唯一反推十元，也不得由十元唯一反推三元。

## 3. 五大主题的形成机制

五大主题不是把两个十元标签简单相加，也不是把十元改名成主题。

其正式理解为：

```text
双方各自成立
↓
由 z 进行补合
↓
双方被合并为一个更高层次的符号化整体
↓
五大主题成立
↓
再观察主题之间的 n 生与 x 克
```

因此：

```text
z：主题形成之前的补合机制
n、x：主题形成之后的生克关系机制
```

“五大主题像五行一样只有生克”，指的是五大主题作为高级符号成立以后，主题与主题之间主要观察生与克；不表示 z 被排除出体系，更不表示补合没有作用。

相反，没有前置的 z 补合，双方仍只是双方，还没有形成完整的主题符号。

## 4. 主题公式的正确读法

例如：

```text
因果：zx + nx
空间：x并z + n
```

当前公式用于标记被补合的双方及主题位置，不得把“+”理解为普通算术加法，也不得把主题直接还原成两个十元标签的机械总和。

正确顺序是：

1. 先分别判断双方是否成立；
2. 再判断双方能否通过 z 补合为一个完整主题；
3. 主题成立后，再进入五大主题的生克关系盘；
4. 最后用十元与动态链解释具体人物、状态、行为、场景和时间结构如何实现该主题关系。

禁止跳步：

```text
看到主题名称
→ 倒推固定十元对子

看到两个十元标签
→ 不经补合直接宣布主题成立

看到主题级生克
→ 把人物本体改判成某个主题或十元
```

## 5. 五大主题与十元并行协作

```text
五大主题：
负责高级归类、主题重心与主题级生克。
回答“整体在处理哪一种高层关系”。

十元：
负责具体对象与实现机制。
回答“具体是谁、处于什么状态、做了什么、在什么场景和时间结构中发生”。

动态链：
负责具体对象之间怎样生、克、补，以及不同阶段如何显影、退隐和转位。
```

所以不得写成：

```text
五大主题负责一切，十元只负责附注。
十元可以直接替代五大主题。
某条十元关系必然等于某条主题关系。
五大主题形成后就不再需要十元分析。
```

更准确的工作分配是：

```text
五大主题很好归类。
十元很好具体化。
动态链很好描述过程。
三元提供高概括关系判断。
四者共同分析，但不互相替代。
```

## 6. 因果克制空间的分层表达

```text
主题形成：
因果双方先经 z 补合，形成“因果”主题。
空间双方先经 z 补合，形成“空间”主题。

主题关系：
因果 x 空间
即：因果克制空间。
```

其具体实现可以不同，例如：

```text
既定后果压缩人物的选择空间。
责任链封闭逃离路径。
已经发生的结果使原有容器无法继续承载。
人物的具体行为触发后果，外部空间随之收缩。
```

这些只是主题级结构描述。具体案例仍必须分别判断人物本体、当前状态、行为功能、外部场景、时间关系与视觉光影，不能从“因果克制空间”直接倒推出固定十元关系。

## 7. 人物、状态、行为、场景与时间关系必须分层

每次剧本、人物或场景分析，至少拆开：

```text
人物稳定本体
当前人物状态
关键行为功能
外部场景
时间关系 / 时间结构
视觉与光影
主题形成中的双方
主题级生克
具体十元动态链
保持不变的人物核心锚点
```

表面关键词、职业、服装、道具、单次行为和光影不能越级证明人物本体。

故事人物的核心锚点优先保持稳定。剧情变化优先落在状态、显影强度、行为功能、关系位置、场景、时间结构和动态链顺序。

## 9. 当前冻结结论

```text
z = 补 / 补合。
n = 生 / 生发。
x = 克 / 克制。

五大主题由 z 先补合双方，形成高级、高层次的符号化整体。
五大主题成立以后，主题之间主要观察 n 生与 x 克。
“五大主题只有生克”不等于“补不属于体系”。

正式主题关系：因果克制空间。
旧表达 n补克nx：停止作为现行关系使用。

五大主题负责高级归类与主题级生克。
十元负责对象具体化与实现机制。
动态链负责具体对象之间的阶段性生、克、补。
三元与十元并行，不是父子派生。
人物核心锚点优先稳定。
```

## 10. 尚未在本协议锁死的问题

以下问题需要单独证据，不从本轮定义自动推出：

```text
每个主题公式中的“双方”是否已经全部完成现行十元语义复验。
主题公式中的 z 作为十元位置，与 z 作为补合关系功能，如何在记号上避免混淆。
五大主题完整生克盘的具体方向是否全部验收。
同一主题能否由多组不同十元双方经 z 补合形成，以及允许变体的边界。
```
