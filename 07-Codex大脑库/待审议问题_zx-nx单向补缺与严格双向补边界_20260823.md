## 问题

当 zx 与 nx 两端都能独立成立，而且 nx 确实解除 zx 当前现实缺口时，是否已经足以锁严格 zx↔nx 补？

当前跨三作品材料回答：不足。

严格补必须继续做反向拿掉：拿掉 zx 后，nx 自身是否也留下一个只能由 zx 补回的不可替代现实缺口。

如果没有，则只能记录“单向补缺”，不能锁严格双向补。

## 三个高纯控制

### 1. 红楼梦｜尤三姐自择柳湘莲

- zx：尤三姐自己锁定婚姻对象。
- nx：贾琏媒介 + 柳湘莲本人真实同意接口。
- nx→zx：成立。没有对方同意，个人选择不能自动成为双方婚约。
- zx→nx：不成立。拿掉尤三姐的 zx 高显影，保留最低限度愿意接受婚约，媒介与对方同意机制仍可运行。
- 结论：两端都真，但仅单向补缺，非严格补。

### 2. 水浒传｜鲁达五台山

- zx：前段公开直接介入郑屠事件并改变现实。
- nx：通缉后进入赵员外—度牒—智真长老的身份与寺院准入通道。
- nx→zx：成立。外部关系/准入接口补掉直接 zx 无法低成本解决的长期安身与身份转换缺口。
- zx→nx：不成立。赵员外关系、度牒与寺院收录功能不依赖鲁达继续保持 zx 高显影才能运行。
- 结论：单向补缺，非严格补。

### 3. 西游记｜孙悟空定风丹

- zx：孙悟空持续占据过火焰山、取扇并再次回到现实冲突的行动方向。
- nx：灵吉菩萨掌握并交付定风丹，直接解除芭蕉扇把主体扇离现场的现实障碍。
- nx→zx：成立。定风丹让原本被强制位移打断的行动链重新可执行。
- zx→nx：不成立。灵吉持有、交付定风丹这一资源/能力接口本身不需要孙悟空 zx 高显影来补其核心功能。
- 结论：单向补缺，非严格补。

## 第三因素伪双向缺口｜首个高纯控制

### 三国演义｜刘备赤壁前联孙抗曹

- zx：刘备一侧保持抗曹、自存与继续取得政治生存空间的方向。
- nx：东吴是否进入联盟、是否投入江东军政资源，最终接口在孙权。
- nx→zx：成立。拿掉孙权/东吴接口，刘备长坂新败后的现实抗曹能力留下明确外援缺口。
- 表面 zx→nx：似乎成立，因为孙权明确认为“非刘豫州莫与当曹操者”，没有刘备会少一个重要盟友。
- 第三因素：曹操南下并同时威胁刘备与江东。
- 第三因素冻结：中和曹操对江东一侧的迫近军事压力后，孙权的联盟许可与军政处分接口仍能独立成立，并不会因为缺少刘备 zx 而失去核心功能；表面反向缺口消失。
- 结论：反向缺口由共同第三因素制造，非 zx 对 nx 的内生补缺，不能锁严格双向补。
- 置信：事实99 / 分类96。

这条控制说明：

> 表面双向拿掉都造成损失，不等于双向缺口都来自两端彼此。若其中一侧缺口由共同敌人、共同资源稀缺、共同制度压力等第三因素制造，冻结该第三因素后缺口消失，则这一侧不能计入严格补。

## 第三因素冻结有效性护栏｜方法控制

### A｜《三国演义》曹操陈留借卫弘家资 vs 刘备联孙抗曹

现有曹操—卫弘案例已 99/98 锁为真严格补：曹操自生反董起兵方向，当前被“资少恐不成事”这一启动资本瓶颈卡住；卫弘的独立家资处分接口直接补入同一瓶颈，资金立即被曹操转换成衣甲、旗幡、募兵与公开军政行动。

若机械地把“董卓专权”称为第三因素并整体冻结，则会同时删除：

- 曹操反董起兵这个 zx 端；
- 启动资本不足这一目标瓶颈；
- 整个陈留起兵测试对象。

这种冻结不是“排除干扰”，而是删掉题目，不能据此把曹操—卫弘从真补改判成伪补。

与之相对，刘备联孙案例中的有效冻结只中和“曹操对江东一侧的迫近军事压力”，同时保留：

- 刘备自己的抗曹 zx；
- 孙权的联盟许可 / 军政资源 nx 接口；
- 刘备一侧缺东吴外援的目标瓶颈。

此时孙权一侧“非刘备不可”的表面反向需求消失，才真正说明该反向缺口主要由共同第三因素制造。

### B｜《水浒传》宋江高唐州高廉妖法

现有高唐州案例已 99/98 锁为真严格补：宋江公开攻城救柴进方向持续成立，但现有普通军力被高廉妖法这一当前专属瓶颈卡住；公孙胜专属破解能力 + 罗真人真实放行/授法构成 nx，解除瓶颈后宋江重新把条件兑现回同一战役目标。

若机械地把“高廉妖法”整体当第三因素冻结成“不存在／对普通军力无效”，则公孙胜/罗真人当然不再必要；但此时被删除的正是 nx 要补的当前现实缺口本身。

因此：

```text
删除高廉善恶评价、妖法视觉奇观、人物强弱评价
→ 题目仍在
→ 可作为有效冻结

删除“普通军力无法穿透高廉妖法”这个命名瓶颈
→ nx 缺口被直接删掉
→ 实验题目已被改写
→ 无效冻结
```

### C｜《红楼梦》鸳鸯抗婚·贾赦强纳压力

现有鸳鸯案例已 99/97 锁为真严格补：鸳鸯明确占据“不嫁贾赦”的自主拒绝方向并公开把该方向压入现实；但贾赦仍拥有继续推进强纳、威胁其未来婚配和家内处境的现实能力，个人拒绝不足以稳定让强纳链失效。贾母的上位保护 / 留用 / 阻断接口直接补入这一现实缺口，并实际让强纳方案停下。

若机械地把“贾赦强纳压力”整体冻结成“贾赦根本不想纳鸳鸯”或“贾赦完全没有继续推进强纳的现实能力”，那么贾母 nx 当然显得不再必要；但此时被删除的正是：

- 鸳鸯 zx 当前状态要顶住的现实对象；
- 贾母 nx 要补的保护 / 阻断缺口；
- “个人拒绝能否变成现实阻断”的整个测试瓶颈。

因此：

```text
删除贾赦人品评价、鸳鸯是否烈性、贾母偏爱、宏观制度主题
→ zx / nx / 强纳瓶颈仍在
→ 可作为有效冻结

删除“贾赦仍能现实推进强纳”
→ 目标瓶颈被直接删掉
→ nx 缺口随题目一起消失
→ 无效冻结
```

### 当前护栏

> **第三因素冻结必须保留被测试的 zx、nx 与目标现实瓶颈，只移除制造表面反向需求的外生干扰。若冻结直接删除端点或当前瓶颈，则该冻结无效，不能计入第7门。**

最低检查：

1. 冻结后 zx 端是否仍独立成立；
2. 冻结后 nx 端是否仍独立成立；
3. 冻结后当前命名瓶颈是否仍在同一对象层可测试；
4. 是否只中和候选第三因素对“反向需求”的贡献，而不是删掉整个任务、冲突或目标。

当前已由《三国演义》《水浒传》《红楼梦》三部独立作品直接复验该方法护栏，覆盖启动资本、专属技术/法术、强制婚配/家内处分三类不同现实瓶颈。该方法子纪律已达到跨三作品门槛，但仍只强化 pending-review，不直接修改 L1、信息卡、准度卡或补卡。

## 当前候选纪律

严格 zx↔nx 补最低必须继续满足：

1. zx 端独立成立；
2. nx 端独立成立；
3. 两端直接作用于同一个当前现实瓶颈；
4. 拿掉 nx，zx 留下不可替代缺口；
5. 拿掉 zx，nx 也留下不可替代缺口；
6. 两个缺口处于同一有效时间窗口；
7. 双向缺口不能主要由共同第三因素制造；冻结第三因素后，双向不可替代性仍应成立。

第7项追加有效性护栏：

> 冻结必须保留 zx、nx 与目标瓶颈；若冻结本身删除了被测试端点或把题目改掉，则测试无效。

其中第5项不得由“双方共同完成一个大目标”“nx 帮得非常关键”“关系很密切”替代；第7项的“伪双向缺口”目前仍只有《三国演义》一份高纯控制，而“冻结有效性护栏”已由《三国演义》《水浒传》《红楼梦》三部作品复验。

## 明确排除

以下均不能单独推出严格补：

- zx + nx 同时出现；
- nx 对 zx 有帮助；
- nx 是 zx 成功的重要条件；
- 两端共同指向同一个大结果；
- 人物历史上长期合作；
- 一端造成压力、另一端事后收拾后果；
- 共同敌人或共同外部压力让双方都“需要盟友”；
- 通过删除 zx、nx 或当前瓶颈本身来制造“冻结后缺口消失”。

## 最小判别句

> 单向补：A 缺 B 会坏，但 B 缺 A 仍能完成自己的核心功能。
>
> 严格双向补：A 缺 B 有明确缺口，B 缺 A 也有明确缺口，而且双方直接对接同一当前瓶颈；冻结共同第三因素后，这两个缺口仍必须存在。
>
> 有效第三因素冻结：题目还在，只移除干扰；若连端点或当前瓶颈一起冻没了，测试无效。
