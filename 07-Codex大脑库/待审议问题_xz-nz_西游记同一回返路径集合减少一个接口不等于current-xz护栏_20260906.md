# xz ↔ nz 水轴待审议问题｜同一回返路径集合减少一个接口，不等于 current xz

## 0｜current canonical 与权限

本文件只服从 latest current canonical：

```text
水＝阳水 xz ↔ 阴水 nz
主题领域＝命运
广义变量＝可逆性与对象特异回返空间
xz：持续收窄
nz：保存、恢复或重建
```

current `xz信息量卡 v2.2` 的主门是：终点前置、方向被未来规定、路径/选择持续收窄、路径汇流、临界逼近。旧 `xz_准度卡_v0.3` 与 `xz补nz_补卡 v0.2` 仍保留旧火药桶主口径，本文件只登记该 canonical 同步债，不越权修改 L1/L2。

木轴/火轴只迁移验证方法：same current window、same object layer、changed variable、nearest-neighbor、removal、reverse、third-factor freeze；不迁移理论结论。

## 1｜研究问题

现有《西游记》第二次逐出控制已经证明：

```text
direct reentry request = actually attempted
direct reentry consent = explicitly denied
mediated reentry path = still available
```

本轮只追一个更窄的问题：

> **如果在同一对象层、同一个 `return_path_set` 上，现实可用接口确实从“至少 direct + mediated”减少到“direct 被拒、mediated 尚存”，这个真实的路径数量下降本身，是否已经足够构成 current xz？**

答案：**不够。**

这不是新采普通案例，而是对同一 evidence-locked 控制做一次 same-variable 最小差异复验。

## 2｜剧情事实

### 第五十六回｜再次逐出

trigger：孙悟空打死拦路强盗，唐僧再次驱逐悟空。

- actor：唐僧 / 孙悟空；
- action：共同运行被切断，孙悟空离队；
- object：唐僧↔孙悟空对象特异师徒关系；
- object_layer：该关系的现实重入资格与可调用回返路径；
- changed_variable：可现实调用的 reentry interface topology；
- observable_result：原共同执行 OFF。

### 第五十七回｜direct reentry reality-test 失败

原著明确给出：孙悟空没有只在远处怀念，而是实际回到唐僧面前请求继续保护取经；唐僧明确拒绝，并再次念紧箍咒驱逐。随后孙悟空转向普陀向观音申诉。

因此本窗口至少可写：

```text
before direct test:
  direct_reentry_path = available-to-attempt
  mediated_path_via_Guanyin = available

after Tang rejection:
  direct_reentry_path = CLOSED in current window
  mediated_path_via_Guanyin = OPEN / actually invoked
```

也就是：**同一个 relevant return-path set 的确发生了局部减少。**

### 第五十八回｜中介路径继续运行并最终恢复

真假悟空事件继续经过观音、天庭、地府、如来等现实裁定接口；六耳猕猴被辨明后，观音送真悟空回唐僧处，唐僧重新收留，原共同取经关系恢复运行。

这说明第五十七回 direct path 关闭时，complete relevant return-path set 并没有归零； surviving path 后续不仅存在，而且被现实调用并完成 reentry。

## 3｜same current window / same object / same changed variable

本轮刻意不允许靠“对象层不同”逃掉：

```text
same actors = 唐僧 / 孙悟空
same current window = 第二次逐出 → direct reentry 被拒 → mediation → 恢复
same object = 唐僧↔孙悟空师徒关系
same object layer = 现实重入资格与回返接口
same changed variable = relevant return-path set 的可调用接口数量/拓扑
```

因此，本轮不是上一轮宝黛式“自然语言同关系、实际 changed variable 不同”的伪同层问题。

真正要锁的是：**即使 same-layer 与 same-variable 已经通过，一次真实 decrement 仍不能自动判 xz。**

## 4｜xz 独立判断

### 已成立的事实

```text
relevant path set 确有局部减少：
direct + mediated
→ direct CLOSED + mediated OPEN
```

但 current xz v2.2 仍不成立：

1. **终点前置不足**：第五十七回没有一个“永久排除孙悟空”的未来终点持续取得结构支配力；
2. **持续收窄不足**：目前只观察到一个 interface 被关闭，而不是多个现实路径跨阶段连续失效；
3. **路径汇流失败**：surviving mediation path 并没有汇回“永久排除”终点，反而导向重新进入；
4. **临界逼近失败**：没有可验证的 `n>1 → 1 → 0` 或持续逼近不可回返临界；
5. **反向证据存在**：中介路径后续被成功调用，并使原关系恢复运行。

所以：

```text
local_path_decrement = TRUE
current_xz = FALSE
```

## 5｜nz 独立判断

本轮不把第五十七回 direct denial 时刻粗判为 stable bilateral `nz=ON`。

原因：唐僧明确拒绝重新接纳，当前 bilateral consent 失败。

但同一窗口也不能写 `return-space=0`：

```text
stable_bilateral_nz = suspended / failed in direct channel
complete_return_space = non-zero
mediated_reentry_path = retained
later_reentry_realized = true
```

因此本轮不是 `xz+nz` 共现正例，也不是 strict 候选；它是 **same-variable false-xz guard**。

## 6｜nearest-neighbor

### `z`

唐僧的明确拒绝是强裁定节点，但一个 `z` 节点关闭一个 interface，不等于 trajectory-level `xz`。

### `x`

紧箍咒与逐出可形成当前控制/处分，但“能把人赶走”不等于“完整未来路径正在向一个终点汇流”。

### `xn`

观音、天庭、地府、如来等裁定接口可形成流程网络；流程存在本身不是 nz，也不是 xz。只有它们是否保留/关闭 returnability 才进入本轮变量。

### `nx`

孙悟空转去观音处可包含沿既有中介通道行动，但不能因为存在外部通道就把 nx 动作本身当 nz。

## 7｜removal / reverse

### removal

拿掉六耳猕猴奇观、打斗、委屈、紧箍咒疼痛、取经主题，只保留：

```text
对象特异关系已成立
→ direct reentry 实际尝试
→ direct interface 被明确拒绝
→ 已有 mediated interface 仍可调用
→ mediated interface 实际被调用
→ 原关系随后恢复
```

仍然可以锁：

> **同一 relevant return-path set 减少一个接口 ≠ current xz。**

### reverse

若要把同层 returnability 真正推到 current xz，至少应出现更强结构：

```text
一个不可回返/永久排除终点先取得结构地位
＋
多个 relevant interfaces 跨阶段持续关闭
＋
改走其他 relevant path 仍不断汇向同一关闭终点
＋
可调用路径逼近 0
```

此时才有资格把“return-space 下降”升级为 trajectory-level xz。

## 8｜third-factor freeze

- 唐僧是否需要悟空的战斗力：解释功能依赖，不生成 xz；
- 观音权威：解释中介为何可用，不自动等于 nz；
- 六耳猕猴：解释真假裁定 trigger，不创造此前已存在的 mediation channel；
- 紧箍咒：解释当前强制驱离，不证明 complete path-set exhaustion；
- 取经任务：解释双方为何持续相关，不替代对象特异 reentry reality-test。

## 10｜本轮新锁边界

> **same object + same changed variable + relevant path count 真实下降，仍然不等于 current xz。**

> **`one-interface decrement` 只能证明局部可逆性下降；要判 xz，必须另证“终点前置＋持续收窄＋路径汇流＋临界逼近”。**

> **所以 `return_path_set: 2 → 1` 不是 xz 的充分条件；真正高价值的后续缺口是能否找到 `n>1 → 1 → 0` 且 alternate paths 仍汇向同一预置终点的四大名著样本。**
