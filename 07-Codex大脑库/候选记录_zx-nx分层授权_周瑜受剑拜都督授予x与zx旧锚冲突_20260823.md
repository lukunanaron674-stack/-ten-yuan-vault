# 候选记录｜周瑜受剑拜都督：外部正式授予的新军权，是 x 还是首次显影即 zx

## 0｜本轮结论

仓库旧正式案例以 99/97 锁定：周瑜在孙权授权前具有 `nx` 关系功能，受剑拜大都督后因决定范围相较授权前扩大，并立即公开调兵，故 `zx` 当前状态成立。

按现行 L1、zx 准度卡以及后来形成的“分层授权”纪律重新复核后，旧 `zx` 锚出现真实分叉：

> 孙权不是仅口头认可周瑜，而是正式把大都督职位、军令剑以及对违令诸将的处分接口交付给周瑜。授权完成以后，这块战区军令权限已经成为周瑜可直接调用的现实局部 `x`。周瑜次日调兵、设先锋、处分迟误者，可以完整解释为“新授 x 的首次正常运行 + xn 组织”，而不一定还需要额外锁一次 `zx`。

若要把授权后的首次用权继续锁成高纯 `zx`，更稳的门槛应是：主体在获得 A 权限后，继续把决定范围推进到明确未授权的 B，并让 B 在原权限节点反对后仍稳定生效。第44回这个窄窗口尚未看到这一层。

因此本轮不覆盖旧正式案例，事实置信 99；分类仅给 92，保留 `candidate/deferred`。

## 1｜剧情事实、触发、对象、动作、结果

### A｜授权前

曹操南下，孙权内部战降未决。周瑜主张抗曹，向孙权分析曹军弱点并请求精兵出战。

真正的最高接口仍在孙权：东吴是否正式开战、是否把全军战区军令交给周瑜，都不是周瑜单方面能让其制度性生效的。

因此：

```text
周瑜有自己的抗曹方向
→ 但开战与授军权最终接口在孙权
→ 必须陈述、请求并取得正式授权
= nx 授权入口
```

锁：`nx_grant_entry_relation: evidence-locked`。

### B｜授权发生

孙权明确决定抗曹，并把佩剑授周瑜，封周瑜为大都督，程普为副都督、鲁肃为赞军校尉，同时授权周瑜对不听号令者依剑处分。

这不是空衔。授权内容对应真实军令、人员与处分对象域。

因此授权完成后至少可以高置信锁：

`x_newly_granted_military_command_boundary: evidence-locked`

### C｜授权后首次运行

周瑜受剑后当众通知诸将次日赴行营听调，迟误者按军令处分；次日升帐后分派先锋、各队、巡警使和军纪。程普起初不服周瑜位次，后见其调兵有法而到行营谢罪。

这些事实证明：

- 新授权限不是名位；
- 周瑜可以直接调用；
- 组织围绕该军令接口运行；
- 周瑜在运行方法上有明显 `xn` 组织。

但它们是否还能额外证明“周瑜把权限继续推出授予边界”，当前不足 95%。

## 2｜nx 判断

`nx_grant_entry_relation: evidence-locked`

“周瑜是否取得东吴全军大都督军令接口”必须通过孙权这一真实最高权限节点；周瑜不能自行让该职位和军令权生效。

这只锁授权入口，不推稳定人物本体。

## 3｜x 判断

`x_newly_granted_military_command_boundary: evidence-locked`

孙权一旦把剑、都督职位和违令处分接口正式交付，周瑜已经能够不逐项回孙权批准而调度诸将、分派部队、执行军纪。

因此：

```text
外部正式授予真实权限
→ 权限进入主体可独立调用边界
= x
```

第44回后半段至少在“战区军令与军纪处分”对象层满足这一点。

## 4｜zx 为什么降级为 deferred

旧正式案例把“授权前没有整套军权 → 授权后有了并首次公开运行”本身视为 `zx` 位置上升。

但现行 zx 准度卡同时明确：

> 权限早已由职位授予，主体只照章执行时，应检查 `x/xn/nx`；zx 还必须证明主体决定范围或影响位置继续扩大。

按这一更严格基线：

- 授权前：没有大都督权；
- 授权完成：大都督权已经成为周瑜的现实 `x`；
- 次日首次调兵：可以完全是该 `x` 的正常公开调用；
- 当前没有明确证据证明周瑜又处分了孙权没有授予的 B 对象域。

因此：

`zx_from_grant_itself: deferred`

## 5｜xn 最近邻

周瑜后续分先锋、排队列、设巡警、定军纪和行军时序，属于明显 `xn` 组织功能。

但 `xn` 回答的是：

> 已经拿到军权以后，怎样组织这套军队运行？

不能替代：

> 这块军权本身是否已越过当前授权基线？

所以记录：

`xn_post_grant_command_organization_neighbor: evidence-locked`

## 6｜关键压力

本轮真正压力不是曹军强弱、周瑜名将身份或赤壁结果，而是：

> zx 的“决定范围上升”究竟以“授权前个人基线”为比较基线，还是以“授权已经完成后的当前现实权限边界”为比较基线？

### 基线 A｜授权前

```text
此前没有全军都督权
→ 现在获得并公开使用
→ 位置明显上升
```

支持旧 `zx` 锚。

### 基线 B｜授权完成后

```text
孙权已经把 A 军令权正式交给周瑜
→ A 已成为周瑜局部 x
→ 后续只使用 A
→ 无新增 B
```

支持 `nx入口 → x + xn`，而非新增 zx。

当前两种解释都能解释主要事实，因此分类不足 95%。

## 7｜拿掉测试

### 拿掉孙权授剑与都督授权

如果孙权只说“你说得对”，却不交军令与处分接口，则周瑜仍需逐项影响孙权，授权后 `x` 不成立，旧 zx 也失去最核心事实支柱。

### 拿掉周瑜首次公开调兵

只剩“正式受剑拜都督”，则只能证明授权发生；现实 `x` 是否真的可调用证据下降。

### 拿掉“必须越当前授权边界才锁 zx”的新纪律

则旧 99/97 案例可继续成立；但会与现有宋江 92% candidate、王熙凤 93% candidate 以及分层授权待审议发生直接冲突。

## 8｜反向测试

### 纯授权 x 版本

```text
孙权授 A：东吴抗曹战区军令权
→ 周瑜在 A 内调兵、处分、组织军队
→ 未进入明确未授权对象域
= nx入口 → x + xn
```

### 真正授权后 zx 版本

```text
孙权只授 A
→ 周瑜主动推进到未授权 B
→ 孙权或原权限结构明确反对 B
→ B仍稳定生效
→ 以后组织按新增 B 接口运行
= zx
```

第44回目前只高纯满足前者。

## 9｜最近邻排除

### nx vs x

- 授权能否生效：必须经过孙权 → `nx`。
- 授权完成后战区军令能否由周瑜独立调用：可以 → `x`。

### x vs zx

- 使用刚刚正式获得的 A 权限 → `x`。
- 把决定范围继续推出当前 A 边界 → 才更稳地锁 `zx`。

### xn vs zx

调兵有法、重排组织可以很强，但不自动说明权限对象域扩大。

### 严格 zx↔nx 补关系

不锁。当前连周瑜自身 zx 端是否应在授权瞬间成立都处于 deferred，不能绕过第一道门硬做补关系。

## 10｜第三因素冻结

冻结：

- 周瑜名将形象；
- 赤壁最终胜利；
- 诸葛亮激将戏剧效果；
- 程普个人态度；
- 孙权是否英明；
- “剑”这一象征道具；
- 官职名称本身。

只看：

1. 谁让大都督权限正式生效；
2. 授权后权限是否真实进入周瑜调用边界；
3. 首次公开用权是否仍在授予范围；
4. 有没有继续推进到未授权 B；
5. B 是否在原权限节点反对下稳定成立。

结论仍是 99/92。

当前同类“外部授予新权限后，首次公开使用究竟是 x 还是 zx”冲突已跨三部独立作品显影：

1. 《红楼梦》王熙凤协理宁国府：99/93 candidate/deferred；

三例共同问题不是“有没有获得新权”，而是：

> **外部正式把新权交给主体以后，这块新权第一次公开运行是否还应额外标记 zx；还是应先锁为 x，只有继续越出当前授权基线才进入 zx。**
