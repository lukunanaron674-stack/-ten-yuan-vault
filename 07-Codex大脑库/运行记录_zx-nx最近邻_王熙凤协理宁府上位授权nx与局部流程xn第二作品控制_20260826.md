# 王熙凤协理宁国府｜上位授权 nx + 局部流程 xn 第二作品控制

## 0｜为什么本轮值得单独锁

本桥段整体的 `x ↔ zx` 边界仍有真实分叉：贾珍交出宁国府对牌并给予宽内务裁量以后，王熙凤立新规究竟只是“授权后的局部 x + xn”，还是又把决定范围公开推出授权基线形成 `zx`，现有候选记录只给 93%，因此本轮**不裁决整体 zx**。

但其中有两项子结论已经分别达到高置信：

```text
能否制度性进入宁国府协理职责
→ 需要贾珍请托 + 王夫人放行 + 凤姐承接
= 上位授权入口 nx

进入职责以后具体怎样运行
→ 凤姐自己查花名册、分岗位、定时刻、设赔补、建汇报与巡查节点
= 局部运行 xn
```

所以本轮只锁：**上位 nx 与局部 xn 可以同时成立，听命不能吞掉执行自主；执行自主也不能倒抹上位授权来源。**

这与《三国演义》貂蝉连环计形成第二部独立作品控制。

---

## 1｜剧情事实、触发、对象、动作、结果

### 触发

秦可卿去世，尤氏患病不能料理宁国府内事。贾珍明确提出请王熙凤暂代一月料理内务；王夫人最初担心凤姐没有办过婚丧大事，并未立即同意。凤姐本人表示愿意承接后，王夫人才放行。

### 被测对象层 A｜“能不能进入宁府协理”

王熙凤不能只凭自己想做就让跨府协理制度性生效。文本真实经过：

```text
贾珍提出任务
→ 王夫人拥有真实放行位置
→ 凤姐承接
→ 协理职责成立
```

随后贾珍交出宁国府对牌；王夫人又明确提醒重要事项仍需问贾珍、尤氏。

因此在**任务来源 / 授权入口层**，最终合法方向与权限入口仍在外部，凤姐真实沿该接口进入，`nx` 成立。

### 被测对象层 B｜“进入以后具体怎么运行”

凤姐到任后没有得到一套写死的操作流程。她自行：

- 索取并检查家口花名册；
- 按岗位分班；
- 把器物短少与具体责任人绑定；
- 设偷懒、赌博、打架等汇报节点；
- 规定卯正二刻点卯、巳正吃饭、午间回事、戌初巡查与交钥匙；
- 让来升家的每日总查；
- 把宁府原有“事无专执、临期推委、滥支冒领”等问题压进一套新的运行骨架。

这些不是“沿别人已经搭好的流程”，而是主体主动组织时间、责任、人员与节点，属于高纯 `xn` 局部执行功能。

### 结果

宁府内务开始按照凤姐设定的岗位、时刻、责任与汇报结构运行。

本轮因此得到：

```text
上位授权入口：nx
局部运行组织：xn
局部已授权处分：x 邻近且已有既有记录支持
是否进一步扩成 zx：deferred
```

## 2｜zx 检查

本轮**不把 zx 作为正式结论**。

支持 zx 的材料确实存在：凤姐公开要求宁府众人“如今可要依着我行”，组织也围绕她的新规则发生重排。

但现有 20260822 候选已经指出：贾珍在此前交出对牌并给出相当宽的内务裁量。真正分歧是：

> zx 的基线应该取“凤姐进入宁府之前”，还是取“授权完成以后已经拥有的宽管理边界”？

若以后能证明凤姐把决定范围公开推出**已授边界之外**，才重新锁 zx。本轮不拿这个 93% 分叉污染稳定的 nx/xn 子结论。

---

## 3｜nx 证据

### 结论

`nx_delegation_entry_relation: evidence-locked`

关键不是“有人请她帮忙”，而是：

1. 跨府协理职责不能由凤姐单方面制度性生效；
2. 王夫人第一次并未自动放行，说明外部批准位置是真门，不是礼仪装饰；
3. 凤姐真实请求/承接这个入口；
4. 重要事项仍保留回问贾珍、尤氏的上位边界。

符合 nx 正本：**方向、权限或通道在外，主体不占最终入口，真实沿外部关系/权限续接。**

---

## 4｜nx vs xn 最近邻

当前准度卡已经明确：

```text
老板给目标，员工主动排程搭流程
→ 不能把全部过程写成纯 nx
```

本例最小拆分：

```text
“去宁国府协理一个月”由外部任务/授权链给出
= nx

“怎样分班、怎样定责任、怎样设时刻、怎样巡查”由凤姐主动重建
= xn
```

这和貂蝉连环计的结构同型：

```text
貂蝉：王允给上位政治任务 → nx；现场话术与节点自搭 → xn
凤姐：贾珍/王夫人给上位协理授权 → nx；宁府运行骨架自搭 → xn
```

一个是谋略执行，一个是组织治理，表面领域完全不同，但核心变量一致。

## 5｜拿掉测试

### 拿掉 nx 授权入口

假设贾珍没有请托、王夫人不放行、宁府也没有对牌/合法管理入口，而凤姐仍自行闯入另一府直接接管：

- 原来的“上位授权 nx”消失；
- 应重新检查 zx / x 的非法或强制扩边问题。

说明授权入口 nx 不是装饰变量。

### 拿掉 xn 运行重建

假设凤姐接受协理后，所有岗位、时刻、责任、流程都由贾珍/王夫人逐项写死，她只能机械照办：

- 上位 nx 仍可成立；
- 但局部 xn 显著下降。

说明 xn 不是由 nx 自动附送。

### 拿掉凤姐“强势、能干”性格评价

只保留授权来源与流程组织事实，结论不变。

## 6｜反向测试

### 反向成纯 nx

```text
上位任务由外部给
+ 所有具体岗位、时刻、处分流程也由外部逐项给定
+ 凤姐只照单执行
```

则可接近纯 nx 行为。

### 反向成 xn 主导且 nx 下降

```text
凤姐无需任何外部授权即可决定是否接管宁府
+ 上位任务对象也由她自己重新定义
+ 再自行搭流程
```

则授权入口 nx 显著下降，应重新检查 x/xn/zx。

### 反向成 zx

若文本出现：

```text
原授权者明确反对某个超边界决定
→ 凤姐仍公开让该决定生效
→ 宁府承认新增决定边界
```

才给 `zx beyond delegated boundary` 新的高质量证据。

## 7｜第三因素冻结

冻结：

- 王熙凤性格强势与“凤辣子”评价；
- 秦可卿之死的情感意义；
- 贾府兴衰主题；
- 她管理效果好坏；
- 宁府众人是否怕她；
- 后续人物命运。

只保留：

```text
上位职责是谁提出并批准？
主体是否真实承接外部入口？
具体运行流程是谁组织？
局部处分权是否已经授权进入 x？
是否有证据越过授权基线形成 zx？
```

`上位 nx + 局部 xn` 结论不变。
