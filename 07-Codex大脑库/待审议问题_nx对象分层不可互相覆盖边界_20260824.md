# 待审议｜nx 对象分层不可互相覆盖边界

## 1｜问题

连续三部独立作品已经证明：主体在较高对象层保留自己的最终方向，并不妨碍另一个局部对象层独立成立 nx；反过来，局部 nx 也不能倒灌成长期终点 nx。

同时必须防止另一种对称误判：

```text
看见局部有人参与 / 有组织资源 / 有部下执行
→ 就把该局部自动写成 nx
```

局部 nx 仍必须证明：关键接口当前真实外置，主体必须沿外部权限、资源或解决通道推进。

## 2｜三作品正向控制

- 《三国演义》关羽｜99/96：最终归属与退出方向非 nx；二夫人供养、安全、曹军门禁与暂时庇护为局部 nx。
- 《水浒传》林冲｜99/97：长期逃生／另寻安身方向非 nx；柴进庄庇护、盘缠、荐书、梁山准入为局部 nx。
- 《红楼梦》鸳鸯｜99/97：婚姻拒绝方向非 nx；贾母家内保护／阻断许可为局部 nx。

## 3｜反向控制 A｜探春兴利除弊｜99/97

王夫人命探春参与裁处家务，这一权限进入层是真 nx；但授权完成以后，园中日常事务、人员、支出和资源已经进入探春可直接裁处的局部边界，属于 x。第56回探春又主动重组人员、资源、责任和收益，属于 xn。

因此：

```text
王夫人正式委派
= nx 授权入口

授权后园中日常对象可直接裁处
= 局部 x

人员 / 资源 / 责任 / 收益重排
= xn
```

不能因为“用了婆子、园子、贾府的钱”就新增局部 nx。

## 4｜反向控制 B｜马谡街亭｜99/98

诸葛亮把守街亭任务、二万五千兵以及现场主将接口交给马谡，因此上位“守街亭”任务层是 nx；但兵力与现场指挥权在授权完成后已经进入马谡可直接调用的局部 x。马谡随后否定“当道下寨”，压过王平意见，重新选择山上屯军、兵力分布和协同关系，属于 xn 运行重设。

最关键的是：

```text
上位任务来自诸葛亮
= nx

现场兵力与主将接口已正式交付
= x

山上屯军 / 分兵 / 协同关系由马谡重设
= xn
```

即使大量部下实际执行马谡命令，也不存在一个新的“必须经过外部许可才能调用这些兵”的局部 nx 接口。

因此本例第二次反向验证：

> **“使用部下 / 使用组织兵力 / 让别人替我执行”不等于 nx。只要这些人员与资源已经稳定进入主体当前 x 调用边界，且运行结构由主体自己 xn 组织，就不能重复计一个局部 nx。**

## 5｜候选纪律

```text
1. 先命名对象层：终点、归属、任务、许可、资源、保护、专业解决、运行方法。
2. 每个对象层分别问：最终方向或关键接口由谁掌握？
3. 某一层排除 nx，不得自动覆盖其他层。
4. 某一局部层成立 nx，不得倒灌成长期终点 nx。
5. 局部只有在关键权限/资源当前仍外置、主体必须经过外部接口时才锁 nx。
6. 若权限已经进入主体稳定可调用边界，转查 x。
7. 若主体自行组织人员、资源、节点与流程，转查 xn。
8. “别人参与”“用了组织资源”“部下执行”都不是 nx 的充分证据。
```

最短版候选：

> **nx 必须按对象层判定；一层非 nx，不得覆盖其他局部 nx。反过来，对象分层也不能制造伪局部 nx：已有 x 与自搭 xn 不得重复计 nx。**

## 6｜拿掉测试模板

### 真局部 nx

拿掉该外部节点后，高层最终方向仍存在，但局部出现明确缺口：保护、许可、资源、准入或专业解决无法按原链成立。

### 伪局部 nx

删除“局部是 nx”这一假设后，事实仍能由：

```text
既有 x 直接调用
+
主体 xn 运行组织
```

完整解释，而且无需经过新的外部许可/资源接口，则所谓局部 nx 是误标。

## 7｜反向测试模板

真正局部 nx 必须看到：

```text
关键资源 / 权限仍掌握在外部
→ 主体不能稳定自行调用
→ 必须重新请求、等待、借用或承接
→ 结果才能生效
```

若变成：

```text
权限已经交付
→ 主体可直接调用
→ 主体自己安排人员 / 资源 / 节点
```

则优先 x + xn，不再新增 nx。

## 8｜最近邻排除

- `nx vs x`：当前仍需别人批准/放行/提供，才是 nx；已经归主体直接处分则是 x。
- `nx vs xn`：沿别人既有接口推进是 nx；自己重排人员、资源、节点和责任是 xn。
- `nx vs zx`：高层非 nx 不自动推出 zx；仍需公开显权、外部响应和决定范围扩大。
- `人物本体 vs 行为功能/关系位置`：现有正反控制均不锁稳定人物本体。

## 9｜第三因素冻结

冻结人物性格、关系亲疏、强弱胜负、身份职业、主题，以及“有人帮忙”“有人执行”“用了组织资源”这些表面描述。

只检查：

1. 当前对象层是什么？
2. 谁占据该层最终方向或关键接口？
3. 主体有没有真实接入外部通道？
4. 当前权限/资源是否已经进入主体 x？
5. 当前运行结构是否由主体 xn 组织？
6. 该层结论是否被错误倒灌到其他层？

## 10｜结论状态

当前正向边界已经跨三部作品稳定复现；反向“伪局部 nx = 其实已有 x / 自搭 xn”现在已有两部独立作品：

- 《红楼梦》探春｜99/97
- 《三国演义》马谡｜99/98

因此 `pending-review` 继续保留，但反向子纪律尚只有两部作品，不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。

## 11｜下一轮优先验证

不要再收第三个《红楼梦》或《三国演义》同型。

优先去《水浒传》或《西游记》寻找第三份独立反向控制：

> 表面主体“用了别人 / 借了部下 / 调了组织资源”，但该人员、资源或权限其实已经稳定进入主体 x 调用边界；主体若又自己搭行动结构，则属 xn，不存在新的外部 nx 接口。

若第三部也 ≥95%，再把“有人参与 ≠ nx；已有 x / 自搭 xn 不得重复计 nx”强化为跨三作品子纪律。
