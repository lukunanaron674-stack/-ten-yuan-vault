# 待审议｜nx 对象分层不可互相覆盖边界

## 1｜问题

连续三部独立作品出现同一边界：

> 主体在较高对象层明确保留自己的最终方向，因此该层不成立 nx；但在另一个局部现实对象层，关键保护、许可、资源、准入或解决接口真实掌握在外部节点，主体又实际接入，因此局部 nx 仍然可以独立成立。

因此需要防止两种对称误判：

```text
高层非 nx
→ 误写成整段所有对象层都非 nx

局部 nx
→ 误写成主体长期最终方向也交给外部
```

两种都不成立。

但反向也必须防：

```text
看见局部有人参与 / 有组织资源
→ 就把该局部自动写成 nx
```

同样不成立。局部 nx 仍必须证明关键接口**当前仍真实外置**，主体必须沿外部权限/资源通道推进。

## 2｜三作品正向控制

### A｜《三国演义》关羽屯土山｜99/96

- 最终归属刘备、何时退出：关羽自己保留，非 nx；
- 二夫人供养、安全、曹军不入门、暂时庇护：权限与资源在曹操，关羽真实接入，局部 nx。

### B｜《水浒传》林冲柴进庄｜99/97

- 是否继续逃避追捕、是否另寻安身：林冲自己决定，非 nx；
- 柴进庄庇护、盘缠、荐书、梁山准入：关键资源和关系权限在外部，林冲真实接入，局部 nx。

### C｜《红楼梦》鸳鸯抗婚｜99/97

- 是否接受贾赦婚配：鸳鸯自己锁定“不从”，非 nx；
- 如何在贾府现实权力结构中真正阻断贾赦：上位保护/留用权在贾母，鸳鸯主动接入，局部 nx。

## 3｜首个反向控制｜《红楼梦》探春兴利除弊｜99/97

王夫人命探春与李纨共同裁处家务，这一**权限进入**层是真 nx。

但授权完成以后，园中日常事务、人员、支出和资源已经进入探春可直接裁处的局部管理边界；第56回探春进一步把责任、收益、人员与资源重新组织。

因此：

```text
王夫人正式委派
= nx 授权入口

委派后园中日常对象可直接裁处
= 局部 x

人员 / 资源 / 责任 / 收益重排
= xn
```

不能因为“婆子是别人”“园子和钱原本属于贾府”“改革使用了组织资源”就新增一个局部 nx。

本例第一次反向验证：

> **对象分层纪律只能保留真实局部 nx，不能反过来把已经内化为主体 x 的权限，或主体自己搭出的 xn 运行结构误标成 nx。**

## 4｜候选纪律

暂建议后续材料必须先拆对象层，再判 nx：

```text
1. 先命名当前判定对象层：
   终点/归属？任务？许可？资源？保护？专业解决？运行方法？

2. 每个对象层分别问：
   最终方向或关键接口由谁掌握？

3. 某一层排除 nx，不能自动覆盖其他层。

4. 某一局部层成立 nx，也不能倒灌成整体人物本体或长期终点 nx。

5. 某局部层只有在关键权限/资源当前仍外置、主体必须经过外部接口时才锁 nx。

6. 若权限已经进入主体稳定可调用边界，转查 x；若主体自行组织人员、资源、节点与流程，转查 xn。
```

最短版候选：

> **nx 必须按对象层判定；一层非 nx，不得覆盖其他对象层的局部 nx。**

同时加反向护栏：

> **对象分层不等于多贴 nx。局部权限已经归主体 x，或主体自行搭成 xn 时，不应再重复判 nx。**

## 5｜为什么不是“人物有主见就非 nx”

三例都显示：

- 关羽对长期归属极有主见；
- 林冲自己决定继续逃生与转移；
- 鸳鸯自己锁定拒婚方向。

但这些主见都不能自动生成：

- 曹操控制区里的家属供养与安全许可；
- 柴进的庄院、钱、荐书与梁山准入；
- 贾母对贾赦的家内阻断权。

所以“主体自主”与“局部 nx”并不冲突。

探春反向控制又证明：

- 有组织人员参与；
- 有现成资源被调用；
- 有上级曾经授权；

也不能反过来证明**当前这个局部仍是 nx**。必须追踪当前调用边界。

## 6｜与 xn / x / zx 的最近邻

- `nx vs xn`：主体自己决定总体终点，不代表局部外部资源/许可是自己搭的流程；若关键接口仍在别人那里，局部优先 nx。反之，若主体自己重排人员、资源、节点和责任，优先查 xn。
- `nx vs x`：若局部资源/权限已经稳定属于主体可调用，则转查 x，不再是 nx。过去通过 nx 获得权限，不代表后续每次调用永久 nx。
- `nx vs zx`：高层非 nx 不能直接推出 zx；仍需独立检查公开显权、外部响应和决定范围扩大。
- `人物本体 vs 行为功能/关系位置`：现有正反控制均不锁稳定人物本体。

## 7｜拿掉测试模板

### 拿掉局部 nx

如果高层最终方向仍存在，但现实出现一个明确局部缺口：保护、许可、资源、准入、专业解决无法按原链成立，则局部 nx 是真功能。

### 拿掉所谓局部 nx 后没有缺口

如果删除“局部是 nx”这一假设以后，事实仍可由：

```text
既有 x 直接调用
+
主体 xn 运行组织
```

完整解释，而且无需经过新的外部许可/资源接口，则所谓局部 nx 是误标。

### 拿掉高层自主方向

如果外部局部接口仍存在，却无法自动生成主体的最高终点，则说明局部 nx 不能覆盖高层方向。

## 8｜反向测试模板

### 整体真的变成 nx

必须看到主体连高层最终方向也真实交给外部，并持续沿外部方向推进。

### 局部 nx 消失

必须看到原外部接口已内化为主体 x，或主体自己搭建可替代 xn 结构，使局部结果不再依赖外部权限/资源。

### 伪局部 nx 的必要反问

```text
这个“别人/资源”当前真能拒绝主体调用吗？
主体是否必须重新请求或等待许可？
如果不经过该外部节点，局部结果是否真的无法按原链成立？
```

若答案是否，则优先查 x / xn，而不是 nx。

## 9｜第三因素冻结

后续复验必须冻结：

- 人物“忠义/刚烈/独立/软弱/能干”等性格词；
- 关系亲疏；
- 强弱、胜负、身份标签；
- 剧情主题；
- “有人帮忙”“用了组织资源”这类表面描述。

只检查：

1. 当前对象层是什么？
2. 谁占据该层最终方向或关键接口？
3. 主体有没有真实接入外部通道？
4. 当前权限/资源是否已经进入主体 x？
5. 当前运行结构是否由主体 xn 组织？
6. 该层结论是否被错误倒灌到其他层？

## 10｜结论状态

当前已有三部独立作品、三种不同对象形态的正向复现：

- 归属方向 vs 家属保护资源；
- 逃生方向 vs 庇护/准入资源；
- 婚姻方向 vs 家内阻断许可。

并已有首个高纯反向控制：

- 《红楼梦》探春：授权入口 nx，但授权完成后的局部管理对象已属 x；运行重构属 xn，不能再新增局部 nx。

因此 `pending-review` 继续保留，但不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
