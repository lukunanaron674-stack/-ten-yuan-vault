# 运行记录｜孙策借兵后军力内化与严格补关系时间窗口

## 0｜结论先行

第十五回“孙策质玺向袁术借兵 → 渡江图取江东”仍保持仓库既有严格 `zx → nx → zx` 正例：孙策自己的江东扩张方向存在，但兵马不足；袁术掌握的三千兵、五百马直接补当前军事启动瓶颈；孙策随即把外部资源转为公开扩张。

但这条严格补关系不能无限延长到孙策后续所有军事行动。

关键闭环标志不是单纯“时间过去了”，而是**资源权限状态已经转换**：

```text
第十五回：
袁术兵马仍是外部资源
→ 必须经袁术同意才能取得
= nx 外部资源接口

借入后用于取江东
→ 军队与新加入将领进入孙策持续统辖
→ 江东平定后孙策可自行分拨将士、守把隘口
= 资源逐渐内化为 x

第十七回：
袁术反过来向孙策借兵
→ 孙策可以直接拒绝
→ 自己点军守江口并决定后续军事路线
= 原“袁术兵权接口”已不再是当前行动的 nx 门
```

因此：

> **严格补关系不仅要同一现实瓶颈直接对接，还要处于同一有效时间窗口。外部 nx 条件一旦已完成补缺、并被主体吸收成稳定 `x` 调用资源，旧 nx 端就应视为本轮闭环结束；后续 zx 不应继续追溯挂在旧 nx 上。**

## 1｜事实链

### 阶段 A｜外部资源仍在袁术手中

孙策不愿久困袁术之下，要借兵渡江图取大业。吕范明确指出袁术未必肯借，孙策遂以传国玉玺作质。袁术本人决定借兵三千、马五百，并给相应军职。

这里的关键事实不是“孙策曾经求过人”，而是：

```text
兵马调用权仍属于袁术
→ 孙策不能自行取得
→ 必须通过袁术真实批准
= nx
```

### 阶段 B｜同一瓶颈被直接解除

孙策取得兵马后立即渡江起兵，持续招纳将领、扩大军队并取得江东。此阶段保持既有严格补结论：外部兵马直接解除“公开扩张缺启动军力”的现实瓶颈，而孙策 `zx` 又把借入资源兑换成公开军事结果。

### 阶段 C｜资源状态发生转换

第十五回末，江南平定以后，孙策已经能够自行分拨将士守把各处隘口。袁术自己也承认“孙策借我军马起事，今日尽得江东地面”。

此时被测试资源已经不再表现为：

```text
每次使用都要回袁术批准
```

而表现为：

```text
已经进入孙策持续统辖的军事系统
```

因此该资源对象层从“外部 nx 接口”向“内部稳定 x 调用资源”转换。

### 阶段 D｜第十七回提供反向确认

袁术称帝后派人向江东问孙策借兵。孙策直接拒绝，并表示自己反而想加兵问罪；随后自行点军守住江口，并决定如何应对袁术。

这构成强反向证据：

> 原本孙策必须向袁术请求才能得到的“兵马启动接口”，已经不是后续军事行动的现实许可门。

## 2｜zx 判断

### 初始严格补窗口

孙策已有自身江东方向；获得外部军力后公开扩张并扩大现实影响，`zx` 端成立。

### 后续阶段

孙策后续仍可能出现新的 `zx` 行为或状态，但不能因为当初三千兵来自袁术，就把所有后续扩张永久写作“旧 nx 补旧 zx”。

判断必须重新问：

```text
当前 zx 被什么瓶颈卡住？
这个瓶颈当前还需要袁术接口吗？
```

第十七回答案是否定的。

---

## 3｜nx 判断

### 第十五回

`nx` 成立于：袁术掌握外部兵马，孙策必须请求并质押玉玺取得。

### 江东平定以后

不能因为资源历史来源是袁术，就继续锁当前 `nx`。

现行 nx / x 最近邻要求：

```text
nx：资源、权限仍在别人手里，需要沿通道借用
x：资源、权限和调用边界已经归主体掌握
```

本例后段更符合后者。

因此：


## 4｜关键压力

初始压力：孙策有江东方向，但直属兵力不足。

初始 nx 直接补的是这个瓶颈。

闭环结束的关键不是“过了两回书”，而是：

- 启动兵力已经实际进入孙策军队；
- 孙策建立新的江东人员、地盘、兵粮与守备系统；
- 后续不再需要袁术逐次批准；
- 袁术反而需要向孙策请求兵力。

所以原瓶颈已经被解决并转态，条件不再相同。

## 5｜拿掉测试

### 拿掉第十五回 nx

在“尚未渡江、直属兵少”的初始窗口，拿掉袁术兵马接口，孙策 `zx` 方向仍在，但留下明确的启动军力缺口。因此原严格补关系仍成立。

### 拿掉后续的旧 nx 历史来源

到第十七回，如果只保留孙策已经掌握江东军队、地盘和守备接口，即使不再追溯“这些兵最初从袁术借来”，孙策当前军事决策仍可独立成立。

因此后续行动对旧 nx 已无当前不可替代缺口。

### 补回旧 nx 历史事实

补回“最初三千兵来自袁术”只增加历史因果来源，不会重新制造当前许可依赖。

所以：

> **历史来源 ≠ 当前补关系端点。**

## 6｜反向测试

若第十七回孙策每次调动那批军马仍必须向袁术请示，袁术可以收回、拒绝或重新分配，那么旧 `nx` 仍在当前窗口工作，严格补闭环可以延长。

原文反而出现：

```text
袁术向孙策借兵
→ 孙策拒绝
```

故不支持延长。

若孙策只是暂时保管袁术军队，袁术始终保留最终撤回权，也应重新检查 `nx`，不能锁内化 `x`。

---

## 7｜最近邻排除

### vs 普通时间间隔

不是“隔得久 = 自动切阶段”。即使时间较长，只要同一外部接口仍是当前瓶颈的必经门，补关系仍可能延续。

### vs x

本例真正的闭环标志就是：旧 nx 资源进入主体稳定调用边界以后，应转查 `x`。

### vs xn

孙策后续招纳、分兵、守隘有 `xn` 组织，但本轮核心不是军队怎么组织，而是旧外部权限接口是否仍然活着。

### vs zx

后续 `zx` 必须按当前新的现实瓶颈重新判，不能靠旧 nx 的历史来源自动获得严格补标签。

案例级候选纪律：

> **严格补关系应有闭环结束条件。外部 nx 条件直接补掉当前瓶颈并被主体吸收成稳定 `x` 后，旧 nx 端不应永久挂在人物后续所有 zx 上。时间窗口的判据应优先看“瓶颈是否仍生效、外部接口是否仍是当前必经门”，而不是机械按章节间隔。**

本轮不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
