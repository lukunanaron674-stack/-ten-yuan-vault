# 运行记录｜鸳鸯抗婚 zn 先成立，贾母公开支持后来追上：第二作品“被承认 vs 真正成立”控制

## 1｜本轮问题

本轮不重新给鸳鸯整个人物贴“刚烈”“反封建”之类标签，也不重复增加 pure-`zn` 计数。只测试一个窄变量：

> **鸳鸯“当前婚姻关系不能由权势、家属或身份收益替主体决定；在强纳条件下宁愿终身不嫁、出家或承担极高代价，也不把最终选择让渡出去”这一 `zn`，是在贾母公开支持以后才成立，还是在获得贾母保护 / 承认以前就已经独立成立？**

如果后者成立，则与宋江首份控制共同支持：

> **外部承认 / 保护可以追上一个已经成立的 `zn`，但不能被倒写成该 `zn` 的起点、必要条件或充分条件。**

## 2｜剧情事实链

### 阶段 A｜上位承认尚未进入，原则已经形成

《红楼梦》第46回，邢夫人先以“做姨娘、体面、尊贵、将来可以使唤人”等现实收益劝鸳鸯接受贾赦强纳。

鸳鸯并未因为这套身份收益而承接。邢夫人离开后，她在平儿、袭人面前已经明确把边界扩展到未来：即使贾赦以后正式娶她、即使换成别的对象，她仍不愿接受；若逼到极处，可以出家、终身不嫁，甚至承担死亡代价。

此时：

```text
贾母公开支持：尚未发生
贾母现实否决：尚未进入当前现场
身份收益：已出现
家属 / 上位压力：已出现
原则边界：已明确
未来调用资格：已说明
```

因此该 `zn` 的最关键成立证据早于贾母介入。

### 阶段 B｜压力升级，原则仍不撤回

随后贾赦通过鸳鸯兄嫂继续施压，并明确威胁：即使以后外嫁，也难逃其手；除非终身不嫁或死亡。

鸳鸯仍然没有撤回原则，而是把它公开带到贾母面前，并把“即使老太太逼我也不能从命”的边界说清，同时剪发明志。

这一点很重要：

> **鸳鸯不是因为先得到贾母担保才敢形成原则；原则已经形成以后，她才把它公开推进到上位保护 / 否决节点。**

### 阶段 C｜贾母的承认 / 保护后来追上

鸳鸯公开誓绝后，贾母才强烈回应，对贾赦一方的做法发怒，并现实站到鸳鸯一侧，使强纳路径受到上位阻断。

因此时间顺序是：

```text
内部拒绝原则 zn 已成立
→ 在高压力下公开表达
→ 贾母后来承认 / 支持并提供现实保护
```

而不是：

```text
贾母先保护
→ 鸳鸯才第一次生成拒绝原则
```

## 3｜zn 证据

本轮沿用 current canonical，把 `zn` 限定为：

> **当前婚姻关系不能由权势、家属或身份收益替主体决定；在强纳条件下，宁愿终身不嫁、出家或承担极高代价，也不把最终婚姻选择让渡出去。**

该原则通过当前硬门：

1. **对象明确**：当前婚姻关系中的最终选择是否可以被外部强制替代。
2. **无上位保护时已进入判断**：私下对平儿、袭人表态时，贾母尚未介入。
3. **奖励 / 身份收益不能换取撤回**：姨娘身份、体面、未来得势没有改变排序。
4. **压力升级后仍继续排序**：兄嫂说项与贾赦威胁都没有换取原则退出。
5. **未来调用资格明确**：鸳鸯把判断扩展到未来对象、终身不嫁 / 出家等条件。
6. **让渡代价可说明**：她明确接受高现实代价，也不把最终选择交出。

因此本窄原则对象层：`zn = true`。

## 4｜外部承认 / 保护检查

本轮将贾母后续反应限定为：

> **对鸳鸯已经形成的拒绝方向进行上位支持、现实保护与强纳阻断。**

它很重要，但功能与 `zn` 的内部成立要分开：

```text
zn：为什么主体即使没有上位保护也不愿让渡最终选择
外部承认 / 保护：后来是否有现实节点支持、保护或承认这个方向
```

因此：

- 贾母保护可以改善现实结果；
- 但贾母保护不是该 `zn` 的时间起点；
- 也不能反过来证明“凡被贾母保护的选择都一定是 zn”。

## 5｜x 检查

本轮不把“鸳鸯有最终拒绝原则”自动判为婚姻关系 `x`。

current `x` 仍要求同一对象真实进入主体稳定的占有、调用、处分、否决或排除边界。原著此阶段贾赦仍保有强现实压力，鸳鸯拒绝方向要稳定现实阻断，还需要贾母这个外部上位节点介入。

所以本轮：

```text
zn = true
同对象层稳定婚姻关系 x = not_locked
```

这与既有 pure-`zn` 记录一致；本轮不重复增加 pure-`zn` 统计。

## 6｜关键本体变量

本轮检查的是：

```text
内部原则什么时候真正过门？
↓
上位保护 / 承认什么时候才进入？
↓
承认到来以前，原则是否已经在利益与压力冲突里独立排序？
```

若答案为“是”，则：

> **被承认 / 被保护的时间 ≠ `zn` 真正成立的时间。**

## 7｜拿掉测试

### 拿掉贾母后续支持

只保留邢夫人利诱、平儿 / 袭人私下对话、兄嫂施压与贾赦威胁：

- 鸳鸯仍已经明确拒绝；
- 仍把原则扩展到未来；
- 仍接受出家 / 终身不嫁 / 高代价作为边界。

所以：

> **贾母的承认 / 保护不是该 `zn` 成立的必要条件。**

### 只保留外部支持，拿掉此前内部原则

如果一个人物此前并无稳定原则，只是在获得贾母式上位保护以后才顺势表态拒绝，而且拿掉保护就立刻撤回，则不能仅凭“上位支持了她”倒推内部 `zn` 已成立。

所以：

> **外部承认 / 保护也不是 `zn` 的充分条件。**

## 8｜反向测试

若剧情改成：

```text
获得贾母保护以前：
主体主要接受身份收益，或始终摇摆

贾母明确站队以后：
才第一次形成“不接受”的原则

保护一撤：
原则立即失去未来指导资格
```

则应优先检查外部认可 / 保护、收益与当前关系，而不能把后来的表态回填成此前已存在的 `zn`。

原著鸳鸯不符合这个反向结构。

## 9｜最近邻排除

- `zn vs z`：贾母支持、旁人同情、外部认可都不是 `zn` 的成立支柱；最硬证据出现在这些支持到来以前。
- `zn vs x`：强烈拒绝原则不等于当前婚姻关系已经进入鸳鸯稳定处分边界。
- `zn vs xn`：如何求助贾母、如何公开表达属于执行路径，不解释为什么最终方向不能让渡。
- `zn vs zx`：公开剪发与誓绝可能有强现实显影，但行动强度本身不能替内部原则定义。
- 稳定人物本体：本轮不锁，只锁该原则跨承认窗口的成立时序。

## 10｜第三因素冻结

冻结：

- “烈女 / 反抗封建婚姻”等后世评价；
- 贾母是否偏爱鸳鸯；
- 贾赦的道德评价；
- 平儿、袭人的同情；
- 最终婚姻结果与后续剧情。

只保留：

```text
上位支持到来以前原则是否已经独立过门？
利益与威胁能否换取原则撤回？
上位支持是否只是后来追上并改善现实结果？
```

结论不变。
