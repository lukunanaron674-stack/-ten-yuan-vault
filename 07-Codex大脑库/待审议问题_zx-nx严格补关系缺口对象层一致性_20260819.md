# 待审议｜zx↔nx 严格补：对象层一致性

## 1｜仍然成立的反向边界

跨三部作品的对象层错位控制仍然有效：

- 《水浒传》林冲：早期“我如何入梁山”的 nx，与后期“谁决定寨主/准入结构”的 zx 不是同一对象层。
- 《西游记》孙悟空：弼马温职务承接 nx，与后续身份等级/凌驾位置 zx 不是同一对象层。
- 《三国演义》曹操：七星刀秘密刺董资源 nx，与陈留公开起兵 zx 不是同一现实变量。

因此继续保留：

> **时间连续、因果连续、人物连续，都不能替代同一对象层/同一现实瓶颈。**

“先发生 A、后发生 B”“A 是 B 的历史前提”都不足以证明 A/B 构成严格补。

必须逐案按现 `zx补nx_补卡` 重验：

1. 两端是否独立成立；
2. 是否同一当前现实瓶颈；

5. 是否只是普通合作/资源相加；
6. 第三因素是否制造伪双向；
7. 两端是否处于同一有效窗口。

当前已恢复曹操、宋江、孙策三份严格补正例，但“严格补时间窗口闭环”本身仍需独立复核。

所以目前保持：


孙策后续“外部兵马逐步内化为 x、旧 nx 退出当前窗口”继续作为 nx 动态资产保留，但**初始严格补成立 + 后续 nx→x** 不能自动等于“严格补时间窗口闭环已复验”。

更基础的 nx 动态纪律继续有效：

```text
nx 真实激活
→ 任务完成 / 瓶颈消失 / 接口退出 / 资源内化
→ 旧 nx 不得永久追挂后续阶段
```

只有在初始阶段确认严格补，并且后续闭环也按同一正本口径通过，才计“严格补时间窗口”。

## 5｜当前可保留的对象层方法

1. 两端必须先独立成立；
2. 时间连续、人物连续、因果连续不能替代对象层一致；
3. 对象名称相同不自动等于同一现实瓶颈；
4. 对象名称不同也不自动排除严格补；
5. 更可靠的是追踪：**两端是否直接作用于同一个当前现实限制变量**；
6. 拿掉任一端时，必须按当前正本检查另一端是否仍成立但出现可命名缺口；
7. “nx 自身核心能力本体必须受损”只属于候选新门，不得覆盖当前正本；
8. 第三因素冻结仍需保留两个端点和当前瓶颈，不能通过删题制造结论；
9. **交换/激活条件与端点功能分层**：第三因素可以解释“为什么接口打开”，但若不能替代 `zx` 的落地权能或 `nx` 的外部条件功能，就不能仅凭其存在否定严格补。
