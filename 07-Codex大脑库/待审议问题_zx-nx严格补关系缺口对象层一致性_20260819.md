# 待审议｜zx↔nx 严格补关系：缺口对象层一致性

## 0｜为什么触发

现行 L1 已明确：木轴 `zx ↔ nx` 是同一核心变量上相反方向的对立统一，但“统一”本身不等于具体案例里已经发生严格补关系。

现行 `zx补nx_补卡` 又要求：

- zx、nx 两端分别独立成立；
- 拿掉任一端，另一端留下可命名缺口；
- 补回后，缺口得到真实改善；
- 普通合作、求人、资源相加不自动构成严格补。

最近连续出现三个跨作品高纯反例：两端都可以独立锁定，前后还有明显时间、因果或位置连续，但二者缺口并不在同一现实变量上，因此无法证明彼此直接补缺。

2026-08-20 加入《水浒传》宋江高唐州严格补正向控制，反证“对象名称必须同名”这一机械解释。2026-08-23 再加入《三国演义》曹操陈留借卫弘家资第二正向控制，进一步证明：外部资源只要直接解除 zx 当前被卡住的现实瓶颈，并在同一有效时间窗口被 zx 兑现回同一目标，即使端点标签不同，也可以是真正严格补。

## 1｜三部独立反向作品

### 1.1 《水浒传》林冲

```text
早期 nx：
林冲本人如何获得梁山成员资格 / 安身准入

后期 zx：
谁掌握梁山最高首领与新成员准入结构
```

前段使林冲身处梁山，是后段发生的历史位置前提；但“我如何入寨”与“谁治理梁山、谁决定别人能否入寨”不是同一现实变量。

结论：`same_gap_object_layer: false`。

### 1.2 《西游记》孙悟空

```text
早期 nx：
是否承接天庭给定的弼马温职务与上位任务

后期 zx：
是否允许天庭以低等级压住自身，以及自身要求的身份/凌驾位置如何进入现实
```

“做弼马温”直接触发“得知未入流 → 反天宫”，但职务承接与身份等级主权不是同一现实变量。

结论：`same_gap_object_layer: false`。

### 1.3 《三国演义》曹操

```text
早期 nx：
秘密刺董路径中的七星宝刀资源接口

后期 zx：
逃回陈留后的公开募兵、发檄、军政动员与影响范围扩张
```

借刀刺董失败直接触发逃亡和公开起兵，但七星刀没有进入陈留募兵体系；后段 zx 也没有补前段“秘密刺杀兵器”缺口。

结论：`same_gap_object_layer: false`。

## 2｜正向控制：对象名不同但同一现实瓶颈

### 2.1 《水浒传》宋江高唐州

```text
zx 端标签：
公开军事推进 / 救柴进 / 破高唐

nx 端标签：
公孙胜专属法术能力 + 罗真人师门许可
```

两端名称并不相同，但它们直接接在同一个现实瓶颈上：

> 宋江已有公开军力，却无法稳定穿透高廉妖法，因此“当前攻城救援无法继续兑现”。

`nx` 接入的专家能力／许可直接解除的就是这个瓶颈；解除以后，宋江重新传令、全军推进，把该条件兑现回同一战役目标。

双向拿掉：

- 拿掉 `nx`：`zx` 仍在，但高廉妖法继续卡住当前攻城救援。
- 拿掉 `zx`：专家／许可仍在，但不会自动生成梁山公开攻城与救援结果。
- 两端补回后，分别直接改善同一个战役瓶颈的两侧缺口。

结论：

```yaml
same_label_object_layer: false
same_real_bottleneck_direct_coupling: true
strict_zx_nx_complement_locked: true
```

### 2.2 《三国演义》曹操陈留借卫弘家资

```text
zx 端标签：
反董起兵 / 公开募兵 / 发檄 / 军政动员

nx 端标签：
卫弘独立家资处分接口
```

两端标签同样不同，但直接对接的是同一个现实瓶颈：

> 曹操已有反董与公开起兵方向，但曹嵩明确指出“资少恐不成事”，即当前公开募兵、装备与军队成形被启动资本不足卡住。

卫弘的家资不是一般背景帮助，而是直接改变这一限制变量。卫弘同意后，家资立即用于置办衣甲旗幡，曹操同步招募义兵、调练军马、发檄扩张，没有经过长阶段闲置或任务重置。

双向拿掉：

- 拿掉 `nx`：曹操 zx 方向仍在，但留下“启动资本/装备不足，公开军队难成形”的直接缺口。
- 拿掉 `zx`：卫弘有钱且愿意给钱，但资本不会自动变成反董募兵、发檄与公开军政行动。
- 两端补回：外部资本被曹操立即兑换成同一陈留起兵目标的现实推进。

结论：

```yaml
same_label_object_layer: false
same_real_bottleneck_direct_coupling: true
same_effective_time_window: true
strict_zx_nx_complement_locked: true
fact_confidence: 99
classification_confidence: 98
```

因此，“对象层一致性”不能机械理解成对象名词必须一致；更可靠的是追踪同一现实限制变量及其有效时间窗口。

## 3｜当前候选纪律（经两个正向控制收窄）

仅进入待审议，不升 L1 / 信息卡 / 准度卡 / 补卡：

> **严格 `zx ↔ nx` 补关系在“两端独立成立 + 双向拿掉”之外，还应增加“同一现实瓶颈直接对接”检查。对象名称可以不同，但双方必须直接改变同一个正在生效的现实限制变量；如果条件进入后长期闲置、环境/目标已经重置，则应重新检查是否仍属于同一轮补关系。**

建议最低检查：

```text
第一门：zx、nx 是否分别独立成立？
↓
第二门：拿掉任一端，另一端是否都留下可命名缺口；补回后是否双向改善？
↓
第三门：A 端提供的资源/权限/作用，是否直接改变 B 端当前被卡住的同一现实瓶颈；B 端是否又把 A 端提供的条件兑现回同一现实目标？
↓
第四门（待继续验证）：这种直接对接是否发生在同一有效时间窗口；若任务、环境、对象状态已经重置，应切阶段复核。
↓
对象标签不同 ≠ 自动伪补
对象标签相同 ≠ 自动真补
```

如果只是时间前提、历史前提、同一人物、同一组织、同一总目标或触发关系，而现实瓶颈已经换掉，优先判普通因果链、压力显影或阶段迁移，不锁严格补关系。

## 4｜为什么不能只要求“同一个总目标”

三个反例都可以被描述成一个很宽的总目标：

- 林冲：都与梁山有关；
- 孙悟空：都与天庭官职有关；
- 曹操：都与反董卓有关。

如果只看总目标，几乎任何连续剧情都能被粘成“互补”。真正有判别力的是：

> **nx 进入以后，是否直接改变 zx 正在缺的那个现实瓶颈；zx 回来以后，是否直接把 nx 提供的条件在同一现实目标上兑现。**

宋江高唐州说明“专家能力/许可”可以直接补军事推进；曹操陈留说明“启动资本/资源”也可以直接补公开动员。两例共同表明：判断应追踪瓶颈因果，而不是按资源标签分类。

## 5｜与真正严格补正例的最小差异

两个正向控制的共同点是：

```text
zx 已有主体方向与公开推进
↓
出现一个具体、可命名、自己无法直接补掉的现实瓶颈
↓
nx 接入外部资源/权限/专家接口
↓
这个接口直接改变的就是 zx 当前被卡住的限制变量
↓
zx 在同一有效窗口内把该条件兑换成同一现实目标的公开推进
```

对象标签可以跨层，例如：

```text
军事推进 ↔ 专家能力/许可
公开动员 ↔ 启动资本/资源
行动权能 ↔ 外部专属处理接口
```

只要有可验证的直接瓶颈对接，就不能因为名词不同误杀真补。

反例则是：

```text
A 只是 B 的历史前提 / 触发前提
或
A、B 虽都属于同一大目标，但分别处理不同现实变量
或
A 曾经补过 B，但中间状态已经重置，后来只是再次利用旧条件
```

## 6｜必须继续反打的问题

### A｜同一现实瓶颈的时间窗口多长？

曹操陈留提供了一个“近乎即时兑现”的正向锚，但仍需要反例：nx 条件确实曾补 zx，随后长期闲置、目标或环境已经重置，后来 zx 才再次出现。此时是否必须切成两个阶段？

### B｜同名对象但不同状态，是否仍是假补？

即使都写作“兵权”“准入权”“身份”，若前后测试的是不同主体、不同权限层或不同生效窗口，也可能不是同一现实瓶颈。

### C｜双向补缺与现实瓶颈对接谁优先？

若双向拿掉已经出现明确缺口，但对象层命名存在争议，应优先追踪限制变量的直接因果链，而不是机械按标签否决。

## 8｜下一轮最值得跑

优先攻击时间窗口反例：

> **zx 与 nx 曾经直接对接同一现实瓶颈，但 nx 条件进入后长期闲置；任务、环境或限制变量已经重置，后来 zx 才再次出现。**

如果这种材料达到 ≥95%，就可以判断：严格补是否必须要求“同一现实瓶颈 + 同一有效时间窗口”，而不是只要求历史上曾经直接补过。
