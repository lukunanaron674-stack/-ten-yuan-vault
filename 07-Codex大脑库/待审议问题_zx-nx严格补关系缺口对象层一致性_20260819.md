# 待审议｜zx↔nx 严格补关系：缺口对象层一致性

## 0｜为什么触发

现行 L1 已明确：木轴 `zx ↔ nx` 是同一核心变量上相反方向的对立统一，但“统一”本身不等于具体案例里已经发生严格补关系。

现行 `zx补nx_补卡` 又要求：

- zx、nx 两端分别独立成立；
- 拿掉任一端，另一端留下可命名缺口；
- 补回后，缺口得到真实改善；
- 普通合作、求人、资源相加不自动构成严格补。

最近连续出现三个跨作品高纯反例：两端都可以独立锁定，前后还有明显时间、因果或位置连续，但二者缺口并不在同一现实变量上，因此无法证明彼此直接补缺。

2026-08-20 加入《水浒传》宋江高唐州严格补正向控制，反证“对象名称必须同名”这一机械解释。2026-08-23 再加入《三国演义》曹操陈留借卫弘家资第二正向控制，进一步证明：外部资源只要直接解除 zx 当前被卡住的现实瓶颈，并在同一有效时间窗口被 zx 兑现回同一目标，即使端点标签不同，也可以是真正严格补。

2026-08-25 对《三国演义》孙策“质玉玺借兵”重新执行双向拿掉与第三因素检查后，撤回旧文件中“初始窗口严格补成立”这一子结论。当前应改判为：

```text
孙策 zx：取江东/扩张方向成立
袁术 nx：兵马资源处分接口成立
nx → zx：成立，兵马解除启动军力不足
zx → nx：不成立，袁术兵马处分接口并不依赖孙策 zx 才能成立
第三因素：传国玉玺的独立交换价值解释袁术合作动机
```

因此孙策不再计入“严格补时间窗口正向控制”。旧文件中“军力后来由 nx 外部资源内化为孙策稳定 x”的资源状态转移观察仍可保留，但只能作为 **nx→x 资源内化 / 历史来源退出** 的独立方法资产，不能再作为“历史严格补后来闭环”的证据。

当前真正仍可作为严格补时间窗口控制的独立作品为：

1. 《水浒传》宋江高唐州：初始严格补成立；原任务完成、原现实瓶颈被消灭并换成新瓶颈后，旧 nx 不再补当前 zx。
2. 《西游记》孙悟空红孩儿：初始严格补成立；红孩儿被收伏、唐僧获救、旧专属瓶颈消失后，旧观音 nx 不得追挂到后续危机。

所以“时间窗口必须重判”的方向仍有高价值，但原先宣称“跨三作品时间窗口严格补控制已满足”的计数必须降回 **2 部独立作品**，等待新的第三作品补足。

## 1｜三部独立反向作品

### 1.1 《水浒传》林冲

```text
早期 nx：林冲本人如何获得梁山成员资格 / 安身准入
后期 zx：谁掌握梁山最高首领与新成员准入结构
```

前段使林冲身处梁山，是后段发生的历史位置前提；但“我如何入寨”与“谁治理梁山、谁决定别人能否入寨”不是同一现实变量。

结论：`same_gap_object_layer: false`。

### 1.2 《西游记》孙悟空

```text
早期 nx：是否承接天庭给定的弼马温职务与上位任务

```

“做弼马温”直接触发“得知未入流 → 反天宫”，但职务承接与身份等级主权不是同一现实变量。

结论：`same_gap_object_layer: false`。

### 1.3 《三国演义》曹操

```text
早期 nx：秘密刺董路径中的七星宝刀资源接口
后期 zx：逃回陈留后的公开募兵、发檄、军政动员与影响范围扩张
```

借刀刺董失败直接触发逃亡和公开起兵，但七星刀没有进入陈留募兵体系；后段 zx 也没有补前段“秘密刺杀兵器”缺口。

结论：`same_gap_object_layer: false`。

## 2｜正向控制：对象名不同但同一现实瓶颈

### 2.1 《水浒传》宋江高唐州

```text
zx 端：公开军事推进 / 救柴进 / 破高唐
nx 端：公孙胜专属法术能力 + 罗真人师门许可
```

两端名称不同，但直接接在同一个现实瓶颈上：宋江已有公开军力，却无法稳定穿透高廉妖法，因此当前攻城救援无法继续兑现。

`nx` 接入的专家能力／许可直接解除的就是这个瓶颈；解除后，宋江重新传令、全军推进，把该条件兑现回同一战役目标。

双向拿掉：

- 拿掉 `nx`：`zx` 仍在，但高廉妖法继续卡住当前攻城救援。
- 拿掉 `zx`：专家／许可仍在，但不会自动生成梁山公开攻城与救援结果。
- 两端补回后，分别直接改善同一个战役瓶颈的两侧缺口。

```yaml
same_label_object_layer: false
same_real_bottleneck_direct_coupling: true
strict_zx_nx_complement_locked: true
```

### 2.2 《三国演义》曹操陈留借卫弘家资

```text
zx 端：反董起兵 / 公开募兵 / 发檄 / 军政动员
nx 端：卫弘独立家资处分接口
```

曹操已有反董与公开起兵方向，但曹嵩明确指出“资少恐不成事”，即当前公开募兵、装备与军队成形被启动资本不足卡住。

卫弘同意后，家资立即用于置办衣甲旗幡，曹操同步招募义兵、调练军马、发檄扩张，没有经过长阶段闲置或任务重置。

双向拿掉：

- 拿掉 `nx`：曹操 zx 方向仍在，但留下启动资本/装备不足的直接缺口。
- 拿掉 `zx`：卫弘有钱且愿意给钱，但资本不会自动变成反董募兵、发檄与公开军政行动。
- 两端补回：外部资本被曹操立即兑换成同一陈留起兵目标的现实推进。

```yaml
same_label_object_layer: false
same_real_bottleneck_direct_coupling: true
same_effective_time_window: true
strict_zx_nx_complement_locked: true
fact_confidence: 99

```

因此，“对象层一致性”不能机械理解成对象名词必须一致；更可靠的是追踪同一现实限制变量及其有效时间窗口。

第十五回孙策已有取江东方向，直属启动兵力不足；袁术掌握三千兵、五百马的外部调用权，孙策以玉玺作质并取得袁术同意。

```text

↓
启动军力不足
↓
袁术 nx：兵马外部资源接口
↓
兵马进入后孙策渡江、招将、扩军
```

但双向拿掉显示：

- 拿掉 `nx`：孙策 zx 留下启动军力不足，`nx→zx` 补缺成立；
- 拿掉孙策 zx：袁术仍有完整兵马处分接口，不会因此失去其核心功能，`zx→nx` 不成立；

## 6｜当前候选纪律（经两个正向控制 + 两个严格补时间窗口控制收窄）

仅进入待审议，不升 L1 / 信息卡 / 准度卡 / 补卡：

> **严格 `zx ↔ nx` 补关系在“两端独立成立 + 双向拿掉”之外，还应增加“同一现实瓶颈直接对接 + 同一有效时间窗口”检查。对象名称可以不同，但双方必须直接改变同一个正在生效的现实限制变量；若当前任务完成、原瓶颈消失或对象状态重置，则旧补关系应闭环结束，后续阶段重新判。历史外部 nx 资源后续内化为主体 x，则属于 nx→x 资源状态转移，不应在没有先证明初始严格补的情况下被拿来充当严格补闭环证据。**

建议最低检查：

```text
第一门：zx、nx 是否分别独立成立？
↓
第二门：拿掉任一端，另一端是否都留下可命名缺口；补回后是否双向改善？
↓
第三门：A 端是否直接改变 B 端当前被卡住的同一现实瓶颈；B 端是否把 A 端提供的条件兑现回同一现实目标？
↓
第四门：这种直接对接是否仍处于同一有效时间窗口？
- 原瓶颈是否仍 active？
- 原任务/对象状态是否仍是同一轮？
- 原 nx 接口是否仍为当前必经门？
↓
资源状态另检：历史 nx 资源是否已稳定进入主体 x？
```

当前第四门的严格补闭环直接控制只剩《水浒传》《西游记》两部独立作品，**未再达到跨3作品强化门槛**。因此时间窗口纪律仍保留 pending-review，但必须把“第三作品补足”重新列为高价值缺口。

## 7｜为什么不能只要求“同一个总目标”

三个反例都可以被描述成一个很宽的总目标：

- 林冲：都与梁山有关；
- 孙悟空：都与天庭官职有关；
- 曹操：都与反董卓有关。

如果只看总目标，几乎任何连续剧情都能被粘成“互补”。真正有判别力的是：

> **nx 进入以后，是否直接改变 zx 正在缺的那个现实瓶颈；zx 回来以后，是否直接把 nx 提供的条件在同一现实目标上兑现。**

宋江高唐州说明“专家能力/许可”可以直接补军事推进；曹操陈留说明“启动资本/资源”也可以直接补公开动员。两例共同表明：判断应追踪瓶颈因果，而不是按资源标签分类。

## 8｜与真正严格补正例的最小差异

两个正向控制共同结构：

```text
zx 已有主体方向与公开推进
↓
出现一个具体、可命名、自己无法直接补掉的现实瓶颈
↓
nx 接入外部资源/权限/专家接口
↓
该接口直接改变 zx 当前被卡住的限制变量
↓
zx 在同一有效窗口内把该条件兑换成同一现实目标的公开推进
```

但必须额外满足：

```text
拿掉 zx 后
nx 自身也留下只能由 zx 补回的不可替代缺口
```

否则即使 nx 对 zx 极关键，也只能记单向补。孙策质玺借兵就是最新反向控制。

## 9｜必须继续反打的问题

### A｜第三份严格补时间窗口闭环能否补回？
