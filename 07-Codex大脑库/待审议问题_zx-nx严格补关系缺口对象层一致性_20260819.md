# 待审议｜zx↔nx 严格补关系：缺口对象层一致性

## 0｜为什么触发

现行 L1 已明确：木轴 `zx ↔ nx` 是同一核心变量上相反方向的对立统一，但“统一”本身不等于具体案例里已经发生严格补关系。

现行 `zx补nx_补卡` 又要求：

- zx、nx 两端分别独立成立；
- 拿掉任一端，另一端留下可命名缺口；
- 补回后，缺口得到真实改善；
- 普通合作、求人、资源相加不自动构成严格补。

最近连续出现三个跨作品高纯反例：两端都可以独立锁定，前后还有明显时间、因果或位置连续，但二者缺口并不在同一对象层，因此无法证明彼此直接补缺。

## 1｜三部独立作品

### 1.1 《水浒传》林冲

```text
早期 nx：
林冲本人如何获得梁山成员资格 / 安身准入

后期 zx：
谁掌握梁山最高首领与新成员准入结构
```

前段使林冲身处梁山，是后段发生的历史位置前提；但“我如何入寨”与“谁治理梁山、谁决定别人能否入寨”不是同一对象层。

结论：`same_gap_object_layer: false`。

### 1.2 《西游记》孙悟空

```text
早期 nx：
是否承接天庭给定的弼马温职务与上位任务

后期 zx：
是否允许天庭以低等级压住自身，以及自身要求的身份/凌驾位置如何进入现实
```

“做弼马温”直接触发“得知未入流 → 反天宫”，但职务承接与身份等级主权不是同一现实变量。

结论：`same_gap_object_layer: false`。

### 1.3 《三国演义》曹操

```text
早期 nx：
秘密刺董路径中的七星宝刀资源接口

后期 zx：
逃回陈留后的公开募兵、发檄、军政动员与影响范围扩张
```

借刀刺董失败直接触发逃亡和公开起兵，但七星刀没有进入陈留募兵体系；后段 zx 也没有补前段“秘密刺杀兵器”缺口。

结论：`same_gap_object_layer: false`。

## 2｜当前候选纪律

仅进入待审议，不升 L1 / 信息卡 / 准度卡 / 补卡：

> **严格 `zx ↔ nx` 补关系在“两端独立成立 + 双向拿掉”之外，还应增加“缺口对象层一致性 / 同一现实变量直接对接”检查。**

建议最低检查：

```text
第一门：zx、nx 是否分别独立成立？
↓
第二门：拿掉任一端，另一端是否都留下可命名缺口；补回后是否双向改善？
↓
第三门：A 端提供的资源/权限/作用，是否直接改变 B 端正在缺的同一对象层、同一现实变量？
↓
如果只是：
时间前提 / 历史前提 / 同一人物 / 同一组织 / 同一总目标 / 触发关系
而缺口对象已经换掉
→ 优先判普通因果链、压力显影或阶段迁移，不锁严格补关系。
```

## 3｜为什么不能只要求“同一个总目标”

三个反例都可以被描述成一个很宽的总目标：

- 林冲：都与梁山有关；
- 孙悟空：都与天庭官职有关；
- 曹操：都与反董卓有关。

如果只看总目标，几乎任何连续剧情都能被粘成“互补”。真正有判别力的是：

> **nx 进入以后，是否直接改变 zx 正在缺的那个变量；zx 回来以后，是否直接把 nx 提供的条件在同一现实目标上兑现。**

## 4｜与真正严格补正例的最小差异

已有高质量严格补正例的共同点是：

```text
zx 已有主体方向与公开推进
↓
出现一个具体、可命名、自己无法直接补掉的资源/权限/专属能力缺口
↓
nx 接入外部资源/权限/专家接口
↓
这个接口直接补的就是 zx 当前被卡住的那个变量
↓
zx 再把该条件兑换成同一现实目标的公开推进
```

例如“公开军事推进缺专属破法接口 → 外部专家/许可直接补破法 → 原军事目标继续兑现”，与“先借刺杀刀、后来改走公开募兵”不同。

## 5｜必须继续反打的问题

当前候选纪律仍需至少一轮真正反例测试：

### A｜对象层名称不同，但是否仍可能直接补同一现实变量？

例如资源层和权限层名称不同，但一个明确改变另一个的现实瓶颈，不能因名词不同就误杀真补。

### B｜同一对象层，但时间跨度很长，是否仍可构成严格补？

如果中间条件已重置，不能仅凭对象名相同认定仍在补同一个缺口。

### C｜双向补缺与“同对象层”谁优先？

若双向拿掉已经出现明确直接缺口，而对象层边界存在命名争议，应优先检查实际变量是否直接因果对接，而不是机械按标签否决。

> 两端表面属于不同对象名（例如资源 vs 权限、专家能力 vs行动接口），但能证明 A 的进入直接修复 B 当前缺口，而且双向拿掉都过。

如果这种案例成立，就能把本待审议从“对象层必须同名”进一步收窄为更准确的：

> **对象层可以不同名，但必须在同一现实变量上存在直接、不可替代的缺口对接。**
