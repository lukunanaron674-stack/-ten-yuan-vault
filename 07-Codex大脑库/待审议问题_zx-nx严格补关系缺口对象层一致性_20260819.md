# 待审议｜zx↔nx 严格补：对象层一致性

## 1｜仍然成立的反向边界

跨三部作品的对象层错位控制仍然有效：

- 《水浒传》林冲：早期“我如何入梁山”的 nx，与后期“谁决定寨主/准入结构”的 zx 不是同一对象层。
- 《西游记》孙悟空：弼马温职务承接 nx，与后续身份等级/凌驾位置 zx 不是同一对象层。
- 《三国演义》曹操：七星刀秘密刺董资源 nx，与陈留公开起兵 zx 不是同一现实变量。

因此继续保留：

> **时间连续、因果连续、人物连续，都不能替代同一对象层/同一现实瓶颈。**

“先发生 A、后发生 B”“A 是 B 的历史前提”都不足以证明 A/B 构成严格补。

## 2｜曹操—卫弘恢复为当前正本下的正向控制

此前本文件把《三国演义》曹操陈留借卫弘家资降成单向补，依据的是一个后来发现与正本冲突的更严候选门：

> 拿掉 zx 后，必须损伤 nx 自身资源/许可/专业能力本体。

当前 `zx补nx_补卡` 并没有这条额外要求。正本明确写：

```text
zx 补 nx
= 把借到的资源、关系与通道转成实际行动、公开决定和结果推进
= 改善 nx 单独运行时“有路径却缺落地权能”的缺口
```

曹操—卫弘按正本复核：

```text
zx 端：曹操反董、募兵、发檄、公开起兵
nx 端：卫弘独立家资接口
当前瓶颈：起兵启动资本 / 装备不足
```

拿掉 nx：曹操方向仍成立，但资本、衣甲旗幡与募兵规模留下明确缺口。

拿掉 zx：卫弘资源路径仍成立，但缺把外部家资转换成公开起兵与现实军政推进的落地权能。

补回后，卫弘家资被曹操立即兑换成衣甲旗幡、募兵与公开行动。

所以当前：

```yaml
same_label_object_layer: false
same_real_bottleneck_direct_coupling: true
strict_zx_nx_complement_under_current_canonical: true
fact_confidence: 99
classification_confidence: 99
```

这重新支持一个较窄结论：

> **对象名称不必机械同名；只要两端独立成立，并直接咬住同一个当前现实瓶颈，仍可能构成当前正本意义下的严格补。**

## 3｜宋江高唐州等旧正向材料改为“按正本待重验”

以下旧材料此前也被更严候选门降级：

- 《水浒传》宋江高唐州；
- 《三国演义》孙策质玺借兵；
- 《红楼梦》鸳鸯抗婚；
- 《西游记》孙悟空红孩儿。

它们当前不能继续写成“已证实单向补”，也不能自动恢复严格补，统一状态为：

```yaml
status: canonical-revalidation-pending
```

必须逐案按现 `zx补nx_补卡` 重验：

1. 两端是否独立成立；
2. 是否同一当前现实瓶颈；
3. 拿掉 nx 后 zx 是否留下可命名缺口；
4. 拿掉 zx 后 nx 是否出现正本意义上的“有路径却缺落地权能”；
5. 是否只是普通合作/资源相加；
6. 第三因素是否制造伪双向；
7. 两端是否处于同一有效窗口。

## 4｜严格补时间窗口统计暂不恢复

此前“严格补时间窗口”主要依赖宋江高唐州、红孩儿等材料；这些案例现在仍在按正本重验。

所以目前仍保持：

```yaml
verified_strict_temporal_window_control_count: 0
```

但这不影响更基础的 nx 动态纪律：

```text
nx 真实激活
→ 任务完成 / 瓶颈消失 / 接口退出 / 资源内化
→ 旧 nx 不得永久追挂后续阶段
```

只有在初始阶段重新证明严格补以后，才有资格把对应闭环计入“严格补时间窗口”。

## 5｜当前可保留的对象层方法

1. 两端必须先独立成立；
2. 时间连续、人物连续、因果连续不能替代对象层一致；
3. 对象名称相同不自动等于同一现实瓶颈；
4. 对象名称不同也不自动排除严格补；
5. 更可靠的是追踪：**两端是否直接作用于同一个当前现实限制变量**；
6. 拿掉任一端时，必须按当前正本检查另一端是否仍成立但出现可命名缺口；
7. “nx 自身核心能力本体必须受损”只属于候选新门，不得覆盖当前正本；
8. 第三因素冻结仍需保留两个端点和当前瓶颈，不能通过删题制造结论。
