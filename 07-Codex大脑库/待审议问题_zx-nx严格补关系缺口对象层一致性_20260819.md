# 待审议｜zx↔nx 严格补关系：缺口对象层一致性

## 0｜为什么触发

现行 L1 已明确：木轴 `zx ↔ nx` 是同一核心变量上相反方向的对立统一，但“统一”本身不等于具体案例里已经发生严格补关系。

现行 `zx补nx_补卡` 又要求：

- zx、nx 两端分别独立成立；
- 拿掉任一端，另一端留下可命名缺口；
- 补回后，缺口得到真实改善；
- 普通合作、求人、资源相加不自动构成严格补。

最近连续出现三个跨作品高纯反例：两端都可以独立锁定，前后还有明显时间、因果或位置连续，但二者缺口并不在同一现实变量上，因此无法证明彼此直接补缺。

2026-08-20 加入《水浒传》宋江高唐州严格补正向控制，反证“对象名称必须同名”这一机械解释。2026-08-23 再加入《三国演义》曹操陈留借卫弘家资第二正向控制，进一步证明：外部资源只要直接解除 zx 当前被卡住的现实瓶颈，并在同一有效时间窗口被 zx 兑现回同一目标，即使端点标签不同，也可以是真正严格补。

时间窗口方面，现已有两种不同闭环机制：

1. 《三国演义》孙策：外部 nx 资源完成补缺后内化为主体稳定 `x`，旧 nx 门退出。
2. 《水浒传》宋江高唐州：外部关系仍存在，但原任务完成、原现实瓶颈被消灭并换成新瓶颈，旧 nx 不再补当前 zx。

因此时间窗口不能机械按章节、时长或“关系还在不在”切分，而要检查当前瓶颈与接口状态。

## 1｜三部独立反向作品

### 1.1 《水浒传》林冲

```text
早期 nx：林冲本人如何获得梁山成员资格 / 安身准入
后期 zx：谁掌握梁山最高首领与新成员准入结构
```

前段使林冲身处梁山，是后段发生的历史位置前提；但“我如何入寨”与“谁治理梁山、谁决定别人能否入寨”不是同一现实变量。

结论：`same_gap_object_layer: false`。

### 1.2 《西游记》孙悟空

```text
早期 nx：是否承接天庭给定的弼马温职务与上位任务
后期 zx：是否允许天庭以低等级压住自身，以及自身要求的身份/凌驾位置如何进入现实
```

“做弼马温”直接触发“得知未入流 → 反天宫”，但职务承接与身份等级主权不是同一现实变量。

结论：`same_gap_object_layer: false`。

### 1.3 《三国演义》曹操

```text
早期 nx：秘密刺董路径中的七星宝刀资源接口
后期 zx：逃回陈留后的公开募兵、发檄、军政动员与影响范围扩张
```

借刀刺董失败直接触发逃亡和公开起兵，但七星刀没有进入陈留募兵体系；后段 zx 也没有补前段“秘密刺杀兵器”缺口。

结论：`same_gap_object_layer: false`。

## 2｜正向控制：对象名不同但同一现实瓶颈

### 2.1 《水浒传》宋江高唐州

```text
zx 端：公开军事推进 / 救柴进 / 破高唐
nx 端：公孙胜专属法术能力 + 罗真人师门许可
```

两端名称不同，但直接接在同一个现实瓶颈上：宋江已有公开军力，却无法稳定穿透高廉妖法，因此当前攻城救援无法继续兑现。

`nx` 接入的专家能力／许可直接解除的就是这个瓶颈；解除后，宋江重新传令、全军推进，把该条件兑现回同一战役目标。

双向拿掉：

- 拿掉 `nx`：`zx` 仍在，但高廉妖法继续卡住当前攻城救援。
- 拿掉 `zx`：专家／许可仍在，但不会自动生成梁山公开攻城与救援结果。
- 两端补回后，分别直接改善同一个战役瓶颈的两侧缺口。


### 2.2 《三国演义》曹操陈留借卫弘家资

```text
zx 端：反董起兵 / 公开募兵 / 发檄 / 军政动员
nx 端：卫弘独立家资处分接口
```

曹操已有反董与公开起兵方向，但曹嵩明确指出“资少恐不成事”，即当前公开募兵、装备与军队成形被启动资本不足卡住。

卫弘同意后，家资立即用于置办衣甲旗幡，曹操同步招募义兵、调练军马、发檄扩张，没有经过长阶段闲置或任务重置。

双向拿掉：

- 拿掉 `nx`：曹操 zx 方向仍在，但留下启动资本/装备不足的直接缺口。
- 拿掉 `zx`：卫弘有钱且愿意给钱，但资本不会自动变成反董募兵、发檄与公开军政行动。

### 3.1 初始窗口：严格补成立

```text
↓
现实瓶颈：启动军力不足
↓
```

### 3.2 闭环结束：旧 nx 资源内化为 x

江东平定后，孙策已经能够自行分拨将士、守把隘口。第十七回袁术反而向孙策借兵，孙策可以直接拒绝，并自行点军守江口、决定后续军事路线。

## 4｜时间窗口控制二：《水浒传》宋江高唐州——任务／瓶颈重置闭环

### 4.2 闭环结束：不是关系消失，而是任务完成

- 高唐州已被攻入；

- 梁山离开高唐州返回山寨。

> **严格补闭环不要求 nx 资源一定内化成 x。若当前任务已经完成、原现实瓶颈被消灭或对象状态重置，即使旧关系仍然存在，也不能把旧 nx 永久挂在后续 zx 上。**

## 5｜当前候选纪律（经两个正向控制 + 两个时间窗口控制收窄）

仅进入待审议，不升 L1 / 信息卡 / 准度卡 / 补卡：

> **严格 `zx ↔ nx` 补关系在“两端独立成立 + 双向拿掉”之外，还应增加“同一现实瓶颈直接对接 + 同一有效时间窗口”检查。对象名称可以不同，但双方必须直接改变同一个正在生效的现实限制变量；若外部条件已内化为主体稳定 `x`，或当前任务完成、原瓶颈消失、对象状态重置，则旧补关系应闭环结束，后续阶段重新判。**

建议最低检查：

```text
第一门：zx、nx 是否分别独立成立？
↓
第二门：拿掉任一端，另一端是否都留下可命名缺口；补回后是否双向改善？
↓
第三门：A 端是否直接改变 B 端当前被卡住的同一现实瓶颈；B 端是否把 A 端提供的条件兑现回同一现实目标？
↓
第四门：这种直接对接是否仍处于同一有效时间窗口？
- 原瓶颈是否仍 active？
- 原任务/对象状态是否仍是同一轮？
- 原 nx 接口是否仍为当前必经门？
- 外部条件是否已内化为主体 x？
↓
对象标签不同 ≠ 自动伪补
对象标签相同 ≠ 自动真补
关系仍存在 ≠ 旧补仍存在
历史上曾经真补 ≠ 当前仍在真补
```

当前第四门已有两部独立作品 99/97 控制，但尚未达到三作品门槛，因此仍保持待审议，不升级核心规则。

## 6｜为什么不能只要求“同一个总目标”

三个反例都可以被描述成一个很宽的总目标：

- 林冲：都与梁山有关；
- 孙悟空：都与天庭官职有关；
- 曹操：都与反董卓有关。

如果只看总目标，几乎任何连续剧情都能被粘成“互补”。真正有判别力的是：

> **nx 进入以后，是否直接改变 zx 正在缺的那个现实瓶颈；zx 回来以后，是否直接把 nx 提供的条件在同一现实目标上兑现。**

宋江高唐州说明“专家能力/许可”可以直接补军事推进；曹操陈留说明“启动资本/资源”也可以直接补公开动员。两例共同表明：判断应追踪瓶颈因果，而不是按资源标签分类。

两个时间窗口控制又进一步说明：即使历史上曾经直接对接过同一瓶颈，只要当前瓶颈已经解决、资源已经内化、任务已经完成或对象状态已经重置，就不能把旧补关系永久追挂到后续 zx。

## 7｜与真正严格补正例的最小差异

两个正向控制共同结构：

```text
zx 已有主体方向与公开推进
↓
出现一个具体、可命名、自己无法直接补掉的现实瓶颈
↓
nx 接入外部资源/权限/专家接口
↓
该接口直接改变 zx 当前被卡住的限制变量
↓
zx 在同一有效窗口内把该条件兑换成同一现实目标的公开推进
```

反例或闭环结束则包括：

```text
A 只是 B 的历史前提 / 触发前提
或
A、B 虽都属于同一大目标，但分别处理不同现实变量
或
A 曾经补过 B，但原任务/瓶颈已经完成并重置
或
A 曾是外部 nx 条件，但已被吸收成主体稳定 x
```

## 8｜必须继续反打的问题

### A｜时间窗口能否形成第三部独立作品复验？

现有两种机制：

1. 《三国演义》孙策：资源内化为 `x` 后闭环结束；
2. 《水浒传》宋江：关系仍在，但任务完成、瓶颈被消灭后闭环结束。

下一步优先去《西游记》或《红楼梦》寻找第三种 ≥95% 控制，确认第四门不是两个漂亮个案。

### B｜同名对象但不同状态，是否仍是假补？

即使都写作“兵权”“准入权”“身份”，若前后测试的是不同主体、不同权限层或不同生效窗口，也可能不是同一现实瓶颈。

### C｜双向补缺与现实瓶颈对接谁优先？

若双向拿掉已经出现明确缺口，但对象层命名存在争议，应优先追踪限制变量的直接因果链，而不是机械按标签否决。
