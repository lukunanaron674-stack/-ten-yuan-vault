# 体量、显影强度与关系作用量分离协议 v1.0

## 1. 协议目的

本协议解决三个经常被混写的问题：

```text
一个十元在对象中占多大位置；
一个十元在当前阶段表现得多明显；
一个关系实际改变目标多少。
```

三者必须分别记录，不得统一写成“力量大小”。

## 2. 三个量的正式区分

### 2.1 体量

体量描述某个已判定十元在指定对象结构中的占位规模与组织范围。

```text
体量回答：
这个十元在该对象中占多大结构位置？
```

体量不等于：

```text
战斗力；
压迫感；
情绪强烈程度；
画面明暗；
关系必胜概率；
箭头本身的力量。
```

体量必须绑定：

```text
具体对象；
具体对象层；
具体阶段；
已经独立成立的十元判断。
```

不得写脱离对象的“某十元天然体量更大”。

### 2.2 显影强度

显影强度描述某个已经存在或已经判定的十元，在当前材料、场景或阶段中表现得多明显。

```text
显影强度回答：
当前看得有多清楚、被调用得有多集中？
```

低显影不等于低体量，高显影也不等于高体量。

例如：

```text
人物稳定本体体量较高，当前阶段却低显影；
人物某次行为中的副元高显影，但不占人物稳定本体的大体量；
场景通过光影放大某种感受，只提高观看层显影，不改写人物体量。
```

### 2.3 关系作用量

关系作用量描述源端点通过已确认机制，对目标端点某个变量造成的实际改变量。

```text
关系作用量回答：
这次生、克、补究竟改变了目标多少？
```

关系作用量必须绑定：

```text
源端点；
目标端点；
作用机制；
目标变量；
所属阶段；
变化前后证据。
```

关系成立与作用量大小是两个问题：

```text
关系可以成立，但作用量很小；
关系可以持续累积，后期作用量才变大；
源端点体量很大，也可能没有有效改变目标；
源端点体量较小，也可能在关键节点改变目标路径。
```

## 3. 禁止互相代替

禁止以下推理：

```text
体量大，所以必然克制成功；
画面显影强，所以人物本体体量大；
一次作用量大，所以目标人物本体被改写；
关系持续很久，所以关系体量一定大；
角色戏份多，所以对应十元体量高；
情绪爆发强，所以稳定本体发生改变。
```

正确顺序是：

```text
先判断对象与十元；
再判断该十元在对象中的体量；
再判断当前阶段的显影强度；
最后依据机制与目标变量，判断关系作用量。
```

## 4. 1—10 标尺的使用权限

1—10 可以作为工作标尺，但三个量必须分别打分：

```text
体量：T1—T10
显影强度：M1—M10
关系作用量：E1—E10
```

不得只写一个裸数字。

数字只表示同一分析框架中的相对工作判断，不自动拥有跨案例、跨对象、跨阶段的绝对可比性。

没有足够证据时允许写：

```text
T未判定
M未判定
E未判定
```

不得为了图表完整而伪造精度。

## 5. 动态链中的使用规则

每个阶段至少分别检查：

```text
端点十元是否仍成立；
端点体量是否变化；
显影强度是否变化；
关系机制是否继续成立；
关系作用量是否累积、衰减、反转或中断；
目标变化落在哪个对象层。
```

前一阶段的高作用量不自动继承到后一阶段。

动态链推进后，人物变化优先落在：

```text
当前状态；
行为功能；
关系位置；
场景承载；
时间压力；
资源与路径；
显影强度；
关系作用量。
```

人物稳定本体与其体量优先保持，除非重新通过独立的本体审核。

## 6. 场景、光影与时间的边界

### 场景

场景可以改变行动范围、资源、选择成本和关系位置，也可以提高或降低某种十元的显影强度。

场景不能仅凭压迫、空旷、温暖或封闭的表面感觉，直接赋予人物体量。

### 光影

光影主要改变观看方式、信息显露、注意力与视觉显影强度。

光影强烈不等于人物十元体量大，也不等于关系作用量大。

### 时间关系

等待、重复、积累、延迟和不可逆节点，可以使关系作用量累积或改变显影强度。

时间长度本身不自动等于作用量；必须证明目标变量确实被改变。

## 7. 三元与十元并行规则

三元与十元可以分别记录体量、显影和关系变化，但不得互相派生：

```text
三元比例不能直接生成十元体量；
十元体量不能自动推出唯一三元比例；
三元显影不能代替十元端点判断；
十元关系作用量不能反向补写三元本体。
```

发生冲突时返回原始证据，分别复核对象层、三元判断与十元判断。

## 9. 当前冻结结论

```text
体量、显影强度与关系作用量是三个不同量。
体量不是力量，也不是箭头的固有权重。
高显影不等于高体量，高体量不等于高作用量。
关系是否成立与关系改变目标多少必须分别判断。
1—10 标尺必须写明 T、M 或 E，不允许裸数字。
人物核心锚点优先稳定，变化优先落在状态、行为、关系、场景、时间结构、显影和作用量。
三元与十元并行判断，不构成父子派生。
```
