# 待审议｜nx 外部接口恢复旧 x 与 zx 扩权边界

## 1｜触发原因

连续材料出现同一边界：

```text
旧 x 真实存在
→ 旧 x 真实丢失
→ 主体无法单独恢复
→ 外部 nx 权限 / 能力接口直接作用于同一个对象
→ 同一个旧 x 恢复
```

同时多份材料显示：

```text
旧 x 恢复
≠ 自动 zx
```

只有恢复后主体决定范围进一步超过旧基线，才另查 zx。

本问题达到三份独立作品/史料门槛，仅进入 pending-review，不直接修改 L1 或信息卡。

## 2｜三份正向控制

### A｜《水浒传》施恩快活林

- 原快活林经营/收益控制属于施恩既有 x。
- 蒋门神现实夺走该控制。
- 施恩无法自行恢复，实际请求武松这一外部强制能力接口。
- 武松直接迫使蒋门神把快活林家火什物交还原主施恩。
- 同一对象重新进入施恩稳定调用边界。

机制：`x丢失 → nx外部强制 → 同对象x恢复`。

### B｜《明史》海瑞释狱复故官

- 海瑞原户部主事职位 x 真实存在。
- 入诏狱、论死后现实履职接口退出。
- 穆宗即位，朝廷释放并“复故官”。
- 原官职权限由外部正式授权重新启用。

机制：`x丢失 → nx正式任命 → 同对象x恢复`。

### C｜《宋史》李纲被罢后复尚书右丞

- 李纲原尚书右丞职位及现实履职权限真实存在。
- 靖康元年二月正式被罢，旧职位权限退出。
- 士民伏阙形成政治压力，但最终复任接口仍在皇帝/朝廷。
- 皇帝正式“复纲右丞”，李纲重新履职。

机制：`x丢失 → nx正式复任 → 同对象x恢复`。

## 3｜反向控制

### A｜《西游记》孙悟空金箍棒

- 金箍棒 x 丢失。
- 多个 nx 外援真实参与危机。
- 这些外援没有直接恢复金箍棒。
- 最终孙悟空自己潜入洞中取回。

结论：`有nx外援参与 ≠ nx恢复同对象x`。

### B｜《水浒传》林冲野猪林

- 林冲刺配后人身移动 x 已退出。
- 鲁智深 nx 救援成功解决“被秘密杀害”这一新增危机。
- 刺配公文、押解与沧州收管继续。

结论：`nx解决旁支危机 ≠ 原x恢复`。

## 4｜当前候选纪律

### 候选 1｜同对象直接恢复

要锁 `nx → x恢复`，至少检查：

1. 被测试 x 在此前真实存在；
2. 该 x 后来真实退出，而非只是受威胁；
3. 外部 nx 接口真实参与；
4. nx 接口直接作用于同一个被测试对象，而非只解决旁支危机；
5. 结果使同一个对象重新进入主体稳定调用/处分边界。

### 候选 2｜恢复旧 x 不自动 zx

```text
恢复到旧基线
→ x恢复

超过旧基线、形成新的更大决定范围
→ 才另查zx
```

职位“复任”、地盘“夺回”、资源“取回”、许可“恢复”都不能仅凭词面判 zx。

### 候选 3｜nx 是恢复接口，不等于稳定人物本体 nx

主体可以非常有主见；只要恢复同一对象所需的最终权限/能力真实在外部，并且主体实际承接该接口，就可以锁 nx 关系/权限功能。

## 5｜最近邻排除

### nx vs x

- nx：恢复入口为什么必须经过外部权限/能力。
- x：恢复完成后，该对象是否重新归主体稳定调用。

### x恢复 vs zx

- x恢复：回到已有基线。
- zx：决定范围继续向旧基线之外扩张。

### nx vs xn

复职流程、救援安排、申诉组织等可能有 xn 邻近；若主体没有主动重建决定性运行骨架，不以 xn 覆盖 nx 恢复接口。

## 6｜拿掉测试模板

```text
拿掉外部nx接口
→ 原x能否自行恢复？

拿掉“同对象恢复”结果
→ 是否只剩旁支危机改善？

拿掉旧x真实存在
→ 后续是否其实是新建x而非恢复？

拿掉旧基线
→ zx是否仍有真实扩权证据？
```

## 7｜下一步审议问题

1. “正式复任但实际权限未恢复”是否只算名位恢复、不能算 x 恢复？
2. 外部接口只恢复部分对象层时，x 是否应分层恢复而非整包恢复？
3. nx 恢复旧 x 后，如果主体立即借恢复位置继续向外扩权，何处开始从 x恢复切入 zx？
4. 强制恢复、正式授权恢复、关系担保恢复是否都共享同一底层结构，还是需要继续分型？
