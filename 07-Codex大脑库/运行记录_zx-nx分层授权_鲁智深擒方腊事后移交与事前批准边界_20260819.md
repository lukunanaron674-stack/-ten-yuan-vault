# 运行记录｜鲁智深擒方腊：事后移交 ≠ 事前批准

## 0｜本轮目的

在王熙凤宁府迟到处分案例已经确认“决定先独立生效、执行后回覆，不等于事前批准”后，寻找第二部独立作品的正向控制。

本轮只切《水浒传》第一百一十九回的窄窗口：鲁智深在征方腊总任务内，追敌入山、擒获方腊，随后把已被绑缚的方腊带去见宋江。检查：

```text
事后把结果移交更高节点
是否等于
行动发生前必须取得更高节点批准？
```

结论：不等于。

## 1｜剧情事实、触发、对象、动作、结果

### 触发

宋军征方腊进入末段。鲁智深此前在乌龙岭追赶夏侯成，深入山中并迷路。

### 明确动作

原文叙述：鲁智深追赶夏侯成入山并将其杀死；随后遇一老僧，被引到茅庵等待。次日方腊从松林中出现，鲁智深当场以禅杖打翻、绑缚。之后遇到搜山军健，才一同把已经擒获的方腊带去见宋江。

顺序为：

```text
发现对象
→ 鲁智深直接出手
→ 方腊被打翻、绑缚
→ 捕获结果已经成立
→ 遇搜山军健
→ 带方腊见宋江
```

不是：

```text
发现方腊
→ 先报宋江
→ 等宋江批准“可以擒”
→ 再实施捕获
```

### 结果

宋江见方腊已经被擒后大喜，随后才进入更高一层的俘虏处置：令将方腊装入陷车，解送东京面见天子。

因此必须把“现场捕获”与“后续最高处置/押解”分层。

## 2｜nx 检查

### 上位征剿方向

鲁智深并非自己创造“征讨、擒获方腊集团”的最高战略方向。他仍处于宋军奉朝廷征方腊的总任务中。

因此：

```text
nx_upper_campaign_direction: evidence-locked
```

### 当前捕获微窗口

但在“眼前是否立即制服并绑缚方腊”这一对象层，鲁智深没有沿另一个外部批准接口推进，也没有等宋江逐项放行。

```text
nx_preapproval_relation_in_capture_microstage: rejected
```

关键纪律：

> **事后移交结果给更高节点，不等于行动前需要更高节点批准。**

后续把方腊交给宋江、再由宋江决定陷车解京，是新的更高处置层，不能倒推现场捕获层属于 `nx` 事前批准。

## 3｜x 检查

当前最强最近邻为局部 `x`：

```text
x_local_capture_execution_boundary: evidence-locked
```

理由不取自“鲁智深是将领/和尚/很能打”这些身份与能力标签，而取自实际行为链：

- 明确敌方目标出现；
- 鲁智深可当场决定实施捕获；
- 捕获无需逐项回宋江批准；
- 结果先独立生效；
- 更高节点只能在捕获之后接手后续处置。

这说明至少在当前战场执行对象层，行动接口已经真实进入鲁智深可直接调用的边界。

注意：本轮不把“方腊最终怎么处置、是否押京、如何定罪”的权限也算给鲁智深。那一层仍明显外置。

## 4｜zx 检查

本轮不因为“鲁智深亲手擒方腊、结果巨大”而新增 `zx`。

```text
zx_new_expansion_in_capture_microstage: rejected_as_primary
```

原因：

- 当前行为发生在既有征讨任务与战场执行范围内；
- 没看到鲁智深借此取得一个此前不存在、以后稳定扩大的更高处分边界；
- 宋军、朝廷没有因此承认“方腊集团最高处置权归鲁智深”；
- 捕获成功是结果，不等于决定范围扩大。

若把“抓到终极敌人”直接判 `zx`，就会把重大成功结果偷换成扩权。

## 5｜xn 最近邻

`xn` 很低。

鲁智深并没有自己设计完整追捕流程、人员调度、长期节点；甚至等待方腊出现这一节点来自老僧指引。

因此本轮核心不是“鲁智深如何组织计划”，而是：

> **现场行动能否不经逐项批准而直接生效。**

## 6｜关键压力

关键压力是战争末段、敌方首领逃亡、现场窗口短暂。

但“战场紧急”不能单独证明 `x`。真正有判别力的是：

```text
鲁智深直接实施
+
结果先成立
+
之后才移交更高节点
```

若文本写成“发现方腊后必须先遣人请示宋江”，即便同样紧急，分类会改变。

## 7｜拿掉测试

### 拿掉鲁智深武力标签

只保留：

```text
目标出现
→ 主体可直接实施职责内捕获
→ 结果生效
→ 事后移交
```

“事后移交 ≠ 事前批准”仍成立。

### 拿掉老僧指引

鲁智深如何遇到方腊的偶然性会变化，但捕获发生后权限时间顺序不变。

### 拿掉宋江后续“装陷车解东京”

现场捕获早已完成，局部 `x` 不受影响。

### 拿掉现场独立生效能力

若改为：

```text
鲁智深发现方腊
→ 只能监视/围住
→ 必须先报宋江
→ 宋江批准后才能绑缚
```

则局部 `x` 显著下降，`nx` 事前批准关系上升。

## 8｜反向测试

### 反向成 nx

```text
行动建议由鲁智深提出
→ 宋江拥有实时否决权
→ 未批准前鲁智深不能让捕获生效
```

### 反向成 zx

```text
鲁智深原本只拥有一般战斗执行权
→ 本次公开夺取敌方最高处置/军政处分权
→ 宋军与朝廷以后承认这一新增决定接口
```

当前文本没有。

### 反向成仅行为而非 x

若鲁智深只是偶然击倒方腊，但随后必须等待别人决定能否拘押、且无法保持控制，那么局部 `x` 证据会下降。本段实际已有绑缚并带走，控制结果真实持续到移交。

## 9｜第三因素冻结

冻结：鲁智深武力强弱、方腊是否“终极敌人”、老僧神异、征方腊胜负、朝廷招安主题、鲁智深后续坐化、人物忠义评价。

只保留：

```text
最高任务是谁给的？
现场捕获是谁决定并先让结果生效？
是否需要事前批准？
移交发生在捕获前还是捕获后？
更高节点接手的是“批准捕获”还是“后续处置”？
```

## 10｜与王熙凤宁府处分的最小差异

### 王熙凤

```text
直接定处罚
→ 处罚执行
→ 执行者回覆
= 处分先独立生效，后回覆
```

### 鲁智深

```text
直接制服并绑缚方腊
→ 捕获结果成立
→ 随后带去见宋江
→ 宋江再处理押解东京
= 捕获先独立生效，后移交
```

两部作品共同支持：

> **“事后报告 / 回覆 / 移交”不能倒推成“决定生效前必须取得外部批准”。判 `nx ↔ x` 必须检查时间顺序与对象层。**

目前同型高纯控制作品数：2（红楼梦、水浒传）。尚未达到三作品门槛，不修改理论正本。
