# 运行记录｜曹操许都实际裁决与献帝名义上级伪 nx 第二反向控制

## 1｜本轮问题

测试一个容易误判的结构：

```text
名义最高上级仍存在
↓
是否因此自动形成 nx 权限关系？
```

结论：**不能。必须继续追踪当前对象层谁拥有真实可使用的否决、修改、处分与最终裁决接口。**

## 2｜剧情 / 史料事实

《后汉书·献帝纪》与相关传记记载，建安元年曹操迎献帝迁许，自领司隶校尉、录尚书事。更关键的是《后汉书》对许都权力结构作出直接概括：

```text
自都许之后，权归曹氏，天子总己，百官备员而已。
```

这里不是只说曹操官位高，而是明确指出实际政治权力归曹氏，天子名义居位，百官多为备员。

伏皇后传进一步给出可否决性的硬反证：曹操诛董承后要求杀董贵人，献帝因董贵人有孕而多次请求保全，仍不能阻止曹操执行。后来曹操又逼献帝废伏皇后，并以自己的政治、武装控制推动处分落实。

因此当前对象层可压成：

```text
名义最高者：汉献帝
↓
但真实宫廷 / 朝政处分接口：曹操
↓
献帝实际请求也不能阻止曹操处分董贵人
↓
名义上级并不构成曹操必须续接的真实许可节点
```

## 3｜zx 判断

本窄阶段不以 zx 为主判。

曹操的现实权力极高，但本轮测试的是“名义上级是否形成 nx 权限关系”，不是重做曹操完整扩权史。若要锁 zx，仍须另证此前边界与此阶段新增公开扩权之间的真实跃迁。

因此：

`zx_in_narrow_stage: rejected_as_primary`

不得从“曹操权大 / 挟天子”四字直接偷判 zx。

## 4｜nx 判断

### 名义层

献帝仍是皇帝，形式上处于最高君主位置。

### 实际对象层

但《后汉书》直接给出“权归曹氏”，并出现献帝实际请求仍不能否决曹操处分的事实。

所以在当前宫廷 / 朝政裁决对象层：

> **不能仅凭君臣名义层级，把曹操写成沿献帝最终许可接口推进的 nx。**

正式判断：

`nx_nominal_emperor_permission_relation: rejected_as_primary`

更接近：

`x_actual_court_decision_boundary: evidence-locked`

即相关实际处分与裁决接口在这一阶段稳定落在曹操一侧。

## 5｜关键压力

关键压力不是“曹操强、献帝弱”，而是：

> **当名义上级真的试图说“不”或请求改变结果时，这个否决是否能让现实结果停下。**

董贵人事件提供了直接压力测试：献帝多次请求，仍不能改变曹操处分结果。

## 6｜拿掉测试

### 拿掉“权归曹氏”的总体史料概括

只保留一次董贵人事件，仍能证明该对象层献帝否决不足，但对“长期稳定 x”证据会稍弱。

### 拿掉董贵人实际求情失败

只保留“权归曹氏”概括，仍支持曹操实际裁决边界，但缺少一次非常直接的真实否决压力测试。

二者同时存在，使分类达到 98%。

### 拿掉曹操现实处分能力

如果曹操所有决策最终都必须等待献帝批准，献帝能够真实拒绝且拒绝后结果不能生效，那么当前对象层应重新检查 nx。

## 7｜反向测试

真正的高纯 nx 权限关系应表现为：

```text
名义上级拥有真实否决权
→ 主体提出方案 / 请求权限
→ 上级可以拒绝、修改、拖延或不放行
→ 主体必须等待、重配或换通道
→ 结果是否生效受该节点真实控制
= nx 权限关系显著
```

而本例实际为：

```text
名义最高者仍在
→ 实际权力稳定归曹氏
→ 名义最高者甚至实际求情仍不能改变结果
= 名义层级不足以锁 nx
```

## 8｜最近邻排除

- `nx vs x`：名义上级存在不等于当前处分权在上级；若实际裁决长期稳定归主体，应优先查 x。
- `x vs zx`：实际已有稳定裁决权不等于本窄阶段继续扩权；zx 需独立验证边界上升。
- `nx vs xn`：曹操如何组织具体政务可另查 xn，本轮只测最终否决 / 裁决权在哪里。
- `身份 / 职业`：皇帝、丞相、大将军等名称都不能直接替代实际可否决性。

## 9｜第三因素冻结

冻结：曹操忠奸评价、挟天子道德判断、汉室合法性、献帝性格、后续魏王九锡、历史成败。

只问：

1. 名义最高者是谁？
2. 冲突时谁真的能说“不”？
3. 谁的决定最终让现实生效？
4. 主体能否绕过名义上级稳定处分？

结论不变。

## 10｜结论

本轮可靠结论：

> **名义上级 / 名义批准链本身不足以构成高质量 nx。若文本明确显示实际裁决权稳定在主体一侧，且名义上级实际反对也不能阻止结果，应优先检查主体 x，而不是机械锁 nx。**
