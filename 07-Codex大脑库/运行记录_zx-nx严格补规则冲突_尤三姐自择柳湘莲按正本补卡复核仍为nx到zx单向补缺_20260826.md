# 运行记录｜尤三姐自择柳湘莲：按 current canonical 重验后仍为 nx→zx 单向补缺

## 1｜本轮目的

此前“尤三姐自择柳湘莲”被记录为 `zx + nx` 共现、`nx→zx` 单向补缺，但后来研究层曾误用比 current canonical 更严的候选门，导致外围三案统一进入 `canonical-revalidation-pending`。

本轮重新读取 L1、zx/nx 信息卡、准度卡与 `zx补nx_补卡`，只按 current canonical 的明文标准重验，不再使用“拿掉 zx 后必须损伤 nx 自身核心能力本体”这一非正本候选门。

## 2｜剧情事实

第65回，尤三姐明确把柳湘莲作为自己要嫁的对象，家庭后续围绕这一指定方向处理婚事。第66回，贾琏在外与柳湘莲说合，柳湘莲同意婚事并交出鸳鸯剑作为定礼；贾琏回去后把鸳鸯剑交给尤三姐，尤三姐接受，婚约进入双方确认状态。

后续柳湘莲听到关于宁国府的负面信息后反悔索回定礼，尤三姐自刎。该后续只用于冻结第三因素，不倒灌本轮初始婚约形成阶段。

## 3｜zx 证据

本轮只锁当前婚姻方向层：

- “嫁给谁”的关键方向由尤三姐自己提出并持续占据；
- 她拒绝家人替换对象；
- 家庭后续必须围绕她指定的柳湘莲推进；
- 个人婚姻方向从“可被外部安排”推进为“必须围绕她自己的选择处理”。

因此当前 `zx` 端成立，但不据此锁人物稳定本体。

## 4｜nx 证据

现实婚约不能由尤三姐单方面处分：

- 贾琏承担真实说合与定礼传递通道；
- 柳湘莲拥有不可替代的同意/否决权；
- 尤三姐实际沿这条媒介 + 对方同意接口，把个人方向推进成双方婚约。

因此 `nx` 是局部关系功能，而不是“没主见”。

## 5｜按 current canonical 做双向补测试

### 5.1 nx → zx：成立

拿掉贾琏说合、柳湘莲同意与定礼接口：

- 尤三姐“只嫁柳湘莲”的 zx 方向仍然存在；
- 但个人选择无法自动形成双方婚约。

可命名缺口：`bilateral_consent_and_mediation_gap`。

因此 `nx_to_zx_gap_filling: true`。

### 5.2 zx → nx：仍不成立

current canonical 对 `zx→nx` 的要求是：nx 路径仍在，但缺把路径兑现成现实结果的“落地权能”。

本例拿掉的只能是“尤三姐公开、自主锁定对象并迫使家庭围绕其选择行动”的 zx 高显影端点；不能把她最低限度的婚姻同意整个删除，否则等于把研究对象本身删掉。

在保留“尤三姐愿意接受柳湘莲婚约”这一最低限度主体同意、但拿掉 zx 高显影后：

- 贾琏仍可说合；
- 柳湘莲仍可同意；
- 鸳鸯剑仍可成为定礼；
- 双方婚约仍可由“媒介 + 双方最低同意”形成。

换言之，nx 路径并不存在一个必须由“尤三姐 zx 高显影”才能补回的独立落地权能缺口。婚姻关系当然需要尤三姐本人同意，但“主体最低同意”不等于 zx，不能把所有双边关系中不可删除的主体参与偷算成 zx 的反向补。

因此 `zx_to_nx_landing_power_gap_filling: false`。

## 6｜关键压力与第三因素冻结

冻结：尤三姐刚烈/痴情评价、柳湘莲后续反悔、尤三姐自刎、柳湘莲出家、贾府整体悲剧、封建婚姻主题。

保留：

1. 尤三姐是否自定婚姻对象；
2. 贾琏媒介是否真实必要；
3. 柳湘莲是否拥有真实同意权；
4. 拿掉 zx 高显影后，nx 路径是否仍缺独立落地权能。

结论不变。

## 7｜最近邻排除

### zx vs x
尤三姐有个人婚姻边界属于 `x` 邻近；本段之所以检查 `zx`，是因为她把自定对象公开压入家庭安排并迫使后续行动围绕其选择展开。

### nx vs xn
媒介流程主要由贾琏承担，不能倒算成尤三姐 `xn`；尤三姐也没有自行搭一套复杂说合流程。

### nx vs nz
专一、情感与可回返关系感受不能替代柳湘莲真实同意权。

### strict complement vs 双边关系常识
“双边关系需要双方”不等于 `zx↔nx` 严格补。若拿掉 zx 高显影后，只要最低主体同意 + nx 媒介/对方同意仍足以形成关系，就不能把“主体参与”偷换成 zx 的落地权能。

## 8｜反向测试

若要升级为 strict，必须出现：

```text
nx 的媒介 / 对方许可接口已经到位
+
尤三姐最低同意也存在
但若没有尤三姐 zx 的公开决定/推进权能
→ 同一个婚约结果仍无法落地
```

原文证据不足以支持这一更强结构。

若反过来家人替尤三姐决定对象，她本人不占婚姻方向，只按外部安排接受，则 zx 显著下降，转向更纯的 nx 候选。
