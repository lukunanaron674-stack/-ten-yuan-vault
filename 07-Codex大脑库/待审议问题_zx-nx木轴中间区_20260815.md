# 待审议问题｜zx ↔ nx 木轴中间区判定纪律

## 0｜为什么触发

当前已有三个独立作品出现同型边界：

1. 《西游记》唐僧女儿国：主体否决“留下/婚姻/王位”替代方向，保留西行最终方向资格，但没有公开扩权。
2. 《水浒传》鲁智深拒官：主体连续否决“还俗为官/名刹僧首”两条路线，保留个人去向资格，但没有公开扩权。
3. 《三国演义》刘备拒取荆州：主体否决诸葛亮提出的高收益扩张路线，保留最终取舍资格，但没有公开扩权。

三例共同最小结构：

```text
真实替代方向存在
→ 主体拥有并使用最终否决/重设资格
→ 不满足 nx 的“最终方向外置”

同时
→ 主体只是守住自己的取舍边界
→ 没有把自身权能公开扩大到外部秩序
→ 不满足 zx 的“显权、扩权、周围结构重排”
```

因此满足“跨至少3个独立作品的同类边界问题”触发条件，应形成待审议问题。

## 1｜待审议命题

是否需要在木轴案例判定纪律中明确写入：

> `zx ↔ nx` 是同一核心变量的两端，不意味着每个案例必须落在其中一端。存在合法中间区：主体保留最终方向资格，但既没有把方向外置给他者，也没有达到 zx 的公开扩权阈值。

候选最短式：

```text
保留最终方向资格 ≠ zx
方向最初来自外部 ≠ nx

zx：保留/生成方向 + 权能公开扩大到外部现实
nx：最终方向/权限/通道外置 + 沿既有方向续接
中间区：最终方向资格仍在主体，但未发生公开扩权
```

## 2｜为什么暂时不能改 L1

三例足以证明“边界问题反复存在”，但还不足以证明需要修改十元本体定义。

可能性至少有三种：

1. 这只是案例判定纪律，需要补到准度层，不需改 L1。
2. 这是木轴连续谱的自然中间状态，L1 已经允许，只需显式说明“非穷尽二分”。
3. 现有 `zx` 或 `nx` 的端点描述仍有隐藏缺口，需要更多正反例确认。

当前不能越级裁定。

## 3｜下一步验证要求

优先寻找与三例形成最小差异的反向样本：

### A｜相似但真 nx

```text
外部给出明确方向
主体没有最终否决/重设资格
主体沿该方向执行
```

要求排除强迫、职位、信息差与临时分工污染。

### B｜相似但真 zx

```text
主体保留自己的方向
并把该方向通过自身公开权能压入现实
使他者/秩序围绕自己重排
决定范围实际扩大
```

要求不能只凭“坚持、拒绝、很强、胜利”判定。

### C｜同人物跨阶段

优先找同一人物：

```text
阶段1：中间区
阶段2：真 zx 或真 nx
```

用最小差异验证端点条件，而不是把阶段变化写成人物换芯。

## 4｜当前纪律

在二审前，案例层先执行：

```text
1. 先问最终方向/否决/重设资格在谁手里。
2. 若主体保留该资格，不得仅凭“有主见”判 zx。
3. 再问主体是否公开扩大自身权能并使外部秩序重排。
4. 若没有，则允许标记为“木轴中间区/两端均未达阈值”。
5. 不得为了二分完整性强塞 zx 或 nx。
6. 该纪律暂只用于研究/案例判定，不修改 L1、信息卡、准度卡与补卡。
```
