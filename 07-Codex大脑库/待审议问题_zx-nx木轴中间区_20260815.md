# 已关闭｜zx ↔ nx 木轴中间区判定纪律

## 0｜为什么曾经触发

已有三个独立作品出现同型边界：

1. 《西游记》唐僧女儿国：主体否决“留下/婚姻/王位”替代方向，保留西行最终方向资格，但没有公开扩权。
2. 《水浒传》鲁智深拒官：主体连续否决“还俗为官/名刹僧首”两条路线，保留个人去向资格，但没有公开扩权。
3. 《三国演义》刘备拒取荆州：主体否决诸葛亮提出的高收益扩张路线，保留最终取舍资格，但没有公开扩权。

三例共同最小结构：

```text
真实替代方向存在
→ 主体拥有并使用最终否决/重设资格
→ 不满足 nx 的“最终方向外置”

同时
→ 主体只是守住自己的取舍边界
→ 没有把自身权能公开扩大到外部秩序
→ 不满足 zx 的“显权、扩权、周围结构重排”
```

因此形成了原 pending-review。

## 1｜原待审议命题

是否需要在木轴案例判定纪律中明确写入：

> `zx ↔ nx` 是同一核心变量的两端，不意味着每个案例必须落在其中一端。存在合法中间区：主体保留最终方向资格，但既没有把方向外置给他者，也没有达到 zx 的公开扩权阈值。

候选最短式：

```text
保留最终方向资格 ≠ zx
方向最初来自外部 ≠ nx

zx：保留/生成方向 + 权能公开扩大到外部现实
nx：最终方向/权限/通道外置 + 沿既有方向续接
中间区：最终方向资格仍在主体，但未发生公开扩权
```

## 3｜最终层级裁定

合并审计结论：

```text
中间区属于案例/准度层合法非端点状态。
L1 无需修改。
L2 无需修改。
```

原因：

```text
1. 真 zx 控制可由现有 zx 端点解释；
2. 真 nx 控制可由现有 nx 端点解释；
3. 中间区不需要新增第三个十元极；
4. 中间区只是两端阈值均未达到；
5. 所有证据仍落在“最终方向与作用权来源”这一核心变量内。
```

最终中间区定义：

```text
WOOD_MIDDLE_ZONE
=
主体保留当前对象层的最终方向 / 否决 / 重设资格
+
没有把最终方向外置给他者或既有通道
+
没有把自身方向通过现实作用权扩张成外部秩序重排
```

## 4｜最终案例判定纪律

```text
1. 先锁 object_layer / current_window。
2. 再问最终方向、否决、重设资格在谁手里。
3. 若主体不占最终方向，检查是否真实激活并持续沿既有通道推进；满足则 nx candidate。
4. 若主体保留/生成自身方向，检查该方向是否通过主体自身现实作用进入公共现实并造成外部真实重排；满足则 zx candidate。
5. 若主体保留最终方向资格，但既未外置，也未公开扩张：WOOD_MIDDLE_ZONE。
6. 不得为了二分完整性强塞 zx 或 nx。
```

```text

外部提出方向 / 接受 / 听从 / 合作 / 职位安排 -> nx
```
