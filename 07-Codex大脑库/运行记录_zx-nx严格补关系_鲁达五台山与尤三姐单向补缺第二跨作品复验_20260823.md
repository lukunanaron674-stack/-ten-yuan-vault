# zx↔nx 严格补关系｜鲁达五台山第二跨作品单向补缺复验

## 结论

本轮不重判人物稳定本体，也不重复制造鲁达正式案例；只把仓库已有鲁达 99/98 控制与尤三姐 99/97 控制作跨作品最小差异复验。

结论：

> **zx、nx 两端都能独立成立，甚至 nx 明确修补了 zx 留下的现实缺口，仍不足以锁严格 `zx ↔ nx` 补关系。若反向拿掉 zx 后，nx 端仍能独立完成自己的当前核心功能，则只属于单向补位，不是严格双向补。**

当前跨作品同型数：2 部——《水浒传》《红楼梦》。尚未达到 3 部独立作品门槛，因此不新建待审议、不修改 L1 或补卡正本。

---

## 1｜本轮事实、触发、对象、动作、结果

### 前段 zx｜拳打镇关西

鲁达为救金翠莲，自行决定介入并公开对郑屠施力，最终直接改写街头冲突结果。该阶段既有仓库记录已锁 `prior_zx_endpoint: evidence-locked`。

### 触发压力｜通缉与长期安身缺口

郑屠死亡以后，鲁达成为逃犯。问题对象从“当场压制郑屠”切换为：

- 如何避免官府持续追捕；
- 如何获得长期安身；
- 如何取得新的身份与寺院准入。

### 后段 nx｜赵员外—智真长老—度牒通道

赵员外掌握庄院庇护、与五台山智真长老的既有关系、檀越身份、度牒与费用；智真长老掌握寺院最终收录接口。鲁达实际接受这一外部方案，并沿该关系与准入网络完成剃度，成为鲁智深。

所以后段 `later_nx_endpoint: evidence-locked`。

---

## 2｜zx 为什么独立成立

前段 zx 不依赖赵员外、智真长老、度牒或寺院关系：

```text
鲁达自己定救人方向
→ 公开施力
→ 郑屠与现场被迫响应
→ 结果被主体权能直接改写
= zx
```

因此即使拿掉后段 nx，前段 zx 仍然成立。

但这只证明 zx 端存在，不证明严格补。

---

## 3｜nx 为什么独立成立

通缉以后，鲁达仍有自己的生存意愿，但“稳定安身 + 身份转换 + 寺院收录”所需的关键接口不在自己手里。

```text
赵员外庄院与关系
+ 度牒与费用
+ 智真长老收录权
→ 外部既有解决通道
```

鲁达没有自己搭建一套新的合法身份系统，而是实际沿该通道推进，所以主判是 nx 关系功能，不是 xn，也不是 x。

---

## 4｜双向拿掉测试

### A｜拿掉 nx

保留鲁达前段 zx，删除赵员外、智真长老、度牒与寺院准入接口。

鲁达的 zx 不消失，但留下明确后果型缺口：

> **公开直接权能无法低成本解决“官府通缉下的长期安身与身份转换”。**

补回 nx 后，庄院、度牒、寺院收录直接改善这一缺口。

所以：

`nx_repairs_zx_gap: supported`

### B｜拿掉 zx

保留赵员外、智真长老、度牒与五台山准入网络，拿掉前段鲁达“公开压制郑屠”的 zx 高显影端点。

后段 nx 仍然能独立完成当前核心功能：

```text
赵员外提供安身与身份转换路径
→ 智真长老收录
→ 剃度完成
→ 新身份成立
```

这里没有出现一个必须由 zx 再介入才能补掉的“落地权能缺口”。

所以：

`zx_repairs_nx_gap: rejected`

双向补缺失败。

---

## 5｜和尤三姐的跨作品最小差异

### 鲁达

```text
zx：前段公开施力造成/留下通缉压力
nx：后段外部身份与准入网络解决安身

nx → zx 后果缺口：成立
zx → nx 功能缺口：不成立
```

### 尤三姐

```text
zx：自己锁定“只嫁柳湘莲”的婚姻方向
nx：贾琏媒介 + 柳湘莲真实同意使婚约落地

nx → zx 现实实现缺口：成立
zx → nx 同意/媒介机制缺口：不成立
```

两例的表面题材完全不同：一个是逃亡身份转换，一个是婚约形成。

但共同结构相同：

> **nx 都能解决 zx 方向或 zx 后果留下的现实实现缺口；反方向却没有一个必须由 zx 才能让 nx 功能成立的不可替代缺口。**

因此这不是题材巧合，而是“单向补位 ≠ 严格双向补”的第二部独立作品复验。

## 6｜最近邻排除

### vs 压力显影

鲁达更适合同时写作：

> 前段 zx 的直接路径在通缉压力下失去适用性，后段 nx 高显影。

压力显影与“严格补关系”不是同一个问题。一个人可以在不同压力下由 zx 转 nx 高显影，而不形成严格双向补。

### vs 普通因果链

拳打镇关西导致通缉，只能证明因果连续；因果连续不能替代双向缺口测试。

### vs xn

赵员外提供的是已经存在的庄院、度牒、檀越与寺院关系通道。鲁达没有自己设计完整身份转换流程，因此后段主判 nx。

### vs x

庄院、度牒与寺院收录权均不属于鲁达稳定调用，所以不能判 x。

### vs “本人最后也配合剃度，所以 zx 回来”

本人走路、同意剃度、配合执行只是普通行动，不满足 zx 的公开显权与决定范围扩大门槛。若把“本人最终做了一点动作”当成 zx 补 nx，则几乎所有求人办事都会被错误包装成严格补。

---

## 7｜反向测试：怎样才会成为严格补

需要额外出现：

```text
nx 提供庄院 / 度牒 / 寺院准入
↓
但这些条件本身仍无法完成身份结果
↓
必须由鲁达自身 zx 的公开权能再次进入
↓
才能让该 nx 通道落地
```

原文没有这种结构。

所以本轮不能从“zx 与 nx 都出现”“nx 明显帮了 zx”跳到严格补。

## 8｜第三因素冻结

冻结：

- 鲁达武力强弱；
- 郑屠善恶评价；
- 佛门主题；
- 赵员外是否仗义；
- 鲁达后来成为梁山好汉；
- 五台山后续破戒情节。

只检查：

1. zx 是否独立成立；
2. nx 是否独立成立；
3. nx 是否补 zx 的现实缺口；
4. zx 是否反向补 nx 的不可替代缺口。

结论仍稳定为 99/98。
