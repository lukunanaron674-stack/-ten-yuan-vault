# 正本读取优先级增补协议 v1.1

## 1. 协议目的

本协议曾用于修补《Codex大脑总入口》中尚未纳入四份最高优先级正本的问题。

新增正本为：

```text
显影机会、可选择性与沉默证据协议；
证据独立性、重复计数与循环论证防污染协议；
证据置信度与对象量级分离协议；
复合判断最弱环节与置信度限级协议。
```

上述内容现已正式写入《Codex大脑总入口》的十五层读取顺序。本页不再对总入口构成临时覆盖，只保留为读取顺序形成过程、审核理由与禁止倒序规则的参考记录。

发生冲突时，以《Codex大脑总入口》当前正文及其所列更高优先级专项正本为准。

## 2. 现行正式读取顺序

涉及三元、十元、人物本体、状态、行为、场景、时间关系、光影、动态链或五大主题时，按以下顺序读取：

```text
1. 五大主题与十元分层接口协议 v0.4
2. 对象层证据归属与跨层防污染协议 v1.0
3. 显影机会、可选择性与沉默证据协议 v1.0
4. 未判定保留与负证据协议 v1.0
5. 证据独立性、重复计数与循环论证防污染协议 v1.0
6. 证据置信度与对象量级分离协议 v1.0
7. 复合判断最弱环节与置信度限级协议 v1.0
8. 动态链因果归属与关系启动协议 v1.0
9. 体量、显影强度与关系作用量分离协议 v1.0
10. 五大主题基准构成与候选变体研究协议 v0.1
11. 五大主题生克盘 v1.0
12. 五大主题显影与判定协议 v1.0
13. 五个现行主题单页
14. 十元现行准度卡、定义正本与已确认关系
15. 旧案例、旧图、旧关键词表与待二审关系盘
```

## 3. 为什么必须这样排序

```text
先分对象层
→ 再检查是否有显影机会
→ 再判断沉默是否有负证据资格
→ 再去重证据并防止循环论证
→ 再给单一命题置信度
→ 再按最弱必要环节限制复合关系
→ 最后才启动动态链、生克补与主题关系
```

不得倒序运行。

尤其禁止：

```text
先看到关系结果
→ 再反推端点十元；

先看到人物失败或沉默
→ 再反推人物本体不存在某元；

先看到强烈画面
→ 再抬高证据置信度；

同一事件拆成多条描述
→ 再伪装成多份独立支持。
```

## 4. 人物核心锚点规则

人物稳定本体仍然优先保持。

新增材料优先更新：

```text
当前状态；
行为功能；
关系位置；
场景限制；
时间窗口；
光影显影；
动态链阶段；
T / M / E；
各命题证据置信度。
```

只有人物在拥有真实选择余地时，跨阶段、跨场景、跨关系对象持续主动反向选择，并重新取得人物本体层 C-A，才允许提出稳定本体改变。

## 5. 三元与十元

```text
三元与十元并行判断；
三元不是十元父级；
十元不是三元子类；
任一层的高置信度不得替另一层补答案。
```

## 6. 当前冻结结论

```text
《Codex大脑总入口》已完成十五层正式读取顺序同步；
本页由临时增补覆盖协议转为历史与审核参考，不再单独覆盖总入口；
所有正式关系判断仍必须先通过对象层、机会、独立证据、单命题置信度和最弱环节审核；
人物核心锚点优先稳定，变化优先落在状态、行为、关系、场景、时间、光影和动态链；
三元与十元并行，不构成父子派生。
```
