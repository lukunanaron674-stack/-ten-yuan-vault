# 待审议问题｜nx：事前批准 与 事后回报边界

## 触发原因

跨三部独立作品连续出现同一边界：

> **主体在被测试的局部对象层可以先让决定/行动结果独立生效，之后仍需要向更高节点回覆、奏报、复命、备案或移交。此时“之后要报告”并不能自动证明“之前必须获得批准”。**

该问题属于现有“zx-nx分层授权灰区”的更窄子问题，但已达到三作品阈值，因此单独形成待审议问题；仍不得直接修改理论正本。

## 三个独立作品

### 1. 《红楼梦》王熙凤｜宁国府处分

```text
凤姐作出处分
→ 处罚直接执行
→ 结果已经生效
→ 执行者再回覆
```

关键：回覆发生在决定生效之后。

### 2. 《水浒传》鲁智深｜擒方腊

```text
鲁智深发现方腊
→ 当场制服并绑缚
→ 捕获结果已经成立
→ 后来移交宋江
```

关键：宋江接手的是下一层押解/处置，不是鲁智深现场捕获的事前批准者。

### 3. 《三国演义》陆逊｜夷陵统军

孙权明授陆逊“先斩后奏”，并划定“阃以内孤主之，阃以外将军制之”。陆逊可直接发布前线军令、约束宿将、部署战役；后续奏报孙权发生在前线决定已经独立运行之后。

关键：文本直接把“后奏”与“先处分”分开。

## 当前最窄候选纪律

> **判断 `nx` 权限关系时，必须区分“事前批准门”和“事后报告义务”。只有当报告/请示是决定生效的前置条件，且外部节点可以真实拒绝、修改或不放行，才构成强 `nx` 权限证据。若主体可以先让局部决定独立生效，之后才回覆、奏报、备案、复命或移交，则这些后续动作本身不能把该局部 `x` 打回 `nx`。**

## 对象层限制

本纪律不能跨对象层扩大。

例如陆逊：

```text
最高战略“破蜀”方向 → 孙权给定 → 上位nx
阃外前线军令/处分 → 陆逊可先独立生效 → 局部x
国家最高战略/阃内权力 → 仍不属于陆逊
```

因此“局部可先做后报”不等于人物整体脱离 nx，也不等于得到完整最高权限。

## zx 限制

“先做后报”同样不是 `zx` 的充分条件。

若这块局部权限本来就已通过职位/授权进入主体边界，当前只是正常调用，应优先解释为 `x`；只有主体进一步公开突破原授权边界，并让更大秩序承认新增决定接口时，才重新检查 `zx`。

## 拿掉测试

### 拿掉事后报告

若局部决定本来即可独立生效，拿掉报告义务后 `x` 仍成立，说明报告不是权限来源。

### 把报告前移

如果改成：

```text
主体提出决定
→ 必须先报告
→ 外部节点可拒绝/修改
→ 批准后才执行
```

则 `nx` 权限关系显著上升，局部 `x` 降级。

### 拿掉独立生效能力

如果主体只能观察、建议、控制现场但不能让结果正式成立，之后还必须经更高节点确认，不能用“曾先行动”冒充完整局部 `x`。

## 最近邻排除

- `x`：当前局部决定能否先独立生效。
- `nx`：该决定是否必须先经过外部批准接口。
- `xn`：主体怎样组织执行流程。
- `zx`：主体是否把决定边界继续向原授权之外公开扩张。

## 第三因素冻结

不得用“有领导、要汇报、职级高低、行动强弱、结果成败、人物忠诚”直接判定。
