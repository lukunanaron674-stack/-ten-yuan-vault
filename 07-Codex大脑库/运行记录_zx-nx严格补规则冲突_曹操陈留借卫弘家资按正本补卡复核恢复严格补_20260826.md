# 曹操陈留借卫弘家资｜按正本补卡复核

## 0｜本轮为何必须先纠偏规则

仓库正本 `zx补nx_补卡` 当前仍是 `canonical-current-card`，并明确写道：

```text
nx 补 zx：补入外部权限、资源、关系与非正面路径，改变 zx 单独运行时的路径缺口。

zx 补 nx：把借到的资源、关系与通道重新转成实际行动、公开决定和结果推进，改变 nx 单独运行时“有路径却缺落地权能”的缺口。
```

其红线要求：拿掉任一端，另一端仍成立但出现可命名缺口；并没有要求“拿掉 zx 后，nx 自己的资源处分能力、许可能力或专业能力本体必须损坏”。

2026-08-25/26 研究层新增的“必须损伤 nx 自身核心功能”门，比正本额外增加条件。该门目前只是研究层候选，且与正本文字直接冲突，因此不能高于正本去撤销正本兼容案例。

本轮按用户既定纪律“仓库正本高于运行记录与提示”处理：先恢复正本口径，再压力测试材料。

## 1｜剧情事实

《三国演义》第五回：

```text
曹操到陈留
→ 自己已有散家资、招募义兵、反董起兵方向
→ 曹嵩指出“资少恐不成事”
→ 推荐巨富卫弘
→ 曹操请求相助
→ 卫弘明确同意以家资相助
→ 曹操发矫诏、招集义兵、竖招兵旗
→ 卫弘尽出家财置办衣甲旗幡
→ 起兵链形成并扩大
```

事实链由通行本第五回直接支持。

## 2｜zx 证据

本阶段 `zx` 成立：

1. 反董、公开起兵方向由曹操自己生成，不由卫弘授予；
2. 曹操亲自发矫诏、招兵、竖旗、调练军马；
3. 外部人物、兵员与诸侯体系围绕其公开行动发生现实响应；
4. 曹操的公开军政影响与决定范围真实扩大。

不是因为“曹操强、是英雄、能号召人”而判 zx，而是公开权能与决定范围确实进入现实并扩大。

## 3｜nx 证据

资源接口层 `nx` 成立：

1. 卫弘家资不在曹操原有稳定处分边界；
2. 卫弘保留真实同意/拒绝权；
3. 曹操必须真实请求，卫弘同意后资源才进入行动链；
4. “资金能否进入”不是曹操自己的排程能力可以替代。

因此这里是 `nx` 关系功能，不是人物本体没主见。

## 4｜按正本做双向拿掉

### 4.1 拿掉 nx

去掉卫弘或等价外部启动资本：

- 曹操的反董起兵 `zx` 仍成立；
- 但原文直接留下“资少恐不成事”的启动资本、衣甲旗幡与募兵规模缺口。

所以：

```text
nx → zx：成立
```

### 4.2 拿掉 zx

保留卫弘的家资与愿意支持这一外部资源通道，但拿掉曹操把资源公开兑换成行动、决定与结果推进的 `zx`：

- `nx` 资源通道仍成立；
- 但它只剩“有资源 / 有通道”；
- 缺少把资源直接兑现成反董募兵、公开军政行动与现实结果推进的落地权能。

这正是正本补卡对 `zx补nx` 的明文定义：

```text
nx 单独运行：有路径却缺落地权能
zx 补入：把借来的资源/通道重新转成实际行动、公开决定与结果推进
```

因此按当前正本：

```text
zx → nx：成立
strict zx↔nx complement：成立
```

关键纠偏：这里不需要证明“卫弘失去处分自己家资的能力”。那是 2026-08-25/26 研究层额外新增的窄门，不是当前正本的反向补定义。

## 5｜反向测试

若曹操只拿到卫弘的钱，却：

- 不公开起兵；
- 不招募；
- 不把资源兑换成现实行动；
- 没有外部秩序响应；

则 `zx` 端无法过门，严格补失败。

若曹操自己已有足够稳定资本，不需卫弘或等价外部资源接口，则 `nx` 端下降，严格补同样失败。

两端必须先各自独立成立，随后才谈补。

## 6｜最近邻排除

- `zx vs x`：已有自有资源的直接调用是 x；本轮 zx 锁公开起兵和军政作用范围的形成/扩大。
- `nx vs x`：卫弘家资在同意前不属于曹操稳定处分，故为 nx。
- `nx vs xn`：募兵、发檄、调练有 xn 邻近，但“资金是否进入行动链”仍由外部资源接口决定。
- `合作 vs 严格补`：不是因为两个人合作就判补；而是两端独立成立，并在同一“起兵落地”瓶颈上分别补掉“资源入口”和“落地权能”缺口。

## 7｜第三因素冻结

冻结曹操忠奸评价、卫弘人物评价、最终讨董胜负、后世魏国结局后：

- zx 与 nx 两端仍独立成立；
- “启动资本不足”瓶颈仍在；
- nx 补入资源，zx 将资源落地为公开行动的双向结构仍在。

不能把“启动资本不足”整体冻掉，因为那会删除当前被测瓶颈本身。
