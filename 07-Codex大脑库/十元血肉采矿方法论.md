# 十元血肉采矿方法论 v1

> **让每个十元从骨架长出人物肉、空间肉、视觉肉、声音肉、动态链肉、误判疤痕。**
> 
> 十元 = 骨架 | 案例 = 血肉 | 动态链 = 筋膜 | 五大主题 = 器官系统 | 创作模板 = 可复活的身体

---

## 核心理念

**不要让 AI 跑"影评/漫评/乐评"，要让 AI 跑"十元信息量采矿"。**

- ❌ 普通分析：这个作品好在哪里。
- ✅ 真正采矿：这个作品给哪个十元增加了哪些体感、行为、空间、视觉、声音、动态链、误判反例。

**十元不是标签，十元是信息密度。信息越分层，AI越能理解；信息越乱堆，AI越会误判。**

---

## 第一部分：密度卡结构（符号信息量包）

每个十元必须建立分层信息量结构，而非词典式定义。

### 信息量等级

| 等级 | 层名 | 用途 | 信息量 |
|------|------|------|--------|
| 1-3 | 词典层 | 快速召回 | 低 |
| 4-6 | 应用层 | 分析角色/场景/故事 | 中 |
| 7-8 | 创作层 | 生图/写故事/设计角色 | 高 |
| 9-10 | 动态链层 | 高级分析/自动化F12 | 完整 |

### 密度卡标准格式（10层结构）

```
【[符号] 信息量卡 v1】

1. 核心本体（主骨）
一句话定义 + 主骨核心语义

2. 第一体感
不是____，而是____（防误判的第一直觉）

3. 人物层
性格 / 状态 / 角色类型

4. 行为层
典型动作 / 反应模式

5. 空间层
成立的场所 / 引发的情境

6. 视觉层
色彩 / 构图 / 光线 / 形状语言

7. 叙事层
故事功能 / 推动方式 / 命运作用

8. 常见互补
[符号] + [符号] = 什么主题

9. 常见污染
[符号] 被 [符号] 污染 = 变成什么

10. 禁止误判
什么看起来像但实际不是 [符号]（必须有误判防线）
```

### 关键原则

- **主骨约束**：所有信息围绕核心语义生长，像骨架长肌肉，不是菜市场装袋
- **先写主骨 → 围绕主骨长肉身 → 设误判防线防溢出**
- **密度卡结构必须从已稳定的十元定义倒推写，不能从直觉写**

## 第二部分：血肉采矿流程 v1

```
第一步：先定主骨架
这个案例主要补哪个十元 / 哪个关系 / 哪个五大主题？

第二步：拆血肉
├─ 人物血肉
├─ 行为血肉
├─ 空间血肉
├─ 视觉血肉
├─ 声音血肉
└─ 叙事血肉

第三步：找关系牙印
├─ 谁作用谁？
├─ 谁污染谁？
├─ 谁克谁？
├─ 谁补谁？
└─ 谁被改写？

第四步：找动态链
起手 → 作用 → 承载 → 冲突 → 结算 → 落点

第五步：回填信息量卡
把新发现写进对应十元卡，而不是停在作品分析里。

第六步：提炼创作模板
这个结构以后怎么偷走？
```

### 正确问法 vs 错误问法

❌ 错误：
```
分析《花束般的恋爱》
```

✅ 正确：
```
用十元信息量采矿方式分析《花束般的恋爱》。
目标不是影评，而是提取：
1. n 的生活承载血肉
2. x 被现实磨损的血肉
3. nz 停靠退化的血肉
4. n+x 角色动态链
5. 可回填到十元信息量卡的素材
```

## 第三部分：不同媒介的采肉价值

### 🎬 影视 — 关系血肉 + 五大主题血肉

影视最擅长：

| 采肉方向 | 典型素材 |
|----------|----------|
| 角色关系 | n 如何慢慢接管 x |
| 命运结构 | 共同趣味如何被生活承载磨损 |
| 本体变化 | nz 停靠如何退化成日常负担 |
| 空间承载 | 场景如何承载十元关系变化 |
| 因果链条 | 事件链如何推动十元转移 |

### 🎨 动画/漫画 — 视觉血肉 + 动态姿态血肉

动画漫画最擅长：

| 采肉方向 | 典型素材 |
|----------|----------|
| 形状 | 这个十元怎么站/怎么转身 |
| 姿态 | 怎么被压/怎么冲出去 |
| 构图 | 怎么被空间吞掉 |
| 表情 | 十元的面部语言 |
| 动作节奏 | 快慢/轻重/急缓 |
| 视觉符号 | 剪影/色彩/纹理 |
| 角色体量 | 大小/压迫感/存在感 |

这对**生图、角色设计、场景设计**特别有用。

### 🎵 音乐 — 顺序感谱 + 力的变化 + 时间血肉

音乐最能补：

| 采肉方向 | 典型素材 |
|----------|----------|
| 力的变化 | 什么时候压/什么时候放 |
| 时间节奏 | 什么时候停/什么时候爆 |
| 回收结构 | 什么时候回收 |
| 十元的声音映射 | N=稳定低密度铺底 |
| | XZ=不稳定中高密度悬置 |
| | ZX=短促强推进爆发 |
| | nz=软化/拖尾/余韵 |
| | xn=节拍/规训/循环 |
| | z=高亮爆点 |
| | x=低频吞没/欲望拖拽 |

音乐分析特别适合解决：**力的大小、变化、传导、顺序感谱。**

## 第四部分：无用分析（已淘汰模式）

以下这些跑法**没有价值**，不应当执行：

```
❌ 分析剧情
❌ 总结主题
❌ 夸作品
❌ 给评分
❌ 写一堆感受
❌ 最后没有回填到十元
```

这就是"看起来很努力，实际没入矿"。

**真正有用的采矿必须输出：**

1. 给哪个十元增加了血肉？
2. 增加的是人物、空间、视觉、声音、叙事，还是动态链？
3. 有没有新的关系牙印？
4. 有没有误判反例？
5. 能不能变成创作模板？

## 第五部分：三大最终产物

### A. 十元血肉库

每个十元下面挂素材：

```
xz：
  影视血肉：...
  动画血肉：...
  音乐血肉：...
  视觉血肉：...
  空间血肉：...
  误判反例：...
```

### B. 十元关系牙印库

```
n → x：生活承载慢慢磨损欲望
x并z → zn+x：表象外壳反噬主体
xz → nz：漂流寻找停靠
xn → z：规则压出执念爆点
```

### C. 创作模板库

```
生活磨损型爱情：
两个人因共同趣味相遇，进入同居承载，
生活结构逐渐接管欲望，
最后不是不爱，而是爱的形态被现实换芯。
```

这个才是能拿来写故事、画图、做角色的金矿。
