# 十元血肉采矿方法论

## 0. 文件定位

本文件是 Codex / F12 / ChatGPT 执行用的「十元血肉采矿方法论」。

它不负责重新发明十元理论，不负责随意改主骨。

它负责把影视、动画、漫画、音乐、游戏、角色、场景、图像分析结果，提炼成可回填到十元密度卡的血肉素材。

一句话：

> 分析作品不是为了写影评，而是为了给十元长血肉。

---

## 1. 采矿目标

每次分析必须回答：

```text
这个案例给哪个十元增加了什么血肉？
这个血肉属于人物、行为、空间、视觉、声音、叙事、动态链，还是误判反例？
能不能回填到信息量卡？
能不能变成创作模板？
```

---

## 2. 媒介价值分工

| 媒介 | 最适合补什么 | 说明 |
|---|---|---|
| 影视 | 关系血肉 / 五大主题血肉 / 叙事动态链 | 最适合看角色关系、命运结构、本体变化、空间承载、因果链条 |
| 动画 / 漫画 | 视觉血肉 / 姿态血肉 / 角色体量 | 最适合看形状、姿态、构图、动作节奏、角色剪影、视觉符号 |
| 音乐 | 顺序感谱 / 力的变化 / 时间血肉 | 最适合看什么时候压、什么时候放、什么时候停、什么时候爆、什么时候回收 |
| 游戏 | 交互血肉 / 资源血肉 / 反馈反噬 | 最适合看玩家输入如何被系统接住、放大、限制、结算 |
| 图像 / 视觉案例 | 视觉接口 / 材质 / 色温 / 信息量 | 最适合补可生图、可画、可设计的画面语言 |

---

## 3. 标准采矿流程

### 第一步：先定主骨

```text
这个案例主要补哪个十元？
主骨是否被挑战？
是补主骨，还是只补血肉？
```

### 第二步：拆血肉

```text
人物血肉：这个十元像什么人？
行为血肉：它怎么动？
空间血肉：它在哪成立？
视觉血肉：它怎么被看见？
声音血肉：它怎么被听见？
叙事血肉：它在故事里负责什么？
```

### 第三步：找关系牙印

```text
谁作用谁？
谁污染谁？
谁克谁？
谁补谁？
谁被改写？
谁生成了新结构？
```

### 第四步：跑动态链

```text
起手 → 第一被作用十元 → 关系类型 → 承载位 → 冲突位 → 结算位 → 最终落点
```

### 第五步：回填密度卡

不能只停在作品分析里。必须写明：

```text
回填到哪张十元信息量卡？
补了哪一层？
是否更新误判反例？
是否生成创作模板？
```

```text

```

### B. 十元关系牙印库

记录十元之间的真实作用痕迹：

```text
n → x：生活承载慢慢磨损欲望
x并z → zn+x：表象外壳反噬主体
xz → nz：危险漂流寻找停靠
xn → z：规则压出执念爆点
```

### C. 创作模板库

把分析转成可复用故事模板：

```text
生活磨损型爱情：
两个人因共同趣味相遇，进入同居承载，生活结构逐渐接管欲望，最后不是不爱，而是爱的形态被现实换芯。
```

## 7. 禁止项

```text
禁止只写剧情总结。
禁止只夸作品。
禁止只给评分。
禁止没有回填位置。
禁止把五大主题倒推成十元起手。
禁止把视觉层直接反推本体。
禁止把承载位默认写成 n。
禁止把怪物 / 恐怖从 xz 核心血肉里排除。
```
