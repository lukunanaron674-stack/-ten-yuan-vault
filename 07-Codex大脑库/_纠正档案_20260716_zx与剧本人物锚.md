# 纠正档案·zx与剧本人物锚

> **治理说明：** 本页是用户口述纠错的锁定记录，`locked` 只约束上方 `scope-lock` 所列纠错事项，不是 z、zx、n 或人物本体规则的全局最高正本。发生定义细化、版本升级或措辞差异时，依次读取《Codex大脑总入口》与对应现行专项正本。本页与现行正本之间是 `explains / covered-by`，不是并列覆盖。

## 1. “脏醒”不是类型

错误吸收：

```text
脏醒 = z+x / z污染 / 新异化类型
```

正确口径：

```text
“脏醒”是语音误识别
正确词是“张扬醒目”
正式符号是 zx
```

不得再围绕“脏醒”建立任何理论分支。

## 2. z 与 zx 的边界

### z

> 精神个体的存在、能力、作品、选择或发现，被一个认可主体看见和确认。

### zx

> 主体学习并理解客观规律，把理解转化为有效改变，使成果显现并得到认可，能力与权能继续扩大。

不能说主观世界替代客观世界，只能说主体扩大改变客观世界的能力。

> **现行读取提示：** 本节保存 2026-07-16 的纠错方向；z 的现行定义读取 `01-十元系统/【z信息量卡v2.2】.md`，zx 的现行定义读取 `01-十元系统/【zx信息量卡v2】.md`。本页不得覆盖后续版本对“认可”“权能公开显现、扩大与凌驾”等机制的细化。

## 3. n 不负责大小取舍

- n 的核心是精神、整体与关系。
- 理解、包容、协调都属于 n 的常见能力。
- 小 / 大只是辅助体感，不是正式定义或等级。
- n 不天然要求小整体服从大整体。
- 此类取舍不是 n 的核心问题。

## 4. 剧本人物锚保持稳定

标准剧本中锁定：

```text
主十元 + 副十元
```

例如 `xz+nz` 在不同压力下可以显出不同侧面，但始终是 `xz+nz`。

人物成长默认改变：

- 状态。
- 行为。
- 关系。
- 能力与经验。
- 对自身的理解。

人物成长默认不改变：

- 主十元。
- 副十元。
- 核心组合。

> **成长负责暴露本性，不负责替换本性。**
