# 待审议｜zn + x 当前共现不等于 strict zn↔x 补

## 1｜触发条件

同一 criterion_version 下，已有 3 部独立作品达到事实与分类 ≥95%，并且在明确当前窗口中 `zn`、`x` 两端分别独立过门：

1. 《三国演义》关羽·挂印封金，99/98。
   - `zn`：旧盟/旧义保留冲突排序与未来指导资格；
   - `x`：曹赐金银、赤兔马等现实掌握边界；
   - 同一关键窗口里，原则进入高调用时局部资源 `x` 尚未全部退出。

2. 《水浒传》晁盖·梁山劫掠处分，99/98。
   - `zn`：不可因取财、脱险或便利任意伤害无关者；
   - `x`：山寨人马、行动与战利品处分边界；
   - `zn` 限制已成立 `x` 的使用方式。

3. 《西游记》唐僧·三打白骨精 / 草寇事件，99/97。
   - `zn`：不可轻率伤害人命；
   - `x`：对孙悟空师徒关系的现实约束/处分权；
   - `zn` 规定关系处分 `x` 的惩戒、保留与终止条件。

因此达到 L4 `pending-review` 门槛。

## 2｜候选命题

> **在同一当前对象窗口中，zn 与 x 可以同时分别独立成立。原则并不要求现实掌握权消失；现实掌握权也不自动吞掉原则。**

目前至少观察到：

```text
关羽：zn 与 x 同时存在 → zn 决定部分 x 的让渡
晁盖：zn 与 x 同时存在 → zn 限制 x 的使用方式
唐僧：zn 与 x 同时存在 → zn 规定关系处分 x 的惩戒/保留/终止条件
```

## 3｜最重要的红线

**co-occurrence ≠ strict complement。**

当前 canonical `zn补x_补卡_v0.1` 对 strict 补还有额外双向缺口要求：

- `zn → x`：掌握对象缺用途、守护/放弃标准与否决原则；
- `x → zn`：意义缺现实落点、可保护对象范围与明确我方边界；
- 拿掉任一端，另一端必须仍成立但重新出现可命名缺口。

所以三部作品只能证明“同段共现可以成立”，不能自动证明 strict `zn↔x`。

当前 strict 压力测试已经产生三份独立作品反向护栏：

1. 《三国演义》关羽，99/97：`zn→x` 成立；拿掉曹赐资源 `x` 后，旧义仍可通过归刘、护送二夫人、离曹行动稳定落地，因此 `x→zn` 不成立。
2. 《水浒传》晁盖，99/98：`zn→x` 成立；拿掉梁山人马/劫掠处分 `x` 后，“不任意伤害无关者”仍有明确现实对象，并可继续约束主体自己的行为，因此 `x→zn` 不成立。
3. 《西游记》唐僧，99/97：`zn→x` 成立；拿掉对孙悟空的师徒处分/约束 `x` 后，“不轻伤人命”仍可约束唐僧自身判断、其他关系与其他现实生命对象，因此 `x→zn` 不成立。

strict 当前为：`0 positive / 3 negative guards / 3 works`。

## 4｜当前最小判定协议

先分别独立验端点：

```text
zn：内部原则是否通过无奖励、冲突排序、未来指导资格等门？
x：具体对象是否真实进入占有、使用、调用、处分或排除边界？
```

再验同一窗口：

```text
两端是否在同一当前对象层真实同时存在？
```

最后才允许进入 strict 补测试：

```text
拿掉 x → zn 是否出现现实落点/对象范围缺口？
拿掉 zn → x 是否出现用途/守护/放弃标准缺口？
第三因素是否能替代其中一端？
```

新增 strict 反向门：

```text
x 只是扩大 / 便利 / 强化 zn 的执行范围
≠
x 对 zn 构成不可替代现实落点
```

并且：

> **被原则保护、对待或评价的对象范围，不等于这些对象必须先进入主体的 x 掌握边界。**

> **关系处分 x 是 zn 的一个现实执行接口，也不自动等于 zn 的不可替代现实落点。**

## 5｜反误判护栏

- “有原则的人也有资源”不是自动 `zn+x`，两端必须分别过门。
- “原则限制权力”不能反推 `x` 不成立。
- “资源被放弃”不能反推 `zn` 一定成立。
- 同作品不同桥段不能冒充独立作品。
- 局部共现不能倒灌成稳定人物本体。
- 共现统计与 strict 补统计必须分开。
- 一个 `x` 对 `zn` 有现实帮助，不等于 strict `x→zn`。
- `x` 扩大原则的执行范围，也不等于原则离开该 `x` 就失去现实对象。
- 原则保护谁，不等于谁归主体占有、调用或处分。
- 关系处分权能直接实施原则，也不等于原则只有这一个现实落点。
