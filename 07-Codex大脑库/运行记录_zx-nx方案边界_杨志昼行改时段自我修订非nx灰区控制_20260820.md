# 杨志昼行改时段｜自我方案修订不能伪装成 nx→xn 灰区

## 1｜本轮问题

近期 `nx ↔ xn` 边界正在测试：主体只改一个关键运行变量、只传播一两层后果时，何时仍属于 nx 内部执行自由，何时已进入 xn 重设。

本轮故意把《水浒传》第十六回杨志押送生辰纲缩到一个极窄窗口：

> 前几日趁五更早凉行、日中歇；进入偏僻危险山路后，杨志改成辰牌起身、白日赶路，并禁止随意投凉处停歇。

表面上它很像“旧方案 → 改一个关键节点 → 一层传播”的中间灰区，但复核后发现：**这个样本不能承担 nx→xn 灰区控制，因为旧时段本来就不是外部方案。**

## 2｜剧情事实

梁中书给定的最高目标是把生辰纲送到东京；杨志此前已经否定公开车运方案，主动设计挑担伪装、人员提调与行程组织，并取得一路早行晚行、住歇由自己安排的执行接口。

上路后：

1. 初离北京五七日，杨志安排五更趁凉走、日中热时歇。
2. 进入人家渐少、行客稀少的山路后，杨志把出发时间改为辰牌，并解释夜间/五更走危险地段风险更高。
3. 时段改变后，军健因酷热、重担要求歇凉，杨志继续催赶甚至以藤条强制，虞候与老都管也因此产生明显冲突。

结果是：时间节点变化确实传播到体力负荷、停歇冲突与人员服从关系，但这些变化都发生在杨志自己已经掌握的押运行程组织层。

## 3｜nx 判断

### 本微窗口：rejected_as_primary

不能因为存在“前一种行程方式”，就把它误写成 nx 的外部旧方案。

关键反证：

```text
早凉行 / 日中歇
= 杨志此前自己的排程

辰牌起身 / 白日赶路
= 杨志后来根据地段风险再次修改自己的排程
```

因此这里不存在：

```text
外部方案 A
→ 主体只做局部改动
```

而是：

```text
主体自定方案 A
→ 环境条件变化
→ 主体修订为方案 B
```

`nx` 在这个微对象层缺少“外部方向/方案通道被实际续接”的前提。

## 4｜xn 最近邻

### present / 但不重锁新结论

这次改时段属于杨志自身排程的持续调整，并真实影响停歇、体力和服从执行，因此具有 `xn` 组织运行邻近。

但仓库已有杨志正式案例已经以 99/98 锁定：整个押运阶段属于“外部给总目标，主体主动重设运输方式、人员接口、时间节点”的 `xn` 高显影。

本轮不重复制造第二个“杨志=xn”案例，只新增一条边界纪律：

> **自我方案 A → 自我方案 B 的修订，不能被误包装成 `nx旧方案 → xn重设`。先查旧方案的来源。**

## 5｜zx 判断

### rejected_as_primary

杨志强制军健白日赶路、改变时间节点，并没有扩大到押送任务之外的新决定范围，也没有让梁府或更高秩序围绕新的杨志权力中心重排。

强硬执行、打骂、拥有临时提调权都不是 zx 的充分条件。

## 6｜拿掉测试

### 拿掉“旧早凉方案”

只保留“进入危险地段后，杨志自行设计白日赶路”，`xn` 自主排程邻近仍成立，nx 仍不会因此出现。

说明旧早凉方案不是外部 nx 支柱。

### 拿掉梁中书的最终押送目标

如果连“送生辰纲到东京”这个上位目标也拿掉，杨志当然连任务背景都不存在；但这只能证明上位任务来自外部，不能把下位时段安排自动判成 nx。

### 拿掉时段变化后的人员冲突

即使军健不抱怨，杨志“根据地段风险自行重排时间节点”的行为结构仍然存在；冲突只证明该调整产生现实后果，不决定十元分类。

## 7｜反向测试

真正适合作为 `nx → xn` 中间灰区的样本应满足：

```text
外部节点明确给出旧运行方案 A
→ 主体承接并实际运行
→ 主体只替换其中一个关键依赖
→ 其余总体骨架继续存在
```

而本例若要变成这种结构，必须让“趁五更早凉、日中歇”本身是梁中书或其他外部权限节点明确规定，杨志后来才自行改成白日赶路。原文不是这样。

## 8｜最近邻排除

### nx vs xn

```text
先问：旧方案是谁设计的？

外部设计 + 我沿着跑
→ nx候选

外部设计 + 我重写关键结构
→ xn上升

我自己设计 A + 我自己改成 B
→ 首先是 xn 内部自我修订问题
→ 不能凭“有旧方案”制造 nx
```

### xn vs zx

重新排时间与管理执行，是“怎么运行”的问题；没有新增决定边界，因此不锁 zx。

## 9｜第三因素冻结

冻结：

- 酷热是否导致最终失败；
- 杨志粗暴性格；
- 军健是否可怜；
- 晁盖吴用最终劫纲；
- 杨志武力与官职。

只保留：旧方案来源、谁拥有时段重设资格、修改是否仍在既有押运授权范围内。
