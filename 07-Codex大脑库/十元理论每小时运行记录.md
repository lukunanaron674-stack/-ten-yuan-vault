### 对象分层

- 稳定本体：`xz` 是长期危险逼近、退路缩窄与无法停留；`zx` 是长期以公开显权、扩权和凌驾成立。一次危机接管不能反推稳定本体。
- 当前状态：危险此刻使旧路径与旧指挥失效；主体此刻公开接管并成为局部决定中心。本轮若成立，优先落在状态层或关系位置层。
- 行为功能：`xz` 显影为逃生、抢窗口、冒险、穿越风险；`zx` 显影为宣告、指挥、夺取决定权、迫使他者围绕其行动。战斗和救人本身不足。
- 光影：警报、倒计时、断路、中轴构图、众人转向和高位镜头只作显影证据。
- 场景：灾难、追杀、战争、车厢、控制室和疏散现场不能替代端点。
- 时间关系：危险先显形；旧决定中心失效；主体随后首次获得公开决定位置。单纯先后仍不足。
- 关系位置：源端点是被局面规定者；目标端点是新的最终方向接口。必须看到他者把决定交给主体，而不只是主体自己冲出去。
- 显影：观察连续两项以上最终决定是否被他者接受，旧中心是否退位，危机后权能是否仅局部归零。
- 动态链：从“世界逼我行动”走向“现场开始围绕我的决定运行”。不机械生成勇气、胜利或领袖人格。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `xz`：危险已可感知逼近；安全路径、退路或时间窗真实缩窄；不行动会被吞没；危险直接改变可用选择。
- 目标端点 `zx`：主体力量公开进入现实；决定范围、影响范围或权能位置扩大；他者跟随、退位或改变行动；主体成为新的公开决定中心。
- 被改变变量：谁拥有现场最终方向决定权、主体决定被默认执行的范围、他者服从与跟随程度、旧秩序决定资格、主体作为公共接口的持续度。
- 关键拆分：危险可以生成“无人决定的空位”；主体占据空位可以生成新的关系位置。但主体的能力、勇气、专长和领导信用可能早已存在，只是被迫显影。
- 成立阶段：危险关闭退路 → 原指挥或规则失效 → 现场形成决定空位 → 他者首次把连续决定交给主体 → 主体公开重定局面。
- 体量：低体量为局部两次以上决定被跟随；中体量为团队路线与行动被持续重定；高体量为危机后新权力中心持续存在。当前证据最多支持低至中体量状态层。
- 显影条件：危险前无正式职位和稳定追随；拿掉危险同阶段不会获得位置；拿掉既有能力、意义、计划与权限后，仍能解释位置为何新增。

### 候选机制

- A 退路剥夺迫使潜在权能公开：危险封死延后与隐藏空间，主体必须把已有能力推到台面，决定范围扩大。理论后果：解释显影时点，不证明能力由危险生成。
- B 旧秩序失效形成决定空位：危险使原指挥、规则或等级失去反应资格，主体占据空位并被他者承认为新接口。理论后果：可支持关系位置层的 `xz 生 zx`，但不自动支持稳定本体层生成。
- C 普通反击、逃生或救人：只有行动强度，没有权能位置变化，排除。
- D 意义、职位、计划或权限借危机显影：分别优先检查 `zn 生 zx`、既有 `x/zx`、`xn` 或 `nx`，不能倒写成本关系。

### 正例候选

1. 《疯狂的麦克斯：狂暴之路》弗瑞奥萨｜绿洲失效后决定反攻：`xz` 是停靠位置与安全路线同时消失；`zx` 候选是公开重定队伍并带领反攻。污染来自既有战斗能力、团队信任、资源判断与潜在领导位置，更支持潜在 zx 显影。
2. 《釜山行》尚华｜感染扩散后的车厢突破：`xz` 是安全路径缩窄；`zx` 候选是站到队伍前方决定突破节奏并被跟随。污染来自体能、保护家人的 `zn` 和临时现场，危机结束后位置不持续。
3. 《你的名字。》三叶｜彗星坠落前疏散：`xz` 是时间窗即将关闭；`zx` 候选是从被否定位置转为推动全镇行动。污染来自广播与计划 `xn`、父亲权限、同伴协作和未来信息，无法证明危险独立生成权能。

### 反例

1. 火灾中跟随消防员逃生：主体没有取得决定位置，主要是 `nx`。
2. 被追杀者击倒敌人后继续逃跑：只是 `xz` 的局部反击。
3. 团队按预案撤离：主要是 `xn` 运行。
4. 军官按职位下令：权能位置先已存在，危险只是显影机会。
5. 因“必须救人”公开领导：优先检查 `zn 生 zx`。
6. 群众因恐惧听从强者：可能只有服从结果，没有证明新决定接口稳定形成。
7. 显权后遭追杀：方向更接近 `zx 生 xz`。
8. 个人勇敢但无人跟随、环境未重排：没有 `zx` 目标端点。

### 最近邻排除

- 与 `xz` 自身行动：临界行动、冒险和抢先选择不等于公开决定范围扩大。
- 与 `zn 生 zx`：意义先规定“必须做什么”；本轮候选由危险先关闭退路并使旧中心失效。
- 与 `xn`：预案、排程、分工和资源组织可解决危机，但不等于主体获得更高决定位置。
- 与 `x`：武器、职位、资源和权限是掌握边界；只有公开显现并使他者重新行动才进入 `zx`。
- 与潜在 `zx` 显影：主体原有能力或信用被迫公开，只能证明状态显影，不证明稳定本体生成。

### 拿掉测试

1. 拿掉危险，主体在同一阶段是否仍会公开扩权？若会，`xz` 不是必要源。
2. 拿掉他者跟随、退位与环境重排，只剩反击、救人或逃生，则 `zx` 不成立。
3. 拿掉既有能力、职位、计划、意义与关系信用，目标若完全消失，危险只提供显影机会。
4. 恢复旧秩序有效指挥后，主体若不再成为决定中心，说明权力真空是关键中介。
5. 若主体只做一次决定，随后所有人恢复原接口，体量不足。
6. 危机结束后位置立即归零，只能判局部状态层，不能反推稳定人物本体。

三个候选均未通过“拿掉既有能力与信用后，危险仍能生成此前不存在的 zx 能力”的纯度测试。

### 反向测试

```text
xz 生 zx 候选：危险先关闭退路并使旧中心失效 → 主体随后占据公开决定位置。
zx 生 xz 候选：主体先公开扩权、夺位和凌驾 → 旧秩序反扑并制造追捕、封锁与危险。
```

“反抗后遭追杀”不能用于证明本轮方向；“危机中站出来”也不能仅凭先后证明生成。

### 动态链后果

```text
旧决定中心仍有效时，我只是其中一员
→ 危险让旧中心失去反应资格
→ 现场出现无人承担的最终决定空位
→ 我连续作出决定，其他人开始围绕其行动
→ 现实决定中心发生暂时转移
```

改变的是现实决定中心的位置与默认接口，不是勇气、能力、胜利、正义性或永久领导人格。

### 95%门槛

高置信通过：

- 99%：普通反击、逃生、战斗和救人不能证明 `xz 生 zx`。
- 99%：目标变量必须落在公开决定范围、他者跟随和现实权能位置。
- 98%：必须排除职位、计划、意义、专长、关系信用和潜在 `zx`。
- 98%：危险制造决定空位与主体权能能力生成必须分开。
- 97%：若关系成立，优先限定为状态层或关系位置层，而非稳定人物本体。

未达到95%：

- 尚不能判断“决定位置新增”是否足以称为 `zx 生位`，还是只属于潜在 `zx` 的显影机会。
