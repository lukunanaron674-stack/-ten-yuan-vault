## 源端点、目标端点与被改变变量

### 源端点 `z`

必须明确：

1. 谁认可谁；
2. 确认的是存在、能力、作品、身份还是选择；
3. 认可是否准确落到主体；
4. 为什么该认可位置重要；
5. 认可者没有同时提供教学、治疗、权限、职位、资源、许可、推荐或失败兜底。

完成、获奖、掌声、录取和成功本身不能代替 `z`。

### 目标端点 `nz`

必须观察：

1. 双方之间出现可回返位置，而非只有被认可者继续靠近；
2. 评价议题已经耗尽，关系不再围绕成绩、作品或确认；
3. 双方分别主动回返；
4. 双方为非评价事项承担成本并修复冲突；
5. 认可者负面判断或撤回赞许后，非评价关系仍保持；
6. 同等级第三认可者不能随意替代原对象。

### 被改变变量

- 认可位置的关系价值；
- 被认可者提出非评价回返的意愿；
- 认可者退出评判后主动回返率；
- 零评价窗口中的关系持续度；
- 非评价冲突修复率；
- 赞许撤回后的关系保持率；
- 对象不可替代性。

### 阶段、体量与显影条件

- 低体量：认可后短暂不舍或单方回返提议，只是前置变量。
- 中体量：评价议题耗尽后双方分别主动回返，并形成普通往来。
- 高体量：负面判断、冲突和阶段结束后仍保持可回返位置。
- 显影条件：零评价窗口、双方无代价退出、负面判断、第三认可者替换、非评价冲突。

## 候选机制

### 候选A：认可位置获得关系价值并触发单方回返提议

```text
重要认可主体准确确认主体
→ 对方不再只是一次评判位置
→ 被认可者希望保留接触
→ 提出一次非评价回返
```

理论后果：只改变关系进入概率和单方提议意愿，尚未改变 `nz` 的双方可信停靠变量。当前约94%，不得借阶段性口径进入正式关系。

### 候选B：评价者退出后转成双方可信停靠对象

```text
认可发生
→ 评价议题耗尽
→ 认可者退出奖励、资源和职位
→ 双方分别主动回返
→ 修复一次非评价冲突
→ 负面判断后仍维持关系
→ nz 上升
```

理论后果：若有两例通过全部控制，可锁关系位置层或当前状态层窄机制，不上推稳定本体。当前约92%。

### 候选C：共同被见证使阶段获得唯一性

```text
共同成果被重要主体确认
→ 共同经历获得明确归因
→ 阶段在记忆中不可替代
→ 不愿结束增强
```

理论后果：最容易被长期共事 `xn`、共同容器 `n`、原有友情与自然离别污染。当前约90%。

## 正例候选

### 《爆裂鼓手》安德鲁与弗莱彻

结尾专业认可位置极其明确，但影片只完成当场确认，没有展示评价议题耗尽后的双方回返、普通往来、负面判断后的关系保持或非评价冲突修复。因此是高纯度 `z` 加缺失 `nz` 的边界例。

### 《国王的演讲》伯蒂与莱昂内尔

莱昂内尔确认伯蒂能够发声并承担职责，二人关系后来继续。但认可前已经有长期训练、共同风险、职业依赖和冲突修复，无法证明 `z` 独立生成停靠。

### 《心灵捕手》威尔与肖恩

肖恩确认威尔不必由创伤定义，关系具有超出治疗的价值。但变化混入长期治疗、事实重释、照护、信任承载和既有关系厚度，不能作为纯例。

## 反例

1. 获奖者继续联系评委以获得下一次评价：评价依赖。
2. 导师长期照顾学生后给予认可：留恋来自 `n` 与既有关系。
3. 员工获表彰后留下：职位、待遇与组织结构变化。
4. 演员即使演出失败也舍不得剧团：`nz` 先于 `z`。
5. 只有被认可者主动联系：单方提议。
6. 认可者撤回赞许后关系立即终止：赞许依赖。
7. 更换同等级评委后产生同样依恋：认可位置依赖。
8. 双方只围绕成绩、作品和下一次评价往来：评判接口未退出。

## 最近邻排除

- `xn 补 z`：训练和证据组织使认可完成。
- `x并z 生 z`：身份或作品壳提供识别接口。
- `xz 补 nz`：失去风险提高停靠重量。
- `nz 生 z`：原有不舍推动最后一次被看见。
- `z` 自循环：继续索取确认。
- `x/xn`：职位、资源、推荐和流程维持联系。

## 动态链后果

当前只允许写为候选：

```text
一个重要主体真正确认了我
→ 这个位置不再只是一次判断
→ 我提出保留往来的非评价回返
→ 若对方退出评判后也主动回来
→ 双方能在无评价、无资源条件下修复普通冲突
→ 负面判断后关系仍保持
→ 才可能发展为双方可信停靠
```

感觉走向：从“终于被这个人看见”，转成“即使他不再评价我，我们仍愿彼此回来”。

不得机械生成友情、爱情、忠诚、永久关系、共同体或稳定人物本体。

## 三元与十元并行核验

三元只核验“被看见—关系位置增值—回返—停靠”的整体感觉运动。

十元只核验：

- `z` 是否保持纯认可；
- `nz` 是否形成双方可回返位置；
- 评价、资源与职位是否退出；
- 非评价冲突是否修复；
- 对象是否不可由第三认可者替代；
- 原有 `n/nz/xn` 是否排除。

两者并行，不构成父子派生。
