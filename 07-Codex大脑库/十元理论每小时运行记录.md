## 3. 源端、目标端、变量与成立条件

### 源端`zx`

- 人物与阶段：人物在多人可见、存在现实代价且有退路的阶段，公开作出最终决定并使其现实生效。
- 人物行为：拒绝退让、承担处分或损失、压过旧决定中心、让选择被他者实际执行或见证。
- 具体名词：公开决定接口、承担代价的显权行为、让选择现实生效的主体权能。
- 排除：单纯演讲、名气、职位、宣传、暴力强迫、群体胜利和镜头高光。

### 目标端`zn`

- 人物与阶段：目标人物此前没有同内容、无奖励也坚持的原则，之后把该原则作为跨情境最终指导资格。
- 人物行为：源离场后自行维护；首次失败、受罚、无观众和利益反转后不撤回；英雄本人背弃时反对英雄而维护原则。
- 具体名词：不可让渡的意义方向、无奖励仍认领的判断、脱离源人物继续运行的原则内容。
- 排除：崇拜英雄、模仿姿态、服从命令、身份表演、群体口号、既有原则显影与一次行动许可。

### 被改变变量

1. 目标人物是否从无该原则内容变为主动认领；
2. 原则是否脱离源人物、奖励、观众、群体与具体场景继续；
3. 目标是否能用自己的语言表达原则，而非只复制源人物口号与姿态；
4. 首次失败后原则是否仍保有最终指导资格；
5. 英雄背弃时，目标是否维护原则而非维护英雄；
6. 同内容同曝光的低`zx`来源能否产生同等变化。

### 成立阶段、体量与显影条件

- 低体量：一次震撼、跟随、复述，只记状态与显影。
- 中体量：目标跨一次代价行动，但仍依赖源人物、群体许可或共同敌人；记录行动阈值下降候选。
- 高体量候选：目标先验原则归零，源离场且奖励、观众和群体撤场后，目标跨新情境、首次失败与英雄背弃仍维护原则。
- 显影条件：内容与曝光近控制；冻结教学、解释、依恋、救命债、身份模仿、共同敌人、奖励、职位、资源和群体感染。

## 4. 候选机制

### A｜公开承担代价独立生成原则内容

```text
高zx人物公开把某项原则做成现实并承担代价
→ 目标人物此前不存在的原则内容第一次在内部成立
→ 原则获得最终指导资格
→ 源人物离场后仍独立运行
```

严格候选约92%。

理论后果：若成立，只能锁“公开承担代价为无先验原则者提供可认领原则内容”的窄机制；不能写成任何英雄行为都自动制造信仰。

### B｜提高原则可实践性并降低首次行动阈值

```text
目标人物已经听过或部分认同原则
→ 高zx人物把原则做成可见现实样本
→ “这不是空话、有人能承担后果”得到证明
→ 目标更敢第一次行动
```

竞争解释约98%。

理论后果：改变的是原则可实践性、行动许可与首次执行阈值，不是`zn`内容新生。

### C｜既有原则显影或第三结构启动

目标人物可能原本已有原则，只因恐惧、孤立或缺乏许可而没有公开行动；也可能由长期教学、亲密依恋、创伤重构、共同敌人、奖励、职位和群体感染启动。

排除解释约98%。

理论后果：应分别记录教学`xn`、承载`n`、确认`z`、身份壳`x并z`、危险`xz`或群体结构，不把最终行为倒归给纯`zx生zn`。

## 5. 正例候选

1. **《死亡诗社》Keating与Todd，结尾课堂阶段**：Keating长期公开挑战权威并承担被解雇的代价；Todd最终率先站上桌，似乎认领“个人判断不应完全交给权威”。但原则内容早已通过长期教学输入，且结尾混入师生依恋、同伴感染与集体许可。该例更支持“既有原则显影和首次行动阈值下降”，不能证明原则内容由`zx`新生。
2. **《V字仇杀队》V与Evey，V离场后的行动阶段**：V公开反抗并承担死亡代价，Evey在其离场后继续推动行动，表面符合“源离场后原则继续”。但变化混入长期解释、亲密依恋、囚禁与创伤重构、共同敌人和直接训练；无法冻结内容来源，不能证明纯关系。
3. **严格控制候选**：人物甲在公开审判中拒绝伪证并承担处分；旁观者乙此前没有“宁受罚也不作伪证”的原则。甲离场后，乙在另一机构、无观众、首次受罚时仍拒绝伪证；甲后来亲自作伪，乙反对甲而维护原则。只有同内容同曝光低`zx`讲述无法产生同等变化，才接近纯例。当前缺两组可核验材料。

## 6. 反例

1. 学生经过长期课程后形成价值观，教师最后一次公开承担代价只触发行动：原则内容主要来自教学。
2. 士兵因指挥官公开冲锋而跟随：命令、职位、共同危险和群体执行足以解释。
3. 粉丝模仿英雄服装、口号和姿态：是身份壳、认可和模仿，不是原则独立运行。
4. 人物被英雄救命后追随：混入承载、救命债和依恋。
5. 群众在胜利现场宣誓：奖励、观众和群体感染未冻结。
6. 人物原本已有原则，只在英雄行动后敢公开表达：属于既有原则显影。

## 7. 最近邻排除

- `zn 生 zx`：解释源人物自己的意义怎样推动其公开决定，不能倒写成旁观者原则新生。
- `xz 生 zx`：危险怎样形成临时公开决定接口，不解释原则内容来源。
- `x并z 生 z`：英雄壳怎样使人物被确认，不解释目标`zn`。
- `xn 补 z`：长期证据怎样补足确认。
- 教学与解释输入：原则内容由跨时间组织提供。
- `z 克 nx`：重要确认可能使人物取回方向，与原则内容新生不同。
- 群体许可与身份模仿：只改变公开行动机会和归属位置。

## 9. 反向测试

反向`zn生zx`是现行几何生位：

```text
人物已有不可让渡意义
→ 公开作出决定并承担代价
→ 形成显权接口
```

因此必须先排除目标人物本来已有`zn`，高`zx`行为只使其显影或降低首次行动阈值。

若英雄背弃后目标也跟随英雄背弃，说明目标依附的是英雄、身份或群体，不是原则。若低`zx`同内容来源产生同等变化，作用主要来自内容、教学或事实，而不是`zx`体量。

## 10. 动态链后果

```text
有人把抽象原则公开做成，并真实承担代价
→ 原则获得可见、可实践的现实形状
→ 旁观者的首次行动阈值下降
→ 既有原则可能显影
→ 只有此前无该原则的人在源离场后仍跨失败、新情境和英雄背弃维护
→ 才接近zn内容新生
```

本轮只允许写感觉走向、实践可行性和行动阈值变化，不机械生成信仰、勇气、群众觉醒、忠诚或稳定人格。

## 11. 三元与十元并行核验

三元观察：谁公开承担代价、谁随后行动、源离场后关系与行为是否继续。

十元区分：

- `zx`：公开决定与承担代价的权能接口；
- `zn`：脱离源人物仍有最终指导资格的原则；
- `xn`：长期教学、解释与组织；
- `z`：重要确认和行动许可；
- `n`：承载、照顾与安全位置；
- `xz`：共同危险和失去压力；
- `x并z`：英雄身份、口号和公共壳。

两套系统并行，没有写成父子派生。
