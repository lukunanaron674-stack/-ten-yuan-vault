### 对象分层

- 稳定本体：`nx` 是长期不占最终方向决定位置，沿既有关系、流程、秩序或他者方向推进；`x并z` 是稳定身份、包装、公开角色或共同说法。不能因人物沉默或身份失效就反推稳定本体。
- 当前状态：主体仍沿既有方向行动，但在某段关系中停止认领、复述或履行身份壳要求；候选最可能成立于关系层与状态层。
- 行为功能：`nx` 显影为不另立旗帜、不主动拆壳、继续沿既有通道行动；`x并z` 显影为命名、代表、包装、角色归类、共同声明与外部解释。
- 光影：侧位、无中心、制服、面具、门面、徽章与共同构图只作辅助显影。
- 场景：组织、公司、家庭、政党、学校、共同声明、职位身份只是候选场景。
- 时间关系：身份壳必须先真实覆盖主体；随后主体停止背书；最后壳的代表、吸纳或解释接口下降。若从未完成吸纳，只能判壳未生成。
- 关系位置：主体必须原本拥有可认领、可复述、可履行和可署名的位置；没有资格或从未被纳入者不构成克制。
- 显影：第三方是否仍能用该壳代表主体；主体名字、行为、发言和成员资格是否仍被壳稳定解释；恢复背书后接口是否恢复。
- 动态链：从“这个壳已经能代表我”转成“我仍沿通道行动，但不再提供它继续代表我的接口”。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `nx`：主体不主动争夺方向或公开拆壳，仍可沿既有流程和关系行动；但持续不进入壳要求的认领、复述、履行、签署或署名位置。
- 目标端点 `x并z`：壳此前已经真实成立，并依赖主体持续接口维持对其代表、吸纳、覆盖和解释资格。
- 被改变变量：壳对主体的代表有效性、吸纳范围、共同背书完整度、第三方归因稳定度、主体行为是否仍能被壳解释，以及主体能否被写入“我们都这样”的共同说法。
- 成立阶段：壳已覆盖主体 → 壳需要持续背书 → 主体不公开反抗但停止复述、履行或署名 → 第三方不再能稳定用壳代表主体 → 壳对该主体的接口下降。
- 体量：低体量为一次具体声明或身份接口失效；中体量为一段关系或组织中持续退出背书；高体量会高度混入公开斗争、资源与制度崩塌，暂不宜锁定。
- 显影条件：拿掉 `x/zx` 压制、资源惩罚、主动揭露、辞职、法律撤销和外部证据后，目标变量仍下降；恢复背书后接口能够恢复。

### 候选机制

- A 认领接口撤回：壳已能代表主体 → 壳依赖主体持续复述、履行或默认承认 → 主体仍沿既有通道行动，却停止提供认领接口 → 壳对该主体的代表与解释资格下降。理论后果：克制对象不是整个壳，而是壳与特定主体之间的接口。
- B 共同背书链缺口：共同壳依赖“大家都这样”的成员链 → 关键成员不公开反对，但不签署、不复述、不允许署名 → 壳覆盖范围从“全体”缩为“部分”。理论后果：改变的是共同壳覆盖边界，而非壳的真假或制度存亡。
- C 竞争解释：资源撤回、职位解除、辞职、公开反抗、价值拒绝、真相曝光、权力摧毁或外部证据击穿。此时启动源更接近 `x/zx/zn/xn/z`，不能倒写成 `nx 克 x并z`。

### 正例候选

1. 《千与千寻》千寻与“小千”身份阶段：她行动上进入油屋流程，但真名记忆使“小千”无法完全覆盖她。支持“行动跟随不等于身份认领”；限制是白龙帮助、汤婆婆权能、真名作为外部证据与千寻主动选择过强，且“小千”是否曾完整成立存在疑问。
2. 《黑客帝国》尼奥与“托马斯·安德森”办公室身份阶段：他不再履行员工身份后，公司壳失去覆盖。限制是主动离职、追捕、现实证据暴露与公开选择过强，更像离开壳而非 `nx` 式接口撤回。
3. 组织共同声明中的不背书成员：成员继续履行普通流程，不公开反对，只拒绝签字、复述或允许名字进入“全体一致”声明，使壳只能代表多数。结构纯度最高，但缺少两个可核验具体人物文本。

### 反例

1. 记者搜证揭露公司造假：启动源是调查、证据与公开揭露。
2. 员工辞职后身份失效：壳失效来自关系终止，不是持续 `nx`。
3. 主体从未加入或从未被要求背书：壳没有形成接口，不能说被克制。
4. 下属因恐惧签署声明：`nx` 可能上升，但 `x并z` 反而得到背书接口。
5. 主体看穿伪装却继续完整履行角色：认知变化没有改变壳的代表资格。
6. 撕下面具公开宣告真实身份：优先检查 `zx/zn` 主动占位。
7. 组织撤回职位、制服、账号或署名：由 `x/xn` 撤销接口。
8. 外部舆论或证据证明身份虚假：壳由外部击穿，不是主体沉默克制。

### 最近邻

- 与 `zn 克 x并z`：主体因“这个身份不对”主动拒绝并撤回意义资格，启动源是 `zn`；本候选要求不另立价值旗帜，只停止提供壳接口。
- 与 `zx 克 x并z`：公开拆壳、强迫揭露、夺取话语权属于 `zx`。
- 与 `x 克 x并z`：撤销职位、名称、资源、账号、合法接口属于 `x`。
- 与反向 `x并z 克 nx`：身份壳先规定可用角色路径，使主体更沿既有方向行动；改变的是 `nx`，不是壳覆盖。

### 拿掉测试

1. 拿掉主体持续不认领后，若恢复复述、履行与署名，壳是否重新取得代表资格？
2. 拿掉主动揭露、辞职、资源撤回、价值拒绝和外部证据后，壳接口是否仍下降？
3. 拿掉“壳此前已成立”后，只剩从未吸纳，则不构成克制。
4. 拿掉壳对主体持续背书的依赖后，沉默是否不再产生作用？若是，说明目标端点要求成立。
5. 拿掉主体原本的认领资格后，是否只是没有资格，而非接口撤回？
6. 拿掉第三方归因变化后，只剩主体心理不认同，目标变量不足。
7. 当前两个具体作品候选均未通过全部测试。

### 反向测试

```text
nx 克 x并z：主体仍沿既有方向行动，但停止提供认领与背书接口 → 壳对该主体的代表和解释资格下降。
x并z 克 nx：稳定身份壳预设角色路径和共同说法 → 主体可用方向被限定 → 更沿壳给出的安排推进。
```

两方向可能反馈，但正向改变壳接口，反向改变主体方向空间，不能互相代证。

### 动态链后果

```text
这个壳原本已经能代表我
→ 我没有另立旗帜，也没有公开拆壳
→ 我仍沿既有通道行动
→ 但不再复述、履行、签署或允许它署名代表我
→ 壳对我的解释资格逐步失效
```

改变的是“壳能否继续把主体写进共同说法”的关系层感觉，不机械生成真相曝光、身份解放、组织崩塌、公开反抗或真实自我回归。

### 三元与十元并行

三元只判断作品整体精神运动；十元本轮只核验 `nx` 的不占位与接口撤回、`x并z` 的既有覆盖和背书依赖。不得由空间主题反推关系成立，也不建立父子派生。

### 95%门槛

- 99%：壳从未完成吸纳，不等于已成立后被克制。
- 99%：看穿、揭露、辞职、公开拒绝、资源撤回和外部证据击穿不能直接归为 `nx 克 x并z`。
- 98%：目标变量必须是代表、吸纳、覆盖与解释接口下降。
- 97%：若成立，优先落在关系层或状态层，而非稳定本体。
- 未达到95%的核心：没有两个具体人物案例同时证明壳此前已成立、依赖持续背书，且在排除公开斗争、资源撤回、主动揭露和外部证据后，仅由持续不认领使第三方停止用该壳代表主体。
