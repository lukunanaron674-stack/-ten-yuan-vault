### 对象分层

- 稳定本体：`zn` 是无奖励、无认可与无结果保证时仍成立的内部意义确定；`n` 是长期让对象落到自身、先接住、再持续处理。一次收留不能反推稳定本体。
- 当前状态：主体此阶段确认“不能丢下”，并撤回拒绝或推出资格；目标最多先落在关系层或状态层。
- 行为功能：拒绝抛弃、允许进入、提供食物、隐藏、照护与承担风险是证据；行为必须继续改变留存时间和负荷处理。
- 光影：誓言、圣性、地下室、暖光、床位与围墙只作显影。
- 场景：宗教、家庭、旅馆、避难所、纪念场所不能替代端点。
- 时间关系：意义先成立 → 对象获准进入 → 跨阶段停留 → 负荷被处理 → 下一阶段仍保留内部位置。只完成前两段不足。
- 关系位置：源主体是意义持有者，目标对象是被接入者或由主体形成的承载关系；领袖、父母、神父、经理等称谓不能直接判关系。
- 显影：对象是否从可拒绝的外部问题，变成不能立即推出、必须持续处理的内部负荷。
- 动态链：意义改变承载入口，随后是否形成跨时间处理；不机械生成建筑、制度或共同体。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `zn`：主体即使没有奖励、法律义务、群体监督和结果保证，仍认为某个人、某件事或某段意义不能被抛下。
- 目标端点 `n`：对象实际进入主体或结构内部，被允许停留，产生的食物、照护、隐蔽、风险、资源或关系负荷被持续处理，而非一次接触后立即转交。
- 被改变变量：拒绝权、推出资格、准入范围、留存时间、再次返回资格、负荷处理持续度、对象由外部议题转为内部责任的程度。
- 成立阶段：意义确认 → 准入启动 → 留存跨阶段 → 负荷处理 → 再次返回或继续内部存在。
- 体量：低体量是一次准入；中体量是同一对象跨阶段停留并被处理；高体量是承接边界稳定扩大并能反复接收。低体量只能作弱证据。
- 显影条件：拿掉成熟建筑、制度、资源权限、领袖命令、亲属职责和法律义务后，准入与持续处理仍由“不能抛下”的意义直接启动。

### 候选机制

#### A｜准入与留存边界重划

```text
zn 确认对象不能被丢下
→ 主体撤回拒绝与推出资格
→ 对象进入自身生活、空间或关系内部
→ 主体持续承担对象负荷
→ n 的准入与留存边界上升
```

理论后果：若成立，只先锁定 `n` 的入口与低中体量承载，不宣称完整建筑、制度或成熟共同体自动生成。

#### B｜意义只提供动机，中介才完成 n

```text
zn 提供“应该接住”的理由
→ x 提供资源与准入权限
→ xn 提供组织、记录与跨时间维持
→ zx 提供公开推动与保护
→ n 形成
```

理论后果：若更准确，`zn 生 n` 只能保留几何压缩；具体链必须显式写出中介。

#### C｜准入启动与承载成立分两段

```text
撤回拒绝权
→ 只证明承载入口打开
跨阶段停留 + 持续处理负荷 + 下一阶段仍保留内部位置
→ 才证明 n 成立
```

理论后果：该拆分可阻止一次收留、捐助、藏匿或口头承诺被误判为完整 `n`。

### 正例候选

1. **《偷书贼》汉斯、罗莎与马克斯**：汉斯确认不能把马克斯交给迫害体系，家庭允许其进入地下室并长期居住，持续承担食物、隐蔽与风险。支持“准入启动 + 跨阶段留存”。限制是家庭空间和准入含 `x`，隐藏安排与持续维持含 `xn`。
2. **《卢旺达饭店》保罗与难民**：保罗撤回把难民推出酒店的资格，难民进入内部并持续获得房间、食物、秩序和风险承担。支持承接边界扩大。限制是经理权限 `x`、谈判与公开推动 `zx`、名单与物资组织 `xn` 均为强中介。
3. **低资源邻里照护结构例**：无领袖和成熟制度时，一户人家因“老人不能独自被留下”先开放住所并连续数日轮流送饭、陪护、处理药物与夜间风险。结构纯度较高，但缺少第二个可核验作品人物文本。

### 反例

1. 一次捐款或一次送饭：只有意义行为，没有对象跨阶段留存与负荷处理。
2. 一次宗教集会：`zn` 与聚集场景共现，没有持续承载。
3. 政府依预算、审批和施工建立纪念馆：启动源主要是 `xn/x/zx`。
4. 领袖命令成员收留难民：方向更接近 `zx/nx`。
5. 商业旅馆因利润接待客人：`n` 可成立，但源端点不是 `zn`。
6. 因法律监护、亲属职责或职位要求接收：拿掉义务后若不接收，不依赖本关系。

### 最近邻排除

- 与 `zn 生 zx`：后者改变公开推进、号召和现实权能；本轮改变谁被允许进入并持续留下。
- 与 `n 生 xn`：后者从既有承载出发，提炼分工、记录和预案；本轮发生在承载入口和留存资格建立阶段。
- 与 `zn 补 x`：补位改变已有掌握边界为何被守、如何被用；本轮要求对象真正进入并成为内部负荷。
- 与普通善良：一次心软、帮助或捐赠缺少跨阶段留存与处理闭环。
- 与 `x/xn/zx`：资源、流程和公开推动可以实现或扩大承载，但不能自动证明意义是独立生成源。

### 拿掉测试

1. 拿掉 `zn`，若仍因商业、行政、法律、亲属或职位义务接收，不成立。
2. 拿掉 `n`，只剩声明、捐助、号召或一次藏匿，目标端点消失。
3. 拿掉 `x` 的房产、资金和正式权限，主体是否仍以生活与风险承担接住对象？
4. 拿掉 `xn` 的成熟流程、名单和轮班，承载是否已经跨阶段开始？
5. 拿掉 `zx` 的领袖命令和公开推动，主体是否仍主动撤回拒绝权？
6. 拿掉建筑，换空间后对象是否仍被允许停留并被持续处理？
7. 拿掉第二阶段的留存与负荷处理，只剩第一次准入，是否仍能判完整 `n`？答案是否定的。

当前两个作品候选均未通过全部第三因素拿掉测试。

### 反向测试

```text
zn 生 n：
不能放弃的意义先成立
→ 对象获得准入与留存资格
→ 承载开始并跨阶段维持

n 生 zn：
对象长期被同一主体或容器接住
→ 共同时间与负荷沉淀
→ 形成不能放弃的内部意义
```

两方向可以反馈，但不能因最终同时存在意义和承载就互相代证。

### 动态链后果

```text
这件事不能被丢下
→ 它不再只是外部问题
→ 我撤回把它推出去的资格
→ 它进入我的生活、空间或关系内部
→ 下一阶段它仍在这里
→ 我继续处理它带来的负荷
```

改变的是：**意义如何先打开承载入口，再能否把入口变成跨时间持续的内部位置。**

不机械生成建筑、制度、组织规模、资源成功或永久稳定。

### 三元与十元并行

三元只核验作品整体精神运动；十元本轮只核验 `zn` 源端点、`n` 目标端点、准入与留存变量、第三因素和方向。不能由本体主题或“信仰建立家园”的题材印象反推 `zn 生 n`。

### 95%门槛

高置信结论：

- “有信仰就建教堂”旧口径失效：99%。
- 建筑、组织规模和规章数量不是 `n` 目标变量：99%。
- 撤回拒绝权只证明准入启动，不足以单独证明完整承载：98%。
- 完整 `n` 至少需要跨阶段留存与实际负荷处理：98%。
- 一次收留、捐助、藏匿和口头承诺不足：99%。
- 后续出现 `x/xn/zx` 不自动抹除初始准入作用，但必须证明它们不是必要生成中介：97%。

未达到95%的核心：

- 缺少两个低权能、低制度、低资源的具体人物案例；
- 《偷书贼》《卢旺达饭店》均混入强 `x/xn/zx`；
- 无法确认“准入启动 + 跨阶段处理”是否足以构成直接生位，还是 `zn` 只提供动机、真正承载由中介完成；
- 用户仍有超过5%概率否定该直接机制。
