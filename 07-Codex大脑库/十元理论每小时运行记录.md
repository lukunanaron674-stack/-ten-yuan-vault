## 源端点、目标端点、变量、阶段、体量与显影

源端点 `z`：重要认可者只确认主体自己的判断、能力或选择资格；不得同时提供路线、职位、许可、资源、长期教学、照护或后果兜底。

目标端点 `nx`：主体此前必须已有真实可行路线、否决能力和承担后果的条件，却因认为自身判断不合法、不可靠或没有资格成立而持续沿外部路线推进。

被改变变量：主体对自身判断资格的认领强度、外部路线的唯一合法性、替代路线提案率、否决权使用率、失败后的再次决定资格，以及方向变化能否迁移到未被认可者直接评价的新选择。

成立阶段：认可前已有路线但自我取消；认可后首次提出路线；认可撤回或反对；首次自主路线失败或受损；随后在新选择中再次提出路线并承担结果。

体量：低体量为单一选择上取回方向；中体量为一段关系或一类选择中持续使用否决；当前无证据支持稳定人物本体改写。

显影条件：认可者不改变许可、资源、教学与风险兜底；主体在首次成功之外，还能在失败和未被直接评价的新选择中继续决定。

## 候选机制与理论后果

### 候选 A：判断资格确认

```text
主体已有可行路线
→ 但认为自己的判断没有资格成立
→ 重要认可者确认“你的判断可以成立”
→ 外部路线不再垄断合法性
→ 主体提出、执行并承担自己的路线
```

理论后果：只可能克制“判断资格自我取消型 `nx`”，不能泛化到缺资源、权限、能力或现实路线的结构性依赖。

### 候选 B：能力资格确认

```text
主体知道自己想走哪条路
→ 但不相信自己能承担后果
→ 认可者确认其能力
→ 主体开始使用否决和决定位置
```

理论后果：若主体只是更努力执行旧安排，只有 `z` 上升，`nx` 未下降。

### 候选 C：局部能力信心

认可只提高被评价任务中的表现，主体在其他选择中仍等待外部方向。此时改变的是局部表现与显影，不是方向合法性。

### 候选 D：结果奖励维持的条件性自主

首次自主路线成功后主体暂时更敢决定；一旦失败便退回认可者或原安排。此时方向资格没有稳定回到主体，只是成功结果提供临时信心。

### 排除候选 E：撤回限制冒充认可作用

认可者同时掌握许可、资源、教学、职位或风险兜底。主体的现实选择空间可能由 `x/xn/zx/n` 的撤限作用生成，不得归给纯 `z`。

## 正例候选

1. **《死亡诗社》托德与基廷｜课堂即兴诗阶段**：基廷确认托德拥有自己的诗性声音，托德从标准答案与沉默位置转向自身表达。污染来自教学结构、强引导、课堂权能和情感承载；没有基廷反对、首次失败及跨选择迁移证据。
2. **《跳出我天地》比利与父亲｜父亲支持舞蹈之后**：家庭路线不再拥有唯一现实资格，但比利此前已有强自主方向，父亲同时提供许可、资源与家庭放行；更像既有自主获得支持。
3. **研究生独立定题结构例**：学生已有可行选题，外部学者只确认其判断能力，不掌握毕业、经费和许可；学者后来反对、第一次新题失败后，学生仍提出第二条独立路线。结构能通过新测试，但缺可核验具体人物文本，不能作为正式案例。

## 反例

1. 老板表扬员工后，员工更努力执行老板路线：`z` 上升，`nx` 未降。
2. 父母说相信孩子，却继续控制学校、资金与许可：认可没有改变方向结构。
3. 导师给出新方案，学生改听导师：只是换外部路线。
4. 上级授予预算、职位或签字权：权限变化，不是纯认可。
5. 长期治疗与训练后主体更独立：可能来自 `xn/n`。
6. 人物本来就坚持自己的路线，认可只使其公开：既有自主显影。
7. 认可者一反对，主体立刻撤回选择：继续依赖认可。
8. 首次自主成功时敢决定，失败后立即退回原安排：结果性信心。
9. 只在被认可领域自主，面对未被评价的新选择仍等待别人决定：局部能力信心。

## 最近邻排除

- `x/zx`：许可、职位、资源和公开放权直接改变现实决定资格。
- `xn/n`：教学、训练、陪伴和照护改变能力与安全感。
- `zn`：主体因事情本身正确而拒绝安排，启动源是内部意义。
- 自信上升：更敢表达不等于提出路线、使用否决并承担后果。
- 换跟随对象：认可者成为新方向中心，`nx` 结构未变。
- 既有自主显影：目标 `nx` 原本不存在。

## 拿掉测试

1. 拿掉认可，只保留教学、许可、资源与放权，主体仍独立，则不依赖 `z`。
2. 拿掉教学、资源、职位、许可和后果兜底，只保留资格确认，主体仍取回方向，才支持直接作用。
3. 将认可者与原方向提供者分开后，方向变化是否仍发生？
4. 拿掉主体原有可行路线，认可后若仍无替代方向，目标端点不存在。
5. 拿掉情绪振奋，只观察替代路线、否决与现实损失。
6. 认可停止、撤回甚至反对后，主体是否仍维持路线？
7. 首次自主路线失败、受损或没有奖励后，主体是否仍保留再次决定资格？
8. 在认可者未直接评价的新选择中，主体是否仍独立提出路线？
9. 若主体随着认可者的意见改变方向，只能判换跟随对象。

现有两个具体作品候选均未通过第 2、3、6、7、8 项组合。

## 反向测试

```text
z 克 nx：
主体因否定自身判断资格而跟随
→ 认可确认判断资格
→ 认可撤回、路线失败和新选择出现后
→ 主体仍持续取回方向

nx 克 z：
主体不表达、不呈现、不进入认可接口
→ 重要确认无法发生
```

两方向改变的变量不同，不能互相代证。

## 动态链后果

```text
我不是没有路线
→ 我只是认为自己的判断没有资格成立
→ 重要的人确认我的判断可以成立
→ 我提出自己的路线
→ 他后来反对，我的第一次选择也失败
→ 在另一项他从未评价的新选择里
→ 我仍提出路线、使用否决并承担代价
→ 方向权才真正回到我这里
```

改变的是主体是否承认自己拥有决定资格，以及外部路线是否仍垄断合法性。不机械生成成熟、勇气、成功或稳定独立人格。
