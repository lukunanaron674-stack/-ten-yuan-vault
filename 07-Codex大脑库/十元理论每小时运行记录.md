## 源端点、目标端点、机制与变量

源端点 `zn`：主体在没有奖励、认可、法律义务、亲属职责和结果保证时，仍认为某个对象不能被抛下。

目标端点 `n`：对象真实进入主体的生活、关系或可用空间，跨阶段停留；主体没有立即推出或转交，而是持续处理对象产生的现实负荷。

被改变变量：拒绝权、推出资格、可接收对象范围、留存时间、再次进入资格、外部议题转为内部负荷的程度，以及负荷持续处理度。

成立阶段：

```text
A 准入启动：zn 撤回拒绝与推出资格
→ B 承载成立：对象跨阶段留存并被持续处理
```

体量：优先落在具体人物、关系或状态层；不自动升级为大型组织、建筑或稳定共同体。

显影条件：拿掉房产、资金、职位、法律义务和成熟流程后，准入与持续承担关系仍存在。

## 候选机制与理论后果

### 候选 A：意义直接重划承载边界

```text
不能抛下
→ 撤回拒绝权
→ 对象进入内部
→ 跨阶段停留
→ 持续承担现实负荷
```

理论后果：`zn` 直接改变 `n` 的准入、留存与承担边界，不生成房屋、资金、权限或成熟流程。该窄机制已锁定。

### 候选 B：意义只提供动机，中介生成承载

```text
zn 提供理由
→ x 提供资源与准入
→ xn 提供组织
→ zx 提供公开推动
→ n 形成
```

理论后果：若所有案例都依赖中介，`zn` 不能独立生 `n`。正式专项以低权能、低制度、低资源案例排除了该解释作为普遍必要条件。

## 正例

1. **《The Kid》流浪汉与弃婴**：流浪汉撤回推出资格，在贫困、无正式监护与成熟制度下长期抚养婴儿；食物、居住、照护与分离风险跨年落入其承担范围。
2. **《何以为家》赞恩与约纳斯**：赞恩没有法律、亲属、资源或职位义务，却在极端贫困中持续寻找食物、移动、照护并承担幼儿风险。
3. **《小偷家族》治、信代与友里**：发现虐待后不再把友里送回，使她跨阶段进入家庭的食物、睡眠、照护与关系位置。

## 反例

1. 一次捐款、送饭、藏匿或临时过夜：只有接纳行为，没有跨阶段承载。
2. 法律、亲属、职位或合同义务接收：源端点不是纯 `zn`。
3. 商业旅馆因利润接待：`n` 可成立，但不是由 `zn` 生成。
4. 领袖命令成员收留：优先检查 `zx/nx`。
5. 政府按预算和工程流程建设：优先检查 `xn/x/zx`。

## 最近邻排除

- `zn 生 zx`：改变公开推进与现实权能；本关系改变对象是否进入并留在内部。
- `n 生 xn`：既有承载因重复负荷提炼组织；本关系发生在承载入口。
- `zn 补 x`：为已有掌握边界提供意义方向；本关系直接改变准入与留存。
- `n 生 zn`：长期被接住后沉淀不能放弃的意义，方向相反。

## 拿掉测试

1. 拿掉 `zn`，若仍因商业、法律、亲属或职位义务接收，不成立。
2. 拿掉第二阶段留存，只剩首次接纳，不足以判完整 `n`。
3. 拿掉成熟流程，对象仍留存且负荷被持续处理，关系仍可成立。
4. 拿掉房产、资金与正式权限，主体仍以生活与风险承担接住对象，纯度上升。
5. 拿掉领袖命令与公开推动，主体仍撤回推出资格，支持直接机制。
6. 替换建筑，只要准入、留存和处理关系保持，`n` 仍成立。

## 反向测试

```text
zn 生 n：不能抛下的意义先成立 → 对象进入并被持续承担。
n 生 zn：对象先长期被接住 → 共同时间与负荷沉淀为不能放弃的意义。
```

两方向可反馈，但不能互相代证。

## 动态链后果

```text
这件事不能被丢下
→ 它获得进入资格
→ 下一阶段仍留在内部
→ 我持续承担它带来的负荷
→ 承载从一次接纳变成可持续内部位置
```

改变的是意义如何打开承载入口，并把入口转成跨时间持续的内部位置。不机械生成建筑、组织、制度、资源成功或永久稳定。
