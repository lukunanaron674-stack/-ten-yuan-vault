### 对象分层

- 稳定本体：`nx` 是主体长期不占方向决定位置，沿他者、关系、流程或现状给出的方向推进；`x` 是对象、资源、地盘、权限或关系被划入“归我掌握”的边界。同一人物顺从与掌握共存不能自动证明生成。
- 当前状态：甲在某段关系中持续让出决定位置；乙可能逐步成为事实决定者。当前只支持关系层与状态层候选。
- 行为功能：甲显影为不提替代方案、不使用否决权、默认乙安排；乙显影为决定、调配、代表、排他使用与最终否决。行为先后仍不足。
- 光影：侧位、跟随、背后站立、中心位置、钥匙与控制台只作辅助显影。
- 场景：家庭、公司、亲密关系、照护、代理、团队均只是候选场景。
- 时间关系：甲持续让位在先，乙事实掌握范围扩大在后；一次委托或短期代办不足。
- 关系位置：源端点与目标端点大概率分属不同主体，必须明确甲让出什么方向，乙新增掌握什么对象或边界。
- 显影：观察乙是否新增事实否决权、排他使用权、调配权、代表权或对关系退出/回返的控制，而不是只多做事情。
- 动态链：从“甲仍可决定但不断默认乙处理”转成“乙的决定逐渐被当成默认有效，甲若想改回必须额外争取”。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `nx`：甲原本拥有真实可拒绝、可另选或可取回的方向位置，却持续不提出自己的安排、不使用否决权，并沿乙给出的方向推进。被暴力强迫、法律剥夺、职位服从或一次委托均不足。
- 目标端点 `x`：乙此前没有稳定掌握该对象或关系边界，随后新增事实上的最终决定、调配、排他使用、代表或否决能力。只是承担更多劳动、提供建议或临时代办不够。
- 被改变变量：乙的事实决定覆盖范围；甲取回决定权所需成本；对象默认归谁调配；他人是否把乙视为最终接口；甲的否决是否从常态权利变成需要解释的例外。
- 成立阶段：甲仍有可选方向 → 长期默认乙决定或使用 → 乙的决定反复被执行且不被撤回 → 周围关系开始把乙视为默认接口 → 乙新增事实掌握边界。
- 体量：低体量为某项日常安排形成默认控制；中体量为一段关系中的资源、时间或对外口径由乙事实掌握；高体量为稳定人物关系结构改变。当前只能支持低至中体量候选。
- 显影条件：拿掉正式授权、资源转让、职位、强制和乙主动夺取后，掌握边界仍因甲持续让位而扩张。

### 候选机制

- A 默认决定累积：甲每轮都不使用自己的方向权 → 乙的决定持续落地且不被撤回 → “乙可以决定”由临时代办变成默认关系事实 → 乙的事实否决与调配边界扩大。理论后果：若成立，`nx 生 x` 是跨主体关系生成，不是顺从者自身长出掌握欲。
- B 接口垄断形成：甲持续不直接面对对象、成员或外部关系，而让乙代为处理 → 信息、口径和资源入口逐渐集中到乙 → 他人只能通过乙完成互动 → 乙获得事实掌握接口。理论后果：必须排除乙主动截断信息、职位规定与资源本来就在乙手中。
- C 竞争解释：乙主动占位、持续施压或凭职位/资源扩张 → 甲被动退后。此时启动源优先是 `x/zx/xn`，甲的 `nx` 只是结果或共现，不能倒写为生位。

### 正例候选

1. 家庭财务代管结构：成年甲仍有独立决定能力，却长期把账单、账户安排和大额消费判断交给伴侣乙；没有正式财产转让。几年后家庭成员默认只有乙能调配资金，甲若要改变安排必须先获得乙同意。支持 A/B，但现实案例常混入收入来源、账户密码与明确授权，纯度不足。
2. 创作团队对外口径结构：主创甲拥有最终表达权，却长期不参与对外沟通，默认制片乙决定发布时间、合作对象与公开表述。久而久之合作方只认乙为最终接口，甲的修改变成例外。支持接口垄断候选，但混入职位、信息集中与合同权限。
3. 《魅影缝匠》中雷诺兹与西里尔的工作关系候选：雷诺兹在生活与工作运行上长期依赖西里尔处理客户、日程和边界，西里尔形成强事实掌握。限制：西里尔原本已有管理位置与稳定 `x/xn`，不能证明由雷诺兹的 `nx` 新生成。

### 反例

1. 老板正式授权经理全权负责项目：权限授予直接生成或扩大 `x`，不是 `nx`。
2. 强势伴侣通过威胁、监控和资源控制接管生活：启动源是 `x/zx`，让位是结果。
3. 员工一次请同事代班：短期委托，没有跨轮次事实掌握。
4. 家长因孩子年幼代为决定：年龄、照护责任与法律位置混杂。
5. 代理人本来持有账户、钥匙和签字权：目标 `x` 已存在，只是显影。
6. 主体因能力不足只能听专业意见：现实能力差与知识依赖，不等于自愿 `nx`。
7. 乙做了更多杂务但不能否决、代表或排他使用：劳动增加，不是掌握边界扩大。
8. 甲仍随时无成本撤回安排且他人始终认甲为最终接口：没有 `x` 生成。

### 最近邻

- 与 `x 生 nx`：若乙先以掌握边界压缩甲的方向，方向应写为 `x → nx`；本轮要求甲的让位在先，乙的掌握在后。
- 与 `z 克 nx`：旧占位口径更接近主动主体持续决定并压退对方；本轮候选要求乙没有主动加压，甲的持续默认才是必要条件。
- 与 `zx`：公开命令、夺位、凌驾与迫使他者围绕自己行动是显权，不是被动累积的事实掌握。
- 与正式授权：授权改变法定或明确权限；本候选改变的是未明说但被反复承认的事实边界。

### 拿掉测试

1. 拿掉甲的持续让位，乙仍凭职位、资源或强制掌握，则不依赖 `nx 生 x`。
2. 拿掉乙主动占位和施压，乙的事实掌握仍因甲每轮默认而扩大，才支持候选。
3. 拿掉正式授权、账户交付、合同与资源转让后，若掌握边界消失，启动源是权限配置。
4. 拿掉周围人的默认承认，只剩乙多做事情，`x` 目标不足。
5. 甲若能随时无成本取回决定且乙不能否决，不构成稳定事实掌握。
6. 当前三个候选均未通过全部排除测试。

### 反向测试

```text
nx 生 x：甲持续不占方向位置 → 乙的默认决定反复落地 → 乙事实掌握边界扩大。
x 生 nx：乙先拥有资源、权限或关系控制 → 甲可选方向被压缩 → 甲沿乙给出的方向推进。
```

两方向可形成反馈，但不能因最后出现“乙掌握、甲跟随”就互相代证。必须核对先出现的是甲的自愿持续让位，还是乙的掌握与压缩。

### 动态链后果

```text
起初：这次先按你的办法
→ 反复：以后也默认你来决定
→ 关系变化：别人开始只找你，决定不再需要再次确认
→ 结果：原本临时的代办变成事实掌握边界
```

改变的是关系中“谁的决定默认有效、谁必须额外争取才能改回”的方向与掌握成本，不是顺从自动制造占有欲、能力或权力人格。
