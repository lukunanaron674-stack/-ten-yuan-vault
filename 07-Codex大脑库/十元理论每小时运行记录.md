### 源端点、目标端点与变量

源端点 `xz`：危险已经真实逼近，安全路线、退路或时间窗缩窄，并使原有指挥、规则或等级失去有效反应资格。拿掉危险或恢复旧中心后，本阶段不会产生新的公开决定接口。

目标端点 `zx`：主体此前没有正式最终决定职位或稳定追随关系；随后连续作出至少两项不同层面的最终决定，他者实际执行并停止等待旧中心重新确认。

被改变变量：现场最终方向决定权、决定默认有效性、他者执行关系、旧中心决定资格、主体是否成为新的公开现实接口。

成立阶段与体量：

```text
低体量：局部逃生关系中临时取得最终接口。
中体量：团队停止等待旧中心并连续执行主体决定。
高体量：危机使旧等级失效，主体成为新的临时权力中心。
```

危机结束后位置立即归零时，只判状态层或关系位置层，不反推稳定本体。

### 候选机制

#### 候选 A：危险迫使已有能力公开显影

```text
危险封死隐藏、等待和延后空间
→ 人物已有能力进入公共现实
→ 决定范围扩大
```

理论后果：解释显影时点，但不证明能力由危险生成。

#### 候选 B：决定空位生成公开接口

```text
危险使旧决定中心失效
→ 现场出现最终决定空位
→ 此前无正式接口的主体连续作出决定
→ 他者执行并停止等待旧中心
→ 状态层 / 关系位置层 zx 新增
```

理论后果：生成的是公开关系位置，不是能力、勇气或领导人格。

#### 候选 C：一次反击、逃生或建议冒充权能

排除。没有连续决定、他者执行与旧中心退位。

### 正例

1. 《海神号遇险记》弗兰克·斯科特：巨浪使船长与船方上层死亡，原秩序无法继续决定。斯科特此前无船上正式指挥职位，却连续决定离开宴会厅、向船底移动、选择通风井与机舱路线，并在多次路线争议和人员伤亡后继续重定行动；幸存者实际跟随并停止等待船方指挥。
2. 《人狼大战》约翰·奥特维：坠机与狼群威胁使机组、公司和日常等级失效。奥特维此前是猎狼人员而非队伍负责人，却连续决定生火与守夜、离开坠机点、制作武器和选择路线；迪亚兹虽质疑其领导，群体仍围绕其判断行动。
3. 《海神号遇险记》罗戈后续接管：斯科特死亡后决定中心再次空出，罗戈从质疑者转为接管剩余队伍并带领其抵达救援点，辅助证明临时接口可在危机中再次生成。

### 反例

1. 火灾中跟随消防员逃生：主体没有取得决定权，主要是 `nx`。
2. 被追杀者击倒敌人继续逃跑：只是 `xz` 临界反击。
3. 团队按既定预案撤离：主要是 `xn` 运行。
4. 军官按职位下令：最终接口此前已经存在。
5. 因“必须救人”公开领导：优先检查 `zn 生 zx`。
6. 一次建议被采纳：没有连续决定与默认接口。
7. 群众因恐惧暂时服从强者：只证明服从结果。
8. 夺权后遭到追杀：方向更接近 `zx 生 xz`。

### 最近邻排除

- 与潜在 `zx` 显影：能力前置不等于决定位置前置；本轮只锁定公开位置新增。
- 与 `zn 生 zx`：后者由意义先规定“必须做”；本轮由危险先使旧中心失效。
- 与 `xn`：预案、排程和分工不等于最终接口转移。
- 与 `x`：掌握武器、资源或职位不等于公开显权。
- 与普通 `xz` 行动：冒险、逃跑和反击必须另证他者执行与旧中心退位。

### 拿掉测试

1. 拿掉危险，主体在同阶段是否仍获得公开最终接口？
2. 恢复旧中心有效指挥后，群体是否仍持续执行主体决定？
3. 拿掉第二项决定、他者执行和旧中心退位，只剩一次正确行动时，目标是否消失？
4. 拿掉正式职位、预案和上级授权后，决定位置是否仍形成？
5. 危机结束后位置若立即归零，是否明确只判状态层？
6. 已有专长是否只作能力条件，与公开决定资格分开记录？

《海神号遇险记》和《人狼大战》均通过“危险前无正式接口、旧中心失效、连续决定被执行”的窄门槛；两例均有既有能力，但没有既有公共最终决定位置。

### 反向测试

```text
xz 生 zx：危险先使旧中心失效 → 主体获得新的公开决定位置。
zx 生 xz：主体先公开扩权或夺位 → 旧秩序反扑并制造危险。
```

两方向不能因为最后都出现领导与危险而互相代证。

### 动态链后果

```text
旧中心仍有效，我只是其中一员
→ 危险使旧中心无法继续决定
→ 现场出现最终决定空位
→ 我连续作出决定
→ 他者开始执行并停止等待旧中心
→ 我成为当前阶段的公开最终接口
```

改变的是现实决定中心的位置与默认有效性，不生成能力、领导人格、胜利或永久权力。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验危险是否使旧中心失效、主体是否首次获得公开最终接口，以及他者是否实际执行。不能从灾难题材、英雄构图或作品结局反推关系成立。

通过，96%。理由：

- 主体均连续作出多项决定并被他者执行；
- 反例能够排除职位下令、预案执行、普通反击和意义推动；
- 机制严格限制在状态层或关系位置层，不夸大为稳定本体生成；
- 三元与十元没有建立父子派生。
