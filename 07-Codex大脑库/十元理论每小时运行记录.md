### 对象分层

- 稳定本体：`xz` 是长期危险逼近、退路缩窄与无法停留；`zx` 是长期依靠公开显权、扩权和凌驾成立。一次危机接管不能反推稳定本体。
- 当前状态：危险正在关闭安全路线；主体此刻成为公开最终决定接口。本轮最可能成立在状态层。
- 行为功能：逃生、战斗、抢窗口属于 `xz` 行为；连续指挥、重定路线、让他者执行并使旧中心退位才触及 `zx`。
- 光影：警报、倒计时、中心构图、众人转向只作显影。
- 场景：灾难、追杀、战争、车厢、洞穴和控制室不能替代端点。
- 时间关系：危险先出现，旧中心失效，主体连续决定，决定被执行。先后仍不足，必须证明位置变化。
- 关系位置：源端是被局面规定者；目标端是新的公开最终接口。能力可以前置，决定位置必须后新增。
- 显影：谁的决定默认有效，谁需要重新确认，谁的路线被群体实际执行。
- 动态链：世界逼迫行动 → 旧中心失效 → 决定空位出现 → 新接口形成；不机械生成胜利、勇气或领导人格。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `xz`：危险以可感知形态逼近，安全路线、退路或时间窗真实缩窄，不行动会被吞没，且危险直接改变可用选择。
- 目标端点 `zx`：主体此前没有公开最终接口；随后连续作出至少两项涉及不同变量的最终决定；他者实际执行；旧指挥、规则或等级的决定资格下降；主体成为新的现实接口。
- 被改变变量：公开最终决定权、决定默认有效性、他者执行度、旧中心失效率、主体决定范围、危机后位置持续时间。
- 成立阶段：危险显形 → 旧中心失效 → 主体第一次公开决定 → 第二项不同变量的决定继续被执行 → 默认接口转移。
- 体量：低体量为局部小组临时接口；中体量为团队路线和资源同时被重定；高体量为旧等级整体失效并形成新权力中心。
- 显影条件：拿掉危险或恢复旧中心后，同阶段不会形成该位置；拿掉他者执行和旧中心退位后，案例只剩个人行动。

### 候选机制

#### A｜退路剥夺迫使潜在能力公开

```text
危险封死隐藏、等待与延后空间
→ 人物已有能力不得不公开进入现实
→ 决定范围扩大
```

理论后果：解释 `zx` 显影时点，不证明能力由 `xz` 生成。

#### B｜旧中心失效生成公开决定位置

```text
危险使原指挥、规则或等级失去反应资格
→ 现场出现最终决定空位
→ 此前无公开最终接口的主体连续作出决定
→ 他者执行并停止等待旧中心
→ 状态层／关系位置层 zx 新增
```

理论后果：生位落在关系位置，不落在能力、人格或稳定本体。

#### C｜一次行动冒充权能

```text
危险出现
→ 人物冲锋、救人、逃跑或说对一次
```

排除：没有连续决定、他者执行和默认接口转移。

### 正例候选

1. **《迷雾》卡莫迪夫人，超市秩序崩解后**：危险持续逼近，原有法律与理性协商失去中心，她从无正式职位者变成能够公开解释危险、提出处置并让群体执行的临时决定中心。支持关系位置生成。限制是宗教身份壳、群体恐惧、话语说服与主动煽动很强，目标可能混入 `x并z/z/zx` 自身扩张。
2. **《绝境盟约／Society of the Snow》南多·帕拉多与罗伯托·卡内萨，雪崩后至翻越安第斯阶段**：原队长与原等待救援路线失效后，两人推动远征方向、装备准备和出发节点，群体转而围绕该路线行动。支持旧中心失效后新接口形成。限制是求生专长、长期协作、群体共识与 `xn` 准备结构明显。
3. **《疯狂的麦克斯：狂暴之路》弗瑞奥萨，绿洲失效后反攻阶段**：她连续重定路线、组织反攻并让队伍执行，目标端点强。限制是既有战斗能力、团队信用和潜在领导位置过强，更像潜在 `zx` 高显影。
4. **《釜山行》尚华，车厢突破阶段**：感染危险使局部秩序失效，他成为突破节奏的公开接口。限制是体能与保护家人的 `zn` 强，且位置短暂。

### 反例

1. 火灾中跟随消防员逃生：主要是 `nx`，主体未取得决定位置。
2. 被追杀者击倒敌人继续逃跑：只是 `xz` 临界反击。
3. 团队按预案撤离：主要是既有 `xn` 运作。
4. 军官按职位下令：公开接口原本存在，危险只提供显影机会。
5. 因“必须救人”而公开领导：优先检查 `zn 生 zx`。
6. 一次建议被采纳：没有连续决定和默认接口转移。
7. 群众因恐惧暂时听从最强者，但下一决定仍等待旧中心：服从结果不足。
8. 夺权后才遭追杀：方向更接近 `zx` 引发 `xz`。

### 最近邻排除

- 与潜在 `zx` 显影：能力前置不等于决定位置前置。必须问危险前谁拥有公开最终接口。
- 与 `zn 生 zx`：前者由危险使旧中心失效；后者由内部意义先规定必须公开行动。
- 与 `xn`：预案、分工、资源准备可以支持行动，但不等于谁成为最终接口。
- 与 `x`：掌握武器、资源或职位不等于公开显权；本轮看他者是否开始围绕主体决定行动。
- 与普通 `xz` 行动：冒险和抢窗口属于 `xz` 自身；只有位置重排才进入目标端。

### 拿掉测试

1. 拿掉危险，主体是否仍会在同阶段获得公开最终接口？若会，不依赖本关系。
2. 恢复旧中心有效指挥后，群体是否仍持续执行主体决定？若不会，支持决定空位机制。
3. 拿掉人物既有专长，若位置无法形成，只能说明能力是必要条件；不能因此自动否定关系位置由危险生成。
4. 拿掉他者执行、旧中心退位和第二项决定，只剩一次正确行动，目标端点消失。
5. 拿掉 `zn` 的救人意义、`xn` 的预案和职位授权后，是否仍因决定空位形成临时公开接口？
6. 危机结束后位置立即归零，只能判状态层；若跨场景持续，才可提高体量。

现有候选仍未同时通过全部测试。

### 反向测试

```text
xz 生 zx：
危险先使旧中心失效
→ 主体随后获得新的公开决定位置

zx 生 xz：
主体先公开扩权、夺位或凌驾
→ 旧秩序反扑并制造追捕、封锁与危险
```

“危机中站出来”和“夺权后遭追杀”不能互相代证。

### 动态链后果

```text
旧中心仍有效，我只是其中一员
→ 危险让旧中心无法继续决定
→ 我连续作出不同层面的最终决定
→ 他者不再等待旧中心，而开始执行我的决定
→ 现实默认接口暂时转移
```

改变的是：**谁是现场公开最终决定接口，以及谁的决定无需重新确认。**

不机械生成能力、领导人格、正义性、胜利或永久权力。

### 95%门槛

高置信结论：

- 危险不能凭空生成专业能力、领导人格或稳定 `zx` 本体：99%。
- 能力前置与公开决定位置前置必须分开：98%。
- 既有专长不自动否定状态层／关系位置层生位：97%。
- 一次说对、冲锋、救人或被听从不足；至少连续两项最终决定被执行：98%。
- 危机后位置立即归零，只能判状态层，不得反推稳定本体：99%。
- 目标变量必须落在公开决定资格、默认有效性、他者执行与旧中心退位：99%。

未达到95%的核心：

- 缺少两个同时满足全部门槛的高纯具体人物案例；
- 《迷雾》混入宗教壳、说服与群体恐惧；《绝境盟约》混入 `xn`、求生专长与群体共识；
- 尚不能确认“危险制造决定空位”是否足以称为直接生位，还是 `xz` 只提供机会、人物主动行动才完成 `zx`；
- 用户仍有超过5%概率拒绝把关系位置新增视为 `zx` 生位。
