## 源端点、目标端点与变量

### 源端点 `nx`

必须同时满足：

- 主体真实拥有可认领、可取回的决定位置；
- 主体并非法律上无权、能力上不能或被主动强迫；
- 主体跨多个事项持续不认领方向、否决与安排位置；
- 这是一种稳定关系功能，不是一次授权、分工或临时代办。

### 目标端点 `x`

必须出现具体掌握边界净增长：

- 新增调配权；
- 新增最终否决权；
- 新增调用与对外代表权；
- 原本共同或模糊的对象、资源、时间、权限或关系范围稳定纳入“归我掌握”；
- 在 nx 主体恢复参与或第三方接口复位后仍有部分事实掌握保留。

## 候选机制

### 候选 A：空位吸纳

```text
nx 主体持续不认领本可拥有的决定位置
→ 关系中形成反复出现的方向空位
→ 已有局部 x 的主体为维持行动而持续代理
→ 临时代办逐步被第三方与双方默认
→ 调配、否决、调用与代表边界扩大
```

理论后果：若成立，`nx` 不直接赠予资源，而是让反复代理负荷沉淀进他者既有掌握边界；只先锁关系层，不改写稳定本体。

### 候选 B：默认授权累积

```text
每次事项都默认由同一主体处理
→ 信息、请求与对外接口集中
→ 外部成员只向该主体请求决定
→ 代理权变成事实上的长期掌握
```

理论后果：若事实控制只来自信息集中、熟练度、账户权限或流程惯性，应判 `xn/x` 第三因素，不判 `nx 生 x`。

### 竞争解释 C：主动占位或职位赋权

```text
x/zx 主体主动要求、施压或凭职位接管
→ nx 主体退让
→ x 同时扩大
```

该结构的直接启动源是 `x/zx/xn`，不是 `nx`。若所有有效案例都依赖此结构，则 `nx 生 x` 只保留几何位。

## 正例候选

1. 《穿普拉达的女王》安迪与米兰达，中段工作关系：安迪逐步放弃私人时间、任务顺序和拒绝边界，米兰达控制范围扩展到全天候时间与私人生活。限制：米兰达主动要求、职位权限与行业制度过强，不能作为纯例。
2. 《长日将尽》史蒂文斯与达林顿勋爵，长期管家阶段：史蒂文斯不把私人判断、情感和人生方向置于最终位置，主人意志进入其私人范围。限制：职业义务、阶级制度和庄园组织是强第三因素。
3. 家庭长期代决结构：成年子女具备法律权利和现实取回能力，却长期不查看账户、不联系机构、不提出居住或职业选择，父母由建议者逐步成为账户、材料、日程和对外沟通的唯一接口。结构纯度最高，但缺具体可核验人物文本。

## 反例

1. 一次委托出差期间由同事代管项目：只是临时代办，原决定者随时可恢复。
2. 老板凭职位和制度直接扩大权限，员工只能服从：x 来源是职位与 `zx/xn`，不是 nx。
3. 一方因掌握密码、账户和关键资料而不可替代：主要是信息或接口 x，不能反推由 nx 生成。
4. 家庭中父母帮助办理手续，但成年子女仍保留最终否决与随时取回权：工作量上升不等于掌握边界上升。
5. 第三方因沟通方便只联系一个人：可能只是习惯和流程集中，未必形成事实归属与否决权。
6. nx 主体能力不足、失能或根本没有合法资格：目标位置从未可供其认领，不构成主动空位。

## 最近邻排除

- `x/zx` 主动接管：若掌握者通过要求、威胁、资源门控或公开权能扩大边界，启动源不是 nx。
- `xn` 流程集中：若变化主要是效率、信息流和工作顺序集中，而归属与最终否决未变，只是组织结构。
- 职位、合同、产权与法律授权：这些直接规定谁掌握，不由 nx 生成。
- 熟练度与信息集中：不可替代性可能来自会做、知道或掌握密码，不等于归我掌握。
- 第三方习惯：别人只找某人可能只是方便，必须观察双方是否承认其最终否决与代表边界。

## 拿掉测试

1. 拿掉 nx 主体持续不认领方向，只保留职位、账户、合同和制度，若 x 仍扩大，案例不依赖 `nx 生 x`。
2. 拿掉 x 主体主动要求与施压，若掌握边界仍因反复代理而扩大，才支持独立生位。
3. 拿掉信息优势与熟练度，换成同等能力代理者，若原 x 主体仍保留新增否决与调用边界，才接近事实掌握。
4. 代理负荷撤回测试：nx 主体恢复参与后，若 x 主体新增边界立即消失，之前只是临时代办；若仍需其批准、调用或代表，才支持沉淀。
5. 第三方接口复位测试：机构重新同时接受双方指令后，若 x 主体仍保留新增控制边界，第三方习惯不是唯一来源。

## 反向测试

交换为 `x 生 nx`：控制边界扩大可能迫使他人跟随，但这属于 x 对方向空间的压缩，不能反证 `nx 生 x`。真正反向测试应观察：当 nx 主体明确取回决定位置时，x 主体是否仅因既有事实掌握而产生抵抗；若抵抗只来自合同、账户、流程或信息成本，则原关系仍未证明。

## 动态链后果

```text
一个人持续不把自己放进最终决定位置
→ 代理负荷反复落到另一人
→ 对方从“替你处理”逐步变成“默认由我调配与否决”
```

改变的是关系里的掌握边界与方向位置分配，不是 nx 自动制造控制欲、支配人格或权力本体。
