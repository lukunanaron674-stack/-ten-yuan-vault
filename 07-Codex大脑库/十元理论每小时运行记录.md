## 本轮性质

本轮只审计 `nx 生 x`。没有新建专项，没有修改核心表、关系词典或待确认队列。新增的是“取回抵抗分层”：把正当性摩擦与事实控制抵抗分开，并将最新缺口原位回写必读中枢。

## 对象分层

| 层级 | `nx` 源端点 | `x` 目标端点 | 本轮判定 |
|---|---|---|---|
| 稳定本体 | 长期不占方向决定位置 | 长期掌握具体边界 | 一次代办或让位不能反推本体 |

| 光影 | 退后、等待、站侧位 | 钥匙、账本、中心座位 | 只作显影 |
| 场景 | 家庭、公司、伴侣、代理关系 | 账户、合同、资源、对外口径 | 场景不能替代端点 |

## 源端点、目标端点、变量、阶段与体量

源端点 `nx`：甲原本拥有真实可行路线、否决权、取回决定的能力和承担结果的资格，却跨轮次持续不提出路线、不使用否决、默认乙处理，并停止直接面对成员、资源或外部接口。

目标端点 `x`：乙此前没有稳定掌握，随后新增最终调配、事实否决、排除替代方案、对外代表或排他控制；甲明确取回时不能立即恢复直接决定。

被改变变量：决定默认有效性、实际否决能力、替代接口可进入性、对外代表资格、原权利主体取回的事实可行性。

成立阶段：优先落在具体关系或组织阶段；稳定本体层未证实。

体量：低体量为一次临时代办；中体量为跨阶段默认代理；高体量只有出现事实拒绝、排他或持续代表才候选 `x`。

显影条件：甲必须明确取回，而不是只表达不满；随后观察乙或第三方能否实际阻止，而非仅要求重新通知、解释、礼貌协商或完成流程。

## 候选机制与理论后果

### 候选 A：默认决定经第三方固化

```text
甲持续不用方向权
→ 乙的决定反复落地
→ 第三方逐渐只向乙请求决定
→ 甲明确取回
→ 第三方仍拒绝绕过乙
```

理论后果：第三方固化是必要第二入口。若甲出现后第三方立即重新承认甲，只是默认代理。

### 候选 B：接口集中形成事实排他

```text
甲长期不接触成员、资源与外部关系
→ 信息、材料与口径集中到乙
→ 乙能够排除甲的直接接触或否决替代路线
```

理论后果：若排他来自信息截断、账户、合同、职位或流程，直接作用源属于 `x/xn`，不能归给纯 `nx`。

### 候选 C：乙主动接管

```text
甲持续让位
→ 乙主动控制信息、排除替代路线并阻止甲取回
→ 掌握形成
```

理论后果：`nx` 只是允许条件，乙的主动 `x/zx/xn` 才是直接生成源。

### 候选 D：默认代理

```text
甲长期不决定
→ 乙成为常用接口
→ 甲明确取回
→ 乙立即归还
```

这里只成立代理、分工或 `xn` 接口，不成立 `x`。

### 本轮新增分层：正当性摩擦与事实控制抵抗

```text
正当性摩擦：
甲取回后需要重新通知、解释、礼貌协商或修正第三方习惯
→ 没有实际拒绝与排他
→ 不构成 x

事实控制抵抗：
甲取回后，乙或第三方仍能拒绝、排除或持续代表
→ 继续追查抵抗能力来自何处
→ 若依赖第二入口，不能归为纯 nx 生 x
```

## 正例候选

1. **家庭财务长期代管**：成年主体长期让伴侣或父母处理账户、住房和对外联系。若取回后银行、房东或家人仍只承认代管者，目标端点候选成立；但抵抗通常来自密码、账户、材料或授权，属于第二入口。
2. **创作团队对外接口**：主创长期不接触合作方，制片成为发布时间、合作与公开口径的唯一接口。若主创取回时合作方仍拒绝绕过制片，通常来自职位、合同、行业流程与信息集中。
3. **《魅影缝匠》雷诺兹与西里尔**：西里尔拥有强事实掌握，但她原本就具备管理位置和 `x/xn`，无法证明目标从无到有。
4. **《穿普拉达的女王》安迪与米兰达**：安迪持续放弃边界，米兰达控制扩大；米兰达既有职位与主动压迫才是明显启动源。

现有候选均不能同时证明：`x` 从无到有，且事实取回抵抗不依赖第二入口。

## 反例

1. 一次代班、代购、代签或临时委托。
2. 伴侣负责财务，但双方随时查账、共同否决，甲取回时立即恢复直接决定。
3. 大家习惯找乙，甲出现后只需重新通知便重新承认甲。
4. 甲取回时只需解释、礼貌协商或完成普通流程。
5. 正式授予预算、账户、签字权、合同权限或职位。
6. 乙靠扣留密码、材料、监控、威胁或信息截断阻止甲。
7. 乙承担更多劳动，却不能事实否决或代表。
8. 甲原本没有合法或现实决定资格，不存在可由 `nx` 空出的源端点。

## 最近邻排除

- `x 生 nx`：乙先有掌握，甲方向空间随后被压缩。
- `xn`：默认联系人、流程负责人和信息汇总者若不能抵抗取回，只是组织接口。
- `zx`：公开夺权、威胁、压退或阻止甲取回属于主动显权。
- 正式授权：直接改变现实权限，不是空位自然生成。
- 普通依赖：更信任、更常找乙，不等于乙拥有否决、排他与持续代表。

## 拿掉测试

1. 拿掉甲持续让位，乙若仍凭职位、产权、账户或合同掌握，不依赖本关系。
2. 拿掉乙主动阻止、信息截断和第三方制度化，乙还能否抵抗甲取回？
3. 拿掉授权、密码、材料、钥匙、合同和账户，掌握是否消失？
4. 拿掉第三方习惯，只看乙能否直接事实否决甲。
5. 甲明确取回：乙立即归还则不成立；乙能够拒绝则继续追查拒绝能力来源。
6. 只有重新通知、解释、协商、礼貌成本或认知滞后，没有事实拒绝、排除或持续代表，不足以判 `x`。
7. 若所有事实抵抗均依赖第二入口，则 `nx` 只能记为空位与允许条件。

## 反向测试

```text
nx 生 x 候选：
甲持续空出方向位置
→ 乙的默认决定被反复承认
→ 甲取回时乙仍能维持掌握

x 生 nx：
乙先拥有掌握边界
→ 甲可用方向被压缩
→ 甲沿乙方向推进
```

最终画面都可能是“乙决定、甲跟随”，但阶段顺序与直接作用源不同，不能互相代证。

## 动态链后果

```text
这次先按你的办法
→ 以后也默认你决定
→ 别人开始只找你
→ 我以为自己随时能够取回
→ 真正取回时先区分：只是需要重新说明，还是你能事实拒绝我
→ 再判断事实抵抗来自空位，还是职位、授权、信息与制度
```

改变的是谁的决定默认有效、谁能排除替代方案、谁能持续代表，以及原权利主体能否真实取回。不机械生成管理能力、权力人格、法定权限或永久控制。

## 三元与十元并行核验

三元继续判断作品整体精神运动。十元本轮只核验方向位置、默认代理、事实掌握和取回抵抗；不把三元当作十元的父级生成器，也不从权力题材反推关系成立。
