## 源端点、目标端点与变量

### 源端点 `nx`

必须同时满足：

- 主体已有由关系、流程、他者或现状提供的外部方向；
- 主体没有主动建立反向路线，也没有公开拆壳；
- 主体原本具备自由复述、履行、签名或允许署名的接口；
- 本周期持续不占认领位置，而不是无机会、不可用、偶然缺席或被禁止；
- 行为不能主要由 `zn` 原则拒绝、`zx` 对抗、`x` 退出或 `xn` 程序撤销驱动。

### 目标端点 `x并z`

必须先分型：

1. 存量身份壳：前期已成立，且无需主体持续背书即可继续存在；
2. 行政归类壳：由法律、登记、第三方数据库或自动规则维持；
3. 职责履行壳：需持续执行岗位行为才能保持可调用性；
4. 共识背书壳：需成员周期复述、签名或允许代表才能维持覆盖；
5. 周期续期壳：每一周期都必须重新完成主体接口。

本轮只保留第4、5类为候选。

### 被改变变量

- 壳对特定主体的下一周期吸纳率；
- 主体名字、行为与立场能否继续被壳代表；
- “全体／我们”覆盖范围；
- 角色可调用性与职责解释力；
- 补做接口后续期能否恢复；
- 旧周期存量是否仍在；
- 目标变化来自主体不认领，还是外部撤销或自动到期。

## 候选机制

### 候选 A：周期认领接口缺失

```text
前一周期 x并z 已真实覆盖主体
→ 本周期壳必须由主体自由复述、履行或允许署名才能续期
→ nx 主体没有另立反向路线，但持续不占认领接口
→ 下一周期覆盖未再生成
→ 壳对该主体的可调用与解释范围下降
```

理论后果：最强结论是“续期失败”，不能直接写成既存壳被摧毁。

### 候选 B：共同背书覆盖缩小

```text
共同壳依赖关键成员形成“我们都这样”的现实
→ nx 成员不反对，也不完成本周期背书
→ 壳只能从“全体”退为“部分”
→ 群体覆盖体量下降
```

理论后果：A 是个体接口层，B 是群体覆盖层，可能是同一候选机制的不同体量。

### 竞争解释 C：既存壳自然到期或外部撤销

```text
合同到期／登记变更／岗位终止／第三方删除
→ 壳失效
```

若拿掉主体不认领后结果仍会发生，则不属于 `nx 克 x并z`。

### 竞争解释 D：主动价值拒绝或退出

```text
主体判断“这个身份不应继续”
→ 主动辞职、揭露、公开拒签或撤回维护
→ 壳覆盖下降
```

启动源优先检查 `zn/zx/x/xn`，不是纯 `nx`。

## 正例候选

1. 组织年度共同声明中的成员乙：上一年度已签署并被列入“全体支持”；本年度组织仍要求每名成员自由签字，乙没有公开反对、没有发表替代立场，只是不签字且不允许名字被代录，声明因此只能写“多数成员”。该结构最接近候选B，但仍是结构例，缺具体人物文本。
2. 周期性公开代言或会员身份：某成员上一周期真实履行并被公开代表，本周期仍沿组织安排工作，却不再提供必须的肖像授权、口头确认或角色履行；组织不能在下一周期继续把其作为公开成员调用。限制：现实案例常混入合同、版权、辞职和法律接口。
3. 《千与千寻》千寻—“小千”身份：行动进入油屋流程，却未完整认领“小千”为全部身份。限制：真名记忆与 `zn`、白龙帮助、汤婆婆权能和后期主动选择共同作用，不能纯化。
4. 《黑客帝国》尼奥—“托马斯·安德森”员工壳：停止履行后公司壳无法继续覆盖。限制：主动选择、逃离、追捕、离职事实和外部证据污染严重。

## 反例

1. 行政系统仍登记某人为员工，即使本人沉默：第三方登记壳未下降。
2. 成员没被要求签字或履行：没有可选择接口，沉默无因果意义。
3. 下属因恐惧继续签署：`nx` 可能上升，但 `x并z` 反而续期成功。
4. 主体公开宣布辞职：优先是主动退出或 `zn/x/zx`，不是 nx。
5. 记者揭露组织造假：搜证与公开行动，优先检查 `xn/zn/zx`。
6. 合同自动到期：自动规则造成，不是主体不认领。
7. 主体因生病不能履行：不可用与无机会，不是 nx。
8. 壳无需主体持续背书即可长期存在：不认领不改变目标变量。

## 最近邻排除

- `zn 克 xn`：主体因不可让渡意义撤回结构应被维护的资格；有明确价值判断和主动撤回。
- `x 克 x并z`：掌握名称、职位、资源、登记或合法接口并撤销壳。
- `zx 克 x并z`：公开权能直接拆壳、强迫揭露或取消身份。
- `xn` 自动续期／撤销：流程与规则直接决定壳是否继续。
- `x并z 克 nx`：身份壳预设主体路线，使其更沿角色推进，方向相反。
- 普通不履职：工作量下降不等于公开壳覆盖下降。

## 拿掉测试

1. 到期归因测试：壳若无论主体是否认领都会到期，则不依赖 nx。
2. 反事实续生测试：主体若完成复述、履行或允许署名，壳是否立即续期；若不能，缺口在别处。
3. 可观察性—源动作测试：第三方是否能观察到主体有接口却持续不完成，而非系统根本没给机会。
4. 存量壳—续期壳测试：旧周期壳是否仍成立；若只是下一周期没生成，不得写成既存壳整体被克。
5. 补做恢复测试：主体稍后补做接口，覆盖是否恢复；若恢复，说明作用落在周期状态层。
6. 拿掉主动拒绝、辞职、揭露、资源撤回和外部登记变化后，目标变化是否仍存在。
7. 拿掉壳对主体背书的依赖后，主体沉默是否完全无效；若是，证明候选只适用于接口依赖壳。

## 反向测试

```text
x并z 克 nx：
稳定身份壳预先规定主体怎样行动、被读取与被调用
→ 可用方向被角色要求限定
→ 主体更沿壳给出的路线推进
→ nx 上升
```

正向若成立，改变的是壳的周期覆盖接口；反向改变的是主体可用方向。两者不能互相代证。

## 动态链后果

当前只允许写：

```text
这个壳上一周期确实包含我
→ 新周期仍需要我自由完成认领接口
→ 我没有另立反对旗帜，只是不再完成续期
→ 壳下一周期不能继续把我算进“我们”
```

改变的感觉走向是：

> 从“被一个公开壳稳定代表”，转成“行动上仍可能沿外部安排，但公开壳失去继续代表我的接口”。

不得机械生成真相曝光、革命、公开反抗、壳整体崩塌、恢复真实身份或群体全部退出。
