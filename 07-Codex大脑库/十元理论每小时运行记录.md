## 本轮性质

本轮只审计 `nx 克 x并z`。没有修改核心生补克表、关系词典、专项索引、旧审计或待确认队列，也没有新建专项。新推进是把 `x并z` 的既有历史覆盖与需要周期主动续签的当前自愿代表资格拆开：纯 `nx` 的持续不进入，最多可能阻断新一轮共识背书的续期，不能撤销行政身份、职责记录、历史署名或已经发生的过去背书。

## 源端点、目标端点、变量、阶段、体量与显影

源端点 `nx`：主体继续沿既有组织、关系或流程的基线方向行动；不争夺最终解释权，不建立公开替代路线，不辞职，不停止关键职责。主体反复拥有明确、同等、可选择的续签或背书位置，却持续不进入。主动拒签、撤名、否决、解释、价值声明和公开揭露均须优先检查 `zn/z/x/zx`。

目标端点 `x并z`：壳此前已经真实覆盖主体，并被第三方用于归类、代表、调用或解释。只有“本人／全体当前自愿支持”这类明确依赖周期主动续签的共识背书壳仍保留候选；行政身份、既有职责、历史署名和过去完成的背书不因本轮未续签而自动消失。

被改变变量：当前自愿代表资格、当期“全体”覆盖范围、续期状态、第三方当前归因稳定度，以及历史覆盖与当期背书之间的距离。

成立阶段：壳此前真实成立；进入新一轮明确续期窗口；主体拥有同等机会且继续基线流程；主体不拒绝、不解释、不撤名，只不进入续签；窗口结束；第三方依据预设续期规则自动降低当期代表资格，同时保留历史身份与既有记录。

体量：低体量是一次当期声明无法写入主体；中体量是多个周期均显示未续期；高体量只有多个关键成员均不续期，使“全体当前支持”稳定退为“多数支持”。当前不支持稳定身份本体被消灭。

显影条件：续签必须是真正可选而非强制职责；未续签状态必须可被第三方识别；规则必须预先规定未续签不等于反对，但会失去当期自愿代表资格；主体不能因无机会、不可用、偶然缺席或从未纳入而缺席。

## 候选机制与理论后果

### 候选 A：存量壳维持

```text
身份、职责或历史背书已经成立
→ 主体继续基线流程但不作新背书
→ 第三方仍保留既有身份与历史归因
```

理论后果：普通存量壳不会因纯 `nx` 沉默自动下降，不能判克位。

### 候选 B：续期背书失效

```text
“本人／全体当前支持”必须周期主动续签
→ 主体继续基线流程但不进入续签位置
→ 无需明确拒绝或解释
→ 续期窗口结束
→ 第三方自动标记未续期并缩小当期覆盖
```

理论后果：`nx` 最多克制壳的当期自愿代表接口，不克制历史身份与既有壳库存。

### 候选 C：主动拒绝触发下降

```text
主体拒签、撤名、否决或声明不认同
→ 第三方停止把壳解释为主体立场
```

理论后果：目标变化清楚，但启动源可能已经属于 `zn/z/x`，不能归入纯 `nx`。

### 候选 D：接口从未成立

主体没有机会、从未被纳入、不可用或偶然缺席，只能判背书没有生成，不能判已成立壳被克制。

2. **《好兵帅克》帅克｜军队职责阶段**：帅克继续沿军队程序行动，源端较接近 `nx`；但军队仍能行政归类和调用他，被削弱的主要是“英勇忠诚士兵”的精神形象，未证明第三方自动缩小正式代表范围。
3. **《抄写员巴特比》巴特比｜拒绝工作阶段**：抄写员壳逐渐无法解释他，目标端较清楚；但他停止关键工作，已经退出继续基线流程的纯 `nx` 源端。
4. **《千与千寻》千寻与“小千”身份阶段**：行动进入油屋流程但完整身份认领未完成；保留真名含 `zn`，白龙帮助含 `n/nz`，汤婆婆权能含 `x/zx`，无法证明纯 `nx` 续期机制。

7. 一次偶然缺席或系统故障，不构成主动不续期。
8. 当期未续签却继续保留历史身份、职责和旧记录，不能写成整个 `x并z` 消失。

## 最近邻排除

- `zn 克 x并z`：主体因身份或立场“不对”而主动撤回意义认领。
- `z 克 x并z` 候选：主体明确不给予认可或确认。
- `x/xn`：撤销职位、名称、账号、合同、权限或系统状态。
- `zx 克 x并z`：公开拆壳、揭露或夺取解释权。
- 生成失败：壳从未成功吸纳主体。
- 维护停止：不续签可能只是停止再生产，必须证明当期代表资格真实下降。
- 反向 `x并z 克 nx`：身份壳预设角色路线，压缩主体方向空间。

## 拿掉测试

1. 拿掉周期主动续签要求，主体不进入是否完全不影响代表资格？
2. 拿掉历史身份与旧记录，只观察当期自愿代表是否下降。
3. 恢复续签后，当期代表资格是否自动恢复？
4. 拿掉拒签、撤名、否决、解释和价值表态，仅保留不进入，第三方是否仍改判？
5. 拿掉辞职、停工、权限撤销、资源变化与证据曝光，结果是否仍存在？
6. 第三方能否排除无机会、不可用、偶然缺席与从未纳入？
7. 未续签只阻断新一轮背书，还是还错误抹除了历史身份？后者不成立。
8. 如果改判来自系统规则、到期字段或合同状态，直接源是否应归入 `xn/x`？必须继续区分：规则提供可观察接口，主体的持续不进入才是候选作用；若规则本身自动撤销身份，则属于 `xn/x`。

## 反向测试

```text
nx 克 x并z 候选：
主体继续基线流程
→ 不进入周期续签位置
→ 当期自愿代表资格自动失效

x并z 克 nx：
身份壳预设角色路线
→ 主体可用方向被限定
→ 主体更沿壳提供的安排推进
```

正向改变当期代表接口，反向改变主体方向空间，不能互相代证。

## 三元与十元并行核验

三元层只能记录：主体没有加入新一轮共同立场，群体说法覆盖缩小。十元层必须另证：源端仍是 `nx` 的不占立场位置，目标端是 `x并z` 的当期自愿代表资格下降。三元中的“没表态”不能自动派生为十元克位。

## 动态链后果

```text
这个壳过去已经能把我写进“我们”
→ 我仍履行基线职责
→ 新一轮当前支持需要主动续签
→ 我不拒绝、不解释，只不进入续签位置
→ 到期后我被标为未续期
→ “全体当前支持”退成“多数支持”
→ 过去身份与历史记录仍保留
```

改变的是当期自愿代表资格与共同覆盖范围，不机械生成身份消失、组织崩塌、真相曝光或真实自我回归。

## 95%门槛

高置信结论：

- 行政归类壳不因内心不认领而失效：99%。
- 完整履职通常维持职责壳：99%。
- 普通存量共识壳在无明确拒绝时不会自动下降：98%。
- 不进入背书位置必须与无机会、不可用、偶然缺席和从未纳入分开：99%。
- 主动拒签、撤名与价值声明可能退出纯 `nx`：98%。
- 周期续期壳可以使纯不进入变得可观察，并只降低当期自愿代表资格：97%。
- 不续签不能撤销历史身份、旧职责与过去背书：99%。

正式机制未达到95%。缺少两个具体人物案例，同时现有纯结构仍依赖预设续期规则，尚不能完全排除 `xn/x` 对目标变化的直接贡献。结论为：几何位置保留；行政壳和职责壳排除；存量共识壳不成立；周期续期的当期背书接口保留极窄候选；不新增待确认问题。
