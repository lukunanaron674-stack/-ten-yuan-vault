### 对象分层

- 稳定本体：`nz` 是长期保留真实共同时间余温、不愿关系结束与回返姿态；`x` 是长期把对象、资源、权限或关系纳入“归我掌握”。一次心软或一次控制不能反推稳定本体。
- 当前状态：本关系主要发生在掌握者已经控制关系对象、同时意识到继续控制会使关系真正断裂的阶段。
- 行为功能：`nz` 显影为等待、保留、回返、维持联系；`x` 显影为替代决定、否决、调用、排除、检查与控制。只有实际边界变化才构成关系证据。
- 光影：暖光、旧物、回望、门锁、监控、密码和私人空间只作显影。
- 场景：亲子、伴侣、旧友、离别、抚养、行程和社交准入只是场景候选。
- 时间关系：具体关系掌握先成立；关系对象准备离开或无法真实回返；掌握者为保留关系主动缩小控制边界。先后本身不足。
- 关系位置：不愿失去的一方与掌握者必须落在同一关系中的可观察边界变化，称谓不能替代端点。
- 显影：观察独占、替代决定、最终否决、检查权限、关系准入与退出、自主路线和自主返回空间。
- 动态链：从“为了不失去你而管得更紧”转成“只有不再完全掌握你，关系才可能继续”。不机械生成和解。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `nz`：必须有真实共同时间、关系余温和“不想让这段关系结束”。一次善良、责任、心软、害怕失去利益均不足。
- 目标端点 `x`：必须有具体关系掌握，包括替对方决定、控制行动与交往、以“属于我方”排除他者、掌握最终否决与调用权，或把关系对象当作可管理对象。
- 被改变变量：独占程度、替代决定强度、最终否决权、对自主路线的容忍度、关系准入与退出边界，以及“属于我”是否改写为“仍与我相连，但不由我完全决定”。
- 成立阶段：`x` 已成立 → 控制使关系对象准备离开或无法真实回返 → `nz` 的关系保留需求在掌握者一侧显影 → 掌握者主动放松控制 → 对方自主离开、自主决定与自主返回空间增加 → `x` 下降。
- 体量：低体量为取消一次非必要检查或局部否决；中体量为恢复社交、行程、身份或生活选择权；高体量为重写整段关系的准入、退出与自主回返边界。
- 显影条件：原先确有关系掌握；退让由掌握者主动完成；直接理由是“不放松，关系会真正结束”；对方自主路线真实增加；法律强制、交易、疲惫、道德原则与外部压服被排除。

### 候选机制

- A 关系保留迫使控制退场：主体发现继续替对方决定会把对方推走，因此主动放松独占、否决与替代决定。理论后果：克制的是控制关系强度，不要求责任、保护或全部现实边界消失。
- B 停靠对象重新成为独立主体：只有对方可以自主离开并自主返回，停靠才真实；关系余温使主体把对方从“归我决定的对象”还原为独立关系主体。理论后果：目标变化落在对象化与调用边界。
- 统一机制：A 是行动过程，B 是对象地位变化。为了让关系仍有真实回返可能，掌握者主动把对方从“归我决定”还原为“可以自己离开、也可以自己回来”。
- 排除 C 一般心软：若无具体掌握边界下降，只是情绪变柔，不能判克制。

### 正例

1. 《海底总动员》马林与尼莫，结尾返校阶段：马林此前替尼莫判断风险、限制探索与行动；失散和重逢后，为让父子关系继续，他允许尼莫独自上学、参与行动并承担适度风险。目标变量是替代决定、行动否决与关系控制下降。
2. 《青春变形记》明与美美，演唱会冲突后的母女阶段：明长期掌握美美的时间、交往、身体变化解释权和人生安排；冲突后，为避免女儿从关系中真正离开，她允许美美保留熊猫、朋友与自己的选择。身份调用、交往否决与替代决定下降。
3. 纯结构例：旧伴侣中，甲长期掌握乙的社交、行程和共同空间；乙准备离开后，甲主动取消定位共享与检查权限，允许乙独立安排生活，理由是“只有不再完全掌握你，我们才可能仍有关系”。

### 反例

1. 法院判决削减监护权：启动源是制度。
2. 对方威胁分手后被迫交出密码：主要是外部压服或关系勒索。
3. 因道德原则放弃财产：优先检查 `zn`。
4. 因疲惫不再管理对方：只是状态下降。
5. 一次允许孩子外出：若最终否决未变，只是局部授权。
6. 正常分工与协商：双方原本均保留否决权，未必存在 `x` 被克。
7. 财产赠与后仍严格控制受赠者：对象转移不等于关系掌握下降。
8. 关系已结束，仅为补偿而让渡：可能是责任、交易或 `xn` 安排。
9. 赌瘾或冲动无法被伴侣劝住：赌瘾不是现行 `x`，也没有关系掌握边界变化。

### 最近邻

- 与 `x 克 nz`：`x 克 nz` 是控制加强，使停靠失去自愿性，目标变量是 `nz`；`nz 克 x` 是关系余温先显影，使控制主动下降，目标变量是 `x`。
- 与 `zn 克 x`：因“继续掌握是不对的”而放弃，即使关系结束也会这样做；本关系的直接理由是“不放松，这段关系会真正结束”。
- 与 `nx`：`nx` 是主体不占方向位置并沿外部方向推进；本关系中原掌握者仍有能力，但主动缩小自己对他人的掌握边界。
- 与 `zx` 剥夺：外部主体以权能迫使交出控制，不是掌握者主动退让。

### 拿掉测试

1. 拿掉 `nz` 后，若主体仍因法律、道德、利益或疲惫放松控制，则不依赖本关系。
2. 拿掉 `x` 后，只剩陪伴与和解，没有目标端点。
3. 拿掉外部强制后，掌握者仍主动退让，支持直接机制。
4. 拿掉关系将结束的风险后仍照样放权，可能是 `zn` 或正常授权。
5. 拿掉具体控制变化，只剩“心软了”，不能判克制。
6. 放松后，对方的自主路线、否决权或退出权必须真实增加。

### 反向测试

```text
nz 克 x：关系余温先显影 → 掌握者主动收窄控制边界 → x 下降。
x 克 nz：控制加强 → 自主停靠、回返与不愿结束下降 → nz 被克制。
```

方向不能因“关系里既有控制又有不舍”而混写。判断取决于先启动的源端点及被改变变量。

### 动态链后果

```text
我害怕失去你
→ 我曾试图把你管得更紧
→ 但继续掌握只会让你真正离开
→ 我放下替你决定的权力
→ 关系仍可能继续，但不再以“你归我掌握”为条件
```

改变的是关系中自主停靠与自主回返的可能性，以及掌握边界是否仍把对方当作可完全管理的对象。不机械生成和解、永久亲密、正确养育、财产转移或控制者人格重生。
