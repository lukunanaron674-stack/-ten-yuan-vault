## 源端点、目标端点、机制变量

### 源端点 `zx`

必须同时出现：

1. 甲的力量公开进入现实；
2. 甲的决定范围、影响位置或等级位置扩大；
3. 他者或旧秩序被迫围绕甲重新反应；
4. 不是普通善举、私人示范、演讲、牺牲或完成任务。

### 目标端点 `zn`

乙必须：

1. 此前没有稳定原则认领；
2. 甲失败、离场，奖励、宣传、胜利和监督撤场后仍坚持；
3. 在无人监督、可以退出且会受损时行动；
4. 坚持原则本身，而不是英雄、阵营、职位、遗命或组织任务；
5. 能在英雄未规定的新情境中自行推出行动；
6. 能把原则用于英雄阵营之外甚至不利对象；
7. 英雄后来背弃原则时，乙拒绝英雄而保留原则。

### 被改变变量

- 原则的内部确定度；
- 无监督执行持续度；
- 原则与英雄身份的可分离度；
- 新情境独立推导能力；
- 原则向无关对象的泛化范围；
- 英雄背弃时原则是否保留；
- 公开权能相较同等曝光、传播与原则内容提供的净增量。

### 成立阶段、体量与显影条件

```text
乙此前无稳定 zn
→ 甲以真实 zx 把原则推入公共现实
→ 甲撤场，奖励、宣传和监督消失
→ 乙在新情境中独立行动
→ 完成去英雄化、无关对象与英雄背弃测试
→ 再控制曝光、重复传播、情绪强度和原则内容
→ 检查真实权能是否仍提供不可替代增量
```

低体量最多支持一个见证者的阶段性原则认领；中体量支持少数组成员在英雄缺席后持续行动；高体量共同体内化目前无证据。稳定本体层不从一次公开事件反推。

## 候选机制与理论后果

### 候选 A：公开见证入口

```text
甲以 zx 把原则推入现实
→ 乙看见原则不是空话
→ 原则的注意权重与现实可信度上升
```

后果：可以解释原则为什么被认真看见，不能证明内部义务已经生成。

### 候选 B：公开承担代价

```text
甲公开推进原则并承担位置、利益或生命代价
→ 乙排除甲借原则谋利的解释
→ 乙更认真对待原则
```

后果：首先证明甲自己的 `zn`；乙的变化仍可能来自 `z`、`n/nz`、情绪冲击或原则内容本身。

### 候选 C：新情境独立推导

```text
甲撤场
→ 乙面对甲未规定的新问题
→ 无遗命、职位或流程可照抄
→ 乙自行从原则推出行动并承担损失
```

后果：能够排除遗命执行，但仍不能证明源必须是 `zx`。

### 候选 D：同原则载体替换

```text
保持原则内容与公开代价
→ 把甲的公开凌驾替换为私人劝说、无权能示范、文字传播或乙自身经验
→ 比较目标 zn 是否明显下降
```

后果：若目标不下降，`zx` 不是必要源。

### 候选 E：等曝光权能差分

```text
固定受众规模、传播次数、画面强度、情绪冲击、原则内容、公开代价与后续结果
→ 只改变甲是否拥有真实公开决定权与凌驾能力
→ 比较乙形成 zn 的强度与持续度
```

后果：若无权能但同曝光版本产生同等目标变化，作用源优先属于 `x并z` 的公共壳、`xn` 的传播重复、`z` 的确认或原则内容；只有真实 `zx` 提供不可替代净增量，才继续接近直接生位。

## 正例候选

### 1. 《饥饿游戏》凯特尼斯与第十一区见证者

- 阶段：露露死亡后的公开悼念与第十一区回应。
- 源端候选：凯特尼斯的公开行动迫使都城重新处理她的影响。
- 目标候选：见证者认领“人不应被当作竞技消费品”的原则。
- 未通过：长期压迫、露露死亡、地区身份、传播符号和反抗组织均足以独立推动目标；没有同等曝光但无决定权的控制版本。

### 2. 《V字仇杀队》V 与伊薇

- 阶段：V 死后伊薇继续执行最后行动。
- 支持点：英雄撤场后仍行动。
- 未通过：明确计划、训练、胁迫、关系依恋、面具身份壳与阵营继承污染严重，更接近遗命执行。

### 3. 《勇敢的心》华莱士与罗伯特·布鲁斯

- 阶段：华莱士死后罗伯特继续反抗。
- 支持点：公开代价和英雄缺席后行动。
- 未通过：民族身份、政治利益与罗伯特既有信念过强，无法证明目标从无到有，也无法隔离曝光和权能。

### 4. 《悲惨世界》主教与冉阿让

- 目标变化清楚：冉阿让后来把救助与不被过去定义认作内部原则。
- 未通过：主教源端更接近 `zn/n/z`，没有足够公开扩权与凌驾，不是纯 `zx`。

## 反例

1. 强者获胜后群众加入胜方：利益与胜利预期。
2. 英雄授勋、立像或进入教材：`z/x并z/xn`。
3. 群众因恐惧服从：权力结果或 `nx`。
4. 追随者原本已有同一原则：既有 `zn` 显影。
5. 继承职位、制服、任务或遗命：`x/x并z/xn/nx`。
6. 删除英雄身份后原则无法运行：英雄依附。
7. 私人示范、文字传播或乙自身经验同样足以生成原则：无 `zx` 必要性。
8. 强者以同等 `zx` 推进任何相反原则，乙都会接受：服从、崇拜或胜方依附。
9. 同等受众、传播与情绪强度下，无决定权示范者产生同等目标变化：公开传播作用，不是权能净增量。

## 最近邻排除

- `zn 生 zx`：甲先有原则，再由甲本人显权；多数英雄案例首先支持这一方向。
- `z`：英雄榜样和精神确认改变认可位置。
- `x并z`：旗帜、称号、面具、纪念和公开身份壳提供可识别接口。
- `n/nz`：恩情、悲痛、共同体承载和关系余温维持英雄依附。
- `xn/nx`：教育、传播、职位继承、组织流程和遗命延续行动。
- 乙独立判断：没有甲的 `zx` 也会形成原则时，不能归因于本关系。

## 拿掉测试

1. 拿掉甲的公开显权，只保留原则、善举与代价。
2. 拿掉胜利、奖励、宣传、纪念和监督。
3. 拿掉乙原有信念。
4. 删除英雄本人、姓名、形象、口号和阵营。
5. 拿掉遗命、计划、职位和流程。
6. 将目标对象替换为英雄阵营之外甚至敌对的人。
7. 英雄背弃原则时，乙是否拒绝英雄？
8. 拿掉恩情、悲痛与关系余温。
9. 将同一原则换成私人劝说、无权能示范、文字传播或乙自身经验。
10. 固定受众规模、传播次数、情绪强度、公开代价和原则内容，只撤掉真实决定权与凌驾能力。
11. 用同等 `zx` 推进另一套无关或相反原则，乙是否也接受？
12. 只保留乙自身压迫经验和独立判断，原则是否仍出现？

现有候选均未通过第 3、7、9、10、11、12 项完整组合。

## 反向测试

```text
zx 生 zn 候选：
甲公开显权
→ 乙去英雄化后仍坚持
→ 同等曝光无权能版本不能产生同等目标
→ 真实权能存在不可替代净增量

zn 生 zx：

→ 甲自己公开推进

```

现有英雄案例仍更稳定支持 `zn 生 zx`，不能用甲自己的原则和显权证明另一个乙新增了 `zn`。

## 三元与十元并行核验

三元层只能记录：

- 强者把原则公开推入现实；
- 见证者后来继续行动；
- 英雄撤场后原则仍被提及。

十元层必须另证：

- 源端是实际公开扩权与凌驾的 `zx`；
- 目标端是乙从无到有的内部义务 `zn`；
- 去英雄化、新情境、无关对象和英雄背弃均通过；
- 同等曝光与传播不能解释目标变化；
- 真实权能提供不可替代净增量。

三元中的“强者示范后有人传承”不能自动派生为十元 `zx 生 zn`。

## 动态链后果

```text
我看见他把原则推入现实
→ 我可能只是震撼、崇拜或执行遗命
→ 他撤场，我面对新情境
→ 删除他的姓名、符号和阵营
→ 我仍按原则行动
→ 即使他背弃原则，我也拒绝他
→ 再把受众、传播、情绪与代价全部固定
→ 撤掉他的实际决定权与凌驾能力
→ 若我仍同样形成原则，zx 只提供见证入口
→ 只有权能本身带来不可替代增量
→ 才继续接近直接生位
```

改变的是见证者对原则的内部归属、来源可分离度、新情境推导、泛化范围与源因果归属；不机械生成英雄崇拜、共同体、胜利、正义性或永久传承。

## 95% 门槛

高置信结论：

- 同主体“行动自证”不能作为正式机制：99%。
- 英雄崇拜、胜方追随、纪念传播、遗命执行和服从不是 `zn`：99%。
- 源目标必须跨主体：98%。
- 去来源、新情境、原则泛化和英雄背弃是目标端必要测试：98%。
- `zx` 能提高原则的公开可见性、现实可信度与见证强度：97%。
- 公开见证入口不等于内部义务生成：98%。
- 同原则载体替换与等曝光权能差分是直接生位的必要门槛：98%。

正式机制未达到 95%。原因：

1. 缺少两个完整通过目标从无到有、去来源、泛化、英雄背弃与等曝光权能差分的具体人物案例；
2. 现有候选持续混入压迫经验、传播、关系感动、既有信念、遗命和组织结构；
3. 目前最多确认 `zx` 提供公开见证入口和现实可信度，不能确认它独立生成乙的 `zn`。
