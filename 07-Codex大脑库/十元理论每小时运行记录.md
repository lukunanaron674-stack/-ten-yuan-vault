### 对象分层

- 稳定本体：`n` 是长期接收、处理并允许对象停留；`x并z` 是长期以公开壳规定内部怎样被世界读取。一次收留、装修或换装不能反推。
- 当前状态：此阶段正在接住并消化负荷，与此阶段正在建立或维护公开界面分开。
- 行为功能：接手、容纳、照护、处理；命名、包装、设置入口、展示。行为须回到端点变量。
- 光影：内部、厚重、包裹、门面、橱窗、制服与舞台只作显影。
- 场景：家、旅馆、医院、避难所、招牌、礼仪和品牌不能替代端点。
- 时间关系：承载可先成立，界面也可先成立；补位不要求固定先后。
- 关系位置：接收者、照护者、前台代表和身份持有者等称谓不能自动判定。
- 显影：观察接收范围、内部真实内容、持续处理能力、可识别性、可进入性和解释稳定度。
- 动态链：改变“这里真的接得住”与“世界知道怎样接近这里”的空间完整度，不机械生成认可或繁荣。

### 双向端点、变量、阶段、体量与显影

- `n 补 x并z`：已有名称、门面、制服、礼仪、品牌或公开角色，但内部承载不足。变量是壳内部真实性、承受真实负荷的能力、公开承诺与内部实际的连接。
- `x并z 补 n`：已有真实接收、照护和内部处理能力，但外界不知道它是什么、怎样进入、由谁接洽。变量是可识别性、进入方式与边界、同一名称或角色的持续指认能力。
- 成立阶段：两端至少一端先独立成立；另一端补入后改变已有端点真实缺口；必须排除 `xn` 运营、`x` 产权、`z` 认可和 `zx` 显权。
- 体量：低体量为一次真实接住或一个入口首次建立；中体量为形式与内部承载反复对应；高体量为组织、家园或文化空间长期保持外部可识别、内部真能接住。
- 显影条件：空壳变为内部有真实承载；不可读容器获得稳定入口；漂亮门面能够承受真实负荷；真实内部获得世界可理解的进入方式。

### 候选机制

- A 内部真实性补壳：公开形式先成立，`n` 实际承担进入后的负荷，使 `x并z` 从展示层变为可使用的真实界面。
- B 公共入口补容器：承载结构先成立，`x并z` 形成名称、门面、角色与进入仪式，使 `n` 获得可辨认边界和公共入口。
- C 运营流程使内外一致：排除；主要属于 `xn`。
- D 产权与品牌绑定：排除；主要属于 `x` 与可能的 `x 生 x并z`。
- 统一机制：`n` 让壳里面真的有东西可承载；`x并z` 让承载结构拥有世界能够读取和进入的形式。互补但不互相生成。

### 正例

1. 《千与千寻》千寻进入并工作后的油屋：华丽浴场、名称、制服和礼仪形成公共壳；锅炉房、浴池、员工与千寻真实接住河神、无脸男、白龙和事故。劳动分工含 `xn`，汤婆婆产权含 `x`，但不替代承载与界面变量。
2. 《布达佩斯大饭店》1932年古斯塔夫管理时期：客房、厨房、员工与服务真实接收旅客、行李、秘密和临时生活；建筑、礼宾身份、制服、礼仪与名称形成统一公共壳。
3. 社区匿名互助站：居民已长期接收家暴、失业和临时无处可去者，随后建立中性名称、固定标识、接洽角色和保护性前台入口，使真实承载能够被安全识别和进入。

### 反例

1. 精装样板间与混凝土楼板并存，只证明物理内外层次。
2. 房子装修漂亮，可能只是审美、消费或展示。
3. 家庭有姓氏和门牌，不证明名称提高了接收和进入能力。
4. 品牌广告增加客流，主要改变传播效率。
5. 避难所有醒目标志但没有床位、照护和处理能力，只有空壳。
6. 真实互助共同体主动拒绝外界进入，若根本没有公共入口缺口，不能硬写 `x并z 补 n`。
7. 统一制服提高纪律，主要是 `xn`。
8. 建筑产权与挂牌同时存在，可能只是 `x 生 x并z`。

### 最近邻

- 与 `x 生 x并z`：后者已有端点是“归我掌握”，本关系已有端点是“真实接住并处理”。
- 与 `x并z 生 z`：后者改变认可主体的识别与归因，本关系改变承载结构的公共入口和空间可读性。
- 与 `n 生 xn`：后者改变排班、记录与持续运行结构，本关系改变壳的内部真实性。
- 与普通建筑内外：物理外墙与房间不是语义上的公共界面与真实承载。

### 拿掉测试

1. 拿掉 `n` 后，壳若只剩展示、欺骗或标识，支持 `n 补 x并z`。
2. 拿掉 `x并z` 后，内部仍能承载却失去统一名称、入口、对外角色与公共可读性，支持 `x并z 补 n`。
3. 拿掉运营流程后，只要内部仍真实接住、外部仍提供进入界面，互补继续成立，可排除 `xn`。
4. 拿掉产权控制后，承载与界面仍互相补足，可排除 `x`。
5. 拿掉认可和宣传效果后，少数进入者仍能通过壳找到并使用容器，可排除 `z`。
6. 任一端拿掉后案例完全不变，则只是共现。

### 反向测试

```text
n 补 x并z：承载内部补足壳的空心问题。
x并z 补 n：公开界面补足容器的不可读、不可进入问题。
```

补位几何对称，但作用变量必须分写。一个案例可以双向显影，不能只写“内外互补”。
