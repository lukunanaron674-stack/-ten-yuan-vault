### 源端点、目标端点与变量

源端点 `z`：重要认可者只确认主体自己的判断、能力或选择资格，不提供方案、职位、资源、许可、训练、长期照护或后果兜底。

目标端点 `nx`：主体此前已有真实可行路线、否决权和承担能力，却因认为自己的判断没有资格成立而持续沿外部方向推进。

被改变变量：

1. 主体是否承认自己的判断有资格成立；
2. 外部路线是否仍垄断合法性；
3. 主体是否提出并执行替代路线；
4. 主体是否实际使用否决权；
5. 认可停止、撤回甚至反对后，主体是否仍维持自己的路线；
6. 主体是否承担独立选择的现实损失。

成立阶段与体量：

```text
低体量：一个具体选择中首次否决外部安排。
中体量：在某段关系或任务中持续保持自己的路线。
高体量：稳定人物本体从长期 nx 转为持续自主决定。当前无证据支持。
```

### 候选机制

#### 候选 A：判断资格确认

```text
主体有自己的可行路线
→ 但认为自己的判断没有资格成立
→ 因而持续沿外部安排
→ 重要认可者确认“你的判断可以成立”
→ 外部路线不再垄断合法性
→ 主体提出并承担自己的路线
```

理论后果：只适用于“判断资格自我取消型 nx”，不能泛化为认可自动让所有跟随者独立。

#### 候选 B：能力资格确认

```text
主体知道自己想走哪条路
→ 但不相信自己能承担后果
→ 重要认可者确认其能力足以承担选择
→ 主体重新使用否决和决定位置
```

理论后果：如果主体只是更努力执行旧安排，只有 `z` 上升，`nx` 未下降。

#### 候选 C：换一个跟随对象

```text
主体不再听原方向提供者
→ 改为只听认可者
```

理论后果：外部路线来源变化，但最终方向权仍不在主体，`nx` 结构没有下降。

#### 候选 D：结构性依赖

主体缺少资源、职位、许可、能力或现实替代路线。认可后仍无法改变方向，只能说明纯 `z` 无法解除该类 `nx`。

### 正例候选

1. **《死亡诗社》托德与基廷，课堂即兴诗阶段**：基廷确认托德拥有自己的诗性声音，托德从沉默和标准答案位置转为说出自己的语言。污染：基廷同时提供教学结构、强引导、课堂权能和情感承载；影片没有充分证明基廷撤回支持或反对后，托德仍保持独立路线。
2. **《跳出我天地》比利与父亲，父亲支持舞蹈之后**：父亲的认可使矿工家庭路线不再拥有唯一现实资格。污染：比利在认可前已有强自主路线，父亲还同时提供资源、许可和家庭权力放行，更像既有自主获得现实支持。
3. **研究生独立定题结构例**：学生有可行选题，却认为自己的判断不够资格；导师只确认判断能力，不给题、经费或许可。导师后来反对新题，学生仍拒绝旧题并承担失败风险。结构通过反认可测试，但缺少第二个可核验作品人物案例。

### 反例

1. 老板表扬员工后，员工更认真执行老板安排：`z` 上升，`nx` 未降。
2. 父母说“我相信你”，却继续掌握学校、资金和许可：认可与方向权分离。
3. 导师给出另一套方案，学生改为执行新方案：只是换了外部方向。
4. 上级授予预算、职位和签字权：主要是 `x` 权限转移。
5. 治疗者通过长期训练和照护使主体独立：主要是 `xn/n`。
6. 人物原本已有并坚持自主路线，认可只让其公开：既有自主显影。
7. 获奖后自信增加，但没有否决任何安排：状态变化。
8. 认可者一反对，主体立刻撤回自己的路线：仍然依赖认可者，未通过反认可测试。

### 最近邻排除

- 与 `x/zx`：职位、资源、许可、放权和公开权能直接改变现实决定资格。
- 与 `xn/n`：教学、训练和照护提高能力与安全感，不等于认可本身克制方向依赖。
- 与 `zn`：主体因“这件事本身正确”而拒绝外部路线，启动源是内部意义。
- 与自信上升：敢说、敢表现不等于提出替代路线、否决并承担结果。
- 与换跟随对象：从服从安排者转成服从认可者，`nx` 仍然存在。
- 与反向 `nx 克 z`：后者改变认可能否发生，本轮改变方向合法性。

### 拿掉测试

1. 拿掉认可，只保留教学、资源、职位和放权，主体仍独立，则不依赖 `z`。
2. 拿掉教学、资源、许可与后果兜底，只保留判断资格确认，主体仍决定，才支持直接机制。
3. 拿掉主体原有可行路线，认可后仍无替代方向，目标端点不足。
4. 拿掉“自己的判断没有资格”的前置自我取消，若主体本来就自主，只是显影。
5. 拿掉情绪振奋，只观察替代路线、否决与损失承担。
6. 认可停止后仍保持方向，才能排除持续追逐认可。
7. 认可者后来撤回支持、提出相反路线甚至否定主体时，主体仍维持路线，才通过反认可测试。
8. 若主体随认可者改变方向，只能判换跟随对象。

### 反向测试

```text
z 克 nx 候选：
主体因否定自己的判断资格而跟随
→ 认可确认判断资格
→ 即使认可者后来反对，主体仍持续取回方向

nx 克 z：
主体不表达、不呈现、不进入认可接口
→ 重要确认无法发生
```

正向改变方向合法性，反向改变认可接口，不能互相代证。

### 动态链后果

```text
我不是没有路线
→ 我只是认为自己的判断没有资格成立
→ 重要的人确认我的判断可以成立
→ 我提出另一条路线并承担代价
→ 他后来撤回认可甚至反对
→ 我仍保留自己的路线
→ 方向权才真正回到我这里
```

改变的是主体是否承认自己拥有决定资格，以及外部路线是否仍垄断合法性。不机械生成成熟、勇气、成功或稳定独立人格。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验认可端点、方向位置、替代路线、否决权和反认可后的持续性。`z` 与 `nx` 并行，不构成父子派生，也不从因果主题倒推关系成立。
