### 对象分层

- 稳定本体：`zn` 是不依赖奖励、认可与结果保证的内部意义确定；`n` 是对象真实落入自身后被接住、允许停留并持续处理。不能从一次心软、收留或建筑出现反推稳定本体。
- 当前状态：主体此阶段确认某对象不能被抛下；随后撤回拒绝或推出该对象的资格，使对象进入自身承担范围。候选最可能先成立于状态层或关系层。
- 行为功能：`zn` 显影为拒绝抛弃、愿意承担代价；`n` 显影为接收、留存、照护、隐藏、修复与处理。行为必须回到准入、留存和内部负荷变量。
- 光影：圣性、誓言、暖光、房屋、地下室、床位与容器构图只作显影证据。
- 场景：宗教、革命、家庭、旅馆、避难所和纪念空间只是候选场景，不能替代端点。
- 时间关系：意义判断先成立；对象随后从可拒绝的外部对象进入内部；成熟流程、资源和制度可以后来出现。先后本身仍不足。
- 关系位置：信念持有者、照护者、家长、经理、神父与共同体成员等称谓不能直接判关系。
- 显影：观察主体是否撤回拒绝权、允许对象跨阶段停留、承担其产生的时间、空间、风险和资源负荷；拿掉意义后对象是否会重新被推出。
- 动态链：从“这件事不能被丢下”走向“它不再只是世界外部的问题，而必须落到我这里”。不机械生成建筑和制度。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `zn`：没有奖励、认可、法律义务或结果保证，主体仍认为某人、某事或某段意义不能被抛下。普通善良、社会职责、口号、声誉压力与任务需要不足。
- 目标端点 `n`：对象真实进入主体或结构内部，被接住、允许持续停留，并由主体承担照护、隐蔽、修复、共在、风险或资源负荷；一次象征接触或立即转交不足。
- 被改变变量：对象的准入资格、主体的拒绝与推出权、允许停留时间、对象由外部议题转为内部负荷的程度、持续处理是否跨阶段成立。
- 目标变量拆分：本轮只考察 `n` 的准入与留存边界，不把完整资源能力、成熟制度、建筑规模、重复接收能力或共同体稳定度写成 `zn` 的直接产物。
- 成立阶段：`zn` 确认不能抛下 → 主体撤回拒绝/推出 → 对象进入内部并停留 → 在成熟 `xn/x/zx` 出现前，真实处理已经持续跨过一个阶段。
- 体量：低体量为撤回拒绝并开始持续承担；中体量为对象跨阶段留存且负荷反复被处理；高体量共同体必然更易混入 `x/xn/zx`，暂不用于锁定直接机制。
- 显影条件：低权能、低制度、低资源；对象原本可被拒绝；拿掉领袖命令、成熟流程、产权与资源权限后承接仍开始；拿掉 `zn` 后对象会重新被推出。

### 候选机制

- A 准入与留存边界重划：`zn` 先确认对象不能被丢下 → 主体撤回拒绝与推出资格 → 对象进入自身生活、空间或关系内部 → 主体持续承担其负荷 → `n` 的准入与留存边界上升。理论后果：直接作用只锁定 n 的入口，不声称完整容器自动成熟。
- B 意义只是动机，中介才生成承载：`zn` 提供理由 → `zx` 公开推动或取得空间 → `xn` 组织维护 → `x` 提供资源和准入权限 → `n` 形成。理论后果：`zn 生 n` 只保留几何压缩，具体链必须写出中介。
- C 共同意义自动生成共同体：多人相信同一件事 → 聚集 → 共同体成立。该候选继续排除；集会、情绪共振和共同口号没有接收、留存与处理闭环。

### 正例候选

1. 《偷书贼》汉斯、罗莎与马克斯｜接纳马克斯进入家庭并长期隐藏阶段：`zn` 候选是不能把马克斯交给迫害体系；`n` 候选是撤回拒绝权、允许其持续居住并承担食物、隐蔽与风险。地下室只是场景，换空间仍可承接。限制是家庭资源与准入含 `x`，隐蔽安排含 `xn`，无法彻底拿掉中介。
2. 《卢旺达饭店》保罗与难民｜酒店由商业空间转为难民承载空间阶段：保罗确认不能把眼前的人交出去等死，随后扩大酒店准入、允许停留并承担房间、食物、秩序和风险。限制是经理权限 `x`、公开谈判与推进 `zx`、名单和物资组织 `xn` 同时存在。
3. 无领袖悼念群体形成长期遗属照护点：共同确认遗属不能被独自留下，先开始接收、陪伴与保存资料，再逐步形成场所和流程。结构纯度较高，但缺乏第二个可核验人物文本，不能独自越过95%。

### 反例

1. 政府依预算、审批和施工计划建设纪念馆：意义题材存在，真正生成承载的是 `xn/zx/x`。
2. 一次性宗教集会：共同信念和聚集共现，没有持续接收、留存和处理负荷。
3. 领袖命令成员收留难民：成员沿指令执行更接近 `nx`，领袖公开推动更接近 `zx`。
4. 商业旅馆因利润长期接待客人：`n` 可以成立，但启动源不是 `zn`。
5. 主体只说“应该帮助他们”或捐一次钱：意义或善举存在，对象没有进入自身承担范围。
6. 因法律监护义务接收：若拿掉法律后不会接住，启动源是制度 `xn`。

### 最近邻

- 与 `zn 生 zx`：后者改变公开推进、号召与权能位置；本轮候选只改变什么对象获得进入和停留资格。
- 与 `n 生 xn`：后者从已经成立的承载出发，为持续运行提炼顺序、分工、记录和预案；本轮候选发生在对象进入承载范围之前。
- 与 `zn 补 x`：补位改变已有资源为什么被守、如何被用；本轮候选改变对象是否被接入，不能用资源用途代替准入变化。
- 与普通善良：一次心软、一顿饭、一次捐赠不具备无回报意义、跨阶段留存与处理闭环。

### 拿掉测试

1. 拿掉 `zn`：若主体仍因商业、行政、亲属或法律义务同样接收，案例不依赖本关系。
2. 拿掉 `n`：若只剩声明、捐款、号召或一次帮忙，目标端点不存在。
3. 拿掉 `zx`：没有领袖命令、公开推动与强制行动后，主体是否仍撤回拒绝并接住对象？
4. 拿掉 `xn`：没有成熟排班、记录和流程时，承接是否已经跨阶段开始？
5. 拿掉 `x`：不拥有完整产权、资金和正式准入权限时，主体是否仍通过生活、空间与风险承担接住对象？
6. 拿掉建筑：换一个物理空间后，准入、留存和处理是否仍成立？
7. 当前两个具体作品候选均未通过全部中介拿掉测试。

### 反向测试

```text
zn 生 n：不能放弃的意义先成立 → 对象获得进入与停留资格 → 承载开始。
n 生 zn：对象长期被同一容器接住 → 共同时间与负荷沉淀 → 形成不能放弃的内部意义。
```

两方向可以形成反馈，但必须观察谁先改变变量。最终同时存在意义与承载不能互相代证。

### 动态链后果

```text
这件事不能被丢下
→ 它不再只是世界外部的问题
→ 我撤回把它推出去的资格
→ 它进入我的生活、空间或关系内部
→ 我开始持续处理它带来的负荷
```

改变的是**意义如何进入承载的准入与留存边界**。它不机械生成建筑、成熟制度、资源、组织成功、永久稳定、公开权能或所有成员共享的意义。

### 三元与十元并行

三元只核验作品整体精神运动与大主题感觉。十元本轮只核验 `zn` 源端点、`n` 的准入与留存目标、具体阶段、第三因素与变量变化。不从本体主题 `zn+x` 或空间主题 `x并z+n` 反推 `zn 生 n`，也不建立父子派生。
