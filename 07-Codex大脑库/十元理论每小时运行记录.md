### 源端点、目标端点与变量

源端点 `nx`：甲原本有真实可行路线、否决权、取回决定的能力与承担资格，却跨轮次持续不使用方向权，不提出方案，不直接面对成员、资源或外部接口。

目标端点 `x`：乙此前没有稳定掌握，随后新增最终调配、真实否决、排除替代方案、对外代表、排他使用或关系控制，并且甲明确取回时不能立即恢复直接决定。

被改变变量：

1. 谁的决定默认有效；
2. 谁能排除替代方案；
3. 谁被第三方视为最终接口；
4. 原权利主体是否可以无条件取回；
5. 取回失败究竟来自乙新生掌握，还是职位、授权、信息和制度第二入口；
6. 乙只是代理，还是已经获得事实否决与排他边界。

成立阶段与体量：

```text
低体量：一次委托或代办，只能判状态。
中体量：跨阶段形成默认接口，但甲取回时仍能立即恢复，只能判代理或 xn。
高体量：甲明确取回后，乙或第三方仍能实际拒绝、排除或持续代表，才触及 x；当前无纯证据支持 nx 独立生成。
```

### 候选机制

#### 候选 A：默认决定经第三方固化

```text
甲持续不用方向权
→ 乙决定反复落地
→ 第三方逐渐只向乙请求决定
→ 乙成为默认接口
→ 甲取回时第三方仍拒绝绕过乙
```

理论后果：`nx` 只提供持续空位，第三方接口固化是必要第二入口。没有取回冲突，只能证明习惯、代理或组织接口。

#### 候选 B：接口集中形成事实排他

```text
甲长期不直接面对成员、资源和外部关系
→ 信息、材料和口径集中到乙
→ 乙可以排除甲的直接接触或否决替代路线
→ x 候选形成
```

理论后果：若排他来自信息截断、账户、职位、合同或流程控制，直接作用源属于既有 `x/xn`，不能归给 `nx`。

#### 候选 C：乙主动接管

```text
甲持续让位
→ 乙主动控制信息、阻止甲取回、要求一切经过自己
→ 掌握形成
```

理论后果：甲的 `nx` 是允许条件，乙的主动 `x/zx/xn` 才是直接生成源。

#### 候选 D：默认代理

```text
甲长期不决定
→ 乙成为常用联系人
→ 甲明确取回
→ 乙立即归还，第三方重新承认甲
```

理论后果：只成立代理、分工或 `xn` 接口，不成立 `x`。

### 正例候选

1. **家庭财务长期代管结构**：甲有法律与现实决定能力，却多年让乙处理账户、账单、住房与对外联系。若甲明确取回后银行、房东或家庭成员仍只承认乙，目标端点候选成立；但这种抵抗通常来自密码、材料、授权、账户与信息控制，属于第二入口。
2. **创作团队对外接口结构**：主创甲长期不面对合作方，制片乙逐渐成为发布时间、合作对象与公开口径的唯一接口。若甲取回时合作方仍拒绝绕过乙，目标端点候选上升；但通常混入职位、合同、行业流程与乙主动管理。
3. **《魅影缝匠》雷诺兹与西里尔**：雷诺兹长期依赖西里尔处理客户、日程与生活接口，西里尔拥有强事实掌握。限制是西里尔原本已有稳定管理位置与 `x/xn`，不能证明目标从无到有。
4. **《穿普拉达的女王》安迪与米兰达**：安迪不断放弃私人时间和可拒绝边界，米兰达控制范围扩大。限制是米兰达的职位、主动要求和 `zx` 压迫本来就提供掌握。

### 反例

1. 一次代班、代购或临时委托：仅状态变化。
2. 伴侣负责财务但双方随时查账并共同否决：普通分工。
3. 大家习惯找乙，但甲出现后立即承认甲：默认接口，不是掌握。
4. 甲取回只需重新通知或多沟通一次：协调摩擦，不是 `x`。
5. 正式授予签字权、预算、账户或合同权限：权限配置。
6. 乙靠威胁、扣留密码、信息截断或监控阻止甲：主动 `x/zx`。
7. 乙承担更多劳动却不能否决或代表：劳动量不等于掌握。
8. 甲本来没有决定资格：不存在可让出的源端点。

### 最近邻排除

- 与 `x 生 nx`：乙先有掌握，甲的可用方向随后被压缩。
- 与 `xn`：默认联系人、流程负责人和信息汇总若不能抵抗取回，只是组织接口。
- 与 `zx`：公开威胁、夺权、压退甲或阻止取回属于主动显权。
- 与正式授权：授权直接改变权限，本轮候选要求没有明确权限转移。
- 与普通依赖：更常找乙、更信任乙、不愿自己处理，不等于乙拥有否决和排他。

### 拿掉测试

1. 拿掉甲持续让位，乙若仍凭职位、产权、账户或合同掌握，不依赖本关系。
2. 拿掉乙主动阻止、信息截断与第三方制度化，乙是否仍能抵抗甲取回？
3. 拿掉正式授权、密码、材料、钥匙和合同，掌握是否消失？
4. 拿掉第三方习惯，只看乙是否能直接否决甲。
5. 让甲明确取回：乙立即归还则不成立；乙可以拒绝则继续追查拒绝能力来源。
6. 只有额外沟通、重新通知和协商成本，没有事实拒绝、排除或持续代表，不足以判 `x`。
7. 现有候选均无法同时满足“目标从无到有”与“取回抵抗不依赖第二入口”。

### 反向测试

```text
nx 生 x 候选：
甲持续空出方向位置
→ 乙默认决定被反复承认
→ 甲取回时乙仍能维持掌握

x 生 nx：
乙先拥有掌握边界
→ 甲可用方向被压缩
→ 甲沿乙方向推进
```

最终画面都可能是“乙决定、甲跟随”，但阶段顺序与直接作用源不同，不能互相代证。

### 动态链后果

```text
这次先按你的办法
→ 以后也默认你决定
→ 别人开始只找你
→ 我以为自己随时能取回
→ 当我真正取回时，你或外部接口拒绝我
→ 继续追查拒绝来自你的新生掌握，还是职位、授权、信息与制度
```

改变的是默认有效性、代表接口、排他能力与原权利主体能否真实取回。不机械生成管理能力、权力人格、法定权限或永久控制。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验甲是否真实让位、乙是否新增掌握、取回是否遭遇事实抵抗，以及抵抗是否来自第二入口。`nx` 与 `x` 并行核验，不构成父子派生，也不从因果主题、家庭题材或人物强弱倒推关系成立。

### 95%门槛

高置信结论：

- 旧“压抑欲望积累成 x”机制失效：99%。
- 同主体“越顺从越生成自己的 x”不成立：99%。
- 默认联系人、代管惯性、重新通知与额外协商不足以证明 `x`：99%。
- `x` 必须通过取回抵抗、事实否决、排他或持续代表显影：98%。
- 甲取回时乙立即归还，只能判代理或 `xn`：99%。
- 取回抵抗若依赖职位、授权、信息控制、第三方制度化、既有 `x/xn` 或乙主动阻止，直接掌握源属于第二入口：98%。
