### 对象分层

- 稳定本体：`zx` 是长期以自身权能公开决定、扩张并迫使现实重排；`zn` 是不依赖奖励、认可和结果保证的内部意义确定。一次显权或一次感动不能反推稳定本体。
- 当前状态：甲在某阶段成为公开决定中心；乙在某阶段开始认领原则。候选最多先落在关系层或状态层。
- 行为功能：甲公开推进、承担代价、压过旧秩序属于 `zx` 证据；乙在甲缺席后继续执行原则、拒绝利益诱因并承担损失属于 `zn` 目标证据。
- 光影：中心构图、群众转向、旗帜、牺牲、火炬与孤独背影只能辅助显影。
- 场景：革命、战争、演说、纪念、传承与信仰题材不能替代端点。
- 时间关系：乙此前无稳定原则 → 甲公开显权 → 甲失败或离场 → 奖励、宣传、监督停止 → 乙仍坚持。缺一段不能锁定。
- 关系位置：源主体甲与目标主体乙必须分开；同主体“我做成了，所以我相信”优先检查 `zn 生 zx`、自我确认或结果反馈。
- 显影：乙是否从“我敬佩他、我属于他的阵营”转成“即使没人看见，我也有义务这样做”。
- 动态链：原则从英雄的公开行动中进入见证者视野，再由见证者在英雄撤场后独立承担；不机械生成共同体、纪念、胜利或正义性。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `zx`：甲的力量必须公开进入现实，决定范围或等级位置扩大，他者与旧秩序被迫围绕甲重新行动；普通善举、演说、牺牲和坚持不足。
- 目标端点 `zn`：乙此前没有稳定原则认领；甲撤场后，乙在无人监督、无奖励、可退出且承担损失时仍坚持可与英雄个人分离的原则。
- 被改变变量：乙对原则的内部确定度、无监督执行持续度、原则与英雄个人的可分离度、去掉胜利后的坚持度、从敬佩到义务的转化程度。
- 成立阶段：见证入口出现 → 英雄中心撤除 → 外部强化物消失 → 乙独立选择并承担后果 → 原则跨主体内化。
- 体量：低体量是一次无监督坚持；中体量是跨阶段反复承担损失；高体量是甲长期缺席后乙仍持续维护原则且不依赖组织监督。
- 显影条件：拿掉英雄本人、宣传、胜利、奖励、群体身份和乙既有信念后，目标仍存在；乙坚持的是原则而非职位、口号或阵营。

### 候选机制

#### A｜原则可行性被公开证明

```text
甲以 zx 把原则推入现实
→ 乙看见原则并非只能停留在口号
→ 乙开始把原则纳入自己的判断
```

理论后果：解释“原则如何获得公开见证入口”。风险是乙若只因成功才相信，更接近 `z` 的结果确认、胜方追随或工具理性。

#### B｜公开承担代价取消谋利解释

```text
甲公开推进原则并承担位置、利益或生命代价
→ 乙确认甲不是借原则谋利
→ 甲离场后乙仍坚持同一原则
```

理论后果：代价可削弱“表演/谋利”解释。风险是代价首先显影甲自己的 `zn`，乙的变化仍可能来自悲痛、个人恩情、`n/nz` 或宣传。

#### C｜见证入口与义务内化分成两步

```text
zx 只让原则公开可见
→ 乙经过独立判断，把原则转成自己的无监督义务
→ zn 才成立
```

理论后果：若该拆分正确，`zx` 是必要见证条件但未必是充分生成源；正式关系需证明第二步不是由 `z/x并z/n/xn` 或乙原有 `zn` 完成。

### 正例候选

1. **《饥饿游戏》凯特尼斯与第十一区见证者**：凯特尼斯公开悼念露露、挑战竞技秩序并承担风险，使“人不应被当作竞技消费品”进入公共现实。限制是长期压迫、悲痛、地区身份、传播符号与反抗组织均能解释后续行动；无法证明乙此前无稳定原则。
2. **《悲惨世界》主教与冉阿让**：冉阿让后续形成“人不应被过去永久定义、应救助他人”的内部义务，目标变化较清楚。限制是主教行为更接近 `zn/n/z`，缺少公开扩权、等级重排和决定范围扩大，源端点不够 `zx`。
3. **《黑暗骑士》蝙蝠侠与渡轮乘客**：乘客在没有获救保证时拒绝主动杀死另一船，具备无奖励原则行动。限制是法律道德、群体监督、两难结构与既有信念过强，蝙蝠侠的 `zx` 并非直接作用链。

### 反例

1. 强者获胜后群众加入胜方：利益与胜利预期，不是 `zn`。
2. 英雄被授勋、立像或写入教材后成为榜样：`z/x并z/xn` 与传播结构。
3. 群众因恐惧服从显权者：`nx` 或权力结果。
4. 追随者本来就相信原则：既有 `zn` 显影。
5. 英雄牺牲后建立纪念馆或组织：`n/xn/x并z`，不等于见证者内部义务。
6. 乙继承职位、制服、任务和组织流程：`x/x并z/xn/nx`，不等于继承原则。
7. 甲自己的内部意义推动甲公开行动：方向是 `zn 生 zx`，不能倒写。
8. 乙只是敬佩、悲伤、感恩或希望像英雄一样被看见：状态、`z/nz` 或身份追随。

### 最近邻排除

- 与 `zn 生 zx`：甲先有内部意义，再由甲自己公开显权；本轮必须是甲的 `zx` 作用于另一个乙的 `zn`。
- 与 `x并z 生 z`：旗帜、称号、作品和公开壳让原则或人物被识别并确认；不解释乙为何形成无监督义务。
- 与 `xn/n`：教育、纪念、组织和共同体持续传播原则，可能是主要内化中介。
- 与 `z`：被英雄认可、被成功证明或被群体表扬，改变的是确认位置，不是原则自完备性。
- 与 `nx`：继续执行英雄留下的路线或职位任务，只是沿既有方向推进。

### 拿掉测试

1. 拿掉甲的公开显权，只保留善举、牺牲或演说；乙若仍变化，源可能是 `zn/z/n`。
2. 拿掉英雄本人、胜利、奖励、宣传、纪念与共同体监督；乙仍坚持才支持目标。
3. 拿掉乙原有信念；必须证明原则真实新增，而非已有 `zn` 被唤醒。
4. 拿掉个人恩情、悲痛与关系余温；乙仍坚持普遍原则，才排除 `n/nz`。
5. 拿掉职位、制服、组织任务与行动惯性；乙仍在可退出时承担损失，才不是 `x/x并z/xn/nx`。
6. 拿掉原则执行的公开观众；乙仍行动，才达到无监督义务。

当前三个具体作品候选均未通过全部测试。

### 反向测试

```text
zx 生 zn 候选：
甲公开显权使原则进入现实
→ 乙在甲撤场后把原则转成自己的义务

zn 生 zx：
甲先有内部原则
→ 甲自己公开推进并取得现实决定位置
```

绝大多数英雄故事更直接证明反向 `zn 生 zx`。不能因甲既有原则又显权，就给同一人物补写 `zx 生 zn`。

### 动态链后果

```text
我看见他把原则推入现实
→ 我可能只是震撼、崇拜或跟随
→ 他失败、离场，宣传、胜利与奖励消失
→ 我仍在无人监督、可退出且会受损时执行同一原则
→ 原则才从“他的”变成“我的义务”
```

改变的是见证者对原则的内部归属、无监督执行与不可背弃度；不机械生成英雄崇拜、共同体、胜利、正义性或永久传承。

### 三元与十元并行

三元只核验作品整体精神运动；十元本轮只核验甲的公开权能端点、乙的内部意义端点、跨主体方向、第三因素和变量变化。不能从因果主题或英雄叙事反推关系成立。

### 95%门槛

高置信修正：

- 同主体“行动自证”不能作为 `zx 生 zn`：99%。
- 见证、震撼、崇拜、宣传、阵营追随与原则内化必须分开：99%。
- 源目标必须跨主体：98%。
- 最强证据必须发生在甲失败、离场、奖励与宣传停止后：98%。
- 乙必须从“敬佩他”转成“我有义务这样做”：98%。

正式机制仍未达到95%，原因是缺少两个同时通过全部拿掉测试的具体人物案例，并且 `zx` 可能只提供公开见证条件，真正内化仍由其他关系或乙的独立判断完成。
