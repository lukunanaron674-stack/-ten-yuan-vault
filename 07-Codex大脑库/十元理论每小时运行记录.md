## 源端点、目标端点、机制变量

### 源端点 `nx`

主体必须继续沿既有流程行动，不建立公开替代路线、不争夺最终解释权、不辞职、不停止关键职责；同时反复拥有明确、平等、可选择的背书或续签机会，却持续不进入。

不是：

- 主动拒签或撤名；
- 明确否决；
- 公开解释自己不认同；
- 揭露、辞职、停工；
- 没有机会、不可用或偶然缺席；
- 壳从未成功纳入主体。

### 目标端点 `x并z`

壳必须此前已真实成立，并被第三方用于归类、代表、调用或解释主体。目标变量限定为：

- 当前自愿代表资格；
- 当期“全体”覆盖范围；
- 续签状态；
- 第三方当期归因稳定度；
- 历史身份、历史背书与当前立场之间的距离。

行政身份、职责记录、历史署名和过去已经完成的背书不能因本轮未续签被倒写为消失。

### 成立阶段、体量与显影条件

```text
壳过去已真实覆盖主体
→ 新一轮当前代表资格需要可选择的主动背书
→ 主体继续基线流程且有同等机会
→ 不拒绝、不撤名、不解释，只不进入背书位置
→ 观察当期归因是否下降
→ 区分第三方主动改判与系统自动到期
```

低体量最多影响一次声明的覆盖范围；中体量可影响连续数轮的当期共同说法；稳定本体层和整个身份壳目前无证据支持。

## 候选机制与理论后果

### 候选 A：历史存量壳维持

```text
身份、职责、历史署名与过去背书已经成立
→ 主体不作新背书
→ 历史归类与旧记录继续存在
```

后果：没有发生克位。

### 候选 B：周期背书停止续生

```text
当前支持资格需要新一轮主动背书
→ 主体不进入续签位置
→ 新一轮背书没有生成
→ “全体当前支持”无法成立
```

后果：最多证明 `nx` 阻断当期共识背书的自愿续生，不等于既有 `x并z` 被削弱。

### 候选 C：预设到期规则自动撤销

```text
代表资格设有固定期限
→ 截止日到点
→ 所有未续签者统一失效
```

后果：直接作用源更接近 `xn/x` 的时间规则与状态管理。主体的 `nx` 只是没有启动新一轮生成条件。

### 候选 D：第三方主动缩小归因

```text
存量代表资格原本默认持续
→ 主体反复有机会但不进入可选背书位置
→ 无自动撤销规则
→ 第三方仍主动把“本人／全体”改为“外部标签／多数”
```

后果：这是当前最接近 `nx 克 x并z` 的极窄候选，但缺少具体人物案例，也难排除第三方解释规则本身的 `xn/z/x` 贡献。

### 候选 E：主动拒绝触发下降

```text
主体拒签、撤名、否决或声明不认同
→ 第三方停止代表主体
```

后果：目标变化清楚，但源动作可能已属于 `zn/z/x`，不能作为纯 `nx` 证据。

## 正例候选

### 1. 周期共同声明中的成员

组织过去已经把成员乙列入共同立场；新季度要求所有成员重新确认“当前仍支持”。乙继续普通职责，有同等机会，不拒绝、不解释，只是不续签。到期后声明从“全体当前支持”改为“多数支持”，历史成员身份与过去签署仍保留。

支持点：源动作接近纯 `nx`，目标变量落在当期自愿代表接口。

未通过：如果所有未续签者都由系统在截止日自动失效，直接作用源是预设期限和自动规则；只能判停止续生。

### 2. 工会或协会的周期立场确认

成员继续缴纳普通会费和完成基础职责，但不进入某一年度政治声明的主动确认界面。第三方随后不再把该成员列为当年度声明支持者。

支持点：历史成员身份与当前立场可以拆开。

未通过：资格变化通常由章程、数据库和统一截止日处理，`xn/x` 贡献明显；缺少具体人物文本。

### 3. 《好兵帅克》帅克

帅克继续军队命令和程序，源端较接近 `nx`；但军队仍能行政归类和调用他。被抽空的是忠诚英雄形象，不是正式身份覆盖或当期代表接口。

### 4. 《抄写员巴特比》巴特比

抄写员壳逐渐无法解释他，目标端较强；但他停止关键工作，已偏离继续基线流程的纯 `nx`。

## 最近邻排除

- `zn 克 x并z`：因为身份或立场“不对”而主动撤回意义认领。
- `z`：明确不给予认可、确认或共同立场。
- `x/xn`：撤销职位、名称、合同、权限、期限或数据库状态。
- `zx 克 x并z`：公开拆壳、揭露或夺取解释权。
- 生成失败：壳从未吸纳主体。
- 维护停止：只阻止壳再生产，不等于克制存量壳。
- 反向 `x并z 克 nx`：身份壳预设角色路线，压缩主体方向空间。

## 拿掉测试

1. 拿掉壳对主动续签的依赖，不进入是否完全无效？
2. 拿掉历史身份与旧记录，只观察当期代表资格。
3. 恢复续签后，当期资格是否恢复？
4. 拿掉拒签、撤名、否决和价值表态，第三方是否仍改判？
5. 拿掉辞职、停工、权限撤销和证据曝光，结果是否仍存在？
6. 第三方能否排除无机会、不可用、偶然缺席和从未纳入？
7. 未续签是否只阻断新一轮背书，没有错误抹除历史库存？
8. 拿掉自动到期和统一撤销规则，第三方是否仍主动缩小代表归因？
9. 若任何原因造成的未续签都在截止日产生相同结果，是否只能判 `xn/x` 规则？
10. 若存量代表资格原本会持续，主体不进入新背书后第三方仍主动改判，能否排除第三方自己的立场判断 `z`？

## 三元与十元并行核验

三元层只能记录：主体没有加入新一轮共同立场，群体说法覆盖缩小。

十元层必须另证：

- 源端仍是 `nx` 的不占立场位置；
- 目标端是已成立 `x并z` 的当期代表能力下降；
- 不是旧壳自然到期或新壳没有生成；
- 不是 `xn/x` 的期限与状态规则统一撤销。

“没续签所以名单少了一个人”不能自动派生为十元克位。

## 动态链后果

```text
这个壳过去已经能把我写进“我们”
→ 我仍履行基线职责
→ 新一轮支持需要主动确认
→ 我不拒绝、不解释，只不进入
→ 若截止日自动失效
→ 只是旧壳到期或当期背书未生成
→ 只有没有自动撤销规则时
→ 第三方仍主动缩小我的代表归因
→ 才继续接近 nx 克 x并z
```

改变的是当期自愿代表资格、共同覆盖范围或续生接口，不机械生成身份消失、组织崩塌、真相曝光或真实自我回归。

## 95% 门槛

高置信结论：

- 行政归类壳不因内心不认领而失效：99%。
- 完整履职通常维持职责壳：99%。
- 历史署名、过去背书和存量身份不能由本轮未续签倒写为消失：99%。
- 主动拒签、撤名和价值声明可能退出纯 `nx`：98%。
- 周期续期壳能让“不进入”变得可观察：97%。
- 预设期限自动失效首先属于旧壳到期、停止续生或 `xn/x` 状态规则：98%。
- “没有再次生成”不得直接写成“既有目标被克”：99%。
- 到期归因／反事实续生测试是必要门槛：98%。

正式机制未达到 95%。当前最多确认：

> `nx` 可能阻断共识背书壳的自愿续生，但尚未证明它直接削弱已成立的 `x并z`。

原因：

1. 缺少两个具体人物案例；
2. 最纯结构候选仍依赖周期规则；
3. 拿掉自动到期后，第三方主动改判可能又混入第三方 `z/xn/x`；
4. 尚未找到“存量壳原本持续，却仅因纯不进入而真实下降”的高纯事件。
