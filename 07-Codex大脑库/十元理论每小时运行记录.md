## 源端点、目标端点与被改变变量

### 源端点 `xz`

必须同时成立：

- 危险以可感知形态逼近；
- 安全路径、资源、时间窗口或退路真实减少；
- 主体不行动会被吞没、捕获或失去最后机会；
- 关键作用不依赖某个施害者的命令、惩罚、酷刑程序或长期制度训练；
- 不是仅有恐惧气氛、黑暗画面、创伤状态或未知信息。

体量：

- 低体量：一次惊吓或短暂风险，只能作用状态层；
- 中体量：持续压缩实践通道、迫使原则排序；
- 高体量：在排除第三因素后，主体持续改判原原则本身错误，且危险解除后不恢复。

### 目标端点 `zn`

危险前必须已有稳定证据：

> 即使没有奖励、认可和监督，这件事仍然是对的；不这样做，我就背弃了自己。

目标变化只允许落在：

1. 原则是否仍被判断为正确；
2. 原则是否仍拥有最终指导资格；
3. 原则是否从无条件改成“安全时才成立”；
4. 危险解除后是否继续维持新判断；
5. 同条件再次出现时是否继续按新原则判断；
6. 新判断能否迁移到与原危险无关的新场景；
7. 当利益方向反转时，是否仍维持新原则。

恐惧、逃跑、公开改口、行动失败、能力不足、创伤麻木和一次妥协均不足。

## 候选机制

### 候选 A：无条件原则被压成生存条件

```text
xz 持续逼近
→ 按原原则行动不断扩大毁灭风险
→ 主体把“无论如何都对”改成“只有安全时才对”
→ zn 的正确性与最终指导资格下降
```

理论后果：若成立，危险改变的不是勇气，而是原则的适用资格；动态感觉是“正确被生存条件降格”。

本轮评价：约92%，仍缺危险解除后持续改判的两例。

### 候选 B：多个 `zn` 重新排序

```text
多个内部意义同时存在
→ xz 使它们无法共同实践
→ 保存生命、保护更多人或承担更高责任取得优先级
→ 某一原则本次没有执行
```

理论后果：这不是 `zn` 总量下降，而是内部意义排序变化；原原则仍可能保持正确性，只在此次不占第一位。

本轮评价：作为排除解释约97%。

### 候选 C：实践通道被封死

```text
xz 缩窄时间、资源和路径
→ 主体仍认为原原则正确
→ 但无法把原则带入现实
→ 行为和显影下降，zn 内核保持
```

理论后果：作用只落在状态、能力和显影机会，不触及稳定原则。

本轮评价：作为排除解释约98%。

### 候选 D：危险揭露原本没有稳定 `zn`

```text
安全环境中重复原则、组织口号或身份规范
→ xz 到来后立刻放弃
→ 危险揭露此前依赖奖励、环境或身份
```

理论后果：目标端点原本未成立，不能判“被克”。

本轮评价：作为排除解释约98%。

### 候选 E：新事实进入导致 `zx` 改线

```text
危险带来新的事实或概率信息
→ 主体修正对现实的理解
→ 具体行动路线改变
→ 原原则底线仍保持
```

理论后果：应判 `x/xn` 信息更新后 `zx` 重新选择，不是 `xz 克 zn`。

## 最近邻排除

- `zx/xn` 强迫：施害者命令、惩罚、酷刑与制度流程主动压迫主体。
- `x/xn → zx`：新事实、概率、资源和时间信息进入后，具体行动改线。
- `zn` 内部排序：更高意义暂时取得优先级，原原则仍被认为正确。
- 状态遮蔽：恐惧、麻木、创伤、疲惫使原则难以显影。
- 能力与路径不足：主体认为正确，但现实上无法执行。
- `x并z` 公开壳变化：公开改口、悔过书、身份否认不等于内部原则改变。
- 原目标不存在：安全环境中的口号没有通过任何代价验证。

## 拿掉测试

1. 拿掉施害者、命令、酷刑流程和制度惩罚；只保留不可控自然临界。
2. 拿掉行为失败；只看主体是否明确改判原则错误。
3. 拿掉新事实纠错；确保不是对现实理解变化导致 `zx` 改线。
4. 拿掉更高原则替换；确保不是多个 `zn` 排序。
5. 危险解除后再承诺：安全恢复时是否仍拒绝原原则。
6. 同条件复判：相同代价再次出现时是否继续按新原则判断。
7. 跨场景迁移：在与原危险无关的新情境中是否维持新判断。
8. 利益方向反转：新原则不再有利于自身时是否仍成立。
9. 危险前稳定基线：此前是否已在无奖励和代价下坚持原原则。
10. 行动机会恢复：能再次实践时是否仍不按原原则行动，且原因是原则资格下降。

## 三元与十元并行

三元只核验作品整体从危险、压缩、取舍到原则复判的精神感觉与运动。

十元只核验：

- `xz` 是否真实由不可控临界、退路和窗口缩窄成立；
- 危险前是否已有稳定 `zn`；
- 变化是否落在原则正确性和最终指导资格；
- 危险解除后是否持续；
- 新事实、更高原则、施害者、制度、能力和状态是否已排除。

不建立“命运主题自动克本体主题”或三元父级派生。
