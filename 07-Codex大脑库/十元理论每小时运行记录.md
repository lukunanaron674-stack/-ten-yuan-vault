### 对象分层

- 稳定本体：`z` 是主体在重要认可位置获得明确确认；`nx` 是主体不占方向决定位置，沿外部方向、关系或既有通道推进。一次鼓励和一次跟随不能反推本体。
- 当前状态：重要认可发生后，主体可能在某项选择上取回方向位置；当前证据只支持状态层与局部关系层候选。
- 行为功能：`z` 显影为被看见、被回应、判断或能力获得确认；`nx` 显影为接受安排、等别人定方向、借既有关系推进。行为先后不等于克制。
- 光影：目光、署名、聚光、侧位、队列只作辅助显影。
- 场景：师徒、家庭、治疗、舞台、学校、公司均只是候选场景。
- 时间关系：认可先发生，方向认领随后上升；只有先后不能证明作用。
- 关系位置：认可者、被认可者、外部方向提供者可能是不同主体，必须分开。
- 显影：观察主体是否提出替代路线、使用否决权、承担自己选择后果，以及外部方向是否从唯一合法选项降为可拒绝选项。
- 动态链：从“只有别人安排的路才算合法”转成“我的判断也有资格成为方向”。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `z`：明确谁认可、认可什么、为何该位置重要，并且认可落到主体自己的判断、能力或选择，而不是普通命令、职位占位、公众注意或完成结果。
- 目标端点 `nx`：认可前主体确实不占方向决定位置，主要沿外部安排推进；不能把普通合作、暂时听取建议或借用资源直接判成 `nx`。
- 被改变变量：方向决定位置认领强度；对外部安排的唯一依赖度；提出替代方向的能力；否决权使用；是否仍只能借他者权限和关系网络推进。
- 成立阶段：认可前 `nx` 已存在 → 重要认可落到主体判断或能力 → 主体在无新增权限、资源和任务指令时提出并承担自己的路线 → 外部方向唯一合法性下降。
- 体量：低体量为一次具体选择取回方向；中体量为在一段关系中持续自行决定；高体量为稳定人物结构改变。当前只支持低至中体量候选。
- 显影条件：认可停止后主体仍保持自己的方向；若只出现情绪振奋、表现更好或继续追逐认可，不成立。

### 候选机制

- A 判断资格确认：重要认可主体确认“你的判断可以成立” → 外部安排不再是唯一合法方向 → 主体提出、选择并承担自己的路线 → `nx` 下降。理论后果：克制的是方向依赖，不是关系网络本身。
- B 能力资格确认：主体此前因不确定能力而沿别人安排 → 重要认可者确认其能力足以承担选择后果 → 主体取回否决与决定位置 → `nx` 下降。理论后果：若认可只让主体更卖力执行原安排，则不成立。
- 排除 C 认可者替主体决定：“重要人物持续决定和占位 → 主体退后”会使 `nx` 上升；源端点更接近 `zx`、`x` 或既有 `xn`，不是 `z 克 nx`。

### 正例候选

1. 《死亡诗社》托德与基廷｜课堂即兴诗阶段：基廷确认托德拥有自己的诗性声音，托德由沉默和依赖标准答案转为说出自己的语言。限制：基廷同时提供教学结构、强引导与照护，混入 `xn/n/zx`，不能证明纯 `z` 直接克制 `nx`。
2. 《跳出我天地》比利与父亲｜父亲支持舞蹈选择后：重要否定者转为确认比利的能力与选择，家庭给定路线不再是唯一现实方向。限制：比利在认可前已有强自主方向，更像 `z` 为既有非 `nx` 提供现实支持。
3. 导师与学生结构例：学生长期只按导师选题；导师明确确认其判断足以独立决定研究方向，随后不再给题，学生仍自行提出路线并承担结果。该结构比作品候选更纯，但仍缺第二个可核验人物案例。

### 反例

1. 老板表扬员工后，员工更认真执行老板安排：`z` 上升，`nx` 未降。
2. 父母说“我相信你”但仍替孩子决定学校和职业：认可与方向权分离。
3. 强势领导持续表达、决定和占位，使成员退后：更接近 `zx/x`。
4. 获奖后情绪高涨却没有新增决定权：只是状态变化。
5. 被看见后更依赖掌声：`z` 上升，甚至可能加强认可依赖。
6. 主体本来就有稳定方向，认可只提供资源和机会：目标 `nx` 原本不存在。
7. 认可者命令主体“独立一点”：仍是外部方向。
8. 认可后只是换了一个更喜欢的跟随对象：`nx` 结构未变。

### 最近邻

- 与 `zx`：公开权能决定、压过并重排现实位置；旧“持续表达和占位”属于这一邻近，不是现行 `z`。
- 与 `x`：若变化来自职位、资源、许可或放权，启动源是权限转移，不是认可本身。
- 与 `zn`：若主体因为“这件事无论如何是对的”而不再跟随，启动源是内部意义；`z` 只可能确认该判断获得关系资格。
- 与普通鼓励：鼓励改变情绪或努力强度；本候选必须改变谁有资格决定方向。

### 拿掉测试

1. 拿掉认可，只保留放权、资源或任务变化，主体仍取回方向，则不依赖 `z`。
2. 拿掉权限转移，只有认可，主体仍持续决定并承担结果，才支持直接作用。
3. 拿掉主体原有自主判断，认可后若仍只能等对方给方向，目标端点不存在。
4. 拿掉情绪振奋，只观察方向、否决与替代方案，关系仍成立才有效。
5. 认可停止后主体仍保持自己的方向，纯度高于继续追逐认可。
6. 当前两个作品候选均未通过完全拿掉 `n/xn/x` 与既有自主性的测试。

### 反向测试

```text
z 克 nx：重要认可确认主体自己的判断或能力 → 外部方向不再是唯一合法方向 → 主体取回方向位置。
nx 克 z：主体长期不呈现、不表达或不进入认可接口 → 认可无法发生或确认概率下降。
```

两方向改变的变量不同。旧占位口径交换后仍暴露源端点错误：强势主体压缩选择不是认可关系。

### 动态链后果

```text
重要的人确认：你的判断和能力可以成立
→ 外部安排不再是唯一合法方向
→ 主体开始提出并承担自己的路线
```

改变的是“谁有资格决定”的关系感觉，不是认可自动制造勇气、成熟、独立人格或稳定本体。
