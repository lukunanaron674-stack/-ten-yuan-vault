## 源端点、目标端点、阶段、体量与显影条件

### 源端点 `zx`

必须同时证明：

- 甲的权能公开进入现实；
- 甲的决定范围、影响位置或等级位置扩大；
- 旧秩序、他者或环境被迫围绕甲重新反应；
- 关键作用不只是演讲、善举、教学、长期坚持、完成任务或获得认可；
- 甲自己的公开行动可由其既有 `zn 生 zx` 解释，但本轮必须另证甲的 `zx` 改变乙。

### 目标端点 `zn`

乙必须新增或显著提高：

- 对明确原则的内部确定度；
- 在无奖励、无监督、英雄缺席、失败或失位时仍坚持的持续度；
- 将原则推广到新情境的能力；
- 原则与英雄本人、英雄身份、组织路线和共同利益的可分离度；
- 英雄后来背弃原则时，仍维护原则而不是维护英雄的稳定性。

不得把“被感动”“觉得他很强”“加入队伍”“重复口号”“穿上标志”“继续执行计划”直接当作 `zn`。

### 被改变变量

1. 乙对原则的内部确定度；
2. 无监督、无奖励与逆风条件下的持续执行度；
3. 原则与源人物的可分离度；
4. 原则跨情境泛化度；
5. 英雄失败、失位或背弃后原则是否仍保有最终指导资格。

被看见度、可行性判断、情绪强度、身份认同、组织服从、胜利预期、号召力和重新准入概率属于最近邻变量，不得顶替。

### 阶段、体量与显影条件

- 低体量：一次公开显权后，一个此前无稳定 `zn` 的见证者在源离场后独立维护原则。
- 中体量：一组见证者在英雄失败、失位或无奖励时仍将原则推广到新情境。
- 高体量：原则脱离英雄、胜利、身份壳与组织奖励，成为共同体内部长期义务。
- 显影条件：必须看到无人监督、逆风、失败、英雄缺席或英雄背弃后的持续选择。

## 候选机制

### 候选 A：权能差分使原则从“不可能”变成“可进入现实”

```text
甲以 zx 迫使现实围绕原则重新反应
→ 乙看到原则确实可以改变现实边界
→ 乙不再把原则视为无效愿望
→ 在甲离场后仍把原则当作自己的内部义务
→ zn 上升
```

理论后果：`zx` 改变的中介变量是原则的现实可实践性；目标变化只能先落在乙的状态或关系层。若乙只是因为成功才相信，优先判 `z` 的结果确认或工具理性。

本轮评价：约91%。`zn` 不依赖外部证明，候选仍存在结构冲突。

### 候选 B：公开承担代价取消“表演或谋利”解释

```text
甲以 zx 公开推进原则并承担失位、失败、惩罚或生命代价
→ 乙无法继续把甲的原则解释为谋利姿态
→ 原则与英雄个人逐步分离
→ 乙在英雄缺席和无奖励时继续坚持
→ zn 上升
```

理论后果：关键变量不是胜利，而是原则可信度与非工具性。若代价只显影甲已有 `zn`，乙的变化仍可能来自 `z`、`n/nz` 或共同利益。

本轮评价：约93%，为当前最强候选。

### 候选 C：显权后留下决定空位，目标继承原则而非权位

```text
甲以 zx 压过旧秩序
→ 甲失败、离场或失去权位
→ 现实留下新的决定空位
→ 乙不只是接替职位或执行计划，而把原则推广到新情境
→ zn 上升
```

理论后果：可以解释“英雄撤场—后继者独立实践”；若乙只是接任职位、复制路线或维持组织，优先判 `x/xn/nx`。

本轮评价：约88%。

## 反例

1. 强者获胜后群众加入胜方：利益、恐惧和胜利预期，不是 `zn`。
2. 英雄被授勋、建立纪念馆、海报、口号和仪式：优先是 `z/x并z/n/xn`。
3. 《浪潮》中学生因教师权威、制服、纪律和群体认同服从：更接近 `nx/x并z/xn`。
4. 学生被老师鼓舞后短期努力：情绪和状态变化，缺跨失败持续。
5. 目标人物原本已稳定相信同一原则：只是既有 `zn` 显影或强化。
6. 目标在英雄失位、失败或被揭露后立刻放弃原则：英雄依附、身份认同或路线跟随。
7. 目标只复制英雄具体动作和计划：更接近 `nx/xn`，没有原则泛化。
8. 魅影骑士、旗帜、领袖称号提高号召与准入：身份桥接，不是原则内化。

## 最近邻排除

- `zn 生 zx`：源人物常先有内部原则，再公开显权；这是源人物最稳的解释，不能倒过来证明乙变化。
- `z`：乙被英雄看见、认可或被结果说服，改变的是可信度，不一定是内部意义。
- `x并z`：旗帜、面具、魅影骑士、领袖称号和纪念物使原则可识别，但认领壳不等于认领原则。
- `n/nz`：共同体承载、关系余温、恩情和忠诚可使乙继续行动，但对象可能是人或关系。
- `xn`：传播、训练、教育、纪律、联盟组织和命令能稳定行为，不等于 `zx` 生成 `zn`。
- `nx`：跟随强者、接替路线和执行遗留计划，不等于目标主体占据内部意义位置。
- `x`：接替职位、武器、资源或组织权限，只说明掌握边界变化。

## 拿掉测试

1. **等曝光权能差分**：原则文本、曝光量、代价、传播与关系相同，仅提高源主体公开决定范围；目标 `zn` 是否显著不同。现无合格近控制组。
2. **同原则载体替换**：换成同样可信但 `zx` 较低的载体，目标是否仍内化。若仍成立，启动源可能是 `z`、教学或原则内容。
3. **去来源**：甲撤场、失败、死亡或失去奖励后，乙是否继续坚持。托德与罗伯特部分通过。
4. **原则泛化**：乙是否在全新情境维护同一原则，而不是复制动作。托德部分通过。
5. **英雄背弃**：甲后来背弃原则时，乙是否维护原则并与甲分离。现有候选无完整证据，是最大缺口。
6. **去胜利与奖励**：拿掉成功、掌声、称号、资源和晋升后是否仍坚持。
7. **去英雄壳**：拿掉面具、旗帜、魅影骑士、纪念与宣传后是否仍能表述并实践原则。
8. **去组织与监督**：拿掉训练、纪律、群体压力、联盟组织和指令后是否仍独立行动。
9. **去关系恩情**：拿掉友情、救命之恩、依恋和成员准入后，原则是否仍推广到陌生对象。
10. **既有 `zn`**：在甲显权前，乙是否已在代价情境维护同一原则；若是，只是显影或强化。

## 动态链后果

当前只允许写：

```text
他把原则以公开权能推到现实中
→ 我先看到原则能够迫使现实回应
→ 当他离场、失败或不再奖励我时
→ 我仍把原则用于新的选择
→ 原则从“他的主张”变成“我的内部义务”
```

感觉走向：

> 从“强者替我做成并规定局面”，转成“即使强者不在，我仍认为这件事必须由我继续”。

不得机械生成英雄崇拜、群体信仰、正义性、永久传承、全体成员 `zn`、胜利后的精神升华或稳定人物本体。

## 三元与十元并行

三元只核验作品整体从显权、见证到继承的精神感觉和关系运动。

十元只核验：

- 甲是否真实达到 `zx`；
- 乙此前是否没有稳定 `zn`；
- 乙是否在源撤场、无奖励、失败、英雄背弃与新情境中仍坚持；
- 权能差分是否独立于认可、英雄壳、关系、组织和共同利益。

不建立 `zx` 是 `zn` 父级、`zn` 是强者行动必然后果，或因果主题自动生成本体主题。
