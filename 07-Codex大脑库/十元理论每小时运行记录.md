### 对象分层

- 稳定本体：`zx` 是长期依靠公开显权、扩权与凌驾成立；`zn` 是长期不依赖奖励、认可和结果保证的内部意义确定。不能从一次演说、胜利、感动或牺牲反推本体。
- 当前状态：甲在某阶段公开成为现实决定中心；乙在后续阶段开始把某原则认作自己不可背弃的意义。当前候选只允许跨主体读取。
- 行为功能：甲公开夺回决定位置、迫使旧秩序重排并承担现实代价；乙在甲缺席、无人监督、可退出时仍按原则行动。追随、纪念、复述口号均不足。
- 光影：中心位、群众转向、牺牲构图、火炬、纪念光与孤独背影只作显影证据。
- 场景：革命、战争、公开审判、牺牲、传承、纪念与信仰题材均不能替代端点。
- 时间关系：乙此前无稳定 `zn` → 甲的 `zx` 公开进入现实 → 甲失败、离场或失去奖励 → 乙独立坚持。只有先后不足以证明生成。
- 关系位置：甲是显权者与现实决定中心；乙是见证者或后继者。甲自己的意义推动显权属于反向 `zn 生 zx`。
- 显影：观察乙能否把原则与英雄身份、胜利、口号、组织和奖励分离，并在无人观看时持续选择。
- 动态链：从“我看见他把原则推入现实”走到“即使他不在、失败了，我也不能放弃这个原则”。不机械生成信仰共同体。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `zx`：甲的力量必须公开进入现实，决定范围或等级位置扩大，旧秩序与他者被迫围绕甲重新反应；普通善举、演说、坚持与完成任务不足。
- 目标端点 `zn`：乙此前没有稳定原则认领；甲离场、失败、无奖励、无群众支持后，乙仍坚持原则本身，而不是英雄本人、群体身份或胜方阵营。
- 被改变变量：乙对原则的内部确定度、无监督持续行动强度、原则与英雄个人的可分离度、去掉胜利与奖励后的坚持度、从“他很强”转成“没人做我也必须做”的程度。
- 成立阶段：乙无既有 `zn` → 甲公开显权并把原则推入现实 → 甲承担可见代价 → 甲失败、离场或失去中心 → 乙在逆风中独立坚持。
- 体量：低体量为一次无人监督的原则选择；中体量为乙跨多个阶段反复坚持；高体量为原则脱离英雄和组织奖励后仍能由多主体独立维持，但高体量更容易混入 `n/xn/x并z`。
- 显影条件：甲乙必须分属不同主体；乙此前无稳定 `zn`；拿掉宣传、组织、纪念、胜方利益、个人恩情和甲本人后，乙仍按原则行动。

### 候选机制

- A 原则可进入现实的存在性证据：甲以 `zx` 使原则真实改变现实，乙由此确认原则并非空话。理论后果：`zx` 提供可行性证据；风险是若乙必须看到成功才相信，更接近 `z` 的结果确认。
- B 可见代价取消谋利解释：甲公开显权并承担位置、利益或生命代价，使乙确认甲并非借原则谋利；甲离场后乙仍坚持。理论后果：关键是原则与英雄个人分离；风险是代价首先显影甲既有 `zn`，乙变化可能来自 `z/n/nz`。
- C 决定空位由原则而非职位继承：甲压过旧秩序后离场，乙不继承甲的权位，而继承其原则义务。理论后果：真正生成点发生在甲离场后；风险是若乙只是接任职位或沿组织流程继续，更接近 `x/xn/nx`。
- D 竞争解释：英雄形象、海报、仪式、纪念、宣传和共同体扩散主要涉及 `x并z/z/n/xn`，不能直接证明 `zn`。

### 正例候选

1. 《饥饿游戏》凯特尼斯与第十一区民众｜露露死亡后的公开悼念：凯特尼斯以公开行动迫使都城权力重新处理她的影响，部分见证者可能认领“人不应被竞技消费”的原则。限制是长期压迫、悲痛、地区身份、传播符号与反抗组织过强，不能证明纯 `zx 生 zn`。
2. 《悲惨世界》主教与冉阿让｜银器宽恕之后：冉阿让后续形成稳定意义变化，目标端点清楚；但主教行为更接近 `zn/n/z`，其 `zx` 是否达到公开扩权与现实决定中心不足，只能作源端点反例校验。
3. 《黑暗骑士》蝙蝠侠与渡轮乘客｜小丑实验阶段：乘客在无奖励和无法保证获救时拒绝主动杀死另一船，目标 `zn` 候选可见；但法律道德、群体监督和两难结构过强，蝙蝠侠的 `zx` 与具体选择缺少直接链。

### 反例

1. 强者获胜后群众加入胜方：利益与胜利预期，不是 `zn`。
2. 英雄获授勋、称号后成为榜样：主要是 `z` 与 `x并z`。
3. 群众因恐惧服从夺权者：主要是 `nx` 或权力结果。
4. 追随者原本就相信同一原则：既有 `zn` 显影，不是新生。
5. 英雄牺牲后建立纪念馆：`n/xn/x并z` 的纪念结构。
6. 组织持续宣传英雄故事后群体认同：传播结构，不是独立内化。
7. 同一人物因自己已有原则而公开显权：方向是 `zn 生 zx`。
8. 乙只是继承甲职位、制服、口号或组织任务：更接近 `x/x并z/xn/nx`。

### 最近邻

- 与反向 `zn 生 zx`：甲先有内部意义，再公开推进，是现有多数英雄案例的真实方向；本轮必须证明甲的 `zx` 使另一个乙新增 `zn`。
- 与 `z`：被英雄认可、感动或确认改变的是精神认可位置，不等于无奖励的内部意义。
- 与 `x并z`：称号、旗帜、面具、海报和纪念仪式提供身份壳与可识别界面。
- 与 `n/xn`：共同体承载、教育、传播、训练与制度维持可以使原则延续，但不能倒写成 `zx` 直接生成 `zn`。

### 拿掉测试

1. 拿掉甲的公开显权，只保留善举、演说或个人牺牲；乙若仍变化，源端点可能是 `zn/z/n`。
2. 拿掉甲的胜利、奖励、英雄称号、纪念与传播；乙仍逆风坚持，才支持目标端点。
3. 拿掉乙原有信念；若变化无法证明，可能只是既有 `zn` 显影。
4. 拿掉甲本人，只保留原则；乙仍坚持，才能证明原则已与英雄分离。
5. 拿掉组织、教育、共同体监督和利益；乙仍无人监督行动，纯度才足够。
6. 拿掉个人恩情与关系余温；乙仍坚持普遍原则，才排除 `n/nz`。
7. 当前三个作品候选均未通过全部测试。

### 反向测试

```text
zx 生 zn：甲公开显权 → 乙新增内部意义，并在甲离场后独立坚持。
zn 生 zx：甲先有内部意义 → 甲自己公开推进、扩权并改变现实。
```

多数英雄故事首先证明后者。必须将甲自己的 `zn→zx` 与甲的 `zx→乙的zn` 分开，不能因两端最终同框就写反方向。

### 动态链后果

```text
我先看见他把原则推入现实
→ 我可能只是被力量、胜利或形象吸引
→ 当他失败、离场、失去奖励与符号中心
→ 我仍在无人监督时选择同一原则
→ 原则才从“他的”变成“我的”
```

改变的是见证者对原则的内部归属与不可背弃度，不机械生成英雄崇拜、共同体、胜利、正义性或永久传承。

### 三元与十元并行

三元只核验作品整体精神运动；十元本轮只核验甲的公开权能端点、乙的新增意义端点、跨主体作用和第三因素。不能从因果主题、本体主题、英雄结局或传承题材反推关系成立。

- 缺少两个完整展示“乙无既有 zn → 甲显权承担代价 → 甲离场后乙独立坚持”的具体人物阶段。
