## 3. 源端、目标端、变量与成立条件

### 源端`xz`

- 人物与阶段：主体进入无明确施害者主导的自然临界阶段。
- 人物行为与环境作用：死亡、永久失去、缺氧、失温、伤病或最后窗口逼近，安全路线和可执行条件收窄。
- 具体名词：自然临界、不可逆损失风险、最后窗口、退路收窄、多个必要对象无法同时保全。
- 排除：制度命令、施害者威胁、惩罚、职位裁决、主动胁迫与单纯心理想象。

### 目标端`zn`

- 人物与阶段：危险前已经跨阶段稳定运行，并承担最终判断资格的原则。
- 具体名词：原则核心、正确性判断、最终指导资格、适用范围、例外边界、反事实指导资格。
- 被改变变量：人物是否仍认为原则本身正确；条件恢复时是否仍应执行；原则是否继续参与最终排序；是否只撤回无条件条款。
- 排除：仅停止当前行动、撤退、切绳、换路线、增加例外、短期创伤回避与身份任务结束。

### 成立阶段、体量与显影条件

- 低体量：危险中暂停执行，只记实践通道压缩。
- 中体量：人物撤回“任何情况下都必须执行”，改成有条件原则，只记适用范围校准。
- 高体量候选：危险解除、能力恢复、对象仍存在后，人物在安全可执行新情境中仍明确否定原则核心与正确性。
- 显影条件：冻结新事实、永久损伤、创伤、身份退出、对象消失、施害者压力、制度命令和竞争原则。

## 4. 候选机制

### A｜原则核心与最终资格持续下降

```text
自然危险显示原原则会反复导致不可接受的整体损失
→ 危险解除后人物仍认为原则本身错误
→ 在安全可执行的新情境中也拒绝它
→ zn原则核心与最终指导资格下降
```

严格候选由约89%降为约87%。当前缺少能够冻结新事实、永久损伤、身份变化和竞争原则的两组纯案例。

### B｜原则暂停调用与实践通道压缩

```text
自然危险关闭能力、时间、路线或对象条件
→ 人物暂时无法执行原则
→ 原则不参与当前行动
→ 条件恢复后重新调用
```

竞争解释约99%。此时下降的是可执行性与当前显影，不是原则正确性。

### C｜无条件版本撤回、条件化与元原则统摄

```text
人物原本把原则理解为无条件命令
→ 危险暴露原则与主体、对象或其他必要责任的冲突
→ 人物加入例外、优先级或更高元原则
→ 原原则核心继续在适用条件中运行
```

这属于边界校准、排序或元原则重写，不等于`zn`被克。

## 5. 正例候选

1. **Simon Yates与Joe Simpson，切绳阶段**：Simon在自己也将被拖落的临界中切断绳索，表面撤回“不抛弃同伴”的无条件版本。但他并未因此判定同伴责任本身错误；案例同时混入Joe生存概率判断、无法沟通及“至少保住一人”的竞争原则，更支持条件化与排序。
2. **Aron Ralston，《127小时》获救后的生活方向变化**：事故使其极端自足与独行原则失去原有位置，之后更强调关系与告知他人。但变化同时混入创伤、新事实、身体损伤与身份重构，无法证明纯自然危险直接克制原则核心。
3. **Beck Weathers珠峰灾难后**：高风险登山不再拥有原有最终指导位置，但永久损伤、创伤、登山者身份变化与家庭原则重排全部参与。
4. **严格控制候选**：救援者在自然临界后身体、能力、路线和对象全部恢复；不存在新事实与竞争原则。在安全且确实可救的新事件中，他仍明确认为“应救助可救者”这一原则本身错误，而不是仅拒绝必死式牺牲。当前缺两组可核验材料。

## 6. 反例

1. 《火星救援》中的Watney不断改变方案，但“活下去并解决问题”的原则持续运行：只有路径变化。
2. Apollo 13放弃登月转为返航：目标排序变化，不是探索意义被克。
3. 消防员因楼体坍塌撤退，条件恢复后继续救援：实践通道暂时关闭。
4. 登山者因失温放弃登顶，康复后再次登山：能力和状态变化。
5. 父母在灾难中放弃事业保护孩子：多个`zn`重新排序。
6. 人物仍认为应该救人，只是不接受无效必死式牺牲：无条件版本撤回，原则核心保留。
7. 危险后人物暂时回避同类场景，但冷却和治疗后恢复：创伤遮蔽，不是原则资格下降。

## 7. 最近邻排除

- `xz 生 zx`：危险生成临时公开决定接口，不处理原则核心下降。
- 多个`zn`排序：某原则让位不等于被克。
- 新事实纠错：人物因信息更新改变判断。
- 能力损伤：不能执行不等于认为不应执行。
- 身份退出：不再承担角色不等于原则错误。
- 创伤回避：状态遮蔽实践，不改写原则正确性。
- 元原则统摄：旧原则被更高规则限定适用范围，但仍保留。
- `zn 克 xn`：意义撤回结构维护资格，目标变量不同。

## 8. 拿掉测试

1. 拿掉危险，只保留新事实，检查原则是否仍变化。
2. 拿掉新事实，只保留危险体验。
3. 恢复身体、能力、资源、路线、时间与现实对象。
4. 冻结家庭、生存、荣誉等竞争原则。
5. 排除施害者、制度命令、身份转换和永久损伤。
6. 设置危险解除后的冷却复判，排除即时恐惧。
7. 换到原原则可以安全执行的新情境。
8. 设置第二次安全窗口，排除创伤回避。
9. 直接询问反事实判断：“若条件允许，该原则是否仍正确且应执行？”
10. 区分原则核心、无条件条款、例外边界、适用范围和当前调用状态。

现有案例均未通过完整组合测试。

## 9. 反向测试

`zn 克 xz`不在现行克位。原则可以提高人物承受危险、坚持行动或组织选择的能力，但不能因此临时生成反向关系。

```text
危险解除后原则恢复
＝实践通道压缩

原则在危险中暂停，但反事实上仍被判定正确
＝原则暂停调用

原则变成条件版本并继续运行
＝适用范围校准

原则被更高元原则限定
＝排序或元原则统摄

安全可执行新情境中仍否定原则核心
＝才接近xz克zn
```

## 10. 动态链后果

```text
原原则曾被人物当作无条件答案
→ 自然临界关闭实践通道并迫使多个必要对象竞争
→ 人物暂停调用、撤回无条件条款或重新排序
→ 原则边界与更高元原则显形
→ 若条件恢复后仍认为原则正确，zn未被克
→ 若安全新情境中仍拒绝原则核心，才接近最终资格下降
```

只改变原则面对现实边界时的感觉走向，不机械生成背叛、犬儒、成长、成熟或人格崩坏。

## 11. 三元与十元并行核验

三元观察：人物是否停止行动、对象是否仍存在、危险解除后是否重新实践。

十元区分：
- `xz`：自然临界、失去窗口与路径收窄；
- `zn`：原则核心、正确性与最终指导资格；
- `xn`：程序、命令与结构维护；
- `n`：承载、保护与恢复条件；
- 其他`zn`：竞争原则与排序。

三元与十元并行，不写成父子派生。
