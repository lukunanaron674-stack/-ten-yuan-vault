### 对象分层

- 稳定本体：`nz` 是长期保留共同时间、关系余温与回返位置；`nx` 是长期不占最终方向决定位置。一次同行或一次让步不能反推稳定本体。
- 当前状态：主体在某段关系中不愿结束，并暂时把最终路线交给对方；最可能先落在关系层或状态层。
- 行为功能：等待、回返、延长共同时间属于 `nz`；撤回自己的可行路线、停止使用否决并沿对方最终路线推进才触及 `nx`。
- 光影：暖光、旧路、并肩、侧位与跟随构图只作显影。
- 场景：重逢、旅途、亲子、师徒和逃亡不能替代端点。
- 时间关系：关系余温先成立、方向让位随后发生，只是必要序列。
- 关系位置：双方必须平等可选；年龄、监护、职位、专业与资源优势会污染方向权判断。
- 显影：主体是否明确撤回自己的路线，对方路线是否成为最终路线，以及拿掉余温后让位是否消失。
- 动态链：关系不愿结束是否使主体退出最终方向位置，不机械生成人格软弱或永久服从。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `nz`：双方已有真实共同时间、关系余温、不愿结束与可信回返位置；一次好感、怕孤独、现实依赖和恋爱题材不足。
- 目标端点 `nx`：主体原本有可行替代路线和真实否决权，随后撤回自己的最终路线，并把决定资格交给关系对象。
- 被改变变量：最终方向认领强度、否决权实际使用、替代路线保留度、非对称让位程度、拿掉关系余温后的方向恢复度。
- 成立阶段：关系已形成余温 → 双方出现路线分歧 → 主体拥有可行替代路线 → 为避免关系结束而撤回自身路线 → 沿对方最终路线推进。
- 体量：低体量是一次关键路线让位；中体量是在一段关系中反复交出最终方向；高体量是稳定人生路线依附。当前证据最多支持低至中体量候选。
- 显影条件：双方平等、可自由拒绝，无年龄、任务、照护、安全、危险、资源、专业、职位和命令优势；拿掉余温后让位消失。

### 候选机制

- A 可信停靠降低独自定向负担：共同时间与回返位置使主体不再认为每一步都必须独自决定。理论后果：最多解释建议接受度或暂时跟随，必须继续证明最终方向位置真实下降。
- B 为维持关系主动撤回方向竞争：主体判断坚持自己的路线会导致共同位置断裂，因此撤回否决和替代路线。理论后果：若成立，只能先落在关系层或状态层。
- C 共同协商：双方形成第三条路线。理论后果：双方仍保留方向位置，不构成 `nx`。
- D 第三因素服从：年龄、照护、任务、资源、危险、专业或职位给出方向。理论后果：`nz` 只与 `nx` 共现，不是启动源。

### 正例候选

1. 山姆与弗罗多，进入魔多与末日火山阶段：长期共同旅程形成强关系余温，山姆沿弗罗多与魔戒使命的最终路线推进。限制：守护意义 `zn`、既定任务 `xn`、照护 `n` 与危险 `xz` 均过强，无法证明 `nz` 独立生成 `nx`。
2. 《末路浩劫》男孩与父亲，长期向南阶段：父亲是唯一可信关系停靠，路线与风险判断由父亲决定。限制：年龄、监护、保护与生存危险决定了原本不平等的方向位置。
3. 旧友重逢结构例：双方平等、路线等价，一方只因不愿再次分离而撤回自己的路线。端点结构较纯，但缺少可核验具体人物文本，不能代替第二个作品正例。

### 反例

1. 杰西与席琳继续散步和交谈：只是共同时间延长与持续协商。
2. 关系深厚但双方各自坚持职业与城市路线：`nz` 成立，`nx` 不上升。
3. 接受医生、导师或专业人员安排：专业与照护位置给出方向。
4. 孩子跟随父母：年龄与监护决定路线。
5. 恋人以分手威胁服从：`x/zx/z` 压力，不是余温直接生成。
6. 对方提供住房、资金或安全后留下：现实依赖与 `n/x`。
7. 双方共同形成第三条路线：共同决策，不是单方方向让位。
8. 主体原本就是稳定 `nx`：关系只是显影机会。

### 最近邻排除

- 与 `n`：`n` 改变能否被接住与安全停留；本轮候选改变谁拥有最终方向。
- 与 `z 克 nx`：`z` 候选使主体重新认领方向；`nz 生 nx` 候选则使主体为保留关系而减少方向认领。
- 与 `x/zx`：资源、威胁、职位和显权导致服从时，不能归给关系余温。
- 与共同协商：协商保留双方方向资格；`nx` 要求一方退出最终决定位置。

### 拿掉测试

1. 拿掉 `nz`，若主体仍因任务、年龄、资源、职位、专业或危险跟随，不成立。
2. 拿掉对方命令、威胁和占位后，主体仍主动撤回自己的路线，才支持候选。
3. 拿掉照护、安全与资源依赖后，让位仍存在，纯度才上升。
4. 拿掉共同时间，只剩一次温柔或好感，源端点消失。
5. 拿掉方向变化，只剩陪伴、听建议或路线协商，目标端点消失。
6. 恢复替代路线和否决机会后，主体仍主动不用，才触及 `nx`。

两个作品候选均未通过全部测试。

### 反向测试

```text
nz 生 nx 候选：关系余温先成立 → 主体为避免关系结束而撤回自己的最终路线 → 沿对方方向推进。
nx 生 nz 候选：主体长期沿对方方向共同生活 → 共同路径积累时间厚度 → 形成不愿结束和回返余温。
```

两方向可能形成反馈，但不能因最终同时存在共同时间与跟随就互相代证。

### 动态链后果

```text
我不愿这段关系结束
→ 我愿意继续同行，也更认真听你的方向
→ 只有当我撤回自己的可行路线
→ 让你的路线成为最终路线
→ 才进入 nz 生 nx 候选
```

改变的是关系中的最终方向认领，不机械生成永久服从、人格软弱、健康关系或正确选择。

### 95%门槛

高置信修正：

- 延长共同时间、提高建议接受度、共同协商均不等于 `nx`：99%。
- `nx` 目标端点必须是非对称最终方向让位：98%。
- 双方平等可选、主体原有可行路线与否决权是硬门槛：98%。
- 年龄、任务、照护、危险、资源、专业和职位必须拆开：99%。
- 若成立，优先限定为关系层或状态层：97%。

未达到95%的核心机制：

- 缺少两个高纯具体人物案例；
- 现有作品候选无法排除任务、照护、年龄、危险与既有不平等；
- 仍不能证明 `nz` 独立生成 `nx`，而非只提高建议权重或提供跟随的显影机会。

结论：几何位置保留；窄候选保留；正式机制未锁定；不新增待确认问题，原因是当前仍是案例纯度不足。
