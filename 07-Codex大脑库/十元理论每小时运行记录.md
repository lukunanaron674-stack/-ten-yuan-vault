### 源端点、目标端点与变量

源端点 `nz`：双方此前真实共同生活、同行或共同阶段，已经形成关系余温、回返位置与不愿关系彻底结束的倾向。一次好感、怕孤独、临时照顾、恋爱题材和现实依赖不足。

目标端点 `nx`：主体原本拥有可行替代路线、真实否决权和承担结果的能力；随后不再占最终决定位置，不提出自己的替代路线，并持续沿关系对象的路线推进。

被改变变量：

1. 主体是否仍认领最终路线；
2. 替代路线是否被主动保留；
3. 否决权是否仍实际使用；
4. 首次让路是一次自主委托，还是跨阶段方向不占位；
5. 关系安全后是否恢复自己的路线；
6. 持续不占位究竟来自 `nz`，还是习惯、路径依赖、共同结构、目标融合或原有 `nx`。

成立阶段与体量：

```text
低体量：为了不分开而一次选择对方路线，只能判关系保全型方向委托。
中体量：关系危机解除后，在该段关系中仍反复不提出替代路线，触及状态层或关系层 nx 候选。
高体量：长期把人生最终方向交给关系对象，必须优先排除稳定 nx 本体、控制、资源依赖与共同生活结构。
```

显影条件：双方平等可选，各自有现实可行路线；无年龄监护、职位命令、任务预设、资源依赖、照护安全、危险压迫和专业能力差。

### 候选机制

#### 候选 A：关系保全产生一次自主委托

```text
主体不愿关系结束
→ 判断坚持自己的路线会造成分离
→ 主动选择对方路线
→ 共同时间得以继续
```

理论后果：`nz` 可以改变本次路线选择，但主体仍在使用自己的最终决定权，因此不足以证明 `nx` 已生成。

#### 候选 B：关系安全后仍持续不恢复方向

```text
首次为了关系让路
→ 关系危机解除
→ 对方明确保证恢复自主路线也不会导致分离
→ 主体仍跨阶段不提出替代路线、不使用否决
→ nx 候选上升
```

理论后果：这是目前唯一能继续审计直接机制的窄入口，但必须排除习惯、路径依赖、共同生活结构、目标融合与稳定 `nx`。

#### 候选 C：共同结构或习惯接管

```text
首次让路后共同生活持续
→ 日程、资源、任务与习惯围绕对方路线固化
→ 主体不再重新开路线
```

理论后果：持续不占位由 `xn/n/x` 或路径依赖维持，`nz` 只解释首次委托，不解释完整 `nx`。

#### 候选 D：共同协商或目标融合

```text
双方各自保留方向资格
→ 形成第三条共同路线，或对方路线已成为主体自己的目标
```

理论后果：没有一方退出最终方向位置，不构成 `nx`。

### 正例候选

1. **山姆与弗罗多｜进入魔多与末日火山阶段**：长期共同旅程形成强关系余温，山姆持续沿弗罗多与魔戒任务的方向推进。限制是守护意义 `zn`、既定任务 `xn`、照护 `n` 与危险 `xz` 均过强；关系安全从未真正恢复，无法执行本轮新增测试。
2. **《末路浩劫》男孩与父亲｜长期向南阶段**：父亲是男孩唯一可信停靠，男孩沿父亲路线行动。限制是年龄、监护、保护、危险和原本不平等的决定权，不能证明平等主体由 `nz` 生成 `nx`。
3. **《最后生还者》艾莉与乔尔｜前往火萤基地阶段**：共同旅程与依恋明显，艾莉长期沿乔尔的判断行动。限制是年龄、护送任务、危险、照护与专业差异；同样无法证明关系安全后仍由 `nz` 维持方向不占位。
4. **旧友重逢结构例**：双方各有同等可行路线，一方只因不愿再次分离而选择对方路线。该结构能够证明一次方向委托，但若对方保证恢复自主路线也不会分开，主体是否仍持续不占位尚无具体作品证据。

### 反例

1. 杰西与席琳继续散步和交谈：共同时间延长，路线持续协商，双方都未退出方向位置。
2. 关系深厚但各自坚持职业、城市和生活路线：`nz` 成立，`nx` 不上升。
3. 接受医生、导师或专业人员安排：方向来自专业位置、`n` 或 `xn`。
4. 孩子跟随父母：年龄与监护决定路线。
5. 恋人以分手威胁服从：启动源是 `x/zx/z` 压力。
6. 对方提供住房、资金或安全后留下：现实依赖与 `n/x` 污染。
7. 双方形成第三条路线：共同决策，不是单方 `nx`。
8. 主体首次为了关系让路，但对方保证关系不会结束后立即恢复自己的路线：只成立一次自主委托。

### 最近邻排除

- 与 `n`：`n` 改变能否被接住、安全停留和返回；本轮目标是最终方向是否持续让出。
- 与 `z 克 nx`：重要认可使主体重新取得判断资格；本轮候选使主体因关系余温少占方向。
- 与 `x/zx`：威胁、资源和显权压缩方向，不属于 `nz` 直接作用。
- 与 `xn`：共同日程、任务与生活结构可以维持既定路线，但不是关系余温直接生成方向不占位。
- 与共同协商：协商保留双方最终方向资格。
- 与自主选择：为了关系选择对方路线的瞬间，主体仍可能正在使用自己的最终决定权。

### 拿掉测试

1. 拿掉 `nz`，若仍因任务、年龄、资源、危险、职位或照护跟随，不成立。
2. 拿掉命令、威胁与对方主动占位后，主体仍让路，才支持关系余温作用。
3. 拿掉照护、安全与资源依赖后，让位仍存在，纯度才上升。
4. 拿掉共同时间，只剩一次好感，源端点消失。
5. 拿掉路线撤回，只剩陪伴、建议和协商，目标端点消失。
6. 关系对象明确保证恢复自主路线不会使关系结束，主体是否仍跨阶段不恢复路线？
7. 拿掉共同日程、任务、生活结构和目标融合后，持续不占位是否仍存在？
8. 证明主体此前并非稳定 `nx`；否则关系只是显影机会。

现有具体人物案例均未通过第六至第八项组合测试。

### 反向测试

```text
nz 生 nx 候选：
关系余温先成立
→ 主体首次自主选择对方路线
→ 关系安全后仍持续不恢复最终方向

nx 生 nz：
主体长期沿对方方向共同生活
→ 共同路径积累时间厚度
→ 形成不愿结束与回返余温
```

两方向可能形成反馈，但不能因为最终同时出现“同行”和“不舍”就互相代证。反向 `nx 生 nz` 更容易由长期共同路径直接解释。

### 动态链后果

```text
我不愿这段关系结束
→ 我主动选择你的路线
→ 这一步仍是我的自主决定
→ 你明确保证我恢复自己的路线也不会失去关系
→ 我仍跨阶段不再开启自己的路线
→ 再排除习惯、共同结构与原有 nx
→ 才能继续审计 nz 是否生成关系层 nx
```

改变的是关系中的最终方向认领持续度，不机械生成永久服从、人格软弱、健康关系、正确选择或共同终局。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验 `nz` 是否真实成立、首次让路是否仍属自主决定、关系安全后主体是否持续不占最终方向，以及持续性是否由习惯、结构与其他十元维持。三元与十元并行，不把 `nz` 写成 `nx` 的父级，也不从命运主题倒推因果关系。

### 95%门槛

高置信结论：

- 延长共同时间、接受建议和共同协商不等于 `nx`：99%。
- 主体主动选择对方路线时，该动作仍可能是自主方向行为：98%。
- 一次方向委托不等于持续方向不占位：99%。
- 关系安全保证测试是区分“怕分离”与持续 `nx` 的必要门槛：97%。
- 关系安全后仍不恢复路线，必须排除习惯、路径依赖、共同结构、目标融合与稳定 `nx`：98%。
- 年龄、任务、照护、危险、资源、职位和专业差必须排除：99%。
