## 本轮性质

本轮只审计 `z 生 nz`。没有修改核心生补克表、关系词典、专项索引、旧审计或待确认队列，也没有新建专项。新推进是增加“零评价窗口／非评价冲突修复测试”，进一步分开：

```text
认可使被认可者想再次回来
```

与：

```text
双方已经形成能脱离评价职能独立存在的可回返关系
```

## 源端点、目标端点、变量、阶段、体量与显影

源端点 `z`：必须明确认可主体是谁、认可谁或什么、为何该位置重要，以及确认是否真实落到主体。掌声、曝光、获奖、录取、签约与泛泛称赞不足。

目标端点 `nz`：停止评价、奖励、推荐、资源、职位与任务以后，双方仍分别主动维护并兑现再次进入、相见、普通相处或非评价性共同内容；关系不得依赖被认可者继续追逐评价，也不得依赖认可者继续确认同一能力或作品。

被改变变量：被认可者的单方回返意愿；认可者是否独立保留进入资格；双方主动发起比例；关系内容中评价功能占比；零评价阶段的持续时间；非评价冲突后的修复能力；关系是否能承受负向评价而不退回评价者—被评价者角色。

成立阶段：重要认可真实发生；评价、奖励和任务撤场；原被认可对象退出互动中心；双方进入零评价窗口；发生与评价无关的普通分歧；双方仍主动修复并保留回返位置。

体量：低体量为被认可者一次回访或单方想念；中体量为评价撤场后双方主动保持普通联系与相处；高体量要求关系跨多个非评价阶段持续、经历普通冲突仍能修复。当前没有高纯证据支持中高体量直接生位。

显影条件：没有作品展示、能力评价、推荐、奖励、资源、任务和身份利益；双方仍主动联系、相见、分享普通生活；负向评价或普通冲突后仍能修复。

## 候选机制与理论后果

### 候选 A：认可生成单方关系提议

```text
重要认可真实落到主体
→ 被认可者不再只把对方当评判位置
→ 产生再次回到其面前的愿望
```

理论后果：可解释单方回返意愿，但不能证明完整 `nz`。

### 候选 B：认可者独立接受

```text
被认可者提出回返
→ 认可者停止评价和利益供给
→ 仍主动保留并兑现进入资格
→ 双方分别维护关系
```

理论后果：更接近完整 `nz`；但认可者的第二个主动动作是否由最初 `z` 生成，仍未证明。

### 候选 C：零评价窗口

```text
原被认可对象退出互动中心
→ 双方一段时间内不评价彼此的能力、作品或选择
→ 仍主动保持普通相处、回返与非评价共同内容
```

理论后果：能排除持续认可依赖，是本轮新增必要门槛。

### 候选 D：非评价冲突修复

```text
双方因时间、边界、日常安排或其他非评价问题发生分歧
→ 不退回导师—学生、治疗者—来访者、评委—选手角色
→ 双方仍主动修复并保留关系入口
```

理论后果：若通过，关系价值才较可能独立于评价职能；当前缺少高纯案例。

### 候选 E：持续认可依赖

```text
我还想被你评价
→ 所以继续靠近你
```

排除。它只是 `z` 延续。

## 正例候选

1. **《心灵捕手》威尔与肖恩｜治疗结束与告别阶段**：肖恩的重要确认使威尔不再只把他当治疗者，单方回返和告别重量清楚。但长期治疗包含强 `n/xn`；影片没有充分呈现一段完全停止心理解释与能力判断的零评价窗口，也缺少非评价冲突后的关系修复。
2. **《国王的演讲》伯蒂与莱昂内尔｜演讲任务完成后的关系阶段**：任务结束后关系继续成为友谊，较接近双方维护。但长期训练、陪伴、共同任务与历史时间厚度足以独立生成关系；无法证明最初认可是直接生成源。
3. **《寻找佛罗斯特》贾马尔与佛罗斯特｜写作指导后期**：认可位置清楚，双方逐渐具有超出单次写作评价的关系价值；但关系由长期写作训练、互助、秘密共享与承载共同形成，仍混入 `xn/n/nz`。
4. **导师确认学生创作语言的结构例**：导师毕业后不再评价作品、提供课程、资源或推荐；双方仍分别主动维持普通关系，并在生活边界冲突后修复。结构能通过本轮测试，但缺少可核验具体人物文本。

## 反例

1. 获奖后舍不得离开领奖台：当前状态。
2. 被偶像点赞后继续追逐回应：持续 `z`。
3. 因推荐、职位、资源或签约维持联系：利益与结构接口。
4. 长期治疗、训练或共同任务结束后不舍：优先检查 `n/xn`。
5. 只有联系方式、关注账号、礼貌邀请或“以后合作”：接口未兑现。
6. 后续互动始终围绕作品评价与能力确认：评价功能没有撤场。
7. 认可者给出负面评价后关系立即断裂：关系仍依赖正向确认。
8. 双方只有被认可者主动联系，认可者从不主动回应或发起：单方提议。
9. 关系在普通边界冲突后只能靠认可者再次夸奖主体恢复：仍退回评价角色。
10. 认可前已有深厚友情，认可只是命名已有关系：目标并非从无到有。

## 最近邻排除

- `n`：长期被接住形成的不舍不能归给认可。
- `xn`：训练、治疗和共同任务提供重复时间与互动结构。
- `z` 延续：继续追逐评价不等于停靠。
- `nz 生 z`：原有关系余温先推动作品、表达或回返寻求确认，方向相反。
- 既有友情：认可可能只是给已有关系命名。
- `x/x并z`：资源、职位、身份与公开壳维持进入接口，不是关系自愿回返。

## 拿掉测试

1. 拿掉认可，只保留照护、训练、任务与友情，关系是否仍持续？
2. 拿掉奖励、推荐、资源、职位、任务与继续评价，双方是否仍主动维护？
3. 拿掉被认可者单方想念，认可者是否仍主动发起并兑现进入？
4. 拿掉礼貌邀请、联系方式和关注账号，真实回返是否发生？
5. 拿掉原被认可的作品、能力或选择，关系是否仍有独立内容？
6. 认可者后来给出负向评价，双方是否仍维护关系？
7. 设置完整零评价窗口，双方是否仍主动相处？
8. 发生与评价无关的普通分歧后，双方是否能修复而不退回评价角色？
9. 换成同等级评价者，原关系是否可完全替代？
10. 拿掉 `n/xn` 和既有友情后，认可是否仍独立生成双向时间厚度？

现有具体案例均未通过第7、第8、第10项组合。

## 反向测试

```text
z 生 nz 候选：
重要认可先发生
→ 评价功能撤场
→ 双方进入零评价窗口并维持普通关系
→ 非评价冲突后仍修复并保留回返位置

nz 生 z：
关系余温与不舍先成立
→ 主体通过作品、表达或回返寻求确认
```

毕业、谢幕、治疗结束和最终作品不能同时给两个方向重复计账。

## 三元与十元并行核验

三元层只能记录：某次确认后双方更愿意继续联系，或共同阶段结束时出现不舍。

十元层必须另证：源端是明确重要认可；目标端是双方可回返关系；评价职能、利益与任务撤场后关系仍独立存在。三元中的“被看见后舍不得”不能自动派生为十元 `z 生 nz`。

## 动态链后果

```text
你真正确认了我
→ 我想再次回到你面前
→ 这最多是单方关系提议
→ 评价、奖励、资源与任务全部停止
→ 我们一段时间不再评价原作品或能力
→ 仍分别主动维持普通相处与回返
→ 发生与评价无关的分歧
→ 我们仍修复关系而不退回评价角色
→ 才继续接近可信可回返关系
```

改变的是认可位置能否跨阶段转成双方独立维护的关系接口，不机械生成友情、爱情、依赖、归属、永久合作或健康关系。

## 95%门槛

高置信结论：

- 完成、获奖、录取、掌声与签约不能直接生成 `nz`：99%。
- 持续追逐认可不是停靠：99%。
- 单方回返只构成关系提议：98%。
- 完整目标需要认可者独立接受并由双方维护：98%。
- 评价对象撤场与负向评价存续是必要门槛：98%／97%。
- 零评价窗口可排除持续评价依赖：98%。
- 非评价冲突修复可检验关系是否真正脱离评价角色：97%。
