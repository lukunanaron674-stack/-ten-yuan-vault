### 对象分层

- 稳定本体：`nx` 是长期不占方向决定位置、沿他者或既有通道推进；`x并z` 是长期稳定、可被世界读取和调用的身份壳。一次沉默或一次拒签不能反推稳定本体。
- 当前状态：主体仍处在既有流程中，但暂时不提供身份壳所需的可选认领、复述、署名或象征履行；候选最多先落在关系层或状态层。
- 行为功能：继续基线流程属于 `nx` 证据；不签署、不复述、不允许署名或不参与可选仪式是候选入口。辞职、停工、公开拒绝和建立替代身份不是纯 `nx`。
- 光影：侧位、沉默、制服、面具、队列和无表情只能辅助显影。
- 场景：公司、军队、组织声明、宗教仪式、学校和家庭不能替代端点。
- 时间关系：身份壳必须先真实覆盖主体，随后可选背书撤回，第三方覆盖再下降；壳从未吸纳主体不叫被克制。
- 关系位置：主体是已被壳代表的成员；壳发布者或第三方依赖主体持续接口维持“本人/全体”的代表资格。
- 显影：第三方是否从“本人立场、全体成员”改读为“外部标签、行政成员或多数成员”，以及壳能否继续引用主体姓名和行为证明自身。
- 动态链：主体仍走在既有通道里，却停止把自己的名字借给“我们都这样”的共同壳；不机械生成揭露、辞职、真实身份回归或组织崩塌。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `nx`：方向与基线流程仍由外部关系、组织或现状给出；主体不建立替代方向，也不公开争夺最终解释权；仍继续必要的基线行动。
- 源端点附加边界：被撤回的只能是可选身份背书接口。若主体停止关键职责、退出流程或公开反抗到不再沿既有方向推进，源端点可能已经不再是 `nx`。
- 目标端点 `x并z`：壳在此前已真实代表主体，并且其自愿性、共同性或“全体”范围依赖主体反复签署、复述、履行或允许署名。
- 被改变变量：自愿代表资格、共同壳覆盖人数、第三方归因合法性、壳引用主体姓名与行为的资格、行政归类与真实立场之间的距离。
- 不包括：法定身份是否存在、职位是否被撤销、资源是否断供、人物内心是否喜欢该身份、壳是否在视觉上显得虚假。
- 成立阶段：壳先成立 → 主体仍沿基线流程 → 可选背书被持续撤回 → 第三方不能再把壳解释为主体自愿立场或全体共同说法 → 覆盖范围下降。
- 体量：低体量是一次“全体声明”被迫改成“多数声明”；中体量是主体长期拒绝象征履行，使角色只能行政覆盖；高体量是多个关键成员同时撤回背书，使共同壳失去自愿代表资格。
- 显影条件：拿掉背书依赖后作用消失；恢复背书后覆盖恢复；主体仍继续基线流程；没有辞职、失能、资源变化、公开反抗、真相曝光或外部资格剥夺。

### 候选机制

#### A｜可选认领接口断供

```text
身份壳已经覆盖主体
→ 壳要把行政归类升级为“本人自愿认领”，需要持续签署、复述、署名或象征履行
→ 主体仍沿基线流程行动，但不提供这些可选接口
→ 第三方只能保留外部标签，不能把壳当作主体立场
→ x并z 对该主体的自愿代表范围下降
```

理论后果：克制对象不是整个壳，而是壳取得“这是他自己的身份/立场”的接口；只适用于依赖反复自愿确认的共识壳。

#### B｜字面服从使象征壳失去主动精神

```text
主体严格沿外部指令行动
→ 只完成最低字面程序，不补入主动认同、倡议与象征表演
→ 壳虽保留行政覆盖，却难以把主体解释为其精神代表
```

理论后果：可能改变“代表性”，但未必改变“覆盖范围”；若只是讽刺效果或观众看出荒谬，目标端点仍不足。

#### C｜关键履行停止或主动退出

```text
主体停止工作、辞职、公开拒绝、另立身份或揭露真相
→ 壳失去覆盖
```

理论后果：目标变化可以成立，但源端点通常已经离开 `nx`，应优先检查 `zn/zx/x/xn` 或关系终止，不能倒写为本关系。

### 正例候选

1. **《抄写员巴特比》巴特比，先完成抄写员身份、后持续说“我宁愿不”并留在办公室的阶段**：员工/抄写员壳此前已经成立，随后角色无法继续解释他，支持“壳已成立后覆盖下降”。但巴特比停止关键工作，不再沿办公室流程推进，源端点已经偏离纯 `nx`；本例只通过目标端，不通过源端。
2. **《好兵帅克》帅克服役阶段**：帅克持续沿军队命令与程序行动，不建立公开替代路线，较接近纯 `nx`；其字面服从不断抽空“主动、忠诚、英勇士兵”的象征精神。限制是军队仍可行政上把他归为士兵，改变的可能只是讽刺性与精神代表度，不足以证明 `x并z` 覆盖真实下降；本例较通过源端，不通过目标端。
3. **组织全体声明中的持续不背书成员**：成员仍参加普通流程，不公开反对，也不退出组织，只拒绝签署、复述和允许姓名进入“全体一致”声明；声明必须从“全体”改为“多数”。端点结构最纯，但缺少两个可核验的具体人物文本，不能独立锁定正式机制。

### 反例

1. **《使女的故事》奥芙弗雷德早期阶段**：内心不认领“使女”身份，但外在继续完整履行，制度和第三方仍稳定用壳代表她；只有内部距离，没有目标变量下降。
2. **《1984》温斯顿公开反叛前**：内心不认同党，但外在履行工作和仪式，党成员壳仍能覆盖他；认知分裂不是克制。
3. 下属因恐惧签署虚假声明：`nx` 可能上升，但签署反而给共同壳增加接口，方向与本关系相反。
4. 员工辞职或人物公开撕下面具：壳可能失效，但启动源是关系终止、主动拒绝、`zn/zx/x`，不是纯 `nx`。
5. 记者搜证揭露组织造假：由调查、证据、意义判断与公开行动击穿，优先检查 `xn/zn/zx`。
6. 主体从未被壳真正吸纳：只能判壳生成失败，不能判已经成立的 `x并z` 被克制。

### 最近邻排除

- 与 `zn 克 x并z`：主体因“这个身份不对”主动撤回价值认领并承担后果，启动源是内部意义；本轮候选不建立替代立场，只停止提供可选背书。
- 与 `zx 克 x并z`：公开拆壳、强迫揭露、夺取话语权与摧毁角色接口属于公开权能。
- 与 `x/xn`：撤销职位、账号、名称、合同、资源或合法接口，是掌握边界或制度配置变化。
- 与纯内部不认同：内心距离若不改变第三方覆盖，只是状态层或本体层分离，没有克制目标。
- 与反向 `x并z 克 nx`：身份壳预设角色路径，使主体更沿既有安排行动，改变的是主体方向空间，而不是壳的代表接口。

### 拿掉测试

1. 拿掉壳对反复自愿背书的依赖，若行政身份仍完整覆盖，候选不成立。
2. 恢复签署、复述、允许署名或象征履行后，壳的自愿代表资格是否恢复？若不恢复，变化来自别处。
3. 拿掉公开拒绝、辞职、资源撤回、失能、证据曝光和外部资格剥夺后，覆盖是否仍下降？
4. 主体若停止关键流程到不再沿既有方向行动，源端点是否已经离开 `nx`？若是，不能归因本关系。
5. 主体只在内心不认领、外在仍完整履行时，第三方是否仍照常用壳代表？若是，目标端点不存在。
6. 壳若从未完成对主体的真实吸纳，只能判未生成，不能判被克制。
7. 当前两个具体人物候选分别只通过源或目标的一半，未通过完整测试。

### 反向测试

```text
nx 克 x并z 候选：主体仍沿基线流程，但撤回可选身份背书 → 壳对主体的自愿代表和共同覆盖下降。
x并z 克 nx：身份壳预设角色路径与外部读取方式 → 主体可用方向被限定 → 更沿壳给出的安排推进。
```

正向改变壳的自愿代表接口；反向改变主体的方向空间。两者不能因为最后同时出现“成员仍在组织里”而互相代证。

### 动态链后果

```text
这个壳已经能把我写进“我们”
→ 我没有另立旗帜，也仍走在既有通道里
→ 但我不再把名字、复述和象征履行借给它
→ 行政标签可能仍在，自愿代表资格开始脱落
→ “全体/本人立场”只能退成“多数/外部归类”
```

改变的是壳对主体的**自愿代表资格与共同覆盖范围**，不是身份整体消失、真相曝光、组织崩塌或真实自我自动回归。

### 三元与十元并行

三元继续核验作品整体精神运动；十元本轮只核验 `nx` 是否仍沿基线方向、`x并z` 是否已成立并依赖持续背书，以及第三方代表接口是否真实下降。不从空间主题、身份题材或人物沉默反推本关系，也不把十元写成三元的子级。

### 95%门槛

高置信修正：

- 壳必须先成立，未完成吸纳不等于被克制：99%。
- 纯 `nx` 完整履行壳要求通常维持或强化壳：99%。
- 只有内心不认领而外在完整履行，不足以改变 `x并z` 公共覆盖：99%。
- 停止关键履行、辞职、公开拒绝若已离开外部方向，不能继续作为纯 `nx` 证据：98%。
- 唯一可保留窄候选是“基线流程继续、可选自愿背书撤回”：97%。
- 目标变量必须收窄为自愿代表资格、全体覆盖、署名与归因合法性：98%。

未达到95%的正式机制：

- 缺少两个同时通过源端与目标端的具体人物案例；
- 《巴特比》通过目标但源端偏离，《好兵帅克》较通过源端但目标覆盖下降不足；
- 尚不能确认“可选背书撤回”是否仍属于 `nx` 的独立行为功能，还是另一种未归类的消极拒绝；
- 候选只适用于依赖持续自愿确认的共识壳，普遍性过窄。

结论：几何位置保留；三分岔红线写入必读中枢；正式机制未锁定；不新增待确认问题，原因是当前仍可通过寻找更纯作品案例和继续区分基线流程/可选背书来独立推进。
