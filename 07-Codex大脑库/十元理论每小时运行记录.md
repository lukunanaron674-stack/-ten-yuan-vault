## 3. 源端、目标端、变量与成立条件

### 源端`z`

- 人物与阶段：重要主体在明确评价节点，对具体人物、作品、选择或完成作出正确归因和清楚确认。
- 具体名词：重要认可位置、准确见证、正确归因、明确判断。
- 排除：礼貌夸奖、掌声、曝光、奖品、职位、资源、合作邀请、治疗职责、导师义务和公开推荐的后续责任。
- 体量：低体量只增加注意；中体量提高被认可者关系价值与回返概率；高体量候选必须同时改变认可者一侧，使双方形成跨失败和冲突的对象特异停靠。

### 目标端`nz`

本轮拆成六个变量：

1. **被认可者关系价值**：认可者是否成为“真正看见我的人”。
2. **被认可者主动回返**：评价结束后是否再次靠近。
3. **认可者认识性投入**：是否为了验证判断、观察发展、收集证据而继续关注。
4. **认可者关系投入**：是否在无新证据、无请求、无义务时仍主动维护对方。
5. **双方修复能力**：负面判断、拒绝标签和非评价冲突后是否能恢复关系。
6. **对象特异性**：同等级第三对象是否不能轻易替代该停靠位置。

严格`z 生 nz`不能只证明第1至第3项；至少要证明第4至第6项由认可启动，而非后续任务、身份、声誉或请求生成。

### 成立阶段与显影条件

- 阶段A：认可前双方关系厚度较低，排除既有友情、长期共同时间和固定承载。
- 阶段B：认可准确发生，但不附带资源、职位、推荐、合同、治疗或教学责任。
- 阶段C：评价议题耗尽，被认可者不再次请求，也不提供新作品或新证据。
- 阶段D：认可者没有公开声誉押注、导师身份或“证明自己看对”的利益。
- 阶段E：被认可者失败、价值下降、拒绝认可者原标签和建议，并发生非评价冲突。
- 显影条件：认可者仍主动维护对方作为关系对象，双方完成修复且第三对象不能替代。

## 4. 候选机制

### A｜准确见证直接生成双方可信停靠

```text
认可者准确看见被认可者真正交出的对象
→ 被认可者主动回返
→ 认可者也因这次见证产生无请求、非评价投入
→ 双方跨失败与冲突形成可信停靠
```

理论后果：若成立，`z`可跨主体生成窄义`nz`关系入口并同时推动双方投入。当前严格候选由约87%降为约85%，关键缺口仍是认可者一侧的独立机制。

### B｜被认可者一侧关系价值与回返上升

```text
人物被准确看见
→ 认可者成为特定见证者
→ 被认可者更愿意靠近、展示、求助或争取回应
```

理论后果：这是约99%的稳定直接机制；只打开被认可者一侧的关系入口，不生成双方可信停靠。

### C｜认可者的认识性投入

```text
认可者形成“这个人具有某种价值或潜力”的判断
→ 为验证判断、预测发展或收集新证据而继续观察
→ 即使主动联系，也可能只是在维护认知模型
```

理论后果：主动关注不等于关系投入。其对象是判断正确性与新证据，不是对方作为可回返、可修复的关系对象。

### D｜身份、声誉与后续互动链

```text
认可者公开推荐、承担导师/评审/治疗角色
或被认可者再次请求并进入共同活动
→ 认可者继续投入
→ 多轮共同时间、自我暴露与承载增厚关系
```

理论后果：关系可以真实形成，但生源属于`zx/x并z/xn/n`或后续互动，不得倒灌进最初一次`z`。

## 5. 正例候选

1. **《心灵捕手》Sean与Will，治疗后期至离别阶段**
   - 源端：Sean准确确认Will的能力、创伤与选择资格。
   - 目标候选：Will把Sean视作重要见证者，双方形成持续关系。
   - 污染：治疗职责、长期会谈、自我暴露、事实重释与现实承载。
   - 判断：支持认可打开关系入口，不支持纯`z`独立生成双方关系。

2. **《寻找弗罗斯特》Forrester与Jamal，写作确认后阶段**
   - 源端：Forrester确认Jamal的写作能力。
   - 目标候选：双方持续回返并形成师友关系。
   - 污染：教学、写作交换、共同秘密、互相保护与Forrester对自身判断的持续验证。
   - 判断：认识性投入、导师角色与后续互动共同作用。

3. **《爆裂鼓手》Fletcher与Andrew，识别其潜力后阶段**
   - 源端：Fletcher明确判断Andrew具有可被逼出的潜力。
   - 后续：Fletcher持续关注并投入极高注意。
   - 结果：关系缺乏安全回返、尊重与冲突修复，关注主要服务于判断验证、控制和成就模型。
   - 判断：强力反证“主动关注等于`nz`关系投入”。

4. **严格控制候选**
   - 评审甲确认陌生创作者乙具有独特表达能力。
   - 评价结束，乙不再请求、无新作品，甲也无导师义务、推荐声誉或收益。
   - 乙后来失败、拒绝“天才”标签并反对甲的建议，甲仍主动关心其生活与选择；双方发生非评价冲突后完成修复。
   - 只有这种结构才接近纯例，当前缺两组可核验材料。

## 6. 反例

1. 学生因导师表扬持续联系，只为推荐和资源：被认可者单方回返。
2. 粉丝被偶像回复后长期留恋：只有单方见证价值。
3. 评委继续看获奖者新作品：评价程序和证据收集仍在运行。
4. 导师持续帮助公开推荐过的学生：可能是声誉押注和判断一致性维护。
5. 治疗者继续会面：职业责任与承载结构。
6. 认可者持续监控对象是否兑现潜力：认识性投入，不是可信停靠。
7. 被认可者拒绝原标签后认可者立刻失去兴趣：关注对象是判断模型。
8. 匿名认可让被认可者强烈留恋，但认可者没有任何后续投入：只证明单方关系价值。

## 7. 最近邻排除

- `x并z 生 z`：对象如何被识别与正确归因。
- `xn 补 z`：长期证据怎样补足认可。
- `xz 补 nz`：失去风险怎样强化归宿。
- `n`：现实接收、照护与持续承载。
- `zx`：公开推荐、声誉押注与判断一致性维护。
- `xn`：评审、教学、治疗和合作程序。
- 既有`nz`显影：关系在认可前已经成立。
- 认识性投入：认可者维护的是预测模型和证据链。
- 后续互动链：被认可者回返后另行生成共同时间与关系厚度。

## 9. 反向测试

```text
原有nz推动人物完成并获得z
≠
z完成后新生nz
```

判断规则：

- 只有被认可者主动回返：关系价值或认可依赖上升。
- 认可者只在出现新证据时回返：认识性追踪。
- 认可者为证明自己判断正确而投入：判断一致性或声誉维护。
- 被认可者拒绝原标签后关注消失：对象是预测模型，不是关系对象。
- 无请求、无新证据、无义务且对方失败后仍主动维护：才支持认可者进入关系。
- 双方跨非评价冲突修复且第三对象不可替代：才接近可信停靠。

## 10. 动态链后果

```text
你准确看见了我真正交出的东西
→ 你在我这里获得特定见证价值
→ 我更愿意再次靠近你
→ 你也可能为了验证判断而继续观察我
→ 我的回返与您的观察可能启动后续互动链
→ 只有认识性、身份、声誉与任务因素拿掉后
→ 你仍维护我作为关系对象并跨冲突修复
→ 才接近双方可信停靠
```

本轮只改变被认可者关系价值、单方回返、认可者认识性追踪概率与后续互动入口；不机械生成友情、爱情、忠诚、永久依赖或共同体。

## 11. 三元与十元并行核验

三元观察：

- 谁作出认可；
- 谁随后回返；
- 认可者关注的是新证据还是人物生活；
- 失败与冲突后双方是否继续。

十元区分：

- `z`：准确确认与正确归因；
- `nz`：双方可信回返、修复与对象特异停靠；
- `xn`：评审、教学、治疗和证据追踪程序；
- `zx`：公开推荐、声誉与权威一致性；
- `n`：现实接收与持续承载；
- `x并z`：导师、评委和专业身份壳。

两套系统并行，没有写成父子派生。
