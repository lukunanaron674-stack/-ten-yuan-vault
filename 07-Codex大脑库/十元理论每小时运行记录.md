## 3. 源端、目标端、变量与成立条件

### 源端`nz`

- 人物与阶段：双方已经跨阶段共同存在；任务、评价或危机结束后仍分别主动回返；分歧后可以修复；关系不会因人物作出不同选择而立即破裂。
- 具体名词：可信回返关系、对象特异停靠、关系安全、共同节奏。
- 排除：分手威胁、住房和资源依赖、照护控制、共同资产强绑、职位命令与危机任务。
- 体量：低体量只提高一次咨询意愿；中体量形成长期委托与共同默认；高体量候选必须使人物的元层重启资格真实下降。

### 目标端`nx`

本轮把目标拆成六个变量：

1. **听取与默认采用**：是否倾向接受特定对象的建议。
2. **一阶判断委托**：是否把具体事项结论交给对方。
3. **共同决策环境**：是否形成固定的信息入口、讨论顺序与默认方案。
4. **暂停共同默认**：人物能否叫停既有共同方案。
5. **启用第三判断者**：人物能否引入新信息源、新专家或新伙伴。
6. **单方面重启判断**：人物能否在不等待对方许可时重新设题、复判并重建标准。

严格`nx`生成要求第4至第6项持续下降。只提高第1至第3项，属于认识性信任、委托稳定或协调锁定。

### 成立阶段与显影条件

- 阶段A：可信回返已经成立，双方形成稳定共同讨论和分工。
- 阶段B：人物默认采用对方判断，记录是否仍保留暂停、换人和复判资格。
- 阶段C：对方连续犯错、失去专业优势，并明确允许人物退出共同默认。
- 阶段D：第三判断者和独立信息渠道可用；关系仍安全；测试人物能否重设决策环境并单方面重开判断。
- 显影条件：人物不是因为冲突成本、习惯、角色分工或共同资产而不重启，而是连“由谁判断、怎样判断、何时重开”的资格也不再自主使用。

## 4. 候选机制

### A｜可信回返生成最终方向资格让位

```text
关系持续提供稳定停靠
→ 独自判断责任和失败风险下降
→ 人物把一阶结论与元层启动权都交给特定对象
→ 无法暂停共同默认、启用第三判断者或单方面重开判断
→ nx上升
```

严格候选由约86%降为约84%。若未来成立，只能先锁“可信停靠使共同判断环境固化并夺走元层重启资格”的窄机制。

### B｜认识性信任与可撤销判断委托

```text
对方跨阶段判断可靠
→ 人物相信其信息和推理成本更低
→ 默认采用或长期委托具体事项
→ 仍保留暂停、换人、引入新证据和重新设题
```

这是高置信竞争解释。人物少做判断，不等于没有判断资格。

### C｜协调锁定与共同决策环境稳定

```text
双方长期共用信息入口、讨论顺序和默认方案
→ 单方退出会打断节奏并增加协调成本
→ 人物不愿单独重启判断
→ 看起来像把方向资格交给关系
```

理论后果：这是共同流程和节奏的`xn`式锁定或关系成本，不等于`nx`元层资格被生成。

2. **《革命之路》April与Frank，巴黎计划形成及崩解阶段**
   - 源端候选：婚姻共同生活形成长期共同节奏，重大方向必须经双方协调。
   - 目标候选：职业、迁居与家庭路线被绑定在共同决策环境中。
   - 污染：共同资产、经济依赖、婚姻角色、性别结构、冲突和怀孕事实。
   - 判断：更支持协调锁定和共同结构，不支持纯`nz 生 nx`。

3. **严格控制候选：平等伴侣甲乙**
   - 双方能力、信息、资源相当，关系不会因不同选择破裂；没有共同资产、照护义务或职业绑定。
   - 甲跨职业、迁居、创作长期采用乙判断。乙连续犯错、失去优势、明确允许退出，第三专家也可用。
   - 只有甲仍不能暂停共同默认、启用第三专家或单方面重设判断问题，才接近纯例。
   - 当前缺两组可核验材料。

## 7. 最近邻排除

- `nz 补 xz`：关系为危险路线提供归宿，不解释方向资格让位。
- `zx 补 nx`：通过既有身份、关系和通道借力做成。
- `n`：照护与现实承载造成代定。
- `xn`：共同流程、信息入口、讨论顺序和协调锁定。
- `xz`：害怕失去关系而顺从。
- 认识性信任：相信对方更懂，但仍能重设判断环境。
- 可撤销判断委托：交出具体结论，保留元层启动权。
- 共同决策环境：很少单独判断，但可以单方面叫停和重开。
- 稳定`nx`本体：人物对所有对象都不占方向，不是由特定`nz`生成。

## 8. 拿掉测试

1. 拿掉共同任务、共同利益和共同路线。
2. 拿掉危机、照护、经济、住房及共同资产依赖。
3. 冻结信息、能力、资源和社会资格差异。
4. 保证不同选择不会破坏关系，并明确允许退出。
5. 让原对象连续犯错并失去专业优势。
6. 提供独立信息渠道和同能力第三判断者。
7. 分开测试暂停共同默认、启用第三人、重新设题和重建标准。
8. 降低现实退出成本，只保留共同节奏和关系情绪成本。
9. 换到职业、迁居、创作三类无共同利益事项。
10. 检查人物能否在不等待原对象许可时单方面开启复判。

## 10. 动态链后果

```text
这里有一个即使我判断错误也能回去的人
→ 我不必独自承担全部判断负荷
→ 我更愿意默认采用并进入共同决策节奏
→ 共同信息入口和默认方案越来越稳定
→ 我可能很少单独启动判断，并对打断节奏感到不适
→ 只要我仍能暂停默认、启用第三人并单方面重开判断，方向仍属于我
→ 只有连重设决策环境的资格都不再自主使用
→ 才接近对象特异的nx上升
```

本轮只改变独自判断负荷、认识性信任、委托稳定性、协调成本与共同决策环境，不机械生成服从、无能或永久依赖。

## 11. 三元与十元并行核验

三元观察：双方是否持续回返、谁承担当前判断、谁能叫停共同方案、分歧后关系是否继续、第三判断者能否进入。

十元区分：

- `nz`：可信回返与对象特异停靠；
- `nx`：不认领最终方向与元层重启位置；
- `xn`：共同流程、信息入口、默认方案和协调锁定；
- `n`：现实照护与承载；
- `xz`：失去关系和退出压力；
- `zx`：公开决定与权限接口。

两套系统并行，没有写成父子派生。
