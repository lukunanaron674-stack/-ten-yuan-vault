### 对象分层

- 稳定本体：`z` 是长期依赖重要认可位置确认自身；`nx` 是长期不占方向决定位置。一次鼓励与一次拒绝安排不能反推稳定本体。
- 当前状态：主体在重要认可后暂时不再沿外部安排，最可能只落在具体关系或阶段。
- 行为功能：被看见、确认、回应属于 `z`；提出替代方案、使用否决权、承担自行选择后果才触及 `nx` 下降。
- 光影：目光、聚光、署名、侧位、队列与后退只作显影。
- 场景：师徒、家庭、治疗、舞台、学校和公司不能替代端点。
- 时间关系：认可先发生、方向认领随后出现只是必要序列，不是充分机制。
- 关系位置：认可者不一定是外部方向提供者；必须分别标出谁认可、谁原本给方向、谁最终承担选择后果。
- 显影：外部路线是否从“唯一合法”降为“可以拒绝”，主体是否在认可撤回后仍保持自己的路线。
- 动态链：重要对象确认主体拥有判断资格，随后主体是否真正取回方向位置；不机械生成独立人格或成熟能力。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `z`：必须写清认可主体、认可对象、确认内容及该认可位置为何重要；认可须落到主体自己的判断、能力或选择资格。
- 目标端点 `nx`：主体此前真实不占方向决定位置，依赖外部安排；随后外部方向的唯一合法性下降，主体开始提出替代路线、使用否决并承担后果。
- 被改变变量：方向决定位置认领强度、外部安排唯一依赖度、替代路线提出率、否决权实际使用、认可停止后的自主持续度、对自行选择后果的承担度。
- 成立阶段：主体先处于真实方向依赖 → 重要认可确认其判断或能力资格 → 外部路线不再是唯一合法 → 主体作出至少一次可拒绝原路线的真实选择 → 认可停止后仍维持并承担后果。
- 体量：低体量是一项选择上取回方向；中体量是在一段关系中持续决定；高体量是稳定人物结构改变。当前证据最多支持低至中体量候选。
- 显影条件：拿掉教学方案、照护支持、职位授权、资源转移和认可者代为承担后果后，认可本身仍是方向认领变化的必要启动源。

### 候选机制

- A 判断资格确认：重要认可者确认“你的判断可以成立”，主体不再把外部路线视为唯一合法，开始提出、执行并承担自己的路线。理论后果：`z` 若克制 `nx`，克制的是方向依赖，不是关系网络本身。
- B 能力资格确认：主体此前因不确定自己能否承担后果而跟随，认可确认其能力足以承担选择，主体重新使用否决与决定位置。理论后果：若只是更努力执行原安排，则只有 `z` 上升，没有 `nx` 下降。
- C 教学与放权复合支持：认可者同时提供方案、训练、照护、资源、许可或替主体承担风险。理论后果：真实启动源可能是 `xn/n/x/zx`，认可只是伴随信号。
- D 既有自主显影：主体本来已有自己的方向，认可只让其敢于公开。理论后果：目标端点此前并不存在 `nx`，不能判克制。

### 正例候选

1. 《死亡诗社》托德与基廷，课堂即兴诗阶段：基廷确认托德拥有自己的诗性声音，托德从沉默与标准答案位置转为说出自己的语言。限制：基廷同时强引导、教学与照护，混入 `xn/n/zx`；作品后续也不足以证明基廷认可停止后托德持续提出并承担独立路线。
2. 《跳出我天地》比利与父亲，父亲支持舞蹈选择之后：父亲由否定者转为确认比利的能力与选择，家庭既定路线不再是唯一合法方向。限制：比利在父亲认可前已有强自主方向，父亲还提供资源与现实放行，更像既有自主获得 `z/x` 支持。
3. 研究生结构例：学生长期只等导师给题；导师仅确认“你的判断足以独立定题”，不再给方案、经费或权限；此后导师不再回应，学生仍提出替代选题、拒绝原路线并承担失败风险。该结构通过端点设计，但缺少可核验的具体作品人物，不能替代第二纯例。

### 反例

1. 老板表扬员工后，员工更认真执行老板安排：`z` 上升，`nx` 未降。
2. 父母说“我相信你”，却仍替孩子决定学校和职业：认可与方向权分离。
3. 导师给出新方案，学生改为执行该方案：只是换了外部方向提供者。
4. 上级授予职位、预算或签字权后主体能决定：主要是 `x` 权限转移。
5. 治疗者长期照护、训练并陪伴主体选择：可能主要来自 `n/xn`。
6. 人物本来就反抗，认可只使其公开表达：既有自主显影，不是 `nx` 被克。
7. 获奖后自信上升但没有否决任何外部路线：只有状态变化。
8. 认可停止后主体再次等待认可者决定：方向认领没有跨阶段持续。

### 最近邻排除

- 与 `zx/x` 对方向空间的作用：公开显权、职位、资源和许可直接改变现实决定权；`z` 只能确认资格，不能偷带权限。
- 与 `xn/n`：教学、训练和照护能提高能力与安全感，但不等于认可本身克制方向依赖。
- 与 `zn`：主体因“这件事本身正确”而拒绝外部路线，启动源是内部意义；`z` 最多确认该判断获得关系资格。
- 与情绪自信：更敢说话、表现更好、情绪振奋不等于提出替代方向与使用否决权。
- 与反向 `nx 克 z`：主体不呈现、不进入认可接口会降低确认发生概率；那改变的是认可接口，不是本轮方向认领变量。

### 拿掉测试

1. 拿掉认可，只保留教学、资源或放权，主体仍取回方向，则不依赖 `z`。
2. 拿掉教学方案、照护、职位、预算、许可和认可者代为承担后果，只保留确认，主体仍持续决定，才支持直接作用。
3. 拿掉人物原有自主性，若认可后仍只能等待对方给方向，目标端点不存在。
4. 拿掉情绪振奋，只看替代路线、否决与后果承担，若变化消失，只是状态提升。
5. 认可停止或认可者离场后，主体仍维持自己的路线，纯度才足够。
6. 若主体只是换了一个更喜欢的外部方向提供者，`nx` 结构未下降。

两个作品候选均未通过全部拿掉测试。

### 反向测试

```text
z 克 nx 候选：重要认可确认主体自己的判断/能力资格 → 外部方向不再唯一合法 → 主体持续提出替代路线、使用否决并承担后果。
nx 克 z 候选：主体持续不表达、不呈现、不进入认可接口 → 重要认可无法发生或逐渐撤回。
```

正向改变方向认领，反向改变认可接口，不能互相代证。旧“强势主体持续表达和占位使他人退后”在反向检查中再次暴露：其源端点更接近 `zx/x`，不是现行 `z`。

### 动态链后果

```text
我一直把你的安排当作唯一合法路线
→ 重要的人只确认：我的判断与能力也有资格成立
→ 我提出另一条路线，并实际拒绝原安排
→ 即使认可停止，我仍承担自己选择的损失
→ 外部方向从唯一合法降为可拒绝选项
```

改变的是“谁有资格决定”与外部路线的唯一合法性，不机械生成勇气、成熟、成功、稳定独立人格或正确选择。

### 三元与十元并行

三元继续核验作品整体精神运动；十元本轮只核验认可端点、方向位置、否决权和后果承担。不能由作品的成长主题反推 `z 克 nx`，也不把 `z` 写成 `nx` 的父级。

### 95%门槛

高置信修正：

- 旧“z 持续表达、决定和占位”与现行 `z` 冲突：99%。
- 认可后只有自信、表达或表现提高，不构成 `nx` 下降：99%。
- 最低可观察结果必须是替代路线、实际否决和后果承担：98%。
- 认可停止后仍维持方向，才排除持续追逐认可：98%。
- 教学、照护、放权、资源和既有自主性必须拆开：98%。

未过95%的核心：

- 缺少两个高纯具体人物案例；
- 无法证明 `z` 直接克制 `nx`，而非让既有自主方向获得显影资格；
- 现有作品候选无法同时拿掉 `xn/n/x/zx` 和既有自主性。

因此：几何位置保留；旧机制继续撤回；判断资格确认候选保留；正式机制未锁定；不新增待确认问题。
