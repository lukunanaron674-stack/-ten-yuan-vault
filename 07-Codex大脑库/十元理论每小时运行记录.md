## 源端点、目标端点、变量、阶段、体量与显影

### 源端点 `z`

必须写清：

1. 谁认可；
2. 认可主体自己的什么判断、能力或选择；
3. 为什么该认可位置重要；
4. 认可是否只确认资格，而没有新增事实、理由、比较、诊断、方案、许可、资源或后果兜底。

普通命令、教学、建议、事实纠正、放权、职位授予、公众注意和完成结果不能代替 `z`。

### 目标端点 `nx`

主体此前必须同时拥有：

- 真实可行的自己路线；
- 实际否决权；
- 独立承担选择结果的能力；
- 但因为否定自己的判断资格，持续沿外部路线推进。

被改变变量：

- 主体对最终方向位置的认领强度；
- 外部路线的唯一合法性；
- 替代路线提出率；
- 否决权使用率；
- 认可撤回和失败后自主是否持续；
- 自主能否迁移到认可者未评价的新选择。

### 成立阶段

```text
主体已有路线却否定自身资格
→ 重要认可只确认资格，不提供新信息或许可
→ 主体提出并承担自己的路线
→ 认可者撤回或反对
→ 首次自主路线失败或没有奖励
→ 新选择出现且认可者未评价
→ 主体仍提出路线、否决外部安排并承担代价
```

### 体量

- 低体量：一个具体选择上取回方向；
- 中体量：一段关系或连续多个选择中持续认领方向；
- 高体量：稳定人物本体改变。当前无证据支持高体量。

### 显影条件

至少需要：

1. 认可前主体确有可行路线；
2. 认可者不兼任许可者、教师、资源门控者或风险兜底者，或这些功能在实验中保持不变；
3. 认可内容不增加事实与方案；
4. 认可撤回后仍自主；
5. 首次失败后仍保留决定资格；
6. 自主迁移到认可者未评价的新选择。

## 候选机制与理论后果

### 候选 A：判断资格确认

```text
主体已有可行路线
→ 但认为自己的判断没有资格成立
→ 重要认可者确认“你的判断可以成立”
→ 外部路线不再垄断合法性
→ 主体提出、否决并承担自己的路线
```

理论后果：只可能作用于判断资格自我取消型 `nx`，不能泛化到结构性依赖。

### 候选 B：能力资格确认

```text
主体知道自己想走哪条路
→ 但不相信自己能承担后果
→ 认可者确认其能力
→ 主体开始使用否决与决定位置
```

理论后果：若主体只是更努力执行旧安排，只有 `z` 上升，`nx` 未下降。

### 候选 C：信息或教学更新

```text
认可者提供证据、比较、诊断、理由或方案
→ 主体修正对自身能力或路线可行性的判断
→ 开始自主行动
```

理论后果：直接作用源更接近 `xn`、事实更新或教学，不是纯 `z`。

### 候选 D：撤限与许可

认可者同时放开职位、资源、家庭许可、课程权限或风险兜底。理论后果：优先检查 `x/zx/xn/n`，不能把撤限后的自主全部归给认可。

### 候选 E：换跟随对象

主体不再听原安排者，只听认可者。方向中心仍在外部，`nx` 没有下降。

## 信息零增量／认可必要性测试

```text
保留认可主体的重要性
→ 删除认可中携带的新事实、理由、比较、诊断、方案、许可、资源与兜底
→ 只留下“你的判断有资格成立”
→ 主体是否仍取回方向
```

再做载体替换：

```text
将相同事实信息匿名提供
或改由低重要性来源提供
→ 若主体仍产生同等自主变化
→ 变化来自信息或事实更新，不来自重要认可位置
```

反向控制：

```text
只给无信息的认可
但不改变许可、资源和现实路径
→ 若主体仍无法提出与承担路线
→ 纯 z 不足以克制该 nx
```

## 正例候选

### 1. 《死亡诗社》托德与基廷｜课堂即兴诗阶段

- `z` 候选：基廷确认托德拥有自己的诗性声音。
- `nx` 候选：托德从不占表达与判断位置转为说出自己的语言。
- 未通过：基廷同时提供强引导、教学结构、比较框架与课堂权能；认可包含明显信息和训练增量。缺少反认可、首次失败保持与跨选择迁移。

### 2. 《跳出我天地》比利与父亲｜父亲支持舞蹈之后

- `z` 候选：父亲确认比利的舞蹈能力与选择。
- `nx` 候选：家庭路线不再拥有唯一现实资格。
- 未通过：比利在认可前已有强自主方向；父亲同时提供许可、资源、家庭放行与风险承担。更像既有自主获得现实支持。

### 3. 《心灵捕手》威尔与肖恩｜治疗后期

- `z` 候选：肖恩确认威尔的价值、能力与选择资格。
- `nx` 候选：威尔开始选择离开既有生活路线。
- 未通过：长期治疗、事实解释、情感承载、建议和关系安全混入 `xn/n`；无法证明信息零增量的纯认可足够。

### 4. 研究生独立定题结构例

学生已有可行选题；不掌握经费、许可与毕业权力的外部学者只确认其判断资格，不提供新证据与方案。学者后来反对、首次选题失败后，学生仍在新课题上独立提出路线。

结构能通过测试，但缺少可核验人物文本，不能承担正式锁定。

## 反例

1. 老板表扬员工后，员工更认真执行老板路线：`z` 上升，`nx` 未降。
2. 父母说相信孩子，却继续控制学校、资金与许可：认可没有改变方向结构。
3. 导师给出新方案，学生改听导师：只是换外部路线。
4. 专家提供能力诊断和证据后，主体修正判断：信息更新，不是纯认可。
5. 上级授予预算、职位或签字权：权限变化。
6. 长期治疗、训练或照护后主体更独立：优先检查 `xn/n`。
7. 人物本来已经坚持自主路线：既有自主显影。
8. 认可者一反对，主体立刻撤回选择：持续依赖认可。
9. 首次自主成功时敢决定，失败后退回安排：条件性自信。
10. 只在被认可领域自主，面对新选择仍等待别人决定：局部能力信心。
11. 相同信息由匿名材料提供也产生同等变化：认可位置不是必要源。

## 最近邻排除

- `x/zx`：许可、职位、资源与公开放权改变现实决定资格。
- `xn/n`：教学、训练、事实解释、陪伴与照护改变能力和安全感。
- `zn`：主体因为事情本身正确而拒绝安排。
- 自信上升：更敢表达不等于取得方向权。
- 信息更新：主体学到新的事实，不等于被重要对象认可。
- 换跟随对象：认可者成为新方向中心。
- 既有自主显影：目标 `nx` 原本没有成立。

## 拿掉测试

1. 拿掉认可，只保留教学、信息、许可、资源和放权，主体仍独立，则不依赖 `z`。
2. 拿掉教学、信息、资源、职位、许可与兜底，只保留资格确认，主体仍取回方向，才支持纯作用。
3. 将认可者与原方向提供者、教师、许可者和资源门控者分开。
4. 将相同事实匿名提供或改由低重要性来源提供，比较自主变化是否相同。
5. 拿掉主体原有可行路线，认可后若仍无替代方向，则目标端点不存在。
6. 拿掉情绪振奋，只观察路线、否决和现实损失。
7. 认可撤回、反对后是否仍自主。
8. 首次自主失败、受损或无奖励后是否仍保留方向资格。
9. 在认可者未评价的新选择中是否仍独立提出路线。
10. 若主体随认可者意见改变方向，只能判换跟随对象。

现有具体人物候选均未通过第2、3、4、7、8、9项完整组合。

## 反向测试

```text
z 克 nx：
主体因否定自身判断资格而跟随
→ 纯认可确认资格
→ 撤回认可、失败和新选择后仍取回方向

nx 克 z：
主体不表达、不呈现、不进入认可接口
→ 重要确认无法发生
```

正向改变方向合法性，反向改变认可能否发生，不能互相代证。

## 三元与十元并行核验

三元层只能记录：重要对象的确认之后，主体开始自己选择。

十元层必须另证：

- 源端是纯 `z`，没有信息、教学和许可增量；
- 目标端原本是判断资格自我取消型 `nx`；
- 被改变的是方向合法性，而非能力、事实模型或现实权限；
- 变化通过反认可、失败和跨选择迁移。

三元中的“被肯定后独立”不能自动派生出十元 `z 克 nx`。

## 动态链后果

```text
我不是没有路线
→ 我认为自己的判断没有资格成立
→ 重要的人只确认我的判断资格，不给新方案或许可
→ 我提出自己的路线
→ 他后来反对，我第一次选择也失败
→ 在另一项他从未评价的新选择里
→ 我仍提出路线、使用否决并承担代价
→ 方向权才真正回到我这里
```

改变的是主体是否承认自己拥有决定资格，以及外部路线是否仍垄断合法性。不机械生成成熟、勇气、成功或稳定独立人格。

## 下一条关系

`nx 生 x`

下一轮重点：

```text

→ 乙承担决定、整理、协调和善后
```
