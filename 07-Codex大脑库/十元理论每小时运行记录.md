## 源端点、目标端点与变量

### 源端点 `xz`

必须同时满足：

1. 自然危险或不可控临界真实逼近；
2. 退路、资源或时间窗口持续缩窄；
3. 不行动会失去最后机会；
4. 作用不主要来自施害者命令、酷刑、制度惩罚、洗脑或长期训练。

### 目标端点 `zn`

危险前必须已有稳定原则：即使没有奖励、认可和监督，主体仍认为它正确，并应指导现实选择。

### 被改变变量

- 原则正确性；
- 适用范围；
- 多原则优先级；
- 实践能力；
- 无条件性；
- 最终指导资格；
- 替代原则的跨案例稳定性；
- 替代原则在利益方向反转时是否仍成立。

### 成立阶段、体量与显影条件

```text
危险前稳定 zn
→ 纯自然 xz 压缩选择
→ 主体作出极端例外
→ 危险解除、事实纠正、能力恢复
→ 同结构与至少两个新案例复判
→ 利益方向反转时替代原则仍工作
```

低体量只支持实践通道受压；中体量支持适用范围条件化或原则排序；高体量才要求旧原则失去最终指导资格，并由可跨案例、反自利的稳定替代原则接管。

## 候选机制与理论后果

### 候选 A：实践通道压缩

```text
xz 缩窄时间、资源和行动路径
→ 主体仍认为旧原则正确
→ 但无法将原则带入现实
```

后果：改变实践能力与显影，不构成 `zn` 被克。

### 候选 B：例外正当化与条件化

```text
危险迫使一次极端选择
→ 主体事后仍认为该次决定合理
→ 原原则改成“通常成立，极端时允许例外”
```

后果：无条件性与适用范围下降，但未必撤销正确性或最终指导资格。

### 候选 C：稳定规范替代

```text
危险迫使主体撤销旧原则的最终指导资格
→ 恢复后仍维持判断
→ 提出稳定替代原则
→ 在至少两个对象不同的新案例中重复工作
→ 主体吃亏、亲近者受损或利益方向反转时仍适用
```

后果：这是当前最接近正式克位的窄候选。

### 候选 D：意义排序重组

保存生命、保护孩子或多数取得更高优先级，旧原则仍正确，只是此次未优先执行。

后果：属于 `zn` 内部排序，不是旧原则被克。

## 最近邻排除

- `zx 克 zn`：施害者以公开权能、命令和惩罚压制意义。
- `xn 克 zn`：规则、训练和长期重复改变原则资格。
- `zn` 内部排序：旧原则仍正确，另一原则优先。
- 事实更新：世界模型改变，规范判断未变。
- 适用范围变化：原则仍正确，但实施条件缩小。
- 创伤与实践通道封闭：做不到，不等于认为不对。
- 危险揭露伪 `zn`：目标端点从未稳定成立。

## 拿掉测试

1. 拿掉施害者、制度、命令、酷刑和洗脑。
2. 拿掉行为失败，只问主体是否认为旧原则失去指导资格。
3. 拿掉竞争原则，旧原则是否仍被撤销。
4. 拿掉错误事实，改判是否仍成立。
5. 危险解除、创伤缓解、能力恢复后，是否仍维持改判。
6. 在低风险同结构情境中再次提供旧原则实践机会。
7. 呈现至少两个对象、地点和主体利益不同的新案例，替代原则是否重复工作。
8. 主体吃亏时，替代原则是否仍适用。
9. 亲近者受损时，替代原则是否仍适用。
10. 利益方向反转后，主体是否仍按同一原则判断。
11. 若只为过去具体行为辩护，退回例外正当化。
12. 危险前是否真有稳定 `zn`。

## 三元与十元并行核验

三元层只能记录：

- 危险迫使选择；
- 主体作出例外；
- 事后重新解释行为。

十元层必须另证：

- 源端确为自然 `xz`；
- 目标端是稳定 `zn`；
- 被改变的是正确性、适用范围、无条件性还是最终指导资格；
- 替代原则能够跨案例迁移；
- 利益方向反转后仍保持一致。

“灾难改变了他”不能自动派生为 `xz 克 zn`。

## 动态链后果

```text
危险逼近
→ 实践空间缩窄
→ 主体作出极端例外
→ 事后可能只是为自己求生辩护
→ 危险解除、事实纠正、能力恢复
→ 在对象和利益方向不同的新案例中复判
→ 替代原则若在主体吃亏时仍工作
→ 旧原则才可能失去最终指导资格
```

改变的是原则无条件性、适用范围或最终指导资格中的具体一层，不机械生成邪恶、虚无、背叛、成熟或人格崩坏。

## 95% 门槛

高置信结论：

- 普通恐惧、逃跑、妥协和无法实践不足：99%。
- 自然危险能压缩实践通道并迫使排序、条件化和例外化：99%。
- 正确性、适用范围、优先级、实践能力和最终指导资格必须拆开：99%。
- 事后认可一次极端行为只能证明例外正当化：98%。
- 恢复后再承诺、反事实同条件复判和跨案例迁移是必要门槛：97%—98%。
- 利益方向反转测试能够排除自利性事后合理化、保护亲近者偏私和只对自己有利的替代规则：98%。
