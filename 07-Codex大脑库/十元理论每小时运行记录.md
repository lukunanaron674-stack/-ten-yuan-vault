## 源端点、目标端点、阶段、体量与显影条件

### 源端点 `z`

必须同时写清：

- 认可主体是谁；
- 认可对象是存在、能力、作品、身份还是选择；
- 该认可位置为何重要；
- 认可是否正确归因到主体；
- 认可是否只完成确认，没有同时提供资源、职位、照护、许可、新结构入口或长期承载。

掌声、曝光、完成、获奖与录取本身都不能代替 `z`。

### 目标端点 `nz`

必须观察：

- 对象是具体关系、共同阶段或可回返位置；
- 主体不愿该关系真正结束；
- 认可者退出评判后，关系仍可继续；
- 双方在零评价、零奖励窗口分别主动回返；
- 双方可以处理与作品、成绩、评价无关的冲突并恢复往来；
- 关系不是只靠原有友情、共同空间、长期共事、照护或组织承载维持。

### 被改变变量

1. 被认可者对认可主体或共同见证位置的保留意愿；
2. 认可位置从一次判断转为可回返关系的程度；
3. 双方在无评价窗口的独立发起率；
4. 评价角色退出后的关系持续度；
5. 非评价冲突后的修复能力；
6. 对特定认可对象的对象特异性；
7. 拿掉原有关系厚度后，新增停靠是否仍存在。

### 阶段、体量与显影条件

- 低体量：认可后短暂不舍、单方延迟离开或再次接近，只算状态层候选。
- 中体量：认可角色退出后，被认可者仍主动维护关系，并出现认可者独立回返。
- 高体量：双方在无评价、无奖励与普通冲突中仍保留可回返位置，形成跨阶段停靠。
- 显影条件：至少出现双方独立发起、认可角色退出、零评价窗口和一次非评价冲突修复。

## 候选机制

### 候选 A：认可者转化为可回返对象

```text
重要认可主体确认主体
→ 被认可者不再只把对方当评判位置
→ 认可位置获得关系价值
→ 在对方不再评价时仍想保留往来
→ nz 上升候选
```

理论后果：`z` 最多先改变对认可位置的单方保留意愿；若没有认可者独立回返，只能停留在低体量状态或回返提议。

本轮评价：约93%。

### 候选 B：共同被见证使阶段获得唯一性

```text
多人共同完成某事
→ 作品与合作被重要主体明确确认
→ “这是我们共同经历的阶段”被命名
→ 共同阶段获得不可替代性
→ 不愿结束增强
```

理论后果：被改变的是共同阶段在关系记忆中的唯一性，不是完成感本身。

风险：时间厚度通常早由长期 `xn` 共事、`n` 共同容器和原有友情提供；认可可能只是命名或显影。

本轮评价：约91%。

### 候选 C：认可先生成单方回返提议，后续互动才发展为双向停靠

```text
重要确认发生
→ 被认可者希望继续接近认可者
→ 提出一次不以评价为目的的回返
→ 认可者也在失去评判权后独立回返
→ 双方经普通冲突修复形成可信停靠
```

理论后果：`z` 可能只负责启动单方提议；从提议到成熟 `nz` 的跨阶段增长，可能主要来自后续 `n/nz` 互动，而非 `z` 单独生成。

本轮评价：约94%，为当前最强候选，但仍不足以锁定正式关系。

### 竞争解释 D：评价依赖

```text
获得重要认可
→ 主体继续接近同一认可者
→ 反复寻求下一次评价
```

若认可者退出评判后关系立即停止，目标是评价依赖或 `z` 自循环，不是 `nz`。

### 竞争解释 E：既有关系被命名

```text
长期共事/照护/友情已经形成关系厚度
→ 最终认可发生
→ 主体更明确意识到自己舍不得
```

这里只能判既有 `nz` 显影、命名或强化。

## 最近邻排除

- `xn 补 z`：组织证据与阶段节点让认可成立，不解释认可后的关系停靠。
- `n`：提供真实成员位置、承载和可返回容器。
- `xz 补 nz`：失去风险和最后窗口提高停靠重量。
- `nz 生 z`：既有不舍推动最后一次表达或完成。
- `x并z 生 z`：公开壳让认可对象可识别，不解释认可后为何不愿结束。
- `z` 自循环：主体继续追求下一次评价。
- `x/xn`：职位、奖励、合同、选拔和组织流程维持联系。
- 一般依恋：换成第三个同样重要的认可者后同样发生，不具对象特异性。

## 拿掉测试

1. **认可前关系厚度基线**：认可前是否已有长期共事、照护、友情、共同空间和反复返回。
2. **双向独立发起**：双方是否分别主动回返，而非一方持续追逐。
3. **认可角色退出**：认可者失去评判、奖励、资源和职位接口后，关系是否继续。
4. **零评价窗口**：双方不谈作品、成绩与认可时，是否仍愿意相处。
5. **非评价冲突修复**：与作品无关的普通冲突后，是否能恢复往来。
6. **第三认可者替换**：换成同等重要的认可者，主体是否同样产生留恋。
7. **拿掉奖励与新结构**：去除奖品、录取、签约、职位和资源后，停靠是否仍增长。
8. **拿掉共同容器**：去除剧团、学校、治疗室、公司和固定空间后，关系是否仍可回返。
9. **单方提议—成熟关系分离**：认可是否只启动一次回返提议，后续增长是否来自新的互动。
10. **反事实未认可组**：相同共事关系未获最终认可时，关系停靠强度是否显著不同。

现有案例没有通过完整组合。

## 动态链后果

当前只允许写：

```text
一个重要主体真正确认了我/我们
→ 我开始希望这个位置不只是一场判断
```

感觉走向：

> 从“终于被看见”，转成“我不只想得到判断，还想看看这个位置能否成为双方都愿意回来的关系”。

不得机械生成：

- 爱情；
- 友情本体；
- 永久关系；
- 共同体；
- 忠诚；
- 毕业留恋；
- 双向承诺；
- 稳定人物本体。

## 三元与十元并行

三元只核验作品整体从被看见、留恋、回返到停靠的精神运动。

十元只核验：

- `z` 是否具有明确认可主体、对象与确认内容；
- `nz` 是否出现具体关系对象、时间厚度和双方回返；
- 认可前关系厚度是否低；
- 评价角色退出、零评价窗口与非评价冲突修复是否通过；
- `n/xn/xz/x并z`、奖励和转场是否为真正来源。

不建立父子派生。
