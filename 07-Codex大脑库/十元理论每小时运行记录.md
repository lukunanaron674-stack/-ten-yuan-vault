### 对象分层

- 稳定本体：不由一次换装、署名或获奖反推人物稳定 `x并z` 或稳定 `z`。
- 当前状态：此刻进入、维护或失去公开壳，与此刻被看见、确认、否认或忽视分开。
- 行为功能：命名、署名、造型、建立公开角色、统一呈现属于 `x并z` 候选行为；展示、回应、确认和归因属于 `z` 关系行为。
- 光影：面具、制服、舞台、橱窗、品牌视觉、聚光和掌声只作显影辅助。
- 场景：发布会、展览、舞台、社交身份、评审与颁奖不能替代端点。
- 时间关系：壳先建立、认可后发生只证明先后；必须证明壳改变了识别和归因条件。
- 关系位置：公开身份持有者、包装者、被包装者与认可主体、被认可主体必须具体说明。
- 显影：观察壳的辨识度、连续性、归因接口，以及认可对象清晰度和确认持续性。
- 动态链：从“内容存在但难以指认”进入“有稳定界面”，再从“看见现象”进入“确认这是你的”。

### 源端点、目标端点、变量、阶段与体量

- 源端点 `x并z`：最低限度稳定的身份名、角色名、笔名、艺名、制服、面具、造型、品牌形象、署名格式、作品风格或公开界面；不要求欺骗，也不要求华丽。
- 目标端点 `z`：明确谁认可、认可谁或什么、认可内容为何、为何该认可位置重要；曝光、点击、传播和目标完成不能代替。
- 被改变变量：对象可识别性、认可归因稳定度、认可对象清晰度、主体是否获得可回应位置、认可是否能跨时间重复落到同一主体。
- 成立阶段：内容、能力或存在已有基础但认可难以归因；壳先建立并持续使用；认可主体随后通过该壳辨认和确认对象。
- 低体量：一次稳定署名或角色名使单个认可者辨认主体。
- 中体量：稳定公开身份使群体持续把多次作品和能力归因给同一主体。
- 高体量：壳成为跨时间文化识别接口，后续认可持续落到同一身份或作品体系。
- 显影条件：拿掉壳后，认可归因、清晰度或持续性显著下降；同时排除宣发、资源、权力和既有高知名度。

### 候选机制及理论后果

- A 可识别接口：主体、能力或作品原本存在，但边界模糊；名称、形象、形式或公开身份使认可主体知道“我看见的是谁／什么”。理论后果：`x并z` 的核心不是美化，而是为认可建立清晰对象。
- B 归因稳定：多次内容原本分散在事件、作品或匿名现象上；稳定壳把多次出现组织到同一主体，使认可反复归因。理论后果：艺名、角色形象、统一风格和品牌人格可加强 `z`，但品牌本身不是 `z`。
- C 扩大曝光：包装更醒目、更多人看到。该候选排除；曝光可来自 `xn` 宣发、`x` 资源、`zx` 显权或平台算法，且未说明谁确认了谁的什么。
- 统一机制：A 先建立识别对象，B 再使多次认可稳定归因，属于同一正式机制的前后阶段。

### 正例

1. 《窈窕淑女》伊莉莎，使馆舞会阶段：发音和礼仪能力已有基础；服装、妆容、称谓和社交角色形成可识别“淑女”壳；舞会认可主体将身份与能力稳定归因给这位被指认的女性。第三因素含 `xn` 训练、`x` 服装资源和希金斯背书，因此本例只证明壳改变识别与归因，不证明壳创造能力。
2. 蜘蛛侠形成稳定英雄身份后：蜘蛛图形、面具、制服和名称使公众、媒体与被救者把多次事件归因给同一公共主体。评价可正可负，但“谁在行动”被持续确认。
3. 匿名艺术家采用稳定笔名、署名格式和作品形式后：观众由分别评价匿名作品，转为持续确认“这些作品来自同一个人”，创作者的能力和精神存在获得稳定认可接口。

### 反例

1. 广告预算增加后曝光上涨：主要是 `x` 资源与 `xn` 宣发；若观众无法归因，没有证明 `z`。
2. 人物穿华丽服装但无人回应：只有 `x并z` 视觉显影，没有认可主体与内容。
3. 已实名知名作品更换统一封面，认可对象和强度不变：只是美术更新。
4. 强权规定所有人称某人为伟大领袖：主要是 `zx` 强迫与 `xn` 传播；被迫复述不等于真实确认。
5. 主体主动站上舞台表达自己：若关键变量是把自己送入认可者视野，优先检查 `z` 的行为显影，不自动判本生位。

### 最近邻排除

- 与 `z` 自身展示：展示是把自己或作品送入重要认可位置；本关系是先建立认可者能够稳定辨认和归因的接口。
- 与 `xn` 传播组织：`xn` 提高到达率和重复呈现；`x并z` 确定被传播对象以什么身份和形式被辨认。
- 与 `x` 资源投放：资源可以买位置、服装和制作，但不保证认可者知道“这是谁”以及认可什么。
- 与 `zx` 公开显权：`zx` 改变他者位置和权能范围；本关系不要求压过他者。
- 与 `x克z`：本关系建立识别和归因接口，使认可正确落到主体；`x克z` 掌握、封锁或劫持接口，使认可无法正确落到主体。

### 拿掉测试

1. 拿掉身份名、稳定形象或呈现形式后，认可仍以同样清晰度落到同一主体，则案例不依赖 `x并z`。
2. 拿掉认可主体和认可内容，只剩漂亮包装、面具或舞台，则没有 `z`。
3. 拿掉宣发渠道和资源后，少量但明确的认可仍通过壳稳定归因，可支持本关系。
4. 拿掉真实能力或内容，只靠壳骗取一次称赞，最多是误认或策略结果，不能证明稳定 `z`。
5. 拿掉壳后作品仍被看见但无法确认是谁、无法持续归因，说明壳改变了 `z` 的成立条件。

### 反向测试

```text
x并z 生 z：壳先建立，认可因此获得识别与归因接口。
z → x并z：认可需要或被看见愿望先存在，主体为了获得确认而设计艺名、形象、舞台人格或作品壳。
```

同一人物可形成反馈，但必须按阶段拆分，不能互相代证。

### 动态链后果

```text
内容、能力或存在已经出现
→ 但世界只能看见零散现象，无法稳定确认是谁
→ 名称、形象、身份或作品形式提供公开接口
→ 多次回应开始落到同一主体
→ “被看见”转为“这是你的存在／能力／作品”
```

改变的是认可层的对象清晰度和归因持续性，不机械生成赞美、成功、真实能力、稳定人格或所有人的认同。
