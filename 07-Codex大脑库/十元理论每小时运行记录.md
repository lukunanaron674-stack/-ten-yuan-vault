## 3. 源端、目标端、变量与成立条件

### 源端`nx`

- 人物与阶段：人物已被职位、亲属、作品署名、组织身份或公共称谓稳定代表，但持续不自称、不复述、不背书，也不主动以该身份发言和行动。
- 具体名词：身份方向不认领、主体认证撤回、第一人称代表接口停止、壳内被动存在。
- 排除：公开否认、撤回授权、辞职、除名、注销、停工、改名、停止履行与数据库更新。

### 目标端`x并z`

- 历史归因壳：旧作品、公开记录与既成事实仍否正确指向人物。
- 制度资格壳：职位、法律资格、亲属身份与名册是否仍有效。
- 静态第三方调用：无需人物现场配合时，他者能否继续通过壳查找、归因、分类和调用人物。
- 互动调用：需要人物现场自称、回应、表演或履行时，壳是否仍能当场工作。
- 主体认证：人物是否主动以第一人称使用、复述和背书身份。
- 被改变变量：五类接口各自的可用性、覆盖范围、当前调用率、恢复条件及是否依赖外部更新。

### 成立阶段、体量与显影条件

- 低体量：主体不自称但他者仍照常归因，只记内部距离与主动认证下降。
- 中体量：需要主体现场配合的互动调用停摆，但历史归因和制度资格维持，只记互动接口不可用。
- 高体量候选：第三方完全不知道主体态度，授权、履行、公告、数据库、传播与规则均冻结时，既存壳的历史归因、静态调用或制度效力仍同步下降，并仅靠主体重新认证恢复。
- 显影条件：第三方不知情；外部结构冻结；同一主体在沉默与自由重新认证之间切换；分别测历史、制度、静态与互动接口。

## 4. 候选机制

### A｜持续认证撤回削弱整体公共壳

```text
主体停止第一人称认证
→ 公共壳失去持续的一手确认
→ 第三方归因、调用与制度置信度下降
→ x并z整体覆盖下降
```

严格候选由约87%降为约85%。现有材料没有证明第三方不知情时历史归因和制度资格会随主体沉默变化。

### B｜互动认证壳当场停摆

```text
某身份壳需要主体现场自称、回应、表演或履行
→ 主体停止配合
→ 该次互动接口无法完成
→ 当场调用失败
```

这一机制约99%，但改变的是互动接口运行，不是历史归因壳、制度壳或整体公共覆盖。它最多是窄前置变量，不能替整条关系背书。

### C｜内部脱钩与未来生产停止

```text
主体不再认领旧壳
→ 新场合不再主动生产同类身份信号
→ 新壳生成减少
→ 下一周期续任或持续表演概率下降
```

这一解释约99%，目标是未来生成与续期，不是当前旧壳被克。

## 5. 正例候选

1. **《谍影重重》Jason Bourne与CIA身份系统，记忆恢复和拒绝旧身份阶段**：Bourne不再认领“训练出的特工身份”，但CIA记录、追踪与第三方归因继续有效。该例更像反证，说明主体拒认不降低历史制度壳。
2. **《楚门的世界》Truman与电视人物壳，结尾离场阶段**：Truman拒绝继续表演，互动壳与节目壳确实失效；但同时发生物理离场、公开事件、节目终止和主要履行停止，无法隔离纯`nx`。
3. **现场发言人严格候选**：发言人的职位、名册、授权、公告和第三方认知均保持，只在一次互动中拒绝以该职位自称和回应。当场发言接口会停摆，但历史职位壳与静态调用仍在。该例支持互动接口不运行，不支持整体壳被克。
4. **演员严格候选**：合同、名册、演出安排、宣传和第三方知识全部保持，只停止自称团员。若第三方不知道其态度时当前归因和调用仍下降，并能仅靠重新自称恢复，才接近纯例。目前缺两组可核验材料。

## 6. 反例

1. 辞职后不再被称为经理：职位与制度已变。
2. 组织公开除名成员：公开权能与程序改变壳。
3. 演员停工后身份淡化：履行、曝光和时间衰减。
4. 艺术家停用旧艺名，但旧作品仍正确归因：只证明新壳不生成。
5. 学生厌恶校服，但系统仍承认学生资格：内部脱钩。
6. 人物拒绝自称父亲，但家庭仍调用其职责：主体认证下降，亲属壳未消失。
7. 公开声明“不要这样称呼我”后调用下降：公开否认成为额外`zx/xn`作用源。
8. 需要本人签字的互动失败：接口缺少现场配合，不等于制度资格消失。

## 7. 最近邻排除

- `x 生 x并z`：实际掌握如何生成公共壳。
- `x并z 克 nz`：公共壳如何污染关系证据。
- `zx 克 n`：公开裁决、除名和成员边界改变。
- `xn`：名册、数据库、传播、续任与程序维护。
- `x`：职位、授权、署名、合同与现实接口。
- 新壳停止生成：未来生产变化。
- 履行停止：人物不再提供壳所代表的行为内容。
- 互动接口停摆：该次调用无法完成，不等于整体身份壳下降。
- 时间衰减与社会遗忘：未证明源于主体不认领。

## 8. 拿掉测试

1. 冻结登记、合同、职位、权限和数据库。
2. 冻结履行、曝光、公告、传播和第三方规则。
3. 让第三方完全不知道主体内部态度。
4. 分开测量历史归因、制度资格、静态调用、互动调用和主体认证。
5. 区分沉默不认领、私下否认、公开否认、撤权和停止履行。
6. 让主体自由重新认证，检查是否无需任何外部更新即可恢复。
7. 对比历史作品、亲属身份、法律身份、自愿社群身份和现场发言身份。
8. 排除停工、失联、遗忘、宣传停止和时间衰减。
9. 把互动任务改为无需主体现场配合，检查静态壳是否仍工作。
10. 把历史归因壳改为纯现场自我呈现壳，检查下降是否只发生在互动接口。

现有候选均未完整通过整体覆盖测试。

## 10. 动态链后果

```text
公共壳仍在代表我
→ 我停止复述、背书和第一人称认证
→ 主体与壳的内部距离扩大
→ 需要我现场配合的互动接口可能停摆
→ 新壳生成和续期概率下降
→ 历史归因、制度资格和静态调用仍可能完全保持
→ 只有整体覆盖随纯认证变化，才接近x并z被克
```

本轮只改变主体认证、互动接口可用性、新壳生成与续期感觉，不机械生成辞职、除名、法律失效、历史归因消失或社会遗忘。

## 11. 三元与十元并行核验

三元观察：

- 人物是否继续承担该角色；
- 他者是否继续通过身份接触、归因和调用；
- 哪类调用需要人物现场配合；
- 关系是否仍通过旧壳运行。

十元区分：

- `nx`：主体不占身份方向与认证位置；
- `x并z`：公共壳的识别、归因、代表与调用界面；
- `xn`：名册、数据库、程序和续期维护；
- `zx`：公开否认、除名与裁决；
- `x`：职位、授权、合同和现实接口。

三元与十元并行，不构成父子派生。
