## 源端点、目标端点、机制变量

### 源端点 `nx`

甲原本必须拥有真实可行路线、否决权、取回决定能力与承担结果资格，却跨轮次持续不提出路线、不使用否决、默认乙处理，并逐渐退出成员、资源与外部接口。一次委托、能力不足、职位服从和被迫交权均不足。

### 目标端点 `x`

乙此前没有稳定掌握，随后必须新增：自主使用与调配边界、事实否决权、排除替代方案、持续代表、保留剩余收益或把部分成本转嫁给甲。甲明确取回时，乙仍能事实阻止。常用联系人、熟练代理和多做劳动不足。

### 成立阶段与体量

```text
甲跨轮次空出方向位置
→ 乙承担决定、协调、记录和善后
→ 第三方与接口向乙集中
→ 甲明确取回
→ 排除第二入口
→ 乙仍保留自主使用、排除与剩余控制
```

低体量只允许判一项关系或资源边界；当前无证据支持稳定本体层。

## 候选机制与理论后果

### 候选 A：代理负荷转移

```text
甲持续不决定
→ 乙不断决定、整理、协调与善后
→ 乙运行负荷上升
```

后果：首先属于代理或 `xn`，不是 `x`。

### 候选 B：第三方接口固化

```text
甲持续让位
→ 第三方只向乙请求决定
→ 乙显得不可替代
```

后果：若撤掉乙本人后另一代理凭完整资料与流程即可接续，只是角色接口；不可替代性来自信息集中和熟练度时，优先判 `xn`。

### 候选 C：剩余控制形成

```text
甲持续让位
→ 乙不仅承担负荷
→ 还能决定剩余资源用途、排除甲直接使用、保留收益或转嫁成本
```

后果：最接近 `x`，但必须排除职位、合同、授权、账户、信息截断、制度保护与主动压迫。

### 候选 D：乙主动接管

乙扣留信息、排除替代路线或阻止甲取回。后果：直接作用源更接近乙的 `x/zx/xn`，甲的 `nx` 只是允许条件。

## 正例候选

### 1. 成年子女与父母｜家庭财务长期代管

子女有法律决定权，却长期不查看账户、不联系机构、不提出住房与职业安排；父母承担支付、材料和外部沟通。`nx` 的方向空位与代理负荷明确。未通过：父母若能排除子女取回，通常依赖账户、密码、材料、授权与信息控制。

### 2. 主创与制片｜创作团队对外接口

主创长期不接触合作方，制片处理预算、发布时间、合作和公开口径。接口集中与不可替代性明显。未通过：职位、合同、行业流程与信息集中构成强第二入口；撤掉制片本人后，完整流程与资料可能允许另一代理接续。

### 3. 《魅影缝匠》雷诺兹与西里尔

西里尔具有强事实掌握，但她原本已有管理位置和接口，不满足 `x` 从无到有。

### 4. 《穿普拉达的女王》安迪与米兰达

安迪持续放弃边界，米兰达控制扩大；米兰达既有职位、主动要求和公开权能才是更强启动源。

## 反例

1. 一次代班、代购、代签或临时委托：只是短期代理。
2. 伴侣负责财务，但双方随时查账、共同否决并可立即取回：无排他控制。
3. 大家习惯找乙，甲出现后只需重新通知：第三方认知滞后。
4. 乙承担大量协调与善后，却不能否决、代表或自主使用资源：代理或 `xn`。
5. 正式授予预算、账户、职位或合同权限：直接源是授权与 `x/xn`。
6. 乙靠扣留密码、材料、监控或信息截断阻止甲：主动控制是第二入口。

## 最近邻排除

- `x 生 nx`：乙先有掌握，甲方向空间随后被压缩。
- `xn`：组织、记录、熟练度、信息汇总和不可替代接口，但无剩余控制。
- `zx`：公开夺权、威胁、压退与阻止取回。
- 正式授权：权限直接改变，不是空位自然生成。
- 普通依赖：信任乙、常找乙，不等于乙有排他与剩余控制。

## 拿掉测试

1. 拿掉甲持续让位，乙若仍凭职位、产权、合同或账户掌握，不依赖本关系。
2. 拿掉乙主动阻止、信息截断和第三方制度化，乙还能否抵抗甲取回？
3. 拿掉授权、密码、材料、钥匙、合同与账户，掌握是否消失？
4. 拿掉第三方习惯，只看乙能否直接否决甲。
5. 撤掉乙本人但保留资料、流程与普通代理资格，另一代理能否接续？
6. 拿掉劳动、责任和善后，只观察乙是否拥有自主使用利益、排他与剩余控制。
7. 甲明确取回后，乙能否保留收益或把成本转嫁给甲？
8. 若事实抵抗和收益边界均依赖第二入口，`nx` 只能记作允许条件。

现有候选均未通过第3、5、6、7、8项完整组合。

## 反向测试

```text
nx 生 x 候选：
甲持续空出方向位置
→ 乙先承担代理负荷
→ 再形成不可替代接口
→ 只有出现排他、剩余控制与取回抵抗才接近 x

x 生 nx：
乙先拥有掌握边界
→ 甲可用方向被压缩
→ 甲沿乙方向推进
```

最终都可能呈现“乙决定、甲跟随”，但正向必须证明 `x` 从无到有并排除第二入口。

## 三元与十元并行核验

三元层只能记录甲让位、乙接手和第三方逐渐找乙。十元层必须另证乙获得的是 `x` 的掌握边界，而不是 `xn` 的组织负荷、熟练度和角色接口。三元中的“长期代管后变得不可替代”不能自动派生 `nx 生 x`。

## 动态链后果

```text
这次先按你的办法
→ 以后也默认你决定
→ 你承担越来越多协调、记录与善后
→ 别人逐渐只找你
→ 这首先只是负荷和接口集中
→ 撤掉你本人后若别人可以接续，仍不是个人掌握
→ 只有你能排除我、决定剩余用途、保留收益或转嫁成本
→ 才继续接近 x
```

改变的是决定负荷、接口集中、可替换性与可能的剩余控制，不机械生成权力人格、法定权限、管理能力或永久控制。

## 95%门槛

高置信结论：

- 旧“欲望积累”机制失效：99%。
- 同主体“越顺从越生成自己的 x”不成立：99%。
- 多做劳动、协调、记录、善后和常用联系人不足：99%。
- 不可替代性可能只是 `xn` 熟练度、信息集中与第三方习惯：98%。
- `x` 必须出现事实排他、剩余控制、自主使用利益或成本转嫁：98%。
- 可替换性／剩余控制测试是必要门槛：98%。
- 事实掌握依赖职位、授权、账户、信息控制、制度化或主动接管时，直接源属于第二入口：98%。

正式机制未达到95%。目前最多确认：`nx` 提供方向空位、代理负荷与掌握扩张条件，尚未证明其独立生成 `x`。
