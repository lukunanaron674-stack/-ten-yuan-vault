## 本轮性质

本轮只审计 `nx 生 x`。没有修改核心生补克表、关系词典、专项索引、旧审计或待确认队列，也没有新建专项。新推进是把“乙替甲持续决定”拆成两种完全不同的结果：一是乙承担更多决定、协调、记录与善后负荷，优先属于代理或 `xn`；二是乙取得可自主使用、否决、排他、代表或转嫁成本的边界，才触及 `x`。

## 源端点、目标端点、变量、阶段、体量与显影

源端点 `nx`：甲原本拥有真实可行路线、否决权、取回决定的能力和承担结果的资格，却跨轮次不提出路线、不使用否决、默认乙处理，并逐渐退出成员、资源与外部接口。

目标端点 `x`：乙此前没有稳定掌握，随后新增对具体对象、资源、权限或关系的自主使用、调配、事实否决、排他、对外代表或成本转嫁能力；甲明确取回时，乙仍可事实阻止，而非只要求重新通知、解释或完成普通流程。

被改变变量：决定负荷、协调负荷、信息集中度、资源使用权、否决权、排他能力、对外代表权、收益归属、成本转嫁方向，以及原权利主体取回的事实可行性。

成立阶段：甲已有权利但持续不使用；乙为维持运行反复代管；第三方开始围绕乙行动；甲明确取回；继续追查乙的抵抗来自负荷惯性还是独立掌握边界。

体量：低体量为单次代办；中体量为跨轮次代理与接口集中；只有出现事实否决、排他、代表或利益归属变化，才接近高作用量 `x`。当前无证据支持稳定本体生成。

显影条件：拿掉职位、合同、账户、授权、信息截断、制度保护和乙主动压迫后，乙仍能排除甲，且获得的不只是劳动与责任，还包括可自主使用的边界或利益。

## 候选机制与理论后果

### 候选 A：决定负荷转移

```text
甲持续不使用方向权
→ 乙为维持生活或项目不断决定、协调、记录和善后
→ 乙承担的运行负荷上升
```

理论后果：这更稳定地生成代理与 `xn` 组织负荷，不足以证明 `x`。若乙没有新增自主使用、排他、否决或代表能力，不能写成掌握。

### 候选 B：默认决定经第三方固化

```text
甲持续让位
→ 乙的决定反复落地
→ 第三方逐渐只向乙请求决定
→ 甲明确取回时，第三方仍拒绝绕过乙
```

理论后果：若抵抗只来自习惯与重新通知成本，仍是代理；若来自制度、合同或账户，直接源属于第二入口。

### 候选 C：接口集中形成事实掌握

```text
甲长期不接触成员、资源和外部关系
→ 信息、材料和口径集中到乙
→ 乙取得排除甲直接进入的能力
```

理论后果：信息截断与接口控制本身已经接近 `x/xn`，`nx` 只能记作允许条件。

### 候选 D：乙主动接管

```text
甲持续让位
→ 乙主动扣留信息、排除替代路线、阻止甲取回
→ 掌握形成
```

理论后果：直接作用源是乙的 `x/zx/xn`，不是甲的 `nx` 独立生位。

## 正例候选

1. **成年子女与父母｜家庭财务长期代管阶段**：子女有法律决定权，却长期不查看账户、不联系机构、不提出住房与职业安排；父母承担支付、材料、日程和对外沟通。支持点是方向空位与负荷转移明确。污染点是父母若能阻止取回，通常依赖账户、密码、授权与材料控制；若不能阻止，只是高负荷代理。
2. **主创与制片｜创作团队长期对外接口阶段**：主创持续不接触合作方，制片处理发布时间、合作、预算和公开口径。支持点是第三方逐渐只找制片。污染点是职位、合同、行业流程、预算权限和信息集中本身就是第二入口。
3. **《魅影缝匠》雷诺兹与西里尔｜工作室与生活管理阶段**：西里尔拥有强事实掌握，但她原本就有稳定管理位置与接口，不符合目标从无到有。
4. **《穿普拉达的女王》安迪与米兰达｜中段工作关系**：安迪持续放弃私人时间与拒绝边界，米兰达控制扩大；但米兰达既有职位、主动要求与公开权能才是更明显的作用源。

## 反例

1. 一次代班、代购、代签或临时委托：只是状态。
2. 伴侣负责财务，但双方随时查账、共同否决并可立即取回：分工或 `xn`。
3. 大家习惯找乙，甲出现后只需重新通知：正当性摩擦，不是事实掌握。
4. 乙承担更多决定、协调与善后，却不能自主使用资源、否决甲或代表甲：负荷增加，不是 `x`。
5. 正式授予预算、账户、职位、签字权或合同权限：权限配置直接生成。
6. 乙靠扣留密码、材料、监控或信息截断阻止甲：直接检查 `x/xn/zx`。
7. 乙可获取额外收益，但收益来自合同或职位：第二入口。
8. 甲原本没有决定资格：不存在可被持续空出的源端点。

## 最近邻排除

- `x 生 nx`：乙先有掌握，甲方向空间随后被压缩。
- `xn`：乙为维持运行承担计划、协调、记录与善后，若不能事实排除甲，优先判组织负荷。
- `zx`：公开夺权、威胁、压退或阻止甲取回属于主动显权。
- 正式授权：直接改变权限，不是空位自然生成。
- 普通依赖：更信任、更常找乙，不等于乙拥有归属、排他和否决能力。

## 拿掉测试

1. 拿掉甲持续让位，乙若仍凭职位、产权、合同或账户掌握，不依赖本关系。
2. 拿掉乙主动阻止、信息截断和第三方制度化，乙还能否抵抗甲取回？
3. 拿掉授权、密码、材料、钥匙、合同和账户，掌握是否消失？
4. 拿掉第三方习惯，只看乙能否直接事实否决甲。
5. 甲明确取回：乙立即归还则不成立；乙能够拒绝则继续追查拒绝来源。
6. 拿掉乙获得的收益、排他、否决与代表能力，只保留劳动、责任和善后，是否只剩 `xn` 负荷？
7. 乙能否把部分成本转嫁给甲，或自主决定资源用途，而非只被迫维持运行？
8. 若全部事实抵抗与收益边界均依赖第二入口，`nx` 只能记作方向空位与允许条件。

## 反向测试

```text
nx 生 x 候选：
甲持续空出方向位置
→ 乙先承担决定与组织负荷
→ 若再形成自主使用、排他、否决和代表边界
→ 才接近 x

x 生 nx：
乙先拥有掌握边界
→ 甲可用方向被压缩
→ 甲沿乙方向推进
```

两者最终都可能呈现“乙决定、甲跟随”，但正向必须证明 `x` 从无到有，且不是第二入口或既有掌握造成。

## 动态链后果

```text
这次先按你的办法
→ 以后也默认你决定
→ 你承担越来越多协调与善后
→ 这首先只是负荷和代理
→ 当我真正取回时
→ 再看你只是疲惫地归还
   还是能排除我、继续代表并自主使用资源
→ 后者仍须追查第二入口
```

改变的是决定负荷、接口集中与可能的掌握边界，不机械生成权力人格、法定权限、管理能力或永久控制。
