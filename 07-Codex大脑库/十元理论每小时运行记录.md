## 源端点、目标端点、阶段与变量

### 源端点 `nx`

必须同时满足：

- 主体原本真实拥有可认领、可取回的决定或否决位置；
- 没有法律、职位、年龄、制度或信息条件使其天然无权；
- 没有甲持续命令、威胁、惩罚或压退；
- 主体跨多个事项反复不提出方向、不接回接口并默认由他者决定；
- 不是一次委托、正常分工、短期疲劳或专业代理。

### 目标端点 `x`

必须新增：

- 对具体对象、时间、资源、权限、关系或接口的实际调配权；
- 不依赖每次重新征得同意的调用权；
- 对原本共同或模糊范围的事实否决权；
- 第三方把其读取为主要决定接口的稳定度；
- 在原 nx 主体尝试取回方向时仍可观察的剩余掌握边界。

工作量、熟练度、信息量、责任感、说话次数和流程协调权均不能代替 `x`。

### 成立阶段与体量

- 低体量：一次代办，只能判状态或授权。
- 中体量：多个阶段反复代决，资源、日程与接口开始向代理者集中。
- 高体量：原本共同的生活、工作、账户、关系与外部表达被一方整体纳入事实掌握。
- 最可能成立层：关系功能层和中体量事实控制层；稳定人物本体不由本关系自动生成。

### 被改变变量

1. 谁拥有最终调配权；
2. 谁拥有事实否决权；
3. 谁能直接调用资源和接口；
4. 第三方默认向谁请求决定；
5. 原主体取回方向后控制是否复位；
6. 代理负荷撤回后是否存在剩余掌握；
7. 剩余掌握是否仍依赖职位、信息不对称、密码、流程成本或主动要求。

## 候选机制

### 候选 A：持续空位被既有掌握边界吸纳

```text
乙拥有可认领方向位置
→ 乙跨阶段持续不认领
→ 甲为维持行动反复代为决定
→ 临时代决逐步成为默认权限
→ 甲的调配、否决与调用边界扩大
```

理论后果：

- `nx` 提供的是持续空位，不是主动赠予对象；
- `x` 必须是甲原有局部掌握边界向共同或模糊范围扩张；
- 若乙一取回方向，甲的控制立即消失，只能判关系功能或可撤回授权；
- 只有取回后仍有净剩余，才接近正式生位。

当前评价：约94%。比旧审计更接近门槛，但无两例纯案例。

### 候选 B：默认授权累积并使外部接口集中

```text
乙每次都默认甲处理
→ 第三方逐渐只向甲请求决定
→ 信息、材料、账户和沟通接口集中
→ 甲取得事实上的长期调用与否决位置
→ x 上升
```

理论后果：

- 可解释“关系内部让位”如何进入现实接口；
- 但第三方流程、信息集中与账户控制既可能是中介，也可能成为真正的 `xn/x` 来源；
- 必须把第三方接口复位、信息对称和职位权限还原后再看剩余控制。

当前评价：约92%。循环归因风险高于候选 A。

### 竞争解释 C：甲主动占位或强制

```text
甲持续要求、命令、惩罚或扩大占位
→ 乙退让
→ 甲控制更多
```

优先检查 `z 克 nx`、`zx` 强制或 `x` 自扩张，不属于纯 `nx 生 x`。

### 竞争解释 D：职位、制度与流程直接赋权

```text
职位／产权／合同／账户／组织流程
→ 甲天然取得控制接口
→ 乙沿该方向行动
```

控制来源是制度与既有 `x/xn`，不是乙的 `nx`。

8. 代理者只是更忙、更熟悉流程或掌握更多信息：工作负荷和 `xn`，不等于归其掌握。
9. 乙取回方向后甲立即交还账户、接口和否决位置：此前是授权或代办。
10. 甲在乙取回后仍控制，只因密码、职位、合同或第三方流程尚未更新：真正来源是既有 `x/xn` 或流程成本。

## 最近邻排除

- `z 克 nx`：甲主动表达、决定和占位，直接缩小乙选择空间。
- `zx` 强制：甲通过惩罚、威胁或公开权能压过乙。
- `xn` 组织：信息和流程为持续运行而集中，但未改变归谁掌握。
- 一次授权：有期限、可撤回且未形成默认长期控制。
- 正常分工：双方仍保留知情、否决、轮换和直接接口。
- 职位 `x`：合同、产权和岗位本来已把权限给甲。
- 信息优势：甲会做、知道得多，不等于拥有最终调用和否决权。
- `x 生 nx`：控制扩大后反过来缩小乙的可用方向，是后续反馈，不可倒证原生位。

## 拿掉测试

1. **无主动压迫测试**：拿掉甲所有主动要求、威胁、惩罚和占位，控制是否仍因乙持续空位扩大。
2. **原始资格测试**：乙是否真实拥有可取回决定权；若本来无权，源端点不成立。
3. **代理负荷撤回测试**：乙明确不再要求代办，甲新增的调配、否决和调用边界是否仍存在。
4. **方向取回测试**：乙重新提出路线、直接接触资源并行使否决，甲能否无条件阻止。
5. **第三方接口复位测试**：外部机构恢复直接向乙确认，甲的事实控制是否消失。
6. **信息对称测试**：乙重新获得账户、材料、密码和全部信息后，甲是否仍有新增控制。
7. **职位权限还原测试**：扣除合同、职位、产权和组织流程自带权限后，还剩多少由持续让位产生的掌握边界。
8. **可替换性测试**：换成另一名同等代理者，控制是否同样集中；若是，可能只是流程功能。
9. **剩余控制测试**：完成第3至第8项复位后，甲是否仍保留新增事实否决或调用边界。
10. **长期重复测试**：拿掉跨阶段重复，只剩一次代办，关系应降级为状态。

结果：结构候选能通过前半测试，但现有作品均无法通过完整“复位后剩余控制”组合。

## 反向测试

```text
x 生 nx：
甲掌握资源、权限、关系和接口
→ 乙的可用方向被甲控制
→ 乙越来越沿甲给出的方向推进
```

两方向可能形成反馈：

```text
乙先持续让位
→ 甲掌握扩大
→ 扩大的控制再使乙更难取回方向
```

但必须按阶段拆开：

- `nx 生 x` 改变甲的掌握范围；
- `x 生 nx` 改变乙的可用方向与通道；
- 后半段成立不能倒证前半段。

## 动态链后果

当前只允许写：

```text
我一次次不认领本可决定的部分
→ 对方为维持行动反复代决
→ 代决逐渐成为默认接口
→ 若我取回方向后仍不能完全复位
→ 对方才可能获得了新增掌握边界
```

改变的感觉走向：

> 从“我暂时不决定”，滑向“即使我现在想决定，这部分也未必能立刻回到我手里”。

不得机械生成：

- 对方一定邪恶；
- 主体永久失去人格；
- 所有合作都会变成控制；
- `nx` 人物必然制造 `x` 人物；
- `nx→x→zx` 可不经端点和阶段直接调用。

## 三元与十元并行核验

三元只核验作品整体从依赖、让位、代管到控制固化的精神感觉。

十元只核验：

- `nx` 主体是否拥有并持续不认领可取回方向；
- `x` 主体是否新增具体调配、调用、否决和归属边界；
- 控制是否在方向取回与代理撤回后仍有净剩余；
- 第三方流程、信息、职位和主动压迫是否为真正来源。

不建立：

```text
nx 是 x 的父级
x 是 nx 的必然后果
因果主题自动生成本体主题
```
