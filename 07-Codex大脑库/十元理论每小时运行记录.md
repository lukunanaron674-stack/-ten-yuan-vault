## 本轮性质

本轮只审计 `zx 生 zn`。没有修改核心生补克表、关系词典、专项索引、旧审计或待确认队列，也没有新建专项。新推进是增加“同原则载体替换／公开权能净增量测试”，用于分开：

```text
zx 让原则被更多人看见、相信它能进入现实
```

与：

```text
zx 直接使乙把原则变成自己的无监督义务
```

现有证据只稳定支持前者。

## 源端点、目标端点、变量、阶段、体量与显影

源端点 `zx`：甲的力量必须公开进入现实；决定范围、影响位置或等级位置扩大；他者与旧秩序被迫围绕甲重新反应。普通善举、演讲、牺牲、坚持、完成任务或私人榜样不足。

目标端点 `zn`：乙此前没有稳定原则认领；甲失败、离场，奖励、宣传、胜利、组织监督和英雄身份撤场后，乙仍在无人监督、可退出且会受损时按原则行动。乙坚持的是原则，而非英雄、阵营、职位、遗命或组织任务。

被改变变量：乙对原则的内部确定度；无监督执行持续度；原则与英雄个人的可分离度；新情境独立推导能力；原则向无关对象的泛化范围；英雄背弃原则时乙是否仍选择原则；以及甲的公开权能相较其他传播载体提供的净作用量。

成立阶段：甲公开显权；乙此前无稳定 `zn`；甲撤场；乙面对未规定的新情境；删除英雄身份与传播壳；乙仍按原则行动；最后做同原则载体替换，确认没有 `zx` 时目标变化明显下降。

体量：低体量为单个见证者形成阶段性原则认领；中体量为一组见证者在英雄撤场后独立行动；高体量要求原则脱离英雄、奖励与组织监督，成为共同体内部不可背弃的意义。当前没有证据支持高体量正式生位。

显影条件：无人监督、逆风、失败、英雄缺席、新情境、无关对象、英雄背弃，以及同原则由非权能载体呈现时的差异。

## 候选机制与理论后果

### 候选 A：公开见证入口

```text
甲以 zx 把原则公开推入现实
→ 乙看见原则不是空话
→ 原则的注意权重与现实可信度上升
```

理论后果：能解释原则为何被认真看见，不能独立证明 `zn` 已生成。

### 候选 B：公开承担代价

```text
甲公开推进原则并承担位置、利益或生命代价
→ 乙排除甲借原则谋利的解释
→ 乙更愿意认真对待原则
```

理论后果：首先证明甲自己的 `zn`；乙的变化仍可能来自 `z` 的精神认可、`n/nz` 的情感关系或原则内容本身。

### 候选 C：新情境独立推导

```text
甲撤场
→ 乙遇到甲未规定的新问题
→ 无遗命、职位、计划或流程可照抄
→ 乙自行从原则推出行动并承担损失
```

理论后果：能排除遗命执行和流程延续，却仍不能证明直接源必须是 `zx`。

### 候选 D：同原则载体替换／公开权能净增量

```text
保持原则内容、代价、乙的处境与结果不变
→ 只把甲的公开凌驾替换为私人劝说、无权能示范或文字传播
→ 比较乙是否仍形成同等 zn
```

理论后果：若目标仍成立，只能判 `zx` 提供公开见证与可信度增量；若目标明显消失，才继续接近直接生位。

## 正例候选

1. **《饥饿游戏》凯特尼斯与第十一区见证者｜露露死亡后的公开悼念阶段**：凯特尼斯的公开行为迫使都城权力重新处理她的影响，原则进入公共现实；但地区压迫、露露死亡、群体身份、传播符号和反抗组织均很强。拿掉凯特尼斯的 `zx`，长期压迫与死亡经验仍可能生成同一原则，未通过净增量测试。
2. **《V字仇杀队》V 与伊薇｜V 死后的列车行动阶段**：伊薇继续推进，但主要执行 V 明确留下的计划，并混入训练、胁迫、关系依恋、面具身份壳和阵营继承。更接近遗命执行。
3. **《勇敢的心》华莱士与罗伯特·布鲁斯｜华莱士死后重新反抗阶段**：华莱士公开行动提供强见证，但罗伯特原有民族身份、政治利益与既有信念过强，目标从无到有无法成立。
4. **《悲惨世界》主教与冉阿让｜主教宽恕后的长期变化**：目标 `zn` 变化清楚，但主教源端更接近 `zn/n/z`，公开扩权与现实凌驾不足。

## 反例

1. 强者获胜后群众加入胜方：利益与胜利预期。
2. 英雄授勋、立像或进入教材：`z/x并z/xn` 的认可、身份壳与传播。
3. 群众因恐惧服从：`nx` 或权力结果。
4. 追随者原本已有同一原则：既有 `zn` 显影。
5. 英雄牺牲后继承职位、制服、任务或遗命：`x/x并z/xn/nx`。
6. 删除英雄姓名和阵营后原则无法运行：英雄依附，不是原则内化。
7. 私人劝说、文字传播、无权能者示范或乙自身经验同样足以形成原则：不能证明 `zx` 是必要源。
8. 同等 `zx` 推进另一套原则时乙也立即接受：更像服从、崇拜或胜方认同，不是原则内容被内化。

## 最近邻排除

- `zn 生 zx`：甲先有原则，再由甲本人显权。多数英雄案例首先证明这一方向。
- `z`：英雄的精神确认、榜样位置与重要认可。
- `x并z`：旗帜、称号、面具、纪念与阵营身份壳。
- `n/nz`：恩情、悲痛、共同体承载与关系余温。
- `xn/nx`：教育、传播、职位继承、组织流程与遗命执行。
- 乙独立判断：没有甲的 `zx` 也会形成原则时，不能归给本关系。

## 拿掉测试

1. 拿掉甲的公开显权，只保留原则内容、善举、牺牲与代价，乙是否仍形成同一原则？
2. 拿掉胜利、奖励、宣传、纪念与监督，乙是否仍坚持？
3. 拿掉乙原有信念，能否证明原则真实新增？
4. 删除英雄本人、姓名、形象、口号与阵营，乙是否仍坚持？
5. 拿掉遗命、计划、职位与流程，乙能否处理未规定的新情境？
6. 把对象换成英雄阵营之外甚至敌对的人，乙是否仍按原则行动？
7. 英雄后来背弃原则，乙是否拒绝英雄？
8. 拿掉个人恩情、悲痛与关系余温，乙是否仍承担普遍原则？
9. 将同一原则改由私人劝说、无权能示范或文字传播呈现，乙是否仍形成同等 `zn`？
10. 用同等 `zx` 推进无关或相反原则，乙是否也接受？若是，优先判服从、崇拜或胜方依附。
11. 拿掉甲的 `zx`，只保留乙自身压迫经验和独立判断，原则是否仍出现？

现有候选均未通过目标从无到有、去来源、新情境、原则泛化、英雄背弃与公开权能净增量的完整组合。

## 反向测试

```text
zx 生 zn 候选：
甲公开显权
→ 乙在甲撤场后独立行动
→ 去英雄化后原则仍运行
→ 且非权能载体无法产生同等目标变化

zn 生 zx：
甲先有稳定内部原则
→ 甲自己公开推进
→ 取得现实决定位置
```

现有英雄案例仍更稳定支持 `zn 生 zx`。甲自己的原则和显权不能冒充另一个乙新增了 `zn`。

## 三元与十元并行核验

三元层只能记录：

- 甲公开推动；
- 乙受到影响；
- 乙后来继续行动。

十元层必须另证：

- 源端确为 `zx` 的公开权能净增量；
- 目标端确为乙从无到有的 `zn`；
- 不是原则内容、关系感动、传播、身份或组织流程完成作用。

三元中的“英雄影响追随者”不能自动派生成十元 `zx 生 zn`。

## 动态链后果

```text
我看见他把原则推入现实
→ 我可能只是震撼、崇拜或执行遗命
→ 他失败、离场，奖励与命令中心消失
→ 我面对他未规定的新情境
→ 删除他的姓名、符号与阵营
→ 我仍从原则推出行动
→ 即使他背弃原则，我也拒绝他
→ 再把同一原则改由无权能载体呈现
→ 若我仍同样形成原则，zx 只提供公开见证
→ 只有公开权能具有不可替代净增量，才继续接近直接生位
```

改变的是见证者对原则的内部归属、来源可分离度、新情境推导、泛化范围及源因果归属，不机械生成英雄崇拜、共同体、胜利、正义性或永久传承。

## 95%门槛

高置信结论：

- 同主体“行动自证”不能作为正式 `zx 生 zn`：99%。
- 英雄崇拜、胜方追随、纪念传播、遗命执行与服从不是 `zn`：99%。
- 源目标必须跨主体：98%。
- 去来源、新情境、原则泛化与英雄背弃是目标端必要测试：98%。
- `zx` 能提高原则的公开可见性与现实可信度：97%。
- 公开见证入口不等于内部义务生成：98%。
- 同原则载体替换与公开权能净增量测试是直接生位的必要门槛：98%。

正式机制未达到95%。缺少两个通过全部测试的具体人物案例；现有案例持续混入压迫经验、传播、关系感动、既有信念、遗命和组织结构。当前只足以保留“`zx` 提供公开见证入口”的窄候选，不足以确认它独立生成乙的 `zn`。本轮不新增待确认问题。
