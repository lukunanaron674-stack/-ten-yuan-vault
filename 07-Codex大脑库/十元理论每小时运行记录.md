### 对象分层

- 稳定本体：`x` 是长期以归属、占有和掌握边界成立；`nz` 是长期保留真实共同时间余温、不愿结束与回返姿态。一次控制或一次不舍不能反推本体。
- 当前状态：本关系主要发生在原有余温仍在、掌握者持续收紧决定、退出与回返边界的阶段。
- 行为功能：`x` 显影为替代决定、最终否决、控制交往、路线、进入与退出；`nz` 显影为等待、回返、继续靠近与不愿结束。
- 光影：门锁、定位、密码、封闭空间、暖光、旧物和旧居只作辅助显影。
- 场景：亲子、伴侣、监护与共同生活只是场景候选。
- 时间关系：真实余温先存在，掌握边界随后收紧，自主停靠与回返下降。先后本身不足。
- 关系位置：掌握者与被掌握者必须处于同一关系结构。
- 显影：观察否决、独占、调用、退出控制是否上升，自愿停留、回返与不愿结束是否下降。
- 动态链：从“这里仍是我想回来的关系”转成“只有离开，我才能重新成为可以选择的人”。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `x`：必须真实掌握行动、交往、身份、路线、进入、退出或回返许可，并实际使用最终否决或调用权。普通吃醋、建议、临时保护和只有控制欲形容词均不足。
- 目标端点 `nz`：克制前必须已有真实共同时间、关系余温、不愿结束和可等待、回返或继续停靠的位置。
- 被改变变量：停留是否仍自愿；离开与返回是否仍由主体决定；回返能否证明余温；共同生活是否由关系变成管理；原关系位置的安全感、可信度和不愿结束强度。
- 成立阶段：关系已有余温 → 掌握边界持续收紧 → 留下不再证明自愿 → 原关系位置变成被管理范围 → `nz` 下降。
- 体量：低体量为少量事项被代决；中体量为交往、时间与路线持续受控；高体量为退出权、身份与人生路线被纳入掌握。
- 显影条件：原有 `nz`、`x` 掌握真实增加、自主退出或回返权下降、停靠意愿实际下降，并排除 `zx` 暴力、`xn` 监控流程、法律强制和原本无余温为唯一启动源。

### 候选机制

- A 自愿性被抽空：留下、离开与返回均受控制，使“仍留在这里”不再证明主体愿意停靠。理论后果：物理同处可以继续，而 `nz` 已下降。
- B 关系位置被管理位置替代：持续替代决定使对方不再作为独立关系主体出现，“我们之间”变成“你在我的范围内”。理论后果：改变的不是距离，而是关系对象资格。
- 统一机制：A 是直接作用过程，B 是结构结果。`x` 先抽空停靠自愿性，再把关系位置替换成管理位置。

### 正例

1. 《海底总动员》前段马林与尼莫：父亲持续替代决定、否决探索，使父子关系与家被体验为管理范围，尼莫以离开争取自主。
2. 《青春变形记》家庭仪式冲突前的明与美美：母亲掌握时间、朋友、身体解释和人生安排，使家庭停靠逐渐等同于放弃自身路线。
3. 《魔发奇缘》离塔前后的葛朵与乐佩：葛朵掌握空间、信息、身份解释和离塔许可，塔从可返回的家变成不能自由退出的管理空间。

### 反例

1. 伴侣一次吃醋但没有限制行动或退出权：只有状态。
2. 家长给安全建议且孩子保留最终决定权：可能是 `n` 或协商。
3. 暴力威胁不准离开：主要是 `zx` 高显影。
4. 安装监控但主体没有最终调用和否决权：可能是 `xn`。
5. 关系原本无余温：目标端点不存在。
6. 双方自愿共享位置和账户且可随时撤回：没有单向掌握。
7. 短期医疗监护有明确退出条件：优先检查 `n/xn`。
8. 人物仍愿自主回家、主动联系和回返：尚未证明 `nz` 下降。

### 最近邻

- 与 `nz 克 x`：本轮是控制先加强、`nz` 下降；反向是余温先显影、`x` 主动下降。
- 与 `x并z 克 nz`：身份壳使人不知道自己停靠的是谁；本轮是知道对方是谁，却不能自由决定是否停靠。
- 与 `zx`：`x` 是“你归我决定”；`zx` 是“我公开逼你服从”。
- 与 `xn`：`xn` 改变流程和监控结构；`x` 改变最终决定、退出与调用权。
- 与 `n`：保护保留自主路线时属于 `n`；进入单向否决与退出控制后才越过为 `x`。

### 拿掉测试

1. 拿掉实际掌握，只保留关心、建议或情绪，若 `nz` 仍下降，则不依赖本关系。
2. 拿掉原有 `nz`，目标端点不存在。
3. 拿掉 `zx` 威胁，只保留低调决定、否决与退出控制，若 `nz` 仍下降，支持 `x` 直接作用。
4. 拿掉 `xn` 监控流程，只保留最终权限，若关系仍受损，支持 `x`。
5. 恢复退出、否决和自主回返权后，若 `nz` 回升，说明自愿性是关键变量。

### 反向测试

```text
x 克 nz：掌握加强 → 自主停靠、回返与不愿结束下降 → nz 被克。
nz 克 x：关系余温先显影 → 掌握者主动收窄控制边界 → x 下降。
```

两方向可形成反馈，但不能互相代证。判断取决于先启动的源端点和被改变变量。

### 动态链后果

```text
我们原本有可以回去的关系
→ 你把我的路线、退出与返回都纳入掌握
→ 我仍留在这里，却不再是因为想留下
→ 关系从停靠变成管理
→ 我开始把离开视为恢复主体位置的必要行动
```

改变的感觉层是：从“我还想回到这里”，转成“只有离开这里，我才能重新成为可以选择的人”。不机械生成分手、仇恨、暴力反抗、控制者必然邪恶或关系永远不能修复。
