### 对象分层

- 稳定本体：不由一次制度阻拦反推人物稳定 `xz`，也不由一套规则反推主体稳定 `xn`。
- 当前状态：本轮主要核验结构已经运行、主体开始偏离、危险逐步显形的阶段。
- 行为功能：`xn` 通过排程、登记、监控、分工、路线和权限节点持续处理偏差；`xz` 通过逃离、抢窗口、冒险通过边界显影。
- 光影：网格、监控屏、时钟、追踪光、断裂路径和倒计时只作辅助证据。
- 场景：学校、公司、监狱、实验室、交通系统、站台和走廊不能替代端点。
- 时间关系：结构先运行、危险后出现只证明先后；必须证明结构处理偏差造成危险可到达性上升。
- 关系位置：管理者、设计者、维护者和系统操作者属于源位置；偏离者、异常者和逃亡者属于目标位置，但称谓本身不构成关系。
- 显影：观察偏差识别率、暴露追踪概率、安全路线、时间窗、退路和稳定停留可能性是否变化。
- 动态链：改变命运路径的可通过性，不机械生成漂流人格、逃脱或胜利。

### 源端点、目标端点、变量、阶段与体量

- 源端点 `xn`：存在主动组织者或已经外化的持续结构，规定正常顺序与时间窗，安排人员、路线、许可和信息接口，记录偏差，并在人物不配合时继续运行。
- 目标端点 `xz`：危险由抽象可能变成可感知逼近；安全路线、时间窗或身份接口减少；偏离会触发追踪、拦截或暴露；人物不能稳定停留，继续等待的代价迅速增加。
- 被改变变量：偏离识别概率、暴露与追踪概率、安全路线数量、可用时间窗、退路宽度、稳定停留可能性。
- 成立阶段：`xn 已运行 → 主体偏离或试图退出 → 结构识别并处理偏差 → 风险路径形成`。
- 低体量：一次身份检查、路线关闭或时间窗缩短。
- 中体量：系统持续追踪，多条安全路径关闭，停留本身变危险。
- 高体量：制度、城市或生活系统全面识别偏离，主体几乎没有结构外安全位置，`xz` 成为阶段主导。
- 显影条件：必须同时存在持续组织、偏差处理、危险显形和路径压缩；拿掉结构后危险应显著下降。

### 候选机制及理论后果

- A 偏差识别：正常流程、记录、监控和节点让偏离可识别，偏离者被标记、追踪或拦截。理论后果是目标变量首先落在暴露率和追踪率。
- B 安全路径压缩：路线、许可、资源和时间窗被结构持续处理，合法安全路径逐条关闭，人物进入临界行动。理论后果是即使没有明确追兵，只要结构持续减少可通过路径，`xz` 也可成立。
- C 单纯排斥：制度不认可人物，只造成孤独、身份焦虑或不公平感；没有危险显形和退路缩窄，本轮排除。
- 机制统一：A 是结构识别偏差，B 是结构继续处理偏差；二者是同一正式机制的前后阶段，不是互斥关系。

### 正例

1. 《逃出绝命镇》克里斯决定离开后：阿米蒂奇家族的邀请、筛选、催眠、拍卖、手术、人员分工和信息隔离已经构成持续 `xn`；克里斯的离开偏差被识别后，车钥匙、身体控制和出口连续关闭，危险从不适感转为明确捕获临界。拿掉完整流程，只剩一次家庭歧视，无法形成同等密度的风险路径。
2. 《楚门的世界》楚门连续尝试离开海景镇阶段：克里斯托夫与节目组长期组织演员、交通、广播、天气、路线和播出节点；楚门偏离后，交通、道路、演员和人工风暴持续封锁正常出口，使他被推入海上临界。
3. 纯结构例：全自动研究设施通过分区权限、门禁记录、摄像头交接、巡逻路线和出口时序识别携带证据逃离的研究员，自动锁闭相邻区域并调整巡逻，使出口逐个减少。

### 反例

1. 学校课表让学生压抑：只有 `xn` 场景和情绪变化，没有危险显形、追踪和路径压缩。
2. 航班因天气取消：人物可能滞留，但源端点不是主体主动组织的 `xn`。
3. 杀手临时追赶逃跑者：危险成立，但没有持续流程、记录与交接，优先检查普通 `xz` 场景或 `zx` 行动。
4. 人物进入制度前已经长期漂流：只能证明先后共现，不能把既有 `xz` 倒写为制度生成。
5. 危险出现后人物制定逃生计划：方向是 `xz→xn` 的动态后果，不是本关系。
6. 监控镜头、制服、迷宫、站台和倒计时只形成视觉相似，不能替代作用机制。

### 最近邻排除

- 与 `xn克zx`：两者源端点都可为持续结构，但 `xn克zx` 改变即时显权扩张范围；`xn生xz` 改变偏离者的安全路线、时间窗与危险可到达性。
- 与 `x克z`：若只是掌握资源、出口或权限，让目标无法完成或被确认，优先检查 `x克z`；只有持续组织使偏离被识别、追踪并压缩安全路径时才进入本关系。
- 与普通 `xz` 场景：走廊、迷宫、追逐和倒计时只说明场景显影，必须证明风险路径由 `xn` 持续产生。
- 与旧“制度排斥→身份漂流”：社会排斥、身份焦虑和制度题材都没有落到目标变量，正式撤回。

### 拿掉测试

1. 拿掉记录、流程、交接和重复处理，只剩一个人临时阻拦，危险若仍完整成立，则主要是 `zx` 或普通冲突。
2. 拿掉人物偏离，结构只是背景，说明关系只在结构处理偏差阶段启动。
3. 结构发现异常却没有关闭路线、减少时间窗或提高追踪率，只产生一次提醒，`xz` 不成立。
4. 拿掉 `xn` 后，怪物、自然灾害或私人仇杀仍会以相同方式追上人物，案例不依赖本关系。
5. 《逃出绝命镇》中拿掉家族重复流程，只保留一次歧视，克里斯仍会不适但不会形成同等捕获临界，故 `xn` 是必要变量。

### 反向测试

```text
xn 生 xz：结构先运行，偏离被识别和持续处理，危险随后显形。
xz → xn：危险先逼近，人物随后主动组织路线、时间、资源和节点应对。
```

同一故事可形成反馈，但必须分阶段写，不能压成“规则让人计划逃跑”。

### 动态链后果

```text
世界已经被安排好
→ 不偏离时暂时安全
→ 一旦试图离开，结构比人物更早识别下一步
→ 正常出口逐个关闭
→ 人物从自由选择转为抢最后一条还能通过的路
```

改变的是命运路径的可通过性。它不自动生成稳定 `xz` 人格、制度必然危险、逃脱、反抗或胜利。
