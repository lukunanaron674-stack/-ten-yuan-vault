### 对象分层

- 稳定本体：`xz` 是持续危险逼近、退路缩窄与无法稳定停留；`zn` 是不依赖奖励、认可和结果保证的内部意义确定。一次危机妥协不能反推稳定本体变化。
- 当前状态：恐惧、绝望、麻木、犹豫和创伤反应可以遮蔽意义显影，但不等于原则正确性改变。
- 行为功能：逃跑、服从、撒谎、公开否认、放弃行动与违背誓言只证明行为受压；只有后续持续改判原则才触及 `zn`。
- 光影：追杀、刑场、黑暗、警报、倒计时和逼近镜头只作危险显影。
- 场景：战争、灾难、酷刑、迫害和生存困境只是候选场景；若有施害者主动设计，必须另查 `zx/xn`。
- 时间关系：危险先出现、主体后妥协只是必要时间序列；本轮必须继续观察危险解除后的原则判断。
- 关系位置：追捕者、施害者、制度与受困者须拆开；施害者命令和惩罚流程不能整体塞进 `xz`。
- 显影：主体是否从“原则正确但我做不到”转为“原则不再正确、只在安全时适用或不再值得支配选择”。
- 动态链：危险压缩行动空间后，是否进一步压低原则的无条件性与最终指导资格；不机械生成虚无、背叛或人格崩坏。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `xz`：可感知危险或异质威胁真实逼近，退路、时间窗和安全行动可能性持续缩窄；不是抽象混乱、悲观思想或施害者的一句威胁。
- 目标端点 `zn`：危险前已经稳定存在的内部原则，主体原本认为其本身正确且应当指导现实选择。
- 被改变变量：原则的无条件正确性、适用范围、最终指导权重、危险解除后的恢复程度，以及主体是否仍愿意让原则支配高代价选择。
- 成立阶段：危险前原则稳定 → 危险反复使遵循原则直接扩大损失 → 主体重写原则适用条件 → 危险解除或降低 → 原原则仍未恢复最终指导资格。
- 体量：低体量是一次犹豫、妥协或表态，不足；中体量是多次按生存条件改写选择；高体量是危险结束后仍持续否定原原则或把它降为安全情境下的奢侈规则。
- 显影条件：拿掉施害者命令、制度惩罚、操纵、奖励和另一条意义排序后，危险本身仍是必要启动源；目标变化必须在危险解除后继续存在。

### 候选机制

- A 生存条件重写：危险使每次按原则行动都显著扩大毁灭概率，主体把“无条件正确”改成“只有安全时才适用”。理论后果：若成立，克制的是 `zn` 的无条件性和最终指导资格，而非行为能力。
- B 责任反转：主体逐渐认为继续坚持原则会把无辜者、亲人或共同体推入危险，因此原原则从“正确”变成“不负责任”。理论后果：这可能不是 `xz` 直接克 `zn`，而是另一条保护性 `zn` 在意义排序中压过原原则。
- C 实践受阻但意义不变：危险使主体逃跑、屈服或暂时无法实践，却仍判断原则正确。理论后果：改变的是状态、行为能力或显影机会，不构成克制。
- D 施害者结构冒充危险：公开命令、精密两难、制度化迫害或持续洗脑迫使主体改判。理论后果：主要启动源可能是 `zx/xn`，危险只是场景与结果。

### 正例候选

1. 《蝙蝠侠：黑暗骑士》哈维·丹特后期：丹特此前把依法实现正义视为最终指导原则；瑞秋死亡、毁容和连续危险后，他转向硬币与复仇，原则本身失去指导资格。限制：小丑的主动设计、操纵和强迫混入 `zx/xn`，创伤与丧失也是强第三因素。
2. 《沉默》罗德里格斯踏绘阶段：持续看到他者因自己的拒绝而受刑，使“不可弃教”的无条件原则被重划。限制：幕府制度化迫害含 `zx/xn`；结果也可能是“救人”这一更高 `zn` 重新排序，而非原 `zn` 被危险克制。
3. 《1984》温斯顿在101室至释放后：极端危险下背叛朱莉娅，后续爱上老大哥，显示意义判断可能持续改变。限制：系统性酷刑、洗脑与权力结构极强，源端点更可能是 `zx/xn`，不能作为纯 `xz` 案例。

### 反例

1. 《勇敢的心》华莱士受刑与死亡逼近时仍坚持自由；危险提高，原则正确性不变，属于 `xz` 与 `zn` 共现或 `zn` 反向压低危险支配。
2. 《末路浩劫》父亲长期处于危险中仍坚持保护孩子和“携带火种”；行为受限但意义持续指导选择。
3. 角色因恐惧逃跑，安全后承认自己当时软弱却仍认为原原则正确；改变的是行为能力与羞耻状态。
4. 施害者逼角色公开写悔过书，但其内心仍不认同；公开壳或表态接口改变，不是 `zn` 改判。
5. 为救另一人而暂时违背誓言，之后仍承认誓言正确；这是意义排序或行动优先级变化。

### 最近邻排除

- 与 `zx/xn` 对 `zn` 的强制：公开权能、惩罚和制度流程直接要求否认意义；本轮若独立成立，危险本身应在拿掉命令与制度后仍改变原则判断。
- 与普通状态崩溃：恐惧、麻木、绝望和创伤可以阻断显影，却不等于“原则不再正确”。
- 与 `zn` 内部优先级重排：为了救人而放弃不可弃教，可能是保护性意义压过身份性意义，不是危险直接消灭意义。
- 与反向 `zn 克 xz`：原则保持无条件有效，使主体不再让危险决定最终方向；目标变量是危险支配力，而非意义正确性。

### 拿掉测试

1. 拿掉危险，只保留施害者命令、惩罚和制度流程，若改判仍发生，案例主要依赖 `zx/xn`。
2. 拿掉施害者与操纵，只保留不可控危险，主体是否仍把原则降为条件性？当前没有两个高纯人物案例通过。
3. 拿掉行为失败，若主体仍明确认为原则不再正确，才可能落到 `zn`；若只是做不到，则不成立。
4. 拿掉原有稳定 `zn`，人物此前只是重复群体口号，则危险只是揭露目标端点从未成立。
5. 拿掉创伤、丧失和另一条意义排序后，原则改判是否仍持续？现有候选均不能可靠通过。
6. 危险解除后若原则恢复指导作用，只能判暂时遮蔽或实践受阻。

### 反向测试

```text
xz 克 zn 候选：危险持续关闭退路 → 原则被改写为条件性 → 危险解除后仍失去最终指导资格。
zn 克 xz 候选：原则保持无条件有效 → 主体不再让危险决定最终方向 → 危险对选择的支配下降。
```

华莱士与《末路浩劫》父亲更接近反向或共现，不能拿来支持正向克制。

### 动态链后果

```text
危险逼近、退路缩窄
→ 每次坚持原则都放大不可承受损失
→ 主体开始把“无条件正确”改成“安全时才适用”
→ 危险结束后，原则仍没有恢复最终指导资格
→ 生存规则、既有安排或他者路径接管选择
```

改变的是原则的无条件性、适用范围与最终指导权重，不机械生成背叛、邪恶、虚无、永久创伤或人格转型。
