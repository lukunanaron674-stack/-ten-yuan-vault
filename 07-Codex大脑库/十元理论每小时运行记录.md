## 3. 源端、目标端、变量与成立条件

### 源端`nx`

- 人物与阶段：人物已经被稳定职位、亲属、作品署名、组织身份或公共称谓代表。
- 人物行为：持续不自称、不复述、不背书、不主动以该身份发言或行动；被称呼时保持沉默或转开话题。
- 具体名词：身份方向不认领、主体主动认证撤回、壳内被动存在、第一人称代表接口停止。
- 排除：公开辞职、除名、注销、撤回授权、停止履行、改名、公告切割与数据库更新。

### 目标端`x并z`

- 具体名词：既存公共身份壳、作品归因壳、职位代表壳、亲属或组织调用接口。
- 四个被改变变量：
  1. 制度有效性；
  2. 外部归因准确度；
  3. 第三方可调用性；
  4. 主体主动认证与第一人称使用。
- 目标成立要求：至少前三项之一在外部结构冻结时真实下降，并能由主体单独重新认证恢复。
- 排除：只降低第四项、只停止新壳生成、只降低下一周期续任概率。

### 成立阶段、体量与显影条件

- 低体量：主体不再自称，但第三方仍照常归因和调用，只记内部脱钩。
- 中体量：新作品、新场合不再使用旧壳，只记新壳停止生成或续期下降。
- 高体量候选：第三方在不知道主体态度、无公告与制度更新时，当前归因或调用随主体认证撤回而下降，并在重新认证后恢复。
- 显影条件：冻结登记、合同、职位、权限、履行、曝光、公告、数据库、传播、第三方规则与时间衰减。

## 4. 候选机制

### A｜主体认证撤回削弱公共壳外部覆盖

```text
主体停止以第一人称认证旧壳
→ 第三方缺失持续的一手确认信号
→ 对旧壳归因与调用置信度下降
→ 当前x并z外部覆盖下降
```

严格候选约87%。若未来成立，也只能先锁“依赖持续主体认证的自愿代表壳”这一窄机制，不能覆盖法律身份、亲属身份、历史作品归因与制度职位。

### B｜内部脱钩、新壳停止生成与续期下降

```text
主体不再认领旧壳
→ 主体与壳的内部距离扩大
→ 新作品和新场合不再生产同类壳
→ 下一周期不续任或主动认证持续下降
```

竞争解释约99%。它改变未来生产与延续，不改变当前旧壳的外部有效性。

### C｜公开否认、撤权或制度更新真正降低外部覆盖

```text
主体公开否认或撤回授权
+ 组织、数据库、履行或第三方规则同步更新
→ 外部归因、调用或制度有效性下降
```

这引入`zx/xn/x`等公开结构，不能归给纯`nx 克 x并z`。

## 5. 正例候选

1. **《黑客帝国》Neo拒绝“Mr. Anderson”阶段**：Neo不再主动认证系统身份，但Agents仍继续以该壳指认和调用他。该例是清楚反证，说明主体认证下降不等于外部归因下降。
2. **《楚门的世界》Truman出口阶段**：Truman拒绝继续表演旧身份，公共壳随节目终止而崩解；但同时发生物理离场、公开事件、主要履行停止和系统终止，无法隔离纯`nx`。
3. **严格演员候选**：演员合同、名册、演出、宣传、第三方知识和制度资格全部保持，只停止自称团员。只有第三方在完全不知道其态度时减少当前调用，并在演员重新自称后无公告恢复，才接近纯例。
4. **艺名候选**：艺术家私下不再认领旧艺名，但不改署、不发声明、不停止履行。旧作品仍被正确归因，说明只改变新壳生产和主动认证。

## 6. 反例

1. 辞职后不再被称为经理：职位与制度已经改变。
2. 组织公开除名成员：公开权能与程序改变壳。
3. 演员停工后身份淡化：履行、曝光与时间衰减。
4. 艺术家停用旧艺名但旧作品仍被正确归因：新壳不生成，旧壳未被克。
5. 学生厌恶校服但系统仍承认学生资格：内部脱钩。
6. 人物拒绝自称父亲，但家庭仍继续调用其职责：主体认证下降，亲属壳未消失。
7. 主体公开声明“不要再这样称呼我”后第三方停止：公开否认已成为额外作用源。
8. 撤回代理授权后身份调用下降：现实权限与调用规则发生变化。

## 7. 最近邻排除

- `x 生 x并z`：解释现实掌握怎样生成公共壳。
- `x并z 克 nz`：解释公共壳怎样污染关系证据。
- `zx 克 n`：公开裁决、除名与成员边界改变。
- `xn`：名册、数据库、续任、传播与规则维护。
- `x`：职位、授权、署名和现实接口。
- 内部认同脱钩：主体体验变化，不等于公共壳下降。
- 新壳停止生成：未来生产链断裂，不等于当前旧壳失效。
- 时间衰减与社会遗忘：没有证明源于`nx`。

## 8. 拿掉测试

1. 拿掉主体不认领，只保留辞职、公告、撤权或数据库更新；若覆盖仍下降，生源不是`nx`。
2. 冻结登记、合同、职位、权限、履行、曝光、公告与数据库。
3. 让第三方完全不知道主体内部态度。
4. 分别测量制度有效性、外部归因、第三方调用和主体认证。
5. 区分沉默不认领、私下否认、公开否认与撤回授权。
6. 让主体自由重新自称，检查无需外部更新能否恢复当前调用。
7. 换到历史作品、亲属身份、法律身份和自愿社群身份，比较壳对持续认证的依赖程度。
8. 区分当前旧壳下降、新壳不生成和下一周期不续期。
9. 拿掉时间衰减、停工、失联和第三方遗忘。
10. 检查公共壳是否本来就需要持续第一人称认证才能运行。

## 10. 动态链后果

```text
公共壳仍在代表我
→ 我停止复述、背书和主动认证它
→ 主体与壳的内部距离扩大
→ 新壳生成与续期概率下降
→ 世界仍可能通过旧壳归因和调用我
→ 只有旧壳本身依赖持续主体认证，且外部覆盖同步下降
→ 才接近nx克x并z
```

## 11. 三元与十元并行核验

三元观察：人物是否继续履行角色、他者是否继续接触和调用、关系是否继续运行。

十元区分：
- `nx`：主体不占身份方向、不主动认证；
- `x并z`：公共壳的归因和调用接口；
- `zx`：公开否认、裁决和除名；
- `xn`：名册、数据库、传播与续任程序；
- `x`：职位、授权、署名和现实掌握。

两套系统并行，没有写成父子派生。
