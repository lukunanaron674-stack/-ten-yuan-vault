## 3. 源端、目标端、变量与成立条件

### 源端`zx`

- 人物与阶段：主体在公开可见阶段作出最终决定，有真实退路却不撤回，并承担处分、损失或危险，使决定现实生效。
- 具体名词：公开决定接口、高成本原则实践、承担后果的主体权能、可观察行为样本。
- 排除：单纯演讲、职位、名气、宣传、胜利镜头、群体声势、暴力强迫、事后神化。

### 目标端`zn`

- 原则命题内容：目标具体认领“什么应当或不应当”。
- 正确性判断：目标是否认为该原则本身正确。
- 选择权重：该原则在竞争原则中是否获得更高优先级。
- 承诺强度：目标愿意为维护该原则承担多少成本。
- 最终指导资格：源人物离场、失败、背弃时，该原则是否仍指导目标。
- 被改变变量：命题内容的新颖度、解释稳定度、跨观察者一致性、选择权重、承诺强度、行动阈值、跨情境持续性和独立修订能力。

### 成立阶段、体量与显影条件

- 低体量：目标震撼、敬佩、复读口号或跟随一次，只记当前状态和行动阈值。
- 中体量：目标本来知道或隐约认同原则，高`zx`样本提高可信度、选择权重和承诺强度；只记原则加权。
- 高体量候选：冻结教学、口号、制度说明、依恋、共同敌人和群体许可后，不同观察者仍从同一高成本行为稳定抽取同一此前不存在的命题；源离场、英雄背弃、失败与新情境中仍独立运行。
- 显影条件：低`zx`等内容对照；多观察者释义一致性；源离场；无观众；首次失败；英雄背弃；竞争解释排除；目标独立改写。

## 4. 候选机制

### A｜公开高成本行为独立生成原则命题

```text
高zx主体公开实践并承担代价
→ 目标从行为中抽取此前不存在的明确原则命题
→ 该命题取得正确性与最终指导资格
→ 脱离源人物后独立运行
```

严格候选由约88%降为约86%。核心障碍是行为本身语义欠定：同一牺牲行为可能被解释为责任、忠诚、身份服从、复仇、群体立场、个人执念或较宽泛“有些东西值得付代价”。

### B｜现实样本提高已知或潜在原则的权重

```text
目标已经听过、理解或隐约拥有候选原则
→ 高zx主体把它做成高成本现实样本
→ “这不是空话”得到证明
→ 可信度、选择权重、承诺强度和首次行动概率上升
```

这是本轮最稳定的解释，约99%。它改变的是原则加权和实践阈值，不等于命题内容新生。

### C｜目标解释层生成较宽泛元原则或事后合理化

```text
目标见证高成本行为
→ 先产生震撼、依恋、群体认同或行动冲动
→ 再用自己的既有语言解释行为
→ 形成较宽泛元原则或事后理由
```

这里命题来源至少部分位于目标已有概念、群体话语与解释结构，不能全部归给`zx`。

## 5. 正例候选

1. **《十二怒汉》陪审员8与陪审员9，第一次改票阶段**：陪审员8公开承担孤立和程序压力，坚持合理怀疑；陪审员9最先改变立场。但“合理怀疑”命题已经由法律程序、陪审职责和讨论内容提供。高`zx`更像证明该原则可以现实坚持，并提高表达许可与选择权重。
2. **《饥饿游戏》Katniss与地区群众，毒莓公开拒绝阶段**：Katniss公开承担死亡风险，拒绝竞技场规则，反抗获得高成本样本。但反抗命题已由长期压迫、共同敌人、Rue之死和群体符号提供；群众也可能抽取“她是我们的象征”“不服从可行”或身份模仿等不同命题。
3. **《死亡诗社》Keating与Todd，结尾课堂阶段**：Keating承担被解雇代价，Todd率先站上桌。但原则内容由长期教学、诗歌讨论和师生关系输入；结尾主要提高承诺强度和群体行动许可。
4. **严格控制候选**：甲在无口号、无教学、无共同敌人的公开场景中拒绝伪证并承担处分。乙此前没有“宁受罚也不作伪证”命题；乙在另一机构、无观众、首次受罚时仍拒绝伪证，甲后来作伪时乙反对甲，并能以自己的语言修改原则。还需证明其他观察者也稳定抽取同一命题，而非责任、反抗权威或个人崇拜。

## 6. 反例

1. 长期课程后学生形成价值观：命题内容主要来自`xn`教学。
2. 士兵因指挥官冲锋而跟随：职位、命令、危机和群体执行足以解释。
3. 粉丝模仿英雄口号、服装和姿态：身份模仿，不是原则独立运行。
4. 人物被英雄救命后追随：混入承载、救命债和依恋。
5. 群众在胜利现场宣誓：奖励、观众、共同敌人和群体感染未冻结。
6. 人物原本已有原则，只在示范后敢公开：既有`zn`显影与行动阈值下降。
7. 不同观察者从同一牺牲行为抽取完全不同意义：证明行为只是解释材料，不是唯一命题生成器。
8. 目标只能复述英雄原话，英雄背弃后也随之背弃：依附人物或身份壳，不是原则取得独立资格。

## 7. 最近邻排除

- `zn 生 zx`：人物已有原则推动其自身公开决定，最容易被倒置成跨主体生成。
- `xz 生 zx`：危险生成临时公开决定接口。
- `xn`：教学、叙述、法律与制度说明提供命题内容。
- `z 克 nx`：认可帮助人物取回判断资格。
- `x并z 生 z`：英雄壳使对象被识别和确认。
- `nz`：目标可能追随人物关系，而非原则。
- 群体许可与身份模仿：提高行动概率和归属位置。
- 事后合理化：先行动或依恋，后生成解释。

## 8. 拿掉测试

1. 拿掉公开承担代价，只保留相同原则内容。
2. 用低`zx`文本、普通讲述或制度说明完整暴露同一命题。
3. 保留高`zx`行为，但拿掉口号、解释和教学内容。
4. 拿掉依恋、救命债、职位、共同敌人、奖励与群体压力。
5. 检查目标此前是否已有同内容原则或较宽泛元原则。
6. 让多个信息背景相近的观察者分别解释同一行为，检查命题一致性。
7. 让源人物离场，并取消观众与即时回报。
8. 加入首次失败、受罚和利益反转。
9. 换到源人物从未评价的新情境。
10. 让英雄本人背弃原则。
11. 加入责任、忠诚、反抗、身份模仿等竞争解释。
12. 要求目标独立改写原则，而非复读英雄口号。

## 9. 反向测试

`zn 生 zx`是现行几何生位：

```text
人物已有不可让渡意义
→ 公开作出决定并承担代价
→ 形成显权接口
```

本轮判断规则：

```text
目标本来已有原则并被示范激活
＝既有zn显影

低zx已经提供命题，高zx后才行动
＝可信度、选择权重和承诺强化

不同观察者抽取不同命题
＝行为提供释义材料，不是唯一命题源

英雄背弃后目标也背弃
＝依附英雄，不是维护原则

目标能独立改写并跨情境维护
＝证明原则脱离英雄运行
≠ 证明命题内容由英雄行为唯一生成
```

## 10. 动态链后果

```text
有人把抽象原则公开做成，并承担真实代价
→ 行为成为高成本现实样本
→ 观察者开始解释“这个行为意味着什么”
→ 已知、潜在或自行抽取的原则获得不同程度加权
→ 可信度、承诺强度与首次行动概率上升
→ 只有此前无该命题且观察者稳定抽取同一内容
→ 并脱离英雄跨失败和新情境运行
→ 才接近严格zx生zn
```

本轮只改变原则现实感、释义入口、选择权重、承诺强度和行动阈值；不机械生成信仰、忠诚、勇气、群众觉醒或稳定人格。

## 11. 三元与十元并行核验

三元观察：

- 谁公开承担代价；
- 谁见证并随后行动；
- 源离场后行动是否继续；
- 英雄背弃时目标是否保持；
- 多个观察者是否抽取一致意义。

十元区分：

- `zx`：公开决定、承担代价并让选择现实生效；
- `zn`：不可让渡原则命题、正确性与最终指导资格；
- `xn`：教学、叙述、制度说明和证据组织；
- `z`：认可与判断资格确认；
- `nz`：依恋、回返和关系停靠；
- `xz`：危险、失去与共同敌人压力；
- `x并z`：英雄身份壳和群体符号。

两套系统并行，没有写成父子派生。
