## 1. 强制规则

1. 每轮开始先记录当前 `main` SHA。
2. 每轮只审计一条十元生、克、补关系；流程修复轮须明确标记“非理论关系审计”。
3. 每轮必须记录：队列状态、对象分层、候选机制、正反例、最近邻、拿掉测试、反向测试、动态链后果、95%门槛、修改文件、理论提交 SHA、失败原因和下一条关系。
4. 没有新证据时只写简短“无可靠进展”，不得重复扩写完整专项审计。
5. 需要同步状态时直接修改现行正本；不得再用几百行 `current-patch` 代替正本原位修正。
6. 写入前重新读取本文件 blob SHA；无法安全原位更新时，本轮必须记为失败，不得另建补记规避。
7. 理论任务不承担仓库层级、索引和补丁生命周期治理；治理工作进入独立治理任务。
8. 三元与十元并行，不建立父子派生。

#### 对象分层

- 稳定本体：`z` 是长期依赖重要认可位置确认自身；`nz` 是长期保留关系余温、不愿承认结束。一次掌声与一次不舍不能反推本体。
- 当前状态：认可发生后的释放或受挫，与谢幕、撤展、毕业时的短期不舍分开。
- 行为功能：呈现、表达、等待、回返只是证据，不替代端点。
- 光影：聚光、观众、暖光、旧物和空位只作显影。
- 场景：展览、演出、答辩、谢幕与告别不自动启动关系。
- 时间关系：认可先、留恋后只证明先后。
- 关系位置：必须明确认可者、被认可者、共同见证关系与可回返位置是否为同一对象链。
- 显影：观察“被确认的位置是否从一次判断变成不愿失去的关系位置”。
- 动态链：只描述认可是否提高停靠强度，不机械生成友情、归属或永久留任。

#### 源端点、目标端点与变量

- 源端点 `z`：认可主体、认可对象、认可内容与该认可位置的重要性均明确，确认真实落到主体。
- 目标端点 `nz`：关系或共同阶段已有可保留对象、时间厚度与回返位置，主体不愿其真正结束。
- 被改变变量：对认可者或共同见证关系的停靠意愿、对阶段结束的抗拒、认可位置是否成为可返回关系、无后续奖励时是否仍想保留共同位置。
- 成立阶段：认可发生后，主体开始把认可者、被见证共同体或共同完成阶段视为不愿失去的关系位置。
- 关系体量：低体量是短暂不舍；中体量是主动延长共同阶段；高体量是改变下一步选择以保留认可关系。
- 显影条件：拿掉奖励、既有友情、固定空间与长期共事后，停靠强度仍因认可明显增加。

#### 候选机制

- 候选 A：重要认可主体确认主体，使对方从评判位置转化为可停靠关系。理论后果是 `z` 只可能在关系层提高停靠强度；风险是关系厚度通常早已存在。
- 候选 B：共同作品或能力被重要主体见证，使共同阶段获得不可替代性。理论后果是被改变的不是完成感，而是共同阶段的唯一性；风险是时间厚度可能真正来自 `xn` 长期共事、`n` 容器或原有友情。
- 排除候选 C：目标完成后自然空虚与留恋。没有认可主体，不能证明 `z`。
- 排除候选 D：获奖、录取、签约后想留下。可能是 `x`、`n`、`xn` 或 `x并z` 的变化。

#### 正例候选

1. 固定剧团最终谢幕：多年共同排演后，导演与重要观众确认其不可替代的共同演出，演员延长谢幕并不愿离开共同舞台。限制是多年排练已形成强 `xn` 与既有 `nz`；拿掉最终认可仍可能同样不舍。
2. 毕业展小组撤展：观众与导师确认“这是你们共同完成的作品与能力”后，成员延迟撤展并保留共同创作计划。限制是目前缺乏可验证人物文本证明认可前后 `nz` 的独立增量。
3. 《爆裂鼓手》安德鲁与弗莱彻结尾对视：认可主体明确，但影片没有展示持续不愿结束或回返姿态，因此不能作为正式正例。

#### 反例

1. 考生录取后进入学校：是结果与新结构变化。
2. 运动员夺冠后立即追逐下一目标：只有 `z` 延续，没有 `nz`。
3. 演员即使演出失败仍舍不得剧团：`nz` 先于 `z`。
4. 导师长期照顾学生后给予认可：留恋可能来自 `n` 与既有关系。
5. 公司表彰后员工愿意留下：待遇、身份、组织归属与奖励无法排除。
6. 掌声后的短暂兴奋：只是当前状态，不是关系沉淀。

#### 最近邻排除

- 与 `xn 补 z`：后者改变认可证据的连续性与阶段收束；本关系若成立，改变的是认可后对关系或共同阶段的不愿结束。
- 与 `n`：`n` 提供真实承载、成员位置和返回容器；长期被接住造成的留恋不能归给 `z`。
- 与 `xz 补 nz`：`xz` 通过可能永远失去提高停靠重量；`z` 必须由“被确认”本身提高停靠强度。
- 与反向 `nz 生 z`：既有不舍推动最后一次演出或表达，不能倒写为认可生成不舍。

#### 拿掉测试

1. 拿掉公开认可后，人物是否仍同样舍不得共同阶段？若是，不依赖 `z`。
2. 拿掉既有友情、共同空间与长期共事后，认可是否仍产生持续停靠？当前无高纯案例通过。
3. 拿掉奖品、录取、签约和新身份后，不愿结束是否仍增强？若否，只是外部结果。
4. 拿掉认可主体，只保留目标完成，若留恋仍出现，只能证明完成后状态变化。
5. 拿掉 `nz` 的等待、回返与保留共同位置，只剩兴奋和感谢，目标端点不存在。

#### 反向测试

反向 `nz 生 z` 在最终演出、告别作品和临别表达中更容易成立：主体因不愿共同阶段结束而追求最后一次被看见。方向切口是：本轮要求认可先实际提高停靠强度；反向则是既有不舍先推动认可。

#### 动态链后果

```text
我终于在重要位置上被你或你们确认
→ 这个位置不再只是评判席
→ 它是否成为我不愿失去的共同关系或阶段
→ nz 的关系层停靠强度可能上升
```

当前更稳妥的结论是：`z` 可以使既有 `nz` 显影、被命名或获得共同见证，但无法确认其在缺少既有关系厚度时独立生成 `nz`。
