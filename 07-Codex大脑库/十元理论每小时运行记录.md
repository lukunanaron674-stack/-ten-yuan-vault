### 对象分层

- 稳定本体：一次求生妥协、一次极端行为或一次创伤反应不能反推稳定 `zn` 被改写。
- 当前状态：恐惧、麻木、绝望、创伤回避和不敢实践只能先判状态层。
- 行为功能：逃跑、偷窃、抛弃、服从、公开否认和违背誓言均不足；必须观察主体对原则正确性的明确改判。
- 光影：暴风、雪原、缺氧、怪物、刑场、黑暗与倒计时只作显影。
- 场景：灾难、荒野、战争、生存困境与迫害不能替代端点。
- 时间关系：危险前原则稳定 → 临界阶段实践受压 → 危险解除、事实纠正与创伤缓解 → 原则判断是否仍改变。
- 关系位置：本轮优先检查自然环境、资源临界和不可控局面；施害者命令、惩罚与制度训练必须拆到 `zx/xn/x`。
- 显影：原原则是否从“无条件正确”变成“只在安全时适用”、错误或不再有最终指导资格。
- 动态链：世界限制实践 → 事实认识更新／创伤反应／意义排序 → 是否真正撤销规范判断；不写成危险自动删信念。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `xz`：危险可感知逼近；退路、时间窗或资源真实缩窄；主体不行动会被吞没；作用不依赖施害者命令和制度惩罚。
- 目标端点 `zn`：危险前已有稳定原则，即没有奖励、认可和监督仍认为其正确并具有最终指导资格。
- 被改变变量：原则正确性、无条件性、适用范围、最终指导资格、危险解除后的恢复度。
- 新增排除变量：事实判断与规范判断必须分开。主体从“我以为救援不会来”改成“我知道救援可能来”，是事实更新；只有从“绝不能抛下同伴”改成“该原则本身错误”才触及 `zn`。
- 成立阶段：危险前、临界选择时、危险解除后、事实纠正后、创伤缓解后。
- 体量：低体量为一次行为妥协；中体量为原则暂时失去实践资格；高体量为危险解除后仍持续撤销原则正确性或指导资格。
- 显影条件：至少两项——明确撤销正确性；无人监督时也不再按原原则判断；危险解除后不恢复；不是另一条更高 `zn` 取得优先级；不是事实误判和创伤回避。

### 候选机制

#### A｜无条件原则被压成生存条件

```text
xz 持续逼近
→ 按原原则行动不断放大毁灭风险
→ 主体把“无论如何都对”改成“安全时才对”
→ 危险解除后仍维持新判断
→ zn 的无条件性和最终指导资格下降
```

理论后果：若成立，改变的是规范适用资格，不是勇气、能力或一次行为。

风险：现有作品往往只展示危机中行为变化，缺少危险解除后的持续规范判断。

#### B｜意义排序重组

```text
多个 zn 同时存在
→ xz 使它们无法共同实践
→ 保存生命、保护家人或保护多数取得更高优先级
→ 原原则此次未执行
```

理论后果：这只能判意义排序，不证明目标 `zn` 被克。

#### C｜实践通道封闭与创伤回避

```text
xz 缩窄行动路径并造成创伤
→ 主体仍认为原原则正确
→ 但暂时无法实践或不敢再次进入类似情境
```

理论后果：只证明状态、显影和实践通道受压。

#### D｜事实判断更新冒充原则改写

```text
主体在危险中依据错误事实作出极端选择
→ 后来知道事实并非如此
→ 对世界会发生什么的判断改变
```

理论后果：改变的是事实模型，不是“什么应该做”的 `zn`。必须把事实错误从原则改判中拿掉。

#### E｜危险揭露原本没有稳定 zn

安全时重复原则，危险到来立刻放弃，且事后也无法证明其曾经无奖励成立。此时危险只是揭露身份口号、法律习惯或环境依赖，目标端点原本不存在。

### 正例候选

1. **《荒野生存》克里斯托弗·麦坎德利斯末期**：自然危险与退出路径恶化后，他对绝对独立的意义似乎发生改写。限制：更可能是经验学习和关系记忆回归；原原则是否为稳定 `zn` 也不确定。
2. **《绝境盟约／Society of the Snow》幸存者决定食用遇难者遗体**：自然危险端点清楚。限制：他们通过宗教与责任重新解释尊重死者，更像保护生命的 `zn` 取得更高优先级，而非旧原则被判为错误。
3. **《迷雾》大卫结尾**：危险和退路归零后作出极端行为。限制：行为仍以保护家人为动机；军队随后出现证明关键事实判断错误；没有危险解除后的稳定原则改判阶段。
4. **《沉默》罗德里格斯踏绘**：行为和意义边界变化明显。限制：制度化迫害与他者受刑含强 `zx/xn`，且可能是救人的另一条 `zn` 压过不可弃教。
5. **《1984》温斯顿**：危险后意义判断持续改变。限制：酷刑、洗脑与制度训练远强于自然 `xz`，不能证明危险本身独立启动。

### 反例

1. 华莱士受刑仍坚持自由：`xz` 上升，`zn` 不降。
2. 《末路浩劫》父亲在持续危险中仍以保护孩子指导选择。
3. 因饥饿偷食物，事后仍认为偷窃不对：行为失败，不是原则改判。
4. 为救多人舍弃一人：可能是两个 `zn` 排序。
5. 危险解除后恢复原原则：状态遮蔽。
6. 被迫公开悔过但内心仍认可旧原则：公开壳或服从变化。
7. 创伤后不敢再次实践，但仍认为原则正确：创伤回避。
8. 因为后来知道救援其实会来而否定当时选择：事实判断更新。

### 最近邻排除

- 与 `zx/xn` 强制改判：命令、酷刑、惩罚流程和洗脑不能整体塞进 `xz`。
- 与状态崩溃：恐惧、麻木和创伤改变显影与实践，不改变原则正确性。
- 与 `zn` 内部排序：保护生命或他人取得优先级，不等于旧原则被克。
- 与事实认识更新：危险信息、救援概率和资源判断改变属于事实模型，不属于规范端点。
- 与反向 `zn 克 xz`：原则保持最终指导资格，使危险不能决定最终方向。

### 拿掉测试

1. 拿掉危险，只保留施害者命令、制度惩罚和洗脑，若改判仍发生，源端点是 `zx/xn`。
2. 拿掉施害者，只保留自然危险，原则是否仍被持续改写？
3. 拿掉行为失败，只问主体是否明确认为原原则不再正确。
4. 拿掉创伤、麻木和回避，原则判断是否仍改变？
5. 拿掉错误事实，主体在事实纠正后是否仍撤销旧原则？
6. 拿掉另一条保护性 `zn`，旧原则是否仍失去指导资格？
7. 危险解除后原则若恢复，只能判暂时遮蔽。

现有候选均未通过全部测试。

### 反向测试

```text
xz 克 zn 候选：
危险使稳定原则从无条件正确退成条件性、错误或无最终指导资格
→ 危险解除、事实纠正和创伤缓解后仍不恢复

zn 克 xz：
原则继续拥有最终指导资格
→ 主体不让危险决定最终方向
```

许多所谓“危险摧毁信念”的案例实际更接近实践失败、意义排序或事实判断更新；反向坚持案例也不能拿来证明正向。

### 动态链后果

```text
危险逼近
→ 实践空间缩窄
→ 主体可能失败、回避、误判或重新排序意义
→ 只有当危险解除、事实纠正与创伤缓解后
→ 主体仍撤销原原则的正确性或最终指导资格
→ 才可能进入 xz 克 zn
```

改变的是原则的规范资格，不机械生成邪恶、背叛、虚无、成熟、创伤或人格崩坏。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只检查 `xz` 的自然危险端点、`zn` 的稳定原则端点、规范判断是否持续改变，以及 `zx/xn`、事实误判、创伤和另一条意义是否是真正作用源。不能因为故事整体黑暗就反推本关系。

### 95%门槛

高置信通过：

- 一次求生妥协、行为失败与公开否认不足：99%。
- “仍知原则正确但做不到”不是 `zn` 被克：99%。
- 事实判断更新不等于规范判断改写：99%。
- 创伤回避与麻木必须先判状态层：98%。
- 危险解除、事实纠正和创伤缓解后的持续改判是硬门槛：98%。
- 另一条 `zn` 排序、`zx/xn` 强制与伪 `zn` 必须排除：98%。

未达到95%的核心：没有两个高纯具体人物案例；现有案例分别混入经验学习、意义排序、错误事实、制度强制或创伤。用户仍有超过5%概率不接受自然危险对规范正确性的直接克制机制。
