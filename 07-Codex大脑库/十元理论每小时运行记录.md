### 对象分层

- 稳定本体：一次认可、一次独立选择不能反推稳定 `nx` 被克，也不能反推人物稳定自主性改变。
- 当前状态：最可能只发生在某一具体选择、某段师徒关系或某一阶段的方向认领。
- 行为功能：`z` 是重要认可主体确认人物自己的判断、能力或选择资格；`nx` 下降必须通过替代路线、否决权和后果承担显影。
- 光影：聚光、目光、署名、鼓掌、主体从侧位走到中心只作显影。
- 场景：学校、家庭、治疗、导师、比赛和舞台不能替代机制。
- 时间关系：主体先因自我判断失格而持续跟随；认可发生；认可停止；主体仍独立决定。
- 关系位置：认可者、外部方向提供者和资源授权者可能不是同一主体，必须拆开。
- 显影：外部路线是否从唯一合法变成可拒绝；主体是否持续提出替代路线并承担损失。
- 动态链：不是“被夸后变勇敢”，而是“自己的判断获得合法资格后，不再把外部路线当作唯一方向”。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `z`：明确谁认可谁、认可何种判断或能力资格、该认可位置为何重要；认可者不提供具体方案、职位、资源、许可或后果兜底。
- 目标端点 `nx`：主体此前有真实替代路线与拒绝能力，却因为认为自己的判断不合法、不可靠或不配成立而持续沿外部方向推进。
- 被改变变量：主体对自身判断资格的认领、外部路线的唯一合法性、替代路线提出率、否决权使用率、独立承担后果的持续度、认可停止后的方向稳定性。
- 成立阶段：认可前的判断自我取消；认可发生；首次替代路线；认可者离场或停止确认；主体继续决定并承担结果。
- 体量：低体量为一次选择上取回方向；中体量为一段关系中持续保留方向权；高体量为稳定人物本体改变。当前无证据支持高体量。
- 显影条件：至少同时出现替代路线、实际否决、认可停止后仍维持方向、承担损失；只更自信、更敢说话或表现更好均不足。

### 候选机制

#### A｜判断资格确认

```text
主体有可行路线
→ 但认为自己的判断没有资格成立
→ 因此持续沿外部安排推进
→ 重要认可者只确认“你的判断可以成立”
→ 外部路线不再垄断合法性
→ 主体提出替代路线、使用否决并承担后果
→ nx 下降
```

理论后果：若成立，`z` 克制的是“判断资格自我取消型 nx”，不是所有关系依赖或流程跟随。

#### B｜能力资格确认

```text
主体不是没有路线
→ 而是不相信自己能承担路线后果
→ 重要认可确认其能力足以承担选择
→ 主体重新使用决定权
```

理论后果：若认可后主体只是更努力执行原安排，则只有 `z` 上升，没有 `nx` 下降。

#### C｜结构性依赖冒充判断失格

```text
主体没有资源、职位、许可、技能或现实替代路线
→ 即使被认可
→ 仍无法改变方向结构
```

理论后果：这种 `nx` 的启动源来自 `x/xn/zx/n` 或客观能力差，纯 `z` 不能直接克制。

#### D｜既有自主性显影

```text
主体原本已有稳定自主路线
→ 认可只使其公开表达或获得现实支持
```

理论后果：目标 `nx` 原本并未成立，不能判克制。

### 正例候选

1. **《死亡诗社》托德与基廷，课堂即兴诗阶段**：基廷确认托德具有自己的诗性声音，托德不再只复述标准答案。限制：主要改变表达资格；基廷同时提供强教学、引导、照护与课堂权能，后续独立路线和认可停止后的持续度不足。
2. **《跳出我天地》比利与父亲，父亲转为支持舞蹈之后**：父亲认可使家庭路线失去唯一现实资格。限制：比利在认可前已明确坚持舞蹈；父亲同时提供资源、放行和家庭权力支持，更像既有自主获得 `z/x` 支持。
3. **独立定题的研究生结构例**：学生有可行选题，却一直认为自己的判断不够资格；导师只确认其判断能力，不给题、经费或许可。导师停止回应后，学生仍拒绝旧题、推进新题并承担失败。端点较纯，但缺少可核验作品人物，不能代替第二个正式正例。

### 反例

1. 老板表扬员工后，员工更认真执行老板方案：`z` 上升，`nx` 未降。
2. 父母说“我相信你”，却继续掌握学校、资金与许可：方向结构未变。
3. 导师给出新方案，学生从执行旧方案改成执行新方案：只是换了跟随对象。
4. 上级授予职位、预算和签字权：主要是 `x` 权限转移。
5. 治疗者通过长期训练、照护与风险兜底使主体能独立：主要混入 `xn/n`。
6. 主体原本就会反抗，认可只使其公开：既有自主显影。
7. 获奖后自信上升，却没有提出替代路线或使用否决：状态变化。
8. 认可停止后主体重新等待认可者决定：方向依赖没有真正下降。

### 最近邻排除

- 与 `x/zx`：资源、职位、许可、放权和公开权能直接改变现实决定资格；纯 `z` 只确认判断资格。
- 与 `xn/n`：教学、训练和照护提高能力与安全感，不等于认可本身改变方向认领。
- 与 `zn`：主体因“这件事本身正确”而拒绝外部路线，启动源是内部意义。
- 与自信上升：更敢表达、更愿表现不等于提出替代路线、否决并承担后果。
- 与反向 `nx 克 z`：不表达、不呈现会关闭认可接口；那改变的是确认能否发生，不是方向合法性。

### 拿掉测试

1. 拿掉认可，只保留教学、资源、职位与放权，主体仍独立，则不依赖 `z`。
2. 拿掉教学、资源、许可和后果兜底，只保留判断资格确认，主体仍持续决定，才支持直接机制。
3. 拿掉主体原有可行路线，若认可后仍没有替代方向，目标端点不足。
4. 拿掉主体“自己的判断不合法”的前置自我取消，若其本来就自主，只有显影没有克制。
5. 拿掉情绪振奋，只观察替代路线、否决与代价承担。
6. 认可停止或认可者离场后仍保持方向，才能排除持续追逐认可。
7. 主体只是换了一个更喜欢的跟随对象，`nx` 结构不变。

现有两个作品候选均未通过完全拿掉教学、资源、放权与既有自主性的测试。

### 反向测试

```text
z 克 nx 候选：
主体因否定自己的判断资格而跟随
→ 重要认可只确认其判断资格
→ 外部路线不再唯一合法
→ 主体持续提出替代路线并承担后果

nx 克 z 候选：
主体持续不表达、不呈现、不进入认可接口
→ 重要确认无法发生或逐步撤回
```

正向改变方向合法性，反向改变认可接口，不能互相代证。

### 动态链后果

```text
我不是没有自己的路线
→ 我只是一直认为自己的判断没有资格成立
→ 重要的人确认：你的判断可以成立
→ 我拒绝原安排并承担自己的选择
→ 即使不再得到确认，我仍保留自己的方向
```

改变的是“谁有资格决定”与“外部路线是否仍垄断合法性”，不机械生成成熟、勇气、成功或稳定独立人格。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只检查 `z` 的认可端点、`nx` 的方向依赖端点、依赖的具体启动源，以及认可停止后的方向持续度。不从因果主题、师徒题材或人物成长结局反推本关系。

### 95%门槛

高置信通过：

- 旧“持续表达、决定和占位”不是现行 `z`：99%。
- 自信、表达和表现提高不等于 `nx` 下降：99%。
- `z` 只能候选克制“判断资格自我取消型 nx”，不能克制职位、资源、能力不足和现实无替代路线造成的结构性 `nx`：98%。
- 最低结果必须包含替代路线、实际否决、认可停止后仍维持方向和承担后果：98%。
- 教学、照护、放权、许可、资源和既有自主性必须拆开：98%。

未达到95%的核心：没有两个高纯具体人物案例；无法确认纯认可直接克制方向依赖，还是只让既有自主路线获得显影资格。用户仍有超过5%概率不接受该窄机制。

结论：几何位置保留；旧机制继续撤回；“判断资格自我取消型 nx”窄候选保留；正式机制未锁定；队列不新增；核心表、关系词典与专项正本不修改。
