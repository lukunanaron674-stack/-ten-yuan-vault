## 源端点、目标端点与变量

### 源端点 `z`

必须写清认可者、认可内容、认可位置的重要性，以及确认是否准确落到主体自己的判断、能力或选择。纯度要求：信息、技能、权限、路线、许可、资源、职位与失败兜底均不增加。

### 目标端点 `nx`

认可前主体必须已经拥有足够信息、基本能力、现实权限、可行替代路线与真实否决权，但仍否定“最终由我判断”的资格。

被改变变量：

- 方向决定位置的认领强度；
- 对外部安排的唯一依赖度；
- 替代路线提出率；
- 否决权实际使用率；
- 首次自主失败后是否继续决定；
- 认可者未评价的新领域是否迁移；
- 认可者后来出错或反对时是否仍保留最终判断资格。

### 阶段、体量与显影

- 低体量：单一事项中提出自己的路线。
- 中体量：在同一关系中跨失败、反认可和新事项持续认领方向。
- 高体量：跨关系、跨领域形成稳定人物结构；当前无证据。
- 显影条件：信息和权限零增量；认可者不兜底；匿名同内容对照；错误认可、反认可、首次失败和未评价领域复测。

## 候选机制

### A. 认可解除判断资格否定

```text
主体已有能力、信息与路线
→ 却认为自己的判断没有资格成立
→ 重要主体只确认“你的判断有资格成立”
→ 外部方向不再是唯一合法方向
→ nx 在状态层或关系位置层下降
```

理论后果：改变的是判断资格认领，不生成知识、正确答案或稳定独立人格。当前约94%。

### B. 认可返还承担后果的资格

```text
主体长期等待权威许可
→ 权威确认主体有资格承担选择后果
→ 同时撤回路线、拒绝代决与兜底
→ 主体首次失败后仍自行复盘
→ 在无人评价的新选择中继续决定
```

理论后果：若认可者仍提供安全路线、许可、纠错或保障，优先判教学、`x`、`xn` 或 `n`。当前约92%。

### C. 竞争解释：既有自主显影

主体原本已能私下决定，只缺表达、公开接口或现实许可。认可只是让既有自主被看见，目标 `nx` 在认可前并未成立。

2. **《心灵捕手》威尔—肖恩｜治疗后段至离开波士顿**：肖恩确认威尔不必由创伤定义，威尔开始选择自己的生活。污染：治疗、事实重释、长期照护、信任承载和具体人生信息；不能纯化为认可单独作用。
3. **《跳出我天地》比利—父亲｜父亲转为支持之后**：父亲确认比利的舞蹈方向，但比利在认可前已有稳定自主；父亲又提供许可、资源与现实通道，更接近既有自主显影和支持。

8. 认可内容被证明错误后，主体把全部方向资格交回：认可依赖，不是 `nx` 持续下降。

## 最近邻排除

- 教学与事实更新：改变知道什么、会不会做。
- 许可、资源与职位放权：改变能不能做。
- `n` 承载：提供失败后的接住与安全位置。
- `zx/x`：通过权能或权限重排现实位置。
- `zn`：不可让渡原则直接收回方向，`z` 只可能确认。
- 普通自信显影：表现增加，但最终方向仍交给别人。
- `nx 生 x`：主体持续让位使他者掌握扩大，不能倒证 `nx` 已被克。

## 动态链后果

```text
我本来有信息、能力、权限和可行路线
→ 但不承认自己有资格作最终判断
→ 一个重要主体准确确认我的判断资格
→ 他不教新方法、不放新权限，也不替我兜底
→ 我在第一次失败后仍继续决定
→ 即使他后来判断错误或反对我的新方向
→ 我修正事实，却不交还最终判断资格
```

感觉走向：从“只有外部认可过的方向才合法”，转成“没人保证正确，我仍有资格承担自己的方向”。不得机械生成成功、天赋、正确路线或稳定人物本体。
