### 对象分层

- 稳定本体：`z` 是长期依赖重要认可位置确认精神存在；`nz` 是长期保留关系余温、回返姿态与不愿结束。一次认可或一次不舍不能反推本体。
- 当前状态：此刻被看见、感激、兴奋或舍不得告别，只能作候选状态。
- 行为功能：展示、表达、回应属于 `z`；主动再次相见、共同创作、回返并为对方保留进入资格才触及 `nz`。
- 光影：聚光、目光、谢幕、旧物、空位与暖光只作显影。
- 场景：课堂、舞台、治疗、师徒、毕业与谢幕不能替代端点。
- 时间关系：认可先发生，任务结束，双方之后仍保留回返接口。先后仍不足，必须证明关系位置新增。
- 关系位置：源端是认可者与被认可者；目标端必须转成双方都承认的可停靠关系，而非单方继续追逐评价。
- 显影：认可者不再评价时，双方是否仍愿意再次见面、共同工作或允许对方重新进入关系。
- 动态链：评价位置成立 → 单方回返意愿出现 → 对方是否保留可信入口 → 评价关系是否转成可停靠关系；不机械生成友情或依恋。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `z`：必须写清认可主体、认可对象、认可内容及该位置的重要性；认可真实落到主体，不是泛泛称赞、曝光、成绩或结果。
- 目标端点 `nz`：认可后新增不愿关系结束、主动回返与可再次进入的位置；奖励、职位、任务和评价停止后仍存在。
- 被改变变量：认可者是否从评价者转成关系对象、双方回返意愿、回返接口是否双向、认可停止后的关系持续度、评价者可替代性、共同位置的可信度。
- 成立阶段：评价关系先成立 → 重要认可发生 → 奖励任务停止 → 被认可者主动回返 → 认可者仍承认其进入资格 → 双向关系位置持续。
- 体量：低体量为单方感谢和想再见，不足；中体量为任务结束后双方主动联系与再次共同活动；高体量为下一阶段选择因保留该关系而改变。
- 显影条件：至少看到双方各自一次主动维持接口；认可者不再提供现实利益；换成同等级评价者不能替代；拿掉长期照护和共同任务后仍成立。

### 候选机制

#### A｜认可者由评判位置转成可停靠关系

```text
重要认可者确认主体真正的能力、存在或选择
→ 被认可者产生再次回到其面前的意愿
→ 认可者在评价结束后仍保留再次进入的关系位置
→ 双方形成可信回返接口
→ nz 上升
```

理论后果：若成立，生成的不是泛依恋，而是“评价已经结束，但我们仍能回到彼此关系中”。

风险：认可者若同时持续照护、治疗或提供安全承载，真正启动源可能是 `n`。

#### B｜共同阶段被确认后沉淀为关系余温

```text
共同成果被重要主体明确确认
→ 共同阶段获得不可替代性
→ 双方主动保留继续共同创作或返回该位置的接口
→ nz 上升
```

理论后果：`z` 改变的是共同阶段的精神重量与是否值得继续。

风险：时间厚度可能主要来自 `xn` 长期共事、`n` 共同容器或既有 `nz`；认可只负责命名。

#### C｜单方认可依赖冒充 nz

```text
我还想被你认可
→ 我不愿离开你
```

排除。这里只证明 `z` 的持续需求，不证明双方关系余温、回返位置或可信停靠。

#### D｜奖励、职位和资源使人留下

```text
被认可
→ 获得机会、身份、团队位置或资源
→ 愿意留下
```

排除。更接近 `x/n/xn/x并z`，不证明认可关系本身生成 `nz`。

### 正例候选

1. **《心灵捕手》威尔与肖恩，治疗结束阶段**：肖恩确认威尔的聪明、创伤与真实选择，不把他只当问题学生或天才工具；威尔对肖恩形成告别重量与回返意愿。限制：肖恩长期接住威尔，`n` 很强；治疗重复过程含 `xn`；影片对治疗结束后的双向回返呈现有限。支持“单方回返意愿”，尚不足证明完整双向停靠。
2. **《国王的演讲》伯蒂与莱昂内尔，战时演讲完成后的友谊阶段**：莱昂内尔确认伯蒂能够发声并承担职责；任务完成后双方仍维持长期朋友关系。限制：长期训练含 `xn`，陪伴与接住含 `n`，战争演讲成功又带来强 `z/zx` 结果，无法证明评价关系仅凭认可转成停靠。
3. **导师确认学生独特创作语言的结构例**：毕业前导师只承担评分位置，随后明确确认学生独特创作语言；毕业后不再提供课程、资源和推荐，双方仍主动保留回访与共同讨论接口。结构纯度较高，但缺乏可核验具体人物文本，不能独自锁定。

### 反例

1. 获奖者舍不得离开领奖台：只是状态兴奋。
2. 学生因推荐信、资源或职位继续联系导师：主要是 `x`。
3. 被偶像点赞后持续追逐更多回应：`z` 延续，不是 `nz`。
4. 演员本来就舍不得剧团，最终认可只命名既有余温：方向可能是 `nz 生 z`。
5. 治疗者长期接住来访者而产生依恋：优先检查 `n`。
6. 项目共同完成后成员不舍，但没有重要认可主体：共同时间或 `xn`。
7. 主体单方面想再见，认可者没有保留入口：只有单方回返意愿，没有可信关系位置。
8. 换一个同等级评价者即可替代原关系：缺少不可替代的关系对象。

### 最近邻排除

- 与 `n`：`n` 提供接住、容纳、照护和安全回返；若不愿结束主要来自长期被接住，不能归给 `z`。
- 与 `z` 自身延续：“我还想被他认可”不等于“即使他不再评价我，我们仍保留彼此关系”。
- 与 `nz 生 z`：若先有舍不得与共同时间，再通过最后作品或表达争取被看见，方向相反。
- 与 `xn 补 z`：长期组织为认可提供证据，不解释认可后是否形成关系停靠。
- 与 `x并z 生 z`：公开壳让对象被识别，不解释双方为何在评价结束后继续回返。

### 拿掉测试

1. 拿掉认可，只保留治疗、照护、共同任务和长期相处，双方是否仍会同样回返？若会，不依赖 `z`。
2. 拿掉奖励、职位、推荐、资源和新身份，双方是否仍主动维护接口？
3. 拿掉认可者后续评价，关系是否仍有价值？若立即失效，只是 `z` 依赖。
4. 拿掉被认可者的单方想念，认可者是否仍保留其进入资格？若没有，完整 `nz` 不成立。
5. 换成同等级评价者，是否可完全替代？若可以，目标只是认可位置，不是不可替代关系对象。
6. 拿掉再次相见、共同创作、主动联系与真实进入，只剩感谢、兴奋和联系方式，目标端点不足。

当前两个具体作品候选均未通过全部测试。

### 反向测试

```text
z 生 nz 候选：
重要认可先发生
→ 双方在评价结束后保留可信回返接口
→ 关系不愿结束与时间厚度上升

nz 生 z：
已有共同时间与不舍
→ 主体通过最后一次作品、表达或回返
→ 主动追求被看见与确认
```

最终演出、告别作品和临别表达更容易证明反向关系，不能倒过来支持本轮。

### 动态链后果

```text
你确认了我的存在、能力或我们的共同阶段
→ 我想再次回到你面前
→ 但这还只是单方愿望
→ 只有你在评价结束后仍为我保留进入、相见或共同创作的位置
→ 我们才从评价关系转成可停靠关系
```

改变的是：**认可位置能否沉淀为双方可信的关系回返接口。**

不机械生成友情、依恋、归属、永久合作或幸福结局。

### 三元与十元并行

三元只核验作品整体精神感受与大主题走向；十元本轮只核验 `z` 认可端点、`nz` 回返端点、双方关系接口和被改变变量。

不因为作品属于师徒、治疗、成长或告别题材就反推 `z 生 nz`，也不从五大主题“时间/命运”倒推关系。

### 95%门槛

#### 已达到高置信的修正

- 获奖、掌声、录取、签约、待遇和完成不是 `z 生 nz`：99%。
- “我还想继续被你认可”只是 `z` 延续，不等于 `nz`：99%。
- 单方想再见、保留联系方式和舍不得告别不足以证明完整可停靠关系：98%。
- 完整目标至少需要认可者也保留再次进入、相见或共同创作的可信接口：97%。
- 治疗照护、长期训练、共同任务和既有友情必须排除：98%。

#### 未达到95%的部分

- 缺少两个高纯具体人物案例；
- 《心灵捕手》与《国王的演讲》都混入强 `n/xn` 与长期关系；
- 不能确认 `z` 独立生成完整 `nz`，还是只生成单方回返意愿，完整停靠仍由 `n/xn` 或既有关系完成；
- 用户仍有超过5%概率不接受“双向可信入口”作为 `nz` 的最低目标端点。

因此：

```text
几何位置：保留
旧完成/获奖口径：撤回
单方回返意愿：不足
双向可信回返候选：保留
正式机制：未锁定
待确认队列：沿用 UQ-20260718-005
核心表、词典与专项正本：不修改
```
