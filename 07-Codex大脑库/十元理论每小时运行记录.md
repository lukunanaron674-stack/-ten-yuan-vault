## 3. 源端、目标端、变量与成立条件

### 源端`zx`

- 人物与阶段：人物在公开可见阶段有真实退路，却作出最终决定并承担处分、损失或危险，使选择现实生效。
- 具体名词：公开决定接口、高成本原则实践、承担后果的主体权能、可观察行为样本。
- 排除：只有演讲、口号、名气、职位、宣传、胜利镜头、暴力强迫或群体声势。
- 体量：低体量只造成注意与情绪震荡；中体量提高原则可信度和行动概率；高体量候选必须使此前无同内容原则的人形成跨情境独立原则。

### 目标端`zn`

本轮拆成七个变量：

1. **原则命题内容**：目标究竟形成了哪一句可陈述的原则。
2. **命题来源**：内容来自行为、教学、制度、文化先验还是目标自己的解释。
3. **正确性判断**：目标是否认为该原则正确。
4. **选择权重**：多个候选原则冲突时，该原则是否胜出。
5. **承诺强度**：目标愿意为原则承担多少代价。
6. **最终指导资格**：原则能否跨情境担任最后判断标准。
7. **独立解释与修订**：目标能否脱离源人物用自己的语言修改原则。

严格`zx 生 zn`要求第1项此前不存在，并证明其主要因果来源是高成本行为，而非第3至第6项仅被加权。

### 成立阶段与显影条件

- 阶段A：目标此前没有同内容原则，也没有更宽泛原则足以推出该命题。
- 阶段B：冻结教学、口号、制度说明、依恋、共同敌人、群体许可与奖励，只保留高成本行为。
- 阶段C：设置不同文化、身份、法律教育和群体话语背景的观察者，检查释义是否仍收敛。
- 阶段D：源人物离场，取消观众与即时回报，加入首次失败和新情境。
- 阶段E：英雄本人背弃原则，检查目标是否反对英雄并独立改写原则。
- 显影条件：只有在共享先验隔离后，观察者仍稳定抽取同一此前不存在的命题，才接近严格生成。

## 4. 候选机制

### A｜高成本行为独立生成原则命题

```text
高zx人物公开实践并承担代价
→ 观察者从行为中抽取此前不存在的原则命题
→ 命题获得正确性与最终指导资格
→ 脱离源人物后独立运行
```

理论后果：若成立，`zx`可跨主体生成窄义`zn`内容；但必须证明行为语义充分且不依赖共享文化模板。严格候选由约86%降为约84%。

### B｜已知或潜在原则获得现实样本与加权

```text
目标已经听过、理解或隐约拥有候选原则
→ 高zx人物把它做成高成本现实样本
→ “这不是空话”得到证明
→ 可信度、选择权重、承诺强度和首次行动概率上升
```

理论后果：这是目前约99%的稳定解释；改变原则权重与行动阈值，不生成命题内容。

### C｜观察者解释层生成命题

```text
高成本行为造成震撼与注意
→ 观察者用自身概念、经验和价值框架解释行为
→ 形成宽泛原则或事后理由
```

理论后果：命题至少部分来自目标解释结构；源端提供材料和压力，不是唯一内容源。

### D｜共享先验造成释义收敛

```text
多个观察者共享法律教育、文化脚本、身份职责或群体话语
→ 看见同一行为后调用同一解释模板
→ 得出相同原则命题
```

理论后果：观察者共识不能直接证明行为生成命题；必须通过异质先验与无共享话语对照。

   - 目标端：群众把行为解释成反抗象征并提高反抗承诺。
   - 污染：长期压迫、共同敌人、Rue之死、地区身份和既有反抗话语先在。
   - 判断：高成本行为使既有反抗命题获得权重，不证明新命题生成。

3. **《死亡诗社》Keating与Todd，结尾课堂阶段**
   - 源端：Keating坚持教学立场并承担被解雇后果。

   - 污染：长期课堂、诗歌讨论、师生依恋和群体许可已经输入原则内容。

4. **严格控制候选：无口号拒绝伪证**

   - 追加要求：来自不同文化、职业与法律教育背景的观察者，也必须稳定抽取同一命题；否则仍只是目标解释或共享模板。

## 7. 最近邻排除

- `zn 生 zx`：人物已有原则推动自身公开决定，最容易被倒置为跨主体生成。
- `xz 生 zx`：危险生成临时决定接口。
- `xn`：教学、叙述、法律和制度说明提供命题内容。
- `z 克 nx`：重要认可帮助人物取回判断资格。
- `x并z 生 z`：英雄壳提供识别与确认接口。
- `nz`：目标可能追随源人物关系，而非原则。
- 群体许可：降低公开行动门槛。
- 身份模仿：复制人物姿态和口号，不是原则独立运行。
- 共享文化先验：解释模板一致，不是行为因果充分。
- 事后合理化：行动冲动先发生，原则陈述后补入。

## 10. 动态链后果

```text
有人把抽象原则公开做成，并承担真实代价
→ 行为成为高成本现实样本
→ 观察者调用自身先验解释“这个行为意味着什么”
→ 已知、潜在或自行抽取的原则获得不同程度加权
→ 可信度、选择权重、承诺强度与首次行动概率上升
→ 只有异质先验观察者仍稳定抽取同一此前不存在的命题
→ 并脱离英雄跨失败、新情境与英雄背弃独立运行
→ 才接近严格zx生zn
```

只允许记录以下感觉走向：

- 原则从抽象话语变成高成本现实样本；
- 原则可信度、选择权重和承诺强度上升；
- 观察者解释活动被启动；
- 首次行动门槛下降。

不得机械生成信仰、忠诚、勇气、群众觉醒、稳定人格或同一原则内容。

## 11. 三元与十元并行核验

三元观察：

- 谁公开承担代价；
- 谁随后解释、模仿或行动；
- 源人物离场后是否继续；
- 英雄背弃时目标是否仍维护；
- 不同观察者是否得出不同含义。

十元区分：

- `zx`：公开决定、承担代价并使选择现实生效；
- `zn`：不可让渡原则内容与最终指导资格；
- `xn`：教学、制度说明、法律教育和话语组织；
- `z`：确认与判断资格；
- `nz`：依恋、回返与人物追随；
- `xz`：危险、失去与共同敌人压力；
- `x并z`：英雄身份和公共符号壳。

两套系统并行，不构成父子派生。

### 未锁定原因

1. 强例中的原则命题均有教学、制度、压迫经验或群体话语先行来源。

3. 多个观察者一致解释可能只是共享先验，并未证明行为语义充分。
4. 独立改写只能证明原则脱离英雄运行，不能倒证命题来源。
5. 尚无两例通过异质先验、无共享话语、源离场、无观众、失败、新情境和英雄背弃组合测试。
