## 3. 源端、目标端、变量与成立条件

### 源端`xz`

- 人物与阶段：主体进入无明确施害者主导的自然临界，死亡、永久失去或不可逆损伤逼近，路线与时间窗明显收窄。
- 具体名词：自然临界、最后窗口、退路收窄、不可逆损失风险、多个对象无法同时保全。
- 排除：制度命令、施害者威胁、公开处罚、信息欺骗、职位压制和主动强迫；这些需要另判`zx/xn/z/x`。
- 体量：
  - 低体量：短时风险，只改变当前状态和一次策略。
  - 中体量：持续危险关闭多条实践路径，迫使原则条件化或排序。
  - 高体量候选：危险解除后仍持续撤销原则未来调用资格，并跨安全新情境保持。

### 目标端`zn`

本轮把目标拆成四个变量：

1. **原则正确性**：人物是否仍认为原则本身正确。
2. **未来调用授权**：条件满足时，该原则是否仍有资格进入最终判断。
3. **当前调用状态**：此刻是否正在用该原则决定行动。
4. **行动策略**：人物当前采取何种具体做法。

严格`xz 克 zn`要求前两项持续下降。只改变后三项，不能判克。

### 成立阶段与显影条件

- 阶段A：危险初现，允许记录恐惧、撤退与策略收缩。
- 阶段B：实践通道关闭，允许记录原则暂停调用、无条件条款撤回和多原则排序。
- 阶段C：危险解除、身体与资源恢复、对象仍存在，设置安全可执行的新情境。
- 阶段D：人物在第二次安全窗口仍明确拒绝原则未来进入判断，才进入严格候选。
- 显影条件：新事实冻结、永久损伤冻结、身份退出冻结、创伤冷却、竞争原则冻结、对象仍存在、能力恢复、跨领域迁移与反事实询问。

## 4. 候选机制

### A｜自然危险撤销原则正确性与未来调用授权

```text
自然危险反复证明原原则会造成不可接受的整体损失
→ 人物不只停止执行，还判断原则本身不再正确
→ 危险解除后撤销该原则未来进入判断的资格
→ 安全新情境中仍拒绝调用
→ zn核心与最终指导资格下降
```

严格候选由约87%降为约85%。

理论后果：若未来成立，只能先锁“自然临界使原则未来调用授权持续撤销”的窄机制，不能把一次撤退、恐惧或策略替换写成整个`zn`被克。

### B｜实践通道压缩与原则暂停调用

```text
危险关闭时间、路线、能力或对象条件
→ 原原则当前无法有效执行
→ 人物暂停调用并改用生存策略
→ 条件恢复后原则重新进入判断
```

这是本轮最稳定的解释，约99%。

理论后果：改变的是当前调用状态与行动策略，不是原则正确性或未来授权。

### C｜适用谓词细化与无条件版本撤回

```text
“任何情况下都必须执行”
→ 危险暴露其边界
→ 改写为“在对象可救、主体可持续、不会同时摧毁其他必要责任时执行”
→ 原则核心继续运行
```

理论后果：属于原则精化、条件化或元原则统摄，不构成克制。

### D｜多原则排序与第三因素改线

变化还可能来自：

- 新事实：对象已经不可救或行为无法产生目标效果；
- 永久损伤：人物不再具备执行能力；
- 身份退出：人物不再承担该角色；
- 创伤回避：原则仍被认可，但安全窗口中暂时无法显影；
- 竞争原则：家庭、生存、责任或真实获得更高优先级；
- 元原则重写：旧原则被更高规则限定，而非消失。

3. **Beck Weathers，珠峰灾难后阶段**  
   - 人物与阶段：灾难后高风险登山失去原有最终位置，家庭和生存排序上升。

   - 目标候选：登山作为最终自我证明`zn`是否下降。
   - 污染：永久损伤、创伤、登山者身份改变与家庭原则重排。

## 6. 反例

1. **《火星救援》Mark Watney**：危险不断迫使方案变化，但“活下去并解决问题”的原则持续被调用；属于策略改变，不是原则被克。
2. **Apollo 13返航决策**：放弃登月改为保命返航，是任务排序与路径改变，探索和职责原则并未被判定错误。
3. **消防员因楼体坍塌撤退**：当前通道关闭；条件恢复后继续救援，反事实指导资格保留。
4. **登山者因失温放弃登顶**：能力和状态不足；康复后再次登山，原则仍获授权。
5. **父母在灾难中放弃事业保护孩子**：多个`zn`排序，不代表事业意义被危险消灭。
6. **人物仍认为应该救人，但拒绝无效必死式牺牲**：撤回无条件版本，原则核心保留。

这些反例分别说明共现、先后、状态变化、策略替换与视觉相似均不足以证明`xz 克 zn`。

## 7. 最近邻排除

- `xz 生 zx`：危险使旧决定中心失效并生成临时公开决定接口；目标变量是决定权能，不是原则资格。
- 多个`zn`排序：某原则让位于更高原则，不等于原原则失去正确性。
- 新事实纠错：人物根据对象不可救、路径无效等事实更新行动。
- 能力损伤：不能执行不等于不认同。
- 身份退出：不再承担角色不等于原则错误。
- 创伤回避：当前无法调用，不等于未来授权撤销。
- 元原则统摄：旧原则被加上条件和例外，仍在适用范围内运行。
- `zn 克 xn`：意义撤回结构维护资格，目标是结构自愿再生产，不是危险对意义核心的作用。

## 8. 拿掉测试

1. 拿掉危险，只保留新事实，检查原则变化是否仍发生。
2. 拿掉新事实，只保留危险体验，检查人物是否仍否定原则核心。
3. 恢复身体、能力、资源、路线、时间和对象。
4. 冻结家庭、生存、荣誉等竞争原则。
5. 排除施害者、制度命令、身份转换和永久损伤。
6. 设置危险解除后的冷却复判。
7. 设置第二次安全窗口，排除短期创伤与条件反射。
8. 换到原则可以安全执行的新情境。
9. 将同一原则迁移到另一对象领域，检查是否仍被拒绝。
10. 分开询问：“原则是否正确”“未来是否应进入判断”“此刻是否调用”“本轮采用什么策略”。

## 10. 动态链后果

```text
原原则曾被理解为当前行动的直接答案
→ 自然临界关闭实践通道并迫使多个对象排序
→ 人物暂停原则调用、改换策略或细化适用谓词
→ 原则仍可能保持正确性和未来调用授权
→ 条件恢复后重新进入判断，则zn未被克
→ 只有安全新情境中仍撤销原则未来资格
→ 才接近zn最终指导资格下降
```

本轮只改变原则面对现实边界时的感觉走向，不把关系当成机械生成背叛、犬儒、成熟、成长或人格崩坏的装置。

## 11. 三元与十元并行核验

三元观察：

- 危险阶段人物实际保全了谁；
- 哪个对象被放弃或暂缓；
- 条件恢复后人物是否重新承担；
- 原则与对象关系是否继续。

十元区分：

- `xz`：自然临界、退路收窄和不可逆损失风险；
- `zn`：原则正确性、最终指导资格和未来调用授权；
- `zx`：危险中临时形成的决定接口；
- `xn`：规则、流程与结构性路径；
- `n`：现实承载与恢复条件；
- 竞争`zn`：多个不可让渡意义之间的排序。

两套系统并行，没有写成父子派生。
