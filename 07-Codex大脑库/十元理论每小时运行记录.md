## 3. 源端、目标端、变量与成立条件

### 源端`z`

- 人物与阶段：重要主体面对一个长期等待外部确认的人，只明确承认“最终判断资格属于你”。
- 具体名词：资格确认、正确见证、判断位置返还、重要认可。
- 排除：答案、路线、教学、新事实、职位、资源、许可、治疗解释、失败兜底和替人物承担后果。
- 体量：低体量只提高表达；中体量可启动一次自主行为；高体量候选必须跨欠定情境、失败和认可者撤场改变标准作者权。

### 目标端`nx`

本轮拆成七个变量：

1. **行为选择权**：能否在具体事项中自行决定。
2. **标准选择权**：能否决定采用哪套既有标准。
3. **标准解释权**：能否说明标准为何适用。
4. **标准修订权**：能否依据新证据修改或废弃标准。
5. **临时标准生成权**：在无现成答案时能否自行提出可撤回规则。
6. **不确定性承担**：证据不足时能否承认风险并继续复判。
7. **失败责任归属**：失败后是否承担作者责任，而非退回认可者。

严格`z 克 nx`至少要求第4至第7项跨阶段回到人物自身。只提高第1至第3项不足以判克。

### 成立阶段与显影条件

- 阶段A：认可前，人物长期等待外部主体提供标准、答案或最终授权。
- 阶段B：重要认可者只返还判断资格，不给路线、标准内容或兜底。
- 阶段C：人物在已有标准内完成第一次选择。
- 阶段D：出现与旧标准冲突的新证据，认可者错误、反对或撤场。
- 阶段E：进入没有现成规则、多个答案都不充分的欠定新领域。
- 阶段F：人物自行提出临时标准、标明可撤回条件、接受反证并承担失败责任。
- 显影条件：无人观看、无替代认可者、无现成模板、首次失败、跨领域和连认可者元规则也无法直接给答案。

### T / M / E

- T：认可者的重要性可很高，但高T不自动降低`nx`稳定本体。
- M：拥抱、肯定、离场可使认可显影极强，但高M不等于关系作用量高。
- E：只有最终判断资格、标准生成权和失败责任实际回到人物，才构成高E克制。

## 4. 候选机制

### A｜资格确认使标准作者权回归

```text
重要主体不再替人物给答案
→ 明确承认人物有最终判断资格
→ 人物撤回“我无资格制定标准”的自我否定
→ 自行选择、生成、检验、废弃并重建标准
→ 失败后仍承担作者责任
→ nx持续下降
```

理论后果：若成立，`z`严格克制`nx`的最终方向资格外置。当前候选由约86%降为约84%。

### B｜表达许可与一次行动启动

```text
人物本来已有方向或标准
→ 认可降低羞耻、孤立与风险感
→ 人物第一次表达或执行
```

理论后果：约99%的稳定解释；改变表达和行动阈值，不改变标准作者权。

### C｜内化评委、内化标准与内化元规则

```text
人物不再等待旧权威
→ 把新认可者的偏好、标准或“忠于自己”的元规则搬进内部
→ 表面上会修改旧标准
→ 实际仍在认可者预设的元框架内行动
```

理论后果：权威从外部位置变为内部规则，`nx`仍可能存在。

### D｜欠定情境中的自我授权

```text
没有现成规则，证据不足且结果不可保证
→ 人物承认只能提出临时标准
→ 自行说明依据、适用边界与撤回条件
→ 结果失败后更新标准而不索取重新授权
```

理论后果：这是本轮新增的严格判据；若缺少该层，只能证明既有标准执行或修订能力。

1. **《心灵捕手》Will与Sean，治疗后期至离开波士顿阶段**
   - 源端：Sean持续把生活选择资格返还给Will。
   - 目标候选：Will不再把最终路线交给教授、Sean或社会期待。
   - 正向证据：Will最终自行离开既有路线。
   - 污染：长期治疗、创伤事实重释、Chuckie推动、Skylar这一明确目标和Sean的持续承载。
   - 判断：支持资格确认与行动启动，不足以证明欠定情境中的临时标准生成。

2. **《海洋奇缘》Moana与祖母Tala，Tala确认身份至Moana独自复航阶段**
   - 源端：Tala承认Moana有资格决定自己与族群的方向。
   - 目标候选：Moana从等待父亲和传统授权转向自行决定。
   - 正向证据：Tala离场后Moana继续航行。
   - 污染：祖先事实、航海知识、使命对象与明确任务路线均已提供标准内容。
   - 判断：支持标准执行权与承诺强化，不证明无模板的新标准生成。

3. **严格控制候选：青年作者与重要编辑**
   - 编辑只确认“最终判断属于你”，不给题材、渠道、评价标准或兜底。
   - 作者在一个没有成熟类型规则的新项目中提出临时标准，说明依据和撤回条件。
   - 编辑明确反对并撤场；项目首次失败后，作者不寻找替代评委，而是依据反证重建标准。
   - 当前缺两组可核验现实或戏剧材料。

7. 失败后说“是你让我相信自己的”，并要求认可者再次确认：责任退回。
8. 在成熟领域独立选择现成标准：标准选择权，不是标准生成权。

## 10. 动态链后果

```text
最终答案和判断标准必须由重要的人替我确认
→ 你承认我有资格判断
→ 我获得表达、尝试和局部决定许可
→ 我可能把你的标准或元规则搬进内部
→ 当现成规则失效、你反对并撤场时
→ 我若能自行提出临时标准、接受反证并承担失败
→ 才接近nx持续下降
```

本轮只改变判断位置、标准作者权、不确定性承担和失败责任的感觉走向，不机械生成能力、成功、正确选择或稳定独立人格。

## 11. 三元与十元并行核验

- `z`：重要确认与判断资格返还；

- `xn`：教学、模板、证据和程序；
- `x`：资源、职位和现实权限；
- `nz`：认可者与人物的关系承载；
- `zx`：公开决定与后果承担接口；
- `zn`：人物最终坚持的原则内容。

两套系统并行，不构成父子派生。
