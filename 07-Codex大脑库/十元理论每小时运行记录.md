# 十元理论每小时运行记录

## 用途

本页用于区分：

```text
定时器已触发
≠ 研究已完成
≠ 文档已修改
≠ GitHub 提交成功
```

每小时理论任务无论成功、无新进展还是失败，都必须在本页留下记录。

## 每轮必填字段

```text
运行ID：YYYY-MM-DD-HH
开始时间：Asia/Shanghai
读取到的 main 提交 SHA：
待确认队列状态：无 / 数量与ID
本轮结论：新增结论 / 仅清理修正 / 无可靠进展 / 失败
95%门槛检查：通过 / 未通过
修改文件：
理论提交 SHA：无则写“无”
运行记录提交 SHA：由该次账本更新提交生成
失败原因：无 / GitHub读取失败 / 文件冲突 / 提交失败 / 其他
下一步：
```

## 验收规则

1. 只有理论文件或队列文件的提交 SHA 已能从 GitHub 读取，才能写“提交成功”。
2. 没有可靠新结论时，允许只写“无可靠进展”，不得为了制造提交而扩写协议。
3. GitHub 读取、更新或提交任一步失败，必须记录失败原因，不得只写“已运行”。
4. 每轮开始前记录读取到的 main SHA；提交后再次核对最新提交，防止并发覆盖。
5. 待确认问题只能写入 `07-Codex大脑库/待用户确认问题队列.md`，不得直接把抽象问题抛给用户。
6. 人物本体、状态、行为、光影、场景、时间关系、关系位置必须分别记录。
7. 三元与十元并行判断，不得写成父子派生关系。
