### 对象分层

- 稳定本体：`xz` 指危险显形、异质逼近、无法稳定停留的长期倾向；`nz` 指关系余温、不愿结束和保留停靠姿态。单次逃跑、告白或留恋不能反推稳定本体。
- 当前状态：`xz` 表现为退路缩窄、时间窗减少、被迫行动；`nz` 表现为等待、回望、舍不得离开。状态同框不等于互补。
- 行为功能：逃亡、穿越、抢窗口、冒险返回；等待、维持旧关系接口、保留位置。行为只作端点证据。
- 光影：雨夜、逆光通道、列车、断桥、暖灯、旧房间、空位均只作显影，不能独立证明关系。
- 场景：边界、站台、逃生路径、旧居、渡口和共同记忆空间只是场景候选。
- 时间关系：可能先漂流后停靠，也可能先有关系余温后为其冒险；补位不要求固定先后。
- 关系位置：漂流者、被追赶者、等待者、旧友、亲人等称谓不能替代十元端点。
- 显影：观察失去风险、回返窗口、停靠是否被重新选择、风险路径方向、回返对象和归宿候选。
- 动态链：改变“离开为何具有命运压力”与“回来为何成为归宿选择”，不机械生成团圆、获救或永久安全。

### 双向端点、变量、阶段、体量与显影

- `xz 补 nz`：已有共同时间、关系余温、不愿结束与可信回返位置，但关系可长期停留在惯性维持。`xz` 补入真正失去、错过窗口和永久离散的可能，使等待、返回或继续保留关系必须被重新选择。
- `nz 补 xz`：已有危险逼近、退路缩窄、被迫移动与方向不确定，但路径可能只有“离开这里”。`nz` 补入明确关系对象、可回返位置和归宿候选，使风险路径拥有方向与收束终点。
- 被改变变量：前向为关系失去概率、返回窗口有限性、停靠选择重量、余温是否经过风险检验；反向为路径方向性、回返对象明确度、承担风险理由、漂流收束度。
- 成立阶段：两端至少分别成立；另一端补入后，原端点的真实缺口发生可观察变化。
- 体量：低体量为一次有限窗口迫使明确是否返回；中体量为跨阶段危险路径持续围绕同一关系终点；高体量为长期漂流与长期等待共同收束人物命运。
- 显影条件：`xz` 必须真实改变退路、时间窗或安全路径；`nz` 必须已有共同时间、关系余温、不愿结束和可回返对象。危险、暖光、恋爱身份或救援结果均不足。

### 候选机制

- A 失去压力使停靠成为选择：已有 `nz` 余温；`xz` 使离散、错过或永久失去成为现实，主体不能继续模糊等待，必须明确是否返回、等待或承担风险。理论后果是 `xz` 不生成柔情，只提高已有停靠的选择重量。
- B 关系终点为漂流定向：已有 `xz` 风险路径；`nz` 提供仍有余温的关系对象与可回返位置，使路径从“远离危险”转为“回到那里/那个人”。理论后果是 `nz` 不消除危险，只改变路径方向与归宿候选。
- C 收留、治疗与保护：排除。若核心变量是危险可达性下降、安全停留时间增加，属于 `n 克 xz`。
- D 走投无路被迫留下：排除。没有自愿停靠、关系余温与可回返位置，不构成 `nz`。

### 正例

1. 《最后生还者》乔尔与艾莉，盐湖城前后至最终选择：二人长期穿越感染区与猎人地带形成 `xz`；父女式余温形成 `nz`。手术可能永久终止关系，使余温从旅途惯性变成乔尔承担巨大风险的选择；艾莉又使原本的护送与赶路获得“带她离开并继续共同生活”的方向。案例含 `zn/zx/n`，但不替代双向变量。
2. 《星际穿越》库珀与墨菲，跨越虫洞至返航阶段：不可预测宇宙路径、时间错位与可能无法返回形成 `xz`；父女余温和长期保留的回返位置形成 `nz`。离散时间使等待获得命运重量；墨菲与承诺为宇宙漂流提供持续回返方向。
3. 结构例：战争撤离中的旧友归返。甲乙曾共同生活多年，关系疏远但余温仍在。道路封锁与时间窗缩窄使“以后联系”失效，甲必须明确是否保留这段关系；旧友又使危险路径获得“回旧城找到乙”的方向。

### 反例

1. 流浪者进入避难所获得床位和医疗：改变实际安全与停留能力，主要是 `n 克 xz`。
2. 追兵逼近后人物突然告白：若此前无共同时间与关系余温，只是临界情绪，不构成 `nz`。
3. 恋人因没钱只能同居：被迫停留，不是自愿停靠。
4. 人物怀念故乡但从不改变路径：`nz` 可能显影，但没有补入 `xz` 的方向变量。
5. 为道德责任返回救陌生人：优先检查 `zn`，不是关系余温启动。
6. 一次获救后产生依赖：可能是 `n` 承载后的关系变化，不证明 `xz ↔ nz` 互补。
7. 危险场景与暖灯、回忆、恋人同框：只是视觉与题材共现。

### 最近邻

- 与 `n 克 xz`：`n` 改变危险可达性、安全停留时间与外部冲击比例；`nz` 改变风险路径方向、回返对象与归宿候选。一句话：`n` 让主体真的停得下来，`nz` 让主体知道为了谁、朝哪里想停下或回来。
- 与 `z 生 nz`：若后者成立，重点是认可怎样产生不愿结束；本关系不要求认可主体，只核验危险与已有关系余温的双向缺口。
- 与 `zn`：因“这是对的”而返回优先判 `zn`；因“不愿这段关系结束、那里仍是回返方向”而返回才偏 `nz`。
- 与普通依恋：恋爱身份、喜欢或依赖不能替代“共同时间 + 关系余温 + 不愿结束 + 可回返位置”。

### 拿掉测试

1. 拿掉 `xz` 后，`nz` 仍可存在，但失去“可能来不及、必须重新选择”的命运重量，支持 `xz 补 nz`。
2. 拿掉 `nz` 后，`xz` 仍可成立，但只剩离开危险、没有明确关系终点，支持 `nz 补 xz`。
3. 拿掉 `n` 的保护与资源后，关系对象仍改变风险路径方向，排除安全容器机制。
4. 拿掉 `zn` 的道德理由后，主体仍因不愿关系结束而返回，支持 `nz` 端点。
5. 拿掉既有共同时间后，只剩临危好感或突然告白，`nz` 端点不足。
6. 任一端拿掉后案例完全不变，则只是共现，不是互补。

### 动态链后果

```text
只有 xz：我必须继续走，但不知道最终去哪里。
只有 nz：我仍留着关系余温，却可以无限期不面对它是否已经结束。
xz ↔ nz：失去风险迫使停靠被重新选择，关系余温让危险路径拥有回返方向。
```

改变的是命运从无尽漂流与无期限等待，收束为“我愿意穿过风险回到哪里，以及我是否仍选择在那里停靠”。不机械生成团圆、获救、永久安全、健康关系或幸福结局。
