## 本轮性质

本轮只审计 `z 生 nz`。没有修改核心表、关系词典、专项索引、旧审计或待确认队列，也没有新建专项。新增“评价对象撤场测试”和“负向评价存续测试”，用于区分：重要认可真正把评价关系转成双方独立维护的可回返关系，还是被认可者继续追逐同一个认可接口，双方后续互动仍围绕被认可能力、作品或选择运行。

## 源端点、目标端点、变量、阶段、体量与显影

源端点 `z`：必须写清认可主体、被认可主体、认可对象及该认可位置为何重要；泛泛称赞、掌声、曝光、获奖、录取和签约不足。

目标端点 `nz`：评价、奖励、推荐、资源、职位和任务停止后，双方仍分别主动维护并兑现再次进入接口；认可者不再只是被认可者追逐的评价源，而成为独立关系对象。

被改变变量：认可者是否从评价者变成关系对象；被认可者的单方回返意愿；认可者是否独立接受；双方主动联系与回返频率；关系是否能在评价对象撤场后继续；负向评价出现时关系是否仍保留。

成立阶段：重要认可已真实发生，随后评价功能与利益接口撤场，双方进入非评价性互动阶段。

体量：低体量为被认可者短暂想再次见面；中体量为双方跨阶段主动回返；高体量稳定友情或长期关系必须排除既有 `n/xn/nz`，不得由一次认可直接反推。

显影条件：无奖励、无推荐、无任务、无资源利益；后续互动不围绕原被认可对象；双方分别发起并兑现进入；认可者对主体新作品或新选择给出负面评价后关系仍持续。

## 候选机制与理论后果

### 候选 A：认可生成单方关系提议

```text
重要认可真实落到主体
→ 被认可者不再只把对方当评判者
→ 产生再次回到其面前的愿望
```

理论后果：较稳定地解释单方回返意愿，但可能只是继续追逐同一个认可者，不足以形成完整 `nz`。

### 候选 B：认可者独立接受并维护

```text
被认可者提出回返
→ 认可者停止评价、奖励和利益供给
→ 仍主动保留并兑现进入资格
→ 双方分别维护关系
```

理论后果：更接近可信可回返关系，但第二个主动动作是否由最初 `z` 直接生成仍未证明。

### 候选 C：评价对象撤场后形成非评价关系

```text
原被认可的能力、作品或选择退出后续互动中心
→ 双方仍主动联系、相见或共同相处
→ 关系不再依赖持续确认
```

理论后果：能够排除 `z` 自身延续，是本轮新增必要门槛。

### 候选 D：负向评价后关系仍存续

```text
认可者后来否定主体的新作品或新选择
→ 双方仍保留进入资格并维护关系
```

理论后果：若通过，说明关系价值已经与持续正向认可分离；但仍须排除此前长期照护、训练、友情和共同任务。

## 正例候选

1. **《心灵捕手》威尔与肖恩｜治疗结束阶段**：肖恩确认威尔的聪明、创伤与真实选择，威尔对关系产生告别重量与回返意愿；但长期治疗含强 `n/xn`，影片缺少评价对象撤场后的双方独立维护与负向评价存续证据。
2. **《国王的演讲》伯蒂与莱昂内尔｜演讲完成后阶段**：任务结束后关系继续成为友谊；但长期训练、陪伴、共同任务与历史关系已经提供时间厚度，无法证明 `z` 独立生成 `nz`。
3. **导师确认学生独特创作语言的结构例｜毕业后阶段**：导师不再提供课程、资源、推荐或评价，双方仍分别主动维护回访；若导师后来否定学生新作而关系仍持续，结构更纯，但目前缺少可核验具体人物文本。

## 反例

1. 获奖者舍不得离开领奖台：状态兴奋。
2. 被偶像点赞后继续追逐回应：`z` 延续。
3. 因推荐、职位、资源或签约维持联系：`x/x并z` 或利益结构。
4. 长期治疗者与来访者产生依恋：优先检查 `n`。
5. 长期训练或共同项目结束后不舍：优先检查 `xn` 与既有 `nz`。
6. 只有联系方式、关注账号、礼貌邀请或“以后合作”：接口未兑现。
7. 后续每次互动仍围绕作品评价、能力确认或请求指导：仍是认可接口延续。
8. 认可者一旦给出负面评价，关系立即断裂：没有形成独立停靠价值。

## 最近邻排除

- `n`：不舍来自长期被接住时，不能归给认可。
- `xn`：训练、治疗与共同任务提供重复时间和结构。
- `z` 自身延续：还想被评价，不等于停止评价后仍有关系价值。
- `nz 生 z`：先有不舍，再以作品或表达寻求确认，方向相反。
- 既有友情：认可只是命名或加强已经存在的关系，不是从无到有。

## 拿掉测试

1. 拿掉认可，只保留照护、训练、任务和友情，关系是否仍持续？
2. 拿掉奖励、推荐、资源、身份与继续评价，双方是否仍主动维护接口？
3. 拿掉被认可者单方想念，认可者是否仍主动发起并兑现进入？
4. 拿掉礼貌邀请与联系方式，只观察真实相见、联系或共同相处是否发生？
5. 拿掉原被认可的作品、能力或选择作为后续互动中心，关系是否仍有独立内容？
6. 认可者后来对新作品或新选择给出负面评价，关系是否仍被双方维护？
7. 换成同等级评价者，关系能否完全替代？
8. 拿掉 `n/xn` 与既有友情后，认可是否仍独立生成双向时间厚度？

现有候选均未通过第 5、6、8 项完整组合。

## 反向测试

```text
z 生 nz 候选：
重要认可先发生
→ 评价功能撤场后双方仍维护关系

nz 生 z：
不舍与回返关系先成立
→ 主体通过作品、表达或再次进入寻求确认
```

告别、毕业、最终演出和回访不能同时为两个方向重复记账。

## 动态链后果

```text
你真正确认了我
→ 我想再次回到你面前
→ 这最多是单方关系提议
→ 你停止评价、奖励和利益供给
→ 原被认可对象退出互动中心
→ 你仍主动为我保留并兑现进入资格
→ 即使你后来否定我的新作品或新选择
→ 我们仍分别维护关系
→ 评价关系才可能沉淀为可信回返关系
```

改变的是认可位置能否跨阶段转成双方独立维护的关系接口，不机械生成友情、爱情、依赖、归属、永久合作或幸福结局。

## 95%门槛

高置信结论：完成、获奖、录取、掌声和签约不能直接生成 `nz`（99%）；持续追逐认可不是停靠（99%）；单方回返只是关系提议（98%）；完整目标需要认可者独立接受并维护（98%）；评价对象撤场测试能够排除持续 `z`（98%）；负向评价存续测试能够检验关系价值是否独立于持续正向认可（97%）。

正式机制未达到95%。缺少两个高纯具体人物案例；现有案例混入强 `n/xn`、既有关系或继续评价；无法证明认可者的独立接受与关系维护由最初 `z` 直接生成。沿用 `UQ-20260718-005`，不新增重复问题。
