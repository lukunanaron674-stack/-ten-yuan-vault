### 源端点、目标端点与变量

源端点 `zx`：甲的力量公开进入现实，决定范围、影响位置或等级位置扩大；旧秩序或他者被迫围绕甲重新反应；普通善举、演讲、牺牲或完成任务均不足。

目标端点 `zn`：乙此前没有稳定原则认领；甲失败、离场、奖励、宣传与胜利中心消失后，乙仍在无人监督、可退出且会受损时按原则行动；坚持对象必须是原则本身，而非英雄、阵营、职位、遗命或组织任务。

被改变变量：

1. 乙对原则的内部确定度；
2. 无监督执行持续度；
3. 原则与英雄姓名、形象、阵营和组织身份的可分离度；
4. 在英雄未规定的新情境中自行推导行动的能力；
5. 原则能否泛化到与原阵营无关甚至不利的新对象；
6. 英雄背弃原则时，乙是否拒绝英雄而保留原则。

成立阶段、体量与显影条件：

```text
低体量：单一见证者在英雄缺席后形成阶段性内部义务。
中体量：多个见证者在无监督与无奖励条件下，分别把原则用于新情境。
高体量：原则脱离英雄、胜利、阵营和制度奖励，成为共同体内部不可背弃的意义；必须排除教育传播与组织监督。
```

显影条件：甲撤场；英雄姓名、形象、口号、遗命、阵营利益和组织监督可被拿掉；乙仍在新情境中自行推导，并承担现实损失。

### 候选机制

#### 候选 A：公开见证入口

```text
甲以 zx 把原则公开推入现实
→ 乙看见原则能够进入现实
→ 原则的注意权重与可信度上升
```

理论后果：解释原则为何被看见，但最多提供见证入口；不能单独证明 `zn` 已生成。

#### 候选 B：公开承担代价取消谋利解释

```text
甲公开推进原则并承担位置、利益或生命代价
→ 乙确认甲不是借原则谋利
→ 英雄个人从原则前退开
→ 乙在甲缺席后继续行动
```

理论后果：代价可以排除表演解释，但首先证明甲自己的 `zn`；乙的变化仍可能来自悲痛、恩情、`n/nz` 或传播。

#### 候选 C：新情境独立推导

```text
甲撤场
→ 乙遇到甲从未规定的问题
→ 没有命令、计划与流程可照抄
→ 乙自行从原则推出行动并承担损失
```

理论后果：比执行遗命更接近原则内化，但仍可能被英雄姓名、阵营与共同体身份污染。

#### 候选 D：去来源与原则泛化

```text
删除英雄姓名、形象、口号、阵营与组织监督
→ 乙面对与原阵营无关的新对象
→ 仍从同一原则推出行动
→ 英雄后来背弃原则时，乙拒绝英雄而保留原则
```

理论后果：这是本轮新增的最强目标测试；若无法通过，只能判英雄依附、阵营延续、`z/x并z` 认同或 `nx/xn` 路线继承。

### 正例候选

1. **《饥饿游戏》凯特尼斯与第十一区见证者**：凯特尼斯公开悼念露露，使反消费人的原则进入现实。污染因素包括长期压迫、悲痛、地区身份、传播符号和反抗组织；缺少删除凯特尼斯符号后对无关对象的原则泛化。
2. **《V字仇杀队》V 与伊薇**：伊薇在 V 死后完成列车行动，说明英雄撤场后仍有行动。但该行动是明确计划，且混入训练、胁迫、依恋、面具符号与阵营继承；更像遗命执行。
3. **《勇敢的心》华莱士与罗伯特·布鲁斯**：华莱士死后罗伯特继续反抗。污染因素是罗伯特原有苏格兰身份、政治利益与已有信念，无法证明目标从无到有。
4. **《悲惨世界》主教与冉阿让**：冉阿让后续原则变化清楚，但主教源端点更接近 `zn/n/z`，公开扩权与现实等级重排不足。
5. **《黑暗骑士》蝙蝠侠与渡轮乘客**：乘客无获救保证仍拒绝杀害另一船，目标行为较清楚；但既有法律道德、群体监督和剧情两难很强，蝙蝠侠的 `zx` 不是直接启动链。

至少两个候选具有具体人物、阶段与双方，但均未通过完整去来源、原则泛化与目标从无到有测试。

### 反例

1. 强者获胜后群众加入胜方：利益与胜利预期。
2. 英雄被授勋、立像、写入教材：`z/x并z/xn`。
3. 群众因恐惧服从：`nx` 或权力结果。
4. 追随者原本就相信原则：既有 `zn` 显影。
5. 英雄牺牲后建立纪念馆或组织：`n/xn/x并z`。
6. 乙继承职位、制服、组织任务或明确遗命：`x/x并z/xn/nx`。
7. 甲自己的原则推动甲显权：方向是 `zn 生 zx`。
8. 乙只会执行英雄预先规定的计划：路线继承，不是原则推导。
9. 英雄后来背弃原则，乙仍因忠诚照做：英雄依附或阵营延续。
10. 删除英雄姓名和符号后，乙无法把原则用于无关对象：来源认同，没有完成原则泛化。

### 最近邻排除

- 与 `zn 生 zx`：甲先有内部原则，再由甲自己公开显权；多数英雄故事首先证明这一方向。
- 与 `z`：英雄对乙的确认、榜样地位与精神认可改变的是认可位置。
- 与 `x并z`：旗帜、称号、面具、纪念和英雄身份壳维持可识别认同。
- 与 `n/nz`：共同体承载、恩情、悲痛与关系余温可以维持对英雄的依附。
- 与 `xn/nx`：教育、传播、职位继承、组织流程与遗命执行可以延续行动，却不证明原则内化。

### 拿掉测试

1. 拿掉甲的公开显权，只保留善举、演讲或牺牲，乙是否仍变化？
2. 拿掉胜利、奖励、宣传、纪念与群体监督，乙是否仍坚持？
3. 拿掉乙原有信念，能否证明原则真实新增？
4. 拿掉英雄本人，乙能否面对新情境自行判断？
5. 拿掉明确遗命、计划、职位任务和组织流程，乙是否仍知道该做什么？
6. 删除英雄姓名、形象、口号和阵营标签后，乙是否仍执行同一原则？
7. 把目标换成与英雄阵营无关甚至敌对的人，乙是否仍按原则行动？
8. 让英雄本人后来背弃原则，乙是否拒绝英雄？
9. 拿掉个人恩情、悲痛和关系余温，乙是否仍坚持普遍原则？
10. 拿掉观众与监督，乙是否仍承担现实损失？

现有案例均未通过第 3、6、7、8 项完整组合。

### 反向测试

```text
zx 生 zn 候选：
甲公开显权使原则进入现实
→ 乙在甲撤场后面对新情境
→ 删除英雄来源后仍从原则推出行动

zn 生 zx：
甲先有内部原则
→ 甲自己公开推进并取得现实决定位置
```

现有英雄案例仍普遍更稳定地支持 `zn 生 zx`；不能因英雄故事最终出现传承，就倒推正向生位。

### 动态链后果

```text
我看见他把原则推入现实
→ 我可能只是震撼、崇拜、跟随或执行遗命
→ 他失败、离场，奖励、宣传与命令中心消失
→ 我遇到他没有交代的新情境
→ 删除他的姓名、符号与阵营后，我仍从原则推出行动
→ 即使他后来背弃原则，我也拒绝他而保留原则
→ 原则才从“他的”变成“我的义务”
```

改变的是见证者对原则的内部归属、新情境推导能力、来源可分离度与原则泛化范围。不机械生成英雄崇拜、共同体、胜利、正义性或永久传承。

### 三元与十元并行核验

三元继续判断作品整体精神运动。

十元本轮只核验：

- 甲是否为真实 `zx` 源端点；
- 乙是否此前没有稳定 `zn`；
- 乙是否在甲撤场后自行推导；
- 英雄姓名、符号、阵营和组织监督被拿掉后，原则是否仍工作；
- 英雄背弃原则时，乙是否选择原则。

不从革命题材、英雄牺牲、群众感动、旗帜传播或结局胜利反推关系成立。

### 95%门槛

高置信结论：

- 99%：同主体“行动自证”不能作为 `zx 生 zn`。
- 99%：见证、崇拜、追随、宣传与原则内化必须分开。
- 99%：执行英雄遗命、职位任务与既定计划不足。
- 98%：乙必须面对英雄未规定的新情境，自行推导行动。
- 98%：必须删除英雄姓名、形象、阵营与组织监督，完成去来源测试。
- 98%：原则必须泛化到与原阵营无关的新对象。
- 98%：英雄背弃原则时，乙选择原则才是强分离证据。
- 98%：源目标必须跨主体，并在甲撤场后验证。

未达到95%的核心机制：

- 缺少两个通过目标从无到有、去来源、原则泛化和英雄背弃测试的具体人物案例；
- 《饥饿游戏》混入压迫、传播与阵营身份；
- 《V字仇杀队》主要是明确遗命与符号继承；
- 《勇敢的心》目标主体原有身份与信念过强；
- `zx` 仍可能只提供公开见证入口，真正内化由乙独立判断、`z/x并z/n/xn` 完成。

结论：

```text
几何位置：保留
同主体机制：撤回
跨主体见证内化：保留窄候选
新增门槛：去来源测试 + 原则泛化测试 + 英雄背弃测试
正式机制：未锁定
待确认队列：不新增，仍属材料与目标从无到有证据不足
```
