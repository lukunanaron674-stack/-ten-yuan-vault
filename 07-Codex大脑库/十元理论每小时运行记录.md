### 源端点、目标端点与变量

源端点 `z`：必须写清谁认可谁、认可什么、认可为何重要，并排除泛泛称赞、曝光、结果和普通掌声。

目标端点 `nz`：奖励、任务、身份与继续评价停止后，双方分别主动保留再次相见、共同创作或回到同一关系位置的实际接口。

被改变变量：

1. 认可者是否从评价者转成关系对象；
2. 被认可者是否产生回返意愿；
3. 认可者是否在停止评价后主动保留并兑现进入资格；
4. 关系能否在无奖励、无任务、无利益时跨阶段持续；
5. 任一方撤回时，关系是否仍只靠被认可者追逐维持。

成立阶段与体量：

```text
低体量：认可后感谢、兴奋、想再见，只构成状态或单方提议。
中体量：双方在任务结束后分别主动联系并兑现再次进入资格。
高体量：双方改变下一阶段选择，只为保留该关系位置。
```

### 候选机制

#### 候选 A：认可生成单方关系提议

```text
重要认可真实落到主体
→ 被认可者不再只把对方当评判者
→ 产生再次回到对方面前的愿望
```

理论后果：`z` 可以较稳定地解释单方回返意愿，但这仍可能只是继续追逐同一认可者。

#### 候选 B：双向完成形成可信回返关系

```text
被认可者提出关系回返
→ 认可者停止评价、奖励和利益供给
→ 仍主动保留并实际兑现再次进入资格
→ 双方分别维护关系接口
→ 完整 nz 候选上升
```

理论后果：完整目标依赖认可者的第二个主动动作；`z` 至少不是自动完成整个 `nz` 的单一充分原因。

#### 候选 C：既有 n/xn/nz 被认可命名

长期照护、训练、共同任务或友情已经形成时间厚度，认可只是最后确认它。排除为既有 `nz` 显影或复合结果。

#### 候选 D：认可依赖

```text
我还想被你评价
→ 所以继续追逐你
```

排除。它只证明 `z` 的持续需求。

### 正例候选

1. 《心灵捕手》威尔与肖恩：肖恩的确认使威尔不再只把他当治疗者，单方回返与告别重量清楚；但长期治疗含强 `n/xn`，且评价结束后的双向实际回返呈现不足。
2. 《国王的演讲》伯蒂与莱昂内尔：任务完成后关系确实延续为友谊；但训练、陪伴、职责与结果性认可均过强，无法证明双向入口由纯 `z` 新生成。
3. 导师确认学生独特创作语言的结构例：若导师毕业后不再提供资源、推荐和评价，却与学生分别主动保留并兑现回访、共同讨论位置，结构较纯；但缺少第二个可核验具体人物文本。

### 反例

1. 获奖后舍不得离开领奖台：状态兴奋。
2. 被偶像点赞后持续追逐更多回应：`z` 延续。
3. 因推荐信、职位、资源或签约继续联系：`x/x并z` 或利益结构。
4. 原本就舍不得剧团、同伴或教室：既有 `nz`。
5. 治疗者长期接住来访者后产生依恋：优先检查 `n`。
6. 项目成员因长期共事不舍：优先检查 `xn` 与共同时间。
7. 只有被认可者想再见，认可者没有实际保留入口：单方关系提议。
8. 只有联系方式、关注账号、礼貌邀请或“以后再合作”：接口未实际兑现。

### 最近邻排除

- 与 `n`：被长期接住而不舍，不能归给认可。
- 与 `xn`：训练和共同任务提供时间厚度，不等于认可生成关系。
- 与 `z` 自身延续：继续想被评价，不等于评价结束后仍有关系价值。
- 与 `nz 生 z`：先有不舍，再通过最后作品或表达追求被看见，方向相反。
- 与 `xz 补 nz`：危险提高失去与回返重量；本轮要求认可本身改变关系入口。

### 拿掉测试

1. 拿掉认可，只保留照护、训练、任务和友情，关系是否仍持续？
2. 拿掉奖励、职位、推荐、资源和继续评价，双方是否仍维护接口？
3. 拿掉被认可者单方想念，认可者是否仍主动保留进入资格？
4. 拿掉认可者礼貌承诺，只看是否实际兑现再次相见或共同创作？
5. 换成同等级评价者，关系是否可以完全替代？
6. 任一方停止维护后，关系是否立即退回单向追逐？
7. 拿掉 `n/xn` 后，认可是否仍独立产生双向时间厚度？

《心灵捕手》和《国王的演讲》均未通过第七项；现有材料也不足以证明认可者的第二个主动动作由 `z` 本身生成。

### 反向测试

```text
z 生 nz 候选：认可先发生 → 双方在评价结束后完成可信回返接口。
nz 生 z：不舍先成立 → 主体通过最后作品、表达或回返追求确认。
```

两方向可以反馈，但不能用同一告别、演出或作品互相代证。

### 动态链后果

```text
你真正确认了我
→ 我开始想回到你面前
→ 这最多是单方关系提议
→ 你停止评价、奖励和利益供给
→ 仍主动为我保留并兑现进入资格
→ 我们分别维护这个位置
→ 评价关系才可能沉淀为可信回返关系
```

改变的是认可位置能否跨阶段转成双方实际维护的关系接口，不机械生成友情、爱情、依赖、永久合作或归属。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验 `z` 是否真实成立、单方回返与双向关系是否分开、`n/xn/x/x并z` 是否是真正来源。不能从毕业、谢幕、师徒或治疗题材反推 `z 生 nz`。

### 95%门槛

未通过。高置信结论：

- 完成、获奖、录取、掌声和签约不能直接生 `nz`：99%；
- 持续追逐认可不等于关系停靠：99%；
- 单方想回返只构成关系提议，不是完整 `nz`：98%；
- 完整目标必须由认可者停止评价后主动保留并兑现入口：98%；
- 礼貌承诺、联系方式和关注账号不足：99%；
- `n/xn`、既有友情、资源和身份必须排除：98%。

未达到95%的核心原因：

- 缺少两个拿掉照护、训练、任务和既有友情后仍成立的具体人物案例；
- 现有案例不能证明认可者的第二个主动动作由 `z` 直接生成；
- 更可能的结构是 `z` 生成单方关系提议，完整 `nz` 需要另一方的独立接受与维护；
- `UQ-20260718-005` 仍覆盖该定义分歧。

结论：

```text
几何位置：保留
旧完成/获奖后自然留恋口径：继续撤回
单方关系提议：高置信成立但不足以构成完整 nz
双向完成候选：保留
正式机制：未锁定
```
