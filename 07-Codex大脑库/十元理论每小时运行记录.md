## 本轮性质

本轮只审计 `zx 生 zn`。没有修改核心表、关系词典、专项索引、旧审计或待确认队列，也没有新建专项。新增“源必要性测试”，用于区分：甲的公开显权真正生成乙的内部原则，还是只让原则进入注意范围，随后由私人善举、传播、既有压迫经验、关系感动或乙自己的独立判断完成内化。

## 源端点、目标端点、变量、阶段、体量与显影

源端点 `zx`：甲的力量公开进入现实，决定范围、影响位置或等级位置扩大，旧秩序和他者围绕甲重新反应；普通善举、演讲、牺牲、坚持和完成任务不足。

目标端点 `zn`：乙此前没有稳定原则认领；甲失败、离场，奖励、宣传和胜利中心消失后，乙仍在无人监督、可以退出且会受损时坚持原则本身，而非英雄、阵营、职位、遗命或组织任务。

被改变变量：乙对原则的内部确定度、无监督执行持续度、原则与英雄身份的可分离度、新情境独立推导能力、原则向无关对象的泛化范围，以及英雄背弃时乙是否仍保留原则。

成立阶段：甲的 `zx` 已公开显现，目标乙此前尚无稳定 `zn`，随后甲撤场，乙在新情境中独立行动。

体量：低体量为单个见证者形成阶段性原则；中体量为多个见证者在甲离场后独立坚持；高体量共同体化必须另查 `n/xn/x并z`，不得直接归给本关系。

显影条件：无奖励、无监督、英雄缺席、没有明确遗命、面对新情境和无关对象，并能够在英雄背弃时拒绝英雄。

## 候选机制与理论后果

### 候选 A：公开见证入口

```text
甲以 zx 把原则推入现实
→ 乙看见原则不是空话
→ 原则的注意权重与现实可信度上升
```

理论后果：较稳定地解释“为什么原则进入乙的注意范围”，但不足以解释“为什么原则成为乙的内部义务”。

### 候选 B：公开承担代价

```text
甲公开推进原则并承担位置、利益或生命代价
→ 乙排除甲借原则谋利的解释
→ 乙开始认真对待原则
```

理论后果：首先证明甲自己的 `zn`；乙的变化仍可能来自悲痛、恩情、`n/nz` 或精神认可 `z`。

### 候选 C：新情境独立推导

```text
甲撤场
→ 乙遇到甲没有规定的新问题
→ 没有遗命、职位或流程可照抄
→ 乙自行从原则推出行动并承担损失
```

理论后果：能够排除遗命执行与 `nx/xn` 延续，但仍不能单独证明源端必须是 `zx`。

### 候选 D：源必要性

```text
乙此前无稳定原则
→ 甲的公开显权首次提供原则的现实证据
→ 把同一原则换成私人劝说、文字传播或无权能者示范时，乙不形成同等 zn
→ 删除英雄身份后，乙仍独立泛化原则
```

理论后果：这是本轮新增的因果门槛。只有目标内化与源必要性同时通过，才可能锁定直接生位。

2. **《V字仇杀队》V 与伊薇｜V 死后的列车行动阶段**：伊薇在 V 撤场后继续行动；但她主要执行明确计划，并混入训练、胁迫、关系依恋、面具身份壳与阵营继承，更像遗命执行。
3. **《勇敢的心》华莱士与罗伯特·布鲁斯｜华莱士死后阶段**：罗伯特继续反抗，但原有民族身份、政治利益与既有信念过强，无法证明目标从无到有。
4. **《悲惨世界》主教与冉阿让｜宽恕后的长期变化**：目标 `zn` 变化清楚，但主教的源端更接近 `zn/n/z`，公开显权不够纯。
5. **《黑暗骑士》蝙蝠侠与渡轮乘客｜渡轮阶段**：无奖励条件下拒绝杀害另一船较接近目标端，但混入既有法律道德、群体监督与剧情两难；蝙蝠侠的 `zx` 不是直接必要源。

## 反例

1. 强者获胜后群众加入胜方：利益与胜利预期。
2. 英雄被授勋、立像或写入教材：`z/x并z/xn`。
3. 群众因恐惧服从：`nx` 或权力结果。
4. 追随者原本已有相同原则：既有 `zn` 显影。
5. 乙继承职位、制服、任务或明确遗命：`x/x并z/xn/nx`。
6. 英雄牺牲后建立纪念共同体：`n/xn/x并z`。
7. 乙只在英雄姓名、口号和阵营存在时坚持：英雄依附，不是原则内化。
8. 私人善举、文字传播或乙既有经验同样足以产生原则：无法证明 `zx` 是必要源。

## 最近邻排除

- `zn 生 zx`：甲先有原则，再由甲自己显权；多数英雄案例首先证明这个方向。
- `z`：英雄看见、认可、鼓励或成为榜样，改变认可位置。
- `x并z`：旗帜、称号、面具、纪念与阵营身份提供公开壳。
- `n/nz`：恩情、悲痛、共同体承载与关系余温维持英雄关系。
- `xn/nx`：教育、传播、职位继承、组织流程和遗命延续行动，但不证明原则内化。
- 乙独立判断：若没有甲的 `zx` 也会形成同一原则，则目标不是由本关系生成。

## 拿掉测试

1. 拿掉甲的公开显权，只保留善举、演讲或牺牲，乙是否仍形成同一原则？
2. 拿掉胜利、奖励、宣传、纪念和监督，乙是否仍坚持？
3. 拿掉乙原有信念，能否证明原则真实新增？
4. 拿掉英雄本人、姓名、形象、口号和阵营，乙是否仍坚持？
5. 拿掉遗命、计划、职位和组织流程，乙能否处理未规定的新情境？
6. 把对象替换为与英雄阵营无关甚至敌对的人，乙是否仍按原则行动？
7. 英雄后来背弃原则，乙是否拒绝英雄？
8. 拿掉个人恩情、悲痛与关系余温，乙是否仍承担普遍原则？
9. 把同一原则改为私人劝说、文字传播或无权能者示范，若乙仍形成同等 `zn`，则 `zx` 不是必要源。
10. 拿掉甲的 `zx` 后，只保留乙自己的压迫经验与独立判断，若原则仍出现，不成立直接生位。

现有候选均未通过目标从无到有、源必要性、去来源、无关对象泛化与英雄背弃的完整组合。

## 动态链后果

```text
我看见他把原则推入现实
→ 我可能只是震撼、崇拜或执行遗命
→ 他失败、离场，奖励与命令中心消失
→ 我遇到他没有交代的新情境
→ 删除他的姓名、符号与阵营
→ 我仍从原则推出行动
→ 即使他后来背弃原则，我也拒绝他
→ 再证明没有他的公开显权，这条原则不会在我这里同样形成
→ 才继续接近 zx 生 zn
```

改变的是见证者对原则的内部归属、来源可分离度、新情境推导、泛化范围与源因果归属，不机械生成英雄崇拜、共同体、胜利、正义性或永久传承。
