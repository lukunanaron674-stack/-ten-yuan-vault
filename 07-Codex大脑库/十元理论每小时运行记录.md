## 3. 源端、目标端、变量与成立条件

### 源端`nx`

- 人物与阶段：原主体具备现实资格，却跨阶段不认领账户、作品、项目、时间或关系的最终方向，并反复让特定代理者代定、代管、代签和对外回应。
- 具体名词：方向空位、决定位置不认领、最终路线外置、持续代理依赖。
- 排除：一次委托、危机分工、明确职位服从、专业代理、短期病弱与外部强迫。
- 体量：低体量只增加一次代理机会；中体量形成默认路由；高体量候选必须在撤权和替代接管后仍改变处分资格。

### 目标端`x`

本轮拆成八个变量：

1. **代理机会**：对象是否反复经过代理者。
2. **事实影响**：代理者是否能使第三方短期改变对象状态。
3. **指令生效来源**：指令因谁的资格、授权、身份或程序而生效。
4. **处分资格**：代理者是否能以自身资格调用、否决、调配、绑定或转交对象。
5. **排除能力**：原主体明确反对时，代理者是否仍能排除原主体。
6. **关键人依赖**：代理者是否成为唯一懂流程、联系人和隐性知识的人。
7. **恢复能力**：数据、凭证、流程和技能补回后，原主体或替代者能否接管。
8. **跨对象迁移**：控制是否能迁移到无历史授权的新对象。

严格`x`要求第4、第5和第8项成立。只证明第1、第2、第6项或恢复时间很长，不足以判生。

### 成立阶段与显影条件

- 阶段A：原主体具备资格和基础能力，但持续不认领方向。
- 阶段B：对象反复经由代理者，形成默认路由、授权历史和知识集中。
- 阶段C：代理者成为关键人，第三方开始等待其指令。
- 阶段D：原主体公开反对并撤销合同、密码、签字、职位和身份接口。
- 阶段E：第三方全部知情，旧程序关闭，技术和传播延迟清零。
- 阶段F：完成数据镜像、凭证托管、流程文档化、替代者训练和中立第三方接管。
- 阶段G：测试代理者是否仍能以自身资格排除原主体，并迁移到新对象。
- 显影条件：没有欺骗、未更新第三方、隐藏凭证、数据扣留、法律授权、职位壳和主动威胁。

### T / M / E

- T：长期让位和代理范围可很大，但高T不自动生成代理者稳定`x`本体。
- M：所有人都找代理者、原主体不会操作，可使控制显影极强，但高M可能只是关键人依赖。
- E：只有处分资格、排除能力和跨对象迁移真实新增，才构成高E生位。

## 4. 候选机制

### A｜方向空位转化为独立处分中心

```text
原主体持续不认领方向
→ 对象反复经由代理者
→ 代理者的指令逐渐脱离逐次授权
→ 能以自身资格排除原主体并处分对象
→ x掌握边界新增
```

理论后果：若成立，只能先锁定“代理接口转化为独立处分中心”的窄机制。当前候选由约85%降为约83%。

### B｜历史授权与执行网络维持控制

```text
原主体反复委托和让位
→ 合同、程序、身份壳、数据库与第三方形成默认执行链
→ 代理者发令后仍有人执行
→ 表面控制持续
```

理论后果：真正使处分生效的是`xn / x并z / zx / x`既有结构，不能归给纯`nx`。

### C｜关键人依赖与路径锁定

```text
长期代管
→ 隐性知识、联系人、例外处理和操作记忆集中
→ 替换者需要高成本重建
→ 代理者成为短期不可替代的事实中心
```

理论后果：改变的是组织与原主体的恢复能力、替换成本和协调瓶颈，不等于代理者获得处分资格。

### D｜原主体接管能力下降

```text
原主体长期不操作
→ 信息断层、技能退化、关系陌生和决策迟滞
→ 撤权后也难以立即接管
→ 代理者看起来仍掌握对象
```

理论后果：原主体`x`或`xn`能力下降，不自动证明代理者`x`新生。

## 6. 反例

1. 家庭会计掌握全部账目，换人需要数月：关键人依赖和迁移成本，不是独立处分资格。
2. 唯一维护生产系统的工程师可通过不配合让系统停摆：知识与操作瓶颈；若凭证托管、文档化和替代训练后失效，则不是`x`。
3. 家长凭资金、密码或监护资格控制账户：既有`x/x并z/zx`直接提供掌握。
4. 助理长期收件和排会议：默认路由与信息入口。
5. 撤权后系统尚未刷新：技术延迟。
6. 第三方不知道撤权：传播与旧口径惯性。
7. 代理者必须欺骗第三方或隐藏数据才能继续操作：生效源是误认、扣留或接口垄断。
8. 原主体不会操作平台，暂时无法接管：能力退化和恢复时间，不是代理者权能新生。

## 7. 最近邻排除

- `z 克 nx`：代理者主动占位、施压或隔离，直接压缩原主体方向。
- `xn`：程序、记录、隐性知识、例外处理、培训与恢复能力。
- `x并z`：职位、治疗者身份、经纪人壳和第三方调用中心。
- `zx 补 nx`：借已有身份、关系、权限和通道做成。
- 合同、监护、所有权、密码与系统权限：直接提供现实掌握。
- 原主体`x`下降：原主体失去能力或接口，不等于代理者`x`新生。
- 关键人依赖：停摆能力和不可替代性不等于处分对象的正向资格。

## 10. 动态链后果

```text
我持续不认领方向
→ 事情反复经由你处理
→ 你积累授权历史、隐性知识和他者服从
→ 我与组织逐渐失去快速接管能力
→ 你成为短期不可替代的事实中心
→ 若镜像、托管、文档化和替代训练后控制消失
→ 下降的是恢复能力，不是你获得独立处分
→ 只有你仍以自身资格排除我并跨新对象处分
→ 才接近x真实新生
```

本轮只改变代理位置、路径依赖、事实控制外观、恢复能力和关系走向，不机械生成所有权、法律资格、职位或稳定支配人格。

## 11. 三元与十元并行核验

三元观察：

- 谁持续让位；
- 谁发出指令；
- 谁使指令生效；
- 谁掌握知识和接口；
- 谁能在恢复条件后取回对象。

十元区分：

- `nx`：原主体不认领最终方向；
- `x`：现实掌握具体对象并能排除他人；
- `xn`：流程、记录、知识、培训和恢复能力；
- `x并z`：职位、身份和公共调用壳；
- `zx`：公开决定与权限接口；
- `z`：主动占位和方向压缩的最近邻来源。

两套系统并行，没有写成父子派生。
