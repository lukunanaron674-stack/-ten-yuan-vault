## 源端点、目标端点与变量

### 源端点 `xz`

必须同时满足：

- 危险以可感知形态逼近；
- 安全路径、资源、时间窗口或退路真实减少；
- 主体不行动就会被吞没或失去最后机会；
- 作用不依赖施害者命令、制度流程、公开惩罚或长期训练；
- 不是单纯信息更新、能力不足或一次情绪恐惧。

### 目标端点 `zn`

危险前必须已有稳定证据：

> 即使没有奖励、认可和监督，这件事仍然是对的；不这样做，我就背弃了自己。

危险后必须观察：

- 原则是否仍被判断为正确；
- 原则是否仍拥有最终指导资格；
- 原则是否从无条件变成“安全时才成立”；
- 危险解除后是否继续维持新判断；
- 同条件再次出现时是否继续按新原则复判；
- 变化是否能迁移到利益方向相反的新情境。

### 被改变变量

1. 原则正确性判断；
2. 原则无条件性；
3. 原则最终指导资格；
4. 主体认定哪些代价仍不可接受；
5. 危险解除后的持续改判度；
6. 跨情境与同条件复判的一致度。

状态恐惧、行为失败、公开改口、无法实践和一次策略反转，不得替代这些变量。

## 候选机制

### 候选 A：无条件原则被压成生存条件

```text
xz 持续逼近
→ 按原原则行动持续扩大毁灭风险
→ 主体把“无论如何都对”改成“只有安全时才对”
→ 原则正确性或最终指导资格持续下降
```

理论后果：若成立，改变的是底线和可接受代价，不是勇气与执行能力。

当前评价：约91%。缺少危险解除后仍持续改判的纯案例。

### 候选 B：多个意义重新排序

```text
多个 zn 同时存在
→ xz 使它们无法共同实践
→ 保存生命、保护他人或更高责任取得优先级
→ 某项原则本轮未执行
```

理论后果：`zn` 没有被克，只是内部优先级变化。《沉默》和《绝境盟约》更接近此机制。

当前评价：约96%，作为排除解释可直接使用。

### 候选 C：实践通道被封死

```text
xz 缩窄时间、资源和行动路径
→ 主体仍认为原原则正确
→ 但无法把原则带入现实
→ 显影与行为下降，内核保持
```

理论后果：属于状态、能力与显影层，不是 `zn` 目标变量下降。

当前评价：约98%，作为排除解释可直接使用。

### 候选 D：危险揭露原本没有稳定 `zn`

```text
安全时重复身份、规范或群体口号
→ xz 到来后立即放弃
→ 原来依赖环境、奖励或身份
```

理论后果：目标端点此前不存在，不能判“被克”。

当前评价：约97%，作为排除解释可直接使用。

### 候选 E：信息新增后 `zx` 重选

```text
危险同时带来新事实或未来信息
→ 主体对现象集合 x 的判断更新
→ 具体决策 zx 反转
→ 原则底线和价值排序不变
```

理论后果：行动反转不等于 `zn` 被克。判断 `zn` 是否变化，应看“什么代价仍不可接受”的底线是否持续改写。

## 反例

1. 《勇敢的心》华莱士受刑仍坚持自由：`xz` 上升，`zn` 不降。
2. 《末路浩劫》父亲持续保护孩子：实践困难，原则继续指导选择。
3. 因饥饿偷食物，事后仍认为偷窃不对：行为失败，不是内核改写。
4. 为救多人舍弃一人：可能是多个 `zn` 排序。
5. 危险解除后重新认领原原则：状态遮蔽或实践中断。
6. 被迫写悔过书、公开否认信仰，内心仍不改判：只改变行为或公开壳。
7. 原原则只是家庭、宗教或组织口号：危险揭露目标端点原本不存在。
8. 新信息显示原行动会造成更大伤害，人物换策略但底线不变：`x` 更新后 `zx` 重选。

## 最近邻排除

- `zx/xn`：施害者命令、制度酷刑、奖惩流程和精密两难。
- 信息更新 `x → zx`：新事实改变具体决策，不改变原则底线。
- `zn` 内部排序：更高意义取得优先级，不等于原意义总量下降。
- 状态遮蔽：恐惧、创伤、疲惫和麻木降低显影。
- 能力/路径不足：主体认为原则正确但做不到。
- `x并z`：公开改口、身份否认和悔过书不等于内部意义改判。
- 原端点不存在：安全环境中的口号、角色规范与身份自我想象。

## 拿掉测试

1. **施害者拿掉**：去掉命令、惩罚和制度流程，只剩自然临界，改判是否仍发生。
2. **行为失败拿掉**：即使假设行动成功，人物是否仍认为原原则不再正确。
3. **信息新增拿掉**：事实集合不变，仅危险体量上升，底线是否仍改写。
4. **更高原则拿掉**：没有另一个 `zn` 取得优先级时，原原则是否仍失效。
5. **恢复后再承诺**：危险解除后，人物是否拒绝重新承诺原原则。
6. **同条件复判**：同样危险再次出现时，是否继续按新原则判断。
7. **跨案例迁移**：在新的对象和情境中，原原则是否仍失去资格。
8. **利益方向反转**：新判断不再保护人物自身利益时，是否仍维持。
9. **原有稳定 `zn` 测试**：危险前是否曾在代价条件下坚持原原则。
10. **显影恢复测试**：机会恢复后原原则重新指导行动，则只属实践通道受阻。

现有候选均未通过全部测试。

## 反向测试

```text
zn 克 xz：
内部意义保持最终指导资格
→ 主体不再让危险决定最终方向
→ 危险对选择空间的支配下降
```

华莱士受刑和《末路浩劫》父亲更接近此方向。

方向区别：

- `xz 克 zn`：危险使原则正确性、无条件性或最终指导资格下降；
- `zn 克 xz`：原则仍正确，并压低危险对最终方向的支配力。

二者不能互相代证。

## 动态链后果

当前只允许写：

```text
危险逼近、退路缩窄
→ 原原则的实践通道被压缩
→ 主体在意义排序、策略调整与原则改判之间分化
→ 只有危险解除后仍撤销原原则正确性者，才进入 xz 克 zn 候选
```

若正式候选成立，感觉走向是：

> 从“无论代价多大，这件事仍然是对的”，转成“危险让我认定，这条原则本身不再有资格支配我的选择”。

不得机械生成：懦弱、背叛、黑化、成长、失去信仰、求生本能胜利或稳定人物本体改变。

## 三元与十元并行

三元只核验作品整体从危险逼近、价值测试到选择收束的感觉运动。

十元只核验：

- `xz` 是否为独立自然临界，而非 `zx/xn` 强迫；
- `zn` 危险前是否稳定存在；
- 变化落在行为、策略、排序，还是原则正确性；
- 危险解除后是否持续；
- 同条件与新情境是否复判。

不建立：

```text
命运主题自动克本体主题
危险是 zn 的父级
行动失败等于意义消失
```
