### 源端点、目标端点与变量

源端点 `nx`：主体仍沿组织、关系、流程或现状提供的基线方向行动，不争夺最终解释权，不建立公开替代路线，也不辞职或停止关键职责。单纯沉默、能力不足、被禁止表达、看穿骗局、主动揭露与公开反抗均不足。

目标端点 `x并z`：身份壳此前已经真实覆盖主体，并能被第三方用于归类、代表、调用或解释主体。目标变化必须发生在壳的代表、覆盖与归因接口，不能只发生在主体内心认同。

本轮把目标壳拆为三类：

1. 行政归类壳：职位、合同、编制、军籍等由制度接口维持；内心不认领通常不使其失效。
2. 职责履行壳：壳依赖主体持续完成关键职责；纯 `nx` 完整照章履行通常维持或强化该壳。
3. 共识背书壳：“全体一致”“本人自愿认同”“我们共同主张”等依赖可选签署、复述、署名或象征参与；仅此类仍保留窄候选。

被改变变量：

1. 壳对主体的自愿代表资格；
2. “全体”覆盖范围；
3. 署名、复述与共同归因合法性；
4. 行政标签与真实立场之间的距离；
5. 第三方能否继续把主体解释为壳的主动代表；
6. 目标变化是已成立壳被削弱，还是壳从未完成生成。

成立阶段与体量：

```text
低体量：一次可选背书缺失，只能使单份声明或局部代表范围缩小。
中体量：主体持续不进入共识背书位置，第三方稳定把“本人／全体”降为“外部归类／多数”。
高体量：多个关键成员均不提供背书，共同壳失去“我们”的现实接口；必须排除公开反抗、组织分裂与新壳建立。
```

显影条件：壳此前已经真实覆盖主体；主体仍继续基线流程；被撤回的接口不是关键职责；第三方实际修改代表判断；无辞职、职位解除、证据曝光、资源撤回或公开拆壳。

### 候选机制

#### 候选 A：共识背书接口断供

```text
共识壳此前已经覆盖主体
→ 壳需要持续签署、复述、署名或象征参与证明自愿代表
→ 主体继续基线流程，不另立方向
→ 只不进入可选背书位置
→ 第三方把“本人／全体立场”降为“外部标签／多数立场”
```

理论后果：若成立，克制对象不是整个身份壳，只是壳与该主体之间的自愿代表接口。

#### 候选 B：字面履行抽空精神代表性

```text
主体严格完成最低字面程序
→ 不补入主动倡议、认同和象征表演
→ 壳难以把主体解释为精神代表
```

理论后果：可能产生讽刺或降低精神代表性，但行政身份与职责覆盖仍可能完整，因此目标变量不足。

#### 候选 C：源动作已经退出 nx

```text
主体拒签、撤回署名、拒绝复述或明确否决
→ 共识壳覆盖下降
```

理论后果：目标端点清楚，但源动作可能已经是 `z/zn/x` 的主动立场、意义或否决行为，而不是“不占最终方向位置”的 `nx`。

#### 候选 D：未完成生成冒充被克

```text
壳从未真正取得主体背书
→ 后续仍不能代表主体
```

理论后果：只能判壳未完成生成，不能判已经成立的 `x并z` 被克制。

### 正例候选

1. **《抄写员巴特比》巴特比与抄写员身份壳**：抄写员壳此前真实成立，后续逐渐无法解释巴特比，目标端点较清楚。但他停止关键工作，已不再继续办公室基线流程，源端点偏离纯 `nx`。
2. **《好兵帅克》帅克与“忠诚英勇士兵”角色壳**：帅克持续沿军队命令与程序行动，不建立公开替代路线，源端点较接近 `nx`。但军队仍能行政上把他归为士兵；被抽空的是英雄化精神形象，行政壳与职责壳没有真实下降。
3. **组织共同声明中的不背书成员结构例**：成员继续普通流程，不辞职、不公开反对，只不允许姓名进入“全体一致”声明，结果壳从“全体”退为“多数”。结构端点最纯，但缺具体人物文本，且拒绝署名是否已构成主动否决仍未解决。

### 反例

1. 《使女的故事》奥芙弗雷德早期：内心不认领，外在完整履行，使女行政与职责壳仍稳定覆盖她。
2. 《1984》温斯顿公开反叛前：内心反党，党成员身份与公共归类没有下降。
3. 下属因恐惧签署虚假声明：`nx` 上升，但签署反而强化共识壳。
4. 员工辞职、人物公开撕下面具或停止关键职责：壳下降，但源端点已经不是纯 `nx`。
5. 记者调查并揭露组织造假：启动源优先检查 `xn/zn/zx`。
6. 壳从未成功吸纳主体：属于生成失败，不是克制。

### 最近邻排除

- 与 `zn 克 x并z`：因“这个身份不对”而撤回价值认领或关键履行，启动源是内部意义。
- 与 `zx 克 x并z`：公开拆壳、揭露、强迫说明与夺取解释权属于公开权能。
- 与 `x/xn`：撤销职位、账号、合同、名称、权限与资源属于掌握或制度配置。
- 与内部不认同：心理距离不自动改变公共覆盖。
- 与反向 `x并z 克 nx`：身份壳预设角色路线，使主体更沿既有安排行动，改变的是主体方向空间。

### 拿掉测试

1. 拿掉壳对持续自愿背书的依赖，沉默、拒签或不复述是否完全无效？
2. 恢复签署、复述和允许署名后，共识壳的自愿代表资格是否恢复？
3. 拿掉辞职、停工、公开拒绝、资源变化、职位解除和证据曝光后，覆盖是否仍下降？
4. 主体若停止关键职责，是否已经退出 `nx`？
5. 只有内心不认领时，第三方是否仍照常用壳代表主体？
6. 壳若从未完成吸纳，是否只是生成失败？
7. 拿掉拒签、撤回署名和明确否决的主动性，只保留“不占位”，第三方是否仍会自行降低代表资格？
8. 若拒签动作带有清楚价值判断、立场宣告或权限否决，源端点是否应改判 `zn/z/x`？

现有具体作品候选分别只通过源端或目标端，没有同时通过第 3、4、7、8 项。

### 反向测试

```text
nx 克 x并z 候选：
主体继续基线流程
→ 不进入可选共识背书位置
→ 壳的自愿代表与共同覆盖下降

x并z 克 nx：
身份壳预设角色路线
→ 主体可用方向被限定
→ 主体更沿壳提供的安排推进
```

正向改变壳的代表接口，反向改变主体的方向空间。反向在行政、家庭和制度身份中更容易成立，不能用来为正向补证。

### 动态链后果

```text
这个壳原本已经能把我写进“我们”
→ 我没有另立旗帜，也仍走在既有通道里
→ 行政标签与关键职责可能继续存在
→ 只有当我不进入可选背书位置，第三方也真的降低自愿代表判断
→ “全体／本人立场”才退成“多数／外部标签”
→ 但还必须证明这种不背书仍属于 nx，而不是主动否决或意义立场
```

改变的是身份壳对主体的自愿代表资格和共同覆盖范围，不机械生成身份消失、组织崩塌、真相曝光或真实自我回归。

### 三元与十元并行核验

三元继续判断作品整体精神运动。

十元本轮只核验：

- `nx` 是否仍沿基线方向并不另立路线；
- `x并z` 是否此前已经真实覆盖主体；
- 目标壳属于行政、职责还是共识背书；
- 第三方代表接口是否真实下降；
- 拒签、撤回署名或拒绝复述是否已经转为 `z/zn/x` 主动行为。

不从身份题材、沉默构图、制服或人物内心独白反推关系成立。

### 95%门槛

高置信结论：

- 99%：壳必须先成立；未完成吸纳不等于被克制。
- 99%：行政归类壳不因主体内心不认领而失效。
- 99%：纯 `nx` 完整履行关键职责通常维持或强化职责壳。
- 98%：停止关键职责、辞职和公开拒绝不能继续作为纯 `nx`。
- 98%：目标变量必须落在自愿代表、共同覆盖、署名与第三方归因。
- 97%：仅共识背书壳保留窄候选。
- 97%：拒签、撤回署名或拒绝复述必须先通过源动作归属测试。

未达到95%的核心机制：

- 缺少两个同时通过源端与目标端的具体人物案例；
- 《巴特比》通过目标端但源端偏离；
- 《好兵帅克》较通过源端但目标端不足；
- 唯一纯结构例缺具体人物，且拒签动作可能已是主动否决；
- 尚不能证明单纯“不占认领位置”会使第三方自行降低已成立壳的代表资格。

结论：

```text
几何位置：保留
行政归类壳：排除直接机制
职责履行壳：排除直接机制
共识背书壳：保留窄候选
正式机制：未锁定
待确认队列：不新增，仍属材料与源动作纯度不足
```
