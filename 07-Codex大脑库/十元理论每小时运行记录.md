### 对象分层

- 稳定本体：`zn` 是无奖励、无认可仍成立的内部意义确定；`xn` 是主体主动组织并使规则、训练、程序、记录或传统跨时间运行。一次抗命或一条规则不能反推本体。
- 当前状态：本关系主要发生在结构已经运行，主体明确判断“继续这样做会背弃我”的阶段。
- 行为功能：`zn` 显影为拒绝执行、拒绝维护、保留原则边界；`xn` 显影为排程、记录、训练、复制、修复与交接。行为必须改变运行变量。
- 光影：孤立站立、沉默拒绝、逆流、队列、表格、仪式与纪律只作辅助显影。
- 场景：军队、法庭、学校、教会、公司、制度与传统只是候选场景。
- 时间关系：内部意义先撤回认同，结构对主体的覆盖、自愿执行或再生产随后下降。先后本身不足。
- 关系位置：必须明确哪一个内部成员、执行者或受规训者撤回维护，以及哪套结构依赖其执行、修复或传递。
- 显影：观察无人监督时的自愿执行、内部修复、跨轮次复制和“这套结构应当继续”的理解是否下降。
- 动态链：从“这套运行方式定义我，也值得我继续维护”转成“结构仍在，但我不再替它主动续命”。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `zn`：主体形成不依赖奖励、认可、群体支持或胜利结果的意义确定，并判断既有运行方式违背不可放弃之物；即使无人看见，仍拒绝替它执行、修复或传递。普通不满、利益受损、冲动反抗、害怕处罚与意见分歧均不足。
- 目标端点 `xn`：已经真实跨时间运行的规则、程序、训练、纪律、记录、节点、交接、传统、重复实践或组织内部复制方式。一次命令或一个强势领导不自动构成 `xn`。
- 被改变变量：结构对主体的覆盖率；无人监督时的自愿执行率；成员主动修复结构的意愿；规则、传统或训练的跨轮次复制率；结构是否仍被理解为“应当继续”；结构是否只能依靠惯性与强制维持外壳。
- 成立阶段：`xn` 已经运行 → `zn` 判断继续维护会背弃不可让渡意义 → 结构对主体覆盖下降 → 自愿执行、内部修复或传递下降。
- 体量：低体量为一个成员拒绝让结构覆盖某项原则；中体量为关键成员撤回维护，流程必须设置例外或重新设计；高体量为群体撤回正当性，结构仍有强制外壳却失去内部再生产。
- 显影条件：拿掉暴力、夺权、财政崩溃、领导更替与外部失败后，结构仍因成员不再认为它值得被主动维护而衰减。

### 候选机制

- A 正当性撤回：`zn` 判断结构违背不可让渡意义 → 规则不再被理解为“应当遵循” → 自愿执行与内部维护下降。理论后果：改变意义接口和自愿再生产，不改变设施、资源或流程知识本身。
- B 覆盖边界被原则截断：`xn` 试图以统一程序覆盖主体 → `zn` 保留不可让渡原则 → 主体只在不违背原则的范围内执行 → 结构适用范围缩小。理论后果：制度可以继续存在，但不能完整定义或调用这个人。
- C 成员退出复制链：结构依赖示范、训练、交接和传递 → `zn` 使成员拒绝把结构交给下一轮 → 结构失去内部复制节点。理论后果：克制可以表现为“不再替结构续命”，不要求公开反抗。
- 统一机制：A 是意义判断，B 是当下覆盖结果，C 是时间后果。`zn` 撤回 `xn` 的“应当被维护”资格，使结构先失去对主体的完整覆盖，再失去成员自愿执行、修复与传递形成的跨轮次再生产。

### 正例

1. 《血战钢锯岭》戴斯蒙德·多斯｜训练与军法阶段：军队以统一训练、武器规范、纪律、考核和服役流程组织士兵；多斯无奖励仍认定不能持枪杀人但必须救人，拒绝让持枪程序覆盖该原则。军队对他的覆盖被截断，最终必须设置例外并重写服役接口。即使没有即时法律胜利，他仍拒绝持枪，说明启动源不是外部认可。
2. 《安提戈涅》安提戈涅｜埋葬波吕涅刻斯阶段：她认定死者必须被埋葬，亲属义务不可被城邦命令取消；禁葬令通过守卫、惩罚与服从程序持续运行。她退出禁令的自愿服从链，禁令仍有强制外壳，却无法取得完整内部认同。
3. 良心拒服兵役者结构例：主体已进入征召、登记、训练和服役程序，却因不可让渡原则拒绝某项行为。制度可以处罚，却不能使其在无人监督时主动维护或把该规范作为正确传统传给下一人。

### 反例

1. 《V字仇杀队》炸毁议会：爆炸、动员、夺取公共局面主要属于 `zx` 行动链。
2. 员工觉得公司文化虚伪却照常执行：只有态度变化，`xn` 的覆盖、执行、修复和复制变量未变。
3. 制度因财政断裂或技术故障停摆：启动源是资源或系统故障。
4. 学生一时愤怒违反校规：可能只是状态、冲动或 `z` 占位，没有稳定 `zn`。
5. 成员因待遇下降辞职：利益变化不等于不可让渡意义。
6. 法律裁定制度无效而成员只服从新法律：启动源更接近外部 `xn/x/zx`。
7. 领导被推翻后流程停止：领导更替不等于内部意义撤回。
8. 一次公开抗议后制度仍被成员正常维护：没有改变自愿执行和复制率。

### 最近邻

- 与 `zx` 对结构的公开压制：`zx` 改变现实权力、设施、命令链和公开局面；`zn 克 xn` 改变正当性、覆盖、自愿执行、内部修复与复制。
- 与 `nx` 停止跟随：`nx` 只说明不再沿既有方向继续；没有“继续这样做会背弃不可让渡意义”，不能判 `zn`。
- 与 `xn` 内部自我修订：结构因效率、法律冲突或反馈而调整，启动源仍是 `xn`；本关系要求成员基于意义撤回维护。
- 与反向 `xn 克 zn`：反向是长期制度、训练与奖惩压缩意义形成、表达或实践条件；本轮改变的是结构运行变量。

### 拿掉测试

1. 拿掉 `zn` 意义判断，只保留利益、恐惧或派系斗争，若结构仍受抵制，则不依赖本关系。
2. 拿掉公开号召、暴力、爆炸和夺权，若成员仍不再自愿执行、维护或传递，支持 `zn` 直接作用。
3. 拿掉已运行的 `xn`，若只剩两种价值观争论，则目标端点不存在。
4. 拿掉关键成员的自愿维护后，制度若依靠纯强制仍能运行，只能判局部或中低体量克制，不能写成“制度被击穿”。
5. 恢复主体对结构的内部认同后，若自愿执行、修复或复制回升，说明意义接口是关键变量。

### 反向测试

```text
zn 克 xn：内部意义撤回“应当维护”资格 → 覆盖、自愿执行、修复与复制下降。
xn 克 zn：长期制度、训练、程序和奖惩组织主体 → 意义形成、表达或实践机会被压缩。
```

两方向不对称。前者改变结构的运行与再生产，后者改变意义的形成或显影条件，不能因人物与制度对立就双向代证。

### 动态链后果

```text
稳定结构仍在运行
→ 主体发现继续维护会背弃不可放弃之物
→ “照规矩做是正确的”变成“我只是被迫照做”
→ 结构仍保留外壳，却失去我主动修复和传给下一轮的支持
```

改变的感觉层是：**制度不是被一拳打碎，而是失去这个人愿意继续替它活下去、修好它并传下去的理由。** 不机械生成革命胜利、制度物理倒塌、群众动员、领导更替或新制度建立。
