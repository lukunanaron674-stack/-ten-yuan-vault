## 本轮性质

本轮只审计 `nz 生 nx`。没有修改核心生补克表、关系词典、专项索引、旧审计或待确认队列，也没有新建专项。新推进是把“主体不提出自己的路线”拆成两种不同结果：一是为了保留关系而暂停定向或作出一次自主委托；二是即使关系安全、对方停止提供路线，主体仍明确承认对方拥有最终决定资格。只有第二种才继续接近 `nx`。

## 对象分层

| 层级 | `nz` 源端点 | `nx` 目标端点 | 本轮判定 |
|---|---|---|---|
| 稳定本体 | 长期保留关系余温与回返位置 | 长期不占最终方向位置 | 不支持由一次关系让路生成 |
| 当前状态 | 此阶段不愿关系或共同阶段结束 | 此阶段沿关系对象路线 | 最可能成立层 |
| 行为功能 | 等待、回返、保留共同时间 | 不提替代路线、不使用否决、把最终方向交给对方 | 暂停提案不足 |
| 光影 | 暖光、旧路、旧物、空位 | 侧位、跟随、让路 | 只作显影 |
| 场景 | 重逢、旅途、告别、共同生活 | 路线、队伍、同行 | 场景不能替代端点 |
| 时间关系 | 关系余温先成立 | 关系安全、路线供给撤场后仍不恢复方向 | 必须跨阶段 |
| 关系位置 | 双方原本平等可选 | 一方持续单向退出最终决定 | 对称交换不成立 |
| 显影 | 害怕关系结束 | 明确承认对方拥有最终决定资格 | 本轮核心 |

## 源端点、目标端点、变量、阶段、体量与显影

源端点 `nz`：关系此前真实存在并积累共同时间；主体保留可信回返位置；关系对象不可随意替换；主体不愿关系或共同阶段结束。一次好感、怕孤独、恋爱题材、临时照顾和现实依赖均不足。

目标端点 `nx`：主体原本拥有可行路线、否决权和承担结果的能力；关系安全后仍长期不提出替代路线、不使用否决，并明确把最终决定资格交给关系对象。只是多陪一段、听建议、等待对方提案或暂时不定向均不足。

被改变变量：独自定向必要感、最终方向资格认领强度、替代路线是否保留、否决权是否使用、提案方向是否长期单向、对方停止提供路线后主体是否恢复自主定向，以及主体是否明确承认对方拥有最终决定资格。

成立阶段：关系余温已经存在；首次为避免分离而让路；分离风险解除；恢复自主不会损害关系；对方停止持续供给路线；共同任务、日程与生活结构被拿掉；观察主体是恢复自主、停滞等待，还是继续把最终决定资格交给对方。

体量：低体量为一次采用对方路线；中体量为一段关系中反复暂停自己的提案；只有在路线供给撤场后仍跨阶段转交最终方向资格，才接近高作用量关系层 `nx`。当前不支持稳定人物本体生成。

显影条件：双方原本平等可选；没有年龄监护、职位命令、任务预设、资源依赖、照护安全、专业能力差与危险压迫；关系安全且自主不会造成分离；对方不再持续提供路线；主体仍明确让对方拥有最终决定资格。

## 候选机制与理论后果

### 候选 A：关系保全型自主委托

```text
主体不愿关系结束
→ 判断坚持自己的路线会造成分离
→ 主体主动选择对方路线
→ 共同时间继续
```

理论后果：`nz` 确实改变本次路线选择，但主体仍在使用自己的最终方向权。这只能证明一次自主委托，不能证明 `nx` 已生成。

### 候选 B：方向暂停

```text
关系危机仍未完全解除
→ 主体暂时不提出自己的路线
→ 等待关系稳定或等待对方先提案
```

理论后果：改变的是定向时机，不是最终方向资格。若对方也不提案时主体只是等待、停滞或之后恢复自主，只判方向暂停。

### 候选 C：方向转交

```text
关系已经安全
→ 恢复自主不会造成分离
→ 对方停止持续提供路线
→ 主体仍明确承认对方拥有最终决定资格
→ 自己跨阶段不使用替代路线与否决
```

理论后果：这是当前最接近关系层 `nx` 的窄候选，但仍须排除习惯、共同结构、目标融合与原有稳定 `nx`。

### 候选 D：对称协商或目标融合

```text
双方轮流提案、否决与让路
或
双方共同形成第三条路线
```

理论后果：双方仍保留方向资格，不构成单向 `nx`。

## 正例候选

1. **山姆与弗罗多｜进入魔多与末日火山阶段**：长期共同旅程形成强关系余温，山姆持续沿弗罗多和魔戒任务方向推进。支持点是山姆行动能力强却不改写最终路线。污染点是守护意义 `zn`、既定任务 `xn`、照护 `n` 与危险 `xz` 均过强，关系从未进入安全阶段，无法执行路线供给撤场和方向转交测试。
2. **《末路浩劫》父亲与男孩｜灾后向南阶段**：父亲是男孩唯一可信停靠，路线与风险判断长期由父亲决定。污染点是年龄、监护、保护、生存危险与原本不平等的决定位置无法拿掉。
3. **《最后生还者》乔尔与艾莉｜护送旅程阶段**：长期共同时间与依恋清楚，艾莉大量沿乔尔判断推进。污染点是年龄差、护送任务、照护、危险与专业能力差。
4. **旧友重逢后的单方让路结构**：双方原本拥有同等可行路线，一方只因不愿再次分离而选择对方路线。该结构可以证明一次关系保全型自主委托，但尚不能证明关系安全且对方停止提案后，主体仍明确转交最终方向资格。

## 反例

1. 杰西与席琳继续散步：共同时间延长与持续协商。
2. 关系深厚但各自坚持职业和城市路线：`nz` 有而 `nx` 无。
3. 接受医生、导师或专业人员安排：专业位置、`n` 或 `xn` 已提供方向。
4. 孩子跟随父母：年龄与监护决定路线。
5. 恋人以分手威胁服从：`x/zx/z` 压力。
6. 因住房、资金或安全留下：`n/x` 现实依赖。
7. 双方形成第三条路线或轮流决定：共同协商。
8. 关系安全、对方停止提案后主体恢复自主路线：一次委托。
9. 对方停止提案后主体只是等待、不行动，也不承认对方拥有最终决定资格：方向暂停，不是方向转交。
10. 主体在关系前已经是稳定 `nx`：关系只是显影机会。

## 最近邻排除

- `n`：改变能否被接住，不等于交出最终路线。
- `z 克 nx`：重要认可使主体重新取得方向资格，本轮方向相反。
- `x/zx`：威胁、控制与资源依赖造成服从。
- `xn`：共同任务、日程和生活结构持续供给路线。
- 共同协商：双方均保留提案与否决资格。
- 目标融合：对方路线已经成为主体自己的目标，不是跟随。
- 稳定 `nx`：关系只提供显影场景，不是生成源。
- 方向暂停：主体不提案但也没有把决定资格交给对方。

## 拿掉测试

1. 拿掉 `nz`，若仍因任务、年龄、危险、资源、职位、专业或照护跟随，不成立。
2. 拿掉命令、威胁和对方主动占位后，主体是否仍让路？
3. 拿掉安全、住房、金钱与照护依赖后，让位是否仍存在？
4. 拿掉共同时间，只剩一次好感，源端点是否消失？
5. 拿掉路线撤回，只剩陪伴、建议与协商，目标端点是否消失？
6. 关系安全、恢复自主不会分离后，主体是否仍不恢复路线？
7. 对方停止持续提供路线后，主体是恢复自主、停滞等待，还是明确转交决定资格？
8. 双方交换提案、否决与让路位置后，是否只是对称协商？
9. 拿掉共同任务、日程、生活结构、目标融合与习惯后，持续不占位是否仍存在？
10. 主体此前是否已经是稳定 `nx`？
11. 若主体只是停止定向而没有承认对方拥有最终决定资格，只能判方向暂停。

现有案例均未通过第 6 至第 11 项完整组合。

## 反向测试

```text
nz 生 nx 候选：
关系余温先成立
→ 主体首次为保全关系选择对方路线
→ 关系安全、路线供给撤场后
→ 仍把最终决定资格交给对方

nx 生 nz：
主体长期沿对方方向共同生活
→ 共同路径积累时间厚度
→ 形成不愿结束与回返余温
```

反向关系更容易由长期同行解释。最终同时出现“不舍与跟随”不能给两个方向重复记账。

## 三元与十元并行核验

三元层只记录关系保全、方向让位与关系持续的粗结构；十元层继续区分 `nz` 的余温停靠与 `nx` 的最终方向不占位。十元关系不是三元的子类派生，三元的关系维持也不能自动证明 `nz 生 nx`。

## 动态链后果

```text
我不愿这段关系结束
→ 我主动选择你的路线
→ 这一步仍是我的自主决定
→ 关系已经安全，恢复自主不会失去你
→ 你停止继续替我提供路线
→ 我若只是等待，就是方向暂停
→ 我若仍明确把最终决定资格交给你
→ 再排除共同结构、习惯与原有 nx
→ 才继续接近 nz 生 nx
```

改变的是关系中最终方向资格的认领与转交，不机械生成永久服从、人格软弱、健康关系、正确选择或共同终局。

- 延长共同时间、听建议与共同协商不等于 `nx`：99%。

- “不提出路线”必须进一步区分方向暂停与方向转交：98%。
- 只有主体明确承认对方拥有最终决定资格，才触及目标端点：97%。
- 年龄、监护、危险、照护、任务、资源、专业差、共同结构、习惯、目标融合与原有稳定 `nx` 必须排除：99%。
