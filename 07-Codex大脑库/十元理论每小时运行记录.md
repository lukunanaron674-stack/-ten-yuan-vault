## 3. 源端、目标端、变量与成立条件

### 源端`nx`

- 人物与阶段：原主体具备现实资格，却跨阶段不认领账户、作品、项目、时间或关系的最终方向，反复让特定代理者代定、代管和对外回应。
- 具体名词：方向空位、决定位置不认领、最终路线外置、持续代理依赖。
- 排除：一次授权、危机分工、专业委托、明确职位服从和强制接管。
- 体量：低体量只产生一次代理机会；中体量形成默认路由；高体量候选必须在授权清零后仍产生独立处分边界。

### 目标端`x`

本轮把目标拆成五个变量：

1. **代理机会**：对象是否反复经过代理者。
2. **事实影响**：代理者是否能使第三方短期改变对象状态。
3. **处分资格**：代理者的指令是否以其自身资格生效。
4. **排除能力**：原主体反对时，代理者是否仍能排除原主体。
5. **跨对象迁移**：掌握是否可迁移到无历史授权的新对象。

新增分账：**原主体接管阻力**包括信息断层、操作能力退化、迁移成本和流程依赖。它可与代理者事实影响同时上升，但不等于第3至第5项成立。

### 成立阶段与显影条件

- 阶段A：原主体反复让位，允许记录代理次数、信息集中和默认路由。
- 阶段B：代理者成为事实中心，仍需追查授权和执行来源。
- 阶段C：原主体公开反对；全部第三方知情；合同、密码、身份壳、程序和自动路由撤销；延迟清零。
- 阶段D：把信息、操作能力和必要知识补回原主体，再测试代理者能否以自身资格排除原主体，并迁移到新对象。
- 显影条件：处分必须由代理者自身资格生效，而不是第三方错误执行旧授权；原主体接管困难不能只来自能力退化或迁移成本。

## 4. 候选机制

### A｜方向空位独立生成处分边界

```text
原主体持续不认领方向
→ 对象反复经过代理者
→ 代理者指令逐渐脱离逐次授权
→ 获得可排除原主体的处分资格
→ x掌握边界新增
```

严格候选由约87%降为约85%。若未来成立，只能先锁“持续方向空位使代理接口转化为独立处分中心”的窄机制。

### B｜历史授权与执行网络维持事实控制

```text
原主体反复委托
→ 合同、程序、数据库、身份壳和第三方形成默认执行链
→ 代理者发令后仍有人执行
→ 表面控制持续
```

这是高置信竞争解释。真正使指令生效的是`xn/x并z/zx/x`网络，不是纯`nx`。

### C｜原主体能力退化与接管成本上升

```text
长期不操作对象
→ 信息断层、技能退化、关系网络陌生和迁移成本累积
→ 原主体即使撤权也难以立即接管
→ 代理者看起来不可替代
```

理论后果：这是原主体操作能力和流程接入下降，不等于代理者获得独立处分资格。

## 5. 正例候选

1. **Britney Spears与Jamie Spears，监护制度运行阶段**
   - 源端候选：Britney长期无法或不被允许认领生活、财务与事业方向。
   - 目标候选：Jamie对财务、合同、医疗和日程的掌握。
   - 污染：法院监护、合同、制度执行与权限直接提供`x`。
   - 判断：证明制度掌握，不证明纯`nx 生 x`。

2. **Elvis Presley与Colonel Tom Parker，事业后期**
   - 源端候选：Elvis长期把事业路线和对外接口交给Parker。
   - 目标候选：Parker成为合同、演出与行业关系的事实中心。
   - 污染：合同、主动操纵、财务依赖、信息差与行业网络。
   - 判断：更支持执行网络与接管成本累积。

3. **严格控制候选：创作者与经纪人**
   - 创作者公开撤销合同、密码、平台权限、署名接口和第三方口径；全部合作方知情，旧程序关闭，延迟清零。
   - 创作者补回作品资料、平台操作和联系人信息后，经纪人仍能以自身资格排除创作者、处分旧作品，并控制无历史授权的新作品。
   - 当前缺两组可核验材料。

## 6. 反例

1. 一次授权助理代购：明确委托。
2. 家长凭资金、密码或监护资格控制账户：既有权限直接提供`x`。
3. 助理长期收件和排会议：默认路由。
4. 负责人主动施压和占位：更接近`z 克 nx`。
5. 撤权后系统尚未刷新：技术延迟。
6. 第三方不知道撤权：旧口径与传播惯性。
7. 代理者懂流程但不能改变对象：知识留存。
8. 原主体不会操作平台而暂时无法接管：能力退化，不是代理者独立掌握。

## 7. 最近邻排除

- `z 克 nx`：代理者主动占位并压缩原主体方向。
- `xn`：程序、记录、默认路由与迁移成本。
- `x并z`：职位、公开壳和调用中心身份。
- `zx 补 nx`：借现成权限、关系与通道做成。
- 合同、所有权、监护、密码和系统权限：直接提供掌握。
- 信息与技能优势：提高影响和接管阻力，不等于对象归代理者掌握。
- 原主体`x`下降：原主体失去操作能力或接口，不自动等于代理者`x`新生。

## 10. 动态链后果

```text
我持续不认领方向
→ 事情反复经由你处理
→ 你积累授权历史、信息、熟练度和他者服从
→ 我逐渐失去操作经验并承担更高接管成本
→ 你看起来成为不可替代的事实中心
→ 若授权清零、能力补回后我能恢复控制，x并未新生
→ 只有你仍以自身资格排除我并跨新对象处分
→ 才接近独立掌握
```

本轮只改变代理机会、事实控制外观、原主体接管阻力和关系走向，不机械生成所有权、法律权利、职位或稳定支配人格。
