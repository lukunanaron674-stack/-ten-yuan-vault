#### 对象分层

- 稳定本体：不从一次服从、代办或接管反推稳定 `nx` 或 `x`。
- 当前状态：犹豫、等待、临时代管与持续关系功能分开。
- 行为功能：`nx` 显影为不取回方向、否决与直接接口；`x` 显影为调配、使用、划界与最终否决。
- 光影：退后、低头、侧位、钥匙、控制台和办公桌只作视觉证据。
- 场景：家庭、公司、婚姻、庄园、账户与职位不能替代端点。
- 时间关系：乙先持续让位、甲后控制更多只证明先后；必须证明空位实际改变掌握边界。
- 关系位置：下属、子女、伴侣、管家与负责人称谓不能替代可认领权和新增事实控制。
- 显影：观察原本共同决定的事项是否转为一方单独调配，以及信息、资源和对外接口是否集中。
- 动态链：只描述“我不决定”如何可能滑向“这部分不再由我掌握”，不写成人格自动生成。

#### 源端点、目标端点与变量

- 源端点 `nx`：主体原本拥有可认领的方向、否决或直接对外位置，却在没有持续强迫时跨阶段不认领，并沿另一方、关系、流程或现状给出的方向推进。
- 目标端点 `x`：另一主体新增对具体对象、资源、时间、权限或关系的调配、使用、归属与最终否决权。
- 被改变变量：谁决定工作顺序、谁调配时间资源、谁控制对外口径、谁拥有最终否决权、原本共同或模糊的范围是否被纳入一方掌握。
- 成立阶段：源主体先拥有真实可取回位置，随后多次不认领；目标主体原本只有局部掌握，之后因反复代决取得稳定事实权限。
- 关系体量：低体量一次代办不成立；中体量多阶段代管时间资源；高体量生活、工作、关系和外部表达整体进入一方控制。
- 显影条件：至少看到共同决定改为单方决定、源主体退出信息或资源接口、目标主体获得新调用或否决权，并跨阶段维持。

#### 候选机制

- 候选 A：持续空位被既有掌握边界吸纳。`nx` 主体长期不认领本可决定的位置，另一方为维持行动反复代决，临时代管逐渐成为默认控制。理论后果：关系只先落在关系层，`x` 不是凭空产生，而是既有掌握吸纳模糊或共同范围。
- 候选 B：默认授权累积为事实控制。多次默认代办使信息、资源与外部请求只流向另一方，可撤回授权逐渐变成稳定事实权限。理论后果：若始终可随时撤回且事实控制未改变，则不成立；并须排除 `xn` 流程集中。
- 竞争 C：`z 克 nx` 同时伴随 `x` 增长。若甲持续表达、要求、决定和占位，直接关系是甲压缩乙的选择空间，`x` 增长只是并发现象。
- 竞争 D：职位、法律或制度直接赋权。若甲本来就拥有权限、乙本来就无权，`x` 来源不是 `nx`。

#### 正例候选

1. 《穿普拉达的女王》中段安迪—米兰达：安迪逐步放弃私人时间、工作节奏和可拒绝边界，米兰达的控制扩展到全天候任务与私人生活；但米兰达主动要求、职位 `x` 与 `zx` 压迫过强，未通过拿掉施压测试。
2. 《长日将尽》史蒂文斯—达林顿勋爵：史蒂文斯长期不把私人判断与生活方向置于最终位置，主人意志进入私人时间、劳动与公开表达；但管家职位、阶级制度和职业 `xn` 是强第三因素。
3. 成年子女—父母长期代决结构：子女拥有账户、居住和职业选择权，却长期不查看、不联系机构、不提出路线；父母从建议逐步掌握账户、日程、租房和对外沟通。这是纯度最高的结构候选，但缺少可核验具体人物文本。

#### 反例

1. 老板一次授权负责人代管项目：仍有期限、撤回权和边界，只是临时分工。
2. 家长威胁子女交出账户密码：启动源是强制、`zx` 或 `x` 自身扩张。
3. 员工职位本来没有预算权限：没有可让出的决定位置。
4. 伴侣因专业分工负责财务，双方仍可查账和共同否决：主要是 `xn`。
5. 公司制度直接授予审批权：`x` 来源是制度，不是成员让位。
6. 乙沉默但甲没有新增调配或否决权：只有 `nx` 显影，没有目标变量变化。

#### 最近邻排除

- 与 `z 克 nx`：前者启动变量是甲的认可/占位作用并改变乙的方向合法性；本候选启动变量是乙在没有持续施压时留下稳定方向空位，并改变甲的掌握范围。
- 与 `zx` 强制：公开显权、惩罚和逼迫不属于本关系。
- 与 `xn` 组织：信息、排程和流程集中不等于归谁掌握；负责人若没有最终使用和否决权，不能判 `x` 上升。
- 与一次授权：一次代办不形成稳定事实控制。

#### 拿掉测试

1. 拿掉 `nx` 主体持续不认领后，若 `x` 仍凭职位、产权或强迫扩大，案例不依赖本关系。
2. 拿掉 `x` 主体主动施压后，若掌握范围仍因反复代决而扩大，才支持候选 A。
3. 拿掉事实控制变化，只剩听话、依赖或关系亲近，目标端点不存在。
4. 拿掉原始可认领位置，主体本来无权，源端点不足。
5. 拿掉长期重复，只剩一次代办，不能从状态推生位。
6. 恢复源主体的信息、否决与直接外部接口后，若掌握边界立即缩回，说明此前可能存在事实吸纳。

#### 反向测试

```text
nx 生 x 候选：乙先持续让位，甲的事实掌握边界随后扩大。
x 生 nx 候选：甲先掌握资源与通道，乙随后越来越只能沿甲给出的方向行动。
```

两方向都可能形成反馈，但改变变量不同。反向可能成立不能证明原方向，必须按阶段拆为“让位→掌握扩大→扩大控制再强化沿路推进”。

#### 动态链后果

```text
我一次次不认领本可决定的部分
→ 关系中的方向空位被对方持续代管
→ 代管变成默认权限
→ 对方的“归我掌握”边界扩大
```

改变的是关系中的事实掌握边界，不机械生成邪恶控制者、永久依赖人格，也不能把 `nx→x→zx` 直接当作自动生成器。

#### 三元与十元并行

三元只核验作品整体精神运动；十元本轮只核验 `nx` 是否持续不占方向位置、`x` 是否获得具体掌握、作用是否独立于 `z/zx/xn` 与职位制度。两套系统不建立父子派生。

3. 拿掉行为失败后，人物仍明确认为原则不再正确，目标变量才落在 `zn`。
4. 拿掉原有稳定 `zn`，若只剩身份口号，不能判被克。
5. 拿掉更高意义排序后，原原则是否仍被持续撤销；否则只是排序变化。

#### 反向测试

```text
xz 克 zn：危险改变意义的无条件性与最终指导资格。

```

华莱士与《末路浩劫》父亲更接近反向候选，证明两方向不能混写。

```text

```
