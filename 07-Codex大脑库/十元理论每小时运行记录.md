### 对象分层

- 稳定本体：`x并z` 是长期通过身份壳、公开角色、包装或表里分层存在；`nz` 是长期保留共同时间余温、不愿结束与回返姿态。一次伪装或一次不舍不能反推稳定本体。
- 当前状态：本关系主要发生在已有关系余温仍存在、身份壳开始主导相处或被揭示的阶段。
- 行为功能：扮演、包装、共同说法、角色履行；等待、回望、延迟告别、保留联系。行为只有改变可信回返变量时才构成关系证据。
- 光影：面具、制服、镜面、精致门面与暖光、旧物、空座、旧居只能辅助显影。
- 场景：婚姻表象、卧底身份、公共家庭、职业角色、旧爱与共同生活阶段只是场景候选。
- 时间关系：真实关系先留下余温，身份壳随后介入或暴露，关系证据被重判，余温与停靠意愿下降。先后本身不足。
- 关系位置：配偶角色、假名、职业身份、公众形象与恋人、伴侣、旧友、家人位置必须分开；核心是角色是否替代或污染真实关系位置。
- 显影：观察表里分层稳定度、行为归因歧义、共同记忆归属、可信回返、停靠意愿与不愿结束强度。
- 动态链：改变的是“我通过谁与你相处”以及“我还能不能回到我们”，不机械生成揭露、仇恨、分手或壳整体崩塌。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `x并z`：存在持续运行而非一次性的身份壳或公共角色；壳真实参与双方相处；同一行为可同时被读取为角色履行与真实靠近；壳决定内部主体如何被关系对象看见；拿掉壳会改变关系结构。
- 目标端点 `nz`：克制前已经有真实共同生活或停靠、时间厚度与余温、至少一方不愿承认结束，并存在可回返、等待或继续保留的位置。
- 被改变变量：过去温柔行为的真实性可判定度、当前靠近行为的归因稳定度、共同记忆是否仍属于真实双方、原关系位置是否仍安全可返回、继续等待与保留联系的意愿。
- 成立阶段：真实关系先留下余温 → 身份壳主导相处或被揭示 → 过去与当下关系证据出现双重归因 → 一方无法确认自己爱过、等待或依恋的是谁 → 回返位置失去可信度 → `nz` 下降。
- 体量：低体量为一次亲近被怀疑为角色动作；中体量为一段共同记忆被重判；高体量为壳覆盖整段关系，真实主体无法回到原位置。
- 显影条件：必须先有真实 `nz`；同一关系证据出现“真实主体 / 身份角色”双重归因；壳是实际相处接口；壳介入后等待、停靠或回返意愿下降；拿掉愤怒、道德谴责和外部惩罚后，可信回返问题仍成立。

### 候选机制

- A 关系位置替代：稳定公共角色长期承担相处功能，双方越来越只通过角色说话和行动，真实主体退出原关系位置，`nz` 找不到可返回对象。理论后果：克制的是“真实双方还能否重新相遇”。
- B 关系证据污染：身份壳与真实动机同时存在，温柔、照顾、承诺和共同记忆都具有双重来源，关系对象无法稳定归因，过去与现在的余温失去可靠证据。理论后果：即使温柔有真实部分，只要无法稳定归因，`nz` 仍会受损。
- 统一机制：B 是直接作用过程，A 是结构结果。身份壳先污染关系证据归因，随后使真实主体退出可返回的关系位置。
- 排除 C“被骗后生气”：愤怒、报复与离开可能来自 `zn` 的价值判断、`zx` 的攻击、`xn` 的骗局流程或 `x` 的占有控制，不足以单独证明本关系。

### 正例

1. 《广告狂人》唐·德雷柏与贝蒂，真实身份被发现后的婚姻阶段：多年婚姻与家庭共同生活已经形成 `nz`；“唐·德雷柏”身份壳被揭开后，过去的照顾、承诺、战争经历与家庭叙述全部出现双重归因，贝蒂无法确认与自己共同生活的是唐还是被扮演出来的唐，原婚姻位置失去可信回返。
2. 《美国谍梦》克拉克与玛莎，身份揭露前后：玛莎已经把共同生活、婚姻与未来当作不愿结束的停靠位置；真实身份暴露后，过去每次照顾、求助与婚姻承诺被重新解释，她仍有余温，却没有可确认的真实对象可返回。
3. 纯结构例：甲以稳定假名、职业与家庭经历同乙共同生活多年；乙后来发现照顾可能是真心，婚姻身份却为任务设置。乙的核心变化是“不知道过去爱我的究竟是谁，也不知道还能回到哪一个我们”。

### 反例

1. 一次普通谎言被揭穿：没有稳定身份壳。
2. 卧底暴露后被组织追杀：改变的是安全与行动后果，优先检查 `xz/xn/zx`。
3. 夫妻对外维持体面、私下仍能真实相处：壳与 `nz` 共存，未发生克制。
4. 演员卸妆后伴侣仍能确认真实主体：回返位置未受损。
5. 《真实的谎言》中秘密身份最终被整合进婚姻：说明壳可暴露而不持续克制 `nz`。
6. 《史密斯夫妇》中双方身份暴露后重建关系：冲突存在，但真实主体重新取得关系位置。
7. 太太社交圈怀疑陌生人：只证明群体边界与信任，不证明 `nz`。
8. 关系本来没有余温，只因骗局结束合作：目标端点不存在。

### 最近邻

- 与 `x 克 nz`：`x` 通过占有、排他、控制和否决使停靠失去自愿性；`x并z` 通过身份壳使关系证据无法归因。最短区别是：`x` 让你不能自由留下；`x并z` 让你不知道自己留下的是谁。
- 与 `xn`：角色脚本、信息隔离、监控和长期骗局流程属于 `xn`；只有这些流程通过身份壳改变关系证据的读取与归因，才进入本关系。
- 与 `zn`：因“欺骗不道德”而离开优先检查 `zn`；本关系拿掉道德判断后仍留下“我无法确认过去与现在的关系属于真实的谁”。
- 与普通信任破裂：普通信任破裂只说明“不相信你”；本关系必须进一步证明共同记忆归属被重判、原关系位置不可返回以及 `nz` 真实下降。

### 拿掉测试

1. 拿掉稳定身份壳，只保留一次谎言，关系若仍同样崩解，则不依赖本关系。
2. 拿掉既有 `nz`，只剩合作与欺骗，目标端点不存在。
3. 拿掉愤怒、道德谴责与外部惩罚，若关系证据仍无法归因，支持本关系。
4. 拿掉 `xn` 的骗局流程，只保留壳已成立的事实，若可信回返仍下降，说明直接作用来自 `x并z`。
5. 壳暴露后双方若能稳定确认真实主体并重新停靠，说明克制被解除或从未达到高体量。
6. 过去关系若无真实共同时间，只是单方幻想，不能判 `nz` 被克。

两个具体案例均通过核心拿掉测试：即使移除外围冲突，身份壳仍迫使过去关系证据被重新归因。

### 反向测试

```text
x并z 克 nz：身份壳污染关系证据归因，使可信回返、关系余温与停靠意愿下降。
nz 克 x并z：真实关系余温使主体无法继续只按任务、角色或公共说法相处，在关键节点放下、背叛或撕开身份壳。
```

《色，戒》王佳芝放走易先生更接近反向 `nz 克 x并z`。同一作品可形成双向拉扯，但目标变量不同，不能互相代证。

### 动态链后果

```text
我们曾经真实共同生活
→ 后来我发现，只能通过你的身份壳理解你
→ 过去每一次温柔都同时像真实与表演
→ 我不再知道该回到你，还是回到你的角色
→ 关系形式可能还在，余温却失去停靠对象
```

改变的感觉层是：关系从“仍可回去”，转成“过去仍有温度，但已找不到可以回去的真实对象”。不机械生成分手、揭穿、报复、仇恨或壳整体崩塌。

### 三元与十元并行

三元继续核验作品整体精神走向；十元只核验 `x并z` 身份壳是否稳定成立、`nz` 是否先有真实共同时间与余温、壳是否使关系证据失去稳定归因、可信回返和停靠意愿是否下降，以及 `xn/x/zx/zn` 是否为第三因素。不得把 `x并z` 写成 `nz` 父级，也不得用五大主题“空间克命运”反推本关系。

### 95%门槛

- 99%：一次谎言、制服、公开身份、角色扮演和被骗后生气不能证明本关系。
- 99%：目标 `nz` 必须在克制前已真实成立。
- 98%：目标变量必须落在关系证据归因、共同记忆归属与可信回返，而不是一般信任、愤怒或安全后果。
- 97%：最近邻能够与 `x 克 nz`、`xn`、`zn` 和普通信任破裂分开。
- 96%：候选 A、B 可统一为“证据污染 → 关系位置替代”的连续过程，两个具体作品案例与一个结构例通过拿掉和反向测试。

结论：96%正式锁定。无需新增待用户确认问题。
