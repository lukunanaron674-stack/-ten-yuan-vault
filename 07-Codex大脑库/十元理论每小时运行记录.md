## 3. 源端、目标端、变量与成立条件

### 源端`nx`

- 人物与阶段：人物已经被职位、亲属关系、旧作品署名、组织身份、艺名或公共称谓稳定指认，却持续不自称、不复述、不背书，并拒绝为当前调用提供第一人称认证。
- 具体名词：身份方向不认领、主体认证撤回、第一人称代表接口停止、壳内被动存在。
- 排除：公开否认、辞职、除名、撤权、停止履行、数据库更新、宣传停止、失联与时间遗忘。
- 体量：低体量只影响一次回应；中体量影响持续自我呈现；高体量候选必须使稳定公共壳多个外部变量同步下降。

### 目标端`x并z`

本轮拆成八个变量：

1. **事实索引壳**：旧作品、历史事件、亲属事实和既成记录是否继续正确归因。
2. **制度资格壳**：职位、法律资格、名册和合同身份是否继续有效。
3. **静态第三方调用**：无需主体配合时，能否继续检索、分类、引用和指认。
4. **持续表演壳**：身份是否依赖主体持续回应、扮演和第一人称维持。
5. **单次互动令牌**：本次发言、签署、回应或代表行为是否成立。
6. **主体认证**：人物是否主动自称、复述和背书。
7. **构成性认证**：主体当下认证是否就是该即时、自愿壳成立的必要条件。
8. **证据性认证**：主体认证是否只为已由事实、制度或记录成立的壳提供证据。

严格`x并z`整体下降至少要证明第1至第3项同步下降。只改变第4至第8项，不能直接判稳定公共壳被克。

### 成立阶段与显影条件

- 阶段A：稳定身份壳已经由事实、制度或持续自我呈现中的至少一种路径建立。
- 阶段B：主体只撤回第一人称认证，不作公开否认，也不改变履行和外部结构。
- 阶段C：第三方不知道主体内部态度，数据库、传播、授权和规则全部冻结。
- 阶段D：分别测量事实索引、制度资格、静态调用、持续表演和当次互动令牌。
- 阶段E：主体自由重新认证，观察哪些变量无需重演、重签、重授权或重登记即可恢复。
- 显影条件：无公告、无撤权、无辞职、无除名、无停止履行、无时间遗忘、无第三方规则更新。

### T / M / E

- T：身份壳可以覆盖人物大量社会关系，但高T不意味着认证撤回产生高作用量。
- M：人物公开说“我不是这个身份”会极强显影内部脱钩，但公开传播已经不是纯`nx`。
- E：只有稳定公共壳的事实索引、制度资格和静态调用因纯认证撤回而下降，才构成高E克位。

## 4. 候选机制

### A｜认证撤回使稳定公共壳整体下降

```text
主体停止第一人称认证
→ 公共壳失去持续的一手确认
→ 事实归因、制度资格与静态调用下降
→ x并z整体覆盖下降
```

理论后果：若成立，只能先锁定“完全依赖持续主体认证、无独立事实和制度维护源的稳定自愿壳”这一窄机制。当前候选由约83%降为约81%。

### B｜构成性认证停摆

```text
某个即时代表壳必须由主体当下自称、回应、签署或表演才成立
→ 主体拒绝完成构成动作
→ 当次互动令牌或该阶段持续表演壳不成立
```

理论后果：约99%成立，但改变的是即时壳和互动接口，不是历史事实、制度资格与稳定公共壳整体覆盖。

### C｜证据性认证撤回

```text
既存壳已由事实、制度、记录或他者规则成立
→ 主体停止为其提供第一人称证词
→ 一手证据减少
→ 稳定壳仍由独立来源维持
```

理论后果：认证是证据通道，不是构成条件；其撤回不足以克制稳定`x并z`。

### D｜内部脱钩与未来生产减少

```text
主体不再认领旧壳
→ 新场合不再生产同类身份信号
→ 新壳生成减少
→ 下一周期续期概率下降
```

理论后果：改变的是未来生产和时间延续，不是当前稳定壳整体下降。

### 5.3 发言人严格控制候选

- 人物与阶段：某机构发言人的职位、授权、名册、历史发言和第三方知识全部保持，只拒绝某次以该职位回应。

- 判断：支持构成性认证与稳定壳分账，不支持整条关系锁定。

## 8. 拿掉测试

1. 冻结登记、合同、职位、权限和数据库。
2. 冻结履行、曝光、公告、传播和第三方规则。
3. 让第三方完全不知道主体内部态度。
4. 分开测量八项目标变量。
5. 区分沉默不认领、私下否认、公开否认、撤权和停止履行。
6. 先判断主体认证在该壳中属于构成条件还是证据通道。
7. 将调用改为无需主体配合，检查稳定壳是否继续运行。
8. 让主体自由重新认证，检查是否无需重演、重签、重授权或重登记即可恢复。
9. 对比旧作品、亲属事实、法律资格、正式职位、自愿即时代表和现场发言身份。
10. 排除失联、停工、宣传停止、遗忘和时间衰减。
11. 区分当前旧壳下降、新壳不生成、下一周期不续期和当次令牌失败。

## 10. 动态链后果

```text
公共壳仍在代表我
→ 我停止复述、背书和第一人称认证
→ 主体与壳的内部距离扩大
→ 若认证是构成条件，即时代表壳或互动令牌停摆
→ 若认证只是证据通道，事实与制度壳继续运行
→ 新壳生成和续期概率下降
→ 只有稳定壳整体覆盖纯随认证变化
→ 才接近x并z被克
```

本轮只改变主体认证、即时接口、未来生产和主体与壳的内部距离，不机械生成辞职、除名、法律失效、历史归因消失或社会遗忘。

## 11. 三元与十元并行核验

三元观察：

- 人物是否继续承担角色；
- 他者是否继续通过记录和制度指认；
- 哪类身份调用需要人物当下完成；
- 重新认证后哪些接口可以直接恢复。

十元区分：

- `nx`：主体不占身份方向与认证位置；
- `x并z`：公共壳的识别、归因、代表和调用界面；
- `xn`：名册、数据库、程序和历史记录；
- `zx`：公开否认、除名和裁决；
- `x`：职位、授权和现实接口。

两套系统并行，没有写成父子派生。
