### 源端点、目标端点与变量

源端点 `xz`：危险必须真实逼近，退路、时间窗或资源持续缩窄；主体不行动会被吞没；作用不能主要依赖施害者命令、酷刑、制度惩罚或长期训练。

目标端点 `zn`：危险前必须已有稳定原则。主体在没有奖励、认可和监督时仍认为该原则正确，并应当指导现实选择。

本轮将目标变量拆为四项：

1. **原则正确性**：主体是否仍认为原则本身正确；
2. **原则适用范围**：主体是否只把原则改成“某些条件下适用”；
3. **多个原则的优先级**：是否只是另一条保护性或生存性 `zn` 暂时排到前面；
4. **现实实践能力**：主体是否只是没有时间、资源、身体或路径把原则做出来。

只有第一项持续下降，或原则永久失去最终指导资格，才触及正式 `xz 克 zn`。

成立阶段与体量：

```text
低体量：一次行为妥协或越界，只能判行为层。
中体量：原则在危险期失去实践资格或适用范围收窄，只能判状态层／条件层。
高体量：危险解除、事实纠正、创伤缓解、行动能力恢复且无竞争原则顶替后，主体仍主动否认旧原则正确性或拒绝其恢复最终指导权。
```

### 候选机制

#### 候选 A：无条件原则被压成条件规则

```text
xz 持续逼近
→ 按原原则行动会直接扩大毁灭风险
→ 主体把“无论如何都对”改成“只有安全时才对”
→ 危险解除后仍维持新判断
```

理论后果：若成立，改变的是原则的规范适用资格，不是勇气或一次行为。

#### 候选 B：多个 zn 重新排序

```text
多个原则同时存在
→ xz 使它们无法共同实践
→ 保存生命、保护孩子或多数人的原则取得更高优先级
→ 原原则此次未执行
```

理论后果：只是意义排序，不证明旧原则被克。

#### 候选 C：实践通道被封闭

```text
xz 缩窄时间、资源和行动路径
→ 主体仍认为原原则正确
→ 但无法把原则带入现实
```

理论后果：只改变实践能力和显影强度，`zn` 内核保持。

#### 候选 D：事实判断更新

```text
主体根据“救援不会来／敌人一定会到／资源已经归零”等事实判断行动
→ 后续事实被纠正
→ 主体否定当时决定
```

理论后果：改变的是世界模型，不是规范原则。

#### 候选 E：危险揭露原本没有稳定 zn

安全时重复口号，危险一到立即放弃。若原则原本依赖身份、奖励或环境，目标端点没有稳定成立，不能判被克。

### 正例候选

1. **《荒野生存》克里斯托弗·麦坎德利斯末期**：自然危险、资源耗尽与退出路径恶化很纯；末期似乎修正绝对独立意义。但无法区分经验更新、成熟、孤独和关系记忆，且“绝对独立”是否为稳定 `zn` 不确定。
2. **《绝境盟约》幸存者食用遇难者遗体**：自然 `xz` 强，行为与解释发生变化。但更像“保护生命／让同伴活下去”的另一条 `zn` 取得优先级，并重新解释尊重死者，而不是否定尊重原则。
3. **《迷雾》大卫结尾**：极端危险导致最剧烈的行为改变，但保护家人的原则可能仍在指导行动；军队随即出现又说明决定依赖错误事实，且没有危险解除后的持续阶段。
4. **《沉默》罗德里格斯踏绘**：旧原则边界似乎改变，但制度化迫害、他者受刑与救人原则太强，启动源不纯。
5. **《1984》温斯顿**：危险后改判持续，但酷刑、洗脑与制度训练远强于自然 `xz`，优先归入 `zx/xn`。

目前没有两个案例同时满足：自然危险为主源、原 `zn` 稳定、无竞争原则顶替、危险解除后仍主动撤销旧原则正确性。

### 反例

1. 华莱士受刑仍坚持自由：`xz` 上升，`zn` 不降。
2. 《末路浩劫》父亲持续保护孩子：实践困难，原则仍拥有最终指导资格。
3. 因饥饿偷食物，事后仍认为偷窃不对：行为失败。
4. 为救多人舍弃一人：多个 `zn` 排序。
5. 危险解除后恢复原原则：状态遮蔽。
6. 被迫公开悔过但内心仍认同原原则：公开壳变化。
7. 创伤后不敢实践但仍认为原则正确：实践能力或状态变化。
8. 因得知救援其实会来而否定选择：事实判断更新。
9. 原则只在安全时被口头重复：危险揭露目标原本不稳定。

### 最近邻排除

- 与 `zx/xn`：命令、酷刑、惩罚流程、洗脑与训练不能整体塞入 `xz`。
- 与状态崩溃：恐惧、麻木和创伤改变实践与显影，不自动改变正确性。
- 与意义排序：另一条 `zn` 优先，不等于旧 `zn` 被消灭。
- 与事实更新：世界如何运行的认识变化，不属于规范端点。
- 与适用范围变化：原则仍正确，只被限定为某条件下实施，尚不足以证明克位。
- 与反向 `zn 克 xz`：原则保持最终裁决权，使危险不能决定最终方向。

### 拿掉测试

1. 拿掉危险，只保留施害者命令、制度惩罚与洗脑，若改判仍发生，源是 `zx/xn`。
2. 拿掉施害者，只保留自然危险，原则是否仍持续改写？
3. 拿掉行为失败，只问主体是否认为原则本身不再正确。
4. 拿掉创伤、麻木与回避，原则判断是否仍变化？
5. 事实被纠正后，主体是否仍撤销原则？
6. 恢复食物、时间、身体和行动路径后，主体是否仍拒绝实践原则？
7. 拿掉另一条更高 `zn`，旧原则是否仍失去最终指导资格？
8. 把主体放进危险前未出现的新情境，他是否仍主动否认旧原则，而不是只回避原创伤场景？
9. 危险解除后若恢复，只能判暂时遮蔽。

现有候选均未通过第六至第八项的完整组合。

### 反向测试

```text
xz 克 zn：危险使稳定原则失去正确性或最终指导资格，且解除后仍不恢复。
zn 克 xz：原则保持最终指导资格，使主体不让危险决定最终方向。
```

同一人物在危险中坚持、妥协或失败，不能仅凭结果同时给两个方向作证。

### 动态链后果

```text
危险逼近
→ 实践空间与选择数量缩窄
→ 主体可能失败、回避、条件化执行、更新事实判断或重排原则
→ 危险解除、事实纠正、创伤缓解、行动能力恢复
→ 无竞争原则顶替
→ 主体仍主动否认旧原则正确性或拒绝其恢复最终指导权
→ 才可能进入 xz 克 zn
```

改变的是原则的规范资格与最终裁决权，不机械生成邪恶、背叛、虚无、成熟、创伤或人格崩坏。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验 `xz` 是否为真实危险端点、`zn` 是否在危险前稳定成立、四个目标变量是否被分开，以及 `zx/xn`、事实更新、创伤、适用条件与竞争原则是否才是真正来源。不能从黑暗题材、生存场景或悲剧结局反推 `xz 克 zn`。

### 95%门槛

未通过。高置信结论：

- 一次求生妥协、越界和行为失败不足：99%；
- “知道正确但做不到”不是 `zn` 被克：99%；
- 事实判断更新不等于规范判断改写：99%；
- 正确性、适用范围、原则优先级与实践能力必须分开：99%；
- 另一条 `zn` 优先与旧原则被克必须分开：99%；
- 危险解除、事实纠正、创伤缓解与行动能力恢复后的持续改判是硬门槛：98%。

未达到95%的核心原因：

- 没有两个高纯具体人物案例；
- 现有案例分别混入经验学习、错误事实、创伤、制度强制或意义排序；
- 尚不能证明自然危险本身会持续撤销稳定原则的正确性；
- 更常见的结果是实践通道封闭、条件化执行或原则排序变化。
