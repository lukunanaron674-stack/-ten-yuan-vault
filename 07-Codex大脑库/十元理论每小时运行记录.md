### 对象分层

- 稳定本体：`z` 是长期依赖重要认可位置确认自身；`nz` 是长期保留关系余温和可回返位置。一次认可或一次不舍不能反推人物本体。
- 当前状态：主体此刻被重要他者确认；随后出现不愿结束、延迟离开或主动保留联系。最可能成立于关系层或状态层。
- 行为功能：`z` 显影为呈现、回应、署名与明确确认；`nz` 显影为等待、回返、延长共同时间与保留再次相见接口。
- 光影：聚光、掌声、谢幕、暖光、旧物和空位只作显影，不能替代端点。
- 场景：演出、答辩、毕业、撤展和告别只是题材候选。
- 时间关系：认可先发生；回返接口、延长共同时间和不愿结束随后出现。先后仍不足。
- 关系位置：认可者与被认可者，或被共同见证的小组；必须确认认可位置是否后来变成可停靠关系对象。
- 显影：观察奖励停止后是否仍主动见面、共同创作、回到原位置或拒绝让关系自然结束。
- 动态链：从“我被你确认”走向“我不愿失去这个共同位置”。不机械生成友情、归属或永久留任。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `z`：认可主体、认可对象、认可内容与该位置的重要性明确；确认真实落到主体，而不是普通掌声、结果或曝光。
- 目标端点 `nz`：关系或共同阶段获得时间厚度；主体主动保留等待、回返、再次相见或继续共同创作的位置；不愿其自然结束。
- 被改变变量：认可者是否从评价位置变成可回返对象；共同阶段结束抗拒度；奖励停止后的联系持续度；具体回返接口是否新增；拿掉认可后该接口是否消失。
- 成立阶段：认可前关系尚可自然结束 → 重要确认发生 → 奖励与任务结束 → 双方仍主动延长共同时间或建立新回返接口。
- 体量：低体量是短暂兴奋与不舍，不足；中体量是主动安排再次见面或共同创作；高体量是改变下一步路线以保留关系位置。
- 显影条件：认可前无稳定 `nz/n/xn`；认可后新增具体而非象征性的回返接口；拿掉奖励、身份和共同任务后仍成立。

### 候选机制

- A 认可者转化为可停靠关系：重要认可使对方从评判者变成“我希望继续被其看见、也愿意再次回到其面前”的关系对象。理论后果：目标变量是关系接口新增，不是自信上升。
- B 共同被见证使阶段获得唯一性：共同成果被重要主体确认，使“这段经历属于我们”被明确，成员主动保留共同阶段。理论后果：可能只命名并强化既有 `nz`，必须排除长期共事 `xn` 和承载 `n`。
- C 既有余温被认可命名：认可只为原有友情或共同时间盖章，没有新增回返接口。此时不构成生位，只是 `nz` 显影或被共同见证。
- D 完成、获奖、录取或签约后自然留恋：没有认可关系端点，或目标来自奖励、身份、新组织与转场，排除。

### 正例候选

1. 固定剧团最终谢幕：重要导演与观众确认共同演出，演员延长告别并希望保留剧团位置。污染来自多年排练形成的强 `xn` 和既有 `nz`；拿掉认可仍可能同样不舍。
2. 毕业展小组撤展：导师和观众确认共同作品后，成员提出继续共同创作。结构接近候选 B，但缺少可核验人物文本，且课程共同任务和长期协作是强第三因素。
3. 《爆裂鼓手》安德鲁与弗莱彻结尾对视：认可主体与认可内容极清楚，但影片没有证明奖励停止后的持续停靠、再次相见或不愿关系结束，因此目标端点不足。

### 反例

1. 考生收到录取后进入学校：新结构、身份或 `n/xn` 变化，不是旧关系停靠。
2. 运动员夺冠后立刻追下一目标：`z` 有，`nz` 无。
3. 获奖者舍不得奖杯：可能是 `x` 或记忆载体，不是关系回返。
4. 演员原本就舍不得剧团，失败也不愿离开：`nz` 先于 `z`。
5. 掌声后短暂兴奋和感谢：当前状态，没有时间厚度。
6. 导师长期照护学生后给予认可：留恋可能主要来自 `n` 和既有关系。
7. 公司表彰后员工因待遇和身份留下：奖励、`x并z/x/n` 污染。

### 最近邻排除

- 与 `xn 补 z`：后者让认可具有跨时间证据和阶段收束；本轮候选改变认可后是否新增关系停靠。
- 与 `n`：被长期接住会自然形成可返回位置；若留恋来自承载，不归给 z。
- 与 `xz 补 nz`：失去风险提高停靠选择重量；z 必须由“被确认”本身新增回返接口。
- 与反向 `nz 生 z`：既有不舍推动最后一次演出、作品或表达以被看见，方向相反。
- 与 `x并z 生 z`：公开壳使认可正确识别，不解释认可后为何不愿结束。

### 拿掉测试

1. 拿掉公开认可，人物是否仍同样舍不得？若是，不依赖 z。
2. 拿掉既有友情、共同空间、长期共事与照护后，认可是否仍新增持续回返？当前无高纯案例通过。
3. 拿掉奖品、录取、签约、新身份和待遇后，停靠是否仍增强？
4. 拿掉认可主体，只保留目标完成，若留恋仍出现，只是完成后状态。
5. 拿掉具体回返行为，只剩兴奋、感谢、释放与谢幕，则 nz 目标端点不存在。
6. 恢复“关系自然结束且无再次联系”后，若理论判断不变，说明只是 z 完成。

### 反向测试

```text
z 生 nz 候选：认可先发生 → 评价位置转成可回返关系 → 主体不愿该共同位置结束。
nz 生 z 候选：既有不舍先成立 → 主体通过最后一次作品、演出或表达追求被看见。
```

最终演出和临别表达更容易证明反向；不能因认可与留恋同框就倒写方向。

### 动态链后果

```text
你确认了我的存在、能力或我们共同完成的阶段
→ 这次确认不再只是一次评价
→ 它是否生成了可以再次回到彼此面前的具体接口
→ 奖励和任务结束后，我们仍主动延长共同时间
```

改变的是认可位置能否沉淀为关系停靠，而不是机械生成友情、依恋、归属、成功或永久合作。
