## 源端点、目标端点、变量、阶段与体量

源端点 `z`：重要认可主体只确认主体自己的判断、能力或选择资格；不得同时提供路线、职位、许可、资源、长期教学、照护或后果兜底。

目标端点 `nx`：主体此前已有真实可行路线、否决权与承担能力，却因认为自己的判断不合法或不可靠而沿外部路线推进。

被改变变量：主体对自身判断资格的承认度、外部路线的唯一合法性、替代路线提出率、否决权使用、承担现实损失的持续度。

成立阶段：优先落在具体选择或关系阶段；当前没有证据支持稳定本体层。

体量：低体量为一次具体选择；中体量为一段关系中跨阶段持续自主；高体量稳定人格改写未证实。

显影条件：认可者停止支持、撤回认可甚至反对后，主体仍维持自己的路线。

## 候选机制与理论后果

### 候选 A：判断资格确认

```text
主体有可行路线
→ 但认为自己的判断没有资格成立
→ 重要认可者确认“你的判断可以成立”
→ 外部路线不再垄断合法性
→ 主体提出、否决并承担自己的路线
```

理论后果：只可能克制“判断资格自我取消型 nx”，不能泛化到结构性依赖。

### 候选 B：能力资格确认

```text
主体知道自己想走哪条路
→ 但不相信自己能承担后果
→ 认可者确认其能力
→ 主体开始使用否决权
```

理论后果：若主体只是更努力执行旧安排，只有 `z` 上升，`nx` 未下降。

### 竞争解释 C：撤回限制而非认可作用

认可者若同时是原方向提供者、教师、许可者、资源门控者或风险兜底者，其支持可能通过撤回限制、提供能力、开放权限或降低风险改变方向。此时直接作用源更接近 `x/xn/zx/n`，不能归给纯 `z`。

### 竞争解释 D：换一个跟随对象

主体不再听原安排者，却改为只听认可者。方向来源换人，但最终方向权仍在他者手中，`nx` 没有下降。

## 正例候选

1. **《死亡诗社》托德与基廷，课堂即兴诗阶段**：基廷确认托德拥有自己的诗性声音，托德从标准答案与沉默位置转为表达自身语言。污染：基廷同时提供教学结构、强引导、课堂权能与情感承载；影片缺少基廷后来反对时托德仍坚持独立路线的验证。
2. **《跳出我天地》比利与父亲，父亲支持舞蹈之后**：父亲确认比利的能力与选择，矿工家庭路线不再拥有唯一现实资格。污染：比利在认可前已经有强自主路线；父亲同时提供许可、资源、家庭权力放行和风险兜底。
3. **研究生独立定题结构例**：学生已有可行选题，却认为自己的判断没有资格；一名不掌握经费、许可与题目分配的外部学者确认其判断能力，后来撤回支持时学生仍拒绝旧题并承担失败。结构可通过测试，但缺可核验人物文本。

## 反例

1. 老板表扬员工后，员工更认真执行老板路线：`z` 上升，`nx` 未降。
2. 父母说“相信你”，却继续控制学校、资金与许可：认可没有改变方向结构。
3. 导师给出一条新方案，学生改听导师：只是换外部路线。
4. 上级授予预算、职位或签字权：主要是 `x/zx` 权限转移。
5. 治疗、训练与长期照护后主体更独立：可能由 `xn/n` 提升能力与安全感。
6. 人物本来就坚持自己的路线，认可只让其公开：既有自主显影，不是 `nx` 被克。
7. 认可者一反对，主体立刻撤回自己的选择：继续依赖认可。

## 最近邻排除

- `x/zx`：职位、资源、许可、公开放权直接改变现实决定资格。
- `xn/n`：教学、训练与照护提升能力、安全感或执行条件。
- `zn`：主体因“这件事本身正确”而拒绝安排，启动源是内部意义。
- 自信上升：更敢表达不等于提出替代路线、使用否决并承担后果。
- `nx 克 z`：改变认可能否发生；本轮改变方向合法性。

## 拿掉测试

1. 拿掉认可，只保留教学、资源、许可与放权，主体仍独立，则不依赖 `z`。
2. 拿掉教学、许可、资源、职位和后果兜底，只保留资格确认，主体仍取回方向，才支持直接作用。
3. 认可者与原方向提供者分离后，方向变化是否仍发生？
4. 同一认可者若不改变权限、路线、资源与风险，确认本身是否足够？
5. 拿掉主体原有可行路线，认可后仍无替代方向，则目标端点不足。
6. 拿掉情绪振奋，只观察替代路线、否决与现实代价。
7. 认可停止、撤回甚至反对后，主体是否仍维持路线？
8. 若主体随认可者改变方向，只能判换跟随对象。

两个具体作品候选均未通过第 2、3、7 项组合。

## 反向测试

```text
z 克 nx：判断资格被确认 → 认可者撤回或反对后，主体仍持续取回方向。
nx 克 z：主体不表达、不呈现、不进入认可接口 → 重要确认无法发生。
```

正向改变外部路线的唯一合法性；反向改变认可能否发生，不能互相代证。

## 动态链后果

```text
我不是没有路线
→ 我认为自己的判断没有资格成立
→ 重要的人确认我的判断可以成立
→ 我提出另一条路线并承担代价
→ 他后来撤回认可甚至反对
→ 我仍维持自己的路线
→ 方向权才真正回到我这里
```

改变的是主体是否承认自己拥有决定资格，以及外部路线是否仍垄断合法性。不机械生成成熟、勇气、成功或稳定独立人格。
