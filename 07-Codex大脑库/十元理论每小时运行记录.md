### 对象分层

- 稳定本体：`nx` 是长期不占方向决定位置；`x` 是长期掌握对象、资源、权限或关系边界。一次让人代办与一次接管不能反推稳定本体。
- 当前状态：甲在某段关系中持续不决定；乙在同一阶段逐渐成为默认接口，最可能先落在关系层或状态层。
- 行为功能：甲不提方案、不使用否决、默认乙安排属于 `nx`；乙决定无需重新确认、可排除替代接口、第三方只找乙才触及 `x`。
- 光影：主位、钥匙、账本、中心构图与侧位只作显影。
- 场景：家庭财务、创作团队、管家关系和代理关系不能替代端点。
- 时间关系：甲持续让位先发生，乙事实掌握随后扩大；先后仍不足以证明生成。
- 关系位置：源主体甲与目标主体乙必须分开；同主体“越顺从越掌握自己”不成立。
- 显影：乙是否新增最终否决、排他使用、对外代表或调配接口；甲取回方向是否开始产生额外成本。
- 动态链：临时代办是否逐渐成为默认掌握，不机械生成权力人格、占有欲或法定权限。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `nx`：甲原本拥有真实可拒绝、可另选、可取回的方向位置，却跨轮次不提出自己的安排、不使用否决并默认乙决定。
- 目标端点 `x`：乙此前没有稳定掌握边界，随后新增事实最终决定、排他使用、对外代表、资源调配或否决接口。
- 被改变变量：乙决定的默认有效性、第三方接口集中度、甲取回方向的协商成本、乙的否决和排他强度、临时代办向事实掌握转化的稳定度。
- 成立阶段：甲可自主决定 → 跨轮次持续让位 → 乙的决定反复落地 → 第三方开始只认乙或乙主动排除替代接口 → 甲取回决定需额外争取 → `x` 候选上升。
- 体量：低体量是单一事务的默认接口；中体量是一段关系内多项事务被乙掌握；高体量是稳定关系边界与对外代表权形成。当前证据最多支持低至中体量候选。
- 显影条件：拿掉正式授权、职位、账户、钥匙、合同、资源优势、能力差与乙主动夺权后，甲持续让位仍是乙事实掌握上升的必要条件。

### 候选机制

- A 默认决定累积：甲每轮不使用方向权，乙的决定持续被执行且不被撤回，第三方逐渐把乙视为最终接口。理论后果：`nx` 只能提供持续空位；事实掌握还需要接口被重复确认。
- B 接口集中：甲长期不直接面对成员、资源或外部关系，信息、口径和调配入口集中到乙，其他人只能通过乙完成互动。理论后果：`x` 表现为事实接口垄断，但必须排除职位与信息截断。
- C 乙主动接管：乙利用甲让位主动排除替代方案、控制信息或要求所有决定经自己确认。理论后果：真实启动源可能是乙的 `x/zx/xn`，甲的 `nx` 只是允许条件或结果。
- D 正式授权：甲明确授予乙账户、职位、签字或合同权限。理论后果：改变的是法定或组织权限，不证明 `nx` 独立生 `x`。

### 正例候选

1. 家庭财务代管：甲有独立决定能力，却多年默认伴侣乙决定账单、账户安排和大额消费；家庭成员逐渐只找乙，甲改变安排时反而需要乙同意。限制：常混入账户密码、收入来源、正式授权与乙既有管理能力。
2. 创作团队对外口径：主创甲拥有最终表达权，却长期默认制片乙决定发布时间、合作对象和公开说法；合作方逐渐只认乙为最终接口。限制：职位、合同、信息集中与主动管理均是强第三因素。
3. 《魅影缝匠》雷诺兹与西里尔：雷诺兹长期依赖西里尔处理客户、日程与生活边界，西里尔形成强事实掌握。限制：西里尔原本已有稳定管理位置和 `x/xn`，无法证明目标端点由雷诺兹的 `nx` 新生成。

### 反例

1. 老板正式授权经理全权负责项目：权限授予，不是 `nx` 生 `x`。
2. 强势伴侣以威胁、监控和资源控制接管生活：优先检查 `x/zx`。
3. 一次请同事代班：临时委托，没有跨轮次事实掌握。
4. 家长替年幼孩子决定：年龄与监护位置已不对等。
5. 代理人本来持有钥匙、账户或签字权：`x` 目标端点原已存在。
6. 因专业能力不足听从专家：现实能力依赖，不是自愿空出方向。
7. 乙承担更多劳动却不能否决、代表或排除其他接口：只是多做事，不是掌握。
8. 甲始终能无成本取回决定，乙无法阻止：没有稳定事实边界。

### 最近邻排除

- 与 `x 生 nx`：乙先有掌握边界并压缩甲方向空间；本轮候选要求甲先持续让位，乙随后新增事实掌握。
- 与 `z 克 nx`：强主体主动表达、决定和占位压退他者不属于现行 `z`，更接近 `x/zx`；本轮要求甲的持续空位是必要条件。
- 与正式授权：授权改变明确权限；本轮若成立，改变的是未明说却被反复执行和第三方承认的事实边界。
- 与 `xn`：乙组织更多流程不等于乙拥有最终否决和排他接口。

### 拿掉测试

1. 拿掉甲的持续让位，乙仍凭职位、资源或强制掌握，则不依赖本关系。
2. 拿掉乙主动接管与第三方接口固化，只剩甲不决定，若 `x` 不出现，说明 `nx` 只是允许条件。
3. 拿掉账户、合同、钥匙和正式授权后，控制若消失，启动源是权限配置。
4. 拿掉周围人的默认承认，只剩乙多干活，目标端点不足。
5. 甲若始终能无成本取回决定，乙没有真实否决，不构成稳定 `x`。
6. 拿掉乙既有管理能力后，若掌握无法形成，不能证明 `nx` 独立生成。

三个候选均未通过全部测试。

### 反向测试

```text
nx 生 x 候选：甲持续让位 → 乙的默认决定被反复承认 → 乙事实掌握扩大。
x 生 nx：乙先拥有掌握边界 → 甲的可选方向被压缩 → 甲沿乙方向推进。
```

两方向可能形成反馈，但不能因最终都表现为“乙决定、甲跟随”就互相代证。

### 动态链后果

```text
这次先按你的办法
→ 以后也默认你决定
→ 别人开始只找你
→ 你的决定不再需要重新确认
→ 我想取回方向时必须额外协商
→ 临时代办才可能转成事实掌握
```

改变的是谁的决定默认有效、谁被视为最终接口，以及取回方向的成本。它不机械生成占有欲、管理能力、权力人格或法定权限。

### 三元与十元并行

三元继续核验作品整体精神运动；十元本轮只核验甲的方向让位、乙的掌握边界、第三方接口与取回成本。不能由因果主题、人物强弱、家庭题材或结局倒推 `nx 生 x`，也不把 `nx` 写成 `x` 的父级。

### 95%门槛

高置信修正：

- 同主体“越顺从越生成自己的 x”不成立：99%。
- 甲不决定不等于乙已经掌握：99%。
- `nx` 最多提供方向空位或允许条件，乙接管或第三方接口固化至少需要一项：97%。
- 目标变量必须落到默认有效、否决、排他、代表接口与取回成本：98%。
- 正式授权、职位、资源、账户、能力差与主动夺权必须排除：98%。

未过95%的核心：

- 缺少两个高纯具体人物案例；
- 不能确定“持续空位 + 第三方固化”是否足以构成直接生位，还是应写成 `nx` 提供条件、`x/zx/xn` 完成接管；
- 现有候选无法同时拿掉权限、资源、职位、既有管理能力与乙主动作用。

因此：几何位置保留；旧欲望口径继续撤回；“默认决定累积”与“接口集中”候选保留；正式机制未锁定；沿用 `UQ-20260718-003`，不新增问题。
