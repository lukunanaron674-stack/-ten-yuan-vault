## 3. 源端、目标端、变量与成立条件

### 源端`nx`

- 人物与阶段：人物已被职位、亲属关系、旧作品署名、组织成员身份、艺名或公共称谓稳定指认；其后持续不自称、不背书、不主动以该身份发言，也拒绝为当前调用提供现场认证。
- 具体名词：身份方向不认领、主体认证撤回、第一人称代表接口停止、壳内被动存在。
- 排除：公开辞职、公开否认、撤回授权、停止履行、失联、改名、除名、数据库更新和法律资格改变。
- 体量：低体量只使一次回应停摆；中体量降低新壳生成与续期；高体量候选必须使稳定既存壳的历史归因、制度资格和静态调用同步下降。

### 目标端`x并z`

本轮把目标拆成六个变量：

1. **事实索引壳**：旧作品、历史事件、亲属事实和既成记录是否继续正确归因。
2. **制度资格壳**：职位、法律资格、名册、合同身份是否继续有效。
3. **静态第三方调用**：无需主体配合时，他者能否继续检索、分类、引用和指认。
4. **持续表演壳**：身份是否需要主体反复表演、回应或以第一人称持续维持。
5. **单次互动令牌**：本次发言、签署、表演、回应或代表行为是否成功完成。
6. **主体认证**：人物是否主动自称、背书和使用该身份。

严格`x并z`整体下降要求第1至第3项同步下降。只影响第4至第6项，最多说明表演接口停摆、当次令牌未成立或新壳生产减少。

### 成立阶段与显影条件

- 阶段A：既存公共壳已经稳定，历史记录、制度资格和第三方规则均保持。
- 阶段B：主体停止第一人称认证，但没有公开通知或撤权，记录本次互动和后续新壳变化。
- 阶段C：第三方完全不知道主体态度；调用改为无需主体现场配合，检查事实索引壳和静态调用是否仍然运行。
- 阶段D：主体自由恢复自称，但不重签、不重演、不恢复授权，检查整体覆盖能否仅靠认证恢复。
- 显影条件：若只有需要主体现场完成的单次令牌变化，不能把该变化上推为稳定公共壳整体下降。

## 4. 候选机制

### A｜主体认证撤回使稳定公共壳整体下降

```text
主体停止第一人称认证
→ 公共壳失去持续的一手确认
→ 历史归因、制度资格与静态调用置信度下降
→ x并z整体覆盖下降
```

严格候选由约85%降为约83%。如果未来成立，也只能先锁“依赖持续主体认证、没有独立事实或制度维护源的自愿代表壳”，不能覆盖历史作品、亲属事实、法律资格和正式职位。

### B｜持续表演壳与单次互动令牌停摆

```text
某次身份调用必须由主体现场自称、回应、签署或表演
→ 主体拒绝完成
→ 本次代表行为没有成立
→ 当前互动令牌失效
```

这一机制约99%，但它改变的是本次接口运行状态，不是稳定公共壳的历史和制度覆盖。

### C｜内部脱钩与未来生产减少

```text
主体不再认领旧壳
→ 新场合不再主动生产同类身份信号
→ 新壳生成减少
→ 下一周期续期概率下降
```

这改变未来生产和时间延续，不是当前既存壳被克。

### D｜外部结构实际降低覆盖

公开否认、撤权、辞职、停止履行、注销、除名、数据库更新或第三方规则改变，可以真实降低公共壳覆盖。但这些作用源属于`zx / xn / x`等外部结构，不能冒充纯`nx`。

## 5. 正例候选

1. **《黑客帝国》Neo拒绝“Mr. Anderson”的阶段**
   - 源端候选：Neo拒绝系统赋予的第一人称身份方向，不再认领该称谓。
   - 目标观察：Agents仍能通过系统记录和旧壳指认、追踪和调用他。
   - 判断：更接近反证；主体认证下降，没有使事实索引壳和制度调用下降。

2. **《谍影重重》Jason Bourne拒绝旧特工身份的阶段**
   - 源端候选：Bourne不再把CIA特工身份作为自我方向。
   - 目标观察：CIA档案、追踪、任务归因和第三方识别继续运行。
   - 判断：历史和制度壳独立于主体认领维持，不支持纯克制。

3. **《楚门的世界》Truman离开节目世界的结尾阶段**
   - 源端候选：Truman拒绝继续表演电视人物壳。
   - 目标候选：直播中的互动壳和节目运行停止。
   - 污染：物理离场、公开事件、节目终止、主要履行停止和制作结构崩解。
   - 判断：证明表演壳需要持续履行，不证明纯认证撤回克制整体公共壳。

4. **严格控制候选：现场发言人与稳定职位壳**
   - 发言人的职位、名册、授权、历史发言和第三方知识全部保持，只拒绝在某场合自称并发言。
   - 当次发言令牌不成立，但职位壳、历史归因和静态调用继续存在。
   - 只有这些稳定壳也在第三方不知情时下降，并仅靠下一次自称恢复，才接近纯例。

当前缺两组可核验纯例。

## 6. 反例

1. 辞职后不再被称为经理：职位和制度已经变化。
2. 组织公开除名成员：公开权能和程序改变壳。
3. 演员停工后角色身份淡化：履行、曝光和时间衰减。
4. 艺术家停用旧艺名，但旧作品仍正确归因：新壳停止生成，旧壳未降。
5. 学生厌恶校服，但系统仍承认学生资格：内部脱钩。
6. 人物拒绝自称父亲，但亲属事实和家庭职责仍被调用：主体认证下降，事实壳仍在。
7. 本人拒绝签字导致一次程序失败：单次互动令牌未完成，不是资格壳消失。
8. 公开声明“不要这样称呼我”后他者停止调用：公开否认和传播成为额外作用源。

## 7. 最近邻排除

- `x 生 x并z`：实际掌握怎样生成公共壳。
- `x并z 克 nz`：公共壳怎样污染关系证据。
- `zx 克 n`：公开裁决、除名和成员边界改变。
- `xn`：名册、数据库、传播、续任和制度维护。
- `x`：职位、合同、授权、署名和现实接口。
- 停止履行：身份内容不再被执行，属于行为与时间路径。
- 新壳停止生成：未来生产变化。
- 单次互动令牌失败：一次调用未完成，不等于稳定壳整体下降。
- 社会遗忘和时间衰减：目标可能下降，但源端不是纯`nx`。

## 8. 拿掉测试

1. 冻结登记、合同、职位、权限和数据库。
2. 冻结履行、曝光、公告、传播和第三方规则。
3. 让第三方完全不知道主体内部态度。
4. 分开测量事实索引壳、制度资格壳、静态调用、持续表演壳、单次互动令牌和主体认证。
5. 区分沉默不认领、私下否认、公开否认、撤权与停止履行。
6. 将调用任务改为无需主体配合，检查稳定壳是否继续运行。
7. 让主体自由重新认证，检查是否无需重演、重签、恢复授权或更新数据库即可恢复。
8. 对比旧作品归因、亲属身份、法律资格、职位、自愿社群身份和一次现场代表行为。
9. 排除停工、失联、遗忘、宣传停止和时间衰减。
10. 区分当前旧壳下降、新壳不生成、下一周期不续期与当次令牌失败。

现有候选均未完整通过稳定壳整体覆盖测试。

## 10. 动态链后果

```text
公共壳仍在代表我
→ 我停止复述、背书和第一人称认证
→ 主体与壳的内部距离扩大
→ 需要我现场完成的互动令牌可能停摆
→ 新壳生成和续期概率下降
→ 事实索引、制度资格和静态调用仍可能保持
→ 只有稳定壳整体覆盖纯随认证变化
→ 才接近x并z被克
```

只允许记录以下感觉走向：

- 主体与身份壳的内部距离扩大；
- 当前互动接口的可用性下降；
- 新壳生产与续期减少；
- 世界仍可能通过既成事实和制度继续指认主体。

不得机械生成辞职、除名、法律失效、历史归因消失、社会遗忘或稳定身份崩解。

## 11. 三元与十元并行核验

三元观察：

- 人物是否继续承担角色；
- 他者是否继续归因、调用和期待履行；
- 哪类调用必须由人物现场完成；
- 人物拒绝后，关系和程序如何继续。

十元区分：

- `nx`：主体不占身份方向和第一人称认证位置；
- `x并z`：公共壳的识别、归因、代表与调用界面；
- `xn`：名册、数据库、传播和续任维护；
- `zx`：公开否认、除名和裁决；
- `x`：职位、授权、合同和现实接口。

两套系统并行，不构成父子派生。
