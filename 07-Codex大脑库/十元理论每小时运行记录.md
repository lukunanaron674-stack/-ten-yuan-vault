### 源端点、目标端点与变量

源端点 `nz`：双方已有真实共同时间、关系余温和可信回返位置；主体不愿共同阶段结束。一次好感、怕孤独、现实依赖或恋爱题材不足。

目标端点 `nx`：主体原本有可行路线、真实否决权和承担后果能力，之后持续不占最终方向位置，沿关系对象给出的路线推进。

被改变变量：最终方向认领、替代路线是否重新开启、否决权是否跨阶段使用、关系危机解除后方向位置是否恢复、跟随是否只在该关系中出现。

成立阶段：优先限定于关系层或状态层。低体量一次让路不足；中体量要求关系稳定后仍跨阶段让出最终方向；高体量尤其要排除稳定 nx 本体、控制、资源、监护和制度身份。

### 候选机制

#### 候选 A：关系余温导致一次方向委托

```text
不愿关系结束
→ 主体主动选择对方路线
→ 共同时间得以继续
```

理论后果：该选择动作本身仍可能是主体在使用自己的最终决定权，只能证明自主选择的方向委托，不足以证明 `nx`。

#### 候选 B：关系稳定后仍持续不恢复最终方向

```text
主体为保留关系而首次让路
→ 关系危机解除，共同位置已经稳定
→ 主体仍不重新开启自己的可行路线
→ 继续把最终方向留给对方
→ 状态层或关系层 nx 候选上升
```

理论后果：本轮首次把“启动时的自主选择”与“启动后的持续方向不占位”分开。只有后者可能触及 `nx`。

#### 候选 C：关系只提高建议权重或同行意愿

主体仍保留否决和替代路线，或双方形成第三条路线。只改变共同时间、建议权重或协商方式，不构成 `nx`。

### 正例候选

1. 山姆与弗罗多，进入魔多至末日火山阶段：关系余温与持续同行明显，但任务 `xn`、守护意义 `zn`、照护 `n` 与危险 `xz` 过强；无法证明关系危机解除后仍持续不恢复方向。
2. 《末路浩劫》男孩与父亲：可信关系降低独自定向需求，但年龄、监护、保护与生存危险使方向位置原本不平等。
3. 旧友重逢结构例：双方各有同等可行路线，一方为避免再次分离选择对方路线。该结构只通过首次让位；若重逢关系已经稳定后主体重新取回路线，则只是一次委托。必须继续观察稳定后是否仍跨阶段不恢复方向。

### 反例

1. 杰西与席琳继续散步，只是延长共同时间和持续协商。
2. 关系深厚但各自坚持职业路线，`nz` 有而 `nx` 无。
3. 接受医生、导师或专业人员安排，方向来自专业与照护。
4. 孩子跟随父母，方向来自年龄与监护。
5. 恋人以分手威胁服从，启动源是 `x/zx/z` 压力。
6. 对方提供住房、钱或安全后留下，混入 `n/x` 与现实依赖。
7. 双方形成第三条路线，属于共同决策。
8. 主体为保留关系主动让路，但关系稳定后立刻恢复自己的路线，只能判自主方向委托。

### 最近邻排除

- 与 `n`：`n` 改变能否被接住；本轮候选改变谁持续拥有最终路线。
- 与 `z 克 nx`：认可使主体重新认领方向；本轮候选是关系余温后持续少占方向。
- 与 `x/zx`：威胁、资源与显权导致服从，不属于 `nz` 作用。
- 与共同协商：协商保留双方方向资格；`nx` 要求一方持续退出最终决定位置。
- 与自主选择：选择对方路线的瞬间仍可能是主体在行使方向权；必须继续观察选择完成后的持续状态。

### 拿掉测试

1. 拿掉 `nz`，若仍因任务、年龄、资源、危险、职位或专业跟随，不成立。
2. 拿掉命令、威胁与对方主动占位后，主体仍让位，才支持候选。
3. 拿掉照护、安全与资源依赖后，让位仍存在，纯度才足够。
4. 拿掉共同时间，只剩一次温柔或好感，源端点消失。
5. 拿掉路线撤回，只剩陪伴、听建议或协商，目标端点消失。
6. 关系危机解除后重新开放自己的路线，说明只是一次委托；仍跨阶段不恢复，才触及 `nx`。
7. 若主体随时可重新开启路线且实际反复使用否决，只能判关系协商。

### 反向测试

```text
nz 生 nx 候选：
关系余温先成立
→ 主体首次自主选择让路
→ 关系稳定后仍持续不恢复最终方向

nx 生 nz：
主体长期沿对方方向共同生活
→ 共同路径积累时间厚度
→ 形成不愿结束与回返余温
```

两方向可能反馈，但不能因为最后同时出现同行与不舍就互相代证。

### 动态链后果

```text
我不愿这段关系结束
→ 我主动选择你的路线
→ 这一步仍可能是我的自主决定
→ 关系已经稳定，我仍不再开启自己的路线
→ 最终方向才从一次委托转成持续不占位
```

改变的是关系中的最终方向认领持续度，而不是陪伴、建议权重、人格软弱、健康关系或共同终局。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验 `nz` 是否已有真实关系余温、`nx` 是否形成跨阶段最终方向不占位，以及任务、危险、照护、资源、年龄与控制是否才是真正作用源。不从命运主题反推因果关系。

### 95%门槛

高置信通过：

- 延长共同时间、听建议与共同协商不等于 `nx`：99%。
- 主体主动选择对方路线时，选择动作本身仍可能是自主方向行为：98%。
- 一次方向委托不等于持续方向不占位：99%。
- 关系危机解除后仍跨阶段不恢复自己的路线，是比“首次让位”更强的目标门槛：97%。
- 年龄、任务、照护、危险、资源、专业、职位与控制必须排除：99%。

未通过正式机制：

- 仍无两个高纯具体人物案例。

- 用户仍有超过5%概率不接受关系层候选。
