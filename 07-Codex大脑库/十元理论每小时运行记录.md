### 对象分层

- 稳定本体：一次让位、代办或接口集中不能反推稳定 `nx` 或稳定 `x`；必须跨轮次且能抵抗原权利主体取回。
- 当前状态：甲暂时不决定、乙暂时代办，只能判状态或代理关系。
- 行为功能：甲不提方案、不使用否决、持续让位；乙调配、否决、排除替代接口、代表对外，并在甲取回时能维持该边界。
- 光影：钥匙、账本、中心座位、他人都看向乙只作显影，不能替代真实否决和排他能力。
- 场景：家庭财务、公司代理、伴侣关系、管家与创作团队只是候选场景。
- 时间关系：甲先持续让位、乙后成为默认接口仍不足；必须再观察甲明确取回后的抵抗结果。
- 关系位置：源主体甲与目标主体乙必须分开；乙原本不得已有稳定掌握边界。
- 显影：乙的决定是否无需重新确认；甲明确取回时乙能否拒绝；第三方是否仍只承认乙；甲是否被排除在直接接口之外。
- 动态链：不是“我不决定，所以你自然拥有”，而是“持续空位经第二入口固化，并在取回冲突中表现为实际掌握”。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `nx`：甲原本拥有真实可行的方向、否决权和取回能力，却跨轮次持续不认领最终决定位置，默认沿乙或既有通道推进。
- 目标端点 `x`：乙此前没有稳定掌握，随后获得对具体对象、资源、时间、权限、关系或对外接口的调配、否决、排他、代表与控制能力。
- 被改变变量：乙决定的默认有效性、乙对替代方案的排除能力、乙的最终否决权、第三方代表接口、甲直接取回的成功率、甲被排除的程度。
- 成立阶段：甲持续让位；乙反复代决；第三方接口集中；甲明确取回；乙或第三方对取回形成真实抵抗；掌握边界跨阶段继续。
- 体量：低体量为一次代办，不足；中体量为多个事项形成默认接口；高体量为乙可抵抗甲取回并维持排他掌握。当前候选未达到高体量纯度。
- 显影条件：至少同时看到乙新增默认有效、实际否决或排他、对外代表，以及甲明确取回时无法立即恢复原边界。

### 候选机制

#### A｜默认决定累积并经第三方固化

```text
甲跨轮次不使用方向权
→ 乙的决定反复落地
→ 第三方逐渐只向乙请求决定
→ 乙成为默认接口
→ 甲明确取回时，第三方仍拒绝绕过乙
→ x 候选上升
```

理论后果：`nx` 提供持续空位；第三方接口固化是必要第二入口。没有取回冲突时，只能证明习惯或代理。

#### B｜接口集中形成事实排他

```text
甲长期不直接面对成员、资源或外部关系
→ 信息、口径和调配入口集中到乙
→ 乙能够排除甲的直接接触或否决替代方案
→ 掌握边界形成
```

理论后果：若排他来自信息截断、制度、账户、职位或乙主动组织，则真正启动源更接近 `x/xn`，不能把全部功劳归给 `nx`。

#### C｜乙主动接管

```text
甲持续让位
→ 乙主动控制信息、排除替代路线、要求所有决定经过自己
→ 乙形成掌握
```

理论后果：甲的 `nx` 只是允许条件；直接生成源是乙的 `x/zx/xn` 行为。

#### D｜默认代理而非掌握

```text
甲长期不决定
→ 乙代办并被大家习惯性寻找
→ 甲一旦明确取回
→ 乙立即归还，第三方重新承认甲
```

理论后果：这里只成立代理、分工或 `xn` 接口，不成立 `x`。

### 正例候选

1. **《穿普拉达的女王》安迪与米兰达，中段工作关系**：安迪持续放弃私人时间、工作节奏和可拒绝边界，米兰达控制范围扩大。限制：米兰达的职位、既有掌握、持续要求与公开压迫都很强；若安迪明确取回边界，米兰达的抵抗主要来自职位和既有 `x/zx`，不能证明 `nx` 独立生成。
2. **《长日将尽》史蒂文斯与达林顿勋爵，管家生涯阶段**：史蒂文斯长期把私人判断和人生方向让给主人，主人意志进入私人生活。限制：阶级、雇佣职责、庄园制度与职位权限是强第三因素；掌握边界不是从无到有。
3. **《魅影缝匠》雷诺兹与西里尔**：雷诺兹依赖西里尔处理客户、日程和生活接口，西里尔具有强事实掌握。限制：西里尔原本已有稳定管理位置、信息接口与 `x/xn`，无法证明目标端点由雷诺兹让位新生成。
4. **成年子女长期由父母代决的结构例**：子女有法律决定权，却长期让父母处理账户、住房、材料和外部沟通；后来机构只认父母。该例只有在子女明确取回时父母仍能拒绝、机构仍拒绝子女直接指令时才触及 `x`。一旦出现这种抵抗，通常又能找到账户权限、材料控制或信息截断等 `x/xn` 第二入口。

### 反例

1. 一次请同事代班：临时委托，随时可撤回。
2. 伴侣长期负责财务，但双方随时可查账、共同否决：分工或 `xn`。
3. 第三方习惯只找乙，但甲一出现便立即承认甲：默认接口，不是掌握。
4. 甲取回时只需多解释或重新通知，没有人能拒绝其决定：存在摩擦成本，不存在 `x` 排他。
5. 老板正式授权经理签字、账户或预算：权限配置直接生成 `x`。
6. 强势伴侣通过威胁、监控或扣留密码接管生活：`x/zx` 主动扩张。
7. 乙承担更多劳动，却不能否决、代表或排除甲：劳动量上升，不是掌握。
8. 甲本来没有法律、能力或职位上的决定资格：没有可让出的方向位置，源端点不成立。

### 最近邻排除

- 与 `x 生 nx`：乙先有掌握，压缩甲可用方向；本轮候选要求甲先持续让位，乙随后新增掌握。
- 与 `xn`：流程负责人、信息协调者和默认联系人可以提高运行效率，但若不能抵抗甲取回，只是组织接口。
- 与 `zx`：公开威胁、惩罚、夺权和压退甲属于主动显权，不是 `nx` 独立生位。
- 与正式授权：授权明确改变权限；本轮候选必须在没有账户、合同、职位和签字权转移时仍形成事实掌握。
- 与普通依赖：更常找乙、觉得乙更会处理，不等于乙拥有排他、否决或最终代表权。

### 拿掉测试

1. 拿掉甲持续让位，乙仍凭职位、产权、账户或强迫掌握，案例不依赖本关系。
2. 拿掉乙主动控制、信息截断和第三方制度化接口，若乙无法抵抗甲取回，`nx` 只提供空位。
3. 拿掉职位、合同、账户、钥匙和正式授权，若掌握消失，启动源是权限配置。
4. 拿掉第三方习惯，只观察乙是否能直接否决甲；若不能，目标端点不足。
5. 让甲明确取回而非仅表达不满：乙若立即归还，不成立；乙若能拒绝，必须继续追查拒绝能力来自何处。
6. 拿掉乙既有管理能力与部分掌握，若无法形成扩张，不能证明 `nx` 凭空生成 `x`。
7. 只存在额外协商成本而无实际拒绝、排除与代表持续，不足以判 `x`。

现有具体作品候选均未同时通过“目标从无到有”和“取回抵抗不依赖既有 x/xn”的测试。

### 反向测试

```text
nx 生 x 候选：
甲持续让位
→ 乙的默认决定被反复承认
→ 乙在甲取回时仍能维持掌握

x 生 nx：
乙先拥有掌握边界
→ 甲的可用方向被压缩
→ 甲更沿乙方向推进
```

两方向可以形成反馈，但最终呈现“乙决定、甲跟随”不能代替阶段证明。

### 动态链后果

```text
这次先按你的办法
→ 以后也默认你决定
→ 别人开始只找你
→ 我以为自己仍能随时取回
→ 当我真正取回时，你或外部接口拒绝了我
→ 临时代管才显出事实掌握
```

改变的是：谁的决定默认有效、谁能排除替代方案、谁能代表关系与资源，以及原权利主体能否真实取回。它不机械生成占有欲、管理能力、法定权限、权力人格或永久控制。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验甲的方向让位、乙的掌握边界、取回冲突和第三方接口，不从因果主题、家庭题材、人物强弱或结局倒推 `nx 生 x`。

### 95%门槛

高置信通过：

- 旧“压抑欲望积累为 x”机制失效：99%。
- 同主体“越顺从越生成自己的 x”不成立：99%。
- 默认代管、习惯性联系人和额外协商成本不足以证明 `x`：99%。
- `x` 目标必须通过取回抵抗、实际否决、排他或代表接口持续显影：98%。
- 若甲明确取回时乙立即归还，只能判代理、分工或 `xn` 接口：99%。
- 满足取回抵抗时，必须继续排除乙既有 `x/xn`、授权、信息控制和主动接管：98%。

未达到95%的核心：缺少两个高纯人物案例；所有能表现稳定抵抗的案例几乎都同时存在账户、职位、合同、信息截断、第三方制度化或乙主动接管。当前更可能是 `nx` 提供允许条件，真正掌握由 `x/xn/zx` 第二入口完成。用户仍有超过5%概率接受关系层“空位吸纳”作为独立生位，因此不擅自撤销几何关系，也不锁定正式机制。

结论：几何位置保留；旧欲望口径继续撤回；空位吸纳与默认授权候选收紧；新增取回抵抗测试；正式机制未锁定；沿用 UQ-20260718-003；核心表、关系词典、专项正本和队列不修改。
