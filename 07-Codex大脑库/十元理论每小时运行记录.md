### 对象分层

- 稳定本体：`zn` 是无奖励与认可仍成立的内部意义；`x` 是对象、资源、地盘、权限或关系归我掌握。一次善举与一次占有不能反推稳定本体。
- 当前状态：此刻确认“这样做是对的”与此刻取得、守住、调配或放松掌握分开。
- 行为功能：坚持、拒绝背弃、按意义选择；占有、调配、划界、保护范围。行为只作端点证据。
- 光影：圣性、精神重量、钥匙、领地、控制台只作显影。
- 场景：信仰场所、工厂、档案、土地和权限系统不能替代端点。
- 时间关系：意义可先出现，掌握也可先存在；互补不要求固定先后。
- 关系位置：守护者、所有者、管理者等称谓不能直接判十元。
- 显影：观察意义指导资格、掌握用途、归属边界、调配能力与否决权。
- 动态链：改变“为何而守”与“守什么、由谁掌握”的本体完整度，不机械生成行动结果。

### 双向端点、变量、阶段、体量与显影

- `zn 补 x`：已有实际掌握，但缺少为何值得这样使用、守护、限制或放弃的内部意义。变量是掌握用途方向、守护与放弃标准、否决权服务的原则。
- `x 补 zn`：已有内部意义，但缺少具体对象、资源、权限和可执行边界。变量是意义的现实落点、可保护与持续投入的对象范围、明确我方边界。
- 成立阶段：资源先存在后按意义重定向；意义先存在后取得具体掌握；或两端同阶段存在且能分别通过拿掉测试。
- 体量：低体量为一次按内部意义使用资源；中体量为长期按意义管理一组资源与权限；高体量为人物存在方式由意义核心与掌握范围共同维持。
- 显影条件：资源用途因 `zn` 改变；意义因 `x` 获得明确对象与边界；主体不是为奖励、名声或服从规则而行动；掌握包含实际调配、保护或否决能力。

### 候选机制

- A 意义为掌握定向：`x` 已成立，`zn` 决定这些掌握应当服务什么。
- B 掌握为意义落地：`zn` 已成立，`x` 提供可控制对象、资源、地盘与权限。
- C 信念自动制造资源：排除；把补位误写成生位。
- D 拥有资源自动产生意义：排除；`x` 不能替代无奖励仍成立的 `zn`。
- 统一机制：`zn` 给 `x` 以内部意义方向；`x` 给 `zn` 以具体对象、资源与现实掌握落点。互补但不互相生成。

### 正例

1. 《辛德勒的名单》辛德勒中后期工厂保护阶段：救人意义改变工厂、资金、名单、雇佣权和交易资源的用途；掌握边界使救人意义形成受保护名单与现实庇护。
2. 《V字仇杀队》V：自由与反抗意义通过影子画廊、档案、广播入口、武器和行动资源获得落点。
3. 家族档案守护者：保存被迫害者证词的意义，与原件、储存空间、访问权限和备份密钥的实际掌握互补。

### 反例

1. 有信仰所以募款成功：主要依赖号召、关系与组织，不是 `zn` 自动补出 `x`。
2. 富豪捐款换名声：有 `x`，但动机依赖 `z/x并z`，不能证明 `zn`。
3. 只有自由信念但无任何可掌握对象与权限：只有 `zn`，互补未成立。
4. 地主留土地给后代：只有归属边界和继承安排，未证明内部意义。
5. 政府按预算和流程保护纪念馆：优先检查 `xn`。
6. “传教士靠近战乱深渊证明信仰”：撤回；危险、深渊与战乱是 `xz` 场景，不是 `x`。

### 最近邻

- 与 `zn 生 n`：后者候选改变承载、接收与抗崩能力；本关系改变已有掌握的用途与意义落点。
- 与 `zn 生 zx`：后者候选要求意义推动公开权能进入现实；本关系不要求公开显权。
- 与 `x 生 x并z`：后者形成公开壳；本关系为意义提供现实掌握落点。
- 与 `zn 克 xn`：后者改变规则结构的指导资格；本关系不要求压倒规则。

### 拿掉测试

1. 拿掉 `zn` 后，`x` 仍存在但用途失去方向，支持 `zn 补 x`。
2. 拿掉 `x` 后，`zn` 仍存在但失去具体对象、资源与保护边界，支持 `x 补 zn`。
3. 拿掉奖励、名声和外部认可后，意义仍指导资源用途，才是 `zn`。
4. 拿掉实际调配、保护和否决权后，只剩口头支持，则没有 `x`。
5. 拿掉任一端案例完全不变，则只是共现，不构成互补。

### 反向测试
