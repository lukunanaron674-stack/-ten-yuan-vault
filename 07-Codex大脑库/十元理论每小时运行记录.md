## 3. 源端、目标端、变量与成立条件

### 源端`z`

- 人物与阶段：重要主体在人物长期等待外部确认时，明确说出或以等价行为确认“最终判断资格属于你”。
- 具体名词：判断资格确认、正确归因、重要主体认可、停止替代决定。
- 排除：答案、路线、教学、新事实、职位、资源、许可、治疗解释和失败兜底；这些分别属于`xn/x/zx/n`或其他前置变量。
- 体量：低体量只提高一次表达；中体量可启动局部自主；高体量候选必须跨失败、反认可、撤场和新领域持续。

### 目标端`nx`

本轮把目标拆成四个变量：

1. **行为选择权**：人物能否在某一事项中自行作决定。
2. **标准选择权**：人物能否决定采用哪套判断标准。
3. **标准解释修订权**：人物能否依据新证据解释、修改、废弃和重建标准。
4. **失败责任归属**：决定失败后，人物是否仍承担标准作者责任，而非把解释、责任或重新授权退回认可者。

严格`z 克 nx`要求后三项跨阶段回到人物自身。只提高第一项，不足以判克。

### 成立阶段与显影条件

- 阶段A：认可发生，允许记录被看见、表达许可和第一次行动。
- 阶段B：人物独立执行某一标准，仍需检查标准来源与修订权。
- 阶段C：认可者判断错误、明确反对或撤场，并出现无人观看的新领域。
- 阶段D：首次失败和新证据冲突后，人物仍自行修订标准、承担结果，不索取重新授权，才进入严格候选。
- 显影条件：拿掉教学、资源、权限和治疗；设置错误认可、反认可、撤场、无人观看、利益反转、标准冲突和失败责任测试。

## 4. 候选机制

### A｜判断资格与标准作者权回归

```text
重要主体停止替人物给答案
→ 明确承认人物拥有判断资格
→ 人物撤回“我无资格选择标准”的自我否定
→ 自行选择、解释、检验并修订标准
→ 失败后仍承担标准作者责任
→ nx持续下降
```

严格候选由约88%降为约86%。

理论后果：若未来成立，只能先锁“重要认可使最终标准作者权持续回归”的窄机制，不能把一次发言、投稿或反抗写成整个`nx`被克。

### B｜表达许可与一次行动启动

```text
人物原本已有方向
→ 重要认可降低羞耻、孤立和风险感
→ 人物第一次表达或行动
```

这是高置信竞争解释。改变的是显影和行动阈值，不是标准作者权。

### C｜认可来源转移、内化评委与内化标准

```text
人物从等待旧权威点头
→ 转为采用新认可者的偏好和判断标准
→ 认可者离场后仍在该标准内部选择
→ 失败时向脑内评委索取解释或把责任退回认可者
```

这会制造独立外观，但最终方向仍外置。

## 5. 正例候选

1. **《心灵捕手》Will与Sean，治疗后期至离开波士顿阶段**  
   - 源端：Sean不断确认Will有资格选择自己的生活。  
   - 目标候选：Will是否取回最终方向与标准作者权。  
   - 污染：长期治疗、创伤事实重释、Sean持续承载、Chuckie推动和Skylar这一明确目标。  
   - 判断：支持行动许可和局部方向回归，未证明失败后独立修订标准。

2. **《跳出我天地》Billy与父亲Jackie、Mrs. Wilkinson，获得家庭支持至进入舞蹈学校阶段**  
   - 源端：父亲与教师承认Billy的舞蹈选择资格。  
   - 目标候选：Billy是否不再等待外部标准。  
   - 污染：训练、经济支持、父亲许可、学校录取和职业标准。  
   - 判断：正式路线和能力结构足以解释持续行动。

3. **严格控制候选：青年作者与重要编辑**  
   - 编辑只确认“最终判断属于你”，不给建议、渠道或兜底。  
   - 作者退稿后自行修订标准；编辑反对并撤场后，作者面对新证据主动废弃旧标准。  
   - 首次失败后不向编辑索取重新授权，也不把失败归因为“编辑当初让我决定”。  
   - 当前缺两组可核验材料。

## 6. 反例

1. 老师认可后又教会方法：主要是教学与能力增长。

4. 评委表扬后人物只投稿一次：一次行动启动。
5. 人物反抗父母，却持续想象导师是否赞同：认可来源转移。
6. 人物熟练执行导师标准，却不能解释或修改：内化标准。
7. 人物失败后说“是你让我相信自己的”：责任仍退回认可者。

## 7. 最近邻排除

- `x并z 生 z`：解释认可对象如何被识别和正确归因。
- `z 补 xn`：认可给程序补入筛选标准与节点。
- `xn 补 z`：长期证据补足认可。
- 教学、新事实、治疗：提供标准内容或认知材料。
- 权限、职位、资源：提供行动条件。
- 既有自主显影：方向本来就在人物手中。
- 认可来源转移：旧权威被新权威替换。
- 内化标准：能执行标准，但没有作者权和修订权。
- 责任退回：失败后仍由认可者承担解释或授权责任。

## 10. 动态链后果

```text
最终答案和判断标准都必须由重要的人替我确认
→ 你承认我有资格判断
→ 我获得表达、尝试和局部决定许可
→ 我也可能把你的标准和责任接口搬进内部
→ 只有你错误、反对、撤场且新证据冲突时
→ 我仍能自行选择、解释、废弃并重建标准
→ 失败后也不把责任退回给你
→ 才接近nx持续下降
```

本轮只改变当前状态、关系位置、标准归属、修订权与责任归属，不机械生成能力、成功、正确选择或稳定独立人格。

## 11. 三元与十元并行核验

三元观察：谁确认人物、人物随后如何决定、失败后谁继续承担判断责任。

十元区分：

- `z`：重要主体的正确确认与资格承认；
- `nx`：最终方向、标准制定和责任位置外置；
- `xn`：教学、证据和标准组织；
- `x/zx`：权限、职位与行动接口；
- `n/nz`：承载、关系支持与回返。

两套系统并行，没有写成父子派生。
