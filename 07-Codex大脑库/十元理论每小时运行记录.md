## 本轮性质

本轮只审计 `nz 生 nx`。没有新建专项，没有修改核心表、关系词典、专项索引或待确认队列。新增的是“路线供给撤场测试”和“对称交换测试”，用于区分一次关系保全型自主委托、持续协商分工与真正单向退出最终方向位置。

## 源端点、目标端点、变量、阶段与体量

源端点 `nz`：双方已经有真实共同时间、关系余温、不可随意替换性与可信回返位置；主体不愿关系或共同阶段结束。一次好感、怕孤独、现实依赖、临时照护和恋爱题材均不足。

目标端点 `nx`：主体原本拥有可行的自己的路线、实际否决权和独立承担结果的能力，随后跨阶段不提出替代路线、不使用否决，并长期把关系对象的路线当作最终路线。

被改变变量：最终方向认领强度、替代路线是否被保留、否决权是否被实际使用、方向提案是否长期单向、关系对象停止供给路线后主体是否恢复自主定向。

成立阶段：优先落在具体关系阶段或状态层；稳定人物本体未证实。

体量：低体量为一次关系保全型让路；中体量为关系安全后连续多个阶段不恢复自己的路线；高体量为长期人生方向单向交由关系对象，必须强力排除原有稳定 `nx`、控制与共同结构。

显影条件：双方原本平等可选；没有年龄、监护、任务、危险、资源、职位、专业能力差、照护安全与威胁；关系安全且恢复自主不会造成分离。

## 候选机制与理论后果

### 候选 A：关系保全型自主委托

```text
主体不愿关系结束
→ 坚持自己的路线会造成分离
→ 主体主动选择对方路线
→ 共同时间继续
```

理论后果：`nz` 高置信改变本次路线选择，但主体仍在使用最终方向权，只能判一次自主委托，不能判完整 `nx`。

### 候选 B：关系安全后持续不恢复方向

```text
首次为了关系让路
→ 关系危机解除
→ 对方保证恢复自主路线不会导致分离
→ 主体仍跨阶段不提出替代路线、不使用否决
```

理论后果：比首次让路更接近状态层或关系层 `nx`，但仍可能由路线供给惯性、共同生活结构、任务、习惯或原有稳定 `nx` 维持。

### 候选 C：路线供给撤场后仍不自主定向

```text
关系保持安全
→ 关系对象停止提供现成路线
→ 没有任务、日程与共同结构替主体定向
→ 主体仍不提出路线、不使用否决
```

理论后果：若成立，才进一步接近持续方向不占位；但必须排除主体原有稳定 `nx`。若主体立即恢复自主提案，之前只是委托或路线供给惯性。

### 候选 D：对称协商或分工

```text
双方根据情境轮流提案、让路和否决
→ 某阶段一方沿另一方路线
```

这里只成立协商、分工或目标融合。双方都保留最终方向资格，不构成单向 `nx`。

## 正例候选

1. **山姆与弗罗多｜进入魔多及末日火山阶段**：长期共同旅程形成强关系余温，山姆持续沿弗罗多和魔戒任务方向推进。未通过：守护意义 `zn`、既定任务 `xn`、照护 `n`、危险 `xz` 均过强；关系从未进入安全阶段，无法执行路线供给撤场测试。
2. **《末路浩劫》男孩与父亲｜长期向南阶段**：父亲是男孩唯一可信停靠，路线与风险判断长期由父亲决定。未通过：年龄、监护、保护、生存危险与原本不平等的方向位置。
3. **《最后生还者》艾莉与乔尔｜护送旅程阶段**：共同时间与依恋明确，艾莉大量沿乔尔判断行动。未通过：年龄差、护送任务、危险、照护与专业能力差。
4. **旧友重逢结构例**：双方各有同等可行路线，一方只因不愿再次分离而选择对方路线。该结构只能证明一次自主委托；缺少关系安全、对象停止供给路线后仍持续不提案的可核验人物文本。

现有候选均没有同时通过关系安全、路线供给撤场、对称交换与第三因素排除。

## 反例

1. 杰西与席琳继续散步：共同时间延长，路线持续协商，双方仍有决定资格。
2. 关系深厚但各自坚持职业与城市路线：`nz` 成立，`nx` 不上升。
3. 接受医生、导师或专家安排：方向来自专业位置、`n` 或 `xn`。
4. 孩子跟随父母：年龄与监护决定方向。
5. 恋人以分手威胁服从：属于 `x/zx/z` 压力。
6. 因住房、资金或安全留下：属于 `n/x` 与现实依赖。
7. 双方形成第三条路线或轮流提案：共同决策或分工。
8. 主体首次为了关系让路，但关系安全、对象停止提案后立即恢复自己的路线：只是一段委托。

## 最近邻排除

- `n`：改变主体能否被接住、保护和持续停留，不等于交出最终路线。
- `z 克 nx`：认可使主体重新取得判断资格；本轮候选相反，是主体少占方向。
- `x/zx`：威胁、控制、资源和显权造成的服从不是 `nz`。
- `xn`：共同日程、任务、生活结构与现成路线可以维持跟随，却不证明关系余温持续生成 `nx`。
- 共同协商：双方保留提案与否决资格。
- 自主选择：为了关系选择对方路线的瞬间，主体仍在行使最终方向权。
- 稳定 `nx`：关系只是显影机会，不是生成源。

## 拿掉测试

1. 拿掉 `nz`，若仍因任务、年龄、资源、危险、职位、照护或专业差跟随，不成立。
2. 拿掉命令、威胁与对方主动占位，主体仍让路，才支持关系余温作用。
3. 拿掉安全与资源依赖后，让位仍存在，纯度才上升。
4. 拿掉共同时间，只剩一次好感，源端点消失。
5. 拿掉路线撤回，只剩陪伴、建议和协商，目标端点消失。
6. 关系安全且恢复自主不会分离时，主体是否仍不恢复路线？
7. 关系对象停止提供路线后，主体是否仍不自主提案？
8. 让双方交换提案与否决位置；若可轮流让路，属于协商或分工。
9. 拿掉共同日程、任务、生活结构、目标融合与习惯，持续不占位是否仍存在？
10. 主体此前是否已经是稳定 `nx`？

## 反向测试

```text
nz 生 nx 候选：
关系余温先成立
→ 主体首次自主选择对方路线
→ 关系安全且路线供给撤场后仍持续不恢复最终方向

nx 生 nz：
主体长期沿对方路线共同生活
→ 共同路径积累时间厚度
→ 形成不愿结束与回返余温
```

反向 `nx 生 nz` 更容易由长期同行解释。两方向可能形成反馈，但不能互相代证。

## 动态链后果

```text
我不愿这段关系结束
→ 我主动选择你的路线
→ 这一步仍是我的自主决定
→ 关系已经安全，恢复自主也不会失去你
→ 你停止继续替我提供路线
→ 我仍不提出自己的路线、不使用否决
→ 再排除共同结构、习惯与原有 nx
→ 才能继续审计 nz 是否生成关系层 nx
```

改变的是关系中的最终方向认领持续度，不机械生成永久服从、人格软弱、健康关系、正确选择或共同终局。

## 三元与十元并行核验

三元只用于核验作品整体精神运动与关系方向，不从“关系温暖”“同行”“不舍”反推十元生位。十元本轮只检查：`nz` 是否先成立、主体是否原有真实路线与否决、关系安全后是否仍单向不占位、对象停止供给路线后是否仍不自主定向，以及第三因素是否被排除。两套系统并行，不构成父子派生。

## 95% 门槛

高置信结论：

- 延长共同时间、听建议与共同协商不等于 `nx`：99%。
- 主体主动选择对方路线时，该动作仍是自主方向行为：98%。
- 一次关系保全型委托不等于持续方向不占位：99%。
- 关系安全保证测试是必要门槛：97%。
- 路线供给撤场测试能够排除现成路线惯性：97%。
- 对称交换测试能够排除协商与分工：98%。
- 年龄、任务、照护、危险、资源、职位、专业差、习惯与稳定 `nx` 必须排除：99%。

正式机制未达到95%的原因：缺少两个高纯具体人物案例；现有作品均含强第三因素；当前证据只能证明 `nz` 生成一次关系保全型自主委托，不能证明路线供给撤场后的持续不占位仍由 `nz` 直接生成。

结论：几何位置保留；关系层窄候选保留；正式机制未锁定；待确认队列不新增；核心表、关系词典与专项索引不修改。
