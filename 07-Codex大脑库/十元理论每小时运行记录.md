## 源端点、目标端点与变量

### 源端点 `z`

必须明确：

1. 谁认可谁；
2. 认可主体的能力、作品、存在或选择中的什么；
3. 为什么该认可位置重要且不可随意替换；
4. 认可是否真实落到主体，而非掌声、曝光、获奖、录取、签约或泛泛称赞。

### 目标端点 `nz`

评价、奖励、推荐、资源、职位、任务与原被认可对象退出互动中心后，双方仍必须：

1. 分别主动发起非评价互动；
2. 实际兑现再次进入、相见或普通相处；
3. 不依赖被认可者继续追逐评价；
4. 不依赖认可者继续确认同一能力或作品；
5. 认可者失去评价权、退休或由他人接替后，关系仍持续；
6. 普通冲突不靠重新夸奖或恢复评价角色修复。

### 被改变变量

- 被认可者的单方回返意愿；
- 认可者是否独立把对方认作关系对象；
- 双方主动发起比例；
- 非评价互动占比；
- 零评价阶段持续时间；
- 评价权撤场后的关系连续性；
- 普通边界冲突后的修复能力；
- 关系是否可被同等级评价者完全替换。

### 成立阶段、体量与显影条件

```text
重要认可真实落到主体
→ 评价、利益、任务与原对象撤场
→ 进入零评价窗口
→ 双方分别主动发起非评价互动
→ 认可者失去评价权或由他人接替
→ 关系仍持续
→ 普通冲突后仍修复
```

低体量只支持被认可者一次主动回访；中体量要求双方分别主动发起并兑现至少一次非评价互动；高体量要求评价角色退出后跨阶段持续，且普通冲突不使关系退回评价结构。本轮不从单次告别反推稳定本体。

## 候选机制与理论后果

### 候选 A：认可生成单方关系提议

```text
重要认可真实落到主体
→ 被认可者不再只把对方当评判位置
→ 产生再次回到其面前的愿望
```

后果：能够解释单方回返提议，不能证明完整 `nz`。

### 候选 B：认可者独立接受

```text
被认可者提出回返
→ 认可者停止评价与利益供给
→ 仍主动保留并兑现进入资格
→ 双方分别维护关系
```

后果：更接近完整目标，但认可者的第二个主动动作是否由最初 `z` 直接生成，仍未证明。

### 候选 C：旧评价角色余温

```text
评价停止
→ 认可者礼貌回应或保留联系方式
→ 被认可者持续主动靠近
```

后果：关系看似持续，实则只有单方回返与被动接收；不构成双向 `nz`。

### 候选 D：双向独立发起

```text
评价、资源、任务全部撤场
→ 双方各自至少一次主动发起与原作品无关的互动
→ 普通相处与回返被实际兑现
```

后果：能够排除礼貌回应、单方追逐和接口留存。

### 候选 E：认可角色退出

```text
认可者失去评价权、退休或由他人接替
→ 原关系不再提供独特评价利益
→ 双方仍主动维持关系
```

后果：若关系停止，说明旧角色仍是维持源；若持续，完整 `nz` 候选上升。

- `nz` 候选：威尔不再只把肖恩当治疗者，告别具有不愿失去关系的重量。
- 支持点：认可内容与认可主体明确。
- 未通过：长期治疗含强 `n/xn`；影片没有完整展示双方分别主动发起的零评价日常，也没有肖恩退出治疗者身份后的跨阶段关系。

### 2. 《国王的演讲》伯蒂与莱昂内尔，演讲任务结束后

- 未通过：长期训练、陪伴、共同任务和承载已提供大量 `xn/n` 时间厚度；无法隔离最初认可的直接作用。

### 4. 结构纯例：导师与学生

导师停止课程、评分、推荐与资源供给，评价权由他人接替；导师与学生仍分别主动发起普通相处，并在时间边界冲突后修复关系。

该结构能通过新测试，但缺少可核验作品人物文本，不能单独锁定机制。

## 反例

1. 获奖后舍不得离开领奖台：状态兴奋。
2. 被偶像点赞后继续追逐回应：持续 `z`。
3. 因推荐、职位、资源或签约维持联系：`x/x并z` 利益接口。
4. 长期治疗、训练或共同任务结束后不舍：优先检查 `n/xn`。
5. 只有联系方式、关注账号或礼貌邀请：入口未兑现。
6. 后续互动始终围绕作品和能力评价：评价功能未撤场。
7. 一次负向评价就使关系断裂：没有独立停靠价值。
8. 只有被认可者主动联系，认可者从不主动发起：单方回返提议。
9. 认可者失去评价权后关系立即停止：旧角色余温。
10. 普通冲突只能靠重新夸奖主体修复：仍依赖评价角色。
11. 认可前已经是深厚友情：目标并非由本轮从无到有。
12. 换成同等级评价者即可完全替代关系：缺少不可替换关系对象。

## 最近邻排除

- **`n`**：长期被接住、容纳和照护产生的不舍不能归给认可。
- **`xn`**：训练、治疗和共同任务提供重复时间与关系结构。
- **持续 `z`**：还想继续被评价，不等于评价停止后仍有关系价值。
- **`nz 生 z`**：关系余温先成立，再推动作品、表达或回返寻求确认。
- **既有友情**：认可只是命名已有关系，目标没有从无到有。
- **`x/x并z`**：资源、职位和身份接口维持进入，不是自愿回返。
- **礼貌回应**：认可者只被动接受联系，不等于其主动维护关系。

## 拿掉测试

1. 拿掉认可，只保留照护、训练、任务和友情，关系是否仍持续？
2. 拿掉奖励、推荐、资源、职位、任务和继续评价，双方是否仍主动维护？
3. 拿掉被认可者单方想念，认可者是否仍主动发起？
4. 拿掉礼貌邀请和联系方式，真实回返是否发生？
5. 拿掉原作品、能力和选择，关系是否仍有独立内容？
6. 认可者给出负向评价后，关系是否仍持续？
7. 设置完整零评价窗口，双方是否仍分别主动相处？
8. 发生非评价冲突后，双方能否修复而不退回评价角色？
9. 认可者失去评价权、退休或由他人接替后，关系是否仍持续？
10. 换成同等级评价者，原关系是否可完全替代？
11. 拿掉 `n/xn` 与既有友情后，认可是否仍独立生成双向时间厚度？

现有具体案例没有通过第 7、8、9、11 项组合。

## 反向测试

```text
z 生 nz 候选：
重要认可先发生
→ 评价功能和认可角色撤场
→ 双方分别主动发起非评价互动
→ 普通冲突后仍修复并保留回返位置

nz 生 z：
关系余温与不舍先成立
→ 主体通过作品、表达或回返寻求确认
```

毕业、谢幕、治疗结束与最终作品不能同时替两个方向重复记账。

## 三元与十元并行核验

三元层只能记录：

- 被确认后更愿意继续联系；
- 共同阶段结束时出现不舍；
- 双方后来仍有来往。

十元层必须另证：

- 源端是明确重要认可 `z`；
- 目标端是双方可信回返关系 `nz`；
- 评价职能、任务与利益撤场后，双方仍分别主动发起；
- 认可角色退出后，关系仍独立存在；
- 普通冲突不靠重新评价修复。

三元里的“被看见后舍不得”不能自动派生为十元 `z 生 nz`。

## 动态链后果

```text
你真正确认了我
→ 我想再次回到你面前
→ 这最多是单方关系提议
→ 评价、奖励、资源和任务全部停止
→ 你不再拥有评价我的独特位置
→ 我们仍分别主动发起普通相处
→ 发生与评价无关的分歧
→ 仍修复关系而不退回评价角色
→ 才继续接近可信可回返关系
```

改变的是认可位置能否跨阶段转成双方独立维护的关系接口，不机械生成友情、爱情、依赖、归属、健康关系或永久合作。
