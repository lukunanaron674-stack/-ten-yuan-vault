### 对象分层

- 稳定本体：不由一次换装、撒谎、注册公司或拥有奢侈品反推稳定 `x` 或 `x并z`。
- 当前状态：此阶段取得或扩大掌握，与此阶段建立、维护或切换公开壳分开。
- 行为功能：占有、调配、划界、否决属于 `x`；命名、挂牌、设立门面、职位、品牌、制服与前台角色属于 `x并z`。
- 光影：金库、钥匙、地盘、幕后网络、招牌、徽记、制服与面具只作显影。
- 场景：企业、黑帮、王权、门店、法人和社交身份不能替代端点。
- 时间关系：先掌握后造壳只是必要条件；必须证明壳由掌握关系的代表、调用、合法性或保护需要启动。
- 关系位置：所有者、控制者、权限持有人与身份持有者、品牌主体、公开代表必须明确。
- 显影：观察实际调配和否决范围，以及掌握边界的对外可识别性、可调用性、接口稳定度和内层暴露程度。
- 动态链：从“这些已归我掌握”进入“世界通过一层壳接触、调用或被隔离于我的掌握范围”。

### 源端点、目标端点、变量、阶段、体量与显影条件

- 源端点 `x`：已存在明确对象、资源、地盘、权限、人员、渠道或关系边界的实际掌握；欲望、企图、生存压力和“想获得”不足。
- 目标端点 `x并z`：形成具有持续性的名称、职位、头衔、制服、徽记、品牌、门店、法人身份、公众人格、前台角色或其他表里接口。
- 被改变变量：掌握边界的对外可识别性、可调用性、可复述性、接口稳定度、内层暴露程度，以及壳能否代表、合法化或保护实际控制范围。
- 成立阶段：实际掌握先成立；随后出现代表、调用、合法性或暴露问题；主体建立并认领公开壳；外界开始通过该壳接触掌握范围。
- 低体量：为单项权限或资源建立稳定名称、标记或公开身份。
- 中体量：稳定职位、公司、门店或公众角色代表一组实际控制关系。
- 高体量：庞大幕后网络由完整合法组织、王权身份或公共品牌作为外壳。
- 显影条件：壳明确服务于已成立掌握；拿掉掌握后壳不会以同样形式出现；壳不是纯求认可、任务伪装或临时骗过检查；壳持续改变外界读取和接触内层的方式。

### 候选机制及理论后果

- A 掌握边界可识别化：实际掌握已经存在，但外界无法稳定识别谁拥有、谁代表、谁有权调用；主体建立名称、职位、徽记、品牌或正式身份，使掌握边界获得公开界面。理论后果：`x并z` 把“实际归我”变成“世界知道通过什么壳接触这一范围”。
- B 内层控制保护化：实际掌握已经存在，但完整暴露会威胁控制；主体建立合法门面、前台角色或社会身份，使外界只接触壳，内层继续受控。理论后果：壳既展示，也限制外界看见掌握内层的程度。
- C 为取得资源而伪造身份：掌握尚未成立，主体先造壳再取得资源。该候选排除为本方向，更接近 `x并z→x`、`xn` 策略或 `z` 目标推进。
- 统一机制：A 与 B 都是“已成立的掌握边界，为了被世界识别、调用、代表或保护，形成稳定公开壳”。

### 正例

1. 《绝命毒师》古斯·弗林，毒品帝国成熟阶段：古斯已经掌握生产、运输、人员、资金和地盘网络；餐饮企业、慈善商人与社区领袖形象成为物流、人员调用和社会接触接口，同时隔离地下控制。拿掉毒品网络后，餐饮身份仍可存在，但不会以同样强度承担掩护、物流和控制接口。
2. 统治者取得领地、税收、军队与任免权限后形成国号、王冠、王室徽记和宫廷身份：现实控制先成立，随后需要让臣民、盟友和敌人知道谁代表该范围、通过何种形式承认和调用权力。
3. 黑帮已控制地盘、现金流、人手与地下渠道后经营运输公司、夜总会或建筑公司作为合法门面：公司名义允许资源被调用、人员被安置和资金同外界交换，同时保护内层控制。

### 反例

1. 《寄生虫》金家伪造学历进入朴家：资源与职位尚未掌握，身份壳是取得资源的前置工具，方向更接近 `x并z→x` 或 `xn` 策略。
2. 富人购买华丽衣服：财富与外观共现，未证明衣服代表、调用或保护掌握边界。
3. 演员因角色换装：只有行为与场景，没有已成立控制范围。
4. 公司按市场计划统一视觉：若启动源是传播排程，优先检查 `xn`；除非品牌壳明确代表特定所有权或控制范围。
5. 冒充警察获得进入权限：壳先帮助取得尚未拥有的权限，属于反向或工具链。

### 最近邻排除

- 与反向 `x并z 生 x`：本关系是实际掌握先成立，壳随后代表或保护；反向是身份、职位、品牌或伪装先成立，随后帮助取得资源、对象或权限。
- 与 `xn`：`xn` 解决怎样排程、组织和重复运行；本关系解决实际掌握通过什么界面被世界读取。
- 与 `z`：`z` 要求明确认可主体与内容；本关系不要求赞美或确认，只要求外界能辨认、调用或被壳隔离。
- 与 `zx`：`zx` 是权能公开扩大并压过他者；本关系可以低调，甚至为了避免显权而造壳。

### 拿掉测试

1. 拿掉实际掌握后，壳仍因求职、表演或任务需要出现，则不依赖 `x`。
2. 拿掉公开壳，实际控制仍存在但难以合法调用、代表或隐藏，支持本关系。
3. 拿掉资源和地盘，只剩漂亮身份，目标端点可能存在但源端点不足。
4. 拿掉合法性与保护需要，只剩获得认可的愿望，优先检查 `z`。
5. 古斯案例拿掉毒品网络后，餐饮商人身份不再承担同等强度的掩护、物流与控制接口，说明关系成立。

### 反向测试

```text
x 生 x并z：先有实际掌握，后因掌握需要造壳。
x并z 生 x：先有壳，壳随后帮助取得掌握。
```

二者可以形成反馈，但必须分阶段，不得因最终同时拥有资源和身份而混写。

### 动态链后果

```text
这些对象、地盘、权限和关系已经归我掌握
→ 世界无法直接同这套掌握关系相处，或完整暴露会威胁它
→ 名称、职位、品牌、门面或公众角色形成
→ 世界开始通过这层壳接触、调用或被隔离于我的范围
```

改变的是**掌握边界进入社会读取系统的方式**，不机械生成虚伪、认可、资源增长、公开显权或稳定人物本体。

### 三元与十元并行

三元只核验作品整体精神感与大关系方向。十元只核验具体阶段中的既有 `x`、随后形成的 `x并z`、表里接口与代表保护变量。两套系统并行，不把 `x` 写成 `x并z` 的父级，也不由公司门面、王冠或制服反推人物稳定三元。
