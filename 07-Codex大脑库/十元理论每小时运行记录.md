## 3. 源端、目标端、变量与成立条件

### 源端`nz`

- 人物与阶段：双方已经跨阶段形成对象特异可信回返；任务、评价和危机结束后仍分别回来，分歧后可以修复。
- 具体名词：可信回返关系、对象特异停靠、关系安全、共同节奏。
- 排除：分手威胁、住房和经济依赖、照护绑缚、职位服从、危机共同路线、信息与能力差。
- 体量：低体量只提高一次听取；中体量形成稳定默认；高体量候选必须跨多个无共同利益领域改变元层资格可达性。

### 目标端`nx`

本轮拆成八个变量：

1. **默认采用率**：人物多常采用对方判断。
2. **一阶委托**：具体结论是否交给对方。
3. **否决资格**：人物能否直接拒绝对方结论。
4. **第三判断者资格**：能否不经原对象许可引入第三人。
5. **私下替代判断**：能否在不破坏关系的情况下独立形成分叉方案。
6. **单方面执行资格**：能否直接执行与共同默认不同的方案。
7. **标准重建资格**：能否重设问题、信息入口和判断标准。
8. **资格可达性**：上述资格在低成本、安全窗口中是否能够被实际调用。

严格`nx`生成要求第3至第8项持续下降。只证明第1和第2项上升，属于认识性信任或可撤销委托。

### 成立阶段与显影条件

- 阶段A：双方关系安全，能力、信息和现实资格相当。
- 阶段B：人物因信任和协调便利，长期默认采用对方判断。
- 阶段C：原对象连续犯错，并明确允许人物退出、换人和独立判断。
- 阶段D：第三判断者可用，切换成本接近零，关系不会因分叉破裂。
- 阶段E：人物获得私下形成替代判断和单方面执行的真实窗口。
- 阶段F：测试人物是主动不用，还是根本无法调用否决、换人与重建标准。
- 显影条件：无危机、无照护、无经济住房依赖、无专业压制、无分手威胁、无共同资产锁定。

### T / M / E

- T：共同生活与判断委托范围可以很大，但高T不自动生成稳定`nx`本体。
- M：人物长期说“听你的”、几乎不单独判断，可使`nx`显影极强，但高M可能只是共同节奏。
- E：只有元层资格从可调用变为不可达，才构成高E生位。

## 4. 候选机制

### A｜可信回返生成最终方向资格让位

```text
关系持续提供安全停靠
→ 独自判断责任和失败负担下降
→ 一阶判断与元层启动权都交给特定对象
→ 否决、第三判断者、私下分叉与标准重建资格不可达
→ nx上升
```

理论后果：若成立，只能先锁定“关系安全使元层方向资格不可达”的窄机制。当前候选由约84%降为约82%。

### B｜认识性信任与可撤销委托

```text
对方长期可靠
→ 人物认为其判断更准、协调成本更低
→ 默认采用或长期委托具体事项
→ 仍可否决、换人、私下形成替代方案并重建标准
```

理论后果：这是现有材料最稳定的解释，约99%，但不构成`nx`生成。

### C｜共同决策环境与协调锁定

```text
双方长期共享信息入口、讨论顺序和默认方案
→ 单方退出会打断共同节奏
→ 人物很少独立启动判断
→ 看起来像方向资格已经交出
```

理论后果：改变的是`xn`式协调环境和切换成本，不等于元层资格消失。

### D｜资格主动闲置与潜在主权保留

```text
人物知道自己可以否决、换人和重设环境
→ 因关系安全、信任与省力而长期不使用
→ 外观上持续跟随
→ 低成本分叉窗口出现时仍能立即调用资格
```

理论后果：不使用资格不等于资格不可达；潜在主权仍在人物自身。

## 7. 最近邻排除

- `nz 补 xz`：关系为危险路径补入归宿。
- `zx 补 nx`：借现成身份、权限和通道做成。
- `n`：照护与现实承载造成代定。
- `xn`：共同流程、信息入口和协调锁定。
- `xz`：害怕失去关系而顺从。
- 认识性信任：相信对方更懂，但保留元层资格。
- 可撤销委托：交出一阶结论，仍能暂停、换人与复判。
- 资格主动闲置：长期不用，但低成本窗口中可立即调用。

## 8. 拿掉测试

1. 拿掉共同任务、共同利益和共同路线。
2. 拿掉危机、照护、住房、经济和共同资产依赖。
3. 冻结信息、能力、资源与社会资格差异。
4. 保证关系不会因退出共同默认而破裂。
5. 让原对象连续犯错并失去专业优势。
6. 提供独立信息渠道和同能力第三判断者。
7. 把第三判断者切换成本降到接近零。
8. 给人物私下形成替代判断的无冲突窗口。
9. 给人物单方面执行分叉方案的真实机会。
10. 分开测试否决、换人、重新设题与标准重建。
11. 跨职业、迁居、创作三类无共同利益事项复测。
12. 检查资格是“不愿使用”还是“无法调用”。

## 10. 动态链后果

```text
这里有一个即使我判断错误也能回去的人
→ 我不必独自承担全部判断负荷
→ 我更愿意进入共同决策节奏并默认采用你的判断
→ 我可能长期不使用否决、第三判断者和单方复判
→ 只要低成本分叉窗口中仍能直接调用这些资格
→ 最终方向仍属于我
→ 只有资格本身不可达
→ 才接近对象特异的nx上升
```

本轮只改变独自判断负荷、认识性信任、共同节奏、资格使用频率与资格可达性，不机械生成服从、无能或永久依赖。

## 11. 三元与十元并行核验

- 双方是否持续回返；
- 谁提出判断；
- 谁执行默认方案；
- 分叉出现时谁能重设环境。

十元区分：

- `nz`：可信回返与对象特异停靠；
- `nx`：主体不占最终方向；
- `xn`：共同流程、信息入口和协调环境；
- `n`：照护与现实承载；
- `xz`：失去关系与破裂压力；
- `zx`：公开权限和决定接口。
