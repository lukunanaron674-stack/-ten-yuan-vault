### 对象分层

- 稳定本体：`xn` 是主体长期主动组织时间、流程、信息与资源；`z` 是主体对重要认可位置的稳定需要。一次计划、一次获奖不能反推本体。
- 当前状态：此阶段排程、训练、记录、复盘，与此阶段被看见、回应、确认或否认分开。
- 行为功能：任务拆分、顺序安排、证据记录、重复训练；作品呈现、评审、答辩与回应。行为只作端点证据。
- 光影：网格、日历、档案、训练痕迹、舞台、评审席和聚光只作显影。
- 场景：实验室、训练室、项目周期、试镜、答辩和展演均不能替代端点。
- 时间关系：长期积累可在认可前或认可后继续；确认节点可位于阶段中途或结尾；先后本身不证明互补。
- 关系位置：组织者、训练者、研究者、导师、评委、观众、同行与自我认可位置，称谓不能替代实际功能。
- 显影：观察证据连续性、重复稳定度、可复核材料密度、认可对象清晰度、组织聚焦度与阶段收束度。
- 动态链：改变“积累怎样获得阶段确认”与“确认怎样获得跨时间重量”，不机械生成成功、获奖或人格成熟。

### 双向端点、变量、阶段、体量与显影

- `xn 补 z`：已有明确认可主体、认可对象与认可内容，但一次表现不足以确认稳定能力。被改变变量是证据连续性、重复稳定度、可复核材料密度、认可者区分运气与稳定能力的能力。
- `z 补 xn`：已有主动组织、训练、记录与材料积累，但缺少认可焦点和阶段收束。被改变变量是组织聚焦对象、材料筛选标准、阶段收束节点、最终呈现内容和下一周期校准依据。
- 成立阶段：至少一端先独立成立，另一端补入后，原端点的真实缺口发生可观察变化。
- 体量：低体量为一次评审帮助短期训练收束或一份记录帮助确认稳定性；中体量为跨月、跨项目的组织与多次认可形成阶段循环；高体量为长期事业、创作或研究持续以重要认可位置校准并以多年积累建立稳定确认。
- 显影条件：`xn` 必须是主动组织而非被动课程、制度或截止日期；`z` 必须有明确认可主体、认可内容与重要认可位置；负面但明确、可归因的专业回应也可成为节点。

### 候选机制

- A 连续证据补认可：重要认可位置已存在，但单次呈现不足；`xn` 通过训练记录、作品序列、实验复现和阶段材料，使认可能够跨时间确认“这确实是你的能力、作品或发现”。
- B 认可节点补组织：长期组织已运行但缺少精神收束点；`z` 通过明确认可主体、内容与确认节点，使主体能够筛选材料、安排呈现并结束当前阶段。
- C 截止日期制造冲刺：排除。日期不是主动组织主体，冲刺不是认可关系，可能只是任务紧迫或 `xz` 状态。
- D 传播流程提高曝光：排除。到达率增长不等于重要认可主体确认，可能只是 `xn/x/x并z`。

### 正例

1. 《爆裂鼓手》安德鲁在 JVC 音乐节演出前后：安德鲁主动组织长期训练、技术拆分与反复纠错，弗莱彻与专业现场构成重要认可位置。训练使能力可重复呈现；专业确认节点使训练聚焦到现场可成立的标准。故事同时含 `zx/xz`，但不替代本轮双向变量。
2. 《国王的演讲》乔治六世战时广播阶段：长期呼吸、节奏、发声、文本和模拟训练，使最终讲话不是偶然顺利；全国广播与听众回应为训练提供明确收束节点。王权含 `zx/x并z`，战争含 `xz`，但不替代训练与确认变量。
3. 科研人员的长期复现实验与同行答辩：实验轮次、参数记录和失败数据形成连续证据；同行确认标准与答辩节点决定哪些数据必须补齐、何时形成阶段结论。

### 反例

1. 考试日期临近后临时熬夜：只有截止日期和紧迫状态，没有稳定主动组织，也没有明确认可主体与内容。
2. 公司按模板做年度汇报：被动流程更接近 `nx` 或制度场景；交差不自动形成 `z`。
3. 广告持续投放后播放量上涨：主要改变曝光和到达率，不证明重要认可关系。
4. 一次比赛夺冠：掌声和结果可能形成状态，但不能证明长期组织补足确认稳定度。
5. 长期练习只为提高技能、完全不在意认可位置：`xn` 成立，`z` 端点不存在。
6. 导师一句称赞后学生开始制定计划：可能是 `z` 驱动后续行为，不等于既有两端互补。
7. 评审明确否定作品但创作者完全不调整组织：`z` 发生回应，却没有补到 `xn`。

### 最近邻

- 与 `x并z 生 z`：后者解决“认可主体能否认出并正确归因对象”；本关系解决“认可内容能否跨时间证明不是偶然”。
- 与 `x 克 z`：后者关闭或劫持认可入口；本关系假设入口已存在，组织补足证据连续性。
- 与 `xn 生 xz`：后者使偏差被识别并压缩安全路线；本关系使认可证据成熟。高压演出可同时含 `xz`，但压力不是补位机制。
- 与普通目标完成：事情做完不等于有人确认谁的什么，也不等于认可位置重要。
- 与 `z` 驱动 `xn`：被认可后开始训练是动态驱动候选；补位要求一端已经成立，另一端改变其真实缺口。

### 拿掉测试

1. 拿掉 `xn` 后，认可是否仍能以同样稳定度确认主体的能力、作品或发现？若不能，支持 `xn 补 z`。
2. 拿掉 `z` 后，长期组织是否仍以同样标准筛选材料、结束阶段并决定呈现？若不能，支持 `z 补 xn`。
3. 拿掉截止日期与高压气氛后，连续证据和认可节点的互补仍成立，排除普通紧迫状态。
4. 拿掉传播资源与公开包装后，少量但明确的专业认可仍能通过长期证据成立，排除流量与壳。
5. 拿掉认可主体，只剩训练、流程和结果，则只剩 `xn`。
6. 拿掉主动组织，只剩课程、制度或被动服从，则 `xn` 端点不足。

### 反向测试

```text
xn 补 z：组织使认可内容跨时间稳定、可复核、可重复确认。
z 补 xn：认可位置使组织获得聚焦、筛选标准与阶段收束节点。
```

补位几何对称，但作用变量必须交换。认可使人开始练习不自动等于 `z 补 xn`；训练后获奖也不自动等于 `xn 补 z`。

### 动态链后果

```text
只有 xn：事情可以长期组织下去，但不知道哪一个精神位置能够确认这一阶段已经成立。
只有 z：已有重要认可位置，但一次被看见不足以确认稳定能力或作品。
xn ↔ z：长期积累形成可确认的证据，认可节点让积累获得阶段焦点与收束。
```

改变的是时间如何从无尽积累变成可确认阶段，以及一次确认如何获得跨时间可信重量。不机械生成获奖、成功、正面评价、事业终局或下一阶段必然继续。
