## 3. 源端、目标端、变量与成立条件

### 源端`z`

- 人物与阶段：重要主体在明确评价节点，对具体人物、作品、选择或完成作出准确判断并正确归因。
- 具体名词：重要认可位置、正确归因、明确见证、判断确认。
- 排除：礼貌夸奖、掌声、曝光、奖品、职位、资源、合作邀请、治疗职责、导师义务、公开押注和声誉维护。
- 体量：
  - 低体量：一句准确认可，只改变被认可者当前状态。
  - 中体量：认可者成为被认可者的特定见证位置，提高单方回返和再次展示概率。
  - 高体量候选：评价耗尽后，认可者在无请求、无义务、无收益且对方价值下降时仍主动投入。

### 目标端`nz`

- 双方回返：双方分别主动发起非评价接触，而非一方请求、另一方礼貌回应。
- 非评价投入：认可者不再需要新作品、新表现或新问题作为出现理由。
- 维护成本：双方在对方失败、价值下降、拒绝建议和负面判断后仍投入时间、情绪或现实成本。
- 冲突修复：与评价内容无关的冲突后，双方仍愿意重开关系。
- 对象特异性：同等级的其他被认可者或认可者不能轻易替代该位置。
- 被改变变量：被认可者关系价值、单方回返概率、认可者主动投入概率、互惠维护强度、冲突修复率、对象不可替代性。

### 成立阶段与显影条件

- 阶段A：认可刚发生，只允许记录被认可者状态和关系入口变化。
- 阶段B：被认可者首次回返，仍不能判双方关系生成。
- 阶段C：认可者在无请求窗口主动非评价投入，才进入严格候选。
- 阶段D：双方跨失败、价值下降、拒绝建议、负面判断和非评价冲突继续维护，才接近稳定`nz`。
- 显影条件：评价耗尽、被认可者不再请求、无新作品可评价、无任务资源、无治疗/导师/职业义务、认可者无声誉押注、第三对象替换、价值下降和冲突修复。

## 4. 候选机制

### A｜准确见证独立生成双方可信停靠

```text
认可者准确看见被认可者真正交出的对象
→ 被认可者把认可者视为特定见证位置并主动回返
→ 认可者也因这次见证而产生无请求、非评价投入
→ 双方跨失败和冲突形成可信停靠
```

严格候选由约89%降为约87%。核心缺口是第二个箭头：单向判断为什么会让认可者本人进入关系，现有材料不能排除身份义务、声誉押注或后续请求。

理论后果：若成立，只能先锁“准确见证启动双向关系”的窄机制，不能直接生成成熟友情、爱情、忠诚或共同体。

### B｜被认可者关系价值与单方回返上升

```text
人物被准确看见
→ 认可者在人物心中成为“真正看见我的人”
→ 被认可者更愿意靠近、展示、求助或争取回应
→ 第一次互动入口打开
```

这是本轮最稳定的解释，约99%。它直接改变被认可者一侧，不等于认可者也形成停靠。

理论后果：`z`可以作为后续关系链的入口条件，但不能独立背书`nz`已经成立。

### C｜认可者判断一致性与身份维护

```text
认可者已经公开确认人物
→ 为维持自己判断的一致性、专业身份、声誉或责任
→ 继续关注、指导、保护或投入
```

该投入表面像关系维护，实际源端可能是：

- `x并z`：评审、导师、治疗者、领导等身份壳；
- `zx`：公开判断后的权威一致性与声誉押注；
- `xn`：教学、评审、治疗或合作程序持续；
- `n`：职业照护与承载责任。

理论后果：不能把这些第三结构倒写成纯`z 生 nz`。

### D｜后续互动链另行增厚关系

```text
被认可者因z主动回返
→ 提出请求、分享新对象或进入共同活动
→ 认可者因新互动回应
→ 多轮共同时间、自我暴露、承载与修复
→ 最终形成nz
```

该链可以真实产生关系，但生源是后续互动、共同时间和承载，不是最初一次认可直接生成完整`nz`。

## 6. 反例

1. 学生因导师表扬而持续联系，只为推荐、资源或继续评价：被认可者单方回返。
2. 粉丝被偶像回复一次后长期留恋，偶像没有后续主动投入：认可依赖，不是双方停靠。
3. 评委持续关注获奖者的新作品：评价程序和专业身份延续。
4. 治疗者继续会面：职业责任与治疗程序运行。
5. 导师为维护公开推荐继续帮助学生：声誉押注和判断一致性。
6. 认可者只在被认可者请求后回应：后续请求启动，不是认可者独立回返。
7. 毕业团队在成功后不愿分开：长期共同时间与离别压力先在。
8. 匿名认可显著提高人物留恋，却不存在认可者后续关系行为：只证明单方见证价值。
9. 认可者在被认可者价值下降后立即转向另一位同等级对象：缺对象特异性。
10. 认可者因担心自己判断错误而持续监控：判断维护，不是关系停靠。

## 9. 反向测试

必须排除：

```text
原有nz推动人物完成并获得z
≠
z完成后新生nz
```

判定规则：

- 只有被认可者主动回返：关系价值或认可依赖上升。
- 认可者因新请求、新作品或职业责任回应：后续程序或互动链。
- 认可者为了证明自己判断正确而持续投入：公开判断一致性或声誉押注。
- 认可者在无请求、无收益、无义务、对方失败且拒绝建议后仍主动投入：才支持认可者进入关系。
- 同等级对象可完全替代：缺对象特异性。
- 双方跨非评价冲突修复：才接近可信停靠。

`nz 生 z`不是本轮反向关系。原有关系可能帮助人物完成并获得认可，但不能用来证明认可生成关系。

## 10. 动态链后果

```text
你准确看见了我真正交出的东西
→ 你在我这里获得特定见证价值
→ 我更愿意再次靠近你
→ 我的回返可能打开新的互动链
→ 你可能因身份义务、声誉押注、请求或共同活动继续投入
→ 只有这些第三因素拿掉后，你仍主动维护
→ 且双方跨失败、价值下降和非评价冲突修复
→ 才接近双方可信停靠
```

本轮只改变：

- 被认可者对认可者的关系价值；
- 单方回返概率；
- 第一次接近与后续互动入口；
- 认可者非评价投入的候选概率。

不得机械生成友情、爱情、忠诚、永久依赖或共同体。

## 11. 三元与十元并行核验

三元观察：

- 谁先回返；
- 谁主动投入；
- 双方在失败与冲突后是否继续；
- 关系是否依赖评价、任务或资源。

十元区分：

- `z`：重要主体对明确对象作出正确归因和确认；
- `nz`：双方可信回返、对象特异停靠和不愿彻底结束；
- `n`：现实接收、照护和持续承载；
- `xn`：评审、教学、治疗、合作与持续程序；
- `x并z`：导师、评委、治疗者和领导等公共身份壳；
- `zx`：公开判断、声誉押注和权威一致性；
- `xz`：离别、失去和最后窗口风险。

三元与十元并行，没有写成父子派生。
