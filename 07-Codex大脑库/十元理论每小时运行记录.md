| 稳定本体 | 长期保留关系余温、回返位置与不愿结束 | 长期不占最终方向位置 | 一次依恋或一次跟随不能反推本体生成 |

## 源端点、目标端点、机制变量

### 源端点 `nz`

必须先存在真实共同时间、可信回返位置、不可任意替换的关系对象，以及主体不愿关系或共同阶段结束。一次好感、怕孤独、临时照顾、现实依赖或恋爱题材不足。

### 目标端点 `nx`

主体原本必须拥有自己的可行路线、实际否决权和独立承担结果的能力；随后跨阶段不提出替代路线、不使用否决，并把他者或关系提供的方向作为最终方向。

### 被改变变量

- 独自定向必要感；
- 最终方向资格的认领强度；
- 替代路线是否继续保留；
- 否决权是否实际使用；
- 决定资格是否只交给特定关系对象；
- 关系对象返还决定资格后，主体是否重新认领；
- 跟随是否由共同任务、资源、专业差或稳定 `nx` 维持。

### 成立阶段、体量与显影条件

```text
nz 已先成立
→ 主体原本拥有平等可行路线
→ 关系危机解除，恢复自主不会造成分离
→ 对方停止持续提供路线
→ 共同任务、日程、资源与专业差被撤掉
→ 比较对象特异性
→ 对方明确返还决定资格
→ 观察主体是否仍反复推回最终决定
```

低体量只能判一次自主委托；中体量可判一段关系中的反复方向让位；稳定本体层目前无证据支持。

## 候选机制与理论后果

### 候选 A：关系保全型自主委托

```text
主体不愿关系结束
→ 认为坚持自己的路线会造成分离
→ 主动选择对方路线
→ 共同时间继续
```

后果：`nz` 可以改变本次路线选择，但主体仍在使用自己的最终方向权；只构成一次委托。

### 候选 B：方向暂停或等待

```text
关系仍需确认
→ 主体暂时不提出路线
→ 等待对方先行动或等待关系稳定
```

后果：改变定向时机，不证明最终方向资格交给他者。

### 候选 C：对象特异的方向转交

```text
关系已安全
→ 恢复自主不会造成分离
→ 非关系对象提供同类路线时主体不交付最终方向
→ 只有该关系对象获得最终决定资格
→ 关系对象明确返还资格
→ 主体仍反复把决定推回该对象
```

后果：最接近关系层 `nx`，但仍须排除信任、专业能力差、习惯、共同结构和原有稳定 `nx`。

### 候选 D：一般依赖或稳定 `nx`

主体把最终方向同样交给任何可靠、强势或更熟悉路线的人。后果：对象不具 `nz` 特异性，关系只提供显影场景。

### 候选 E：对称协商与目标融合

双方轮流提案、否决、让路，或形成第三条共同路线。后果：双方仍保留方向资格，不构成单向 `nx`。

## 正例候选

### 1. 山姆与弗罗多｜进入魔多及末日火山阶段

`nz` 候选是长期共同旅程与不愿放弃彼此；`nx` 候选是山姆不改写弗罗多和魔戒任务认领的最终方向，持续沿其路线推进。

未通过：守护意义 `zn`、既定任务 `xn`、照护 `n`、生存危险 `xz` 同时存在；关系从未安全，无法执行对象特异性和决定返还测试。

### 2. 《末路浩劫》父亲与男孩｜长期向南阶段

父亲是男孩唯一可信关系位置，路线与风险判断主要由父亲决定。

未通过：年龄、监护、保护、生存危险和原本不平等的决定资格无法排除。男孩并非先有平等可行路线再由 `nz` 交出。

### 3. 《最后生还者》乔尔与艾莉｜护送旅程阶段

共同时间和关系余温明确，艾莉在多个阶段接受乔尔的路线和风险判断。

未通过：年龄差、护送任务、危险、照护与专业能力差均构成强第三因素；乔尔返还决定资格后的反应也不足以验证。

### 4. 纯结构候选：旧友重逢后的方向交付

甲乙曾有长期共同生活。重逢后关系已明确安全，双方各有同等可行路线。甲不依赖乙的资源与专业，只把最终方向交给乙；同等级陌生人提出同样路线时甲不交付。乙后来明确说“你自己决定也不会失去我”，甲仍反复要求乙作最终决定。

该结构能够通过对象特异性与决定返还测试，但缺少具体可核验人物文本，不能据此锁定。

## 反例

1. 接受医生、导师或专家路线：专业能力与 `n/xn`。
2. 员工因喜欢老板服从工作安排：职位已经给出方向。
3. 恋人以分手威胁服从：`x/zx/z` 强制。
4. 孩子跟随父母：年龄和监护。
5. 走投无路时接受陌生人带路：`xz` 与现实通道。
6. 关系深厚但双方各自坚持方向：`nz` 有而 `nx` 不上升。
7. 主体本来就是稳定 `nx`：关系只让其显影。
8. 因住所、金钱、安全和照护接受安排：`n/x` 现实条件。
9. 对方返还决定资格后主体立即恢复自主：可撤回委托。
10. 主体对任何可靠对象都同样说“你决定”：一般依赖或稳定 `nx`。
11. 双方轮流决定与让路：对称协商。
12. 主体只是停滞、不知道下一步：方向暂停，不是方向转交。

## 最近邻排除

- `n`：改变能否被接住、保护与持续停留，不等于交出最终方向。
- `z 克 nx`：重要确认使主体重新取得方向资格，与本轮方向相反。
- `x/zx`：威胁、资源控制、职位与主动占位造成服从。
- `xn`：共同任务、日程、流程和专业路线持续定向。
- 对称协商：双方仍保留提案和否决资格。
- 目标融合：对方路线已成为主体自己的目标。
- 稳定 `nx`：主体对不同对象均交出方向，关系不是生成源。
- 信任加权：认为对方建议更可靠，不等于承认其拥有最终决定资格。

## 拿掉测试

1. 拿掉 `nz`，若仍因任务、年龄、危险、资源、职位、专业或照护跟随，不成立。
2. 拿掉命令、威胁和对方主动占位后，主体是否仍让路？
3. 拿掉安全、住房、金钱和照护依赖后，让位是否仍存在？
4. 拿掉共同时间，只剩一次好感，源端点是否消失？
5. 拿掉路线转交，只剩陪伴、建议和协商，目标端点是否消失？
6. 关系安全、恢复自主不会造成分离后，主体是否仍不恢复方向？
7. 对方停止提供路线后，主体是恢复自主、停滞等待，还是明确转交决定资格？
8. 将同类路线改由同等可靠的非关系对象提供，主体是否也交出方向？
9. 关系对象明确返还决定资格并保证关系不受影响后，主体是否仍反复推回决定？
10. 双方交换提案、否决和让路位置后，是否只是对称协商？
11. 拿掉共同任务、日程、生活结构、目标融合与习惯后，持续不占位是否仍存在？
12. 主体此前是否已经是稳定 `nx`？

现有具体案例均未通过第6至第12项完整组合。

## 反向测试

```text
nz 生 nx 候选：
关系余温先成立
→ 主体为保全关系作出一次自主委托
→ 关系安全、路线供给撤场后
→ 只对该关系对象持续交付最终方向
→ 对方返还资格后仍反复推回

nx 生 nz：
主体长期沿对方方向共同生活
→ 共同路径积累时间厚度
→ 形成不愿结束与可信回返位置
```

反向关系更容易由长期同行直接解释。最终同时出现“不舍与跟随”，不能两边重复记账。

## 三元与十元并行核验

三元层只能记录：为了保留关系，主体让一步、继续同行或反复听取对方意见。

十元层必须另证：源端是不可替换的关系余温 `nz`；目标端是最终方向不占位 `nx`；关系安全和路线供给撤场后，主体仍对该对象特异地转交方向，并在对方返还时拒绝重新认领。

三元中的“为了关系听你的”不能自动派生为十元 `nz 生 nx`。

## 动态链后果

```text
我不愿这段关系结束
→ 我主动选择你的路线
→ 这仍是我的自主决定
→ 关系已经安全，恢复自主不会失去你
→ 你停止替我提供路线
→ 别人给同样建议时，我不把最终方向交给他
→ 你明确把决定资格还给我
→ 我仍反复把最终决定推回给你
→ 再排除习惯、共同结构和原有 nx
→ 才继续接近关系层 nx
```

改变的是关系中最终方向资格的认领对象与可撤回性，不机械生成永久服从、人格软弱、健康关系、正确选择或共同终局。

## 95%门槛

高置信结论：

- 延长共同时间、听建议和共同协商不等于 `nx`：99%。
- 主体主动选择对方路线仍是一次自主方向行为：98%。
- 一次关系保全型委托不等于持续方向不占位：99%。
- 关系安全、路线供给撤场、对称交换与方向暂停—方向转交测试均为必要门槛：97%—98%。
- 对象特异性测试可以排除一般依赖和稳定 `nx`：98%。
- 决定返还测试可以区分可撤回委托与持续方向不占位：98%。
- 年龄、监护、危险、照护、任务、资源、专业差、共同结构、习惯、目标融合及原有稳定 `nx` 必须排除：99%。

正式机制未达到95%。目前最多确认：`nz` 可以降低独自定向必要感、提高特定对象路线权重并生成一次关系保全型委托；尚未证明它独立生成持续 `nx`。
