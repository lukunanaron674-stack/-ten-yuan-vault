### 源端点、目标端点与变量

源端点 `zn`：主体在没有奖励、认可、法律义务、亲属职责和结果保证时，仍认为某人或某事不能被抛下。

目标端点 `n`：对象真实进入主体的生活、关系或可用空间，跨阶段停留；主体没有立即推出或转交，而是持续处理其带来的现实负荷。

被改变变量：拒绝权、推出资格、可接收对象范围、留存时间、再次进入资格、外部议题转成内部负荷的程度，以及食物、照护、隐藏、风险与关系负荷的持续处理度。

成立阶段与体量：

```text
A 准入启动：zn 撤回拒绝和推出资格。
B 承载成立：对象跨阶段留存，负荷被持续处理，并保留再次进入或返回位置。
```

只有 A 没有 B，不判完整 `n`。低体量可发生在单个人对单一对象的跨阶段照护；高体量的组织、建筑和可扩容共同体需要另证 `x/xn/zx`。

### 候选机制

#### 候选 A：意义直接重划准入与留存边界

```text
这件事不能被丢下
→ 主体撤回可以拒绝或推出的资格
→ 对象进入内部
→ 下一阶段仍留下
→ 主体持续承担对象产生的负荷
→ n 成立或上升
```

理论后果：`zn` 直接生成的是准入、留存与承担关系，不直接生成房屋、资金、流程、权限和成熟共同体。

#### 候选 B：意义只提供动机，x/xn/zx 才形成 n

```text
zn 提供理由
→ x 提供准入与资源
→ xn 组织持续处理
→ zx 公开推动
→ n 形成
```

理论后果：若所有案例都需要这些中介，`zn 生 n` 只能保留几何压缩。新低权能案例表明，成熟中介可被拿掉，而跨阶段承载仍成立，因此候选 B 不再能解释全部案例。

#### 候选 C：一次心软或善举

```text
主体觉得不能丢下
→ 一次送饭、捐助、藏匿或临时过夜
```

排除。缺少跨阶段留存与负荷处理。

### 正例

1. 《The Kid》流浪汉与弃婴：流浪汉最初试图把婴儿交出去，随后撤回推出选择；在贫困、无正式监护和无成熟制度下跨年承担食物、居住、照护与分离风险。低资源、低制度、无职位命令，完整通过两段式门槛。
2. 《何以为家／Capernaum》赞恩与约纳斯：拉希尔消失后，赞恩没有法律、亲属、资源和职位义务，却继续在极端贫困中寻找食物、移动、照护并承担风险。初始互惠条件失效后承载仍跨阶段继续，支持直接机制。
3. 《小偷家族》治与信代接纳友里：二人发现友里遭虐待后不再把她送回，使她跨阶段获得食物、睡眠、照护和关系位置。房屋是实现条件，但准入启动来自撤回推出资格。

### 反例

1. 一次捐款、送饭、藏匿或临时过夜：缺少完整 `n`。
2. 因法律、亲属、职位或合同义务接收：源端点不是纯 `zn`。
3. 商业旅馆因利润接待：`n` 可成立，但不是由 `zn` 生成。
4. 领袖命令成员收留：优先检查 `zx/nx`。
5. 政府按预算、审批和工程计划建纪念馆：优先检查 `xn/x/zx`。
6. 只有“应该帮助”的言论，未改变准入与留存边界：目标端点不存在。

### 最近邻排除

- 与 `zn 生 zx`：后者改变公开推进与现实权能；本轮改变对象是否进入并留在内部。
- 与 `n 生 xn`：后者从既有承载提炼分工、记录与预案；本轮发生在承载入口。
- 与 `zn 补 x`：补位为已有掌握边界提供意义方向；本轮直接改变准入与留存。
- 与 `n 生 zn`：长期承载沉淀不能放弃的意义，方向相反。
- 与普通善良：一次情绪和一次动作没有持续内部位置。

### 拿掉测试

1. 拿掉 `zn`，若仍因商业、法律、亲属或职位义务接收，不成立。
2. 拿掉第二阶段留存，只剩首次接纳，不判完整 `n`。
3. 拿掉成熟流程，若对象仍留存且负荷持续被处理，关系仍成立。
4. 拿掉房产、资金与正式权限，若主体仍用生活与风险承担接住对象，纯度上升。
5. 拿掉领袖命令与公开推动，若仍撤回推出资格，支持直接机制。
6. 换掉建筑，只要准入、留存和处理关系保持，`n` 仍成立。

三个新案例中，《The Kid》与《何以为家》同时通过低权能、低制度、低资源和跨阶段承载门槛；《小偷家族》作为带既有空间条件的辅助例。

### 反向测试

```text
zn 生 n：不能抛下的意义先成立 → 对象进入并被持续承担。
n 生 zn：对象先长期被接住 → 共同时间与负荷沉淀为不能放弃的意义。
```

两方向可以反馈，但不能因最后同时存在意义与照护就互相代证。

### 动态链后果

```text
这件事不能被丢下
→ 它获得进入资格
→ 下一阶段仍留在内部
→ 我持续承担它带来的负荷
→ 一次接纳变成可持续内部位置
```

改变的是意义如何打开承载入口，并把入口转成跨时间持续的内部位置。不生成建筑、组织、制度、资源成功或永久稳定。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验 `zn` 是否撤回拒绝资格、对象是否真实进入、是否跨阶段留存以及现实负荷是否持续被处理。不能从本体主题、空间主题、贫困题材或家庭题材反推关系成立。
