### 对象分层

- 稳定本体：不因一次收留判人物稳定 `n`；不因一次逃亡判人物稳定 `xz`。
- 当前状态：`n` 此阶段正在接住、保护、补给和处理；`xz` 此阶段危险逼近、退路缩窄、无法稳定停留。
- 行为功能：开门、收留、救治、补给、掩护、值守；逃离、抢窗口、穿越风险路径。
- 光影：暖室、围墙、内部灯光、风雨、追踪光和倒计时只作辅助。
- 场景：家庭、社区、医院、避难所、公路、边境和追捕路线不能替代端点。
- 时间关系：先逃亡后进入某地只证明先后；必须观察危险可到达性或继续移动紧迫度真实下降。
- 关系位置：居民、医生、守门人、接收者、逃亡者和漂流者称谓不能替代实际功能。
- 显影：观察接收范围、抗崩能力、安全停留时间、危险可达性、移动紧迫度和退路宽度。
- 动态链：世界从“所有地方都是下一段逃生路线”转成“终于出现能把危险留在外面的内部”。

### 端点、变量、阶段、体量与显影

- 源端点 `n`：真实运行的承载结构，能接收进入者、提供内部位置、承担保护、照护、补给或处理，并在外部压力下保持一定抗崩。
- 目标端点 `xz`：危险可感知逼近、安全路线减少、无法稳定停留、不行动便会被追上或错过窗口，主体被迫沿风险路径移动。
- 被改变变量：危险可到达性、安全停留时间、继续移动紧迫度、可用退路与安全路径数量、外部冲击直接落到主体的比例，以及主体能否从“通道上的人”变成“内部被接住的人”。
- 成立阶段：`xz` 已显形；`n` 已实际运行；主体进入承载范围；危险可到达性或继续移动紧迫度随后下降。
- 体量：低体量为短时急救、藏身和补给；中体量为安全屋、家庭或社区持续接收；高体量为聚落、后方或保护网络长期吸收风险。
- 显影条件：追兵更难直接抵达，主体得到治疗、休息和安全时间，不必立即寻找下一条路线，或可以反复返回而不是只穿过。

### 候选机制

- A 危险隔离与冲击吸收：`n` 位于危险与主体之间，由墙体、成员、资源或照护能力承担外部冲击。
- B 漂流落地与行动紧迫解除：`n` 提供停留、补给、恢复与返回位置，使主体不再必须抢下一条路线或最后窗口。
- C 拘禁与路径封锁：制度、权限或强权把主体关住；正式排除。“无法移动”不等于“被承载”。
- 统一机制：`n` 一方面替主体承受危险，另一方面提供内部位置，使主体不再必须靠继续移动来维持存在。

### 正例

1. 《最后生还者》乔尔与艾莉进入杰克逊聚落：住房、供电、巡逻、食物、医疗、成员分工和接收关系替二人承担外部风险，长期赶路暂时停止。
2. 《行尸走肉》瑞克一行进入亚历山大安全区初期：围墙、住房、水电、食物、医疗与社区防御先承担外部危险，一行人不再每天寻找临时营地。
3. 运行中的灾后避难所接收洪水与失温中的居民：高地、床位、医疗、食物和值守使居民不必夜间继续寻找路线。

### 反例

1. 签证制度拦住流浪者：属于 `xn/x`，没有接收、保护或安全停留。
2. 收容所把流浪猫关进笼子：若只有捕捉和锁闭，只是拘禁。
3. 恋人让逃亡者不想离开：优先检查 `nz`；危险仍可直接到达。
4. 空房子供一次躲藏：只有空间外观，没有持续承载与处理能力。
5. 监狱终止漂流：强制关闭路径可能反而增强无退路和危险临界。
6. 暴风自行停止：`xz` 自然结束，不依赖 `n`。

### 最近邻

- 与 `nz`：`nz` 改变“我是否想留下”；`n` 改变“这里是否接得住我，所以我能留下”。
- 与 `xn`：门禁、巡逻表、登记和分工只是组织行为；形成真实接收、保护和抗崩能力后才构成 `n`。
- 与 `x`：地盘与权限掌握不等于承载；只排除外人、不承担内部成员，不能判 `n`。
- 与 `zx`：英雄冲入危险把人带走是公开行动；进入持续承载结构后才启动本关系。
- 与 `xz` 自然结束：追兵离开、暴风停止和倒计时结束不属于 `n` 的作用。

### 拿掉测试

1. 拿掉接收、保护和处理能力，只留下建筑，`xz` 若仍同样下降，则不依赖 `n`。
2. 拿掉外部危险，主体本来就能停留，则没有目标端点。
3. 拿掉墙、成员、补给和照护后，主体又必须继续移动，支持本关系。
4. 拿掉情感依恋，主体仍因结构安全而能停下，说明不是 `nz` 替代。
5. 拿掉规则与命令，只要承载仍能运行，关系仍成立，说明不以 `xn/zx` 为必要源端点。

### 反向测试

```text
n 克 xz：承载结构降低危险可到达性、移动紧迫度和漂流强度。

```
