### 对象分层

- 稳定本体：`nz` 是长期保留共同时间、关系余温与可信回返位置；`nx` 是长期不占方向决定位置。一次同行、一次听建议不能反推本体。
- 当前状态：主体在某段关系中不愿结束，并可能暂时沿关系对象给出的方向推进；当前最多支持关系层或状态层候选。
- 行为功能：`nz` 显影为等待、回返、延长共同时间、恢复联系；`nx` 显影为不使用否决、放弃替代路线、沿对方最终方向行动。
- 光影：暖光、旧路、旧物、并肩与跟随构图只作辅助显影。
- 场景：重逢、告别、旅途、旧居、家庭、任务均只是候选场景。
- 时间关系：关系余温先成立，方向让位随后发生；先后不足以证明生成。
- 关系位置：双方必须平等可选，排除年龄、监护、职位、任务、专业与资源依赖。
- 显影：观察主体是否真正退出最终决定位置，而不是只多陪一会、更愿意听建议或共同协商。
- 动态链：从“我仍想让关系继续”推进到“我因此把某一段最终方向交给你”。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `nz`：关系真实存在过，形成共同时间和余温；主体不愿关系或共同阶段彻底结束，并保留等待、回返或继续靠近的位置。
- 目标端点 `nx`：主体原本有可行替代路线和实际否决权；关系对象提出明确方向后，主体不再占最终决定位置并沿该方向推进。
- 被改变变量：独自定向必要感、最终方向认领强度、替代路线保留度、否决权实际使用、跟随是否只在该段关系中出现。
- 成立阶段：`nz` 先成立 → 关系继续与方向竞争发生冲突 → 主体主动减少否决与替代路线使用 → 实际退出最终方向位置 → `nx` 在关系层上升。
- 体量：低体量为一次具体路线让位；中体量为一段关系中反复交出最终方向；高体量会高度混入稳定 `nx`、控制与身份，不宜轻易判定。
- 显影条件：双方平等可选、无现实依赖、无职位差、无危险压迫，且拿掉关系余温后让位消失。

### 候选机制

- A 可信停靠降低独自定向负担：共同时间与回返位置真实存在，使主体不再认为每一步都必须独自决定，暂时接受关系对象已经给出的路线。理论后果：只能先落在关系层或状态层，必须看到最终方向位置下降。
- B 为维持关系主动减少方向竞争：主体判断继续争夺方向会使共同位置断裂，于是主动停止使用否决与替代路线，沿对方方向继续。理论后果：若对方靠威胁、资源或职位占位，则应改查 `x/zx/xn`。
- C 竞争解释：共同时间延长、建议权重上升或双方协商生成新路线。这些只改变停留时间、建议接受度或路线形成方式，不构成单方 `nx`。

### 正例候选

1. 山姆与弗罗多｜进入魔多与末日火山阶段：长期共同旅程形成强关系余温，山姆没有改写最终路线并背负弗罗多继续。限制：守护朋友的 `zn`、既定任务 `xn`、承载照护 `n` 与生存风险过强，无法证明 `nz` 独立生成 `nx`。
2. 《末路浩劫》男孩与父亲｜长期向南阶段：父亲是男孩唯一可信关系停靠，路线由父亲决定。限制：年龄、监护、保护、危险与原本不平等的决定权无法拿掉。
3. 旧友重逢结构例：双方拥有同等可行路线、无资源职位优势；一方仅因不愿关系再次结束而把最终路线交给对方。结构端点清楚，但缺可核验具体作品文本，不能充当第二个正式正例。

### 反例

1. 杰西与席琳继续散步交谈：共同时间延长、路线协商，不是单方方向让位。
2. 关系深厚但双方各自坚持职业和城市路线：`nz` 成立，`nx` 不上升。
3. 接受医生、导师或专业人员安排：专业位置、照护或既有 `xn` 给出方向。
4. 孩子跟随父母：年龄与监护决定路线。
5. 恋人以分手威胁服从：启动源是 `z/x/zx` 压力，不是关系余温。
6. 对方提供住房、钱和安全后留下：现实依赖、`n/x` 混入。
7. 双方共同形成第三条路线：共同协商，不是某一方退出最终方向位置。
8. 主体原本就是稳定 `nx`：关系只提供显影机会，不是生成源。

### 最近邻

- 与 `n`：`n` 改变能否被接住、保护和持续停留；本候选只改变最终方向位置是否让出。有人接住我，不等于我把方向交给他。
- 与 `z 克 nx`：后者是重要确认使主体重新认领自身方向；本候选是没有外部确认或压迫时，主体因关系余温主动少占方向。
- 与 `x/zx`：资源掌握、威胁、显权和关系入口控制导致服从，不属于本关系。
- 与共同协商：协商改变路线形成方式；`nx` 必须看到某一主体不占最终决定位置。

### 拿掉测试

1. 拿掉 `nz` 后仍因任务、年龄、职位、资源、危险或照护同样跟随，则不依赖本关系。
2. 拿掉对方主动占位、命令和威胁后，主体仍因关系余温少占方向，才支持候选。
3. 拿掉现实照护与安全条件后，方向让位仍成立，纯度才上升。
4. 拿掉既有共同时间，只剩一次温柔，源端点消失。
5. 拿掉方向位置变化，只剩陪伴、延长时间和听建议，目标端点消失。
6. 恢复替代路线和否决机会后，主体仍主动不使用，才支持关系层机制。
7. 当前两个具体作品候选均未通过全部测试。

### 反向测试

```text
nz 生 nx：已有关系余温 → 主体降低独自定向必要感 → 暂时沿对方最终方向。
nx 生 nz：主体长期沿对方方向共同生活 → 共同路径积累时间厚度 → 形成不愿结束与回返余温。
```

反向方向更容易找到纯案例，两方向可能反馈，但不能互相代证。

### 动态链后果

```text
我仍想让这段关系继续
→ 我愿意多留一段，并更认真听你的方向
→ 只有当我实际退出最终决定位置
→ 才进入 nz 生 nx 候选
```

改变的是关系中的最终方向认领，不机械生成永久服从、人格软弱、健康关系、正确选择或共同终局。

### 三元与十元并行
