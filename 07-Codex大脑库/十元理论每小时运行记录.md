### 对象分层

- 稳定本体：`n` 是长期让对象或问题落入内部并持续接住、消化；`xn` 是长期主动安排顺序、时间、信息、资源和节点。一次接手或一次排程不能反推稳定本体。
- 当前状态：此阶段正在接收、容纳、照护与处理负荷；随后正在搭流程、排顺序、记录与复盘。状态先后本身不足。
- 行为功能：接手、照护、收容、承担、不推出；分工、排班、记录、交接、预案。行为只作端点证据。
- 光影：室内、后台、包裹面、表格、时钟、路线图只作显影。
- 场景：家庭、医院、救援点、任务控制中心、互助站只是场景候选，不能替代机制。
- 时间关系：承载必须先真实运行，反复或并发负荷随后迫使经验被跨轮次组织。
- 关系位置：照护者、接收者、负责人、调度者等称谓不直接等于十元。
- 显影：观察接收范围、负荷密度、处理顺序、记录连续性、交接能力和人员更替后的运行稳定度。
- 动态链：从“事情落到我这里并被接住”进入“我必须安排它以后怎样继续被接住”，不机械生成制度成功。

### 源端点、目标端点、变量、阶段、体量与显影

- 源端点 `n`：对象或问题已经进入主体或结构内部；主体没有立刻推出、转移或拒绝；允许其停留并持续承担时间、空间、照护、风险或资源负荷。
- 目标端点 `xn`：主体主动组织处理顺序、时间、分工、信息、记录、资源、节点、复盘或预案；规则存在和照章执行均不足。
- 被改变变量：处理顺序、负荷分配、信息跨轮次保存、资源消耗可预判性、再次进入时对临场救火的依赖、人员更替后的持续运行能力、单次接住能否转成可重复承载。
- 成立阶段：n 已运行 → 负荷重复、并发或持续增加 → 临场处理出现遗漏、冲突、浪费或崩溃风险 → 主体主动提炼组织方式 → 组织跨轮次服务于继续承载。
- 体量：低体量为个人用药、复诊与生活顺序；中体量为家庭、救援组或小团队的轮班、库存和交接；高体量为长期共同体把经验固化为训练、程序、档案和抗崩结构。
- 显影条件：必须排除职位制度、利润目标、外部命令、纯效率优化和被动跟随作为真正启动源。

### 候选机制

- A 负荷密度迫使承载组织化：持续接收超过直觉处理能力，若不排列和分工就会遗漏或崩溃，因此主体建立顺序、轮班、资源分配和节点。理论后果：直接变量是继续承载所需的运行组织度。
- B 承载经验沉淀为跨轮次记忆：反复处理相似负荷，若不保存经验就会重复付出代价，因此建立记录、交接、复盘、训练和预案。理论后果：让“这次接住了”变成“下次仍能接住”。
- C 外部制度先行：排除。若上级、法律或既有机构先规定流程，优先检查既有 `xn`、`nx` 跟随、`zx` 命令或 `x` 权限。
- D 利润与效率优化：排除。若启动源是降本增效，主要证明 `xn/x`，不证明 `n` 为源。

### 正例

1. 《阿波罗13号》事故后的 Gene Kranz 与任务控制中心：三名宇航员的生存负荷进入地面团队，团队为继续接住该异常负荷重组问题分工、模拟、耗电记录和返回节点。既有 NASA 制度、Kranz 的 `zx` 与资源 `x` 是第三因素，但具体异常救援结构并非照旧流程机械执行。
2. 《十三条命》确认被困者后的洞穴救援：救援共同体持续承担被困者生存、水位、氧气、潜水员安全和撤离窗口，随后建立潜水路线、氧气布点、人员轮换与撤离顺序。
3. 灾后互助站：先接收撤离者、药品需求与失联信息；人数和事项持续增加后，口头协调开始遗漏，主体建立登记、床位、库存、值班、交接与转介。

### 反例

1. 家庭存在所以自然有家规：可能来自父权、传统、宗教、法律或控制，只是题材共现。
2. 公司为利润建立标准流程：启动源是效率与资源目标，主要属于 `xn/x`。
3. 医院执行国家统一规范：外部制度先于具体承载，属于既有 `xn` 约束内部运行。
4. 母亲预设孩子作息：若不是根据实际睡眠与喂养负荷反复调整，只是 `xn` 直接组织。
5. 一次事故临时分工：只有行为层显影，缺少持续、重复与跨轮次保存。
6. 上级命令团队轮班：启动源是 `zx` 或既有组织，执行者可能只是 `nx`。
7. 仓库有货架、编号和库存表：空间能装东西不等于 `n`，库存系统也不证明承载先发生。

### 最近邻

- 与 `xn` 自身启动：为目标、效率或预判主动搭结构是纯 `xn`；已经接住持续负荷、为了继续接得住才组织运行，才是 `n 生 xn`。
- 与 `zn 生 n`：后者候选改变什么必须被接住；本关系要求对象已经被接住，随后改变运行组织度。
- 与 `zx` 推进：公开权能号召与决定不是本关系必要条件；本关系可以低调发生。
- 与 `nx` 跟随：沿现有班表执行不等于主动决定流程怎样运行。
- 与反向 `xn 生 n`：前者改变运行组织度；反向改变承载容量、接收范围与抗崩能力。

### 拿掉测试

1. 拿掉 `n` 后，流程若仍会因利润、法律、目标或命令同样出现，则不依赖本关系。
2. 拿掉持续负荷，只保留容器与成员，组织若仍同样形成，只是场景共现。
3. 拿掉外部制度与命令后，承载主体仍主动排列、记录和分工，支持直接机制。
4. 拿掉跨轮次保存，只剩一次临场协调，通常不足以构成目标 `xn`。
5. 拿掉主动组织，只剩“大家都很忙”，目标端点不存在。
6. 拿掉承载对象，组织失去具体服务对象与运行理由，说明 `n` 是关键启动条件。

### 反向测试

```text
n 生 xn：承载已经成立，反复负荷使运行组织度上升。
xn 生 n：流程、排班与资源配置先成立，使接收范围、承载容量和抗崩能力上升。
```

两个方向可以形成反馈，但目标变量不同，不能互相代证。

### 动态链后果

```text
事情已经落到我这里
→ 我先接住
→ 同类负荷不断进入
→ 只靠当场反应会漏、会乱、会垮
→ 我把经验变成顺序、记录、分工和节点
→ 以后仍能继续接住
```

改变的是从厚重、即时的承载，进入能够穿过时间持续运行的结构。不机械生成官僚制度、高效率、控制欲、永久稳定或所有家庭与医院的规则。

### 三元与十元并行

三元只核验作品整体精神运动；十元只核验 `n` 是否先真实接住、负荷是否重复或并发、`xn` 是否由主体主动组织、变量是否落在运行方式。空间主题与时间主题并行，不能用“空间→时间”反推本关系。

### 95%门槛

- 99%：家庭、医院或容器与规则共现不能证明生位。
- 99%：目标端点必须是主体主动组织，而不是规则存在。
- 98%：必须排除外部制度、职位命令、利润效率和 `nx` 跟随。
- 98%：变量应落在顺序、分工、记录、节点与跨轮次运行能力。
- 97%：负荷密度与承载记忆可统一为完整直接机制。
- 97%：两个具体事件案例与一个结构例通过最近邻、拿掉与反向测试。

结论：97%正式锁定。无需新增待用户确认问题。
