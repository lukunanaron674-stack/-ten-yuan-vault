# 马谡街亭｜只改一个关键根节点，何时足以进入 xn 结构重设？

## 1｜本轮问题

上一轮关羽华容道已经锁定：

```text
只改一个极关键的最终处置节点
+ 其余位置、兵力、协同、路线与持续流程未重建
→ 当前最终执行层 nx 可退出
→ 但不足以自动锁 xn 方案重设
```

本轮用马谡街亭做直接反向最小差异：

> 同样可以把变化追到“一个根关键节点”，但这个节点一改，是否会迫使资源、协同、风险与后续运行结构一起重新绑定？

如果会，则 xn 的门槛不能按“改了几个节点”计数，而应看改动有没有产生结构传播。

## 2｜剧情事实

诸葛亮给马谡二万五千精兵，并令王平相助，同时给出明确运行约束：

1. 下寨必须在要道，使魏军不能轻易通过；
2. 安营后绘制四至八道地理图本回报；
3. 凡事与王平商议停当，不可轻易自专。

马谡到街亭后，首先改变的根节点可以压成一个：

```text
原关键节点：五路总口 / 要道下寨
↓
马谡改为：侧边孤山 / 山上屯军
```

但这个位置变化不是孤立微调。它立即传播到整个运行结构：

- 防守对象从“封住交通要道”改成“凭高临下、诱敌围山后死战”；
- 水源从正常防守条件变成可被敌军切断的关键生存资源；
- 王平提出的平地要寨协同不再能按原方案工作；
- 马谡进一步把五千兵拨给王平另寨，主力与副部的空间/协同结构发生分裂；
- 原本的成功条件“守住要道使敌不能偷过”被替换为“敌来围山后凭高死战破敌”；
- 原方案无法在同一骨架下继续运行。

随后魏军据此围山并断绝汲水，街亭失守。胜败不是十元判据，但它反向证明这些结构变化真实进入了战场运行，而不是马谡只在口头上换了一个地名。

## 3｜nx 判断

### 上位任务层：成立

“守街亭、服务蜀军北伐”这个最高任务仍来自诸葛亮，马谡没有把上位战略目标改成别的任务。

因此：

`nx_upper_task_relation: evidence-locked`

### 具体运行方式层：排除为主判

马谡没有沿诸葛亮给出的“要道下寨 + 与王平协同”的关键骨架续接，而是在真实低成本重设窗口里主动改掉根位置，并让整个战术运行随之改写。

因此：

`nx_in_operational_method_layer: rejected_as_primary`

不能用“上级给了守街亭任务”覆盖下位运行层的自主重构。

## 4｜xn 判断

本轮锁定：

`xn_structural_rewrite_in_operational_layer: evidence-locked`

关键理由不是“马谡改了很多东西”，而是：

```text
一个根关键节点被替换
↓
资源条件重新绑定
+ 协同接口重新绑定
+ 兵力分布重新绑定
+ 成功/失败条件重新定义
+ 原方案无法按旧骨架继续
↓
= 结构传播
```

因此，一个节点也可以足以触发 xn；前提是它是运行骨架的锚点，改变后会迫使依赖结构重组。

## 5｜zx 判断

排除为主判。

马谡以主将身份压过王平意见、调兵上山，使用的是本次任务已经授予的局部指挥接口。没有证据显示他因此取得了更高、可持续调用的新军政决定范围，也没有让诸葛亮或蜀军体系承认新增的马谡最高权力接口。

因此：

`zx_in_narrow_stage: rejected_as_primary`

“违令、主意大、能压副将”都不是 zx 的充分条件。

## 6｜与关羽华容道的最小差异

### 关羽

```text
改动节点：曹操最终放 / 不放
位置、兵力、埋伏、协同与前段流程：基本不变
后果：一次终局裁定被否决
结构传播：无
→ nx最终执行层退出
→ xn方案重设不成立
```

### 马谡

```text
改动根节点：在哪里下寨
位置改变后：水源、兵力、王平协同、战斗逻辑、成功条件全部重新绑定
结构传播：有
→ 当前运行层 nx 下降
→ xn结构重设成立
```

所以：

> **xn 的阈值不是“节点数量”，也不是“这个节点听起来有多重要”，而是这个改动有没有结构传播性。**

## 7｜关键压力

压力来自：

- 街亭是北伐交通咽喉；
- 司马懿、张郃逼近；
- 诸葛亮已给明确运行约束；
- 王平在现场持续提出低成本纠错。

这些压力提高了重设行为的可观察性，但不直接决定十元。

## 8｜拿掉测试

### 拿掉最终失败

假设马谡山上屯兵最后获胜，只要“改位置 → 资源/协同/成功条件随之重组”的事实仍在，xn 判断不变。

### 拿掉王平反对

证据略弱，但诸葛亮出发前已明确要求要道下寨与协同；马谡仍然改变根节点并重组运行，核心结论仍成立。

### 拿掉后续五千兵分寨

如果改成山上屯军却仍能完整保留原要道封锁、王平协同、水源与成功条件，则 xn 会下降。正是现实中这些依赖结构无法保持，才使“改驻营点”成为结构性重设而非普通执行自由。

## 9｜反向测试

### 反向成“单节点但非 xn”

如果主体只改变最终裁定，或只换一个不影响资源、协同、成功条件和后续流程的节点，原方案仍可按同一骨架运行，则应像关羽华容道一样：不自动锁 xn。

### 反向成 nx

如果马谡按要道下寨，与王平商议并沿既定防守骨架推进，即使自己微调营门、巡逻或交战节奏，仍应优先 nx。

### 反向成 zx

只有马谡借此公开取得此前没有的更高军政决定范围，并让组织承认该新增接口，才检查 zx。

## 10｜最近邻排除

### nx vs xn

```text
nx：主体沿外部关键运行骨架推进。
xn：主体使关键运行依赖重新绑定，旧骨架不能原样继续。
```

本轮最小判据是“结构传播”，不是动作数量。

### xn vs 一次裁定 / 否决

一次最终裁定可以很重要，但若不导致持续运行结构重组，仍不足以锁 xn。关羽华容道就是负控制。

### xn vs zx

结构重组回答“怎样运行”；zx 还要求主体的现实决定范围发生扩权。马谡没有后者。

### nx vs xz

魏军逼近与断水风险属于危险压力，不能替代运行权来源判定。

## 11｜第三因素冻结

冻结：

- 马谡傲慢、自负、熟读兵书；
- 诸葛亮是否用人失误；
- 王平能力高低；
- 街亭最终胜败；
- 马谡军令状与后续死刑；
- 蜀魏立场与历史评价。

只保留：

```text
外部原方案骨架是什么？
主体真正改了哪个根节点？
这个节点改变后，哪些依赖结构被迫重新绑定？
旧方案还能否按原骨架运行？
主体有没有取得更高权限？
```

结论不变。

## 12｜本轮新增边界

可靠新增：

```text
“替换一个关键节点”本身既不是 xn 的充分条件，也不是不足条件。

真正门槛：
关键节点变化
+ 依赖结构发生传播式重组
+ 旧方案无法按同一决定性骨架继续
→ xn 显著上升
```

因此现有待审议中的“替换关键节点”应始终与“旧方案在关键结构上能否原样运行”绑定阅读，不能单独拿出来做关键词判定。
