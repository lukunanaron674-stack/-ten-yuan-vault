# 刘备入川援刘璋至自领益州牧｜zx↔nx 分层授权越界扩权压力测试

## 结论

本轮锁定：

> 刘备最初进入西川，是在刘璋明确邀请、供给、并委托拒张鲁的外援/任务关系中进入，前段存在真实 `nx` 授权入口；到葭萌关后，在被委托的拒张鲁对象域内拥有局部军事调用，可形成局部 `x`。但第62回双方公开决裂后，刘备不再沿刘璋的授权边界续接，而是攻取关隘、城池，最终第65回进入成都、自领益州牧，并处分刘璋去向、益州官员与府库资源。决定范围从“受邀外援/边防任务”扩展到“整个益州最高军政处分”，因此后段 `zx` 独立高显影。

本轮不锁刘备稳定人物本体，不锁严格 `zx↔nx` 补关系。

## 1｜剧情事实

### 前段授权 A

第60回刘璋为防张鲁，正式修书请求刘备兴师入川；同时遣孟达领兵迎接，并准备大批军马、资粮、钱帛接应。第61回张鲁欲犯葭萌关，刘璋再次明确请刘备前往拒守，刘备领诺并率本部到葭萌关。

因此前段的对象层不是“刘备自己宣布有权进入益州替刘璋布防”，而是：

```text
刘璋给出入川外援/拒张鲁任务
→ 刘备接受
→ 实际进入葭萌关履行
= nx 授权入口
```

授权完成后，在“葭萌关拒张鲁”这一局部任务对象层，刘备拥有现场兵力与指挥调用，可记局部 `x`。

### 决裂

第62回刘备向刘璋索取更多精兵、钱粮，刘璋只给老弱军四千和较少粮米，并命杨怀、高沛紧守关隘。刘备撕毁回书；刘璋随后认定刘备欲夺其基业，下令各关添兵，不许荆州一人一骑入关。双方由“外援授权关系”转成明确敌对。

### 后段对象域 B

刘备随后攻取涪水关、雒城等益州节点。第65回刘璋投降后，刘备进入成都公厅，益州官员拜于堂下；刘备迁置刘璋，自领益州牧，重新任用降臣、升赏旧部、调用府库、开仓赈民。

结果：

```text
原授权对象域 A：入川外援 / 拒张鲁 / 葭萌关边防
↓
刘璋明确撤回合作并转为阻止
↓
刘备继续推进
↓
新对象域 B：成都 + 益州最高人事、行政、府库、旧主处分
↓
B 最终稳定进入刘备现实决定范围
= zx
```

## 2｜nx 判断

### 2.1 前段成立

刘备进入益州、取得入川援军身份与葭萌关拒敌任务，并非自己单方面使之成立。刘璋真实拥有“邀不邀请、给不给兵粮、让不让其进入本州承担防务”的外部接口，刘备也实际承接并履行，因此前段 `nx_prior_invited_aid_entry` 锁定。

### 2.2 后段退出

第62回刘璋已经公开切断继续合作的方向：限制兵粮、紧守关隘，并随后明确下令阻止荆州军继续进入。此后刘备攻关取城，不再是沿刘璋既有授权通道续接。

所以不能写成：

> 因为最初是刘璋请进来的，所以刘备后来取得整个益州仍是 nx。

入口关系不能无限污染后续对象层。

## 3｜zx 判断

后段满足 zx 的独立硬证据：

1. **旧权限边界清楚**：原任务是作为外援拒张鲁，而非处分整个益州。
2. **B 明确不在旧授权内**：刘璋与臣下公开反对刘备夺取基业，并实际设关阻止。
3. **主体公开把权能推进 B**：攻取关隘、城池并进入成都。
4. **外部秩序真实响应**：刘璋体系军事抵抗、守将防御，最终投降；益州官员转入新秩序。
5. **决定范围真实扩大并稳定**：刘备自领益州牧，实际处分刘璋、官员、旧部、府库与百姓资源。

因此本例不是“违令”或“把已有军权用得很猛”，而是：

> **从受邀外援/边防任务的 A 对象域，推进到整个益州最高军政处分的 B 对象域，并让 B 稳定成为现实权限。**

`zx_beyond_invited_aid_boundary: evidence-locked`。

## 4｜关键压力

- 张鲁威胁使刘璋开放刘备入川接口；
- 刘璋内部黄权、王累等明确反对，证明“把益州交给刘备”并非原授权内容；
- 第62回兵粮争执与刘璋设关使原合作关系正式断裂；
- 后续军事抵抗使 B 对象域不是形式赠与，而是主体在外部反对下推进并最终成立。

压力只用于显影，不把“战争胜利”本身当 zx。

## 5｜拿掉测试

### 拿掉最初刘璋邀请

若刘备一开始就是自主侵入益州，则后段仍可能是 zx，但本例不再承担“授权后越界”的最小差异。

### 拿掉刘璋明确反对/设关

若刘璋后来主动把整个益州最高处分权正式转交刘备，则更接近权力交接，必须重新检查 nx→x，而不能用本例高纯锁“越授权”。

### 拿掉第65回现实处分

若刘备只攻入成都但马上被赶走，或不能处分益州人事、府库与旧主，则只能证明扩权尝试，不能锁新的 B 权限已经稳定成立。

### 拿掉战争胜负

只要仍能观察到“B 最终真实成为刘备稳定决定范围”，zx 结论不依赖单场战役胜负。

## 6｜反向测试

### 授权内高强使用，非 zx

```text
刘璋请刘备守葭萌关
→ 刘备在葭萌关主动排兵布阵
→ 甚至违背某个具体建议
→ 仍只处分被交付的边防任务
= x/xn 邻近
≠ zx
```

### 真正授权后越界 zx

```text
授权 A
→ B 明确不属于 A
→ 原权限节点真实反对/阻止
→ 主体公开推进 B
→ 原结构无法把 B 压回
→ B 稳定进入主体现实决定范围
= zx
```

刘备本例属于后者。

## 7｜最近邻排除

### zx vs x

葭萌关任务授权完成后的现场兵力调用是局部 `x`；取得整个益州的最高处分范围则超过该基线，属于后段 `zx`。

### zx vs xn

庞统、诸葛亮的攻蜀计策与刘备的军事组织可形成 `xn` 邻近，但这只解释“怎样夺益州”，不替代“决定范围从 A 扩到 B”的 zx 主变量。

### zx vs nx

前段入川授权是 `nx`；后段刘璋已经公开反对并封锁接口，刘备不再沿其权限通道续接，因此后段不能延续 nx 主判。

### zx vs 强弱/胜负/身份

刘备是皇叔、刘璋软弱、刘备最终胜利，都不是判据。冻结这些标签后，只看授权对象域与现实决定范围变化，结论不变。

## 8｜第三因素冻结

冻结：刘备仁德主题、同宗身份、张松法正内应、庞统诸葛亮智谋、战争胜负、刘璋性格评价。

只保留：

- 原授权 A 是什么；
- B 是否明确不在 A；
- 原权限节点是否真实反对；
- 主体是否仍公开推进 B；
- B 是否最终稳定进入主体现实决定范围。

结论保持 99/98。

## 9｜与既有控制的最小差异

### 马谡街亭

```text
已有主将 A 权限
→ 在 A 内违令、改方案
→ 仍只处分街亭守备对象
= x + xn
≠ zx
```

### 凯撒

```text
高卢军权 A
→ 越入意大利 B
→ 原结构反对
→ B 进入现实控制
= zx
```

### 路易-拿破仑

```text
宪法总统权 A
→ 突破明文禁止的议会/宪制 B
→ 原结构拒绝
→ B 后来制度化
= zx
```

### 刘备

```text
入川外援/拒张鲁 A
→ 夺取益州最高处分 B
→ 刘璋体系明确反对
→ B 最终稳定成立
= zx
```

因此当前案例级边界进一步支持：

> **“授权后越界”是否构成 zx，不看是否违令、是否强势，而看决定范围是否跨出原授权对象域，并在外部反对下使新对象域成为稳定现实权限。**
