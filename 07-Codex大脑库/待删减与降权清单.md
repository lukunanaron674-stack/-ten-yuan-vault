# 待删减与降权清单

## 使用规则

这里不是垃圾桶。

这里是 Codex 判断“哪些内容不该继续占高权重”的缓冲区。

进入这里的内容不会立刻删除，只会先标记原因。

## Codex 自主权

删减规则由 Codex 自己执行。

Codex 可以主动做四类动作：

1. **降权**：内容保留，但不作为核心判断依据。
2. **合并**：重复内容合入更清晰的主文件。
3. **隔离**：疑似污染内容移入待二审、废案或旧库。
4. **建议删除**：确认无价值、重复且污染检索时，列入删除建议。

默认动作顺序：

```text
标记 -> 降权 -> 合并 / 隔离 -> 建议删除
```

除非用户明确授权批量清理，否则 Codex 不直接大规模物理删除文件。

## 降权原因类型

- 重复：已有更清晰版本。
- 弱链：只有感觉，没有动态链。
- 弱证：缺少作品或场景证据。
- 误判：疑似五维倒推十元、zn 默认起手、n 默认承载。
- 过时：被新版本规则替代。
- 污染：会误导后续判断。
- 素材化：适合当素材，不适合当理论。

## 当前待观察

### 1. README 编码异常

文件：`README.md`

降权类型：过时 / 编码污染

原因：当前读取显示为乱码，说明可能存在编码问题。它不适合作为 Codex 第一入口，否则会污染索引理解。

建议处理：保留原文件，后续新建或修复一个 UTF-8 版 README / 总入口。

### 2. 根目录超长标题文件

文件：根目录下“我觉得可以搞成3个方向...”长文件名 markdown

降权类型：文件名污染 / 待整理

原因：内容本身很重要，是三方向蓝图的原始表达；但文件名过长，影响检索、Git、阅读和后续自动化。

建议处理：保留内容，后续合并进 `07-Codex大脑库/给你看的大脑报告.md` 或改名为 `三方向总蓝图_原始笔记.md`。

### 3. 重复旧库与银矿素材

位置：`05-银矿库/00-待二审散点池`、`06-旧库迁入`

降权类型：重复 / 弱证 / 待二审

原因：其中存在大量“完成入库”“钧已评价”“奶白素材”混合文件，可能有重复版本、旧评分、未统一字段。

建议处理：不删。先由 F12 反例与误判清理框抽取重复清单，再决定合并或隔离。

下一步由 Codex 在阅读旧库、银矿库、F12 输出时逐步填入。
