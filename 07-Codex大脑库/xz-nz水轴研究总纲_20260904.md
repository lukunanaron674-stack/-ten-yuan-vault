### 《Homunculus》名越进｜第1—2卷开颅实验阶段

研究问题：高危险、不可逆、主动进入危险程序是否足以构成 current xz？

- 终点前置：不足；一次实验结果风险不等于未来终点先取得结构地位。
- 方向被未来规定：不足；经济压力、报酬与实验提案即可解释主要方向。
- 路径持续收窄：不足；没有形成多个真实可选未来逐步关闭的过程。
- 路径汇流：不足；没有“换路仍回到同一终点”的可验证结构。

## 4｜第四轮：第一份 current pure nz 高纯伪例护栏

### 《葬送的芙莉莲》芙莉莲 / 辛美尔｜葬礼后履行旧同伴遗愿

#### 研究问题

> “旧关系仍能继续产生现实行动功能”是否足以证明“双方仍存在可现实重新进入的关系位置”？

本轮复验行为库历史 `FR-001`。旧记录事实层保留，不修改行为库；本轮只在水轴 L4 按 current `nz v2.0` 重新判定稳定关系端点。

#### 事实骨架

- trigger：辛美尔去世，旧勇者队共同旅程在人际层结束；
- actor：芙莉莲；
- action：参加葬礼，并在迟到理解后继续履行旧同伴遗愿；
- object：辛美尔、旧勇者队及遗愿留下的继续接口；
- object_layer：旧对象特异关系在对象本人死亡后，是否仍保有双方现实退出/重入与修复资格；
- changed_variable：旧共同功能从现实共同生活转为遗愿、记忆与后续行动接口；
- observable_result：旧关系继续影响芙莉莲的现实旅程，但辛美尔本人无法再作为现实关系主体重新进入该关系。

旧 `FR-001` 的事实与行为层判断曾把“已结束关系仍保留对象特异、可继续调用的共同功能”归为 `nz`、置信度 96；该事实层仍可保留。但 current `nz v2.0` 比“功能接口延续”多了一道不可省略的现实门：稳定 nz 必须具有双方现实退出自由、现实回返路径，以及回来后重新接近/修复的能力；只有单方怀念或遗留接口不能自动锁 stable nz。

#### current nz 独立门

1. **对象特异：通过。** 被测对象明确是辛美尔/旧勇者队，不是任意替代关系。
2. **真实共同关系：通过。** 旧勇者队共同旅程曾现实成立。
3. **自由退出：不构成决定性支持。** 本例的关系结束来自死亡，不是双方仍存在的现实退出/重入资格。
4. **现实回返：失败。** 辛美尔本人已死亡，原对象本人无法在分离后现实重新进入该关系。
5. **修复/重新接近：失败。** 后续可以继续理解、履行遗愿、访问记忆或寻找与亡者相关的目的地，但这些不能让原双方在同一现实关系层重新建立可信接近。
6. **双方性：失败。** 后续现实动作主要由芙莉莲单方继续完成；旧对象留下的遗愿/记忆可作为 relation interface，但不是双方当前可调用的 bilateral reentry。

#### current window

```text
A：芙莉莲 ↔ 辛美尔 / 旧勇者队关系曾现实成立
→ B：辛美尔死亡，原共同关系的人际共同生活终止
→ C：遗愿、记忆与旧共同功能继续影响芙莉莲现实行动
→ D：原对象本人仍无法现实重新进入、回应并修复同一关系
```

#### 最近邻

- `nz candidate / legacy relation residue`：对象特异与旧共同关系都很强，所以非常容易看起来像 nz；真正缺口是 bilateral reality-returnability。
- `nx`：接受旧同伴/艾泽给出的路线时，沿既有外部通道推进可单独归 nx；不能因为目的与辛美尔有关就把路线动作倒贴为 nz。
- `xn`：把遗愿组织成可持续旅程步骤时可出现流程端，但不是本轮被测关系回返变量。
- 记忆/纪念/遗产接口：可以长期保存对象特异意义，却不等于双方仍有现实重入资格。

#### 拿掉测试

拿掉“辛美尔很重要”“葬礼很悲伤”“旧关系仍影响人生”这些主题和情绪，只保留：

```text
对象特异旧关系真实存在
＋ 对象本人死亡
＋ 遗愿/记忆接口继续产生现实行动
＋ 原对象本人无法现实重入、回应、修复
```

stable `nz` 不成立；成立的是 **legacy relation interface continuation**。

#### 反向测试

若对象不是死亡，而是现实分离后双方仍自由存在；随后双方主动再次接触、相互回应并恢复可信共同节奏，则 pure `nz` 应上升。Hiccup ↔ Toothless 已提供这条正向最近邻。

#### 第三因素冻结

- 遗愿：解释为什么旧关系继续产生行动，不生成 bilateral reentry；
- 记忆与悼念：解释对象特异意义保存，不生成双方现实关系资格；
- 灵魂安眠之地/再次对话目标：属于后续路线与世界设定接口；在真正现实、双向重新进入发生前，不可事后回填为此前已经稳定存在的 nz；
- 长寿与迟到理解：解释体验差异，不是关系回返本体。

## 6｜第三轮：第一份 current pure xz verified positive

### 《Steins;Gate》冈部伦太郎 / 椎名真由理｜α吸引域反复救援窗口

#### 研究问题

> “知道有人会死”与“多个真实替代路径都持续汇回同一前置终点”之间，最小差异在哪里？

本样本只测试 `xz`。Mayuri 与 Okabe 的关系本身不在本轮测试 `nz`，因此不因对象特异情感、童年关系或救援动机倒推水轴另一端，也不测试 strict `xz↔nz`。

#### 事实骨架

- trigger：Mayuri 首次在 Rounder 袭击中死亡后，Okabe 启动 Time Leap，反复返回死亡前窗口尝试改变结果；
- actor：Okabe（行动主体）；被测 trajectory object：Mayuri 在 α attractor field 内的近期生死结果；
- action：多次 time leap，并改变离开实验室、交通路线、风险规避方式及救援安排；
- object_layer：同一 attractor field 内“Mayuri 是否在该收束时间窗死亡”的未来结果层；
- changed_variable：具体死亡路径、地点、直接原因和 Okabe 的救援方案不断变化；
- observable_result：具体路径变化，但 Mayuri 的死亡在不同 world line / 尝试中反复兑现；随后 Suzuha 明确说明要救 Mayuri 必须逃离 α Attractor Field、跨过 1% divergence，而不是继续在同一吸引域内部只换局部路线。

事实依据：Crunchyroll 第13—14集公开简介确认 Okabe 因 Mayuri 死亡而 time leap 回到过去并反复尝试纠正结果但失败；公开 episode synopsis 与世界线说明记录 Mayuri 在不同尝试中以不同方式死亡，并把 α attractor field 的 convergence 解释为同一结果在不同 world line 中反复汇合。以上只作 L4 案例事实来源，不作 canonical 来源。

#### current xz 主骨

1. **终点前置：通过。** 首次死亡之后，后续每次 leap 的 current window 都已经以“Mayuri 将在该吸引域的近期窗口死亡”为前置未来终点；这个终点先于后续救援行动取得结构地位。
2. **方向被未来规定：通过。** Okabe 的当前行动排序几乎全部被这个未来节点重排：离城、换交通方式、规避 Rounder、重新安排救援都围绕终点展开。
3. **路径持续收窄：通过。** 每次失败都现实排除一个“仅修改局部路径即可脱离死亡”的候选方案；有效选项从大量局部改法逐步缩到“必须改变世界线/吸引域层级”。
4. **路径汇流：强通过。** Moeka/袭击、交通与事故等具体路径可以改变，但结果仍不断汇回 Mayuri 死亡；这是 current xz v2.2 最关键的“改走另一条路仍回到同一终点”现实测试。
5. **临界逼近：通过。** 每次 leap 都重新进入有限的死亡前窗口，救援时间和有效选项被同一临界节点压迫；结果尚未发生时已经规定当前行为。
6. **不是一次性不可逆决定：通过。** 本样本正好与 Homunculus 对照：不是一次选择之后退路变少，而是多轮真实替代路径被逐次尝试并否决。

#### current window

```text
A：Mayuri 首次死亡，未来终点获得结构地位
→ B1：Okabe time leap，改变局部救援路径
→ 终点仍兑现
→ B2/B3/...：继续更换交通、逃离、规避与干预方式
→ 具体路径不同，但终点继续汇流
→ C：局部方案集合被现实压缩
→ 必须改变 attractor field / world-line 层级才有可能解除该终点
```

#### 最近邻

- `z`：单独“死亡时间点/截止点”只是节点；本样本之所以是 xz，在于这个未来节点提前支配多轮 current action，并让不同路径反复汇流。
- `zx`：Okabe 的 time leap 与干预是主动外推因果手段，但它们没有解释为什么不同外推仍回到同一结果；被测变量是未来终点对路径空间的收束。
- `xn`：attractor field / world-line 规则可作为流程结构解释层，但“规则存在”本身不是 xz；本轮只计规则现实表现为多个可选路径持续压向同一未来终点的部分。
- `x`：Rounder、枪击、事故等直接危险可以变化，拿掉某一具体危险仍保留死亡收束，因此不靠单一当下危险成立。
- `nz`：Okabe 与 Mayuri 的关系解释为什么他持续救援，不解释为什么替代路线继续汇回同一死亡终点。

#### 拿掉测试

拿掉枪、SERN、Moeka、某一种死亡方式、悲伤演出和“青梅竹马”关系标签，只保留：

```text
已知未来终点
＋ 多次真实回到终点前
＋ 每次改变不同路径
＋ 不同路径仍兑现同一终点
＋ 局部方案逐次被现实否决
```

`xz` 主骨仍成立。

若拿掉“同一终点反复汇流”，只剩某次危险或一次失败，则 pure xz 明显下降。

#### 反向测试

若 Okabe 改变任一普通局部路径后，Mayuri 的死亡窗口便稳定消失，或不同路线导向多个等价未来而没有同一结果回收，则 `xz` 应显著下降。实际 α attractor field 窗口恰好相反：局部路径改变不足以解除同一终点，必须跨越更高层级的 world-line/attractor-field 条件。

#### 第三因素冻结

- SERN/Rounder：能解释部分具体死亡路径，不足以解释无 Rounder 直接完成时仍发生的结果汇流；
- Okabe 的救援意志：解释为何不断尝试，不解释为何尝试空间被同一未来结果压缩；
- Time Leap Machine：提供反复测试接口，不生成收束终点；
- attractor-field 规则：是该作品内实现命运收束的制度/世界机制载体，应保留为 mechanism，不把“有设定规则”本身偷换成 xz；真正计入 xz 的是它对具体 trajectory 的可观察结果：不同现实路径持续汇回同一未来节点。
