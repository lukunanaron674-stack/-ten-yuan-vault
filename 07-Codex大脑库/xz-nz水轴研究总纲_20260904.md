## 3｜第一轮：pure xz 高纯伪例护栏

### 《Homunculus》名越进｜第1—2卷开颅实验阶段

研究问题：高危险、不可逆、主动进入危险程序是否足以构成 current xz？

事实骨架：汽油/金钱耗尽后，伊藤提出 70 万日元开颅实验；名越从不理会到接受实验并进入手术。对象层是一项身体处置决定与实验交易，现实结果是接受 trepanation，后续出现异常知觉。

current xz 独立门：

- 终点前置：不足；一次实验结果风险不等于未来终点先取得结构地位。
- 方向被未来规定：不足；经济压力、报酬与实验提案即可解释主要方向。
- 路径持续收窄：不足；没有形成多个真实可选未来逐步关闭的过程。
- 临界不断逼近：不足；更接近一次决策后进入手术，而非持续收束轨迹。

最近邻：`x` 身体处置边界、`nx` 沿外部提案行动、`z` 一次关键节点，以及 `xz_firepowder` 危险显影均需要排除。

拿掉测试：拿掉手术刀、开颅、异常视觉和阴暗题材，只剩“经济压力下接受一次付费人体实验”，current xz 主骨不再可见。

反向测试：若明确未来终点先成立，之后现实替代方案逐一失效、退出窗口持续关闭、不同选择不断汇回同一终点，xz 才上升。

第三因素：汽油耗尽、金钱耗尽、70 万日元报酬、伊藤掌握实验信息、实验性诱因。

锁定护栏：

> **高危险 / 不可逆 / 主动进入危险程序 ≠ current xz。**

> **一次“已经无法轻易回头”的决定 ≠ “未来终点先取得结构地位并让路径持续收窄”。**

## 4｜nz 历史记录的 revalidation 入口


## 5｜第二轮：第一份 current pure nz verified positive

### 《How to Train Your Dragon: The Hidden World》Hiccup ↔ Toothless｜告别后约十年再会

#### 研究问题

> “关系很深 / 会怀念”与“双方在长期真实分离后仍保有可调用回返位置”之间，最小差异在哪里？

本样本只测试 `nz`，不因作品同时有危险、未来、告别等内容倒推 `xz`，也不测试 strict `xz↔nz`。

#### 事实骨架

- trigger：击败 Grimmel 后，Hiccup 认识到龙在人类世界仍不安全，主动让 Toothless 与其他龙进入 Hidden World；
- actor：关系主体 Hiccup / Toothless；
- action：双方完成现实告别并长期分离；约十年后 Hiccup 带 Astrid 与孩子来到 Hidden World 边缘，重新与 Toothless 接触；
- object：Hiccup ↔ Toothless 这段对象特异关系；
- object_layer：长期伙伴关系的退出、保留与重新进入资格；
- changed_variable：关系从日常共同生活转为长期分离，再从分离状态恢复现实接近；
- observable_result：Toothless 在重新识别 Hiccup 后恢复身体亲近，Hiccup 家人与 Toothless 家族接触，并再次共同飞行。

事实来源：DreamWorks 官方 franchise material 将 Toothless 定义为 Hiccup 的 best friend / human teammate；DreamWorks《Homecoming》官方说明明确把故事放在《The Hidden World》结尾后约十年的时间窗口，并继续称二者为 special relationship；《The Hidden World》公开剧情资料记录结尾的告别、十年后访问、识别与再次共同飞行。该材料用于 L4 案例事实，不作为 canonical 来源。

#### current nz 六项门

1. **对象特异：通过。** Toothless 不是“任意一只龙”，Hiccup 也不是“任意一个维京人”；二者在系列中具有持续、相互识别的伙伴关系。
2. **关系证据：通过。** 分离前已有长期共同生活、训练、飞行与互相救援的共同历史。
3. **自由性：通过。** 最终分离不是由一方扣留、职位、资源或生存控制强迫对方留在关系中；Hiccup 主动解除日常占有/共同生活形式，Toothless实际离开并建立自己的家庭。
4. **回返性：通过。** 长期分离后，双方仍存在现实可调用的重新接触路径，而不是只剩怀念或遗物。
5. **修复/重新接近：通过。** 再会时存在短暂识别距离，随后恢复身体接近、家庭介绍与共同飞行，关系不是只恢复“旧搭档”称谓壳。
6. **非单方想象：通过。** 回返由双方实际互动完成。

#### current window

```text
A：共同生活/伙伴关系已现实成立
→ B：主动告别、约十年真实分离，各自建立生活/家庭
→ C：现实再会、相互识别、重新接近并共同飞行
```

关键不是 A 的感情强度，而是 B 后仍能实际进入 C。

#### 最近邻

- `n`：照护、承载不是主变量；长期分离期间没有靠持续内部承载维持关系。
- `x`：Hiccup 最终恰恰放弃把 Toothless 留在自己治理/调用范围内；若必须扣留才能维持，反而违背本样本。
- `z`：再会不是为了取得重要主体认可；关系本身的回返资格才是被测变量。
- `nx`：Toothless 并非因不占方向而被动沿 Hiccup 路线返回；长期分离期间双方各自生活。
- `xz`：危险和人龙安全问题解释为什么分离，却不能解释“十年后仍能重新进入同一对象特异关系”。

#### 拿掉测试

拿掉 Grimmel、战争、龙族安全危机、怀旧色调、婚姻/亲属称谓与结尾感伤，只保留：

```text
对象特异长期伙伴
→ 自由分离并各自生活多年
→ 之后双方现实重新接触
→ 恢复可信亲近与共同活动
```

`nz` 主骨仍成立。

#### 反向测试

若 Toothless 明确拒绝重新接触，或 Hiccup 只能靠捕获/控制把其带回，或十年后只有 Hiccup 单方怀念而无现实互动，则 stable `nz` 应下降。本片实际结果与这些反向条件相反。

#### 第三因素冻结

- 外部危险解释“为什么分开”，不解释“为什么多年后关系仍可实际回来”；
- Hiccup 的家庭不替代 Hiccup↔Toothless 的对象特异性；
- Hidden World 地理位置只是回返通道，不是 nz 本身；
- 童年/系列怀旧只影响观感，拿掉仍剩现实重逢行为。

#### 判定

```yaml
sample_type: pure-nz-positive
criterion_version: water-axis-boundary-v1-current-canonical_20260904
current_xz: not_tested
current_nz: true
strict_xz_nz: not_tested
maturity: evidence-locked
confidence_fact: 98
confidence_classification: 97
increment:
  pure_nz_positive_controls: 1
  independent_works: 1
```

锁定规则：

> **怀念 / 旧关系仍有意义 ≠ stable nz；长期真实分离后，双方仍能自由、现实地重新进入同一对象特异关系并恢复可信接近，才是更强的 pure nz reality-test。**

> **“离开后仍能回来”必须是现实回返资格，不是记忆、遗愿或身份壳继续存在。**
