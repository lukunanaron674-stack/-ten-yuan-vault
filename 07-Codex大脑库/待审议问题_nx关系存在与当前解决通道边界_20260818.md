# 待审议｜nx：关系存在 ≠ 当前解决通道正在工作

## 1｜触发原因

连续三部独立作品出现同类边界：

```text
同一关系早期：
主体有自己无法直接解决的缺口
→ 对方掌握关键资源 / 庇护 / 权限
→ 主体沿关系网络请求并取得帮助
= nx 关系功能成立

同一关系后期：
关系仍然存在
→ 但对方不再承担主体当前缺口的解决接口
→ 行为转为回访、回报、保护、救援或承接托付
= 不能机械继承早期 nx 标签
```

这不是一次偶然差异，而是跨《红楼梦》《水浒传》《三国演义》三部独立作品复现。

---

## 2｜三部作品

### 《红楼梦》刘姥姥

一进荣国府：家计困难，沿周瑞家的—平儿—凤姐权限网络求助，属于 nx 关系功能。

二进荣国府：丰收后带头茬瓜果菜蔬回礼、请安、探访；没有先提出新的资源缺口，后续赠物大量由荣府主动发生。当前入府阶段不能继续因“又进荣府”自动判 nx。

### 《水浒传》宋江—柴进

早期：宋江被追捕，柴进掌握庄院、接纳与庇护条件，宋江投柴进，属于 nx 关系功能。

后期：柴进被拘押，反而成为被救对象；宋江主动领兵营救。对柴进这条关系不再承担宋江当前问题的外部解决接口。

### 《三国演义》刘备—刘表

早期：刘备败走投刘表，刘表掌握荆州接纳、住所、驻屯资源，刘备沿关系取得庇护，属于 nx 关系功能。

后期：刘表病危托孤并欲让荆州，刘备拒绝自领，承诺辅佐其子。关系行为转为回应托付与维护既有关系安排，不再是刘备借刘表解决自身当前资源缺口。

---

## 3｜候选纪律

当前只提出候选，不修改正本：

> **关系存在不是 nx 的充分条件。**
>
> **nx 关系功能必须检查“当前事件中，这条关系是否正在承担主体所需的外部方向、权限、资源或解决通道”。**
>
> **同一关系过去承担过 nx，不产生永久继承。后续每次都必须重判当前功能。**

候选判断式：

```text
当前缺口存在？
↓
对方是否掌握不可直接替代的方向 / 权限 / 资源 / 解决接口？
↓
主体是否正在通过这条关系请求、借用、续接？
↓
三项都满足，才增强 nx 关系功能证据。
```

如果当前行为主要是：

```text
回访 / 回礼 / 报恩 / 保护 / 救援 / 陪伴 / 回应托付
```

则不能仅凭“仍在同一关系网络里”继续锁 nx，应转查 `nz / n / x / xn / zx` 等最近邻，但不得关键词直判。

---

## 4｜与 nz 的边界仍未锁

三例都出现 `nz` 最近邻外观，但本待审议只处理 nx 的必要条件，不越轴重写水轴。

仍需后续验证：

```text
关系本身有持续价值
+ 不再承担外部解决通道
```

是否足以锁 `nz`，必须单独回到 nz 正本与准度卡测试。

所以当前只允许写：

```text
nx 当前关系功能退出 / 不成立
```

不允许自动写：

```text
因此必然 = nz
```

## 5｜反例 / 双功能限制证据：鸳鸯拒婚

已有正式案例《红楼梦》鸳鸯拒婚可作为本待审议的第一条反向限制证据，而不是重复制造新案例。

鸳鸯与贾母之间并非一次性、纯工具关系。文本明确呈现鸳鸯是贾母长期依赖的贴身大丫鬟，贾母日常生活离不开她；鸳鸯本人在贾赦婚配压力出现后，也首先要求“回声老太太”，并最终当众向贾母陈情。

此时同一关系同时存在两层：

```text
A｜既有关系 / 信任层
鸳鸯—贾母的长期主仆亲近、日常依赖与信任仍在
→ 不能把关系理解成临时工具

B｜当前权限通道层
贾赦拥有现实家族压力
→ 鸳鸯自己能锁定“不嫁”方向
→ 但自己没有足以让贾赦停手的家族最高权限
→ 通过贾母这一既有关系进入真实否决接口
→ 贾母公开阻断贾赦
= nx 关系功能仍然成立
```

因此，本待审议必须增加一条限制：

> **“关系本身有持续价值”不能反向推出“当前 nx 一定退出”。**
>
> **关系维系/信任与 nx 权限通道可以在不同对象层同时存在。真正决定 nx 是否成立的仍是：当前缺口是否需要借这条关系接入外部方向、权限、资源或解决接口。**

本轮不据此正式锁 `nz`。原因是当前任务只复核木轴，且 nz 必须回到水轴正本与准度卡独立验证。这里只能锁定：

```text
关系深度 / 关系价值存在
≠
nx 必然退出
```

### 对原候选纪律的修正方式

原纪律“关系存在不是 nx 的充分条件”保持不变；新增反向限制：

```text
关系维系明显
↓
不能直接排除 nx
↓
仍须检查当前是否存在真实外置权限/资源缺口
↓
若存在，关系层与 nx 功能层可并存
```

这使边界从单向规则变为双向规则：

```text
有关系 ≠ 自动 nx
有关系价值 ≠ 自动非 nx
当前解决接口是否正在工作，才是 nx 关系功能的关键变量
```

## 6｜需要继续寻找的反例

优先找：

1. 关系看似只是回访/报恩，但实际仍暗含明确资源请求，因此 nx 仍成立；
2. 对方一度从解决接口变成被保护对象，后来又重新掌握关键资源，使 nx 关系功能再次返回；
3. 第二部、第三部作品中“关系本身有持续价值 + 当前仍承担现实权限通道”的双功能样本，验证鸳鸯是否可跨作品复现；
4. 无长期关系，只发生一次现实权限请求，验证“关系深度”不是 nx 必要条件。
