# 《水浒传》林冲柴进庄庇护转梁山｜zx↔nx 通道可持续性压力测试

## 结论先行

本轮锁定 **`nx` 已真实激活，但旧 `nx` 通道并非永久持续；当外部压力使该通道不再可持续，主体停止沿旧通道推进并转接另一个既有外部关系/权限网络时，旧 nx 执行窗口结束，新 nx 通道可以重新激活。**

这与“外部方案本身无效”的失败不同。柴进东庄的庇护一开始是真有效的；真正使其退出当前执行位的是官府画影图形、沿乡搜捕的压力升级，使继续留庄会连累柴进且不能稳定解决林冲的长期安身问题。

## 1｜剧情事实、触发、对象、动作与结果

山神庙后，林冲杀死陆谦、富安等人，成为官府重点追捕对象。林冲再次到柴进庄上，柴进明确让他放心并实际收留，林冲在东庄住了数日。

随后沧州方面因草料场、杀人等事发出公文，画影图形，沿乡搜捕。林冲得知搜捕越来越紧，主动对柴进说明：不是柴进不肯留，而是如果官差搜到庄上，会连累柴进，因此请求盘缠，准备另投他处安身。

柴进没有要求林冲自己另建安身体系，而是打开另一条既有关系网络：说明梁山泊王伦等人与自己有书信往来，愿修书推荐。林冲接受这一转接，之后经朱贵识别柴进荐书，实际进入梁山准入链。

最小链：

```text
官府追捕后需要安身
→ 柴进庄真实收留
= nx旧通道激活

官府搜捕升级
→ 继续留庄开始连累柴进且不再可持续
→ 林冲主动停止沿旧庇护通道续接

柴进打开梁山既有关系网络
→ 荐书
→ 朱贵接引
→ 王伦准入
= 新nx通道激活
```

## 2｜nx 证据

### A｜柴进庄阶段

林冲不能凭自己的稳定权限生成“柴进庄可以合法/现实庇护我”这一结果。庄院、庄客、物资和柴进本人的庇护意愿都属于外部节点。林冲实际接受并在庄上居住，因此 `nx_chai_jin_shelter_behavior_function` 与 `nx_chai_jin_shelter_relation_position` 均成立。

### B｜梁山转接阶段

旧通道不可持续后，林冲没有公开夺取柴进庄的处分权，也没有自己建立一个全新的长期安身体系，而是继续沿另一条外部既有关系与准入网络推进：柴进荐书→朱贵接引→王伦/梁山准入。

因此这里不是 `nx退出→zx`，而是：

```text
nx(A)失去可持续性
→ 主体停止续接A
→ 转接外部既有B
→ nx(B)重新激活
```

## 3｜zx 判断

本窄阶段 `zx` 排除为主判。

林冲主动提出离开柴进庄，也主动决定继续求安身处，但这不等于他取得了新的公共决定范围。他没有把柴进庄、梁山准入权或官府追捕结构变成自己的处分对象。

因此：

> 主动离开一个失效通道 ≠ zx。

只有如果他不再依赖任何外部准入，而是凭自身权能公开建立并稳定占据一个此前不属于自己的新安身/组织决定接口，才重新检查 zx。

## 4｜关键压力

关键变量不是“柴进帮助失败”，而是 **外部环境改变了旧通道的可持续性**：官司追捕由背景风险升级为画影图形、沿乡搜捕，继续留庄会把柴进一起卷入现实风险。

所以旧 nx 结束的机制是：

```text
通道本身曾经有效
+
主体确实使用过
+
外部压力改变现实约束
→ 旧通道不再能稳定承担同一功能
```

这与《西游记》孙悟空四海龙王施雨案的“方案直接对目标瓶颈无效”形成不同机制。

## 5｜拿掉测试

### 拿掉柴进庄旧 nx

林冲仍有逃避追捕、寻找安身处的需要，但会失去第一个现实可用的庇护节点。说明旧 nx 不是假接口。

### 拿掉官府搜捕升级

如果柴进庄能够长期安全庇护林冲，且没有现实连累风险，那么没有足够理由锁定旧通道退出；林冲完全可能继续沿该 nx 通道生活。

### 拿掉梁山新通道

旧通道仍然会因搜捕压力而变得不可持续，但“转接另一个 nx”这一后半结构消失，只能锁旧 nx 退出，不能锁新 nx 激活。

## 6｜反向测试

### 反向A：旧 nx 持续

```text
官府搜捕没有升级
→ 柴进仍能稳定庇护
→ 林冲继续住庄
= 原nx持续
```

### 反向B：zx 接管

```text
柴进庄不可持续
→ 林冲不再接入任何外部关系/准入网络
→ 自己公开建立新的安身组织与处分接口
→ 他人开始围绕该新增接口运行
= 才查zx
```

### 反向C：xn主导

如果林冲已经拥有可自由调用的地点、人员、资源，随后重点变成自己安排转移路线、物资、节点和长期安置流程，则应转查 xn；原文核心仍是外部关系/准入接口的连续转接。

## 7｜最近邻排除

### nx vs xn

林冲会判断风险、选择离开，这有计划邻近；但长期庇护资格、柴进荐书、梁山准入都不是他自己搭出来的流程，因此 nx 仍是主判。

### nx vs x

柴进庄和梁山准入都不属于林冲稳定处分边界。

### nx vs zx

“旧节点失效后换节点”只证明主体停止沿 A、开始沿 B；不证明主体自己取得了 A 或 B 的最终权限。

### nx持续 vs 历史nx

曾经住过柴进庄，只能证明过去的 nx 真实存在。转投梁山以后，不能继续把“柴进庄庇护”写成当前执行中的 nx 路线。

## 8｜第三因素冻结

冻结：林冲武力、柴进仗义评价、王伦性格、梁山好坏、官府正当性、后续火并王伦、林冲稳定人物类型。

只保留：

```text
旧外部通道是否真实生效？
什么现实变量使其不再可持续？
主体是否停止沿旧通道？
主体之后是自行接管，还是转接另一个外部既有通道？
```

结论仍稳定为 99/98。

## 9｜与《西游记》四海龙王案的跨作品最小差异

```text
孙悟空：
nx真实接入→方案执行→直接证明无效→停止续接→转观音

林冲：
nx真实接入→通道一度有效→外部搜捕压力升级→通道不可持续→停止续接→转梁山
```

共同支持：

> `nx` 激活不等于永久持续，必须追踪主体当前是否仍真实沿该外部通道续接。

不同闭环机制：

1. 方案对目标瓶颈本身无效；
2. 通道本身有效，但外部压力使其不再可持续。

当前该“nx执行窗口可退出”边界已在《西游记》《水浒传》两部独立作品中出现，尚未达到三作品待审议阈值。

## 10｜严格 zx补nx 检查

本轮不锁严格补关系。当前重点是 nx 通道激活、失效与转接；没有必要为了形成对子，强行把林冲的自主安身目标包装成独立高纯 zx，再制造双向不可替代缺口。
