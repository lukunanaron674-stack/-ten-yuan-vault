## 源端点、目标端点与被改变变量

### 源端点 z

必须存在明确认可主体，并写清认可对象是主体自己的判断、能力、作品或选择。命令、职位、持续占位、公开压迫和替主体决定均不能代替 z。

### 目标端点 nx

主体原本不占方向决定位置，沿外部关系、流程或安排推进。

被改变变量：

- 主体对方向决定位置的认领强度；
- 对外部安排的唯一依赖度；
- 是否提出替代方向；
- 是否保留否决权；
- 认可停止后能否继续承担自己的路线。

成立阶段：认可事件之后，主体真实取回至少一个具体选择中的决定与否决位置。

关系体量：当前只允许低至中体量的状态层与关系层候选；无证据支持稳定人物本体改变。

显影条件：认可后必须出现持续方向权变化，不能只有情绪振奋、表现改善或继续追逐认可。

## 候选机制

### 候选A：判断资格确认

```text
重要认可主体确认“你的判断可以成立”
→ 外部安排不再是唯一合法方向
→ 主体提出、选择并承担自己的路线
→ nx下降
```

理论后果：若成立，z克制的是nx的方向依赖，不是关系网络、协作或求人功能本身。

### 候选B：能力资格确认

```text
主体因不确定自身能力而长期沿别人安排
→ 认可者确认其足以承担选择后果
→ 主体取回决定与否决位置
→ nx下降
```

理论后果：若认可只让主体更努力执行原安排，则z上升而nx不降。

### 已撤回候选

```text
z持续表达、决定和占位
→ nx不断退后
```

撤回原因：现行z是认可关系；持续决定、占位与压退他者更接近zx、x、xn或外部方向主体，而且该过程更可能使nx上升。

### 纯结构候选

学生长期只按导师选题。导师确认“你的判断足以独立决定研究方向”，并停止给题；学生仍持续提出、选择和承担自己的路线。若被表扬后仍等待导师决定，则不成立。

1. 老板表扬员工后，员工更认真执行老板安排：z上升，nx未降。

5. 被看见后更加依赖掌声：z增强，不构成nx下降。

7. 认可者命令主体“独立一点”：主体仍沿外部方向。
8. 主体只是换了一个更喜欢的跟随对象：nx结构未变。

## 最近邻排除

- 与 `zx克nx`：zx通过公开权能、决定和占位重排现实；z只确认主体的存在、能力或选择。
- 与 `x克nx`：若核心变化来自正式放权、资源、许可或权限转移，则作用源是x。
- 与 `zn克nx`：若主体因为不可背弃的意义拒绝继续跟随，启动源是zn；z最多确认其判断获得关系资格。

## 拿掉测试

1. 拿掉认可，只保留资源或放权，主体仍取回方向，则不依赖z。
2. 拿掉权限转移，只保留确认，主体仍持续决定，才支持z直接作用。
3. 拿掉主体原有自主判断，认可后仍等待对方给方向，则目标端点不存在。
4. 拿掉情绪振奋，只观察决定、否决和替代方案，关系仍成立才有效。
5. 认可停止后主体仍保持自己的方向，纯度高于继续追逐认可。

两个具体作品候选均未通过完全拿掉n、xn、x与既有自主性的测试。

## 反向测试

交换为 `nx克z`：主体长期不表达、不呈现、不进入认可接口，可能使认可无法发生。反向改变的是认可接口；本轮正向改变的是方向认领，不能互相代证。
