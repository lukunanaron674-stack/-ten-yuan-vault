# zx / xn / nx 对象分层与旧口径覆盖补丁 v0.1

> 本补丁不新增十元关系，只把已经锁定的 zx、xn、nx 正本口径放进同一套对象分层，防止人物本体、状态、行为、场景和时间结构互相冒名顶替。

## 1. 立即覆盖的旧口径

《十元判定校准协议｜草案》候选表中的旧表述：

```text
zx：目标执行、保持路径有效、完成本身构成存在方式
```

自本补丁起不得继续作为 zx 本体定义。正式替换为：

```text
zx 本体：张扬醒目、主体权能显现与扩大，或在压制中持续复起。
zx 行为：目标执行、路径推进、换路、破局、做成、重新站起。
```

因此：

> **目标执行可以是 zx 的标准行为，但“正在执行目标”不能单独证明人物本体是 zx。**

## 2. 三者最小本体边界

```text
zx：主体力量必须进入现实、显现、做成，并扩大或持续复起。

xn：主体主动把信息、行动与资源放入计划、时间、规则或隐藏结构，
    通过记录、重复、等待和积累形成持续力量；
    长期外化后可形成制度、传统、家族、历史惯性等客观结构。

nx：主体不主动占据选择、方向和位置，
    把决定留给别人、流程、关系或现状，并沿已有安排继续。
```

最短切口：

```text
zx：我要让我的力量重新进入现实。
xn：我要把事情放进时间与结构，使积累发挥力量。
nx：此刻我不建立方向，沿既有条件继续。
```

## 3. 必须先标注判断对象

同一个十元词，在以下对象上不能混写：

### 3.1 人物本体

判断长期稳定、拿掉后人物整体崩塌的核心结构。

```text
人物本体 zx：长期依靠权能显现、扩大或复起成立。
人物本体 xn：长期依靠计划、记录、时间组织与结构积累成立。
人物本体 nx：长期不主动占据方向与位置，沿外部安排维持自身。
```

### 3.2 人物状态

判断某阶段在压力下高显影的运行方式，不自动改写人物核心锚点。

```text
zx 状态：权能上升、破局、复起、重新夺回行动位置。
xn 状态：观察、记录、排程、等待节点、组织隐藏结构。
nx 状态：暂不占据方向，沿已有条件继续，等待外部条件改变。
```

### 3.3 行为

行为只能证明当下功能，不能独自证明人物本体。

```text
执行目标、破局、做成 → 优先检查 zx 行为。
记录、算计、安排节点、延迟结算 → 优先检查 xn 行为。
不作方向选择、顺着安排继续 → 优先检查 nx 行为。
```

### 3.4 场景与环境

```text
xn 场景：制度、传统、流程、家族积累、历史惯性、时间沉淀成的结构。
nx 场景：不能直接成立。nx 首先是主体在既有安排中的位置方式，
         不能只凭“安静、停留、被关住”给环境贴 nx。
zx 场景：只能描述权能显现、上升、突破或复起的场域功能，
         不能凭中心构图、王座、利剑直接判本体。
```

### 3.5 光影与视觉

光影只能提供视觉十元，不得越级证明人物本体：

```text
轴向上升、中心显现、反弹复起 → 可辅助 zx 视觉。
档案、刻度、重复序列、山体压制、时间层叠 → 可辅助 xn 视觉。
退位、留白、被流程带走、方向权旁落 → 可辅助 nx 状态显影。
```

## 4. 时间关系不是人物成长补丁

故事中人物核心锚点优先保持稳定。压力变化通常改动的是：

```text
显影强度
+ 人物状态
+ 行为功能
+ 关系位置
+ 动态链顺序
```

不得轻易写成：

```text
人物原本没有某副元
→ 被事件压制
→ 剧情中途生成一个新的副元
```

除非有足够证据证明人物存在方式已经整体重构，否则优先解释为：

```text
稳定本体一直存在
→ 外部关系改变
→ 原本较弱的一侧被迫高显影
```

## 5. 孙悟空金标准应用

《西游记》齐天大圣孙悟空当前稳定锚点：

```text
人物本体：zx + nx
外部场景 / 时间结构：五行山式 xn
标准关系：xn 克 zx，nx 补 zx
```

正确分层：

```text
求学阶段：人物本体已是 zx+nx。
大闹阶段：zx 高显影。
五行山阶段：环境与时间结构 xn 克制 zx。
             人物没有生成新的 nx，原有 nx 状态被迫高显影。
条件改变：zx 再次复起并进入现实。
```

不得写成：

```text
纯 zx 孙悟空
→ 五行山压制
→ 后天长出 nx
```

原因是五行山改变的是行动条件、关系位置和显影强度，不是给人物安装新的核心零件。

## 6. 三组最近邻反误判

### 6.1 zx vs xn

```text
正在执行计划 ≠ zx 本体。
```

- 若执行服务于主体权能显现、扩大或复起，检查 zx。
- 若行动来自长期计划、记录、时间节点与隐藏组织，检查 xn。
- 同一场戏可以是 xn 主导计划、zx 承担落地行为。

### 6.2 xn vs nx

```text
等待 ≠ 自动 nx。
```

- 为计划、节点和结算主动等待：xn。
- 不占据方向，把选择留给外部条件而继续：nx。
- 暗中观察、记账、算计、等待翻牌：优先 xn，不再归 nx。

### 6.3 zx vs nx

```text
暂时不行动 ≠ 人物失去 zx。
```

- zx 被外部结构压制时，可以暂时无法执行。
- 若人物原有 nx 能沿条件继续，表现为 nx 高显影、zx 低显影。
- 条件解除后 zx 复起，证明前段是状态与关系变化，不是本体消失。

## 7. 标准输出新增字段

以后分析 zx、xn、nx 交界案例时，在结论前增加：

```text
【人物稳定本体】
【当前人物状态】
【关键行为功能】
【外部场景 / 时间结构】
【视觉与光影辅助】
【关系变化】
【哪些未发生变化】
```

最后一项必须明确写出人物核心锚点是否保持稳定，防止把动态链误写成人物换芯。

## 8. 召回版

```text
zx 本体是权能显现、扩大与持续复起；目标执行只是标准行为。
xn 主动把信息和行动放进时间、计划、规则或隐藏结构，让积累形成力量。
nx 不主动占据方向与位置，沿既有条件继续。

人物本体优先稳定；剧情通常改变状态、行为、场景、关系与显影强度。
孙悟空从起点就是 zx+nx，五行山只是以 xn 克 zx，迫使原有 nx 高显影。
```
