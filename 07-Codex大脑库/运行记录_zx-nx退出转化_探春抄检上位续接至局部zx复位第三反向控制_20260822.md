# 运行记录｜探春抄检：上位 nx 续接至局部 zx 复位第三反向控制

## 0｜结论先行

本轮锁定：

> **探春先真实承接“查物、查明问题”这一上位外部搜检任务，但当外部执行继续侵入到丫鬟与自身身体边界时，她停止续接该局部方向；随后并不是因为 nx 下降就自动获得 zx，而是通过公开设界、直接否决越界并迫使搜检队调整行为，独立通过 zx 的现实显权门槛。**

因此本例可作为现有“nx退出 ≠ zx自动出现”待审议的第三部独立反向控制，但必须保留对象层警告：前段 nx 与后段 zx 位于同一搜检事件的不同嵌套对象层，不能写成同一权限对象的一键翻转。

## 1｜剧情事实

### 触发

王夫人批准夜间搜检大观园，凤姐、王善保家的等携上位授权进入秋爽斋。

### 前段明确动作：上位任务真实续接

探春没有否定“查明物品、洗清嫌疑”这一上位搜检目的。她提前命人开门等候；凤姐说明来意后，探春主动命丫鬟把自己的箱柜、妆盒、衣包等全部打开，请凤姐查阅。

这不是单纯“外部权限存在”，而是主体在上位查物对象层真实接入并推进外部任务，因此锁：

`nx_upper_search_task_continuation: evidence-locked`

### 后段明确动作：局部续接终止

当搜检从“查物”继续推进到“搜丫鬟、由奴仆翻探春身体”时，探春明确划界：自己的东西可以搜，丫鬟不可任意搜，尤其拒绝奴仆对自己动手搜身。

王善保家的拉扯探春衣襟越界后，探春当场反击，并坚持若要查自己，可以由自己解衣、让凤姐检查，而不是任奴仆翻身。

### 结果

凤姐、平儿等立即制止王善保家的、替探春整理衣裙、陪笑安抚，王善保家的退避；搜检队不再沿原来的越界方式继续。

因此后段不是只有“不服从”，而出现：

```text
外部局部方向继续压入
→ 探春停止续接
→ 公开设定自身边界
→ 越界时直接否决
→ 执行组真实改变行为
→ 主体局部决定位置恢复/上升
= zx 独立成立
```

## 2｜zx 判断

### 成立，但必须独立取证

zx 不是由“nx退出”推出，而由以下证据单独成立：

1. 探春公开表达当前边界；
2. 她把自身拒绝权直接压入现实；
3. 王善保家的原执行方式被实际阻断；
4. 凤姐、平儿及搜检队围绕探春的新边界重新行动；
5. 探春从单纯受查对象恢复为该局部搜检边界的决定者之一。

因此锁：

`zx_pressure_reassertion_state: evidence-locked`

不锁人物稳定本体。

## 3｜nx 判断

### 上位查物层：成立

外部搜检任务由王夫人/凤姐体系给出，探春没有重写“是否查明物品”这一上位目的，而是主动开箱、配合查阅，因此不是“权限只在外但主体没接入”的伪 nx。

### 局部身体/丫鬟边界：退出

当外部方向变为“执行者可以按其方式搜丫鬟、翻探春身体”时，探春不再续接，并保留否决/重设资格。

因此锁：

`nx_in_local_body_and_household_boundary: rejected`

这再次说明：

> **上位任务 nx 成立，不会自动覆盖所有下位对象层。**

## 4｜关键压力

- 王夫人正式授权；
- 凤姐带队执行；
- 王善保家的借邢夫人陪房身份越界；
- 夜间突击搜检使探春原局部位置被压缩。

压力只负责显影，不直接判符号。

## 5｜拿掉测试

### 拿掉后段 zx 独立证据

若探春只是停止配合，却没有公开设界、没有阻断越界、搜检队也没有改变行为，则最多能锁：

`nx下降/退出`

不能锁 zx。

### 拿掉前段上位 nx 续接

若探春一开始就完全拒绝所有搜检，不开箱、不接受上位查物任务，则本例仍可能有 zx 冲突，但不能承担“已承接 nx 后退出”的反向控制功能。

### 拿掉一巴掌

只保留主动开箱、明确划界、拒绝奴仆搜身并迫使凤姐等改变执行方式，zx 核心证据仍在。因此暴力动作不是分类支柱。

## 6｜反向测试

### 只有 nx 退出但非 zx

```text
接受查物
→ 后来不愿继续
→ 单纯离开/拒绝
→ 外部系统没有围绕主体新增边界重排
= nx退出，但不足以zx
```

### 持续 nx

```text
接受上位搜检
→ 连局部身体/丫鬟边界也完全交给执行组
→ 对方怎样搜就怎样搜
= nx继续
```

### 本例真正 zx

```text
nx局部退出
→ 公开设界
→ 直接否决越界
→ 执行组真实调整
→ 主体决定位置恢复/上升
= zx
```

## 7｜最近邻排除

### zx vs x

探春原有院内与身体边界构成 x 邻近，但本例不是静态正常调用：外部执行已经压缩其位置，随后才发生公开反推与对方重新响应，所以当前高显影更偏 zx 受压复位。

### nx vs xn

探春提前开门有预判，但没有搭建人员、时序、记录、复核等持续搜检流程，不能以 xn 主判。

### zx vs 强势/身份

小姐身份、脾气、一巴掌都不是直接证据。真正证据仍是公开权能是否改变现实中的他者行动与主体决定位置。

## 8｜第三因素冻结

冻结：探春庶出身份、王善保家的品行、凤姐立场、王夫人动机、后续司棋事件、家族衰败主题。

只保留：

- 前段是否真实续接外部查物任务；
- 后段是否停止续接局部越界方向；
- zx 是否另有公开显权、外部响应和位置上升证据。

结论不变。

## 9｜与现有反向正例的最小差异

- 《西游记》孙悟空：上位职务 nx → 退出 → 自定齐天大圣并迫使天庭响应 → zx。
- 《水浒传》林冲：准入接口 nx → 不再承认王伦最终接口 → 清除旧中心并使组织重排 → zx。
- 《红楼梦》探春：上位查物 nx → 局部搜检方向退出 → 公开划界并迫使执行组调整 → zx。

三例共同证明：

> **真正的动态转化不是“nx一降，zx自动升”，而是“nx退出后必须重新独立取得zx证据”。**

本例额外提醒：对象层可以嵌套切换，必须逐层标注，不能把上位任务与局部边界压成同一个权限对象。
