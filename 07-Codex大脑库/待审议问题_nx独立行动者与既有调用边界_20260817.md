# 待审议问题｜nx：独立行动者 vs 既有调用边界

## 1｜触发原因

连续三部独立作品出现同一边界：

```text
主体自己有明确目标
↓
需要另一个人的关键能力/行动
↓
问题不在“用了别人”
而在：
该人的相关行动是否已经进入主体稳定可调用边界
```

三部正向材料均显示：

> 若关键行动者在该具体行动上仍保留本人重新同意/拒绝资格，或主体还必须经过一个无法绕开的真实授权节点，主体只能通过请求、说服、关系或授权网络让其行动，则 `nx` 外部行动者关系功能明显增强。

反向材料则显示：

> 若该人的相关行动已经真实纳入主体既有军令/职责调用范围，可在职责边界内直接分派，而无需每次重新取得对方作为“外部节点”的批准，则不应因为“使用的是另一个人”自动判 nx，优先检查 `x/xn`。

## 2｜三部正向证据

### A｜《西游记》猪八戒义激猴王

commit: `e9e5b2aadaea390884ddc8084c411219871865cd`

- 孙悟空已经离开取经队伍。
- 八戒自己有救唐僧的明确方向。
- 八戒不能直接命令孙悟空重新出手。
- 必须请求、说明、激将。
- 孙悟空本人最后决定“去不去”。

因此支持：

`独立行动者本人重新批准 → nx外部行动者接口`

### B｜《水浒传》施恩请武松夺快活林

commit: `b48d9cd0212eeecf6fd309703f1dc98aae6284f4`

- 施恩自己有夺回快活林的方向。
- 武松不是施恩稳定命令边界里的下属。
- 施恩必须请求武松本人。
- 武松自行决定是否出手，也自行决定行动方式。

因此再次支持：

`关键行动能力仍归独立行动者本人决定 → nx关系功能`

### C｜《红楼梦》贾珍请凤姐协理宁国府

commit: `9e86701cbe78f6e3fcd3c1f7a8f669e36cf3bcdb`

- 贾珍自己有把宁国府丧事办好的方向。
- 王熙凤不是贾珍可直接分派的宁府普通下属。
- 贾珍必须向王夫人请求授权。
- 凤姐本人也明确确认愿意并能承接。
- 两道门通过后，凤姐才接入宁府并取得对牌。

这一例进一步把 nx 外部行动者结构拆成：

```text
行动者本人承接门
+
组织/家庭真实授权门
```

## 3｜反向控制

### 《三国演义》诸葛亮北伐点将

commit: `cb09681eed3725e89f80fb76e37b8fdba34e4f7a`

- 北伐诸将已经进入诸葛亮既有军令系统。
- 诸葛亮能够直接决定岗位、兵力、搭档。
- 不需要把每个将领重新当成一个外部求援对象逐一说服。

因此优先：

`x 既有调用边界 + xn 组织调度`

而非：

`nx 外部行动者`

## 4｜灰区材料

### 《西游记》孙悟空被逐前后

commit: `8b83e8da76fe8b7e1c843a8ad65bea6796d6c8a7`

当前仍为 candidate/deferred。

它提示一个更细的问题：

> 关系/组织内部的“日常职责可直接分配”，是否足够构成稳定 `x` 调用边界？

需要继续寻找：

- 日常任务可直接分派；
- 重大行动仍必须本人重新同意；
- 文本能清楚显示这两个调用层级不同。

## 5｜候选纪律

当前只形成待审议，不修改正本：

### 候选规则 A

```text
“使用另一个人的能力” ≠ 自动 nx。
```

### 候选规则 B

判断一个独立行动者是否构成 nx 外部接口，应优先检查：

1. 该具体行动是否需要对方本人重新同意；
2. 对方是否拥有真实拒绝权；
3. 是否存在主体无法绕开的外部授权节点；
4. 主体能否在职责/组织边界内直接分派该行动；
5. 若被拒绝，主体能否依靠既有命令权直接使行动生效。

### 候选规则 C

```text
需要本人/外部门重新放行
→ nx证据增强

该行动已稳定纳入主体真实命令/调用边界
→ nx下降
→ 优先检查x/xn
```

## 6｜必须防止的误判

禁止：

- 因为“人是独立人格”就说任何组织用人都是 nx；
- 因为“对方是下属”就默认主体拥有所有类型行动的无限调用权；
- 把普通说服成功写成 zx；
- 把对方的武力、专业能力或强弱直接判十元；
- 把一次请求反推主体稳定 nx 本体；
- 把主仆、军令、亲族等身份词当作权限事实本身。

## 7｜下一步验证

优先找真正的“部分调用边界”案例：

```text
主体平时可以直接分配日常任务
但某类重大行动必须重新取得本人同意
```

目标是判断 `x ↔ nx` 是否存在稳定的按“行动类型/权限层级”拆分方式。

达到更多高纯正反例前：

- 不修改 L1；
- 不修改 zx/nx 信息卡；
- 不修改准度卡；
- 不修改 zx补nx 补卡；
- 不把本待审议内容冒充正式十元定义。
