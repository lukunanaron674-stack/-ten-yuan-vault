# 《西游记》孙悟空弼马温 → 反下天宫｜zx↔nx 严格补关系对象层错位控制

## 0｜结论先行

本轮不重造孙悟空端点案例，只复审两个已经分别锁定的阶段能否因为“同一人物、同一回目、前后直接相连”而拼成严格 `zx ↔ nx` 补关系。

结论：**不能。**

两端都真：

- 弼马温到任阶段：上位职务与最高任务由玉帝/天庭官职体系给定，孙悟空承接并进入御马监，`nx_upper_task_relation_position` 已正式锁定；御马监内部另有局部 `x`，不影响上位职责层 `nx`。
- 得知弼马温“未入流”后：孙悟空主动否定天庭给他的等级位置，反下天宫，在花果山自号“齐天大圣”，并公开对抗天兵；“逼天庭承认齐天大圣”属于仓库既有 `zx` 锚。

但两个端点解决的不是同一个缺口：

```text
弼马温 nx 的对象：
“我要不要承接天庭给定的御马监职务，以及在什么上位任务框架中工作”

反天宫 zx 的对象：
“天庭等级体系是否有资格把我压在低位，以及我要求什么身份/凌驾位置”
```

前段受职确实触发了后段得知官阶低的冲突，但这只是**时间与触发前提**。它没有直接补后段 zx 在“身份/等级主权”上的现实缺口；后段 zx 也没有回头补前段“御马监任务是谁给、是否承接”的旧缺口。

因此正式锁为：

> **两端都真 + 同一回目连续 + 后段由前段触发，也不等于严格补。严格补还要求两端缺口处在同一对象层，或至少能证明直接改变同一个现实变量。**

## 1｜剧情事实与触发

### 阶段 A｜受封弼马温并到任

玉帝命群臣寻找缺职，最终任孙悟空为弼马温，并由木德星官送至御马监。孙悟空到任后会集监丞、监副、典簿、力士，查点事务和马匹，持续管理天马。

这一层的结构是：

```text
天庭已有职位体系
→ 玉帝决定孙悟空担任弼马温
→ 上位任务 = 管理御马监
→ 孙悟空承接并到任
= nx 上位职责关系位置
```

### 阶段 B｜得知官阶后反下天宫

孙悟空后来询问弼马温品级，得知只是“未入流”末等职位，立刻认为玉帝轻贤，推倒公案、取出金箍棒，打出御马监并反下天宫。回花果山后，独角鬼王建议“齐天大圣”名号，孙悟空立即采用，公开立旗；天庭随后出兵征讨，孙悟空公开迎战并要求天庭承认其自定身份。

这一层不是“继续完成御马监任务”，而是：

```text
天庭等级位置压低主体
→ 主体公开否定
→ 退出原职务体系
→ 自定齐天大圣身份
→ 迫使天庭围绕其权能重新响应
= zx 高显影
```

## 2｜两端独立成立：第一门通过

### nx 端

即使删掉后续反天宫，只保留“玉帝任职 → 孙悟空到任 → 承接御马监上位职责”，上位任务层的 `nx` 仍成立。

### zx 端

即使不把“曾经做过弼马温”当成任何资源帮助，只保留“主体拒绝低位等级 → 退出 → 自定齐天大圣 → 公开迫使天庭回应”，后段 `zx` 仍可独立成立。

因此本例不是“贾芸型”：不是一端根本不存在。

## 3｜第三道下限：缺口对象层错位

### 3.1 nx 端的实际对象

前段问题是：

> **主体是否进入一个由外部组织给定的岗位与上位任务。**

被测试变量是：

- 职务来源；
- 上位职责；
- 是否承接既有官职体系安排。

### 3.2 zx 端的实际对象

后段问题已经切换成：

> **主体在天庭等级体系里接受什么身份、是否允许外部等级压住自身，以及能否把自定身份公开压入现实。**

被测试变量是：

- 等级承认；
- 身份主权；
- 公开凌驾位置；
- 天庭是否被迫围绕主体重新反应。

所以：

```text
A 的 nx 缺口 = “职务/任务由谁给，我是否沿它做”
B 的 zx 缺口 = “我的身份和等级由谁最终决定，我能否公开把自定位置压入现实”
```

虽然都发生在“天庭官职”背景里，却不是同一被改变变量。

## 4｜为什么“触发关系”不能冒充“补关系”

本例确实有直接触发：

```text
先做弼马温
→ 才有机会得知官阶低
→ 受到等级羞辱
→ 反下天宫、自号齐天大圣
```

但这只能证明：

> **前段 nx 是后段 zx 的情境/触发前提。**

不能证明：

> **前段 nx 正在给后段 zx 提供其缺失的外部接口、资源或权限。**

前段御马监任务并没有帮助孙悟空取得“齐天大圣”的等级承认；相反，后段 zx 正是通过拒绝该岗位位置而出现。

同样，后段 zx 也没有把“如何完成御马监上位任务”这件事做得更完整。它直接终止了那条任务线。

## 5｜双向拿掉测试

### 5.1 拿掉前段 nx

假设不经过“承接弼马温并实际养马”这一具体 nx，而以其他等价方式让孙悟空知道天庭把他放在极低等级；只要“低位等级压制 → 主体拒绝 → 自定齐天大圣 → 公开对抗天庭”的条件仍在，后段 `zx` 仍成立。

后段不会留下：

> “因为缺少御马监上位任务承接，所以无法把身份主权压入现实”

这种同对象缺口。

因此：

`nx_repairs_later_zx_same_object_gap: rejected`

### 5.2 拿掉后段 zx

保留前段完整任职：玉帝仍可任命、孙悟空仍可到任、御马监上位任务仍由天庭给定，前段 `nx` 不需要“后来自号齐天大圣”才能成立。

后段 zx 不会反向补：

> “孙悟空如何承接御马监职务”

这个早期问题。

因此：

`zx_repairs_prior_nx_same_object_gap: rejected`

## 6｜最近邻排除

### 普通因果/触发链

本例最接近：

> **前一关系位置制造后续冲突信息 → 后一阶段由主体公开反弹。**

这是动态触发，不是严格补。

### 压力显影

弼马温阶段可出现 `nx` 上位职责位置；官阶羞辱压力出现后，孙悟空 `zx` 高显影。这个“哪一端在什么压力下显影”的动态是真实的，但动态切换本身仍不等于互补。

### x

御马监内部日常管理已有局部 `x`，但后段“齐天大圣身份主权”并不是这一局部 `x` 的自然扩展；二者对象不同，不能用 `x` 把前后硬接起来。

### xn

孙悟空没有靠复杂排程、流程与节点组织来完成“齐天大圣”身份对抗，`xn` 不是后段主判。

## 7｜关键压力与第三因素冻结

关键压力：得知弼马温“未入流”、感到天庭以低位等级压住自身。

冻结以下第三因素：

- 孙悟空神通强弱；
- 官名好不好听；
- 独角鬼王建议本身；
- 天庭后来是否再次招安；
- 最终是否受封空衔；
- 花果山群猴拥戴；
- 后续蟠桃园与大闹天宫。

只保留：

```text
前段：谁给上位任务？主体是否承接？
后段：谁占身份/等级最终方向？主体是否公开把自身位置压入现实？
两个缺口是否在同一对象层直接互补？
```

结论仍稳定。

## 8｜与林冲对象层错位控制的跨作品复现

《水浒传》林冲：

```text
早期 nx = “我自己怎么获得梁山成员准入”
后期 zx = “谁决定梁山最高首领与新来者准入”
→ 同组织、前后有因果，但对象层错位
```

《西游记》孙悟空：

```text
早期 nx = “我是否承接天庭给定的御马监上位任务”
后期 zx = “我的天庭等级/身份是否由外部压低，还是由我公开自定并逼其回应”
→ 同官职体系、直接触发相连，但对象层错位
```

所以当前同类跨作品支持数为 2：

`cross_work_same_boundary_count: 2`

尚未达到三作品阈值，因此本轮不创建待审议问题，也不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。

```text
阶段：弼马温受职 ↔ 得知官阶后反天宫、自号齐天大圣
样本类型：伪严格 zx+nx 补关系／对象层错位第二跨作品控制

nx端：evidence-locked
zx端：evidence-locked
两端独立成立：通过
同一对象层：否
前段 nx 直接补后段 zx 缺口：否
后段 zx 反向补前段 nx 缺口：否
严格 zx↔nx 补关系：false
事实置信：99

```

当前最窄纪律：

> **“同一人物 + 同一组织体系 + 前段直接触发后段”仍不足以构成严格补。必须继续追问：两个端点真正修复的是不是同一个现实变量。**
