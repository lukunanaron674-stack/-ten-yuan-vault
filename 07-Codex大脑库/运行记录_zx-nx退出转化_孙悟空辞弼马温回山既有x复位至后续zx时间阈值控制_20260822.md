# 《西游记》孙悟空辞弼马温回山｜nx退出、既有x复位与后续zx时间阈值控制

## 0｜结论先行

本轮不再把“弼马温 → 齐天大圣”作为一个整体直接判动态转化，而把中间时间窗单独切出：

```text
阶段A：
玉帝任弼马温 → 孙悟空到任并履职
= 上位任务 nx

阶段B：
得知未入流 → 不再承接 → 打出御马监 → 回花果山高登原有宝位
= nx退出 + 既有x复位/重入
≠ zx

阶段C：
采纳齐天大圣名号 → 公开立旗并向各洞传播 → 天庭出兵 → 孙悟空公开迎战并要求承认新身份
= zx独立成立
```

因此正式锁定：

> **nx退出以后，主体即使重新掌握自己的既有对象域，也只能先检查 `x`。只有决定范围进一步超出旧基线、公开压入现实并迫使外部秩序围绕新增权能响应时，才进入 `zx`。**

本轮新增的不是“孙悟空又一个zx案例”，而是 zx 真正开始之前的时间阈值。

## 1｜剧情事实、触发、对象、动作、结果

### 阶段A｜弼马温：上位nx已确认

仓库已有正式案例锁定：玉帝任孙悟空为弼马温，孙悟空实际到任御马监并履行管理职责，因此“为什么进入御马监、最高任务是什么”这一上位职责层属于 `nx`；御马监内部另有局部 `x`。

### 阶段B｜即时退出窗：只截到独角鬼王出现之前

孙悟空询问官品，得知弼马温“未入流”，明确表示“不做他”，推倒公案，取出金箍棒，打出御马监和南天门，回到花果山。

回山后，四健将和群猴迎接，他重新“高登宝位”。群猴听完经过后也只是庆贺大王回来，恢复花果山原有王位与生活结构。

这一时点尚未发生：

- “齐天大圣”名号；
- 新旌旗；
- 向各洞传播新等级要求；
- 天庭因该新身份要求出兵；
- 孙悟空以新等级诉求迫使天庭重排。

所以这个微窗口的最窄结果是：

```text
停止弼马温nx续接
+
返回原有花果山自决/王位对象域
= 既有x重新显影
```

### 阶段C｜后续zx对照

独角鬼王提出“齐天大圣”，孙悟空采纳，命四健将立“齐天大圣”旌旗，并要求以后只以此称呼、传与各洞妖王。天庭随后因其反下天宫出兵；战斗中孙悟空进一步要求玉帝承认该名号。

这才进入仓库已有 `zx` 锚：自身新身份/等级要求公开进入现实，天庭秩序必须围绕其新增权能回应，主体凌驾位置相对旧基线上升。

## 2｜zx判断

### 即时退出窗：排除为主判

孙悟空打出御马监很强、很公开，但单凭这一动作仍不足以通过 zx 第四门。

真正要问的是：

> **此时他的决定范围相对“原有花果山之王 + 可自行去留”是否已经扩大？**

证据不足。

他回到的是原来已有的花果山王位；群猴恢复原来的“大王”称谓与宝位结构。此刻还没有建立高于旧基线的新公共决定位置。

因此锁：

`zx_in_immediate_exit_window: rejected_as_primary`

### 后续齐天大圣窗：沿用既有zx锚

到自号、立旗、传播、天庭出兵与公开对抗后，才重新独立满足：

1. 自身新方向/身份要求；
2. 权能公开显现；
3. 外部秩序真实响应；
4. 凌驾/决定位置相对旧基线上升。

## 3｜nx判断

前段弼马温上位任务 `nx` 已锁。

得知官阶后，孙悟空明确停止履职并离开天庭，所以当前职务执行层：

`nx_in_immediate_exit_window: rejected_as_primary`

重要的是：

> **nx退出只说明他不再沿天庭给定的弼马温方向继续。它本身不说明新的权能边界已经出现。**

## 4｜x最近邻：本轮核心

花果山王位不是反出天宫后新取得的。

孙悟空上天以前就已经是花果山猴王；回山后四健将、群猴重新迎接其“高登宝位”，更符合：

> **重新进入/显影自己原有的局部控制与身份边界。**

因此锁：

`x_preexisting_huaguoshan_boundary_reoccupied: evidence-locked`

同时明确：

`x_was_not_newly_created_in_exit_window: true`

这使本例成为现有 pending-review 所需的最小时间阈值：

```text
nx退出
→ 旧x重新显影
→ 尚非zx
→ 后续另有新增公开权能证据
→ 才zx
```

## 5｜关键压力

关键压力是得知弼马温“未入流”产生的等级冲突。

压力负责触发退出，但不能直接判 zx。

冻结“受辱程度、战斗力、脾气、英雄评价”后，只看权限状态：

- 弼马温任务是否继续？否；
- 花果山旧王位是否恢复进入现实？是；
- 是否已经取得高于旧基线的新决定范围？即时退出窗没有。

结论不变。

## 6｜拿掉测试

### 拿掉齐天大圣后续

只保留：

```text
得知官小
→ 辞弼马温
→ 打出天门
→ 回花果山继续做原来的猴王
```

仍能锁 `nx退出 + 旧x重入`，但不能锁 zx。

这证明后续 zx 有独立证据链。

### 拿掉花果山旧王位

如果孙悟空退出以后没有任何原有稳定对象域，只是独自离开天庭，那么只能锁 `nx退出`；本轮的 `x` 复位/重入证据也会下降。

### 拿掉外部响应与新增身份要求

即使退出动作再激烈，没有自号、立旗、等级诉求与天庭围绕新增权能的响应，也不能补成 zx。

## 7｜反向测试

### 纯“nx退出 → x”版本

如果孙悟空辞职后一直在花果山只做原来的猴王，不向天庭提出新等级要求、不建立新增公共身份接口，则长期保持：

`nx退出 + 旧x`

### 真正“nx退出 → zx”版本

原文后续：

```text
旧x重入
→ 自定齐天大圣
→ 公开立旗/传播
→ 天庭出兵
→ 新等级要求成为公共冲突中心
= zx
```

因此转化门槛不在“离开”，而在“超过旧x基线的新公开权能”。

## 8｜最近邻排除

### x vs zx

```text
x：回到原有花果山王位，恢复既有可调用边界。
zx：把身份/等级要求继续推到“与天齐”，迫使天庭秩序围绕新位置响应。
```

这是本轮主边界。

### nx vs x

弼马温最高任务由天庭给定是 nx；回山后花果山王位属于孙悟空原有局部对象域是 x。对象层与时间窗不同。

### nx vs xn

即时退出只是停止履职并回山，没有搭新的持续流程、资源和节点系统；`xn` 不主判。

### zx vs 强烈反抗

“推倒公案、打出御马监”是强烈行为，但拿掉后续新增等级位置，它不足以证明决定范围扩大。

## 9｜第三因素冻结

冻结：

- 孙悟空神通强弱；
- 独角鬼王建议是否聪明；
- 天庭后来是否正式给齐天大圣空衔；
- 后续蟠桃园、大闹天宫；
- 花果山群猴对他的感情；
- 官阶羞辱的道德评价。

只保留：

```text
哪个nx停止？
退出后回到的是旧x还是新边界？
什么时候第一次出现高于旧x基线的公开权能？
外部秩序何时第一次围绕新增权能响应？
```

结论仍稳定。
