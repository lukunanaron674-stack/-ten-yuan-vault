# 待审议｜pure x 独立成立与现实掌握不需要 zn 共同过门边界

## 1｜候选命题

在同一窄对象层，只要具体对象、资源、职事、地盘或权限已经真实进入主体稳定的占有、调用、调配、处分或排除边界，`x` 可以独立成立；不要求同时存在一项 `zn` 内部最终原则。

反过来，现实用途、工作责任、治理职责、身份名位、外部认可或“这个对象很重要”都不能替代 `zn` 的独立过门。

## 2｜三部作品控制

### 《红楼梦》刘姥姥一进荣国府｜99/98

机制：私人物品 / 资源完成交付。

凤姐给出的银钱完成交付后，刘姥姥可以直接占有、使用并尝试再处分；原节点不保留逐次许可。家庭用途和过冬需要不足独立成立 `zn`。

### 《西游记》孙悟空权管蟠桃园｜99/98

机制：公共职事 / 管理权限真实接管。

园务明确交付后，孙悟空进入园中查勘，土地与力士围绕其管理位置响应；园务 `x` 成立。高称号、品级刺激和工作职责不足独立成立 `zn`。

### 《三国演义》刘备权领徐州｜99/97

机制：稳定地区军政治理真实接管。

刘备接受“权领徐州事”后，直接配置辅佐/幕官、调入军马、发布安民命令，现实行政节点响应；徐州治理 `x` 成立。当前治理窗口不足独立锁定一项通过无奖励、冲突排序和未来调用门的 `zn`。

## 3｜共同最小结构

```text
被测对象明确
+
主体明确
+
现实掌握类型明确
+
权限不是纯名义/一次接触
+
拿掉掌握关系后案例核心明显变化
→ x 可独立成立
```

而 `zn` 必须另外证明：

```text
内部原则明确
+
拿掉奖励/认可/制度要求仍进入判断
+
冲突中保有最终排序资格
+
跨阶段保留未来调用资格
```

两组门不得互相代替。

## 4｜机制覆盖

三案不是同一“别人送东西”换皮：

1. 私人物品/资源处分；
2. 公共职事/管理权限；
3. 地区军政治理/现实行政权限。

因此候选边界已经跨越三种 `x` 外形。

## 5｜反误判纪律

1. `x` 成立 ≠ 自动 `zn+x`。
2. “我知道这东西拿来干什么” ≠ “存在不可轻易让渡的内部原则”。
3. 工作职责 / 管理责任 / 治理责任 ≠ 自动 `zn`。
4. 历史权限来自外部 ≠ 当前永远只能算外置；完成真实接管后重新检查 `x`。
5. 名义职位 / 称号 / 牌印 / 授权意向 ≠ `x`；仍需现实掌握证据。
6. pure-`x` 只针对当前窄对象层，不锁人物稳定本体。

## 6｜需要的反向护栏

达到 pending-review 后停止继续堆第四个普通正例。下一步优先找：

- 表面有占有/管理，但权限随时可被原节点逐项撤回，稳定 `x` 实际不过门；
- 只有流程组织 `xn`，却没有对象归属/处分权的伪 pure-`x`；
- 只有一次临时持有、密码、职位或代理授权的伪 pure-`x`；
- 看似无 `zn`，但隐藏存在一项已经独立过门、正在直接规定 `x` 用途与边界的反例。
