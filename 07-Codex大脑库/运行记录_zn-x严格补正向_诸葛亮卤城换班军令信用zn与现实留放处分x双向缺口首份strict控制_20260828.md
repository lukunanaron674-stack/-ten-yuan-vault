# 运行记录｜zn-x strict 正向｜诸葛亮卤城换班：军令信用 zn 与现实留放处分 x 双向缺口

## 1｜本轮问题

火轴此前已经得到 3 部作品、4 份 strict 反向护栏，反复证明：

```text
x 对 zn 有帮助 / 执行接口
≠
x 是 zn 不可替代现实落点
```

本轮继续按 P0 强门寻找第一份真正 strict 正例。要求先满足：

```text
同一当前窗口
+
同一对象层
+
zn 独立过门
+
x 独立过门
+
第三方不能替主体提供现实处分 / 落点
```

然后才允许分别做 `zn→x` 与 `x→zn` 双向拿掉。

本轮结论：**《三国演义》第一百零一回诸葛亮卤城换班达到 99/95，可作为第一份 L4 evidence-locked strict `zn↔x` 正向控制。**

---

## 2｜剧情事实

第一百零一回中，诸葛亮此前已经建立蜀军分班轮换制度：

```text
大军分两班
→ 限一百日为期
→ 循环相转
→ 违限者按军法处治
```

到卤城阶段，长史杨仪报告：

```text
一百日期限已足
+
汉中新班已出川口
+
现存八万军中四万应当换班
```

诸葛亮直接回答：

> 既有令，便教速行。

此时魏军突然急攻，孙礼率雍凉大军袭剑阁，司马懿又来攻卤城。杨仪建议把本来应换班的四万兵暂时留下，等新军到后再换。

诸葛亮拒绝，明确给出原则：

> **用兵命将，以信为本；既有令在先，岂可失信。**

并补充：这些军士已经准备归家，父母妻子正在等待，即使自己面临大难，也不能因此强留。

随后他真实下令：

```text
应去之兵
→ 当日便行
```

军士后来主动表示愿意留下迎敌，是**在诸葛亮已经决定不强留、并真正允许他们离营之后**发生的自愿行为。

所以不能把“军士后来愿留”倒写成诸葛亮其实从未放弃留兵处分。

## 3｜被测对象层

本轮只测：

> **诸葛亮对直属蜀军换班、留营、放行的现实军令 / 处分边界。**

不测：

- 整个蜀汉政治本体；
- 北伐大义整体；
- 诸葛亮永久人格；
- 普遍意义上的所有“诚信”；
- 士兵对诸葛亮的感恩。

这是一个窄而清楚的“我军军令信用与留放处分”对象层。

## 4｜x 端点：现实留放处分权真实成立

current `x` 要求：

```text
对象明确
+
主体明确
+
实际占有 / 调配 / 调用 / 处分 / 否决 / 排除能力明确
+
不是纯名义、职位或一次接触
```

本例满足：

- 被测对象：当前八万蜀军中应换班的四万军士；
- 掌握主体：诸葛亮；
- 权限类型：设定轮换、决定何时换班、决定是否留营、发出放行军令；
- 现实响应：杨仪与全军以诸葛亮军令为执行节点，应去军士按命准备离营；
- 魏军急攻时，杨仪把“是否临时留下这四万兵”直接交由诸葛亮裁决，说明这不是只有头衔而没有同层处分能力。

因此本窄对象层：

```text
x = true
```

不是 `xn` 单纯流程设计，因为真正被测的是：

> **这批兵此刻到底由谁决定留还是走。**

## 5｜zn 端点：主帅不得因即时战术利益单方破坏已发布军令信用

本轮 `zn` 不写成泛泛的“诸葛亮很讲信用”。

严格限定为：

> **对直属军队已经由自己正式发布并形成期待的轮换军令，主帅不得因为临时战术利益而单方破例；统军信用不只约束士兵，也反过来约束掌令者本人。**

### 5.1 原则命题明确

诸葛亮自己明确说：

```text
用兵命将，以信为本
既有令在先，岂可失信
```

不是后人替他概括。

### 5.2 无奖励 / 无认可门

当前并不存在“守信即可获得更高奖励”的外部诱因。

相反，现实压力是：

```text
魏军急攻
+
剑阁受威胁
+
多留四万熟兵显然更安全
```

也就是说，当前即时利益**支持破例留兵**，原则却把结果排向“不强留”。

### 5.3 冲突排序门

杨仪明确提出战术上更有利的方案：

```text
暂留换班军
→ 等新军到
→ 再轮换
```

诸葛亮明确拒绝，并接受现实风险。

所以原则真实改变最终选择。

### 5.4 未来调用与边界门

“用兵命将，以信为本”不是只针对这四万人一次性的情绪反应，而是一个可复用的统军标准。

其边界也非常清楚：

```text
已经公开下令
+
部属已经形成确定归期
→ 主帅不能因为当前更方便就任意撤回
```

### 5.5 跨情境旁证

第一百零一回本身已经提供“先建立轮换令 → 后遇敌压测试”的跨阶段复验。

另外，第九十六回“斩马谡 + 自请贬三级”提供同类旁证：

- 与马谡私情很深，仍要求“明正军律”；
- 马谡被正军法后，诸葛亮又把街亭失误责任反向追到自己，主动上表请贬。

这不拿来给本轮增加第二个 `x`，只作为：

> **统军规则不能只约束下属、掌令者本人也受其约束**

的独立旁证。

因此本轮 `zn` 可锁：

```text
zn = true
```

## 6｜为什么不是 xn / z / nx / zx

### 6.1 zn vs xn

分兵两班、一百日轮换属于 `xn` 流程设计邻近。

但本轮关键问题不是“怎样设计轮换”，而是：

> 敌军已经来了，是否为了眼前收益破坏自己已经发布的军令？

这是价值 / 原则排序，不是流程骨架本身。

### 6.2 zn vs z

军士后来感恩、自愿留下，属于后续现实反馈。

诸葛亮的“不强留”决定发生在这些反馈之前，所以不能用后来的拥戴解释原则。

### 6.3 x vs nx

诸葛亮不是借用别人手里的留放权限；是否留下应换班军直接由他的军令生效。

### 6.4 x vs zx

本轮不测试扩权。他已经拥有该军令处分边界，只是在调用既有 `x`。

## 8｜方向一：zn → x 缺口

先拿掉本轮 `zn`，保留完整 `x`：

```text
诸葛亮仍然拥有：
设定轮换
决定留营
决定放行
调动军队
处分违令
```

也就是说 `x` 本身仍成立。

但遇到魏军急攻时，若拿掉“已经对我军发布的命令不得因即时利益任意破坏”这一原则，`x` 会重新出现明确缺口：

```text
有军队
有处分权
有战术利益
却缺少：
什么时候即使能强留，也不应强留
已经对部属形成的承诺是否约束主帅自己
临时军情能否无限覆盖既有军令信用
```

所以 `zn` 给 `x` 补入：

> **军令使用、变更与例外的内部边界。**

结论：

```text
zn → x = true
```

## 9｜方向二：x → zn 不可替代现实落点

这是此前 strict 正例一直过不了的强门。

本轮反向拿掉被测 `x`：

> 假设诸葛亮没有对这批直属蜀军的现实轮换 / 留放处分边界。

`zn` 作为抽象原则仍可以存在：

> 统军命将应守信，掌令者不能任意破坏已经发布的军令。

但它会重新出现一个非常具体、且不能由本窗口其他对象替代的现实缺口：

```text
没有“我的直属军队”这一现实边界
→ 没有由我发布并可由我撤回 / 保持的轮换军令
→ 没有我能现实决定“强留还是放行”的对象
→ 原则失去当前“我方军令信用”落点
```

这里的关键不是：

> “没有军队，守信更难执行。”

而是：

> **被测原则本身就在规定‘我对我方直属军队已经发布的军令如何约束我自己’；没有该现实掌军边界，当前原则缺少它所定义的‘我方 / 我的军令 / 我的留放处分对象’。**

### 9.1 为什么主体自身行为不能替代

此前晁盖、唐僧 strict 失败，是因为拿掉 `x` 后，原则还能直接约束主体自己的普通行为或其他关系。

本例不同。

诸葛亮当然仍可以在别的事情上“做人守信”，但那只是更宽泛的诚信原则，不能替代本轮窄命题：

> **主帅对已经向直属军队发布的轮换军令负有自我约束。**

如果没有直属军队与留放处分关系，“主帅—我军—军令”这一现实对象结构就不存在。

### 9.2 为什么第三方不能替代 x

- 刘禅没有在此窗口替诸葛亮决定四万人去留；
- 杨仪反而建议留兵，并不提供同向第三方否决；
- 军士后来自愿留下发生在诸葛亮先放行之后，不能倒填成 `x` 来源；
- “敌军急攻”是压力因素，不是现实掌握边界。

因此没有发现一个不含诸葛亮当前 `x` 的第三因素，可以等价提供：

```text
谁是“我方直属军队”
谁能发布 / 保持 / 撤回该轮换令
谁对“是否强留”拥有现实决定权
```

所以：

```text
x → zn = true
```

## 10｜反向测试

### 10.1 若只有 zn，没有 x

若诸葛亮只是一个旁观谋士，对这批兵没有留放处分权：

```text
“主帅应守信”仍可作为原则成立
```

但它只能成为对别人的评价 / 抽象规范，无法在当前窗口形成：

```text
我的军令
+
我的直属部属
+
我能否强留他们
```

因此出现 current canonical 所说的“现实落点 / 明确我方边界”缺口。

### 10.2 若只有 x，没有 zn

若他拥有全部留放处分权，但没有“军令信用反向约束掌令者”原则：

```text
面对魏军急攻
→ 完全可以为了战术利益暂留四万换班军
```

`x` 仍在，但缺少内部使用与例外标准。

因此出现“有对象和权力却缺方向依据”的缺口。

## 12｜与既有 strict 负控制的差异

### 关羽

曹赐资源并不定义旧义的“我方”对象，旧义还有归刘、护送二嫂、自身离曹等替代落点。

### 晁盖

山寨武力 `x` 扩大不伤无关者原则的执行范围，但原则仍能直接约束晁盖自身并指向外部百姓。

### 唐僧

师徒处分 `x` 只是“不轻伤人命”原则的一条执行接口；原则还有其他生命对象和自身判断落点。

### 诸葛亮本例

被测 `zn` 不是一般“要守信”，而是：

> **掌令者不得任意破坏自己已经对直属军队建立的军令信用。**

而被测 `x` 正是：

> **谁属于当前直属军队，以及谁能现实决定该轮换军令保留 / 破例 / 强留 / 放行。**

因此 `x` 不是额外工具，而是该原则 current-window 中“我方军令边界”的构成性现实落点。
