# 待审议｜nx：外部权限关系是否应要求“真实可使用的否决/修改能力”

## 1｜触发原因

三部独立作品出现同型边界：

```text
主体自己可以有方向、方案甚至局部组织能力
↓
某个关键审批 / 资源 / 配置接口声称在外部
↓
如果外部主体真的能够拒绝、修改、不放行
↓
主体必须沿该边界重配或等待
↓
该对象层的 nx 权限关系证据显著增强
```

相反，仅有“上级”“所有者”“批准人”等身份名义，而文本中从未显示其真实可否决性，证据强度应更谨慎。

## 2｜三部作品

### A｜《红楼梦》平儿玫瑰露案

平儿主动重设结案方案，但凤姐并非形式盖章。她实际提出继续严查、罚跪等更强处分，平儿继续劝说后才获放行。

因此：方案设计可在平儿；最终处分否决接口仍真实在凤姐。

### B｜《水浒传》吴用杭州水军调度

吴用主动设计南面水路扰乱方案，但宋江真实否决“张横、三阮全部去”，理由是西路仍需水军。吴用必须缩减并重配。

因此：方案设计可在吴用；有限水军最终配置的否决接口仍真实在宋江。

### C｜《西游记》孙悟空南海借净瓶

孙悟空有明确救师方向，但观音对净瓶、龙女和降妖资源的委托方式保留真实控制。净瓶不能被悟空直接拿走，龙女随行方案也未直接放行，最终解决接口保持在观音一侧。

因此：目标可在悟空；关键资源调用与处分接口仍真实外置。

## 3｜候选纪律

仅作为 pending-review：

> **判 nx 权限关系时，不能只从职位、所有权、授权链或名义审批倒推。高质量证据应优先要求外部权限节点表现出真实、可使用的否决、修改、不放行或资源保留能力。**

可压成四问：

```text
谁名义上拥有权限？
谁在冲突时真的能说“不”？
说“不”以后主体是否必须重配、等待或换通道？
主体能否低成本绕过这个节点？
```

## 4｜不等于修改 nx 定义

现行 nx v2.5 已经要求权限、资源或解决通道真实在别人手里，并禁止从职位、合同、监护等结构直接推出稳定 nx。

因此本问题更可能属于“证据纪律/准度强化”，而不一定需要修改 L1 或核心定义。

## 5｜与 xn / x / zx 的关系

```text
xn：主体自己设计怎么运行。
nx：关键外部权限仍能真实否决或限制。
x：该权限已经稳定归主体自行处分。
zx：主体把决定边界公开推到原本不属于自己的范围，并使秩序承认新增接口。
```

不同对象层可以同时出现，不能互相覆盖。

## 6｜后续验证需求

下一步优先寻找反例：

1. 名义上必须上报，但上级从不实际否决，主体实际上长期自行决定；
2. 外部节点曾经有权，但已事实弃权或自动批准；
3. 主体可以低成本绕过外部节点并稳定自行处分；
4. 同一人物跨阶段比较“真实外部否决存在 → 外部节点失效/弃权 → 权限转为 x 或进一步 zx”的变化。

## 8｜反向证据 1：诸葛亮建兴元年开府治事

《三国志·蜀书·诸葛亮传》与《资治通鉴》均记刘禅即位后，诸葛亮开府治事、领益州牧，“政事无巨细，咸决于亮”。

这个案例的重要性不是“诸葛亮权力很大”，而是它直接提供了一个与前三例相反的权限结构：

```text
名义最高者仍是刘禅
↓
但日常政务的实际裁决接口稳定落在诸葛亮
↓
史料不是写“诸葛亮上报后自动获批”
而是直接写“政事无巨细，咸决于亮”
↓
因此不能仅凭君臣名义层级锁 nx
↓
该对象层优先检查 x
```

### 与正向三例的差异

正向三例都有文本级的真实外部限制：

- 凤姐会反对、修改平儿方案；
- 宋江会否决吴用的水军配置；
- 观音会保留净瓶、龙女和最终降伏接口。

诸葛亮本例则相反：就“日常政务实际裁决”这个对象层，史料直接把决定位置写在诸葛亮一侧。

因此本反例支持候选纪律中的核心区分：

> **名义上级 ≠ 自动 nx；真实可使用的外部否决能力，才是高质量 nx 权限关系的关键证据。若实际事务长期由主体自行裁决，应优先检查 x。**

### 仍不直接修改正本

本反例虽然达到 evidence-locked，但目前只是一条高纯反向证据，尚不足以单独推动 L1 或信息卡改版。继续保持 pending-review，等待更多跨作品/历史反例和同人物阶段切换材料。
