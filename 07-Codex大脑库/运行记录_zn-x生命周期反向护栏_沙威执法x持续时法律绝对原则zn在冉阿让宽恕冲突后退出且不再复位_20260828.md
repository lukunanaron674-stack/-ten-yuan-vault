# 运行记录｜zn-x 生命周期反向护栏｜沙威：现实执法 x 仍在，但旧法律绝对原则 zn 在同类冲突中退出且不再复位

## 1｜为什么选这条

当前 lifecycle 已有 3 部作品正向控制，都证明 `x` 的关闭、失去、恢复或载体替换，不足自动删除此前已成立的 `zn`。

本轮按高信息增益优先级专找反方向：

```text
同一 x 仍现实 on
+
此前 zn 已独立成立
→ 后续同类冲突中旧 zn 明确不再进入最终排序
→ 且后续没有复位
```

P0 strict 正例本轮仍没有达到 ≥95% 的干净材料，不降门硬凑；因此转 P1。

## 2｜被测对象层

### 2.1 被测 zn

不是“沙威是警察”或“沙威严厉”。

被测原则压成：

> **法律与正式司法秩序拥有最终道德/行动裁定资格；既然对象依法应被逮捕，就不应因私人恩惠、同情或例外关系擅自放弃执行。**

这个原则在前期有独立硬证据：

- 沙威长期把法律秩序作为最高判断标准；
- 当他认为自己错误控告马德兰市长时，不是靠外部逼迫，而是主动要求上级将自己免职/惩罚，理由是自己失职，说明“依法、尽责、错误应受罚”已进入对自身的冲突排序；
- 他追捕冉阿让时，身份、私人感情和对方现实善行都长期不能覆盖“依法逮捕”的标准。

因此本轮把旧 `zn` 视为**此前已经独立成立**，而不是临时口号。

### 2.2 被测 x

被测 `x` 不是“警察职位名义”，而是沙威在下水道出口重新遇到冉阿让以后，对**当前逮捕 / 扣留 / 移交冉阿让这一具体执法对象层**拥有的现实处分权。

硬证据：

- 沙威实际重新控制冉阿让；
- 冉阿让明确处于其执法权力之下；
- 沙威可以决定是否立即押送、是否允许短暂绕行、最终是否交回司法系统；
- 最后“放走”之所以构成严重冲突，恰恰因为他当时拥有现实可执行的逮捕/移交权限，而不是只有空头职位。

所以：

```text
x_current_in_arrest_disposition_layer = true
```

## 3｜剧情事实链

### 阶段 A｜旧 zn 已高纯成立

早期沙威把法律与职责放在个人情感之上；即使错误可能伤害自己仕途，也主动要求因失职受罚。

结构：

```text
无奖励
+
对自己不利
+
仍要求按法律/职责标准处理
→ 旧 zn 进入最终排序
```

### 阶段 B｜冉阿让在街垒放走沙威

冉阿让本可杀死沙威，却解除束缚、让他离开。

这一步制造了此前原则模型无法轻易处理的新事实：

```text
依法应追捕的“罪犯”
+
现实上却对自己施以高代价宽恕
```

### 阶段 C｜x 仍真实 on

下水道出口以后，沙威重新控制冉阿让。

此时不是“警察身份还在”这么弱，而是同一逮捕对象层的现实处分已经重新到手：

```text
冉阿让在沙威控制中
→ 可以依法押回
→ x 当前真实 on
```

### 阶段 D｜旧 zn 不再完成最终排序

面对“依法逮捕冉阿让”这一与旧原则高度同型的现实冲突，沙威最后没有按旧规则执行，而是放走冉阿让。

重要的是：文本随后不是把这写成一次战术暂停，而是明确进入**原则体系崩解**：沙威意识到自己做了违反警察条例、司法秩序与法典的释放行为，并且无法再回到旧的单一法律标准。

最后他自杀。

所以本轮生命周期链为：

```text
old zn = established
+
current arrest/disposition x = still on
→ 新事实使旧原则失去最终指导能力
→ 在同类执法冲突中旧 zn 明确不再完成排序
→ 后续没有复位
→ old zn lifecycle exits / collapses
```

## 4｜为什么这是 lifecycle 反向护栏

此前正向控制主要防止：

```text
x 变了
≠
zn 一定变了
```

沙威反过来证明：

```text
x 没有先消失
≠
zn 就一定继续存在
```

因此真正应该锁的是：

> **`x lifecycle` 与 `zn lifecycle` 必须双向分离审计。`x` 持续 on，不能替此前已成立的 `zn` 保鲜；只要后续出现同类冲突，而旧原则明确不再进入最终排序并且无法复位，就必须允许判定旧 `zn` 已退出 / 崩解。**

## 5｜拿掉测试

### 拿掉 x

如果沙威根本没有重新获得对冉阿让的现实逮捕/移交权，那么“他是否仍按旧法律原则执行”就缺少同一对象层的硬测试。

因此当前 `x` 的持续存在，反而让本轮生命周期判断更强：

> 不是因为没权执行所以没执行，而是**有现实权限却无法再按旧原则执行**。

### 拿掉冉阿让的宽恕事实

如果没有“依法应追捕者却对沙威施以宽恕”这个新事实，缺少足够证据证明旧原则会在同一冲突中崩解。

所以关键第三因素不是职位变化，而是**旧原则无法吸收的新道德事实**。

## 6｜反向测试

若剧情是：

```text
沙威暂时放走冉阿让
→ 之后仍明确认为旧法律绝对原则正确
→ 下一次同类冲突重新依法逮捕
```

那么更适合判：

- 当前调用暂停；
- pressure-display / 临时遮蔽；
- 不能判旧 `zn` lifecycle 退出。

原作不是这样：放走之后，他明确无法把“依法逮捕”与新事实重新统一，最终没有复位，而是以自杀结束该原则体系。

## 7｜最近邻排除

### zn vs z

这不是因为外部认可撤销。相反，沙威仍处于警察与法律秩序一侧；旧原则崩解发生在内部判准无法继续工作时。

### zn vs xn

是否押送、先送马吕斯、走哪条路线属于流程；本轮问的是**为什么最终不再把依法逮捕作为最高排序**。

### x vs 名义职位

不能只说“沙威还是警察”。真正 `x` 证据来自他此刻确实能扣留、押送或释放冉阿让。

### lifecycle vs pressure-display

本案不是“旧原则一时表达不出来、后面又回来”。文本给出了同类冲突中的实质违背、明确原则崩解与最终不复位，因此优先计 lifecycle negative guard，不计 pressure-display positive。

## 8｜第三因素冻结

冻结：

- 沙威善恶评价；
- 冉阿让是否“更高尚”；
- 浪漫主义主题；
- 自杀的戏剧强度；
- 警察职业标签。

只保留：

```text
旧原则此前是否独立成立？
同一现实 x 是否仍 on？
后续是否出现同类冲突？
旧原则是否继续完成最终排序？
之后是否有复位证据？
```

结论不变。
