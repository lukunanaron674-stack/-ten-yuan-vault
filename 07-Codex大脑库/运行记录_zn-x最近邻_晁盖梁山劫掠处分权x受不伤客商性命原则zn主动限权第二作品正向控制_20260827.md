# zn ↔ x 最近邻｜晁盖：真实山寨处分权 x 受“不伤无关者”原则 zn 主动限权

## 1｜窄对象层

本轮只测试两个明确对象：

- `x`：晁盖成为梁山山寨之主后，对山寨人马、劫掠行动、战利品分配和行动边界拥有现实指挥/处分权限；
- `zn`：在取财、脱险和武力行动中，对不抵抗的客商/无关百姓不得任意伤害，财富获取与战斗便利不能自动越过这条内部边界。

不据“山寨之主”“义士”“好汉”等身份标签直接判端点。

## 2｜剧情事实与可观察结果

第20回，晁盖已真实履行山寨首领权限：调拨阮氏、刘唐、杜迁、宋万等人下山，安排接应；战后又能决定财物入库与分配、人员安置等。

当朱贵探知客商经过时，晁盖同意取其金帛财物，但明确给行动划线：只取财物，不得伤害客商性命。次日报捷时，他首先追问是否杀人；得知客商逃走且无人被害后明显认可，并再次强调山寨不可伤人。

第39回江州劫法场后，李逵沿江滥杀百姓，晁盖再次在高压撤退窗口中制止，明确区分“救人/突围”与“伤害无关百姓”。

因此该边界不是一次偶发口号，而是在不同压力情境下重复进入现实选择。

## 3｜x 证据

`x` 不是“名义当头领”，而是现实权限已经进入晁盖直接调用边界：

- 能分派多批人马执行具体行动；
- 能调整接应与增援；
- 能规定战利品如何入库、如何分配；
- 能给劫掠行动设定可做/不可做的处分边界；
- 指令实际被山寨组织执行。

所以当前山寨行动与处分权限层 `x` 独立成立。

## 4｜zn 证据

本轮被测原则不是抽象“仁义”，而是窄规则：

> 在取财、脱险或战斗便利与无关者生命发生冲突时，不能因为自己有力量/权限就任意伤害不抵抗客商和百姓。

该原则通过以下压力门：

1. 无外部奖励：没有因为“不杀客商”得到新的上级许可或外部奖赏；
2. 冲突排序：更彻底暴力可以降低劫掠或撤退中的操作阻力，但晁盖仍主动限制己方武力；
3. 边界明确：可以取财/战斗，但不能因此任意伤害无关者；
4. 未来调用资格：第20回形成规则后，第39回在完全不同的江州脱险压力下再次出现同型限制。

因此当前原则对象层 `zn` 独立成立。

## 5｜zn vs x 最近邻

本例新增的不是“有原则所以没有 x”，恰好相反：

```text
x 已成立
→ 我确实有现实能力和权限这样做

zn 仍成立
→ 但并非所有可处分范围都值得被使用
→ 原则给 x 划出不可越过的使用边界
```

因此最短判别句：

> **有权做什么，是 x；为什么即使有权也不做某些事，是 zn。**

这与关羽挂印封金形成第二独立作品控制：

- 关羽：zn 在冲突中促使主体主动让渡部分 x；
- 晁盖：zn 在冲突中主动限制已成立 x 的使用方式。

说明 `zn vs x` 的区分不能缩成“是否丢掉资源”，还包括“是否给现实掌握权设不可越过的处分边界”。

## 6｜拿掉测试

### 拿掉 zn

保留晁盖首领权限、人马、财物调度权与劫掠目标，但删除“不伤无关者”原则，则同一 x 结构仍可完整存在，只是对客商/百姓的武力处分边界明显扩大。

说明 `x` 不依赖 `zn` 才成立。

### 拿掉 x

保留“不应任意伤害无关者”的原则，但假设晁盖没有山寨人马和处分权限，该原则仍可作为内部判断存在，只是缺少当前这批现实对象可供限制。

说明 `zn` 也不等于 `x`。

本轮只做最近邻分离，不据此自动升级 `zn+x strict complement`。

## 7｜反向测试

若文本改成：

- 晁盖只是口头说“不伤人”，但无人听从且他无现实指挥权，则 `x` 下降；
- 只有在外部惩罚、官府压力或收益计算下才临时不杀人，压力一撤原则就消失，则 `zn` 下降；
- 本次仅因“客商已经逃掉、无需再杀”而事后美化，则不足以锁 `zn`。

原文本反而显示事前明确限权、事后复核，并在江州另一压力情境再次制止滥杀。

## 8｜最近邻排除

- `zn vs z`：没有依赖外部认可、封号或奖赏；
- `zn vs xn`：分派接应、分配战利品有 xn 邻近，但“为何不能伤无关者”不是流程问题；
- `x vs zx`：成为首领、打赢官军可另查 zx，但本轮锁的是已经形成后的现实处分/调用边界，不重复把每次下令都记成扩权；
- `x vs nx`：这些山寨人马与行动处分在本窗口已可由晁盖直接调拨，不需逐次经过另一外部许可节点。
