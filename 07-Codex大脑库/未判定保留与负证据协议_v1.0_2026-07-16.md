# 未判定保留与负证据协议 v1.0

## 1. 协议目的

本协议解决一个基础问题：

```text
什么时候必须停止判定，保留未知；
什么能够构成反证；
什么只是尚未观察到，不能被误写成不存在。
```

本协议不新增三元或十元定义，不修改生克补位置，也不把三元与十元写成父子派生关系。

## 2. 未判定是正式结果

当证据不足、对象层混杂、阶段边界不清或最近邻无法排除时，正式输出可以是：

```text
未判定
候选未收束
当前只确认对象层，不确认十元点位
当前只确认功能，不确认人物本体
```

未判定不是失败，也不是等待后置关系替它补答案。

禁止为了完成表格、凑齐 Top-2、运行动态链或归入五大主题而制造点位。

## 3. 三类“没有”必须分开

### 3.1 未观察到

```text
现有材料没有提供相关证据。
```

只能得出：

```text
未知 / 证据不足
```

不能得出：

```text
该十元不存在
该三元倾向不存在
人物没有这种稳定本体
```

### 3.2 暂未显影

对象可能具有某稳定锚点，但在当前阶段、场景或关系中没有高显影。

```text
低显影 ≠ 不存在
退隐 ≠ 被删除
未被当前行为调用 ≠ 人物失去该本体
```

剧情变化优先解释为状态、行为功能、关系位置、场景、时间压力和动态链顺序变化。

### 3.3 有结构性反证

只有出现与候选核心成立方式相冲突的稳定证据，才可作为负证据。

负证据必须说明：

```text
反对的是哪个候选；
冲突发生在哪个对象层；
是否跨阶段重复；
是否在有选择余地时仍成立；
它破坏了候选的哪一项核心条件。
```

## 4. 负证据的最低标准

一条材料要成为人物稳定本体的负证据，至少应满足两项：

```text
跨阶段重复；
在关键选择中出现；
不是被迫服从、伪装、失能或场景限制；
与候选的存在方式、核心痛苦或反复选择直接冲突；
拿掉该反证后，候选才勉强成立。
```

单次反常行为通常只证明状态变化、行为功能变化或关系压力，不足以推翻人物核心锚点。

## 5. 各对象层的反证不得串层

```text
光影反差
不能反证人物本体；

场景压迫
不能反证人物本体；

一次行为失常
不能反证稳定本体；

当前状态低显影
不能反证稳定本体；

关系失败
不能反证端点原有十元；

结局死亡、失败或被捕
不能反证人物此前的存在方式。
```

反证必须在目标层重新成立。

## 6. Top-2 不是强制配额

十元判定校准中的 Top-2 是候选收束工具，不是必须凑满两个标签的格式要求。

允许：

```text
只有一个弱候选；
三个候选尚未排除；
只确认不是某两个最近邻；
只确认功能层，不确认本体层；
完全未判定。
```

禁止：

```text
因为模板要求 Top-2，便从视觉、职业、场景或结局中补第二候选。
```

## 7. 进入关系链前的停机条件

出现任一情况，应停止进入最终生克补或动态链：

```text
端点对象层未冻结；
端点仍为 B / C 级；
端点只有表面关键词支持；
人物本体与当前状态未分开；
行为功能被当成人物本体；
场景、时间或光影证据被转借给人物；
三元与十元尚未独立判断；
关系只能靠结局倒推；
存在同等强度的相反解释。
```

此时只能写：

```text
候选链
待复验关系
尚不能启动关系判定
```

## 8. 冲突证据的处理顺序

当材料互相冲突时，不做平均，也不选更顺故事的一边。

```text
先检查是否属于不同对象层；
再检查是否属于不同阶段；
再检查是否为本体与状态差异；
再检查是否为主动选择与被迫反应差异；
最后才判断是否真正反证。
```

若冲突仍无法消解，保留未判定。

## 9. 人物核心锚点的保护

人物稳定本体优先保持不变。

下列现象优先解释为显影变化，而非核心改写：

```text
遭受压制后沉默；
进入陌生场景后行为收缩；
临近结局时暂时极端化；
被迫服从；
为了关系采取非典型行为；
光影、服装或姿态突然改变；
某一阶段副元高显影。
```

只有人物的存在方式、核心痛苦与反复选择出现持续、主动、跨阶段的整体重构，才重新审核稳定本体。

## 10. 三元与十元的未判定必须分别保留

```text
十元未判定
不等于三元也未判定；

三元未判定
不等于十元也未判定；

三元已有倾向
不能替十元补点位；

十元候选明确
不能反推唯一三元比例。
```

两套系统分别记录证据、置信度与反证。

## 11. 标准输出

```text
- 分析对象：
- 对象层：本体 / 状态 / 行为 / 场景 / 时间 / 光影 / 关系
- 当前可确认：
- 当前候选：
- 未观察到：
- 暂未显影：
- 结构性反证：
- 最近邻尚未排除：
- 十元结论：A / B / C / 未判定
- 三元结论：独立填写 / 未判定
- 是否允许进入关系链：是 / 候选链 / 否
- 仍缺的最小证据：
```

## 12. 最终封存

```text
没有证据，不等于没有该元。
没有显影，不等于人物失去核心。
一次反常，不等于稳定本体被推翻。
未判定是正式结论，不得由关系、主题或故事顺滑度代填。
人物核心优先稳定，变化优先落在状态、关系与动态链。
```
