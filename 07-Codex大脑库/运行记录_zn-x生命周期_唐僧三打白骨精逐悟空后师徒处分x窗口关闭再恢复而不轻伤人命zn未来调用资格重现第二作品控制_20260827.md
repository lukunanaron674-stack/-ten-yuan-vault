## 3｜生命周期事实链

### 阶段 A｜第27回：zn + x 同时运行

唐僧把孙悟空击杀的人形对象理解为平人，以“不应行凶伤人”的判断反复使用紧箍、警告，并最终写贬书逐走孙悟空。

本阶段：

```text
不轻伤人命 zn = 高调用
师徒处分 / 约束 x = 现实运行
```

### 阶段 B｜逐走后：当前师徒直接处分 x 的对象退出同行窗口

唐僧不是把处分权“换成了另一种更强 x”，而是直接使用既有处分 `x` 终止当前同行关系。孙悟空离队后，原先针对“当前同行孙悟空”的紧箍、留用、逐退等直接处分接口不再是当前可持续运行对象。

本阶段只锁：

```text
active_master_disciple_disciplinary_x_window = off / inactive for current同行对象
```

不声称两人的全部历史师徒关系在宇宙意义上彻底不存在，也不声称唐僧的 zn 在离队期间每一刻都高显影。

### 阶段 C｜第31回：孙悟空重返，师徒同行关系恢复

孙悟空因宝象国危机重新返回并救回唐僧，唐僧重新以“悟空 / 贤徒”关系接纳，取经同行恢复。

此后，师徒处分/约束对象再次进入当前关系窗口。

### 阶段 D｜第56-57回：同一 zn 原则再次进入同类处分排序

草寇事件中，孙悟空再次因杀伤人命与唐僧发生冲突；唐僧再次以“不应轻伤性命”的原则责罚、逐走孙悟空。

因此观察到：

```text
阶段A：zn 高调用 + x 运行
→ 阶段B：当前直接处分 x 窗口关闭
→ 阶段C：关系恢复，x 窗口重新打开
→ 阶段D：同一 zn 原则再次获得未来调用并进入处分排序
```

## 4｜本轮真正锁出的生命周期结论

本轮不锁“zn 在阶段B每一刻都持续高显影”，因为文本没有必要提供这种连续监测。

可靠结论是：

> **当前关系 `x` 的运行窗口关闭，不足以删除 `zn` 的未来调用资格；当同类关系对象重新进入现实窗口后，同一原则可以再次被调用。**

也就是：

```text
x current-window off
≠
zn future-call qualification erased
```

这与严颜首份 lifecycle 控制形成不同机制：

- 严颜：领地/军政 `x` 真实失去后，`zn` 在同一高压窗口仍直接继续排序；
- 唐僧：关系处分 `x` 当前窗口关闭并后来恢复，同一 `zn` 在后续跨阶段重新进入同类排序。

两案共同支持：**`x` 生命周期与 `zn` 原则的未来调用资格不是同一个变量。**

## 5｜zn 证据

本轮沿用既有原则锚：

> 对人命不可轻率施杀；取经关系不能只因为“保护我 / 战力高”就无限放开徒弟对疑似平人的杀伤。

该原则在第27回与第56-57回两个远隔窗口重复进入高代价冲突排序，因此符合 `zn` 准度卡的“跨阶段保留未来调用资格”门。

本轮新增价值不是再证明 `zn=true`，而是证明：**关系 `x` 中间经历 off→on，并没有让这项原则只能解释为第一次关系窗口的临时规则。**

## 6｜x 证据

被测 `x` 仍然只限于：

> 唐僧对孙悟空当前师徒同行关系的现实处分 / 约束权限。

第27回它能通过紧箍、警告、逐退直接生效；逐走后当前直接处分对象退出同行窗口；第31回重新接纳后关系恢复；第56-57回再次能使用同类处分。

因此本轮锁的是 `x` 的**当前窗口生命周期**，不是“孙悟空这个人归唐僧所有”。

## 7｜拿掉测试

### 拿掉 x 窗口持续性

即使第27回逐走后，原直接处分关系暂时不再运行，第56-57回同一原则仍能再次进入判断。

所以：

> `zn` 的未来调用资格不依赖这项 `x` 在所有中间阶段连续保持 on。

### 拿掉 zn 的未来资格

如果第27回只是一次误判/情绪，而后续草寇事件完全不再出现同类杀生边界，则不能锁本轮 lifecycle。

原著提供了跨阶段复现，因此反向不成立。
