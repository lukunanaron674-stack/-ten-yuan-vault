# 林冲柴进庄：长期逃生方向非 nx，与局部庇护/盘缠/荐书 nx 可以同时成立

## 结论先行

本轮不重复“柴进庄旧 nx 因搜捕压力失效后转接梁山”的既有时间窗口结论，而是换对象层重新压力测试：

> 林冲在山神庙后并没有把“是否继续逃避官府追捕、是否另寻安身处”这一总体去向交给柴进决定，因此长期逃生/自保方向层不应判 nx；但在“柴进庄能否现实庇护、盘缠能否取得、梁山荐书与准入能否成立”这些局部对象层，关键资源和通道真实掌握在柴进、朱贵、王伦等外部节点手里，林冲实际接入并续接，因此局部 nx 关系功能成立。

这与《三国演义》关羽屯土山案例形成第二部独立作品复验：

```text
长期最终方向不交给外部
≠
桥段中所有局部许可/资源/保护关系都不是 nx
```

## 1｜剧情事实、触发、对象、动作与结果

### 触发

林冲在山神庙后杀死陆谦、富安等人，官府追捕升级，成为必须继续寻找安全去处的逃亡者。

### 柴进庄阶段

林冲再次到柴进庄后，柴进真实收留，林冲在东庄住了数日。这里不是一句情义表态，而是庄院、食宿、庄客与现实庇护都真正进入林冲当前生存链。

### 搜捕升级与主体自己的去向决定

官府画影图形、沿乡搜捕后，林冲主动向柴进提出：不是柴进不肯留，而是继续留下会连累柴进，因此请求盘缠，准备另投他处栖身。

这一动作说明：

```text
是否继续留在柴进庄
是否另寻安身处
是否继续逃离官府追捕
→ 当前最高去向并未由柴进替林冲决定
```

### 外部局部资源与通道

林冲虽然自己决定继续离开、另寻安身处，但他不能单方面生成：

- 柴进庄的现实庇护资格；
- 柴进愿意提供的盘缠；
- 柴进与梁山王伦等人的既有关系；
- 柴进荐书的信用作用；
- 朱贵的识别与接引；
- 王伦/梁山最终准入。

柴进提出梁山并修书推荐，林冲接受；之后林冲携荐书到梁山，经朱贵接引，实际进入王伦的准入链。

最小链：

```text
总体终点：
继续逃避追捕 / 寻求可持续安身
→ 林冲自己保持
= 长期方向层非 nx

局部现实条件：
柴进庄庇护
+ 盘缠
+ 柴进荐书
+ 梁山准入
→ 权限/资源在外部节点
→ 林冲真实接入并承接
= 局部 nx
```

## 2｜为什么长期逃生/自保方向层不是 nx

林冲没有把“要不要继续逃、要不要另投他处、何时离开柴进庄”交给柴进作最终裁定。

关键事实是：搜捕升级以后，林冲自己提出离开柴进庄，并明确表示另投他处安身。柴进随后提供的是一个现实可用路径，而不是替林冲生成“我现在要不要继续逃亡”这个最高终点。

因此本轮锁：

- `long_term_escape_or_survival_direction_nx: rejected`

这并不自动等于 zx。主动保留自己的去向，只能先排除该层 nx；是否 zx 还需另外检查公开显权与决定范围扩大。

## 3｜为什么局部庇护/盘缠/荐书层可以成立 nx

### A｜柴进庄庇护

庄院、庄客、食宿与柴进本人是否愿意承担庇护风险，都不属于林冲稳定处分范围。林冲真实接受并住在东庄，因此：

- `local_shelter_nx_relation_function: evidence-locked`

### B｜盘缠

林冲主动决定离开，但离开所需盘缠由柴进外部资源接口提供。林冲不能凭“我想走”自动生成柴进的钱，因此：

- `travel_funds_nx_relation_function: evidence-locked`

### C｜荐书与梁山准入

柴进拥有与梁山人物的既有社会关系，并实际修书推荐；林冲随后沿荐书→朱贵接引→王伦准入继续推进。

因此：

- `recommendation_and_admission_channel_nx: evidence-locked`

这里的 nx 不是“林冲没主见”，而是：

> 自己的总体去向仍由自己保持，但让这个去向现实落地所需的某些局部许可、资源与关系接口确实在别人手里。

## 4｜zx 判断

本窄阶段不以 zx 主判。

林冲主动决定离开柴进庄、继续求生，并没有因此：

- 取得柴进庄的处分权；
- 取得梁山成员准入权；
- 迫使官府追捕结构围绕林冲的新权限接口重排；
- 扩大自己的公共决定范围。

所以：

> 自己决定“我接下来去哪” ≠ zx。

本轮锁：

- `zx_from_escape_choice_itself: rejected_as_primary`

## 5｜关键压力

压力包括：

- 官府追捕；
- 柴进庄被连累风险；
- 林冲当前无稳定合法安身处；
- 梁山准入仍需经过外部节点。

这些压力不能直接判 nx。

真正的 nx 证据必须落到局部对象层：

> 谁能现实提供庇护、盘缠、信用推荐和组织准入？林冲有没有实际沿这些接口续接？

## 6｜拿掉测试

### 拿掉柴进的庇护/盘缠/荐书

林冲“继续逃避追捕、另寻安身”的总体方向仍然存在。

但会留下多个现实缺口：

- 当前安全住处消失；
- 离开所需盘缠缺失；
- 梁山荐书与熟人信用通道消失；
- 进入梁山的现实难度显著上升。

因此局部 nx 是真功能。

### 拿掉林冲自己的继续逃生方向

如果林冲决定自首、返回官府处置，那么柴进提供梁山荐书也不会自动生成“继续逃亡并投梁山”这个总体方向。

所以外部局部通道不能反向覆盖主体最高终点。

## 7｜反向测试

### 长期方向也变成 nx

若柴进规定：

```text
你必须去梁山
什么时候离开由我决定
你不能选择其他安身终点
```

而林冲真实接受并把最终去向交给柴进，则长期方向层 nx 才明显上升。

原文不是。

### 局部资源层不再 nx

若林冲自己稳定拥有：

- 安全庄院；
- 可自由调用的盘缠；
- 梁山内部稳定准入权；

则这些局部对象层会转查 x/xn，而非 nx。

## 8｜最近邻排除

### nx vs xn

林冲会判断搜捕风险并决定转移，存在计划邻近；但庄院庇护、盘缠、荐书信用和梁山准入并非他自己搭建的人员/资源/流程系统，因此这些局部层仍优先 nx。

### nx vs x

柴进的钱、庄院和梁山准入接口都不属于林冲自己的稳定调用边界。

### nx vs zx

自己保留总体去向，只能说明该层非 nx；要锁 zx 仍需公开显权、外部响应和决定范围扩大。

### 长期方向层 vs 局部资源/许可层

这是本轮核心：

```text
“我总体要不要继续逃、去哪里活下去”
≠
“我当前必须经过谁取得住处、盘缠、推荐与准入”
```

前者可以非 nx，后者可以同时 nx。

## 9｜第三因素冻结

冻结：

- 林冲武力；
- 柴进义气评价；
- 官府正当性；
- 王伦性格；
- 后续火并王伦；
- 林冲稳定人物类型。

只看：

1. 总体逃生/安身终点由谁决定？
2. 庇护、盘缠、荐书与准入由谁拥有现实资源/权限？
3. 林冲是否实际经过并承接这些外部接口？

结论仍稳定：

```text
长期逃生/自保方向层：非 nx
局部庇护/盘缠/荐书/准入层：nx 成立
```

## 10｜与关羽屯土山的跨作品最小差异

### 关羽

```text
长期归属刘备
= 非 nx

曹方家属供养 / 门禁安全 / 暂时庇护
= 局部 nx
```

### 林冲

```text
继续逃生 / 另寻安身总体去向
= 非 nx

柴进庄庇护 / 盘缠 / 荐书 / 梁山准入
= 局部 nx
```

共同支持：

> 一层非 nx 不得覆盖其他对象层的局部 nx。

目前该边界已跨《三国演义》《水浒传》两部独立作品复现，尚未达到三作品待审议阈值。

## 11｜严格 zx补nx 检查

本轮不锁严格补关系。虽然林冲自己的逃生方向与外部资源/通道确实存在功能配合，但当前没有必要为了形成对子，把“总体逃生方向非 nx”强行升级为独立高纯 zx，再制造双向不可替代缺口。

## 下一证据目标

优先寻找《红楼梦》或《西游记》第三个同型：

> 主体明确保留自己的长期最终方向，但在某个局部保护、许可、资源、专业或关系对象层真实接入他者接口。

若跨至少三部独立作品稳定复现，再建立“nx 对象分层不可互相覆盖”的待审议纪律；本轮不修改 L1 或核心信息卡。
