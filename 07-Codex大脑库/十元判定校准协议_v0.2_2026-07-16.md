# 十元判定校准协议 v0.2

> 本协议只负责把分析对象判到正确十元点位。三元、十元、生克补、动态链和五大主题是相互配合的分析层，不得写成父子派生关系；任何后置关系都不能反过来替错误点位补答案。

## 1. 正式顺序

```text
锁定分析单位
→ 无标签观察
→ 区分对象层
→ 提出十元 Top-2
→ 区分主 / 副 / 功能 / 视觉
→ 最近邻排除
→ 拿掉测试 / 起手测试
→ 十元点位确认
→ 十元与三元的比例质感核对
→ 独立三元判定
→ 生克补查表
→ 动态链
→ 五大主题归仓
```

任何一步没有通过，后面步骤不得替前面补答案。

## 2. 先锁定分析单位

必须先写清楚当前判断的是：

```text
整部作品 / 单个角色 / 角色某阶段 / 一段关系 / 一个行为
单场戏 / 场景环境 / 时间结构 / 光影视觉 / 物象 / 规则
```

整部作品通常不是一个纯十元。训练准度时优先使用角色阶段、单场戏、单一关系动作等较小单位。

## 3. 无标签观察

在写十元前，只记录可验证内容：

```text
谁在做什么？
什么反复出现？
哪件事使结构不可逆？
角色最怕失去什么？
哪个是表层行为，哪个是底层驱动？
什么被拿掉后，人物会不再成立？
外部场景和时间条件对人物做了什么？
```

禁止根据题材、职业、服装、光影、结局或单一关键词直接填十元。

## 4. 强制区分对象层

每次判断至少拆成以下七项：

```text
【人物稳定本体】
【当前人物状态】
【关键行为功能】
【外部场景】
【时间关系 / 时间结构】
【视觉与光影辅助】
【关系变化与动态链】
```

规则：

- 人物稳定本体：跨阶段反复成立，拿掉后人物的存在方式、核心痛苦和反复选择同时崩塌。
- 当前人物状态：压力下暂时高显影或低显影，不自动改写本体。
- 关键行为功能：某一段剧情承担执行、承载、冲突、停靠、结算等作用，只能证明当下功能。
- 外部场景：环境本身的十元，不得越级变成人物本体。
- 时间关系 / 时间结构：长期积累、阶段顺序、等待条件、历史惯性等独立记录。
- 视觉与光影：只负责外观、姿态、气氛和显影方式，不能单独判人物主十元。
- 关系与动态链：说明谁压制谁、谁补住谁、什么发生变化；不能反向证明端点。

## 5. 十元候选表

| 十元 | 当前核心检查方向 | 常见误判 |
|---|---|---|
| zx | 张扬醒目；主体权能显现、扩大；被压制后持续复起 | 有目标、有效率、会执行、先动手不自动等于人物本体 zx |
| x并z | 表象、包装、被观看、媒介化、伪装与身份壳 | 漂亮、会表演、穿着醒目不自动等于 x并z |
| zn | 意义、信念、精神核心、价值归宿 | 有目标、有口号、正义职业不自动等于 zn |
| z | 执念、光点、爆点、被看见、被点燃 | 努力、坚持、热血不自动等于 z |
| n | 承载、安顿、处理、维持关系与生活结构 | 被动忍受、待在家里不自动等于 n |
| nz | 依恋、停靠、柔情、舍不得结束 | 爱人、等待、回家不自动等于 nz |
| xn | 主动把信息、行动与资源放进计划、时间、规则或隐藏结构，通过记录、等待、重复和积累形成持续力量 | 一次思考、普通职业理性、身处制度场景不自动等于 xn |
| nx | 不主动占据选择、方向和位置，把决定留给别人、流程、关系或现状，并沿既有安排继续 | 沉默、聪明、暗中观察、算计、记账、等待翻牌不自动等于 nx |
| xz | 临界、漂流、危险边缘、命运不稳 | 遇到危险、经历悲惨不自动等于 xz |
| x | 欲望、占有、吞没、深层驱动与失控 | 黑暗、冷酷、反派不自动等于 x |

第一次只提交 Top-2，不急着制造唯一答案。

## 6. 主、副、功能、视觉

| 层级 | 判断标准 |
|---|---|
| 主十元 | 拿掉后，人物存在方式、核心痛苦和反复选择同时崩塌 |
| 副十元 | 长期为主十元提供方向、厚度、压力或保存机制 |
| 功能十元 | 只负责某段剧情中的具体作用，不代表人物本体 |
| 视觉十元 | 只负责外观、气氛、姿态和第一印象 |

不得用行为频率代替人物本体，也不得因为某状态持续很久就自动把它升格为本体。

## 7. 三道门

### 7.1 拿掉测试

拿掉该十元，当前分析单位是否立即失去成立方式？

### 7.2 最近邻排除

至少排除一个最近邻，例如：

```text
zx vs z
zx vs xn
zn vs z
n vs nz
xn vs nx
xz vs x
x并z vs x
```

### 7.3 起手测试

它是最早、最深、最反复使人物运动的力，还是中途才出现的剧情工具、环境压力或状态显影？

三道门都通过才能标记 A 级；否则只保留候选。

## 8. 置信度门槛

| 等级 | 条件 | 后续动作 |
|---|---|---|
| A | 本体与状态、行为、场景、时间、视觉已分开；拿掉测试通过；最近邻已排除 | 可进入生克补 |
| B | Top-2 明确，但主位或对象层仍难分 | 保留候选，只写候选链 |
| C | 分析单位混杂或证据不足 | 拆小单位，重新观察 |

```text
只有 A 点可以进入强关系链。
A + B 只能写候选链。
B + B 或含 C，不得写最终生克补。
```

## 9. 生克补硬门槛

只有端点通过点位审核后，才查标准位置盘：

```text
生：A 是否结构性推出 B？
克：A 是否压制、限制或迫使 B 转向？
补：A 与 B 是否为不完整的两极，合起来形成完整张力？
```

几何位置关系与内容语义必须分开：旧关系表中的位置可以保留，但若旧角色名、动机解释或比喻与当前信息量卡冲突，旧语义冻结，不能继续自动补义。

## 10. 当前锁定的 zx / xn / nx 边界

```text
zx：我要让主体权能进入现实、扩大，或在压制后再次复起。
xn：我要把信息、行动与资源放进时间和结构，使积累发挥力量。
nx：此刻我不建立方向、不占据位置，沿既有条件继续。
```

### 10.1 行为与本体

```text
目标执行、路径推进、换路、破局、做成、重新站起
```

这些是 zx 的常见行为，但不能单独证明人物本体 zx。

```text
暗中观察、隐蔽判断、算计、记录、等待节点、延迟结算
```

这些优先归 xn 检查，不再归 nx。

### 10.2 等待的分界

```text
为了计划、节点、积累和结算而等待 → xn
因为不主动占据选择和方向而继续等 → nx
```

## 11. 人物核心锚点稳定原则

故事人物的核心锚点优先保持稳定。剧情变化首先解释为：

```text
显影强度变化
+ 当前状态变化
+ 行为功能变化
+ 外部场景与时间压力变化
+ 关系位置变化
+ 动态链顺序变化
```

不得轻易写成：

```text
人物原本没有某副元
→ 经历事件
→ 中途生成一个新副元
```

只有人物存在方式、核心痛苦与反复选择整体重构，并通过重新审核，才考虑稳定本体改变。

## 12. 孙悟空校准锚

本卡只指《西游记》中的齐天大圣孙悟空：

```text
人物稳定本体：zx + nx
求学阶段：zx 与 nx 已存在
大闹阶段：zx 高显影
五行山：外部高体量 xn 克 zx，原有 nx 高显影
条件解除：zx 再次复起
```

五行山改变的是行动条件、状态显影和关系位置，不生成新的 nx。

其中“求学阶段已表现 nx”是当前用户确认的人物结构锚；在逐段原著事件证据卡建立前，不擅自扩写未经核对的具体段落作为证明。

## 13. 三元与十元的关系禁区

```text
三元不是十元的父级。
十元不是由三元派生出的子类。
三元判定不能替代十元判定。
十元判定也不能反推唯一三元答案。
```

允许做的是并行核对、语义映射和关系验证；不允许写成谱系式生成关系。

### 13.1 三元复核的正式顺序

```text
先独立确认十元点位
→ 写出该点位可能呈现的x/n/z比例质感
→ 再用三元自身证据独立判断比例
→ 核对两层是否相容
→ 最后才允许验证十元生克补
```

当前三元定义：

- x（醒）：具体对象、物质关系、所有权、价值、局部因果、切分与边界。
- n（耐）：精神整体、多方关系、理解、包容、协调与承载。
- z：精神个体需要认可主体看见、回应并确认自己的位置。

若三元结果与十元候选冲突，回到无标签证据重查；不得为了符合公式而改点位。

### 13.2 xn的x多n少质感

```text
x：切分、判断归属、价值与积累
+ 少量n：把私人边界扩大并稳定成家族、阶级、资本、制度与高墙
= 已判xn的一种内部比例质感
```

强x的正确是“只有我是对的，你们都是错的”；强n的正确是“你们都对，但我是最对的”。这一对照只用于解释质地，不直接生成xn。

## 14. 安迪校准锚

> **“计划正在被执行”不等于人物主zx。**

如果大量行动是深层思考、长期计划和秩序结构的产物，应优先检查xn；zx可能只是把计划落地的功能十元，精神信仰可以位于zn副位。

```text
安迪（《肖申克的救赎》）
主十元：xn
副十元：zn
功能十元：zx
```

## 16. 最终封存

```text
先拆分析单位，
再分人物本体、状态、行为、场景、时间、视觉和关系，
再做最近邻排除、拿掉测试与起手测试，
再独立复核三元比例，
最后才允许生克补和动态链运行。

点位负责真，关系负责动；
点位不真，关系越完整，错得越稳定。
```
