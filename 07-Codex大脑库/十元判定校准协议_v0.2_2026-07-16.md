# 十元判定校准协议 v0.3

> 本协议只读取现行正本信息量卡与正式关系表。错误旧卡、迁移池和覆盖补丁不再参与判定。

## 1. 正式判定顺序

```text
锁定分析单位
→ 无标签观察
→ 区分对象层
→ 提出十元 Top-2
→ 最近邻排除
→ 拿掉测试
→ 起手测试
→ 确认主 / 副 / 功能 / 视觉
→ 十元点位确认
→ 查正式生克补位置
→ 证明具体作用机制
→ 组成动态链
→ 五大主题归仓
```

后置关系不能反过来替错误点位补答案。

## 2. 先锁定分析单位

每次先写清楚当前判断的是：

```text
整部作品 / 单个角色 / 角色某阶段 / 一段关系 / 一个行为
单场戏 / 外部场景 / 时间结构 / 光影视觉 / 物象 / 规则
```

整部作品通常不是一个纯十元。训练准度时优先使用角色阶段、单场戏、单一关系动作等较小单位。

## 3. 无标签观察

在写十元前，只记录可验证内容：

```text
谁在做什么？
谁决定方向？
谁掌握对象、资源和权限？
谁主动组织时间、流程和节点？
谁需要沿别人的关系与权限通道办事？
什么反复出现？
什么被拿掉后，人物或场景不再成立？
```

禁止根据职业、身份、服装、道具、题材、光影、结局或单一关键词直接填十元。

## 4. 强制区分对象层

每次至少拆成：

```text
【人物稳定本体】
【当前人物状态】
【关键行为功能】
【关系位置与权限通道】
【外部场景】
【时间关系 / 时间结构】
【视觉与光影辅助】
【动态链变化】
```

### 规则

- 人物稳定本体：跨阶段反复成立，拿掉后人物整体崩塌。
- 当前状态：某阶段高显影或低显影，不自动改写本体。
- 行为功能：只证明当下怎样办事。
- 关系位置与权限通道：判断方向和权限在谁手中，尤其用于 nx。
- 外部场景：环境本身的十元，不得越级变成人物本体。
- 时间结构：长期积累、规则、阶段顺序和历史惯性独立记录。
- 视觉：只负责外观与显影方式。
- 动态链：说明关系怎样变化，不能反向生成端点。

## 5. 十元候选表

| 十元 | 当前核心检查方向 | 常见误判 |
|---|---|---|
| zx | 权能公开显现、张扬扩大、凌驾于他者之上 | 有目标、会执行、很能打、很能挨打不自动等于 zx |
| x并z | 表象、包装、被观看、媒介化、身份壳 | 漂亮、会表演、醒目不自动等于 x并z |
| zn | 意义、信念、精神核心、价值归宿 | 有口号、做正确事不自动等于 zn |
| z | 执念、光点、爆点、被看见、被点燃 | 努力、坚持、热血不自动等于 z |
| n | 承载、安顿、处理、维持关系与生活结构 | 被动忍受、待在家里不自动等于 n |
| nz | 依恋、停靠、柔情、舍不得结束 | 爱人、回家、等待不自动等于 nz |
| xn | 主动组织计划、时间、规则、信息、流程和节点，使积累形成持续力量 | 遵守规则、接受命令、普通工作不自动等于 xn |
| nx | 不占据方向决定权，沿别人、关系、流程、秩序或现状给出的方向推进 | 沉默、幕后、聪明、看牌、记账不自动等于 nx |
| xz | 临界、漂流、危险边缘、命运不稳 | 遇到危险或悲惨不自动等于 xz |
| x | 对象、资源、地盘、权限和关系被纳入“归我 / 我方掌握”的边界 | 黑暗、欲望、吞噬、反派、幕后身份不自动等于 x |

第一次只提交 Top-2，不急着制造唯一答案。

## 6. 四元核心边界

```text
x：什么归我掌握。
zx：我的权能怎样公开显现、扩大并压过他者。
xn：我怎样主动组织它持续运行。
nx：方向和权限不在我这里，我怎样沿已有关系与安排推进。
```

### 6.1 x vs zx

```text
幕后控制整片地盘：x。
公开登场让所有势力低头：zx。
```

判断句：是在强调“东西归谁”，还是“谁的力量骑到所有人头上”？

### 6.2 xn vs nx

```text
老板安排什么就做什么：nx。
接到目标后主动排程、搭流程、分资源、预判节点：xn。
```

判断句：方向由谁定，运行方式由谁组织？

### 6.3 zx vs nx

```text
直接以自己的权能压过去：zx。
进入既有人际、身份和权限网络，求人、借力、托关系办成：nx。
```

强 zx 人物使用 nx 功能，不等于人物整体没主见。必须区分人物本体与关系功能。

### 6.4 x vs nx

```text
唐人街幕后 Boss 控制钱、地盘、手下与关系网：x。
员工沿老板安排继续：nx。
```

幕后不等于 nx。关键是控制权在谁手里。

## 7. 三道门

### 7.1 拿掉测试

拿掉该十元，当前分析单位是否立即失去成立方式？

### 7.2 最近邻排除

至少排除一个最近邻：

```text
x vs zx
x vs xn
zx vs nx
xn vs nx
zx vs z
n vs nz
xz vs x
x并z vs x
```

### 7.3 起手测试

它是最早、最深、最反复使人物运动的力，还是中途出现的行为工具、关系通道、环境压力或状态显影？

三道门都通过才能标记 A 级。

## 8. 主、副、功能、视觉

| 层级 | 判断标准 |
|---|---|
| 主十元 | 拿掉后人物存在方式、核心痛苦和反复选择同时崩塌 |
| 副十元 | 跨阶段反复为主十元提供另一条稳定运行路径 |
| 功能十元 | 只负责某段剧情怎样办事，不代表人物整体人格 |
| 视觉十元 | 只负责外观、气氛、姿态和第一印象 |

行为频率不能代替人物本体。

## 9. 置信度门槛

| 等级 | 条件 | 后续动作 |
|---|---|---|
| A | 对象层分开；拿掉测试通过；最近邻已排除；有反例 | 可进入强关系链 |
| B | Top-2 明确，但主位或对象层仍难分 | 保留候选，只写候选链 |
| C | 分析单位混杂或证据不足 | 拆小单位重新观察 |

```text
只有 A 点可以进入强关系链。
A + B 只能写候选链。
B + B 或含 C，不得写最终生克补。
```

## 10. 生克补硬门槛

先查正式位置，再证明内容机制：

```text
生：A 是否结构性促成 B 的目标变量？
克：A 是否压制、限制或迫使 B 转向？
补：A 与 B 是否提供两条互相补足的运行路径？
```

几何位置与具体语义分开。正式关系表中未锁定机制的关系，只能保留候选，不得自动补故事。

当前特别规定：

```text
nx 生 x：位置保留，旧“欲望积累”机制删除，等待新案例验收。
```

## 11. 孙悟空校准锚

本卡只指《西游记》齐天大圣孙悟空：

```text
人物稳定结构：zx + nx
zx 主证据：与天齐名、骑到所有人头上的无敌权能姿态
nx 主证据：取经途中求人、借法宝、请救兵、走神仙人情与权限网络
外部 xn：五行山与天庭既有制度结构
```

标准动态：

```text
直接战斗与压过对手：zx
→ 遇到武力不能直接处理的法宝、身份或权限问题
→ 求人、借力、走关系：nx
→ 获得资源或许可
→ zx 再次直接显现
```

不得再用以下旧句作为核心结论：

```text
孙悟空的 nx 主要来自五行山压制
求学阶段已经充分证明 nx
nx 只是让 zx 被压时继续存活
```

五行山只说明外部 xn 可以克 zx，不负责制造或主要证明 nx。

## 13. 正本纪律

- 正本信息量卡直接更新，不再创建“覆盖补丁”代替修改。
- 错误旧卡删除，历史由 Git 保存。
- 迁移完成的候选池删除，不让过时语义继续参与检索。
- 新概念只有通过 95% 门槛才写入正本；真实分叉只留最少问题。
