# 五大主题与十元分层接口协议 v0.4

## 1. 正式迁移

```text
Legacy（旧十元表达）

n 补克 nx

↓

Current（正式主题表达）

因果克制空间
```

旧表达停止作为现行十元关系、人物判定或动态链结论使用，仅允许在迁移说明中出现。

## 2. 两套“补”必须分开

### A. 十元关系层的互补

两个十元同时出现时，若它们处于互补关系，就在十元层发生相互互补。

```text
十元 A + 十元 B
→ 十元层互补
```

这仍然属于具体对象、人物关系、状态关系或动态链，不会因为两个十元同时出现，就自动生成五大主题。

### B. 五大主题生成系统的统一补合

五大主题由另一套专门解决主题的系统生成。

这套系统以统一的 `z = 补合`，把预设的十元构成双方合并为高级主题符号：

```text
主题生成系统 z
+ 预设十元构成双方
→ 五大主题
```

其关键不是“故事里两个十元碰巧一起出现”，而是理论系统在主题层对指定双方进行统一补合。

因此：

```text
两个十元一起出现
≠ 自动生成主题

两个十元一起出现
→ 只说明十元层可能发生互补、相生、相克或并列

五大主题诞生
→ 来自专门的主题生成系统统一补合
```

## 3. 十元构成区与主题关系区

### 十元构成区

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

这些公式中的符号全部是十元点位。

例如：

```text
时间 = xn + z
```

其中 `z` 是十元点位 z，是时间主题的十元构成成员。

公式中的 `+` 表示系统预设的构成双方，不表示两个现实对象相遇，也不表示一次十元动态链事件。

### 五大主题关系区

```text
z = 补 / 补合
n = 生 / 生发
x = 克 / 克制
```

这里的 `z / n / x` 是主题系统中的关系功能。

```text
z：统一补合指定十元构成双方，生成主题
n：主题与主题之间的生发
x：主题与主题之间的克制
```

同字母出现在不同区域，按所在区域判读，不构成父子派生。

## 4. 五大主题正式生成机制

```text
理论系统预设十元构成双方
↓
主题生成系统用关系层 z 统一补合
↓
形成高级、高层次的五大主题符号
↓
主题之间再按关系层 n 生、x 克运行
```

主题生成不是案例内临时发生的事件，也不要求先证明某个人物同时拥有公式中的两个十元。

具体故事只是在十元、人物、状态、行为、场景和时间结构中，对既有主题进行承载、显影和实现。

## 5. 五大主题正式生环

```text
空间 生 时间
时间 生 命运
命运 生 因果
因果 生 本体
本体 生 空间
```

闭环：

```text
空间 → 时间 → 命运 → 因果 → 本体 → 空间
```

关系符号：

```text
空间 n 时间
时间 n 命运
命运 n 因果
因果 n 本体
本体 n 空间
```

## 6. 五大主题正式克环

```text
空间 克 命运
命运 克 本体
本体 克 时间
时间 克 因果
因果 克 空间
```

闭环：

```text
空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

关系符号：

```text
空间 x 命运
命运 x 本体
本体 x 时间
时间 x 因果
因果 x 空间
```

`因果克制空间` 因而属于正式克环，不是从旧 `n 补克 nx` 翻译出来的一条十元关系。

## 7. 五大主题与十元各自作用

```text
五大主题：
负责高级归类、主题重心、主题生成与主题级生克。

十元：
负责人物、状态、行为、场景、时间结构等具体对象的语义与关系。

动态链：
负责具体对象之间怎样生、克、补，以及阶段中的显影、退隐、转位。

三元：
提供高概括的关系与结构判断，与十元并行，不构成父子派生。
```

最短工作原则：

```text
五大主题很好归类。
十元很好具体化。
动态链很好描述过程。
三元提供高概括判断。
```

## 8. 主题关系不能还原成唯一十元关系

主题生克盘确定的是高级主题之间的方向。

例如：

```text
因果 x 空间
```

不能自动还原为：

```text
某个固定十元 A 克 某个固定十元 B
```

具体案例必须分别判断：

```text
人物稳定本体
当前人物状态
关键行为功能
外部场景
时间关系 / 时间结构
视觉与光影
十元层生克补
主题承载与主题级生克
保持不变的人物核心锚点
```

人物核心锚点优先保持稳定。变化主要落在状态、显影、关系与动态链。

## 10. 当前冻结结论

```text
十元同时出现，只在十元层发生互补、生、克或并列，不自动生成五大主题。
五大主题由另一套专门的主题生成系统统一 z 补合而诞生。

十元构成公式中的符号是十元点位。
主题生成与主题关系中的 z、n、x 是关系功能。

正式生环：
空间生时间，时间生命运，命运生因果，因果生本体，本体生空间。

正式克环：
空间克命运，命运克本体，本体克时间，时间克因果，因果克空间。

正式主题关系：因果克制空间。
旧表达 n补克nx：停止作为现行关系使用。

五大主题负责高级归类。
十元负责具体化。
动态链负责阶段过程。
三元与十元并行，不是父子派生。
人物核心锚点优先稳定。
```
