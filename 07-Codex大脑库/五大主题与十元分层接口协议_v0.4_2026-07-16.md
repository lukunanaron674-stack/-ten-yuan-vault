# 五大主题与十元分层接口协议 v0.4

## 1. 正式迁移

```text
Legacy（旧十元表达）

n 补克 nx

↓

Current（正式主题表达）

因果克制空间
```

旧表达停止作为现行十元关系、人物判定或动态链结论使用，仅允许在迁移说明中出现。

## 2. 两套“补”必须分开

### 十元层互补

两个十元在具体案例中同时出现时，若它们处于互补位置，就在十元层发生相互互补。

```text
十元 A + 十元 B
→ 十元层互补、生克或并列
→ 不自动生成五大主题
```

这属于具体人物、状态、行为、场景、时间结构或动态链。

### 五大主题生成系统

五大主题由另一套专门处理主题的系统生成。

```text
理论系统预设十元构成双方
↓
主题生成系统以统一的关系层 z 补合
↓
形成高级、高层次的主题符号
```

主题生成不是案例内临时发生的事件，也不要求某个人物同时拥有公式中的两个十元。

## 3. 十元构成区与主题关系区

### 十元构成区

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

这些符号全部是十元点位。

公式中的 `+` 表示系统预设的构成双方，不表示两个现实对象相遇，也不表示一次动态链事件。

### 主题关系区

```text
z = 补 / 补合
n = 生 / 生发
x = 克 / 克制
```

```text
z：统一补合指定十元构成双方，生成主题
n：主题与主题之间的生发
x：主题与主题之间的克制
```

同一字母出现在不同区域，按所在区域判读，不构成三元与十元的父子派生。

## 4. 五大主题最小定义

```text
空间：
对象如何被放置、容纳、分隔、并存并建立边界的位置结构。
核心问题：什么能够在哪里存在，彼此如何共处或受限？

时间：
变化如何按先后、持续、积累、循环或阶段展开的进程结构。
核心问题：事物怎样从之前走到之后，什么被改变或保留？

命运：
多种可能如何逐步收束为某种去向、归宿或不可逆结果的方向结构。
核心问题：这一切最终走向哪里？

因果：
前因如何经过作用链产生后果，并使结果具有来源、责任与可追溯性。
核心问题：什么导致了什么？

本体：
对象在变化、关系与表现中仍被识别为其自身的存在核心与根本性质。
核心问题：它究竟是什么？
```

这些定义属于主题层，不是十元定义的改写，也不能反向证明具体人物本体。

## 5. 五大主题正式生克盘

### 生环

```text
空间 生 时间
时间 生 命运
命运 生 因果
因果 生 本体
本体 生 空间
```

闭环：

```text
空间 → 时间 → 命运 → 因果 → 本体 → 空间
```

### 克环

```text
空间 克 命运
命运 克 本体
本体 克 时间
时间 克 因果
因果 克 空间
```

闭环：

```text
空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

完整方向以 [[02-五大主题/五大主题生克盘_v1.0_2026-07-16]] 为准。

## 6. 主题显影与主次判定

故事不是重新生成主题，而是在人物、状态、行为、场景、时间结构和动态链中承载、显影和实现既有主题。

显影等级：

```text
0级：背景存在
1级：局部主题
2级：次主题
3级：主主题
```

主主题不能依靠关键词命中数量判定，必须由中心问题、关键转折、高潮与结局共同支持。

两个主题同时出现，不等于主题生克已经启动。主题生克必须出现明确方向，并真实改变目标主题的能力、边界、路径或答案。

完整标准以 [[02-五大主题/五大主题显影与判定协议_v1.0_2026-07-16]] 为准。

## 7. 五大主题与十元各自作用

```text
五大主题：
负责高级归类、主题重心、主题生成与主题级生克。

十元：
负责人物、状态、行为、场景、时间结构等具体对象的语义与关系。

动态链：
负责具体对象之间怎样生、克、补，以及阶段中的显影、退隐和转位。

三元：
提供高概括的关系与结构判断，与十元并行，不构成父子派生。
```

最短工作原则：

```text
五大主题很好归类。
十元很好具体化。
动态链很好描述过程。
三元提供高概括判断。
```

## 8. 主题关系不能还原成唯一十元关系

例如：

```text
因果 x 空间
```

不能自动还原成：

```text
某个固定十元 A 克 某个固定十元 B
```

同样，十元层两个对象发生互补，也不能推出五大主题在案例内被重新生成。

主题层与十元层必须分别写明关系端点。

## 9. 人物、状态、行为、场景与时间关系必须分层

每次分析至少拆开：

```text
人物稳定本体
当前人物状态
关键行为功能
外部场景
时间关系 / 时间结构
视觉与光影
十元层生克补
主题显影等级
主题级生克
动态链阶段
保持不变的人物核心锚点
```

表面关键词、职业、服装、道具、单次行为、场景外观和光影不能越级证明人物本体。

人物核心锚点优先保持稳定。变化主要落在状态、显影强度、行为功能、关系位置、场景、时间结构和动态链顺序。

## 11. 当前冻结结论

```text
十元同时出现，只在十元层发生互补、生、克或并列，不自动生成五大主题。
五大主题由专门的主题生成系统统一 z 补合而诞生。

十元构成公式中的符号是十元点位。
主题生成与主题关系中的 z、n、x 是关系功能。

正式生环：
空间生时间，时间生命运，命运生因果，因果生本体，本体生空间。

正式克环：
空间克命运，命运克本体，本体克时间，时间克因果，因果克空间。

正式主题关系：因果克制空间。
旧表达 n补克nx：停止作为现行关系使用。

五大主题负责高级归类。
十元负责具体化。
动态链负责阶段过程。
三元与十元并行，不是父子派生。
人物核心锚点优先稳定。
```
