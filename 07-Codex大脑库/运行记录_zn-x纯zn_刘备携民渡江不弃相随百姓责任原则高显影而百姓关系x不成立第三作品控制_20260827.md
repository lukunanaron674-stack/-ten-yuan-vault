# 刘备携民渡江｜第三作品 pure-zn 控制

## 1｜被测对象层

只测试“曹军逼近、撤退速度与生存概率明显受拖累时，主体是否仍认为不能为了自身脱险主动抛弃已经自愿相随、把安危托付给自己的百姓”这一窄原则对象层。

不把“仁君”“汉室宗亲”“爱民”“哭泣”“主角”这些身份、标签、情绪或主题直接当成 `zn`；也不因此给刘备整个人物锁稳定本体。

## 2｜剧情事实

《三国演义》第41回中：

- 曹操大军逼近，樊城不可久守，刘备与诸葛亮开始撤离；
- 刘备首先提出“百姓相随许久，安忍弃之”，并允许愿随者同行、不愿者留下；
- 两县百姓大量随行，撤退速度因此显著降低；
- 到南岸时仍有百姓未渡，刘备先催船继续渡民，之后才上马；
- 诸将明确指出：带着大量百姓每日只能行十余里，曹军很快会追上，建议暂弃百姓先走；
- 刘备拒绝该建议，理由是“举大事者必以人为本；今人归我，奈何弃之”；
- 随后简雍又以凶兆和追兵风险再次建议速弃百姓，刘备仍以“百姓从新野相随至此，吾安忍弃之”拒绝；
- 曹军最终追至长坂，刘备军遭到重大现实损失，说明这项原则不是无成本姿态。

## 3｜zn 证据

本轮原则只压成：

> **已经自愿相随并把现实安危托付给主体的百姓，不能在主体为了提高自己脱险概率时被主动抛弃；领导关系一旦形成，就产生不能只在安全时承认的现实责任。**

按 `zn_准度卡_v0.1` 检查：

1. **原则命题明确**：不是泛化成“永远不允许撤退”，而是“不为自身脱险主动抛弃已相随百姓”；
2. **不可轻易让渡**：更快撤退、更高生存概率、军事便利都不能换取原则撤回；
3. **无奖励/认可仍进入判断**：最硬节点发生在追兵逼近、军情恶化时，不依赖封赏或旁观赞誉；
4. **冲突排序**：原则直接与军队速度、指挥安全和保存实力冲突，刘备仍连续把百姓责任放入最终排序；
5. **未来调用资格**：同一撤退链中，渡河、诸将再劝、简雍再劝、追兵真正到来等连续压力窗口里，判断没有因危险升级而退出；
6. **边界与代价明确**：百姓可自行选择是否跟随，但一旦自愿相随并形成现实依附关系，刘备不接受“为了我先活下来就把他们丢下”这一解决方式；代价是撤退效率与军事安全显著下降。

因此本窄原则对象层 `zn` 高显影成立。

## 4｜x 证据

同一被测对象层不独立锁 `x`。

- 被测对象是“相随百姓是否进入刘备可稳定占有、调用、处分、否决或排除的掌握边界”；
- 百姓是否同行由其自愿选择，刘备明确允许愿随者跟随、不愿者留下；
- 刘备可以组织渡河、安排军队保护和路线，但这更直接证明领导/组织行为，不等于百姓本身成为其可处分对象；
- 原著没有显示刘备可以像处分资源、部属权限或领地那样稳定决定这些百姓的退出、归属与使用；
- 因此“我承担他们的安危责任”不能偷换成“他们归我掌握”。

所以本轮只计 pure-zn control，不计 `zn+x` 当前共现，也不计 strict `zn↔x` complement。

## 5｜关键压力

- 曹操主力快速追击；
- 数万至十余万军民同行导致撤退速度极慢；
- 诸将从军事效率角度明确建议先弃百姓；
- 简雍在危险进一步上升时再次提出同类建议；
- 长坂追击最终证明风险真实发生，而非假想道德题。

压力只用于检验原则是否会被让渡，不是 `zn` 定义本身。

## 6｜拿掉测试

拿掉“仁君”评价、百姓哭拜、后世赞诗、刘备汉室身份与最后历史名声，只保留“百姓自愿相随 → 撤退被拖慢 → 多次有人建议为了自身安全抛弃他们 → 刘备持续拒绝”这一因果链，原则仍进入判断。

如果再拿掉“对已相随百姓不能为了自身脱险主动抛弃”的内部标准，只剩军事谨慎、政治表演或收买民心，就很难解释：

- 为什么追兵越来越近时仍反复拒绝最快撤退方案；
- 为什么在未渡百姓还在北岸时先继续催船渡民，再上马；
- 为什么风险已经从抽象警告变成现实追击后，判断仍未改变。

## 7｜反向测试

若原著结构改成以下任一情况，`zn` 证据会显著下降：

- 只在百姓围观或赞颂时说“不弃”，追兵一近立即独自先走；
- 保留百姓仅因为他们能提供钱粮、兵源或政治收益，一旦成本大于收益就立刻撤回；
- 百姓并未自愿相随，也没有形成现实托付关系，刘备只是抽象宣言“爱民”；
- 军事情境变化后，原则不再具有未来调用资格。

此时应重新检查 `z / xn / zx / x` 等最近邻，而不能继续锁 pure `zn`。

## 8｜最近邻排除

- `zn vs z`：核心节点发生在现实危险和军事不利中，不依赖重要他者认可；百姓支持是背景事实，不是原则的唯一来源；
- `zn vs xn`：安排船只、断后、保护老小、路线选择回答“怎么撤”，不能替代“为什么不能把已相随百姓抛下”这一原则；
- `zn vs zx`：刘备作为领军者的公开决定可以有 `zx` 邻近，但公开决定强度不是 `zn` 的定义；
- `zn vs x`：领导、保护和责任不等于百姓进入主体稳定处分边界；本轮同一百姓关系对象层不锁 `x`；
- `zn vs nz`：百姓愿随、能否留下属于关系去留与回返问题的邻近，但本轮锁的是主体自己的责任原则是否继续拥有最终指导资格。

## 9｜第三因素冻结

冻结：

- “仁君”文学形象；
- 百姓对刘备的拥戴；
- 曹操善恶评价；
- 后世诗赞；
- 刘备是否最终取得天下；
- 长坂坡其他英雄桥段。

只保留：百姓自愿相随、主体可选择先行脱身、多轮军事压力、明确弃民建议、主体连续拒绝、现实代价最终发生。结论不变。

## 10｜与前两份 pure-zn 控制的最小差异

```text
《水浒传》鲁智深：
他者受害 → 一旦承担救援就应救彻 → 关系责任原则

《红楼梦》鸳鸯：
主体自身被强制定义婚姻关系 → 不让权势替自己决定 → 自我决定边界原则

《三国演义》刘备：
群体自愿相随并形成现实托付 → 不为自身脱险主动抛弃 → 领导/公共责任原则
```

三案都让 `zn` 独立通过无奖励、冲突排序、未来调用与让渡代价门，同时都不把被保护/被负责对象偷写成 `x`；三种机制分别覆盖个人救护责任、自我决定边界、群体领导责任。

因此本例增加 pure-zn 第三独立作品控制，达到同 criterion 跨 3 works 的 L4 待审议门槛；只允许建立 pending-review，不得自动修改 L2 canonical。
