# 运行记录｜诸葛亮自贬后复丞相：复职 ≠ 追溯撤销

## 1｜本轮问题

当前 `nx：事前批准 与 事后回报边界` 待审议已经把事后变化拆成：

- A：事后报告/备案；
- B：事后追责主体；
- C1：真正追溯撤销旧决定；
- C2：重新授权/重新接纳/新任命。

本轮专门测试一个最容易误判成 C1 的文本：**诸葛亮街亭败后被正式贬为右将军，后来又被诏“复丞相”。**

问题是：后面的“复丞相”是否意味着前面的贬职被追溯判无效？

结论：**不是。属于 C2 的后续恢复/重新任命，而不是 C1 追溯撤销。**

## 2｜剧情事实

### 阶段 A｜第九十六回：贬职真实生效

街亭失守后，诸葛亮上表自请贬降。后主采纳，正式下诏：

- 贬诸葛亮为右将军；
- 仍“行丞相事”；
- “照旧总督军马”。

诸葛亮实际接受诏命。

因此：**名位上的贬降是真实生效的，并非只停留在提议阶段。**

同时，文本又明确保留其实际军政运行接口：“行丞相事，照旧总督军马”。所以这一阶段不能把“名位下降”直接等同为实际处分权限全部退出。

### 阶段 B｜后续形成新功

贬职以后，诸葛亮继续统军；后续出现斩王双、郭淮退走、恢复武都阴平等新的战功事实。

### 阶段 C｜第九十九回：复丞相

后主随后遣费祎赍诏，诏书明确以街亭后的自贬、以及后来斩王双、复二郡等战功作为理由，命诸葛亮“今复君丞相”。

诸葛亮起初辞让，费祎继续劝说后才接受。

所以时间结构是：

```text
原贬职真实生效
→ 中间以右将军名位运行
→ 实际军政统辖大体连续
→ 后续发生新的战功
→ 皇帝基于新条件恢复丞相名位
```

而不是：

```text
原贬职真实生效
→ 后来宣布原贬职从一开始就是错误/无效
→ 旧处分被追溯抹除
```

## 3｜zx 判断

### 复职阶段不新增 zx

表面上“右将军 → 丞相”像位置上升，但现行 zx 不能只看官名升降。

最关键的反证恰在第九十六回：诸葛亮被贬后仍“行丞相事，照旧总督军马”。这说明本轮恢复的首先是**正式名位**，而不是一个此前完全丧失、如今重新扩张出来的实际军政决定范围。

因此锁：

`zx_new_expansion_at_reinstatement: rejected_as_primary`

若以后要判 zx，必须另证“复丞相”让诸葛亮的实际决定范围相较贬职期进一步公开扩大，而不能拿职位名称本身代替。

## 4｜nx 判断

在“是否接受恢复丞相名位”这个极窄入口层：

- 恢复方向由后主诏令提出；
- 诸葛亮先辞；
- 费祎劝说后接受。

因此存在 `nx` 承接行为外观，但只记录：

`nx_reinstatement_entry_behavior: present_but_not_primary`

不能由一次接受复职，反推诸葛亮稳定人物本体为 nx。

同时，在贬职期间的实际军政运行层，文本明确保留“行丞相事、照旧总督军马”，所以更接近已有 `x` 运行接口连续存在：

`x_operational_authority_continuity_during_demotion: evidence-locked`

## 5｜关键压力

关键压力是街亭失败后的军法/政治责任，以及随后新的战功积累。

真正决定 C1/C2 分类的不是“复”字，而是：

1. 原贬职是否真实生效；
2. 中间状态是否真实存在；
3. 后来恢复是否依赖新的功绩与新诏；
4. 文本是否明确宣布原贬职本身错误、无效并追溯回滚。

本例前 3 项为是，第 4 项为否，因此是 C2。

## 6｜拿掉测试

### 拿掉后续新战功

若没有斩王双、郭淮退走、复二郡等后续条件，现有文本就失去“为什么后来复丞相”的主要依据。

说明恢复依赖新条件，不是对旧处分的单纯追溯撤销。

### 拿掉“复丞相”三个字

只保留“恢复原职”这一结果，也不能自动推出 C1；仍必须检查旧决定是否被宣布无效。

### 拿掉名位，只看实际权限

诸葛亮在被贬期间仍“行丞相事、照旧总督军马”，所以实际运行权连续性很强。进一步证明不能拿职位名称变化直接替代 `x/zx/nx` 对象层判断。

## 7｜反向测试

真正 C1 应更接近：

```text
右将军贬职已经生效
→ 后来更高/最终权限明确认定该贬职错误或无效
→ 撤销原贬职决定本身
→ 恢复原官，并处理贬职期间因旧处分产生的状态
→ 恢复不依赖新功、新申请或重新任命逻辑
```

本例没有“旧贬职决定被判无效”这一硬门。

## 8｜最近邻排除

- `C1追溯撤销`：旧决定本身后来被判失效，并产生回滚。
- `C2重新恢复/任命`：旧决定曾真实有效，后来因新条件建立新状态。本例属于此类。
- `x`：被贬期间实际军政统辖接口仍连续存在。
- `nx`：复职入口来自外部诏令，但只支持窄行为层。
- `zx`：不能由官名恢复直接推出实际权能扩张。
- `xn`：后续军事组织存在，但不是本轮 C1/C2 分类主轴。

## 9｜第三因素冻结

以下全部不参与主判：

- 诸葛亮是否忠臣；
- 街亭失败责任究竟多大；
- 刘禅是否真心想贬；
- 马谡该不该斩；
- 后续北伐胜负评价；
- 丞相和右将军哪个听起来更尊贵。

只看：**旧处分是否真实生效、后来是否明确撤销旧决定本身、恢复是否由新条件重新建立。**

## 10｜本轮结论

```text
正式贬职
+ 中间状态真实存在
+ 新战功出现
+ 新诏恢复名位
+ 没有宣布旧贬职自始无效
= C2 重新恢复/任命
≠ C1 追溯撤销
```

同时补一条重要木轴限制：

> **职位名位的恢复不自动等于 zx；职位名位的降低也不自动等于 x 实际权限退出。必须回到被测试对象层的真实调用与处分边界。**
