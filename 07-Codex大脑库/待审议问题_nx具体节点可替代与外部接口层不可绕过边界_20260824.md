# 待审议｜nx具体节点可替代与外部接口层不可绕过边界

## 触发原因

连续三个独立作品出现同类边界：主体当前关键现实瓶颈需要外部权限、资源、庇护或裁决接口，但某一个具体命名节点并非唯一；主体可以更换外部节点继续推进，而 `nx` 关系功能仍然保持。

因此需要区分：

```text
具体姓名/节点是否唯一不可替代
vs
同一现实瓶颈是否仍必须经过某类外部接口
```

前者不是 nx 的必要条件；后者才更接近 nx 的关键权限变量。

## 三作品正向控制

### 1｜《水浒传》宋江

杀阎婆惜后，宋江自己决定离开，也能列出柴进、花荣、孔太公三个安身候选。具体某一个人并非唯一不可替代；但安全庄院、藏匿许可、衣食和保护能力仍然掌握在外部主体手里。主体没有自有稳定等价庇护系统。

结论：具体节点可替代，但外部庇护接口层仍为 nx。

### 2｜《红楼梦》贾芸

先求贾琏谋差事未成，转向凤姐；主体没有自己取得派差权，而是从一个既有权限节点转接到另一个真正有效的权限节点。

结论：A 节点失败不迫使 zx；只要关键派差权限仍在外部，转 B 节点仍可保持 nx。

### 3｜《西游记》真假美猴王

观音、天庭、唐僧、地府等辨真接口连续失败后，孙悟空没有自行成为最终裁决者，而是继续升级寻找外部识别/裁决节点，最终到如来处完成辨识。

结论：多个外部节点连续失效，仍不能自动推出 zx；关键看主体是否停止依赖外部裁决接口并自己取得最终决定权。

## 反向控制A｜玄奘禁边令下秘密西行

玄奘没有取得唐朝正式出境许可，确实绕过了“中央官方许可”这一正常低成本接口；但实际边境段并非纯主体自给，而是连续使用了慧威法师弟子密送、州吏李昌毁追捕文书、地方供给与马匹、胡人向导搭桥等外部关系 / 资源接口。

因此不能写成：

```text
绕过官方P1
→ 自动等于内部自给P2
→ 整体nx消失
```

更准确的是：

```text
中央官方许可nx退出
→ 实际路线切换到地方非正式外部接口
→ 局部nx仍可成立
```

这构成 99/97 高纯反向控制：

> 绕过一种外部接口，不等于绕过整个外部接口层。

## 反向控制B｜孙悟空二调芭蕉扇

第60回中，孙悟空已经确认直接向罗刹女借扇失败，转而自己设计新的 P2：跟踪牛魔王、偷辟水金睛兽、变作牛魔王、利用丈夫身份进入芭蕉洞并套取真扇与口诀。

这条 P2 的运行骨架高度由主体自搭，属于明显 `xn`；但它仍不是关羽五关式“纯内部闭环”。原因是：

- 真芭蕉扇仍由罗刹女掌握；
- 孙悟空无法用自己的已有资源制造等价真扇；
- 资源最终仍由罗刹女亲自交出；
- 真扇使用口诀也由罗刹女外部提供；
- P2 成功依赖“牛魔王丈夫身份 → 罗刹女信任并交付”的既有关系通道。

所以应拆为：

```text
怎么骗到真扇？
→ 主体自搭 P2
→ xn

真扇与口诀从哪里来？
→ 仍在罗刹女外部接口
→ 局部 nx
```

结论：

> **主体自己设计替代路线，不等于替代路线的关键条件已经内部化。**

这构成第二份 99/97 反向控制，并补出与玄奘不同的机制：玄奘是“地方关系/资源节点接力”，孙悟空是“关键资源持有人 + 身份关系通道”。

## 当前候选纪律

### 纪律A｜具体节点可替代，不自动削弱 nx

如果：

```text
A外部节点不可用
→ 主体转B外部节点
→ B仍掌握当前关键许可/资源/裁决
→ 主体仍须实际接入
```

则 `nx` 可以持续。

### 纪律B｜不可绕过应在“接口层”而非“姓名层”检查

优先问：

> 对同一现实瓶颈，主体是否存在一个不依赖同类外部权限/资源的稳定内部路线？

而不是只问：

> 某一个具体人是不是唯一能帮？

### 纪律C｜真正削弱 nx 的是内部化绕行

若主体可以：

- 稳定；
- 可重复；
- 不经任何等价外部权限 / 关系 / 资源节点；
- 仍实现同一结果对象，

则局部 nx 应明显下降，优先转查 `x/xn/zx`。

成本高低不能单独决定 nx 是否存在；仓库已有关羽五关案表明，主体若已经真实执行高成本自有路线并实现同一结果，当前许可 nx 可以退出。

### 纪律D｜换结果对象不能冒充“绕过”

如果外部许可拿不到，主体改成实现另一个不同结果，例如从“正式司法裁决”改为“私力报仇”，这是对象层变化，应重新分类，不能简单说原 nx 因为存在替代路线而消失。

### 纪律E｜绕过P1后仍需检查P2是否还是外部接口

玄奘与孙悟空两份反向控制共同要求：

```text
P1原接口没用
→ P2是谁提供关键放行 / 资源 / 专业 / 关系？
```

若 P2 仍依赖独立外部节点，则只能说 P1 的 nx 退出，不能推出“整体外部接口依赖已经消失”。

尤其要防止两种误判：

1. **换接口型**：绕过中央许可，却改走地方关系/资源接口；
2. **自搭方案假内部型**：主体自己设计欺骗/计划，但关键资源仍须由外部持有人发生转移。

### 纪律F｜xn 自搭骨架不能替代 nx 的资源/权限检查

主体可以同时：

```text
自己搭 P2 的步骤与节点
= xn

仍需外部关键资源 / 权限 / 关系接口
= nx
```

因此“这个办法是我自己想的”不是排除 nx 的充分条件。

## 与“真实否决权”待审议的关系

本问题不否定真实否决的重要性，而是补充：

> 一个具体节点有真实否决权，不代表它必须是唯一节点。

需要继续分辨：

```text
节点A能否决
但节点B可独立批准同一结果
```

此时 A 对主体不是“全局唯一门”，但主体仍可能处于更高层的外部权限网络 nx 中。

## 暂不改正本原因

虽然三部独立作品已经达到待审议门槛，且反向控制已增加到两种机制，但“高成本自有绕行”和“高成本但仍借外部接口”的直接跨作品正向复验仍不足以修改正本。

因此：

- 不修改 L1；
- 不修改 zx/nx 信息卡；
- 不修改准度卡；
- 不修改 `zx补nx_补卡`；
- 保持 `pending-review`。

## 下一轮最值得跑

继续寻找真正和关羽形成最小差异的第二部独立材料：

```text
正常外部许可 P1 存在
→ 主体不使用 P1
→ 高成本 P2 实际成功
→ P2 不依赖任何等价外部许可 / 关系 / 关键资源持有人完成转移
→ P1 与 P2 实现同一结果对象
```

同时保留双反向门：

- 武松门：P2 不得换结果对象；
- 玄奘/孙悟空门：P2 不得只是换外部接口，或“自搭 xn 但关键资源仍外置”。
