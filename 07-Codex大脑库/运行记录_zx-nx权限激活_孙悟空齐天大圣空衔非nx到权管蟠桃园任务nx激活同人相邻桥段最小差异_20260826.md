# 《西游记》孙悟空｜齐天大圣空衔非 nx → 权管蟠桃园任务 nx 激活｜同人相邻桥段最小差异

## 0｜结论先行

本轮不重复旧结论“齐天大圣空衔阶段名位高但无实际扩权”。本轮只测试一个更窄的变量：

> **名义进入天庭体系是否足以激活 nx，还是必须等外部任务／权限通道真实进入当前行动链以后，局部 nx 才成立。**

结论：

```text
A｜齐天大圣空衔：
有官无禄 + 无事管 + 天庭安置
→ 外部体系存在
→ 但没有当前任务方向被孙悟空承接
→ 本窄任务层 nx 不激活

B｜玉帝点差权管蟠桃园：
外部明确给出管理任务
→ 孙悟空欢喜谢恩并真实承接
→ 进入桃园查勘、调用园内既有人员
→ 当前任务层 nx 激活
```

因此本轮锁定：

> **关系／体系／身份存在 ≠ nx 已激活。外部方向、权限或任务必须真实进入主体当前行动链，并被主体承接，才构成当前 nx 证据。**

这不改孙悟空稳定 `zx+nx` 锚，也不把“管桃园”升级成纯 nx 人物本体。

---

## 1｜剧情事实

### A｜空衔阶段

第四回天庭按孙悟空此前自号“齐天大圣”的要求予以招安。齐天大圣职位被明确安排为“有官无禄”，并不授实际事务；第五回开头继续写孙悟空在齐天府无事牵萦、自由闲游，与诸神交游。

### B｜任务激活阶段

因孙悟空无事闲游，许旌阳建议给他一件实际职事。玉帝随后明确宣诏：“你且权管那蟠桃园，早晚好生在意。”孙悟空欢喜谢恩，随即进入蟠桃园查勘，并向土地说明自己奉玉帝点差代管桃园；土地与园内力士据此向他行礼并引其入园。

### 触发

外部变量从：

```text
只有名义体系 / 身份安置
```

切换成：

```text
明确任务方向 + 真实职事 + 主体承接 + 当前执行
```

### 结果

同一人物、同一体系、相邻桥段，仅“当前任务是否真实进入行动链”改变，即出现任务层 nx 的开关差异。

## 2｜zx 检查

### 空衔阶段

不新增 zx。旧记录已经锁定：齐天大圣名位极高，但“有官无禄、无事管”不能单独证明新的实际决定范围扩大。

### 管桃园阶段

本轮也不把“奉命管理桃园”自动写成 zx。

原因：

```text
任务由玉帝给出
+ 孙悟空进入被授予的管理对象
+ 园内人员按既有职掌配合
```

首先支持的是任务层 nx 与局部管理 `x` 候选，而不是“决定范围由孙悟空自身公开扩张”的 zx。

若后续孙悟空公开越过授权边界、把新的处分范围压入现实，才另查 zx；不能把后续偷桃、闹会等倒灌成本轮任务入口的 zx。

---

## 3｜nx 检查

### A｜为什么空衔阶段非 nx

现行 nx 要求：

```text
方向 / 权限 / 解决通道外置
+ 主体不占当前最终方向
+ 主体真实沿该外部方向推进
```

空衔阶段只有天庭身份和居所，缺少“当前要做什么”的外部任务输入。孙悟空无事闲游，不能因为住在天庭、受封、接受礼遇，就自动记上位 nx。

### B｜为什么管桃园后任务层 nx 成立

玉帝给出明确任务：权管蟠桃园，并要求“早晚好生在意”。孙悟空没有重定义这个任务目标，而是谢恩、入园查勘，并按该身份进入已有园务结构。

因此：

```text
上位任务方向：玉帝给出
任务对象：蟠桃园
任务入口：天庭职事授权
主体行为：真实承接并执行
= 当前任务层 nx
```

注意：这只锁“任务来源 / 授权入口”层。进入园后形成的具体对象管理权限，可另查局部 `x`；若主体主动重组流程则另查 `xn`。

---

## 4｜关键压力

关键压力不是战斗、惩罚或生存威胁，而是**天庭为了避免孙悟空无事生端，主动给他一个职事**。

冻结“天庭怕不怕他”“孙悟空是不是齐天大圣”等背景后，本轮仍只看：

```text
有没有当前外部任务？
主体有没有真实承接？
承接前后行动链是否发生可观察变化？
```

---

## 5｜拿掉测试

### 拿掉任务本身

保留齐天大圣称号、府署、天庭居住与礼遇，但删掉“权管蟠桃园”职事：

> 孙悟空仍可在天庭闲游，当前任务层 nx 消失。

说明“在体系里”不足以解释任务 nx。

### 拿掉主体承接

保留玉帝点差，但若孙悟空拒绝、不入园、不按该任务继续：

> 只能证明外部任务存在，不能证明当前 nx 已激活。

### 拿掉名位

即使不叫“齐天大圣”，只要仍有“外部明确交付桃园管理任务 + 主体真实承接”，任务层 nx 仍可成立。

因此名位不是核心变量。

---

## 6｜反向测试

### 反向成非 nx

若玉帝只给一个空头称号，没有任何当前任务，孙悟空也没有沿外部方向推进：

```text
体系存在
≠ nx 激活
```

### 反向成更强 xn

若玉帝只说“把桃园管好”，而孙悟空随后主动重建园务人员、时序、节点与流程，则：

```text
上位任务 nx
+ 局部运行 xn
```

应分层并存。

### 反向成 zx

若孙悟空不只是执行桃园职事，而是公开把自身权能推进到原授权之外，并迫使更高秩序承认新的决定范围，才重新检查 zx。

---

## 7｜最近邻排除

### nx vs xn

本轮锁的是“任务方向从哪里来”。玉帝明确给任务，孙悟空承接，先成立 nx。是否自己搭桃园运行骨架，需要另外证据，不能把“进入园内查勘”直接当 xn。

### nx vs x

天庭给出的管理权限在授权后可能形成局部 `x`：孙悟空可在桃园对象域内调用既有人员、进行管理。但局部 `x` 不会倒抹“这项任务是谁给的”这一上位 nx。

### nx vs zx

受封、受礼遇、进入官署、接受职事，都不是 zx 充分条件。zx 仍要另证主体自身权能公开扩张决定范围。

### nx vs 纯服从

孙悟空不是纯 nx 人物本体。本轮只锁一个任务层关系功能，不改稳定人物结构。

## 8｜第三因素冻结

冻结：

- 孙悟空的战力与英雄评价；
- 天庭是否害怕孙悟空；
- 齐天大圣名号的象征意义；
- 后续偷桃、偷丹、反天宫；
- 桃园本身的重要性。

保留：

```text
外部任务是否明确存在
主体是否真实承接
承接后是否沿任务进入行动链
任务入口与局部运行权是否分层
```

结论不变。

## 9｜人物稳定本体 / 当前状态 / 行为功能 / 关系位置 / 外部压力

```text
稳定人物本体：保持仓库既有孙悟空 zx+nx 锚，不重判。
当前状态 A：齐天大圣空衔，无当前任务，任务层 nx 不激活。
当前状态 B：奉命权管蟠桃园，当前任务层 nx 激活。
行为功能：谢恩、入园查勘、沿职事推进。
关系位置：任务方向与授权入口在玉帝/天庭一侧。
外部压力：天庭以给职事方式约束无事闲游，但非本轮 nx 定义本身。
```

## 10｜最小差异结论

同一人物、同一组织、同一名位，只变一个变量：

```text
有没有“当前外部任务 + 主体真实承接”
```

结果：

```text
有官无禄 / 无事管
→ 非当前任务 nx

权管蟠桃园 / 谢恩承接 / 入园执行
→ 当前任务 nx 成立
```

最短护栏：

> **名义体系存在 ≠ nx 已激活；当前外部方向必须真实进入行动链，并被主体承接。**

本轮与《三国演义》关羽土山约三事共同支持“名义进入体系不能自动锁 nx”，但两者机制不同：关羽保留最终方向、否决与退出；孙悟空空衔阶段则更直接——根本没有当前上位任务进入行动链。二者不能机械合并为同一正例计数，只作为相邻护栏互相校准。
