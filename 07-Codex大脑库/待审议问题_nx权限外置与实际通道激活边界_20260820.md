# 待审议｜nx：权限外置 与 实际通道激活边界

## 1｜为什么进入待审议

当前已经跨三部独立作品稳定出现同一边界：

> **外部方向、权限、命令或解决接口客观存在，并不足以自动生成 nx 行为/关系功能。**

三组材料都显示，必须继续观察主体在被测试对象层是否真的承认并沿外部方向、权限、关系或流程推进。

这不是修改 nx 正本，而是对现行 `nx v2.5` 中“主体承认并借用该位置 / 沿既有通道推进”的判据进行案例级强化审议。

## 2｜三部独立作品反向证据

### A｜《三国演义》关羽过五关

- 曹操文凭 / 回报丞相的合法通关接口真实存在。
- 守关者明确提出可以先禀曹操再放行。
- 关羽知道该接口存在，但拒绝等待、不请求补发文凭。
- 他直接以公开强制改变通行结果。

结论：`external_permission_exists = true`，但 `actual_external_permission_channel_used = false`，当前通行层 nx 排除。

### B｜《水浒传》武松飞云浦后

- 官府内部仍存在知府、叶孔目等可能重新评价案件的权限节点。
- 武松脱险后没有转向申诉、复审或请求外部裁决。
- 他切换为直接复仇 / 逃亡路径。

结论：外部司法权限存在，但当前行动链没有实际沿该权限通道推进，nx 不自动成立。

### C｜《红楼梦》探春抄检大观园

- 王夫人批准搜检，外部上位授权真实存在。
- 探春承认“搜检任务存在”，并主动开门、开箱接受核查。
- 但在“本院怎样查、奴仆能否搜身、自己是否保留否决资格”这一局部对象层，她没有顺着外部执行者的全部既定方式推进。
- 王善保家的越界后，探春公开反击并迫使执行方式改变。

结论：承认一个上位权威事实存在，也不等于当前每个局部对象层都自动成为 nx。

## 3｜正向控制：没有主动求人，也可以真实激活 nx

### A｜《红楼梦》周瑞家的送宫花

薛姨妈把十二枝宫花的关键任务结构直接给定：三位姑娘各一对，黛玉两枝，其余四枝给凤姐。周瑞家的没有主动请求这个任务，也没有“求人办事”的姿态，只是承接以后沿贾府既有房舍、人际和传递通道逐项送达。

关键点：

- 方向由外部给出；
- 受赠对象与数量由外部给出；
- 主体没有改写最终任务；
- 主体在实际执行窗口持续沿该既有安排推进；
- 局部选择“顺路先去哪一处”不改变最终对象与数量，不足以改判 xn。

该案例已以 `99/98`、`evidence-locked` 锁定：

`nx_behavior_function_in_delivery_stage: evidence-locked`

### B｜《三国演义》赵云博望坡诱敌

诸葛亮获得刘备剑印后调度博望坡之战，把赵云调回任前部，并把当前战术终点明确规定为“不要赢，只要输”。赵云没有主动请求这个任务，也没有先自行提出诱敌方案；真正与夏侯惇交战后，他数合诈败、退十余里后回马再战、再战数合又退，实际持续沿外部给定的诱敌方向推进。

关键点：

- “当前要赢还是要诱退”的战术终点由诸葛亮给出；
- 主体未主动求人；
- 赵云拥有很强作战能力，但没有把当前战术终点改写为正面取胜；
- nx 不只停在领命入口，而是在真正执行窗口持续续接；
- 交战节奏与回马时机属于局部执行自由，不足以覆盖外部战术终点已经给定这一事实。

该案例已以 `99/98`、`evidence-locked` 锁定：

`nx_behavior_function_in_tactical_task: evidence-locked`

两条正向控制共同反证：

> **“实际通道激活”不等于“必须主动求人”。**

被动收到命令、差事、既有流程或战术任务以后，只要主体真实把当前行为接上外部方向并持续续接，同样可以形成高纯 nx 行为功能。

## 4｜候选纪律

当前最窄候选：

```text
外部方向 / 权限 / 解决接口存在
→ 只能证明权限位置、压力来源或可用通道存在

若主体在被测试对象层：
承认该外部位置
+ 实际请求 / 等待 / 借用 / 服从 / 承接 / 沿流程推进
→ nx 行为/关系功能上升

若主体明确拒绝、绕开或在该对象层保留并使用最终否决/重设资格
→ 不能只凭“权限在外”判 nx
→ 转查 zx / x / xn / 其他邻近
```

## 5｜需要防止的矫枉过正

本待审议不能被误写成：

> “只有主体主动求人，才有 nx。”

周瑞家的与赵云已经提供两部独立作品的正式正向控制：主体都没有主动求助，也没有先自行生成当前任务终点，却真实承接并续接外部既定方向，因此 nx 行为功能成立。

纯 nx 的服从、默认延续、等待安排、承接差事，同样可能没有显式求人动作。真正变量应是：

> **主体是否实际把当前方向/权限/解决过程接到外部既有通道上继续。**

因此“实际通道激活”包括但不限于：

- 主动请求；
- 等待外部批准；
- 接受并沿命令继续；
- 被动承接差事并真实执行；
- 被动承接战术终点并在执行窗口持续实现；
- 默认延续既有流程；
- 承认外部裁定并按其结果推进；
- 借用既有人情、身份、制度或权限接口。

而不要求一定出现“求”这个表面动作。

## 6｜与 nx 关系位置的区别

必须分开：

```text
关系位置：权限确实在别人手里。
行为功能：主体当前是否沿那个权限位置推进。
人物本体：主体是否跨场景稳定不占最终方向。
```

因此可能出现：

```text
权限外置 = true
nx关系位置候选 = true
nx当前行为功能 = false
```

也可能出现：

```text
外部任务方向已给定 = true
主体未主动求人 = true
主体实际承接并持续执行 = true
nx当前行为功能 = true
```

不能让关系位置覆盖行为层，也不能把 nx 关系功能缩成“主动求人”。

## 7｜最近邻防线

### nx vs zx

若主体拒绝外部通道，并以自身权能公开改变原阻断结果，转查 zx；但“拒绝”本身不自动等于 zx。

赵云控制同时说明：强行动、强战斗、处于前部位置都不能自动覆盖 nx；若“当前战术终点”仍由外部给定并被真实续接，则该对象层 nx 可以成立。

### nx vs x

若主体不需要外部批准，是因为该对象权限本来就已进入自身稳定调用边界，优先 x，而不是“未使用 nx”。

### nx vs xn

若主体收到外部目标后，核心是主动搭建替代流程、节点、排程和资源组织，xn 上升；但普通执行顺序、顺路选择、交战动作或局部动作自由不能覆盖外部最终方向已经给定这一事实。

### nx vs nz

关系价值、亲密、忠义、回报不决定通道是否激活。关系可以存在而当前 nx 功能不工作。

## 8｜拿掉与反向测试模板

### 拿掉外部权限 / 方向

若外部权限或方向本来不存在，本问题不再是“外置但是否激活”的边界，应重新判断 zx/x/xn 等。

### 拿掉主体拒绝 / 绕开行为

如果主体随后真实进入外部接口并等待、服从或沿其结果推进，nx 应明显上升。

### 拿掉主动求人动作

若主体虽然不求人，但仍承接既定命令、差事、战术终点或流程并持续执行，nx 行为功能可以保持；当前已有周瑞家的、赵云两部独立作品正向控制。

### 反向真 nx

```text
外部方向 / 权限 / 流程存在
→ 主体不占当前最终重设位置
→ 实际请求 / 等待 / 服从 / 承接 / 默认延续
→ 结果沿外部决定接口或既定方向推进
= nx
```

## 9｜下一步最值得验证的问题

1. **第三部被动承接型正向控制**：优先《西游记》或《水浒传》，寻找“没有主动求人，但收到外部命令/任务后，在真正执行窗口持续沿给定终点推进”的高纯案例；若第三部达到 ≥95%，再考虑把“通道激活不要求主动求人”强化为准度层纪律。
2. **部分对象层控制**：主体接受上位目标，却拒绝某个局部执行方式；继续精确切清哪些层 nx 成立、哪些层不成立。
3. **绕开但不扩权控制**：主体拒绝外部权限通道，却只是换一条自建流程，没有公开扩权，应优先 xn 而非 zx。

## 10｜当前结论状态

`status: pending-review`

目前只允许作为准度层待审议纪律使用：

> **权限外置是 nx 的重要前提，但不是充分条件；主体在当前对象层实际沿外部方向、关系、权限或流程续接，才是 nx 行为/关系功能成立的关键观察项。实际通道激活不要求主动求人，被动承接、服从、等待和默认延续同样可以成立。**

当前正向控制数：`2`：

- 《红楼梦》周瑞家的送宫花，99/98；
- 《三国演义》赵云博望坡诱敌，99/98。

禁止据此直接修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡。待第三部正向控制与更多反向材料后再决定是否升格。
