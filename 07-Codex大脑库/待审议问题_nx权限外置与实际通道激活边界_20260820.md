# 待审议｜nx：权限外置 与 实际通道激活边界

## 1｜为什么进入待审议

当前已经跨三部独立作品稳定出现同一边界：

> **外部方向、权限、命令或解决接口客观存在，并不足以自动生成 nx 行为/关系功能。**

三组材料都显示，必须继续观察主体在被测试对象层是否真的承认并沿外部方向、权限、关系或流程推进。

这不是修改 nx 正本，而是对现行 `nx v2.5` 中“主体承认并借用该位置 / 沿既有通道推进”的判据进行案例级强化审议。

## 2｜三部独立作品证据

### A｜《三国演义》关羽过五关

- 曹操文凭 / 回报丞相的合法通关接口真实存在。
- 守关者明确提出可以先禀曹操再放行。
- 关羽知道该接口存在，但拒绝等待、不请求补发文凭。
- 他直接以公开强制改变通行结果。

结论：`external_permission_exists = true`，但 `actual_external_permission_channel_used = false`，当前通行层 nx 排除。

### B｜《水浒传》武松飞云浦后

- 官府内部仍存在知府、叶孔目等可能重新评价案件的权限节点。
- 武松脱险后没有转向申诉、复审或请求外部裁决。
- 他切换为直接复仇 / 逃亡路径。

结论：外部司法权限存在，但当前行动链没有实际沿该权限通道推进，nx 不自动成立。

### C｜《红楼梦》探春抄检大观园

- 王夫人批准搜检，外部上位授权真实存在。
- 探春承认“搜检任务存在”，并主动开门、开箱接受核查。
- 但在“本院怎样查、奴仆能否搜身、自己是否保留否决资格”这一局部对象层，她没有顺着外部执行者的全部既定方式推进。
- 王善保家的越界后，探春公开反击并迫使执行方式改变。

结论：承认一个上位权威事实存在，也不等于当前每个局部对象层都自动成为 nx。

## 3｜候选纪律

当前最窄候选：

```text
外部方向 / 权限 / 解决接口存在
→ 只能证明权限位置、压力来源或可用通道存在

若主体在被测试对象层：
承认该外部位置
+ 实际请求 / 等待 / 借用 / 服从 / 沿流程推进
→ nx 行为/关系功能上升

若主体明确拒绝、绕开或在该对象层保留并使用最终否决/重设资格
→ 不能只凭“权限在外”判 nx
→ 转查 zx / x / xn / 其他邻近
```

## 4｜需要防止的矫枉过正

本待审议不能被误写成：

> “只有主体主动求人，才有 nx。”

纯 nx 的服从、默认延续、等待安排也可能没有显式求人动作。真正变量应是：

> **主体是否实际把当前方向/权限/解决过程接到外部既有通道上继续。**

因此“实际通道激活”包括但不限于：

- 主动请求；
- 等待外部批准；
- 接受并沿命令继续；
- 承认外部裁定并按其结果推进；
- 借用既有人情、身份、制度或权限接口。

而不要求一定出现“求”这个表面动作。

## 5｜与 nx 关系位置的区别

必须分开：

```text
关系位置：权限确实在别人手里。
行为功能：主体当前是否沿那个权限位置推进。
人物本体：主体是否跨场景稳定不占最终方向。
```

因此可能出现：

```text
权限外置 = true
nx关系位置候选 = true
nx当前行为功能 = false
```

不能让关系位置覆盖行为层，也不能从一次拒绝反推人物稳定本体非 nx。

## 6｜最近邻防线

### nx vs zx

若主体拒绝外部通道，并以自身权能公开改变原阻断结果，转查 zx；但“拒绝”本身不自动等于 zx。

### nx vs x

若主体不需要外部批准，是因为该对象权限本来就已进入自身稳定调用边界，优先 x，而不是“未使用 nx”。

### nx vs xn

若主体绕开外部通道后，核心是主动搭建替代流程、节点、排程和资源组织，优先提高 xn；不能把“另想办法”直接判 zx。

### nx vs nz

关系价值、亲密、忠义、回报不决定通道是否激活。关系可以存在而当前 nx 功能不工作。

## 7｜拿掉与反向测试模板

### 拿掉外部权限

若外部权限本来不存在，本问题不再是“权限外置但未激活”的边界，而应重新判断 zx/x/xn 等。

### 拿掉主体拒绝 / 绕开行为

如果主体随后真实进入外部接口并等待其决定生效，nx 应明显上升。

### 反向真 nx

```text
外部权限存在
→ 主体承认该权限是当前必经门
→ 实际请求 / 等待 / 服从 / 借用
→ 结果沿外部决定接口生效
= nx
```

## 8｜下一步最值得验证的问题

1. **被动服从型控制**：主体没有主动“求人”，但收到命令后实际沿通道推进，能否防止本纪律被误写成“只有主动请求才算 nx”。
2. **部分对象层控制**：主体接受上位目标，却拒绝某个局部执行方式；需要精确切清哪些层 nx 成立、哪些层不成立。
3. **绕开但不扩权控制**：主体拒绝外部权限通道，却只是换一条自建流程，没有公开扩权，应优先 xn 而非 zx。

## 9｜当前结论状态

`status: pending-review`

目前只允许作为准度层待审议纪律使用：

> **权限外置是 nx 的重要前提，但不是充分条件；主体在当前对象层实际沿外部方向、关系、权限或流程续接，才是 nx 行为/关系功能成立的关键观察项。**

禁止据此直接修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡。待更多正向/反向控制后再决定是否升格。
