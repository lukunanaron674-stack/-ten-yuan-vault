# 刘备三让徐州｜外部承认/牌印交付 ≠ 现实 x，权领后才成立第三作品控制

## 0｜本轮问题

本轮只测试火轴一个窄变量：

> 徐州官员、百姓已经明确推举，牌印也已经捧到刘备面前，是否足以证明徐州军政治理 `x` 已经归刘备掌握？

结论：**不足。**

真正的现实 `x` 直到刘备接受“权领徐州事”，并开始用人、调兵、安民后才成立。

## 1｜剧情事实与最小差异

陶谦病危时再次要求刘备受取徐州牌印，刘备仍推辞。陶谦死后，徐州官员捧牌印交送刘备，刘备仍“固辞”；次日百姓拥挤府前哭拜，请刘备领州，关羽、张飞再劝，刘备才同意“权领徐州事”。

接受以后，文本立即给出现实治理动作：

- 以孙乾、糜竺为辅；
- 以陈登为幕官；
- 将小沛军马尽数调入城中；
- 出榜安民；
- 安排陶谦丧事并申奏朝廷。

因此同一徐州治理对象层可以切成：

```text
阶段A｜牌印已送 + 官民推举
外部承认：有
权力交付意向：有
刘备真实接受：否
徐州治理决定是否由刘备稳定生效：否
→ 被测 x = off

阶段B｜刘备“乃许权领徐州事”
真实接受：有
用人：有
调兵入城：有
安民命令：有
现实节点围绕其治理位置运行：有
→ 被测 x = on
```

## 2｜x 证据

current canonical 要求 `x` 看到明确对象进入主体实际占有、使用、调配、调用、处分、否决或排除边界，不能只靠职位、印信、视觉或一次接触。

本例阶段B满足：

```text
徐州军政/治理对象明确
+
刘备成为现实掌握主体
+
可调入军马
+
可安排州内辅佐与幕官
+
可发布安民命令
+
现实行政节点开始围绕其决定运行
= 徐州治理 x 成立
```

阶段A虽然已有牌印和集体拥戴，但刘备仍实际拒绝，因此不能把“别人想把权给你”提前写成“权已经归你”。

## 3｜zn 检查

本轮不锁 `zn`。

刘备前期拒绝与后期接受都存在“汉家城池、仁义名声、百姓安危、责任条件变化”等多重解释，但当前窄桥段不足以独立证明某一内部不可轻易让渡原则同时通过：

- 无奖励/认可仍进入判断；
- 冲突中保有最终排序资格；
- 跨阶段保留未来调用资格；
- 有明确边界与让渡代价。

因此：

```yaml
zn_current_for_tested_governance_object: not_locked
stable_zn_essence_locked: false
```

这防止把“被百姓拥戴后接州”倒推成某种宏大本体原则。

## 4｜关键本体变量

本轮真正比较：

```text
外部定义/承认/交付意向是否存在？
vs
被测对象是否已经真实进入主体掌握边界？
```

最短纪律：

> **别人承认你“应该拥有” ≠ 你已经现实拥有。**

> **牌印送到面前 ≠ 权限已经生效。**

## 5｜拿掉测试

### 拿掉“百姓拥戴/牌印交付”

只要保留阶段B的真实接管、用人、调兵与安民命令，徐州治理 `x` 仍可成立。

→ 外部承认/牌印不是现实 `x` 的必要条件。

### 拿掉真实接管与生效动作

保留所有推举、牌印与劝进，但刘备继续拒绝、不用人、不调兵、不发治理命令。

→ 徐州治理 `x` 不成立。

→ 名义/承认不是现实 `x` 的充分条件。

## 6｜反向测试

若要在阶段A就锁 `x`，必须看到至少一种硬证据：

```text
刘备虽口头推辞
但徐州同类重大治理决定已经可由他直接作出并生效
或
他已稳定调用军政资源且无需再次取得接受/授权
```

原著阶段A没有这种证据。

反过来，阶段B已经出现连续现实生效，所以 `x` 明确转为 on。

## 7｜最近邻排除

- `x vs z`：百姓拥戴、官员推举首先是外部认可/支持，不等于现实处分权；
- `x vs nx`：接受徐州方向的入口来源可另查 `nx`，但真实接管后徐州治理范围本身进入刘备当前掌握，应重新检查 `x`；
- `x vs xn`：如何配置孙乾、糜竺、陈登、军马与安民流程有 `xn` 邻近，但“这些对象是否已经归刘备可调配”仍是 `x` 问题；
- `x vs zx`：接掌既有权力真空后的治理位置，不因规模大就自动等于公开扩权 `zx`。

## 8｜第三因素冻结

冻结：

- 刘备仁义/虚伪评价；
- 皇叔身份；
- 陶谦善恶；
- 曹操后来是否攻徐州；
- 刘备最终是否守得住徐州；
- 文学上的“三让”形象。

只保留：

```text
牌印/推举是否出现
→ 主体是否真实接受
→ 决定是否现实生效
→ 人员、军马和治理对象是否进入稳定调配边界
```

结论不变。
