## 源端点、目标端点与变量

本关系为补位，不按父子生成处理。

### xz 补 nz

- 已有端点：一段关系已有余温与不愿结束；
- 作用机制：离散、错过和永久失去成为现实可能，迫使主体确认是否返回、等待或承担风险；
- 被改变变量：返回窗口、停靠是否经风险检验、关系余温的选择重量。

### nz 补 xz

- 已有端点：主体被危险推着移动，但只有远离，没有明确去向；
- 作用机制：仍有余温的关系对象成为可回返位置；
- 被改变变量：风险路径方向、承担理由、关系终点和归宿候选。

## 候选机制

### A：失去压力使停靠成为选择

```text
已有关系余温
→ xz 使永久失去成为现实可能
→ 模糊等待无法无限延长
→ 主体明确是否返回或承担风险
→ nz 获得选择重量
```

### B：关系终点为漂流定向

```text
主体不断被危险推着移动
→ nz 提供可回返对象
→ 路径从“离开这里”转成“回到那里／那个人”
→ xz 获得方向与收束候选
```

### 排除机制

收留、食物、医疗、防御和现实安全主要属于 `n 克 xz`；走投无路被迫留下不构成自愿停靠。

## 正例

### 《最后生还者》乔尔与艾莉

- xz：感染区、猎人地带、手术导致永久失去的风险；
- nz：旅途中形成的父女式余温；
- xz 补 nz：手术可能让关系永久终止，使余温从同行惯性变成乔尔必须承担代价的选择；
- nz 补 xz：艾莉成为明确回返对象，使护送路径转成“带她离开并继续共同生活”。

### 《星际穿越》库珀与墨菲

- xz：宇宙路径、时间错位和可能无法返回；
- nz：父女关系余温及长期保留的回返位置；
- xz 补 nz：可能永别使等待获得跨越一生的命运重量；
- nz 补 xz：墨菲和父女承诺使宇宙漂流持续具有“回去”的方向。

### 纯结构例

战争撤离中，甲因不愿与旧友乙以未告别结束而冒险返回旧城。道路封锁和时间窗缩窄使余温必须接受选择检验；旧友关系使危险路径获得明确方向。

## 反例

1. 流浪猫被固定投喂：优先判 n 的照护承载。
2. 避难所提供床位医疗：改变安全可达性，属于 n 克 xz。
3. 两个人同时想念：只是情绪共现。
4. 没钱只能同居：被迫停留，不是自愿停靠。
5. 追兵逼近后突然告白：可能只是临界状态。
6. 怀念故乡但不改变路径：没有补入 xz 的方向变量。
7. 为道德责任救陌生人：优先判 zn。

## 最近邻

- 与 `n 克 xz`：n 改变安全可达性和停留能力；nz 改变风险路径方向与回返对象。
- 与 `z 生 nz`：z 若成立，改变认可关系是否沉淀为不愿结束；本关系不要求认可主体。
- 与 `zn`：因原则冒险返回是 zn；因不愿关系结束而返回才偏 nz。
- 与普通爱情依恋：关系标签不能替代双向缺口变量。

## 拿掉测试

1. 拿掉 xz 的失去风险，若停靠重量不变，则 xz 未补入。
2. 拿掉 nz 的回返对象，若路径方向不变，则 nz 未补入。
3. 拿掉食物、房屋、医疗和保护后仍成立，才排除 n。
4. 拿掉道德责任后仍因关系余温返回，才排除 zn。
5. 拿掉恋爱或亲属标签后仍有共同时间和关系余温，才排除题材替代。

## 反向测试

```text
xz 补 nz ≠ xz 生 nz
nz 补 xz ≠ nz 生 xz
```

xz 不创造柔情，只让已有柔情面对失去风险；nz 不创造危险，只给已有风险路径提供回返对象。

## 动态链后果

```text
关系可能真正失去
→ 模糊余温接受选择检验
→ 主体决定是否返回或等待
→ 回返对象反过来给危险路径定向
```

改变的是命运中的离开是否拥有可返回的关系终点，以及停靠是否经过真实失去风险检验。

不机械生成获救、团圆、永久安全、爱情或正确选择。
