# 《水浒传》宋江高唐州｜异名对象但同一现实瓶颈正向控制

## 0｜本轮问题

当前待审议已由三部作品锁出一个反例边界：`zx` 与 `nx` 即使都独立成立、前后也有因果连续，只要二者解决的是不同对象层／不同现实变量，就不能锁严格补关系。

本轮专门反打一个危险误读：

> 是否必须要求 `zx` 缺口与 `nx` 补入对象在名称上属于“同一对象层”？

结论：**不需要同名，但必须直接作用于同一个现实瓶颈。**

本例原正式案例已以 `99/97` 锁定严格 `zx+nx` 补关系。本轮不重复制造人物结论，只审查“对象名不同是否会误杀真补”。

## 1｜剧情事实、触发、对象、动作与结果

### 触发

宋江率梁山军攻高唐州救柴进。高廉妖法使普通军力与宋江现有处理路径无法稳定推进，形成明确的当前瓶颈。

### 对象

- `zx` 端对象：宋江公开军事推进／梁山军能否把“救柴进、破高唐”继续压进现实。
- `nx` 端对象：公孙胜的专属法术能力 + 罗真人对其离山与新法授予的外部许可接口。

对象名称明显不同：一个是“军事推进”，一个是“专家能力／许可”。

### 明确动作

1. 高廉妖法实际阻断梁山军推进。
2. 吴用识别必须寻找公孙胜。
3. 公孙胜不能自行立即下山，需要请示罗真人。
4. 罗真人第一次真实拒绝，证明许可门不是装饰。
5. 后来罗真人放行并授予可破高廉的正法。
6. 公孙胜回军后，宋江重新传令拔寨推进。
7. 公孙胜破解高廉妖法，梁山军继续公开进攻，高唐州被攻入，救援目标继续兑现。

### 结果

`nx` 进入后没有替换宋江的最高救援／攻城方向；它直接解除的是宋江 `zx` 当前推进被卡住的那个阻断条件。宋江随后重新把该条件兑换为同一战役目标的公开推进。

## 2｜zx 证据

`zx` 独立成立在：

```text
宋江自己占据救柴进／破高唐方向
→ 公开率军推进
→ 外部破解条件进入后重新传令全军进攻
→ 原阻断结构被压破
→ 梁山现实作用范围推进到高唐州城内
```

这里不是把“宋江是首领”直接判 `zx`；既有主帅权限属于 `x` 最近邻。本轮 `zx` 锁的是自身公开作用持续向新的现实范围推进。

## 3｜nx 证据

`nx` 独立成立在：

```text
普通军力无法稳定处理高廉妖法
→ 专属法术不在宋江原有处分范围
→ 公孙胜又受罗真人真实许可约束
→ 必须经过外部专家／师门接口
→ 罗真人可真实拒绝并实际拒绝过
```

因此 `nx` 不是“宋江没主见”，而是强主体在专属能力／许可层的关系功能。

## 4｜关键压力

关键压力不是“高廉强”或“梁山败过”，而是：

> **同一个现实瓶颈：宋江已有公开军力，但无法稳定穿透高廉妖法，导致当前攻城救援无法继续兑现。**

`nx` 提供的法术／许可虽然与 `zx` 的“军事推进”不是同名对象，却直接改变这一瓶颈的必要条件。

## 5｜拿掉测试

### 5.1 拿掉 nx

拿掉公孙胜、罗真人及等价专属破解接口：

- 宋江的 `zx` 方向和公开军力仍成立；
- 但高廉妖法继续卡住同一攻城救援瓶颈。

缺口：`公开军事推进缺少可稳定穿透专属妖法的处理接口`。

### 5.2 补回 nx

罗真人放行并授法，公孙胜回军破解妖法；这个补入不是另开一个无关问题，而是直接解除 `zx` 当前瓶颈。

### 5.3 拿掉 zx

只保留罗真人愿意放人、公孙胜会破法：

- `nx` 专家／许可接口仍存在；
- 但不会自动生成“梁山公开攻城并救柴进”的现实推进。

缺口：`外部破解条件缺少被主体转化为同一战役目标的公开落地权能`。

### 5.4 补回 zx

宋江重新传令、组织全军推进，把 `nx` 提供的破解条件兑现为同一战役目标。

双向拿掉均通过。

## 6｜反向测试

### 反向成对象层错位伪补

如果公孙胜／罗真人提供的是另一个与当前高唐攻城无直接关系的资源，例如只处理宋江日后个人身份、另一场战役或无关政治许可，那么即便时间上紧接本段，也不能锁严格补。

### 反向成普通协作

如果高廉妖法并未真实形成专属阻断，普通军力同样可以稳定解决，而公孙胜只是锦上添花，则 `nx` 对 `zx` 的必要缺口显著下降，严格补应降级。

## 7｜最近邻排除

- `nx vs xn`：寻找公孙胜的路线、传报和节点安排偏 `xn`；为什么必须经过公孙胜／罗真人这一外部专属接口，才是 `nx`。
- `nx vs x`：公孙胜师门许可与新授正法不在宋江稳定处分范围，不能判 `x`。
- `zx vs x`：宋江已有梁山军令权是 `x`；本轮 `zx` 是公开推进跨过新的现实阻断。
- `zx vs xn`：战役组织偏 `xn`，但不能替代公开作用范围被继续推进的 `zx`。

## 8｜第三因素冻结

冻结：宋江首领身份、公孙胜人物强弱、高廉善恶、妖法视觉奇观、梁山最终胜负、柴进关系价值、吴用谋略评价。

只保留：

```text
zx 当前推进被何变量卡住？
nx 新增的条件是否直接解除这个变量？
解除后 zx 是否把该条件兑现回同一现实目标？
```

结论不变。

## 9｜本轮结论

本例明确反证“对象名称必须相同”这一机械版本。

更准确的候选纪律应是：

> **严格 `zx↔nx` 补关系不要求两个端点在文字标签上同名；要求的是双方缺口必须在同一现实瓶颈上直接因果对接。**

机器可读：

```yaml
zx_endpoint: evidence-locked
nx_endpoint: evidence-locked
strict_zx_nx_complement_locked: true
same_label_object_layer: false
same_real_bottleneck_direct_coupling: true

zx_converts_nx_condition_into_same_goal: true
```

本轮只作为现有 `pending-review` 的正向控制，不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
