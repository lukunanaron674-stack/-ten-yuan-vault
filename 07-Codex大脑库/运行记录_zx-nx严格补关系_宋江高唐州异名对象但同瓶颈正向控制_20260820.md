# 运行记录｜宋江高唐州｜旧严格补子结论撤回

## 保留的事实资产

- 宋江持续占据破高唐、救柴进的公开推进方向，当前 `zx` 端保留。
- 高廉妖法真实阻断普通军力。
- 公孙胜专属能力与罗真人放行/授法不在宋江稳定调用边界，当前 `nx` 端保留。
- `nx` 接入后直接解除宋江当前推进瓶颈，因此 `nx→zx` 单向补缺成立。
- 对象名称不同但直接作用于同一现实瓶颈这一观察仍可保留。

## 撤回的子结论

旧记录把下列句子当作 `zx→nx` 反向缺口：

> 没有宋江的公开军事推进，公孙胜/罗真人的破解条件不会自动生成梁山攻城救援结果。

按 2026-08-26 新双向拿掉门，这只能证明“共同结果缺少主体行动端”，不能证明 `nx` 自身核心功能受损。

拿掉宋江 `zx` 后：

- 公孙胜的专业破解能力仍存在；
- 罗真人的许可/授法处分接口仍存在；
- 该外部接口没有因为缺少宋江 `zx` 而失去自身核心功能。

因此：

```yaml
nx_to_zx_gap_filling: true
zx_to_nx_core_gap_filling: false
strict_zx_nx_complement_locked: false
one_way_complement: nx_to_zx
```

高廉被处理、柴进获救、任务结束后，旧公孙胜/罗真人接口不再是后续战役的当前必经门，这一“nx 当前窗口会随任务/瓶颈结束而关闭”的观察仍有效。

但它不再计作“严格补闭环”，只计作：
