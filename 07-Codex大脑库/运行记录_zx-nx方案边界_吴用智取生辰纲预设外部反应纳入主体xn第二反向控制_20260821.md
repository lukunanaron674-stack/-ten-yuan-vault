# 范围
仅截取《水浒传》第十六回黄泥冈实施“智取生辰纲”的执行结构：吴用预先安排七人扮作贩枣客、白胜扮卖酒人，以“先证明酒可饮—制造争酒—借白胜夺瓢完成下药—诱使押送方解除戒心并饮酒”为圈套，使杨志一行的外部反应成为主体方案中的功能性节点。

本记录不重做仓库已有“公孙胜提供路数、晁盖提供白胜条件是否构成nx”的信息源边界案例；该旧案例仍维持 candidate/deferred。这里只研究：外部主体的反应何时可以计入吴用自己的 xn 结构传播。

# 剧情事实
1. 公孙胜提供生辰纲将从黄泥冈经过的路数，晁盖提供白胜这一可用人际节点；吴用随后明确表示自己已安排圈套，并主张具体智取计策。
2. 到黄泥冈执行时，七人扮作贩枣客，白胜扮作卖酒人。酒并非一开始就全部下药；七人先真实饮用好酒，用可见的安全行为降低押送方戒心。
3. 刘唐故意再去兜酒，白胜当众阻拦；这场“争酒”并非偶发冲突，而是给吴用创造下药动作的遮蔽接口。
4. 吴用把药抖入瓢中，假作再去兜酒；白胜劈手夺瓢并把其中药酒倾回桶内。后文明确点明“那计较都是吴用主张”。
5. 杨志一方看到七人先饮无事，又在炎热、口渴和军汉强烈饮酒意愿下最终买酒饮用；随后中药倒地，七人按预先目标取走生辰纲。
6. 因此杨志一方“由怀疑到解除戒心、最终饮酒”的反应不是吴用动作之后随机发生的背景，而是圈套必须诱发并利用的中间节点。

# 木轴判定

## zx
本窄阶段不锁 zx。

吴用的计策最终成功改变了生辰纲归属，但整个过程以隐藏身份、伪装、诱导和秘密下药为主；没有证据表明吴用借此取得新的公开组织处分权、让原有秩序承认一个扩大后的吴用决定接口，或使其稳定决定范围上升。

因此：
- 计策成功 ≠ zx；
- 对方被我算中 ≠ zx；
- 结果巨大 ≠ 公开扩权。

本段主邻近是 xn，而不是 zx。

## nx
方案设计层 nx 排除为主判。

公孙胜提供路线、晁盖提供白胜这一外部条件的边界仍服从既有 candidate：外部事实信息源是否计入 nx 解决通道，仓库尚未正式锁定。

但一旦进入“怎样让杨志一行喝下药酒”的运行结构，关键圈套、人员角色、欺骗节点、下药窗口与最终取纲路径由吴用自行组织，不是沿某个外部主体给出的完整解决方案续接。

因此：
`nx_in_scheme_design_layer: rejected_as_primary`

## xn
高纯成立。

吴用不只是预测“杨志可能会喝酒”，而是主动把外部反应写进了自己的运行骨架：

```text
先让贩枣客真实饮酒
→ 诱发“酒看起来安全”的判断
→ 故意制造刘唐争酒
→ 诱发白胜当众夺瓢
→ 吴用借该节点完成隐蔽下药
→ 押送方在口渴与安全表象下买酒
→ 中药倒地
→ 取走生辰纲
```

外部动作虽然由白胜、刘唐、杨志与军汉分别完成，但传播关系主要由吴用预设、诱导并继续接续。

因此：
`xn_subject_structural_rewrite: evidence-locked`
`external_reaction_preplanned_as_scheme_node: evidence-locked`
`external_reaction_counts_toward_subject_xn: true`

# 与诸葛亮博望坡的最小差异与同构

诸葛亮博望坡：
- 赵云诈败是主动诱导；
- 夏侯惇追击是外部反应；
- 追击进入火攻、伏兵的预设下游节点；
- 因而追击可计入诸葛亮 xn 结构。

吴用黄泥冈：
- 贩枣客先饮、争酒是主动诱导；
- 押送方解除戒心并最终饮酒是外部反应；
- 饮酒进入中药、失去行动力、取纲的预设下游节点；
- 因而该外部反应可计入吴用 xn 结构。

共同变量不是“对方做了什么”，而是：

> 对方的反应是否被主体预设、诱导、纳入结构，并由主体继续利用。

# 拿掉测试

## 拿掉杨志一方最终饮酒反应
若杨志坚持禁酒，军汉最终也不喝，吴用当前圈套无法按原样进入“中药倒地→取纲”的下游节点。说明“目标方饮酒”是结构性功能节点，不是事后背景。

## 拿掉前置安全表象
若七人没有先喝好酒、没有让押送方看见“饮后无事”，杨志的戒心不会按原设计被削弱，当前诱导骨架显著受损。

## 拿掉吴用的预设与接续
若七人只是偶然争酒、杨志一行偶然喝酒，而吴用事前没有把这些反应连接到下药与取纲节点，则这些外部动作只能记作外部反应，不能倒算吴用 xn。

## 拿掉公孙胜与晁盖的事实输入
吴用当前这套黄泥冈方案需要重做，说明信息条件重要；但这不改变本轮的 xn 归因判断：一旦方案形成，外部反应是否属于其结构，取决于吴用是否预设、诱导和接续，而不是信息最初由谁提供。

# 反向测试

## 反向成“外部反应不计入主体 xn”
吴用只让七人站在黄泥冈，杨志一方因为自身内部矛盾偶然买酒，吴用没有预设该反应也没有为它配置后续节点。此时即使结果碰巧有利，也不能把目标方反应计入吴用 xn。

## 反向成 nx
若完整的“先饮酒示安全—争酒—下药—诱饮—取纲”方案来自另一个外部人物，而吴用主要按其既有方案执行，则方案设计层 nx 显著上升。

## 反向成 zx
若吴用借此公开取得原先不存在的梁山/聚义组织最终处分权，并让众人以后必须围绕其新增决定接口运行，才应另查 zx；本桥段没有。

# 最近邻排除

## xn vs 外部反应传播
不是看到对方有反应就算 xn。至少需要：
1. 主体预设反应；
2. 主体主动制造诱导条件；
3. 反应成为下游必要/功能性节点；
4. 主体继续利用该反应推进。

本例四项齐全。

## xn vs zx
吴用高度控制结果，但控制方案结构与扩大公开决定范围是两回事。前者支持 xn，后者本段不成立。

## nx vs xn
外部提供事实条件与主体自行组织解决方案必须分开。本轮冻结既有“信息源是否算nx”争议，不借新 xn 证据倒灌修改旧 candidate。

# 关键压力
- 生辰纲有押送队和杨志警惕；
- 黄泥冈炎热、军汉口渴，提高饮酒诱因；
- 直接硬取风险高，因此方案需要让目标方自己进入失能节点。

压力只是解释为什么诱导结构必要，不直接判十元。

# 第三因素冻结
冻结：吴用“智多星”称号、最终成功、杨志个人性格、晁盖领袖身份、七星聚义象征、下药伦理、后续梁山经历。

只保留：谁设计运行骨架、谁预设外部反应、谁诱导该反应、该反应是否进入下游节点、主体是否继续利用。

# 结论
本轮正式锁定：

> 外部主体的动作并不因“由别人亲自完成”就自动排除在主体 xn 之外。若主体事先设计诱导条件，把该反应作为自己方案的功能性中间节点，并继续利用其触发下游结构，则该反应可以计入主体 xn 传播。

本例与《三国演义》诸葛亮博望坡形成第二部独立作品反向正例。
