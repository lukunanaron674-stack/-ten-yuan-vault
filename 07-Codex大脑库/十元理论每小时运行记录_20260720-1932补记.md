总词典旧条目：

```text
《逃出绝命镇》
被规则系统排斥
→ 身份漂流
```

正式专项：

```text
xn 主动组织正常顺序、路线、时间窗、人员与许可
→ 主体偏离后被记录、识别并持续处理
→ 可用路线、时间窗与退路逐步减少
→ 危险由抽象可能转为可感知逼近
→ xz 上升
```

旧条目缺少 xn 的主动组织、偏差识别和持续运行，也缺少 xz 的风险可达性、时间窗和退路变量；并混入社会排斥、身份焦虑及 x并z 身份壳问题。

## 源端点、目标端点与变量

### 源端点 xn

- 有主动组织者或持续运行的外化结构；
- 规定正常顺序、路线、时间窗、人员、许可与信息接口；
- 记录偏差并跨节点、交接和重复流程持续处理；
- 不是一次临时命令或单个强者临时阻拦。

### 目标端点 xz

- 危险从抽象可能变成可感知逼近；
- 安全路线、时间窗或身份接口减少；
- 偏离触发追踪、拦截、暴露或封锁；
- 主体不能稳定停留，必须沿高风险路径行动。

### 被改变变量

```text
偏离被识别概率
暴露与追踪概率
安全路线数量
可用时间窗
退路宽度
稳定停留可能性
危险可到达性
```

### 成立阶段、体量与显影

```text
xn 已经运行
→ 主体开始偏离或退出
→ 结构识别并持续处理偏差
→ 风险路径形成
```

低体量为单次检查提高暴露或关闭一条路线；中体量为持续追踪和多条路径关闭；高体量为整个城市、组织或生活系统都能识别偏离。

## 候选机制

### A：偏差识别

```text
xn规定正常流程
→ 记录、监控与节点使偏离可识别
→ 偏离者被标记、追踪或拦截
→ 危险由潜在转为显形
→ xz上升
```

理论后果：目标变量是暴露率、追踪率和危险可到达性，不是一般制度压抑。

### B：安全路径压缩

```text
xn组织路线、许可、资源与时间窗
→ 安全通过方式被限定
→ 偏离后剩余路径逐条关闭
→ 退路缩窄并进入临界行动
→ xz上升
```

理论后果：不需要明确追兵；结构持续减少可用路径即可形成 xz。

两种候选统一为：

```text
识别偏差
→ 持续处理偏差
→ 压缩安全路径
→ xz成立
```

## 正例

### 《逃出绝命镇》克里斯决定离开阿米蒂奇家

xn 为邀请、筛选、催眠、拍卖、手术、人员分工与信息隔离的重复流程；xz 为车钥匙、身体控制和出口连续被切断。核心不是“不被认可后的身份漂流”，而是结构把偏离转成捕获流程。

### 《楚门的世界》楚门连续尝试离开海景镇

xn 为节目组对演员、交通、路线、广播、天气与播出节点的长期组织；xz 为正常出口逐条失效，最后只剩人工风暴与海上临界。让危险持续追上偏离行为的是节目系统的长期组织与调度。

### 自动门禁结构例

刷卡偏差被记录，相邻区域自动锁闭，巡逻路线调整，可用出口减少，研究员必须在下一轮封锁前穿越危险区域。

## 反例

1. 学校课表让学生压抑：只有制度场景和情绪变化。
2. 航班因天气取消：有 xz 状态，但源端点不是主动 xn。
3. 杀手临时追赶：主要是 zx 或普通追逐，没有持续结构。
4. 人物进入制度前已经漂流：只是先后共现。
5. 危险出现后才制定逃生计划：属于反向 `xz→xn`。
6. 制度只表达排斥，不改变路线和时间窗：可能是 x并z、z 或情绪状态。

## 最近邻

- 与 `xn克zx`：前者改变权能即时扩张范围，本关系改变偏离者的安全路线和危险可到达性；
- 与 `x克z`：掌握资源、出口或认可接口不等于持续结构识别偏差；
- 与普通 xz 场景：迷宫、站台、走廊、监控和倒计时不能代替 xn 的主动组织。

## 拿掉测试

1. 拿掉流程、记录、交接和重复处理，只剩临时阻拦，若危险仍完整，则不依赖 xn；
2. 拿掉人物偏离，危险不显形，说明关系只在结构处理偏差阶段成立；
3. 结构识别异常却不关闭路线、不减少时间窗，xz 不成立；
4. 拿掉 xn 后，自然灾害、怪物或私人仇杀仍完整追上人物，案例不依赖本关系；
5. 《逃出绝命镇》拿掉重复捕获流程，只留一次歧视，不会形成同强度临界。
