# 木轴清尾｜zx↔nx 中间区 → 真 nx 跨作品最小差异闭环

## 0｜本轮只解决一个问题

本轮只处理待审议问题中的 A 槽：

> 外部方向已经明确存在时，什么最小变化会让“主体保留最终方向资格的合法中间区”真正跨到 `nx`？

不新增第四、第五个“拒绝别人方案”的中间区样本，不处理新的 zx 扩样，也不修改 L1/L2 canonical。

## 1｜current canonical

L1 v1.6：

```text
木 = zx ↔ nx
核心变量 = 最终方向与作用权来源
zx = 自身生成并占据方向，且现实作用权向外展开
nx = 不占最终方向、沿既有通道续接
```

本轮只在 L4 案例/准度纪律层做端点最小差异闭环。

## 4｜最小判别式

两例都满足：

```text
external_direction_exists = true
actor_has_capacity = true
actor_can_act_voluntarily = true
```

因此这些不能区分中间区与 nx。

真正差异：

```text
中间区：
external_direction exists
+ actor retains final veto/reset right
+ actor may reject and choose another endpoint

真 nx：
external_direction exists
+ final direction/role/channel remains external
+ actor does not occupy final reset position
+ actor actually continues through that channel
```

最短式：

```text
“方向来自外部” ≠ nx

nx = final_direction_not_occupied_by_actor
   + actual_channel_activation
   + continued_execution_along_existing_direction
```

木轴中间区与真 nx 的关键开关不是“有没有外部任务”，而是：

```text
actor_final_veto_reset_right: retained -> not occupied
```

且必须出现现实续接，不能只停在名义安排。

## 5｜nearest-neighbor

### vs zx

- 鲁智深：保留自身去向，但没有公开扩权，故中间区。
- 小白龙：当前窗口没有以自身权能改写取经终点、服务对象或角色结构，故不判 zx。

### vs xn

小白龙不是因为自行搭建计划、节点、排程而判 nx；即使执行时存在局部行动自由，当前任务终点与角色接口仍由外部既定。

### vs x

小白龙没有取得对整个取经任务、唐僧、角色系统的掌握/处分权；局部执行能力不能覆盖木轴方向来源。

## 10｜失败类型与 guard

新增清尾 guard：

```text
FALSE_NX_EXTERNAL_ORIGIN
= 方向最初来自外部，就直接判 nx

FALSE_NX_OBEDIENCE_WORD
= 看见“接受/听从/合作”就判 nx

FALSE_NX_NOMINAL_ASSIGNMENT
= 只有任务/身份名义存在，但当前行动链未实际续接

FALSE_NX_TEMPORARY_ROLE_CONFUSION
= 仅因一次临时分工或职位动作就把稳定方向资格外置
```

执行纪律：

```text
1. 先问当前对象层的最终否决/重设资格在谁手里。
2. 若主体仍可真实否决并另择，不能仅凭外部方向来源判 nx。
3. 若最终方向/角色接口外置，再检查主体是否真正激活并持续沿既有通道推进。
4. 强迫、职位、奖惩、一次临时分工只能做第三因素，不能替代上述两步。
```
