# 运行记录｜关羽五关无文凭：高成本内部绕行同一结果的非 nx 控制

## 研究问题

当前 `待审议问题_nx具体节点可替代与外部接口层不可绕过边界_20260824.md` 已提出：如果主体存在不依赖同类外部接口的内部路线，nx 应下降；但此前缺少“内部路线明显更贵、更危险，却确实能实现同一结果”的高纯控制。

本轮只测试《三国演义》第27回一个窄对象：

> 关羽能否在没有曹方通关文凭的情况下，实际通过沿途关隘并继续北上寻刘备？

不把“合法获批通行”与“物理上通过关隘”混成同一个对象。

## 剧情事实

1. 关羽得知刘备消息后决定离开曹营。此前多次到曹操府上求见而不得，于是留下书信、封金挂印后直接离开。
2. 曹操随后追上送行，承认此前“不忘故主”的约定，不追杀关羽；但文本没有显示关羽获得可供沿途关隘查验的正式通关文凭。
3. 第27回沿途关将反复以“无丞相文凭”为理由阻拦关羽。
4. 关羽没有回到曹操处补办文凭，也没有转接另一个等价批准节点，而是以自身武力强行通过。
5. 该路线不是一次偶然成功：连续经过五处关隘，斩六将，最终渡过黄河进入袁绍地界，实际完成“通过曹方关隘继续北上”这一结果。

主要文本依据：
- 《三国演义》第27回《中国哲学书电子化计划》：https://ctext.org/sanguo-yanyi/ch27/zh
- 同回简体版：https://ctext.org/sanguo-yanyi/ch27/zhs

## 对象与路径切分

```text
结果对象 R：
实际通过曹方关隘并继续北上寻刘备

低成本正常路径 P1：
取得曹方正式通关文凭 / 许可
→ 各关按权限放行

实际高成本路径 P2：
无文凭
→ 关将阻拦
→ 关羽以自身武力强行突破
→ 五关连续成功
→ 同一 R 实现
```

关键是：P2 不是“换成另一个结果”。关羽并没有从“北上寻刘备”改成“占领关隘”“自立势力”或“取得合法通关资格”；他仍实现原来的物理通行结果。

## zx 判断

本轮不把“斩将强行过关”自动锁成 zx。

支持 zx 候选的事实：
- 关羽自己的北上寻兄方向明确；
- 外部关隘试图阻断；
- 他以自身权能迫使局部现实让路。

但是否因此形成可持续、公开承认的新决定范围，证据不足。本轮只需要确认：他存在并实际执行一条不依赖许可接口的内部强制路线。

因此：

`zx_from_bypass_itself: deferred`

不得因为“能打赢守关者”直接偷渡 zx。

## nx 判断

### 正常许可接口确实存在

沿途关将把曹操文凭当作正常放行条件，说明“曹方正式通关许可”是一条真实、低成本的外部权限路线。

### 但当前实际执行层 nx 不成立

关羽没有沿这个接口推进：
- 没有取得文凭；
- 没有等待批准；
- 没有在被拒后返回补办；
- 没有转接另一个等价许可节点。

他实际走的是主体自身武力绕行。

所以在“第27回实际过关执行层”应锁：

`nx_permission_route_in_actual_execution: rejected`

这说明：

> 外部许可路线存在，甚至更低成本，并不自动让主体当前行为成为 nx；当前仍要看主体实际沿哪条路线实现同一结果。

## 高成本绕行为什么仍然重要

本例内部路线明显不是低成本：
- 连续发生武力冲突；
- 存在受伤、死亡、追责风险；
- 关羽本人也承认沿途杀人属于“事不得已”。

但这条路线同时具备：
- 实际可执行；
- 连续五关重复成功；
- 不依赖同类外部批准；
- 实现同一个“实际通行”结果。

因此本例反对一个过强命题：

> 只有低成本内部绕行才足以让 nx 退出。

至少在“主体已经真实选择并成功执行内部绕行”的当前行为层，高成本不会自动把旧许可 nx 重新挂回来。

## 拿掉测试

### 拿掉曹方许可路线 P1

关羽仍可沿 P2 强行突破，并且原文本证明这条路线可重复成功。

因此当前实际通行并不以 P1 为不可替代条件。

### 拿掉内部绕行 P2

若又没有正式文凭，则关羽会在第一道真实执行关卡重新留下“无法通过”的缺口。

这证明 P2 是当前行为链的关键现实能力。

### 给关羽补入正式文凭

如果他取得并真实沿文凭通道通过各关，则该执行窗口会明显向 nx 权限关系上升；但这是另一个事实版本，不是原文实际路径。

## 反向测试

### 高成本但仍 nx 的版本

如果所谓“内部绕行”虽然危险，却最终仍必须在关键节点请求外部批准才能使同一通行结果成立，则 nx 仍可保留。

### 换对象伪绕行

如果无文凭后，关羽选择攻占关隘、建立自己的地盘，这已经把结果从“通过关隘”换成“取得关隘处分权”，应重新检查 zx/x/xn，不能拿来证明原通行 nx 被绕过。

本例没有换对象：他杀将后继续赶路。

## 最近邻排除

### nx vs x/zx

本轮只锁“许可接口未被实际使用”。关羽自身武力是否构成 x 或 zx，需要另按决定范围检查，不能把 nx 排除直接等同于 zx。

### nx vs xn

路线选择、护送二嫂、处理多个关隘有 xn 邻近；但本轮核心不是流程设计，而是“同一结果是否必须经过外部批准”。

### 存在许可 vs 实际续接许可

有一个低成本合法接口存在，不代表主体当前就在沿它推进。这与仓库已有“权限存在 ≠ 通道自动激活”纪律一致。

## 第三因素冻结

冻结：关羽忠义评价、武力强弱、曹操对其敬重、过五关的英雄叙事、六将善恶、路线地理争议。

只保留：
1. 结果对象是否为实际通行；
2. 是否存在正常外部许可路线；
3. 关羽是否取得并沿该许可；
4. 是否存在主体自有高成本绕行；
5. 绕行是否真实重复成功；
6. 是否实现同一结果。

结论仍稳定为 99/97。

## 本轮结论

最窄可靠纪律：

> nx 的“不可绕过”不能只按成本二元判断，也必须看主体当前实际执行路径。
>
> 若主体已经真实使用一条不依赖同类外部权限的内部路线，并稳定实现同一结果，则即使该路线成本高、风险大，当前执行层也不能仅因存在更便宜的外部许可路线而继续锁 nx。

但本例尚不能单独证明：

> “只要理论上存在一个高成本内部路线，即使主体没用，也应降低 nx。”

这个更强命题继续保留待验证。
