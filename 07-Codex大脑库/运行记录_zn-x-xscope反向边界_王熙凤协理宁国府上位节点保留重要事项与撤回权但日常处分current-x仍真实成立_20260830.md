# 王熙凤协理宁国府｜上位可撤/重要事项保留 ≠ 当前局部 x 不成立

## 0｜本轮目的

`x scope` 已达到 L4 `pending-review`，普通正向停止堆叠。本轮专测其下一阶段反向边界：

> **权限由上位节点授予、上位仍保留重要事项覆盖/未来撤回可能，是否足以把已经真实生效的 current `x` 降成“只是代理，因此 x=false”？**

结论：不足。

本轮复用已有 99/98 王熙凤协理宁府事实资产，只增加新的 `x scope` 研究用途，不重复计普通 positive control。

## 1｜剧情事实与最小对象层

第13回，贾珍请王熙凤协理宁国府，王夫人放行，宁府对牌进入凤姐手中；日常资源调用不需要逐项向贾珍重新申请。

同时，上位结构没有消失：王夫人明确保留“有了事问哥哥嫂子”的重要事项提醒。也就是说，凤姐获得的不是永久、全局、不可撤销的最终所有权，而是一个有来源、有范围的现实 current delegation。

第14回，迟到媳妇被传到凤姐面前后，凤姐直接决定：

- 打二十板；
- 革一月银米。

执行者立即照办，之后才回来回覆；没有出现“每次处罚必须先报贾珍/尤氏同意，否则不能生效”。

因此被测对象层必须严格锁为：

> **宁国府丧事协理窗口内的日常人员纪律处分 current `x`。**

## 2｜x scope 分账

```yaml
object: 宁国府丧事期间日常人员纪律处分
subject: 王熙凤
permission_type: 处罚 / 银米处分 / 日常纪律裁处
scope: 局部日常事项
term: 协理窗口内
source_node: 贾珍请托 + 王夫人放行
revocability: 上位结构理论上仍可撤回/终止协理
return_obligation: 不适用
higher_level_override: 重要事项仍保留上位回问/覆盖
current_same-layer_effect: 可不经逐次批准直接生效
ultimate_title: false
full_global_disposition: false
current_local_x: true
```

所以本轮不允许把它压成一个粗糙句子：

```text
“可撤销代理” → x=false
```

真正结构是：

```text
current local x = true
+
future revocability / higher-scope override = true
```

二者可以同时成立。

## 3｜关键边界

本轮锁出：

> **revocability ≠ current non-possession。**

以及：

> **上位节点保留未来收回/更高范围覆盖权，不等于主体在撤回发生以前没有真实 current `x`。**

要否定 current `x`，必须看到更强证据，例如：

```text
同一被测日常对象层
→ 每次决定都必须重新申请许可
→ 上位节点可在结果生效前逐次说“不”
→ 未批准前主体决定不能直接进入现实执行
```

原第14回迟到处分不是这种结构。

## 4｜拿掉测试

### 拿掉上位“永久授权”假设

即使不假设凤姐拥有永久、全局、不可撤销权限，只保留：

```text
协理授权当前有效
+
日常处分决定可以直接生效
```

局部 current `x` 仍成立。

说明“永久最终归属”不是 current `x` 的必要条件。

### 拿掉直接生效

如果改成：

```text
凤姐只能提出处罚建议
→ 贾珍逐次批准后才执行
```

则当前日常处分 `x` 会明显下降，应重新检查代理/通道关系。

所以真正必要的是 current same-layer effect，而不是“权限永远不会被收回”。

## 5｜反向测试

未来若贾珍/王夫人明确终止协理、收回对牌，并使凤姐后续同类处罚不再能直接生效，则应判：

```text
current x lifecycle ended
```

不能倒写为：

```text
此前 current x 从未成立
```

这同时说明 `x scope` 与 lifecycle 必须分账：

> **后来被撤回，是 `x` 的生命周期变化；不是对过去真实 current `x` 的否定。**

## 6｜最近邻排除

### x vs nx

授权入口来自外部，可以有 `nx` 邻近；但任务/权限来源不等于当前处分是否已经现实归主体直接使用。来源层与 current possession 层分开。

### x vs xn

分班、点卯、时序设计属于“怎么运行”；本轮只看“处罚结果能否由凤姐直接生效”。

### x vs z

贾珍信任、王夫人认可、宁府众人畏惧都不是 current `x` 的硬证据；硬证据仍是同层处分直接生效。

### x vs zx

本轮不研究扩权，只研究既有授权 scope 内 current possession 是否真实成立。

## 7｜第三因素冻结

冻结：凤姐强势性格、管理才干、家族身份、声望、宁府众人是否害怕她。

只保留四个变量：

```text
权限来源是谁？
被测 scope 是什么？
当前决定是否逐次重新申请？
结果是否可直接生效？
```

结论不变。

## 8｜与 x-scope pending-review 的关系

此前四个正向控制主要证明：

> 窄 `x=true` 不能向更宽 scope 倒灌。

本轮补的是反方向：

> **更宽 scope / 永久归属没有成立，也不能反向把已经成立的窄 current `x` 抹掉。**

因此 x-scope 现在形成双向防误判：

```text
禁止：窄 x → 宽 x 倒灌
同时禁止：宽 x 不成立 → 窄 current x 也被抹除
```
