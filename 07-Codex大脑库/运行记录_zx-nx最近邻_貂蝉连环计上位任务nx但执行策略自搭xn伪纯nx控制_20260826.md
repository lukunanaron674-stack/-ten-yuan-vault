# 运行记录｜貂蝉连环计：上位任务 nx，但执行策略自搭 xn，不能写成纯 nx

## 1｜剧情事实

第8回中，王允先明确提出完整上位目标：利用董卓、吕布二人好色，先将貂蝉许给吕布，再献与董卓，使二人反目，最终借吕布除董卓。貂蝉此前只表示若王允有用她之处愿意效力；具体“离间董卓吕布、令吕布杀董卓”的目标与初始结构由王允提出。

貂蝉接受后并非机械照步骤行动。她明确回答“望即献妾与彼，妾自有道理”。进入董卓府后，她分别对吕布与董卓使用哭诉、示弱、制造误认和自刎威胁等局部手段，使两边对彼此的敌意持续增加。第9回董卓一度接受李儒建议，准备把貂蝉赐给吕布；貂蝉立刻以宁死不受辱、自刎威胁等方式反向改变董卓决定，使其收回赐蝉方案并继续占有她，从而继续放大董卓与吕布冲突。

结果：王允给出的上位离间方向持续存在，但具体执行节点并非全部由王允逐条预设，貂蝉在现场自行组织了关键策略。

## 2｜对象层拆分

```text
上位任务 / 最终政治目标：
离间董卓与吕布 → 借吕布除董卓
→ 由王允提出
→ 貂蝉接受并沿该方向推进
= nx

局部执行方法：
何时哭诉 / 对谁示弱 / 怎样制造误认 / 是否用自刎威胁改变节点
→ 貂蝉现场自行选择、调整
= xn 邻近高显影
```

因此不能因为貂蝉“听王允安排”就把整段写成纯 nx，也不能因为她很会操盘就把上位任务来源倒写成 xn。

## 3｜zx 判断

本窄阶段不锁 zx。

貂蝉确实主动、聪明、能改变董卓和吕布的行为，但她主要依靠隐匿、诱导、情绪表演与节点操盘推进，没有公开把自己的权能压到一个新增决定范围上，也没有让现行政治秩序承认她成为新的公开处分节点。

因此：

```text
结果改变
+ 很主动
+ 操盘成功
≠ zx
```

优先排查 xn，而不是把秘密策略成功误写成公开扩权。

## 4｜nx 判断

在“为什么要离间董卓吕布、最终要实现什么”这一上位对象层，nx 成立：

1. 上位目标由王允明确给出；
2. 貂蝉接受该目标，没有把最终政治方向改成自己的另一套目标；
3. 她真实沿王允设计的关系结构进入董卓 / 吕布两端；
4. 她没有夺取王允这一上位谋划层的最终重设位置。

但该 nx 只锁在上位任务 / 关系方向层，不能覆盖局部执行策略。

## 5｜nx vs xn 最近邻

最小差异：

```text
王允：
给出“离间两人 → 除董卓”的任务与初始关系结构

貂蝉：
在具体互动中自行决定哭诉、误导、自刎威胁等节点动作
```

所以本例的高纯结构是：

```text
上位任务 nx
+
局部执行 xn
```

不是：

```text
整段纯 nx
```

也不是：

```text
因为执行有自主性 → 上位 nx 消失
```

## 6｜拿掉测试

### 拿掉上位 nx

去掉王允给出的“离间董卓吕布、除董卓”任务，只保留貂蝉的表演、哭诉、自刎等能力：

- 她仍可能具有策略执行能力；
- 但原著这条明确的政治行动方向与关系对象组合不再自动成立。

说明上位 nx 是真实结构。

### 拿掉局部 xn

保留王允的上位方案，但假设貂蝉只能机械重复预设话术，不根据董卓、吕布现场反应调整：

- 第9回董卓准备把她赐给吕布这一节点就缺少原著中实际发生的反向调整机制；
- 连环计的具体推进能力显著下降。

说明局部 xn 不是装饰性因素。

## 7｜反向测试

### 反向成更纯 nx

如果王允把每个对象、每句关键话术、每个时间节点都预先写死，貂蝉只照令执行，且不自行重排策略，则 xn 明显下降，更接近纯任务 nx。

### 反向成更强 xn

如果貂蝉只接受“除董卓”这个粗目标，随后自行选择对象、关系链、离间机制和全部流程，则 xn 明显上升，上位 nx 只保留极薄任务入口。

### 反向成 zx

如果貂蝉公开取得并扩大现实政治处分位置，使董卓、吕布或朝廷公开围绕她新增的决定权运行，才重新检查 zx。原著本阶段没有这层证据。

## 8｜第三因素冻结

冻结：
- 貂蝉美貌；
- 董卓 / 吕布好色的人格评价；
- 忠汉 / 奸臣道德判断；
- 后世“美人计”标签；
- 最终董卓死亡的胜负结果。

只保留：
1. 上位目标由谁提出；
2. 主体是否接受并沿该目标推进；
3. 局部执行节点由谁组织、调整；
4. 是否存在公开新增决定权。

结论不变。

## 9｜人物层纪律

本例只锁当前关系与行为功能，不锁貂蝉稳定人物本体。

```text
当前上位关系功能：nx
当前局部运行功能：xn
稳定人物本体：deferred / 不判
```

一次服从不能推出稳定 nx；一次聪明操盘也不能推出稳定 xn 或 zx。
