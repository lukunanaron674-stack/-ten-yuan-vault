# PARA组织法

## 来源
Tiago Forte《第二大腦》（Building a Second Brain）

## 四层结构

| 层级 | 英文 | 含义 | 判断标准 |
|---|---|---|---|
| P | Projects | 正在进行的、有截止日期和目标的短期任务 | "这件事有明确的完成时刻吗？" |
| A | Areas | 需要长期维持高标准的责任领域 | "这件事有没有截止日期？"没有就是Area |
| R | Resources | 持续关注的兴趣、素材、未来参考 | "只是感兴趣/可能有用？" |
| A | Archives | 已完成项目、不再活跃领域 | "三个月内会再用到吗？" |

## 与 ten-yuan-vault 的对照

当前 vault 天然包含了类似结构：

| PARA | vault对应 | 匹配度 |
|---|---|---|
| P-项目 | `10-创作/`、F12活跃采矿任务 | ⭐⭐⭐ |
| A-领域 | `01-十元系统/`、`02-五大主题/` | ⭐⭐⭐⭐⭐ |
| R-资源 | `05-银矿库/`（作品素材）、`09-可视化库/` | ⭐⭐⭐⭐⭐ |
| A-归档 | `03-对话归档/`、`12_归档包/` | ⭐⭐⭐⭐ |

## 核心洞察

vault 已经天然是 PARA 结构，只是命名不同。不需要重构。
真正可以加强的是：

1. **让"项目"更明确**：在 `10-创作/` 下给每个活跃创作建一个带截止日期的项目页
2. **定期归档**：把 6个月没更新的领域/项目移入 `12_归档包/`
3. **PARA 不是文件夹而是状态**：同一篇笔记可以从 Resources 变成 Project 变成 Archive，取决于你的行动状态

## 一句话
> PARA 帮你的 vault 从"知识仓库"变成"行动引擎"。
