# 十元声音特征库

## 总则

每个十元从以下7个维度定义其"声音指纹"：
1. **起手方式** — 第一秒做什么
2. **节奏型** — 推进/停滞/循环/断裂
3. **音区与动态** — 高/中/低，平稳/起伏
4. **编曲密度** — 稀疏/适中/浓密/压迫
5. **人声位置** — 靠前（宣告）/靠中（叙述）/靠后（空间）
6. **和声色彩** — 大调/小调/调性模糊/不解决
7. **时间感** — 向前推/停滞/循环/倒计时

---

## z（冲动/追光）

| 维度 | 特征 | 来源案例 |
|:----|:----|:--------|
| **起手** | 无前奏或极短前奏，第一秒进入主题（秒針を咬む 第一秒就是ACAね的嗓音；Neighbormind蓄力2秒即爆发） | G15, G16, H01-H03 |
| **节奏** | 急促、推进、不给你喘气。节拍不拖，常在八分/十六分音符上运行 | 全体z案例 |
| **音区动态** | 中高音区为主，持续向上攀升。副歌比主歌更高——一直在"追" | 全体z案例 |
| **编曲密度** | 适中偏密——但不压迫（压迫是x的特征）。编曲是"推着歌往前走"不是"压着歌往下沉" | 全体z案例 |
| **人声位置** | 靠前——"我在这里"的宣告。人声不躲在混响里，不躲在乐器后面 | 火炎(宣告z), 秒針(撕裂z) |
| **和声色彩** | 大调偏多或调性明确——z有方向所以不会模糊。不解决是z的特征（追到了也不用解决） | 秒針不解决，KICK BACK不解决 |
| **时间感** | 向前推——不回顾、不循环。追不会重来，所以z的时间是单向的 | 所有z案例 |
| **金矿门槛** | 3/3必须：起手满分+人声靠前+节奏推进+结尾呼应开头（追到了吗？还是继续追？） | Neighbormind回答了"两个人对抗后还是在一起"，秒針回答了"钟停了" |

## zn（意义/信念）

| 维度 | 特征 | 来源案例 |
|:----|:----|:--------|
| **起手** | 叙述性起手——不是宣告、不是爆发——在"说一件事"。起手不追求冲击力，追求"重量" | G01钢琴长音起, G19"縦の糸はあなた", G20钢琴低音起 |
| **节奏** | 中速或慢速——不赶时间。意义不需要追赶 | 全体zn金矿 |
| **音区动态** | 中音区为主，动态从平缓到渐强——不是爆发式，是展开式 | G01从低吟到嘶吼再回落的展开 |
| **编曲密度** | 适中——太密会稀释意义的分量。zn不允许多余 | 全体——多一个音就假了 |
| **人声位置** | 靠中或略靠前——不是宣告"我在这里"，是"我和你说一件事"。语言的位置不会太远 | G19中島みゆき, G20米津 |
| **和声色彩** | 小调偏多或调性偏暗——意义常常在忧伤中被确认。但不确定可以有大调（糸是大调——意义是明亮的） | G19大调, G20小调, G01调性模糊 |
| **时间感** | 展开/叙事——不是在追，是在"展开一幅画卷"。没有终点（意义不需要被追到） | 所有zn金矿 |
| **金矿门槛** | 3/3必须：无一笔浪费（zn不能有任何多余的符号）+ 结尾呼应开头（不说"我找到了意义"，说"我走过了意义"） | G01回到沉默, G20"あなたのいない世界"回到开头 |

## n（承载/空间）

| 维度 | 特征 | 来源案例 |
|:----|:----|:--------|
| **起手** | 渐入——不是开始，是"你发现自己已经在里面了"。n的起手不是"听，我开始了"，是"你已经被这里包围了" | G21长音渐起, H05钢琴长音 |
| **节奏** | 慢速或律动松弛——不推进。n不需要去任何地方 | 所有n案例 |
| **音区动态** | 中低音区为主，动态极小——n不需要变化，需要恒定 | G21全程密度变化但音高恒定 |
| **编曲密度** | 稀疏——n需要空间。密了就失去了"被承载"的可能 | G21只有合成器，H05只有钢琴 |
| **人声位置** | 无或靠后——n的歌常无人声，因为有人声就有"表达"——n不表达 | G21无人声，H05无词钢琴曲 |
| **和声色彩** | 调性模糊——n不告诉你"这是什么调"，因为回答了就不再是空间了 | G21，H05，H06——大量sus4/7和弦 |
| **时间感** | 停滞/循环——n可以永远在原地。不是"不想走"（nz），是"不需要走" | 所有n案例 |
| **金矿门槛** | 3/3极其困难——n天然弱在"克制关系不可替换"（环境音乐可被替换的空间大）。唯一通过的是Brian Eno——他定义的"环境音乐"本身就是n的极致，不可替换的不是谱子是系统 | 唯一金矿：G21 |

## nz（依恋/等待）

| 维度 | 特征 | 来源案例 |
|:----|:----|:--------|
| **起手** | 温柔的进入——不是在宣告"我要等"，是"我就在这里等"。起手常是钢琴或吉他独奏，不拥挤 | G22"あなたを待つ", H08"春よ" |
| **节奏** | 慢速或中速偏缓——不赶。等待不需要速度 | 全体nz案例 |
| **音区动态** | 中音区为主，动态平缓——nz不是爆发（z），不是平铺（n），是"刚好能被感知的温度" | G22全曲平缓 |
| **编曲密度** | 稀疏至适中——太密的话等待就无处可放 | 全体nz案例 |
| **人声位置** | 靠中或略靠前——有温度但不宣告。nz和z的对比：z是"我在——你看我"，nz是"我在——你如果看到就好了" | G22一青窈靠中的嗓音 |
| **和声色彩** | 大调偏多——等待本身是温暖的。如果nz是小调，它就在靠向xz（担心等不到） | G22大调，H08大调 |
| **时间感** | 停滞/l 延长——不是不流动（n），是不想流动。nz想把此刻拉长——每一个音符都在说"别结束" | 全体nz案例，尾音拖长 |
| **金矿门槛** | 3/3需要"等待有变化"——不是停在同程度的等待，是等的过程里穿过"会来吗→还没来→但我在等"。只有ハナミズキ做到——"薄紅色の花が咲く頃"回应了"あなたを待つ" | 唯一金矿：G22 |

## xz（临界/漂流）

| 维度 | 特征 | 来源案例 |
|:----|:----|:--------|
| **起手** | 不确定的起手——没有"我是谁"的宣告，没有"开始"的宣言。音从暗处来 | G23弦乐从弱到强的长音，G24铁琴的摇篮曲般进入 |
| **节奏** | 慢速或中速——但不同于n的"停滞"，xz的慢是"一步一回头"的慢——不确定要不要往前走 | 全体xz案例 |
| **音区动态** | 中音区为主，动态起伏明显——但不是z的向上，而是"来回"——在边界上的摆动 | G23回到"I'm not here"的循环 |
| **编曲密度** | 稀疏——xz需要空间来"漂"。密了就撞墙了 | G23只有假声+弦乐断续进入，G24只有铁琴+人声 |
| **人声位置** | 靠前但像在隔着一层玻璃——不是z的"看我"，是"你看到我了吗？" | G23"I'm not here"——听到了但人不在 |
| **和声色彩** | 小调或调性模糊——在边界上的人不需要明确的调性 | G23调性模糊，G24小调 |
| **时间感** | 循环或停滞——xz走不出去，所以时间在原地打转 | G23中间的弦乐让他"被看见"后又回到"I'm not here"——循环 |
| **金矿门槛** | 3/3需要"温柔说重话"（No Surprises）或"消失中确认存在"（How to Disappear）。两者都在边界和存在之间切换，而不是停在边界上 | 金矿：G23, G24 |

## nx（暗算/底牌）

| 维度 | 特征 | 来源案例 |
|:----|:----|:--------|
| **起手** | 冷静的起手——不宣告、不爆发、不叙述。像是在"已经知道答案"的状态下开始说话 | G25冰冷的处理器人声开始，G26bassloop开始 |
| **节奏** | 中速、律动感强——但不同于zx的执行感，nx的节奏是"算好了的节奏"——每一下都在正确的位置 | G25八分钟同节奏，G26五分钟同loop |
| **音区动态** | 中低音区为主，动态平稳——nx不会突然大声，因为它不需要被注意到 | 全体nx案例 |
| **编曲密度** | 适中偏稀——密了就会暴露"我在用力"——nx不费力 | 全体nx案例 |
| **人声位置** | 靠中或略靠后——不是靠后（n的空间），是"在暗处说话"——你能听到但看不清她的脸 | G25处理器声音，G26Gibbons的冷嗓 |
| **和声色彩** | 小调或调性偏暗——nx不需要阳光 | 全体nx案例 |
| **时间感** | 循环或平行——nx不推进，它在结算。结算不需要新信息，只需要算完 | G25八分钟循环，G26五分钟循环 |
| **金矿门槛** | 3/3需要"冷中有理由"——纯冷的nx是可以被替换的态度，但冷+理由（Glory Box的"give me a reason"）就不可替换了 | 金矿：G25, G26 |

## x（欲望/反噬）

| 维度 | 特征 | 来源案例 |
|:----|:----|:--------|
| **起手** | 压迫性或失控性起手——不是"要开始了"，是"已经开始了、压不住了" | H12"買ってくれませんか"(华丽下的压迫)、H13"命に嫌われている"(被存在拒绝) |
| **节奏** | 不稳定或机械推进——欲望本身没有节奏，所以在音乐里x的节奏要么被压缩到极限（机械——Closer），要么完全撕裂 | H12的稳定节奏(包装下的x)、H13的推进 |
| **音区动态** | 中低音区压迫高音区爆发——x是"被压抑→爆发的循环" | 全体x案例 |
| **编曲密度** | 浓密或压迫——x需要具象化的压迫感 | 全体x案例 |
| **人声位置** | 靠前——但不同于z的"看我"，x的靠前是"我在这里——你逃不掉" | H12蔷薇的华丽靠前(优雅的威胁) |
| **和声色彩** | 小调为主或调性扭曲——x不适配大调（大调的光明感会消解x） | 全体x案例 |
| **时间感** | 循环/不解决——欲望没有终点。到了还不够，还想要更多 | x金矿0首——所以这是推测而非案例结论 |
| **金矿门槛** | x **目前0金矿**。三项标准中"克制关系不可替换"最难——x的欲望本身是一种通用能量，很难让听众觉得"这首歌的欲望不能换"。候选方向：工业音乐、极端金属、噪音摇滚中被精密控制的欲望 | 暂无 |

## xn（规则/制度）

| 维度 | 特征 | 来源案例 |
|:----|:----|:--------|
| **起手** | 规则起手——不是爆发、不是叙述、不是空间。是"规则开始了"：重复的音型、固定的节奏 | G29钢琴固定音型, G30合成器读清单 |
| **节奏** | 机械、固定、不变化——规则不需要变化 | 全体xn案例——Glass的八分音符、Carpenter的5/4拍 |
| **音区动态** | 中音区为主，动态极小——规则如果有动态会被认为"规则有情绪" | 全体xn案例 |
| **编曲密度** | 稀疏——规则只需要"够执行"的密度 | G30只有合成器读清单 |
| **人声位置** | 靠前但面无表情——不是"我宣告"（z），是"系统在播报" | G30合成器人声，G25处理器人声 |
| **和声色彩** | 调性明确但不喜欢转调——规则不需要换调 | 全体xn案例——同一调性贯穿 |
| **时间感** | 循环——规则不会自己结束 | 全体xn案例 |
| **金矿门槛** | 纯规则几乎不可能金矿（Metamorphosis 2.5/3，Halloween 2/3）。xn要金矿需要"规则被检验"——Forbidden Colours的xn被nz检验（规则和爱的冲突），Fitter Happier的xn被zn检验（清单和人生的冲突） | 金矿：G29, G30（都有另一个十元") |

## 核心发现

1. **纯十元 vs 复合十元的金矿分布**
   - 纯十元金矿：n(1), z(2), nz(1), xz(2), nx(2), x并z(1), zx(1) — 共10首
   - 复合十元（该十元+"检验与被检验的另一十元"）金矿：zn(4), xn(2), 本体类(14全部复合) — 共20首
   - **结论：需要"被检验"的十元（zn、xn）比不需要的（n、z）更容易金矿**——因为检验本身就是动态链，天然满足"结尾呼应开头"

2. **x（欲望）零金矿不是偶然**
   - x是所有十元中最"没有结构"的——欲望不可被"/检验"（它检验别人）
   - 可能方向：**x搭配另一个十元一起才有可能金矿**（如x+zn = 命に嫌われている 2/3高银——接近了）

3. **三项标准中最根本的是"结尾呼应开头+选择与失去同步"**
   - 有无数的歌满足前两项（克制专精、没有浪费）但卡在第三项
   - 第三项要求：**歌必须走过一段路**——不是原地复述
   - 这也是纯规则（xn、n循环型）最难金矿的原因
