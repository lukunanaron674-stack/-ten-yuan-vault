## 063. 绝命毒师·沃尔特·怀特

**判定：n → x**（从"为家人"的承载者到"因为我擅长这个"的欲望者）

**关键场景：**
1. 制毒是为了家人在他死后有钱——"我是为了家人" → n（他真的是这么想的——绝症后的第一反应是"他们怎么办"）
2. "I am the one who knocks" → n的转折：n变成了借口（家人需要钱→所以我可以控制一切→所以我最大）
3. "I did it for me. I liked it." ——最后一集对斯凯勒坦白 → x（他终于承认了——不是家人，是我想要。欲望在最后承认了它自己）

**互斥排除：**
- 不是zn：他**装**了一整部像是有意义（为家人），但他没有——最后他承认了
- 不是zx：他的行动不是突破，是**一步步被欲望蚕食**
- 不是x（从一开始）：他一开始是n。x是长出来的

**匹配公式？** 是（动态变化）。n→x——库里没有这个直接变化轨迹（艾伦是zx+nx→x，怀特是n→x）。

## 064. 绝命毒师·杰西·平克曼

**判定：z + nz**（追光 + 渴望归属——但他追的全是坏的光点）

**关键场景：**
1. 和怀特制毒——不是因为钱，是因为"我们做的东西好" → z（他想被怀特认可——这是一个坏的光点）
2. 对简、对孩子、对那个他被囚禁的少年 → nz（他一直在找一个"可以停靠的人"——但他停靠的每次都是毒梟的房子）
3. 最后逃出——哭着笑 → nz完成了？不，他在车里笑的不是自由——是"我终于可以不用再找了"

**互斥排除：**
- 不是n：他不是承载者——他是**需要被承载**的人
- 不是x：他不贪婪。他是软弱，不是坏

**匹配公式？** 是。z+nz——柯布相同组合（冲突型）。怀特的nz（"想有归宿"）和柯布的nz（放不下梅尔）一样，都在阻碍z（"想被认可"）。

## 065. 权力的游戏·提利昂·兰尼斯特

**判定：nx + z**（用智力看到所有底牌 + 被血缘亲情牵动的冲动——"我救了你无数次，你还要杀我？"）

**关键场景：**
1. 黑水河之战——用野火和链子打退史坦尼斯 → nx（他算到了每一步——战场是棋局）
2. 审判——"我认罪，因为我是侏儒" → nx的极致（他看穿了——权力不在乎真相，他只做他必须做的）
3. 杀泰温——"她睡我歌女" → z（冲动在那一刻突破了所有nx——被压抑的Z（被爱、被认可、被看见）在那一刻爆炸了）

**互斥排除：**
- 不是xn：他不是建立规则——他是**利用**规则的人
- 不是zn：他不追问意义——他很清楚权力游戏没有意义

**匹配公式？** 是。nx+z=暗算+冲动（和姜仁浩nx+z相同组合）。提利昂的nx是"聪明人的武器"，z是"侏儒的伤口"——nx保护z，z偶尔冲破nx。

## 066. 权力的游戏·琼恩·雪诺

**判定：zn + n**（意义的守护者 + 承载北境——"我的watch永远不结束"）

**关键场景：**
1. 加入守夜人 → zn（不是因为他想当兵——是因为他需要"一个意义"来定义自己这个私生子）
2. 杀耶哥蕊特、联合野人、被守夜人捅死又复活 → n（他承载着"更大的使命"——不管大家怎么对他，他做他认为对的事）
3. 最后杀了丹妮莉丝 → zn（为了保护更大多数——意义做了最艰难的决定）

**互斥排除：**
- 不是zx：他**一直在被推着走**——被杀、被复活、被选为王。他不是主动突破的人
- 不是nz：他没有个人情感上的等待——他的爱（耶哥蕊特）过去了就是过去了

**匹配公式？** 是。zn+n=意义+承载（和安迪相同组合）。安迪的n是"凿子"（工具），琼恩的n是"北境和野人"（责任的重量）。

## 067. 权力的游戏·丹妮莉丝·坦格利安

**判定：zn → x**（从"解放所有奴隶"的意义到"所有人必须臣服"的欲望）

**关键场景：**
1. 奴隶湾——"我是龙之母" → zn（她真的相信"打破锁链"——这是她活着的意义）
2. 弥林——"我生来就是去统治的" → zn开始转x（意义变成了权力的正当化理由）
3. 君临——屠城 → x（她征服了——征服不再是"为了打破锁链"，而是"因为我可以"）

**互斥排除：**
- 不是n：她不是在承载——她是在**解放中统治**。两种姿态都不能简化为"承载"
- 不是xz：她不是漂流——她的方向很清楚，只是方向本身变质了

**匹配公式？** 是（动态变化）。zn→x——和夜神月（xn→x）不同，丹妮是从意义（zn）堕入欲望（x）的。

## 068. 真探·拉斯特·科尔（第一季）

**判定：nx + zn**（看到了底牌——"时间是平的"——然后追问意义）

**关键场景：**
1. "我认为人类意识只是一个错误" → nx（他看到了底牌——存在没有意义，我们只是偶然出现的）
2. 追黄衣王——不是正义，是**结算** → nx（他要清算一个旧账，不是救世界）
3. 医院里——"暗在暗的地方，**光明也赢了**" → zn（他找到了一个极小、极脆弱的意义——在虚无里选择了相信一点点光）

**互斥排除：**
- 不是xn：他不建立系统——他活在社会系统**之外**
- 不是z：他不是追光——他是被黑暗追

**匹配公式？** 是。nx+zn（和助手牧濑红莉栖相同组合，但不同色彩）。牧濑的nx+zn是"科学成就信念"，拉斯特的nx+zn是"虚无中捡起来的信念"。

## 069. 黑镜·圣朱尼佩罗（San Junipero）
