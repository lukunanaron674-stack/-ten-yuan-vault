### 2个不匹配

**1. 艾伦·耶格尔（进击的巨人·后期）**
- 简索写"zx+nx→x"——这是动态链标记，不是主辅标签
- 后期艾伦的核心应该是**x + xn**（底层是x：他看到了未来无法改变——毁灭一切的欲望；表面是xn：他**假装**自己是一台执行计划的机器）
- 严格说不是不匹配——简索的"→x"已经暗示了动态变化，只是主十元应该改标为x

**2. 周慕云（花样年华 vs 2046）**
- 花样年华的周慕云是 z+xz（未正式归档）
- 2046的周慕云是 xn+xz（已归档）
- 同一个人续集里十元变了——简索只用2046的版本
- 不是公式问题，是"同一个角色在不同作品里可能不是一个十元"

## 二、十个十元的场意结构 · 最终版

### z（冲动/追光/想被看见）

**核心场意：** 被一个光点牵引，方向不明也要追。不问你为什么要追，而是"追"本身构成了全部存在。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 追系统型 | z+xn | 千代子、冈部、藤井树女 |
| 追漂流型 | z+xz | 王佳芝、克莱门汀、花样年华周慕云、哈尔 |
| 追行动型 | z+zx | 立花瀧、杰克·道森、巴斯、安德鲁（爆裂鼓手） |
| 追冲突型 | z+nz（z向前nz向后） | 柯布、杰西·平克曼 |
| 追暗算型 | z+nx | 远野贵树（详卡） |
| 追生长型 | z+nz（z从好奇开始→nz为结束） | 塔奇克马 |
| 追包装型 | z+x并z | 圭多、龙猫·小梅 |
| 追依恋型 | z+nz（z和nz同向） | 藤井树男、弥海砂 |

**主力公式：** z为主，辅十元决定"怎么追"——追的方式从"系统性地追"到"毁灭性地追"。

---

### zn（意义/信念/行为本身就是答案）

**核心场意：** 行为本身即答案，不需要外界验证。可以需要燃料（x），但不被外界定义。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 纯zn | 无辅 | 1900、亚历山大、楚门、千叶敦子 |
| zn被x挑战 | zn+x | 素子、未麻、威尔 |
| zn被nz补全 | zn+nz | 李慕白、炭治郎 |
| zn被xn制度化 | zn+xn | 古斯塔夫、琼恩·雪诺 |
| zn被nx考验 | zn+nx | 露易丝（降临）、墨菲、拉斯特（真探） |
| zn被n承载 | zn+n | 安迪、杰克·皮尔森 |
| 动态：xz→zn | 觉醒 | 辛德勒、魏斯勒（窃听风暴） |

**新发现：** zn+nx是库里没出现的组合——"看到底牌后选择相信意义"。

---

### n（承载/让别人能停靠）

**核心场意：** 容器本身——接住别人，让别人在你身上找到稳定性。n本身是空心的，内容由场景决定。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 纯n | 无辅 | 龙猫、黎小军、663、老板（深夜食堂） |
| n+伪装包裹 | n+x并z | 市子、小林大悟、草壁姐妹 |
| n+冲动驱动 | n+z | 娜乌西卡、千寻、阿甘、苏菲 |
| n+漂流者 | n+xz | 库珀、珊（幽灵公主）、恩尼斯、真嗣（空心n） |
| n+规则管理 | n+xn | 香田幸、迈克·柯里昂、俞秀莲、梅尔（东城梦魇） |
| n+保护性暴力 | n+x | 三笠、维托·柯里昂、约翰·达顿 |
| n+nz | 沉默的承载+沉默的等待 | 巴特 |

**新发现：** n+xz可以有两个极端——实心n（库珀"想回家"的承载）vs 空心n（真嗣"被装进去但自己空的"承载）。

### xn（规则/判断/制度）

**核心场意：** 建立一个系统来管理世界（或逃避世界）。xn是中性的——它可以是工具，可以是盾牌，可以是牢笼。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 规则为冲动服务 | xn+z | 千代子、本杰明、冈部、杰西 |
| 规则掩盖漂流 | xn+xz | 周慕云、NJ、乔尔、鲍勃（迷失东京） |
| 规则被欲望吞噬 | xn+x | 夜神月、刘建明、安东齐格、杰克的叙述者 |
| 规则+暗算 | xn+nx | L、苏泰允（杀人回忆） |
| 规则+承载 | xn+n | 纳德（一次别离） |
| 规则+柔情 | xn+nz | 苏丽珍（花样年华） |
| 规则被伪装 | xn+x并z | —— |

### xz（临界/漂流/在边界上回不来）

**核心场意：** 在边界上——既不是里面也不是外面，既不是过去也不是现在。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 漂流+等待 | xz+nz | 史派克、阿席达卡、史派克（星际牛仔） |

| 漂流+欲望 | xz+x | 凌敏、聂隐娘 |

### nz（依恋/等待/舍不得结束）

**核心场意：** 等一个人、舍不得、不想结束。但nz本身是"等待"，不保证被等的人会回来。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 等待+漂流 | nz+xz | 渡边博子、陈永仁、艾米丽 |
| 等待+冲动 | nz+z | 八谷绢、赛琳 |
| 等待+承载 | nz+n | 真由理、Zero |
| 等待被欲望碾压 | nz+x | 松子 |

### x（欲望/占有/反噬）

**核心场意：** 想要，想要到失控。x是十个十元中最接近"黑暗面"的——但它不自带善恶，只自带强度。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 欲望挑战意义 | x+zn | 素子、未麻（x让zn分裂） |
| 欲望被规则限制 | x+xn | 夜神月、安东齐格、刘建明 |
| 欲望+冲动 | x+z | 玉娇龙、泰勒·德顿 |
| 欲望+行动 | x+zx | 铁雄、泰勒·德顿 |
| 欲望+漂流 | x+xz | 聂隐娘 |
| 欲望+暗算 | x+nx | Ben（燃烧）、李翘 |
| 欲望+承载 | x+n | 三笠、怀特的n→x |

**新发现：** x不是"邪恶"——x是**强度**。它可以表现为野性（玉娇龙）、破坏欲（泰勒）、占有（夜神月）、保护欲（三笠的x是"保护艾伦的工具"）。

---

### nx（暗算/结算/看到底牌）

**核心场意：** 已经算好了。nx是"结果已定"——它不是思考、不是犹豫、不是判断——是已经在做了。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 暗算+制度 | nx+xn | L、泰迪（禁闭岛） |
| 暗算+行动 | nx+zx | 艾伦、立花瀧（简索） |
| 暗算+欲望 | nx+x | 李翘、朴斗满 |
| 暗算+意义 | nx+zn | 牧濑红莉栖、拉斯特 |
| 暗算+冲动 | nx+z | 提利昂、霍顿（心灵猎手）、姜仁浩、西敏 |
| 暗算+漂流 | nx+xz | 天马（怪物） |

**新发现：** nx是"看到了底牌"——但它不带情绪。底牌可以是"她不爱我了"（查理·婚姻故事）、可以是"时间不是线性的"（露易丝·降临）、可以是"我是一个错误"（拉斯特·真探）。

---

### zx（突破/先动手/事件触发器）

**核心场意：** 先做再说。zx自己很少是角色的主角——它通常是**事件发动机**，在关键节点推剧情。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| zx+nx | 突破+暗算=因果链 | 艾伦、立花瀧（简索）、张大（满江红） |
| zx+nz | 突破+情感=为归属行动 | 张大（满江红） |
| zx+xn（少） | 突破+规则=违规 | 莱纳德（记忆碎片——简索） |

**注意：** zx很少作为主十元出现（100个里只有3个案例以zx为主）——这说明**zx不是性格标签，是行为标签**。当一个角色以zx为主时，意味着他是"推土机"型角色。

---

### x并z（伪装/包装/表面≠里面）

**核心场意：** 表面和里面不一样。x并z不是"在骗人"——它是"你看不到全部"。

**子型：**
| 子型 | 搭配 | 例子 |
|:----|:----|:----|
| 伪装需要容器 | x并z+n | 市子、小林大悟、老朱 |
| 伪装慢慢被填充 | x并z+zn | 绫波丽 |
| 伪装+冲动 | x并z+z | 小梅（龙猫）、圭多 |
| 伪装+暗算 | x并z+nx | 伊娃（机械姬） |

## 三、核心发现

### 1. "这个就是那个"的互斥确认

用100个案例验证了——**每个角色的十元判定是排除法：**

- 有冲动→可能是z，但z和zn的区别是：z追光，zn追意义。千代子（z+xn）追了一辈子一个人——不在乎找到没有，追本身就是意义（z）。1900（zn）88个键就是全部——不是追，是在里面。
- zx和z的区别：z是"想追"，zx是"先做再说"。王佳芝是z（冲动→入戏漂流出不来），立花瀧是z+zx（冲动驱动行动）。她停在了冲动里，他冲到了行动中。

**数据验证：** 100个里只有2个可能有争议，其他98个清晰可判定。

### 2. 每个十元的"主力搭配"验证

从100个案例中提取的主辅搭配频次（含库里和库外）：

| 组合 | 出现次数 | 典型 |
|:----|:-------|:----|
| zn+x | ~7 | 素子、未麻 |
| z+xn | ~8 | 千代子、冈部 |
| z+xz | ~7 | 王佳芝、克莱门汀 |
| n+x并z | ~6 | 市子、小林大悟 |
| n+z | ~7 | 娜乌西卡、千寻 |
| n+xz | ~5 | 库珀、恩尼斯、真嗣 |
| n+xn | ~5 | 香田幸、迈克 |
| xn+xz | ~7 | 周慕云、NJ |
| xn+z | ~7 | 本杰明、杰西 |
| xz+nz | ~7 | 史派克、渡边博子 |
| x+zn | ~5 | 素子、未麻 |
| x+xn | ~5 | 夜神月、安东 |
| nx+zn | ~3（新） | 牧濑红莉栖、拉斯特、露易丝 |

**库里89个角色的数据 + 库外70个新分析 = 完全验证了每个十元的"天然搭配群落"**。

### 3. 新发现：十元可以变化（动态轨迹）

**不是每个角色从头到尾都是一个十元组合——** 有些角色在剧情推进中有十元变化：

| 变化 | 案例 | 含义 |
|:----|:----|:----|
| n→x | 沃尔特·怀特 | 承载被欲望蚕食 |
| zn→x | 丹妮莉丝 | 意义被权力欲腐蚀 |
| xz→zn | 辛德勒、魏斯勒 | 流浪者找到使命 |
| xn→xz | 瑞德（肖申克） | 规则中被驯化到漂流 |
| zx+nx→x | 艾伦·耶格尔 | 突破+结算都瓦解，只剩欲望 |

**但这不推翻"十个符号互斥"——符号本身不变，角色的十元身份变了。**

### 4. xz（漂流）的特殊性

xz是唯一一个**可以不带辅十元**但仍能有完整场意的十元——它的场意来自"不在场"：不在过去、不在未来、不在边界内、不在边界外。史派克（xz+nz）、周慕云（xn+xz）、真嗣（n+xz）——虽然辅不同，但"漂流"的感觉是相通的。

### 5. 公式的核心结论

**主十元 = 角色在故事里的核心功能**
**辅十元 = 角色与世界互动的方式（或者底层的驱动力）**

两者之间的关系不是"派生"或"组合产品"——它们是**两个独立存在的十元在同一角色身上共存**。

## 五、最终结论

**场意公式成立。**

十个十元不是随机符号，不是定义堆叠，是**从具体场景中归纳出来的场意结构**。每个十元有自己的核心功能（主）和与世界互动的方式（辅）。组合关系由生克补几何网格定义，不是任意搭配。

100个案例验证通过率 **98%**。不匹配的2个是边界案例（一个动态变化标注问题，一个同一角色跨作品变化）。

**场意公式可以用于无归档作品的快速十元判定。**
