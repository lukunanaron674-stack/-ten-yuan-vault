# 场意公式验证方法论

## 核心假设

十个十元不是"定义"出来的，是从具体场景里归纳出来的"场意结构"。
每个十元有自己的核心场意（主角的功能），搭配决定具体色彩。

## 场意公式表（当前）

| 十元 | 核心场意 | 主次关系 | 稳定搭配（数据来自简索） |
|:----|:--------|:---------|:------------------------|
| z | 被光点牵引，方向不明也要追 | z为主，辅决定"怎么追" | z+xn(7) > z+xz(4) |
| zn | 行为本身就是答案 | 纯zn完整，有辅=被挑战 | zn+x(5) |
| n | 接住别人，让别人能停靠 | n是容器，场意由内容定 | n+x并z(6) > n+z(5) |
| xn | 建立系统来管理/逃避世界 | xn是中性框架，辅定方向 | xn+xz(7) = xn+z(7) |
| xz | 在边界上回不来 | xz主体，nz是等待 | xz+nz(7) = xz+xn(7) |
| nz | 等一个人，舍不得结束 | nz主体，xz是漂的对象 | nz+xz(7) |
| x | 想要到失控 | x是燃料，辅定方向 | x+zn(5) = x+xn(5) |
| nx | 已经算好了，看到底牌了 | nx是闭环动作 | nx+xn(3) |
| zx | 先做再说，事件触发器 | zx是动作，很少为主 | zx+nx(2) |
| x并z | 表面≠里面，需要n承载 | x并z需要n做容器 | x并z+n(6) |

## 验证方法

1. 每个作品选1-2个核心角色
2. 先不问"库里怎么说"，直接看具体场景场意
3. 用排除法：不是这个就是那个（互斥）
4. 记录"匹配"或"不匹配"，不匹配时修正公式
5. 100个之后汇总：公式的修正率、误判模式、新发现

## 记录格式

```
作品：xxx
角色：xxx
判定：主+辅
依据：[关键场景1]、[关键场景2]、[关键场景3]
互斥排除：[为什么不是别的]
匹配公式？：是/否（如否，说明偏差）
```
