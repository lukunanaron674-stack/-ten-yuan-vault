# zx 金矿 · 目标/执行型

zx的难点：金矿级的zx需要"执行在变化"——不只是执行一个动作（OST循环），而是执行过程中**被推着走/走歪了/还是走到了**。

## zx-金01. Bloodborne OST — 《Ludwig, the Holy Blade》

- 克制关系不可替换？✅ 管弦乐中段的"回想"——前段野兽般的混乱和后段骑士主题的再现——不可替换。换任何一个编织，路德维希的"想起我是谁"就不存在了
- 无一笔浪费？✅ 前段的嘶吼只出现在前段——后段不重复——因为"想起后就不需要嘶吼了"
- 结尾呼应开头？✅ 开头：你是野兽。结尾：你是猎人。同一个旋律，两种身份。主角的目标在执行过程中被自己重新定义了
- 选择与失去同步？✅ 想起自己是猎人的瞬间——同步失去野兽的自由——不能再乱咬了

**动态链：** xz(临界/兽化) → x(被欲望吞噬) → zn(记起意义) → n(承载——我是猎人) → zn(完成)

**总分：3/3 ✅ 金矿**

- 结尾呼应开头？✅ 开头：单独钢琴。结尾：单独钢琴。中间走过了所有乐器的加入和撤离——执行完成
- 选择与失去同步？✅ 钢琴选择重复——同步失去"停止"的可能——执行最可怕的事是越执行越停不下来

**总分：2/3 ❌ 高银——可替换60%**

## zx-金04. 川井憲次 — 《傀儡謡》

- 克制关系不可替换？✅ 日本古语+机械感节奏——川井憲次的獨創性。但没有第二个人能唱同样的"機械儀式感"
- 无一笔浪费？⚠️ 节奏几乎没有变化——但这不是浪费，是"仪式不需要变化"——zx的执行在这里是"一直执行"
- 结尾呼应开头？⚠️ 结尾的开头和结尾几乎一样——仪式开始、仪式结束时还是同样的节奏——执行没有变化。不是不呼应，是没有发展
- 选择与失去同步？⚠️ 节奏没有变化所以"选择"不明显

**动态链：** zx(执行仪式) → xn(规则/仪式本身) → zx(执行完了——仪式改变了吗？没有)

**总分：1.5/3 ❌ 银矿——zx在这里更像xn（规则执行而非目标执行）**
