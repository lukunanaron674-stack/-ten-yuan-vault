# 证据置信度与对象量级分离协议 v1.0

## 1. 协议目的

本协议解决两类经常被混写的问题：

```text
我们有多大把握判定某对象属于某三元、十元或关系；
该对象中的十元体量、当前显影和关系作用究竟有多大。
```

前者是认识层问题，后者是对象与关系层问题。两者必须分别记录。

## 2. 四个维度不得混写

```text
C：证据置信度，回答“这个判断有多可靠？”
T：体量，回答“该十元在指定对象结构中占多大位置？”
M：显影强度，回答“该十元在当前阶段表现得多明显？”
E：关系作用量，回答“源端点实际改变目标变量多少？”
```

正式红线：

```text
高 C ≠ 高 T
高 C ≠ 高 M
高 C ≠ 高 E
低 C ≠ 低 T
低 M ≠ 低 C
高 M ≠ 高 C
```

## 3. 证据置信度 C 的定义

证据置信度只描述当前判断获得了多少同层、独立、可复核的支持，以及最近邻和反向解释被排除到什么程度。

它不描述：

```text
人物有多强；
十元在人物中占多大；
画面表现有多突出；
关系造成的后果有多大；
主题有多重要。
```

C 必须绑定一个明确命题，例如：

```text
人物稳定本体为 zn；
当前行为功能为 zx；
外部场景在本阶段为 xn；
A 克制 B 的行动路径；
某主题达到次主题等级。
```

不得写脱离命题的“这个角色置信度很高”。

## 4. 置信度等级

延续现行十元校准协议的 A / B / C 门槛，并明确其语义：

### C-A：可正式调用

同时满足：

```text
分析单位与阶段明确；
人物本体、状态、行为、场景、时间结构、光影和关系已经分层；
关键证据属于目标对象与目标层；
拿掉测试通过；
至少一个最近邻被排除；
不存在同等强度的反向解释；
结论不依赖题材词、职业、服装、光影或结局倒推。
```

可进入正式三元、十元、生克补或动态链调用，但仍必须遵守各层自己的启动条件。

### C-B：候选成立

```text
已有较强候选；
但对象层、主副位、最近邻、阶段或反向解释仍有一项未收束。
```

只能进入候选链或待复验记录，不得作为自动补义依据。

### C-C：未形成有效判断

```text
分析单位混杂；
材料不足；
证据主要来自跨层借用；
只能依靠关键词、视觉印象或结局倒推。
```

必须拆小分析单位或保留未判定。

## 5. C 与 T / M / E 的组合规则

允许出现：

```text
C-A + T低：高度确定该十元只是人物稳定本体中的小体量副元。
C-A + M低：高度确定该十元存在，但当前阶段低显影。
C-A + E低：高度确定关系成立，但实际作用很小。
C-B + M高：画面或行为非常明显，但十元点位仍未收束。
C-C + T未判定：材料不足，不能把“不确定”写成“小体量”。
C-A + T高 + M低：稳定核心占位大，但当前阶段暂时退隐。
```

禁止出现：

```text
证据少，所以 T 低；
看得不明显，所以 C 低；
画面很强，所以 C-A；
后果很严重，所以端点一定判对；
关系作用量大，所以人物稳定本体被改写。
```

## 6. 不同对象层分别计算 C

同一人物或同一场景可以同时拥有不同层级的置信度：

```text
人物稳定本体：C-B
当前状态：C-A
关键行为功能：C-A
外部场景：C-A
时间结构：C-B
光影显影：C-A
动态链关系：C-C
```

不得用某一层的 C-A 替其他层补答案。

例如：

```text
监狱场景 xn 为 C-A
≠ 囚犯人物本体 xn 为 C-A

人物某次 zx 行为为 C-A
≠ 人物稳定本体 zx 为 C-A

关系后果清楚为 C-A
≠ 生、克、补方向已经自动达到 C-A
```

## 7. 人物核心锚点规则

人物稳定本体的 C-A 必须依赖跨阶段反复证据，而不是单场高显影。

剧情推进后，优先重新记录：

```text
状态 C / M；
行为功能 C / M；
关系位置 C；
场景和时间压力 C；
动态链关系 C / E。
```

人物核心锚点默认保持。只有存在方式、核心痛苦和反复选择发生持续整体重构，并重新获得本体层 C-A，才允许提出稳定本体改变。

## 8. 三元与十元并行规则

三元与十元必须分别给出置信度：

```text
三元判断 C-A
不自动使十元判断达到 C-A；

十元判断 C-A
不自动使三元比例达到 C-A。
```

两层可以相容、冲突或一层已确认而另一层未判定。发生冲突时返回原始证据，不能把一层写成另一层的父子派生。

## 9. 动态链中的置信度更新

每一阶段重新检查：

```text
端点命题的 C 是否仍成立；
对象层是否变化；
阶段是否变化；
作用机制的 C 是否成立；
目标变量变化的 C 是否成立；
关系方向是否存在反向解释；
T、M、E 是否需要重新估计。
```

前一阶段 C-A 不自动继承到后一阶段。

材料增加后，允许：

```text
C-C → C-B → C-A
C-A → C-B
C-B → 未判定
```

置信度下降不等于对象十元发生变化，只表示当前解释资格下降。

## 10. 标准记录模板

```text
### 判断命题卡

- 分析单位：
- 所属阶段：
- 判断命题：
- 对象：
- 对象层：人物本体 / 状态 / 行为 / 场景 / 时间结构 / 光影 / 关系
- 三元候选与 C：
- 十元候选与 C：
- 同层正证据：
- 同层反证据：
- 最近邻排除：
- 反向解释：
- 置信度：C-A / C-B / C-C / 未判定
- 体量 T：
- 显影强度 M：
- 关系作用量 E：
- 人物核心锚点是否保持：
- 尚缺证据：
```

## 11. 当前冻结结论

```text
证据置信度 C 与体量 T、显影强度 M、关系作用量 E 是不同维度。
不确定不能写成小体量，低显影不能写成低置信，高显影不能写成高置信。
每个置信度必须绑定具体命题、对象层与阶段。
人物本体、状态、行为、场景、时间结构、光影和关系分别计算置信度。
三元与十元分别审核置信度，不构成父子派生。
人物核心锚点优先稳定，置信度变化不自动等于人物本体变化。
```
