# 运行记录｜凯撒越卢比孔：授权内军权越出对象域后，zx 扩权独立成立

## 1｜本轮问题

上一轮马谡街亭已经锁住：

> **违令、压过副将、让部队执行自己的新方案，仍不足以构成 zx。**

因为马谡实际调用的仍是诸葛亮已经交给他的“守街亭主将”局部指挥接口。

本轮寻找真正正向最小差异：

```text
上级 / 制度明确只交付 A 对象域
→ 主体把现实决定权推进到 B
→ 原制度明确反对并试图阻止
→ 主体仍让 B 新接口公开生效
→ 外部系统围绕新事实重排
```

凯撒越卢比孔满足这一结构。

## 2｜事实链

### A｜原授权对象域真实存在

前59年的 lex Vatinia 及后续安排，给凯撒高卢、伊利里库姆等行省的总督与军队指挥权。也就是说：

```text
外部制度授予行省统兵入口
= nx 授权入口

授权完成后
高卢行省军团、将领、军事行动进入凯撒稳定调用范围
= 局部 x
```

这里不能把凯撒的每一次高卢军事行动继续写成 nx；授权以后，该对象域内存在真实 x。

### B｜原制度明确要求终止 / 不允许把同一军权带入意大利

前49年，元老院要求凯撒在指定期限前解散军队；相关古典材料与后世史学概括均把“不解散军队、带军进入意大利”视为与共和国现行政治—军事边界的公开冲突。

卢比孔正是高卢行省军权对象域与意大利政治核心区域之间的象征性 / 实际边界。

### C｜主体公开越过原授权对象域

凯撒没有只在高卢境内继续使用旧军权，也没有按元老院要求解除军团，而是带第十三军团越过卢比孔、进入意大利，并持续向南推进。

因此：

```text
旧 x：高卢等行省军权
↓
原制度要求终止 / 不准带入意大利
↓
凯撒公开把军事实力推进到意大利政治对象域
```

这一步不是“在旧 x 内违令”，而是对象域本身向外推进。

### D｜外部系统被迫重新响应，主体现实决定范围上升

凯撒进入意大利后，庞培、执政官及大量元老撤离；意大利城市与军政节点被凯撒迅速控制。到前49年三月，凯撒已经成为意大利的现实主导者。

因此出现：

```text
原来：凯撒稳定处分的是行省军权
后来：凯撒的军事实力直接决定意大利核心政治空间
→ 原共和国节点撤离 / 重排
→ 主体现实影响与决定范围上升
```

`zx_beyond_delegated_boundary: evidence-locked`

## 3｜分层判断

### nx：原授权入口成立

凯撒的高卢总督 / 统兵权不是单凭私人意志自行生成，它首先经罗马既有政治—法律机制授予。

所以：

`nx_prior_constitutional_command_entry: evidence-locked`

但这里只锁“原军权如何合法进入凯撒手里”的授权入口，不锁凯撒稳定人物本体为 nx。

### x：原行省军权成立

授权完成后，军团与高卢等行省军事事务进入凯撒稳定调用边界。

`x_delegated_gallic_command_boundary: evidence-locked`

### 当前越卢比孔执行层：nx 排除为主判

在元老院已经要求解散军队的冲突窗口，凯撒没有沿外部解除军权方向继续，也没有等待新的许可再进入意大利。

`nx_in_rubicon_execution_window: rejected_as_primary`

### zx：成立

本例通过 zx 四道硬门：

1. **主体自己的新方向明确**：不接受解除军权，主动把军事实力推进意大利；
2. **权能公开进入现实**：不是秘密操纵，而是军团公开越界、占领节点；
3. **外部体系真实响应**：庞培、执政官和大批元老撤离，政治军事结构围绕凯撒推进重新行动；
4. **决定范围扩大**：从行省军权跃迁到意大利核心政治空间的现实主导。

因此：

`zx_beyond_delegated_boundary: evidence-locked`

## 4｜关键压力

压力不是“凯撒野心大”或“他赢了内战”。

真正压力变量是：

```text
原授权边界可被清楚识别
+
原制度明确要求停止旧军权
+
主体把旧权能带入原授权之外的新对象域
+
原制度节点确实试图抵抗 / 撤离
+
新对象域最终被主体实际控制
```

这正是马谡案例缺失的部分。

## 5｜拿掉测试

### 拿掉“越过卢比孔进入意大利”

如果凯撒只是留在高卢拒绝解散军团，仍然属于旧 x 与上级冲突问题，zx 是否成立会显著下降。

→ **进入新对象域是本例 zx 的支柱。**

### 拿掉庞培、执政官、元老撤离与意大利控制结果

如果凯撒越界后立刻被制止、军团解散、意大利政治结构没有围绕他重排，则只能证明越界尝试，不能高置信锁“决定范围真实上升”。

→ **外部现实响应与新边界落地是 zx 第四门。**

### 拿掉原高卢正式授权

如果凯撒从来没有一块可识别的授权 x，就不能承担“授权后越界”的最小差异控制，只能作为普通夺权 / 侵入案例重新判。

## 6｜反向测试

### 反向成马谡型：违令但仍在旧 x 内

```text
凯撒仍只在高卢境内统兵
→ 拒绝某个元老院运行指令
→ 但没有把军权推进意大利
= 可为 x / xn / 违令，zx 不自动成立
```

### 反向成真正 zx

原文本实际发生：

```text
行省军权 A
→ 制度要求终止
→ 主体公开把军权推进意大利 B
→ 原政治军事节点撤离 / 重排
→ B 进入主体实际决定范围
= zx
```

## 7｜最近邻排除

### zx vs x

`x` 是在已经拥有的高卢军权范围内正常 / 强势调用；本例的关键是军权对象域从高卢推进到意大利核心政治空间，因此超过原基线。

### zx vs xn

凯撒进入意大利后的行军、占城、兵力调度当然有 xn 组织邻近，但“运行怎么组织”不能替代本轮更核心的“决定范围从 A 推到 B”。

### zx vs nx

原军权入口可有 nx；但越卢比孔时凯撒恰恰停止沿元老院的解除军权方向推进，并把自身军事实力直接压入新对象域。

### zx vs 单纯违法 / 违令

违法、违令本身不是 zx。若没有新对象域真实控制与外部结构重排，仍不能成立。

## 8｜第三因素冻结

冻结：凯撒人格评价、共和国合法性争议、庞培能力、内战道德、凯撒最后是否独裁、后世“越过卢比孔”象征意义。

只保留：

- 原授权对象域；
- 外部制度是否明确反对 / 要求终止；
- 主体是否公开进入新对象域；
- 新对象域是否真实进入主体影响 / 决定范围；
- 外部系统是否被迫重排。

结论仍为 99/98。

## 9｜与马谡街亭的最小差异

| 检查项 | 马谡街亭 | 凯撒越卢比孔 |
|---|---|---|
| 原授权 x | 守街亭现场主将 | 高卢等行省军权 |
| 是否违背上级 | 是 | 是 |
| 是否重写运行方法 | 是 | 是/有 |
| 是否进入原授权外新对象域 | 否 | **是：意大利** |
| 新对象域是否真实生效 | 否 | **是** |
| 外部系统是否围绕新增接口重排 | 否 | **是** |
| zx | 排除 | **成立** |

所以本轮新增的高纯案例级纪律是：

> **授权后越界要锁 zx，不能只看“违令”或“方案自己定”，而要看到决定权真正进入原授权之外的新对象域，并在外部反对下仍形成现实有效的新边界。**

## 10｜结论

本轮正式结论：

> **凯撒越卢比孔是“外部授权入口 nx → 行省局部 x → 越授权对象域后 zx 高显影”的高纯正向控制。**
>
> **真正区分马谡型 x/xn 与 zx 的，不是服不服从，而是决定范围有没有从已授权 A 真正推进到未授权 B，并迫使现实秩序围绕新增边界重排。**

不修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡；目前这是“授权后越界扩权”第一份高纯正向控制，不建立新待审议。
