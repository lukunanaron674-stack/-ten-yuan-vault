# 杨志 vs 诸葛亮｜纸面权限对现实生效权的双向最小差异

## 1｜本轮问题

只看名义结构，会得到两个相反但都危险的误判：

```text
杨志：梁中书明文授权住歇听其提调
→ 看起来已经是稳定局部 x

诸葛亮：刘禅仍是皇帝，诸葛亮仍是臣
→ 看起来日常政务仍须沿皇帝权限，像 nx
```

本轮直接冻结身份、官名与道德评价，只问同一个现实问题：

> 冲突发生时，谁能在结果生效以前真正说“不”，并迫使另一方重配、等待或让渡？

结论：十元权限层应优先追踪现实生效权，而不是纸面箭头。

## 2｜事实 A：杨志——名义 x，但现实稳定 x 不足

《水浒传》第16回出发前，梁中书明确把一路早行晚行、住歇提调权交给杨志。纸面结构支持局部 x 候选。

但黄泥冈冲突时：

```text
杨志：不能停
谢都管：要停
众军健实际停下
杨志“无可奈何”
```

因此“是否停歇”这个微对象上：

- 名义授权存在；
- 杨志却不能稳定让自己的决定生效；
- 谢都管的既有身份/关系权重可以真实覆盖结果；
- 当前关系位置出现局部 nx 显影。

锁：

`yang_zhi_nominal_x_but_real_external_veto: evidence-locked`

## 3｜事实 B：诸葛亮——名义 nx，但现实外部否决不足

建兴元年刘禅即位后，诸葛亮开府治事、领益州牧。《三国志》《资治通鉴》均记“政事无巨细，咸决于亮”。

纸面结构仍有皇帝刘禅在上，但日常政务对象层的现实结构是：

```text
名义最高者：刘禅
实际日常政务裁决：诸葛亮
史料直接记“咸决于亮”
```

没有高质量证据显示每项关键日常政务都必须先回刘禅并接受其真实事前否决；相反，现实处分稳定落在诸葛亮一侧。

因此该对象层：

- 名义上级存在；
- 但不能仅凭君臣层级锁 nx；
- 优先检查实际 x。

锁：

`zhuge_liang_nominal_nx_but_real_external_veto_absent: evidence-locked`

## 4｜双向最小差异

两例真正形成镜像：

```text
杨志：
纸面上“归我管”
+
冲突时别人能压住我的决定
=
稳定 x 下降，局部 nx 上升

诸葛亮：
纸面上“我上面还有人”
+
现实事务长期由我直接裁决
=
名义 nx 下降，实际 x 上升
```

所以：

> 名义授权不能自动生成 x；名义上级也不能自动生成 nx。

真正关键的是：

> 决定生效以前，谁拥有现实可使用的否决/覆盖能力？

## 5｜zx 判断

两例本轮都不额外锁 zx。

### 杨志

没有扩大决定范围，冲突中反而无法维持既有决定。

### 诸葛亮

能锁的是建兴元年日常政务实际 x；是否从此前权限边界进一步扩为 zx，需要单独比较授权前后与新增范围，本轮不偷锁。

因此：

`zx_from_authority_magnitude_or_conflict: rejected_as_inference`

## 6｜nx 判断

本轮对 nx 的最窄纪律不是“有人比你官大”，而是：

```text
外部节点当前是否真的能说“不”？
这个“不”是否发生在结果生效以前？
主体说了算以后，外部节点还能不能压回？
主体是否必须重配、等待、让渡或换通道？
```

杨志：是，局部 nx 显影。

诸葛亮：在日常政务对象层，没有足够证据支持这种外部实质否决，优先 x。

## 7｜拿掉测试

### 拿掉名义头衔

只保留现实冲突结果：

- 杨志决定被覆盖；
- 诸葛亮日常政务稳定自行裁决。

分类仍不变。

说明名义头衔不是支柱。

### 拿掉现实生效差异

若杨志的“不停”最终仍强制生效，则局部 x 上升、nx 下降。

若诸葛亮关键政务必须逐项奏刘禅，刘禅可真实拒绝并迫使重配，则 nx 上升、x 下降。

说明现实可否决性才是支柱。

## 8｜反向测试

```text
纸面授权给主体
+
外部节点反对也不能阻止
→ 更接近 x

纸面授权给主体
+
外部节点反对能直接改结果
→ x 稳定性下降，查 nx

纸面上级存在
+
上级能事前否决并迫使主体重配
→ nx 增强

纸面上级存在
+
现实长期由主体直接裁决
→ nx 下降，查 x
```

## 9｜最近邻排除

### nx vs x

核心不是“名义归谁”，而是当前现实生效权归谁。

### nx vs xn

杨志前置运输路线设计属于 xn；诸葛亮约官职、修法制也有 xn 邻近。xn 回答“怎么组织运行”，不回答“谁能最终说不”。

### x vs zx

实际拥有权限是 x；把权限范围继续推出旧边界才重新检查 zx。权很大不等于正在扩权。

## 10｜第三因素冻结

冻结：

- 杨志暴躁、谢都管身份评价、生辰纲最后被劫、酷热；
- 刘禅年龄、诸葛亮忠奸评价、托孤道德叙事、后续北伐；
- 官名、爵位、英雄/权臣标签。

只保留：

```text
谁的决定实际生效？
谁能在生效前真实否决？
被否决后谁必须让渡/重配？
```

结论保持事实99 / 分类98。
