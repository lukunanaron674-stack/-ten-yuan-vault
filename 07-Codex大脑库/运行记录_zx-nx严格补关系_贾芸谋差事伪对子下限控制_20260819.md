# 《红楼梦》贾芸谋差事｜zx↔nx 严格补关系伪对子下限控制

## 0｜结论

本轮不重复创建贾芸角色案例，复用既有 99/98 `evidence-locked` 案例，新增一个严格 `zx↔nx` 补关系的负控制。

结论：

```text
贾芸有明确目标
+ 会筹钱、送礼、换权限节点
+ 最终求人成功
≠
严格 zx+nx 补关系
```

本段高纯成立的是 `nx` 权限关系功能；`xn` 解释其筹资、换节点、选择接近方式等策略组织。`zx` 独立端没有达到准度卡要求，因此双向补缺测试在 zx 端直接失败。

## 1｜剧情事实

### 触发
贾芸想在荣府谋得一个园内工程差事，以取得收入和立足机会。

### 对象
- 贾芸：目标主体、求人和后续执行者。
- 贾琏：第一个外部权限节点，未能办成。
- 王熙凤：真正能把园内种花木工程派给贾芸的权限节点。
- 倪二：短期资金来源，用于贾芸购买冰片、麝香等礼物。

### 明确动作
1. 贾芸先求贾琏谋差，未成。
2. 贾芸借倪二银子，购买香料，主动改变接近方式。
3. 贾芸转向凤姐，送礼、奉承并明确请求派差。
4. 凤姐真实掌握园内工程派差接口，并最终同意把种花木工程交给贾芸。
5. 贾芸随后领票、领对牌、到银库领二百两，再采购花木进入执行。

### 结果
贾芸成功取得差事，但派差权限从始至终没有转移到贾芸本人；成功来自他识别并进入有效外部权限接口。

## 2｜nx 证据

`nx` 成立在权限关系层：

```text
我要谋差事：贾芸自己决定
谁能把差事合法派给我：在外部
贾琏节点失败
→ 转接凤姐节点
→ 凤姐批准
→ 领票、对牌、银库流程落地
```

因此：

`nx_relation_function_stage: evidence-locked`

这不是纯 nx 本体。贾芸自己的谋生目标非常清楚，也会积极寻找有效路径。

## 3｜为什么 zx 不成立

贾芸很主动，甚至可以说相当会办事，但 `zx_准度卡_v0.1` 要求的是：

1. 主体自身力量或决定接口明确；
2. 权能公开进入现实；
3. 他者/秩序围绕其力量重新反应；
4. 主体决定范围、影响位置或凌驾程度上升。

本段缺少第4项的硬证据：

- 贾芸没有取得园内工程派差权；
- 没有获得可以自行给自己或别人分工程的接口；
- 荣府工程秩序没有开始围绕一个新增的“贾芸决定节点”运行；
- 凤姐批准后，他只是执行已获授权的工程。

因此：

`zx_independent_endpoint: rejected`

主动、会求人、会送礼、会换节点、最后成功，都不是 zx 的替代判据。

## 4｜严格补关系双向拿掉测试

### 4.1 拿掉 nx 端

拿掉凤姐及所有等价的外部派差权限节点：

- 贾芸仍然有“我要谋差事”的目标；
- 也仍可能有筹钱、送礼、观察关系节点的策略能力；
- 但不能因此说 zx 端仍独立成立，因为这些只证明目标与行动主动性，不能证明公开扩权或决定范围上升。

这里留下的是“缺权限”的现实问题，但**留下缺口并不足以反向制造 zx**。

所以严格补卡要求的“拿掉 nx 后，zx 仍独立成立但出现可命名缺口”没有通过。

### 4.2 补回 nx 端

凤姐接口补回后，贾芸确实取得了差事。这说明 nx 对任务成功有真实作用，但只证明“外部权限通道有效”，不证明它是在补一个已经独立成立的 zx 端。

### 4.3 拿掉所谓 zx 端

如果把贾芸的“主动性、会筹划、会奉承、会换节点”全部拿掉，只保留“他想谋差并通过凤姐批准取得差事”，nx 关系功能仍然可以成立。

也就是说，所谓 zx 端不是 nx 成立的结构必要项。

### 4.4 补回所谓 zx 端

把主动筹钱、送礼、换节点加回来，只会增强 `xn` 的策略组织和人物主动程度，并不会自动产生 zx 的扩权硬证据。

结论：

```text
双向拿掉失败
→ strict_zx_nx_complement_locked: false
```

## 5｜为什么这是“伪对子”而不是普通 nx 案例的重复

表面上它很容易被误读成：

```text
主体很主动（像 zx）
+
中途求人（像 nx）
+
最后成功
=
zx+nx 补关系
```

但正本要求的是：**两端分别独立成立，再检查彼此是否补缺。**

本例中：

- `nx` 独立成立；
- `zx` 只存在“主动”外观，不满足扩权门槛；
- 因而补关系在第一步“两端独立成立”就失败。

本轮新增价值是为 `zx补nx_补卡` 提供一个高纯下限控制：

> **“自主目标 + 主动求人 + 成功”不是严格补关系。**

## 6｜最近邻排除

### nx vs xn
贾芸借钱、买香料、调整求人对象和接近方式，都有 `xn` 邻近。`xn` 回答“怎样组织求人过程”；`nx` 回答“为什么最终必须经过凤姐的派差权限”。

### nx vs x
凤姐的派差权、领票/对牌和银库权限都不归贾芸，所以不是 `x`。

### zx vs xn
“会筹划、会换节点”优先说明 `xn`，不能代替 zx 的公开显权和决定范围扩大。

### zx vs x
取得工程以后，贾芸对获批范围内的采购、施工可能出现局部 `x/xn`，但这不能倒推此前发生了 zx 扩权。

## 7｜关键压力

关键压力是贾芸缺少可以自行处分的荣府工程准入/派差权限。

这个压力使 `nx` 外部权限关系功能显影；它没有把贾芸自动推成 zx，也没有生成严格补关系。

## 8｜反向测试

### 真 zx+nx 版本
若贾芸原本已经以自身权能公开建立一个新的工程承包/管理决定范围，随后因某项外部许可、资金或准入接口缺失而必须借凤姐补入，补回后又继续以自己的新增决定权公开推进，才可能进入严格 `zx+nx`。

### 纯 nx 版本
若贾芸连“我要谋差事”也不主动形成，只等凤姐随意安排，则更接近纯 nx 行为/本体候选。

### xn 主位版本
若派差权限已经到手，真正难点变成采购、预算、工期、人员、节点组织，应转查 `xn`。

## 9｜第三因素冻结

以下全部冻结，不参与主判：

- 贾芸贫穷；
- 倪二仗义；
- 贾芸会奉承；
- 凤姐喜欢听好话；
- 送礼是否道德；
- 后来工程是否赚钱；
- 贾芸与小红后续关系；
- 贾芸是否“聪明能干”。

冻结后仍保留：

```text
关键派差权在外部
→ 贾芸通过关系节点取得
→ nx成立

但没有新增决定范围
→ zx不成立
→ 严格补关系失败
```

## 10｜对象层结论

- 稳定人物本体：不锁。
- 当前目标：贾芸自主形成“谋差事”。
- `nx` 关系功能：高显影，正式锁定。
- `xn` 行为邻近：筹资、送礼、换节点、接近策略。
- `zx`：独立端排除。
- `x`：仅在获批后的具体工程执行范围内可能出现邻近，不倒灌。
- 严格 `zx↔nx` 补关系：排除。

## 11｜与真补关系的最小差异

对照现有曹操陈留借资、宋江高唐州请公孙胜：

```text
真补关系：
zx端先独立成立
→ 出现可命名缺口
→ nx补入
→ zx重新把外部条件兑现成公开扩张

贾芸：
只有主动目标/策略
→ nx权限通道成立
→ 取得差事
但没有独立zx端
```

所以：

> **严格补关系首先要过“两端独立成立”，再谈补缺；不能把“主动性”当成 zx，占一个名额就算对子。**

## 12｜版本纪律

本轮不修改 L1、zx/nx 信息卡、两张准度卡或 `zx补nx_补卡`。该结果只是对已锁红线“求人一次、普通协作不足”的材料级下限控制，不构成新的理论边界问题。
