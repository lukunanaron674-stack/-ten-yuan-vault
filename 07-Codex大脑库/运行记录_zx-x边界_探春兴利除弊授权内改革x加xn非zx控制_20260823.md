# 运行记录｜探春兴利除弊：授权内改革的 x + xn 与伪 zx 控制

## 0｜本轮问题

当前 `zx↔x` 研究已经确认：

- 已有权限成功调用，不等于 zx；
- 主体已有 x 也不妨碍后来在新对象域或同域更高处分范围出现 zx；
- 下一步需寻找“同一对象域 A1→A2”的扩权阈值。

本轮用《红楼梦》第55—56回探春暂代理家务并实行大观园改革做反向压力测试：

> 在同一荣府家务管理域内，主体把制度和运行方法改得很深，是否就足以证明决定范围从 A1 扩到 A2？

结论：**不足。** 本段高纯成立的是 `nx授权入口 → 局部x → xn重建流程`；缺少“原本明确不属于探春的 A2 权限后来稳定转归探春”的硬证据，因此 `zx` 在本窄阶段排除为主判。

## 1｜剧情事实

### 1.1 授权入口

第55回凤姐病后不能理事，王夫人先令李纨协理家中琐事，随后又命探春与李纨共同裁处；文本还明确说明只是暂代，待凤姐恢复仍交还原职。

这说明探春不是自行宣布取得荣府管理权，而是通过王夫人的真实委派进入该管理对象域。

因此：

```text
外部真实委派
→ 探春接受并开始办事
= nx 授权入口
```

### 1.2 授权后的局部 x

进入临时管理岗位后，探春与李纨实际处理家中日常事务，设固定办事地点，接收回话并作出裁处。

因此在已交付的“家中琐碎事务/园中管理”对象层，探春已经形成可以直接调用的局部管理边界：

```text
委派完成
→ 日常裁处可直接生效
= 局部 x
```

### 1.3 第56回制度改革

探春进一步发现重复支出和园中资源浪费，提出削减重复头油脂粉支出，并借鉴赖大家花园经营经验，把园内花木、稻田等交给熟悉各项事务的婆子分区管理；管理者可取得一部分收益，同时承担维护责任，从而减少花匠、扫园等额外支出。

这明显改变了：

- 资源使用方式；
- 人员责任分配；
- 收益与激励；
- 园中维护流程；
- 支出结构。

因此运行方法层 `xn` 高显影。

## 2｜zx 判断

### 2.1 为什么不能因为“改革很大”就锁 zx

现行 zx 要求的不是：

> 我把制度改得更聪明、更有效。

而是：

> 我把自己的现实决定范围推进到此前不属于自己的位置，并让外部秩序围绕这个新增边界重新运行。

本段没有看到足够硬的 A1→A2 权限扩张证据。

王夫人已经把“家中琐碎事务”“合同李纨裁处”这一管理对象域交给探春。第56回的节支、承包、责任重配，都仍然发生在这块已经交付的园内/家务管理域里。

所以：

```text
已有 A1：暂代理家务/园中管理
→ 在 A1 内重新设计制度和运行方法
→ 结果被执行
= x + xn

并不能自动推出：
→ 新增 A2 权限
= zx
```

### 2.2 本轮未见的 zx 硬证据

若要锁同域 A1→A2 zx，至少应进一步看到：

1. A2 原本明确保留给王夫人/凤姐/另一权限节点；
2. 探春此前无权处分 A2；
3. 原节点真实反对或拒绝探春进入 A2；
4. 探春仍公开推进 A2；
5. A2 最终稳定进入探春处分范围。

第55—56回没有把这五点锁到 ≥95%。

因此：

`zx_from_reform_inside_delegated_domain: rejected_as_primary`

## 3｜nx 判断

### 3.1 授权入口 nx 成立

探春进入临时家务管理，不是自己夺取，而是王夫人明确命她与李纨共同裁处。

所以：

`nx_delegation_entry_relation: evidence-locked`

### 3.2 授权后不能永久 nx

但王夫人授权完成以后，探春对已经交付的日常家务并非逐项等待王夫人批准。

因此不能写成：

```text
王夫人是上级
→ 探春以后每项改革都自动 nx
```

更准确是：

```text
权限如何进入：nx
权限进入后谁可直接调用：x
运行结构怎样重搭：xn
是否超过当前权限基线：再查 zx
```

## 4｜xn 最近邻

探春第56回真正高显影的是运行重构：

- 识别重复支出；
- 取消冗余供应；
- 按园中资源类别分派责任；
- 把维护、收益、激励绑定；
- 用局部收益补整体支出；
- 改变原来“只支出、不负责”的流程。

这属于典型“节点、人员、资源、责任和收益关系重排”。

因此：

`xn_policy_and_process_rebuild: evidence-locked`

但 `xn` 不能反向冒充 `zx`。

## 5｜关键压力

压力来自：

- 凤姐病中暂不能理事；
- 荣府日常支出重复；
- 大观园资源长期低效使用；
- 婆子、买办、管理流程存在宿弊。

这些压力逼出探春的改革能力，但不能直接判十元。

## 6｜拿掉测试

### 6.1 拿掉王夫人委派

如果探春没有被授权管理家务，却自行宣布可以处分园中支出、人员和资源，而且原权力节点反对后仍无法压回，那么 zx 置信会显著上升。

本案并非如此。

### 6.2 拿掉改革创新

若探春只按原规则处理日常回话，仍然可以锁：

```text
nx 授权入口
→ x 日常调用
```

但 `xn` 会明显下降。

### 6.3 拿掉任何 A2 新权限证据

本段仍能完整解释为：

```text
授权进入
→ 既有管理 x
→ 改流程 xn
```

说明 zx 不是解释本段事实所必需。

## 7｜反向测试

真正同域 zx 应长成：

```text
A1：探春只获日常家务裁处
↓
A2：某类重大财权/人事权明确保留给王夫人或凤姐
↓
探春公开进入 A2
↓
原节点真实拒绝
↓
拒绝仍无法压回
↓
A2 以后稳定由探春处分
= 同域 A1→A2 zx
```

而本例是：

```text
A1：临时家务/园中管理已经授权
↓
探春在 A1 内重构制度与运行方式
= x + xn
≠ zx
```

## 8｜最近邻排除

### x vs zx

- `x`：当前管理对象域已经属于探春可直接调用；
- `zx`：必须证明决定范围超过当前授权上限。

### xn vs zx

- `xn`：制度、人员、资源、激励怎样重新组织；
- `zx`：谁新增取得了什么决定权。

改革越聪明，不等于权限越大。

### nx vs x

- `nx`：王夫人把权限交给探春的入口；
- `x`：交付以后，探春对日常家务可直接裁处。

### 稳定本体 vs 当前状态

本轮只锁当前阶段功能，不推：

> 探春稳定人物本体 = x / xn / nx。

## 9｜第三因素冻结

冻结：

- 探春精明能干；
- 凤姐身体状况；
- 贾府经济衰败主题；
- 宝钗是否赞成；
- 改革是否“现代”；
- 后续是否长期成功。

只问：

1. 权限入口来自谁？
2. 授权后哪些对象已经归探春直接裁处？
3. 第56回改变的是“运行方法”还是“决定范围”？
4. 是否出现明确未授权 A2 被探春稳定取得？

答案支持 99/97：`nx入口 + x + xn，非zx主判`。

## 10｜本轮结论

最窄可靠结论：

> **同一管理对象域内，主体把制度改得更深、更复杂、更有效，若仍处于已经交付的权限边界内，优先解释为 `x + xn`，不能仅凭“改革/改旧规/结果显著”锁 `zx`。**

这为后续寻找真正的“同域 A1→A2 zx”提供反向控制：

> 真 zx 必须证明的不是“方法更大胆”，而是“决定范围真的超过旧上限”。

当前不修改 L1、zx/nx 信息卡、zx/nx 准度卡或 zx补nx_补卡。
