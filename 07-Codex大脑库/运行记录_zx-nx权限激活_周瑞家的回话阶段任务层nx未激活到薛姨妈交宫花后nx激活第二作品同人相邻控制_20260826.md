# 《红楼梦》周瑞家的｜回话结束到送宫花：nx off→on 同人相邻最小差异

## 0｜结论先行

本轮不重复制造“周瑞家的送宫花 = nx”这一旧结论，而是把同一场景切成相邻两个窗口，只改变“当前外部任务是否进入行动链”。

```text
窗口A｜宫花任务尚未出现
周瑞家的长期处于贾府关系/职位网络
+ 来梨香院是为了完成此前回王夫人话的事项
+ 回话结束后“方欲退出”
→ 宫花这个被测任务层尚无外部方向进入行动链
→ 宫花任务层 nx = off

窗口B｜薛姨妈临时交付宫花
“你且站住”
→ 明确给出十二枝花、对象与数量
→ 周瑞家的接匣、逐处送达
→ 当前宫花任务层真实沿外部既定方向续接
→ 宫花任务层 nx = on
```

因此第二份独立作品的同人相邻开关控制成立：

> **长期关系/组织位置存在，不等于某个当前任务层 nx 永久在线；明确任务进入行动链并被主体真实承接，才激活该任务层 nx。**

与《西游记》孙悟空“齐天大圣空衔 → 权管蟠桃园”机制同型，但作品、人物、组织结构不同。

## 1｜剧情事实、触发、对象、动作、结果

### 窗口A｜任务前

- 周瑞家的送走刘姥姥后，来找王夫人回话。
- 王夫人当时在薛姨妈处，周瑞家的转到梨香院。
- 她进入后先与宝钗交谈，随后王夫人问话，她趁便把刘姥姥之事回明。
- 回话完成、王夫人无进一步指令后，周瑞家的“方欲退出”。

此时周瑞家的与王夫人、薛姨妈、贾府的长期关系网络都真实存在，但“送宫花”任务尚未出现。

### 窗口B｜任务进入

- 薛姨妈临时叫住周瑞家的，取出十二枝宫花。
- 薛姨妈明确给出分配结构：三位姑娘各一对、黛玉两枝、凤姐四枝。
- 周瑞家的接过花匣，按这一既定对象与数量逐处送达。
- 她可顺路决定先去哪一处，但未重写核心对象、数量与任务终点。

触发：薛姨妈临时想起宫花，明确交付送花差事。
对象：十二枝宫花及其既定受赠对象。
明确动作：接匣、逐处送花、说明缘故。
结果：宫花任务按外部给定方向完成。

## 2｜nx 判断

### 窗口A｜宫花任务层 nx 不激活

这里不是说周瑞家的整体“非 nx”，而是严格限定到尚未出现的宫花任务层。

```text
组织关系存在 = true
宫花任务方向存在 = false
主体沿宫花任务推进 = false
→ 宫花任务层 nx 不激活
```

她此前“回王夫人话”属于另一个任务对象层，不能因为上一项差事是外部任务，就把下一项尚未出现的宫花任务提前挂上 nx。

### 窗口B｜宫花任务层 nx 激活

```text
任务方向由薛姨妈给出
+ 对象与数量由薛姨妈给出
+ 周瑞家的真实接匣并持续执行
+ 没有抢最终重设位置
→ nx 行为/关系功能成立
```

本轮锁的是当前任务功能，不推周瑞家的稳定人物本体。

## 3｜zx 判断

本轮两个窗口都不新增 zx。

- 任务前长期身处贾府关系网，不是 zx。
- 任务后把差事办完，也不是 zx。
- 顺路选择、熟悉房舍、能说会办，没有形成新增公开决定范围。

因此：

`zx_in_tested_delivery_transition: rejected_as_primary`

## 4｜nx vs xn 最近邻

周瑞家的在送花过程中有顺路选择和局部执行自由，但关键运行骨架并未由她重新设计：

- 是否送：外部给定；
- 送给谁：外部给定；
- 数量：外部给定；
- 最终任务：把这些花送到指定对象。

因此局部路径自由不足以独立锁 xn。

若薛姨妈只说“这些花你看着办”，由周瑞家的自行定义对象、数量、规则、节点，则 xn/x 才明显上升。

## 5｜拿掉测试

### 拿掉长期组织身份

假设执行者不是王夫人陪房，只要薛姨妈仍明确给出任务、对象和数量，执行者真实承接并沿该通道送达，窗口B的 nx 行为功能仍可成立。

说明“身份长期存在”不是分类支柱。

### 拿掉宫花任务进入

保留周瑞家的长期贾府关系、熟悉房舍、人情网络，但薛姨妈不叫住、不交花、不下任务：

→ 宫花任务层 nx 不成立。

这正是本轮最小差异。

### 拿掉主体承接

即使薛姨妈提出任务，但周瑞家的拒绝、不接匣、不沿安排送达：

→ 只能证明外部任务存在，不能证明当前 nx 已激活。

## 6｜反向测试

### 反向成更纯 nx

薛姨妈不仅给对象和数量，还逐项规定顺序、时间和每个节点；周瑞家的机械照办。

### 反向成 xn

薛姨妈只给抽象目标“把花分送出去”，周瑞家的自行设计受赠对象、数量、顺序和规则。

### 反向成 zx

周瑞家的原本没有宫花分配处分权，却公开夺取并扩大这块决定范围，使薛姨妈和贾府成员以后围绕她的新分配接口运行。

原文均不支持。

## 7｜第三因素冻结

冻结：

- 周瑞家的性格、阶层、年龄；
- 她是否圆滑势利；
- 与宝钗的闲谈；
- 黛玉后续不满；
- 宫花审美/象征；
- 周瑞女婿官司；
- 贾府整体等级制度。

只保留：

```text
同一人物
+ 长期关系/组织位置基本不变
+ 当前任务是否存在
+ 当前任务是否真实进入行动链
+ 主体是否承接并续接
```

结论不变。

## 8｜与《西游记》孙悟空相邻控制对照

```text
《西游记》孙悟空
齐天大圣空衔：体系/名位存在，但无当前任务 → nx off
权管蟠桃园：明确任务进入并承接 → nx on

《红楼梦》周瑞家的
回话完成欲退出：贾府关系存在，但宫花任务尚未出现 → nx off
薛姨妈临时交花：明确任务进入并承接 → nx on
```

两案共同冻结了一个常见误判：

> **关系位置 / 身份 / 组织网络长期存在，不等于当前每个任务对象层的 nx 自动在线。**

当前已形成 2 部独立作品的同人相邻 `nx off→on` 控制；尚未达到“同一新边界跨3作品”单独升级门槛，因此只记 `evidence-locked`，不新建新的正本规则，也不修改核心定义。
