# 漫画作品驱动的十元生克补与五主生克分析协议 v0.1

> 本页是案例实作协议，不改写官方理论。主任务是借作品观察十元生克补与五主生克；`is-a` 素材库和故事生成器是第二用途。

判断与落库遵守 [[高置信结论直写与待用户确认门控协议_v1.0_2026-07-17]]：认可把握达到95%的结论直接完成并提交；真正需要用户划界的问题在完成对象分层、正反例、最近邻排除、拿掉测试和理论后果后，进入 [[待用户确认问题队列]]。

## 1. 目标主次

```text
第一目标：作品案例 → 十元对象 → 生 / 克 / 补 → 动态链
第二目标：作品结构 → 五主显影 → 五主生 / 克
第三目标：is-a 内容盘点 → 知道作品里有什么、怎样组织、怎样复用
第四目标：把盘点结果转成故事控制器和创作素材
```

主维、次维、辅维只能做导航，不能代替关系分析。一个案例真正要留下的是：谁作用于谁、发生了什么改变、由哪个场景证明、关系持续了多久。

## 2. 四层不能混写

| 层 | 回答什么 | 允许产出 | 禁止越级 |
|---|---|---|---|
| 作品事实层 | 作品里具体有什么、发生了什么 | 人物、状态、行为、场景、时间结构、结果 | 不凭题材词直接判十元或五主 |
| `is-a` 内容层 | 这些内容分别属于哪类 | 人物库、关系库、空间库、场景库、道具库、意象库、镜头库 | 不把 `part-of`、`has-a` 当 `is-a` |
| 十元关系层 | 具体对象怎样互相作用 | 生、克、补、被生、被克、阶段链 | 十元互补不自动生成五大主题 |
| 五主关系层 | 哪些高级问题真正组织作品 | 显影等级、主次主题、主题级生克 | 两主题共现不等于生克启动 |

## 3. 十元生克补怎样从作品里取证

每条关系都必须写出两个端点，端点可以是人物、状态、行为、场景或时间结构。

```text
生：A 为 B 提供出现、持续、积累或进入下一阶段的条件。
克：A 压缩、限制、改写或破坏 B 的行动空间与成立条件。
补：A 与 B 位于固定互补对子，双方各自补足对方缺少的功能。
```

固定补位对子：

```text
zx ↔ nx
zn ↔ x
n ↔ x并z
xn ↔ z
xz ↔ nz
```

记录格式：

```text
关系：A（十元） 生 / 克 / 补 B（十元）
端点：A 是谁或什么；B 是谁或什么
证据：具体章节、反复场景、转折或结果
作用：B 的能力、边界、路径或状态怎样改变
阶段：起手 / 累积 / 转折 / 回收 / 崩坏 / 扭曲
置信度：高 / 中 / 低
反证：什么事实会推翻这条关系
```

注意：当前 `nx` 已改为“不主动占据选择、方向和位置，顺着已有安排继续”。涉及 `nx` 的旧暗算、账本、追踪、幕后结算案例全部不能直接沿用。

## 4. 五主生克怎样从作品里取证

先判显影，再谈关系：

```text
0级 背景存在
1级 局部主题
2级 次主题
3级 主主题
```

只有源主题和目标主题都达到结构性显影，并且源主题明确改变目标主题的能力、边界、路径或答案，才启动主题级生克。

正式关系盘：

```text
生环：空间 → 时间 → 命运 → 因果 → 本体 → 空间
克环：空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

五主关系卡：

```text
源主题：
目标主题：
关系：生 / 克
双方显影等级：
决定性改变：
承载对象：人物 / 状态 / 行为 / 场景 / 时间结构
高层证据：关键转折、高潮或结局
反证：若删除源主题，目标主题是否仍按原路径成立
```

## 5. `is-a` 在这里负责什么

`is-a` 不是结论层，而是作品内容的货架。它先让我们知道“有什么”，再为十元关系分析提供可指认的对象。

| 素材库 | 主要回答 | 在十元分析中的用途 |
|---|---|---|
| 人物库 | 谁在故事里 | 生克补端点、稳定锚点候选 |
| 关系库 | 谁与谁被怎样连接 | 动态链发生的关系容器 |
| 空间库 | 人为什么必须碰面 | 场景端点、边界与承载证据 |
| 场景库 | 每章具体发生什么 | 最小证据单元 |
| 道具库 | 什么触发或记录变化 | 触发器、证物，不单独判主题 |
| 意象库 | 什么反复承载抽象变化 | 显影辅助证据 |
| 镜头库 | 变化怎样不靠台词被看见 | 视觉辅助证据 |

因此正确顺序是：

```text
is-a 盘点对象
→ 找到对象之间的十元作用
→ 形成阶段动态链
→ 判断五主显影与主题级生克
→ 最后才回收为故事控制器或创作素材
```

## 6. 《Hirayasumi》首轮验证假设

来源：[[Hirayasumi_is-a漫画名词素材库_试作.canvas]]。以下只利用当前事实底座和 Canvas 已有提取，不改漫画库 94 分与正式归仓；需要实读逐章复核。

### 6.1 十元层候选

| 候选关系 | 当前对象端点 | 为什么值得验证 | 置信度 |
|---|---|---|---|
| `n 生 xn` | 平屋共同生活、饭桌与照料（n）→ 作息、家务和反复相遇的生活秩序（xn） | 承载持续后自然生出维持共居的节奏与规则 | 中 |
| `xn 补 z` | 美大作业、截止日期和生活节奏（xn）↔ 夏美想完成创作、想被认可的执念（z） | 截止日期把创作冲动压成行动爆点，执念也让时间规则获得内容 | 中，需逐章确认 |
| `n 克 xz` | 可返回的平屋与弱关系照料（n）→ 上京、失败后失归和漂流状态（xz） | 稳定容器逐步压低人物继续漂流的必要性 | 中高 |
| `x并z` 反衬 `n`（非互补） | 平屋、饭桌、院子、照料与可返回结构均归 n | 温和、无欺骗性的生活外壳不判 x并z；包装或表里张力可以反衬真实承载，但不形成案例内互补 | 用户已确认，UQ-20260717-001 已解决 |

### 6.2 五主层候选

| 主题关系 | 显影假设 | 决定性改变 | 当前状态 |
|---|---|---|---|
| `空间 生 时间` | 空间3级；时间2级候选 | 平屋迫使人物重复吃饭、收衣、往返，关系变化才得以按日常节奏累积 | 首要实读验证 |
| `空间 克 命运` | 空间3级；命运1-2级候选 | 可返回的住处把“继续漂流的多种可能”压缩为“可以停留或回来” | 待确认命运是否达到结构性显影 |

目前不能仅凭“有房屋、有日常、有归宿感”宣布主题生克成立。需要找到跨章节重复、关键转折和结局回答。

## 7. 三个故事控制器的正确位置

```text
日常生活漫画：控制事件大小。
都市共居漫画：控制人物关系发动方式。
低事件空间叙事：控制表达方法。
```

它们是从 `is-a` 素材层回收出来的创作控制器，不是十元或五主分类标签，也不能替代生克补分析。

《洗完再走》的生成公式继续保留，但用途改为“验证素材库是否可调用”。理论研究的主问题仍是：这些人物、空间、节奏与物件在具体场景里构成了哪条十元动态链，又让哪一组五主关系显影。

## 8. 后续每部重点漫画的双产出

### A. 主产出：关系证据卡

- 选 2-4 条十元生克补候选，必须写明端点、证据、改变和反证。
- 选 0-2 条五主生克候选；证据不足时允许写“未启动”。
- 不以主维/次维短评代替关系分析。

### B. 次产出：内容地图卡

- 盘点人物、关系、空间、场景、道具、意象和镜头。
- 严格区分 `is-a`、`part-of`、`has-a`、`carries`。
- 最后说明哪些内容可以回收为故事控制器或创作素材。

## 9. 当前结论

《Hirayasumi》Canvas 已经完成了“知道有什么”和“怎样调用素材”的大部分工作，也已经出现 `n 生 xn`、`n 克 xz` 等十元关系雏形；但此前重心偏创作生成，五主生克尚未形成正式证据卡。

从本协议起，漫画分析的主线改为：

```text
作品不是被拿来贴五大主题标签，
而是被拿来观察十元怎样作用、五主怎样显影和互相改变。
```
