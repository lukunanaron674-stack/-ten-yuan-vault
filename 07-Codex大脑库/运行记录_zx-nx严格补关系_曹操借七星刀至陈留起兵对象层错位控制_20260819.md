# 《三国演义》曹操借七星刀 → 陈留起兵｜zx↔nx 严格补关系对象层错位控制

## 0｜结论先行

本轮只复审一个窄问题：曹操第四回借王允七星宝刀刺董卓，与第五回逃回陈留后公开起兵，能否因为“同一人物、同一反董目标、前后直接因果”而锁成严格 `zx ↔ nx` 补关系。

结论：**不能。**

两端分别成立，但解决的不是同一个现实缺口：

```text
第四回 nx：
曹操自己决定刺董卓
→ 但七星宝刀属于王允
→ 必须请求王允借出
→ nx 外部兵器资源关系功能

第五回 zx：
刺董失败、逃回陈留
→ 曹操转为公开募兵、发檄、调练军马
→ 各方人员与诸侯开始围绕其公开行动响应
→ zx 公开军政作用范围扩张
```

前段失败确实导致逃亡并触发后段起兵，但七星宝刀并没有补“公开军事动员”缺口；后段公开起兵也没有反向补“秘密刺杀需要什么兵器”这一旧缺口。

因此正式锁：

> **同一总目标 + 直接因果 + zx/nx 两端都真，仍不足以构成严格补。必须继续检查两端是否直接改变同一对象层、同一现实变量。**

## 1｜剧情事实、触发、对象、动作、结果

### 阶段 A｜借七星宝刀刺董

王允宴集群臣忧董卓专权。曹操主动提出刺杀董卓，并明确说明自己因董卓信任而有接近机会；随后主动向王允请求借七星宝刀。王允同意并把刀交给曹操。

次日曹操携刀进入相府，准备趁董卓卧床时行刺；董卓从镜中发现异常，曹操临时改口称献刀，随后借马逃离。刺杀失败，董卓随后下令通缉。

被测试对象层：

> **秘密刺杀所需的特定兵器资源，是否已经归曹操稳定掌握。**

答案是否定的：刀属于王允，曹操必须请求资源持有人本人同意。

因此：

`nx_endpoint: evidence-locked`

### 阶段 B｜逃回陈留公开起兵

曹操逃回陈留后，决定散家资、招募义兵。其父指出自有资财不足，之后另通过卫弘取得启动资金。曹操继而公开发矫诏、招集义兵、竖旗，乐进、李典、夏侯惇、夏侯渊、曹仁、曹洪等陆续进入，诸镇亦开始响应檄文。

被测试对象层：

> **曹操能否把自己的反董方向公开压入现实，并形成新的军政动员与影响范围。**

这一阶段公开行动、现实响应与作用位置上升均成立，所以：

`zx_endpoint: evidence-locked`

注意：第五回卫弘家资本身另构成 `nx` 资源关系功能，并可与该段 zx 构成独立严格补案例；但这不能倒灌成“第四回七星刀也在补同一缺口”。每条关系必须按自己实际改变的对象判断。

## 2｜第一门：两端是否分别独立成立

### nx 端

删除后续陈留起兵，只保留：

```text
曹操自己定刺董方向
→ 特定兵器在王允手里
→ 主动请求借刀
→ 王允可以给或不给
```

`nx` 关系功能仍独立成立。

### zx 端

删除“曾借七星刀”这一前史，只保留曹操逃到陈留后公开募兵、发檄、调练军马并引发现实响应，`zx` 仍可独立成立。

所以本例不是“一端根本不存在”的贾芸型伪补。

## 3｜第三道下限：缺口对象层错位

### 3.1 nx 的真实缺口

前段缺的是：

> **秘密刺杀路径中的特定兵器资源。**

变量是：

- 七星宝刀归谁；
- 曹操能否自行调用；
- 是否必须经王允同意。

### 3.2 zx 的真实缺口

后段处理的是：

> **公开军政动员能否形成，并把反董方向扩大为现实军力与政治响应。**

变量是：

- 公开募兵；
- 军队形成；
- 檄文传播；
- 各方响应；
- 曹操军政作用范围扩大。

因此：

```text
nx gap = 秘密刺杀兵器接口
zx gap = 公开军事动员与影响范围
```

同属“反董”总目标，不代表是同一现实变量。

## 4｜为什么直接因果仍不是补关系

时间链确实非常近：

```text
借刀刺董
→ 行刺失败
→ 被通缉逃亡
→ 回陈留
→ 改走公开起兵路线
```

所以前段是后段的**情境与触发前提**。

但严格补需要的是：

> A 端提供的资源/权限/能力，直接修复 B 端正在缺的变量；B 端又把 A 端提供的条件兑换成同一现实目标的完整推进。

七星宝刀没有进入陈留募兵体系；事实上它在行刺失败时已经被交给董卓。后段起兵依赖的是另一套资源、人员与公开动员结构。

因此：

`temporal_trigger_only: true`

## 5｜双向拿掉测试

### 5.1 拿掉前段 nx

假设曹操使用别的兵器，甚至完全没有发生“向王允借七星刀”这一资源关系，只要之后仍发生“刺董失败/与董卓决裂 → 逃回陈留 → 公开募兵反董”，后段 `zx` 仍然可成立。

后段不会出现：

> “因为缺少王允七星刀，所以无法公开募兵、发檄、形成军队。”

因此：

`nx_repairs_later_zx_same_object_gap: rejected`

### 5.2 拿掉后段 zx

只保留第四回，曹操仍可以完整经历“主动刺董 → 请求借刀 → 王允借刀 → 实施刺杀”。后来的陈留公开起兵并不是前段 nx 成立的必要补项。

因此：

`zx_repairs_prior_nx_same_object_gap: rejected`

## 6｜最近邻排除

### 普通因果/路径切换

本例最接近：

> **秘密路径失败 → 压力升级 → 主体切换到公开路径。**

这是路径切换与压力显影，不是严格补。

### xn

曹操如何接近董卓、如何逃亡、如何发檄募兵都有策略与组织成分；但 `xn` 解释“怎么组织”，不能替代“王允的刀为何必须请求”这一 nx 权限/资源问题，也不能替代后段公开扩权的 zx。

### x

七星刀在前段不归曹操稳定掌握，所以不是 x；后段军队形成以后部分军力会逐渐进入 x 调用边界，但那是 zx 扩张后的稳定化，不应倒灌前段。

### 第五回卫弘 nx

卫弘家资与陈留起兵是另一条直接资源缺口关系：它确实直接补公开募兵的启动资本，不能因为两种 nx 都出现在曹操身上就把“王允借刀”与“卫弘出资”视为等价。

## 7｜关键压力与第三因素冻结

关键压力：行刺失败后董卓公开通缉，原秘密刺杀路径终止，曹操必须离开洛阳并另建反董路径。

冻结：

- 曹操忠奸评价；
- 宝刀名贵程度；
- 董卓、吕布战力；
- 陈宫是否离去；
- 卫弘个人道德评价；
- 后续十八路诸侯成败；
- 曹操最终是否称霸。

只保留：

```text
前段 nx 到底缺什么？
后段 zx 到底在扩大什么？
两端是否直接改变同一现实变量？
```

结论不变。

## 8｜跨作品第三控制

已存在：

1. 《水浒传》林冲：早期 nx 处理“本人入寨资格”，后期 zx 处理“梁山最高治理/他人准入结构”。
2. 《西游记》孙悟空：早期 nx 处理“承接御马监职务”，后期 zx 处理“自身等级/身份主权”。
3. 《三国演义》曹操：早期 nx 处理“秘密刺杀兵器资源”，后期 zx 处理“公开军事动员与军政影响扩张”。

三例共同支持：

> **时间连续、同人物、同组织甚至同总目标，都不能代替“缺口对象层一致”测试。**

本轮达到三部独立作品门槛，应新建 `pending-review`，但不得直接修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
