# 运行记录｜公孙胜二仙山：罗真人事前拒绝能真实卡住下山结果

## 0｜本轮目标

补 P4“名义权限 vs 现实否决权”的正向最小控制：寻找一个外部上位节点不只是名义存在，而是在结果生效前说“不”以后，主体确实不能按原方向继续，必须等待、重配或再次请求；节点后来放行后，结果才恢复可执行。

本轮只判公孙胜在“是否离开二仙山、下山赴高唐州”这一许可对象层，不判其稳定人物本体。

## 1｜剧情事实

### 触发

宋江高唐州受高廉妖法所阻，派戴宗、李逵寻找公孙胜，请其下山破法。

### 对象

当前被测试的不是“公孙胜有没有自己的政治立场”，而是：

> **公孙胜此刻能否离开二仙山、重新赴梁山任务。**

### 明确动作与结果

1. 公孙胜带戴宗、李逵见罗真人时，明确说：梁山义友来呼唤自己，自己“未敢擅便，故来禀问我师”。
2. 戴宗请求暂请公孙胜下山破高廉。
3. 罗真人明确拒绝，要求二人下山另行商议。
4. 拒绝后，公孙胜没有自行下山赴高唐州，而是把戴宗、李逵带下山，原请求链当场中止。
5. 李逵之后以暴力企图解决罗真人，失败；三人再次上山哀告。
6. 罗真人改变决定，明确表示“权教他去走一遭”，并随后授法、交代条件。
7. 取得许可后，公孙胜才正式拜辞下山，并赴高唐州破高廉。

事实链形成完整的：

```text
请求许可
→ 事前拒绝
→ 原结果不能生效
→ 再次请求/重配
→ 外部节点改为放行
→ 结果恢复可执行
```

## 2｜zx / nx 分类

### 2.1 nx：高纯成立

本窄对象层满足 nx 关键条件：

```text
下山许可当前掌握在罗真人
→ 公孙胜本人承认“未敢擅便”
→ 罗真人第一次拒绝后，公孙胜不自行越过
→ 原下山任务链暂停
→ 罗真人后来明确放行
→ 公孙胜才正式离山
```

这里不是“公孙胜听话所以 nx”，而是**关键许可接口真实外置，而且主体真实承认并沿用这个接口**。

### 2.2 zx：本窄对象层排除

公孙胜没有在第一次被拒绝后公开夺取“是否下山”的最终处分权，也没有让罗真人的许可位置失效。

李逵的暴力行为不能倒灌成公孙胜的 zx；而且李逵斧劈罗真人也没有成功取消罗真人的真实许可位置，最后仍回到请求/放行链。

所以本轮不是 `zx+nx` 共现，而是许可关系层的高纯 `nx`。

## 3｜关键压力

压力来自高唐州军情紧迫、宋江急需破法、公孙胜与梁山旧义。

但压力不能替代十元判据。冻结“兄弟义气”“军情很急”“高廉很强”等因素后，只要保留：

```text
谁能决定公孙胜当前能否下山？
拒绝是否真实卡住结果？
主体有没有绕过？
放行后结果是否才恢复？
```

结论不变。

## 4｜拿掉测试

### 拿掉罗真人的真实否决权

假设罗真人只是礼仪上的师父，公孙胜即使被拒绝仍可照常下山、不会付出额外改道或等待成本，则本轮 nx 权限证据大幅下降。

原著并非如此：第一次拒绝以后，公孙胜没有继续赴高唐州，原链实际停止。

### 拿掉公孙胜的接口承认

如果公孙胜第一次被拒绝后直接离山、用自身地位让罗真人无法阻止，则应转查 `x/zx`；原著同样不是如此。

## 5｜反向测试

把本案改写成：

```text
罗真人说“不许下山”
→ 公孙胜仍立即自行离山
→ 罗真人无法阻止、无法改变结果
→ 下山结果照常生效
```

则“罗真人是师父/名义上级”只剩纸面身份，不能锁 nx。

这与仓库最近的《三国演义》曹操—献帝文学复验构成最小反向对照：

```text
曹操案：名义最高者献帝明确反对，但反对不能卡住结果 → 当前非 nx
公孙胜案：罗真人明确拒绝，拒绝真实卡住下山结果；后来放行才恢复 → nx 权限证据强
```

## 6｜最近邻排除

### nx vs xn

戴宗、李逵如何找山、重返松鹤轩、再次请求，可以有流程与组织；但公孙胜当前“能否下山”的关键变量不是自己搭流程，而是罗真人是否放行，所以本层优先 nx。

### nx vs x

若离山权限已经稳定进入公孙胜可自行处分边界，应判 x；但“未敢擅便”以及第一次拒绝后实际停止，直接排除当前 x 主判。

### nx vs zx

如果主体以自身权能取消罗真人否决并强行让下山结果生效，才转查 zx；本例未发生。

### 身份/听话 vs nx

“师徒身份”“尊师”“听话”都不是充分证据；真正证据是**拒绝能在结果生效前产生现实阻断，并迫使主体继续走该外部许可接口**。

## 7｜第三因素冻结

冻结：

- 公孙胜性格；
- 罗真人法力强弱；
- 李逵莽撞；
- 梁山兄弟感情；
- 高廉战力；
- 结局胜负；
- 道教身份与主题。

只保留五问：

1. 谁名义拥有许可？
2. 谁能在结果生效前真实说“不”？
3. 这个“不”是否阻止/延迟同一下山结果？
4. 主体被拒后是否必须重配、等待或再次请求？
5. 外部节点后来放行后，结果是否才恢复？

五问全部支持真实外部权限。

## 8｜人物本体 / 状态 / 行为 / 关系位置分层

```text
稳定人物本体：不锁；本轮不能推出公孙胜整体“没主见”。
当前状态：等待师父决定能否离山。
行为功能：禀问、接受第一次拒绝、在后来放行后下山。
关系位置：罗真人掌握当前真实许可接口，公孙胜沿其续接。
外部压力：高唐州军情只是提高请求强度，不改变权限来源。
```

## 10｜与现行正本的关系

本例强化而不修改现行 L1 / nx 正本：

- L1：木轴检查最终方向与作用权来源；
- nx：方向、权限或解决通道在外，主体不占最终决定，沿既有接口续接；
- 本例只是把“真实外部权限”压成可观察的事前否决证据。

不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
