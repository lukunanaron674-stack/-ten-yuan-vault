# 运行记录｜马谡街亭：违背明确上级方案并让下属执行，不等于 zx 扩权

## 1｜本轮问题

上一轮王熙凤协理宁国府留下 93% 灰区：外部正式授予一块真实局部权限以后，主体在该权限内高强度使用、重建规则，究竟只是 `x + xn`，还是已经进入 `zx`？

本轮用马谡街亭做反向压力：

> 若主体不仅自行重组运行方案，甚至明确违背上级给出的运行约束、压过副将意见，并让部队照自己的新方案执行，这是否已经足以锁 `zx`？

结论：**不足。**

## 2｜剧情事实

诸葛亮把守街亭任务交给马谡，拨二万五千兵并令王平相助，同时明确要求：

- 在要道下寨；
- 安营后绘图回报；
- 与王平商议，不可轻易自专。

马谡到街亭后却否定当道下寨，改主张山上屯军。王平连续指出断水、被围风险，并建议在五路总口下寨；马谡仍拒绝。王平退而求其次，请求分兵另寨作犄角，马谡只拨五千兵让其自行去寨，自己仍把主力放到山上。

结果是：马谡实际使用本次主将所掌握的兵力与指挥接口，让主力按自己改写后的方案运行；但街亭随后失守。

失败本身不参与十元判定。

## 3｜分层判断

### 上位任务层：nx 成立

“守街亭”这一最高任务来自诸葛亮，马谡仍然没有取消该总体任务。因此：

`nx_upper_task_relation: evidence-locked`

### 局部指挥层：x 成立

本次守街亭的兵力与现场主将接口已经正式交给马谡。他可以调动主力，也可以拨五千兵给王平。因此该局部指挥边界是真实 `x`，不是每个动作仍需逐项回诸葛亮批准。

`x_delegated_local_command_boundary: evidence-locked`

### 运行方法层：xn 高显影

马谡没有沿“当道下寨 + 与王平商议”的既有运行方式推进，而是重新选择位置、兵力分布与协同关系。

`xn_operational_rewrite: evidence-locked`

### zx：排除为主判

关键点：**违令、压过副将、让部队执行新方案，都不足以证明决定范围扩大。**

马谡实际使用的仍是诸葛亮已经授予的“本次守街亭主将”局部指挥接口。文本没有显示：

- 他取得了超出本次守街亭的新军政对象；
- 蜀军制度承认他拥有比原授权更高的长期处分权；
- 诸葛亮以后必须围绕一个新增“马谡最高决定接口”运行；
- 违令结果被制度性承认为新的权限边界。

因此：

`zx_beyond_delegated_boundary: rejected_as_primary`

## 4｜关键压力

本轮压力比普通“授权内自由发挥”更强：

```text
上级方案明确
+
副将持续反对
+
主体仍直接让主力执行自己的替代方案
```

即便如此，仍只能高置信锁：

> 既有局部 `x` 被强势使用 + `xn` 运行重写。

不能自动锁 `zx`。

## 5｜拿掉测试

### 拿掉诸葛亮明确的“当道下寨/与王平商议”约束

如果只剩“守住街亭”，马谡自己设计山上方案，那么 `xn` 仍成立，但“违令”这一压力消失。`zx` 仍不会凭空成立。

### 拿掉马谡的主将授权

如果马谡原本没有调动这些兵力的局部指挥接口，却公开夺取并稳定取得兵权，才应重新检查 `zx`。

### 拿掉街亭失败

即使山上方案最终获胜，分类仍然不变：胜负不能代替权限边界证据。

## 6｜反向测试

### 反向成更纯 x + xn

上级只给“守街亭”总任务，完整战术自由已明确下放给马谡；马谡在这块边界里设计山上方案。

→ 局部 `x + xn` 更纯，仍非 zx。

### 反向成 zx

必须出现额外证据：

```text
原授权只覆盖 A
→ 马谡公开把决定权推进 B
→ 上级或组织原本能阻止
→ 但新 B 接口实际稳定生效
→ 后续秩序承认该新增边界
```

原文没有。

## 7｜最近邻排除

### zx vs x

已有授权范围内的强势调用、误用、违令使用，仍首先是 `x` 的使用问题；`zx` 必须看到权限边界本身向外扩大。

### zx vs xn

“把既有方案重写得很彻底”回答的是运行方式由谁组织，优先 `xn`；不能拿运行重构代替权限扩张。

### nx vs xn

上位任务仍来自诸葛亮，所以任务层保留 nx；具体运行层由马谡重设，因此运行层 nx 下降、xn 上升。

## 8｜第三因素冻结

冻结：马谡自负、熟读兵书、王平能力、诸葛亮用人评价、街亭胜负、军令状、生死后果、蜀魏立场。

只保留：

- 原授权边界是什么；
- 马谡实际调用什么；
- 是否重写运行结构；
- 是否把决定范围推进到原授权之外；
- 新边界是否被组织现实承认。

结论仍为 99/98。

## 9｜与王熙凤 93% 候选的最小差异意义

本例提供一条反向控制：

> **甚至“明确违背上级运行指令 + 压过副手 + 让下属照自己方案执行”，仍不自动构成 zx。**

因此王熙凤协理宁国府若要从“授权后的局部 x + xn”进一步锁成 zx，不能只依赖：

- 她很强势；
- 她改了旧规；
- 她能处罚下属；
- 宁府人员都照她新规运行。

还必须继续找：**她把决定范围推进到贾珍/王夫人明确未交付的对象层，而且该新增接口现实稳定生效。**

这使“授权内高强使用”与“真正越授权扩权”的分界更窄，但目前只有本例作为专项反向控制，不新建理论正本规则。

## 10｜结论

本轮正式结论：

> **违令 ≠ zx；强势使用已授权的局部 x ≠ zx；主体把运行方案重写为自己的结构，优先检查 xn。只有决定范围真正越过原授权基线并被现实结构承认，才重新检查 zx。**

不修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡。
