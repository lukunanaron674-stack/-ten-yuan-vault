# 运行记录｜贺拆幽州诱敌：执行自由不等于 xn 方案重设

## 1｜本轮目的

补足“外部方案已经存在，但主体只在执行层自由发挥”这一反向控制的第三部独立作品。

已有反向控制：

1. 《西游记》孙悟空红孩儿诱敌：破门、叫阵、激将、败退等临场动作未替换观音的关键诱敌与收伏骨架。
2. 《三国演义》赵云博望坡诱敌：交战数合、回马、再次退却等节奏自由未替换诸葛亮“不要赢、只要输”的战术终点。

本轮检查《水浒传》是否复现同型结构。

## 2｜剧情事实

贺重宝先向辽方提出幽州诱敌方案：利用青石峪地形，把宋军引入幽州境内，再由后续军力围困。

随后贺重宝把军队分为三队，并明确给两个弟弟具体执行约束：

```text
贺拆去打霸州
贺云去打蓟州
都不要赢
只佯输诈败
引入幽州境界
```

贺拆实际在霸州方向接战宋江军。文本写明，他与宋军交锋“不曾斗的三合”，便引军败走。

因此贺拆并非逐动作遥控：文本没有规定他必须斗几合、以何招式退、具体在何一秒转身；但他真实保留了决定性方案骨架：

```text
不取胜
→ 短暂接战
→ 败退
→ 为诱敌深入服务
```

宋江当刻没有直接追贺拆，但辽方两路示弱与后续贺重宝继续诱击共同构成同一幽州诱敌结构。贺拆个人执行并未重设这套方案。

## 3｜对象、触发、动作与结果

- 触发：贺重宝决定用诈败把宋军诱向幽州及青石峪体系。
- 对象：贺拆所领霸州方向部队的前线诱敌任务。
- 外部给定关键终点：不要赢；佯输诈败；把敌方行动方向推向幽州。
- 贺拆自主动作：自行完成接敌，并在不足三合后选择退走。
- 结果：局部战斗没有变成追求正面胜利；诱敌方案骨架保持。

## 4｜nx 判断

锁定：`nx_external_scheme_continuation: evidence-locked`。

理由不是“贺拆听哥哥的话”这一身份伦理，而是：

```text
关键战术方向与终点已经由贺重宝给出
→ 贺拆没有取得或使用最终重设位
→ 真正执行窗口仍沿既定诈败方向推进
```

符合现行 nx：方向/方案骨架在外部，主体实际沿已有方向与通道续接。

这只锁当前行为功能，不推贺拆稳定人物本体为纯 nx。

## 5｜xn 最近邻排除

贺拆拥有局部执行自由：

- 是否先短战；
- 具体战几合；
- 何时拨军退却；
- 前线动作节奏。

但这些都没有替换：

- “不要赢”的成功/失败条件；
- “佯输诈败”的关键节点；
- “诱向幽州”的战术终点；
- 贺重宝后续围困结构；
- 整体协同接口。

因此：

```text
局部交战长度 / 退却时机自由
≠ 关键运行结构重设
```

锁定：`xn_key_scheme_rewrite: rejected`。

## 6｜zx 判断

锁定：`zx_in_narrow_stage: rejected_as_primary`。

贺拆带兵接战、主动选择退却，不代表其决定范围扩大，也没有公开夺取贺重宝的最高战术方向，更没有让辽军体系围绕新增的“贺拆最高决定接口”重排。

普通战斗行动、执行熟练度与临场主动性均不足以锁 zx。

## 7｜拿掉测试

### 拿掉贺拆的局部自由

假设改成上级连“接战三合后退”都逐项写死，只要贺拆仍按“诈败诱敌”执行，nx 仍成立。

说明交战长度、退却时机不是 nx 的分类支柱。

### 拿掉外部关键骨架

如果贺重宝只说“你去霸州自行处理”，没有规定不许取胜、诈败、诱向幽州，而贺拆自己设计整套诱敌节点，那么 nx 会明显下降，应转查 xn。

### 拿掉真实续接

如果贺拆口头领命，真正交锋后却改成正面求胜、拒绝败退，则最多只有承接入口，不能锁执行层 nx。

## 8｜反向测试

真正的 xn 重设应出现：

```text
贺重宝给出诈败诱敌方案
→ 贺拆否定关键节点
→ 改变诱敌目标区域 / 成功条件 / 兵力协同
→ 旧方案无法按原骨架继续运行
```

原文没有。

真正的 zx 则还需：

```text
贺拆公开取得此前不属于自己的更高战术决定范围
→ 辽军围绕新增决定接口重排
```

原文同样没有。

## 9｜第三因素冻结

不得用以下因素直判十元：

- 贺拆武力强弱；
- 辽宋胜负；
- 贺重宝是否最终成功诱敌；
- 贺拆是否忠于兄长；
- 军人职业；
- 宋江当刻有没有追赶。

本轮只检查：关键方案骨架由谁给出、主体是否替换它、局部执行自由是否触及决定性节点。

## 10｜跨作品增量

现在反向控制跨三部独立作品：

```text
西游记｜孙悟空红孩儿诱敌
三国演义｜赵云博望坡诱敌
水浒传｜贺拆幽州诈败诱敌
```

三例共同支持：

> 主体在真实执行中可以拥有路线、话术、动作顺序、交战长度、回马或退却时机等自由；只要决定性节点、资源配置、协同接口、成功/失败条件与最终处置路径未被替换，就不足以把 nx 的方案续接判成 xn 方案重设。
