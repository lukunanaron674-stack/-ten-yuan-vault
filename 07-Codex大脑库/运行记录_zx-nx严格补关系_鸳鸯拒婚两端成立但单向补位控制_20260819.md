# 《红楼梦》鸳鸯拒婚｜zx↔nx 严格补关系复审

## 0｜结论先行

本轮不改写既有正式案例对本桥段的基础判断：

- `zx` 当前状态 / 行为功能独立成立：婚姻与去留方向由鸳鸯本人明确占据，她持续拒绝贾赦，并公开把“不去、不嫁”压入现实。
- `nx` 关系功能独立成立：鸳鸯本人没有足以让贾赦停止的家族最高权限，必须进入贾母这一既有权威接口取得保护性否决。

但本轮按 `zx补nx_补卡` 的严格标准复审后，**不锁严格 `zx ↔ nx` 补关系**。

原因不是某一端不存在，而是双向拿掉测试不对称：

```text
拿掉 nx
→ zx 拒绝方向仍在
→ 但缺少能稳定压住贾赦的外部家族否决接口
→ nx 补回后缺口明显改善

拿掉 zx 的公开显权端
→ 只要鸳鸯仍保留“不愿被纳妾”的最低目标并进入贾母保护接口
→ 贾母自身已有家族权威就能阻断贾赦
→ nx 并不出现“有路径却缺落地权能”的独立缺口
```

因此本例更准确地属于：

> **`nx` 单向补足 `zx` 的外部权限缺口，但 `zx` 并未反向补足 `nx` 一个不可替代的落地权能缺口。**

这与《水浒传》鲁达五台山案例形成第二部独立作品的同类反例。

---

## 1｜剧情事实

### 触发

贾赦欲纳鸳鸯为妾，由邢夫人、鸳鸯兄嫂等多层关系施压，并进一步威胁鸳鸯今后的婚配与去处。

### 对象

本轮只看：

- 鸳鸯对自身婚姻 / 去留方向的决定；
- 贾赦持续施压；
- 贾母作为能够现实阻断贾赦的家族高位权限节点。

### 明确动作

1. 鸳鸯在利益诱导和家庭劝说下持续拒绝。
2. 贾赦通过其兄长传递更强威胁，表示即使鸳鸯以后嫁给别人也难逃其控制。
3. 鸳鸯仍不改变“不去、不嫁”方向，并要求回禀贾母。
4. 鸳鸯当众向贾母陈情，把自己的拒绝公开化并承担后果。
5. 贾母随后调用自身家族权威站到鸳鸯一边，贾赦的纳妾安排在这一阶段无法继续。

### 结果

- 鸳鸯自身方向没有被贾赦改写；
- 现实阻断贾赦的关键高位权限来自贾母；
- 两端在实际剧情中都成立，但其互补关系需要继续接受双向拿掉测试。

---

## 2｜zx 端独立成立

本段 `zx` 不是“鸳鸯很刚烈”，而是：

```text
外部要求她成为贾赦之妾
→ 鸳鸯形成相反方向
→ 持续不交出方向资格
→ 面对升级威胁仍公开表明立场
→ 现实婚配安排被迫围绕这一公开拒绝重新处理
```

因此既有案例锁定的 `zx` 当前状态 / 行为功能继续保留。

本轮不升级稳定人物本体。

---

## 3｜nx 端独立成立

鸳鸯自己能够决定“不愿意”，不等于她拥有“让贾赦必须停止”的家族处分权。

当前关键权限结构是：

```text
鸳鸯：拥有自身方向
贾母：拥有更高家族保护 / 否决权
```

鸳鸯必须通过既有主仆信任和贾母的家族位置，让这个外部权限真正进入事件。

所以 `nx` 锁在关系功能与权限位置，而不是纯 nx 本体。

---

## 4｜严格补关系第一门：两端是否分别成立

通过。

- 拿掉“贾母会保护她”这一结果预设，鸳鸯仍有清楚的公开拒绝方向，`zx` 端不是由 nx 倒推出的。
- 拿掉鸳鸯的强势性格标签，只保留“关键家族否决权限不在本人、必须进入贾母接口”，`nx` 关系功能仍可独立识别。

因此本例不是贾芸那种“所谓 zx 端其实只是主动性 / xn”的第一门失败。

---

## 5｜严格补关系第二门：双向拿掉测试

### 5.1 拿掉 nx：zx 留下明确缺口

保留鸳鸯全部拒绝方向与公开表达，但拿掉贾母或等价的现实高位保护接口：

```text
鸳鸯仍明确拒绝
→ zx 方向资格仍成立
→ 但贾赦仍掌握强家族与婚配施压位置
→ “让拒绝在贾府结构中稳定生效”出现明确权限缺口
```

补回贾母的 nx 权限接口以后，这个缺口明显改善。

因此：

```yaml
nx_repairs_zx_gap: supported
```

### 5.2 拿掉 zx 的公开显权端：nx 不出现对称缺口

严格复审时不能把“拿掉 zx”偷换成“把鸳鸯的任何最低目标也删掉”。否则 nx 关系功能会因为没有待解决问题而一起消失，无法形成有效反事实。

所以更合适的反事实是：

```text
鸳鸯仍不愿被纳妾
但不以公开对抗 / 显权方式把自身方向压入现实
→ 她直接进入贾母保护接口
```

此时只要贾母愿意并使用其家族权威，贾母本身就可以让“阻止贾赦”这一保护结果落地。

也就是说，nx 在本例并没有留下：

> “外部通道已经有了，但缺少鸳鸯 zx 才能把通道转换为现实结果。”

因此：

```yaml
zx_repairs_nx_gap: rejected
```

严格双向互补失败。

---

## 6｜为什么不能因“zx + nx 同场”直接锁补

现行 L1 只说明 `zx ↔ nx` 是木内部同一核心变量的阴阳两端，不保证某个具体案例里两端同时出现就自动形成严格补关系。

本例实际更像：

```text
自身拒绝方向 zx
+
外部家族保护权限 nx
```

它们在同一事件链中协同，但严格补卡还要求：

```text
nx 补 zx 的缺口
且
zx 也补 nx 的缺口
```

本例只高置信通过第一方向。

所以：

> **共存 / 协作 / 同一结果链 ≠ 严格互补。**

---

## 7｜最近邻排除

### zx vs x

鸳鸯没有稳定掌握贾赦、家族婚配或贾母权限，不是 `x`。她的 zx 只锁当前公开拒绝与方向显影。

### nx vs xn

鸳鸯没有搭一套新的人员、时间、流程和节点系统；进入贾母处陈情是使用已有权威接口，所以 `nx` 不被 `xn` 吞掉。

### nx vs nz

鸳鸯与贾母长期信任、关系价值很高，但关系价值不能替代“贾母当前是否真实承担保护 / 否决接口”这一权限判断。本轮不越轴正式锁 `nz`。

### zx vs xz

贾赦威胁与“死 / 终身不嫁”等极端后果是压力，不是 zx 的直接判据。冻结生死措辞以后，方向与权限结构仍在。

## 8｜第三因素冻结

冻结：

- 鸳鸯刚烈、忠诚等人物评价；
- 贾赦好色、强势等道德评价；
- 主仆感情；
- “宁死不从”的戏剧强度；
- 贾母是否偏爱鸳鸯；
- 最终贾赦另买嫣红等后续结果。

只保留：

```text
谁占据自身最终方向？
谁掌握现实保护 / 否决权限？
拿掉任一端后，另一端留下什么缺口？
补回以后缺口是否双向改善？
```

结论仍稳定。

---

## 9｜与既有严格补正例的最小差异

真正严格补正例要求：

```text
zx 有自己的公开方向与落地权能
→ 但缺外部专属资源 / 权限
nx 补入该缺口

nx 有外部资源 / 通道
→ 但资源本身不会自动变成完整公开推进
zx 再把它兑现成现实行动
```

而鸳鸯这里：

```text
nx 的外部权限持有人——贾母
本身就能让“阻断贾赦”这一权限结果生效
```

因此缺少反向的 `zx → nx` 必要补位。

---

## 10｜与鲁达五台山案例的跨作品复现

《水浒传》鲁达五台山：

- 前段 zx 真成立；
- 后段 nx 真成立；
- nx 能补 zx 在“安身 / 身份转换”上的缺口；
- 但后段 nx 通道自身已足以完成当前任务，反向 `zx → nx` 缺口不成立。

《红楼梦》鸳鸯拒婚：

- 当前 zx 真成立；
- 当前 nx 真成立；
- nx 能补 zx 在“让拒绝稳定压过贾赦”上的权限缺口；
- 但贾母权限自身即可落地保护结果，反向 `zx → nx` 缺口不成立。

因此目前形成两个独立作品的同类边界控制：

> **两端都成立 ≠ 严格补；单向补位仍不足。**

跨作品数目前为 2，未达到新待审议阈值。

优先继续寻找与本轮不同的第三种伪对子：

> `zx`、`nx` 两端都独立成立，且双向看似都有缺口，但两边缺口位于不同对象层、并非彼此修复。
