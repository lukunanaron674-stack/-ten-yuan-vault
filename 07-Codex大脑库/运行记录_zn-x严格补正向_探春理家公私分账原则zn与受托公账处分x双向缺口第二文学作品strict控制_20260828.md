## 2｜剧情事实

### 2.1 现实授权与办事窗口

王夫人因凤姐病中不能理事，将家中琐碎事务暂交李纨，并命探春合同李纨裁处。探春、李纨每日在议事厅受理家务，执事媳妇连续来回事情，说明这不是只有“小姐 / 协理”称号。

### 2.2 赵国基丧银

赵姨娘兄弟赵国基死亡。李纨先按袭人母亲案例提出四十两，吴新登家的准备拿对牌去支银，探春立即叫回，要求查旧账、区分“家里 / 外头”的既有公例。

查账后，探春决定：

```text
赵国基丧银
→ 二十两
```

赵姨娘随后直接以母女 / 私亲关系施压，要求探春额外“拉扯”自家人。探春仍拒绝因私亲提高公账支出，并把自己当前行为明确放回“照管家务 / 按旧规矩办 / 不敢添减混出主意”的公开可核验边界。

凤姐随后又通过平儿表示“照常例二十两，也可由姑娘裁度再添些”。探春仍拒绝替公账开私情口子：凤姐若日后自己另添，是凤姐自己的施恩；当前由探春处分的这一笔，不由她任意加码。

### 2.3 第五十六回跨情境复验

第二天讨论家务时，探春主动指出姑娘们月钱、头油脂粉等存在重复支出。这里甚至涉及探春自己与姐妹们的既得使用便利。

她仍主张取消重复买办费用，并进一步提出大观园分区给老成婆子管理、减少浪费、把园中产出反补园务的方案。

因此本轮原则不是：

> “别人规定什么，我机械照做什么。”

而是跨两个财政情境反复出现：

```text
亲属私情不能改写公账处分
+
自己 / 姐妹受益也不能让重复支出继续
+
公账需要可公开解释、可核验、避免重复与私情侵入
```

## 3｜被测对象层

本轮只测：

> **探春在王夫人授权的理家窗口中，对当前荣府日常公账、丧银与部分园务开支的现实裁处 / 增减 / 停支处分边界。**

不测：

- 探春对整个荣国府的最终总权；
- 王夫人的最高家政权；
- 探春全部人格；
- 普遍意义上的所有“公正”；
- 第七十四回抄检大观园的全局权限。

这与既有 `local x ≠ global x` 护栏兼容。

## 4｜x 端点：受托公账处分 x 独立成立

current `x` 要求：对象明确、主体明确、实际占有 / 调配 / 调用 / 处分 / 否决 / 排除能力明确，并且不是纯名义。

本窗口满足：

- 被测对象：赵国基丧银、日常重复买办开支、部分园务公费；
- 主体：探春；
- 现实处分：叫停原拟四十两、命查旧账、裁为二十两；拒绝再添；第五十六回提出并推动取消重复开支、重组园务费用；
- 现实响应：吴新登家的、平儿、李纨及相关媳妇以当前裁决继续执行；
- 不需每一笔重新向王夫人逐项申请。

因此：

```text
x = true
```

### 4.1 为什么“共享管理”不等于没有 x

李纨、宝钗等处在同一理家结构中，不等于探春没有现实 `x`。

本轮只要求证明：

> **探春自己的同层裁处能直接改变被测公账结果。**

赵国基丧银从拟四十两被探春叫停并改为二十两，就是现实处分证据。

### 4.2 为什么“未来可撤”不追溯否定 current x

王夫人可以未来收回理家权限，只说明 current `x` 有生命周期，不说明任内从未成立。

## 5｜zn 端点：受托处分公账时，私亲与自身受益不得改写可公开核验的公私边界

本轮不把 `zn` 写成泛泛的“探春很公正”。

严格限定为：

> **当自己现实受托处分公共家务 / 公账时，不能因为生母亲属关系、做人情需要或自己 / 姐妹的当前便利而任意改变可公开核验的公例与账目边界；公账必须能与私情分开说明。**

### 5.1 原则命题明确

赵姨娘要求以亲属身份额外照顾时，探春明确把“私亲”与“照管家务按规矩办”拆开，并拒绝由自己任意添减。

### 5.2 无奖励 / 无认可门

此处最强压力并不是奖励她守规矩，而是：

- 生母当面哭闹、指责她忘本；
- 亲属关系要求她用当前公账权限做人情；
- 凤姐甚至给出“再添些也使得”的宽松口径。

探春仍不借自己的权限替私亲加码。

第五十六回又进一步出现反奖励证据：她主动削减包含自己与姐妹日常使用在内的重复脂粉开支。

所以原则不依赖“别人要求她必须节省”这一单一外部制度来源。

### 5.3 冲突排序门

真正冲突是：

```text
顺从生母 / 给自家人做人情
+
保留自己 / 姐妹现有便利
vs
受托公账处分必须公私分开、可核验
```

最终选择反复由后者完成排序。

### 5.4 跨阶段未来调用

第五十五回是亲属丧银；第五十六回转到重复采购、园务成本与管理收益，原则继续进入新的财政对象。

因此不是一次情绪反应。

### 5.5 边界与让渡代价

探春允许：

- 依公开可查的例处分；
- 如果凤姐日后用自己名义另行施恩，由凤姐承担该决定；
- 当前由自己负责的公账，不用“私亲 / 好人情”名义任意改账。

边界可说明、可执行。

因此：

```text
zn = true
```

## 6｜最近邻排除

### 6.1 zn vs 外部制度服从

旧例本身不是 `zn` 的充分条件。

如果探春只因“祖宗旧规矩写着二十两”而机械执行，本轮 `zn` 不够。

第五十六回主动发现并取消重复开支、连自己 / 姐妹的便利也纳入削减，提供了独立于单一旧例的跨情境证据：

> **她在维护的是公私 / 公账边界，而不仅是某一条旧数字。**

### 6.2 zn vs xn

查账、园务分包、费用重组回答“怎么把家务运行得更有效”，属于 `xn` 邻近。

本轮 `zn` 回答的是：

> **即使我有权改账，哪些理由不能成为我改账的正当依据。**

### 6.3 x vs xn

园务流程设计可以是 `xn`；但赵国基丧银到底支多少、重复公费是否停、被测对象能否直接处分，是 `x`。

### 6.4 x vs nx

王夫人是上位授权来源，可有 `nx` 邻近；但任内具体公账对象已经进入探春可直接裁处的局部 `x`。

外部授权来源不等于主体当前永远没有现实掌握。

## 7｜strict 双向拿掉

### 7.1 zn → x：成立

拿掉“公私分账 / 私情不得改写公账处分”原则：

- 探春仍拥有当前日常公账处分 `x`；
- 仍能把二十两改成四十两；
- 仍能给亲属额外人情；
- 仍能保留对自己 / 姐妹有利的重复开支。

但 `x` 会重新出现一个可命名缺口：

> **我有权处分公账，但什么理由不应被我拿来改账？什么情况下即使我能给，也不应由我用公共处分权给？**

所以：

```text
zn_to_x_gap_filling = true
```

### 7.2 x → zn：成立

拿掉探春当前真实的公账处分 `x`：

- 她仍可以抽象认为“公私要分”；
- 也仍可以批评别人徇私。

但本轮被测窄原则会失去其 current 不可替代现实结构：

```text
由我当前受托处分的公账
+
我现实可以增减 / 停支 / 改制的对象
+
我是否利用自己的这项权力替私亲或自己谋便利
```

这条原则的核心不是评价“别人应该怎样管账”，而是在规定：

> **“我当前手里的这项公共处分权，不能被我拿来混入私亲和自身便利。”**

没有该 current `x`，它仍可作为抽象价值存在，但失去本轮“我的现实公共处分对象 / 我的自我约束目标”。

李纨、凤姐、王夫人的权限不能等价替代这一点：她们可以拥有各自的家政权，却不能替探春完成“探春是否利用自己当前手里的这份公账处分权徇私”这一现实对象结构。

所以：

```text
x_to_zn_gap_filling = true
```

## 9｜与首份正向及负控制的最小差异

### 9.1 与诸葛亮

共同结构：

```text
主体真实掌握 x
+
zn 命题天然规定“我手里这项 x 应怎样被我使用 / 限制”
+
x 又构成该原则的 current “我的对象 / 我方边界”
```

区别：

- 诸葛亮：直属军队留放处分 `x`；军令信用 `zn`。
- 探春：受托公账增减处分 `x`；公私分账 / 不徇私 `zn`。

因此不是同一剧情机制换皮。

### 9.2 与关羽 / 晁盖 / 唐僧负控制

那些案例中，被测 `x` 主要是原则的执行接口或扩大器；拿掉它以后，`zn` 仍有其他稳定现实对象可以承载。

探春本轮不同：

> 被测原则本身直接索引“我当前受托处分的公账是否被我混入私情”，因此 current `x` 是原则的构成性现实对象，而不只是工具。
