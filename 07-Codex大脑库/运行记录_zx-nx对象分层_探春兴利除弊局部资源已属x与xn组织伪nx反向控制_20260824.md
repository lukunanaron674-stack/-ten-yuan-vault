# 运行记录｜探春兴利除弊：局部资源已属 x、运行重排属 xn，不应误标为局部 nx

## 0｜本轮问题

现有 `nx对象分层不可互相覆盖边界` 已经跨三部作品证明：高层非 nx 不能覆盖真实局部 nx。下一步必须反打：

> 表面上主体有自己的总体方向，局部又使用了别人、人员或资源，是否就能把这个局部直接写成 nx？

本轮用《红楼梦》第55—56回探春暂代理家务并兴利除弊做反向控制。

结论：**不能。** 王夫人的委派入口是 nx；委派完成后，园中日常管理对象、人员与资源已经进入探春可直接裁处的局部 x；探春进一步重排责任、收益、人员与资源属于 xn。不存在一个仍在外部、需要逐次取得许可才能调用的局部 nx 接口。

## 1｜事实与对象层

第55回王夫人正式命探春与李纨共同裁处家务，探春由此进入临时家务管理对象域。第56回她进一步削减重复支出，并把大观园不同资源和区域交给熟悉事务的婆子分区负责，使收益、维护、责任和节支重新绑定。

必须拆成三层：

```text
权限进入：
王夫人正式委派
→ 探春接受
= nx 授权入口

授权完成后的管理边界：
园中日常事务、人员与资源可由探春直接裁处
= 局部 x

运行方法：
人员 + 责任 + 收益 + 资源 + 支出重新组织
= xn
```

## 2｜为什么这里的“别人/资源”不是局部 nx

nx v2.5 要求关键方向、权限或解决通道仍真实掌握在外部节点，主体必须沿那个外部接口推进。

本段中，婆子、园中花木、稻田、日常支出等不是每次都需要探春重新去找王夫人或凤姐借用。王夫人的委派完成后，这些日常管理对象已经进入探春当前可调用的管理边界。

因此：

```text
有人参与
≠ nx

使用别人劳动
≠ nx

局部资源原本来自组织
≠ 当前仍 nx
```

真正要问的是：**当前调用时，主体是否仍必须经过另一个独立外部许可/处分接口？** 本段未见。

## 3｜zx 判断

本窄阶段不因“改革很主动”直接锁 zx。

探春没有证明自己把处分范围推进到王夫人/凤姐明确保留且真实反对的新增对象域。改革发生在已交付的家务/园中管理边界内，因此现有正式记录仍支持：`x + xn`，非 zx 主判。

## 4｜nx 判断

### 4.1 真 nx：授权入口

王夫人是否把临时家务管理权交给探春，探春不能自行宣布成立。因此：

`nx_delegation_entry_relation: evidence-locked`

### 4.2 伪 nx：授权后的局部调用

授权完成以后，探春对园中日常资源、人员与支出进行直接裁处。若仍把“婆子是别人”“钱和园子原属于贾府”当成 nx，会把已经进入主体局部处分边界的 x 错写成外部通道。

因此：

`local_staff_or_garden_resources_as_nx: rejected_as_primary`

## 5｜xn 最近邻

探春真正做的是：

- 识别重复支出；
- 重分人员责任；
- 按资源类别分区；
- 把收益与维护绑定；
- 调整支出与激励结构。

这些都是主体主动搭运行节点与关系，故 `xn_policy_and_process_rebuild: evidence-locked`。

## 6｜关键压力

压力包括凤姐病中、荣府支出重复、园中资源浪费、旧流程低效。

这些只解释为什么改革发生，不直接决定十元。冻结这些主题词以后，仍可只靠“权限是否已交付、调用是否仍需外部许可、流程是否由主体组织”完成分类。

## 7｜拿掉测试

### 拿掉王夫人原始委派

如果探春从未取得日常家务管理权，却必须逐项请求王夫人开放园中人员、钱物和处分权限，则局部 nx 会明显上升。

原文不是。

### 拿掉所谓局部 nx

把“婆子/园中资源属于别人所以是 nx”这一假设拿掉，事实链仍完整：

```text
nx 授权入口
→ x 局部管理边界
→ xn 运行重构
```

没有出现新的现实缺口，因此所谓局部 nx 不是必要变量。

### 拿掉局部 x

如果探春已经被委派，却仍不能直接裁处任何园中人员、支出与资源，必须逐项回王夫人批准，那么 `x` 会下降、局部 nx 会重新成立。

## 8｜反向测试

真正局部 nx 应是：

```text
主体有总体方向
↓
局部关键资源/许可仍在另一节点
↓
主体不能稳定自行调用
↓
必须请求/借用/承接
↓
结果才生效
= 局部 nx
```

本例则是：

```text
外部先完成一次真实授权
↓
局部日常管理权已进入主体边界
↓
主体自行组织人员与资源
= x + xn
≠ 新的局部 nx
```

## 9｜最近邻排除

- `nx vs x`：当前仍需外部批准才可调用＝nx；已经归主体直接处分＝x。
- `nx vs xn`：关键接口来自外部并沿其续接＝nx；主体自己重排人员、资源、责任与节点＝xn。
- `nx授权入口 vs 后续当前状态`：过去通过 nx 获得权限，不代表以后每次调用仍是 nx。
- `人物本体 vs 当前功能`：本轮不锁探春稳定人物本体。

## 10｜第三因素冻结

冻结：探春精明、贾府衰败、凤姐病情、宝钗意见、改革效果和人物好恶。

只检查：

1. 王夫人是否完成真实委派？
2. 委派后日常对象是否可由探春直接裁处？
3. 调用这些对象时是否仍需另一外部许可？
4. 运行结构是否由探春主动组织？

答案支持 99/97：`nx入口 + 局部x + xn；伪局部nx排除`。

## 11｜结论

最窄可靠结论：

> **对象分层纪律不能反过来制造 nx。某局部层只有在关键权限/资源仍真实外置、主体必须沿外部接口推进时才是 nx；若该局部权限已通过此前授权进入主体稳定可调用边界，则当前优先判 x；若主体自己重排人员、资源和节点，则另判 xn。**

本轮不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
