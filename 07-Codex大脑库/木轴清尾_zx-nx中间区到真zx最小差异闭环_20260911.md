# 木轴清尾｜zx↔nx 中间区 → 真 zx 最小差异闭环

## 0｜本轮只解决一个问题

本轮只处理待审议问题中的 B 槽：

> 主体保留自己的最终方向后，什么额外条件会让“合法中间区”真正跨过 `zx` 阈值？

不新增第四、第五个“拒绝别人方案”的同型中间区样本，也不尝试同时解决真 `nx` 或同人物跨阶段。

## 1｜current canonical 锚点

L1 v1.6 的木轴为：

```text
木 = 阳木 zx ↔ 阴木 nx
广义变量 = 最终方向与作用权来源
zx = 自身生成并占据方向
nx = 不占最终方向、沿既有通道续接
```

本轮不修改 L1，只在 L4 案例判定层补端点最小差异。

## 2｜最小差异对

### A｜中间区控制：唐僧｜女儿国

```text
高价值替代方向存在
→ 唐僧保留“是否改道”的最终否决/重设资格
→ 他明确继续西行
→ 但没有把自身权能扩大成女儿国必须围绕其新增决定范围重排
```

判定：

```text
nx: FAIL
zx: FAIL
result: WOOD_MIDDLE_ZONE
```

关键不是“他不够坚定”，而是：方向资格虽在自身，现实作用范围仍主要停留在“守住自己的路线”。

### B｜真 zx 控制：鸳鸯｜拒婚

```text
外部给出婚配/去留方向
→ 鸳鸯保留最终方向并明确生成“不去、不嫁”
→ 拒绝从私下态度升级为公开陈述与现实不可配合
→ 原婚配安排必须针对她的公开方向重新反应
→ 当前婚配对象层出现真实 zx 行为功能
```

同时，鸳鸯还通过贾母既有权限接口完成保护性阻断，因此该段存在 `nx` 关系功能；这不否定同一对象层中的真实 `zx`，但意味着本例不是“纯 zx 本体”样本。

判定：

```text
zx: PASS (current-state / behavior-function)
nx: PASS (relationship-function, separate responsibility)
result: TRUE_ZX_PRESENT_NOT_PURE_ZX
```

## 4｜真正跨过 zx 阈值的最小变化

两例共享：

```text
主体都保留最终方向资格
主体都拒绝外部替代方向
主体都没有把“方向是谁定的”交给别人
```

因此这些因素不能区分中间区与 `zx`。

真正最小差异是：

```text
中间区：
self-retained direction
+ external-effect scope remains defensive/private

真 zx：
self-retained/generated direction
+ direction becomes a public reality constraint
+ external actors/order must materially reconfigure around it
```

最短判别式：

```text
保留最终方向资格 ≠ zx

zx = 自身方向资格
   + 自身方向被压入公共现实
   + 外部行动/秩序因该方向发生真实重排
```

这里的“重排”不要求主体拥有全局最高权力；但必须至少存在一个由主体自身方向直接触发、可观察、不可只归因于第三方代理的现实外部反应。

## 5｜nearest-neighbor

### vs nx

- 唐僧：面对替代方向仍保留最终否决/重设资格，因此不是 `nx`。
- 鸳鸯：自己的婚配方向没有交给贾母；贾母承担的是保护性否决权限，不是替鸳鸯决定“愿不愿嫁”。因此 `nx` 关系功能不能覆盖 `zx` 方向源。

### vs z

是否由某个最高裁定点出面，不是本轮核心。即便冻结贾母的最高长辈地位，仍可单独检查鸳鸯是否保有并公开实现自己的方向。

### vs x

拥有或调用资源/权限本身不等于 `zx`。本轮只问最终方向来源及该方向是否向外产生现实重排。

## 6｜removal test

### 唐僧

拿掉女王身份、美貌、王位与佛教主题，只保留“外部提供高收益替代路线，主体保留否决并继续原方向”，仍然是：

```text
方向资格保留
但无公开扩权
→ 中间区
```

### 鸳鸯

拿掉“刚烈”“宁死不从”等性格/情绪词，只保留：

```text
主体明确生成拒绝方向
→ 将拒绝公开化并使自身不再配合既定婚配安排
→ 外部计划必须针对该方向发生真实反应
```

`zx` 行为功能仍成立。

若进一步拿掉“公开现实化”这一步，只剩私下不愿意，则 `zx` 证据显著下降并回落到中间区候选。

## 7｜reverse test

将唐僧改写为：

```text
不仅决定继续西行
→ 还以自身现实权能使女儿国规则/政权必须新增围绕其方向的决定结构
```

则从中间区向 `zx` 上升。

将鸳鸯改写为：

```text
内心不愿意
→ 但不公开、不行动、不使外部安排因自身方向发生变化
```

则从 `zx` 回落到中间区。

## 9｜positive / negative controls

### positive control｜真 zx 存在

鸳鸯拒婚：

```text
自身方向明确
+ 公开现实化
+ 外部婚配安排因此必须重排
→ zx PASS
```

### negative control｜中间区

唐僧女儿国：

```text
自身方向明确
+ 拒绝替代路线
+ 只守住自己的去向
+ 未新增对外决定范围
→ zx FAIL / middle-zone
```

## 10｜失败类型

新增清尾 guard：

```text
FALSE_ZX_SELF_ASSERTION
= 有主见/拒绝/坚持/自我方向，但没有公共现实约束与外部结构重排

FALSE_ZX_THIRD_PARTY_BORROW
= 外部结构变化主要由第三方权限完成，却把第三方作用全部倒灌给主体 zx
```

对应纪律：

```text
1. 先锁主体自己的最终方向资格。
2. 再查该方向是否由主体自身行为进入公共现实。
3. 再查外部结构变化中，哪些由主体方向直接造成，哪些由第三方权限造成。
4. 只有主体自己的那部分现实外溢可计 zx；第三方权限另记 nx/x/z 等责任，不得借给 zx。
```
