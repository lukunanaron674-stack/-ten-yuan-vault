## 本轮结论

仅清理修正。撤回《寄生虫》“生存欲/想活下去→伪造学历、身份、经历”作为 `x生x并z` 纯案例的资格。

现行 x 是对象、资源、地盘、权限或关系进入“归我掌握”的边界，不是一般生存欲或获取欲。伪造身份首先是策略行为、身份包装与表面/内在分层候选，不能因为它帮助人物取得资源，就倒写为 x 生成 x并z。

`x生x并z` 的几何位置继续保留，具体机制未锁定。

## 对象分层

- 稳定本体：人物稳定 x 与稳定 x并z 均未由《寄生虫》该条旧概括证明。
- 当前状态：贫困、焦虑、生存压力、想改善生活。
- 行为功能：伪造学历、编造身份、设计进入雇主家庭的步骤。
- 光影与视觉：服装、证件、姿态和豪宅对比只属于显影。
- 场景：半地下室与豪宅是空间条件，不自动构成关系端点。
- 时间关系：先伪装后取得工作只是先后顺序。
- 关系位置：雇员、家教、司机、管家等身份接口。
- 动态链：必须另证哪一个已成立的 x 掌握边界改变了哪一个 x并z 变量。

## 源端点、目标端点与变量

- 源端点 x：主体已经掌握或正在扩大明确对象、资源、地盘、权限或关系范围。
- 目标端点 x并z：主体制作、认领或维持一层“被世界看到的自己”，且表层与内部形成稳定分层。
- 候选被改变变量：维持公开身份壳的必要性、投入强度、持续性与壳对内部掌握范围的保护能力。
- 成立阶段：不能只在一次骗取机会的瞬间成立；应在掌握范围已经形成后，外壳被持续制作或维护。
- 显影条件：壳被公共识别、主体持续认领、拿掉壳会直接损害已掌握范围。

## 候选机制

### 候选A：掌握范围需要公共外壳保护

```text
x 已拥有资源、权限、地盘或关系
→ 裸露真实掌握方式会使范围不稳或遭到夺回
→ 主体制作并维持可被社会接受的身份、品牌、职位或说法
→ x并z增强
```

理论后果：`x生x并z` 是“掌握边界为了稳定存在而生成社会界面”。

### 候选B：x并z只是取得x的前置工具

```text
主体尚未掌握目标对象
→ 先伪装、包装或制造身份接口
→ 借此取得工作、资源、权限或关系
→ x扩大
```

理论后果：方向更接近 `x并z→x`，不能倒写为 `x→x并z`。

### 候选C：xn / z 同时推动包装与获取

```text
计划、步骤、规则判断或完成目标
→ 同时产生身份包装行为
→ 同时带来资源取得
```

理论后果：x 与 x并z只是共同结果，真正源端点可能是 xn 或 z。

## 正例候选

1. 幕后掌握多个公司与关系网的主体，为保护已经存在的控制范围，长期建立慈善家、合法企业家或公共品牌身份；拿掉该公共壳后，其既有掌握网络会直接失稳。此例支持候选A，但须排除单纯公关流程 xn。
2. 已掌握地下组织、资源与地盘的首领，为使范围能在公开社会中持续运转，主动维持合法职位、基金会或家族品牌，并把该身份视为自身存在的一层。此例同时具备 x 与 x并z 端点，但仍需具体作品阶段验证。

## 反例

1. 《寄生虫》金家在尚未取得雇主家庭资源前先伪造身份，包装主要是进入接口，更接近候选B或xn策略，不能证明 x 先生成 x并z。
2. 求职者包装简历以获得工作，若尚无掌握边界，只证明策略与身份呈现。
3. 已有公司按常规制作品牌视觉，若品牌完全由流程部门执行且掌握边界不受其影响，更接近 xn，不证明 x 生 x并z。
4. 角色穿制服、化妆或使用一次假名，只是行为与显影，没有稳定表里分层。

## 最近邻排除

- 与 `x并z→x`：外壳先帮助取得资源、权限或关系时，应判反向候选；x生x并z要求掌握边界先成立，并实际提高外壳需求。
- 与 xn：流程化公关、品牌维护、身份材料制作若由计划和规则驱动，目标变量是运行秩序，不是壳作为存在形式。
- 与 z：为赢得机会、完成任务或被看见而包装自己，首先检查 z 的目标显现。
- 与 zx：公开炫耀权力、让所有人低头是显权，不等于制造表里分层的壳。

## 拿掉测试

- 拿掉既有掌握边界后，人物仍会为了进入目标关系而伪装，则案例不依赖 `x生x并z`。
- 拿掉身份壳后，既有资源、权限与关系仍同样稳定，则壳没有被 x 生成或维持的必要性。
- 拿掉计划、奖惩、目标期限后，若主体仍因保护已掌握范围而持续维护公共壳，才支持候选A。

## 反向测试

交换为 `x并z→x` 后，《寄生虫》旧案例反而更顺：伪造身份提供进入雇主家庭的接口，随后取得工作、收入与关系位置。因此该案例不能证明原方向。

## 动态链后果

若候选A成立：

```text
x
掌握范围形成
→ x并z
为保护范围建立可被接受的公共壳
→ z

```

感觉走向是“先拥有，再包装拥有，最后兑现包装”。

若候选B更普遍，则母行 `x→x并z→z` 只能保留几何位置；具体故事应改写为 `x并z→x` 或 `xn/z→x并z + x`。
