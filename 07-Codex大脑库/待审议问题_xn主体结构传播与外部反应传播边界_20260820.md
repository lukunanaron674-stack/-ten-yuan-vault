# 待审议｜xn 主体结构传播 vs 外部反应传播边界

## 1｜问题来源

当前 `nx ↔ xn` 灰区研究已经明确：

- 只是执行自由，不足以锁 xn；
- 单个关键节点改变，也不自动锁 xn；
- 一个根节点若由主体主动改变，并进一步让资源、协同、成功条件和后续流程重新绑定，可支持 xn 高显影。

新问题来自另一种强误判源：

> 主体只做一次拒绝、否决或局部边界重设，外部系统因为这一动作连续改变人员、资源、流程甚至战略。能不能把这些外部后果的传播深度倒算成主体自己的 xn 结构传播？

三部独立作品的高纯控制共同回答：不能自动这样算。

## 2｜三部独立作品控制

### A｜《三国演义》关羽拒婚辱吴

- 前置：关羽已接受“东和孙权”的上位战略。
- 当前动作：面对孙权联姻合作接口，关羽直接拒绝并逐使。
- 下游：孙权大怒，吴方自行转向谋取荆州并重排对曹、对刘战略。
- 主体 xn：未锁。

关键原因：后续多层战略变化是孙权 / 东吴自己组织的，不是关羽主动建立的新外交结构。

### B｜《水浒传》李逵扯诏

- 前置：朝廷招安接口正式进入梁山。
- 当前动作：李逵扯诏、欲殴钦差，公开拒绝招安。
- 下游：宋江、卢俊义制止李逵，梁山核心层修复现场，使团与众头领继续反应。
- 主体 xn：未锁。

关键原因：现场修复与后续组织处理由宋江、卢俊义等外部节点完成，李逵没有搭建替代的反招安运行结构。

### C｜《红楼梦》探春抄检

- 前置：王夫人批准搜检，凤姐等携真实上位权限进入秋爽斋。
- 当前动作：探春允许查物，但拒绝奴仆越界搜身；越界发生后公开反击并重申边界。
- 下游：凤姐、平儿等调整执行方式；王善保家的后续被外部系统责打；搜检结果继续由其他家族节点处理。
- 主体 xn：未锁。

关键原因：探春只重设自己的局部边界，没有设计新的跨院搜检流程、人员配置、复核节点或成功条件。

## 3｜当前最窄候选纪律

> **xn 的“结构传播”必须首先归因于主体自己对运行骨架的重新组织。外部主体、对手、上级或环境因为我的动作而产生的连锁调整，不能直接计入我的 xn 传播深度。**

可写成：

```text
主体改动 A
↓
外部系统自己调整 B/C/D
≠
主体主动重组 A/B/C/D
```

因此在判断“一个关键节点是否已经传播成 xn”时，必须增加归因检查：

```text
谁主动改了后续关键依赖？
├─ 主体自己重排节点 / 资源 / 协同 / 成功条件
│  → 可计入主体 xn 结构传播
└─ 外部对手 / 上级 / 环境自行调整
   → 先记外部反应传播，不计入主体 xn
```

## 4｜与 zx / nx 的关系

### 与 nx

主体拒绝一个既有外部接口，只能说明当前该接口的 nx 续接下降或退出；若主体没有建立替代运行结构，不能自动升级 xn。

### 与 zx

主体动作迫使外部系统大量反应，也不能自动锁 zx。zx 仍须独立满足：主体权能公开显现、现实响应、并且主体决定范围或影响位置真实上升。

因此：

```text
外部反应很多
≠ xn
≠ zx
```

必须分别检查“谁重组结构”和“谁扩大决定范围”。

## 5｜拿掉测试纪律

### 拿掉外部后续反应

若只保留主体当前拒绝 / 否决，而主体自己仍没有替代流程，则 xn 仍不成立，说明外部后果不是主体 xn 的支柱。

### 拿掉主体自身结构重组

若所有后续节点变化都来自外部系统，则不能因为结果传播多层而锁主体 xn。

### 反向成真 xn

需要看到主体在拒绝 / 否决后进一步主动：

- 重排关键节点；
- 重配人员或资源；
- 改写协同接口；
- 重设成功 / 失败条件；
- 建立新的持续运行路径；
- 使旧方案无法按原骨架继续。

## 6｜防止矫枉过正

本候选不是说“外部反应永远与 xn 无关”。

如果主体主动设计一个动作，本来就以诱发对方按预设路线重排为结构节点，而且后续外部反应是主体方案的一部分，例如：

```text
主体预设诱导节点
→ 对方按预期调整
→ 主体继续接下游节点
→ 整套传播属于主体主动搭建的运行结构
```

则外部反应可以作为主体 xn 的一部分证据。

真正区别是：

> **外部反应是否被主体事先纳入自己搭建的结构，并由主体继续组织其后续节点。**

不是简单按“动作发生在谁身上”机械切断。

## 7｜待继续验证

优先寻找以下两种材料：

1. 正向边界：主体只做一次动作，对方产生多层反应，但主体完全没有预设/接续这些变化，验证非 xn。
2. 反向控制：主体故意设计诱导动作，使对方反应成为自己方案中的预设节点，并继续利用该反应推进，验证外部反应也可以进入主体 xn 结构。

只有正反两侧都稳定后，才考虑是否将“传播归因检查”提升到准度卡或 nx↔xn 边界正本。
