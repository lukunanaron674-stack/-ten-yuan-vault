# 待审议｜xn 主体结构传播 vs 外部反应传播边界

## 1｜问题来源

当前 `nx ↔ xn` 灰区研究已经明确：

- 只是执行自由，不足以锁 xn；
- 单个关键节点改变，也不自动锁 xn；
- 一个根节点若由主体主动改变，并进一步让资源、协同、成功条件和后续流程重新绑定，可支持 xn 高显影。

新问题来自另一种强误判源：

> 主体只做一次拒绝、否决或局部边界重设，外部系统因为这一动作连续改变人员、资源、流程甚至战略。能不能把这些外部后果的传播深度倒算成主体自己的 xn 结构传播？

三部独立作品的高纯控制共同回答：不能自动这样算。

## 2｜三部独立作品控制

### A｜《三国演义》关羽拒婚辱吴

- 前置：关羽已接受“东和孙权”的上位战略。
- 当前动作：面对孙权联姻合作接口，关羽直接拒绝并逐使。
- 下游：孙权大怒，吴方自行转向谋取荆州并重排对曹、对刘战略。
- 主体 xn：未锁。

关键原因：后续多层战略变化是孙权 / 东吴自己组织的，不是关羽主动建立的新外交结构。

### B｜《水浒传》李逵扯诏

- 前置：朝廷招安接口正式进入梁山。
- 当前动作：李逵扯诏、欲殴钦差，公开拒绝招安。
- 下游：宋江、卢俊义制止李逵，梁山核心层修复现场，使团与众头领继续反应。
- 主体 xn：未锁。

关键原因：现场修复与后续组织处理由宋江、卢俊义等外部节点完成，李逵没有搭建替代的反招安运行结构。

### C｜《红楼梦》探春抄检

- 前置：王夫人批准搜检，凤姐等携真实上位权限进入秋爽斋。
- 当前动作：探春允许查物，但拒绝奴仆越界搜身；越界发生后公开反击并重申边界。
- 下游：凤姐、平儿等调整执行方式；王善保家的后续被外部系统责打；搜检结果继续由其他家族节点处理。
- 主体 xn：未锁。

关键原因：探春只重设自己的局部边界，没有设计新的跨院搜检流程、人员配置、复核节点或成功条件。

## 3｜反向控制

### A｜《三国演义》诸葛亮博望坡

- 主体先统一配置赵云、刘备、关羽、张飞、关平、刘封等节点。
- 赵云被明确要求“不要赢，只要输”，用于诱导夏侯惇继续追击。
- 刘备随后再退，使敌军继续深入。
- 夏侯惇追入博望坡后，火攻、伏兵、粮草攻击等下游节点按主体预设接续。
- 韩浩已经识别“赵云诱敌，恐有埋伏”，进一步证明追击不是与方案无关的偶然背景，而正是被诱导的关键外部反应。
- 主体 xn：锁定。

关键原因：夏侯惇的追击虽然物理上由外部主体完成，但诸葛亮事先设计了诱导条件，把该反应作为自己方案中的中间节点，并继续用它触发后续资源、协同与成功条件。

### B｜《水浒传》吴用智取生辰纲

- 吴用先安排七人扮贩枣客、白胜扮卖酒人，并明确整套计较由自己主张。
- 七人先真实饮用好酒，主动制造“酒可安全饮用”的可见证据。
- 刘唐故意争酒、白胜当众夺瓢，为吴用隐蔽下药创造结构性节点。
- 目标方由怀疑转向解除戒心并最终买酒饮用，不是事后偶然背景，而是圈套必须诱发的外部反应。
- 该反应随后直接触发“中药失能→取走生辰纲”的下游结果。
- 主体 xn：锁定。

关键原因：吴用不只是猜到杨志一行会喝酒，而是主动制造安全表象与争酒场景，把目标方“解除戒心并饮酒”预设成方案中间节点，并继续利用其完成下药与取纲。

因此目前形成两部独立作品的高纯反向控制：

```text
主体预设诱导节点
→ 外部主体按预期反应
→ 反应进入主体预设结构
→ 主体继续利用该反应触发下游节点
= 该外部反应可计入主体 xn 结构传播
```

## 4｜当前最窄候选纪律

> **xn 的“结构传播”必须首先归因于主体自己对运行骨架的重新组织。外部主体、对手、上级或环境因为我的动作而产生的连锁调整，不能直接计入我的 xn 传播深度。**

但“动作由外部主体完成”不是排除条件。真正需要检查的是：

> **该外部反应是否被主体事先纳入自己搭建的结构，并由主体继续组织其后续节点。**

可写成：

```text
A｜非 xn 外部反应传播
主体改动 A
↓
外部系统自己调整 B/C/D
↓
主体未预设、未接续
≠ 主体 xn

B｜可计入主体 xn 的外部反应节点
主体预设诱导 A
↓
外部按预期产生 B
↓
主体早已为 B 配置下游 C/D
↓
主体继续利用 B 推进
= B 可计入主体 xn 结构
```

因此在判断“一个关键节点是否已经传播成 xn”时，必须增加归因检查：

```text
谁主动组织了传播关系？
├─ 主体自己重排节点 / 资源 / 协同 / 成功条件
│  → 可计入主体 xn
├─ 外部动作虽由别人完成，但主体事先设计诱导并纳入下游结构
│  → 也可计入主体 xn
└─ 外部对手 / 上级 / 环境自行调整，主体未预设也未接续
   → 只记外部反应传播，不计入主体 xn
```

## 5｜与 zx / nx 的关系

### 与 nx

主体拒绝一个既有外部接口，只能说明当前该接口的 nx 续接下降或退出；若主体没有建立替代运行结构，不能自动升级 xn。

反过来，主体即使需要借用外部组织权威取得执行资格，也不等于其具体方案骨架必然是 nx。应分开检查“权限入口来自谁”与“运行结构由谁搭建”。

吴用案例还增加一条冻结纪律：外部提供事实信息或条件是否构成 nx，应继续由“信息源 vs 解决通道”边界单独判断，不能因为主体 xn 已成立，就倒灌把信息源自动判成 nx 或非 nx。

### 与 zx

主体动作迫使外部系统大量反应，也不能自动锁 zx。zx 仍须独立满足：主体权能公开显现、现实响应、并且主体决定范围或影响位置真实上升。

因此：

```text
外部反应很多
≠ 自动 xn
≠ 自动 zx
```

必须分别检查“谁组织了传播结构”和“谁扩大决定范围”。

## 6｜拿掉测试纪律

### 拿掉外部后续反应

若只保留主体当前拒绝 / 否决，而主体自己仍没有替代流程，则 xn 仍不成立，说明外部后果不是主体 xn 的支柱。

### 拿掉主体的预设与接续

若外部反应仍会发生，但主体此前没有把它放入自己的运行结构，也没有利用它触发后续节点，则该反应不能计入主体 xn。

### 拿掉预设外部反应节点

若方案本身依赖该外部反应才能进入下游，而外部不按预期反应时方案无法原样继续，则该反应是结构性真实节点，而不是事后解释。

诸葛亮案例中，夏侯惇若不继续追击，原预设火攻伏击结构无法原样触发；吴用案例中，押送方若始终拒绝饮酒，原预设“中药失能→取纲”结构同样无法原样触发。

### 反向成真 xn

需要看到主体主动：

- 重排关键节点；
- 重配人员或资源；
- 改写协同接口；
- 重设成功 / 失败条件；
- 建立新的持续运行路径；
- 或预设诱导外部反应，并把该反应接进自己后续节点。

## 7｜防止矫枉过正

本候选不是说“只要预测到了对手反应，就算 xn”。

预测若没有进入方案结构，例如只是猜到对方会生气，却没有为这个反应配置后续节点、资源与成功条件，仍不足以计入主体 xn。

至少需要看到：

```text
预设反应
+
诱导动作
+
反应成为下游的必要/功能性节点
+
主体继续接续该节点
```

诸葛亮博望坡与吴用智取生辰纲两例满足这一组条件；关羽拒婚、李逵扯诏、探春抄检三例不满足。

## 8｜待继续验证

下一步优先寻找第三部独立作品的反向控制：

1. 主体主动诱导外部主体产生预设反应；
2. 该反应不是偶然后果，而是后续资源 / 协同 / 成功条件的中间节点；
3. 主体继续利用该反应推进；
4. 与“外部自己反应、主体没有预设/接续”的负控制形成最小差异。

优先《西游记》或《红楼梦》。若第三部仍稳定达到至少95%，再考虑是否将“传播归因检查”提升到准度卡或 nx↔xn 边界正本。
