# 运行记录｜路易-拿破仑1851政变：授权总统权越出宪法边界后，zx 独立成立

## 1｜本轮问题

凯撒越卢比孔已经给出第一份高纯正向控制：

> 原制度只授权 A 对象域 → 主体把权能推进未授权 B → 原制度明确反对 → B 仍真实成立 → zx。

但凯撒是典型军权跨域案例，必须排除“只有带兵进入新领地才会显得像 zx”的机制污染。

本轮选择第二共和国总统路易-拿破仑，测试一个更制度化、非行省统兵对象的最小差异：

```text
宪法正式授予总统 A 权限
→ 宪法明确禁止总统拥有 B：解散议会 / 暂停宪制 / 延长自身权力边界
→ 议会真实拒绝修改边界
→ 主体公开发动政变，直接让 B 生效
→ 新宪法把原本禁止的权能纳入总统现实权限
→ 后续进一步转入帝制
```

## 2｜事实链

### A｜原授权对象域清楚存在

1848年宪法明确把行政权委托给一名共和国总统。路易-拿破仑通过普选进入这一职位，因此“总统职位与原法定行政权”不是私人自行制造，而是经既有宪法—选举接口成立。

```text
宪法 / 选举开放总统职位
→ 路易-拿破仑当选并承接
= nx 授权入口

授权完成以后
→ 法定总统行政权限进入其稳定调用范围
= 局部 x
```

这里只锁权限来源，不锁稳定人物本体为 nx。

### B｜B 边界不是模糊灰区，而是宪法明文禁止

1848年宪法至少给出三条非常硬的边界：

- 总统任期四年，不能立即连任；
- 总统不得解散或延宕国民议会；
- 总统不得以任何方式暂停宪法与法律的效力。

第68条进一步规定，若总统解散国民议会、阻碍议会履职，即构成叛国，总统依法失职。

因此本例的 A / B 边界不是后人主观解释：

```text
A = 宪法授权总统行政权
B = 解散议会、突破原任期与宪法制衡边界
```

B 明确不在原授权内。

### C｜原权限节点真的拒绝过，不是橡皮章

路易-拿破仑曾推动延长自己的政治任期 / 修改宪法，但国民议会反对相关修宪方案。

所以不存在“议会其实默认同意，只是手续没办完”的弱许可解释。

原结构真实表现为：

```text
主体想扩大 A
→ 现有制度节点拒绝
→ 正常通道没有开放 B
```

### D｜主体公开越过边界并使 B 现实生效

1851年12月2日政变时，路易-拿破仑以法令直接解散国民议会，并重置政治程序。该动作恰好是1848年宪法明文禁止总统做的事情。

这不是在原总统 x 内“强势使用已有权限”，而是把自身权能推进到旧宪法明确排除的对象域。

`nx_in_coup_execution_window: rejected_as_primary`

### E｜新边界没有被旧结构立即压回，而是制度化

1852年宪法由政变产生，显著扩大总统权力。与1848年“总统不得解散国民议会”相反，新制度明确赋予总统召集、休会、延长和解散立法团的权力。1852年11月又进一步转为第二帝国宪法。

因此出现：

```text
旧制度：解散立法机关不属于总统权限
↓
政变：主体公开使这项权能生效
↓
新制度：解散立法团等权力进入总统稳定权限
↓
外部政治结构围绕新边界重排
= 决定范围真实扩大
```

`zx_beyond_delegated_constitutional_boundary: evidence-locked`

## 3｜分层判断

### nx：原总统权限入口成立

总统职位与初始行政权必须通过1848宪法和选举接口才成为有效公共权限，所以可锁：

`nx_prior_constitutional_presidential_entry: evidence-locked`

但这只说明“原 A 权限怎么合法进入主体手里”。

### x：原总统权限成立

当选之后，宪法已经授予的总统行政权限属于主体可稳定调用的局部 x。

`x_delegated_presidential_boundary: evidence-locked`

### 当前政变窗口：nx 排除为主判

当议会与宪法拒绝开放更大的权限后，路易-拿破仑没有继续沿既有修宪 / 议会许可通道等待，而是直接绕过并清除该限制。

### zx：成立

本例完整通过 zx 四道硬门：

1. **主体新方向明确**：突破四年任期与议会制衡边界，保留并扩大自身国家权力；
2. **权能公开进入现实**：公开政变、解散国民议会，不是秘密个人愿望；
3. **外部体系真实响应**：旧议会—宪法结构被中断，新政治秩序重建；
4. **决定范围扩大**：1848年明确禁止的解散立法机关等权力，在1852制度中成为总统可调用的正式权限。

因此：

`zx_beyond_delegated_constitutional_boundary: evidence-locked`

## 4｜关键压力


不使用“拿破仑野心”“政变很强”“后来当皇帝”“是否受欢迎”直接判十元。

## 5｜拿掉测试

### 拿掉宪法明文禁止

如果1848年总统本来就有权解散议会，那么1851年的同一动作首先只是旧 x 调用，zx 证据会大幅下降。

→ **旧授权边界明确存在，是本例支柱。**

### 拿掉议会真实拒绝

即使仍可判越宪，但“原结构确实不愿开放 B”这一压力证据会变弱。

### 拿掉1852新制度中的权限扩大

如果政变发动后立刻失败，旧议会恢复，总统被撤职，则只能证明扩权尝试，不能高置信锁“新的决定范围已经成立”。

→ **新边界稳定落地是 zx 第四门。**

### 拿掉军事镇压

只保留：宪法禁止 → 议会拒绝 → 主体公开解散议会 → 新宪法把解散权等纳入总统权限，zx 主结构仍成立。

因此本例的核心不是“军队打赢”，而是**公共权力对象域发生现实扩张**。

## 6｜反向测试

### 马谡型：违令但仍在旧授权对象域

```text
总统在原法定行政权内
→ 与议会冲突
→ 自己选择强硬执行方法
→ 但不取得宪法明确禁止的新权限
= 可查 x / xn
≠ 自动 zx
```

### 真 zx

```text
原授权 A
→ B 明确被禁止
→ 原节点真实拒绝
→ 主体公开把权能推进 B
→ 旧结构无法压回
→ B 进入稳定公共权限
= zx
```

本例属于后者。

## 7｜最近邻排除

### zx vs x

1848宪法内已经授予的总统权是 x；把“解散议会、突破旧宪制边界”的权能从禁止项变成现实稳定权限，才是 zx。

### zx vs xn

政变的人事、军队、法令、投票与新宪法设计有明显 xn 邻近，但这些回答“扩权怎么组织”；本轮回答的是“决定范围有没有从 A 推到 B”。

### zx vs nx

原总统入口可以有 nx；但政变窗口恰恰不再沿议会 / 宪法的正常许可通道推进。

### zx vs 强硬 / 违法 / 政变标签

违法、政变、镇压都不是独立判据。若 B 没有成为新的现实决定范围，仍不能仅凭这些词锁 zx。
