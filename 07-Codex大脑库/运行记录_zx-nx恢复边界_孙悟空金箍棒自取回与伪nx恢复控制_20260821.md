# 《西游记》孙悟空金箍棒自行取回｜zx-nx 恢复边界反向控制

## 1｜剧情事实

第五十回，青牛精以金刚琢把孙悟空的金箍棒套走，孙悟空当场失去原本稳定掌握、长期直接调用的核心兵器。

第五十一回，孙悟空明确说明金箍棒已被夺，因此难以制服妖怪；随后进入天庭，请李天王、哪吒、雷公、火德星君、水德系统等多个外部节点援助。这些外部接口都是真实的 `nx` 关系 / 能力通道，但都没有替孙悟空恢复金箍棒这一具体对象的控制。

在多轮外援失效后，孙悟空自己提出偷取宝贝的路线，变成小虫潜入金兜洞，发现金箍棒靠在东壁，直接拿回铁棒、现出原身、打出洞门。原文以“主杖还归与本人”收束这一段。

因此最小结构为：

```text
原阶段：
金箍棒长期归孙悟空稳定直接调用
= x

金刚琢套走金箍棒
= 原 x 丢失

孙悟空连续接入天庭 / 神将外援
= nx 外部帮助真实存在

但：
这些外援没有恢复金箍棒这一同对象 x

孙悟空自己潜入洞中
→ 自己发现并拿回金箍棒
→ 自己打出洞门
= x 自行恢复
```

## 2｜x 判断

本轮 `x` 必须锁定在非常窄的对象层：

> 孙悟空对金箍棒这一具体兵器的稳定现实调用权。

金箍棒此前长期处于其稳定直接调用范围；被金刚琢套走后，这一调用边界真实中断；孙悟空自行潜入洞中取回以后，又重新恢复。

因此锁定：

- `x_prior_weapon_control_boundary: evidence-locked`
- `x_weapon_control_lost_after_diamond_snare: evidence-locked`
- `x_weapon_control_self_restored: evidence-locked`

本例说明：

> `x` 的恢复必须追踪“同一个被测试对象”到底由谁重新纳入主体稳定调用范围。

不能因为过程中出现很多外援，就把恢复原因自动归给外援。

## 3｜nx 判断

本阶段确实有大量 `nx` 关系功能：孙悟空不断进入天庭、神将、水火等已有关系 / 能力网络，请求他者帮助解决青牛精与金刚琢问题。

因此：

`nx_external_help_attempts: evidence-locked`

但在“金箍棒这个旧 x 是谁恢复的”这一同对象问题上：

`nx_external_help_restored_same_x_object: rejected`

理由是：李天王、哪吒、雷公、火德、水德等外援没有把金箍棒交还孙悟空，也没有使其恢复对该兵器的稳定调用。真正发生同对象恢复的是孙悟空自己潜入洞中拿回。

因此必须切开：

```text
nx 外援参与当前危机
≠
nx 外援恢复了每一个丢失的 x 对象
```

## 4｜zx 判断

本微阶段排除 `zx` 为主判。

孙悟空潜入、偷回金箍棒、打出洞门都非常主动，但结果只是把此前已经拥有的金箍棒重新拿回，没有证据表明其决定范围或稳定处分边界相较于原状态继续扩大。

因此：

`zx_in_recovery_microstage: rejected_as_primary`

关键纪律：

> 恢复旧 x ≠ 新 zx。

即使恢复过程主要由主体自己完成，也不能仅因“主动夺回”就自动判 zx；还必须看到决定边界相对原状态继续扩大。

## 5｜关键压力

关键压力不是“青牛精强”或“孙悟空失去武器后很难受”，而是：

- 金箍棒这一原稳定调用对象被现实夺走；
- 孙悟空一度无法直接调用；
- 多个外部 nx 能力接口真实进入，但并未恢复这一同对象控制；
- 最终恢复动作由主体自行完成。

这组事实足够测试“nx 参与”和“nx 恢复 x”之间的因果边界。

## 6｜拿掉测试

### 拿掉所有外部 nx 救兵

只保留：金箍棒被夺 → 孙悟空潜入洞中 → 自己拿回。

金箍棒旧 `x` 仍然可以恢复。

因此这些外援不是“金箍棒 x 恢复”的必要条件。

### 拿掉孙悟空潜入取回动作

保留此前所有天庭 / 神将外援，金箍棒仍没有因此回到孙悟空稳定调用范围。

因此：

> 外援存在 ≠ 同对象 x 已恢复。

### 拿掉“金箍棒原来长期归孙悟空调用”

如果这件兵器从未属于孙悟空稳定调用范围，那么后续拿到它属于新取得对象，不能再判“旧 x 恢复”。

## 7｜反向测试

### 真正的 `nx → x恢复`

应当出现：

```text
旧 x 丢失
→ 主体无法自行恢复
→ 外部 nx 节点直接改变同一个被测试对象
→ 该对象重新进入主体稳定调用范围
= nx 外部接口恢复 x
```

例如外部节点直接裁决归还、强制交还、正式复职、解锁权限等。

### 真正的 `zx`

需要出现：

```text
拿回旧 x
→ 同时进一步取得原来没有的更大处分范围
→ 外部秩序承认新增决定边界
= 才检查 zx
```

本例没有。

## 8｜最近邻排除

### nx vs x恢复因果

- `nx`：孙悟空确实在危机中调用了多个外部关系 / 能力接口。
- `x恢复`：金箍棒最终由谁重新纳入孙悟空稳定调用范围。

这两个问题不能因为发生在同一章就自动合并。

### x vs zx

拿回原有兵器只回到旧边界，优先判 `x` 恢复；是否 `zx` 要另看有没有越过原边界。

### nx vs xn

孙悟空连续更换救兵、尝试水火、偷入洞中存在方案组织与策略邻近，但本轮主问题是同对象恢复来源，不以 `xn` 为主判。

## 9｜第三因素冻结

冻结：

- 孙悟空战斗力；
- 青牛精强弱；
- 金刚琢神奇程度；
- 玉帝、哪吒、火德、水德等身份高低；
- 唐僧是否被救；
- 最后太上老君是否收服青牛；
- 小说宗教寓意。

只问：

1. 金箍棒原来是否属于孙悟空稳定调用对象？
2. 是否被现实夺走？
3. 外援是否真实参与？
4. 外援是否直接恢复了金箍棒这一同对象控制？
5. 最后是谁把金箍棒重新拿回并恢复调用？

答案依次为：是、是、是、否、孙悟空本人。

## 10｜严格 zx↔nx 补关系检查

不锁。

本轮虽然有真实 `nx` 外援关系，但孙悟空在“金箍棒恢复”这一同对象窗口中并不存在一个由 nx 端实际补成的 `zx` 缺口；同时本微阶段 zx 独立端也未成立。

不能写成：

> 孙悟空有 zx + 请了很多神仙 = 严格 zx↔nx 补。

## 11｜与施恩、海瑞案例的边界差异

《水浒传》施恩：

`x丢失 → nx武松直接强制蒋门神交还 → x恢复`

《明史》海瑞：

`x丢失 → nx朝廷正式复故官 → x恢复`

《西游记》孙悟空本例：

`x丢失 → nx外援大量参与危机 → 但同对象x由主体自己取回`

因此新增案例级纪律：

> **判断“nx 是否恢复旧 x”必须检查因果是否直接落在同一被测试对象上。仅有外援参与、甚至外援对整个危机很重要，都不足以把该对象的 x 恢复归因于 nx。**

当前只作为高纯反向控制，不修改理论正本，不新建待审议问题。

## 12｜结论

本轮锁定：

> **孙悟空金箍棒被夺后自行潜入金兜洞取回 = `旧 x 丢失 → nx 外援参与但未恢复同对象 x → 主体自行恢复 x`。**

这是一条“伪 `nx → x恢复`”高纯反例。

不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
