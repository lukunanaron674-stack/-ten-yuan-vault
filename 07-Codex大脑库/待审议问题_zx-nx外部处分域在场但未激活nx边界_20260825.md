# 待审议｜外部对象／处分域在场但未激活 nx 的边界

## 0｜触发原因

连续三部独立作品出现同型结构：

```text
关键对象、处分接口或最终结果域原本真实在主体之外
≠
主体正在沿外部权限接口续接
```

若主体没有请求、借用、等待批准或承认原接口的最终否决位置，而是以自身权能直接压掉原持有者当前处分能力，并使同一结果对象转由自身强制作用改写，则“对象在外部”本身不足以成立 `nx`。

这不是说所有“抢夺”都自动是 `zx`；仍必须独立满足 zx 的公开显权、现实响应与决定范围扩大等条件。

## 1｜三部独立控制

### 1.1 《西游记》孙悟空｜幽冥强取生死簿

- 外部对象/处分域：阴司生死簿与寿命名录处分。
- 主体动作：不申请、不等待十王批准，强令取簿并亲自勾改猴属名录。
- 结果：原阴司处分结果被改写；十王无法维持旧结果，只能向更高系统上奏。
- `nx`：本窄阶段排除，因为主体没有沿阴司许可接口续接。
- `zx`：高显影；生死处分这一新对象域被主体权能公开压入现实。
- 局部 `x`：簿册被夺入当前直接处分边界后，悟空亲自勾改，可进一步检查局部 x。

### 1.2 《水浒传》李逵｜江州劫法场

- 外部对象/处分域：江州官府对宋江、戴宗的人身与死刑执行链。
- 主体动作：不求赦免、不走司法上诉，不承认官府为必须经过的放行接口；直接冲入法场攻击执行节点。
- 结果：处决链被中断，原定终局处分无法按原方向生效。
- `nx`：本窄阶段排除；救援结果不依赖外部批准。
- `zx`：高显影；主体自身强制力公开改变正在生效的终局结果。
- 局部 `x`：不自动成立。李逵没有因此取得稳定司法处分权，因此不能机械复制孙悟空“夺入后局部 x”的后半段。

### 1.3 《三国演义》董卓｜废少帝立陈留王

仓库既有 99/98 `evidence-locked` 案例原本用于 `zx vs x` 边界，本轮只复用其事实链作为第三作品控制，不重新制造人物结论。

- 外部对象/处分域：皇帝废立与朝廷最高政治方向原本不属于董卓既有军队调用边界。
- 主体动作：董卓主动提出废少帝、立陈留王；面对丁原、卢植等反对，以武力与军法威胁压制异议，并继续推进废立。
- 结果：少帝被废、陈留王被立，朝廷最高政治结果被实际重排。
- `nx`：本窄阶段排除。董卓没有向太后、百官或其他更高节点申请废立，也没有把“废不废、立谁”交给外部主体最终裁决。
- `zx`：已锁。原有军权公开越界进入原本不属于他的皇位废立层，并迫使朝廷围绕其方向重排。

这份第三控制与前两份的对象形态不同：前两份偏“具体对象/执行链”，董卓偏“最高政治处分域”。共同变量不是物件形态，而是：**原本外置的关键结果域没有被主体当作必须沿用的外部许可门，而是被主体直接压过并改写。**

## 2｜候选纪律

当前仅形成待审议，不改 L1 或核心卡：

> **外部性只是 nx 的必要背景之一，不是充分条件。nx 还必须证明主体真实沿外部方向、权限、关系或解决接口续接。若主体直接取消原接口当前的否决/处分能力，并以自身权能改写同一结果对象，则优先检查 zx，而不是因为“对象原本在别人手里”重复计 nx。**

最短版：

```text
对象在外 ≠ nx
沿外部接口续接 = nx候选
压掉外部接口并改同一结果 = 优先查zx
```

## 3｜拿掉测试

### 真 nx

拿掉外部许可/资源/处分节点后，主体无法按同一结果对象继续推进；恢复该接口并真实获得批准/借用/放行后，结果才成立。

### 外部在场但非 nx

拿掉“主体获得外部许可”这一假设，原事实链仍能完整解释：

```text
主体自身方向已定
→ 不承认原接口为必须经过的门
→ 直接压掉原接口当前否决/处分能力
→ 同一结果被改写
```

则不能仅凭外部对象或处分域存在判 nx。

## 4｜反向测试

把三例分别改成以下结构时，才明显转向 nx：

- 孙悟空必须先获十王批准，判官依正式许可代为改簿；
- 李逵必须向知府或上级司法节点申请赦免，获批后法场放人；
- 董卓只能提出废立建议，最终必须等待太后/群臣/合法最高节点批准，自己不能压过否决。

共同变化是：

```text
外部节点重新拥有真实否决
+
主体承认并实际沿该接口续接
```

## 5｜最近邻排除

- `nx vs zx`：关键不是对象是不是在别人手里，而是主体最终是否沿该外部接口推进，还是直接压过该接口并扩张自身决定范围。
- `nx vs x`：若权限/资源已经稳定进入主体可直接调用边界，转查 x；但李逵案提醒，瞬时中断外部处分不等于取得稳定 x。
- `nx vs xn`：主体自己设计步骤、调兵或安排节点属于 xn 邻近，不能替代“外部接口是否真实被沿用”的检查。
- `强烈反抗 vs zx`：反抗、暴力、胜负不能单判 zx；必须看到现实结果域、决定范围或秩序位置被主体权能真实改写。

## 6｜第三因素冻结

冻结人物善恶、残暴程度、武力强弱、身份高低、历史评价、主题立场、是否“英雄/奸臣”。只保留：

1. 当前被测试的结果对象/处分域是什么；
2. 原本谁掌握该结果域；
3. 主体是否请求、借用、等待批准；
4. 原接口是否保留真实否决；
5. 主体是否直接取消/压掉该接口的当前处分能力；
6. 同一结果是否被主体自身权能实际改写；
7. 决定范围是否因此上升到原本不属于主体的层级。

三例结论保持不变。

## 7｜与现有待审议的关系

本问题与 `nx权限外置与实际通道激活边界` 相邻，但不是完全同义：

- “权限外置与实际激活”主要问：外部接口存在时，主体有没有真实进入并沿它推进；
- 本问题进一步锁定一个高强度反向结构：**外部处分域虽然在场，但主体不是未激活后停着，而是直接把原接口压掉并改写同一结果。**

因此本文件保留为独立窄问题，避免把“接口未激活”“接口转接”“接口被强制压掉”混成一类。
