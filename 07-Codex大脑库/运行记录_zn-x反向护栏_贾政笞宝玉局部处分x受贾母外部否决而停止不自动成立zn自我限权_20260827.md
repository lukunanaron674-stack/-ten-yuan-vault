# 运行记录｜贾政笞宝玉：现实处分 x 被外部否决限制，不自动成立 zn 自我限权

## 1｜本轮测试问题

火轴当前 `zn vs x` pending-review 已有三部正向控制，并明确需要第二类高纯反例：

> 主体确实拥有现实 `x`，也出现“我不再继续使用这项权力”的结果，但这个限制若主要由外部命令、惩罚压力、现实否决或收益计算造成，能否直接当作 `zn`？

本轮用《红楼梦》第三十三回贾政笞宝玉测试。

本轮只判断“停止继续笞打”是否能作为 `zn` 自我限权证据，不判断贾政整个人物是否存在其他 `zn` 原则。

## 2｜剧情事实

贾政因琪官、金钏等事震怒，对宝玉实施重责。众人劝阻未能立即终止，说明贾政在“父亲训子/当前处分”局部层拥有现实可执行的处分权限。

王夫人介入后，贾政仍一度坚持。贾母到场，公开斥责贾政，并以自己要回南京等方式施加家内最高压力。贾政随后跪下认错，承诺以后不再打宝玉，原处分链停止。

仓库既有木轴记录已经以 99/98 锁定：`local_x_before_veto = true`、`higher_layer_real_veto = true`，并证明贾母的否决能真实改变同一处分结果。

## 3｜对象层

被测 `x`：贾政对宝玉当前家内训子/责打处分的现实执行权限。

被测 `zn` 候选：若有人把“贾政最后停止继续打”解释成“内部原则主动限制自己的处分权”，则需证明停止主要由主体内部不可轻易让渡原则驱动，并通过无奖励/认可、冲突排序和未来指导资格门。

本轮不把“父慈子孝”“光宗耀祖”等宽泛伦理标签自动当作被测 `zn`。

## 4｜x 证据

当前局部处分 `x` 成立：

- 贾政能直接命令并实施责打；
- 处分在贾母介入前已经真实生效；
- 众门客与王夫人的普通劝阻不能立即取代他的局部处分决定；
- 因此这不是“父亲身份”名义，而是现实执行权限。

最短：

```text
x = 当前我确实能处分什么
```

## 5｜zn 检查：为什么“停止”不足以锁自我限权 zn

`zn` canonical 要求内部原则在拿掉认可、制度要求、群体许可与当前利益以后，仍能进入判断，并在冲突中拥有未来指导资格。

本例“停止继续打”的直接因果链是：

```text
贾母到场
→ 公开否定继续重责
→ 家内最高现实压力/否决进入
→ 贾政认错、承诺不再打
→ 原处分停止
```

因此，停止可以由“外部真实否决压入后，主体服从/承接”完整解释。

仅凭结果：

```text
主体原本有 x
→ 后来不再使用 x
```

不足以推出：

```text
内部原则 zn 主动限制 x
```

本轮锁定的是：`zn_self_limitation_from_stopping = false`。

这不等于“贾政没有任何 zn”；只表示本桥段的停止动作不能单独充当 zn 证据。

## 6｜关键压力

关键压力不是宝玉受伤程度，也不是“贾政孝顺”的性格标签，而是：

> 贾母把上位现实否决真正压入同一处分链，并让继续处分的结果停止。

这正好给火轴提供一种与晁盖/唐僧不同的限制机制：

```text
晁盖 / 唐僧：
内部原则进入排序
→ 主体主动限制已成立 x

贾政本轮：
外部现实否决进入
→ 主体停止继续使用局部 x
```

两者表面都像“有权但没继续用”，因果来源不同。

## 7｜拿掉测试

### 7.1 拿掉贾母外部否决

如果没有贾母介入，只保留贾政已成立的局部处分 `x`，原著没有足够证据证明他会在同一节点因为一条内部不可让渡原则自行停止。

因此本桥段的“停止”高度依赖外部否决，不能作为独立 `zn` 证据。

### 7.2 拿掉“停止动作”

即使不使用“后来停止”作为证据，前段局部 `x` 仍然成立，因为处分已经真实执行。

所以：

> `x` 成立与 `zn` 是否成立必须分别取证。

## 8｜反向测试

如果改成：

```text
没有贾母、没有外部惩罚或否决
→ 贾政在继续责打明显更有利于其眼前控制目的时
→ 因自己明确坚持的内部原则主动停止
→ 并在后续类似冲突继续按同一原则限制处分
```

才会显著支持 `zn` 自我限权。

原著当前桥段没有提供这种纯度。

## 9｜最近邻排除

### zn vs z / nx

如果限制主要来自重要他者的现实认可/否决或外部权限位置，应先检查 `z/nx` 等外部关系机制，不能直接写内部 `zn`。

### zn vs x

`x` 回答“当前能不能处分”；`zn` 回答“什么内部原则让主体即使有权也不这样用”。本例前者成立，后者不能由停止动作单独证明。

### x vs zx

贾政前段是在已存在的父亲训子处分边界内执行，不因责打强烈就自动升级 `zx`。

## 10｜第三因素冻结

冻结：

- 贾政严父/孝子评价；
- 宝玉是否该打；
- 贾母是否偏爱宝玉；
- 金钏、琪官前史；
- 家族礼教主题；
- 后世道德评价。

只保留：

1. 局部处分是否真实生效；
2. 外部上位否决是否真实进入；
3. 停止是否主要由该外部否决触发；
4. 是否有独立内部原则跨情境继续限制同一 x。

结论不变。

## 11｜本轮新增边界

> **x 被限制 / 停止使用，不等于 zn 自动成立。必须区分“内部原则自我限权”与“外部命令、惩罚压力、现实否决造成的限权”。**

最短：

```text
有权但没继续用
≠
一定是原则在限制权力
```

这条与孙悟空弃弼马温护栏互补：

- 孙悟空：主动退出真实 x，也不足自动推出 zn；
- 贾政：真实 x 被外部否决限制，也不足自动推出 zn。
