# zx↔nx 压力显影｜宋江高唐州第二作品正向控制

## 0｜本轮目的

本轮不重复增加“宋江高唐州严格补”样本，也不重判宋江稳定人物本体。只检查一个窄问题：

> 同一“破高唐、救柴进”对象层上，主体原有 zx 公开推进被外部专属瓶颈压低后，nx 关系功能是否抬高；瓶颈解除后，原 zx 是否按 zx 自身硬判据重新进入现实。

当前相关 canonical：
- L1：木轴核心变量为“最终方向与作用权来源”。
- zx：自身权能公开进入现实、使秩序响应并扩大决定/影响范围。
- nx：关键方向、权限或解决通道在外，主体真实沿外部接口续接。

本记录不得覆盖 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。

## 1｜剧情事实链

### A｜压力前 / 原 zx 公开推进

宋江已经公开率梁山军马攻打高唐州，当前目标是破城并救柴进。战役方向没有交给外部节点；宋江以主将身份持续传令、调军并让梁山军事行动围绕该方向运行。

### B｜压力进入 / 原直接推进被封

高廉以妖法/神兵形成普通梁山军力无法稳定穿透的专属瓶颈。现有正面军事推进受阻，原来的“靠梁山自身军力继续压过去”不再足以完成同一当前结果。

这里的压力作用是：

```text
宋江的破高唐方向仍在
+
自身公开军事推进的现实入口被专属妖法卡住
→ 当前 zx 的现实推进显影下降
```

不是人物突然失去主见，也不是稳定本体换芯。

### C｜压力窗口 / nx 专业解决接口抬高

为破解高廉妖法，梁山必须进入公孙胜的专属专业能力接口；公孙胜又受罗真人真实许可约束。罗真人先前拒绝时，请援链不能直接完成；后续放行并授法，公孙胜才回到高唐州。

所以当前同一瓶颈层：

```text
专属破解能力不在宋江稳定调用边界
+
许可也不在宋江手里
+
宋江一方真实进入并沿该接口推进
= nx 高显影
```

### D｜压力解除 / zx 按自身硬门复位

公孙胜取得法门回军后，宋江、吴用、公孙胜重新商议破高廉；公孙胜提出军阵方案，宋江“传令”，各寨拔寨直抵高唐州，次日披挂列阵、摇旗擂鼓，再次公开推进。高廉被破、被杀后，宋江收军入城、下令不得伤害百姓，并继续搜救柴进。

因此解压后的复位不是“宋江又能调用原来的兵了”这么松的 `x` 证据，而是：

```text
主体仍占据同一战役最终方向
→ 自身主将权能重新公开进入现实
→ 军队/敌方/城池秩序重新围绕其命令响应
→ 破城救援结果继续向前推进
= zx 硬证据重新出现
```

## 2｜zx 证据

### 压力前
- 最终战役方向由宋江持续占据；
- 公开率军、传令、攻城；
- 梁山军队与高唐州防御体系围绕其军事推进真实响应。

### 压力中
- 方向没有让出，但自身正面军力的现实进入能力被高廉妖法压低；
- 因此记录为 `zx suppressed_not_erased`，不写成人物本体消失。

### 压力解除后
- 宋江重新传令、列阵、公开推进；
- 现实系统重新围绕其主将权能运行；
- 结果从“被妖法卡住”重新推进到破城、收城、救援。

结论：当前 zx 的“现实显影下降→复位”成立。

## 3｜nx 证据

- 高廉妖法的专属破解能力不在宋江稳定 `x` 边界；
- 公孙胜是外部专业解决节点；
- 罗真人对公孙胜下山/授法拥有真实许可位置；
- 梁山真实寻找、请求并接入该外部专业/许可通道；
- 条件补入后才恢复同一战役推进。

所以 nx 是当前压力窗口的真实关系功能，不等于宋江“没主见”。

## 4｜关键压力

关键压力不是“高廉很强”，而是：

> **普通梁山军力无法稳定穿透高廉妖法，使宋江原 zx 的公开军事推进在同一战役对象层失去有效现实入口。**

压力只负责封住入口；nx 成立仍要另证主体真实接入外部专业/许可通道。

## 5｜拿掉测试

### 拿掉 nx 接口

去掉公孙胜/罗真人或等价专属破解条件：
- 宋江破高唐、救柴进方向仍在；
- 但高廉妖法瓶颈仍存在；
- 原公开军事推进无法稳定完成同一结果。

→ nx 是压力窗口中的真实缺口。

### 拿掉“zx 复位”假设

如果破解后只看到宋江恢复对既有部下的日常调用，却没有重新公开传令、攻城并推动战役结果，则最多只能写 `x` 恢复，不能锁 zx 复位。

原文实际给出了“传令→拔寨→列阵→攻城→收城”的公开推进链，所以本例通过复位硬门。

## 6｜反向测试

### 反向 A｜只有 nx、没有 zx 复位

若公孙胜破解后，战役由公孙胜或其他外部节点全程自行完成，宋江只被动跟随，没有重新公开占据并推进战役方向：
→ 只能锁 nx 高显影，不能计完整压力显影正例。

### 反向 B｜只有 x 恢复

若危机后宋江只是重新能调用旧部、休整、维持营地，没有新增公开推进与现实响应：
→ 只记 `x` 恢复，不记 zx 复位。

本例两种反向均不符合原著。

## 7｜最近邻排除

### zx vs x

- 既有主将兵权、能调用梁山军队：`x` 邻近；
- 压力解除后重新公开传令、推进攻城并使现实战役结构重新响应：才是本轮 zx 复位证据。

### nx vs xn

- 派人寻找、传报、安排军阵可有 `xn` 邻近；
- 但“破解能力/许可能否取得”仍在公孙胜/罗真人外部接口，主判 nx。

### 压力显影 vs 严格补

本例已有独立 strict 记录，本轮不重复增加 strict control 数。压力显影只问：同对象层的端点显影是否因压力发生可验证的下降/抬高/复位。

### 压力显影 vs 人物换芯

本轮不锁宋江稳定本体，也不写“宋江从 zx 变成 nx 再变回 zx”。更准确是：

```text
同一战役方向仍在
→ 外压封住 zx 现实入口
→ nx 专业/许可功能高显影
→ 瓶颈解除
→ zx 按自身硬判据复位
```

## 8｜第三因素冻结

可冻结：
- 宋江英雄/反贼评价；
- 高廉善恶；
- 柴进与宋江私人关系；
- 妖法视觉奇观；
- 最终梁山整体命运。

必须保留：
- 同一“破高唐、救柴进”对象层；
- 高廉妖法这个当前命名瓶颈；
- 公孙胜/罗真人外部破解接口；
- 解压后宋江重新公开传令并推进现实结果。

冻结后结论不变。

## 9｜与现有压力显影资产的最小差异

### 正向1｜《西游记》孙悟空五行山
- 自身脱困权能现实入口被封；
- 外部救援 nx 抬高；
- 解压后原 zx 硬证据复位。

### 正向2｜《水浒传》宋江高唐州（本轮）
- 自身公开军事推进被专属技术/妖法瓶颈封住；
- 外部专业能力+许可 nx 抬高；
- 破解后重新公开传令、攻城、收城，zx 硬证据复位。

两者对象域不同（人身封压 vs 战役专业阻断），但测试结构一致。

现有反向护栏继续有效：
- 刘备离许都：对象层不一致，不计正例；
- 曹操华容道：解压后只验证既有 `x` 恢复，不足锁 zx 复位。
