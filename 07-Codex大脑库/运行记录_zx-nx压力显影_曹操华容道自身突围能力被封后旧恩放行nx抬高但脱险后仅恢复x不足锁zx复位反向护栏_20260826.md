# 运行记录｜曹操华容道：自身突围能力被封后旧恩放行 nx 抬高，但脱险后仅恢复 x 不足锁 zx 复位

## 1｜本轮问题

测试木轴压力显影的新门槛：

```text
同一对象层
→ 原本主体可自行推进
→ 强外压封住自身现实入口
→ nx 外部关系/许可成为当前必经门
→ 压力解除
→ 原端是否真的以同一层硬证据复位？
```

《三国演义》第50回华容道非常接近完整正例，但最后一门不足：曹操脱险后确实恢复自身军队指挥与后续行动，却只能高置信锁回既有 `x`，不能仅凭“又能自己指挥了”偷判 `zx` 复位。

因此本轮不增加压力显影正例计数，锁为反向护栏。

## 2｜剧情事实

### 触发

赤壁战败后，曹操率残军连续遭赵云、张飞等截击，进入华容道时已经人困马乏、军力严重衰减。

### 对象

当前只测试一个窄对象层：

> **曹操能否继续通过华容道，完成当前撤退/脱离截杀。**

### 明确动作

1. 关羽率五百校刀手截住华容道，曹军惊惧。
2. 曹操先提出“决一死战”，但部下明确回答人马疲乏，已经难以再战。
3. 程昱提出利用关羽“恩怨分明、信义素著”的既有关系资源，由曹操亲自陈说旧恩，可能获得放行。
4. 曹操接受这一方案，亲自向关羽请求以昔日之情放行。
5. 关羽先以军令回应，不愿徇私；曹操继续援引五关斩将等旧情与信义关系。
6. 关羽最终勒回马、命军士四散摆开，曹操与众将从该许可缝隙冲过。
7. 曹操脱离华容道后继续向南郡前进，遇曹仁军后重新进入自身既有军队指挥/整顿范围。

### 结果

华容道这一窄窗口中，曹操自身残余军力无法稳定强行穿透关羽封锁；真正让“继续撤退”恢复可执行的，是关羽基于旧恩关系作出的实际放行。

文本依据：
- 《三国演义》第50回，Chinese Text Project / 维基文库 / 汉川草庐等版本一致记录“曹军人马疲乏难战 → 程昱建议以旧恩求关羽 → 曹操亲自陈情 → 关羽放行 → 曹操脱险”。

## 3｜zx 判断

### 3.1 华容道当前突破层：不锁 zx

不能因为曹操通常强势、善战、长期掌军，就在本段继续自动记 `zx`。

当前事实是：

```text
曹操想继续撤退
→ 但残余自身军力已无法稳定强行突破
→ 关羽仍真实掌握“放不放过去”的当前否决位置
→ 曹操没有压掉该位置
```

所以“继续通过华容道”这个同一对象层上，当前自身权能进入现实的入口被强压力封住，`zx` 硬门不足。

### 3.2 脱险以后：只能锁既有 x 恢复

曹操脱险至南郡后重新能够：

- 调用自己的将领与残军；
- 安排休整；
- 继续后续军事行动。

但这些首先证明：

> **已有军队/指挥资源重新回到曹操可直接调用的既有 `x` 边界。**

不能从“又能自己下令”直接推出：

> “决定范围新增 / 公开凌驾位置上升 / `zx` 已复位”。

因此：

```yaml
post_release_x_command_recovery: true
post_release_zx_hard_gate: not_proven
```

这正是本轮反向护栏的核心。

## 4｜nx 判断

在“能否通过华容道继续撤退”这一窄对象层，`nx` 高纯成立。

```text
当前通路被关羽封锁
→ 曹操自身军力难以强行突破
→ 程昱指出旧恩/信义关系通道
→ 曹操真实采用该通道并亲自陈情
→ 关羽保留真实否决权
→ 关羽实际放行后撤退恢复
= nx
```

关键不是“曹操求人一次”，而是：

> **同一结果的当前必经许可/关系接口在关羽一侧，而且曹操真实沿这个外部关系接口推进。**

## 5｜关键压力

关键压力是三项叠加：

1. 赤壁战败后的军力损耗；
2. 连续追击导致人困马乏；
3. 关羽在狭窄华容道形成真实封锁与否决。

这些压力共同封住曹操原本依赖自身军力直接突围的现实入口。

但压力本身不等于 nx；只有曹操实际转入“旧恩关系 → 关羽放行”通道以后，当前 nx 才成立。

## 6｜拿掉测试

### 拿掉 nx 外部放行

如果去掉关羽基于旧恩作出的放行，又不给曹操等价外部通道：

- 曹操继续撤退的目标仍在；
- 但残军已难以正面强行突破；
- 华容道当前通行留下明确现实缺口。

说明 `nx` 不是装饰。

### 拿掉曹操通常的强势/军权背景

即使不引用曹操此前的长期权力，只看本段：

```text
自身方案难以执行
→ 真实接入旧恩关系
→ 外部节点放行
→ 结果恢复
```

仍足以独立锁当前 nx。

### 拿掉“脱险后 zx 复位”假设

只保留脱险后重新调动自己军队、进入南郡：

- 剧情仍完整；
- 只用既有 `x` 恢复即可解释；
- 不需要额外假定 `zx` 决定范围新增。

因此完整“zx受压→nx高显影→zx复位”链不能据此锁定。

## 7｜反向测试

### 真正完整压力显影正例应更强

如果脱险后紧接着出现：

```text
曹操重新把原本不属于自己的决定范围公开压入现实
→ 外部秩序被迫响应
→ 与受压前同一 zx 端硬证据重新出现
```

才有资格把后段写成 `zx` 复位。

### 只恢复自主行动的情况

如果只是：

```text
恢复行军
恢复指挥自己原有部下
恢复既有资源调用
```

则优先锁 `x` 恢复，不自动升级为 `zx` 复位。

## 8｜最近邻排除

### nx vs xn

程昱提出“用旧恩陈情”可以视为局部方案建议，但曹操能否过关的核心不是自己搭了一套复杂流程，而是关羽是否放行。

所以主判 `nx`，不是 `xn`。

### nx vs x

关羽的放行权不在曹操稳定处分边界内，曹操不能直接调用，所以不是曹操自己的 `x`。

### zx vs x

脱险后曹操重新调动既有军队，首先是 `x`；只有出现决定范围新增、凌驾位置上升等证据时才重新查 `zx`。

### 压力显影 vs 普通“遇险求人”

本例之所以比普通求人更接近压力显影，是因为：

- 同一“继续撤退/通过华容道”对象层；
- 自身直接突破入口被压力真实封住；
- nx 关系通道成为当前结果的实际恢复条件。

但“解压后 zx 复位”仍不足，因此只能锁近正例护栏，不能凑完整正例。

## 9｜第三因素冻结

冻结：

- 曹操忠奸评价；
- 关羽义气评价；
- 赤壁最终历史胜负；
- 诸葛亮是否故意放曹操；
- 曹操后来的政治结局。

只保留：

1. 同一撤退对象层是否被封；
2. 自身军力是否还能稳定直接完成；
3. 关羽是否保留真实放行/否决位置；
4. 曹操是否真实沿旧恩关系接口推进；
5. 放行后恢复的是既有 `x`，还是新的 `zx` 硬证据。

结论不变。

## 10｜稳定本体 / 当前状态 / 行为功能 / 关系位置 / 外部压力

- 稳定人物本体：本轮不锁曹操为某种固定十元。
- 华容道当前状态：自身直接突围能力被外压压低。
- 当前关系功能：`nx` 高显影。
- 当前行为功能：采用旧恩关系通道取得放行。
- 关系位置：关羽掌握当前通路真实否决/放行权。
- 脱险后：既有军队指挥 `x` 恢复；`zx` 复位未达硬门。

## 11｜本轮新护栏

> **压力解除后“恢复自主行动”不等于 `zx` 复位。若恢复的只是主体原本已经拥有的资源、部下或权限调用，优先判 `x` 恢复；只有同一端重新出现公开显权、决定范围新增或凌驾位置上升等 `zx` 硬证据，才能把完整链写成 `zx受压 → nx高显影 → zx复位`。**

这条护栏与既有刘备反向控制作用不同：

- 刘备护栏：防“不同对象层”误凑压力显影；
- 曹操护栏：防“解压后仅恢复 x”误写成 zx 复位。

两道门共同提高 P7 压力显影研究纯度。
