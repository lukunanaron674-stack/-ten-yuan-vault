# 《水浒传》杨志黄泥冈｜名义提调 x 与现实外部否决后的局部 nx 显影控制

## 1｜本轮问题

此前仓库已经锁定：杨志接下押运任务后，主动否掉原运输方案、重设伪装、人员与行程节点，因此“上级给最终目标”本身不能判 nx，运行层应优先检查 xn。

本轮只切同一回后半段一个更窄微窗口：

> 梁中书已经明文把“一路早行晚行、住歇”提调权交给杨志；但到了黄泥冈真正发生“是否停歇”的冲突时，这块名义权限是否仍然稳定属于杨志的现实 x？

结论：不能只看授权文本。黄泥冈冲突显示谢都管的身份与关系权重能够真实压过杨志，使“停歇”这一具体决定无法按杨志意志生效。因此本微窗口应锁：

- 前置运输/行程设计：xn；
- 名义提调：存在；
- 现实稳定局部 x：在“是否停歇”对象上不足；
- 谢都管真实否决/覆盖后，杨志被迫让渡当前最终决定，局部 nx 关系位置高显影。

不外推杨志稳定人物本体。

## 2｜剧情事实

### 前置授权

杨志在出发前已经明确担心谢都管和两个虞候身份特殊，会与自己“别拗”，并指出一旦如此自己不敢与之争执。梁中书因此当厅吩咐：一路早行晚行、住歇都听杨志，不可别拗。

所以纸面/名义结构是：

```text
梁中书正式授权
→ 早行晚行 / 住歇由杨志提调
→ 表面形成局部指挥 x
```

### 黄泥冈冲突

到黄泥冈，杨志基于强人出没风险，坚持不能停歇，并持续驱赶军健起行。

谢都管却明确要求众人暂歇，并进一步表示自己要坐一坐，让杨志自行先赶其他人。众军汉也集体反抗。原文最后写杨志“无可奈何”。

### 可观察结果

- 杨志的“不得停歇”没有现实生效；
- 谢都管的“停一停”实际成为现场结果；
- 梁中书先前的名义授权未能保证杨志在冲突时稳定拥有最终处分；
- 这不是单纯意见不同，而是现实决定结果发生了覆盖。

## 3｜zx / nx / x / xn 判断

### zx：rejected_as_primary

杨志很强硬，也使用藤条强制军健，但没有出现决定范围扩大：

- 没有取得高于原押运任务的新权限；
- 没有迫使谢都管或梁府秩序承认新增的杨志最高接口；
- 冲突结果反而显示其现场决定被压回。

因此“强硬、打骂、坚持己见”不能判 zx。

### xn：前置运行层成立

此前伪装运输、行军时段、危险路段节奏等都由杨志主动重设，仍然属于明确 xn 高显影。

但 xn 回答的是：

> 怎么设计押运行程？

不回答：

> 冲突时谁最终能让“停/不停”生效？

### x：名义存在，现实稳定性不足

梁中书确实把提调权交给杨志，所以不能说完全没有局部 x 的授权来源。

但在本轮“黄泥冈是否停歇”的窄对象上，真正压力测试结果是：

```text
杨志说不停
→ 谢都管反对
→ 军健随谢都管停下
→ 杨志无法使原决定持续生效
```

因此不能仅凭“名义上归杨志提调”继续锁高纯稳定 x。

### nx：关系位置在冲突窗口高显影

谢都管不是杨志自己设计的节点，而是梁夫人/太师府既有关系体系中的高权重外部人物。杨志出发前已经预判自己“如何敢和他争执得”。

真正冲突时，杨志无法维持自己的停歇决定，并被迫接受谢都管与众人的现实方向。

因此，在“是否停歇”这个具体对象层：

> 主体不再占最终方向，现实行动沿外部既有关系权重所形成的结果续接。

可锁局部 nx 关系位置显影。

这不是说杨志整个押运阶段都变成 nx，也不是推翻前段 xn。

## 4｜关键压力

关键压力不是酷热本身，也不是黄泥冈有强盗。

真正使木轴显影的是：

> 名义授权与现实关系权重发生冲突。

酷热只提供了冲突发生条件；真正需要观察的是：

- 杨志能否让自己的决定生效？
- 谢都管能否在冲突中真实改变结果？
- 名义授权是否足以压住这个外部关系节点？

答案是：不能。

## 5｜拿掉测试

### 拿掉谢都管真实覆盖能力

如果谢都管只是发表意见，但梁中书的授权能让军健仍必须执行杨志“不得停歇”的决定，则本微窗口会重新更接近稳定局部 x。

### 拿掉梁中书名义授权

即使没有那句“都听杨志提调”，黄泥冈现场仍能看到谢都管对结果的现实覆盖；但本轮“名义 x 与真实权限不同”的最小差异价值会下降。

### 拿掉酷热

如果仍发生“杨志要求继续走、谢都管要求停、谢都管方向实际生效”，权限判断仍不变。

所以酷热是触发条件，不是分类支柱。

## 6｜反向测试

### 反向成稳定 x

```text
谢都管反对停歇安排
→ 军健仍必须听杨志
→ 杨志决定直接生效
→ 谢都管只能事后抱怨
```

这种结构才更像高纯局部 x。

### 反向成更纯 nx

如果梁中书从一开始就规定：

```text
停歇必须听谢都管
→ 杨志只能照其决定押运
```

则“是否停歇”这一对象层会更纯地落入 nx。

原文介于两者之间，但现实压力测试明显向后者显影，所以分类置信锁 96，而不是假装 99。

## 7｜最近邻排除

### nx vs xn

- 杨志主动设计运输、行程：xn；
- 黄泥冈冲突中最终必须让渡“停/不停”决定：nx 关系位置显影。

两者属于不同对象层/时间切片，不冲突。

### nx vs x

- 名义授权：支持 x 候选；
- 冲突时真实否决/覆盖：削弱稳定 x，并增强 nx。

因此本轮最重要的纪律是：

> 名义“归我管”不能替代现实压力测试。

### nx vs n

军健疲惫、队伍承载、酷热都可能有其他语义邻近，但不能解释“谁能让停歇决定最终生效”。

### zx vs 强势

强硬表达和使用藤条都不能替代决定范围扩大。

## 8｜第三因素冻结

冻结：

- 酷热；
- 生辰纲最后被劫；
- 杨志性格暴躁；
- 谢都管年龄/身份评价；
- 吴用计谋；
- 谁的风险判断更正确。

只保留：

```text
谁名义上被授予停歇提调？
谁在冲突时真正能改变结果？
主体能否低成本绕过外部节点并稳定让自己的决定生效？
主体是否最终沿外部关系权重形成的结果继续？
```

结论仍为：事实99 / 分类96。

> **“名义上已经授权给主体”不等于该对象层已经稳定成为主体 x。必须做冲突压力测试：当外部关系节点真实反对时，谁的决定能在结果生效前压住另一方？若主体无法让自己的决定生效，并被迫沿外部节点形成的现实方向继续，则该微窗口仍可出现局部 nx 关系位置显影。**
