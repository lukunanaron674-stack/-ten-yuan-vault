# 《三国演义》曹操陈留借卫弘家资｜严格 zx↔nx 补｜正本复核恢复

## 1｜事实链

```text
曹操先有反董、公开起兵方向
→ 曹嵩指出“资少恐不成事”
→ 推荐巨富卫弘
→ 曹操真实请求
→ 卫弘真实同意并出资
→ 曹操发矫诏、招义兵、竖招兵旗
→ 卫弘尽出家财置办衣甲旗幡
→ 公开起兵链落地并扩大
```

## 2｜两端独立成立

### zx

- 反董与公开起兵方向由曹操自身生成；
- 发矫诏、招兵、竖旗与扩张军政影响由曹操公开推进；
- 外部秩序与人员围绕其行动真实响应；
- 决定范围与公开作用位置扩大。

### nx

- 卫弘家资不在曹操原有稳定处分边界；
- 卫弘保留真实同意/拒绝权；
- 曹操必须请求，资源才进入行动链；
- 资金入口不是曹操自己的 xn 排程可以替代。

## 3｜按当前 canonical 补卡做双向拿掉

### nx → zx

拿掉卫弘或等价外部资本：曹操 `zx` 方向仍在，但“资少恐不成事”，启动资本、装备与募兵规模出现直接缺口。

### zx → nx

拿掉曹操把资源转成公开行动、决定与结果推进的 `zx`：卫弘这端仍有资源、仍有外部通道，但只剩“有路径 / 有资源”，缺把借出的资源兑现成公开起兵、军政行动和现实结果推进的**落地权能**。

这正是当前 `zx补nx_补卡` 的明文定义：

```text
zx 补 nx
= 把借到的资源、关系与通道重新转成实际行动、公开决定和结果推进
= 改变 nx 单独运行时“有路径却缺落地权能”的缺口
```

因此：

```yaml

nx_to_zx_gap_filling: true

```

## 5｜最近邻排除

- `zx vs x`：已有资源直接调用是 x；公开起兵与作用范围扩大才锁 zx。
- `nx vs x`：卫弘家资在同意前不归曹操稳定处分，故为 nx。
- `nx vs xn`：募兵、发檄、调练有 xn 邻近，但资源能否进入仍由外部接口决定。
- `普通合作 vs 严格补`：不是“合作成功”就算补，而是两端先独立过门，并分别补同一“起兵落地”瓶颈中的资源入口缺口与落地权能缺口。

## 6｜第三因素冻结

冻结人物善恶、矫诏合法性、后续胜负与魏国结局后，两端和当前瓶颈仍成立。

不能整体删除“启动资本不足”，否则是在删掉测试对象而不是控制变量。
