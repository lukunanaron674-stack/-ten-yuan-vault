# 《三国演义》曹操陈留借卫弘家资｜旧记录纠偏

## 0｜状态说明

本文件原先以事实99 / 分类98锁定“严格 `zx↔nx` 补”。

2026-08-25 在仓库已经形成“严格补必须做双向拿掉；拿掉 zx 后，nx 自身也必须留下不可替代核心缺口”的新方法纪律后，本案例重新压力测试。

重审结论：

```text
曹操 zx：成立
卫弘家资 nx：成立
nx → zx：成立
zx → nx：不成立
严格双向补：撤回
单向补缺：nx → zx
```

详细论证见：

`运行记录_zx-nx严格补关系_曹操陈留借卫弘家资旧严格补经双向拿掉重审为nx到zx单向补缺_20260825.md`

## 1｜保留的事实资产

原事实链保持不变：

- 曹操到陈留后先有反董、公开起兵方向；
- 曹嵩明确指出“资少恐不成事”；
- 卫弘家资不属于曹操既有处分范围；
- 曹操必须真实请求，卫弘可以同意或拒绝；
- 卫弘同意后家资进入行动链；
- 曹操随后发矫诏、招义兵、竖旗，卫弘尽出家财置办衣甲旗幡。

所以本案仍然是一个很好的：

```text
zx 自生方向
+
nx 外部资源接口
+
同一现实瓶颈直接补入
```

材料。

## 2｜撤回的旧子结论

旧记录曾写：

> 拿掉曹操 zx，只剩卫弘有钱，资本不会自动变成反董军队，因此 zx 也补 nx。

按当前更严格的双向拿掉纪律，这个理由不足。

“资本不会自动变成曹操的反董军队”只说明：

> 曹操是共同目标“陈留起兵”的行动转化端。

它不能证明：

> 卫弘 `nx` 这一资源处分接口自身存在一个只有曹操 `zx` 才能补回的核心功能缺口。

卫弘即使没有曹操这一轮 `zx` 高显影，仍然拥有完整的家资处分能力，仍可以决定是否把资源投入其他对象或事业。

因此：

```yaml
nx_to_zx_gap_filling: true
zx_to_nx_gap_filling: false
strict_zx_nx_complement_locked: false
one_way_complement: nx_to_zx
```

## 3｜仍然有效的方法资产

以下观察继续保留：

1. `nx` 直接补掉的是当前“启动资本不足”瓶颈，而不是无关帮助；
2. 资源进入后在同一有效时间窗口被迅速兑现；
3. `nx vs x`：卫弘家资在请求前不归曹操稳定处分；
4. `nx vs xn`：募兵、发檄、调练属于运行组织邻近，不能替代“资金是否能进入行动链”的外部权限判断；
5. `zx vs x`：后续军队稳定归曹操调用后可转 `x`，但公开起兵作用范围形成与扩大仍可检查 `zx`。

## 4｜当前结论

本文件作为历史记录保留，但“严格补第二正向控制”身份已经撤销。

后续任何统计、案例矩阵、cross-work 计数，应以 2026-08-25 的重审记录为准，不得继续把本案计入“真严格双向补”正例。

本次纠偏不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
