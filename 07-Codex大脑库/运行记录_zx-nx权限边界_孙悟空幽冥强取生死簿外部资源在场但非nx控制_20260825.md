# 运行记录｜孙悟空幽冥强取生死簿：外部资源在场但未沿外部权限接口的非 nx 控制

## 0｜本轮问题

现有 nx 正本强调：方向、权限或解决通道在外部，主体不占最终方向，而是沿既有关系、权限、流程或通道续接。

本轮专门测试一个容易误判的结构：

```text
关键对象原本属于外部系统
+ 外部人员实际把对象拿到主体面前
→ 是否自动等于 nx？
```

《西游记》第三回孙悟空闯幽冥、强令十王取出生死簿并自行勾名，提供了高纯反例。

## 1｜剧情事实、触发、对象、动作与结果

### 1.1 触发

孙悟空醉后魂被勾入幽冥界，醒悟后认为自己已经修仙得道、寿与天齐，不应再受阴司拘摄。

### 1.2 对象

本轮锁定对象为：

> **阴司生死名录中“孙悟空及猴属是否继续受阴司寿命记录与拘摄”的处分结果。**

不把“整个天庭秩序”“孙悟空一生反天”混入本轮。

### 1.3 明确动作

原著第三回连续写明：

1. 孙悟空持棒闯到森罗殿；
2. 十王见其凶猛而退让；
3. 孙悟空命十王取生死簿；
4. 十王命判官取出相关文簿；
5. 孙悟空亲自检阅；
6. 命取笔；
7. 亲手把自己及猴属有名者一概勾销；
8. 随后持棒打出幽冥界；
9. 十王不敢相近，只能转向地藏王并准备上奏天庭。

### 1.4 结果

猴属名录被实际改写；阴司原有寿命处分结果无法在当场维持，后续只能转向更高系统处理。

事实置信：99。

## 2｜zx 判断

本阶段锁定为 `zx` 高显影状态，但不据此锁稳定人物本体。

### 2.1 最终方向由主体占据

孙悟空没有接受阴司“你仍受此簿管辖”的方向，也不是在阴司内部请求一个例外许可，而是自己提出：

```text
我不受你们管
→ 把簿子拿来
→ 我自己改掉
```

方向来源明确在主体。

### 2.2 主体权能公开压入现实

- 持棒进入森罗殿；
- 十王和判官被迫响应；
- 原本不属于主体的生死名录处分对象被直接交到其手中；
- 主体亲自改写；
- 原系统无法当场恢复旧结果，只能向更高层上奏。

符合 zx 准度卡：主体自己的力量进入公开现实、外部秩序被迫回应、决定范围从“花果山自有猴王治理”推进到“阴司生死名录处分”这一新对象域。

因此：`zx_stage: evidence-locked`。

## 3｜nx 判断

### 3.1 表面上为什么很像 nx

如果只看表面，会看到：

- 生死簿本来在阴司手里；
- 十王、判官属于外部系统；
- 判官实际从司房把文簿拿出来；
- 孙悟空使用了外部系统已有的簿册和笔。

很容易误写成：

```text
关键资源在别人手里
→ 别人把资源拿来
→ 主体借外部资源办成
= nx
```

### 3.2 为什么本轮排除 nx

现行 nx 不是“碰到外部对象”或“别人做了一个动作”就成立，而是主体必须承认并沿外部已有方向、权限或解决通道推进。

本例中恰恰相反：

1. 十王没有保留最终批准／否决位置；
2. 判官取簿不是主体沿其正常权限流程申请成功，而是在武力威慑下执行孙悟空命令；
3. 孙悟空没有把“是否勾名”的决定交给十王、判官或阴司制度；
4. 生死簿到手后，最终处分动作由孙悟空本人直接完成；
5. 阴司的既有规则方向被主体公开否定，而不是被主体承接。

因此：

```text
外部对象存在
≠ 外部接口被主体承接

外部人员被迫递交对象
≠ 主体沿外部权限通道推进
```

本轮 `nx_current_execution: rejected`。

## 4｜局部 x

需要防止另一个误写：既然 nx 被排除，就把全过程全写成 zx。

更准确的时间切片是：

```text
生死簿原本不归孙悟空处分
→ zx 强制打破原边界
→ 文簿与笔进入其当前直接调用范围
→ 孙悟空亲自勾改
= 局部 x 控制形成
```

这里 `x` 描述的是夺取之后当前对象已经进入主体直接掌握与处分边界；`zx` 描述的是这个边界如何被公开强行扩大进原本不属于主体的新对象域。

二者不可互相替代。

## 5｜nx vs xn 最近邻

本桥段有连续步骤，但没有“主体主动排程、搭长期流程、组织节点持续运行”的强证据。

```text
闯殿 → 取簿 → 检阅 → 勾名 → 离开
```

主要是一次短时强制处分链，不应仅因有步骤顺序就写成 xn。

因此：`xn_neighbor: weak_not_primary`。

## 6｜拿掉测试

### 6.1 拿掉十王／判官的自愿许可

事实链不受影响，因为原著里他们并非自由保留许可并由孙悟空请求通过；相反，是在孙悟空威慑下退让、取簿。

所以“外部自愿批准”不是结果必要条件。

### 6.2 拿掉孙悟空的强制权能

若没有其持棒闯入、压住十王并夺取处分位置，阴司没有证据会主动把生死簿交给他任意改写。

本轮结果链立即留下核心缺口。

这支持 zx，而不是 nx。

### 6.3 拿掉生死簿这一外部对象

则无法以同一方式完成“勾销名录”结果。

但这只能证明外部对象是必要对象，不证明外部权限接口是 nx。对象依赖与权限依赖必须分开。

## 7｜反向测试

### 7.1 真 nx 反向

若改成：

```text
孙悟空请求十王审查
→ 十王保留是否批准删名的真实否决权
→ 十王按阴司规则批准
→ 判官按既有权限代为修改
```

则该执行明显更接近 nx：最终权限与解决通道仍在阴司，主体沿其推进。

原著不是这个结构。

### 7.2 外部对象在场反向

若“只要关键对象原属别人”就自动算 nx，那么：

- 强夺兵器；
- 抢占关隘；
- 夺取印信；
- 强制改写账册；

都会因为对象最初在外部而被错误加上 nx。

这与现行 nx“沿外部方向／权限通道续接”矛盾。

## 8｜第三因素冻结

冻结以下变量：

- 孙悟空是否真的已经跳出五行、理论上应不应死；
- 其修仙身份是否合法；
- 后续天庭如何处理；
- 齐天大圣后来的稳定人物形象；
- 战力高低作为人物标签。

只保留：

1. 生死簿原本属于阴司处分对象；
2. 谁决定是否取簿；
3. 谁保留修改结果前的真实否决位置；
4. 主体是请求沿用接口，还是强制夺取对象；
5. 最终谁亲自改写结果。

结论仍稳定：本轮是 zx 扩权进入新对象域，随后形成局部 x；当前执行不成立 nx。

## 9｜人物本体、状态、行为、关系位置分层

- 人物稳定本体：本轮不新增锁定，避免重复制造“孙悟空整体 zx”的既有结论。
- 当前状态：zx 高显影。
- 行为功能：闯入、强令、夺取、亲改为 zx 行为链。
- 关系位置：孙悟空不承认阴司的最终处分权，而是把其压离最终决定位置。
- 外部压力：魂被勾走和阴司寿命登记触发冲突，但不能单独判十元。
- 局部对象控制：文簿进入手后形成 x。

## 10｜严格 zx↔nx 补测试

不成立。

原因不是 nx 不重要，而是本轮当前执行根本没有独立成立 nx 端。

因此：

```text
zx = true
nx = false
strict_complement = false
```

不能因为“孙悟空 + 阴司外部资源”就制造伪 zx+nx 对子。

## 11｜本轮新增价值

本轮不重复“孙悟空 zx 很强”的旧锚，而新增一个权限／资源判别边界：

> **nx 检查的是主体是否沿外部方向、权限或解决接口续接，不是关键对象是否起初位于主体之外。外部对象即使不可缺，只要主体通过自身权能强制夺取、压掉原持有者的最终否决，并自行处分结果，就不能仅凭“资源来自外部”追加 nx。**

最短式：

```text
对象外置 ≠ nx
接口外置且主体真实沿用 = nx候选
对象被强制夺入自己的处分边界 = 优先 zx→x
```

当前只有《西游记》一份直接高纯控制，不建立新的待审议问题，不改理论正本。
