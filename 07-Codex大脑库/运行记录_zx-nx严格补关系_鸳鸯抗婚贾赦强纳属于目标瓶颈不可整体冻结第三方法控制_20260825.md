# 运行记录｜鸳鸯抗婚：贾赦强纳是目标瓶颈，不得作为“第三因素”整体冻掉

## 1｜本轮目的

本轮不重复制造“鸳鸯 = zx+nx”结论。该阶段已有 99/97 `evidence-locked` 严格补正向记录。

本轮只测试一个方法问题：

> 在严格 `zx↔nx` 补的第三因素冻结中，能不能把“贾赦强纳鸳鸯的现实压力”整体当作第三因素删除，再据此说贾母的 nx 保护接口并不必要？

结论：**不能。** 这样做会把当前命名瓶颈本身删掉，属于改题，不是排除外生干扰。

## 2｜剧情事实

第46回中，贾赦欲纳鸳鸯为妾，先经邢夫人、鸳鸯兄嫂持续游说和施压。鸳鸯多次明确拒绝。贾赦进一步放话：即使鸳鸯将来另嫁，也难逃其手，除非终身不嫁或死亡。

鸳鸯随后主动到贾母面前，当众说明自己绝不从命，并以剪发、终身不嫁等方式把拒绝公开压入现实。贾母得知后震怒，明确否定贾赦取得鸳鸯的要求；随后该强纳方案被现实阻断，贾赦另买妾室。

最小事实链：

```text
贾赦强纳压力真实进入现实
↓
鸳鸯自主拒绝并公开维持“不嫁”方向
= zx 当前状态
↓
但仅靠个人拒绝不足以稳定压掉贾赦的家内强制能力
= 当前现实瓶颈
↓
鸳鸯进入贾母这一上位保护 / 留用 / 阻断接口
= nx 关系功能
↓
贾母实际否决贾赦
↓
同一“被强纳为妾”瓶颈被阻断
```

## 3｜zx / nx 端沿用既有锁定

### zx

本轮不锁稳定人物本体，只沿用当前阶段 `zx`：

- 是否嫁贾赦的最终方向由鸳鸯自己占据；
- 她不把该方向交给邢夫人、兄嫂或贾赦；
- 她公开把拒绝压入现实，并让家内权力结构必须回应。

### nx

本轮沿用“保护 / 现实阻断接口”层 `nx`：

- 鸳鸯不掌握足以稳定压住贾赦的家内最高阻断能力；
- 贾母掌握真实上位保护、留用和否决接口；
- 鸳鸯主动把问题带到贾母面前；
- 贾母实际使用该权限，让强纳方案不能继续按原链生效。

因此是“自己有最终拒绝方向”与“局部现实阻断仍须外部接口”并存，不能把 nx 误写成没主见。

## 4｜关键压力与目标瓶颈

本轮被测的**目标现实瓶颈**不是抽象的“封建社会”“男权文化”或“贾府制度”，而是一个可观察、当前、同层的现实限制：

> **鸳鸯已经明确拒绝，但贾赦仍拥有足以继续推进强纳、威胁其未来婚配和家内处境的现实能力；鸳鸯个人拒绝尚不足以让该强纳链稳定失效。**

贾母 nx 端直接补的正是这个缺口：把鸳鸯的自主拒绝从个人方向，变成对贾赦具有现实阻断力的结果。

## 5｜无效第三因素冻结

若机械地做：

```text
“冻结贾赦强纳压力”
= 设定贾赦根本不想纳鸳鸯
或
= 设定贾赦没有任何继续强迫的现实能力
```

那么当然会得到：

```text
鸳鸯不再需要贾母保护
→ nx 看起来不必要
```

但这个结论没有方法价值，因为被删除的正是：

1. 鸳鸯 zx 当前状态要顶住的现实对象；
2. 贾母 nx 要补的现实缺口；
3. “个人拒绝能否变成现实阻断”的整个测试瓶颈。

也就是说，冻结以后不是“第三因素被控制”，而是题目本身被删除。

## 6｜有效冻结应该删什么

可以冻结：

- 贾赦的人品评价；
- 鸳鸯是否“烈性”；
- 贾母是否偏爱谁；
- 贾府主题、阶级、性别宏大解释；
- 后续贾赦另买小妾这一戏剧结果；
- 读者对强纳行为的道德评价。

只要仍保留：

```text
A. 鸳鸯自己明确拒绝
B. 贾赦仍有现实推进强纳的能力
C. 鸳鸯个人拒绝不足以稳定阻断
D. 贾母拥有并实际使用外部阻断接口
```

zx、nx 与目标瓶颈都还在桌面上，测试才有效。

## 7｜拿掉测试

### 拿掉 nx

拿掉贾母或等价上位阻断接口：

- 鸳鸯“不嫁”的 zx 方向仍在；
- 贾赦的现实强迫 / 威胁能力仍在；
- “如何让拒绝稳定生效”留下明确缺口。

### 拿掉 zx

如果拿掉鸳鸯自己的明确拒绝方向，只保留贾母的一般家内权力，则贾母并不会自动生成“替鸳鸯拒绝贾赦”的同一结果。现有严格补记录已经据此锁过双向不可替代性；本轮不重复计数。

## 8｜反向测试

一个有效的第三因素冻结，必须像这样：

```text
保留鸳鸯拒绝 zx
+ 保留贾母阻断 nx
+ 保留贾赦强纳这个当前瓶颈

只中和某个额外变量 X
→ 检查所谓反向需求是否消失
```

如果 X 一删，连“强纳是否会继续”这个瓶颈都没了，则 X 不是可随意冻结的外生干扰，而是当前测试对象的一部分。

## 9｜最近邻排除

- `nx vs x`：贾母的上位阻断权没有稳定进入鸳鸯直接处分边界，因此不是鸳鸯的 x。
- `nx vs xn`：鸳鸯选择何时当众说明有行动组织，但关键变量仍是外部阻断接口是否掌握在贾母手里，不以 xn 为主。
- `zx vs x`：个人婚姻/身体边界有 x 邻近，但在现实强迫压入后，鸳鸯必须公开把边界重新推回现实，沿用既有“受压复位型 zx 当前状态”锁定。
- `第三因素 vs 目标瓶颈`：能否整体删除“贾赦仍可推进强纳”必须先问：删除后，zx、nx 与当前缺口还剩不剩；本例答案是否。

## 10｜第三因素冻结

冻结以下表面变量后结论不变：

- 强弱、身份、职业；
- 谁更可怜 / 谁更可恶；
- 鸳鸯是否最终终身不嫁；
- 贾母与贾赦的亲疏；
- 贾府宏观制度主题。

真正保留的是同层因果：

```text
自主拒绝方向
+
现实强迫仍可继续
+
个人方向不足以稳定阻断
+
外部上位接口真实阻断
```

## 11｜本轮方法结论

本例成为第三份独立作品“第三因素冻结有效性护栏”控制：

```text
《三国演义》曹操陈留：启动资本瓶颈
《水浒传》宋江高唐州：专属妖法 / 技术瓶颈
《红楼梦》鸳鸯抗婚：强制婚配 / 家内处分瓶颈
```

三种对象域不同，但共同支持：

> **第三因素冻结必须保留被测试的 zx、nx 与当前命名瓶颈；如果冻结直接删除端点、关键缺口或整个任务对象，就不是控制变量，而是在换题。**

当前达到跨 3 独立作品方法复验门槛，可强化现有 pending-review 的方法护栏；仍不得修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
