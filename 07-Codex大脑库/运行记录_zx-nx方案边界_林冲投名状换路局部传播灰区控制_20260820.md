# 水浒传｜林冲投名状换路｜nx↔xn 局部传播灰区控制

## 1｜剧情事实、触发、对象、动作与结果

王伦给林冲的梁山准入条件是：三日内取得投名状，否则不能入伙。第一日林冲按条件下山，从早等到晚，因为没有遇到一个孤单客人而未完成。

第二日林冲再次下山。小喽啰提出改投南山路，两人到林中潜伏等待。午间出现约三百余人的大队，林冲没有贸然下手；其后仍未遇到孤单目标，当晚继续返回梁山。文本还预告第三日将再换到东山路寻找。

因此本轮只观察一个很窄的变化：

```text
执行地点 / 等待路线改变
→ 实际遇到的目标池发生改变
→ 但投名状任务、三日期限、准入规则、成功条件都没有改变
```

## 2｜nx 判断

### nx_actual_continuation_behavior: evidence-locked

林冲没有重设“取得投名状以换取梁山准入”这个外部终点。第一天环境失败以后，第二天仍真实进入同一任务；路线变化只是为了继续寻找符合原成功条件的目标。

因此：

> **局部变量发生变化，甚至带来一层真实下游效果，也不自动使 nx 退出。只要关键外部骨架仍被持续续接，当前行为层仍可保持 nx。**

本轮只锁行为功能，不锁林冲稳定人物本体。

## 3｜xn 判断

### xn_structural_rewrite_in_operational_layer: rejected_as_primary

这一例比“单纯回马、话术、动作顺序”更接近真正灰区，因为换路确实产生了下游变化：

```text
路线位置改变
→ 遭遇对象池改变
```

但传播到此为止，没有继续重绑：

- 任务终点；
- 准入权限；
- 三日期限；
- 成功/失败条件；
- 人员协同关系；
- 资源配置；
- 最终处置路径。

旧方案仍可沿同一骨架运行：

```text
下山
→ 找孤单目标
→ 取得投名状
→ 回寨换取准入
```

因此，本轮压出一个中间档：

> **“发生一层下游传播”仍不足以锁 xn。xn 更需要改动继续传播到关键依赖结构，使旧方案不能再按原决定性骨架运行。**

## 4｜zx 判断

### zx_in_narrow_stage: rejected_as_primary

林冲换路线、继续尝试、面对三百余人选择不动手，都没有使他获得梁山准入权，也没有让王伦或山寨围绕一个新增的林冲决定接口重排。

因此：

```text
主动换路线 ≠ zx
继续尝试 ≠ zx
执行中有判断 ≠ zx
```

本段缺少 zx 所需的公开扩权与决定范围上升。

## 5｜关键压力

压力来自：

- 三日期限仍在；
- 孤单目标由环境提供，主体不能保证出现；
- 第二日出现的是三百余人结队，不符合原任务的低成本可执行条件。

这些压力并没有改变任务骨架，只促使执行层寻找新的地点。

## 6｜拿掉测试

### 拿掉“换南山路”

若第二天仍在原地点等待，只要继续执行“寻找孤单目标取得投名状”，nx 仍成立。说明路线选择不是 nx 的分类支柱。

### 拿掉“遭遇三百余人”

只保留“换路后继续寻找孤单目标”，结论仍然是 nx 保持、xn 不高锁。三百余人只是证明路线改变确实改变了遭遇池，不是分类必要条件。

### 拿掉外部成功条件

如果王伦不再规定投名状与三日期限，只说“你自己想办法证明资格”，然后林冲自行定义目标、资源、步骤与成功条件，才应明显转查 xn。

## 7｜反向测试

### 反向成 xn

如果换路以后，林冲进一步决定：

```text
不再寻找孤单客人
→ 改用另一种资格证明
→ 重配人员 / 资源
→ 改成功条件
→ 让原“杀人取投名状”的流程无法继续
```

则结构传播足以使 xn 显著上升。

### 反向成 zx

如果林冲因条件受阻而公开否定王伦的准入规则，夺取或迫使山寨承认新的准入决定接口，才检查 zx。

## 8｜最近邻排除

### nx vs xn

```text
林冲本例：
路线改变
→ 遭遇池改变
→ 传播停止
→ 原任务骨架仍可运行
= nx 保持，xn 不高锁

马谡街亭：
驻营根节点改变
→ 水源、兵力、协同、成功条件重新绑定
→ 原方案不能按旧骨架运行
= xn 上升
```

所以差别不是“有没有后果”，而是**后果有没有继续传播到关键依赖结构**。

### nx vs x

梁山准入权仍在王伦，不在林冲。

### xn vs zx

重新组织怎么运行属于 xn；获得新的、更大决定范围才属于 zx。本例两者都不足。

## 9｜第三因素冻结

冻结：

- 林冲武力；
- 王伦是否嫉贤；
- 投名状制度是否合理；
- 三百人理论上是否能打；
- 后续是否遇到杨志；
- 后来是否火并王伦。

只保留：

```text
谁给任务骨架？
主体改了哪个变量？
这个改动传播了几层？
是否使关键依赖重新绑定？
旧方案还能否按同一骨架继续？
```

## 10｜结论

- nx 当前实际续接：evidence-locked
- xn 结构重设：rejected_as_primary
- zx 当前扩权：rejected_as_primary
- 局部变化：路线 / 等待地点
- 一层下游传播：遭遇对象池改变
- 关键依赖重绑：未发生
- 旧方案同骨架可继续：true
- 稳定人物本体：not locked
- 严格 zx↔nx 补关系：not locked

本轮最窄新增纪律：

> **零传播当然不足以锁 xn；但“一层局部传播”也仍可能只是 nx 内部执行调整。真正跨向 xn 的更强证据，是改动继续传播到关键依赖结构，并使旧方案不能按原决定性骨架运行。**
