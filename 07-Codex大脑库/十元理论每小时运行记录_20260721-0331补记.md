## 对象分层

- 稳定本体：`zn` 为无奖励仍成立的内部意义，`x` 为对象、资源、权限或关系归我掌握。
- 当前状态：意义确认与取得、守住、调配掌握只是阶段状态。
- 行为功能：坚持、拒绝背弃；占有、调配、划界、保护范围。
- 光影：圣性高光与钥匙、边界、领地只作显影。
- 场景：信仰场所、工厂、档案、土地不能替代端点。
- 时间关系：补位不要求固定先后。
- 关系位置：信念持有者与所有者、管理者不能仅凭称谓判定。
- 显影：观察意义指导资格、掌握用途、归属边界、调配和否决权。
- 动态链：改变本体完整度，不机械生成财富、行动成功或认可。

## 双向端点与被改变变量

### `zn 补 x`

已有 `x`，缺少为何值得这样使用、守护、限制或放弃的内部意义。`zn` 改变掌握用途、保护对象、否决原则及扩张边界。

### `x 补 zn`

已有 `zn`，缺少具体对象、资源、权限和可执行边界。`x` 改变意义的现实落点、可保护对象与“我方边界”。

## 候选机制

1. 意义为掌握定向：已有资源与权限，由 `zn` 决定服务什么。
2. 掌握为意义落地：已有内部意义，由 `x` 提供可守护、调配和持续投入的现实对象。
3. 排除：信念自动制造资源。
4. 排除：拥有资源自动产生意义。

## 正例

1. 《辛德勒的名单》辛德勒中后期：工厂、资金、名单与雇佣权由其掌握，救人意义改变资源用途；拿掉任一端，互补结构均明显残缺。
2. 《V字仇杀队》V：自由与反抗意义为影子画廊、档案、武器和广播入口定向；掌握资源使意义获得现实落点。
3. 家族档案守护者：意义决定档案用途，访问权、储存空间与备份密钥提供现实边界。

## 反例

1. 传教士进入战乱地带：可能是 `zn+xz`，没有 `x` 掌握边界。
2. 有信仰所以募款成功：依赖 `zx/nx/xn`。
3. 富豪捐款换名声：优先检查 `z/x并z`。
4. 只有自由信念、没有对象或权限：只有 `zn`。
5. 地主留地给后代：只有 `x` 与继承安排。
6. 政府按制度保护纪念馆：可能主要是 `xn`。

## 最近邻排除

- 与 `zn 生 n`：后者若成立，改变承载、接收与抗崩；本关系改变掌握用途与意义落点。
- 与 `zn 生 zx`：后者改变公开权能行动；本关系不要求显权。
- 与 `x 克 z`：后者控制认可入口；本关系处理掌握边界服务什么意义。
- 与 `xn`：排期、预算、流程不等于对象和权限归主体掌握。

## 拿掉测试

1. 拿掉 `zn`，资源是否仍以同样方式被保护、使用和限制？
2. 拿掉 `x`，意义是否仍有同等现实保护范围？
3. 拿掉奖励、名声与外部认可，主体是否仍按同一意义使用掌握范围？
4. 拿掉所有权、访问权、调配权和否决权，若只剩借用，则 `x` 不足。
5. 拿掉行动、组织和借力后，互补仍可存在，但不能机械生成行动结果。

## 反向测试

`zn补x` 与 `x补zn` 是同一补位关系的两个观察方向，不是互相生成。`zn` 不自动制造资源，`x` 不自动制造意义。
