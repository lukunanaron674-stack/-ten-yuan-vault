## 源端点、目标端点与变量

### 源端点 nx

- 方向、权限或行动通道已经由他者、关系、流程或现状给出；
- 主体不占最终决定位置；
- 同时不主动认领、复述或代表身份壳要求的立场；
- 排除看穿骗局、公开揭露、主动反抗、价值拒绝、能力不足与被禁止表态。

### 目标端点 x并z

必须是已经成立、且需要主体持续认领、履行、复述或默认承认才能覆盖主体的稳定壳：身份、包装、共同说法、公开角色或表面秩序。

### 被改变变量

- 壳能否把主体纳入身份范围；
- 主体是否完成认领、复述与履行；
- “我们都这样认为”能否成立；
- 壳对主体行为的解释权；
- 壳对特定主体或群体的覆盖范围。

## 候选机制

### 候选A：认领接口缺失

```text
已经成立的身份壳需要主体持续认领或履行
→ nx主体行动上仍沿现成通道推进
→ 但始终不占认领与表达位置
→ 壳无法完成“这也是你的身份／立场”
→ x并z对该主体的吸纳与解释接口下降
```

理论后果：克制对象仅限壳对特定主体的吸纳接口，不等于壳整体被摧毁。

### 候选B：共同背书链中断

```text
共同壳依赖成员形成“大家都这样”的现实
→ 关键成员既不另立旗帜，也不复述、不签署、不允许被代表
→ 共同说法缺少必要背书环节
→ 壳对群体的覆盖范围下降
```

理论后果：可能只是候选A从个人体量扩大到群体体量，尚未证明是第二条独立机制。

### 竞争解释：壳未生成

若身份壳从未成功覆盖主体，只能说明生成条件不足；必须证明壳先成立，随后因持续不认领而失去原有接口，才能谈“克制”。

## 正例候选

1. **《千与千寻》千寻与“小千”身份阶段**：千寻行动上进入油屋流程，却没有完整认领“小千”为全部身份。支持“行动跟随不等于身份认领”，但混入白龙帮助、真名记忆、救父母目标、汤婆婆权能与后期主动选择，不能独立锁定。
2. **《黑客帝国》尼奥与“托马斯·安德森”员工壳**：公司壳最终无法继续解释尼奥，但壳失效发生在真相揭露、墨菲斯引导、特工追捕、主动选择和实际离职之后，不能证明作用源是nx。
3. **组织共同声明中的不背书成员**：身份壳已经成立，成员继续履行日常流程，不另立组织也不公开发动反对，但拒绝签字、复述或允许名字进入“全体一致”声明，使壳只能代表部分成员。结构纯度最高，但缺两个具体人物文本。

## 反例

2. 下属因恐惧签署虚假声明：nx可能上升，壳反而获得接口。
3. 看穿伪装却继续完整扮演：认知变化未改变壳覆盖。

7. 因能力不足无法履行角色：只是状态失败。
8. 主体从一开始就没有加入身份壳：属于生成失败。

5. 拿掉主体原本可以认领的位置后，是否只是没有资格？
6. 拿掉“壳已经成立”这一前提后，是否退化为生成失败？

## 反向测试

```text
x并z 克 nx：
稳定身份壳预先规定主体怎样行动和被读取
→ 可用方向被角色要求限定
→ 主体更沿壳给出的路线推进
→ nx上升
```

正向改变壳的吸纳、代表与解释接口；反向改变主体的可用方向与角色路径。两者不对称，不能互相代证。

## 动态链后果

```text
壳已经说“你也是我们的一部分”
→ 主体行动上仍留在既有流程中
→ 却始终不说“这也是我”
→ 壳对该主体的解释权逐步失效
```

改变的是壳对主体的覆盖资格，不机械生成觉醒、真相曝光、公开反抗或组织整体崩塌。
