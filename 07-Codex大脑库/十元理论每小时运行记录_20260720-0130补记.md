- 稳定本体：不从一次危机领导反推稳定 xz 或 zx 本体；
- 当前状态：危险逼近与临时公开接管是本轮最可能成立层；
- 行为功能：逃跑、反击、冒险与指挥、夺位、公开领路分开；
- 光影：警报、逼近阴影、中心构图和众人转向只作显影；
- 场景：灾难、追杀、战争和指挥现场不能代替端点；
- 时间关系：危险先出现、显权后出现只证明先后；
- 关系位置：必须从被局面规定者转为新的公开决定中心；
- 显影：观察决定范围、服从关系和权能位置是否扩大；
- 动态链：只描述“世界逼我行动”转向“我开始规定世界行动”。

## 源端点与目标端点

### xz 源端点

危险已经可感知地逼近，安全路径、时间窗口或退路真实缩窄，不行动会被吞没。

### zx 目标端点

主体力量公开进入现实，决定范围与影响位置扩大，他者、环境或既有等级围绕其力量重新反应。

### 被改变变量

- 现场最终方向决定权；
- 主体公开权能的可见范围；
- 他者跟随、服从或退位程度；
- 旧秩序的决定资格；
- 主体是否成为新的现实运行中心。

## 候选机制

### A：退路剥夺迫使潜在权能公开

危险封死延后空间，使原本可以隐藏、等待或局部使用的能力被迫公开，主体夺回方向并扩大决定范围。

理论后果：更容易证明显影时点被提前，不足以证明此前不存在的 zx 被生成。

### B：旧秩序失效形成权力真空

临界危险使既有指挥和等级失去反应能力，现场出现决定空位，主体以自身力量接管并让他者围绕其行动。

理论后果：若成立，生成点不在恐惧本身，而在危险制造的关系位置空缺。

### 排除候选

- 普通逃跑、反击和救人；
- 职位本来赋予的指挥；
- `zn 生 zx` 的意义推动；
- xn 应急预案的执行；
- nx 通过既有权限和关系网络借力。

## 正例候选

1. 《疯狂的麦克斯：狂暴之路》弗瑞奥萨在绿洲失效后决定反攻：xz 关闭继续漂流的安全可能，zx 候选表现为公开重定全队方向并改变城堡权力结构；但既有能力、团队信用和潜在领导位置很强。
2. 《釜山行》尚华在感染扩散后的车厢突破：xz 使安全路径缩窄，尚华成为局部公开领路与决定中心；但体能、保护家人的 zn 与临时性很强。
3. 《你的名字。》三叶在彗星坠落前推动疏散：危险与时间窗口明确，但计划、广播、同伴与镇长权限含强 xn、nx 和 x 中介。

## 反例

1. 跟随消防员逃生：主要是 nx。
2. 击倒一名敌人后继续逃跑：只是 xz 行动型子骨。
3. 按既定预案撤离：主要是 xn。
4. 军官按职位下令：既有 x / zx 显影。
5. 因道德确信救人：优先检查 `zn 生 zx`。
6. 群众因恐惧听从最强者：服从结果不等于权能真正扩大。
7. 夺权后才遭追杀：更接近反向链。
8. 危险中表现勇敢但无人跟随、环境未重排：没有 zx 目标端点。

## 最近邻排除

- 与 xz 自身行动层：只有行动改变公开权能位置才进入 zx；
- 与 `zn 生 zx`：区别在意义先启动还是危险先关闭退路；
- 与 xn：计划和分工不等于显权扩权；
- 与 z：被看见和成为焦点不等于凌驾与决定范围扩大；
- 与 x：拥有资源和职位不等于公开显权。

## 拿掉测试

1. 拿掉危险后若主体仍会同阶段公开扩权，xz 不是必要源端点；
2. 拿掉权能位置变化，只剩逃跑、反击、救人或计划成功，zx 不成立；
3. 拿掉他者跟随、退位与环境重排，只剩能力展示，目标端点不足；
4. 拿掉既有能力、职位、计划和意义后 zx 完全消失，说明危险可能只提供显影机会；
5. 恢复旧秩序有效指挥后主体不再占位，支持权力真空是关键中介；
6. 危机结束后权能位置立即归零，只能判状态层。

三个候选均未通过“拿掉既有能力、意义或组织条件后仍能稳定生成 zx”的纯度测试。

## 反向测试

交换为 `zx 生 xz`：公开扩权和夺位可能制造追捕、封锁、敌意和新的危险路径。

方向切口：

- `xz 生 zx` 候选：危险先关闭退路，主体随后公开接管；
- `zx 生 xz` 候选：显权先改变秩序，危险随后反扑。

## 动态链后果

候选机制只改变现实决定中心的位置：

```text
危险逼得我不能再隐藏力量
→ 旧秩序无法继续决定
→ 我把权能推到现实台面
→ 他者开始围绕我行动
```

不机械生成胜利、英雄身份、稳定领导力或人物本体变化。
