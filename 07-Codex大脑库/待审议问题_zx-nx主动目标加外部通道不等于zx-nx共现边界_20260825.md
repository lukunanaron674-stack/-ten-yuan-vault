# 待审议｜主动目标 + 外部通道不等于 zx+nx 共现边界

## 0｜为什么建立

连续三部独立作品出现同型误判风险：

```text
主体自己先有目标
+
主体非常主动、坚持、执行
+
关键权限 / 资源 / 专业方案在外部
+
主体真实沿外部接口推进
```

自然语言很容易把前半段写成 `zx`、后半段写成 `nx`，然后直接得到 `zx+nx`。

现有三部高纯控制表明：**这一步不成立。**

仓库正本要求 `zx` 与 `nx` 分别独立过门：

- `zx` 不是“我有自己的目标”，而是主体自身权能公开进入现实，使他者/秩序围绕其力量重新反应，并出现决定范围、影响位置或凌驾程度的新增；
- `nx` 则可以发生在一个非常有目标、很主动的主体身上，只要当前关键方向、权限或解决通道仍在外部，主体真实沿其续接。

因此：

> **自有目标是 zx 的背景条件候选，不是 zx 本身。主动性、坚持和执行强度也都不能替代 zx 的公开显权与扩权门。**

---

## 1｜第三控制：水浒传｜林冲投梁山｜99/98

### 1.1 剧情事实

林冲在官府追捕压力下，已经有明确的自有目标：寻找长期安身处、进入梁山。

他持柴进荐书到梁山，但梁山成员准入权并不在林冲手里。王伦先明确拒收；经朱贵、杜迁、宋万等劝说后，仍只给出“三日内取得投名状则容入伙，否则不收”的条件。

林冲没有夺取准入权，也没有强迫梁山承认自己已经是成员，而是接受条件，随后连续下山执行。

结构为：

```text
主体已有目标：我要入梁山安身
↓
准入权在王伦
↓
王伦真实拒绝并附条件
↓
林冲实际承接外部条件
↓
成员结果仍取决于外部准入接口
= nx
```

### 1.2 nx 证据

`nx` 在“组织准入许可”对象层高纯成立：

1. 王伦拥有真实可拒绝、拖延、附条件的准入权；
2. 林冲不能单方面让“成为梁山成员”生效；
3. 林冲没有绕过该节点；
4. 林冲真实沿外部条件推进。

这不是“林冲求人一次”，而是关键许可接口当前真实外置。

### 1.3 zx 证据检查

本窄阶段 `zx` 不独立过门。

林冲确实：

- 自己想入梁山；
- 有很强的生存意志；
- 愿意执行高成本投名状条件；
- 武艺高强。

但这些都不是 zx 充分证据。

本段缺少：

```text
主体自身决定接口公开压入现实
→ 梁山准入秩序被迫围绕林冲新增位置重排
→ 林冲决定范围真实扩大
```

后续“火并王伦”属于另一阶段、另一对象层，不能倒灌回来给本段补 zx。

---

## 2｜拿掉测试

### 2.1 拿掉 nx

拿掉王伦或等价外部准入接口，又不给林冲自有梁山成员处分权：

```text
林冲“我要安身、我要入梁山”的目标仍存在
但“我如何成为梁山成员”留下明确制度准入缺口
```

所以 nx 是本段真实关系功能。

### 2.2 拿掉所谓 zx

冻结“林冲目标很明确、很主动、武艺强、愿意完成投名状”等表面 zx 候选，只保留最低限度的“愿意申请加入梁山”：

```text
外部准入权仍在王伦
→ 王伦仍可拒绝/附条件
→ 林冲仍必须沿接口推进
```

nx 核心机制不受破坏。

所以这里不存在一个已经独立过门、拿掉后会让 nx 自身核心功能出现不可替代缺口的 zx 端。

### 2.3 对严格补的意义

现行补卡要求两端独立成立。本例在最前面就失败：

```text
nx：独立成立
zx：本窄阶段未独立成立
→ 不能先写 zx+nx
→ 更不能进入严格补
```

## 3｜反向测试

### 3.1 反向成真正 zx+nx 共现

若同一阶段出现：

```text
A层：林冲真实沿王伦或其他外部准入接口取得某项许可（nx）
同时
B层：林冲公开把自身决定范围推进原本不属于自己的组织权力范围，并迫使梁山结构真实重排（zx）
```

才可以检查 `zx+nx` 共现。

即使两端都成立，也还必须继续检查对象层、同一瓶颈、时间窗口与严格补门槛。

### 3.2 反向成 zx 主导

若王伦拒绝后，林冲当场夺取梁山准入权、改写成员规则，并使旧头领结构服从，则 `zx` 上升、当前许可 `nx` 下降。

后续火并王伦接近这种结构，但那已经是后续阶段，不能倒灌本轮。

### 3.3 反向成 xn

若王伦只给“自行证明资格”的开放目标，而期限、对象、验证流程、路径全部由林冲自己设计，则 `xn` 上升；原著“三日投名状”关键条件由王伦给出，因此本段仍以 nx 为主。

## 4｜最近邻排除

### zx vs 自有目标

```text
我自己知道我要什么
≠
我已经把自身权能公开扩到世界之上
```

自有目标只说明主体不是“没有任何方向”，不能直接推出 zx。

### zx vs 强行动力

主动三顾、主动托关系、主动跑条件、主动求人，都可以发生在 nx 关系功能中。行动强度不是方向/权限来源。

### nx vs xn

别人给定关键许可、期限、条件，主体沿之推进：优先 nx。

主体自己重组人员、资源、时间与流程：才转查 xn。

### nx vs x

当前准入权仍在外部、主体必须重新请求/满足条件：nx。

若准入权已稳定进入主体可直接处分边界：转查 x。

## 5｜第三因素冻结

冻结：

- 林冲悲剧遭遇；
- 王伦人格好坏；
- 林冲武艺强弱；
- 是否最终完成投名状；
- 后续火并王伦；
- 梁山“英雄聚义”主题；
- 角色身份与胜负。

只检查：

1. 主体目标是否先于外部接口存在；
2. 关键许可/资源/方案是否当前外置；
3. 主体是否真实沿该接口推进；
4. 主体是否在当前窄阶段出现 zx 所需的公开显权与决定范围新增。

结论不变。

### 三国演义｜刘备三顾茅庐｜99/98

```text

外部接口：诸葛亮专业战略方案
结果：nx成立；主动求贤与坚持不足以锁zx
```

### 水浒传｜林冲投梁山｜99/98


三例对象完全不同：权势关系链、专业解决通道、组织准入许可；共同变量却一致：

```text
主体自己有目标
+
关键实现接口在外部
+
主体真实沿接口推进
+
当前没有独立的公开扩权事实
=
nx 可高纯成立
但 zx 不得由“主动目标”补出来
```

## 7｜当前候选纪律

### 纪律 A｜两端独立过门是 zx+nx 共现的第0门

在写 `zx+nx` 以前，必须分别证明：

```text
zx：自身权能公开进入现实 + 外部真实响应 + 决定范围/影响位置新增
nx：关键方向/权限/通道当前外置 + 主体真实沿其续接
```

缺一端，就只记录实际成立的一端及最近邻。

### 纪律 B｜“我自己定目标”不能充当 zx

主体拥有自己的最终目标，只能排除某些“纯没主见 nx 本体”解释；不能自动生成 zx 行为/状态。

### 纪律 C｜强主体完全可以单独高显影 nx 关系功能

人物有主见、能打、会组织、很主动，都不妨碍在某个对象层沿真实外部接口推进。

### 纪律 D｜跨阶段不得倒灌

后续出现真正 zx，不得倒灌回此前纯 nx / nx主导阶段，伪造“稳定 zx+nx 始终同时高显影”。

### 纪律 E｜严格补必须在第0门之后

如果 `zx` 本身未独立成立，就无需继续讨论同瓶颈、双向拿掉、时间窗口和第三因素；本例已经在第0门失败。

## 8｜与现有正本的关系

本待审议问题目前**不要求修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`**。

原因是现行文件已经分别写明：

- zx 的核心不是普通行动力，而是权能公开显现、扩大、使外部重新反应；
- nx 关系功能可以发生在强主体身上；
- 补卡要求两端分别独立成立。

本轮新增价值主要是把这些已有原则压成一个跨三作品的**最近邻执行纪律**，防止案例判定时把“主动目标 + 外部借力”机械拼成 `zx+nx`。

结论：

> **主体自己有目标、主动坚持并不等于 zx。若关键权限、资源或专业解决通道仍在外部，主体真实沿其推进，而当前窄阶段没有独立的公开显权与决定范围新增，则可以是高纯 nx 关系功能，而不是 zx+nx。写 zx+nx 前必须先让两端分别独立过门。**
