# 运行记录｜孙悟空红孩儿｜按 current canonical 恢复严格 zx↔nx 补

## 1｜剧情事实

红孩儿摄走唐僧。孙悟空、猪八戒先正面索战；红孩儿以三昧真火击退，四海龙王施雨也不能灭火，孙悟空自身直接路径明确受阻。随后孙悟空亲赴南海请求观音。

观音不是单纯替孙悟空“包办结果”。她提供孙悟空无法稳定调用的净瓶甘露、天罡刀化莲台及收伏能力，并明确要求悟空回去索战，`许败不许胜`，把红孩儿引到她布置的收伏位置。孙悟空领命，公开叫阵、打破洞门、与红孩儿交战并故意败退，把红孩儿引入观音的现实收伏场，之后观音完成收伏，唐僧救援链恢复。

## 2｜zx 证据

本阶段 `zx` 不是“孙悟空很能打”或“是主角”。

- 救师与突破火云洞阻断的当前方向由孙悟空持续占据；
- 他先公开索战并把自身权能压入现实；
- 外部方案接入后，他仍亲自叫阵、破门、交战、诱敌，把条件转成现实推进；
- 红孩儿与火云洞必须围绕其公开行动作出反应。

因此 `zx` 当前状态独立成立。

## 3｜nx 证据

`nx` 只锁在“专属解决能力/高位收伏接口”这一对象层：

- 三昧真火与红孩儿的收伏条件不在孙悟空稳定直接处分边界；
- 四海龙王方案已失败，普通直接路径不足；
- 观音掌握净瓶、天罡刀、收伏与处分能力；
- 孙悟空主动进入这一既有高位权限/解决通道，请求并真实沿其方案推进。

故 `nx` 关系功能独立成立，不反推人物本体没主见。

## 4｜严格补双向拿掉测试

### 4.1 拿掉 nx

去掉观音或等价专属收伏接口：

```text
孙悟空救师/破局方向仍成立
→ 但三昧真火与红孩儿专属阻断仍在
→ 当前直接路径留下明确解决能力缺口
```

所以 `nx → zx` 成立。

### 4.2 拿掉 zx

保留观音的净瓶、天罡刀、法力、收伏路径，但拿掉孙悟空把该路径转成当前现实行动的落地端：

```text
解决路径存在
→ 但缺少把红孩儿从火云洞现实引入观音收伏场的公开行动端
→ 缺少把外部条件兑换成当前救师/取经结果推进的落地权能
```

原文尤其强：观音明确要求悟空“许败不许胜”，由悟空亲自叫阵、交战并把红孩儿引来。这不是“观音能力本体受损”，而正是 current canonical `zx补nx_补卡` 所说的：`nx` 单独运行时“有路径却缺落地权能”。

所以 `zx → nx` 也成立。

## 5｜最近邻排除

- `nx vs xn`：悟空确有欺骗、诱敌与局部策略，但本轮关键解决能力与收伏权限来自观音；执行策略不能抹掉真实 nx 接口。
- `nx vs x`：观音的净瓶、天罡刀与收伏权不归悟空稳定直接调用。
- `zx vs x`：既有战斗能力属于 x 邻近；本轮 zx 锁的是公开救援方向持续占据并把外部方案兑现成现实推进。
- `zx vs 普通战斗`：战斗只是媒介，必须看是否公开改变现实响应与结果推进。

## 6｜反向测试

若孙悟空自己稳定灭掉三昧真火并独立收伏红孩儿，不再需要观音接口，则 nx 明显下降。

若观音完全不需要悟空参与、自己从南海直接完成同一收伏和救师结果，则 `zx→nx` 的“落地权能缺口”会明显减弱，需要重新判断严格补。

原著恰恰相反：观音明确把悟空作为诱敌与现实接入端。

## 7｜第三因素冻结

可冻结：孙悟空主角身份、观音善恶评价、与观音是否熟悉、红孩儿最终成为善财童子、取经宏大主题。

不能冻结：三昧真火造成的当前瓶颈、观音专属解决接口、悟空按方案诱敌这一现实接入动作。把这些删掉是在换题。

## 8｜人物稳定本体 / 当前状态 / 关系功能 / 压力分层

- 稳定人物本体：本轮不新增锁定；沿用仓库中孙悟空 `zx` 主位锚。
- 当前状态：`zx` 救援/破局方向持续成立。
- 关系功能：观音高位解决接口使 `nx` 高显影。
- 行为功能：叫阵、破门、故意败退、诱敌是 zx/xn 邻近执行层。
- 外部压力：三昧真火与专属收伏难度封住单一直接路径，抬高 nx 接口价值；压力本身不等于 nx。
