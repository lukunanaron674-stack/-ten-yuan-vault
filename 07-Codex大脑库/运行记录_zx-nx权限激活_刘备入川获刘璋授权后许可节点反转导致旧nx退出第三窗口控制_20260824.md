# 刘备入川授权节点反转｜nx 激活后退出第三窗口控制

## 结论

本轮不重做刘备“入川援刘璋→夺益州”的人物案例，只抽取一个更窄的权限激活窗口：

> 刘璋最初是真实授权节点，刘备也真实承接入川外援与葭萌关防务，因此前段 `nx` 已实际激活；第62回刘璋从授权者转成限制兵粮、设关阻止、拒绝荆州军继续进入的反向权限节点后，原 `nx` 通道不再可续接。刘备后续行动不能继续沿用“最初刘璋请我入川”的旧 nx 标签。

本例补出第三种 nx 退出机制：

```text
外部节点原本真的开放通道
→ 主体真实承接并执行
→ 外部节点后来撤回/反转许可
→ 旧通道本身失效
→ 主体不再沿该通道推进
= 旧 nx 执行窗口结束
```

## 1｜剧情事实

第60回，刘璋为拒张鲁，接受张松建议，修书结好刘备，并令法正出使、孟达领精兵迎刘备入川为援。第61回张鲁威胁葭萌关时，刘璋进一步明确请刘备前往拒守，刘备领诺并实际进入该任务。

因此前段不是“刘备自行进入益州后顺便帮忙”，而是：

```text
刘璋开放入川/外援/拒张鲁权限通道
→ 刘备接受
→ 实际履行
= nx 激活
```

第62回局势改变。刘备索兵粮后，刘璋只给较少兵粮，并命杨怀、高沛严守关隘；随后刘璋听从黄权等建议，令各关添兵把守，不许荆州一人一骑入关。原授权节点已从“开放通道”转成“封闭通道”。

## 2｜nx 判断

### 前段成立

刘备不能单方面让“受刘璋邀请入川为援、承担葭萌关防务”成为刘璋体系认可的现实关系；刘璋本人拥有是否邀请、是否放行、是否供给、是否让其承担防务的真实权限。刘备实际承接并履行，所以前段 `nx_initial_invited_aid_relation` 锁定。

### 后段退出

第62回以后，旧权限节点不再允许原通道继续：限制供给、严守关口、禁止荆州军继续进入。此时若刘备仍推进，只能重新检查新的 `x/xn/zx` 结构，不能把旧 nx 永久延伸。

因此：

> **nx 曾经成立，不代表外部节点改变立场后仍然成立。**

## 3｜zx 判断

本窄阶段不把“刘备拒绝继续服从刘璋”自动写成 zx。

真正 zx 必须重新独立看到：主体自身权能公开进入现实、原结构真实响应、决定范围扩大。仓库已有后续“攻取益州→自领益州牧”的 99/98 正式案例承担这一部分。

所以：

```text
旧 nx 退出
≠ 自动 zx

旧 nx 退出
→ 重新检查 x / xn / zx
```

## 4｜关键压力

本例压力不是“外部环境更危险”，也不是“方案执行后证明无效”，而是：

> **外部权限节点自身从授权者变成阻止者。**

这使它与已有两例形成三种不同机制：

```text
西游记·孙悟空四海龙王：
方案真实执行，但对目标瓶颈无效
→ nx退出

水浒传·林冲柴进庄：
通道原本有效，但外部搜捕压力使其不可持续
→ nx退出

三国演义·刘备入川：
通道原本有效，但授权节点本人撤回/反转许可
→ nx退出
```

## 5｜拿掉测试

### 拿掉刘璋最初邀请与任务授权

刘备仍可能有入川计划，但本例不再能证明“旧 nx 已真实激活”。所以最初授权是前段 nx 的必要证据。

### 拿掉刘璋后续设关与反转

若刘璋继续欢迎刘备、持续供给并允许其按原关系推进，则不足以锁旧 nx 退出。

### 拿掉刘备后续夺益州

旧 nx 退出仍然成立；只是无法继续讨论后段 zx。因此“nx退出”与“后来是否成功扩权”是两条独立证据链。

## 6｜反向测试

### nx 持续

```text
刘璋继续开放入川/供给/防务接口
→ 刘备继续沿该关系执行
= nx持续
```

### nx 节点反转后退出

```text
刘璋原本开放
→ 后来明确限制、拒绝、封关
→ 刘备不再沿旧许可通道推进
= 旧nx退出
```

### 错误判法

```text
最初是刘璋请刘备入川
→ 所以后面所有益州行动都继续算nx
```

该判法被本例否定。

## 7｜最近邻排除

### nx vs xn

刘备后续怎样组织军队、攻关、调度属于 `xn` 邻近；本例只问旧权限通道是否仍然有效并被主体续接。

### nx vs x

授权完成后，在葭萌关局部已交付的现场军事调用可形成局部 `x`；这不等于旧上位授权通道永久存在。

### nx vs zx

停止沿刘璋通道，只能先锁 `nx` 退出；后续是否 `zx` 必须另做扩权硬门验证。

## 8｜第三因素冻结

冻结刘备仁德/野心评价、张松法正内应、庞统诸葛亮谋略、战争胜负、刘璋性格强弱，只保留：

- 初始外部通道是否真实开放；
- 主体是否真实承接；
- 外部节点后来是否真实撤回/反转；
- 主体此后是否继续沿旧通道推进。

结论保持 99/98。

## 9｜跨作品边界

本例使“nx 激活后仍需持续检查当前通道有效性”首次形成三部独立作品、三种不同失效机制：

1. 《西游记》：方案本身无效；
2. 《水浒传》：外部压力使原有效通道不可持续；
3. 《三国演义》：外部许可节点本人撤回/反转。
