## 双向端点、机制与被改变变量

### xn 补 z

已有 z：认可主体、认可对象与认可位置已经明确，但单次表现不足以证明稳定能力。

xn 补入后改变：

- 被认可内容的证据连续性；
- 能力或作品的重复稳定度；
- 认可者可复核的材料密度；
- 认可从“这次做到了”转成“这确实是你的能力、作品或选择”。

### z 补 xn

已有 xn：时间、训练、流程、信息、记录与资源已经被主动组织，但缺少精神聚焦和阶段收束标准。

z 补入后改变：

- 长期组织的聚焦对象；
- 材料筛选标准；
- 阶段收束节点；
- 哪些成果值得进入呈现；
- 认可后下一周期保留、修正或放弃什么。

## 候选机制

### 候选A：连续证据补认可

```text
z已有重要认可位置
→ 单次呈现不足以确认稳定能力
→ xn形成训练记录、作品序列、实验复现与阶段材料
→ 认可主体可跨时间确认“这确实是你的能力或作品”
→ z的确认稳定度上升
```

理论后果：xn不制造认可主体，也不保证正面评价；它使被认可内容具备跨时间可确认性。

### 候选B：认可节点补组织

```text
xn已经持续组织材料和行动
→ 长期积累缺少精神收束点
→ z明确认可主体、认可内容与确认节点
→ 主体据此筛选材料、安排呈现并结束当前阶段
→ xn的聚焦度与阶段完整度上升
```

理论后果：z不替主体排程；它提供“什么值得被呈现和确认”的精神焦点。

### 排除候选

```text
截止日期逼近
→ 开始冲刺
```

仅能说明任务紧迫、普通状态或 xz 临界，不足以构成 `xn补z`。

- z：弗莱彻及专业现场是否确认其爵士鼓手能力；
- xn补z：长期训练使速度、节拍、耐力和应变可重复出现，认可获得连续证据；
- z补xn：专业认可位置与现场节点让训练从无尽加量转向明确呈现标准；
- 第三因素：存在zx压迫、xz临界与创伤，但不影响互补变量单独识别。

### 《国王的演讲》乔治六世，战时广播阶段

- z：全国听众、王室与乔治本人确认其能否完成公开讲话；
- xn补z：广播能力由偶然成功转为可复现能力；
- z补xn：广播确认节点决定训练材料怎样筛选、何时收束；
- 第三因素：王位身份、战争压力和n承载存在，但端点与变量仍可区分。

## 反例

1. 只有考试日期，没有主体主动组织时间、材料与复盘；
2. 只有冲刺兴奋，没有明确认可主体、认可内容与认可位置；
3. 持续投放只提高曝光或到达率，没有重要认可主体确认；
4. 训练很多但没有任何认可缺口变化；
5. 得到一次表扬，但组织方式、材料筛选和阶段收束均未改变；
6. 按学校课程被动上课，不是主体主动 xn；
7. 截止日期造成恐慌和退路缩窄，更接近 xz；
8. 奖励只让人更努力，不自动构成 z 的精神确认。

## 最近邻排除

- 与 `xn生xz`：xn把偏离变成临界风险，改变的是安全路径与风险；本关系改变的是证据连续性和阶段确认。
- 与 `x并z生z`：可识别壳建立被看见接口；本关系让被认可内容跨时间可复核。
- 与 `x克z`：控制认可入口和归因，使确认无法落回主体；本关系提高确认稳定度。
- 与普通目标管理：目标、截止日期和绩效数字不等于认可主体与认可内容。

## 拿掉测试

1. 拿掉xn连续组织后，若认可仍只依赖一次偶然表现，说明xn补z成立；
2. 拿掉z认可节点后，若训练继续扩张却无法筛选和收束，说明z补xn成立；
3. 拿掉截止日期后，只要连续证据与认可节点仍存在，互补仍成立；
4. 拿掉认可主体与认可内容，只剩冲刺，z端点消失；
5. 拿掉主动组织，只剩被动课程，xn端点消失。

## 反向测试

本关系是补位，不写成互相生成：

- xn不能自动制造认可主体；
- z不能自动生成排程、记录与训练结构；
- 两端必须先至少一端成立，另一端补足其缺口变量；
- 交换书写顺序只改变观察入口，不改变互补关系方向。
