# xz 母行生位一致性纠错协议 v1.0

## 结论

`xz` 的正式生位是 `zx`，不是 `xn`。

```text
xz 生 zx
xn 生 xz
```

因此，`01-十元系统/十元生补克表.md` 中“当前母行生位口径”表的这一行：

```text
xz | xn | nz | xz→xn→nz
```

属于把“被生位 xn”误抄为“生位”的表格错误。现行正确口径为：

```text
xz | zx | nz | xz→zx→nz
```

本协议在该表格完成直接改写前，优先覆盖上述错误行；不得继续用 `xz→xn→nz` 作为现行母行。

## 对象分层

本轮修正只涉及十元几何关系表与三点母行索引，不涉及：

- 人物稳定本体；
- 阶段状态；
- 行为功能；
- 场景与光影；
- 五大主题生成；
- 个案动态链是否实际启动。

几何生位被修正，不代表任何具体人物只要出现 `xz` 就必然生成 `zx`。个案仍须证明作用机制与目标变量。

## 正本核对

### 十元关系表内部互证

现行十元关系表写明：

```text
zx：被生 xz
xz：生 zx
xn：生 xz
xz：被生 xn
```

四项彼此闭合，形成两条不同方向的关系：

```text
xn → xz → zx
```

不能把 `xz 被 xn 生` 反写成 `xz 生 xn`。

### 十元关系词典互证

现行关系词典“生对子”明确记录：

```text
xn 生 xz
xz 生 zx
```

与关系表一致，不支持 `xz 生 xn`。

## 候选机制与最近邻排除

### 候选 A：xz 生 zx

机制候选：漂流、临界或无归属状态迫使对象寻找可执行方向，使原本存在的行动接口被启动或增强。

该机制与现行几何生位一致。

### 候选 B：xz 生 xn

若成立，应表现为漂流状态直接生成规则、秩序、节点或制度压力。但现行正本只支持 `xn 生 xz`，即规则与制度排斥、压迫或切断归属后推出漂流，而非反向。

候选 B 与现行关系表、被生位及关系词典同时冲突，排除。

### 最近邻：xn 生 xz

`xn → xz` 容易在抄表时被误读为 `xz → xn`。两者端点相同但方向相反，目标变量完全不同：

```text
xn → xz：规则改变归属、通行或稳定位置，使漂流增加。
xz → zx：漂流改变行动方向接口，使突破与执行增加。
```

不得因端点相邻而交换箭头方向。

## 正反例

### 正例结构：xz → zx

```text
对象处于持续漂流或临界状态
→ 原有停靠与稳定路径不足
→ 为摆脱悬置，寻找明确方向并开始行动
→ zx 的执行接口被启动或增强
```

这里只能证明阶段关系启动，不自动证明人物稳定本体是 zx。

### 反例结构：只有 xz，没有 zx

```text
对象持续漂流
→ 仍未形成目标、请求、方向或执行步骤
→ zx 未启动
```

这说明几何生位不是自动因果。

### 反例结构：xn → xz

```text
制度、规则或节点限制通行与归属
→ 对象失去稳定位置
→ xz 增长
```

该结构证明的是 `xn 生 xz`，不能拿来为 `xz 生 xn` 作证。

## 拿掉测试

### 拿掉 xz

若对象并无漂流、临界或无归属压力，仍可由其他原因产生 zx，因此具体案例中的 `xz → zx` 不能只凭先后成立，必须证明行动方向是由该漂流压力推动。

### 拿掉 zx

若漂流存在但始终未出现明确行动方向、突破步骤或执行接口，则只保留 xz，不判关系启动。

### 拿掉 xn

若漂流仍由失去停靠、关系断裂或自身迁移造成，则个案可有 xz 而无 xn；因此不能把所有 xz 都倒推为 xn 所生。

## 理论后果

1. 三点母行应改为 `xz→zx→nz`。
2. `xn→xz→z` 保持不变；它属于以 xn 为主十元的母行。
3. `xn→xz` 与 `xz→zx` 可连续形成动态链，但必须分别证明两个作用机制，不能因几何相接自动成立。
4. 不得将 `xz→xn→nz` 用于人物、场景、音乐、叙事或五大主题分析。
5. 本修正不改变命运主题构成 `xz+nz`，也不把十元母行写成五大主题的父子派生。
