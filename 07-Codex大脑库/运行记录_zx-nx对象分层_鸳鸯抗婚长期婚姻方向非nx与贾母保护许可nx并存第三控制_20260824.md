# 鸳鸯抗婚：长期婚姻方向非 nx，与局部保护/许可 nx 可以同时成立

## 1｜剧情事实、触发、对象、动作与结果

贾赦欲纳鸳鸯为妾，先经邢夫人、鸳鸯兄嫂等层层施压。鸳鸯自己明确锁定“不从贾赦”的最终婚姻方向，并进一步表示即使面对其他婚配压力也不改此方向。贾赦随后公开威胁，称她即便将来嫁给别人也难逃其控制。

鸳鸯随后主动把问题带到贾母面前，当众公开拒绝并以剪发表示边界不可撤回。贾母得知后实际行使家内上位留用与阻断权限，否定贾赦取得鸳鸯，并要求鸳鸯继续留在自己身边；贾赦后续未能继续按原强纳路线推进。

最小事实链：

```text
长期婚姻方向：
不嫁贾赦／最终是否接受该婚配
→ 鸳鸯自己占据
= 该层非 nx

局部现实保护：
能否在贾府内部真实阻断贾赦
→ 关键权限在贾母
→ 鸳鸯主动进入该接口
→ 贾母真实否决并使阻断生效
= 局部 nx
```

## 2｜zx 判断

鸳鸯当前 zx 状态独立成立，但不锁稳定人物本体。

支持 zx 的不是“刚烈”或“剪头发”，而是：

1. 最终拒绝方向由鸳鸯自己生成；
2. 邢夫人、兄嫂、贾赦都没有取得该方向权；
3. 鸳鸯把拒绝公开压入现实；
4. 家内权力结构必须围绕这一拒绝事实做出响应。

当前锁：

- `zx_current_state_stage: evidence-locked`

最近邻 `x` 存在：婚姻与身体边界本来属于主体个人边界。但该边界已经被贾赦的现实强迫能力压缩，因此此处更像受压复位型 zx 当前状态，而非无人侵犯时的静态 x 调用。

## 3｜为什么长期婚姻方向层不是 nx

在“我是否嫁贾赦”这一对象层，鸳鸯并没有把最终方向交给贾母决定。

即使没有贾母出场，鸳鸯仍然明确保持：

```text
我不从贾赦
```

所以：

- `long_term_marriage_direction_nx: rejected`

贾母没有替鸳鸯生成“不嫁”的方向；她承担的是让该方向在贾府现实权力结构中获得可执行保护。

## 4｜为什么保护/许可层成立 nx

“鸳鸯自己不愿意”与“贾赦在贾府内部是否真的被阻断”不是同一对象层。

鸳鸯自己不能稳定生成：

- 对贾赦说“不”后让其家内处分真正停止的上位权限；
- 自己继续留在贾母房中的家内留用权；
- 对邢夫人和贾赦形成实际约束的上位家内处分。

这些现实权限在贾母一侧。

鸳鸯做的是：

```text
自己保持拒绝方向
→ 主动把问题接入贾母的家内上位保护/许可接口
→ 贾母真实使用该权限
→ 贾赦强纳链被现实阻断
= nx 保护/许可关系功能
```

所以锁：

- `protection_permission_nx_relation_function: evidence-locked`
- `household_blockade_permission_nx: evidence-locked`

## 5｜关键压力

关键压力包括：

- 贾赦的家长/主子地位；
- 邢夫人与兄嫂的持续施压；
- 鸳鸯个人拒绝不足以天然消除贾赦的现实强制能力。

这些压力本身不能直接判 nx。

真正 nx 证据是：在“让强纳现实停止”这一局部对象层，决定性阻断权限不在鸳鸯本人，而在贾母；鸳鸯实际进入并续接该权限接口。

## 6｜拿掉测试

### 拿掉局部 nx

拿掉贾母真实阻断权限，鸳鸯“不嫁”的最高方向仍存在。

但会重新留下现实缺口：

- 贾赦已经明确威胁继续控制其未来婚配；
- 鸳鸯个人拒绝缺少足以稳定压停贾赦的家内上位权限。

说明保护/许可层 nx 是真功能。

### 拿掉鸳鸯自己的长期拒绝方向

如果鸳鸯自己愿意嫁贾赦，则贾母的保护权限不会自动生成“必须阻断这桩婚事”的主体方向。

所以外部局部权限不能反向覆盖长期方向层。

## 7｜反向测试

### 长期方向也变成 nx

若鸳鸯并无自己的拒绝方向，只是询问贾母是否应该接受贾赦，然后完全按贾母决定执行，则长期婚姻方向层会明显向 nx 上升。

### 局部保护层不再 nx

若鸳鸯自己已稳定拥有足以约束贾赦的家内处分权，能单方面让强纳停止，则保护层应转查 x/zx，而非 nx。

## 8｜最近邻排除

- `nx vs nz`：贾母疼爱鸳鸯可以解释为什么愿意保护，但不能替代谁拥有真实阻断贾赦的权限。
- `nx vs xn`：鸳鸯公开申诉、剪发属于行动策略，不等于她自己搭建了一套多节点保护体系；主变量仍是调用贾母既有权限接口。
- `nx vs x`：贾母的家内最高阻断权不是鸳鸯稳定拥有的权限。
- `nx vs zx`：长期方向自己掌握，并不会把局部保护接口自动变成自己的权限。

本轮最关键分离：

```text
“我最终愿不愿意嫁”
≠
“我当前必须经过谁，让这个拒绝在家内现实中真正生效”
```

## 9｜第三因素冻结

冻结：

- 鸳鸯刚烈/忠贞评价；
- 贾赦道德评价；
- 贾母偏爱程度；
- 剪发行为戏剧强度；
- 后续鸳鸯结局。

只检查：

1. 最终婚姻方向由谁占据？
2. 贾赦强纳形成的现实阻断权限由谁掌握？
3. 鸳鸯有没有真实接入该接口？

结论仍稳定：

```text
长期婚姻方向层：非 nx
局部保护/许可层：nx 成立
```

## 10｜跨作品最小差异

现在三部作品出现同一边界：

- 《三国演义》关羽：最终归刘备/退出方向非 nx；曹操家属供养、安全许可层 nx。
- 《水浒传》林冲：长期逃生/另寻安身方向非 nx；柴进庇护、盘缠、荐书与梁山准入层 nx。
- 《红楼梦》鸳鸯：长期婚姻拒绝方向非 nx；贾母家内保护/阻断许可层 nx。

三例对象完全不同，但同一结构稳定：

> 一个较高对象层排除 nx，不得覆盖另一个较低对象层已经真实成立的局部 nx。
