# 运行记录｜探春理家：局部 x 真实成立，但上位节点仍能越级发动全局抄检，因此不能从“协理”倒灌为整个大观园稳定 x

## 1｜本轮问题

本轮先按 P0 搜索 strict `zn↔x` 正例，但现有候选仍不能同时通过 `zn→x` 与 `x→zn` 的不可替代双向缺口，因此不降低 strict 强门。

转入 P6，测试《红楼梦》探春理家：

> **王夫人已经明确委托探春参与理家，而且探春确实拥有一批现实可生效的日常管理动作；这是否足以推出“整个大观园管理对象层已经稳定进入探春 x”？**

结论：**不能。**

本例比“纯名义授权”更强，因为探春的局部 `x` 不是假的；真正被否定的是从局部现实 `x` 向全局稳定 `x` 的倒灌。

## 2｜current canonical

### `x`

依 `x_准度卡_v0.1`：

> `x` = 对象、资源、地盘、权限或关系进入“归我 / 我方掌握”的边界，主体拥有实际占有、使用、调配、调用、处分或排除能力。

关键不是职位，而是：

```text
被测对象明确
+
权限类型明确
+
同类决定能现实生效
+
不是纯名义 / 一次接触
```

同时，若权限来自别人且原节点仍可撤回、覆盖或在结果生效前越级改写，就必须按对象层重新审计稳定 `x`。

### `zn`

本轮不锁 `zn`。探春的性格、才干、改革倾向、家族责任或对抄检的愤怒，都不能代替内部不可轻易让渡原则的六项硬门。

## 3｜剧情事实链

### 阶段 A｜第55回：王夫人真实委托，但委托范围本来就是分层的

凤姐病中不能理事，王夫人：

- 大事仍由自己主张；
- 家中琐碎事务暂交李纨协理；
- 再命探春合同李纨裁处；
- 后又请宝钗照看，并明确“有想不到的事来告诉我”。

因此第55回本身就没有支持“王夫人把整个大观园最终管理权永久交出”。

但探春后续对若干日常事务、开支与园务改革确实能产生现实结果，所以不能反过来写成“她完全没有 x”。

本轮锁：

```text
日常 / 局部管理 x = 有真实成立证据
全局 / 最终管理 x = 不能由协理名义直接推出
```

### 阶段 B｜第74回：王夫人直接重新进入全局管理链

发现绣春囊后，王夫人没有把“是否全园抄检”交由探春最终裁定，而是：

- 直接召见凤姐；
- 接受王善保家的提议；
- 决定夜间抄检大观园；
- 凤姐明确说自己“奉太太的命来”。

这说明王夫人仍然保有在特殊事件里直接重新进入园务、发出覆盖性全局命令的现实能力。

### 阶段 C｜探春局部抵抗成功，但不能取消整个抄检

抄检队到探春处后：

- 探春允许搜自己的箱柜；
- 明确拒绝搜自己的丫头；
- 凤姐等最终接受这一局部边界，没有继续搜探春丫头；
- 探春甚至掌掴越界拉扯自己的王善保家的。

这说明探春当前不是无权者：

```text
局部房内 / 自身关系边界的 x 或否决能力 = 真实存在
```

但与此同时：

- 王夫人发动的全园抄检并未被探春取消；
- 抄检继续前往其他院落；
- 探春只能对自己这一局部对象层设限。

因此：

```text
local x = true
≠
global stable x = true
```

## 4｜本轮核心裁决

本例正式锁定：

> **真实局部 `x` + 协理/管理身份，也不能自动推出整个组织或任务层已经稳定进入主体 `x`。**

当上位授权节点仍能：

```text
在同一更高对象层直接重新进入
+
发出覆盖性命令
+
使现实节点绕过局部管理者继续执行
```

则必须把 `x` 按对象层拆开。

最短：

```text
局部能管
≠
全局归我
```

## 5｜与杨志反向护栏的差异

### 杨志

- 名义提调与部分现场管理存在；
- 在黄泥冈“是否停歇”的同一决策上，谢都管直接覆盖杨志；
- 因而被测对象层稳定 `x` 不足。

机制：

```text
same-layer decision overridden
```

### 探春

- 日常局部管理 `x` 确实成立；
- 但更高层的全园特殊事件管理权仍由王夫人直接发动；
- 探春只能守住自己的局部边界，不能取消全局命令。

机制：

```text
local x real
+
upper/global scope remains externally overridable
```

两案共同支持：

> **授权后出现真实管理动作，也不能把权限范围向上倒灌；必须逐层验证最终谁能让决定直接生效。**

## 6｜拿掉测试

### 拿掉“协理”称谓

只保留探春现实能裁处部分日常事务、局部命令能生效：

→ 局部 `x` 仍可成立。

所以名义不是局部 `x` 的必要条件。

### 拿掉上位覆盖

如果王夫人此后不能直接进入园务，也不能越级发动全局抄检，所有全园管理决定都必须由探春批准：

→ 全局 `x` 会明显上升。

原著不是这样。

## 7｜反向测试

若一个人物：

```text
有协理身份
+ 有局部管理行为
+ 上位节点在重大事项上仍可随时绕过并覆盖
```

则不能写：

```text
“整个管理对象层已归其 x”
```

只能按实际权限切层：

```text
日常局部 x = on
全局最终 x = off / not locked
```
