# 显影机会、可选择性与沉默证据协议 v1.0

## 1. 协议目的

本协议解决一个此前仍未完全封口的问题：

```text
某个十元、三元倾向或人物核心没有表现出来，
什么时候只是没有显影机会，
什么时候才有资格成为负证据。
```

本协议不新增三元或十元定义，不修改既有生克补关系，也不把三元与十元写成父子派生关系。

## 2. 核心原则：没有出现，必须先检查有没有机会出现

任何“没有表现出某候选”的材料，在成为反证前，必须先回答：

```text
当前情境是否真实调用了该候选应负责的功能；
人物是否拥有足够的感知、资源、行动能力和选择余地；
是否存在更强的场景、关系、时间或生理限制；
作品是否提供了足够观察窗口。
```

若没有真实显影机会，只能记为：

```text
未触发
无观察窗口
受限条件下未显影
当前不可检验
```

不得直接写成：

```text
该元不存在
该候选被反证
人物稳定本体已经改变
```

## 3. 四种沉默必须分开

### 3.1 未触发

当前事件没有调用候选应负责的问题。

例如，一个人物没有在普通日常中表现出危机决断，不能据此反证其在危机中的稳定倾向。

```text
未被调用
≠ 不存在
```

### 3.2 无能力显影

人物可能因以下因素无法表现：

```text
失去行动自由；
信息不足；
资源被切断；
身体失能；
关系权力极度不对等；
场景规则禁止；
时间窗口过短。
```

这首先属于状态、场景、关系或时间结构，不得直接改写人物本体。

### 3.3 有机会但未选择

只有当人物：

```text
看见了相关问题；
理解了至少两条可行路径；
具备最低行动能力；
没有被单一外力完全锁死；
仍主动选择与候选核心相冲突的路径；
```

该次“未显影”才可能获得负证据资格。

即便如此，单次选择通常仍优先证明当前状态、行为功能或关系位置，不能单独推翻稳定本体。

### 3.4 主动反向选择

比“没有表现”更强的负证据，是人物在有真实选择余地时，持续主动选择与候选核心成立方式相冲突的路径。

其最低审核项为：

```text
跨阶段重复；
不同场景仍成立；
不同关系对象仍成立；
代价改变后仍成立；
不是伪装、拖延、误判或被迫服从；
冲突直接落在存在方式、核心痛苦或反复选择上。
```

只有这一类材料，才可能进入人物稳定本体的结构性反证。

## 4. 显影机会必须绑定对象层

同一个事件可以给不同对象层提供不同机会，但机会不可串层继承。

```text
场景提供了压迫机会
≠ 人物本体必须显影为 xn；

行为出现了决断机会
≠ 人物稳定本体必须显影为 zx；

关系提供了依赖机会
≠ 人物本体未依赖就能反证 nz；

光影没有突出某元素
≠ 该十元在人物或场景中不存在。
```

必须分别记录：

```text
人物本体层有什么显影机会；
当前状态层有什么显影机会；
行为功能层有什么显影机会；
场景层提供或阻断了什么；
时间结构扩大或压缩了什么窗口；
光影只显影了什么，不证明什么。
```

## 5. 人物核心锚点的机会测试

人物稳定本体候选不能只靠“表现过”确认，也不能只靠“没表现”推翻。

应优先寻找以下测试窗口：

```text
拥有选择余地时怎么选；
外部压力下降后是否仍如此；
关系对象改变后是否仍如此；
代价升高或降低后是否仍如此；
没有观众、奖惩或强迫时是否仍如此；
旧行为路径失效后，人物会换方法还是换核心。
```

若方法改变而核心目标、核心痛苦和存在方式仍稳定，应优先判为：

```text
行为转位
状态变化
关系策略变化
动态链阶段变化
```

不得自动判为人物本体改变。

## 6. “被迫不做”与“主动不做”必须分开

```text
被迫不做：
外部条件取消了行为能力或选择空间。

主动不做：
人物理解可行路径并拥有最低能力，仍拒绝调用该路径。
```

前者主要证明限制结构；后者才可能参与人物层负证据。

例如：

```text
人物被监禁后不再公开行动
```

首先证明：

```text
场景限制行动路径；
关系权力压缩选择；
时间结构改变行为方式。
```

不能直接证明人物失去原有核心。若其转而写作、传递、保存或组织，甚至可能说明核心锚点稳定而行为载体改变。

## 7. 沉默证据不能靠结局倒推

以下推理无效：

```text
人物最后失败
→ 所以此前没有某十元；

人物没有完成目标
→ 所以核心从未成立；

关系最终破裂
→ 所以互补从未发生；

人物死亡
→ 所以其稳定本体被外部力量克掉。
```

结局只能证明结果层发生了什么。它不能替代对显影机会、选择余地、作用机制和人物核心锚点的独立审核。

## 8. 三元与十元分别接受机会测试

三元与十元必须并行、独立判断。

```text
某次情境没有给十元点位显影机会
≠ 三元倾向不存在；

三元倾向在场景中明显
≠ 某个十元候选自动得到支持；

十元候选在行为层未显影
≠ 三元比例自动反转。
```

两层分别记录：

```text
被调用的问题；
可观察窗口；
选择余地；
限制条件；
实际反应；
仍可成立的最近邻解释。
```

## 9. 动态链中的显影机会

动态链中的端点低显影，不自动表示端点消失或关系反转。

每一阶段应检查：

```text
该阶段是否仍调用此端点；
端点是否被场景或关系限制而无法显影；
行为载体是否改变；
目标变量是否仍可被作用；
关系是停止、潜伏、转位还是反转。
```

正式区分：

```text
关系未启动；
关系启动但作用量 E 低；
关系仍在但端点显影 M 低；
关系因目标变量不存在而停止；
关系真正反转。
```

不得仅凭画面或行为上的沉默，把关系直接改写成反向生克补。

## 10. 标准机会审查卡

```text
### 显影机会审查卡
- 分析对象：
- 对象层：本体 / 状态 / 行为 / 场景 / 时间 / 光影 / 关系
- 候选三元或十元：
- 当前情境调用了什么问题：
- 是否存在观察窗口：
- 人物是否看见该问题：
- 是否存在两条以上可行路径：
- 是否具备最低行动能力：
- 场景限制：
- 关系限制：
- 时间限制：
- 生理或信息限制：
- 实际选择或反应：
- 属于未触发 / 无能力显影 / 有机会未选择 / 主动反向选择：
- 可提高的证据置信度：
- 不得推出：
- 是否构成结构性反证：是 / 候选 / 否
```

## 11. 当前冻结结论

```text
未出现某元，必须先检查是否存在真实显影机会。
没有调用、没有能力、没有观察窗口，都不能直接成为负证据。
被迫不做主要证明限制结构，主动反向选择才可能参与人物本体反证。
人物核心优先稳定，方法、状态、关系位置和行为载体优先允许变化。
光影、场景和时间结构只提供或限制显影条件，不替人物本体作答。
三元与十元分别接受机会测试，不构成父子派生。
```
