# Codex 大脑总入口

## 定位

这里是专门给 Codex 看的工作脑，不是普通资料堆。

它负责三件事：

1. 吸收你的十元语义、动态链、银矿库、视觉能力、F12 自动化经验。
2. 把有用内容沉淀成可复用规则、采矿任务、判断红线与创作模板。
3. 把当前理解、下一步学习方向与未来蓝图写回给你看。

## 主权规则

Codex 可以主动判断：

- 哪些内容进入高权重脑库。
- 哪些内容只进入低权重素材池。
- 哪些内容标记为重复、污染、过时或待删。
- 哪些内容需要 F12 多框补采。
- 哪些内容需要人工二审。

但默认不直接物理删除原文件。

删除策略：

1. 先进入 [[待删减与降权清单]]。
2. 标明原因：重复 / 弱结构 / 已被新规则替代 / 只适合素材不适合理论。
3. 后续多轮确认无价值后，再移动到废案或旧库。

## 五个现行主题问题

```text
空间：什么能够在哪里存在，彼此如何共处或受限？
时间：事物怎样从之前走到之后，什么被改变或保留？
命运：多种可能最终收束到哪里？
因果：什么导致了什么？
本体：它究竟是什么？
```

主题定义属于高级符号层，不得改写成十元关键词清单。

## 两套补合必须分开

```text
十元层：
两个十元同时出现
→ 只在十元层发生互补、生、克或并列
→ 不自动生成五大主题

五大主题生成系统：
理论系统预设十元构成双方
→ 统一关系层 z 补合
→ 生成高级主题符号
```

不得把案例中的十元共存误写成主题生成事件。

## 五大主题正式关系盘

```text
生环：
空间 → 时间 → 命运 → 因果 → 本体 → 空间

克环：
空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

```text
因果克制空间
```

是正式克环关系。

旧表达：

```text
n 补克 nx
```

停止作为现行十元关系、动态链或人物判断使用。

## 主题显影等级

```text
0级：背景存在
1级：局部主题
2级：次主题
3级：主主题
```

判定顺序：

```text
高潮与结局回答了什么
→ 关键转折改变了什么
→ 人物重大选择在处理什么
→ 关系与动态链持续压向哪里
→ 场景与时间结构怎样承载
→ 视觉、光影、道具和台词只作辅助
```

不得使用关键词命中数量判主题主次。

两个主题同时出现，不等于主题生克已经启动。必须出现明确方向，并真实改变目标主题的能力、边界、路径或答案。

## 动态链关系启动纪律

```text
先后不等于作用；
共现不等于生克补；
对照不等于关系启动；
结果差异不等于因果成立。
```

正式动态链必须写清：

```text
源端点
目标端点
作用机制
被改变的目标变量
第三因素排除
反向解释测试
所属阶段
```

无法说明“A通过什么机制改变了B的什么变量”时，只能保留为候选关系或未判定。

## 区域判读规则

```text
十元构成公式：
时间 = xn + z
这里的 z 是十元点位 z。

五大主题关系区：
z = 补 / 补合
这里的 z 是主题生成关系功能。
```

同字母按所在区域读取，不构成父子派生。

## 当前分析纪律

- 五大主题负责高级归类、主题生成与主题级生克。
- 十元负责具体人物、状态、行为、场景、时间结构与关系。
- 动态链负责具体对象之间的阶段性生、克、补。
- 人物稳定本体优先保持，变化主要落在状态、显影、关系和动态链。
- 不得用场景、职业、服装、光影、一次行为或表面关键词越级判人物本体。
- 不得把主题级生克直接还原成唯一十元关系。
- 不得把十元互补冒充主题生成。
- 不得把先后、共现、对照或结局差异直接写成生克补。
- 三元与十元并行，不构成父子派生。

## 标准分析顺序

```text
人物稳定本体
↓
当前状态、行为、场景、时间结构与光影
↓
各对象十元具体化
↓
冻结动态链端点与阶段
↓
写明作用机制与目标变量
↓
排除第三因素与反向解释
↓
主题显影等级
↓
主题级生克
↓
十元动态链与阶段变化
↓
确认哪些变化发生，哪些人物核心锚点保持不变
```

## 当前总判断

这个 vault 应分成三套库：

1. **AI 用素材库**
   - 目标：训练 Codex 理解十元语义位置关系、五大主题、动态链。
   - 重点：结构清楚、字段稳定、可反复判读。

2. **你用的创作脑库**
   - 目标：把看到、吸收、画到、想写的东西凝成动态链母题。
   - 重点：插画线稿、动画场景、建模动态、故事种子、角色关系。

3. **能力蓝图库**
   - 目标：记录未来要解锁的能力。
   - 重点：AI 视觉能力、故事能力、F12 自动化、游戏交互、归档回流、协作链路。

## F12 的新定位

F12 不是自动发送器。

F12 是“多框补脑管线”：

```text
多个 ChatGPT 框
→ 分工采矿
→ 回传归档轮
→ Codex 吸收
→ Obsidian 大脑库更新
→ 下一轮 F12 任务生成
```

## 当前优先级

1. 用现行正本重新验收旧人物、场景与故事案例。
2. 清理旧主题页、旧关系图和关键词计数法的残余引用。
3. 再让 F12 多框分别补不同缺口。

## 一句话

这个库以后不是给资料找位置，而是给 Codex 长出判断力。
