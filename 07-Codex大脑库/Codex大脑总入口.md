# Codex 大脑总入口

## 定位

这里是专门给 Codex 看的工作脑，不是普通资料堆。

它负责三件事：

1. 吸收你的十元语义、动态链、银矿库、视觉能力、F12 自动化经验。
2. 把我认为有用的内容沉淀成可复用规则、采矿任务、判断红线、创作模板。
3. 把对你有用的“我当前怎么理解、下一步该练什么、未来蓝图是什么”写回给你看。

## 主权规则

Codex 可以主动判断：

- 哪些内容进入高权重脑库。
- 哪些内容只进入低权重素材池。
- 哪些内容标记为重复、污染、过时、待删。
- 哪些内容需要 F12 多框补采。
- 哪些内容需要你人工二审。

但默认不直接物理删除原文件。

删除策略：

1. 先进入 [[待删减与降权清单]]。
2. 标明原因：重复 / 弱结构 / 已被新规则替代 / 只适合素材不适合理论。
3. 如果后续多轮都无价值，再移动到废案或旧库。

## 当前语义优先级

涉及三元、十元、五大主题与动态链接口时，优先读取：

```text
五大主题与十元分层接口协议 v0.3
```

区域判读规则：

```text
十元构成区：
时间 = xn + z
这里的 z 是十元点位 z。

五大主题关系区：
z = 补 / 补合
这里的 z 是关系功能。

两个区域同字母，不是同一个对象。
先看所在区域，再读符号。
```

核心顺序：

```text
十元构成双方分别成立
→ 在五大主题关系区由 z 补合双方
→ 五大主题形成高级符号
→ 主题之间再观察 n 生与 x 克
→ 十元与动态链负责具体化
```

不得把“三元与十元并行”误写成父子派生，也不得从主题名称直接倒推人物本体或唯一十元对子。

## 当前总判断

这个 vault 应分成三套库：

1. **AI 用素材库**
   - 目标：训练 Codex 理解十元语义位置关系、五大主题、动态链。
   - 重点：结构清楚、字段稳定、可反复判读。

2. **你用的创作脑库**
   - 目标：把你看到、吸收、画到、想写的东西凝成动态链母题。
   - 重点：插画线稿、动画场景、建模动态、故事种子、角色关系。

3. **能力蓝图库**
   - 目标：记录未来要解锁的能力。
   - 重点：AI 视觉能力、故事能力、F12 自动化、游戏交互、归档回流、协作链路。

## F12 的新定位

F12 不是自动发送器。

F12 是“多框补脑管线”：

```text
多个 ChatGPT 框
-> 分工采矿
-> 回传归档轮
-> Codex 吸收
-> Obsidian 大脑库更新
-> 下一轮 F12 任务生成
```

## 当前优先级

1. 先让 Codex 能稳定读懂十元语义和五大主题。
2. 再让 F12 多框分别补不同缺口。
3. 最后把输出分成“给 Codex 的脑库”和“给你看的报告库”。

## 一句话

这个库以后不是给资料找位置，而是给 Codex 长出判断力。
