# Codex 大脑总入口

## 定位

这里是专门给 Codex 看的工作脑，不是普通资料堆。

它负责三件事：

1. 吸收你的十元语义、动态链、银矿库、视觉能力、F12 自动化经验。
2. 把我认为有用的内容沉淀成可复用规则、采矿任务、判断红线、创作模板。
3. 把对你有用的“我当前怎么理解、下一步该练什么、未来蓝图是什么”写回给你看。

## 主权规则

Codex 可以主动判断：

- 哪些内容进入高权重脑库。
- 哪些内容只进入低权重素材池。
- 哪些内容标记为重复、污染、过时、待删。
- 哪些内容需要 F12 多框补采。
- 哪些内容需要你人工二审。

但默认不直接物理删除原文件。

删除策略：

1. 先进入 [[待删减与降权清单]]。
2. 标明原因：重复 / 弱结构 / 已被新规则替代 / 只适合素材不适合理论。
3. 如果后续多轮都无价值，再移动到废案或旧库。

## 当前语义优先级

涉及三元、十元、五大主题与动态链接口时，优先读取：

```text
五大主题与十元分层接口协议 v0.4
五大主题生克盘 v1.0
```

## 两套补合必须分开

```text
十元层：
两个十元同时出现
→ 只在十元层发生互补、生、克或并列
→ 不自动生成五大主题

五大主题生成系统：
统一关系层 z
+ 系统预设的十元构成双方
→ 生成高级主题符号
```

不得把案例中的十元共存，误写成主题生成事件。

## 五大主题正式关系盘

```text
生环：
空间 → 时间 → 命运 → 因果 → 本体 → 空间

克环：
空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

其中：

```text
因果克制空间
```

是正式克环关系。

旧表达：

```text
n 补克 nx
```

停止作为现行十元关系、动态链或人物判断使用。

## 区域判读规则

```text
十元构成公式：
时间 = xn + z
这里的 z 是十元点位 z。

五大主题关系区：
z = 补 / 补合
这里的 z 是主题生成关系功能。
```

同字母按所在区域读取，不构成父子派生。

## 当前分析纪律

- 五大主题负责高级归类、主题生成与主题级生克。
- 十元负责具体人物、状态、行为、场景、时间结构与关系。
- 动态链负责具体对象之间的阶段性生、克、补。
- 人物稳定本体优先保持，变化主要落在状态、显影、关系和动态链。
- 不得用场景、职业、服装、光影、一次行为或表面关键词越级判人物本体。
- 不得把主题级生克直接还原成唯一十元关系。
- 三元与十元并行，不构成父子派生。

## 当前总判断

这个 vault 应分成三套库：

1. **AI 用素材库**
   - 目标：训练 Codex 理解十元语义位置关系、五大主题、动态链。
   - 重点：结构清楚、字段稳定、可反复判读。

2. **你用的创作脑库**
   - 目标：把你看到、吸收、画到、想写的东西凝成动态链母题。
   - 重点：插画线稿、动画场景、建模动态、故事种子、角色关系。

3. **能力蓝图库**
   - 目标：记录未来要解锁的能力。
   - 重点：AI 视觉能力、故事能力、F12 自动化、游戏交互、归档回流、协作链路。

## F12 的新定位

F12 不是自动发送器。

F12 是“多框补脑管线”：

```text
多个 ChatGPT 框
-> 分工采矿
-> 回传归档轮
-> Codex 吸收
-> Obsidian 大脑库更新
-> 下一轮 F12 任务生成
```

## 当前优先级

1. 先让 Codex 能稳定读懂十元语义和五大主题。
2. 再让 F12 多框分别补不同缺口。
3. 最后把输出分成“给 Codex 的脑库”和“给你看的报告库”。

## 一句话

这个库以后不是给资料找位置，而是给 Codex 长出判断力。
