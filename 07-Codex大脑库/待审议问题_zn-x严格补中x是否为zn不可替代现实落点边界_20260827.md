# 待审议｜strict zn↔x 中 x 是否为 zn 不可替代现实落点的边界

## 1｜触发条件

在同一 criterion_version 下，strict `zn↔x` 压力测试已经出现 3 部独立作品的高置信反向护栏，并新增一份不同 `x` 类型的同作品生命周期旁证：

1. 《三国演义》关羽·挂印封金，99/97。
2. 《水浒传》晁盖·梁山劫掠处分，99/98。
3. 《西游记》唐僧·三打白骨精 / 草寇事件，99/97。
4. 《三国演义》严颜·巴郡守城→城失被擒，99/97；主要新增用途是首份火轴生命周期控制，同时提供“稳定领地/守城军政处分 `x` 真实失去后 `zn` 仍持续”的反向旁证。

前三案已经足以达到 L4 `pending-review` 门槛；严颜不增加跨作品数，但扩大了 `x` 类型覆盖，并提供真实发生的 `x` 丢失测试。

共同满足：

```text
zn 独立成立
+
x 独立成立或曾真实成立
+
zn → x 缺口成立
但
x → zn 缺口不成立
```

不得自动修改 current canonical。

## 2｜候选边界

> **`x` 能帮助、扩大、便利或强化 `zn` 的现实执行，不等于该 `x` 在 strict 意义下构成 `zn` 的不可替代现实落点。**

strict `x→zn` 必须进一步证明：

```text
拿掉被测 x
→ zn 仍成立
但重新出现可命名现实缺口，例如：
   - 没有现实对象可指向
   - 没有可保护 / 可守护对象范围
   - 没有明确“我方”边界
   - 没有任何主体自身行为、其他关系或其他现实对象可继续承载该原则
```

如果原则仍能通过其他既有对象、关系、行动或主体自身行为稳定落地，则只允许：

```text
zn+x co-occurrence
+
zn→x 单向补
```

不能锁 strict `zn↔x`。

## 3｜负控制

### 3.1｜关羽｜曹赐资源不是旧义唯一现实落点

- `zn`：刘备旧盟/旧义；
- `x`：曹赐金银、侯印、赤兔马等现实掌握对象；
- `zn→x`：旧义给资源提供保留/让渡与使用标准；
- `x→zn`：不成立。拿掉这些曹赐资源后，旧义仍可通过归刘、护送二夫人、离曹寻找刘备等现实行动稳定落地。

### 3.2｜晁盖｜山寨处分权不是“不伤无关者”原则唯一现实落点

- `zn`：不可任意伤害无关客商/百姓；
- `x`：山寨人马、行动和战利品处分边界；
- `zn→x`：原则限制武力/处分 `x` 的使用边界；
- `x→zn`：不成立。拿掉山寨处分权后，原则仍能指向客商、百姓并约束晁盖自身行为。

### 3.3｜唐僧｜师徒处分权只是原则的一条执行接口

- `zn`：不可轻率伤害人命；
- `x`：对孙悟空师徒关系的紧箍、留用、逐退等现实处分/约束权限；
- `zn→x`：原则给处分 `x` 提供惩戒、保留和终止标准；
- `x→zn`：不成立。拿掉该关系处分权后，原则仍能约束唐僧自己的判断、其他关系和其他现实生命对象。

### 3.4｜严颜｜巴郡守城处分 x 真实失去后 zn 仍持续

- `zn`：不可因敌军武力、死亡威胁而屈膝归降；关系改变必须重新经过主体自身价值判断；
- `x`：严颜对巴郡守城军力、城门与防御行动的现实调配/处分边界；
- 压力前 `x` 真实成立；张飞破城、生擒严颜后该 `x` 真实断开；
- 在 `x` 已失的情况下，严颜仍拒绝威逼屈降，说明原巴郡 `x` 不是该 `zn` 的不可替代现实落点；
- 张飞撤销威逼、改以义礼相待后，严颜才自愿归附，显示原则不是简单“永不加入任何人”，而是继续规定可接受关系改变的条件。

这份材料主要登记为 `lifecycle-control`：

```text
x 成立
→ x 真实失去
→ zn 仍持续
→ 关系条件改变
→ zn 继续决定新的可接受边界
```

## 4｜共同结构

当前 `x` 类型覆盖已经包括：

```text
关羽：资源 x
晁盖：组织武力 / 处分 x
唐僧：关系处分 / 约束 x
严颜：稳定领地 / 守城军政处分 x
```

共同反向结果仍是：

```text
x 对 zn 有现实作用
≠
x 是 zn 唯一或不可替代的现实落点
```

严颜进一步给出了真实发生的拿掉：

```text
原 x 不是“假设拿掉”
而是实际失去
→ zn 仍能通过主体自身选择与新的现实冲突继续落地
```

因此 strict 反向门应优先检查“不可替代现实落点”，不能只检查“是否有帮助”。

## 5｜反误判护栏

- 原则保护谁 ≠ 谁必须进入主体 `x`。
- 原则评价谁 ≠ 谁必须进入主体 `x`。
- `x` 扩大原则执行范围 ≠ `x→zn`。
- `x` 提高原则执行效率 ≠ `x→zn`。
- `x` 给原则一个额外行动接口 ≠ `x→zn`。
- “没有这个 x，当前这件事更难” ≠ “没有这个 x，zn 没有现实落点”。
- `zn+x` 共现不得自动升级 strict。
- **`x` 已真实失去而 `zn` 仍继续排序，是反驳“该 x 为不可替代现实落点”的高价值生命周期证据。**
- 原则后续允许关系改变，不等于原则消失；先检查它是否只是重新定义了可接受改变的条件。

## 6｜与 current canonical 的关系

本待审议不改写 `zn补x_补卡_v0.1`，只提出一个证据门：

> current canonical 所说的“`x` 给 `zn` 补现实落点 / 可保护对象范围 / 明确我方边界”，在 strict 统计时应证明该缺口真实且不可由主体自身行为、其他对象或其他关系稳定替代。

是否把这一证据门正式写入 L2，需要授权审议；自动任务不得升格。
