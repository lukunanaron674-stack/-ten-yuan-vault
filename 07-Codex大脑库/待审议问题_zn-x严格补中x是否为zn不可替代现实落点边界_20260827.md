## 2｜正向一：诸葛亮卤城换班｜99/95

被测对象层：诸葛亮对直属蜀军换班、留营、放行的现实军令 / 处分边界。

### zn

> **对直属军队已经由自己正式发布并形成期待的轮换军令，主帅不得因为临时战术利益单方破例；统军信用反过来约束掌令者本人。**

魏军急攻时，多留四万熟兵更有即时战术利益，但诸葛亮仍坚持既有轮换令。

### x

- 可设定轮换；
- 决定留营或放行；
- 军令由杨仪与全军现实执行；
- “是否临时留下四万应换班军”由诸葛亮直接裁决。

因此当前留放处分 `x=true`。

### 双向缺口

`zn→x=true`：拿掉军令信用原则，现实军队处分仍存在，但失去“何时即使有权强留也不应强留”的内部限制标准。

`x→zn=true`：拿掉当前直属军队留放处分，窄原则失去“我的直属军队—我的军令—我的留放对象”这一不可替代 current 现实结构。

## 3｜正向二：探春理家公私分账｜99/95

被测对象层：王夫人授权理家窗口中，探春对荣府日常公账、赵国基丧银及部分园务开支的现实增减 / 停支 / 改制处分边界。

### x

第五十五回，探春能直接叫停李纨先拟的四十两、要求查旧账、将赵国基丧银裁为二十两，并拒绝平儿转达的“再添些也使得”宽松口径。第五十六回又推动取消重复买办费用、重组园务开支与管理方式。

因此任内局部公账处分 `x=true`。

### zn

> **当自己现实受托处分公共家务 / 公账时，不能因为生母亲属关系、做人情需要或自己 / 姐妹的当前便利而任意改变可公开核验的公例与账目边界；公账必须与私情分开。**

赵姨娘亲属压力与涉及自己/姐妹的重复脂粉开支，使该原则不只是机械服从一条旧例。

### 双向缺口

`zn→x=true`：拿掉公私分账原则，探春仍有公账处分权，但失去“什么理由即使能给也不应由我拿公共处分权去给”的内部使用 / 例外标准。

`x→zn=true`：拿掉探春当前真实公账处分 `x`，本轮窄原则失去“由我当前处分的公账—我能实际增减 / 停支的对象—我是否拿自己的这项权力徇私”这一 current 构成性现实对象。

## 4｜正向三：晁盖共同财物公共化处分｜99/95

被测对象层：晁盖接掌梁山后，对已经进入其现实处分范围的共同所得、战利品、公库财物的入库、保留与分配边界。

### x

第20回晁盖可直接决定：

- 自家庄上金银财帛与生辰纲所得如何赏众；
- 战后所得如何赏劳；
- 新劫财物多少入库、多少向头领与山上山下成员分配；
- 掌库节点按其决定执行。

因此共同财物 / 公库分配处分 `x=true`。

### zn

窄原则不是泛泛“仗义疏财”，而是：

> **进入自己寨主处分范围、由共同冒险与共同战果形成的财物，不应因为自己坐主位就私有化；首领应把它处理为共同储备和共同成员可分配的公共所得。**

文本连续出现：

- 自家财物也投入赏众；
- 战获继续赏劳；
- 客商财物每样一半入库，另一半再分给十一位头领与山上山下众人；
- 晁盖明确把当前富贵安乐归于众弟兄共同才能。

因此该原则对多个不同来源财物重复进入处分排序，并包含真实个人让渡代价，`zn=true`。

### 双向缺口

`zn→x=true`：拿掉原则，晁盖仍有财物处分权，但失去“为何不能首领私占、何时入公库、何时向共同成员分配”的内部用途/保留/私人占有边界。

`x→zn=true`：拿掉晁盖当前对共同所得 / 公库财物的现实处分，窄原则失去“我作为寨主当前真实掌握的共同财物—我可以私用/入库/分配—我是否将共同所得私有化”这一 current 构成性现实对象。客商、百姓和一般个人行为不能等价替代“我手里的共同财富”对象边界。

### 与晁盖旧 strict 负控制不冲突

旧负控制测试的是另一条 `zn`：“不任意伤害无关者”。该原则离开山寨处分 `x` 后仍可直接指向客商、百姓并约束晁盖本人，所以 `x→zn=false`。

本轮测试的是“我手里共同所得如何处分”，原则本身天然索引当前共同财物 `x`，所以 `x→zn=true`。

这说明 strict 必须按**原则 × 对象层**裁决，不能按人物统一贴标签。

## 5｜三份文学正向的共同结构

三份文学正向的 `x` 类型不同：

```text
诸葛亮：直属军队留放处分 x
探春：受托公账处分 x
晁盖：共同财物 / 公库分配处分 x
```

却共同支持一个更窄的 L4 候选：

> **高纯 strict `x→zn` 更可能出现在“对象构成型 x + 自我约束型 zn”中：`zn` 命题天然规定“我当前真实掌握的这项对象 / 权限应怎样被我使用、限制、分配、变更或退出”，而该 `x` 又构成原则不可替代的 current “我的对象 / 我方边界”。**

必须继续防止：

> **为了让 strict 通过而事后把宽原则人工缩窄成“关于我的 x 的原则”。**

晁盖本例之所以暂过 95，是因为文本本身跨自家财物、生辰纲、军事战获、客商财物反复生成同一“共同所得如何由寨主处分”的对象结构，而不是单场事后裁词。

## 9｜当前反误判纪律

- co-occurrence ≠ strict。
- 同一人物跨阶段两个强端点 ≠ 当前共现。
- 最终结果与 `zn` 同向 ≠ 主体拥有使结果生效的 `x`。
- 第三方现实否决必须归第三方。
- 原则保护 / 评价谁 ≠ 谁必须进入主体 `x`。
- `x` 扩大原则执行范围 ≠ `x→zn`。
- 现实执行接口 ≠ 不可替代现实落点。
- 外部制度 / 旧例存在 ≠ 自动 `zn`。
- 共享管理 ≠ 主体没有局部 `x`，但必须证明主体自己的同层决定能直接改变结果。
- future revocability ≠ current `x` never existed。
- 对象构成型 `x` 是 strict 正向采矿方向，不是新的 canonical 定义。
- **同一人物可在不同原则 × 对象层上分别出现 strict 正向与 strict 负向，不能按人物统一升降。**
- **共同财物公共化是 strict 正向候选时，必须排除组织惯例、成员强制或外部制度足以独立解释分配结果。**
