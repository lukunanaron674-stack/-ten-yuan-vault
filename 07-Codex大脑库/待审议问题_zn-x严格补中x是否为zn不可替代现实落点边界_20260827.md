## 9｜当前强化纪律

- current reality anchor ≠ absolute metaphysical uniqueness。
- execution / amplification / settlement interface ≠ object-constituting anchor。
- `real x loss ≠ automatic x→zn gap`。
- 多个不同 `x` 默认分别测试，禁止 composite-x bundling。
- `one-off effective override ≠ stable x`。
- `temporary custody/use/agency x ≠ full disposition/ownership x`。
- `territorial/internal-governance x ≠ stable externally exclusionary protected-range x`。
- current-control 可以真实、稳定，同时 ultimate-title / permanent ownership 仍有争议、期限或返还义务。
- people/object anchor 与 protected-range anchor 分层；people presence alone 不自动否决范围型 `x→zn`。
- declared protective range / 能力声明 / 设定威望 ≠ observed protected-range `x`。
- 名义法律/血统保护资格 ≠ stable protected-range `x`。
- **`zn=true` ≠ `x` 自动成立；一次由 zn 驱动的局部 effect ≠ stable disposition/custody/exclusion x。**
- **same-object true zn + true x 仍需检查 x 端 competing purpose/ranking anchor；双端同窗共现不是双向缺口。**
- **subject-exclusive authorship / ordinary self-agency ≠ x；不能为了 strict 后验把本人行为作者资格拼成权限对象。**
- **已有首个 strict-v2 正向 ≠ 门槛可以下降；下一步应做不同题材/不同对象机制的 adversarial replication，而不是复制救援/庇护母型。**
