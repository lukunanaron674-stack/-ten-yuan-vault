## 2｜正向一：诸葛亮卤城换班｜99/95

被测对象层：诸葛亮对直属蜀军换班、留营、放行的现实军令 / 处分边界。

### zn

> **对直属军队已经由自己正式发布并形成期待的轮换军令，主帅不得因为临时战术利益单方破例；统军信用反过来约束掌令者本人。**

### x

因此当前留放处分 `x=true`。

### 双向缺口

`zn→x=true`：拿掉军令信用原则，现实军队处分仍存在，但失去“何时即使有权强留也不应强留”的内部限制标准。

`x→zn=true`：拿掉当前直属军队留放处分，窄原则失去“我的直属军队—我的军令—我的留放对象”这一不可替代 current 现实结构。

## 3｜正向二：探春理家公私分账｜99/95

被测对象层：王夫人授权理家窗口中，探春对荣府日常公账、赵国基丧银及部分园务开支的现实增减 / 停支 / 改制处分边界。

### x

第五十五回，探春能直接：

- 叫停李纨先拟的四十两；
- 要求查旧账；
- 将赵国基丧银裁为二十两；
- 拒绝平儿转达的“再添些也使得”宽松口径。

第五十六回又能推动取消重复买办费用、重组园务开支与管理方式。

因此任内局部公账处分 `x=true`。李纨共同理事与王夫人未来可收回权限，都不追溯否定探春当前同层决定能直接改变结果。

### zn

窄原则不是泛泛“探春很公正”，而是：

> **当自己现实受托处分公共家务 / 公账时，不能因为生母亲属关系、做人情需要或自己 / 姐妹的当前便利而任意改变可公开核验的公例与账目边界；公账必须与私情分开。**

第五十五回，赵姨娘以生母 / 亲属关系直接施压；探春仍不借当前公账权限替私亲加码。

第五十六回，她又主动削减包含自己与姐妹日常使用在内的重复脂粉开支，说明这不是机械服从某一条旧例，而是跨财政对象持续限制自己如何使用公账处分权。

因此 `zn=true`。

### 双向缺口

`zn→x=true`：拿掉公私分账原则，探春仍有公账处分权，但失去“什么理由即使能给也不应由我拿公共处分权去给”的内部使用 / 例外标准。

`x→zn=true`：拿掉探春当前真实公账处分 `x`，原则仍可抽象存在，但本轮窄原则失去“由我当前处分的公账—我能实际增减 / 停支的对象—我是否拿自己的这项权力徇私”这一 current 构成性现实对象。

李纨、凤姐、王夫人的各自权限不能替代“探春是否利用探春自己当前手里的这份公账处分权徇私”这一现实结构。

## 4｜两份文学正向的共同结构

当前两份文学正向虽然 `x` 类型不同，却共同支持一个更窄的 L4 候选：

> **高纯 strict `x→zn` 更可能出现在“对象构成型 x + 自我约束型 zn”中：`zn` 命题天然就在规定“我当前真实掌握的这项对象 / 权限应怎样被我使用、限制、变更或退出”，而该 `x` 又构成原则不可替代的 current “我的对象 / 我方边界”。**

```text
诸葛亮：
我的直属军队 / 我的轮换军令
→ 军令信用反过来约束我的留放处分

探春：
我受托处分的公账
→ 公私分账原则反过来约束我能否拿这份公账权做人情
```

这与“原则只是借某个资源 / 权限执行”不同。

但必须继续防止：

> **为了让 strict 通过而事后把一个宽原则人工缩窄成“关于我的 x 的原则”。**

第三作品必须自然出现同型结构，不能靠语义裁剪凑门。

## 8｜当前反误判纪律

- co-occurrence ≠ strict。
- 同一人物跨阶段两个强端点 ≠ 当前共现。
- 最终结果与 `zn` 同向 ≠ 主体拥有使结果生效的 `x`。
- 第三方现实否决必须归第三方。
- 原则保护 / 评价谁 ≠ 谁必须进入主体 `x`。
- `x` 扩大原则执行范围 ≠ `x→zn`。
- 现实执行接口 ≠ 不可替代现实落点。
- 外部制度 / 旧例存在 ≠ 自动 `zn`；必须证明主体在拿掉单一制度刺激后仍保留内部排序资格。
- 共享管理 ≠ 主体没有局部 `x`，但必须证明主体自己的同层决定能直接改变结果。
- future revocability ≠ current `x` never existed。
- 对象构成型 `x` 是 strict 正向采矿方向，不是新的 canonical 定义。
