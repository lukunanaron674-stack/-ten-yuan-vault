## 10｜强化纪律

1. 同 criterion_version 才允许跨作品计数。
2. control 数与 independent work 数分开；同一作品多个角色不能重复增加 works。
3. `evidence-locked` 可被对抗审计撤回；事实99不等于分类永久95。
4. 修正过强判据 ≠ 所有旧 deferred 自动恢复。

6. 高纯 P1 `zn` 不得跨原则倒灌 P2。
7. current anchor gap 与“未来所有可能载体都不存在”严格分开。
8. execution interface / amplification interface / screened resource / old governance object 都不自动等于 current reality anchor。
9. `real x loss ≠ automatic x→zn gap`。
10. 多个不同 `x` 共同承载同一原则时，默认分别测，不得为通过 strict 事后捆绑。
11. 公开自罚、公开自限与治理收益同向时，必须先冻结服众/信誉/绩效/威慑等第三因素，再判断 `zn` 是否独立。
12. 对象当场表现触发的敬佩/认可不能倒填成压力前已成立 `zn`。
13. 一次物理可杀/可抓/可击倒机会不能补成稳定 `x`。
14. 真实稳定 `x` + 释放结果也不能替 `zn` 端上班；先冻结外部通道、政治交换、资源回报与战略合作。
15. outcome-changing opportunity 与 object-constituting current anchor 必须分开。
