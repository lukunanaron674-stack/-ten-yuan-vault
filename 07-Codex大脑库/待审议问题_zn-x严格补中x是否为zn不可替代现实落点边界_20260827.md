# 待审议｜strict zn↔x 中 x 是否为 zn 不可替代现实落点的边界

## 1｜触发条件

在同一 criterion_version 下，strict `zn↔x` 压力测试已经出现 3 部独立作品的高置信反向护栏：

1. 《三国演义》关羽·挂印封金，99/97。
2. 《水浒传》晁盖·梁山劫掠处分，99/98。
3. 《西游记》唐僧·三打白骨精 / 草寇事件，99/97。

三案均满足：

```text
zn 独立成立
+
x 独立成立
+
同一当前窗口 zn+x 共现
+
zn → x 缺口成立
但
x → zn 缺口不成立
```

因此达到 L4 `pending-review` 门槛，但不得自动修改 current canonical。

## 2｜候选边界

> **`x` 能帮助、扩大、便利或强化 `zn` 的现实执行，不等于该 `x` 在 strict 意义下构成 `zn` 的不可替代现实落点。**

strict `x→zn` 必须进一步证明：

```text
拿掉被测 x
→ zn 仍成立
但重新出现可命名现实缺口，例如：
   - 没有现实对象可指向
   - 没有可保护 / 可守护对象范围
   - 没有明确“我方”边界
   - 没有任何主体自身行为、其他关系或其他现实对象可继续承载该原则
```

如果原则仍能通过其他既有对象、关系、行动或主体自身行为稳定落地，则只允许：

```text
zn+x co-occurrence
+
zn→x 单向补
```

不能锁 strict `zn↔x`。

## 3｜三作品负控制

### 3.1｜关羽｜曹赐资源不是旧义唯一现实落点

- `zn`：刘备旧盟/旧义；
- `x`：曹赐金银、侯印、赤兔马等现实掌握对象；
- `zn→x`：旧义给资源提供保留/让渡与使用标准；
- `x→zn`：不成立。拿掉这些曹赐资源后，旧义仍可通过归刘、护送二夫人、离曹寻找刘备等现实行动稳定落地。

### 3.2｜晁盖｜山寨处分权不是“不伤无关者”原则唯一现实落点

- `zn`：不可任意伤害无关客商/百姓；
- `x`：山寨人马、行动和战利品处分边界；
- `zn→x`：原则限制武力/处分 `x` 的使用边界；
- `x→zn`：不成立。拿掉山寨处分权后，原则仍能指向客商、百姓并约束晁盖自身行为。

### 3.3｜唐僧｜师徒处分权只是原则的一条执行接口

- `zn`：不可轻率伤害人命；
- `x`：对孙悟空师徒关系的紧箍、留用、逐退等现实处分/约束权限；
- `zn→x`：原则给处分 `x` 提供惩戒、保留和终止标准；
- `x→zn`：不成立。拿掉该关系处分权后，原则仍能约束唐僧自己的判断、其他关系和其他现实生命对象。

## 4｜共同结构

三案虽然 `x` 类型不同：

```text
关羽：资源 x
晁盖：组织武力 / 处分 x
唐僧：关系处分 / 约束 x
```

但都出现同一反向结果：

```text
x 对 zn 有现实作用
≠
x 是 zn 唯一或不可替代的现实落点
```

因此 strict 反向门应优先检查“不可替代现实落点”，不能只检查“是否有帮助”。

## 5｜反误判护栏

- 原则保护谁 ≠ 谁必须进入主体 `x`。
- 原则评价谁 ≠ 谁必须进入主体 `x`。
- `x` 扩大原则执行范围 ≠ `x→zn`。
- `x` 提高原则执行效率 ≠ `x→zn`。
- `x` 给原则一个额外行动接口 ≠ `x→zn`。
- “没有这个 x，当前这件事更难” ≠ “没有这个 x，zn 没有现实落点”。
- `zn+x` 共现不得自动升级 strict。

## 6｜与 current canonical 的关系

本待审议不改写 `zn补x_补卡_v0.1`，只提出一个证据门：

> current canonical 所说的“`x` 给 `zn` 补现实落点 / 可保护对象范围 / 明确我方边界”，在 strict 统计时应证明该缺口真实且不可由主体自身行为、其他对象或其他关系稳定替代。

是否把这一证据门正式写入 L2，需要授权审议；自动任务不得升格。

## 8｜下一步高价值测试

不再继续堆第四份同型负控制。优先：

1. 寻找第一份真正通过 `x→zn` 不可替代现实落点门的 strict 正例候选；
2. 寻找“表面 x 是唯一落点，实际第三因素提供等价落点”的反例；
3. 寻找一个 `x` 类型不是资源、组织权、关系处分权的候选，例如稳定领地、专属身份处分边界、不可替代对象归属；
4. 在找到 strict 正例前，禁止因 co-occurrence 或单向 `zn→x` 自动增加 strict positive count。
