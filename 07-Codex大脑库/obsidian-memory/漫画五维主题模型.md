# 漫画五维主题模型

## Observations
- 本体型 zn+x：内核燃烧/存在驱动，关注个体精神燃烧、存在追问、核心欲望驱动。
- 时间型 xn+z：节拍压迫/时机精准，关注规则框架下的时机博弈、节奏压迫、精准爆发。
- 空间型 x并z+n：场域包裹/停留感，关注作品营造的强场域、可停留世界和读者沉浸。
- 因果型 zx+nx：局势博弈/暗流推动，关注多方势力、暗线因果链、局势推演和算计。
- 命运型 xz+nz：漂流宿命/缘分遭遇，关注宿命漂流、巧合遭遇、等待、重逢和命运回响。
