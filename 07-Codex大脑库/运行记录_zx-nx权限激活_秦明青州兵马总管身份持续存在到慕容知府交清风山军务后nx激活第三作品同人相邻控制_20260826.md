# 《水浒传》秦明｜青州兵马总管身份既存 → 清风山军务进入行动链：nx off→on 第三作品控制

## 0｜结论先行

本轮只测试一个窄变量：**身份 / 职位长期存在，是否足以让当前任务层 nx 自动在线。**

结论：不够。

```text
窗口A｜清风山军务尚未进入
秦明已是青州指挥司总管本州兵马秦统制
+ 官职、组织关系、兵权入口长期存在
+ 但本轮“清风寨告急 / 征剿花荣清风山”任务尚未进入行动链
→ 本被测任务层 nx = off

窗口B｜慕容知府召见并交付军务
黄信飞报清风寨告急
→ 慕容知府差人请秦明议军情
→ 秦明阅读申状，明确承接清风寨军务
→ 连夜点一百马军、四百步军，次日出征
→ 本被测任务层 nx = on
```

因此与《西游记》孙悟空“齐天大圣空衔→权管蟠桃园”、《红楼梦》周瑞家的“回话完成欲退出→薛姨妈临时交宫花”形成第三部独立作品的同人相邻开关控制。

> **关系位置 / 职位 / 组织网络存在，只证明外部接口存在；明确任务进入当前行动链并被主体真实承接，才把该任务层 nx 从 off 切到 on。**

## 1｜剧情事实、触发、对象、动作、结果

### 窗口A｜任务前

- 秦明在本回出场前已经是“青州指挥司总管本州兵马秦统制”。
- 这一身份意味着他长期处于青州官军体系，并拥有既有兵马调用入口。
- 但在黄信飞报到来、慕容知府召见以前，本轮被测的“清风寨告急 / 征剿花荣清风山”任务尚未进入秦明当前行动链。

因此必须拆开：

```text
组织关系存在 = true
清风山当前任务进入行动链 = false
主体沿该任务推进 = false
→ 清风山任务层 nx 不激活
```

### 窗口B｜任务进入

- 黄信飞马报知慕容知府：花荣反叛、结连清风山，清风寨告急，请早遣良将。
- 慕容知府差人去请秦明急来商议军情。
- 秦明到府，看完黄信申状后，明确答应立即起军马。
- 慕容知府进一步催促不可迟慢，秦明承接后回指挥司，点起一百马军、四百步军。
- 次日出城，接受知府嘱付后直奔清风寨。

触发：黄信告急申状进入知府军政链，并由慕容知府正式交给秦明处理。
对象：清风寨告急与清风山征剿军务。
明确动作：到府议军、承接任务、点兵、整队、出征。
结果：秦明当前行动正式接入外部军务方向。

## 2｜nx 判断

### 窗口A｜本被测任务层 nx 不激活

这里不是说秦明人物整体“非 nx”，也不是说官职无意义；只限定到尚未出现的清风山军务。

```text
官职 / 组织位置存在
≠
当前清风山任务方向已经被主体承接
```

因此本窗口只能证明：外部权限网络和潜在任务入口存在。

### 窗口B｜本被测任务层 nx 激活

```text
当前最高军务对象由外部告急链提出
+ 慕容知府把任务正式交给秦明
+ 秦明不改写“处理清风寨告急 / 出兵”这一上位方向
+ 主体真实点兵并沿该任务推进
→ 上位任务层 nx 成立
```

这符合现行 nx 正本：方向、权限或解决通道已经存在，主体不占最终方向重设位，并沿既有关系、权限和流程继续行动。

## 3｜zx 判断

本轮不新增 zx。

- 秦明是总管、能领兵、战斗力强，都不是 zx 充分条件。
- 当前“要不要处理清风寨告急 / 是否出兵”的上位军务并非由秦明新增扩张出来。
- 出兵本身属于职业 / 任务执行，不自动形成新增公开决定范围。

因此：

`zx_in_tested_activation_transition: rejected_as_primary`

若后续秦明公开越过慕容知府 / 朝廷保留的上位战略处分边界，并让军政秩序围绕其新决定位置重排，才另查 zx。

## 4｜nx vs xn 最近邻

窗口B中秦明确有局部运行自主：

- 自己回指挥司点一百马军、四百步军；
- 摆布起身、整队出征；
- 战术层可有自行组织。

因此局部 `xn` 有邻近证据。

但本轮只测试“清风山军务是否进入当前行动链”的上位任务层：

```text
上位军务来源 / 任务方向 = 外部给出 → nx
具体兵力配置与出征组织 = 可另查 xn
```

二者不能互相覆盖。

## 5｜拿掉测试

### 拿掉长期官职身份

假设执行者不是长期青州兵马总管，只要慕容知府仍真实把清风寨军务交给他，而他承接并沿外部任务推进，任务层 nx 仍可成立。

说明“长期职位”不是本轮 nx 成立的唯一支柱。

### 拿掉任务进入

保留秦明全部官职、兵马入口、军队关系，但黄信没有告急、慕容知府没有召见交任务：

→ 本被测清风山任务层 nx 不成立。

### 拿掉主体承接

慕容知府提出任务，但秦明拒绝、不点兵、不沿该方向推进：

→ 只能证明外部任务存在，不能证明当前 nx 已激活。

## 6｜反向测试

### 反向成更纯 nx

若慕容知府不仅给出上位军务，还把兵力、路线、时序、战术节点逐项写死，秦明机械执行，则局部 xn 进一步下降，纯任务 nx 上升。

### 反向成 nx + xn

现文本已经有一定这种结构：上位任务 nx；点兵、整队、具体作战组织可形成局部 xn 邻近。若后续材料证明核心运行骨架主要由秦明主动重搭，则 xn 可单独升级。

### 反向成 zx

若秦明原本没有更高军政处分权，却公开把“是否征剿、征剿对象与整体战略”夺入自己的决定边界，慕容知府等反而围绕其新增决定接口运行，才转查 zx。

## 7｜第三因素冻结

冻结：

- 秦明“霹雳火”性格；
- 武艺高强；
- 对花荣的愤怒；
- 官军 / 梁山善恶评价；
- 后续秦明是否归梁山；
- 战斗胜负。

只保留：

```text
同一人物
+ 官职 / 组织关系持续存在
+ 当前清风山任务是否已经进入行动链
+ 慕容知府是否真实交付
+ 秦明是否真实承接并续接
```

结论不变。

## 8｜三作品最小差异对照

```text
《西游记》孙悟空
齐天大圣空衔：体系/名位存在，无当前职事 → nx off
权管蟠桃园：明确任务进入并承接 → nx on

《红楼梦》周瑞家的
回话结束欲退出：长期关系存在，宫花任务尚未出现 → nx off
薛姨妈临时交花：明确任务进入并承接 → nx on

《水浒传》秦明
青州兵马总管身份既存：组织/职位存在，清风山军务尚未进入 → nx off
慕容知府交清风寨告急军务并被承接：→ nx on
```

三案人物身份、组织类型与任务对象不同，但共同冻结：

> **长期关系/组织位置存在，不等于当前任务层 nx 自动在线；实际任务接入 + 主体承接，才构成任务层 nx 激活。**
