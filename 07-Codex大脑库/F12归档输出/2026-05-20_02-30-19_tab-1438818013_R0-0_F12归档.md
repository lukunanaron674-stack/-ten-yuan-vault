【Codex 正式回传包】
1. 起手判断规则
起手十元不能由结局、主题、五维、视觉、题材倒推。
起手必须来自最先发动故事 / 交互 / 人物行动 / 系统反馈的推动力。
2. 承载位判断规则
承载位不能默认写 n。
承载可能是 n、xn、nx、x并z+n、n+xn、n+nx 或其他复合结构。
判断承载位时必须问：到底是谁在承载变化、代价、停留、压力？
3. 五大主题归仓规则
五大主题只负责高阶归仓：
时间 = xn + z
本体 = zn + x
空间 = x并z + n
因果 = zx + nx
命运 = xz + nz

不能因为作品属于命运类，就倒推出起手必是 xz。
不能因为作品属于空间类，就倒推出起手必是 x并z。
4. 动态链闭合规则
一条动态链必须至少包含：
起手十元
被作用十元
转折机制
结果落点
误判风险

没有转折机制的链条，降权。
只有情绪形容的链条，降权。
没有关系依据的桥接，降权。
5. 故事种子生产规则
好故事种子不是漂亮设定，而是可运行结构。

标准字段：
一句话故事
起手十元
被作用十元
动态链结果
五大主题归仓
画面钩子
角色关系钩子
最大误判风险
