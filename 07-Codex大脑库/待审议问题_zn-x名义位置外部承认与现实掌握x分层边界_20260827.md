# 待审议｜zn-x 名义位置 / 外部承认 与现实掌握 x 分层边界

## 0｜候选命题

当前三部独立作品、同一 criterion 下出现同型最小差异：

> **名义身份、高称号、家族位置、外部承认、牌印/授权/交付意向，都不能单独证明现实 `x` 已成立。**

> **现实 `x` 必须另证：明确被测对象进入主体可稳定调用、管理、调配、处分、否决或排除边界，并产生现实节点响应。**

两份独立作品反向护栏进一步说明：

> **即使已经出现正式授权与部分真实管理动作，也不能把局部 `x` 向整个任务层或更高对象层倒灌。原节点若仍能在同一层直接覆盖，或在更高范围越级发动覆盖性命令，则必须按对象层拆分 `x`。**

本文件只到 L4 `pending-review`，不得覆盖 current canonical。

## 1｜三份正向控制

### 1.1《西游记》孙悟空｜齐天大圣空衔 → 权管蟠桃园｜99/98

- 阶段A：齐天大圣名位、府署、礼遇、外部承认真实存在；但公共职事层仍是“有官无禄 / 不与管事”，被测现实管理 `x = off`。
- 阶段B：玉帝明确授予“权管蟠桃园”，孙悟空进入园务，土地与各类力士围绕其管理位置响应，园务 `x = on`。
- 分水岭：不是称号，而是现实管理对象和节点真正接入。

### 1.2《红楼梦》王熙凤｜原有贾府身份 / 当家声望 → 协理宁国府局部处分 x｜99/98

- 阶段A：家族身份、管理经验、办事声望已存在，但宁府丧事期间日常人员处分权不能由此倒推。
- 阶段B：贾珍请托、王夫人放行、对牌交付后进入协理位置；第14回迟到媳妇处罚由凤姐直接决定并现实生效，之后才回覆，局部处分 `x = on`。
- 对象层护栏：局部日常处分 `x` 成立，不向整个宁府全部权限倒灌。

### 1.3《三国演义》刘备｜徐州牌印 / 官民推举 → 权领徐州事｜99/97

- 阶段A：陶谦死后，官员捧牌印、百姓哭拜推举，外部承认与权力交付意向很强；刘备仍固辞，徐州治理 `x = off`。
- 阶段B：刘备“乃许权领徐州事”后，用孙乾、糜竺、陈登，调小沛军马入城，出榜安民，现实治理节点围绕其位置运行，徐州治理 `x = on`。
- 分水岭：不是牌印被送到面前，而是主体真实接受并使同类治理决定现实生效。

## 2｜共同变量

三案表面载体不同：

```text
高称号 / 府署
家族身份 / 声望 / 对牌
牌印 / 官民推举 / 权力交付意向
```

但共同问题相同：

```text
“别人如何定义/承认/授权我”
≠
“被测对象是否已经进入我的现实掌握边界”
```

当前最稳的 `x` on 门：

1. 被测对象明确；
2. 主体明确；
3. 实际权限类型明确；
4. 决定能在同类对象上直接现实生效；
5. 不是每次都要重新取得同一权限；
6. 现实节点围绕主体的调用/处分位置响应。

## 3｜拿掉与反向协议

### 拿掉名义身份 / 外部承认

若现实管理、处分、调配仍可直接生效，`x` 可以继续成立。

→ 名义位置不是 `x` 的必要条件。

### 拿掉现实接管 / 生效

若只剩称号、职位、印信、牌照、推举、授权意向或一次接触，而同类决定不能直接落地，`x` 不应成立。

→ 名义位置不是 `x` 的充分条件。

### 反向成立 x

要从名义候选升级现实 `x`，至少应看到：

```text
稳定调用 / 管理 / 调配 / 处分 / 否决 / 排除
+
现实结果响应
+
同类权限无需逐次重新申请
```

同时还要继续检查：

```text
被测对象层是否只是局部？
上位节点是否仍保留同层事前覆盖？
上位节点是否仍可在更高范围越级发动覆盖性命令？
```

## 4｜最近邻护栏

- `x vs z`：称号、拥戴、认可首先是位置/评价信息，不能替实际掌握；
- `x vs nx`：外部任务/授权入口可来自别人，但接管以后具体对象是否进入当前掌握要重新检查 `x`；
- `x vs xn`：主体会组织流程，不等于对象归属边界自动成立；
- `x vs zx`：公开获得高位或扩张影响不能替代稳定处分边界；
- `x vs 物理持有`：拿着印信、钥匙、文件、牌照只是一条候选证据，必须看它背后的权限是否真实可用；
- `local x vs global x`：局部能直接生效，不等于整个组织或任务层最终都归主体掌握。

## 5｜反误判纪律

1. **名义身份 / 高称号 / 外部承认 ≠ 现实 `x`。**
2. **授权意向 / 牌印交付 ≠ 权限已经生效。**
3. **局部 `x` 成立 ≠ 整个组织/任务层全部 `x` 成立。**
4. **现实 `x` 的核心不是“别人说你有权”，而是“同类决定是否能由你直接生效”。**
5. **同一人物、同一组织内出现 off→on，是比跨人物静态对比更高价值的最小差异证据。**
6. **名义授权伴随部分真实管理动作，也不能自动推出整个对象层稳定 `x`；原节点若仍能在结果生效前现实覆盖，必须按对象层降级。**
7. **真实局部 `x` 也不能向更高范围倒灌；上位节点仍可越级发动覆盖性全局命令时，只能锁局部 `x`。**
8. **“局部能管”与“全局归我”必须拆开审计。**

## 7｜反向护栏

### 7.1《水浒传》杨志｜生辰纲名义提调 → 黄泥冈决定被谢都管现实覆盖｜99/98

- 梁中书真实把押送任务交给杨志，并接受其运输方案；杨志也确有催行、约束等部分现场管理动作。
- 但在“黄泥冈是否停歇”这个同一对象层，杨志明确坚持不能停，老都管要求停，众军最终停下；杨志不能稳定让自己的决定直接生效。
- 后续买酒节点中，老都管再次介入，杨志最终让步。
- 因而本例不是“杨志完全没有任何 x”，而是：**名义授权 + 部分局部管理 ≠ 整个押运对象层的稳定现实 `x`。**
- 关键负证据：原关系节点仍保有真实事前覆盖能力。

机制：

```text
same-layer decision overridden
```

### 7.2《红楼梦》探春｜受托理家，局部 x 真实成立，但王夫人仍可越级发动全园抄检｜99/97

- 第55回王夫人明确区分“大事自己主张”与“家中琐碎事务暂令李纨协理、命探春合同裁处”，说明委托从一开始就是分层的。
- 探春后续确实能够裁处部分日常事务，所以局部 `x` 真实成立，不能写成纯名义授权。
- 第74回绣春囊事件中，王夫人直接重新进入园务，接受抄检方案并命凤姐等夜间全园搜查；凤姐到探春处明确说明自己“奉太太的命来”。
- 探春能守住自己院内的局部边界：允许搜自己的箱柜，但拒绝搜丫头；凤姐最终接受这一局部限制。
- 但探春不能取消王夫人发动的全园抄检，搜查仍继续到其他院落。
- 因而：**局部日常管理 `x = on`，不等于全局/最终大观园管理 `x = on`。**
- 关键负证据：上位节点仍可在更高范围越级发动覆盖性命令。

机制：

```text
local x real
+
upper/global scope remains externally overridable
```

## 8｜两类反向护栏共同支持什么

```text
杨志：
授权已经给出
+ 部分管理动作存在
+ 同层决定仍被现实覆盖
→ 稳定 x 不能整体锁定

探春：
局部 x 已真实成立
+ 上位节点仍保留更高范围覆盖按钮
→ 局部 x 不得向全局 x 倒灌
```

共同纪律：

> **现实掌握必须按对象层和权限范围逐层审计。授权、局部管理和部分生效都不能替代“最终谁能在被测范围内让决定稳定直接生效”。**

## 9｜下一步最高价值反例

不再继续堆普通“名义不足”正例，也不复制探春式局部/全局案例。

优先第三种反向机制：

```text
正式授权已经给出
+ 主体已有一段真实稳定 x
+ 上位节点平时不直接覆盖单次决定
但仍保留撤回 / 改派 / 收回整段权限的现实按钮
→ 检查稳定 x 的边界到底如何定义
```

其次继续保持 P0：寻找第一份真正通过 `x→zn` 不可替代现实落点门的 strict `zn↔x` 正例。

所有后续结果仍只用于压 L4 边界，不自动修改 L2。
