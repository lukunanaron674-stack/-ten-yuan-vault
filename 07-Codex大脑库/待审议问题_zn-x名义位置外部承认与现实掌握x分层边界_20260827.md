# 待审议｜zn-x 名义位置 / 外部承认 与现实掌握 x 分层边界

## 0｜候选命题

三部独立正向作品共同支持：

> **名义身份、高称号、家族位置、外部承认、牌印、授权或交付意向，都不能单独证明现实 `x` 已成立。**

现实 `x` 必须另证：明确被测对象进入主体可稳定调用、管理、调配、处分、否决或排除边界，并产生现实节点响应。

当前又有两类负向护栏与一类“可撤但真实”边界控制，要求把以下变量拆开：

```text
当前可用权
同层最终决定权
权限范围
上位覆盖权
整段撤销权
永久归属
```

本文件只到 L4 `pending-review`，不得覆盖 current canonical。

## 1｜三份正向控制

高称号、府署、礼遇和承认先存在，但公共职事 `x` 仍未成立；真正“权管蟠桃园”后，园务对象、土地与力士节点进入其现实管理链，园务 `x` 才 on。

### 1.2《红楼梦》王熙凤｜原有贾府身份 → 协理宁国府局部处分 x｜99/98

原有家族身份、管理经验与声望不足推出宁府处分 `x`；真实协理授权进入后，第14回同类处分决定可直接现实生效，局部 `x` 才成立。局部不得倒灌全部宁府权限。

### 1.3《三国演义》刘备｜徐州牌印 / 官民推举 → 权领徐州事｜99/97

牌印与推举已经到场，但刘备仍固辞时徐州治理 `x` 不成立；接受“权领徐州事”并开始用人、调兵、安民后，治理节点围绕其决定运行，地区治理 `x` 才 on。

## 2｜现实 x 的最小 on 门

1. 被测对象明确；
2. 掌握主体明确；
3. 实际权限类型明确；
4. 同类决定能现实生效；
5. 不是每次都重新取得同一权限；
6. 现实节点围绕主体的调用/处分位置响应。

还必须继续审计：

```text
被测范围是否只是局部？
上位节点是否仍保留同层事前覆盖？
上位节点是否仍能在更高范围发动覆盖性命令？
上位节点是否只保留未来整段撤销权？
```

## 3｜反向护栏 A：同层决定被覆盖

### 《水浒传》杨志｜生辰纲名义提调 → 黄泥冈决定被谢都管覆盖｜99/98

授权与部分管理动作真实存在，但在“是否停歇”等同层关键决定上，谢都管仍能让现实结果压回杨志的决定。

结论：

```text
正式授权 + 部分管理
+ 同层关键决定仍被现实覆盖
→ 被测同层稳定 x 不足
```

## 4｜反向护栏 B：局部 x 不能倒灌全局 x

### 《红楼梦》探春｜受托理家 → 王夫人仍可越级发动全园抄检｜99/97

探春日常局部管理 `x` 真实成立；但第74回王夫人仍可直接发动覆盖全园的抄检。探春能守住自己院内局部边界，却不能取消全局抄检。

结论：

```text
local x = true
+ upper/global scope remains externally overridable
→ global stable x 不能倒灌锁定
```

## 5｜边界控制 C：可撤销不等于此前 x 为假

### 《西游记》天蓬元帅｜掌管天河八万水军 → 后被玉帝整段贬黜｜99/98

天蓬任内有明确现实掌管对象与军务范围，当前 `x` 可独立成立；后来玉帝通过上位处分整段结束该位置，只能证明原 `x` 生命周期终止，不能追溯性写成“此前从未有现实 x”。

结论：

```text
阶段 A：任内现实掌管稳定运行 → current x = on
阶段 B：上位节点实际撤销整段位置 → current x = off
```

因此：

> **可撤销是 `x` 的稳定性 / 生命周期变量，不是自动否定 current `x` 的充分条件。**

这与杨志、探春不同：

```text
杨志：同层决定仍被压回 → 同层稳定 x 不足
探春：局部 x 真，但全局仍被上位覆盖 → scope 必须拆分
天蓬：任内 current x 真，未来整段可撤 → current x 与永久归属必须拆分
```

## 6｜最近邻与反误判纪律

- `x vs z`：称号、拥戴、认可不能替代现实掌握。
- `x vs nx`：授权入口来自别人，不等于授权后没有现实局部 `x`。
- `x vs xn`：会组织流程不等于掌握对象归属边界。
- `x vs zx`：公开高位或显权不能替代稳定处分边界。
- `local x vs global x`：局部能管不等于全局归我。
- `current x vs permanent ownership`：当前现实可用权不等于永久不可撤归属。

固定纪律：

1. 名义身份 / 高称号 / 外部承认 ≠ 现实 `x`。
2. 授权意向 / 牌印交付 ≠ 权限已经生效。
3. 局部 `x` 成立 ≠ 整个组织/任务层全部 `x` 成立。
4. 名义授权 + 部分管理 ≠ 稳定全局 `x`。
5. 上位节点可在同层现实覆盖时，必须降低对应范围 `x` 判断。
6. 上位节点可在更高范围越级覆盖时，只能锁局部 `x`。
7. **上位节点未来能整段撤销 ≠ 当前现实 `x` 从未成立。**
8. **当前可用权、范围、override、revocation 与永久归属必须分开审计。**
