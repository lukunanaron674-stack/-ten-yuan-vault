# 待审议｜zn-x 名义位置 / 外部承认 与现实掌握 x 分层边界

## 0｜候选命题

当前三部独立作品、同一 criterion 下出现同型最小差异：

> **名义身份、高称号、家族位置、外部承认、牌印/授权/交付意向，都不能单独证明现实 `x` 已成立。**

> **现实 `x` 必须另证：明确被测对象进入主体可稳定调用、管理、调配、处分、否决或排除边界，并产生现实节点响应。**

本文件只到 L4 `pending-review`，不得覆盖 current canonical。

## 1｜三份正向控制

### 1.1《西游记》孙悟空｜齐天大圣空衔 → 权管蟠桃园｜99/98

- 阶段A：齐天大圣名位、府署、礼遇、外部承认真实存在；但公共职事层仍是“有官无禄 / 不与管事”，被测现实管理 `x = off`。
- 阶段B：玉帝明确授予“权管蟠桃园”，孙悟空进入园务，土地与各类力士围绕其管理位置响应，园务 `x = on`。
- 分水岭：不是称号，而是现实管理对象和节点真正接入。

### 1.2《红楼梦》王熙凤｜原有贾府身份 / 当家声望 → 协理宁国府局部处分 x｜99/98

- 阶段A：家族身份、管理经验、办事声望已存在，但宁府丧事期间日常人员处分权不能由此倒推。
- 阶段B：贾珍请托、王夫人放行、对牌交付后进入协理位置；第14回迟到媳妇处罚由凤姐直接决定并现实生效，之后才回覆，局部处分 `x = on`。
- 对象层护栏：局部日常处分 `x` 成立，不向整个宁府全部权限倒灌。

### 1.3《三国演义》刘备｜徐州牌印 / 官民推举 → 权领徐州事｜99/97

- 阶段A：陶谦死后，官员捧牌印、百姓哭拜推举，外部承认与权力交付意向很强；刘备仍固辞，徐州治理 `x = off`。
- 阶段B：刘备“乃许权领徐州事”后，用孙乾、糜竺、陈登，调小沛军马入城，出榜安民，现实治理节点围绕其位置运行，徐州治理 `x = on`。
- 分水岭：不是牌印被送到面前，而是主体真实接受并使同类治理决定现实生效。

## 2｜共同变量

三案表面载体不同：

```text
高称号 / 府署
家族身份 / 声望 / 对牌
牌印 / 官民推举 / 权力交付意向
```

但共同问题相同：

```text
“别人如何定义/承认/授权我”
≠
“被测对象是否已经进入我的现实掌握边界”
```

当前最稳的 `x` on 门：

1. 被测对象明确；
2. 主体明确；
3. 实际权限类型明确；
4. 决定能在同类对象上直接现实生效；
5. 不是每次都要重新取得同一权限；
6. 现实节点围绕主体的调用/处分位置响应。

## 3｜拿掉与反向协议

### 拿掉名义身份 / 外部承认

若现实管理、处分、调配仍可直接生效，`x` 可以继续成立。

→ 名义位置不是 `x` 的必要条件。

### 拿掉现实接管 / 生效

若只剩称号、职位、印信、牌照、推举、授权意向或一次接触，而同类决定不能直接落地，`x` 不应成立。

→ 名义位置不是 `x` 的充分条件。

### 反向成立 x

要从名义候选升级现实 `x`，至少应看到：

```text
稳定调用 / 管理 / 调配 / 处分 / 否决 / 排除
+
现实结果响应
+
同类权限无需逐次重新申请
```

## 4｜最近邻护栏

- `x vs z`：称号、拥戴、认可首先是位置/评价信息，不能替实际掌握；
- `x vs nx`：外部任务/授权入口可来自别人，但接管以后具体对象是否进入当前掌握要重新检查 `x`；
- `x vs xn`：主体会组织流程，不等于对象归属边界自动成立；
- `x vs zx`：公开获得高位或扩张影响不能替代稳定处分边界；
- `x vs 物理持有`：拿着印信、钥匙、文件、牌照只是一条候选证据，必须看它背后的权限是否真实可用。

## 5｜反误判纪律

1. **名义身份 / 高称号 / 外部承认 ≠ 现实 `x`。**
2. **授权意向 / 牌印交付 ≠ 权限已经生效。**
3. **局部 `x` 成立 ≠ 整个组织/任务层全部 `x` 成立。**
4. **现实 `x` 的核心不是“别人说你有权”，而是“同类决定是否能由你直接生效”。**
5. **同一人物、同一组织内出现 off→on，是比跨人物静态对比更高价值的最小差异证据。**

## 7｜下一步最高价值反例

优先寻找：

```text
主体已经得到名位 / 证件 / 印信 / 公开授权
+
甚至别人普遍认为“这事归他管”
但
同一对象层决定仍被原节点稳定撤回 / 覆盖 / 否决
→ 证明现实 x 仍未成立或只成立局部候选
```

其次寻找：

```text
没有高称号 / 正式身份
但主体事实上长期直接调用、处分同一对象
→ 证明现实 x 可以先于名义位置成立
```

二者都只用于压边界，不自动修改 L2。
