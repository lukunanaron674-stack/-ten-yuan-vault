# 待审议｜zx↔nx 旧严格补判据系统性过宽

## 0｜问题

最近的新双向拿掉门要求：

```text
拿掉 nx：zx 自身仍成立，但出现只能由 nx 补回的核心缺口
拿掉 zx：nx 自身仍成立，但也出现只能由 zx 补回的核心缺口
```

旧材料中曾大量使用另一种较宽写法：

> “没有 zx，nx 提供的资源/许可/保护不会自动生成这个共同结果。”

这句话只能证明 **共同结果需要行动端**，不能证明 **nx 自身核心功能因缺少 zx 而受损**。

如果 nx 仍然完整拥有自己的资源处分、许可、保护、专业解决或收伏能力，那么 `zx→nx` 反向缺口就没有成立。此时只能锁 `nx→zx` 单向补缺。

## 1｜跨作品回扫

### 1.1 三国演义｜孙策质玺借兵｜99/98

- zx：取江东/扩张方向。
- nx：袁术兵马外部处分接口。
- nx→zx：兵马补掉启动军力不足。
- zx→nx：不成立。拿掉孙策 zx，袁术仍完整拥有兵马处分功能。
- 第三因素：玉玺独立交换价值解释袁术合作动机。
- 结论：单向补。

### 1.2 三国演义｜曹操陈留借卫弘家资｜99/98

- zx：反董起兵/募兵/发檄。
- nx：卫弘家资处分接口。
- nx→zx：资金补掉启动资本与装备缺口。
- zx→nx：不成立。拿掉曹操 zx，卫弘的家资处分能力仍完整。
- “钱不会自动变成反董军队”只是共同结果缺行动端，不是卫弘 nx 自身缺口。
- 结论：单向补。

### 1.3 水浒传｜宋江高唐州｜99/98

- zx：破高唐/救柴进的公开军事推进。
- nx：公孙胜专属能力 + 罗真人许可。
- nx→zx：外部破解接口直接解除高廉妖法瓶颈。
- 旧反向缺口写成“没有宋江 zx，专家条件不会自动生成梁山攻城救援结果”。
- 新规则下这不够：拿掉宋江 zx，公孙胜的专业能力与罗真人的许可处分能力仍然完整，不发生 nx 自身功能损伤。
- 结论：旧严格补子结论撤回，改为 `nx→zx` 单向补。

### 1.4 红楼梦｜鸳鸯抗婚｜99/97

- zx：鸳鸯公开坚持“不嫁贾赦”。
- nx：贾母真实保护/留用/阻断接口。
- nx→zx：贾母权限使个人拒绝获得现实阻断力。
- 旧反向缺口写成“没有鸳鸯拒绝，贾母不会自动生成保护该拒绝的具体目标”。
- 新规则下这不够：没有触发对象/具体请求，不等于贾母的保护、留用、家内否决能力本身受损。
- 结论：旧严格补子结论撤回，改为 `nx→zx` 单向补。

### 1.5 西游记｜孙悟空红孩儿｜99/97

- zx：救师/突破红孩儿阻断的当前行动方向。
- nx：观音的专属收伏能力与高位解决接口。
- nx→zx：观音接口补掉三昧真火与红孩儿专属瓶颈。
- 旧文件没有通过现行 `zx→nx` 核心功能缺口门，只证明观音条件进入后共同任务得以完成。
- 拿掉孙悟空 zx，不会使观音的收伏能力/处分接口自身失去核心功能。
- 结论：不再记“初始严格补”；只保留 `nx→zx` 单向补与“任务完成后旧 nx 当前窗口关闭”的有效观察。

## 2｜系统性边界

跨《三国演义》《水浒传》《红楼梦》《西游记》四部独立作品，同一旧判据问题已经复现：

```text
A. nx 能帮助 zx 完成共同结果
≠
B. zx 能补 nx 自身核心功能缺口
```

严格补要求 B，不能拿“没有主体行动就没有共同结果”替代 B。

最短判别句：

> **反向拿掉必须打到 nx 自身核心功能，而不是只让共同结果失去执行者、目标触发者或兑换者。**

## 3｜反向缺口的合格与不合格

### 不合格

- 资源不会自动变成主体目标；
- 许可不会自动生成主体行动；
- 保护权没有具体对象时不会自动启动；
- 专家能力没有任务时不会自动产生战役结果；
- 外部接口缺少“有人来用它”。

这些都只是“共同结果缺调用者/触发者”，不是 nx 自身缺口。

### 合格候选

拿掉 zx 后，nx 自身仍成立，但其核心资源、权限、解决能力或现实作用必须出现一个**只能由 zx 补回**的不可替代缺口，例如：

- nx 的关键权限本身无法取得/维持；
- nx 的核心资源无法完成其自身必须完成的现实功能；
- nx 的关键处分/保护能力会因缺少 zx 而真实失效，而不是仅仅“没被调用”；
- 反向缺口不是由共同敌人、交换品、制度门槛等第三因素制造。

当前仓库尚缺足够高纯真严格补正例，禁止为了保留旧统计而降低门槛。

## 4｜对时间窗口研究的影响

“nx 当前执行窗口会结束”这一观察仍成立，但必须与“严格补时间窗口”拆开。

可继续保留：

```text
历史上 nx 真实激活
→ 当前任务完成 / 瓶颈消失 / 接口退出 / 资源内化
→ 旧 nx 不得永久追挂后续阶段
```

不得继续写：

```text
旧案例初始只是 nx→zx 单向补
→ 后来窗口关闭
→ 因而证明了“严格补闭环”
```

时间窗口是 nx 动态纪律；严格补闭环必须先证明初始双向严格补。

这条方法可直接迁移到另外四轴：

> **对子中的反向补缺必须作用到另一端自身结构，而不能只证明共同结果需要两个参与者。**
