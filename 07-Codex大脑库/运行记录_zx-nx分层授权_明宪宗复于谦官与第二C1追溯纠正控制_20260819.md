# 运行记录｜明宪宗复于谦官与第二 C1 追溯纠正控制

## 0｜本轮目的

当前待审议已经区分：

```text
A｜事后报告/备案
B｜事后追责主体
C1｜真正追溯撤销/纠正旧决定本身
C2｜重新授权/重新接纳/新任命
```

仓库上一轮已用宋孝宗追复岳飞原官锁定首个高纯 C1。本轮寻找第二个独立历史控制，测试“旧处分已生效 + 被处分者无后续新功 + 后来最高权限明确认定旧案受枉并恢复旧官/官方状态”是否稳定复现。

## 1｜史料事实

### 1.1 旧处分真实生效

天顺元年夺门之变后，于谦与王文被捕。石亨、徐有贞等以谋逆罪构陷，于谦最终被处极刑，并发生籍家、家属受牵连等现实后果。

该状态不是口头威胁、未执行处分或待审决定，而是已经完成的政治/刑事处分。

### 1.2 后来旧案本身被重新评价

《明史》记载，石亨、曹吉祥等相继败亡后，“谦事白”。成化初，于谦之子于冕获赦归来，上疏为父讼冤，随后出现“得复官赐祭”。相关诰文还明确表示：

```text
在先帝已知其枉
而朕心实怜其忠
```

因此后段不是只追加一个新荣誉，而是对旧案官方评价本身进行纠正，并恢复于谦原有官的政治名位。

### 1.3 与 C2 的决定性差别

于谦已在天顺元年被处死。

所以不可能存在：

```text
旧处分生效
→ 于谦后来重新立功
→ 朝廷按新功重新任命
= C2
```

更符合：

```text
旧处分真实生效
→ 构陷者败亡、旧案重新审视
→ 最高权限承认旧案受枉
→ 复原官 + 赐祭
→ 官方政治/官爵状态被追溯纠正
= C1
```

## 2｜zx 判断

### 结论

`zx_new_expansion_in_revocation_stage: rejected_as_primary`

明宪宗能够为旧案昭雪、恢复官爵，是既有最高皇权在旧案/官爵对象层的直接调用。没有证据显示宪宗因本案获得一个此前不存在的新决定范围。

现行 zx 必须看到主体自身权能公开进入现实并继续扩大决定边界。本案影响巨大，但“决定影响巨大”不能替代“权限边界扩大”。

所以：

> 旧案被皇帝纠正 ≠ 皇帝因此发生新的 zx 扩权。

## 3｜nx 判断

### 结论

`nx_in_revocation_decision_layer: rejected_as_primary`

在“是否纠正于谦旧政治/官爵处分”这一窄对象层，最终决定接口就在皇帝一侧。宪宗不需要再向另一个更高现实权限主体请求批准后才使复官赐祭生效。

于冕的上疏属于触发/信息输入，不等于最终权限在于冕手里，也不把宪宗变成 nx。

因此本轮更接近：

`x_existing_final_revocation_authority_neighbor: evidence-locked`

## 4｜关键压力

关键历史压力包括：

- 夺门之变后的政治清洗；
- 石亨、徐有贞、曹吉祥等权力集团变化；
- 成化初对旧案的重新评价。

这些只能解释为什么旧案获得重新审视，不能直接判 zx/nx。

真正有判别力的是：

```text
旧处分已实际生效
+ 旧案后来被明确认定受枉
+ 恢复的是原官/旧官方状态
+ 被处分者已死亡，无法通过后续新功建立新状态
```

## 5｜拿掉测试

### 5.1 拿掉“忠臣”“冤案”等价值评价

只保留：

```text
原谋逆处分已执行
→ 后来官方认定旧案受枉
→ 复官赐祭
```

C1 仍成立。

### 5.2 拿掉后来的谥号、祠祭扩展

只保留成化初“谦事白 → 复官赐祭”，本轮 C1 仍成立；弘治年间追加太傅、谥肃愍等不是分类支柱。

### 5.3 拿掉于冕的个人上疏

若仍存在最终皇权主动/经其他渠道确认旧案受枉并恢复原官，C1 的权限结构仍成立。于冕上疏是触发证据，不是恢复权来源。

## 6｜反向测试

### 6.1 反向成 C2

如果结构是：

```text
于谦旧处分有效
→ 本人后来重新立功或重新承担职务
→ 朝廷依据新功再授职位
```

则应判 C2，不是 C1。

### 6.2 反向成“追加荣誉但不纠正旧处分”

若朝廷只追加祭祀、谥号或纪念，但不承认旧案受枉、不恢复原官或旧政治状态，则 C1 显著下降。

### 6.3 反向成 nx

若宪宗只能建议复官，必须经过另一个真实最终节点批准才能生效，则本对象层 nx 上升。史料不支持此结构。

## 7｜最近邻排除

### 7.1 x

本轮最强最近邻是 `x`：既有最高官爵/旧案纠正接口在皇权侧，当前是其直接调用。

### 7.2 xn

于冕上疏、礼部办理、祭祀安排等属于程序与执行层，不回答谁拥有最终纠正接口。

### 7.3 zx

皇帝决定很强、结果影响很大，不等于决定范围新增。无扩边即不重复收 zx。

### 7.4 nx

存在上疏与臣下建议，不等于皇帝沿臣下权限通道推进。必须分清信息输入与最终决定权。

## 8｜第三因素冻结

以下因素全部冻结，不参与木轴主判：

- 于谦是否忠臣；
- 夺门之变的道德评价；
- 石亨、徐有贞等人的善恶；
- 英宗是否后悔；
- 后世祭祀与民族英雄形象；
- 明宪宗个人政治评价。

只检查：

> 旧处分是否真实生效？后来处理的是旧决定本身还是新状态？谁掌握最终纠正接口？该接口是否需要外部再批准？

## 9｜与岳飞 C1 的最小差异

### 岳飞

```text
旧冤狱处分生效
→ 二十年后宋孝宗追复元官
→ 处理旧官爵/官方记录
= C1
```

### 于谦

```text
旧谋逆处分生效
→ 构陷集团败亡、旧案“事白”
→ 成化初明确认定受枉并复官赐祭
→ 处理旧政治/官爵状态
= C1
```

两例共同排除：

> “后来恢复”只能是 C2。

更窄纪律为：

> 若被处分者已无法产生后续新功，且最终权限明确针对旧案受枉/旧官爵状态实施恢复，则“恢复”可以构成真正 C1，而不是新状态的重新任命。
