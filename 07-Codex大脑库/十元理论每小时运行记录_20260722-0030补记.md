## 源端点、目标端点与变量

### 源端点 zn

```text
没有奖励、认可、监督与结果保证
主体仍认为某个人、某件事或某段意义不能被抛下
```

排除普通善良、社会职责、宗教身份、法律义务、害怕评价和任务性承担。

### 目标端点 n

```text
对象进入主体或结构内部
→ 被接住
→ 被允许停留
→ 负荷被持续处理
→ 不是立即推出、外包或一次象征动作
```

### 被改变变量

- “不能推出去”的对象范围；
- 愿意接收的对象范围；
- 接入后的持续承担时间；
- 对象是否从外部议题变成内部负荷；
- 是否形成接收、停留和处理闭环。

### 成立阶段与体量

```text
zn 确定对象不能被放弃
→ 对象被纳入自身承担范围
→ 接收与处理反复成立
→ n 的承载边界或能力上升
```

低体量为一次明确接手；中体量为持续照护、隐藏或承担后果；高体量为可重复接收并跨时间处理负荷的结构。

## 候选机制

### 候选 A：意义扩大承接边界

```text
这件事不能被丢下
→ 主体重划什么必须由自己接住
→ 外部对象进入自身承担范围
→ 持续接收与处理形成
→ n 上升
```

理论后果：若成立，目标变量是承接边界，不要求先有建筑或公开号召；最多先锁关系层或结构启动层。

### 候选 B：意义只提供理由，中介才形成 n

```text
zn 提供理由
→ zx 公开推动并守住空间
→ xn 分工、记录和维持
→ x 提供资源、权限与准入
→ n 形成
```

理论后果：若 B 更准确，母行只能保留几何压缩，具体链应写 `zn→zx/xn/x→n`。

### 排除候选

“多人相信同一件事，聚集后自动形成共同体”不成立。没有接收、停留、持续处理与抗崩能力，就没有 `n`。

“不能把马克斯交给迫害体系”使外部逃亡者进入家庭内部并被长期隐藏、供给和照护。但隐藏规则 `xn` 与家庭资源、准入 `x` 仍不可拿掉。

无统一领袖的群体因“遗属不能被独自留下”形成固定接收、资料保存、休息与陪伴位置。该结构更接近低 `zx` 起点，但缺少第二个可核验人物文本。

4. 拿掉成熟 `xn` 时承接若已开始，只能支持低体量 A；
