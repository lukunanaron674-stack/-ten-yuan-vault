# 待审议｜外部承认与内部 zn 真正成立的时序必须分层

## 0｜状态

本文件是 L4 `pending-review`，不是 L2 正本。

达到跨 3 独立作品门槛后停止自动升格，只提出待审议命题与证据门：

> **外部承认 / 保护 / 合法化可以追上一个已经独立成立的 `zn`，但不能被倒写成该 `zn` 的生成时点；同时，强外部承认也不能单独制造 `zn`。**

因此候选纪律是：

```text
recognition timing
≠
zn establishment timing
```

## 1｜正向控制｜3 works

### 1.1 《水浒传》宋江｜99/98

- 第36回与第71回，正式招安 / 赦免尚未到来，相关“最终仍保留合法回返 / 归顺资格”的原则已在高代价冲突中进入排序。
- 第82回朝廷正式招安，是外部最高权威后来追上并允许该方向现实兑现。
- 拿掉第82回承认，前述 `zn` 仍能独立成立。

结论：`recognition_can_lag_established_zn = true`。

### 1.2 《红楼梦》鸳鸯｜99/98

- 贾母公开支持以前，鸳鸯已在邢夫人、兄嫂的利益诱因和威胁中明确拒绝强纳，并把边界扩展到未来。
- 贾母介入后，外部保护 / 承认改善现实结果，但不是该拒绝原则的起点。

结论：`high_level_support_can_lag_established_zn = true`。

### 1.3 《三国演义》关羽｜99/98

- 第25回旧义已进入约三事与未来退出条件；第26回在曹操厚待、爵禄存在时仍决定离曹归刘。
- 第27回曹操才公开称许其“不忘故主”“财贿不动其心、爵禄不移其志”。
- 曹操的赞许是后来识别已经成立的原则，而不是生成旧义。

结论：`explicit_recognition_can_lag_established_zn = true`。

## 2｜反向护栏｜1 work

### 《三国演义》吕布｜99/98

- 认董卓义父、公开关系命名、封赏与组织位置都很强。
- 但这些承认高度伴随赤兔、金珠、官位与现实收益；后续冲突中“父子之义”也未稳定保留最终排序资格。

因此：

> **强外部承认 ≠ 内部 `zn` 真正成立。**

该护栏证明承认不仅不是必要条件，也不是充分条件。

## 3｜候选证据门

### 3.1 正向“承认后来追上”至少满足

1. `zn` 在外部承认到来前已经独立通过 current canonical；
2. 承认前存在无奖励 / 高代价或至少明确冲突排序证据；
3. 外部承认到来后识别的是同一原则对象，不是换了新对象；
4. 拿掉后续承认，先前 `zn` 仍能解释实际选择；
5. 不把被承认后的名位、资源或权限自动写成 `x`。

### 3.2 反向“强承认仍不足”至少满足

1. 关系命名、称号、封赏、公开赞许或高位保护真实存在；
2. 拿掉这些外部认可以后，候选原则不能独立过 `zn` 硬门；
3. 冲突中缺稳定排序或未来调用资格；
4. 不因“被评价得很像某原则”就回填主体内部本体。

## 4｜与最近邻分层

### `zn vs z`

外部赞誉、合法化、保护、封号首先是外部确认层；只有主体内部原则在无这些认可时仍独立过门，才锁 `zn`。

### `zn vs x`

被承认 / 被授予身份不等于现实对象进入主体稳定处分边界。`x` 必须另查实际调用、处分、否决或排除。

### `zn vs lifecycle`

“承认后来追上”回答**谁先成立**；lifecycle 回答**端点在窗口变化中是否继续、关闭、复位或换载体**。两类统计分账。
