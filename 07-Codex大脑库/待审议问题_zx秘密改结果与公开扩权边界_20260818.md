# 待审议问题｜zx：秘密改结果 与 公开扩权 的边界

## 1｜触发原因

连续三部独立作品出现同型材料：主体确实成功改变具体结果，但主要依靠秘密绕权、欺骗、诱导或让他者误操作完成；主体并未公开取得新增决定位置，也没有让现实秩序围绕一个新增的主体权限接口运行。

## 2｜三部作品证据

### 《西游记》孙悟空偷桃偷酒偷丹

- 通过支开、隐身、伪装、趁无人、定身等方式绕过资源权限。
- 蟠桃、御酒、金丹结果被真实改变。
- 但孙悟空没有在该秘密阶段公开取得王母/老君/天庭资源处分权；本人反而因预期追责而逃离。
- 结论：秘密改结果，伪 zx。

### 《三国演义》周瑜蒋干盗书

- 周瑜秘密制造假书与观察窗口，诱使蒋干把假情报带回曹营。
- 曹操调用自己的处分权误杀蔡瑁、张允。
- 周瑜成功改变曹营人事结果，但没有取得曹营将领处分权。
- 结论：秘密操纵成功，伪 zx。

### 《红楼梦》王熙凤毒设相思局

- 凤姐通过假约、封锁空间、再次诱导、调用贾蓉贾蔷设局，使贾瑞受困、受辱、负债。
- 结果被实际改变，但凤姐没有公开建立或取得一个新增的正式处分接口。
- 结论：秘密操纵成功，伪 zx。

## 3｜候选纪律

当前候选：

> **结果变化不是 zx 的充分条件。**

高质量 zx 证据仍应优先满足：

```text
主体自身权能公开进入现实
→ 他者/秩序被迫围绕主体重新反应
→ 主体决定范围、作用位置或凌驾程度真实上升
```

若主要机制是：

```text
隐匿 / 欺骗 / 诱导 / 绕权 / 让他人误操作
→ 具体结果成功改变
→ 但现实没有承认或被迫围绕主体新增的决定接口运行
```

则应优先排除“成功 = zx”，并检查 `xn / x / nx` 等最近邻。

## 4｜与真 zx 的最小差异

需要继续寻找反向材料：

### 真 zx

```text
公开施加自身权能
→ 原决定结构失效或退让
→ 主体成为新的现实决定来源
→ 主体作用位置/决定范围上升
```

### 秘密改结果伪 zx

```text
秘密改变结果
→ 原权限主体在不知情/误判中被绕开或误操作
→ 主体没有取得新增公开决定位置
```

## 5｜待验证问题

1. “公开”是否是 zx 的必要硬门，还是存在极少数幕后扩权也可判 zx 的情况？
2. 若秘密操纵长期反复成功，并最终让主体事实上稳定控制他者/系统，是否应从 `xn` 过渡检查 `x`，而非直接检查 zx？
3. 何种“他者重新反应”才算围绕主体权能重排，而不是仅仅被误导后的结果变化？
4. 若秘密阶段后暴露，并进入公开对抗/扩权，是否必须严格切成两个阶段分别判定？
