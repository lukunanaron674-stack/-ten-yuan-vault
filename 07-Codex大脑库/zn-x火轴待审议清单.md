## C｜当前反误判纪律

1. 放弃/失去 `x` ≠ 自动 `zn`。
2. 已成立 `x` 被限制 ≠ 自动 `zn`；先查限制来源。
3. 外部封号/认可/身份变化 ≠ `zn` 被改写。
4. 职位、印信、代理授权 ≠ 稳定 `x`。
5. 保护/责任/不抛下/公共责任 ≠ 被负责对象进入 `x`。
6. `zn` 限制 `x` 使用方式，不等于 `x` 不成立。
7. `zn+x` 共现前，两端必须分别独立过 current canonical。
8. 跨阶段、跨对象层的高纯端点不能拼成当前共现。
9. 最终结果与 `zn` 同向 ≠ 主体拥有使结果生效的 `x`；第三方 veto 必须归第三方。
10. co-occurrence ≠ strict complement。
11. strict 同 criterion_version 才累计跨作品。
12. current reality anchor ≠ absolute metaphysical uniqueness。
13. strict `x→zn` 禁止循环定义：先用不引用被测 `x` 的语言独立命名 `zn`。
14. 共享治理 `x` 不能私有化给单一领导者。
15. 高纯 P1 `zn` 不能跨原则倒灌。
16. `self-restraint-looking use of x ≠ independent zn`。
17. local `x` ≠ global `x`；future revocability ≠ prior current x never existed。
18. 当前 `x` 关闭 ≠ `zn` 未来调用资格删除；`x` 持续 on ≠ `zn` 永久持续。
19. historical `zn` ≠ permanent identity。
20. recognition time ≠ establishment time。
21. 高责任/高代价 ≠ `zn`。
22. 真实第三因素足以解释同一结果时，不重复拿结果证明 `x`。
23. pressure-display 解压后必须 same principle + same boundary + same conflict-order criterion。
24. evidence-locked 可被对抗审计撤回。
25. control 数与 independent work 数分开。
26. execution/amplification/screened resource/old governance object 不自动等于 strict current anchor。
27. `real x loss ≠ automatic x→zn gap`。
28. 多个不同 `x` 共同承载同一原则时默认分别测，禁止按目标结果事后拼装 composite `x`。
29. 公开自罚/自限与治理收益同向时，必须先冻结服众、信誉、绩效和威慑等第三因素。
30. 对象当场表现触发的敬佩/认可不能倒填成压力前已成立 `zn`。
31. 一次物理可杀/可抓/可击倒机会不能补成稳定 `x`。
32. 稳定 `x` + 主动释放结果也不能替 `zn` 端上班；先冻结外部通道、政治交换、资源回报与战略合作。
33. outcome-changing opportunity ≠ object-constituting current anchor。
34. 同一 instrumental policy 的多次重复 ≠ `zn` 跨情境未来调用资格。
35. 候选原则与正式制度/角色规则语义同构时，必须额外证明 evidence independence。
36. 巨大 delegated `x` 只会放大风险/诱惑，不自动成为 `zn` 的现实构成 anchor。
37. 稳定庇护空间若真实构成受保护群体、持续供给接口和明确我方边界，可以通过 strict `x→zn` v2，但必须与钱、人脉、电话等辅助资源分账。
