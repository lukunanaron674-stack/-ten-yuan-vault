## C｜当前反误判纪律

1. 放弃 / 失去 `x` ≠ 自动 `zn`。
2. 已成立 `x` 被限制 ≠ 自动 `zn`；先查限制来源。
3. 外部封号 / 认可 / 身份变化 ≠ `zn` 被改写。
4. 持有对象、职位、印信、代理授权 ≠ 稳定 `x`。
5. 历史外部来源 ≠ 当前永久外置；完成交付后重新查 `x`。
6. 保护 / 责任 / 不抛下 / 公共责任 ≠ 被负责对象进入 `x`。
7. `zn` 限制 `x` 的使用方式，不等于 `x` 不成立。
8. `zn+x` 共现前，两端必须分别独立过 current canonical。
9. co-occurrence ≠ strict complement。
10. 现实执行接口 ≠ `zn` 不可替代现实落点。
11. 名义身份 / 高称号 / 外部承认 ≠ 现实 `x`。
12. 外部交权意向 ≠ 权已经归主体。
13. 名义授权 + 部分管理动作 ≠ 稳定全局 `x`。
14. 局部现实 `x` 成立 ≠ 整个组织 / 任务层全部 `x` 成立。
15. 上位节点能未来整段撤销 ≠ 当前现实 `x` 从未成立；current-x、scope、override、revocation 与永久归属分开。
16. 当前 `x` 关闭 ≠ `zn` 未来调用资格被删除。
17. old `x` lost + different new `x` formed ≠ `zn` 必然被替换。
18. 被承认的时间 ≠ `zn` 真正成立的时间。
19. 强外部承认 ≠ `zn`。
20. 被承认 / 赦免 / 受诏 ≠ 自动形成现实 `x`。
21. 高责任执行 / 承担代价 ≠ `zn`；先拿掉外部委任、身份收益、问责与惩罚压力。
22. `x` 持续 on ≠ 已成立 `zn` 永久持续；后续同类冲突可真实退出/崩解。
23. 不同新 `x` 稳定形成 ≠ 旧 `zn` 必然跨载体持续。
24. 历史上曾成立的 `zn` ≠ 永久人物本体。
25. `x` 可以独立成立，不要求同步存在 `zn`。
26. 资源用途、职责、治理责任与“对象很重要” ≠ 自动 `zn`。
27. 被保护、共同移动、当前协同 ≠ 稳定现实 `x`；若第三因素已足以解释结果，不能重复拿结果证明 `x`。
28. **expression window blocked ≠ `zn` erased；pressure-display 必须在解压后按同一原则、同一硬门复位。**
29. **压力后的稳定原则 ≠ 压力前已经存在的同一原则；禁止 temporal backfill。**
30. **关系连续 ≠ 原则内容完全相同；pressure-display 必须比较同一可命名原则。**
