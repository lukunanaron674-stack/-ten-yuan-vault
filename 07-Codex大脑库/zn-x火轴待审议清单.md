## C｜火轴反例优先协议

第一类 negative guard 已有 1 work：

> **放弃/失去 x ≠ 自动 zn。**

当前控制：

```text
《西游记》孙悟空弼马温
实际掌握御马监职事/马匹管理 x
+
因官阶低、被轻视主动弃职
+
没有独立内部原则通过未来指导资格门
→ x 退出成立，zn 不自动成立
```

继续优先找第二独立作品：

```text
主体失去或放弃资源/职位/关系
+
原因是被迫、策略、地位比较、资源无价值、换取更大利益或外部命令
+
没有一项内部不可轻易让渡原则拥有冲突排序与未来指导资格
→ zn 不成立
```

第二类 negative guard：

> **外部封号/认可/身份变化 ≠ zn 被改写。**

第三类 negative guard：

> **持有对象 ≠ x 稳定成立。**

必须继续查实际使用、调配、处分、否决、排除以及撤权后是否仍成立。

第四类边界护栏（由 pure-x 首轮反向提示）：

> **资源来自别人 ≠ 当前一定 nx。**

如果交付已经完成，原节点不再保留逐次许可/撤回，而主体拥有直接处分能力，则优先检查当前 `x`；历史来源不能永久追挂。

第五类边界护栏（由 pure-zn 首轮提示）：

> **保护 / 不抛下某人 ≠ x。**

必须继续检查对象是否真的进入主体占有、调用、处分或排除边界；关系强度与责任原则不能替代 `x`。

第六类边界护栏（由晁盖第二正向控制提示）：

> **zn 限制 x 的使用方式，不等于 x 不成立。**

主体可以真实拥有处分/调用权，同时用内部原则给自己划定“即使有权也不做”的边界。不能把自我限权误写成“其实没有 x”。
