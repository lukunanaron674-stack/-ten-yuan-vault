# 五大主题与十元分层接口协议 v0.1

## 1. 本轮正式迁移

```text
Legacy（旧十元表达）

n 补克 nx

↓

Current（正式主题表达）

因果克制空间
```

旧表达停止作为现行十元关系、人物判定或动态链结论使用。

“因果克制空间”属于五大主题层的正式关系表达。它说明：因果的结果链、责任链、必然后果或结构性代价，压缩、封闭或改写空间能够继续容纳、展开和提供选择的条件。

它不自动等于某一条固定的十元关系。

## 2. 五大主题与十元并行，不互相替代

五大主题和十元各有独立作用：

```text
五大主题：
负责宏观归类、主题重心与主题级关系。
回答“这段故事主要在处理什么”。

十元：
负责人物、状态、行为、场景、时间结构等对象的具体语义。
回答“具体是谁、以什么方式、通过什么机制发生”。
```

因此不得写成：

```text
五大主题负责一切，十元只负责附注。
十元可以直接替代五大主题。
五大主题关系必然对应唯一十元对子。
```

正确关系是：

```text
五大主题很好归类。
十元很好具体化。
两层共同分析，颗粒度与任务不同。
```

## 3. 三元、十元、五大主题、动态链的职责

### 三元

提供高概括结构判断。

三元与十元并行，不得写成父子派生关系，也不得由一方唯一反推另一方。

### 十元

提供具体对象与功能语义判断。

十元判定必须区分：

```text
人物稳定本体
当前状态
关键行为功能
外部场景
时间关系 / 时间结构
视觉与光影
关系位置
```

表面关键词、职业、服装、道具、单次行为和光影不能越级证明人物本体。

### 五大主题

提供故事、人物线、场景线或事件群的宏观归类，并表达主题层关系。

需要继续区分：

```text
整部故事的主主题
局部段落的主题
人物承载的主题倾向
场景承载的主题倾向
主题之间的生克关系
```

### 动态链

表达具体对象在阶段中的生、克、补、显影、退隐和关系变化。

动态链不能只写抽象标签，必须注明关系端点属于人物本体、状态、行为、场景还是时间结构。

## 4. 主题关系与十元机制不是一一对应

同一个“因果克制空间”，可以由不同十元结构实现。

例如可能表现为：

```text
既定后果压缩人物可选择的空间。
责任链封死逃离路径。
长期积累的结果使原有容器无法继续承载。
某人物的具体行为触发后果，外部空间随之收缩。
```

这些案例必须分别判定人物本体、状态、行为、场景与时间结构，不能先看到“因果克空间”就倒推出固定十元关系。

硬规则：

> 禁止把五大主题关系直接翻译成唯一十元关系；也禁止拿某一条十元关系冒充整个主题关系。

## 5. 剧本与人物分析的稳定锚点

故事人物的核心锚点优先保持稳定。

剧情变化优先落在：

```text
当前状态变化
显影强度变化
行为功能变化
关系位置变化
外部场景变化
时间结构变化
动态链顺序变化
```

除非人物的存在方式发生整体重构，否则不得因为一次事件、一次服从、一次爆发、一次算计或一次视觉变化，就改写人物稳定本体。

## 7. 当前冻结结论

```text
正式主题关系：因果克制空间。
旧表达 n补克nx：停止作为现行关系使用，仅允许在迁移说明中出现。
五大主题：负责宏观归类与主题关系。
十元：负责具体对象与实现机制。
三元与十元：并行判断，不是父子派生。
动态链：负责具体对象之间的阶段性变化。
人物核心锚点：优先稳定，变化主要落在状态、关系和动态链。
```
