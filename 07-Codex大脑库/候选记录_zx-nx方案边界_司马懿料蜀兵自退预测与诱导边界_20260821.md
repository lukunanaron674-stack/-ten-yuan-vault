# 候选记录｜司马懿料蜀兵自退：预测 vs 诱导边界

## 1｜事实窗口

《三国演义》第98回，司马懿判断：陈仓道路受阻，其余小路运粮困难，蜀军行粮只能支持约一月，因此主张魏军坚守诸路关隘、不主动出战，等待蜀军粮尽自行退却，届时再乘虚追击。他同时提醒曹真：追兵必须先看虚实，避免深入中诸葛亮之计。

曹真接诏后继续布置各路坚守，并由郭淮、孙礼等提出封锁运粮小路、诱劫粮等具体措施。诸葛亮随后也明确判断魏军坚守是因为看准蜀军缺粮；在取得局部胜利后，仍因军粮不足主动撤兵。

## 2｜当前最小结构

```text
司马懿预判：
蜀军粮运困难
→ 不足一月
→ 将自行退兵

司马懿预设下游：
先坚守不战
→ 待退
→ 再乘虚击之
```

关键灰区：

- “蜀兵自退”不是司马懿直接命令的动作；
- 他也没有像博望坡诸葛亮、智取生辰纲吴用、收红孩儿观音那样，明确制造一个专门诱导动作，让对方按预设反应进入节点；
- 但魏军“坚守不出”与既有运粮受阻又确实持续维持了蜀军的后勤压力，因此也不能干净地说成完全没有诱导或条件塑造。

## 3｜zx 判断

当前窄阶段不锁 zx。

司马懿提出判断和战略建议，不等于自身决定范围继续扩大。是否拥有更高军事处分权、是否公开扩权，需要另证；本段主变量是方案结构，不是权限扩张。

结论：

`zx_in_narrow_stage: rejected_as_primary`

## 4｜nx 判断

司马懿的建议需要魏帝下诏、曹真等前线节点执行，因此存在权限入口 / 组织执行上的外部接口邻近；但“蜀军粮尽自退”的判断和“待退再击”的方案骨架由司马懿提出，不宜把方案设计层主判成 nx。

结论：

`nx_authority_execution_relation: present_but_not_primary`

## 5｜xn 灰区

支持 xn 的证据：

1. 主体明确预判外部反应“蜀兵自退”；
2. 主体事前把该反应放入“坚守→退兵→乘虚击之”的方案结构；
3. 该外部反应不是事后才被解释，而是提前出现于方案；
4. 若蜀军不退，原“乘虚击之”的下游节点无法按原方案触发。

反对直接锁 xn 的证据：

1. 缺少博望坡、黄泥冈、红孩儿那种清楚的主动诱导动作；
2. “坚守不战”究竟是在主动制造对方退兵，还是只是在利用对方已有粮运瓶颈，文本可双解；
3. 实际后段中，曹真一方又加入封锁小路、诱粮等独立方案，导致“退兵条件到底由谁组织”进一步混杂；
4. 蜀军最终确实撤退，但司马懿预设的“乘虚追击”并未按最初结构完整兑现，执行闭环不够干净。

因此当前不锁：

`external_reaction_counts_toward_subject_xn: deferred`

## 6｜拿掉测试

### 拿掉司马懿的预测

若只剩魏军普通坚守、蜀军因粮尽自行退，不能把“蜀军退兵”计入司马懿 xn。

### 拿掉主动条件塑造

若魏军并未通过坚守、封路等行为改变蜀军处境，只是司马懿纯粹预测对方某时会退，那么能否仅凭“预测 + 预设后续利用”把该反应计入 xn，正是当前未决点。

### 拿掉后续接续

若主体预测正确，但外部反应发生后主体并没有按预设继续利用，则只能证明预测，不足以证明完整结构传播已经兑现。

## 7｜反向测试

### 明确可锁 xn 的版本

```text
主体预判对方会退
→ 主体主动制造退兵条件
→ 对方按预期退
→ 主体预置追击节点立即接续
= xn 强
```

### 明确不可锁 xn 的版本

```text
主体随口预测对方会退
→ 没有组织条件
→ 对方后来自己退
→ 主体事后才临时利用
= 不足以把该反应计入主体xn
```

本例夹在两者之间。

## 8｜最近邻排除

- `nx`：外部权限与执行节点存在，但方案判断本身不是沿别人现成方案续接。
- `zx`：战略判断正确、影响大，不等于决定范围扩张。
- `xn`：真正争议是“预判 + 预设利用”是否已经足以组织传播关系，还是必须存在更明确的主动诱导 / 条件塑造。
- `z`：退兵是未来关键节点，但本轮研究重点不是单一裁定，而是节点是否被主体组织进结构。

## 9｜第三因素冻结

冻结：司马懿是否比诸葛亮聪明、曹真能力、蜀魏最终胜负、历史真实性、人物官职高低、后续北伐结果。

只检查：

1. 外部反应是否被事前预测；
2. 主体是否主动制造该反应条件；
3. 该反应是否被事前放入方案结构；
4. 反应发生后是否由主体继续按预设接续。
