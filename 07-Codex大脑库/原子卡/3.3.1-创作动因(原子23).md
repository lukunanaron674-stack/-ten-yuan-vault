# 3.3.1 创作动因（原子23）

## 基础定义
创作动因是引发艺术创作行为的初始驱动力。

## 三元分析

### 无三元干涉
内部动因（表现欲望）vs 外部动因（社会需求/委托）

### 三元解释
- **内部 = zn**（心中有话不得不说）
- **外部 = nx/xn**（社会暗流或规则要求）
- **理想状态**：内外共振——zn想说的恰好就是nx需要的
- **最坏状态**：纯外部驱动没有内部响应——作品沦为任务
- **最危险状态**：zn被x并z替代——当创作动因变成"这个能火"，精神内核就被流量欲望污染

### 因果链定位（zx+nx）
创作动因是因果链的起点：内部(zn)催生行动(zx)，外部(nx)设定方向和边界
