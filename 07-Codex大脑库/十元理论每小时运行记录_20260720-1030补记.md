## 源端点

`nz` 必须先存在：

```text
真实共同关系
→ 时间厚度与余温
→ 不愿承认关系结束
→ 仍保留回返、等待或继续靠近的位置
```

一次好感、一次照顾、恋爱题材、现实依赖和害怕孤独均不够。

## 目标端点

`nx` 必须出现：

```text
方向、权限或解决通道由他者／关系给出
→ 主体不把自己放在最终决定位置
→ 沿该方向或通道继续行动
```

听一次建议、正常分工、被威胁服从和原本无权决定均不够。

## 被改变变量

- 主体对方向决定位置的认领强度；
- 独自决定的必要感；
- 对关系给出方向的接受度；
- 是否保留替代方案与否决位置；
- 跟随是否只在该段关系中发生；
- 拿掉关系余温后，跟随是否仍成立。

## 候选机制

### 候选A：可信停靠降低独自定向负担

```text
已有关系余温与可信回返位置
→ 主体不再把每一步都视为必须独自决定
→ 暂时接受关系对象已给出的方向
→ nx 状态／关系功能上升
```

理论后果：只可先成立于关系层和状态层，不表示 nz 把非 nx 人物永久改造成 nx。

### 候选B：为了维持关系而让出方向

```text
主体不愿关系结束
→ 判断持续争夺方向会破坏停靠
→ 主动少占决定位置
→ 沿对方方向继续
```

理论后果：nx 由保留关系目的触发；但必须排除对方主动领路、控制与身份权力。

### 排除机制C：n 的现实接住冒充 nz

住房、资源、照护和安全使主体接受安排，改变方向的可能是 n 与现实依赖，不是 nz。

### 排除机制D：权力／身份服从

上级、家长、导师或伴侣本来拥有决定权时，优先检查 x、zx、xn、年龄和监护关系。

## 拿掉测试

1. 拿掉 nz 后，若主体仍因职位、年龄、资源、危险或任务跟随，不成立；
2. 拿掉对方主动领路后，若 nx 消失，更接近外部方向压入；
3. 拿掉现实照护与安全条件后仍因不愿结束而跟随，才支持直接作用；
4. 拿掉共同时间，只剩一次温柔，源端点不存在；
5. 拿掉方向认领变化，只剩陪伴与不舍，目标端点不存在；
6. 恢复替代路线与否决机会后仍主动少占方向，候选纯度才提高。

