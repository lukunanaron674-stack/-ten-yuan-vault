# 待审议｜nx：外部方案已经存在，但主体实际重设关键运行结构

## 1｜触发原因

连续三部独立作品出现同型边界：

```text
外部目标/方案已经存在
→ 主体拥有真实低成本重设窗口
→ 主体不是沿旧方案续接
→ 实际否定、替换关键运行结构
→ nx 在该运行层下降
→ xn 最近邻上升
```

该问题已跨《水浒传》《三国演义》《红楼梦》复现，达到建立待审议问题门槛。

## 2｜三部作品

### A｜《水浒传》杨志押送生辰纲

梁中书给出押送目标与原始运输方案；杨志否定公开车运，改成挑担伪装，并重设人员服从与行军时段。

锁定：外部最终目标仍在，但运行层不是单纯 nx；优先检查 xn。

### B｜《三国演义》马谡守街亭

诸葛亮不仅给“守街亭”目标，还给要道下寨、与王平商议等明确约束；马谡到场后主动否定并改成山上屯军。

锁定：外部已有明确方案时，主体仍可通过实际重写让当前运行层 nx 下降。

### C｜《红楼梦》薛宝钗园务二次重设

探春已经提出婆子分片管理、收益与归账方案；宝钗进一步否定“归到里头”的关键环节，改成不归账、以收益直接抵若干园内支出，并新增分润、利益冲突与人选接口设计。

锁定：合作参与不等于沿方案执行；如果主体实际替换关键运行机制，应检查 xn。

## 3｜最小共同结构

三例共同保留：

```text
上位目标可以来自外部
外部甚至可以已经给出一套方案
但主体仍拥有真实重设窗口
且实际使用该窗口
```

三例共同变化：

```text
谁决定“怎么运行”
```

因此待审议核心不是“外部目标是不是 nx”，而是：

> **nx 的外部方向/通道口径，应否明确加入对象层纪律：上位目标外置不能自动覆盖下位运行层；当主体实际重设关键流程、节点、资源与协同结构时，该运行层应优先检查 xn。**

## 4｜候选纪律

仅作为 pending-review，不写入正本：

```text
外部给目标 + 主体沿既有方案执行
→ nx候选

外部给目标/方案 + 主体拥有重设窗口但未使用
→ 仍可为nx候选

外部给目标/方案 + 主体实际否定并重设关键运行结构
→ 当前运行层nx下降，优先检查xn
```

## 5｜不能偷换成 zx

三例也共同证明：

> **方案重写 ≠ 自动扩权。**

若主体只是利用已有授权范围重新组织运行，而没有取得更高决定范围、没有让外部秩序围绕新增权力中心重排，仍不能因为“我推翻了旧方案”直接判 zx。

## 6｜后续验证需求

下一步不再继续堆第四个同型正例，优先寻找反例：

1. 主体看似修改方案，但修改只是在外部方案预留的普通自由度内，是否仍应判 nx？
2. 主体提出局部修补，但关键节点、资源和最终流程仍由外部决定，何时只是 nx 内部微调？
3. 主体真正重设方案以后，又是否因上级逐项审批而重新表现 nx 权限关系？
4. 找同一人物跨阶段的最小差异，检查“执行旧方案 → 改写方案”是否稳定对应 nx 下降 / xn 上升。
