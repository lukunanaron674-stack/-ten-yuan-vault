# 待审议｜nx：外部方案已经存在，但主体实际重设关键运行结构

## 1｜触发原因

连续三部独立作品出现同型边界：

```text
外部目标/方案已经存在
→ 主体拥有真实低成本重设窗口
→ 主体不是沿旧方案续接
→ 实际否定、替换关键运行结构
→ nx 在该运行层下降
→ xn 最近邻上升
```

该问题已跨《水浒传》《三国演义》《红楼梦》复现，达到建立待审议问题门槛。

当前又补入两部反向控制，用来防止规则被误读成：

```text
主体只要自行改了若干执行动作
→ 就自动算xn方案重设
```

现有反向控制来自《西游记》孙悟空红孩儿诱敌与《三国演义》赵云博望坡诱敌。二者都显示：主体可以拥有明显临场自由，但只要关键节点、资源、协同接口、成功/失败条件与最终处置路径没有被替换，nx 的外部方案/任务续接仍可保持。

这些反向控制不改变待审议状态，也不修改理论正本。

## 2｜三部正向作品

### A｜《水浒传》杨志押送生辰纲

梁中书给出押送目标与原始运输方案；杨志否定公开车运，改成挑担伪装，并重设人员服从与行军时段。

锁定：外部最终目标仍在，但运行层不是单纯 nx；优先检查 xn。

### B｜《三国演义》马谡守街亭

诸葛亮不仅给“守街亭”目标，还给要道下寨、与王平商议等明确约束；马谡到场后主动否定并改成山上屯军。

锁定：外部已有明确方案时，主体仍可通过实际重写让当前运行层 nx 下降。

### C｜《红楼梦》薛宝钗园务二次重设

探春已经提出婆子分片管理、收益与归账方案；宝钗进一步否定“归到里头”的关键环节，改成不归账、以收益直接抵若干园内支出，并新增分润、利益冲突与人选接口设计。

锁定：合作参与不等于沿方案执行；如果主体实际替换关键运行机制，应检查 xn。

## 3｜反向控制

### A｜《西游记》孙悟空红孩儿诱敌

观音已经规定决定性方案骨架：

```text
孙悟空去索战
→ 许败不许胜
→ 把红孩儿引到观音所在位置
→ 由观音掌握最终陷阱、资源与收伏接口
```

孙悟空在执行中确有自主变化，包括打破洞门、叫阵、短暂交战、故意败退、使用激将话术等；但这些动作没有改写：

- “诱敌而不是正面击杀”的总体方法；
- “许败不许胜”的关键节点；
- 最终诱导位置；
- 观音掌握的关键资源；
- 最终收伏与处分接口。

因此高置信锁定：

```text
局部执行自由度
≠ 关键运行结构重设
```

关联正式案例：`05-银矿库/角色库的/西游记_孙悟空红孩儿诱敌_zx-nx局部执行自由度反例_20260816.md`，事实置信 99，分类置信 98。

### B｜《三国演义》赵云博望坡诱敌

诸葛亮把赵云前部任务的决定性终点规定得非常清楚：

```text
不要赢
只要输
→ 以诈败把夏侯惇继续引入博望坡后续伏击结构
```

赵云在真实执行中并非机械木偶。他可以自行决定交战数合、何时回马、何时再次退却，并实际出现“数合后诈败 → 退十余里回战 → 再战数合再退”的局部节奏变化。

但这些变化没有替换：

- “诱敌而不是当场取胜”的关键战术终点；
- 博望坡整体诱入结构；
- 伏兵、火攻等关键资源与协同接口；
- 成功条件；
- 更高层战术处置路径。

真正执行窗口里，赵云持续兑现诸葛亮给定的“不要赢、只要输”。因此高置信锁定：

```text
局部战斗节奏 / 回马时机 / 动作顺序自由
≠ 关键战术方案重设
```

本例中 `nx_behavior_function_in_tactical_task: evidence-locked`，而 `xn_local_execution_neighbor: present_but_secondary`。角色自己回一次马，并没有因此晋升成整场战争的系统架构师。

关联正式案例：`05-银矿库/角色库的/三国演义_赵云博望坡诱敌_zx-nx被动承接通道激活压力测试_20260820.md`，事实置信 99，分类置信 98。

## 4｜最小共同结构

三例正向支持共同保留：

```text
上位目标可以来自外部
外部甚至可以已经给出一套方案
但主体仍拥有真实重设窗口
且实际使用该窗口
```

三例共同变化：

```text
谁决定“怎么运行”
```

两部反向控制进一步要求把“怎么运行”分成两层：

```text
执行层手段：
话术、路线、动作顺序、临场微调、交战节奏、回马时机

关键运行骨架：
决定性节点、资源配置、协同接口、失败/成功条件、最终处置接口
```

因此待审议核心不是“外部目标是不是 nx”，也不是“主体有没有自己想动作”，而是：

> **主体有没有实际替换决定性运行结构。**

## 5｜候选纪律

仅作为 pending-review，不写入正本：

```text
外部给目标 + 主体沿既有方案执行
→ nx候选

外部给目标/方案 + 主体拥有重设窗口但未使用
→ 仍可为nx候选

外部给目标/方案 + 主体仅在预留执行自由度内微调
+ 关键节点、资源与最终接口未变
→ nx不因局部变化自动下降
→ 不足以锁xn方案重设

外部给目标/方案 + 主体实际否定并重设关键运行结构
→ 当前运行层nx下降
→ 优先检查xn
```

目前最重要的判别问题压成五问：

1. 谁给最终目标？
2. 谁设计关键运行骨架？
3. 主体改的是执行层手段，还是关键节点/资源/接口？
4. 拿掉主体的临场微调后，原方案能否仍按同一骨架成立？
5. 主体的自由是否改变成功/失败条件或最终处置路径？

## 6｜不能偷换成 zx

正向三例与两部反向控制都共同证明：

> **方案重写或执行自由 ≠ 自动扩权。**

若主体只是在已有授权范围内重新组织运行，或只在外部方案允许范围内自由发挥，而没有取得更高决定范围、没有让外部秩序围绕新增权力中心重排，仍不能因为“我改了做法”直接判 zx。

## 7｜最近邻边界

### nx vs xn

```text
nx：关键方向/方案骨架仍由外部给出，主体实际沿它推进。
xn：主体实际重设决定性流程、节点、资源与协同结构。
```

不能用“主体有自主动作”作为 xn 的捷径。

### xn 的最低强化证据

优先要求至少出现一项：

- 替换关键节点；
- 改变资源配置；
- 重设协同接口；
- 改变成功/失败条件；
- 改变最终处置路径；
- 让旧方案在关键结构上不能原样运行。

只有路线、话术、动作先后、交战节奏、回马时机或普通执行微调，证据不足。

## 8｜后续验证需求

下一步不再继续堆第四个“真实方案重设”正例，优先寻找反向与灰区：

1. **第三部独立作品的局部执行自由反例**：优先《水浒传》或《红楼梦》，要求主体明显拥有临场自由，但关键节点/资源/终点保持不变，检查 nx 是否稳定保持。
2. 主体提出局部修补，但关键节点、资源和最终流程仍由外部决定，何时只是 nx 内部微调？
3. 主体真正重设方案以后，又是否因上级逐项审批而重新表现 nx 权限关系？
4. 找同一人物跨阶段的最小差异，检查“执行旧方案 → 改写方案”是否稳定对应 nx 下降 / xn 上升。
