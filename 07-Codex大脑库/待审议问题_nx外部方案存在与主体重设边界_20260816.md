# 待审议｜nx：外部方案已经存在，但主体实际重设关键运行结构

## 1｜触发原因

连续三部独立作品出现同型正向边界：

```text
外部目标/方案已经存在
→ 主体拥有真实低成本重设窗口
→ 主体不是沿旧方案续接
→ 实际否定、替换关键运行结构
→ nx 在该运行层下降
→ xn 最近邻上升
```

该问题已跨《水浒传》《三国演义》《红楼梦》复现，达到待审议门槛。

同时，现已补齐三部独立作品的反向控制，用来防止规则被误读成：

```text
主体只要自行改了若干执行动作
→ 就自动算 xn 方案重设
```

三部反向控制共同显示：主体可以拥有明显临场自由，但只要关键节点、资源配置、协同接口、成功/失败条件与最终处置路径没有被替换，nx 的外部方案/任务续接仍可保持。

这些反向控制只强化边界，不修改理论正本。

## 2｜三部正向作品

### A｜《水浒传》杨志押送生辰纲

梁中书给出押送目标与原始运输方案；杨志否定公开车运，改成挑担伪装，并重设人员服从与行军时段。

锁定：外部最终目标仍在，但运行层不是单纯 nx；优先检查 xn。

### B｜《三国演义》马谡守街亭

诸葛亮不仅给“守街亭”目标，还给要道下寨、与王平商议等明确约束；马谡到场后主动否定并改成山上屯军。

锁定：外部已有明确方案时，主体仍可通过实际重写让当前运行层 nx 下降。

### C｜《红楼梦》薛宝钗园务二次重设

探春已提出婆子分片管理、收益与归账方案；宝钗进一步否定“归到里头”的关键环节，改成不归账、以收益直接抵若干园内支出，并新增分润、利益冲突与人选接口设计。

锁定：合作参与不等于沿方案执行；如果主体实际替换关键运行机制，应检查 xn。

## 3｜三部反向控制

### A｜《西游记》孙悟空红孩儿诱敌

观音规定：孙悟空索战、许败不许胜、把红孩儿引到指定位置，由观音掌握最终陷阱、资源与收伏接口。

孙悟空执行中自行破门、叫阵、短战、败退、激将，但没有改写诱敌总体方法、关键节点、最终诱导位置、关键资源或最终处分接口。

结论：

```text
局部执行自由
≠ 关键运行结构重设
```

事实置信 99，分类置信 98。

### B｜《三国演义》赵云博望坡诱敌

诸葛亮明确给定“不要赢，只要输”的前部诱敌终点。赵云可自行决定交战数合、回马时机、再次退却节奏，但未替换诱敌终点、伏兵/火攻协同、成功条件或更高处置路径。

结论：

```text
局部战斗节奏 / 回马时机 / 动作顺序自由
≠ 关键战术方案重设
```

事实置信 99，分类置信 98。

### C｜《水浒传》贺拆幽州诱敌

贺重宝明确规定贺拆、贺云“都不要赢，只佯输诈败，引入幽州境界”。贺拆在霸州方向接敌后“不曾斗的三合”即引军败走。

贺拆可以自行决定短战几合、何时转退等前线节奏，但没有改写：

- “不要赢”的成功/失败条件；
- “佯输诈败”的关键节点；
- “诱入幽州”的战术终点；
- 贺重宝后续围困结构与整体协同接口。

结论：

```text
短战几合 / 退却时机自由
≠ 关键诱敌方案重设
```

事实置信 99，分类置信 97。关联运行记录：`07-Codex大脑库/运行记录_zx-nx方案边界_贺拆幽州诱敌执行自由反向控制_20260820.md`，commit `e139315df90fac1812c46f0bf55c4e5b450cdb09`。

## 4｜最小共同结构

三例正向支持共同保留：

```text
上位目标可以来自外部
外部甚至已经给出方案
主体拥有真实重设窗口
且实际使用该窗口重写关键运行结构
```

三例反向控制共同保留：

```text
主体拥有临场自由
但只调整执行层手段
关键运行骨架仍由外部给定并被真实续接
```

因此“怎么运行”必须拆成两层：

```text
执行层手段：
话术、路线、动作顺序、临场微调、交战节奏、回马/退却时机

关键运行骨架：
决定性节点、资源配置、协同接口、失败/成功条件、最终处置接口
```

待审议核心不是“主体有没有自己想动作”，而是：

> **主体有没有实际替换决定性运行结构。**

## 5｜候选纪律

仅作为 pending-review，不写入正本：

```text
外部给目标 + 主体沿既有方案执行
→ nx候选

外部给目标/方案 + 主体拥有重设窗口但未使用
→ 仍可为nx候选

外部给目标/方案 + 主体仅在预留执行自由度内微调
+ 关键节点、资源与最终接口未变
→ nx不因局部变化自动下降
→ 不足以锁xn方案重设

外部给目标/方案 + 主体实际否定并重设关键运行结构
→ 当前运行层nx下降
→ 优先检查xn
```

当前五问：

1. 谁给最终目标？
2. 谁设计关键运行骨架？
3. 主体改的是执行层手段，还是关键节点/资源/接口？
4. 拿掉主体的临场微调后，原方案能否仍按同一骨架成立？
5. 主体的自由是否改变成功/失败条件或最终处置路径？

## 6｜不能偷换成 zx

三例正向与三例反向控制共同证明：

> **方案重写或执行自由 ≠ 自动扩权。**

若主体只在已有授权范围内重新组织运行，或只在外部方案允许范围内自由发挥，而没有取得更高决定范围、没有让外部秩序围绕新增权力中心重排，不能直接判 zx。

## 7｜最近邻边界

### nx vs xn

```text
nx：关键方向/方案骨架仍由外部给出，主体实际沿它推进。
xn：主体实际重设决定性流程、节点、资源与协同结构。
```

不能用“主体有自主动作”作为 xn 的捷径。

### xn 的最低强化证据

优先要求至少出现一项：

- 替换关键节点；
- 改变资源配置；
- 重设协同接口；
- 改变成功/失败条件；
- 改变最终处置路径；
- 让旧方案在关键结构上不能原样运行。

只有路线、话术、动作先后、交战节奏、回马/退却时机或普通执行微调，证据不足。

## 8｜后续验证需求

三部执行自由反向控制已补齐，下一步不再堆第四个同型。

优先测试灰区：

1. 主体提出局部修补，关键节点、资源和最终流程仍由外部决定，何时仍只是 nx 内部微调？
2. 主体只替换一个关键节点，但其余结构未变，是否已经足以让 xn 上升？
3. 主体真正重设方案以后，又因上级逐项审批，是否会在权限关系层重新表现 nx？
4. 找同一人物最小差异，比较“执行旧方案 → 改一个关键节点 → 重写整个方案”三档。
