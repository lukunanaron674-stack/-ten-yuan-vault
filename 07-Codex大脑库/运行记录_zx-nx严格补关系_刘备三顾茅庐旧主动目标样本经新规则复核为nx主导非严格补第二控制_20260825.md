# 运行记录｜刘备三顾茅庐旧主动目标样本经新规则复核为 nx 主导非严格补第二控制

## 0｜本轮问题

旧记录已以 99/97 锁定：刘备在三顾茅庐阶段有自己的政治方向，但关键战略方案在诸葛亮这一外部专业接口，故 `nx` 关系功能成立；本窄阶段不足以锁高纯 `zx`。

本轮不重复制造“刘备三顾=nx”这一结论，而用当前更严格的 `zx↔nx` 补关系规则复核一个常见误判：

> 主体自己定目标、非常主动、反复坚持，同时又借外部专业通道办事，是否就可以直接写成 `zx+nx`？

结论：**不可以。** 本桥段形成第二独立作品控制：`nx` 独立过门，但 `zx` 在本窄阶段没有独立过门；因此连高纯 `zx+nx` 共现都不能先假定，更不能判严格补。

---

## 1｜剧情事实

### 事实 A｜刘备的最高政治方向先于诸葛亮存在

刘备寻找孔明，是因为自己已有求贤、安邦定国、继续政治行动的方向；不是诸葛亮先替刘备制造“要不要继续”的终极目标。

### 事实 B｜关键战略解决方案在外部

徐庶、司马徽等把诸葛亮指向为关键智略主体。刘备明确承认自己“智术短浅”，必须向孔明问计，不能凭已有能力自行生成同等战略方案。

### 事实 C｜主体真实沿外部接口推进

前两次未见孔明后，刘备没有强制取得其人或智略；第三次仍按荐举—拜访—等待—请教的外部关系路径推进。孔明未起时刘备继续等待，最终进入问计。

### 事实 D｜战略方案由诸葛亮提供

荆州、益州、联孙、待天下有变再两路北伐等运行骨架由诸葛亮提出。刘备取得此前不掌握的系统方案，并进一步邀请诸葛亮出山。

### 结果

刘备的既有政治方向得到一个外部专业解决通道补入，但在本窄阶段没有出现刘备本人公开扩大决定范围、压过诸葛亮或更大秩序的事实。

## 2｜样本类型

```text
nx关系功能正例
+
伪zx+nx反例
+
严格补第0门第二独立作品控制
```

不是：

```text
“刘备很主动”
+
“刘备找诸葛亮帮忙”
=
zx+nx
```

主动性与外部借力只是表面共现，不能替代两端独立成立。

---

## 3｜nx 证据

本轮 `nx` 高纯成立在“专业解决通道”对象层：

```text
刘备已有目标
→ 关键战略知识不在自己手里
→ 诸葛亮掌握独立专业接口
→ 刘备必须通过荐举、拜访、等待、请教真实接入
→ 接入后取得战略方案
```

关键点不是“刘备求人”三个字，而是：

- 解决通道真实外置；
- 刘备不能稳定自行调用；
- 诸葛亮在三顾阶段仍是独立主体，不是刘备已有 `x`；
- 刘备没有绕过这个接口，而是持续沿其推进。

因此：

```yaml
nx_relation_function_stage: evidence-locked
```

---

## 4｜zx 证据检查：本窄阶段不独立过门

刘备当然有目标、有主见、有坚持，也亲自三次拜访。但这些不能替代 `zx` 的核心门。

本桥段缺少：

```text
主体自身权能公开压入现实
→ 他者/秩序被迫围绕主体新增决定位置重排
→ 主体影响或决定范围扩大
```

刘备没有：

- 强迫诸葛亮交出方案；
- 把诸葛亮的智略处分权夺入自己边界；
- 逼迫外部政治秩序承认自己新增的决定位置；
- 在三顾这一窄阶段完成一个新对象域的公开扩权。

所以：

```yaml
zx_in_narrow_stage: rejected_as_primary
```

这不否定刘备在其他阶段可以有 `zx`；这里只禁止把“主动定目标”本身偷换成 `zx`。

---

## 5｜关键压力

压力来自：

```text
政治方向仍在
+
自身战略能力存在真实缺口
+
高质量专业方案外置
+
接口暂时不开放 / 不立即可得
```

在这种压力下，刘备的选择是继续沿外部专业接口推进，而不是以自身权能压掉接口。

这使 `nx` 更纯，同时仍不足以推出 `zx`。

---

## 6｜拿掉测试

### 6.1 拿掉 nx

拿掉诸葛亮或等价外部专业战略接口，又不给刘备同等内部战略能力：

```text
刘备政治目标仍然存在
但“如何形成系统战略”留下明确缺口
```

因此 `nx` 对本阶段推进是实质条件。

### 6.2 拿掉所谓 zx

把“刘备非常主动、坚持三顾、自己定目标”这些表面 `zx` 候选冻结，只保留：

```text
刘备愿意继续政治行动
+
关键方案仍在外部
+
刘备真实沿荐举 / 拜访 / 请教接口取得方案
```

`nx` 核心机制仍完整。

说明这里不存在一个已经独立过门、且拿掉后会让 nx 自身核心功能出现不可替代缺口的 `zx` 端。

### 6.3 对严格补的意义

现行 `zx补nx_补卡` 要求两端分别独立成立；本例在第0门就失败：

```text
nx：独立成立
zx：本窄阶段未独立成立
→ 不进入严格补后续门
```

无需再用“关系很关键”“刘备很主动”强行补足不存在的 zx。

## 7｜反向测试

### 反向成真正 zx+nx 共现

若改写成：

```text
刘备一边真实沿诸葛亮专业接口取得外部方案（nx）
同时在另一个独立对象层
公开把自身决定范围推进原本不属于自己的范围
并迫使外部秩序真实重排（zx）
```

则可以检查 `zx+nx` 共现，但仍需继续验证是否同一对象层、是否同一瓶颈、是否严格补。

### 反向成 zx 主导

若刘备不是请教，而是以自身权能强迫诸葛亮交出方案，压掉诸葛亮的真实拒绝位置并把智略处分纳入自己边界，则 `zx` 上升、`nx` 下降。

### 反向成 xn

若诸葛亮只提供一个最低目标提示，而荆益、联盟、阶段、资源与进军节点全部由刘备自己重组，则转查 `xn`。

## 8｜最近邻排除

### `nx vs xn`

刘备组织三次拜访不是本轮 `xn` 主证据。真正被问的是“关键战略结构由谁提供”。隆中对的运行骨架由诸葛亮外部提供，因此主判 `nx`。

### `nx vs x`

三顾期间诸葛亮尚未进入刘备稳定可直接调用的资源边界；必须请求、等待、请教，所以不是 `x`。

### `zx vs 主动性`

主动、坚持、礼贤、自己定目标都不是 `zx` 的充分条件。没有公开扩权与现实位置上升，不锁高纯 `zx`。

### `zx+nx vs 两种表面特征共现`

“我自己想做这件事”与“我需要别人帮我”可以同时发生，但这只是自然语言层面的主动 + 借力，不等于十元两端都已经独立成立。

---

## 9｜第三因素冻结

冻结：

- 刘备是否仁德；
- 诸葛亮是否天下第一谋士；
- 三顾茅庐的传奇性；
- 后续蜀汉成败；
- 刘备是否“很有主见”；
- 礼贤下士的道德评价；
- 后世政治象征。

只保留：

1. 谁拥有当前最高政治方向；
2. 谁掌握关键战略解决接口；
3. 刘备是否能稳定自行调用该接口；
4. 刘备是否真实沿外部接口推进；
5. 本阶段有没有发生刘备决定范围公开扩大。

结论仍是：`nx` 成立；`zx` 本窄阶段不独立过门。

## 13｜最短纪律

> **“我自己定目标”不等于 zx；“我主动借外部通道”也不自动形成 zx+nx。先分别证明两端独立成立。若 nx 真，而 zx 只剩主动性、坚持或主观目标，则记 nx 主导，不进入严格补测试。**
