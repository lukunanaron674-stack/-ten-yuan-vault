# 运行记录｜zn-x 压力显影反向护栏｜迈克尔·柯里昂

## 1｜本轮问题

P0 strict `zn↔x` 仍未找到能同时通过 `zn→x` 与 `x→zn` 不可替代双向缺口的 ≥95% 正例，因此不降低门槛。

本轮转向已进入 L4 pending-review 的 pressure-display 边界，专测第二种高价值伪复位：

> **压力后重新出现与旧原则主题相似的口号，是否足以证明旧 `zn` 已按原边界复位？**

答案：不够。

本轮复用 Michael 既有 lifecycle 资产，但研究用途与计数独立；不重复增加 lifecycle negative guard。

## 2｜压力前同一原则 P 已成立

影片婚礼阶段，Michael 已长期处于 Corleone 犯罪业务现实管理链之外，并向 Kay 明确区分：家族的犯罪做法属于他的 family，但不是他要成为的自己。

本轮旧 `zn` P 仍沿用已锁窄定义：

> **可以属于这个家庭，但不把家族犯罪权力与暴力秩序作为自己最终生活 / 行动归属；与该犯罪业务保持现实距离。**

该原则不是职位、战争英雄身份或一句形象台词倒推，而有参军、长期未进入业务链、公开区分“家族 / 我”等前置行为支持。

## 3｜关键压力确实改变现实行动

Vito 遇刺、医院危机、Sollozzo 与腐败警察介入以后，Michael 从外围保护父亲转为主动提出并执行 Sollozzo / McCluskey 双杀，随后流亡西西里。

这段高压足以造成一次重大原则越界，因此如果后来旧 P 按原边界恢复，才可能构成 pressure-display。

## 4｜为什么“以后会合法化”不是旧 P 的复位

Michael 回到美国、与 Kay 重建关系时，已经明确承认自己正在为父亲工作，同时承诺 Corleone 家族将在几年内“完全合法化”。

这句话与旧 P 共享“合法 / 非犯罪”主题词，但对象层与排序结构已经改变：

```text
旧 P：
我不把家族犯罪权力作为自己的现实行动归属

后来口号 P2：
我已经进入 / 接管家族业务
→ 未来把这个业务转成合法
```

P2 并不是 P 的原边界复位。

最关键的是：P2 出现以后，Michael 并未退出犯罪业务，反而继续取得并稳定使用家族组织、人事、交易与暴力处分 `x`。

因此不能用“仍然谈合法化”这一主题相似性，证明 pressure-display 的 `same principle / same boundary / same conflict-order criterion` 已经恢复。

## 5｜影片结尾的现实排序反证

到影片末段：

- Michael 已成为 Corleone 家族的现实最高决策者；
- 他组织并完成 rival dons、Moe Greene、Tessio、Carlo 等人的清除 / 处分；
- 面对 Kay 对 Carlo 死亡的直接追问，他否认事实并继续封闭家族业务边界；
- 下属以 Don Corleone 对其完成现实服从与承认。

所以压力后的实际排序不是：

```text
旧 P 恢复
→ 重新退出犯罪权力
```

而是：

```text
主题相似的“未来合法化”口号仍存在
+
现实家族权力 x 稳定形成并主动使用
+
旧“保持现实距离”边界未恢复
→ old P not restored
```

## 6｜pressure-display 反向护栏

本例新增：

> **相似口号 ≠ 同一 `zn` 复位。**

pressure-display 的解压复位门不能只检查词汇、身份或主题相似，必须比较：

```text
same principle
same boundary
same conflict-order criterion
```

如果压力后只是出现“合法、正义、忠诚、自由”等相似词，但主体在同类现实冲突中的最终排序已经由新原则 / 新利益结构接管，则应优先判 lifecycle replacement / false restoration，而不是 pressure-display。

## 7｜拿掉测试

### 拿掉“合法化”口号

只看 Michael 后续真实进入家族业务、稳定取得组织 / 暴力处分 `x` 并持续主动使用，旧 P 未复位的结论不变。

因此口号不是旧 P 恢复的必要证据。

### 拿掉后续现实排序

如果影片只是出现“我要让家族合法化”，随后 Michael 真的退出犯罪业务、交出家族暴力 `x` 并重新恢复与旧犯罪秩序的现实距离，那么才可重新测试 pressure-display 正向复位。

原片没有发生这一结构。

## 8｜反向测试

要锁真正 pressure-display，应看到：

```text
压力前 P 已成立
→ 压力中 P 的直接表达被封
→ 压力下降 / 解除
→ P 以原边界重新决定同类冲突
```

Michael 的后段不满足最后一项。

## 9｜最近邻排除

### pressure-display vs lifecycle

本例的 primary research use 是 pressure-display negative guard；Michael 既有 lifecycle 记录已另锁“旧 `zn` 被新排序替换”。

本轮不重复增加 lifecycle 计数，只借用该已锁事实回答：

> **为什么相似合法化语言不能冒充 old `zn` 的复位。**

### zn vs z

“Don Corleone”、家族承认、Kay 的信任都不是 `zn` 证据。

### zn vs xn

如何合法化、如何清除敌手、如何安排组织属于执行流程，不回答 old P 是否恢复。

### x vs zx

后期 family-business `x` 依据稳定组织、人事和暴力处分现实生效，不靠 Don 称号本身；本轮不增加新的 `x` 统计。

## 10｜第三因素冻结

冻结：

- Michael 是否“变坏”的道德评价；
- Mafia 类型片主题；
- 视觉象征与结尾关门镜头的审美解释；
- 续集情节；
- Kay 是否相信 Michael。

只保留：

```text
old P before pressure
→ pressure transition
→ later similar-language statement
→ same object-layer real choices
→ old boundary restored or not
```

结论不变。
