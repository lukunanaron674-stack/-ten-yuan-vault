# 复合判断最弱环节与置信度限级协议 v1.0

## 1. 协议目的

一个正式生、克、补、动态链或主题关系结论，通常不是单一命题，而是由多个必要命题共同组成。

例如：

```text
A 的十元点位成立；
B 的十元点位成立；
A 与 B 属于明确对象层和阶段；
A 通过某种机制作用于 B；
B 的某个内部变量因此发生改变；
作用方向是生、克或补；
第三因素和反向解释不足以替代该解释。
```

只要其中一个必要环节尚未收束，整条关系就不能获得高于该环节的正式资格。

## 2. 最弱必要环节原则

复合判断的置信等级，不得高于其必要组成命题中最低的有效等级。

```text
关系链总置信度
≤
源端点置信度、目标端点置信度、对象层置信度、阶段置信度、机制置信度、目标变量变化置信度、方向置信度、排他解释置信度中的最低者
```

这里的“最低者”是调用门槛，不是数学平均值。

禁止：

```text
多个 C-A 平均掉一个 C-C；
用严重后果抬高机制置信度；
用端点判断正确代替关系方向正确；
用结局明确代替过程链明确；
用主题显影强代替十元端点可靠。
```

## 3. 正式动态链的必要命题卡

每一条正式关系至少拆成：

```text
P1：源端点是什么对象、什么对象层、什么阶段；
P2：目标端点是什么对象、什么对象层、什么阶段；
P3：源端点的三元或十元判断；
P4：目标端点的三元或十元判断；
P5：源端点通过什么具体机制作用；
P6：目标的什么变量发生改变；
P7：变化方向为何属于生、克或补；
P8：第三因素为何不足以解释该变化；
P9：反向关系为何不与当前方向同等成立。
```

任何必要命题为 C-C 或未判定时，整条关系不得进入正式动态链。

任何必要命题为 C-B 时，整条关系最高只能记为：

```text
候选关系 / 待复验动态链 / C-B
```

只有所有必要命题均达到 C-A，整条关系才获得 C-A 调用资格。

## 4. 端点正确不等于关系正确

允许出现：

```text
源端点十元：C-A
目标端点十元：C-A
作用机制：C-B
关系方向：C-B
整条关系：最高 C-B
```

也允许：

```text
结果变化：C-A
第三因素排除：C-C
整条关系：未判定
```

因此：

```text
A 是 zx：C-A
B 是 xn：C-A
≠ zx 克 xn：C-A
```

端点身份、作用机制和关系方向必须分别审核。

## 5. 结果严重不抬高关系置信度

后果明显、伤害严重、人物死亡、关系破裂或结局不可逆，只能证明结果层发生了强变化。

它不能自动证明：

```text
源端点是哪一个十元；
目标端点是哪一个十元；
变化由哪个机制导致；
关系方向是生、克还是补；
人物稳定本体发生改变。
```

结果层的高 C 与关系层的 C 必须分开。

## 6. 三元与十元复合判断仍然并行

若一条关系同时使用三元与十元描述，必须分别建立命题卡：

```text
三元端点与关系命题；
十元端点与关系命题。
```

三元层 C-A 不会补高十元层的 C-B；十元层 C-A 也不会补高三元层的未判定。

两层相容只能增加复核价值，不能形成父子派生，也不能替代任一层自己的证据。

## 7. 人物本体不得成为默认承压变量

当关系成立时，目标变量优先从以下层级寻找：

```text
当前状态；
行动能力；
行为路径；
资源；
关系位置；
场景中的活动边界；
时间压力；
显影强度；
持续条件。
```

人物稳定本体只有在本体层独立获得跨阶段 C-A 反证，并通过重新校准后，才允许作为被改变变量。

因此：

```text
关系作用量 E 高
≠ 人物稳定本体改变；
状态被压制
≠ 本体被删除；
行为被迫转位
≠ 人物长出新的核心十元。
```

## 8. 多阶段链逐段限级

动态链不得用前一阶段的高置信覆盖后一阶段的缺口。

每一阶段分别记录：

```text
端点；
对象层；
阶段；
机制；
目标变量；
方向；
第三因素；
反向解释；
该阶段总置信度。
```

允许：

```text
阶段一：C-A
阶段二：C-B
阶段三：未判定
```

整条长链若要求三个阶段连续成立，其整体资格不得高于阶段三的未判定。

可以保留已经成立的局部阶段，不得为了保住整条漂亮链条而补造缺失阶段。

## 9. 主题级关系的同样限制

主题级生克也属于复合判断。

至少需要分别确认：

```text
源主题有结构性显影；
目标主题有结构性显影；
两者属于同一作品分析单位与可比较阶段；
源主题改变了目标主题的能力、边界、路径或答案；
方向明确；
高潮、转折或持续累积提供高层证据。
```

作品中两个主题均达到次主题或主主题，不等于主题关系自动达到 C-A。

主题显影置信度与主题关系置信度必须分别记录。

## 11. 当前冻结结论

```text
复合判断的置信度不得高于最弱必要环节。
多个高置信命题不能平均掉一个未判定环节。
端点正确不等于关系正确，结果严重不等于机制明确。
三元与十元分别审核，不互相补高置信度，也不构成父子派生。
多阶段动态链逐段限级，局部成立不得冒充整链成立。
人物核心锚点优先稳定，关系变化默认落在状态、行为、关系位置、场景、时间压力和动态链变量。
```
