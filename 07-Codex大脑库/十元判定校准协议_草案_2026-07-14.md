# 十元判定校准协议｜草案

> 本页只校准十元点位，不设置其他前置推导层。十元点位通过后，才允许进入生克补。

## 1. 正式开发顺序

~~~
锁定分析单位
→ 无标签观察
→ 提出十元 Top-2 候选
→ 区分主十元 / 副十元 / 功能十元 / 视觉十元
→ 排除最近误判
→ 拿掉测试 / 起手测试
→ 十元点位确认
→ 生克补查表
→ 动态链
→ 五大主题归仓
~~~

任何一步没有通过，后面的步骤不能替前面补答案。

## 2. 第零步：锁定分析单位

先明确分析对象：

~~~
整部作品 / 单个角色 / 角色某阶段 / 一段关系 / 一个场景 / 一个物象 / 一条规则
~~~

整部电影通常不是一个纯十元。训练判定准度时，优先使用“角色某阶段、单场戏、单一关系动作”等小单位，避免多个十元互相污染。

## 3. 第一步：无标签观察

在写十元前，只记录可验证内容：

~~~
谁在做什么？
什么东西反复出现？
哪件事让结构开始不可逆？
角色最怕失去什么？
哪个动作是表层行为，哪个是底层驱动？
什么被拿掉以后，人物会不再成立？
~~~

禁止先看到题材、画面风格、结局或角色职业，就直接填十元。

## 4. 第二步：提出十元候选

| 十元 | 核心检查方向 | 常见误判 |
|---|---|---|
| zx | 目标执行、保持路径有效、完成本身构成存在方式 | 有计划、有行动不自动等于 zx |
| x并z | 表象、包装、被观看、媒介化、伪装与身份壳 | 穿得漂亮、会表演不自动等于 x并z |
| zn | 意义、信念、精神核心、价值归宿 | 有目标、有口号不自动等于 zn |
| z | 执念、光点、爆点、被看见、被点燃 | 努力、坚持、热血不自动等于 z |
| n | 承载、安顿、处理、维持关系与生活结构 | 被动忍受、待在家里不自动等于 n |
| nz | 依恋、停靠、柔情、舍不得结束 | 爱人、等待、回家不自动等于 nz |
| xn | 计划、规则、制度、长期秩序、流程结构 | 会思考、职业理性不自动等于 xn |
| nx | 隐性判断、暗流、记账、算计、等待结算 | 聪明、沉默、藏秘密不自动等于 nx |
| xz | 临界、漂流、危险边缘、命运不稳 | 遇到危险、经历悲惨不自动等于 xz |
| x | 欲望、占有、吞没、深层驱动与失控 | 黑暗、冷酷、反派不自动等于 x |

第一次只给 Top-2，不急着写唯一答案。

## 5. 第三步：分清四层

| 层级 | 判断标准 |
|---|---|
| 主十元 | 拿掉后，人物的存在方式、核心痛苦和反复选择同时崩塌 |
| 副十元 | 为主十元提供精神方向、情感厚度或持续压力 |
| 功能十元 | 只负责某段剧情中的执行、承载、冲突或结算 |
| 视觉十元 | 只负责外观、气氛、姿态和第一印象 |

不得用功能频率代替人物本体。

## 6. 第四步：十元通过三道门

### 门一：拿掉测试

拿掉这个十元，当前分析单位是否立即失去成立方式？

### 门二：最近误判对照

必须至少排除一个最近邻，例如：

~~~
zx vs z
zx vs xn
zn vs z
n vs nz
xn vs nx
xz vs x
x并z vs x
~~~

### 门三：起手测试

它是最早、最深、最反复使人物运动的力，还是中途才出现的剧情工具？

三道门都通过，十元才能标记为 A 级；否则只保留候选，不进入强生克补链。

## 7. 置信度门槛

| 等级 | 条件 | 后续动作 |
|---|---|---|
| A | 主副功能层级明确、拿掉测试通过、最近邻已排除 | 可以进入生克补判断 |
| B | Top-2 已明确，但主位仍难分 | 保留两个候选，不进入强关系链 |
| C | 分析单位混杂，或观察证据不足 | 拆小分析单位，重新观察 |

关系层硬门槛：

~~~
只有 A 点可以进入强关系链。
A + B 只能写候选链。
B + B 或含 C，不得写最终生克补。
~~~

## 8. 生克补判定

只有两个端点都通过点位审核后，才机械查标准位置盘：

~~~
生：A 是否结构性推出 B？
克：A 是否压制、限制或迫使 B 转向？
补：A 与 B 是否分别是不完整的两极，合起来才形成完整张力？
~~~

生克补不能反过来证明点位：“这条链讲得通”不等于“两个十元判对了”。

## 9. 反驳式训练

训练时由 Codex 先提交一个可被推翻的判断，用户指出第一处断裂：

~~~
【分析单位】
【无标签事实】
【Codex 主十元】
【Codex 副十元】
【Codex 功能十元】
【最近邻排除】
【最可能错在哪里】
~~~

用户纠错优先提供：

~~~
【正确主十元】
【正确副十元】
【功能十元】
【决定性证据】
【一刀切开的边界句】
【错在】分析单位 / 主副功能混淆 / 最近邻 / 起手 / 关系
~~~

只告诉“答案错了”能修一题；指出哪一层错、边界在哪里，才能修改判断器。

## 10. 金标准样本包

每个十元提供：

~~~
3 个纯正例：为什么拿掉它就崩。
2 个近邻反例：看起来像它，实际为什么不是。
1 个混合边界例：主十元、副十元、功能十元怎样分。
~~~

优先用单场戏、单角色阶段或单关系动作，不用整部电影作为第一轮训练单位。

### 10.1 训练素材优先级

| 优先级 | 素材 | 适合判断什么 | 注意 |
|---:|---|---|---|
| 1 | 角色某阶段 + 2—3 个决定性场景 | 主十元、起手、最近邻排除 | 最推荐；必须限定阶段 |
| 2 | 一段角色关系 + 起点/转折/结算三个节点 | 主副十元、关系动作 | 不要笼统概括整部作品 |
| 3 | 单场戏 + 台词/动作/前因后果 | 纯十元、功能十元 | 最适合做纯正例和盲测 |
| 4 | 30—90 秒视频片段或准确时间码 | 行动顺序、起手、层级变化 | 仍要说明上下文 |
| 5 | 3—6 张同一场景截图 | 视觉十元、空间、姿态、显影方式 | 只能辅助本体判断 |
| 6 | 单张角色立绘/海报 | 视觉十元、包装层、第一印象误判 | 不能单独判主十元 |
| 7 | 整部电影名称 | 后期综合盲测 | 前期污染最大 |

### 10.2 最省力的提交格式

~~~
十元：
样本类型：纯正例 / 近邻反例 / 混合边界例
电影：
角色：
阶段或场景：
发生了什么（3—5句）：
正确主十元：
正确副十元：
功能十元：
决定性理由：
最容易误判成：
为什么不是：
图片/片段：可选
~~~

最低限度：

~~~
电影 + 角色 + 明确阶段 + 正确主十元 + 为什么不是最近邻十元
~~~

### 10.3 推荐投喂顺序

~~~
第 1 轮：某十元的 3 个纯正例。
第 2 轮：同一十元的 2 个近邻反例。
第 3 轮：同一十元的 1 个混合边界例。
第 4 轮：3 个不附答案的新片段盲测。
通过后，再进入下一个十元。
~~~

## 11. 当前已确认的防错规则

### 安迪案例：zx / xn

> “计划正在被执行”不等于人物主 zx。

如果大量行动是深层思考、长期计划和秩序结构的产物，应优先检查 xn。zx可能只是把计划落地的功能十元；精神信仰可以位于 zn 副位。

安迪当前校准：

~~~
主十元：xn
副十元：zn
功能十元：zx
~~~

## 13. 最终封存

~~~
准度不是靠把更多电影塞进关系表提高的。

先把观察单位拆小，
再分清主十元、副十元、功能十元和视觉十元，
通过最近邻排除、拿掉测试和起手测试锁点，
最后才允许生克补运行。

点位负责真，关系负责动；
点位不真，关系越完整，错得越稳定。
~~~
