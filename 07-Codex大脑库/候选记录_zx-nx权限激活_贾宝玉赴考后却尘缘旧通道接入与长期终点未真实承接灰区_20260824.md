# 候选记录｜贾宝玉赴考后却尘缘：行为接入旧通道，不等于长期终点已经真实承接

## 1｜本轮问题

现有研究已区分：
- 徐庶：旧长期方向仍认可，只是临时优先级覆盖；
- 李俊：明确否定旧长期终点并执行新持续路线；
- 陶渊明：旧官职通道真实激活，后续耐久退出并恢复更早个人方向。

本轮原本试图寻找第三份四大名著内部“耐久终点重写”材料，优先测试《红楼梦》贾宝玉第118—120回“用功赴考 → 中举 → 出家”。

压力测试后发现真正分叉：

> 宝玉确实真实进入科举执行通道，但文本同时强烈暗示，他并没有把“长期仕途/功名人生”真正当作自己的持续终点。

因此本轮不能高置信写成：

> 旧nx长期终点已真实承接 → 后来长期重写。

更合理的候选问题是：

> **行为层接入 / 执行一个外部通道，是否足以推出长期终点层也已承接？**

答案目前是否定倾向，但存在作者层、文本策略与动机解释分叉，故分类只给91%，保留 candidate/deferred。

## 2｜剧情事实

第118回，宝钗明确劝宝玉“收心用功”，希望他至少取得一第，以尽家族与君亲责任。宝玉口头接受“从此而止”这一限定，并随后与贾兰谈文章、下场规矩，真正开始静室用功。

但同一回中，宝玉又明确说自己是去“诓这个功名”；在宝钗提出“搏得一第，便是从此而止”后，他对“从此而止”表现出明显另有所指。宝钗也察觉他“改得太速太好”，担心另有变故。

第119回，宝玉真实赴乡试，最终中第七名举人；但出场后即失踪，没有沿中举后的功名/官职路线继续推进。第120回则通过雪中向贾政拜别等情节完成俗缘退出。

因此事实链可以稳定写成：

```text
家庭 / 婚姻 / 科举规范持续推动
→ 宝玉真实用功
→ 真实准备下场
→ 真实参加乡试
→ 中举
= 行为层已进入外部功名通道

但同时：
在进入前已明确使用“诓这个功名”等表述
+ 对“从此而止”作另一层理解
+ 中举后不继续仕途而直接退出
= 长期功名终点是否曾被主体真正承接，不能直接锁定
```

## 3｜nx 判断

### 3.1 行为 / 执行层

这一层可以高置信确认：

> `exam_channel_behavioral_entry: evidence-locked`

宝玉不是只听建议。他实际：
- 接受家人关于下场的现实安排；
- 读书备考；
- 与贾兰讨论文章与考试规则；
- 进入乡试；
- 完成考试并中举。

所以“完全没有接入任何外部通道”不符合事实。

### 3.2 长期终点层

这里不能锁高纯nx。

真正的问题是：

> 他进入科举行为链时，是否真的把“通过科举继续进入功名/仕途人生”作为自己的持续最高终点？

文本反而给出强反证：
- “诓这个功名”；
- 对“从此而止”的特殊接受；
- 宝钗持续怀疑其变化过快；
- 中举后不继续进入正常功名链，而直接失踪。

因此：

> **行为执行沿外部通道 ≠ 长期最终方向一定来自外部。**

这与此前刘备“借截袁术之命脱离许都”的分层边界相容：子任务层可以nx，主体上位最终方向仍可能另有来源。

## 4｜zx 检查

本窄“赴考/退出”阶段不因主动出走自动锁zx。

宝玉没有因为离场：
- 取得新的公共处分权；
- 改写科举制度；
- 扩大现实公共决定范围；
- 迫使制度围绕其新增权力接口运行。

所以：

> 长期拒绝旧世俗路线，也不自动等于zx。

`zx_from_exit_itself: rejected_as_primary`

## 5｜xn 最近邻

宝玉确实自行安排部分读书、静室与备考行为，但“退出功名路线”本身不能因此自动判xn。

若另切“他如何组织出走/出家”这一对象层，需要独立检查人员、资源、节点与持续流程；本轮不倒灌。

`xn_from_exit_itself: rejected_as_primary`

## 6｜关键压力

关键压力包括：
- 家族衰败后的继嗣 / 功名期待；
- 宝钗、袭人、王夫人的持续规劝；
- 贾政要求读书与科举；
- 宝玉自身对“尘缘”与出世方向的持续牵引。

这些压力共同制造了一个特殊结构：

> 主体可以在行为层高度配合一条外部路线，同时并未把这条路线真正接受为自己的长期终点。

## 7｜拿掉测试

### 拿掉“诓这个功名 / 从此而止”及出走前兆

如果只剩：

> 家人劝考 → 宝玉真心用功 → 赴考 → 中举 → 后来某个新事件再使其改变人生方向，

那么“旧长期功名终点曾真实承接 → 后来耐久重写”会明显增强。

原文并不是这样。

### 拿掉真实赴考与中举

如果只剩嘴上答应家人，却没有真实下场，则连“行为层nx接入”都不能高置信成立。

因此本例真正有价值的是：

> **行为接入很真，长期终点承接却仍可是假/工具化。**

## 8｜反向测试

真正高纯“耐久终点重写”应满足：

```text
旧nx通道真实激活
+ 主体此前确实把旧持续终点当作自己的长期执行终点
→ 后来明确否定
→ 持续执行新长期方向
= 耐久终点重写
```

本例缺的恰恰是第二项。

反向的“工具化接入”结构则是：

```text
外部长期路线存在
→ 主体为完成局部义务/节点而真实进入
→ 但从未真正承接该路线的长期终点
→ 完成局部节点后退出
= 行为层可nx，长期终点层不宜锁nx
```

宝玉第118—120回更接近这一侧。

## 9｜第三因素冻结

冻结：
- 后四十回作者归属争议的价值判断；
- 宝玉“叛逆/觉悟”文学主题；
- 通灵宝玉、和尚道士的超自然解释；
- 是否认同其出家结局。

只保留文本事实：
1. 家庭/科举通道是否真实存在？是。
2. 宝玉是否真实进入并执行？是。
3. 他是否明确表现出把功名仅当局部节点/工具的迹象？是。
4. 是否有足够证据证明他曾真把长期仕途终点作为持续最高方向？不足。
5. 中举后是否继续沿旧路线？否。
6. 退出本身是否构成zx扩权？否。

因此“长期终点曾经真实nx承接”仍存在超过5%的真实分叉。

## 10｜最近邻排除

### 行为层nx vs 终点层nx

最重要：

> **走进一条路，不等于认可这条路的最终终点。**

### nx vs xn

自己认真备考，不等于整条科举路径由主体自行搭建。

### nx vs zx

退出旧路线，不等于扩大公共决定范围。

### 目标重写 vs 目标从未承接

这是本轮最关键的新灰区：

> “原来真想走A，后来改成B”

和

> “为了完成局部节点暂时走A，但长期一直没有把A当最终终点”

不能写成同一种“耐久终点重写”。

## 11｜结论

本轮不形成第三份耐久终点重写正式正例。

可靠结论仅到：

> **贾宝玉第118—120回真实进入科举行为通道，但文本不足以证明他曾把长期功名/仕途终点真正承接为自己的持续最高方向。**

因此本例应保留为：

> **candidate/deferred｜行为层nx接入与长期终点nx承接分层灰区。**

它反而对后续研究提出更锋利的问题：

> **nx 应不应该区分“局部行为/任务接入”与“长期终点承接”？**

目前只有本例，不建立待审议问题，不修改L1、信息卡、准度卡或补卡。
