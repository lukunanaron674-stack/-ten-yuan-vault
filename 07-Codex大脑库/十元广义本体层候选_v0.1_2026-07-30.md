# 十元广义本体层候选 v0.1

> 本文件建立十元的第一层“广义本体层”。它不修改、不撤销现行十元信息卡与准度卡。现行卡片继续承担人物、关系、状态、行为及具体对象判定；本文件只研究这些狭义表现之上的跨领域共同结构。

## 0. 三层定义结构

```text
第一层：广义本体层
十元在任何对象、任何领域中都不变的最小结构操作。

第二层：领域关系层
广义结构进入人际、叙事、构图、音乐、游戏或社会后形成的关系规则。

第三层：狭义人物层
该关系结构进入具体人物后形成的心理、欲望、性格、行为和显影。
```

现行信息卡主要覆盖第三层，并已部分进入第二层；第一层此前没有独立正本。

## 1. 广义定义硬门

一条候选只有同时通过以下测试，才有资格进入广义本体层：

1. **去人物测试**：删掉“人物、主体、心理、欲望、认可、对错、台词”后仍成立。
2. **跨领域测试**：至少能稳定映射到人物、人际关系、叙事、构图、音乐、游戏系统、社会结构七类对象。
3. **最小操作测试**：定义说明“它对对象结构做了什么”，而不是列举气质、题材、道具或行为。
4. **生成测试**：该广义定义能够生成现行信息卡中的狭义表现，而不是与旧卡争夺同一层级。
5. **最近邻测试**：相邻十元必须能用“改变哪个变量”区分。
6. **拿掉测试**：拿掉该结构操作后，其跨领域结果应同步下降。
7. **不反推关系测试**：广义本体层不得自行锁定任何生、克、补机制。

# 2. 十元广义本体层候选

## 2.1 ZN（zn）｜并存赋义

### 广义定义

> **ZN 是使一个或多个对象获得并保留独立意义成立资格的结构；不同对象的成立不必以互相取消为代价。**

### 最小结构式

```text
对象进入意义判断
→ 获得不可随意抹除的成立资格
→ 可参与后续选择、组织与发展
→ 多项意义可并存
```

### 核心变量

- 意义成立资格；
- 不可随意取消性；
- 多项意义并存度；
- 后续指导与调用资格。

### 与现行人物卡的连接

现行 `zn` 卡中的“不可轻易让渡的内部意义、原则正确性与未来最终指导资格”，是 ZN 进入单一人物内部后的狭义形态。

### 已确认的人际关系显影

> **你们都对，我也是对的。**

这里的“都对”不是事实判断，而是多方都被保留为具有意义成立资格的对象。

---

## 2.2 z｜单点最高化

### 广义定义

> **z 是从多个对象中确立一个最高重要点，并把注意、评价、资源或结构重心集中到该点；外围对象可以存在，但不参与中心资格的竞争。**

### 最小结构式

```text
多个对象并存
→ 一个对象被选为最高中心
→ 结构重心向该点集中
→ 其他对象被降为外围或无关项
```

### 核心变量

- 中心唯一性；
- 最高重要度；
- 聚焦强度；
- 外围对象的无关化程度。

### 与现行人物卡的连接

现行 `z` 卡中的“需要重要认可主体看见并确认自己”，是人物把“自己”送入最高评价点、要求该点获得确认的狭义形态；认可不是广义本体的全部。

### 已确认的人际关系显影

> **我是最对的，你们不关我事。**

这里的关键不是主动否定别人，而是“我”被置为最高中心，别人被排除出中心判断。

---

## 2.3 ZX（zx）｜排他确立

### 广义定义

> **ZX 是一个对象通过压退、替代、否定或取消竞争对象的有效位置，确立并扩大自身的决定资格与作用范围。**

### 最小结构式

```text
多个对象争夺同一位置或方向
→ 一个对象压低、替代或取消其他对象
→ 自身位置被确立
→ 决定范围扩大
```

### 核心变量

- 排他程度；
- 竞争对象有效性下降；
- 自身决定资格上升；
- 作用范围扩张。

### 与现行人物卡的连接

现行 `zx` 卡中的“权能公开显现、扩大、凌驾和征服”，是排他确立进入人物与权力关系后的狭义高显影。

### 已确认的人际关系显影

> **我是对的，你们都是错的。**

自身正确性的确立以他者正确性被取消为条件。

---

## 2.4 x并z｜壳化接口

### 广义定义

> **x并z 是把内部对象、结构或能力映射为稳定外部形式，使外部能够持续识别、进入、调用、归因、代表或保护它。**

### 最小结构式

```text
内部对象存在
→ 形成稳定外部映射
→ 第三方通过该映射接触内部
→ 对象获得公共可读与可调用接口
```

### 核心变量

- 外部可识别性；
- 映射稳定度；
- 调用与进入能力；
- 壳对内部的代表与保护能力。

### 与现行人物卡的连接

身份、名称、职位、作品形式、品牌、前台、界面、保护壳和伪装，都是该广义操作在具体领域中的狭义载体。

---

## 2.5 N（n）｜内部承载

### 广义定义

> **N 是让对象进入一个结构内部、获得持续位置，并由该结构吸收、处理与承担其长期负荷，使对象能够继续存在。**

### 最小结构式

```text
对象进入内部
→ 获得稳定位置
→ 负荷由内部结构持续处理
→ 对象与结构不被立即推出或压垮
```

### 核心变量

- 内部准入；
- 稳定位置；
- 负荷吸收；
- 持续处理；
- 结构抗崩能力。

### 与现行人物卡的连接

照护、接收、保护、成员容纳与持续承担，是内部承载进入人物、组织和关系后的狭义形态。

---

## 2.6 NZ（nz）｜可回返联结

### 广义定义

> **NZ 是分离、扰动或局部断裂之后，两个对象仍保留真实可调用的重新连接、修复与复归路径。**

### 最小结构式

```text
对象曾建立连接
→ 发生分离、偏离或冲突
→ 连接未被彻底取消
→ 对象可重新接近、修复并恢复共同结构
```

### 核心变量

- 对象特异性；
- 回返路径；
- 修复能力；
- 分离后的连续性；
- 重新连接可信度。

### 与现行人物卡的连接

等待、归宿、旧关系、自由离开后返回、冲突后修复，是可回返联结在人际领域中的狭义形态。

---

## 2.7 XN（xn）｜时序组织

### 广义定义

> **XN 是把分散对象排列进可保存、可重复、可跨阶段延续的顺序、规则与流程，使一次变化转化为持续运行。**

### 最小结构式

```text
对象分散或一次性发生
→ 被排列进顺序、节点、规则与记录
→ 状态可跨阶段保存
→ 运行可以重复、积累与延续
```

### 核心变量

- 顺序；
- 时间节点；
- 状态保存；
- 可重复性；
- 累积性；
- 持续运行能力。

### 与现行人物卡的连接

主动排程、搭流程、记录、预判节点和组织资源，是时序组织进入人物行为后的狭义形态；人物是否主动属于人物层判定，不是所有领域的必要措辞。

---

## 2.8 NX（nx）｜沿既有方向续接

### 广义定义

> **NX 是对象不生成或不占据最终方向，而是接入已经存在的路径、关系、权限或结构通道，沿其方向继续传递和推进。**

### 最小结构式

```text
方向或通道已经存在
→ 对象进入该通道
→ 不重设最终方向
→ 沿既有结构完成续接、传递或推进
```

### 核心变量

- 方向来源外置；
- 通道依赖度；
- 续接能力；
- 自主改写程度；
- 既有结构调用度。

### 与现行人物卡的连接

跟随安排、求人、借力、人情通道和沿权限办事，是该广义操作进入人物与人际关系后的狭义形态。

---

## 2.9 XZ（xz）｜临界收窄

### 广义定义

> **XZ 是某种变化以可到达的运动势能逼近，使对象可用的空间、时间、路线、选择或可逆性持续减少。**

### 最小结构式

```text
变化正在逼近或扩张
→ 对象可用边界不断缩小
→ 退路、时间窗与可逆性下降
→ 系统进入临界
```

### 核心变量

- 变化可到达性；
- 边界收缩速度；
- 可用路线数量；
- 时间窗；
- 可逆性；
- 临界程度。

### 与现行人物卡的连接

危险逼近、追逐、最后窗口、逃亡与临界选择，是临界收窄在人物、场景和叙事中的狭义形态；“危险”是最常见对象，不限定广义结构只能用于人物生存。

---

## 2.10 X（x）｜归属掌握

### 广义定义

> **X 是划定一个归属与控制边界，使对象进入某一范围，并由该范围获得使用、调用、调配、处分、否决或排除资格。**

### 最小结构式

```text
对象边界被切定
→ 对象进入某一归属范围
→ 控制与调用资格集中
→ 范围内外获得不同处置规则
```

### 核心变量

- 归属边界；
- 控制资格；
- 调用与调配能力；
- 处分与排除能力；
- 内外差异。

### 与现行人物卡的连接

占有资源、地盘、权限、关系或对象，是归属掌握进入人物、组织和社会关系后的狭义形态。

### 人际关系层状态

> **未定义。**

不得把 X 类推成“我是对的，外部整体是错的”或其他对错口径。

# 3. 三个成立结构的统一边界

| 十元 | 广义成立结构 | 人际关系已确认句 | 是否取消他者 |
|---|---|---|---|
| ZN | 多项意义可以并存成立 | 你们都对，我也是对的 | 否 |
| z | 一个对象被提升为最高中心，其他对象退出中心判断 | 我是最对的，你们不关我事 | 不主动取消，只无关化 |
| ZX | 自身通过压退、否定或替代竞争对象而确立 | 我是对的，你们都是错的 | 是 |
| X | 归属掌握，不属于该对错轴的已确认项 | 未定义 | 未判定 |

这张表只描述广义结构与已确认的人际显影，不把“对错句”升级为全部领域定义。

# 5. 最近邻最小差异

```text
ZN：保留多个对象的意义成立资格。
z：把一个对象提升为最高中心，其他对象无关化。
ZX：通过取消或压退其他对象来排他确立自身。

X：决定什么归入哪一掌握范围。
x并z：决定内部对象如何获得外部可识别接口。

N：让对象进入内部并被持续承载。
NZ：让断开或分离后的对象仍可重新连接与修复。

XN：生成可保存、可重复、可积累的持续秩序。
NX：不生成最终方向，沿已有方向与通道续接。

XZ：使可用边界、路线、时间窗和可逆性收窄。
```

# 6. 当前不确定项

1. **z 的“单点最高化”能否完整生成现行“重要认可主体确认”口径**，需要跨人物、音乐、视觉、制度案例复核；当前只标为高价值候选。
2. **ZN 的“多项意义并存”与现行“单项不可让渡意义”之间**，需要确认二者是广义—狭义关系，还是还缺一个更高共同结构。
3. **ZX 的排他确立**需要区分“竞争对象自然退出”与“被其主动取消”，避免把普通胜出全部判为 ZX。
4. **XZ 是否能从危险领域上升为一切‘临界收窄’**，需要音乐、构图、制度三类非人物案例通过拿掉测试。
5. **X 的人际关系层保持未定义**，不得为了十元齐整而类推。
6. 本文件不得直接覆盖现行十元信息卡、准度卡及生克补关系正本；每项只有跨领域证据、最近邻排除、拿掉与反向测试稳定后，才提交人工二审。

# 7. 每小时审议标准

每轮只审一个可失败问题，不重复扩写全文。

```text
读强制必读与现行十元卡
→ 选一元或一组最近邻
→ 在七领域中至少检验三个不同领域
→ 做去人物、生成、最近邻、拿掉、反向测试
→ 记录支持证据、反例和最低置信项
→ 有实质变化才更新候选版本
→ 无新证据只记录“本轮不变 + 下一审议点”
```

### 建议轮转顺序

```text
ZN → z → ZX → x并z → N → NZ → XN → NX → XZ → X
→ 三元组 ZN/z/ZX 总审
→ 十元全局重复与缺口审
→ 回到 ZN
```

### 审议输出字段

```text
【本轮对象】
【当前广义候选】
【检验领域】
【支持证据】
【反例/失效处】
【最近邻排除】
【拿掉/反向】
【最低置信项】
【结论】保留 / 缩窄 / 扩展 / 拆分 / 未判定
【下一审议点】
```
