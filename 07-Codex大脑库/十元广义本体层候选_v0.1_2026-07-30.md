# 十元广义本体层候选 v0.2

## 三层

```text
广义本体层：任何领域不变的最小结构操作
→ 领域关系层：进入人物、人际、叙事、构图、音乐、游戏、社会后的变量
→ 狭义人物层：人物在触发下对对象做出的可观察行为
```

同行阴阳必须在同一对象层和同一核心变量上写出相反操作。

## 五组广义—狭义定义

| 十元 | 广义本体 | 狭义人物 |
|---|---|---|
| zx 阳木 | 占据方向源，以自身权能向外施加并压退竞争方向 | 我来定方向并直接改写外部对象 |
| nx 阴木 | 不占最终方向，沿既有路线、关系、权限或通道续接 | 方向不是我定，我沿已有通道继续 |
| zn 阳火 | 保留自己与他者的独立意义、选择和成立资格 | 我成立，也实际让他者继续成立 |
| x 阴火 | 把对象纳入单一归属掌握边界 | 对象、资源、权限或关系归我调用处分 |
| n 阳土 | 让对象真实进入内部并持续承担负荷 | 接收、照护、供给并让对象留下 |
| x并z 阴土 | 把内部对象映射成外部公共壳和调用接口 | 建立身份、名称、职位、作品形式或界面 |
| xn 阳金 | 把重心分布进顺序、规则、记录和流程 | 排程、搭流程、分配资源、记录节点 |
| z 阴金 | 把一个对象提升为最高中心，其他对象退出中心判断 | 只保留一条最高路线/目标，外部判断不进入裁定 |
| xz 阳水 | 收窄路线、时间窗、退路和可逆空间 | 窗口正在关闭，返回可能持续下降 |
| nz 阴水 | 保存或重开对象特异的回返、修复和连接路径 | 保留位置、重新联系、冲突后修复 |

## z/zn/ZX

```text
ZN：多主体独立成立；主动保存他者资格。
z：单点最高化；他者退出中心判断但不必被取消。
ZX：排他确立；他者被压退、否定、替代或取消。
```

人际口径：

```text
ZN＝你们都对，我也是对的。
z＝我是最对的，你们不关我事。
ZX＝我是对的，你们都是错的。
X未定义。
```

## 本轮修正

- 旧z“认可主体确认”降为条件子型，不再是纯z必要条件。
- 旧zn“私人不可让渡原则”过窄；只守自己的唯一路线优先检查z。
- x固定阴火；xn固定阳金。
- 所有含z/zn的旧关系机制冻结再审。
