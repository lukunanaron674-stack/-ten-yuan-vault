# 关羽屯土山：长期归属非 nx，与局部保护/资源 nx 可以同时成立

## 结论先行

本轮不推翻既有《关羽 zx↔nx 木轴压力测试》。旧案在“最终归属、否决权、退出权”这一对象层排除纯 nx，继续成立。

本轮新增的是对象分层：

> 关羽没有把长期归属交给曹操，因此“归属方向层”不是 nx；但为了保全刘备二夫人并取得现实供养、安全边界与暂时庇护，他真实接入曹操掌握的外部许可/资源接口，因此“家属供给与保护资源层”存在高纯 nx 关系功能。

因此不能从“主体保留最终方向”推出“桥段中所有局部外部接口都不是 nx”。

## 1｜剧情事实

### 触发

下邳失守，关羽被曹军围于土山，突围困难。张辽提出暂时接受曹方安排，以保二夫人并等待刘备消息。

### 关羽提出三项条件

1. 只降汉，不降曹；
2. 二夫人继续按刘备俸禄养赡，曹方人员不得随意进入其门；
3. 一旦得知刘备去向，无论远近，立即辞去。

关羽明确表示三者缺一即不接受。

### 曹操的真实许可与资源动作

曹操最终同意三项条件，并进一步：

- 同意二夫人按刘备俸给养赡，甚至增加供给；
- 接受家属安全边界与门禁约束；
- 退军三十里，让关羽先入城告知二夫人；
- 后续给关羽安排许昌住处，形成现实庇护和供养条件。

### 可观察结果

- 关羽长期归向仍锁定刘备；
- 曹操无权把“最终归属曹方”强行写入协议；
- 但二夫人的供养、居住安全、军队不入门等现实条件，确实必须由曹操一侧的军政与资源处分接口使其生效；
- 关羽随后真实接受并在该保护/供养框架内暂时生活与行动。

## 2｜为什么长期归属层仍然不是 nx

既有正式案例的核心结论保留：

```text
曹方提出暂降
→ 关羽重写成立条件
→ 保留最终归向刘备
→ 保留退出权
→ 三项条件缺一即拒绝
```

所以在“我最终属于谁、何时退出”这一层，关羽没有把方向权交给曹操。

本轮继续锁：

- `long_term_allegiance_nx: rejected`
- `exit_direction_nx: rejected`

这与旧案一致。

## 3｜为什么保护/资源层可以成立 nx

但“二夫人如何在曹军控制环境下得到供养和安全”是另一个对象层。

关羽不能仅凭自己的长期忠刘方向自动生成：

- 曹军不入二夫人住所的现实禁令；
- 刘备原俸禄继续拨给二夫人的资源；
- 曹方控制区内的住处和庇护；
- 曹军退兵、停止继续攻击的现实条件。

这些决定性权限和资源在曹操一侧。

关羽做的是：

```text
自己设定不可放弃的家属保护要求
→ 把这些要求接入曹操掌握的军政/资源接口
→ 曹操真实批准并执行
→ 关羽接受并沿该框架暂时续接
= nx 保护/资源关系功能
```

所以本轮正式锁：

- `protection_resource_nx_relation_function: evidence-locked`
- `family_provision_permission_nx: evidence-locked`
- `family_safety_boundary_permission_nx: evidence-locked`

## 4｜关键压力

压力包括：

- 军事包围；
- 下邳失守；
- 二夫人安全；
- 关羽本人短期生存与等待刘备消息。

这些压力不能直接判 nx。

真正的 nx 证据不是“他无路可走”，而是：

> 在具体的家属供养与安全对象层，关键现实权限确实在曹操手里，关羽实际经过并使用了这个接口。

## 5｜拿掉测试

### 拿掉曹操的保护/资源许可

保留关羽“我只归刘备”的长期方向。

此时关羽仍然保持自己的归属方向，但会重新留下现实缺口：

- 二夫人的供养无法由关羽单方面保证；
- 曹军是否进入住所、是否继续威胁家属，不由关羽稳定处分；
- 在曹方控制区内的庇护与住处无法按原链成立。

因此局部 nx 是真功能。

### 拿掉关羽的最终归向条件

如果关羽完全接受“以后最终归属曹操、去留由曹操决定”，则长期归属层 nx 会显著上升。

原文不是。

### 拿掉军事包围强迫

即使没有死亡威胁，只要关羽仍需要曹操的现实资源/许可来保障二夫人，则保护资源层 nx 仍可成立；反之，若这些条件已经属于关羽自己的稳定处分范围，则 nx 会下降。

## 6｜反向测试

### 只有长期方向自主，没有局部 nx

若关羽自己拥有可稳定调用的住处、供给、军队和保护权，二夫人的安全完全不需曹操批准，则：

```text
长期归向自己定
+
保护资源也自己能调用
→ 不成立本轮局部 nx
```

### 长期方向也转为 nx

若曹操规定：

```text
最终归属曹方
何时离开由曹操决定
关羽不得设置退出条件
```

而关羽真实接受并持续沿此推进，则长期归属层才明显向 nx 转移。

## 7｜最近邻排除

### nx vs zx

关羽公开谈判并让曹操接受条件，存在局部 zx 候选；但本轮不把谈判成功本身升级为 zx。zx 仍需单独检查决定范围或凌驾位置是否真实新增。

### nx vs xn

本段核心不是关羽自己搭人员、时序、资源流程，而是调用曹操已有的军政与供给接口，因此保护资源层优先 nx，而非 xn。

### nx vs x

若二夫人的供给、安全禁令和住处本来就是关羽自己稳定可调用的资源，则应查 x。原文中这些现实接口掌握在曹方。

### 长期归属层 vs 局部资源层

这是本轮最关键的最近邻排除：

```text
“我最终归谁”
≠
“我当前必须经过谁取得某个现实保护/资源条件”
```

前者可以非 nx，后者可以同时 nx。

## 8｜第三因素冻结

冻结：

- 关羽忠义评价；
- 曹操爱才；
- 关羽武力；
- 后续挂印封金、千里走单骑；
- 历史史实与小说虚构争议。

只看：

1. 最终归向由谁决定？
2. 家属供养与安全条件由谁拥有现实处分权？
3. 关羽是否实际经过并承接该接口？

结论仍稳定：

```text
最终归属层：非 nx
保护/资源层：nx 成立
```

## 9｜本轮对木轴的新增价值

此前旧案已经证明：

> 进入他者体系，不等于把长期最终方向交出去。

本轮进一步补：

> 保留长期最终方向，也不等于主体在所有局部现实条件上都没有 nx。

因此以后必须强制拆层：

```text
终点/归属层
任务层
许可层
资源层
保护层
运行方法层
```

不能用某一层的“非 nx”覆盖整段事件。

## 下一证据目标

优先寻找《红楼梦》或《水浒传》中第二个同型：

> 主体明确保留自己的长期最终方向，但在一个局部保护、许可或资源对象层真实接入他者接口，因此“长期非 nx + 局部 nx”并存。

若跨至少三部独立作品稳定复现，再建立“nx 对象分层不可互相覆盖”的待审议纪律；本轮不修改 L1 或核心信息卡。
