# 运行记录｜孙悟空二调芭蕉扇：自搭欺骗 xn 很强，但关键真扇仍经罗刹女关系 / 资源接口取得

## 结论摘要

本轮不把孙悟空第60回“变作牛魔王骗真扇”计为第二个关羽五关式“高成本纯内部绕行”正例。

最窄可靠结论：

> 主体自己设计一条复杂替代路线，并不等于该路线已经内部自给。若实现同一结果仍依赖另一个主体掌握的关键资源，而且主体实际借用既有身份 / 关系通道促成资源转移，则 `xn` 自搭路线与局部 `nx` 关系 / 资源功能可以并存。

## 一｜剧情事实、触发、对象、动作、结果

### 触发

孙悟空为过火焰山需要真芭蕉扇。第59回向罗刹女直接借扇失败，且先取得过假扇；第60回又去找牛魔王，希望由牛魔王出面使罗刹女借真扇，仍未成功。

### 对象

当前结果对象固定为：

> **取得能够真正扇灭火焰山火焰的真芭蕉扇及其使用方法。**

因此本轮不同于武松“正式司法裁决 → 私力复仇”的换结果对象；这里 P1 / P2 均指向同一个真扇取得结果。

### 明确动作

牛魔王赴碧波潭宴饮后，孙悟空判断继续等待或直接求借无效，于是：

1. 偷走辟水金睛兽；
2. 变作牛魔王外貌；
3. 以“丈夫回家”的身份进入芭蕉洞；
4. 利用罗刹女对丈夫身份的信任询问真扇位置；
5. 罗刹女亲自吐出真扇交给“牛魔王”；
6. 罗刹女继续说出将扇变大的口诀；
7. 孙悟空记住口诀、带真扇离开。

### 结果

孙悟空确实取得真扇，并能按罗刹女所授方法将其变大；因此替代路线真实成功到达“取得真扇”这一结果。

## 二｜zx 判断

### 当前最高方向端：成立

“必须取得真扇、继续过火焰山”的方向仍由孙悟空自己维持。他没有把最终行动方向交给牛魔王或罗刹女。

### 但“骗到真扇”本身不额外锁 zx

欺骗成功、强主体、自主设计，并不自动等于决定范围扩大。孙悟空没有因此获得一个稳定的“以后谁能处分芭蕉扇由我决定”的公共权限接口。

因此：

`zx_from_deception_itself: rejected_as_primary`

## 三｜nx 判断

### 正常直接借扇 P1 已失败

罗刹女已经明确不愿正常借扇，牛魔王也没有成为成功的正常许可中介。因此 P1 直接求借通道没有被主体继续采用。

### 但 P2 并非纯内部自给

孙悟空的方案骨架确实主要由自己设计，这部分有明显 `xn`：侦察、跟踪、变形、伪装、身份利用、套取口诀。

然而真扇仍然：

- 不在孙悟空稳定 `x` 边界内；
- 实物由罗刹女掌握；
- 孙悟空不能只靠自己的已有资源“制造一把等价真扇”；
- 最终资源转移仍通过“牛魔王丈夫身份 → 罗刹女信任并交付”的既有关系通道完成；
- 使用方法也由罗刹女从外部提供。

因此局部仍可锁：

`nx_relation_resource_function: evidence-locked`

这里的 nx 不是“孙悟空听罗刹女决定过不过山”，而是：

> **关键资源与知识接口仍外置，主体通过既有关系身份通道实际取得。**

## 四｜与 xn 的最近邻排除

本例必须同时保留两层：

```text
怎么骗到扇？
→ 孙悟空自己搭欺骗路径
→ xn

真扇与口诀当前由谁掌握？
→ 罗刹女
→ 主体必须促成外部资源转移
→ 局部 nx
```

所以：

> **自己设计 P2 ≠ P2 所需全部关键条件都已内部化。**

若只因为“计策是孙悟空自己想的”就把整条链判为非 nx，会把运行方案来源与关键资源权限来源混为一层。

## 五｜拿掉测试

### 拿掉正常直接借扇 P1

原剧情证明孙悟空仍可通过 P2 取得真扇。因此：

> P1 不是最终结果的不可替代条件。

### 拿掉罗刹女持有的真扇 / 口诀接口

只保留孙悟空的变形、欺骗、金睛兽与计划，无法按原链得到“真芭蕉扇 + 使用方法”。

因此：

> **P2 的关键现实条件仍未内部化。**

### 拿掉“丈夫关系身份”

如果孙悟空不能让罗刹女相信自己是牛魔王，则原文这条资源交付链直接失去关键入口，需要重新另找方式。

因此既有关系通道是 P2 的真实结构支柱，而非装饰。

## 六｜反向测试

真正的关羽式纯内部绕行应满足：

```text
P1 外部许可失败
→ 主体改走 P2
→ P2 不依赖等价外部许可 / 关系 / 关键资源接口
→ 仍实现同一结果 R
```

本例实际是：

```text
P1 直接借扇失败
→ 孙悟空自搭欺骗 P2
→ P2 仍依赖罗刹女持有真扇
→ 仍借“丈夫身份”这一既有关系通道促成交付
→ 同一 R 实现
```

所以它只能证明：

> **原 P1 被绕过，但外部接口层没有被消灭，而是换成了“身份/关系 + 资源转移”的另一种接口。**

## 七｜第三因素冻结

冻结：

- 孙悟空是否聪明；
- 变形术强弱；
- 罗刹女与牛魔王夫妻伦理评价；
- 红孩儿旧怨；
- 后续牛魔王夺回扇子与第61回结局。

只保留：

1. 真扇是否仍由外部主体掌握；
2. P2 是否必须让该外部资源发生转移；
3. 主体是否实际借用了既有关系身份通道；
4. 主体能否不经这些外部条件稳定得到同一个真扇结果。

结论仍为 99/97。

## 八｜结论状态

`evidence-locked`

本轮可靠边界：

> **高强 xn 自搭替代路线，不足以证明 nx 已消失。应继续检查 P2 的关键资源、权限、关系与专业条件是否真正内部化。**

> **“绕过原许可方式”与“绕过整个外部接口层”必须分开。**

本轮不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。

## 九｜与现有控制的最小差异

- 关羽五关：无文凭后，以自身武力连续实现同一物理通行结果；当前许可 nx 可退出。
- 玄奘秘密西行：绕过中央许可，但继续依赖地方僧人、州吏、向导、马匹等外部接口。
- 孙悟空二调芭蕉扇：绕过直接求借，自己设计欺骗路径，但真扇与口诀仍由罗刹女掌握，并通过夫妻身份关系通道完成资源转移。

玄奘与孙悟空分别形成“地方关系/资源接力”和“资源持有人+身份关系利用”两种不同反向机制。

## 十｜下一轮

继续寻找第二个真正关羽型正例，但增加硬门：

- P1 / P2 必须保持同一结果对象；
- P2 不得只是换另一个外部节点；
- P2 不得仍依赖关键外部资源持有人主动/被诱导完成转移；
- P2 必须由主体已有 `x` 与自搭 `xn` 足以闭环；
- 成本可以高，但必须实际成功并可清楚验证。
