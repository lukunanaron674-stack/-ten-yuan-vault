# 待审议问题｜《水浒传》宋江招安线：二极化不等于 current xz，真实回返通道可在征讨压力下继续存在

## 0｜权限与 current canonical

本文件仅是 L4 水轴边界研究，不修改 L1/L2、信息卡、准度卡或正式关系卡。

按 latest main 的 L1 v1.6：

```text
水＝阳水 xz ↔ 阴水 nz
主题领域＝命运
广义变量＝可逆性与对象特异回返空间
xz＝持续收窄
nz＝保存、恢复或重建
```

本轮沿用 current `xz v2.2` 的“终点前置＋路径持续收窄＋路径汇流”门，以及 `nz v2.0` 的对象特异、真实关系、自由性、现实回返与修复门。旧火药桶口径只作历史/子型，不倒灌本轮。

## 1｜研究问题

当前高价值缺口是寻找：

```text
same actor
+ same current window
+ same object
+ same changed_variable
```

下 `xz` 与 `nz` 是否能同时独立成立。

《水浒传》宋江第七十五至八十二回提供一个非常接近的最近邻：梁山与朝廷的现实关系被战争与招安反复拉扯，看上去“未来越来越只剩少数结局”，同时宋江又一直保存向朝廷重新进入的招安通道。

本轮结论不是硬锁共现，而是锁一条更上游的 guard：

> **同一对象层的未来处置空间从“很多政治可能”压成“征讨/归顺等少数现实端点”，仍不自动等于 current `xz`。二极化、选项变少、战争升级，都不足以替代“一个前置终点持续取得支配地位并让不同路径汇向它”。**

并且：

> **征讨压力存在、一次或多次招安接口失败，也不自动使对象特异回返通道归零；只要该通道后来仍被现实主体反复调用、对方也现实回应并最终完成重新进入，`nz` 可以独立成立。**

## 2｜固定事实字段

```yaml
trigger:
  - 前次招安因诏书措辞、御酒被调包及梁山内部冲突而失败
  - 两次招安受损后朝廷继续派兵征讨
actor: 宋江（兼作梁山归顺意向的主要行为主体）
action:
  - 失败后仍明确向朝廷表达归降、尽忠报国意向
  - 面对再征讨组织防御
  - 擒高俅后不杀，现实请求其回朝再奏招安
  - 后续接受新的赦诏并率众归顺
object: 宋江/梁山 ↔ 朝廷秩序的现实归顺与合法身份关系
object_layer: 梁山相对于朝廷的现实政治/法律 reentry 与处置路径
changed_variable: 该对象层上可现实继续的未来处置/回返路径集合
observable_result:
  - 失败招安并未终结宋江的归顺意向
  - 朝廷征讨与梁山抵抗继续存在
  - 宋江仍主动保留并调用招安接口
  - 高俅被擒后宋江再次请求宽赦招安
  - 第八十二回新的赦诏现实到达，梁山全伙受招安
```

## 3｜文本事实锚点

### 第七十五回｜失败招安后，归顺意向没有消失

招安使者离山时，宋江明确说明并非梁山“无心归降”，并请求对方回朝善言；其表达的现实目标仍是尽忠报国，而不是把本轮失败视为与朝廷关系的终局断绝。

事实源：`《忠义水浒传》第七十五回 活阎罗倒船偷御酒 黑旋风扯诏谤徽宗`。

### 第八十回｜战争升级，但宋江继续现实调用回返接口

两次招安受损后，宋江明确担心“越增的罪恶重了”、朝廷必再派兵。高俅再征梁山并被擒后，宋江没有将其处死，而是以归顺主体身份再次请求宽恩与招安；高俅现实答应回朝奏请宽赦招安。

这说明同一窗口里：

```text
征讨 channel = active
招安/reentry channel = 仍可现实调用
```

而不是“战争升级 → 招安路径已经不存在”。

### 第八十二回｜回返接口最终真正兑现

新的赦诏现实到达梁山，诏文明确赦免宋江等此前罪责，并要求其归降；宋江等接受诏书、谢恩，随后完成全伙受招安。

因此本轮不是用后见之明给早期单方愿望贴 `nz`，而是存在：

```text
早期明确归顺意向
→ 失败
→ 再征讨
→ 再次现实调用中介/招安路径
→ 朝廷现实回应
→ 新赦诏到达
→ 实际重新进入朝廷秩序
```

## 4｜nz 独立判断

### 4.1 对象特异：通过

被测对象不是“找任何能收留梁山的势力”，而是明确回到朝廷秩序、获得赦免与合法身份。

### 4.2 真实关系：通过

宋江原本即处在宋朝地方官吏/法律秩序中；落草以后，被测的是重新进入同一朝廷政治法律秩序，而非创造一段全新无关关系。

### 4.3 回返现实性：通过

不是只有“想招安”的台词；招安使者、诏书、高俅转奏、宿太尉赦诏等接口均真实发生并被反复调用。

### 4.4 双方性：通过

朝廷侧并非全程拒绝。不同使者/权臣会扭曲过程，但皇帝侧最终再次发出赦诏并现实接纳；第八十二回完成重新进入。

### 4.5 修复/重新接近：通过

此前“贼/征讨对象”的法律政治位置被赦免和归顺机制现实改写，旧冲突关系进入新的合法共同秩序。

因此：

```yaml
current_nz: true
nz_subtype: political-legal-reentry / repaired-legitimate-return
```

本轮不把“忠义主题”“宋江想当官”“最后真的招安”本身当判据；真正证据是对象特异、失败后路径仍现实可调用、对方现实回应和最终重新进入。

## 5｜xz 独立判断｜为什么本轮反而不能锁

这个窗口很容易被误判成：

```text
招安失败
→ 征讨升级
→ 梁山政治未来越来越少
→ 最后受招安
→ 所以 xz
```

但 current `xz v2.2` 不能用最终结局倒推。

### 5.1 终点前置：不足

至少在第七十五至八十回的 current reality 中，存在两个性质不同且都现实的高层端点：

```text
A：继续征讨 / 军事冲突
B：重新招安 / 归顺
```

而且 B 并非只在事后出现，它在战争中仍被宋江现实保留和调用。

### 5.2 路径持续收窄：不稳定

招安接口不是单向关闭：它失败、受阻，又经高俅/宿太尉等现实节点重新打开。路径集合发生重排、争夺与重开，而不是稳定单调地 `n>...>1→0` 或汇向同一结局。

### 5.3 路径汇流：失败

军事征讨与政治招安并不是“不同表面路径最终都回到同一个前置终点”的同义分支。它们在本窗口仍会产生不同现实结果。

### 5.4 最终受招安不能后验制造 xz

第八十二回实际归顺，只证明其中一条路径最后兑现；不能把“最后选中了 B”倒写成“此前所有路径早就在向 B 汇流”。

因此：

```yaml
current_xz: false
false_positive_source:
  - political pressure
  - war escalation
  - option count reduction
  - final outcome hindsight
```

## 6｜same object / same changed_variable 检查

这次与宝黛后期“伪同层”不同。

```text
same_actor: TRUE
same_current_window: TRUE
same_object: TRUE
same_object_layer: TRUE
same_changed_variable: TRUE
```

两端都在测：

> **宋江/梁山相对于朝廷秩序的现实未来处置与重新进入路径集合。**

因此失败不是因为跨层，而是因为 `xz` 本身没有过 current 独立门。

这使本案成为比“cross-layer co-occurrence ≠ strict”更近的一道前置护栏。

## 7｜最近邻

### vs z

诏书、招安使者、高俅转奏、赦诏都是关键裁定节点，但节点反复出现只说明 `z/xn` 流程在运行，不自动证明未来路径持续汇流。

### vs xn

招安、征讨都依赖多节点制度流程。流程越来越复杂或越来越强硬，不等于 xz；必须另外看到未来选项稳定收窄并向同一前置终点汇流。

### vs zx

宋江主动放高俅、请求转奏，会推动后续招安因果；这是“现在推出后果”的候选，不等于“未来终点已经在牵引现在”。

### vs nz

本案恰好说明：`nz` 可以在巨大外部压力下仍成立，只要对象特异的现实 reentry path 没有归零，而且后来被双方现实兑现。

## 8｜拿掉测试

### 拿掉 nz

假设宋江从第七十五回起明确放弃朝廷、拒绝任何赦免与使者，朝廷也永久取消所有招安接口，只剩征讨。

那么 `nz` 显著下降；但是否形成 `xz` 仍需继续检查征讨是否让不同现实路径持续汇向同一前置终点，不能自动上升。

### 拿掉战争升级

假设没有童贯/高俅继续征讨，而招安路径仍被宋江与朝廷反复现实调用并最终完成，`nz` 仍然可以成立。

所以：

```text
war pressure ≠ nz cause
nz retained ≠ xz cause
```

## 9｜反向测试

真正把本案推向 current xz，至少需要出现：

```text
一个未来终点先取得稳定结构地位
+ 其他现实端点持续失效
+ 招安/征讨/中介/等待等不同路径都越来越回到该同一终点
+ 新接口不是反复重开替代未来，而只是同一终点的不同入口
```

本窗口没有达到这套标准。

## 10｜第三因素冻结

必须拿掉：

- “忠义”主题词；
- 宋江人格评价；
- 朝廷正统性；
- 最终招安结局的后见之明；
- 战争胜负；
- 高俅/蔡京的善恶评价。

剩下的结构仍是：

```text
对象特异回返通道多次受阻
+ 仍被现实调用
+ 对方仍有回应接口
+ 最终真实重入
= nz strong

政治/军事未来被压缩成少数端点
+ 端点之间仍真实竞争
+ 回返接口会重新打开
+ 没有稳定单一终点汇流
= xz false
```

## 12｜本轮锁定规则

> **二极化 ≠ xz。**

> **“未来只剩两三个现实端点”只能证明 option-set 变少，不能证明这些端点已经向同一个前置终点汇流。**

> **路径数量下降但会反复重开、不同端点仍真实竞争时，不得因为最终结局已经发生而后验锁 xz。**

> **same actor + same window + same object + same changed_variable 只是 strict/co-occurrence 的资格门，不替代两端独立成立。**

## 13｜下一轮最高价值缺口

继续优先四大名著，不降门槛：

```text
same actor
+ same current window
+ same object
+ same changed_variable
+ xz independently true
+ nz independently true
```

然后再做 removal / reverse 判断是否只是 same-layer co-occurrence non-strict，还是进入真正 strict 候选。

如果下一批仍只是“选项变少但多个端点继续真实竞争”，应优先累计为 current xz false-positive guard，而不是硬凑水轴共现。
