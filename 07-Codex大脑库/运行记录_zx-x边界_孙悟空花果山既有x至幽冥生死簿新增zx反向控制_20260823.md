# 运行记录｜孙悟空：花果山既有 x → 幽冥生死簿新增 zx

## 1｜本轮目的

现有 `zx↔x` 待审议已经跨《西游记》《红楼梦》《三国演义》锁住反面纪律：已有权限公开成功行使，优先检查 `x`，不能只因结果强烈就判 `zx`。

本轮专门补它要求的反向最小差异：

```text
阶段1：主体已经拥有一块稳定局部权限 = x
阶段2：主体进入原本不属于自己的新对象域
阶段3：公开取得并实际改写该新对象域的处分接口
= 新增 zx
```

选择孙悟空，是因为同一人物、连续早期阶段、对象域边界非常清楚，且第三回“勾销生死簿”已有 99/98 正式 zx 锚，不重复制造同义人物结论。

## 2｜剧情事实

### 2.1 花果山：既有局部 x

第一回中，石猴发现水帘洞后，众猴依此前约定拜其为王。他随后高登王位，称美猴王，并在花果山水帘洞内部“分派君臣佐使”，长期作为猴群首领运行。

这说明在进入幽冥界以前，孙悟空已经有一块真实、稳定、可直接调用的局部对象域：

```text
花果山 / 水帘洞
+ 猴群内部首领位置
+ 君臣佐使分派
= 既有局部 x
```

这里不需要 `zx` 才能解释每一次猴群内部命令；权限已经建立后，正常调用优先是 `x`。

### 2.2 幽冥界：进入新对象域

第三回，孙悟空被勾死人拘入幽冥界后，不接受阴司对其寿数和死亡的处分。十王、判官原本掌握生死簿及其更改接口；孙悟空要求取簿、亲自检阅，拿过笔簿，先勾销自己，又把“猴属之类，但有名者”一概勾去，随后宣布不再受阴司管辖并持棒离开。

十王无法维持原处分，只能转向地藏王及天庭奏报。

因此本轮新增对象不是“花果山猴群”，而是：

```text
阴司生死名录
+ 寿命 / 死亡记录处分接口
```

该对象域在冲突发生前并不属于孙悟空原有 `x`。

## 3｜触发、对象、动作、结果

- 触发：阴司依据生死簿拘取孙悟空。
- 旧 x 对象：花果山、水帘洞、猴群首领内部调用边界。
- 新 zx 对象：阴司生死簿及猴属寿命/死亡记录处分界面。
- 明确动作：否定阴司处分；公开闯入森罗殿；要求取出生死簿；取得笔簿；自行勾销本人及猴属名录。
- 结果：原本不属于孙悟空的生死处分界面被其直接改写；阴司当场不能压回，只能向更高系统报告。

## 4｜zx 证据

本轮 `zx` 成立不是因为孙悟空“本来就是猴王”，而恰恰因为：

```text
原有 x = 花果山猴群治理
新对象 B = 阴司生死处分
B 原本不归孙悟空
→ 孙悟空公开把自身权能推进 B
→ 阴司实际被迫响应
→ B 的现实结果被改写
= 决定范围超过旧 x 基线
```

四道硬门均过：

1. 自身方向明确：拒绝阴司对自己和猴属的死亡处分；
2. 权能公开显现：公开闯殿、索簿、亲手改写，不是秘密偷改；
3. 外部真实响应：十王、判官配合取簿递笔且无法当场恢复原决定；
4. 决定范围扩大：由花果山猴群首领，跨入原不属于自己的阴司生死记录处分对象域。

因此 `zx_new_underworld_life_death_disposition_boundary: evidence-locked`。

## 5｜x 最近邻排除

如果孙悟空只是回花果山命令猴群、重新分派君臣、处理洞内事务，即使所有猴子都服从，也首先是既有 `x` 的成功调用。

本段之所以不能降成 `x`，就在于：

> 生死簿更改权在冲突前不属于孙悟空。

所以 `x` 与 `zx` 最短差异再次得到同人物控制：

```text
x：我本来就能处分 A，现在把 A 用出来。
zx：我原本不能处分 B，现在公开把权能推进 B，并让 B 真正按新增位置改变。
```

## 6｜nx 排除

孙悟空没有向十王、地藏王或天庭申请更正并等待批准，没有沿阴司既有申诉/许可通道续接，也没有借关系节点取得处分结果。

因此第三回窄阶段：

`nx_in_underworld_narrow_stage: rejected`。

这也说明本轮不是严格 `zx↔nx` 补关系案例。

## 7｜xn 最近邻排除

取簿、查名、勾名存在步骤，但核心变量不是流程如何设计，而是“谁取得原本不属于自己的最终处分接口”。

若主体只在自己已有权限内重排流程，才优先检查 `xn`；本例核心是权限对象域真实外扩，因此 `zx` 主判。

## 8｜关键压力

外部压力是阴司宣称并执行对孙悟空寿命/死亡的终局处分。

压力本身不判 `zx`。真正显影的是：主体没有回到花果山旧权限解决，而是把自身决定边界直接推进阴司新对象域。

## 9｜拿掉测试

### 拿掉花果山既有 x

第三回勾销生死簿仍然可以单独判 `zx`，但会失去本轮用于 `x↔zx` 的“旧基线 → 新对象域”最小差异价值。

### 拿掉生死簿新对象域

若孙悟空只是在花果山继续当美猴王、调度猴群，则仅能证明旧 `x` 有效，不能锁新增 `zx`。

### 拿掉阴司现实响应

如果孙悟空只口头宣布“不归你们管”，但名录没有改变、十王立即压回且处分照旧，则 `zx` 第四门显著下降。

### 拿掉战斗强度

只保留“原权限不在我 → 我公开取得并改写 → 原系统无法维持旧结果”，`zx` 仍成立。证明战斗强度不是支柱。

## 10｜反向测试

### 反向为纯 x

```text
生死名录本来就归孙悟空长期正常处分
→ 他按常规修改猴属记录
= x
```

原文不是。

### 反向为 nx

```text
孙悟空发现寿数问题
→ 向十王/地藏王申请
→ 外部节点审核批准
→ 孙悟空接受结果
= nx 权限通道
```

原文不是。

### 反向为扩权尝试但未成立

```text
孙悟空试图夺生死簿
→ 阴司立即夺回
→ 名录未改变
→ 新对象域没有进入其现实决定范围
= 只能查 zx 尝试，不能锁高纯 zx
```

原文同样不是。

## 11｜第三因素冻结

冻结：孙悟空战斗力、仙术、齐天大圣后续身份、人物主十元、善恶评价、死亡主题、梦境叙述形式、最后是否被天庭追责。

只保留：

```text
旧权限对象域是什么？
新对象域原本归谁？
主体是否公开推进？
原系统是否真实响应？
新对象域是否被实际改写？
```

分类仍保持 98%。

- 旧状态/关系位置：花果山猴王的既有局部 `x`。
- 当前状态：第三回 `zx` 高显影。
- 行为功能：公开夺取并改写阴司生死处分接口。
- nx：本窄阶段排除。
- 严格 `zx↔nx` 补关系：不锁。
