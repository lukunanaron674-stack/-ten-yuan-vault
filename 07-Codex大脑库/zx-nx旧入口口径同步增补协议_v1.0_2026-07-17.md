# zx—nx 旧入口口径同步增补协议 v1.0

## 1. 发现的同步缺口

专项正本已经确认：

```text
zx 启动人情接口；
nx 承接并延续已经成立的互惠关系。
```

但两个高频入口仍保留以下旧概括：

```text
zx 提供方向和开路；
nx 提供人际、照顾、日常承接与社会支持。
```

该旧概括会把关系机制误读为 nx 的稳定本体能力，并让人以为 nx 会主动经营人脉、主动拉关系或主动做人情世故。

从本协议起，上述旧概括在涉及 `zx ↔ nx` 时停止作为正式口径。

## 2. 现行正式口径

```text
nx 本来愿意帮助别人，
但在没有明确请求、具体事务或名正言顺的关系入口时，
通常不会主动伸手建立人情接口。

zx 通过主动开口、明确请求或把 nx 拉入第一次互助事件，
为 nx 提供关系进入许可、具体角色和合理行动理由。

接口成立以后，
nx 通过可靠承接、回帮、照顾和后续执行，
让一次性接触发展为可持续的互惠关系。
```

最短冻结句：

```text
zx 启动人情接口；
nx 延续人情循环。
```

## 3. 对象分层

必须区分：

```text
人物稳定本体：nx 是否长期不主动占据选择、方向和位置；
当前状态：nx 此刻是否愿意帮助、是否已有明确行动理由；
行为功能：某次搭手、回帮、照顾或完成托付；
关系位置：zx 是否承担第一次开口与关系启动；
时间关系：第一次互助是否形成后续回流；
动态链：接口是否真正被启动，互惠是否真正被延续。
```

不得把：

```text
一次帮忙
= nx 本体；

会照顾人
= nx 天生擅长社交；

zx 主动开口
= zx 接管 nx 的全部方向；

nx 没有主动伸手
= nx 没有帮助意愿。
```

## 4. 候选机制与最近邻排除

### 4.1 不是领导—服从

```text
zx 改变的是关系进入许可和第一次互助机会；
不是替 nx 决定全部人生方向。
```

### 4.2 不是主动社交—资源经营

```text
nx 改变的是已经成立关系中的事务完成度、互惠持续性和关系回流；
不是主动建立社交网络。
```

### 4.3 不是善意从无到有

```text
zx 没有创造 nx 的善意；
zx 只是给原有帮助意愿提供了明确、正当、可执行的入口。
```

### 4.4 不是单次好人行为

```text
某人偶尔帮助别人，只能先记录为行为；
只有关系接口与持续互惠机制实际成立，才可调用 zx—nx 互补。
```

## 5. 拿掉测试

### 拿掉 zx

```text
nx 仍可能愿意帮，
但因没有明确请求、具体角色或合理入口而不主动伸手；
互助关系难以启动。
```

### 拿掉 nx

```text
zx 即使完成第一次开口，
关系也可能停留在一次性接触；
缺少可靠承接、回帮和后续延续。
```

### 两者同时存在但关系未启动

```text
人物同框或分别具有 zx、nx 特征
≠ zx—nx 互补已经发生；
必须观察到第一次接口启动与后续互惠承接。
```

## 6. 对现有文档的读取规则

在以下旧入口正文尚未直接同步前：

```text

```

凡读到：

```text
nx 提供人际维护、社会资源、关系缓冲；
nx 独立完成人际经营；
zx 提供方向、nx 负责人际。
```

必须改读为：

```text
zx 提供第一次关系入口与明确行动理由；
nx 承接并延续已经成立的互惠关系。
```

专项校准正本与本增补协议优先于旧入口措辞。

## 7. 理论后果

```text
1. nx 的稳定本体不再被“会做人际关系”污染。
2. zx—nx 互补从能力拼盘改为关系过程。
3. 动态链必须同时证明“启动”与“延续”两个阶段。
4. 一次帮助、善良、照顾或熟人社会行为不能单独判 nx。
5. zx 与 nx 的互补资格仍成立，因为双方改变的变量不同且互相不可替代。
```

## 8. 当前冻结结论

```text
zx—nx 互补的核心不是“方向开路 ↔ 人际经营”，
而是“关系接口启动 ↔ 互惠承接延续”。

nx 本来愿意帮，但没有明确、正当的关系入口时通常不主动伸手；
zx 负责制造第一次可进入的互助事实；
nx 负责让该事实继续形成回帮、照顾与长期互惠。

该结论属于关系机制，
不替换 zx 或 nx 的人物稳定本体定义。
```
