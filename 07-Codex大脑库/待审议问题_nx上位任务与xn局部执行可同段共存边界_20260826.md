# 待审议｜nx 上位任务与 xn 局部执行可同段共存边界

## 0｜为什么形成待审议

已经连续跨三个独立作品观察到同型结构：

```text
上位目标 / 授权 / 任务入口由外部给出
+ 主体真实承接
= nx

但进入任务以后
具体人员、资源、节点、话术、时序或流程由主体自行组织
= xn
```

三部作品分别来自谋略、组织治理和军事战役，表面类型不同，核心变量一致，因此达到“跨至少 3 个独立作品的同类边界问题”门槛。

本文件仅形成 `pending-review`，不得直接修改 L1、nx 信息卡、准度卡或十元核心定义。

---

## 1｜三部作品控制

### A｜《三国演义》貂蝉连环计｜99/97

```text
王允：给出离间董卓吕布、借吕布除董卓的上位政治任务
→ nx

貂蝉：现场自行组织哭诉、误导、自刎威胁等执行节点
→ xn
```

护栏：秘密操盘成功不等于 zx；本轮只锁上位 nx + 局部 xn。

### B｜《红楼梦》王熙凤协理宁国府｜99/98

```text
贾珍请托 + 王夫人放行跨府协理任务
→ nx

凤姐：自行分班、定责任、定时刻、设赔补、汇报、巡查节点
→ xn
```

护栏：授权完成后的局部 x 与是否进一步扩成 zx 仍需分层；不能拿整体 zx 分叉污染 nx/xn 子结论。

### C｜《水浒传》呼延灼征梁山｜99/98

```text
高俅 / 朝廷给“征剿梁山”最高任务
→ nx

呼延灼：举先锋、调三路军马、分装备、编前中后军、打造并运行连环马
→ xn
```

护栏：已有局部战役统辖可形成 x 邻近；领兵和排阵本身不等于 zx。

## 2｜当前最窄待审议规则

候选纪律：

> **“谁决定要做什么”与“谁决定具体怎么运行”必须分层。上位任务或授权来源外置并被主体真实承接，可成立 nx；主体在该任务内部主动组织人员、资源、节点、时序与流程，可同时成立局部 xn。两者不互相覆盖。**

更短：

```text
老板给目标
+ 我自己搭流程
= 上位 nx + 局部 xn
```

不是：

```text
接了别人的任务
→ 整段纯 nx
```

也不是：

```text
我会计划、会组织
→ 上位任务来源自动不再 nx
```

新增反向护栏：

```text
名义进入上级体系 / 接受其职位、供给、保护或资源
≠ 上位 nx 自动成立
```

若主体真实重写该关系的最高目标、保留最终否决与退出权，并未沿上级方向作为自己的最终方向推进，则应先降低或排除该对象层的 nx，再检查局部 x/xn/zx；不能只凭“已经入了这个体系”永久追挂 nx。

---

## 3｜必须保留的对象层检查

在任何候选案中必须分开：

```text
A 上位任务 / 最终目标是谁给？
B 主体有没有真实承接该外部方向？
C 局部运行方法是谁组织？
D 局部权限是否已经内化为 x？
E 主体是否进一步公开越过授权边界形成 zx？
```

A/B 支持 nx；C 支持 xn；D 是 x 最近邻；E 才重新检查 zx。

不得用一个层面的证据覆盖另一个层面。

特别补充：**A 有外部方案或名义任务，并不等于 B“真实承接”已经成立。** 必须检查主体是否把该方向作为自己的当前最高任务继续推进，还是仅把外部身份/资源当作临时接口，同时保留或重写最终方向。

## 4｜拿掉与反向测试模板

### 拿掉上位 nx

去掉外部任务 / 授权，让主体自行决定最高目标：

- 若局部组织能力仍在，xn 可继续成立；
- 但原上位 nx 应消失。

### 拿掉局部 xn

保留外部任务，但把所有具体方法、节点、时序和资源配置都改成上级逐项写死：

- nx 仍可成立；
- xn 应显著下降；
- 整段更接近纯任务 nx。

### 反向成更强 xn

若上级只给极粗目标，主体自己重新定义对象、流程和节点，xn 上升；但只要最高任务仍真实外置，不能自动抹掉上位 nx。

### 反向成伪 nx

若名义上进入上级体系，但主体：

```text
重写关系成立条件
+ 保留最终归向
+ 保留否决权
+ 保留明确退出权
+ 上级反而必须接受这些条件
```

则不能只凭“入职 / 投降 / 受封 / 接受供给”锁上位 nx。此时应先检查该对象层的最终方向是否其实仍由主体占据。

### 反向成 zx

只有主体公开把决定范围推到原授权之外，使更高秩序围绕其新增决定权重新反应，才检查 zx。

## 5｜最近邻护栏

### nx vs xn

```text
nx：方向 / 权限 / 任务入口由外部给出，主体沿其推进。
xn：主体主动组织运行方式，使事情按自己搭出的节点与流程持续运行。
```

新增《西游记》反向护栏：**执行复杂、动作很多、战斗很多，不足以单锁 xn。** 如果关键节点、胜负方向与终点已经由外部方案预设，而主体只是在节点内部完成临场动作，仍应优先判 nx；只有主体真实重组核心运行骨架时，xn 才上升。

新增《三国演义》反向护栏：**名义上进入外部体系、接受资源或职位，不足以单锁上位 nx。** 如果主体没有把对方的最高方向当作自己的最终方向，而是重写条件、保留否决和退出，甚至让对方围绕这些条件调整，则该对象层优先排除或降低 nx。

### nx vs x

外部任务入口可为 nx；进入任务后，某些人员 / 资源 / 权限若已经稳定进入主体直接调用边界，可形成局部 x。x 不会自动删除上位 nx。

### xn vs zx

会设计流程、调兵、排程、操盘，不等于公开扩权。zx 必须另证权能公开显现、现实秩序响应和决定范围扩大。

## 6｜第三因素冻结

应冻结：

- 人物聪明、强势、能干等性格评价；
- 职业和身份标签；
- 最终胜负；
- 道德评价；
- “谋略家 / 管理者 / 名将”等主题标签。

保留：

```text
上位目标来源
主体是否承接
局部运行结构由谁搭
局部权限是否稳定内化
是否越过授权边界
```

如果冻结后仍得到同一分层，边界才有方法价值。

对“伪 nx”还应额外冻结：外部强迫、生存威胁、职位名义、一次临时供给。真正保留的是主体是否拥有并实际使用**最终否决、重设与退出位置**。

## 7｜反例方向与已锁反向护栏

### 7.1 伪 xn｜《西游记》孙悟空红孩儿诱敌｜99/98

观音明确给出当前战术子任务的关键运行节点：

```text
去索战
→ 许败不许胜
→ 败回观音跟前
```

悟空“领命”后叫阵、破门、交战、诱敌，动作极多，但没有重组关键胜负方向与终点。破门等只是节点内部的局部执行，不足以证明主体自己搭了运行骨架。

因此：

```text
当前战术子任务 nx：成立
当前战术子任务 xn：不足以独立成立
```

最短护栏：

> **忙、会打、临场动作多 ≠ xn；关键运行节点由谁设计，才是核心。**

这条是 `negative guard`，不增加三部正向控制的 `cross_work_count`。

### 7.2 伪 nx｜《三国演义》关羽土山约三事｜99/97

曹方提出“暂降”方案，并在后续提供职位、供给、居所与保护，看起来很像“进入上级体系 → nx”。但关羽在关系成立前明确提出三约：只降汉不降曹；二嫂供给和门禁必须按其要求；一旦得知刘备去向，无论远近立即辞去。三者缺一即拒绝。曹操最终逐项接受，甚至按关羽要求先退军，关系才能成立。

因此本窄对象层不是：

```text
曹方给最终方向
→ 关羽接受
→ 沿曹方方向继续
```

而是：

```text
曹方给临时方案
→ 关羽重写关系成立条件
→ 保留最终归向刘备
→ 保留否决与退出权
→ 曹操反过来接受并调整
```

拿掉曹操的军力包围与生存压力后，这个结构仍然说明：**名义进入他者体系、接受他者资源，不等于主体把最终方向交给他者。**

反向若改为“何时离开、最终归向、家属安排均由曹方决定，关羽不设条件也不保留退出”，上位 nx 才明显上升。

本条复用 2026-08-15 已有 `evidence-locked` 99/97 压力测试，不重复制造新人物案例文件；本轮新增的是把它作为本待审议的第二类反向护栏正式纳入。

最短护栏：

> **入体系 / 受供给 / 受封 ≠ nx；真实承接对方最终方向才是。**

### 7.3 后续继续寻找

1. 第二份**伪 xn**：看似很忙、会执行，但具体流程其实上级已写死，主体没有重组节点；
2. 第二份**伪 nx**：名义上有上级任务或体系，但主体保留最终方向、否决与退出，或真实重定义最高任务。

```text

老板给目标，员工主动排程搭流程：xn 上升
```

本待审议不是另造新定义，而是在三作品材料中进一步验证：

> **上位 nx 与局部 xn 可以同段并存，必须按对象层拆分。**
