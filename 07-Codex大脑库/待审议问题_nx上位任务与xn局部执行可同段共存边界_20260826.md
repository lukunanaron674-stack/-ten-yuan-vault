# 待审议｜nx 上位任务与 xn 局部执行可同段共存边界

## 0｜为什么形成待审议

已经连续跨三个独立作品观察到同型结构：

```text
上位目标 / 授权 / 任务入口由外部给出
+ 主体真实承接
= nx

但进入任务以后
具体人员、资源、节点、话术、时序或流程由主体自行组织
= xn
```

三部作品分别来自谋略、组织治理和军事战役，表面类型不同，核心变量一致，因此达到“跨至少 3 个独立作品的同类边界问题”门槛。

本文件仅形成 `pending-review`，不得直接修改 L1、nx 信息卡、准度卡或十元核心定义。

---

## 1｜三部作品控制

### A｜《三国演义》貂蝉连环计｜99/97

```text
王允：给出离间董卓吕布、借吕布除董卓的上位政治任务
→ nx

貂蝉：现场自行组织哭诉、误导、自刎威胁等执行节点
→ xn
```

护栏：秘密操盘成功不等于 zx；本轮只锁上位 nx + 局部 xn。

### B｜《红楼梦》王熙凤协理宁国府｜99/98

```text
贾珍请托 + 王夫人放行跨府协理任务
→ nx

凤姐：自行分班、定责任、定时刻、设赔补、汇报、巡查节点
→ xn
```

护栏：授权完成后的局部 x 与是否进一步扩成 zx 仍需分层；不能拿整体 zx 分叉污染 nx/xn 子结论。

### C｜《水浒传》呼延灼征梁山｜99/98

```text
高俅 / 朝廷给“征剿梁山”最高任务
→ nx

呼延灼：举先锋、调三路军马、分装备、编前中后军、打造并运行连环马
→ xn
```

护栏：已有局部战役统辖可形成 x 邻近；领兵和排阵本身不等于 zx。

## 2｜当前最窄待审议规则

候选纪律：

> **“谁决定要做什么”与“谁决定具体怎么运行”必须分层。上位任务或授权来源外置并被主体真实承接，可成立 nx；主体在该任务内部主动组织人员、资源、节点、时序与流程，可同时成立局部 xn。两者不互相覆盖。**

更短：

```text
老板给目标
+ 我自己搭流程
= 上位 nx + 局部 xn
```

不是：

```text
接了别人的任务
→ 整段纯 nx
```

也不是：

```text
我会计划、会组织
→ 上位任务来源自动不再 nx
```

---

## 3｜必须保留的对象层检查

在任何候选案中必须分开：

```text
A 上位任务 / 最终目标是谁给？
B 主体有没有真实承接该外部方向？
C 局部运行方法是谁组织？
D 局部权限是否已经内化为 x？
E 主体是否进一步公开越过授权边界形成 zx？
```

A/B 支持 nx；C 支持 xn；D 是 x 最近邻；E 才重新检查 zx。

不得用一个层面的证据覆盖另一个层面。

---

## 4｜拿掉与反向测试模板

### 拿掉上位 nx

去掉外部任务 / 授权，让主体自行决定最高目标：

- 若局部组织能力仍在，xn 可继续成立；
- 但原上位 nx 应消失。

### 拿掉局部 xn

保留外部任务，但把所有具体方法、节点、时序和资源配置都改成上级逐项写死：

- nx 仍可成立；
- xn 应显著下降；
- 整段更接近纯任务 nx。

### 反向成更强 xn

若上级只给极粗目标，主体自己重新定义对象、流程和节点，xn 上升；但只要最高任务仍真实外置，不能自动抹掉上位 nx。

### 反向成 zx

只有主体公开把决定范围推到原授权之外，使更高秩序围绕其新增决定权重新反应，才检查 zx。

---

## 5｜最近邻护栏

### nx vs xn

```text
nx：方向 / 权限 / 任务入口由外部给出，主体沿其推进。
xn：主体主动组织运行方式，使事情按自己搭出的节点与流程持续运行。
```

### nx vs x

外部任务入口可为 nx；进入任务后，某些人员 / 资源 / 权限若已经稳定进入主体直接调用边界，可形成局部 x。x 不会自动删除上位 nx。

### xn vs zx

会设计流程、调兵、排程、操盘，不等于公开扩权。zx 必须另证权能公开显现、现实秩序响应和决定范围扩大。

---

## 6｜第三因素冻结

应冻结：

- 人物聪明、强势、能干等性格评价；
- 职业和身份标签；
- 最终胜负；
- 道德评价；
- “谋略家 / 管理者 / 名将”等主题标签。

保留：

```text
上位目标来源
主体是否承接
局部运行结构由谁搭
局部权限是否稳定内化
是否越过授权边界
```

如果冻结后仍得到同一分层，边界才有方法价值。

---

## 7｜反例方向

后续优先找两类护栏：

1. **伪 xn**：看似很忙、会执行，但具体流程其实上级已写死，主体没有重组节点；
2. **伪 nx**：名义上有上级任务，但主体实际上把最高任务目标也重设了，只是借用合法身份或资源入口。

尤其应从《西游记》补一份反向或正向控制，避免当前三部作品都偏人类政治 / 组织场景。
