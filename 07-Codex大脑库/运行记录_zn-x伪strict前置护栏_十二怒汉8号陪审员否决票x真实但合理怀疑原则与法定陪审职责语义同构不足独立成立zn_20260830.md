# 运行记录｜《十二怒汉》8号陪审员：否决票 x 真实，但合理怀疑候选 zn 与法定陪审职责语义同构

## 1｜本轮问题

P0 继续搜索第二份可靠文学 strict `zn↔x` v2 正向。

8号陪审员看起来非常接近：

```text
他真实拥有一票陪审表决 / 否决 x
+
他坚持“有人命在此，不能在没有充分讨论、仍有合理怀疑时就判有罪”
→ 是否可以锁 zn+x，再进入 strict？
```

本轮裁决：**不能启动 strict。**

不是 `x` 不够，而是候选 `zn` 与该角色的正式制度职责在内容上高度同构，当前证据不足以把“内部不可轻易让渡原则”与“认真履行法定陪审职责”分离到 ≥95%。

## 2｜剧情事实

### 2.1 制度前提

法官在陪审团退庭前明确交代：

- 若存在合理怀疑，应作无罪裁决；
- 若不存在合理怀疑，才应在良知下判有罪；
- 判决必须一致；
- 有罪将导致强制死刑。

因此从一开始，陪审员的正式角色就已经被制度规定为：

> **不得在合理怀疑仍存在时授权有罪裁决，并必须认真完成事实审议。**

### 2.2 8号陪审员的现实行为

首轮表决为 11 票有罪、1 票无罪。

8号陪审员并未声称自己已经证明被告无辜，而是拒绝在几分钟内把一个年轻人的生命送入死刑结果，要求先讨论证据和“如果我们错了怎么办”。

此后他持续检查证据：

- 刀具是否真的独一无二；
- 证人听见、看见的条件是否可靠；
- 时间、距离与经过列车等事实是否支持原证词；
- 其他陪审员的偏见和私人投射是否替代了证据判断。

最终陪审团从 11:1 转为一致无罪。

## 3｜x 端：高纯成立

被测对象不是“8号陪审员很有影响力”，而是：

> **他在本案陪审裁决中的正式表决 / 否决权限。**

为什么 `x=true`：

1. 对象明确：本案有罪 / 无罪裁决；
2. 主体明确：8号陪审员本人；
3. 权限明确：投票、拒绝加入有罪一致裁决；
4. 该权限不是名义：判决必须一致，他的一票真实阻断立即有罪结果；
5. 拿掉这一票，首轮 11:1 的现实结构会立刻变化。

所以当前窗口：

```yaml
x_current_for_jury_vote_and_veto: true
```

这符合 current `x` canonical：真实权限、明确对象、现实结果可被主体的决定改变。

## 4｜候选 zn：为什么不能独立锁

最自然的候选原则可以写为：

> **当一个人的生命将由当前裁决决定，而证据仍存在合理怀疑时，不应仓促授权有罪；应先完成足够审议。**

这当然“很像” `zn`，而且8号陪审员确实承受：

- 11人的群体压力；
- 被催促快速结束；
- 时间与社交成本；
- 其他人的敌意。

但 current `zn` 的拿掉测试要求：

> 拿掉认可、奖励、群体许可、**制度要求**与当前利益后，原则仍应进入判断。

本例最大的问题是：**法官给陪审员的正式规则，与候选原则的核心内容几乎重合。**

```text
制度职责：
合理怀疑存在 → 不得判有罪
必须认真区分事实与臆测

候选 zn：
合理怀疑存在 → 不应授权有罪
必须先认真审议
```

因此观察到8号陪审员坚持讨论，可以同时被两套机制解释：

```text
A｜内部 zn
他把“不能在合理怀疑下夺走生命”内化为不可轻易让渡原则

B｜高质量角色履责
他比其他陪审员更认真地执行法定陪审职责
```

当前电影窗口缺少足够独立证据把 B 冻结掉。

## 5｜新护栏：role-rule isomorphism confound

本轮锁出新的 strict 前置误判机制：

> **当外部制度规则与候选 `zn` 在语义上高度同构时，主体即使高成本、逆群体压力地执行该规则，也不能仅凭该角色内行为自动证明独立 `zn`。**

研究层简称：

`role-rule isomorphism confound｜角色规则—候选原则同构混淆`

最短公式：

```text
真实 x
+
认真履行 x 所属角色的正式规则
+
高代价 / 逆群体压力
≠
独立 zn 自动成立
```

必须额外看到至少一种更强证据：

1. 主体在该正式角色之外的独立情境也按同一原则排序；
2. 制度允许更宽松处理，而主体仍主动收紧自己的原则边界；
3. 正式职责与主体当前利益/角色收益同时被拿掉后，原则仍继续进入判断；
4. 主体明确拒绝一个“制度上允许但与内部原则冲突”的选择。

## 6｜为什么这不等于“制度原则永远不能成为 zn”

本轮并不裁决：

> “来源于法律、职业、宗教或制度的原则都不可能内化为 `zn`。”

原则完全可能被主体真正内化。

问题只是证据门：

> **当制度规则本身已经足以解释当前行为时，不能用同一个行为同时证明“制度要求存在”与“内部 zn 已独立成立”。**

这属于 `evidence_independence` 问题，而不是端点定义改写。

## 7｜拿掉测试

### 7.1 拿掉制度要求

假设法官没有明确要求“合理怀疑必须无罪”、没有一致裁决与死刑责任框架。

现有电影材料不足以 ≥95% 证明8号陪审员仍会以完全同一原则、同一边界承担相同阻断成本。

所以 `zn` 独立门未过。

### 7.2 拿掉 x

如果8号陪审员没有现实投票/否决权限，只是旁听者，那么他的意见无法直接阻断有罪裁决。

因此 `x` 是真的；但这只说明现实权限成立，不能反向替 `zn` 补票。

## 8｜反向测试

若存在以下材料，`zn` 才会明显上升：

```text
陪审制度允许他草率同意
或
他已退出陪审角色、没有正式义务
+
仍在独立高代价情境中坚持：
不能在证据不足时让国家剥夺一个人的生命
```

当前影片没有提供足够这类角色外复验。

## 9｜最近邻排除

### zn vs xn

8号陪审员怎样拆证词、重构时间线、提出秘密投票，是“如何推进审议”的流程/策略邻近；不能替代“为什么必须审慎裁决”的内部原则端。

### zn vs z

他一开始处于 11:1 少数，不靠群体赞誉才坚持，因此 `z` 认可并非主要解释；但这不能自动解决“制度职责”第三因素。

### x vs zx

8号陪审员后来影响整个房间、成为事实上的讨论核心，不等于其 `x` 扩张。被测 `x` 始终只锁正式的一票表决 / 否决权限。

### x vs xn

他能够组织讨论，不等于他拥有其他陪审员的票。其他人仍能自由改变或保留自己的裁决。

## 10｜第三因素冻结

本轮冻结：

- 电影把8号陪审员塑造成“理性英雄”的叙事评价；
- 其他陪审员的偏见程度；
- 最终被告究竟客观有罪还是无罪；
- 8号陪审员后来的领导魅力；
- 观众对死刑的态度。

只保留：

> 正式陪审规则、个人投票权限、首轮少数压力、行为是否可由角色规则完整解释。

结论不变。

## 13｜与已有护栏的差异

本轮不是宋江陈桥驿“外部法度 + 集体问责”换皮，也不是王熙凤“治理绩效”换皮。

区别是：

> **外部角色规则与候选内部原则本身的内容几乎相同。**

因此它专门防一种更隐蔽的错误：

```text
制度先定义“你应该这样判断”
↓
主体在该职位内认真照做
↓
研究者把这份认真执行
倒写成“主体内部必有同内容 zn”
```

这会直接污染所有职业伦理、司法、宗教戒律、军纪、医德与受托治理类 strict 搜索。
