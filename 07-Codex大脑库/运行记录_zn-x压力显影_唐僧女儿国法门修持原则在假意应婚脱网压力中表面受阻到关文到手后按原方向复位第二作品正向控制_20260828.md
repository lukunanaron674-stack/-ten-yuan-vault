# 运行记录｜唐僧女儿国：法门修持 zn 在假意应婚脱网压力中表面受阻，关文到手后按原方向复位

## 1｜本轮目的

P0 strict `zn↔x` 第一正例继续执行强门检查，但当前没有候选能同时通过 `zn→x` 与 `x→zn` 的不可替代双向缺口，因此本轮不降低 strict 标准。

转 P1：寻找第二部独立作品的 pressure-display 正向控制。要求：

```text
压力前：同一可命名 zn 已独立成立
压力中：zn 的最强现实表达被外部条件封住，但未来指导资格仍保留
解压后：同一 zn 按原判据复位，而不是新原则后生再倒填
```

## 2｜剧情事实

### 阶段 A｜压力前：原则已经显式存在

第54回师徒进入西梁女国之前，唐僧先明确告诫徒弟在女国必须谨慎守规矩，不可放荡情怀、紊乱法门教旨。

本轮把被测原则压窄为：

> **不因女色、婚配与现实高收益改变西行修持归向；婚姻关系不能替代当前法门/取经方向。**

这不是从“唐僧是和尚”身份直接倒推。压力前已有明确原则表达；随后女王以婚配、一国之富和现实身份收益提出替代路径时，该原则才进入真正冲突测试。

### 阶段 B｜压力进入：直接表达窗口被策略性封住

女王提出婚配并希望唐僧留下。孙悟空判断若当场强硬拒绝，对方可能不肯倒换关文、不放师徒继续西行，且存在现实伤害风险，因此提出“将计就计”：表面应下婚事，先取得关文并出城，再脱身继续西行。

唐僧接受的是**脱网策略**，不是把婚配改写成最终归属。

可观察结构：

```text
原则 P：不因婚配退出西行修持
+
现实压力：关文/放行仍由女国控制 + 直接拒绝可能产生安全风险
→ “公开立即拒婚并直接离境”这一最强表达窗口被封
→ 唐僧策略性表面应承
```

因此压力窗口不能仅凭“表面答应婚事”判旧 `zn` 已退出。

### 阶段 C｜解压：原方向立即复位

关文完成倒换、师徒取得出城条件后，唐僧并未把表面婚约继续当作真实最终关系，而是在出城节点立即要求女王回国，自己继续西行取经。

这不是压力后新发明一条原则，而是压力前已明确的“不可紊乱法门/不因婚配改变西行修持归向”重新恢复最强现实表达。

### 阶段 D｜相邻复验：第55回同类诱婚压力下继续守持

紧接第55回，唐僧又被蝎子精掳走并以婚配、色诱等方式施压；其“性正修持不坏身”继续维持同一类修持/不因女色改写归向的判断。

这一相邻复验用于确认第54回出城后的复位不是一次性策略翻转。

## 3｜zn 判定

### 支持

- 原则在婚配压力正式进入前已经明确表达；
- 女王提供婚配、身份与现实收益后，原则没有被这些奖励替换；
- 表面应承由“取得关文/避免冲突/继续西行”的脱网策略解释；
- 解压后，原西行修持方向立即重新获得现实行动资格；
- 第55回相邻同类诱婚压力继续复验相同边界。

结论：

```yaml
zn_before_pressure: true
zn_future_guidance_retained_during_pressure: true
strongest_expression_window_blocked: true
same_zn_reappears_after_release: true
```

本轮不锁唐僧稳定人物本体，只锁这一婚配/修持对象层与当前阶段。

## 4｜pressure-display 判定

### 正向结构

```text
压力前：
P = 不因女色/婚配改变西行修持归向
→ 已成立

压力中：
直接拒婚 + 直接离境
→ 被关文/放行/安全条件压住
→ 只能策略性表面应承

解压：
关文到手 + 出城条件形成
→ 立即恢复继续西行
→ 第55回同类诱婚压力继续按同一边界守持
```

因此：

> **expression window blocked ≠ `zn` erased。**

且满足与徐庶反向护栏相反的时间同一性条件：本例原则在压力前已经可命名、已进入判断；不是压力后才形成的新原则。

## 5｜拿掉测试

### 拿掉压力条件

若删掉“关文/放行受女国控制 + 直接拒绝存在冲突风险”，孙悟空就没有必要设计假意应婚脱网；唐僧可以直接把原原则完整表达为拒婚并继续西行。

说明压力主要作用于**表达方式/行动窗口**。

### 拿掉 zn

只保留“想离开女国”而删掉“不因婚配改变法门/西行归向”的内部标准，就无法解释：

- 为何女王提供高收益婚配仍不成为最终归属；
- 为何关文到手后立刻退出婚配路径；
- 为何第55回同类婚配/色诱压力下仍保持同类修持边界。

## 6｜反向测试

若出现以下结构，则不能判 pressure-display：

```text
压力前：没有可独立识别的同一原则
压力后：才第一次形成“不婚/不为女色所动”标准
```

这会落入徐庶式 temporal-backfill 护栏。

或：

```text
压力解除后
唐僧仍真实接受女王婚配并长期退出西行
```

则应检查 lifecycle / 原原则退出，而不能写“复位”。

原著不符合这两种反向。

## 7｜最近邻排除

- `zn vs 身份`：和尚身份不是判据；判据来自压力前原则表达、奖励冲突排序与解压后复位。
- `zn vs nx`：取经使命有外部任务来源邻近，但本轮不靠“别人命令他取经”锁 `zn`，而靠婚配/收益冲突中他仍不把最终归向让渡出去。
- `zn vs xn`：假意应婚、倒换关文是“怎么脱身”的策略骨架，不等于“为什么最终不能留下成婚”。
- `pressure-display vs lifecycle`：压力解除后同一原则按同一边界复位，故不判旧 `zn` 退出。
- `x`：本轮不增加 `x`；关文、王位、婚姻关系均不在本轮作为唐僧现实掌握对象取证。
