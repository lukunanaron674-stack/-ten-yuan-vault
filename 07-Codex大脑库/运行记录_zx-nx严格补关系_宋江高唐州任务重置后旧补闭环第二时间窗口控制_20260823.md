# 运行记录｜宋江高唐州｜从“严格补闭环”改归 nx 当前窗口关闭

## 保留的有效观察

高唐州阶段：

- 宋江救柴进/破高唐方向仍在；
- 高廉妖法形成现实瓶颈；
- 公孙胜专属能力 + 罗真人许可为真实外部 `nx` 接口；
- 该接口补掉宋江当前推进缺口，`nx→zx` 单向补成立。

任务完成后：

- 高廉死亡；
- 高唐州攻入；
- 柴进获救；
- 梁山返回并进入呼延灼连环马新问题；
- 公孙胜关系仍在，但旧“破高廉”接口不再是新瓶颈的当前必经门。

因此继续锁：

> **关系连续 ≠ 瓶颈连续。旧 nx 当前执行窗口可以因为任务完成/瓶颈消失而关闭。**

## 撤回的标签

旧记录把初始阶段当作“严格 zx↔nx 补”，并把后续称为“严格补闭环”。

2026-08-26 新双向拿掉门重审后，初始阶段只通过 `nx→zx`，没有证明 `zx→nx` 打到 nx 自身核心功能。因此：

```yaml
strict_zx_nx_complement_in_initial_window: false
one_way_complement: nx_to_zx
```

所以后续只应称为：

> **单向补完成后的 nx 当前窗口关闭 / 任务瓶颈重置。**

不能继续计入“严格补时间窗口”控制数量。

本记录不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
