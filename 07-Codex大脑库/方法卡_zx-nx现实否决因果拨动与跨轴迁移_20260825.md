# 方法卡｜zx↔nx 现实否决因果拨动与跨轴迁移

## 0｜本卡用途

本卡只把已经形成的 P4“名义权限 vs 现实否决权”压缩成可重复执行的方法，不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。

核心不是看“谁职位高”“谁名义上批准”，而是观察同一结果在外部节点拒绝与放行之间是否发生可重复的因果切换。

## 1｜最强可观察结构：拒绝停住 / 放行恢复

高质量 nx 权限证据优先寻找：

```text
主体请求同一权限 / 资源 / 放行
→ 外部节点在结果生效前明确拒绝
→ 同一结果真实停止、延迟或被迫重配
→ 主体没有稳定绕过该节点
→ 外部节点后来放行 / 修改许可
→ 同一结果恢复可执行
```

把它记为“现实否决因果拨动”。

它比“上级存在”“所有者存在”“主体尊重某人”强得多，因为前者直接观察到了外部接口对同一结果的现实控制力。

## 2｜本轮新增正向控制：公孙胜二仙山

《水浒传》第53回：

```text
公孙胜想下山赴高唐州
→ 明言“未敢擅便”，向罗真人禀问
→ 罗真人第一次拒绝
→ 公孙胜没有自行离山，原下山链停止
→ 再次请求
→ 罗真人改为放行并授法
→ 公孙胜才正式拜辞下山
```

因此在“当前能否离开二仙山”这个窄对象层：

- 外部许可真实存在；
- 事前拒绝真实卡住同一结果；
- 主体没有稳定绕过；
- 放行后结果恢复；
- `nx` 高纯成立；
- 同层 `zx` 排除。

事实置信 99，分类置信 98，状态 `evidence-locked`。

这条材料不增加 P4 独立作品计数，因为《水浒传》已经在该 pending-review 的跨作品支持中存在；它的价值是把方法从“现实能否说不”进一步压成可观察的因果拨动。

## 3｜最小反向对照：曹操 / 献帝

近期《三国演义》曹操—献帝文学复验提供反向结构：

```text
献帝名义最高
→ 献帝在结果生效前明确反对 / 求情
→ 曹操可以直接拒绝
→ 同一处分结果照常生效
```

所以：

```text
名义最高 + 明确说“不”
但“不”无法阻止 / 修改 / 延迟结果
≠ 高质量 nx 权限证据
```

与公孙胜同框后，最小差异只剩：

```text
“不”是否真的让同一结果停下来？
```

## 4｜现实否决六问

在原五问基础上，加入“放行恢复”验证：

1. 谁名义上拥有权限？
2. 谁能在结果生效前真实说“不”？
3. 这个“不”能否阻止、修改或延迟同一结果？
4. 被否决后主体是否必须等待、重配、再次请求或换通道？
5. 主体能否绕过该节点并稳定让同一结果生效？
6. 若同一外部节点后来放行，原结果是否随之恢复可执行？

第 6 问不是所有案例都必须具备，但一旦出现，会显著增强“该外部节点确实控制当前接口”的因果证据。

## 5｜强弱分档候选

当前只作方法层工作分档，不改核心定义：

### A档｜完整因果拨动

```text
拒绝
→ 同一结果停住
→ 放行
→ 同一结果恢复
```

最强 nx 权限证据。

### B档｜有效否决但未观察恢复

```text
拒绝
→ 同一结果停止 / 被迫换通道
```

仍是强 nx 权限证据，但缺少同节点重新放行的反向恢复验证。

### C档｜仅修改 / 延迟

外部节点能修改条件、资源量、时间或执行方式，但不能完全禁止结果。需按对象层判断其掌握的是“最终结果否决”还是“局部配置接口”，不能机械升级成整体 nx。

### D档｜仅建议 / 名义反对

外部节点表达意见、反对、求情或事后不满，但结果无需等待其许可即可稳定生效。不能仅凭身份或反对动作锁 nx，优先转查 `x/zx/xn`。

## 6｜拿掉与反向测试模板

### 拿掉真实否决

若去掉外部节点的现实否决能力后，主体仍能稳定、低成本、无需等价外部接口地实现同一结果，则 nx 权限证据显著下降。

### 反向恢复

若同一节点从“拒绝”改成“放行”后，结果立即从不可执行转为可执行，说明该节点对当前对象层存在真实因果控制。

### 绕过测试

若主体被拒后可以稳定改走完全内部路线实现同一结果，则需要重新检查 `x/xn/zx`，不能仅凭最初一次请求永久保留 nx。

## 7｜对象层护栏

现实否决必须和被测结果同层。

```text
只能否决局部执行方式
≠ 能否决整体任务

只能限制资源量
≠ 能否决最终方向

只能延迟时间
≠ 自动拥有最终处分权
```

因此探春抄检类“局部拒绝成功”不能倒灌成“整个上位处分接口失效”；反过来，局部真实否决也不应被更高层非 nx 结论覆盖。

## 8｜与 zx / x / xn 的最近邻

```text
nx：关键外部节点的事前否决真实有效，主体承认并沿接口续接。
x：该权限已经稳定进入主体可直接处分边界。
xn：主体自己重组步骤、人员、资源、节点和流程。
zx：主体把决定边界推进原本不属于自己的对象域，并使原秩序被迫响应。
```

“被上级拒绝”“违令”“很强硬”“最终成功”都不能替代上述硬判据。

## 9｜跨轴迁移模板

“现实否决因果拨动”可以迁移，但只测试**边界是否真实有效**，不替代其他四轴自己的端点定义。

### 火轴 `zn ↔ x`

测试名义所有者 / 归属者是否真的能阻止对象被主体纳入处分边界。若拒绝能让归属结果停住、放行后才恢复，说明归属边界是真实的。

### 土轴 `n ↔ x并z`

测试名义入口 / 边界控制者是否真的能阻止对象跨越内外。拒绝停住、放行恢复，可验证空间边界是否现实有效。

### 金轴 `xn ↔ z`

测试名义最高裁定者是否真的能在流程落地前终止或改写最终裁定。若下级方案再完整也必须等待其放行，说明最高裁定点真实存在。

### 水轴 `xz ↔ nz`

测试名义上的回返 / 恢复许可是否真正控制现实回返。若拒绝使回返路径关闭、放行后恢复，说明回返空间不是纸面存在。

## 10｜下一步高价值边界

P4 的“名义权限 vs 现实否决”最小正反对照已经基本成形，下一步不再优先堆同型上级案例，而应测试**否决强度阈值**：

1. 完全否决 vs 只能延迟；
2. 完全否决 vs 只能修改执行方式；
3. 单一节点否决 vs 存在等价外部替代节点；
4. 一次有效否决 vs 长期稳定可绕过；
5. 局部资源否决 vs 整体结果否决。

同时木轴总体优先级仍保持：

```text
P2：高成本纯内部绕行第三独立作品
P3：第三因素冻结跨作品复验
P4：现实否决强度阈值
```
