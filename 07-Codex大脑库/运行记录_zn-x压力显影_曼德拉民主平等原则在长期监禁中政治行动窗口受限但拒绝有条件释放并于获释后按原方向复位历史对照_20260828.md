# zn-x 压力显影｜曼德拉长期监禁历史对照

## 1｜本轮问题

只测试一个问题：

> 一个已经独立成立的 `zn`，在外部压力长期压缩其公开政治行动窗口时，是否会因此被误判为已经退出？

本轮不把历史人物整体贴成十元标签，不增加 `x`、`zn+x` 或 strict 统计。

## 2｜被测 zn

将原则压窄为：

> 追求一个民主、自由、非种族支配、具有平等机会的社会；个人自由不能以放弃集体反种族隔离目标为交换条件。

### 压力前独立成立

1964 年 Rivonia Trial 中，Mandela 已公开把民主、自由、反对白人和黑人支配、平等机会写成愿意承担死亡代价的理想。这里发生在长期监禁之前，不能由 1990 年后的声望倒填。

## 3｜压力窗口

长期监禁真实压缩了：

- 自由移动；
- 公开组织政治行动；
- 正常群众动员；
- 公开领导 ANC 的现实行动窗口。

但最关键的反证是：1985 年等有条件释放方案出现时，他拒绝用个人自由交换对集体解放原则的实质让渡。

因此压力窗口更准确写成：

```text
zn future-guidance = retained
public political action window = heavily constrained
personal-liberty tradeoff test = principle retained
```

而不是：

```text
zn = erased
```

## 4｜解压后复位

1990-02-11 获释后，Mandela 立即重新进入公开政治行动：继续反种族隔离、推动非种族民主，并进入结束白人少数统治的正式谈判进程。

所以时间链为：

```text
1964 原原则已成立
→ 长期监禁压缩公开行动窗口
→ 有条件释放压力测试中拒绝以原则换个人自由
→ 1990 获释
→ 同一民主 / 平等 / 反种族支配方向重新进入公开政治行动
```

这满足 pressure-display 的核心时间同一性门：压力前原则先成立，压力中未来指导资格未被删除，行动窗口恢复后原方向重新高显影。

## 5｜拿掉测试

拿掉 1990 年后的诺贝尔奖、总统身份、国际赞誉：

- 1964 原原则仍成立；
- 监禁期拒绝有条件释放仍可证明原则未以个人自由换出。

因此后来的外部承认不是本轮 `zn` 的支柱。

拿掉监禁压力：

- 就不会出现“公开行动窗口被长期压缩”的 pressure-display 测试；
- 但原则本身仍可成立。

## 6｜反向测试

若历史结构是：

```text
压力前原则并未独立成立
→ 压力后才形成新的民主 / 平等原则
```

则应归入原则形成 / lifecycle，不得时间倒填成 pressure-display。

若获释后在同类冲突中原原则明确不再返回，而新的稳定排序接管，则应归 lifecycle exit / replacement。

本例均不符合这些反向结构。

## 7｜最近邻排除

- `zn vs z`：后来的国际认可与总统身份不是原则成立来源；最硬证据早于这些认可。
- `zn vs xn`：谈判、组织、动员方式回答“怎么实现”，不回答“什么目标不可用个人自由换掉”。
- pressure-display vs lifecycle：本例原原则跨压力保持，并在释放后继续公开指导行动，不能写成原则退出后再生。
- stable-character-essence：不锁，只锁本轮可命名原则和时间窗口。

## 8｜第三因素冻结

冻结：

- 后世英雄化；
- 诺贝尔和平奖；
- 总统身份；
- 对 ANC 全部策略的道德评价；
- 具体武装 / 谈判策略变化。

只保留：

```text
压力前原则是否已成立？
监禁是否真实压缩公开行动？
原则是否在高代价交换中仍保留排序资格？
压力解除后是否按同一核心方向重新进入公开行动？
```

结论不变。

## 9｜与现有火轴 pressure-display 的关系

现有正向文学控制：

1. 《三国演义》关羽：归刘行动窗口被现实条件封住，条件解除后旧义按原硬门复位。
2. 《西游记》唐僧：女儿国压力迫使表面策略性应婚，脱网后原修持 / 西行方向复位。

本例新增的是历史对照：

3. Mandela：长期监禁压缩公开政治行动窗口，但原则通过有条件释放交换测试，并在获释后重新公开高显影。

本例不冒充“第三部文学作品”，因此不自动建立 pressure-display pending-review；它只增强同一判据的跨媒介 / 历史稳健性。

现有反向护栏继续有效：徐庶案例证明压力后才明确形成的新原则不得倒填为压力前已存在。

### 本轮新增纪律

> **长期无法公开实施 ≠ `zn` 被删除。**

并且：

> **pressure-display 不要求压力中完全沉默；只要关键现实行动窗口被真实压缩，而同一原则仍能通过高代价交换测试，并在解压后按原核心方向恢复公开指导，就可支持“表达受阻 ≠ 原则退场”。**
