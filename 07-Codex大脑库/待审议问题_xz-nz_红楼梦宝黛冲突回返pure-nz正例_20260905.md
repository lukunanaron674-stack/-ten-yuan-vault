# xz ↔ nz 水轴待审议问题｜《红楼梦》宝黛冲突回返 pure nz 正例

## 0｜current canonical

只服从 latest L1 v1.6：

```text
水＝阳水 xz ↔ 阴水 nz
主题领域＝命运
广义变量＝可逆性与对象特异回返空间
xz：持续收窄
nz：保存、恢复或重建
```

本文件是 L4 研究层，不修改 L1/L2、信息卡、准度卡、正式关系卡。木轴与火轴仅迁移验证方法，不迁移结论。

## 1｜本轮研究问题

四大名著第一优先样本池中，能否找到一份不靠“爱情很深”“青梅竹马”“命中注定”等题材词，而由现实冲突后的双向回返与修复直接证明 current stable `nz` 的高纯正例？

本轮只测试 `nz`；不因宝黛恋爱主题、悲剧结局或金玉良缘等后续信息倒推 `xz`。

## 2｜剧情事实

### trigger

第二十九回，宝玉与黛玉因“好姻缘”等话题及彼此误解发生严重口角。宝玉砸通灵玉，黛玉剪玉穗，二人哭泣、分开，之后一日未见面。

### actor / relation

贾宝玉 ↔ 林黛玉。

### action

第三十回，双方分开后均出现后悔与失落。宝玉主动到潇湘馆请求重新接近；黛玉起初不许开门，之后实际让宝玉进入。宝玉直接要求不要彼此不理、不要因外人介入而变得生分；黛玉虽然仍哭、仍责怪，但继续回应，递手帕，并与宝玉恢复近距离互动。凤姐到场时直接判断二人已经自行和好，并将二人一同带到贾母处。

### object

宝玉↔黛玉这一对象特异关系本身，在冲突与暂时分离后是否仍保有现实、双方可调用的回返与修复位置。

### object_layer

关系层的 reentry eligibility / repair capacity / credible return-position；不测试婚配制度、家族裁定、财产、身份或后续死亡结局。

### changed_variable

```text
原本亲近关系
→ 严重口角与砸玉/剪穗
→ 暂时不见面、双方后悔
→ 宝玉现实上门请求重接
→ 黛玉起初拒门但没有永久取消关系资格
→ 实际开门、进入、相互回应
→ 递帕、拉手、继续说话
→ 外部观察者确认二人已自行和好
→ 共同关系恢复接近
```

### observable_result

冲突没有把关系变成单方怀念，也没有把回返资格归零。分离后出现真实 reentry attempt、现实接纳、双方回应与修复后的共同节奏恢复。

## 3｜current nz 独立门

1. **对象特异：强通过。** 被测的是宝玉↔黛玉，不是任意亲近者。
2. **真实共同关系：强通过。** 冲突前已有长期、重复相互回应；第二十九回本身也明确二人“求近之心”。
3. **自由性：通过。** 本次重接不是职位、资源扣留、生存威胁或强制留置导致；宝玉主动上门，黛玉可拒绝、可回应。
4. **现实回返：强通过。** 分开后宝玉实际返回潇湘馆，请求重接，最终被现实放入并继续互动。
5. **修复性：强通过。** 黛玉仍表达不满，但关系从“不见面/哭泣”恢复到直接交谈、递帕、拉手、共同回到贾母处。
6. **双方性：通过。** 不是宝玉单方面“我还爱她”；黛玉虽然先拒门和哭泣，但实际回应、递帕并恢复共同接近。

因此：

```text
current_nz = true
maturity = evidence-locked
```

## 4｜current xz 独立门

本窗口不成立 current `xz`。

- 没有明确未来终点先取得结构地位；
- 没有多个现实关系路径持续被关闭；
- 没有不同选择反复汇流到同一不可逃终点；
- 反而现实证据显示冲突后存在可调用回返通道，并成功完成修复。

“金玉良缘”话题、嫉妒、悲剧预感、后续婚姻结局都不能事后倒灌成本窗口已经成立的 `xz`。

```text
current_xz = false
strict_xz_nz = false
```

## 5｜same current window / same object layer

窗口固定为：

```text
第二十九回严重口角
→ 砸玉/剪穗
→ 一日未见、双方后悔
→ 第三十回宝玉现实上门
→ 黛玉起初拒门
→ 实际允许进入与回应
→ 递帕/拉手/继续交谈
→ 恢复共同接近
```

对象层始终是宝玉↔黛玉关系的“是否仍可回来、回来后是否能修复”，不混入未来婚配制度。

## 6｜nearest-neighbor

### `z`
“开门/不许开门”“去不去贾母处”是局部裁定节点，但不能解释冲突后双方持续保留的对象特异回返资格与修复能力。

### `x`
若一方通过禁止退出、扣留资源、强迫对方留下形成“关系不断”，应优先检查 `x`；本例相反，双方都具有拒绝、离开、重新靠近的现实自由。

### `n`
照顾、陪伴、递帕可以有承载成分，但 `n` 解释“接住对象”，不能替代“冲突后仍可回返并修复”的关系变量。

### `nx`
宝玉上门这一单次行为可具有沿既有关系通道重新接近的行动色彩，但 `nx` 不足以解释为什么这条对象特异通道在冲突后仍然有效。

## 7｜removal test

拿掉：

- 爱情题材；
- 青梅竹马；
- 金玉良缘；
- 宝玉摔玉的戏剧性；
- 黛玉哭泣与身体反应；
- 后续悲剧结局。

只保留：

```text
对象特异关系真实成立
＋ 严重冲突
＋ 暂时分离
＋ 双方均未把关系永久撤销
＋ 一方现实请求重入
＋ 另一方现实回应
＋ 冲突后恢复接近
```

stable `nz` 仍成立。

## 8｜reverse test

若改写为：

- 宝玉上门后黛玉永久拒绝任何接触；
- 双方只有单方回忆，没有现实 reentry；
- 回来只是家族命令、资源强迫或身份义务；
- 重新见面只能恢复表面称谓，无法重新接近；

则 stable `nz` 应显著下降。

## 9｜third-factor freeze

冻结以下因素后结论不变：

- 贾母希望二人和好；
- 凤姐来“说和”；
- 宝钗在场；
- 金玉良缘议题；
- 宝黛未来婚姻是否可能；
- 作品最终悲剧走向。

尤其凤姐到场前，宝黛已经自行完成现实重接；第三方最多确认/推动场面结束，不是 `nz` 的主要生成原因。

## 11｜本轮锁定的新边界

> **stable nz 不要求分离很久，也不要求正式“离队/复归”。只要对象特异关系先真实成立，发生足够真实的冲突与暂时断开后，双方仍保留自由、现实可调用的回返资格，并能完成修复与重新接近，就可以形成高纯修复型 nz。**

同时锁定负护栏：

> **“感情很深 / 很舍不得 / 哭得很厉害 / 注定是一对” ≠ nz。真正证据是冲突后的 bilateral reentry + repair。**

## 12｜与现有水轴资产的最小差异

- 相比 Hiccup↔Toothless：本例不是长期物理分离后的归宿型回返，而是同一关系内部的冲突修复型回返；
- 相比《西游记》孙悟空被逐 guard：孙悟空案例用于证明“某一接口关闭≠完整 return-space 归零”；本例直接提供双方现实重入成功，因此是 positive control，不是 false-transition guard；
- 相比《三国演义》关羽麦城：关羽样本锁 `xz` 的 option-set contraction；本例锁 `nz` 的 relation repair，changed_variable 与 object layer 均不同。

下一轮最高价值缺口：优先寻找四大名著内 **同人物 + 同 current window + same object layer 的 `xz=true` 与 `nz=true` 共现**，再做 removal/reverse 判断是否仍 non-strict；若没有足够干净样本，不降低 95 门槛强行锁定。
