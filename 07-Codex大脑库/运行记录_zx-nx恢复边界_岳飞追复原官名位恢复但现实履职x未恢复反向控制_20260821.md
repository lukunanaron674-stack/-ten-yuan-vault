# 运行记录｜岳飞追复元官：名位恢复但现实履职 x 未恢复

## 0｜本轮目的

当前待审议提出灰区：

> “正式复任/复官”是否必然等于旧 `x` 现实恢复？

本轮复用仓库已经锁定的岳飞 C1 材料，但更换被测试对象层：不再问“旧官方处分是否被追溯纠正”，而是问“追复元官是否恢复了岳飞生前可实际调用的军政职位 `x`”。

## 1｜史料事实

岳飞绍兴十一年已经死亡。绍兴三十二年七月，宋孝宗下诏追复岳飞元官，以礼改葬，访求其后并录用；追复告词恢复少保、武胜定国军节度使、武昌郡开国公等旧官方名位。

因此两个对象必须拆开：

```text
对象A｜法律/官方名位与记录
旧处分后被追溯纠正
→ 追复元官
→ 官方状态恢复

对象B｜活体实际军政调用能力
岳飞已经死亡
→ 不可能重新统军、签署、调度、处分人员或履行职务
→ 现实 operational x 没有恢复
```

## 2｜zx 判断

`zx_in_restoration_stage: rejected_as_primary`

追复影响很大，但没有发生岳飞自身权能公开扩张。岳飞无法在本阶段行动，更不存在其决定范围超过生前旧基线。

所以：

> 名位被追复 ≠ 岳飞 zx。

同时也不能把宋孝宗的最高既有追复权限重复收成 zx；那是另一个主体、另一个对象层。

## 3｜nx 判断

`subject_nx_channel_activation_in_restoration_stage: rejected`

这是本轮重要反向限制。

现行 nx 要求主体在当前对象层实际沿外部方向、权限或解决通道推进。岳飞已经死亡，不可能主动请求、承接、等待批准或实际续接追复通道。

因此：

> “外部权限替某人恢复名位”不能自动写成“这个人使用了 nx 恢复接口”。

这里可以说：

- 追复决定来源在外部皇权；
- 官方名位状态被外部最高权限改写；

但不能把岳飞本人锁成当前 `nx` 行为/关系功能。

## 4｜x 判断：必须分对象层

### 4.1 官方名位/法律状态层

`official_status_restored: evidence-locked`

追复元官直接恢复了官方名位、政治记录与法律身份对象层。仓库既有 C1 案已经锁定这一层。

### 4.2 现实履职/军政调用层

`operational_command_x_restored: rejected_impossible_due_to_death`

`x` 若指对象、资源、职位权限可由主体稳定实际调用，那么岳飞死后不可能重新：

- 统率军队；
- 调度人员；
- 使用军政印信；
- 执行职务处分；
- 承担现实岗位运行。

所以“追复元官”只能证明名位对象层恢复，不能证明活体 operational x 恢复。

## 5｜最近邻排除

### x vs 名位状态

官名、爵位、官方记录可以是被恢复的法律/身份对象，但不等于实际调用权同步恢复。

### nx vs 外部替主体改状态

外部节点拥有决定权，不等于被改变状态的人自己正在使用 nx。仍须检查主体有没有实际续接通道。

### zx vs 追复

恢复到旧名位甚至追加荣誉，都不能替代“主体自身决定范围扩大”的证据。

## 6｜拿掉测试

### 拿掉“追复元官”

官方名位恢复不成立。

### 拿掉岳飞死亡事实

如果被恢复者仍在世，并在复任后重新获得人员、资源、签署权和实际职位调用，那么才可能进一步锁 `x` 现实恢复，并检查 nx 复任入口。

### 拿掉实际履职证据要求

若只凭“复官”两个字就锁 operational x，便会把死者追复、荣誉恢复和现实在岗复权混为一层。

## 7｜反向测试

真正的 `nx → operational x 恢复` 应满足：

```text
旧职位x真实退出
→ 外部正式权限重新开放同一职位
→ 主体实际承接该入口
→ 人员/资源/签署权/调用接口重新到位
→ 主体恢复实际履职
```

海瑞、李纲属于这一侧。

岳飞本例则是：

```text
旧官方状态被追溯纠正
→ 名位恢复
→ 但主体已死亡
→ 现实履职接口不可能恢复
```

## 8｜第三因素冻结

冻结：岳飞忠奸评价、冤案道德判断、追谥武穆、后世封王、民族英雄评价、宋金政治环境。

只看：

1. 恢复的对象是什么；
2. 主体是否仍能实际调用；
3. 外部接口是否由主体本人真实续接。

结论不变。

## 9｜本轮结论

事实置信：99
分类置信：98

最窄结论：

> **“复官/追复元官”首先只证明官方名位/法律状态发生恢复；要锁现实 `x` 恢复，还必须看到主体重新取得并实际使用同一职位的人员、资源、签署、处分或调用接口。**

同时：

> **外部节点替主体改变状态，不自动等于主体当前激活 `nx`；`nx` 仍要求主体在对象层真实沿该外部通道续接。**

## 10｜理论正本处理

本轮不得修改：

- L1；
- zx/nx 信息卡；
- zx/nx 准度卡；
- zx补nx_补卡。

仅作为现有“nx 外部接口恢复旧 x 与 zx 扩权边界”待审议的反向控制。
