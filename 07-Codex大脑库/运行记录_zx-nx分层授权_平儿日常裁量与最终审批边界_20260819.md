# 运行记录｜平儿：日常/方案裁量 ≠ 完整独立处分 x

## 0｜本轮目的

反打近期“上级存在但局部 x 仍可成立”的正向控制，检查另一侧：

> 主体在日常运行中可以持续调查、暂缓、重设方案，看起来具有较强局部裁量；但真正触及最终处分冲突时，更高权限节点仍能拒绝、修改或不放行。此时能否把日常裁量直接升级成完整局部 `x`？

结论：不能。必须按对象层拆开。

## 1｜剧情事实、触发、对象、动作、结果

凤姐先对柳家母女下达严厉处分。平儿发现五儿申辩与物证来源存在疑点后，没有机械执行，而是暂缓、复查袭人/芳官等来源、整理牵连关系，并形成“缩小追查、避免扩大牵连、从轻放人”的替代方案。

但平儿没有单方面宣布原处分失效。她明确说要再回凤姐；形成替代方案后也再次回报。凤姐起初并非自动同意，仍主张继续严查、逼供和革退；平儿继续劝说后，凤姐最终才批准放手，平儿随后正式放人结案。

结果链：

```text
凤姐原处分
→ 平儿暂缓/复查
→ 平儿重设方案
→ 回凤姐审批
→ 凤姐先坚持原方向
→ 平儿继续说服
→ 凤姐批准
→ 新方案正式生效
```

## 2｜zx 检查

排除为主判。

平儿的意见最终被采纳，不等于她取得了新的家内最高处分范围。没有证据显示此后同等级案件可绕开凤姐，由平儿独立裁决；也没有出现贾府秩序围绕新增“平儿最终处分接口”重排。

```text
zx_in_narrow_stage: rejected_as_primary
```

## 3｜nx 检查

在“最终让新方案覆盖旧处分”这一对象层，`nx` 成立。

平儿拥有自己的判断与方案，所以不是纯 nx 本体；但关键批准接口仍在凤姐。尤其凤姐第一次听取新方案后仍能明确拒绝其方向、继续主张严查，证明这不是装饰性审批。

```text
nx_final_approval_relation_position: evidence-locked
```

## 4｜x / xn 最近邻排除

`xn` 高显影：平儿自己组织调查、暂缓、责任叙事和替代结案路径。

但“能自己设计怎么处理”不等于“有权让处理结果最终生效”。因此：

```text
xn：方案如何重设
nx：方案能否正式生效仍须外部批准
x：只有该对象层决定可无需逐项回上级而直接生效时才高锁
```

本轮新增纪律：

> **持续日常裁量 / 方案裁量，只能证明运行层自主度；不能单独证明最终处分接口已进入主体稳定 `x` 边界。冲突/否决窗口的证据权重高于普通运行自由度。**

## 5｜拿掉测试

- 拿掉“平儿贤惠、善良”等评价，结构不变。
- 拿掉平儿的方案重设，只剩照令执行，则 `xn` 下降，最终审批层 `nx` 仍可更强。
- 拿掉凤姐最终批准：若凤姐坚持原处分，平儿当前替代方案不能按既有权限结构正式结案，说明外部审批是真实接口。
- 拿掉凤姐的真实否决能力，改成所有方案都自动批准，则当前 `nx` 最硬证据显著下降，应重新检查局部 `x`。

## 6｜反向测试

### 反向成局部 x

```text
平儿发现问题
→ 自行调查并重设
→ 无需回凤姐
→ 可直接撤销/减免/结案
→ 结果立即生效
```

则该最终处分对象层优先锁 `x`。

### 反向成 zx

若平儿原本无这块最终处分权，却通过本案公开取得更高裁决范围，并让贾府以后承认其新增接口，才进一步检查 `zx`。

### 反向成更纯 nx

若平儿连调查与方案重设都没有，只机械执行凤姐原处分，则运行层也更偏 `nx`。

## 7｜第三因素冻结

冻结人物性格、主仆身份、柳五儿是否无辜、宝玉揽责、赵姨娘/探春牵连、案件道德评价。只保留：

```text
谁能重设方案？
谁能让方案最终生效？
冲突时谁能说“不”？
是否必须回更高权限节点？
```

结论不变。

## 8｜与近期正向控制的最小差异

诸葛亮斩马谡：更高君主仍在，但军法处分无需逐项回报，求情不能改变，处分直接生效 → 强冲突型局部 `x`。

弼马温 / 呼延灼：上级仍在，但日常/战役内部持续直接调用 → 中强度局部 `x` 证据。

平儿：运行与方案层自主很强，但最终处分冲突仍必须回凤姐，而且凤姐真实使用过拒绝/修改能力 → **运行自主不能覆盖最终审批 `nx`**。

因此证据等级进一步压实为：

```text
冲突后可独立生效
> 持续明确直接调用
> 普通执行/方案裁量
> 单纯职位、头衔、名位
```
