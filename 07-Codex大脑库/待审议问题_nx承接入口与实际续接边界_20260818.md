# 待审议问题｜nx：承接入口与实际续接边界

## 1｜问题

当前 nx 研究中，容易出现一种假阳性：

```text
别人给任务/命令
→ 主体口头接受
→ 主体进入流程
→ 直接判 nx
```

但连续三部作品显示，**承接入口**与**实际续接**必须分开。

需要审议：

> `nx` 行为功能是否应明确要求：在真正执行/结果窗口，主体仍沿外部方向把该对象层实际推进；若主体只在入口处口头接受、形式进入流程，随后主动否决、改掉、停掉或伪造完成结果，则不能以入口服从覆盖后续实际不续接。

## 2｜三作品证据

### 《三国演义》关羽华容道

关羽接受诸葛亮军令、立军令状并赴华容道，但曹操真正到达时，关羽实际放行并承担违令后果。

边界：

> **明确命令 + 明确接受 + 高惩罚，不足以证明最终执行层 nx。**

### 《水浒传》朱仝私放雷横

朱仝接受押解任务并进入司法流程，却在关键结果窗口主动开枷放雷横、故意延迟追赶。

边界：

> **程序续接外观不能覆盖最终结果否决。**

### 《西游记》猪八戒平顶山巡山

八戒明确选择并接受巡山任务，也实际进山；但第一次执行过程中主动停止、睡觉，并准备谎报已巡山。

边界：

> **口头承接与进入路径，只能证明入口层；实际执行层仍须重新判。**

## 3｜正向控制

### 孙悟空被逐

孙悟空不同意唐僧判断，也反复申辩，但唐僧正式解除关系后，悟空最终接贬书、拜别并离开。

这说明：

> **心理不同意不打掉 nx；实际结果是否续接才关键。**

### 赵云长坂坡

刘备给出“保护老小”的上位任务；赵云途中高度自主搜索、折返、突围，但最终仍把阿斗交还刘备。

这说明：

> **局部自主不打掉上位终点 nx，只要同一对象层的终点仍实际完成。**

## 4｜候选纪律

目前只作为 pending-review，候选写法：

> **nx 的入口承接与实际续接应分层判断。**
>
> - 口头接受、领命、进入流程：只能证明“承接入口”存在；
> - 真正执行/结果窗口仍沿外部方向推进：才是高质量 nx 行为功能证据；
> - 若主体在关键窗口主动否决、停掉、改写或伪造结果，则该对象层 nx 应下降或排除；
> - 心理反对、局部抱怨、局部执行自由度本身不构成反证，必须看到实际方向是否被改写。

## 5｜与 xn 的边界

若主体不沿外部方案，但主动另建流程、节点、时间或资源配置，应转查 `xn`。

但“单纯逃避、偷懒、撒谎”也不能为了排除 nx 就自动判 xn；只有存在足够结构化的运行组织时，xn 才能成为主判。

因此：

```text
口头承接 + 原样完成
→ nx 上升

口头承接 + 局部自主 + 终点不变
→ 上位 nx 可保留，局部查 xn

口头承接 + 关键执行/结果被主动改写
→ 同对象层 nx 下降/排除

主动重建关键运行结构
→ 进一步查 xn
```

## 6｜与 zx 的边界

违令、停工、放人、撒谎、改变结果，都不是 zx 的充分条件。

仍须独立满足：

```text
自身权能公开进入现实
→ 他者/秩序围绕主体重新反应
→ 主体决定范围或作用位置真实上升
```

因此关羽、朱仝、猪八戒三例都不能因“不听命”自动判 zx。

## 7｜待继续验证

下一步优先找反例，而不是第四个同型：

1. 主体口头拒绝任务，但最后实际仍按外部方向完成，是否仍可锁 nx；
2. 主体先中断任务，后在没有额外强迫的情况下主动恢复并完成，如何切阶段；
3. 主体只改中间方法但不改终点时，哪些层级保留 nx、哪些层级转查 xn；
4. 承接入口本身是否应只作为弱证据，不单独进入稳定人物本体推断。
