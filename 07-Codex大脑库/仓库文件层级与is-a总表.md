# 仓库文件层级与 is-a 总表

> 本表只治理文件身份、读取顺序与覆盖关系，不替代或改写三元、十元理论内容。三元与十元并行，不建立父子派生。

## 关系词

- `parent / child`：文件层级上的直接上下位。
- `implements`：落实上位协议。
- `explains`：解释上位文件，不覆盖它。
- `supplements`：补充但不替代。
- `supersedes / covered-by`：明确覆盖。
- `conflicts-with`：存在未解决冲突。
- `example-of`：案例验证。
- `index-of`：索引入口。
