## 5. 源端点、目标端点与变量

### 源端点 nx

必须同时存在：

1. 主体原本拥有可认领的决定、否决或替代路线；
2. 并非法律、职位或能力上根本无权；
3. 没有持续受到威胁或强迫；
4. 跨多个阶段默认由他者决定；
5. 即使可以取回位置，也继续不认领。

### 目标端点 x

必须出现实际掌握增长：

- 原本共同决定的事项改由一方单独决定；
- 账户、资源、时间或对外接口集中；
- 新增调用权、否决权或排除权；
- 临时代办变成事实上的长期掌握；
- 外部成员开始只把该主体视为决定接口。

### 被改变变量

- 决定权归属；
- 最终否决权；
- 资源与时间调配权；
- 对外口径控制；
- 原共同边界被纳入单方掌握的程度。

## 6. 候选机制

### 候选A：空位吸纳

```text
nx主体持续不认领本可拥有的决定位置
→ 关系中形成稳定方向空位
→ 已有局部x的他者为维持行动反复代决
→ 临时代管成为默认控制
→ x的掌握边界扩大
```

理论后果：若成立，只能先锁在关系层；`x` 不是凭空生成，而是既有掌握边界吸纳空出的范围。

### 候选B：默认授权累积

```text
每次具体事项都默认由对方处理
→ 单次默认授权反复出现
→ 信息与外部接口逐渐集中
→ 他者获得事实上的长期调用和否决权
→ x上升
```

理论后果：必须证明授权已改变事实控制；若仍可随时撤回、双方共同查账和共同否决，只是分工或 `xn`。

### 竞争解释C：主动占位压退nx

```text
甲持续要求、决定、施压和占位
→ 乙选择空间下降
→ 甲同时掌握更多
```

理论后果：直接关系更接近 `zx/x` 压位或旧 `z克nx` 竞争解释，x增长可能只是并发现象，不能证明 `nx生x`。

### 竞争解释D：职位或制度直接赋权

```text
职位、法律或组织规则本已把权限给甲
→ 甲掌握更多
→ 乙按结构服从
```

此时 x 的来源是职位、产权或制度，不是 nx。

## 7. 正例候选

### 7.1 《穿普拉达的女王》安迪与米兰达｜中段工作关系

- nx候选：安迪逐步不再认领私人时间、任务边界和拒绝位置；
- x候选：米兰达对其日程、通讯、任务优先级和私人生活的控制扩大；
- 支持点：控制范围确实从办公室扩展至全天候生活；
- 未通过点：米兰达持续主动提出要求，职位x与公开压位过强。拿掉主动施压，扩张未必发生。

结论：复合候选，不足以锁定。

### 7.2 《长日将尽》史蒂文斯与达林顿勋爵｜管家生涯阶段

- nx候选：史蒂文斯不把私人判断、感情与生活方向置于最终决定位置；
- x候选：主人意志进入他的时间、劳动、公开表达和人生路径；
- 支持点：大量让位并非每次由直接威胁触发；
- 未通过点：管家职位、阶级制度和职业 `xn` 已经预设服务范围，难证明新增掌握主要由 nx 空位生成。

结论：复合候选，不足以锁定。

### 7.3 成年子女长期由父母代决｜结构候选

成年子女依法拥有账户、居住、职业与机构沟通权，却长期不查账、不提出路线、不联系机构，所有决定都要求父母代办。父母最初仅协助，随后掌握账户、材料、日程、住房与对外沟通，外部机构也只向父母请求决定。

该结构最支持候选A/B，但缺少可核验的具体人物文本，不能满足至少两个具体案例的正式门槛。

## 8. 反例

1. 老板一次委托负责人代管项目：只是临时授权。
2. 家长威胁子女交出密码：启动源是强制、`zx` 或 `x` 自扩张。
3. 员工职位本来没有预算权：不存在可让出的决定位置。
4. 伴侣按专业分工负责财务，双方随时可查账并共同否决：只是分工或 `xn`。
5. 主体主动赠与财产：可能来自 `zn`、`nz`、交易或法律安排。
6. 公司制度赋予负责人审批权：x来自制度授权。
7. 乙持续沉默，但甲没有新增调用或否决权：只有nx显影。
8. 甲控制增长时乙持续强烈反抗：源端点不是nx。
9. 外部机构依法要求监护人代理：权限来源不是主体让位。
10. 一方短期生病由另一方代办：当前状态，不构成跨阶段掌握扩张。

## 9. 最近邻排除

### 与主动压位

- 本候选：拿掉甲主动要求后，乙持续空位仍推动事实集中；
- 主动压位：甲的要求、威胁或职位权力本身推动控制增长。

### 与 xn 组织

- `xn` 解决信息、流程和时间怎样持续运行；
- `x` 解决谁拥有最终调用、调配与否决权。

信息集中不等于归属集中。

### 与一次授权

- 一次授权有明确范围、期限和撤回接口；
- 候选关系要求默认授权跨阶段累积，并改变事实掌握。

### 与反向 x 生 nx

控制者扩大掌握后，确实可能使另一方更沿其安排推进。但这解释的是 `x→nx`，不能证明 nx 是 x 增长的启动源。

## 10. 拿掉测试

1. 拿掉nx主体的持续空位，若x仍凭职位、产权或威胁扩大，关系不成立。
2. 拿掉x主体的主动施压，若事实控制仍因反复代办而增加，才支持候选。
3. 拿掉职位、法律与既有产权后，掌握增长仍须存在。
4. 拿掉信息集中，只观察最终调用和否决权；若未变化，不构成x。
5. 恢复nx主体的自主决定、查账、否决和外部联系后，x边界应明显回缩。
6. 若代理权始终可即时撤回且从未改变外部接口，只是临时分工。

两个具体作品候选仍未通过全部测试。

## 11. 反向测试

```text
nx生x：
持续空出的决定位置
→ 他者既有掌握边界吸纳该空位

x生nx：
掌握边界先扩大
→ 另一方可用方向和否决位置缩小
→ 更沿控制者安排推进
```

两条方向均可在同一关系中形成反馈，因此必须逐阶段记录“谁先变化、直接变量是什么”。现有作品案例更容易证明后者或双向反馈，而不是纯 `nx生x`。

## 12. 动态链后果

若候选成立，改变的是：

> 关系中的方向空位，是否逐渐被他者转化为事实掌握边界。

它不机械生成强势人格、所有权、权力欲、永久服从或正确管理。也不能把“一个人懒得决定”写成“另一个人自动拥有一切”，理论箭头不是过户大厅。

## 13. 三元与十元并行

三元继续独立核验作品整体精神运动。

十元本轮只核验：

- nx主体是否拥有但持续不认领决定位置；
- x主体的调用、否决与掌握边界是否真实增加；
- 是否由职位、制度、产权、强制或主动压位启动；
- 关系方向是否可与反向反馈区分。

不把因果主题与本体主题写成父子派生。
