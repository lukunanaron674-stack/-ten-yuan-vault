# 运行记录｜孙悟空：弼马温 A1 → 齐天大圣 A2｜同一天庭等级域内部扩权第二控制

## 0｜本轮目的

上一轮《三国演义》曹丕“魏王/丞相 A1 → 皇帝最高主权 A2”已经给出首个高纯控制：`zx` 不一定需要跨进一个全新的对象域 B；在同一宏观对象域内部，只要现实决定范围从 A1 推到原本不属于主体的 A2，并公开、稳定生效，同样可以形成 `zx`。

本轮专门寻找第二份独立作品控制，而且优先四大名著。孙悟空第四回恰好提供极干净的同域等级跃迁：

```text
A1 = 天庭正式授予的弼马温低位身份/职务
A2 = 天庭原先不承认、后来被迫正式授录的齐天大圣高位身份
```

只分析第四回这一连续阶段，不由此给孙悟空整个人物重新贴稳定十元标签。

---

## 1｜剧情事实

### 1.1 A1：弼马温已经是真实既有位置

玉帝通过天庭官职体系任命孙悟空为弼马温，并送其到御马监上任。孙悟空到任后真实管理御马监人员、事务与天马。

因此：

```text
天庭授职入口
→ 孙悟空真实承接
= nx 上位授权入口

授权完成后
→ 御马监局部职务权限真实可调用
= A1 局部 x
```

A1 并不是空名号。仓库已有《西游记_孙悟空任弼马温_zx-nx分层授权压力测试_20260816.md》以 99/97 锁定“上位 nx + 局部 x + 非 zx”。

### 1.2 触发：孙悟空发现 A1 的等级极低

孙悟空得知弼马温“未入流”后，明确拒绝继续承接该低位职务，打出御马监、反下天宫。

这一动作首先只能证明：

```text
当前弼马温职务 nx 退出
```

不能仅凭“不干了”自动判 `zx`。

### 1.3 A2：齐天大圣不是原本已有权限

回到花果山后，独角鬼王提出“齐天大圣”称号。孙悟空接受，并命四健将制作“齐天大圣”旌旗、公开传播该新身份。

此时 A2 仍只是主体自行提出的新等级要求，天庭并未承认。

### 1.4 天庭真实反对 A2

玉帝得知孙悟空反下天宫后，并未直接承认“齐天大圣”，而是派托塔李天王、哪吒等天兵下界擒拿。

孙悟空公开迎战，并明确要求把“齐天大圣”这个官衔回报玉帝：若不遂其心，还要继续打上灵霄宝殿。

因此原等级秩序对 A2 存在真实反对，不是形式盖章。

### 1.5 A2 后来正式进入天庭公开等级秩序

天兵不能压回孙悟空后，太白金星提出招安、授录“齐天大圣”。玉帝准奏，正式宣孙悟空为齐天大圣，并为其建齐天大圣府，配置二司与仙吏。

所以最终发生的不是：

```text
孙悟空自己在山里喊个称号
```

而是：

```text
原天庭等级系统不承认 A2
→ 公开出兵压回
→ 无法恢复原结果
→ A2 最终被正式写入天庭等级与组织安排
= A2 稳定现实化
```

## 2｜zx 判断

`zx_same_domain_A1_to_A2_expansion: evidence-locked`

本例的关键不是“孙悟空能打”，而是五项同时成立：

1. A1 已经真实存在：弼马温职务与御马监局部权限；
2. A2 与 A1 属于同一宏观对象域：天庭公开身份、官位与等级位置；
3. A2 原本不属于孙悟空，也不被天庭承认；
4. 孙悟空公开把自身身份/等级要求推进到 A2，天庭真实出兵反对；
5. 天庭无法把其压回 A1，最终正式授录齐天大圣并建立相应府署。

因此：

> **`zx` 不要求一定跨对象域。**
> **在同一对象域内部，只要主体把现实决定/凌驾位置从旧 A1 推到原本不属于自己的 A2，并迫使外部秩序重新响应且 A2 稳定成立，同样可以形成 zx。**

这里的 `zx` 增量不是“从御马监管理更多马”，而是同一天庭等级体系中，主体公开把自己的等级位置推过旧上限。

---

## 3｜x 判断

A1 应继续解释为既有 `x`：

```text
弼马温职位已经正式授予
→ 御马监局部人员、事务、天马可被其日常调用
= x
```

不能因为后续齐天大圣出现，就把此前每次御马监管理动作倒写成 `zx`。

本轮真正的 `zx` 发生在：

```text
A1 已经成立
→ A2 原本不属于主体
→ A2 被主体公开推进并迫使旧等级秩序响应
→ A2 最终正式现实化
```

---

## 4｜nx 判断

### 4.1 前段授权入口：nx 成立

弼马温不是孙悟空自己合法任命给自己的职位。玉帝/天庭官职体系是真实授权入口，孙悟空先接受并到任，所以：

`nx_prior_heavenly_office_entry: evidence-locked`

### 4.2 A2 扩张窗口：nx 排除为主判

“齐天大圣”并不是天庭先给出、孙悟空沿既有晋升通道申请获得。

真实链是：

```text
主体先自行提出 A2
→ 天庭先拒绝并出兵
→ 主体公开维持 A2 要求
→ 原秩序无法压回
→ 天庭后来才正式授录
```

因此不能把最后“玉帝授录”倒写成：

```text
A2 的最终方向本来由玉帝生成
→ 孙悟空只是沿许可通道获得
= nx
```

更准确的是：天庭后来的正式授录，是对主体已经公开压入现实的 A2 所作的制度响应与吸纳。

所以：

`nx_in_qitian_expansion_window: rejected_as_primary`

## 5｜xn 最近邻

孙悟空确实做了：

- 立旗；
- 传各洞妖王；
- 组织花果山兵力；
- 与天兵连续作战；
- 接受太白金星再次招安。

这些有运行组织与阶段推进，可以有 `xn` 邻近。

但本轮主变量不是：

> 齐天大圣如何一步步被组织出来？

而是：

> 同一天庭等级对象域里，主体公开等级位置是否从 A1 推到了 A2？

所以 `xn` 次级，`zx` 主判。

## 6｜关键压力

本轮关键压力不是“官小受辱”这一情绪，而是：

```text
同一天庭等级/官位对象域
A1 已经属于主体
A2 原本明确不属于主体
→ 原等级系统真实拒绝 A2
→ 主体公开维持并推进 A2
→ 原系统无法压回
→ A2 最终正式进入现实秩序
```

这直接压力测试“同域内部是否也能出现 zx”。

## 7｜拿掉测试

### 7.1 拿掉 A1 弼马温

如果孙悟空此前没有任何天庭官职，直接自号齐天大圣并最终迫使天庭承认，仍可能锁 `zx`，但本轮将失去“同域 A1→A2”的控制价值。

### 7.2 拿掉天庭最初反对

如果玉帝一开始就主动、自愿授予齐天大圣，并拥有真实可使用的自由否决权，那么结构会明显转向：

```text
nx 授权入口
→ 新 A2 x
```

而不是当前高纯 `zx`。

### 7.3 拿掉正式授录

如果孙悟空只是花果山内部自称“齐天大圣”，天庭始终不承认、原等级秩序也未发生有效改变，则最多是身份宣称/扩位尝试，不能高纯锁 A2 已稳定进入现实等级结构。

### 7.4 拿掉战斗胜负

只保留：

```text
旧系统不承认 A2
→ 主体公开提出并维持
→ 外部系统被迫重新处理
→ A2 最终进入正式等级秩序
```

`zx` 仍成立。

因此“能打赢哪吒”不是十元判据。

```text
→ 原系统无法压回
→ A2 最终稳定进入同一等级秩序
= zx
```

本例属于第三种。

## 9｜最近邻排除

### zx vs x

```text
x：我已经是弼马温，我在弼马温职掌里用权。
zx：我把公开等级位置从弼马温旧上限推进到此前不属于我的齐天大圣 A2。
```

### zx vs nx

最后由玉帝“授录”不能单独证明 A2 是 nx，因为真正方向并非天庭先给，且天庭曾真实反对、试图压回。

### zx vs xn

立旗、组织、作战是运行过程；等级位置是否扩大才是本轮主变量。

### zx vs 强弱/胜负

如果天庭最终仍把孙悟空压回弼马温或完全否定 A2，即使他打赢若干天将，也不能锁 A2 已稳定形成。

## 10｜第三因素冻结

以下全部冻结，不参与主判：

- 孙悟空神通强弱；
- 官阶羞辱感；
- 独角鬼王是否最先提出“齐天大圣”四字；

- 后续蟠桃园、大闹天宫与五行山；

只检查：

```text
A1 是否已存在？
A2 是否属于同一对象域？
A2 是否原本不属于主体？
原系统是否真实反对？
主体是否公开推进 A2？
A2 是否最终稳定进入现实秩序？
```

六项均成立，分类保持 98%。

```text
A1 = 魏王/丞相等既有政治处分
A2 = 皇帝最高主权
同一国家政治统治域内部
→ A1 到 A2
```

```text
A1 = 弼马温既有天庭身份/局部职务
```

> **zx 的增量单位不是“有没有换领域”，而是“现实决定/凌驾范围有没有超过旧 x 上限”。**

当前只有 2 个独立高纯材料，不达到“新建独立待审议问题”的三作品门槛。本轮只新增运行记录，不修改 L1、zx/nx 信息卡、准度卡、`zx补nx_补卡`，也不空涨任何 pending-review 版本。
