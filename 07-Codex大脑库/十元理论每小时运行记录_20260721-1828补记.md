## 源端点、目标端点与变量

### 源端点 z

必须明确：

1. 谁认可；
2. 认可谁；
3. 认可的是判断、能力还是选择；
4. 该认可位置为何重要；
5. 认可是否真正落到主体自身。

普通命令、强势表达、职位放权、公众注意、结果成功和资源许可不能替代 `z`。

### 目标端点 nx

被改变变量：

- 对方向决定位置的认领强度；
- 对外部安排的唯一依赖度；
- 是否提出替代方向；
- 是否保留否决权；
- 是否仍只能沿他者权限或关系通道推进。

### 成立阶段

```text
主体原本在一个具体关系或阶段中不占方向位置
→ 重要认可主体确认其自身判断或能力足以成立
→ 外部安排不再是唯一合法方向
→ 主体提出、选择并承担自己的路线
→ nx下降
```

### 关系体量与显影条件

- 低体量：一个具体选择上取回否决权；
- 中体量：在一段关系中持续提出并承担自己的方向；
- 高体量：稳定人物结构改变，本轮无证据支持。

显影条件：认可后必须出现实际方向权变化，不能只有情绪振奋、成绩变好或继续追逐认可。

## 候选机制

### 候选A：判断资格确认

```text
重要认可主体确认“你的判断可以成立”
→ 主体不再把外部方向视为唯一合法方向
→ 开始提出并承担自己的路线
→ nx下降
```

理论后果：`z` 只克制局部关系中的方向依赖，不克制关系网络本身。

### 候选B：能力资格确认

```text
主体此前因不确定自身能力而沿别人安排
→ 重要认可主体确认其有能力承担选择后果
→ 主体取回否决与决定位置
→ nx下降
```

理论后果：若认可只让主体更努力执行原安排，则只是表现增强，不构成克制。

### 竞争解释C：认可只给既有自主性盖章

```text
主体原本已有自己的方向
→ 认可提供支持、许可、资源或现实通道
→ 主体方向更容易实现
```

此时目标 `nx` 原本不存在，或真正改变变量的是 `x` 的权限转移、`n` 的承载、`xn` 的训练结构，而不是 `z克nx`。

## 正例候选

### 1. 《死亡诗社》托德与基廷｜课堂即兴诗阶段

- z：基廷确认托德具有自己的诗性声音，不只是沉默者或标准答案执行者。
- nx候选：托德从不占表达与判断位置，转为说出自己的语言。
- 可观察结果：主体第一次承担自己的表达，而非复述课堂标准。
- 第三因素：基廷同时提供强引导、教学结构、情绪推动和安全容器，混入 `xn`、`zx`、`n`。
- 拿掉结果：拿掉基廷的强引导后，无法确认仅靠“认可”仍会发生同等方向变化。

结论：支持候选A，但未通过纯度门槛。

### 2. 《国王的演讲》乔治六世与莱昂内尔｜战时广播前后

- z候选：莱昂内尔持续确认乔治具有自己的声音、判断和完成公开表达的能力。
- nx候选：乔治逐步不再只沿王室礼仪、医生权威和他人替代安排，开始主动决定训练与讲话方式。
- 可观察结果：从被治疗、被安排的位置，转为主动使用自己的声音承担广播。
- 第三因素：长期训练 `xn`、王位职责 `zx/x`、国家危机 `xz`、朋友式承载 `n/nz` 均很强。
- 拿掉结果：拿掉训练和职位责任后，认可是否足以独立降低 `nx` 无法证明。

结论：复合候选，不足以锁定。

### 3. 独立研究方向结构例

学生长期只按导师给题。导师明确确认：“你的判断足以独立决定研究方向。”导师随后不再提供题目和资源倾斜，学生仍自行提出、否决并承担路线。

该结构较纯，但缺少第二个可核验人物文本，不能单独越过95%。

## 最近邻排除

### 与 zx 或 x 压位

旧“持续表达、决定和占位”会使他者更退后，方向上甚至可能增加 `nx`，不能叫现行 `z克nx`。

### 与 x 放权

若主体能决定，是因为职位、许可、资源和最终否决权被移交，变化来自 `x` 边界，而非一句认可。

### 与 xn 训练

长期训练使主体能够独立完成，改变的是能力与运行结构；`z` 只能负责确认该能力获得关系资格。

### 与 zn 克 nx

若主体因“这件事无论如何都是对的”而拒绝跟随，启动源是内部意义 `zn`，不依赖认可。

## 拿掉测试

1. 拿掉认可，只保留放权或资源，主体仍取回方向，则不依赖 `z`。
2. 拿掉权限转移，只有认可，主体仍持续决定，才支持直接作用。
3. 拿掉训练结构后，主体若无法承担选择，认可可能只是一句鼓励。
4. 拿掉安全承载后，主体仍在逆风中保持方向，纯度更高。
5. 拿掉主体原有自主判断，认可后仍只等对方给路线，则目标端点不存在。
6. 认可停止以后主体仍保持方向，纯度高于继续追逐认可。
7. 只观察否决权、替代方案和决定承担，不用情绪高涨代替变量。

两个具体作品候选都未通过全部测试。
