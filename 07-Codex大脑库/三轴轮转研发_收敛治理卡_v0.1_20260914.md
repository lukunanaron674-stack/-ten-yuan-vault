# 三轴轮转研发｜收敛治理卡 v0.1

## 0｜目的

三轴已经进入高成熟阶段。此后轮转的默认目标不再是“主动发明新边界”，而是：

```text
真实自然语言/真实运行记录
→ 固定字段 IR
→ 既有 guard 压力测试
→ nearest-neighbor / removal / reverse / freeze-third-factor
→ 只有旧 guard 被真实击穿，才新增研究卡
```

本卡只治理 L4 research 工作流，不修改 L1/L2 canonical、十元信息卡、准度卡、正式关系卡或 behavior evidence 正本。

---

## 1｜轮转优先级

每轮只推进 1 条轴。

优先顺序：

1. 最新解释器 E2E / 回归存在真实 failure 的轴；
2. 存在未闭合高风险 pending 的轴；
3. 最近最久未推进的非成熟轴；
4. 若都无明显优先级，按 水 → 金 → 土 循环。

附加限制：

```text
禁止连续两轮无理由重复同一轴。
```

如果某轴被标记 `AXIS_MATURE_CANDIDATE=true`，且最近一轮候选缺口被既有 guard 完整解释，则降低一档优先级。

---

## 2｜成熟轴的默认工作模式

当轴成熟度 >= 9.95 / 10 时，默认进入：

```text
REGRESSION_FIRST_MODE
```

禁止把“还能想出一个新例子”视为信息增益。

本模式下，一轮必须先回答：

```yaml
failure_source:
  real_regression: true|false
  real_natural_language_misclassification: true|false
  old_guard_incomplete: true|false
  old_guard_directly_covers_case: true|false
```

只有下面任一条件成立，才允许新提交：

```text
A. 新机制
B. 新边界
C. 新 guard
D. 新正反控制类别
E. 新真实状态迁移
F. 旧 guard 无法解释的有效失败证据
G. canonical / 旧研究冲突形成新的 sync debt
```

其余情况：

```text
NO_INFORMATION_GAIN
→ no commit
```

---

## 3｜无提交不是失败

若完整跑完以下方法后，结果被既有 guard 完整解释：

```text
nearest-neighbor
removal
reverse
freeze-third-factor
positive control
negative control
```

则输出：

```yaml
round_result: CLOSED_BY_EXISTING_GUARD
commit: none
maturity_change: 0
```

这被视为“收敛证据”，不是空转。

连续出现 2 次 `CLOSED_BY_EXISTING_GUARD`，且该轴核心 pending 已闭合：

```text
AXIS_MATURE_CANDIDATE = true
rotation_priority -= 1
```

连续出现 3 次：

```text
AXIS_REGRESSION_ONLY = true
```

之后除非解释器真实 failure / 新 corpus 失败命中，否则不主动为该轴创造研究题目。

每轮必须包含：


不得因某轴“看起来用不到”就删除字段；允许字段值为 `not_material_to_this_test`，但必须显式写出。

## 5｜三轴高风险误判入口

### 水轴 xz ↔ nz

优先测试：

```text
对象身份迁移
同 scope 双 PASS
周期回返 vs 最后宽限
多 actor 回返证据聚合
当前残余 nz vs future xz
```

若新例子只是在“最后机会/还有路/改名后回来”等既有结构上换题材，不立新卡。

### 金轴 xn ↔ z

优先测试：

```text
decision_right / execution_right 混淆
条件状态下最终裁定
参与集合被顺序/提前停止塑形
授权撤销 vs 当前个案接管
名义多人流程 vs 实际最终中心
```

若只是把“主席/批准/签字/排序”换成新职业，不立新卡。

### 土轴 n ↔ x并z

优先测试：

```text
tested object 锚定错误
parent / child 证据回填
capability role vs runtime instance
passive residence vs sustained load
双向箭头未 SPLIT_IR
```

若只是“平台/空间/组织/队列”名词替换，不立新卡。
