# 运行记录｜宋江高唐州：梁山军已属 x，而公孙胜／罗真人才是真 nx 外部接口

## 0｜结论

本轮锁定第三份跨作品“伪局部 nx”反向控制：

> 宋江在高唐州大量使用梁山头领、士兵和既有军力，并不因此新增局部 nx。作为梁山主帅，常规军队与军令接口已经处于其当前稳定调用边界，属于局部 x；具体派兵、进退、寻找解决节点等组织方式可有 xn 邻近。真正的 nx 只出现在宋江当前无法稳定调用的外部专属接口：公孙胜的法术能力以及罗真人对其离山与授法的真实许可。

最小结构：

```text
救柴进／破高唐的公开方向
= zx 当前方向端

梁山既有军队、头领、主帅军令
= 宋江局部 x

派兵、拔寨、寻找节点、重新组织推进
= xn 邻近

公孙胜专属法术 + 罗真人真实许可
= nx
```

## 1｜剧情事实

1. 宋江率梁山军救柴进、攻高唐州，梁山军已由其公开调度。
2. 高廉妖法使常规梁山军多次受挫，普通军力无法稳定穿透当前瓶颈。
3. 吴用判断需寻公孙胜，宋江派戴宗、李逵前往寻找。
4. 公孙胜不能自行立即离山，明确需要禀问罗真人。
5. 罗真人先真实拒绝，后才允许公孙胜下山并授予可破高廉的正法。
6. 公孙胜返回后负责专属破法；宋江继续作为主帅传令拔寨、组织全军推进，最终高唐州被攻入、柴进获救。

## 2｜为什么梁山军不是新的局部 nx

表面上宋江“用了很多别人”：吴用、戴宗、李逵、各头领、普通士兵都在替整场行动执行。

但 nx 不按人数判定，而按当前关键权限/资源是否仍外置判定。

梁山常规兵力与主帅军令在该阶段已经属于宋江可直接调用的既有对象域：

```text
宋江下令
→ 梁山军执行
```

不需要每次重新经过另一个外部许可节点，故优先是局部 x，而不是新增 nx。

若把“有部下执行”本身判 nx，会产生重复计数：同一块已经进入主体 x 的组织资源，每次被调用都被重新登记成外部依赖。

## 3｜真正的 nx 在哪里

公孙胜／罗真人层不同。

关键能力与许可并不在宋江原有稳定处分边界内：

- 宋江无法自行生成公孙胜的专属破法能力；
- 公孙胜是否能离山又受罗真人真实控制；
- 罗真人确实先拒绝，证明许可节点不是装饰；
- 宋江只能通过寻找、请求、放行与授法链条取得该解决条件。

因此：

```text
普通梁山军力 = x
外部专属法术／师门许可 = nx
```

同一桥段里同时存在二者，正好构成局部最小差异。

## 4｜zx 判定

本轮不以“宋江是首领”直接判 zx。已有正式案例已锁定：宋江自己占据救柴进、破高唐的公开军事方向，并在取得外部破解条件后继续把梁山力量压入高唐州现实，因此当前方向／推进端可有 zx 高显影。

但“梁山士兵听令”本身只是已有军令 x 的调用，不应重复算 zx，也不应改写成 nx。

## 5｜xn 最近邻

吴用提出寻找公孙胜、戴宗李逵执行寻找、宋江安排拔寨与军队推进，都可有 xn 运行组织邻近。

最短区分：

```text
谁拥有并可直接调用常规兵力？
→ 宋江，x

谁在组织怎么找人、怎么推进？
→ 宋江／吴用等，xn 邻近

为什么必须经过公孙胜／罗真人？
→ 关键能力与许可在外部，nx
```

## 6｜拿掉测试

### 6.1 拿掉“梁山军是局部 nx”这一假设

事实链仍可完整解释：

```text
宋江已有梁山军令 x
+
自行组织推进 xn
+
遇到专属妖法缺口后接入公孙胜／罗真人 nx
```

没有出现新的普通兵力外部许可缺口，所以“梁山军参与 = nx”不是必要解释。

### 6.2 拿掉宋江对梁山军的既有 x

若宋江每调一队兵都必须重新向另一个独立权限节点申请、等待批准，普通军力层才会重新向 nx 上升。

原案例不是。

### 6.3 拿掉公孙胜／罗真人 nx

高廉妖法造成的专属能力缺口重新出现，说明这一层才是真实外部 nx。

## 7｜反向测试

真正局部 nx：

```text
关键兵力／资源／许可仍在另一节点
→ 宋江不能稳定自行调用
→ 必须重新请求、借用或等待批准
→ 结果才能继续
= nx
```

伪局部 nx：

```text
人员／军力已经属于主体稳定 x
→ 主体直接调度
→ 自己组织行动节点 xn
= 不新增 nx
```

## 8｜第三因素冻结

冻结高廉强弱、妖法奇观、宋江首领身份评价、战役胜负、吴用智谋以及公孙胜人物主题。

只检查：

1. 当前普通军力是否已归宋江直接调用？是。
2. 普通军力每次调用是否仍需新的外部许可？否。
3. 当前行动结构是否存在主体自行组织？是，xn 邻近。
4. 公孙胜／罗真人能力与许可是否仍真实外置？是。
5. 主体是否必须经过该外部接口才能取得专属破解条件？是。

结论保持 99/98。

## 9｜与前两部作品的跨作品同型

- 《红楼梦》探春：授权入口 nx → 园中日常管理已成 x → 自己重构人员资源责任为 xn；不能因使用婆子和贾府资源新增 nx。
- 《三国演义》马谡：守街亭上位任务 nx → 已授主将兵力为 x → 山上屯军与分兵结构由自己 xn 重设；不能因部下执行新增 nx。
- 《水浒传》宋江：梁山常规军队与军令为 x → 组织推进有 xn 邻近；真正 nx 仅在公孙胜／罗真人外部专属能力与许可。

因此跨三作品支持：

> **“有人参与 / 部下执行 / 使用组织资源”不是 nx 的充分证据。若资源与权限已经进入主体稳定 x 调用边界，且主体自行组织运行，则不得重复计局部 nx。真正 nx 必须有当前仍外置、主体无法稳定自行调用且必须经过的关键接口。**
