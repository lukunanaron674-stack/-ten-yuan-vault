# 定义的规则

## 问题

Copi 的 6 条定义规则（种差+属、非循环、不过宽、不过窄、不含混、非否定）是否适用于三根基和六派生？

## 回答

**部分适用。** 三根基和六派生的定义应尽量满足这些规则，但有些规则需要根据体系特点调整。

### 检查结果

| 规则 | 适用性 | 说明 |
|:----|:------|:-----|
| 规则1（种差+属） | ✅ 适用 | 每个十元应有属（它是哪类）+ 种差（它和同类其他概念的区别） |
| 规则2（非循环） | ✅ 适用 | "Z=执念，执念=Z" 这种循环要避免 |
| 规则3（不过宽） | ✅ 适用 | 外延不能宽到"什么都能装"——R6保障了这一点 |
| 规则4（不过窄） | ⚠️ 暂不考虑 | 如果发现遗漏可补充，但目前尚未发现 |
| 规则5（不含混） | ✅ 适用 | 不能用"暗流"这种含混日常词作为定义的核心 |
| 规则6（非否定） | ⚠️ 有例外 | 有时用"不是什么"来划边界是有帮助的，但不应用"不是X也不是Z"作为唯一的定义方式 |

### 当前定义状态

| 十元 | 规则1（种差+属） | 规则2（非循环） | 规则3（不过宽） | 规则5（不含混） |
|:----|:----------------|:---------------|:---------------|:---------------|
| X | ✅ 属：认知模式；种差：小边界 | ✅ | ✅ 3条核心属性锚定 | ✅ |
| N | ✅ 属：认知模式；种差：大边界 | ✅ | ✅ 3条核心属性锚定 | ✅ |
| Z | ✅ 属：驱动力；种差：自我确认 | ✅ | ✅ 4条核心属性锚定 | ✅ |
| ZX | ✅ 属：Z的派生；种差：指向X | ✅ | ✅ | ✅ |
| ZN | ✅ 属：Z的派生；种差：指向N | ✅ | ✅ | ✅ |
| XZ | ✅ 属：X的派生；种差：指向Z | ✅ | ✅ | ✅ |
| XN | ✅ 属：X的派生；种差：指向N | ✅ | ✅ | ✅ |
| NZ | ✅ 属：N的派生；种差：指向Z | ✅ | ✅ | ✅ |
| NX | ✅ 属：N的派生；种差：指向X | ✅ | ✅ | ✅ |

## 规则

> **规则 R7（种差+属）**：每个十元的定义必须包含"属"（属于哪一类）和"种差"（与同类中其他概念的区别）。
>
> **规则 R8（来源锚定）**：派生十元的定义必须明确其来源根基和指向方向——不能脱离"X指向N"这类结构来单独定义xn。
>
> **规则 R9（反例保留）**：如果某个十元的定义找不到反例（"什么情况下这个十元明显不适用"），说明定义可能过宽，需要收紧。
