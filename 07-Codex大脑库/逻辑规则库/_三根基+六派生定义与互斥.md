# 三根基 + 六派生 · 完整定义与互斥边界

## ⚠️ 重要区分

本表涉及**两种不同性质的"互斥"**：

1. **定义互斥（概念层）**：A 的定义不能包含 B 的成分——X ≠ N ≠ Z。这是保障概念干净的逻辑红线。
2. **RGB轮盘共存（运作层）**：三根基可以在同一个人身上以任意比例共存——一个人可以同时是强Z和高N，就像红和蓝可以混合成紫色。**定义互斥不意味着不能共存。**

两者不矛盾——定义互斥管的是"概念不能混淆"，RGB共存管的是"实际分析中它们可以一起出现"。

## 三根基（根基层）

### X（小边界）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | 在具体/物质边界内运作的认知与行动模式 |
| **核心属性** | ① 关注具体而非抽象 ② 倾向于分析、切割、区分 ③ 从利己/自身利益出发 ④ 追求清晰和可控 |
| **定义上不是** | 不是N（大边界），不是Z（自我确认驱动力） |

### N（大边界）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | 扩展/消解边界的认知与行动模式 |
| **核心属性** | ① 关注整体而非局部 ② 倾向于包容、承载、接纳 ③ 从利他/归属出发 ④ 追求意义和连接 |
| **定义上不是** | 不是X（小边界），不是Z（自我确认驱动力） |

### Z（自我确认）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | 精神个体确认"我"的存在、渴望被世界看到/认可的驱动力 |
| **核心属性** | ① 向外投射自我 ② 提升能力以影响世界 ③ 不被认可则无意义 ④ 要有"我"的痕迹 |
| **定义上不是** | 不是X（小边界），不是N（大边界） |

## 六派生（派生层）

派生十元 = **一个根基指向另一个根基的方向性组合**。

### ZX（突破行动）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | Z指向X——以Z的能量（自我确认）驱动X方向（具体行动） |
| **核心属性** | ① 主动发起 ② 目标明确（要做什么）③ 向外释放能量 ④ 结果导向 |
| **定义上不是** | 不是zn（不是向内凝聚，不是信念） |

### ZN（精神信念）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | Z指向N——以Z的能量（自我确认）驱动N方向（精神归属） |
| **核心属性** | ① 内在坚守 ② 意义导向（相信什么）③ 向内凝聚能量 ④ 不需要外部验证 |
| **定义上不是** | 不是zx（不是向外行动，不是目标导向） |

### XZ（临界判断）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | X指向Z——以X的清晰分析驱动Z的判断（在边界上的"险棋"） |
| **核心属性** | ① 风险感知 ② 边界上的决策 ③ 清醒但不安全 ④ 刀口舔血 |
| **定义上不是** | 不是xn（不是秩序管理/规律维持，是险棋不是规则） |

### XN（秩序管理）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | X指向N——以X的分析能力驱动N的秩序（把范围管好） |
| **核心属性** | ① 规律/规则 ② 维持节奏和框架 ③ 可预测性 ④ 让系统持续运转 |
| **定义上不是** | 不是xz（不是临界判断，不是险棋而是规则） |

### NZ（情感链接）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | N指向Z——以N的包容承载驱动Z的情感连接（用温情锚定"我"） |
| **核心属性** | ① 依恋/柔情 ② 被动吸引 ③ 不想结束 ④ 情感沉溺 |
| **定义上不是** | 不是nx（不是客观分析，不是冷静，是情感投入） |

### NX（客观逻辑）

| 项目 | 内容 |
|:----|:-----|
| **本质定义** | N指向X——以N的承载驱动X的客观分析（在大范围看到底发生了什么） |
| **核心属性** | ① 冷静观察 ② 暗流/计算 ③ 不卷入情感 ④ 看到底牌 |
| **定义上不是** | 不是nz（不是情感链接，不是投入，是抽离分析） |

## 互斥总表

### 定义互斥（概念层干净）

| 对比 | 定义互斥？ | 依据 |
|:----|:----------|:-----|
| X vs N | ✅ 互斥 | 小边界 vs 大边界，方向相反 |
| X vs Z | ✅ 互斥 | 具体分析 vs 自我确认，完全不同类 |
| N vs Z | ✅ 互斥 | 归属包容 vs 自我投射，完全不同类 |
| zx vs zn | ✅ 互斥 | 向外行动 vs 向内信念 |
| xz vs xn | ✅ 互斥 | 临界判断 vs 秩序管理 |
| nz vs nx | ✅ 互斥 | 情感链接 vs 客观逻辑 |
| zx vs nx | ✅ 互斥 | Z根基 vs N根基的不同派生 |
| zn vs xn | ✅ 互斥 | Z根基 vs N根基的不同派生 |

### RGB轮盘共存（运作层自由组合）

| 组合 | 是否可能 | 例子 |
|:----|:--------|:-----|
| 强Z + 高X | ✅ 共存 | 一个有野心且在具体层面精于算计的人 |
| 强Z + 高N | ✅ 共存 | 一个有强烈信念且包容/号召众人的人 |
| 高X + 高N | ✅ 共存 | 一个既精通具体分析又有大格局视野的人 |
| 强Z + 高X + 高N | ✅ 共存 | 三者都强的全才型 |
| 三弱 | ✅ 共存 | 全元/原点——平衡但无突出方向 |
