# 不相容关系

## 原版概括

两个概念如果不具有包含关系且外延没有重叠，则它们处于**不相容关系**。金岳霖将其分为：
- **矛盾关系**：A 与非 A。两者既互斥又穷尽（如"活着"与"没活着"）
- **反对关系**：A 与 B，两者互斥但不穷尽（如"红色"与"蓝色"，还有第三种颜色存在）

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | "z 和 n 能同时出现在一个人身上吗？"——从根基层面，它们是不相容的；但从派生层面，zn 就是一个 Z+N 的融合产物 |
| **z（本质）** | Z/X/N 在根基层是**反对关系**（互斥但不穷尽——可能有"全元"覆盖三者之外的状态）。派生层之间（如 zx 和 nx）也是反对关系。 |
| **n（应用）** | 判断"某个人的 zx 和 nx 同时很强"——这在根基上是矛盾的（一个人不能同时以 x 为方向驱动的 z 和以 n 为方向驱动的 x），但在流程/体量模型中可以被解释为"交替主导" |

## 十元理论应用规则

> **规则 R16（根基不相容）**：在任何静态分析中，一个人不能同时属于两个不同的根基类型（Z/X/N）。
>
> **规则 R17（派生交替许可）**：在动态/流程分析中，派生十元可以交替出现（如"先 zx 后 nx"），但这不是"同时属于"而是"时序切换"。
>
> **规则 R18（矛盾关系保留）**：全元（原点）和其他十元是矛盾关系——要么在原点，要么不在。没有中间态。

## 不相容关系图

```
根基层面（反对关系）：
  Z ──→ 互斥 ──→ X
   ↓               ↓
  互斥           互斥
   ↓               ↓
  N ──→ 互斥 ──→ (全元)

派生层面（反对关系）：
  zx ↔ zn    (同根基派生，弱不相容——表现为能量的两种出口方向)
  xz ↔ xn    (同根基派生，弱不相容)
  nz ↔ nx    (同根基派生，弱不相容)
  zx ↔ nx    (不同根基派生，强不相容)
  zn ↔ xn    (不同根基派生，强不相容)
  zx ↔ nz    (介于之间——Z根基 vs N根基，强不相容)
```
