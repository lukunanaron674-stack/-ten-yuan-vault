# 映射与复合（外部图 vs 内部图）

## 原版概括

Lawvere 在 Session 1 中建立了范畴论的三个基本操作：

1. **映射（map/morphism）**：f: A → B，从集合 A 到集合 B 的对应规则
2. **复合（composition）**：f: A → B 且 g: B → C，则 g∘f: A → C
3. **恒等映射（identity map）**：每个对象 A 都有 id_A: A → A，满足 id∘f = f 且 f∘id = f

**关键区分：外部图 vs 内部图**
- **外部图**（external diagram）：用一个点代表一个集合，一个箭头代表一个映射——你"从外面"看结构
- **内部图**（internal diagram）：展开集合的具体元素，显示每个元素被映射到哪个元素——你"从里面"看

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | 在十元分析中，"外部图"视角看到的是"nz 生 nx"这个箭头；"内部图"视角要展开"nz的具体哪些能量流向了nx的哪些具体表现" |
| **z（本质）** | 外部图用于理论层面的关系推演（生克链）、内部图用于具体人格分析（这个人的nz中的"依恋"具体流向了他行为中的哪一部分） |
| **n（应用）** | 在理论讨论中明确标注你是在画"外部图"还是"内部图"——避免把结构层次的讨论和内容层次的讨论混在一起 |

## 规则

> **规则 R46（视角标注）**：每次画十元关系图时，必须标注是"外部图（概念层）"还是"内部图（实例层）"。

## 示例

```
外部图（概念层）：
  nz ──生──→ nx
  ↑这个箭头不需要展开nz里有什么，只需要知道关系存在

内部图（实例层）：
  nz = {依恋, 不舍, 柔情, 被动吸引}
  nx = {计算, 分析, 观察, 评估}
  映射 f: nz → nx
   依恋 → 计算（"因为依恋，所以开始计算得失"）
   不舍 → 评估（"因为不舍，所以评估还有多少时间"）
```
