# 积（×）、和（+）与分配律

## 原版概括

**积（Product）** A × B：从A和B到"第三方"的通用构造。在Set中 = 笛卡尔积（有序对）。
- 投影箭头 π₁: A×B → A, π₂: A×B → B
- 通用性质：对任意有箭头到A和B的X，存在唯一箭头 X → A×B

**和/余积（Sum/Coproduct）** A + B：从"第三方"到A和B的通用构造。在Set中 = 不交并（disjoint union）。
- 注入箭头 ι₁: A → A+B, ι₂: B → A+B
- 通用性质：对任意A和B有箭头进入的X，存在唯一箭头 A+B → X

**分配律（Distributive Law）**：A × (B + C) ≅ (A × B) + (A × C)
- 在Set中成立，但不是所有范畴都成立（这是"让范畴变为分配范畴"的条件）

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | zx（Z主X从）这个结构：既不是Z×X（积——两个人格同时存在平行），也不是Z+X（和——要么Z要么X二选一），而是**Z主导的X方向箭头** |
| **z（本质）** | 你的主从结构（如zx）可能对应范畴论中的**合成箭头（composite arrow）** 而非积或和。但方向性（Z→X）和标签（"x方向驱动的z"）让你有定义新运算的自由。 |
| **n（应用）** | 分配律在你的理论中表现为：Z × (nx + nz) ≅ (Z × nx) + (Z × nz)——即Z根基与N派生组合时，先分配再组合与先组合再分配等价。这个性质保证了你的组合规则是一致的。 |

## 十元理论的分配律应用

```
分配律在十元组合中的应用：
  
  检查：Z与(N派生)的组合是否满足分配律？
  
  Z × (nz + nx)  ≅  (Z × nz) + (Z × nx)
  左边：先把nz和nx合成"N的柔情与理性"，再以Z驱动
  右边：Z分别驱动nz（=zn）和nx（=zx），然后并列
  
  如果语义上两者等价 → 你的组合规则是"分配的" ✅
  如果不等价 → 说明zn和zx不是Z×nz和Z×nx那么简单的关系
```

**结论**：十元组合的分配律性质[待二审]——这是检查你的派生系统是否自洽的一个数学工具。
