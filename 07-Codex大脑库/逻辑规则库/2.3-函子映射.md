# 函子映射

## 原版概括

**函子（functor）** F: C → D 是一个从范畴 C 到范畴 D 的结构保持映射。它必须满足：
1. 将 C 中的每个对象映射到 D 中的一个对象
2. 将 C 中的每个态射 f: A → B 映射到 D 中的一个态射 F(f): F(A) → F(B)
3. 保持恒等态射：F(id_A) = id_F(A)
4. 保持复合：F(g∘f) = F(g)∘F(f)

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | 你的五大主题中，"xn+z → 时间"——这本质上是一个函子映射：从十元范畴到抽象维度范畴 |
| **z（本质）** | "十元符号 → 抽象维度"这个跃迁不是随意的，而必须是一个**函子**：它不仅映射符号本身，还必须将十元之间的关系（生/克/补）也映射到维度之间的关系上 |
| **n（应用）** | 验证你的五大主题映射是否合法：xn+z → 时间，那么这个映射是否保持了"xn 生 nz"也被映射为"时间中的某种结构"？如果不保持，这个映射就是不合法的 |

## 十元理论应用规则

> **规则 R28（函子合法性）**：任何"十元→抽象维度"的映射（如 xn+z → 时间）必须是函子——即不仅映射符号，还映射符号之间的关系。
>
> **规则 R29（复合保持）**：如果十元 A → B → C 在十元范畴中成立（复合），那么在目标维度范畴中，F(A) → F(B) → F(C) 也必须成立。
>
> **规则 R30（不是所有映射都是函子）**：如果一个映射只映射符号不映射关系，那它就不是函子，不能用于理论论证。

## 函子映射实例验证

```
十元范畴 C（部分）：
  对象：xn, z, nz, ...
  态射：xn ─生─→ xz, z ─生─→ nz, ...

函子 F: C → 维度范畴 D：
  F(xn) = 秩序
  F(z)  = 瞬间
  F(nz) = 依恋
  F(xn ─生─→ xz) = 秩序 ─蕴含─→ 临界
  要求：如果 nz ─克─→ xn（在十元范畴中），
       则 F(nz) ─对应─→ F(xn)（在维度范畴中）也必须成立

如果"依恋"和"秩序"在维度范畴中没有对应关系，
那么 F 不是函子——这个映射不合法。
```

**结论**：五大主题映射必须经过函子合法性检查，否则只是修辞上的"很像"，不是理论上的"成立"。
