# 🧮 箭头语法规则库 — 总入口

## 定位

这是十元理论的辅助结构语法层，用于描述已经完成对象分层与十元判断的端点之间如何发生关系。

箭头语法不能替代：

```text
人物本体判断；
人物状态与行为功能判断；
场景、光影和时间关系分层；
三元独立判断；
十元端点独立判断。
```

范畴论只作为结构类比工具，不拥有反向修改三元/十元正本定义的权限。

体量的现行写法：

```text
体量 T：十元在指定对象结构中的占位规模；
显影 M：十元在当前阶段表现得多明显；
作用量 E：关系实际改变目标多少。
```

不得再写“体量就是箭头力量”。

## 当前纪律

```text
先冻结对象与层级，再画箭头；
先证明机制与目标变量，再判生克补；
关系方向与关系作用量分别记录；
体量、显影和作用量不得混写；
人物核心锚点优先稳定；
三元与十元并行，不构成父子派生。
```
