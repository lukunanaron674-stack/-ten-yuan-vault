# 🧮 箭头语法规则库 — 总入口

## 定位

这是十元理论的**高阶语法层**。逻辑规则定义了"概念是什么"，箭头语法定义"概念之间的关系怎么画"。

范畴论的核心思想：**不研究对象本身，只研究对象之间的箭头（态射/morphism）**。这对于十元理论的意义是：
- 不再问"Z 是什么"，转而问"Z → X 的箭头意味着什么"
- 不再定义"体量标尺的值是多少"，转而定义"体量 3 → 体量 7 的箭头是怎么发生的"
- 将"时空映射"（xn+z → 时间）理解为**函子（functor）**——从十元范畴到维度范畴的结构保持映射
