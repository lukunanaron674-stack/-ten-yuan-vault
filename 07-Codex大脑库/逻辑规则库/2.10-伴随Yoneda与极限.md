# 伴随（Adjunction）、Yoneda引理与极限

## 原版概括

**伴随函子（Adjunction）** F ⊣ G：F: C → D, G: D → C 是一对伴随函子，如果对任意 A ∈ C, B ∈ D，有：
Hom_D(F(A), B) ≅ Hom_C(A, G(B))
- 自由→遗忘伴随：自由群函子 ⊣ 遗忘函子（群→集合）
- 核心直觉：F做"自由构造"，G做"遗忘限制"，两者互为伴随

**Yoneda引理**：每个范畴都可以嵌入到它的"预层范畴"中。Homs云淡风轻地告诉你：**一个对象由它与其他对象的所有关系完全决定**。
- 正式：Nat(Hom(-, A), F) ≅ F(A)
- 非正式：你只要知道一个对象如何被其他所有对象"看"（映射到它），你就完全知道了这个对象

**极限与余极限**：乘积、等子、拉回（极限）和余积、余等子、推出（余极限）的统一定义——通过通用性质（universal property）

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | "全元"和"Z"之间：从全元到Z有唯一箭头（全元→Z），但反过来从Z到全元也有唯一箭头——这是一对伴随吗？ |
| **z（本质）** | **Yoneda引理**对十元理论最重要：一个十元命格不是由它的"内在本质"定义的，而是由它与其他所有十元的关系（生、克、补、主从）完全决定的。nz和nx之间的生关系，比nz"本身是什么"更能定义nz。 |
| **n（应用）** | 伴随函子可以用来建模"体量变化"和"命格转化"——比如从"正常状态的z"到"吞没状态的z"的转化，可能是一个伴随关系。 |

## 规则

> **规则 R51（Yoneda原则）**：每个十元命格由它与其他所有十元的关系网络完全定义。不存在"脱离关系的十元本质"——nz就是"它生nx、被zn生、被z克……"的关系总和。
>
> **规则 R52（伴随作为转化）**：体量跃迁（如z(3)→z(9)）如果是一个可逆过程，那么它是范畴论中的一个**同构（isomorphism）**；如果不可逆，它可能是一对**伴随**（一边自由构造，一边遗忘收敛）。

## Yoneda原则在十元中的意义

```
传统定义："nz是柔情依恋，是被动吸引"
  → 试图通过"内涵"定义nz
  → 问题是：什么叫"柔情"？这又需要另外的定义——无限回归

Yoneda式定义：nz由以下关系完全定义：
  - nz 生 nx
  - nz 被 zn 生
  - nz 被 z 克
  - nz 与 n 是根基派生关系
  - nz 中的"z方向" = "朝向外部的被动情感投射"
  - ...

→ 不需要追问"柔情是什么"——知道nz在所有生克补关系中的位置就够了
→ 这对你的原子卡片有深远影响：每个十元卡片不需要"定义段"，只需要"关系段"
```
