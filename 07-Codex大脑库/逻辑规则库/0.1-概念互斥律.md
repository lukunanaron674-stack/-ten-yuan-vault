# 概念互斥律

## 原版概括

两个概念如果外延（包含的对象集合）没有任何重合，则称它们为**互斥关系**（mutually exclusive）。
在逻辑学中，划分一个集合时，子类之间必须互斥——否则会出现**概念交叉**的谬误。

关键判定标准：
- 如果 ∃X (X ∈ A 且 X ∈ B)，则 A 和 B 不是互斥的
- 互斥不要求穷尽（两个互斥概念可以一起留出空白区域）

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | "某人的行为既是 Z（执念爆发）又是 X（理性计算）"——这种判断在概念上是否合法？ |
| **z（本质）** | Z/X/N 作为底层根基，必须是互斥的。一个人格特征如果同时属于两个根基，说明根基没有切干净。 |
| **n（应用）** | 用于审核 01-十元系统/ 中每个十元的定义边界：x vs xz、n vs nx 之间是否存在交叉 |

## 十元理论应用规则

> **规则 R1（互斥性）**：Z、X、N 三个根基词项在任何合法判断中，不能有一个实体同时属于其中两个。
>
> **规则 R2（派生词项边界）**：派生十元（zx, zn, xz, xn, nz, nx）之间的互斥性弱于根基——允许同根基派生词之间有连续性，但不同根基派生词（如 zx 与 nx）必须互斥。

## 常见违规案例

| 违规类型 | 例子 | 问题 |
|:---------|:-----|:-----|
| 根基交叉 | "这种感觉既 Z 又 N" | Z 和 N 被当成可叠加的属性而非互斥的根基 |
| 派生污染 | "zx 和 nx 都带有 x 成分所以可以同时出现" | 虽然都含 x，但主从结构不同，不能混用 |
