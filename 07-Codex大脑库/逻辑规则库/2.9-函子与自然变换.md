# 函子（Functor）与自然变换（Natural Transformation）

## 原版概括

**函子 F: C → D**：范畴之间的结构保持映射。
- 将 C 的对象映射到 D 的对象
- 将 C 的态射 f: A→B 映射到 D 的态射 F(f): F(A)→F(B)
- 保持复合：F(g∘f) = F(g)∘F(f)
- 保持恒等：F(id_A) = id_F(A)

**自然变换 η: F ⇒ G**：两个函子 F, G: C → D 之间的"箭头族"。
- 对 C 中每个对象 A，给一个 D 中的态射 η_A: F(A) → G(A)
- 自然性条件：对任何 f: A→B，η_B ∘ F(f) = G(f) ∘ η_A

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | "xn+z → 时间"——如果你把它视为一个函子 F: 十元范畴 → 抽象维度范畴，那么必须满足：十元范畴中的生克关系被映射为维度范畴中对应的关系 |
| **z（本质）** | **自然变换**更精妙：如果同时有两个"十元→维度"的映射（比如"xn+z → 时间"和"xn+z → 空间"两个函子），自然变换描述了它们之间的关系——其中一个是否可以"自然地"转化为另一个 |
| **n（应用）** | 当两个不同的分析者（或者同一个分析者在不同上下文中）对同一个十元组合做出不同的维度解释时——这两种解释之间是否存在一个"自然变换"？如果存在，它们就是同一理论的不同视角而非互相矛盾 |

## 规则

> **规则 R49（函子一致性）**：任何"十元→维度/感受"的映射必须同时映射该十元的生克关系——不能只映射符号不映射关系。
>
> **规则 R50（自然变换作为视角转换）**：同一十元组合的两种不同解释，如果它们之间存在自然变换（一种解释的结构可以保持性地转化为另一种），则两者都是合法的——它们只是不同的视角。

## 示例：十元音乐分析中的映射

```
音乐分析函子 F: 十元范畴 → 感受范畴
  
  十元范畴中的关系：             感受范畴中的对应：
  nz ─生─→ nx                 依恋感 ─生出─→ 计算感
  z  ─克─→ n                  爆点 ─克制─→ 稳定
  
  F(nz) = 依恋感
  F(nx) = 计算感
  F(nz ─生─→ nx) = 依恋感 ─生出─→ 计算感
  ✅ 函子成立

另一种分析函子 G: 十元范畴 → 音乐风格范畴
  G(nz) = R&B
  G(nx) = 电子
  G(nz ─生─→ nx) = R&B ─?─→ 电子
  ❓ 需要检查R&B和电子之间是否有对应关系——可能不是函子
```
