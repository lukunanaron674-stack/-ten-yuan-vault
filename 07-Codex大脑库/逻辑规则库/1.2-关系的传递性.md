# 关系的传递性

## 原版概括

关系逻辑中，关系的**传递性**分为三种（金岳霖 §6）：

1. **传递关系**：如果 A R B 且 B R C，则 A R C（如"大于"、"之前"）
2. **反传递关系**：如果 A R B 且 B R C，则 A 不 R C（如"父亲"——A是B的父亲，B是C的父亲，则A不是C的父亲）
3. **非传递关系**：A R B 且 B R C 时，A R C 可能成立也可能不成立（如"朋友"、"认识"）

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | "nz 生 nx，nx 生 xn"——那么"nz 生 xn"成立吗？这就是传递性的问题 |
| **z（本质）** | **"生"关系是传递的**（A生B，B生C → A生C）。这是顺时针相生链的运作基础。**"克"关系是反传递的**？需要验证。 |
| **n（应用）** | 如果"生"是传递的，那么你可以从一个十元出发，沿着生链推演出整个环。这决定了你的"二层分析"（生克链运算）的合法性 |

## 十元理论应用规则

> **规则 R13（生传递）**：A 生 B 且 B 生 C → A 生 C。允许在生链上做任意长度的推演。
>
> **规则 R14（克不传递？待验证）**：A 克 B 且 B 克 C → ？克关系是否传递，需要引入第三维度的上下文来判断（因为克往往是对称的反向，可能形成循环）。
>
> **规则 R15（补不传递）**：A 补 B 且 B 补 C → A 不必然补 C。补是一种局部调剂关系，不能链式推演。

## 生克链传递性实例

```
传递性成立（生的链）：
  nz 生 nx → nx 生 xn → xn 生 xz → xz 生 zx → zx 生 zn → zn 生 nz
  所以：nz（间接）生 xz、zx、zn……
  整个循环是自洽的：任意节点经过 6 步回到自身

传递性待定（克的链）：
  n 克 z → z 克 x → x 克 n
  从 n 出发：n 克 z → z 克 x → 那么 n 克 x 是否成立？
  → 这取决于"克"是否传递，当前标记为【待二审】
```
