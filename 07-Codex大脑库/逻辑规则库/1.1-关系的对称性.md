# 关系的对称性

## 原版概括

关系逻辑中，关系的**对称性**分为三种（金岳霖 §6）：

1. **对称关系**：如果 A R B 则 B R A（如"等于"、"相邻"）
2. **非对称关系**：如果 A R B 则必然 B 不 R A（如"大于"、"父亲"）
3. **反对称关系**：如果 A R B 则 B R A 不必然成立（如"喜欢"、"帮助"）

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | 十元中的"生"——"nz 生 nx"是否意味着"nx 生 nz"？直觉上不是 |
| **z（本质）** | **"生"关系是非对称的**：A 生 B 意味着 B 不生 A（否则就不是"生"而是"互相促进"了）。**"克"关系也是非对称的**：A 克 B 意味着 B 不克 A（否则就是相互抵消而非单向克制）。**"补"关系需要单独分析**。 |
| **n（应用）** | 决定生克链的流向规则：只能从生者流向被生者，不能反向。这是阴阳链单向流转的逻辑基础 |

## 十元理论应用规则

> **规则 R10（生非对称）**：如果十元 A "生"十元 B，则 B 在任何合法推演中都不能"生"A。
>
> **规则 R11（克非对称）**：如果十元 A "克"十元 B，则 B 在任何合法推演中都不能"克"A。
>
> **规则 R12（补的对称性待定）**："补"关系目前未在逻辑上锁定对称性——如果有"A 补 B"且"B 补 A"的情况，需要单独论证而不是默认成立。

## 生克链中的对称性实例

```
顺时针相生（非对称）：
  n 生 x → x 生 z → z 生 n
  nz 生 nx → nx 生 xn → xn 生 xz → xz 生 zx → zx 生 zn → zn 生 nz
  （以上均不可逆）

逆时针相克（非对称）：
  n 克 z → z 克 x → x 克 n
  （均不可逆——不能反过来说 z 克 n）

补（对称性分析中）：
  nx 补 zx — 如果这种"补"是能量补充，那么 zx 是否会回补 nx？不必然。
```
