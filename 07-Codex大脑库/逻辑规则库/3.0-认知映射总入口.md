# 🧩 认知映射规则库 — 总入口

## 定位

这是十元理论的**认知合法性层**。前三个步骤（逻辑规则 + 形式关系 + 箭头语法）保证了理论内部的自洽性，但无法回答这个问题：

> "凭什么 `xn+z` 就等于'时间'？这难道不是一种修辞比喻吗？"

认知科学（特别是侯世达的类比与映射理论）提供了**大脑如何建立这类跨域映射**的机制解释。它告诉你的理论：
- 这种映射不是随意的——它符合人类认知的**概念复合（conceptual blending）**机制
- 这种映射不是独断的——它有明确的**认知操作规则**
