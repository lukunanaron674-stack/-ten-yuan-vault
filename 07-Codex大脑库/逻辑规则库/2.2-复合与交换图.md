# 复合与交换图

## 原版概括

范畴论中，**复合（composition）** 是箭头的核心运算：如果 f: A → B, g: B → C，则存在 g∘f: A → C。

**交换图（commutative diagram）** 是验证复合是否自洽的工具：如果从 A 到 C 有两条路径（A→B→C 和 A→D→C），且两条路径的复合结果相同，则这个图是**交换的**。

## 三元分析

| 维度 | 分析 |
|:----|:-----|
| **x（现象）** | 在音乐分析中，你写"nz 生 nx，nx 生 xn"——但这里隐含了一个问题：nz → nx → xn 和 nz → xn（直接生）结果一致吗？ |
| **z（本质）** | 生克链本质上就是箭头的**复合**。顺时针相生链 `n→x→z→n` 是一个可交换图——从任何起点出发，经过 3 步复合回到自身。 |
| **n（应用）** | 用交换图验证你的生克环是否自洽：如果 A→B→C 的复合结果 ≠ A→C 的直接箭头，说明路径依赖路径不一致——理论有漏洞。 |

## 十元理论应用规则

> **规则 R26（复合闭合）**：沿生链的任意复合必须等于对应的直接关系。即：A 生 B 且 B 生 C → A 生 C，且 C 的"被生状态"与 A→C 直接生相同。
>
> **规则 R27（交换图检查）**：每当引入一个新的箭头关系时，必须检查它与已有的箭头路径是否构成交换图。如果不构成，说明新关系要么是多余的，要么是矛盾的。

## 十元生链交换图示例

```
顺时针相生环的可交换性：

          n
      ↗     ↘
    x  ←───  z?    检查：n→x→z 是否等于 n→z？

事实：n 生 x，x 生 z
根据规则R13（生传递）：n 生 z
所以：n→x→z 的复合 == n→z
     ✅ 交换图成立

派生六元环：
    nz ──→ nx
     ↑       ↓
    zn ←─── zx    检查：nz→nx→xn→xz→zx→zn→nz 回到自身
     ↑       ↓                          ↓
    zx ←─── xz    6步复合后回到 nz
     ✅ 自洽
```
