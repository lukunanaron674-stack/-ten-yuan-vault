# 🧠 逻辑规则库 — 总入口

## 定位

这是十元理论的**元规则层**。不直接定义 Z/X/N 是什么，而是定义：
- 什么样的定义是**干净的**（概念互斥、划分穷尽）
- 什么样的推演是**有效的**（关系的对称性、传递性）
- 什么样的映射是**合法的**（类比、跨界映射的限制条件）

## 使用说明

1. 每一张原子卡都产出一个**可复用的规则**（如"如果两个概念有交叉，则它们不是互斥的"）
2. 这些规则将用于审核 `01-十元系统/` 下所有官方文件的概念边界
3. 规则之间不矛盾——如果发现矛盾，说明底层逻辑还没打通
