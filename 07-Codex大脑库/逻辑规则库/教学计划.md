# 📚 三元理论构建 — 定制教学计划

## 总纲

从概念界定开始打底，逐步建链、升维、赋能，每一张卡片你都要过目、讨论、修改或通过，然后标记 `status: finalized`。

---

## 🟢 Phase 1：逻辑学打底（概念边界）
**目标**：把 Z/X/N 的边界像刀削一样干净

| 周次 | 卡片 | 讨论焦点 |
|:---:|:-----|:--------|
| W1-1 | [[0.1-概念互斥律]] | Z/X/N 真的互斥吗？有没有模糊地带？你的直觉中被打破过哪些边界？ |
| W1-2 | [[0.2-划分穷尽律]] | 十元命格真的覆盖了"所有人格可能"吗？你的经验中有什么人格现象是十个装不下的？ |
| W2-1 | [[0.3-内涵与外延]] | Z/X/N 在日常使用中"太宽了"吗？派生层和根基层的"粒度跳跃"怎么操作？ |
| W2-2 | [[0.4-定义的规则]] | 逐条检查 01-十元系统/ 中每个命格的定义——哪些违反了这6条规则？ |

**验收标准**：你能指出 01-十元系统/ 中至少 3 个定义问题，并给出修正方向。

## 🟡 Phase 2：形式逻辑建链（关系推演）
**目标**：让生克补的推演规则不依赖直觉，依赖逻辑

| 周次 | 卡片 | 讨论焦点 |
|:---:|:-----|:--------|
| W3-1 | [[1.1-关系的对称性]] | "生"不可逆——这条你同意吗？"补"可不可逆？情感上有没有"互相补"的情况？ |
| W3-2 | [[1.2-关系的传递性]] | "A生B、B生C → A生C"——你的顺时针环真的满足这个吗？检查一下你的生克环是否自洽 |
| W4-1 | [[1.3-不相容关系]] | 一个人真的不能同时是zx和nz吗？动态切换和静态固有的区别怎么界定？ |
| W4-2 | [[1.4-逻辑谬误清单]] | 翻出你的真实讨论记录（聊天、银矿库）——找到了几个谬误案例？ |

**验收标准**：你能用"生非对称性"和"传递性"来解释为什么你的生克环是顺时针的。

## 🔵 Phase 3：范畴论升维（箭头语法）
**目标**：从"是什么"升维到"怎么画"

| 周次 | 卡片 | 讨论焦点 |
|:---:|:-----|:--------|
| W5-1 | [[2.1-态射语法]] + [[2.6-外部图与内部图]] | 把所有生克补关系都"画成箭头"——你觉得这个统一语法好用吗？外部图和内部图怎么区分？ |
| W5-2 | [[2.7-终对象与始对象]] + [[2.2-复合与交换图]] | 全元 = 零对象？这个类比你觉得成立吗？生克环的"交换性检查"你手动验证一遍？ |
| W6-1 | [[2.5-主从结构的范畴表达]] + [[2.8-积和与分配律]] | zx的"Z主X从"用箭头画出来 + 你的组合是否满足分配律？ |
| W6-2 | [[2.4-体量标尺的箭头模型]] | 体量1、3、5、7、9分别对应什么箭头权重？用箭头模型重新解释一次"吞没" |
| W7-1 | [[2.3-函子映射]] + [[2.9-函子与自然变换]] | xn+z=时间 这个映射真的是函子吗？检查一个音乐分析中的映射 |
| W7-2 | [[2.10-伴随Yoneda与极限]] | Yoneda：nz由它的关系网络完全定义——这条你同意吗？对你的体系有什么影响？ |

**验收标准**：你能用箭头语法（A→B + 标签+权重）描述任何一个十元关系链。

| W8-2 | [[3.2-跨域类比映射]] | "人格≈能量"这个类比——5条共享关系够不够？你有没有其他核心类比想检查？ |
