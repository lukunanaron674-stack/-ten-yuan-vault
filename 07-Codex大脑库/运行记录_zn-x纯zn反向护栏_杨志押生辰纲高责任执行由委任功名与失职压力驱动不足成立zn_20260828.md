# 杨志押生辰纲｜高责任执行由外部委任、功名与失职压力驱动，不足成立 pure `zn`

## 1｜本轮问题

只测试一个窄候选原则：

> 杨志在押送生辰纲时极度谨慎、强硬催行、承担高风险，看起来像“受托之物必须不计代价护送到底”的责任原则。这个表现是否足以锁 pure `zn`？

结论：**不足。** 本例可以高纯证明“高责任执行、承受代价、坚持任务”都不是 `zn` 的充分条件；当前行为链由外部委任、功名恢复/恩遇、任务失败责任与现实风险共同驱动，拿掉这些外因后，缺少同一原则仍跨情境保留未来指导资格的证据。

## 2｜剧情事实

《水浒传》第16回：

1. 梁中书把生辰纲押送任务交给杨志，并接受杨志提出的低调装扮、精简人手等运输方案；
2. 杨志一路真实组织队伍、催行、约束军健，并因担心强人出没坚持危险地段不能随意停歇；
3. 这说明杨志不是敷衍任务，当前执行强度与风险意识都很高；
4. 同一人物此前明确把恢复功名、取得进身与对提携者报答放在现实职业链中，梁中书对其抬举也是当前任务关系的重要背景；
5. 第17回生辰纲失去后，杨志首先面对的是“无颜回见梁中书”、失职后果与现实逃亡压力，原押运任务随对象失去而立即终止；
6. 当前材料没有出现：在没有委任、没有官位/恩遇、没有失职惩罚、也没有同一财物收益的另一个独立情境里，杨志仍把“受托财物必须不计代价护到底”作为不可轻易让渡原则重复调用。

因此最小事实链是：

```text
明确外部委任
+
现实职业上升 / 恩遇背景
+
任务失败责任与惩罚压力
+
主体高强度执行
≠
内部不可轻易让渡原则已经成立
```

## 3｜zn 判断

current `zn` 要求：

- 原则命题明确；
- 无奖励、认可与观看时仍进入判断；
- 与利益、安全等发生冲突时仍影响最终排序；
- 跨阶段保留未来调用资格；
- 有明确边界或让渡代价。

本例的候选“受托押运职责”只在外部任务窗口中高显影，而当前材料没有独立通过最关键的两道门：

```text
拿掉外部委任 / 职业收益 / 恩遇 / 失职压力
→ 同一原则仍会进入判断？

换到另一独立受托情境
→ 同一原则仍保有未来调用资格？
```

目前均缺高纯证据。

所以本轮锁：

```yaml
zn_current_for_tested_responsibility_principle: false
stable_zn_essence_locked: false
```

这不等于“杨志整个人没有任何 `zn`”；只排除把本轮高责任执行本身当作该原则已经成立的证据。

## 4｜x 检查

本轮不是 pure-`x` 测试，也不把整趟押运权限重新计数。

已有同阶段火轴记录已经证明：杨志在运输方案设计、日常催行等子任务有真实管理动作，但“黄泥冈是否停歇”仍可被老都管现实覆盖，因此不能把整个押运任务层写成稳定全局 `x`。

这里仅保留对象层纪律：

> 高责任执行不是 `zn` 的充分条件；局部管理也不自动形成整体现实 `x`。

## 5｜关键本体变量

本轮真正检查的是：

> **一个看起来非常负责、愿意承担代价的人，是因为内部不可轻易让渡原则在指导，还是因为外部任务、身份收益、恩遇与失败后果在持续施压？**

可观察分水岭：

```text
外部任务存在时很负责
≠
外部任务消失后原则仍成立
```

## 6｜拿掉测试

### 拿掉外部委任

如果没有梁中书的押送任务，只保留“道路危险、杨志谨慎”的性格线索，当前没有证据证明他会自行生成并长期维护“任何受托财物都必须不计代价护到底”的原则。

### 拿掉职业收益与恩遇

如果拿掉进身、抬举、报答提携者等现实职业背景，现有材料不足证明同样的任务强度仍会由内部原则独立维持。

### 拿掉失职后果

如果任务失败不会带来问责、羞耻、职业损失或现实危险，当前也没有跨情境材料证明该原则仍会以同样优先级进入判断。

因此这些外因不是可以轻松冻结掉的装饰，而是当前行为链的重要解释变量。

## 7｜反向测试

要把同类材料升级为真正 `zn`，应看到：

```text
没有上级委任
或没有奖励 / 进身 / 恩遇
或违背原则反而更有利

主体仍坚持同一明确责任原则
+
在另一个独立情境再次按它排序
+
能够说明何时可让渡、何时绝不让渡
```

原著当前被测桥段没有达到这一纯度。

## 8｜最近邻排除

- `zn vs xn`：杨志自行设计路线、组织押运、调整时段，首先回答“怎样完成任务”，不等于“什么不可让渡”；
- `zn vs z`：功名、进身、被梁中书抬举与评价是重要外部激励，不能反向当作内部 `zn`；
- `zn vs x`：局部管理权限与实际掌握是另一个端点，不能因为“我负责这个对象”就自动产生内部原则；
- `zn vs 惩罚驱动`：害怕失败、问责、失去前途可以产生高强度执行，但 current canonical 明确要求拿掉制度/惩罚后原则仍能进入判断。

## 9｜第三因素冻结

冻结：

- 酷热；
- 吴用等人的计谋；
- 杨志脾气暴躁；
- 生辰纲最终是否被劫；
- “杨家将后代”身份标签；
- 对杨志能力高低的评价。

不能冻结：

- 梁中书委任；
- 当前职业/进身背景；
- 提携恩遇；
- 失职责任与后果。

因为本轮恰恰要检验这些外因是否足以解释“高责任执行”。
