### 源端点、目标端点与变量

源端点 `zx`：甲的力量公开进入现实，决定范围、影响位置或等级位置扩大，旧秩序与他者被迫围绕甲重新反应。普通善举、演讲、牺牲与坚持不足。

目标端点 `zn`：乙此前没有稳定原则认领；甲失败、离场、奖励与宣传停止后，乙仍在无人监督、可退出且会受损时坚持原则本身。乙面对甲未交代的新情境时，能自行从原则推出行动；若英雄遗命与原则冲突，乙能拒绝英雄而保留原则。

被改变变量：乙对原则的内部确定度、无监督执行持续度、新情境推导能力、原则与英雄个人的可分离度、拒绝冲突遗命的能力，以及去掉胜利、阵营与奖励后的坚持度。

成立阶段与体量：低体量为单一见证者在具体阶段形成内部义务；中体量为多人在甲撤场后各自独立推导；高体量须证明原则脱离英雄、职位、组织命令与宣传后仍持续。现阶段只允许候选落在状态层或关系层。

### 候选机制

#### 候选 A：公开见证入口

```text
甲以 zx 把原则推入现实
→ 乙看见原则能够进入公共现实
→ 乙开始认真对待该原则
```

理论后果：只能解释见证入口与注意权重，不能直接证明 `zn` 生成。若乙只是因为甲成功或强大才相信，更接近 `z`、工具理性或胜方追随。

#### 候选 B：公开代价取消谋利解释

```text
甲公开推进原则并承担利益、位置或生命代价
→ 乙确认甲不是借原则谋利
→ 甲撤场后乙仍坚持原则
```

理论后果：代价可削弱表演解释，但首先证明甲自己的 `zn`；乙的变化仍可能来自悲痛、恩情、`n/nz` 与传播。

#### 候选 C：新情境独立推导

```text
甲撤场
→ 乙遇到甲从未规定的新情境
→ 乙不是复述口号或执行遗命
→ 而是从原则自行推出新行动并承担损失
→ zn 候选上升
```

理论后果：这是本轮新增的最低目标门槛。若乙只执行甲留下的明确命令、计划、职位任务或组织流程，最多证明 `nx/xn`、身份继承或遗命延续。

#### 候选 D：原则高于英雄

```text
英雄遗命、阵营利益或组织命令与原则冲突
→ 乙拒绝英雄个人与阵营
→ 仍保留原则并独立行动
```

理论后果：只有这一测试能强力证明原则已经与英雄个人分离；当前没有合格具体案例。

### 正例候选

1. 《饥饿游戏》凯特尼斯与第十一区见证者：凯特尼斯公开悼念露露并挑战竞技秩序，使原则进入公共现实。污染来自长期压迫、悲痛、地区身份、传播符号与反抗组织；无法证明目标此前无稳定 `zn`，也缺少甲撤场后的新情境独立推导。
2. 《悲惨世界》主教与冉阿让：冉阿让后续内部意义变化清楚，但主教源端点更接近 `zn/n/z`，公开扩权与等级重排不足；不构成纯 `zx`。
3. 《黑暗骑士》蝙蝠侠与渡轮乘客：乘客在无获救保证时拒绝杀死另一船，目标端点候选较清楚；但既有法律道德、群体监督与剧情两难过强，蝙蝠侠的 `zx` 与该选择缺少直接作用链。
4. 《V字仇杀队》V 与伊薇：V 撤场后伊薇完成列车行动，表面接近传承；但该行动是 V 明确留下的计划，且混入长期训练、胁迫、关系依恋与符号继承，只能证明遗命执行，不能通过新情境推导测试。
5. 《勇敢的心》华莱士与罗伯特·布鲁斯：华莱士死后罗伯特继续反抗，表面接近原则传承；但罗伯特原有苏格兰身份、政治利益与既有信念过强，也没有证明目标 `zn` 从无到有。

### 反例

1. 强者获胜后群众加入胜方：利益与胜利预期。
2. 英雄被授勋、立像或写入教材：`z/x并z/xn`。
3. 群众因恐惧服从：`nx` 或权力结果。
4. 乙原本就相信原则：既有 `zn` 显影。
5. 英雄牺牲后建立纪念馆或组织：`n/xn/x并z`。
6. 乙继承职位、制服、任务或明确遗命：`x/x并z/xn/nx`。
7. 甲自己的内部原则推动甲显权：方向是 `zn 生 zx`。
8. 乙只是敬佩、悲伤、感恩或追随英雄：状态、`z` 或 `nz`。
9. 乙严格执行英雄预先写好的计划，面对新情境却不会自行判断：遗命延续，不是原则内化。
10. 英雄要求乙违背原则，乙仍因忠诚照做：说明英雄个人高于原则，目标 `zn` 不成立。

### 最近邻排除

- 与 `zn 生 zx`：甲先有内部原则再自己显权；本轮必须是另一个乙新增原则。
- 与 `z`：被英雄看见、鼓励或确认改变认可位置，不等于内部义务。
- 与 `x并z`：旗帜、称号、面具、纪念与共同身份属于公开壳；认领壳不等于认领原则。
- 与 `n/nz`：共同体承载、个人恩情与关系余温可以使乙留恋英雄，但不证明普遍原则内化。
- 与 `xn/nx`：教育、传播、训练、组织流程、职位继承与遗命执行都可能让行动持续，却不证明乙自行判断。

### 拿掉测试

1. 拿掉甲的公开显权，只保留善举、演讲或牺牲，乙仍变化，则不依赖 `zx`。
2. 拿掉胜利、奖励、英雄称号、宣传、纪念与共同体监督，乙仍坚持才支持目标。
3. 拿掉乙原有信念，必须证明原则真实新增。
4. 拿掉甲本人，只保留原则，乙仍能面对新情境自行推导行动。
5. 拿掉甲留下的明确命令、计划、职位任务与组织流程，乙是否仍知道该做什么？
6. 让英雄遗命与原则发生冲突，乙若拒绝英雄而保留原则，原则与个人才真正分离。
7. 拿掉个人恩情、悲痛与关系余温，乙仍坚持普遍原则，才排除 `n/nz`。
8. 拿掉公开观众与监督，乙仍行动，才达到无监督义务。

现有候选均未通过全部测试。

### 反向测试

```text
zx 生 zn 候选：
甲公开显权使原则进入现实
→ 乙在甲撤场后面对新情境独立推导原则行动

zn 生 zx：
甲先有内部原则
→ 甲自己公开推进并取得现实决定位置
```

现有英雄案例普遍更稳定地证明反向 `zn 生 zx`。不能用甲自己的原则与显权给乙的目标端点作证。

### 动态链后果

```text
我看见他把原则推入现实
→ 我可能只是震撼、崇拜、跟随或执行遗命
→ 他失败、离场，奖励、宣传与命令中心消失
→ 我遇到他没有交代的新情境
→ 我从原则自行推出行动
→ 即使必须拒绝英雄遗命或阵营利益，我仍保留原则
→ 原则才从“他的”变成“我的义务”
```

改变的是见证者对原则的内部归属、新情境推导能力与不可背弃度。不机械生成英雄崇拜、共同体、胜利、正义性或永久传承。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只核验：甲是否达到 `zx`；乙此前是否没有稳定 `zn`；乙是否在甲撤场后面对新情境独立推导；`z/x并z/n/xn/nx/nz` 与既有 `zn` 是否才是真正中介。不建立父子派生，不从因果主题反推本体主题。
