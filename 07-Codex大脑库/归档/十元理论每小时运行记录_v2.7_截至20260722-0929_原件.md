### 对象分层

- 稳定本体：不由一次处分、驱逐或命令反推人物稳定 `zx`；不因家庭、学校或团队存在就自动判稳定 `n`。
- 当前状态：恐惧、羞耻、愤怒和麻木只是作用后的状态。
- 行为功能：公开命令、处分、驱逐、隔离、强迫表态和强制改组是 `zx` 行为候选。
- 光影：制服、审讯灯、铁门和中心高位构图只辅助显影。
- 场景：监狱、家庭、学校和组织不是端点本身。
- 时间关系：先处罚后关系破裂只证明先后。
- 关系位置：上级、家长、校长和典狱长只有实际公开行使权能时才进入 `zx`。
- 显影：成员资格、接收能力、互信、返回或连续运行真实下降。
- 动态链：只改变共同体承载能力，不机械生成修复、革命或胜利。

### 端点、变量、阶段、体量与显影

- 源端点 `zx`：明确主体公开行使权能，直接裁决他者位置、资格或行动，并具有压过对象的现实效力。
- 目标端点 `n`：已经形成接收成员、反复返回、持续照顾、保护、互信或共同生活的承载结构。
- 被改变变量：成员资格、接收边界、照顾连续性、成员互信、返回能力和结构抗崩能力。
- 成立阶段：`n` 已运行 → `zx` 公开裁决资格或运行条件 → 接收、保护、互信或运行被迫停止。
- 低体量：一次公开命令暂时打断接收或照顾。
- 中体量：互信下降、成员不敢互助、共同体运行受损。
- 高体量：成员资格被取消、共同体解体或承载结构无法继续存在。
- 显影条件：原本会接纳的人被拒绝、照顾停止、成员退出、彼此怀疑或结构不能继续保护弱者。

### 候选机制及理论后果

- A 资格取消：公开宣布某人不再属于共同体，使 `n` 失去继续接收、保护与照顾该成员的资格。目标变量首先落在成员资格和接收边界。
- B 运行中断：命令、惩罚或强制改组压过既有承载结构，使照顾、互信、分工与返回机制停止。目标变量落在连续运行能力。
- 排除 C 资源封锁：仅掌握物资、通信、场地或出口而无公开显权时优先检查 `x`。
- 结论：A/B 是同一正式机制的两个入口，分别针对成员位置与结构运行。

### 正例

1. 方志敏监狱剧本中的狱友共同体：狱友已形成递水、照顾病弱者、传递消息和互相承认的 `n`；管理者公开以处分、审讯和隔离权迫使某人否认同伴，再宣布其“已经背叛”，使其他狱友停止接收、照顾和传递消息。
2. 家庭首领公开逐出成员：家庭原本持续提供居住、保护和照顾；家长当众宣布某人“不再是这个家的人”，并要求其他成员停止联系和支持，直接切断成员资格与照顾连续性。
3. 校长强制拆散学生互助小组：小组已长期提供学习、食物和情绪支持；校长公开处分核心成员并威胁继续接触者，导致互助、接收和返回停止。

### 反例

1. 上级当众辱骂成员，但团队继续接纳、保护和合作：只有 `zx` 行为共现，`n` 未变化。
2. 毕业、合同到期或迁居导致小组自然结束：只是时间关系。
3. 扣住纸笔、通信和文稿出口：若改变完成和被看见条件，优先检查 `x克z`。
4. 成员主动泄密后被共同体排除：没有外部主体公开压位时，不自动判 `zx克n`。
5. 柯布设计多层梦境并植入想法：没有清楚呈现既有 `n` 的承载变量下降。
6. 暴君烧毁空城：普通破坏或暴力，不自动等于击穿承载结构。

### 最近邻排除

- 与 `x克z`：前者掌握必要对象、资源、权限或显现入口，使完成或被确认受阻；本关系公开裁决成员资格或压停结构运行。
- 与 `xn克zx`：前者由既有规则、流程和时间结构限制单次显权；本关系由单一公开权能反过来击穿承载。
- 与 `n克xz`：前者由承载隔离危险并提供停留位置；本关系使容器失去接住成员的能力。
- 与普通破坏：只有承载资格、接收能力、互信、返回或连续运行下降，才进入目标端点。

### 拿掉测试

1. 拿掉公开命令、惩罚或资格裁决后，`n` 是否恢复接收与运行？若是，支持本关系。
2. 保留恐惧和资源不足，但成员仍能互助，说明 `n` 仍成立，不能判克制。
3. 拿掉既有 `n` 后只剩个人受罚，没有目标端点。
4. 拿掉成员资格与连续运行变化，只保留强势气势，案例不需要本关系。
5. 拿掉《盗梦空间》的承载解释，故事仍可由 `xn/x/z` 与心理操控说明，旧案例不成立。

### 反向测试

```text
n 克 zx：共同体通过保护、互助与反复接收，限制单一主体的公开强制范围。
zx 克 n：公开权能裁决资格或运行条件，使共同体承载能力下降。
```

反向改变 `zx` 的权能范围；本关系改变 `n` 的承载能力，方向不对称。

### 动态链后果

```text
原本“这里还能接住我们”
→ 某个公开权能开始决定谁配留下、谁能被照顾
→ 共同体从容器变成筛除与服从的场所
→ 成员不再相信这里能接住自己
```

改变的是承载层的安全、互信和返回资格，不把关系当成机械生成器。
