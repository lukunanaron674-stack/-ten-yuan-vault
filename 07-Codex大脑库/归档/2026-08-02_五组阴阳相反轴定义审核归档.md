# 2026-08-02｜五组阴阳相反轴定义审核归档

## 审核对象

| 五行轴 | 阳端 | 阴端 | 原提议变量 |
|---|---|---|---|
| 木 | zx | nx | 占据方向源并施力 ↔ 让出方向源、沿既有通道推进 |
| 火 | zn | x | 保留多主体独立成立 ↔ 把对象纳入单一掌握边界 |
| 土 | n | x并z | 内部真实承载 ↔ 外部公共壳与接口 |
| 金 | xn | z | 把重心分布进流程和节点 ↔ 把重心集中到单一最高点 |
| 水 | xz | nz | 关闭退路与可逆空间 ↔ 保存或重新打开回返路径 |

## 审核决定

五组配对保留，但统一要求：

```text
同一对象层
+ 同一核心变量
+ 相反方向的结构操作
```

## 最终归档定义

| 五行轴 | 最终相反变量 | 审核状态 |
|---|---|---|
| 木 `zx↔nx` | 最终方向与作用权来源：主体生成并占据方向 ↔ 不占最终方向、沿外部已有通道续接 | 强成立 |
| 火 `zn↔x` | 对象独立成立资格与归属方式：保留对象自身成立 ↔ 纳入掌握、调用与处分边界 | 成立，完成去人际化 |
| 土 `n↔x并z` | 对象跨越内外边界方向：外→内纳入承载 ↔ 内→外映射外化 | 原定义偏互补，修正后成立 |
| 金 `xn↔z` | 运行权与裁定重心配置：分布到规则节点流程 ↔ 收束到单一最高裁定点 | 原定义偏视觉，修正后成立 |
| 水 `xz↔nz` | 可逆性与对象特异回返空间：持续收窄 ↔ 保存、恢复或重建 | 强成立 |

## 关键修正

1. `nx`用“不占据最终方向”，不用“让出方向源”。
2. 火轴广义层不用“多主体”作为必要措辞，改为“对象自身独立成立资格”。
3. 土轴必须写边界流向，不能只写“内部承载/外部壳”。
4. 金轴必须写运行权与裁定权配置，不能只写“分散/集中”。
5. 水轴使用中性“收窄”，不预设必有主体主动关闭。
