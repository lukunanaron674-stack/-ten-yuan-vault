### 源端点、目标端点与变量

源端点 `nx`：主体仍沿既有关系、流程或组织提供的基线方向推进，不建立公开替代路线，不争夺最终解释权；撤回的只能是非关键、可选的签署、复述、署名或象征背书。停止关键职责、辞职、公开反抗或另立方向会使源端点偏离 `nx`。

目标端点 `x并z`：壳必须已经真实覆盖主体，并被第三方用于归类、调用或代表。被改变变量不是主体内心认不认同，而是壳对主体的自愿代表资格、共同覆盖范围、署名合法性与第三方归因稳定度。

成立阶段：优先限定于关系层或状态层。低体量一次拒签只缩小局部声明；中体量要求跨轮次撤回可选背书；高体量必须证明多个关键成员的背书缺失使“全体”覆盖真实下降，同时行政身份和关键职责仍存续。

### 本轮关键分流：三类壳

#### 1. 行政归类壳

职位、户籍、合同、编制、军籍等由制度接口维持。主体内心不认领或拒绝象征背书，通常不使行政壳失效。若职位被撤销、合同终止或账号关闭，启动源是 `x/xn` 配置，不是纯 `nx`。

#### 2. 职责履行壳

壳通过主体持续完成关键职责而获得现实证据。纯 `nx` 若完整照章履行，反而持续维持或强化该壳；若停止关键职责到足以使壳失效，主体往往已经不再沿既有方向推进，源端点偏离 `nx`。

#### 3. 共识背书壳

“全体一致”“本人自愿支持”“我们共同主张”等壳依赖成员反复提供可选签署、复述、署名或象征背书。主体可以继续基线流程，却撤回这些非关键接口，使壳只能代表多数或外部行政标签。只有这一类仍保留窄候选。

### 候选机制

#### 候选 A：可选背书断供

```text
共识壳已经真实覆盖主体
→ 壳依赖持续签署、复述、署名或象征背书
→ 主体继续基线流程，不另立方向
→ 只撤回可选背书
→ 第三方不再把壳解释为主体自愿立场
→ “全体／本人立场”退为“多数／外部标签”
```

理论后果：克制的不是整个身份壳，而是壳与特定主体之间的自愿代表接口；适用域仅限共识背书壳。

#### 候选 B：字面服从抽空象征精神

```text
主体严格完成最低字面程序
→ 不补入主动倡议、认同与象征表演
→ 壳难以把主体解释为自身精神代表
```

理论后果：可能产生讽刺或精神代表性下降，但若行政归类和职责覆盖仍完整，就未必达到 `x并z` 被克制的目标变量。

#### 竞争解释：停止履行或主动退出

辞职、停工、公开拒绝、揭露、另立身份与资源撤回确实可能使壳失效，但启动源更接近 `zn/zx/x/xn` 或关系终止，不能倒写成纯 `nx`。

### 正例候选

1. 《抄写员巴特比》巴特比：抄写员壳此前已经成立，后来角色壳逐渐无法解释他。目标端点较清楚，但他停止关键工作，已经不再沿办公室基线流程推进，源端点偏离 `nx`。
2. 《好兵帅克》帅克：持续沿军队命令与程序行动，不建立公开替代路线，源端点较接近 `nx`；但军队仍能行政上把他归为士兵，职责壳也被字面执行维持。被抽空的是“英勇忠诚士兵”的精神代表性，目标端点不足。
3. 组织共同声明中的不背书成员：成员继续普通流程，不公开反对、不辞职，只拒绝签署和允许名字进入“全体一致”声明；结果从“全体一致”退成“多数成员支持”。结构最纯，但缺少两个可核验的具体人物文本。

### 反例

1. 《使女的故事》奥芙弗雷德早期：内心不认领，外在完整履行，使女壳仍稳定覆盖她。
2. 《1984》温斯顿公开反叛前：内心反党，外在继续履行，党成员身份仍有效。
3. 下属因恐惧签署虚假声明：`nx` 上升，但签署反而强化共识壳。
4. 员工辞职、人物撕下面具或公开另立身份：壳下降，但源端点不再是纯 `nx`。
5. 记者调查并揭露组织造假：优先检查 `xn/zn/zx`。
6. 壳从未成功吸纳主体：只能判生成失败，不能判已成立壳被克。
7. 行政机构继续依法登记主体，主体仅在内心拒绝该身份：公共覆盖没有变化。
8. 主体完整照章履行全部关键职责：职责壳获得更多现实证据，通常被维持而非克制。

### 最近邻排除

- 与 `zn 克 x并z`：因“这个身份不对”主动撤回价值认领或拒绝关键履行，启动源是内部意义。
- 与 `zx 克 x并z`：公开拆壳、揭露、夺取解释权或强迫改名属于公开权能。
- 与 `x/xn`：撤销职位、合同、账号、名称和资源属于权限或制度配置。
- 与内部不认同：只在内心保持距离，不改变第三方公共覆盖。
- 与反向 `x并z 克 nx`：身份壳预设角色路线，使主体可用方向被限定；改变的是主体方向空间。

### 拿掉测试

1. 拿掉壳对自愿背书的依赖，沉默或拒签是否完全无效？若是，只剩行政壳或职责壳。
2. 恢复签署、复述、署名和象征背书后，共识壳的代表范围是否恢复？
3. 拿掉辞职、停工、公开拒绝、资源变化、职位解除和真相曝光后，覆盖是否仍下降？
4. 主体若停止关键职责到足以削弱壳，是否已经离开 `nx`？
5. 只有内心不认领时，第三方是否仍照常用壳代表主体？若是，目标端点未变。
6. 壳若从未完成吸纳，是否只是没有生成？
7. 行政身份与关键职责保持不变，仅撤回可选背书时，“全体／本人立场”是否真实缩小？这是窄候选的核心测试。

### 反向测试

```text
nx 克 x并z 候选：
主体继续基线流程
→ 撤回共识壳依赖的可选背书
→ 壳对主体的自愿代表与共同覆盖下降

x并z 克 nx：
身份壳预设角色路线
→ 主体可用方向被限定
→ 主体更沿壳提供的安排推进
```

正向改变壳的代表接口；反向改变主体的方向空间，不能互相代证。

### 动态链后果

```text
这个壳原本已经能把我写进“我们”
→ 我没有另立旗帜，也仍走在既有通道里
→ 我只是不再把名字、复述和象征背书借给它
→ 行政标签与关键职责可能仍在
→ 自愿代表资格开始脱落
→ “全体／本人立场”退成“多数／外部归类”
```

改变的是壳对主体的自愿代表资格与共同覆盖范围，不机械生成身份消失、真相曝光、组织崩塌或真实自我回归。

### 三元与十元并行

三元只核验作品整体精神运动。十元本轮只检查 `nx` 是否仍沿基线方向、`x并z` 是否已成立、壳属于行政归类／职责履行／共识背书中的哪一类，以及第三方代表接口是否真实下降。不从空间主题、身份题材或人物沉默反推关系成立。

- 壳必须先成立；未完成吸纳不等于被克制：99%。
- 行政归类壳不依赖内心认领，纯沉默与心理距离通常无效：99%。
- 职责履行壳会被纯 `nx` 的完整履行继续维持或强化：99%。

- 唯一可保留候选是“继续基线流程、撤回可选背书，使共识壳覆盖缩小”：97%。
- 目标变量必须落在自愿代表、共同覆盖、署名和第三方归因合法性：98%。

未通过正式机制：
