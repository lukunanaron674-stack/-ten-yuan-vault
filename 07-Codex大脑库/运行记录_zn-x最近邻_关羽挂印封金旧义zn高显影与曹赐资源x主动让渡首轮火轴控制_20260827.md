# 关羽挂印封金｜旧义 zn 高显影与曹赐资源 x 主动让渡

## 0｜本轮裁决

本轮不做“关羽整个人是什么”的永久贴标签，只裁一个明确对象层：

> **当曹操提供的金银、侯印、府中人役与留用条件，和关羽先前对刘备的誓约/旧义发生冲突时，哪一项拥有最终排序与未来指导资格？**

结论：

```text
旧义 / 誓约的未来指导资格
→ zn 高纯成立

曹赐金银 / 汉寿亭侯印等资源掌握
→ 曾进入局部 x 候选/状态
→ 离曹时被主动封存、悬印、放弃

整段“纯 zn”：不锁
原因：赤兔马等局部资源仍被继续使用，x 不能按整段全对象层一刀清零

zn+x 严格补：本轮不进入
```

## 1｜剧情事实

《三国演义》第26回：

1. 关羽在曹操处已经获得封侯、金银、府第、人役等现实待遇，曹操持续试图厚待并留住关羽；
2. 关羽得知刘备确在袁绍处后，明确表示昔日之言不可背；
3. 他给刘备的书中说明自己此前只是因下邳失守、二嫂责任而暂时羁身，并未改变原归向；
4. 多次向曹操辞行不得见后，他仍决定离开；
5. 临行时把曹操累次所赐金银封置库中，把汉寿亭侯印悬于堂上，曹操所拨人役不带，只带旧从人与二位夫人离开；
6. 关羽仍骑赤兔马，因此本轮不能把“曹操所赐的一切对象都被放弃”写成事实。

主要文本来源：
- 《三国演义》第26回，维基文库：https://zh.wikisource.org/zh/三國演義/第026回
- 中国哲学书电子化计划：https://ctext.org/sanguo-yanyi/ch26/zh

## 2｜zn 证据

current canonical：`zn = 主体内部一项不可轻易让渡的意义或原则，拥有未来调用、冲突排序与最终指导选择的资格。`

本例逐门：

```text
原则对象明确
→ 与刘备旧盟/旧义不可背

外部奖励存在
→ 曹操封侯、金银、礼遇、留用

冲突排序发生
→ 留曹继续享有现实收益 vs 归刘履行旧义

最终选择
→ 离曹归刘

未来调用资格
→ 关羽明确把旧盟当作后续行动的最终指导标准
```

尤其重要的是：`zn` 不是由后世“忠义关公”称号倒推，而是由桥段内部的**反奖励选择**证明。

拿掉曹操的认可、封侯、金银甚至后世评价，关羽先前誓约仍进入当前判断并决定离开，这通过 zn 的认可/奖励拿掉门。

## 3｜x 证据与边界

current canonical：`x = 对象、资源、地盘、权限或关系进入“归我 / 我方掌握”的边界，主体拥有实际占有、使用、调配、调用、处分或排除能力。`

本例不能说 x 完全不存在：

- 曹赐金银在离开前确实已进入关羽实际持有范围；
- 汉寿亭侯印作为职位/权限凭证至少构成 x 候选；
- 赤兔马继续由关羽占有、使用，形成清晰局部 x。

但离曹这个关键窗口里，关羽对一批曹赐对象执行的是：

```text
金银 → 封存不带
侯印 → 悬回不带
曹拨人役 → 不带
```

因此最稳结论不是“关羽没有 x”，而是：

> **当 x 资源层与 zn 原则层冲突时，关羽主动让渡一批 x 对象，zn 仍保持最终排序权。**

这直接提供 `zn vs x` 最近邻边界：

```text
“我拥有它”
≠
“它决定我为什么继续做选择”
```

## 4｜关键本体变量

本轮火轴核心变量不是“关羽属于刘备阵营”这个名义标签，而是：

> **哪一项内部意义拥有在现实收益冲突中继续定义“我应该成为/保持什么样的自己”的指导资格。**

可观察变化：

```text
曹方身份 / 待遇 / 资源持续增加
→ 没有把旧义从最终指导位替换掉

刘备消息出现
→ 旧义重新进入当前高调用
→ 资源与职位被主动降权/放弃
→ 行动改为离曹归刘
```

这支持“被外部承认/封侯 ≠ 本体原则被外部身份替换”。

## 5｜关键压力

压力包括：

- 曹操持续厚待与留用；
- 官职、金银、府第、人役等现实利益；
- 曹操通过回避不见延迟其离开；
- 离开存在追兵与现实风险。

这些压力没有制造 zn；它们只是提供了高质量反事实条件，让“旧义是否真有不可轻易让渡与冲突排序资格”变得可观察。

## 6｜拿掉测试

### 拿掉奖励 / 认可

去掉曹操赞赏、封侯、金银、社会评价：

- 关羽的旧盟原则仍可成立；
- “得知刘备 → 应归刘”的判断仍可成立。

→ 支持 zn。

### 拿掉 zn

如果去掉“旧义具有最终指导资格”，只保留现实资源与职位：

- 没有足够结构解释为何在曹方收益明显时仍必须离开；
- 封金挂印也失去当前排序依据。

→ zn 是当前选择的核心解释变量。

### 拿掉 x 资源

如果曹操从未给任何金银、印绶、资源：

- zn 仍可成立；
- 但本轮“原则优先于已掌握资源”的最近邻压力测试会失去对照强度。

→ x 是高价值对照变量，但不是 zn 成立的必要条件。

## 7｜反向测试

若桥段改成：

```text
得知刘备消息
→ 关羽认为旧盟可以因曹操封侯厚赏而作废
→ 继续留曹
→ 后续不再把旧盟当作指导标准
```

则当前 zn 会显著下降。

若改成：

```text
旧义仍认为正确
→ 但当前只因暂时安全/策略而暂停离开
→ 后续仍保留明确未来履行资格
```

则不能仅凭暂停行动判 zn 消失。

## 8｜最近邻排除

### zn vs z

曹操高度认可、封侯只是外部认可。即便认可存在，真正决定离开的标准不是“谁更认可我”，所以不以 z 为主。

### zn vs x

- `x` 回答：哪些金银、印绶、马匹归关羽掌握；
- `zn` 回答：发生冲突时，为什么这些东西可以被放弃，以及什么标准仍能指导未来。

本轮正是两层硬拆。

### zn vs xn

收拾车马、安排二嫂、选择离开路线可以有运行组织，但它们回答“怎么离开”，不回答“为什么必须离开”。

### zn vs zx

关羽出北门、门吏退避有局部公开显权候选，但这不能反过来定义旧义原则；本轮不新增 zx 统计。

## 9｜第三因素冻结

冻结：

- 后世关公神化；
- “忠义”文化标签；
- 三国阵营正邪评价；
- 关羽武力强弱；
- 最终是否成功与刘备会合。

只保留：

```text
先前誓约是否明确
外部奖励是否真实存在
原则与收益是否发生冲突
哪一项最终排序选择
原则是否仍保留未来指导资格
```

结论不变。
