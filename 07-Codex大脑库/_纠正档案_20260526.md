# 纠正档案

## 一、十元命名与定义

### 1. xz ≠ 流浪
- 错误：我说 xz 的场意是"流浪"
- 纠正：**xz = 压迫**（黑恶势力、控制、重压）
- 流浪是 **nx + xz**，不是 xz 本身

### 2. x ≠ 深渊
- 错误：我说 x 是"深渊"
- 纠正：**x = 贪念**（物质欲望、执念）
- 深渊是 **x + z**，不是 x 本身

### 3. nx ≠ 鉴/幕
- 错误：我说 nx 是"鉴"、"幕"
- 纠正：**nx = 世故**（人情世故、淡淡的哀伤、白发）

### 4. xn ≠ 高墙
- 错误：我说 xn 是"高墙"
- 纠正：**xn = 法律**（规则、秩序、一辈子按轨道走）
- 用户原话："xn法律很对啊，xn的人就是有高墙的人"

### 5. zx ≠ 事件触发器
- 错误：我说 zx 是"事件触发器"
- 纠正：**zx = 王权**（目标驱动 + 持续执行 + 结果确认）
- 用户原话："zx是国王，万王之王，是利剑，是向上生长"
- 摩羯 = zx（12星座→10十元映射中，摩羯只能落到zx）

### 6. znx → x并z（面具 → 模具）
- 错误：我把面具定位为 znx
- 纠正：**面具 = x并z**，不是 znx
- 题材词为"模具"（待确认）

### 7. 概念的定义：zx → nz
- 错误：我把"概念的定义"定位为 zx（突破者）
- 纠正：**nz**（划清边界的冲动 z + 固定为语言的承载 n）

## 二、体系结构

### 8. 十个十元是平等互斥的独立符号
- 错误：我几次试图把十元写成"Z指向X"的派生结构
- 纠正：**十个十元是平等互斥的**，不是从三根基派生出来的
- 十元之间的关系是"位置关系"，不是"派生关系"

### 9. 三元核心定义
- z = **楚王弓**（有边界的执念，不是普世的）
- n = **精神个体**（生而为人就有的资格，不是谁给的）
- x = **现象之流**（流动不居的世界表象）
- 注意：这不是修辞——三元就叫"楚王弓/精神个体/现象之流"

## 三、分析方法

### 10. 音乐评分：四项维度 → 三项结构性标准
- 旧体系：四个维度打分
- 纠正后：**三个结构性标准**
  1. 克制关系不可替换
  2. 无一笔浪费
  3. 结尾呼应开头 + 选择与失去同步

### 11. 十元命名必须用双字题材词
- 不可以用：单字（霜/凉/鉴/幕/深渊）

- 必须用：**双字题材词**（舞台/信仰/家园/守望/压迫/世故/贪念/法律/王权）

## 附录：十元体系正本（归档）

### 三元核心定义（根基）

这十个字不是比喻——三元就叫这个：

- **z = 楚王弓** — 有边界的执念，不是普世的爱
- **n = 精神个体** — 生而为人就有的资格，不是谁赋予的
- **x = 现象之流** — 流动不居的世界表象

三根基不是三个"东西"——三根基是**z/n/x之间的关系**。
