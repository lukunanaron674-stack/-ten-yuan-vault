# 纠正档案

## 一、十元命名与定义

### 1. xz ≠ 流浪
- 错误：我说 xz 的场意是“流浪”
- 纠正：**xz = 压迫**（黑恶势力、控制、重压）
- 流浪是 **nx + xz**，不是 xz 本身

### 2. x ≠ 深渊
- 错误：我说 x 是“深渊”
- 纠正：**x = 贪念**（物质欲望、执念）
- 深渊是 **x + z**，不是 x 本身

### 3. nx ≠ 鉴/幕
- 错误：我说 nx 是“鉴”“幕”
- 纠正：**nx = 世故**（人情世故、淡淡的哀伤、白发）

### 4. xn ≠ 高墙
- 错误：我说 xn 是“高墙”
- 纠正：**xn = 法律**（规则、秩序、一辈子按轨道走）
- 用户原话：“xn法律很对啊，xn的人就是有高墙的人”

### 5. zx ≠ 事件触发器
- 错误：我说 zx 是“事件触发器”
- 纠正：**zx = 王权**（目标驱动 + 持续执行 + 结果确认）
- 用户原话：“zx是国王，万王之王，是利剑，是向上生长”
- 摩羯 = zx（12星座→10十元映射中，摩羯只能落到zx）

### 6. znx → x并z（面具 → 模具）
- 错误：我把面具定位为 znx
- 纠正：**面具 = x并z**，不是 znx
- 题材词为“模具”（待确认）

### 7. 概念的定义：zx → nz
- 错误：我把“概念的定义”定位为 zx（突破者）
- 纠正：**nz**（划清边界的冲动 z + 固定为语言的承载 n）

## 二、体系结构

### 8. 十个十元是平等互斥的独立符号
- 错误：我几次试图把十元写成“Z指向X”的派生结构
- 纠正：**十个十元是平等互斥的**，不是从三元派生出来的
- 十元之间的关系是“位置关系”，不是“派生关系”
- 三元用于描述十元内部的比例、质地和侧重
- 例如 nx 可以表现为 n 多、x 少，但 nx 与 n 在十元判定中仍是同一层级的位置

### 9. 三元核心定义（2026-07-16 用户重新校正）

旧错误：

```text
z = 楚王弓
n = 精神个体
x = 现象之流
```

该对应关系已经被用户正式推翻，不得继续使用。

当前正确口径：

#### z：精神个体需要另一个精神个体的认可

- 一个精神个体面对庞大的物质客观世界，会感到自身非常渺小。
- 单靠物质客观世界无法确认自己的精神存在。
- 它需要另一个精神个体看见、回应和认可自己。
- 舞台、展示、荣耀、追光只是 z 的外部表现。

> **z = 一个精神个体需要另一个精神个体确认：我看见你，你的精神存在对我成立。**

#### x（醒）：具体物象，小而清

- x 关注具体物象、物质、所有权、功能、局部因果与眼前利益。
- 关注区域小，变量少，边界清晰，因此往往聪明、冷静、逻辑清楚。
- x 容易显得自私和狭隘，是因为区域之外的人、精神和大关系被弱化。
- 更接近理科式切分与分析。

> **醒看物，所以窄而清。**

#### n（耐）：大区域与大关系，大而空

- n 不锁死在单个物品上，更关注人与人、群体与群体、国家与国家、历史与精神整体的关系。
- 区域大，变量多，边界模糊，所以思考容易显得空、散、乱，具体物质逻辑较弱。
- n 的优势是宏观、人际、社会和整体关系理解。
- 更接近文科式整体与关系思考。

> **耐看关系，所以大而乱。**

核心交换：

```text
x：牺牲广度，换取清晰
n：牺牲清晰，换取广度
```

### 9.1 楚庄王弓的正式归属

楚庄王弓不是 z 的定义，而是 **n 与 x 的核心教学案例**。

```text
具体的弓 = x
楚国区域 = n扩大一层
全人类区域 = n继续扩大
自然区域 = n继续扩大
空 = 最高n，区域最大
```

- 士兵或具体物主关注弓是否离开原位，是 x 的具体物象视角。
- 楚庄王把区域扩大到楚国。
- 孔子把区域扩大到全人类。
- 孟子把区域扩大到自然与腐化循环。
- 高僧以“空”容纳并消解得失与对象区分，是最 n 的位置。

## 三、分析方法

### 10. 音乐评分：四项维度 → 三项结构性标准
- 旧体系：四个维度打分
- 纠正后：**三个结构性标准**
  1. 克制关系不可替换
  2. 无一笔浪费
  3. 结尾呼应开头 + 选择与失去同步

### 11. 十元命名必须用双字题材词
- 不可以用：单字（霜/凉/鉴/幕/深渊）
- 不可以用：解释性词（执念驱动者/事件触发器）
- 必须用：**双字题材词**（舞台/信仰/家园/守望/压迫/世故/贪念/法律/王权）

### 12. 判断对象决定证据优先级（2026-07-16）

- 人物本体优先看动机、选择方式和长期稳定结构。
- 单张插画优先看光影、颜色、氛围、构图与空间关系。
- 漫画、电影优先看时间点变化、事件转折与关系运动。
- 同一张图可以是“人物本体 zn + 光影场 xz”，属于不同对象层级，并不冲突。

### 场意互斥验证

每个十元必须满足“either this or that”。一个场景的核心场意只能落在一个十元，不能模棱两可；但不同对象层级可以同时出现不同十元。

### 音乐评价标准（三项结构性标准）

1. **克制关系不可替换**：这首歌的克制关系是内在必然的，换一个克制就不成立。
2. **无一笔浪费**：没有一个音符、一句词是多余的。
3. **结尾呼应开头 + 选择与失去同步**：结构闭环。

### 十元命名规则

- **必须用双字题材词**：如舞台/信仰/家园/守望/王权/压迫/世故/贪念/法律/模具。
- 不可用单字（霜、凉、鉴、幕、渊）。
- 不可用解释性词（执念驱动者、事件触发器）。
