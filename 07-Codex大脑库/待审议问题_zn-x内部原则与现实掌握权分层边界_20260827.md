# 待审议｜zn 内部原则与 x 现实掌握权分层边界

## 1｜待审议命题

在同一明确对象层，`zn` 与 `x` 必须分别取证：

- `x` 回答：哪些具体对象、资源、关系、地盘或权限真实进入主体掌握、调用、处分或排除边界；
- `zn` 回答：什么内部不可轻易让渡的意义/原则，能够在冲突中排序，并保留未来指导资格。

当前跨作品材料支持：

> **“我掌握什么”与“为什么守 / 为什么即使有权也不这样用”不是同一个变量。zn 可以促使主体让渡部分 x，也可以限制已成立 x 的使用方式，或规定关系处分 x 的使用/终止条件；这些变化都不自动消灭 x。**

本文件只到 pending-review，不覆盖 L2 canonical。

## 2｜三部独立作品正向控制

### A｜《三国演义》关羽·挂印封金｜99/98

- zn：对刘备旧盟/旧义保留最终指导资格；
- x：曹赐金银、侯印、人役等具体资源/权限对象真实进入掌握；
- 机制：当部分 x 与 zn 冲突，主体主动让渡一部分 x，zn 继续指导后续行动。

### B｜《水浒传》晁盖·梁山劫掠与江州劫法场｜99/98

- zn：不可因取财、脱险或便利任意伤害不抵抗客商/无关百姓；
- x：梁山人马、劫掠行动、战利品与行动边界真实进入晁盖指挥/处分范围；
- 机制：zn 不要求 x 消失，而是给已成立 x 的使用划出“即使有权也不做”的边界。

### C｜《西游记》唐僧·三打白骨精 / 草寇事件｜99/97

- zn：对人命不可轻率施杀；不能仅因“保护我”就无限授权徒弟对疑似平人行凶；
- x：对孙悟空的师徒处分/约束权限有现实生效证据，包括紧箍咒、留用与逐退；
- 机制：zn 决定关系处分 x 的惩戒、保留与终止条件，即使这会损失强保护者带来的现实安全收益。

三案机制不同，但同一 criterion 下共同支持“内部原则与现实掌握权分层”。

## 3｜现有反向护栏

### A｜《西游记》孙悟空·弃弼马温｜99/98

实际 x 成立并主动退出，但触发高度依赖官阶低、被轻视与地位比较；缺少独立通过 zn 冲突排序和未来指导资格门的内部原则。

因此：

> **放弃 / 失去 x ≠ 自动 zn。**

这条反例防止把“舍弃资源/职位”本身误写成原则证据。

### B｜《红楼梦》贾政·笞宝玉遇贾母真实否决后停止｜99/98

贾政在“父亲训子/当前责打”局部层确有现实可执行处分 `x`；贾母到场后以家内最高现实否决压入同一处分链，贾政认错并停止继续责打。

停止可以由“外部真实否决进入 → 主体服从/承接”完整解释，当前桥段缺少一条独立内部原则，在拿掉外部否决后仍会让贾政主动停止，并跨情境继续限制同一处分权。

因此：

> **x 被限制 / 停止使用 ≠ zn 自动成立。必须区分内部原则自我限权与外部命令、惩罚压力、现实否决造成的限权。**

这条反例不判断贾政整个人物是否存在其他 `zn`，只否定“停止动作本身足以证明 zn 自我限权”。

## 4｜当前可保留的工作规则

1. `x` 成立不要求主体无限制使用它；自我限权可以与真实掌握权共存。
2. `zn` 成立不要求主体先放弃资源；原则可以通过限制、保留、处分或退出条件显影。
3. 让渡 x 只能作为 zn 的压力证据，不能替代 zn 的内部原则、冲突排序与未来指导资格门。
4. 保护/责任/承诺本身不能自动当 x，必须继续查对象是否真实进入掌握/处分边界。
5. 关系处分权属于 x 候选时，必须用实际生效证明，不能用“师父/首领/长辈”等名义身份代替。
6. 主体停止使用已成立 x 时，必须先区分限制来源：内部原则、外部命令/否决、惩罚恐惧、收益策略或临时战术；只有前者经过 zn 独立门才支持 `zn` 自我限权。
