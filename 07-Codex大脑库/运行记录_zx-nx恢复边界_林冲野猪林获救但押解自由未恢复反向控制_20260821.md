# 《水浒传》林冲野猪林获救但继续刺配｜zx↔nx 恢复边界反向控制

## 1｜剧情事实、触发、对象、动作、结果

对象截面只取林冲被判刺配沧州、董超薛霸野猪林欲杀、鲁智深介入救下、随后仍按公文送入沧州牢城营这一连续窗口，不外推林冲整个人物稳定本体。

事实链：

1. 林冲被开封府正式判脊杖、刺面并刺配沧州，董超、薛霸持公文监押前往；其原先可自行决定去留的人身移动边界已经被司法押解切断。
2. 高俅一方另行买通董超、薛霸，要求在野猪林秘密杀害林冲；二人把林冲绑树并准备下手。
3. 鲁智深公开介入，割断绳索、阻止杀害，并持续威慑董超、薛霸，使二人不敢再下杀手。
4. 鲁智深明确选择“直送兄弟到沧州”，而不是解除刺配、公文或合法押解关系；林冲本人也没有因此成为自由身。
5. 鲁智深离开后，董超、薛霸继续押送林冲；到沧州后仍向州衙下公文，林冲被正式收进牢城营。

触发：刺配途中出现非法灭口。

被测试对象必须拆成两个：

- 对象A：林冲是否被秘密杀害，即即时生存结果；
- 对象B：林冲是否仍受刺配、公文和牢城收管约束，即人身移动/合法押解控制。

明确动作：鲁智深阻断杀害、解除野猪林绑缚、护送并威慑公人；但不撤销刺配文书，不解除沧州收管。

结果：对象A被成功救回/保住；对象B没有恢复，林冲仍被押至沧州牢城。

## 2｜zx / nx 主判

### 林冲当前 zx：rejected_as_primary

本窗口中，真正公开压退董超、薛霸并改写野猪林现场结果的是鲁智深，不是林冲自身权能。林冲甚至请求鲁智深不要杀两名公人，但这只是对救援者的一次请求，不构成林冲决定范围扩大。

因此：

`zx_in_lin_chong_narrow_stage: rejected_as_primary`

不能因为“林冲最终活下来”就把结果成功倒算成林冲自身 zx。

### 林冲当前 nx：evidence-locked at rescue relation function

林冲的即时生存结果在野猪林已无法靠自己稳定处理；真正能阻止董超、薛霸杀害的是鲁智深的外部强制能力。林冲接受并依赖这一外部救援关系，故可锁：

`nx_external_rescue_relation_function: evidence-locked`

但必须马上做对象层限制：这个 nx 只解决“活下来/不被秘密杀害”，没有恢复“合法押解下的人身自由”。

## 3｜恢复边界主结论

本轮不是：

```text
x丢失
→ nx外援
→ 同一个x恢复
```

而是：

```text
对象B：原人身移动x
→ 刺配后丢失

对象A：额外生存危机
→ nx鲁智深介入
→ 杀害被阻断

但对象B仍然：
公文押解 → 沧州收管
→ 原x没有恢复
```

因此正式锁：

`nx_rescue_restored_same_x_object: rejected`

`legal_custody_and_mobility_x_restored: false`

这与“施恩借武松夺回快活林”“海瑞经朝廷复故官”不同：那两类正例中，外部 nx 接口直接作用于原本丢失的同一个控制对象，并使其重新进入主体稳定调用边界；本例外援只切断了一个附加的非法杀害结果。

## 4｜关键压力

- 正式司法刺配已经使林冲的人身移动边界退出；
- 高俅另加非法灭口，使生存问题在押解问题之上再次加压；
- 鲁智深能穿透灭口压力，但没有也未尝试穿透正式刺配关系。

压力必须拆层，否则非常容易把“救命成功”误写成“自由恢复”。

## 5｜最近邻排除

### nx vs x恢复

`nx`只说明外部能力/关系被实际调用；要锁`x恢复`，还必须看到同一被测试对象重新进入主体稳定处分或调用边界。

本例没有。

### zx vs 鲁智深代为显权

鲁智深的公开强制介入可在鲁智深角色层锁zx；不能把另一个人的显权倒算成林冲自己的zx。

### nx vs nz

鲁智深与林冲的情义解释为什么救，但不能替代“谁掌握当前解决能力”的木轴事实。

### nx vs xn

鲁智深跟踪、护送有计划邻近；林冲本窗口没有主动搭建持续救援流程。主判仍是外部关系/能力通道，而非林冲的xn。

## 6｜拿掉测试

### 拿掉鲁智深

董超、薛霸已经进入实际杀害动作，林冲没有稳定自行脱身接口；即时生存结果留下明确缺口。

因此鲁智深作为nx救援节点是真功能。

### 拿掉“刺配公文仍继续生效”

如果鲁智深救下林冲后同时使官方公文失效、让董超薛霸失去合法押送资格，并使林冲自由决定去留，那么才可能锁“原人身移动x恢复”。原文恰恰没有。

### 拿掉沧州最终收管结果

即使只看“鲁智深直送到沧州、董薛仍保持公人押解角色”，也已能证明自由没有被明确恢复；沧州牢城正式收管则把该反证进一步锁死。

## 7｜反向测试

真正的`nx → 同对象x恢复`版本应为：

```text
林冲被刺配、失去自由
→ 外部节点取得正式赦免/撤销刺配
→ 董超薛霸失去押解权限
→ 林冲恢复自行决定去留
= nx直接恢复原人身移动x
```

原文不是。

真正的林冲`zx`版本应为：

```text
林冲靠自身公开权能解除押解
→ 董超薛霸与官府无法继续执行
→ 自己的行动决定范围真实扩大
```

原文同样不是。

## 8｜第三因素冻结

冻结：

- 林冲是否懦弱、隐忍；
- 鲁智深是否侠义；
- 高俅是否奸恶；
- 刺配是否冤案；
- 后续林冲上梁山；
- 武力强弱和人物主题。

只问：

1. 哪个对象原本丢失？
2. 外援直接改变的是不是同一个对象？
3. 同一个控制边界是否重新归主体稳定调用？

答案分别是：人身移动自由；不是；没有。

## 9｜稳定本体 / 状态 / 行为 / 关系 / 压力分层

- 稳定本体：不锁。
- 当前状态：林冲受司法押解，原人身移动x退出。
- 行为功能：接受鲁智深外部救援，nx关系功能成立。
- 关系位置：鲁智深掌握当前反灭口强制能力；官府仍掌握合法押解与收管接口。
- 外部压力：司法刺配 + 非法灭口双重压力。

## 10｜严格 zx↔nx 补关系

不锁。

林冲自身zx端在当前窗口没有独立成立，严格补关系第一道门即失败。

`strict_zx_nx_complement_locked: false`

本轮最小纪律：

> 外部 nx 接口成功解决了当前危机，不等于主体之前丢失的那个 x 已经恢复。必须追踪“外援直接改变的是不是同一个被测试对象”。野猪林中，鲁智深恢复/保住的是林冲的生存结果，不是刺配状态下已经丢失的人身移动控制；后者直到沧州仍未恢复。
