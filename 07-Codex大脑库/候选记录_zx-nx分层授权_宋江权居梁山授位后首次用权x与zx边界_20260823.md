# 候选记录｜宋江权居梁山：外部授位后的首次公开用权究竟是 x 还是 zx

## 0｜本轮结论

本轮不推翻旧 99/97 正式案例，但按现行分层授权纪律复核后，`zx` 分类出现真实分叉，因此降为本候选：

> **外部群体真实授予一块此前不存在的新权限时，授权入口可锁 nx；授权完成后该权限已经真实归主体调用，可锁新形成的局部 x。仅凭“第一次公开使用这块新权、组织围绕该授权运行”是否还足以额外锁 zx，当前只有 92% 把握，暂不再锁。**

真正需要区分：

```text
A｜外部授予新权限
→ nx 授权入口
→ 权限真实到位
→ x

B｜主体自己把决定范围推出当前授权边界
→ 外部原节点反对/无法压回
→ 新对象域稳定进入主体处分范围
→ zx
```

宋江第60回明确满足 A；是否满足 B，文本不足 95%。

## 1｜剧情事实

晁盖临终留下条件：捉得射死自己的人，便立为梁山泊主。晁盖死后，林冲、公孙胜、吴用及众头领商议后主动推举宋江。宋江先以晁盖遗言为由拒绝立即居位。吴用随后提出“权且尊临此位”，以后再依遗言处理。宋江接受“权当此位”。

随后宋江确实开始主持山寨事务，改聚义厅为忠义堂、分六寨、调整头领岗位和守备，众人按新安排运行。

## 2｜nx 判断

`nx_succession_entry_relation: evidence-locked`

主位并非宋江先自行宣布取得，而是众头领主动提出、宋江先拒、吴用再给临时承接方案，宋江最终接受。

因此“新主位从何进入主体”这一入口层清楚属于外部授位/推举关系：

```text
主位空缺
→ 众头领提出宋江承接
→ 宋江接受
= nx 授权/承接入口
```

这不意味着宋江稳定人物本体是 nx。

## 3｜x 判断

`x_newly_granted_leader_authority: evidence-locked`

授权一旦完成，宋江已可实际主持山寨、调度头领、重排六寨与守备。这不是空衔。

因此至少可以高置信锁：

> **新授主位已经成为宋江可独立调用的现实局部权限。**

也就是：

```text
外部授位完成
→ 现实处分接口进入主体
→ 主体可以直接使相关决定生效
= x
```

## 4｜zx 为什么降级

旧正式案例把“从原来没有寨主最高权，到获得并首次公开运行”视为 `zx` 位置上升。

但现行分层授权待审议已经形成更严格的邻近纪律：

> **别人把一块真实权限正式交给我，授权完成后优先可解释为 x；只有我继续把决定范围推出原授权边界，才有更强 zx 证据。**

按这一基线，宋江第60回的六寨重排和号令头领都可以解释为：

> **在众头领已经正式交给他的“权居寨主”权限内首次使用新 x。**

目前没有看到第60回这个窄窗口里：

- 众头领明确只授权 A，而宋江又推进到 B；
- 原授权群体对 B 明确反对；
- 宋江仍把 B 做成新的稳定处分接口。

因此：

`zx_from_grant_itself: deferred`

## 5｜关键压力

压力是“晁盖死亡导致最高接口空缺，但遗言又限制正式继承”。

它让三层同时显影：

1. 谁提出新主位承接方向；
2. 新权限是否真实交付；
3. 主体是否又越出交付边界。

前两项清楚，第三项在本窄窗口不清楚。

## 6｜拿掉测试

### 拿掉众头领推举

若宋江自己宣布做寨主，并迫使众人接受，则 `nx` 授位入口消失，`zx` 会明显上升。

### 拿掉六寨重排

只剩“众人推举、宋江接受称号”，则只能证明名位/授权入口，局部 `x` 是否真实形成都会下降。

### 拿掉“越授权边界”要求

若仅以“此前没有此权、现在有了且公开使用”就自动锁 zx，则周瑜、宋江旧案例可以维持；但会与现行“授权后局部 x / 已有权限有效≠扩权”纪律发生直接冲突。

## 7｜反向测试

### 纯授权 x 版本

```text
众头领正式授予寨主权限
→ 宋江在该权限内调度山寨
→ 没有越过授权范围
= nx入口 → x
```

### 真正授权后 zx 版本

```text
众头领只授 A
→ 宋江主动推进到未授权 B
→ 原授权节点明确反对
→ B仍稳定生效
→ 梁山以后按新增接口运行
= zx
```

第60回目前更接近前者。

## 8｜最近邻排除

### x vs zx

`x`：授权完成后，这块主位权限已经归宋江现实调用。

`zx`：必须证明主体又把决定范围推过当前授权基线，而不只是第一次使用新获得的权限。

### nx vs x

`nx` 只解释新主位入口来自外部推举；权限交付后，具体主位处分不应永久继续写成 nx。

### xn vs zx

分六寨、重排岗位有 xn 组织邻近，但流程重组不等于决定范围超过授权边界。

## 9｜第三因素冻结

冻结宋江是否权谋、晁盖遗言道德争议、金圣叹批语、宋江声望、李逵拥戴、后续卢俊义与招安，只看：

- 谁授位；
- 权限是否真实交付；
- 首次用权是否在授权范围内；
- 是否出现越授权边界并稳定生效。
