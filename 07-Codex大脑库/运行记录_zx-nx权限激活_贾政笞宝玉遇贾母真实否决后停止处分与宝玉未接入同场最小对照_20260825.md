# 运行记录｜贾政笞宝玉：局部 x 遇贾母真实否决后转入 nx 约束

## 1｜本轮测试问题

同一《红楼梦》第三十三回已经有“宝玉被外部救援，但宝玉本人未接入 nx 通道”的 99/97 控制。本轮改以贾政为主体，测试同一事件中另一侧：

> 外部上位节点真正说“不”，而主体停止原处分、认罪并沿该上位方向继续时，是否形成当前 nx 关系功能？

这不是重复宝玉案，而是同场最小差异：

```text
宝玉：外部节点替他改变结果，但本人没有承接/续接 → nx 不激活
贾政：外部节点对他的处分方向作出真实否决，他承认并服从 → nx 激活
```

## 2｜剧情事实

第三十三回中，贾政因琪官、金钏等事件震怒，对宝玉施以重责。众门客劝阻无效；王夫人先进入书房，抱住板子劝阻，贾政一度仍坚持继续处分，甚至提出要勒死宝玉。

随后贾母到场，公开斥责贾政下手过重，并以自己要回南京等方式施加家内最高压力。贾政没有继续以父亲身份维持原处分方向，而是叩头认罪，表示以后不再打宝玉；之后在贾母仍怒时也不敢自便，并依其要求退出。

本轮只测试“贾政是否继续笞打/处分宝玉”这一当前对象层，不把贾政整个人物本体锁成 nx。

## 3｜触发、对象、动作、结果

```text
触发：贾母到场并公开否定继续重责
对象：宝玉当前是否继续被贾政重责/处分
原局部权限：贾政作为父亲已在执行家内训子处分
外部上位接口：贾母的家内最高否决位置
明确动作：贾母斥责、要求停止并以离府施压；贾政叩头认罪、承诺不再打、停止处分
结果：原处分链停止，宝玉被移走；贾政不再维持原方向
```

## 4｜zx 检查

本窄阶段 `zx` 排除。

贾政前段打宝玉很强烈，也直接命令小厮执行，但强烈、能命令、身份高都不是 zx 充分条件。

在“父亲训子”这个对象层，贾政原本已经拥有局部家内处分权，前段更多是既有 `x` 被强烈调用；没有证据表明他因此新增了此前不属于自己的决定范围。

贾母到场后，他更没有把自己的权能继续向上扩张、压掉贾母的最终否决位置。相反，他停止并认罪。

因此：

```text
zx_in_narrow_stage = rejected
```

## 5｜nx 检查

本轮当前关系功能 `nx` 高纯成立。

关键不是“贾母年长”或“贾政孝顺”，而是现实权限链：

```text
贾母对当前处分拥有真实上位否决
→ 她的反对发生在结果继续生效以前
→ 反对能够停止/修改同一处分结果
→ 贾政没有绕过该节点继续执行
→ 贾政叩头认罪并接受停止方向
→ 当前处分链按外部上位方向结束
= nx 当前关系功能
```

这符合现行 nx：最终方向/权限在外部，主体不抢最终否决位置，并真实沿既有关系与权限通道续接。

注意：这里锁的是**当前关系功能/状态**，不是“贾政长期没主见”的人物本体。

## 6｜关键压力

关键压力不是“宝玉被打得很惨”本身，而是：

> 贾母把家内最高否决权真实压入当前处分链。

王夫人的劝阻阶段仍存在真实争议，因为贾政一度继续坚持；贾母到场后则形成更干净的现实分界：原处分停止，贾政认罪，不再保持最终方向。

## 7｜拿掉测试

### 7.1 拿掉贾母的真实否决能力

如果贾母只是名义长辈，反对后贾政仍可稳定继续打、结果完全不受影响，则本轮 nx 权限证据显著下降。

原著不是如此：贾母介入后，贾政停止、认罪并退出。

### 7.2 拿掉贾政的承接/服从

如果贾母虽然改变了现场，但贾政本人没有接受、等待、服从或沿其方向继续，则只能证明外部状态改变，不能直接锁主体 nx。

这正是同场宝玉案：宝玉被救，但本人没有激活外部通道，所以 nx 行为被排除。

## 8｜反向测试

若改写为：

```text
贾母明确说不许再打
→ 贾政公开拒绝
→ 继续稳定处分宝玉
→ 贾母无法停止/修改结果
```

则贾母只剩名义位置，当前 nx 应下降，转查贾政既有 x 或新增 zx。

若改写为：

```text
贾母自行救走宝玉
→ 贾政未承认、不服从、不沿其方向续接
```

则更接近“外部结果变化，但主体本人未激活 nx”，与宝玉旧控制同型。

## 9｜最近邻排除

### nx vs x

- 贾政在“父亲训子”局部层原本已有 `x`；
- 但当贾母的更高层真实否决被触发后，当前“是否还能继续处分”的最终方向不再由贾政独占；
- 因此局部 `x` 的存在不排除更高层当前 `nx` 关系约束。

### nx vs xn

本轮核心不是贾政如何安排人、板子、时间或执行流程，而是谁拥有最终停止/继续的现实决定权；所以不以 `xn` 主判。

### nx vs zx

贾政没有压掉贾母的上位否决位置，也没有扩大自己的决定范围；反而沿外部家内权威给出的停止方向结束处分。

## 10｜第三因素冻结

冻结：

- 贾政是否严父；
- 贾母是否偏爱宝玉；
- 宝玉是否该打；
- 王夫人与贾母的亲情强度；
- 琪官、金钏等前史；
- 贾政是否“孝顺”的道德评价。

只保留：

1. 谁在结果继续生效前拥有真实否决；
2. 这个否决能否真的停止/修改同一处分；
3. 贾政是否绕过；
4. 贾政是否接受并沿外部方向结束原处分。

结论仍稳定：当前关系功能 nx 成立。

## 11｜与宝玉旧控制的同场最小差异

```text
同一外部介入：王夫人/贾母改变笞打结果

宝玉作为主体：
没有请求、承接、等待、借用或沿通道续接
→ 外部救援有效 ≠ 宝玉 nx 激活

贾政作为主体：
外部上位节点否决其当前处分
→ 贾政停止、认罪、承认该方向
→ 主体真实进入外部权限约束
→ nx 激活
```

因此本轮支持一条更精确的判别：

> **不能只问“外部节点有没有改变结果”，还必须问“被测试主体与该外部方向之间发生了什么”。外部改变结果 + 主体不承接，不足以锁 nx；外部拥有真实否决 + 主体承认并沿其方向续接，则 nx 关系功能显著成立。**

## 12｜严格补检查

本窄阶段不锁 `zx+nx`，更不锁严格补：

- `zx` 端没有独立过门；
- 前段局部 `x` 与后段 nx 上位约束也不是 `zx↔nx` 两端严格互补。

因此：

```text
strict_zx_nx_complement_locked = false
```
