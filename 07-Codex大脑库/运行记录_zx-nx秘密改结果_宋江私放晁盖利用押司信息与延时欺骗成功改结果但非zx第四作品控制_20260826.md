# 运行记录｜《水浒传》宋江私放晁盖｜秘密改结果成功但非 zx 第四作品控制

## 0｜结论先行

第十八回“宋公明私放晁天王”是高纯的**秘密改结果伪 zx**控制。

宋江得知何涛携正式公文来郓城县捉拿晁盖后，自己决定救晁盖；他没有公开夺取县衙的缉捕处分权，也没有让知县、何涛或官府承认一个新增的“宋江可以决定谁抓谁不抓”的公开接口，而是：

```text
利用押司身份取得案件信息
→ 以程序理由稳住何涛
→ 安排伴当拖住县衙衔接
→ 自己秘密骑马去东溪村报信
→ 让晁盖获得逃走窗口
```

因此：

```yaml
zx_current_state: false
nx_current_relation: false
xn_neighbor: high
x_neighbor: local_information_access_only
classification: secret_result_change_false_zx
```

它把仓库既有“秘密改结果 ≠ 公开扩权”边界从《西游记》《三国演义》《红楼梦》扩展到《水浒传》，形成四大名著完整覆盖。

## 1｜剧情事实、触发、对象、动作、结果

### 事实

何涛受济州府差遣，携实封公文到郓城县，准备捉拿晁盖等人。何涛在茶坊遇到当日值班押司宋江，将案件及晁盖名字告知宋江，并请他协助办理。

宋江得知后，内心明确形成“晁盖若被捕性命便休，我要救他”的方向。

### 明确动作

宋江随后连续做了四件事：

1. 表面附和何涛，称晁盖应受惩治；
2. 以“实封公文须由何涛亲自当厅投下、本官看后才能施行”为理由，让何涛继续等待；
3. 安排伴当守在茶坊门前，如果知县坐衙，就继续安抚何涛，说宋江即来；
4. 自己从后门牵马出城，赶往东溪村给晁盖报信。

### 结果

晁盖因此获得提前逃走的时间窗口。后来正式捕捉到来时，晁盖一方已能转移、逃脱。

本轮只判宋江这一段，不把朱仝、雷横后续放走晁盖倒灌进宋江分类。

---

## 2｜zx 检查

### 2.1 为什么“自己决定救人”还不够

宋江的救人方向确实由自己产生，但现行 zx 还要求：

```text
自身权能公开进入现实
→ 他者 / 秩序围绕主体权能重新反应
→ 主体决定范围、作用位置或凌驾程度真实上升
```

本段缺少这些硬门。

宋江没有公开宣布：

- 晁盖不得捕；
- 何涛不得投文；
- 知县必须服从宋江；
- 宋江取得案件最终处分权。

相反，他必须隐藏真实方向、假装配合、利用程序话术拖延，并在官府不知情时偷偷报信。

### 2.2 结果真的改变，也不能倒推 zx

晁盖最终获得逃走窗口，说明宋江的秘密行动真实改变了局部结果。

但：

> **结果变化 ≠ 决定接口公开扩张。**

原有官府缉捕结构并没有承认宋江取得新的处分位置；官府若知道真实行为，反而会把它视为泄密与妨碍执行。

所以本段优先排除 zx。

---

## 3｜nx 检查

本窄阶段 `nx` 也不成立。

何涛、知县和正式公文确实构成一个既有官府方向：

```text
接受公文
→ 正式立案/发落
→ 差人捉晁盖
```

但宋江没有沿这个外部方向推进；他表面顺从只是欺骗手段，真实行动方向正好与官府缉捕方向相反。

因此不能因为：

- 他是押司；
- 他身处县衙流程；
- 他说了几句程序话；

就判当前 nx。

`nx` 要求主体真实沿外部方向、权限或通道续接；伪装成顺从不等于实际承接。

---

## 4｜最近邻排除

### 4.1 zx vs xn

宋江真正高显影的是方法组织：

```text
拖延何涛
→ 安排伴当接续安抚
→ 自己脱身
→ 骑马报信
```

这是明显的步骤、节点与时序组织，优先检查 `xn`。

本轮不把“方法很有效”升级成 zx。

### 4.2 zx vs x

宋江作为值日押司，确实拥有现实的信息接触与办事位置；何涛也正因为这一既有位置才向他透露案件。

这最多支持：

```text
案件信息接触／局部办事接口
= x 邻近
```

但“能接触信息”不等于“拥有决定晁盖是否被捕的处分权”。

### 4.3 nx vs xn

宋江不是接受外部目标后照流程做事，而是主动重排步骤，让既有流程暂时不能按原节奏运行，所以优先 `xn`，不是 nx。

## 5｜拿掉测试

### 拿掉秘密欺骗与时序组织

只保留宋江“我想救晁盖”的内部目标：

- 不能自动产生逃走窗口；
- 官府流程仍会继续；
- 不能证明 zx。

说明实际结果高度依赖其秘密 `xn` 方法。

### 拿掉公开扩权假设

完全不假设宋江取得任何新增公开处分权，原剧情仍能完整解释：

```text
已有信息接触
+ 秘密拖延
+ 私下报信
→ 晁盖提前获得消息
```

所以 zx 并非解释本段结果的必要变量。

### 拿掉官府外部方向

如果不存在真实缉捕公文与即将落地的捕捉流程，则宋江的“私放”不再有同一测试意义；但这只说明官府流程是外部压力/被绕过对象，不证明宋江沿它形成 nx。

## 6｜反向测试

### 真 zx 版本

若改写为：

```text
宋江公开宣布不准捕晁盖
→ 知县/何涛实际退让
→ 官府缉捕结果因宋江公开权能而停止
→ 宋江成为新的案件决定来源
```

则才明显进入 zx。

### 真 nx 版本

若改写为：

```text
宋江接受何涛的正式方向
→ 按公文流程办理
→ 不改写、不欺骗、不另搭反向路线
```

则当前办事行为才更接近 nx。

原著两者都不是。

## 7｜第三因素冻结

冻结：

- 宋江是否“仗义”；
- 晁盖是否值得救；
- 官府是否合法正义；
- 宋江后来是否上梁山；
- 晁盖最终是否成为梁山首领；
- 读者的忠义评价。

只保留：

```text
谁掌握正式缉捕接口？
宋江是否公开取得新增处分权？
宋江是否真实沿官府方向推进？
具体结果主要通过公开权能还是秘密欺骗/时序组织改变？
```

结论仍不变：秘密改结果成立，zx 与 nx 均不是本窄阶段主判。

## 9｜与现有跨作品边界的关系

仓库此前已有三份同型高纯材料：

1. 《西游记》孙悟空偷桃偷酒偷丹：秘密绕资源权限，结果变化但未取得公开处分权；
2. 《三国演义》周瑜蒋干盗书：诱导曹操误操作，改变曹营人事但未取得曹营处分权；
3. 《红楼梦》王熙凤毒设相思局：秘密设局改变贾瑞结果，但未建立新增公开处分接口。

宋江这一例加入后，四大名著全部出现同类边界：

> **秘密绕权、欺骗、时序组织或让原权限主体在不知情状态下失去结果，并不自动构成 zx。zx 仍必须单独证明主体自身权能公开进入现实，并形成新增决定位置。**

同时本例增加一个此前三例不完全相同的机制：

> **主体可以利用自己已有的正式职位/信息接触 `x`，去秘密破坏该职位所属系统的执行结果；“从系统内部成功改结果”仍不能自动升级 zx。**
