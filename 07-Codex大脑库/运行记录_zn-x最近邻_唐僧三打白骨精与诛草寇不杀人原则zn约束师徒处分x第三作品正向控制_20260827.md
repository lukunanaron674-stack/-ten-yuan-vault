# 唐僧三打白骨精 / 草寇事件｜不杀人原则 zn 约束师徒处分 x｜第三作品正向控制

## 1｜被测对象层

只测试“唐僧对徒弟孙悟空的现实师徒处分权，以及什么内部原则指导这项处分权如何使用”。不把唐僧整个人物贴成 zn/x，也不把取经主题、僧人身份或佛教标签当证据。

## 2｜剧情事实

第27回白骨精连续变化成人形，孙悟空多次出手。唐僧把这些对象理解为平人，并明确以“出家人行善”“不可行凶伤人”一类判断反复念紧箍咒、警告并最终写贬书逐走孙悟空。

第56-57回草寇事件提供跨情境复验：孙悟空打死草寇后，唐僧再次因为“人身不应轻伤性命”的原则责罚并逐走悟空；观音随后也明确概括唐三藏“一心秉善为僧，决不轻伤性命”。

可观察结果：同一原则并非只在白骨精一次误判中出现，而是在不同对象、不同阶段重复进入对孙悟空的关系处分判断。

## 3｜zn 证据

被测原则：

> 对人命不可轻率施杀；取经关系不能以“保护我”为理由无限授权徒弟对疑似平人行凶。

该原则通过当前 zn 硬门：

- 不是外部奖励或称号触发；
- 与“保留最强保护者孙悟空”这一现实利益发生冲突；
- 即使逐走悟空会显著降低自身安全，唐僧仍让该原则排序选择；
- 第27回与第56-57回跨情境重复出现，具有未来调用资格；
- 原则边界并非“任何杀戮都不允许”，文本区分妖魔与人身，说明它有对象边界而非空泛善良标签。

结论：当前原则对象层 zn 成立。

## 4｜x 证据

被测 x 不是“孙悟空归唐僧所有”，而是“师徒关系中的现实处分/约束权限”。

可观察证据：

- 唐僧掌握紧箍咒的现实约束入口，并能实际使孙悟空承受约束；
- 能决定警告、继续留队、逐走；
- 第27回最终写出贬书，现实终止当前师徒同行关系；
- 第56-57回再次使用同类处分关系，说明不是一次名义身份。

因此在“师徒关系处分权限”这一窄对象层，x 成立。

## 5｜zn vs x 最小边界

本例不是“原则存在，所以 x 消失”。相反：

```text
x：唐僧真实拥有并使用师徒关系处分/约束权
zn：什么原则决定这项权不能只按安全收益、战力收益来使用
```

与已有两份正向控制形成第三种机制：

- 关羽：zn 促使让渡部分 x；
- 晁盖：zn 限制既有武力/处分 x 的使用方式；
- 唐僧：zn 决定关系处分 x 的保留、惩戒与终止条件。

## 6｜拿掉测试

拿掉 zn 原则：保留师父身份、紧箍咒和逐徒权限，唐僧仍有 x，但“为何宁可损失最强保护者也反复处分/逐走悟空”失去稳定内部排序解释。

拿掉 x：保留不轻伤人命原则，原则仍可作为内部判断存在，但唐僧失去对孙悟空的现实关系处分落点。

两端可独立拆分，因此支持最近邻分离与当前 zn+x 共现；本轮不做 strict complement 双向缺口闭锁。

## 7｜反向测试

若唐僧只是因为八戒一句话、别人评价或一时生气处罚悟空，且后续没有跨情境重复原则，则 zn 应下降。

若唐僧只有“师父”名义，却不能实际念咒、留用或逐退悟空，则 x 应下降。

原著两种反向均不成立。

## 8｜最近邻排除

- zn vs z：僧人身份、外部“慈悲”评价不是本轮支柱；真正证据是原则在高代价冲突中持续排序。
- zn vs xn：如何赶路、谁打妖怪属于流程；不能解释为什么某类杀人行为构成不可接受边界。
- x vs nx：本轮处分不需要逐次向观音/朝廷申请，当前关系处分有直接生效证据。
- x vs zx：反复使用已形成的师徒处分权优先是 x；不把每次念咒/逐徒都重复算扩权。

## 9｜第三因素冻结

冻结：佛教主题、唐僧善恶评价、白骨精真实身份、八戒挑拨、孙悟空是否更强、后续是否重新收徒。

保留：原则是否明确、是否与现实安全收益冲突、是否进入处分排序、是否跨情境重复、处分权是否真实生效。

结论不变。
