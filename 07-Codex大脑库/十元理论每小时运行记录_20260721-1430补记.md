## 3. 端点、变量、阶段与体量

### 源端点 zn

必须在没有奖励、名声、认可和结果保证时，主体仍判断某人、某事或某段意义不能被抛下。

### 目标端点 n

必须出现真实承载：对象进入主体或结构内部，被允许停留，其负荷被持续处理，而不是一次象征动作、转交或推出。

### 被改变变量

- “不能推出去”的对象范围；
- 愿意接收的对象范围；
- 接入后持续承担的时间；
- 是否允许对象进入自身生活、空间或共同体；
- 对象是否从外部议题变成内部负荷；
- 是否形成接收、停留、处理的闭环。

### 成立阶段

```text
zn 已确定某对象不能被放弃
→ 主体把该对象纳入自身承接范围
→ 接收与处理跨时间反复成立
→ n 的承载边界或承载能力上升
```

### 关系体量

- 低体量：一次明确接手，只能作弱证据；
- 中体量：持续接纳同一对象并承担照护、隐蔽或后果；
- 高体量：承接边界稳定扩大，形成可重复接收和跨时间处理负荷的结构。

### 显影条件

对象必须真的进入内部；主体没有立即外包或推出；承载持续；拿掉 zn 后承接范围会明显缩小。

## 4. 候选机制

### 候选 A：意义扩大承接边界

```text
zn：这件事不能被丢下
→ 主体重新划定什么必须由自己接住
→ 原本可拒绝、推出或视为外部的对象进入承担范围
→ 持续接收与处理形成
→ n 上升
```

理论后果：若成立，`zn生n` 的直接变量不是建筑出现，而是不可放弃之物进入承接范围。关系可先限定在关系层或结构启动层，不自动生成成熟共同体。

### 候选 B：zn 只提供理由，zx/xn/x 才形成 n

```text
zn 提供“应该接住”的理由
→ zx 公开推进、取得或守住空间
→ xn 排期、分工、记录和维持
→ x 提供资源、权限和准入边界
→ n 最终形成
```

理论后果：若 B 更准确，母行只保留几何压缩，具体链条必须写 `zn→zx/xn/x→n`，不能把意义题材直接写成容器生成。

### 候选 C：共同意义聚集自动形成共同体

继续排除。聚集可能只是一次集会、号召、共同认可或情绪共振；没有接收、停留、持续处理和抗崩能力，就没有 n。

## 5. 正例候选

### 《卢旺达饭店》保罗与进入酒店的难民

- 阶段：酒店由商业接待空间转为接收、隐藏、供给并持续承担难民风险的阶段；
- zn：保罗逐渐确认眼前的人不能被交出去等死；
- n：难民进入酒店内部，房间、食物、秩序与风险被持续承担；
- 支持：意义判断改变了谁能被推出去；
- 限制：经理权限 x、谈判与公开推进 zx、物资和名单 xn 均为强第三因素。

结论：支持候选 A 可辨认，不足以证明 A 独立生成 n。

### 《偷书贼》汉斯、罗莎与马克斯

- 阶段：家庭决定长期隐藏并照护马克斯；
- zn：不能把马克斯交给迫害体系；
- n：马克斯进入家庭内部，被长期隐藏、供给、照护，家庭承担持续风险；
- 支持：建筑可替换，目标变量仍是家庭承接边界扩大；
- 限制：隐蔽规则 xn 与家庭资源、空间权限 x 仍是重要中介。

结论：比“建教堂”纯，但仍不能证明 zn 对 n 的普遍直接生成效力。

### 无统一领袖的长期遗属照护点

悼念群体因“遇难者不能被遗忘、遗属不能被独自留下”，逐渐形成固定接收遗属、保存资料、提供休息与陪伴的位置。

结论：作为结构模型支持 A；缺少具体人物文本，不能单独越过95%。

## 6. 反例

1. 政府按行政流程建设纪念馆，主要是 xn/zx；
2. 一次宗教集会，只证明意义与场景共现；
3. 因声誉压力开放避难所，优先检查 z/x并z；
4. 领袖命令成员收留难民，优先检查 zx/nx；
5. 商业旅馆因利润接待客人，可以有 n，但没有 zn 源端点；
6. 只发表“应该帮助”的言论，没有对象进入承担范围；
7. 法律义务监护，拿掉制度后不再接收，主要是 xn；
8. 一次性捐款或转交专业机构，没有形成自身持续承载。

## 7. 最近邻排除

- 与 `zn生zx`：后者改变公开推进、号召与权能范围；本关系只观察承接边界；
- 与 `n生xn`：后者是既有承载为了持续而提炼规则；本关系要求意义先改变谁必须被接住；
- 与 `zn补x`：后者为已有掌握边界定向，或让意义获得资源落点；不要求对象进入内部承载；
- 与普通善良：一次心软不具备无奖励意义与跨时间处理闭环；
- 与 `x/n` 共现：拥有房屋、资源或准入权不等于真实承载。

## 8. 拿掉测试

1. 拿掉 zn 后，如果仍因商业、行政、亲属义务同样接收，则不依赖本关系；
2. 拿掉 n，只剩信念、捐款或号召，目标端点消失；
3. 拿掉 zx 后仍自发接住对象，才支持直接机制；
4. 拿掉成熟 xn 时，承接若已经开始可支持 A，但长期稳定仍可能依赖 xn；
5. 拿掉 x 的资源和产权后，仍通过生活与风险承担接住对象，才不只是资源掌握；
6. 拿掉建筑后承接仍成立，说明建筑只是场景；
7. 若对象只是被转交给另一个结构，主体自身 n 没有生成。

两个具体人物候选仍未通过全部拿掉测试。

## 9. 反向测试

```text
zn 生 n：
意义先改变承接边界
→ 对象进入内部并被持续处理

n 生 zn：
长期共同承载先发生
→ “不能放弃”逐渐沉淀为内部意义
```

两者可以形成反馈，但不能因最终同时出现意义与共同体就互相代证。

## 10. 动态链后果

候选 A：

```text
这件事不能被丢下
→ 它不再只是世界外部的问题
→ 它落到我这里
→ 我允许它停留并持续处理其负荷
```

候选 B：

```text
意义提出方向
→ 权能、组织与资源把方向变成现实结构
→ n 才形成
```

关系改变的是“什么必须进入我方承担范围”，不机械生成建筑、制度、组织成功、永久稳定或公共权能。
