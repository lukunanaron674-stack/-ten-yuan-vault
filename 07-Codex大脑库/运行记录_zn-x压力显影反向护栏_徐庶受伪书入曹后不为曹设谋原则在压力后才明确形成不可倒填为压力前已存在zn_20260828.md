# 运行记录｜徐庶入曹：压力之后才明确形成的“不为曹设谋”原则，不得倒填成压力之前已存在、只是被遮蔽的 zn

## 1｜本轮问题

本轮先按 P0 搜索 strict `zn↔x` 正例，但现有候选仍不能同时通过 `zn→x` 与 `x→zn` 的不可替代双向缺口，因此不降低 strict 强门。

转入 P8 后，选择徐庶“伪书召母→离刘入曹→徐母死→终身不为曹设谋”桥段，原本测试：

> **它能否成为第二份 pressure-display 正例：压力只封住旧 `zn` 的行动表达，压力解除后原 `zn` 按原硬门复位？**

结论：**不能。**

原因不是事实弱，而是时间顺序不允许把后来的原则倒填到压力之前。

因此本轮正式锁为 pressure-display 第一份反向护栏：

> **压力之后才明确形成 / 重定向的原则，不得被回写成压力之前已经成立、只是暂时无法表达的 `zn`。**

## 2｜current canonical

### `zn`

依 `zn_准度卡_v0.1`：

> 主体内部一项不可轻易让渡的意义或原则，必须能在无奖励 / 认可时进入判断，在冲突中影响排序，并跨阶段保留未来调用资格。

pressure-display 因而至少要求：

```text
压力前：同一 zn 已独立成立
压力中：原则资格仍在，只是当前最强表达窗口被封
压力后：同一 zn 按原硬判据重新出现
```

若“压力后”的原则内容本身发生新增、重定向或边界重写，就不能自动称为“原 zn 复位”。

## 3｜剧情事实链

### 阶段 A｜第36回：徐庶在刘备侧真实谋划，曹操通过其母制造外部压力

徐庶此前作为刘备谋士，已经真实参与军事谋划并取得战果。

曹操一方利用徐庶至孝，先控制徐母，再伪造徐母书信，制造“母亲需要自己前往曹地”的现实压力。

徐庶收到书信后选择离开刘备前往曹营。

这一阶段足以证明：

```text
外部压力真实改变当前行动路径 = true
```

但它**不足以证明**：

```text
“不为曹操设一谋”这一具体 zn
在压力前已经成立 = true
```

### 阶段 B｜徐母死后：新的明确原则边界出现

徐庶到曹后，徐母因其受骗离刘而愤怒，随后自尽。

之后徐庶形成非常明确的新边界：

> 身虽在曹，不为曹操设谋。

第41回曹操派徐庶去劝降刘备时，徐庶反而向刘备说明曹军真实进攻态势，并明确表示自己虽身在曹营，但不会为曹操谋划。

这一节点第一次给出高纯、可跨阶段调用的“不为曹设谋”原则。

### 阶段 C｜第48回：该原则继续跨阶段调用

赤壁前，徐庶识破庞统连环计，却明确表示自己感刘备厚恩、从未忘报，而且已经说过终身不为曹操设谋，因此不会揭破庞统计策；他只求自保脱离即将到来的兵败风险。

这说明：

```text
徐母死后形成的“不为曹设谋”原则
→ 跨阶段保留未来调用资格
→ 在现实风险中继续影响选择
```

因此**压力后 `zn` 的成立本身很强**。

但这仍不能解决 pressure-display 的时间门。

## 4｜为什么不能计 pressure-display 正例

真正需要证明的是：

```text
压力前已成立的同一 zn
→ 压力中仅表达受阻
→ 压力后按原判据复位
```

徐庶本例实际更接近：

```text
压力前：
为刘备效力 / 感知遇之恩等关系事实存在
但“不为曹设谋”这一具体原则尚未被独立锁定

压力进入：
伪书 / 母亲压力改变行动路径，徐庶离刘入曹

压力后：
徐母死亡 + 受骗事实进入
→ 原关系意义发生重定向
→ “终身不为曹设谋”成为新的明确原则边界

后续：
该新边界稳定跨阶段调用
```

因此不能写成：

```text
“不为曹设谋 zn”
压力前已成立
只是被伪书暂时遮蔽
后来恢复
```

这属于**时间倒灌**。

## 5｜本轮锁定的反误判纪律

### 5.1 压力后的稳定原则 ≠ 压力前已经存在的同一原则

后续原则即使非常稳定、非常高纯，也只能证明：

```text
后续 zn = 成立
```

不能自动证明：

```text
压力前同一 zn = 已成立
```

### 5.2 关系连续 ≠ 原则内容完全相同

徐庶对刘备有知遇关系、旧情与不忘报答，可以作为后续原则形成的重要来源。

但：

```text
感刘备厚恩
≠
压力前已经形成“终身不为曹设谋”这一同内容 zn
```

pressure-display 必须比较**同一可命名原则**，不能只靠“人物看起来还是忠于同一边”来偷换内容。

### 5.3 pressure-display 与 lifecycle / principle-formation 必须分账

本例更适合描述为：

```text
外压改变当前路径
+
后续重大事件使原则边界重新明确
+
新 zn 跨阶段稳定
```

它可以未来进入“原则形成 / 改写 / 生命周期”研究，但本轮不重复增加 lifecycle 统计。

## 6｜拿掉测试

### 拿掉徐母死亡与受骗后的重定向节点

若只保留：

```text
伪书压力
→ 徐庶离刘入曹
```

现有证据不足以锁：

> “终身不为曹设谋”已经在压力前拥有未来调用资格。

因此 pressure-display 正例失败。

### 拿掉后续第41 / 48回复验

则“不为曹设谋”原则的跨阶段未来调用证据下降，也不能把它稳定锁成高纯 `zn`。

这说明：

- 后续原则成立很强；
- 但它的**成立时点**不能被提前。

## 7｜反向测试

要让类似案例真正成为 pressure-display 正例，必须出现：

```text
压力前
主体已经明确声明 / 多次执行原则 P
+
P 已通过无奖励、冲突排序、未来调用门

压力中
外部条件只阻断 P 的直接行动表达
但 P 的判断标准仍明确保留

压力解除
主体重新按同一 P、同一边界、同一硬门行动
```

若压力后出现的是：

```text
P2 = 新原则 / 新边界 / 重定向原则
```

则只能研究 P1→P2 的形成或生命周期，不能写作 P1 pressure-display 复位。

## 8｜最近邻排除

### `zn vs z`

“不为曹设谋”后续并不依赖曹操认可；第41、48回甚至在曹方现实位置中反向限制自己，因此后续 `zn` 可以成立。

### `zn vs nx`

“人身在曹营 / 接受曹方差遣入口”属于关系或任务通道问题，不能回答内部原则到底何时形成。

### `zn vs xn`

第48回设计借口离开曹军属于流程策略，解释“怎么避祸”，不能替代“不为曹设谋”的原则内容。

### pressure-display vs lifecycle

本轮不锁“旧 zn 被遮蔽后复位”，也不直接锁“旧 zn 已退出”。真正确定的是：**压力前没有足够证据证明后来这个同内容原则已经成立，因此 pressure-display 的前置门不满足。**

## 9｜第三因素冻结

冻结：

- “徐庶进曹营，一言不发”的后世歇后语；
- 正史徐庶是否真的完全不为曹谋；
- 刘备 / 曹操的道德评价；
- 徐母的伦理评价；
- 电视剧改编。

只保留《三国演义》文本内：

```text
压力前原则内容是否已经独立过门
→ 压力是否改变行动路径
→ 后续原则内容是否新增 / 重定向
→ 后续原则是否跨阶段稳定
```

结论不变。

## 10｜对象层

- 曹营职位或军马是否形成 `x`；
- 徐庶所有对刘关系的统一标签。
