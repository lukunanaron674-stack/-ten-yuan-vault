# 运行记录｜诸葛亮博望坡：预设敌方反应可计入主体 xn

## 1｜剧情事实

刘备把剑印交给诸葛亮后，诸葛亮统一部署博望坡战术：关羽、张飞分别伏于豫山、安林并等待火起后攻击粮草；关平、刘封携引火之物等待指定时点；赵云担任前部，明确要求“不要赢，只要输”；刘备自引后援，见火后再回军掩杀。

实战中赵云数合诈败，夏侯惇追赶；赵云退十余里后再战再退。韩浩已明确警告“赵云诱敌，恐有埋伏”，夏侯惇仍继续追入博望坡。刘备随后再退，使曹军继续深入；待曹军进入狭窄、芦苇密布区域，预置火攻与伏兵按原结构发动，曹军大败。

## 2｜最小结构

```text
主体预设：
赵云诈败
→ 诱发夏侯惇追击
→ 刘备再退继续加深追击
→ 敌军进入博望坡火攻区
→ 预置火攻节点启动
→ 关羽 / 张飞等伏兵接续

敌方追击不是方案之外的偶然后果，
而是主体主动设计并继续利用的中间节点。
```

## 3｜xn 判断

本阶段 `xn_subject_structural_rewrite: evidence-locked`。

关键不只是“诸葛亮预测敌人会追”，而是：

- 诱敌动作由主体预设；
- 敌方追击是后续火攻成立的必要过渡节点；
- 主体提前配置赵云、刘备、关平、刘封、关羽、张飞的不同接口；
- 敌方进入特定空间以后，后续节点按预设继续触发；
- 整套方案的成功条件本来就包含“让夏侯惇继续追入”。

因此，虽然“追击”这个动作物理上由夏侯惇完成，它仍可以合法计入诸葛亮 xn 的运行结构。

## 4｜nx 判断

在权限入口层，诸葛亮先请求刘备交付剑印，以确保关羽、张飞等将服从军令，因此存在 `nx_authority_entry_relation: present_but_not_primary`：执行权的正式组织接口来自刘备。

但在本轮被测试的“博望坡方案骨架由谁生成”对象层，诸葛亮不是沿刘备或别人既有方案续接，而是自行配置节点、资源、人员、诱敌条件与触发时机，所以该运行层不以 nx 为主判。

## 5｜zx 判断

本窄阶段 `zx_in_narrow_stage: rejected_as_primary`。

诸葛亮确实公开发令并让军队围绕方案运行，但本轮没有证明他进一步突破刘备已经交付的军师/剑印权限边界，取得更高或更广的新增处分范围。强控制与巨大胜果不能单独替代 zx 的扩权门槛。

## 6｜拿掉测试

### 拿掉敌方追击节点

若夏侯惇识破诱敌并停止追击，后续预置火攻与伏击结构不能按原方案自然进入目标位置。说明敌方反应是该方案的真实结构节点，而非事后装饰。

### 拿掉主体的预设与接续

若赵云只是偶然败走、夏侯惇偶然追击，而诸葛亮此前没有把“诈败→追入→火攻”配置进方案，也没有下游节点接续，那么敌方追击只能算外部反应传播，不能倒算主体 xn。

## 7｜反向测试

真正的非 xn 外部反应型：

```text
主体只做一次动作
→ 对手自行产生多层调整
→ 主体没有预设该反应
→ 也没有利用该反应进入后续节点
```

这与关羽拒婚、李逵扯诏、探春抄检三例同型，应继续排除主体 xn 结构传播。

真正的当前正向型：

```text
主体预设诱导动作
→ 对方按预期反应
→ 该反应是预设中间节点
→ 主体继续利用该节点触发后续资源 / 协同 / 成功条件
= 外部反应可计入主体 xn
```

## 8｜最近邻排除

- `nx`：剑印/军令合法接口来自刘备，只解释权限入口，不解释方案是谁搭建。
- `x`：获得剑印后的既有局部军令调用可以转查 x，但本轮核心是方案结构设计。
- `zx`：公开指挥不等于权限边界进一步扩张。
- `z`：关键节点与触发时机虽有收束成分，但整体是多节点、多资源、多协同的主动运行编排，xn 更强。

## 9｜第三因素冻结

冻结诸葛亮“神机妙算”的人物评价、夏侯惇轻敌、关张是否服气、最终胜负以及历史真实性。只保留：主体是否预设对手反应、是否把该反应作为后续节点、是否继续利用该节点组织资源与协同。

## 10｜结论

高置信锁定：

> **外部反应并非天然不能计入主体 xn。若主体事先设计诱导条件，把对方反应作为自己方案中的预设中间节点，并继续利用该反应触发下游资源、协同或成功条件，则该外部反应可以计入主体 xn 的结构传播。**

这与“对手/上级自行反应，而主体没有预设或接续”的三部负控制形成直接最小差异。
