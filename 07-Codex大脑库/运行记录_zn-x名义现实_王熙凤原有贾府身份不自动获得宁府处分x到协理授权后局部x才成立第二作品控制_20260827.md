# 王熙凤协理宁国府｜名义身份不自动生成宁府现实 x 的第二作品控制

## 0｜本轮目的

只测试火轴当前尚未成熟的窄边界：

> **人物原有家族身份、管家声望、能力认可或跨府亲属位置，是否足以让“宁国府具体日常处分/调用权限”自动成为其现实 `x`？**

结论：不足。必须等被测对象层发生真实授权、接管，并看到决定可直接生效，才锁局部 `x`。

本轮不重判王熙凤整体人物本体，不重判整个宁府所有重要事项是否全部内化，也不把本例计入 pure-x、zn+x 或 strict complement。

## 1｜剧情事实：同一人物、相邻阶段、只改变现实接管

### 阶段 A｜协理授权以前

王熙凤在荣国府已有稳定家族身份、当家经验和办事声望，也属于荣宁两府亲族网络中的高可见人物。

但被测对象层是：

> **宁国府丧事期间的具体日常资源调用、人员管理与纪律处分。**

在贾珍正式请托、王夫人放行、宁国府对牌交付以前，没有证据表明凤姐可仅凭既有身份，直接对宁国府人员作出同样能立即生效的日常处分决定。

因此本轮只锁：

```text
existing_family_status = true
existing_reputation_and_management_skill = true
ningguo_daily_disposition_x_before_delegation = false_or_not_established
```

不是说凤姐“什么权都没有”，而是禁止从别的对象层既有权力倒灌到本轮宁国府具体处分对象层。

### 阶段 B｜协理授权进入

第13回，贾珍明确请凤姐协理宁国府，王夫人放行，贾珍把宁国府对牌交给凤姐，并给出很宽的日常资源调用口径：所需可凭对牌取用，不必逐项问他。

同时，王夫人保留“有了事问哥哥嫂子”的上位提醒。因此本轮只测试**局部日常处分/调用 x 是否成立**，不把它扩大成“整个宁府全部权限已经完全内化”。

### 阶段 C｜局部现实 x 被实际拨动

第14回，迟到媳妇被传到凤姐面前。凤姐没有先找贾珍、尤氏或王夫人逐次批准，而是直接决定：

- 打二十板；
- 革一月银米。

执行者立即照办，之后才回来回覆；宁府众人随后按新纪律运行。

这给出了比“拿到对牌”更硬的 `x` 证据：

```text
明确对象：宁府当前迟到处分
主体：王熙凤
权限类型：处罚 / 削减银米 / 日常纪律处分
事前逐次批准：未发生
现实结果：决定直接执行并影响后续组织行为
→ local_ningguo_disposition_x = true
```

## 2｜x 证据

current canonical 要求 `x` 不是头衔、视觉或一次接触，而是对象真实进入主体占有、使用、调配、调用、处分、否决或排除边界。

本例局部 `x` 的最硬证据不是“凤姐很能干”“贾珍信任她”“对牌在手”，而是：

> **具体处分决定无需重新逐次请示即可生效。**

所以当前窄对象层：

```text
x_current = true
x_object_layer = 宁国府丧事期间的局部日常人员纪律处分
```

## 3｜zn 证据

本轮不锁 `zn`。

“好强、爱揽事、要把事办好、维持秩序”都不足以独立证明某项不可轻易让渡的内部原则通过：

- 无奖励/认可仍进入判断；
- 冲突排序；
- 跨阶段未来调用资格；
- 明确边界与让渡代价。

因此：

```text
zn_from_management_identity = false
zn_from_competence_or_reputation = false
stable_zn_essence_locked = false
```

## 4｜关键本体变量

本轮真正测试的不是“她是不是管家”，而是：

> **一个被测权限对象，什么时候从“别人知道你能办事 / 你有家族身份”变成“现实归你直接处分”？**

最小变量是：

```text
名义身份 / 声望 / 亲属网络
→ 不足

真实授权 + 对象层接管 + 直接生效
→ 支持现实 x
```

## 5｜拿掉测试

### 拿掉家族身份与声望

只要仍保留：

```text
明确授权
+
真实接管
+
同类日常处分可直接生效
```

该局部 `x` 仍可成立。

说明名义身份不是现实 `x` 的必要条件。

### 拿掉真实授权与直接生效

只保留“凤姐是琏二奶奶 / 会管家 / 宁府人认识她 / 贾珍觉得她能干”，则不足以证明宁府迟到处分已经归她直接掌握。

说明名义位置也不是现实 `x` 的充分条件。

## 6｜反向测试

如果文本改成：

```text
凤姐虽被请来协理
→ 每一次处罚都必须先报贾珍批准
→ 贾珍可逐次说不
→ 未批准前决定不能生效
```

则被测局部日常处分 `x` 会明显下降，应重新检查代理授权 / nx 等最近邻。

原著第14回的迟到处分并不是这种结构。

## 7｜最近邻排除

### x vs nx

- 授权入口来自外部，不妨碍授权后某一窄对象层形成局部 `x`；
- 任务来源与当前处分归属必须分层；
- “整个宁府重要事项是否仍保留上位否决”继续 deferred，不能倒灌本轮局部 `x`。

### x vs xn

凤姐自行分班、点卯、设责任、安排时序可有 `xn`；但 `xn` 回答“怎样运行”，本轮 `x` 回答“处罚决定是否现实归她直接处分”。

### x vs zx

处罚成功只能说明局部有权；是否越过既有授权边界形成新的公开扩权，要另证，不能把一次局部处分重复记成 `zx`。

### x vs z / 名义身份

别人承认凤姐能干、家族位置高、称呼她为当家人，都不能替代现实处分的直接生效证据。

## 8｜第三因素冻结

冻结：

- 凤姐性格强势；
- 贾珍对她的信任；
- 她在荣国府的声望；
- 丧礼规模；
- 宁府众人怕不怕她；
- 后续铁槛寺等情节。

只保留：

```text
被测对象层是什么？
授权前是否已能直接处分？
授权后是否真实接管？
决定是否能不经逐次批准直接生效？
```

结论不变。

### 《红楼梦》王熙凤

```text

→ 宁府具体日常处分 x 不自动成立

协理授权 + 对牌接管 + 第14回处分直接生效
→ 局部宁府处分 x on
```

两案共同支持：

> **名义身份、外部承认、声望或高位置不能替代被测对象层的现实掌握证据。现实 `x` 必须看到对象真正进入主体调用、管理、处分或排除边界。**

二者机制不同但 criterion 相同，因此本例计为第二独立作品控制。
