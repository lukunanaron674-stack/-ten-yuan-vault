# 待审议｜nx 任务层同人相邻 off→on 激活开关边界

## 1｜问题

现行 nx 正本要求：

```text
方向、权限或解决通道已经存在
+ 主体不占最终决定位置
+ 主体真实沿外部安排、关系或通道推进
→ nx
```

三部独立作品现在进一步给出一个更窄的相邻开关问题：

> **同一人物、同一长期组织/关系环境基本不变时，某一具体任务层的 nx 是否只有在“任务进入当前行动链 + 主体真实承接”后才从 off 切到 on？**

本文件只提出待审议边界，不修改正本。

## 2｜三部作品控制

### A｜《西游记》孙悟空

```text
齐天大圣空衔
→ 天庭体系、名位、府署都存在
→ 但无当前具体职事
→ 被测任务层 nx = off

权管蟠桃园
→ 玉帝明确给出园务任务
→ 孙悟空谢恩、入园查勘并承接执行
→ 被测任务层 nx = on
```

最小差异：长期天庭关系基本不变，只切换当前任务是否进入并被承接。

### B｜《红楼梦》周瑞家的

```text
回王夫人话结束后方欲退出
→ 贾府长期关系仍在
→ 宫花任务尚未出现
→ 宫花任务层 nx = off

薛姨妈临时交十二枝宫花
→ 明确对象与数量
→ 周瑞家的接匣并逐处送达
→ 宫花任务层 nx = on
```

最小差异：人物、关系网络和地点连续，只新增一项明确任务并发生承接。

### C｜《水浒传》秦明

```text
青州兵马总管身份既存
→ 官职、组织关系、兵马入口都存在
→ 清风山军务尚未进入行动链
→ 清风山任务层 nx = off

慕容知府因清风寨告急召见
→ 黄信申状进入军政链
→ 秦明明确承接并点兵出征
→ 清风山任务层 nx = on
```

最小差异：同一官职和组织位置持续存在，只切换当前军务是否真实进入并被承接。

## 3｜第一份反向护栏｜《红楼梦》鸳鸯抗婚

本例专门检查：

> **外部方向已经明确发出，甚至伴随高压威逼时，是否会仅凭“方向出现”就自动把 nx 切到 on？**

事实链：

```text
贾赦要纳鸳鸯为妾
→ 经邢夫人、兄嫂反复转达
→ 利诱 + 威胁都已明确
→ 外部婚姻方向已经真实进入关系场

但鸳鸯：
→ 咬定不愿意
→ 不接受姨娘方向
→ 不沿该关系继续
→ 到贾母前公开誓绝并剪发明志
```

因此：

```text
external_direction_present = true
subject_actual_acceptance = false
subject_actual_continuation = false
current_nx_relation_active = false
```

该护栏支持：

> **任务/方向发出 ≠ 任务/方向已经接入主体行动链。nx 从 off 切到 on 仍需主体真实承接与续接。高压力、身份关系、利诱与命令存在都不能替代“接入”。**

本例不增加 `cross_work_count`；其作用是给现有三作品正向开关模型补反向边界。

## 4｜当前最窄候选纪律

```text
身份 / 职位 / 组织关系 / 外部接口长期存在
→ 只能证明潜在关系位置与可用通道存在
→ 不能自动给每个尚未出现的任务对象层追挂 nx

明确任务 / 方向 / 权限过程进入当前行动链
+ 主体真实接受、等待、请求、借用、服从、承接或沿流程推进
→ 该任务对象层 nx 从 off 切到 on

明确任务 / 方向已经发出
但主体拒绝承接、不沿该方向续接
→ 不能只凭“方向已出现”判 nx on
```

这不是说 nx 必须“接命令”；求人、借力、许可、专业通道等仍可形成其他类型 nx。这里只讨论“已有组织/关系 + 当前任务/方向层”的激活边界。

## 5｜最近邻与护栏

### 5.1 不能用身份直判

```text
人在组织里
有上级
有职位
有待遇
有长期关系
```

都不能单独证明某个当前任务层 nx 已激活。

### 5.2 任务发出 ≠ 任务已接入

外部任务已经提出，但主体拒绝、改写最高方向、切走另一通道，仍需重新判断 nx；不能只凭“命令发出了”锁定。

鸳鸯护栏进一步证明：即使外部方向已经非常明确，并伴随高压力，只要主体没有真实承接与续接，当前对象层 nx 仍可保持 off。

### 5.3 nx vs xn

外部给上位任务，可以成立 nx；主体在任务内部自行搭人员、资源、节点、时序和流程，可同时形成局部 xn。

因此：

```text
任务层 nx 激活
≠
整段纯 nx
```

### 5.4 nx vs x

任务承接后，局部资源/权限可能逐步进入主体稳定调用边界形成 x；不能用后续 x 倒灌抹掉初始 nx，也不能用初始 nx 永久追挂后续已内化的 x。

### 5.5 非 nx ≠ 自动 zx

主体拒绝承接外部方向，不会自动推出 zx。zx 仍须独立满足：

```text
主体自身权能公开进入现实
→ 他者/秩序被迫响应
→ 决定范围、影响位置或凌驾程度上升
```

鸳鸯本例的婚姻拒绝层有既有 zx 支持，但不能由“nx off”直接倒推。

## 6｜拿掉测试

对候选案例至少做：

1. 拿掉长期身份，只保留明确任务进入与承接：若 nx 行为功能仍成立，说明身份不是唯一支柱。
2. 保留全部身份/组织关系，拿掉当前任务进入：若被测任务层 nx 消失，支持 off 状态。
3. 保留任务发出，拿掉主体承接：若 nx 无法成立，说明“任务存在”与“通道激活”必须分开。
4. 保留高压力/命令/利诱，主体仍拒绝承接：若 nx 仍不成立，说明强度不能替代接入。

## 7｜反向测试

后续高价值反例应继续寻找：

```text
身份 / 职位长期存在
+ 明确任务已经发出
但主体：
  拒绝承接
  或重定义最高目标
  或直接夺取最终决定位置
  或转走非该外部通道
→ 当前任务层 nx 仍不激活 / 退出
```

已有第一份护栏：鸳鸯抗婚（红楼梦）。

下一步优先换独立作品，而不是继续堆《红楼梦》同型。

## 8｜第三因素冻结

冻结：

- 人物强弱、性格、忠诚度；
- 职业声望；
- 任务难度；
- 最终胜负；
- 道德评价；
- 外部压力强度本身。

只保留：

```text
同一人物
+ 长期关系/组织位置是否持续
+ 当前具体任务/方向是否存在并进入关系场
+ 主体是否真实承接/续接
```

## 9｜与 `nx承接入口与实际续接边界` 的关系

两者相邻但不重复：

```text
本文件：
方向/任务出现
→ 主体是否真正接入？

承接入口与实际续接边界：
主体已口头承接/形式进入
→ 执行或结果窗口是否仍真实续接？
```

鸳鸯本例位于更前一层：

> **方向已出现，但入口本身就没有真实承接。**

关羽华容道、朱仝私放雷横、猪八戒巡山等则属于“入口发生过承接，但后续执行/结果窗口反向改写”。
