# 鸳鸯抗婚｜第二作品 pure-zn 控制

## 1｜被测对象层

只测试“面对贾赦以家内权势强纳为妾时，主体是否保留不可由权势替代决定的婚姻拒绝原则”这一窄原则对象层。

不把“刚烈”“丫鬟”“忠于贾母”“女性反抗”这些身份、标签或主题直接当成 `zn`；也不因此给鸳鸯整个人物锁稳定本体。

## 2｜剧情事实

《红楼梦》第46回中：

- 贾赦明确要纳鸳鸯为妾，邢夫人、鸳鸯兄嫂先后承担劝说与施压；
- 利益诱因很强：姨娘身份、体面、家人可能随之得势；
- 威胁也明确：贾赦声称若鸳鸯不从，将来无论嫁谁也难逃其手；
- 鸳鸯在邢夫人劝说、嫂子劝说、哥哥转达贾赦威胁等不同节点均持续拒绝；
- 她最终到贾母面前公开表明：不仅不愿嫁贾赦，而且即使换成宝玉、其他高位对象，甚至贾母逼迫，她也宁愿终身不嫁、出家或死，也不接受被强迫决定的婚姻；
- 她当众剪发，显示该原则不是无代价口号，而是在现实强压下进入最终选择。

## 3｜zn 证据

本轮原则只压成：

> **当前婚姻关系不能由权势、家属或身份收益替主体决定；在强纳条件下，宁愿终身不嫁、出家或承担生命代价，也不把最终婚姻选择让渡出去。**

按 `zn_准度卡_v0.1` 检查：

1. **原则命题明确**：不是“讨厌贾赦”这么窄，而是拒绝在强迫结构下把婚姻决定权交出；
2. **不可轻易让渡**：姨娘身份、体面、家族收益均不能换取原则撤回；
3. **无奖励/认可仍进入判断**：她的拒绝先于贾母保护，不依赖旁人赞扬；
4. **冲突排序**：与现实安全、家族压力、未来婚配空间、利益诱因正面冲突时，原则仍排序最终选择；
5. **未来调用资格**：她把判断扩展到“将来嫁谁”“贾母以后不在”“即使换成其他对象”这些未来窗口，而不是只拒绝当前一次劝说；
6. **边界与让渡代价明确**：宁愿不嫁、出家或死，也不接受强制婚姻。

因此本窄原则对象层 `zn` 高显影成立。

## 4｜x 证据

同一被测对象层不独立锁 `x`。

- 本轮被测对象是“贾赦强纳 / 当前婚姻关系是否进入鸳鸯可稳定处分的掌握边界”；
- 鸳鸯拥有明确拒绝意志，但“我拒绝”本身不等于社会关系结果已经进入她稳定直接处分边界；
- 贾赦仍以家内权势持续施压，并声称未来可继续阻断其婚配；
- 原著当前结果真正稳定停住，还需要贾母这一外部上位现实保护/否决节点介入；
- 因此不能把“主体有最终内部原则”偷换成“主体已经拥有该婚姻关系的现实 x”。

这一区分与现行 `x_准度卡_v0.1` 一致：`x` 必须证明实际占有、调用、处分、否决或排除边界，而不是只有意志、口号或一次拒绝。

所以本轮只计 pure-zn control，不计 `zn+x` 当前共现，也不计 strict `zn↔x` complement。

## 5｜关键压力

- 贾赦的家内权势与持续威胁；
- 邢夫人、兄嫂的关系压力；
- 姨娘身份、体面与家族利益诱因；
- 家生女儿身份造成的现实退出困难；
- 对未来婚配空间被贾赦报复性封锁的威胁。

压力只用于检验原则是否会被让渡，不是 `zn` 定义本身。

## 6｜拿掉测试

拿掉贾母后续保护、袭人平儿支持、旁人认可、后世“刚烈”评价，只保留贾赦强纳、家人劝说与鸳鸯自己的连续选择，拒绝原则仍进入判断。

如果再拿掉“不能让权势替自己决定婚姻”这一内部标准，只剩“个人不喜欢贾赦”或一次情绪性拒绝，就很难解释：

- 为什么换成其他高位对象也拒绝；
- 为什么利益诱因不能改变选择；
- 为什么会把判断延伸到未来并明确不嫁/出家/死的边界。

## 7｜反向测试

若原著结构改成以下任一情况，`zn` 证据会显著下降：

- 只因为贾母明确反对后才跟着拒绝；
- 只因贾赦年老或个人厌恶而拒绝，却愿意在同样强迫结构下接受更年轻/更高位对象；
- 一旦姨娘身份、金钱或家族收益足够高就撤回原则；
- 当前口头拒绝，但在压力稍减后不再保留同一判断边界。

此时应重新检查 `z / xz / x / nx` 等最近邻，而不能继续锁 pure `zn`。

## 8｜最近邻排除

- `zn vs z`：拒绝先于贾母公开支持，且与身份收益相冲突，不靠重要他者认可才成立；
- `zn vs xn`：如何求助、何时公开、是否剪发属于执行与节点选择，不能替代“为什么绝不接受强纳”这一原则；
- `zn vs zx`：公开誓言、剪发和迫使家内秩序回应可以有显权邻近，但“反抗很强”不是 `zn` 定义；
- `zn vs x`：内部最终拒绝原则不等于现实婚姻关系已经归主体稳定处分；本轮该对象层 `x` 不独立过门；
- `zn vs nz`：未来不嫁/出家是原则给出的边界，不自动等于关系回返/修复结构。

## 9｜第三因素冻结

冻结：

- “刚烈女性”文化评价；
- 贾赦善恶；
- 贾母是否偏爱鸳鸯；
- 袭人、平儿的友情支持；
- 《红楼梦》婚姻/女性主题；
- 后续人物结局。

只保留：外部强纳方向、利益与威胁、主体多节点连续拒绝、跨未来条件声明、明确让渡代价。结论不变。

## 10｜与首份 pure-zn 控制的最小差异

```text
《水浒传》鲁智深：
他者受害 → 救护责任原则 → 无奖励、有代价仍持续执行

《红楼梦》鸳鸯：
主体自身被强制定义婚姻关系 → 不让权势替自己决定 → 利益/威胁均不能换取让渡
```

两案都只锁内部原则，不把保护对象、婚姻对象或关系本身偷写成 `x`，但原则机制不同：前者是**关系责任 / 救护承诺**，后者是**主体自我决定边界 / 拒绝强制定义**。

因此本例增加 pure-zn 第二独立作品控制，但不建立新的 pending-review；仍需第三部独立作品、同 criterion、事实与分类均 ≥95% 后再考虑升格。
