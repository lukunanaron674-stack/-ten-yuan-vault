# 对象层证据归属与跨层防污染协议 v1.0

## 1. 协议目的

本协议只解决一件事：

```text
一条证据究竟属于哪个对象、哪个层级，能够证明什么，不能证明什么。
```

它不新增三元或十元定义，不修改既有生克补位置，也不把三元与十元写成父子派生关系。

## 2. 基本原则：证据先归属，结论后运行

每条证据必须先绑定到明确对象：

```text
谁 / 什么对象
在什么阶段
以什么方式
承载了什么现象
```

未完成对象归属的证据，不得进入三元、十元、生克补、动态链或五大主题结论。

标准顺序：

```text
识别证据
→ 指定证据所属对象
→ 指定证据所属层级
→ 判断该证据的证明权限
→ 与同层证据组成候选
→ 再进入十元与三元判定
```

## 3. 七类对象层与证明权限

### 3.1 人物稳定本体

能够证明：

```text
跨阶段反复成立的存在方式
核心痛苦
反复选择
最难被外部条件改变的锚点
```

不能仅由以下内容证明：

```text
一次行为
一段状态
职业
服装
场景
光影
他人评价
结局结果
```

人物稳定本体必须通过跨阶段证据、拿掉测试、最近邻排除与起手测试共同确认。

### 3.2 当前人物状态

能够证明：

```text
此阶段什么高显影或低显影
压力下人物暂时如何反应
此刻人物被迫处于什么关系位置
```

不能自动证明：

```text
人物永久拥有新的主十元或副十元
人物核心锚点已经改变
```

状态持续时间长，也不自动升级为本体。

### 3.3 关键行为功能

能够证明：

```text
这一行为在当前结构中承担执行、承载、冲突、停靠、隐藏、结算或改写等功能
```

不能自动证明：

```text
行为者的稳定本体就是该功能十元
```

同一种行为可能由不同本体驱动；同一种本体也可能使用不同功能行为。

### 3.4 外部场景

能够证明：

```text
环境本身的结构
环境对人物施加的限制、诱导、承载或压迫
人物能够在哪里行动以及不能在哪里行动
```

不能自动证明：

```text
人物本体与场景同元
人物因为长期处在某场景便拥有该场景的十元
```

监狱可以是高体量限制结构，但囚犯不因此自动成为 xn；温暖房间可以承载 nz，但居住者不因此自动成为 nz。

### 3.5 时间关系 / 时间结构

能够证明：

```text
先后、等待、积累、重复、历史惯性、节点、阶段和不可逆进程
```

不能自动证明：

```text
人物本体 xn
作品主主题为时间
```

只有当人物主动把信息、行动或资源放入结构与积累，时间证据才可参与 xn 候选；若时间只是外部条件，应继续保留在时间层。

### 3.6 视觉与光影

能够证明：

```text
外观、姿态、气氛、观看方式与显影强度
```

不能单独证明：

```text
人物主十元
人物稳定本体
主题主次
关系端点
```

黑暗不等于 x，锐利不等于 zx，柔光不等于 nz，冷色不等于 xn。

### 3.7 关系变化与动态链

能够证明：

```text
谁改变了谁
改变发生在哪个阶段
目标对象的能力、边界、路径、状态或显影如何变化
```

不能反向证明：

```text
端点本来就属于某个十元
关系结果自动生成新的稳定本体
```

动态链只描述已经通过审核的对象怎样运动，不负责替端点补点位。

## 4. 证据不可跨对象继承

正式规则：

```text
A对象的证据，只能首先证明A对象。
```

若要用于判断B对象，必须额外证明：

```text
A确实对B造成了结构性作用；
该作用在B内部形成了可重复、可验证的表现；
B的表现不是一次性服从、模仿、伪装或被迫反应。
```

因此禁止：

```text
场景很压迫
→ 人物本体就是压迫型十元

某行为很果断
→ 行为者本体就是 zx

某人被长期控制
→ 某人的本体就是 nx

某关系形成互补
→ 两个端点各自必然是公式中的固定十元
```

## 5. 证据不可跨层升级

低层证据不能在没有中间验证的情况下直接升级为高层结论。

```text
视觉证据
不能直接升级为行为功能；

行为功能
不能直接升级为当前状态；

当前状态
不能直接升级为稳定本体；

单个对象十元
不能直接升级为作品主主题；

主题关系
不能直接还原成唯一十元关系。
```

允许升级的唯一方式，是在目标层重新完成该层所需的证据审核。

## 6. 同一证据可以多层使用，但必须分别陈述

同一事件可能同时提供多层证据，但必须拆开书写。

示例：人物在监狱中持续写作。

```text
人物稳定本体层：
写作是否来自跨阶段反复成立的信念与存在方式。

当前状态层：
人物是否在受限环境下进入高压、孤立或集中状态。

行为功能层：
写作在当前剧情中承担保存、传递、反抗、整理或结算功能。

场景层：
监狱如何限制行动、交流和身体自由。

时间层：
长期囚禁、等待、累积书写与临近结局怎样改变行为意义。

光影层：
阴影、窄窗和局部亮光怎样辅助显影。

动态链层：
外部限制如何压缩行动，却是否反向促使信念、文本或关系扩大。
```

禁止把这些不同层的证据揉成一句“他在黑暗监狱里写作，所以他是某十元”。

## 7. 关系端点身份冻结

进入生克补与动态链前，必须冻结端点：

```text
端点名称
端点对象类型
端点所在阶段
端点十元置信度
端点是否为本体 / 状态 / 行为 / 场景 / 时间结构
```

关系运行过程中不得偷换端点。

例如：

```text
开始写“监狱场景 xn 克 人物行为 zx”
中途不得改写成“xn 克 人物本体 zx”
```

除非重新完成“人物本体 zx”的独立审核。

## 8. 人物核心锚点稳定规则

故事剧本中的人物核心锚点优先保持稳定。

剧情变化优先解释为：

```text
当前状态变化
行为功能变化
关系位置变化
场景承载变化
时间压力变化
显影强度变化
动态链阶段变化
```

只有当以下三项同时重构，才允许提出“人物稳定本体改变”的候选：

```text
存在方式
核心痛苦
反复选择
```

即使满足，也只能重新进入 Top-2 与三道门审核，不能直接锁定。

## 9. 三元与十元并行校验

三元证据与十元证据使用同一对象归属原则，但分别独立判断。

```text
三元不是十元的父级；
十元不是三元的子类；
三元比例不能替代十元点位；
十元公式不能反推唯一三元比例。
```

允许：

```text
对同一对象分别完成三元判断与十元判断
→ 检查两者是否相容
→ 若冲突，回到证据归属重新审核
```

禁止为了让公式好看而把场景、行为或状态证据挪给人物本体。

## 10. 标准证据卡

```text
### 证据编号

- 原始事实：
- 所属对象：
- 对象阶段：
- 所属层级：本体 / 状态 / 行为 / 场景 / 时间 / 光影 / 关系
- 可证明：
- 不可证明：
- 是否跨对象使用：是 / 否
- 若是，结构作用证据：
- 三元候选：
- 十元候选：
- 置信度：A / B / C
```

## 11. 最终封存

```text
证据必须先有主人，才能有结论。
场景归场景，时间归时间，光影归光影，行为归行为，状态归状态，本体归本体。
关系负责改变端点，不负责伪造端点。
动态链负责运动，不负责替错误点位圆故事。
人物核心优先稳定，变化优先落在状态、关系与阶段过程。
```
