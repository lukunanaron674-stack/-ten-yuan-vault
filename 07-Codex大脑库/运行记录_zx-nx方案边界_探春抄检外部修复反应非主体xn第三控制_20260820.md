# 探春抄检｜外部修复与追责传播不等于主体 xn 结构传播

## 1｜本轮问题

已有两部独立作品出现同一边界：

- 《三国演义》关羽拒婚：关羽只拒绝一个外交合作接口，孙权及东吴随后自己重排战略；不能把东吴的多层反应倒算成关羽的 xn。
- 《水浒传》李逵扯诏：李逵只做强烈拒绝/破坏，宋江、卢俊义、钦差与梁山组织随后自行修复现场；不能把组织修复链倒算成李逵的 xn。

本轮用《红楼梦》探春抄检验证第三部：主体只重申局部边界并否决越界执行，随后搜检队、王善保家的、邢夫人一侧出现连续调整与追责，这些下游传播能否反推探春主动重构搜检系统？

结论：不能。

## 2｜剧情事实、触发、对象、动作、结果

### 触发

绣春囊事件后，王夫人批准夜间搜检大观园，凤姐、王善保家的等携带真实上位授权进入各院。

### 对象

只看秋爽斋局部搜检边界：

- 是否允许搜检物品；
- 谁能接触探春本人；
- 探春是否把局部否决与边界重设资格完全交给外部执行组。

### 探春明确动作

1. 预先开门秉烛等待，不躲避上位搜检任务。
2. 主动开箱，请凤姐检查自己的物品。
3. 要求搜检队把“已经搜明白”说清，拒绝留下模糊责任。
4. 明确区分“查物”与“奴仆搜身”：允许前者，不接受后者。
5. 王善保家的越界拉扯衣襟时，探春当场掌掴并公开斥责。
6. 凤姐、平儿等立即制止、陪笑、调整执行方式，不再沿王善保家的越界方式继续。

### 下游外部反应

第七十五回进一步出现：

- 王善保家的因多事而被邢夫人责打；
- 搜检事件继续由凤姐、周瑞家的等处理后续；
- 各房与相关人员围绕抄检结果继续产生新的处分与修复动作。

这些反应是真实传播，但主要由外部组织节点自行完成，不是探春主动设计的新搜检流程。

最小结构：

```text
上位搜检权限进入秋爽斋
↓
探春允许查物，但否决奴仆越界搜身
↓
王善保家的越界
↓
探春公开反击并重申边界
↓
凤姐 / 平儿 / 搜检队调整行为
↓
王善保家的后续被外部系统责打、处理
```

后半段传播很深，但不是探春搭出来的新运行结构。

## 3｜zx 判断

### 当前受压复位状态：evidence-locked

沿用正式案例的高纯结论：

```text
外部搜检权压入本院
→ 探春局部位置被压成受查对象
→ 探春公开提出并执行边界
→ 越界时直接否决
→ 执行组实际改变行为
→ 探春局部决定位置恢复 / 上升
```

因此：

- `zx_pressure_reassertion_state: evidence-locked`

但只锁当前状态、行为功能与关系位置，不锁稳定人物本体。

zx 不是“一巴掌”本身，而是自身权能公开进入现实后，执行组必须重新围绕其边界行动。

## 4｜nx 判断

### 当前局部搜检边界：rejected

上位搜检权限真实存在，但探春没有把秋爽斋内“怎样查、谁能碰自己、越界是否接受”的局部最终判断全部交给外部执行组。

她承认并配合“查物”这一上位任务，却拒绝“奴仆可随意搜身”这一越界执行方式。

因此：

- `nx_in_local_search_boundary: rejected`

这不是否认外部权限，而是对象层切分：接受上位任务存在，不等于当前每一个局部接口都沿外部方向续接。

## 5｜xn 判断

### rejected as primary

本轮最危险的误判是：

```text
探春拒绝越界
→ 搜检队调整
→ 王善保家的被责打
→ 各房继续处理后续
→ 所以探春发生 xn 结构重设？
```

不成立。

探春本人没有主动：

- 重新设计大观园搜检流程；
- 调配新的搜检人员；
- 重设跨院搜检顺序；
- 建立新的记录、复核或追责节点；
- 重新定义整个搜检行动的成功条件；
- 建立一套替代王夫人/凤姐原方案的持续运行骨架。

她做的是：在自己的局部对象层公开划边界并否决越界执行。

随后搜检队怎样调整、王善保家的怎样被责罚、其他房怎样继续处理，是外部系统对她的行动和抄检结果作出的反应。

因此：

- `xn_subject_structural_rewrite_in_search_layer: rejected_as_primary`
- `external_organization_reaction_propagation: evidence-locked`

候选纪律：

> 主体动作引发外部系统多层重排，不等于主体主动完成了 xn 结构重设。xn 的结构传播必须归因于主体自己对节点、资源、协同、成功条件或运行骨架的重新组织。

## 6｜关键压力

压力由多层外部权威叠加：

- 王夫人批准；
- 凤姐带队执行；
- 王善保家的借邢夫人陪房身份越界；
- 夜间突击搜检程序压力。

压力使探春局部 zx 受压复位高显影，但压力本身不能直接制造 xn。

## 7｜拿掉测试

### 拿掉后续王善保家的受罚

只保留：

```text
搜检队进入
→ 探春划定局部边界
→ 越界时否决
→ 执行组当场调整
```

zx 当前状态、局部 nx 退出、xn 未重构三个判断仍成立。

说明第七十五回的外部追责链不是分类支柱。

### 拿掉一巴掌

只保留探春主动开箱、拒绝奴仆搜身、要求凤姐说明并迫使搜检方式调整，核心结论仍成立。

暴力只增加显影强度，不决定 xn。

### 拿掉王夫人真实授权

则不能再把本轮写成“外部权限真实存在但局部 nx 未续接”的压力控制；外部权限是真实前置条件。

## 8｜反向测试

### 反向成持续 nx

```text
搜检队进入
→ 探春不保留局部否决资格
→ 对方决定怎样搜就怎样搜
→ 主体实际沿外部执行方式继续
= nx上升
```

### 反向成 xn

```text
探春否决越界搜检
→ 主动提出并建立一套替代搜检程序
→ 重排人员 / 搜检顺序 / 记录 / 复核 / 责任节点
→ 原搜检骨架无法按旧方式继续
= xn显著上升
```

### 反向成伪 zx

若探春只是口头生气，对方仍按原方式完成搜身且其局部决定位置没有恢复，则 zx 证据显著下降。

## 9｜最近邻排除

### zx vs x

探春原本确有院内身份与身体边界，构成 x 邻近；但本轮出现“位置受压 → 公开反推 → 对方重新回应 → 局部决定位置恢复/上升”，所以当前状态锁 zx，不把已有身份本身当 zx。

### nx vs xn

不沿外部局部执行方式，只能证明该微窗口 nx 退出；没有主体自己搭替代运行结构，不能自动升级 xn。

### xn vs 外部反应传播

本轮核心：

```text
探春否决越界
→ 凤姐等调整
→ 王善保家的受外部系统处分
→ 后续抄检结果由其他组织节点继续处理
```

传播存在，但传播的组织者不是探春。

### zx vs xn

公开把局部边界压回现实回答“谁成为当前更强决定力量”；重新搭流程、节点与资源回答“运行结构怎样被重新组织”。二者不能互相替代。

## 10｜第三因素冻结

冻结：

- 探春是否庶出；
- 王善保家的性格与身份评价；
- 抄检大观园主题意义；
- 晴雯、司棋后续命运；
- 凤姐是否真心支持探春；
- 邢夫人责打王善保家的动机；
- 一巴掌的戏剧强度。

只问：谁拥有当前局部边界、探春是否沿外部接口续接、后续结构变化是谁主动组织的。

## 11｜跨作品意义

同一边界已跨三部独立作品：

1. 《三国演义》关羽拒婚辱吴：主体拒绝，东吴自行重排战略；主体 xn 不成立。
2. 《水浒传》李逵扯诏：主体拒绝/破坏，梁山与使团自行修复现场；主体 xn 不成立。
3. 《红楼梦》探春抄检：主体划定局部边界并否决越界，搜检队与家族系统自行调整、追责；主体 xn 不成立。

共同候选：

> 外部反应传播的深度不能直接计入主体 xn。必须证明关键依赖的重新绑定是由主体自己组织，而不是对方、上级或环境为了应对主体动作而自行发生。

该边界已达到三作品阈值，应建立待审议问题，但不得直接修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡。

## 12｜本轮结论

```text
探春：
上位搜检权限真实存在
+ 当前局部搜检方式不完整续接 → nx局部退出
+ 公开恢复局部决定边界 → zx状态高显影
+ 外部系统随后多层调整 / 追责
+ 探春本人没有搭替代运行骨架 → xn不成立
```

本轮锁定：第三部“外部反应传播 ≠ 主体 xn 结构传播”高纯控制。
