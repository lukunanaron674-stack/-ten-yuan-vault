# 《三国演义》马岱遗计执行 vs 诸葛亮草船借箭｜nx↔xn 最小差异

## 0｜结论

本轮不制造新人物标签，而是锁一个同作品最小差异：

> **外部给定“最终目标”本身，只能支持该目标层的 nx；是否继续锁运行层 nx，必须再问“关键运行骨架是谁设计的”。**
>
> 马岱一案中，目标对象、潜伏角色、触发条件、执行时点和最终处置路径均由诸葛亮遗计预设，马岱真实持续续接，因此运行层仍为高纯 nx。
>
> 草船借箭中，周瑜只锁“十万枝箭”这一上位任务终点；诸葛亮把十日改成三日，并自行组织船、军士、草束、大雾、接近曹营、承箭、回收交付等关键节点，因此上位终点 nx 保留，而运行层 nx 下降、xn 高显影。

最小纪律：

```text
外部给目标
≠ 外部给运行骨架

外部给目标 + 外部给关键骨架 + 主体真实续接
→ 运行层 nx

外部给目标 + 主体自己搭关键骨架
→ 目标层 nx 可保留
→ 运行层优先查 xn
```

## 1｜事实对照

### A｜马岱

诸葛亮临终召马岱入帐授密计，并给杨仪锦囊设置后续触发。第105回明确回收：马岱只待魏延喊叫时，从背后斩之。马岱没有自己重新定义目标对象、潜伏位置、启动条件或最终处置路径。

结果：魏延在预设窗口被斩。

### B｜诸葛亮草船借箭

周瑜要求诸葛亮监造十万枝箭，并先提出十日。诸葛亮接受“交十万箭”终点，却主动改成三日，随后绕开常规监造，自行向鲁肃取得二十只船、军士、布幔、草束，并利用第三日大雾驶近曹营承箭，最终交付十余万枝。

结果：上位终点保持，但决定性实现结构由诸葛亮重建。

## 2｜zx 检查

两例均不因“动作强 / 结果大”自动锁 zx。

- 马岱亲手斩魏延，但没有取得更高处分范围；执行的是预设处置。
- 诸葛亮完成十余万箭并令周瑜叹服，但没有因此取得东吴新增军令处分权。

因此本轮不新增 zx 结论。

## 3｜nx 检查

### 马岱

`nx_behavior_function: evidence-locked`

理由：不仅终点来自外部，决定性运行骨架也来自外部，且主体真实持续执行至触发点。

### 诸葛亮

`nx_upper_task_endpoint_continuity: evidence-locked`

`nx_in_operational_method_layer: rejected`

理由：十万箭终点由周瑜给定并被完成，但实现方法、关键节点与资源编排由诸葛亮重设。

## 4｜xn 最近邻

马岱：复杂执行不等于 xn。潜伏、等待、欺骗和最后斩杀都没有替换决定性骨架。

诸葛亮：不是普通执行自由，而是关键期限、资源配置、协同接口与实现路径被主体重新组织，因此运行层 xn 高显影。

## 5｜关键压力

马岱：诸葛亮死亡、魏延与杨仪冲突、必须隐蔽处理叛乱。

诸葛亮：周瑜设置十万箭军务、三日军令状、并故意让工匠与材料拖延。

压力只解释为何执行/重设发生，不直接判十元。

## 6｜拿掉测试

### 拿掉马岱案中的外部运行骨架

若只剩“提防并处理魏延”这一目标，而潜伏、接近、触发、时点和斩杀路径都由马岱自己设计，则运行层 nx 显著下降，必须转查 xn。

### 拿掉草船案中的主体运行重设

若周瑜连船只、草束、时机、路线、承箭方式都已经给定，而诸葛亮只照做，则运行层会明显回到 nx。

### 拿掉两案最终成功

马岱失手或诸葛亮未足十万，都不会单独改变“谁给方向 / 谁搭骨架”的分类，因此胜负不是主判。

## 7｜反向测试

```text
同样的外部目标
↓
若关键骨架也由外部给定
→ nx 运行层上升

若关键骨架由主体新建
→ nx 仅保留在上位目标层
→ xn 运行层上升
```

这说明 `nx ↔ xn` 的真正分界不在“是否接了任务”，而在对象层：

> **终点来源** 与 **运行骨架来源** 必须分别判。

## 8｜最近邻排除

- `nx vs xn`：看关键运行结构由谁组织，不看动作数量。
- `nx vs zx`：沿外部目标或自行搭方案都不自动扩大公共决定范围。
- `x`：临时取得船只、军士或执行权限不等于稳定拥有更高处分边界。
- 人物能力、忠诚、聪明、战果、身份全部冻结，不用于直判。
