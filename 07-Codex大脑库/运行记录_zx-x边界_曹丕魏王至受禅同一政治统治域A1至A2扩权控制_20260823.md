# 运行记录｜曹丕：魏王/丞相既有 x → 同一政治统治域内帝位 A2 → zx

## 0｜本轮目的

验证 `zx↔x` 当前最危险的新边界：

> zx 是否必须跨到全新的对象域 B？
> 还是在同一政治统治对象域内部，只要决定范围从 A1 真实推进到原本不属于主体的 A2，也足以形成 zx？

本轮只分析《三国演义》第78-80回曹丕嗣魏王、丞相后至受禅称帝这一连续阶段，不给整个人物贴稳定十元标签。

## 1｜剧情事实

### 1.1 A1 既有权限

曹操死后，第78回中曹丕经献帝诏命被封为魏王、丞相、冀州牧，并即日登位。第79回开头又写其以魏王身份升赏文武、统甲兵三十万。

因此在受禅之前，曹丕已经真实拥有一块稳定政治军政处分边界：

```text
A1 = 魏王 / 丞相 / 冀州牧
   + 魏国与既有军政、人事处分
= 既有 x
```

### 1.2 A2 原本不属于曹丕

汉献帝仍是名义上的皇帝，帝位、玉玺与“天下最高主权”在形式与制度层仍不属于曹丕。

第79-80回中，华歆、王朗等推动献帝禅位；献帝并非自由主动放弃，而是在群臣逼迫、威胁环境下被迫接受禅让程序。

### 1.3 A2 被公开推进并稳定生效

第80回中，受禅台完成，献帝亲奉玉玺，曹丕登帝位，改元黄初、国号大魏，大赦天下，百官朝贺；献帝则被降为山阳公并退出皇帝位置。

结果不是一次象征性宣称，而是：

```text
旧最高帝位接口失效
→ 曹丕取得皇帝位置
→ 改元、国号、百官、赦令、人事处分全部按新接口运行
= A2 稳定进入曹丕现实决定范围
```

## 2｜zx 判断

`zx_same_domain_A1_to_A2_expansion: evidence-locked`

本例不依赖“曹丕篡汉”这一道德/历史标签，而看权限增量：

1. A1 在冲突前已经真实属于曹丕；
2. A2 与 A1 属于同一宏观对象域：国家政治统治与最高处分；
3. A2 原本不属于曹丕；
4. 原最高节点献帝被迫退出，无法维持旧结果；
5. 曹丕公开取得 A2；
6. A2 后续以皇帝、改元、百官朝贺与全国处分形式稳定运行。

因此本例支持：

> **zx 不要求一定跨到完全不同的对象域。**
> **在同一对象域内部，只要决定范围从 A1 推进到原本不属于主体的 A2，并公开、稳定生效，同样可以形成 zx。**

## 3｜x 判断

A1 仍应解释为既有 `x`：

```text
魏王 / 丞相 / 冀州牧权限已经到手
→ 在该范围内升赏、统兵、治理
= x
```

不能因为曹丕后来称帝，就把此前每一次魏王用权倒写成 zx。

本轮真正的 zx 增量发生在：

```text
A1 已经存在
→ A2 以前不属于主体
→ A2 被新增并稳定化
```

## 4｜nx 判断

`nx_formal_abdication_permission_relation: rejected_as_primary`

表面上，曹丕通过“献帝禅让、奉玺”取得帝位，看起来像通过外部许可接口获得新权限。

但原文同时给出强烈反证：

- 献帝的决定环境受到华歆等人持续逼迫；
- 禅让流程本身由曹丕集团设计并推动；
- 曹丕两次退回玺绶主要服务于公开合法化形式；
- 献帝没有真实、可自由使用的否决能力来阻止最终结果。

因此不能把“形式禅让”高纯锁成曹丕的 `nx` 权限关系。

更准确是：

> **形式许可存在，但真实最终方向与作用权来源已经主要被曹丕集团占据。**

## 5｜xn 最近邻

受禅程序包含：

- 群臣推动；
- 多次诏书；
- 退玺；
- 受禅台；
- 公卿、军队、礼仪；
- 改元与制度切换。

这有明显 `xn` 组织邻近。

但本轮核心问题不是“怎样完成称帝流程”，而是：

> **同一政治统治域内，主体的最终决定范围是否从 A1 扩到 A2。**

所以 `xn` 次级，`zx` 主判。

## 6｜关键压力

关键压力不是曹丕野心、汉室衰微或群臣谄媚，而是：

```text
同一政治统治对象域
A1 已经属于主体
A2 原本仍属于另一个最高节点
→ 主体公开推进 A2
→ 原节点无法维持旧结果
→ A2 稳定生效
```

这直接压力测试“zx 是否必须跨对象域”。

## 7｜拿掉测试

### 7.1 拿掉 A1

如果曹丕此前没有魏王/丞相等既有政治处分边界，称帝仍可能是 zx，但本轮将失去“同一对象域 A1→A2”的控制价值。

### 7.2 拿掉献帝被迫退出

如果献帝仍稳定保有帝位并能否决曹丕称帝，而曹丕只是自称皇帝却无法让全国秩序转向，则只能算扩权尝试，不能锁 97%。

### 7.3 拿掉改元、国号、百官朝贺与全国处分

如果只有一次受禅仪式而后没有现实制度切换，则 A2 是否真正进入曹丕稳定决定范围会明显变弱。

### 7.4 拿掉强迫性，只保留自由禅让

若献帝拥有真实自由否决权并主动、独立决定把 A2 正式授予曹丕，则本例会明显转向：

```text
nx 授权入口
→ 新 A2 形成 x
```

而不是当前高纯的 zx。

## 8｜反向测试

### 8.1 只有 x

```text
曹丕继续只做魏王 / 丞相
→ 在 A1 内升赏、统兵、处分魏国事务
= x
```

### 8.2 同域 zx

```text
已有 A1
→ A2 明确不属于主体
→ 原 A2 节点无法自由维持旧结果
→ 主体公开把权能推进 A2
→ A2 稳定进入主体决定范围
= zx
```

### 8.3 真 nx 授位

```text
A2 原节点拥有真实可使用的否决权
→ 主体必须等待其自由批准
→ 批准后 A2 才能生效
= nx 授权入口 + 新 x
```

曹丕本例与此不完全相同。

## 9｜最近邻排除

### zx vs x

- A1 内使用已有权：`x`
- 同域内把决定范围推进原本不属于自己的 A2：重新检查 `zx`

### zx vs nx

形式上的诏书、禅让、玉玺不能自动证明 `nx`；必须检查原许可节点是否真实拥有可使用的否决权。

### zx vs xn

组织一套复杂禅让流程属于 `xn` 邻近，但不能替代“权限范围是否扩大”的主判。

### zx vs 身份/胜负/道德

“皇帝”“篡位”“曹魏胜出”都不能单独判十元；本轮只按 A1/A2 权限对象和现实生效判断。

## 10｜第三因素冻结

冻结：

- 曹丕人格评价；
- 汉献帝软弱评价；
- 华歆等人动机；
- 汉魏正统争论；
- 后世篡位评价；
- 曹氏军事强弱。

只保留：

- A1 是否已属于曹丕；
- A2 是否属于同一政治统治对象域且原本不属于曹丕；
- 原 A2 节点是否能维持旧结果；
- A2 是否公开、稳定成为曹丕的新决定范围。

结论仍稳定在 97%。

## 11｜结论

```text
已有 x=A1
≠ 后续所有动作只能是 x

同一对象域内部：
A1 → 原本不属于主体的 A2
+ 原最高节点被迫退出
+ A2 公开稳定生效
= zx 可以成立
```

本轮只新增一份高纯同域 A1→A2 控制，不修改 L1、zx/nx 信息卡、准度卡、zx补nx_补卡，也不新建待审议问题。
