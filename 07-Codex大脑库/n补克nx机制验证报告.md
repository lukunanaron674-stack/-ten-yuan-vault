# 旧关系迁移页

```text
Legacy（旧十元表达）

n 补克 nx

↓

Current（正式主题表达）

因果克制空间
```

本文件原有的“机制验证”结论停止作为现行十元关系使用。

原因：旧报告把 `n` 当作空间主题的直接替身，把旧版 `nx` 当作因果主题的直接替身，由此把主题层关系压缩成固定十元对子。随着 `nx` 语义修正为“不占据方向决定权，沿既有安排与关系继续”，原报告中的“暗账、算计、结算”证据也已失效。

## 当前使用规则

- 正式主题关系：**因果克制空间**。
- 五大主题负责宏观归类与主题级关系。
- 十元负责人物、状态、行为、场景和时间结构的具体语义与实现机制。
- “因果克制空间”不得自动翻译成唯一十元关系。
- 旧案例如需恢复，必须重新拆分人物本体、状态、行为、场景、时间关系、视觉光影与动态链。
- 人物核心锚点优先稳定，不因旧关系迁移而自动改判。
