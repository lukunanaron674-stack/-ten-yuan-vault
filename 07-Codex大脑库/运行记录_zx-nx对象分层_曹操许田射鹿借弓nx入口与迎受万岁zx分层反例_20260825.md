# 运行记录｜曹操许田射鹿：借弓 nx 入口与迎受万岁 zx 的对象分层控制

## 1｜剧情事实

《三国演义》第20回：献帝连射三箭不中，明确对曹操说“卿射之”。曹操随后向献帝讨取宝雕弓与金鈚箭，得到该外部资源后射中大鹿。群臣见金鈚箭，以为是献帝射中，纷纷向献帝呼“万岁”；曹操却纵马遮到献帝之前，主动迎受这一本应指向皇帝的公开呼贺。之后曹操又未归还宝雕弓，亲自悬带。

事实链：

```text
献帝允许曹操射鹿
→ 曹操向献帝讨取宝雕弓、金鈚箭
→ 使用外部资源射中大鹿
→ 群臣误以为天子射中并向天子呼万岁
→ 曹操主动遮到天子之前迎受呼贺
→ 群臣失色
→ 曹操不还宝雕弓，亲自悬带
```

## 2｜对象分层

本桥段不能整段一刀切成 zx 或 nx，必须拆成两个对象层。

### A｜“宝雕弓 / 金鈚箭的使用权”对象层

- 资源原本属于献帝；
- 曹操没有直接夺取后射，而是先在献帝“卿射之”的许可下讨取；
- 当前资源调用入口仍经过献帝已有位置。

因此：

```text
外部许可 + 外部资源接口
→ 主体真实接入并使用
= 局部 nx 关系功能
```

### B｜“万岁呼贺 / 公开象征位置”对象层

- 群臣的“万岁”原本明确指向献帝；
- 曹操没有等待献帝转授，也没有沿礼制许可接口承接；
- 曹操主动纵马遮于献帝之前，直接迎受呼贺；
- 群臣“皆失色”，说明等级秩序被迫正面响应；
- 后续不还御弓并亲自悬带，继续强化公开僭越位置。

因此：

```text
主体自身主动占据原本不属于自己的公开象征位置
→ 权能进入现实
→ 群臣与等级秩序被迫响应
→ 凌驾程度上升
= zx 当前状态高显影
```

## 3｜样本类型

本轮不是纯 zx，也不是纯 nx；更不是严格 `zx↔nx` 补。

最准确分类：

> **同一短桥段中，先出现局部 nx 资源入口，随后在另一个对象层出现 zx 公开越位；两端对象层不同，因此不能把“同段共现”误写成严格补，也不能让前段 nx 覆盖后段 zx。**

## 4｜关键压力

关键压力不是“曹操很强”或“皇帝很弱”，而是群臣误认金鈚箭属于天子、公开呼“万岁”这一瞬间。

这制造了一个可观察的象征位置窗口：

```text
呼贺本来指向谁？
主体是否沿既有礼制位置等待承接？
还是直接把自身位置压到皇帝之前？
```

曹操选择后者，因此 zx 在这一对象层高显影。

## 5｜拿掉测试

### 拿掉献帝“卿射之”与御弓金箭

曹操仍可能凭自己的弓箭射鹿，但“沿外部皇权资源接口调用”的 nx 证据消失。说明该 nx 绑定的是御弓/金箭使用权对象层。

### 拿掉“纵马遮于天子之前迎受万岁”

保留“献帝许可 + 借御弓射鹿”，则局部 nx 仍完整成立，但 zx 的公开凌驾证据显著下降。说明后段 zx 不是前段 nx 的换词。

### 拿掉前段 nx

假设曹操自带弓箭射中鹿，但群臣仍误把荣誉归天子、曹操仍强行迎受万岁，则后段 zx 仍可成立。说明 zx 不依赖前段 nx 才成立。

因此两端不是互为必要缺口，严格补不成立。

## 6｜反向测试

### 反向 A｜若全段都是 nx

应表现为：

```text
献帝许可射鹿
→ 借御弓
→ 射中
→ 群臣向献帝呼万岁
→ 曹操退居臣位，只向献帝称贺
```

这时主体始终沿皇帝既有位置和礼制通道推进，zx 会显著下降。

### 反向 B｜若全段都是 zx

应表现为曹操连御弓/金箭也不经献帝许可，直接夺用，并同时公开迎受万岁。原著并非如此，所以不能把前段资源调用也强行写成 zx。

## 7｜最近邻排除

- `nx vs x`：御弓/金箭在当前射鹿入口并未稳定归曹操直接处分；先经献帝许可，故优先 nx。后续不还弓可形成占有/僭越邻近，但不能倒灌覆盖前面的调用入口。
- `nx vs xn`：曹操组织围猎可有 xn 邻近，但“讨天子弓箭并使用”不是排程与流程重构，当前核的是外部资源/许可接口。
- `zx vs x`：后段不是单纯“已经有权所以使用”；“万岁”公开象征位置原本不属于曹操，他主动把自己压到天子之前，且群臣失色，符合新增凌驾位置。
- `zx vs 普通战斗/能射`：射中鹿本身不能单判 zx；真正 zx 证据是迎受万岁与公开压过天子位置。
- `人物本体 vs 当前状态`：本轮只锁当前桥段结构，不据此直接判曹操稳定本体。

## 8｜第三因素冻结

冻结：曹操忠奸评价、魏代汉后世结果、关羽是否真能斩曹操、刘备长期政治立场、围猎本身的军事训练功能。

只保留：

1. 御弓/金箭的当前使用权来自谁；
2. 群臣的万岁原本指向谁；
3. 曹操是否经过新的公开许可再承接该象征位置；
4. 群臣/等级秩序是否真实被迫响应。

结论不变：前段局部 nx，后段 zx。

## 9｜与严格补关系的关系

本例直接反证：

```text
zx 与 nx 在同一桥段先后出现
≠
zx↔nx 严格补
```

原因：

- nx 缺口对象：御弓/金箭的外部资源与使用许可；
- zx 扩张对象：公开皇权象征位置与群臣呼贺指向；
- 二者并非同一个当前现实瓶颈；
- 拿掉前段 nx，后段 zx 仍可成立；
- 拿掉后段 zx，前段 nx 也仍可完整运行。

所以当前只记录“同段分层共现”，不升级严格补。

## 10｜可靠结论

> **同一桥段可以同时出现局部 nx 与 zx，但必须逐对象层判断。主体在资源/许可层真实沿外部接口续接，不妨碍其随后在另一个象征/决定对象层自行越位并高显影 zx；反过来，前段 nx 也不能因为后段 zx 而被抹掉。共现不等于同一对象层，更不等于严格补。**

该结论与现行 L1“同一对象层、同一核心变量、相反方向”以及 `zx补nx_补卡` 的双向拿掉要求一致，不修改任何正本。
