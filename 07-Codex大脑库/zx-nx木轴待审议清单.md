# zx↔nx 木轴待审议清单

> 本文件只做待审议状态索引，不替代各待审议正文，也不得覆盖 canonical。详细事实、拿掉/反向测试与置信度以对应运行记录和待审议文件为准。

## A｜已跨作品形成 pending-review

1. **nx 对象分层不可互相覆盖**
   - 正向：关羽 / 林冲 / 鸳鸯
   - 反向：探春 / 马谡 / 宋江
   - 核心：高层最终方向与局部许可、资源、保护接口必须分层。

2. **nx 激活与当前通道持续有效性**
   - 核心：历史上曾沿某接口 ≠ 当前仍是 nx；必须按当前执行窗口检查激活、退出与目标变化。

3. **具体节点可替代 vs 外部接口层不可绕过**
   - 核心：换 A 节点到 B 节点不等于摆脱 nx；真正削弱 nx 的是稳定、可重复、无需等价外部接口而完成同一结果的内部路线。

4. **外部对象 / 处分域在场 ≠ nx**
   - 控制：《西游记》孙悟空生死簿 / 《水浒传》李逵劫法场 / 《三国演义》董卓废立
   - 护栏：《红楼梦》探春抄检
   - 核心：外部性只证明对象在外；主体是否真实沿接口续接要另证。

5. **主动目标 + 外部通道 ≠ zx+nx 自动共现**
   - 控制：王熙凤铁槛寺 / 刘备三顾茅庐 / 林冲投梁山
   - 核心：自有目标、主动性、坚持不能代替 zx 的公开显权与决定范围新增。

6. **名义权限 vs 现实否决权**
   - 核心两门：A 实效门（能否卡住同一结果）；B 激活门（接口本轮是否真实进入行动链）。
   - 强控制：公孙胜—罗真人“拒绝→停住→放行→恢复”；曹操—献帝为反向。

7. **秘密改结果 ≠ 公开扩权 zx**
   - 四大名著覆盖：孙悟空偷桃酒丹 / 周瑜蒋干盗书 / 王熙凤毒设相思局 / 宋江私放晁盖
   - 核心：隐匿、欺骗、诱导、绕权、时序组织能改结果，但不能自动推出公开决定接口新增。

8. **严格 zx↔nx 补时间窗口闭环与旧 nx 接口退出**
   - verified：红孩儿 / 宋江高唐州 / 孙策质玺借兵
   - 机制 A：瓶颈解决 / 旧接口退出
   - 机制 B：外部 nx 资源稳定内化为 x
   - 反向护栏：杨志黄泥冈，名义交付/对象在手但原外部现实否决仍活跃，不算稳定 x 内化。

9. **nx 上位任务与 xn 局部执行可同段共存**
   - 正向：《三国演义》貂蝉连环计｜99/97；《红楼梦》王熙凤协理宁国府｜99/98；《水浒传》呼延灼征梁山｜99/98
   - 反向护栏：《西游记》孙悟空红孩儿按观音“许败不许胜”预设诱敌｜99/98｜活跃执行不等于 xn
   - 当前结构：3 个正向 works + 1 个 negative guard work；反向护栏不增加 `cross_work_count`。
   - 核心：谁决定“要做什么”与谁决定“具体怎么运行”必须分层。上位任务/授权来源外置且被承接，可为 nx；任务内部人员、资源、节点、时序、流程由主体自行组织，可同时为局部 xn。
   - 反筛选：动作多、执行复杂、会临场处理，不足以单锁 xn；若关键节点、胜负方向与终点已经由外部方案预设，主体只在节点内部完成动作，优先仍判 nx。
   - 邻近护栏：局部权限已稳定内化时另查 x；公开越过授权边界时另查 zx。

## D｜下一步高价值缺口

1. **nx + xn 分层第二类反向护栏（伪 nx）**：优先《西游记》或《三国演义》，找“名义上接了上级任务、也使用其身份/资源入口，但主体实际上把最高任务目标重新定义”的材料；用于检验何时上位 nx 应下降，而不能只凭名义任务继续追挂。
2. **严格补时间窗口反例**：资源/权限看似内化但原节点仍可撤回；任务表面完成但同一瓶颈复发；旧节点退出但等价外部接口仍在。

4. **高成本内部绕行第三独立作品**：必须先证明正常 P1 当前仍开放可用。
5. **第三因素制造伪双向缺口第二独立作品**：优先共同资源稀缺、制度门槛、身份规则。
6. **压力显影第二、第三份真正正例**：必须同对象层，且解压后原端按自身硬判据复位。

## E｜可迁移到火/土/金/水的方法

- 对象层拆分；
- 拿掉 / 反向测试；
- 当前执行窗口；
- 现实否决因果拨动；
- 第三因素冻结；
- canonical > pending-review > evidence-locked > candidate/deferred 的层级纪律；
- **上位目标来源与局部运行权分层**：尤其可迁移到金轴 `xn↔z`，外部给目标不等于主体没有自己的运行骨架组织权；
- **执行动作复杂度 ≠ 运行骨架自主**：跨轴判断都应追问关键节点、终点、胜负/裁定方向究竟由谁预设，而不是数主体做了多少动作；
- **x 内化经过现实否决门**：名义授权、对象在手只证明候选，旧外部节点若仍可稳定覆盖结果，不能宣布旧 nx 退出；
- **初始对子成立与后续窗口闭环分开统计**。
