# 运行记录｜鸳鸯抗婚：外部方向已明确发出，但主体拒绝承接，因此该对象层 nx 不激活

## 1｜本轮目的

当前 `nx任务层同人相邻off-on激活开关边界` 已有三部作品正向控制：

```text
关系/身份长期存在
→ 当前具体任务尚未进入行动链：nx off
→ 明确任务进入 + 主体承接：nx on
```

但还缺一个高纯反向护栏：

```text
外部方向已经明确发出
+
压力很强
+
主体仍不承接
→ 是否能只凭“方向出现了”就判 nx 激活？
```

本轮用鸳鸯抗婚只测试这一窄变量，不重复重判此前已经完成的“鸳鸯—贾母严格补”结论。

## 2｜剧情事实链

### 触发

贾赦要纳鸳鸯为妾，先由邢夫人、鸳鸯嫂子等转达，又经鸳鸯哥哥继续转达贾赦的明确要求与威胁。

### 对象

本轮只看：

> **“鸳鸯是否承接贾赦给出的婚姻方向，并沿该方向进入姨娘关系。”**

### 明确外部方向

外部方向已经非常清楚：

```text
贾赦要纳鸳鸯
→ 兄嫂反复转达
→ 许以体面、姨娘位置
→ 同时附带威胁：若不从，未来也难逃其手
```

所以不是“任务/方向尚未出现”的 off 状态。

### 主体动作

鸳鸯的连续行为却是：

```text
听到要求
→ 咬定不愿意
→ 不接受条件
→ 不进入姨娘关系
→ 到贾母前公开陈述拒绝
→ 表示即使贾母逼迫也不从
→ 剪发明志
```

### 结果

贾赦给出的婚姻方向没有被鸳鸯承接；之后贾母介入，强纳路径被阻断。

## 3｜nx 判断

### 3.1 外部方向存在：是

这一步只证明：

> `potential_external_direction = true`

不能直接推出：

> `current_nx_relation = true`

### 3.2 主体真实承接：否

现行 nx 正本要求：

```text
方向、权限或解决通道已经存在
+
主体不占最终决定位置
+
主体真实沿外部方向/通道续接
→ nx
```

鸳鸯恰好缺第二、第三步：

- 她不把最终婚姻方向交给贾赦；
- 她没有沿“成为姨娘”的路径推进；
- 她反而持续否决并退出该方向。

因此：

```text
贾赦婚姻方向已发出
≠
鸳鸯婚姻对象层 nx 已激活
```

本轮结论：

> **该对象层 nx 不激活。**

## 4｜zx 判断

本轮不以“敢拒绝”“很刚烈”直接判 zx。

但鸳鸯在该婚姻方向层存在已经被仓库反复验证的当前 zx 高显影：

```text
自身拒绝方向明确
→ 在强压力下仍不交出最终方向
→ 公开把“不嫁”压入现实
→ 迫使贾府上位秩序响应
```

所以本轮允许记录：

```text
current_zx_state = true
```

但稳定人物本体不锁。

## 5｜关键压力

本轮压力很强：

- 家生奴婢身份；
- 贾赦家内权力；
- 兄嫂反复劝说；
- 利诱；
- 明确威胁未来婚配空间。

但这些只证明外部压力强，不证明主体真实承接。

压力甚至使本例更有价值：

> **即使外部方向清楚、压力高，只要主体没有真实接入并续接，该对象层 nx 仍不能自动激活。**

## 6｜拿掉测试

### 拿掉贾赦方向

如果没有“纳妾”要求，本轮被测关系对象消失，因此不构成测试。

### 保留贾赦方向，拿掉鸳鸯承接

这正是原著：

```text
方向仍在
+
压力仍在
+
主体不承接
→ nx 不成立
```

说明“外部方向出现”不是 nx 的充分条件。

### 拿掉高压威胁，只保留普通邀请

只要鸳鸯仍拒绝承接，nx 仍不成立。

所以本结论不依赖“压力太大所以不算自愿”这种旁支解释。

## 7｜反向测试

如果改写为：

```text
贾赦提出纳妾方向
→ 鸳鸯接受
→ 进入姨娘安排
→ 按该关系位置继续
```

则该婚姻关系对象层 `nx` 会明显上升。

如果只是：

```text
口头说“愿意”
→ 实际转身逃走/反悔/破坏婚姻落地
```

则还必须继续看真正执行/结果窗口，不能只凭入口口头接受锁 nx。

## 8｜最近邻排除

### nx vs 强迫

外部强迫、监护、身份和经济压力不能单独判 nx。现行 nx 准度卡明确要求拿掉强迫后检查主体是否仍沿外部方向续接。

本例即使保留压力，也没有续接。

### nx vs xn

鸳鸯公开陈述、选择向贾母求保护，有行动组织，但本轮主变量不是流程搭建，不以 xn 为主。

### nx vs zx

“拒绝外部方向”本身也不能自动判 zx；zx 仍需独立满足公开显权、现实响应、决定位置上升。本例这些条件在婚姻拒绝层已有支持，但不能从“非 nx”直接倒推。

## 9｜第三因素冻结

冻结：

- 鸳鸯烈性/忠贞评价；
- 贾赦好色与道德评价；
- 贾母是否偏爱鸳鸯；
- 家族主题；
- 后续贾赦另买嫣红。

只保留：

```text
外部方向是否明确？
主体是否真实承接？
主体是否沿该方向续接？
最终方向是否仍由主体保留？
```

结论不变。

## 10｜与现有两个 pending-review 的关系

### 对 `nx任务层同人相邻off-on激活开关边界`

本例补第一份反向护栏：

```text
任务/方向发出
≠
nx 自动 on

还必须：
主体真实承接并续接
```

### 对 `nx承接入口与实际续接边界`

本例位于更前一层：

```text
外部方向已出现
→ 但入口本身就没有真实承接
```

因此与“口头承接后结果窗口反向改写”的关羽华容道、朱仝私放雷横、猪八戒巡山不同。

它补的是：

> **方向出现 ≠ 入口承接。**
