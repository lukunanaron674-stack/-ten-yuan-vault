# 关羽拒婚辱吴｜外部反应链不等于主体 xn 结构传播

## 1｜本轮问题

现有 nx↔xn 灰区已经区分：

- 单一终局否决但不重组结构：关羽华容道，非 xn；
- 单一外围变量改变并只产生一层外围后果：林冲换路，非 xn；
- 单一根节点改变并主动迫使资源、协同、成功条件多层重绑：马谡街亭，xn 高显影。

本轮增加一个更危险的误判来源：

> 主体只改一个关键外交接口，但对方随后出现多层战略反应，甚至导致更大结构变化。这个“多层后果”能不能反过来证明主体发生了 xn 结构重设？

本轮结论：不能。必须区分“主体主动重组自己的运行结构”与“外部主体对我的否决作出连锁反应”。

## 2｜剧情事实、触发、对象、动作、结果

### 阶段 A｜第六十三回：上位战略承接

诸葛亮把荆州印绶交给关羽，并明确给出“北拒曹操，东和孙权”的战略约束。关羽接受并表示牢记。

因此已有正式案例锁定：

```text
荆州守备最高战略方向来自刘备集团 / 诸葛亮
→ 关羽承接
→ 上位战略方向层 nx 关系位置成立
```

### 阶段 B｜第七十三回：联姻合作接口出现

孙权遣诸葛瑾向关羽求亲，明确把联姻表述为“两家结好，并力破曹”的合作接口。

关羽没有沿这个接口推进，也没有提出替代性的东吴合作方案，而是直接拒绝，并以侮辱性表达把诸葛瑾逐出。

### 结果

诸葛瑾回报后，孙权大怒，开始与群臣商议取荆州，并进一步向曹操侧形成新的合作与夹击设想。

因此发生了明显的下游传播：

```text
关羽拒绝联姻合作接口
↓
孙权愤怒
↓
吴方战略判断改变
↓
开始谋取荆州 / 与曹方形成新的互动
```

但这条传播链的后半段，是孙权及东吴系统自己的反应，不是关羽主动设计的新外交运行结构。

## 3｜nx 判断

### 3.1 既有上位战略 nx：继续成立为前置事实

第六十三回关羽已经接受“东和孙权”的上位战略约束。该结论沿用已有正式案例：

- `nx_prior_strategic_direction_relation: evidence-locked`

### 3.2 当前联姻合作接口执行层：nx 退出

本轮不能把“第六十三回曾经承接过 nx”无限覆盖到第七十三回。

在“是否沿孙权当前提出的结好 / 合作接口推进”这一具体对象层：

```text
外部既有战略：东和孙权
↓
当前出现一个明确合作接口：联姻结好、并力破曹
↓
关羽主动拒绝
↓
不继续沿该接口推进
```

因此锁定：

- `nx_in_marriage_alliance_execution_layer: rejected`

注意：本轮只说“该具体合作接口没有被续接”，不扩大为“关羽在这一刻形式上废除了所有对吴合作可能”。对象层必须保持窄。

## 4｜xn 判断

### rejected as primary

表面诱饵很强：

```text
关羽拒婚
→ 孙权大怒
→ 吴方改战略
→ 后来荆州局势重构
→ 所以关羽做了 xn 结构重设？
```

不成立。

关羽自己没有：

- 建立新的东吴替代合作流程；
- 重配荆州外交资源；
- 新设盟友节点；
- 重写“北线 / 东线”协同系统；
- 设计新的外交成功条件；
- 把旧“东和孙权”替换为一套新的持续运行方案。

他做的是一个关键接口上的拒绝 / 否决。

后续多层变化主要来自孙权一侧的自主反应。因此：

```text
主体动作产生巨大外部后果
≠
主体主动重组自己的运行结构
```

锁定：

- `xn_subject_structural_rewrite_in_diplomatic_layer: rejected_as_primary`
- `external_counterparty_reaction_propagation: evidence-locked`

## 5｜zx 判断

### rejected as primary

关羽的拒绝公开、强硬，而且确实迫使孙权和东吴重新反应，但仍不足以锁 zx。

关键缺口在 zx 准度卡第四门：

> 主体决定范围、影响位置或凌驾程度是否真实上升？

本段没有证据显示关羽因此获得了更大的荆州 / 刘备集团外交处分边界，也没有让东吴承认新的“关羽更高决定接口”。

相反，东吴的反应是转向对抗和谋取荆州。

因此：

- `zx_in_narrow_stage: rejected_as_primary`

“别人因为我一句话大怒并改战略”不能自动成为 zx 扩权。外部反应存在，只满足 zx 检查的一部分，不等于决定范围上升。

## 6｜关键压力

本轮压力不是生存或暴力，而是双重战略约束：

- 北面曹操压力仍在；
- 东吴尝试用联姻加强合作关系。

这个环境让“东和孙权”从抽象战略变成一个可执行的具体外交接口。

关羽拒绝该接口，使 nx 在这一微对象层退出，但没有自动生成 xn 或 zx。

## 7｜拿掉测试

### 拿掉孙权后续愤怒和战略转向

只保留：

```text
外部战略要求东和孙权
→ 孙权给出结好合作接口
→ 关羽拒绝且不提供替代合作路径
```

当前“该接口 nx 未续接、xn 未重构”的结论仍成立。

说明孙权的后续多层反应不是分类支柱。

### 拿掉侮辱性措辞，仅保留明确拒婚

当前接口仍然没有被续接，nx 仍下降；但吴方敌意升级的强度可能减弱。

说明“侮辱”主要是外部反应强度变量，不是 nx / xn 分类的核心变量。

### 拿掉既有“东和孙权”战略

如果不存在外部给定的东线合作方向，那么就不能把本轮写成“已承接 nx 后在执行层退出”。届时只剩关羽对一个婚姻 / 联盟提议的独立拒绝，需要重新分类。

## 8｜反向测试

### 反向成持续 nx

```text
孙权提出联姻结好
→ 关羽按既有“东和孙权”方向接受或进入协商
→ 不重设最终战略
→ nx 继续成立
```

### 反向成 xn

```text
关羽拒绝联姻这一接口
→ 但立即主动建立另一套对吴合作机制
→ 重配使者 / 资源 / 交换条件 / 协同节点
→ 使“东和孙权”以新骨架继续运行
```

这种“拒绝旧接口 + 主动搭替代结构”才会显著提高 xn。

### 反向成 zx

关羽若借此事件把自身外交处分权推出原授权边界，并让刘备集团 / 东吴实际承认新的更高关羽决定位置，才检查 zx。

## 9｜最近邻排除

### nx vs xn

本轮核心：

```text
不沿旧接口
≠ 自动 xn

外部系统因我的拒绝发生多层反应
≠ 我的结构重设
```

xn 强证据仍应看主体是否主动重新组织关键节点、资源、协同接口和持续运行方式。

### nx vs x

关羽对自己女儿婚事有现实否决资格，不等于东吴外交最高战略整体归他稳定处分。本轮不把家庭婚配局部资格覆盖到集团战略层。

### zx vs x

强硬调用已有局部否决资格，也不等于决定范围扩大。

### zx vs xn

造成大后果既不是扩权的充分条件，也不是结构重设的充分条件。

## 10｜第三因素冻结

冻结：

- 关羽骄傲 / 性格评价；
- 孙权是否真心想联姻；
- 诸葛瑾个人立场；
- 后来吕蒙白衣渡江；
- 关羽最终失荆州、败走麦城；
- 历史真实与小说加工差异；
- 婚姻伦理与门第评价。

只保留：

```text
既有外部战略是什么？
当前具体接口有没有被续接？
主体有没有主动建立替代运行结构？
后续传播是谁主动组织出来的？
主体决定范围有没有扩大？
```

## 11｜与现有控制的最小差异

### 关羽华容道

```text
一个终局节点否决
→ 几乎没有主体结构传播
→ nx 最终执行层退出
→ 非 xn
```

### 林冲投名状换路

```text
一个执行变量改变
→ 一层外围传播
→ 旧骨架仍可运行
→ 非 xn
```

### 马谡街亭

```text
一个根节点改变
→ 主体主动让兵力 / 协同 / 水源 / 成功条件多层重绑
→ 旧骨架失效
→ xn
```

### 本轮关羽拒婚辱吴

```text
一个关键外交接口拒绝
→ 外部对手出现多层战略反应
→ 但主体没有主动搭替代结构
→ 非 xn
```

因此新增一个很重要的传播维度：

> 不能只看“后果传播了几层”，还必须看“是谁在主动组织这些传播”。

## 12｜结论

```text
事实置信：99
分类置信：97
状态：evidence-locked
```

本轮正式锁定：

> **外部反应链不能冒充主体 xn 结构传播。**

当前 nx↔xn 灰区判别至少要同时看：

1. 旧方案是否来自外部；
2. 主体是否继续沿当前接口推进；
3. 主体是否主动改变关键依赖；
4. 改动是否传播到资源 / 协同 / 成功条件 / 后续流程；
5. 这些传播是主体主动重组，还是外部主体对其动作的反应。

本轮不修改 L1、zx/nx 信息卡、准度卡或 zx补nx_补卡。若未来跨至少三部独立作品重复出现“外部反应传播被误判为主体 xn”的同类边界，再形成待审议问题。
