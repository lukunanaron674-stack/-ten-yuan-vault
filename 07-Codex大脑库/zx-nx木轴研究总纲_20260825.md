# zx↔nx 木轴研究总纲｜2026-08-25

## 0｜用途

本文件只做研究资产消化、索引、状态压缩与方法论沉淀，不替代 L1、信息卡、准度卡或补卡。

统一状态纪律：

```text
正本 / 信息卡 / 准度卡 / 补卡

```

任何新纪律必须先经过运行记录、最小差异、反向测试和跨作品复验，再决定是否有资格进入正本。

## 1｜当前木轴最稳定骨架

```text
zx：主体占据最终方向与作用权来源，并把自身权能压入现实。

nx：主体不占最终方向；关键权限、资源或解决接口仍在外部；主体真实沿既有关系、权限、流程或通道续接。
```

必须冻结：人物性格、强弱、身份、职业、胜负、听不听话、是否求人一次、是否“很主动”等表面变量。

## 2｜最近邻判定地图

### 2.1 zx vs x

```text
x：本来已经拥有该对象域的稳定调用/处分权，现在把它用出来。

zx：决定范围、影响位置或凌驾程度真实推进到原来不属于主体的对象域/层级。
```

核心纪律：**权力有效 ≠ 权力扩大。**

正向/反向控制已经跨作品稳定：
- 唐僧逐悟空、贾母阻鸳鸯、诸葛亮斩马谡：已有权限成功行使，优先 x。
- 孙悟空幽冥生死簿、刘备益州、林冲火并王伦：旧 x 存在，但新对象域被主体推进，zx 可新增。

状态：pending-review。

### 2.2 nx vs x

```text
nx：关键许可/资源/保护/专业解决接口当前仍外置，主体不能稳定自行调用。

x：权限或资源已经稳定进入主体当前直接调用边界。
```

不得因“有人参与、部下执行、用了组织资源”重复计 nx。

### 2.3 nx vs xn

```text
nx：沿别人已有方向、权限或通道推进。

xn：主体自己组织人员、资源、节点、流程、排程或运行骨架。
```

同一桥段可以是：

```text
上位任务 nx
+
局部权限 x
+
主体运行重构 xn
```

三者不能互相覆盖。

## 3｜nx 研究已稳定分支

### 3.1 对象分层

高层最终方向非 nx，不覆盖局部保护、许可、资源、专业接口 nx；反过来局部 nx 也不得倒灌成长期终点 nx。

正向跨作品：关羽、林冲、鸳鸯。
反向跨作品：探春、马谡、宋江。

《三国演义》曹操许田射鹿又补出第三种用途：同一短桥段里，可以先在资源/许可层真实成立局部 nx，随后在另一个象征/决定位置层高显影 zx。

```text
A层：外部许可/资源接口仍有效，主体沿接口调用
= nx

B层：主体未经新的上位授权，把自身决定/象征位置推进原本不属于自己的范围
= zx

A 与 B 不同对象层
→ 可共现
→ 不得互相覆盖
→ 不得仅凭共现判严格补
```

状态：对象分层主干 pending-review；曹操许田案为 evidence-locked 分层反例。

### 3.2 nx 激活与退出窗口

nx 不是历史关系永久标签，必须按当前执行窗口判断。

已锁四类退出机制：
1. 方案失效；
2. 环境使通道不可持续；
3. 许可节点撤回/反转；
4. 通道仍有效，但主体当前最高行动目标改变并主动停止续接。

状态：pending-review。

### 3.3 具体节点可替代 vs 外部接口层不可绕过

A 外部节点失败后转 B 节点，如果同一现实瓶颈仍必须经过某类外部许可、资源或裁决接口，nx 可以持续。

真正削弱 nx 的不是“换人”，而是存在稳定、可重复、不经等价外部接口、仍实现同一结果对象的内部路线。

正向控制：
- 关羽五关；
- 甘地自取盐。

反向护栏：
- 武松：换结果对象不能冒充同结果绕过；
- 玄奘：绕官方许可但继续依赖地方外部接口；
- 孙悟空二调芭蕉扇：方案由主体自搭 xn，但真扇/口诀仍外置，局部 nx 仍在；
- 凯撒越卢比孔：P1 已关闭/反转，只能证明旧 nx 通道失效后的内部续行，不能冒充“P1 仍开放可用而主体主动绕过”的第三正例。

前置门：

```text
先检查 P1 当前状态

P1 当前开放、可用
+ 主体主动不走
+ P2 不依赖等价外部接口
+ 同一结果完成
→ 才进入“可用 P1 主动内部绕行”模板

P1 已撤回 / 关闭 / 反转
+ 主体依靠既有 x 继续实现结果
→ 只证明旧 nx 当前窗口退出 / 通道失效后的内部续行
→ 不计前述模板的跨作品正例
```

状态：pending-review 主干；凯撒为 evidence-locked negative guard。

### 3.4 外部对象／处分域在场 ≠ nx

三部独立作品已形成 pending-review：
- 《西游记》孙悟空幽冥强取生死簿；
- 《水浒传》李逵江州劫法场；
- 《三国演义》董卓废少帝立陈留王。

共同变量：

```text
关键对象、处分接口或最终结果域原本在外部
≠
主体正在沿外部权限接口续接
```

若主体以自身权能直接压掉原持有者当前否决/处分能力，并使同一结果转由自身强制作用改写，优先检查 zx。

只有关键权限/资源随后稳定进入主体可直接处分边界时，才进一步检查局部 x。

已并入两道反筛选护栏：
1. 曹操许田射鹿：御弓/金箭调用前确实经过献帝许可，前段是真 nx；
2. 探春抄检秋爽斋：局部拒绝/局部限缩/击退执行者，不等于整个上位处分接口失效。

对象层护栏：

```text
被压掉的接口层
必须与
声称被主体改写的结果层
一致
```

状态：pending-review，3 works + 1 高纯反向护栏。

### 3.5 主动目标 + 外部通道 ≠ zx+nx 共现

三部独立作品已形成 pending-review：
- 《红楼梦》王熙凤铁槛寺；
- 《三国演义》刘备三顾茅庐；
- 《水浒传》林冲投梁山。

共同纪律：

```text
主体自己有目标
+ 主体非常主动、坚持、执行
+ 关键权限 / 资源 / 专业方案仍在外部
+ 主体真实沿外部接口推进
≠
自动得到 zx + nx
```

必须先分别过门：
- 自有目标、主动性、行动强度，只说明主体不是“无方向”，不能替代 zx 的公开显权与决定范围新增；
- nx 完全可以发生在主动、强势、有明确目标的主体上。

该问题与严格补“第0门”合流使用，但不与严格补待审议文件合并。

### 3.6 名义权限 vs 现实否决权

对应既有待审议：
`07-Codex大脑库/待审议问题_nx真实外部权限需具可否决性_20260817.md`

已有三部正向作品：
- 《红楼梦》平儿玫瑰露案：凤姐能真实反对、修改方案；
- 《水浒传》吴用杭州水军调度：宋江能真实否决并迫使重配；
- 《西游记》孙悟空南海借净瓶：观音保留净瓶、龙女与最终解决接口。

已有反向控制：
- 诸葛亮开府治事：名义上刘禅最高，但日常政务实际裁决稳定落在诸葛亮；
- 曹操许都：献帝名义最高，现实请求仍不能阻止曹操处分；
- 王熙凤宁国府处分：执行后回覆不等于事前批准。

2026-08-25 新增《三国演义》曹操衣带诏后弑董贵妃文学复验：献帝在结果生效前已经明确求情，伏皇后还提出替代处分，但曹操全部拒绝并让原决定直接执行。该记录以 99/98 锁定“当前非 nx / 名义最高无现实否决”，`zx vs x` 仍 deferred。

**这条文学复验不增加独立作品计数**，因为它与既有《后汉书》曹操许都控制属于同一历史权力结构的不同文本版本；它只用于强化方法，不虚增 cross_work_count。

P4 现在压缩成五问：

```text
1. 谁名义上拥有权限？
2. 谁在结果生效前真的能说“不”？
3. 这个“不”能否阻止、修改或延迟结果？
4. 说“不”以后，主体是否必须重配、等待或换通道？
5. 主体能否绕过该节点并稳定让同一结果生效？
```

判定优先级：

```text
名义上级 / 所有者 / 批准人
只能提供候选外部性

真实事前否决成立
+ 主体必须承认并重配
→ nx 权限证据显著增强

反对只发生在事后
或事前反对也不能改变结果
→ 该节点不足以锁当前 nx
→ 转查 x / zx / xn
```

P4 最短方法句：

> 不要先问“谁职位最高”，先问“结果生效前，谁真的能让它停下来”。

状态：pending-review；本轮只强化方法模板，不改 L1、信息卡、准度卡或补卡。

## 4｜zx↔nx 严格补研究

### 4.1 严格补最低门槛

0. **先分别证明 zx、nx 两端独立成立；**
1. 两端直接作用于同一当前现实瓶颈；
2. 拿掉 nx，zx 留下不可替代缺口；
3. 拿掉 zx，nx 也留下不可替代缺口；
4. 两个缺口位于同一有效时间窗口；
5. 双向缺口不能主要由共同第三因素制造；
6. 第三因素冻结必须保留 zx、nx 与目标瓶颈，不能把题目冻没。

### 4.2 已分出的伪补类型

- 单端未独立过门：王熙凤铁槛寺、刘备三顾茅庐、林冲投梁山；
- 对象层错位：两端都真，但不是同一现实变量；曹操许田射鹿是紧邻反例；
- 单向补缺：nx→zx 成立，但 zx→nx 不成立；
- 时间窗口闭环：历史上严格补成立，但任务结束或资源内化后旧补退出；
- 第三因素伪双向：共同敌人、制度压力等制造表面互需。

状态：多项 pending-review，禁止直接写入正本。

## 6｜待审议清单与当前高价值缺口

### 已达到跨作品 pending-review 的主干

- `zx vs x`：已有权限成功行使 ≠ 扩权；旧 x 不妨碍新对象域新增 zx。
- `nx 对象分层不可覆盖`：高层非 nx 与局部 nx 可并存；已有 x/xn 不得重复计局部 nx。
- `nx 激活与当前通道持续有效性`：历史 nx 不永久继承。
- `nx 具体节点可替代与外部接口层不可绕过`：换具体人不等于摆脱外部接口层。
- `外部处分域在场但未激活 nx`：对象/处分域在外不等于 nx；直接压掉接口并改写同一结果优先查 zx。
- `主动目标 + 外部通道不等于 zx+nx 共现`：自有目标与主动性不能替代 zx 独立过门。
- `nx 真实外部权限需具可否决性`：名义权限不是充分证据；结果生效前的真实否决/修改能力才是高质量权限证据。
- `严格补对象层/时间窗口/单向补/第三因素`：多项 pending-review 已形成。

### P1｜外部处分域在场但未激活 nx

已成熟为 3 作品正向 + 《红楼梦》反向护栏，优先级下降。

若继续扩，只接受：

```text
上位处分接口原本真实有效
→ 主体完全不沿该接口
→ 与被测结果同层的最终否决/处分能力失效
→ 同一结果对象被主体自身权能改写
```

### P2｜高成本内部绕行充分条件

当前最值得继续补之一。第三作品候选必须同时满足：
- P1 当前开放、可用；
- 主体主动不使用 P1；
- 同一结果对象；
- P2 实际成功；
- P2 不依赖等价外部许可、关系或关键资源转移。

关羽、甘地为正向；凯撒为 P1 已关闭护栏。

### P3｜第三因素冻结方法

当前只有刘备联孙抗曹一组高纯伪双向控制和曹操卫弘一组有效冻结护栏。

继续优先从《西游记》《水浒传》《红楼梦》找非“共同敌人”机制的跨作品复验，如共同资源稀缺、制度规则、身份门槛等。

### P4｜名义权限 vs 现实否决权

本轮已从“需要压缩”推进到**可复用五问模板**，因此不再优先堆同型“名义高但无效”案例。

下一步最有价值的是做**最小反面对照**：

```text
名义上级存在
+ 上级在结果生效前真实说“不”
+ 这个“不”确实卡住同一结果
+ 主体必须重配 / 等待 / 换通道
```

优先从《西游记》《水浒传》《红楼梦》找与曹操文学复验形成同框对照的高纯材料。

## 7｜可迁移到其他四轴的方法论

以下模板不是木轴专属。

### 火轴 zn↔x
- 对象层拆分；
- 拿掉测试；
- 名义归属 vs 实际处分边界；
- 局部归属变化不得倒灌成整体本体变化；
- 严格对子前先独立锁两端；
- 主体自己“想成为/保持某种本体”不能替代 zn 独立成立；
- **名义所有者/监护者存在，也要检查其是否真的能在对象成立/归属生效前否决。**

### 土轴 n↔x并z
- 内外对象层命名；
- 同一对象跨边界前后对照；
- 外部参与不等于已经纳入；
- 局部边界穿透不等于整体空间边界改写；
- 主体主动移动不等于 n/x并z 已独立过门；
- **所谓“入口控制者”是否真的能阻止对象跨界，优先看现实可否决而非名义门禁。**

### 金轴 xn↔z
- 运行骨架 vs 最终裁定节点分离；
- 节点替代 vs 接口层不变；
- 当前执行权与历史授权分离；
- 局部执行节点被推回不等于最高裁定点换位；
- 主体计划很多不能替代 xn 运行骨架重组；
- **最高名义裁定者 ≠ 实际 z；要检查谁能在流程落地前真实否决/改写最终裁定。**

### 水轴 xz↔nz
- 同一结果对象测试；
- 路径失效 vs 目标改变；
- 时间窗口闭环；
- 第三因素冻结；
- 局部回返空间恢复不等于整体命运路径恢复；
- 主体想回去/不想回去不等于 nz/xz 已独立成立；
- **名义上“允许回返”的通道若无法现实放行/阻断，不得机械计入真实回返空间。**

### 跨轴通用五问｜现实否决模板

```text
1. 谁名义拥有该接口？
2. 谁能在结果生效前真实说“不”？
3. 这个“不”能否改变、阻止或延迟同一结果？
4. 被否决后主体是否必须重配、等待或换通道？
5. 主体是否存在稳定绕过该节点、仍实现同一结果的路线？
```

这套五问用于判断“名义结构”是否真的构成当前有效边界，不直接替代任何一轴自己的端点硬判据。

## 8｜整理纪律

1. 正本 > 信息卡 > 准度卡 > 补卡 > pending-review > evidence/candidate。
2. 运行记录只证明该轮事实/边界，不自动升级正本。
3. 同一机制已有 pending-review 时，新案例优先补控制、反例或方法，不再平行制造同义待审议文件。
4. 新边界不足 3 部独立作品时，保留 evidence/candidate，不抢跑。
5. 无真实新增/修正时不提交。
6. 后续整理优先更新本总纲，不制造“总纲的总纲”。
7. 反向护栏若只是细化既有 pending-review，应并入原主干和总纲。
8. 严格对子研究先分别锁两端；主动、强势、自有目标、外部借力都不能替代端点硬判据。
9. 任何“主动绕过外部接口”的跨作品计数前，先验证 P1 当前仍真实开放可用。
10. 主动性/自有目标只能作为候选背景，不能替代任何十元端点自己的硬判据。
11. **同一历史事件的史料版、演义版、影视版可以用于复验鲁棒性，但不得机械增加独立作品计数。**
12. **权限类判断先做“现实否决五问”；名义上级、所有者、批准人、事后回报链都不能单独推出 nx。**
