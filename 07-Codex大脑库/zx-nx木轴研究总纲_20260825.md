## 1｜木轴当前骨架

```text
zx：主体占据最终方向与作用权来源，并把自身权能压入现实。

nx：主体不占最终方向；关键权限、资源或解决接口仍在外部；主体真实沿既有关系、权限、流程或通道续接。
```

禁止直接用：强弱、身份、职业、胜负、听话、求人一次、主动性、有无明确目标来判十元。

## 2｜最近邻地图

### 2.1 zx vs x

```text
x：冲突前已经拥有该对象域稳定调用/处分权，现在把它用出来。
zx：决定范围、影响位置或凌驾程度推进到原本不属于主体的对象域/层级。
```

稳定纪律：**权力有效 ≠ 权力扩大。**

### 2.2 nx vs x

```text
nx：关键许可/资源/保护/专业接口仍外置，主体不能稳定自行调用。
x：权限/资源已经稳定进入主体直接调用边界。
```

“有人参与 / 部下执行 / 使用组织资源”不是 nx 充分证据。

### 2.3 nx vs xn

```text
nx：沿别人已有方向、权限、接口推进。
xn：主体自己搭人员、资源、节点、流程、排程与运行骨架。
```

可同时存在：上位任务 nx + 局部 x + 自搭 xn，不能重复计数。

## 3｜nx / zx 已形成的研究主干

### 3.1 对象分层｜pending-review

高层最终方向非 nx，不覆盖局部保护/许可/资源 nx；局部 nx 也不得倒灌成长期终点 nx。

正向：关羽、林冲、鸳鸯。反向：探春、马谡、宋江。

### 3.2 nx 激活与退出窗口｜pending-review

nx 按当前执行窗口判断，不是历史关系永久标签。

已锁退出机制：
1. 方案失效；
2. 环境不可持续；
3. 许可节点撤回/反转；
4. 通道仍有效，但主体当前最高行动目标改变并停止续接。

### 3.3 具体节点可替代 vs 接口层不可绕过｜pending-review

换具体人不等于摆脱 nx。真正削弱 nx 的是：存在稳定、可重复、不经等价外部接口、仍实现同一结果的内部路线。

前置门：

```text
P1 当前开放可用
+ 主体主动不走
+ P2 不依赖等价外部接口
+ 同一结果完成
→ 才计“可用 P1 主动内部绕行”
```

关羽五关、甘地自取盐为正向；武松、玄奘、孙悟空二调芭蕉扇、凯撒为不同反筛选护栏。

### 3.4 外部对象 / 处分域在场 ≠ nx｜pending-review

孙悟空生死簿、李逵劫法场、董卓废立形成三作品控制：

> 对象/处分域在外，只证明外部性；主体若没有沿接口续接，而是直接压掉原接口当前否决/处分能力并改写同一结果，优先检查 zx。

护栏：探春抄检只压回局部越界，不等于整体搜检接口失效。

### 3.5 主动目标 + 外部通道 ≠ zx+nx｜pending-review

王熙凤铁槛寺、刘备三顾茅庐、林冲投梁山跨三作品支持：

> “我自己想干 + 我很主动 + 我真实走外部接口”不能自动推出 zx+nx。zx 必须另证公开显权与决定范围新增。

### 3.6 名义权限 vs 现实否决权｜P4 pending-review

当前方法拆两门：

```text
A 实效门：外部节点真的能卡住同一结果吗？
B 激活门：该接口本轮真的进入主体行动链了吗？
```

最强因果拨动：

```text
拒绝 → 同一结果停住 → 放行 → 同一结果恢复
```

证据分档：A 因果拨动；B 有效拒绝；C 只改条件/时间/方式；D 名义反对但结果照常。

### 3.7 秘密改结果 ≠ 公开扩权 zx｜pending-review × 四大名著

当前已由四部独立作品复现：

- 《西游记》孙悟空偷桃偷酒偷丹；
- 《三国演义》周瑜蒋干盗书；
- 《红楼梦》王熙凤毒设相思局；
- 《水浒传》宋江私放晁盖。

共同纪律：

```text
隐匿 / 欺骗 / 诱导 / 绕权 / 时序组织
→ 具体结果成功改变
→ 但现实没有围绕主体新增的公开决定接口运行
≠ zx
```

宋江新增“系统内部秘密反向型”控制：主体可以拥有正式职位或信息入口 `x`，并利用该入口 + `xn` 时序组织秘密破坏系统结果；只要没有公开扩张处分边界，仍不得因为“事情办成”升级 zx。

阶段护栏：司马懿诈病 → 高平陵证明同一人物必须切段：秘密布局阶段优先 `xn / 非zx`，公开夺权后重新检查 zx；后段不能倒灌前段。

## 4｜严格 zx↔nx 补｜2026-08-26 重大纠偏

### 4.1 当前最低门

0. zx、nx 两端先独立成立；
1. 两端直接作用于同一当前现实瓶颈；
2. 拿掉 nx，zx 自身留下不可替代缺口；
3. 拿掉 zx，nx **自身核心功能**也留下不可替代缺口；
4. 两缺口在同一有效时间窗口；
5. 反向缺口不能只是“没有调用者/触发者/行动者/兑换者”；
6. 双向缺口不能主要由共同第三因素制造；
7. 第三因素冻结必须保留 zx、nx 与目标瓶颈。

### 4.2 旧严格补判据系统性过宽｜pending-review

新双向拿掉门回扫后，以下旧“严格补”子结论已撤回：

- 三国演义：孙策质玺借兵 → `nx→zx` 单向补；
- 三国演义：曹操陈留借卫弘家资 → `nx→zx` 单向补；
- 水浒传：宋江高唐州 → `nx→zx` 单向补；
- 红楼梦：鸳鸯抗婚 → `nx→zx` 单向补；
- 西游记：孙悟空红孩儿 → `nx→zx` 单向补，只保留 nx 窗口关闭。

跨四作品共同错误：

```text
“没有 zx，nx 条件不会自动生成共同结果”
≠
“没有 zx，nx 自身核心功能会受损”
```

因此当前：

```yaml
verified_high_purity_strict_zx_nx_positive_count: 0
verified_strict_temporal_window_control_count: 0
```

这不等于严格补不存在，只表示旧高纯正例在新门槛下全部需要重建。

### 4.3 当前已锁单向补

尤三姐、鲁达五台山、孙悟空定风丹、孙策质玺借兵、曹操卫弘、宋江高唐州、鸳鸯抗婚、孙悟空红孩儿。

统一结构：

```text
nx→zx：成立
zx→nx：没有打到 nx 自身核心功能
→ 单向补
```

### 4.4 严格补时间窗口与 nx 窗口必须拆开

仍可保留：

```text
nx 真实激活
→ 任务完成 / 瓶颈消失 / 接口退出 / 资源内化
→ 旧 nx 不得永久追挂后续阶段
```

但禁止继续用单向补案例证明“严格补闭环”。

时间窗口首先是 **nx 动态纪律**；严格补闭环必须先证明初始双向严格补。

### 4.5 第三因素冻结

“冻结有效性护栏”已跨三作品复验：曹操陈留、宋江高唐州、鸳鸯抗婚。

方法仍有效，即使这些案例的旧严格补子结论已撤回：

> 冻结不能直接删掉被测试端点或当前命名瓶颈。

“第三因素制造表面双向缺口”目前仍只有刘备联孙抗曹一部高纯控制，继续补样本。

## 7｜可迁移到火/土/金/水的方法

可直接复用：

1. 对象层拆分；
2. 最近邻排除；
3. 拿掉 / 反向测试；
4. 当前执行窗口；
5. 现实否决因果拨动；
6. P1 当前可用性检查；
7. 第三因素冻结；
8. 对子第0门：两端先独立成立；
9. **反向补缺必须打到另一端自身结构，不能只证明共同结果需要两个参与者；**
10. 新方法出现后必须回扫旧高置信正例，重算 control_count/cross_work_count；
11. **结果变化与权能位置变化分离**：秘密操纵、诱导或时序组织可以改变结果，但不能自动证明任何轴的“位置/边界/归属/裁定/去向”端点发生结构升级；
12. **阶段切分禁止倒灌**：后段公开结构变化不能反向证明前段秘密准备已经属于同一端点。

跨轴原则：

> 火/土/金/水以后判断“严格补”时，同样必须区分“另一端自身结构真的受损”与“共同产物只是少了一个行动/触发端”。

秘密改结果方法的跨轴迁移：

- 火轴 `zn↔x`：秘密影响对象归属结果，不等于主体公开取得归属/处分边界；
- 土轴 `n↔x并z`：秘密绕过空间边界成功，不等于空间边界本身已被主体重写；
- 金轴 `xn↔z`：幕后安排结果，不等于主体成为公开最高裁定点；
- 水轴 `xz↔nz`：秘密改变一次去向，不等于现实回返空间或不可逆结构已经被稳定改写。

## 8｜仓库治理纪律

- 正本高于本总纲。
- evidence-locked 不自动升级正本。
- 同一结论优先归并总纲/待审议，不重复造同义文件。
- 新方法推翻旧子结论时，保留原事实资产，但必须明确 `superseded-subconclusion`。
- cross-work 只按独立作品计，同一历史事件不同版本不重复计数。
- 没有真实新增/修正不提交。
