本文件只做研究资产消化、索引、状态压缩与方法论沉淀，不替代 L1、信息卡、准度卡或补卡。


新纪律必须经过：事实链 → 最近邻排除 → 拿掉 → 反向 → 第三因素冻结 → 跨作品复验，才有资格上提；不足 3 个独立作品时不抢跑。

## 1｜木轴当前最稳定骨架

```text
zx：主体占据最终方向与作用权来源，并把自身权能压入现实。

nx：主体不占最终方向；关键权限、资源或解决接口仍在外部；主体真实沿既有关系、权限、流程或通道续接。
```

必须冻结：强弱、身份、职业、胜负、听不听话、求人一次、是否主动、是否有明确目标等表面变量。

## 2｜最近邻判定地图

### 2.1 zx vs x

```text
x：本来已经拥有该对象域稳定调用/处分权，现在把它用出来。
zx：决定范围、影响位置或凌驾程度推进到原来不属于主体的对象域/层级。
```

纪律：**权力有效 ≠ 权力扩大。**

- 反例：唐僧逐悟空、贾母阻鸳鸯、诸葛亮斩马谡 → 已有权限成功行使，优先 x。
- 正向：孙悟空幽冥生死簿、刘备益州、林冲火并王伦 → 旧 x 存在，但新对象域被推进，zx 可新增。

状态：pending-review。

### 2.2 nx vs x

```text
nx：关键许可/资源/保护/专业解决接口当前仍外置，主体不能稳定自行调用。
x：权限或资源已经稳定进入主体当前直接调用边界。
```

“有人参与 / 部下执行 / 使用组织资源”都不是 nx 充分证据。

### 2.3 nx vs xn

```text
nx：沿别人已有方向、权限或通道推进。
xn：主体自己组织人员、资源、节点、流程、排程或运行骨架。
```

同一桥段可以同时存在：上位任务 nx + 局部权限 x + 主体运行重构 xn，不能互相覆盖或重复计数。

## 3｜nx 已形成的稳定研究分支

### 3.1 对象分层

高层最终方向非 nx，不覆盖局部保护、许可、资源、专业接口 nx；反过来局部 nx 也不得倒灌成长期终点 nx。

- 正向：关羽、林冲、鸳鸯。
- 反向：探春、马谡、宋江。
- 同段分层：曹操许田射鹿，前段资源许可层 nx，后段象征/决定位置层 zx。

```text
A层 nx + B层 zx
≠ 同一对象层
≠ 自动严格补
```

状态：pending-review；许田案 evidence-locked。

### 3.2 nx 激活与退出窗口

nx 不是历史关系永久标签，必须按当前执行窗口判断。已锁四类退出机制：

1. 方案失效；
2. 环境使通道不可持续；
3. 许可节点撤回/反转；
4. 通道仍有效，但主体当前最高行动目标改变并主动停止续接。

状态：pending-review。

### 3.3 具体节点可替代 vs 外部接口层不可绕过

换具体人不等于摆脱 nx；真正削弱 nx 的是：存在稳定、可重复、不经等价外部接口、仍实现同一结果对象的内部路线。

- 正向：关羽五关、甘地自取盐。
- 护栏：武松换结果对象；玄奘换地方外部接口；孙悟空二调芭蕉扇自搭 xn 但真扇/口诀仍外置；凯撒越卢比孔 P1 已关闭，不能冒充“可用 P1 主动绕过”。

前置门：

```text
P1 当前开放可用
+ 主体主动不走
+ P2 不依赖等价外部接口
+ 同一结果完成
→ 才计“可用 P1 主动内部绕行”

P1 已撤回 / 关闭 / 反转
→ 只证明旧 nx 窗口退出后的内部续行
→ 不计上述模板正例
```

状态：pending-review 主干；凯撒 evidence-locked negative guard。

### 3.4 外部对象／处分域在场 ≠ nx

三部独立作品已形成 pending-review：孙悟空强取生死簿、李逵江州劫法场、董卓废立。

```text
对象 / 处分接口 / 最终结果域在外部
≠ 主体正在沿外部接口续接
```

若主体直接压掉原持有者当前否决/处分能力，并以自身权能改写同一结果，优先检查 zx。

护栏：
- 曹操许田射鹿前段确实经过献帝许可，是真 nx；
- 探春抄检只压回局部越界，不等于整个上位搜检接口失效。

对象层纪律：**被压掉的接口层，必须与声称被改写的结果层一致。**

### 3.5 主动目标 + 外部通道 ≠ zx+nx 共现

三部独立作品：王熙凤铁槛寺、刘备三顾茅庐、林冲投梁山。

```text
主体自己有目标
+ 很主动 / 坚持 / 执行强
+ 关键权限 / 资源 / 专业方案仍在外部
+ 主体真实沿外部接口推进
≠ 自动 zx + nx
```

自有目标与主动性不能替代 zx 的公开显权与决定范围新增；nx 完全可以出现在主动、强势、有明确目标的主体上。

状态：pending-review。与严格补“第0门”合流使用，但不合并文件。

### 3.6 名义权限 vs 现实否决权｜P4

对应：`待审议问题_nx真实外部权限需具可否决性_20260817.md`

当前最强方法已沉淀到：
`方法卡_zx-nx现实否决因果拨动与跨轴迁移_20260825.md`

已有三部正向作品：平儿—凤姐、吴用—宋江、孙悟空—观音。

已有反向：诸葛亮—刘禅、曹操—献帝、王熙凤处分后回覆。

最新方法控制：
- 《三国演义》曹操弑董贵妃：献帝事前求情仍无法卡住结果 → 名义最高无现实否决，当前非 nx；`zx vs x` deferred。
- 《水浒传》公孙胜二仙山：罗真人拒绝 → 下山结果停住；后来放行 → 同一结果恢复 → A档“现实否决因果拨动”，99/98 evidence-locked。
- 《红楼梦》贾政笞宝玉遇贾母：贾母介入后处分停止，贾政承接上位方向；同场还能与“宝玉被动获救但本人未激活 nx”形成主体激活差异。99/98 evidence-locked。

P4 当前应拆两门：

```text
A｜实效门：外部节点真的能卡住同一结果吗？
B｜激活门：该接口在本轮真的进入主体行动链了吗？
```

现实否决六问：

```text
1. 谁名义上拥有权限？
2. 谁能在结果生效前真实说“不”？
3. 这个“不”能否阻止、修改或延迟同一结果？
4. 被否决后主体是否必须等待、重配、再次请求或换通道？
5. 主体能否绕过该节点并稳定让同一结果生效？
6. 若同一节点后来放行，原结果是否随之恢复可执行？
```

证据分档：
- A档：拒绝 → 同一结果停住 → 放行 → 同一结果恢复；
- B档：有效拒绝 → 结果停止/被迫换通道；
- C档：只能修改条件、资源量、时间或执行方式，必须按对象层判；
- D档：仅建议/名义反对，结果可照常生效，不足以锁 nx。

最短方法句：**不要先问谁职位最高，先问结果生效前谁真的能让它停下来；再问主体有没有实际沿这个接口走。**

状态：P4 pending-review；方法卡 method-working；不增加跨作品计数。

## 4｜zx↔nx 严格补研究

### 4.1 严格补最低门槛

0. zx、nx 两端先分别独立成立；
1. 两端直接作用于同一当前现实瓶颈；
2. 拿掉 nx，zx 留下不可替代缺口；
3. 拿掉 zx，nx 也留下不可替代缺口；
4. 两缺口位于同一有效时间窗口；
5. 双向缺口不能主要由共同第三因素制造；
6. 第三因素冻结必须保留 zx、nx 与目标瓶颈，不能把题目冻没。

### 4.2 已分出的伪补类型

- 单端未独立过门：王熙凤铁槛寺、刘备三顾茅庐、林冲投梁山；
- 对象层错位：两端都真，但不是同一现实变量；曹操许田射鹿是紧邻反例；
- 单向补缺：nx→zx 成立，但 zx→nx 不成立；
- 时间窗口闭环：历史严格补成立，但任务结束或资源内化后旧补退出；
- 第三因素伪双向：共同敌人、制度压力等制造表面互需。

状态：多项 pending-review，禁止直接写入正本。

## 6｜待审议清单与高价值缺口

### 已达到跨作品 pending-review 的主干

- zx vs x：已有权限成功行使 ≠ 扩权；旧 x 不妨碍新对象域新增 zx。
- nx 对象分层不可覆盖：高层非 nx 与局部 nx 可并存；已有 x/xn 不得重复计局部 nx。
- nx 激活与当前通道持续有效性：历史 nx 不永久继承。
- nx 具体节点可替代与外部接口层不可绕过：换具体人不等于摆脱外部接口层。
- 外部处分域在场但未激活 nx：对象/处分域在外不等于 nx。
- 主动目标 + 外部通道不等于 zx+nx 共现。
- nx 真实外部权限需具可否决性：名义权限不是充分证据；P4 已有因果拨动方法卡。
- 严格补对象层 / 时间窗口 / 单向补 / 第三因素：多项 pending-review。

### P2｜高成本内部绕行第三独立作品

仍是最高价值缺口之一。第三作品必须同时满足：P1 当前开放可用、主体主动不用、同一结果对象、P2 实际成功、P2 不依赖等价外部许可/关系/关键资源转移。

### P3｜第三因素冻结跨作品复验

当前主要由刘备联孙抗曹伪双向控制 + 曹操卫弘有效冻结护栏支撑。下一步优先从《西游记》《水浒传》《红楼梦》找非“共同敌人”机制：共同资源稀缺、制度规则、身份门槛等。

### P4｜现实否决强度阈值

P4 基础判定已经方法化，不再优先堆“上级说不”的同型案例。下一步测试：

1. 完全否决 vs 只能延迟；
2. 完全否决 vs 只能修改执行方式；
3. 单一节点否决 vs 存在等价外部替代节点；
4. 一次有效否决 vs 长期稳定可绕过；
5. 局部资源否决 vs 整体结果否决。

## 7｜可迁移到火 / 土 / 金 / 水的方法

这些方法只验证边界，不替代各轴端点硬定义：

- **对象层拆分**：不同层结果不得互相覆盖。
- **拿掉 / 反向测试**：判断端点是否真实必要。
- **当前执行窗口**：历史关系不能永久继承。
- **现实否决因果拨动**：拒绝是否让同一结果停住，放行是否恢复。
- **P1 当前可用性检查**：区分主动绕行与旧通道失效后内部续行。
- **第三因素冻结**：保留被测端点与瓶颈，只移除外生干扰。
- **严格对子第0门**：先分别锁两端，再谈补。

跨轴映射：

```text
火 zn↔x：名义归属者能否真实阻止对象被纳入处分边界？
土 n↔x并z：名义入口控制者能否真实阻止对象跨界？
金 xn↔z：名义最高裁定者能否在流程落地前真实停掉/改写最终裁定？
水 xz↔nz：名义回返许可是否真的能关闭/恢复现实回返路径？
```

## 8｜整理纪律

1. 正本 > 信息卡 > 准度卡 > 补卡 > pending-review > evidence/candidate。
2. 运行记录只证明该轮事实/边界，不自动升级正本。
3. 同一机制已有 pending-review 时，新案例优先补控制、反例或方法，不再制造同义待审议文件。
4. 新边界不足 3 部独立作品时保留 evidence/candidate，不抢跑。
5. 无真实新增/修正时不提交。
6. 后续优先更新本总纲，不制造“总纲的总纲”。
7. 反向护栏若只是细化已有主干，优先并入原 pending-review 与本总纲。
8. 严格对子先分别锁两端；主动、强势、自有目标、外部借力不能替代端点硬判据。
9. 任何“主动绕过外部接口”跨作品计数前，先验证 P1 当前仍开放可用。
10. 同一历史事件的史料版、演义版、影视版可用于鲁棒性复验，但不得机械增加独立作品计数。
11. 权限类判断优先调用 `方法卡_zx-nx现实否决因果拨动与跨轴迁移_20260825.md`；名义身份、事后回报都不能单独推出 nx。
12. P4 必须同时检查“接口是否真实有效”与“主体本轮是否实际激活接口”。
