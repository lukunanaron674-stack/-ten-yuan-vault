# zx↔nx 木轴研究总纲｜2026-08-25

## 0｜用途

本文件只做研究资产消化、索引与状态压缩，不替代 L1、信息卡、准度卡或补卡。任何新纪律必须先经过运行记录 / 候选 / pending-review，再决定是否有资格进入正本。

## 1｜当前木轴最稳定骨架

```text
zx：主体占据最终方向与作用权来源，并把自身权能压入现实。
nx：主体不占最终方向，关键权限/资源/解决接口仍在外部，主体真实沿既有关系、权限、流程或通道续接。
```

必须同时冻结人物性格、强弱、职业、身份、胜负、听话与否、是否求人一次等表面变量。

## 2｜最近邻判定地图

### 2.1 zx vs x

```text
x：本来已经拥有该对象域的稳定调用/处分权，现在把它用出来。
zx：决定范围、影响位置或凌驾程度真实推进到原来不属于主体的对象域/层级。
```

关键纪律：权力有效不等于权力扩大；比较的是“本轮这个对象域此前是否已归主体决定”。

已形成跨作品待审议：
- 唐僧逐悟空 / 贾母阻鸳鸯 / 诸葛亮斩马谡：已有权限成功行使，优先 x。
- 孙悟空幽冥生死簿 / 刘备益州 / 林冲火并王伦：旧 x 存在，但新对象域被主体推进，zx 可新增。

### 2.2 nx vs x

```text
nx：关键许可/资源/保护/专业解决接口当前仍外置，主体不能稳定自行调用。
x：权限或资源已经稳定进入主体当前直接调用边界。
```

不得因“有人参与 / 部下执行 / 使用组织资源”重复计 nx。

### 2.3 nx vs xn

```text
nx：沿别人已有方向/权限/通道推进。
xn：主体自己组织人员、资源、节点、流程、排程或运行骨架。
```

同一桥段可并存：上位任务 nx + 局部 x + 运行重构 xn。

## 3｜nx 研究已稳定分支

### 3.1 对象分层

高层最终方向非 nx，不覆盖局部保护/许可/资源/专业接口 nx；反过来局部 nx 也不得倒灌成长期终点 nx。

正向跨作品：关羽、林冲、鸳鸯。
反向跨作品：探春、马谡、宋江，证明“局部有人参与”不等于局部 nx。

2026-08-25 新增《三国演义》曹操许田射鹿控制，补出第三种对象分层用途：**同一短桥段里可以先在资源/许可层真实成立局部 nx，随后又在另一个象征/决定位置层高显影 zx。前段 nx 不能覆盖后段 zx，后段 zx 也不能倒灌抹掉前段 nx；两端同段共现仍不等于同一对象层，更不等于严格补。**

最小模板：

```text
A对象层：外部许可/资源接口仍真实有效，主体沿接口调用
= nx

B对象层：主体未经新的上位授权，直接把自身决定/象征位置推入原本不属于自己的范围
= zx

A 与 B 不同对象层
→ 可共现
→ 不得互相覆盖
→ 不得仅凭共现判严格补
```

状态：pending-review 主干不变；曹操许田案作为 `evidence-locked` 分层反例并入，不另建同义待审议。

### 3.2 nx 激活与退出窗口

nx 不是历史关系永久标签，必须按当前执行窗口判断。

目前已锁四类退出机制：
1. 方案失效；
2. 环境使通道不可持续；
3. 许可节点撤回/反转；
4. 通道仍有效，但主体当前最高行动目标改变并主动停止续接。

状态：pending-review。

### 3.3 具体节点可替代 vs 外部接口层不可绕过

A 节点失败后改走 B 节点，如果同一现实瓶颈仍必须经过某类外部许可/资源/裁决接口，nx 可以持续。

真正削弱 nx 的不是“换人”，而是存在稳定、可重复、不经等价外部接口、仍实现同一结果对象的内部路线。

正向控制：
- 关羽五关、甘地自取盐：当前正常 P1 仍作为现实可走路线存在，但主体实际不用 P1，而以不依赖等价外部关键接口的高成本 P2 完成同一结果对象。

反向护栏：
- 武松：不能把“换结果对象”冒充同结果绕过；
- 玄奘：绕官方许可但继续依赖地方外部接口；
- 孙悟空二调芭蕉扇：方案由主体自搭 xn，但真扇/口诀仍外置，因此仍有局部 nx；
- **凯撒越卢比孔**：当前执行窗口中旧军权已被元老院要求终止，合法携军进入意大利的 P1 已关闭/反转。凯撒确实依靠已内化的军团 `x` 完成同一物理结果，但这只能证明“P1 关闭后的内部续行”，不能冒充“P1 仍开放可用而主体主动绕过”的第三正例。

由凯撒护栏新增的前置门：

```text
先检查 P1 当前状态

P1 当前开放、可用
+ 主体主动不走
+ P2 不依赖等价外部接口
+ 同一结果完成
→ 才进入“可用 P1 主动内部绕行”模板

P1 已撤回 / 关闭 / 反转
+ 主体依靠既有 x 继续实现结果
→ 只能证明旧 nx 当前窗口退出 / 通道失效后的内部续行
→ 不计入前述模板的跨作品正例数量
```

状态：pending-review 主干不变；凯撒案为 `evidence-locked / near-positive boundary guard`，不计第三正例。

### 3.4 外部对象／处分域在场 ≠ nx

已形成三部独立作品控制：
- 《西游记》孙悟空幽冥强取生死簿：外部簿册/处分接口在场，但主体不沿阴司许可接口，而是强取并亲自改写结果。
- 《水浒传》李逵江州劫法场：外部人身/司法处分接口在场，但主体不沿赦免/司法许可接口，而是直接中断执行链并改写同一结果。
- 《三国演义》董卓废少帝立陈留王：皇帝废立处分域原本不属于董卓既有军权，但董卓没有沿太后/百官许可门推进，而是直接压掉反对与否决位置并完成废立。

共同窄变量：

```text
关键对象、处分接口或最终结果域原本在外部
≠
主体沿外部权限接口续接
```

若主体以自身权能直接压掉原持有者当前否决/处分能力，并使同一结果转由自身强制作用改写，优先检查 `zx`；只有在关键权限/资源随后稳定进入主体可直接处分边界时，才进一步检查局部 `x`，不能因为对象原本在别人手里重复计 `nx`。

状态：**pending-review，cross_work_count = 3，negative_guard_count = 1**。对应文件：
`07-Codex大脑库/待审议问题_zx-nx外部处分域在场但未激活nx边界_20260825.md`

与“nx 权限外置与实际通道激活”相邻但不合并：前者一般检查接口是否实际激活；本问题专门锁定更强的反向结构——**接口不只是未被沿用，而是被主体直接压掉并改写同一结果。**

已并入两个反筛选护栏：

1. **曹操许田射鹿**：御弓/金箭调用前确实经过献帝许可，前段是真实 nx；不能为了凑样本把“沿接口调用”和“压掉接口”混成一种。
2. **《红楼梦》探春抄检秋爽斋**：上位搜检授权仍有效，探春也接受部分检查；她压掉的是局部越界搜身/搜丫头方式，而不是整个上位搜检任务。因此“局部拒绝/局部限缩/击退执行者”不等于“整体处分接口失效”。

由探春护栏新增的对象层纪律：

```text
被压掉的接口层
必须与
声称被主体改写的结果层
保持一致
```

若上位任务仍继续运行，只是某个子对象或执行方式被主体限缩，则只能记录局部 zx / 局部非 nx，不能升级成“整体接口被压掉”。

### 3.5 主动目标 + 外部通道 ≠ zx+nx 共现

已由三部独立作品形成 `pending-review`：
- 《红楼梦》王熙凤铁槛寺：主体自己接下请托并推动退亲，但真正跨权限靠“贾府关系 → 云光 → 守备”外部链；本窄阶段 nx 成立，zx 未独立过门。
- 《三国演义》刘备三顾茅庐：主体已有政治目标、主动求贤，但关键战略方案来自诸葛亮这一外部专业解决接口；主动性与自有目标不足以锁 zx。
- 《水浒传》林冲投梁山：主体已有安身/入伙目标，也主动执行投名状，但梁山准入权在王伦；林冲真实沿外部准入条件推进，本窄阶段仍没有 zx 所需的决定范围新增。

共同纪律：

```text
主体自己有目标
+ 主体非常主动、坚持、执行
+ 关键权限 / 资源 / 专业方案仍在外部
+ 主体真实沿外部接口推进
≠
自动得到 zx + nx
```

必须先分别过门：
- 自有目标、主动性、坚持、行动强度只说明“主体不是没有方向”，不能替代 zx 的公开显权与决定范围新增；
- nx 可以发生在非常主动、非常有目标的主体上，只要关键接口当前仍外置且被主体真实沿用。

对应文件：
`07-Codex大脑库/待审议问题_zx-nx主动目标加外部通道不等于zx-nx共现边界_20260825.md`

该问题与严格补“第0门”合流使用，但不与严格补待审议文件合并：前者解决“两端是否真的同时成立”，后者解决“两端成立以后是否构成严格补”。

## 4｜zx↔nx 严格补研究

### 4.1 严格补最低门槛

1. zx 独立成立；
2. nx 独立成立；
3. 两端直接作用于同一当前现实瓶颈；
4. 拿掉 nx，zx 留下不可替代缺口；
5. 拿掉 zx，nx 也留下不可替代缺口；
6. 两个缺口位于同一有效时间窗口；
7. 双向缺口不能主要由共同第三因素制造。

### 4.2 已分出的伪补类型

- **单端未独立过门**：现已由王熙凤铁槛寺、刘备三顾茅庐、林冲投梁山跨三作品形成独立 `pending-review`。三例共同证明，“主体自己定目标 + 主动执行 + 沿外部通道办成”可以是高纯 nx，但若 zx 没有独立达到公开显权/决定范围新增门槛，就连 `zx+nx` 共现都不能先假定，更不能进入严格补。
- 对象层错位：两端都真，但不是同一现实变量；曹操许田射鹿现提供“同一短桥段先 nx 后 zx、仍因对象层不同而非严格补”的紧邻反例；
- 单向补缺：nx→zx 成立，但 zx→nx 不成立；
- 时间窗口闭环：历史上严格补成立，但任务结束/资源内化后旧补关系退出；
- 第三因素伪双向：共同敌人、制度压力等制造表面互需。

因此严格补的第0门现在明确为：**先分别证明两端真实成立，再做补关系测试。主动、有主见、自己定目标、幕后操盘成功，都不能替代 zx 独立过门。**

状态：多项 pending-review，禁止直接写入正本。

## 6｜待审议清单与当前高价值缺口

### 已达到跨作品 pending-review 的主干

- `zx vs x`：已有权限成功行使 ≠ 扩权；旧 x 不妨碍新对象域新增 zx。
- `nx 对象分层不可覆盖`：高层非 nx 与局部 nx 可并存；已有 x/xn 不得重复计局部 nx。
- `nx 激活与当前通道持续有效性`：历史 nx 不永久继承；方案失效、环境失效、许可反转、主体目标改变均可关闭旧窗口。
- `nx 具体节点可替代与外部接口层不可绕过`：换具体人不等于摆脱外部接口层；同结果纯内部绕行才真正削弱 nx；其中“可用 P1 主动绕行”必须额外证明 P1 当前仍开放可用，凯撒护栏已排除 P1 已关闭/反转的伪第三正例。
- `外部处分域在场但未激活 nx`：对象/处分域在外不等于 nx；直接压掉接口并改写同一结果优先查 zx；探春护栏已进一步锁定“必须是同一对象层的最终处分接口失效”。
- `主动目标 + 外部通道不等于 zx+nx 共现`：自有目标与主动性不能替代 zx 独立过门；王熙凤、刘备、林冲三作品已形成 99/98 同型控制。
- `严格补对象层/时间窗口/单向补/第三因素`：多份 pending-review 已形成；“先独立锁两端”的第0门现已有独立三作品 pending-review 支撑，但仍不直接改正本。

### P1｜外部处分域在场但未激活 nx：第四作品正向复验

三作品门槛已满足，《红楼梦》探春也已经提供第一份高纯反向护栏，因此 P1 不再优先机械寻找“强烈拒绝”的材料。

当前若继续扩 P1，只接受真正满足以下结构的第四作品正向复验：

```text
上位处分接口原本真实有效
→ 主体完全不沿该接口
→ 与被测结果同层的最终否决/处分能力失效
→ 同一结果对象被主体自身权能改写
```

探春已经证明以下结构不够：

```text
局部拒绝 / 局部限缩 / 击退执行者
+
上位任务仍有效并继续运行
≠
整体接口被压掉
```

P1 当前从“急需第四作品”降为**成熟待审议 + 反向护栏已建立**，后续优先级低于 P2/P3/P4。

### P2｜高成本内部绕行的充分条件

当前木轴最值得继续补的材料之一。继续找与关羽/甘地同型、但机制不同的第三部独立作品，必须先通过凯撒护栏，再确认：
- **P1 在当前执行窗口仍开放、可用，并且主体现实上可以选择沿用；**
- 主体主动不使用 P1；
- 同一结果对象；
- P2 实际成功；
- P2 不依赖等价外部许可/关系/关键资源转移；
- 高成本本身不影响是否 nx。

不得把以下结构计入第三正例：

```text
P1 已撤回 / 关闭 / 反转
→ 主体依靠已有 x 或内部资源继续推进
```

这类材料用于研究“nx 通道失效后的内部续行”，不用于证明“仍可用 P1 被主体主动绕过”。

### P3｜第三因素冻结方法

当前只有刘备联孙抗曹一组高纯伪双向控制和曹操卫弘一组有效冻结护栏；需要《西游记》《水浒传》或《红楼梦》继续复验。

### P4｜名义权限 vs 现实否决权

杨志等控制已经强化“纸面授权≠稳定 x/nx 判定”，但仍需继续压缩成可迁移方法模板：优先检查结果生效前谁拥有真实否决。

## 7｜可迁移到其他四轴的方法论

以下模板不是木轴专属，可迁移：

### 火轴 zn↔x
- 对象层拆分；
- 拿掉测试；
- “名义归属 vs 实际处分边界”冻结；
- 既有边界与新纳入边界比较；
- 局部归属变化不得倒灌成整体本体归属变化；
- 严格对子前先独立锁两端；
- **“主体自己想成为/保持某种本体”不能替代 zn 独立成立；自有愿望与真实成立资格必须分开。**
- **历史上存在某归属接口，不等于当前仍开放；先检查当前归属入口是否有效，再判断主体是主动绕过还是接口已经失效。**

### 土轴 n↔x并z
- 内外对象层命名；
- 相同对象跨边界前后对照；
- 外部参与不等于已经纳入；
- 结果对象一致性测试；
- 局部边界穿透不等于整体空间边界改写；
- 严格对子前先做两端独立成立测试；
- **主体主动移动/进入/推出对象，不等于 n 或 x并z 已独立过门；仍要检查真实跨界方向与承载/外化结果。**
- **历史通道存在 ≠ 当前通道开放；比较内部穿越与外部通道时先冻结当前可用性。**

### 金轴 xn↔z
- 运行骨架 vs 最终裁定节点分离；
- 节点替代 vs 接口层不变；
- 时间窗口；
- 当前执行权与历史授权分离；
- 局部执行节点被推回不等于最高裁定节点已经换位；
- 自己组织流程不能自动推出 xn 与 z 同时高显影，仍需分别过门；
- **“主体很主动、计划很多”只能作为 xn 候选，不能替代运行骨架确实由主体重组这一硬门。**
- **比较“主动改走自有流程”和“原流程被关闭后重建”时，必须先检查旧流程当前是否仍可用。**

### 水轴 xz↔nz
- 同一结果对象测试；
- 路径失效 vs 目标改变；
- 时间窗口闭环；
- 第三因素冻结，防止把共同压力误判成两端内生关系；
- 局部回返空间恢复不等于整体命运路径恢复；
- 严格对子前先分别证明收窄端与回返端真实成立；
- **主体主观上想回去/不想回去，不等于 nz/xz 已独立成立；必须检查现实回返空间或不可逆收窄是否真的改变。**
- **区分“仍有回返路但主动不走”与“回返路已经关闭”：两者都可能表现为不回返，但机制不能合并。**

## 8｜整理纪律

1. 正本 > 信息卡 > 准度卡 > 补卡 > pending-review > evidence/candidate。
2. 运行记录只证明该轮事实/边界，不自动升级正本。
3. 同一机制若已有跨作品 pending-review，新案例优先补控制计数，不再平行制造同义待审议文件。
4. 新边界不足 3 部独立作品时，保留 evidence/candidate，不抢跑。
5. 无真实新增/修正时不提交。
6. 后续每小时整理优先更新本总纲，而不是继续制造新的“总纲的总纲”。
7. 一个反向护栏若只是细化既有 pending-review，应优先并入原待审议文件和总纲，不再单独制造第二份同义待审议。
8. 严格对子研究必须先分别锁两端；“主体主动 + 外部借力”“自己定目标 + 沿关系办成”等描述不得作为两端已成立的替代证据。
9. **任何“主动绕过外部接口”的跨作品计数前，先验证该接口在当前执行窗口仍真实开放可用；若 P1 已关闭/撤回/反转，只能归入通道失效后的内部续行，不得混入可用 P1 主动绕行样本。**
10. **任何十元端点的“主动性/自有目标”都只能作为候选背景，不得替代该端点自己的硬判据；这一纪律可作为木轴向其他四轴迁移时的通用前置门。**
