## 1｜木轴当前骨架

```text
zx：主体占据最终方向与作用权来源，并把自身权能压入现实。

nx：主体不占最终方向；关键权限、资源或解决接口仍在外部；主体真实沿既有关系、权限、流程或通道续接。
```

禁止直接用强弱、身份、职业、胜负、听话、求人一次、主动性、有无明确目标判十元。

## 2｜最近邻地图

### 2.1 zx vs x

```text
x：冲突前已经拥有该对象域稳定调用/处分权，现在把它用出来。
zx：决定范围、影响位置或凌驾程度推进到原本不属于主体的对象域/层级。
```

稳定纪律：**权力有效 ≠ 权力扩大。**

### 2.2 nx vs x

```text
nx：关键许可/资源/保护/专业接口仍外置，主体不能稳定自行调用。
x：权限/资源已经稳定进入主体直接调用边界。
```

“有人参与 / 部下执行 / 使用组织资源”不是 nx 充分证据。

### 2.3 nx vs xn

```text
nx：沿别人已有方向、权限、接口推进。
xn：主体自己搭人员、资源、节点、流程、排程与运行骨架。
```

可同时存在：上位任务 nx + 局部 x + 自搭 xn，不能重复计数。

## 3｜nx / zx 已形成的研究主干

### 3.1 对象分层｜pending-review

高层最终方向非 nx，不覆盖局部保护/许可/资源 nx；局部 nx 也不得倒灌成长期终点 nx。

正向：关羽、林冲、鸳鸯。反向：探春、马谡、宋江。

### 3.2 nx 激活与退出窗口｜pending-review

nx 按当前执行窗口判断，不是历史关系永久标签。

已锁退出机制：
1. 方案失效；
2. 环境不可持续；
3. 许可节点撤回/反转；
4. 通道仍有效，但主体当前最高行动目标改变并停止续接。

### 3.3 具体节点可替代 vs 接口层不可绕过｜pending-review

换具体人不等于摆脱 nx。真正削弱 nx 的是：存在稳定、可重复、不经等价外部接口、仍实现同一结果的内部路线。

前置门：

```text
P1 当前开放可用
+ 主体主动不走
+ P2 不依赖等价外部接口
+ 同一结果完成
→ 才计“可用 P1 主动内部绕行”
```

关羽五关、甘地自取盐为正向；武松、玄奘、孙悟空二调芭蕉扇、凯撒为反筛选护栏。

### 3.4 外部对象 / 处分域在场 ≠ nx｜pending-review

孙悟空生死簿、李逵劫法场、董卓废立形成三作品控制：

> 对象/处分域在外，只证明外部性；主体若没有沿接口续接，而是直接压掉原接口当前否决/处分能力并改写同一结果，优先检查 zx。

护栏：探春抄检只压回局部越界，不等于整体搜检接口失效。

### 3.5 主动目标 + 外部通道 ≠ zx+nx｜pending-review

王熙凤铁槛寺、刘备三顾茅庐、林冲投梁山跨三作品支持：

> “我自己想干 + 我很主动 + 我真实走外部接口”不能自动推出 zx+nx。zx 必须另证公开显权与决定范围新增。

### 3.6 名义权限 vs 现实否决权｜P4 pending-review

当前方法拆两门：

```text
A 实效门：外部节点真的能卡住同一结果吗？
B 激活门：该接口本轮真的进入主体行动链了吗？
```

最强因果拨动：

```text
拒绝 → 同一结果停住 → 放行 → 同一结果恢复
```

证据分档：A 因果拨动；B 有效拒绝；C 只改条件/时间/方式；D 名义反对但结果照常。

### 3.7 秘密改结果 ≠ 公开扩权 zx｜pending-review × 四大名著

当前四部独立作品复现：
- 《西游记》孙悟空偷桃偷酒偷丹；
- 《三国演义》周瑜蒋干盗书；
- 《红楼梦》王熙凤毒设相思局；
- 《水浒传》宋江私放晁盖。

共同纪律：

```text
隐匿 / 欺骗 / 诱导 / 绕权 / 时序组织
→ 具体结果成功改变
→ 但现实没有围绕主体新增的公开决定接口运行
≠ zx
```

宋江补出“系统内部秘密反向型”：主体可拥有正式职位/信息入口 `x`，再利用 `x + xn` 秘密破坏系统结果；只要没有公开扩张处分边界，仍不得升级 zx。

阶段护栏：司马懿诈病 → 高平陵证明必须切段；后段公开扩权不能倒灌前段秘密布局。

### 3.8 压力显影 ≠ 人物换芯｜evidence-locked × 1 positive + 2 negative guards

当前首个直接正向控制：

- 《西游记》孙悟空｜五行山受压 → 观音/唐僧救援通道 nx 高显影 → 揭帖脱困后 zx 快速复位｜事实99 / 分类97。

当前反向护栏：

- 《三国演义》刘备｜借截袁术之命离许都｜任务/兵力接口 nx 高显影，但“脱离许都”更高目标仍由刘备自己生成，且刘备用 xn 把外部任务工具化｜事实99 / 分类98｜**对象层不一致，不得计作第二份直接压力显影正例。**
- 《三国演义》曹操｜赤壁败退至华容道｜同一“继续撤退”对象层中，自身突围入口被压力封住、关羽旧恩放行通道 nx 高显影；但脱险后只恢复对既有将领/残军的调用 `x`，没有重新出现 zx 所需的公开扩权/决定范围上升硬证据｜事实99 / 分类98｜**解压后仅恢复 x，不得冒充 zx 复位。**

正向结构：

```text
稳定端原本成立
→ 强外压封住该端权能进入现实的入口
→ 另一端关系功能在同一当前对象层高显影
→ 压力解除
→ 原端以自身硬判据重新出现
```

最小纪律：

> **当前显影变化不等于稳定人物本体改写。**

第一道护栏｜对象层一致性：

> **压力显影必须先证明“被压低的一端”和“抬高的一端”作用于同一个当前对象层。高层最终方向仍由主体自定、只是子任务/兵力/许可层 nx 抬高，或主体用 xn 把外部接口工具化，优先判对象分层 + nx/xn 共存，不能写成 `zx 被克 → nx 显影`。**

第二道护栏｜复位硬判据：

> **压力解除后，必须重新看到原端自身的硬判据，才能写“原端复位”。恢复自主行动、恢复旧职位、恢复既有资源调用或恢复普通 `x`，都不能自动替代 `zx` 的公开显权、现实响应与决定范围/凌驾位置新增。**

最短式：

```text
恢复自主行动 / 恢复既有 x
≠
zx 复位
```

判断时必须分开：稳定本体、当前状态、行为功能、关系位置、对象层、外部压力，以及**解压后恢复的究竟是哪一个端点**。高压窗口中 zx 现实显影下降、nx 关系功能上升，不得机械写成“人物从 zx 变成 nx”；解压后若只恢复 `x`，也不得机械写成“zx 回来了”。

- `07-Codex大脑库/运行记录_zx-nx压力显影_曹操华容道自身突围能力被封后旧恩放行nx抬高但脱险后仅恢复x不足锁zx复位反向护栏_20260826.md`

## 4｜严格 zx↔nx 补｜2026-08-26 重大纠偏

### 4.1 当前最低门

0. zx、nx 两端先独立成立；
1. 两端直接作用于同一当前现实瓶颈；
2. 拿掉 nx，zx 自身留下不可替代缺口；
3. 拿掉 zx，nx **自身核心功能**也留下不可替代缺口；
4. 两缺口在同一有效时间窗口；
5. 反向缺口不能只是“没有调用者/触发者/行动者/兑换者”；
6. 双向缺口不能主要由共同第三因素制造；
7. 第三因素冻结必须保留 zx、nx 与目标瓶颈。

### 4.2 旧严格补判据系统性过宽｜pending-review

新双向拿掉门回扫后，以下旧“严格补”子结论已撤回：
- 三国演义：孙策质玺借兵 → `nx→zx` 单向补；
- 三国演义：曹操陈留借卫弘家资 → `nx→zx` 单向补；
- 水浒传：宋江高唐州 → `nx→zx` 单向补；
- 红楼梦：鸳鸯抗婚 → `nx→zx` 单向补；
- 西游记：孙悟空红孩儿 → `nx→zx` 单向补，只保留 nx 窗口关闭。

跨四作品共同错误：

```text
“没有 zx，nx 条件不会自动生成共同结果”
≠
“没有 zx，nx 自身核心功能会受损”
```

当前：

```yaml

```

这不等于严格补不存在，只表示旧高纯正例在新门槛下全部需要重建。

### 4.3 当前已锁单向补

尤三姐、鲁达五台山、孙悟空定风丹、孙策质玺借兵、曹操卫弘、宋江高唐州、鸳鸯抗婚、孙悟空红孩儿。

统一结构：

```text
→ 单向补
```

### 4.4 严格补时间窗口与 nx 窗口必须拆开

仍可保留：

```text

→ 任务完成 / 瓶颈消失 / 接口退出 / 资源内化
→ 旧 nx 不得永久追挂后续阶段
```

但禁止继续用单向补案例证明“严格补闭环”。时间窗口首先是 nx 动态纪律；严格补闭环必须先证明初始双向严格补。

### 4.5 第三因素冻结

“冻结有效性护栏”已跨三作品复验：曹操陈留、宋江高唐州、鸳鸯抗婚。

方法仍有效，即使这些案例的旧严格补子结论已撤回：

### P4｜现实否决强度阈值

继续测：完全否决 vs 延迟、改方式、可替代节点、长期可绕过、局部否决。

### P5｜旧高置信资产回扫

继续搜索所有历史：

`strict_zx_nx_complement_locked: true`

按新双向拿掉门重算，明确 supersede 旧子结论，保留不受影响的事实与方法资产。

### P6｜秘密阶段 → 公开扩权的跨作品阶段复验

同时继续找第二份“正式系统内部人利用既有 x 入口秘密反向干预，但仍非 zx”的独立作品控制。

### P7｜压力显影跨作品复验

当前只有《西游记》孙悟空五行山 1 份直接高纯正向控制；《三国演义》刘备借截袁术离许都与曹操华容道只计反向护栏，不增加正向作品数。

下一步优先《水浒传》《红楼梦》寻找：

```text
稳定一端已有可靠人物锚
→ 外部压力明确封住该端现实入口
→ 另一端关系功能在同一窄对象层高显影
→ 压力解除
→ 原端以该端自己的硬判据迅速复位
```

第一道反筛选门：**对象层一致性。**
- 被压力压低的一端与因此抬高的另一端必须作用于同一当前对象/现实瓶颈；
- 高层最终方向仍由主体自定、只是子任务层 nx 抬高，不计直接压力显影；
- 主体用 xn 把外部任务/许可接口工具化，也不能冒充“zx 被克 → nx 显影”。

第二道反筛选门：**复位端点硬判据。**
- 压力解除后，必须重新看到原端自己的硬判据；
- 对 `zx` 而言，仅恢复自主行动、旧职位、旧兵力调用或普通 `x` 不够，必须重新出现公开显权、现实响应、决定范围/凌驾位置新增；
- 对其他端点亦同理，不能用邻近十元的恢复代替原端复位。

其他反筛选要求：
- 不得只凭“人物变弱/听话/求人”判另一端；
- 必须证明现实入口被压、另一端接口真实成立；
- 必须区分稳定人物本体与当前关系功能；
- 若压力解除后没有原端硬判据复位证据，则不得硬写“压力显影”。

跨至少3部独立作品正向复现后，才建立独立 pending-review。

## 7｜可迁移到火/土/金/水的方法

可直接复用：
1. 对象层拆分；
2. 最近邻排除；
3. 拿掉 / 反向测试；
4. 当前执行窗口；
5. 现实否决因果拨动；
6. P1 当前可用性检查；
7. 第三因素冻结；
8. 对子第0门：两端先独立成立；
9. **反向补缺必须打到另一端自身结构，不能只证明共同结果需要两个参与者；**
10. 新方法出现后必须回扫旧高置信正例，重算 control_count/cross_work_count；
11. **结果变化与权能位置变化分离**：秘密操纵、诱导或时序组织可以改变结果，但不能自动证明任何轴的结构位置升级；
12. **阶段切分禁止倒灌**：后段公开结构变化不能反向证明前段秘密准备已经属于同一端点；
13. **压力显影与稳定本体分离**：一端因外压失去现实入口、另一端当前功能上升时，先记录显影切换；只有跨窗口稳定持续，才讨论本体改写；
14. **压力显影先过对象层一致性**：不同层的“高层自定方向 + 子任务外部接口”不能冒充同一轴两端在同一对象上的压力切换；
15. **解压复位按原端硬判据验收**：恢复普通自主性、旧资源调用或邻近十元，只能证明相应结构恢复，不能冒充被测试端点复位。

跨轴迁移：

- 火 `zn↔x`：外压可能暂时压低“独立成立”或“归属处分”的现实显影；解压后仅恢复一般使用/归属，不等于原先被测试的独立成立或处分端点复位，必须按 `zn`/`x` 各自硬判据重新验收；
- 土 `n↔x并z`：通道/边界被封住后重新能通行，不等于原本被测试的承载/外化边界端点已恢复，必须确认同一空间对象层和原端结构重新出现；
- 金 `xn↔z`：流程重新运行，不等于原分布运行权或最高裁定点已经恢复；必须重新证明节点分布或最高裁定权本身；
- 水 `xz↔nz`：一次路线重新开放，不等于稳定回返空间或不可逆收窄结构已经恢复；必须重新证明现实回返/收窄端点。

秘密改结果方法继续适用：
- 火轴：秘密影响归属结果，不等于公开取得归属/处分边界；
- 土轴：秘密绕过空间边界成功，不等于空间边界本身已被主体重写；
- 金轴：幕后安排结果，不等于主体成为公开最高裁定点；
- 水轴：秘密改变一次去向，不等于现实回返空间或不可逆结构已稳定改写。

## 8｜仓库治理纪律

- 正本高于本总纲。
- evidence-locked 不自动升级正本。
- 同一结论优先归并总纲/待审议，不重复造同义文件。
- 新方法推翻旧子结论时，保留原事实资产，但必须明确 `superseded-subconclusion`。
- cross-work 只按独立作品计，同一历史事件不同版本不重复计数。
- 新增压力显影材料先进入 `evidence-locked`；只有正向控制跨3作品才建立 pending-review，反向护栏不计正向作品数。
- 没有真实新增/修正不提交。
