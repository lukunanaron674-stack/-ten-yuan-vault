# zx↔nx 权限边界｜甘地盐税抗争：殖民盐垄断 P1 与海边自取盐 P2 高成本纯内部绕行第二正向控制

## 0｜本轮研究问题

现有待审议已经有《三国演义》关羽过五关一份高纯正向控制：正常外部许可路线存在，但主体实际改走高成本、自有、可成功的 P2，并实现同一结果对象，因此当前许可 nx 退出。

同时已有三个重要反门：

1. 武松：P2 换了结果对象，不能算同结果绕行；
2. 玄奘：绕过中央许可后仍依赖地方关系/资源接口，不是纯内部闭环；
3. 孙悟空二调芭蕉扇：P2 步骤虽由主体自搭，但关键真扇与口诀仍须外部持有人转移，也不是纯内部闭环。

本轮测试：能否找到第二种、非武力过关机制的高成本纯内部 P2。

## 1｜剧情/历史事实、触发、对象、动作与结果

### 事实A｜正常外部资源路线 P1 确实存在

英国盐法禁止印度人自行收集或销售盐，并维持盐的制造与销售垄断；印度居民被迫从英属盐业体系购买盐并承担盐税。

因此在“合法取得盐”这一窄对象上，正常路线是：

```text
P1：
殖民盐业垄断生产/销售
→ 居民通过外部市场渠道购买
→ 取得盐
```

关键盐资源的合法生产和销售接口不在普通印度居民自己手里。

### 事实B｜甘地明确不使用 P1，而设计高成本 P2

1930年3月，甘地从萨巴尔马蒂出发，徒步约240英里前往丹迪海岸，公开宣布要违反盐法。到达丹迪后，他没有通过英属盐业垄断购买盐，而是在海边直接取得含盐物并以此破盐法。

```text
P2：
长距离徒步
→ 到达海岸
→ 直接从自然盐源取得盐
→ 不经殖民盐业购买/许可
→ 同样取得盐
```

P2 成本高、时间长、政治和人身风险高，但在关键盐资源层不需要另一个外部资源持有人把盐转移给甘地，也不需要殖民政府批准。

### 事实C｜结果对象保持一致

本轮故意把结果对象锁窄为：

> R = 主体取得并持有盐。

不把“废除盐法”“印度独立”“政治动员成功”混进 R。

在这一对象层：

```text
P1：购买殖民垄断盐 → 取得盐
P2：海边自行取得/制作盐 → 取得盐
```

因此：`same_result_object_preserved: true`。

## 2｜zx 判断

本窄阶段 `zx_public_defiance_stage: evidence-locked`。

支持点不是“甘地很伟大”或“很多人跟随”，而是：

1. 违反盐法的方向由主体公开提出并维持；
2. 主体自身行动进入公开现实；
3. 殖民政府、警察与社会被迫围绕该行动响应；
4. 原本由殖民盐法规定的“只能通过垄断渠道取得盐”被主体公开压出一个现实例外，并迅速形成广泛模仿。

但这里只锁当前公开抗争状态，不锁稳定人物本体。

## 3｜nx 判断

### 3.1 P1 是真实外部资源通道

如果主体选择合法常规取得盐，就必须通过殖民垄断的制造/销售网络。

这一层具备 nx 关系/资源接口结构：

```text
关键资源不在主体手里
→ 正常取得必须沿外部既有垄断渠道
= nx 候选
```

### 3.2 但当前实际执行没有使用 P1

甘地在丹迪并未购买垄断盐，也未等待外部批准，而是直接从海边取得盐。

因此：

`nx_monopoly_resource_route_in_actual_execution: rejected`

不能因为“世界上存在一个合法购买接口”，就把没有使用该接口的当前执行层仍判 nx。

## 4｜关键压力

关键压力包括：

- 盐法禁止私人收集/制造盐；
- 合法盐由殖民体系垄断；
- P2 需要约240英里徒步；
- 主体预期存在逮捕、镇压等政治风险。

这些压力解释 P2 为什么高成本，但不能单独判十元。

真正判据仍是：

> P2 实际闭环时，关键资源/许可是否还必须从独立外部节点取得？

本例在“取得盐”这一对象层答案是否。

## 5｜拿掉测试

### 拿掉 P1 外部垄断路线

甘地的 P2 仍然能够从海边取得盐。

因此 P1 不是当前“取得盐”结果的不可替代条件。

### 拿掉 P2 自取盐能力，同时拒绝使用 P1

则主体重新留下“无法取得盐”的现实缺口。

因此当前实际链真正依赖 P2。

### 拿掉同行者和政治群众

群众规模会影响运动传播与政治 zx 强度，但不影响丹迪微窗口中甘地本人从海边取得盐这一关键闭环。

所以本轮不把群众支持误判成 nx 关键资源接口。

## 6｜反向测试

### 武松门｜结果对象是否改变？

没有。

本轮不把“废除盐法”作为 R，只比较“取得盐”。P1/P2 都实现同一 R。

### 玄奘门｜P2 是否只是换另一个外部接口？

不是。

关键盐资源来自自然盐源，不需要另一个人/机构批准放行，也不需要一个新外部盐持有人把成品盐转移给甘地。

### 孙悟空门｜是否“自搭 xn，但关键资源仍外置”？

不是。

行军、路线、群众动员有明显 xn 邻近，但“盐”本身并不需要殖民垄断者或其他独立持有人交付。

## 7｜最近邻排除

### nx vs xn

240英里行军、宣传、节点安排属于 xn 邻近；但这些回答“P2 怎么组织”，不回答“盐是否仍须从外部垄断接口取得”。

### nx vs x

P2 完成前，盐并非主体稳定拥有；P2 完成后，具体取得的盐进入主体持有边界。不能把后状态倒灌到起点。

### nx vs zx

排除 P1 的 nx 不自动生成 zx。本例之所以可锁当前 zx，是因为另有公开破法、社会/制度响应与影响扩大证据；不是因为“没走 nx 所以自动 zx”。

## 8｜第三因素冻结

冻结：

- 印度独立的大主题；
- 甘地人格评价与宗教声望；
- 后续大规模逮捕；
- 盐税最终政策后果；
- 国大党组织的长期政治效果。

只保留：

1. 正常盐资源是否由外部垄断控制；
2. 主体当前是否使用该接口；
3. P2 是否高成本；
4. P2 是否还依赖等价外部许可/关系/关键资源持有人；
5. P1/P2 是否实现同一“取得盐”结果。

结论仍稳定。

## 9｜与关羽五关形成第二种独立机制

```text
关羽：
正常文凭许可 P1
→ 不使用
→ 自身武力高风险连续过关 P2
→ 同一实际通行结果
→ 当前许可 nx 退出

甘地：
殖民盐垄断购买 P1
→ 不使用
→ 徒步海岸、自行取/制盐 P2
→ 同一取得盐结果
→ 当前垄断资源 nx 退出
```

两者机制不同：

- 关羽是“许可/关卡”型；
- 甘地是“垄断关键资源”型。

共同结构是：

> 高成本本身不会让 nx 自动复活；只要主体实际采用 P2，P2 不依赖等价外部关键接口，并稳定实现同一结果对象，当前 P1 的 nx 可以退出。
