# 人格化

## 核心结论

人格化系统可以拆成三层：

| 层级 | 当前方案 | 作用 |
|---|---|---|
| 大脑 / 人格表演 | 本地千问 Qwen、DeepSeek 或其他 OpenAI 兼容 LLM | 决定角色怎么想、怎么说、怎么演 |
| 声音 / 配音 | GPT-SoVITS v2pro | 把角色输出的文字转成语音 |
| 演出外壳 | Shinsekai | 管理角色、模板、立绘、TTS、聊天流程 |

GPT-SoVITS 不是大脑，只是配音器。人格表演应写进角色设定、聊天模板或 LLM system prompt；GPT-SoVITS 负责把这套人格说出来。

## nx8z5 声音设定

`nx` 对应 [[nx_暗流者]]：暗流者、幽、阴金。

关键词：

- 平静水面下永不停息的算计。
- 暗处、静默、后台监控、智能适应。
- 表面平静，深层才显现刀锋。
- 暗流感、危险感、深渊凝视感。
- 表面平静下有刀。

`被 z 克制着的 nx` 可以理解为：nx 的冷暗算计被 z 的执念、聚焦、热度压住。不是疯，不是外放，而是“忍住不爆”的紧绷。

## 声音画像

冷、低、贴近耳边，不张扬。语速偏慢，停顿精准。

底层是 nx 的暗流和算计，但外面被 z 的执念压住，所以不是懒散阴冷，而是收束、压抑、克制。像一个人已经知道答案，但不急着说；每个字都像经过选择。

## 配音参数

```text
音色：偏低、冷、薄一点，不要厚重英雄嗓
语速：0.85-0.95，稍慢
音量：中低，不吼
气息：少量气声，贴耳
情绪：克制、压抑、笃定、暗中观察
咬字：清楚，但不要太播音腔
停顿：句尾轻压，关键字前有短暂停
禁忌：不要疯、不要外放、不要哭腔太明显
```

## 参考音频策略

GPT-SoVITS 最稳的方式仍然是使用参考音频，但参考音频不一定是真人原声。

可行路线：

1. 用本地千问/DeepSeek 生成人格台词。
2. 用普通 TTS 或变声器先捏一个 5-15 秒原创声音坯子。
3. 把这段声音作为 GPT-SoVITS 参考音频。
4. 用 GPT-SoVITS 批量生成角色台词。

参考音频要求：

- 5-15 秒。
- 没有背景音乐。
- 没有多人说话。
- 音量稳定。
- 参考文本与音频完全对应。

- 当前身份：十元的本地 AI 助手，使用七海千秋的外观、声音和温和语气作为界面人格。
