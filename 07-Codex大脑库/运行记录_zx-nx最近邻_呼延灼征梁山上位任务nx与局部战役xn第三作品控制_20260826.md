# 呼延灼征梁山｜上位任务 nx + 局部战役 xn 第三作品控制

## 0｜本轮只测试一个窄变量

仓库已经有呼延灼 99/96 的“分层授权”正式记录。本轮不重复建立人物案例，不重新讨论“上位 nx + 局部 x”是否成立，只抽取其中一个此前未进入 `nx vs xn` 跨作品计数的稳定子结构：

```text
“征剿梁山”这一最高任务从哪里来？
→ 高俅 / 朝廷军令
→ 呼延灼承接
= 上位 nx

“接到任务后具体怎样组织战役？”
→ 举荐先锋、调三路军马、选甲仗、配置前中后军、打造并运行连环马
→ 呼延灼主动组织
= 局部 xn
```

本轮目标：检查“上位任务 nx”是否可以与“局部执行 xn”稳定共存，而不把整段机械写成纯 nx。

---

## 1｜剧情事实、触发、对象、动作、结果

### 触发

高俅 / 朝廷决定征剿梁山，要求呼延灼等回州拣选精锐军马并按期出师。

### 被测对象层 A｜上位任务

“是否征剿梁山、最高征剿对象是谁”不是呼延灼自己提出或重设的。呼延灼接受这一军令并沿其推进。

因此：

```text
上位政治 / 战略任务来源：外部
主体真实承接：是
主体是否取得最高任务重设权：否
= nx
```

### 被测对象层 B｜局部执行运行

接到任务后，文本出现一系列由呼延灼主动组织的运行动作：

1. 高俅询问先锋人选，呼延灼自行举保韩滔、彭玘；
2. 呼延灼主动指出甲仗不足并请求补足资源入口；
3. 获准后自行到甲仗库选取所需甲仗、兵器；
4. 回州调集三路军马；
5. 把资源分配到三军并形成前军 / 中军 / 后军结构；
6. 打造、编组并运行连环马战术；
7. 交战中持续收军、下寨、调整本部战役运行。

这些动作不是高俅逐项写死的操作清单，而是主体在上位任务之下主动配置人员、资源、节点和运行结构。

因此：

```text
局部战役运行组织：xn 高显影
```

### 结果

最高征剿方向继续来自外部，但具体战役骨架由呼延灼主动组织。整段不能写成纯 nx。

---

## 2｜zx 检查

本窄阶段不锁 zx。

呼延灼领兵、排阵、部下服从，首先可由已授战役权限 `x` 与局部运行 `xn` 解释。现有正式记录没有显示他把决定范围继续公开推到高俅 / 朝廷原本保留的更高战略对象层。

因此：

```text
能打 / 是主将 / 会命令 / 战术有效
≠ zx
```

若以后出现他公开夺取“是否征剿、征剿谁”等上位战略重设权，并迫使上级体系承认新的决定边界，才重新检查 zx。

---

## 3｜nx 证据

上位任务层 `nx` 成立：

1. 最高征剿目标由高俅 / 朝廷给出；
2. 呼延灼没有重新定义最高任务；
3. 他真实接受军令并以此为本轮行动入口；
4. 上位合法性、初始调兵与资源入口仍来自外部权力网络。

符合现行 nx 正本：方向、权限或解决通道已由外部给出，主体不占最终方向位置，并真实沿其续接。

---

## 4｜nx vs xn 最近邻

本例最小差异：

```text
高俅 / 朝廷：
给“征剿梁山”的最高任务与合法军令入口
= nx

呼延灼：
选先锋、调军、分装备、编前中后军、打造并运行连环马
= xn
```

所以：

> **谁决定“要做什么”，和谁决定“具体怎么运行”，必须拆开。**

上位任务来自别人，不会自动吞掉主体真实存在的局部 `xn`；局部运行很主动，也不会倒抹上位任务来源的 `nx`。

## 5｜拿掉测试

### 拿掉上位 nx

假设没有高俅 / 朝廷的征剿任务，呼延灼自行决定“我要征梁山”并自行取得所需合法军政入口：

- 本轮上位 nx 消失；
- 应重新检查其上位目标来源是否属于自身 `xn / x / zx`。

说明上位 nx 是独立变量。

### 拿掉局部 xn

保留“征剿梁山”的上位命令，但假设高俅把先锋、军马数量、甲仗分配、前中后军、连环马结构、进退节点全部逐项写死，呼延灼只能照单执行：

- 上位 nx 仍成立；
- 局部 xn 明显下降；
- 整段会更接近纯任务 nx。

说明局部 xn 不是由 nx 自动附送。

## 6｜反向测试

### 反向成更纯 nx

```text
上位任务外部给
+ 具体执行方法 / 节点 / 时序 /资源分配也全部外部逐项给定
+ 主体只照办
```

则 xn 降低，纯 nx 候选上升。

### 反向成更强 xn

```text
上级只给一个极粗目标
+ 呼延灼自行定义战役对象层、选择人员、资源、战术和全部流程
```

则 xn 上升，但只要最高任务仍外置，上位 nx 仍可以保留。

### 反向成 zx

若呼延灼进一步公开夺取原属高俅 / 朝廷的最高战略处分权，并让上级体系围绕其新增决定权重新运行，才检查 zx。

## 7｜第三因素冻结

冻结：

- 呼延灼名将身份；
- 呼延赞后裔身份；
- 连环马强不强；
- 官军 / 梁山善恶；
- 最终胜负；
- 高俅奸臣评价；
- 呼延灼后来是否归顺梁山。

只保留：

```text
最高任务谁给？
主体有没有真实承接？
具体执行流程是谁组织？
局部人员、资源和节点是谁配置？
有没有公开越过授权边界？
```

结论不变。
