# zx / xn / nx 一致性审计与关系表语义覆盖 v0.1

> 本页只处理已经达到 95% 以上确定度的内部一致性问题。几何位置关系继续有效；旧关系表中与当前正本冲突的角色名、动机解释和叙事比喻，自本页起停止作为语义依据。

## 1. 审计结论

### 1.1 保留不动的底层关系

以下关系在当前正本、位置表与孙悟空人物锚中一致：

```text
xn 克 zx
z 克 nx
zx ↔ nx（补位）
```

《西游记》齐天大圣孙悟空的当前稳定结构继续锁定为：

```text
人物稳定本体：zx + nx
外部高体量结构：五行山式 xn
动态关系：xn 克 zx，原有 nx 高显影并补住 zx
```

五行山改变的是行动条件、状态显影与关系位置，不是人物中途生成新的副元。

## 2. 已确认的旧语义冲突

### 2.1 《十元生补克表》的 nx 旧标签失效

旧表曾使用：

```text
nx = 暗流算计 / 幕后操盘 / 风控结算 / 暗线运作
```

该组描述与当前 `【nx信息量卡v2】` 冲突，停止使用。

正式覆盖为：

```text
nx：不主动占据选择、方向和位置，
    把决定留给别人、流程、关系或现状，
    并沿已有安排继续。
```

因此旧表中下列解释全部仅保留为历史文本，不再参与判定：

```text
“突破开局与暗流算计共同组成结算”
“破局者需要风控结算”
“算计者”
“幕后操盘手”
“暗算拆掉伪善者的画饼”
“算计抵不过孤注一掷”
“深沉蛛网需要破局者”
“阴险设计孕育恶之欲望”
```

几何关系 `zx ↔ nx`、`z 克 nx`、`nx 克 x并z` 与 `nx 生 x` 暂不因旧解释失效而删除；它们属于位置关系。其新的现象解释必须另做案例验证，不能继续沿用“暗算、结算”自动补义。

### 2.2 《十元生补克表》的 xn 旧标签过窄

旧表曾把 xn 主要写成：

```text
制度 / 条例 / 冷面执行 / 绝对程序
```

这不是完全错误，但只是 xn 长期外化后的部分形态，不能继续充当完整本体定义。

正式覆盖为：

```text
xn：主动把信息、行动与资源放入计划、时间、规则或隐藏结构，
    通过记录、重复、等待和积累形成持续力量；
    长期外化后可形成制度、传统、家族、谱系、历史惯性等客观结构。
```

所以：

```text
制度是 xn 的一种高体量外显，不是 xn 的唯一入口。
五行山式 xn 的重点不是物理重量，而是时间、规则与前置积累已经形成结构。
```

### 2.3 《十元生补克表》的 zx 旧标签过窄

旧表曾把 zx 主要写成：

```text
开局 / 突破 / 破局 / 先动手
```

这些可以保留为 zx 行为，但不能再代替 zx 本体。

正式覆盖为：

```text
zx 本体：张扬醒目、主体权能显现与扩大，或在反复压制中持续复起。
zx 行为：目标执行、路径推进、换路、破局、做成、重新站起。
```

因此孙悟空的 zx 不是因为“会战斗”或“先动手”，而是外界无法对其主体意志作最终定义，主体力量必须再次进入现实。

### 2.4 《十元判定校准协议》中的 zx 候选行失效

旧候选行：

```text
zx：目标执行、保持路径有效、完成本身构成存在方式
```

停止作为本体定义。应按以下方式读取：

```text
核心检查：权能是否显现、扩大，或在压制后持续复起。
常见行为：目标执行、路径推进、换路、破局、做成。
误判防线：有目标、有行动、有效率，不自动等于人物本体 zx。
```

## 3. 对象分层后的统一判定

分析 zx、xn、nx 交界案例，必须分别填写：

```text
【人物稳定本体】
【当前人物状态】
【关键行为功能】
【外部场景 / 时间结构】
【视觉辅助】
【关系变化】
【稳定本体是否改变】
```

不得用某一场的功能行为，直接重写人物稳定本体。

## 4. 孙悟空一致性复核

### 4.1 已通过

```text
人物稳定本体：zx+nx
求学阶段：zx 与 nx 已存在
大闹阶段：zx 高显影
五行山阶段：外部 xn 克 zx，原有 nx 高显影
条件解除：zx 再次复起
```

这与以下当前正本一致：

- zx 的“无限复起、不可被最终击倒”。
- nx 的“不主动占据方向，沿既有条件继续”。
- xn 的“时间、规则与前置积累形成持续结构”。
- 位置关系中的 `xn 克 zx` 与 `zx ↔ nx`。

### 4.2 证据等级限制

“求学阶段已经表现 nx”当前属于用户确认的人物结构锚，但仓库尚未建立逐段原著事件证据卡。

因此允许写：

```text
当前人物锚锁定为自始 zx+nx。
```

暂不允许擅自扩写：

```text
某个未经核对的原著细节必然证明 nx。
```

这不是理论分叉，只是证据包尚未补齐。

## 5. 本轮不擅自锁定的真实分叉

以下问题超过 5% 不确定度，本轮只登记，不作结论：

1. `nx 生 x` 在新 nx 口径下的标准现象解释是什么。
2. `nx 克 x并z` 在新 nx 口径下是“不占位使包装失去承接”，还是另有更准确机制。
3. `nz 生 nx` 是否仍成立于当前母行口径，以及应如何摆脱旧“温柔受伤黑化生算计”的错误解释。
4. `zx ↔ nx` 的普遍补位机制，是否统一表述为“主动夺回方向 ↔ 暂不占方向而保存延续”，还是需要区分不同体量。

在这些问题完成案例验证前：

```text
保留几何关系
冻结旧语义
不制造新解释
```
