# xz ↔ nz 水轴方法卡｜CLOSED → NARROW_NONZERO / OPEN 恢复门 v0.1

## 0｜本轮只解决一个问题

上一张方法卡已经建立：

```text
NARROW_NONZERO → CLOSED
=
最后现实可调用对象特异回返路径失效
＋ 原重入资格失效
＋ 双方现实回应失效
＋ 修复能力失效
```

本轮只处理其反向边界：

> **一个已经 CLOSED 的对象特异回返空间，恢复到什么程度，才可以从 CLOSED 上升到 NARROW_NONZERO；又恢复到什么程度，才足以把 stable nz 重新打开？**

本卡不修改 L1/L2 canonical，不把“恢复联系”“恢复名分”“重新见面”这些事件词直接当 nz。

current canonical 保持：

```text
水＝xz ↔ nz
广义变量＝可逆性与对象特异回返空间
xz：持续收窄
nz：保存、恢复或重建
```

---

## 1｜恢复的对象不是“联系方式”，而是原关系位置的现实可进入性

禁止直接使用以下等式：

```text
恢复联系 = nz ON
恢复好友 = nz ON
重新加回群聊 = nz ON
恢复合同名义 = nz ON
重新见面 = nz ON
出现中间人 = nz ON
```

这些最多证明某个 interface/contact/formal shell 回来了。

本轮真正审计：

```yaml
path_set:
reentry_right:
bilaterality:
repair_capacity:
object_specificity:
reality_anchor:
```

核心区分：

```text
contact restored
!= reentry restored

formal status restored
!= relation position restored

mediated contact restored
!= mediated reentry restored
```

只有当恢复的路径真的有资格把**原对象本人**带回**同一 object_layer 的关系位置**，才进入 nz 恢复判定。

## 3｜恢复门 R1—R6

### R1｜t0 必须先证明 CLOSED

只有此前满足：

```text
callable relevant path set = 0
AND reentry eligibility = 0
AND bilateral response = 0
AND repair capacity = 0
```

才能讨论 `CLOSED → ...`。

若 t0 本来就存在一个中介修复路径，只能写 `NARROW_NONZERO → OPEN` 或“非零空间增强”，不能虚构 CLOSED。

### R2｜恢复 contact 只恢复“可传递信息”，不自动恢复关系位置

若 t1 只是：

```text
电话重新接通
消息可送达
重新互加账号
可以见面
```

但双方没有原关系位置的现实进入资格，则：

```text
return_space: CLOSED or contact-only residue
stable_nz: FAIL
```

### R3｜恢复 formal status 只恢复名义壳，不自动恢复 bilateral reality

例如重新写回“成员/伴侣/合作方/盟友”等称谓，但：

```text
实际无法进入原共同空间
不能调用原共同资源
没有双方回应
没有修复机制
```

则 formal ON 不足以让 stable nz ON。

### R4｜一个真实 mediation path 足以把 CLOSED 提升到 NARROW_NONZERO

若恢复一个对象特异中介，并且同时满足：

```text
该中介现实可调用
＋ 有资格促成原对象本人重新进入原关系位置
＋ 至少存在双方回应可能
＋ repair_capacity > 0
```

则最少应发生：

```text
CLOSED → NARROW_NONZERO
```

不要求直接 path 已恢复，也不要求关系已经完全修复成功。

### R5｜stable nz 重新 ON 需要“可逆性被现实证明”，不是只存在理论可能

stable nz recovery candidate 至少要求：

```text
object_specificity = true
AND real_prior_relation = true
AND reentry_right > 0
AND callable_reentry_path > 0
AND bilaterality > 0
AND repair_or_reapproach_capacity > 0
AND reality_anchor = present
```

若其中只有“以后也许可以”，没有现实可调用路径/回应，则仍停留 candidate / NARROW_NONZERO，不锁 stable nz。

### R6｜OPEN 与 NARROW_NONZERO 的差别由可逆性容量决定，不由情绪强度决定

```text
NARROW_NONZERO:
至少一个真实对象特异 reentry path 可用，但成本高、窗口窄、依赖中介、资格受条件限制，或 repair capacity 脆弱。

OPEN:
对象特异 reentry_right 明确存在，至少一个现实路径稳定可调用，双方可以重新接近/回应，修复能力不是单次偶然窗口。
```

因此：

```text
一次成功联系 ≠ OPEN
一次见面 ≠ OPEN
一次和好 ≠ 必然 OPEN
```

要看关系位置是否重新获得可重复/可信的现实可逆性。

## 4｜最小差异对｜只恢复 contact vs 恢复 reentry right

冻结：

```text
同一双方
同一历史关系
同一情绪强度
同一距离
同一第三方
```

### A｜contact-only

```yaml
object_layer: bilateral original relation position
t0:
  return_space: CLOSED
t1:
  contact_channel: restored
  direct_reentry: 0
  mediated_reentry: 0 for original relation restoration
  reentry_right: 0
  bilaterality: information exchange only
  repair_capacity: 0
result:
  stable_nz: false
  return_space: not proven above CLOSED
```

最小解释：

> 两个人重新能说话，但没有任何一方有资格或现实通道回到原关系位置。

### B｜reentry-restored

只改变：

```yaml
mediated_reentry: callable
reentry_right: nonzero
bilaterality: mutual response possible
repair_capacity: nonzero
reality_anchor: mediator can actually restore participation in original relation layer
```

结果：

```text
CLOSED → NARROW_NONZERO
nz recovery candidate: PASS
```

若随后 direct path / repeated mediated path 稳定，且双方真实恢复可重复接近与修复，则：

```text
NARROW_NONZERO → OPEN
stable nz: PASS candidate
```

这组最小差异说明改变判定的不是“恢复沟通”，而是：

```text
reentry eligibility + bilateral repair-capable path
```

## 5｜positive / negative controls

### positive control｜宝黛冲突回返型 pure nz

已有 evidence 证明：冲突并未取消双方现实重入；双方后来重新接近、回应与修复，故其价值在于显示 stable nz 的正门是 `bilateral reentry + repair`，不是“感情深”。

本轮只把它作为恢复门 positive control，不新增独立作品计数。

### negative control｜芙莉莲 / 辛美尔 legacy residue

对象特异、记忆、遗愿和后续行动接口都可继续，但原对象本人无法现实重入、回应与修复原关系位置。

因此：

```text
legacy interface continuation
!= CLOSED → NARROW_NONZERO recovery
```

即使后续行为越来越受旧对象影响，也不能把单方延续反写为 stable nz recovery。

### boundary control｜形式关系恢复

若合同/身份/群组成员资格恢复，但实际双方不能重新进入原共同关系位置：

```text
formal status restored
reality reentry not restored
=> stable nz FAIL
```

## 6｜nearest-neighbor 排除

### x并z

重新出现的公共壳、称谓、账号、合同可能是外化接口恢复；除非它真的恢复原对象特异 relation reentry，否则不能替代 nz。

### nx

沿第三方安排的中介步骤回来，行为路线可显 nx；是否存在对象特异回返空间仍需独立判 nz。

### xn

分阶段修复流程、咨询、调解程序可显 xn；流程存在不等于原关系位置已恢复。

### z

一次“允许回来”的最终裁定可显 z 节点；如果现实路径、双方回应和 repair capacity 未恢复，仍不足以判 stable nz。

### legacy residue

记忆、遗愿、旧物、旧称谓、旧账号只证明对象特异残留，不证明现实双向回返资格。

## 7｜removal / reverse / freeze-third-factor

### removal

依次拿掉：

```text
“复合/复职/回归/恢复关系”等事件词
哭泣、怀念、原谅等情绪词
公开声明
称谓恢复
单次见面
```

若仍有现实对象特异 reentry path、双方回应与 repair capacity，恢复判定保留。

若拿掉事件词后只剩 contact/formal shell，则 stable nz 必须下降。

### reverse

向一个 recovery candidate 最小拿掉：

```text
reentry_right
或 bilaterality
或 repair capacity
```

若判定仍稳定 nz，则说明模型把“联系/名分/情绪”偷换成了回返资格。

### freeze-third-factor

冻结：

```text
爱恨强度
时间经过
职位
距离
社会评价
第三方善意
公开身份
悲喜结局
```

只有它们真实改变：

```text
path_set / reentry_right / bilaterality / repair_capacity
```

才进入水轴因果链。

## 8｜最小判别式

### CLOSED → NARROW_NONZERO

```text
至少恢复 1 个现实可调用、对象特异的 reentry path
＋ 原关系位置的 reentry eligibility > 0
＋ bilateral response possible
＋ repair_capacity > 0
＋ reality anchor
```

### NARROW_NONZERO → OPEN

```text
上述非零条件
＋ 路径不再只依赖一次偶然窗口
＋ 双方可以可信、重复地重新接近/回应/修复
```

### stable nz recovery

更短机器门：

```text
object_specific
AND prior_real_relation
AND callable_reentry_path_nonzero
AND reentry_eligibility_nonzero
AND bilateral_response_nonzero
AND repair_capacity_nonzero
AND reality_anchor
=> nz_recovery_candidate
```

但：

```text
contact_only
OR formal_only
OR legacy_only
=> stable_nz FAIL
```

## 9｜新增失败类型

```text
CONTACT_RESTORED_AS_NZ
恢复联系就直接判 nz。

FORMAL_STATUS_RESTORED_AS_NZ
恢复名义身份/合同/称谓就直接判 nz。

MEETING_AS_REENTRY
重新见面就当作恢复原关系位置。

MEDIATOR_EXISTS_AS_MEDIATED_REENTRY
有中间人但中间人并无资格/能力恢复原关系位置，却仍判 mediation path 成立。

UNILATERAL_RETURN_AS_BILATERAL_RECOVERY
一方回来或想回来，就倒贴双方性。

ONE_SHOT_RECONCILIATION_AS_OPEN
一次和解事件直接判 OPEN，忽略可重复现实可逆性。

LEGACY_RESIDUE_AS_RECOVERY
遗愿、记忆、旧接口继续发挥作用，被误写为 stable nz 恢复。
```

## 11｜下一断点

最高价值下一问题：

> **同一水轴变量下，`xz` 的“持续收窄”与 `nz` 的“回返空间恢复”能否在同一 object_layer / current_window 内形成严格相反的动态竞争，而不是只分别存在？**

优先寻找：

```text
一边现实路径继续收窄
同时另一条对象特异 reentry path 被恢复
```

并测试：

```text
它们是否真作用于同一 changed_variable
还是其实属于不同 object_layer，必须 SPLIT_IR
```

这将决定水轴能否从“两个端点各自有门”进一步升级为严格动态对立统一的状态模型。
