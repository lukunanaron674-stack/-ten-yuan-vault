## 1｜事实锚点

高权威外部事实源：

1. US Holocaust Memorial Museum, `Oskar Schindler`：1944秋 Schindler 获准把军工厂迁往 Brünnlitz；约 1,000 名犹太囚犯从 Plaszow 转入该工厂；从 1944年10月到 1945年5月，他投入自己在 Kraków 获得的财富保护这些囚犯；工厂虽名义为军工厂，约八个月仅生产一车弹药，并用虚假生产数字避免 SS 关闭营地。
2. Yad Vashem, Righteous Among the Nations / Oskar Schindler：Schindler 获得把工厂改为军工厂并迁往 Brünnlitz、雇佣约 1,100 名犹太人的许可；他把约 700 名 Plaszow 囚犯加入雇员名单，并通过异常努力把约 300 名女性从 Auschwitz 转到 Brünnlitz。

事实边界特别冻结：USHHM 指出 transfer lists 并非 Schindler 单方最终决定，德国/SS 体系仍保留外部审批和强制节点。因此本轮不得把“名单最终裁决权”或 Gross-Rosen/SS 的 camp sovereign authority 倒灌为 Schindler 的 unilateral x。

## 2｜zn 独立过门

先不用被测 x 命名 zn：

> 在纳粹系统性迫害与杀戮背景下，眼前这些犹太囚犯应被尽可能保住生命；即使继续保护意味着持续亏损、个人风险和放弃原有获利路径，这一排序仍应继续。

通过点：

- 不是职位义务：Schindler 原本来 Kraków 是为获利，保护排序不是其职业角色的当然要求。
- 不是战略收益：Brünnlitz 阶段需要消耗其既有财富，且工厂真实军工产出极低。
- 不是公开自罚/名望：保护需要欺骗纳粹生产监管、持续承担风险，不以公开奖励为必要条件。
- future-call retained：1944秋迁厂后至 1945年5月持续投入食品、药品、工厂存在与人员保护，不是一次情绪动作。

判：`zn=true`。

## 5｜zn→x｜通过

问题：拿掉被测 zn 后，Schindler 的 Brünnlitz organizational x 是否仍有足够独立用途/排序 anchor，使其保持同样迁厂、雇佣与资源配置方向？

但本轮只锁 Brünnlitz current window。该阶段：

- USHMM 明确记载 Schindler devoted himself to saving approximately 1,000 Jewish prisoners，并为此耗费在 Kraków 获得的财富；
- 工厂约八个月仅生产一车弹药；
- 他与 Stern / Pemper 伪造生产数字的目的，是防止 SS 关闭 camp/factory organization；
- Yad Vashem 记载其取得迁厂和雇佣约 1,100 名犹太人的许可，并加入大量本非真实专业工人的囚犯。

因此在这个窄 current window 内，普通商业获利/军工生产不再能解释“为何维持这批人、为何持续投入、为何维持该组织存在”的主要排序方向。

## 8｜拿掉 / 反向 / 第三因素冻结

### 拿掉 zn

工厂的抽象管理能力仍可存在，但 Brünnlitz 阶段把亏损、低产出、假生产数据和特定人员雇佣持续组织成救人边界的方向缺口出现。

### 拿掉 x

原则仍成立，人仍存在，但 Schindler subject-specific 的 employment / organizational / resource protection range 消失。

### 反向

不能从“工厂存在”反推 zn；早期 Emalia 的获利阶段就是现实反例压力。必须锁到 Brünnlitz rescue window 才通过。

不能从“Schindler想救人”反推出整个 Gross-Rosen 或 SS 体系归他掌握；外部审批和暴力主权继续冻结。

### 第三因素

冻结但不抹除：

- German/SS relocation approval and camp authority；
- Stern / Pemper 的协作与假生产数据；
- Emilie Schindler 的食品/药物协助；
- 当地秘密供给者；
- 战争末期宏观局势。

这些是现实必要背景/协作节点，但在本 current window 下没有形成一个等价的 **Schindler-subject-specific Brünnlitz factory organizational x anchor**。
