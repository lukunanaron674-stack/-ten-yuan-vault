# zx—nx 互补关系接口与互惠承接校准协议 v1.0

## 1. 本次校准

旧写法：

```text
nx 擅长做人际关系、人情世故，并主动为 zx 经营关系。
```

该写法过度扩大了 nx 的本体能力，现予以废止。

当前正式结论是：

```text
nx 在该关系中本来愿意帮助别人，
但在没有明确请求、具体事务或名正言顺的关系理由时，
通常不会主动伸手建立人情接口。

zx 先主动开口、把 nx 拉入一个具体互助事件，
给 nx 一个明确且正当的帮助理由；
关系接口成立以后，nx 才能自然地承接、回帮并维持互惠。
```

因此：

```text
zx 启动人情接口；
nx 承接并延续已经成立的人情。
```

## 2. “愿意帮”与“主动建立关系”必须分开

```text
nx 本来愿意帮
≠ nx 会主动求人、拉关系、送人情或建立社交局面；

nx 没有主动伸手
≠ nx 没有帮助意愿；

zx 给出明确请求和具体角色
≠ zx 从无到有地制造了 nx 的善意。
```

zx 改变的是 nx 的关系进入条件，而不是 nx 的人物核心：

```text
关系进入许可；
名正言顺的行动理由；
具体可承接的任务；
互惠关系的第一次事实。
```

## 3. zx 补 nx：强行打开关系接口

常见载体可以是主动、强势、熟人化的大妈大爷式人物，但该形象只是案例载体，不是 zx 的定义。

正式机制：

```text
zx 主动接近、直接开口或把 nx 拉进一件具体事务
→ 明确要求 nx 搭把手
→ nx 获得“我现在可以合理地帮他”的明确理由和位置
→ nx 不必主动发起模糊的人际试探
→ 第一次互助关系成立
```

zx 为 nx 补足的是：

```text
第一次开口；
关系启动；
行动许可；
明确角色；
互惠循环的起点。
```

这不是简单的领导与服从，也不是 zx 接管 nx 的全部人生方向。

## 4. nx 补 zx：承接具体事务并使互助持续

第一次关系接口成立后：

```text
nx 认真完成被托付的具体帮助
→ 形成“我帮过你／你也可以帮我”的真实往来
→ nx 可以名正言顺地继续回帮、照顾和承接
→ 互助关系从一次事件发展为可持续的人情循环
→ zx 获得日常执行、关系回流和长期互助支持
```

nx 为 zx 补足的是：

```text
具体事务的可靠承接；
已成立关系中的回帮；
互助的延续；
日常照顾与执行；
人情关系的回流。
```

不得再概括为：

```text
nx 天生善于社交；
nx 主动经营所有人际关系；
nx 负责替 zx 拉关系和做人情世故。
```

## 5. 双向互补的准确结构

```text
zx 没有启动：
nx 即使愿意帮，也可能因没有明确理由而不主动伸手；
互助关系无法开始。

nx 没有承接：
zx 即使强行打开关系，也可能只剩一次性接触；
互助关系无法稳定延续。
```

所以双方改变的变量不同：

```text
zx → nx：改变关系进入许可、行动理由与第一次互助机会；
nx → zx：改变事务完成度、互助持续性与关系回流能力。
```

两条方向都成立，因此仍属于正式互补；但互补内容应写成：

```text
关系接口启动 ↔ 互惠承接延续
```

而不是：

```text
领导带领 ↔ 被动跟随；
开路行动 ↔ 天生社交；
决定一切 ↔ 服从一切。
```

## 6. 对象层纪律

分析具体人物时必须分开：

```text
人物本体：是否稳定以 zx 或 nx 的方式处理选择和位置；
关系状态：是否已经存在明确请求与互助理由；
行为：某次被要求帮忙、实际搭手、回帮或照顾；
场景：社区、家庭、工作等是否允许关系启动；
时间关系：第一次帮忙是否形成后续互惠；
动态链：zx 是否真正打开接口，nx 是否真正使互助延续。
```

不能因为人物做过一次好事，就直接判定其本体为 nx；也不能因为人物主动开过一次口，就直接判定其本体为 zx。

## 7. 当前冻结结论

```text
nx 在 zx—nx 互补关系中本来愿意帮，但没有明确、正当的关系入口时通常不主动伸手。
zx 通过主动开口、具体请求和第一次互助事件，为 nx 建立名正言顺的帮助理由。
nx 在接口成立后承接事务、回帮和延续互惠，使关系不止停留在一次性启动。
“nx 做人际关系”应改写为“nx 承接并延续已经启动的互惠关系”。
zx 启动人情接口，nx 延续人情循环。
该结论属于关系机制，不替换 nx 的核心定义，也不把 nx 写成天生的社交经营者。
```
