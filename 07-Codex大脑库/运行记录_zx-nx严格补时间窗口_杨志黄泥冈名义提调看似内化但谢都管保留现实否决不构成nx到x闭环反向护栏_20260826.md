# 杨志黄泥冈｜“看似拿到手”不等于 nx 已内化为 x

## 0｜本轮问题

新建立的 strict temporal closure 待审议里，B 型机制是：

```text
外部 nx 资源/权限
→ 稳定进入主体直接调用与处分边界
→ 不再逐次经过原外部批准
→ nx → x 内化
→ 原 nx 接口退出当前窗口
```

本轮专门找反向护栏：

> **纸面上已经“交给主体提调”、对象也已经在主体手里，是否就足以判 x 内化并关闭旧 nx？**

杨志押送生辰纲给出高纯反例：不够。

## 1｜剧情事实

梁中书起初把押送责任交给杨志。杨志明确提出：若谢都管、两个虞候同行，必须一路早行、晚行、住歇都听自己提调，否则自己不敢领状。

梁中书随后当厅要求谢都管等“一路上早起晚行住歇，都要听他言语，不可和他别拗”。从纸面看：

```text
生辰纲在杨志押送链中
+
路线与住歇提调权明确授给杨志
→ 很像已经形成稳定局部 x
```

但到黄泥冈，杨志坚持不能停歇，并明确说明此处强人出没；谢都管却主张让众军休息，并公开压回杨志继续催行、责打军健的决定。众军实际停下，杨志最终无法维持“不停”的决定。

所以事实链是：

```text
纸面提调权给杨志
→ 对象与人员也在其当前押送链里
→ 真冲突发生
→ 谢都管仍可在结果生效前压回决定
→ 杨志必须让渡/重配
```

这说明“拿在手里、名义归我提调”还没有跨过稳定 x 的现实权限阈值。

## 2｜zx 判断

本轮不锁 zx。

杨志很强硬、会打人、坚持自己的专业判断，都不能代替 zx 的硬门。

在“是否停歇”这个微对象上，他没有扩大决定范围，反而无法维持已经名义授予的决定位置。

因此：

```yaml
zx_current_state: rejected_for_this_micro_object
```

## 3｜nx 判断

在黄泥冈“是否停歇 / 是否继续推进”这个窄对象层，局部 nx 显影成立。

关键不是谢都管名义身份高，而是：

```text
谢都管的反对发生在结果生效前
+
这个反对真的改变了执行结果
+
杨志不能稳定绕过
+
杨志必须让渡/重配
```

所以：

```yaml
real_external_veto_still_active: true
local_nx_relation_function: true
stable_x_internalization: false
```

这符合现行 nx 准度卡：权限仍在外部、主体不能稳定自行处分时，不能因为一次授权或临时持有就直接判 x。

## 4｜为什么这是 temporal closure B 型的反向护栏

孙策资源内化型正例要求的是：

```text
外部资源进入主体持续统辖
→ 原节点不再能逐次批准/撤回/卡住
→ 后续主体可直接调用
→ nx → x
```

杨志恰好相反：

```text
表面：
人、货、押送责任、早晚住歇提调权都“给了杨志”

现实：
冲突时谢都管仍能压住“是否停歇”这一当前决定
→ 原外部否决层没有退出
→ x 内化不成立
→ 不能据此宣布旧 nx 关闭
```

因此锁出新的反筛选句：

> **资源/权限“已交付”“在手中”“由你负责”只证明 x 候选；若原外部节点仍能在同一对象结果生效前真实撤回、覆盖、否决或迫使主体重配，则资源/权限尚未稳定内化为 x，不能用它证明 strict temporal closure。**

## 5｜拿掉测试

### 拿掉纸面授权

只保留黄泥冈现实冲突：谢都管反对，杨志的“不停”无法稳定生效。

结论仍然是：当前现实处分边界没有稳定归杨志。

说明纸面授权不是 x 的充分条件。

### 拿掉谢都管现实否决

假设谢都管只能建议，反对也不能阻止杨志继续催行，众军最终仍必须按杨志“不停”的决定执行：

```text
稳定 x 证据明显上升
nx 下降
```

说明真正支柱是现实事前否决能力。

## 6｜反向测试

真正支持 B 型 `nx→x` 内化的材料，应看到：

```text
资源/权限进入主体手中
→ 后续调用无需回原节点逐次批准
→ 原节点反对不能稳定撤回/覆盖
→ 主体能自行决定使用、调度或处分
```

若仍是：

```text
名义交付
+
原节点一说“不”就能改变同一结果
```

则不能判稳定 x，更不能宣布旧 nx 接口退出。

## 7｜最近邻排除

### nx vs x

本轮核心。看现实可否决性，不看“领状”“提调”“对象已经在手里”这些纸面词。

### nx vs xn

杨志对路线、行程、风险的安排有明显 xn 邻近，但 xn 回答“怎么组织运输”，不回答“最终谁能让停歇决定生效”。

### x vs zx

即使未来证明杨志拥有稳定押运处分权，也先是 x；只有决定范围继续推出旧边界并公开扩权才查 zx。

## 8｜第三因素冻结

冻结：

- 天气酷热；
- 杨志暴躁；
- 众军是否喜欢他；
- 生辰纲最终被劫；
- 谢都管身份评价；
- 吴用是否高明。

只保留：

```text
纸面权限交给谁？
当前对象是否已在主体手中？
原外部节点能否在生效前真实说“不”？
这个“不”能否改同一结果？
主体是否必须让渡/重配？
```

结论保持。

## 9｜人物层与压力层

本轮不锁杨志稳定本体。

- 人物稳定本体：不锁；
- 当前运输组织：xn 邻近；
- 当前“是否停歇”权限关系：局部 nx 高显影；
- 名义提调：x 候选但被现实否决击穿；
- 外部压力：黄泥冈风险 + 团队疲劳只负责触发冲突，不直接决定十元分类。
