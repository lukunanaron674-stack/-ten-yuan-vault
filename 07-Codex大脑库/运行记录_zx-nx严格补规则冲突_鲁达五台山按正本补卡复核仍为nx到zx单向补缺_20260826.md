# zx↔nx｜鲁达五台山按 current canonical 重验：仍为 nx→zx 单向补缺

## 0｜结论

按当前 canonical `zx补nx_补卡` 重验后，鲁达“拳打镇关西 → 通缉逃亡 → 赵员外/智真长老/度牒 → 五台山剃度”仍不构成严格 `zx↔nx` 双向补。

最稳结论：

```text
zx：成立（前段公开施力、强行改写郑屠冲突）
nx：成立（后段沿赵员外—智真长老—度牒—寺院准入通道完成安身与身份转换）
nx→zx：成立，外部关系/身份通道补 zx 后果留下的长期安身缺口
zx→nx：不成立，拿掉前段 zx 高显影后，后段 nx 通道仍可独立完成其当前核心身份转换功能
strict zx↔nx：否
one-way complement：nx→zx
```

本轮不改 L1、信息卡、准度卡或补卡正本。

---

## 1｜剧情事实链

### 前段｜zx

鲁达为救金翠莲，自行决定介入郑屠冲突，公开施力，三拳打死郑屠。主体自己的方向和权能直接进入现实，郑屠与现场被迫响应，结果被强制改写。

郑屠死亡后，鲁达进入通缉/逃亡窗口。

### 后段｜nx

鲁达逃至赵员外庄上后，官差继续打听追捕。赵员外提出五台山方案：

- 五台山文殊院智真长老与赵员外有既有关系；
- 赵家是寺院施主檀越；
- 赵员外已有一张五花度牒；
- 赵员外承担费用与物资；
- 智真长老掌握最终寺院收录/剃度接口。

鲁达明确接受“做和尚、专靠员外做主”的方案，随后沿该既有关系、度牒、费用、寺院准入通道完成剃度，成为鲁智深。

原著第四回还明确出现寺中众僧反对、智真长老最终决定剃度，进一步证明最终准入权限并不在鲁达手里。

## 2｜zx 端独立成立

前段 zx 不依赖赵员外、智真长老、度牒、寺院关系：

```text
自己定救人方向
→ 自身权能公开进入现实
→ 郑屠/现场被迫回应
→ 冲突结果被主体强制改写
= zx
```

这里不是“鲁达很能打”就判 zx，而是满足公开显权、现实响应、决定范围/影响位置上升。

人物稳定本体本轮不锁，只锁当前状态端点。

---

## 3｜nx 端独立成立

通缉后的当前对象已经切换为：

```text
长期安身
+ 合法/可持续身份转换
+ 寺院准入
```

这些关键权限和解决通道都不在鲁达稳定调用边界：

```text
赵员外：庄院庇护、檀越关系、度牒、费用
智真长老：寺院最终收录/剃度权限
鲁达：真实接受并沿该通道续接
= nx关系功能
```

这不是纯 nx 人物本体，也不是 xn。鲁达没有自己搭一套新的身份系统，而是进入既有关系和权限网络。

## 4｜双向拿掉测试

### A｜拿掉 nx

保留前段鲁达 zx，但删除赵员外、智真长老、度牒和寺院准入接口。

结果：

```text
鲁达仍有自己的方向和公开强力
→ 但官府通缉仍在
→ “长期安身 + 身份转换”留下明确现实缺口
```

补回 nx 后，外部庄院、度牒、寺院关系直接改善该缺口。

因此：

`nx_to_zx_gap_filling: true`

### B｜拿掉 zx 高显影

只拿掉前段“公开压制郑屠并形成 zx 高显影”这一端点，保留最低限度的“鲁达需要安身/愿意接受出家方案”这一任务对象。

此时：

```text
赵员外仍可提供度牒、费用、关系与安身路径
智真长老仍可决定是否收录
鲁达最低限度承接后仍可完成剃度与身份转换
```

后段 nx 通道没有出现 current canonical 所要求的独立“有路径却缺落地权能”缺口。

关键区别：本人走路、同意剃度、配合仪式只是普通承接动作，不能自动升级为 zx 的公开落地权能。如果把“本人最终参与执行”都算成 zx→nx，则几乎所有求人办事都会被膨胀成严格补。

因此：

`zx_to_nx_landing_power_gap_filling: false`

严格双向补失败。

## 5｜为什么这次与曹操/宋江/孙策/鸳鸯/红孩儿不同

这些已恢复 strict 的案例中，外部 nx 路径虽存在，但同一当前结果仍需要 zx 端把路径兑换成公开行动、决定与结果推进。

鲁达五台山不同：

```text
赵员外关系/度牒/费用
+ 智真长老准入决定
+ 鲁达最低限度承接
→ 身份转换本身即可完成
```

前段 zx 的公开显权并不是后段 nx 通道落地的不可替代条件。

因此 canonical 纠偏并不意味着所有旧“单向补”都恢复 strict；本例继续作为 strict 与普通单向补之间的反例护栏。

## 6｜最近邻排除

### nx vs xn

鲁达没有自己设计“如何取得度牒、如何建立寺院关系、谁来批准”的完整流程；关键通道由赵员外和寺院既有结构给出，主判 nx。

### nx vs x

度牒、费用、赵员外关系、智真长老收录权在进入前都不属于鲁达稳定调用边界，因此不是 x。

### zx vs 普通行动

鲁达接受剃度、走到寺院、参与仪式，不满足 zx 的公开扩权硬门，不能拿这些动作去补反向缺口。

### 压力显影 vs strict complement

本段更适合同时作为：

```text
前段直接路径 zx
→ 通缉压力使该路径不适合长期安身
→ 后段 nx 关系功能抬高
```

但“压力显影”与“严格双向补”是不同问题，不能互相代替。

## 7｜反向测试：怎样才会变成 strict

若原文出现：

```text
赵员外提供度牒/关系
智真长老同意收录
↓
但这些条件仍不足以让剃度/身份转换真实成立
↓
必须由鲁达自身 zx 的公开权能再次进入
↓
才能迫使寺院、制度或外部秩序完成该身份结果
```

则 `zx→nx` 可重新检查。

原著没有这一结构。

