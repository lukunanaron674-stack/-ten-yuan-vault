# 《水浒传》宋江三处投奔候选｜具体节点可替代但外部接口层仍为 nx 第三控制

## 结论先行

本轮锁定一个权限边界控制：**nx 不要求某一个具体姓名的外部节点绝对不可替代。**

真正需要检查的是同一现实瓶颈在当前窗口中，主体是否仍必须经过某类外部已有权限、资源、关系或裁决接口才能闭环。

宋江杀阎婆惜后，自己决定必须离开原处，也会主动比较柴进、花荣、孔太公三个安身候选；但他不能单方面生成一个安全庄院、庇护许可和对官府追捕的保护能力。于是“柴进这个人”并非唯一不可替代节点，但“外部庇护接口”仍然不可由宋江自己稳定替代。本阶段仍锁 `nx` 关系功能。

这与《红楼梦》贾芸先求贾琏未成、再转凤姐，以及《西游记》真假美猴王连续更换外部辨真节点形成三作品同型。

## 1｜剧情事实、触发、对象、动作与结果

### 触发

宋江杀阎婆惜后被官府追捕，原居地不再适合作为长期安全落脚点。

### 对象

当前对象不是“宋江人生最终方向”，而是更窄的：

> 怎样取得一个现实可用的安全落脚、藏身与保护接口。

### 明确动作

宋江并非只知道柴进一人。他主动列出三个可投奔之处：

- 柴进庄；
- 花荣处；
- 孔太公庄。

随后与宋清商议，决定先投柴进。到柴庄后明确说明无处安身、特来投奔；柴进作出接纳决定并提供庄院、衣食和保护。

### 结果

```text
主体自己决定逃离
+
主体自己比较多个候选节点
↓
但关键安全资源/庇护许可仍在外部
↓
选择柴进这一既有关系节点
↓
柴进批准并提供资源
↓
当前安身瓶颈解除
= nx关系功能
```

## 2｜nx 证据

本轮不锁宋江稳定人物本体为 nx。

宋江有自己的判断：知道要离开、知道可以选谁、会比较候选关系网络。

但关键问题是：

> 宋江能不能不经过任何外部主体，自己稳定生成等价的庄院、藏匿、衣食和抗追捕保护？

本段不能。

所以 nx 成立在关系功能与现实权限位置。

更重要的是：

> **nx 的不可替代性应优先检查“接口层”，而不是“具体姓名层”。**

柴进不是唯一候选，但所有候选方案都仍属于“通过他者已有庇护/关系资源取得安全落脚”的外部接口类。

## 3｜为什么存在替代节点仍不取消 nx

若把“nx 必须只有唯一一个人能帮”当成判据，会产生明显误判。

宋江有柴进、花荣、孔太公三个候选；贾芸可以从贾琏转凤姐；孙悟空辨真假可以从观音、天庭、唐僧、地府逐级转向如来。

三个案例都说明：

```text
A节点失败/不用
→ 转B节点
→ 仍然必须经过外部权限/资源/裁决接口
= nx可以持续
```

所以应区分：

```text
具体节点可替代
≠ 外部接口层可自给
```

只有当主体出现真正的内部化绕行：不再需要同类外部接口，自己即可稳定让同一结果生效，nx 才明显下降。

## 4｜zx 检查

宋江主动选择投奔对象，不等于取得庇护处分权。

他没有：

- 自己取得柴庄或其他庄院的稳定处分权；
- 强迫柴进/花荣/孔太公必须收留；
- 建立一个由自己控制的替代庇护系统；
- 扩大到可以给自己或别人签发同类庇护许可。

因此 `zx_takeover_of_interface: rejected`。

主动换节点只能说明主体有选择权，不等于外部权限已经被主体接管。

## 5｜xn 最近邻排除

宋江会比较三个去处，并与宋清商议，这有 `xn` 邻近。

但 xn 只解释：

> 他怎样选择、排序和切换候选路径。

它不能生成：

- 柴进庄的实际所有/处分；
- 柴进是否接纳；
- 花荣、孔太公是否提供同等级庇护。

所以当前运行选择可以有 xn，但关键安身接口仍为 nx。

## 6｜拿掉测试

### 拿掉柴进这个具体人

保留花荣、孔太公等外部庇护候选，宋江仍可继续沿另一外部关系接口求庇护。

结论：

> 柴进姓名不是 nx 的必要支柱。

### 拿掉整个外部庇护接口类

假设柴进、花荣、孔太公及其他外部关系网络全部不存在，同时宋江也没有自己的安全庄院和稳定保护系统，则当前安身缺口重新出现。

结论：

> 外部庇护接口类是当前 nx 的真正支柱。

### 补入主体自有稳定庇护系统

如果宋江自己已有可直接调用的安全庄院、护卫、资源和持续藏匿体系，不需任何外部接纳者，则同一安身对象层的 nx 会明显下降，转查 `x/xn`。

## 7｜反向测试

### 反向A：低成本稳定内部绕行

```text
外部节点拒绝
→ 主体立即调用自己已有的等价庇护系统
→ 不需要任何外部许可
→ 同一安身结果稳定实现
```

则局部 nx 显著下降。

### 反向B：只是换一个外部节点

```text
柴进不行
→ 去花荣
→ 仍须花荣接纳和提供资源
```

仍然是 nx，只是节点转接。

### 反向C：改变结果对象

如果宋江不再追求“获得安全庇护”，而改为公开与官府决战、另建武装据点，则已经换了对象层，应重新检查 zx/x/xn，不能把它当作原 nx 的简单绕行。

## 8｜第三因素冻结

冻结：宋江名望、柴进仗义、花荣友情、孔太公亲近程度、官府善恶、宋江后来上梁山、具体距离和路费。

只问：

1. 当前同一安身瓶颈还在吗？
2. 任一可行路线是否仍必须经过外部主体的庇护/资源/许可？
3. 主体有没有一个稳定、自有、可直接调用的等价内部路线？

答案仍为：外部接口层依赖存在，具体节点可替代不取消 nx。

## 9｜跨作品最小差异

### 《红楼梦》贾芸

贾琏未办成 → 转凤姐 → 仍须外部派差权限生效。

### 《西游记》真假美猴王

观音/天庭/唐僧/地府无法辨真 → 转如来 → 仍须外部识别/裁决接口完成。

### 《水浒传》宋江

柴进并非唯一候选 → 花荣/孔太公也可作为替代 → 仍须外部庇护接口提供现实安全条件。

三者共同支持：

> **具体节点的可替代性，只能削弱“此人唯一不可替代”的说法，不能自动削弱 nx 本身。**
>
> **nx 应优先在“同一现实瓶颈是否仍需某类外部接口”这一层判断。**
