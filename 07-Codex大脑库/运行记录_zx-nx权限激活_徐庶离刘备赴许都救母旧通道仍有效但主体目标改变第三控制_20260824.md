# 运行记录｜徐庶离刘备赴许都救母：旧 nx 通道仍有效，但主体当前目标改变

## 0｜结论

本轮只锁当前行为/关系位置，不锁徐庶稳定本体。

```text
刘备重用徐庶为军师
→ 徐庶真实进入并持续承担军师关系/任务
= nx 已激活

程昱伪造徐母书信
→ 徐庶相信母亲被曹操拘押、性命受威胁
→ 当前最高行动终点从“继续辅佐刘备”切换为“立即赴许都救母”
→ 主动告辞离开
= 旧 nx 当前执行窗口结束
```

关键控制：刘备没有撤回徐庶的军师关系，也没有封闭其继续效力的通道；相反，刘备允许徐庶离去，并明确表示见过母亲后仍可能再得奉教。因此本例不是“外部通道撤回”，而是主体当前目标改变导致主动停止续接。

## 1｜剧情事实、触发、对象、动作、结果

### 前段：旧 nx 真激活

第三十五回后，徐庶以单福身份进入刘备集团，受刘备重用，并实际作为军师提供谋划、参与新野军事运行。这里不把徐庶的智谋本身判 nx；nx 只锁“作为刘备麾下军师，真实进入并续接主从/任务通道”这一关系位置。

### 触发

第三十六回，曹操采纳程昱之计，将徐母赚至许都；徐母拒绝写信后，程昱仿其笔迹伪造家书，令徐庶误以为母亲被拘、生命悬危，并要求其星夜赴许都。

### 明确动作

徐庶读信后直接向刘备说明真实身份与母亲处境，并明确表示：并非不愿继续效力，而是母亲被执，当前不得不离开；随后拜辞赴许都。

### 结果

刘备并未撤销关系或拒绝徐庶继续效力，而是允许其离开，并表示与母亲相见后仍可能再得奉教。旧通道仍然有效、开放；退出原因发生在徐庶当前目标侧。

## 2｜nx 判断

### 2.1 前段成立

徐庶已经真实进入刘备军师关系，并持续在该组织/任务通道内行动，因此：

`nx_prior_service_relation: evidence-locked`

但这不等于“徐庶稳定本体没主见”。他的具体谋略设计可出现 xn 邻近；本轮 nx 只锁上位关系/任务续接。

### 2.2 退出窗口成立

本轮核心是：

```text
旧通道仍有效
+
刘备没有撤回角色/许可
+
旧任务并未被证明失效
+
徐庶当前最高行动终点改为救母
+
徐庶实际离开并停止旧关系续接
= 旧 nx 当前窗口结束
```

因此：

`nx_old_route_after_exit: rejected_as_current_execution_route`

## 3｜zx 判断

退出本身不成立 zx。

徐庶没有因为离开刘备而：

- 取得更大的公共决定范围；
- 改写刘备集团的最高方向；
- 迫使刘备集团围绕新增“徐庶最高决定接口”重排；
- 公开把自身权能推进到此前不属于自己的新处分域。

所以：

`zx_from_exit_itself: rejected_as_primary`

“自己决定离开”只能证明当前目标/个人选择发生变化，不能替 zx 通过扩权硬门。

## 4｜xn 最近邻排除

徐庶离开前确实做了说明、告辞，并在临走时推荐诸葛亮，但本窄窗口没有出现由徐庶自行搭建的多节点长期运行系统。

本轮主变量是“还沿不沿旧刘备军师通道”，不是“怎样组织一套新的持续流程”。因此：

`xn_in_exit_stage: rejected_as_primary`

## 5｜关键压力

关键压力是徐庶相信：

> 母亲被曹操拘押、性命受威胁。

这改变的是徐庶当前行动优先级/最高终点，而不是刘备通道本身的有效性。

必须区分：

```text
外部通道失效
≠
主体因新高优先目标主动停止使用仍有效通道
```

## 6｜拿掉测试

### 拿掉伪造母书与母亲危机

若没有新的救母目标，刘备军师关系仍有效，徐庶没有文本级理由在此窗口退出；旧 nx 应继续。

### 拿掉刘备继续开放关系的证据

若刘备明确罢免徐庶、禁止其返回，则会变成“外部节点撤回/反转”型，不能承担主体目标改变控制。

### 拿掉徐庶实际离开

若徐庶只是担忧母亲，却仍继续留在新野履职，则只能锁目标冲突/压力，不能锁旧 nx 当前窗口已经退出。

## 7｜反向测试

### nx 持续

```text
母亲危机没有成为当前最高目标
+
刘备通道仍开放
+
徐庶继续履行军师职责
= nx 持续
```

### 主体目标改变型退出

```text
刘备通道仍开放、有效
+
主体当前最高行动终点切换为救母
+
实际停止旧关系续接并离开
= 旧 nx 窗口结束
```

### 真正 zx

还必须额外看到退出后徐庶公开扩大自身现实决定范围。原文这一窄阶段没有。

## 8｜第三因素冻结

冻结：徐庶“至孝”性格标签、曹操善恶、程昱计谋评价、伪信真假、诸葛亮推荐、后续徐母自尽。

只保留六问：

1. 旧刘备军师通道是否真实激活？是。
2. 离开时通道是否仍有效？是。
3. 刘备是否撤回/拒绝？否。
4. 徐庶当前最高行动终点是否改变？是。
5. 是否实际停止续接？是。
6. 退出本身是否扩大决定范围？否。

分类仍稳定为 96%。

## 9｜跨作品最小差异

现有同型：

- 《西游记》猪八戒：取经通道仍有效 → 当前目标转向招赘 → 退出。
- 《水浒传》李俊：赴京朝觐/受官通道仍有效 → 当前目标转向不愿为官、出海 → 退出。
- 《三国演义》徐庶：刘备军师通道仍有效 → 当前目标转向赴许都救母 → 退出。

三部都支持：

> **通道仍有效，不足以证明当前 nx 仍持续；还必须检查主体当前最高行动终点是否仍与旧通道一致，并且是否仍真实续接。**
