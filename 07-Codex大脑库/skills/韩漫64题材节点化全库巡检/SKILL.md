# 韩漫64题材节点化全库巡检 Skill v1.2

## 1｜体系口径

### 1.1 十元就是五行

本 Skill 中不得把“五行”和“十元”写成两套系统或上下两层。

正确口径：

```text
十元＝五行＝同一套理论本体
```

### 1.2 三种工作层

```text
底层理论层
十元定义、对子、五维、生克补与动态规律

应用教学层
用十元拆解外部知识，建立具体名词联想、概念区别、对象关系和创作用途

分析验证层
用12节点、主体权限、体量顺序、生克补、反证与动态链验证具体案例
```

当前韩漫64题材库必须同时保留应用教学和分析验证，但不能把两层混成一篇难以阅读的文档。

---

## 2｜三个载体的固定职责

### 2.1 分类 Markdown：应用教学正本

对应 `A_..._节点化.md` 至 `H_..._节点化.md`。

Markdown只负责：

1. 题材学习目标；
2. 具体专业名词解释；
3. 相邻名词区别；
4. 用十元扩展具体名词联想；
5. 对象之间的连接关系；
6. 可直接使用的剧情、角色与场景联想；
7. 跨题材名词索引。

不得把以下内容作为教学正文主体：

- 12节点审计表；
- 端点判定过程；
- 体量与顺序记录；
- 生克补关系状态审计；
- 动态链验证报告；
- 十元基础定义词典。

这些内容转入详细 Canvas。

### 2.2 详细 Canvas：分析验证载体

对应 `R4_<区>_*.canvas`。

详细 Canvas负责：

- 12节点；
- 主对象与关联对象；
- 主体、权限与关系功能；
- 前后状态与不可逆变量；
- 阶段主次十元；
- 体量与顺序；
- 生克补关系状态；
- 对子动态链；
- 拿掉、反向、第三因素与失败边；
- 结算和稳定锚点。

### 2.3 视觉总览 Canvas：教学导航

对应 `R4_<区>_*_视觉总览.canvas`。

视觉总览负责：

- 8题材导航；
- 每题材核心名词；
- 十元具体名词联想网；
- 最重要的名词区别；
- 对象连接链；
- 创作入口；
- 指向详细分析 Canvas 的链接。

视觉总览不得冒充理论正本，也不得只显示抽象十元符号。

## 3｜最高门禁：十元用于教知识

### 3.1 不研究十元给自己用

题材库的学习对象是外部知识，例如：

- 股份、表决权、否决权、控制权；
- 血缘、法律身份、家族承认、资源准入；
- 发布权、署名权、版权、流量与专业认可；
- 皇位、军权、诏书、财政与官僚体系。

十元负责把这些对象拆开、扩展和连接，不是题材文件要重新讲授的对象。

### 3.2 必须有具体名词联想

每个题材至少建立一张“十元具体名词联想表”。

最低格式：

```text
x  → 具体权利、资源、入口和控制名词
z  → 具体认可主体、确认行为和采用结果
zx → 具体公开显权、夺权、裁决和强制动作
xn → 具体制度、流程、计划和长期组织名词
nx → 具体代理、代持、傀儡、被安排和方向让位名词
n  → 具体内部接纳、承载、团队和共同体名词
zn → 具体原则、身份核心、使命和不可让渡名词
nz → 具体庇护、归属、回返和修复名词
xz → 具体风险、截止、暴露、冻结和退路压缩名词
x并z → 具体职位、称号、标签、身份和公共接口名词
```

不是每个题材都必须强行让十元全部成立，但教学联想可以说明：

- 哪些名词常出现；
- 哪些只在特定分支出现；
- 哪些在该题材中通常缺席；
- 哪些最容易混淆。

### 3.3 禁止抽象替代具体

禁止只写：

```text
资源、权力、身份、关系、认可、制度、危机
```

必须继续下钻，例如：

```text
资源 → 股份、现金流、军饷、账号、排期、教育基金
权力 → 表决、否决、任免、处置、发布、署名、军令
身份 → 董事长、法人代表、继承人、皇帝、艺名、正式配偶
```

### 3.4 必须做名词区别

每个题材至少区分三组最容易混淆的相邻对象，例如：

```text
股份 ≠ 控制权
继承资格 ≠ 已经继承
流量 ≠ 认可
皇位 ≠ 军权
婚约 ≠ 真实关系
变美 ≠ 社会位置上升
```

每次运行严格只处理一个题材。

一个题材完成时必须同步：

1. 分类 Markdown 中该题材的应用教学内容；
2. 详细 Canvas 中该题材的12节点分析；
3. 视觉总览 Canvas 中该题材的教学导航卡；
4. `state.json`；
5. `run-ledger.md`。

不得只完成分析而没有教学，也不得只写名词表而没有详细分析验证。

## 7｜应用教学写作标准

每个题材的 Markdown 至少包含：

```text
学习目标
→ 核心名词表
→ 十元具体名词联想表
→ 关键名词区别
→ 对象连接链
→ 剧情／角色／场景联想
```

### 核心名词表

每个名词写：

- 它是什么；
- 它包含哪些权利、资格、关系或机构；
- 它不等于什么；
- 它能改变哪些可观察变量。

### 对象连接链

必须先写知识对象之间怎样连接，例如：

```text
继承资格
→ 股份或董事席位
→ 表决联盟
→ 任免与资金调用
→ 实际控制权
→ 正式职位与对外身份
```

不得只给十元符号链。

### 创作联想

至少给两个能直接用于创作的变化，例如：

- 名位与实权分离；
- 认可与资源准入分离；
- 公开身份与内部归属分离；
- 获得位置但失去退路；
- 拿到资源却让出方向权。

## 8｜分析验证标准

详细 Canvas继续使用12节点：

```text
0 入口
1 对象
2 主体
3 权限与关系功能
4 触发行为
5 状态变化
6 十元端点
7 生克补
8 动态链
9 主题
10 反证
11 输出
```

### 动态链最低格式

```text
【阶段A：对象状态｜主符号体量｜次符号体量】
  ──触发、条件、被改变变量──▶
【阶段B：对象状态｜主符号体量｜次符号体量】
  ──接管条件／失败边──▶
【结算：主体、对象、稳定锚点】
```

必须包含主次符号、箭头、对象层、体量、顺序、触发、接管条件、第三因素、失败边与结算。

### 关系状态

每条生克补关系标记：

```text
已锁定可候选
条件调用
研究中未锁定
本题材不成立
```

未锁定关系不得写成正式关系。

## 9｜高风险边界

- 十元就是五行，禁止拆成两套体系。
- 股份不等于控制权；职位不等于实权；资格不等于取得。
- 流量不等于认可；名位不等于军权；婚约不等于真实关系。
- `nx` 不是现实落地，而是主体不占据本可拥有的方向位置。
- 被动守规则、忙碌和行业流程不自动构成 `xn`。
- 打脸、胜利和愤怒不自动构成 `zx`。
- 称号、服装和视觉符号不自动构成 `x并z`。
- 题材名、职业、身份和气质不得直接继承十元。

---

## 10｜跨区治理

题材可以跨区，但必须分清本区教学什么：

- B区教身份、准入、名位、控制、阶级和社会位置；
- 职业生产细节转H区；
- 能力升级细节转D区；
- 恋爱关系功能转A区；
- 危险犯罪程序转E区。

跨区不是删除题材，而是避免一份文件假装自己懂全世界。人类百科全书式文件通常最后只剩标题很有气势。

## 11｜Canvas写入规则

### 详细 Canvas

- 保留原Group、ID、坐标、尺寸、颜色和无关边；
- 只修改当前题材的12节点与必要边；
- JSON可解析，节点与边ID唯一；
- 只承担分析验证，不堆教学词典。

### 视觉总览 Canvas

每张题材卡至少包含：

```text
学习目标
核心名词
十元具体名词联想

对象连接链
创作入口
详细分析链接
```

## 12｜写入、并发与恢复

写前记录最新 main SHA并重读目标blob。写后立即远端读回。

任一步失败：

- 不推进 `currentTopic`；
- 标记 `PARTIAL_RECOVERY_REQUIRED`；
- 下轮优先核对和恢复；
- 不得覆盖并发修改；
- 不得因单轮失败、工具错误或额度顾虑停用任务。

不得修改 `01-十元系统/` 理论正本。

## 13｜完成门

一个题材只有同时满足以下条件才算完成：

- Markdown 已形成可读的应用教学；
- 至少一组核心名词有独立解释；
- 有十元具体名词联想表；
- 有相邻名词区别；
- 有对象连接链与创作联想；
- 详细 Canvas 的12节点分析已同步；
- 视觉总览教学卡已同步；
- 对象链和十元动态链均存在于适当载体；
- 关系状态符合现行L2；
- JSON、提交和远端读回全部通过；
- 状态与账本推进一致。
