# T-A01｜契约婚姻｜12节点修正提案

> 本提案保存本轮已完成的实质审计。尚未同步回写分类 Markdown、详细 Canvas 与视觉总览，因此不得将 T-A01 标记为完成。

## 发现的问题

1. 旧“核心对象”把公共配偶身份、合同、财产与退出权混成同一变量。
2. “合同启动或被迫续约”只写事件名，没有行动者、目的、回应、收益、代价与第三因素。
3. 主 `x并z` 从入口固定陪跑到结算，没有逐阶段重判 `xn / x / nz` 是否接管。
4. `x并z克nz`、`x生x并z`、`nz克x` 只列关系名称，没有标明现行状态、机制、变量与失败边。
5. 动态链是剧情摘要，不是对子到对子；缺主次体量、箭头、触发条件、接管条件、被改变变量与稳定锚点。
6. “结局相爱”没有分账共同时间、关系余温、回返位置与公共身份壳，容易把爱情结果直接判成 `nz`。

## 修正后的12节点

### 0｜入口

- 初始候选主：`x并z`。
- 辅助候选：`xn / x / nz`。
- 结论等级：`scaffold-topic / topic_node_incomplete`。
- 纪律：契约婚姻题材名不继承任何十元；公共配偶壳、合同组织、资源掌握与关系余温须逐阶段重判。

### 1｜对象

- 主对象：**对外可识别、可调用并承担关系角色的公共配偶身份壳**。
- 关联对象分账：
  - 合同条款与续约流程；
  - 财产、居住、名额与家族资源；
  - 退出、否决与解释权限；
  - 双方真实关系、共同时间与可回返位置。
- 禁止把合同、财产、身份壳和真实关系合成一个“大对象”。

### 2｜主体

- 签约双方：分别记录稳定本体与当前行动位置。
- 合同提出者／续约推动者：当前阶段行动者。
- 家族、公司、法律或公共场景：身份壳的采用与调用接口。
- 财产与居住控制者：`x` 候选主体。
- 真实关系的双方：`nz` 是否成立的关系主体。
- “客观上结婚”与“被外界采用为配偶”必须分账。

### 3｜关系

- 权限：谁定义合同、谁能退出、谁掌握资源、谁解释条款、谁拥有最终否决与续约决定权。
- 功能：谁维持公共身份壳、谁承载共同生活、谁确认双方关系、谁对外代表。
- 每项权限和功能必须落到具体主体，不保留空泛检查菜单。

### 4｜触发

- 候选触发：合同提出、公共身份被调用、续约窗口、违约危机或退出申请。
- 案例必填：行动者／对象／目的／对方独立回应／即时收益／延迟代价／第三因素。
- 被迫签约优先排查 `x / zx / xn`，不能因为存在合同就判 `xn`。

### 5｜状态

```text
前态：双方没有稳定公共配偶接口，或只有利益同盟
→ 触发：合同及公共调用条件成立
→ 后态：公共身份壳被机构、家族或公众采用；资源与退出边界被重新分配
→ 后续分支：真实关系仍为空 / 共同生活产生承载 / 形成共同时间与回返位置
```

不可逆变量优先记录：公共采用范围、退出成本、资源调用权、共同居住连续性、再次返回资格。

### 6｜十元端点

- 阶段A：条款、期限、信息与行动被主动组织时，`xn` 候选；被动遵守合同不算。
- 阶段B：配偶身份成为可识别、可调用、可对外代表的接口时，`x并z` 候选接管。
- 阶段C：财产、居住、名额、否决或退出边界被具体主体掌握时，`x` 候选。
- 阶段D：跨阶段共同时间、关系余温、不愿结束与可信回返位置成立时，`nz` 候选；结局相爱不够。
- 每段需补主体归属、对象层、体量与顺序。

### 7｜生克补

- `x生x并z`：可作为已锁定关系候选。必须证明实际掌握边界先成立，并因对外识别、调用或保护需要生成公共配偶壳。
- `x并z克nz`：不得只因“假婚姻压住真感情”就调用；须核对现行关系卡是否已锁定，并证明公共壳具体降低共同时间、回返资格或关系余温的成立能力。
- `nz克x`：不得把“爱战胜金钱”写成关系；须证明已有关系停靠怎样具体减少掌握、占有或控制边界。
- 若关系卡状态不明，统一登记为 `condition-check-required`，不得写正式机制。

### 8｜动态链

```text
【阶段A：xn候选｜x候选｜合同与资源边界被组织】
  ──合同被公共接口采用；改变变量=身份可识别性/调用范围/退出成本──▶
【阶段B：x并z主｜xn或x次｜公共配偶壳运行】
  ──共同生活跨阶段持续；接管条件=真实承载+共同时间+可信回返位置──▶
【阶段C1：nz候选接管｜x并z次｜壳与真实关系重新对齐】
  ──结算=关系是否主动保留、公共壳是否重建、退出权是否恢复──▶
【稳定锚点：具体关系主体 + 公共身份采用范围 + 可回返位置】
```

失败边：

- 只有合同和同居，没有共同时间与可信回返位置，`nz` 不接管。
- 只有称呼、婚礼或视觉情侣符号，没有公共调用功能，`x并z` 不成立。
- 条款由外部强制且主体只被动执行，不能把该主体判为 `xn`。
- 资源边界没有改变时，不登记 `x` 上升或下降。

### 9｜主题

- 暂不自动升格。
- 若中心问题持续围绕长期合同组织与阶段性关系确认，可登记时间候选。
- 若公共壳与内部真实关系构成全片中心问题，并由转折、高潮与结局共同结算，可登记本体或空间候选，仍需另行验证构成对。

### 10｜反证

- 有合同不等于 `xn` 人物。
- 有婚姻称号、戒指、婚礼和同居不等于 `x并z`。
- 财产多、家族强势不等于当前主体拥有 `x`。
- 结局相爱不等于全程 `nz`。
- 拿掉公共身份壳后若主要冲突仍以同样方式运行，主 `x并z` 降级。
- 若真正推动情节的是强制、资源控制或期限组织，主驱动应重分配给 `zx / x / xn`。

### 11｜输出

- 公共身份壳卡；
- 合同组织卡；
- 资源与退出权限卡；
- 双主体关系卡；
- 分阶段端点卡；
- 条件关系卡；
- 对子动态链卡；
- 失败边与反证卡。
