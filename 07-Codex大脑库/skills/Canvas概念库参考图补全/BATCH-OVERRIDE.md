# Canvas 概念库参考图补全｜批处理覆盖规则

本文件在 `SKILL.md` 与 `RUNTIME-OVERRIDE.md` 之后生效；账本写入另以 `LEDGER-PROTOCOL.md` 为最终规则。

## 单轮容量

- 一次运行最多完成 5 个概念或历史节点恢复。
- 当前断点未完成时，必须先恢复当前断点；恢复成功后才可使用本轮剩余额度。
- 每个概念必须独立完成：参考笔记、Canvas file 节点与连线、提交 main、远端读回、状态更新与独立账本记录。
- 只有当前概念达到 `remoteVerified=true` 且 `canvasLinked=true`，并且独立账本记录已远端读回，才能继续本轮下一个概念。
- 任一步失败立即停止本轮；此前已经远端验证的成功项保留，不回滚。
- 单轮达到 5 个成功项，或当前库没有更多合格候选时，结束本轮并报告真实结果。

## 分片账本

- 禁止继续向 `run-ledger.md` 追加完整历史。
- 每个产生新证据或新状态的概念结束时，在 `run-ledger.d/YYYY-MM/` 创建一份不可变记录。
- 创建成功并远端读回后，只更新 `run-ledger-latest.json` 小指针文件。
- 已存在且内容一致的记录视为幂等成功；同路径内容不一致时立即停止，不覆盖。
- 旧历史只从 `ledger-archive/` 读取，不得修改。
- 相同节点、相同 Canvas/参考 blob、相同故障类型与相同下一动作的重复失败，适用 `LEDGER-PROTOCOL.md` 的失败去重规则：不得为心跳或错误重述制造新的 state、分片和 latest 提交。
- 重复失败且仓库无变化时，输出 `RETRY_DEFERRED_NO_REPO_CHANGE`，保留断点并等待下一轮。

## 图像来源

- 继续优先寻找作者、许可和来源页可核验的真实参考图。
- 禁止调用 AI 生图工具。
- 找不到可靠外部参考时，按运行覆盖规则创建 `prompt-reference` 并停止当前节点。
