# visual-hierarchy｜视觉层级规则 v0.1

## 目标

让人一眼知道：当前问题是什么、主要方向有哪些、现在该看哪里。

## 层级

- L0 ROOT / 当前问题：100%
- L1 一级主方向：80%
- L2 二级候选：60%
- L3 证据/说明：45%
- L4 折叠入口/历史：30%

百分比仅表示视觉尺寸参考，不表示十元强度、权重或概率。

## 同屏规则

- L1 同屏最多 3 个视觉中心。
- 同一级节点尺寸、字段顺序、间距保持一致。
- 一个语义簇内部紧凑；不同语义簇之间保留明显空白。
- contrast 可左右镜像；child 默认向下展开；evidence 靠近被支持节点但视觉降级。
- focus 只能有 1 个；必要时可同时显示 2 个主要 alternative，但不能都伪装成 focus。

## 折叠

折叠入口必须显示：

```text
[+N] 该簇还有 N 个候选
```

不得把折叠节点从数据中删除。

## 禁止

- 颜色、大小替代语义字段；
- 每个候选都抢一级视觉中心；
- 因节点文本较长就默认更重要；
- 画布自动布局改变父子/并列关系。
