# 十元链｜十元生克补的故事构成 Skill

**唯一短名：十元链。** “克—补—生”“双补”“双重补”“架桥”“三角克”“蓄补爆发”都是可能的链型/构成候选，不是由图形自动推出的全局关系定律。

## 默认触发
用户说“做十元链、登记卡片、这部电影是什么构成、像《钢琴师》那样先克后补再爆发、生克补怎么串联、横纵构图”时使用。若用户只要取名，先一句话回答，不自动生成冗长研究。

1. 执行前读取仓库 `AGENTS.md`、`07-Codex大脑库/每次任务必读_十元关系防遗忘清单.md`、`08-生克补动态链研究/每次任务必读_生克补动态链滚动中枢.md`。

3. 影片事实需实际版本/事件来源；F1剧情事件≠F2原片视听证据≠F3真人感受。使用影片证据时调用 `ten-yuan-film-analysis`；横纵文字图调用 `story-horizontal-vertical-text`；修改 Canvas 必须调用 `obsidian-canvas-layout`。

## 符号必填门禁｜USER 2026-11-02 校正
每一张电影「十元链」的**主图必须保留已确认的人物十元标注**，例如人物描述后的 `xn`、`z`，以及阻断层的 `zn x`；**不要求把所有行动边改写成公式**，不能只写「A帮助B」「两人互学」而完全没有具体行动和十元。每个符号必须注明**谁的哪一段感受/动作**，再跟一个可核具体事件、变量增减、下一阶段因果。格式为：
~~~text
第一阶段｜克【H】
源十元 ─克?→ 目标十元：具体人物/事件、已有能力或关系↓
          ↓
第二阶段｜补【H】
源十元 ─补?→ 目标十元：补入什么、功能/选择↑
          ↓
...
结局｜回收：十元′结果↑／不可逆残留仍在
~~~
`?`是未经过L2关系裁决的**研究记号**，不是把相反五轴或剧情顺序断言为生克补。只获悉人物旧归档主次十元时，写【旧角色卡/H】而非当代感受实测；物件、时间压力、疾病不能客观等于十元，必须固定电影语境和观众反应。**「双补」至少画出两条独立有证据的方向箭头；没有合法符号机制就标补?，不能省略符号也不能强行定律。** 「双桥汇聚」以 `符号 ─信息桥→ 符号` 表示，不把信息搬运自动写成补、生、克。

案例特记：旧角色卡《我们一起摇太阳》凌敏 X+XZ、吕途 N+XZ，但只能说两人有支持行动，不能无证据写 `XZ克X`、`N补X` 为严格关系；《情书》XZ↔NZ 是五轴感受对照，不是 `XZ克NZ`，把「旧事重排」硬写 `XN` 或把画像曝光硬写 `Z` 均属未证。**本Skill只教表达，不确认以上箭头机制。**

**固定呈现原则**：以**人物在具体事件中如何作用**为中心。按「第几层／关系名称 → 人物的性格、需求、十元符号 → 双方行为箭头 → 阶段改变 → 克制/阻断事件及十元标注 → 升级后的具体行动和时间代价 → 汇合」纵向写；不把用户原话改成纯公式，也不强加 `【XN】` `【Z】` 到每个人名后。用户指定的十元符号放在原本句子位置；克补的正式机理状态另放简短审核，**不挤进用户主图**。

### 其它作品沿用**排版方式**，不照搬剧情或固定三幕
- **分层标题**：第一层、第二层、第三层、结局；可以因作品增加或减少，不固定每部都“双补／本体双克”。
- **每层主体**：`角色：当前条件或需求 十元符号`；下一行 `角色 ──具体事件／具体行为──→ 另一角色 十元符号`；箭头表示实际作用行为而非自动被验证的“补／克”定律。
- **跨层连接**：垂直 `↓` 明确事件造成下一阶段的何种转折、强制阻断与回收；时间、体量、代价和末尾未回收部分按作品事实写。
- **先有故事事件、人物感受假设，再做关系审核**；关系缺证不要硬套符号，`XN`、`Z`、`ZN` 等写用户确认的标注即可。对未经核验的生克补，不在图内加 `补?` `克?` 破坏读图；图后简短写“关系为USER/H待审”。
- **具体事件是零件，不是抽象的价值解释**。不得以“互相帮助”“共同成长”代替具体行为箭头。

## 案例修正：双克与错位双回收（2026-11-03）

**超时空辉耀姬｜本体双克【USER】**：本体补对 ZN↔X 同时分别克制时间补对 XN↔Z 的两端；作用线为 ZN克XN（彩叶）、X克Z（辉夜）。不是 ZN克X，也不是两次都作用同一个人。受阻后辉夜跨越约8000年成为八千代、彩叶花10年研发身体，XN与Z沿自身方向将双补从日常升级到世界体量。此为用户确认的电影结构解释，不解除现行涉及 Z/ZN 的严格关系冻结。

**情书｜错位双回收链【H】**：博子（旧卡 nz+xz）给已故未婚夫寄信，女藤井树因同名回复；两人长相相似令博子怀疑自己是不是替身。博子在雪山向逝者问候，女藤井树则通过后辈送来的旧书及卡背肖像知道曾被男藤井树喜欢。女藤井树最后没有寄出画像相关的信，故旧「双桥完全汇聚」说法不准确；是两条各自结尾的回收。女藤井树旧卡 xn+z 曾遭用户质疑，保持待判；XZ↔NZ是五轴互补，不等于XZ克NZ。

**格式**：统一使用用户指定的「第一层人物十元＋具体行动箭头／第二层关系受阻／第三层分别回收」等宽图；不限于固定三幕，也不将信息往来直接称作严格生克补。

## R1→R2｜先分析后映射的十元审稿角色（USER 2026-11-03）
**用户目标**：先获得自然、完整、深刻的影视/故事分析，再由“十元代理”做一轮独立的符号映射复核。**主流程只需两轮，不强迫第一轮边想剧情边塞十元。** 第二轮是审稿角色/工作步骤；仓库中的文字规则不意味着已经创建或运行本地独立进程。

### R1｜内容分析（原稿锁定）
- 任务：用人物、真实事件、动机、阻力、具体行动、因果、高潮和结局完成自然的电影/故事分析；判断母结构，重视事实与人物心理。
- 输出：`R1_DRAFT`（完整文字图）＋ `EVENTS`（至少三个可核事件）＋ `ROLE_LIST`；既有用户十元标签可保留，但**不要求为每句话硬标十元**。
- 结束门：用户认可的洞察、事件顺序及不对称结局先保住。**冻结 R1 的内容主线**供第二轮逐段对应；不能因符号映射反过来改写影片事实。

### R2｜十元代理审校（必跑；只映射、少修改）
输入：R1_DRAFT、EVENTS、ROLE_LIST、用户明确给出的角色十元/关系、当前 L2 十元正本与关系冻结状态。
1. **角色定位**：每个出场关键人物的既有确定十元直接标在“人物：缺口/能力”后；用户未确定的角色只写`十元待判`，不要为了完整率杜撰。
2. **逐层贴标**：在每一层原有的**具体动作箭头**上附相应人物/感受符号，写清`谁作用于谁／通过何事件／哪个缺口或变量改变`。使用用户确认的等宽文字呈现，保留R1原动作、人物姓名和语言美感。
3. **生克补审计**：区分五轴静态对照、情节因果与严格生克补；先查L2。若被证据支持，仅作`生/克/补候选【H】`；合法用户标注以`【USER】`保存但不伪称L2实证。含 z/zn 关系仍遵守 `endpoint-redefinition-freeze`。**不为了图好看硬写不存在的克补箭头**。
4. **跨幕追踪**：先列初始两个端点和各自缺口，再看克/阻断实际改变谁，再看结局的体量、方向、残留；双补必须有两条不同的可见作用，双克必须逐条检验源端与目标端，不能把两个名字并排当作双克。
5. **完成检查**：每个已确认十元角色的标注有落点；每条声称的克/补/生可指向具体事件；未定的符号显式`待判`；R1所有关键事件和结局均被保留。输出 `R2_SYMBOL_OVERLAY`（主图）＋`待判关系≤3条`，不要重写整篇R1。
**仅在R2检查失败时**进行一次定点修复（修漏标或纠错），不启动无止境R3/R4。用户主动要求研究更多时另立工作。

## 核心审核（五问）
- **作用**：A通过什么可观察机制改变B的哪一个变量？没有就只标“拓扑/候选”，不能称严格生克补。
- **时间**：每一阶段的结果是否成为下一阶段的必要前提？先后不等于作用。
- **高潮**：“蓄补爆发”是否有**保存的能力/期待 + 被阻断的表达 + 新事件打开闸门 + 真正行动兑现**四要件？它是叙事显影强度，不等于凭空积攒十元作用量。
- **反事实**：拿掉蓄补、临界触发、实际兑现、残留，高潮是否仍成立？各问分别记录。
- **证据**：USER提法、F1事实、F2视听、【H】创作预测、F3人评分开；未实测 human_feeling=null。

## 标准示范｜《钢琴师》【USER关系判读＋H整理】

          ↓
XN   ──补──→ Z ：不能公开弹琴，但音乐身份仍保存
          ↓

### 双补审计必须做的反事实
1. 如果A、B只是交替安慰，没有改变对方原有缺口及后续独立行动，判【互助，不是严格双补】。
2. 如果第一层的帮助必须以另一人牺牲为前提，应先记【交易/伪补】，随后是否反转需独立事实。
3. 如果“第二轮”只重复第一轮原动作，是【持续双补】，不构成双重／回环双补；要求跨阶段**新缺口和新行为证据**。
4. 如果第三人或旧物只是转送消息，优先记【信息桥/汇聚拓扑】；没有可验证十元端点+变量，不凭“联结”二字判生或补。
5. 记录 F1/F2/F3；没有真实原片声画 F2 不写镜头时码、机位与准确配乐，也不从电影剧情反推观众十元感受已经证实。
