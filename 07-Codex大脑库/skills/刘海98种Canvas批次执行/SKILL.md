## 核心顺序

```text
真实发型资料
→ 名称规范化
→ 视觉差异核验
→ 去重与家族归类
→ 十元映射
→ Canvas 入库
→ GitHub 提交
```

禁止倒序：

```text
十元分类
→ 为凑数量编造发型名称
→ 用相似图片伪装成不同类型
```

## 核心原则

1. **真实资料先于十元映射。**
2. **找图优先，生图后置。** AI生图不能用来证明某种刘海真实存在。
3. **不平均分配十元。** 十元数量允许自然失衡。
4. **不把状态当基础类型。** 风吹、湿发、睡醒、工作、运动只能作为状态字段。
5. **删掉标题后仍应看得出结构差异。**
6. **没有实际写入 GitHub，不得声称完成。**
7. **用户只说“继续”时，直接读取进度并执行下一批，不反问可自行判断的问题。**

## 每批标准流程

### 1｜检索真实资料

优先级：

1. 专业美发媒体
2. 发型师或沙龙官网
3. 韩国、日本、中文、英文发型目录
4. 主流时尚媒体发型专题
5. 可核验的原作者社交账号或作品页

每个候选记录：

- 中文规范名
- 英文、韩文或日文原名
- 常见同义词
- 来源页面
- 参考图地址
- 来源类型

禁止把搜索缩略图当永久来源。

### 2｜名称规范化

区分：

- 规范主名
- 地区称呼
- 同义词
- 营销别名

同一结构仅因营销文案不同，不重复计数。

### 3｜视觉差异核验

每种记录：

| 参数 | 示例 |
|---|---|
| 长度 | 眉上、齐眉、过眉、眼下、颧骨、下巴 |
| 密度 | 极薄、轻薄、中等、厚重 |
| 分线 | 无分线、中分、三七、二八、偏侧 |
| 边缘 | 平直、圆弧、羽化、锯齿、缺口 |
| 卷度 | 直、内扣C卷、外翻、S卷、自然卷 |
| 宽度 | 窄三角区、标准、宽版、延伸至鬓角 |
| 遮挡 | 全露额、透额、半遮、遮眼 |
| 连接 | 与鬓角断开、自然连接、长侧帘连接 |

7种之间至少在两个参数上可见不同，或一个核心参数上显著不同。

### 4｜十元映射

每种独立记录：

```yaml
主十元:
副十元:
体量: 1-10
纯度: 0-100
五维归属:
视觉证据:
误判项:
```

十元视觉参考：

- `x`：边界、锋利、自我轮廓、拒绝混入
- `z`：节点、截断、切口、瞬间变化
- `n`：承载、连接、包裹、脸侧关系
- `zn`：原生、自然、贴近本来状态
- `nz`：停靠、柔软、归属、余波
- `xn`：秩序、分线、等距、规整节拍
- `nx`：让位、留白、退后、弱化存在
- `zx`：行动、功能、清晰视野、操作便利
- `xz`：漂流、不定方向、临界、风迹
- `x并z`：遮蔽、外壳、表面与内里分离

五维：

- 时间 = `xn + z`
- 本体 = `zn + x`
- 空间 = `x并z + n`
- 因果 = `zx + nx`
- 命运 = `xz + nz`

映射理由必须来自刘海本身，不依赖模特表情、服装、背景或天气。

### 5｜Canvas 写入

每种至少保留：

1. 真实参考图或来源节点
2. 说明文本节点

说明节点至少包含：

```markdown
## 编号｜中文规范名
**原名：**
**家族：**
**类型层级：**

**结构参数**
- 长度：
- 密度：
- 分线：
- 边缘：
- 卷度：
- 宽度：
- 遮挡：
- 连接：

**十元映射**
- 主：
- 副：
- 体量：
- 纯度：
- 五维：
- 视觉证据：
- 误判：

**来源**
- 页面：
- 图片：
- 来源类型：
- 核验日期：
```

排版：

- 每批一个 group
- 每批7种
- 图片／链接节点与说明节点分开
- 保留来源链接
- 不用整张海报代替可编辑节点

### 6｜批次审计

- [ ] 恰好7种
- [ ] 每种有真实来源
- [ ] 名称无乱码
- [ ] 没有明显重复结构
- [ ] 没把整体发型或配饰当刘海
- [ ] 每种有主、副十元
- [ ] 映射理由来自刘海本身
- [ ] Canvas 可编辑
- [ ] 进度数字已更新
- [ ] GitHub 已提交

任一关键项失败，本批不得标记完成。
