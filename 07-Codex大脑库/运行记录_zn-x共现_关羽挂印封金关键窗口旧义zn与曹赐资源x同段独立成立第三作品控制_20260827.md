# 关羽挂印封金｜zn + x 同段共现第三作品复验

## 0｜本轮只测试共现，不测试 strict

旧记录已经以 99/98 锁定：

- `zn`：对刘备旧盟/旧义拥有冲突排序与未来指导资格；
- `x`：曹赐金银、赤兔马等具体资源已经进入关羽现实占有/使用边界；
- 冲突发生后，关羽主动封金、悬印、不带曹拨人役，但赤兔马继续使用。

本轮只重新检查一个窄问题：

> **在“得知刘备消息 → 作出离曹选择 → 开始让渡部分资源”的同一当前窗口里，zn 与 x 是否曾同时独立成立？**

结论：成立。

## 1｜同一窗口为什么不是把两个阶段硬拼

得知刘备消息时：

- 旧义已经进入当前冲突排序，并决定“应归刘”；
- 曹赐金银仍在关羽实际持有范围；
- 赤兔马仍由关羽占有、使用；
- 侯印、人役等对象也尚处于随后即将让渡的现实关系中。

也就是说，`zn` 开始高调用时，`x` 并没有先全部消失。

随后“封金 / 悬印 / 不带人役”恰好证明：

> **主体是在已经拥有一批 x 的情况下，由 zn 决定哪些 x 应让渡；不是先没有 x，后来才出现 zn。**

赤兔马继续使用又说明，zn 并不要求把所有 x 一刀清零。

## 2｜zn 独立证据

`zn` 仍按旧记录：

- 旧盟/旧义对象明确；
- 曹操封侯、金银、礼遇构成真实反奖励压力；
- 冲突中旧义仍占最终排序；
- 得知刘备消息后，它重新进入当前高调用并指导离曹；
- 拿掉外部认可、地位和奖励，旧义仍能继续作为未来判断标准。

所以 `zn` 不依赖 `x` 才成立。

## 3｜x 独立证据

`x` 也不是因为“曹操送过东西”就成立，而是：

- 金银已进入关羽实际持有边界；
- 赤兔马被持续占有、骑乘和使用；
- 主体能够选择哪些对象带走、哪些封存/悬回；
- 这种选择本身说明对象曾处于现实处分边界，而非纯名义关联。

所以当前关键窗口里至少存在高纯局部 `x`。

## 4｜拿掉测试

### 拿掉 zn

保留金银、赤兔马等 `x`：

- `x` 仍然成立；
- 只是失去“为什么必须离曹、为什么部分资源应让渡”的内部排序依据。

### 拿掉 x

假设曹操从未给任何可现实掌握的资源：

- 旧义 `zn` 仍可成立；
- 但“原则如何处理已掌握对象”的共现测试消失。

两端都能独立成立，因此共现不是互相定义出来的。

## 5｜反向测试

如果得知刘备消息以前，曹赐资源已经全部被收回、失去实际控制，而关羽只是空手依据旧义离开：

- `zn` 可成立；
- 本轮 `zn+x` 同段共现不能成立。

原桥段不是这种结构，因为关键窗口中金银仍在持有边界，赤兔马还继续使用。

## 6｜最近邻排除

- `x ≠ z`：被曹操封侯、认可只是外部评价；真正的 `x` 证据来自实际持有、使用与处分。
- `zn ≠ z`：旧义不靠曹操认可才成立。
- `zn ≠ xn`：收拾车马、安排离开流程解释“怎么走”，不解释“为什么必须走”。
- `x ≠ zx`：当前锁的是既有资源掌握，不把每次处分对象都重复升级为扩权。
