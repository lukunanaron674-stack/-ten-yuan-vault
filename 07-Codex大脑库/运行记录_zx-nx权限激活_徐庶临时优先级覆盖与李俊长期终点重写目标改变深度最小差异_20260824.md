# 运行记录｜徐庶临时优先级覆盖 vs 李俊长期终点重写

## 1｜本轮问题

现有待审议已经跨三部作品锁定：即使旧 nx 通道仍然有效、开放、可用，只要主体当前最高行动目标改变并实际停止续接，旧 nx 当前执行窗口也可以结束。

本轮继续压力测试一个更细的问题：

> “当前优先级临时切换”和“长期最终终点真正重写”，是否应该被判成不同的 nx 退出层级？这种深度差异是否会自动把后者推成 zx 或 xn？

直接用两组已高置信材料做最小差异：

- 《三国演义》徐庶离刘备赴许都救母；
- 《水浒传》李俊班师途中诈病脱队、明确不愿朝京为官并转向出海。

## 2｜事实 A：徐庶 = 当前优先级覆盖

徐庶此前已经真实进入刘备集团并承担军师关系。收到伪造的徐母书信后，他明确说明并非不愿继续效力，而是母亲被扣、当前不得不离开，并说“容图后会”。刘备也明确保留“待与老夫人相见之后，或者再得奉教”的可能。

因此：

```text
旧长期方向：继续效力刘备
= 没有被明确否定

当前压力：母亲被扣 / 性命危险
→ 当前最高行动优先级切换为赴许都救母
→ 实际拜辞离开
= 旧 nx 当前窗口结束
```

本例锁的是：**current priority override（当前优先级覆盖）**，而不是长期价值方向已永久改写。

## 3｜事实 B：李俊 = 长期终点重写

李俊此前已经真实承接招安后的朝廷任务与宋江军令体系，并实际处在班师赴京、准备朝觐受官的路径上。到苏州城外，他诈病脱队；随后文本明确点破“原非患病，只是不愿朝京为官”。他又与童威、童猛转寻费保等人，实际造船出海。

因此：

```text
旧长期终点：赴京朝觐 / 接受官职

旧通道：仍有效、开放、可用
外部节点：没有撤回资格

但：
主体明确“不愿朝京为官”
→ 实际脱离旧路线
→ 建立并执行出海新路线
= 旧 nx 当前窗口结束
+ 长期终点重写证据显著强于徐庶
```

本例锁的是：**durable endpoint rewrite（长期终点重写）**。

## 4｜共同 nx 判断

两例都满足：

1. 旧 nx 曾经真实激活；
2. 旧通道在退出时仍有效、开放、可用；
3. 外部节点没有撤回；
4. 主体停止真实续接；
5. 因此旧 nx 当前执行窗口结束。

所以：

> nx 当前退出只需要“主体当前不再沿旧外部方向续接”。
>
> 至于这个变化是临时优先级覆盖，还是长期终点重写，是下一层深度变量，不能反过来否定 nx 已退出这一当前事实。

## 5｜zx 检查

两例都不能仅凭“目标改变”自动锁 zx。

### 徐庶

离开刘备救母没有扩大公共决定范围，没有建立新的徐庶最高处分接口。

### 李俊

“不愿为官、转向出海”比徐庶更长期、更彻底，但在班师脱队这个窄阶段仍没有因此取得宋江军、朝廷或其他组织的新最高处分权。

因此：

> **目标改变得更久、更彻底 ≠ zx。**

zx 仍必须独立看到主体自身权能公开进入现实、外部结构围绕新增接口响应、决定范围或位置真实上升。

## 6｜xn 最近邻

长期终点重写也不自动等于 xn。

徐庶离开主要是单一当前行动终点切换，xn 不主判。

李俊后段“诈病 → 找费保 → 造船 → 出海”存在明显 xn 规划邻近，但：

- “旧 nx 是否退出”由是否继续赴京判定；
- “新路线怎样搭起来”才检查 xn。

所以：

> **目标换了 ≠ 已经搭好新运行结构。**
>
> 只有新人员、资源、时序、节点与持续流程被主体组织起来，才另外锁 xn。

## 7｜关键压力

徐庶：母亲被扣，形成强烈但可逆的当前优先级压力。

李俊：对“朝京为官”这一长期终点本身作否定，并实际执行替代路线。

压力强度和持续性不同，但都不直接判十元；只用于识别目标改变的深度。

## 8｜拿掉测试

### 拿掉徐庶“容图后会 / 再得奉教”

如果文本改成徐庶明确永久否定继续效力刘备，那么他的材料会向李俊型长期终点重写靠近；但旧 nx 当前退出本身仍成立。

### 拿掉李俊“不愿朝京为官”

如果李俊只是暂时病停，并准备痊愈后继续朝觐，则不能锁长期终点重写，甚至不能锁旧 nx 已退出。

### 拿掉李俊后续出海

“不愿朝京为官 + 实际脱离班师队伍”已经足以支持旧终点被否定；出海主要强化新的长期路线真实执行，并增加 xn 邻近。

## 9｜反向测试

### 临时优先级覆盖

```text
旧长期方向仍认可
+
当前更高优先事项出现
→ 暂停旧 nx
→ 理论上仍保留未来恢复旧通道可能
```

徐庶属于这一侧。

### 长期终点重写

```text
旧通道仍有效
+
主体明确否定旧长期终点
→ 实际脱离
→ 执行替代长期路线
= 旧 nx 退出更深
```

李俊属于这一侧。

### 真 zx

无论临时还是长期目标改变，若没有额外出现：

```text
主体新增公开权能
→ 外部结构真实响应
→ 决定范围 / 位置上升
```

都不能自动判 zx。

## 10｜第三因素冻结

冻结徐庶“孝”的人物评价、曹操善恶、程昱计谋；冻结李俊后来是否成为暹罗国主、招安主题和宋江忠君评价。

只保留：

- 旧 nx 是否真实激活；
- 旧通道退出时是否仍有效；
- 主体是否停止续接；
- 主体是否明确保留旧长期方向；
- 主体是否明确否定旧长期终点并执行替代路线；
- 是否出现独立 zx / xn 硬证据。

结论保持 99/97。

## 11｜结论

> **nx 的“当前退出”与“目标改变深度”应分开记录。**
>
> 徐庶证明：临时最高行动优先级覆盖，已经足以让旧 nx 当前执行窗口结束，而不要求稳定长期方向换芯。
>
> 李俊证明：主体也可以更深地否定旧长期终点并执行替代路线，但这种“更长期、更彻底”的目标重写本身仍不自动等于 zx；新路线是否形成 xn，也必须另验运行骨架。

因此当前最小纪律是：

```text
第一问：当前还沿旧通道吗？
→ 决定 nx 当前性

第二问：只是临时优先级覆盖，还是长期终点重写？
→ 决定目标改变深度

第三问：新方向有没有扩权 / 搭结构？
→ 分别重新检查 zx / xn
```

本轮只形成两部作品的直接最小差异，不建立新的 pending-review，不修改 L1、信息卡、准度卡或补卡。
