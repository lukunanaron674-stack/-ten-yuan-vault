# 框架卡片模板 — Hermes 使用

## 格式规范
每个框架包含三部分：

```
# [主题名称]

## 大框架概述
[一句话描述这个知识域的范畴]

## 子域清单（带索引）
1.1 [子域1] — 一句话说明
1.2 [子域2] — 一句话说明
1.3 [子域3] — 一句话说明

## 原子化拆分指令（给 Trae）
每个子域拆成 3-10 张原子卡
编号规则: 子域号.序号
  例: 1.1.1, 1.1.2, 1.2.1, 1.2.2...
模板见 _bridge/原子卡模板.md
```

## 写入位置
- 框架文件: `05-银矿库/[主题名称]/框架.md`
- 通知 Trae: `07-Codex大脑库/_bridge/for_trae.md`
