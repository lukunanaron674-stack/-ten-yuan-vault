# 原子卡模板

## 核心逻辑
一张卡 = 一个不可再分的最小知识单位。

## 编号体系（三层）
- **1.0 主题级** — 整个框架
- **1.1 子域级** — 一个子领域
- **1.1.1 原子级** — 该子域下的一张卡

## 一张卡的内容（四块）

### 1. 原版概括
用最精炼的话说清楚这个概念是什么。不讲故事，不绕。

### 2. 三元分析（核心）
三个视角：

- **x（现象/表象）**：看得见的部分，公式、定义、例子
- **z（本质/结构）**：底层原理，为什么是这样
- **n（应用/连接）**：有什么用，跟别的东西怎么连

### 3. 关联概念
跟哪些其他原子卡有关系

### 4. 讨论笔记
以后你和我（桌宠）聊这个知识点时产生的记录

## YAML 头部
```
---
status: draft  # draft → finalized（讨论通过后改）
index: 1.1.1   # 与文件名一致
parent: 1.1    # 所属子域的索引
---
```
