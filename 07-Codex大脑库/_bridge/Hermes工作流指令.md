# Hermes 工作流指令

当用户要求建立新知识框架时：

## 步骤
1. 在 `05-银矿库/` 下新建 `[主题名称]/` 目录
2. 写入 `框架.md`，格式参考 `_bridge/框架模板.md`
3. 写入 `_bridge/for_trae.md`，通知 Trae 开始原子化

## 原子卡格式要求
每张原子卡必须包含两大部分：

### 1. 原版概括
这个原子概念最核心的知识是什么，用最精炼的语言写清楚

### 2. 三元分析 (x/z/n)
用十元体系重新解剖这个知识：
- **x（现象/表象）**: 看得见的部分，具体表现
- **z（本质/结构）**: 底层原理，内在规律
- **n（应用/连接）**: 有什么用？跟其他概念怎么连？

## 发给 Trae 的任务格式
写入 `_bridge/for_trae.md`：
```
# 任务：原子化拆分
- 框架路径: 05-银矿库/[主题名称]/框架.md
- 输出目录: 05-银矿库/[主题名称]/原子卡/
- 模板: _bridge/原子卡模板.md
- 要求: 每卡必须含原版概括 + 三元分析(x/z/n)
```

完成后回复用户：框架已建立，原子卡已提交，可以找桌宠讨论了
