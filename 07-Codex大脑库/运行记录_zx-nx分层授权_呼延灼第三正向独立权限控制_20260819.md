# zx↔nx 分层授权｜呼延灼作为第三正向独立权限控制

## 结论先行

本轮不重复创建呼延灼人物案例，而是复用仓库已有 99/96 `evidence-locked` 正式案例，针对当前分层授权待审议中的问题 B3 做第三部独立作品正向控制。

锁定：

> **组织上存在更高上级，不等于局部对象层仍是 `nx`。呼延灼的最高征剿方向来自高俅／朝廷，但战役内部的先锋配置、三路军马、装备分配、编军与连环马等接口已真实进入其局部统辖边界，因此该层可成立 `x`；不能因为高俅仍在上位就把整段全部写成 `nx`。**

本轮也不锁 `zx`。呼延灼是在已授局部战役边界内正常运行，没有证据显示他继续把决定范围公开推到原授权之外。

---

## 1｜剧情事实、触发、对象、动作、结果

### 触发

高俅／朝廷决定征剿梁山，要求呼延灼等回州拣选精锐军马并按期出师。

### 被测试对象层

本轮不是问“呼延灼能不能改变朝廷征剿梁山的最高战略”，而是问：

> **战役内部的先锋、军马、装备、编军、阵型与本部战役调度，是否已经进入呼延灼可直接调用的局部权限边界。**

### 明确动作

1. 高俅询问先锋人选，呼延灼直接举保韩滔、彭玘。
2. 高俅给出最高任务：回州选兵，收剿梁山。
3. 呼延灼发现甲仗不足，向高俅取得一次资源入口授权，可在京师甲仗库任意选取所需衣甲军器，并另获战马。
4. 回州后，呼延灼实际调集韩滔、彭玘所属军马前来会合。
5. 呼延灼把从京师关领的甲仗、战马等分配三军，并打造连环铁铠。
6. 出军时形成前军韩滔、中军呼延灼、后军彭玘的结构。
7. 实际交战中，呼延灼收转本部军马、下寨并持续运行连环马战役接口。

### 结果

- “打不打梁山、征剿对象是谁”仍由高俅／朝廷给定；
- 但战役内部大量人员、资源、编军和调度并不表现为每一步都回高俅逐项批准；
- 因此上位层 `nx` 与局部 `x` 可以同时成立。

## 2｜zx 证据

### 结论

`zx_in_delegated_campaign_stage: rejected_as_primary`

呼延灼领军、布连环马、让部下服从，都不能自动锁 `zx`。现行 zx 准度要求决定范围真实扩大，而本段最强结构是：

```text
上级给最高任务与合法资源入口
→ 呼延灼获得局部战役统辖
→ 在既有授权边界内持续组织运行
```

没有出现：

```text
呼延灼把战役局部权继续公开推入更高政治/战略对象层
→ 高俅或朝廷被迫承认新的呼延灼决定边界
```

所以这里是已有/已授权局部 `x` 的使用，不是新的 `zx` 扩边。

## 3｜nx 证据

### 上位战略层：成立

`nx_strategic_mission_relation_stage: evidence-locked`

“征剿梁山”由高俅／朝廷军令给定。呼延灼没有取得“是否征剿、征剿谁”的最终重设资格，因此在最高任务来源层沿外部军令推进，符合 `nx` 关系位置。

### 局部战役层：不能因为高俅还在上面继续判 nx

呼延灼对战役内部对象存在真实、持续的直接调用：举先锋、调兵、分装备、编三军、运行连环马、收军下寨。

因此沿用原正式案例：

`x_local_campaign_command_neighbor: evidence-locked`

这正是本轮作为 B3 正向控制的核心。

---

## 4｜关键压力

本轮的压力不是生死危险，而是**权限层级同时存在**：

```text
最高战略方向：外部
战役合法性与初始资源入口：外部
战役内部持续统辖：主体
运行组织方式：主体高显影
```

如果只问“上面还有没有高俅”，会误把全部对象层写成 `nx`。

真正需要问：

> **在当前具体对象层，决定是否仍需逐项回上级批准，还是已经进入主体可持续直接调用的边界？**

---

## 5｜拿掉测试

### 拿掉高俅的具体身份

只保留“更高上级给总体军事任务”，而主体对战役内部人员、资源与调度可持续直接调用，仍得到：

`上位 nx + 局部 x`

### 拿掉呼延灼的名将身份和武力

只保留局部接口的实际调用，结论不变。说明不是身份或战力直判。

### 拿掉局部直接调用

若先锋、三军、装备、阵型、收军下寨都必须逐项回高俅批准，则局部 `x` 会显著下降，转向宝钗式或纯代理式 `nx`。

### 拿掉战役胜负

即使呼延灼最后战败，只要局部权限归属与调用结构不变，分类不变。

## 6｜反向测试

### 反向成更深 nx

```text
高俅给最高目标
+ 连先锋、分兵、装备、阵型、进退都逐项规定
+ 呼延灼只能照办
```

则局部 `x/xn` 明显下降，`nx` 覆盖更深。

### 反向成更强 x 证据

若文本进一步出现：

```text
韩滔或彭玘明确拒绝呼延灼的战役命令
→ 呼延灼无需回高俅
→ 可直接处分并让结果生效
```

则会达到与诸葛亮斩马谡更接近的“冲突后独立生效”强证据。

### 反向成 zx

若呼延灼取得局部统辖后，继续公开夺取原属高俅／朝廷的更高战略处分权，并让上级体系承认该新增边界，才重新检查 `zx`。

## 7｜最近邻排除

### nx vs x

```text
最高征剿方向是谁给？ → 高俅／朝廷 → nx
战役内部对象谁能持续直接调用？ → 呼延灼 → x
```

### x vs zx

```text
x：局部权限已经进入我当前调用边界。
zx：我继续公开把决定边界向原授权之外推大。
```

本段只有前者。

### nx vs xn

呼延灼主动配置先锋、兵马、装备与阵型，`xn` 明显高显影；但 `xn` 回答“怎么组织战役”，不能抹掉上位战略方向外置的 `nx`，也不能替代局部调用权归属的 `x`。

## 8｜第三因素冻结

冻结以下因素：

- 呼延灼名将身份；
- 呼延赞后裔身份；
- 连环马是否厉害；
- 官军／梁山善恶评价；
- 最终胜负；
- 高俅奸臣评价；
- 呼延灼后来是否上梁山。

只保留：

```text
最高任务谁给？
局部对象谁能实际调用？
是否需要逐项回上级批准？
是否把权限继续推过原边界？
```

结论不变。

## 9｜三作品正向控制

### 三国演义｜诸葛亮斩马谡

```text
更高上级刘禅仍存在
+ 冲突/求情窗口真实出现
+ 局部军法处分直接生效
= 强冲突型局部 x
```

### 西游记｜孙悟空弼马温

```text
更高上级玉帝仍存在
+ 御马监人员/事务/天马持续直接管理
= 持续运行型局部 x
```

### 水浒传｜呼延灼征梁山

```text
更高上级高俅／朝廷仍存在
+ 战役内部先锋/兵马/装备/编军/阵型持续直接调度
= 战役统辖型局部 x
```

三部独立作品共同支持：

> **“组织上仍有更高上级”不是局部 `nx` 的充分条件。被测试对象已经进入主体可独立/持续调用的实际边界时，该局部层可成立 `x`。**

同时保留证据强度等级：

```text
冲突后仍可独立生效
>
持续、明确、反复直接调用
>
单纯职位/头衔/名位
```

呼延灼本例属于第二档，不伪装成与诸葛亮同强度的冲突处分证据。
