# 运行记录｜李逵江州劫法场｜外部司法处分在场但非 nx 第二控制

## 1｜本轮为什么重测这个桥段

已有正式案例已经 99/98 锁定：李逵江州劫法场是“自身权能公开介入并改写处决结果”的纯 zx 当前状态正例，本轮不重复制造“李逵 = zx”这一结论。

本轮只抽取一个新的窄变量：

> **关键对象与关键处分权明明都在外部，是否就必须计 nx？**

这是对 2026-08-25《西游记》孙悟空幽冥强取生死簿单例边界的第二部独立作品复验。

## 2｜剧情事实、触发、对象、动作、结果

### 事实

江州府已经完成宋江、戴宗的死刑文书、法场布置与执行准备；二人被押入法场，刽子手、土兵、监斩官构成现实司法处分链。处决进入最后执行窗口时，李逵从人群/茶坊方向公开冲入法场，以双斧攻击执行者并冲击监斩节点；梁山众人同时发动救援，宋江、戴宗最终被救出。

### 触发

```text
外部司法系统已把宋江、戴宗推进到公开死刑执行窗口。
```

### 对象

- 宋江、戴宗当前人身控制；
- 刽子手与法场护卫；
- 监斩官所代表的处决执行接口；
- “按既定判决完成处决”这一当前结果对象。

### 李逵的明确动作

- 公开冲入法场；
- 直接砍倒/逼退执行者；
- 冲击监斩节点；
- 不请求赦免、不等待批准、不承认该司法接口为必须经过的解决通道；
- 以自身强制作用使既有处决链无法继续。

### 结果

```text
处决执行被中断
→ 原司法执行节点失去维持当前结果的能力
→ 宋江、戴宗脱离原处决链
→ 现场现实方向从“完成处决”改写为“救出并突围”
```

## 3｜样本类型

本轮锁定：

```text
纯 zx 当前状态：沿用既有 99/98 正例
当前 nx：rejected
外部对象/处分接口在场但非 nx：第二独立作品 evidence-locked 控制
严格 zx↔nx 补：不锁
稳定人物本体：不锁
```

本轮不是新增“强烈反抗 = zx”规则，而是新增对 nx 的排除控制。

## 4｜zx 证据

沿用既有正式案例，不重复扩写：

1. 李逵自身作用力直接进入公开处决现场；
2. 执行者、护卫与监斩节点被迫回应；
3. 原处决方向现实失效；
4. 李逵由外部行动者成为现场突破作用来源之一；
5. 这不是既有司法权限的正常调用，因此不是普通 x。

所以当前 zx 仍为高显影。

## 5｜为什么“外部对象在场”不能推出 nx

这里确实存在最强版本的外部性：

```text
人身控制在江州府
死刑文书在江州府
执行许可在监斩系统
刽子手与护卫在江州府
```

但 nx 还要求：主体**真实沿这个外部方向、权限或解决通道续接**。

李逵没有做任何下列行为：

- 向知府、监斩官或上级官府申请赦免；
- 等待司法节点批准后放人；
- 承认“只有外部节点同意，救人结果才可生效”；
- 借司法关系、身份或许可网络完成同一结果。

相反：

```text
外部处分接口存在
→ 主体不沿用
→ 主体公开攻击执行接口
→ 原接口的否决/处分能力在当前现场被强制压掉
→ 结果由主体一侧的强制作用改写
```

因此，本轮 `nx = rejected`。

## 6｜与孙悟空生死簿控制的最小同型

### 《西游记》孙悟空

```text
生死簿原在阴司外部
→ 悟空不申请正常修改
→ 强取簿册并亲自勾改
→ 阴司原处分节点无法维持旧结果
= 外部对象在场，但当前非 nx
```

### 《水浒传》李逵

```text
宋江/戴宗人身与死刑执行原在江州司法系统
→ 李逵不申请赦免/放行
→ 直接攻击执行链并强制中断
→ 原司法节点无法维持旧结果
= 外部对象/处分接口在场，但当前非 nx
```

两例对象不同：一个是生死名录处分，一个是现实刑罚与人身控制；共同变量却一致：

> **关键对象原本在外部，不等于主体必须通过外部接口才能改变同一结果。若主体直接压掉原持有者的当前否决/处分能力，使结果转由自身强制作用改写，外部性本身不能计 nx。**

## 7｜最近邻排除

### nx vs zx

- nx：承认并沿外部许可/资源/关系接口推进；
- 本例：公开中断外部处分接口，使它不能继续决定结果；
- 因此当前偏 zx，而非 nx。

### nx vs x

李逵并未长期取得江州司法处分权，也没有把法场变成稳定自有制度资源；所以不能把整个现场后续都写成 x。这里只能说旧司法接口在当前执行窗口被强制失效，结果被改写。

### nx vs xn

梁山整体救援含有吴用等人的计划、伪装、时机与协同，属于团队层 xn 污染。冻结这些设计，只保留李逵个人“直接攻击执行链并中断处决”，本轮 nx 排除仍成立。

### 普通战斗

不是“能打 = 非 nx”。若李逵虽然攻击，却仍必须等待某个外部司法节点最终批准放人，同一结果仍需外部接口，则可存在 nx。事实不是如此。

## 8｜拿掉测试

### 拿掉“外部对象在场”这个表面条件

若只看李逵直接破坏处决接口，zx 结构仍成立；说明“对象/人身/文书在外部”不是 nx 的充分条件。

### 拿掉“外部许可/关系续接”

原著本来就没有这条续接，救援链仍实际发生，说明当前结果不依赖司法许可 nx。

### 拿掉李逵自身强制作用

若冻结李逵个人冲入法场、攻击执行者，只剩“司法系统掌握人身与处分”，并不能推出“李逵沿它推进”；只能说明外部控制存在，不能自动生成 nx。

## 9｜反向测试

### 反向成 nx

若李逵改为：

```text
找到知府/上级司法节点
→ 请求赦免或调取公文
→ 外部节点保留真实否决权
→ 获批后才放人
```

则同一“救出宋江戴宗”结果明显进入 nx 权限通道。

### 反向成伪 zx

若李逵冲击法场却被压回，处决继续完成，原司法节点仍保持最终处分结果，则只能是强烈反抗，不能锁当前 zx。

## 10｜第三因素冻结

冻结：

- 李逵“黑旋风”身份；
- 武力强弱与杀伤数量；
- 忠义主题；
- 晁盖/吴用智谋；
- 宋江人物重要性；
- 后续梁山历史。

只保留：

```text
外部处分接口当前是否真实存在？是。
主体是否沿它请求/借用/续接？否。
主体是否直接压掉其当前执行能力？是。
同一结果是否因此被改写？是。
```

结论不变。

## 11｜人物分层

- 稳定人物本体：本轮不锁。
- 当前状态：zx 高显影，沿用既有正式案例。
- 行为功能：公开中断外部处决执行链。
- 关系位置：不承认江州司法节点为救人结果必须经过的许可端。
- 外部压力：终局处决已进入执行窗口。
- nx：当前窄对象层排除。
