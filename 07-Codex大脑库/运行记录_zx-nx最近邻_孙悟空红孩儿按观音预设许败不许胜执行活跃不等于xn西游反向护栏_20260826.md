# 运行记录｜孙悟空红孩儿：按观音预设“许败不许胜”执行，活跃不等于 xn

## 0｜本轮测试问题

现有 pending-review 已跨《三国演义》《红楼梦》《水浒传》形成：

```text
上位任务 / 授权由外部给出并承接 = nx
局部人员、节点、时序、流程由主体自己重组 = xn
```

本轮专门寻找《西游记》反向护栏：**主体看起来非常忙、会打、会执行，但关键运行节点其实由外部方案预设时，不能只凭动作活跃把局部执行误判为 xn。**

## 1｜剧情事实

《西游记》第42回红孩儿段：

1. 孙悟空此前正面斗红孩儿、借四海龙王雨水均未解决三昧真火问题，之后去南海请观音。
2. 观音完成收伏场布置后，明确在悟空手心写“迷”字，并给出具体执行指令：去索战，**许败不许胜**；败退到观音跟前，由观音收伏红孩儿。
3. 悟空“领命”返回火云洞，叫阵、破门，引红孩儿出战。
4. 悟空按设定完成战斗与败退，把红孩儿引到观音预设的收伏场。
5. 红孩儿进入观音的陷阱后，核心收伏由观音预设的法力与法器完成。

原文关键因果链：

```text
观音预设战术节点
→ 悟空领命
→ 索战
→ 许败不许胜
→ 败回观音前
→ 红孩儿进入预设收伏场
```

## 2｜对象层拆分

### 上位人物目标层

悟空“救唐僧 / 解决红孩儿”并不是观音替他生成，人物稳定 zx 锚与救师方向不在本轮重判。

### 当前战术子任务层

本轮只测：**“怎样把红孩儿导入观音收伏场”**。

这个子任务的关键运行节点不是悟空自己重新设计，而是观音明确预设：

```text
去索战
→ 不许胜
→ 必须败
→ 败回我这里
```

悟空真实承接并沿该方案执行，因此当前战术子任务优先判 nx。

## 3｜nx 证据

当前战术子任务中：

- 解决通道已由观音建立；
- 关键胜负方向被外部明确规定为“许败不许胜”；
- 关键终点节点被外部规定为“败将来我这跟前”；
- 悟空明确“领命”；
- 实际执行沿该外部方案推进。

符合 nx 正本：方向、权限或解决通道已存在，主体不占当前子任务最终决定位置，沿外部安排继续行动。

## 4｜xn 证据与排除

悟空执行时确实非常活跃：叫阵、破门、交战、诱敌。

但动作多、临场反应多，不等于 xn。要锁 xn，必须看到主体主动重组人员、资源、节点、时序或流程，使任务按自己搭出的运行骨架持续推进。

本例核心节点已经被观音写死：

```text
索战
→ 必须败
→ 败回指定位置
```

悟空破门只是为使红孩儿进入既定索战节点的局部动作，没有改写核心运行骨架，也没有自行替换关键终点。

因此：

```text
当前战术子任务 xn：不足以独立成立
活跃执行：不能作为 xn 充分证据
```

## 5｜zx 检查

本轮不把“叫阵、破门、交战”直接算 zx。

原因：当前子任务的胜负方向和落点由观音方案控制；悟空没有在这一子任务中把决定范围推进到观音预设之外。人物稳定 zx 与更高层救师方向另有既有材料，不从本轮战术执行倒推。

所以：

```text
稳定人物 zx：沿用既有锚，不在本轮重锁
当前战术子任务 zx：不以本轮执行动作单独成立
```

## 6｜拿掉测试

### 拿掉观音预设方案

若去掉“许败不许胜 / 败回我前”的明确指令：

- 悟空仍可主动战斗；
- 但原著这条指定诱敌链失去外部运行骨架；
- 此时才需要重新检查悟空是否自行搭出新的节点与时序，从而使 xn 上升。

因此当前 nx 不是表面命令，而是对子任务结构有实质约束。

### 拿掉悟空的高动作量

如果悟空仍按同一预设节点执行，只是动作更简单：

```text
索战 → 故意败退 → 引到观音前
```

当前 nx 核心仍完整。

说明“打得多、动作多、临场叫骂”不是 xn 必要条件。

## 7｜反向测试

如果改写为：

```text
观音只说“把红孩儿引来”
→ 悟空自己选择诱敌对象、时间、路线、真假胜负、伏击节点
→ 自行搭完整运行骨架
```

则局部 xn 明显上升。

如果观音进一步逐项规定连破门、交战时长、退路线、终点等细节，则更接近纯任务 nx。

原著位于两者之间，但核心关键节点由观音预设，悟空的局部动作不足以独立锁 xn，因此作为“活跃执行 ≠ xn”的反向护栏成立。

## 8｜最近邻排除

### nx vs xn

```text
别人预设关键运行节点，我沿着做
= nx 优先

我主动重组关键节点、时序与流程
= xn 上升
```

不能把“执行复杂”写成“运行骨架由我建立”。

### nx vs x

观音的收伏法力、法器与最终处分能力没有进入悟空稳定调用边界，因此不是 x。

### xn vs zx

会诱敌、会战斗、会临场处理，不等于公开扩权；zx 仍需另证决定范围扩大。

## 9｜第三因素冻结

冻结：

- 悟空能不能打；
- 红孩儿强弱；
- 观音地位；
- 主角身份；
- 最终收伏成功。

保留：

```text
关键运行节点是谁设计？
主体是否真实承接？
主体有没有重组核心节点？
高动作量是否只是执行既定骨架？
```

结论不变。
