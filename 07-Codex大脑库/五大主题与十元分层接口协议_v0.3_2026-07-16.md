# 五大主题与十元分层接口协议 v0.3

## 1. 正式迁移

```text
Legacy（旧十元表达）

n 补克 nx

↓

Current（正式主题表达）

因果克制空间
```

旧表达停止作为现行十元关系、人物判定或动态链结论使用，仅允许在迁移说明中出现。

“因果克制空间”属于五大主题形成后的主题级克制关系，不自动等于某一条固定十元关系。

## 2. 关系层的 z、n、x

```text
z = 补 / 补合
n = 生 / 生发
x = 克 / 克制
```

这里的 `z / n / x` 位于关系层，用于描述关系功能：

```text
z：把双方补合为一个更高层次整体
n：一个主题生发另一个主题
x：一个主题克制另一个主题
```

这套关系功能不把三元写成十元的父级，也不表示十元由三元机械派生。

三元与十元仍然并行判断，不得由一方唯一反推另一方。

## 3. 十元构成区与关系区必须分开读取

同一个字母出现在不同区域，不代表它们是同一个对象，也不构成记号冲突。

### 十元构成区

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

在这些公式中：

```text
xn、z、zn、x、x并z、n、zx、nx、xz、nz
全部是十元点位。
```

因此：

```text
时间 = xn + z
```

其中的 `z` 明确是十元中的 `z`，是时间主题的十元构成成员。

### 五大主题关系区

```text
z = 补合关系
n = 生发关系
x = 克制关系
```

这里的 `z` 是关系功能，不是“时间公式中的十元 z”。

最短判读规则：

```text
先看所在区域，再读字母含义。

十元构成公式中的 z
→ 十元点位 z

五大主题形成或关系说明中的 z
→ 补合关系 z
```

不需要给两者另造新符号，也不得因为同字母就把两个区域混成同一层。

## 4. 五大主题的形成机制

五大主题不是两个十元标签的普通相加，也不是把十元改名成主题。

正式顺序为：

```text
十元构成双方分别成立
↓
在五大主题关系区，由 z 补合双方
↓
形成更高层次的主题符号
↓
主题成立以后，再观察主题之间的 n 生与 x 克
```

例如时间主题：

```text
十元构成区：xn + z

其中：
xn = 十元 xn
z = 十元 z

五大主题关系区：
关系层 z 补合上述两个十元成员
↓
形成“时间”主题
```

这里没有“z 吞掉 z”的问题，因为前者属于关系区，后者属于十元构成区。

“五大主题像五行一样只有生克”，指的是主题形成以后，主题与主题之间主要观察 n 生与 x 克；不表示关系层 z 被排除，也不表示补合没有作用。

## 5. 主题公式的正确读法

主题公式中的 `+` 用于标记十元构成双方与位置，不是普通算术加法，也不是关系层 `z` 的替代符号。

正确顺序：

1. 在十元构成区分别判断双方是否成立；
2. 在五大主题关系区判断双方是否被 z 补合为完整主题；
3. 主题成立后进入五大主题生克盘；
4. 用十元和动态链解释人物、状态、行为、场景、时间结构如何实现主题关系。

禁止跳步：

```text
看到主题名称
→ 倒推固定十元对子

看到两个十元标签
→ 不经关系层补合直接宣布主题成立

看到关系层 z
→ 把它误判成十元构成中的 z

看到主题级生克
→ 改写人物稳定本体
```

## 6. 五大主题与十元并行协作

```text
五大主题：
负责高级归类、主题重心与主题级生克。

十元：
负责具体人物、状态、行为、场景、时间结构与实现机制。

动态链：
负责具体对象之间怎样生、克、补，以及不同阶段怎样显影、退隐和转位。

三元：
提供高概括的关系与结构判断，与十元并行，不构成父子派生。
```

工作原则：

```text
五大主题很好归类。
十元很好具体化。
动态链很好描述过程。
三元提供高概括判断。
四者共同分析，但不互相替代。
```

## 7. 因果克制空间的分层表达

```text
十元构成区：
因果：zx + nx
空间：x并z + n

五大主题形成：
关系层 z 补合因果双方，形成“因果”。
关系层 z 补合空间双方，形成“空间”。

主题关系区：
因果 x 空间
即：因果克制空间。
```

具体案例仍必须分别判断：

```text
人物稳定本体
当前人物状态
关键行为功能
外部场景
时间关系 / 时间结构
视觉与光影
十元构成双方
主题级生克
具体十元动态链
保持不变的人物核心锚点
```

不能从“因果克制空间”直接倒推出固定十元关系，也不能用场景、光影、职业、道具或一次行为改写人物本体。

## 9. 当前冻结结论

```text
关系层：z = 补，n = 生，x = 克。

十元构成公式中的 z：是十元点位 z。
五大主题形成说明中的 z：是关系层补合功能。
两个区域同字母，不是同一个对象，不构成记号冲突。

五大主题由关系层 z 补合十元构成双方，形成高级符号。
五大主题成立以后，主题之间主要观察 n 生与 x 克。

正式主题关系：因果克制空间。
旧表达 n补克nx：停止作为现行关系使用。

五大主题负责高级归类。
十元负责具体化。
动态链负责阶段过程。
三元与十元并行，不是父子派生。
人物核心锚点优先稳定。
```

## 10. 尚未锁死的问题

以下问题不能从本轮区域区分自动推出：

```text
五大主题完整生环与克环的全部方向。
每个主题公式的十元双方是否都已通过现行语义复验。
同一主题能否存在多组十元构成变体，以及变体边界。
关系层 z 补合成立的最低判据与失败判据。
```
