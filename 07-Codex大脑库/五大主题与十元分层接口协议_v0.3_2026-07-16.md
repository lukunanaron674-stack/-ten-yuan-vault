# 五大主题与十元分层接口协议 v0.3（已退役）

现行正本：

```text
07-Codex大脑库/五大主题与十元分层接口协议_v0.4_2026-07-16.md
```

退役原因：v0.3 仍把五大主题生成写得像“案例中两个十元先同时成立，再被 z 补合”。

现行修正：

```text
两个十元同时出现
→ 只在十元层发生互补、生、克或并列
→ 不自动生成五大主题

五大主题生成
→ 属于另一套专门解决主题的系统
→ 由主题生成系统统一 z 补合预设十元构成双方
→ 形成高级主题符号
```

同时，五大主题正式生克盘已经锁定：

```text
生环：空间 → 时间 → 命运 → 因果 → 本体 → 空间
克环：空间 → 命运 → 本体 → 时间 → 因果 → 空间
```

其余现行规则均以 v0.4 为准。
