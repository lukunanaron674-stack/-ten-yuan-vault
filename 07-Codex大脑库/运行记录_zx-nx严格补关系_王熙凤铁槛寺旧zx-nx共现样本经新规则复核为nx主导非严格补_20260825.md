# 运行记录｜王熙凤铁槛寺旧 zx-nx 共现样本复核

## 0｜本轮目的

旧案已经 99/97 锁定：王熙凤有自己的目标与操盘意图，但真正改变长安守备退亲结果的关键权限在贾府—云光—守备这一外部权势链；因此本桥段的高纯木轴证据是 `nx` 关系功能，而不是“凤姐强势所以 zx”。

本轮不重复制造案例，只用现行 L1 与 `zx补nx_补卡` 重新检查：

> 这类“主体自己定目标 + 借外部权势链办成”的桥段，能否因为 `zx` 与 `nx` 在描述上同时出现，就进入严格 `zx↔nx` 补？

结论：不能。

## 1｜剧情事实

触发：静虚请求王熙凤插手张家退亲纠纷。

对象：长安守备是否退婚，以及谁拥有真正改变该结果的现实影响接口。

明确动作：

```text
静虚提供关系入口
→ 王熙凤决定接手
→ 命来旺儿办信
→ 假托贾琏名义
→ 通过贾府与云光旧关系
→ 云光再影响长安守备
```

结果：退亲纠纷沿既有权势网络被改变。

## 2｜zx 判断

本轮仍不锁高纯 `zx`。

支持 zx 的表面因素包括：

- 王熙凤自己决定接手；
- 主动调动下人；
- 敢把手伸到长安县事务；
- 结果体现贾府势力外溢。

但这些不足以满足现行 zx 高纯门槛。真正穿过权限边界的关键动作不是王熙凤以自身公开权能直接迫使守备围绕她本人重排，而是：

```text
假托贾琏
+ 调用贾府旧情
+ 经云光中转
+ 由云光影响守备
```

因此当前桥段最多有 `x/xn` 邻近：王熙凤可调下人、组织书信步骤，但不能把“幕后操盘成功”偷换成高纯 zx。

## 3｜nx 判断

`nx` 关系功能高纯成立。

关键权限不在王熙凤本人手里；她不能直接处分长安守备家的婚约立场。现实结果必须通过既有关系与外部权势接口推进：

```text
贾府旧关系
→ 云光
→ 长安守备
```

这符合 L1 木轴阴端：主体不占该对象层的最终作用权来源，而沿既有关系／权限通道续接。

本轮锁的是行为功能与关系位置，不外推稳定人物本体。

## 4｜关键压力

压力变量只有一个：

> 长安守备的退亲处分不在王熙凤直接稳定调用边界内。

冻结王熙凤“狠、贪、强、能办事”等性格标签，压力仍然存在；只有接入外部权限链，原目标才可继续推进。

## 5｜拿掉测试

### 拿掉 nx

拿掉云光或等价外部权限接口，同时不赋予王熙凤新的直接处分权：

```text
王熙凤仍想办成
→ 目标与主动性仍在
→ 但原权限链断裂
→ 原结果不能按同一路径稳定落地
```

说明 `nx` 对结果有真实不可替代作用。

### 拿掉所谓 zx

把王熙凤的“强势、敢接事、个人主见”降到最低，只保留她愿意接受静虚请托并沿贾府—云光—守备关系通道推进：

`nx` 核心机制仍成立。

而且云光作为外部权限节点的核心功能并不会因为王熙凤缺少高显影 zx 就失去自身权限。

因此无法证明：

```text
拿掉 zx
→ nx 留下只能由 zx 补回的不可替代缺口
```

严格双向补失败。

## 6｜反向测试

若改写为：

```text
王熙凤本人公开拥有或夺得对守备的直接处分权
→ 不借贾琏名义
→ 不经云光
→ 直接迫使守备改结果
```

才会明显向 `zx` 上升，同时 `nx` 下降。

若改写为：

```text
王熙凤的公开 zx 已独立成立
→ 但当前被某一外部专属权限卡住
→ nx 接口解除同一瓶颈
→ 反过来 nx 端自身也缺王熙凤 zx 才能完成核心功能
```

才有资格继续查严格 `zx↔nx` 补。

原桥段不满足。

## 7｜最近邻排除

- `nx vs xn`：送信、人员、时序可有 xn，但“为什么必须经过云光”仍是 nx。
- `nx vs x`：王熙凤能直接调用来旺儿属于局部 x；云光／守备权限不属于她的稳定 x。
- `nx vs zx`：主动、有主见、幕后操盘成功都不是 zx 充分条件；缺少自身公开显权并扩大该对象层决定范围。
- `共现 vs 严格补`：描述中同时能谈到主动目标与关系借力，不等于两端已经分别独立成立，更不等于双向补缺。

## 8｜第三因素冻结

冻结：

- 三千两银子；
- “弄权”回目标题；
- 凤姐性格评价；
- 贾府整体权势印象；
- 后续悲剧；
- 道德判断。

只保留：

```text
谁决定目标
谁掌握直接权限
主体是否真实沿外部接口
zx 是否独立达到门槛
拿掉任一端是否形成双向不可替代缺口
```

结论不变。

## 9｜结论

```yaml
pure_zx: false
pure_nx: false
zx_plus_nx_strict_pair: false
nx_function_high_manifestation: true
x_neighbor: true
xn_neighbor: true
strict_complement: false
```

最短判别句：

> **自己定目标 + 借外部权势链办成，不等于 `zx+nx` 严格对子。先分别锁两端；若 zx 本身没有独立过门，或拿掉 zx 后 nx 仍能保持核心权限功能，则最多是 nx 主导的关系借力，不得升级成严格补。**

## 10｜资产意义

这条复核用于约束早期“权限借力”样本的使用方式：

- 可以继续作为 `nx` 关系功能高纯正例；
- 可以作为“主动主体也可高显影 nx”的反例；
- 不得作为严格 `zx↔nx` 补正例；
- 不据此修改 L1、zx/nx 信息卡、准度卡或补卡。

后续若要测试严格补，优先选择两端都能独立锁定、并直接咬住同一现实瓶颈的桥段。
