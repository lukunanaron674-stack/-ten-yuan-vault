## 端点与被改变变量

### 源端点 `nz`

必须先有真实共同时间、关系余温与不愿让关系以断裂结束的需要。善良、愧疚、一次心软、家庭题材与普通赠礼均不够。

### 目标端点 `x`

必须已有明确掌握：对象、资源、权限、地盘或关系由主体占有、调用、排除、否决或划界。

### 被改变变量

- 独占程度；
- 排除权；
- 否决与调用边界；
- 私人掌握是否改成共享、归还或开放；
- 关系对象是否仍被当作可控制对象。

### 成立阶段

```text
x 掌握边界先成立
→ nz 的关系保留需要显影
→ 主体发现继续独占会让关系真正结束
→ 主体主动缩小、开放或归还掌握边界
```

### 体量与显影条件

- 低体量：一次暂缓否决、允许共享；
- 中体量：持续开放资源、权限或关系位置；
- 高体量：重新定义“归我”，将私人对象转为关系共有或可归还。

显影必须是掌握者主动改变边界，而非被法院、暴力、破产、制度或交易迫使。

## 候选机制

### 候选A：关系保留压缩独占

```text

→ 意识到继续坚持“只能归我”会切断关系
→ 主动放松排除权、否决权或独占调用
→ x 下降
```

理论后果：若成立，`nz` 克制的是掌握强度，不要求所有权消失。

### 候选B：对象由私人掌握重分类为关系共有

```text
对象原本处于私人掌握边界
→ 长期关系使对象承载共同时间与双方位置
→ 主体不再只把对象当“我的东西”
→ 对象进入共享、归还或共同记忆边界
→ x 下降
```

理论后果：目标变量是归属边界重写，而不是情绪感动。

### 排除候选：因爱牺牲或普通赠与

```text

→ 给钱、给房、给机会
```

不足以证明本关系，可能实际由 `zn` 的道德判断、`nx` 的让位、交易、遗嘱流程或剧情任务启动。

- 与 `zx`：外部主体强迫交出对象或权限，不是 `nz`。
- 与反向 `x克nz`：掌握先收紧、关系余温和自愿停靠后下降，方向相反。
- 与普通共享：没有“不这样关系会真正结束”的关系保留压力，不足以判克制。

## 拿掉测试

1. 拿掉关系保留需要，若主体仍因道德、法律、利益或任务开放边界，则不依赖 `nz`。
2. 拿掉已成立的独占、调用或否决权，只剩普通赠礼，则目标端点不存在。
3. 拿掉外部强制，主体仍主动缩小边界，才支持正向关系。
4. 拿掉关系断裂风险，主体仍照样让渡，可能是稳定 `zn`、`nx` 或交易。
5. 恢复主体完整掌握后，关系若仍能保持同等余温，说明掌握变化不是关系必要条件。
