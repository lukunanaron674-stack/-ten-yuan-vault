# 运行记录｜孙策质玺借兵按当前正本补卡复核恢复严格 zx↔nx 补

## 0｜结论

第十五回“孙策已有取江东方向 → 直属启动兵力不足 → 以玉玺作质向袁术请求 → 袁术借兵三千、马五百 → 孙策立即渡江扩张”的初始窗口，按当前 `canonical-current-card`《zx补nx_补卡 v0.1》重新裁决：

```yaml
zx: true
nx: true
nx_to_zx_gap_filling: true
zx_to_nx_landing_power_gap_filling: true
strict_zx_nx_complement_locked: true
```

2026-08-25 将本例降为“仅 nx→zx 单向补”的记录，使用了比 canonical 更严的候选门——要求拿掉 zx 后必须损伤 nx 自身资源处分能力。该门不在当前正本中，不能越级覆盖 canonical，因此本轮 supersede 该降级子结论。

## 1｜剧情事实、触发、对象、动作、结果

### 触发

孙策不愿久困袁术之下，想继父志、救母舅并图取江东，但缺足够直属启动兵力。吕范明确担心袁术不肯借兵；孙策提出以传国玉玺作质。

### 对象

- A：孙策自己占据的江东扩张方向。
- B：袁术掌握的三千兵、五百马外部调用权。
- C：玉玺，作为激活 B 接口的交换/质押条件。

### 动作与结果

袁术见玉玺后同意借兵三千、马五百，并给军职；孙策取得资源后立即领兵渡江，招将、扩军、取地，把外部条件兑现成公开军事行动和现实扩张。

第十七回袁术反向向孙策借兵，孙策可以拒绝并自行点军守江口，说明后续旧 B 已逐渐内化为孙策稳定 `x`，不能把初始 nx 永久挂到后续阶段。

## 2｜zx 判定

`zx` 独立成立。

不是因为孙策勇猛或胜利，而是：江东扩张最终方向由孙策自己占据；取得条件后由其自身军政权能公开推进；外部地盘、将领与军事秩序围绕其行动响应；现实作用范围持续扩大。

### 最近邻排除

- `x`：已有少量旧部调用只能解释局部已有资源，不能解释新的公开扩张范围。
- `xn`：质押设计、招将、分兵、路线组织可有 xn，但不是“最终方向与公开作用权来源”的主判。

## 3｜nx 判定

兵马资源层 `nx` 独立成立：三千兵、五百马仍在袁术处分范围；孙策不能自行调走；必须提出请求并满足质押条件；袁术保留真实批准/拒绝权；批准后资源才转移。

### nx vs xn

“用玉玺作质”是孙策主动组织的取得资源方案，可有 `xn` 邻近；但“兵马最终能否交付”仍由袁术外部接口决定，所以 xn 不能抹掉 nx。

### nx vs x

借出以前，兵马不在孙策稳定直接调用边界；江东扩张后逐渐进入孙策持续统辖，才转查 `x`。

## 4｜关键压力 / 现实瓶颈

```text
孙策 zx 江东方向已经存在
+
直属启动军力不足
```

袁术兵马接口直接解除这个现实启动瓶颈。

## 5｜拿掉测试

### 拿掉 nx

去掉袁术兵马且不给等价外部军力：孙策江东方向仍成立，但启动兵力出现明确、可命名缺口。因此 `nx → zx` 成立。

### 拿掉 zx

保留袁术兵马、许可与玉玺交易路径，但去掉孙策把借入条件转换成公开江东行动的 `zx` 落地权能：外部路径仍存在，却不会自行生成孙策的渡江、招将、扩军、取地与现实结果推进。

这正对应当前 canonical 补卡对 `zx补nx` 的明文定义：

> zx 把借到的资源、关系与通道重新转成实际行动、公开决定和结果推进，改变 nx 单独运行时“有路径却缺落地权能”的缺口。

因此按当前正本，`zx → nx` 反向补缺通过。

## 6｜第三因素冻结：玉玺为什么不破坏严格补

玉玺是“袁术为什么愿意开放兵马接口”的激活/交换条件，它可以解释 B 接口为何本轮被打开，但它不替代两端在同一扩张瓶颈中的功能：

- 冻结玉玺的特殊诱因，只要仍保留一个等价、真实可开放的袁术兵马接口，`nx` 仍提供外部启动军力；
- 该外部军力仍必须由孙策 `zx` 兑现成公开江东扩张结果；
- 玉玺不能自己把三千兵、五百马变成孙策的江东军政现实。

因此玉玺不能作为“第三因素制造伪双向补”的充分证据。此前把“袁术想要玉玺”与“zx 对 nx 的落地权能补缺”混成同一反向变量，是对象层错位。

有效第三因素冻结仍不得删除：孙策江东方向、启动军力不足、袁术外部兵马接口或“把外部条件兑现成现实”的测试对象，否则只是删题。

## 7｜反向测试

若孙策拿到兵马后不具备任何公开行动与兑现能力，兵马只停留为外部给出的资源条件，则 `nx` 路径存在而现实扩张不落地；这正是 canonical 所命名的反向缺口。

若袁术兵马本来已归孙策稳定调用，则 nx 端消失，不构成本轮严格补。

## 8｜稳定本体 / 当前状态 / 关系位置

- 稳定人物本体：本轮不锁。
- 当前状态：孙策 `zx` 高显影。
- 关系功能：袁术兵马接口 `nx` 高显影。
- 局部行为功能：质押与后续军事组织有 `xn` 邻近。
- 后续转态：外部兵马逐渐内化为孙策 `x`，旧 nx 当前窗口关闭。

## 9｜最终结论

当前 canonical 下，本例恢复为高纯严格 `zx↔nx` 补正例；同时保留“严格补有时间窗口、外部 nx 资源可内化为 x、历史来源不等于当前接口”的旧成果。
