# 第二大腦的MOC结构

## 来源

Tiago Forte《第二大腦》（Building a Second Brain）

## 核心概念：MOC (Map of Content)

MOC 不是传统的文件夹层级，而是**动态的内容地图**：
- 一个 MOC 是一篇笔记，里面用 [[wikilink]] 链接到相关笔记
- 同一篇笔记可以出现在多个 MOC 中
- MOC 可以随时重组，不改变底下的原子笔记

## 与 ten-yuan-vault 的对照

当前 vault 已经在用 MOC 模式：

| MOC | 位置 |
|---|---|
| 总入口 | `00-中枢索引/总入口.md` |
| 角色库总索引 | `05-银矿库/角色库/角色库总索引.md` |
| 待二审散点池索引 | `05-银矿库/00-待二审散点池/待二审散点池索引.md` |
| Codex大脑总入口 | `07-Codex大脑库/Codex大脑总入口.md` |

## 可以加强的点

- 五大主题入口（`02-五大主题/`）目前只有分类页，可以升级为真正的 MOC
- 给每个十元类型建一个 MOC，汇总理论+案例+角色
- MOC 之间可以互相链接，形成"MOC 网络"
