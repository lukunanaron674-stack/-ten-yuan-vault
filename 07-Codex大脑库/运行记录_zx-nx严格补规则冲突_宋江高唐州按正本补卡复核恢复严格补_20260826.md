# 运行记录｜宋江高唐州｜按正本补卡复核恢复严格补

## 1｜剧情事实

- 宋江持续占据“破高唐、救柴进”的公开推进方向。
- 高廉妖法真实阻断梁山普通军力，现有公开军事推进被卡住。
- 宋江不能凭自身现有军力稳定解除该专属瓶颈，因此派戴宗、李逵寻找公孙胜。
- 公孙胜本人不能擅自下山，必须经过罗真人许可；罗真人第一次拒绝后，原请援链真实停住。
- 罗真人后来改为放行并授法，公孙胜下山回到高唐州，专属破解能力进入战役。
- 该条件接入后，宋江重新传令、组织公开军力继续推进，最终破除高廉妖法、推进救援与破城。

## 2｜zx 端

宋江的 `zx` 不来自“他是梁山首领”，而来自：

```text
破高唐 / 救柴进的最终方向由宋江持续占据
→ 公开率军推进
→ 瓶颈解除后继续把军力压入现实
→ 攻城 / 救援结果继续扩大
```

因此当前 `zx` 端独立成立。

## 3｜nx 端

公孙胜专属破解能力与罗真人许可/授法不在宋江稳定直接调用边界：

```text
普通军力无法解决当前瓶颈
→ 必须寻找外部专业解决接口
→ 公孙胜又必须经过罗真人放行
→ 外部接口真实激活后才进入当前战役
```

因此当前 `nx` 端独立成立。

## 4｜拿掉测试

### 拿掉 nx

去掉公孙胜 / 罗真人这一等价外部专业解决通道，同时保留宋江公开推进方向：

```text
zx 仍成立
→ 但高廉妖法继续阻断
→ 当前战役留下明确“专属破解路径”缺口
```

所以 `nx→zx` 补缺成立。

### 拿掉 zx

保留公孙胜能力与罗真人许可/授法，但拿掉宋江当前公开军事推进端：

```text
nx 的外部专业路径仍存在
→ 但缺把该路径重新转成梁山军令、公开军事行动、攻城救援与结果推进的落地权能
```

这与当前 canonical `zx补nx_补卡` 的明文定义直接一致：

> `zx` 把借到的资源、关系与通道重新转成实际行动、公开决定和结果推进，改变 `nx` 单独运行时“有路径却缺落地权能”的缺口。

因此在**当前正本**下，`zx→nx` 也成立。

## 5｜反向测试

若改写为：

```text
公孙胜 / 罗真人接口一出现
→ 不需要宋江任何公开军令、军队组织或结果推进
→ 外部能力自行完成全部破城救援结果
```

则 `zx→nx` 会显著下降，本案不再是当前结构。

若改写为：

```text
宋江现有军力可稳定自行破解高廉妖法
```

则 `nx→zx` 会下降，外部专业通道不再是必要补缺。

## 6｜最近邻排除

- `nx vs x`：公孙胜能力与罗真人许可在接入前不属于宋江稳定直接处分边界，因此不是 `x`。
- `nx vs xn`：派人寻找、请求、回军的流程有 `xn` 邻近，但“能否获得专属破解条件”仍由外部接口决定。
- `zx vs x`：宋江对既有梁山军力的直接调用属于 `x`；本轮 `zx` 锁的是持续公开推进同一战役方向并在条件补入后把作用权兑现到新的现实结果。
- 普通合作排除：两端先独立成立，并直接作用于同一个“高廉妖法阻断当前攻城救援”的现实瓶颈。

## 7｜第三因素冻结

可冻结：宋江英雄评价、高廉善恶、柴进关系亲疏、妖法奇观、最终胜负已知。

不可把“高廉妖法造成的当前专属破解瓶颈”整体删除，否则等于删掉本轮测试对象。

冻结有效外生噪音后，`zx`、`nx`、同一现实瓶颈和双向补缺仍保留。
