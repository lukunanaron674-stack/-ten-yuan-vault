# 运行记录｜严颜巴郡 x 失去后 zn 仍持续：首份火轴生命周期控制

## 1｜本轮问题

本轮不把“太守”“忠臣”“不降”这些身份/标签直接当作火轴结论，只测试一个窄变量：

> **巴郡现实守城/军政处分 `x` 被张飞夺走以后，严颜内部的“不可因武力威逼而屈膝归降”原则 `zn` 是否仍继续进入判断？若继续，说明 `x` 失去不自动让 `zn` 消失，也能反向压力测试 strict `x→zn`。**

对象层严格限制为：

```text
x：严颜对巴郡当前守城军力、城门与防御行动的现实调配/处分边界
zn：面对敌军武力与死亡威胁时，不因威逼而屈膝归降；归附若发生，必须重新经过主体自己的价值判断
```

不锁人物整体稳定本体。

## 2｜剧情事实链

《三国演义》第六十三回：

1. 严颜作为巴郡守将，得知张飞来攻后，实际调动本部数千军马、安排守城，并拒绝开城投降。
2. 张飞用计破城，严颜被生擒；巴郡城防与军队处分已经不再由严颜掌握。
3. 在 `x` 已失的情况下，张飞要求他归降并以斩首相威胁，严颜仍拒绝屈膝，明确表示宁受斩也不因威逼而降。
4. 张飞随后停止威逼、亲自解缚、礼敬严颜。严颜在关系条件改变后“感其恩义”而归附，并主动提出协助入川。

来源核验：
- 《三国演义》第63回，中国哲学书电子化计划；
- 《三国演义》第63回，古文岛/古诗文网镜像；
- 《三国志》“张飞义释严颜”史料可作事实旁证，但本轮分类只以小说阶段为主。

## 3｜x 证据

### 3.1 压力前 x 成立

不是因为“严颜是太守”就判 `x`，而是存在可观察的现实处分：

```text
点起本部军马
→ 决定守城策略
→ 军士尽数上城守护
→ 对来使作出处分
→ 现实城防围绕其命令运行
```

因此当前“巴郡守城军政处分”对象层 `x` 成立。

### 3.2 被擒后 x 真实失去

张飞破城后：

```text
巴郡已被对方控制
+
严颜被缚押到厅上
+
原守城军力不再由严颜处分
```

这不是名义降权，而是现实掌握边界已经断开。

## 4｜zn 证据

本轮原则不能粗写成“永远不投降”，因为原著后面严颜确实归附张飞。更精确的原则边界是：

> **不能因敌方武力、威逼和死亡恐惧而屈膝归降；是否归附仍需主体自己的价值判断，不能由威胁替主体决定。**

这个原则通过当前准度门：

1. **原则命题明确**：拒绝被威逼屈降。
2. **不可轻易让渡**：城已失、本人被擒，仍不因现实失败撤回。
3. **无奖励/认可仍成立**：当时只有死亡威胁，没有奖励。
4. **冲突排序**：生命安全与屈降发生冲突时，原则压过保命。
5. **未来指导资格**：张飞改变关系方式、撤掉威逼并以义相待后，严颜才重新判断是否归附；说明原则不是“死也不加入任何人”，而是继续决定“什么条件下可以改变关系”。
6. **边界/条件可说明**：威逼屈降不可接受；自愿基于新价值判断的归附可以重新判断。

因此当前窄原则对象层 `zn` 成立。

## 5｜关键生命周期变化

本轮首次得到火轴直接生命周期链：

```text
阶段 A：
巴郡守城处分 x 成立
+
拒绝威逼屈降 zn 成立

阶段 B：
城失 / 被擒
→ 原巴郡处分 x = lost

阶段 C：
x 已失
+
死亡威胁进入
→ zn 仍继续排序
→ 拒绝屈膝

阶段 D：
威逼关系被撤销、张飞改以义礼相待
→ zn 没有消失
→ 而是按自身边界重新判断“自愿归附”
```

所以：

> **`x` 的失去不自动等于 `zn` 退出；`zn` 可以在失去原现实掌握对象以后继续保留未来指导资格。**

## 6｜strict zn↔x 反向压力测试

### 6.1 zn → x

在守城阶段，`zn` 给 `x` 提供“不因武力威逼而交出城防/关系位置”的守护与让渡标准，支持 `zn→x`。

### 6.2 x → zn

不成立。

因为本案直接提供了比假设更强的现实拿掉测试：

```text
巴郡处分 x 已真实失去
→ zn 没有悬空
→ 仍直接约束严颜自身的屈降选择
→ 仍有现实冲突对象（张飞的威逼/归附要求）
```

因此原巴郡 `x` 不是该 `zn` 的不可替代现实落点。

本案可作为第四种 `x` 类型的 strict 负控制：

```text
关羽：资源 x
晁盖：组织武力/处分 x
唐僧：关系处分/约束 x
严颜：稳定领地/守城军政处分 x
```

但本轮的主要新增用途是 `lifecycle-control`，不是继续堆同型 strict 反例数量。

## 7｜拿掉与反向测试

### 拿掉 x

原著已经真实发生：巴郡失守、处分权断开。

结果：`zn` 仍在死亡压力下进入最终选择。

### 拿掉 zn

若严颜没有“不可因威逼屈降”的内部原则，则城失被擒后可以直接以保命排序接受强制归降；原著的拒跪、拒降与受斩威胁下不改口将失去最直接解释。

### 反向改写

如果剧情是：

```text
城一失
→ 严颜立刻因为职位/军权不存在而放弃原判断
→ 只按胜者命令改变归属
```

则支持“x 丢失带动 zn 退出”。原著不是这种结构。

## 8｜最近邻排除

- `zn vs z`：拒绝不是为了获得旁观者认可；最强证据发生在被俘、受斩威胁时。
- `zn vs xn`：守城部署属于 `xn` 邻近，但不能解释城失以后为何仍拒绝屈降。
- `x vs zx`：巴郡守城阶段锁的是已有军政处分边界，不把每次下令重复记作扩权。
- `x vs 名义职位`：太守名义不是支柱；真实调兵、守城、处分使 x 成立，城失被缚使 x 真实退出。
- “后来归附”不等于前面 `zn` 不成立；它反而提供原则边界：拒绝威逼屈降，不等于永久拒绝一切自愿关系重建。

## 9｜第三因素冻结


## 11｜本轮锁出的火轴纪律

1. **`x` 失去 ≠ `zn` 自动失去。**
2. **稳定职位/领地处分退出必须按现实掌握断开判断，不能只看头衔。**
3. **原则在原 `x` 丢失后仍可通过主体自身行为与新的现实冲突继续落地。**
4. **原则后续允许关系改变，不等于原则消失；必须检查它是否只是重新规定了可接受改变的条件。**
5. **生命周期必须把端点成立、失去、保留和重新调用分阶段记录，不能从结局倒灌前一阶段。**

## 12｜下一步

优先级：

1. 继续寻找第一份真正通过 `x→zn` 不可替代现实落点门的 strict 正例候选；
2. 找第二份生命周期控制，最好是反向结构：`zn` 暂停/失去后 `x` 是否仍持续，或压力解除后 `zn` 复位；
3. 找第一份伪 `zn+x` 共现；
4. 不再机械增加第五份 strict 同型负控制。
