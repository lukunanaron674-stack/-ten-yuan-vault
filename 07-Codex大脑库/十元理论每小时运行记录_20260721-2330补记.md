## 源端点、目标端点与变量

### 源端点 zx

甲必须同时出现：

1. 力量公开进入现实；
2. 决定范围、影响位置或等级位置扩大；
3. 他者或旧秩序被迫围绕甲重新反应；
4. 不是普通善举、演讲、坚持或任务完成。

### 目标端点 zn

乙必须在甲显权后新增或显著增强：

1. 对某一原则的内部意义认领；
2. 甲离场、失败、没有奖励与群众支持时仍坚持；
3. 坚持对象是原则，不是英雄本人、群体身份或胜利阵营；
4. 拿掉宣传、纪念与从众后仍成立。

### 被改变变量

- 乙对原则的内部确定度；
- 无监督时持续行动的强度；
- 原则与英雄个人的可分离度；
- 去除胜利结果后是否仍认领；
- 是否从“他很强”转为“没人做，我也必须做”。

### 成立阶段、体量与显影条件

- 成立阶段：甲已经达到 zx，乙此前尚无稳定 zn；
- 低体量：单个见证者形成阶段性内部意义；

- 高体量：原则脱离英雄、胜利与制度奖励，成为共同体不可背弃的意义；
- 显影条件：必须看到无人监督、逆风、失败或英雄缺席后的持续选择。

## 候选机制

### 候选A：原则可行性被显权证明

```text
甲以 zx 把原则公开推入现实
→ 乙看见原则不是空话
→ 乙开始把原则认作值得坚持的内部意义
→ zn 上升
```

理论后果：zx 提供“原则能够进入现实”的存在性证据。

风险：若乙必须看到成功才相信，更接近 z 的结果确认、工具理性或胜方追随，与 zn 的自完备性冲突。

### 候选B：公开承担代价使原则与个人分离

```text
甲显权并公开承担位置、利益或生命代价
→ 乙确认甲不是借原则谋利
→ 英雄个人从原则前退开
→ 乙在甲缺席时仍坚持原则
→ zn 上升
```

理论后果：关键不是胜利，而是代价取消“表演或谋利”的解释。

风险：承担代价首先显影甲自身已有 zn；乙的变化仍可能来自 z、n、nz 或个人恩情。

### 候选C：决定空位被原则继承

```text
甲以 zx 压过旧秩序并离场
→ 现实留下决定空位
→ 乙不继承甲的权位，而继承其原则
→ 无奖励时仍按原则行动
```

理论后果：真正生成点发生在甲离场以后。

风险：若乙只是接任职位或沿组织流程继续，更接近 x、xn 或 nx。

## 动态链后果

当前唯一可保留的窄链条：

```text
他把原则以公开权能推入现实
→ 我先看见的是力量
→ 当他失败、离场或不再奖励我时
→ 我仍选择那个原则
→ 原则从“他的”变成“我的”
```
