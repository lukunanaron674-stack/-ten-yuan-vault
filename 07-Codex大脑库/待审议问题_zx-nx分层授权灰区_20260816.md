# 待审议问题｜zx↔nx 分层授权灰区

## 触发原因

连续材料压力测试中，已经跨三个独立作品复现同一类边界：

> **主体的“上位任务／战略方向”可以由外部给定，因此在该对象层呈现 `nx` 关系位置；与此同时，任务内部的局部对象、资源、人员和调用边界又可以真实交给主体，形成 `x`。这种分层不能因为主体有局部实权就抹掉上位 `nx`，也不能因为上位方向外置就把主体所有局部权限都写成 `nx`。**

目前支持案例：

1. 《三国演义》关羽受印守荆州；
2. 《水浒传》呼延灼征梁山；
3. 《西游记》孙悟空任弼马温。

三例都满足：

```text
上位任务 / 战略方向由外部给定
+
局部职务或战役权限真实可独立调用
+
未见主体把最高方向或决定边界继续公开推到原授权之外
```

因此触发待审议阈值，但不直接改理论正本。

2026-08-18 补入《红楼梦》薛宝钗反向控制：王夫人虽明确请宝钗协助照看园中，但同时规定若相关人“不听”，宝钗必须回报王夫人。该例证明“受托、被授权、进入管理位置”本身不足以证明局部 `x` 已形成；必须检查冲突发生时，主体能否不回原授权者而独立让处分生效。

2026-08-18 再补《西游记》孙悟空“齐天大圣”空衔反向控制：天庭正式承认高名位并设置府署，但明确“不与他事管，不与他俸禄”，第五回又写其“无事闲游”，直到后来另授“权管蟠桃园”才出现具体管理对象。该例进一步证明：**连“正式头衔 + 专门府署”都不能替代实际调用/处分接口；若连对象层职掌都没有，局部 `x` 不应锁，更不能把名位上升直接写成新的 `zx` 扩权。**

2026-08-19 补入《三国演义》刘备许都受封反向控制：刘备已被汉献帝拜为左将军、宜城亭侯，但曹操明确判断其“名虽近君，实在吾掌握之内”；刘备若要离开许都并调用五万人马，仍须通过曹操/朝廷的真实授权接口。该例证明：**即使不是纯空衔，而是拥有正式高名位和自身既有力量，也不能跨对象层从名位直接推出某一关键行动/资源接口已归主体独立处分。**

2026-08-19 再补《三国演义》诸葛亮挥泪斩马谡作为“反向反例／正向独立处分控制”：诸葛亮名义上仍处于后主刘禅之下，但在北伐军法对象层，对马谡的违令处分不需要先回成都逐项申请后主批准；蒋琬现场求情也不能改变其处分，马谡被实际处决。随后诸葛亮对**自己官位**的贬降才另行上表后主。该例证明：**“组织中仍有更高上级”不能单独推出当前局部权限仍是 `nx`；必须看被测试对象层的决定能否由主体独立生效。**

## 需要审议的核心问题

### 问题 A｜木轴是否应显式要求“对象层分层”

当前 L1 已经把木轴定义为“最终方向与作用权来源”，但案例显示同一人物同一阶段可以出现：

```text
最高方向来源：外部 → nx
局部调用边界：自身可独立处分 → x
```

待审议：是否需要在准度层明确写出“最高方向层、局部权限层、运行方法层必须分开，不可互相覆盖”。

### 问题 B｜受权获得真实局部权限何时仍只是 x，何时升为 zx

三个正向样本提示：

```text
别人把一块权限正式交给我
→ 我在边界内正常调用
```

优先可解释为局部 `x`，并不自动等于 `zx`。

只有进一步出现：

```text
我把决定边界公开推到原授权之外
→ 他者或秩序围绕新增决定接口重新反应
→ 我的决定范围继续上升
```

才有充分理由锁 `zx`。

该边界与现有“已有权限有效 ≠ 权限扩大”的待审议问题相邻，但本问题强调的是**授权层级分割**，不是单纯静态 `x vs zx`。

### 问题 B2｜“被授权”何时连局部 x 都不能锁

目前已有三部独立作品的反向控制。

《红楼梦》宝钗案例：

```text
上级给我照看/提醒/协助职责
→ 我可以发现问题并提出意见
→ 但冲突发生后，对方若不听
→ 我仍必须回到原授权者
→ 新方案/处分不能由我独立生效
```

《西游记》齐天大圣空衔案例：

```text
正式给高头衔
+ 给专门府署
→ 但明确无事管、无俸禄
→ 没有任何具体对象/资源进入稳定处分边界
→ 连“冲突后能否独立生效”的测试对象都不存在
```

《三国演义》刘备许都受封案例：

```text
正式给左将军、宜城亭侯等高名位
+ 人物自身也有既有随从与政治身份
→ 但关键离许/大规模军队调用仍受曹操—朝廷接口控制
→ 名位不能跨对象层替代真实独立处分权
```

三者分别卡住三种伪授权：

```text
宝钗型：有协助功能，但无最终独立处分
齐天大圣空衔型：连实际职掌本身都没有
刘备许都型：有正式高名位与部分既有力量，但被测试的关键行动/资源接口仍外置
```

当前最窄候选纪律：

> **局部 `x` 的高质量证据，不是“有任务、有头衔、有府署、有协助权、有高名位”，而是主体在被测试的对象层拥有真实可独立调用的决定/处分接口。若无实际职掌，或发生不服从/冲突后仍必须回到原授权者，或关键行动/资源必须重新通过外部授权接口，局部 `x` 应降级或排除；是否保留 `nx` 则继续按该阶段真实方向/权限来源另判。**

三部作品的反向控制现已达到待审议强化门槛，但仍不得直接修改 L1 或十元核心定义。

### 问题 B3｜有更高上级时，局部 x 会不会被误杀成 nx

《三国演义》诸葛亮斩马谡提供首个高纯正向独立处分控制：

```text
名义最高君主仍是刘禅
+
诸葛亮当前掌握北伐军法处分接口
+
马谡违令后，诸葛亮可直接作出处分
+
蒋琬求情不能改变
+
处分直接生效
+
诸葛亮本人官位处分才另行上表后主
```

结论：

> **局部对象层若存在可独立生效的真实处分接口，即使组织结构上仍有更高上级，该层仍可锁 `x`；不能因为“上面还有人”就自动保留 `nx`。**

这条目前只有一个高纯控制，只作为防过拟合限制，不升级准度正本。

### 问题 C｜nx 与 xn 不应跨对象层互相覆盖

呼延灼案例尤其明显：

```text
征剿梁山这个最高目标：外部给定 → nx
拿到任务后如何分兵、布阵、调资源：主体组织 → xn
```

因此“会组织运行”不能自动取消更上层的 nx；反过来，最高任务外置也不能把主体自己设计的运行方式写成 nx。

## 三正例 + 三反向控制 + 一项正向独立处分控制的最小差异

### 关羽

```text
刘备集团给：守荆州
诸葛亮给：北拒曹操，东和孙权
关羽掌握：荆州本地文武和守备的局部调用
```

结论：上位战略 nx + 局部 x。

### 呼延灼

```text
高俅/朝廷给：征剿梁山
呼延灼掌握：先锋、三军、装备、阵型与局部战役调度
```

结论：上位战略 nx + 局部 x + xn。

### 孙悟空弼马温

```text
玉帝给：去御马监任弼马温、管理天马
孙悟空掌握：御马监内部官员、事务核查与日常养马管理
```

结论：上位职责 nx + 局部 x；本段不锁 zx。

### 薛宝钗照看大观园｜反向控制 1

```text
王夫人给：协助照看园中、发现问题可以说
宝钗拥有：观察、提醒、报告的协助功能
冲突测试：相关人若“不听”，必须回王夫人
最终强制处分：仍在王夫人
```

结论：上位授权存在，但局部独立 `x` 未形成；保留 `nx` 权限关系，排除“受托即 zx”。

### 孙悟空齐天大圣空衔｜反向控制 2

```text
天庭给：齐天大圣正式名号 + 齐天大圣府
实际职掌：明文无事管、无俸禄
第五回状态：无事闲游
直到后来另授蟠桃园：才出现具体管理对象
```

结论：名位和府署存在，但实际对象/资源/权限没有进入稳定处分边界；局部 `x` 不成立，正式受封后的窄阶段也不能仅凭名位继续制造新的 `zx` 扩权。

### 刘备许都受封｜反向控制 3

```text
献帝给：左将军 + 宜城亭侯 + 皇叔身份确认
刘备已有：关张等既有随从与自身政治目标
曹操实际控制：许都行动出口 + 朝廷军令 + 五万人马配置
文本硬证据：“名虽近君，实在吾掌握之内”
```

结论：正式名位与部分既有力量存在，但在“离许/大规模军队调用”这一对象层，独立 `x` 不能仅凭头衔推出；刘备仍须沿曹操/朝廷真实授权接口推进，形成 `nx` 权限关系，且受封本身不足以制造新的 `zx`。

### 诸葛亮斩马谡｜正向独立处分控制 1

```text
后主刘禅：仍是蜀汉名义最高君主
诸葛亮：北伐军法处分主体
马谡违令失街亭
→ 诸葛亮直接判斩
→ 蒋琬求情无效
→ 马谡实际被斩
→ 不需要先回后主逐项批准

随后：
诸葛亮要处分自己的官位
→ 另行上表后主
→ 后主实际贬其官
```

结论：同一人物同一回中已经显示**对象层分割**：马谡军法处分接口在诸葛亮，故该层为既有 `x`；诸葛亮本人官位处分接口仍在后主。上级存在不能把前者误写成 `nx`，处分有效也不能把既有 `x` 误写成 `zx`。

这组差异把授权连续谱扩成六档：

```text
空衔/纯名位：有头衔/府署，无实际职掌 → 伪x/伪zx
名位存在但关键对象层仍外控：有正式身份/部分既有力量，但关键行动/资源需外部授权 → nx + 伪完整x/伪zx
纯代理：目标、方法、关键批准都在外 → nx 深
名义/协助授权：有任务、有观察或提醒权，但冲突后仍回上级 → nx + 伪x/伪zx
真实局部授权：最高方向外置，但局部接口可独立调用 → nx + x
真实局部授权后继续公开越界扩张 → 再检查 zx
```

同时增加一个横向防误判：

```text
组织上仍有更高上级
≠
所有局部对象层都仍是 nx
```

## 拿掉测试

### 拿掉具体作品和职位名称

统一改写为：

```text
上级给我一个不可由我重设的总体任务
→ 同时把任务内部一块对象和人员的实际调用权交给我
→ 我可独立处理局部事务
→ 但不能自行改写最高任务
```

前三例结构仍同型。

### 拿掉局部独立权

如果任何关键操作都必须逐项回到上级批准，则局部 `x` 应下降，更接近纯代理 `nx`。宝钗案例就是该反向控制的高纯实例。

### 拿掉实际职掌本身

如果只保留高名位、府署、礼遇，而没有任何具体对象/资源进入主体处分边界，则连局部 `x` 的最低门槛都不应满足。齐天大圣空衔案例就是该反向控制。

### 拿掉刘备案例中的曹操/朝廷行动与军队授权门

如果左将军身份本身已经稳定附带自由离许和五万人马独立调用权，刘备无需重新请求、曹操也不能阻断，则该对象层会从“名位存在但关键接口外置”向局部 `x` 移动。

### 拿掉最高方向外置

如果主体连“要不要做、做什么总体任务”都能自行决定，则上位 `nx` 下降，应重新检查 `x/xn/zx`。

### 拿掉宝钗案例中的王夫人最终否决接口

若宝钗在相关人不听时可以直接处分且立即生效，无需再回王夫人，则该例会从“名义/协助授权”向“真实局部 x”移动。

### 给齐天大圣空衔补入真实职掌

如果受封后立即稳定获得某类神将、资源或跨部门事务的独立处分接口，则该例不再是纯空衔，应重新检查局部 `x`；若权限首次公开运行并继续扩大，再另查 `zx`。

### 拿掉诸葛亮案例中的局部军法独立生效

如果马谡是否被斩必须先报后主、等后主批准，诸葛亮只有建议权，那么该对象层的 `x` 会下降，转而检查 `nx` 权限关系。

## 反向测试

### 反向 0｜纯空衔

```text
有头衔/名位/府署
+ 无具体职掌
+ 无稳定处分对象
```

局部 `x` 不应成立；是否有 `nx` 要回到该身份方向是谁生成、主体是否沿外部方向推进另判。

### 反向 0.5｜名位存在但关键对象层仍外控

```text
有正式职位/名位
+ 可能有部分既有力量
+ 被测试的关键行动/资源仍须重新经过外部授权
```

不得从名位跨对象层偷推局部 `x`；若主体实际沿外部授权接口推进，则该对象层可出现 `nx` 权限关系。

### 反向 1｜纯代理

```text
上级给目标
+ 上级给方法
+ 上级保留每一步批准权
+ 主体只执行
```

更接近 nx 覆盖较深的代理结构。

### 反向 2｜名义/协助授权

```text
上级给任务或管理角色
+ 主体可观察、提醒、建议
+ 一遇真实冲突仍须回上级
```

局部 `x` 不应高锁，优先保留 `nx` 权限关系。

### 反向 3｜局部 x

```text
上级给最高目标
+ 主体对局部对象有真实独立调用权
```

即关羽、呼延灼、弼马温三例的灰区结构。

### 反向 3.5｜有更高上级但局部决定可独立生效

```text
组织上存在更高上级
+ 被测试的局部对象已经进入主体处分边界
+ 冲突发生时无需回上级逐项批准
+ 决定可直接生效
```

该对象层优先 `x`，不得仅凭“上面还有人”自动判 `nx`。诸葛亮斩马谡是当前首个高纯控制。

### 反向 4｜zx 上升

```text
主体取得局部权限后
→ 继续公开突破授权边界
→ 让更大秩序围绕新增权能重排
```

此时才应提高 zx。

## 当前建议纪律（仅待审议，不是正本）

暂建议研究时采用以下分层问法：

```text
0. 是否真的存在可处分的对象/资源/职掌，而不是只有头衔？
1. 被测试的具体对象层，主体是否真的拥有独立调用权，而不是仅有更高名位？
2. 谁决定最高方向？
3. 谁掌握局部对象/资源的真实调用权？
4. 发生冲突、不服从或需要行动时，谁能让决定独立生效？
5. 组织上即使存在更高上级，该局部决定是否仍须回上级逐项批准？
6. 谁设计运行流程与节点？
7. 主体有没有把决定边界继续公开推大？
```

对应候选：

```text
只有名位、无实际职掌 → 伪x/伪zx
有名位但关键对象层仍须外部授权 → 该层x降级，按实际通道检查nx
最高方向外置 → nx
冲突后仍须回上级 → nx 保留，局部 x 降级
局部调用权可独立生效 → x
有更高上级但局部决定无需逐项回报 → 该层仍可为x，不自动nx
主动组织运行 → xn
公开扩大决定边界 → zx
```

八问必须按对象层分别取证，不得因为其中一项成立就覆盖另外几项。

诸葛亮控制又补上一条防过拟合限制：**“组织中存在更高上级”同样不是局部 `nx` 的充分条件。若冲突发生时主体可在当前对象层独立让决定生效，则该层仍应优先检查 `x`。**
