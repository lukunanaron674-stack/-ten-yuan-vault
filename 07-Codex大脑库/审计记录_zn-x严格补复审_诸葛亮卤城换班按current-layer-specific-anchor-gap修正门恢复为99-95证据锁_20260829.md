## 6｜方向二：按修正后的 current-layer-specific-anchor-gap，x→zn 成立

这是本轮核心。

### 6.1 不再使用“宇宙唯一载体”错误门

上一轮 93 分的重要降分理由是：

> 即使拿掉这批直属军队的留放 `x`，守信原则还可以作用于其他军令、承诺和规则，因此当前 `x` 不是世界唯一现实载体。

两个 canonical backtest 已证明：

> **“未来 / 别处仍可能有其他载体”不能自动否决 current strict。**

current canonical 真正要求的是：拿掉被测 `x` 后，本轮当前对象层是否重新失去原本由该 `x` 提供的具体、稳定现实边界。

### 6.2 当前对象层的现实缺口确实重新出现

若拿掉诸葛亮对这批应换班直属军士的现实留放处分边界：

- “守住既有信用”这个原则仍抽象成立；
- 但它在当前卤城窗口失去一个明确的现实对象范围：这批已形成归期期待的直属军士；
- 失去一个可由主体现实保持 / 撤回的规则接口：是否临时强留；
- 失去一个明确“我方”边界：这是由主体自己的军令和处分权造成、也必须由主体自己的处分选择兑现的信用问题。

所以当前对象层会从：

```text
原则
+ 明确直属对象
+ 我能现实违背 / 保持的军令处分
```

退回为：

```text
原则仍在
但本轮这块具体、可兑现、可被主体亲自破坏或维护的现实军令信用边界消失
```

这与 L2 canonical “x 给 zn 补具体对象 / 资源 / 权限 / 可执行边界”的要求一致。

因此：

```yaml
x_to_zn_gap_filling_under_current_canonical: true
```

### 6.3 其他可能载体为何不构成同窗竞争替代

“其他军令、其他承诺、未来规则”只是理论上的其他载体；当前卤城同一窗口内，并没有另一套现实对象稳定提供同等的：

> **四万应换班直属军士 + 主体能强留 / 放行 + 已形成归期期待**

这一现实边界。

所以本轮没有发现 `same-window equivalent real carrier`。
