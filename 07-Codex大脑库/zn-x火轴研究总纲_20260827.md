# zn ↔ x 火轴研究总纲｜2026-08-27

> L4 研究总览，不是 L2 正本。所有定义以 current canonical 为准；本文件只负责状态地图、案例矩阵、方法沉淀、待审议索引与高价值缺口。

## 1｜current canonical 骨架

L1 v1.6 固定：

```text
火 = 阳火 zn ↔ 阴火 x
主题领域 = 本体
广义变量 = 对象独立成立资格与归属方式：保留自身成立 ↔ 纳入掌握、调用与处分边界
```

`zn`：主体内部一项不可轻易让渡的意义或原则，必须能在无奖励/认可时进入判断，在冲突中排序选择，并保留未来调用资格。

`x`：对象、资源、地盘、权限或关系真实进入“归我 / 我方掌握”的边界，主体拥有实际占有、使用、调配、调用、处分、否决或排除能力。

`zn ↔ x` 补卡 current canonical：
- `zn → x`：补掌握用途、守护与放弃标准、否决原则；
- `x → zn`：补意义的现实落点、可保护对象范围与明确我方边界；
- 两端必须先独立成立；strict 还需双向拿掉后出现可命名且不可替代的缺口。

## 2｜固定验证协议

木轴只迁移方法，不迁移语义。火轴统一检查：

1. **对象层**：原则对象与掌握对象必须明确；局部不得倒灌人物整体。
2. **当前窗口**：区分稳定本体、当前状态、行为显影、关系位置、外部压力。
3. **最近邻**：`zn vs z/xn/n/zx/x/nz`；`x vs zx/xn/nx/x并z/nz`。
4. **拿掉**：去掉认可、奖励、职位、资源、称号后，端点是否仍成立。
5. **反向**：原则让渡/掌握失去后是否出现可观察改变。
6. **第三因素冻结**：道德评价、阵营、题材、胜负、称号不能替代端点。
7. **名义 ≠ 现实**：身份、职位、牌印、授权意向不自动证明现实 `x`。
8. **输入 ≠ 成立**：外部定义、承认、要求出现，不自动构成 `zn` 或 `x`。
9. **局部 ≠ 整体**：一项 `zn/x` 不自动定义整个人物。
10. **拒绝一端 ≠ 对端成立**：放弃资源不自动证明 `zn`；拒绝关系不自动证明现实 `x`。
11. **成熟度与权力分离**：L4 99/99 仍不能覆盖 L2；跨作品必须同 criterion_version。
12. **正反分账**：positive、negative guard、lifecycle、pressure display、strict 分别统计。

## 5｜当前已强化出的火轴纪律

1. 反奖励选择是 `zn` 高价值压力测试，不是定义本身。
2. 放弃 `x` ≠ `x` 从未成立；放弃 `x` 也 ≠ `zn` 自动成立。
3. pure `zn` 不需要先有 `x`；责任/保护对象 ≠ 掌握对象。
4. 高责任执行/承担代价 ≠ `zn`；先拿掉外部委任、收益、恩遇、问责与惩罚压力。
5. `zn` 可以限制已成立 `x` 的使用而不消灭 `x`；有权不用 ≠ 没有权。
6. 限制 `x` 前先查限制来源；外部命令/否决/惩罚/收益/临时策略不足锁 `zn`。
7. 关系处分 `x` 必须用现实生效证明。
8. 历史外部来源 ≠ 当前永久外置；完成交付后重新查 `x`。
9. `zn+x` 共现必须先让两端分别过门；共现 ≠ strict。
10. 现实执行接口 ≠ `zn` 不可替代现实落点。
11. 名义身份/高称号/外部承认 ≠ 现实 `x`。
12. 外部交权意向 ≠ 权已经归主体；名义授权 + 部分管理动作 ≠ 稳定全局 `x`。
13. 局部现实 `x` 成立 ≠ 整个组织/任务层全部 `x` 成立。
14. 当前 `x` 关闭 ≠ `zn` 未来调用资格被删除。
15. old `x` lost + different new `x` formed ≠ `zn` 必然被替换。
16. `x` 持续 on ≠ 已成立 `zn` 永久持续。
17. different new `x` formed ≠ old `zn` 必然跨载体持续；要检查新排序是否接管。
18. 历史上曾成立 `zn` ≠ 永久人物本体；允许真实退出、崩解、替换和不复位。
19. 被承认的时间 ≠ `zn` 真正成立时间；承认既非必要也非充分。
20. 被承认/赦免/受诏 ≠ 自动形成现实 `x`。
