## 5｜当前强化纪律

1. pure `zn` 不需要先有 `x`；责任/保护对象 ≠ 掌握对象。
2. `x` 可独立成立，不要求同步 `zn`。
3. 高责任/高代价 ≠ `zn`；先拿掉外部驱动。
4. `zn+x` 共现必须两端分别过门；co-occurrence ≠ strict。
5. strict 同 criterion_version 才累计；control 与 independent work 分账。
6. current reality anchor ≠ absolute metaphysical uniqueness。
7. strict `x→zn` 禁止循环定义；先用不引用被测 `x` 的语言命名 `zn`。
8. subject-specific / shared-governance `x` 不跨对象借用；多个不同 `x` 禁止 posthoc composite bundling。
9. local `x` ≠ global `x`；future revocability ≠ prior current x never existed。
10. execution / amplification / settlement interface 不自动等于 current anchor。
11. `real x loss ≠ automatic x→zn gap`。
12. transient capability/opportunity 与 one-off effective override 都不补成 stable disposition `x`。
13. **temporary custody/use/agency `x` ≠ ownership/full disposition `x`；物在我手 ≠ 对象完整归我处分。**
14. endpoint attribution：第三方产权、保护、否决与外部政治节点若直接进入结果，不得倒灌进主体 `x`。
15. standing commitment / formed expectation 可本身构成 same-window anchor；履约处分能力 ≠ 承诺对象本身。
16. decisive outcome control ≠ object-constituting anchor。
17. **people/object anchor 与 protected-range / organized-boundary anchor 分层；people presence alone 不自动否决范围型 `x→zn`。**
18. **declared protective range / 能力声明 / 设定威望 ≠ observed protected-range `x`。**
19. protection-range 正向至少要求 `boundary-on + object-inside + risk-test + observed exclusion/change`，或同机制独立复验。
20. evidence-locked 可被 adversarial audit 撤回。
