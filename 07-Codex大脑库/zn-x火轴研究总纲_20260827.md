## 5｜当前强化纪律

1. pure `zn` 不需要先有 `x`；责任/保护对象 ≠ 掌握对象。
2. `x` 可独立成立，不要求同步 `zn`。
3. 高责任/高代价 ≠ `zn`；先拿掉外部驱动。
4. `zn+x` 共现必须两端分别过门；co-occurrence ≠ strict。
5. strict 同 criterion_version 才累计跨作品；control 与 independent work 分账。
6. current reality anchor ≠ absolute metaphysical uniqueness。
7. strict `x→zn` 禁止循环定义；先用不引用被测 `x` 的语言命名 `zn`。
8. subject-specific / shared-governance `x` 不跨对象借用。
9. `self-restraint-looking use of x ≠ independent zn`。
10. local `x` ≠ global `x`；future revocability ≠ prior current x never existed。
11. `x lifecycle ≠ zn lifecycle`；historical `zn` ≠ permanent identity。
12. pressure-display 必须 same principle + same boundary + same conflict-order criterion。
13. evidence-locked 可被 adversarial audit 撤回。
14. execution / amplification / screened resource / old governance object 不自动等于 current anchor。
15. `real x loss ≠ automatic x→zn gap`。
16. 多个不同 `x` 默认分别测试，禁止 posthoc composite-x bundling。
17. 瞬时 capability/opportunity 不补成 stable disposition `x`。
18. 稳定 `x` + 主动释放也不能替 `zn`；先冻结战略、交换、资源回报。
19. 同一长期 instrumental policy 的多轮重复 ≠ `zn` 跨情境复验。
20. 候选原则与正式制度/角色规则语义同构时，必须补 evidence independence。
21. 巨大 delegated `x` 只放大风险/诱惑，不自动成为 `zn` 构成 anchor。
22. endpoint attribution：主体 operations/management `x` 与完整现实保护效果必须分开；第三方产权、保护、否决与外部政治节点若直接进入同一结果，不能倒灌进主体 `x`。
23. 被保护者本人可直接构成 same-window 原则对象；operations `x` 不因组织这些人而自动获得对象构成地位。
24. standing commitment / formed expectation 可本身构成 `zn` 的 same-window reality anchor；履约/违约处分接口不自动等于承诺对象 anchor。
25. 一次强制/越权的有效改写即使现实生效，也不自动构成 stable `x`；必须检查持续持有、重复调用、管理、处分与排除边界。
26. **决定性执行权 ≠ 对象构成型 anchor；一个 `x` 直接决定最终结果，也不能替代 `x→zn` 的对象构成证明。**
