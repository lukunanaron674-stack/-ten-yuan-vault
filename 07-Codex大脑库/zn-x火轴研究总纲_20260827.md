## 1｜current canonical 骨架

```text
火 = 阳火 zn ↔ 阴火 x
主题领域 = 本体
```

- `zn`：内部不可轻易让渡的意义/原则；必须能在无奖励/认可时进入判断，在冲突中排序并保有未来调用资格。
- `x`：对象、资源、地盘、权限或关系真实进入“归我/我方掌握”边界，具有实际占有、调用、处分、否决或排除能力。
- `zn→x`：补掌握用途、守护/放弃标准与否决原则。
- `x→zn`：补现实落点、可保护对象范围与明确我方边界。
- strict：两端先独立过门，再做同窗、同对象层、主体归因、第三因素冻结与双向缺口。

```text
current x ≠ permanent ownership
local x ≠ global x
future revocability ≠ prior current x never existed
x lifecycle ≠ zn lifecycle
expression window blocked ≠ zn erased
later stable principle ≠ same principle already existed before pressure
similar language ≠ same principle restored
```

## 5｜当前强化纪律

1. pure `zn` 不需要先有 `x`；责任/保护对象 ≠ 掌握对象。
2. `x` 可独立成立，不要求同步 `zn`。
3. 高责任/高代价 ≠ `zn`；先拿掉外部驱动。
4. `zn` 可限制已成立 `x` 的使用而不消灭 `x`。
5. `zn+x` 共现必须两端分别过门；co-occurrence ≠ strict。
6. 跨阶段/跨对象端点不能拼共现。
7. 结果与 `zn` 同向 ≠ 主体拥有使结果生效的 `x`；第三方 veto 归第三方。
8. strict 同 criterion_version 才累计跨作品。
9. control 数与 independent work 数分开。
10. current reality anchor ≠ absolute metaphysical uniqueness。
11. strict `x→zn` 禁止循环定义。
12. subject-specific `x` 不能跨对象借用；共享治理不能私有化给领导者。
13. 高纯 P1 `zn` 不跨原则倒灌。
14. `self-restraint-looking use of x ≠ independent zn`。
15. local `x` ≠ global `x`；future revocability ≠ prior current x never existed。
16. `x lifecycle ≠ zn lifecycle`；历史曾成立 `zn` ≠ 永久人物本体。
17. pressure-display 必须 same principle + same boundary + same conflict-order criterion。
18. evidence-locked 可被对抗审计撤回。
19. 修正过强判据 ≠ 所有旧 deferred 自动恢复。
20. canonical calibration 与普通 cross-work 分账。
21. execution / amplification / screened resource / old governance object 不自动等于 current anchor。
22. future alternative 不自动否决 strict；same-window existing anchor 会削弱 `x→zn`。
23. `real x loss ≠ automatic x→zn gap`。
24. 多个不同 `x` 共同承载同一原则时默认分别测，禁止按目标结果事后拼装 composite `x`。
25. 公开自罚/自限与治理收益同向时，先冻结服众、信誉、绩效、威慑等第三因素。
26. 对象当场表现触发的敬佩/认可不能倒填成压力前已成立 `zn`。
27. 一次物理可杀/可抓/可击倒机会不能补成稳定 `x`。
28. 稳定 `x` + 主动释放结果也不能替 `zn` 端上班；先冻外部通道、政治交换、资源回报与战略合作。
29. outcome-changing opportunity 与 object-constituting current anchor 分开。
30. 同一长期 instrumental policy 的多轮重复不是 `zn` 跨情境复验。
31. 候选原则与正式制度/角色规则语义同构时，必须补角色外或制度允许但主体主动收紧边界的独立证据。
32. 巨大 delegated `x` 只会放大原则风险和诱惑，不自动成为 `zn` 构成 anchor。
33. 大规模稳定庇护空间可以成为 current anchor，但必须把空间 `x` 与钱、人脉、电话、国际关系等辅助资源分开测试。
