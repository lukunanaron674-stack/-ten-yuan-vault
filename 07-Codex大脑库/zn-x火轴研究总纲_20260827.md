# zn ↔ x 火轴研究总纲｜2026-08-27

> L4 研究总览，不是 L2 正本。所有端点和关系定义以 current canonical 为准；本文件只负责状态地图、案例矩阵、方法沉淀、待审议索引与高价值缺口。

## 1｜current canonical 骨架

```text
火 = 阳火 zn ↔ 阴火 x
主题领域 = 本体
广义变量 = 对象独立成立资格与归属方式：保留自身成立 ↔ 纳入掌握、调用与处分边界
```

- `zn`：主体内部不可轻易让渡的意义/原则，必须能在无奖励/认可时进入判断，在冲突中排序，并保留未来调用资格。
- `x`：对象、资源、地盘、权限或关系真实进入“归我/我方掌握”的边界，主体拥有实际占有、使用、调配、调用、处分、否决或排除能力。
- `zn→x`：补掌握用途、守护/放弃标准与否决原则。
- `x→zn`：补意义的现实落点、可保护对象范围与明确我方边界。
- strict 必须两端先独立成立，再做双向拿掉并出现可命名、不可替代的缺口。

### canonical 元数据债

L1 v1.6 明确 `x = 阴火`。历史 `x` 信息卡 frontmatter 曾残留 `element: 阴水`。状态继续标记 `canonical-metadata-debt / needs-authorized-fix`，本总纲不自行修改 L2。

## 2｜固定验证协议

木轴只迁移方法，不迁移语义。火轴统一检查：对象层、当前窗口、最近邻、拿掉、反向、第三因素冻结、名义≠现实、输入≠成立、局部≠整体、拒绝一端≠对端成立、成熟度与权力分离、正反/生命周期/压力/strict 分账。

新增细化：

```text
current x
≠ permanent ownership
local x
≠ global x
future revocability
≠ prior current x never existed
expression window blocked
≠ zn erased
later stable principle
≠ same principle already existed before pressure
```

## 3｜当前研究资产总表

### 3.1｜zn vs x 最近邻

- 护栏：孙悟空弃弼马温；贾政笞宝玉后受贾母现实否决。
- 核心：`x` 回答“我实际掌握什么”；`zn` 回答“为什么守，以及为什么即使有权也不这样使用”。

### 3.2｜pure zn

状态：`3 positive / 3 works + 1 negative guard / 1 work / pending-review`。

- 正向：鲁智深、鸳鸯、刘备携民渡江。
- 护栏：杨志押送生辰纲，高责任/高代价可由外部委任、功名/恩遇、问责与惩罚压力解释，不能自动锁 `zn`。

### 3.3｜pure x

状态：`3 positive / 3 works / pending-review`。

- 刘姥姥：私人物品/资源处分。
- 孙悟空权管蟠桃园：公共职事/管理权限。
- 刘备权领徐州：地区军政治理。

纪律：现实 `x` 可以独立成立，不要求同步存在 `zn`；用途、职责、治理责任与“对象很重要”不能自动制造 `zn`。

### 3.4｜zn+x 当前共现

状态：`3 positive / 3 works + 4 negative guards / 3 guard works / pending-review`。

正向：关羽、晁盖、唐僧。

四类伪共现：
1. 孙悟空弼马温：`x=true`，`zn` 未独立过门。
2. 关羽“汉寿亭侯”：`zn=true`，名位/印信不足证明现实 `x`。
3. 鲁智深野猪林：`zn=true`，保护/责任对象不等于现实掌握 `x`。
4. 刘备携民渡江：百姓自愿跟随 + 当前协同足以解释表面结果，不需要假设稳定 `x`。

纪律：端点先各自过门；第三因素必须是真实存在且足以独立解释同一结果，不能当万能逃生口。

### 3.5｜strict zn↔x

状态：`0 positive + 4 negative guards / 3 works / pending-review`。

- 关羽、晁盖、唐僧三案均为 `zn→x=true`，但 `x→zn` 的不可替代现实落点门失败。
- 严颜为同作品生命周期旁证：巴郡军政 `x` 被真实拿掉后，拒绝威逼屈降 `zn` 仍持续。

当前最异常、最高价值问题仍是：**为什么火轴普通共现已经成熟，但 strict 正例仍为 0。** 不得为得到第一个正例降低 `x→zn` 强门。

### 3.6｜名义位置 / 外部承认 vs 现实 x

状态：`3 positive / 3 works + 2 negative guards / 2 works + 1 revocable-but-real control / 1 work / pending-review`。

正向：孙悟空空衔→蟠桃园；王熙凤原身份→宁府局部处分；刘备三让徐州→真实接管。

反向：
- 杨志：同层关键决定仍被原节点现实覆盖。
- 探春：局部日常 `x` 真实成立，但上位节点仍可在更高范围发动全局覆盖，local `x` 不得倒灌 global `x`。

边界控制：
- 天蓬元帅：任内对八万水军的 current `x` 真实成立；后来玉帝整段撤销，只结束其 lifecycle，不能追溯性否定此前 `x`。

因此必须分开：current-x / same-layer override / scope / global override / revocation / permanent ownership。

### 3.7｜lifecycle

状态：`3 positive / 3 works + 2 negative guards / 2 works / pending-review`。

正向：严颜、唐僧、宋江。
反向：沙威、迈克尔·柯里昂。

纪律：`x lifecycle ≠ zn lifecycle`；`x off` 不自动删除 `zn`，`x on` 不替 `zn` 保鲜，不同新 `x` 形成也不证明旧 `zn` 必然跨载体持续。

### 3.8｜被承认 vs 真正成立

状态：`3 positive / 3 works + 1 negative guard / 1 work / pending-review`。

- 正向：宋江、鸳鸯、关羽，均为 `zn` 先独立成立，外部承认后来追上。
- 反向：吕布，关系命名、封赏、组织位置与公开承认很强，但不足替代 `zn` 无奖励门、冲突排序与未来调用资格。

结论候选：承认既不是 `zn` 必要条件，也不是充分条件；承认时点不得回填成 `zn` 生成时点。

### 3.9｜pressure display

状态：`1 positive / 1 work + 1 negative guard / 1 work / evidence-locked`。

- 正向：《三国演义》关羽土山受困→暂居曹营→得知刘备消息后辞曹归刘，99/97。压力封住最强行动表达，但旧义未来指导资格仍在；解压后按同一硬门复位。

## 5｜当前强化纪律

1. 放弃/失去 `x` ≠ 自动 `zn`。
2. pure `zn` 不需要先有 `x`；责任/保护对象 ≠ 掌握对象。
3. `x` 可以独立成立，不要求同步存在 `zn`。
4. 高责任/高代价 ≠ `zn`；先拿掉外部驱动。
5. `zn` 可限制已成立 `x` 的使用而不消灭 `x`。
6. 限制 `x` 前先查限制来源；外部命令/现实否决/惩罚/收益/策略不足锁 `zn`。
7. `zn+x` 共现必须两端分别过门；co-occurrence ≠ strict。
8. 现实执行接口 ≠ `zn` 不可替代现实落点。
9. 名义身份、称号、牌印、交权意向 ≠ 现实 `x`。
10. 名义授权 + 部分管理 ≠ 稳定全局 `x`。
11. 局部 `x` 成立 ≠ 整体/全局 `x` 成立。
12. 上位节点未来能整段撤销 ≠ current `x` 从未成立。
13. current-x、scope、override、revocation、permanent ownership 分开。
14. 当前 `x` 关闭 ≠ `zn` 未来调用资格删除。
15. `x` 持续 on ≠ `zn` 永久持续。
16. 不同新 `x` 形成 ≠ 旧 `zn` 必然跨载体持续。
17. 历史曾成立 `zn` ≠ 永久人物本体。
18. 被承认时间 ≠ `zn` 成立时间；承认既非必要也非充分。
19. 被保护、共同移动、当前协同 ≠ 稳定 `x`；真实第三因素足以解释结果时不能重复取证。
20. **expression window blocked ≠ `zn` erased。**
21. **pressure-display 解压后必须按同一可命名原则、同一 canonical 硬门复位。**
22. **压力后的稳定原则 ≠ 压力前已经存在的同一原则；禁止 temporal backfill。**
23. **关系连续 ≠ 原则内容相同。**
