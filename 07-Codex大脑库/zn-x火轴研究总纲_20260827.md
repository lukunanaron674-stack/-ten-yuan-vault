## 5｜当前强化纪律

1. pure `zn` 不需要先有 `x`；责任/保护对象 ≠ 掌握对象。
2. `x` 可独立成立，不要求同步 `zn`。
3. 高责任/高代价 ≠ `zn`；先拿掉外部驱动。
4. `zn+x` 共现必须两端分别过门；co-occurrence ≠ strict。
5. strict 同 criterion_version 才累计；control 与 independent work 分账。
6. current reality anchor ≠ absolute metaphysical uniqueness。
7. strict `x→zn` 禁止循环定义；先用不引用被测 `x` 的语言命名 `zn`。
8. subject-specific/shared-governance `x` 不跨对象私有化；多个不同 `x` 禁止 posthoc composite bundling。
9. local `x` ≠ global `x`；future revocability ≠ prior current x never existed。
10. future whole-block revocation ≠ same-layer pre-effect veto。
11. shared governance x ≠ unilateral disposition x。
12. **source decision structure ≠ consultation structure ≠ final decision structure ≠ current execution structure。**
13. collective conferral 既不预设后续逐项 joint，也不自动产生领导者 full-scope unilateral `x`。
14. broad consultation / proposal / persuasion ≠ shared/joint final decision；最终裁决与同层 veto 单独取证。
15. **`x` 可以 scope expansion / contraction；迁移前窄 `x` 不得写成 `x=false`，迁移后宽 `x` 不得倒填到迁移前。**
16. execution/amplification/settlement interface 不自动等于 current anchor。
17. transient capability/opportunity 与 one-off effective override 都不补成 stable disposition `x`。
18. temporary custody/use/agency `x` ≠ ownership/full disposition `x`。
19. endpoint attribution：第三方产权、保护、否决与外部政治节点不得倒灌主体 `x`。
20. standing commitment / formed expectation 可本身构成 same-window anchor；履约能力 ≠ 承诺对象。
21. decisive outcome control ≠ object-constituting anchor。
22. people/object anchor 与 protected-range / organized-boundary anchor 分层。
23. declared protective range / 能力声明 / 设定威望 ≠ observed protected-range `x`。
24. territorial/internal-governance `x` ≠ stable externally exclusionary protected-range `x`。
25. protection-range 正向要求 `boundary-on + object-inside + risk-test + observed exclusion/change`，并排除第三方等价保护。
26. evidence-locked 可被 adversarial audit 撤回。
