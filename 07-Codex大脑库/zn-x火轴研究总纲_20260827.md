# zn ↔ x 火轴研究总纲｜2026-08-27

> 本文件是 L4 研究总览，不是 L2 正本。所有定义以 current canonical 为准；本文件只负责状态地图、案例矩阵、方法迁移与待验证缺口。

## 1｜正本骨架

### zn

`zn = 主体内部一项不可轻易让渡的意义或原则，拥有未来调用、冲突排序与最终指导选择的资格。`

最短：**为什么值得守，以及什么原则拥有最终指导资格。**

### x

`x = 对象、资源、地盘、权限或关系进入“归我 / 我方掌握”的边界，主体拥有实际占有、使用、调配、调用、处分或排除能力。`

最短：**具体什么归我掌握。**

### zn ↔ x 补卡正本

- `zn → x`：给掌握对象补用途、守护/放弃标准与否决原则。
- `x → zn`：给意义补现实落点、可保护对象范围与明确我方边界。
- 红线：意义不会自动制造资源；拥有资源不会自动产生意义。拿掉任一端，另一端必须仍成立但重新出现方向或落点缺口。

## 2｜火轴固定验证方法

木轴只迁移方法，不迁移语义。火轴每个案例固定检查：

1. 对象层：原则对象与掌握对象必须明确；局部成立不得倒灌人物整体。
2. 当前窗口：区分稳定本体、当前状态、行为显影、关系位置与压力。
3. 最近邻：至少检查 `zn vs z/xn/n/zx/x/nz` 与 `x vs zx/xn/nx/x并z/nz`。
4. 拿掉：去掉奖励、认可、职位、资源、外观后，端点是否仍成立。
5. 反向：若主体让渡原则/放弃掌握，是否出现可观察改变。
6. 第三因素冻结：道德评价、阵营、称号、题材、胜负不能替代端点。
7. 名义 ≠ 现实：名义身份/称号/职位不自动证明 zn 或 x。
8. 输入 ≠ 接入：外部定义、承认或要求出现，不自动构成本体端点。
9. 局部 ≠ 整体：一项资源 x 或一项原则 zn 不自动定义整个人物。
10. 拒绝一端 ≠ 对端自动成立：放弃资源不自动证明 zn；拒绝原则不自动证明 x。

## 3｜已锁资产

### 3.1 关羽挂印封金｜《三国演义》第26回

状态：`evidence-locked 99/98`。

核心对象层：

- `zn`：对刘备旧盟/旧义的内部最终指导资格；
- `x`：曹赐金银、侯印、人役、赤兔马等具体资源/权限对象。

已锁结论：

> 当部分曹赐 x 资源与旧义 zn 冲突时，关羽主动封金、挂印、放弃人役，旧义仍保留最终排序与未来指导资格。

因此首轮最小边界为：

```text
我拥有某对象
≠
该对象决定我为什么继续选择

x：什么归我掌握
zn：为什么守、什么拥有最终指导资格
```

注意：赤兔马继续使用，因此不把整段涂成“纯 zn”；本轮也不计 `zn+x` strict complement。

### 3.2 孙悟空弃弼马温｜《西游记》第4回

状态：`evidence-locked 99/98`，negative guard。

核心对象层：

- `x`：御马监正堂职事与千匹天马管理范围真实进入孙悟空掌握；
- `zn`：若要成立，必须有独立于官阶、认可、地位比较的内部不可轻易让渡原则；本窄桥段证据不足。

已锁结论：

> **放弃 / 退出已经真实成立的 x，不足以自动推出 zn。**

触发主要来自“弼马温未入流、官阶最低、被轻视”等外部等级信息；只用 `x成立 → 得知官小 → 主动弃职 → 追求更高称号` 已可解释当前桥段，不需要额外假设稳定 zn。

因此：

```text
x 退出是事实
≠
内部原则 zn 已成立
```

这条只作为 `zn vs x` 反向护栏，不增加 positive control。

### 3.3 刘姥姥一进荣国府获赠银钱｜《红楼梦》第6回

状态：`evidence-locked 99/98`，pure-x control。

核心对象层：王熙凤/平儿完成交付后的二十两银子与一吊钱。

已锁结论：

- 银钱被刘姥姥实际拿走；
- 她拥有现实使用与处分能力，并主动尝试把其中一块转给周瑞家的孩子；
- 无需回原交付节点逐次批准；
- 因此当前银钱对象层 `x` 独立成立。

`zn` 不锁：家庭过冬、现实用途与感恩不足以独立通过不可轻易让渡原则、冲突排序和未来指导资格门。

因此这条只计当前对象层 pure-x，不锁刘姥姥整个人物本体。

新增边界：

> **外部来源 ≠ 当前永久 nx；完成真实交付并取得直接处分权后，当前对象应重新检查 x。现实用途 / 家庭需求 ≠ 自动 zn。**

### 3.4 鲁智深野猪林救林冲并坚持护送｜《水浒传》

状态：`evidence-locked 99/97`，pure-zn control。

核心原则对象：见强者以不义方式伤害弱者时应介入救护；一旦承担救援，就应把被救者送出持续危险，而非只做一次表面救援。

已锁结论：

- “救人须救彻”给出直接原则边界；
- 无奖励、无认可下仍执行；
- 继续护送带来现实风险与后续代价；
- 更早金翠莲桥段提供跨情境重复支持，但不另计 control；
- 同一原则对象层 `x` 不锁：保护林冲不等于林冲或其安全进入鲁智深的占有、调用、处分或排除边界。

因此本轮只计当前原则层 pure-zn，不锁鲁智深整个人物本体，不计 `zn+x` 或 strict complement。

新增边界：

> **pure zn 不需要先有一个可掌握的 x 对象；保护 / 责任 / 不抛下某人也不等于 x。**

### 3.5 晁盖梁山初立后自限劫掠武力处分｜《水浒传》第20回 / 第39回跨情境复验

状态：`evidence-locked 99/98`，第二独立作品 `zn vs x` 正向控制，同时提供当前 `zn+x` 共现证据。

核心对象层：

- `x`：梁山人马、劫掠行动、战利品入库/分配与行动边界已进入晁盖现实指挥、调用和处分范围；
- `zn`：即使已有现实武力与处分权，也不能因取财、脱险或操作便利任意伤害不抵抗客商与无关百姓。

已锁结论：

- 第20回晁盖允许取财，但明确限制不得伤害客商性命，并在报捷时再次追问是否杀人；
- 第39回江州劫法场的高压撤退窗口中，仍制止李逵滥杀无关百姓，提供跨情境重复支持；
- `x` 没有因为原则限制就消失：晁盖仍有现实调兵、部署、分配和约束行动的权限；
- `zn` 也不是由“首领身份”或外部认可生成，而是对已成立 `x` 的使用方式施加内部边界。

新增最小边界：

```text
x：我有权做什么
zn：为什么即使有权，我也不做某些事
```

与关羽不同：关羽是 `zn` 促使主动让渡部分 `x`；晁盖是 `zn` 对已经成立的 `x` 进行持续自我限权。

本轮只锁最近邻分离与 `zn+x` 当前共现，不做 strict complement 双向缺口闭锁。

### 3.6 唐僧三打白骨精 / 草寇事件｜《西游记》第27回、第56–57回

## 5｜当前已强化出的火轴纪律

### 5.1 反奖励选择是 zn 的高价值压力测试，不是 zn 定义本身

奖励、认可、职位、资源越强，若主体仍让不可让渡原则排序最终选择，zn 证据越干净；但没有奖励也可以有 zn，不能把“牺牲利益”写成 zn 的必要定义。

### 5.2 放弃 x 不等于 x 从未成立

对象曾真实进入主体掌握范围，之后主动让渡/封存/退出，只能说明 `x` 当前下降或退出；不能倒改历史对象层。

### 5.3 放弃 x 也不等于 zn 自动成立

主动退出、承担代价、行为决绝都只是动作事实。若没有一项内部原则独立通过“无奖励/无认可仍成立、冲突排序、未来调用资格”等门，则不能从退出行为反推 zn。

### 5.4 一项原则压过一批资源，不等于“整个人物纯 zn”

必须逐对象检查仍保留的 x，例如关羽案例中的赤兔马。

### 5.5 被外部封侯/认可 ≠ 内部意义被替换

名位和认可属于外部条件；只有它们真正替换了主体未来指导资格，才讨论 zn 被改写/退出。

### 5.6 资源外部来源 ≠ 当前永久 nx

历史上由别人提供、赠与或转交，只说明来源。若交付已经完成、原节点不再保留逐次许可/撤回，而主体取得实际使用与处分能力，则当前应优先检查 `x`，不能永久追挂来源型 `nx`。

### 5.7 现实用途 / 家庭需求 ≠ 自动 zn

“拿这个对象做什么”只能说明用途；要升级 `zn`，仍需独立证明内部原则、冲突排序与未来指导资格。

### 5.8 pure zn 不需要先有 x 对象

只要内部原则独立通过无奖励、冲突排序、未来指导资格与边界说明门，就可在窄原则对象层成立；不能要求原则必须先绑定一项可掌握资源。

### 5.9 保护 / 责任 / 不抛下 ≠ x

关系责任强度不能替代实际掌握证据。要成立 `x`，仍需证明对象真实进入主体占有、调用、处分或排除边界。

### 5.10 zn 限制 x 的使用方式，不等于 x 不成立

主体可以真实拥有处分、调用和排除能力，同时以内部原则给自身权力划边界。自我限权证明的是 `zn` 对 `x` 使用方式的排序，不是“其实没有 x”。

最短：**有权不用 ≠ 没有权。**

### 5.11 关系处分 x 也必须用现实生效证明

“师父、首领、长辈、伴侣”等关系名义不能替代 `x`。只有警告、留用、处分、否决、逐退等现实权限真实生效，才进入关系处分 `x` 候选。

### 5.12 自我限制也不自动是 zn

主体拥有 `x` 并主动限制其使用，只是 zn 候选入口。若限制主要来自外部命令、惩罚恐惧、收益计算、临时策略或舆论观看，拿掉这些条件后不再保留未来指导资格，则不能锁 `zn`。
