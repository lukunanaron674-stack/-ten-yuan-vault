## 5｜当前强化纪律

1. pure `zn` 不需要先有 `x`；责任/保护对象 ≠ 掌握对象。
2. `x` 可以独立成立，不要求同步存在 `zn`。
3. 高责任/高代价 ≠ `zn`；先拿掉外部驱动。
4. `zn` 可限制已成立 `x` 的使用而不消灭 `x`。
5. 限制 `x` 前先查来源；外部命令/否决/惩罚/收益/策略不足锁 `zn`。
6. `zn+x` 共现必须两端分别过门；co-occurrence ≠ strict。
7. 跨阶段/跨对象端点不能拼共现；同一人物不是对象层胶水。
8. 最终结果与 `zn` 同向 ≠ 主体拥有使结果生效的 `x`；第三方 veto 归第三方。
9. strict 同 criterion_version 才能累计跨作品；v1/v2 分账。
10. current reality anchor ≠ absolute metaphysical uniqueness。
11. strict `x→zn` 禁止循环定义：先在不引用被测 `x` 的条件下独立命名 `zn`。
12. subject-specific `x` 不能跨对象层借用；共享治理不能私有化给领导者。
13. 高纯 P1 `zn` 不能跨原则倒灌 P2。
14. `self-restraint-looking use of x ≠ independent zn`。
15. local `x` ≠ global `x`；future revocability ≠ prior current x never existed。
16. `x lifecycle ≠ zn lifecycle`；历史曾成立 `zn` ≠ 永久人物本体。
17. pressure-display 必须 same principle + same boundary + same conflict-order criterion；禁止 temporal backfill 与相似口号假复位。
18. evidence-locked 可被对抗审计撤回；事实99不等于分类永久95。
19. 修正过强判据 ≠ 所有旧 deferred 自动恢复。
20. canonical calibration control 与普通文学 cross-work control 分账。
