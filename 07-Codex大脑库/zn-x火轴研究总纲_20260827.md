# zn ↔ x 火轴研究总纲｜2026-08-27

> 本文件是 L4 研究总览，不是 L2 正本。所有定义以 current canonical 为准；本文件只负责状态地图、案例矩阵、方法迁移与待验证缺口。

## 1｜正本骨架

### zn

`zn = 主体内部一项不可轻易让渡的意义或原则，拥有未来调用、冲突排序与最终指导选择的资格。`

最短：**为什么值得守，以及什么原则拥有最终指导资格。**

### x

`x = 对象、资源、地盘、权限或关系进入“归我 / 我方掌握”的边界，主体拥有实际占有、使用、调配、调用、处分或排除能力。`

最短：**具体什么归我掌握。**

### zn ↔ x 补卡正本

- `zn → x`：给掌握对象补用途、守护/放弃标准与否决原则。
- `x → zn`：给意义补现实落点、可保护对象范围与明确我方边界。
- 红线：意义不会自动制造资源；拥有资源不会自动产生意义。拿掉任一端，另一端必须仍成立但重新出现方向或落点缺口。

## 2｜火轴固定验证方法

木轴只迁移方法，不迁移语义。火轴每个案例固定检查：

1. 对象层：原则对象与掌握对象必须明确；局部成立不得倒灌人物整体。
2. 当前窗口：区分稳定本体、当前状态、行为显影、关系位置与压力。
3. 最近邻：至少检查 `zn vs z/xn/n/zx/x/nz` 与 `x vs zx/xn/nx/x并z/nz`。
4. 拿掉：去掉奖励、认可、职位、资源、外观后，端点是否仍成立。
5. 反向：若主体让渡原则/放弃掌握，是否出现可观察改变。
6. 第三因素冻结：道德评价、阵营、称号、题材、胜负不能替代端点。
7. 名义 ≠ 现实：名义身份/称号/职位不自动证明 zn 或 x。
8. 输入 ≠ 接入：外部定义、承认或要求出现，不自动构成本体端点。
9. 局部 ≠ 整体：一项资源 x 或一项原则 zn 不自动定义整个人物。
10. 拒绝一端 ≠ 对端自动成立：放弃资源不自动证明 zn；拒绝原则不自动证明 x。

## 3｜首轮已锁资产

### 3.1 关羽挂印封金｜《三国演义》第26回

状态：`evidence-locked 99/98`。

核心对象层：

- `zn`：对刘备旧盟/旧义的内部最终指导资格；
- `x`：曹赐金银、侯印、人役、赤兔马等具体资源/权限对象。

已锁结论：

> 当部分曹赐 x 资源与旧义 zn 冲突时，关羽主动封金、挂印、放弃人役，旧义仍保留最终排序与未来指导资格。

因此首轮最小边界为：

```text
我拥有某对象
≠
该对象决定我为什么继续选择

x：什么归我掌握
zn：为什么守、什么拥有最终指导资格
```

注意：赤兔马继续使用，因此不把整段涂成“纯 zn”；本轮也不计 `zn+x` strict complement。

## 5｜从首轮材料强化出的火轴纪律

### 5.1 反奖励选择是 zn 的高价值压力测试，不是 zn 定义本身

奖励、认可、职位、资源越强，若主体仍让不可让渡原则排序最终选择，zn 证据越干净；但没有奖励也可以有 zn，不能把“牺牲利益”写成 zn 的必要定义。

### 5.2 放弃 x 不等于 x 从未成立

对象曾真实进入主体掌握范围，之后主动让渡/封存/退出，只能说明 `x` 当前下降或退出；不能倒改历史对象层。

### 5.3 一项原则压过一批资源，不等于“整个人物纯 zn”

必须逐对象检查仍保留的 x，例如本例赤兔马。

### 5.4 被外部封侯/认可 ≠ 内部意义被替换

名位和认可属于外部条件；只有它们真正替换了主体未来指导资格，才讨论 zn 被改写/退出。

## 7｜当前高价值缺口

P1｜第二份 `zn vs x` 同判据控制：优先《西游记》《水浒传》《红楼梦》，最好比关羽更干净，资源放弃后没有明显 x 残留。

P2｜纯 zn：原则在无奖励、无认可、无现实掌握对象加成时仍稳定指导冲突选择。

P3｜纯 x：有稳定掌握、处分、排除能力，但没有可锁的不可让渡内部意义。

P4｜伪 zn：口号、忠义称号、阵营标签、一次牺牲，看似原则但无法通过冲突排序/未来调用门。

P5｜伪 x：名义拥有、临时持有、代理授权、一次接触，看似“归我”但无稳定实际处分。

P6｜`zn+x` 共现与 strict complement：两端先独立过门，再查“方向依据缺口 ↔ 现实落点缺口”，禁止普通‘有理想又有资源’冒充补关系。

P7｜名义本体 vs 现实本体：被封号、被称呼、血统、职位或阵营变化，是否真的改变内部原则或掌握边界。

P8｜压力显影：外压封住 zn 或 x 的现实显影后，另一端是否抬高；解压后必须按原端硬判据验收复位。

P9｜被替代/改写：外部新身份、新资源、新关系进入后，旧 zn 是否仍保留未来调用资格；旧 x 是否仍保留现实处分权。

## 8｜下一轮优先级

第一优先：找第二份 `zn vs x` 同判据最小控制，验证“原则可要求主动限制/让渡已掌握资源，而原则未来指导资格继续存在”是否跨作品稳定。

第二优先：找一份反向护栏——主体放弃/失去资源只是被迫、策略性或资源无价值，并没有不可让渡原则参与，防止“放弃 x = zn”误判。
