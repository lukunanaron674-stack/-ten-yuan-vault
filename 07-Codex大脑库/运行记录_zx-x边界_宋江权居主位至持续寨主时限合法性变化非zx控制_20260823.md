# 运行记录｜宋江“权居主位”到持续寨主：时限与合法性加固不等于 zx 扩权

## 0｜本轮结论

本轮锁定一个 `x ↔ zx` 最近邻反例：

> **宋江从“权居主位”发展为后续持续稳居梁山第一位，最清楚的变化是任期稳定性与组织合法性加固；没有证据显示其寨主决定对象范围因此从 A1 扩成更大的 A2。**

因此：

```text
临时/条件性主位 x
→ 任期与合法性加固
→ 仍是同一寨主处分对象域
= x 持续/稳定化
≠ 自动 zx
```

本轮不推翻仓库旧“第60回首次用权是否 zx”的 92% candidate；这里测试的是更晚的“临时→持续”变化，结论可以独立达到 97%。

## 1｜剧情事实

### 1.1 初始入口

晁盖死后，众头领推举宋江主寨。宋江以晁盖遗言“捉得史文恭者便为梁山泊主”为由拒绝立即正式继位。吴用提出先让宋江“权且尊临此位”，宋江接受，并明确以后捉得史文恭者仍应承接主位。

所以第60回是：

```text
众头领推举
→ 宋江接受临时/条件性承接
= nx 授位入口

授权完成
→ 宋江真实主持山寨、分六寨、调头领
= 寨主局部 x
```

### 1.2 条件真正被触发

第68回卢俊义实际生擒史文恭，满足晁盖遗命。宋江公开提出依遗言让卢俊义做梁山泊主；卢俊义拒绝，吴用及众头领也坚持宋江为尊。随后宋江提出以东平、东昌两城再作比较，但卢俊义仍明确表示只愿听宋江差遣。

### 1.3 后续稳定结果

到第71回，宋江仍居梁山第一位，并回顾为“众弟兄英雄扶助，立我为头”。梁山一百八人最终排序与组织运行都以宋江居首、卢俊义居次为现实结果。

因此事实变化可以压成：

```text
A1：权居/条件性寨主
↓
继承条件被实际触发
↓
潜在接替者卢俊义拒绝
+ 众头领继续支持宋江
↓
宋江持续居首
= A1 的任期/合法性稳定化
```

## 2｜zx 判断

`zx_from_tenure_or_legitimacy_extension: rejected_as_primary`

zx 信息卡与准度卡要求主体公开显权后，决定范围、影响位置或凌驾程度真实上升。

本轮虽然宋江的位置“更稳”，但没有看到：

- 原来只能决定梁山事务的一部分，后来新增另一部分；
- 原来没有某类处分权，后来这类处分权进入其稳定边界；
- 原有寨主对象域之外出现新的 B，并被宋江取得；
- 原权限节点反对其新增 B，但 B 仍稳定成立。

第60回宋江作为“权居主位”时已经能主持山寨、分寨、调头领；第71回仍是主持同一梁山组织的寨主最高接口。变化主要是**时限、条件与合法性**，不是可观察的处分范围扩宽。

所以：

> **位置持续时间变长 ≠ 决定范围变大。**
> **合法性加固 ≠ 自动 zx。**

## 3｜nx 判断

`nx_initial_succession_entry_relation: evidence-locked`

最初主位入口明确来自众头领推举与承接关系，宋江不是自己先宣布获得梁山主位。

但本轮后半段不能把“众人继续拥戴”永久写成 nx 主判：一旦寨主权限已经真实进入宋江稳定调用范围，日常主持与处分优先属于 `x`。

因此：

```text
谁把主位入口交给宋江？
→ nx 可解释

主位进入宋江后，他能否直接主持梁山？
→ x

主位后来更稳、更长期，是否等于权限范围扩大？
→ 否，非自动 zx
```

## 4｜关键压力

压力不是一般“众人拥护”，而是晁盖遗命真的被触发：卢俊义确实捉到史文恭。

如果宋江只是一直没有遇到接替条件，那么“权居”可能只是名义上的临时字样；第68回之后，原条件真正进入现实，组织必须重新处理谁做寨主，这才让“临时性/合法性”成为可观察变量。

结果却是：

- 宋江先主张让位；
- 卢俊义拒绝；
- 众头领反对更换；
- 最终宋江继续居首。

因此本轮可以把“任期稳定化”与“权限扩张”分离。

## 5｜拿掉测试

### 5.1 拿掉卢俊义擒史文恭

如果晁盖遗命从未触发，无法高纯证明宋江的临时主位经历过一次真实继承压力测试；只能说临时状态一直延续。

### 5.2 拿掉众头领与卢俊义的继续支持

若卢俊义接受主位、众人随之换主，宋江的原 `x` 会退出，而不是稳定化。

### 5.3 拿掉“处分范围扩张”证据

本例仍完整成立为“x 的持续/合法性加固”，说明 zx 并不是解释结果所必需。

### 5.4 拿掉时限/合法性变化

如果第60回一开始就是无条件永久寨主，则本轮研究对象消失，但宋江的寨主 `x` 仍可以成立。

## 6｜反向测试

### 6.1 真正同域 zx

要从同一“梁山寨主权”对象域锁 zx，应看到：

```text
原 A1：寨主只拥有一部分明确处分范围
↓
A2：另一部分原本保留给别的节点
↓
宋江公开推进 A2
↓
原节点真实反对/试图阻止
↓
A2 最终稳定归宋江
= 同域 A1→A2 zx
```

本轮没有这种证据。

### 6.2 纯 x 稳定化

```text
原来已经能处分同一批对象
→ 临时条件解除/任期变长/合法性增强
→ 仍处分同一批对象
= x 稳定化
```

本例更符合这一侧。

## 7｜最近邻排除

### zx vs x

`x` 看权限是否已经归主体稳定调用；`zx` 还要看到决定范围新增/上升。

“主位从临时变稳定”只提高稳定性，不自动提高范围。

### zx vs z

组织对宋江的拥戴、认可、合法化有 `z` 认可邻近，但本轮不以认可本身判 zx。只有认可进一步带来新的决定范围，才重新检查 zx。

### nx vs x

外部推举解释入口；入口完成后，寨主权限已经进入宋江现实调用边界。

### xn vs zx

宋江提出东平/东昌比较、组织继承解决过程有 `xn` 邻近，但流程如何解决继承争议不等于权限范围扩大。

## 8｜第三因素冻结

冻结：

- 宋江是否权谋；
- 金圣叹批语；
- 吴用是否暗中帮助宋江保位；
- 宋江谦让是否真心；
- 后续招安路线；
- 东平、东昌战役胜负本身。

只保留：

- 原主位可处分什么；
- 临时条件是否真实触发；
- 条件处理后谁继续拥有同一处分接口；
- 是否出现新的处分对象/权限范围。

结论仍稳定。
