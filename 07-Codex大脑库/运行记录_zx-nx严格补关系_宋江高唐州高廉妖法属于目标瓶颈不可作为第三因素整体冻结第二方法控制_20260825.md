# 《水浒传》宋江高唐州｜第三因素冻结有效性第二独立作品控制

## 0｜本轮问题

现有高唐州控制已经以事实 99 / 分类 98 锁定严格 `zx↔nx` 补：宋江的公开军事推进被高廉妖法这一当前现实瓶颈卡住；公孙胜的专属法术能力与罗真人真实放行/授法接口构成 `nx`，解除瓶颈后，宋江重新把条件兑现为同一救援攻城目标。

本轮不重复制造人物结论，只压力测试“第三因素冻结”方法：

> 如果为了排除共同第三因素，直接把“高廉妖法”整体冻结掉，再发现公孙胜/罗真人不再必要，能否据此否定原严格补？

结论：**不能。这样的冻结无效，因为它不是移除干扰，而是直接删除被测试的当前现实瓶颈。**

## 1｜剧情事实、触发、对象、动作、结果

### 触发与对象

- 宋江率梁山军攻高唐州，目标是救柴进并推进攻城。
- 高廉以异术实际阻断梁山普通军力与现有处理路径。
- 吴用识别需要寻找公孙胜。
- 公孙胜不能自行立即下山，需经过罗真人真实许可；罗真人第一次明确拒绝。
- 后来罗真人改为放行并授予破法所需法术。
- 公孙胜回军后破高廉法术，宋江继续推进，高唐州被攻入，柴进救援链恢复。

原著直接出现“高廉异术造成阻断”“罗真人先拒后放行授法”“公孙胜回军破法并使战役恢复推进”的连续事实链。

## 2｜zx 证据

本轮沿用既有锁定，不重新计新案例：

```text
宋江自己占据救柴进／破高唐方向
→ 公开率军推进
→ 被现实瓶颈卡住但方向未交出
→ 破解条件进入后重新传令推进
→ 作用范围继续进入高唐州
= zx 当前状态高显影
```

这里不是“宋江是首领所以 zx”；既有军令权属于 `x` 最近邻，`zx` 锁的是自身公开作用继续压入新的现实范围。

## 3｜nx 证据

同样沿用既有锁定：

```text
普通军力不能稳定处理高廉妖法
→ 专属破解能力不在宋江稳定处分范围
→ 公孙胜受罗真人真实许可约束
→ 必须经过外部专家／师门接口
→ 罗真人曾实际拒绝
→ 后来放行授法才恢复可用
= nx 关系功能
```

`nx` 不是宋江“没主见”，而是关键专业解决能力与许可仍在外部。

## 4｜关键压力

本轮必须把压力拆成两类：

### 4.1 被测试瓶颈

`高廉妖法使梁山现有普通军力无法稳定继续攻城救援`。

这是 `nx` 要直接补的**题目本身**。

### 4.2 可冻结干扰

例如：

- 高廉善恶评价；
- 宋江英雄/首领身份评价；
- 柴进私人关系价值；
- 妖法视觉奇观；
- 最终胜负已知；
- 公孙胜人物强弱评价；
- 吴用聪明与否。

这些都可冻结，因为冻结后 `zx`、`nx` 与“当前攻城被专属妖法卡住”仍留在桌面。

## 5｜拿掉测试

### 5.1 拿掉 nx

拿掉公孙胜、罗真人及等价专属破解接口：

- 宋江的 `zx` 方向仍在；
- 高廉妖法仍然卡住同一战役瓶颈。

`zx` 留下明确缺口。

### 5.2 拿掉 zx

只保留公孙胜会破法、罗真人愿意放行：

- 外部能力／许可仍存在；
- 但不会自动生成梁山公开攻城、救柴进的现实结果。

`nx` 端同样留下“条件无人兑现到同一战役目标”的缺口。

### 5.3 错误拿掉：把瓶颈本身删掉

如果直接设定：

```text
高廉妖法不存在／对普通军力完全无效
```

则：

- 宋江原本被测试的“现有军力无法穿透专属妖法”缺口被直接删除；
- 公孙胜/罗真人这一 `nx` 接口自然不再必要；
- 但这不是证明 `nx` 可替代，而是把需要 `nx` 的题目删掉了。

因此该操作不能计作有效第三因素冻结。

## 6｜反向测试

### 有效冻结

冻结“高廉很邪恶”“宋江与柴进关系深”“公孙胜很强”等外生叙事评价，同时保留：

```text
宋江 zx 方向
+ 高廉妖法造成的当前技术瓶颈
+ 公孙胜/罗真人 nx 接口
```

双向缺口仍存在，严格补不受影响。

### 无效冻结

若冻结动作直接使：

```text
当前妖法瓶颈消失
或
宋江救柴进/攻城 zx 端消失
或
公孙胜/罗真人 nx 端本身被删掉
```

则实验对象已被改写，不能据此判真补为伪补。

## 7｜最近邻排除

- `nx vs x`：公孙胜专属能力及罗真人放行/授法不在宋江稳定直接调用范围，不能判 `x`。
- `nx vs xn`：寻找公孙胜、安排戴宗李逵、传报节点可有 `xn`，但“为什么必须经过外部专属能力/许可”仍是 `nx`。
- `zx vs x`：宋江已有军令权是 `x`；公开军事作用继续推进到新的现实范围才是 `zx`。
- `第三因素 vs 目标瓶颈`：能被安全冻结的是外生干扰；若冻结后当前命名瓶颈本身消失，则该变量不是可冻结第三因素，而是实验题目组成部分。

## 8｜第三因素冻结有效性护栏

本例给出第二部独立作品方法控制：

```text
有效冻结必须同时保留：
1. zx 端独立成立；
2. nx 端独立成立；
3. 当前被命名的现实瓶颈仍存在；
4. 只移除制造表面反向需求的外生干扰。
```

如果冻结本身删除了第 1、2、3 任一项，就不是“排除第三因素”，而是“换题”。

与《三国演义》曹操陈留借卫弘家资的方法控制形成跨作品复验：

- 曹操案：不能把“启动资本不足”连同反董起兵题目一起冻没；
- 宋江案：不能把“专属妖法阻断”这个当前瓶颈整体冻没。

两例对象不同（启动资本 vs 专属技术/法术瓶颈），共同变量一致：**第三因素冻结不能删除被测试缺口本身。**

## 9｜稳定本体、当前状态与关系位置

- 宋江稳定人物本体：本轮不锁。
- 当前状态：`zx` 高显影，沿用既有控制。
- 行为功能：公开军事推进为 zx 显影。
- 关系位置：在专属破解能力/许可层真实 `nx`。
- 外部压力：高廉妖法是当前被测试瓶颈，不等于人物本体。

## 10｜结论

事实置信：99。
分类置信：98。

本轮锁定的不是新人物标签，而是方法边界：

> **第三因素冻结必须保留 zx、nx 与当前命名瓶颈；若冻结直接删除目标瓶颈本身，就不是控制变量，而是删除实验题目。**

当前该方法护栏已从《三国演义》扩展到《水浒传》第二部独立作品，但仍未达到跨 3 作品，因此不升级核心定义，不修改 L1、zx/nx 信息卡、准度卡或 `zx补nx_补卡`。
