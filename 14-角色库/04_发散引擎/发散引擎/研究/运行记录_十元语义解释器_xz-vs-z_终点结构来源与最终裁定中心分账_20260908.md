# 十元语义解释器｜xz vs z：终点结构来源与最终裁定中心分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元候选判定 → Z 发散器”。current canonical 永远高于本研究；不得覆盖 L1/L2 canonical，不得修改十元信息卡、准度卡、正式关系卡或行为 evidence 正本。

## 1. 本轮翻译债务

现有解释器已经有两个正确但仍不够机器稳定的结论：

- `z`：最高裁定中心/最终裁定点收束；
- `xz`：same-layer 的现实 path_set 在 current_window 内持续减少、汇流或失去回退接口。

剩余债务出在固定 IR 字段 `future_endpoint`：自然语言中“最终只会剩一个结果 / 最后只能去那里 / 最终确定为 B”都会让解释器填入一个 endpoint。若把 `future_endpoint != null` 当成 xz 证据，z 的一次最终裁定就会被误升级成 xz；反过来，如果把“只剩一个终点”理解成 z，又会把无人裁定的结构性收窄误写成最高裁定中心。

本轮新增：

```text
ENDPOINT_PROVENANCE_AUDIT_REQUIRED

future_endpoint 只是终态描述，不是十元标签。
必须追问终态是如何生成的：

A. adjudicated endpoint
   多个同层候选仍在线 -> 单一最终裁定中心作出 binding choice -> 一个结果生效
   = z candidate

B. structurally constrained endpoint
   多条同层现实路径 -> 随阶段真实关闭/汇流/失去回退 -> 剩余路径逼近终点
   = xz candidate

C. accidental / exogenous endpoint
   随机、事故、物理损坏、第三方突发删除让结果只剩一个
   = 不凭“唯一终点”锁 z 或 xz
```

固定 IR 不新增字段；endpoint provenance 必须编码进 `relation_source + relation_shape + current_window + path_set + decision_right + reality_anchor`。

## 2. 自然语言 → IR 结构还原规则

遇到“最终、最后、只能、必然、唯一结果、只剩、终局、无路可退、拍板”等语言时：

1. 锁 `actor/object/object_layer`，先确认是在同一候选裁定层，还是未来可选路径层；
2. `current_window` 必须覆盖 endpoint 生成前后，不能只截取最后一句；
3. `changed_variable` 分流：
   - `adjudication_center_distribution` → 查 z；
   - `real_option_set_contraction` → 查 xz；
   - 原因未知 → unknown，不猜；
4. `relation_source` 写 endpoint 的现实来源：final authority / staged closure / external accident / automatic rule / unknown；
5. `relation_shape` 区分 `multi_candidate_to_binding_choice` 与 `multi_path_to_progressive_convergence`；
6. `decision_right`：z 必须审计谁能让结果 binding；xz 可以没有单一最高裁定主体；
7. `path_set`：z 列裁定前仍具同等候选资格的结果路径；xz 必须列至少两个阶段的现实可行路径变化；
8. `future_endpoint` 只记录终态，不得单独产标签；
9. `reality_anchor` 必须证明 endpoint 的生成机制，而不仅是“最后确实只有一个结果”。

## 3. 标准输入与完整 IR

输入：

> “港口有三条撤离路线。台风逼近后，东线先因桥梁封闭退出，第二天北线渡轮停航，只剩西线仍可通行；气象部门不能决定哪条路关闭，它只是发布信息。另一个独立事项里，三家承包商都通过资格审查并保持有效投标，最终评审委员会有权从三家中指定一家中标，委员会一旦裁定，其余两家的本轮中标资格立即终止。”

### IR-A｜xz：结构性终点逼近

```yaml
actor: 港口撤离体系
object: 可现实使用的撤离路线
object_layer: 台风窗口内的撤离可选路径层
current_window: 三条可行 -> 东线关闭剩两条 -> 北线停航剩西线
changed_variable: real_option_set_contraction
relation_source: staged_external_closures
relation_shape: multi_path_to_progressive_convergence
Decision_right: none_single_final_adjudicator
path_set:
  - stage_0: [east, north, west]
  - stage_1: [north, west]
  - stage_2: [west]
reentry_right: closed_routes_not_currently_recoverable
future_endpoint: west_route_only_if_current_closure_state_continues
reality_anchor: 两次独立现实关闭使可走路线从3降到2再降到1，没有任何主体通过最终裁定选择西线
```

判定：**xz candidate PASS；z FAIL on this layer**。

### IR-B｜z：最终裁定生成唯一结果

```yaml
actor: 最终评审委员会
object: 本轮中标结果
object_layer: 三家有效投标的最终裁定层
current_window: 三家均保持有效 -> 委员会终审 -> 一家中标其余退出本轮资格
changed_variable: adjudication_center_distribution
relation_source: institutional_final_authority
relation_shape: multi_candidate_to_binding_single_choice
Decision_right: committee_single_final_adjudication
path_set:
  - bidder_A_valid_candidate
  - bidder_B_valid_candidate
  - bidder_C_valid_candidate
reentry_right: no_reentry_within_current_round_after_binding_award
future_endpoint: one_binding_winner_after_adjudication
reality_anchor: 裁定前没有候选路径逐步减少；委员会一次 binding choice 才使三家变成一家有效中标结果
```

判定：**z candidate PASS；xz FAIL/insufficient on this layer**。

## 4. Positive decision gates

### xz candidate gate

```text
XZ1 object_layer 是现实未来选项/路径/回退空间；
XZ2 current_window 至少含两个可比较的路径状态；
XZ3 path_set 在同层真实发生 3→2→1、2→1 或等价持续汇流/关闭；
XZ4 endpoint provenance 来自 staged contraction，而不是一次 final choice；
XZ5 reality_anchor 证明每次收窄都改变现实可行性；
XZ6 removal 某个收窄事件后，可选集应重新变宽或 convergence 减弱；
XZ7 `future_endpoint != null` 单独不足。
```

### z candidate gate

```text
Z1 object_layer 是答案/方案/裁决/标准/候选最终有效性层；
Z2 裁定前至少两个同层候选判断/结果仍具现实资格；
Z3 存在单一最高中心或最终 binding adjudicator；
Z4 decision_right 能使一个判断取得最终效力并排除同层竞争结果；
Z5 endpoint provenance 来自 binding adjudication，而不是自然路径耗尽；
Z6 removal 最终裁定中心后，原 binding 唯一结果不能以同样机制成立；
Z7 “最后只剩一个”本身不足。
```

## 5. nearest-neighbor 最小差异

### xz vs z

```text
xz：先看到“路怎么一条条少掉”，终点是路径结构逼出来的。
z：先看到“谁/什么拥有最后裁定权”，终点是 binding choice 定出来的。
```

最小反事实：

- 把最终裁定者撤掉，但现实路线仍会逐日关闭到一条 → xz 可保持，z 下降；
- 保留最终裁定者，但所有候选直到拍板前都完整在线 → z 可保持，xz 不成立。

### xz vs nz

`xz` 看 same-layer option set 的持续收窄；`nz` 看原对象特异关系的可执行回返/修复空间。一个入口当前关闭不自动 xz；一个人还能回来也不反向推出路径没有收窄。

### z vs xn

`z` 是最终裁定重心收束；`xn` 是运行、记录、顺序、规则节点形成可持续结构。复杂评审流程可以 xn，但只有 final binding center 才查 z。

## 6. false-positive guards

1. **关键词诱导**：“最后只能选A”不自动 z/xz，先查 endpoint provenance。
2. **题材/职业/情绪诱导**：国王、法官、医生、绝望、悲惨、胜利均不提供 gate。
3. **对象层错位**：技术迁移路线收窄不能证明管理委员会 z；委员会终审也不能证明技术路径 xz。
4. **时间窗错位**：只看最终阶段的单一路径，不能倒推之前发生 progressive contraction。
5. **同关系词异对象层**：“只剩一个”可能是候选被裁定排除，也可能是现实路径逐步关闭，必须拆层。
6. **对端不存在不等于本端成立**：没有最终裁定者不推出 xz；没有路径收窄也不推出 z。
7. **一次淘汰伪 xz**：一次投票从五案直接选一案是 z candidate，不因 5→1 表面计数变化就自动 xz。
8. **自然耗尽伪 z**：三条道路因天气逐条关闭到一条，没有任何 final adjudicator，不判 z。
9. **自动规则伪 z**：固定阈值机械筛掉候选，若没有单一最高裁定中心，不因结果 binding 就自动 z；按实际规则结构重建。
10. **future_endpoint 污染护栏**：`future_endpoint` 非空只说明可描述终态，不说明该终态由 xz 还是 z 生成。

## 7. removal / reverse / same-layer / current-window

### Removal

- xz：恢复北线渡轮。如果 path_set 从 `[west]` 变回 `[north, west]`，contraction 归因成立；评审委员会的 z 不受影响。
- z：取消委员会终审权，改为三家都继续有效直至另一个共同机制决定。若 binding 唯一结果消失，则 z 归因成立；港口路线 xz 不受影响。

### Reverse

- 保留“最后只有一家”字样，但改成委员会抽签且无任何主体拥有 final adjudication：z 需重判，不能吃词面。
- 保留“只剩西线”字样，但改成三条路从一开始就只有西线合法开放，current_window 没有收窄：xz FAIL/UNKNOWN。
- 把逐步关闭改为三条路线都持续可行，只由指挥官最终指定西线：xz 下降，z candidate 上升。

### Same-layer

比较 xz/z 时，必须在同一个 tested object_layer 内判断 endpoint 是“被路径结构逼近”还是“被最高裁定中心选定”。若一句话同时含撤离路径和合同裁决，必须 SPLIT_IR。

### Current-window

- 历史上路线曾收窄，但当前已恢复多路，不得继续贴 xz；
- 历史上某委员会曾终审，但当前改为多中心共同决定，不得继续贴 z；
- endpoint provenance 只认 current_window 内可验证机制。

## 8. adversarial tests

### T1｜关键词诱导
“主管说‘最后只能留一个’，但他无终审权；三个方案也没有逐步退出，最终由随机数抽一个。”
预期：**z FAIL/UNKNOWN；xz FAIL**。

### T2｜题材/职业/情绪诱导
“绝望的医生说病人只剩一种结局，但实际三种治疗仍同时可行，治疗方案由家属共同决定。”
预期：不能从职业/情绪/悲惨程度倒推 xz/z。

### T3｜对象层错位
“旧系统回退接口每周减少；董事会同时保留五人共同表决，没有单一终审者。”
预期：技术路径层 **xz candidate PASS**；董事会层不因同句出现‘最终迁移’而 z。

### T4｜时间窗错位
“今天只剩一条山路可走，但这条路过去三个月一直是唯一合法路线。”
预期：没有 current-window contraction，**xz FAIL/UNKNOWN**；也无 final adjudicator，z 不成立。

### T5｜同关系词异对象层
A：“三条撤离路逐日关闭到一条。” → xz candidate。
B：“三名评委意见都有效，主席最终指定一案。” → z candidate。
同一个“最后只剩一个”不得共享 IR。

### T6｜对端不存在不等于本端成立
“委员会解散，所有路线也因资料不足无法判断是否开放。”
预期：z 不成立不能推出 xz；xz 不可判也不能推出 z。

### T7｜一次裁定伪 xz
“五个剧本一直都可提交，制片人周五一次终审选B，其余立即出局。”
预期：**z candidate PASS；xz FAIL/insufficient**，5→1 是裁定结果，不是 staged path contraction。

### T8｜自然耗尽伪 z
“三家供应商中两家先后因破产和许可证失效退出，只剩A；无人拥有把A裁成唯一赢家的终审权。”
预期：仅凭结果唯一 **z FAIL**；是否 xz 取决于 tested layer 是否是现实候选路径并存在跨阶段 contraction，不能自动贴。

### T9｜自动阈值
“系统按预先固定阈值逐轮淘汰方案，任何人都不能覆盖规则。”
预期：不因最终一案判 z；若 same-layer 可行路径确实逐轮减少，可查 xz，但需 reality anchor 与 current_window。

### T10｜裁定中心存在但路径未收窄
“三个方案直到最后一分钟都保持完整资格，最高法院终审后只让A生效。”
预期：**z PASS / xz FAIL**。

### T11｜收窄与裁定分阶段共存
“三条路线先因现实条件缩成两条，随后指挥官从剩余两条中终审指定一条。”
预期：同一大事件中可出现前段 xz + 后段 z，但必须按 current_window 分段，不得用一个 future_endpoint 吞掉两个机制。

### T12｜终点预测伪证据
“分析师预测最终都会迁到新平台，但当前所有旧接口仍有效，也没人拥有强制最终裁定权。”
预期：future endpoint 只是预测，**xz/z 均 FAIL/UNKNOWN**。

## 9. 状态迁移规则

新增两条独立状态轨：

```text
OPTION_SET_STATE:
multiple_real_paths
-> fewer_real_paths
-> one_real_path
= xz candidate 上升
```

```text
ADJUDICATION_STATE:
multiple_valid_candidates
-> binding_final_center_acts
-> one_binding_result
= z candidate 上升
```

关键不变量：

```text
one endpoint != z automatically
one endpoint != xz automatically
future_endpoint != provenance
count reduction caused by adjudication != staged path contraction
```

## 10. 成功门与结论

本轮不是重复“z 是裁定、xz 是收窄”定义，而是新增固定 IR 的机器约束：

1. `ENDPOINT_PROVENANCE_AUDIT_REQUIRED`；
2. `future_endpoint` 从判定证据降为终态描述，必须由其他字段证明来源；
3. 明确 `count reduction caused by binding adjudication` 不得伪装成 xz path contraction；
4. 新增 z/xz 分阶段共存状态迁移规则；
5. 新增 future_endpoint 污染类 adversarial negatives。

结论：**PASS，可提交 research-only candidate。**

## 11. 下一轮最高翻译风险

本轮占用 `xz / z`，下一轮避开两者。当前优先检查 `zx vs x并z`：自然语言里的“公开代表 / 对外发声 / 把自己的方向推到外部”容易把公共壳的第三方可调用性与主体权能向外推进混在一起。下一轮应优先审计 `external_visibility` 到底改变的是 `public_interface_mapping`，还是 `actor_directional_power_distribution`。
