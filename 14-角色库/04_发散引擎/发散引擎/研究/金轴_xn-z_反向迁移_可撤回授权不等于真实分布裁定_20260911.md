# 金轴 xn↔z｜反向迁移：可撤回授权不等于真实分布裁定

> L4 research-only。本文件只测试 `z → xn` 的最小反向迁移，不修改 L1/L2 canonical、信息卡、准度卡、关系卡或行为 evidence 正本。

## 0｜本轮缺口

上轮已验证 `xn → z`：多个局部 binding gate 若被一个中心取得同层全面覆盖与最终否决权，裁定重心会从分布结构坍缩为单一中心。

本轮只解决反方向：

> 一个最高中心把任务、审核或判断下放给多个节点时，何时仍只是 `z` 的代理展开，何时才真正成为 `xn`？

新增候选门：

`DELEGATION-INDEPENDENCE-GATE-v0.1`

核心变量：`local_binding_independence`。

## 1｜current criterion

current canonical：

- `xn`：运行权/判断权分布到顺序、规则、记录、节点与流程；
- `z`：判断权与结构重心收束到单一最高中心或最终裁定点。

本轮操作化：

```text
多节点 + 权限可被一个中心在同层同窗内随时收回/覆盖
→ 仍是 z

多节点 + 局部结果不依赖中心持续许可
+ 同层不可被一个中心任意收回/覆盖
+ 能独立触发现实状态迁移
→ xn candidate
```

## 2｜strict 同层同窗最小差异对

固定系统：同一动画项目发布资格审查。固定 actor、object、object_layer、current_window、三个审核节点、顺序、记录和输出。只改变局部 binding effect 的独立性。

### T2｜真 xn：局部 binding effect 脱离中心持续许可

三门的当前轮效力不依赖 director 持续授权。任一门在自身对象范围内都可直接触发返工或停止当前轮推进；director 没有同层覆盖权，只保留全部通过后的执行动作。

```yaml

object: same
object_layer: same
current_window: same
changed_variable: local_binding_independence
relation_source: rule_grounded_nonrevocable_local_authority
relation_shape: multiple_binding_local_nodes_without_same_layer_override
decision_right: distributed_local_binding
path_set: [safety_gate, budget_gate, copyright_gate]
reentry_right: failed_item_reenters_after_repair_and_new_round
future_endpoint: 三门全部通过后进入执行
reality_anchor: 任一门失败都独立改变当前轮现实状态，director 不能同层收回或覆盖
```

判定：`xn PASS 0.98`；`z FAIL 0.96`。

## 3｜最小判别式

```text
revocable delegated authority ≠ distributed authority
```

真正的最小开关：

```text
局部现实效力是否仍依赖单一中心的持续许可。
```

若依赖且同层可撤回，仍是 `z`；若不依赖、不可被同层单中心任意覆盖，且多个节点各自能改变现实状态，支持 `xn`。

## 4｜nearest-neighbor / removal / reverse / freeze-third-factor

**nearest-neighbor**：T0 与 T2 节点数量、人员、步骤、记录、输出全部相同，只差 `local_binding_independence`。

**removal**：T0 拿掉 director 的同层撤回/覆盖权，若三门结果仍生效，则 z 的关键来源消失；T2 拿掉局部门独立 binding effect，只保留上报，则 xn 消失。

**reverse**：保留“授权、分权、多部门、委员会”等词，但允许 director 同层无条件收回，仍判 z；删除这些词，只保留多个节点不可被单一中心覆盖的独立现实效力，仍判 xn。

**freeze-third-factor**：actor、object、object_layer、current_window、人员、节点数、顺序、材料、记录和输出冻结。只改变：

```text
same_layer_revocability: true -> false
local_binding_independence: false -> true
```

## 5｜正反控制

**正控 xn**：工程发布流程中多个 required checks 各自能直接阻止当前轮继续，执行负责人不能跳过失败门。

**正控 z**：多个检查只产出报告，最后一个中心可以在当前轮统一决定是否采纳。

**反控 1**：工作任务分给三个人，但三人只能执行和汇报，没有独立状态迁移权，不能判 xn。

**反控 2**：咨询委员会可投票形成建议，但结果可被最高中心完整忽略，仍是 z。

**反控 3**：A 临时代理 B 做最终裁定，只是单中心身份更换，不是分布裁定。

**反控 4**：当前轮是 xn，但中心能改下一轮制度，应做 current-layer xn / meta-layer z 的 SPLIT_IR，不能跨层倒灌。

## 7｜失败类型

- `REVOCABLE_DELEGATION_AS_XN`：可随时收回的下放误判 xn。
- `TASK_DISTRIBUTION_AS_AUTHORITY_DISTRIBUTION`：任务分开误判权力分布。
- `CONSULTATION_AS_BINDING_DECISION`：建议/投票输入误判为现实裁定源。
- `TEMPORARY_PROXY_AS_DISTRIBUTED_CENTER`：代理人替班误判多中心。
- `META_POLICY_POWER_AS_CURRENT_ROUND_OVERRIDE`：未来规则修改权误判当前轮覆盖权。
- `CURRENT_ROUND_XN_ERASED_BY_META_Z`：元层 z 倒灌抹掉当前层 xn。
- `EXECUTION_RIGHT_AS_DECISION_RIGHT`：执行动作误判裁定权。

## 8｜结论与成熟度

本轮独立支持 `z → xn`：

> **单中心把任务或判断下放给多个节点，只要这些节点的现实效力仍可被该中心在同层同窗内无条件收回或覆盖，就仍是 z 的代理展开；只有多个节点获得不依赖单一中心持续许可、且同层不可被其任意收回/覆盖的 binding effect，才构成真正的 xn。**

与上轮合并后形成双向迁移：

```text
xn → z：局部 binding effect 被单中心全面覆盖
z → xn：局部 binding effect 脱离单中心可撤回许可，恢复多个独立现实效力源
```

这与 current canonical 的“运行权与裁定重心配置”一致，无需修改 L1。

研究层成熟度：`7.6 -> 8.0 / 10`。

下一断点：只测试“多数投票 / 多签 / quorum 是否天然构成 xn”，重点区分多签机械满足单一规则与多个签署节点各自不可替代的 binding effect，并检查 tie-breaker / chair veto 何时把结构重新拉回 z。
