# 十元语义解释器｜zn vs nx：主动保存他者资格与外部方向不占位分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元候选判定 → Z 发散器”。current canonical 永远高于本研究；不得覆盖 L1/L2 canonical，不得修改十元信息卡、准度卡、正式关系卡或行为 evidence 正本。

## 1. 本轮目标与翻译债务

目标混淆对：`zn vs nx`。

当前高风险自然语言包括：“我不干涉你”“由你决定”“我听你的”“你自己选”“我尊重你的决定”“按你的方案走”。这些句子共享一个表面现象：actor 没有把自己的决定压到 other 上。但 canonical 所测变量不同：

- `zn`：actor 自己成立，同时**实际保存他者作为独立对象继续成立的资格/路径**；
- `nx`：actor **不占最终方向位置**，并沿外部已有方向、关系、权限或通道推进。

因此不能从“actor 没干涉”直接推 `zn`，也不能从“别人决定”直接推 `nx`。

本轮新增候选规则：`PRESERVATION-ACT-vs-NONOCCUPATION-ROUTE-v0.1`。

核心区分：

```text
NONINTERFERENCE_CAUSE_AUDIT_REQUIRED

同样表现为“我没有改你的决定”，先问原因：
A. actor 有能力/位置影响该同层资格，却存在现实边界、承诺或制度，使 other 的独立资格被保存
   -> 可进入 zn gate
B. actor 本来就不占该方向/权限位置，并且自己沿 other/external 已给出的路线推进
   -> 可进入 nx gate
C. actor 只是没注意、没能力、不同层无权、临时不行动
   -> 两边都不能据此 positive
```

这条规则不是新增 canonical 字段，而是强制利用现有 `object_layer / relation_source / decision_right / path_set / reality_anchor` 还原“不干涉”的因果来源。

## 2. 自然语言 → Semantic IR 结构还原规则

固定先抽 IR，再判十元：

1. `actor`：当前被判主体；不要把双方整体写成 actor 后丢失谁在让位/保存谁。
2. `object`：锁定“被保存的他者资格”或“actor 正在推进的外部方向/任务”，不得用“关系很好”代替对象。
3. `object_layer`：优先区分“他者独立选择资格层”与“actor 自己的任务方向/执行通道层”。一句话跨层必须 `SPLIT_IR`。
4. `current_window`：只取保存资格或沿外部路线真实发生的窗口。历史上的尊重、服从、授权不自动延续。
5. `changed_variable`：优先填写 `independent_endpoint_preservation`、`external_direction_route_activation`、`decision_right_distribution` 或 `unknown`。
6. `relation_source`：记录 tested direction/path 来自 self / external / shared / unknown。`external` 只说明来源，不等于 nx positive。
7. `relation_shape`：优先区分 `self-plus-other-independent`、`actor-follows-external-direction`、`tolerated-but-unprotected`、`no-authority-to-interfere`、`unknown`。
8. `decision_right`：必须写清“谁对谁的对象层有最终决定资格”。`other_on_other` 不等于 `actor_follows_other`。
9. `path_set`：zn 至少需要 `self_path + other_independent_path`；nx 至少需要一条 actor 实际采用的 `external_route`。不能拿同一条 path 同时充两边证据。
10. `reentry_right`：若涉及退出后恢复资格才填写；本轮无证据时保持 null/unknown。
11. `future_endpoint`：只有文本真的锁终局才填；不得从“听你的”猜长期归向。
12. `reality_anchor`：zn 要证明 actor 的边界使 other 的独立资格现实存活；nx 要证明 external route 的接受/拒绝能现实改变 actor 的推进。

### 新 IR 约束：CAPACITY-AND-ATTRIBUTION AUDIT

`zn` 的 other endpoint 存活不能只看结果，还要检查 attribution：

```text
ZNA1 other endpoint 当前确实存在；
ZNA2 actor 与该 same-layer endpoint 存在可辨认的关系边界，而非完全无关；
ZNA3 other endpoint 的存活可归因于 actor 所维持/承认的边界、共同规则或不可单方吞并结构；
ZNA4 若 actor 在该层从来没有干预资格，不能把“没干涉”记成 actor 的 zn 保存证据；
ZNA5 若 actor 有干预资格却只是暂时没动作，也不能仅凭静默 positive，必须有稳定 boundary / decision-right evidence。
```

这把“主动保存/结构性保存”与“无能力干涉/纯没动作”正式拆开。

## 3. 标准输入与完整 IR

输入：

> “联合工作室里，林澈和周宁各自拥有自己产品线的最终选题权。林澈坚持实验动画线，同时共同章程规定他不能撤销周宁商业线的预算、账号和发布资格；周宁也能拒绝林澈对自己产品线的改题要求。另一方面，林澈负责的一次联合发布必须采用周宁已经确定的上线日期，林澈没有改期权；他接受这个日期后，再自己安排当天的现场人员。”

必须拆成两个 IR。

### IR-A｜他者独立资格保存层

```yaml
actor: 林澈
object: 周宁商业短片线的独立选题与继续运营资格
object_layer: 同一工作室内各产品线独立决定资格层
current_window: 双方路线并存 -> 林澈坚持自身路线 -> 周宁路线继续保有资格
changed_variable: independent_endpoint_preservation
relation_source: shared_constitutional_boundary
relation_shape: self-plus-other-independent
decision_right: self_on_self_route + other_on_other_route
path_set:
  - self_path: 林澈继续决定实验动画线
  - other_independent_path: 周宁继续决定商业线选题并保有预算账号发布资格
reentry_right: null
future_endpoint: null
reality_anchor: 共同章程阻止林澈单方撤销周宁同层资格，周宁可现实拒绝林澈对自身产品线的改题
```

判定：`zn candidate PASS`。

关键不是“林澈不干涉”，而是 other endpoint 的决定权与运行路径在 same layer 被现实保存，并且存在可验证边界。

### IR-B｜联合发布外部方向层

```yaml
actor: 林澈
object: 本次联合发布的上线日期
object_layer: 联合发布最终日期决定与执行方向层
current_window: 周宁确定日期 -> 林澈接受该日期 -> 按该日期准备发布
changed_variable: external_direction_route_activation
relation_source: external
relation_shape: actor-follows-external-direction
decision_right: external_final_on_release_date
path_set:
  - external_route: 周宁给定上线日期
  - actor_adopts_route: 林澈按该日期推进发布
reentry_right: null
future_endpoint: release_on_given_date
reality_anchor: 林澈没有改期权；若周宁改变日期，林澈的本次发布时间随之改变
```

判定：`nx candidate PASS`。

“林澈自己安排现场人员”属于局部运行结构层，另查 xn，不抹掉日期方向层 nx。

## 4. Positive decision gates

### zn candidate gate

```text
ZN1 object_layer + current_window 明确；
ZN2 self endpoint 可辨认且 actor 自身继续成立；
ZN3 other endpoint 可辨认且拥有同层独立 decision_right/path；
ZN4 path_set 至少包含 self_path + other_independent_path；
ZN5 other endpoint 的存活不是 actor 无能力、无关系、没注意或纯静默造成；
ZN6 存在 shared/actor-maintained boundary，使 actor 不能把 other 的同层资格吸收到自身；
ZN7 reality_anchor 证明 other 可以现实拒绝、继续、选择或运行；
ZN8 removal 保存边界后，other endpoint 出现可命名现实缺口。
```

### nx candidate gate

```text
NX1 object_layer + current_window 明确；
NX2 tested direction/permission/path 已由 external/relationship/process 给出；
NX3 actor 在该 tested layer 不占 final direction right；
NX4 actor 实际接受并沿至少一条 external_route 推进；
NX5 external route 在当前窗口可现实约束 actor，而非纯建议/背景；
NX6 removal external route 后，同层推进出现现实缺口或必须重建方向；
NX7 “我让你自己决定”若 actor 自己没有沿该决定推进，不足以凭 other_on_other 判 nx；
NX8 external source 仅存在但 path 未激活，不判 positive。
```

## 5. nearest-neighbor 最小差异

### zn vs nx

最小差异：

```text
zn: 我有我自己的 endpoint，同时你保有你自己的 endpoint。
nx: 当前这个 tested direction 不是我最终决定，我沿你/外部已经给出的 route 推进。
```

`other_on_other` 与 `actor_follows_other` 必须分开。

### zn vs x

`zn` 保存他者独立资格；`x` 把对象纳入主体归属/调用/处分边界。主体“允许”他者暂时使用自己可随时撤回的资源，不足以证明 zn。

### nx vs xn

`nx` 问方向/权限/外部通道从哪里来且 actor 是否沿它推进；`xn` 问 actor 是否主动搭建运行顺序、记录、节点和流程。可出现“外部日期 nx + 本地排班 xn”分层并存。

## 6. false-positive guards

1. **不干涉词护栏**：“随你、你决定、我不管、我尊重”只触发 IR 抽取，不触发 zn。
2. **无权干涉护栏**：actor 从来没有该层权限，不能把“没阻止”记成其 zn 保存行为。
3. **静默护栏**：actor 有权但本次只是暂时没动作，且无稳定 boundary，不足以 positive zn。
4. **别人决定护栏**：other 对自己的事自己决定，不等于 actor 的 nx；只有 actor 自己沿该 external direction 推进才检查 nx。
5. **外部来源护栏**：relation_source=external 不等于 nx；route 必须 current-window activated。
6. **建议护栏**：actor 听取建议后仍拥有完整否决和改写权，不能只因“听了你的”判 nx。
7. **对象层护栏**：保留他者选题权与接受他者为联合发布定日期可能在两个层同时发生，必须拆 IR。
8. **题材护栏**：民主、婚姻、友情、自由职业、温柔情绪都不能倒推 zn；秘书、士兵、下属等身份也不能倒推 nx。
9. **结果并存护栏**：两条路线碰巧同时存在但互不相关，不能硬拼 zn。
10. **对端缺席护栏**：zn FAIL 不推出 nx；nx FAIL 不推出 zn。

## 7. removal / reverse / same-layer / current-window

### Removal

- `zn removal`：拿掉阻止 actor 吞并 other endpoint 的现实边界；若 other 仍完全独立且与 actor 无关，原 zn attribution 下降；若拿掉后 actor 可现实撤销 other 同层资格，则保存边界有效。
- `nx removal`：拿掉 external direction/permission route；若 actor 仍以同一路径、同最终方向稳定推进且无需等价外部来源，则 nx 证据下降。

### Reverse

- 保留“我尊重你”字样，但改成 actor 本来就无权触碰 other 的对象层，且双方毫无关系：zn 必须 FAIL/UNKNOWN。
- 保留“我听你的”字样，但 actor 可随时改写最终方向且这次只是巧合采用建议：nx 必须 FAIL/弱。
- 保留 same-layer 双端独立资格，同时让 actor 不沿 other 方向推进：可 zn，不应硬判 nx。
- 保留 external route 且 actor 真实沿它推进，但 external actor 自己并没有因主体保存而获得独立资格：可 nx，不应硬判 zn。

### Same-layer

必须比较同一个 tested object_layer：

- “周宁对自己的产品线有独立选题权”是 independent endpoint 层；
- “林澈此次联合发布的日期由周宁决定”是林澈自身任务方向层。

两句都出现“周宁决定”，但第一句主要回答 other 是否独立成立，第二句回答 actor 是否沿 external direction 推进。

### Current-window

去年双方各自独立不代表今年仍 zn；去年总听某人安排也不代表当前仍 nx。必须重新确认 current window 的 boundary 与 activated route。

## 8. adversarial tests

### T1｜关键词诱导
输入：“他说‘你的事你自己决定’，其实两人根本不认识，他也没有任何权限或关系能影响对方。”
预期：`zn FAIL/UNKNOWN`；`nx FAIL`。不干涉词不能创造保存关系。

### T2｜题材/职业/情绪诱导
输入：“温柔的军官尊重士兵的人生选择，但这次撤离路线仍由军官本人最终决定并执行。”
预期：人生选择层若无实际保存边界证据，zn 不自动成立；撤离方向层 nx FAIL。温柔/军官/尊重都不触发标签。

### T3｜对象层错位
输入：“主编不能改作者署名，作者保有署名最终决定权；但本期封面日期由主编确定，作者按这个日期交稿。”
预期：署名资格层可查 `zn`；作者交稿日期方向层可查 `nx`。必须 SPLIT_IR。

### T4｜时间窗错位
输入：“去年合伙协议保证双方独立产品线；今年协议已废止，A 可以单方关闭 B 的项目，而 B 也不再参与 A 的发布安排。”
预期：当前旧 `zn` 不得沿用；没有 activated external route 也不能补 `nx`。

### T5｜同关系词异对象层
A：“经理说‘你自己决定作品主题’，合同也规定经理无权撤销作者的署名与发表资格。”
B：“经理说‘这个项目你自己决定上线日’，随后经理自己的宣传活动必须跟随该上线日，且不能改期。”
预期：A 的他者独立资格层可查 `zn`；B 对经理自身宣传日期方向层可查 `nx`。同样“你自己决定”不能共用标签。

### T6｜对端不存在不等于本端成立
输入：“她没有控制别人的资格，也没有沿任何人的路线推进，只是退出项目并停止行动。”
预期：`zn FAIL/UNKNOWN`，`nx FAIL/UNKNOWN`。一个端点缺席不能补另一个端点。

### T7｜无权干涉伪 zn
输入：“房东说‘我从不干涉你的职业’，但职业选择从来不属于租赁合同或房东权限范围。”
预期：tested 职业层 `zn FAIL/UNKNOWN`。这是 no-authority-to-interfere，不是 actor 保存了职业独立资格。

### T8｜建议采纳伪 nx
输入：“导演听演员建议，把镜头改成近景；导演始终有完整最终剪辑权，也可以立刻改回远景。”
预期：`nx FAIL/弱`。采用建议不等于 actor 不占最终方向。

### T9｜zn 强、nx 弱
输入：“两位联合创始人各自拥有自己产品线的最终否决权，任何一方都不能取消另一方资格；双方本季也完全没有互相替对方定任务方向。”
预期：独立资格层 `zn candidate PASS`；没有 actor-follows-external-route，`nx FAIL`。

### T10｜nx 强、zn 弱
输入：“助理必须按法务给定的模板和审批结果提交文件，法务拒绝就不能提交；助理并没有保存法务作为独立对象的任何资格，法务权来自制度本身。”
预期：提交方向/权限层 `nx candidate PASS`；`zn FAIL/不适用`。

## 9. 状态迁移规则

新增解释器状态迁移候选：

```text
STATE A: no-authority-to-interfere
  other endpoint 存在，但与 actor tested boundary 无归因
  -> zn 不得 positive

STATE B: tolerated-but-revocable
  actor 有权撤销，暂时未撤，且无稳定 boundary
  -> zn 仍不足

STATE C: protected-independent-endpoint
  stable boundary + other decision_right + executable path
  -> zn candidate 上升

STATE D: actor-adopts-external-direction
  actor 自身 tested task 的 final direction 外置并实际沿 route 推进
  -> nx candidate 上升
```

状态 C 与 D 可分层并存，但不能因一个状态存在就推另一个。

## 10. 成功门结论

本轮 **PASS**。

新增信息不是案例数量，而是：

1. `NONINTERFERENCE_CAUSE_AUDIT_REQUIRED`：不干涉必须追因果来源；
2. `CAPACITY-AND-ATTRIBUTION AUDIT`：zn 保存证据必须排除“本来无权干涉”；
3. `other_on_other != actor_follows_other`：他者自决与主体沿他者方向推进正式拆开；
4. `no-authority -> tolerated-revocable -> protected-independent` 的状态迁移约束；
5. 新 adversarial negatives：无权干涉伪 zn、建议采纳伪 nx。

以上均为 research-only candidate，不覆盖 current canonical。

## 11. 下一轮风险

本轮使用 `zn` 与 `nx`，下一轮不得继续选择这两个十元。

下一最高翻译风险候选：`zx vs xn`。

风险点：自然语言中的“我来安排 / 我定规则 / 我把事情做成”既可能是 `xn` 的运行结构生成，也可能是 `zx` 的自身方向/权能向现实压入。下一轮应优先用 `changed_variable + decision_right + relation_shape` 区分“组织运行方式”与“扩张/确立自身最终方向”。
