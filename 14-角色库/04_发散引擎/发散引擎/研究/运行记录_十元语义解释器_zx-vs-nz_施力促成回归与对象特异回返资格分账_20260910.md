# 十元语义解释器｜zx vs nz：施力促成回归与对象特异回返资格分账

> research-only。只服务 `自然语言 -> Ten-Yuan Semantic IR -> 十元判定 -> Z 发散器`。current canonical 永远高于本文件。本记录不得反向覆盖 canonical。

## 1｜本轮翻译债务

高风险自然语言：

```text
“我把他追回来了。”
“我硬把局面救回来了。”
“我打通了回去的路。”
“最后他还是回到我这里。”
```

这些句子把至少两件事压成一个“回来”：

1. **return cause**：是谁以自己的力量改变现实方向，使“回归”这个结果发生；
2. **return right / return position**：对象特异关系是否本来就保存、恢复或重建了一个可自愿调用的回返位置。

因此新增：

```text
RETURN-CAUSE-vs-RETURN-RIGHT-v0.1
RETURN-AGENT-vs-RETURN-HOLDER_AUDIT_REQUIRED
VOLUNTARY-REENTRY-vs-FORCED-RELOCATION_AUDIT_REQUIRED
CAUSE-REMOVAL-vs-RIGHT-REMOVAL_AUDIT_REQUIRED
```

核心不变量：

```text
actor caused return
!=
object held a return right

forced back into same place
!=
credible nz reentry

credible return path exists
!=
some actor publicly expanded power
```

## 2｜自然语言 -> IR 结构还原规则

解释“回来/追回/救回/带回/打通回路”时，不得把 `reentry_right` 当作“最终回来了”的结果字段。

必须按以下顺序拆：

```text
A. actor：谁被测？施力者、返回者、关系本身必须分角色。
B. object：是“返回事件结果”，还是“原对象特异关系中的返回位置”？
C. object_layer：现实方向改变层 vs 对象特异关系回返层。
D. current_window：施力发生窗口与关系回返资格有效窗口分别冻结。
E. changed_variable：
   - zx 候选查 self-attributable power / influence / direction scope 是否扩大并压入现实；
   - nz 候选查 object-specific reentry recoverability 是否保存/恢复/重建。
F. relation_source：返回结果来自主体直接施力，还是来自 standing relation / 双方修复接口。
G. relation_shape：强制迁移/压回 vs 自愿离开后可调用的返回/修复位置。
H. decision_right：施力者是否扩大现实决定范围；返回者是否拥有拒绝、离开、返回资格。
I. path_set：
   - zx 只记录主体实际部署的现实作用路径；
   - nz 只记录退出、保留位置、修复、重新进入同一对象特异关系的路径。
J. reentry_right：只描述返回者/关系持有的回返资格；禁止写成“施力者能把人带回来”。
K. future_endpoint：zx 记录现实权能作用后的方向终点；nz 记录回返窗口/关系位置是否继续有效。
L. reality_anchor：分别证明“谁的权能改变了现实”与“对象是否能自愿回到原关系”。
```

### 新字段纪律

以下写法视为 schema-role error：

```yaml
reentry_right: 我能强行把他带回来
reentry_right: 老板能命令他回来
reentry_right: 警察能押他回来
```

这些是 `decision_right / relation_source / relation_shape` 的候选事实，不是 nz 正证据。

## 3｜标准输入

> 乐队主唱陈岚三个月前主动退出原乐队。乐队章程与成员实践一直保留“原成员一年内可恢复原席位”的位置，陈岚可以拒绝返回，也可在期限内主动恢复。演出前，制作人林澈发现主唱临时缺位，他公开动用自己的制作资源、合同协调权和媒体承诺压下两个反对方，连续改排练计划、调预算、逼合作场地方重新排期，最终让陈岚愿意回来。陈岚回来后恢复的是原乐队原席位，而不是重新竞聘一个同类岗位。

必须 `SPLIT_IR`。

## 4｜完整 IR-A：zx

```yaml
actor: 林澈
object: 让陈岚回归成为当前演出可实现方向这一现实结果
object_layer: self_power_to_real_direction_change_layer
current_window: 主唱缺位 -> 两方反对 -> 林澈公开调资源/合同/排期 -> 反对结构被压过 -> 回归成为现实可执行方向
changed_variable: actor_public_power_and_influence_scope_on_current_return_outcome
relation_source: actor_deployed_own_production_resources_contract_coordination_and_public_commitment
relation_shape: self_attributable_power_enters_reality_and_forces_surrounding_structure_to_react_until_return_direction_becomes_executable
decision_right: actor_expands_current_coordination_and_resource_decision_scope_but_does_not_own_chenlan_personal_return_consent
path_set:
  - reallocate_rehearsal_schedule
  - redirect_budget
  - renegotiate_venue_timing
  - publicly_commit_to_return_plan
  - override_or_outmaneuver_two_current_objections
reentry_right: null
future_endpoint: chenlan_return_becomes_current_executable_outcome
reality_anchor: 林澈公开部署自身资源与协调权后，反对方和场地方被迫重新反应，原本无法落地的回归方向变成现实可执行
```

判定：**zx PASS candidate**。关键不是“追回来了”，而是主体权能公开显现、现实作用范围扩大、环境围绕其力量重新反应。

## 5｜完整 IR-B：nz

```yaml
actor: 陈岚与原乐队之间的对象特异成员关系
object: 陈岚退出后一年内恢复原乐队原席位的可信回返位置
object_layer: object_specific_relation_reentry_layer
current_window: 原成员在队 -> 主动退出 -> 三个月分离 -> 一年回返窗口仍有效 -> 自愿决定返回 -> 恢复原席位
changed_variable: object_specific_reentry_recoverability
relation_source: prior_specific_membership_plus_standing_return_practice
relation_shape: prior_specific_relation_to_free_exit_to_preserved_return_position_to_voluntary_same_relation_reentry
decision_right: chenlan_retains_refusal_and_return_choice; producer_cannot_substitute_personal_return_consent
path_set:
  - prior_membership_in_same_band
  - voluntary_exit
  - one_year_return_window
  - voluntary_return_choice
  - restore_same_original_seat
reentry_right: chenlan_holds_object_specific_voluntary_return_right_within_one_year
future_endpoint: return_position_expires_after_one_year_if_not_exercised
reality_anchor: 陈岚可以拒绝返回；其回来恢复的是退出前同一乐队原席位，并有既存的一年回返规则与共同实践支持
```

判定：**nz PASS candidate**。

## 6｜Positive decision gate

### zx positive gate

```text
IF actor/object/object_layer/current_window 明确
AND relation_source 能归因于主体自身现实权能
AND 主体权能公开进入现实
AND same-layer influence/decision scope 实际扩大
AND environment/others 因该权能重新反应
AND removal 主体直接权能后该现实方向显著失去可执行性
THEN zx candidate PASS
ELSE KEEP_UNKNOWN / FAIL
```

### nz positive gate

```text
IF prior object-specific relation 真实存在
AND 存在真实退出/分离或关系受损
AND 返回目标是同一原关系或可识别修复位置
AND 返回者拥有自愿离开/拒绝/回返资格
AND reentry path 可现实调用而非单方想象
AND removal standing return/repair position 后回归只能变成新申请、求人特批或强制迁回
THEN nz candidate PASS
ELSE KEEP_UNKNOWN / FAIL
```

## 7｜Nearest-neighbor 最小差异

### NN1｜同样“把他带回来”：强制迁回 vs 自愿回返

A. “老板用合同处罚逼离职成员必须回来，不回就扣全部尾款。”

```text
返回结果可能由 actor 强力促成
→ zx 可查
但自由退出/拒绝权被破坏
→ nz FAIL/下降
```

B. “老板什么也没做，原成员按既存一年回返权主动恢复原席位。”

```text
nz PASS
zx 不自动成立
```

最小差异：**return cause 是否来自施力者；return right 是否由返回者/关系持有。**

### NN2｜同样“打通回去的路”：现实障碍清除 vs 关系位置存在

A. “林澈用自己的权限压下封锁、恢复航班，让陈岚物理上能回城；但原乐队明确不再接纳。”

```text
现实方向改变可查 zx
nz FAIL
```

B. “交通一直畅通，但乐队明确保留原席位和修复接口，陈岚随时可自愿恢复。”

```text
nz PASS
zx 不自动成立
```

### NN3｜zx vs nx 防串账

如果“回归”只能靠求人调用别人独有权限，优先查 nx；只有 tested actor 自身权能公开显现并扩大现实决定范围，才查 zx。

### NN4｜nz vs x 防串账

如果“回来”是因为不能自由离开、资源被扣留、身份被掌握，优先查 x / x克nz 风险，不得把被迫返回当高 nz。

## 8｜False-positive guards

```text
“追回来了” != zx
“回来了” != nz
“打通回去的路” != nz
“他最终回到我身边” != nz
“我很强势地挽回关系” != zx
一次说服成功 != stable zx
同一个地点重新出现 != same relation reentry
强制返回 != credible nz
主体为回归投入很多资源 != 返回者拥有 reentry right
返回者拥有 standing return != 存在 zx actor
zx FAIL != nz PASS
nz FAIL != zx PASS
```

额外 guard：

```text
outcome_same_as_before
!=
relationship_restored
```

对象被物理放回原地点、重新挂回同名职位、恢复旧账号，都必须继续审计 object identity / relation continuity / voluntary reentry，不能靠“看起来回去了”判 nz。

## 9｜Adversarial tests

### T1｜关键词诱导
“我终于把她追回来了，她还是回来了。”没有权能扩大、原关系、自由退出或回返规则事实。
- expected: zx UNKNOWN; nz UNKNOWN。

### T2｜题材/职业/情绪诱导
“霸道总裁冒雨追回前任，哭着说永远别走。”
- expected: 不凭霸道、总裁、爱情、哭泣判 zx/nz。

### T3｜对象层错位
“市长动用权限恢复封路，使前成员能回到城市；原协会仍拒绝恢复其成员资格。”
- traffic/direction layer: zx 可查。
- membership reentry layer: nz FAIL。

### T4｜时间窗错位
“去年原成员可一年内恢复原席位，今年章程已取消；制作人今年仍强行协调其回来做一次嘉宾。”
- current nz: 不继承去年资格。
- current zx: 若权能扩大事实成立可查。

### T5｜同关系词异对象层
“他回到公司”一处指物理回到办公楼，一处指恢复原合伙人席位。
- physical location return != object-specific relation reentry。
- 必须拆 IR。

### T6｜对端不存在不等于本端成立
“没人阻止他回来，但也没有任何原关系位置；没有人施力推动。”
- zx FAIL/UNKNOWN；nz FAIL/UNKNOWN。

### T7｜强制回返伪 nz
“家族冻结账户并威胁断供，逼成员搬回祖宅。”
- 可查 x/zx 等控制施力结构；nz 不得因‘回家’成立。

### T8｜standing return 无 zx
“原研究员退出后180天内满足客观条件即可恢复原席位，系统自动执行，无人需要推动。”
- nz PASS；zx 不自动成立。

### T9｜zx 清障但关系不恢复
“负责人公开夺回场地和合同，确保旧成员可参加演出；旧成员只作为临时嘉宾，原成员关系永久终止。”
- zx 可查；nz FAIL。

### T10｜nz 修复但无权能凌驾
“两位朋友争执半年后主动重新联系、道歉并恢复旧有互访，没有第三方权力介入。”
- nz 可强；zx 不自动成立。

### T11｜双层同时成立
“林澈以自身权能压下现实阻碍，但陈岚仍可自由拒绝；陈岚最后依据原成员 standing return 自愿恢复原席位。”
- zx + nz 均可 PASS candidate，但必须 SPLIT_IR。

### T12｜mutation
A. 保留林澈所有施力行为，把陈岚的 standing return 改为“无资格，只能被合同强制召回”。
- zx 可保持；nz ↓。

B. 删除林澈全部施力，把 standing return 改为“系统自动恢复，陈岚自愿触发”。
- nz 可保持/↑；zx ↓。

mutation 后必须重新抽取完整 IR，禁止标签直接翻转。

## 10｜Removal / reverse / same-layer / current-window

### Removal-A｜移除施力者

删除林澈的预算、合同、排期协调与公开推动，但保留一年 standing return 且陈岚仍可自行恢复：

```text
zx ↓
nz 保持
```

### Removal-B｜移除回返资格

保留林澈全部现实权能推动，但把原成员资格改成“退出即永久终止，只能重新竞聘”：

```text
zx 可保持
nz ↓
```

### Reverse｜自愿回返改强制迁回

```text
voluntary same-relation reentry
→ forced relocation / compelled return
```

若施力仍强，zx 可保持或上升；nz 必须下降/重审。禁止写成“回得越强，nz 越强”。

### Same-layer

```text
self_power_to_real_direction_change_layer
!=
object_specific_relation_reentry_layer
```

同一句“我把他带回原团队”至少要先问：
- 谁改变现实方向？
- 谁持有返回资格？
- 返回者能否拒绝？
- 回的是原关系还是同名新位置？

### Current-window

施力发生窗口与 standing return 有效窗口必须分别冻结：
- 去年有 nz 不得自动继承到今年；
- 去年某人强力推动过一次，也不得继承为今年 zx；
- 当前只证明“回来结果发生”仍不足以反推两个历史结构。

## 11｜状态迁移规则

### zx 轨

```text
mere desire to bring back
→ deploy own power publicly
→ others/environment react
→ same-layer influence/decision scope expands
→ return direction becomes reality because of that expansion
= zx evidence ↑
```

### nz 轨

```text
prior specific relation
→ free exit / separation
→ preserved or rebuilt return position
→ voluntary callable reentry
→ same relation restored/repaired
= nz evidence ↑
```

新增不变量：

```text
zx-return-cause ↑ != nz-return-right ↑
nz-return-right ↑ != zx-return-cause ↑
forced-return success != nz strengthening
```

## 12｜成功门结论

本轮不是重复既有 `zx↔nx` 的“直达权能 vs 借力通道”，也不是重复 `n↔nz` 的“持续承载 vs 离开后回返”。新增信息增益是：

1. 把 **return cause** 与 **return right** 正式拆为两个不同 Semantic IR 对象层；
2. 新增 `RETURN-AGENT-vs-RETURN-HOLDER` 角色审计；
3. 将“施力者能把对象带回来”明确排除出 `reentry_right` 正证据；
4. 新增 **voluntary reentry vs forced relocation** 判定门；
5. 新增 cause-removal / right-removal 独立不变量；
6. 新增“结果回到原处 ≠ 原关系恢复”的 adversarial negative。

结论：**PASS / 有新增翻译规则，允许提交为 research-only candidate。**

## 13｜Gate-registry compatibility

未来若进入 Semantic IR gate registry，本候选门只能引用固定 12 字段；`null/unknown` 不得作为正证据。职业、情绪、题材、“追回”“回家”“挽回”等词面均不得成为 predicate。`reentry_right` 的正证据主体必须是返回者/对象特异关系持有者，而不是施力者。
