# 十元发散操作表 · 建表

> 每个十元不是"一个定义"，而是至少四类东西。R1 目标：10 元 × 每元 5–10 个**结构变换动作**。
> 状态图例：✅L定稿 / 🟡粗骨架·待定稿 / ⬜未建

## 操作协议（模板）

```text
发现问题  ：它能在任意对象里发现什么变量
变换动作  ：它能怎么改这个变量（5–10 个结构变换）
继续分叉  ：改完还能沿什么方向继续长
边界排除  ：哪些只是标签/情绪/职业/题材换皮，不算真结构变化
```

## ✅ xz（L 亲手定稿）

```text
发现：哪里存在未来选择空间正在缩小？
变换：
  1. 加明确截止时间
  2. 减少可选路径
  3. 让一次选择永久关闭另一条路
  4. 让代价随时间增长
  5. 让主体不知道真正截止点
继续分叉：为什么关闭？谁造成关闭？主体知不知道？能否逆转？逆转代价是多少？
排除：惨 ≠ xz｜死亡 ≠ 自动 xz｜黑暗风格 ≠ xz
```

## ✅ nx（L 亲手定稿）

```text
发现：哪里存在外部已经成立的方向、权限或通道？
变换：
  1. 主体必须接入既有路径
  2. 把关键权限拆到别人手里
  3. 让解决过程必须逐节点借力
  4. 让执行者可替换但方向不随人改变
  5. 把最终改题权放到外部节点
继续分叉：能否退出？能否换通道？谁拥有最终改题权？借来的权限会不会过户？主体在哪一层仍有自主权？
排除：弱 ≠ nx｜服从 ≠ nx｜员工 ≠ nx｜求人 ≠ 自动 nx
```
