## 最高层级

```text
五大主题与五行是两套不同系统。
两套系统都可以调用十元，但调用目的不同。
相同十元点位只允许建立“映射／对照”，不得写成身份等同。
```

### 五行系统

五行研究同一核心变量上的五组阴阳操作轴：

```text
木：阳木 zx ↔ 阴木 nx
火：阳火 zn ↔ 阴火 x
土：阳土 n ↔ 阴土 x并z
金：阳金 xn ↔ 阴金 z
水：阳水 xz ↔ 阴水 nz
```

本目录按正式主十元，将98项刘海唯一归入一个五行阴阳端。

### 五大主题系统

五大主题研究作品、事件或视觉结构最终在讨论什么：

```text
时间：xn + z
本体：zn + x
空间：x并z + n
因果：zx + nx
命运：xz + nz
```

以上是当前主题系统的狭义基准映射，不等于“金就是时间、木就是因果”。一个刘海可具有明确五行结构，却没有完整主题显影；主题必须另看语境、阶段、变化和结果。

## 刘海库调用

1. 先按正式主十元进入唯一五行主库。
2. 在卡片中单独记录五行归属与五大主题标签，禁止合并成一个字段。
3. 五行具象词用于判断操作轴；主题具象词用于判断高层问题是否显影。
4. 副十元只作交叉关联，不复制完整条目。
5. 五行Canvas必须保留原参考图、来源页、结构研究、正式主副十元、体量、纯度、误判边界与原研究Canvas链接。
6. 图片采用外部研究引用。公开仓库不复制无授权版权原图；冻结备份保存Canvas及其证据链接。
7. 任一Canvas出现Git冲突标记、漏项、重号、缺图或退化成纯文字清单，视为构建失败。
