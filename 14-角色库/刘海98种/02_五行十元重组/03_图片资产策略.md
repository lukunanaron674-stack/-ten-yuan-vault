# 刘海98种｜图片资产策略

## 当前正式模式

```text
image_mode: external_research_reference
local_asset: false
source_page_required: true
```

五行库中的参考图来自公开美发、时尚和专业资料页，用作视觉研究证据。公开仓库默认保存：

- 图片URL
- 来源页URL
- 刘海编号与名称
- 结构判断和误判边界

不默认保存第三方版权图片文件本身。

## 为什么不把外链冒充本地图片

Canvas中的：

```markdown
![](https://example.com/image.jpg)
```

表示外部研究引用，不表示图片已经进入仓库。卡片必须明确显示“外部研究引用”，禁止写成“本地资产已备份”。

## 冻结备份范围

冻结副本保存研究Canvas及其中的图片、来源链接，因此能够恢复证据链和布局；它不复制第三方版权原图字节。

## 本地缓存

本地创作环境可建立不提交仓库的缓存目录：

```text
.local-cache/刘海98种图片/
```

用途仅限：

- 防止临时断链影响个人查看
- 绘画与造型参考
- 链接替换前的人工比对

本地缓存不是正本，不得无授权推送到公开仓库。

## 图片门禁

1. 每项必须有图片URL和来源页。
2. 同一图片URL不得证明两个正式类型。
3. 搜索结果缩略图不能取代来源页。
4. 图像与名称不匹配时，条目失败关闭。
5. 链接失效时保留旧来源记录，并按S级图片Skill替换。
6. 98项完整性与重复检查写入 `02_图片与结构审计报告.md`。
