# S级 Skill｜刘海98种五行十元分库 v1.3

## 最高口径

```text
五行＝广义对立统一体。
五大主题＝五行在叙事领域的狭义子项。
五大主题 --is-a狭义[domain=叙事]→ 五行。
```

固定继承：

```text
木 zx↔nx ← 因果 is-a狭义[叙事]
火 zn↔x  ← 本体 is-a狭义[叙事]
土 n↔x并z ← 空间 is-a狭义[叙事]
金 xn↔z  ← 时间 is-a狭义[叙事]
水 xz↔nz ← 命运 is-a狭义[叙事]
```

每条类型继承边必须保存：轴继承度100、同行阳端100、同行阴端100。两个十元100表示完整继承，不是具体刘海的比例。

## 五行研究卡最低字段

1. 编号、中文名、原名；
2. 参考图与来源页；
3. 五行父项、阴阳端、正式主副十元；
4. 类型十元继承映射度；
5. 实例十元映射度，总和100；
6. 固定叙事狭义主题；
7. `child --is-a狭义[domain=叙事]→ parent`；
8. 结构参数、体量、纯度、证据置信度；
9. 刘海领域具象证据；
10. 原研究主题标签、视觉证据、误判边界；
11. 原研究Canvas链接和图片模式。

```yaml
  同行阳端: 100

```

### 刘海实例层 v1

```text
主十元映射度＝旧纯度
副十元映射度＝100－旧纯度
其余八项＝0
总和＝100
模型＝provisional-two-pole-normalized

```

主副映射度只用于当前迁移，不得宣称已完成十维终审。映射度、纯度、体量和证据置信度必须分字段保存。

## 图片策略

- 图片来自原研究库，不重新造图；
- 公开仓库保留外部URL和来源页；
- 98项必须有98条唯一图片证据；
- 已知重复图必须替换并保留纠偏说明。

## 自动重建与审计

```text
重建：../tools/rebuild_five_element_canvases.py
继承补丁：../tools/apply_is_a_narrow_semantics.py
映射度补丁：../tools/apply_ten_yuan_mapping_degree.py

结构审计：02_图片与结构审计报告.md
链接审计：04_外链可用性报告.md
```

自动任务必须：

- 检查Git冲突标记；
- 收集01–98完整研究文本；
- 应用正式十元纠偏；
- 生成五库完整研究卡；
- 写入叙事 `is-a狭义` 边及类型十元继承度；
- 写入98项实例十元映射度；
- 检查每卡映射度总和100；
- 检查漏项、重号、缺图、重复图和死链；
- 禁止Canvas退化成文字清单。

## 失败条件

- 编号或五库总数不等于98；
- 缺图、缺来源或图片重复；
- 出现Git冲突标记；
- 五行Canvas退化；
- 缺少 `is-a狭义` 父项、子项、领域或类型十元继承度；
- 缺实例十元映射度，或总和不等于100；
- 把映射度、纯度、体量、置信度混成同一字段；
- 冻结备份没有实际副本。
