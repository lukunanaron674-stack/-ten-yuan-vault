# S级 Skill｜现代服装视觉词库建库 v0.1

## 定位

本 Skill 把「真实参考图采集 → 名称规范 → 服装结构指纹 → 十元判断 → 配比度 → 单十元本征映射准度 → 五行分库 → Canvas 可视化 → 审计」压成一条可重复执行链。

题材限定为现代服装。当前先建立女性／中性日常服装基准，不把古装、军服史料、奇幻服装、舞台服和纯概念秀场造型混入同一批。

唯一正式路径：

```text
14-角色库/现代服装
```

旧资料只作候选来源：

```text
09-给674（我）用的库/三元理论/服装词库_五大主题映射.md
10-创作/OC服装参考/
```

不得直接把旧分数或 Pinterest、淘宝、AI 角色图迁入正本。

## 最高层级

```text
五行＝广义父项
现代服装狭义结构 --is-a狭义[domain=现代服装]→ 五行
五大主题 --is-a狭义[domain=叙事]→ 五行
```

现代服装领域的五个狭义子项：

| 五行父项 | 现代服装狭义子项 | 十元轴 |
|---|---|---|
| 木 | 功能行动 | zx ↔ nx |
| 火 | 身体本体 | zn ↔ x |
| 土 | 包裹层次 | n ↔ x并z |
| 金 | 剪裁秩序 | xn ↔ z |
| 水 | 流动变形 | xz ↔ nz |

叙事主题只作跨领域显影，不得替代现代服装狭义子项。

## 两套数字

```text
十元配比度：一件服装由哪些十元共同构成，各占多少；总和必须为100%。
单十元本征映射准度：这件服装有多像目标十元本体；0–100独立评分，不参与配比总和。
```

不得把体量、纯度、证据置信度、本征准度和配比度混成一个“强度”。

## 真实图片证据

继承 S 级真实参考图片采集 Skill：

- 必须保留原始来源页、图片 URL、访问日期和来源机构；
- 图片与页面名称必须双向一致；
- 一级结构至少六项可判断；
- 同一图片不得证明两个正式类型；
- AI 生成图、无来源搬运图、搜索缩略图不得作为正式证据；
- 公开仓库默认保存远程引用，不擅自复制第三方图片文件；
- 证据不足时状态只能是 `evidence-pending`。

## 服装结构指纹

每条至少记录：

```yaml
轮廓:
长度:
领型:
袖型:
闭合:
材质:
贴体度:
层级:
对称性:
功能件:
覆盖范围:
运动方式:
```

一级差异优先级：

1. 身体与外壳关系；
2. 开合和层级；
3. 轮廓与长度；
4. 功能和受力方向；
5. 对称／截断／可逆；
6. 材质和装饰。

颜色、品牌、模特气质、价格、流行标签不能决定十元。

## 本征准度评分

| 维度 | 分值 |
|---|---:|
| 十元核心操作是否成立 | 40 |
| 轮廓／开合／层级是否持续支持 | 25 |
| 材质和构造是否支持 | 15 |
| 与同行对立端能否清楚区分 | 10 |
| 图片与文字证据是否充分 | 10 |

总分 100。十元内排名只按本征准度排序；同分共享名次。

## 执行顺序

1. 锁定现代服装家族和数量；
2. 建立三倍候选池；
3. 规范中文名与原文名；
4. 图片／名称双向核验；
5. 写结构指纹；
6. 与已有服装做跨批去重；
7. 判断主、副十元；
8. 写十元配比度；
9. 独立评本征准度；
10. 写五行父项、现代服装狭义子项和叙事显影；
11. 生成 Canvas；
12. 生成十元内排行榜；
13. 回读检查图片、编号、总和、路径和冲突标记；
14. 提交 main。
