# 角色比例库 · 总文件

> 本文件是 05_体态库 的总纲。三个核心概念 + 五行比例代号总表 + 比例载入例子分析（持续积累）。

## 三个核心概念

| 概念 | 定义 |
|---|---|
| **比例** | 一条可复用的体态比例模板，用「代号 + 十元映射」登记（如 278xz = 沙漏女体）。是静态资产 |
| **比例灌入** | 把某条比例（或其分区片段）套到具体角色/生成任务上的动作——**整个库的核心操作**。可整段灌入，也可分区拼装（如 头取A码 + 身腿取B码） |
| **复合比** | 同一分区内**叠加多条比例码**（如胸腔 = zx971+xz278 双码复合）。与分区拼装的区别：拼装是各分区各取一码，复合是单分区多码叠加 |
| **比例感** | 载入后的视觉体感校验——头身比、块面节奏、轮廓倾向是否符合该代号应有的气质。每次载入后回填「比例感评估」形成闭环 |

# 比例灌入例子分析（持续积累）

> 每次灌入实践在下面追加一节。格式：灌入组合 → 来源 → 灌入方式 → 比例感评估 → 修正记录。

## 例01 · 红发角色：头 nx563 + 身腿 xz（分区拼装）

- **灌入组合**：头 = 木·nx563，身体和腿 = 水·xz
- **来源**：批次05 卡（近景 + 全景两张）
- **灌入方式**：**分区拼装**——非整段灌入，头部从木库取码，身腿从水库取码
- **比例感评估**：
  - 头身比 ≈5.5-6，头大身小分离明显——nx563 的头体量给了「幼态+注视感」
  - 身腿 xz 部分被大外套弱化收束，腿部短柱化——xz 的锋利感被外套软化，整体偏「稳」而非「利」
  - 结论：木头 + 水身的组合成立，气质 = 幼态注视 + 沉稳承载，无冲突
- **修正记录**：无（首例，待 674 复核）

## 例02 · 复合比双实例：胸腔 zx971+xz278 复合 ／ 下 nz ／ 头 nx

- **灌入组合**：胸腔 = 木·zx971 + 水·xz278（**分区内双码复合**），下半身 = 水·nz，头 = 木·nx
- **来源**：批次06 卡（黑袍大剑骑士 + 龙影兽装战士，同一配方两个实例）
- **灌入方式**：**复合比**——胸腔单分区叠加两码；与例01 的分区拼装构成两种灌入方式的对照
- **比例感评估**：
  - 胸腔双码成立：zx 给甲胄威压、xz 给体积节奏，叠加后胸成为绝对视觉中心
  - nz 下身 + nx 头 = 两端都收，重量全部让给胸——配方重心结构是**单极胸腔**
  - 跨画风稳定：写实厚涂（骑士）与速涂兽装（战士）两实例胸腔主导度一致，说明该复合比对画风不敏感
  - **整体 xn331（金）**：双实例的整体气质 = 金的「裁定/收束」感——华丽甲饰 + 冷峻剪影，胸腔虽主导但不散，被整体金的秩序感收住
- **修正记录**：✅ 归库定案 = **金**（整体码 xn331，674 定 2026-09-29），卡已由水库迁入金库
