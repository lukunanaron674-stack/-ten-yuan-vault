# 十元体型比例总纲 v0.1

## 1. 总目标
把十元类型转译为可重复生产的人体比例语言：

**十元 → 数字比例组合 → 身体区域映射 → 灰色体膜模板**

数字体系：331 / 575 / 851 / 931 / 971 / 853。

## 2. 数字使用规则
数字不是单一尺寸标签，而是完整比例语言。

每次记录必须包含四项：
1. 数字
2. 身体落点
3. 权重：主 / 辅 / 局部
4. 分布：上半身 / 下半身 / 跨上下 / 单点

### 禁止
- 331=节点
- 851=长
- 931=宽
- 971=长腿
- 853=骨盆

以上均只可作为实验假设，不能锁死。

## 3. 身体观察层
固定观察顺序：

头 → 肩 → 胸腔 → 腰腹 → 骨盆 → 上臂 → 前臂 → 手 → 大腿 → 小腿 → 脚 → 整体轮廓

必要时手继续拆：
掌 / 指

腿继续拆：
大腿 / 小腿 / 脚

## 4. XN 当前一级候选
### XN-A 圣职瘦长
**331主 / 851辅 / 575局部**

当前稳定解释：
- 331：维持整体收束主结构
- 851：跨胸腔、手臂、腿进行纵向展开
- 575：腰腹与局部过渡
- 关键不是“腿长”，而是**851是否同时进入上半身与下半身**

候选映射：
- 头：331（辅）
- 肩：331（主）
- 胸腔：851+331（主/辅）
- 腰腹：575（辅）
- 骨盆：331/575（主）
- 上臂：851（辅）
- 前臂：851/575（辅）
- 手：331/575（局部）
- 大腿：851（辅）
- 小腿：851/575（辅）
- 脚：331/575（局部）
- 整体：331（主）

## 5. X瘦高待验证方向
当前不把 X 直接等同于 931 或 971。

重点验证：
- 851/971 是否集中在四肢，而胸腔相对压缩
- 腰部收束后，骨盆 / 小腿 / 手脚是否重新建立第二个体量中心
- 853 / 931 / 971 进入骨盆、末端或局部后，是否产生稳定 X 感

## 6. 当前最强分界假设
XN-A：
> 331主结构 + 851跨上下半身展开 + 575过渡

X瘦高：
> 可能同样使用331与851，但强比例更多集中于四肢或下半身，使“核心缩短 / 肢体扩张”更明显

## 7. 冲突处理
如果外部角色出现：
- 极长腿但仍核心稳定
- 小头但腿不长
- 窄肩但骨盆明显
- 大手脚但整体仍收束

不直接判定数字体系错误。  
先检查：
- 数字是否落在不同身体区域
- 主辅权重是否不同
- 上下半身是否重复同一辅数字
- 是否存在一次或多次局部回弹
- 是否是服装/姿势造成误判
