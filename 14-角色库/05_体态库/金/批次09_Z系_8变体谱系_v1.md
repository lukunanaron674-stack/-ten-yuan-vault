# 批次09 · Z 系 8 变体谱系（金）

**核心记录：纯 Z 轴的 8 个变体型，674 定归金库（与 z292 同行）。每型含 正面+侧面 三视图 与 胸-腰-骨盆 三段块面拆解。**

Z 轴语义与 XN 系对照：XN 是「收、直、节制」（批次08），Z 系谱系名全部指向**运动与变化**——灵活、转折、突变、偏移，是「动」的骨架线。

## 8 型清单

| 型号 | 名称 | 体态特征（目测） |
|---|---|---|
| Z-A | 灵活跳脱型 | 重心偏移，四肢 ready-state，随时可动 |
| Z-B | 曲线转折型 | 脊柱 S 曲线明显，胯位侧顶 |
| Z-C | 机敏突变型 | 瘦而紧，关节角度锐利，爆发预备姿 |
| Z-D | 装饰扩展型 | 肩部/臂部异常延展（为服饰配件留的体态空间） |
| Z-E | 古灵精怪型 | 全系头身比最小（≈4-5头身），圆润幼态 |
| Z-F | 不对称偏移型 | 左右失衡构图，重心单侧 |
| Z-G | 都市轻盈型 | 窄肩长腿，体量轻 |
| Z-H | 舞台时髦型 | 时装周台步姿，颈长背直胯摆 |

## 与批次08（XN 系）对照

| 维度 | XN 系（金·批次08） | Z 系（金·批次09） |
|---|---|---|
| 关键词 | 收直节制 | 灵动变化 |
| 站姿 | 静态规训 | 动态预备 |
| 曲线 | 直线主导 | 曲线/S 型/偏移主导 |
| 头身 | 6.5-8.5 | 4-8（E 型拉低下限） |
| 职业域 | 圣职/审判/模特 | 舞者/艺人/舞台 |

**金的两个骨架分支**：XN 线 = 金的「裁定·秩序」面（静），Z 线 = 金的「锋锐·机变」面（动）——两卡并读即金轴全身谱系。
