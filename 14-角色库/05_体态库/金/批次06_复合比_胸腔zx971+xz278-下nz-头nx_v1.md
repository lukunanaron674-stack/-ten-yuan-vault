# 批次06 · 复合比：整体 xn331（金）｜胸腔 zx971+xz278 ／ 下 nz ／ 头 nx

**核心记录（674 口径）：这两张都是复合比——整体 = xn331（金），胸腔 = zx971 加 xz278 复合（木水双码叠加），下半身 = nz，头 = nx。**

**归库定案：整体码 xn331 属金 → 本卡归金库。**（分区码木水对半不作归库依据，整体码优先。）

本卡是比例库第一张**复合比**卡：同一分区（胸腔）同时灌入两条比例码，不是分区拼装（批次05 那种各分区各取一码），而是**分区内叠加**。

| 分区 | 灌入码 | 视觉表现（两实例共性） |

| **胸腔** | zx971（木·权能甲胄）+ xz278（水·块面收放） | 胸腔是全身体量最大点：既有钱能甲胄/徽记的「权能外显」（zx），又有大块面体积收放（xz）——两码叠加 = **厚重且带威压的胸** |

## 比例感评估（首读）

- 胸腔双码复合成立：zx 给「甲胄威压」，xz 给「体积节奏」，叠加后胸腔成为绝对视觉中心，两实例虽画风不同（写实厚涂 vs 速涂兽装）但胸腔主导度一致
- nz 下身 + nx 头 = 上下两端都「收」，把全部重量让给胸——复合比的重心结构是**单极胸腔**
- 与批次05（分区拼装）对比：批次05 是头大身小两端并重，批次06 是胸大两头轻——**复合比分区叠加 vs 分区拼装**两种灌入方式的对照样本
