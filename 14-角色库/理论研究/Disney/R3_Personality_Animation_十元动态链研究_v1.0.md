# 一、核心发现

Disney Personality Animation 的核心：

> 动画不是让角色移动，而是让角色因为某种想法而移动。

普通动画：

```
事件
↓
动作
```

人格动画：

```
事件
↓
角色理解
↓
角色选择
↓
动作
↓
结果
```

同一个事件，不同十元结构，会产生不同动作。

# 五、Disney四阶段动作结构 × 动态链

## 1. Anticipation（预备）

对应：动态链起点。

```
内心决定
↓
身体准备
```

## 2. Action（行动）

对应：十元爆发。

ZX：

```
改变关系
```

动作：
- 冲刺
- 介入
- 打破排列

## 3. Reaction（反应）

对应：生克结果。

动作：
- 停顿
- 回头
- 重新判断

## 4. Follow Through（后续）

对应：补关系。

动作结束后：
- 尾巴
- 表情
- 环境

继续表达角色状态。

# 六、动态链动画化模型

## A型：先压后扬再压

```
双克
↓
双生
↓
三克
↓
选择
↓
互补
```

适合：主角成长线。

## B型：交替拉扯

```
克ZX
↓
生ZX
↓
克Z
↓
生Z
↓
克NZ
```

适合：冒险、追逐。

## C型：并行收束

```
ZX线变化
+
Z线变化
↓
最终交汇
```

适合：电影高潮。

关键词：
