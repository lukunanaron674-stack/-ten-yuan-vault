# 现代服装库｜五行十元与双指标规则 v0.2

> 本文件只定义现代服装库的局部工作语言，不修改全局十元正本。服装领域五个狭义工作名需要后续通过案例和反例审计，再决定是否提升为L1。

## 1｜五行广义轴在服装中的观察方式

| 五行 | 十元对立 | 服装领域局部工作名 | 观察问题 |
|---|---|---|---|
| 木 | zx ↔ nx | 动向 | 服装主动规定身体／视线方向，还是顺应身体和既有层级续接？ |
| 火 | zn ↔ x | 体式 | 服装依靠自身材料与形态成立，还是靠切割、控制、调用身体而成立？ |
| 土 | n ↔ x并z | 包界 | 服装向内容纳承载，还是把内部组织外化成壳层和可见界面？ |
| 金 | xn ↔ z | 制式 | 规则分布在多个节点流程，还是由单一扣点、截点或中心完成裁定？ |
| 水 | xz ↔ nz | 变适 | 服装持续收窄可能性，还是保留恢复、重建、调节与回接空间？ |

标准本库写法：

```text
动向 --is-a狭义[domain=现代服装, status=local-working]→ 木
体式 --is-a狭义[domain=现代服装, status=local-working]→ 火
包界 --is-a狭义[domain=现代服装, status=local-working]→ 土
制式 --is-a狭义[domain=现代服装, status=local-working]→ 金
变适 --is-a狭义[domain=现代服装, status=local-working]→ 水
```

这些局部工作名不是服装类别。飞行夹克仍然是外套／夹克家族，而不是“木类服装”。

## 2｜十元的服装领域可观察端

### zx｜阳木

- 主动建立斜向、前冲、上提或外推方向；
- 结构引导身体采取动作；
- 功能件沿行动链布置；
- 典型证据：斜向门襟、上提束带、高位固定、前后导向明显。

### nx｜阴木

- 顺应身体原有走向；
- 作为内搭、连接层或柔性过渡层续接；
- 不抢最终轮廓方向；
- 典型证据：柔软层叠、自然垂顺、过渡下摆、低侵入连接。

### zn｜阳火

- 依靠材质、体量、纹理或贴身关系自然成立；
- 不需要复杂切割也能保持身份；
- 典型证据：基础T恤、自然针织、原生褶皱、材质自成轮廓。

### x｜阴火

- 通过切割、暴露、紧束、开口或控制身体而成立；
- 对身体有明确调用和处分边界；
- 典型证据：硬切开口、紧身束缚、锐角裁片、功能性拆解。

### n｜阳土

- 向内包裹、承载、容纳身体或其他层；
- 形成可进入、可停靠的空间；
- 典型证据：宽松大衣、袋状轮廓、深口袋、层内可容纳。

### x并z｜阴土

- 将内部结构外化成壳体、表面与界面；
- 以硬挺外层、护罩、膜层或展示面隔开内外；
- 典型证据：硬壳外套、结构化肩部、表面模块、外置防护层。

### xn｜阳金

- 规则分布在多个节点；
- 等距纽扣、重复褶裥、模块口袋和制式分割形成流程；
- 典型证据：制服、工装系统、套装、重复扣点。

### z｜阴金

- 单一中心、扣点、腰封、截点或徽记完成裁定；
- 典型证据：唯一腰带、中央扣、领结、单点封闭、关键徽章。

### xz｜阳水

- 层级、用途或调节空间被持续削减；
- 可能性收窄到单一路径；
- 典型证据：极简削减、不可拆结构、单一用途防护、逐级收紧。

### nz｜阴水

- 可恢复、可调节、可拆装、可回接；
- 保留不同穿法和使用状态；
- 典型证据：可逆穿、可拆袖、抽绳调节、模块重组、旧衣修补。

## 3｜十元配比度

十元配比度回答：

```text
这件服装内部由哪些十元共同构成，各占多少？
```

规则：

- 十项总和必须为100；
- 评分尺度必须写明是单品、整套造型还是局部细节；
- 配比最高者为主十元，第二高者为副十元；
- 不得用旧五大主题词表的单一分类直接生成配比；
- 证据不足时使用区间或 `provisional`，不得伪造精确度。

示例：

```yaml
analysis_object: MA-1飞行夹克
analysis_scale: 单品结构
composition_ratio:
  zx: 28
  xn: 24
  x并z: 18
  n: 10
  z: 8
  x: 5
  nz: 4
  zn: 2
  nx: 1
  xz: 0
sum: 100
status: provisional
```

## 4｜单十元本征映射准度

本征准度回答：

```text
它单独看，有多像某个十元本身？
```

规则：

- 每个目标十元独立0–100；
- 不参与十项配比总和；
- 只能在相同领域、相同尺度、相同评分表下排名；
- 分数必须有正证、反证和最近邻比较；
- 同分采用竞赛排名法。

```yaml
archetype_accuracy:
  target: zx
  score: 84
  domain: 现代服装
  scale: 单品结构
  positive_evidence:
    - 斜向门襟明确引导视线
    - 高位束带强化上提方向
  counterevidence:
    - 整体仍受制式节点约束
  nearest_confusion: xn
  evidence_confidence: 78
  status: provisional
```

## 5｜五行本征映射准度

五行准度回答：

```text
这件服装有多完整地显现某一五行的对立统一轴？
```

机器字段：

```yaml
five_element_archetype_accuracy:
  target: 木|火|土|金|水
  score: 0-100
  domain: 现代服装
  scale: 单品结构|整体搭配
  positive_evidence: []
  counterevidence: []
  evidence_confidence:
  status: provisional|evidence-tested|canonical
```

规则：

- 五个五行各自独立0–100；
- 不要求五行准度总和为100；
- 不由同行两个十元本征准度机械相加、平均或相减；
- 必须判断这件服装是否真正覆盖该五行广义轴，而不只是出现其中一端；
- 只能在现代服装领域、相同分析尺度与相同评分规程内排序；
- 98项完成后生成木、火、土、金、水五个独立排行榜。

五行归属与五行准度不同：

```text
五行归属＝当前最主要的五行轴。
五行本征准度＝它有多完整地体现该五行轴。
```

## 6｜禁止“十元对比度”

现代服装库不建立以下正本字段：

```text
十元对比度
主副十元差值
同行阴阳差值
```

分数差可以在人工分析时临时查看，但不得成为第三套评分系统、研究卡最低字段或正式排行榜。

正式数字体系只有：

1. 十元配比度；
2. 单十元本征映射准度；
3. 五行本征映射准度；
4. 证据置信度；
5. 必要时的体量与纯度。

## 7｜旧服装词表的迁移规则

旧《服装词库｜五大主题映射》中的“精密度”不得直接视为新本征准度。

迁移时：

1. 保留服装名称、旧精密度、旧强度和旧说明；
2. 标记 `legacy-theme-score`；
3. 重新判断本体分类和结构变量；
4. 重新映射十元配比；
5. 按单十元本体判据重评本征准度；
6. 单独重评五行本征准度；
7. 旧分数只作排序候选，不作正本。

## 9｜失败条件

- 把服装类别直接命名为木、火、土、金、水；
- 把五大主题当现代服装一级分类；
- 配比度不等于100；
- 本征准度参与配比总和；
- 五行准度由同行十元分数机械计算；
- 建立或写入“十元对比度”正本字段；
- 用情绪、品牌或角色性格替代结构证据；
- 没有反证和最近邻却给出高分；
- 将局部工作名冒充全局L1正本。
