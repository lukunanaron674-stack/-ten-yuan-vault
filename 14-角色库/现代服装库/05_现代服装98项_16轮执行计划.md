# 现代服装98项｜16轮执行计划

## 0｜总规模

现代服装库按刘海98种库的建库强度执行：

```text
14轮内容建库 × 每轮7项 ＝ 98项正式服装研究卡
第15轮＝跨批结构、图片与来源审计
第16轮＝五行十元重组、准度排行与总索引收口
总计16轮
```

不建立“十元对比度”字段。

正式数字层只保留：

1. 十元配比度，总和100%；
2. 单十元本征映射准度，独立0–100；
3. 五行本征映射准度，独立0–100；
4. 证据置信度；
5. 体量与纯度，如该条确有必要。

## 3｜图片标准

- 每项至少一张S图，或两张互补A图；
- 保存图片URL和来源页URL；
- 名称与图片必须双向核验；
- 同图不同尺寸、裁切和镜像视为重复；
- AI图、Pinterest二传、无来源搬运和纯营销图不得进入正式卡；
- 98项正式图URL必须唯一，重复组为0。

## 4｜数字标准

### 十元配比度

```text
回答：这件服装内部由哪些十元构成？
十项总和＝100%。
```

### 单十元本征映射准度

```text
回答：它有多像某个十元本身？
独立0–100，不参与配比总和。
按十个十元分别生成排行榜。
```

### 五行本征映射准度

```text
回答：它有多完整地显现某个五行的对立统一轴？
独立0–100，不由同行两端机械求和。
按木、火、土、金、水分别生成排行榜。
```

### 禁止字段

```text
十元对比度：不建立。
主副差值：只可作为临时计算，不保存为正本理论字段。
同行阴阳差值：只可辅助观察，不进入研究卡最低字段。
```

## 5｜第15轮｜跨批总审计

检查：

- 编号01–98完整、无重号；
- 正式名称和层级无冲突；
- 同结构不同营销名是否被误拆；
- 每项决定性变量和最近邻边界是否成立；
- 图片98/98、来源98/98；
- 图片URL唯一98、重复组0；
- 死链、403、404、410单独报告；
- 无Git冲突标记；
- 每卡十元配比度总和100；
- 不存在“十元对比度”字段。

## 6｜第16轮｜五行十元重组与收口

生成：

1. 五行总索引 Canvas；
2. 木、火、土、金、水五个完整研究 Canvas；
3. 十元本征映射准度排行榜，共10榜；
4. 五行本征映射准度排行榜，共5榜；
5. 图片与结构审计报告；
6. 外链可用性报告；
7. 98项冻结备份与MANIFEST；
8. 总 Skill、CHANGELOG 和自动防退化门禁。
