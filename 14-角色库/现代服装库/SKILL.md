# S级 Skill｜现代服装角色视觉词库建库 v1.1

## 0｜定位

本库建立可供角色设计、分镜造型、服装提示词、统一重绘和十元分析使用的**现代服装本体词库**。

它不是穿搭推荐，也不是品牌、潮流热词或情绪风格图板。它首先回答：

```text
这件东西在服装结构上到底是什么？
它与最近似服装的决定性差异是什么？
图片能否真实证明这种结构存在？
它在当前尺度上的十元配比、单十元本征准度与五行准度如何？
```

## 1｜范围

### 收录

- 现代日常女装；
- 职业、校服、制服与礼仪服装；
- 运动、户外、工装、机能与防护服装；
- 现代成年女性内衣、家居服、鞋靴与配饰；
- 现代亚文化和设计师服装，但必须能说明结构来源；
- 男装、中性服装及同一结构的性别化变体，可作为补充，不抢占本库女性主线。

### 不直接收录

- 民国、古代、民族历史服装正本，另入时代服装库；
- 纯奇幻、科幻概念服装，另作创作变体或下游衍生；
- 仅靠品牌、明星、颜色或“高级感”等情绪词成立的条目；
- 单次搭配状态冒充独立服装类型；
- AI生成图作为真实服装类型存在证据；
- 未成年人内衣、年龄不明幼态内衣、情趣服和露骨成人内容。

## 2｜人物与审美图源总规则

女性服装参考图优先顺序：

```text
中国品牌官方页面
→ 中文市场官方页面
→ 来源明确标注为中国成年女模特的公开资料
→ 其他高质量成年女性结构图
```

“中国女”必须有来源依据，不得靠外貌猜测国籍、民族或血统。

“少女”统一解释为：

```text
18岁以上成年女性的少女感、甜美感、清新感与年轻感
```

视觉方向优先：

- 中国女性审美语境；
- 年轻成年、清秀、甜美、时尚；
- 正面、四分之三或全身结构清晰；
- 模特姿势不遮挡衣服主要廓形；
- 人物好看服务于角色视觉参考，但不能盖过服装结构证据。

### 年龄与内容硬失败

- 未成年人或来源无法确认年龄、且明显幼态的内衣图片；
- 校服、儿童化道具与内衣的性暗示组合；
- 露骨姿势、性行为暗示、裸露重点部位或成人内容；
- 只因页面写“少女、美少女”就默认人物成年；
- 将童装、青少年内衣或儿童家居服混入成人库。

## 3｜权威层级

```text
现代服装本体分类
→ 家族
→ 正式类型
→ 子型
→ 结构变体
→ 单次造型／搭配实例
```

示例：

```text
外套
→ 夹克
→ 飞行夹克
→ MA-1
→ 短款／长款／绗缝／皮革变体
→ 某角色的一次具体穿搭
```

品牌名、风格名和搭配名不得越级冒充正式结构类型。

## 4｜一级分类

1. **上衣**：T恤、衬衫、背心、针织、卫衣、罩衫等；
2. **下装**：长裤、短裤、裙装、裙裤等；
3. **连体服装**：连衣裙、连体裤、背带裤、工装连体服等；
4. **外套**：夹克、西装外套、风衣、大衣、羽绒、披覆类等；
5. **套装与制式**：西装套装、制服、校服、职业装、礼仪套装；
6. **运动与功能**：运动、户外、工装、机能和防护，固定11项主干；
7. **成年女性内衣**：非露骨、日常、甜美和基础结构；
8. **家居服**：室内活动服，不自动并入睡衣；
9. **鞋靴**：运动鞋、皮鞋、凉鞋、靴类、功能鞋；
10. **配饰与穿戴件**：帽、围巾、手套、腰带、包袋、首饰、眼镜；
11. **整体搭配**：只记录多件组合、层叠和角色造型，不替代单品分类。

## 5｜正式类型的一级结构变量

每种服装至少明确一个决定性一级变量：

- 穿着部位与覆盖范围；
- 单件／上下分体／连体；
- 内层／中层／外层；
- 廓形：H、A、X、O、T或其他可描述轮廓；
- 松量与贴体程度；
- 长度与关键停点；
- 领型、袖型、腰线、裤型或裙摆；
- 开合：套头、纽扣、拉链、系带、裹身、后扣等；
- 结构分割、口袋、褶裥、拼接；
- 材料硬挺度、垂坠、弹性、透明度；
- 功能：保暖、防护、运动、承载、支撑、制式识别；
- 与身体动作的关系。

颜色、印花、品牌、模特气质和临时卷袖不得作为一级类型差异。

### 内衣专项变量

- 罩杯：无杯、三角软杯、模杯、全罩、半罩；
- 下围：无钢圈、软支撑、钢圈；
- 肩带：宽度、位置、可调节性、可拆卸性；
- 包覆与支撑；
- 后扣、套头或前扣；
- 面料弹性、透气、蕾丝／棉质比例；
- 上下装是否成套；
- 日常基础、运动支撑或造型内搭用途。

人物身体、胸围大小和性感程度不得替代内衣结构描述。

## 6｜真实参考图门禁

继承 `S级_真实参考图片采集`，并增加服装专项要求。

正式条目最低需要：

- 一张S图；或
- 两张互补A图；
- 至少能辨认正面结构、长度、廓形、开合与关键分割；
- 复杂服装尽量补充背面、侧面或平铺图；
- 来源页必须明确名称，或来自品牌档案、设计师、服装教育资料；
- 电商图可证明具体商品结构，但不得单独证明行业通用类型名称；
- 模特必须是成年语境；内衣条目必须有明确成年来源依据。

### 服装图片硬失败

- 身体姿势、遮挡或裁切导致廓形和开合不可见；
- 页面名称与图片结构不一致；
- 同一商品换颜色被记成多个类型；
- 只因面料、图案或品牌不同就拆成新类型；
- Cosplay、AI图或概念画被用作现实服装本体证据；
- 将人物气质误当成服装结构；
- 无来源页、无核验日期或重复图片；
- 内衣模特年龄不明、明显幼态或内容露骨。

## 7｜十元与五行分析层

服装分类与十元分析必须分层：

```text
服装是什么：由本体分类决定。
服装怎样作用：由十元与五行分析决定。
```

### 五行在服装领域的局部工作名 v0.1

| 五行 | 十元两端 | 服装领域工作轴 |
|---|---|---|
| 木 | zx ↔ nx | 动向：主动导向身体／视线 ↔ 顺应既有身体与层级续接 |
| 火 | zn ↔ x | 体式：依靠自身材质与形态成立 ↔ 被切割、调用、控制而成立 |
| 土 | n ↔ x并z | 包界：向内容纳与承载 ↔ 将内部结构外化为壳层与界面 |
| 金 | xn ↔ z | 制式：规则分布到多个节点 ↔ 收束到单一裁定点 |
| 水 | xz ↔ nz | 变适：持续收窄、削减可能性 ↔ 保存、恢复、重建与回接 |

这些轴不能替代上衣、裤装、外套和内衣等本体分类。

### 五行本征映射准度

```yaml

  target: 木|火|土|金|水
```

## 10｜去重规则

以下通常不是新类型：

- 同版型换颜色、图案或品牌；
- 同一服装只改变面料，除非材料改变一级结构或功能；
- 单纯卷袖、塞衣角、敞开拉链；
- 同一商品不同模特；
- 营销名不同但结构变量相同；
- “辣妹、松弛、高级、学院、氛围、少女感”等风格词没有结构证据。

正式拆分至少需要：

- 两项稳定可见结构差异；或
- 一项决定性的一级变量差异。
