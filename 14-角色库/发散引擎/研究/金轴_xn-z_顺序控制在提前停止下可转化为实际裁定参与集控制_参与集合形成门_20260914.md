# 金轴｜顺序控制在提前停止下可转化为实际裁定参与集控制：参与集合形成门

## 0｜本轮只解决一个问题

固定候选对象、证据、评审节点、单节点投票权、阈值规则，只改变：

```text
谁决定评审顺序
+
达到阈值后是否提前停止、未轮到节点是否永不进入本轮binding judgment
```

问题：

> 单一协调者仅有“排序权”，表面上没有最终票、没有覆盖权；但如果流程达到阈值就立即停止，后续节点永不进入本轮裁定，那么排序权是否仍只是无害 agenda ordering？

结论：

```text
ordering_control + all binding nodes inevitably participate
-> ordering alone remains xn-compatible
```

但：

```text
ordering_control
+ early_stop
+ unqueried nodes lose this case's binding participation
-> ordering can become participation-set formation control
```

若单一中心可以据已知/可预测立场自由排序，从而稳定决定“哪些节点实际进入binding set”，则必须分账：

```text
participation_set_formation = z-like center candidate
judgment_within_realized_set = xn possible
whole = SPLIT_IR_BY_DECISION_STAGE
```

只有进一步强到：

```text
center can choose a sequence that guarantees a target outcome
+ omitted nodes have no independent reentry/reopen path
```

才允许升级为 strong/effective z candidate。

本轮保持 L4 research-only，不修改 canonical。

## 2｜两端判定与置信度

### S0｜只改时间顺序，所有节点必然参与

```text
xn PASS 0.98
z FAIL 0.97
```

排序不改变谁拥有binding judgment，也不改变谁进入本案记录。

### S1｜有提前停止，但顺序由固定规则/随机机制生成

```text
xn PASS 0.96
z FAIL 0.94
```

虽然本轮实际参与集合是子集，但该子集不是单一中心自由形成，而是规则结构生成。

### S2｜P自由排序 + 提前停止 + 未轮到节点本案失权

```text
participation_set_formation:
  z-like candidate PASS 0.95

judgment_within_realized_set:
  xn PASS 0.96

whole:
  SPLIT_IR_BY_DECISION_STAGE 0.96
```

关键不是“P排了先后”，而是：

```text
order now determines who gets to exercise binding judgment at all
```

### S3｜P可利用已知立场排序，稳定把本案推到目标结果

```text
effective z strong candidate 0.97
xn substantive independence weakened 0.91
```

前提必须真实验证：

```text
sequence -> realized subset -> outcome
```

不能只因“主席知道大家意见”就脑补 z。

## 4｜Removal

### Removal A｜删除 early-stop

保留 P 的完全排序权，但必须等所有binding节点投票：

```text
participation-set z-like evidence disappears
-> xn remains
```

### Removal B｜保留 early-stop，删除自由排序

改为固定轮值/公开随机顺序：

```text
single-center participation-set control disappears
-> xn rises
```

### Removal C｜保留自由排序与 early-stop，但给未轮到节点独立 reopen right

若被跳过节点可在关闭后按公开规则要求本案重开并进入binding record：

```text
center-shaped participation set weakens sharply
```

说明 current-case irreversibility / no-reentry 是关键放大器。

## 7｜跨域正反控制

### Positive xn｜工程审批

5 个独立检查器全部必须完成，release manager 只决定谁先跑；最终结果等全部检查器返回。

```text
xn PASS
```

### Positive xn｜规则化 early-stop

5 个审查节点，达到3个同向票立即停止，但顺序每案由公开随机种子产生，任何人不能改序。

```text
xn PASS
```

### Positive split｜制度审议

5 名委员，达到3票立即结案；主席可自由决定发言/投票顺序，未轮到者结案后无本案投票权。

```text
participation_set layer = z-like candidate
realized voting subset = xn
whole = SPLIT_IR
```

### Positive effective-z candidate｜创作验收

5 名评审立场已基本公开，达到3个赞成即结束；总导演自由排序，稳定把三个赞成者排前，反对者永远来不及进入binding record，且无重开权。

```text
effective outcome control via participation-set shaping = strong z candidate
```

### Negative control｜只是发言顺序

主席安排先后，但所有委员最终必须投 binding 票：

```text
ordering alone != z
```

## 8｜失败类型

```text
FAILURE_ORDERING_ALWAYS_HARMLESS
```

忽略 early-stop，使真实参与集合已被顺序塑形仍判纯 xn。

```text
FAILURE_ANY_ORDERING_AS_Z
```

没有 early-stop/失权机制，仅因主席排顺序就判 z。

```text
FAILURE_REALIZED_SUBSET_AS_FULL_DISTRIBUTION
```

名义上有5个节点，就默认5个都参与本案，忽略实际只有前三个进入binding record。

```text
FAILURE_RULE_GENERATED_SUBSET_AS_CENTER_CONTROL
```

随机/固定规则产生子集，却误判为单中心控制。

```text
FAILURE_SEQUENCE_TARGETING_IGNORED
```

单中心可利用已知立场自由排序并稳定塑造结果，却只记录“无最终票”。

## 10｜最小判别式

```text
ordering power
+ all binding nodes inevitably participate
-> ordering alone does not create z
```

```text
ordering power
+ early-stop
+ skipped nodes lose current-case binding participation
-> inspect participation-set formation
```

```text

+ judgment inside set remains distributed
-> upstream z-like / downstream xn

```

```text

-> strong/effective z candidate
```

最短版：

> 顺序只有在它决定“谁来得及成为裁定者”时，才从排期权变成裁定参与集形成权。
