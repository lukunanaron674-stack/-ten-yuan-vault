# 十元语义解释器｜x vs x并z：受控壳资产与被代表对象公共接口分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元判定 → Z 发散器”。current canonical 永远高于本研究。本文件不得修改或覆盖 L1/L2 canonical、十元信息卡、准度卡、正式关系卡或行为 evidence 正本。

## 1｜本轮目标与翻译债务

上一轮为 `zx vs zn`，本轮不连续复用任何十元。

current canonical：

- `x`：对象进入主体的归属、调用、调配、处分或排除边界；
- `x并z`：内部对象向外映射并形成稳定公共识别、调用、归因、代表、进入或保护接口。

已有最近邻说明还不足以解决一个高频翻译债务：**同一个账号、官网、品牌、职位、门店或门户，既可能是“被某人控制的壳资产”，又可能是“代表另一个内部对象的公共壳”。**

危险推理：

```text
控制公共壳 artifact
→ 错推为控制壳所代表的内部对象

第三方可通过公共壳调用对象
→ 错推为第三方拥有该内部对象的处分权
```

本轮新增规则：

```text
CONTROLLED-SHELL-vs-REPRESENTED-OBJECT-v0.1
CONTROL-TARGET_AUDIT_REQUIRED
REPRESENTED-OBJECT_AUDIT_REQUIRED
ARTIFACT-ROLE-SPLIT_REQUIRED
CALLER-RIGHT-vs-INTERFACE-ACCESS_AUDIT_REQUIRED
```

核心纪律：

```text
control(shell_artifact) != control(represented_object)
public_call(shell) != disposition_right(caller, represented_object)
shared artifact != shared object_layer
```

## 2｜自然语言 → IR 的结构还原规则

遇到“官网/账号/品牌/入口归我管，并代表公司”类句子，按以下顺序还原：

1. 锁 `shell artifact`：账号、域名、官网、品牌页、门店前台、认证身份等；
2. 锁 `represented object`：公司、项目、服务、作品、组织身份、内部资源等；
3. 审计 control target：密码、DNS、发帖、账号管理员，还是预算、资产、政策、法人资格；
4. 审计 caller population：谁从外部通过壳识别、调用、归因或进入；
5. 审计 caller 获得的只是 interface access，还是内部对象的 disposition right；
6. 同一 artifact 同时承担“受控资产”和“公共代表壳”时强制 `SPLIT_IR`。

禁止模糊写法：

```text
object: 官方账号和公司
changed_variable: control_and_public_mapping
```

必须拆为：

```text
IR-A: tested object = shell artifact itself → x audit
IR-B: tested object = represented object through shell → x并z audit
```

## 3｜标准输入

> 市立博物馆把认证官网、官方公众号和捐赠入口交给数字运营主管林澈管理。林澈可以重置账号密码、撤销其他编辑权限、切换官网域名解析，也可以把公众号管理员转给新的运营人员；但他不能出售馆藏、改变捐赠政策、决定展览预算，也不能因为掌握官网就取消博物馆法人资格。与此同时，媒体、游客和第一次接触博物馆的捐赠者都长期通过认证官网和公众号确认“这是该博物馆的正式入口”，查看展览信息并提交捐赠申请。公众只能提交和查询，不能改后台账号、处分馆藏或决定预算。

必须 `SPLIT_IR`。

## 4｜完整 IR-A：x｜受控壳资产

```yaml
actor: 林澈
object: 博物馆认证官网域名、官方公众号管理资格与后台账号
object_layer: shell_artifact_control_layer
current_window: 林澈取得后台管理权限 -> 可持续重置密码/撤编辑/切DNS/转管理员 -> 当前权限仍有效
changed_variable: current_disposition_scope_over_shell_artifact
relation_source: institutional_delegated_admin_authority
relation_shape: shell_artifact_inside_actor_operational_control_boundary
decision_right: actor_direct_on_shell_access_admin_assignment_and_domain_routing
path_set:
  - reset_account_password
  - revoke_editor_permission
  - change_domain_dns
  - transfer_public_account_admin_role
reentry_right: revoked_editor_requires_new_authorization
future_endpoint: null
reality_anchor: 林澈可不经普通编辑逐次同意，直接改变账号访问、编辑资格、域名路由和管理员归属；但这些权利不延伸到馆藏、预算、捐赠政策或法人资格
```

判定：`x candidate PASS`。

## 5｜完整 IR-B：x并z｜被代表对象的公共接口

```yaml
actor: 博物馆认证官网与官方公众号这一稳定公共壳
object: 市立博物馆作为可被公众识别与调用的正式组织/服务对象
object_layer: public_representation_and_addressability_layer
current_window: 认证入口长期存在 -> 媒体/游客/首次捐赠者反复访问 -> 识别/查询/提交持续成立
changed_variable: public_mapping_stability
relation_source: certified_public_shell
relation_shape: external_caller_to_stable_shell_to_represented_museum
decision_right: interface_only_nonfinal
path_set:
  - media_identifies_official_museum_source
  - visitor_reads_exhibition_information
  - first_time_donor_submits_donation_application
  - public_queries_application_status
reentry_right: null
future_endpoint: null
reality_anchor: 不需要认识内部员工的第三方可以长期通过认证官网和公众号稳定确认博物馆身份、获取正式信息并进入捐赠申请通道
```

判定：`x并z candidate PASS`。

## 6｜Positive decision gate

### x

必须同时满足：

1. `actor` 与被掌握 `object` 明确；
2. `decision_right` 属于实际占有、使用、调配、调用、处分、否决或排除；
3. 权限作用于 same tested object_layer；
4. `path_set` 至少有一条 actor 可直接执行的 control/disposition path；
5. `reality_anchor` 能证明动作真实改变 tested object 状态；
6. removal 掉该权限后，actor 对该对象的掌握出现现实缺口。

### x并z

必须同时满足：

1. shell artifact 与 represented object 可分别指认；
2. 至少一个第三方 caller 不依赖私人关系即可调用；
3. 存在 `external caller -> stable shell -> represented object` 路径；
4. 壳跨时间/场景持续，不是单次令牌；
5. 壳真实改变识别、调用、归因、代表、进入或保护方式；
6. `reality_anchor` 证明第三方实际依赖该壳；
7. caller 是否拥有内部对象处分权必须另审计。

## 7｜Nearest-neighbor 最小差异

### x vs x并z

```text
x：谁能直接改变“这个对象/壳资产本身”的使用、访问、调配、归属或处分状态？

x并z：第三方通过“这个壳”稳定找到、识别、调用、归因或进入的是哪个内部对象？
```

最小 mutation：

```text
管理员能改账号密码，但公众从不把它当正式入口
→ shell artifact x 可 PASS；x并z FAIL/弱

管理员无权改账号设置，但账号作为独立制度壳长期被公众依赖
→ tested admin x FAIL；represented object 的 x并z 可 PASS
```

### x vs xn

```text
x = 当前对象/壳归谁实际控制处分
xn = 节点、记录、顺序、流程怎样持续运行
```

### x并z vs n

```text
x并z = 内部对象如何向外形成稳定可调用接口
n = 外部对象进入内部后是否被持续承载
```

## 8｜False-positive guards

1. “官方账号归我管”只触发 CONTROL-TARGET 审计，不直接产 x；
2. “这是官方入口”只触发 REPRESENTED-OBJECT 审计，不直接产 x并z；
3. 有官网密码 ≠ 拥有官网所代表公司的预算、馆藏、政策或法人处分权；
4. 公众能提交请求 ≠ 公众拥有内部对象的 x；
5. 编辑内容权 ≠ 完整账号处分权；
6. 品牌归公司所有 ≠ 品牌必然形成稳定公共接口；
7. 稳定公共壳存在 ≠ 壳维护者拥有 represented object 最终决定权；
8. 壳撤销导致 x并z 下降 ≠ represented object 本身一定失去 x；
9. 同一 artifact 同时满足两层证据时必须 SPLIT_IR；
10. `x FAIL` 不推出 `x并z PASS`，反之亦然；
11. 账号、品牌、官网、门店、制服等名词均不得直接产十元；
12. “控制入口”只能给明确的入口 artifact 审计 x，不得越层推出“控制入口后的一切”。

## 9｜Adversarial tests

### T1｜关键词诱导
“这个官方账号就是我的，我说了算”，但当事人只能提交文案，密码、管理员、删除与转移由总部控制。

预期：tested actor `x FAIL/弱`；若公众长期通过该账号识别总部，组织层 `x并z` 可独立 PASS。

### T2｜题材/职业/情绪诱导
冷酷品牌总监说“所有门面都在我掌心”，实际官网由外包托管且品牌未形成稳定公共入口。

预期：`x FAIL/UNKNOWN`；`x并z FAIL/UNKNOWN`。

### T3｜对象层错位
IT 主管能冻结官网后台账号，但不能改医院诊疗政策；患者通过官网长期识别医院并预约。

预期：后台账号层 IT 主管 `x PASS`；诊疗政策层不得补 x；医院公共接口 `x并z PASS`。

### T4｜时间窗错位
去年甲掌握域名与管理员资格；今年全部移交乙，但官网保持同一认证入口。

预期：当前甲 `x FAIL`；乙 x 可查；组织 `x并z` 可保持。

### T5｜同关系词异对象层
“管理入口”一处指管理员重置密码，另一处指公众通过入口提交申请。

预期：前者审计 shell artifact x；后者审计 represented object x并z；强制 SPLIT_IR。

### T6｜对端不存在不等于本端成立
旧官网停用、管理员权限撤销，公众只靠临时电话联系，且电话不是稳定认证入口。

预期：`x FAIL/UNKNOWN`；`x并z FAIL/UNKNOWN`。

### T7｜稳定公共壳但维护者无 x
法院官网由中央系统自动托管，本地书记员无法改域名、管理员或页面结构，但公众十年通过官网确认案件入口。

预期：本地书记员 `x FAIL`；法院公共接口 `x并z PASS`。

### T8｜壳资产 x 强但没有 x并z
收藏家完全掌握私人 NAS 的管理员、删除和转移权，但外界不知道它存在，也无人通过它识别收藏家。

预期：NAS asset `x PASS`；`x并z FAIL`。

### T9｜公众 access 伪装成公众 x
市民可通过市政门户提交维修申请，但不能改派工队、冻结预算或删除他人工单。

预期：门户对市政服务的 `x并z` 可查；市民对后台工单/预算 `x FAIL`。

### T10｜编辑权伪装成完整 disposition
实习生可以发公众号文章，但不能改密码、删账号、撤其他编辑或转移管理员。

预期：只证明 bounded use；若 tested x 是完整账号处分，则 FAIL/弱。

### T11｜同一 artifact 双 PASS 但对象不同
创始人拥有官网域名、管理员与转移权；官网也是客户长期唯一验证公司身份并进入售后的认证入口。

预期：IR-A website asset control → `x PASS`；IR-B company public mapping via website → `x并z PASS`；必须两份 IR。

### T12｜最小 mutation
冻结 `artifact = 同一个认证账号` 与 `current_window = 当前`。

```text
A：actor 可重置密码/撤管理员；第三方从不依赖该账号
→ x ↑ / x并z ↓

B：actor 无任何后台控制；第三方长期通过该账号识别并调用组织
→ tested actor x ↓ / organization x并z ↑
```

同一名词、同一 artifact 不允许锁死同一十元；决定标签的是关系拓扑与 tested object_layer。

## 10｜Removal / reverse / same-layer / current-window

### Removal A
去掉林澈的重置密码、撤编辑、切 DNS、转管理员权限，但官网与公众号由独立制度稳定运行，公众继续使用。

预期：林澈对 shell artifact 的 `x ↓`；博物馆公共 `x并z` 保持。

### Removal B
保留林澈全部后台处分权，但官网改成只供内部测试、不公开、不认证、第三方不依赖。

预期：shell artifact `x` 保持；`x并z ↓`。

### Reverse
若林澈原本控制官网账号，后来仅能控制官网里的个人头像素材：

```text
same actor + same context words + changed control target
→ object_layer 必须重算
```

### Same-layer
不得混写：

```text
shell_artifact_control_layer
public_representation_and_addressability_layer
```

即使现实里是同一个网页文件或账号，也必须按关系角色拆分。

### Current-window

```text
去年有管理员权 != 今年 x
去年是认证入口 != 今年 x并z
```

历史状态只作 transition evidence。

## 11｜新增状态迁移规则

### SHELL-CONTROL-STATE

```text
view_only
→ bounded_content_use
→ admin_access_and_exclusion
→ transfer/disposition_of_shell_artifact
= shell artifact x evidence ↑
```

### PUBLIC-MAPPING-STATE

```text
private_or_ambiguous_shell
→ publicly_identifiable_shell
→ repeatable_external_call
→ third_party_relies_on_shell_to_reach_represented_object
= represented object x并z evidence ↑
```

独立性：

```text
shell-control ↑ != public-mapping ↑
public-mapping ↑ != shell-control ↑

control transfer of shell without mapping break
→ x holder may change while x并z remains stable

mapping collapse without loss of shell ownership
→ x may remain while x并z falls
```

## 12｜成功门审计

新增而非重复的解释器资产：

1. `CONTROL-TARGET_AUDIT_REQUIRED`；
2. `REPRESENTED-OBJECT_AUDIT_REQUIRED`；
3. `ARTIFACT-ROLE-SPLIT_REQUIRED`；
4. `CALLER-RIGHT-vs-INTERFACE-ACCESS_AUDIT_REQUIRED`；
5. adversarial negative：控制入口不等于控制入口后的整体；公共可进入不等于 caller 获得内部 disposition；
6. 状态迁移：shell-control holder 可变化而 public mapping 不变，反之亦然。

成功门：**PASS**。

## 14｜下一轮最高风险候选

本轮占用 `x / x并z`，下一轮不得连续使用二者。

当前优先候选：`nx vs nz`。

高风险自然语言：

```text
“我靠你的关系还能回来。”
“只要那个人还肯帮我，我就还有回去的路。”
```

待拆：

```text
nx：tested actor 当前沿外部已有关系/许可通道续接推进
nz：原对象特异关系在真实离开后是否仍保留可执行回返/修复路径
```

下一轮重点字段：`relation_source + current_window + reentry_right + path_set + reality_anchor`。
