# 十元语义解释器轮转｜x vs zn｜处分边界与不可让渡指导资格分账

> research-only；本记录只增加自然语言→Semantic IR 的候选翻译纪律，不修改 current canonical。

## 0. 本轮目标与翻译债务

L1 将火轴固定为 `zn ↔ x`，共同变量是“对象独立成立资格与归属方式”：`zn` 侧保留自身成立，`x` 侧纳入掌握、调用与处分边界。current 信息卡进一步规定：`x` 核心是“归我掌握”；`zn` 核心是不可轻易让渡的内部意义/原则拥有未来调用、冲突排序与最终指导资格。

自然语言最危险的压缩形式是：

```text
“他是我的人，所以我能决定他的事。”
“这是我的角色，我想怎么改都行。”
“我负责这支队，所以他们必须服从我。”
```

所有格、组织归属、照护关系、创作者身份都可能让解释器把“局部控制权”偷换成“对象整体进入处分边界”；反过来，一句“我尊重他的选择”也不能自动生成稳定 `zn`。

本轮新增规则：

```text
POSSESSIVE-PHRASE-NOT-DISPOSITION-SCOPE-v0.1
CONTROLLED-ASPECT-vs-WHOLE-OBJECT_AUDIT_REQUIRED
PRINCIPLE-GUIDANCE-vs-OBJECT-OWNERSHIP_AUDIT_REQUIRED
REFUSAL-RIGHT-EVIDENCE-vs-NORMATIVE-SLOGAN_AUDIT_REQUIRED
```

核心约束：

```text
“我的X” != X整体进入x处分边界
can assign role/task != can dispose person/selfhood/consent
protects an object's refusal/independent endpoint != lacks all x control
has x over one aspect != zn automatically disappears
states respect/autonomy != stable zn
```

### IR 结构还原纪律

遇到所有格、归属词、管理词、保护词时，先做四步：

1. 把名词短语拆成 `whole_object` 与 `controlled_aspect`：人、角色、作品、账户、席位、设备本体，与其工作包、权限位、排期、使用权、展示版本等不得默认同层。
2. 对 `x` 只抽取 actor 当前可执行的占有/使用/调配/冻结/转交/处分动作，不能用“属于我”作为替代证据。
3. 对 `zn` 抽取明确原则命题，并检查它是否在真实冲突中排序候选、无奖励仍进入判断、跨阶段保留未来指导资格。
4. 若同一句同时含局部控制与不可让渡原则，必须 `SPLIT_IR`；不得用一个 `changed_variable: ownership_or_respect` 混装。

`changed_variable` 若只写 `ownership`、`control`、`respect`、`autonomy`、`belongs_to_me`，均为 `NEEDS_MORE_STRUCTURE`。

## 1. 标准输入

> 制片组负责人林澈可以给组内演员分配拍摄工作包、调整班次、冻结片场工作证，并在项目期内回收公司配发的设备；这些权限无需逐次请示。但演员本人对高风险动作保留签署或拒绝同意的资格，林澈不能代签。林澈一直坚持“危险动作必须由当事人自己同意，不能因为进度、预算或我是负责人就替他决定”。一次夜戏延期会损失预算且没有媒体在场时，他仍取消了未获本人同意的动作，并事后明确以后同类冲突仍按此原则处理。

该句必须拆成两个 IR。

### IR-A｜x

```yaml
actor: 林澈
object: 项目期内演员的工作包、班次、片场工作证与公司配发设备的使用状态
object_layer: bounded_project_role_and_resource_disposition_layer
current_window: 项目开始 -> 日常拍摄 -> 当前管理权限持续有效
changed_variable: current_bounded_disposition_scope
relation_source: institutionally_delegated_project_management_authority
relation_shape: specified_project_role_and_resource_aspects_inside_actor_direct_control_boundary
decision_right: actor_can_assign_work_packages + adjust_shifts + freeze_work_badge + reclaim_company_equipment
path_set:
  - assign_work_package
  - adjust_shift
  - freeze_work_badge
  - reclaim_company_equipment
reentry_right: frozen_badge_requires_rule_based_reactivation
future_endpoint: authority_ends_or_changes_when_project_or_delegation_ends
reality_anchor: 林澈无需逐次请示即可现实改变工作包、班次、工作证和公司设备状态，但不能代替演员签署高风险动作同意
```

判定：`x PASS`，但仅限明确的项目角色/资源处分层；不得把 object 扩成“演员本人整体”。

### IR-B｜zn

```yaml
actor: 林澈
object: “高风险动作必须由当事人本人同意，负责人不得以进度或预算替代其同意”这一内部原则
object_layer: internal_nontransferable_principle_guidance_layer
current_window: 原则已存在 -> 夜戏预算冲突 -> 无媒体/奖励 -> 未获本人同意 -> 取消动作 -> 事后保留未来调用资格
changed_variable: principle_conflict_ranking_and_future_guidance_eligibility
relation_source: actor_internalized_nontransferable_principle
relation_shape: internal_principle_preserves_person_specific_consent_as_non_substitutable_and_ranks_schedule_or_budget_below_it
decision_right: principle_has_internal_conflict_ranking_and_future_guidance_eligibility
path_set:
  - force_action_for_schedule_or_budget: normatively_rejected
  - require_person_specific_consent: principle_preferred
reentry_right: null
future_endpoint: same_principle_remains_eligible_in_future_high_risk_action_conflicts
reality_anchor: 在延期造成预算损失且无人观看时，林澈仍取消未获本人同意的动作，并明确以后仍按同一原则处理
```

判定：`zn PASS`。

## 2. Positive decision gates

### x positive gate

同时满足：

```text
X1 tested object / controlled_aspect 明确；
X2 current_window 内 actor 拥有现实可执行的占有、使用、调配、冻结、排除、转交或处分动作；
X3 decision_right 指向该具体 object_layer，而不是职位/所有格词；
X4 reality_anchor 能证明 actor 现在无需额外自由裁量批准即可改变该对象状态；
X5 removal 掉该 control right 后，actor 对该层对象的现实能力出现缺口。
```

### zn positive gate

同时满足：

```text
ZN1 原则/意义命题明确；
ZN2 主体把它视为不能轻易让渡，而非一次情绪或口号；
ZN3 存在至少两个现实冲突候选，原则能够改变排序；
ZN4 拿掉奖励、认可、观众或当前利益后仍进入判断；
ZN5 跨阶段保留未来调用/最终指导资格；
ZN6 reality_anchor 至少给出一次与现实代价相冲突的行为或稳定反事实证据。
```

### 同轴防偷换

```text
x 的 decision_right 证明“actor 能改什么对象状态”。
zn 的 decision_right 证明“哪项内部原则有资格排序选择”。
两者不得共享同一条抽象 `has_right` 作为正证据。
```

## 3. Nearest-neighbor 最小差异

### 3.1 局部管理权 vs 对象整体处分

```text
负责人可排班、分工、冻结工作证
→ 对这些 aspect 可 x

负责人因此可替演员签署危险动作同意
→ 不成立；object_layer 越界
```

最小改变只是把“排班权”扩写成“替本人同意”，如果没有新的权源与现实权限证据，解释器必须拒绝扩层。

### 3.2 保护独立同意的稳定原则 vs 一次礼貌尊重

```text
预算受损、无人观看仍拒绝代签，未来继续适用
→ zn evidence 强

负责人说“我尊重大家意见”，但冲突时随时覆盖
→ zn FAIL/不足
```

### 3.3 x 与 zn 可同时成立，不做互斥捷径

```text
对班次/设备有 x
+
对危险动作同意坚持不可替代原则有 zn
→ SPLIT_IR
```

L1 的相反轴不等于案例里两端不能在不同对象层同时显影；只有 same-layer、same-variable 时才讨论相反方向。

## 4. False-positive guards

```text
“我的员工/我的孩子/我的角色/我的作品” != 整体 x
职位是老板/父母/导演/作者 != x
有合同关系 != 对人的全部处分权
可以安排工作 != 可以替代人格/同意/独立判断
保护对象一次 != zn
说“尊重自由” != zn
对象有拒绝权 != actor 必然 zn；可能只是法律外部约束
actor 有局部 x != zn 必然下降
zn PASS != actor 对对象没有任何 x
x FAIL != zn PASS
zn FAIL != x PASS
```

特别锁定：

```text
EXTERNAL-LAW-vs-INTERNAL-PRINCIPLE
```

如果负责人只是怕违法处罚才不强迫演员，优先把 relation_source 记为外部制度约束；不能把“结果看起来尊重选择”倒推成 `zn`。

## 5. Removal / reverse / same-layer / current-window

### Removal A：移除项目管理权

把排班、工作证、设备调配权全部交给制片办公室，但林澈仍在无奖励条件下坚持危险动作本人同意：

```text
林澈 x ↓
林澈 zn 可保持
```

### Removal B：移除内部原则

保留全部班次/设备控制权，但林澈稳定改判“预算足够重要时可以替演员决定”：

```text
x 保持
旧 zn evidence ↓
```

### Reverse

把“本人同意优先于预算”稳定反转为“预算优先，负责人可替代本人决定”，只反转原则排序轨；除非管理权限也发生事实变化，否则不能据此自动提高 x 的处分范围。

### Same-layer audit

```text
person_as_rights_bearing_subject
!=
project_role_assignment_state
!=
company_equipment_use_state
!=
internal_principle_guidance
```

同一个自然语言名词“演员”可以同时出现在多个层，但 IR 必须明确 tested object 是“人本人”还是“其项目角色状态/公司资源权限”。

### Current-window audit

去年拥有排班权、今年合同已结束：旧 x 不继承。
去年坚持原则、今年已稳定明确放弃：旧 zn 不继承。
当前职位不允许把历史 control scope 或历史 principle state 自动续贴。

## 6. Adversarial tests

| # | 类型 | 输入 | 预期 |
|---|---|---|---|
| 1 | 关键词诱导 | “他是我的人，我当然尊重他的选择。”无权限与冲突事实 | x/zn 均 `NEEDS_MORE_STRUCTURE` |
| 2 | 题材/职业/情绪诱导 | 黑帮老大深情说“我的兄弟谁也不能动” | 不凭黑帮、深情、占有语气判 x/zn |
| 3 | 对象层错位 | 主管能冻结员工系统账号，因此声称能替员工签离职协议 | 账号层 x 可查；人格/合同决定层不得扩 x |
| 4 | 时间窗错位 | 去年导演有最终排班权，今年项目结束；去年也坚持安全原则，今年公开撤回 | 当前旧 x/zn 均不得继承 |
| 5 | 同关系词异对象层 | “我的角色”一处指版权资产，一处指角色在故事中的独立价值原则 | 必须拆 object_layer；不得共享 ownership 变量 |
| 6 | 对端不存在不等于本端成立 | 负责人既无真实控制权，也没有稳定原则，只是嘴上说“大家自己决定” | x FAIL/UNKNOWN；zn FAIL/UNKNOWN |
| 7 | 法律约束伪 zn | 负责人只因违法会被罚款才不强迫演员，一旦豁免就强迫 | 不凭尊重结果判 zn；relation_source 优先外部制度 |
| 8 | 所有格伪 x | “我的孩子”但家长无法处分孩子财产、身体和法定权利 | 所有格不足以整体 x；逐层审具体监护权限 |
| 9 | 局部 x + 强 zn | 教练可排训练时段，但无监督时仍坚持运动员伤病可拒训 | 排期层 x PASS；原则层 zn 可 PASS；SPLIT_IR |
|10| 强 x + 无 zn | 公司拥有设备并可任意调拨，但只按成本决定是否保留项目 | 设备层 x PASS；不可由“保护资产”补 zn |
|11| 原则强但对象不归属 | 医生坚持“急症不得因贫困拒诊”，患者实际属于另一医院且医生无调配权 | zn 可查；对患者/资源 x 不自动成立 |
|12| mutation | A=可排班但不能代签且稳定尊重本人同意；B=仍可排班但原则改成可代替本人决定 | x 可保持；zn 必须重审/下降；不得把原则反转误写成 x 自动上升 |

## 7. 状态迁移规则

### x 轨

```text
symbolic_possessive_only
→ bounded_use_right
→ allocation/exclusion_right
→ transfer/freeze/disposition_right_on_defined_aspect
= x evidence ↑
```

禁止跨越 `controlled_aspect` 自动升级到 `whole_object_disposition`。

### zn 轨

```text
courtesy_or_slogan
→ explicit_principle
→ principle_changes_conflict_ranking
→ no_reward_or_counter_interest_still_guides
→ cross_stage_future_guidance_eligibility
= zn evidence ↑
```

两轨独立：

```text
x ↑ != zn ↓
zn ↑ != x ↓
```

只有同一对象层、同一核心变量、相反方向均有证据时，才允许进一步调用 L1 火轴相反结构；本研究不建立新的正式关系机制。

## 8. 成功门

本轮不是扩案例，而是新增以下解释器资产：

1. `POSSESSIVE-PHRASE-NOT-DISPOSITION-SCOPE`：所有格不得充当 x 的处分范围证据；
2. `CONTROLLED-ASPECT-vs-WHOLE-OBJECT`：强制拆分局部受控 aspect 与对象整体；
3. `PRINCIPLE-GUIDANCE-vs-OBJECT-OWNERSHIP`：zn 原则指导资格与 x 对象处分权使用不同 evidence channel；
4. `EXTERNAL-LAW-vs-INTERNAL-PRINCIPLE`：外部约束造成的“尊重结果”不得冒充 zn；
5. mutation 锁：原则排序改变不得自动改变 x scope，控制权变化不得自动改写 zn。

结论：`PASS`，达到研究提交成功门；不得覆盖 canonical。
