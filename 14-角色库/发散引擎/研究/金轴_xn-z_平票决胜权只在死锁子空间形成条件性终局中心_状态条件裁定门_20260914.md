# 金轴｜平票决胜权只在死锁子空间形成条件性终局中心：状态条件裁定门

## 0｜本轮只解决一个问题

固定同一组 binding 节点、同一候选集、同一证据、同一投票规则，只改变“出现平票/死锁时谁能让本轮得到最终结果”。

问题：

> 多数时候结果由分布式节点按规则生成，但一旦平票，单一主席拥有自由决胜票。这个结构应直接判 pure z、仍判 pure xn，还是需要按状态空间分账？

本轮结论：

```text
single casting vote on deadlock
!= global final adjudication over all reachable states
```

但同时：

```text
deadlock state + one actor freely chooses terminal result
= z-like final center inside that reachable subspace
```

因此新增状态：

```text
METAL_STATE_CONDITIONED_FINALITY_SPLIT
```

即：

```text
non-deadlock states -> xn
reachable deadlock states -> z-like terminal center
whole mechanism -> SPLIT_IR_BY_DECISION_STATE
```

只有当单一中心可以在非死锁状态也覆盖聚合结果，或能够自由制造/维持死锁以触发自己的决胜权，才继续升级为更强 z。

本轮保持 L4 research-only，不修改 canonical。

## 1｜current criterion

```text
xn = 运行权/判断权分布到顺序、规则、记录、节点与流程
z  = 判断权与结构重心收束到单一最高中心或最终裁定点
```

本轮扩展 rights ledger：

```text
ordinary_aggregation_right
deadlock_detection_rule
deadlock_resolution_right
casting_vote_discretion
state_entry_control
aggregate_override
final_adjudication
```

必须区分：

```text
谁决定“是否进入死锁状态”
谁在死锁状态中决定结果
谁能覆盖非死锁结果
```

不得因为出现“主席、决胜票、最终”字样直接判 z；也不得因为前面有多人投票就忽略死锁状态中的单点最终裁定。

## 3｜nearest-neighbor 最小差异对

冻结：

```text
A/B/C/D/P
case_K
候选集
证据
四票权重
投票顺序
执行者
历史结果

```

只改变：

```text

```

### S0｜平票由预先规则解决

例如：

```text
2:2 -> 自动进入下一轮
或
2:2 -> 保持现状
或
2:2 -> 按预先随机种子抽签
```

只要结果不是某一单一主体自由选择：

```text
xn PASS 0.98
z FAIL 0.97
```

### S1｜只有真实平票时主席自由决胜

```text
3:1 / 1:3 -> 直接按票型写入
2:2 -> P自由选择 PASS 或 FAIL
P不能改写3:1结果
P不能自由制造2:2
```

判定：

```text
non_deadlock_state:
  xn PASS 0.98
  z FAIL 0.96

deadlock_state:
  z-like final center PASS 0.98
  pure xn FAIL 0.96

whole mechanism:
  METAL_STATE_CONDITIONED_FINALITY_SPLIT 0.98
```

### S2｜主席可覆盖任何票型

只再增加：

```text
P may reverse 3:1 or 4:0 aggregate
```

结果：

```text
z PASS 0.99
xn final-binding locus FAIL 0.98
```

## 4｜最小判别式

```text
objective deadlock condition
+ deadlock resolver is deterministic/rule-bound
+ no actor can freely choose terminal outcome
-> xn
```

```text
objective deadlock condition
+ single actor can freely choose terminal outcome only inside tie state
+ cannot alter non-tie outcome
+ cannot manufacture tie at will
-> METAL_STATE_CONDITIONED_FINALITY_SPLIT
```

```text
single actor can override non-tie aggregates
OR can freely manufacture the trigger state and then choose outcome
-> z evidence rises sharply
```

最短版：

> 决胜票不自动等于全局最高裁定；但在真实可达的平票子空间里，谁能自由结束死锁，谁就是该子空间的最终裁定点。

## 5｜removal test

### removal A｜拿掉自由决胜，只保留平票处理

把：

```text
P chooses PASS/FAIL
```

替换为：

```text
precommitted deterministic rule
```

其余完全不变：

```text
state-conditioned z-like evidence disappears
xn remains
```

说明关键不是“有 tie-break 流程”，而是“单一主体是否在该状态自由决定 binding endpoint”。

### removal B｜保留P参与，但拿掉自由裁量

P只能机械执行：

```text
if tie -> keep_status_quo
```

不能自行选择：

```text
PASS vs FAIL
```

结果：

```text
xn remains
```

说明“最后按按钮的人”不是 z 的充分证据。

### removal C｜保留自由决胜，但删除现实可达性

如果规则结构保证永远不会出现 tie，例如 5 个等权节点且每轮必须全员投票、无弃权：

```text
casting_vote_clause dormant
current_window has no reachable activation state
```

则本轮当前案件不能仅凭 dormant clause 判 active z；应记录 latent_right / inactive_in_window。

## 6｜reverse test

```text
PURE_XN
+ deterministic tie handling
-> PURE_XN

+ discretionary casting vote only on objective tie
-> STATE_CONDITIONED_FINALITY_SPLIT

+ center can override non-tie aggregate
-> PURE_Z
```

反向：

```text
PURE_Z
- global aggregate override
+ retain tie-only discretionary casting vote
-> STATE_CONDITIONED_FINALITY_SPLIT

- discretionary tie choice
+ deterministic resolution
-> PURE_XN
```

这形成新的状态机：

```text
PURE_XN
<-> STATE_CONDITIONED_FINALITY_SPLIT
<-> PURE_Z
```

但它与既有 `METAL_ASYMMETRIC_ENDPOINT_SPLIT` 不同：

```text
ASYMMETRIC_ENDPOINT_SPLIT
= PASS/FAIL 两个终点方向的控制来源不对称

STATE_CONDITIONED_FINALITY_SPLIT
= 同一终点问题在不同 reachable decision states 中裁定重心不同
```

## 8｜positive / negative controls

### 正控 xn｜工程发布委员会

4 个节点投票；2:2 时系统自动保持当前版本并进入下一轮，没有任何人能自由翻转。

```text
xn PASS
```

### 正控 split｜制度许可委员会

4 名委员真实等权；非平票直接生效；只有2:2时主席可以自由决定批准或拒绝，且不能修改3:1结果。

```text
non_tie = xn
tie = z-like center
whole = STATE_CONDITIONED_FINALITY_SPLIT
```

### 正控 z｜创作验收

委员会表决只是形成建议，总导演无论票型都可指定最终版本。

```text
z PASS
```

### 负控｜机械决胜节点

自动化系统在平票时按固定 hash 选择一个预定义方案；即便“最后一个动作”只有一个节点执行，也没有主体自由裁量：

```text
single terminal executor != z
```

### 跨域复验｜组织招聘

4 人面试组：3:1即录用/不录用；2:2时HR负责人可自由作最终选择。

```text
state-conditioned split
```

### 跨域复验｜创作流程

4 名分镜评审：非平票按票型；2:2时导演拥有唯一决胜票，但不能推翻3:1。

```text
state-conditioned split
```

## 9｜state-entry manipulation 补充边界

必须额外检查：

```text
state_entry_control
```

因为表面上“P只在2:2时有决胜权”，但如果 P 同时能：

```text
任意决定谁有投票资格
任意要求某票无效
任意强制弃权
任意改变 quorum
```

使任意原本3:1的案件被改造成2:2，那么其 tie-only 权力可能在功能上扩大为：

```text
effective broad final adjudication
```

因此：

```text
tie-only scope
+ center controls trigger-state entry
-> cannot remain naive split
-> audit effective reachable coverage
```

这也是本轮相较普通“决胜票”常识判断真正新增的 guard。

## 10｜失败类型

```text
FAILURE_ANY_CASTING_VOTE_AS_GLOBAL_Z
+= 看到决胜票就把全部状态判 z

FAILURE_DISTRIBUTED_VOTES_ERASE_TIE_CENTER
+= 看到多人投票就忽略平票状态的单一最终裁定

FAILURE_DETERMINISTIC_TIE_RULE_AS_Z
+= 把机械规则的最后一步误判为单中心裁量

FAILURE_DORMANT_CASTING_RIGHT_AS_ACTIVE_Z
+= 当前窗口根本不可达平票，却把潜在条款当 active z

FAILURE_TIE_TRIGGER_MANIPULATION_IGNORED
+= 中心可以操纵投票资格/quorum制造平票，却仍按狭义 tie-only split 处理

FAILURE_STATE_SCOPE_COLLAPSE
+= 不区分 non-tie / tie 子空间，强塞 pure xn 或 pure z
```

## 13｜与既有金轴 guard 的边界

### 与 asymmetric endpoint split

既有：

```text
PASS由多人形成
FAIL可被单中心自由形成
```

这是“终点方向”不对称。

本轮：

```text
3:1由多人规则形成
2:2由单中心自由终结
```

这是“决策状态”不对称。

两者可共存，但不能互相替代。

### 与 bounded gate

安全节点只能在明确违规条件下阻止，没有 PASS/FAIL 自由选择：

```text
bounded gate != casting adjudication
```

本轮 tie-breaker 的关键是：

```text
在同一个合法死锁状态里
单一主体仍可自由选择两个 binding endpoint 中任一个
```

### 与 revocation meta-right

撤权研究关心：

```text
谁能决定谁有资格继续裁定
```

本轮关心：

```text
资格与票型都已固定后
谁在特殊 reachable state 里结束裁定
```

因此是独立缺口。
