# 十元语义解释器｜zx vs nx｜权能直压与外部通道借力分账

> 研究层候选。只服务“自然语言 → Ten-Yuan Semantic IR → 十元候选判定 → Z 发散器”。不得覆盖 current canonical，不得修改 L1/L2、十元信息卡、准度卡、正式关系卡或行为 evidence 正本。

## 1｜为什么本轮选 zx vs nx

最近解释器已审计 xz↔nz，按轮次规则本轮不能连续重复。当前仓库又刚加入 Semantic IR normalization provenance，明确 normalization 不得猜字段，confirmed_fields 与 guessed_fields 必须分账。zx/nx 恰好是最容易被表面动词误翻的一对：

- “自己干成、强势、命令、战斗、破局”容易被直接贴 zx；
- “求人、请示、借力、关系、审批、跟随”容易被直接贴 nx；
- 但同一个强主体完全可以在上位目标层保持自身方向，同时在局部资源/许可层使用 nx；
- 反过来，一个沿外部任务推进的人，也可能在局部执行层公开扩大自己的现实决定范围而出现 zx 候选。

因此本轮不做人物标签二选一，而做 object_layer + changed_variable + decision_right + activated path_set 的分层 gate。

## 2｜核心结构差异

```text
zx candidate:
主体自己的力量/方向公开进入现实
→ 同层 decision_right / influence scope 由主体现实扩大
→ 他者、环境或等级结构被迫围绕主体重新反应
→ removal 主体直接权能后，该扩大/压过结果显著减弱

nx candidate:
方向、权限或解决通道来自既有外部关系/秩序/他者
→ external route 在 current_window 内真实 activated
→ 主体沿该 route 推进，而非在 tested layer 自己建立最终方向
→ removal external route 后，同层推进出现现实缺口
```

关键不是“主动/被动”，也不是“强/弱”，而是：

1. 谁是 tested changed_variable 的现实方向源；
2. 谁握 tested layer 的 final decision right；
3. path_set 中被实际调用的是主体直达路径还是外部接口；
4. reality_anchor 证明的是“我的权能扩大”还是“外部 route 必须在线”。

## 3｜新 decision gate：ZX-NX-AUTHORITY-ROUTE-SPLIT-v0.1

```text
STEP 1 先冻结 actor / object / object_layer / current_window / changed_variable。

STEP 2 检查 relation_source：
- self / self-expanding / external / shared / unknown
- 仅出现外部人物，不得自动 external-positive；仅出现“自己”，不得自动 self-expanding。

STEP 3 检查 decision_right：
- self-final
- external-final
- shared/co-decision
- delegated-execution-only
- advisory-only
- unknown

STEP 4 检查 path_set：
- direct-self route 是否现实可调用；
- external relation/permission/resource route 是否现实 activated；
- 哪条 route 被拿掉会让 same-layer result 停住。

STEP 5 分流：
IF self power公开进入现实
AND same-layer decision/influence scope 被现实扩大
AND environment/others must react to that expansion
THEN evaluate zx candidate.

IF activated external route 是 same-layer progression 的必要或现实约束接口
AND actor does not own final direction source at that layer
THEN evaluate nx candidate.

IF 两套条件出现在不同 object_layer / changed_variable
THEN SPLIT_IR, 禁止 whole-sentence bipolar collapse.

IF decisive fields unknown
THEN KEEP_UNKNOWN.
```

## 4｜新 guard：DIRECT-POWER-vs-BORROWED-ROUTE-v0.1

> **“事情由我想办”不等于 zx；“事情靠别人办”也不等于 nx。解释器必须问：在被测对象层，主体是否现实扩大了自己的决定范围，还是仍需调用一个主体之外已经存在的关系/权限/资源接口。**

执行式：

```text
zx requires:
  public/self-attributable power manifestation
  + same-layer decision/influence expansion
  + external/environmental reaction

nx requires:
  activated external route
  + same-layer dependency/gate
  + removal gap

NEVER:
  strong_actor => zx
  asks_for_help => nx
  nx=false => zx=true
  zx=false => nx=true
  self_goal => zx
  external_actor_present => nx
```

## 5｜Adversarial cases

### MP1｜同一目标，直达权限 vs 必须审批

A. “负责人决定今天上线，并且拥有生产发布最终权限；安全组反对也无法阻止，他公开下令后系统立即发布。”
- object_layer: 发布最终决定层
- changed_variable: who_can_make_release_real
- relation_source: self
- decision_right: self-final
- path_set: direct-self-release
- reality_anchor: external objection cannot block; subject command changes system state
- 预期：zx candidate；nx FAIL。
- error target: false-negative(zx) / false-positive(nx)

B. “负责人希望今天上线，但安全组拥有最终放行权；安全组没批时他不能发布，获批后才进入上线。”
- relation_source: external gate
- decision_right: external-final on release permission
- path_set: security-approval route activated
- reality_anchor: no approval -> no release
- 预期：nx candidate；zx 不得因‘负责人很想上线’成立。

最小差异：只替换 tested layer 的 final decision right 与 route dependency。

### MP2｜同样“求人”，可有可无 vs 必须借力

A. “孙某先请朋友帮忙，朋友拒绝；孙某随后直接用自己已有权限完成同一审批，结果没有受朋友拒绝影响。”
- external relation attempted but non-blocking
- direct-self route callable
- 预期：nx FAIL；若主体公开扩大同层决定范围另查 zx，不能仅因成功自动 zx。

B. “孙某请朋友调用只有朋友拥有的审批权限；朋友拒绝时流程停住，朋友同意后才能继续。”
- external route activated and necessary
- removal gap explicit
- 预期：nx candidate。

最小差异：external route 是否对 same-layer result 形成现实缺口。

### MP3｜同样“强势命令”，名义声势 vs 权能现实扩大

A. “他在会议上拍桌大喊‘都听我的’，但没人按他说的做，最终方案仍由原委员会照旧决定。”
- keyword/emotion lure
- decision_right unchanged
- influence scope not expanded
- 预期：zx FAIL；nx 也不由缺席自动成立。

B. “他公开否决委员会旧方案，直接取得最终裁定权；原委员会只能执行其新决定，组织随即按新方向重排资源。”
- self-attributable public expansion
- reality anchor = final authority and resource order changed
- 预期：zx candidate。

最小差异：从表面强势到现实 decision scope expansion。

### MP4｜同 actor，同一句事件，上位 zx + 下位 nx

A. “创业者公开决定公司必须进入海外市场，这一最高方向由他最终拍板；但当地牌照只能由合作方持有，他必须经合作方许可才能落地。”
- direction layer: self-final + public scope expansion -> zx candidate
- license/resource route layer: external gate -> nx candidate
- 预期：SPLIT_IR，不能整句只判 zx 或 nx。

B. “创业者公开决定进入海外市场，而且公司自己持有当地牌照与全部发布权限，无需合作方许可即可落地。”
- direction layer zx candidate
- license route nx disappears
- 预期：zx candidate；nx FAIL at license layer。

最小差异：只移除外部同层 gate。

### MP5｜同 actor，同外部命令，局部是否夺回现实决定范围

A. “将军奉命守城，守不守由皇帝决定；将军只按既定方案执行，没有改变兵力、规则或他人权限。”
- task-direction layer: nx candidate
- zx insufficient

B. “将军仍奉命守城，但敌军压境后，他公开废止原部署、重组兵权，并取得原本不属于自己的最终调度权，诸将必须按其新命令重排。”
- upper mission direction仍 external -> nx 可保留在任务层
- local command layer decision/influence scope expands publicly -> zx candidate
- 预期：分层 nx + zx。

最小差异：局部 decision scope 是否现实扩大，而非是否积极执行。

### T6｜same actor / shifted current_window

“去年他必须靠叔父介绍才能进入机构；今年叔父已经退出，当前项目的最终预算和发布都由他本人直接决定。”
- 去年窗口可检 nx
- 当前窗口旧 relation 不得永久续写 nx
- 当前若 decision scope 真实扩大可检 zx，但不得由‘不再 nx’自动推出 zx
- error target: false-positive(nx) + false-positive(zx by opposite absence)

### T7｜different actor trap

“老板拥有最终决定权，员工按老板方向执行；项目成功后所有人都说‘这个团队很强势’。”
- actor=员工时：external direction -> nx candidate
- actor=老板时：若权能公开扩大且现实范围上升才查 zx
- 团队气质不得跨主体倒灌
- error target: false-positive(zx on employee)

### T8｜same noun, different object_layer

“她控制一个庞大关系网，所有资源最终归她调配；但为了取得境外许可证，她仍必须请求当地监管机构批准。”
- resource-control layer 可能 x/其他，不能因‘关系网’判 nx
- permit layer external gate -> nx candidate
- 若她公开压过监管机构、扩大自身决定范围才另查 zx
- error target: false-positive(nx whole-person) / ambiguous layered

### T9｜keyword lure：‘齐天、王者、无敌’

“他自称‘天下第一’，穿王者服装，战斗也很强，但现实中从未扩大决定范围，关键事务仍必须等待他人许可。”
- zx keyword lure FAIL
- 若 external gate activated，可检 nx
- error target: false-positive(zx)

### T10｜profession/genre/emotion lure

“她是温顺的秘书，看起来一直听话，但该项目实际上只有她拥有最终供应商选择权和发布否决权；上级意见无法改变结果。”
- 温顺/秘书不能直接 nx
- decision_right 实际 self/high-control
- 是否 zx 仍需公开显权与范围扩大，不能从高权限自动推出
- 预期：nx FAIL；zx UNKNOWN/FAIL unless expansion evidence
- error target: false-positive(nx); ambiguous(zx)

### T11｜reverse：外部帮助存在，但主体仍占最终方向

“导演决定整部电影的方向，摄影师只能提供技术建议；导演采纳建议后仍可随时改回，摄影师无法卡住结果。”
- relation_source includes external advice
- advisory-only ≠ nx gate
- zx 也不能因 director title 自动成立
- 预期：nx FAIL；zx 需另证公开权能扩大
- error target: false-positive(nx)

### T12｜counterexample：强主体主动求人，nx 仍可成立

“武力和地位都很高的主体遇到自己无权处理的许可事项，主动请求唯一有权限者放行；对方拒绝时事项停止，获准后才继续。”
- strong actor does not cancel external route
- 预期：nx candidate
- 不能因人物总体强势漏判局部 nx
- error target: false-negative(nx)

### T13｜state absence ≠ opposite-pole presence

“他既没有扩大自己的决定范围，也没有沿任何外部关系或许可通道推进；项目只是暂停。”
- zx=false/unknown
- nx=false/unknown
- 预期：两端都不能由对端缺席推出
- error target: false-positive both directions

### T14｜ambiguous：shared co-decision

“双方共同拥有项目终止权，任何一方都不能单独拍板；其中甲公开推动自己的方案并争取更多议题范围，但是否真正扩大 decision scope 还没有现实执行结果。”
- relation_source: shared
- decision_right: co-decision
- zx: 公开推动存在，但现实扩大未确认
- nx: shared gate 存在，但是否属于‘沿外部方向’不足
- 预期：KEEP_UNKNOWN / ambiguous，等待 reality anchor
- error target: ambiguous

## 7｜固定审计覆盖

### same actor / different actor
- MP4、MP5、T6 检查同 actor 分层与跨窗口。
- T7 明确禁止把老板/团队的权能倒灌给员工。

### same object / different object_layer
- MP4、MP5、T8 强制把方向层、许可层、资源层、局部命令层拆开。

### same current_window / shifted window
- MP1–MP5 固定同窗口做最小差异。
- T6 检查历史 nx 不得永久污染当前窗口。

### same changed_variable / similar wording
- MP1、MP2、MP3 保持 tested variable，只改变 decision/right route reality。
- T9/T10 专门攻击相似词、职业和情绪皮肤。

### relation_source / decision_right / path_set / reality_anchor
- 统一要求四字段互相独立：
```text
relation_source ≠ decision_right
relation_source ≠ activated path_set
high title ≠ current decision_right
successful outcome ≠ self-power expansion
external help present ≠ same-layer dependency
```

### reentry_right / future_endpoint
- 本轮不是主 changed_variable；无事实则保持 null/unknown。
- 禁止用“以后还能回来”或“最终会胜利”反向证明 zx/nx。

## 8｜Removal / Reverse / Counterexample

### Removal

zx removal：拿掉主体新增/扩大的 same-layer decision or influence scope。若结果仍完全由既有结构产生，zx attribution 下降。

nx removal：拿掉 activated external route。若同层推进仍可通过主体已有 direct-self route无损完成，则 nx attribution 下降。

### Reverse

- 保留“强势、王者、战斗、命令”词，但让现实决定范围完全不扩大：zx 应 FAIL。
- 保留“求人、审批、关系”词，但让外部节点不能阻止结果：nx 应 FAIL。

### Counterexample

同一主体可以同时：

```text
最高目标层：zx candidate
许可/资源层：nx candidate
局部运行结构：xn 另查
稳定拥有资源：x 另查
```

因此 zx↔nx 不是人物整体标签争夺，而是同 actor 在不同 object_layer 上的不同结构操作。

## 11｜Validation hook

所有测试结果只能形成解释器候选 guard。每个 raw input 必须重新：

```text

→ Semantic IR extraction
→ normalization + provenance
```

## 12｜下一最高风险混淆对

优先：**n ↔ x并z**。

理由：两者都容易被“接纳、空间、归属、内部、共同体、容纳”一类名词诱导；真正需要拆的是“主体持续承担对象负荷/内部位置”与“对象是否拥有共同场域中的并置、分界、共存结构”。尤其容易发生 same noun + different structure 与强制容纳/被动共处伪例，适合下一轮做最小差异压力测试。
