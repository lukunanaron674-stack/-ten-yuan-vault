# 十元语义解释器｜zx vs zn：自身方向压进现实与他者独立端点保存分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元判定 → Z 发散器”。current canonical 永远高于本研究。不得修改或覆盖 L1/L2 canonical、十元信息卡、准度卡、正式关系卡、行为 evidence 正本。

## 1｜为什么本轮选 zx vs zn

current canonical：

- `zx`：生成并占据最终方向，以自身权能直接作用；L2 进一步锁为“通过施力压退、替代或取消竞争方向而确立自身”。
- `zn`：保留对象自身意义、选择、发展与独立成立资格；L2 进一步锁为“自己成立，同时实际保存他者作为独立对象继续成立”。

高风险自然语言：

- “我坚持我的，你也可以坚持你的。”
- “我把自己的路线推到底，但不会取消你的资格。”
- “我要证明我是对的，但你仍然有选择权。”
- “我赢了，但没有把你从桌上赶走。”
- “我尊重你，但最后必须按我的方向走。”

这些句子同时带有 self-direction 与 other-existence。若解释器只看“坚持/强势/尊重/允许”词面，会在 `zx` 与 `zn` 之间发生双贴或错贴。

本轮不新增案例数量，新增的是：

```text
SELF-DIRECTION-POWER-vs-OTHER-ENDPOINT-PRESERVATION-v0.1

COMPETITOR-ENDPOINT-STATUS_AUDIT_REQUIRED
POWER-EFFECT-vs-ENDPOINT-EFFECT_AUDIT_REQUIRED
```

核心纪律：

```text
actor 自身方向获得更强现实效力
!=
other endpoint 被保存为独立成立位置

actor 赢得当前冲突
!=
other 永久失去独立成立资格

other 没被消灭
!=
actor 主动保存了 other 的独立资格
```

## 2｜自然语言 → IR 的结构还原规则

遇到“我坚持我的，你也保留你的”一类句子，不得直接双贴。按以下顺序拆：

### Step A｜锁定 tested actor 与 tested object

必须分别问：

1. actor 的**自身方向**是什么？
2. 与它竞争或并存的 other endpoint 是什么？
3. 两者是否在**同一 object_layer**？

若“我坚持产品方向A，但你保留自己的私人信仰”属于不同层，必须 `SPLIT_IR`，不能拿私人信仰的独立资格给产品层补 `zn`。

### Step B｜审计 self-direction 的现实效力

检查：

```text
表达/偏好
→ 可执行权能
→ 权能现实使用
→ 竞争方向、他者或秩序必须重新反应
```

只有后两段真实发生，才进入 `zx` positive gate。

### Step C｜审计 other endpoint 的当前资格

检查 other 是否仍拥有：

- 自己的选择权；
- 自己的继续成立路径；
- actor 不能单方撤销的资格边界；
- 可现实行使的同层 decision right。

只有“other 没被碰”不够。必须证明 other 的独立成立资格在 tested relation 中被现实保存。

### Step D｜区分 outcome 与 qualification

必须把“谁在当前冲突中赢”与“谁仍有资格作为独立 endpoint 存在”拆开：

```text
current outcome winner
!=
endpoint qualification owner
```

actor 可以赢得一次项目方向，却仍然保留 other 在下一项目、另一预算池或同层 veto 中的独立资格；也可以嘴上尊重对方，但通过新权能彻底撤销其同层资格。

## 3｜标准输入句

> 两位联合创始人原本各自拥有一条产品线，A 负责专业版，B 负责大众版，双方都能独立决定各自产品的题材和预算。后来公司只能保留一条首页主推位。A 取得主推位最终配置权，把专业版设为唯一首页主推，并取消 B 对首页主推位的同等冻结权；但 A 没有取得大众版的选题、预算或存续处分权，章程仍规定 B 可以独立运营大众版，也可以拒绝 A 改动大众版内容。

该句必须拆成两个 IR。

## 4｜完整 IR-A：zx

```yaml
actor: A
object: 首页主推位的产品方向与现实配置
object_layer: homepage_priority_direction_layer
current_window: A/B均可争夺主推 -> A取得最终配置权 -> A将专业版设为唯一主推 -> B失去同等冻结权
changed_variable: directional_power_distribution
relation_source: actor_asserted_direction_with_new_final_configuration_authority
relation_shape: coequal_competing_directions_to_actor_direction_with_binding_priority
 decision_right: actor_final_on_homepage_priority
path_set:
  - actor_direction: professional_product_homepage_priority
  - competing_direction: mass_product_homepage_priority
  - actor_configuration_right
  - competitor_equal_freeze_right_removed
reentry_right: competitor_requires_new_authority_to_regain_equal_homepage_priority
future_endpoint: professional_product_remains_priority_if_current_authority_holds
reality_anchor: A现实使用新增配置权让专业版取得唯一首页主推，B的同等冻结权被取消
```

判定：`zx candidate PASS`。

注意：`zx` 的证据不是“A很坚持”，而是 `directional_power_distribution` 真实改变。

## 5｜完整 IR-B：zn

```yaml
actor: A
object: B对大众版产品线的独立选题、预算与继续成立资格
object_layer: independent_product_line_endpoint_layer
current_window: 双方产品线并存 -> 首页主推权变化 -> 大众版仍独立运行
changed_variable: independent_endpoint_preservation
relation_source: shared_constitutional_boundary
relation_shape: actor_wins_priority_conflict_while_other_endpoint_remains_independently_valid
 decision_right: self_on_self_product_line + other_on_other_product_line
path_set:
  - self_path: A继续决定专业版
  - other_independent_path: B继续决定大众版题材与预算
  - other_refusal_path: B可拒绝A改动大众版内容
reentry_right: null
future_endpoint: null
reality_anchor: 即使A赢得首页主推，A仍不能单方撤销B的大众版、预算或内容决定权，B的拒绝具有现实效力
```

判定：`zn candidate PASS`。

注意：这里不是因为 A “善良”或“尊重 B”，而是因为同层边界真实保存 B 作为独立 endpoint。

## 6｜Positive decision gate

### zx positive gate

至少满足：

```text
ZX1 actor 有明确自身方向；
ZX2 tested object_layer 存在竞争方向、既有秩序或他者现实效力；
ZX3 actor 获得/调用可执行权能，而非仅表达偏好；
ZX4 actor 的权能真实改变 directional_power_distribution；
ZX5 竞争方向/环境/秩序因此被迫重新反应、退位、失去同等效力或被替代；
ZX6 reality_anchor 能落到现实权能变化，不依赖身份、情绪、胜负词或视觉词。
```

### zn positive gate

至少满足：

```text
ZN1 self endpoint 当前成立；
ZN2 other endpoint 当前也真实存在；
ZN3 other 拥有可执行的同层独立 decision right / continuation path；
ZN4 actor 与 other 存在真实关系边界，而非完全无关；
ZN5 actor 不能单方吞并、撤销或改写 other 的独立资格，或该边界由 actor 共同维持；
ZN6 reality_anchor 证明 other 的独立资格正在现实保存，而非仅“暂时没碰”。
```

## 7｜nearest-neighbor 最小差异

### zx vs zn

```text
zx：
“我的方向有没有通过现实权能变得更强，并改变竞争结构？”

zn：
“在我自己成立时，对方是否仍作为独立 endpoint 真实成立？”
```

最小突变：

```text
A把自己的方案推成唯一主推，但B仍有自己的产品线最终权
→ zx 可上升；zn 可同时保持（不同 object_layer 必须拆IR）

A不扩大自己任何方向权，只确保B继续拥有自己的产品线决定权
→ zn 可上升；zx 不自动变化
```

### zx vs x

```text
x：已有对象/资源/权限进入我的掌握与处分边界。
zx：我把自身方向通过权能压进现实，改变竞争方向的现实效力。
```

### zn vs nx

```text
zn：other 的独立 endpoint 被保存。
nx：tested actor 不占最终方向，沿外部既有路线、关系、权限或通道续接。
```

## 8｜false-positive guards

```text
“我坚持自己” != zx
“我尊重你” != zn
“我赢了” != zx
“你没输” != zn
“我没干涉你” != zn
“我允许你存在” != zn（若actor可随时撤销且无稳定边界）
“你还有别的选择” != zn（若该选择不在tested same-layer）
“双方都有意见” != zn
“双方最后都活着” != zn
“最后按我的方案” != zx（若只是外部规则自动选中）
```

特别护栏：

```text
COMPETITOR-NONDESTRUCTION != OTHER-ENDPOINT-PRESERVATION
```

竞争方向只是没有被物理消灭，不等于其同层独立资格被保存。

## 9｜removal / reverse / same-layer / current-window

### Removal A｜移除 zx

把首页主推位恢复为轮换制，A不再拥有最终配置权；B大众版独立权保持。

预期：

```text
zx ↓
zn 保持
```

### Removal B｜移除 zn

保留 A 的首页主推最终配置权，同时赋予 A 单方取消大众版预算、改题和终止产品线的权力。

预期：

```text
zx 可保持
zn ↓
```

### Reverse

若 A 原本能单方取消 B 产品线，后来取消该处分权并建立双方不可互撤边界，而首页主推权不变：

```text
zn ↑
zx 不自动变化
```

若双方产品线独立边界不变，但 A 后来取得首页主推最终配置权并现实压掉 B 的同等主推资格：

```text
zx ↑
zn 不自动变化
```

### Same-layer

必须冻结 object_layer。

```text
首页主推位的竞争方向
!=
大众版产品线的独立存续资格
```

不能拿“B还有大众版”来证明首页主推层的 zn；若要测试首页主推层 zn，必须证明 B 在首页主推层仍保有独立同等资格。

### Current-window

去年 A/B 均有产品线独立权，今年 A 已取得所有产品线最终处分权：不得续贴去年 `zn`。

去年 A 曾强推路线，今年已失去全部推进权：不得续贴去年 `zx`。

## 10｜12 个 adversarial tests

### T1｜关键词诱导

输入：
> “我坚持我的路线，也尊重你的路线。”

事实：双方都没有任何可执行 decision right，最终方向由第三方自动算法决定。

预期：`zx FAIL/UNKNOWN`；`zn FAIL/UNKNOWN`。不得靠“坚持/尊重”直判。

### T2｜题材 / 职业 / 情绪诱导

输入：
> 铁血国王高声宣称“诸侯各守其土”，语气强硬、身份最高。

事实：他既无新增权能改变诸侯路线，也能随时撤销诸侯领地且无稳定独立边界。

预期：不能因国王、铁血、宣告判 zx；不能因“各守其土”判 zn。

### T3｜对象层错位

输入：
> 导演强推自己的电影剪辑版本成为院线版，但尊重演员私人宗教选择。

预期：院线剪辑层可查 zx；私人宗教层的独立资格不能给剪辑层补 zn。必须 `SPLIT_IR`。

### T4｜时间窗错位

输入：
> 去年两位合伙人各管一条产品线；今年A取得全部预算和终止权，但采访仍说“我们一直彼此独立”。

预期：当前 zn 必须下降/失败；历史状态不能继承。

### T5｜同关系词异对象层

输入：
> “我让你保留自己的方向。”

事实 A：指“你可继续经营自己的产品线”。
事实 B：指“你可在会议里表达意见，但最后我能单方撤掉你的项目”。

预期：A 可查 zn；B 不足以判 zn。

### T6｜对端不存在不等于本端成立

输入：
> B的项目因市场自然停产，A没有施力；之后只剩A项目。

预期：B endpoint 消失不推出 A 的 zx；zn 也不能仅因“A没亲手取消B”成立。

### T7｜赢得结果但非 zx

输入：
> 两方案抽签，A方案被随机抽中成为唯一执行方案。

预期：A“赢了”不等于 zx，因 actor 权能未改变竞争结构。

### T8｜未干涉但非 zn

输入：
> A从未修改B项目，因为A本来就完全没有权限接触B项目，双方是两家无关公司。

预期：不能把“没干涉”判为 A 的 zn 保存。

### T9｜zx PASS / zn FAIL

输入：
> A取得总预算、最终选题和撤项权，公开推进A路线，并关闭B路线。

预期：同层 `zx PASS`；`zn FAIL`。

### T10｜zn PASS / zx FAIL

输入：
> 双方章程规定彼此不可撤销对方项目，A也没有增加自己的权能或改变竞争方向效力。

预期：`zn PASS candidate`；`zx FAIL/unchanged`。

### T11｜同一主体不同层双成立

输入：
> A取得首页主推权压掉B的同等首页资格，但B仍独立拥有自己的产品线最终权。

预期：必须 `SPLIT_IR`：首页主推层 `zx PASS`；产品线独立层 `zn PASS`。不得一个 IR 双贴。

### T12｜最小 mutation

冻结：

```text
actor=A
object=B产品线
relation_source=shared_constitutional_boundary
current_window=本季度
```

Mutation 1：

```text
decision_right: A可单方撤销B产品线
path_set: A推进自己的路线并撤掉B
reality_anchor: B失去继续成立资格
```

预期：`zx ↑ / zn ↓`（若 same-layer 自身方向现实效力同步上升）。

Mutation 2：

```text
decision_right: A仅决定A线；B最终决定B线
path_set: self_path + other_independent_path
reality_anchor: B拒绝A改动时具有现实阻断效力
```

预期：`zn ↑ / zx` 必须重新独立审计，不能自动保留。

## 11｜新增状态迁移规则

```text
SELF-DIRECTION-POWER:
preference_only
→ executable_self_direction_right
→ right_used_in_reality
→ competitor/environment_forced_to_react
= zx evidence ↑
```

```text
OTHER-ENDPOINT-STATUS:
other_exists_incidentally
→ other_has_explicit_same-layer_right
→ actor_cannot_unilaterally_revoke
→ other_exercises_independent_path_in_reality
= zn evidence ↑
```

两个状态轨互相独立：

```text
zx ↑ != zn ↓ automatically
zn ↑ != zx ↓ automatically
```

只有在**同一 object_layer + 同一 current_window + 同一 changed_variable** 下，actor 的方向权扩张确实以吞并/撤销 other endpoint 为代价，才允许观察到 `zx ↑` 与 `zn ↓` 的耦合。

## 12｜成功门检查

本轮新增，不是已有机制重复：

1. `COMPETITOR-ENDPOINT-STATUS_AUDIT_REQUIRED`；
2. `POWER-EFFECT-vs-ENDPOINT-EFFECT_AUDIT_REQUIRED`；
3. current outcome winner 与 endpoint qualification 的强制分离；
4. “竞争者未被消灭 != 独立 endpoint 被保存”的 adversarial negative；
5. zx 与 zn 双状态轨及 only-if-same-layer coupling 条件；
6. 同一主体不同 object layer 可分别 zx / zn，必须拆 IR。

因此：`PASS`。

## 13｜下一轮风险候选

本轮占用 `zx / zn`，下一轮不得连续选择二者。

当前下一轮候选：`n vs nz`。

高风险语言：

```text
“我一直给你留着位置”
“你回来以后我会接住你”
“你一直在我这里”
```

需要继续拆：

```text
n = 对象当前进入内部以后，现实负荷是否持续被承载
nz = 对象真正离开以后，原对象特异回返路径是否仍可执行
```

重点字段：`current_window + relation_shape + reentry_right + reality_anchor`。
