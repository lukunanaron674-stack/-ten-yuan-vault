# 单十元发散语法候选 L4

> 本文件只承载可供 `14-角色库/发散引擎/十元发散引擎.canvas` 后续镜像的研究候选。current canonical 永远优先。本文件不得反改 L1/L2、信息卡、准度卡、关系卡或行为 evidence 正本。

## zx｜现实决定半径扩张语法

### 0｜本轮最小研究问题

现有 Canvas 已能问“哪里存在最终方向由主体生成、夺取、扩大或公开反推”，但还没有一个可执行的纵向发散动作。若继续只写“更强、更霸气、更有王权”，就会退化为审美词和案例抽卡。

本轮只解决一个 changed_variable：

```text
changed_variable = subject_effective_decision_radius
```

即：

> **在同一对象层上，主体自己生成的方向，现实中有多大范围必须围绕它重新响应？**

这里的“半径”不是地理距离，而是现实作用范围：哪些对象、节点、角色、规则或行动必须把主体新增方向当成不可忽略的输入。

### 1｜core_variable

```text
core_variable:
  subject_effective_decision_radius
```

最低观测字段：

```text
actor
object_layer
baseline_decision_radius
new_direction_generated_by_actor
public_reality_entry
mandatory_response_nodes
post_change_decision_radius
trigger
```

### 2｜discovery_question

把任意对象交给 zx，不问“它像不像王”，而问：

> **谁只能在既有方向里行动，谁能让自己的新方向进入现实，并迫使更多相关节点改为围绕它重新响应？**

进一步拆成：

1. 当前谁在生成最终方向？
2. 主体自己的方向是否只是个人选择，还是进入了共享现实？
3. 哪些节点原本可以忽略主体，现在不能忽略？
4. 决定范围是否真实从 `R0` 扩张为 `R1`？
5. 扩张后是否需要继续扩张，还是已经达到对象层自然边界？

### 3｜mother_transform

```text
mother_transform:
  EXPAND_SUBJECT_DECISION_RADIUS

R0 = 原本现实中必须响应主体方向的节点集合
D  = 主体自行生成的新方向
T  = 使 D 进入共享现实的真实 trigger
R1 = trigger 后必须重新响应 D 的节点集合

zx candidate requires:
  D originates from actor
  D enters shared reality
  R1 is structurally larger/stronger than R0
  at least one external node changes behavior because D cannot be ignored
```

最短语法：

> **让“我的方向”从只对我有效，变成更多现实节点必须回应的方向。**

这比“变强”更可执行，因为它直接告诉发散引擎要改哪个结构变量。

### 4｜child_branches

以下不是同义词，而是改变 `subject_effective_decision_radius` 的不同结构方式。

#### A｜新增方向接口 `create_new_direction_interface`

```text
原规则没有该方向位置
→ 主体公开提出新的方向/方案/名位
→ 其他节点被迫决定接受、阻断、谈判或重新布局
→ R0 → R1
```

典型锚：孙悟空从“接受天庭已有品级”改成自立“齐天大圣”。重点不是称号，而是原等级体系必须新增响应位置。

发散问法：
- 当前系统里有什么“根本没有给主体的选项”？
- 主体怎样把这个不存在的选项强行变成所有人必须处理的问题？

#### B｜越出原授权边界 `expand_beyond_delegated_scope`

```text
主体原本只在局部范围内有方向权
→ trigger 出现
→ 主体把决定范围推进到原授权之外
→ 上位/平行节点必须围绕新增范围响应
```

关键不是“违令”。若只是把既有任务换一种执行方式，优先检查 xn；若只是使用已有处分权限，优先检查 x。

发散问法：
- 现在是谁允许主体决定到这里为止？
- 什么事件会迫使主体把“我只能决定 A”改成“B 也由我定”？

#### C｜受压后重新占回方向源 `reassert_after_suppression`

```text
主体方向曾被外部秩序压回/夺走
→ 主体重新把自身方向公开推入现实
→ 原本可忽略/压制主体的节点再次必须回应
→ decision radius 回升或超过旧峰值
```

这不是普通“不服输”。若只是个人继续坚持、退出、拒绝，没有使更多外部节点围绕其方向重排，则不够 zx。

发散问法：
- 哪个外部节点让主体的方向暂时失效？
- 主体如何让同一现实再次围绕自己的方向重开响应？

#### D｜从单点否决升级为公共重排 `veto_to_reordering`

```text
主体最初只能说“不”
→ 不再只阻止单一动作
→ 主体提出替代方向并迫使多个相关节点改排
→ local veto → broader direction generation
```

这是本轮新增的高价值分叉：**“否决”本身不是 zx；从单点否决升级为新的公共方向源，才进入 zx 候选。**

它能防止把鸳鸯拒婚、关羽拒受某条件这类强硬拒绝直接写成“扩权”。

### 5｜continue_conditions

只有出现以下任一真实变化时，zx 分支才继续向下长：

```text
1. mandatory_response_nodes 继续增加；
2. object_layer 不变，但 subject 决定范围从局部扩到更宽同层范围；
3. 原先只能响应既有规则，后来开始生成新规则/新方向接口；
4. 被压制后重新占回方向源，且现实响应范围发生可观测恢复或扩大；
5. veto 升级为 replacement direction，使其他节点必须重新排序。
```

允许继续纵向追问：

```text
谁还可以无视主体？
哪个节点仍拥有高一层最终方向权？
主体要让哪一个新增节点也必须响应，才构成下一次结构扩张？
```

### 6｜stop_conditions

出现以下任一情况即停止 zx 纵向套娃：

```text
S1. 只是同一决定范围内更强、更狠、更成功，没有新增必须响应节点；
S2. 只是在既有授权内优化执行方式，优先 xn；
S3. 只是在已有对象/权限上使用、处分、调配，优先 x；
S4. 只是拒绝、退出、不配合，主体方向未扩张为共享现实输入；
S5. 只是借上级、人情、制度、通道推进，主体没有占据最终方向源，优先 nx；
S6. 只产生结果影响，但没有可识别的方向生成与现实响应结构；
S7. 已达到该 object_layer 的自然最高 decision radius，再向上必须换 object layer；此时停止本树，另开对象层。
```

### 7｜nearest_neighbors

#### 最近邻 1｜x

```text
x  = 我现实掌握/调用/处分什么对象或权限。
zx = 我的方向进入现实后，哪些更多节点必须围绕它重新响应。
```

最小差异：

> **已有处置边界内使用权能，不等于扩大决定半径。**

幕后 Boss 已控制全部资源但不改公共方向，可能 x 高而 zx 不高；公开把更多势力压入自己的方向响应范围，才是 zx 变量变化。

#### 最近邻 2｜xn

```text
xn = 把行动、资源、节点组织进流程/时序/执行结构。
zx = 改变最终方向源及其现实作用半径。
```

最小差异：

> **把同一个任务执行得更聪明，不等于取得更大的最终方向权。**

马谡街亭类材料正适合作 guard：违令、换执行方案、局部战术重组若没有让更大现实范围承认新的最终方向，不能因为“我自己做主”就判 zx。

#### 最近邻 3｜nx

```text
nx = 进入既有外部方向/权限/关系通道续接。
zx = 自己生成方向，并让现实扩大对该方向的响应范围。
```

最小差异：

> **借来能办成事的权限，不等于方向源归自己。**

《红楼梦》鸳鸯拒婚可见两者能并存：自身婚姻去留方向由她明确占据，但阻断贾赦仍需进入贾母既有权威接口；不能把“请贾母处理”写成 zx 扩权。

### 8｜removal / reverse

#### removal

拿掉“主体自己生成的新方向”，如果剩余结构仍能由：

- 原制度目标；
- 上级命令；
- 既有授权；
- 既有流程；
- 第三方权威；

完整解释，则本轮 zx mother transform 不成立。

#### reverse

保留主体的强势、战斗力、执行成功、公开姿态，但把 `mandatory_response_nodes` 固定不变：

```text
R1 = R0
```

若仍觉得“很 zx”，说明判断可能被气势/结果污染。

真正的反向测试应是：

```text
主体仍很强
但现实决定半径没有扩大
→ 不计本轮 EXPAND_SUBJECT_DECISION_RADIUS
```

### 9｜counterexample / false-positive guard

#### Guard A｜强拒绝 ≠ zx 扩张

《红楼梦》鸳鸯拒婚可作为最小反例：

```text
个人最终选择非常明确
+ 强烈拒绝外部安排
≠
自动产生更宽公共决定半径
```

只有当“我不嫁”进一步变成“这个家族以后这类婚配规则也必须由我生成/重排”之类的同层真实扩张，才进入本轮母动作。

#### Guard B｜违令 ≠ zx 扩张

《三国演义》马谡街亭类控制：

```text
不照上级方案执行
+ 自己换战术
≠
上位最终方向权已被主体夺取/扩大
```

若 changed_variable 只是执行结构，优先 xn。

#### Guard C｜赢了 ≠ zx 扩张

```text
战斗胜利 / 目标完成 / 对方失败
```

只说明结果，不说明谁成为新的方向源，也不说明决定半径变化。

### 10｜composable_interface

zx 最适合在“方向源/决定半径”变量层与其它十元组合，而不是直接拼标签。

```text
zx × nx:
  同一目标上，主体自己生成最终方向，但实现该方向需要接入外部权限/关系通道。
  interface = direction_source ↔ external_access_route

zx × x:
  主体先拥有局部处分边界，再把该边界公开推进为更宽决定范围。
  interface = possessed_scope → expanded_decision_radius

zx × xn:
  主体先生成/扩大方向，再把新增方向组织成可持续运行流程。
  interface = direction_generation → operationalization

zx × z:
  主体方向已经提出，但只有经过关键裁定点确认/采用后才变成制度现实。
  interface = generated_direction → final_confirmation

zx × xz:
  主体扩张方向的同时压缩其他终点/回头路。
  interface = decision_radius_expansion ↔ return_path_contraction
```

组合硬门：每个十元必须先独立过 current canonical；same actor / same window / same object 不自动等于组合成立。

### 12｜给 Canvas 的最短镜像摘要

```text
zx｜现实决定半径扩张
发现：谁能让“自己的方向”从只对自己有效，变成更多现实节点必须回应？
母动作：EXPAND_SUBJECT_DECISION_RADIUS（R0→R1）
子分叉：新增方向接口 / 越出原授权边界 / 受压后重新占回方向源 / 单点否决升级为公共重排
继续：必须响应节点继续增加、同层决定范围继续扩大或新增规则接口
停止：仅更强/更成功、仅执行优化、仅使用已有权限、仅拒绝退出、仅借外部通道、换对象层
护栏：强拒绝≠zx；违令≠zx；赢了≠zx
组合接口：direction_source 可接 nx external route、x possessed scope、xn operationalization、z final confirmation、xz return-path contraction
状态：L4/L5 research-only candidate
```
