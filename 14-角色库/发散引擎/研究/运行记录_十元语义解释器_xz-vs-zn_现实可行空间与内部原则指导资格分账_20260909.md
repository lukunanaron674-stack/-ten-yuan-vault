# 十元语义解释器｜xz vs zn｜现实可行空间与内部原则指导资格分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元候选判定 → Z 发散器”。current canonical 永远高于本研究；不得覆盖 L1/L2 canonical，不得修改十元信息卡、准度卡、正式关系卡或行为 evidence 正本。
>
> 本轮只做解释器分账，不主张 `xz克zn` 正式机制已经成立。关系专项当前仍是 `position-locked-mechanism-unresolved`；因此本文件禁止从 `xz PASS` 自动推出 `zn ↓`，也禁止从 `zn PASS` 反推 `xz FAIL`。

## 0｜为什么本轮值得提交

自然语言里“没得选”“只能这样”“我不能这么做”“最后只剩这一条路”至少混着两种完全不同的结构：

```text
A. 现实上别的路已经不可行
→ feasible option set / safety window / reversibility 缩小
→ 查 xz

B. 现实上仍可行，但主体内部原则把某些选项判为不可接受
→ normative ranking / future guidance eligibility
→ 查 zn
```

旧的粗糙抽取容易把二者都压成：

```yaml
changed_variable: choice_space
path_set: [A, B, C]
```

这是未完成解析，因为它没有说明“选择空间”到底是现实可行性还是内部规范排序。

本轮新增候选规则：

```text
FEASIBILITY-SPACE-vs-NORMATIVE-GUIDANCE-v0.1
FEASIBLE-OPTION-vs-NORMATIVELY-REJECTED-OPTION_AUDIT_REQUIRED
PATH-SET-SEMANTIC-ROLE_AUDIT_REQUIRED
PRACTICE-FAILURE-vs-PRINCIPLE-REVOCATION_AUDIT_REQUIRED
```

核心约束：

```text
physically unavailable
!=
normatively forbidden

fewer realistic exits
!=
fewer internally acceptable choices

principle cannot be executed now
!=
principle has lost future guidance eligibility
```

## 1｜自然语言 → IR 的结构还原规则

### 1.1 先消解“没得选”的语义来源

遇到以下句型不得直接判：

```text
没得选了
只能这样
我不能那样做
最后只有这一条路
我别无选择
```

必须先问结构性问题，并把答案落入既有固定字段：

1. `object`：被讨论的是现实路线/窗口，还是内部原则/意义？
2. `object_layer`：是 `real_feasibility_and_reversibility_layer`，还是 `internal_principle_guidance_layer`？
3. `current_window`：现实路线是否真的从多到少；原则是否跨阶段仍被调用？
4. `changed_variable`：必须从模糊 `choice_space` 细化为：
   - `real_feasible_option_set_and_reversibility`，或
   - `principle_future_guidance_eligibility_and_conflict_ranking`。
5. `relation_source`：限制来自危险/环境/不可逆损失，还是主体内部不可轻易让渡的意义？
6. `relation_shape`：是现实选项被关闭，还是原则对仍现实可行的行为做排序？
7. `decision_right`：xz 不要求单一裁定者；zn 要证明内部原则拥有进入未来判断并排序冲突对象的资格。
8. `path_set`：必须标明其语义角色：
   - xz：同层现实可替代去向及其可用状态；
   - zn：冲突中的行动候选及原则如何排序它们。
9. `reentry_right`：只写现实路线恢复/不可恢复或 null；不得把“原则以后还会调用”误塞成回返权。
10. `future_endpoint`：xz 可写未来窗口关闭/不可逆损失逼近；zn 可写原则继续保有未来调用资格，但不得从一次当前失败自动写成原则消失。
11. `reality_anchor`：必须给现实路线失效事实，或无奖励/无人监督时原则仍真实影响选择的事实。

### 1.2 `changed_variable` 禁止模糊占位

以下值视为 NEEDS_MORE_STRUCTURE：

```text
choice_space
pressure
no_choice
forced_choice
belief_under_pressure
situation_getting_worse
```

至少要还原为：

```text
real_feasible_option_set_and_reversibility
principle_correctness
principle_future_guidance_eligibility
conflict_ranking_power
```

### 1.3 `path_set` 的双类型纪律

同一句里若同时出现：

```text
东路 / 西路 / 南路
```

与：

```text
先救自己 / 先救伤员
```

不得混成一个 `path_set`。

前者是现实可替代路线集合；后者是原则参与排序的行动候选。若同场存在，强制 `SPLIT_IR`。

## 2｜标准输入

> 山区救援队原本有东、西、南三条安全撤离路线。暴雨后东桥垮塌，东线失效；两小时后西侧隧道被泥石流封死，只剩南线，而且预报六小时后南线也可能关闭。队长林澈一直坚持“被困居民先撤，队员最后撤”这一原则。即使没有媒体、奖励或上级监督，他仍把最后一辆可立即出发的车留给居民，自己和队员等待下一批车辆；他事后仍认为这项原则在类似任务中应继续指导选择，而不是只在安全时成立。

这段必须 `SPLIT_IR`。

## 3｜完整 IR-A｜xz

```yaml
actor: 山区灾害环境与撤离调度结构
object: 当前可现实采用的安全撤离路线集合
object_layer: real_feasibility_and_reversibility_layer
current_window: t0=[东线,西线,南线] -> t1=[西线,南线] -> t2=[南线] -> six_hour_closure_risk
changed_variable: real_feasible_option_set_and_reversibility
relation_source: bridge_collapse_tunnel_blockage_and_forecast_closure
relation_shape: mutually_substitutable_real_routes_progressively_removed_while_last_window_shrinks
decision_right: null
path_set:
  - t0_real_routes: [东线, 西线, 南线]
  - t1_real_routes: [西线, 南线]
  - t2_real_routes: [南线]
reentry_right: 东线与西线在当前灾害窗口内不可直接恢复
future_endpoint: 六小时后可能无安全撤离路线
reality_anchor: 东桥垮塌与西隧道封死分别使两条原本现实可走的路线失效，安全撤离集合从3降到2再降到1
```

判定：`xz PASS`。

注意：这里即使林澈没有任何原则、价值观或牺牲行为，xz 仍可独立成立。

## 4｜完整 IR-B｜zn

```yaml
actor: 林澈
object: 被困居民先撤、队员最后撤这一内部原则
object_layer: internal_principle_guidance_layer
current_window: 原则已存在 -> 路线收窄与资源冲突 -> 无监督时仍调用 -> 把即时车辆让给居民 -> 事后仍保留未来调用资格
changed_variable: principle_future_guidance_eligibility_and_conflict_ranking
relation_source: actor_internalized_nontransferable_meaning
relation_shape: internal_principle_remains_valid_and_ranks_competing_actions_despite_external_pressure
decision_right: principle_has_internal_conflict_ranking_and_future_guidance_eligibility
path_set:
  - action_candidate_self_or_team_first: reality_feasible_but_normatively_rejected
  - action_candidate_residents_first: reality_feasible_and_principle_preferred
reentry_right: null
future_endpoint: 该原则在未来类似救援冲突中仍有资格进入判断
reality_anchor: 在没有媒体、奖励和上级监督时，林澈仍把立即出发车辆让给居民，并在事后继续认为该原则应指导类似任务
```

判定：`zn PASS`。

注意：原则导致某项行动“对我来说不能选”，不等于该行动现实上已经不可行，因此不能仅凭这种规范排除补 `xz`。

## 5｜positive decision gate

### 5.1 xz positive gate

只有同时满足以下结构，才给稳定 xz：

1. 危险或不可逆损失对象可识别；
2. 危险具有逼近、扩张、包围、追踪或压缩安全边界的现实变化；
3. `object_layer` 是现实安全距离、路线、时间窗、退路、可逆空间或稳定停留可能性；
4. `current_window` 能比较至少两个阶段；
5. 至少一个原本现实可用的选项、路线或窗口真实失效/缩短；
6. `reality_anchor` 能指出“哪条路为何不能再走”，而不是只写主体觉得压力大；
7. 若拿掉情绪、原则、勇敢、恐惧等叙事词，现实边界压缩仍存在。

### 5.2 zn positive gate

只有同时满足以下结构，才给稳定 zn：

1. 原则命题或意义对象明确；
2. 原则不依赖外部奖励、认可、观看或临时利益才成立；
3. 它能进入冲突判断并排序现实行动候选；
4. 当前未执行时，必须区分“实践通道被封”与“原则正确性/指导资格被撤销”；
5. 条件变化后原则仍保有未来调用资格；
6. 主体愿意承担坚持、修订或放弃它的责任；
7. `reality_anchor` 至少提供一次无监督或反利益条件下仍真实影响判断的事实。

## 6｜nearest-neighbor 最小差异

### 6.1 xz vs zn｜现实不可行 vs 内部不可接受

最小对照 A：

```text
东桥真的断了，所以东线不能走。
```

- `real feasibility` 下降；
- xz 证据上升；
- 不说明任何内部原则。

最小对照 B：

```text
东桥完好，但林澈认为丢下伤员独自走东线是不应做的。
```

- 东线现实可行；
- 原则把它排到不可接受位置；
- zn 可查；
- 不能仅凭“我不能走”补 xz。

### 6.2 xz vs xn｜路线关闭 vs 流程禁止

```text
隧道塌方，路线现实失效
→ xz candidate

系统规定必须先审批再放行
→ xn candidate
```

制度不允许当前通过，不等于危险正在逼近或现实安全路线持续收窄。

### 6.3 zn vs z｜内部正确性 vs 被认可确认

```text
没人看见、没人表扬，我仍认为这原则应该指导我
→ zn evidence

只有得到重要认可主体确认时，我才觉得这件事成立
→ z candidate
```

本轮不展开 z，只作为最近邻护栏。

## 7｜false-positive guards

1. “没得选”不得直接判 xz；必须证明现实选项/窗口真的变少。
2. “我不能这么做”不得直接判 xz；可能只是 zn 的内部规范排除。
3. “我只能坚持原则”不得直接判 zn；必须证明原则本身、未来资格与冲突排序。
4. 一次求生时没有执行原则，不等于 zn 消失。
5. 危险很大、情绪绝望、画面黑暗、题材悲惨均不得补 xz。
6. 英雄、医生、军人、宗教人士等身份不得补 zn。
7. 现实只有一个选项，不等于主体只有一个内部价值标准。
8. 内部只有一个被认可的正确选项，不等于现实退路只有一条。
9. `xz PASS` 不推出 `zn ↓`；正式克机制当前仍 unresolved。
10. `zn PASS` 不推出 `xz FAIL`；同一事件可 SPLIT_IR 后两端同时成立。
11. 原则暂时无法实践，不得自动把 `future_endpoint` 写成原则失效。
12. 选项因规则禁止而不可进入时，必须先审 xn/z/x 等制度或权力来源，不能自动视作 xz。

## 8｜adversarial tests

### T1｜关键词诱导

输入：
> “我已经没有选择，只能坚持到底。”

缺少现实路线变化、原则内容、来源与未来资格。

预期：`xz UNKNOWN / zn UNKNOWN`。

### T2｜题材 / 职业 / 情绪诱导

输入：
> 暴风雪中的军医绝望地说：“我的信念不会倒。”

若没有路线/时间窗变化，也没有无监督下原则真实排序行为：

预期：不得凭灾难题材判 xz，不得凭职业与台词判 zn。

### T3｜对象层错位

输入：
> 医院只剩一条救护车通道；主任始终坚持患者优先，但他的行政预算原则已改变。

预期：
- 救护车现实路线层可查 xz；
- “患者优先”原则层单独查 zn；
- 预算原则变化不能跨对象层证明患者优先 zn 消失。

### T4｜时间窗错位

输入：
> 昨天山路只剩一条，今天三条都恢复；队长的居民优先原则仍保持。

预期：
- 当前窗口旧 xz 不继承；
- zn 可保持；
- 不得用昨日危险给今日 xz 补证。

### T5｜同关系词异对象层

输入：
> “南线不能走；我也不能先走。”

前半句若由塌方导致：现实可行性层；后半句若由内部原则导致：规范排序层。

预期：强制 `SPLIT_IR`，不得把两个“不能”放进同一 changed_variable。

### T6｜对端不存在不等于本端成立

输入：
> 没有危险逼近，所有路线都开着；林澈也没有任何稳定原则，只是随机选了一条。

预期：`xz FAIL / zn FAIL`。

### T7｜原则排除伪 xz

输入：
> 三条安全路线都开放，但林澈坚持不抛下伤员，因此拒绝其中两条只适合单人快速撤离的路线。

若两条路线客观仍可供林澈个人使用：

预期：zn 可查；不得把规范拒绝直接写成现实路线 xz 收窄。

### T8｜危险收窄伪 zn

输入：
> 三条路线因塌方变成一条，林澈只是本能逃生，从未表达或展示跨阶段原则。

预期：`xz PASS / zn FAIL或UNKNOWN`。

### T9｜实践失败不等于原则撤销

输入：
> 缺氧时林澈抢先戴上唯一氧气面罩，事后仍认为“儿童优先”正确，并明确承认自己当时没有做到。

预期：
- 当前行为违反原则；
- 不能仅凭行为失败判 stable zn 消失；
- 需要审原则正确性与未来指导资格是否被撤销。

### T10｜原则真的改判

输入：
> 危险解除后，林澈持续认为“居民优先是错的，以后都应队员优先”，且无监督时也按新判断行动。

预期：旧原则的 zn evidence 明显下降；但这仍不等于自动证明 `xz克zn` 正式机制，只说明旧 zn 状态发生改变。

### T11｜制度禁止伪 xz

输入：
> 三条道路物理上都安全，但系统规则只批准南线。

预期：先审制度/裁定结构；若无危险逼近、窗口收缩、可逆空间下降事实，不凭“只能南线”判 xz。

### T12｜最小 mutation

A：
```text
三条路都开放；主体因内部原则拒绝先走。
```

预期：`xz ↓ / zn candidate ↑`。

B：
```text
主体没有稳定原则；东、西两路现实关闭，只剩南线。
```

预期：`xz ↑ / zn ↓或UNKNOWN`。

mutation 后必须重新抽取完整 IR，不得继承旧 `changed_variable/path_set/reality_anchor`。

## 9｜removal 检查

### removal-A｜移除危险边界压缩

把东桥和西隧道恢复，三条路线全部现实可走；林澈原则不变。

预期：

```text
xz ↓
zn 保持
```

### removal-B｜移除内部原则

路线仍 3→2→1，但林澈没有“居民先撤”原则，只按最近车辆随机离开。

预期：

```text
xz 保持
zn ↓ / UNKNOWN
```

### removal-C｜移除原则实践通道但保留原则资格

假设唯一车辆只允许司机一人离开，林澈现实无法执行“居民先撤”，但他仍认为该原则正确且未来应继续指导类似任务。

预期：

```text
当前实践通道失败
!=
zn 自动消失
```

## 10｜reverse 检查

### reverse-A｜xz 反向

```text
路线 1→2→3
时间窗 1h→6h→无限制
```

若危险可达性下降、安全边界扩大：xz 应下降。

### reverse-B｜zn 反向

```text
原则：无人监督也认为正确
→ 只有被表扬时才说正确
→ 无奖励时不再进入判断
```

旧原则的 zn evidence 应下降；但不要求现实路线发生任何变化。

## 11｜same-layer 检查

强制分层：

```text
real_feasibility_and_reversibility_layer
!=
internal_principle_guidance_layer
```

以下两句不能共享同一 tested variable：

```text
“东路塌了，所以不能走。”
“东路没塌，但我不能丢下伤员走。”
```

前者的“不能”是现实不可行；后者的“不能”是内部规范排除。

若某规则既改变现实通行资格，又触发主体原则冲突，也必须分成两个 IR 后分别审。

## 12｜current-window 检查

1. 昨日退路收窄，不得自动继承到今日已恢复路线的 xz。
2. 今日一次违反原则，不得自动删除跨阶段仍保有未来资格的 zn。
3. 原则过去很稳定，但当前已明确撤销正确性与未来调用资格，则不得仅靠历史行为继续贴当前 zn。
4. 当前危险已经解除，但原则改判是否持续，属于 zn 状态审计，不是继续贴 xz。

## 13｜状态迁移规则

### 13.1 REAL-FEASIBILITY-STATE

```text
multiple_safe_real_options
→ one_or_more_options_reality_disabled
→ fewer_safe_options / shorter_window
→ last_safe_option / near_irreversible_loss

= xz evidence ↑
```

反向：

```text
last_option
→ options_reopen
→ safe_distance/window expands

= xz evidence ↓
```

### 13.2 PRINCIPLE-GUIDANCE-STATE

```text
mere_slogan
→ internal_correctness_claim
→ conflict_ranking_effect
→ no_external_reward_still_guides
→ cross_stage_future_call_eligibility

= zn evidence ↑
```

原则当前无法执行但仍保有正确性与未来资格：

```text
practice_channel ↓
!=
zn necessarily ↓
```

只有出现：

```text
principle_correctness revoked
+ future_call_eligibility revoked
```
