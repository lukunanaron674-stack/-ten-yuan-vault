# 十元语义解释器｜x vs xz｜当前处分边界与未来终点收窄分账

> 研究层候选。只服务“自然语言 → Ten-Yuan Semantic IR → 十元候选判定 → Z 发散器”。不得覆盖 current canonical，不得写入十元信息卡、准度卡、正式关系卡或行为 evidence 正本。

## 1｜本轮翻译债务

上一轮 `zn vs x` 已把“可撤销处分边界”从“他者独立端点保存”中拆出，但解释器仍有一个高风险捷径：看到“以后还能拿回来 / 最终会回到这里 / 被收回 / 回归 / 无法回头”等未来词，就可能把 current x 与 xz 混判。

current 水轴研究已明确：xz 的主骨不是“未来存在一个结果”也不是“一次不可逆决定”，而是：

```text
未来终点先取得结构地位
+ 当前选择/路径空间持续收窄
+ 不同路径出现汇流
+ 临界不断逼近
```

因此新增 IR 约束：

```text
reentry_right ≠ xz
future_endpoint ≠ xz
current possession/control ≠ future convergence
future loss of x ≠ current x absent
future return possibility ≠ xz positive
```

## 2｜结构还原规则

遇到“拥有 / 掌握 / 借用 / 收回 / 归还 / 最终回去 / 迟早 / 无法回头”等句子时，禁止先贴标签，按以下顺序还原：

1. actor：谁是当前被判主体；
2. object：被调用/处分/回返/收窄的具体对象；
3. object_layer：当前资源/权限层，还是未来路径/终点层；
4. current_window：只截取当前现实有效窗口；
5. changed_variable：当前变的是 `control_scope`，还是 `real_option_set / future_endpoint_convergence`；
6. relation_source / relation_shape：当前支配来源与未来路径形状分别记录，不互相代替；
7. decision_right：当前谁能实际调用、排除、调配、处分；
8. path_set：列当前真实可行路径；xz 必须审计路径是否随阶段真实减少/汇流，而不是只列故事里提到的选项；
9. reentry_right：退出/失去后能否自行重新进入。它主要用于 x/nx/nz 等边界分流，本身不是 xz positive gate；
10. future_endpoint：只有文本真实给出结构性未来终点才填；“有计划/有期限/将来归还”不足以自动升级；
11. reality_anchor：x 看当前现实拨动；xz 看路径空间是否被未来终点现实持续压缩。

## 3｜标准输入与完整 IR

输入：

> “林岚现在拥有工作室服务器管理员权限，可以创建账号、冻结账号和调整存储额度。公司规定六个月后权限自动回收，但在这六个月里她不需要再次申请。与此同时，服务器迁移项目已经锁定最终切换日：旧机房每月关闭一组服务，替代延期窗口也逐月取消，到切换日前所有生产服务都必须汇入新集群。”

### IR-A｜当前权限处分层

```yaml
actor: 林岚
object: 工作室服务器管理员权限
object_layer: 当前服务器账户与额度管理权限层
current_window: 权限已授予 -> 六个月有效期内 -> 自动回收前
changed_variable: current_control_scope
relation_source: institutional_conferral
relation_shape: time-bounded-current-direct-control
decision_right: actor_direct_within_granted_scope
path_set:
  - create_account
  - freeze_account
  - adjust_storage_quota
reentry_right: external_permission_required_after_term_expiry
future_endpoint: permission_expires_at_six_months
reality_anchor: 当前无需再次申请即可直接创建/冻结账号和调整额度
```

判定：**x candidate PASS**。未来有明确回收期限不抹掉当前真实 x；`term/revocability/return_obligation` 与 current control 必须分账。

### IR-B｜未来路径收窄层

```yaml
actor: 迁移项目执行体系
object: 生产服务最终运行位置
object_layer: 服务迁移的未来可选路径与终点层
current_window: 迁移开始 -> 旧服务逐批关闭 -> 延期窗口逐批取消 -> 最终切换日
changed_variable: real_option_set_contraction
relation_source: migration_program
relation_shape: multiple-current-options_to_single_future_endpoint
decision_right: shared_program_governance
path_set:
  - remain_temporarily_on_old_cluster
  - migrate_by_batch
  - use_remaining_delay_window
reentry_right: progressively_lost_after_each_shutdown
future_endpoint: all_production_services_on_new_cluster
reality_anchor: 每关闭一批旧服务且取消一批延期窗口，真实可选路径减少；最终全部汇入新集群
```

判定：**xz candidate PASS**。

同一句可以分层出现 `x + xz`，但理由完全不同：x 看当前处分边界；xz 看未来终点如何持续压缩真实路径空间。

## 4｜Positive decision gates

### x candidate gate

```text
X1 object / object_layer 明确；
X2 current_window 明确；
X3 actor 对 tested object 存在当前现实 use/call/allocate/dispose/veto/exclude 之一；
X4 至少一条 actor-specific control path 当前可直接调用；
X5 reality_anchor 能证明“主体拨动 → 同层对象状态改变”；
X6 term / revocability / return obligation 只描述边界，不得自动否掉当前 X1-X5。
```

### xz candidate gate

```text
XZ1 object_layer 明确为未来路径/可选空间/终点收束层；
XZ2 current_window 覆盖至少两个可比较阶段，而非一次结果；
XZ3 future_endpoint 在当前结构中已取得现实约束地位；
XZ4 path_set 可枚举，且真实 option set 随阶段收窄；
XZ5 至少出现“关闭路径 / 失去窗口 / 不同路线汇入同一终点”之一的现实证据；
XZ6 removal future-endpoint constraint 后，原持续收窄轨迹应明显减弱或消失；
XZ7 单纯 deadline、归还义务、未来失权、一次不可逆决定、危险感均不足。
```

## 5｜nearest neighbors

### x vs xz

```text
x：现在我能对什么对象进行现实调用/处分？
xz：未来终点是否正在持续减少我/系统还能走的真实路径？
```

最小差异：`六个月后自动回收管理员权限` 可以与“当前六个月内 x PASS”同时成立，但如果这只是一个到期节点，没有路径逐步关闭/汇流，则该事实本身 **xz FAIL**。

### x vs nx

```text
x：当前直接调用路径在 actor 边界内。
nx：关键接口仍在外部，主体需沿外部 route 推进。
```

最小差异字段：`reentry_right`。当前可直接调用但期满后需重新申请，不意味着当前窗口已经是 nx。

### xz vs nz

```text
xz：对象特异回返/可选空间持续减少并向终点汇流。
nz：保存、恢复或重建现实回返空间。
```

“以后可以回来”只触发 reentry 字段抽取；若没有真实、对象特异、可执行的回返路径，不能直接判 nz。反之，当前没有回返权也不自动推出 xz，仍需持续收窄结构。

## 6｜false-positive guards

1. **期限诱导**：有到期日 ≠ xz；到期前当前直接处分仍可是 x。
2. **归还词诱导**：“借来的以后要还” ≠ xz；先判 current governance / disposition，再看未来 path-set。
3. **回归词诱导**：“迟早回家” ≠ xz；口头预期不是现实路径汇流。
4. **不可逆诱导**：一次不可逆选择 ≠ xz；必须有持续收窄或汇流。
5. **危险/悲剧诱导**：危险、死亡、失败、悲惨程度均不得倒推 xz。
6. **当前失权诱导**：未来会失去 x ≠ 当前 x 已消失。
7. **对端缺席护栏**：当前 x FAIL 不推出 xz；xz FAIL 也不推出 x。
8. **单路径起点护栏**：一开始就只有一条路，不能把“没有替代路径”伪装成“路径持续收窄”。

## 7｜removal / reverse / same-layer / current-window

### Removal

- x：拿掉 actor 当前 direct control path。若同层对象仍完全一样受 actor 现实拨动，原 x 证据不足；若主体立即无法创建/冻结/调配，则 x 有 reality gap。
- xz：拿掉 future endpoint 对当前结构的约束。若选项仍按同样序列持续关闭并汇流，需寻找第三因素；若收窄停止，则 endpoint constraint 有归因价值。

### Reverse

- 保留“六个月后归还”但让 actor 在当前六个月内从未能直接调用资源：x 应 FAIL/UNKNOWN，而不是被“借用”字眼骗过。
- 保留“最终都会去新集群”口号，但允许旧集群无限续期、任意新开替代集群、延期窗口不减少：xz 应 FAIL/UNKNOWN。

### Same-layer

“管理员权限当前处分层”与“服务器迁移未来路径层”必须拆成两个 IR；禁止用未来迁移终点倒灌当前权限，也禁止用当前权限范围证明未来命运收束。

### Current-window

- 当前 x 只判当前现实有效窗口；未来自动撤权属于 scope transition，不回写成“现在无权”。
- xz 必须在同一收束过程内比较多个阶段；历史上曾无路可走、现在路径已重新打开，不得永久贴 xz。

## 8｜adversarial tests

### T1｜关键词诱导
输入：“这把钥匙是借我的，下个月一定要还，但这个月我可以随时开门、锁门和授权同事进入。”
结论：**x PASS；xz 不因‘一定要还’成立。**

### T2｜题材/职业/情绪诱导
输入：“死刑律师悲观地说客户命运已注定，但案件仍有三个真实上诉层级、减刑申请和重新审理路径。”
结论：**xz FAIL/UNKNOWN**；职业、悲观、‘命运已注定’均不能覆盖 real path_set。

### T3｜对象层错位
输入：“船长当前能处分本船燃料，但航线因海峡逐段封锁最终只能进入唯一港口。”
结论：燃料处分层查 **x**；航线未来选项层查 **xz**；不得一锅判。

### T4｜时间窗错位
输入：“去年他的访问权被逐步收窄直至清零；今年重新获得完整管理员权限。”
结论：当前窗口 **x 可 PASS**；不能把去年收窄永久贴到今年 xz。

### T5｜同关系词异对象层
输入A：“权限最终归还总部。”
输入B：“所有撤离路线最终汇入同一出口。”
A：若只有期限性 return obligation，主要是 x-scope/term；不自动 xz。
B：若路径逐步关闭且真实汇流，可查 xz。
结论：同样“最终归”，对象层不同。

### T6｜对端不存在不等于本端成立
输入：“账号被冻结，用户现在既不能控制它，也没有证据表明未来路径正在收窄或汇向某终点。”
结论：**x FAIL；xz 也 FAIL/UNKNOWN**。

### T7｜未来回返伪 xz
输入：“她辞职后合同允许一年内无条件复职，但是否回来完全由她自己决定，期间还有多个职业选择。”
结论：`reentry_right=strong`，但 **xz FAIL**；未来回返权不是路径收窄。

### T8｜一次不可逆伪 xz
输入：“他一次性销毁了旧手机，之后不能恢复数据。”
结论：仅凭一次不可逆结果 **xz FAIL/UNKNOWN**；没有持续路径收窄过程。

### T9｜期限性当前 x 压力测试
输入：“研究员拿到三个月独立设备控制权，资助方三个月后自动收回；期间资助方不能逐次否决设备调用。”
结论：当前窗口 **x PASS**；`revocable/term-limited ≠ current no-x`。

### T10｜口头终点伪 xz
输入：“经理反复说‘年底一定上市’，但团队可以无限延期、改项目、取消上市或换市场，且这些选项都现实有效。”
结论：**xz FAIL**；future_endpoint 只是宣言，不是 reality anchor。

## 11｜下一轮最高翻译风险

优先 `xz vs nz` 的 **reentry_right polarity**：

```text
“有回去的可能”
到底是：
- 真实对象特异回返空间被保存/恢复（nz candidate），
- 只是口头愿望/法律可能性/单方记忆（nz false positive），
- 还是未来路径实际上仍在持续关闭（xz candidate）。
```

下一轮应重点校准：`reentry_right` 的存在、可执行性、双方性/对象特异性，以及它与 `real_option_set` 的动态变化不得互相替代。
