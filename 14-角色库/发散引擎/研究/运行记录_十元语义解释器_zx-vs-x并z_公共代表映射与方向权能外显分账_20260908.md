# 十元语义解释器｜zx vs x并z：公共代表映射与方向权能外显分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元候选判定 → Z 发散器”。current canonical 永远高于本研究；不得覆盖 L1/L2 canonical，不得修改十元信息卡、准度卡、正式关系卡或行为 evidence 正本。

## 1｜目标混淆对与翻译债务

目标：`zx vs x并z`。

高风险语言包括：“公开发声”“代表我们”“官方账号”“站到台前”“对外宣布”“让所有人都看到”“成为门面”“把自己的主张推向公众”。这些句子都带 external visibility，但 current canonical 所测变量不同：

- `x并z`：内部对象/关系/能力通过稳定公共壳，被第三方识别、调用、归因、代表、进入或保护；
- `zx`：主体自身方向与权能公开进入现实，并实际改变他者、环境、秩序或竞争方向的反应与效力。

已有研究分别锁过“x并z 不是唯一裁定中心”“zx 不是流程拓扑”。本轮新增的翻译缺口是：解释器遇到“公开代表/对外发声”时，常把“被谁代表”与“谁的方向因此获得现实推进力”混成同一 actor/object。

本轮新增候选规则：

`REPRESENTATION-MAPPING-vs-DIRECTIONAL-EXTERNALIZATION-v0.1`

核心硬约束：

```text
REPRESENTATION_BEARER_AUDIT_REQUIRED
PUBLICITY_EFFECT_AUDIT_REQUIRED

represented_object != power_bearer
stable_public_mapping != directional_power_expansion
external_visibility != zx
external_visibility != x并z
```

## 2｜自然语言 → Semantic IR 结构还原规则

固定先抽 IR，再判十元：

1. `actor`：先判断谁维护公共壳、谁施加方向权能。若同一句里不是同一主体，必须 SPLIT_IR。
2. `object`：区分“被外部识别/归因/调用的内部对象”与“主体正在推进并压入现实的方向/权能”。
3. `object_layer`：
   - x并z 优先测试 public representation / addressability / attribution / interface layer；
   - zx 优先测试 directional power / competing direction / decision-scope effect layer。
4. `current_window`：必须给出公开动作前后。历史知名、曾经是门面、曾经扩权都不能自动续贴当前。
5. `changed_variable`：
   - x并z：`public_mapping_stability` / `third_party_addressability` / `public_attribution_route`；
   - zx：`directional_power_distribution` / `actor_direction_binding_force` / `decision_scope_expansion`。
6. `relation_source`：x并z 追“公共壳与内部对象的映射从哪里成立”；zx 追“现实压力/扩权由谁施加”。
7. `relation_shape`：
   - x并z：`third_party -> stable_public_shell -> represented_internal_object`；
   - zx：`actor_direction -> public_reality -> competitors_or_environment_react`。
8. `decision_right`：x并z 可以是 `interface_only_nonfinal`、`spokesperson_without_policy_discretion` 或 null；zx 若涉及方向权必须看到 actor 在 tested layer 的现实影响范围增加，不能把“有麦克风”改写成“有方向权”。
9. `path_set`：
   - x并z：公共识别、归因、调用、进入等 route；
   - zx：actor 方向、竞争方向、被迫调整的现实接口或权能位置。
10. `reentry_right`：仅在文本确有资格恢复/竞争方向回返时填写；公共账号反复登录不是 reentry_right。
11. `future_endpoint`：公开壳通常可 null；zx 只有文本明确方向终局才填，不因“公开宣言”脑补胜利。
12. `reality_anchor`：x并z 要证明第三方确实依赖该壳识别/调用/归因；zx 要证明公开进入现实后，至少一个他者、竞争方向或制度安排发生可归因的现实反应。

### 新 IR 约束 A｜REPRESENTATION_BEARER_AUDIT

```text
问：第三方通过这个公开壳，究竟在识别谁/什么？

若公开账号、发言人、官网、制服、品牌等只是把
“组织/作品/服务/职位”稳定映射给外部世界，
→ x并z evidence。

不能因为 spokesperson 是一个人，就自动把被代表对象改写成 spokesperson 自身方向。
```

### 新 IR 约束 B｜PUBLICITY_EFFECT_AUDIT

```text
问：公开动作之后，现实里到底变了什么？

若只改变 third-party mapping：
“大家知道从哪里找到我们 / 这是谁的官方口径 / 这个作品归谁”
→ x并z 上升，zx 不自动变化。

若 actor 的自身方向因此获得新增现实效力，并迫使竞争方向、他者或秩序调整：
→ zx candidate 上升。

若只是曝光度、热搜、被看见、情绪震动：
→ 两端都不得仅凭 publicity 成立。
```

## 3｜标准输入与完整 IR

输入：

> “公益组织长期使用一个认证官网和统一官方账号。账号发布的内容由秘书处按既定稿件发送，发言人林澈没有权修改组织政策；外部媒体、捐赠者和合作机构都通过这个账号确认组织身份、查询项目入口和引用正式声明。后来在组织内部原本并存的‘只做线下救助’与‘建立线上援助平台’两条路线发生冲突。林澈取得平台项目的独立预算和上线决定权后，公开宣布平台将在三十天内上线，并立即签约支付接口、招募技术团队；原本反对平台的部门因此失去冻结项目的同等权力，只能重新调整资源配合上线。”

必须拆两个 IR。

### IR-A｜公共代表映射层：x并z candidate

```yaml
actor: 公益组织秘书处与官方账号维护方
object: 公益组织的公共身份、正式声明与项目入口
object_layer: public_representation_and_addressability_layer
current_window: 认证官网/官方账号持续运行 -> 外部第三方反复识别/引用/进入
changed_variable: public_mapping_stability
relation_source: institutional_public_shell
relation_shape: third_party_to_stable_public_shell_to_organization
 decision_right: spokesperson_without_policy_discretion
path_set:
  - media_identifies_official_account
  - donors_verify_organization_identity
  - partners_quote_formal_statement
  - public_enters_project_information_route
reentry_right: null
future_endpoint: null
reality_anchor: 外部第三方稳定依赖认证官网和官方账号识别组织、引用声明并进入项目入口；林澈本人无政策改写权
```

判定：`x并z candidate PASS`。

这里“公开发声”是稳定公共壳功能，发言人本人没有因此取得 tested policy layer 的方向权。

### IR-B｜方向权能外显层：zx candidate

```yaml
actor: 林澈
object: 线上援助平台方向的现实上线资格与资源推进权
object_layer: 线下-only 与线上平台两条竞争方向的现实效力层
current_window: 两路线并存 -> 林澈取得预算/上线权 -> 公开锁定平台上线 -> 签约与招募 -> 反对部门失去同等冻结权并调整资源
changed_variable: directional_power_distribution
relation_source: actor_asserted_direction_with_new_operational_authority
relation_shape: coequal_competing_directions_to_actor_direction_with_binding_reality_effect
 decision_right: actor_final_on_platform_launch_within_project_scope
path_set:
  - actor_direction: online_aid_platform
  - competing_direction: offline_only
  - payment_interface_contract
  - technical_team_recruitment
  - opposing_department_loses_equal_freeze_power
reentry_right: competing_direction_requires_new_authority_to_block_project
future_endpoint: platform_launch_if_current_commitments_hold
reality_anchor: 公开宣布不是唯一证据；真正锚点是预算、签约、招募和冻结权变化共同使竞争方向失去同等现实效力
```

判定：`zx candidate PASS`。

这里公开动作只是权能进入现实的一个可观察节点；若没有后续资源承诺、决定范围变化与竞争方向反应，不能仅凭宣言锁 zx。

## 4｜Positive decision gates

### x并z candidate gate

```text
XZB1 object_layer 明确是公共识别/归因/调用/代表/进入/保护接口；
XZB2 存在至少一个无需私人关系即可成立的第三方 caller；
XZB3 存在 stable public shell，并能跨场景重复映射到内部对象；
XZB4 relation_shape 是 caller -> shell -> represented object；
XZB5 represented object 明确，不得把“发言人”默认等同于“发言人自身方向”；
XZB6 decision_right 可非最终、纯接口或无政策裁量；
XZB7 reality_anchor 证明第三方实际依赖该壳完成识别/归因/调用；
XZB8 removal 公共壳后，第三方 mapping 出现可命名断裂，即使内部方向权完全不变。
```

### zx candidate gate

```text
ZX1 object_layer 明确是自身方向、决定范围或竞争方向现实效力；
ZX2 actor 自身方向/权能已公开或现实进入外部/共同现实，而非只内部想法；
ZX3 changed_variable 指向 directional power / decision scope，而不是 publicity/brand mapping；
ZX4 至少一个竞争方向、他者、环境或秩序因 actor 的施力发生可辨认反应；
ZX5 actor 的 tested decision scope 或方向 binding force 现实增加；
ZX6 若有“公开宣布”，必须存在独立于宣言的 reality anchor，如资源调度、资格变化、合同、执行接口、他者被迫改线；
ZX7 竞争方向自然消失、媒体自发关注、单纯走红不能归因给 actor zx；
ZX8 removal actor 的新增施力/扩权后，竞争方向或秩序反应应出现可命名恢复，即使公共壳仍稳定存在。
```

## 5｜nearest-neighbor 最小差异

### zx vs x并z

```text
x并z：世界通过什么稳定公共壳识别/调用“这个内部对象”？
zx：谁的自身方向因现实施力获得更强效力，并迫使别的方向/秩序重新反应？
```

最小 IR 差异：

```text
public_mapping_stability
vs
directional_power_distribution
```

### x并z vs z

一个账号可以是唯一官方接口，但没有任何最终裁定权；稳定公共映射不等于单一最高裁定中心。

### zx vs x

已有预算、账号、设备处分权可形成 x；只有这些资源被主体用于把自身方向压入现实、扩大方向效力并改变竞争反应，才进一步查 zx。

### zx vs xn

“搭建发布流程、排班、审核节点”是运行结构；“使自己的路线取得新增现实优先并压退竞争路线”才是方向权能推进。

## 6｜False-positive guards

1. “官方发言人”职业/身份 ≠ zx。
2. “公开宣布” ≠ zx；若无人被迫调整、决定范围未变，只是表达。
3. “公开账号” ≠ x并z；若无人能稳定通过它识别/调用/归因内部对象，只是展示页。
4. 高曝光、热搜、粉丝增长 ≠ x并z；知名度不是稳定公共壳本身。
5. 被媒体称为“代表人物” ≠ x并z；必须有现实稳定映射或归因功能。
6. 发言人代组织朗读既定文本 ≠ 发言人 zx。
7. 主体强推方向但通过一次私下会议完成，也可 zx；缺公共壳不否定 zx。
8. 稳定官网多年存在但内部政策权完全分散，x并z 可强，zx 可弱/无。
9. 竞争方向因市场自然失败，不因 actor 公开发声而失败，不能倒推 zx。
10. x并z FAIL 不推出 zx；zx FAIL 不推出 x并z。

## 7｜Adversarial tests

### A1｜关键词诱导

输入：“她是我们唯一官方发言人，所有采访都由她出面，但她只能照董事会批准的稿子念，不能改政策。”

预期：组织公共代表层可 `x并z candidate`；发言人 tested actor 的 `zx FAIL/弱`。关键词“唯一/官方/发言”不得直接产 zx。

### A2｜题材/职业/情绪诱导

输入：“叛军领袖在万人面前愤怒演说，极具煽动力；演说结束后部队路线、资源、权限和对手行为均未改变，且没有稳定对外接口。”

预期：不得因领袖、万人、愤怒、煽动倒推 zx/x并z；两端 `FAIL/UNKNOWN`。

### A3｜对象层错位

输入：“大学官网稳定代表学校发布招生信息；教授另在院务会上取得实验方向独立预算并压掉旧方案。”

预期：官网/学校公共映射层查 x并z；教授/实验方向权层查 zx；不得互补标签。

### A4｜时间窗错位

输入：“去年她拥有认证官方账号且能单方决定产品方向；今年账号仍由她维护，但产品方向已改为委员会共同决定。”

预期：当前 x并z 可保持；去年 zx 不得续贴今年。

### A5｜同关系词异对象层

输入：“对外代表”在第一句指官方账号代表组织身份，在第二句指某派领袖把本派方案公开推成唯一现实路线。

预期：前者优先 x并z；后者需经过 zx gate。相同“代表”词不能共享十元。

### A6｜对端不存在不等于本端成立

输入：“组织没有官网、没有稳定账号，也没人拥有推动任何方向的新增权力。”

预期：x并z FAIL 不推出 zx；zx FAIL 也不推出 x并z；两端均 FAIL/UNKNOWN。

### A7｜稳定壳强、zx弱

输入：“医院官方公众号十年稳定发布挂号、地图和公告，运营员只能按审核稿发布，不能改变诊疗方向。”

预期：x并z PASS；运营员 zx FAIL。

### A8｜zx强、无稳定公共壳

输入：“合伙人会议中，林澈获得新增预算否决权，立即停止竞争项目资金并把资源转向自己的平台；全过程没有公开账号或媒体动作。”

预期：zx PASS candidate；不能因为不公开传播就判 zx FAIL；x并z 无对应公共壳证据。

### A9｜曝光伪 x并z

输入：“短片一夜爆红，数百万人看到作者名字，但名字没有稳定认证、官网、归因规则或可重复调用接口，多个同名账号互相冲突。”

预期：高曝光不足以锁稳定 x并z；需更多 mapping 证据。

### A10｜宣言伪 zx

输入：“经理公开宣布‘以后全部做A’，但预算、审批、上线权都在董事会，竞争项目B照常推进。”

预期：zx FAIL/弱；公开性不替代现实 binding force。

### A11｜同一主体双层并存

输入：“创始人账号是品牌稳定官方入口；同一天他新增终审权并取消B产品上线资格。”

预期：必须 SPLIT_IR。账号公共映射层 x并z；竞争方向权层 zx。不得一个 IR 双贴。

### A12｜状态迁移测试

输入：“个人博客最初只是表达观点；后来被组织认证为官方公告入口；再后来博主取得预算与项目终审权，并用这些权力让自己的路线取代原并行路线。”

预期：
- 第一阶段：表达本身不锁 x并z/zx；
- 第二阶段：stable public mapping 出现，x并z ↑；
- 第三阶段：directional binding force 与竞争方向变化出现，zx ↑；
- 两种上升时间点必须分开。

## 8｜Removal / reverse / same-layer / current-window

### 8.1 x并z removal

保留林澈平台预算、上线权、合同与招募，只撤掉认证官网/官方账号，让外部无法稳定识别组织正式入口。

预期：`x并z ↓`；`zx` 可保持。

### 8.2 zx removal

保留认证官网/官方账号与所有稳定第三方 mapping，但撤掉林澈新增预算/上线权，恢复反对部门同等冻结权。

预期：`zx ↓`；`x并z` 可保持。

### 8.3 reverse

- 保留“公开宣布”字样，但让竞争方向与决定范围完全不变 → zx 必须掉。
- 保留“官方账号”字样，但第三方无法稳定识别对象、账号频繁冲突且无人依赖 → x并z 必须重新审计/下降。

### 8.4 same-layer

同一个组织可以同时存在强 x并z 与强 zx，但必须是两个 object_layer：

```text
public representation layer
!=
directional power layer
```

若不能明确被代表对象与方向权对象，返回 `NEEDS_MORE_STRUCTURE`，不得双贴。

### 8.5 current-window

历史上曾是公共门面，不代表当前仍有稳定 mapping；历史上曾强推方向，也不代表当前仍有扩权。两个状态独立按 current_window 更新。

## 9｜状态迁移规则

### PUBLIC-MAPPING STATE

```text
private/ambiguous expression
→ certified stable public shell
→ repeatedly relied on by third parties
= x并z ↑
```

### DIRECTIONAL-POWER STATE

```text
expression/opinion only
→ actor gains executable decision scope
→ actor uses scope in reality
→ competitors/environment lose equal effect or must react
= zx ↑
```

核心不变量：

```text
x并z ↑ 不自动推出 zx ↑
zx ↑ 不自动推出 x并z ↑
public visibility is only an observation channel, not a symbol label
```

## 10｜本轮成功门

本轮不是重复已有机制，新增至少以下解释器资产：

1. `REPRESENTATION_BEARER_AUDIT_REQUIRED`：区分公共壳代表的内部对象与发言/维护者本人；
2. `PUBLICITY_EFFECT_AUDIT_REQUIRED`：要求把“被看见”后的实际 changed_variable 分型；
3. 新 IR 约束：`represented_object != power_bearer`；
4. 新最小差异：`public_mapping_stability vs directional_power_distribution`；
5. 新 adversarial negative：“发言人照稿念”“爆红但无稳定映射”“公开宣言但竞争方向不变”；
6. 新状态迁移：公共映射建立与方向权能扩大允许在不同时间独立上升。

结论：`PASS`。允许提交 research-only 运行记录；不得反写 current canonical。

## 11｜下一轮风险

本轮占用 `zx / x并z`，下一轮不得继续选择二者。

当前高风险候选：`n vs x`。

需要进一步拆：

```text
“对象进入我这里并持续由我承担”
vs
“对象进入我的当前掌握/调用/处分边界”
```

危险语言是“我养着它 / 我保管它 / 它归我管 / 放在我这里”。下一轮应重点审计 `load_bearer`、`disposition_right` 与 `object_presence`，避免“持续承载”被翻成“拥有处分权”。
