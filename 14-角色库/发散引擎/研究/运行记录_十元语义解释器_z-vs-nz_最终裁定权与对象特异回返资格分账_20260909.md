# 十元语义解释器｜z vs nz｜最终裁定权与对象特异回返资格分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元判定 → Z 发散器”。current canonical 永远高于本研究；本文件不得覆盖 canonical。

## 0｜本轮翻译债务

高风险句型：

```text
最终还是他决定我能不能回来。
只要主任点头，我就能回原组。
我有回去的资格，但争议由委员会最后裁定。
```

这些句子容易把两个不同主体位置压进同一个“能不能回来”：

```text
z：谁/什么对当前同层争议拥有 binding final validity？
nz：原对象特异关系是否保存、恢复或重建可信回返位置？
```

已有 nz 研究已经区分 standing return 与 per-instance discretionary return。本轮新增的是 **权利/关系归属与裁定者归属的解耦约束**，以及 **裁定者替换不应自动改写回返关系**。

新增候选规则：

```text
ADJUDICATOR-HOLDER-vs-RETURN-CLAIM-HOLDER-v0.1
DECISION-RIGHT-SUBJECT_AUDIT_REQUIRED
REENTRY-RIGHT-SUBJECT_AUDIT_REQUIRED
ADJUDICATOR-REPLACEMENT-INVARIANCE_AUDIT_REQUIRED
RESIDUAL-DISCRETION_AUDIT_REQUIRED
```

核心不变量：

```text
gatekeeper can finally decide != claimant has nz
claimant has standing return path != clerk/committee is z
change adjudicator holder != automatically change nz relation
remove return entitlement != automatically remove z adjudication power
```

## 1｜自然语言 → IR 结构还原规则

遇到“谁决定能不能回来 / 批不批准回去 / 最终能否恢复原位”时，不得先写 `reentry_right: yes` 或直接贴 z/nz。按固定字段依次还原：

1. `actor`：当前测试的是裁定者、返回者，还是原关系本身。
2. `object`：z 测“哪一个判断获得最终效力”；nz 测“哪一段原对象特异关系/位置可否回返”。
3. `object_layer`：`same_layer_reentry_adjudication` 与 `object_specific_relation_reentry_layer` 必须分开。
4. `current_window`：先前关系 -> 真实退出/分离 -> 当前回返请求 -> 是否存在争议 -> 谁让结论 binding -> 是否实际恢复原关系。
5. `changed_variable`：z=`binding_reentry_adjudication_location`；nz=`object_specific_reentry_recoverability`。
6. `relation_source`：z 写 final authority 来源；nz 写原关系、standing rule、双方承诺或修复接口来源。
7. `relation_shape`：z=`competing_reentry_judgments -> single_binding_adjudication_center`；nz=`prior_specific_relation -> real_exit -> preserved/rebuilt_return_path -> same_relation`。
8. `decision_right`：必须写清“谁能 bind 哪一个问题”。只有核验客观条件、无剩余裁量时，不得把核验员写成 z。
9. `path_set`：z 放候选判断/争议 -> 最终采用；nz 放真实退出后返回同一关系的接口。禁止混装。
10. `reentry_right`：必须写清权利/路径属于谁或哪段关系，不能把 gatekeeper 的批准权填进 claimant 的 reentry_right。
11. `future_endpoint`：z 写裁定在何条件下保持 binding；nz 写回返窗口、修复终点或失效条件。
12. `reality_anchor`：z 要指出谁能现实终结同层争议；nz 要指出真实离开后仍可回到同一对象特异关系，而不是进入同类新位置。

若只能抽出：

```yaml
changed_variable: can_return
```

则判 `NEEDS_MORE_STRUCTURE`。

### 新增字段纪律：主体归属不得互借

```text
decision_right.subject = final adjudicator / binding standard holder
reentry_right.subject = former participant / object-specific relation
```

若二者被自然语言省略，允许 `unknown`，不得默认同一主体。

### 新增不变性检查：ADJUDICATOR-REPLACEMENT

保持原关系、退出事实、standing return 条件完全不变，只把“甲主任核验/裁定”换成“乙委员会核验/裁定”：

```text
若 nz 判断随裁定者姓名一起变化
→ IR 污染，FAIL
```

相反，若撤销 standing return / 修复接口，但保留委员会对新申请的最终决定权：

```text
z 可保持
nz 应下降或转 UNKNOWN/FAIL
```

## 2｜标准输入与完整 IR

输入：

> 研究员陈岚曾是“北辰课题组”的正式成员，三个月前主动退出。章程仍规定原成员退出180天内可申请恢复原课题组原席位；身份、期限与原席位连续性满足时，秘书无权自由拒绝。但若“是否仍属于原席位连续性”发生争议，学术委员会拥有最终解释和裁定权，其他部门不能覆盖。陈岚第90天申请恢复，秘书确认身份和期限，但财务与项目办对席位连续性意见相反；委员会最终裁定“连续性成立”，陈岚随后恢复原课题组原席位。

必须 `SPLIT_IR`。

### 2.1 z IR

```yaml
actor: 学术委员会
object: 陈岚是否满足“原席位连续性”这一争议条件的最终有效判断
object_layer: same_layer_reentry_adjudication

changed_variable: binding_reentry_adjudication_location
relation_source: charter_granted_final_interpretation_authority
relation_shape: competing_same_layer_reentry_judgments_to_single_binding_center
decision_right: committee_has_final_bind_and_override_right_on_contested_continuity_question
path_set:
  - finance_judgment_not_continuous
  - project_office_judgment_continuous
  - committee_final_judgment_continuous
reentry_right: null
future_endpoint: continuity_judgment_remains_binding_unless_same_or_higher_authority_reopens
reality_anchor: 财务与项目办冲突后，委员会结论使争议结束，其他部门不能以自己的判断覆盖
```

判定：`z PASS`。

### 2.2 nz IR

```yaml
actor: 陈岚与北辰课题组之间的原成员关系
object: 陈岚退出后180天内恢复原课题组原席位的对象特异回返位置
object_layer: object_specific_relation_reentry_layer
current_window: 原成员在组 -> 主动退出 -> 90天分离 -> standing return window仍有效 -> 条件核验/争议裁定 -> 恢复原席位
changed_variable: object_specific_reentry_recoverability
relation_source: standing_charter_return_rule_plus_prior_specific_membership
relation_shape: prior_specific_membership_to_real_exit_to_preserved_return_claim_to_same_membership_position
decision_right: claimant_has_no_final_adjudication_right_on_dispute; objective_conditions_plus_binding_interpretation_govern_execution

  - prior_membership_in_beichen_group
  - voluntary_exit
  - return_window_180_days

  - contested_continuity_resolution

reentry_right: chenlan_holds_standing_object_specific_return_claim_within_180_days_subject_to_defined_conditions
future_endpoint: standing_return_window_expires_after_180_days_if_not_exercised
reality_anchor: 陈岚真实退出90天后并非重新竞聘新岗位，而是依据原成员规则恢复同一课题组原席位；秘书不能自由把合格申请当新申请拒绝
```

判定：`nz PASS`。

> 两端同时成立不表示 z 生 nz 或任何正式关系机制成立；这里只做 Semantic IR 分账。

## 3｜Positive decision gate

### z candidate-positive

```text
Z-G1 当前存在同层竞争判断/解释/批准结论；
Z-G2 tested actor/standard 明确；
Z-G3 对争议问题具有真实 final bind / override / veto / interpretation right；
Z-G4 其结论现实终止或支配同层争议；
Z-G5 replacement/remove 测试能定位 final validity holder；
Z-G6 仅执行客观核验、没有 residual discretion/binding interpretation 的办事员不得自动 z。
```

### nz candidate-positive

```text
NZ-G1 存在对象特异的先前关系/位置；
NZ-G2 发生真实退出、分离或中断；
NZ-G3 当前回返目标是同一原关系或可识别修复位置；
NZ-G4 存在可信可执行的 standing return / repair / reconnection path；
NZ-G5 reentry_right 的主体是 former participant/relationship，不是 gatekeeper；
NZ-G6 更换裁定者而不改变原关系与回返规则时，nz 应保持；
NZ-G7 完全作为陌生新申请、每次由第三方自由裁量重新接纳时，stable nz 不足。
```

## 4｜Nearest-neighbor 最小差异

### 4.1 z vs nz｜同一句“最终决定能不能回来”

```text
委员会对“连续性是否成立”有最终 binding interpretation
→ z

陈岚作为原成员在180天内仍拥有返回同一原席位的可执行关系路径
→ nz
```

### 4.2 gatekeeper discretionary admission vs standing return

```text
原成员无任何保留资格；退出后和陌生人一样重新申请，主任可自由决定收不收
→ 主任在该申请层可查 z
→ nz FAIL/弱

原成员满足客观条件即可恢复，前台只能核验身份期限
→ nz PASS
→ 前台 z FAIL/不足
```

### 4.3 nz vs nx

```text
“我本来有原关系回返资格”
→ nz

“我没有回返资格，只能求人走第三方关系特批”
→ nx candidate
```

## 5｜False-positive guards

```text
“他决定我能不能回来” != nz
“我可以回来” != 某个审批者 z
有 gatekeeper != 有 standing return
有 standing return != 有单一最高裁定者
一次获批回归 != stable nz
有表单/核验员 != z
职位最高 != z，必须在当前争议层有 binding final validity
进入同名新岗位 != 回到同一对象特异关系
z FAIL != nz PASS
nz FAIL != z PASS
```

特别禁止：

```text
reentry_right: director_can_approve_return
```

这把裁定者权限错误塞进了返回者权利字段，应判 schema-role FAIL。

## 6｜Removal / reverse / same-layer / current-window

### removal A｜替换裁定者

把学术委员会改成仲裁委员会，原章程与180天回返规则不变：

```text
z holder 迁移/重审
nz 保持
```

### removal B｜撤销 standing return

改成退出即永久失去原席位，所有人只能作为新人重新申请；委员会仍拥有新申请最终裁定权：

```text
z 可保持
nz ↓
```

### reverse｜把自由裁量改为机械核验

原来主任可自由决定收不收；改成满足身份+期限即自动恢复，主任只核验：

```text
主任 z ↓
nz ↑ / 可保持
```

不得把“审批人还坐在那里”当作 z 不变。

### same-layer

```text
reentry_dispute_final_validity_layer
!=
object_specific_return_recoverability_layer
```

同一张“恢复申请表”可以同时触发两层，但不得共用一个 IR。

### current-window

去年180天回返条款有效、今年章程已删除：历史 nz 不继承到当前。

去年主任有 final interpretation right、今年改委员会：历史主任 z 不继承到当前。

## 7｜Adversarial tests

1. **关键词诱导**：“最后还是他决定我能不能回来。”没有原关系、退出事实、争议层和权限来源。→ `NEEDS_MORE_STRUCTURE`。
2. **题材/职业/情绪诱导**：冷酷校长说“想回来就求我”。若退出者与学校无 standing return，只能重新申请，不能因校园/怀旧判 nz；校长是否 z 另查实际 final right。
3. **对象层错位**：公司董事会最终决定股东资格争议，但员工回原项目席位按自动规则恢复。→ 股东层 z 与项目成员层 nz 分开。
4. **时间窗错位**：去年有90天回返权，今年条款删除。即使今年同一主任仍能审批新人，旧 nz 不继承。
5. **同关系词异对象层**：“恢复”一处指恢复原成员席位，一处指恢复系统账号。前者可查 nz；后者可能只是 x/xn，不得共用 reentry_right。
6. **对端不存在不等于本端成立**：无人有最终裁定权、原成员退出也永久失去资格。→ z/nz 都 FAIL/UNKNOWN。
7. **gatekeeper 伪 nz**：主任可自由决定是否重新录取任何离职者，无 standing relation。→ z 可查，nz FAIL。
8. **standing return 伪 z**：满足180天+身份条件系统自动恢复，客服无权拒绝。→ nz PASS，客服 z FAIL。
9. **裁定者替换污染测试**：只把甲委员会替换为乙委员会，原回返规则不变；若解释器把 nz 改判，FAIL。
10. **权利主体错位测试**：IR 写 `reentry_right: committee_can_approve`。→ schema-role FAIL，必须重抽。
11. **同事件双层成立**：原成员有 standing return，但“连续性”发生真实争议并由委员会最终裁定。→ `z + nz`，强制 SPLIT_IR。
12. **最小 mutation**：A=`无standing return + 主任自由裁量`；B=`standing return + 主任只客观核验`。预期 A: z candidate↑/nz↓；B: nz↑/主任z↓。mutation 后必须重新抽取全部 IR。
