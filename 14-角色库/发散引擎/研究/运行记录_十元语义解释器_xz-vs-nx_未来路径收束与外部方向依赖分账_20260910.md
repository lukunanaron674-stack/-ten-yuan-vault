# 十元语义解释器｜xz vs nx｜未来路径收束与外部方向依赖分账

## 0｜本轮目标与去重

上一轮解释器为 `x vs xn`，本轮避开 `x/xn`。写前检查发现 `z vs xz` 已有独立解释器分账；`xz vs nx` 仅在 current canonical 中有最近邻短句，尚未形成独立 Semantic IR 约束。

本轮不扩案例库，目标是解决自然语言中的高债务句：

```text
“我只能这么做。”
“只剩这一条路。”
“必须沿他们给的路走。”
“最后大家都会走到这里。”
```

这些句子可能描述两种完全不同的结构：

```text
xz：未来终点已取得结构地位，多个可能路径随过程推进而关闭/汇流，选择空间持续收窄。
nx：tested actor 不占最终方向、权限或解决通道，当前行动沿外部既有方向/关系/权限继续。
```

本轮新增约束：

```text
GLOBAL-FUTURE-PATH-SET-vs-ACTOR-ROUTE-SET_AUDIT_REQUIRED
CONVERGENCE-SOURCE-vs-DIRECTION-SOURCE_AUDIT_REQUIRED
ONLY-PATH-SEMANTIC-TYPE_AUDIT_REQUIRED
ACTOR-PERMITTED-SET-NOT-EQUAL-FUTURE-POSSIBILITY-SET
```

核心不变量：

```text
“全局/对象层未来还剩几条真实可能路径”
!=
“这个 actor 当前被允许/能够借用哪条外部通道”

future possibility shrinks
!=
actor follows an external direction

actor is permitted only one route
!=
the world/process itself has converged to one future endpoint
```

`path_set` 仍使用固定 Semantic IR 字段，不新增 schema 字段；但其成员语义必须由 `object_layer + current_window + relation_shape` 约束：

```text
xz.path_set：同一对象层、同一未来问题下的可能路径/退路/结局分支，以及它们如何随时间失效或汇流。
nx.path_set：tested actor 当前借用/服从/经过的外部方向、关系、权限或解决通道。
```

两类成员不得混装。若同一句同时出现未来路径收束与 actor 外部方向依赖，必须 `SPLIT_IR`。

## 1｜自然语言 → IR 结构还原规则

遇到“只能、必须、唯一道路、没得选、照这个方向走”时，不允许关键词直判。按以下顺序还原：

1. 先确定 `actor` 与 `object`：是在描述一个过程/关系/人物未来整体，还是描述某个 tested actor 的当前办事路径。
2. 确定 `object_layer`：未来可能性/可逆性层，还是 actor-specific 方向/权限依赖层。
3. 冻结 `current_window`：比较的是同一个时间窗口内的路径变化，禁止拿过去已经关闭的路替当前制造 xz，也禁止拿过去一次服从制造当前 nx。
4. 对 `path_set` 做语义类型审计：成员是“未来可能路径”还是“actor 借用的外部通道”。
5. 检查 `changed_variable`：若变化是未来分支减少、路径汇流、临界逼近，才继续查 xz；若变化是 actor 对外部方向/权限/通道的依赖，才继续查 nx。
6. 检查 `relation_source`：xz 的收束必须来自已经取得结构地位的未来终点、不可逆过程、现实事件链或持续关闭机制；nx 的方向/权限/解决通道必须来自 actor 之外的既有位置。
7. 检查 `decision_right`：xz 可为 null；nx 必须能说明 actor 为什么不占该层最终方向/权限。若该 actor 自己拥有直接决定权，则 nx 下降。
8. 最后用 `reality_anchor` 证明结构，而不是用“绝望、听话、危险、严格、强势”等语气词补字段。

若无法确定“唯一”究竟是未来可能性唯一，还是 actor 被许可路线唯一，则输出 `unknown/NEEDS_MORE_STRUCTURE`，不得强填。

## 2｜标准输入句

> 山谷科研站已收到预警：六小时后主泄洪道会开启，届时低洼站区必须清空。最初东、西、南三条撤离线都能在六小时内到达高地；随后东桥垮塌，西线又因连续落石预计无法在泄洪前通过，只剩南线仍能赶在六小时终点前完成撤离。司机林澈虽然知道南线现实可走，但他没有灾区道路调度权；南线检查站要求救援指挥部为外来车辆签发临时通行许可。指挥部不批准，他本人不能沿南线进入；获批后，他只能在该许可范围内继续。

该句必须拆为 `SPLIT_IR`。

## 3｜完整 IR-A：xz

```yaml
actor: 山谷科研站撤离事件链
object: 六小时泄洪终点前仍能完成撤离的未来路径集合
object_layer: future_possibility_convergence_and_reversibility_layer
current_window: t0=六小时前东/西/南均可完成撤离 -> t1=东桥垮塌后剩西/南 -> t2=西线无法在终点前通过后只剩南线 -> t3=六小时泄洪终点兑现
changed_variable: future_path_set_convergence_toward_preexisting_deadline_endpoint
relation_source: six_hour_flood_release_endpoint_plus_bridge_collapse_plus_time_window_failure_on_west_route
relation_shape: multiple_same-purpose_future_paths_progressively_close_or_fail_to_reach_the_same_preexisting_endpoint_window_until_paths_converge
 decision_right: null
path_set:
  - east_route: feasible_at_t0_then_closed_by_bridge_collapse
  - west_route: feasible_at_t0_then_fails_six_hour_endpoint_window
  - south_route: remains_feasible_before_endpoint
reentry_right: null
future_endpoint: six_hour_flood_release_requires_lowland_station_clearance
reality_anchor: 六小时泄洪终点在前，东桥垮塌后东线退出可行集合，西线又因无法在六小时内通过而退出；南线成为终点兑现前仅剩的真实撤离路径
```

注意：上例 YAML 中 `decision_right` 与其余固定字段同级；实现解析时必须按固定 schema 正规化，不得因展示空格推断新层级。

判定：`xz PASS candidate`。

为什么不是只凭“危险”：因为真正正证据是 **六小时终点先取得结构地位，并且 t0→t1→t2 的路径集合持续减少，使当前过程被未来终点收束**。

## 4｜完整 IR-B：nx

```yaml
actor: 林澈
object: 当前外来车辆经南线进入灾区并完成撤离运输的行动
object_layer: actor_specific_external_direction_and_permission_dependency_layer
current_window: 南线现实可通行 -> 林澈无道路调度权 -> 向救援指挥部申请 -> 获许可才可进入 -> 沿许可范围行动
changed_variable: actor_current_action_dependency_on_external_permission_route
relation_source: rescue_command_holds_existing_disaster_road_permission_and_direction_position
relation_shape: tested_actor_without_final_route_permission_position_to_external_authority_to_bounded_existing_route_for_current_action
 decision_right: actor_has_no_final_disaster_route_permission_right_and_cannot_override_command_denial
path_set:
  - request_temporary_access_from_rescue_command
  - receive_bounded_south_route_permission
  - continue_current_transport_within_external_permission
reentry_right: null
future_endpoint: current_transport_completes_or_permission_expires
reality_anchor: 南线在林澈未获许可时仍现实可走，但林澈本人不能直接调用该道路权限；指挥部拒绝即可阻断他的当前行动，获批后他只能沿既有许可范围推进
```

判定：`nx PASS candidate`。

关键反事实：如果道路完全不变，只把林澈改成拥有该道路直接调度权，他的 `nx` 会下降，但 `xz` 的六小时未来收束不应因此变化。

## 5｜positive decision gate

### xz positive gate

```text
A. 有可识别的 future_endpoint，且它在结果兑现前已经对当前过程取得结构地位；
B. current_window 内至少两个时间切片可比较；
C. path_set 属于同一对象层、同一未来问题的可能路径/退路/结局分支；
D. 至少一个原本真实可达的未来路径随过程失效，或多个分支持续汇向同一 endpoint；
E. 选择减少不是只因为某一个 actor 没权限，而是该对象层的未来可能性本身被收窄；
F. reality_anchor 能指出“哪个路径何时、为何退出未来可行集合”。
```

缺少 A 或 B，不应只凭“现在只剩一条路”高判纯 xz。

### nx positive gate

```text
A. tested actor 与 current action 明确；
B. 方向、权限或解决通道已由 actor 外部的位置/关系/秩序给出；
C. actor 在该层不占最终方向或对应权限；
D. actor 实际沿该外部路径推进，而不是仅仅知道它存在；
E. external route/authority 的拒绝、撤回或变更会改变 actor 当前行动路径；
F. reality_anchor 能证明“世界仍可能有路，但这个 actor 必须借/沿谁的路”。
```

仅仅“必须使用统一入口”仍不足：若 actor 具有直接 standing qualification，入口只是机械调用界面，需继续区分 x并z/xn 等，而不能自动判 nx。

## 6｜nearest-neighbor 最小差异

### 差异 1｜“只剩一条路”的原因

```text
东桥断、西线赶不上六小时终点，所有同层撤离者都只剩南线
→ future possibility set 3→2→1
→ xz ↑

三条路都能准时到达，但林澈的上级只授权他走南线
→ global future possibility set 仍为3
→ actor-specific external direction dependency ↑
→ nx 优先
```

最小差异字段：`object_layer + path_set + relation_source`。

### 差异 2｜改变 actor 权限，不改变未来世界

```text
给林澈直接道路调度权
→ nx ↓
→ 六小时泄洪、东桥垮塌、西线超窗均不变
→ xz 保持
```

最小差异字段：`decision_right`。

### 差异 3｜改变未来收束，不改变 actor 依赖

```text
修复东桥并解除西线超窗，使三条路线都可在六小时内撤离
→ xz ↓

但三条路仍都必须由救援指挥部许可，林澈仍无直接权限
→ nx 可保持
```

最小差异字段：`current_window + future_endpoint + path_set`。

### 与 z 的护栏

救援指挥部若拥有某项争议的最终 binding adjudication，可另查 z；但“林澈沿它给出的方向走”描述的是林澈的 nx 层。不能因为 external authority 很强，就把 authority 与 follower 塞进同一个 IR。

## 7｜false-positive guards

```text
“只能这么做” != xz
“只能这么做” != nx
“只剩一条路” != xz，除非能证明未来终点/路径收束
“上级只允许一条路” != 世界只剩一条未来可能性
“没有选择” != future possibility set 已收窄
“必须走流程/官网” != nx，若只是机械接口且 actor 已有直接资格
被动/听话/绝望/无助 != nx
危险/死亡/倒计时 != xz，若它没有收紧当前未来路径
nx FAIL != xz PASS
xz FAIL != nx PASS
actor permitted option count != object-layer future possibility count
```

新增 schema-role guard：

```text
若 xz.path_set 中成员写成“向老板申请、托关系、借权限”，说明 path_set 类型污染；
若 nx.path_set 中成员写成“未来结局A/B/C最终汇流到死亡”，说明 path_set 类型污染。
```

## 8｜adversarial tests

| # | 强制类型 | 输入 | 预期 |
|---|---|---|---|
| 1 | 关键词诱导 | “我已经没得选，只能走他们给的唯一道路。”没有说明终点、替代路径、权限来源。 | `xz/nx = UNKNOWN`，禁止按“只能/唯一”直判。 |
| 2 | 题材/职业/情绪诱导 | 绝望的逃犯哭着说“命运逼我服从警长”。无具体路径变化与 direction right。 | 不凭逃亡、绝望、服从气氛判 xz/nx。 |
| 3 | 对象层错位 | 城市三座桥只剩一座能在洪峰前通车；公司员工另因内部审批不能开车。 | 城市未来撤离层查 xz；员工审批依赖层另查 nx，强制双 IR。 |
| 4 | 时间窗错位 | 昨天东桥断、西桥封，今天已全部修复；今天员工仍需主管许可。 | 当前 xz 不继承昨天；当前 nx 可查。 |
| 5 | 同关系词异对象层 | “通道”一处指洪峰前现实撤离路线，一处指找副院长借审批权限。 | 前者进入 xz path_set 候选；后者进入 nx path_set 候选，不得共享成员。 |
| 6 | 对端不存在不等于本端成立 | 三条路线都开放且 actor 有直接合法调度权。 | xz FAIL/弱，nx FAIL；不能因一端不存在补另一端。 |
| 7 | actor-only restriction | 三条道路都能准时抵达；指挥部只批准林澈走南线。 | xz 不因 actor 被限路成立；nx candidate。 |
| 8 | future-only convergence | 东、西路线相继失效，只剩南线；林澈自己拥有全部道路调度权，无需任何他者许可。 | xz PASS candidate；nx FAIL/弱。 |
| 9 | 两端同时成立 | 路线 3→2→1，同时林澈对最后南线仍须向指挥部借用权限。 | `SPLIT_IR`，xz+n x 独立判定；不得合并 path_set。 |
| 10 | mechanical-interface trap | 法律直接赋予 actor 通行资格，只要求所有车辆扫码登记，扫码系统不能自由拒绝。 | 不因“必须过系统”自动判 nx；另查 xn/x并z。 |
| 11 | endpoint-without-convergence | 六小时后有会议截止，但三条等价方案始终都可完成，未收窄也未汇流。 | 单独 deadline 不足以判纯 xz。 |
| 12 | mutation | 把“道路现实失效”改成“道路都开放，只是上级禁止 actor 使用”；或反向改回。 | 必须重新抽取 `object_layer/current_window/relation_source/path_set/decision_right`；前者 nx↑/xz↓，后者 xz↑/nx未必成立。 |

注：第 9 条中的 `xz+n x` 文字只表达“两份独立 IR 同时成立”，实现时应解析为 `xz + nx`，不得生成新符号。

## 9｜removal / reverse / same-layer / current-window

### Removal A｜拿掉未来收束源

修复东桥、西线重新能在六小时内通过，三条未来路线恢复：

```text
xz ↓
nx 可保持（若林澈仍需指挥部许可）
```

### Removal B｜拿掉 external direction dependency

给林澈当前灾区道路直接调度资格：

```text
nx ↓
xz 保持（六小时 endpoint 与路线收束不变）
```

### Reverse

把：

```text
道路现实/时间上已经无法到达 endpoint
```

改成：

```text
道路仍完全可达，只是 external authority 不允许 tested actor 使用
```

必须重新抽 IR。此 mutation 改变的是 `relation_source + object_layer + decision_right`，不能机械把同一个“只能”句子继续判 xz。

### Same-layer

```text
future_possibility_convergence_and_reversibility_layer
!=
actor_specific_external_direction_and_permission_dependency_layer
```

只有在同一对象层、同一核心变量上才能比较“路径是不是减少”。“全局未来只剩1条”与“某 actor 被许可1条”不是同一个计数器。

### Current-window

```text
昨天路径 3→1，不等于今天仍是 xz；
昨天依赖某负责人，不等于今天仍是 nx。
```

每轮抽取必须冻结当前窗口。若道路已恢复或 actor 已取得直接权限，旧状态不得继承。

## 10｜状态迁移规则

### xz

```text
future endpoint 尚未形成结构压力
→ endpoint 获得结构地位
→ 多条未来路径开始关闭/汇流
→ 选择空间持续减少
→ 少数/唯一未来路径
→ endpoint 兑现
```

### nx

```text
actor 自持方向/权限
→ 当前事项出现 actor 外部方向或权限需求
→ actor 进入既有关系/权限/流程通道
→ external holder 可以 enable/block/change actor 当前行动
→ actor 高依赖外部方向继续
```

本轮新增状态不变量：

```text
xz ↑ != nx ↑
nx ↑ != xz ↑
GLOBAL_FUTURE_PATH_COUNT != ACTOR_PERMITTED_ROUTE_COUNT
```

## 11｜成功门检查

本轮存在真实新增，满足提交门：

```text
新增翻译规则：GLOBAL-FUTURE-PATH-SET-vs-ACTOR-ROUTE-SET
新增 IR 字段约束：path_set 语义类型必须由 object_layer/current_window/relation_shape 锁定
新增 nearest-neighbor：future possibility count vs actor permitted route count
新增 adversarial negative：actor-only restriction 不得伪装成 xz
新增 removal/mutation：改 actor 权限不应改变 xz；恢复未来路径不应自动改变 nx
新增状态不变量：GLOBAL_FUTURE_PATH_COUNT != ACTOR_PERMITTED_ROUTE_COUNT
```

因此：`PASS / submit`。

若 future canonical 改写 xz 或 nx，本研究自动降级，以 future current canonical 为准。
