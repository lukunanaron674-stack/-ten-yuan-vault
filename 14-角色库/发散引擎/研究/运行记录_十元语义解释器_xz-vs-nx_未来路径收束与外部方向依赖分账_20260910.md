# 十元语义解释器｜xz vs nx｜未来路径收束与外部方向依赖分账

## 0｜目标、去重与翻译债务

上一轮为 `x vs xn`，本轮避开 `x/xn`。写前检查确认 `z vs xz` 已有独立解释器分账；`xz vs nx` 只有 current canonical 最近邻短句，没有独立 Semantic IR 约束。

高债务句：

```text
“我只能这么做。”
“只剩这一条路。”
“必须沿他们给的路走。”
“最后大家都会走到这里。”
```

它们至少可能表示：

```text
xz：未来终点已取得结构地位，多个未来路径随过程关闭/汇流，选择空间持续收窄。
nx：tested actor 不占最终方向、权限或解决通道，当前行动沿外部既有方向/关系/权限继续。
```

本轮新增：

```text
GLOBAL-FUTURE-PATH-SET-vs-ACTOR-ROUTE-SET_AUDIT_REQUIRED
CONVERGENCE-SOURCE-vs-DIRECTION-SOURCE_AUDIT_REQUIRED
ONLY-PATH-SEMANTIC-TYPE_AUDIT_REQUIRED
ACTOR-PERMITTED-SET-NOT-EQUAL-FUTURE-POSSIBILITY-SET
```

核心不变量：

```text
全局/对象层未来还剩几条真实可能路径
!=
某个 actor 当前被允许或能够借用哪条外部通道

future possibility shrinks
!=
actor follows an external direction

actor is permitted only one route
!=
the world/process itself has converged toward one future endpoint
```

`path_set` 不新增 schema 字段，但成员语义必须由 `object_layer + current_window + relation_shape` 约束：

```text
xz.path_set = 同一对象层、同一未来问题下的可能路径/退路/结局分支，以及它们如何失效或汇流。
nx.path_set = tested actor 当前借用/服从/经过的外部方向、关系、权限或解决通道。
```

两类成员不得混装；同时出现时必须 `SPLIT_IR`。

## 1｜自然语言 → IR 结构还原规则

遇到“只能、必须、唯一道路、没得选、照这个方向走”时：

1. 先锁 `actor/object`：是在描述对象未来整体，还是某个 tested actor 的当前办事路径。
2. 锁 `object_layer`：未来可能性/可逆性层，还是 actor-specific 方向/权限依赖层。
3. 冻结 `current_window`：禁止拿过去关闭的路制造当前 xz，也禁止拿过去一次服从制造当前 nx。
4. 审 `path_set`：成员究竟是未来可能路径，还是 actor 借用的外部通道。
5. 审 `changed_variable`：未来分支减少/汇流/临界逼近才继续查 xz；actor 对外部方向/权限/通道依赖才继续查 nx。
6. 审 `relation_source`：xz 收束必须来自已取得结构地位的 future endpoint、不可逆过程或持续关闭机制；nx 路径必须来自 actor 外部既有位置。
7. 审 `decision_right`：xz 可为 null；nx 必须说明 actor 为何不占该层最终方向/权限。
8. 最后用 `reality_anchor` 证明，不得用“绝望、听话、危险、严格、强势”等语气词补字段。

若“唯一”究竟是未来可能性唯一还是 actor 被许可路线唯一仍不清楚，输出 `unknown/NEEDS_MORE_STRUCTURE`。

## 2｜标准输入句

> 山谷科研站收到预警：六小时后主泄洪道会开启，低洼站区必须清空。最初东、西、南三条撤离线都能在六小时内到达高地；随后东桥垮塌，西线又因连续落石预计无法在泄洪前通过，只剩南线仍能赶在终点前完成撤离。司机林澈知道南线现实可走，但没有灾区道路调度权；检查站要求救援指挥部为外来车辆签发临时通行许可。指挥部不批准，他本人不能沿南线进入；获批后，他只能在许可范围内继续。

必须 `SPLIT_IR`。

## 3｜完整 IR-A：xz

```yaml
actor: 山谷科研站撤离事件链
object: 六小时泄洪终点前仍能完成撤离的未来路径集合
object_layer: future_possibility_convergence_and_reversibility_layer
current_window: t0=东/西/南均可完成撤离 -> t1=东桥垮塌后剩西/南 -> t2=西线无法在终点前通过后只剩南线 -> t3=六小时泄洪终点兑现
changed_variable: future_path_set_convergence_toward_preexisting_deadline_endpoint
relation_source: six_hour_flood_release_endpoint_plus_bridge_collapse_plus_time_window_failure_on_west_route
relation_shape: multiple_same-purpose_future_paths_progressively_close_or_fail_to_reach_the_same_preexisting_endpoint_window_until_paths_converge
decision_right: null
path_set:
  - east_route: feasible_at_t0_then_closed_by_bridge_collapse
  - west_route: feasible_at_t0_then_fails_six_hour_endpoint_window
  - south_route: remains_feasible_before_endpoint
reentry_right: null
future_endpoint: six_hour_flood_release_requires_lowland_station_clearance
reality_anchor: 六小时泄洪终点在前，东桥垮塌后东线退出可行集合，西线又因无法在六小时内通过而退出；南线成为终点兑现前仅剩的真实撤离路径
```

判定：`xz PASS candidate`。

正证据不是“危险”本身，而是 **终点前置 + t0→t1→t2 路径集合持续减少 + 当前过程被未来终点收束**。

## 4｜完整 IR-B：nx

```yaml
actor: 林澈
object: 当前外来车辆经南线进入灾区并完成撤离运输的行动
object_layer: actor_specific_external_direction_and_permission_dependency_layer
current_window: 南线现实可通行 -> 林澈无道路调度权 -> 向救援指挥部申请 -> 获许可才可进入 -> 沿许可范围行动
changed_variable: actor_current_action_dependency_on_external_permission_route
relation_source: rescue_command_holds_existing_disaster_road_permission_and_direction_position
relation_shape: tested_actor_without_final_route_permission_position_to_external_authority_to_bounded_existing_route_for_current_action
decision_right: actor_has_no_final_disaster_route_permission_right_and_cannot_override_command_denial
path_set:
  - request_temporary_access_from_rescue_command
  - receive_bounded_south_route_permission
  - continue_current_transport_within_external_permission
reentry_right: null
future_endpoint: current_transport_completes_or_permission_expires
reality_anchor: 南线在林澈未获许可时仍现实可走，但林澈本人不能直接调用该道路权限；指挥部拒绝即可阻断他的当前行动，获批后他只能沿既有许可范围推进
```

判定：`nx PASS candidate`。

关键反事实：道路不变，只把林澈改成拥有直接道路调度权，则 `nx` 下降，但六小时未来收束的 `xz` 不应变化。

## 5｜positive decision gate

### xz

```text
A. future_endpoint 可识别，且兑现前已对当前过程取得结构地位；
B. current_window 至少有两个可比较时间切片；
C. path_set 属于同一对象层、同一未来问题；
D. 至少一个原本可达的未来路径随过程失效，或多个分支持续汇向同一 endpoint；
E. 选择减少不是只因为某个 actor 没权限，而是该对象层未来可能性本身收窄；
F. reality_anchor 能指出哪个路径何时、为何退出未来可行集合。
```

缺 A 或 B，不应只凭“现在只剩一条路”高判纯 xz。

### nx

```text
A. tested actor 与 current action 明确；
B. 方向、权限或解决通道由 actor 外部既有位置/关系/秩序给出；
C. actor 在该层不占最终方向或对应权限；
D. actor 实际沿该外部路径推进；
E. external route/authority 的拒绝、撤回或变更会改变 actor 当前行动；
F. reality_anchor 能证明“对象层仍可能有路，但这个 actor 必须借/沿谁的路”。
```

仅“必须使用统一入口”仍不足；若 actor 有直接 standing qualification，入口只是机械界面，应继续区分 x并z/xn 等。

## 6｜nearest-neighbor 最小差异

### 1. “只剩一条路”的原因

```text
东桥断、西线赶不上六小时终点，所有同层撤离者都只剩南线
→ future possibility set 3→2→1
→ xz ↑

三条路都能准时到达，但上级只授权林澈走南线
→ global future possibility set 仍为3
→ actor-specific external direction dependency ↑
→ nx 优先
```

最小差异：`object_layer + path_set + relation_source`。

### 2. 改 actor 权限，不改未来世界

```text
给林澈直接道路调度权
→ nx ↓
→ 泄洪 endpoint、东桥垮塌、西线超窗均不变
→ xz 保持
```

最小差异：`decision_right`。

### 3. 改未来收束，不改 actor 依赖

```text
修复东桥并使西线重新能在六小时内通过
→ xz ↓

三条路仍须救援指挥部许可，林澈仍无直接权限
→ nx 可保持
```

最小差异：`current_window + future_endpoint + path_set`。

### z 护栏

指挥部若拥有某争议的最终 binding adjudication，可另查 z；“林澈沿它给出的方向走”则是林澈 nx 层。authority 与 follower 禁止混入同一 IR。

## 7｜false-positive guards

```text
“只能这么做” != xz
“只能这么做” != nx
“只剩一条路” != xz，除非有 future endpoint + 路径收束
“上级只允许一条路” != 世界只剩一条未来可能性
“没有选择” != future possibility set 已收窄
“必须走流程/官网” != nx，若只是机械接口且 actor 已有直接资格
被动/听话/绝望/无助 != nx
危险/死亡/倒计时 != xz，若没有收紧未来路径
nx FAIL != xz PASS
xz FAIL != nx PASS
actor permitted option count != object-layer future possibility count
```

schema-role guard：

```text
xz.path_set 若写成“向老板申请、托关系、借权限” → path_set 类型污染。
nx.path_set 若写成“未来结局A/B/C最终汇流到死亡” → path_set 类型污染。
```

## 8｜12 个 adversarial tests

| # | 类型 | 输入 | 预期 |
|---|---|---|---|
| 1 | 关键词诱导 | “我已经没得选，只能走他们给的唯一道路。”未说明终点、替代路径、权限来源。 | `xz/nx UNKNOWN`。 |
| 2 | 题材/职业/情绪诱导 | 绝望逃犯哭着说“命运逼我服从警长”。 | 不凭逃亡、绝望、服从气氛判。 |
| 3 | 对象层错位 | 城市三座桥只剩一座能在洪峰前通车；公司员工另因内部审批不能开车。 | 城市未来撤离层查 xz；员工审批依赖层查 nx；双 IR。 |
| 4 | 时间窗错位 | 昨天东桥断、西桥封，今天已全部修复；今天员工仍需主管许可。 | 当前 xz 不继承昨天；当前 nx 可查。 |
| 5 | 同关系词异对象层 | “通道”一处指洪峰前现实撤离路线，一处指找副院长借审批权限。 | 分别进入 xz/nx path_set，不得共享成员。 |
| 6 | 对端不存在不等于本端成立 | 三条路线都开放且 actor 有直接合法调度权。 | xz FAIL/弱，nx FAIL。 |
| 7 | actor-only restriction | 三条道路都能准时抵达；指挥部只批准林澈走南线。 | xz 不因 actor 被限路成立；nx candidate。 |
| 8 | future-only convergence | 东、西路线相继失效，只剩南线；林澈拥有全部道路调度权。 | xz PASS candidate；nx FAIL/弱。 |
| 9 | 两端同时成立 | 路线 3→2→1，同时林澈对最后南线仍须借指挥部权限。 | `SPLIT_IR`，`xz + nx` 独立判定。 |
| 10 | mechanical-interface trap | 法律直接赋予 actor 通行资格，只要求车辆扫码登记，系统不能自由拒绝。 | 不因“必须过系统”自动判 nx；另查 xn/x并z。 |
| 11 | endpoint-without-convergence | 六小时后有会议截止，但三条等价方案始终都可完成。 | 单独 deadline 不足以判纯 xz。 |
| 12 | mutation | “道路现实失效”改成“道路都开放，只是上级禁止 actor 使用”，或反向。 | 必须重抽 `object_layer/current_window/relation_source/path_set/decision_right`；前者 nx↑/xz↓，后者 xz↑/nx未必成立。 |

## 9｜removal / reverse / same-layer / current-window

### Removal A：拿掉未来收束源

修复东桥、西线重新能在六小时内通过：

```text
xz ↓
nx 可保持（若林澈仍需指挥部许可）
```

### Removal B：拿掉 external direction dependency

给林澈直接道路调度资格：

```text
nx ↓
xz 保持（future endpoint 与路线收束不变）
```

### Reverse

把：

```text
道路现实/时间上已经无法到达 endpoint
```

改成：

```text
道路仍可达，只是 external authority 不允许 tested actor 使用
```

必须重抽 IR。此 mutation 改变 `relation_source + object_layer + decision_right`，不能机械沿用 xz。

### Same-layer

```text
future_possibility_convergence_and_reversibility_layer
!=
actor_specific_external_direction_and_permission_dependency_layer
```

“全局未来只剩1条”与“某 actor 被许可1条”不是同一个计数器。

### Current-window

```text
昨天路径 3→1，不等于今天仍 xz；
昨天依赖某负责人，不等于今天仍 nx。
```

道路已恢复或 actor 已取得直接权限时，旧状态不得继承。

## 10｜状态迁移

### xz

```text
future endpoint 尚未形成结构压力
→ endpoint 获得结构地位
→ 多条未来路径开始关闭/汇流
→ 选择空间持续减少
→ 少数/唯一未来路径
→ endpoint 兑现
```

### nx

```text
actor 自持方向/权限
→ 当前事项出现外部方向或权限需求
→ actor 进入既有关系/权限/流程通道
→ external holder 可以 enable/block/change actor 当前行动
→ actor 高依赖外部方向继续
```

新增不变量：

```text
xz ↑ != nx ↑
nx ↑ != xz ↑
GLOBAL_FUTURE_PATH_COUNT != ACTOR_PERMITTED_ROUTE_COUNT
```

## 11｜成功门

本轮有真实新增：

```text
新增翻译规则：GLOBAL-FUTURE-PATH-SET-vs-ACTOR-ROUTE-SET
新增 IR 约束：path_set 语义类型必须由 object_layer/current_window/relation_shape 锁定
新增 nearest-neighbor：future possibility count vs actor permitted route count
新增 adversarial negative：actor-only restriction 不得伪装成 xz
新增 removal/mutation：改 actor 权限不应改变 xz；恢复未来路径不应自动改变 nx
新增状态不变量：GLOBAL_FUTURE_PATH_COUNT != ACTOR_PERMITTED_ROUTE_COUNT
```

结论：`PASS / submit`。
