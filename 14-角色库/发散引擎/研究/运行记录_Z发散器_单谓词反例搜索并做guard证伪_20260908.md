# Z发散器｜OP-010 COUNTEREXAMPLE_SEARCH｜单谓词反例搜索并做 guard 证伪

> research-only。current canonical、十元语义解释器、L1/L2、十元信息卡、准度卡、正式关系卡与行为 evidence 正本均只读。本 operator 只改变查询坐标，不把生成反例当作十元结论，也不累计成 xn 或任何十元案例库。

## 0｜为什么值得保留

普通“找反例”很容易退化成 retrieval-only：给一个规则，再让模型找十个故事说它不成立。这只扩大样本集合，没有改变观察坐标。

本 operator 把 counterexample search 改写成 **guard falsification mutation**：

1. 先把一个结构主张压成 `target_predicate`；
2. 从该主张中只选 **一个** Semantic IR 字段作为被检验谓词；
3. 把该字段从 baseline confirmed value 改成 falsifying value / null / removed member；
4. 其余 Semantic IR 字段全部冻结；
5. 再问：在这个最近邻 counterfactual 中，原 target_predicate 是否仍可成立？

所以它改变的不是“去哪里找更多答案”，而是“哪一个必要条件值得被单独证伪”。

核心纪律：

```text
counterexample search != example retrieval
one guard test == one mutated Semantic IR field
nearest-neighbor preservation > dramatic story variation
surviving outcome != automatic Ten-Yuan label
```

当前仓库已有可执行 `ten-yuan-semantic-ir-mutation-contract-v0.1`，要求 frozen/mutated 字段分离、禁止 unauthorized drift、无真实结构变化时拒绝。本 operator 直接继承这一纪律。

## 1｜operator contract

```yaml
operator_name: COUNTEREXAMPLE_SEARCH
mutation_type: counterexample_search_guard_falsification
input_ir_prerequisites:
  required:
    - actor
    - object
    - object_layer
    - current_window
    - changed_variable
    - reality_anchor
  required_research_trace:
    - target_predicate
    - claimed_required_field
    - claimed_required_value
    - falsifying_value_or_removal
  preferred:
    - relation_source
    - relation_shape
    - decision_right
    - path_set
    - reentry_right
    - future_endpoint
mutated_fields:
  - exactly_one_of:
      - relation_source
      - relation_shape
      - decision_right
      - path_set
      - reentry_right
      - future_endpoint
      - reality_anchor
frozen_fields:
  - actor
  - object
  - object_layer
  - current_window
  - changed_variable
  - every Semantic IR field not selected as claimed_required_field
research_local_frozen:
  - target_predicate
  - source_event_or_problem
validation_hook: REINTERPRET_BASELINE_AND_COUNTERFACTUAL_WITH_CURRENT_TEN_YUAN_SEMANTIC_INTERPRETER
```

说明：`target_predicate / claimed_required_field / falsifying_value_or_removal` 均为 research-local trace，不新增 Semantic IR schema 字段。

### 单字段硬门

```text
|mutated_fields| must equal 1
```

如果为了制造反例必须同时改 `decision_right + path_set`，本轮停止，返回：

`COUNTEREXAMPLE_REQUIRES_MULTI_FIELD_DRIFT`

它不是当前 operator 的成功样本。

## 2｜query_template

```text
给定 baseline Semantic IR：
actor={actor}
object={object}
object_layer={object_layer}
current_window={current_window}
changed_variable={changed_variable}
relation_source={relation_source}
relation_shape={relation_shape}
decision_right={decision_right}
path_set={path_set}
reentry_right={reentry_right}
future_endpoint={future_endpoint}
reality_anchor={reality_anchor}

以及一个待证伪的结构主张：
target_predicate={claim}
claimed_required_field={one Semantic IR field}
claimed_required_value={baseline value}

执行 COUNTEREXAMPLE_SEARCH：
1. 把 target_predicate 改写为可判真的结构命题，不允许用人物气质/题材/结局当谓词。
2. 只选择 claimed_required_field 一个 Semantic IR 字段作为 mutation target。
3. 生成最小 falsifying mutation：
   - scalar/role field：替换为 nearest valid alternative 或 null；
   - path_set：只移除被声称必要的一个 member，不顺手增添新 bypass；
   - reality_anchor：只移除该 predicate 对应的一个 confirmed anchor，不发明补偿锚点。
4. 其余 Semantic IR 字段逐项冻结；禁止换 actor/object/object_layer/current_window/changed_variable。
5. 在变换后的 IR 上问：target_predicate 是否仍可由现实结构支持？
6. 如果仍成立，输出 GUARD_TOO_STRONG_OR_NOT_NECESSARY，并指出 surviving mechanism；该 mechanism 必须已由冻结字段或独立 reality anchor 支持。
7. 如果不成立，输出 GUARD_SURVIVES_FALSIFICATION；不得为了“找到反例”继续自由发散。
8. 如果结论变成 unknown，输出 INCONCLUSIVE_NEEDS_REALITY_ANCHOR。
9. 若只是找更多类似故事，REJECTED_RETRIEVAL_ONLY。
10. 若只是换名字/职业/题材/同义词，REJECTED_RESKIN。
11. 若为维持结论偷偷新增 actor/path/authority/condition，REJECTED_COMPENSATION_INJECTION。
12. baseline 与 counterfactual 必须分别重新经过 current 十元语义解释器；Z 不继承原 symbol。
```

## 3｜expected xn activation

本 operator 对 xn 的价值在于：把模型已有的大量 process / sequencing / routing / fallback / retry / approval / handoff / dependency 知识用于 **寻找“原以为必要的流程谓词被拿掉后，还有没有同层 surviving mechanism”**。

典型调用：

```text
claimed guard: “这个流程必须经过单一审批者”
mutation: decision_right(single-final) -> co-decision / null
frozen: actor/object/layer/window/changed_variable/path_set/anchors
query AI knowledge: 是否存在同层 joint approval / quorum / automatic gate 仍满足 target_predicate？
```

注意：模型能召回 surviving mechanism，只说明原 guard 可能过宽，不等于 candidate 自动属于 `xn`。必须重新走解释器。

## 4｜新增 guard

### `ONE-PREDICATE-FALSIFICATION-v0.1`

```text
one run -> one claimed predicate -> one mutated IR field
```

同时变化两个以上 IR 字段，不算最小反例。

### `NEAREST-NEIGHBOR-PRESERVATION-v0.1`

counterfactual 必须尽可能保持：

```text
same actor
same object
same object_layer
same current_window
same changed_variable
same target_predicate
```

反例靠换题材或换事件成立，直接失去证伪价值。

### `NO-COMPENSATION-INJECTION-v0.1`

删除一个必要条件后，不允许模型自动新增：

```text
new actor
new permission
new path
new bypass
new emergency state
new future rescue
```

除非这些结构在 baseline 已存在、只是此前未被作为 claimed predicate 使用。

### `SURVIVING-OUTCOME-NEEDS-ANCHOR-v0.1`

“拿掉 A 后结果仍发生”不能只靠故事愿望。必须指出 frozen field / retained reality anchor 中真正支持结果继续成立的机制。

### `FAILED-FALSIFICATION-IS-SUCCESSFUL-AUDIT`

如果 mutation 后 target_predicate 确实失效，返回 `GUARD_SURVIVES_FALSIFICATION` 即可。operator 不以“必须找到反例”为成功条件。

这条很重要，否则模型会为了交差开始自造密道、隐藏权限和突然出现的副本管理员。

## 6｜stop condition

出现任一情况立即停止：

1. 单字段 mutation 已得到 `GUARD_TOO_STRONG_OR_NOT_NECESSARY`；
2. 单字段 mutation 已得到 `GUARD_SURVIVES_FALSIFICATION`；
3. 结果只能保持 unknown，且没有更多同层 confirmed reality anchor；
4. 继续寻找反例需要改第二个 Semantic IR 字段；
5. 继续寻找反例需要换 actor/object/object_layer/current_window/changed_variable；
6. 连续候选只是在换词、换职业、换作品皮肤；
7. 已经能判断 guard 的必要性，不继续堆案例。

## 7｜when_not_to_use

- 目标只是“找更多类似案例”时不用；
- 尚未有明确 target_predicate 时不用；
- baseline IR 大量字段为 null、无法冻结最近邻时不用；
- 想比较同词不同结构，优先 OP-009 SAME_NOUN_DIFFERENT_STRUCTURE；
- 想枚举所有路径，优先 OP-003 ENUMERATE_PATH_SET；
- 想删除一个外部现实条件，优先 OP-005 REMOVE_CONDITION；
- 想直接改变 relation 方向，优先 OP-007 REVERSE_RELATION；
- 想测试多个字段协同变化时，本 operator 明确不适用。

## 8｜跨领域测试

> 以下只测试 operator 是否能稳定改变“哪一个必要条件值得被检索”，不累计为 xn 或十元 evidence。

### T1｜《红楼梦》：公开拒绝是否“必须由上位者最终裁定”才现实有效

baseline query：同一拒婚事件、同一个人同意层与 current window。

```text
target_predicate = 本人拒绝是否已在当前同意层形成现实阻断
claimed_required_field = decision_right
baseline = 上位 final holder 可阻断婚配推进
mutation = decision_right -> null/unknown for the tested personal-consent layer
all other IR fields frozen
```

检索重点变成：公开拒绝、当众声明、现实执行是否已经产生同层阻断，而不是去找另一个“更厉害的人物”。

**结果：PASS / INCONCLUSIVE-OR-GUARD-SCOPE-TOO-BROAD。** operator 能迫使解释器区分“个人同意层有效拒绝”与“家族最终裁定层”；若需要上移 object_layer 才能继续讨论 final authority，应返回 layer conflict，而不是制造反例。

### T2｜《西游记》：最终回返是否“必须由主体自己拥有 direct reentry_right”

```text
target_predicate = 该关系在目标窗口内是否仍存在现实回返可能
claimed_required_field = reentry_right
baseline = actor-specific direct reentry callable
mutation = reentry_right -> false/null
path_set / relation_source / current_window frozen
```

若 baseline 已确认存在 mediated path，则 operator 应把问题改成：**direct self-callable reentry 消失后，system-level mediated reentry 是否仍支持“存在回返可能”**。

**结果：PASS / GUARD_TOO_STRONG_OR_NOT_NECESSARY（仅针对“任何回返可能”这一宽 predicate）。** 若 target_predicate 改成“主体可自行回返”，则 guard 反而应 surviving。该测试证明 predicate scope 必须先锁定。

### T3｜工程发布：生产部署是否“必须存在单一 final approver”

```text
target_predicate = 当前版本存在一条现实可调用的 release route
claimed_required_field = decision_right
baseline = single final approver
mutation = decision_right -> co-decision / conditional holder
path_set 与 release object_layer frozen
```

检索 AI 已有的 quorum / joint approval / policy gate 知识，但只有 baseline reality anchor 已支持这类 holder topology 才可保留。

**结果：PASS。** 若 release route 在 co-decision 下仍真实可调用，原“single holder 必要”guard 被证伪；若 baseline 没有共同决策 anchor，则 INCONCLUSIVE，不允许现场发明委员会。

### T4｜制度采购：推进是否“必须依赖当前指定的一个审批 route”

```text
target_predicate = 当前采购仍存在合法推进路径
claimed_required_field = path_set
baseline = {ordinary_approval, preconfirmed_emergency_route}
mutation = remove ordinary_approval only
all other fields frozen
```

检索重点不是“再想个办法”，而是检查 baseline 已存在的 emergency route 是否属于同一 object_layer、同一 changed_variable、当前 window 可调用。

**结果：PASS / GUARD_TOO_STRONG_OR_NOT_NECESSARY。** 若 emergency route 已 confirmed，`ordinary_approval` 不是 target predicate 的必要条件；若 emergency route 不可调用，则 guard survives。

### T5｜现实医疗：某病人进入 ICU 是否“必须由当前 named route 完成”

```text
target_predicate = 当前窗口病人仍有同层 ICU admission path
claimed_required_field = path_set
baseline = {ED_admission, transfer_center_route}
mutation = remove ED_admission only
```

冻结 patient/object_layer/eligibility/current_window，不得新增医院或床位。

**结果：PASS。** 只有 baseline 已 confirmed 的 transfer-center route 能作为 surviving mechanism；若它只属于跨院转运而不是同一 ICU admission object layer，则必须判 CROSS_LAYER_COUNTEREXAMPLE，不能算反例。

### T6｜反例控制：唯一 retry API 是否真为必要 path

```text
target_predicate = 当前系统存在一次可调用的 retry
claimed_required_field = path_set
baseline = {retry_api}
mutation = remove retry_api
```

所有其他字段冻结，且 baseline 无其他 retry route。

**结果：PASS-CONTROL / GUARD_SURVIVES_FALSIFICATION。** operator 应停在这里，不准为了“找到反例”发明隐藏 endpoint。

## 9｜防退化 probes

### Probe-R1｜换作品找反例

“再找十个没有审批也成功的故事。”

没有做单字段 Semantic IR mutation。

**REJECTED_RETRIEVAL_ONLY。**

### Probe-R2｜换职业换名词

“把审批人换成舰长、医生、校长，看规则是否还成立。”

只是换主体职业皮肤。

**REJECTED_RESKIN。**

### Probe-R3｜补偿注入

移除唯一 route 后，为了保持 target predicate，模型自动新增“隐藏密道/管理员后门/紧急豁免”。

**REJECTED_COMPENSATION_INJECTION。**

### Probe-R4｜多字段漂移

移除 `path_set` member 的同时又把 `decision_right` 换成另一个 holder。

**COUNTEREXAMPLE_REQUIRES_MULTI_FIELD_DRIFT。**

### 为什么有信息增益

OP-005 REMOVE_CONDITION 问的是：**拿掉一个现实条件，结构怎么变？**

OP-010 COUNTEREXAMPLE_SEARCH 问的是：**一个我们声称“必要”的 IR predicate 真的是必要的吗？**

两者不是同一件事。OP-010 的新价值在于把 guard 本身作为攻击对象，并强制 nearest-neighbor / one-field falsification，因此能审计当前 interpreter guard、Z operator guard、decision gate prerequisite 是否写得过宽。

## 11｜validation hook

每个 baseline/counterfactual pair 必须执行：

```text
validate Semantic IR shape
→ enforce one mutated field
→ enforce frozen-field equality
→ confirm no compensation injection
→ inspect retained reality anchors
→ rerun current Ten-Yuan semantic interpreter on baseline
→ rerun current Ten-Yuan semantic interpreter on counterfactual
→ compare interpretation delta
```

禁止：

```text
generated counterexample
=> directly label Ten-Yuan
```

## 12｜下一最高价值 mutation

下一轮优先：`NEAREST_NEIGHBOR_SEARCH`，但必须定义成 **Semantic IR Hamming-1 / constrained-neighbor search**，不是“找相似案例”。

建议核心：

```text
freeze target changed_variable + object_layer + current_window
choose exactly one additional IR coordinate to vary
enumerate structurally nearest valid neighbors
rank by interpretation delta / mechanism delta
reject lexical similarity without IR delta
```

这样 Z 会从“单点 mutation”继续长出一个受约束的局部邻域搜索器，可以系统地发现解释器决策边界，而不是把“最近邻”退化成语义 embedding 相似度。
