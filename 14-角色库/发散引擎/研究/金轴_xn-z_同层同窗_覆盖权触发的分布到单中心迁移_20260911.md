# 金轴 xn↔z｜同层同窗：覆盖权触发的分布→单中心迁移

> L4 research-only。只测试金轴最小结构迁移，不修改 L1/L2 canonical、信息卡、准度卡、正式关系卡或行为 evidence。

## 0｜本轮缺口

前两轮已分别建立：

```text
BINDING-EFFECT-LOCUS-v0.1
final action ≠ final center

EFFECTIVE-DISTRIBUTION-GATE-v0.1
many nodes ≠ distributed authority
```

仍缺一块关键拼图：

> 在 actor、object、object_layer、current_window、节点数、流程顺序都不变时，究竟哪一个最小结构变量能把同一系统从 `xn` 翻转为 `z`？

本轮只测试一个候选变量：

```text
unilateral_override_scope
```

即：单一中心能否无条件覆盖原本具有现实效力的局部门。

新增候选判据：

```text
OVERRIDE-COLLAPSE-TRANSITION-v0.1
```

---

## 1｜核心假设

金轴迁移不是：

```text
多节点 → 少节点
复杂流程 → 简单流程
多人 → 一人
```

而是：

```text
多个节点仍存在
但局部 binding effect 被一个中心获得无条件覆盖权
→ 裁定重心发生结构性坍缩
```

因此严格迁移应允许“流程外观完全不变”，只改变：

```text
局部门的不可覆盖性
```

---

## 2｜同层同窗最小差异对

固定背景：

> 同一动画项目的成片发布审查包含安全、预算、版权三个门。三个门、负责人、材料、顺序、输出都保持不变。

### 状态 T0｜真 xn：三个局部门不可被单中心覆盖

```yaml
actor: 动画项目发布审查系统
object: 成片是否获得本轮发布资格
object_layer: 当前轮发布资格裁定层
current_window: 安全审查 -> 预算审查 -> 版权审查 -> 发布资格形成
changed_variable: adjudication_center_distribution
relation_source: distributed_non_overridable_local_gates
relation_shape: three_binding_local_gates_without_unilateral_override
decision_right: distributed_across_three_gates
path_set:
  - safety_gate
  - budget_gate
  - copyright_gate
reentry_right: failed_gate_can_reenter_after_repair
future_endpoint: release_only_if_all_gates_pass
reality_anchor: 任一门都可独立阻止本轮发布；负责人不得跳过任何失败门
binding_effect_source: distributed_nodes
execution_right: release_manager_only_after_all_pass
adjudication_right: distributed_local
counterfactual_override: no
local_state_transition_right: true_for_each_gate
unilateral_override_scope: none
```

判定：

```text
xn candidate PASS = 0.98
z FAIL = 0.97
```

原因：当前 object_layer 的现实有效性由三个不可省略、不可被单中心覆盖的局部门共同生成。

---

### 状态 T1｜边界态：负责人只有有限紧急豁免

只改一项：

> 负责人可在“预算门”失败时使用一次书面豁免，但不能覆盖安全门与版权门。

```yaml
actor: 动画项目发布审查系统
object: 成片是否获得本轮发布资格
object_layer: 当前轮发布资格裁定层
current_window: same_as_T0
changed_variable: adjudication_center_distribution
relation_source: distributed_gates_with_partial_override
relation_shape: distributed_binding_nodes_with_one_limited_override
decision_right: distributed_with_partial_exception
path_set:
  - safety_gate
  - budget_gate
  - copyright_gate
reentry_right: failed_nonoverridable_gate_requires_repair
future_endpoint: release_after_remaining_binding_gates
reality_anchor: 负责人只能覆盖预算门；安全/版权失败仍独立阻止发布
binding_effect_source: mostly_distributed_nodes
execution_right: release_manager
adjudication_right: distributed_plus_partial_override
counterfactual_override: partial
local_state_transition_right: true_for_each_gate
unilateral_override_scope: one_of_three_limited
```

判定：

```text
xn remains candidate PASS = 0.88
z whole-layer FAIL / local z-like exception only = 0.80
```

本轮重要边界：

> 出现一个局部覆盖权，不足以自动宣布整个 object_layer 已经坍缩为 z。

只要仍有多个独立门对同层结果保持不可覆盖的 binding effect，分布结构尚未消失。

---

### 状态 T2｜真 z：单中心获得全局无条件覆盖权

再次只改同一个变量：

> 负责人现在可以对安全、预算、版权三个门的任一失败结果直接签发最终豁免，也可以在三门全部通过后否决发布；负责人决定一旦作出，其他门在本轮无权重新阻止或覆盖。

```yaml
actor: 动画项目发布审查系统
object: 成片是否获得本轮发布资格
object_layer: 当前轮发布资格裁定层
current_window: same_as_T0
changed_variable: adjudication_center_distribution
relation_source: global_unilateral_override
relation_shape: distributed_inputs_collapsed_under_single_final_center
decision_right: single_final_center
path_set:
  - safety_input
  - budget_input
  - copyright_input
  - release_manager_final_decision
reentry_right: only_if_final_center_reopens_round
future_endpoint: release_or_block_as_decided_by_single_center
reality_anchor: 三门继续产出判断，但其 binding effect 均可被负责人直接覆盖；负责人也可否决全部通过结果
binding_effect_source: single_final_center
execution_right: release_manager
adjudication_right: single_final_center
counterfactual_override: yes_global
local_state_transition_right: gates_advisory_or_provisional_under_override
unilateral_override_scope: all_binding_gates_plus_final_veto
```

判定：

```text
xn FAIL at current adjudication layer = 0.96
z candidate PASS = 0.98
```

注意：三个门仍然存在、仍然产生记录、仍然按相同顺序运行，但金轴判定已经翻转。

## 3｜最小判别式

```text
xn → z 的关键不在节点消失，
而在“不可覆盖的局部 binding effect”是否被单一中心全面降格为可覆盖输入。
```

压缩：

```text
local binding nodes remain non-overridable
→ xn

partial override while multiple non-overridable gates remain
→ xn-dominant boundary state / SPLIT audit

global unilateral override + final veto
→ binding-effect locus collapses to one center
→ z
```

候选迁移门：

```text
OVERRIDE-COLLAPSE-TRANSITION-v0.1
```

## 4｜removal test

### T0

拿掉负责人，只保留三门与自动发布：

```text
原有分布裁定仍可运行
→ 负责人不是必要 binding center
→ xn 保持
```

### T2

拿掉负责人的全局覆盖/否决权，只保留其机械发布动作：

```text
三门恢复不可覆盖的局部效力
→ z 消失
→ xn 恢复
```

说明翻转由 override 权引发，而非负责人身份或最后动作顺序。

---

## 5｜reverse test

保持“负责人、最终、批准、签字”全部词面，但令负责人不得覆盖任何门：

```text
z FAIL
xn PASS
```

删除所有这些词，只写：

> “节点 R 可以无条件使任一门的失败失效，也可以让全部通过失效；其他节点不能覆盖 R。”

则：

```text
z PASS
xn FAIL at same layer
```

关键词再次被证明既非必要也非充分。

## 6｜freeze-third-factor

T0/T1/T2 冻结：

- actor 不变
- object 不变
- object_layer 不变
- current_window 不变
- 节点数 = 3 + 负责人
- 节点顺序不变
- 记录形式不变
- 输出仍是“本轮可发布 / 不可发布”
- 三门仍产生判断

唯一主变量：

```text
unilateral_override_scope:
none → partial → global
```

观察结果：

```text
none    → xn
partial → xn-dominant boundary / mixed audit
full    → z
```

支持“裁定重心配置”确实可以在同层同窗内发生连续结构迁移，而不是靠换题材或换角色制造差异。

## 7｜positive / negative controls

### Positive control｜工程发布系统

CI 发布包含安全扫描、测试、签名校验三门。若任一失败都不可人工覆盖，则当前发布资格层优先 `xn`。若新增一个 root release authority，可无条件强制发布或阻断所有结果，则当前层转为 `z candidate`。

### Negative control 1｜管理员只是重启流程

管理员可“重开一轮”，但不能在当前轮直接覆盖任一门的结果：

```text
reentry_right ≠ current-round adjudication override
→ 不足以判 z
```

### Negative control 2｜只能覆盖执行时间

负责人可决定今天还是明天发布，但不能改变是否满足发布资格：

```text
execution scheduling ≠ adjudication-center collapse
→ 不足以判 z
```

### Negative control 3｜一个门天然权重更高

安全门比预算门重要，但它仍只能裁定自己的局部对象，不能覆盖版权门或最终重写整个发布资格：

```text
asymmetric local power ≠ single final center
```

## 8｜nearest-neighbor

### xn vs z

```text
xn：多个节点的局部 binding effect 对同层最终状态是共同必要的，且不存在全局无条件覆盖中心。
z：所有局部结果最终都可被一个中心覆盖/否决，现实有效性收束到该中心。
```

### z vs x

拥有“豁免某项规则”的处分能力不自动等于 z。必须进一步证明该能力覆盖的是当前 object_layer 的最终有效性，而不是局部对象的使用/处分。

### xn vs nx

多个节点执行既定流程，但都没有局部 binding effect，仍不能判 xn；那可能只是沿既有方向接力执行。

## 9｜新增失败类型

```text
PARTIAL_OVERRIDE_AS_FULL_Z
```

触发：单中心只能覆盖一个局部门，却被误判为整个 object_layer 的 z。

```text
HIGH_WEIGHT_LOCAL_GATE_AS_FINAL_CENTER
```

触发：某个局部门更重要/权重更高，就被误判为最高裁定中心。

```text
REOPEN_RIGHT_AS_OVERRIDE_RIGHT
```

触发：能够重开下一轮，被误写为能够直接改写当前轮结果。

```text
EXECUTION_TIMING_AS_ADJUDICATION_COLLAPSE
```

触发：能决定何时执行，被误写为能决定结果是否有效。

```text
NODE_PRESENCE_AS_DISTRIBUTION_PERSISTENCE
```

触发：因为局部门仍存在、仍产出记录，就错误认为 xn 仍存在；忽略这些节点已被全局覆盖权降格为可覆盖输入。

## 10｜本轮结论

本轮得到一个比“xn 与 z 分别是什么”更强的候选迁移规则：

```text
OVERRIDE-COLLAPSE-TRANSITION-v0.1
```

当前最短表达：

> **金轴从 xn 向 z 的最小迁移，不要求删掉流程节点；只要一个单一中心获得对同层全部局部 binding effect 的全局无条件覆盖/否决权，裁定重心就会从分布结构坍缩到单一中心。**

反方向同理形成候选预测：

```text
若单一中心失去全局覆盖权，
且多个局部门恢复独立、不可被单一节点覆盖的 binding effect，
则 z → xn 应成立。
```

该反向迁移尚需下一轮独立压力测试，不能因形式对称直接视为已证实。

## 11｜成熟度与下一断点

研究层暂定：

```text
金轴成熟度：7.2 → 7.6 / 10
```

理由：首次获得同 actor / object / object_layer / current_window 的严格状态迁移，而不是把 xn 与 z 分别描述。

下一断点只测试反方向：

```text
z → xn
```

重点区分：

1. 单一中心只是“授权下放”，但随时可无条件收回/覆盖，是否仍应保持 z；
2. 什么条件下局部门才算真正恢复独立 binding effect，而不是 delegated execution；
3. revocable delegation 与 genuine distributed authority 的最小差异。
