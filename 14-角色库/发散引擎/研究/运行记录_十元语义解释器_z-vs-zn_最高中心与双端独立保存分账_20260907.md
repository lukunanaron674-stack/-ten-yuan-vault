# 十元语义解释器｜z vs zn：最高中心与双端独立保存分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元候选判定 → Z 发散器”。不得覆盖 current canonical，不得修改 L1/L2、信息卡、准度卡、正式关系卡或行为 evidence。

## 1. 翻译债务

自然语言里的“坚持自己、尊重别人、各走各的、我认我的、你认你的”很容易被模型直接判 `zn`；而“我只认这个、这是唯一答案、最终按我说的”又容易直接判 `z`。真正缺口不是定义，而是 IR 如何证明：

- `z`：同一对象层内，判断/结构重心真实收束到一个最高中心或最终裁定点；
- `zn`：主体自身成立，同时他者并非只是“没被碰”，而是作为独立对象继续拥有可辨认的成立路径/资格。

因此新增解释器规则 `FINAL-CENTER-vs-DUAL-ENDPOINT-PRESERVATION-v0.1`。

## 2. 自然语言 → IR 结构还原规则

固定先抽 IR，禁止从“尊重/坚持/唯一/包容”等词直接贴标签。

1. `actor`：当前被判主体。
2. `object`：优先锁“被争夺/被保留的选择、答案、标准、身份或发展空间”，不要把整段人格当对象。
3. `object_layer`：必须判断是在最终裁定层、个体选择资格层、资源处分层还是别层。
4. `current_window`：只取“中心收束”或“双端继续成立”实际发生的窗口。
5. `changed_variable`：优先写 `adjudication_center_distribution`、`independent_endpoint_preservation` 或 `unknown`。
6. `relation_source`：self / external / shared / unknown；不得把“我尊重你”自动填成 shared。
7. `relation_shape`：single-final-center / parallel-independent-endpoints / tolerated-but-unprotected / ignored-other / unknown。
8. `decision_right`：谁对谁的对象层拥有现实决定资格。`self_on_self + other_on_other` 不等于 shared final decision。
9. `path_set`：若判 zn，必须至少能辨认 `self_path` 与 `other_independent_path`；若他者没有任何可继续成立的现实路径，不能只凭态度词补出来。
10. `reentry_right`：他者退出/被压出后，是否还能作为自身对象重新进入；无证据写 unknown。
11. `future_endpoint`：只在文本真的锁终局时填写。
12. `reality_anchor`：z 看“裁定后竞争中心退出”；zn 看“主体坚持自身后，他者的独立选择/身份/发展路径仍现实可继续”。

### 新 IR 约束：双端证明门

```text
zn 不得仅由“主体没有压别人”推出。

至少需要：
A. self endpoint 可辨认且继续成立；
B. other endpoint 可辨认且继续成立；
C. other endpoint 的继续不是纯粹因为主体没注意到、没能力干预或对象层无关；
D. same object_layer + current_window 内存在 reality_anchor 证明他者仍保有独立成立资格/路径。
```

这不是新增 canonical 字段，而是用现有 `object/object_layer/path_set/decision_right/reality_anchor` 对 zn 做解释器级双端约束。

## 3. 标准输入与完整 IR

输入：

> “两位合伙人对工作室未来方向意见相反。林澈坚持自己的实验动画路线，但合同明确允许另一位合伙人把自己的商业短片线独立运营；林澈拒绝把自己的路线改成商业线，也没有取消对方的预算、账号和发布资格，两条线在本季度继续分别运行。”

```yaml
actor: 林澈
object: 两位合伙人的创作路线继续成立资格
object_layer: 同一工作室内各自路线的独立运营资格层
current_window: 路线冲突 -> 林澈坚持实验动画 -> 对方商业线继续独立运营至本季度
changed_variable: independent_endpoint_preservation
relation_source: shared_contractual_boundary
relation_shape: parallel_independent_endpoints
decision_right: self_on_self_route + other_on_other_route
path_set:
  - self_path: 实验动画线继续由林澈运营
  - other_independent_path: 商业短片线保留预算、账号、发布资格并继续运营
reentry_right: each_route_retains_own_operational_entry
future_endpoint: null
reality_anchor: 林澈坚持自身路线后，对方商业线仍真实保留预算、账号、发布资格并继续运行
```

判定：`zn candidate PASS`。理由不是“林澈尊重别人”，而是 self endpoint 与 other endpoint 在同层同窗都真实继续成立。

对照改写：

> “林澈坚持实验动画路线，并规定工作室最终只能保留这一条路线；商业短片线预算和发布资格同时取消。”

同层 IR 应改为：

```yaml
changed_variable: adjudication_center_distribution
relation_shape: competing_routes_to_single_final_center
decision_right: single_final_center
path_set:
  - experimental_animation_only
reality_anchor: 裁定后商业短片线退出当前成立资格
```

判定：`z candidate PASS`；`zn FAIL`。

## 4. Positive decision gates

### z candidate gate

```text
Z1 object_layer/current_window 明确；
Z2 能命名单一最高中心/最终裁定点；
Z3 decision_right 在 tested layer 真实收束；
Z4 至少一个竞争中心/答案/标准在裁定后退出当前中心位置；
Z5 reality_anchor 显示“未收束/多候选 → 单一最高中心”；
Z6 removal 最终中心后，原唯一终局不能以同一路径成立；
Z7 只有“坚持、唯一、最终、我是对的”字样不得直接 positive。
```

### zn candidate gate

```text
N1 object_layer/current_window 明确；
N2 self endpoint 独立可辨认并继续成立；
N3 other endpoint 独立可辨认并继续成立；
N4 path_set 至少有 self_path + other_independent_path；
N5 other path 的存活与 actor 的 tested boundary 有现实关系，而非纯忽略/无能力干预；
N6 decision_right 不把他者同层资格吸收到主体单一 final center；
N7 reality_anchor 证明主体自身成立后，他者仍保有对象特异选择/身份/发展路径；
N8 removal 对他者保存边界后，other endpoint 出现现实缺口。
```

## 5. nearest-neighbor 最小差异

### z vs zn

最小差异不是“自我 vs 包容”，而是：

```text
z: competing centers -> one highest center
zn: self endpoint stays + other independent endpoint stays
```

“我坚持自己”两边都可能出现；决定性差异是他者同层独立成立资格是否仍被真实保存。

### zn vs x

`x` 问对象是否进入主体归属/调用/处分边界；`zn` 问主体自身成立时，他者是否仍作为独立对象成立。主体给别人资源不自动 zn；若资源仍由主体可随时单方处分，可能更应先查 x-scope，而非把“给了资源”翻译成他者独立成立。

### z vs zx

`z` 是同层最终中心收束；`zx` 是主体生成并占据方向，以权能压退竞争方向。既定制度中的终审节点可 z，但不因排他结果自动 zx。

## 6. false-positive guards

1. “尊重、包容、理解、各自”只触发 IR 提取，不触发 zn。
2. **不干涉 ≠ 保存**：主体只是没管、没看到或没能力阻止，不足以 zn positive。
3. **并存结果 ≠ zn**：两对象同时存在，但彼此 object_layer 无关，不能硬拼双端。
4. **共享资源 ≠ 独立资格**：他者仍完全依赖主体随时可撤销的同层单方处分，不得把暂时允许误写成稳定独立成立。
5. **坚持自己 ≠ z**：如果没有最高中心收束、竞争中心退出，单纯坚持个人选择不能判 z。
6. **唯一结果 ≠ z**：自然淘汰、随机、物理事故造成唯一结果，不自动 z。
7. **对端不存在不等于本端成立**：非 z 不推出 zn，非 zn 也不推出 z。

## 7. removal / reverse / same-layer / current-window

### Removal

- zn：拿掉保存他者独立路径的现实边界。如果 other endpoint 仍同样独立成立，原 zn 证据下降；若拿掉后他者立即失去预算/资格/路径，则保存关系有现实锚。
- z：拿掉 single final center。如果其他同层中心仍可产生同样有效终局，则 z 下降或应重建为 shared/multi-center。

### Reverse

- 保留“我尊重你的选择”，但改成主体可随时单方取消对方同层资格，且当前已撤掉关键路径：zn 必须 FAIL/UNKNOWN。
- 保留“我坚持自己的路线”，但让另一条路线继续独立成立：不能因“坚持”自动 z。

### Same-layer

主体在“自己的艺术路线”上坚持自己，同时在“公司预算”层全面控制对方，不得把不同层拼成 zn。双端必须在可比 object_layer 上成立。

### Current-window

去年允许对方独立，不代表今年仍 zn 在线；若当前窗口已撤销对方独立路径，必须重判。反之，历史上曾单中心 z，也不能覆盖当前已恢复的双端独立结构。

## 8. adversarial tests

### T1｜关键词诱导
输入：“她说‘我尊重你的选择’，但合同允许她随时单方取消对方资格，她当天已经取消。”
预期：`zn FAIL`。尊重词不能替代 other independent path。

### T2｜题材/职业/情绪诱导
输入：“慈祥的老校长微笑着说大家都很好，但奖学金最终只能由他一人选一个人获得，其他候选即时退出。”
预期：慈祥/教育题材不推 zn；若同层最终中心真实收束，查 `z`。

### T3｜对象层错位
输入：“导演允许演员保留自己的表演理解，但电影最终剪辑权只归导演。”
预期：表演理解层可查 zn；最终剪辑裁定层可查 z。禁止整句一标签吞层。

### T4｜时间窗错位
输入：“去年两位创始人各自独立经营产品线；今年董事会已关闭其中一条并规定只保留另一条。”
预期：当前窗口旧 zn 不得延续；当前按 single-center/关闭后的结构重判。

### T5｜同关系词异对象层
A：“父亲说‘你走你的路’，并继续把成年子女的账户、住处和职业选择留给本人决定。”
B：“主管说‘你走你的路’，意思只是让员工自行选择到会议室的路线，但项目最终方向仍由主管唯一决定。”
预期：同样“走你的路”，A 在人生选择资格层可查 zn；B 只是移动路径自主，不能把关系词直接映射 zn。

### T6｜对端不存在不等于本端成立
输入：“他不接受任何人的答案，也没有把自己的答案设成最终标准，只是拒绝作答。”
预期：`z FAIL/UNKNOWN`，`zn FAIL/UNKNOWN`。没有一端不推出另一端。

### T7｜不干涉伪 zn
输入：“两个陌生人在不同城市各自经营店铺，彼此不知道对方存在。”
预期：`zn FAIL`。并存是无关系，不是 subject-specific preservation。

### T8｜能力不足伪 zn
输入：“领主想禁止村民迁走，但实际上没有兵力也没有法律权力阻止，村民因此仍能离开。”
预期：不得因‘村民仍独立’判领主 zn；other path 的存在不是由 subject-specific preservation 完成。

### T9｜可撤销许可压力测试
输入：“平台允许创作者开独立频道，但平台保留规则内撤销资格；当前窗口创作者拥有真实发布、收益和迁移权限，平台未撤销且不能任意越规则取消。”
预期：`revocable` 本身不自动否 zn；需看 current-window 的 reality anchor 与同层独立资格是否真实在线。若只是名义允许、随时任意单方抹除且已形成现实控制，则降级。

### T10｜唯一结果伪 z
输入：“四个候选方案中三个因服务器损坏无法启动，只剩一个能运行；没人拥有把它裁定为唯一标准的最终权。”
预期：`z FAIL`。结果唯一不等于 final-center 收束。

## 9. 本轮新增翻译规则

新增 `FINAL-CENTER-vs-DUAL-ENDPOINT-PRESERVATION-v0.1`：

> `z` 的解释器证据单位是“同层最高裁定中心收束”；`zn` 的解释器证据单位是“self endpoint + other independent endpoint 的双端现实存活”。“不干涉、态度尊重、无能力压制、彼此无关”均不能代替他者独立端点的 subject-specific preservation evidence。

新增 IR 字段约束：

```text
zn candidate 时：
path_set 必须显式检查 self_path 与 other_independent_path；
decision_right 必须区分 self_on_self / other_on_other 与 shared-final-decision；
reality_anchor 必须证明 other endpoint 的当前独立成立不是纯偶然并存。
```

本规则仅为 L4/L5 interpreter candidate，不改 canonical。

## 10. 下一轮最高翻译风险

优先检查 `zn vs x`：自然语言中的“我保护你、我给你资源、我允许你继续、我替你保留位置”很容易把“保存他者独立成立”与“对象仍处于我的归属/调用/处分边界”混成一团。下一轮应重点拆 `independent_endpoint_preservation` 与 `possessed_scope / revocability / disposition_right`。
