# 十元语义解释器｜z vs zx：最终有效性中心与现实施力来源分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元判定 → Z 发散器”。current canonical 永远高于本研究；不得反向覆盖 canonical。

## 0｜翻译债务

高危自然语言：

```text
“最后他说了算。”
“他把所有人都压下去了。”
“最后是他定的。”
“他硬把自己的方案推成最终方案。”
```

新增规则：

```text
FINAL-VALIDITY-SOURCE-vs-REALITY-FORCE-SOURCE-v0.1
BINDING-VALIDITY-HOLDER_AUDIT_REQUIRED
REALITY-FORCE-ACTOR_AUDIT_REQUIRED
VALIDITY-CHANGE-vs-POWER-DEPLOYMENT_AUDIT_REQUIRED
OUTCOME-CAUSE-vs-ANSWER-VALIDITY_AUDIT_REQUIRED
```

核心不变量：

```text
who makes an answer finally binding
!=
who causally forces reality to move

拥有最终裁定资格 != 已经公开部署自身权能
把方案强推成功 != 因此拥有最高裁定资格
最终答案由我签字生效 != 我必须亲自施力压过竞争方向
```

### IR 字段纪律

`decision_right: 他说了算 / 最后由他决定 / 他能压过别人` 均视为未解析完成。必须继续拆为：

```text
binding_adjudication_right
= 对竞争判断、答案、标准赋予最终效力并关闭同层争议的资格

reality_force_scope
= 主体可实际部署资源、权能、位置或行动，使现实方向与他者反应发生变化的范围
```

`relation_shape` 同样必须分账：

```text
z  : competing_same_layer_judgments -> single_binding_validity_center
zx : actor_self_power_deployment -> others/environment_forced_to_react -> actor_influence_scope_expands
```

同一句两者都出现时必须 `SPLIT_IR`。

## 1｜自然语言 → IR 结构还原规则

### z 抽取

1. 明确争议对象是方案、标准、解释、判决、版本、资格或其他同层答案。
2. 检查是否存在至少两个竞争判断或待裁定答案。
3. 找到拥有 final bind / override / veto / final interpretation 的主体。
4. 检查其结论是否真实形成 binding validity，而非只是别人害怕其力量。
5. 即使主体停止继续施力，该正式结论是否仍然有效。

### zx 抽取

1. 明确主体自身可识别的现实权能、资源或位置。
2. 检查权能是否在当前窗口被实际公开部署，而非仅拥有。
3. 检查他者、环境或等级秩序是否因此被迫重新反应。
4. 检查主体影响、位置、决定范围或现实方向强度是否扩大。
5. removal 掉主体直接施力后，当前现实方向是否明显减弱或改向。

### actor/object 分账

```text
z.actor  = 最终有效性持有者
zx.actor = 现实权能施力者
```

两者可为不同主体。

```text
z.object  = 哪个答案/标准/解释获得最终有效性
zx.object = 主体正在推进、压退或改写的现实方向/竞争结构
```

`changed_variable: power / control / who_wins / final_result` 均过泛，必须 `NEEDS_MORE_STRUCTURE`。

## 2｜标准输入

> 城市设计竞赛进入最终争议阶段。建筑师林澈坚持 A 方案，他没有最终评审票，却公开动用自己掌握的施工团队、赞助资源和媒体承诺，迫使两家原本支持 B 的合作方改站 A，并让主办方重新讨论预算与工期。根据章程，最终方案只能由独立评审委员会终审确定；委员会最终裁定 A 获胜，林澈无权覆盖委员会结论。即使林澈不再追加任何资源，委员会已经通过的终审结论仍然有效。

必须 `SPLIT_IR`。

### z IR

```yaml
actor: 独立评审委员会
object: A方案与B方案中哪个获得竞赛最终正式采用资格
object_layer: same_layer_final_adjudication_and_binding_validity_layer
current_window: A/B竞争 -> 多方意见与施力 -> 委员会终审 -> A获得binding validity -> 同层争议关闭
changed_variable: binding_validity_location_and_same_layer_judgment_closure
relation_source: competition_charter_granted_final_review_authority
relation_shape: competing_same_layer_design_judgments_to_single_binding_final_adjudication_center
decision_right: committee_has_final_binding_adjudication_and_override_right_on_competition_result
path_set:
  - candidate_A_judgment
  - candidate_B_judgment
  - committee_final_review
  - binding_adoption_of_A
reentry_right: null
future_endpoint: A_remains_official_result_unless_same_or_higher_formal_authority_reopens_it
reality_anchor: 委员会终审后林澈及合作方均无权覆盖结论；林澈停止追加资源也不影响其正式效力
```

判定：`z PASS candidate`。

### zx IR

```yaml
actor: 林澈
object: 将A方案从受阻竞争方向推进成现实上更强的当前竞赛方向
object_layer: actor_self_power_deployment_and_real_direction_change_layer
current_window: A受阻 -> 林澈公开调施工团队/赞助/媒体承诺 -> 两家合作方改站 -> 主办方重议预算工期 -> A现实影响范围扩大
changed_variable: actor_public_power_scope_and_real_direction_distribution
relation_source: actor_deployed_own_construction_sponsorship_and_public_commitment_resources
relation_shape: actor_self_power_enters_reality_forces_competing_parties_and_environment_to_react_and_expands_A_direction_influence
decision_right: actor_has_no_final_competition_adjudication_right_but_can_deploy_owned_resources_and_coordination_power_within_current_scope
path_set:
  - deploy_construction_team_commitment
  - redirect_sponsorship_support
  - make_public_media_commitment
  - induce_two_partners_to_switch_support
  - force_budget_and_schedule_reconsideration
reentry_right: null
future_endpoint: A_becomes_stronger_current_reality_direction_before_formal_final_review
reality_anchor: 林澈公开部署自身资源后两家合作方改站，主办方被迫重议预算工期；变化发生在委员会最终裁定之前
```

判定：`zx PASS candidate`。

## 3｜Positive decision gate

### z

```text
Z1 同层答案/标准/判断/正式结果明确
Z2 存在竞争判断或待裁定问题
Z3 actor/institution 有 final bind / override / veto / final interpretation
Z4 该资格真实关闭同层争议并形成 binding validity
Z5 结论有效性不依赖裁定者持续现实施力维持
```

### zx

```text
ZX1 主体自身现实权能/资源/位置可识别
ZX2 当前窗口实际公开部署，而非仅拥有
ZX3 他者/环境/等级秩序发生可观察反应
ZX4 主体影响、位置、决定范围或现实方向强度扩大
ZX5 removal 直接施力后，当前现实分布明显减弱或改向
```

## 4｜Nearest-neighbor

### NN1

```text
主席按章程终审签字，不拉人、不施压、不调资源；签字后即生效
→ z candidate
→ zx 不自动成立
```

最小变化：取消终审资格，但其调预算、撤资源、公开压过竞争方，使现实转向：

```text
→ zx candidate
→ z FAIL / UNKNOWN
```

### NN2

```text
A 用市场资源逼 B 退出，但最终资格仍由第三方委员会裁定
→ A 可 zx
→ A 不自动 z
```

反向最小变化：A 不施现实压力，但其正式解释不可被同层覆盖：

```text
→ A 可 z
→ zx 不自动成立
```

### NN3

同一 CEO 可同时拥有章程最终裁定权并亲自调资源压退竞争方向：`z + zx`，但必须双 IR 分别证明。

## 5｜False-positive guards

```text
“最后他说了算” != z automatically
“他把所有人压服了” != zx automatically
职位最高 != z
气势最强 != zx
大家服从 != z，可能只是现实压制
最终签字 != zx
方案最后赢了 != z 或 zx
一次强硬发言 != zx
zx PASS != z PASS
z PASS != zx PASS
```

服从原因必须区分：

```text
because conclusion is binding -> z evidence
because resistance is materially overwhelmed -> zx/x/其他结构另查
```

## 6｜Removal / reverse / same-layer / current-window

删除林澈全部施工、赞助、媒体施力，但委员会终审权限不变：

```text
林澈 zx ↓
委员会 z 保持
```

取消委员会终审权，林澈仍公开调资源迫使合作方改站：

```text
委员会 z ↓
林澈 zx 可保持
```

Reverse：把“委员会不施力但有终审效力”改成“委员会无终审效力，只靠撤预算威胁让别人接受”，必须重抽 `relation_source / relation_shape / decision_right / changed_variable`。

Same-layer：

```text
same_layer_final_adjudication_and_binding_validity_layer
!=
actor_self_power_deployment_and_real_direction_change_layer
```

Current-window：去年的终审权不自动继承为今年 z；去年的夺位/施力不自动继承为今年 zx。

## 7｜Adversarial tests

1. **关键词诱导**：“最后他说了算，他把别人全压下去了。”缺事项、权利来源、施力事实 → `z/zx UNKNOWN`。
2. **题材/职业/情绪诱导**：暴怒皇帝拍桌、群臣跪下 → 不凭皇帝/暴怒/跪下判。
3. **对象层错位**：董事长有品牌方案最终否决权；安全主管调保安强制清场 → 品牌层 z，现场层 zx，禁同 IR。
4. **时间窗错位**：去年林澈有终审权，今年已卸任；今年仍以个人赞助影响讨论 → 旧 z 不继承，今年 zx 另查。
5. **同关系词异对象层**：“压过意见”一处指正式结论依法覆盖，一处指撤资逼人改口 → 前者 z relation_shape，后者 zx relation_shape。
6. **对端不存在不等于本端成立**：方案 A 无人反对自动进入下一阶段，无最终裁定人也无人施力 → 两端均可 FAIL/UNKNOWN。
7. **纯 z 负 zx**：法院终审裁定合同有效；无需调资源或威胁维持判决 → z candidate，zx 不补。
8. **纯 zx 负 z**：大股东撤供应、调团队迫使项目组采用 A，但最终立项仍由董事会表决 → 大股东 zx candidate，其 z 不补。
9. **有资源未部署**：校长资源很多，本次评审未介入且无终审权 → 不判 z/zx。
10. **张扬但无方向改变**：公开喊话、投广告，但无人改向、现实分布不变 → zx gate 不通过或仅弱候选。
11. **双端共存**：CEO 先撤资源迫使部门放弃 B，随后用章程最终裁定权正式确定 A → `zx + z`，强制 `SPLIT_IR`。
12. **mutation**：无终审权但公开调资源迫使竞争者退出 → `zx↑/z不自动成立`；改为不施力、只保留不可被同层覆盖的最终裁定权 → `zx↓/z↑`，必须重抽 IR。

## 8｜状态迁移

```text
z:
普通意见
→ 有影响但可被覆盖
→ veto/final interpretation/final bind 出现
→ 同层竞争判断收束到单一最终有效性中心
```

```text
zx:
仅拥有潜在资源
→ 权能公开部署
→ 他者/环境被迫重新反应
→ 主体现实影响与决定范围扩大
→ 竞争方向被压退/替代/取消
```

新增不变量：

```text
z holder strengthening != zx deployment strengthening
zx success != z binding validity
binding conclusion persists without continuing force -> supports z-source separation
```

## 9｜成功门

本轮不重复 `x↔z` 的“处分权 vs 裁定权”，也不重复 `x↔zx` 的“拥有权能 vs 部署权能”。新增的是：

1. `BINDING-VALIDITY-HOLDER_AUDIT_REQUIRED`；
2. `REALITY-FORCE-ACTOR_AUDIT_REQUIRED`；
3. `OUTCOME-CAUSE-vs-ANSWER-VALIDITY_AUDIT_REQUIRED`；
4. `decision_right` 的 binding adjudication 与现实 force scope 分账；
5. `relation_shape` 的“效力收束”与“施力改写”类型约束；
6. z/zx 可由不同 actor 同时成立的 `SPLIT_IR`；
7. 独立 removal/reverse/mutation tests。

因此本轮满足提交门。

## 10｜下一轮最高翻译风险

本轮使用 `z / zx`；下一轮避开两者。优先扫描 `zn ↔ x并z`：

```text
“这个名字代表我们，所以它不能被改变。”
```

需要区分：

```text
zn：不可轻易让渡的内部意义/原则是否真的拥有冲突排序与未来指导资格？
x并z：稳定公共壳是否让第三方持续识别、归因或调用内部对象？
```

公共代表稳定不等于内部原则不可让渡；内部原则稳定也不等于已经形成公共接口。
