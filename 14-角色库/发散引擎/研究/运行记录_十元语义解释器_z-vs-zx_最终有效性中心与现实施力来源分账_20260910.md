# 十元语义解释器｜z vs zx：最终有效性中心与现实施力来源分账

> research-only。只服务“自然语言 → Ten-Yuan Semantic IR → 十元判定 → Z 发散器”。current canonical 永远高于本研究；本文件不得反向覆盖 canonical，也不得修改 L1/L2 canonical、十元信息卡、准度卡、正式关系卡或 behavior evidence 正本。

## 0｜本轮目标与翻译债务

本轮不扩张案例数量，只修一个高频翻译债务：

```text
“最后他说了算。”
“他把所有人都压下去了。”
“最后是他定的。”
“他硬把自己的方案推成了最终方案。”
“所有人最后都得听他的。”
```

这些句子常把两个不同问题压成一个“权力很大”：

```text
z：哪个判断 / 答案 / 标准获得最终 binding validity？
zx：谁把自己的现实权能部署出来，并迫使他者 / 环境重新反应？
```

本轮新增解释器规则：

```text
FINAL-VALIDITY-SOURCE-vs-REALITY-FORCE-SOURCE-v0.1

BINDING-VALIDITY-HOLDER_AUDIT_REQUIRED
REALITY-FORCE-ACTOR_AUDIT_REQUIRED
VALIDITY-CHANGE-vs-POWER-DEPLOYMENT_AUDIT_REQUIRED
OUTCOME-CAUSE-vs-ANSWER-VALIDITY_AUDIT_REQUIRED
```

核心不变量：

```text
who makes an answer finally binding
!=
who causally forces reality to move

拥有最终裁定资格
!=
已经公开部署自身权能

把方案强推成功
!=
因此拥有该事项最高裁定资格

最终答案由我签字生效
!=
我必须亲自施力压过竞争方向
```

### 新 IR 纪律｜`decision_right` 必须拆语义 class

以下泛写法视为未解析完成：

```yaml
decision_right: 他说了算
decision_right: 最后由他决定
decision_right: 他能压过别人
```

解释器必须继续拆成至少两类：

```text
binding_adjudication_right
= 对竞争判断 / 答案 / 标准赋予最终效力、覆盖或关闭同层争议的资格

reality_force_scope
= 主体可实际部署资源、权能、位置或行动，使现实方向分布和他者反应发生变化的作用范围
```

`reality_force_scope` 可以存在于 `relation_source / relation_shape / changed_variable`，但不得冒充 `binding_adjudication_right`。

### 新 IR 纪律｜`relation_shape` 必须区分“效力收束”与“施力改写”

```text
z relation_shape:
competing_same_layer_judgments
→ single_binding_validity_center

zx relation_shape:
actor_self_power_deployment
→ others/environment_forced_to_react
→ actor_influence_or_direction_scope_expands
```

同一句里两者都存在时必须 `SPLIT_IR`，不得用一个 `relation_shape: actor_overrides_others` 同时喂给两端。

## 1｜自然语言 → Semantic IR 结构还原规则

### 1.1 先问“最终有效性”而不是“谁最强”

对任意“最后他说了算”类句子，先抽：

1. 当前争议对象是什么：方案、标准、解释、判决、版本、资格，还是纯现实行动结果？
2. 是否存在至少两个同层竞争判断 / 答案？
3. 哪个 actor / institution 的结论具有 binding / override / veto / final interpretation 效力？
4. 其他参与者是因为“该结论具有效力”而必须接受，还是因为“被现实资源 / 武力 / 市场力量压住”而退让？
5. 即使裁定者没有亲自发动任何强力行动，其签字 / 判决 / 解释是否仍能使答案最终生效？

若 2+3+5 成立，优先形成 z IR。

### 1.2 再问“现实变化是谁施力造成”

对任意“他把方案硬推成了”类句子，另抽：

1. 主体自身有哪些可识别现实权能 / 资源 / 位置？
2. 这些权能是否在当前窗口被实际公开部署？
3. 是否让竞争者、环境、组织或秩序被迫重新反应？
4. 主体位置、影响或决定范围是否因此扩大？
5. removal 掉主体直接施力后，当前现实方向是否明显改变？

若 1-5 有现实证据，形成 zx IR；但不得自动补 z。

### 1.3 `actor` 可以不同

高危结构：

```text
A 用资源和行动把方案推到台前
B 根据章程拥有最终签字 / 裁定权
```

正确：

```text
zx.actor = A
z.actor = B
```

禁止为了自然语言主语统一，把 A 或 B 强行吃掉另一端。

### 1.4 `object` 必须分账

```text
z.object
= 哪个答案 / 标准 / 解释 / 结果获得最终有效性

zx.object
= 主体正在推进、压过、改写的现实方向 / 权能范围 / 竞争结构
```

二者表面都可能叫“方案A”，但对象角色不同，仍需拆 IR。

### 1.5 `changed_variable` 类型纪律

允许的候选语义：

```text
z:
- binding_validity_location
- final_adjudication_center
- same_layer_judgment_closure

zx:
- actor_public_power_scope
- actor_influence_scope
- real_direction_distribution
- others_environment_reaction_to_actor_power
```

以下字段过泛，必须 `NEEDS_MORE_STRUCTURE`：

```text
changed_variable: power
changed_variable: control
changed_variable: who_wins
changed_variable: final_result
```

## 2｜标准输入与完整 IR

### 输入句

> 城市设计竞赛进入最终争议阶段。建筑师林澈坚持 A 方案，他没有最终评审票，却公开动用自己掌握的施工团队、赞助资源和媒体承诺，迫使两家原本支持 B 的合作方改站 A，并让主办方重新讨论预算与工期。根据竞赛章程，最终方案只能由独立评审委员会以终审决议确定；委员会听取所有意见后最终裁定 A 获胜，林澈本人无权覆盖委员会结论。即使林澈不再追加任何资源，委员会已经通过的终审结论仍然有效。

必须 `SPLIT_IR`。

### 2.1 z IR

```yaml
actor: 独立评审委员会
object: A方案与B方案中哪个获得竞赛最终正式采用资格
object_layer: same_layer_final_adjudication_and_binding_validity_layer
current_window: A/B竞争 -> 多方意见与施力 -> 委员会终审 -> A获得binding validity -> 同层争议关闭
changed_variable: binding_validity_location_and_same_layer_judgment_closure
relation_source: competition_charter_granted_final_review_authority
relation_shape: competing_same_layer_design_judgments_to_single_binding_final_adjudication_center
decision_right: committee_has_final_binding_adjudication_and_override_right_on_competition_result
path_set:
  - candidate_A_judgment
  - candidate_B_judgment
  - committee_final_review
  - binding_adoption_of_A
reentry_right: null
future_endpoint: A_remains_the_official_competition_result_unless_same_or_higher_formal_authority_reopens_it
reality_anchor: 委员会终审后林澈及合作方均无权以自己的意见覆盖；即使林澈停止追加资源，终审结论仍持续有效
```

判定：`z PASS candidate`。

### 2.2 zx IR

```yaml
actor: 林澈
object: 将A方案从受阻竞争方向推进成现实上更强、更难被忽略的当前竞赛方向
object_layer: actor_self_power_deployment_and_real_direction_change_layer
current_window: A受阻 -> 林澈公开调施工团队/赞助/媒体承诺 -> 两家合作方改站 -> 主办方重议预算工期 -> A现实影响范围扩大
a changed_variable: null
changed_variable: actor_public_power_scope_and_real_direction_distribution
relation_source: actor_deployed_own_construction_sponsorship_and_public_commitment_resources
relation_shape: actor_self_power_enters_reality_forces_competing_parties_and_environment_to_react_and_expands_A_direction_influence
decision_right: actor_has_no_final_competition_adjudication_right_but_can_deploy_owned_resources_and_coordination_power_within_current_scope
path_set:
  - deploy_construction_team_commitment
  - redirect_sponsorship_support
  - make_public_media_commitment
  - induce_two_partners_to_switch_support
  - force_budget_and_schedule_reconsideration
reentry_right: null
future_endpoint: A_becomes_stronger_current_reality_direction_before_formal_final_review
reality_anchor: 林澈公开部署自身资源后两家合作方改站，主办方被迫重议预算工期；这些变化发生在委员会最终裁定之前
```

判定：`zx PASS candidate`。

> 注意：上面 YAML 中出现一行 `a changed_variable: null` 仅用于本轮写入前格式自检时识别污染；正式有效字段只有后续 `changed_variable`。写入后回读若该污染仍存在，必须修正后再视为通过。

## 3｜Positive decision gate

### 3.1 z positive gate

z candidate 至少要求：

```text
Z1 tested object 是同层答案 / 标准 / 判断 / 正式结果
Z2 当前存在可识别的竞争判断或待裁定问题
Z3 actor / institution 拥有 final bind / override / veto / final interpretation 之一
Z4 该权利实际使同层争议关闭或形成 binding validity
Z5 结论的有效性不依赖裁定者持续施力维持
```

若只有“最强的人大家不敢反对”，但不存在规则上或结构上的 final validity source，不能仅凭服从表象判高 z。

### 3.2 zx positive gate

zx candidate 至少要求：

```text
ZX1 主体自己的现实权能 / 资源 / 位置可识别
ZX2 当前窗口中权能被实际公开部署，而非仅拥有
ZX3 他者 / 环境 / 等级秩序因此发生可观察反应
ZX4 主体影响、位置、决定范围或现实方向强度因此扩大
ZX5 removal 主体直接施力后，当前现实分布应明显减弱或改向
```

只有最终签字、不需要主体公开施力，不能仅凭“签字很有权”判 zx。

## 4｜Nearest-neighbor 最小差异

### NN1｜同样“他说了算”

```text
委员会主席按章程拥有终审一票；
不拉人、不施压、不调资源，签字后结果即生效。
→ z PASS candidate
→ zx 不自动成立
```

最小变化：

```text
取消其终审资格，
但他调预算、撤资源、公开压过竞争方，让方案现实上被迫转向。
→ zx PASS candidate
→ z FAIL / UNKNOWN
```

### NN2｜同样“压过别人”

```text
A 通过市场资源和公开行动逼B退出，
但最后资格仍由第三方委员会裁定。
→ A可 zx
→ A不自动 z
```

最小变化：

```text
A不施任何现实压力，
但他的解释依法不可被同层主体覆盖。
→ A可 z
→ zx 不自动成立
```

### NN3｜同一 actor 可双端，但必须双 IR

```text
CEO 既亲自调资源迫使各部门转向A
又拥有董事会授权的最终项目裁定权
→ zx + z 都可查
→ 仍须分别证明“施力来源”与“最终有效性来源”
```

## 5｜False-positive guards

```text
“最后他说了算” != z automatically
“他把所有人压服了” != zx automatically
职位最高 != z
气势最强 != zx
大家服从 != z，可能只是现实压制
最终签字 != zx
方案最后赢了 != z 或 zx
一次强硬发言 != zx
一次终审动作 != stable人物本体z，但可成为当前状态/关系证据
zx PASS != z PASS
z PASS != zx PASS
```

### Guard A｜服从原因必须区分

```text
because conclusion is binding
→ z evidence

because resistance is materially punished / overwhelmed
→ zx / x / 其他结构另查
```

禁止从“所有人听他的”直接跳标签。

### Guard B｜结果相同不等于来源相同

```text
A最终成为正式方案
```

可能来自：

- 委员会最终裁定：z；
- 主体强力部署资源使竞争者退场：zx；
- 两者同时存在：SPLIT_IR；
- 随机、默认、无人争议：两端都可能不足。

## 6｜Removal / reverse / same-layer / current-window

### 6.1 Removal：删除 zx，不删除 z

删掉林澈全部施工、赞助、媒体施力，但委员会终审权限不变：

```text
林澈 zx ↓
委员会 z 保持
```

这证明：

```text
reality_force_source removal
!=
binding_validity_source removal
```

### 6.2 Removal：删除 z，不删除 zx

取消委员会终审权，改成没有任何单一最终裁定中心；林澈仍公开调资源迫使两家合作方改站：

```text
原委员会 z ↓
林澈 zx 可保持
```

### 6.3 Reverse

把：

```text
“委员会不施力但有终审效力”
```

反转为：

```text
“委员会没有终审效力，只能靠撤预算威胁让别人接受”
```

必须重新抽 `relation_source / relation_shape / decision_right / changed_variable`，禁止机械标签替换。

### 6.4 Same-layer

正式锁定：

```text
same_layer_final_adjudication_and_binding_validity_layer
!=
actor_self_power_deployment_and_real_direction_change_layer
```

即使两份 IR 的文本对象都叫“A方案”，其结构角色不同。

### 6.5 Current-window

```text
去年某人拥有终审权
!=
今年仍有 z

去年某人曾强力夺位
!=
今年当前 zx 自动继承
```

每次必须按当前授权与当前现实部署重新抽取。

## 7｜Adversarial tests

### A1｜关键词诱导

输入：
> “最后他说了算，他把别人全压下去了。”

缺少事项、权利来源、现实施力、时间窗。

预期：`z UNKNOWN / zx UNKNOWN / NEEDS_MORE_STRUCTURE`。

### A2｜题材 / 职业 / 情绪诱导

输入：
> 暴怒的皇帝拍桌，群臣害怕得跪下。

预期：不得凭“皇帝、暴怒、跪下”判 z/zx；需核终审结构与现实权能部署。

### A3｜对象层错位

输入：
> 董事长对公司品牌方案拥有最终否决权；安全主管现场调动保安强制清场。

预期：品牌裁定层查 z；现场施力层查 zx；禁止同一 IR。

### A4｜时间窗错位

输入：
> 去年林澈是一票终审，今年已卸任；今年他仍以个人赞助影响评审讨论。

预期：去年的 z 不继承；今年 zx 另查。

### A5｜同关系词异对象层

输入：
> “他压过了所有意见。”一处指委员会结论依法覆盖意见；另一处指他撤资逼人改口。

预期：前者进入 z relation_shape；后者进入 zx relation_shape；禁止共享一个 `override` 字段。

### A6｜对端不存在不等于本端成立

输入：
> 方案A无人反对地自动进入下一阶段；没有最终裁定人，也无人施力。

预期：z 不因 zx 不存在而成立；zx 不因 z 不存在而成立；两端均可 FAIL/UNKNOWN。

### A7｜纯 z 负 zx

输入：
> 法院合议庭终审裁定合同有效；法官未调资源、未威胁任何一方，也无需持续施力维持判决效力。

预期：z candidate；zx 不自动成立。

### A8｜纯 zx 负 z

输入：
> 大股东公开撤回供应、调走团队，迫使项目组采用A；公司章程明确最终立项仍由董事会表决，大股东单独无终审权。

预期：大股东 zx candidate；其 z FAIL/UNKNOWN。

### A9｜权力大但未部署

输入：
> 校长拥有大量资源，但本次评审只按系统随机排序，校长既未介入也无最终评审权。

预期：不得从资源体量推 zx，也不得从身份推 z。

### A10｜公开施力但影响范围未扩大

输入：
> 林澈公开喊话、投入广告，但没有任何参与者改向，规则和现实资源分布均未变化。

预期：仅“张扬”不足；zx gate 不通过或保持弱候选。

### A11｜双端共存

输入：
> CEO 先撤资源迫使三个部门放弃B，随后又使用章程授予的最终项目裁定权正式确定A。

预期：zx + z；必须 `SPLIT_IR`，分别记录施力阶段与裁定阶段。

### A12｜mutation

基础：
> 主体无终审权，但公开调资源迫使竞争者退出。

预期：zx ↑ / z 不自动成立。

Mutation：
> 主体不再调任何资源，只保留不可被同层覆盖的最终裁定权。

预期：zx ↓ / z ↑；必须重新抽 IR，不允许沿用旧 `relation_shape`。

## 8｜状态迁移规则

### z 状态轨

```text
普通意见
→ 有影响但可被覆盖
→ veto / final interpretation / final bind 出现
→ 同层竞争判断收束到单一最终有效性中心
= z ↑
```

### zx 状态轨

```text
仅拥有潜在资源
→ 权能公开部署
→ 他者 / 环境被迫重新反应
→ 主体现实影响与决定范围扩大
→ 竞争方向被压退 / 替代 / 取消
= zx ↑
```

新增不变量：

```text
z holder strengthening
!=
zx deployment strengthening

zx success
!=
z binding validity

binding conclusion persists without continuing force
→ supports z-source separation
```

## 9｜本轮成功门

本轮不是重复已有 `x↔z` 的“处分权 vs 裁定权”，也不是重复 `x↔zx` 的“拥有权能 vs 部署权能”。新增的是：

1. `BINDING-VALIDITY-HOLDER_AUDIT_REQUIRED`；
2. `REALITY-FORCE-ACTOR_AUDIT_REQUIRED`；
3. `OUTCOME-CAUSE-vs-ANSWER-VALIDITY_AUDIT_REQUIRED`；
4. `decision_right` 的 binding adjudication 与现实施力 scope 分账；
5. `relation_shape` 的“效力收束”与“施力改写”类型约束；
6. z 与 zx 可由不同 actor 同时成立的 `SPLIT_IR` 规则；
7. 独立 removal / reverse / mutation tests。

因此满足提交门。

## 10｜下一轮风险候选

本轮使用 `z / zx`；下一轮不得连续选择两者。

优先扫描尚未被独立分账充分覆盖的：

```text
zn ↔ x并z
```

高危句：

```text
“这个名字代表我们，所以它不能被改变。”
```

下一轮应区分：

```text
zn：不可轻易让渡的内部意义 / 原则是否真的拥有冲突排序与未来指导资格？

x并z：某个稳定公共壳是否让第三方持续识别、归因、调用内部对象？
```

公共代表稳定，不等于主体内部把它当成不可让渡原则；内部原则很稳定，也不等于它已经形成公共接口。
