# S级 Skill｜刘海98种五行十元分库 v1.0

## 最高口径

```text
五行就是十元。
五行不是五大主题名称。
```

固定身份：

```text
木：阳木zx ↔ 阴木nx
火：阳火zn ↔ 阴火x
土：阳土n ↔ 阴土x并z
金：阳金xn ↔ 阴金z
水：阳水xz ↔ 阴水nz
```

同行阴阳在同一对象层、同一核心变量上执行反向结构操作；共同成轴、相互规定。对立统一不自动等于严格互补、生克、共现或转化。

## 标准执行顺序

1. 读取原研究 Skill 与冻结备份。
2. 应用正式映射纠偏覆盖表。
3. 每项按主十元进入唯一十元位置。
4. 十元按固定阴阳身份进入唯一五行库。
5. 副十元只建立距离和交叉链接，不复制完整条目。
6. 更新总表、十元圆环 Canvas 与目标五行 Canvas。
7. 校验十元总数=98、五行总数=98、编号01–98无漏项无重复。
8. GitHub提交后回读验证。

## 十元距离

固定环序：

`zx → z → zn → nz → n → nx → xn → x → xz → x并z → zx`

最短环距离：

`d(a,b)=min(|i-j|,10-|i-j|)`

- d0：同十元
- d1：最近邻
- d2：次近邻
- d3–4：远邻
- d5：同行阴阳对径

距离仅表示L1语义空间位置，不直接证明生、克、补、互补或动态迁移。

## 当前正式数量

```text
木：zx6 + nx12 = 18
火：zn8 + x11 = 19
土：n21 + x并z12 = 33
金：xn11 + z7 = 18
水：xz9 + nz1 = 10
合计：98
```

分布不要求平均。禁止为了五库版面平衡修改理论映射或制造伪类型。

## 硬失败

出现以下任一情况，停止提交并标记待修复：

- 把五行写成时间、本体、空间、因果、命运；
- 把`z`与`zn`错误配成同一轴；
- 一个条目按主十元进入多个五行库；
- 未应用12项正式纠偏；
- 总数不等于98；
- 把环距离直接写成生克补关系；
- 删除或覆盖冻结研究资产。
