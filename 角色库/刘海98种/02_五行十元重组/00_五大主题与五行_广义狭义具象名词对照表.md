# 刘海98种｜五大主题与五行：广义、狭义、具象名词对照表

## 0｜最高区别

| 系统 | 回答的问题 | 广义层 | 狭义层 | 在刘海库中的用途 |
|---|---|---|---|---|
| 五大主题 | 一个对象、作品或结构最终在讨论什么高级问题 | 时间、本体、空间、因果、命运五种高级结构 | 现行基准十元构成；尚不宣称是唯一构成 | 作为高层主题、视觉叙事与设计意图标签，不能仅凭发型外观自动成立 |
| 五行 | 同一核心变量上，阴阳两端如何执行相反操作并共同成轴 | 木火土金水五条结构相反轴 | 十个十元的固定阴阳五行身份 | 作为98项刘海的基础十元分库与结构操作分类 |

**硬边界：**

```text
五大主题 ≠ 五行。
相同十元组合 ≠ 相同理论对象。
五大主题是高级问题结构；五行是十元的五组阴阳相反轴。
```

# 一｜五大主题表

## 1.1 广义、狭义与刘海具象名词

| 五大主题 | 广义定义 | 狭义基准十元构成 | 刘海领域具象名词 | 不得误判为主题的单一表象 |
|---|---|---|---|---|
| 时间 | 变化按先后、持续、积累、循环或阶段展开的进程结构；回答“怎样从之前走到之后” | `xn + z` | 生长阶段、眉上→齐眉→过眉、渐层、重复编织、等距卷度、分线刻度、截短节点、留长过程、过渡刘海 | 仅仅整齐、出现齐线、短发或复古年代感 |
| 本体 | 对象在变化、关系和表现中仍被识别为其自身的存在核心；回答“它究竟是什么” | `zn + x` | 原生发质、自来卷、自然发流、素发、胎毛、独立发束、明确轮廓、保留原有卷型、未经造型的质地 | 仅仅“自然感”“高级感”“露额”或模特气质真实 |
| 空间 | 对象如何被放置、容纳、分隔、并存并建立边界；回答“什么能在哪里存在” | `x并z + n` | 覆盖、包额、遮眼、脸框、侧束接入、层叠、内外层、发壳、宽度、分区、留白区、鬓角连接 | 仅仅头发很长、很厚、画面占比大 |
| 因果 | 前因如何经过作用链产生后果，使结果具有来源和可追溯性；回答“什么导致了什么” | `zx + nx` | 斜扫、外拨、推开、导向、让位、裂口、别耳、束起、剪切动作、造型操作、发束受力方向 | 仅仅有方向、有动作感、看起来干练 |
| 命运 | 多种可能如何收束为去向、归宿或不可逆结果；回答“最终走向哪里” | `xz + nz` | 风迹、碎散、退路收窄、遮挡加深、不可逆剪短、残留长束、回卷、内扣落点、回接、修复、生长后的归位 | 仅仅凌乱、波浪、忧郁、复古或“宿命感” |

## 1.2 五大主题的正确调用

```text
广义主题问题成立
→ 检查中心结构、阶段、转折和结果
→ 再用现行基准十元构成解释
→ 最后提取刘海领域的具象名词作为视觉证据
```

刘海具象名词只能帮助主题显影，不能反向单独证明主题。例如“齐线”可能是时间视觉词，但一张齐刘海图片本身并不自动拥有时间主题。

# 二｜五行表

## 2.1 广义相反轴、狭义十元与刘海具象名词

| 五行 | 广义核心变量与对立统一 | 狭义固定十元 | 阳端刘海具象名词 | 阴端刘海具象名词 |
|---|---|---|---|---|
| 木 | 最终方向与作用权从哪里产生：自身生成并占据方向 ↔ 不占最终方向、沿已有路线续接 | 阳木 `zx` ↔ 阴木 `nx` | 外翻、上挑、斜扫、拨开、锐向、主动分流、单向推进、发束改变周围轮廓 | 顺发流、沿分线、自然裂开、退入两侧、稀疏让位、贴合已有层次、沿既有路线垂落 |
| 火 | 对象能否作为自身独立成立 ↔ 被纳入某种归属、调用、调配或排除边界 | 阳火 `zn` ↔ 阴火 `x` | 原生卷、自然直、胎毛、独立卷束、保留自有纹理、未被统一造型、每束仍作为自己成立 | 硬边剪裁、统一轮廓、剃除、框定、划分内外、归入指定造型、被发胶或工具控制、拒绝混入 |
| 土 | 对象跨越内外边界的方向：外部进入内部并被承载 ↔ 内部映射到外部形成公共接口 | 阳土 `n` ↔ 阴土 `x并z` | 侧束接入主体、鬓角融合、脸框层承载、外部碎发收入发髻、层与层连续连接、包容多束 | 完整刘海面、遮眼层、厚片、发壳、头盔形、统一外轮廓、内部发量外化为可识别造型 |
| 金 | 运行权和裁定重心如何配置：分布到规则、步骤和节点 ↔ 收束到单一最高中心或最终裁定点 | 阳金 `xn` ↔ 阴金 `z` | 等距分线、重复编织、对称双束、规律卷径、层级顺序、多个剪切节点、流程化排列 | 中央尖点、唯一分线焦点、单一截点、中心束、最高点、最终短边、一个决定全局的视觉节点 |
| 水 | 可逆性与对象特异回返空间：退路持续收窄 ↔ 保存或恢复回返、修复和重新连接路径 | 阳水 `xz` ↔ 阴水 `nz` | 碎散、风吹偏移、渐失、乱波、遮挡加深、路径断裂、越来越难恢复原位、不可逆剪短 | 回卷、内扣、钩回、落点、回接鬓角、恢复分线、重新连接、保留可别回或可长回的路径 |

## 2.2 五行的正确调用

```text
锁定同一对象层
→ 锁定同一核心变量
→ 判断操作方向
→ 判定十元
→ 由十元固定身份进入五行阴阳端
```

同行阴阳既对立又统一，统一指“共同成轴、相互规定”，不自动等于严格互补、生克或转化。

# 三｜相同组合为何不是同一个东西

| 相同十元组合 | 作为五大主题时 | 作为五行时 |
|---|---|---|
| `zx + nx` | 因果的现行基准构成：解释前因如何作用并产生后果 | 木轴的阴阳两端：解释最终方向与作用权来源的相反操作 |
| `zn + x` | 本体的现行基准构成：解释变化中对象究竟是什么 | 火轴的阴阳两端：解释独立成立资格与归属方式 |
| `x并z + n` | 空间的现行基准构成：解释容纳、分隔、共处和位置边界 | 土轴的阴阳两端：解释内外边界穿越方向 |
| `xn + z` | 时间的现行基准构成：解释先后、阶段、持续和积累 | 金轴的阴阳两端：解释运行权分布与最高裁定集中 |
| `xz + nz` | 命运的现行基准构成：解释可能性如何走向归宿 | 水轴的阴阳两端：解释可逆空间收窄与回返路径保存 |

因此，公式外形相同，只说明两套系统调用了同一批十元点位；五大主题和五行的对象层、问题、判据和用途完全不同。

# 四｜刘海98种分库规则

## 4.1 五行主库

- 按正式纠偏后的**主十元**进入唯一五行阴阳端。
- 五行库是基础结构分库，98项必须且只能有一个主归属。
- 副十元用于交叉链接，不复制完整条目。

## 4.2 五大主题标签

- 五大主题不能按主十元机械分库。
- 只有当刘海设计确实承载相应高级问题时，才添加主题显影标签。
- 同一刘海可以没有明确主题，也可以在设计语境中出现主次主题。
- “十元组合碰巧对应主题公式”不等于主题已经成立。

## 4.3 具象名词层

每项刘海至少记录：

```yaml
五行主归属:
阴阳端:
主十元:
副十元:
具象结构名词: []
候选五大主题: []
主题显影等级: 0|1|2|3
主题证据:
```

具象名词是视觉检索词与证据词，不是新的理论层级，也不得替代广义定义和狭义映射。
