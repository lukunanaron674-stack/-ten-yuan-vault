## 最高分层边界

```text
五大主题 ≠ 五行。
五大主题是高级问题结构；五行是十元的五组阴阳相反轴。
相同十元组合不表示两个系统是同一个理论对象。
```

五大主题的现行基准构成：

- 时间：`xn + z`
- 本体：`zn + x`
- 空间：`x并z + n`
- 因果：`zx + nx`
- 命运：`xz + nz`

五行就是十元的五组阴阳对立统一轴：

- 木：阳木 `zx` ↔ 阴木 `nx`
- 火：阳火 `zn` ↔ 阴火 `x`
- 土：阳土 `n` ↔ 阴土 `x并z`
- 金：阳金 `xn` ↔ 阴金 `z`
- 水：阳水 `xz` ↔ 阴水 `nz`

两套系统虽然调用相同十元点位，但对象层、核心问题、判据和用途不同。广义定义、狭义十元映射和刘海具象名词统一见：`00_五大主题与五行_广义狭义具象名词对照表.md`。

同行阴阳在同一对象层、同一核心变量上执行反向操作；二者共同成轴、相互规定，但不自动等于严格互补、生克或转化。

## 十元圆环与距离

固定环序：

`zx → z → zn → nz → n → nx → xn → x → xz → x并z → zx`

最短环距离：`d(a,b)=min(|i-j|,10-|i-j|)`。

- 距离0：同十元
- 距离1：最近邻
- 距离2：次近邻
- 距离3–4：远邻
- 距离5：同行阴阳对径

距离只用于语义空间排布和查找近似项，不自动生成生、克、补。

## 归档原则

1. 每个刘海条目按正式纠偏后的主十元进入唯一十元库。
2. 十元库再归入唯一五行库。
3. 副十元只作为相近相远交叉链接，不复制完整条目。
4. 五大主题不能按主十元机械分库，只能作为高层显影标签。
5. 具象名词是视觉检索词和证据词，不得替代广义定义与狭义映射。
6. 原研究建库保持冻结，不静默改写。
7. 当前分库数量：木18、火19、土33、金18、水10，总计98。
