## 核心口径

五行就是十元的五组阴阳对立统一轴，不是五大主题名称：

- 木：阳木 `zx` ↔ 阴木 `nx`
- 火：阳火 `zn` ↔ 阴火 `x`
- 土：阳土 `n` ↔ 阴土 `x并z`
- 金：阳金 `xn` ↔ 阴金 `z`
- 水：阳水 `xz` ↔ 阴水 `nz`

同行阴阳在同一对象层、同一核心变量上执行反向操作；二者共同成轴、相互规定，但不自动等于严格互补、生克或转化。

## 十元圆环与距离

固定环序：

`zx → z → zn → nz → n → nx → xn → x → xz → x并z → zx`

最短环距离：`d(a,b)=min(|i-j|,10-|i-j|)`。

- 距离0：同十元
- 距离1：最近邻
- 距离2：次近邻
- 距离3–4：远邻
- 距离5：同行阴阳对径

距离只用于语义空间排布和查找近似项，不自动生成生、克、补。

## 归档原则

1. 每个刘海条目按正式纠偏后的主十元进入唯一十元库。
2. 十元库再归入唯一五行库。
3. 副十元只作为相近相远交叉链接，不复制完整条目。
4. 原研究建库保持冻结，不静默改写。
5. 当前分库数量：木18、火19、土33、金18、水10，总计98。
