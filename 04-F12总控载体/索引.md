# 04-F12总控载体｜索引

这里是 F12 自动化系统的文档区，不是实际运行代码目录。

它负责记录：

```text
自动化投料
payload 货架
7框任务
工单断点
回复完成检测
GitHub / Obsidian 回流
```

## 一句话定位

F12 总控载体不是中枢脑，而是一座自动渡口：

```text
把任务送进 ChatGPT 页面
把结果带回 GitHub / Obsidian
让断掉的长任务能继续
```

## 核心文档

- [[F12总控载体蓝图]]：总结构、总方向、功能边界。
- [[v0.1-投针]]：单次注入，把一个任务打进页面。
- [[v0.2-货架]]：payload 仓库，管理 7 框 × 多轮任务素材。
- [[v0.3-工单断点]]：任务卡、工单、checkpoint，解决中断续跑。

## 功能分块比喻

| 模块 | 比喻名 | 十元定位 | 作用 |
|---|---|---|---|
| v0.1 单次注入 | 投针 | zx+nx | 把代码 / payload 打进页面 |
| v0.2 payload 仓库 | 货架 | n+xn | 存放可复用任务 |
| 框位注册 | 门牌 | x并z+xn | 标记 7 个 ChatGPT 框是谁 |
| v0.3 工单 | 航海令 | xn | 管一批任务的顺序和状态 |
| 任务卡 | 船票 | n | 单个任务的身份和状态 |
| checkpoint | 锚点 | nx+n | 断了之后从哪里继续 |
| 页面完成检测 | 小狗灯 | nx | 看上一条是否生成完 |
| 回复收集 | 矿车 | n+nx | 把 7 框结果拖回来 |
| GitHub 回流 | 铁轨仓 | xn+n | 远程版本保存 |
| Obsidian 可视化 | 星图 | x并z+n | 把文档变成图谱 |
| 中枢整合 | 炼炉 | nx+zn | 把多框结果炼成游戏 / 理论结论 |
