# 影刀流程：重载 F12 扩展

动作名：`reload_f12_extension`

## 目标

解决 Codex 无法稳定点击 Edge 扩展页的问题。影刀负责机械点击，Codex 只检查结果。

## 录制步骤

1. 打开 Edge。
2. 地址栏输入：

```text
edge://extensions/
```

3. 等页面加载完成。
4. 搜索或定位：

```text
Ten Yuan F12 Controller
```

5. 点击该扩展卡片上的“重新加载”按钮。
6. 等 2 秒。
7. 写入：

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\04-F12总控载体\yingdao-bridge\outbox\result.json
```

成功结果：

```json
{
  "ok": true,
  "action": "reload_f12_extension",
  "status": "done",
  "message": "F12 extension reloaded.",
  "updatedAt": "当前时间",
  "error": null
}
```

失败结果：

```json
{
  "ok": false,
  "action": "reload_f12_extension",
  "status": "failed",
  "message": "F12 extension reload failed.",
  "updatedAt": "当前时间",
  "error": "失败原因"
}
```

## 验收

Codex 再运行：

```powershell
node C:\Users\19308\.codex\skills\ten-yuan-f12-operator\scripts\f12.js multi-script <tabId> <script.js>
```

如果返回真实脚本结果，而不是只返回 `script_executed content.js`，说明扩展已吃到新版后台。
