# 影刀应用：F12桥监听器怎么写

这个文件解决影刀触发器里的“请选择应用”。

影刀里的“应用”不是 Windows 软件，而是一个影刀自动化流程。  
你需要先新建一个应用流程，发布后，文件触发器才能选择它。

## 1. 新建应用

在影刀顶部点：

```text
应用 -> 新建
```

名称填：

```text
F12桥监听器
```

类型选普通应用 / 桌面自动化流程即可。

## 2. 第一版只做桥测试

先不要急着操作 ChatGPT。第一版只验证：

```text
command.json 被改动
-> 触发器启动这个应用
-> 应用能读到命令
-> 应用能写 result.json
```

## 3. 应用流程步骤

### 步骤 1：读取文本文件

文件路径：

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\04-F12总控载体\yingdao-bridge\inbox\command.json
```

保存到变量：

```text
commandText
```

### 步骤 2：JSON 解析

把 `commandText` 解析成 JSON。

保存到变量：

```text
command
```

需要用到字段：

```text
command.action
command.status
command.manifestPath
command.promptDir
command.imageDir
command.totalSheets
```

### 步骤 3：判断 status

条件：

```text
command.status != "RUN_NOW"
```

如果成立：

```text
结束流程
```

意思是：只有 Codex 写了 `RUN_NOW`，影刀才真正执行。

### 步骤 4：调试弹窗

先加一个弹窗或日志：

```text
收到 Codex 命令：${command.action}
```

如果影刀变量写法不一样，就直接显示 `commandText`。

这一步是为了确认桥接成功。

### 步骤 5：按 action 分支

第一版只处理这个：

```text
generate_chatgpt_contact_sheets_for_canvas
```

如果：

```text
command.action == "generate_chatgpt_contact_sheets_for_canvas"
```

先不要真的生图，先写一个测试结果文件。

写入文件：

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\04-F12总控载体\yingdao-bridge\outbox\minguo-contact-sheet-result.json
```

内容：

```json
{
  "ok": true,
  "action": "generate_chatgpt_contact_sheets_for_canvas",
  "stage": "bridge_test",
  "message": "影刀已经收到 Codex 命令",
  "completed": 0,
  "failed": 0,
  "error": null
}
```

### 步骤 6：写通用 result.json

写入文件：

```text

```

内容：

```json
{
  "ok": true,
  "action": "bridge_test",
  "message": "F12桥监听器已被文件触发器启动",
  "error": null
}
```

### 步骤 7：把 command.json 改回 idle

写入文件：

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\04-F12总控载体\yingdao-bridge\inbox\command.json
```

内容：

```json
{
  "action": "idle",
  "status": "idle",
  "updatedAt": "由影刀填写当前时间"
}
```

如果影刀不会填当前时间，可以先写固定文本：

```json
{
  "action": "idle",
  "status": "idle",
  "updatedAt": "yingdao"
}
```

## 4. 保存并发布

应用做好后，点：

```text
保存 -> 发布
```

然后回到：

```text
触发器 -> 文件触发器
```

在“应用”那里选择：

```text
F12桥监听器
```

## 5. 测试方式

让 Codex 写一次：

```json
{
  "action": "generate_chatgpt_contact_sheets_for_canvas",
  "status": "RUN_NOW"
}
```

如果成功，应该看到：

1. 影刀流程被自动启动
2. `outbox\result.json` 被写入
3. `command.json` 被改回 idle

这三条成立，桥就接上了。

## 6. 第二版再加真实动作

桥测试成功后，再把 `generate_chatgpt_contact_sheets_for_canvas` 分支替换成真实动作：

1. 读取 manifest
2. 逐个读取 promptPath
3. 切到 ChatGPT
4. 粘贴提示词
5. 等图生成
6. 保存图片到 imagePath
7. 写结果
