# DLT-MUS-012｜第十批：高银 × 关系撤除 / 桥变量筛选

## 0. 证据纪律
- 原始资料：`12_归档包/本体类音乐银矿归档_R1-R15_Obsidian.md`及库内旧分析卡。
- 评分口径：100分制；95+金矿、90–94高银、85–89银矿。四项为听感起手25、zn+x命中25、动态链30、复用20。
- 本轮未重新试听音频；不写时间码。体量1–10均为基于旧卡的结构显著性假设，不等于响度；关系强度1–10是若关系成立时对目标变量的改变幅度假设，不等于情绪强度。
- v2.22：几何位置锁定不等于机制/作品事件成立。普通箭头仅表示时间顺序。
- 正本本轮重点可调用：`XN克ZX`、`ZX↔NX补`、`ZX克N`、`XN生XZ`、`X并Z生Z`、`X生X并Z`、`X克Z`、`N克XZ`、`ZN↔X补`；其余只按运行时正本状态记录，证据不足即待验。

## 1. M83｜Weight of the World｜94/100 高银
- 原始：被制造者回收；旧链 `ZN → X → NZ → ZN`。
- 起：ZN8 / X3；承：ZN6 / X7；转：NZ8 / ZN4；合：ZN9 / NZ6。
- 时间图：`ZN8 → X7`；`NZ3→8 → ZN9`。箭头均先视为时序。
- 关系审核：`ZN↔X补`为正本锁定位置与机制，但旧卡没有“掌握用途方向/意义现实落点”桥变量，作品事件待验。候选强度5/10；主体ZN↔对象X。
- 因果/终点：旧资料支持“被制造者→回收主体”叙述，不足以证明NZ→ZN是生克补。终点ZN回升。
- 传播：P0；P1候选。

## 2. M84｜Non-Breath Oblige｜92/100 高银
- 原始：社会缺氧型；旧链 `NX → XN → ZN → X → ZN缺氧`。
- 起：NX8 / XN3；承：XN8 / NX6；转：ZN7 / X6；合：X7 / ZN3。
- 时间图：`NX8 → XN8 → ZN7`，支路 `X3→7`。
- 关系审核：旧链相邻边不能自动转成关系。`ZN↔X补`虽为锁定关系，但终点“ZN缺氧”更像补位失败/撤除候选，而非补位成功。候选强度6/10，作品事件待验。
- 桥变量候选：若X只保留现实边界而不能为ZN提供现实落点，则可作为“关系位置存在但功能未补上”的负控制。
- 传播：P0。

## 3. M85｜Hide and Seek｜92/100 高银
- 原始：声码器碎片化型；旧链 `X并Z → ZN → X → ZN裂开`。
- 起：X并Z8 / ZN3；承：ZN7 / X并Z6；转：X8 / ZN5；合：ZN3 / X7。
- 时间图：`X并Z8 → ZN7 → X8 → ZN3`。
- 关系审核：X并Z与ZN无当前直接固定边可据旧卡调用；`ZN↔X补`为锁定关系，但“裂开”意味着更值得测试关系撤除而非成功补位。候选强度6/10，主体/对象ZN↔X，作品证据待验。
- 终点：ZN裂开；P0。

## 4. M86｜Hurt｜91/100 高银
- 原始：自我审判型；旧链 `ZN → X腐蚀 → NX审判 → ZN空心`。
- 起：ZN8 / X3；承：X7 / ZN6；转：NX8 / ZN4；合：ZN2 / NX6。
- 时间图：`ZN8 → X7 → NX8 → ZN2`。
- 关系审核：`ZN↔X补`位置/机制锁定，但“X腐蚀”不能自动等于X补ZN或克ZN；X与ZN是补位关系，不是克。若现实掌握对象反而侵蚀意义，应记录为“补位未成立/功能反向”，不可伪造新克制边。
- 终点：ZN空心；P0，关系撤除负样本价值高。

## 5. M87｜ECHO｜91/100 高银

- 关系审核：`ZN↔X补`可测试，但旧资料只给破碎终点，没有明确“X给ZN现实落点”事件。候选关系强度5/10，待验。
- 终点：ZN破碎；P0。

## 6. M88｜Blackstar｜91/100 高银
- 原始：死亡仪式型；旧链 `ZN → X死亡 → X并Z仪式 → ZN′`。
- 起：ZN8 / X3；承：X8 / ZN5；转：X并Z8 / ZN4；合：ZN8′ / X并Z5。
- 时间图：`ZN8 → X8`；`X并Z3→8 → ZN8′`。
- 关系审核：`X生X并Z`为锁定关系，但必须先证明“实际掌握边界成立→需要公开可识别壳→壳形成”；旧卡的“死亡→仪式”不足。关系强度候选7/10，主体X→对象X并Z，作品事件待验。X并Z→ZN无固定直接边，不填。
- 终点：新ZN；P0/P1候选。

## 7. M89｜Duvet｜91/100 高银

## 8. M90｜Copycat｜91/100 高银

## 9. M91｜Cell Block Tango｜91/100 高银
- 原始：罪责舞台供述型；旧链 `ZX → NX → X → X并Z → ZN′`。
- 起：ZX8 / NX4；承：NX8 / ZX6；转：X8 / X并Z4；合：X并Z8 / ZN7′。

- 关系审核：`ZX↔NX补`与`X生X并Z`均为正本锁定关系。前者需证明“自身显权”与“借既有通道”真实互补，旧卡不足；后者需证明实际掌握边界生成公开壳，旧卡仍不足。候选强度分别5/10、7/10。
- P2候选：若ZX↔NX产生的行动结果形成X的实际掌握边界，随后X生X并Z，则存在桥变量；当前旧卡没有该桥证据。

- 终点：ZN困住；P0。

# 11. 本轮新增母型

## H67｜补位位置存在，但功能撤除
`ZN ↔ X`在几何上可补，但作品终点表现为ZN空心/裂开/困住。研究重点从“有没有两元”转为“缺口是否真的被补上”。M84/M85/M86/M90/M92构成一组强负控制候选。

## H68｜壳化生成候选
`X → X并Z`只有在“掌握边界→公开识别/调用需求→稳定壳形成”桥变量完整时才是生。M88可作为待验正候选。

## H69｜双合法边不等于P2
M91同时拥有`ZX↔NX`与`X→X并Z`两个正本合法关系位置，但只有前一关系的输出真正生成X的掌握边界，才可传播到后一关系。否则只是两条孤立合法边。

## H70｜高分零关系控制
M89 Duvet旧链变化丰富，但当前材料不能确认任何相邻固定关系事件。高动态感与高分不要求生克补密集。

# 12. 对黎黎隆的抽象迁移（不改角色本体）
固定：内部 `ZX主 / Z次 / XN微量`。外部世界XN可高，不等于黎黎隆内部XN升高。

本轮更值得测试的不是继续堆边，而是“关系撤除→新关系启动”：
```text
外部XN ─克→ ZX受限
   │
   └─生→ XZ风险上升
            │
            └─生→ ZX临时公开权能（需作品桥变量）
                     │
                     ├─若旧通道仍可借力：ZX ↔ NX补
                     └─若通道撤除：补位失败 → ZX必须独立承担决定
```
这里最后一支尤其适合黎黎隆：不是把NX硬加进人格，而是故事条件让“可借力通道”出现/撤除，从而改变固定ZX的行动方式。Z仍作为次属性保留，不因音乐样本而改写。
