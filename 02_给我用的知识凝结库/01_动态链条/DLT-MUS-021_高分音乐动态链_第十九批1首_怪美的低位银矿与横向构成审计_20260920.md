## 2. 本轮新增母型

### H99｜外层持续线 × 内层变量换位型
同一个外层属性可跨多个阶段持续在场，而内部高位属性依次换位：

```text
外层 A ───────────────────┐
   │                      │
   ↓                      │
内部 B → C → D            │
   └──────────────────────┘
              ↓
           终点 E′
```

价值：横向“构成线”不再只画同阶段并列，也可以画**跨阶段持续存在的背景/外壳轨**。它与生克补边必须视觉、文字上分开。

### H100｜合法关系反向出现 ≠ 关系成立
若正本锁定 `A 生 B`，作品旧链出现 `B → ... → A`，只能登记为“端点共现/反向时间位置”，不能倒推 `A生B`。M139再次提供负控制。

### H101｜终点换形不等于上一节点生成
`X → ZN′` 的时间相邻只说明旧卡认为主体随后换形。若正本没有 `X生ZN`，或没有作品桥变量证明补位机制，就不能把终点换形解释成前一节点“生成”。

## 3. 对黎黎隆的抽象时间构图迁移

角色本体继续冻结：**ZX主 / Z次 / XN微量**。本轮只迁移构图，不改配比、不把外部十元灌进角色本体。

可适配母型：**ZX主轨持续 × Z阶段夺位 × XN微量作为外部/背景组织条件**。

```text
【起】
ZX8 ───────────────────────┐
 │                         │  ZX主轨持续
 ↓                         │
【承】                      │
ZX7 ───── Z7               │
 │          │              │
 ↓          ↓              │
【转】                      │
ZX6 ───── Z9 ───── XN2     │
 │          │              │
 └──────┬───┘              │
        ↓                   │
【合】                      │
      ZX9 + Z6 + XN2 ◀─────┘
```

这里：
- 横向 `ZX—Z—XN` 只表示同阶段构成，不是关系边；
- 纵向表示时间；
- 只有后续故事/音乐证据出现明确端点与桥变量，才把某条横线升级为“生/克/补”；
- 这个构图特别适合黎黎隆“ZX一直是主驱动，但Z会在中段短暂夺取操作层”的角色节奏，同时不需要把Z误写成固定的追查/理解功能。
