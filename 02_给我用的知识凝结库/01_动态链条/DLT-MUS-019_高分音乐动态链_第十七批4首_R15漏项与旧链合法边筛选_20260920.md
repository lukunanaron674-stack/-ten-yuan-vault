## 2. M134｜Hibana｜89/100 银矿

### 原始资料
- R15历史类型：**火花证明过载型**。
- 原链：`x → zn → xn → x并z → zn过载`。
- R15二审警告：防止普通高速燃曲误判。
- 仓库未检出更细的独立原卡；因此“原有主次十元”除链条显著性外不擅自补造。按旧链暂记：主候选 x / zn；次候选 xn / x并z，**分析假设，不是原卡明示字段**。

### 起承转合｜横竖混合时间构图
```text
起  x7 ───────→ 承  zn6
                    │
                    ▼
                 xn7 ───────→ 转  x并z7
                                  │
                                  ▼
                              合  zn8（过载）
```
阶段体量是假设：起 x7；承 zn6 + xn7；转 x并z7 + zn6；合 zn8（过载态）+ x5。

### 生克补审计
- `x → zn`：正本中 x 与 zn 为**补位组**，不是“x生zn”。旧链只有先后，补位功能未证明，关系留空。
- `zn → xn`：位置表中是 `zn克xn` 的几何方向，但本轮没有“zn如何降低xn组织/持续运行变量”的作品证据，待验，强度留空。
- `xn → x并z`：不是v2.22已锁定的相邻关系事件；普通箭头。
- `x并z → zn过载`：不是已锁定的直接关系事件；终点变化不能反推关系。

### 终点
`zn过载` 是旧资料终点描述；为什么过载、由谁作用、改变了什么桥变量，当前资料不足。

## 3. M135｜Rebirth｜89/100 银矿

```text

            │
            ▼
承        x并z8 ──────→ 转 nx7
                           │
                           ▼

```

### 生克补审计

### 终点

## 4. M136｜Karma Police｜89/100 银矿

### 原始资料
- R13/R15历史类型：**审判回流崩散型**。
- 原链：`nx → zn → x → xn → zn崩散`。
- 二审结果：89保留，理由为“审判回流成立”。
- 未检出独立“主/次十元”字段；按旧链显著性暂记主候选 nx / zn，次候选 x / xn，属于分析假设。

### 起承转合
```text
起 nx7 ───→ zn6
             │
             ▼
承          x7 ─────→ 转 xn7
                          │
                          ▼
                      合 zn8（崩散）
```
阶段体量：起 nx7；承 zn6 + x7；转 xn7 + zn5；合 zn8（崩散态）+ xn4。

### 生克补审计
- `nx → zn`：正本位置表不是可直接据旧箭头登记的关系事件。
- `zn → x`：两者为补位组；必须证明“意义给掌握用途方向 / 掌握给意义现实落点”的缺口被填。旧链无此证据，留空。
- `x → xn`：普通时序，不关系化。
- `xn → zn崩散`：正本几何为 `zn克xn`，方向相反；不能因zn最终崩散就倒推 `xn克zn`。

### 终点
`zn崩散` 保留为旧卡终点。审判回流是结构描述，不自动等于某一克关系。

## 5. M137｜人柱アリス｜86/100 银矿

- R15历史类型：**童话故事吞主体型**。
- 原链：`x并z → zn → x → xz → zn被吞`。
- 独立旧分析明确写“主要十元：x并z → zn → x → xz → zn被吞”；旧解释为童话包装→存在→欲望撕裂→边界→消失。
- R15二审警告：防止叙事歌词强于声音结构。

### 起承转合
```text
起 x并z8 ─────→ zn6
                 │
                 ▼
承              x7 ─────→ 转 xz8
                              │
                              ▼
                          合 zn9（被吞）
```
阶段体量：起 x并z8；承 zn6 + x7；转 xz8 + zn5；合 zn9（被吞态）+ x并z5。

### 生克补审计
- `x并z → zn`：普通结构顺序；不能由“包装中出现主体”推关系。
- `zn → x`：补位几何存在，但旧解释“被欲望撕裂”反而不证明补位成功；标**位置存在、作品补位未验**。
- `x → xz`：无可直接调用的已锁定关系事件；普通时序。
- `xz → zn被吞`：位置表为 `xz克zn` 的几何方向，但本轮没有读取到 canonical-current 的 xz克zn 机制正文，且作品端只有叙事概括；故**机制/作品证据未验收**，强度留空。

### 终点
`zn被吞` 是旧分析终点。歌词/童话叙事污染风险较高，因此不能拿“人柱/吞噬”字面当克关系证据。

## 6. 本轮新增母型

### H92｜“旧链命中合法几何边”不等于P1
```text
旧链 A → B
      │
      ├─ 正本位置合法
      │
      └─ 但缺 canonical 机制正文 / 作品桥变量
             ↓
           仍为 P0
```
样本：M135 `x并z→nx`、M137 `xz→zn`。

### H93｜“终点受损”不能反向制造克
```text
A → B → C → zn崩散
              ↑
不能因此把最后一个相邻元 C 自动写成“克zn”
```
样本：M134、M136、M137。

### H94｜补位组可以作为失败/缺口观测，而非强行登记补
M134/M136/M137 都出现 `zn` 与 `x`，但当前材料没有证明两端互相填补缺口。后续盲测应允许：
- 补成立；
- 补位位置存在但失败；
- 两元仅共现；
- 无法判断。

### H95｜高分音乐的“强结构变化”与“可验生克补”应分榜
本轮4首历史均为86–89银矿，动态链结构清楚，但**可靠P1=0**。这继续支持：音乐构图质量榜与关系机制可信度榜必须分开。

外部XN可以作为世界结构很高，但不等于黎黎隆内部XN上升。
