# DLT-MUS-002｜第二批：8首高分音乐 + 2首对照；八种时间构图与ZX迁移

## 口径
本批仅从仓库已存在的评分和分析卡抽取结构，**没有回听音轨、不能标注新的精确音乐秒数或冒称听觉验证**。旧卡的「A→B」只表示分析者按时间理解的主题阶段，不自动等于现行十元正本的「A生/克/补B」。标为3/3的是另一套结构性金矿标准，不能擅自换算成百分制。歌曲评分不是故事动态链评分。为防止题材、歌词、演出语境污染，以下每项都单列「可迁移时间拓扑」而不将旧卡比喻作为正式生克机制。

## 8首高分

### M09 Neighbormind｜旧z矿97/100
旧链：Z → XZ → ZX → X → ZN。旧卡认为双主体Z交替，先蓄力再边界对抗，进而推进，代价阶段后回到意义。
时间拓扑：双主体错位进入 → 对抗形成共同动作 → 行动代价同时作用两端 → 收束到第三个共享结果。
单元：**双主动主体彼此抬高、后汇合**。不是「两条线平行出现」；双主体必须改变彼此行动条件。
故事迁移：黎黎隆ZX仍主导；另一个主体有自己的主动位置，不能将主角本体改Z。

### M10 秒針を咬む｜旧z矿95/100
旧链：Z → XZ → Z → X → N（尾段留白标问号）。
时间拓扑：强起手 → 第一次碰壁 → 同一主体回冲 → 行动越界/代价 → 悬置而非完满互补。
单元：**回冲变质**；第二次行动对象或条件要与第一次不同，否则只有音量升级。

### M11 ハナミズキ｜旧nz矿3/3
旧链：NZ → XZ → NZ（强化/加深）。
时间拓扑：低压稳定态 → 有限的失去/错过风险介入 → 回到原属性但等候条件已经改变。
单元：**小幅克压+同元异态回收**，不必有双大克/三大克，且结尾悬置。
注意：现行十元表XZ↔NZ为补位，旧音乐卡XZ阶段不能自动被标记成「XZ克NZ」。

### M12 How to Disappear Completely｜旧xz矿3/3
旧链：XZ → ZN → XZ（状态已变化）。
时间拓扑：主体撤离/临界起手 → 中段短暂确认/显形 → 原属性回归，但此前显形已留下结果。
单元：**中途显形→外观同初始、内部状态不同**；重复主题并非原地踏步。
注意：卡片将弦乐进入解释为被看见属旧主观分析，无独立音轨复审。

### M13 No Surprises｜旧xz矿3/3
旧链：X → XZ → N。
时间拓扑：压迫蓄积 → 临界阈值 → 低动态落地收束（非强化主属性）。
单元：**减法高潮**；情绪/音响强度并非高潮必须上升；N的静止与承担是否真成立需具象验证。
对照：M10尾段N悬置，M13尾段N收束，同符号不同功能。

### M14 Forbidden Colours｜旧xn矿3/3
旧链：XN → NZ → XZ → XN（规则仍在，但被触碰）。
时间拓扑：稳定约束 → 另一关系进入 → 有限窗口/临界选择 → 回到未被推翻的约束。
单元：**限制不消失的带伤回环**；主角不必打败外部XN才能实现变化。
注意：这不是「XN克NZ」之类的固定关系断言。

### M15 Fitter Happier｜旧xn矿3/3；本体归档94/100（不同口径）
旧链：XN → X并Z → ZN → X → ZN消失。另一旧三角分析涉及XN框定ZX与ZN检验XN。
时间拓扑：系统逐步纳入对象 → 正向外壳掩盖对主体的替代 → 后段主体原有资格失去 → 未回收。
单元：**低动作强度的持续收编→负向收束**；大克不必呈现为更大的外部暴力。
关系注意：旧卡「XN吸收ZX」属事件机制描述，不擅自创造第4种固定关系种类。

### M16 アイドル｜旧x并z矿3/3
旧链：X并Z → ZN → X → ZN空心。
时间拓扑：外部形象先行 → 内部主体被检验 → 运作越成功越改变主体条件 → 外壳保留但主题空心。
单元：**成功反噬/外壳未坏而内核变质**。
关系注意：不要把所有公开身份或可爱装束默认为X并Z生克关系。

## 两个低对照组（仅用于结构对照，非贬低音乐）
C01 火炎｜旧z矿91/100（高银）：Z → X并Z → Z保持。卡片理由：主属性辨识度高，但中段未造成可观察的阶段变化。对照M10「Z→XZ→Z→X→N」，检验回冲有没有改变路径。
C02 Metamorphosis One｜旧xn矿2.5/3（高银边缘）：XN持续运行，首尾状态相似。对照M14「XN→NZ→XZ→XN」，检验外部条件插入是否改变最后XN作用范围。静态循环并非音乐创作失败，只是在以“动态故事生成”为目的时可迁移转折较少。

## 抽象时间构图母型（本批相对第一批新增或细分）
H07 双主体错位→互相改变→共同结果（M09）
H08 克→同主体再行动→行动代价→悬置收束（M10）
H09 稳态→有限风险→同元异态回收；低强度也可有结果（M11）
H10 临界→被看见→回到临界，但条件改变（M12）
H11 压迫→临界→减法高潮（M13）
H12 稳定约束→另一关系检验→临界→原约束带伤继续（M14）
H13 无显性爆发的渐进收编→原主体被替代（M15）
H14 外壳越成功→内部主题越空心（M16）

## 角色ZX主/Z次/XN微量：迁移成“待具象校验”的四个实验
- E1 双主体改变：外部XN克ZX→NX补ZX提供另一行动通道→黎黎隆ZX与外部主体共同改变同一个变量；不能声称NX一定善良或替她承担代价。
- E2 带伤回环：XN克ZX→XZ生ZX（**仅当真实危险造成本来没有的公开最终决定空位，且有人接续执行时成立**）→XN仍存在→ZX在有限窗口作出新的主导选择。内部微量XN不与外部XN合并。
- E3 渐进收编：外部XN克ZX不是直接关掉行动，而是逐步限定它的时间窗、路线和可执行范围→Z与XN的补位若满足认可/组织条件可改变侧支，但不默认解除克ZX→ZX最终选择需要改变一种不可继续的旧条件。
- E4 减法高潮：外部XN克ZX→NX补ZX建立非正面路径→ZX主动撤回对原目标的一部分控制（**这是角色ZX的决定，并非将自身本体改成NX/NZ**）→新关系不一定补位结局。
这些实验都还没有做逐边的场景机制证明；目标是结构发散，不是预先宣布适合8分钟动画。

## 研究发现与反证
1. 旧库的高分结构不全是「双克→双生→三克→互补」；回环、悬置、替代、减法高潮都出现过。
2. **同符号回归**要区分新条件/代价是否留下；删除中段后终点若不变，则动态不足。
3. **双线并行**要检验双方是否通过同一变量相互影响；没有交汇只是一对并列歌曲。
4. 旧评分同时含十元命中、表演辨识、歌词/语境、结构纯度等，不可从高分反推对应时间构图具有普适故事优越性。
5. 用M10对照C01，用M14对照C02，下一步在不换主十元与外部关系组的条件下做顺序与作用强度消融；声音证据需要回听或带时间码音频资料核查。
