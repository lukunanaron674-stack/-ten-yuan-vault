# DLT-MUS-001｜高分音乐拆成动态链：第一批8首 + 对照1首

## 审核口径
- 分数照抄已有归档，不重新评分。本体音乐R1-R15归档的95+分数与另一套金矿总表的3/3属于不同口径。原始歌曲卡95分（如Ado/Da-iCE）与另一主题仓的重评（Ado 87）并存，不能隐去。
- 下文【→】仅代表旧分析阶段时序，不等于固定的十元「生」；【生/克/补】仅在查正本并达到机制条件时成立。
- 以下是**旧分析卡的二次结构抽取**，不是已经独立播放全曲、量出时间码、用音频盲测验证。不得将音乐的评分直接转称故事构图的分数。
- 角色的十元主ZX/次Z/微量XN固定，音乐中某首主ZN/XN/XZ，不等于角色自身变成ZN/XN/XZ。故事迁移只移植时间拓扑和相应合法关系，不移植人物本体。

## A. 八首高分样本

### MUS-01｜Ludwig, the Holy Blade｜98（本体音乐金矿归档）
旧链：XZ → X → ZN → N → ZN；《zx-金矿5首》还列为3/3“ZX执行过程中身份变化”。
时间构图：起（原有状态被临界/失稳主导）→承（单向运动增强，却未确认自身方向）→转（原有身份/意义重新进入）→合（经由承载落地）→末（回到ZN，但主体状态已变）。
叙事零件：**中段换芯 + 首尾同符号异状态**。音乐归类为ZX金矿不等于主角色ZX必须起手。不得仅凭OST所属游戏剧情声称乐曲单独证明十元关系。
迁移条件：为ZX人物保留原行动目标，但让它在中段被重新定义，结果不能只是强度升级。

### MUS-02｜The Great Gig in the Sky｜98
旧链：XZ → ZN → X → N → ZN。
时间构图：起（临界压迫）→承（主体表达浮现）→转（存在边界遭到具体限制/冲击）→后（原本无法表达的部分被承接）→合（回到ZN）。
叙事零件：**由压迫进入表达，经历边界，再由外部承接回流**。归档强调“无词人声”，说明旧分析不是只从歌词挖意义；但各次十元跳转尚非逐边正式关系判例。
迁移条件：若用于ZX线，只抽“被压→显形→回流”时间关系；不把ZG/ZN直接改称ZX。

### MUS-03｜O Superman｜97
旧链：XN → ZN → X → X并Z → ZN被替代。
时间构图：起（稳定外部结构占位）→承（主体意义试图进入）→转（掌握边界成为必要关口）→再转（公开壳/机器媒介代替原有表达）→合（没有回到原来的主体，而是主体被替代）。
叙事零件：**不可逆的替代结尾 / 成功的外部结构，失败的主体回流**。不是所有好作品都需要“互补结局”。
关系注意：XN→ZN等原卡箭头为阶段标签，不自动判为XN生ZN。

### MUS-04｜Answers｜97
旧链：ZN → X → NX → N → ZN。
时间构图：起（原有意义）→承（现实掌握与边界成为冲突场）→转（行动位置或责任发生变更）→后（新的承载得以运行）→合（原有ZN主题重新确认）。
叙事零件：**主体意义→代价/让位→承载→主题回收**。
关系注意：NX被称为“代偿”的旧判不等于现行正本中NX的固定语义，正式迁移应按当前关系卡重判。

### MUS-05｜Unknown Mother Goose｜96
旧链：ZN → X → XN → NX → ZN。
时间构图：起（意义先成立）→承（意义进入现实边界）→转（持续规则/组织形成压力）→后（主体通过其他关系或通道推进）→合（再回ZN）。
叙事零件：**起手主题→两级不同性质的限制→间接路径→同主题异状态回收**。
生克审核：XN→NX等时序关系不能直接称克或生。

### MUS-06｜ODDS&ENDS｜96
旧链：ZN → X → XN → NZ → ZN。
时间构图：起（主体意义）→承（具体掌握关系介入）→转（重复流程/持续结构介入）→后（缓慢联系/关系余温重新显现）→合（ZN回收）。
叙事零件：**中段持续规则与尾段关系余温对照，末端复归原主题**。与MUS-05的区别：二者前段相似，倒数第二段不同：NX vs NZ，最终意义的回流条件不同。替换测试适合验证“补位路径是否可互换”。

### MUS-07｜うっせぇわ（Ado）｜用户原歌曲卡95；另一主题仓评分87
原始用户卡：ZX起手，XN/N/XZ随后出现，以XZ为主题；旧判“N克XZ→XN生XZ→XZ生ZX→XZ爆发”。旧卡内部的具体边需按现行关系正本复核；现行正本：N克XZ、XN生XZ、XZ生ZX的几何位置存在，分别成立还要满足机制条件。
时间构图：起（ZX强势露面）→揭示（N对XZ的持续克制是深层条件）→承（XN推动XZ临界积累）→转（XZ生成临时ZX决断的条件）→合（XZ释放/回流）。
叙事零件：**表面起手≠深层驱动；前段克制持续积累，后段才显性释放**。
注意：本体音乐归档的Usseewa 87是不同矿区审稿，95与87不可合成一个“客观评分”。

### MUS-08｜ハイボールブギ（Da-iCE）｜用户原歌曲卡95
旧用户卡：Z/Z/XZ/ZX/N多方向，ZN主题；“三角克制→ZX/ZN/N嫁接，旧克制暂时失效→XZ压住ZN”。
时间构图：起（多方交错，中心主题尚未主导）→承（新的生发/搭桥使原有克制链断开）→转（中心主题短暂获得空位）→合（另一条支路回头收束中心，**末段为克制而非互补**）。
叙事零件：**三角克 + 中段断链 + 延迟收束**，可用作时间拓扑，不应将原卡每个“z克zn”“xz压zn”等措辞直接升级为已锁十元克边。

## B. 一首高银对照

### MUS-09｜Fitter Happier（Radiohead）｜本体归档94
旧链：XN → X并Z → ZN → X → ZN消失。另一旧三角专题表示XN持续规定ZX的行动条件、ZN追问XN的意义。
时间构图：持续规则起手→身份表面/主体关系被归入规则→另一关系提供检验→没有真正恢复，末端主体失去原状。
叙事零件：**规则收编主动性，不靠直接强压也能让主角失去原行动空间**。
注意：旧卡有“吸收ZX”比“克ZX”更细的描述，现行固定XN克ZX需单独核验受限变量，不能把“吸收”作新关系类型。

## C. 从高分音乐真正提取出的时间构图

- H1 受压→显形→回流（MUS-02）
- H2 中段换芯→首尾同元异状态（MUS-01/MUS-05）
- H3 强规则起手→主体被替代，**无补结尾**（MUS-03/MUS-09）
- H4 两级限制→外路介入→主题回收（MUS-05/MUS-06）
- H5 表层主动起手→深层克制延迟揭示→临界释放（MUS-07）
- H6 三角交错→中段断链→延迟克制收束（MUS-08）

比较优先做同边不同时间/强度的对照；不要把每首歌曲的顺序标签自动改写为“生克补已经成立”，更不要用归档分数证明故事一定好看。

## D. 后续检验
逐首回听并按真实录音标记时间码、音乐事件（音型/人声/音区/节奏/密度/暂停/主题再现）、结构变化，做删段测试。旧评分表只能辅助挑选，不能充当听觉实测。再用现行正本逐边核验，并仅把时间构图迁移至角色固定的ZX主/Z次/XN微量上。
