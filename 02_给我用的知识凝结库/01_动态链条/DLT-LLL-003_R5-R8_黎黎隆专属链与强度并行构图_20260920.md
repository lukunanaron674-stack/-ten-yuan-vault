# DLT-LLL-003｜R5–R8 剩余轮次：ZX专属链、双线构图、角色反事实、冻结创作语法

## 0｜边界和重要纠错
1. **固定人物**：ZX主、Z次、XN微量，三个是角色本体/设定；局部行动受压不改变本体。外部XN必须另给对象ID。ZX指主体公开显权、实际改变他人执行或决定结构，不等于所有行动/好胜；Z指重要认可主体对目标完成明确确认，不是普通聪明、侦察或随机信息；内部XN是角色的主动跨时间组织，不是「记住一次失败」就算。
2. **使用现行关系表**：外部XN克ZX；XZ生ZX（条件严格，真实XZ触发后有决定空位、连续决定被他者执行，不能当作「危险提升战力」）；NX↔补↔ZX；ZX克N；ZX生ZN（表有位置但生成机制未锁）；X克Z；X并Z生Z；Z↔补↔XN；ZN克XN；N克XZ。
3. 先前口头例子“ZN生ZX”“NZ生Z”“XN克Z”不在现行表对应位置，**不得当已合法边**。旧音乐三角「XN克ZX → ZX生ZN* → ZN克XN」仅研究时序拓扑，*边research-active。
4. **关系事件、阶段与体量分账**：「双克」可指两条不同克边或同一边二次激活，应分别记录。K3=N克XZ是克**生源**，不等于第三条直接克ZX。一次生源减弱不自动撤销以前的ZX状态。互补不是「克制关系变成相补」，应引入已有的合法NX↔ZX、Z↔XN端点并说明缺口。
5. 本文件仅完成逻辑穷举后的创作结构对照与纸面反事实，不报告不存在的观众盲测、作品效果、角色真实十元测量，也不修改正本/旧Evaluator冻结版。

## R5｜ZX主线：同边改变作用顺序、压力与补位

代号：K=外部XN克主角ZX；S=XZ生主角ZX（独立真实触发及临时决定接口）；B=NX补主角ZX（非正面权限/借力通道）；G=ZN克外部XN（ZN独立成立或来自待验ZX生ZN）；L=ZX克外部N（必须导致实际承载功能下降）。强度记作某一次边对具体changed_variable造成的影响程度，1–10是创作旋钮，不是固定十元体量或故事分数。

| 编号 | 时间/拓扑 | 核心变化 | 结构门禁 |
|---|---|---|---|
| ZX-51 先克后补 | K(中) → B(中) → ZX沿新增路径二次显权 | 克仍存在，解决的是ZX缺乏非正面路径 | 拿掉NX后确实丢失该路径 |
| ZX-52 先补后克 | B(中) → K(强) → ZX保留部分路径而重新选择 | 先有补位资产，后受限，不等于补位被直接克掉 | 明确K压的是ZX哪一个决定范围 |
| ZX-53 先生后重克 | S(中) → K(强) → B(中) | 新生临时公开决定接口迅速进入既有长期结构 | XZ生ZX的触发、决定空位及他者执行成立 |
| ZX-54 先克后生后截源 | K(中) → S(中) → N克同一XZ源 → B(中) | 新生通道的持续来源失效，既有ZX临时成果保留/回落须逐项证明 | N真接住风险，不是封路或单纯压制 |
| ZX-55 克制方受克 | K(中) ∥ G(中) → ZX重新行动 | 另一端取消维护XN的资格，不等于一击摧毁已积累结构 | ZN独立成立，源端主体明确，XN维持资格确实下降 |
| ZX-56 先补克制方 | K(中) → Z补XN(中) → K作用对象/重点变化 → B | 补可能增强XN的聚焦，形成压力递进而非「补了就赢」 | Z有真实认可主体/对象；XN有实际跨时间组织 |
| ZX-57 主动反向回环 | ZX克N → N生XN的持续条件变化 → 已有XN克ZX → B | 主角的行动影响已有外部结构的继续生成，不等于受克的N凭空生出更多XN | N此前真实承载且对应XN组织主动性可证 |
| ZX-58 三角候选隔离 | K → ZX生ZN* → G → ZX行动条件改变 | 旧音乐三角可保留时间语法 | *未锁，不得计入「全部合法实链」 |

**强度受控对照：**以ZX-54为固定拓扑，只变强度，不改对象和关系方向：
- a「压小/生中/截源强/补中」K=3,S=6,N克XZ=9,B=6：前段可以有短暂成果；后段不自动清零，而要追问新增通道能否继续发挥作用。
- b「压强/生小/截源中/补强」K=9,S=3,N克XZ=6,B=9：主角第一次生发未必打开目标路径，结尾需具体NX缺口与授权渠道，否则只是补量空喊。
- c「压强/生强/截源小/补弱」K=9,S=9,N克XZ=3,B=3：即使生发充分，能否越过XN仍取决于不同变量；低补不天然构成高潮。
上述强弱值是创作参数，并非推导出真实成功率或效果。真正的自变量包括：作用时间窗、被改变变量、持续/累积、可逆性与剩余路径数；不允许用一个纯强度数字取代机制。

## R6｜ZX+Z双线：横纵混合的四个母型

采用两条已锁边：主线K1=外部XN克ZX，S1=XZ生ZX；次线K2=外部X克Z，S2=X并Z生Z；追加主线生源追击K3=N克同一XZ。Z不等于「发现线索」，须有明确认可主体/对象/认可内容；双线汇合只能通过共同的目标变量/角色实际可执行的新路径成立。

| 编号 | 图形/时间骨架 | 生克压量特征 | 汇合条件 |
|---|---|---|---|
| DZ-61 集中压扬压 | 【起】K1∥K2 →【承】S1∥S2 →【转】K1持续+K2持续+K3新触发 →【选择】ZX决定 →【合】NX补ZX | 双克/双生/三条当前有效克制；**K1 K2持续不算新增两条关系** | 次线Z的认可结果进入最终可执行路径，K3切断的是主线生源 |
| DZ-62 交替拉扯 | K1 → S1 → K2 → S2 → K3 → ZX决定 → B | 主线克生后轮到次线，再追主线生源；同边可弱→强 | 次线后出现的认可结果改变ZX已取得成果的使用/归因/执行接口 |
| DZ-63 错位并行 | 主：K1→S1→K3；次：K2→S2；主先行，次后收束，在ZX选择前汇合→B | 两条时间曲线错开；独立支路不应虚画成交叉 | 删次线，ZX结局必须发生明确变化，否则次线降级为背景 |
| DZ-64 反向承接 | 先K1；次线Z补外部XN → XN的聚焦对象改变 → 主线ZX受压方式变化；另一路B补ZX → ZX决定 | 主角辅助Z的补不是「救ZX」，反而可改强外部克制 | 必须给Z、XN不同主体、认可位置；明确为何补入聚焦会变更ZX的可行路径 |

**3种结尾位置对照**（不强制终局补）：
- 早补：B在K前已成立，后半段检验互补在压力下的持续条件；
- 中补：K→B→K3，在两次限制之间先生成新路径，再让下一阶段检验；
- 晚补：K→S→K3→抉择→B，互补是选择产生的实际结果而非自动奖励。
三个位置与DZ-61—64交叉，形成12个**实验配置槽**（4×3，尚未核验实例）；合并同构或无法满足因果的槽位，不宣称12种全是不同有效故事。

## R7｜四组反事实：角色专属性与构图效力（纸面测试，不是外部盲测）

测试顺序：保持外部事件和同一组边，只替换主角驱动，问初始行动和选择还是否原样成立。ZX存在需要明确公开决定/他者执行/原有主导权变化，仅表情强烈、抢先跑动或「想赢」不够。

| 样本 | ZX人物起手/结果 | 改为Z主 | 改为XN主 | 审查结论 |
|---|---|---|---|---|
| ZX-51 K→B | ZX必须亲自作出并落实此前受阻的公开决定，NX提供被封闭时缺乏的间接路径 | 若只追求谁认可结论，原有ZX被克边不再是同一主角主冲突 | 若长期组织本身是主要目标，ZX不再是角色主驱动 | 起手需明确ZX公开行动，结尾NX只是补具体路径，不是另一个人替她赢 |
| ZX-54 K→S→截源→B | 新决定接口出现后，主角需要利用它做两项被执行的决定，生源消退仍对现有决定权负责 | 认可不是对临时决定接口的同义词 | 既有职业指挥不应误判为XZ新生ZX | XZ源审计若未通过，整条S边标「未成立」 |
| DZ-62 主次交替 | ZX争得具体决定权，Z次线的认可结果影响这一决定能否继续被正确归因/执行 | 若最终只追求被认可，主次倒置 | 若重心变成长期组织任务，角色内微量XN被错误放大 | 两线的同一终点必须精确到某个决定权或执行接口 |
| DZ-64 补克制方 | ZX原有显权受到更加聚焦的XN限制，她通过NX间接路径仍亲自决定 | Z主更易把认可当最终目标；相同顺序可用但不是同一人物链 | XN主可把组织延续当目标，ZX人格驱动消失 | 「Z补XN使其更强」只是条件候选，不自动形成克增强 |

**通用删除/换序测试**：
1. 删除主角ZX的第一步主动实际作用：若剩余故事照样成立，降级为外部世界链。
2. 删除Z支线：若ZX行动条件与最终抉择无变化，标记为独立支线而非强行并行汇聚。
3. 删除NX补：如果此前ZX并无「缺间接路径」的可证明缺口，补不成立。
4. 把K3提前到S1之前：故事将变成「生源未成立/未触发」型，不能继续沿用原先「希望生成后被截」的叙事意义。
5. 把ZX替换为任何普通主动角色，若「公开显权与被他者执行」的机制没有变化，则不构成ZX专属证据。

## R8｜可复用专属链语法（冻结创作输入输出格式，非冻结故事验证结果）

输入（不变）：character={ZX主,Z次,XN微量}；当前十元正本版本及每边机制状态；目标变量/主体/对象ID；时间窗；强度配置；并行/错位/汇合；结尾选择方式。

构图生成：
1. 从正本位置表生成合法候选边，单独标记 locked / research-active；不得在正文把后一类冒充已锁定。
2. 以ZX为主轴，可选择【受克、生发、补缺、改克制方、截生源、外向作用】路径；Z作为次线接入【受克、生发、补外部XN】的实际认可结构。内部微量XN不得与外部XN合并。
3. 时间穷举包括事件首次触发、持续阶段、二次强化与早中晚补；先生成横向状态矩阵（同时有效边）、后生成纵向转移矩阵（真正改变了何种变量）。
4. 输出每一阶段：source→relation→target、对象ID/归属、强度（可选创作旋钮）、mechanism、changed_variable_before/after、residue、next_affordance、主导权/行动权持有者。
5. 先做硬性门禁：关系锁定状态；事件端点同对象/可桥接；删边必要性；主角ZX发动及关键决定；Z次线实际汇合；NX补填真实路径缺口；结局不无代价删除既有XN/其他后果。
6. 之后才能用《动态链质量评估器 v1.0》进行具体故事案例打分，并单独跑其尚未完成的R5跨题材盲测。**本次纸面审查不得冒充Evaluator R5通过**。
