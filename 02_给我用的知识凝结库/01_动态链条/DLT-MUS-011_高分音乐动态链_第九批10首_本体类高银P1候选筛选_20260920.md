## 0. 正本约束
运行时读取 `01-十元系统/十元生补克表.md`：v2.22，2026-07-24。与本批最相关的已锁定关系包括 `xn克zx`、`zx↔nx补`、`zx克n`、`xn生xz`、`x并z生z`、`x生x并z`、`x克z`、`n克xz`、`zn↔x补` 等。关系位置表还存在更多几何边，但没有专项机制证据时不提升为作品关系事件。

## M73｜Who Will Know｜94/100 高银
- 原始：怪物生命承认；旧链 `zn → x → xz → n → zn`。
- 起：ZN8 / X3。承：ZN7 / X7。转：XZ8 / N3。合：N7 / ZN9。
- 时间图：`ZN8 ─→ X7 ─→ XZ8`；转段另起 `N3→7 ─→ ZN9`。
- 合法关系候选：`ZN↔X补`（正本锁定；作品发生待验，强度假设5）；后段若N真实接收/保护并使XZ危险可达性下降，则 `N克XZ`（锁定机制；作品证据待验，强度假设7）。
- 主体/对象：前者ZN主体↔X掌握对象；后者N承载结构→XZ风险主体。
- 因果桥：必须证明“承载能力上升→安全停留/退路恢复→XZ下降”。旧链仅有顺序，不足。
- 终点：ZN回收。传播深度：P0；若补足N克XZ机制证据可升P1。

# 1. 本轮新增母型

### H65｜承载后置风险吸收候选
`XZ高 → N后置上升 → XZ下降 → 核心回收`。只有N实际接住风险主体并改变安全停留/退路变量时才是N克XZ；否则只是时间构图。

### H66｜补位撤除型
`ZN↔X` 原本可能完整 → X边界放弃/失效 → ZN出现缺口。研究重点从“关系发生”扩到“已成立关系被撤除”。

### H67｜壳生成传播候选
`ZN↔X补 → X生X并Z`。若第一关系改变后的X边界正是第二关系的源端点条件，才可能P2。M82是本轮最值得后续实听/原卡深挖的对象。

### H68｜风险—归宿双端补位候选
`XZ ↔ NZ` 不以体量同升为证据，而以“风险路径获得回返终点 / 归宿获得真实失去窗口”双缺口测试为证据。M81是强P1候选。

# 2. 黎黎隆迁移：只迁移时间构图
人物本体保持 `ZX主 / Z次 / XN微量`，不改。

可测试抽象骨架：
```text
外部XN ─克候选→ ZX受限
   │
   └─生→ XZ风险条件
            │
            ├─若XZ真实制造决定空位 ─生→ ZX重新显权
            │
            └─若N承载介入 ─被N克→ 风险下降

ZX ─────↔补↔──── NX
```
说明：这里的外部XN不等于黎黎隆内部XN体量上升。真正值得借H67测试的是“上一关系产生的变量是否成为下一关系的源端点条件”，而不是照抄歌曲十元。
