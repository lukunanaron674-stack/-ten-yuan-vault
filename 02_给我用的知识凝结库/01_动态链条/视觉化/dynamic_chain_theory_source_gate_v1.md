# 动态链理论输入闸门 v1.0

目的：视觉化只能消费“已确认理论”，不能把视觉实验结果反写成十元理论。

## 当前可直接作为理论底座使用
- 核心链：`zn → n → x`
- 判定：`x ≤ n → 回收`
- 判定：`x > n → 崩坏`
- 分叉：`zn → n`（循环） / `zn → x`（崩坏）
- 五维固定映射：
  - 时间 = `xn + z`
  - 本体 = `zn + x`
  - 空间 = `x并z + n`
  - 因果 = `zx + nx`
  - 命运 = `xz + nz`

## 闸门规则
1. 视觉操作失败，只能修视觉操作或生成策略。
2. 视觉操作成功，也不能自动证明一条十元关系成立。
3. 未带明确冻结/确认来源的链，禁止进入 canonical bridge。
4. 允许建立 candidate bridge，但必须显式标记 CANDIDATE，且不得写回十元定义卡。
5. 任何新链进入视觉化前，先补 source_of_truth 与 freeze_status。
