## 一句话目的

把我自己的真实处境（求职 / 创作 / 项目 / 关系）用 674-105 的动态链语法做成**可审计的链**：不是事件流水账，而是「前一阶段制造后一阶段」。

## 铁律（继承 674-105）

1. 不重定义十元本体（X / Z / N / ZN / NZ / XN / NX / ZX / XZ / X并Z）。
2. 五轴相反关系不自动写成生克补；同框、攻击、成长、帮助都不自动算生克补。
3. 一条合格边必须记录齐：`trigger / mechanism / changed_variable / Δ / residue / next_affordance / relation_type / reversibility`。
4. 位置允许 ≠ 实际发生；固定对子不许串（如 N补X并Z ≠ N补ZN）。
5. 每条链单独一个 md 文件，文件名 `链NNN_标题.md`；本表只登记状态，不复制正文。
