# MUS-CHAT-02 / 03｜关系判定与基础位置组合穷举

> 结论：基础位置合法、情境事件成立、前后状态继承是三道不同的检查。位置合法不是事件发生，事件发生也不是有效连续动态链。此次为 Chat 内机械枚举与构造例逻辑检查，**不是**听音、多人盲判、审美评价或实际泛化准确率。

## 1. 规则依据与判定门禁

来源为已核对的 `01-十元系统/关系五对校验包_v0.1.md`：生10条、克10条、补4个无向对（按有向使用为8条），总计28条已确认有向边。补 `XN↔Z` 仍待校准，未纳入穷举。

两级检查：
1. 十元位置盘、边型和箭头方向是否满足 canonical；不满足则 FAIL（十元候选关系）。
2. 具体行为、源/目标对象、改变变量、before/after、机制与替代解释是否支持该作用。

判定标签：
- PASS：在记录的明确情境及机制条件下成立；构造例的 PASS 不等于外部实证。
- FAIL：方向/位置不合法，或可观察事件否定了所主张的机制。
- AMBIGUOUS：证据不足或替代解释无法排除。
- NONE：没有必要把已观察到的并行、相邻或普通变化标注为生克补。

### 构造最小反例

| 候选 | 情境变化 | 标签 |
|---|---|---|
| XN克ZX | 流程实质阻断其既有行动路径 | 构造情境 PASS |
| XN克ZX | 流程存在但既有行动毫不受限 | NONE |
| XN克ZX | 行动失败但流程/设备故障无法区分 | AMBIGUOUS |
| ZX生ZN | 主动行动导致原本不存在的持续归属关系形成 | 条件性 PASS |
| ZX生ZN | 仅短暂接触，无持续关系 | 不足以确认生成 |
| ZX生ZN | 关系早已存在，先前行动不是其生成条件 | 原主张 FAIL |
| ZN克XN | 归属关系具体阻断一项已有流程 | 条件性 PASS |
| ZN克XN | 关系与流程共存，流程不受限制 | NONE |
| X补ZN | X 提供 ZN 原缺失的决定边界，作用变量变化 | 补候选，待证 |
| X补ZN | 只有共现，无缺口、补足机制及结果 | NONE |
| Z补ZX | 因“机灵帮助行动”直接记标准补 | FAIL：不在已确认位置盘 |
| XN克ZN | 把具体限制直接视为此标准克方向 | FAIL：基础方向不合法（ZN克XN 才是标准边） |

## 2. 穷举方式及可复核计数

有向图节点为10个十元，已确认边28条（生10、克10、补8）。每条边记录 `source,relation,target`。2步链指 `edge1.target == edge2.source`；3步链再连接一条同样满足端点相等的边。允许重复节点/立即返向，计入的是位置组合，不是独立故事。

- 2步有向连续位置路径：**80**，关系型9类。
  - 生→生10；生→克10；生→补8；
  - 克→生10；克→克10；克→补8；
  - 补→生8；补→克8；补→补8。
- 3步有向连续位置路径：**228**，关系型27类。
- 2步立即返回源十元路径：8（确认的补对反向往返），不自动等于新增纵向变化。
- 3步返回源十元路径：30（位置闭合候选），不能宣称30个有效反馈/回收母型。
- 3步经过4个互异十元位置的路径：158（仅位置层的去重特征，非事件因果合格率）。

### 示例：合法路径 ≠ 因果通过

```text
XN ─克→ ZX ─生→ ZN ─克→ XN
XZ ─克→ ZN ─生→ N  ─克→ XZ
ZN ─克→ XN ─克→ ZX ─生→ ZN′
```

这些边在基础位置上合法；应分别提出并验证中间主体如何获得条件、对象跨阶段是否一致、前段 delta 能否作为后段输入、最终新状态是否实际反向作用于源对象。

### 横向并行候选

```text
XZ ─克→ ZN ←补─ X
             │
             └─生?→ N
```

XZ克ZN、X补ZN、ZN生N 均为基础合法边；但两条横向边可能作用于不同变量而互不抵消，后续生成是否依赖其汇合必须另证。
