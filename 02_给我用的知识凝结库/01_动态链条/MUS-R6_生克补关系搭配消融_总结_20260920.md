# MUS-R6｜生克补关系搭配消融：总结与交接

> 一句话结论：**有效的动态链，不是生克补标签的排列，而是前一阶段的具体变化能否构成下一阶段的启动条件。**
>
> 本轮为**构造情境中的理论消融**，不是已完成真实音频改编、独立盲听或审美效果验证。不得将其“完成”状态混同于仓库现有 Dynamic Chain Evaluator 的 R6 项目实战里程碑。

## 1｜研究问题及输入

固定同一主体、目标、环境与初始障碍，在尽可能不更动其他条件的前提下，分别删除条件、交换获得顺序、调转关系的作用方向、组合横向条件，以及改变既有关系的作用范围，观察后续状态是否不同。

构造场景仅用于测试因果：黎黎隆（ZX 主 8 / Z 中 5 / XN 小 2）试图救出城市收容区中的奇幻生命。城市门禁 XN 限制她的直接救援行动 ZX；可用维护通道暂设为需要 **K：获知开启时机** 和 **C：奇幻生命主动配合** 两个条件同时满足。

### 统一基准

```text
初始：城市 XN 9 ──克──→ 黎黎隆 ZX 8
直接路径：被阻断
K：获知维护通道开启时机（主角既有 Z 的机灵/变通的具体表现）
C：奇幻生命主动配合
终点条件：K ∧ C → 维护通道可用 → 救援行动可继续
```

**十元合法性约束**：`XN 克 ZX` 在《关系五对校验包 v0.1》基础克环中有位置依据；“Z 帮助 ZX”仅记作主体内部能力协同或 `none`/待判，不自动记为 `Z 补 ZX`；合作不自动成为 `ZX 生 ZN`，须另有持续关系与合法边的证据。不得因剧情动词“帮助”“生成”直接推定标准边型。

## 2｜五组消融：操作、结果与边界

| 实验 | 冻结项与操作 | 在构造条件下所得结论 | 不可越界推断 |
|---|---|---|---|
| E1 关系/条件删除 | 冻结目标与设施规则；分别移除 K、C | 无 K 无 C：受限；仅 K：有路线信息但缺开启条件；仅 C：有合作但缺时机；K+C：路径可用。K、C 在此模型中联合必要 | “共同必要”不自动证明参与者在十元本体上互补 |
| E2 顺序替换 | 保持 K、C 均可获得，交换其先后 | 无时间窗口/状态依赖时，终点均可为 K∧C，**顺序未必改变最终结果** | 若额外加入短暂窗口，已增加新变量，不能把变化单独归因于排序 |
| E3 方向替换 | 固定主角与奇幻生命，改由谁向谁提供条件 | 可改变谁是提供者、接受者、行动依赖及后续关系位置 | 若角色能力/初态不支持反向作用，反向版本无效；位置盘的有向边也必须重新核对 |
| E4 横向复合 | 将 K 与 C 作为不同来源的必要输入，在同一阶段汇合 | 并行支路共同使新路径成立；该新状态可进入下一阶段作为输入 | 不能把并行支路硬写成 `K 生 C` 或 `C 生 K` |
| E5 作用范围 | 保持“XN 限制 ZX”的候选边型，分别限制正门、正门+维护通道、全部已有路径 | 同一关系类型可因**适用范围与可替代路径**不同而出现不同后续 | 不是纯粹的“体量单变量”实测，不能直接折算为 XN 6/8/10 或克量 |

### 横向支路与纵向推进（示例）

```text
横向 T0：城市 XN ─克→ 主角 ZX（直接入口失效）
                         │
                         ├── 主角 Z 发现开启时机 → K
                         └── 奇幻生命主动配合 → C
                                               │
纵向 T1：                 K + C ──共同满足──→ 新路径可用
                                               │
纵向 T2：                            ZX 经新路径实施救援
                                               │
纵向 T3：       救援结果可能为持续合作关系提供条件（待证）
```

**回收对象**：起点“救援路径被阻断”的问题；终点通过新路径回应这一问题。门禁仍在不妨碍局部行动回收。不能因“救援成功”自动宣称所有世界观冲突回收。

## 3｜保留为候选的结构规则

1. **条件分账**：分别记下克限制什么变量、补候选增加什么条件、新路径依赖什么条件；不能用十元体量相减、相加代替机制。
2. **状态继承**：前段输出的 `changed_variable / delta` 应成为后段某条关系的输入、启动条件或新的作用对象；若后段不依赖该结果，只能记并行或顺序相邻。
3. **顺序依赖须另证**：只有明确时间窗口、资源消耗、前置条件或不可逆状态时，调序才可能改变可行性。不得通过暗加情境条件使某一排列必胜。
4. **方向须双重验证**：位置盘合法 + 参与者当前能力/条件确能实施；反转不是简单倒箭头。
5. **关系作用范围独立于类型**：同是 XN 克 ZX，局部门禁与全路径限制可导致不同可行空间；强度/体量必须有独立标定。
6. **回收不等于关系消失**：起点的具体问题得到可追踪回应即可构成局部回收；原始限制可以仍然存在。
7. **允许 none**：帮助、合作、路径发现、时间连续、主题再现都不是自动的标准生克补边。

## 4｜研究所得与未验证内容

**已完成**：五组构造情境的逻辑消融与变量分账；建立“同结果不代表同路径”“关系排序不必然改变结局”“共同必要不等于标准补对”等防错规则；建立用于 R7 的输入/输出模板。

**未完成**：在实际音频中制作受控改编并由听众盲判；独立标注者对十元符号、关系类型和方向的一致性检验；体量 1–10 的操作量表验证；不同关系搭配的审美效果验证。不得据此给 MUS-10、MUS-02 或本轮构图计算新的音乐质量分。

**实验限制**：维护通道需 K∧C 是人为设定，结论仅在该情境下成立；角色、外部设施及生命的能力如果被改写，已不是单因素消融。人物行动因果不能直接等同于音乐材料中的功能依赖。
