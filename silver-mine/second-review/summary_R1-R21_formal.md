## 1. 五大主题锚点总表

| 五大主题 | 核心锚点 | 是否稳定 | 判准尺一句话 | 最大风险 |
|---|---|---|---|---|
| 时间 xn+z | 《暖暖内含光》《降临》《下一站，天国》 | 稳定 | 时间仓真正看“经历、记忆、选择、语言、关系如何被规则/顺序/回放/压缩结构重新组织”。 | 怀旧、非线性形式、结尾感动、时间设定奇观冒充结构。 |
| 本体 zn+x | 《未麻的部屋》《纽约提喻法》《人生切割术》 | 稳定 | 本体仓真正看“谁正在夺取、替换、切割或改写主体资格”。 | 把身份焦虑、精神崩溃、职场痛苦、元叙事形式直接当本体。 |
| 空间 x并z+n | 《楚门的世界》《寄生虫》《狗牙》 | 稳定 | 空间仓真正看“空间如何决定进入、停留、观看、隐藏、圈养、逃离”。 | 漂亮场景、房子/小镇/家庭、阶级情绪、封闭氛围冒充空间结构。 |

| 命运 xz+nz | 《小偷家族》《牯岭街少年杀人事件》《亲爱的》 | 稳定 | 命运仓真正看“失归者如何寻找停靠，停靠如何生成、错认、断链或重判”。 | 悲伤氛围、亲情催泪、青春残酷、结尾离散感冒充命运结构。 |

## 2. 升核心锚点名单

| 作品 | 五大主题 | 升锚点理由 | 判准作用 |
|---|---|---|---|

| 《降临》 | 时间 xn+z | nx 解码 x并z 符号，生成 xn 非线性时间认知，改写 zx 选择。 | 校正“时间不是设定，而是认知结构被改写”。 |
| 《下一站，天国》 | 时间 xn+z | xn 中转规则压缩人生，z 单点记忆生成 nz 永恒停靠。 | 校正“记忆不是怀旧，而是被规则提纯后的停靠点”。 |
| 《未麻的部屋》 | 本体 zn+x | x并z 偶像外壳反咬 zn+x，nx 真假审查失稳。 | 校正“本体危机不一定 zn 起手，表象可夺身”。 |
| 《纽约提喻法》 | 本体 zn+x | x并z 作品外壳吞入生活，xn 排练机制无终，主体被角色替换。 | 校正“作品不是只表达主体，也可能吞食主体”。 |

| 《20世纪少年》 | 因果 zx+nx | zx 童年游戏经 x并z 符号组织化，激活 nx 暗账回流。 | 校正“童年不是怀旧，符号组织化后会变成因果怪物”。 |

## 4. 新增动态骨型

### 时间仓 xn+z

1. **擦除回吸链**  
   `zx 主动擦除 → xn 程序删除 → nz 残影回吸 → 空白处再触发关系`  
   样本：《暖暖内含光》

2. **解码换时链**  
   `nx 语义判断 → x并z 符号接口 → xn 时间认知改写 → zx 选择被重写 → zn 被压出`  
   样本：《降临》

3. **单点封存链**  
   `xn 中转规则 → 人生经验被压缩 → z 单点记忆被选出 → nz 永恒停靠 → zn 被压出`  
   样本：《下一站，天国》

### 本体仓 zn+x

4. **表象夺身链**  
   `x并z 外壳生成 → 外壳反咬 zn+x → nx 审查失稳 → 自我资格崩裂`  
   样本：《未麻的部屋》

5. **作品吞生链**  
   `x并z 作品外壳启动 → 生活被作品化 → xn 排练无终 → zn+x 被角色替换`  
   样本：《纽约提喻法》

6. **人格切割殖民链**  
   `xn 制度切割 → zn+x 主体被拆开 → x并z 职业外壳殖民 → 双我反咬制度`  
   样本：《人生切割术》

### 空间仓 x并z+n

7. **包装空间破壳链**  
   `x并z 包装 n → 生成观看空间 → nx 异常识别 → zn+x 主体破壳出逃`  
   样本：《楚门的世界》

8. **空间寄生爆裂链**  
   `zx 主动寄生 → x并z 身份伪装 → x并z+n 阶级容器 → 隐层显影 → n 承载爆裂`  
   样本：《寄生虫》

9. **语言围栏逃逸链**  
   `xn 命名规则 → x并z+n 现实围栏 → zn+x 主体圈养 → z 刺破规则 → x 反咬逃逸`  
   样本：《狗牙》

### 因果仓 zx+nx

10. **暗线空洞链**  
   `zx 调查推进 → nx 判断失效 → xz 污染行动 → 因果不可结算`  
   样本：《杀人回忆》

11. **善意反咬链**  
   `zx 善意行动 → nx 旧罪暗账 → nx 反咬 zx → x 失控显影 → zn+x 审判悬置`  
   样本：《Monster》

12. **童年暗账放大链**  
   `zx 童年游戏 → x并z 符号保存 → x并z 组织化放大 → nx 暗账回流 → 旧游戏反噬世界`  
   样本：《20世纪少年》

### 命运仓 xz+nz

13. **临时家庭生成链**  
   `xz 临界遭遇 → nz 停靠回应 → n 临时家庭生成 → 外部 n/xn 夺回资格 → zn 被压出`  
   样本：《小偷家族》

14. **停靠错认断链**  
   `xz 青春失归 → nz 停靠错认 → x 被污染放大 → x 破 nz → 杀人断链 → zn 失去落点`  
   样本：《牯岭街少年杀人事件》

15. **双重归属重判链**  
   `xz 亲缘失散 → nz 原停靠断线 → nz 第二停靠生成 → nz 互相反咬 → zx 寻找认领 → 停靠资格重判`  
   样本：《亲爱的》

## 5. 创作模板库可转化项

| 骨型 | 可转成什么故事模板 |
|---|---|
| 擦除回吸链 | 主角主动删除关系/记忆/身份，但被删除之物从残影中回吸，空白处重新相遇。 |
| 解码换时链 | 主角解码不可读符号，符号反过来改写时间认知，使选择在已知代价中重做。 |
| 单点封存链 | 角色被规则要求从一生中选择一个记忆点，让单点承担永恒停靠。 |
| 表象夺身链 | 公众形象、账号、偶像壳、替身外壳脱离本人，反过来争夺“谁才是真的我”。 |
| 作品吞生链 | 创作者用作品复刻人生，作品逐渐扩张成规则系统，最终替换作者主体。 |
| 人格切割殖民链 | 制度把人格切成可用版本，再用职业/组织外壳殖民其中一半。 |
| 包装空间破壳链 | 角色生活的家/小镇/社区其实是观看机器，角色通过异常识别破壳逃离。 |
| 空间寄生爆裂链 | 下层人物借伪装进入上层空间，隐藏层显影，阶级容器过载爆裂。 |
| 语言围栏逃逸链 | 权威改写词义制造封闭现实，角色利用规则裂缝反咬出逃。 |
| 暗线空洞链 | 调查行动持续推进，但暗线判断无法闭合，行动越努力越暴露空洞。 |
| 善意反咬链 | 主角一次善意选择进入旧账，多年后反咬自身信念与行动资格。 |
| 童年暗账放大链 | 童年游戏/标志/预言被成人世界组织化，最终反噬现实。 |
| 临时家庭生成链 | 临界漂流者被非法但真实的日常照料接住，形成临时家庭，又被外部资格夺回。 |
| 停靠错认断链 | 失归者把某段关系误认成唯一归宿，停靠失败后 x 爆裂断链。 |
| 双重归属重判链 | 失散者在另一处生成真实停靠，原归属归来后两套归属争夺资格。 |
