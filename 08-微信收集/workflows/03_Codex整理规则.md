# Codex 整理规则

当用户说“微信收集好了”时：

1. 扫描：

```text

```

2. 读取最新 txt / md。
3. 输出整理到：

```text

```

## 整理格式

```markdown

## 来源

- 聊天：
- 时间：
- 原始文件：

## 核心信息

## 待办

## 人物 / 项目 / 素材

## 可归入 Obsidian 的位置

## 原文摘录
```

## 注意

- 不要伪造没出现的信息。
- 私人敏感内容只做本地整理，不外发。
- 如果原文混乱，先做“粗整理”，不要过度推断。
