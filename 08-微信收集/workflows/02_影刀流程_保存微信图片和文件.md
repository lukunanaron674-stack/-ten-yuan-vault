# 影刀流程：保存微信图片和文件

动作名：`collect_wechat_attachments`

## 目标

把微信聊天中的图片、文件、压缩包、文档另存到 Obsidian 附件目录。

## 保存目录

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\08-微信收集\attachments
```

## 录制步骤

1. 打开微信目标聊天。
2. 找到图片或文件。
3. 右键。
4. 选择“另存为”或“保存到”。
5. 保存到 attachments 目录。
6. 文件名尽量加聊天名和日期。

示例：

```text
画师群_参考图_2026-07-10_01.png
客户A_需求文档_2026-07-10.docx
```

## 整理规则

- 不覆盖旧文件。
- 不要删除微信原文件。
- 不要自动发送或转发。
- 保存完告诉 Codex：“微信附件保存好了”。
