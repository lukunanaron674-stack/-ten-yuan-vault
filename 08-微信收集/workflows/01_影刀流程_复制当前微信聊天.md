# 影刀流程：复制当前微信聊天

动作名：`collect_current_wechat_chat`

## 目标

把微信电脑版当前聊天窗口的可见内容复制成文本文件，放到 Obsidian 的微信收集 inbox。

## 保存目录

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\08-微信收集\inbox
```

## 录制步骤

1. 打开微信电脑版。
2. 进入目标聊天窗口。
3. 点击聊天记录区域。
4. 按 `Ctrl + A`。
5. 按 `Ctrl + C`。
6. 新建文本文件，粘贴。
7. 保存到：

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\08-微信收集\inbox
```

文件名建议：

```text
微信_聊天名_主题_YYYY-MM-DD_HH-mm.txt
```

## 如果 Ctrl+A 复制不到完整聊天

用这个替代流程：

1. 在微信聊天里点右上角搜索。
2. 输入关键词。
3. 逐条打开相关结果。
4. 复制相关消息上下文。
5. 保存成同一个 txt 或多个 txt。

## 输出结果

如果会写 JSON，写入：

```text
C:\Users\19308\Documents\Obsidian\ten-yuan-vault\08-微信收集\outbox\result.json
```

成功格式：

```json
{
  "ok": true,
  "action": "collect_current_wechat_chat",
  "source": "WeChat",
  "chatName": "聊天名",
  "textFiles": [
    "C:\\Users\\19308\\Documents\\Obsidian\\ten-yuan-vault\\08-微信收集\\inbox\\微信_聊天名_主题_2026-07-10_0105.txt"
  ],
  "attachments": [],
  "createdAt": "当前时间",
  "error": null
}
```

不会写 JSON 也没事，只要 txt 保存到 inbox，Codex 会自己扫描。
