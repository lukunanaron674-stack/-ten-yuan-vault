## 02 JSON契约、人物同体与证据等级

遵守**实际当前累计JSON字段**，现行R47已核结构如下；保留老字段与未知扩展，不重新生成清空旧数组的JSON。

- `people[]`：`QSP-####`、`name`、`aliases`、`type`（PERSON / UNRESOLVED_IDENTITY / ANONYMOUS_PERSON / HISTORICAL_PERSON）、`source_chapters`、`evidence_sources`、`world_impact_P`、`ten_yuan` 等。无证同体只登记开放问题，不随意合并ID。
- `relationships[]`：`QSPR-####`、`source`、`target`、`type`、`chapter`、`description`、`evidence_status`、`source_file`；`source/target` 必须指向已有QSP。旧数据可有 `ACTION_REPORTED` 等枚举，**不能为统一枚举破坏性改写历史记录**。
- `person_organization_edges[]`：`QSPA-####`、`person_id`、`organization_id`、`relation`、`evidence_chapter`、`evidence_status`、`source_file`。组织端点只能是R24实际存在的 `QS21-###` / `QS22-N###`。
- 每条新证据：作者章号/题名、来源URL或章卡路径、实际行动与结果、人物关系及时点、证据等级和边界。必须区分 `FACT`、`TESTIMONY`、`PROPOSAL`、`ACCUSATION`、`INFERENCE`、`DECISION`、`PLAN`、`EXECUTION`；模型不兼容的新等级可留在附属MD，不将推断写成FACT。
- **同体去重**优先同一QSP + 作者章 + 行为/关系类型 + 实际内容 + 证据来源；同段不同转载站不算两个事件。代号、同名、别名、匿名身份需要原文锚；仅相同称谓不足以合并。
- 人物组织关系不能自动生成组织`part-of`。过去任职≠现在任职，申请≠获准，获准≠履职，邀约≠实际合作；家族资助≠军权；个人P≠组织W。
- 具体反例：太子提议给陈迹右司卫≠已任命；带路甲士被怀疑景朝细作≠确证谍籍；交俘决议≠交俘完成；掌柜承诺有密道≠通道真实；乌云闻到声音≠已证谋杀。老吴、胡三爷/胡钧羡、掌柜/东家、阿大/阿四/二刀/袍哥等身份冲突不能无证合并。
- 十元在现行理论中是**情境下的感受基元**，不是“此人永远属于某固定十元”；人物采集阶段不自动评分/映射。

## 03 来源分级与作者章节覆盖

- 校准章号依**作者章题 + 相邻章 + 正文边界**；不同小说站URL编号、合页、请假条可能错位，不按`chapterNumber`直接替代作者章号。多站镜像不一定是独立源；异书混入标`SOURCE_CONTAMINATED`。
- 可用状态：`INDEX_ONLY`（目录）、`OPENING_ONLY`（章首）、`BODY_PARTIAL`（可读正文片段）、`EXISTING_CHAPTER_NOTES_PARTIAL`（既有章卡）、`SINGLE_REPRINT_BODY_TO_END`（单站转载见章末）、`SOURCE_GAP`（缺正文）、`SOURCE_CONTAMINATED`（污染）。**转载到章末≠出版原著/严格全文PASS**。
- 对旧严格PASS冲突、镜像序号偏移、来源争议分别挂账；不能把“检查过目录”计为“整章已核”。历史有859/860乃至后续作者章的来源范围问题，**不可硬编码总章数或按人物数算完成率**。
- 来源耗尽可登记`SOURCE_LIMITED_AND_READY_FOR_FURTHER_TEXT`，不能假报全书穷尽；单次STOP不等于最终Done。
